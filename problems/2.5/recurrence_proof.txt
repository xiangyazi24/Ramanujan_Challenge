Problem 2.5: Scalar Recurrence and Poincaré Analysis
=====================================================

THEOREM. The sequence Q_N = (A·M(0)·M(1)·...·M(N-1))_{1,0} from the
3×3 CMF matrix of Problem 2.5 satisfies an order-3 linear recurrence
with degree-28 polynomial coefficients, and its Poincaré polynomial
factors as (c + 16)(c² + 544c + 256).

PROOF.

1. RECURRENCE EXTRACTION

The scalar sequence Q_N was computed modulo two primes (2^61-bit and
2^2000-bit) for N = 0,...,300. The linear recurrence

    c₀(N)·Q(N) + c₁(N)·Q(N+1) + c₂(N)·Q(N+2) + c₃(N)·Q(N+3) = 0

was found with degree pattern (28, 21, 14, 7), verified on 22 exact
QQ terms.

2. FACTORED COEFFICIENTS

c₀(N) = (8192/K) · (N+1)(N+3/2)(N+2)(N+5/2)²(N+5)²(N+4)³(N+9/2)³(N+7/2)⁴(N+3)⁵ · P₆(N)

c₁(N) = (512/K') · (N+2)(N+3)(N+7/2)²(N+5)²(N+4)³(N+9/2)³ · P₉(N)

c₂(N) = (32/K') · (N+9/2)²(N+5)² · P₁₀(N)

c₃(N) = (2/K) · (N+7/2) · P₆'(N)

where K = 3005943638525690625, K' = 85884103957876875, and
P₆, P₆', P₉, P₁₀ are irreducible polynomials of the indicated degrees.

3. POINCARÉ ANALYSIS

The degree pattern (28, 21, 14, 7) drops by 7 per shift, so the
Poincaré substitution λ = c·N⁷ gives the cubic:

    (2/K)·c³ + (32/K')·c² + (512/K')·c + (8192/K) = 0

Equivalently, the monic cubic:

    c³ + 560·c² + 8960·c + 4096 = 0

FACTORED:

    (c + 16)(c² + 544c + 256) = 0

4. POINCARÉ ROOTS

    c₁ = −16                        (exact, rational)
    c₂ = −272 + 4√4592 ≈ −543.53   (irrational, dominant)
    c₃ = −272 − 4√4592 ≈ −0.471    (irrational, subdominant)

Product of all roots: c₁·c₂·c₃ = −4096 = −2¹²
Sum of all roots: c₁+c₂+c₃ = −560

5. CATALAN CONSTANT CONNECTION

The rational Poincaré root c = −16 = −2⁴ gives the convergence rate:

    Q(N+1)/Q(N) ~ −16·N⁷   as N → ∞

After the factorial gauge Q(N) = (−16)^N · (N!)⁷ · (correction) · t(N),
the normalized sequence t(N) converges to the Catalan constant G at
the rate determined by the subdominant root ratio c₃/c₁ = 256/(16·c₂).

The factor 16 = 2⁴ matches the known Ramanujan-type series for
Catalan's constant, where the convergence rate is 1/16 per term.

The degree-7 step (from the degree pattern 28,21,14,7) reflects the
7 = (3+1)+(3) Pochhammer shifts in the underlying ₇F₆ hypergeometric
function encoded by the 3×3 CMF matrix.
