## 1. 独立重推导的基本结构（可当事实用，均有机器验证或两行证明）

记 r = n − p ∈ [0, p)，窗口 p ∈ (n/2, n]。

**1.1 窗口等价**。Gessel 数位定理（n = 1·p + r）给 b_n ≡ b_1 b_r = 5 b_r (mod p)，5 是单位（p>5），故

  H(n) = #{p ∈ (n/2,n] : p | b_n} = #{p : n−p ∈ Z_p}，**精确等价**。

猜想的等价形式：**单个整数 b_n 的素因子中落在 (n/2,n] 的个数 = o(n/log n)**，即顶部窗素数只携带 log b_n = (log α)n ≈ 3.5255n 质量中的 o(n)。

**1.2 尺寸论证原则性失效（7 倍富余）**。窗口总 log 质量 θ(n)−θ(n/2) = n/2 + o(n)，而 log b_n ≈ 3.5255n ≈ 7.05×(n/2)。even 全部窗素数以 **p³** 整除 b_n 也只需 1.5n < 3.53n。任何"b_n 装不下"式论证不可能成立。

**1.3 gcd 的价结构**。v_p(gcd(d³a_n, d³b_n)) = 3 + min(v_p(a_n), v_p(b_n))，p ∈ (n/2,n]。贡献为 0 当且仅当 v_p(a_n) = −3（a_n 带满 1/p³）。a_n = b_n H_n^{(3)} + 尾项 的分解显示 1/p³ 系数 ≈ b_n + 修正，与卷宗事实 1 的 p | b_n 判据一致（细节从略，判据以你们已验证版本为准）。

**1.4 卡索拉蒂排斥**。W_r = a_r b_{r−1} − b_r a_{r−1} = 6/r³，对 r < p 是 p-单位（a_r 在 r < p 时 p-整）。推论：Z_p 无相邻元素；p | b_r ⟹ a_r, b_{r±1} 皆 ≢ 0；**同一 p 不能同时是 n 与 n±1 的坏素数**。

**1.5 反射与坏性对合**。事实 3 给 Z_p 关于 r ↔ p−1−r 对称。推论：(n,p) 坏 ⟺ (n′,p) 坏，n′ = 3p−n−1，且 p 自动落在 n′ 的窗口内（两端不等式都自动满足）。这是 (n,p) 平面上的对合，不动点 p = (2n+1)/3。坏性由此**成对散开**到不同的 n′——反集中的启发式信号，但我没能把它变成定理。

**1.6 边缘排除（目前唯一无条件点态排除）**。z = n−p ≤ log_α(n/2) ⟹ 0 < b_z < p ⟹ p 不坏；反射后 z 接近 p−1 的对称带同样排除。只排 O(log n) 个素数。数值上还有：z ∈ {0,1} 及反射位由 b_p ≡ 5, b_{p+1} ≡ 25 (mod p³/p) 直接排除。

## 2. 不可能性引理（no-go）：行局部信息到不了点态

**引理**。设某证明只使用如下"逐行"事实：每个 Z_p 反射对称、|Z_p| ≤ 3p^{2/3}（或任何 ≥ 4 的容量界）、无相邻元素、值分布/能量界 N_p(c) ≤ 8p^{3/4}、E(p) ≪ p^{5/3}、以及任意只约束单个 p 之数据的性质。则该证明不能给出点态 H(n) = o(n/log n)。

**证明**。给定目标 n₀，对每个 p ∈ (n₀/2, n₀] 取 Z*_p = {n₀−p, p−1−(n₀−p)}（若两元素相邻则弃掉该 p，至多 O(1) 损失）。每行满足全部所列约束（2 个元素、对称、不相邻、值可自由安排以满足能量界），而 H*(n₀) = (1−o(1))·(π(n₀)−π(n₀/2))。∎

**推论（战略）**：卷宗事实 2、3、4 全是行局部的；事实 5 是纵向的（p-幂指标，不联结同一 n 处的不同素数）；事实 6 是逐 p 的代数结构。**密度-1 结果已经榨干了行局部信息的极限**；点态需要一条真正的跨素数全局律。改进 |Z_p| 指数、改进能量指数，对点态是死轴。

## 3. 三分法校准：可除序列 / 代数 / Apéry

把同一个点态问题移植到三类模型序列上，结论截然不同（全部机器验证）：

**3.1 可除序列极点（Mersenne, Fibonacci）：点态可证，n^{1/2+o(1)}**。
Mersenne M_n = 2ⁿ−1：坏 p 有不变量 d = ord_p(2)，满足 **d | n**（apparition）与 **p ≡ 1 (mod d)**（同余刚性），且 ord = d 的素数共同整除单个整数 2^d−1（预算刚性）。双重计数交叉：
  H_M(n) ≤ Σ_{d|n} min(n/2d + 1, d·log2/log(n/2)) ≤ τ(n)·√(n log2/(2log n)) = n^{1/2+o(1)} = o(n/log n)。✓
Fibonacci：我验证了恒等式 **p | F_{n−p} ⟺ p | F_{n−ε}，ε = (5|p)**（300 随机试验 0 反例；两行证明：F_{p−1}≡0 或 F_{p+1}≡0 按 ε 分类）。于是 d = ω(p) | gcd(n−p, p−ε) ⟹ d | n−ε，同模板得 n^{1/2+o(1)}。

**3.2 代数极点（中心二项式）：点态在每个 n 处为假**。
c_r = C(2r,r)（代数生成函数 (1−4x)^{−1/2}，同样有 Lucas 结构）：Kummer 进位给出 **p | c_{n−p} ⟺ 2(n−p) ≥ p ⟺ p ≤ 2n/3**。故 (n/2, 2n/3] 的全部素数都坏：H_binom(n) ≈ (1/3)·窗口素数数，**正比例，对每个 n**。验证：n=500: 14/42；n=1234: 29/89；n=5000: 103/302。其 Z̃_p = 区间 [⌈p/2⌉, p−1]——注意它**不**反射对称：反射对称性(事实 3)是 Apéry 算子自对偶(Sym²/K3)的真非泛型特征。

**3.3 Apéry 居中**：非可除序列（Z_p 不是等差列，无 apparition 秩），非代数（|Z_p| = O(p^{2/3}) 已证稀疏，数值上 O(1)）。**缺的东西有了名字：apparition 律的替代物**——一条把"p | b_r"翻译成"某低复杂度不变量 inv(p) 与 (n, p) 的同余条件 + 共享 inv 的素数共同整除一个小整数"的定律。Mersenne 模板显示：一旦有这样的律，点态就机械地跟出来（√n 界）。

**双重过滤器（评审任何未来证明思路用）**：(i) 只用行局部事实 ⟹ 被 §2 杀死；(ii) 机制若移植到 C(2r,r) 依然"成立" ⟹ 被 §3.2 杀死（那里结论为假）。两条合用相当锋利。

## 4. 新超同余（本报告主要正面产出）：万有 mod-p² Gessel

把 v_r := b_{p+r} 看作 r 的序列，其递推系数为 P(p+r)，按 p 展开到一阶 ⟹ 修正项 g_p(r) := (b_{p+r} − 5b_r)/p mod p 满足以 b 为源的非齐次递推，故 g_p = G^{univ} + x_p a + y_p b。数值惊喜：**对所有测试素数 x_p ≡ 10, y_p ≡ 0，无任何 p 依赖**（p < 200 全部 r 验证，0 反例），且万有序列被识别为调和加权导数 Apéry 和：

  **定理 N1（数值上确立；11 ≤ p < 200 全指标验证）**
  b_{p+r} ≡ 5 b_r + 10 p D_r (mod p²)，对所有 r < p，
  其中 D_r = Σ_{k=0}^r C(r,k)² C(r+k,k)² (H_{r+k} − H_{r−k})，D_0 = 0, D_1 = 6。

（校核样例：p=7, r=1: 25 + 70·6 = 445 ≡ 4 = b_8 mod 49 ✓。r = 0 退化为 Beukers b_p ≡ 5，且已知 mod p³ 成立。等价改写 G_r + 10a_r = 10D_r 亦给出恒等式 D_r = 2Σ C²C²(H_{r+k} − H_k) 与 a_r 的关系。）

**文献待查**：此式可能在 Coster 学位论文(1988)或 Osburn–Straub 一系超同余文献中；即使已知，下面的战略解读仍然成立。

**战略解读（对点态的意义，双刃）**：
- 负面：我原本最看好的"一阶 Frobenius 导数不变量当 apparition 律"**此路不通**——一阶形变完全万有，携带零比特 p 信息。
- 正面：这本身是强刚性，并精确指出 **p 依赖的 Wieferich 型不变量最早出现在 mod p³**：写 b_{p+r} ≡ 5b_r + 10pD_r + p²(E_r^{univ} + x′_p a_r + y′_p b_r) (mod p³)，则 (x′_p, y′_p) ∈ F_p² 是第一批真不变量。**建议立刻数值提取 (x′_p, y′_p) 并测试其与 γ_p（level-6 权-4 系数）、Fermat 商、Bernoulli 数的相关**。若 x′_p 有模形式表达式——那就是 apparition 律的藏身处，§3.1 模板随即接管。同样值得做：反射恒等式 y_{p−1−n} = y_n 的 mod-p² 一阶形变（其修正序列是什么？）。

**5.2 预算引理（杀死伴随整数路线）**。若某机制给出"每个坏 p 整除显式整数 X_n"，要得 H ≤ c·n/log n 需 log X_n ≤ c·n·(约)。所有自然候选（b 的组合、卡索拉蒂化整 d³W = −6d³/n³、交叉卡索拉蒂 b_na_m − a_nb_m）要么带 d³ 死重（v_p ≥ 3 平凡）、要么 log 尺寸 ≥ A·(间距)。Fibonacci 案例是清醒剂：那里坏 p | F_{n∓1} 是精确的，但 log F ≈ 0.481n > 窗质量的一半，预算仍旧透支——**Fibonacci 的点态也不是靠预算证的，是靠同余刚性**（§3.1）。结论：找伴随整数不如找同余刚性。
