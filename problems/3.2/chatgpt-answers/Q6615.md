# P3.2 Index-Mellin comparison: first construction map

## Executive verdict

The verified depth tower is a genuine index-direction finite-state object, but it is not yet the required fixed Frobenius object. The obstruction is exactly the previously identified wall:

```
index shift:      v -> v+1
is represented by a recurrence cocycle A_v

Dwork Frobenius:  t -> t^p
is represented by a semilinear operator Phi_p
```

The missing theorem is a comparison identifying these two actions on one finite-rank object.

What exists:

1. a finite rank p-adic recurrence state for the index direction;
2. the rank-4 Dwork crystal and its semilinear Frobenius law;
3. the depth-tower congruence generated from the single seed c[p].

What is missing:

```
Index-Mellin comparison theorem:
The recurrence-index cocycle generated by the Apéry coefficient tail
is isomorphic, after Mellin transform/contiguity, to a fixed
finite-rank Frobenius module with one operator Phi_p.
```

Without this comparison, the verified tower is a cocycle, not a single Frobenius orbit.

# 1. Minimal state space for the depth tower

The verified relation is

```
p^3 c[p+v] = (p^3 c[p]) K_v(p) mod p^7
```

with fixed kernel K_v generated by the v-recurrence.

The smallest natural state is not the scalar sequence c_n. It is the companion state of the recurrence.

Write the Apéry recurrence as

```
Y_{n+1}=A(n)Y_n

Y_n=(c_n,n^3 c_{n-1})^T.
```

Then

```
A(n)= [ P(n)/n^3    -1/n^3 ]
      [ n^3          0    ]
```

away from singular indices.

Therefore the first candidate state space is

```
V_index = span{c_n,c_{n-1}}

rank = 2.
```

For the depth tower modulo p^7 this is insufficient because the verified laws contain D,E,F jets. The stable lift is

```
V_depth = V_index tensor Z_p[epsilon]/(epsilon^4)
```

with dimension

```
rank(V_depth)=2*4=8.
```

The rank-4 crystal is a quotient after imposing the Apéry period relation; the raw recurrence jet space is rank 8.

The readout is linear:

```
c[p+v] = l_v(Y_p)
```

where l_v is the first coordinate of

```
A(p+v-1)...A(p)Y_p.
```

Thus task 1 succeeds at the cocycle level.

It does not yet produce a fixed operator Phi.

# 2. Collision determinant in the state space

The collision determinant is

```
Delta(r,h)=b_r c_{r+h}-c_r b_{r+h}.
```

Let

```
S_r=(b_r,c_r)^T.
```

Then

```
S_{r+h}=A(r+h-1)...A(r)S_r.
```

Hence

```
Delta(r,h)=w^T S_r wedge
             (A(r+h-1)...A(r)S_r)
```

with fixed alternating vector

```
w((x1,y1),(x2,y2))=x1 y2-y1 x2.
```

Equivalently, in matrix form,

```
Delta(r,h)=<Omega, S_r tensor A(r+h-1)...A(r)S_r>
```

where Omega is the determinant functional.

The problem is that

```
A(r+h-1)...A(r)
```

is not an iterate of one matrix.

The cocycle is nonautonomous.

## Periodicity question

Modulo p,

```
A(r+p)=A(r)
```

whenever denominators are interpreted on the regular range. Therefore the cocycle is periodic with period p in the base variable.

The generated group is therefore the finite monodromy group

```
Gamma_p=<A(0),A(1),...,A(p-1)> subset GL_2(F_p).
```

However, this does not give

```
A(r+h-1)...A(r)=Phi^h
```

because the starting point r remains in the product.

The mirror relation

```
pi(p-1-r)=pi(r)
```

is an involution on orbit points, not a replacement for translation invariance.

# 3. Trace formula boundary terms

For a fixed polynomial M_h, assuming irreducibility and generic Galois group, one can write

```
C_h = main_h + error_h
```

with Weil type error

```
error_h = O(deg(M_h)*sqrt(p)).
```

Since

```
deg(M_h) approximately 3h,
```

we get

```
|error_h|^2 << h^2 p.
```

A more conservative trace-function estimate gives the already used

```
h^4 p
```

budget.

Summing:

```
Sum_{h<=H} h^4 p = p H^5/5.
```

The GPRV budget is O(p), so

```
p H^5 <= p
```

hence

```
H <= 1.
```

Thus naive Weil-by-h cannot touch a growing h-range.

Even the better h^2 error gives

```
Sum h^2 p = p H^3/3
```

and still requires H=O(1).

This is exactly why a finite-rank lift is needed.

# Final answers

(a) Least-confident point:

The rank count (rank 8 before quotient, rank 4 after crystal reduction) is the least certain part. The quotient depends on the exact integral lattice chosen for the jet extension. The existence of a comparison map is the main unknown.

(b) Shared blind spot:

The likely blind spot is assuming that a one-variable Dwork parameter automatically controls coefficient-index translation. Dwork Frobenius controls the generating function variable t. The Apéry gap problem asks for translation in the coefficient index. The missing theorem is precisely the bridge between these two directions.
