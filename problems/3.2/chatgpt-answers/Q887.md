# Full p-adic order-statistics theorem for primitive interpolation pairs

## Executive verdict

I read the repository at commit 9688ca1, including Q867, the Q885 question and its working-note follow-up, Sections 159--162 of the current resume, and q32_pade_zero_absorber.py.

The conjectured valuation formula is true, with no Apéry-specific input and no normality hypothesis.

The correct general statement is a discrete-valuation interpolation lemma.

```plain text
Let R be a DVR with uniformizer pi and residue field k.
Let x_0,...,x_H in R have pairwise distinct reductions modulo pi.
Let u_0,...,u_H be nonzero elements of R.
Let a,b >= 0 with a+b=H.

Suppose P,Q in R[x] satisfy
    deg P <= a,
    deg Q <= b,
    P(x_s)=u_s Q(x_s) for 0<=s<=H,
and suppose the pair is primitive:
    min(content_pi(P),content_pi(Q))=0.

Put e_s=v_pi(u_s), and order them as
    e_(1)>=e_(2)>=...>=e_(H+1).

Then
    content_pi(P)=e_(a+1).
```

Here content_pi(P) is the minimum valuation of the coefficients of P in any integral degree basis. In the Apéry application the polynomials are written in the binomial basis. Since p>H, the binomial and monomial bases are related over Z_p by an invertible triangular matrix, so the two contents agree.

Applied to

```plain text
x_s=s,
 u_s=A_s,
 pi=p,
 b=H-a,
```

this gives the desired full prime-power identity

```plain text
v_p(content(P_(H,a)))=e_(a+1),
```

where the e_(i) are the ordered values of v_p(A_s), 0<=s<=H.

This strictly generalizes Q867's a=1 theorem.

The proof also gives the sharp post-content zero absorber. Put

```plain text
d=e_(a+1),
P_sharp=pi^(-d) P.
```

Then, at every interpolation node,

```plain text
v_pi(P_sharp(x_s))
    =e_s+v_pi(Q(x_s))-d.
```

In particular:

```plain text
if e_s>d, then x_s is necessarily a root of P_sharp modulo pi;

if e_s=d, then x_s is a root of P_sharp modulo pi
             iff Q(x_s)=0 modulo pi;

if e_s<d, then Q(x_s) is divisible by pi^(d-e_s), and
x_s is a root of P_sharp modulo pi
             iff Q(x_s) is divisible by pi^(d-e_s+1).
```

Thus content removal absorbs exactly the common valuation layer d; only nodes strictly above that layer are forced to remain roots.

This is a complete local theorem, but it does not prove the pointwise o(H) bound. It quantifies the absorber rather than compressing the candidate-window radical. After choosing a numerator degree above the vertical zero-count bound, one still needs a genuinely global estimate for the candidate-prime gcd of the content-free Padé values. No current recurrence, Smith, or adjacent-Padé identity provides that estimate.

# 1. General DVR interpolation theorem

## 1.1 Integral degree bases

Let R be a discrete valuation ring, pi a uniformizer, and v=v_pi.

For a polynomial F of degree at most r, define

```plain text
c_pi(F)=min valuation of its coefficients.
```

This is independent of the chosen R-basis of the degree-<=r polynomial module.

If x_0,...,x_r are distinct modulo pi, their Vandermonde determinant is a unit. Therefore:

```plain text
c_pi(F)>=t
iff
F(x_i)=0 modulo pi^t for r+1 distinct nodes x_i.
```

For the Apéry nodes 0,1,...,H and a prime p>H, every difference i-j and every factorial r!, r<=H, is a p-adic unit. Hence the monomial basis and the integer-valued binomial basis

```plain text
1, binom(x,1),...,binom(x,r)
```

are related by a matrix in GL_(r+1)(Z_p).

So v_p(content(P)) in the repository's Newton/binomial coordinates is exactly c_p(P).

## 1.2 The theorem

```plain text
THEOREM (valuation order statistic).

Let x_0,...,x_H have distinct reductions modulo pi.
Let u_s be nonzero.
Let a+b=H.
Let P,Q be a primitive integral pair satisfying

    deg P<=a,
    deg Q<=b,
    P(x_s)=u_s Q(x_s), 0<=s<=H.

Write e_s=v(u_s), ordered decreasingly as

    e_(1)>=...>=e_(H+1).

Then

    c_pi(P)=e_(a+1).
```

## 1.3 Lower bound: layer-by-layer root counting

Put

```plain text
d=e_(a+1).
```

We prove inductively that

```plain text
pi^k divides P coefficientwise for every 0<=k<=d.
```

The case k=0 is trivial. Suppose k>=1 and pi^(k-1) divides P. Define

```plain text
P_(k-1)=P/pi^(k-1).
```

Because k<=d=e_(a+1), at least a+1 indices satisfy

```plain text
e_s>=k.
```

At each such node,

```plain text
P_(k-1)(x_s)
 =u_s Q(x_s)/pi^(k-1)
 =0 modulo pi.
```

The reduction of P_(k-1) has degree at most a and at least a+1 distinct roots. Therefore it is the zero polynomial modulo pi, so

```plain text
pi^k divides P.
```

Induction gives

```plain text
c_pi(P)>=d.
```

## 1.4 Upper bound: one extra layer violates primitivity

Assume for contradiction that

```plain text
pi^(d+1) divides P.
```

There are at most a nodes with

```plain text
e_s>=d+1,
```

because d=e_(a+1). Hence at least

```plain text
H+1-a=b+1
```

nodes satisfy e_s<=d.

At each such node,

```plain text
u_s Q(x_s)=P(x_s)=0 modulo pi^(d+1),
```

and therefore

```plain text
Q(x_s)=0 modulo pi.
```

The reduction of Q has degree at most b and at least b+1 distinct roots. Thus

```plain text
pi divides Q coefficientwise.
```

But pi also divides P, contradicting primitivity of the pair. Therefore

```plain text
c_pi(P)<=d.
```

Combining the two inequalities proves

```plain text
c_pi(P)=e_(a+1).
```

This proof is exact at every prime power. It contains no genericity, noncancellation, or simple-root assumption.

# 2. Normality audit

## 2.1 No Padé normality is needed

The theorem above does not require:

```plain text
- uniqueness of the rational interpolation pair;
- one-dimensionality of the Padé kernel;
- nonvanishing of a specified maximal minor;
- coprimality of P and Q as polynomials;
- normality of a Padé table.
```

It holds for every primitive integral pair satisfying the interpolation and degree bounds.

This is important because the repository's cofactor construction assumes a full-row-rank kernel matrix in order to select a canonical one-dimensional pair. The exact finite computations verify that condition in the tested range, but a general all-H,a normality theorem is not needed for the valuation identity.

## 2.2 Existence and primitivity in the Apéry system

For fixed H,a, put b=H-a. The coefficients of P and Q give

```plain text
(a+1)+(b+1)=H+2
```

unknowns, while interpolation at 0,...,H gives H+1 homogeneous linear equations. Thus a nonzero rational solution always exists.

After clearing denominators and dividing by the gcd of all coefficients, one obtains a primitive integral pair.

Neither component can vanish identically. If P=0, then

```plain text
A_s Q(s)=0 for every s.
```

All Apéry numbers are nonzero, so Q has H+1 roots but degree at most H-a<=H, forcing Q=0, a contradiction. The same argument excludes Q=0.

Therefore all hypotheses of the DVR theorem hold for every Apéry interpolation pair and every prime p>H.

If the Padé kernel happens to have dimension greater than one at some height, every primitive vector in that kernel still has the same numerator-content valuation e_(a+1). The claimed formula is therefore insensitive to normality failure.

# 3. Sharp post-content zero absorber

Let

```plain text
d=e_(a+1),
P_sharp=pi^(-d)P.
```

The theorem says that P_sharp is integral and nonzero modulo pi.

For each node define

```plain text
r_s=v(P_sharp(x_s)).
```

From interpolation,

```plain text
r_s=e_s+v(Q(x_s))-d.                         (3.1)
```

The right side is nonnegative because P_sharp is integral.

Split the nodes into three valuation layers:

```plain text
S_> ={s:e_s>d},
S_= ={s:e_s=d},
S_< ={s:e_s<d}.
```

Then:

```plain text
s in S_>:
    r_s>=e_s-d>=1.
    Hence P_sharp(x_s)=0 modulo pi.

s in S_=:
    r_s=v(Q(x_s)).
    Hence P_sharp(x_s)=0 modulo pi iff Q(x_s)=0 modulo pi.

s in S_<:
    interpolation and pi^d|P imply
        v(Q(x_s))>=d-e_s.
    Moreover
        r_s=v(Q(x_s))-(d-e_s).
    Hence P_sharp(x_s)=0 modulo pi iff
        v(Q(x_s))>=d-e_s+1.
```

This is the exact residual-valuation theorem requested in the question.

## 3.1 Polynomial factorization modulo pi

Since every node in S_> is a forced root,

```plain text
P_sharp(x)
 = unit_or_polynomial(x) * product_(s in S_>)(x-x_s)
   modulo pi.
```

More precisely, there is a nonzero polynomial R(x) over the residue field with

```plain text
P_sharp(x)
 = R(x) product_(s in S_>)(x-x_s) modulo pi,

deg R <= a-|S_>|.
```

Thus the forced roots after content removal are exactly the nodes lying strictly above the (a+1)st valuation layer. Any additional roots come from the threshold or lower layers through the extra divisibility of Q described above.

## 3.2 Dual root statement for Q

For every s in S_<, one has

```plain text
Q(x_s)=0 modulo pi.
```

The polynomial Q modulo pi is nonzero. Indeed, if pi|Q, interpolation at all H+1 nodes would imply pi|P, contradicting primitivity when d=0; when d>0, primitivity already directly forces Q to be a unit polynomial modulo pi.

Therefore

```plain text
|S_<|<=b.
```

This is the dual order-statistics constraint.

# 4. Recovery of the exponent-one zero-absorber theorem

Let

```plain text
Z={s:p|u_s},
r=|Z|.
```

The mod-p theorem checked by q32_pade_zero_absorber.py follows immediately.

## 4.1 More than a roots

If

```plain text
r>a,
```

then e_(a+1)>=1, so

```plain text
p divides content(P).
```

Equivalently,

```plain text
P is the zero polynomial modulo p.
```

## 4.2 Exactly a roots

If

```plain text
r=a,
```

then e_(a+1)=0. Hence P is nonzero modulo p, and every node in Z is a root. There are exactly a such roots and deg P<=a, so the interpolation-node roots are exactly Z.

## 4.3 Fewer than a roots

If

```plain text
r<a,
```

then again e_(a+1)=0. The roots include Z, and there can be at most a-r additional interpolation-node roots.

Thus:

```plain text
P=0 polynomial modulo p iff |Z|>a.

If |Z|<=a, the interpolation-node roots contain Z
and have total cardinality at most a.

If |Z|=a, the interpolation-node roots are exactly Z.
```

The script tests precisely this exponent-one shadow. The order-statistics theorem proves its complete prime-power refinement.

```plain text
u_s=A_s,

p>H.
```

Let

```plain text
e_s=v_p(A_s),
e_(1)>=...>=e_(H+1).
```

For every primitive integral interpolation pair

```plain text
deg P_(H,a)<=a,
deg Q_(H,a)<=H-a,
P_(H,a)(s)=A_s Q_(H,a)(s),
```

one has

```plain text
v_p(content(P_(H,a)))=e_(a+1).             (5.1)
```

This includes Q867 as a=1:

```plain text
v_p(content(P_(H,1)))=e_(2).
```

```plain text
v_p(content(P_(H,0)))=e_(1),
```

# 6. Candidate-window consequences

Put

```plain text
n=3H+1,
2H<p<=n,
j=n-p.
```

Then 0<=j<=H, p>H, and for every integer-valued polynomial of degree at most H,

```plain text
P(n)=P(j) modulo p.
```

The target condition is

```plain text
p|A_j.
```

## 6.1 What content removal does

For a fixed degree a, let

```plain text
d_a=e_(a+1),
P_(H,a)^sharp=p^(-d_a) P_(H,a)
```

locally over Z_p.

At the moving node j, the residual valuation is

```plain text
v_p(P_(H,a)^sharp(j))
 =v_p(A_j)+v_p(Q_(H,a)(j))-d_a.             (6.1)
```

Therefore:

```plain text
if v_p(A_j)>d_a, the target prime survives content removal;

if v_p(A_j)=d_a, survival depends on Q_(H,a)(j) modulo p;

if v_p(A_j)<d_a, Q_(H,a)(j) is forced to absorb d_a-v_p(A_j)
layers, and one further layer is needed for the prime to survive.
```

In particular, when all prefix zeros are simple and their number is r:

```plain text
a<r:
    d_a=1, and content removal absorbs the entire forced zero layer;
    the target node is not automatically a root of P_sharp.

a=r:
    d_a=0, and the interpolation-node roots are exactly Z_p(H).

a>r:
    d_a=0, the roots include Z_p(H), with at most a-r extras.
```

So dividing each numerator by its own content is not harmless if one then takes a gcd over degrees below the zero count: it can remove the target prime itself.

## 6.2 The growing-family theorem remains local

Let

```plain text
Z_p(H)={s<=H:p|A_s},
r_p=|Z_p(H)|.
```

The exponent-one family theorem is

```plain text
p divides gcd_(0<=a<=A) P_(H,a)(n)
iff
j in Z_p(H) or r_p>A.
```

The new valuation theorem upgrades the absorber alternative from support to exact prime powers:

```plain text
v_p(content(P_(H,a)))=the (a+1)st largest prefix valuation.
```

It does not remove the alternative r_p>A; it explains it exactly.

If a proved uniform vertical bound gives

```plain text
r_p<=A(H)
```

for every candidate prime, then the common candidate-window support of the family through degree A(H) is exactly the direct target. This remains an exact support identity, not a height estimate.

# 7. Does this create a smaller carrier?

Locally, yes: it identifies and removes every automatic prime-power absorber with no loss of information about the residual polynomial.

Globally, no proof of o(H) follows.

There are three reasons.

## 7.1 The top-degree numerator already has exact target support

At a=H, the denominator is constant and P_(H,H) is the ordinary degree-H interpolant of the Apéry values. Since A_0=1, its content is a unit at every prime. For a candidate prime,

```plain text
p|P_(H,H)(n)
iff
p|P_(H,H)(j)
iff
p|A_j.
```

Thus a single known integer already has exactly the target candidate support. Its failure is Archimedean: it has positive exponential height.

The valuation theorem does not reduce that height.

## 7.2 A content-free tail family is still an exact re-encoding

Choose A above the vertical zero-count bound and consider degrees

```plain text
A<=a<=H.
```

At candidate primes, all these numerators have p-unit content, and every target node is a root of each numerator. Including a=H removes every nontarget candidate prime. Hence

```plain text
rad_(2H<p<=3H+1)
 gcd_(A<=a<=H) P_(H,a)(3H+1)
```

has exactly the target support.

But this is again a coordinate representation of the target radical. No current theorem bounds the height of this gcd.

## 7.3 Smith and adjacent identities do not provide compression

The content exponents now have a complete order-statistics description, but after those factors are removed the remaining roots are governed by the residual Padé polynomials R(x) in Section 3. Their common candidate-prime support is the same moving-zero set.

Adjacent cross-product identities still contain the full binomial carrier, and the repository has already shown that saturation by that carrier removes the desired prime together with the automatic factor. The new content theorem does not alter that balance.

# 8. Exact remaining global theorem

The local p-adic problem is now closed. The remaining problem is entirely global and Archimedean/horizontal.

One explicit recurrence-specific formulation is:

```plain text
Let A(H) be any proved uniform upper bound for |Z_p(H)|
for all candidate primes 2H<p<=3H+1.

Prove

log rad_(2H<p<=3H+1)
    gcd_(A(H)<=a<=H) P_(H,a)(3H+1)
 =o(H).
```

Because the candidate-window support of this gcd is exactly

```plain text
{p:2H<p<=3H+1 and p|A_(3H+1-p)},
```

this theorem is equivalent, at the radical-support level, to the direct q=1 target. It is not a weaker consequence of the order-statistics lemma.

A genuinely new advance would have to control the residual content-free Padé family, for example by proving a horizontal correlation estimate of the form

```plain text
sum over candidate primes p for which
several content-free residual Padé polynomials share the moving root j=n-p
of log p
=o(H).
```

No current vertical zero count, recurrence, Dwork congruence, or Smith normal form gives this estimate.

# 9. Hostile verdict

The conjectured formula is correct at full p-adic strength:

```plain text
v_p(content(P_(H,a)))=e_(a+1).
```

It is not merely an Apéry theorem. It is a general DVR interpolation theorem based on two facts:

```plain text
(a) a degree-a polynomial with a+1 distinct roots modulo p is zero;

(b) if one more common p-layer were present in P, then Q would have
    b+1 roots modulo p, contradicting primitive normalization.
```

The theorem completely resolves the local content/zero-absorber mechanism and supplies exact residual node valuations after content removal.

It does not prove the desired pointwise bound. Once the order-statistic content is stripped, the surviving candidate-prime problem is still the original moving-root problem in a different basis.

The narrowest missing statement is therefore not another local Smith lemma. It is a global estimate for the candidate-prime radical of the content-free growing Padé family, or an equivalent cross-prime correlation theorem for the actual Apéry sequence.

# 10. Reproducible exact verification

The repository script q32_pade_zero_absorber.py checks only the exponent-one shadow. The following extension checks the full order-statistics identity once the exact primitive pair routine is imported.

```python
from math import gcd


def vp(value, prime):
    value = abs(value)
    if value == 0:
        return 10**9
    exponent = 0
    while value % prime == 0:
        value //= prime
        exponent += 1
    return exponent


def content_valuation(coefficients, prime):
    return min(vp(value, prime) for value in coefficients)


def check_order_statistic(height, prime, apery, numerators):
    valuations = sorted(
        (vp(apery[node], prime) for node in range(height + 1)),
        reverse=True,
    )
    for numerator_degree, numerator in enumerate(numerators):
        expected = valuations[numerator_degree]
        actual = content_valuation(numerator, prime)
        assert actual == expected, (
            height,
            prime,
            numerator_degree,
            valuations,
            actual,
        )
```

The proof above, rather than this finite audit, establishes the statement for all heights, all primes p>H, all prime powers, and every primitive interpolation pair.
