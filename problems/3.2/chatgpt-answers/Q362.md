# Near-primitive Mellin characters: the cyclotomic norm does not amplify an Apéry zero

## Verdict

The proposed order split is a valid and useful all-n reduction:

```plain text
m := n-q,
g := gcd(p-1,m),
d := (p-1)/g = ord(omega_p^m).
```

For fixed q, primes with d <= D are parametrized by

```plain text
p = 1 + d g,
g | m,
d <= D,
```

so there are at most D tau(m) candidates. With the known large-prime depth bound v_p(G_n) <= 6, their total logarithmic weight for q <= Q is

```plain text
<= 6 Q D n^{o(1)} log n.
```

Taking

```plain text
D = n^(1-epsilon)/Q
```

makes this n^(1-epsilon+o(1)). The remaining primes satisfy

```plain text
d > D,
g = (p-1)/d < n/(qD) <= (Q/q)n^epsilon,
```

so the hard characters are indeed faithful or nearly faithful on a quotient of order comparable to p.

But the small-kernel regime does not create cyclotomic norm amplification. The exact reason is:

Since d | p-1, the rational prime p splits completely in Q(zeta_d) and in every subfield. The completion at the one chosen prime above p is just Q_p. Its local norm has degree one. A zero at that prime therefore contributes one factor p, not p^{phi(d)}.

Galois conjugation moves the algebraic trace and the prime above p simultaneously. It does not produce zeros of all conjugate characters at one fixed p-adic place. In the minimal trace field, a single simple vanishing contributes exactly

```plain text
v_p(Norm(trace)) = 1.
```

The forced inversion symmetry can produce a factor p^2 if one unnecessarily takes the norm from the full cyclotomic field, but in the maximal real/minimal trace field it is still one factor. There is no amplification by phi(d).

The archimedean side cancels any possible benefit. If e is the degree of the trace field, the rank-two weight-three Weil bound gives

```plain text
|sigma(trace)| <= 2 p^(3/2),
log |Norm(trace)| <= e(3/2 log p + log 2).
```

Thus one factor p consumes only 1/e of the available norm height. Near-primitivity makes e large—generically about phi(d)/2—so it makes this norm argument weaker, not stronger.

Gross–Koblitz and Stickelberger give the same verdict. Their predictable valuations are bounded piecewise-linear functions of the character exponent. In the balanced Apéry 4F3, the minimum valuation is zero for every character. The residue b_r is the unit-level leading coefficient; b_r=0 is cancellation among p-adic units. The quantity g=gcd(r,p-1) does not supply an extra valuation.

Accordingly, the order split banks a real unconditional o(n) contribution, but the near-primitive remainder still needs a genuinely horizontal carrier or non-alignment theorem. Cyclotomic degree by itself does not provide one.

# 1. The elementary order split

Let p <= n, put

```plain text
q := floor(n/p),
r := n-qp,
m := n-q.
```

Because p = 1 modulo p-1,

```plain text
r = n-qp = n-q = m                 (mod p-1),
```

and therefore

```plain text
omega_p^r = omega_p^m.
```

Put

```plain text
g := gcd(p-1,m),
d := (p-1)/g.
```

Then g | m, p=1+dg, and d is the exact order of the character. Hence, for fixed q and d <= D, every candidate prime occurs among

```plain text
{1+dg : d<=D, g|m}.
```

There are at most

```plain text
D tau(m) = D n^{o(1)}
```

candidate integers, and therefore at most that many primes. For the Apéry gcd, the Wronskian estimate gives

```plain text
v_p(G_n) <= 6                       for sqrt(n)<p<=n.
```

Thus the logarithmic weight from q<=Q, d<=D is at most

```plain text
6 sum_{q<=Q} D tau(n-q) log n
 <= 6 Q D n^{o(1)} log n.           (1.1)
```

With D=n^(1-epsilon)/Q, this is n^(1-epsilon+o(1)).

For the complement,

```plain text
g = (p-1)/d < p/D <= n/(qD)
  = (Q/q)n^epsilon.                 (1.2)
```

So the reduction is correct: after an unconditional negligible part, the character has a kernel of size at most Q n^epsilon/q and order d close to p/g.

What follows audits whether this helps algebraically.

# 2. The exact character and cyclotomic field

Write

```plain text
p-1 = gd,
m = gs,
gcd(s,d)=1.
```

Let chi_0 be a fixed order-d character of F_p^*. Then

```plain text
omega_p^m = chi_0^s,
```

and it is faithful on the quotient

```plain text
F_p^*/ker(chi_0)  ~=  C_d.
```

All faithful characters of this quotient are

```plain text
chi_0^(as),    a in (Z/dZ)^*.
```

Their values lie in

```plain text
K_d := Q(zeta_d),
Gal(K_d/Q) ~= (Z/dZ)^*.
```

For a finite hypergeometric/Mellin trace defined over the rational base object, Galois acts in the expected way:

```plain text
sigma_a(T_p(chi)) = T_p(chi^a).       (2.1)
```

This is the standard field-of-definition mechanism for finite hypergeometric functions. Beukers' Proposition 2.9 describes the fixed field via automorphisms of the finite algebras, and Theorem 1.5 gives algebraic integrality after the bounded normalization dictated by the hypergeometric data:

- F. Beukers, “Fields of definition of finite hypergeometric functions,”, especially Proposition 2.9 and Theorem 1.5.

- F. Beukers, H. Cohen, A. Mellit, “Finite hypergeometric functions,”, Pure Appl. Math. Q. 11 (2015), 559–589.

- N. Katz, Convolution and Equidistribution: Sato–Tate Theorems for Finite-Field Mellin Transforms, Princeton, 2012.

For the Apéry character family, self-duality gives at least

```plain text
T_p(chi) = T_p(chi^(-1)).             (2.2)
```

This is the character-theoretic source of

```plain text
b_r = b_(p-1-r) mod p.
```

Therefore the trace normally lies in a subfield of the maximal real field

```plain text
K_d^+ = Q(zeta_d + zeta_d^(-1)).
```

Let

```plain text
H := {a in (Z/dZ)^* : T_p(chi^a)=T_p(chi)},
L := K_d^H,
e := [L:Q] = phi(d)/|H|.
```

At least {-1,1} subset H in the self-dual case; generically there is no reason for a larger stabilizer. The kernel size g does not enlarge H: every primitive character chi^a has the same kernel, but the Mellin trace remembers the character, not merely its kernel.

If it depended only on the kernel, all primitive-character values would be equal and the trace would be rational. That is not the Apéry Mellin spectrum.

# 3. Decomposition group: why conjugation does not stay at the chosen prime

Since

```plain text
d | p-1,
```

we have

```plain text
p = 1 mod d.
```

Consequently p splits completely in K_d and in L. This is the standard cyclotomic splitting criterion; see L. Washington, Introduction to Cyclotomic Fields, Chapters 1–2.

Choose an element t in F_p^* of exact order d. The primes of K_d above p can be written

```plain text
P_t = (p, zeta_d - t),
```

with t ranging over the primitive d-th roots in F_p. There are phi(d) of them, and

```plain text
(K_d)_(P_t) ~= Q_p,
D(P_t/p) = {1}.                       (3.1)
```

The same holds in L: every local completion at p is Q_p and the decomposition group is trivial.

Now suppose the chosen Apéry character corresponds to P_t, and let A=T_p(chi) after removing any predictable universal p-power normalization. The congruence has the form

```plain text
A mod P_t = u_(p,r) b_r mod p,
u_(p,r) in F_p^*.                    (3.2)
```

Thus b_r=0 mod p means

```plain text
A in P_t.                              (3.3)
```

For a in Gal(K_d/Q), Galois conjugation gives

```plain text
A in P_t
  => sigma_a(A) in sigma_a(P_t).       (3.4)
```

Up to the harmless inverse convention in labeling the primes,

```plain text
sigma_a(A) = T_p(chi^a),
sigma_a(P_t) = P_(t^(a^(-1))).         (3.5)
```

The desired amplification would require either

```plain text
A in sigma_a(P_t)       for many a,
```

or

```plain text
sigma_a(A) in P_t       for many a.
```

Neither follows from (3.4). Because the decomposition group in (3.1) is trivial, no nonidentity Galois element fixes the selected prime.

This is the exact stabilizer/decomposition-group obstruction:

Conjugation transports the zero diagonally in (character, prime-above-p) space. It does not create many zeros on the horizontal slice with one fixed p-adic embedding.

# 4. The norm valuation: one zero costs one factor p

Let A in O_L be the integral trace in its minimal field. Since p splits completely,

```plain text
v_p(N_(L/Q)(A))
 = sum_{P|p} v_P(A).                  (4.1)
```

Every residue degree is one. Therefore, if

```plain text
v_(P_0)(A)=1,
v_P(A)=0 for P != P_0,
```

then

```plain text
v_p(N_(L/Q)(A)) = 1.                  (4.2)
```

This is the generic simple-zero situation. More generally the norm exponent is the number of vanishing character orbits, counted with local multiplicity—not the degree of the cyclotomic field.

If one works in the full field K_d although A in L=K_d^H, then

```plain text
N_(K_d/Q)(A) = N_(L/Q)(A)^|H|,
```

so a single prime of L contributes p^|H|. For the forced inversion symmetry H={+-1}, this is p^2. But this is artificial duplication: in the minimal real trace field the exponent is still one, and the archimedean norm is squared by the same factor.

### Rationality would amplify—but it is exactly what is absent

If A were a rational integer, then one prime above p dividing A would imply all primes above p divide A; in the full cyclotomic norm,

```plain text
N_(K_d/Q)(A) = A^phi(d),
```

so the exponent would be phi(d)v_p(A).

But the fact that the reduction in (3.2) lies in F_p does not imply A in Q. Every prime above a completely split p has residue field F_p. Rationality of the residue is automatic.

Moreover, rationality of A would force

```plain text
T_p(chi^a)=T_p(chi)
```

for every a, i.e. constancy on all primitive characters with the same kernel. The Apéry Mellin function is not constant. Near-primitivity therefore gives a large Galois orbit, not a large norm valuation.

# 5. Equivalent resultant calculation

The same obstruction can be stated without algebraic-number terminology.

Suppose an integral polynomial or Laurent polynomial F_(p,d)(X) represents the chosen normalized trace on primitive d-th roots:

```plain text
A = F_(p,d)(zeta_d).
```

Then

```plain text
N_(K_d/Q)(A)
 = +-Res(Phi_d, F_(p,d))
 = product_{a in (Z/dZ)^*} F_(p,d)(zeta_d^a).   (5.1)
```

Since p does not divide d, Phi_d is squarefree modulo p and splits completely. With Teichmüller lifts of the primitive roots,

```plain text
v_p Res(Phi_d,F_(p,d))
 = sum_{xi in mu_d^prim(F_p)} v_p(F_(p,d)(xi)).        (5.2)
```

Thus:

- one simple primitive root of F_(p,d) mod p contributes one factor p;

- k simple roots contribute p^k;

- inversion symmetry pairs roots and gives p^2 in the full cyclotomic resultant, or one factor in the real quotient;

- there is no automatic p^phi(d).

Formula (5.2) is exactly the vertical root count in norm language. It does not turn one selected root into many roots.

# 6. Archimedean height cancels the cyclotomic degree

For the rank-two weight-three Mellin object, every complex conjugate satisfies a Weil bound

```plain text
|sigma(A)| <= 2 p^(3/2)                (6.1)
```

(up to an inessential fixed normalization constant at the finite set of degenerate characters). Therefore

```plain text
log |N_(L/Q)(A)|
 <= e(3/2 log p + log 2).              (6.2)
```

If z character orbits vanish, then (4.1) gives

```plain text
z log p <= log |N_(L/Q)(A)|,
```

and hence only

```plain text
z <= (3/2)e + O(e/log p).              (6.3)
```

This is of the same order as the total number e of available characters. It is not a nontrivial zero bound.

For a single zero, the comparison is worse:

```plain text
required divisibility:  log p,
available height:       ~ (3/2)e log p.
```

When the character is near primitive, d is large and generically

```plain text
e = phi(d)/2 = d^(1-o(1)).
```

So only a 1/e fraction of the norm capacity is used. The large cyclotomic degree is an archimedean liability.

The same estimate applied to (5.1) gives

```plain text
|Res(Phi_d,F_(p,d))|
 <= (2p^(3/2))^phi(d).                 (6.4)
```

Again, one factor p is negligible.

# 7. Why this does not become a fixed-n cross-prime certificate

For fixed n and q, the exponent

```plain text
m=n-q
```

is fixed, but the following objects still vary with p:

```plain text
d=(p-1)/g,
K_d=Q(zeta_d),
the prime P_t above p,
the finite-field additive character,
the Gross-Koblitz Gamma_p values,
the Frobenius trace A_(p,m),
the Hasse polynomial H_p.
```

The cyclotomic norm therefore produces a different integer

```plain text
C_(p,m) := N_(L_(p,m)/Q)(A_(p,m))
```

for every candidate prime. The implication

```plain text
p bad => p | C_(p,m)
```

is tautological and cannot be multiplied into a fixed certificate.

Even if one multiplies these separate norms, (6.2) gives

```plain text
sum_{p bad} log p
 <= sum_{p bad} [L_(p,m):Q](3/2 log p+O(1)),          (7.1)
```

whose right side is larger than the left by the cyclotomic degrees. This is no restriction.

## The tempting carrier b_m is not valid here

For a genuinely fixed integer m and primes p>m, the first-digit Mellin congruence can indeed have carrier b_m. But in the current application

```plain text
m=n-q=q(p-1)+r
```

is usually larger than p. Character exponents are periodic modulo p-1, while the Apéry Lucas law is digital in base p; these are different reductions.

Indeed, if r>=q,

```plain text
m=qp+(r-q),
b_m = b_q b_(r-q) mod p,
```

whereas if r<q,

```plain text
m=(q-1)p+(p+r-q),
b_m = b_(q-1)b_(p+r-q) mod p.          (7.2)
```

Neither expression is generally b_r. Thus

```plain text
T_p(omega_p^m)=T_p(omega_p^r) = b_r mod p
```

does not produce

```plain text
T_p(omega_p^m)=b_m mod p.
```

The fixed-m carrier that exists eventually for p>m does not cover the moving range p~n/q<m.

A genuine breakthrough would require a nonzero integer or fixed algebraic object C_(n,q) independent of p such that

```plain text
p bad in the q-slice => p | C_(n,q),
log |C_(n,q)| = o(n).
```

The cyclotomic norm above does not construct such an object.

# 8. Small kernel does not shorten the Mellin transform

Let H=ker(chi) with |H|=g. If the underlying trace function is K_p(x), then

```plain text
M_p(chi)
 = sum_{x in F_p^*} K_p(x)chi(x)
 = sum_{y in F_p^*/H} chi(y)
     [sum_{h in H} K_p(yh)].           (8.1)
```

The quotient has size

```plain text
d=(p-1)/g.
```

When g is small, the inner bracket contains only a few terms, but the outer transform has nearly p terms. There is no descent to a smaller finite field: the additive/Frobenius trace function is not constant on multiplicative kernel cosets.

Thus the near-primitive regime is the least favorable regime for quotient compression. A large kernel would shorten the character sum; a tiny kernel does not.

# 9. Gross–Koblitz: no extra valuation in the near-primitive regime

For 0<=j<=p-2, Gross–Koblitz gives

```plain text
g(bar(omega)^j)
 = -pi^j Gamma_p(j/(p-1)),
pi^(p-1)=-p,                            (9.1)
```

so

```plain text
v_p(g(bar(omega)^j)) = j/(p-1).         (9.2)
```

Reference: B. Gross and N. Koblitz, “Gauss sums and the p-adic Gamma-function,” Ann. of Math. 109 (1979), 569–581.

For j=gs and p-1=gd, this is

```plain text
s/d
```

after choosing the least residue. Large d does not make this valuation large: s runs through the units modulo d, so s/d can lie anywhere in (0,1).

For Jacobi sums, Stickelberger's ideal factorization makes the same point. In a standard convention,

```plain text
v_(P_t)(J(chi^a,chi^b))
 = <ta/d> + <tb/d> - <t(a+b)/d>
 in {0,1},                                  (9.3)
```

when all three characters are nontrivial. A bounded product of Jacobi sums therefore has O(1) valuation at a selected prime, independently of phi(d). See B. Berndt, R. Evans, K. Williams, Gauss and Jacobi Sums, Wiley, 1998, and Washington's cyclotomic-field treatment of Stickelberger ideals.

Balanced hypergeometric normalization cancels these predictable valuation blocks. What remains is a sum of units.

## Exact Apéry leading coefficient

For the Apéry Mellin trace, the Gross–Koblitz calculation has already been reduced to the following exact form. For z in [1,p-2], the relative valuation of the k-th Gauss-sum term is

```plain text
2 * 1_(k>z) + 2 * 1_(k>p-1-z)
 in {0,2,4}.                              (9.4)
```

The minimum is zero for every z, attained throughout

```plain text
0 <= k <= min(z,p-1-z).
```

The unit-level coefficient is

```plain text
L_p(z)
 = sum_{k=0}^{min(z,p-1-z)}
     binom(z,k)^2 binom(p-1-z,k)^2
 = b_z mod p.                              (9.5)
```

The last equality uses

```plain text
binom(p-1-z,k) = (-1)^k binom(z+k,k) mod p.
```

Thus

```plain text
b_z=0 mod p
```

is not forced by a positive Stickelberger slope. It is cancellation among the zero-valuation terms of (9.5). The number

```plain text
gcd(z,p-1)
```

does not appear in (9.4) or (9.5).

This calculation is recorded in the project note Q32_KatzMellin_vertical.md, §§7–10. The hypergeometric/Casoratian background is summarized in Q338.

So Gross–Koblitz gives a definitive negative answer to the proposed extra-valuation mechanism:

Near-primitivity changes the Galois orbit of the character, but it does not raise the Hodge/Stickelberger valuation. Non-ordinarity remains one extra p caused by unit cancellation.

# 10. What has actually been gained

The order split should be kept. It gives a clean theorem-level reduction:

```plain text
All low-order character contributions (d<=n^(1-epsilon)/Q)
are n^(1-epsilon+o(1)) in logarithmic weight.
```

The residual problem can be stated sharply as follows.

For each q<=Q, put m=n-q. Control primes

```plain text
p = 1 + gd,
g | m,
g <= (Q/q)n^epsilon,
d > n^(1-epsilon)/Q,
```

for which the rank-two weight-three Mellin trace at the faithful character chi_0^(m/g) is non-ordinary.

The cyclotomic audit proves:

1. p splits completely in the trace field;

1. the local degree at the selected prime is one;

1. one simple zero contributes one factor p to the minimal norm;

1. Galois conjugation moves the prime and character together;

1. the norm height grows proportionally to the Galois degree;

1. Gross–Koblitz supplies no order-dependent extra valuation;

1. no fixed-n carrier is produced.

Therefore the small-kernel reduction does not close the pointwise theorem by norm amplification. The missing input remains one of the following genuinely cross-prime statements:

```plain text
- a fixed carrier C_(n,q) of subexponential height;
- a horizontal non-ordinary-prime bound for the unbounded-order slice;
- a small-CRT/non-alignment theorem for the Hasse roots;
- a new relation coupling traces in the varying cyclotomic fields.
```

## Final answer

The near-primitive split is a valid unconditional reduction, but the balanced 4F3 cyclotomic realization does not amplify a single Apéry zero. Because p splits completely in the order-d cyclotomic field, the decomposition group at the chosen prime is trivial and the local norm degree is one. In the minimal trace field, a simple zero costs exactly one factor p; inversion gives at most the already-known factor two in the full field. The global norm has degree-proportional Weil height, and Gross–Koblitz shows that the zero is unit cancellation with no extra Stickelberger valuation. Hence small kernel does not provide the desired fixed-n cross-prime certificate.
