## Important normality caveat

The general Padé kernel has rank b, but that does not automatically prove that the particular flag minor tau_b is nonzero for every H,b. The signed Newton matrix is not totally positive; the repository already contains a negative consecutive order-six minor. The implementation therefore checks each pivot and stops rather than silently changing the answer.

A completely pivot-robust fallback is straightforward: for a failed prefix, run one pivoted exact nullspace elimination for that b. This still replaces b+1 cofactor determinants by one elimination, but that fallback was not exercised by the unavailable runner. Consequently the committed branch is correctly left as a draft rather than represented as validated production code.
