# Executive verdict

The anchored determinant construction is valid, but Q871 made two claims too strongly.

1. Integrality and the degree upper bound are unconditional. For every pair of primitive integral interpolation solutions,

```plain text
W_(1,b)(x)
 := P_(H,1)(x) Q_(H,b)(x)
    - P_(H,b)(x) Q_(H,1)(x)
 = Phi_H(x) K_(H,b)(x),

Phi_H(x)=product_(s=0)^H (x-s),
K_(H,b) in Z[x],
deg K_(H,b) <= b-2.
```

1. Exact degree and projective independence are not presently proved for every height. The repository proves existence of a nonzero primitive pair in every degree and verifies the canonical cofactor kernel in finite ranges, but it does not contain an all-height Padé normality theorem showing simultaneously

```plain text
deg P_(H,b)=b,
deg Q_(H,1)=H-1,
```

or showing that the canonical degree-one and degree-b pairs are never proportional. Consequently K_(H,3) is always integral of degree at most one, but it can be constant or identically zero in an exceptional degree-drop/kernel-degeneracy case. Q871's exact support theorem remains valid, while the phrase “genuinely independent linear polynomial for every H” must be conditional on nondegeneracy.

1. The derivative-at-the-node argument is one-way, not an equivalence. A candidate-window good prime common to the two numerator values divides K_(H,b)(n). The converse fails in general. The first exact failure factor is the degree-one derivative defect

```plain text
D_(H,1)(j)
 := P_(H,1)'(j)-A_j Q_(H,1)'(j).
```

At an interpolation node one has the exact identity

```plain text
Phi_H'(j) K_(H,b)(j)
 = D_(H,1)(j) Q_(H,b)(j)
   - D_(H,b)(j) Q_(H,1)(j),

D_(H,b)(j)
 := P_(H,b)'(j)-A_j Q_(H,b)'(j).
```

If A_j is a unit and P_(H,1)(j)=0, then Q_(H,1)(j)=0, so

```plain text
Phi_H'(j) K_(H,b)(j)
 = D_(H,1)(j) Q_(H,b)(j).
```

Thus, away from D_(H,1)(j)=0, the anchored determinant detects the higher numerator root exactly. On the derivative-defect locus every anchored K_(H,b)(j) vanishes automatically and the elimination loses all information about P_(H,b)(j). This is the first unavoidable factor in the anchored family.

1. The linear polynomial has an explicit exact formula. Write

```plain text
P_(H,3)(x)=p_3 x^3+p_2 x^2+p_1 x+p_0,
Q_(H,1)(x)=q_(H-1)x^(H-1)+q_(H-2)x^(H-2)+...,
S_H=H(H+1)/2.
```

Then

```plain text
K_(H,3)(x)=alpha_H x+beta_H,

alpha_H=-p_3 q_(H-1),

beta_H
 =-(p_3 q_(H-2)+p_2 q_(H-1))
   +S_H alpha_H.
```

Therefore

```plain text
content(K_(H,3))=gcd(alpha_H,beta_H),

K_(H,3)(3H+1)
 =-(p_3 q_(H-2)+p_2 q_(H-1))
   +(3H+1+S_H)alpha_H.
```

These identities remain correct in every degree-drop case: if alpha_H=0, the anchored polynomial is constant; if also beta_H=0, the cross determinant is identically zero.

1. The anchored numerator family has an exact support theorem. Let

```plain text
S_B={1,3,4,...,B},
n=3H+1,
Z_p(H)={s in [0,H]:p|A_s},
z_p(H)=#Z_p(H),
j=n-p.
```

For candidate primes 2H<p<=n, the radical of

```plain text
gcd_(a in S_B) P_(H,a)(n),
```

with the binomial carrier has support equal to the disjoint union of:

```plain text
(T) target primes: j in Z_p(H);

(E0) z_p(H)=0 and j is a common projective extra root
     of every selected numerator;

(E2) z_p(H)=2, j notin Z_p(H), and j is a common extra root
     of every selected numerator of degree at least 3;

(EB) z_p(H)>B, in which case every selected numerator is
     coefficientwise divisible by p.
```

There are no other good-prime classes. In particular, Q871's degree-three pair leaves not only the four-zero content obstruction but also the z=0 and z=2 common-extra-root obstructions.

1. Adding the missing degrees 0 and 2 gives exact equivalence with the full growing Padé family. For

```plain text
G_(H,B)(n)=gcd_(0<=a<=B) P_(H,a)(n),
```

one has the exact candidate support

```plain text
p|G_(H,B)(n)
iff
j in Z_p(H) or z_p(H)>B.
```

The degree a=z_p(H) member removes every non-target prime when z_p(H)<=B; if z_p(H)>B, every numerator is absorbed into its content. Thus the full family is exactly the anchored family plus the two missing purification degrees 0 and 2. The anchored family is strictly weaker: it retains E0 and E2.

1. No short anchored Bezout or recurrence currently gives logarithmic height o(H). Euclidean elimination against the linear K_(H,3) produces ordinary resultants and the slope factor alpha_H; it discards the marked evaluation or reintroduces the unmarked prefix-zero saturation from Q890. The only verified Apéry recurrence identity in the latest branch is a scalar finite-difference stencil; its proposed lift to saturated compound minors was retracted by the working-note audit.

Accordingly, the strongest exact outcome is a complete anchored-family ledger and a sharper no-go boundary. It does not prove the q=1 target.

# 1. Primitive Padé pairs and what is actually known about normality

For each numerator degree a, choose a primitive integral solution

```plain text
deg P_(H,a)<=a,
deg Q_(H,a)<=H-a,
P_(H,a)(s)=A_s Q_(H,a)(s),
0<=s<=H,

gcd(all coefficients of P_(H,a) and Q_(H,a))=1.
```

Existence requires no normality theorem. There are H+2 coefficients and H+1 homogeneous interpolation equations, so a nonzero rational solution exists. Clearing denominators and dividing the total coefficient gcd gives a primitive integral pair. Neither polynomial is identically zero, since all A_s are nonzero and the complementary polynomial would otherwise have too many roots.

The latest branch proves the order-statistic content theorem for every primitive solution and every prime p>H:

```plain text
v_p(content(P_(H,a)))=e_(a+1),
```

where

```plain text
e_(1)>=...>=e_(H+1)
```

are the ordered valuations v_p(A_s). This theorem does not need uniqueness or normality.

What is not proved globally is that the rational solution space is one-dimensional at every (H,a), or that the canonical cofactor choice has both degrees at their upper bounds. Finite computations verify these properties in the tested ranges. Therefore all statements below are formulated for arbitrary chosen primitive solutions and separate the nondegenerate and degree-drop cases.

# 2. Integrality and exact degree audit of the anchored determinant

For b>=2, put

```plain text
W_(1,b)(x)
 =P_(H,1)(x)Q_(H,b)(x)
  -P_(H,b)(x)Q_(H,1)(x).
```

At every interpolation node,

```plain text
W_(1,b)(s)
 =A_s Q_(H,1)(s)Q_(H,b)(s)
  -A_s Q_(H,b)(s)Q_(H,1)(s)
 =0.
```

Hence all H+1 linear factors divide the integral polynomial. Since

```plain text
Phi_H(x)=product_(s=0)^H(x-s)
```

is monic, polynomial long division takes place in Z[x] and gives

```plain text
W_(1,b)=Phi_H K_(H,b),
K_(H,b) in Z[x].
```

The degree bounds are

```plain text
deg(P_(H,1)Q_(H,b))<=H-b+1,

deg(P_(H,b)Q_(H,1))<=H+b-1.
```

Therefore

```plain text
deg K_(H,b)<=b-2.
```

This remains valid if either product drops in degree.

For b=2, K_(H,2) is constant and one recovers Q802's adjacent pollution constant.

For b=3, K_(H,3) has degree at most one. It has exact degree one precisely when

```plain text
lc(P_(H,3)) lc(Q_(H,1)) !=0.
```

Indeed, the lower product has degree at most H-2, while the upper product has possible degree H+2; hence the coefficient of x^(H+2) in W_(1,3) is

```plain text
-lc(P_(H,3))lc(Q_(H,1)).
```

Because Phi_H is monic, this is the slope of K_(H,3). Thus Q871's projective-independence statement is conditional on the two exact-degree assertions. If the slope vanishes, the determinant can be constant or zero.

If K_(H,b)=0, the two rational functions P/Q are equal wherever defined. This can occur only through a kernel degeneracy/projective coincidence; the present repository does not prove its exclusion for all heights. In that case the assertion “every good common prime divides K” becomes vacuous and rad(K(n)) must not be written.

# 3. Reciprocal-moment construction of the primitive numerator directions

The primitive formulas can be written entirely in terms of reciprocal Apéry moments.

For integers k,i>=0, define

```plain text
mu_(k,i)
 := Delta^k(s^i/A_s)|_(s=0)
 = sum_(s=0)^k (-1)^(k-s) binom(k,s) s^i/A_s.
```

A polynomial

```plain text
Z_(H,a)(x)=sum_(i=0)^a c_i x^i
```

has an interpolating quotient of degree at most H-a precisely when

```plain text
sum_(i=0)^a mu_(k,i)c_i=0
```

for

```plain text
k=H-a+1,...,H.
```

Let M_(H,a) be this a by (a+1) reciprocal-moment matrix. When it has rank a, a rational kernel generator is the signed maximal-cofactor vector

```plain text
c_i^raw=(-1)^i det(M_(H,a) with column i deleted).
```

Clear denominators and divide the coefficient gcd to obtain a primitive integer polynomial

```plain text
z_(H,a)(x)=sum_(i=0)^a z_(a,i)x^i.
```

The least multiplier making all node quotients integral is

```plain text
m_(H,a)
 =lcm_(0<=s<=H)
    A_s/gcd(A_s,z_(H,a)(s)).
```

Then, up to one sign,

```plain text
P_(H,a)=m_(H,a) z_(H,a),

Q_(H,a)
 =sum_(k=0)^(H-a)
   Delta^k(P_(H,a)(s)/A_s)|_(s=0) binom(x,k).
```

Minimality of the multiplier proves total primitivity of the pair.

For a=1, the matrix has the single row at k=H. Writing

```plain text
U_H=mu_(H,0),
V_H=mu_(H,1)=H(U_H-U_(H-1)),
```

the rational direction is

```plain text
P_(H,1)^rat(x)=V_H-U_H x.
```

This is Q850's reciprocal-boundary formula.

For a=3, the exact rational direction is the kernel of

```plain text
[ mu_(H-2,0) mu_(H-2,1) mu_(H-2,2) mu_(H-2,3) ]
[ mu_(H-1,0) mu_(H-1,1) mu_(H-1,2) mu_(H-1,3) ]
[ mu_(H,0)   mu_(H,1)   mu_(H,2)   mu_(H,3)   ].
```

Thus every coefficient of P_(H,3) is an explicit 3 by 3 determinant of reciprocal Apéry moments, followed by the exact nodewise multiplier above. No Smith ambiguity remains.

If this moment matrix drops rank, the cofactor vector is zero and one must select a primitive vector in the larger kernel. All determinant formulas below still hold for the selected pair, but there is then no canonical one-dimensional direction without an extra convention.

# 4. Exact primitive formula for the linear anchored polynomial

Write the primitive integral polynomials in the monomial basis:

```plain text
P_(H,3)(x)=p_3x^3+p_2x^2+p_1x+p_0,

Q_(H,1)(x)
 =q_(H-1)x^(H-1)+q_(H-2)x^(H-2)+...,

Phi_H(x)=x^(H+1)-S_H x^H+...,
S_H=H(H+1)/2.
```

Since

```plain text
deg(P_(H,1)Q_(H,3))<=H-2,
```

that product contributes nothing to the coefficients of degrees H+2 and H+1. Therefore

```plain text
[x^(H+2)]W_(1,3)=-p_3q_(H-1),

[x^(H+1)]W_(1,3)
 =-(p_3q_(H-2)+p_2q_(H-1)).
```

If

```plain text
K_(H,3)(x)=alpha_Hx+beta_H,
```

then comparison in

```plain text
W_(1,3)=Phi_H K_(H,3)
```

gives

```plain text
alpha_H=-p_3q_(H-1),

beta_H
 =-(p_3q_(H-2)+p_2q_(H-1))
   +S_Halpha_H.                                  (4.1)
```

Consequently

```plain text
content(K_(H,3))
 =gcd(alpha_H,beta_H),                            (4.2)
```

and the marked evaluation is

```plain text
K_(H,3)(3H+1)
 =-(p_3q_(H-2)+p_2q_(H-1))
  +(3H+1+S_H)alpha_H.                            (4.3)
```

These are exact integer formulas.

To express the top coefficients of Q_(H,1) directly through reciprocal moments, put

```plain text
d_k
 :=Delta^k(P_(H,1)(s)/A_s)|_(s=0).
```

Then

```plain text
q_(H-1)=d_(H-1)/(H-1)!,

q_(H-2)
 =[d_(H-2)-(H-2)d_(H-1)/2]/(H-2)!.              (4.4)
```

The right sides are integers because Q_(H,1) is integral, although the displayed reciprocal-moment representation is rational term by term.

Equations (4.1)--(4.4) are the requested explicit primitive formula. They also identify every exceptional case:

```plain text
alpha_H=0
iff
deg P_(H,3)<3 or deg Q_(H,1)<H-1;

alpha_H=beta_H=0
iff
K_(H,3)=0.
```

No asymptotic bound for (4.2) or (4.3) follows from these formulas. Each reciprocal moment has exponential denominator clearing, and the multiplier/content theorem supplies only local order statistics.

# 5. General explicit formula for every anchored pollution polynomial

For b>=3, write

```plain text
F_(H,b)(x)=P_(H,b)(x)Q_(H,1)(x)
          =sum_t f_(b,t)x^t.
```

Because

```plain text
deg(P_(H,1)Q_(H,b))<=H-b+1<H+1,
```

it contributes only to the remainder on division by Phi_H. Therefore the anchored quotient has the exact simpler description

```plain text
K_(H,b)
 =-quo_(Phi_H)(P_(H,b)Q_(H,1)),                 (5.1)
```

where quo is the Euclidean quotient in Z[x].

Write

```plain text
Phi_H(x)
 =x^(H+1)+phi_1x^H+phi_2x^(H-1)+...,

K_(H,b)(x)=sum_(r=0)^(b-2) kappa_(b,r)x^r.
```

The coefficients are obtained by the exact descending recursion

```plain text
kappa_(b,b-2)=-f_(b,H+b-1),

kappa_(b,r)
 =-f_(b,H+1+r)
  -sum_(i=1)^(b-2-r) phi_i kappa_(b,r+i),

r=b-3,...,0.                                     (5.2)
```

Thus

```plain text
content(K_(H,b))
 =gcd_(0<=r<=b-2) kappa_(b,r),                   (5.3)

K_(H,b)(3H+1)
 =sum_(r=0)^(b-2) kappa_(b,r)(3H+1)^r.           (5.4)
```

These are exact and directly reproducible from the primitive Padé coefficient vectors. They avoid constructing Q_(H,b) altogether: only P_(H,b) and the single anchored denominator Q_(H,1) are needed.

## Content forced by numerator contents

If

```plain text
c_a=content(P_(H,a)),
```

then every coefficient of W_(1,b) is divisible by

```plain text
gcd(c_1,c_b).
```

Division by the monic Phi_H preserves coefficientwise divisibility, so

```plain text
v_p(content(K_(H,b)))
 >=min(v_p(c_1),v_p(c_b))
 =min(e_(2),e_(b+1))
 =e_(b+1).                                       (5.5)
```

In particular,

```plain text
z_p(H)>=b+1
 => p|content(K_(H,b)).                           (5.6)
```

This is a lower bound, not an equality: determinant cancellation can add further content.

# 6. Correct derivative-at-the-node theorem

For every node j, define

```plain text
D_(H,a)(j)
 :=P_(H,a)'(j)-A_jQ_(H,a)'(j).
```

Differentiate

```plain text
P_(H,1)Q_(H,b)-P_(H,b)Q_(H,1)
 =Phi_HK_(H,b)
```

and use

```plain text
P_(H,a)(j)=A_jQ_(H,a)(j).
```

One obtains the exact node identity

```plain text
Phi_H'(j)K_(H,b)(j)
 =D_(H,1)(j)Q_(H,b)(j)
  -D_(H,b)(j)Q_(H,1)(j).                        (6.1)
```

Since

```plain text
Phi_H'(j)=(-1)^(H-j)j!(H-j)!
```

is a unit modulo every candidate prime, (6.1) is a sharp local equation.

Now let p=n-j>2H be a good candidate prime and suppose

```plain text
p|P_(H,1)(n).
```

Reduction from n to j gives P_(H,1)(j)=0; because A_j is a unit,

```plain text
Q_(H,1)(j)=0.
```

Therefore (6.1) becomes

```plain text
Phi_H'(j)K_(H,b)(j)
 =D_(H,1)(j)Q_(H,b)(j)  (mod p).                (6.2)
```

Hence:

```plain text
if D_(H,1)(j) !=0 mod p, then

    K_(H,b)(j)=0 mod p
    iff Q_(H,b)(j)=0 mod p
    iff P_(H,b)(j)=0 mod p.                     (6.3)
```

But if

```plain text
D_(H,1)(j)=0 mod p,
```

then

```plain text
K_(H,b)(j)=0 mod p
```

for every b, irrespective of P_(H,b)(j). Thus the whole anchored determinant family is blind on the singular derivative-defect locus.

This proves that Q871's implication

```plain text
common good prime => p|K_(H,b)(n)
```

is correct, but the reverse implication is false without the extra unit condition (6.3).

A global integral carrier for this exceptional locus can be formed by interpolating the node data D_(H,1)(j) with degree at most H; call it Delta_(H,1)(x). Then every singular candidate prime divides

```plain text
gcd(P_(H,1)(n),Delta_(H,1)(n),B_H).
```

This is exact, but the interpolant has no known subexponential-height bound. It is the first unavoidable marked factor produced by anchored elimination.

# 7. Exact candidate support of the anchored numerator family

Put

```plain text
S_B={1,3,4,...,B},

G^anch_(H,B)
 :=rad_(2H<p<=n)
   gcd(B_H, {P_(H,a)(n):a in S_B}).
```

For a candidate prime, let

```plain text
Z=Z_p(H),
z=|Z|,
j=n-p.
```

The order-statistic/zero-absorber theorem says:

```plain text
if z>a, then P_(H,a)=0 polynomial mod p;

if z<=a, then the nonzero reduction of P_(H,a)
contains Z among its node roots and has at most a-z extra node roots;

if z=a, its node-root set is exactly Z.                (7.1)
```

Use (7.1) degree by degree.

## Target class

If

```plain text
j in Z,
```

then every numerator vanishes at j; the prime is in the anchored gcd.

## Good primes with z=1

The degree-one numerator has exactly the unique zero node as its root. Therefore a good moving node is excluded.

## Good primes with 3<=z<=B

The selected family contains degree a=z, whose node-root set is exactly Z. Therefore a good moving node is excluded.

## Good primes with z>B

Every selected degree satisfies a<z, so every numerator is coefficientwise zero modulo p. The prime enters automatically.

## Good primes with z=0

There is no degree-zero member. The prime enters precisely when j is a common extra root of all selected projective numerators.

## Good primes with z=2

The degree-one numerator is coefficientwise zero, and degree two is missing. The prime enters precisely when j is an extra root of every selected numerator of degree at least three.

Therefore the exact support factorization is

```plain text
G^anch_(H,B)
 =T_H E_0(H,B) E_2(H,B) E_>(H,B),              (7.2)
```

where the factors are pairwise coprime squarefree products over candidate primes and

```plain text
T_H:
    j in Z_p(H);

E_0(H,B):
    z_p(H)=0 and
    P_(H,a)(j)=0 mod p for every a in S_B;

E_2(H,B):
    z_p(H)=2,
    j notin Z_p(H), and
    P_(H,a)(j)=0 mod p for every a=3,...,B;

E_>(H,B):
    z_p(H)>B and j notin Z_p(H).                (7.3)
```

No unproved weighted estimate is used here.

For B=3, the last class is exactly the “at least four prefix zeros” obstruction highlighted by Q871, but (7.2) shows the two additional projective classes that must also be controlled.

# 8. Relation to the anchored K-polynomial evaluations

Every prime in the good pollution factor

```plain text
E_0 E_2 E_>
```

is common to P_(H,1)(n) and every P_(H,b)(n), hence Q871's differentiated argument gives

```plain text
E_0(H,B)E_2(H,B)E_>(H,B)
 |
rad_(2H<p<=n)
 gcd_(3<=b<=B) K_(H,b)(n),                      (8.1)
```

provided none of the relevant K polynomials is identically zero. If one is zero, the right side must be interpreted by omitting it; it supplies no constraint.

The reverse divisibility is false for two reasons.

1. A prime can divide all anchored K values on the derivative-defect locus without dividing any higher numerator.

1. A prime can divide the K values through coefficient content or accidental polynomial roots while failing the anchor equation P_(H,1)(n)=0.

Away from

```plain text
P_(H,1)(n)D_(H,1)(j)=0 mod p,
```

identity (6.3) restores equivalence prime by prime. Thus the anchored K family is an exact replacement for the higher numerator family only on the regular anchor locus.

# 9. Adding degrees 0 and 2: exact equivalence with the full growing family

Define

```plain text
G^full_(H,B)
 :=rad_(2H<p<=n)
   gcd(B_H,P_(H,0)(n),P_(H,1)(n),...,P_(H,B)(n)).
```

Then the zero-absorber theorem gives the exact formula

```plain text
G^full_(H,B)
 =T_H V_>(H,B),                                 (9.1)
```

where

```plain text
V_>(H,B)
 :=product_({candidate good p:z_p(H)>B})p.       (9.2)
```

Proof:

```plain text
z<=B:
    the degree-a=z numerator is nonzero mod p
    and its node roots are exactly Z_p(H);
    hence a good moving node is excluded.

z>B:
    every degree a<=B is below the zero count;
    every numerator is coefficientwise zero mod p.
```

The missing degree zero removes E_0: when z=0, P_(H,0) is a nonzero constant modulo p.

The missing degree two removes E_2: when z=2, the degree-two numerator has exactly the two prefix zero nodes and no extra node root.

Therefore

```plain text
anchored family + degrees {0,2}
 = full growing Padé family
```

at the exact candidate-support level, with all primitive saturation factors already incorporated by the content theorem.

The anchored family by itself is not equivalent to the full family. Its strictly larger obstacle is precisely

```plain text
E_0(H,B)E_2(H,B).
```

# 10. Pseudo-division by the linear anchor and the first unavoidable resultant factor

Assume the nondegenerate case

```plain text
K_(H,3)(x)=alpha_Hx+beta_H,
alpha_H!=0.
```

For each b>=4, integral pseudo-division gives

```plain text
alpha_H^(b-2) K_(H,b)(x)
 =S_(H,b)(x)K_(H,3)(x)+rho_(H,b),               (10.1)
```

where

```plain text
rho_(H,b)
 =alpha_H^(b-2)
   K_(H,b)(-beta_H/alpha_H)
```

is an integer, equal up to sign to the resultant

```plain text
Res_x(K_(H,3),K_(H,b)).                          (10.2)
```

Hence a prime dividing all marked values satisfies

```plain text
p|K_(H,3)(n)
```

and, unless p|alpha_H,

```plain text
p|rho_(H,b)
```

for all b>=4.

This is the shortest possible Bezout elimination. It fails for three exact reasons.

1. Slope factor. Every prime dividing alpha_H is lost in pseudo-division. From (4.1),

```plain text
alpha_H=-lc(P_(H,3))lc(Q_(H,1)),
```

so this factor already contains primitive-saturation and degree-drop information.

1. Unmarked resultant saturation. The constants rho_(H,b) are ordinary resultants. Q890 proves that once a projective Padé tail shares any prefix-zero polynomial, ordinary resultants record the existence of an arbitrary prefix zero and forget the marked moving node. The same phenomenon can enter the anchored K resultants through content and common polynomial factors.

1. No height saving. Even if all resultants are nonzero, no bound

```plain text
log gcd_(4<=b<=B) |rho_(H,b)|=o(H)
```

is known. Standard Sylvester/Hadamard estimates are exponential or worse and work in the wrong direction.

Keeping K_(H,3)(n) in (10.1) retains one marked evaluation, but all additional elimination data are unmarked constants. Thus pseudo-division reduces the anchored family to

```plain text
K_(H,3)(n),
alpha_H,
{rho_(H,b):4<=b<=B},
```

without supplying a sublinear-height carrier.

# 11. Recurrence audit

The latest main commit contains one verified Apéry-specific finite-difference identity for the Newton table entries. It is a 12-term scalar stencil obtained by applying finite differences to the cubic Apéry recurrence.

The working-note audit retracts the claimed continuation from that scalar stencil to recurrences for saturated maximal minors. Determinant multilinearity applies to an entire row or column, whereas the scalar stencil moves one entry with coefficients depending on the column index. No common displacement identity

```plain text
sum_i L_i M R_i = boundary matrix
```

with controlled rank has been proved. Therefore there is presently no valid recurrence in b for

```plain text
P_(H,b),
K_(H,b),
content(K_(H,b)),
K_(H,b)(3H+1),
```

after primitive saturation.

Any claimed short recurrence obtained from raw cofactors but ignoring the maximal-minor gcd delta_(H,b) is invalid. The exact primitive value is

```plain text
P_(H,b)(n)
 =+-E_(H,b)(n)/delta_(H,b),
```

and the saturation indices vary with b.

# 14. Sharp remaining statements

The smallest fixed anchored family, B=3, would advance the problem only if all three estimates were proved:

```plain text
log E_0(H,3)=o(H),
log E_2(H,3)=o(H),
log E_>(H,3)=o(H).
```

The last is the unproved weighted four-prefix-zero estimate. The first two are common-projective-extra-root estimates and are not consequences of the vertical zero-count theorem.

For general fixed B, the exact obstacle is

```plain text
log E_0(H,B)
 +log E_2(H,B)
 +log E_>(H,B)
 =o(H).                                         (14.1)
```

For the full family, the exact obstacle is strictly smaller:

```plain text
log V_>(H,B)=o(H).                              (14.2)
```

At the zero-absorber scale

```plain text
B>=max_(candidate p) z_p(H),
```

formula (14.2) becomes empty and the candidate support is exactly the target support. What remains is not support purification but the original desired estimate on the target radical itself, equivalently the candidate-window radical of the full family gcd.

The next concrete lemma with genuine new content is therefore one of the following.

```plain text
Marked anchored-regularity lemma:
For all candidate good primes outside total logarithmic weight o(H),
D_(H,1)(n-p) is a p-unit and the common zeros of
K_(H,3),...,K_(H,B) at n have total weight o(H).
```

or, more directly,

```plain text
Primitive growing-family height lemma:
For B=ceil(C H^(2/3)),

log rad_(2H<p<=3H+1)
 gcd_(0<=a<=B) P_(H,a)(3H+1)
 =o(H).
```

No theorem on current main proves either statement. The anchored construction gives a useful exact decomposition, but after full primitive auditing it does not yet produce a shorter proof obligation than the growing-family lemma.
