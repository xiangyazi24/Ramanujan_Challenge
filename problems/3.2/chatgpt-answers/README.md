# ChatGPT archive for Problem 3.2

This directory contains raw answer drops selected by Problem 3.2 content.
Files are named by the global `ask-gpt` ledger number.  Code extracted from
fenced blocks is under `attachments/`.

Important limitations:

- These are oracle outputs, not accepted proofs.
- Some Notion exports omit displayed equation blocks.  The research log
  records equations that were independently reconstructed and checked.
- A returned answer is cited as proved only after its load-bearing statements
  have been independently derived, tested, or matched to a primary source.
- The global ledger interleaves unrelated projects.  Only entries positively
  identified as Problem 3.2 material are copied here.

The exact prompt text was not historically persisted by the bridge; older
question topics are recoverable from its ledger and are summarized in the
frontier log.  Future Problem 3.2 dispatches should be run from the
`Ramanujan_Challenge` repository so `ask-gpt-git` points every `dm` tab to
this GitHub repository.
