# Q6594 — FAV and finite-rank state-space lift

## Executive verdict

The finite-rank lift is the correct conceptual escape route, but it splits into two independent missing theorems:

1. **Comparison theorem (currently missing):** identify the index-shift family h -> M_h with iterates of a fixed finite-rank Frobenius/contiguity object.
2. **Family cancellation theorem (also missing):** once such an object exists, prove a vertical-in-h variance estimate.

The present obstruction is therefore not simply "GRH is weak". It is a categorical mismatch: existing Dwork/Katz technology controls a fixed sheaf as the arithmetic parameter varies, whereas GPRV fixes p and varies an effective conductor parameter h.

The sharp wall is:

```
index Frobenius/contiguity comparison:
  {M_h}_{h>=1}  --->  iterates of one bounded-rank F-crystal T
```

without this comparison, [FAV] is an extra axiom; with it, [FAV] becomes a standard-looking second-moment statement for a fixed object.

---

# 1. Precise finite-rank lift formulation

Let A be the rank-4 Apéry mixed crystal already isolated from the depth tower. Write

```
Phi : A^{sigma} -> A
Nabla_theta Phi = G(t) Phi - p Phi G(t^p)
```

for the semilinear Frobenius relation.

The desired object is not the t-family alone. It should be a finite-rank object

```
T = (A, Phi, U, Gamma)
```

where U is an integral unit-root/overconvergent subquotient and Gamma is a fixed correspondence implementing index translation.

The required comparison conjecture is:

```
(Index-Mellin comparison)

There exist a finite-rank F-isocrystal T and a fixed correspondence K on T
such that for every h>=1,

C_h(p) = mu_h + Tr( K o Frob_p^h | T ) + E_h(p),

with

sum_{h<=p} |E_h(p)|^2 = O(p).
```

Equivalently, after removing the mirror-forced component,

```
M_h-root count = fixed trace functional applied to the h-th iterate.
```

The missing point is that the known Dwork identity is

```
t -> t^p
```

Frobenius on coefficients, while the gap polynomial is generated by

```
h -> h+1
```

index contiguity.

The needed conjecture is therefore not "Dwork gives cancellation" but:

```
The Mellin/contiguity realization of the Apéry crystal identifies
index translation with a finite-rank Frobenius-compatible operator.
```

The depth tower and the relation

```
p^3 c[p+v] = c[p] K_v(p) mod p^7
```

support the existence of such a structure, but do not prove the comparison.

# 2. What [FAV] becomes after the lift

Assume the lift exists and T has bounded conductor.

Then [FAV] becomes a fixed-sheaf correlation statement:

```
Sum_{h<=H} |Tr(rho(Frob_p^h))-a_h|^2 <= C p
```

for H up to p.

This is much closer to known Frobenius equidistribution, but there is an important quantifier difference.

Known technology:

- Deligne equidistribution: fixed lisse sheaf, primes varying.
- Katz monodromy: fixed family over a parameter variety.
- Kowalski large sieve for Frobenius: averaging over primes and characters.

Theorem-level examples:

- Deligne, Weil II, proves square-root cancellation for trace functions attached to fixed pure sheaves when the finite-field point parameter varies.
- Katz, *Gauss sums, Kloosterman sums, and monodromy groups*, develops fixed sheaf monodromy and moments.
- Kowalski, *The large sieve and its applications*, Ch. 8, gives Frobenius large sieve estimates when the family and conductor are controlled.

None directly gives:

```
fixed p + h=1,...,p + iterates of one operator
```

unless the lift reduces h to a genuine orbit of a fixed dynamical Frobenius object and one proves an additional spectral-gap statement for that operator.

Thus bounded conductor is necessary but not automatically sufficient.

# 3. Literature audit

## Dwork families

Relevant:

- Dwork's original p-adic cohomology construction.
- Adolphson-Sperber, *Exponential sums and Newton polyhedra*.
- Wan's Newton polygon program.

What they prove:

Fixed Laurent polynomial family -> p-adic cohomology -> Frobenius slopes.

Mismatch:

They vary p or the geometric parameter. They do not prove a fixed-p variance over growing iterate index h.

## Katz hypergeometric/Kloosterman sheaves

Relevant:

- Katz, *Exponential Sums and Differential Equations*.
- Katz, *Rigid Local Systems*.

What they prove:

Fixed conductor lisse sheaf, monodromy, vertical Sato-Tate.

Mismatch:

The Apéry M_h have degree growing linearly in h. Their splitting fields/conductors are not known to arise as one fixed sheaf.

## Fu-Wan and Fouvry-Kowalski-Michel

These prove strong moment estimates for trace functions.

Mismatch:

The trace function is fixed and the finite-field parameter varies. Here p is fixed and the trace object changes with h.

## Denef-Loeser / Christol point-count ideas

They can package definable families.

Mismatch:

The index h enters as recurrence depth, not as a bounded-complexity algebraic parameter. No finite-rank motivic presentation is known.

## Kloosterman moments

Near miss:

Moments of Kloosterman sheaves are exactly a successful finite-rank lift.

Failure of analogy:

Kloosterman family has fixed rank and conductor. Here proving that M_h is a matrix coefficient of a fixed rank object is the theorem still missing.

# 4. Sharp GRH wall

Assume:

- Gal(M_h)=S_{m_h}
- Artin holomorphy
- GRH

For one h:

```
C_h-mu_h = O(m_h^A sqrt(p) log D_h)
```

with m_h ~ 3h.

Squaring:

```
(C_h-mu_h)^2 <= p * h^{2A} * log^2 D_h
```

Summing h<=p:

```
G <= p log^2(p) sum_{h<=p} h^{2A}
```

therefore

```
G <= p^{2A+2} log^2 p
```

(up to the additional discriminant logarithm). This is polynomially far above GPRV:

```
GPRV target: O(p)
GRH pointwise sum: O(p^{2A+2+o(1)})
```

The missing strengthening is exactly:

```
Family independence axiom:

For the Artin representations rho_h,

sum_{h<=p} |Tr rho_h(Frob_p)-E_h|^2 = O(p)
```

uniformly in p.

This is [FAV]. It is not implied by GRH; it is an orthogonality statement between different h-level Frobenius traces.

# 5. Relation to Q-SIGMA-1/2

The new unconditional estimate

```
Q_p(Delta) << Delta^(5/2)
```

moves the energy side above the trivial barrier but does not touch the quenched family wall.

It corresponds to partial control of collision geometry:

```
local recurrence complexity -> sigma > 1/2
```

whereas GPRV requires:

```
all h-level Frobenius fluctuations decorrelate at fixed p.
```

The missing coordinate is therefore still family compatibility, not local cancellation.

---

# 6. Final wall statement

The whole obstruction is one theorem:

```
Finite-rank index-Frobenius comparison theorem:

The Apéry gap-polynomial family M_h is the sequence of trace
coefficients of a bounded-rank overconvergent F-crystal operator.
```

If this theorem is proved, the remaining problem becomes a standard Frobenius variance/spectral problem.

If it fails, then GPRV is genuinely a growing-conductor quenched theorem with no known technology.

# Required final answers

## (a) Least-confident step

The least certain step is the existence of the exact comparison operator Gamma. The depth tower strongly suggests a finite-rank mixed object, but the current evidence only gives p-adic congruence transport, not an actual equality of trace functions.

## (b) Likely shared blind spot

The shared blind spot is assuming that the polynomial family h -> M_h is the fundamental object. It may only be a sequence of shadows of a smaller crystal. Conversely, it may not admit such a collapse at all; proving or disproving that is the decisive categorical test.
