# Verdict

There is an exact target-compatible amplification inside the second-order Apéry recurrence, but it is adaptive to the unknown zero set.

If

```plain text
Z_p(H)={t_1<...<t_z},
```

then the product of the canonical gap continuants over the consecutive zero gaps satisfies

```plain text
p^(z-1) | product_(i=1)^(z-1)
              N_(t_(i+1)-t_i)(t_i),
```

and this adaptive integer has logarithmic height only

```plain text
<= H log 117 + 3 log(H!)
= O(H log H).
```

More precisely its p-adic valuation is at least

```plain text
sum_(i=1)^(z-1)
  min(v_p(A_(t_i)),v_p(A_(t_(i+1)))).
```

This is the strongest clean positive amplification I can prove from the recurrence.

It does not produce the requested fixed global integer E_H, because its factors depend on which nodes are zeros modulo the particular prime p.

The strongest fixed global replacement is the short-gap product

```plain text
E_(H,L)
 = product_(0<=a<b<=H, 2<=b-a<=L)
     N_(b-a)(a).
```

For every target prime with z=z_p(H),

```plain text
v_p(E_(H,L))
 >= z-1-floor(H/(L+1)).
```

Its exact height bound is

```plain text
log E_(H,L)
 <= ((H+1)L(L-1)/2)
      * (log 117+3 log H).
```

Consequently, if R_H(Z) is the product of direct target primes having at least Z prefix zeros, and

```plain text
L=ceil(2H/(Z-1)),  Z>=3,
```

then

```plain text
R_H(Z)^ceil((Z-1)/2) | E_(H,L),
```

and hence

```plain text
log R_H(Z)
 <= (H+1)(log 117+3 log H)L(L-1)/(Z-1)

 < 4H^2(H+1)(log 117+3 log H)/(Z-1)^3
   +2H(H+1)(log 117+3 log H)/(Z-1)^2.
```

In asymptotic form,

```plain text
log R_H(Z)
 = O(H^3 log H / Z^3
     +H^2 log H / Z^2).
```

This is the sharpest proved high-zero inequality from the target-anchored continuant route.

It becomes o(H) only if

```plain text
Z >> H^(2/3) (log H)^(1/3).
```

But the existing vertical theorem gives

```plain text
z_p(H) << p^(2/3) << H^(2/3)
```

in the candidate window. Thus the range in which the new inequality would be sublinear is eventually empty. Even an ideal factorial normalization removing the displayed log H would give only O(H) at Z of order H^(2/3). The gain/height balance therefore saturates exactly at the known vertical scale.

The definite verdict is:

```plain text
The second-order recurrence gives a perfect adaptive p^(z-1)
amplifier of O(H log H) height, but no fixed global version
with O(H polylog H) height and linear gain throughout the
actual range z<=O(H^(2/3)).
```

A recurrence-compatible countermodel below shows why this failure is structural: the order-two recurrence, fixed initial state, unit off-diagonal transfer, exact Casoratian law, and no-consecutive-zero property permit an arbitrary prescribed nonconsecutive target zero set. The missing input must use the exact Apéry cubic or an equivalent Lucas/Dwork/hypergeometric identity that forces many zero pairs into one fixed sparse family of gaps.

# 3. Full p-adic two-zero valuation

Fix p>H and put

```plain text
e_s=v_p(A_s).
```

```plain text
v_p(X_s)=e_s.
```

If row_s=(r_s,s_s), then

```plain text
v_p(det(row_a,row_b))
 >=min(e_a,e_b).                               (3.1)
```

Combining (2.4) with the fact that a! is a p-unit gives:

```plain text

 >=min(v_p(A_a),v_p(A_b)).                     (3.2)
```

```plain text

  => p|N_(b-a)(a).                              (3.3)
```

The converse also holds once one endpoint is known to be a zero: since row_a is nonzero and annihilates (1,5) modulo p, it spans the line F_p*(-5,1), and (2.2) shows every transfer row is nonzero. Thus

```plain text
p|A_a
```

No recurrence singularity occurs on [0,H], because all transfer determinants m^6, m<=H, are p-units.

Equation (2.2) also proves that two zeros cannot be consecutive.

# 4. Positivity and exact height of one gap

The gap continuants are positive. More strongly,

```plain text
N_(h+1)(a)>(a+h+1)^3 N_h(a),  h>=1.           (4.1)
```

For h=1, this is

```plain text
P(a+1)>(a+2)^3.
```

If (4.1) holds one step earlier, put m=a+h. Then

```plain text
N_h(a)>m^3N_(h-1)(a),
```

so

```plain text
N_(h+1)(a)
 >[P(m)-m^3]N_h(a)
 >(m+1)^3N_h(a).
```

For an upper bound, for every m>=1,

```plain text
P(m)<=117m^3.
```

Since all N_h(a) are positive, (2.3) gives

```plain text
N_(h+1)(a)<P(a+h)N_h(a).
```

Thus, for d>=1,

```plain text
0<N_d(a)
 <=117^(d-1)
   *[((a+d-1)!)/a!]^3.                         (4.2)
```

Every essential factor in the amplification is therefore a nonzero integer. There are no hidden candidate-prime denominators.

# 5. The adaptive consecutive-gap amplifier

Let

```plain text
Z_p(H)={t_1<...<t_z}.
```

The target condition says that the moving node

```plain text
j=3H+1-p
```

is one of the t_i, but the argument below uses the complete zero set.

Define

```plain text
C_(p,H)
 =product_(i=1)^(z-1)
    N_(t_(i+1)-t_i)(t_i).                       (5.1)
```

By (3.2),

```plain text
v_p(C_(p,H))
 >=sum_(i=1)^(z-1)
      min(e_(t_i),e_(t_(i+1)))
 >=z-1.                                         (5.2)
```

Hence

```plain text
p^(z-1)|C_(p,H).                                (5.3)
```

The zero gaps are disjoint and their total length is at most H. Applying (4.2) gives

```plain text
C_(p,H)
 <=117^H(H!)^3,                                 (5.4)
```

so

```plain text
log C_(p,H)
 <=H log117+3log(H!)
 <=H log117+3H logH.                            (5.5)
```

This is a genuine compression. A star product joining the marked zero j separately to every companion would have total path length as large as zH; joining the zeros by their ordered path has total length at most H and keeps the same z-1 p-adic factors.

Equivalently, (5.1) is the determinant of a block-diagonal collection of the Dirichlet recurrence blocks between consecutive zero nodes. It is the optimal spanning-tree choice after the zero set is known.

The fatal defect is that C_(p,H) depends on p through Z_p(H). It is not one fixed integer attached only to H.

# 6. The strongest fixed global continuant product

For 2<=L<=H, define

```plain text
E_(H,L)
 =product_(d=2)^L
   product_(a=0)^(H-d)
     N_d(a).                                     (6.1)
```

This integer is independent of p and contains every gap continuant of length at most L exactly once.

Let

```plain text
d_i=t_(i+1)-t_i.
```

Since

```plain text
sum_i d_i=t_z-t_1<=H,
```

the number of gaps with d_i>=L+1 is at most

```plain text
floor(H/(L+1)).
```

Every remaining consecutive gap contributes one factor of p to (6.1). Therefore

```plain text
v_p(E_(H,L))
 >=z-1-floor(H/(L+1)).                           (6.2)
```

This is the exact global amplification law.

Using (4.2),

```plain text
log E_(H,L)
 <=sum_(d=2)^L (H-d+1)(d-1)
      *(log117+3logH)

 <=((H+1)L(L-1)/2)
      *(log117+3logH).                           (6.3)
```

Thus, if L is polylogarithmic,

```plain text
log E_(H,L)=O(H polylog H).
```

But then (6.2) is positive only when

```plain text
z>H/(L+1)+1.
```

For every fixed polylogarithmic L, this threshold is

```plain text
H/polylog H,
```

which is much larger than the known upper bound O(H^(2/3)). Hence every candidate prime in the actual possible range has zero guaranteed exponent in every polylog-height member of this short-gap family.

```plain text
R_H(Z)^ceil((Z-1)/2)
```

```plain text

 <=(H+1)(log117+3logH)
    *L_Z(L_Z-1)/(Z-1).                           (7.5)
```

Since

```plain text
L_Z-1<2H/(Z-1),
L_Z<=2H/(Z-1)+1,
```

```plain text

 <4H^2(H+1)(log117+3logH)/(Z-1)^3
  +2H(H+1)(log117+3logH)/(Z-1)^2.               (7.6)
```

At the largest possible zero scale


The established vertical bound excludes (7.7) for all sufficiently large candidate primes. The theorem is therefore a genuine inequality but not a nonvacuous asymptotic saving.

# 8. Why factorial normalization does not repair the exponent balance

The large factors in (4.2) come from the scaled integral recurrence. One may divide by products of

```plain text
(a+1)^3...(b-1)^3
```

and work with the original rational recurrence. Every such denominator is supported on primes at most H, hence is a p-unit for the candidate primes.

This can reduce Archimedean constants, but it cannot change the p-adic exponent in (6.2).

Even under the unrealistically favorable replacement

```plain text
log|normalized N_d(a)|=O(d)
```

for every gap, the same global short-gap product would satisfy only

```plain text
log E_(H,L)=O(HL^2),
```

and the optimized high-zero estimate would be

```plain text
log R_H(Z)=O(H^3/Z^3).
```

At Z of order H^(2/3) this is still only O(H), not o(H). Thus the failure is not the spare logH in the crude height bound. The selective exponent and the number of possible gap locations are exactly balanced at the vertical 2/3 scale.

# 9. Why the relation p+j=n is absent from the prefix recurrence

On the interval [0,H], the recurrence contains only the index m and the fixed cubic P(m). Since p>H, every transfer matrix is invertible modulo p.

The equality

```plain text
p+j=n
```

enters only when the solution is continued past the singular index m=p.

For the scaled transfer matrix

```plain text
T(m)=[[P(m),-m^6],[1,0]],
```

one has

```plain text
det T(m)=m^6.
```

The transfer from j to n=p+j crosses m=p exactly once, so its determinant has the universal valuation

```plain text
v_p(product_(m=j)^(n-1) det T(m))=6.             (9.1)
```

This factor occurs for good and bad primes alike. Dividing by the universal p^6 returns the normalized singular transfer; it supplies no factor depending on z_p(H).

The existing Frobenius-jet audits make the same point in a stronger form. At a bad residue, the zeroth coordinate vanishes, but normalized first and second singular jets can be p-units. Exterior order t forces p^t only because the construction has homogeneous determinant degree t; its height grows by the same order. No currently proved Dwork congruence makes the normalized jet valuation grow with the number of unrelated prefix zeros.

Thus the moving relation p+j=n does not improve the recurrence-only gap ledger. A positive argument must use an additional cross-residue hypergeometric identity, not merely cross the singular transfer point.

# 10. Determinants with z zero nodes: exact gain/height audit

At a zero node, the transfer row is nonzero but lies on the fixed line

```plain text
F_p*(-5,1).
```

Thus one zero does not make a row divisible by p; it imposes one projective rank condition. Each additional zero supplies one independent two-row minor divisible by p.

A tree on the z zero nodes therefore gives exactly z-1 forced Casoratian factors. The consecutive-gap path in Section 5 minimizes the total recurrence span and achieves

```plain text
selective valuation: at least z-1,
logarithmic height: O(H logH).
```

A determinant using an anchored star at j uses z-1 paths whose total length may be Theta(zH), so its height is O(zH logH) for the same p^(z-1) gain.

An unmarked determinant or resultant using all possible nodes avoids choosing the zero set, but it must cover Theta(H^2) possible pairs. Its natural height becomes Theta(H^3 logH) before the z-fold gain is used. This is exactly the loss quantified by (7.6).

Hence a z-row or z-edge determinant does not create superlinear amplification. It pays one multilinear degree, and at least one local span, for each forced p-factor.

# 11. Exact recurrence-compatible countermodel

The inability to choose a fixed sparse family of useful gaps is not special to the proof above.

Fix H, a candidate prime

```plain text
2H<p<=3H+1,
j=3H+1-p,
```

and any nonconsecutive set

```plain text
Z subset {2,...,H},
j in Z.
```

There exist integers c_1,...,c_(H-1) with

```plain text
|c_m|<=p/2<=2H
```

such that

```plain text
U_0=1,
U_1=5,
U_(m+1)=c_mU_m-m^6U_(m-1)                       (11.1)
```

has zero set modulo p on [0,H] exactly equal to Z.

## Construction

Choose c_m successively.

If

```plain text
U_m !=0 mod p,
```

there is exactly one residue class

```plain text
c_m=m^6U_(m-1)/U_m mod p                       (11.2)
```

that makes U_(m+1)=0. Choose this residue when m+1 in Z, and choose any other residue otherwise.

If

```plain text
U_m=0 mod p,
```

then m in Z. Since Z has no consecutive elements, m+1 notin Z, and induction gives U_(m-1)!=0. Because m<p,

```plain text
U_(m+1)=-m^6U_(m-1)!=0 mod p,
```

independently of c_m.

Taking least absolute representatives proves the coefficient bound.

This model preserves:

```plain text
fixed initial state (1,5);
off-diagonal coefficient -m^6;
coefficient size O(H);
exact adjacent determinant (m!)^6;
all gap-continuant and Casoratian identities;
no consecutive zeros;
the marked target relation p+j=3H+1.
```

But it permits an arbitrary nonconsecutive companion-zero pattern.

It does not preserve

```plain text
c_m=34m^3+51m^2+27m+5,
```

nor Apéry Lucas/Dwork congruences, reflection, or the hypergeometric/Picard--Fuchs origin.

Therefore no theorem derived only from the generic second-order recurrence axioms can force the companion zeros into a predetermined sparse set of gaps.

# 12. Sparse-gap obstruction for fixed continuant certificates

Consider any fixed multiplicative certificate built from marked two-zero detectors

```plain text
N_(b-a)(a)
```

for an edge set Gamma_H on the nodes 0,...,H.

Its guaranteed p-adic exponent at a zero set Z is at most the number of selected edges induced by Z.

If the certificate has logarithmic height O(H polylogH), then it can contain only O(H polylogH) distinct nontrivial gap factors, since every gap of length at least two has N_d(a)>1.

A graph with O(H polylogH) edges has an independent set of cardinality

```plain text
Omega(H/polylogH).
```

This follows, for example, from

```plain text
alpha(G)>=V^2/(2|E|+V).
```

Restricting first to one parity class ensures that the independent set is also nonconsecutive.

For large H,

```plain text
H/polylogH >> H^(2/3).
```

The countermodel in Section 11 realizes a target zero set of size floor(H^(2/3)) inside such an independent set. Every selected pair detector is then a p-unit, although the target has z of the maximal expected order.

This proves a rigorous no-go for the full class of fixed low-height products of marked continuants, Casoratian trees, and matrix-tree constructions whose valuation is certified edge by edge. It does not claim to classify every imaginable nonlinear hypergeometric identity; such an identity is precisely the missing extra structure.

# 13. The exact extra Apéry identity that would reopen the route

A sufficient recurrence-specific replacement is the following sparse marked-gap theorem.

```plain text
Sparse Apéry zero-graph theorem.

There exist fixed edge sets Gamma_H on {0,...,H} such that

  sum_((a,b) in Gamma_H) (b-a)
    = O(H polylogH),

and a constant c>0 such that, for every candidate target prime p,

  #{(a,b) in Gamma_H:
      p|A_a and p|A_b}
    >=c*(z_p(H)-1).
```

Under this theorem define

```plain text
E_H^*
 =product_((a,b) in Gamma_H)
    N_(b-a)(a).                                  (13.1)
```

Equations (3.2) and (4.2) give

```plain text
p^(c(z_p(H)-1))|E_H^*                           (13.2)
```

for every target prime, while

```plain text
log|E_H^*|=O(H polylogH).                       (13.3)
```

Hence targets with z_p(H)>=Z would satisfy

```plain text
sum log p
 <=log|E_H^*|/(c(Z-1))
 =O(H polylogH/Z).                              (13.4)
```

This is genuinely useful for every Z tending faster than the fixed polylogarithmic loss, and in particular throughout the high-zero regime.

The countermodel proves that this theorem cannot follow from order two, bounded coefficients, the determinant law, or no consecutive zeros. It must exploit one of the following equivalent kinds of genuinely Apéry-specific information:

```plain text
- the exact cubic P(m)=34m^3+51m^2+27m+5;
- a Dwork congruence coupling different bad residues, not only one
  residue and its Frobenius jet;
- a hypergeometric identity forcing additive structure or expansion
  in the zero set;
- a modular/Picard--Fuchs relation that places many companion zeros
  in one fixed sparse family of gap continuants.
```

A target-anchored version would be even sharper: find a fixed sparse graph for which a positive proportion of the edges joining the marked node j=3H+1-p to, or through, the other zero nodes is forced by the exact Apéry arithmetic.

No current Lucas congruence supplies this. Lucas propagates one residue vertically,

```plain text
A_(qp+r)=A_qA_r mod p,
```

but does not correlate two distinct residues r and s. The first and higher singular-jet formulas likewise retain separate normalized coordinates and do not add their valuations.

# 14. Final conclusion

The attempted amplification succeeds locally and fails globally for a precise reason.

```plain text
Adaptive zero-chain:
  p^(z-1) divides one integer of height exp(O(H logH)).
  This is optimal after the zero set is known.

Fixed global short-gap product:
  v_p >= z-1-floor(H/(L+1)),
  log height = O(H L^2 logH).

Optimized high-zero radical:
  log R_H(Z)=O(H^3 logH/Z^3).

At z=O(H^(2/3)):
  the bound saturates at O(H logH), not o(H).
```

The relation p+j=n contributes only a universal singular transfer factor when the recurrence crosses m=p; it does not make the selective valuation grow with the number of prefix zeros.

Thus no target-specific p-adic amplification of the requested strength is presently derivable from the second-order recurrence alone. The sharp surviving lemma is the sparse Apéry zero-graph theorem in Section 13. Proving it, or an equivalent Dwork/hypergeometric compression identity, would turn the adaptive p^(z-1) phenomenon into one globally small integer and would give the desired high-zero radical saving.
