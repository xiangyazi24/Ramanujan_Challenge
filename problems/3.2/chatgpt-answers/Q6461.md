# 1. The exact one-variable Weil theorem

## 1.1 Artin–Schreier criterion

[PROVED] Lemma 1.1. Let f in F_p(s). If

```plain text
f = h^p - h + c
```

for h in Fbar_p(s) and a constant c, then every pole of the nonconstant function f has order divisible by p.

Proof. If h has a pole of order m>0 at a point x, then h^p has pole order pm, strictly larger than the pole order m of h. Hence the leading polar term cannot cancel in h^p-h, and the resulting pole order is pm. If h has no pole on P^1, then h is constant, so f is constant. ∎

Consequently, a nonconstant rational function all of whose pole orders lie in {1,2,3} is not of Artin–Schreier form for every p>3.

## 1.2 Exact conductor constant

[STANDARD, with proof and citations] Theorem 1.2. Let f in F_p(s) be nonconstant and not of Artin–Schreier form. Let its actual poles on P^1 be x_1,...,x_m, of orders d_1,...,d_m, after Artin–Schreier reduction; assume p does not divide any d_i. Put

```plain text
D(f) = sum_i (d_i+1) - 2.
```

For a nontrivial additive character psi of F_p, the projective-open sum satisfies

```plain text
| sum_(x in (P^1 minus poles)(F_p)) psi(f(x)) |
    <= D(f) sqrt(p).                                      (1.1)
```

For the affine sum, if infinity is regular, one removes its one trace value and obtains

```plain text
| sum_(x in F_p, x not a finite pole) psi(f(x)) |
    <= D(f) sqrt(p) + 1.                                  (1.2)
```

Proof. Attach the rank-one Artin–Schreier sheaf L_psi(f) on the pole complement. At a pole of reduced order d_i, its Swan conductor is d_i. It is geometrically nontrivial because f is not h^p-h+c; hence H_c^0=H_c^2=0. Grothendieck–Ogg–Shafarevich gives

```plain text
dim H_c^1 = sum_i(d_i+1)-2 = D(f).
```

The trace formula identifies the sum with minus the Frobenius trace on H_c^1, and Deligne purity puts every eigenvalue on the complex circle of radius sqrt(p). This proves (1.1); (1.2) differs by the regular value at infinity. ∎

This is the exact conductor form of the classical Bombieri–Weil rational-function estimate. Primary anchors:

- Enrico Bombieri, “On exponential sums in finite fields,” American Journal of Mathematics 88 (1966), 71–105, DOI 10.2307/2373048.

- Pierre Deligne, “La conjecture de Weil II,” Publ. Math. IHÉS 52 (1980), 137–252, DOI 10.1007/BF02684780.

The displayed constant follows directly from the conductor calculation, so no unverified theorem number is needed.


# 4. L=2: explicit matrix and complete classification

Put P_0=P(s) and P_1=P(s+1). Formula (2.3) gives

```plain text
T_(s,2)=1/[s^3(s+1)^3] times

[ P_1 P_0-(s+1)^6       -s^6 P_1 ]
[ P_0                    -s^6     ].                (4.1)
```

Equivalently, with a(x)=P(x)/x^3,

```plain text

T_12=-a(s+1)s^3,
T_21=a(s)/(s+1)^3,
T_22=-(s/(s+1))^3.                                  (4.2)
```

Near s=0, the polar parts of the first column are

```plain text
T_11=584 s^(-3)+2556 s^(-2)+3534 s^(-1)+O(1),
T_21=  5 s^(-3)+  12 s^(-2)+   0 s^(-1)+O(1).       (4.3)
```

The three 2x2 minors of the coefficient matrix in (4.3) have greatest common divisor 6:



[PROVED] Proposition 6.1. As a rational function, ell(T_(s,L)) is the constant kappa if and only if the polynomial identity

```plain text
N_(L,ell)(s) - kappa D_L(s) = 0                    (6.2)
```

holds in F_p[s].

This is an explicit finite classification. Let M_L be the coefficient matrix whose five columns, in the monomial basis 1,s,...,s^(3L+3), are

```plain text

-s^6 U_(L-1)(s+1),
U_(L-1)(s),
-s^6 U_(L-2)(s+1),
-D_L(s).                                           (6.3)
```

Then the complete constant list is

```plain text

 = projection to the first four coordinates of ker(M_L mod p).       (6.4)
```

The corresponding fifth coordinate is the constant kappa. Since every polynomial in (6.3) has degree at most 3L+3, this is a fixed finite row reduction for fixed L.

If a phase takes one constant value at every admissible point of F_p, then after clearing denominators the polynomial in (6.2) has at least p-L roots. Hence, when

```plain text
p>4L+3,                                             (6.5)
```

pointwise constancy and rational-function constancy are equivalent.

[GAP-AFFINE-L]. Prove that rank(M_L)=5 over every F_p with p>max(3,L) for every L>=2, or classify the exceptional pairs (L,p).

# 7. Uniform sliding-block Weil theorem

[PROVED + STANDARD] Theorem 7.1 (SLIDING-WEIL-L, corrected exact form). Fix L>=1, let p>max(3,L), and let ell be a linear functional such that

```plain text
ell notin K_(L,p).                                  (7.1)
```

Then f(s)=ell(T_(s,L)) is nonconstant and not of Artin–Schreier form. If P_f is its actual pole set on P^1, with orders d_x, then

```plain text
|sum_(s in F_p, s not a finite pole of f) e_p(f(s))|
 <= [sum_(x in P_f)(d_x+1)-2] sqrt(p)
    + 1_(infinity regular).                        (7.2)
```

In particular,

```plain text
sum_(x in P_f)(d_x+1)-2 <= 4L+2.                   (7.3)
```

If the sum is instead taken over the prescribed block domain

```plain text
Omega_L=F_p minus {0,-1,...,-(L-1)},                (7.4)
```

some of those deleted points may be removable for the particular phase. Restoring/removing them costs at most L, and therefore

```plain text
|sum_(s in Omega_L) e_p(ell(T_(s,L)))|
 <= (4L+2)sqrt(p)+L+1
 <= (5L+3)sqrt(p).                                 (7.5)
```

Thus one may take the explicit polynomial constant

```plain text
C(L)=5L+3.                                          (7.6)
```

Proof. Proposition 2.2 gives actual pole orders at most three. Since the phase is nonconstant, it has a pole somewhere; Lemma 1.1 rules out h^p-h+c for p>3. Apply Theorem 1.2 and account for deleted regular points. ∎

For L=1, the sharper uniform constant 6 in (3.3) is valid.

# 9. Why this does not imply collision energy

Let

```plain text
V_s=(s^3b_s,b_(s-1))^T,
T_(s,h)V_s=V_(s+h).                                 (9.1)
```

```plain text
rho_(s,h)=((s+h)/s)^3,
R_(s,h)=(T_11(s,h)-rho_(s,h), T_12(s,h)).            (9.2)
```

Then

```plain text
b_(s+h)=b_s
iff R_(s,h) V_s=0.                                  (9.3)
```

This is the exact collision equation. For fixed h, after clearing denominators it defines a correspondence

```plain text
C_h subset A^1_s times P^1_[X:Y],
(T_11-rho)X+T_12Y=0,                                (9.4)
```

of degree O(h) in s and degree one in the incoming projective state.

The point actually inserted into (9.4) is

```plain text
[V_s]=[G_(s-1)...G_1(5,1)].                         (9.5)
```

The history in (9.5) has length s-1. It is not a fixed-degree rational function of s; any ordinary interpolation over F_p has complexity of order p. Consequently, additive orthogonality produces

```plain text
1_(b_(s+h)=b_s)
 =1/p sum_(xi in F_p) e_p(xi R_(s,h)V_s),           (9.6)
```

and the phase in (9.6) is not ell(T_(s,h)). The fixed-block Weil theorem controls the future block alone, while collision energy asks whether the full incoming history lands in the kernel line selected by that block.

This is the precise history/future coupling obstruction. Neither det T=1 nor strong reflection removes V_s.

[PROVED NEGATIVE INTERFACE]. SLIDING-WEIL-L by itself gives no bound for
