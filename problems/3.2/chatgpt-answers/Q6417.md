# 4. Why Newton-above-Hodge cannot bound the count

## 4.1 It is a lower-bound theory for each block

Newton-above-Hodge gives inequalities for slopes inside a fixed (r)-block. It does not impose an upper bound on the number of blocks whose first slope rises above zero. Since all block determinants have the same endpoint, moving one block from slopes ((0,3)) to ((1,2)) preserves the total slope (3).

Summing endpoints over all (r) yields a known quantity (asymp p), independent of (|Z_p|). Summing first slopes would be relevant, but the first slope is not an additive determinant invariant and no mass formula for it is supplied by Hodge theory.

# 8. Final assessment

The Wan-school intuition was close in one important sense: defining-characteristic slopes are the right local language, and the project’s equivalence between (pmid M_p(r)) and loss of the unit-root line is genuine.

It fails as a counting mechanism for three precise reasons:

1. the tame character is a discrete block label, not the (T)-adic variable;

1. Newton/Hodge theory controls Frobenius eigenvalues and determinants, whereas the event is cancellation in a trace;

1. the only full-family trace determinant is the circulant resultant, whose mod-(mathfrak P) nullity is exactly the original zero count.

Therefore no (O(p^{1/2})), (o(p)), or polylogarithmic theorem follows from Newton-above-Hodge, slope stability, generic ordinarity, or spectral halo as currently proved. Such a theorem would be a genuinely new cross-tame-character result.

Verdict: DEAD. The only surviving dispatch is the explicit Apéry resultant-factorization audit in Section 7; success there would constitute new structure beyond the existing T-adic formalism.
