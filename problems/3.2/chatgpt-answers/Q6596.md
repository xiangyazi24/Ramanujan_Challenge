# Fiber multiplicity: sigma=1/3 theorem, fiber-tail reduction, scoped incidence death

```plain text
THM-Q-SIGMA-ONE-THIRD

Let m_I(v) be the multiplicity of value v on a block I of length L.
Choose K = ceil(L^(1/3)). Then

m_I(v)-1 <= L/(K+1) + (3/2)K(K-1) <= 4L^(2/3).

Proof.

List all occurrences of the same fiber value v in increasing order. Split consecutive gaps into long gaps (>K) and short gaps (<=K).

The number of long gaps is at most L/(K+1), because their total length is bounded by L.

Every short gap h gives a collision of two points separated by h. The number of short-gap collisions is bounded by

sum_{h<=K} R_h <= sum_{h=1}^K 3h = (3/2)K(K-1),

using the degree bound R_h <= 3h.

Therefore

m_I(v)-1 <= L/(K+1)+(3/2)K(K-1).

With K=ceil(L^(1/3)), both terms are O(L^(2/3)), giving

m_I(v)-1 <= 4L^(2/3).

Corollary.

For the full window Delta,

max_r d_Delta(r) <= 4Delta^(2/3).

Since

sum_r d_Delta(r) <= (3/2)Delta^2,

we obtain

Q_p(Delta)=sum_r C(d_Delta(r),2)

<= (1/2)(max_r d_Delta(r))(sum_r d_Delta(r))

<= (1/2)(4Delta^(2/3))((3/2)Delta^2)

=3Delta^(8/3).

Status: THEOREM.
```

# Scoped incidence death

```plain text
Let

S={(r,pi(r)):0<=r<p}

inside A^1 x P^1(F_p).

For each fiber target v, the equation

phi_j(pi(r),r)=v

defines a bounded-degree cocycle curve.

A large fiber m_v>=T gives at least T incidences between S and one curve.

Using the Stevens-de Zeeuw type estimate

I(P,C) << (|P||C|)^(11/15)+|P|+|C|,

and |P|=|C|=p, we get

I << p^(22/15)+p.

At the desired threshold T=p^(1/3), the rich curve count is bounded by

p^(22/15)/p^(1/3)

=p^(17/15).

This is larger than p, the total number of curves, so no saving appears.

The missing input is not incidence geometry but dynamical rigidity:

A single Mobius cocycle orbit cannot have p^(1/3) repeated intersections with one low-degree translate of itself.

Status: DEATH-SCOPED.
```

# PHI-LINEAR-DEAD

```plain text
Theorem.

Assume the normalized rank-four Frobenius system

Phi_tilde=[[F,z],[0,p^3]]

with

h=(C,theta C,theta^2 C)^T

and equations

theta F=A F-p F A(t^p)

theta z=A z+p^3 u-p F u(t^p).

Then

z(t)=p^3 h(t)-F(t)h(t^p)+beta*bvec(t).

Proof.

The displayed expression is a particular solution. The difference between any two solutions satisfies the homogeneous rank-four equation. The last filtration quotient is constant, and the difference has no logarithmic part at t=0. Hence it is a pure horizontal section in the first block, giving beta*bvec(t).

Therefore

[t^n]z_1=p^3 c[n]+beta b[n],

for n<p.

For two indices r,s,

b[r][t^s]z_1-b[s][t^r]z_1

=p^3(b[r]c[s]-b[s]c[r]).

The beta term cancels identically. Therefore the mixed Frobenius extension produces no new collision equation in this rank-four first-block setting.

Status: DEATH(scoped: rank-4 linear, first block, mod p^4).
```
