## 4.3 FFT implementation in Python

The Gauss table can be computed by one FFT. If x_r=g^r\pmod p, then

```python
import numpy as np
from sympy import primitive_root


def gauss_table(p: int):
    """Return primitive root g and G[m] = sum_x omega^m(x) exp(2*pi*i*x/p)."""
    if p < 3:
        raise ValueError("p must be an odd prime")

    N = p - 1
    g = int(primitive_root(p))

    phase = np.empty(N, dtype=np.complex128)
    x = 1
    for r in range(N):
        phase[r] = np.exp(2j * np.pi * x / p)
        x = (x * g) % p

    # numpy.ifft has the positive Fourier sign and includes 1/N.
    G = N * np.fft.ifft(phase)
    return g, G


def apery_trace_one(p: int, z: int, G=None):
    """Compute the complex hypergeometric lift T_{p,z}, 1 <= z <= p-2."""
    N = p - 1
    if not (1 <= z <= p - 2):
        raise ValueError("The nondegenerate formula requires 1 <= z <= p-2")

    if G is None:
        _, G = gauss_table(p)

    j = np.arange(N)
    numerator = (
        G[(j + z) % N] ** 2
        * G[(j - z) % N] ** 2
        * G[(-j) % N] ** 4
    )
    denominator = G[z] ** 2 * G[(-z) % N] ** 2
    return -np.mean(numerator / denominator)


def apery_trace_all(p: int):
    """Compute T_{p,z} for all nondegenerate z. Cost after FFT: O(p^2)."""
    _, G = gauss_table(p)
    N = p - 1
    j = np.arange(N)
    Gminusj4 = G[(-j) % N] ** 4

    T = np.full(p, np.nan + 0j, dtype=np.complex128)
    for z in range(1, N):
        numerator = (
            G[(j + z) % N] ** 2
            * G[(j - z) % N] ** 2
            * Gminusj4
        )
        denominator = G[z] ** 2 * G[(-z) % N] ** 2
        T[z] = -np.mean(numerator / denominator)

    return T
```

## 6.1 Size and normalization

Each generic Jacobi-product summand in Section 4 has absolute size about p^2. That is the no-cancellation scale. The hypergeometric trace itself is expected on the weight-3 scale

|\mathcal T_{p,z}|\asymp p^{3/2},

and a rank-4 Deligne bound at a lisse point is of the form

|\mathcal T|\le 4p^{3/2}.

At t=1 the balanced rank-4 hypergeometric sheaf is at a singular fiber, so lower-weight pieces may occur. The central identity exhibits exactly such a term: \mathcal T=a(p)+p.

## 6.2 Why varying all z is not one Sato--Tate family

For fixed p, replacing z changes A_z, hence changes the local monodromy characters of the hypergeometric sheaf. As p changes, the rational parameter z/(p-1) also changes. Therefore

\{\mathcal T_{p,z}:1\le z\le p-2\}

is a mixture of different character orders and different hypergeometric data. It is not a set of Frobenius conjugacy classes from one fixed compatible system.

This is also why the general-z identity does not make the function z\mapsto b_z\bmod p a single bounded-conductor trace function: z indexes the character parameters rather than the geometric argument of one sheaf.
