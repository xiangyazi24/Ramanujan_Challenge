# Exact character_to_radicand recipe

## Executive correction

For one quadratic subfield route

```plain text
K = K12 = L^H,
F = K'_i = L^J,
H <= J <= Q = Gal(L/Q),
[J:H] = 2,
```

a single radicand d_target in F*/F*2 can encode the characters of several weight-two words only when those words are blocks in the same Q-orbit and their stabilizer characters transport back to one character of J.

Choose a base block word w0 with Stab_Q(w0)=J. For every word wt assigned to this sextic, choose qt in Q with

```plain text
wt = w0^qt
```

for the right action. Then

```plain text
Stab_Q(wt) = qt^(-1) J qt.
```

Transport its character back to J by

```plain text
psi_t(j) = chi_wt(qt^(-1) j qt),   j in J.
```

The necessary and sufficient one-column compatibility test is

```plain text
psi_1 = psi_2 = ... = psi_s =: psi_i in Hom(J,F2).
```

Test equality on generators of J. If it fails, there is no single sextic radicand that realizes the tuple. The grouping into one norm column is wrong, or the cocycle/root coordinates are misaligned. Use one column per compatible word orbit/relation field instead.

When the test passes, put

```plain text
U_i = ker(psi_i) <= J.
```

The exact target square class is the unique class

```plain text
[d_target_i] in F*/F*2
```

such that

```plain text
F(sqrt(d_target_i)) = L^U_i.
```

Equivalently,

```plain text
[d_target_i] in D_F := ker(F*/F*2 -> L*/L*2)
```

and the action of J on sqrt(d_target_i) is psi_i.

This is the replacement for the coarse relative discriminant. The class

```plain text
tr^2 - 4*nm
```

of the quadratic extension K/F realizes only the particular character

```plain text
J -> J/H ~= C2,
```

whose kernel is H. It is correct only when psi_i is that character.

# 1. Why one class controls all three words

Let

```plain text
N_{K/F}(delta) = d_target_i.
```

For the base pair word w0,

```plain text
P_w0(delta) = product_{a in w0} a(delta)
            = N_{K/F}(delta)
            = d_target_i.
```

Choose gamma0 = sqrt(d_target_i) in L. Then for j in J,

```plain text
j(gamma0)/gamma0 = (-1)^psi_i(j).
```

For wt=w0^qt, its relation product and root are automatically

```plain text
P_wt(delta) = qt(d_target_i),
gamma_t     = qt(gamma0),
```

and its stabilizer character is the conjugate character

```plain text
chi_wt(qt^(-1) j qt) = psi_i(j).
```

Thus the three target characters are not three independent radicands in one sextic. They are three conjugate readings of one class. The global cocycle finder should already enforce this; make the equality above a hard assertion.

There is no literal pullback from three unrelated fields F_w to F. In this clean weight-two lane, the fields F_wt are conjugates qt(F), and the other classes are qt(d_target_i). If a word has F_w=L^Stab(w) not conjugate to F, this function is not applicable; use the monomial-resolvent/relation-field path from Q165.

# 2. Production-optimal construction: cache a radicand basis per sextic

Let

```plain text
h = dim_F2 Hom(J,F2).
```

In GAP choose a basis

```plain text
psi_1,...,psi_h of Hom(J,F2).
```

For each basis character, construct one radicand

```plain text
F(sqrt(d_k)) = L^ker(psi_k).
```

Then every target character has coordinates

```plain text
psi_i = a_1 psi_1 + ... + a_h psi_h,
```

and the target radicand is simply

```plain text
d_target_i = product_k d_k^a_k  modulo F*2.
```

This works because multiplication of radicands adds quadratic characters. The expensive local/Selmer solve is therefore once per basis character, not once per target.

Store the cache key

```plain text
(base_closure_id, sextic_embedding_id, J_subgroup_id, character_basis_version)
```

and store each d_k as an element of the exact embedded sextic, not merely as an abstract isomorphic sextic polynomial.

# 3. Exact local-symbol target

## 3.1 Support set and probe set are different

Use two disjoint sets of finite places of F.

```plain text
S_support:
  all primes above 2;
  all primes of F ramified in L/F, or more tightly all primes ramified
  in the target subextension L^U_i/F;
  any extra primes needed by the chosen complete 2-Selmer basis.

T_probe:
  prime ideals p of F outside S_support;
  p unramified in L/F;
  p equipped with a certified Frobenius element Frob_p in J.
```

Do not put the Legendre probe primes into S_support. At a probe, the candidate must be a unit so that its ordinary quadratic residue symbol is defined.

Since L is totally real, every target quadratic subextension inside L is totally real. Therefore the target sign bit at each of the six real places is zero:

```plain text
d_target_i is positive at every real embedding of F.
```

## 3.2 Exact chi -> bit rule

For every probe prime p_l with chosen arithmetic Frobenius g_l in J, set

```plain text
b_l = psi_i(g_l) in F2.
```

Use the convention

```plain text
b_l = 0  <=> d_target is a square modulo p_l
             <=> p_l splits in F(sqrt(d_target))/F,

b_l = 1  <=> d_target is a nonsquare modulo p_l
             <=> p_l is inert in the unramified quadratic extension.
```

This is exactly the relation

```plain text
Frob_p(sqrt(d))/sqrt(d) = (d/p) = (-1)^psi_i(Frob_p).
```

For a word wt=w0^qt, the same bit can be audited as

```plain text
b_l = chi_wt(qt^(-1) g_l qt).
```

All words assigned to the sextic must return the same bit at every probe after this transport.

## 3.3 How many probes make the solve exact?

Let

```plain text
X = F(S_support,2)
```

be the complete 2-Selmer square-class space used by the solver, with basis

```plain text
x_1,...,x_m.
```

Complete means:

```plain text
S-units / squares
+ lifts of Cl_S(F)[2].
```

bnfsunit alone is not the complete Selmer group when the S-class group has 2-torsion. In PARI, bnfunits(bnf,S)[1] gives the independent S-unit generators including ordinary units and torsion; append your existing lifts of Cl_S[2].

For probes p_l, form

```plain text
M[l,j] = 0 if x_j is a square mod p_l,
         1 otherwise.
```

Append the six real-sign rows with target zero. Keep adding certified unramified probes until

```plain text
rank_F2(M) = m.
```

At that point the symbol map is injective on the chosen complete source. If the target subextension is unramified outside S_support, the solution is the unique square class in X with the requested character. This is an exact certificate, not a statistical Frobenius fingerprint.

If full rank is reached and the system is inconsistent, one of the following is true:

```plain text
- S_support omits a prime ramified in L^U_i/F;
- the source omits an S-class 2-torsion lift;
- Frobenius/prime/embedding labels are wrong;
- the transported word characters are not one character of J.
```

Enlarge T_probe to increase rank. Enlarge S_support only when the target conductor requires it; adding random support primes merely creates extraneous square classes.

# 4. Executable GP pseudocode

The GAP/Python side should export, per sextic:

```plain text
psi_coordinates      coordinates in the cached Hom(J,F2) basis;
target_probe_bits    psi_i(Frob_p) for the ordered probe list;
word_transport_audit one row per word, required to equal target_probe_bits.
```

The GP side consumes square-class generators and target bits. The following is valid PARI/GP 2.17-style pseudocode.

```javascript
\\ All Xgens must be expanded elements of F in nf/bnf representation.
\\ They must form a basis of the complete F(S,2), including Cl_S[2] lifts.

rank2(M) = matrank(M * Mod(1,2));

quad_symbol_bit(nf, a, pr) =
{
  my(v = nfeltval(nf,a,pr));
  if(v != 0,
    error("probe prime is in the support of candidate generator"));

  my(mp = nfmodprinit(nf,pr,'t));
  my(abar = nfmodpr(nf,a,mp));
  if(abar == 0, error("zero residue at probe prime"));

  if(issquare(abar), 0, 1)
};

sign_bit(nf,a,k) =
{
  my(s = nfeltsign(nf,a));
  if(s[k] < 0, 1, 0)
};

squareclass_product(nf, Xgens, x) =
{
  my(d = 1);
  for(j=1,#Xgens,
    if(lift(x[j]) % 2,
      d = nfeltmul(nf,d,Xgens[j]);
    );
  );
  d
};

build_character_matrix(bnfF, Xgens, probes) =
{
  my(nf = bnfF.nf);
  my(np = #probes, m = #Xgens, r1 = nf.r1);
  my(M = matrix(np+r1,m));

  for(i=1,np,
    for(j=1,m,
      M[i,j] = quad_symbol_bit(nf,Xgens[j],probes[i]);
    );
  );

  \\ L is totally real, so target radicands must be totally positive.
  for(k=1,r1,
    for(j=1,m,
      M[np+k,j] = sign_bit(nf,Xgens[j],k);
    );
  );
  M
};

character_to_radicand(bnfF, Xgens, probes, target_bits, Tnorm) =
{
  my(nf = bnfF.nf);
  my(np = #probes, m = #Xgens, r1 = nf.r1);
  if(#target_bits != np, error("target bit count mismatch"));

  my(M = build_character_matrix(bnfF,Xgens,probes));
  my(b = vectorv(np+r1,i, if(i<=np,target_bits[i],0)));

  if(rank2(M) < m,
    return(["NEED_MORE_PROBES", rank2(M), m]);
  );

  my(sol = matsolvemod(M,2,b,1));
  if(sol == 0,
    return(["NO_SELMER_SOLUTION"]);
  );

  my(x = lift(sol[1]) % 2);
  my(d = squareclass_product(nf,Xgens,x));

  \\ Hard audits.
  my(rt);
  if(nfeltissquare(nf,d,&rt),
    return(["TRIVIAL_CHARACTER_BUG",d]);
  );
  if(vecmin(nfeltsign(nf,d)) < 0,
    return(["INFINITE_PLACE_BUG",d]);
  );

  for(i=1,np,
    if(quad_symbol_bit(nf,d,probes[i]) != target_bits[i],
      error("post-solve symbol audit failed at probe ",i));
  );

  \\ Tnorm = rnfisnorminit(bnfF, relpol_K12_over_F, 1)
  \\ because K12/F is quadratic Galois.
  my(N = rnfisnorm(Tnorm,d));

  \\ PARI returns [delta,q] with d = Norm(delta)*q.
  if(N[2] != 1,
    return(["TARGET_CLASS_NOT_A_NORM",d,x,N[2]]);
  );

  my(delta_column = N[1]);
  return(["OK",d,delta_column,x]);
};
```

For the cached-basis version, run character_to_radicand once for each basis character psi_k, store d_k and delta_k, and form a target class by multiplying the d_k. You may either:

```plain text
- call rnfisnorm once on the final product d_target; or
- multiply the cached norm preimages delta_k, since norms multiply.
```

The second path is effectively free:

```plain text
N(product delta_k^a_k) = product d_k^a_k.
```

# 5. Norm feasibility is a separate exact gate

The target character determines one square class in F*/F*2. It does not automatically imply that this class is in

```plain text
N_{K/F}(K*).
```

For the quadratic Galois extension K/F, PARI's rnfisnorm result is exact: accept only when its correction factor q is 1.

This property depends only on the square class. Multiplying d_target by a square cannot repair a failed norm equation, because every square in F is already the norm of the same element viewed in K.

Therefore

```plain text
TARGET_CLASS_NOT_A_NORM
```

is a certified base/sextic-route failure, not a reason to enlarge the Selmer support or retry random representatives.

# 6. Exact-conductor refinement

The full-rank unramified probe solve is enough to determine the target square class. For a smaller matrix, add local rows derived from the target subgroup:

```plain text
For an odd prime p of F ramified in L/F:
  target quadratic extension ramifies at p
  iff psi_i is nontrivial on the inertia subgroup I_p <= J.
```

For a squarefree representative away from 2, encode this as the valuation-parity row

```plain text
v_p(d) mod 2 = 1 iff psi_i(I_p) != 0.
```

At primes above 2, valuation parity is not a complete local square-class invariant. Either retain the full-rank good-prime probe method or add a full basis of local dyadic square-class/Hilbert-symbol rows. Do not represent a dyadic target by one parity bit.

# 7. Pair-lane regression

For the known-good 24T8152 pair lane:

```plain text
one sextic F=K6,
one base pair word w0,
J=Stab_Q(w0),
one target character psi=chi_w0.
```

The transport-compatibility test is vacuous. The recipe gives

```plain text
U = ker(chi_w0),
F(sqrt(d_target)) = L^U,
N_{K12/F}(delta) = d_target.
```

This is exactly the old constructor. Regression tests should compare square classes, not literal coefficients:

```javascript
\\ d_old and d_new are elements of K6
my(q = nfeltdiv(nf6,d_new,d_old), s);
if(!nfeltissquare(nf6,q,&s),
  error("new radicand is not the pair-lane target square class"));
```

Then assert:

```plain text
- old and new target probe-bit vectors agree;
- both `rnfisnorm` calls return q=1;
- the resulting relation-root character is chi_w0;
- exact identification returns the same 24T8152 route.
```

# Bottom line

The missing function is not “fit three independent word characters by one sextic element.” It is:

```plain text
1. transport all word characters to J and assert they are one psi_i;
2. select the quadratic subextension L^ker(psi_i)/K'_i;
3. construct its unique square class in a complete K'_i(S,2) source by
   full-rank unramified Frobenius/Legendre equations;
4. solve N_{K12/K'_i}(delta)=d_target_i;
5. reject permanently if the target class is not a norm.
```

With a cached basis of Hom(J,F2), the per-target operation reduces to XOR of character coordinates and multiplication of cached radicands/norm preimages.
