# Apéry recurrence inside the bordered-minor ledger

## Verdict

At commit 9688ca1b52431669daff3f5efc50d9c228778330, the new information from Sections 160--162 is exactly this: the whole family removes local zero-set pollution, but the remaining gcd is a gcd of individually saturated bordered minors. The Apéry recurrence does impose a genuine finite bivariate stencil on the Newton multiplication matrix. It also gives a constant-boundary-displacement description of every finite Padé block. These are Apéry-specific identities and are proved below.

They still do not produce a subexponential integer combination of the primitive values. The obstruction is now completely explicit: after passing to maximal minors, the recurrence introduces shifted-column boundary minors which are not maximal minors of the original block R_(H,a). Therefore the last determinantal divisor delta_(H,a) need not divide them. Every raw determinant identity consequently acquires uncontrolled cross-saturation quotients after primitive normalization.

The smallest recurrence-specific theorem that would reopen the route is stated in Section 8. It asks only for subexponential control of these finitely many shifted-minor saturation quotients for 0<=a<=ceil(H^(2/3)); it is strictly smaller than estimating the Padé values themselves.

No low-order recurrence in H or a for the primitive values is supported by the exact small cases. The raw matrix has a finite stencil, but the saturation sequence already jumps at the first nontrivial examples:

# 1. Newton multiplication matrix

```plain text
A_0=1,
A_1=5,
(s+1)^3 A_(s+1)
 -(34s^3+51s^2+27s+5)A_s
 +s^3 A_(s-1)=0.
```

Define

```plain text
N_(r,l) = Delta^r A_l,
M_(k,l) = binom(k,l) N_(k-l,l),   0<=l<=k.
```

The first Apéry numbers and Newton coefficients are

```plain text
A_0=1, A_1=5, A_2=73, A_3=1445,
c_0=1, c_1=4, c_2=64, c_3=1240.
```

Hence

```plain text
M_(0,0)=1,

M_(2,0)=64,    M_(2,1)=136,   M_(2,2)=73,
M_(3,0)=1240,  M_(3,1)=3912,  M_(3,2)=4116,  M_(3,3)=1445.
```


# 2. Exact 12-term bivariate recurrence for finite differences

Apply Delta^r to the Apéry recurrence as a recurrence in the lower index l. The discrete Leibniz rule is

```plain text
Delta^r(fg)(l)
 = sum_(h=0)^r binom(r,h)
     (Delta^h f)(l)
     (Delta^(r-h) g)(l+h).
```

Only h<=3 occurs because all coefficient polynomials are cubic. Set

```plain text
P(l)=34l^3+51l^2+27l+5.
```

The required finite differences are

```plain text
dplus_0(l)=(l+1)^3,
dplus_1(l)=3l^2+9l+7,
dplus_2(l)=6l+12,
dplus_3(l)=6;

dP_0(l)=34l^3+51l^2+27l+5,
dP_1(l)=102l^2+204l+112,
dP_2(l)=204l+306,
dP_3(l)=204;

dminus_0(l)=l^3,
dminus_1(l)=3l^2+3l+1,
dminus_2(l)=6l+6,
dminus_3(l)=6.
```

Therefore, for every r>=0 and every l>=1, with terms having negative indices omitted,

```plain text
sum_(h=0)^min(3,r) binom(r,h) * (
    dplus_h(l)  N_(r-h,l+h+1)
  - dP_h(l)     N_(r-h,l+h)
  + dminus_h(l) N_(r-h,l+h-1)
) = 0.                                           (2.1)
```

This is a genuine Apéry-specific bivariate recurrence. It is not a generic Pluecker identity.

Substituting r=k-l and

```plain text
N_(r,l)=M_(r+l,l)/binom(r+l,l)
```

gives the matrix stencil

```plain text
sum_(h=0)^min(3,k-l) binom(k-l,h) * (
    dplus_h(l)
      M_(k+1,l+h+1)/binom(k+1,l+h+1)
  - dP_h(l)
      M_(k,l+h)/binom(k,l+h)
  + dminus_h(l)
      M_(k-1,l+h-1)/binom(k-1,l+h-1)
) = 0.                                           (2.2)
```

After multiplying by the product of the finitely many displayed binomial denominators, (2.2) is an integral polynomial-coefficient recurrence. Its stencil uses only rows k-1,k,k+1 and columns from l-1 through l+4.

# 3. Banded Newton-operator form

There is a second useful form. For fixed l, define

```plain text
f_l(s)=A_s binom(s,l).
```

Multiplying the Apéry recurrence by binom(s,l) and clearing the two elementary binomial ratios gives

```plain text
(s-l)(s+1)^2(s+1-l) f_l(s+1)
 -(s-l)P(s) f_l(s)
 +s^4 f_l(s-1)=0.                                (3.1)
```

Shift once to remove the backward translate:

```plain text
(x+1-l)(x+2)^2(x+2-l) E^2 f_l
 -(x+1-l)P(x+1) E f_l
 +(x+1)^4 f_l = 0,                               (3.2)
```

where (Ef)(x)=f(x+1).

In the Newton basis, if m=(m_0,m_1,...) is the coefficient vector, then

```plain text
(E m)_k = m_k+m_(k+1),
(X m)_k = k m_k + k m_(k-1),
```

with m_(-1)=0. Thus the conjugate of (3.2) is a banded operator with at most four lower and two upper diagonals. Every column of M is annihilated by this explicit banded operator.

For any finite rectangular block, the failure of the infinite identity is supported only on:

```plain text
one top row,
one bottom row,
one left boundary column,
four right boundary columns.
```

Hence the recurrence displacement of a finite block has rank at most seven. This is the promised low-displacement-rank identity.

# 4. What happens to compound matrices

Let

```plain text
C_b(I,J)=det M[I,J],   |I|=|J|=b.
```

Applying (2.2) to one selected entry and using determinant multilinearity yields a finite recurrence among b x b minors. Every term is obtained from (I,J) by one of the following moves:

```plain text
row move:    k -> k-1, k, or k+1;
column move: l -> l-1, l, l+1, l+2, l+3, or l+4;
one row and one column are moved at a time.
```

The number of terms is bounded by 12b; the coefficients are explicit products of the polynomials in Section 2 and binomial factors.

For an interior minor all shifted minors remain in the same infinite compound matrix. For R_(H,a), however, the rightmost shifts l+1,...,l+4 leave the column set 0..b, and the row shifts at a+1 or H leave the row interval. The recurrence therefore closes only after adjoining a finite boundary family of shifted minors.

Define S_(H,a) to be the set of all b x b minors obtained from a maximal minor of R_(H,a) by:

```plain text
moving one row by at most one,
and moving one column by an offset in {-1,0,1,2,3,4}.
```

Then the recurrence gives exact integral linear relations among

```plain text
maximal minors of R_(H,a)
and minors in S_(H,a).
```

The cardinality of S_(H,a) is polynomial in b, and the offset set is fixed. This is a strict recurrence-specific reduction.

# 5. Exact saturation obstruction

The last determinantal divisor satisfies

```plain text
delta_(H,a)
 = gcd{ maximal minors of R_(H,a) }.
```

Therefore it divides every integral combination of the unshifted maximal minors. It need not divide a shifted minor in S_(H,a), because that minor belongs to a different row/column presentation.

Write

```plain text
sigma_(H,a)
 = gcd( delta_(H,a),
        all shifted boundary minors in S_(H,a) ).
```

The recurrence relations become primitive identities only after division by sigma_(H,a), not after division by delta_(H,a). The exact loss is

```plain text
q_(H,a) = delta_(H,a)/sigma_(H,a).                (5.1)
```

Every attempted recurrence for the primitive bordered minors acquires coefficients divisible by, or denominators equal to, these q_(H,a). This is the precise term that Q885's bordered ledger did not yet identify.

The obstruction appears already at the h=3 term of (2.2): it contains

```plain text
6 binom(k-l,3)
  M_(k+1,l+4)/binom(k+1,l+4),                    (5.2)
```

which, at the right boundary l=b, introduces column b+4. The corresponding compound term is not a maximal minor of R_(H,a). No statement about delta_(H,a) alone controls its primitive quotient.

Thus any raw determinant recurrence which omits the quotient (5.1) is invalid for the primitive Padé pair.

# 7. Why a direct subexponential combination is not yet obtained

Suppose one derives a raw relation

```plain text
sum_(a=0)^A c_(H,a) E_(H,a)(3H+1) = F_H,
```

where

```plain text
E_(H,a)=det([R_(H,a);w(3H+1)]).
```

Since

```plain text
E_(H,a)=delta_(H,a) P_(H,a)(3H+1),
```

the corresponding primitive relation is

```plain text
sum_(a=0)^A c_(H,a) delta_(H,a) P_(H,a)(3H+1)=F_H.
```

Even if the c_(H,a) are polynomially bounded and F_H is small, the coefficients c_(H,a)delta_(H,a) may have quadratic-exponential height. Dividing by a common gcd does not help unless the relative saturation spread is controlled.

The Apéry stencil supplies the raw relation; it supplies no estimate of

```plain text
lcm_(0<=a<=A) delta_(H,a)
 /
gcd_(0<=a<=A) delta_(H,a),                       (7.1)
```

nor of the finer boundary quotients q_(H,a) in (5.1). This is the remaining primitive obstruction.

# 8. Weakest recurrence-specific theorem that remains

Let A_H=ceil(H^(2/3)). For every 0<=a<=A_H, let S_(H,a) be the finite recurrence-boundary minor family from Section 4 and define

```plain text
sigma_(H,a)
 = gcd(delta_(H,a), S_(H,a)),
q_(H,a)=delta_(H,a)/sigma_(H,a).
```

The smallest sufficient new theorem exposed by the Apéry recurrence is:

```plain text
Recurrence-saturation transport lemma.

For A_H=ceil(H^(2/3)),

log lcm_(0<=a<=A_H) q_(H,a) = o(H),               (8.1)

and the recurrence-boundary compound system contains an integral relation

sum_(a=0)^A_H u_(H,a)
  [det([R_(H,a);w(3H+1)])/sigma_(H,a)]
   = T_H,                                         (8.2)

with

max_a log(1+|u_(H,a)|)=o(H),
0<|T_H|=exp(o(H)).
```

Then substituting

```plain text
det([R;w])/sigma = q_(H,a) P_(H,a)(3H+1)
```

and dividing the coefficients by their gcd produces a nonzero integer combination of the primitive Padé values of logarithmic height o(H). Every candidate prime dividing all P_(H,a)(3H+1) divides T_H, proving the desired candidate-window radical bound.

The genuinely new part is (8.1). Relation (8.2) is a finite elimination problem for the explicit recurrence stencil; without (8.1), it is only a raw determinant identity and is unusable after primitive normalization.

A still narrower theorem, sufficient for the same purpose, is the pointwise bound

```plain text
sum_(0<=a<=A_H) log q_(H,a)=o(H).                 (8.3)
```

This is stronger than (8.1) but easier to state and test. It concerns only shifted-minor saturation created by the Apéry recurrence; it does not restate the original moving-prime support problem.

# 9. Final conclusion

The Apéry recurrence contributes real structure:

```plain text
1. an explicit 12-term recurrence for N_(r,l);
2. an explicit finite stencil for M_(k,l);
3. a banded Newton-operator annihilator;
4. boundary displacement rank at most seven for every finite block;
5. a finite recurrence system for compound minors.
```

But the primitive family is controlled by delta_(H,a), and the compound recurrence exits the original maximal-minor ideal at the explicit h=3, l -> l+4 boundary term. The resulting quotient q_(H,a) is the exact saturation loss.

Accordingly, no theorem-grade subexponential combination is currently obtained. The sharp remaining problem is not another generic determinant estimate; it is the recurrence-specific saturation-transport bound (8.1), or the stronger summatory version (8.3), together with finite elimination in the explicit compound stencil.
