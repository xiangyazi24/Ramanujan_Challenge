
paired with the fixed numerator-degree-one primitive numerator

```plain text

P_(H,1)(x) Q_(H,3)(x)

 = Phi_H(x) K_H(x),

Phi_H(x) := product_(s=0)^H (x-s),
deg K_H <= 1,
K_H in Z[x].
```

At

```plain text
n = 3H+1,
B_H = binom(n,H+1),
```

every direct q=1 target prime divides all three integers

```plain text
P_(H,1)(n),  P_(H,3)(n),  B_H.
```

```plain text
rad_(2H<p<=n) gcd(P_(H,1)(n),P_(H,3)(n),B_H)
 = T_H E_H,

gcd(T_H,E_H)=1,
E_H | rad_(2H<p<=n)(K_H(n)),
```

where

```plain text
T_H
 = product_({0<=j<=H : p=n-j prime, p|A_j}) p
 = rad_(p>2H) gcd(A_n,B_H)
```

is the original direct target core.

This is a genuine improvement over merely adjoining the adjacent numerator: the entire good-prime pollution is compressed into one linear determinant value. But it does not yet prove o(H). The latest all-degree content theorem gives a sharp obstruction:

```plain text
If a candidate prime p has at least four prefix zeros
among A_0,...,A_H,
then p divides both numerator contents
content(P_(H,1)) and content(P_(H,3)).
```

Hence such a prime divides both certificate values for every evaluation point, independently of the moving node. If the moving node is not a zero, it is automatic good-prime pollution, and the determinant theorem forces it into K_H(n).

Thus the degree-three certificate reduces the problem to two precise estimates:

```plain text
(V4)  sum_({candidate p : #Z_p(H)>=4,
                         n-p notin Z_p(H)}) log p = o(H),

(LIN) log rad_(2H<p<=n)(K_H(n)) = o(H)
```

Neither estimate is currently proved. The first is a weighted four-prefix-zero theorem; the second is a candidate-window radical theorem for an explicit linear Padé determinant. Total-height bounds for K_H(n) are much too large.

There is also a general dichotomy. This is the exact saturation point of the two-certificate route.

# 1. Canonical Padé notation and primitive normalization

Let

```plain text
A_s = sum_k binom(s,k)^2 binom(s+k,k)^2.
```

For each numerator degree a, the canonical primitive integral Padé pair is

```plain text
deg P_(H,a) <= a,
deg Q_(H,a) <= H-a,
P_(H,a)(s) = A_s Q_(H,a)(s),  0<=s<=H,
```

with total coefficient gcd one. The latest main branch proves the exact local content formula. If p>H and

```plain text
e_s = v_p(A_s),
e_(1)>=...>=e_(H+1)
```

are the ordered node valuations, then

```plain text
v_p(content(P_(H,a))) = e_(a+1).               (1.1)
```

In particular, writing

```plain text
Z_p(H) = {s in [0,H] : p|A_s},
z_p(H) = #Z_p(H),
```

one has

```plain text
p | content(P_(H,a))
iff z_p(H) >= a+1.                              (1.2)
```

For a=1, Q850 and Q867 identify

```plain text
P_(H,1)(x)=m_H z_H(x),
deg z_H=1,
```

and prove

```plain text
v_p(m_H)=e_(2).
```

Thus P_(H,1) contains every candidate prime with at least two prefix zeros, regardless of the moving node.

The degree-three pair is projectively independent of the degree-one pair. In the canonical normal Padé family its numerator has exact degree three; hence it cannot be a scalar multiple of a degree-one polynomial. This is the first nonadjacent degree for which the determinant quotient is nonconstant but still linear.

# 2. Why degree three is the optimal first second certificate

For two numerator degrees a<b, define

```plain text
W_(a,b)(x)
 := P_(H,a)(x)Q_(H,b)(x)
    -P_(H,b)(x)Q_(H,a)(x).
```

At every interpolation node s=0,...,H,

```plain text
W_(a,b)(s)
 = A_s Q_(H,a)(s)Q_(H,b)(s)
  -A_s Q_(H,b)(s)Q_(H,a)(s)
 = 0.
```

Therefore the monic node polynomial

```plain text
Phi_H(x)=product_(s=0)^H(x-s)
```

divides W_(a,b) in Z[x]. The degree bound is

```plain text
deg(P_a Q_b) <= a+H-b,
deg(P_b Q_a) <= b+H-a,
```

so

```plain text
deg W_(a,b) <= H+(b-a),

deg K_(a,b) <= b-a-1,

W_(a,b)=Phi_H K_(a,b),
K_(a,b) in Z[x].                                (2.1)
```

For a=1:

```plain text
b=2  => deg K_(1,2)<=0,
b=3  => deg K_(1,3)<=1.
```

The first line is exactly the adjacent Q802 constant kappa_1; it supplies no new direction-dependent support. The second line is the minimal genuinely nonadjacent determinant. We therefore set

```plain text
R_H=P_(H,3),
K_H=K_(1,3).
```

Explicitly,

```plain text
P_(H,1)Q_(H,3)-P_(H,3)Q_(H,1)
 = Phi_H K_H,
K_H(x)=alpha_H x+beta_H                 (possibly constant in exceptional H).
                                                        (2.2)
```

Even if the linear coefficient vanishes at an exceptional height, the identity remains valid; then the pollution is supported on one constant integer, reducing to the adjacent-type case.

# 3. Every target prime divides both certificates

Put

```plain text
n=3H+1,
B_H=binom(n,H+1).
```

Let

```plain text
2H<p<=n,
p=n-j,
0<=j<=H.
```

Then p>H, and for every integral polynomial of degree at most H, Newton/binomial reduction gives

```plain text
F(n)=F(j)  (mod p).                              (3.1)
```

If p|A_j, interpolation gives for every Padé degree a

```plain text
P_(H,a)(n)
 =P_(H,a)(j)
 =A_j Q_(H,a)(j)
 =0                                             (mod p). (3.2)
```

Thus every target prime divides both

```plain text
P_(H,1)(n),
P_(H,3)(n).
```

The candidate-window binomial carrier satisfies

```plain text
p|B_H,
v_p(B_H)=1,                                   (3.3)
```

because the numerator interval of B_H contains the unique factor p=n-j, while its denominator and every other numerator factor are p-units.

Consequently

```plain text

      gcd(P_(H,1)(n),P_(H,3)(n),B_H).          (3.4)
```

Here


# 4. Exact good-prime pollution theorem

Define

```plain text
G_H
 := rad_(2H<p<=n)
      gcd(P_(H,1)(n),P_(H,3)(n),B_H).
```

Since T_H|G_H, define the squarefree quotient

```plain text
E_H=G_H/T_H.
```

## Theorem 4.1

```plain text
G_H=T_H E_H,
gcd(T_H,E_H)=1,
E_H | rad_(2H<p<=n)(K_H(n)).                   (4.1)
```

More exactly,

```plain text
E_H
 = product_({candidate p=n-j :
             p not| A_j,
             p|P_(H,1)(n),
             p|P_(H,3)(n)}) p.                (4.2)
```

### Proof

The exact product formula (4.2) is simply the definition of the target quotient: candidate primes are selected by B_H; those with p|A_j form T_H; the remaining common numerator primes form E_H.

Take a prime in (4.2). By (3.1),

```plain text
P_(H,1)(j)=P_(H,3)(j)=0  (mod p).
```

Because p not|A_j, interpolation implies

```plain text
Q_(H,1)(j)=Q_(H,3)(j)=0  (mod p).              (4.3)
```

Differentiate (2.2):

```plain text
W'_(1,3)
 =P'_(H,1)Q_(H,3)+P_(H,1)Q'_(H,3)
  -P'_(H,3)Q_(H,1)-P_(H,3)Q'_(H,1).
```

Every term vanishes modulo p at x=j by (4.3) and the two numerator congruences. Hence

```plain text
W'_(1,3)(j)=0  (mod p).                        (4.4)
```

On the right side of (2.2), since Phi_H(j)=0,

```plain text
W'_(1,3)(j)=Phi'_H(j)K_H(j).                   (4.5)
```

The derivative is

```plain text
Phi'_H(j)=(-1)^(H-j)j!(H-j)!,                 (4.6)
```

which is a p-unit because p>H. Therefore

```plain text
K_H(j)=0  (mod p).
```

Finally n=j+p, so

```plain text
K_H(n)=K_H(j)=0  (mod p).
```

Thus every prime in E_H divides K_H(n), proving (4.1).

This is strictly stronger than the adjacent identity. Q802 places adjacent pollution in an arbitrary large constant kappa_b. Here every good common prime is forced into one explicit polynomial value of degree at most one.

# 5. Exact content obstruction for the degree-three choice

The all-degree content theorem (1.1) gives

```plain text
v_p(content(P_(H,1)))=e_(2),
v_p(content(P_(H,3)))=e_(4).                   (5.1)
```

Therefore

```plain text
z_p(H)>=4
 => p|content(P_(H,1))
    and p|content(P_(H,3)).                    (5.2)
```

For every candidate prime satisfying (5.2),

```plain text
p|P_(H,1)(n),
p|P_(H,3)(n)                                  (5.3)
```

without using j=n-p and without using the projective roots.

If additionally

```plain text
p not| A_j,
```

then p is good-prime pollution. Theorem 4.1 forces

```plain text
p|K_H(n).                                     (5.4)
```

Hence the explicit automatic pollution factor

```plain text
V_H^(4)
 := product_({candidate p=n-j :
              z_p(H)>=4,
              p not|A_j})p                    (5.5)
```

satisfies

```plain text
V_H^(4) | E_H | rad(K_H(n)).                  (5.6)
```

This is the first exact obstruction that is absent from the adjacent discussion. The degree-three certificate does not merely inherit Q802's kappa pollution: it inherits a precisely characterized four-zero content factor.

A height proof for K_H(n) would therefore automatically prove a weighted theorem about candidate primes with four prefix zeros. No such theorem is presently available from the pointwise zero-count bound

```plain text
z_p(H)=O(p^(2/3)).
```

That bound controls the number of zeros inside one prime; it does not control how often z_p(H)>=4 along the moving candidate line p=3H+1-j.

# 6. Complete candidate-window classification below the four-zero threshold

For z_p(H)<=3, the degree-three numerator content is a p-unit. Its reduction after content removal is a nonzero polynomial of degree at most three that vanishes at every prefix zero.

Combine this with Q867's exact degree-one classification.

## z_p(H)=0

```plain text
p not|content(P_(H,1)),
p not|content(P_(H,3)).
```

A common prime is pure projective-root pollution:

```plain text
P_(H,1)(j)=P_(H,3)(j)=0,
A_j !=0.
```

It is forced into K_H(n) by Theorem 4.1.

## z_p(H)=1

Let the unique zero node be r. Q867 gives

```plain text
P_(H,1)(n)=0  (mod p)
iff j=r.
```

Therefore there is no good-prime pollution from this class. If the degree-one numerator vanishes, the prime is already the target.

## z_p(H)=2

The degree-one numerator is divisible by p through its content. The degree-three projective numerator vanishes at the two genuine zero nodes and has at most one additional interpolation-node root. Thus a good common prime can occur only if the moving node is that one extra root.

## z_p(H)=3

Again the degree-one numerator is content-divisible. The degree-three projective numerator has the three genuine zero nodes as all of its interpolation-node roots. Hence it has no extra interpolation-node root. Therefore

```plain text
j notin Z_p(H)
 => p not|P_(H,3)(j),
```

provided the degree-three reduction has exact degree three. In the canonical normal family this is the generic and expected case. If its degree drops modulo p, the statement weakens to the general theorem that the number of extra roots is at most 3-z_p(H)=0; so the conclusion still holds.

Thus the only nonautomatic good-prime pollution below four zeros comes from

```plain text
z_p(H)=0
```

or from the single extra root available when

```plain text
z_p(H)=2.
```

The exact decomposition is therefore

```plain text
E_H = E_H^(0) E_H^(2) E_H^(>=4),              (6.1)
```

where the factors are pairwise coprime squarefree products according to the three cases, and every factor divides rad(K_H(n)).

This is a useful sharpening: the troublesome z=3 class is eliminated completely by choosing degree three rather than degree two.

# 7. The linear determinant does not yet have sublinear height

From (2.2), evaluated at n,

```plain text
K_H(n)
 = [P_(H,1)(n)Q_(H,3)(n)
    -P_(H,3)(n)Q_(H,1)(n)] / Phi_H(n).        (7.1)
```

The denominator is explicit:

```plain text
Phi_H(3H+1)
 = product_(r=2H+1)^(3H+1) r
 = (H+1)! binom(3H+1,H+1).                   (7.2)
```

Hence

```plain text
log Phi_H(3H+1)=H log H+O(H).                 (7.3)
```

But the primitive Padé coefficients and values contain the lattice-index/content factors audited in Q850 and the later all-degree theorem. The available determinant estimates give only

```plain text
log|P_(H,a)(n)|,
log|Q_(H,a)(n)|
```

of at least linear and in raw determinant normalizations often superlinear size. Subtracting the explicit H log H+O(H) denominator in (7.1) does not yield

```plain text
log|K_H(n)|=o(H).
```

The only unconditional support consequence is

```plain text
log E_H <= log rad(K_H(n)) <= log|K_H(n)|,     (7.4)
```

which is presently ineffective for the target asymptotic.

There is no valid argument that a linear polynomial value must have small radical: its coefficients depend on H and can themselves carry an exponentially large candidate-window radical. The word “linear” refers to the variable x, not to coefficient height.

The adjacent Plücker relation also explains why no hidden small coefficient appears automatically. Let

```plain text
W_(1,2)=Phi_H kappa_1,
W_(2,3)=Phi_H kappa_2.
```

Then the exact determinant identity gives

```plain text
P_(H,2) K_H
 = kappa_2 P_(H,1)+kappa_1 P_(H,3),           (7.5)

Q_(H,2) K_H
 = kappa_2 Q_(H,1)+kappa_1 Q_(H,3).           (7.6)
```

These identities are proved by expanding both sides and cancelling the middle terms. They show that the linear pollution determinant is generated by the two adjacent constants after saturation by the middle Padé pair. They do not bound its height or radical; at primes where P_(H,2) also vanishes, (7.5) is tautological.

Thus the nonadjacent choice is genuinely more selective at the support level, but its coefficient height is not automatically smaller than the adjacent constants.

```plain text
 => p|content(P_(H,1))
```

# 9. Growing-degree alternative and its exact saturation point

The proved zero-count bound permits a numerator degree

```plain text
A_H=O(H^(2/3))                              (9.1)
```

large enough that, for every candidate prime p<=3H+1,

```plain text
z_p(H)<=A_H.                                  (9.2)
```

One may take an explicit uniform value from the block bound. For any integer L>=2,

```plain text
z_p(H)
 <= ceil(p/L)+(3/2)(L-1)(L-2)+1
 <= ceil((3H+1)/L)+(3/2)(L-1)(L-2)+1.
```

Choosing

```plain text
L=floor(H^(1/3))+1
```

gives an explicit A_H=O(H^(2/3)) valid for the whole candidate window.

Let

```plain text
Z_(H,A_H)=P_(H,A_H)/content(P_(H,A_H)).
```

Because z_p(H)<=A_H, the candidate prime does not divide the removed numerator content, and every target node is a root of Z_(H,A_H) modulo p. Hence the integral polynomial

```plain text
R_H^tail := Z_(H,A_H)                          (9.3)
```

is another valid target certificate.

This removes automatic content pollution from the second certificate. But the determinant with degree one now has

```plain text
deg K_(1,A_H)<=A_H-2=O(H^(2/3)).              (9.4)
```

The good-prime radical is again supported on

```plain text
K_(1,A_H)(n),
```

and no o(H) height or candidate-window radical bound is known. The latest generic interpolation/Fitting audit proves that no theorem based only on integer interpolation, Smith data, or generic resultants can supply such a bound: a CRT countermodel can retain the full candidate primorial. Any positive estimate must use the Apéry recurrence in the normalized projective coefficients.

Thus the route has an exact dichotomy:

```plain text
small fixed degree:
  low-degree determinant,
  unavoidable high-zero content pollution;

growing degree above the zero threshold:
  no content pollution,
  growing-degree projective resultant with no known height saving.
```

# 10. Strongest proof-grade conclusion and next lemma

The degree-three certificate gives the clean theorem

```plain text
rad_(2H<p<=3H+1)
 gcd(P_(H,1)(3H+1),P_(H,3)(3H+1),binom(3H+1,H+1))

 = T_H E_H,

E_H=E_H^(0)E_H^(2)E_H^(>=4),

E_H | rad(K_H(3H+1)),

deg K_H<=1,

E_H^(>=4)
 = product_({candidate p :
             #Z_p(H)>=4,
             3H+1-p notin Z_p(H)})p.          (10.1)
```

The equality in the last line is the automatic-content part of the pollution; E_H^(0) and E_H^(2) are the remaining projective extra-root parts.

A sufficient theorem is therefore:

```plain text
Second-certificate lemma.

For K_H defined by

  P_(H,1)Q_(H,3)-P_(H,3)Q_(H,1)=Phi_H K_H,

one has

  log rad_(2H<p<=3H+1)(K_H(3H+1))=o(H).
                                                        (SC3)
```

(SC3) immediately gives

```plain text
log G_H=log T_H+o(H).
```

It does not by itself prove log T_H=o(H); the target core is intentionally retained. To solve the original q=1 target through two certificates, one still needs a second certificate whose common radical is itself o(H), or an independent estimate for T_H.

The weakest useful decomposition is instead the pair of Apéry-specific lemmas

```plain text
(V4)
  sum_({candidate p : #Z_p(H)>=4,
                       moving node is good}) log p=o(H),

(XR3)
  the candidate-window radical contributed by
  z_p(H)=0 or 2 extra projective roots of P_(H,3)
  has logarithmic weight o(H).                 (10.2)
```

Together, (V4)+(XR3) prove

```plain text
log E_H=o(H).
```

At present neither follows from the recurrence, Lucas congruences, the zero-count bound, or total-height estimates.

The next concrete lemma should attack (V4), because it is forced into every fixed-degree certificate and is independent of coefficient-height normalization:

```plain text
Candidate four-zero lemma.

sum_({2H<p<=3H+1 :
      p prime,
      # {0<=s<=H:p|A_s} >=4}) log p=o(H).       (10.3)
```

A stronger but cleaner recurrence formulation is a fourth factorial-moment bound for prefix zero counts along the candidate window. Once (10.3) is available, the degree-three determinant leaves only the two explicitly described extra-root classes and becomes the sharpest low-degree second-certificate route.

# Final assessment

An unconditional q=1 proof is not obtained. The degree-three numerator is nevertheless the correct second certificate:

- it is the first genuinely independent nonadjacent direction;

- its determinant quotient is exactly linear;

- every target prime divides both values;

- every good common prime divides that one linear value;

- the all-degree content theorem identifies the exact automatic obstruction as the four-prefix-zero candidate set;

- degree two merely recovers Q802, while higher fixed degrees exchange a higher zero threshold for a higher-degree determinant;

- growing degrees eliminate content pollution but re-enter the unresolved growing-family resultant problem.

This is the sharp proof-grade reduction presently available from the special a=1 formula and the latest primitive-content theorem.
