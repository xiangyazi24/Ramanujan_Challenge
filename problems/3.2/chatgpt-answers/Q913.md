# Factorial moments for Apéry prefix-zero counts

## Verdict

Let

```plain text
A_m = sum_r binom(m,r)^2 binom(m+r,r)^2,
n = 3H+1,
Z_p(H) = {0<=s<=H : p|A_s},
z_p(H) = |Z_p(H)|,
```

for primes 2H<p<=3H+1. Using only the exact second-order Apéry recurrence, its cleared transfer matrices, and the gap continuants, one can prove a fully explicit family of factorial-moment bounds. The strongest consequence is not the ordinary fixed-order Markov estimate. It is an adaptive short-gap second-moment estimate:

```plain text
For 8<=B<=H and
L = ceil(4(H+1)/B),

sum_{2H<p<=3H+1, z_p(H)>B} log p
 <= 25 H(H+1)^2 [log 118 + 6 log(H+1)] / B^3.
```

Thus

```plain text
sum_{z_p(H)>B} log p
 << H^3 log H / B^3.
```

The same bound holds after restricting to target-conditioned primes

```plain text
p | A_(3H+1-p).
```

At the available Padé scale

```plain text
B = C H^(2/3),
```

the bound is only

```plain text
O_C(H log H),
```

not o(H). It becomes o(H) only when

```plain text
B^3 / (H^2 log H) -> infinity,
```

for example

```plain text
B = H^(2/3) (log H)^(1/3+epsilon),
```

which is larger than the currently available O(H^(2/3)) Padé degree scale.

Higher fixed factorial moments and growing-order moments are rigorously worse. The pair estimate is optimal within the entire method that multiplies individual gap continuants and bounds them by absolute height. The missing ingredient is therefore not another choice of r. It is one Apéry-specific compressed short-gap carrier whose logarithmic height is o(H^(5/3)) while retaining one p-adic unit of multiplicity for every short zero pair. A precise statement appears in Section 10.


and the existing continuant/Casoratian framework. No numerical asymptotic is inferred from finite data.

# 1. Cleared recurrence and transfer determinant

Write

```plain text
P(m) = 34m^3+51m^2+27m+5.
```

The Apéry recurrence is

```plain text
(m+1)^3 A_(m+1) - P(m) A_m + m^3 A_(m-1) = 0.
```

Clear the factorial denominators by

```plain text
X_m = (m!)^3 A_m.
```

Then

```plain text
X_(m+1) = P(m) X_m - m^6 X_(m-1).                 (1.1)
```

Equivalently,

```plain text
[ X_(m+1) ]   [ P(m)  -m^6 ] [ X_m     ]
[ X_m     ] = [ 1       0   ] [ X_(m-1) ].         (1.2)
```

The transfer determinant is

```plain text
det T_m = m^6.                                      (1.3)
```

For every candidate prime p>2H, all factorials and all integers 1,...,H are p-adic units. Therefore

```plain text
p|A_s  iff  p|X_s,   0<=s<=H.                      (1.4)
```

Also two consecutive zeros are impossible. If

```plain text
X_s = X_(s+1) = 0 mod p,
```

then repeated use of the invertible transfer matrices modulo p forces

```plain text
X_0 = X_1 = 0 mod p,
```

contradicting X_0=A_0=1.

# 2. Exact gap continuants

For h>=1, define

```plain text
N_1(s)=1,
N_2(s)=P(s+1),

N_(h+1)(s)
 = P(s+h) N_h(s) - (s+h)^6 N_(h-1)(s).             (2.1)
```

Induction in the recurrence gives

```plain text
X_(s+h)
 = N_h(s) X_(s+1)
   - (s+1)^6 N_(h-1)(s+1) X_s.                     (2.2)
```

The first exact cases are

```plain text
N_1(s)=1,

N_2(s)=P(s+1),

N_3(s)=P(s+2)P(s+1)-(s+2)^6,

N_4(s)=P(s+3)P(s+2)P(s+1)
       -P(s+3)(s+2)^6
       -(s+3)^6P(s+1).                              (2.3)
```

If 0<=s<s+h<=H and both endpoints are zero modulo a candidate prime, then X_(s+1) is a unit modulo p, because consecutive zeros are impossible. Equation (2.2) therefore gives the exact pair certificate

```plain text
p|A_s and p|A_(s+h)
  => p|N_h(s).                                      (2.4)
```

The same statement follows from the corresponding two-by-two Casoratian minor.

# 3. Explicit height of one continuant

For 0<=s<s+h<=H,

```plain text
P(s+h) <= 117(H+1)^3,
(s+h)^6 <= (H+1)^6.
```

Set

```plain text
U_H = 118(H+1)^6,
Lambda_H = log U_H
         = log 118 + 6 log(H+1).                    (3.1)
```

The recurrence (2.1) gives inductively

```plain text
0<|N_h(s)| <= U_H^(h-1),
log|N_h(s)| <= (h-1)Lambda_H.                       (3.2)
```

Only the upper bound is used below. It records the factorial-height trap explicitly: one gap of length h costs O(h log H) in logarithmic height.

The degree ledger is also exact. As a polynomial in s,

```plain text
deg_s N_h = 3(h-1).                                (3.3)
```

Its leading coefficients c_h satisfy

```plain text
c_1=1,
c_2=34,
c_(h+1)=34c_h-c_(h-1).                            (3.4)
```

Thus the polynomial degree itself already grows linearly with the gap.

# 4. Gap-resolved pair moment

For a candidate prime define

```plain text
C_p(h)
 = #{0<=s<=H-h : s,s+h in Z_p(H)}.                 (4.1)
```

For fixed h, every occurrence counted by C_p(h) contributes one factor p to

```plain text
prod_(s=0)^(H-h) N_h(s).
```

Hence

```plain text
sum_(2H<p<=3H+1) C_p(h) log p
 <= sum_(s=0)^(H-h) log|N_h(s)|
 <= (H-h+1)(h-1)Lambda_H.                          (4.2)
```

Summing over gaps shorter than L gives

```plain text
W_2(H,L)
 := sum_p sum_(1<=h<L) C_p(h) log p

 <= Lambda_H
    sum_(h=2)^(L-1) (H-h+1)(h-1)

 <= (1/2) H L^2 Lambda_H.                           (4.3)
```

This is the strongest direct second factorial-moment inequality from the individual gap continuants.

For the unrestricted second factorial moment,

```plain text
M_2(H)
 = sum_p (z_p(H))_2 log p
 = 2 sum_p sum_(h=1)^H C_p(h) log p,
```

so (4.2) yields

```plain text
M_2(H)
 <= 2 Lambda_H
    sum_(h=2)^H (H-h+1)(h-1)

 = H(H-1)(H+1) Lambda_H / 3.                        (4.4)
```

In particular,

```plain text
M_2(H) << H^3 log H.                                (4.5)
```

# 5. All fixed factorial moments

Let

```plain text
M_r(H)
 = sum_(2H<p<=3H+1) (z_p(H))_r log p.              (5.1)
```

Take an r-element zero set

```plain text
s_1<...<s_r.
```

For each consecutive gap, (2.4) gives

```plain text
p | N_(s_(i+1)-s_i)(s_i),
1<=i<r.
```

Therefore

```plain text
p^(r-1)
 | prod_(i=1)^(r-1)
     N_(s_(i+1)-s_i)(s_i).                          (5.2)
```

After multiplying over all zero r-subsets and counting how often a fixed pair can occur as consecutive members, one obtains

```plain text
M_r(H)
 <= [r!/(r-1)] binom(H-1,r-2)
    sum_(0<=s<t<=H) log|N_(t-s)(s)|.                (5.3)
```

Using (3.2),

```plain text
sum_(0<=s<t<=H) log|N_(t-s)(s)|
 <= Lambda_H
    sum_(h=2)^H (H-h+1)(h-1)

 = H(H-1)(H+1)Lambda_H / 6.                         (5.4)
```

Thus, for every fixed r>=2,

```plain text
M_r(H)
 <= [r!/(6(r-1))]
    binom(H-1,r-2)
    H(H-1)(H+1)Lambda_H.                            (5.5)
```

Hence

```plain text
M_r(H) <<_r H^(r+1) log H.                          (5.6)
```

For r=1, the elementary carrier p|A_s gives

```plain text
M_1(H)
 <= sum_(s=0)^H log A_s
 <= [H(H+1)/2] log(17+12sqrt(2)),                   (5.7)
```

using the positive moment bound A_s<=(17+12sqrt(2))^s.

# 6. Ordinary Markov optimization fails

For every r>=1,

```plain text
sum_(z_p(H)>B) log p
 <= M_r(H)/(B+1)_r.                                 (6.1)
```

For fixed r>=2, (5.6) gives

```plain text
sum_(z_p(H)>B) log p
 <<_r H^(r+1) log H / B^r.                          (6.2)
```

At

```plain text
B = H^(2/3),
```

this is

```plain text
<<_r H^(1+r/3) log H.                               (6.3)
```

The exponent increases with r. The fixed-order optimum is r=1, which only gives O(H^(4/3)); among genuine multi-zero moments, r=2 gives O(H^(5/3)log H).

Letting r grow cannot help. Formula (5.5) contains both

```plain text
binom(H-1,r-2)
```

and the factorial factor r!/(r-1). For B<=H^(2/3), the ratio of the r+1 estimate to the r estimate is bounded below, up to absolute constants, by

```plain text
H/B >= H^(1/3).                                     (6.4)
```

Thus every increase in moment order worsens the bound by at least a power of H.

# 7. Adaptive short-gap pair bound

The ordinary moment wastes information because a large zero set must create many short gaps. Partition [0,H] into

```plain text
q = ceil((H+1)/L)
```

consecutive blocks of length at most L. If a prime has z=z_p(H) zeros, and z_i zeros fall in block i, then the number of zero pairs at distance <L is at least

```plain text
sum_i binom(z_i,2)
 >= (z^2/q-z)/2.                                    (7.1)
```

Assume

```plain text
8<=B<=H,
L=ceil(4(H+1)/B).                                   (7.2)
```

Then

```plain text
q<=B/2.
```

Whenever z>B, equation (7.1) gives at least B/2 short zero pairs. Therefore

```plain text
(B/2)
 sum_(z_p(H)>B) log p
 <= W_2(H,L).                                       (7.3)
```

Combining with (4.3),

```plain text
sum_(z_p(H)>B) log p
 <= H L^2 Lambda_H / B.                             (7.4)
```

Since B<=H implies

```plain text
L<=5(H+1)/B,
```

we obtain the explicit theorem

```plain text
sum_(2H<p<=3H+1, z_p(H)>B) log p
 <= 25 H(H+1)^2
    [log 118+6log(H+1)] / B^3.                     (7.5)
```

This is strictly stronger than every ordinary fixed factorial-moment estimate at the relevant scale.

# 8. Target-conditioned primes

Define

```plain text
T(H,B)
 = sum_{
     2H<p<=3H+1,
     p|A_(3H+1-p),
     z_p(H)>B
   } log p.                                         (8.1)
```

Since this is a subfamily of the primes in (7.5),

```plain text
T(H,B)
 <= 25 H(H+1)^2
    [log 118+6log(H+1)] / B^3.                     (8.2)
```

Retaining the marked zero does not improve the exponent through the available continuant identities. Indeed, write

```plain text
j=3H+1-p.
```

Each additional zero s yields the marked pair certificate

```plain text
p | N_|s-j|(min(s,j)).                              (8.3)
```

But a marked zero may be isolated while the remaining zeros cluster elsewhere. The only unconditional consequence of z_p(H)>B is the existence of many short pairs somewhere in the zero set, not many short pairs incident to j. Passing to a marked resultant therefore loses exactly the short-gap multiplicity that makes (7.5) possible.

The crude marked factorial moments satisfy

```plain text
sum_target (z_p(H)-1)_r log p
 <= (H+1)_(r+1) log(3H+1),                          (8.4)
```

which is weaker than (7.5) after Markov optimization. No extra p-adic digit follows from reflection; the first reflected factor is the same forced factor already encoded by the marked zero.

# 9. Sharp optimization at the Padé scale

Put

```plain text
B=C H^(2/3),
C>0 fixed.
```

Then (7.5) gives

```plain text
sum_(z_p(H)>B) log p
 <= [25/C^3 + o(1)]
    H [log 118+6log H].                             (9.1)
```

Thus the continuant method proves only

```plain text
O_C(H log H).                                       (9.2)
```

It reaches o(H) precisely under

```plain text
B^3 / [H^2 log H] -> infinity.                     (9.3)
```

For example,

```plain text
B=H^(2/3)(log H)^(1/3+epsilon)
```

works, while

```plain text
B=O(H^(2/3))
```

does not.

Higher adaptive factorial moments do not repair this. If one counts r zeros in one block of length L, the continuant product has height

```plain text
O_r(H L^r log H),                                  (9.4)
```

while z>B forces only Omega_r(B) such local r-clusters when L is chosen at its minimum scale L asymp rH/B. The resulting tail estimate is

```plain text
O_r(H^(r+1) log H / B^(r+1)).                       (9.5)
```

At B=H^(2/3), this equals

```plain text
O_r(H^((r+1)/3) log H),                             (9.6)
```

which is minimized at r=2. Growing r is still worse.

This is the sharp no-go for all factorial-moment arguments obtained by multiplying individual gap continuants and paying their absolute factorial height.

# 10. Smallest Apéry-specific compression lemma that would change the result

Let

```plain text
L_H = ceil(4 H^(1/3)).                              (10.1)
```

For a candidate prime define the short-pair count

```plain text
c_p(H)
 = #{0<=s<t<=H : t-s<L_H,
                     p|A_s,
                     p|A_t}.                        (10.2)
```

The naive carrier is

```plain text
C_H^naive
 = prod_(1<=h<L_H)
   prod_(0<=s<=H-h) N_h(s).                         (10.3)
```

It has

```plain text
v_p(C_H^naive) >= c_p(H),                           (10.4)
```

but only the height bound

```plain text
log|C_H^naive|
 = O(H L_H^2 log H)
 = O(H^(5/3) log H).                                (10.5)
```

The exact missing statement is:

```plain text
Short-gap Apéry compression lemma.

There exists a nonzero integer C_H, constructed from the
second-order Apéry recurrence, such that for every prime
2H<p<=3H+1,

    v_p(C_H) >= c_p(H),

and

    log|C_H| = o(H^(5/3)).                           (10.6)
```

This lemma would immediately imply the desired weighted tail estimate at the available degree scale. Indeed, if

```plain text
B=ceil(H^(2/3)),
```

then every prime with z_p(H)>B has

```plain text
c_p(H) >= B/2,
```

so

```plain text
sum_(z_p(H)>B) log p
 <= 2 log|C_H|/B
 = o(H).                                            (10.7)
```

The target-conditioned version may weaken (10.6) by requiring the valuation inequality only for primes satisfying

```plain text
p|A_(3H+1-p).
```

That is the smallest theorem exposed by the factorial-moment audit. It must compress many gap continuants jointly; a product, ordinary resultant, or pairwise Casoratian cannot meet the height threshold.

# 11. Final theorem

The strongest unconditional continuant moment theorem is:

```plain text
Theorem.
Let H>=8 and 8<=B<=H. For

    Z_p(H)={0<=s<=H:p|A_s},
    z_p(H)=|Z_p(H)|,

one has

    sum_{2H<p<=3H+1, z_p(H)>B} log p
    <= 25 H(H+1)^2
       [log 118+6log(H+1)] / B^3.

The same bound holds after imposing

    p|A_(3H+1-p).
```

Consequently, the exact second-order recurrence and all factorial moments formed from its individual gap continuants do not yet remove the growing-family pollution at degree O(H^(2/3)). They miss by one logarithmic factor in the strongest adaptive second-moment argument. The short-gap Apéry compression lemma (10.6), or any equivalent construction producing superlinear p-adic multiplicity at sub-naive height, is the minimal remaining advance.
