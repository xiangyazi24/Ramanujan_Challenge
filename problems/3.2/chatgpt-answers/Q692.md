# 12. Reproducible exact verification

The following Sage code verifies the coefficient formula, the universal determinant division, and retention of every bad prime.

```python
from sage.all import ZZ, binomial, matrix, prime_range, prod


def franel(k):
    return ZZ(sum(binomial(k, a)^3 for a in range(k + 1)))


def apery(k):
    return ZZ(sum(binomial(k, a)^2 * binomial(k + a, a)^2
                  for a in range(k + 1)))


def L(n, k):
    if k < 0 or k > n:
        return ZZ(0)
    return ZZ(binomial(n, k) * binomial(n + k, k))


def coeff_vector(n, J):
    F = [franel(k) for k in range(n + 1)]
    C = [ZZ(0)] * (n + 1)
    C[0] = sum(L(n, i) * F[i] for i in range(J + 1))

    for d in range(1, n + 1):
        lo = max(0, J - d + 1)
        hi = min(J, n - d)
        C[d] = sum(
            (-1)^(J - i)
            * L(n, i + d)
            * binomial(i + d, i)
            * binomial(d - 1, J - i)
            * F[i]
            for i in range(lo, hi + 1)
        )
    return C


def folded_index(n, p):
    return min(n - p, 2*p - 1 - n)


def candidate_primes(n, J):
    return [p for p in prime_range(n // 2 + 1, n + 1)
            if folded_index(n, p) <= J]


def candidate_primorial(n, J):
    return prod(candidate_primes(n, J), ZZ(1))


def check_pair(n, A, B):
    CA = coeff_vector(n, A)
    CB = coeff_vector(n, B)

    Delta = CA[0] * CB[1] - CA[1] * CB[0]
    P = candidate_primorial(n, A)
    assert Delta % P == 0

    Q = Delta // P
    for p in candidate_primes(n, B):
        j = folded_index(n, p)
        if apery(j) % p == 0:
            assert Q % p == 0
    return Delta, P, Q


def check_general_minor(n, cutoffs, degrees):
    assert len(cutoffs) == len(degrees)
    rows = [coeff_vector(n, J) for J in cutoffs]
    M = matrix(ZZ, [[row[d] for d in degrees] for row in rows])
    Delta = M.det()

    U = prod((candidate_primorial(n, J)
              for J in cutoffs[:-1]), ZZ(1))
    assert Delta % U == 0

    Q = Delta // U
    for p in candidate_primes(n, cutoffs[-1]):
        j = folded_index(n, p)
        if apery(j) % p == 0:
            assert Q % p == 0
    return Delta, U, Q


for n in range(20, 120):
    Jstar = (n - 1) // 3
    if Jstar >= 2:
        check_pair(n, 0, Jstar)
        check_pair(n, Jstar // 2, Jstar)

print("multiscale determinant divisibility: PASS")
```

The code verifies divisibility, not an Archimedean saving. The height calculation in Sections 7–9 is what rules out the raw fixed-order implementation.

# Final conclusion

The multiscale determinant idea has a clean exact algebraic form, but its two hoped-for gains do not occur simultaneously.

- Exact universal saturation is available.

- A bad prime survives saturation.

- The selective excess is only one power, independent of the number of rows.

- Natural fixed-order coefficient minors have a positive linear height floor equal to the entropy of the largest cutoff.

- Multiscale repetition reproduces the trivial 1/2 prime-interval bound, with branchwise constants 1/3 and 1/6.

The Franel tail lattice opens a narrower, genuinely new possibility: degree-growing signed functionals whose branch-purified normalized determinants have subexponential geometric mean. Proving (MS), rather than another raw determinant bound, is the weakest surviving lemma for this route.
