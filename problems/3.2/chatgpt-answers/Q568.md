## 5.1 G-function denominator theorems

The seven generating functions

A concrete countermodel is the central-binomial algebraic G-function

whose coefficients contain all primes in substantial linear intervals. Algebraicity and excellent denominator control do not imply sparse numerator support.

Reference: S. Fischler and T. Rivoal, On the denominators of the Taylor coefficients of G-functions, Kyushu J. Math. 71 (2017), 287–298.

## 5.2 Schmidt's Subspace Theorem

The gcd theorems of Corvaja–Zannier, Levin, Grieve–Wang, and Xiao apply to power sums, linear recurrences, or evaluations of fixed polynomials at S-unit points. Their load-bearing input is a finite set of algebraic exponential bases.

The section S_s(m) is P-recursive with polynomially varying coefficients; it is not a constant-coefficient linear recurrence or a finite power sum. The factorial ratio B_s(m) is hypergeometric, not an S-unit orbit. Replacing the exact sequences by their dominant asymptotic bases does not satisfy the hypotheses.

Relevant references:

- P. Corvaja and U. Zannier, Finiteness of integral values for the ratio of two linear recurrences, Invent. Math. 149 (2002), 431–451;

- N. Grieve and J. T.-Y. Wang, Greatest common divisors with moving targets and consequences for linear recurrence sequences;

- Z. Xiao, Greatest common divisors for polynomials in almost units and applications to linear recurrence sequences, Math. Z. 306 (2024), article 61.

None of these theorems has hypotheses covering the pair (S_s(m),B_s(m)).

## 5.3 p-adic analytic continuation

Strassmann-type arguments count zeros of one fixed p-adic analytic function in one fixed residue characteristic. Here:

- the prime p is the summation variable;

- only one index is sampled for each p;

- the selected index is j=n-3p or its reflection;

- the local identity is exactly S_n\equiv A_j\pmod p.

A p-adic interpolation of the section sequence would therefore restate the original zero condition. It would not couple the different primes.

## 5.4 Arithmetic resultants and same-index norms

An annihilating differential or recurrence operator acts on a whole sequence. A common prime divisor of two values at one index is not a common solution of the two operators. Therefore an operator resultant does not yield a scalar integer divisible by the pointwise gcd.

Likewise, a norm argument requires S_s(m) and B_s(m) to be coordinates of a fixed algebraic extension or algebraic group orbit. No such finite-degree algebraic relation is known. D-finiteness alone does not supply a norm.

# 8. Reproducible checks

The valuation correction can be checked without constructing the Apéry numbers:

```python
from math import comb
from sympy import primerange

def interval_valuation(n, p):
    K = (n + 4) // 7
    B = comb(n, K) * comb(n + K, K)
    v = 0
    while B % p == 0:
        B //= p
        v += 1
    r = n - 3*p
    predicted = int(r < K) + int(p - r <= K)
    return v, predicted

for n in range(20, 500):
    for p in primerange(n//4 + 1, n//3 + 1):
        v, predicted = interval_valuation(n, p)
        assert v == predicted
        if v == 2:
            assert n % 7 == 3
            assert 7*p == 2*n + 1
```
