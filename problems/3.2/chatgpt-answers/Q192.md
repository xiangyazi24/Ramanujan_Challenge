# Collision energy of Gauss-sum and hypergeometric values

Search date: 21 July 2026

## Executive verdict

There is no unconditional theorem of the form

```plain text
bounded-complexity multiplicative/hypergeometric trace function
    => collision energy E(p) << p^(1+epsilon).
```

In that generality the assertion is false, even for rank-one Kummer trace functions and even for a product of only two Gauss sums. Bounded conductor, a bounded number of Gauss factors, or hypergeometric monodromy does not play the role of polynomial degree for level sets.

The clean positive statements are much narrower:

1. For a bounded-degree algebraic map f : F_p -> F_p, every fibre has size at most deg f, hence E(f) <= (deg f)p.

1. If all additive twists

1. For a raw, single Gauss-sum monomial whose total Stickelberger valuation has nonzero slope in the character exponent, Gross–Koblitz gives O(1) exact algebraic fibres, hence raw collision energy O(p).

1. The previous item normally does not apply after the unit normalization/reduction needed to obtain an F_p-valued hypergeometric quantity. That normalization removes exactly the valuation coordinate that distinguished the characters. Balanced products include explicit examples with energy asymptotic to p^2/2 or p^2.

Katz, Rojas-León, Kazhdan–Polishchuk, and Forey–Fresán–Kowalski prove deep equidistribution and classify universal multiplicative relations among complex normalized Gauss/Mellin values. Those results are not fibre bounds, do not give O(p^epsilon) characters per exact value, and do not survive automatically after reduction modulo the same prime p.

For the Apéry function H(r)=b_r mod p, the useful black-box target remains

```plain text
sum_{t != 0} |sum_{r=0}^{p-1} e_p(t b_r)|^2 << p^(2+epsilon),
```

or, more strongly, |sum_r e_p(t b_r)| << p^(1/2+epsilon/2) for every t != 0. I found no existing theorem that supplies this merely from a Gauss-sum or Gamma_p representation of the coefficients.

# 1. Four categories that must not be conflated

The phrase “bounded-complexity hypergeometric trace function” can refer to four mathematically different objects.

This distinction is load-bearing for Apéry coefficients. Deligne's theory controls traces of Frobenius and linear sums of those traces. It does not say that applying the nonlinear map

```plain text
z |-> e_p(z mod p)
```

to a p-adic unit-root value produces another bounded-conductor ℓ-adic trace function.

Likewise, a coefficient sequence of a degree-~p hypergeometric/Hasse polynomial is not automatically a bounded-conductor trace function in the coefficient index r. The underlying family may have bounded geometric complexity while the map

```plain text
r |-> coefficient number r
```

has complexity growing with p.

# 2. The polynomial comparison: the correct bound is dp, not p+O(1)

Let f in F_p[X] be nonconstant of degree d<p, and put

```plain text
N_f(a) := #{x in F_p : f(x)=a},
E(f)   := sum_a N_f(a)^2.
```

Since N_f(a) <= d,

```plain text
E(f) <= d sum_a N_f(a) = dp.                         (2.1)
```

The assertion E(f)=p+O(1) is false for general bounded-degree polynomials. For f(x)=x^2,

```plain text
E(f)=2p-1.
```

Geometrically,

```plain text
E(f) = #{(x,y) in F_p^2 : f(x)-f(y)=0}.
```

The diagonal contributes p; each additional F_p-defined component of

```plain text
(f(X)-f(Y))/(X-Y)=0
```

can contribute another p+O_d(sqrt p) by Weil–Deligne. Thus the leading constant records the algebraic correspondences preserving f, rather than always being 1.

For a bounded-degree rational map, the same direct fibre argument gives E=O_d(p) away from its bounded set of poles.

The relevant general source for square-root estimates on bounded-complexity sheaves is Deligne, “La conjecture de Weil II,” Publ. Math. IHÉS 52 (1980), 137–252. Uniform bookkeeping of sheaf complexity under the six operations is developed by Sawin–Forey–Fresán–Kowalski, “Quantitative sheaf theory,” JAMS 36 (2023), 653–726.

# 3. The exact Fourier criterion for collision energy

For any H : F_p -> F_p, define

```plain text
S_t(H) := sum_{r in F_p} e_p(t H(r)),
e_p(x) := exp(2 pi i x/p).
```

Orthogonality gives the exact identity

```plain text
1_{H(r)=H(s)} = (1/p) sum_{t in F_p} e_p(t(H(r)-H(s))),
```

hence

```plain text
E(H)
 = (1/p) sum_{t in F_p} |S_t(H)|^2
 = p + (1/p) sum_{t != 0} |S_t(H)|^2.                (3.1)
```

Consequences:

```plain text
|S_t(H)| <= C sqrt(p) for every t != 0
    => E(H) <= (1+C^2)p.                              (3.2)
```

More generally,

```plain text
|S_t(H)| << p^(1/2+eta)
    => E(H) << p^(1+2eta),                            (3.3)
```

and the desired p^(1+epsilon) follows from the mean-square statement

```plain text
sum_{t != 0} |S_t(H)|^2 << p^(2+epsilon).             (3.4)
```

This is the right replacement for “degree” when direct fibre control is unavailable.

## When Deligne supplies (3.2)

If H=f(r) is a bounded-degree rational function and t f is not Artin–Schreier-degenerate, then

```plain text
r |-> e_p(t f(r))
```

is the trace of the pullback of an Artin–Schreier sheaf of bounded conductor. Deligne gives O_f(sqrt p), and (3.2) follows.

## Why this does not follow for an arbitrary trace function

If H(r)=t_F(r) is itself the numerical trace of an ℓ-adic sheaf, there is no general sheaf operation whose trace is

```plain text
e_p(t * t_F(r)).
```

The six-functor formalism is linear/tensorial in trace functions; “put the trace value into another additive character” is a nonlinear operation on the numerical trace. Thus bounded conductor of F does not imply bounded conductor—or even sheaf-theoretic origin—of e_p(tH).

This is exactly the missing bridge in the Apéry application.

# 4. General bounded-complexity multiplicative functions can have energy ~p^2

## 4.1 Rank-one Kummer counterexample

Let eta be a fixed-order multiplicative character of order d, extended by eta(0)=0, and regard its roots of unity inside F_p when d | p-1. This is a rank-one Kummer trace function of bounded conductor. Each nonzero value has exactly (p-1)/d preimages, so

```plain text
E(eta)
 = 1 + d ((p-1)/d)^2
 = 1 + (p-1)^2/d
 ~ p^2/d.                                             (4.1)
```

For the quadratic character, E~p^2/2.

Thus bounded sheaf conductor does not imply even E=o(p^2).

## 4.2 A product of two Gauss sums

Let chi run through the nontrivial characters of F_p^*. The elementary conjugation identity is

```plain text
G(chi) G(chi_bar) = chi(-1) p.                        (4.2)
```

It is displayed as equation (1) in the introduction of Antonio Rojas-León, “Equidistribution and independence of Gauss sums,” Adv. Math. 450 (2024), 109762, arXiv:2207.12439.

Therefore the normalized two-factor product

```plain text
H(chi) := G(chi)G(chi_bar)/p = chi(-1)
```

takes only the two values +1 and -1. Among the p-2 nontrivial characters the fibre sizes are (p-3)/2 and (p-1)/2, so

```plain text
E(H)
 = ((p-3)/2)^2 + ((p-1)/2)^2
 = (p^2-4p+5)/2.                                     (4.3)
```

If one also divides by chi(-1), the normalized product is identically 1, and its energy is (p-2)^2.

This directly refutes the proposed theorem for “a product of O(1) Gauss sums.” The Hasse–Davenport product formula supplies many further bounded-complexity collapses.

## 4.3 What extra hypotheses would be needed

At minimum one must exclude:

- finite-image Kummer factors;

- conjugate Gauss-pair cancellations;

- Frobenius/Galois invariance;

- Hasse–Davenport relations;

- constant or finite-order objects in the Mellin-convolution category.

Even after excluding all universal relations, no published theorem located in this search bounds every exact fibre by p^epsilon. Universal relation-freeness and accidental level-set multiplicity are different questions.

# 5. A genuine positive result: the Stickelberger-slope criterion for raw Gauss monomials

There is one useful unconditional “multiplicative degree” statement, but it applies before unit normalization and before reduction modulo p.

Let omega be the Teichmüller character and choose pi with

```plain text
pi^(p-1) = -p.
```

For 0 <= j <= p-2, Gross–Koblitz gives, up to the standard choice of additive-character convention,

```plain text
G(omega_bar^j)
 = - pi^j Gamma_p(j/(p-1)).                           (5.1)
```

Since Gamma_p is a p-adic unit,

```plain text
v_pi(G(omega_bar^j)) = j.                             (5.2)
```

The source is Gross–Koblitz, “Gauss sums and the p-adic Gamma-function,” Ann. of Math. 109 (1979), 569–581.

## Proposition 5.1 — raw nonzero-slope monomials have bounded fibres

Fix integers a_i,e_i and fixed-complexity shifts b_i(p) for 1<=i<=s. Put

```plain text
j_i(r) := least residue of a_i r+b_i(p) modulo p-1 in [0,p-2],
F_p(r) := c_p product_i G(omega_bar^(j_i(r)))^(e_i),  0<=r<=p-2,
```

excluding the O_s(1) values where a conventionally excluded trivial-character factor occurs. Assume c_p is independent of r, and define the total slope

```plain text
A := sum_i e_i a_i.                                   (5.3)
```

Then, if A != 0, every exact algebraic value of F_p(r) is assumed only O_C(1) times, where C depends on the fixed data but not on p. Consequently the raw exact-value energy is O_C(p).

### Proof

By (5.2),

```plain text
V(r) := v_pi(F_p(r))
      = v_pi(c_p) + sum_i e_i j_i(r).                 (5.4)
```

As r runs through [0,p-2], each sawtooth function j_i(r) has O(|a_i|+1) linear pieces. Their common refinement has

```plain text
O(1+sum_i |a_i|)
```

intervals. On every such interval,

```plain text
V(r) = A r + C_I.                                     (5.5)
```

If A!=0, a prescribed valuation occurs at most once on each interval. Equality F_p(r)=y forces V(r)=v_pi(y), so the fibre of y has bounded size. Summing the squares of the fibres gives O_C(p).

### Scope of the proposition

This is the sharp place where Stickelberger really acts like a degree. It proves, for example, that the raw single Gauss sums G(omega_bar^r) are injective under a fixed p-adic embedding: their valuations are 0,1,...,p-2.

But the proposition does not answer the Apéry question, for three reasons:

1. It treats one monomial, not a sum of several monomials with possible cancellation.

1. It treats exact values in the cyclotomic/p-adic field, not their reduction to F_p.

1. Hypergeometric and Jacobi expressions are commonly balanced, so A=0.

If A=0, (5.5) is constant on each interval and the valuation gives no separation. Equation (4.2) is the basic example.

# 6. Why normalization destroys the Stickelberger coordinate

An F_p-valued nonzero quantity must be a p-adic unit before reduction. If the raw product has valuation V(r), one forms a normalized unit

```plain text
U_p(r) := pi^(-V(r)) F_p(r)
        = product_i Gamma_p(j_i(r)/(p-1))^(e_i)
          times an r-independent unit.                (6.1)
```

The valuation is now identically zero. The coordinate that made Proposition 5.1 work has been deliberately removed.

Worse, reducing an unnormalized varying-valuation product modulo pi sends every positive-valuation value to 0, creating a huge zero fibre. Thus one cannot retain the slope and simultaneously obtain the desired F_p-valued map by naive reduction.

Stickelberger's leading congruence makes the residual difficulty concrete. With standard conventions,

```plain text
G(omega_bar^j)/pi^j = -1/j! mod pi                   (6.2)
```

(up to the harmless convention-dependent sign). Therefore even the one-factor normalized unit contains the value-distribution problem for

```plain text
j! mod p.
```

That problem is not known to have bounded fibres. Grebennikov–Sagdeev–Semchankau–Vasilevskii prove that

```plain text
1!,2!,..., (p-1)! mod p
```

assume at least

```plain text
(sqrt(2)+o(1)) sqrt(p)
```

distinct values; see “On the sequence n! mod p,” Rev. Mat. Iberoam. 40 (2024), 637–648, arXiv:2204.01153. They also obtain (1+o(1))sqrt p distinct values on intervals of length >p^(7/8+epsilon).

These are strong image-size results, but they neither give O(p^epsilon) maximum fibres nor an energy upper bound p^(1+epsilon). In a targeted search I found no published collision-energy theorem of that strength for the factorial sequence itself.

This is strong evidence that normalized Gamma_p products do not have an off-the-shelf bounded-fibre theorem.

# 7. What Katz/Rojas-León equidistribution does—and does not—give

## 7.1 Independent complex equidistribution

Katz proves in Gauss Sums, Kloosterman Sums, and Monodromy Groups, Chapter 9, Theorem 9.5 independent equidistribution of tuples of shifted normalized Gauss sums. Rojas-León substantially generalizes this.

Rojas-León's Theorem 1 considers monomials in several variable characters. Under an explicit linear-independence condition on the associated character divisors, the tuples of normalized Gauss sums become Haar-equidistributed on a product of unit circles as the extension degree grows. His Theorem 2 says that universal monomial relations are generated by:

- conjugation G(chi)G(chi_bar)=chi(-1)q;

- Frobenius/Galois invariance;

- Hasse–Davenport products.

Kazhdan–Polishchuk give the underlying divisor viewpoint in “Fourier transform over finite field and identities between Gauss sums,” Selecta Math. 9 (2003), 63–100: monomial identities correspond to linear relations among divisors on character space.

Katz's general Mellin-transform framework is Convolution and Equidistribution: Sato–Tate Theorems for Finite-Field Mellin Transforms. The main equidistribution theorem is Theorem 7.2 and is stated in the extension-field aspect. Forey–Fresán–Kowalski generalize the tannakian Fourier/Mellin framework to connected commutative algebraic groups in “Arithmetic Fourier transforms over finite fields: generic vanishing, convolution, and equidistribution,” arXiv:2109.11961v6, accepted for Astérisque.

## 7.2 A qualitative consequence for exact complex values

Suppose empirical measures of complex values

```plain text
mu_N := (1/N) sum_chi delta_{F(chi)}
```

converge weakly to a non-atomic measure. Then the largest exact complex fibre is o(N): otherwise a subsequence would retain an atom of fixed positive mass. Consequently

```plain text
E_complex(F)=o(N^2).                                  (7.1)
```

That is the most one can infer abstractly from atomless equidistribution.

It is far weaker than N^(1+epsilon). Equidistribution controls continuous test functions or fixed moments; exact equality is a microscopic, discontinuous condition. To reach N^(1+epsilon) one would need effective discrepancy at the scale of the minimum separation between algebraic values, together with quantitative height/separation estimates. The cited theorems do not state such a result.

## 7.3 Why complex equidistribution does not control reduction mod p

Distinct cyclotomic or p-adic algebraic values may reduce to the same element of F_p. Macroscopic Haar distribution under a complex embedding gives no bound on that collapse. This is especially severe for normalized Gauss products, whose residue is a factorial/Gamma_p expression.

Therefore neither Katz's nor Rojas-León's equidistribution theorem implies an upper bound for

```plain text
#{(chi,chi') : H(chi)=H(chi') in F_p}.
```

## 7.4 Relation classification is not a fibre theorem

Rojas-León's Theorem 2 and Kazhdan–Polishchuk classify identities that hold uniformly over a character family. A large fibre at one prime is an “accidental” collection of equalities

```plain text
F_p(chi)=c
```

for many individual characters. It need not come from a universal monomial identity. I found no theorem in these sources converting relation-freeness into O(p^epsilon) level sets.

# 8. Why Manin–Mumford rigidity does not apply

The character group is cyclic, and one can write chi=omega^(-r). This tempts one to regard all characters as torsion points of a torus and apply torsion-point rigidity.

That analogy would be valid if there were a fixed bounded-degree rational map

```plain text
R : G_m -> A^1
```

such that F(chi)=R(zeta) for the corresponding torsion point zeta. Then the equation

```plain text
R(x)=R(y)
```

would be a fixed bounded-degree algebraic curve and direct degree arguments—not even Manin–Mumford—would control fibres.

A Gauss sum as a function of the twisting character is not such a map:

- its definition depends on the finite field and additive character;

- its natural home is an arithmetic Mellin transform;

- the order of the character group is p-1 and grows with p;

- any polynomial interpolation in omega^(-r) generally has degree comparable to p;

- after Gross–Koblitz normalization, the residue contains factorial-scale variation.

Manin–Mumford concerns torsion points on a fixed subvariety of a fixed semiabelian variety. Here the function and its equality locus vary with p and do not have known bounded algebraic degree. I found no applicable Manin–Mumford or “Gauss-sum distinctness” theorem giving near-injectivity on the whole character group.

# 9. Direct answers to the three questions

## (1) Does bounded multiplicative/hypergeometric complexity imply E(p)<<p^(1+epsilon)?

No. The statement is false in general.

- A fixed-order Kummer trace function has energy ~p^2/d.

- The two-Gauss-sum product G(chi)G(chi_bar)/p=chi(-1) has energy ~p^2/2.

- Bounded conductor controls linear trace sums, not nonlinear exact level sets.

What replaces polynomial degree is one of two additional structures:

1. Algebraic-map structure: H(r) is a bounded-degree rational function. Then fibres are bounded directly and E=O(p).

1. Additive-twist structure: every e_p(tH(r)) is itself a bounded-conductor trace function with no geometrically trivial component. Then Deligne plus (3.1) gives E=O(p).

A Gauss-product formula for H does not by itself provide either structure.

## (2) Is the character-variable hypergeometric value nearly injective by rigidity?

No general result found, and it is false without strong exclusions.

- Raw single Gauss sums are injective under a fixed p-adic embedding because Gross–Koblitz gives distinct valuations.

- Raw monomials with nonzero total Stickelberger slope have O(1) exact algebraic fibres by Proposition 5.1.

- Balanced products can have fibres of size ~p/2 or p.

- Unit-normalized/reduced values lose the valuation invariant.

- Katz/Rojas-León give equidistribution and relation classification, not microscopic fibre bounds.

- Manin–Mumford does not apply because the Gauss/Mellin transform is not a fixed bounded-degree algebraic map on the torsion torus.

## (3) Is #{chi:H(chi)=c}=O(p^epsilon) known for a fixed product of Gauss sums?

Not in the stated generality; it is explicitly false. Equation (4.2) gives a two-factor counterexample.

A correct conditional version is:

```plain text
raw monomial + nonzero total Stickelberger slope
    => max fibre O_C(1)
    => raw energy O_C(p).                              (9.1)
```

For a balanced raw product, a unit-normalized product, a Gamma_p unit product, or a finite sum of Gauss monomials, Stickelberger valuations do not give such a bound. I found no published theorem asserting O(p^epsilon) fibres in that regime.

# 10. What to audit in the exact Apéry formula

Before attempting to import any hypergeometric theorem, write the formula in the following normalized form.

## 10.1 Product or sum?

Determine whether

```plain text
H(r)=one Gauss monomial
```

or

```plain text
H(r)=sum of J=O(1) Gauss monomials.
```

Proposition 5.1 applies only to the first. For a sum, equal minimal valuations can cancel, and no generic bounded-fibre conclusion follows.

## 10.2 Compute the total Stickelberger slope

For each factor write

```plain text
j_i(r)=<a_i r+b_i>_(p-1)
```

and compute

```plain text
A=sum_i e_i a_i.
```

- If A!=0 and equality is taken for raw algebraic values, the fibre problem is solved by Proposition 5.1.

- If A=0, the valuation method is silent.

- If an r-dependent power of pi is divided out before reduction, the valuation method is also silent even when the raw slope was nonzero.

## 10.3 Remove all forced Gauss identities

Use conjugation, Frobenius invariance, and Hasse–Davenport to simplify the product. Rojas-León's Theorem 2 says these generate universal monomial relations in his setting. Any remaining finite-image factor must be identified explicitly.

## 10.4 Identify the actual target field

Ask whether equality is in:

- the cyclotomic field;

- a fixed p-adic embedding;

- the residue field after unit normalization;

- F_p after a further trace/norm.

The answer changes completely across these cases.

## 10.5 Try to construct the additive-twist sheaf

The decisive question is not “is H hypergeometric?” but:

For each t!=0, can r |-> e_p(tH(r)) be realized as a uniformly bounded-conductor trace function?

If yes, Deligne gives the desired energy immediately. If not, classical hypergeometric monodromy does not close the problem.

For H(r)=b_r mod p, all current evidence points to the latter situation: the coefficient/unit-root object is not a bounded-degree algebraic map in r, and no standard sheaf operation produces the additive exponential of its reduced coefficient value.

# 12. Practical conclusion for the Apéry project

The proposed shortcut

```plain text
bounded hypergeometric complexity
    -> nearly injective in the twisting character
    -> E(p)<<p^(1+epsilon)
```

is not available and is false as a general principle.

The one unconditional route worth testing immediately is the raw Stickelberger-slope audit. It may collapse part of the formula or prove bounded fibres for an unnormalized factor. But if the Apéry value is a balanced unit product—or, more likely, a sum/coefficient extracted from such objects—the audit will certify why Stickelberger cannot finish.

After that audit, the genuine target is (3.4): mean-square cancellation of the additive twists of b_r. This is a new horizontal/nonlinear trace problem, not a routine consequence of finite hypergeometric monodromy.
