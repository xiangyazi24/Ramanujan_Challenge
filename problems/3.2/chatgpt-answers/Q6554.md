# 1. 口径锁定

令轨道指标集长度为 N。题面使用 0,...,p-2，所以 N=p-1；论文节有时使用 1,...,p-2，所以 N=p-2。以下只用 N=p+O(1)，但每条不等式对任意有限序列都精确成立。

对任意颜色序列

```plain text
x_0, x_1, ..., x_(N-1)
```

定义非回绕返回：

```plain text
d_D(r) = #{ h : 1 <= h <= D, r+h < N, x_(r+h)=x_r }
S_D    = sum_r d_D(r)
       = sum_(1<=h<=D) R_h
Q_D    = sum_r binom(d_D(r),2)
P_D    = #{ r : d_D(r) > 0 }
E      = sum_v m_v^2.
```

这里 m_v 是颜色 v 的全局重数。必须强调：本证明所需的 Q_D 是这个完整、非回绕的轨道量。若实际程序只统计删去某些退化层后的 Q_D^reg，必须另证被删项可吸收；第 7 节给出精确条件。

# 2. 被漏看的关键不等式：Q 单独如何控制窗口总数

## 2.1 最短证明：support + repeat excess

对每个非负整数 d，有

```plain text
d <= 1_(d>0) + binom(d,2).
```

逐点检查：

```plain text
d=0: 0 <= 0
d=1: 1 <= 1
d=2: 2 <= 1+1
d>=3: d-1 <= d(d-1)/2.
```

求和得到精确的 P/Q 分解上界：

```plain text
S_D = P_D + sum_r (d_D(r)-1)_+
    <= P_D + Q_D
    <= N + Q_D.                                      (2.1)
```

因此

```plain text
Q_D <= C*N   ==>   S_D <= (1+C)*N.                  (2.2)
```

这已经完整回答“Q 不看 singleton 怎么够”的问题：它确实不看 singleton，但 singleton base point 最多只有 N 个。

## 2.2 Q6526 原文使用的 Cauchy 证明

还有一个对大 Q_D 更好的版本：

```plain text
sum_r d_D(r)^2 = S_D + 2*Q_D.
```

Cauchy 给

```plain text
S_D^2 <= N * (S_D + 2*Q_D).                         (2.3)
```

解正根：

```plain text
S_D <= (N + sqrt(N^2 + 8*N*Q_D))/2.                (2.4)
```

特别地，若 Q_D <= C*N，则

```plain text
S_D <= ((1 + sqrt(1+8C))/2) * N.                   (2.5)
```

这就是 Q6526 第 2 节被 display stripping 掩盖的步骤，也是仓库 prop:oe-sigma-machine 中的同一行。

## 2.3 用户反驳中真正失效的一句

你方写道 singleton 质量可以达到 Delta^2。这在 subcritical 区间可以成立，但在本靶使用的 supercritical 区间不成立：

```plain text
P_D <= number of base points = N.
```

当

```plain text
D = sqrt(N)*L,    L>1,
```

有

```plain text
D^2 = N*L^2 > N.
```

所以“两两不交的 singleton root sets”最多装满 N 个 base point；超过 N 的逐层次数质量必然产生重复 base point，而那些重复恰由 Q_D 计数。

# 3. 块分解逐行重建

把 0,...,N-1 分成

```plain text
B = ceil(N/D)
```

个连续块，每块长度至多 D。令 m_(v,j) 是颜色 v 在第 j 块的重数。

对每个 v，Cauchy 给

```plain text
m_v^2 = (sum_j m_(v,j))^2
      <= B * sum_j m_(v,j)^2.
```

对 v 求和：

```plain text
E <= B * sum_(v,j) m_(v,j)^2.                       (3.1)
```

块内能量展开为

```plain text
sum_(v,j) m_(v,j)^2
  = N + 2 * W_D,                                    (3.2)
```

其中 W_D 是同块内无序同色对数。每个同块对的正 gap 小于 D，所以

```plain text
W_D <= S_D.                                         (3.3)
```

于是得到任意颜色序列都成立的确定性块不等式：

```plain text
E <= ceil(N/D) * (N + 2*S_D).                       (3.4)
```

插入 (2.1)：

```plain text
E <= ceil(N/D) * (3*N + 2*Q_D).                    (3.5)
```

若 Q_D <= C*N，则

```plain text
E <= (3+2C) * (N^2/D + N).                          (3.6)
```

取

```plain text
D = floor(sqrt(N)*L),
1 << L <= c*sqrt(N),
```

得到

```plain text
E << N^(3/2)/L + N.                                 (3.7)
```

这正是 Q6526 的结论。+N 来自 ceil(N/D) <= N/D+1。

没有任何跨块相消。整个证明只用了：

```plain text
integer outdegrees
+ support <= N
+ Cauchy across blocks
+ positivity.
```

# 4. 对所有可能推导路径的逐一判定

## 路径 A：只用逐 gap 次数界

已知每层 R_h << h，所以

```plain text
S_D << D^2.
```

插入 (3.4)：

```plain text
E << N^2/D + N*D.                                   (4.1)
```

在 D=sqrt(N)*L 时：

```plain text
E << N^(3/2)/L + N^(3/2)*L.                         (4.2)
```

判定：正确，但没有使用 Q 假设，因此不能反驳 Q6526。

正确做法是使用联合上界

```plain text
S_D <= min( c*D^2,
            N+Q_D,
            (N+sqrt(N^2+8NQ_D))/2 ).                (4.3)
```

在 supercritical 区间且 Q_D<<N 时，第二或第三项远优于次数项。

## 路径 B：P/Q 分解

使用 (2.1) 后接 (3.4)。

判定：有效，且是最短证明。

## 路径 C：Q6526 原始 Cauchy 路径

使用 (2.3)--(2.5) 后接 (3.4)。

判定：有效；这就是原推导。

## 路径 D：逐块局部 wedge 计数

在每块中把返回关系看成有向图；d_D(r) 是出度，Q_D 是同一顶点发出的两条边组成的 wedge 数。逐块有

```plain text
number of edges <= number of active vertices + number of wedges.
```

对块求和后仍得到

```plain text
W_D <= N + Q_D.
```

再用 (3.1)。

判定：有效，但只是路径 B 的图论重述。

## 路径 E：随机平移或 Fejer 加权块

对所有块起点平移取平均，gap h<D 的同色对以权重约 1-h/D 被收入同块。得到的是一个 Fejer 加权版本的 S_D。

判定：有效，但不产生额外幂次相消；仍需 (2.1) 或 (2.3)。

## 路径 F：假设存在跨块相消

E、块能量和 Q_D 全是非负量；上述证明没有带符号对象。

判定：不存在，也不需要。 若另造 Fourier/Fejer 带符号证明，那是不同路线，不是 Q6526 的推导。

## 路径 G：由 Q_D<<N 推出 E<<N

判定：错误。 第 5 节给出达到 N^2/D 的精确反模型。Q6526 只声称 N^2/D+N，没有过度结论。

## 路径 H：在 D<=sqrt(N) 用 Q_D<<N 破 3/2

由 (3.6)，

```plain text

```

判定：错误。 supercritical 条件是载重条件，不是装饰。

# 5. 一个精确 sharpness 模型

令 N=B*D，定义

```plain text
x_n = n mod D,    0 <= n < N.
```

也就是每个长度 D 的块都按同样顺序出现 D 个颜色。

则：

```plain text
每个颜色出现 B 次；
同色相邻出现的 gap 恰为 D；
对 r < N-D，有 d_D(r)=1；
对最后一块，有 d_D(r)=0；
Q_D=0；
S_D=N-D；
E=D*B^2=N^2/D.
```

所以即使 Q_D=0，能量仍可达到

```plain text
E = N^2/D.
```

在 D=sqrt(N)*L 时正是

```plain text
E = N^(3/2)/L.
```

这证明三件事：

1. Q6526 的尺度基本最优。

1. Q_D 单独不可能推出 E=O(N)。

1. singleton 支撑可以达到 N，但不能达到 supercritical 的 D^2=N*L^2。

最小机器核对：

```python
from math import comb

B, D = 7, 11
N = B * D
x = [n % D for n in range(N)]

d = []
for r in range(N):
    d.append(sum(1 for h in range(1, D + 1)
                 if r + h < N and x[r+h] == x[r]))

Q = sum(comb(a, 2) for a in d)
S = sum(d)
mult = [B] * D
E = sum(a*a for a in mult)

assert Q == 0
assert S == N - D
assert E == N*N // D
```


确实是该块证明的最小直接接口。

## 6.2 原 Q6526 的 pair 版本

定义：同一尺度上

```plain text
Q_D << N.                                            [MESO-PAIR]
```

或保留原名

```plain text
Q_D << N.                                            [MESO-QRLL]
```

```plain text
[MESO-PAIR]  ==>  [MESO-TOTAL]  ==>  (6.1).          (6.2)
```


则


因此，要得到“任何严格 little-o 改进”，真正最弱的重复返回条件不是 Q_D<<N，而是

在某个 supercritical 尺度成立。

若目标是 Q6526 的具体 1/L 增益，则干净条件 Q_D<<N 正好够用。

所以该路线不仅能给对数节省；若能把 Q 界推进到多项式 supercritical 尺度，就直接给固定幂节省。

# 7. 它与 P^first 墙究竟是什么关系

精确恒等关系是

```plain text
S_D = P_D + repeat_excess,
repeat_excess = sum_r (d_D(r)-1)_+ <= Q_D.           (7.1)
```

## subcritical: P-wall 真正载重

若 D<=sqrt(N)，则逐层次数总和 D^2<=N。完全可能有

```plain text
Q_D=0,
P_D=S_D about D^2.
```

这就是仓库 Q6515 的 disjoint-singleton 反模型。此时 Q 工具原则上看不到主项，P-wall 无法绕过。

## critical: 只能重现 3/2

若 D about sqrt(N)，则

```plain text
P_D<=N about D^2.
```

即使 Q_D<<N，也只得到 S_D<<N，插块后仍是 E<<N^(3/2)。

## supercritical: P-wall 被环境大小自动支付

若 D=sqrt(N)*L，则

```plain text
P_D <= N = D^2/L^2.
```

singleton 项已经免费满足 [MESO-TOTAL] 所需尺度；只需控制 repeat excess，而它正由 Q 覆盖。

因此：

- [MESO-TOTAL] 确实“包含 singleton”。

- 但它不是 P_D<<D，也不是完整的 H^2 -> H 首返回定理。

- 它允许 P_D 饱和到 N。

- 它只是在 supercritical 窗口要求 S_D<<N，比随机真值 S_D about 1.44D 弱得多。

所以“最短接口”不必撤回；应改写为“利用 D=sqrt(N) 处的环境容量相变而绕开 P-wall 的最短 one-scale 接口”。

# 9. 与 T3-2MINUS 的关系

令

```plain text
T3 = sum_v m_v*(m_v-1)*(m_v-2).
```

仓库 AR.1 的初等插值引理可独立重推如下。若

```plain text
T3 <= N^tau,    1 <= tau < 2,
```

取阈值

```plain text
M0 = N^((tau-1)/2).
```

小纤维贡献：

```plain text
sum_(m_v<=M0) m_v^2 <= M0*N.
```

大纤维使用

```plain text
m^3 = (m)_3 + 3*m^2 - 2*m
```

并在 M0>=6 时吸收 3/M0，得到

```plain text
sum_(m_v>M0) m_v^2 << T3/M0.
```

两项平衡：

```plain text
E << N^((1+tau)/2).                                 (9.1)
```

所以

```plain text
T3 << N^(2-delta)
   ==> E << N^(3/2-delta/2).                         [T3-2MINUS]
```

这条链成立，仓库已由 Q6530/Q6532 双源验证。

它与 [MESO-PAIR] 不可互推：

- Q_D 只数 span 至多 D 的三点簇；长 span 三元组不进入它。

- 全局 T3 控制所有三元组。

- 精确地，Q_D <= T3/6，但 T3<<N^(2-delta) 一般不够推出 Q_D<<N。

- 反向上，一个尺度的 Q_D<<N 完全不限制 span 大于 D 的 T3。

因此二者是两个不同的“破 3/2”接口：一个是 one-scale local triple count，一个是 global third factorial moment。

# 11. 对三问的直接回答

## (1) Q6526 是否存在隐藏跨块相消或别的分解？

不存在跨块相消。原链成立，靠的是：

```plain text
Q_D controls repeat excess;
singleton support <= N;
therefore S_D<=N+Q_D;
then block Cauchy.
```

Q6526 原文使用了等价的 S_D^2<=N(S_D+2Q_D)。你方复推遗漏了这一行。

## (2) 最小陈述是否应改成 S_D<<N？它是否就是 P-wall 本体？

对该块证明，S_D<<N 是逻辑最小的干净直接版本，应命名 [MESO-TOTAL]。但原 Q_D<<N 自动推出它，所以原第四靶不需撤回。

它不是完整 P-wall 本体：它允许 P_D 达到 N，而 P-wall 的强版本要求接近随机尺度 P_D<<D*polylog. 超临界窗口使 P_D<=N 已经足够。

## (3) 若第四靶撤回，最短接口是否回到 T3-2MINUS？

前提不成立：第四靶无需撤回。

若因为证明可行性而主动放弃 MESO，则 [T3-2MINUS] 确实是下一条最干净的 global interface；与此同时 [BLOCK-SUBQUAD] 是另一条不可比的 direct small-gap interface。仓库 AR.2 把两者都列为 3/2 内部的显式最小缺口，这个排序应保留。

# 12. 实施时必须加的三个防错条件

1. 非回绕口径。 块证明使用 r+h<N。若有循环 FFT 版本，证明一个循环上界可推出非回绕上界；但不能把“删掉 wrap 后的残差 Q”不加说明地代入。

1. 完整 Q 或可吸收的删项。 若镜像强制返回被删去，每个 base point 至多删一个返回。写 d=d_reg+e, e in {0,1}，则

```plain text
Q_full = Q_reg + sum_r e(r)*d_reg(r)
       <= Q_reg + S_reg
       <= N + 2*Q_reg.
```

所以 Q_reg<<N 仍够。若删去的退化层允许每个 base point 有无界多个返回，则必须另证上界。

1. L 的范围。 必须有

```plain text
1 << L << sqrt(N)
```

或至少 D<=N。固定幂版要求 0<eta<1/2。

# 13. 最后两问

## (a) 本轮最没把握的一点

组合推导本身我把握很高；它对任意有限颜色序列成立，并有 sharpness 模型。

我最没把握的是项目实际准备证明的 Q_p(Delta) 是否与这里的完整非回绕 Q 完全同口径。如果它是 renewal 里剥离了 mirror、cut edge、apparition-degenerate layers 的 Q^reg，必须逐类做第 12 节的吸收账。mirror 可吸收；任意多重污染不能自动吸收。

第二个不确定点是证明可行性：从 Delta about sqrt(p) 推到 sqrt(p)*L 可能仍需要同一个 quenched family theorem。组合接口较弱，不代表算术证明必然较近。

## (b) 双方共同盲点可能在哪

第一盲点已经被本审计暴露：把逐层根数总和 D^2 与 base-point union 支撑混为一谈，忽略在 D=sqrt(p) 处发生的环境容量相变。

第二盲点是相反方向的过度乐观：即使 MESO reduction 正确，薄的结构化 lag families 仍可能在 supercritical 区制造大 Q_D；均值型 Poisson 数据未必看见高分位异常。下一批数值应直接输出

```plain text
Q_p(D)/p
```

在 D=sqrt(p)*L、多个增长 L 上的 max 和高分位，并按 mirror、small-field splitting、degree-drop、apparition classes 分层，而不只看 H<=128 的均值。
