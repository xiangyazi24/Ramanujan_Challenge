# Mod-p² quotient rows for the Apéry/Franel cutoff array

## Verdict

At the canonical repository commit 710a25d4be1630e5df54c4df2b7b3382fa04d8d6, the proposed escape hatch does not produce a second selective linear condition.

There is an exact coefficientwise mod-p² formula for the ray row

```plain text
T_(q p+r, p-1)(c),
```

and its first quotient is controlled by a two-state Frobenius jet:

```plain text
zeroth state:      A_r mod p,
first state:       an explicit parameter derivative / Lucas-defect polynomial.
```

On a bad fiber, only the zeroth state vanishes. The first state is generally nonzero. Two ray rows therefore recover two first-order quantities; they do not give two vanishing equations.

The sharp constant-coefficient formula is this. Put

```plain text
S_q(p,r) := [c^0] T_(q p+r, p-1)(c),
Acal_p(X) := sum_(m=0)^(p-1) L(X,m) F_m,
Dcal_(p,r) := Acal_p'(r) mod p.
```

Then, for every odd prime p, every 0 <= r < p, and every integer q,

```plain text
S_q(p,r) = A_r + q p Dcal_(p,r)            (mod p^2).
```

If p divides A_r and

```plain text
u_r := A_r/p mod p,
```

then

```plain text
S_q(p,r)/p = u_r + q Dcal_(p,r)            (mod p).
```

Thus the two rows q=1 and q=2 give

```plain text
S_1/p = u_r + Dcal_(p,r),
S_2/p = u_r + 2 Dcal_(p,r)                 (mod p).
```

The determinant of the coefficient matrix is one. These rows measure the two states u_r and Dcal_(p,r); badness imposes neither state to be zero.

The concrete first counterexample is already

```plain text
p=5, r=1, n=6:
[c^0] T_(6,4)  =   1,188,265,
[c^0] T_(11,4) = 159,262,225,

T_(6,4)(0)/5   = 3 mod 5,
T_(11,4)(0)/5  = 0 mod 5,

(T_(11,4)(0)-T_(6,4)(0))/5 = 2 mod 5.
```

So the first ray difference has exactly one factor 5, not 25, even though both rows vanish modulo 5.

The published Gessel–Lucas congruence for the full Apéry sequence has exactly the same two-state form:

```plain text
A_(q p+r)
 = A_r A_q + p q A'_r A_q                 (mod p^2),
0 <= r < p,  p >= 3.
```

At a bad digit,

```plain text
A_(q p+r)/p
 = A_q (A_r/p + q A'_r)                   (mod p).
```

This is an explicit two-state linear p-scheme, not an extra-zero theorem. The strongest concrete obstruction is

```plain text
A_3 = 1445 = 5*17^2,
A'_3 = 4438 = 1 mod 17,

A_20 = 17*5 = 85 mod 17^2,
A_13 = -17 mod 17^2.
```

Thus even when the lower Apéry value is already divisible by 17², the propagated and reflected values have only one factor 17. This rules out a second condition coming from either a second ray or a second cutoff.

A primitive 2-by-2 Hasse boundary does have p² selectivity—the Q777 constant minor remains valid—but that p² is the ordinary exterior-square product of two p-divisible rows. The mod-p² quotient formula supplies no additional factor and no height cancellation. Its logarithmic height is known only to be O(n); no o(n) estimate follows.

So the sharp conclusion is:

```plain text
linear ray/WZ boundary:
    one selective p;

first finite difference:
    one universal p, quotient = derivative state;

second finite difference:
    universal p^2, hence no selectivity after saturation;

2-by-2 Hasse determinant:
    selective p^2, but exterior degree = 2;
    no proved o(2n) height;

unit-root/Dwork method:
    valid on the ordinary locus where the Hasse state is a unit;
    at A_r=0 it exposes a derivative state rather than forcing it to vanish.
```

No unconditional solution of Problem 3.2 is claimed.

# 2. Definitions

Use

```plain text
F_m := sum_a binom(m,a)^3,
L(N,k) := binom(N,k) binom(N+k,k),
Q_N(t) := sum_k L(N,k)t^k,
```

and

```plain text
g_m(c)
 := sum_(i=0)^m binom(m,i)(-c)^(m-i)F_i,

K_(N,m)(c)
 := [y^m] Q_N(c+y)
  = sum_(k=m)^N L(N,k)binom(k,m)c^(k-m),

T_(N,J)(c)
 := sum_(m=0)^J K_(N,m)(c)g_m(c).
```

For the cutoff J=p-1, interchange the m and k sums. Define

```plain text
B_p(k;c)
 := sum_(m=0)^min(k,p-1)
      binom(k,m)c^(k-m)g_m(c).
```

Then

```plain text
T_(N,p-1)(c)
 = sum_(k=0)^N L(N,k) B_p(k;c).
```

Write

```plain text
N=q p+r,
k=a p+b,
0 <= r,b < p.
```

Lucas gives the two principal reductions

```plain text
L(q p+r,a p+b)
 = L(q,a)L(r,b)                            (mod p),

B_p(a p+b;c)
 = c^(a p)F_b                              (mod p).
```

The second identity is ordinary binomial inversion:

```plain text
sum_(m=0)^b binom(b,m)c^(b-m)g_m(c)=F_b.
```

# 3. Exact coefficientwise first-defect formula

Define the integral first Lucas defects

```plain text
lambda_(q,r;a,b)
 := [L(q p+r,a p+b)-L(q,a)L(r,b)]/p,
```

and, coefficientwise in Z[c],

```plain text
mu_(a,b)(c)
 := [B_p(a p+b;c)-c^(a p)F_b]/p.
```

Both quotients are integral because their numerators vanish modulo p.

Let the double sum below range over

```plain text
0 <= a <= q,
0 <= b < p,
a p+b <= q p+r.
```

Then the exact expansion modulo p² is

```plain text
T_(q p+r,p-1)(c)
 = A_r Q_q(c^p) + p E_(q,r,p)(c)           (mod p^2),
```

where

```plain text
E_(q,r,p)(c)
 := sum_(a,b) {
      lambda_(q,r;a,b)c^(a p)F_b
      + L(q,a)L(r,b)mu_(a,b)(c)
    }                                      (mod p).
```

## Proof

Insert

```plain text
L(q p+r,a p+b)
 = L(q,a)L(r,b)+p lambda_(q,r;a,b),
```

and

```plain text
B_p(a p+b;c)
 = c^(a p)F_b+p mu_(a,b)(c)
```

into the double sum for T. The product of the two defect terms is divisible by p². The principal product factors as

```plain text
sum_a L(q,a)c^(a p) * sum_b L(r,b)F_b
 = Q_q(c^p) A_r.
```

This proves the formula.

If p divides A_r, put

```plain text
u_r:=A_r/p mod p.
```

The quotient row is therefore

```plain text
T_(q p+r,p-1)(c)/p
 = u_r Q_q(c^p)+E_(q,r,p)(c)               (mod p).
```

Equivalently, after subtracting the known principal block before division,

```plain text
[T_(q p+r,p-1)(c)-A_rQ_q(c^p)]/p
 = E_(q,r,p)(c)                            (mod p).
```

This last defect exists for good and bad digits. Subtracting the principal block removes the only zeroth-order occurrence of badness; it does not create another selective zero.

# 4. Harmonic formulas for the defects

All harmonic numbers below are interpreted in Z_(p):

```plain text
H_m := sum_(h=1)^m 1/h,
H_0 := 0.
```

## 4.1 No-carry Lucas defect

Assume the ray is in the uniform linear range

```plain text
0 <= q <= (p-1)/2,
0 <= a <= q,
0 <= b <= j:=min(r,p-1-r).
```

Then no low-digit carry occurs in any factorial, and

```plain text
lambda_(q,r;a,b)
 = L(q,a)L(r,b) * Phi_(q,r;a,b)            (mod p),
```

with

```plain text
Phi_(q,r;a,b)
 := (q+a)H_(r+b)
    -(q-a)H_(r-b)
    -2a H_b.
```

Indeed, the two binomial factors have first-order expansions

```plain text
binom(q p+r,a p+b)
 /[binom(q,a)binom(r,b)]
 = 1+p{qH_r-aH_b-(q-a)H_(r-b)}             (mod p^2),
```

and

```plain text
binom((q+a)p+r+b,a p+b)
 /[binom(q+a,a)binom(r+b,b)]
 = 1+p{(q+a)H_(r+b)-aH_b-qH_r}             (mod p^2).
```

Multiplication gives the displayed Phi.

For b>j, the principal Lucas coefficient vanishes. The normalized quantity

```plain text
lambda_(q,r;a,b) mod p
```

is then a first carry residue. It is explicit from the factorial quotient, but it is not controlled by A_j=0; these carry residues are part of the first Frobenius defect.

## 4.2 The binomial-translation defect

For a>=1, Taylor expansion of the polynomial binom(x,m) at x=b gives

```plain text
binom(a p+b,m)
 = binom(b,m)+a p beta_m(b)                 (mod p^2),
```

where

```plain text
beta_0(b)=0,
```

and, for 1 <= m < p,

```plain text
beta_m(b)
 = binom(b,m)(H_b-H_(b-m))
                                  if m <= b,

beta_m(b)
 = (-1)^(m-b-1) / [m binom(m-1,b)]
                                  if b < m < p.
```

Every denominator is a p-adic unit. Consequently

```plain text
mu_(a,b)(c)
 = a sum_(m=0)^(p-1)
       beta_m(b)c^(a p+b-m)g_m(c)           (mod p),
```

while

```plain text
mu_(0,b)(c)=0.
```

This is a fully explicit coefficientwise mod-p² formula. It contains harmonic terms in the no-carry part and normalized simple-root/carry terms beyond the low digit. No unit-root theorem is being assumed.

# 5. The constant coefficient: exact two-state Frobenius jet

At c=0, only k=m survives in the defining sum. Hence

```plain text
S_q(p,r)
 := [c^0]T_(q p+r,p-1)(c)
  = sum_(m=0)^(p-1)L(q p+r,m)F_m.
```

Define the degree-2(p-1) polynomial over Z_(p)

```plain text
Acal_p(X)
 := sum_(m=0)^(p-1)L(X,m)F_m.
```

For the integer r<p, all terms with m>r vanish, so the Strehl–Franel identity gives

```plain text
Acal_p(r)=A_r.
```

Ordinary Taylor expansion at X=r now gives

```plain text
Acal_p(r+q p)
 = Acal_p(r)+q p Acal_p'(r)                 (mod p^2).
```

Therefore

```plain text
S_q(p,r)
 = A_r+q p Dcal_(p,r)                       (mod p^2),

Dcal_(p,r):=Acal_p'(r) mod p.
```

The derivative is explicitly

```plain text
Dcal_(p,r)
 = sum_(m=0)^r
     L(r,m)F_m(H_(r+m)-H_(r-m))

   + sum_(m=r+1)^(p-1)
     (-1)^(m-r-1) F_m binom(r+m,m)
     /[m binom(m-1,r)]                      (mod p).
```

The second sum is load-bearing. Although L(r,m)=0 for m>r, its derivative at the simple zero is usually nonzero.

If p divides A_r, then

```plain text
S_q(p,r)/p
 = u_r+q Dcal_(p,r)                         (mod p),

u_r:=A_r/p mod p.
```

For a reflected digit r=p-1-j, the exact Apéry reflection formula from the repository is

```plain text
A_(p-1-j)
 = A_j-2p W_j                               (mod p^2),
```

where

```plain text
W_j
 := sum_(k=0)^j
      binom(j,k)^2 binom(j+k,k)^2
      (H_(j+k)-H_(j-k)).
```

Thus

```plain text
u_(p-1-j)=u_j-2W_j                          (mod p).
```

So even the scalar state in the quotient row remembers the branch through an independent harmonic correction.

# 6. Exact linear saturation theorem

Let alpha_q be p-integral coefficients, chosen independently of the first-jet values u_r and Dcal_(p,r), and put

```plain text
B := sum_q alpha_q S_q(p,r),
M_0 := sum_q alpha_q,
M_1 := sum_q q alpha_q.
```

Then

```plain text
B
 = A_r M_0+p Dcal_(p,r)M_1                 (mod p^2).
```

On a bad digit,

```plain text
B/p
 = u_r M_0+Dcal_(p,r)M_1                   (mod p).
```

This gives the complete first-jet trichotomy.

```plain text
Case 1: M_0 != 0 mod p.

The boundary distinguishes good from bad at order p,
but a second p requires the extra relation
u_r M_0 + Dcal_(p,r) M_1 = 0.
That relation is not implied by A_r=0 mod p.
```

```plain text
Case 2: M_0 = 0 mod p and M_1 != 0 mod p.

The boundary is divisible by p for every digit, good or bad.
Its quotient is the derivative state Dcal_(p,r)M_1.
A second p means Dcal_(p,r)=0, an independent condition.
```

```plain text
Case 3: M_0 = M_1 = 0 mod p.

The boundary is divisible by p^2 for every digit, good or bad.
The p^2 factor is universal and disappears after saturation.
```

For two rows q=1,2, the moment matrix is

```plain text
[1 1]
[1 2]
```

with determinant one. Thus M_0=M_1=0 has only the trivial coefficient vector modulo p. There is no primitive two-ray linear boundary with selective p² forced solely by badness.

For finite differences, the theorem specializes to

```plain text
Delta S_q
 := S_(q+1)-S_q
  = p Dcal_(p,r)                            (mod p^2),

Delta^2 S_q
  = 0                                       (mod p^2).
```

The first difference has one universal p and a generally nonzero derivative quotient. The second difference has a universal p². Neither provides selective amplification.

This is the precise saturation theorem for the natural cross-ray WZ/finite-difference class. It uses the actual Apéry/Franel coefficient array, not a formal all-bad model.

# 8. Published Gessel–Lucas formula: the same two-state obstruction

Straub’s Theorem 1.3, extending Gessel’s Apéry result, states—with the corrigendum 0 <= r < p—that for p>=3,

```plain text
A_(q p+r)
 = A_r A_q+p q A'_r A_q                  (mod p^2).
```

For the Apéry sequence, the formal derivative is the actual derivative of Zagier’s interpolation and has the harmonic formula

```plain text
A'_r
 = 2 sum_(k=0)^r
     binom(r,k)^2 binom(r+k,k)^2
     (H_(r+k)-H_(r-k)).
```

At a bad digit,

```plain text
A_(q p+r)/p
 = A_q (u_r+q A'_r)                        (mod p).
```

Thus the full Apéry sequence itself is a two-state linear p-scheme modulo p². The second state is a derivative, not another zero.

# 9. Why Dwork/unit-root language does not restore the missing zero

The Dwork congruence in the Franel-tail draft concerns the cutoff parameter J in

```plain text
P_J(x)=CT (1-x Lambda)^J,
```

and has the shape

```plain text
P_(J+m p^a)(x)P_floor(J/p)(x^p)
 = P_J(x)P_(floor(J/p)+m p^(a-1))(x^p)     (mod p^a).
```

Its logarithmic derivative proves integrality of a parameter derivative. It does not give the required coefficientwise mod-p² factorization of

```plain text
T_(q p+r,p-1)(c)
```

in the outer index and cutoff simultaneously.

More conceptually, the unit-root quotient is available on the ordinary locus, where the zeroth Hasse/Frobenius state is a p-adic unit. At a bad digit

```plain text
A_r=0 mod p,
```

that unit line is precisely what degenerates. One cannot divide by A_r and continue the ordinary unit-root formula. The next object is a first Frobenius derivative or extension state—the quantities A'_r, Dcal_(p,r), and the coefficientwise defects E_(q,r,p) above. Dwork theory explains why such states are p-adically coherent; it does not force them to vanish.

This is consistent with the classical formal-Brauer/unit-root literature:

- Stienstra–Beukers, On the Picard–Fuchs Equation and the Formal Brauer Group of Certain Elliptic K3-Surfaces, Math. Ann. 271 (1985), 269–304;

- Paul T. Young, Apéry numbers, Jacobi sums, and special values of generalized p-adic hypergeometric functions, J. Number Theory 41 (1992), 231–255;

- Samol–van Straten, Dwork Congruences and Reflexive Polytopes;

- Mellit–Vlasenko, Dwork’s congruences for the constant terms of powers of a Laurent polynomial.

No cited theorem states that the first Frobenius derivative vanishes when the Hasse state vanishes. The explicit p=5 and p=17 calculations show that such a statement would be false here.

# 10. The primitive 2-by-2 boundary

The order-two constant Hasse minor from Q777 is

```plain text
D_2(n,J)
 := [c^0]T_(n,J-1) * [c^J]T_(n+J,J-1)
    -[c^J]T_(n,J-1) * [c^0]T_(n+J,J-1).
```

At J=p>4, the principal block polynomials are

```plain text
Q_1(z)=1+2z,
Q_2(z)=1+6z+6z^2.
```

Hence, for a good digit,

```plain text
D_2(n,p)=4A_j^2 mod p,
```

which is a p-adic unit. For a bad digit, every row entry is divisible by p, so

```plain text
p^2 divides D_2(n,p).
```

Thus D_2 has genuine p² selectivity.

This does not come from a new mod-p² linear congruence. It is the exterior square of two rows, each having one factor p.

To see the quotient explicitly, write

```plain text
E_q(c):=E_(q,r,p)(c),

e_(q,0):=[c^0]E_q(c),
e_(q,1):=[c^p]E_q(c).
```

On a bad fiber, after division of each row by p, the two coefficient vectors are

```plain text
q=1: (u_r+e_(1,0), 2u_r+e_(1,1)),
q=2: (u_r+e_(2,0), 6u_r+e_(2,1)).
```

Therefore

```plain text
D_2(n,p)/p^2
 = (u_r+e_(1,0))(6u_r+e_(2,1))
   -(2u_r+e_(1,1))(u_r+e_(2,0))            (mod p).
```

The quotient depends on four first-defect residues. It is not forced to vanish and supplies no third factor p. Conversely, it contains no evident global cancellation useful for height.

## Height

The full polynomial Hasse-Wronskian is already closed by Q777’s exact leading coefficient:

```plain text
log H(W_t)
 >= log(4)*(t n+J t(t-1)/2)
    -O(t log(n+tJ)).
```

For the selected constant minor D_2, signed cancellation remains possible, so no comparable lower bound is proved. A completely explicit upper bound follows directly from the finite sums. Since

```plain text
F_m <= 8^m,
```

and

```plain text

 <= 2^N sum_k binom(N,k)20^k
 = 42^N,
```

one obtains

```plain text
|[c^d]T_(N,J)(c)| <= 42^N
```

for every coefficient, and therefore, for J<=n,

```plain text

            <= 2*42^(3n).
```

Thus

```plain text
log |D_2(n,J)| = O(n).
```

This is subquadratic, but it is not o(2n) and gives no saving for Problem 3.2. The mod-p² calculation does not improve this Archimedean estimate.

# 11. Exact no-go and the remaining theorem

The new mod-p² information closes the proposed linear escape hatch:

```plain text
1. The zeroth block state is A_r.
2. The first quotient contains u_r=A_r/p and a derivative/Lucas-defect state.
3. Badness kills only A_r mod p.
4. A first difference isolates the derivative state and is universally p-divisible.
5. A second difference is universally p^2-divisible.
6. Two rows give p^2 only after taking an exterior square.
```

A genuinely new linear p² theorem would have to prove an identity of the following form for explicit p-integral operators L_q:

```plain text
sum_q L_q E_(q,r,p)(c)
 = A_r C_(p,r)(c)                          (mod p),
```

while the principal combination

```plain text
sum_q L_q Q_q(c^p)
```

remains nonzero. The constant-coefficient theorem forces two moment conditions on such an identity, and the p=5 example refutes the natural first-difference candidate. No Dwork, unit-root, reflection, or published supercongruence theorem supplies this identity.

The only surviving concrete order-two target is exactly the selected-minor estimate already isolated by Q777:

```plain text
M=floor(n/2),

C_2(n)
 := lcm_(M<J<=n) gcd(J^2,D_2(n,J)).

Needed:
log C_2(n)=o(n).
```

Because every top-half q=1 bad prime contributes p^2, this estimate would imply the required q=1 logarithmic saving. But it is a new signed moving-minor theorem; it is not a consequence of the mod-p² quotient formula.

The sharpest correct conclusion is therefore:

```plain text
The actual Apéry/Franel Dwork structure produces a rank-two first jet.
It refutes, rather than proves, a second selective linear vanishing.
The order-two determinant survives only as exterior-power amplification,
with the same unresolved moving-minor height problem as in Q777.
```

from math import comb


def franel(m):
    return sum(comb(m, a)**3 for a in range(m + 1))


def Lpoly(X, m):
    # Integer-valued polynomial L(X,m), evaluated at integer X.
    if X < 0:
        raise ValueError
    if m > X:
        return 0
    return comb(X, m) * comb(X + m, m)


def apery(n):
    return sum(comb(n, k)**2 * comb(n + k, k)**2
               for k in range(n + 1))


def cutoff_constant(N, p):
    return sum(Lpoly(N, m) * franel(m) for m in range(p))


def harmonic(n):
    return sum((Fraction(1, k) for k in range(1, n + 1)), Fraction(0))


def truncated_strehl_derivative(p, r):
    ans = Fraction(0)
    for m in range(p):
        if m <= r:
            deriv = Fraction(Lpoly(r, m)) * (harmonic(r + m) - harmonic(r - m))
        else:
            deriv = (Fraction((-1)**(m-r-1), m * comb(m - 1, r))
                     * comb(r + m, m))
        ans += franel(m) * deriv
    assert ans.denominator % p != 0
    return (ans.numerator * pow(ans.denominator, -1, p)) % p


# p=5, r=1 ray counterexample.
p, r = 5, 1
S1 = cutoff_constant(p + r, p)
S2 = cutoff_constant(2*p + r, p)
assert S1 == 1_188_265
assert S2 == 159_262_225
D = truncated_strehl_derivative(p, r)
assert D == 2
assert (S1 // p) % p == (apery(r)//p + D) % p
assert (S2 // p) % p == (apery(r)//p + 2*D) % p
assert ((S2 - S1)//p) % p == 2

# Published Apéry formal derivative at n=3.
Aprime3 = 2 * sum(
    comb(3, k)**2 * comb(3 + k, k)**2
    * (harmonic(3 + k) - harmonic(3 - k))
    for k in range(4)
)
assert Aprime3 == 4438
assert Aprime3 % 17 == 1
assert apery(3) == 1445 == 5*17**2

# Gessel-Lucas consequences modulo 17^2.
assert (apery(3)*apery(1) + 17*Aprime3*apery(1)) % 17**2 == 85
assert (apery(3) - 17*Aprime3) % 17**2 == 272
