# The (q=1) Apéry slice as a horizontal sieve problem

## Verdict

Write

```plain text
alpha_n := sum_{k=0}^n binom(n,k)^2 binom(n+k,k)^2,
f(t)    := sum_{n>=0} alpha_n t^n,
A_p(t)  := sum_{r=0}^{p-1} alpha_r t^r.
```

For (n/2<ple n), put (r=n-p). Gessel–Lucas gives

```plain text
alpha_n ≡ alpha_1 alpha_r = 5 alpha_r  (mod p),
```

so, apart from (p=5),

```plain text
p is q=1-bad  <=>  p | alpha_n  <=>  r=n-p belongs to Z_p.
```

Thus the requested quantity is simply

```plain text
K_1(n) := #{p prime : n/2<p<=n and p|alpha_n}.
```

No known larger-sieve, Frobenius-sieve, or determinant-method argument improves the unconditional pointwise bound

```plain text
K_1(n) <= pi(n)-pi(n/2) = (1/2+o(1)) n/log n.
```

The 2025–26 Caruso–Fürnsinn–Vargas-Montoya–Zudilin theorem does not change this. It is a precise vertical, fixed-characteristic Kummer statement about the whole series (fbmod p). It gives no restriction on the location of a zero coefficient, no auxiliary-modulus residue restriction on the bad primes, and no compatible system to which a Frobenius large sieve can be applied.

The exact missing input is a cross-characteristic Fourier/large-sieve estimate. If

```plain text
Z_p   := {r<p : alpha_r=0 mod p},
U_p(h):= sum_{r in Z_p} exp(-2 pi i h r/p),
```

then Fourier inversion gives

```plain text
K_1(n)
 = sum_{n/2<p<=n} |Z_p|/p
 + sum_{n/2<p<=n} (1/p) sum_{h=1}^{p-1} U_p(h) exp(2 pi i h n/p).   (H)
```

The proved bound (|Z_p|ll p^{2/3}) makes the first term (O(n^{2/3}/log n)). Therefore any uniform estimate

```plain text
sup_n | sum_{n/2<p<=n} (1/p) sum_{h!=0} U_p(h)e_p(hn) |
    << n/(log n)^(1+delta)                              (HLS_delta)
```

for one fixed (delta>0) would prove (K_1(n)=o(n/log n)), and hence the desired weighted (q=1) bound. No available theorem supplies (HLS_delta).

## 1. What the 2025 Galois-group theorem actually says

Caruso, Fürnsinn, Vargas-Montoya and Zudilin start from

```plain text
f ≡ A_p f^p  (mod p),
```

so that, in (mathbf F_p(t,f)),

```plain text
f^(p-1) = A_p(t)^(-1).
```

Their Theorems 1 and 2 state:

```plain text
p ≡ 1,5,7,11  (mod 24):
    Gal(F_p(t,f)/F_p(t)) = (F_p^x)^2,
    A_p(t) = B_p(t)^2;

p ≡ 13,17,19,23 (mod 24):
    Gal(F_p(t,f)/F_p(t)) = F_p^x,
    A_p(t) = (t^2-34t+1) B_p(t)^2.
```

The group therefore has order ((p-1)/2) or (p-1). See Caruso–Fürnsinn–Vargas-Montoya–Zudilin, Galois Groups of Apéry-like Series Modulo Primes, Theorems 1–2, first posted as arXiv:2510.23298.

This is substantial algebraic information, but it concerns the Kummer class of the polynomial as a whole. The Galois action is

```plain text
sigma_c(f)=c f,   c in F_p^x or in the square subgroup.
```

It does not act on the coefficient index (r), and coefficient extraction

```plain text
A_p(t) -> [t^r]A_p(t)
```

is not a Frobenius conjugacy class or a splitting condition at a place (t=a). Function-field Chebotarev can study evaluations and splitting of places of (mathbf F_p(t)); it does not distribute the coefficients of the defining polynomial.

The factorization is likewise insufficient. In the square case,

```plain text
alpha_r = sum_{i+j=r} [t^i]B_p [t^j]B_p,
```

and in the other case it is a fixed three-term linear combination of such convolutions. A convolution coefficient can vanish arbitrarily often. A large Galois group does not serve as a “degree bound” for coefficient fibres.

## 2. A rigorous demonstration that the Galois theorem alone has no horizontal content

The following local models satisfy the same Kummer-group conclusions while having almost all coefficients equal to zero.

Let (e=(p-1)/2).

### Square-subgroup branch

Take

```plain text
B_p(t)=1+t^e,
A_p(t)=B_p(t)^2=1+2t^e+t^(p-1).
```

The polynomial has constant and leading coefficient (1), degree (p-1), and every coefficient of degree (1le rle p-2), except (r=e), is zero.

Let (F_pinmathbf F_p[[t]]) be the unique unit series satisfying

```plain text
F_p=A_p F_p^p.
```

Explicitly,

```plain text
F_p(t)=product_{j>=0} A_p(t^(p^j)),
```

so its coefficients have the exact (p)-Lucas digit-product property. Also

```plain text
F_p^(p-1)=A_p^(-1).
```

Since (B_p) has simple zeros, its class is not a proper power in (mathbf F_p(t)^times); the Kummer class of (B_p^{-2}) has order ((p-1)/2). Hence the generated Galois group is exactly the square subgroup.

For a prescribed fixed (n), the target index is (r=n-p). The exceptional equality (r=e) determines at most one prime (p=(2n+1)/3). Thus this local model has the target coefficient zero for essentially every (pin(n/2,n]).

### Full-group branch

Let

```plain text
Delta(t)=t^2-34t+1,
s=(p-3)/2,
B_p(t)=1+t^s,
A_p(t)=Delta(t)B_p(t)^2.
```

Then (A_p) again has degree (p-1), constant and leading coefficient (1), but only (O(1)) nonzero coefficient positions. Since (Delta) has simple zeros for (pge5), the divisor of (A_p) has a valuation equal to (1) at some place; its Kummer class has order (p-1), giving the full group (mathbf F_p^times).

These examples are not reductions of one fixed rational diagonal. Their role is narrower and decisive:

The exact Galois-group and square-factorization conclusions of the 2025 theorem are compatible with maximal coefficient sparsity and with alignment at one chosen integer. Therefore that theorem alone cannot feed a horizontal sieve.

The fixed-integral-diagonal hypothesis is the only remaining source of cross-prime coherence, and the Galois theorem does not quantify it.

## 3. The fixed rational-diagonal property alone also cannot give a pointwise saving

Straub represents the Apéry numbers as the diagonal coefficients of

```plain text
1 / (((1-x1-x2)(1-x3-x4))-x1 x2 x3 x4).
```

See A. Straub, “Multivariate Apéry numbers and supercongruences of rational functions,” Algebra & Number Theory 8 (2014), 1985–2008.

But no class-level theorem for rational diagonals can yield (o(n/log n)). The central binomial coefficients are the diagonal of (1/(1-x-y)), and for every prime

```plain text
n/2 < p <= 2n/3
```

one has

```plain text
v_p binom(2n,n)=1.
```

Indeed, writing (n=p+r), the addition (n+n) has one base-(p) carry exactly when (2rge p), i.e. (ple2n/3). Consequently

```plain text
#{p in (n/2,n] : p | binom(2n,n)}
 >= pi(2n/3)-pi(n/2)
 ~ n/(6 log n).
```

So holonomicity, diagonality, algebraicity modulo (p), and fixed rational complexity do not by themselves force horizontal sparsity. Apéry needs a sequence-specific cross-prime theorem.

## 4. Gallagher’s larger sieve: the required hypothesis is absent

Gallagher’s larger sieve bounds a set (mathcal Ssubset[1,N]) when, for many auxiliary moduli (ell), its elements occupy at most (g(ell)) residue classes modulo (ell), with

```plain text
sum_{ell} log ell / g(ell) > log N
```

in the relevant form. See P. X. Gallagher, “A larger sieve,” Acta Arith. 18 (1971), 77–81.

To apply it to

```plain text
S_n={p in (n/2,n] : p|alpha_n},
```

one would need, for many fixed auxiliary primes (ell), a theorem such as

```plain text
#{p mod ell : p in S_n} <= g(ell) << ell^(1-delta).
```

Nothing of this kind follows from the mod-(p) Galois group. That theorem merely partitions the running primes by (pbmod24), and both Galois branches permit coefficient zeros. It excludes no odd residue class modulo (24), and supplies no information modulo any growing family of auxiliary (ell).

Thus the larger-sieve denominator has no positive input: from current knowledge one must take (g(ell)=ell). The self-divisibility condition (p|alpha_n) is not a residue-class restriction on (pbmodell).

## 5. Why the Frobenius large sieve does not apply

Kowalski’s Frobenius sieve and its compatible-system variants require a fixed geometric family and auxiliary reductions. A typical setup fixes:

```plain text
- one base characteristic p0 or one global compatible system;
- one parameter space U;
- representations rho_lambda for auxiliary primes lambda;
- characteristic polynomials independent of lambda;
- uniformly bounded conductor and controlled monodromy;
- an event represented by conjugacy-invariant subsets Omega_lambda.
```

See E. Kowalski, “The large sieve, monodromy and zeta functions of curves”, and C. Perret-Gentil, “Exponential sums over finite fields and the large sieve,” IMRN 2020, especially Definition 2.1 and Theorem 2.9.

The Apéry coefficient problem violates the setup twice.

### The representation moves with the sampled prime

For every running prime (p), CFVZ construct a different extension

```plain text
F_p(t,f_p)/F_p(t)
```

of degree ((p-1)/2) or (p-1). The coefficient field, base field, defining polynomial, and group order all change with (p). There is no fixed compatible system in auxiliary (lambda), and no product-surjectivity statement across distinct residue characteristics.

### The event is not Frobenius-theoretic

The event is

```plain text
[t^(n-p)]A_p(t)=0.
```

It is a linear condition on a coefficient of the truncation polynomial, not a condition on the Frobenius conjugacy class of a rational point (t=a). The Kummer group controls the roots of

```plain text
y^(p-1)=A_p(t)^(-1)
```

as a function-field extension. It does not control the additive Fourier spectrum of the coefficient-zero positions.

Even a genuine fixed compatible system with integer traces would not automatically help with a condition reduced modulo the same running prime (p). A Frobenius sieve detects conditions modulo fixed auxiliary (ell); (p|alpha_n) has no proper local subset in those auxiliary images unless one first proves new congruences linking the quotient (alpha_n/p) to them.

## 6. Why the determinant method stops at the height bound

The determinant method counts rational or integral points on varieties of fixed degree and dimension; its uniformity is with respect to coefficients while degree and dimension remain fixed. See, for example, P. Salberger, “Counting rational points on projective varieties,” Proc. LMS 126 (2023), 1092–1133.

There is no fixed bounded-degree variety here.

1. The algebraic degree of (fbmod p) is exactly ((p-1)/2) or (p-1), so a model built from the CFVZ algebraic equation has degree growing linearly with the point being counted.

1. Writing (A_p=B_p^2) introduces (asymp p/2) coefficient variables. The ambient dimension grows with (p).

1. The fixed rational diagonal gives a bounded-complexity generating object, but extracting its (n)-th diagonal coefficient is not a rational-point condition of bounded degree in the variable (p).

If one instead discards the generating representation and treats (alpha_n) as one fixed integer, the determinant/height argument is simply

```plain text
K_1(n) log(n/2) <= log |alpha_n|.
```

Since

```plain text
log alpha_n = n log(17+12 sqrt(2)) + O(log n),
```

this is (O(n/log n)), weaker than prime counting. In fact

```plain text
log product_{n/2<p<=n} p
 = theta(n)-theta(n/2)
 = (1/2+o(1))n,
```

whereas (logalpha_nsim3.52549n). The integer (alpha_n) is large enough to contain every candidate prime without violating height. No determinant argument based only on size can save a logarithm.

## 7. The exact missing horizontal large-sieve inequality

Let

```plain text
Z_p={r<p:alpha_r=0 mod p},
U_p(h)=sum_{r in Z_p} e_p(-hr).
```

Fourier inversion on (mathbf F_p) gives

```plain text
1_{Z_p}(x)
 = |Z_p|/p + (1/p) sum_{h=1}^{p-1} U_p(h)e_p(hx).
```

Since (n-pequiv npmod p), this yields the exact identity (H) in the verdict.

The current row bound gives

```plain text
sum_{n/2<p<=n} |Z_p|/p
 << sum_{p~n} p^(-1/3)
 << n^(2/3)/log n.
```

Thus the q=1 pointwise theorem is reduced to a single explicit cross-prime estimate:

```plain text
(HLS_delta)
|sum_{n/2<p<=n} (1/p) sum_{h!=0} U_p(h)e_p(hn)|
    << n/(log n)^(1+delta)
```

uniformly in (n), for any fixed (delta>0).

The ordinary Montgomery–Vaughan large sieve does not give this. Parseval gives

```plain text
sum_{h=1}^{p-1}|U_p(h)|^2
 = p|Z_p|-|Z_p|^2.
```

For frequencies (h/p) with (pasymp N), the spacing is only (asymp N^{-2}). Therefore over an interval of (N) values of (n), the classical inequality gives only

```plain text
sum_{n in an interval of length N} |E_N(n)|^2
 <= (N+4N^2)
    sum_{p~N} (|Z_p|/p-|Z_p|^2/p^2)
 << N^2 A_N,

A_N:=sum_{p~N}|Z_p|/p.
```

See H. Montgomery and R. Vaughan, “The large sieve,” Mathematika 20 (1973), 119–134.

Even under the conjectural best-scale (A_Nasymp1/log N), the deterministic consequence is only

```plain text
|E_N(n)| <= N/sqrt(log N),
```

which is larger than (N/log N). With the proved (A_Nll N^{2/3}/log N), it is much worse. A pointwise result therefore requires cancellation between different prime moduli and their coefficient-zero Fourier phases, not merely Parseval within each prime.

Equivalent sufficient formulations are:

```plain text
- the L-infinity bound (HLS_delta);
- a sufficiently strong high factorial moment / small-CRT dispersion theorem;
- a bilinear estimate for the cross-prime sums U_p(h)e_p(hn);
- auxiliary-modulus residue restrictions on the bad primes strong enough for Gallagher.
```

The 2025 Galois theorem supplies none of these quantities.

## Final answer

The strongest complete pointwise statement obtainable from the stated inputs is still

```plain text
#{p in (n/2,n] : p|alpha_n} <= (1/2+o(1)) n/log n,
```

with the previously proved endpoint/localization savings on restricted subintervals, but no saving over prime counting on the full (q=1) range.

The fixed rational diagonal explains algebraicity and Lucas propagation. The CFVZ theorem determines the exact Kummer group and square class of the truncation polynomial. Neither provides the missing horizontal coefficient-phase dispersion across different residue characteristics. A proof must establish (HLS_delta) or an equivalent small-CRT/high-moment theorem; that is the precise new arithmetic input.
