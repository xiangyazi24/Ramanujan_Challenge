# 2. What is known about gcd(b_r,b_s)

## 2.1 No strong-divisibility law is known

The Apéry numbers are not a divisibility sequence:

[

b_1=5,qquad b_2=73,

]

so 1|2 but b_1\nmid b_2; in particular there is no analogue of

[

gcd(b_m,b_n)=b_{gcd(m,n)}.

]

I found no published theorem giving a useful uniform upper bound for gcd(b_m,b_n) at arbitrary distinct comparable indices. The closest arithmetic literature concerns individual terms:

- Luca–Shparlinski, Arithmetic properties of Apéry numbers, prove density-one lower bounds for the number and size of prime factors of a single b_n, not upper bounds for pairwise gcds.

- Malik–Straub, Divisibility properties of sporadic Apéry-like numbers, establish Lucas congruences and periodicity phenomena, not pair-gcd estimates.

- Delaygue, Arithmetic properties of Apéry-like numbers, proves p-adic valuation lower bounds and Lucas criteria, again not a general gcd(b_m,b_n) theorem.

The usual Subspace-Theorem gcd results for constant-coefficient linear recurrences do not apply: the Apéry sequence is P-recursive with polynomial coefficients and has asymptotic b_n\asymp \alpha^n n^{-3/2}, so it is not a C-finite exponential-polynomial sequence. This obstruction was already isolated in the project’s Q5505 audit.

## 2.2 Consecutive terms: only small primes can be common

Let c_n=a_n/6. The cross-Wronskian is

[

b_{n+1}c_n-b_nc_{n+1}=-frac1{(n+1)^3}.

]

After clearing the known denominators of c_n,c_{n+1}, any common divisor of b_n,b_{n+1} is supported on primes arising from the denominator-clearing factors. In particular, a prime p>n+1 cannot divide both consecutive terms. This is the integer version of the proved no-consecutive-zero lemma in the first digit block.

It does not imply that general gcd(b_r,b_s) is small when s-r is large.

## 2.3 What the existing data say

The existing Z_p data already measure the relevant large-prime part. Under the observed model

[

z_p=2K_p,qquad K_psimoperatorname{Poisson}(1/2),

]

one has

[

mathbb E z_p=1,

qquad

mathbb E z_p^2=4bigl((1/2)^2+1/2bigr)=3,

]

and

[

mathbb Ebinom{z_p}{2}=1.

]

Hence the model predicts about one unordered pair of first-block zeros per prime, and therefore

[

mathcal R_triangle(X)sim pi(2X)-pi(X).

]

So, empirically, a typical pair (r,s) has no common prime in (X,2X]; the average dyadic large-prime count per pair is of order 1/(X\log X). This does not mean the full integer gcd is uniformly O(1): smaller primes can recur through Lucas-digit structure.

Also, merely proving “O(1) dyadic prime factors on average per pair” would give only \mathcal R(X)=O(X^2). The random prediction is O(X/\log X), much stronger.

# 4. Why the resultant appears only at the third zero

For a pair b_r\equiv b_{r+h}\equiv0, the transfer gives the single scalar condition

[

N_h(r)equiv0pmod p.

]

There is no second polynomial equation in the base variable r, so there is nothing to eliminate. In particular, there is no nonzero integer depending only on h whose prime divisors contain all pair primes.

The repo’s Lemma U mechanism is different. Equality of two full fundamental-solution states imposes two equations, represented by N_h(r)=0 and an additional transfer entry L_h(r)=0. Their resultant/subresultants can therefore control universal-state collisions. A scalar zero pair imposes only one equation and cannot use that two-coordinate rigidity.

Likewise, the proved consecutive-continuant identity

[

N_h(x+1)N_h(x)-N_{h-1}(x+1)N_{h+1}(x)=Q_h(x)^2

tag{4.1}

]

shows that a common root of N_h and N_{h+1} must be a forced boundary root. This controls simultaneous returns at two adjacent gaps. It does not bound the roots of one N_h, hence does not bound the pair second moment.

A true gap-only resultant appears for three zeros. If

[

p>r+k,qquad

pmid b_r,b_{r+h},b_{r+k},qquad 0<h<k,

]

then

[

N_h(r)equiv N_k(r)equiv0pmod p.

]

After removing any known boundary common factors, this forces

[

pmid operatorname{Res}_x(N_h,N_k).

tag{4.2}

]

Thus resultants naturally attack the third factorial moment

[

T_3(X):=sum_{X<ple2X}(z_p)_{3}.

]

This can still control the second moment because the exact elementary inequality

[

z^2le2z+(z)_3

qquad(zinmathbb Z_{ge0})

tag{4.3}

]

has difference z(z-2)^2. Hence

[

S_2(X)le2S_1(X)+T_3(X).

tag{4.4}

]

However, a bare resultant-height sum is far too large. The degrees are 3(h-1) and 3(k-1), and standard height bounds give roughly

[

log|operatorname{Res}(N_h,N_k)|

ll hklog(h+k).

]

Summing the resulting possible dyadic prime divisors over all h,k\ll X loses several powers of X. To gain anything, one needs structural information such as bounded primitive gcd degree, strong factor sharing laws, or cancellation/dispersion across (h,k). The existence of the resultant alone is not enough.

# 5. The current continuant method reproduces X^{7/3} exactly

Let

[

mathcal P(X,H)

:=sum_{X<ple2X}

tag{5.1}

]

[

lesum_{X<ple2X}sum_{hle H}3(h-1)

Now partition [0,p) into intervals of length at most H. If a block contains a_j zeros, all \binom{a_j}{2} pairs in that block have gap <H. Cauchy gives

[

sum_jbinom{a_j}{2}

ge frac12left(frac{z_p^2}{lceil p/Hrceil}-z_pright).

Consequently, for an absolute constant C,

[

z_p^2

le Cfrac pHbigl(U_p(H)+z_pbigr),

tag{5.3}

]

where U_p(H) is the number of zero pairs with gap <H. Summing and using p\asymp X gives

[

ll frac XHbigl(mathcal P(X,H)+S_1(X)bigr).

Let

- \delta=1/2: exponent 1/2;
