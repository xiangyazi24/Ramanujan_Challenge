## 8. Exact computational search plan

The following search distinguishes the unrestricted lattice optimum from named orthogonal-polynomial filters.

```python
# Exact inputs: C[0..n] from the Q556 coefficient formula.
# No floating point is used in the certificate stage.

J = (n - 3) // 7

# Taylor/binomial moments at epsilon = -1.
D = []
for k in range(J + 1):
    Dk = sum((-1)**d * binomial(d, k) * C[d]
             for d in range(k, n + 1))
    D.append(ZZ(Dk))

# Unrestricted degree-m optimum.
g = 0
for m in range(1, J + 1):
    g = gcd(g, D[m])
    r = D[0] % abs(g)
    if r == 0:
        mu = abs(g)          # least nonzero value in the affine lattice
    else:
        mu = min(r, abs(g) - r)
    record(n, m, log(mu)/n)

# Recover one Bezout vector and audit coefficient height.
# Use xgcd or an LLL/CVP lattice with a penalty coordinate for coefficients.

# Krawtchouk family.
for N in [J, J//2, J//3]:
    Kprev = [ZZ(1)] * (n + 1)
    Kcur  = [ZZ(N - 2*d) for d in range(n + 1)]
    test_dot_products(Kprev, Kcur)
    for m in range(1, N):
        Knext = [((N - 2*d)*Kcur[d] - (N-m+1)*Kprev[d]) // (m+1)
                 for d in range(n + 1)]
        assert all(((N - 2*d)*Kcur[d] - (N-m+1)*Kprev[d]) % (m+1) == 0
                   for d in range(n + 1))
        Rminus = sum((-1)**d * Knext[d] * C[d]
                     for d in range(n + 1))
        if Rminus != 0:
            record(n, N, m+1, log(abs(Rminus))/n)
        Kprev, Kcur = Kcur, Knext
```
