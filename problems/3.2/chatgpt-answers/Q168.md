# Breakthrough hunt: can density-one smallness force pointwise Apéry gcd smallness?

## Verdict

No—at least not from the recurrence/Lucas rigidity currently proved. The exact propagation law is real and clean, but it is an anti-propagation law at the scale relevant to log G_n / n:

1. A lower-channel prime p responsible for p | G_N generally disappears at both immediate neighbors N-1 and N+1.

1. It reappears on the arithmetic progression with the same base-p last digit:

1. For many distinct primes dividing one anomalously large G_N, those progressions separate immediately. In [N,2N], two distinct primes p,p' > sqrt(N) cannot both be inherited at the same shifted point through the same residue, because that would force pp' | (m-N) while 0 < m-N <= N.

1. More generally, including the proved palindromic zero p-1-r, every prime inherited from the known zero at N divides one of the two integers

So a linear-size spike at N can be followed by ~N/log N small one-prime shadows, but it does not force even one additional index m asymp N with log G_m > delta m. Density-one smallness is perfectly compatible with such isolated spikes.

The strongest theorem obtainable from the present inputs is the propagated-shadow bound proved below:

```plain text
For the lower-channel primes that divide G_N, the total weight forced at
any different m in [N,2N] is O(log N), not Omega(N).
```

This closes the proposed density-to-pointwise route negatively. To exclude a spike, one still needs a genuinely cross-prime non-alignment theorem—essentially the A_3/small-CRT dispersion input in a new guise.

Route (3) is also dead. The reduced denominator is d_n b_n/G_n, not b_n/G_n; the Rhin–Viola irrationality measure yields exactly the already-proved

```plain text
limsup log G_n/n <= 5.24673...,
```

and has no leverage on a putative spike of size epsilon n for small fixed epsilon.

# 1. Normalize the objects before using the recurrence

Let

```plain text
(n+1)^3 u_{n+1} = P(n)u_n - n^3u_{n-1},
P(n) = (2n+1)(17n^2+17n+5),
```

with

```plain text
(b_0,b_1) = (1,5),
(a_0,a_1) = (0,6),
d_n = lcm(1,...,n)^3,
A_n = d_n a_n,
B_n = d_n b_n,
G_n = gcd(A_n,B_n).
```

The exact Wronskian is

```plain text
a_{n+1}b_n - a_n b_{n+1} = 6/(n+1)^3.              (W)
```

The current self-contained project proof records two facts that are decisive here:

- for sqrt(n) < p <= n,

- writing n=qp+r, 0<=r<p, one has the large-prime support law

See Q3.2_density_theorem.md, especially the Wronskian estimate and Theorem B.

There are therefore two channels:

```plain text
companion channel: a_q = 0 mod p,
lower channel:     b_r = 0 mod p.
```

The companion channel has already been bounded pointwise by O(n^(2/3)) primes, hence contributes only

```plain text
O(n^(2/3) log n) = o(n)                               (1.3)
```

to the large-prime gcd. Any hypothetical epsilon n counterexample must therefore obtain essentially all of its mass from the lower channel.

This distinction also explains why the naive phrase “p divides both a_n and b_n” is misleading. For p<=n, the common divisor belongs to the denominator-cleared pair (d_n a_n,d_n b_n). It is not a common zero of the two raw solutions in a field where their Wronskian is a unit.

Indeed, if two genuinely p-integral independent solutions both vanished at an index n with p not divide 6n, (W) at n-1 would give a contradiction. Large factors of G_n occur because the p^3 inside d_n changes the integral lattice.

# 2. What the three-term recurrence says locally

Suppose a solution u is integral modulo a modulus D, with

```plain text
gcd(D,n(n+1))=1,
u_n = 0 mod D.
```

The recurrence gives only

```plain text
u_{n+1} = -[n^3/(n+1)^3] u_{n-1} mod D.              (2.1)
```

Thus a zero at n makes the two neighbors proportional. It does not make either neighbor zero.

Apply this inside one non-singular base-p block. The proved companion block identity is

```plain text
p^3 a_{qp+s} = a_q b_s mod p,     0<=s<p,             (2.2)
```

while Gessel’s Lucas congruence is

```plain text
b_{qp+s} = b_q b_s mod p.                              (2.3)
```

Gessel’s original reference is Ira Gessel, “Some congruences for Apéry numbers,” J. Number Theory 14 (1982), 362–368, DOI.

Now take

```plain text
N = q p+r,
1 <= r <= p-2,
b_r = 0 mod p,
a_q != 0 mod p.                                       (2.4)
```

The restriction on r is automatic for a lower-channel zero: b_0=1, and the first-block palindromy gives b_{p-1}=b_0=1 mod p.

The recurrence proves that no two consecutive first-block Apéry values vanish. Hence

```plain text
b_{r-1} != 0 mod p,
b_{r+1} != 0 mod p.                                   (2.5)
```

Using (2.2),

```plain text
p^3 a_{N-1} = a_q b_{r-1} != 0 mod p,
p^3 a_{N+1} = a_q b_{r+1} != 0 mod p.                 (2.6)
```

Therefore, whenever the same large-prime support law applies at the neighbors,

```plain text
p | G_N,
p not| G_{N-1},
p not| G_{N+1}.                                       (2.7)
```

This is the exact opposite of the desired local propagation.

### Companion-channel exception

If instead a_q=0 mod p, then (2.2) gives

```plain text
p | G_{qp+s}  for every 0<=s<p.                       (2.8)
```

This is genuine dense block propagation. But it occurs only in the companion channel, whose total pointwise weight is already o(n) by (1.3). The only channel large enough to support a counterexample is precisely the channel with isolated local zeros.

# 3. Exact arithmetic-progression propagation

The lower channel does propagate, but only vertically through the quotient digit.

## Proposition 3.1 — same-digit propagation

Let p>=7, let r<p satisfy b_r=0 mod p, and let 1<=j<p. Then

```plain text
p | G_{jp+r}.                                         (3.1)
```

Proof. The integer m=jp+r satisfies sqrt(m)<p<=m because m<p^2. The support law and (2.2) give

```plain text
p | G_m  <=>  a_j b_r = 0 mod p,
```

which holds. square

Consequently, if N=qp+r, then

```plain text
p | G_{N+kp}                                           (3.2)
```

for every k with

```plain text
1 <= q+k < p.
```

For b_m alone, Lucas gives the stronger unrestricted statement

```plain text
m = r mod p  =>  p | b_m.                             (3.3)
```

But for G_m, the fully audited statement needed here is already (3.1), which covers every bounded neighborhood of N once p is comparable to N.

## What does not propagate

Equation (3.1) propagates only the support p | G_m. It does not imply

```plain text
v_p(G_{jp+r}) >= v_p(G_N).
```

So even the bounded exponent v_p(G_N)<=6 need not travel with the prime. Prime-power gcd mass propagates more weakly than squarefree support.

# 4. A hypothetical spike must come from many top-range lower primes

Assume the large-prime part violates the target at some large N:

```plain text
L(N) := sum_{sqrt(N)<p<=N} v_p(G_N) log p >= epsilon N.    (4.1)
```

The small-prime part is O(sqrt N), and the companion channel is O(N^(2/3)log N). Hence, for sufficiently large N, the lower channel alone carries at least (say)

```plain text
(3epsilon/4)N.                                        (4.2)
```

Use the depth bound v_p(G_N)<=6. For any fixed small eta>0, Chebyshev’s estimate gives

```plain text
sum_{p<=eta N} v_p(G_N)log p
 <= 6 theta(eta N)
 <= 12 eta N                                             (4.3)
```

for all sufficiently large N. Taking eta=epsilon/48 shows that lower-channel primes

```plain text
p > eta N                                               (4.4)
```

carry at least a fixed positive fraction of epsilon N.

Since each such prime contributes at most 6log N, their number is at least

```plain text
K_N >= c epsilon N/log N                               (4.5)
```

for an absolute numerical c>0 (for the displayed allocation one may take c=1/12 after slightly enlarging the threshold for N).

Thus the breakthrough scenario really is:

one index N aligns asymp N/log N different zero-residue conditions, with all relevant primes comparable to N.

This is exactly the bounded-quotient localization already found in the previous attack round.

# 5. Counting the propagated shadows in [N,2N]

For each top prime in (4.4), same-digit propagation gives the points

```plain text
N+p, N+2p, ..., N+floor(N/p)p.                         (5.1)
```

There are at most

```plain text
floor(N/p) <= 1/eta                                   (5.2)
```

such points per prime.

Hence the total number of forced incidences is only

```plain text
O_epsilon(K_N) = O_epsilon(N/log N).                   (5.3)
```

This is already density zero in the shell.

More importantly, the incidences do not pile up.

## Proposition 5.1 — no overlap of same-residue shadows

Let N<m<=2N. If two distinct primes p,p'>sqrt N are inherited from N through their same zero residue, then

```plain text
p | m-N,
p' | m-N.
```

Therefore

```plain text
pp' | m-N.
```

But pp'>N while 0<m-N<=N, contradiction. Thus:

```plain text
At every m in (N,2N], at most one old prime can arrive
through the same-residue progression.                 (5.4)
```

So the K_N primes responsible for the spike at N fan out to essentially different neighboring indices. At N+p, the recurrence forces only the one prime p, contributing at most

```plain text
6 log N = o(N).                                        (5.5)
```

No such point is exceptional for the density theorem’s fixed threshold delta m.

# 6. The palindromic zero does not rescue propagation

The first-block Apéry sequence also satisfies

```plain text
b_{p-1-r} = b_r mod p.                                 (6.1)
```

Thus a known zero r=N mod p forces one second residue

```plain text
r* = p-1-r = -1-N mod p.                               (6.2)
```

For another index m, the two forced possibilities are therefore

```plain text
m = N mod p       <=> p | m-N,
m = -N-1 mod p    <=> p | m+N+1.                      (6.3)
```

This yields a useful global product bound.

## Theorem 6.1 — propagated-shadow bound

Let P_N be any set of lower-channel primes p>sqrt N for which the known zero at N mod p is tracked, together with its palindromic mate. For m!=N, partition the primes forced at m into

```plain text
P_-(m) := {p : p | m-N},
P_+(m) := {p : p | m+N+1}.
```

Then

```plain text
product_{p in P_-(m)} p | |m-N|,
product_{p in P_+(m)} p | m+N+1.                      (6.4)
```

Consequently their squarefree logarithmic weight satisfies

```plain text
sum_{p forced from N at m} log p
 <= log|m-N| + log(m+N+1).                             (6.5)
```

If m in [N,2N] and the primes are in the top range p>eta N, then p>sqrt m for large N, so v_p(G_m)<=6. Hence

```plain text
sum_{p forced from N at m} v_p(G_m)log p
 <= 6[log|m-N|+log(m+N+1)]
 <= 12 log(3N).                                        (6.6)
```

In particular,

```plain text
forced inherited weight at m = O(log N) = o(m)         (6.7)
```

uniformly for every m in [N,2N], m!=N.

This is a genuine theorem from the current recurrence, block identity, palindromy, and Wronskian depth bound. It is the strongest useful propagation statement available—and it rules out the desired bootstrap.

### Why this remains an obstruction at arbitrary distance

Suppose a squarefree product

```plain text
R = product_{p in S} p
```

of old bad primes is to reappear through the same residues. Then the next common point satisfies

```plain text
m = N mod R,
```

so, apart from N, it lies at distance at least R. If the original inherited weight is log R >= cN, then

```plain text
m >= R >= exp(cN),
log R = O(log m) = o(m).                               (6.8)
```

Allowing each prime to choose its palindromic residue does not change this conclusion: (6.4) implies

```plain text
R <= |m-N|(m+N+1),                                    (6.9)
```

so log R <= 2log(m+N+1)+O(1).

The full old divisor can recur only exponentially far away, where its logarithm is negligible relative to the new index.

# 7. Why density-one smallness cannot see this shadow

The proved density theorem says that for every fixed delta>0,

```plain text
#{m<=X : log G_m > delta m} = o(X).                    (7.1)
```

A counterexample at N with log G_N>epsilon N may cast:

- asymp N/log N one-prime shadows in [N,2N];

- each shadow carrying only O(log N) forced gcd weight;

- no second point carrying a fixed positive fraction of its index.

Therefore none of the shadows belongs to the exceptional set in (7.1) once N is large.

Even the shell total is harmless. For top primes p>eta N,

```plain text
sum_{N<m<=2N} inherited_weight(m)
 <= 6 sum_{p in P_N} floor(N/p)log p
 <= (6/eta) sum_{p in P_N} log p
 = O_epsilon(N).                                       (7.2)
```

The existing density proof allows a shell total much larger than this. There is no contradiction.

This gives a clean conceptual obstruction:

Density-to-pointwise bootstrapping would require a large value of G_N to create many nearby values of order exp(cN). The recurrence creates many nearby values divisible by one old prime, which is only polynomial-size information.

Finite-order recurrence rigidity controls the modular location of a prime; it does not preserve the simultaneous alignment of N/log N different primes.

# 8. Composite gcd propagation also fails

Let D be the product of many lower-channel primes dividing G_N, all away from coefficient singularities. Reducing the recurrence modulo each prime gives

```plain text
u_{N+1} = lambda_p u_{N-1} mod p,                     (8.1)
```

not u_{N+1}=0. Chinese remaindering yields a vector congruence modulo rad(D), but no divisibility of either neighboring vector.

The joint same-residue recurrence of all prime factors requires

```plain text
m = N mod rad(D).                                      (8.2)
```

If log D >= epsilon N and every exponent is at most 6, then

```plain text
log rad(D) >= (epsilon/6)N.                            (8.3)
```

So the first joint recurrence lies at distance at least

```plain text
rad(D) >= exp(epsilon N/6).                            (8.4)
```

Again, at that index the inherited logarithmic gcd is only O(log m), not Omega(m).

Thus there is no hidden composite-divisor propagation missed by the primewise discussion.

# 9. What extra input would actually make density imply pointwise?

One would need a theorem not supplied by the recurrence alone. Equivalent useful forms include:

1. Incidence expansion: every index incident to K bad primes forces cK-sized incidence at cN other indices, with many primes per index—not merely one prime per index.

1. Small-CRT dispersion: a four-prime or higher-moment bound excluding a common unusually small CRT representative. This is the D4/A_3 route already isolated.

1. A new cross-prime algebraic relation: the conditions

1. A strong divisibility law: something comparable to Lucas sequences, forcing a large radical of G_N into many neighboring G_m. The Apéry sequence explicitly lacks this structure, and (2.7) rules out the most direct version.

Any proof of one of these would be a real breakthrough. But it would not be “density plus recurrence” alone; it would be precisely the missing horizontal non-concentration theorem.

The adversarial construction from the previous round captures the logical issue: sparse, palindromic, nonconsecutive zero sets can all be arranged to contain N mod p for a chosen N, creating one huge spike and clean immediate neighbors. Preventing that arrangement requires using the fact that all sets arise from the single global Apéry sequence—the hard cross-prime arithmetic.

# 10. Irrationality-measure route: exact calculation

Let

```plain text
alpha0 := 17+12sqrt(2).
```

The Apéry asymptotics give

```plain text
log b_n = (log alpha0)n + o(n),
|zeta(3)-a_n/b_n| = exp(-2(log alpha0)n+o(n)),          (10.1)
```

and the prime number theorem gives

```plain text
log d_n = 3n+o(n).                                     (10.2)
```

After reducing the integer pair (d_n a_n,d_n b_n) by G_n, the denominator is

```plain text
Q_n = d_n b_n/G_n,                                     (10.3)
```

not b_n/G_n. In particular,

```plain text
log Q_n
 = [3+log alpha0]n - log G_n + o(n).                   (10.4)
```

Write

```plain text
g_n := log G_n/n.
```

The effective approximation exponent of this particular rational is

```plain text
mu_eff(g_n)
 = 2log(alpha0)/(3+log(alpha0)-g_n).                   (10.5)
```

Rhin and Viola proved the upper irrationality-measure bound

```plain text
mu(zeta(3)) <= 5.513890...                              (10.6)
```

in Georges Rhin and Carlo Viola, “The group structure for zeta(3),” Acta Arith. 97 (2001), 269–293, DOI.

Consequently an infinite subsequence with g_n above a fixed value can be excluded only when

```plain text
2log(alpha0)/(3+log(alpha0)-g) > 5.513890...            (10.7)
```

or equivalently

```plain text
g > 3+log(alpha0)
      - 2log(alpha0)/5.513890...
  = 5.24673... .                                       (10.8)
```

This is exactly the already-proved bound

```plain text
limsup log G_n/n <= 5.24673... .                        (10.9)
```

For a putative log G_n>epsilon n with small epsilon, the exponent in (10.5) is only slightly larger than

```plain text
2log(alpha0)/(3+log(alpha0)) approx 1.08,               (10.10)
```

far below 5.513890.

There is a second logical limitation: an irrationality measure is an asymptotic statement allowing finitely many exceptional rational approximations. It cannot, by itself, rule out one isolated anomalously large G_N.

So route (3) is conclusively exhausted by (10.8): it gives the current 5.24673 limsup and nothing near o(n).

# 11. Final answer to the proposed breakthrough

## (1) GCD propagation

The exact useful law is:

```plain text
lower channel b_r=0:
    p | G_{jp+r} for every 1<=j<p;
    if a_q!=0, then p does not divide G_{N-1} or G_{N+1};

companion channel a_q=0:
    p divides the entire quotient block qp,...,(q+1)p-1.
```

The second channel is already pointwise negligible. The first is the only mass-capable channel and is locally anti-propagating.

## (2) Counting

A spike of size epsilon N forces >>epsilon N/log N top-range lower primes, but in [N,2N] they create only O_epsilon(N/log N) distinct one-prime shadows. The inherited weight at every different point is O(log N), by Theorem 6.1. Therefore no positive-density set of delta m-large gcds is forced.

Hence density-one smallness does not imply pointwise smallness through this mechanism.

## (3) Irrationality feedback

Confirmed dead. The correct reduced denominator includes d_n; Rhin–Viola yields only the threshold 5.24673..., and even that is a limsup statement rather than a prohibition on one isolated index.

## Research verdict

```plain text
RECURRENCE-ONLY DENSITY BOOTSTRAP: CLOSED NEGATIVELY.
```

The recurrence supplies a precise propagated-shadow theorem, but it shows that a large gcd spike can be isolated. Closing the all-n theorem still requires cross-prime dispersion/non-alignment—A_3, D4, averaged zero-set Fourier cancellation, or a comparably strong new arithmetic substitute.
