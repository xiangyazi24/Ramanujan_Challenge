# Apéry zero-set Fourier coefficients: the p-1 power creates growing complexity

## Verdict

Let

```plain text
Z_p := {0 <= r < p : b_r = 0 mod p},
U_p(h) := sum_{r in Z_p} e_p(-hr),
e_p(x) := exp(2 pi i x/p).
```

For h != 0, the exact zero-indicator identities are

```plain text
U_p(h)
 = - sum_{r mod p} b_r^(p-1) e_p(-hr),                         (I)

U_p(h)
 = (1/p) sum_{u in F_p^*} S_p(u,h),
S_p(u,h) := sum_{r mod p} e_p(u b_r - hr).                     (II)
```

These formulas are exact, but they do not put U_p(h) in the bounded-conductor trace-function category.

The obstruction is concrete:

1. The Apéry recurrence lifts b_r^(p-1) to the (p-1)st symmetric power of a two-dimensional transfer system. Its natural rank is p, not O(1).

1. The rational-diagonal representation turns b_r^(p-1) into a diagonal of a product of p-1 independent copies; the number of variables grows linearly with p.

1. The Caruso–Fürnsinn–Vargas-Montoya–Zudilin factorization

1. If one tries to interpolate the zero indicator by a polynomial in r, its degree is almost p: whenever Z_p is nonempty,

So no existing bounded-conductor trace-function theorem applies to U_p(h) merely from the recurrence, diagonal representation, or truncation-square theorem.

I do not obtain a new unconditional numerical saving for K_1(n). I do obtain a sharper proof-grade reduction than the full L^infinity estimate in Q452.

Set

```plain text
I_n := {p prime : n/2 < p <= n},
K_1(n) := #{p in I_n : n-p in Z_p}.
```

Choose

```plain text
H := floor(n^(2/3) (log n)^2).
```

Then a Fejér-majorant argument reduces the all-n target to the following low-frequency bilinear dispersion estimate:

```plain text
(LFBD_eta)

| sum_{1<=h<H} (1-h/H)
    sum_{p != q in I_n}
      U_p(h) conjugate(U_q(h))
      exp(2 pi i h n (1/p-1/q)) |

    << n^(8/3)/(log n)^eta
```

for any fixed eta>0, uniformly in n.

This estimate is strictly less ambitious than Q452's full-frequency HLS_delta target in the relevant sense:

- it uses only h < n^(2/3) log^2 n, not all h<p;

- it asks only for a second-moment/bilinear logarithmic saving;

- it yields exactly K_1(n)=o(n/log n), with no fixed rate required.

It is also sharp at the correct obstruction scale: a singleton residue system aligned at one integer makes the left side of (LFBD_eta) of order n^(8/3), so any logarithmic saving rules out precisely the alignment that blocks the pointwise theorem.

No current large-sieve, trace-function, Kloosterman-fraction, or CFVZ Galois-group theorem proves (LFBD_eta). This is the cleanest falsifiable residual target I see.

# 1. Exact zero-indicator formulas

For an element x in F_p, Fermat gives

```plain text
1_{x=0} = 1-x^(p-1)                                   (1.1)
```

as an F_p-valued function. Since the right side takes the literal integer values 0 and 1, it may be inserted into the complex Fourier sum without ambiguity.

For h != 0,

```plain text
sum_{r mod p} e_p(-hr)=0,
```

so

```plain text
U_p(h)
 = sum_r (1-b_r^(p-1)) e_p(-hr)
 = -sum_r b_r^(p-1)e_p(-hr).                          (1.2)
```

Additive orthogonality gives a second exact formula:

```plain text
1_{x=0} = (1/p) sum_{u mod p} e_p(ux).
```

Therefore

```plain text
U_p(h)
 = (1/p) sum_{u != 0} sum_r e_p(u b_r-hr),            (1.3)
```

because the u=0 term again vanishes for h != 0.

Formula (1.3) might look like a route to Deligne. The missing step would be a bounded-conductor realization of

```plain text
r -> e_p(u b_r).
```

That step is not available. Even if r -> b_r is itself a Frobenius trace, exponentiating the numerical trace value by another additive character is not one of the bounded-complexity sheaf operations. The six-functor/trace-function formalism is linear and tensorial; it does not turn

```plain text
t_F(r) -> e_p(u t_F(r))
```

into a bounded-conductor sheaf uniformly in p.

Fouvry–Kowalski–Michel's prime-sum theorem assumes a fixed-modulus trace weight of bounded conductor, with constants polynomial in that conductor; see Theorem 1.5 of Algebraic trace functions over the primes. Their own conductor examples show that an additive polynomial phase of degree d has conductor d+2. A conductor of order p destroys the uniform saving.

# 2. The recurrence produces a rank-p symmetric-power system

Define the cleared Apéry sequence

```plain text
W_r := (r!)^3 b_r.
```

The recurrence becomes

```plain text
W_{r+1} = P(r)W_r-r^6W_{r-1},
P(r)=34r^3+51r^2+27r+5.                              (2.1)
```

Thus

```plain text
v_r := (W_r,W_{r-1})^T,

v_{r+1}
 = [ P(r)  -r^6 ] v_r.
   [  1      0  ]                                         (2.2)
```

For 0<=r<p, Fermat gives

```plain text
W_r^(p-1)=b_r^(p-1),                                  (2.3)
```

because r! is a p-unit.

Now form all monomials of total degree p-1:

```plain text
W_r^(p-1), W_r^(p-2)W_{r-1}, ..., W_{r-1}^(p-1).
```

They transform linearly under

```plain text
Sym^(p-1) A(r),
```

where A(r) is the 2 x 2 matrix in (2.2). This space has dimension exactly

```plain text
p.                                                     (2.4)
```

The coordinate W_r^(p-1)=b_r^(p-1) is one matrix coefficient of this rank-p system. Adding the constant 1 gives a rank-p+1 inhomogeneous realization of the zero indicator.

After normalizing the transfer matrix to determinant one, Sym^(p-1) is the natural degree-p-1 representation of SL_2(F_p); on the full SL_2 envelope it is the p-dimensional Steinberg module. Thus the representation-theoretic object naturally selected by Fermat's exponent is maximally characteristic-dependent, not bounded rank.

This does not prove that no miraculous unrelated bounded-rank description of the particular Apéry zero indicator can exist. It proves that the recurrence-plus-Fermat construction itself cannot provide one.

# 3. The rational diagonal also grows linearly in dimension

Straub gives a fixed rational-diagonal representation for the Apéry generating series; one convenient form is

```plain text
sum_{n>=0} b_n t^n
 = Diag 1 / (((1-x1-x2)(1-x3-x4))-x1x2x3x4).
```

See A. Straub, Multivariate Apéry numbers and supercongruences of rational functions.

Let R(x1,x2,x3,x4) denote this rational function. Then

```plain text
b_n^(p-1)
```

is the full diagonal coefficient of

```plain text
product_{j=1}^{p-1} R(x_{j,1},x_{j,2},x_{j,3},x_{j,4}).  (3.1)
```

The representation is exact, but it uses

```plain text
4(p-1)
```

variables. Cohomological rank/Betti complexity therefore grows with p; fixed-complexity diagonal theorems do not apply uniformly.

This is the diagonal analogue of the symmetric-power calculation: coefficientwise exponentiation is implemented by a tensor/Hadamard construction whose size grows with the exponent.

Quantitative sheaf theory controls the six operations in terms of the input complexity; it does not make an input of complexity ~p bounded. See Forey–Fresán–Kowalski–Sawin, Quantitative sheaf theory, and Fouvry–Kowalski–Michel, On the conductor of cohomological transforms.

# 4. Why the CFVZ square factorization does not control coefficient zeros

Let

```plain text
A_p(t) := sum_{r=0}^{p-1} b_r t^r in F_p[t].
```

Caruso–Fürnsinn–Vargas-Montoya–Zudilin prove:

```plain text
A_p(t)=B_p(t)^2,
```

for p == 1,5,7,11 mod 24, and

```plain text
A_p(t)=(t^2-34t+1)B_p(t)^2,
```

for p == 13,17,19,23 mod 24. See Theorems 1–2 of Galois Groups of Apéry-like Series Modulo Primes, published online in the Bulletin of the Australian Mathematical Society in 2026.

This factorization is powerful for the Kummer extension generated by the whole series, but it is the wrong multiplication for U_p(h).

If

```plain text
B_p(t)=sum_j c_j t^j,
```

then in the square branch

```plain text
b_r = sum_{i+j=r} c_i c_j.                            (4.1)
```

The zero indicator requires

```plain text
b_r^(p-1)
 = (sum_{i+j=r} c_i c_j)^(p-1).                       (4.2)
```

There is no Frobenius collapse at exponent p-1. Already for two summands,

```plain text
(x+y)^(p-1)
 = sum_{k=0}^{p-1} (-1)^k x^(p-1-k)y^k mod p,         (4.3)
```

because binom(p-1,k)=(-1)^k mod p; all mixed terms survive.

Equivalently, define the coefficientwise/Hadamard power

```plain text
A_p^{odot(p-1)}(t):=sum_r b_r^(p-1)t^r.
```

Then

```plain text
sum_r 1_{b_r=0}t^r
 = (1-t^p)/(1-t) - A_p^{odot(p-1)}(t).                (4.4)
```

CFVZ controls ordinary multiplication of A_p(t). It gives no simplification of the Hadamard power in (4.4).

There is also a characteristic obstruction to a naive discrete-Fourier diagonalization. The complex transform U_p(h) uses pth roots of unity, but in characteristic p

```plain text
t^p-1=(t-1)^p.
```

The group algebra F_p[C_p] is non-semisimple and has no p distinct additive characters. Thus the mod-p square factorization cannot be diagonalized by the complex length-p DFT. There is no ring homomorphism F_p -> C preserving the convolution identity.

This is the precise reason the cyclic Galois group of index 1 or 2 does not translate into a bound for U_p(h).

# 5. A degree lower bound for any polynomial zero-indicator model

Let D_p(X) be the unique polynomial of degree at most p-1 satisfying

```plain text
D_p(r)=1_{r in Z_p},   r in F_p.                      (5.1)
```

If Z_p is nonempty, D_p is nonzero and has at least

```plain text
p-|Z_p|
```

roots. Therefore

```plain text
deg D_p >= p-|Z_p|.                                   (5.2)
```

Using the proved bound |Z_p|<=3p^(2/3)+O(1),

```plain text
deg D_p >= p-3p^(2/3)-O(1).                           (5.3)
```

The same argument applies to any rational-function representation with no poles on F_p: its numerator must have degree at least p-|Z_p|.

So the zero indicator is not a bounded-degree polynomial/rational trace weight. This does not exclude an exotic bounded-conductor sheaf with the same trace values, but it shows that the most direct algebraic model has essentially maximal degree.

# 6. What the classical additive large sieve gives—and why it is too weak

For a fixed dyadic block P<p<=2P, define

```plain text
E_P(m)
 := sum_{P<p<=2P} (1/p) sum_{h!=0} U_p(h)e_p(hm).
```

Montgomery–Vaughan's additive large sieve gives, for an interval of length N,

```plain text
sum_{M<m<=M+N} |E_P(m)|^2
 <= (N+4P^2)
    sum_{P<p<=2P} sum_{h!=0}|U_p(h)|^2/p^2.           (6.1)
```

Parseval gives the exact same-prime identity

```plain text
sum_{h mod p}|U_p(h)|^2=p|Z_p|.                       (6.2)
```

Hence

```plain text
sum_{M<m<=M+N}|E_P(m)|^2
 << (N+P^2) sum_{P<p<=2P}|Z_p|/p.                    (6.3)
```

With |Z_p|<<p^(2/3) and N~P, this is

```plain text
<< P^(8/3)/log P.                                     (6.4)
```

The resulting pointwise bound from L^2 is worse than P and gives no saving over prime counting.

The P^2 term is not a cosmetic artifact. The low Farey frequencies 1/p are separated only by ~P^(-2) and are highly coherent on intervals of length P. A moduli-only improvement by a logarithm would still miss the needed scale by a positive power.

Iwaniec's large sieve with prime moduli concerns a different multiplicative-character setup and rough-supported coefficients. It does not estimate this two-variable additive array U_p(h).

The sparse-moduli improvements of Baker–Munsch–Shparlinski depend on additive energy of the modulus sequence; see Additive energy and a large sieve inequality for sparse sequences. Here the moduli are already the ordinary primes. The obstruction lies in the numerator/root coefficients, not in sparse moduli.

Bettin–Chandee and Duke–Friedlander–Iwaniec obtain savings for bilinear/trilinear forms with Kloosterman fractions such as

```plain text
e(a inverse(m)/n),
```

with coefficient variables that separate multiplicatively. Our phase is

```plain text
e(hn/p),
```

and U_p(h) is an inseparable (p,h)-array. There is no modular inverse or product-factorization to which those theorems apply. See Bettin–Chandee, Trilinear forms with Kloosterman fractions.

# 7. A new rigorous low-frequency reduction

The full Fourier identity uses all p-1 frequencies. Positivity allows us to retain only a shorter initial segment.

For 1<=H<p, define the normalized Fejér kernel

```plain text
Phi_{p,H}(x)
 := (1/H^2) |sum_{j=0}^{H-1}e_p(jx)|^2

 = 1/H
   + (2/H) Re sum_{h=1}^{H-1}(1-h/H)e_p(hx).          (7.1)
```

It is nonnegative and Phi_{p,H}(0)=1. Therefore, for every residue r,

```plain text
1_{r in Z_p}
 <= sum_{z in Z_p} Phi_{p,H}(r-z).                    (7.2)
```

Expanding gives

```plain text
1_{r in Z_p}
 <= |Z_p|/H
    + (2/H) Re sum_{h=1}^{H-1}
        (1-h/H) U_p(h)e_p(hr).                        (7.3)
```

For the q=1 slice, r=n-p, and

```plain text
e_p(h(n-p))=e_p(hn).
```

Thus, with

```plain text
T_n := sum_{p in I_n}|Z_p|,
V_h(n):=sum_{p in I_n}U_p(h)e_p(hn),
w_h:=1-h/H,
```

we obtain the exact upper bound

```plain text
K_1(n)
 <= T_n/H + (2/H) Re sum_{h=1}^{H-1} w_h V_h(n).      (7.4)
```

The proved zero-count estimate gives

```plain text
T_n << n^(5/3)/log n.                                 (7.5)
```

Choose

```plain text
H=floor(n^(2/3)(log n)^2).                            (7.6)
```

Then

```plain text
T_n/H << n/(log n)^3=o(n/log n).                      (7.7)
```

Only the low-frequency form in (7.4) remains.

# 8. The precise weaker bilinear estimate that suffices

Cauchy–Schwarz gives

```plain text
|sum_{h<H}w_hV_h(n)|^2
 <= H sum_{h<H}w_h|V_h(n)|^2.                         (8.1)
```

Set

```plain text
M_n(H):=sum_{h=1}^{H-1}w_h|V_h(n)|^2.                 (8.2)
```

Expanding in the prime variable,

```plain text
M_n(H)=D_n(H)+C_n(H),                                 (8.3)
```

where

```plain text
D_n(H)
 := sum_{h<H}w_h sum_{p in I_n}|U_p(h)|^2,            (8.4)
```

and

```plain text
C_n(H)
 := 2 Re sum_{h<H}w_h
      sum_{p<q in I_n}
        U_p(h) conjugate(U_q(h))
        exp(2 pi i h n(1/p-1/q)).                     (8.5)
```

The diagonal is already small. By Parseval,

```plain text
D_n(H)
 <= sum_{p in I_n}p|Z_p|
 << n^(8/3)/log n
 = o(n^(8/3)).                                        (8.6)
```

Therefore the following single estimate is sufficient:

```plain text
(LFBD_eta)

|C_n(H)| << n^(8/3)/(log n)^eta,
H=n^(2/3)(log n)^2,                                   (8.7)
```

uniformly in n, for any fixed eta>0.

Indeed, (8.6)–(8.7) give

```plain text
M_n(H)=o(n^(8/3)).                                    (8.8)
```

Then (8.1) and (7.4) imply

```plain text
K_1(n)
 << n/(log n)^3
    + H^(-1/2)o(n^(4/3))
 = o(n/log n).                                        (8.9)
```

Finally, the Wronskian bound v_p(G_n)<=6 for p>n/2 yields

```plain text
sum_{n/2<p<=n} v_p(G_n)log p
 <= 6(log n)K_1(n)
 = o(n).                                              (8.10)
```

So (LFBD_eta) closes the entire q=1 weighted contribution.

## Centered pair-correlation form

Expanding U_p in roots shows exactly what (LFBD_eta) says. Put

```plain text
theta_{p,r}(n):=(n-r)/p.
```

The Fejér kernel

```plain text
F_H(t):=(1/H)|sum_{j=0}^{H-1}e(jt)|^2
       =1+2 sum_{h=1}^{H-1}w_h cos(2 pi h t)
```

gives

```plain text
C_n(H)
 = sum_{p<q}
   sum_{r in Z_p, s in Z_q}
     [F_H(theta_{p,r}(n)-theta_{q,s}(n))-1].          (8.11)
```

Thus (LFBD_eta) is a centered near-collision estimate for the moving rational points (n-r)/p.

It is falsifiable and sharp:

- A simultaneous q=1 hit has theta_{p,n-p}(n)=1.

- If singleton sets are adversarially aligned at one n, then roughly n/log n points coincide at 1.

- Their contribution is

Hence a logarithmic saving in (LFBD_eta) excludes precisely the worst alignment and no more.

This is materially weaker than proving Q452's full-frequency L^infinity bound: it asks only for a centered second moment over h<H=o(n) and only a logarithmic saving over the aligned extremum.

# 9. Why current machinery still does not prove (LFBD_eta)

Expanding the phase difference gives

```plain text
theta_{p,r}(n)-theta_{q,s}(n)
 = [n(q-p)+ps-qr]/(pq).                               (9.1)
```

The h-average localizes the integer numerator in (9.1) to a window of width about

```plain text
pq/H ~ n^(4/3)/(log n)^2.                             (9.2)
```

A proof of (LFBD_eta) therefore needs cancellation in the signed count of solutions to

```plain text
n(q-p)+ps-qr approximately k pq,

r in Z_p, s in Z_q.                                   (9.3)
```

The available information

```plain text
|Z_p|<<p^(2/3),
palindromy,
no consecutive zeros,
A_p=B_p^2 or Delta B_p^2
```

does not control this cross-characteristic bilinear incidence.

The classical spacing bound treats the pairs (p,r) as arbitrary Farey points and loses n^2. The square factorization is vertical in each F_p[t]; it gives no relation between the coefficient-zero locations for two different primes p and q. The recurrence is likewise characteristic-local.

A proof would require one genuinely new ingredient, such as:

- a cross-prime estimate for the low Fourier coefficients U_p(h);

- a horizontal trace-function realization of the coefficient-zero indicator with bounded complexity;

- or a direct determinant/resultant certificate for the bilinear relation (9.3) of subexponential height.

None follows from the 2025–26 Galois-group theorem.

# 10. Final answer

The exact zero-indicator identity does not unlock a bounded-complexity trace function. The exponent p-1 forces:

```plain text
rank p       in the recurrence/symmetric-power model,
O(p) variables in the rational-diagonal model,
degree ~p   in any polynomial indicator model.
```

The truncation-square theorem controls ordinary multiplication of the generating polynomial and does not simplify the necessary Hadamard power of its coefficients.

No current dispersion theorem beats the n^2 Farey-spacing loss for the resulting structured array.

The concrete residual theorem to attack is (LFBD_eta) in (8.7), equivalently the centered pair-correlation estimate (8.11). It is substantially narrower than the full Q452 target, is exactly strong enough for uniform o(n), and is saturated by the explicit aligned-singleton obstruction. Proving any fixed logarithmic saving in it would close the q=1 Apéry gcd contribution.
