# Executive verdict

The hit-adaptive Siegel route has an exact Smith-theoretic closure.

For each numerator degree L, let Lambda_(H,L) be the integral Newton–Padé solution lattice

```plain text
(P,Q) in Int_Z[x]_(<=L) x Int_Z[x]_(<=H-L),
P(s)=A_s Q(s), 0<=s<=H.
```

Let

```plain text
epsilon_n(P,Q)=P(n),
n=3H+1.
```

Then the quotient by the evaluation-zero sublattice is cyclic, and its exact arithmetic covolume is a determinantal-divisor ratio:

```plain text
Lambda_(H,L) / ker(epsilon_n)
  ~= g_(H,L)(n) Z,

g_(H,L)(n)
  = Delta_(r+1)([C_(H,L);e_n]) / Delta_r(C_(H,L)),
```

provided evaluation is nonzero on the lattice. Here C_(H,L) is the exact integral interpolation matrix, r=rank C_(H,L), and Delta_k denotes the gcd of the nonzero k x k minors. If evaluation vanishes identically, the numerator is zero and the ratio is interpreted as zero.

Consequently:

```plain text
Every value P(n) arising from an exact integral Padé solution
is an integer multiple of g_(H,L)(n).
```

If the rational Padé kernel has the expected dimension one, then

```plain text
g_(H,L)(n)=|P_(H,L)^prim(n)|,
```

exactly: it is the primitive saturated bordered determinant already used in the repository. There is no second hit-adaptive vector with a smaller nonzero evaluation inside the same degree.

For a hypothetical target set J, every solution satisfies

```plain text
R_J | P(n),
R_J=product_(j in J)(n-j).
```

Hence

```plain text
R_J | g_(H,L)(n).
```

This proves that exact interpolation does not repair the circularity within one Padé degree. Choosing a basis depending symmetrically on J, applying Minkowski to the kernel, taking divided differences, or imposing Hermite zeros merely chooses another lattice vector whose evaluation is still a multiple of the same generator.

There are two precise refinements.

1. At maximal numerator degree L=H, the quotient is canonically generated by the fixed Newton interpolation carrier

```plain text
F_H(x)=sum_(k=0)^H Delta^k A_0 binom(x,k),
F_H(s)=A_s.
```

Indeed

```plain text
Lambda_(H,H)=Z (F_H,1),

g_(H,H)(n)=|F_H(n)|.
```

Thus the fixed carrier is not merely one possible certificate: it is the exact primitive quotient generator in that degree.

1. If several degrees are allowed, the direct-sum evaluation image is

```plain text
gcd_(L in S) g_(H,L)(n) Z.
```

Under one-dimensional normality this is exactly

```plain text
gcd_(L in S) P_(H,L)^prim(n).
```

Therefore the hit-adaptive multi-degree construction is exactly the growing Padé-family gcd from working-note Sections 160–166. It is not a new Siegel quotient. The fixed Newton carrier is the L=H member; adding lower degrees can reduce its generator only through the already isolated saturated bordered-minor gcd.

No Apéry-specific cancellation of logarithmic height o(H) is presently proved. The weakest concrete identity that would reopen the route is an explicit recurrence-derived combination

```plain text
0 != C_H
   = sum_(L in S_H) c_(H,L) P_(H,L)^prim(3H+1),

log |C_H|=o(H),
```

with coefficients constructed independently of the unknown target radical. Equivalently, one needs a subexponential nonzero element of the ideal generated by the saturated bordered evaluations. Every target prime would divide C_H, closing q=1. The existing scalar finite-difference stencil does not provide such an identity, and its claimed compound-minor lift has been retracted on latest main.

# 1. Exact target-node collapse

Put

```plain text
n=3H+1,
J subset {0,...,H},
p_j=n-j prime,
p_j>2H,
p_j|A_j,
R_J=product_(j in J)p_j.
```

Let

```plain text
P(x)=sum_(i=0)^L p_i binom(x,i)
```

be integral in the binomial basis, with

```plain text
L<min_(j in J)p_j.
```

For each j in J, since n=j+p_j, Lucas reduction for the binomial basis gives

```plain text
binom(n,i)=binom(j,i) mod p_j,
0<=i<=L<p_j.
```

Therefore

```plain text
P(n)=P(j) mod p_j.
```

The primes p_j=n-j are distinct, so the Chinese remainder theorem yields

```plain text
[p_j|P(j) for every j in J]
iff
R_J|P(n).                                      (1.1)
```

For an exact Padé solution,

```plain text
P(j)=A_j Q(j),
```

and the target hypothesis gives p_j|P(j). Thus every exact integral solution satisfies

```plain text
R_J|P(n).                                      (1.2)
```

Equation (1.2) is independent of the dimension of the solution lattice and of the chosen basis. It already implies that the arithmetic generator of the evaluation image is divisible by R_J.

# 2. The exact interpolation matrix

Use the binomial bases

```plain text
P(x)=sum_(i=0)^L p_i binom(x,i),
Q(x)=sum_(k=0)^(H-L) q_k binom(x,k).
```

Put

```plain text
N=(L+1)+(H-L+1)=H+2.
```

Define the (H+1) x (H+2) integer matrix

```plain text
C_(H,L)[s,i]       = binom(s,i),
C_(H,L)[s,L+1+k]   = -A_s binom(s,k),

0<=s<=H,
0<=i<=L,
0<=k<=H-L.
```

If

```plain text
v=(p_0,...,p_L,q_0,...,q_(H-L))^T,
```

then the exact Padé equations are simply

```plain text
C_(H,L) v=0.                                  (2.1)
```

Hence the integral solution module is

```plain text
Lambda_(H,L)=ker_Z C_(H,L).                   (2.2)
```

Because the target is a kernel over Z, it is saturated: if an integer multiple of v lies in the kernel, then v itself lies in the kernel.

The evaluation row is

```plain text
e_n=(binom(n,0),...,binom(n,L),0,...,0),       (2.3)
```

so that

```plain text
e_n v=P(n).                                   (2.4)
```

No modular dimension count appears in (2.1)–(2.4). They are the exact integral equations.

# 3. Smith evaluation-quotient theorem

For an integer matrix C of rank r, write

```plain text
Delta_r(C)=gcd of all nonzero r x r minors of C,
Delta_0(C)=1.
```

Let [C;e] denote the matrix obtained by adjoining the integer row e.

## Theorem 3.1 — exact evaluation image

Let

```plain text
Lambda=ker_Z C,
e:Z^N->Z.
```

If e vanishes on Lambda, then

```plain text
e(Lambda)={0},
Delta_(r+1)([C;e])=0.
```

Otherwise

```plain text
e(Lambda)=g Z,

g=Delta_(r+1)([C;e])/Delta_r(C).              (3.1)
```

Consequently

```plain text
Lambda/ker(e|Lambda) ~= g Z.                   (3.2)
```

### Proof

Apply unimodular row and column operations to put C in Smith form

```plain text
C ~ [ diag(d_1,...,d_r)  0 ],
d_1|d_2|...|d_r.
```

These operations preserve the kernel up to a lattice isomorphism and preserve determinantal divisors. In the transformed coordinates,

```plain text
Lambda={0}^r x Z^(N-r).
```

Write the transformed evaluation row as

```plain text
e=(a_1,...,a_r,b_1,...,b_(N-r)).
```

Then

```plain text
e(Lambda)=gcd(b_1,...,b_(N-r)) Z.              (3.3)
```

Also

```plain text
Delta_r(C)=d_1...d_r.
```

Every nonzero (r+1)-minor of [C;e] must use all r diagonal columns and one kernel column. Its determinant is

```plain text
+-d_1...d_r b_i.
```

Therefore

```plain text
Delta_(r+1)([C;e])
 =(d_1...d_r) gcd(b_1,...,b_(N-r)),
```

which proves (3.1). Equation (3.2) follows from the first isomorphism theorem. ∎

Applying Theorem 3.1 to (2.1)–(2.4) gives the promised exact generator

```plain text
g_(H,L)(n)
 =Delta_(r+1)([C_(H,L);e_n])
   /Delta_r(C_(H,L)).                           (3.4)
```

This ratio is the arithmetic covolume/content of the evaluation quotient. It is basis-independent and already includes every Smith saturation factor.

# 4. Relation to the primitive Padé numerator

Suppose the interpolation matrix has full row rank

```plain text
rank C_(H,L)=H+1.
```

Then Lambda_(H,L) has rank one. Let

```plain text
v_(H,L)^prim
```

be its primitive generator, and let

```plain text
(P_(H,L)^prim,Q_(H,L)^prim)
```

be the corresponding primitive integral pair. If its evaluation is nonzero, then

```plain text
Lambda_(H,L)=Z v_(H,L)^prim,

ker(epsilon_n)=0,

g_(H,L)(n)=|P_(H,L)^prim(n)|.                 (4.1)
```

Equivalently, if

```plain text
E_(H,L)(n)=det([C_(H,L);e_n])
```

and

```plain text
delta_(H,L)=Delta_(H+1)(C_(H,L)),
```

then

```plain text
P_(H,L)^prim(n)=+-E_(H,L)(n)/delta_(H,L).      (4.2)
```

This is exactly the saturated bordered-minor formula in Q885 and working-note equation (163.3).

Thus a hit-adaptive Siegel vector in one normal Padé degree cannot be new:

```plain text
Every exact integral solution is an integer multiple
of the primitive Padé pair,
so every nonzero evaluation is an integer multiple
of P_(H,L)^prim(n).                            (4.3)
```

If normality fails, Theorem 3.1 is stronger than (4.1): the solution lattice has higher rank, but its evaluation image still has the single exact generator (3.4). Minkowski can help find a short coefficient vector; it cannot produce an evaluation smaller than the positive generator.

Combining (1.2) with (3.4) gives

```plain text
R_J | g_(H,L)(n).                              (4.4)
```

So any proof that a nonzero exact solution has evaluation exp(o(H)) already proves R_J=exp(o(H)); it does not precede that conclusion.

# 5. Maximal degree and the fixed Newton carrier

Define the exact Newton interpolation polynomial

```plain text
F_H(x)
 =sum_(k=0)^H c_k binom(x,k),

c_k=Delta^k A_0
   =sum_(s=0)^k (-1)^(k-s)binom(k,s)A_s.       (5.1)
```

Then

```plain text
F_H(s)=A_s,
0<=s<=H.                                      (5.2)
```

At numerator degree L=H, the denominator has degree zero. Write Q(x)=q. The interpolation equations force

```plain text
P(s)=q A_s=q F_H(s)
```

at H+1 nodes. Since both polynomials have degree at most H,

```plain text
P=q F_H.                                      (5.3)
```

Integral binomial coefficients imply q in Z. Hence

```plain text
Lambda_(H,H)=Z (F_H,1).                        (5.4)
```

The pair is primitive because the denominator coefficient is one. Therefore

```plain text
g_(H,H)(n)=|F_H(n)|.                           (5.5)
```

This answers the fixed-carrier question exactly:

```plain text
The quotient is canonically generated by F_H(n)
for the maximal numerator-degree solution lattice.
```

For a target node j,

```plain text
F_H(n)=F_H(j)=A_j mod p_j,
```

because deg F_H=H<p_j. Therefore

```plain text
R_J|F_H(n).                                    (5.6)
```

No alternate exact degree-H Padé solution can improve this carrier.

# 6. Exact factorization through the Newton carrier

There is a useful global identity over Q[x]. Since F_H(s)=A_s, every exact solution satisfies

```plain text
P(s)-F_H(s)Q(s)=0,
0<=s<=H.
```

Thus

```plain text
P(x)-F_H(x)Q(x)=Phi_H(x)S(x),                 (6.1)

Phi_H(x)=product_(s=0)^H(x-s),
```

for some rational polynomial S. The integrality of S depends on the chosen coefficient basis and saturation, so (6.1) is used only as a rational identity; the exact integral content is already handled by Theorem 3.1.

Evaluating at n gives

```plain text
P(n)=F_H(n)Q(n)+Phi_H(n)S(n).                  (6.2)
```

For a target prime p=n-j,

```plain text
p|F_H(n),
p|Phi_H(n),
```

so (6.2) rederives p|P(n). It also explains why changing Q, adding divided-difference corrections, or telescoping among exact interpolation equations cannot remove target divisibility: both universal generators on the right vanish modulo every target prime.

At L=H, the degree bound forces S=0 and recovers (5.3). At smaller L, the Padé constraints choose special cancellations between the two terms in (6.2), but the Smith quotient shows that these cancellations yield precisely the saturated generator g_(H,L)(n), not a hidden smaller lattice value.

# 7. Several degrees: exact equivalence with the growing Padé family

Let S be a finite set of numerator degrees and form the direct-sum solution lattice

```plain text
Lambda_(H,S)=direct_sum_(L in S) Lambda_(H,L).
```

Define the summed evaluation

```plain text
E_n((v_L)_(L in S))
 =sum_(L in S) epsilon_n(v_L).                 (7.1)
```

Since the image of each summand is g_(H,L)(n)Z,

```plain text
E_n(Lambda_(H,S))
 =gcd_(L in S) g_(H,L)(n) Z.                  (7.2)
```

Under one-dimensional normality in each degree,

```plain text
gcd_(L in S) g_(H,L)(n)
 =gcd_(L in S)|P_(H,L)^prim(n)|.              (7.3)
```

This is exactly the growing-family integer computed in working-note Sections 160–164. Its candidate support obeys the proved zero-absorber law:

```plain text
p divides gcd_(0<=L<=B)P_(H,L)^prim(n)
iff
j=n-p belongs to Z_p(H)
  or |Z_p(H)|>B.                               (7.4)
```

Consequently:

```plain text
Allowing hit-adaptive linear combinations across degrees
is algebraically equivalent to taking the gcd of the
primitive degreewise evaluations.                         (7.5)
```

There is no separate Siegel object between the one-degree generator and the growing-family gcd.

The fixed Newton carrier is merely the L=H member of this system. Adding lower degrees can make the common generator much smaller than F_H(n), as the exact data at H=74 and H=80 demonstrate, but proving a subexponential bound for that gcd is precisely the unresolved growing-family theorem (161.3).

# 8. Why the proposed hit-adaptive constructions fail exactly

## 8.1 Vanishing polynomial at the selected nodes

Let

```plain text
V_J(x)=product_(j in J)(x-j).
```

Then

```plain text
V_J(n)=product_(j in J)(n-j)=R_J.              (8.1)
```

Any construction that enforces selected-node vanishing by writing

```plain text
P=V_J U
```

therefore inserts the unknown radical into the marked evaluation exactly, even though R_J is not written as a coefficient. Hermite multiplicity gives powers of the same factor:

```plain text
V_J(n)^m=R_J^m.                                (8.2)
```

This is the first unavoidable factor in hit-adaptive Hermite interpolation.

## 8.2 Divided differences

An integral divided-difference identity expressing P(n) from values at selected nodes is another coordinate formula for the same evaluation map. Because every selected value is divisible by its corresponding p_j and P(n) is simultaneously congruent to each P(j), the output lies in R_J Z. Changing interpolation nodes cannot change the image ideal (3.1).

## 8.3 Adjugate and Smith duality

Adjugate constructions produce bordered minors of [C;e_n]. Dividing by Delta_r(C) is exactly the primitive saturation in (3.4). Omitting that divisor gives a larger raw determinant; dividing by anything further leaves the integral solution lattice. Thus Smith duality does not generate an additional cancellation beyond g_(H,L)(n).

## 8.4 Linear functionals annihilating evaluation-zero solutions

Let

```plain text
Lambda_0=ker(epsilon_n|Lambda_(H,L)).
```

Any homomorphism from Lambda_(H,L) to Z that annihilates Lambda_0 factors through

```plain text
Lambda_(H,L)/Lambda_0 ~= g_(H,L)(n)Z.
```

Therefore it is an integer multiple of the primitive evaluation coordinate. A putative recurrence functional cannot define a smaller nonzero integer unless it proves an additional divisibility/cancellation identity for the generator itself.

## 8.5 Minkowski and Siegel

Minkowski can bound the norm of a nonzero vector in Lambda or in Lambda_0. It does not bound the least positive element of epsilon_n(Lambda) below its exact generator. If a short vector has nonzero evaluation, then

```plain text
|P(n)|>=g_(H,L)(n)>=R_J.                       (8.3)
```

If it lies in Lambda_0, its evaluation is zero and it supplies no radical bound.

# 9. What the Apéry recurrence currently adds—and does not add

The recurrence

```plain text
(s+1)^3A_(s+1)
 -(34s^3+51s^2+27s+5)A_s
 +s^3A_(s-1)=0                                  (9.1)
```

is genuine additional structure beyond arbitrary interpolation data. Finite differences of (9.1) give the verified scalar stencil recorded in Q888.

However, the latest working-note audit retracts the claimed lift from that scalar entrywise stencil to saturated compound minors. Determinant multilinearity applies to entire rows or columns; the Q888 relation moves one matrix entry while the other entries in the relevant row and column do not obey the same move. No valid identity of the form

```plain text
sum_i L_i M R_i = boundary matrix of small rank
```

has been proved for the interpolation matrix, and no exterior-power recurrence for the determinantal divisors Delta_r(C_(H,L)) is available.

Therefore (9.1) has not yet changed the quotient formula (3.4) into a smaller generator. It is already encoded numerically in the entries A_s, but exploiting it requires a new symbolic relation among the saturated bordered minors, not merely among the scalar sequence entries.

# 10. Exact no-go theorem

## Theorem 10.1 — hit-adaptive exact-Padé no-go

Fix H, L, and a hypothetical target set J as above. Let Lambda_(H,L) be the exact integral Padé solution lattice, and suppose L<min_(j in J)p_j.

Then:

```plain text
(1) epsilon_n(Lambda_(H,L))=g_(H,L)(n)Z,
    with g_(H,L)(n) given by (3.4).

(2) R_J|g_(H,L)(n).

(3) Every nonzero exact evaluation has size at least R_J.

(4) Any J-dependent choice of a lattice vector, provided it does not
    alter the exact equations or insert denominators, has evaluation
    in the same ideal g_(H,L)(n)Z.

(5) Under normality, the quotient generator is exactly
    |P_(H,L)^prim(n)|.

(6) At L=H, it is exactly |F_H(n)|.

(7) Across several degrees, the smallest evaluation ideal is exactly
    the gcd of the degreewise primitive evaluations.
```

Hence exact Apéry interpolation repairs neither the one-degree Siegel argument nor the multi-degree argument automatically. It replaces the vague circularity by an exact saturated integer generator.

### Proof

Statements (1), (4), and (7) are Theorem 3.1 and direct-sum functoriality. Statement (2) follows from (1.2), since every element of the image is divisible by R_J. Statement (3) follows from (1)–(2). Statement (5) is (4.1), and statement (6) is (5.5). ∎

# 11. Weakest concrete identity that would reopen the route

The theorem above shows precisely what a successful recurrence argument must produce.

## Single-degree reopening lemma

For some degree L=L(H), construct explicitly an integer C_(H,L) such that

```plain text
0<|C_(H,L)|=exp(o(H)),

g_(H,L)(3H+1) | C_(H,L).                      (11.1)
```

Equivalently, in the normal case prove a recurrence-derived identity

```plain text
C_(H,L)=u_H P_(H,L)^prim(3H+1),
```

with u_H an integer and C_(H,L) subexponential. Since R_J|g_(H,L), (11.1) would imply the q=1 target.

A mere upper bound for the raw bordered determinant is insufficient; the identity must track the saturation divisor Delta_r(C) exactly.

## Growing-family reopening lemma

More flexibly, choose a sublinear degree set S_H and construct integers c_(H,L) such that

```plain text
C_H
 =sum_(L in S_H)c_(H,L)P_(H,L)^prim(3H+1),

0<|C_H|=exp(o(H)).                              (11.2)
```

Then

```plain text
gcd_(L in S_H)P_(H,L)^prim(3H+1) | C_H.       (11.3)
```

If S_H contains all degrees through a vertical zero-count bound, every target prime divides the gcd while the only candidate-window excess is removed by the zero absorber. Thus (11.2) would close q=1.

In matrix language, (11.2) is a recurrence-specific short nonzero element of the ideal generated by the saturated bordered-minor ratios

```plain text
E_(H,L)(n)/Delta_(H+1)(C_(H,L)).               (11.4)
```

This is the weakest concrete reopening target. It is stronger than a scalar recurrence stencil and weaker than bounding every individual Padé value.

No identity of type (11.1) or (11.2) is currently proved.

# 12. Final status

The exact quotient computation gives a definitive repair of the failed Siegel proposal:

```plain text
One degree:
    quotient generator = saturated primitive Padé evaluation.

Maximal degree:
    quotient generator = fixed Newton carrier F_H(n).

Several degrees:
    quotient generator = growing-family gcd.

Hit-adaptive node vanishing:
    first unavoidable factor = V_J(n)=R_J.

Smith/adjugate normalization:
    exact factor = determinantal-divisor ratio.
```

Thus no hidden affine freedom remains after exact interpolation and primitive saturation. The next proof step must be an Apéry-recurrence identity among saturated bordered evaluations with a nonzero subexponential right-hand side. Without that identity, the route is exactly equivalent to the already open growing-family gcd problem.
