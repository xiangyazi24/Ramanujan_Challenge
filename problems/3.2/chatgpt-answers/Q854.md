# 8. Quantitative order cutoff and the exact high-order family

Let

```plain text
H = floor((n-1)/3),
S_1(n)
  = sum_{0 <= r <= H,
          p=n-r prime,
          p | A_r}
      log p.
```

For every term, 2n/3 < p <= n. Put

```plain text
g = gcd(p-1,r),
d = (p-1)/g,
j = r/g.
```

Then

```plain text
p-1 = d g,
r   = j g,
gcd(d,j)=1,
1 <= j <= d/2,
n-1 = (d+j)g.
```

Equivalently,

```plain text
p = d(n-1)/(d+j)+1
  = (d n+j)/(d+j).
```

This is the exact bounded-order parametrization from Q817. In particular, for fixed d, every candidate is indexed by an integer j with

```plain text
1 <= j <= d/2,
gcd(d,j)=1,
d+j | n-1.
```

Dropping the divisibility and primality constraints gives

```plain text
# {candidate primes with d <= D}
  <= sum_{d<=D} floor(d/2)
  <= D^2/4 + D/2.
```

Hence their logarithmic weight is

```plain text
S_1^(<=D)(n)
  <= (D^2/4 + D/2) log n.
```

The useful choice is

```plain text
D(n) = floor(sqrt(n)/(log n)^2).
```

It gives

```plain text
S_1^(<=D)(n)
  = O(n/(log n)^3)
  = o(n).
```

More generally, any D(n) satisfying

```plain text
D(n) -> infinity,
D(n)^2 log n = o(n)
```

removes all bounded- and moderately growing-order characters.

The residual target is therefore

```plain text
S_1^(>D)(n)
  = sum_{0 <= r <= H,
          p=n-r prime,
          p | A_r,
          ord(omega_p^r)>D}
      log p
  = o(n).
```

For this residual range,

```plain text
g = (p-1)/d < n/D.
```

With the displayed choice of D, the Kummer character has kernel

```plain text
g < sqrt(n)(log n)^2,
```

but this condition alone still leaves linearly much prime weight. For instance, when n-1 is a power of 2, a positive proportion of primes in the q=1 interval can have gcd(p-1,n-1)=1 or 2. Thus the high-order reduction must use the Apéry vanishing, not merely arithmetic progressions for p.

## 8.1 The actual finite-field object

Choose an integral Laurent polynomial Phi with

```plain text
A_r = CT(Phi^r).
```

For a good prime p and a multiplicative character chi of F_p^*, define the Kummer sum

```plain text
T_p(chi)
  = sum_{x in (F_p^*)^3} chi(Phi(x)),
```

where a nontrivial character is extended by zero at 0.

For

```plain text
chi = omega_p^r,
0 < r < p-1,
```

and the prime mathfrak p_{p,r} of the cyclotomic coefficient field selected by the Teichmüller embedding, torus orthogonality gives

```plain text
T_p(omega_p^r)
  = -A_r                  (mod mathfrak p_{p,r}).
```

Thus the bad event is

```plain text
mathfrak p_{p,r} | T_p(omega_p^r).
```

One may alternatively package the same Mellin value using the rank-three transcendental K3 local system V_l on the four-punctured parameter line:

```plain text
M_p(chi)
  = alternating Frobenius trace on
    H_c^*(U_bar,
          V_l tensor L_chi).
```

After the fixed boundary corrections and integral normalization,

```plain text
M_p(omega_p^r)
  = unit * A_r            (mod mathfrak p_{p,r}).
```

This is the exact family to which any Mellin theorem must be applied. The moving datum is the marked pair

```plain text
(p, chi_{p,n}),
chi_{p,n}=omega_p^(n-p).
```

It is one character in each different finite field, selected by the same outer integer n.

## 8.2 Uniform geometric conductor versus horizontal rank growth

A rank-one Kummer sheaf is tamely ramified at 0 and infinity, independently of the order of the character. Tensoring the fixed Apéry local system by L_chi therefore has a geometric conductor bounded independently of d, away from the fixed bad primes. This is the same bounded-conductor fact used in Fouvry–Kowalski–Michel for functions such as chi(f(x)); see their conductor discussion and Corollary 1.12 in Algebraic trace functions over the primes.

This boundedness is genuinely useful inside one finite field. It means that Deligne constants for fixed tensor constructions do not automatically grow with the order d.

It does not create a horizontal compatible system as p varies. The values of an order-d character lie in

```plain text
Q(zeta_d),
```

whose degree is phi(d). Restriction of scalars is irrelevant to a per-prime Deligne estimate: one chooses one auxiliary l-adic embedding and works with the original fixed geometric rank.

Restriction of scalars becomes highly relevant if one tries to manufacture a representation over a fixed number field and apply Chebotarev across rational primes. Its rank then grows at least proportionally to

```plain text
phi(d),
```

and the degree and discriminant of the required division fields grow accordingly. Since the residual range has d as large as order p, this destroys every available uniform horizontal Chebotarev estimate.

# 9. Hostile audit of the claimed rank-two, weight-three, symplectic SL2 package

The sentence in Q817 asserting that the generic Mellin cohomology is rank two, pure of weight three, symplectic, and has connected monodromy SL2 is withdrawn. No primary theorem cited there establishes that package for this Apéry Mellin family.

## 9.1 Rank

Let

```plain text
U = P^1 minus {four singular points},
rank(V_l)=3.
```

For a generic tame Kummer twist and compactly supported cohomology, Grothendieck–Ogg–Shafarevich gives

```plain text
chi_c(U, V_l tensor L_chi)
  = rank(V_l) * chi_c(U)
    - total Swan conductor.
```

At good primes the local system and Kummer twist are tame, so

```plain text
chi_c(U)=2-4=-2,
chi_c(U, V_l tensor L_chi)=-6.
```

If the generic twist has no H_c^0 and no H_c^2, then

```plain text
dim H_c^1(U_bar,V_l tensor L_chi)=6.
```

Therefore the most immediate generic compact-support object is dimension six, not two.

A rank-two primitive quotient might exist only after an explicit middle-extension calculation, removal of boundary pieces, and proof of a decomposition. Its dimension depends on the exact local monodromy invariants at all four punctures. None of that was supplied in Q817.

The Grothendieck–Ogg–Shafarevich formula is the standard Euler-characteristic theorem for lisse sheaves on curves; a modern quantitative statement is recorded in Quantitative sheaf theory. The rank computation above uses only its tame curve case.

## 9.2 Weight

The K3 transcendental sheaf is pure of weight two. Deligne's Weil II bounds imply that compactly supported H^1 has weights at most three. Purity of exactly weight three requires a clean middle-extension statement eliminating lower-weight boundary contributions.

Thus the safe claim is

```plain text
weights <= 3,
```

not automatic purity of weight three.

The primary reference is Deligne, La conjecture de Weil II, especially the weight bounds for compactly supported cohomology.

## 9.3 Duality and monodromy

The K3 local system is orthogonally self-dual, but

```plain text
(V_l tensor L_chi)^dual
  = V_l tensor L_(chi^-1).
```

For a generic character of order greater than two,

```plain text
chi != chi^-1.
```

Therefore the twist is not self-dual as one object. Poincare duality pairs the chi-cohomology with the chi^-1-cohomology; it does not give an alternating form on the single chi-space.

Consequently neither “symplectic” nor connected monodromy SL2 follows. Establishing a convolution monodromy group would require a separate Katz-style Tannakian calculation. Original geometric monodromy SO3 of the K3 sheaf does not automatically become SL2 for its Mellin transform.

Katz's book Convolution and Equidistribution devotes separate chapters to autodualities, signs, and the examples with groups SL(n), Sp(n), and SO(n) precisely because the group is not inferred merely from the input rank and weight.

# 10. Existing theorem audit, exact exponent, and the next lemma

## 10.1 Katz finite-field Mellin equidistribution

Katz's Theorem 7.2 assumes a fixed pure arithmetically semisimple convolution object over a fixed finite field k, with a specified quotient

```plain text
G_arith/G_geom = Z/nZ.
```

It then lets extension fields E/k grow and averages the Frobenius classes over all good multiplicative characters of E^*. See The Main Theorem.

Its quantifiers are

```plain text
fix k and the sheaf;
let [E:k] -> infinity;
average over almost all characters of E^*.
```

The q=1 diagonal has the incompatible quantifiers

```plain text
fix n;
for each rational prime p change the field to F_p;
select one character chi_{p,n};
test divisibility at the prime above the same p.
```

Moreover Katz controls complex Frobenius conjugacy classes. The event

```plain text
mathfrak p_{p,r} | M_p(chi_{p,n})
```

is a same-characteristic p-adic local condition, not a continuous class function on the compact monodromy group. Katz's theorem therefore gives no bound for S_1^(>D)(n).

## 10.2 Fouvry–Kowalski–Michel over prime arguments

The closest theorem with an explicit power saving is Fouvry–Kowalski–Michel, Theorem 1.5. For one fixed prime modulus P, one nonexceptional trace function K on F_P of bounded conductor, and a prime-variable sum of length X, it gives, for every eta<1/24,

```plain text
sum_{l prime} K(l) V(l/X)
  << X (1+P/X)^(1/6) P^(-eta).
```

At X comparable with P, this is

```plain text
O(P^(1-eta)),
eta<1/24.
```

It becomes nontrivial for X > P^(3/4+epsilon). The conductor dependence is polynomial. These statements and constants are explicit in Theorem 1.5.

This would cross the required threshold if the q=1 diagonal were a prime sum of one fixed trace function modulo one fixed P. It is not:

```plain text
outer prime = p,
modulus      = p,
field        = F_p,
character    = chi_{p,n},
observable   = residual zero indicator.
```

Setting P=p separately for each summand leaves only one prime argument in each application. There is nothing to sum. In addition,

```plain text
1_{p | A_r}
```

is not known to be a bounded-conductor trace function. Writing it as

```plain text
1 - A_r^(p-1)
```

or as an additive-character average uses tensor degree or a number of phases growing with p.

The 2025–2026 theorem Bilinear forms with trace functions enlarges the class of fixed-modulus sheaves whose bilinear sums can be controlled. It retains the same fundamental requirement: a single finite field and a bounded-complexity trace kernel. It does not combine one marked residual Mellin coefficient from every different field.

## 10.3 Frobenius large sieves

Kowalski's The large sieve, monodromy and zeta functions of curves averages Frobenius conjugacy classes in a fixed algebraic family over finite fields. His abstract Principle of the large sieve still requires a family of local sieve maps and a controlled large-sieve constant.

Here the marked point is not a geometric parameter of a fixed family. It is the character

```plain text
chi_{p,n}=omega_p^(n-p),
```

and the forbidden class is the p-adic divisibility of its integral Mellin trace. No compatible collection of bounded-index finite quotients has been constructed whose local forbidden density represents this event.

Therefore these Frobenius large sieves do not apply.

## 10.4 Composite-modulus multiplier reconstruction

Suppose, much more favorably than is currently justified, that one had a rank-two weight-three integer trace a_{p,n} with

```plain text
p | A_(n-p)
  iff p | a_{p,n}.
```

At a bad prime,

```plain text
a_{p,n}=p m_{p,n},
|m_{p,n}| <= 2 sqrt(p).
```

To identify m_{p,n} from congruences modulo an auxiliary squarefree modulus M, one needs

```plain text
M > 4 sqrt(p).
```

For a generic rank-two system, the division field modulo M has degree on the scale

```plain text
|GL_2(Z/MZ)| = M^(4+o(1)).
```

Taking

```plain text
M = p^(1/2+delta)
```

therefore gives degree at least

```plain text
p^(2+4delta+o(1)).
```

Even under GRH, the standard effective Chebotarev error contains a term of size schematically

```plain text
p^(1/2)
  * ([L:Q] log p + log |Disc L|).
```

Ignoring the discriminant already yields

```plain text
p^(5/2+4delta+o(1)),
```

far larger than the total prime-counting scale p/log p. Effective Chebotarev therefore cannot reach the reconstructing modulus. The actual moving-character problem is harder because there is not one fixed compatible rank-two system in the first place.

This is the quantified version of the “same-multiplier” barrier. Effective Chebotarev in this form goes back to Lagarias–Odlyzko and Serre; a standard GRH statement is summarized in the effective-Chebotarev theorem quoted in Cojocaru–David's The Square Sieve and the Lang–Trotter Conjecture.

## 10.5 Strongest theorem that actually applies

After the exact bounded-order lemma, the strongest unconditional theorem that applies without inventing a new trace family is simply the prime number theorem/Chebyshev bound in the interval:

```plain text
sum_{2n/3 < p <= n} log p
  = n/3 + o(n).
```

Hence

```plain text
S_1^(>D)(n)
  <= n/3 + o(n).
```

Its exponent is exactly 1. It does not cross the o(n) threshold.

Brun–Titchmarsh applied after fixing the kernel g or the order d does not improve the aggregate exponent. The near-primitive class g=1 alone can contain a positive proportion of all primes in the interval. The latest repository computations also contain actual fixed-n triples with g=1, so no uniqueness principle is available.

## 10.6 Weakest precise new theorem that closes q=1

A direct power-form statement is the following.

Marked Mellin diagonal local-limit theorem (MMDL(c)). There exist absolute constants

```plain text
c>0,
C>0,
n_0>=1
```

such that, for every n>=n_0 and every

```plain text
2 <= D <= sqrt(n)/(log n)^2,
```

one has

```plain text
sum_{0 <= r <= floor((n-1)/3),
    p=n-r prime,
    ord(omega_p^r)>D,
    mathfrak p_{p,r} | T_p(omega_p^r)}
  log p

<= C n D^(-c) + C n^(1-c).
```

The same theorem may be stated with the normalized K3 Mellin trace M_p in place of the constant-term Kummer sum T_p, provided the fixed integral boundary correction is included.

This theorem has exactly the necessary quantifiers:

```plain text
uniform in the fixed outer n;
one marked character in every varying F_p;
same-characteristic residual vanishing;
no averaging over n.
```

It immediately proves the q=1 target. Choose any fixed

```plain text
0<beta<1/2
```

and put

```plain text
D=n^beta.
```

Then the bounded-order part satisfies

```plain text
S_1^(<=D)(n)
  << n^(2 beta) log n
  = o(n),
```

while MMDL(c) gives

```plain text
S_1^(>D)(n)
  << n^(1-beta c)+n^(1-c)
  = o(n).
```

Thus

```plain text
S_1(n)=o(n).
```

A qualitatively weaker, nearly minimal version is:

```plain text
For every epsilon>0 there exist D_0 and n_0 such that,
for all n>=n_0 and all D with
D_0<=D<=sqrt(n)/(log n)^2,

the high-order marked residual sum is <=epsilon n.
```

Together with any slowly growing D(n) satisfying

```plain text
D(n)^2 log n=o(n),
```

this also closes q=1.

## 10.7 Next concrete lemma

The next useful lemma should not assert SL2 monodromy or ordinary complex equidistribution. It should construct a residual detector with horizontal compatibility.

A proof-grade reopen lemma is:

```plain text
There exist fixed integers R,C and, for every good p,
a collection of at most C middle-extension sheaves
G_(p,a) on A^1/F_p,

rank(G_(p,a))<=R,
cond(G_(p,a))<=C,

such that for every high-order r

1_{p | A_r} - 1/p
  = sum_{a=1}^C c_(p,a) t_(G_(p,a))(r),

sum_a |c_(p,a)| <= C,
```

and the family of marked values

```plain text
t_(G_(p,a))(n-p)
```

satisfies a cross-characteristic large-sieve estimate with a power saving, uniformly in n.

The first line alone would permit same-prime Deligne estimates. The second, horizontal estimate is the genuinely new part and is what the pointwise diagonal requires.

No such residual detector is known. The identity

```plain text
1_{p | A_r}=1-A_r^(p-1)
```

has tensor degree growing with p, and additive orthogonality uses p phases; both violate the fixed R,C requirement.

# Recorded false routes

- Generic rank two / SL2. Withdrawn: generic compact-support dimension is naturally six before an unproved primitive decomposition; generic Kummer twists are not self-dual.

- Katz character equidistribution. Wrong limit and wrong observable: it averages all characters over extensions of one fixed finite field and controls complex classes, not one p-adically vanishing marked character per prime field.

- FKM prime sums. Wrong modulus quantifier: it fixes one finite field and varies prime arguments inside it. The available saving is P^(-eta), eta<1/24, but no single P exists here.

- Uniform geometric conductor solves the problem. False: conductor is uniform locally, but there is no horizontal compatible family; coefficient-field and restriction-of-scalars growth matter precisely when one tries to apply Chebotarev across p.

- Composite-modulus reconstruction. The modulus must exceed sqrt(p); generic division-field degree then grows like the fourth power of that modulus, making even GRH Chebotarev errors vastly larger than the main scale.

- Brun–Titchmarsh on the multiplier constraint. High order allows kernel g=1, which leaves a positive proportion of the interval. It gives exponent 1, not a little-oh.

- Average over characters or over outer n. Neither implies the required fixed-n diagonal statement.

# Final verdict

The bounded-order theorem is a genuine unconditional deletion:

```plain text
D=sqrt(n)/(log n)^2
  => bounded-order weight O(n/log^3 n).
```

The surviving high-order characters have uniformly bounded local geometric conductor, but Q817's claimed rank-two symplectic SL2 package is unsupported and is withdrawn. Every existing Mellin/trace-function theorem has the wrong finite-field or averaging quantifiers, and the strongest theorem that actually applies leaves a linear bound

```plain text
S_1^(>D)(n) <= n/3+o(n).
```

The next concrete target is MMDL(c), the marked residual Mellin diagonal local-limit theorem above. Any fixed c>0 closes q=1 after the quantitative order split. Proving it requires genuinely new cross-characteristic arithmetic for same-characteristic residual Mellin traces; no current Deligne, Katz, FKM, Frobenius-large-sieve, or effective-Chebotarev theorem supplies it.
