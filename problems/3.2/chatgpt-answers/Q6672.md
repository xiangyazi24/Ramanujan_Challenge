# Executive verdict

There is a clean closed form, but one normalization correction is essential.

Write

```plain text
d = deg N_h = 3h-3,
e = deg C_h = 4h-4,
L_h = lc(N_h),
F_h = product_{r=0}^{h-1} (r!)^3 b_r.
```

With the standard discriminant convention

```plain text
Disc(f) = (-1)^(n(n-1)/2) Res(f,f') / lc(f),
```

the ordinary zero-fiber resultant is exactly

```plain text
Res_X(C_h,N_h) = L_h Disc(N_h) F_h^2.                  (E1)
```

There is no sign and no power of 2 in this uncentered X-normalization.

However, the project polynomial is formed first as

```plain text
mathcal V_h(T) = Res_X(C_h, N_h - T q_h^3).
```

The second argument has generic X-degree 3h, but at T=0 its degree drops to

3h-3. Therefore specialization contributes three powers of lc(C_h):

```plain text

  = lc(C_h)^3 Res_X(C_h,N_h)
  = (-3L_h)^3 Res_X(C_h,N_h)
  = -27 L_h^4 Disc(N_h) F_h^2.                         (E2)
```

This degree-drop factor is exactly what is needed to match the stored exact

resultants for h=2,3.

If the project symbol V_h denotes the primitive integer part of mathcal V_h,

let

```plain text
c_h = content(mathcal V_h) > 0
```

and let eps_h in {+1,-1} be the sign used to make the primitive leading

coefficient positive. Then

```plain text
V_h(0)
  = eps_h * [-27 L_h^4 Disc(N_h) F_h^2] / c_h.          (E3)
```

For the integral descent V_h(T)=W_h(T^2), one has W_h(0)=V_h(0). For a monic

rational W_h, divide once more by the leading coefficient.

The zero-fiber consequence is exact:

```plain text

  <=> Disc(N_h) != 0
  <=> gcd(N_h,N_h')=1
  <=> N_h is squarefree over Q.                         (E4)
```

Here the other factors never vanish: deg N_h is banked, every b_r is positive,

and the pole-value law gives gcd(N_h,q_h)=1.

# 1. Exact derivation of Res(C_h,N_h)

Use

```plain text
q_h(X) = product_{a=1}^h (X+a),
C_h = q_h N_h' - 3q_h' N_h.
```

Let the roots of N_h in an algebraic closure be alpha_1,...,alpha_d, counted

with multiplicity. At each root,

```plain text
C_h(alpha_i) = q_h(alpha_i) N_h'(alpha_i).              (1.1)
```

The term -3q_h'N_h vanishes at alpha_i. Using the root-product definition of

the resultant,

```plain text
Res(N_h,C_h)
  = L_h^e product_i C_h(alpha_i)
  = L_h^e product_i q_h(alpha_i) product_i N_h'(alpha_i).
```

Since

```plain text
deg q_h + deg N_h' = h + (d-1) = 4h-4 = e,
```

the leading-coefficient powers match exactly, and multiplicativity gives

```plain text
Res(N_h,C_h)
  = Res(N_h,q_h) Res(N_h,N_h').                         (1.2)
```

Also

```plain text
d*e = (3h-3)(4h-4)
```

is even, so

```plain text
Res(C_h,N_h) = Res(N_h,C_h).                            (1.3)
```

Now q_h is monic with roots -1,...,-h. Thus

```plain text
Res(q_h,N_h) = product_{j=1}^h N_h(-j),

Res(N_h,q_h)
  = (-1)^(dh) product_{j=1}^h N_h(-j).                 (1.4)
```

For the derivative resultant,

```plain text
Res(N_h,N_h')
  = (-1)^(d(d-1)/2) L_h Disc(N_h).                     (1.5)
```

Combining (1.2)-(1.5),

```plain text
Res(C_h,N_h)
  = (-1)^[dh+d(d-1)/2]
    L_h Disc(N_h)
    product_{j=1}^h N_h(-j).                           (1.6)
```

# 7. What is currently known about Disc(N_h)

## 7.1 Exact structural facts

No all-h closed product formula for Disc(N_h) is currently banked.

The adjacent-resultant identity

```plain text
Res(N_h,N_{h-1})
  = +/- product_{j=1}^{h-2} ((j!)^3 b_j)^6
```

is not a self-discriminant identity. It proves adjacent coprimality, but it does

not control gcd(N_h,N_h') or Disc(N_h).

The h-recurrence also does not close on discriminants. Differentiating

```plain text
N_{h+1}=P(X+h)N_h-(X+h)^6N_{h-1}
```

introduces both N_h' and N_{h-1}', and resultants with N_{h+1} do not reduce to a

single previous discriminant. A repeated root of N_h need not propagate to

N_{h+1}; adjacent coprimality merely says it is not simultaneously a root of

N_{h-1}.

## 7.2 Banked local patterns relevant to the discriminant

The Montes/qI campaign has identified strong first-layer local structure, but

not a closed discriminant law.

At ell=3,

```plain text
N_h(X) = R_h(X)^3 mod 3
```

for every h. Thus N_h' is coefficientwise divisible by 3, so the first mod-3

layer is maximally inseparable. In particular,

```plain text
v_3 Res(N_h,N_h') >= d,
```

and therefore

```plain text
v_3 Disc(N_h) >= d - v_3(L_h).                         (7.1)
```

This lower bound is crude but rigorous. It explains why ordinary Dedekind

factorization or a first Newton polygon at 3 is blind: the relevant information

begins at the first nonzero 3-adic correction and its higher MacLane-Montes type

tree.

At ell=2, the exact four-step degeneration of N_h mod 2 forces residue-class

content and repeated-root phenomena. Again the first layer is not a generic

squarefree reduction.

At ell=17, the leading coefficient L_h is a Lucas sequence with an exact

17-adic valuation law. This constrains one endpoint of the Newton polygon but

does not by itself determine v_17(Disc(N_h)).

The finite Montes certificates compute local type trees, local factor degrees,

indices, and discriminant contributions for each certified h. Those data can be

harvested into a table of v_ell(Disc(N_h)), but no periodic all-h formula for the

full polynomial discriminant has yet been proved. One must also distinguish

```plain text
polynomial discriminant
  = field discriminant * index(Z[alpha])^2
```

when N_h or its centered quotient is irreducible. Montes reports both ramification

and index information; conflating them would give the wrong Eisenstein filter.

## 7.3 Finite-range consequences already available

Every finite-range irreducibility certificate for N_h or its appropriate

primitive centered factor implies separability in characteristic zero, hence a

nonzero discriminant for that row.

More directly, the full-Morse certificates for the critical-value polynomial

through h=30 give V_h(0)!=0. By (E4), they therefore certify

```plain text
Disc(N_h) != 0
```

for every 2<=h<=30.

The current empirical note that discriminant heights grow on roughly an

h^2 log h scale is a height observation, not a factorization or valuation law.

It should not be used as an all-h nonvanishing proof.

# 8. Eisenstein feasibility for W_h

Let W_h(S) be the primitive integral descent of the even primitive V_h(T), so

```plain text
V_h(T)=W_h(T^2),
deg W_h=2h-2,
W_h(0)=V_h(0).
```

For ordinary Eisenstein at a prime ell and at S=0, the machine must check

```plain text
1. ell does not divide lc(W_h);
2. ell divides every nonleading coefficient of W_h;
3. ell^2 does not divide W_h(0).                        (8.1)
```

The constant-term formula gives a cheap candidate filter.

## 8.1 Clean candidates

The cleanest candidates are primes ell satisfying

```plain text
ell does not divide 3 L_h F_h,
v_ell(Disc(N_h))=1,
ell does not divide c_h.                                (8.2)
```

Then (6.3) gives

```plain text
v_ell(W_h(0))=1.
```

Such an ell is a new simple discriminant prime, not already forced by the

factorial, Apéry, leading-coefficient, or content factors.

## 8.2 Usually poor candidates

Primes dividing F_h enter the raw constant with even exponent at least 2.

Therefore primes coming only from factorials or Apéry numbers are normally poor

ordinary-Eisenstein candidates.

Primes dividing L_h enter the raw constant with exponent at least 4.

The prime 3 has the baseline factor 27 and also heavy discriminant divisibility

from the Frobenius-cube reduction. It is unlikely to give ordinary Eisenstein at

S=0, although it remains a strong higher-Newton/Montes prime.

The prime 2 has large factorial contribution and centered-content effects. It is

likewise better treated by exact content removal and higher-order Newton data.

Content cancellation can resurrect one of these primes, but it must be checked

rather than assumed. The primitive valuation is the raw valuation minus

v_ell(c_h).

## 8.3 Interior coefficients remain an independent condition

A simple discriminant prime only settles the constant-term valuation. It does

not imply that all interior coefficients are divisible by ell.

The cheap modular test is

```plain text
W_h(S) mod ell = u S^(2h-2),  u != 0.                  (8.3)
```

Equivalently, because V_h(T)=W_h(T^2),

```plain text
V_h(T) mod ell = u T^(4h-4).                           (8.4)
```

Then one exact mod-ell^2 constant check distinguishes Eisenstein from a higher

constant valuation.

## 8.4 Shifted Eisenstein and Newton fallback

The campaign should also test shifted polynomials

```plain text
W_h(S+a)
```

for small residue classes a mod ell. A necessary first-layer signature is

```plain text
W_h(S) mod ell = u(S-a)^(2h-2).                         (8.5)
```

If ordinary Eisenstein fails because the constant valuation is greater than one,

a one-edge Dumas/Newton criterion may still prove irreducibility. The formula

(6.3) supplies the left endpoint exactly; the machine then checks whether every

interior coefficient lies strictly above the required edge and whether the

endpoint gcd condition is favorable.

# 10. Squarefreeness and the [N-SQFREE] package

The equivalence can be seen without resultants.

Let alpha be a root of N_h. The pole-value law says N_h(-j)!=0 for every pole

-j, so

```plain text
q_h(alpha) != 0.
```

At alpha,

```plain text
C_h(alpha)=q_h(alpha)N_h'(alpha).                       (10.1)
```

Therefore

```plain text
N_h(alpha)=C_h(alpha)=0
  <=> N_h(alpha)=N_h'(alpha)=0.                         (10.2)
```

Hence

```plain text
gcd(N_h,C_h)=1
  <=> gcd(N_h,N_h')=1
  <=> Disc(N_h)!=0.                                     (10.3)
```

Using (3.6), this is also equivalent to

```plain text
mathcal V_h(0)!=0,
```

and therefore to nonvanishing of the primitive V_h(0).

Thus the zero-critical-value gate is not merely related to [N-SQFREE]; after the

pole-value law it is exactly [N-SQFREE].

What is already banked:

- finite-range full Morse through h=30 implies [N-SQFREE] through h=30;

- any characteristic-zero irreducibility certificate for N_h or its primitive

- adjacent coprimality does not prove self-squarefreeness all h.

What remains open is the uniform all-h proof of

```plain text
gcd(N_h,N_h')=1.
```

The formula (9.1) turns that statement into the exact all-h nonvanishing of the

last special value V_h(0).

```plain text

F_h = product_{r=0}^{h-1}(r!)^3 b_r.
```

For the raw critical-value resultant


# Required self-audit

## (a) Least-confident sign/power

The ordinary formula (11.1) and the raw formula (11.2) are high confidence: the

sign exponent simplifies to an even integer, and the missing cube is independently

forced by the three-degree specialization drop and verified exactly at h=2,3.

The only convention-dependent part is (11.3): the project sometimes writes V_h

for a primitive part, sometimes only up to a nonzero scalar. The content c_h and

the final sign eps_h must therefore be read from the exact normalization used in

a given file. No universal closed formula for c_h is proved here.

## (b) Likely blind spot

The main blind spot is to identify

```plain text
mathcal V_h(0)
```

directly with Res(C_h,N_h). Because N_h-Tq_h^3 has generic degree 3h but degree

3h-3 at T=0, that loses the factor lc(C_h)^3=(-3L_h)^3.

A second blind spot is to treat a simple prime divisor of Disc(N_h) as an

Eisenstein certificate. It only supplies the desired constant valuation after

content removal. Interior coefficient divisibility, leading-coefficient

unitness, and the distinction between polynomial discriminant, field

discriminant, and index must still be checked.
