# 10. Height audit

The Apéry asymptotic is

[

Since every lower-channel bad prime divides (b_n), the certificate

This gives only a linear bound for the bad-prime logarithmic mass.

## 10.3 The folded gcd certificate

[

Therefore the exact outcome is:

- the cocycle scalar constraint collapses to palindromy;

- the raw p-independent product certificate has quadratic logarithmic height;

- the only potentially useful fixed certificate is the folded gcd (9.3), whose subexponentiality is open.

# 11. Why a non-diagonal gauge cannot change this conclusion

A full classification of bounded-degree non-diagonal gauges is unnecessary for the bridge question. The reflection relation is gauge-covariant.

Let (G(t)) be any rational gauge that is invertible at the relevant parameters, and define

[

widetilde B(t)=G(t+1)^{-1}B(t)G(t).

]

Set

[

widetilde H(t)

=G(-t)^{-1}H(t)G(t)^{-mathsf T}.

]

Using (R), one obtains

[

boxed{

widetilde B(-1-t)

=widetilde H(t),widetilde B(t)^{mathsf T}

}

tag{11.1}

]

Indeed,

[

begin{aligned}

widetilde B(-1-t)

&=G(-t)^{-1}B(-1-t)G(-1-t)\

&=G(-t)^{-1}H(t)G(t)^{-mathsf T}

end{aligned}

]

The first and last factors are exactly (widetilde H(t)) and (widetilde H(t+1)^{-1}).

Hence every regular gauge retains the same telescoping reflected-product structure. It may simplify the appearance of the cocycle, but it cannot turn the universal symplectic identity into an extra scalar condition on a zero prefix. A singular gauge could manufacture apparent extra factors, but those factors would be gauge poles/zeros rather than arithmetic restrictions on the Apéry orbit.

So the diagonal divisor obstruction from Q340 need not be extended to a classification of all non-diagonal gauges for the present purpose. The bridge failure is gauge-invariant.

# Final answer to the all-(n) bottleneck

The exact reflected cocycle does produce a strong matrix theorem:

[

B(-1-t)=H(t)B(t)^{mathsf T}H(t+1)^{-1},

]

[

B(p-2)cdots B(1)=w,

]

and

[

B(p-r-1)cdots B(r)=H(r)w.

]

But at a lower-channel zero it yields only the forced reflected zero and the neighboring palindromic value. The prefix remains a free Borel-coset parameter, so there is no non-tautological scalar or triangular constraint to eliminate.

The only real cross-prime output is the folded moving-target condition (8.1) and the fixed certificate

[

C_n^{mathrm{fold}}

=gcd!left(b_n,

operatorname{lcm}_{jle(n-1)/3}b_jright).

]

Proving

[

log C_n^{mathrm{fold}}=o(n)

]

would solve the lower-channel pointwise problem. The cocycle symmetry itself does not prove it. Thus the reflection route does not bypass the arithmetic wall; it converts it into a precise integer gcd problem involving (b_n) and the first third of the Apéry sequence.
