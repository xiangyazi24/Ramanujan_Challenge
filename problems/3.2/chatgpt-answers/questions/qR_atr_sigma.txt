  E^pi << p^{5/3} 平凡; [THM-ENERGY-3/2] E^pi << 2.45 p^{3/2} 无条件(块分割+deg 界);
  deg_r N_h = 3(h-1) => J(h,k) := #共同根(N_h, N_k) <= 3 min(h,k) (deg 界)。

  (Q_sigma) Q_p(Delta) << Delta^{3-sigma} p^eps => E^pi << p^{2 - 1/(3-sigma) + eps}。
  sigma=0 即平凡 p^{5/3}; sigma=1 给 p^{3/2}; 最现实第一档 Q << Delta^{2+o(1)} 给 p^{3/2+o(1)}...
  注意 sigma=1 才追平 3/2 定理, 所以真正的新东西从 sigma > 1 开始; 但任何严格 sigma > 0
  的干净方法论都可能可放大, 我们都要。
- 数据: Q_p(H)/(H + H^2/p) <= 0.28 全场(p 到 10^5, dyadic H 到 p/3), H<=128 时恰为 0;
  T3/p = 3.974 vs 随机 4.000; 小 h 结构根: N_2 的 disc=-51 Chebotarev 律 R_2 = 1 + 2[(-51|p)=1]。
