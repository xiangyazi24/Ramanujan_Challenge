latest main branch, especially the exact direct q=1 core in Section 148,

index n has a large target set

  J={j<=floor((n-1)/3): p_j=n-j is prime and p_j divides A_j}

with radical R=product_{j in J} p_j. Allow the auxiliary construction to
depend symmetrically on the actual index set J (but do not put R or the
unknown prime quotients into its coefficients). Use the fact that a
counterexample supplies many nodes, so the certificate only has to

primitive normalization and nonvanishing. The certificate must exploit
the exact Apéry cubic or binomial/diagonal realization: Section 80 shows

balance that killed full-grid Padé interpolation. If it still fails,

force enough same-block close pairs that a product of gap continuants can
