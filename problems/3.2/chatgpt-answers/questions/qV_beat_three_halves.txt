[P3.2 Apery gap 战役三: 直攻 E^pi << p^{3/2 - delta}——3/2 定理的证明内部找 delta]

背景(已证定理, 这轮的原材料):
- [THM-ENERGY-3/2] E^pi <= 2.45 p^{3/2} 无条件。证明机制 = 块分割: 把 n in [0, p-2] 切成
  长 L 的块, 块内碰撞用 deg 界(gap h <= L 的碰撞对每块 O(L^2) 上界经 R_h <= 3(h-1)+1 求和 = O(L^2)),
  跨块用一致重数/平凡计数, 优化 L = sqrt(p)。
- 一致重数 mult(v) <= 3 p^{2/3} 每 v(continuant 2/3 论证, 只用递推结构)。
- E^pi <= 2N + T3(一行不等式); T3 = sum_v m_v(m_v-1)(m_v-2)。
- 镜像: 轨道精确 2-对-1(逐点代数恒等)——半轨道(n < (p-1)/2)上通用重数 1 猜想,
  E^pi = O(p) <=> 半轨道能量 O(p)。
- Casoratian 刚性: 相邻点 pi(n), pi(n+1) 不能碰撞(Delta = -1/n^3 != 0), 且更一般
  Delta_{r,h} 有显式小 h 公式(N_1=1, N_2(r)=P(r+1) 三次)。
- sigma 机器(接口): Q_p(Delta) << Delta^{3-sigma} p^eps => E^pi << p^{2-1/(3-sigma)+eps}。
  数据: Q_p(H) 在 H <= 128 时恰为 0(!), 全场 Q_p(H)/(H+H^2/p) <= 0.28。

本轮任务(在 3/2 证明内部找任何显式 delta > 0——常数改进不要, 要指数):
1. 3/2 证明的账本审计: 块分割证明里哪一步最浪费? 具体地: 块内 O(L^2) 上界用的是
   "最坏情形所有 gap 全饱和 R_h = 3(h-1)"——但 sum_{h<=L} R_h 的真实值 = 碰撞总数
   S_p(L) 有没有已证的优于 L^2 的界? 注意我们已证 H <= 128 时 Q_p = 0 是经验而非定理——
   但"deg 界 + 相继互素 + 结式公式"能否给出某个小范围 h <= h_0(p) 的无条件 R_h 界优于 3(h-1)?
   哪怕 h_0 = log p、界是 O(h/log h), 插进块分割就是 delta > 0。请把这条账算穿。
2. 混合杠杆: 块分割(3/2) 与一致重数(2/3 界)是两个独立机制, 现有证明只用其一优化。
   二者联合(比如: 重数大的 v 贡献用 2/3 界控, 重数小的 v 块内控)的最优插值指数是多少?
   请设 max mult = p^theta 做参数化优化, 算出 E^pi << p^{f(theta)} 的显式 f, 然后代入
   已证 theta <= 2/3——若 f(2/3) < 3/2 就直接赢了; 若 = 3/2 请指出卡点在哪个不等式。
3. 半轨道约化的免费收益: 镜像 2-对-1 是逐点代数恒等(非统计)。3/2 证明若在半轨道上做,
   常数减半; 但有没有结构性收益(镜像点对的碰撞同步性把有效 gap 集合减半 =>
   某处 2 变 sqrt2)? 请认真核算而非直觉。
4. 判决要求: 若 1-3 全部卡死, 请对每条给出精确的"卡死不等式"(哪一行, 为什么不可改进,
   反例或启发式), 这些将作为立项文档"3/2 是当前方法极限"的论证节。
