# Uniform parameter-C2 conjugacy lemma audit

## Verdict

The stated lemma is correct after one necessary correction: the hypothesis A_n=A_inf+O(n^-2) is not the natural form for the Apery cell recurrence. The actual transfer matrix has a generally nonzero 1/n term. The correct conclusion uses the Benzaid-Lutz weak dichotomy form: remove the diagonal 1/n drift first, then apply the summable remainder theorem.

## Corrected normal form

Write

```javascript
A_n(z)=A_inf + B_1(z)/n + B_2(z)/n^2 + O(n^-3)
```

uniformly in C^2(K). Choose an analytic eigenbasis of A_inf, with eigenvalues lambda,lambda^-1. The diagonal part of B_1 produces exponents

```javascript
D(z)=diag(d_+(z),d_-(z))
```

and the fundamental solutions have the form

```javascript
u_+(n,z)=lambda^n n^{d_+(z)}(v_+(z)+O(1/n))
u_-(n,z)=lambda^{-n} n^{d_-(z)}(v_-(z)+O(1/n)).
```

The off-diagonal part is removed by a near-identity C^2 conjugacy because the spectral gap makes the homological equation invertible.

## Parameter uniformity

The fixed point construction is on the Banach space of sequences with norm

```javascript
||X|| = sup_n n ||X_n||_{C^2(K)}.
```

The contraction constant depends only on:

```javascript
sup ||B_2||_{C^2}, spectral gap |lambda-lambda^-1|, and the compact set K.
```

It is therefore uniform in z. Differentiating the fixed point equation once gives the same Volterra operator with an inhomogeneous source controlled by ||partial_z E_n||; differentiating twice gives the same argument with the quadratic derivative terms. Hence:

```javascript
||r_n||_{C^2(K)} <= C/n.
```

This is the needed strengthening of the fixed-z asymptotic integration theorem.

## Consequence for the cell function

For the two-sided cell near pole -j, after rescaling:

```javascript
N_h = prefactor(j,h) * K_h(z) * (1+O(1/j)+O(1/(h-j))).
```

The conjugacy gives

```javascript
||K_h-K_inf||_{C^2(K)} <= C(1/j+1/(h-j)).
```

with

```javascript
K_inf(z)=phi(-z)phi(z)+z^6 gamma(-z)gamma(z).
```

## Apery verification

The raw companion matrix does not satisfy the original O(n^-2) assumption. Expanding rational recurrence coefficients gives

```javascript
A_n(z)=A_inf+B_1(z)/n+O(n^-2).
```

Therefore the required input is the weak Benzaid-Lutz reduction, not the stronger summable perturbation theorem. The logarithmic/power corrections are harmless because they are explicit and cancel in normalized critical-value comparisons.

## Critical structure computation recipe

Compute phi,gamma by recurrence expansion in 1/lambda:

1. diagonalize A_inf.

1. solve the recurrence coefficient-by-coefficient for the Perron and contracting solutions.

1. truncate at order N.

1. form

```javascript
K_N(z)=phi_N(-z)phi_N(z)+z^6 gamma_N(-z)gamma_N(z).
```

1. solve K_N'(z)=0 and evaluate K_N at roots.

Required machine checks:

```javascript
min |K_N''(critical point)| > 0
min |K_N(a)-K_N(b)| > 0 for distinct critical points.
```

These give the simple-critical and nonresonance constants.

## Certificate+asymptotics squeeze

```javascript
C_asym : C^2 convergence constant

```

Choose h0 satisfying


## Least-confident step

The least-confident step is not the parameter differentiation argument; it is the explicit computation of the Apery B_1(z) term and proving that all induced power exponents are compatible with the chosen cell normalization.

## Blind spot

The blind spot is assuming the stronger O(n^-2) conjugacy theorem applies directly. The Apery recurrence naturally carries a 1/n asymptotic drift, so the correct object is a renormalized Benzaid-Lutz normal form, not a pure summable perturbation.
