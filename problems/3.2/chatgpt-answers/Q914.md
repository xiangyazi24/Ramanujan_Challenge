# Fixed-core hypergeometric attack: exact Kummer strata and a sharp first-order saturation theorem

## Executive verdict

Let

```plain text
n = 3H+1,
A_n = sum_(k=0)^n binom(n,k)^2 binom(n+k,k)^2,
B_H = binom(3H+1,H+1),
T_H = rad_(p>2H) gcd(A_n,B_H).
```

The desired theorem is

```plain text
log T_H = o(H).
```

I do not obtain such a theorem from a termwise WZ/creative-telescoping identity. I obtain an exact local decomposition and a sharp saturation result explaining why every first-order fixed-core identity falls back to the original moving zero.

The decisive facts are:

1. For every candidate prime

```plain text
p = n-j,
0 <= j <= H,
p > 2H,
```

the Apéry summand has exactly two Kummer-unit blocks: k=b and k=p+b, 0<=b<=j. Every other summand is divisible by p^2 after squaring.

1. On the two unit blocks,

```plain text
L_n(b)       = L_j(b)       (mod p),
L_n(p+b)     = 2 L_j(b)     (mod p),
```

where

```plain text
L_m(k)=binom(m,k)binom(m+k,k).
```

Consequently

```plain text
A_(p+j) = 5 A_j   (mod p).
```

This is the complete first-order information. The middle Kummer strata supply no independent condition.

1. Every candidate prime divides B_H exactly once:

```plain text
v_p(B_H)=1.
```

Thus, after clearing any rational coefficients whose denominators are supported on primes <=2H, every identity

```plain text
E_H = u_H A_(3H+1) + v_H B_H
```

satisfies

```plain text
E_H = 5 u_H A_j   (mod p).
```

If u_H is a unit at every candidate prime, then the candidate-window support of E_H is exactly the target support. This is a re-encoding, not a height saving.

1. If u_H=0, the identity retains the whole carrier interval. Its large-prime radical has

```plain text
log rad_(p>2H)(B_H)
  = theta(3H+1)-theta(2H)
  = H+o(H).
```

If u_H is nonzero and candidate-prime-unit, proving |E_H|=exp(o(H)) is already a complete solution of the original target.

1. A Gosper/WZ antidifference for the Apéry summand alone cannot have only fixed endpoint terms with polynomial or subexponential prefactors. The endpoint hypergeometric scale is at most 16^n up to subexponential factors, whereas

```plain text
A_n = (17+12 sqrt(2))^(n+o(n)).
```

The first unavoidable boundary is therefore the surviving low/high Kummer block carrying 5A_j; it cannot be replaced by the middle stratum.

1. The multi-hit auxiliary form

```plain text
E = sum_r c_r (product_(i!=r) p_i) A_(j_r)
```

is exactly saturated by the selected prime product. Every p_r divides E, hence

```plain text
product_r p_r | E.
```

Any nonzero such integer already has logarithm at least the target weight. Dividing by the product removes the selective divisibility and makes the construction circular.

1. Derivatives, reflection, and Hermite interpolation do not add local rank. The condition p|A_j supplies one scalar zero. It does not force an index derivative, a companion value, or a contiguous Apéry value to vanish. Hermite multiplicity therefore increases Vandermonde/factorial cost without increasing selective p-adic order.

The definite verdict is:

The fixed-core factorial decomposition is exact, but its first-order local quotient has rank one. Every admissible linear WZ/finite-difference identity either retains the full binomial carrier or produces an integer whose candidate support is exactly the original moving-zero support. No subexponential boundary follows from termwise Kummer stratification alone.

The route can be reopened only with a genuinely new second local condition—such as a selective mod-p^2 relation not paid for by universal finite-difference factors—or an explicit WZ boundary whose cleared integer height is proved exp(o(H)).

# 1. Exact factorial summand

Put

```plain text
F_n(k)
  = binom(n,k)^2 binom(n+k,k)^2
  = [ (n+k)! / (k!^2 (n-k)!) ]^2.
```

Then

```plain text
A_n = sum_(k=0)^n F_n(k).
```

Fix a candidate prime

```plain text
p=n-j,
0<=j<=H,
n=p+j,
p>2H>=2j.
```

Write

```plain text
L_n(k)=binom(n,k)binom(n+k,k),
F_n(k)=L_n(k)^2.
```

Since n<2p, every k has one of the forms

```plain text
k=b,
0<=b<p,
```

or

```plain text
k=p+b,
0<=b<=j.
```

## Lemma 1.1 — exact unit strata

For 0<=b<=j,

```plain text
L_(p+j)(b) = L_j(b) (mod p),
L_(p+j)(p+b) = 2 L_j(b) (mod p).
```

For j<k<p,

```plain text
p | L_(p+j)(k).
```

Therefore

```plain text
p^2 | F_(p+j)(k)
```

for every j<k<p.

### Proof

For the low block, Lucas gives

```plain text
binom(p+j,b) = binom(j,b) (mod p),
```

and, because j+b< p,

```plain text
binom(p+j+b,b)=binom(j+b,b) (mod p).
```

Thus the first congruence follows.

For the high block,

```plain text
binom(p+j,p+b)=binom(j,b) (mod p),
```

while the base-p digits of 2p+j+b and p+b give

```plain text
binom(2p+j+b,p+b)
 = binom(2,1) binom(j+b,b)
 = 2 binom(j+b,b) (mod p).
```

If j<k<p, the first binomial binom(p+j,k) has lower digit k>j and hence vanishes modulo p. Squaring proves the p^2 statement. ∎

## Corollary 1.2 — complete first-order block reduction

Split

```plain text
A_(p+j)
  = sum_(b=0)^j F_(p+j)(b)
    + sum_(k=j+1)^(p-1) F_(p+j)(k)
    + sum_(b=0)^j F_(p+j)(p+b).
```

Modulo p,

```plain text
first block  = A_j,
middle block = 0,
last block   = 4 A_j.
```

Hence

```plain text
A_(p+j)=5A_j (mod p).
```

Equivalently, there is an integer R_(p,j) such that

```plain text
A_(p+j)=5A_j+p R_(p,j).
```

The quotient R_(p,j) contains the first Lucas defects of the two unit blocks. The middle block begins only at order p^2; it cannot supply a second first-order equation.

# 2. Exact carrier valuation

For

```plain text
B_H=binom(3H+1,H+1)
    =(3H+1)!/((H+1)!(2H)!),
```

and a candidate prime 2H<p<=3H+1,

```plain text
v_p((3H+1)!)=1,
v_p((H+1)!)=0,
v_p((2H)!)=0.
```

Therefore

```plain text
v_p(B_H)=1.
```

Conversely every prime in (2H,3H+1] divides B_H once. Thus

```plain text
rad_(p>2H)(B_H)
  = product_(2H<p<=3H+1) p,
```

and the prime number theorem gives

```plain text
log rad_(p>2H)(B_H)
  = H+o(H).
```

The full Archimedean height is larger:

```plain text
log B_H
  = H log(27/4)+O(log H),
```

because

```plain text
log binom(3H,H)
  = 3H h(1/3)+O(log H)
  = H log(27/4)+O(log H).
```

So the carrier has candidate radical rate 1 and integer height rate log(27/4)=1.909542... per H.

# 3. Exact saturation of every cleared linear identity

Let

```plain text
U_H=u_H/D_H,
V_H=v_H/D_H,
```

where u_H,v_H,D_H are integers and every prime divisor of D_H is at most 2H. Clearing denominators gives

```plain text
E_H=u_H A_(3H+1)+v_H B_H in Z.
```

For a candidate p=n-j, the denominator is a p-unit and

```plain text
E_H
  = u_H A_n+v_H B_H
  = 5u_H A_j (mod p).
```

## Theorem 3.1 — candidate-window ledger

For every candidate prime p=n-j,

```plain text
p|E_H
iff
p|u_H A_j.
```

Therefore:

```plain text
if p does not divide u_H:
    p|E_H iff p|A_j;

if p divides u_H:
    p|E_H regardless of A_j.
```

In particular, if

```plain text
gcd(u_H, product_(2H<p<=3H+1)p)=1,
```

then

```plain text
rad_(2H<p<=3H+1)(E_H)=T_H.
```

This is an exact equivalence. A bound

```plain text
0<|E_H|=exp(o(H))
```

would immediately prove the desired theorem, but no part of the factorial reduction bounds this integer.

If u_H=0, then E_H=v_HB_H retains every candidate prime and has candidate radical exp(H+o(H)) unless v_H=0.

## Corollary 3.2 — short families do not add local rank

For a finite family

```plain text
E_(H,r)=u_(H,r)A_n+v_(H,r)B_H,
1<=r<=R,
```

with every u_(H,r) a candidate-prime unit,

```plain text
rad_candidate gcd_r E_(H,r)=T_H.
```

Thus several identities can remove good-prime pollution but do not strengthen the local target condition. Any nonzero member of subexponential height would already solve the theorem by itself.

# 4. What a WZ telescoper must leave at the boundary

Suppose a termwise construction produces

```plain text
u_H F_(3H+1)(k)+v_H G_H(k)
  = Delta_k R_H(k),
```

where

```plain text
sum_k G_H(k)=B_H,
```

and all cleared denominators are supported on primes <=2H. Summing gives

```plain text
u_H A_(3H+1)+v_H B_H
  = R_H(k_max+1)-R_H(k_min).
```

At a candidate prime, the exact Kummer split from Section 1 shows:

```plain text
middle stratum contributes 0 modulo p;
low plus high strata contribute 5u_H A_j modulo p;
carrier contributes 0 modulo p.
```

Therefore the boundary difference satisfies

```plain text
R_H(k_max+1)-R_H(k_min)
  =5u_H A_j (mod p).
```

This identifies the first unavoidable boundary term. A telescoper can reorganize the summation, but modulo the candidate prime it cannot replace the surviving scalar A_j by a second independent quantity.

## 4.1 No rational Gosper antidifference for the Apéry summand alone

Assume, for contradiction, that

```plain text
F_n(k)=G_n(k+1)-G_n(k),
G_n(k)=R(n,k)F_n(k),
```

with R(n,k) rational and with endpoint values having only polynomial or subexponential prefactors relative to F_n(0) and F_n(n). Summing would express A_n through endpoint scales

```plain text
F_n(0)=1,
F_n(n)=binom(2n,n)^2=16^(n+o(n)).
```

But

```plain text
A_n=(17+12sqrt(2))^(n+o(n)),
17+12sqrt(2)>16.
```

This is impossible. Hence a WZ proof must either use coefficients of exponential size, introduce additional interior boundaries, or retain a nontrivial sum. The first nonremovable interior boundary is precisely the low/high Kummer block above.

# 5. Exact failure of the multi-hit auxiliary form

Let selected distinct candidate primes be

```plain text
p_r=n-j_r,
p_r|A_(j_r),
1<=r<=K,
```

and put

```plain text
P=product_(r=1)^K p_r.
```

Consider

```plain text
E=sum_(r=1)^K c_r (P/p_r) A_(j_r),
```

with integers c_r.

Fix p_t. Every term with r!=t contains the explicit factor p_t. The remaining term contains A_(j_t), which is divisible by p_t. Therefore

```plain text
p_t|E
```

for every t, and hence

```plain text
P|E.
```

If E!=0, then

```plain text
log|E|>=log P=sum_r log p_r.
```

Thus this construction cannot prove that the target weight is smaller than the logarithm of its own certificate; it reproduces the target product exactly.

Writing

```plain text
E=P * sum_r c_r A_(j_r)/p_r
```

makes the saturation explicit. Dividing by P removes the selective divisibility and leaves an arbitrary integer linear form. Any proof that the quotient is zero or small is already an independent relation among the selected Apéry values.

The same argument applies to determinant analogues: if one target factor is inserted once in each complementary cofactor, the determinant is divisible by the full selected product. Exterior degree increases local multiplicity and determinant degree together.

# 6. Why reflection, derivatives, and the companion do not cross the barrier

## 6.1 Reflection

The interpolation identity

```plain text
A(z)=A(-1-z)
```

pairs a zero at j modulo p with the reflected index p-1-j. It does not create a second independent value at the direct outer index n=p+j. Both reductions carry the same scalar A_j.

## 6.2 Index derivatives

A value zero does not force

```plain text
A'(j)=0 (mod p).
```

The repository's exact derivative scans and mod-p^2 audits exhibit simple zeros. Therefore a Hermite condition has only one selective row; derivative rows are generally units.

## 6.3 Companion solution

Let C_j be the classical companion. Its Casoratian satisfies

```plain text
C_(j+1)A_j-C_jA_(j+1)=6/(j+1)^3.
```

For p>2H>=2j, the right side is a p-unit. Hence

```plain text
p|A_j
implies
p does not divide C_j,
p does not divide A_(j+1).
```

So the companion and contiguous values explicitly fail to provide another zero.

## 6.4 Hermite interpolation cost

For irregular selected nodes j_1,...,j_K, ordinary divided differences have denominators

```plain text
product_(r<s)(j_s-j_r).
```

These differences are candidate-prime units because their absolute values are at most H<p. Clearing them preserves the one existing p-factor but creates no new one. Repeating nodes through derivatives raises the confluent Vandermonde and factorial cost while the selective valuation remains one. Thus multiplicity does not improve the normalized local ledger.

from math import comb


def apery_mod(m, p):
    return sum(
        comb(m,k)**2 * comb(m+k,k)**2
        for k in range(m+1)
    ) % p


def check(H, p):
    n = 3*H + 1
    j = n-p
    assert 0 <= j <= H
    assert p > 2*H

    low = sum(
        (comb(n,b)*comb(n+b,b))**2
        for b in range(j+1)
    )
    middle = sum(
        (comb(n,k)*comb(n+k,k))**2
        for k in range(j+1,p)
    )
    high = sum(
        (comb(n,p+b)*comb(n+p+b,p+b))**2
        for b in range(j+1)
    )

    assert low % p == apery_mod(j,p)
    assert middle % (p*p) == 0
    assert high % p == 4*apery_mod(j,p) % p
    assert comb(n,H+1) % p == 0
    assert (low+middle+high) % p == 5*apery_mod(j,p) % p


check(5,11)
check(74,193)
check(80,197)

# 8. Sharp no-go theorem for the fixed-core first-order class

Define a first-order fixed-core certificate to be any nonzero integer obtained after:

```plain text
1. taking finitely many hypergeometric summands contiguous to F_(3H+1)(k);
2. applying rational finite differences in k and H;
3. clearing denominators supported on primes <=2H;
4. summing over fixed H-dependent ranges;
5. retaining only A_(3H+1), B_H, and boundary terms whose
   candidate-prime reduction is determined by the Kummer blocks.
```

## Theorem 8.1 — rank-one saturation

For every such certificate E_H, its reduction at a candidate prime has the form

```plain text
E_H = c_H(p,j) A_j (mod p),
```

where c_H(p,j) is an explicitly computable scalar. If c_H(p,j) is a unit throughout the candidate window, then

```plain text
p|E_H iff p|A_j.
```

If c_H(p,j)=0 for all candidates, the certificate is supported on the universal carrier and retains every candidate prime.

### Proof

Every middle summand is zero modulo p. The surviving low and high blocks reduce termwise to 1 and 4 times the same lower Apéry summand. Rational finite differences and contiguous combinations act linearly on these two blocks. Hence the entire first-order reduction is a scalar multiple of their common sum A_j. The carrier itself is zero modulo p. No other local coordinate survives. ∎

This theorem is sharp: the identity A_n=5A_j mod p realizes a unit scalar, while B_H=0 mod p realizes the universal-carrier case.

It does not exclude a genuinely second-order construction. To escape, one needs one of:

```plain text
- a mod-p^2 quotient relation whose new coordinate vanishes selectively
  when A_j=0;

- a boundary integer E_H with exact nonzero proof and
  log|E_H|=o(H);

- two local congruences whose determinant has selective order two but
  whose cleared Archimedean height is o(H) per selective copy.
```

The existing Frobenius-jet audits show that the obvious derivative and ray quotients are new states, not new zeros.

# 9. Final verdict

The special factorial pair does admit a complete termwise audit. It explains the Lucas factor 5, identifies every Kummer valuation stratum, and proves that the fixed binomial carrier has exactly one copy of every candidate prime.

What it does not do is compress the moving-zero radical. At first order, the local space is one-dimensional:

```plain text
surviving local coordinate = A_j.
```

Every admissible linear identity therefore has one of two outcomes:

```plain text
unit coefficient of A_j:
    candidate support is exactly T_H;

zero coefficient of A_j:
    the full candidate carrier survives.
```

The first case is equivalent to the desired theorem once a subexponential height bound is requested; the second has linear radical weight. The multi-hit, Hermite, reflection, companion, and ordinary WZ variants do not alter this ledger.

Accordingly, the fixed-core hypergeometric route is closed at first order. The weakest meaningful reopening lemma is:

```plain text
There exist cleared hypergeometric boundary integers E_H != 0 such that

    rad_(2H<p<=3H+1)(E_H)=T_H

and

    log|E_H|=o(H).
```

A stronger local reopening would be a selective second-order congruence not generated by the universal Lucas defect. Neither statement is currently proved.
