# 1. Newton interpolation identity

By Newton interpolation,

```plain text
F_H(x)
 = sum_(k=0)^H Delta^k A_0 binom(x,k)
```

is the unique polynomial of degree at most H satisfying

```plain text
F_H(s)=A_s,
0<=s<=H.
```

The constant coefficient is A_0=1, so

```plain text
content(F_H)=1.
```

Also N_H is monic, hence primitive. Unlike the Padé numerators, the fixed pair has no removed global content to track.

For later use,

```plain text
N_H(n)
 = product_(s=0)^H (3H+1-s)
 = (3H+1)!/(2H)!
 = (H+1)! binom(3H+1,H+1).
```

For every candidate prime 2H<p<=3H+1,

```plain text
v_p(N_H(n))=1,
v_p((H+1)!)=0,
v_p binom(3H+1,H+1)=1.
```

Thus N_H(n) and the smaller binomial carrier have identical candidate-window support and valuation.

# 2. Exact modular gcd

Fix a prime p>H. The node differences satisfy

```plain text
0<|r-s|<=H<p,
```

so the linear factors x-s, 0<=s<=H, are pairwise coprime in F_p[x]. Since

```plain text
F_H(s)=A_s,
```

one has

```plain text
x-s divides F_H mod p
iff p divides A_s.
```

Therefore

```plain text
D_p(x)
 := gcd_Fp[x](F_H,N_H)
 = product_(s in Z_p(H)) (x-s),

Z_p(H):={s in [0,H]:p|A_s}.
```

This proves the stated modular gcd formula with no genericity or normality hypothesis.

# 10. Reproducible Sage test

```python
from sage.all import ZZ, PolynomialRing, binomial, gcd, prime_range

R = PolynomialRing(ZZ, 'x')
x = R.gen()


def apery(n):
    return ZZ(sum(binomial(n,k)^2 * binomial(n+k,k)^2
                  for k in range(n+1)))


def newton_coefficients(H):
    vals = [apery(s) for s in range(H+1)]
    cur = vals[:]
    out = []
    while cur:
        out.append(ZZ(cur[0]))
        cur = [cur[i+1]-cur[i] for i in range(len(cur)-1)]
    return out


def falling_binomial_poly(k):
    if k == 0:
        return R(1)
    return R(prod(x-r for r in range(k)) / ZZ(k).factorial())


def fixed_pair(H):
    c = newton_coefficients(H)
    F = sum(c[k] * falling_binomial_poly(k) for k in range(H+1))
    N = prod(x-s for s in range(H+1))
    return R(F), R(N)


def check(H):
    F, N = fixed_pair(H)
    n = 3*H+1

    assert F.content() == 1
    assert N.is_monic()
    for s in range(H+1):
        assert F(s) == apery(s)

    for p in prime_range(H+1, n+1):
        Fp = F.change_ring(GF(p))
        Np = N.change_ring(GF(p))
        g = Fp.gcd(Np).monic()

        roots = [s for s in range(H+1) if apery(s) % p == 0]
        expected = prod(Fp.parent().gen()-s for s in roots)
        if roots:
            expected = expected.monic()
        else:
            expected = Fp.parent()(1)
        assert g == expected

        if 2*H < p <= n:
            j = n-p
            target = (apery(j) % p == 0)
            assert (F(n) % p == 0) == target
            assert (g(n % p) == 0) == target

            # Sage subresultant sequence order may be implementation-specific;
            # select its last nonzero member modulo p and compare with gcd.
            seq = Fp.subresultants(Np)
            nz = [S for S in seq if S != 0]
            assert nz
            first_gcd_like = min(nz, key=lambda S: S.degree()).monic()
            assert first_gcd_like == g
            assert (first_gcd_like(n % p) == 0) == target

    B = binomial(n,H+1)
    target_rad = ZZ(1)
    for p in prime_range(2*H+1,n+1):
        if apery(n-p) % p == 0:
            target_rad *= p

    core = gcd(ZZ(F(n)), ZZ(B)).radical()
    window_core = ZZ(1)
    for p in prime_range(2*H+1,n+1):
        if core % p == 0:
            window_core *= p
    assert window_core == target_rad


for H in range(1,31):
    check(H)

print('fixed-pair gcd, subresultant, and marked Fitting identities passed')
```

# 11. Failure mechanisms

## Failure 1: ordinary resultant

Already closed by Q890. It detects

```plain text
exists s<=H with p|A_s
```

and forgets the marked node.

## Failure 2: varying first subresultant as a separate invariant

Once evaluated at a point already lying on N_H=0, it collapses to

```plain text
F_H(n)=0.
```

The varying gcd degree adds no arithmetic condition.

## Failure 3: principal-subresultant coefficient products

These encode the number of prefix zeros. Multiplying or taking gcds of them reintroduces vertical zero-count information and unmarked saturation. Saturating by the first nonzero principal coefficient returns the marked ideal (F_H(n),N_H(n)).

## Failure 4: recurrence-only simplification

The four-step recurrence reduces storage and proves holonomicity, but no known Bézout identity turns F_H(n) into an integer of sublinear height while preserving all candidate factors.

## Failure 5: comparison with Padé family

The fixed pair and growing family have equal candidate-window support, not a proved integer divisibility. Universal Smith/interpolation algebra cannot convert support equality into a small gcd.

# 12. Weakest remaining theorem

The fixed-subresultant route closes Problem 3.2 exactly if one proves

```plain text
log rad_(2H<p<=3H+1)
    gcd(F_H(3H+1), binom(3H+1,H+1))
 = o(H).
```

Equivalently, using N_H(n),

```plain text
log rad_(2H<p<=3H+1)
    Fitt_0( Z[x]/(F_H,N_H,x-(3H+1)) )
 = o(H).
```

This is the sharp marked-root core. It is strictly simpler to state than the growing-family bordered-minor lemma, but it is not weaker arithmetically: both candidate-window radicals are exactly the direct q=1 target.

A genuine advance must therefore prove an Apéry-specific gcd estimate between the Newton interpolant value and the binomial carrier, or an exact recurrence identity producing a smaller marked representative. The subresultant chain alone has been completely saturated.
