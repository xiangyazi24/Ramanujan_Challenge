# 3. Audit of the first harmonic defects

All formulas in this section are identities in \mathbf Z_{(p)}.

## 3.1 No-carry Lucas defect

Assume

```plain text
0<=q<=(p-1)/2,
0<=a<=q,
0<=b<=j:=min(r,p-1-r).
```

Then b\le r, r+b<p, and q+a<p. Every displayed harmonic denominator is a p-adic unit. Put

```plain text
Phi_(q,r;a,b)
 := (q+a)H_(r+b)
    -(q-a)H_(r-b)
    -2aH_b.
```

The audited formula is

```plain text
lambda_(q,r;a,b)
 = L(q,a)L(r,b)Phi_(q,r;a,b)                (mod p).
```

It follows from

```plain text
binom(qp+r,ap+b)
 /[binom(q,a)binom(r,b)]
 = 1+p[qH_r-aH_b-(q-a)H_(r-b)]             (mod p^2),
```

and

```plain text
binom((q+a)p+r+b,ap+b)
 /[binom(q+a,a)binom(r+b,b)]
 = 1+p[(q+a)H_(r+b)-aH_b-qH_r]             (mod p^2).
```

For b>j, a Lucas principal factor vanishes. The normalized carry term \lambda\bmod p remains explicit, but it is a first-defect coordinate and is not controlled by A_j=0.

## 3.2 Binomial-translation defect

For 1\le m<p, define

```plain text
beta_m(b)
 := d/dx binom(x,m) at x=b.
```

Explicitly,

```plain text
beta_m(b)
 = binom(b,m)(H_b-H_(b-m))
                                  if m<=b,

beta_m(b)
 = (-1)^(m-b-1)/[m binom(m-1,b)]
                                  if b<m<p.
```

Then

```plain text
binom(ap+b,m)
 = binom(b,m)+ap beta_m(b)                  (mod p^2),
```

and therefore

```plain text
mu_(a,b)(c)
 = a sum_(m=0)^(p-1)
       beta_m(b)c^(ap+b-m)g_m(c)            (mod p).
```

This formula is correct. The m>b part is indispensable: \binom{x}{m} has a simple zero at x=b, not a double zero.

## 3.3 Harmonic-scope correction

For the constant derivative below, expressions such as

```plain text
L(r,m)(H_(r+m)-H_(r-m))
```

remain valid when r+m\ge p, but the product must be evaluated as one p-integral rational number. The factor L(r,m) cancels the possible 1/p denominator. It is not legitimate to reduce H_{r+m} and L(r,m) separately modulo p.

# 10. All-order saturation for the constant coefficient

Let R=\mathbf Z_{(p)}, let f\in R[X], and put

```plain text
s_q:=f(r+pq),
d_m:=Delta^m s_0.
```

## Theorem 10.1: universal finite-difference filtration

For every m\ge0,

```plain text
p^m divides d_m.
```

More exactly,

```plain text
d_m
 = sum_(nu>=m)
     p^nu m! S(nu,m) f^(nu)(r)/nu!,
```

where S(\nu,m) is the Stirling number of the second kind. For m<p,

```plain text
d_m/p^m=f^(m)(r)                            (mod p).
```

The normalized jets d_m/p^m, 0\le m<h<p, are algebraically independent in the universal polynomial class: arbitrary values in \mathbf F_p are realized by a polynomial of degree at most h.

## Theorem 10.2: selective-degree saturation

Give d_m universal weight m. Let

```plain text
I(d_0,...,d_h)
```

be a polynomial of ordinary degree at most D. Remove its maximal universal power of p, as determined by the minimum weighted degree of its monomials. On the bad locus

```plain text
d_0=f(r)=0 mod p,
```

the additional order forced solely by badness is the order of vanishing of the initial polynomial along the hyperplane d_0=0. It is at most D.

Equivalently:

```plain text
selective p-order after universal saturation
    <= ordinary degree of the invariant.
```

Any larger order means that the initial polynomial vanishes identically in the normalized higher jets. That is a new algebraic relation, not a consequence of Taylor expansion, finite differences, Dwork congruences, or the single equation A_r=0.

This theorem closes scalar finite differences, Hankel determinants, discrete Wronskians, Hessians, discriminants, and Schwarzian numerators derived only from the ray values S_q.

# 11. All-order saturation for the full cutoff rows

Write the singular expansion formally as

```plain text

  = a Q_q(c^p)
    +pE_(q,1)(c)
    +p^2E_(q,2)(c)
    +...,
```

Let I(F_{q_1},\ldots,F_{q_t}) be a polynomial invariant that is multihomogeneous of row degrees d_1,\ldots,d_t, and put

```plain text

```

On a bad fiber, write a=pu. Every monomial of I contains exactly D row factors. Choosing a principal factor aQ_q contributes one p, while choosing a defect factor pE_{q,1} also contributes one p. Hence

```plain text
p^D divides I(F_(q_1),...,F_(q_t))
```

for every bad fiber. After division by p^D, its initial form is an explicit polynomial in

```plain text
u=A_r/p,
Q_q,
E_(q,1),
E_(q,2), ... .
```

There is no formal mechanism that supplies a (D+1)-st selective factor. Such a factor is equivalent to vanishing of this initial form on the actual singular jet tuple.

For determinants, D is the matrix size. Thus

```plain text
t rows -> at most p^t forced by A_r=0;
```

and Q777’s exterior-power order is optimal in the formal jet algebra.

## Independence hypothesis needed for a complete actual-array no-go

To rule out every conceivable invariant for the distinguished Apéry array, one would need the following horizontal noncontainment theorem.

```plain text
Singular-jet independence (SJI_D,h):

For every nonzero polynomial P of degree <=D in the normalized
jet coordinates, modulo the universal block identities, there exists
an actual bad pair (p,r) with p>h such that

    P(Jet_h(p,r)) != 0 mod p.
```

This is not known. It is a cross-characteristic arithmetic theorem about the fixed Apéry initial state, not a local Dwork theorem.

# 12. Height and the different reopen lemma

Universal finite-difference powers do not improve the global height ratio. At the moving cutoff J=p, a universal factor p^w globalizes through a carrier containing J^w. The least common multiple already has

```plain text
log lcm(1,...,n)^w=(1+o(1))wn.
```

For full row invariants of degree D, the local selective order is at most D, while standard coefficient bounds give exponential height \exp(O(Dn)). Factorial, Vandermonde, and Hasse normalizations remove universal powers but do not change this degree/order ratio.

The higher-Frobenius-jet route should therefore be reopened only after an actual singular-jet relation is proved. A genuinely different route is the short-gap pair theorem isolated in Q589.

Let m_D(n,h) and m_R(n,h) count direct/direct and reflected/reflected pairs of q=1 hits whose folded indices differ by h. The following uniform theorem would suffice:

```plain text
For every h<=n^(1/3),

    m_D(n,h)+m_R(n,h) <= h n^(o(1)).
```

Indeed, if K hits lie in an interval of length O(n), at least K/2 adjacent gaps are at most 2n/K. Summing the proposed bound through that threshold gives

```plain text
K <= (n/K)^2 n^(o(1)),
```

hence

```plain text
K<=n^(2/3+o(1)).
```

The total q=1 logarithmic weight is then

```plain text
K log n=n^(2/3+o(1))=o(n).
```

This lemma concerns two different moving primes and cannot be reduced to repeated Frobenius jets of one prime. It is therefore a genuinely different reopen condition.

The following is a fail-closed standard-Python checker for the scalar p^3 Taylor law, the reflection correction, and the p=5 full-vector minors. It is supplied for execution in the canonical checkout; it was not run in this connector-only response.

```python
from fractions import Fraction
from math import comb


def C(n, k):
    return comb(n, k) if 0 <= k <= n else 0


def franel(n):
    return sum(C(n, k) ** 3 for k in range(n + 1))


def apery(n):
    return sum(C(n, k) ** 2 * C(n + k, k) ** 2
               for k in range(n + 1))


def L(n, k):
    return C(n, k) * C(n + k, k)


def H(n, power=1):
    return sum((Fraction(1, k ** power) for k in range(1, n + 1)),
               Fraction(0))


def coeff_T(N, J, d):
    if d == 0:
        return sum(L(N, i) * franel(i) for i in range(J + 1))
    lo = max(0, J - d + 1)
    hi = min(J, N - d)
    return sum(
        (-1) ** (J - i)
        * L(N, i + d)
        * C(i + d, i)
        * C(d - 1, J - i)
        * franel(i)
        for i in range(lo, hi + 1)
    ) if lo <= hi else 0


def cutoff_constant(N, p):
    return coeff_T(N, p - 1, 0)


def L_derivatives(p, r):
    D = Fraction(0)
    E = Fraction(0)
    for m in range(p):
        if m <= r:
            base = Fraction(L(r, m))
            d1 = H(r + m) - H(r - m)
            d2 = H(r - m, 2) - H(r + m, 2)
            lp = base * d1
            lpp2 = base * (d1 * d1 + d2) / 2
        else:
            alpha = Fraction((-1) ** (m - r - 1),
                             m * C(m - 1, r))
            base = C(r + m, m)
            lp = alpha * base
            lpp2 = alpha * base * (H(r + m) - H(m - r - 1))
        D += franel(m) * lp
        E += franel(m) * lpp2
    assert D.denominator % p != 0
    assert E.denominator % p != 0
    return D, E


def mod_fraction(x, modulus):
    assert x.denominator % modulus != 0
    return x.numerator * pow(x.denominator, -1, modulus) % modulus


def forward_difference(values):
    return [values[i + 1] - values[i] for i in range(len(values) - 1)]


def vp(x, p):
    x = abs(x)
    if x == 0:
        return 10 ** 9
    e = 0
    while x % p == 0:
        x //= p
        e += 1
    return e


def check_scalar_p3(p, r):
    D, E = L_derivatives(p, r)
    modulus = p ** 3
    vals = [cutoff_constant(q * p + r, p) for q in range(4)]
    for q, value in enumerate(vals):
        rhs = (apery(r)
               + q * p * mod_fraction(D, modulus)
               + q * q * p * p * mod_fraction(E, modulus))
        assert (value - rhs) % modulus == 0, (p, r, q)
    diffs = vals
    for m in range(1, 4):
        diffs = forward_difference(diffs)
        assert diffs[0] % (p ** m) == 0, (p, r, m)


def check_p5_bad_fiber():
    p, r = 5, 1
    vals = [cutoff_constant(q * p + r, p) for q in range(4)]
    assert vals == [5, 1_188_265, 159_262_225, 3_081_565_385]

    d1 = forward_difference(vals)
    d2 = forward_difference(d1)
    d3 = forward_difference(d2)
    assert vp(d1[0], 5) == 1
    assert vp(d2[0], 5) == 2
    assert vp(d3[0], 5) == 3
    schwarz = d1[2] * d1[0] - d1[1] ** 2
    assert vp(schwarz, 5) == 4

    M = []
    for q in (1, 2, 3):
        N = q * p + r
        M.append([(coeff_T(N, p - 1, a * p) // p) % p
                  for a in (0, 1, 2)])
    assert M == [[3, 4, 0], [0, 4, 3], [2, 2, 0]]
    det3 = (
        M[0][0] * (M[1][1] * M[2][2] - M[1][2] * M[2][1])
        - M[0][1] * (M[1][0] * M[2][2] - M[1][2] * M[2][0])
        + M[0][2] * (M[1][0] * M[2][1] - M[1][1] * M[2][0])
    ) % p
    assert det3 == 1
    assert (M[0][0] * M[1][1] - M[0][1] * M[1][0]) % p == 2


def primes_up_to(n):
    out = []
    for x in range(2, n + 1):
        if all(x % d for d in range(2, int(x ** 0.5) + 1)):
            out.append(x)
    return out


# Broad scalar audit: all residues and the first three rays.
for p in primes_up_to(43):
    if p == 2:
        continue
    for r in range(p):
        check_scalar_p3(p, r)

check_p5_bad_fiber()
print("all p^3 scalar jets and p=5 full-vector minors passed")
```

# Final conclusion

The prime-cube calculation does not reveal a hidden second or third selective Frobenius equation. It reveals a growing jet:

```plain text
constant coordinate:
    A_r, Acal_p'(r), Acal_p''(r)/2, ...;

full cutoff row:
    A_r Q_q, E_(q,1), E_(q,2), ... .
```

Finite differences isolate these states with universal powers of p. Polynomial and determinant invariants can convert one bad factor per homogeneous row degree, but no faster. The first actual bad fiber already saturates this bound in scalar differences, order-two and order-three Hasse minors, and a nonlinear Schwarzian numerator.

Therefore every higher same-prime Frobenius-jet attack is closed at the formal level. Reopening it requires a genuinely new algebraic relation among the actual singular jets across residue characteristics. The more distinct alternative is the horizontal short-gap pair theorem of Section 12.
