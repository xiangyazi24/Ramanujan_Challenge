# Adjacent Apéry–Padé gcds: an exact Apéry-core reduction and a theorem-hypothesis no-go

## Executive verdict

The requested estimate for one fixed interior slope remains unproved by the presently available theorems. What can be proved unconditionally is a sharper structural statement that uses the actual Apéry sequence, not merely interpolation:

1. Every adjacent numerator gcd contains a slope-independent Apéry core

```plain text
T_H = rad_{p>2H} gcd(A_{3H+1}, binom(3H+1,H+1)).
```

1. After dividing the radical of the adjacent gcd by this known factor, every remaining prime divides the adjacent constant kappa_b. Thus, for every fixed slope, the problem splits exactly into one fixed two-sequence gcd lemma plus one Padé-pollution lemma.

1. The Apéry core is exactly the direct q=1 moving-zero sum:

```plain text
log T_H
  = sum_{0<=j<=H} log rad_{p>2H} gcd(A_j, 3H+1-j)
  = sum_{
      0<=j<=H,
      p=3H+1-j prime,
      p | A_j
    } log p.
```

Consequently, a subexponential adjacent gcd for any interior value of theta necessarily proves the fixed two-sequence estimate

```plain text
log rad_{p>2H} gcd(
  A_{3H+1},
  binom(3H+1,H+1)
) = o(H).
```

No verified Corvaja–Zannier, moving-target Subspace-Theorem, or linear-recurrence gcd theorem covers this pair. The precise failures are fixed degree, fixed torus dimension, fixed S, and constant-coefficient recurrence hypotheses. The positive moment representation supplies a clean proof that the relevant sequences are not constant-coefficient recurrence sequences.

The small exact gcds through H=40 therefore have a two-sided interpretation. They are not explained by the universal adjacent identities, and their persistence for the distinguished state (A_0,A_1)=(1,5) is genuine arithmetic evidence. But radical-smallness can be reproduced by a hostile prime-local solution of the same Apéry transfer recurrence once the initial projective state is allowed to depend on p; the universal Padé identities can simultaneously keep every kappa_b a unit. Hence the finite data do not yet distinguish global cross-characteristic coherence from a local model.

## 1. Setup and the only Apéry inputs used

Write the Apéry numbers as

```plain text
A_m = sum_{k=0}^m binom(m,k)^2 binom(m+k,k)^2,
A_0=1, A_1=5,

(m+1)^3 A_{m+1}
  - (34m^3+51m^2+27m+5) A_m
  + m^3 A_{m-1}
  = 0.
```

Their generating function is a G-function satisfying Edgar's third-order Fuchsian equation

```plain text
z^2(z^2-34z+1)F'''(z)
 + 3z(2z^2-51z+1)F''(z)
 + (7z^2-112z+1)F'(z)
 + (z-5)F(z)
 = 0.
```

The arithmetic input needed below is the Apéry Lucas congruence. In the corrected range 0<=r<p,

```plain text
A_{pm+r} = A_m A_r  (mod p).
```

In particular, if n=p+j with 0<=j<p, then

```plain text
A_n = A_{p+j} = A_1 A_j = 5 A_j  (mod p).
```

For H>=3 and p>2H, the prime p is larger than 5, so

```plain text
p | A_n  <=>  p | A_j.
```

Now put

```plain text
n = 3H+1,
b = floor(theta H),
B_H = binom(n,H+1).
```

For each Padé index t, let (P_t,Q_t) be an integral Newton–Padé pair with

```plain text
deg P_t <= H-t,
deg Q_t <= t,
P_t(j) = A_j Q_t(j)  for 0<=j<=H.
```

All coefficients are understood in the binomial/Newton basis. No normality or one-dimensional-kernel hypothesis is needed for the support theorem below: any chosen nonzero integral pairs satisfying these interpolation and degree conditions suffice.

For adjacent indices, the universal identity is

```plain text
W_b(x)
 := P_b(x)Q_{b+1}(x)-P_{b+1}(x)Q_b(x)
  = kappa_b binom(x,H+1).
```

The proof below does not estimate kappa_b; it uses the identity only to classify the primes that are not in the Apéry core.

For an integer M, write

```plain text
rad_{p>y}(M) = product_{p>y, p prime, p|M} p.
```

Define

```plain text
U_H = P_b(n),
V_H = P_{b+1}(n),
R_H(theta) = rad_{p>2H} gcd(U_H,V_H),
T_H = rad_{p>2H} gcd(A_n,B_H).
```

## 2. Exact Apéry-core factorization

### Theorem 2.1 — Apéry-core factorization

For every H>=3, every 0<=b<H, and every adjacent integral interpolation pair as above, one has

```plain text
T_H | R_H(theta).
```

Consequently the squarefree quotient

```plain text
N_H(theta) = R_H(theta) / T_H
```

is an integer, coprime to T_H, and every prime divisor of N_H(theta) divides kappa_b. Equivalently,

```plain text
R_H(theta) = T_H N_H(theta),
gcd(T_H,N_H(theta))=1,
N_H(theta) | rad_{p>2H}(kappa_b)
```

whenever kappa_b is nonzero; if kappa_b=0, the last assertion means simply that every prime in the quotient is supported on the identically vanishing adjacent determinant.

Moreover,

```plain text
T_H
 = product_{j=0}^H rad_{p>2H} gcd(A_j,n-j)
 = product_{
     0<=j<=H,
     n-j prime,
     n-j | A_j
   } (n-j).
```

Thus T_H is precisely the direct q=1 moving-zero radical.

### Proof

Step 1: the large-prime support of the binomial coefficient

Use

```plain text
B_H
 = binom(3H+1,H+1)
 = ((2H+1)(2H+2)...(3H+1))/(H+1)!.
```

Let p>2H. The denominator is a p-adic unit. The numerator interval has length H+1<p, so it contains at most one multiple of p. Also 3H+1<2p for H>=2, so any such multiple is p itself. Therefore

```plain text
p | B_H
  <=>
there is a unique j in {0,...,H} with p=n-j,
```

and in that case

```plain text
v_p(B_H)=1.
```

Step 2: the Apéry core divides every Padé numerator value

Take p|T_H. By Step 1, p=n-j for a unique 0<=j<=H. Since n=p+j and j<p, the Lucas congruence gives

```plain text
A_n = 5A_j  (mod p).
```

Because p>5, the condition p|A_n implies p|A_j.

For every k<=H<p, Lucas' congruence for binomial coefficients gives

```plain text
binom(n,k) = binom(j,k)  (mod p).
```

Hence every integral Newton polynomial of degree at most H has the same value at n and j modulo p. In particular,

```plain text
P_t(n)
 = P_t(j)
 = A_j Q_t(j)
 = 0  (mod p)
```

for every Padé index t. Thus p divides both U_H and V_H, proving

```plain text
T_H | R_H(theta).
```

Notice that this is stronger than an adjacent statement: the same T_H divides the large-prime radical of the gcd of any finite Padé chain.

Step 3: every common prime outside the Apéry core divides kappa_b

Let p>2H divide both U_H and V_H, and suppose p does not divide T_H. Evaluating the adjacent identity at n yields

```plain text
0
 = kappa_b B_H  (mod p).
```

If p does not divide B_H, this immediately gives p|kappa_b.

Assume instead that p|B_H. Step 1 supplies the unique j with p=n-j. Since p is not in T_H, one has p not dividing A_n; the Apéry Lucas congruence then gives p not dividing A_j. Reducing the numerator interpolation congruences gives

```plain text
0 = P_b(n) = A_j Q_b(j)       (mod p),
0 = P_{b+1}(n) = A_j Q_{b+1}(j) (mod p),
```

so

```plain text
Q_b(j)=Q_{b+1}(j)=0  (mod p).
```

At the node j, interpolation also gives P_b(j)=P_{b+1}(j)=0 modulo p. Differentiate the adjacent identity and evaluate at x=j. Every term on the derivative of the left side contains one of these four zero values, hence

```plain text
0
 = kappa_b * (d/dx binom(x,H+1))|_{x=j}
   (mod p).
```

The derivative is

```plain text
(d/dx binom(x,H+1))|_{x=j}
 = (-1)^(H-j) j!(H-j)!/(H+1)!.
```

All factorials involve integers smaller than p, so this is a p-adic unit. Therefore p|kappa_b.

We have proved that every prime in R_H(theta) but not in T_H divides kappa_b. Since both radicals are squarefree, the asserted factorization follows.

Step 4: the moving-divisor identity

If p>2H divides both A_j and n-j, then

```plain text
2H < p <= n-j <= 3H+1 < 2p.
```

Thus n-j=p; in particular, n-j is prime. Conversely, every direct prime p=n-j with p|A_j contributes to the displayed gcd. Different j give different primes. This proves

```plain text
T_H
 = product_{j=0}^H rad_{p>2H} gcd(A_j,n-j).
```

Together with Steps 1 and 2, this is also exactly

```plain text
T_H = rad_{p>2H} gcd(A_n,B_H).
```

This completes the proof.

## 3. The weakest exact replacement for the adjacent-gcd conjecture

Theorem 2.1 separates the desired statement into two nonnegative logarithmic terms:

```plain text
log R_H(theta)
  = log T_H + log N_H(theta).
```

Therefore, for a fixed theta in (0,1), the requested estimate is equivalent to the conjunction of the following two lemmas.

### Lemma A — fixed Apéry–binomial gcd

```plain text
log rad_{p>2H} gcd(
  A_{3H+1},
  binom(3H+1,H+1)
) = o(H).
```

Equivalently,

```plain text
sum_{j=0}^H
  log rad_{p>2H} gcd(A_j,3H+1-j)
 = o(H).
```

This lemma is independent of theta, of Padé normality, and of Smith factors. It is necessary for every adjacent pair and every fixed finite chain.

### Lemma B(theta) — non-core adjacent pollution

With b=floor(theta H),

```plain text
log N_H(theta)=o(H),

N_H(theta)
 = rad_{p>2H} gcd(P_b(n),P_{b+1}(n)) / T_H.
```

Every prime in N_H(theta) divides kappa_b, but replacing Lemma B by a bound for all of rad(kappa_b) is stronger than necessary and is not supported by the existing data.

The exact logical relation is

```plain text
adjacent-gcd lemma at theta
  <=>
Lemma A + Lemma B(theta).
```

In particular, any proof that starts from the adjacent pair but never proves Lemma A has not yet controlled the actual Apéry bad primes. This is the promised reduction to the weakest fixed two-sequence gcd statement.

# 4. Audit of the proposed Diophantine inputs

## 4.1 Moving-target Subspace-Theorem gcd bounds

The closest theorem I found is Grieve–Wang, Theorem 1.2, a moving-target version of the polynomial gcd theorem. Its hypotheses are materially stronger than “the coefficients may depend on the index.” It fixes:

- a number field and a finite set S of places;

- a fixed number of torus coordinates;

- S-unit arguments in that fixed torus;

- polynomial degrees that are positive constants independent of the moving index;

- coprimality and a nonzero-constant-term condition;

- coefficient height o of the argument height.

Its conclusion is also a dichotomy: a small-gcd estimate on an infinite subset of indices, or containment in moving translates of proper algebraic subgroups. The paper explicitly explains that the infinite-subset conclusion is best possible in that generality.

None of the natural encodings of the present problem satisfies these hypotheses.

### Direct one-variable encoding

Taking

```plain text
f_H(x)=P_floor(theta H)(x),
g_H(x)=P_{floor(theta H)+1}(x),
u_H=3H+1
```

fails immediately because

```plain text
deg f_H = H-floor(theta H),
deg g_H = H-floor(theta H)-1,
```

so both degrees grow linearly with H. Moreover, u_H=3H+1 is not an S-unit in a fixed finite set S, and no fixed finitely generated multiplicative group contains all of these integers.

### Binomial-coordinate lift

One might try to regard a Newton polynomial as a linear form in

```plain text
(1, binom(n,1), ..., binom(n,H)).
```

This turns growing polynomial degree into degree one, but the ambient projective or torus dimension is now H+1. The Subspace Theorem fixes the dimension before the index varies. Its constants and exceptional subspaces are not uniform under this lift. In addition, the binomial coordinates are not points of a fixed S-unit group.

### Coefficient heights and quantifiers

The primitive Padé coefficient heights are exactly part of the unsolved Smith-normalized determinant problem. They have not been proved to be o of any valid fixed-torus argument height. Even if every other hypothesis were repaired, a conclusion on an unspecified infinite subsequence would not imply the required estimate uniformly for all H.

Thus Grieve–Wang cannot be invoked here. Applying it separately at each H is vacuous: the degree, dimension, exceptional set, and theorem constants would all be allowed to change with the single point under consideration.

## 4.2 Fixed-polynomial and almost-S-unit results

Xiao's Theorem 1.3 treats fixed coprime polynomials evaluated at almost-S-unit points in a fixed-dimensional torus. Its quantitative form has a constant proportional to deg f+deg g; allowing the degree to be Theta(H) would already destroy the desired uniform scale even if the theorem otherwise extended.

There is also no direct fixed-polynomial encoding of the fixed two-sequence core. The tempting choice

```plain text
f(x,y)=x,
g(x,y)=y,
(x,y)=(A_{3H+1},B_H)
```

uses two polynomials that both vanish at the origin, contrary to the theorem's stated hypothesis. More fundamentally, the points (A_{3H+1},B_H) have not been shown to be almost S-units for any fixed S; such a statement would itself require strong control of their prime support.

The earlier Corvaja–Zannier and Levin polynomial-gcd theorems have the same fixed-polynomial/fixed-torus architecture. They do not supply uniformity when both the degree and the number of coordinates grow.

## 4.3 Why the linear-recurrence gcd theorems do not cover the fixed core

In the cited gcd literature, “linear recurrence sequence” means a constant-coefficient recurrence, equivalently a generalized power sum

```plain text
u_H = sum_{i=1}^r Q_i(H) alpha_i^H
```

with finitely many fixed roots alpha_i and ordinary polynomials Q_i. This is the C-finite class, not the polynomial-coefficient or P-recursive class.

The two sequences in Lemma A are not C-finite. The positive moment representation gives a short proof for the Apéry subsequence.

Edgar proves that, with

```plain text
c = 17+12 sqrt(2),
A_m = integral_0^c x^m phi(x) dx,
phi(x)>0,
phi(c-y)=C_phi y^(1/2)+O(y^(3/2))
```

for a positive constant C_phi. Watson's endpoint lemma gives

```plain text
A_m = C_A c^m m^(-3/2)(1+O(1/m)).
```

Hence

```plain text
A_{3H+1}
 = C'_A (c^3)^H H^(-3/2)(1+O(1/H)).
```

Stirling's formula gives

```plain text
B_H = binom(3H+1,H+1)
    = C_B (27/4)^H H^(-1/2)(1+O(1/H)).
```

A constant-coefficient recurrence has a rational generating function. Coefficients of a rational function are finite sums of terms Q(H)alpha^H; at a dominant pole the powers of H are nonnegative integers. A nonzero dominant asymptotic with powers H^(-3/2) or H^(-1/2) is impossible. Therefore neither sequence in Lemma A belongs to the class covered by the linear-recurrence gcd theorems.

For completeness, the two exponential bases are themselves multiplicatively independent. If

```plain text
(c^3)^a = (27/4)^b
```

with integers a,b, taking the norm from Q(sqrt(2)) to Q gives

```plain text
1 = (27/4)^(2b),
```

so b=0, and then a=0 because c>1. This does not rescue the recurrence theorems: asymptotic resemblance to two independent exponentials is not an exact generalized-power-sum representation, and Archimedean error terms do not control common prime divisors.

## 4.4 What the positive moment representation does and does not give

The moment representation is genuine extra structure unavailable to formal interpolation. It proves positivity, Hankel total positivity, the endpoint asymptotic above, and strong Archimedean information about the Padé matrix entries. It also explains why the first signed strip and the weighted-Pascal comparison model have positive exponential rates.

It does not directly constrain

```plain text
A_j = 0  (mod 3H+1-j).
```

The moment integral is an identity over the real or complex numbers. Reducing the integer moment A_j modulo a prime whose value moves with j is not an operation on the positive measure. Any successful use of the measure would need an additional arithmetic bridge—such as a fixed-order recurrence for the relevant saturated minors, a compatible family of motives retaining the coefficient index, or a new gcd theorem for G-function coefficients. No such bridge is supplied by Stieltjes positivity alone.

Q763 identifies the same scale obstruction on the analytic Padé side. Entrywise endpoint asymptotics determine the common H^2 free energy, but the adjacent numerator value is controlled by the next H-scale term of an oscillatory determinant. The endpoint exponent -3/2, discrete entropy, and Stokes cancellation all live at precisely that scale. Thus the positive weighted-Pascal model is evidence, not a transfer theorem.

## 4.5 The exact arithmetic-monodromy target

Let

```plain text
F_p(T) = sum_{r=0}^{p-1} (A_r mod p) T^r in F_p[T].
```

The Apéry-core support has the exact coefficient formulation

```plain text
p | T_H
  <=>
2H < p <= 3H+1
and
[T^(3H+1-p)] F_p(T) = 0.
```

Therefore the weakest monodromy-style statement that would prove Lemma A is

```plain text
sum_{
  2H<p<=3H+1,
  [T^(3H+1-p)]F_p(T)=0
} log p
 = o(H).
```

This is a diagonal, moving-coefficient problem: the characteristic p, the polynomial degree p-1, and the coefficient index 3H+1-p all vary together. Fixed-parameter Frobenius-trace or bounded-conductor equidistribution theorems do not automatically give such a pointwise coefficient-zero estimate. A monodromy proof would have to construct one fixed-complexity arithmetic object whose trace or Hasse invariant retains this moving index. Replacing the moving index by a central or otherwise fixed residue loses the problem, exactly as the canonical frontier note warns.

The Lucas congruence is already the first piece of such arithmetic coherence. It converts the coefficient-zero condition at j into the fixed-sequence gcd gcd(A_{3H+1},B_H). What is missing is a cross-prime theorem for the distinguished integral solution, not another single-prime transfer identity.

## 4.6 Solid-minor recurrences do not yet produce a fixed sequence

For the normal square Padé table, Q786 proves

```plain text
|kappa_b|
 = binom(H+1,b+1) tau_b^2/(delta_b delta_{b+1}),
```

where tau_b is a solid Newton minor and delta_b is the last determinantal divisor of the denominator kernel matrix. The raw solid minors obey Desnanot–Jacobi/Toda relations, but those relations introduce shifted row and column windows. The consecutive ratio is

```plain text
kappa_{b+1}/kappa_b
 = -(H-b)/(b+2)
   * (tau_{b+1}/tau_b)^2
   * delta_b/delta_{b+2}.
```

Thus the recurrence does not close on the single diagonal sequence

```plain text
H -> kappa_floor(theta H),
```

or on the adjacent values U_H,V_H. Both shifted minors and two-step Smith ratios remain. In particular, no fixed-order constant-coefficient recurrence—or even a proved fixed-order polynomial-coefficient recurrence—has been derived for these diagonal quantities. The Toda structure is real, but it has the same growing-lattice-parameter obstruction as the moving-polynomial approach.

# 5. A hostile Apéry-holonomy local model

The exact reduction above identifies what must be global. It is also possible to prove a local no-go showing why the recurrence, by itself, does not force small or large direct support.

## 5.1 Prime-local transfer module

Fix a prime p. For an arbitrary solution u_m of the Apéry recurrence on the nonsingular range 1<=m<=p-2, put

```plain text
S_m = (u_m,u_{m-1})^T,

S_{m+1}=T_m S_m,

T_m = [
  (34m^3+51m^2+27m+5)/(m+1)^3,  -m^3/(m+1)^3;
  1,                                      0
].
```

Over F_p,

```plain text
det T_m = m^3/(m+1)^3 != 0
```

through this range. Hence transfer from the initial projective state

```plain text
[u_1:u_0] in P^1(F_p)
```

to every state before the singular boundary is invertible. For each fixed index j<p, the condition

```plain text
u_j=0
```

excludes at most one projective initial state: it is the kernel of one nonzero linear functional on the two-dimensional solution space.

For a fixed prime p, the q=1 indices arising from all integers H are

```plain text
j=3H+1-p,
subject to 2H<p<=3H+1.
```

The number of such H is at most

```plain text
floor((p-1)/2)-ceil((p-1)/3)+1 < p+1.
```

There are exactly p+1 projective initial states. Therefore one can choose a single state depending on p that avoids every one of these zero conditions. The resulting prime-local solution has

```plain text
u_{3H+1-p} != 0  (mod p)
```

for every q=1 incidence at that prime.

Conversely, for any one selected index j, choosing the kernel state realizes u_j=0. Thus the nonsingular Apéry transfer matrices permit both the presence and the complete absence of the direct support.

This model retains genuine local holonomy:

- the exact polynomial recurrence on 1<=m<=p-2;

- invertible transfer and the associated Casoratian identities;

- the impossibility of two consecutive zeros for a nonzero state.

It deliberately drops the distinguished regular initial condition

```plain text
[u_1:u_0]=[5:1].
```

If the recurrence is imposed at m=0, then u_1=5u_0 and the projective freedom disappears. Likewise, the model does not claim the global positive moment representation or the Apéry Lucas law for its altered state. That is exactly the point: all local transfer geometry leaves room for a hostile model; the actual problem resides in using the same integral state (1,5) in every characteristic.

## 5.2 The adjacent identities are compatible with unit kappa

At a direct prime, localize at p and divide the binomial carrier by its unit part, so its value is represented by B=p. For any finite adjacent chain choose p-adic units kappa_t and put

```plain text
Q_t=1,
P_b=p u_0,
P_{t+1}=P_t-p kappa_t.
```

Choose u_0 outside finitely many residue classes. Then every P_t has valuation exactly one, every Q_t is a unit, every kappa_t is a unit, and

```plain text
P_t Q_{t+1}-P_{t+1}Q_t = kappa_t p.
```

Thus a bad common prime need not enter any adjacent kappa. This is the local saturation model from Q786 in its simplest form. It proves that no combination of adjacent determinants, Smith division by the carrier, or Plücker/Toda identities can detect the original one-row rank loss after saturation.

Combining the two local constructions gives the hostile conclusion:

```plain text
prime-local Apéry transfer + universal adjacent identities
```

can model either no direct bad primes at all or valuation-one common bad primes with unit kappa. The missing invariant must therefore couple the distinguished state across different characteristics.

# 6. What the finite exact data mean

The checked-in script research/scripts/q32_adjacent_pade_kappa.py constructs all primitive pairs, verifies the adjacent identity and leading-coefficient formula exactly, and computes adjacent and triple gcds. At commit 710a25d4be1630e5df54c4df2b7b3382fa04d8d6, its default maximum_height is 30, and Q786 explicitly discusses gcd computations through H=30. The present prompt supplies the additional assertion that the exact gcd data have been extended through H=40; the resume's separately documented H=40 extension concerns the all-split numerator-minimality scan, not by itself a fixed-interior gcd table.

Two cautions matter for the present question.

First, the script's headline statistic minimizes over b. The frontier note says the minimizing adjacent pair is usually the edge b=0,1. A minimum-over-all-splits table is not evidence for one fixed interior slope b=floor(theta H). The latter requires extracting and plotting the same slope for every H, with no post hoc choice of b.

Second, even an exact interior table through H=40 measures only finitely many selected prime factors of the carrier. Theorem 2.1 shows why small values are arithmetically meaningful but logically insufficient:

```plain text
R_H(theta)=T_H N_H(theta).
```

Smallness means that both the actual Apéry core and the non-core pollution happened to be small in the tested range. The universal identities explain neither fact. Yet Section 5 shows that prime-local recurrence modules with p-dependent state can reproduce radical 1, while the adjacent local model can make the kappa factors units. Hence the observed smallness is reproducible at the level of all currently exploited local constraints.

There is no contradiction between these statements:

- Weak compatibility: same recurrence matrices and local determinant identities, but a state depending on p. Small gcds are easy to reproduce.

- Strong compatibility: the same recurrence together with the fixed regular state (1,5), the characteristic-zero moment representation, and its reductions in every characteristic. This uniquely gives the actual Apéry sequence, so persistent smallness would be genuine global arithmetic.

The data support the strong arithmetic conjecture, but they do not prove that the strong model behaves differently from the weak one asymptotically.

## Apéry–binomial radical lemma

```plain text
For n=3H+1,
log rad_{p>2H} gcd(
  A_n,
  binom(n,H+1)
) = o(H).
```

Equivalent moving-divisor form:

```plain text
sum_{
  0<=j<=H,
  p=3H+1-j prime,
  p|A_j
} log p
 = o(H).
```

Equivalent moving-coefficient form:

```plain text
sum_{
  2H<p<=3H+1,
  [T^(3H+1-p)]F_p(T)=0
} log p
 = o(H).
```

This is the weakest fixed two-sequence or moving-divisor lemma forced by every adjacent slope. It is where Apéry holonomy, the G-function, arithmetic monodromy, or a new Subspace-Theorem analogue for P-recursive sequences must enter.

After that lemma is proved, one may optimize the interior slope solely to control the pollution factor. An exact sufficient statement is

```plain text
For one fixed theta in (0,1),
log N_H(theta)=o(H),

N_H(theta)
 = rad_{p>2H} gcd(P_b(n),P_{b+1}(n)) / T_H,
b=floor(theta H).
```

In candidate-prime language, its remaining support is

```plain text
p=n-j,
A_j != 0 (mod p),
Q_b(j)=Q_{b+1}(j)=0 (mod p),
```

together with common primes p>n; all such primes divide kappa_b. A theorem bounding this simultaneous denominator-zero support would be genuinely Padé-specific. It should not be conflated with the Apéry-core lemma.

A stronger but simpler sufficient condition would be

```plain text
log rad_{p>2H}(kappa_floor(theta H))=o(H),
```

but the exact reduction shows that this is more than necessary, and the Smith-normalized square formula gives no reason to expect it without new arithmetic.

No existing theorem audited here proves the requested o(H) bound. The obstruction is not merely that the Padé degrees grow. The actual adjacent gcd contains a slope-independent, fixed two-sequence Apéry factor that survives every Smith saturation and every choice of interior split.

The new unconditional conclusion is the exact factorization

```plain text
rad_{p>2H} gcd(P_b(3H+1),P_{b+1}(3H+1))
 = rad_{p>2H} gcd(
     A_{3H+1},
     binom(3H+1,H+1)
   )
   * N_H(theta),
```

with coprime factors and with every prime of N_H(theta) dividing kappa_b.

This gives a hostile equivalence rather than another citation of the carrier:

```plain text
one fixed interior adjacent-gcd theorem
  <=>
fixed Apéry–binomial radical lemma
  +
that slope's non-core pollution lemma.
```

The first lemma is independent of Padé interpolation and is exactly the direct moving-zero problem. The second is where an interior split can help. Any future proof that does not visibly establish both pieces has not closed the adjacent-gcd target.
