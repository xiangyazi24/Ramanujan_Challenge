# Correction of the Q888 matrix-to-minor lift

## Executive verdict

I audited the latest main commit 1113361cf05bb316c88f1062a15328b47d962ef3, the Q888 question, the current working-note continuation, and the exact Apéry/Padé matrix definitions.

The scalar recurrence for

```plain text
N_(r,l) = Delta^r A_l
```

is valid. It gives a genuine twelve-term bivariate recurrence and a genuine finite matrix identity of the requested form

```plain text
sum_i L_i M R_i = 0
```

when the ambient matrix contains the shifted rows and columns.

However, the load-bearing compound step claimed in Q888 is invalid. The determinant or exterior power of a sum is not the sum of the determinants or exterior powers. The correct polarization contains mixed determinants in which different columns use different recurrence terms. These mixed determinants are not members of the claimed uniformly shifted-minor family.

The precise correction is:

```plain text
1. The scalar twelve-term recurrence survives.

2. The finite matrix identity survives, with every operator and dimension
   written explicitly below.

3. If one compresses to R_(H,a), the discarded part is supported on the
   first and last output rows and the last four output columns. Hence a
   matrix-level boundary rank bound <= 6 is valid; the earlier <= 7 count
   can be sharpened.

4. This low matrix rank does NOT imply a closed recurrence for maximal
   minors. The exterior expansion contains mixed compounds.

5. The claimed shifted-minor family S_(H,a), its scalar quotient q_(H,a),
   and the resulting primitive bordered-value recurrence must therefore be
   retracted. They have not been proved by the scalar recurrence.

6. delta_(H,a) cannot be divided out termwise in the mixed relation. No
   divisibility theorem for the mixed determinants by the relevant Smith
   factors is presently available.
```

An exact 2 x 2 Apéry calculation demonstrates the flaw:

```plain text
For output rows k=2,3 and columns l=0,1, let A_1,...,A_12 be the
matrices contributed by the twelve recurrence terms.

sum_i A_i = 0 entrywise,

det(sum_i A_i) = 0,

but

sum_i det(A_i) = 1687347858288 != 0.
```

The missing value is cancelled by the mixed two-column determinants. Thus even the smallest nontrivial compound already refutes the pure-shifted-minor lift.

The weakest useful repair is an Apéry-specific saturated mixed-compound closure theorem: one would have to prove that all mixed determinants in the polarized recurrence reduce, after exact Smith saturation, to a bounded-rank integral module generated by primitive bordered Padé values. No such theorem is currently known. Even that closure would not finish the problem without a separate nonzero exp(o(H)) height theorem.

# 1. The exact twelve-term recurrence

The Apéry recurrence is

```plain text
(l+1)^3 A_(l+1)
- P(l) A_l
+ l^3 A_(l-1) = 0,

P(l)=34l^3+51l^2+27l+5.
```

For forward differences, use

```plain text
Delta^r(fg)(l)
 = sum_(t=0)^r binom(r,t)
     Delta^t f(l) Delta^(r-t) g(l+t).
```

Since all coefficient polynomials have degree three, only 0<=t<=3 occurs. Define

```plain text
a_0(l)=(l+1)^3,
a_1(l)=3l^2+9l+7,
a_2(l)=6l+12,
a_3(l)=6;

b_0(l)=34l^3+51l^2+27l+5,
b_1(l)=102l^2+204l+112,
b_2(l)=204l+306,
b_3(l)=204;

c_0(l)=l^3,
c_1(l)=3l^2+3l+1,
c_2(l)=6l+6,
c_3(l)=6.
```

Then, with the convention that an out-of-range N_(r,l) is zero,

```plain text
sum_(t=0)^3 binom(r,t) [
    a_t(l) N_(r-t,l+t+1)
  - b_t(l) N_(r-t,l+t)
  + c_t(l) N_(r-t,l+t-1)
] = 0.                                      (1.1)
```

This is the valid scalar twelve-term recurrence.

# 2. Conversion to the Padé matrix M

Put

```plain text
M[k,l] = binom(k,l) N_(k-l,l)
       = binom(k,l) Delta^(k-l) A_l,
```

and set M[k,l]=0 when k<0, l<0, or l>k.

Multiplying (1.1) by (k+1) binom(k,l), where r=k-l, gives a polynomial-coefficient identity. Define

```plain text
h_0(l)=(l+1)^4,
h_1(l)=(l+1)(l+2)(3l^2+9l+7),
h_2(l)=3(l+1)(l+2)^2(l+3),
h_3(l)=(l+1)(l+2)(l+3)(l+4);

m_0(l)=34l^3+51l^2+27l+5,
m_1(l)=(l+1)(102l^2+204l+112),
m_2(l)=51(l+1)(l+2)(2l+3),
m_3(l)=34(l+1)(l+2)(l+3);

g_0(l)=l^2,
g_1(l)=3l^2+3l+1,
g_2(l)=3(l+1)^2,
g_3(l)=(l+1)(l+2).
```

The exact entry recurrence is

```plain text
sum_(t=0)^3 [
    h_t(l) M[k+1,l+t+1]
  - (k+1)m_t(l) M[k,l+t]
  + k(k+1)g_t(l) M[k-1,l+t-1]
] = 0.                                      (2.1)
```

The formula is valid for every k,l>=0; the zero convention handles all boundaries. In particular, the apparently singular factor in the backward term has cancelled, and every coefficient in (2.1) is integral.

# 3. Exact finite matrix identity with dimensions

Let

```plain text
I = {a+1,...,H},
J = {0,...,b},
b = H-a.
```

Thus

```plain text
|I|=b,
|J|=b+1.
```

Use the ambient index sets

```plain text
I_tilde = {a,...,H+1},       |I_tilde|=b+2,
J_tilde = {0,...,b+4},       |J_tilde|=b+5.
```

Let M_tilde be the (b+2) x (b+5) submatrix with these row and column indices, again using zero entries above the triangular boundary.

For each t=0,1,2,3, define three left matrices of size

```plain text
b x (b+2)
```

and three right matrices of size

```plain text
(b+5) x (b+1)
```

by

```plain text
L_(+,t)[k,u] = 1_(u=k+1),
R_(+,t)[v,l] = h_t(l) 1_(v=l+t+1);

L_(0,t)[k,u] = -(k+1) 1_(u=k),
R_(0,t)[v,l] = m_t(l) 1_(v=l+t);

L_(-,t)[k,u] = k(k+1) 1_(u=k-1),
R_(-,t)[v,l] = g_t(l) 1_(v=l+t-1).
```

Here k ranges through I, u through I_tilde, l through J, and v through J_tilde. A nonexistent index gives zero; in particular g_0(0)=0, so the apparent column -1 never contributes.

Then the exact finite identity is

```plain text
sum_(t=0)^3 [
    L_(+,t) M_tilde R_(+,t)
  + L_(0,t) M_tilde R_(0,t)
  + L_(-,t) M_tilde R_(-,t)
] = 0_(b x (b+1)).                              (3.1)
```

Every entry of (3.1) is exactly (2.1). This is the requested valid matrix lift.

# 4. What remains of the boundary-rank statement

Let

```plain text
R_(H,a) = M[I,J].
```

If every shifted term in (3.1) is split into an interior part using only R_(H,a) and an exterior part, the exterior matrix is supported in

```plain text
- the first output row k=a+1;
- the last output row k=H;
- the last four output columns l=b-3,b-2,b-1,b.
```

There is no left-column contribution because the only negative shift is multiplied by g_0(0)=0.

Therefore one obtains a valid displacement equation

```plain text
sum_i L_i^int R_(H,a) R_i^int = B_(H,a),        (4.1)
```

where

```plain text
support(B_(H,a))
  is contained in two rows union four columns,

rank(B_(H,a)) <= 6.                              (4.2)
```

Thus the informal rank <= 7 boundary count can be repaired and sharpened at the ordinary matrix level.

But this fact is much weaker than what Q888 used. The boundary matrix depends on exterior strips of the actual Apéry matrix, and (4.1) is a twelve-term displacement, not a two-term Sylvester equation such as

```plain text
A R - R B = U V^T.
```

A low-rank right side in a twelve-term displacement does not linearize maximal minors.

# 5. The correct exterior-power calculation

Write the twelve output matrices in (3.1) as

```plain text
A_1,...,A_12,

sum_(nu=1)^12 A_nu = 0.
```

Fix m output columns j_1,...,j_m, and write a_(nu,j) for column j of A_nu. Since each summed column is zero,

```plain text
0
 = wedge_(q=1)^m (sum_(nu=1)^12 a_(nu,j_q))
 = sum_(phi:{1,...,m}->{1,...,12})
     a_(phi(1),j_1) wedge ... wedge a_(phi(m),j_m).   (5.1)
```

After choosing m output rows, (5.1) becomes

```plain text
0
 = sum_phi det(
       column j_1 from A_(phi(1)),
       ...,
       column j_m from A_(phi(m))
   ).                                               (5.2)
```

The twelve constant maps phi give the twelve pure compound terms. Every nonconstant phi gives a mixed determinant.

For one pure term, ordinary Cauchy--Binet is valid:

```plain text
det((L_nu M_tilde R_nu)[I_0,J_0])
 = sum_(K,L; |K|=|L|=m)
     det(L_nu[I_0,K])
     det(M_tilde[K,L])
     det(R_nu[L,J_0]).                              (5.3)
```

Because L_nu,R_nu are weighted shifts, (5.3) is a weighted sum of shifted minors of M.

However, the mixed terms in (5.2) use different row and column shifts in different columns. They are not pure minors of one shifted copy of M. Their number grows like 12^m, not like a fixed boundary width.

This is the exact point where Q888's Sections 3--5 fail.

# 6. Exact small-compound countercheck

Take output rows

```plain text
k=2,3
```

and output columns

```plain text
l=0,1.
```

Construct the twelve 2 x 2 matrices from the terms in (2.1), using the exact Apéry values. Entrywise,

```plain text
sum_i A_i = 0_(2 x 2).
```

Therefore

```plain text
det(sum_i A_i)=0.
```

But exact arithmetic gives

```plain text
sum_i det(A_i)=1687347858288.                      (6.1)
```

The nonzero value in (6.1) is cancelled by the mixed two-column determinants in (5.2). Hence no identity obtained by simply replacing every matrix term in (3.1) by its maximal minor can be correct.

The following executable check verifies both (2.1) and (6.1):

```python
from fractions import Fraction
from math import comb

A = [1, 5]
for n in range(1, 30):
    P = 34*n**3 + 51*n**2 + 27*n + 5
    A.append((P*A[n] - n**3*A[n-1]) // (n+1)**3)

def Delta(r, l):
    return sum((-1)**(r-i)*comb(r, i)*A[l+i]
               for i in range(r+1))

def M(k, l):
    if k < 0 or l < 0 or l > k:
        return 0
    return comb(k, l)*Delta(k-l, l)

def coeffs(l):
    a = [(l+1)**3, 3*l*l+9*l+7, 6*l+12, 6]
    b = [34*l**3+51*l**2+27*l+5,
         102*l*l+204*l+112, 204*l+306, 204]
    c = [l**3, 3*l*l+3*l+1, 6*l+6, 6]
    return a, b, c

def term(kind, t, k, l):
    a, b, c = coeffs(l)
    if kind == '+':
        h = (l+t+1)*comb(l+t, t)*a[t]
        return h*M(k+1, l+t+1)
    if kind == '0':
        m = comb(l+t, t)*b[t]
        return -(k+1)*m*M(k, l+t)
    if l+t == 0:
        g = 0
    else:
        g = Fraction(comb(l+t, t)*c[t], l+t)
    return k*(k+1)*g*M(k-1, l+t-1)

# Entrywise audit.
for k in range(15):
    for l in range(k+1):
        assert sum(term(kind, t, k, l)
                   for kind in ['+', '0', '-']
                   for t in range(4)) == 0

# First compound audit.
rows = [2, 3]
cols = [0, 1]
terms = []
for kind in ['+', '0', '-']:
    for t in range(4):
        terms.append([[term(kind, t, k, l) for l in cols]
                      for k in rows])

def det2(X):
    return X[0][0]*X[1][1] - X[0][1]*X[1][0]

assert sum(det2(X) for X in terms) == 1687347858288
```

# 7. Retraction of the claimed shifted-minor recurrence

Q888's proposed lift treated the scalar recurrence as though one could change one entry of a determinant and identify the result with a determinant having one shifted row or column. That is not valid:

```plain text
- shifting one scalar entry does not shift the other entries in its row;
- shifting one scalar entry does not shift the other entries in its column;
- multilinearity creates mixed determinants, not one moved-row minor;
- the mixed terms survive even when the ordinary matrix boundary has low rank.
```

Therefore the following claims are retracted:

```plain text
- closure of the proposed shifted-minor family S_(H,a);
- a scalar recurrence for that family derived from (1.1);
- the quotient q_(H,a) obtained by dividing the alleged raw-minor relation;
- any integral recurrence for primitive bordered values based on that quotient;
- any height conclusion obtained from finite elimination of that false relation.
```

The matrix-level rank bound survives only in the corrected form (4.1)--(4.2).

# 8. Smith normalization and delta_(H,a)

Let

```plain text
R_(H,a)=M[a+1..H,0..H-a],

delta_(H,a)=gcd of its maximal minors.
```

The primitive Padé denominator is the cofactor vector divided by delta_(H,a), and a primitive bordered value has the exact form

```plain text
P_(H,a)(n)
 = +/- det([R_(H,a); w(n)]) / delta_(H,a).          (8.1)
```

Formula (8.1) remains valid individually.

The corrected compound relation (5.2) contains mixed determinants built from different shifted operators. Such a determinant is generally neither

```plain text
- a maximal minor of R_(H,a), nor
- a bordered determinant with determinantal divisor delta_(H,a), nor
- a minor of one neighboring R_(H+r,a+s) with a known divisor.
```

Consequently there is no justified operation

```plain text
raw determinant relation
    divide termwise by delta_(H,a)
primitive bordered-value relation.
```

To obtain an integral relation among primitive values, one must first prove a common divisibility statement for every mixed determinant. Q888 supplied no such statement, and the scalar recurrence does not imply one.

This is the exact saturation obstruction.

# 9. No height theorem follows from the corrected relation

The coefficients in (2.1) are polynomial in k,l, but the compounds have order

```plain text
m=H-a.
```

After polarization, the number of mixed terms and the sizes of their raw determinants grow with m. A finite algebraic elimination of (5.2) does not establish any of the following:

```plain text
- that the resulting integer is nonzero;
- that target primes divide it after primitive normalization;
- that its logarithmic height is o(H);
- that cancellation survives division by Smith factors.
```

Raw minors naturally have quadratic-exponential height. The recurrence supplies no bound showing that the Smith-normalized mixed combination collapses to exp(o(H)).

Thus Q888's proposed final step must be retracted rather than left as a conditional proof.

# 10. Weakest repairable lemma

The recurrence-minor route can be reopened by proving the following concrete statement.

```plain text
SATURATED MIXED-COMPOUND CLOSURE LEMMA.

For m=H-a, polarize the exact twelve-term identity (3.1) in exterior
order m. Let C_(H,a) be the Z-module generated by all mixed determinants
appearing in (5.2), including the boundary strips.

Prove that, after saturation, C_(H,a) has rank bounded independently of
H and a, and is generated by a fixed-width family of primitive bordered
Padé values

    P_(H+r,a+s)(3H+1),   |r|+|s|<=C,

with transition coefficients of logarithmic height o(H).

Moreover, prove that this saturated module contains a nonzero integer E_H
such that

    every direct target prime divides E_H,
    log|E_H|=o(H).
```

The bounded-rank closure is the missing algebraic statement. The last two clauses are the missing arithmetic-height statement. Neither follows from the scalar recurrence or from the matrix boundary rank.

A weaker closure theorem without the nonzero low-height element would still be a legitimate structural advance, but it would not prove Problem 3.2.
