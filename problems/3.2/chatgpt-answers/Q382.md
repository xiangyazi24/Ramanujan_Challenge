# The folded `q=1` Apéry gcd: exact support, a real partial saving, and the remaining old-prime theorem
## Verdict
Let
```plain text
b_n = sum_{k=0}^n binom(n,k)^2 binom(n+k,k)^2,
J = floor((n-1)/3),
C_n^fold = gcd(b_n, lcm_{0<=j<=J} b_j).
```
The folded object is useful, but its sharp interpretation is more restrictive than it first appears:
> **For primes ****`p>n/2`****, the prime support of ****`C_n^fold`**** is exactly the prime support of ****`b_n`****.**
More precisely, apart from the finite primes `2,3,5`,
```plain text
p | C_n^fold   <=>   p | b_n   <=>   p belongs to the q=1 lower channel.
```
Thus the fold does **not** create a second independent divisibility condition. It repackages the same top-half prime factors of the single integer `b_n` as factors already seen among `b_0,...,b_J`.
For the Apéry gcd sequence `G_n`, the Wronskian gives
```plain text
v_p(G_n) <= 6,                 n/2 < p <= n,
```
so the `q=1` contribution is equivalent, up to the constant factor `6`, to the radical of the folded gcd:
```plain text
log rad_(n/2,n](C_n^fold)
 <= sum_{n/2<p<=n} v_p(G_n) log p
 <= 6 log rad_(n/2,n](C_n^fold).                      (V)
```
I do **not** obtain the full desired `o(n)` bound. I do obtain one unconditional all-`n` partial:
```plain text
The primes whose folded index j is <= n/(log n)^2
contribute O(n/log n) to the q=1 weighted gcd.          (P)
```
Equivalently, after an `o(n)` loss one may restrict to the genuinely hard middle region
```plain text
n/2 + n/(2 log^2 n) < p < n - n/log^2 n.
```
The exact binomial formula, Wronskian, continuants, and known primitive-divisor/gcd technology do not currently control that middle region. The weakest genuinely new theorem needed is either of the equivalent support forms
```plain text
log rad_(n/2,n] gcd(b_n, lcm_{j<=n/3} b_j) = o(n),     (OLD)
```
or
```plain text
#{j<=n/3 : n-j is prime and n-j|b_j}
+
#{j<=n/3 : (n+1+j)/2 is prime and (n+1+j)/2|b_j}
 = o(n/log n).                                         (LIN)
```
A log-power estimate `O(n/log^(1+delta)n)` in `(LIN)` would already suffice. This is a quantitative **large primitive-support / moving linear prime-divisor theorem** for the Apéry sequence. I found no published theorem of this shape.
The distinction requested in the question is essential:
- `(OLD)` concerns **prime support** and is enough for `G_n` because of the depth bound `v_p(G_n)<=6`;
- `log C_n^fold=o(n)` is stronger and additionally requires control of repeated valuations of common primes.

# 1. Exact folded support theorem
Take a prime
```plain text
n/2 < p <= n
```
and write
```plain text
n = p+r,       0<=r<p.
```
Gessel's Lucas congruence gives
```plain text
b_n = b_(p+r) = b_1 b_r = 5 b_r       (mod p).       (1.1)
```
The first Apéry block is palindromic:
```plain text
b_(p-1-r) = b_r                         (mod p).       (1.2)
```
Define
```plain text
j = min(r, p-1-r).
```
Then `j<=J`, and exactly one of the following descriptions holds, except at the meeting boundary where they coincide:
```plain text
j=r:
    p=n-j;

j=p-1-r:
    j=2p-n-1,
    p=(n+1+j)/2.                                      (1.3)
```
The maximum possible folded index occurs where the two expressions are equal:
```plain text
n-p = 2p-n-1,
3p=2n+1,
j=(n-1)/3.
```
This proves the forward implication stated in Q359.
The converse is equally important and makes the folded gcd exact.
- If `p=n-j` is prime, `j<=J`, and `p|b_j`, then `p>n/2`, `r=j`, and (1.1) gives `p|b_n`.
- If `p=(n+1+j)/2` is an integer prime, `j<=J`, and `p|b_j`, then
	```plain text
r=n-p=(n-1-j)/2,
p-1-r=j,
	```
	so (1.2) gives `p|b_r`, and then (1.1) gives `p|b_n`.
Hence, for all sufficiently large `n`,
```plain text
{p prime : n/2<p<=n, p|b_n}
=
{n-j prime : 0<=j<=J, n-j|b_j}
 union
{(n+1+j)/2 prime : 0<=j<=J, (n+1+j)/2|b_j}.          (1.4)
```
Now suppose merely that `p>n/2` divides `b_n`. Formula (1.4) produces a folded index `j<=J` with `p|b_j`; therefore `p` divides the lcm in `C_n^fold`. Conversely, every prime dividing `C_n^fold` divides `b_n` by definition. Thus
```plain text
rad_(n/2,n](C_n^fold) = rad_(n/2,n](b_n).             (1.5)
```
This is the sharp obstruction to treating the two arguments of the gcd as independent.
For `q=1`, the proved companion support law is
```plain text
p|G_n <=> a_1 b_r=6b_r=0 mod p,
```
so the same support set is exactly the top-half support of `G_n`. Combining this with the Wronskian depth estimate gives `(V)`.
Sources: [Q359, exact folded support](https://app.notion.com/p/3a67a6c4fa848142bbebc1dc48566183), and Gessel, [“Some congruences for Apéry numbers”](https://doi.org/10.1016/0022-314X(82)90071-3), *J. Number Theory* 14 (1982), 362–368.

# 2. Prime support is not the same as weighted valuation
For a prime `p`,
```plain text
v_p(C_n^fold)
 = min(v_p(b_n), max_{0<=j<=J} v_p(b_j)).             (2.1)
```
The fold proves only that the maximum on the right is at least `1` for a top-half support prime. It does not force equality of the two valuations and does not bound either one.
This matters because the original `G_n` problem has an independent Wronskian estimate
```plain text
v_p(G_n)<=6,
```
whereas `C_n^fold` itself has no analogous proved uniform depth bound.
## 2.1 The mod-`p^2` formula exposes the extra condition
Rowland–Yassawi–Krattenthaler record Gessel's exact first-order lift
```plain text
b_(d+pt)
 = (b_d + pt b'_d) b_t                    (mod p^2),  (2.2)
```
where `b'_d` is the derivative at `d` of the entire Apéry interpolation; see their equation (4).
For the branch `n=p+j`, `t=1`, this becomes
```plain text
b_n = 5(b_j+p b'_j)                        (mod p^2). (2.3)
```
Because `p>2j`, all denominators entering `b'_j` are `p`-units. If
```plain text
b_j=p c_j,
```
then
```plain text
b_n/p = 5(c_j+b'_j)                         (mod p).  (2.4)
```
Thus `p^2|b_n` is an additional derivative cancellation; it is not forced by `p|b_j`.
For the reflected branch the situation is even less automatic. The same paper defines
```plain text
D(p)={d : b_d=b_(p-1-d) mod p^2}
```
and proves that the derivative-free Lucas congruence modulo `p^2` holds for all upper digits precisely for `d in D(p)`. The mod-`p` palindromy used by the fold is universal, while its mod-`p^2` lift is not.
Therefore:
> The folded support theorem controls the radical. A bound for the full integer `C_n^fold` additionally needs a separate repeated-valuation theorem.
Reference: E. Rowland, R. Yassawi and C. Krattenthaler, [“Lucas congruences for the Apéry numbers modulo ](https://www.mat.univie.ac.at/~kratt/artikel/rowyass.pdf)[`p^2`](https://www.mat.univie.ac.at/~kratt/artikel/rowyass.pdf)[”](https://www.mat.univie.ac.at/~kratt/artikel/rowyass.pdf), *Integers* 21 (2021), A20, equations (2)–(4) and Theorem 2.

# 3. Why the exact binomial sum does not separate the candidate prime
For every folded candidate one has
```plain text
p>2j.                                                  (3.1)
```
Indeed:
```plain text
p=n-j,      j< n/3  => p>2j,
```
and
```plain text
p=(n+1+j)/2,  j<=(n-1)/3  => p>=2j+1.
```
In the exact formula
```plain text
b_j = sum_{k=0}^j binom(j,k)^2 binom(j+k,k)^2,         (3.2)
```
all factorial arguments are at most `2j<p`. Consequently every individual summand is a nonzero `p`-adic unit. The condition
```plain text
p|b_j
```
is therefore pure cancellation among `j+1` nonzero residues modulo `p`; it is not caused by a visible factor in one binomial term.
This kills the most direct Kummer/Legendre-factor strategy. There are no carries and no termwise large prime whose occurrence can be assigned to a particular factorial quotient. The phenomenon is exactly the hypergeometric cancellation already seen in the Hasse-polynomial description of the first Apéry block.
Positivity over the integers does not help: for `j` proportional to `n`, `b_j` is exponentially larger than the candidate prime.

# 4. What the Wronskian and the gap continuants do give
Let `p` be a `q=1` bad prime and let `j` be its folded index. Put
```plain text
h=n-j.
```
Q338 gives the exact Casoratian formula
```plain text
N_h(j)
 = ((n!/j!)^3/6) (a_n b_j-b_n a_j).                  (4.1)
```
Because
```plain text
j<p<=n<2p,
```
the interval `(j,n]` contains exactly one multiple of `p`, namely `p`, so
```plain text
v_p((n!/j!)^3)=3.                                     (4.2)
```
Write
```plain text
alpha_n^(p)=p^3a_n,
```
which is `p`-integral. The `q=1` companion block identity gives
```plain text
alpha_n^(p)=a_1b_r=6b_r=0 mod p.                      (4.3)
```
The folded congruence gives `p|b_j`, and Lucas gives `p|b_n`. Writing
```plain text
(n!/j!)^3=p^3u,      u a p-unit,
```
formula (4.1) becomes
```plain text
N_h(j)
 = u/6 [alpha_n^(p)b_j-p^3b_na_j].                   (4.4)
```
Both terms in the bracket are divisible by `p^2`, hence
```plain text
p^2 | N_(n-j)(j).                                     (4.5)
```
This is a genuine new certificate extracted from the Wronskian/continuant structure.
## 4.1 Why the certificate is too tall
The determinant formula for `N_h(j)` has dimension `h-1`; its entries are polynomially bounded in `n`. The matching expansion or Hadamard's inequality gives
```plain text
log |N_(n-j)(j)| = O((n-j) log n)=O(n log n).         (4.6)
```
If `R_n` is the squarefree product of all top-half bad primes, assigning each prime to its folded `j` gives
```plain text
R_n^2 | product_{0<=j<=J} N_(n-j)(j),                 (4.7)
```
but
```plain text
log product_{j<=J}|N_(n-j)(j)| = O(n^2 log n).        (4.8)
```
This is much larger than the desired `o(n)` scale. Even summing only over successful indices is useless in the worst case: `~n/log n` successful indices, each with height `O(n log n)`, still allow quadratic total height.
The exact formula therefore supplies local multiplicity `p^2`, but no cross-index compression.
## 4.2 Why resultants do not compress the certificates
The adjacent-resultant and Dodgson identities from Q338 are powerful when one prime produces **several nearby zeros** of the same recurrence. They prevent or classify clustering. A folded `q=1` prime contributes one isolated zero index, which is precisely the regime those identities do not penalize.
There is an even sharper degeneration in the reflected branch. Q359 proves that the transfer from `j` to its reflected index `p-1-j` is universally anti-diagonal. Equivalently, the relevant gap continuant is zero modulo `p` for every `j`, whether or not `b_j=0`. Thus the most tempting reflected resultant contains no information about the Apéry zero: its vanishing is a structural identity of the full cycle.
So resultants can certify **extra** zero coincidences, but the fold supplies exactly one forced mirror pair and no extra coincidence.
Sources: [Q338, Casoratian and resultant identities](https://app.notion.com/p/3a67a6c4fa8481a2bb9ce90ba7c7ff30) and [Q359, exact reflected transfer](https://app.notion.com/p/3a67a6c4fa848142bbebc1dc48566183).

# 5. Why primitive-divisor and known gcd theorems do not close it
The integer `C_n^fold` is the part of `b_n` supported on primes already occurring among the first `n/3` Apéry terms. In divisibility-sequence terminology, it is an **old part** of `b_n`.
For Lucas and Lehmer sequences there is a cyclotomic factorization and a rank-of-apparition law. Bilu–Hanrot–Voutier prove that every term beyond index `30` has a primitive divisor. The Apéry sequence has neither property:
```plain text
b_1=5 does not divide b_2=73,
```
and there is no known law `p|b_n <=> rho(p)|n`.
More importantly, existence of one primitive divisor would be far too weak here. Removing one prime of size at most `n` saves only `O(log n)` from an integer of logarithmic size `~3.52549n`. What is needed is a **large primitive radical**, not merely one primitive prime.
Reference: Y. Bilu, G. Hanrot and P. Voutier, [“Existence of primitive divisors of Lucas and Lehmer numbers”](https://doi.org/10.1515/crll.2001.080), *J. reine angew. Math.* 539 (2001), 75–122.
The Subspace-Theorem gcd results also have the wrong structure. Bugeaud–Corvaja–Zannier prove, for fixed multiplicatively independent integers `a,b`,
```plain text
gcd(a^n-1,b^n-1) <= exp(epsilon n)
```
for all sufficiently large `n`. Extensions to algebraic linear recurrences and moving `S`-unit targets still use fixed finite-dimensional exponential/S-unit data. They do not cover a P-recursive sequence with polynomially varying coefficients, nor a gcd against an lcm of `Theta(n)` moving earlier terms.
References:
- Y. Bugeaud, P. Corvaja and U. Zannier, [“An upper bound for the G.C.D. of ](https://doi.org/10.1007/s00209-002-0449-z)[`a^n-1`](https://doi.org/10.1007/s00209-002-0449-z)[ and ](https://doi.org/10.1007/s00209-002-0449-z)[`b^n-1`](https://doi.org/10.1007/s00209-002-0449-z)[”](https://doi.org/10.1007/s00209-002-0449-z), *Math. Z.* 243 (2003), 79–84.
- N. Grieve and J. T.-Y. Wang, [“Greatest common divisors with moving targets and consequences for linear recurrence sequences”](https://arxiv.org/abs/1902.09109).
Finally, a pairwise estimate would not automatically suffice. Even a uniform statement
```plain text
log gcd(b_n,b_j)=o(n)
```
for every `j<=n/3` could allow disjoint prime sets for different `j`; taking the lcm aggregates all of them. The required theorem must control the **union of old prime supports**, not each pair separately.
The closest direct Apéry arithmetic paper I located, Luca–Shparlinski, proves density-one lower bounds on the total number and largest size of prime factors of `b_n`; it gives no pointwise upper bound on this old part:
- F. Luca and I. E. Shparlinski, [“Arithmetic properties of Apéry numbers”](https://doi.org/10.1112/jlms/jdn031), *J. London Math. Soc.* 78 (2008), 545–562.

# 6. An unconditional sublinear edge theorem
The fold nevertheless gives a simple all-`n` saving near the two endpoints of the top-half prime interval.
Let
```plain text
Y= floor(n/log^2 n).
```
There are at most two candidate primes for each folded index `j`, so the number of bad candidates with `j<=Y` is at most
```plain text
2Y+O(1).
```
For `G_n`, each has valuation at most `6` and logarithm at most `log n`. Therefore
```plain text
sum_{q=1 bad p with folded j<=Y} v_p(G_n)log p
 <= 12Y log n+O(log n)
 = O(n/log n).                                        (6.1)
```
This proves `(P)`.
In prime coordinates, the discarded edge ranges are
```plain text
(n/2, (n+1+Y)/2]          from p=(n+1+j)/2,
[n-Y,n]                   from p=n-j.                 (6.2)
```
Thus the only unresolved `q=1` primes may be restricted to
```plain text
(n+1+Y)/2 < p < n-Y.                                  (6.3)
```
More generally, any choice
```plain text
Y=o(n/log n)
```
gives an `o(n)` edge contribution. This is a genuine, though limited, pointwise reduction.
For the radical of `C_n^fold`, the same proof works with the factor `6` removed. It does **not** bound the full `log C_n^fold` without a valuation theorem.

# 7. The weakest new theorem that closes the `q=1` slice
Define
```plain text
S_-(n)
 := {j<=J : p=n-j is prime and p|b_j},

S_+(n)
 := {j<=J : n+1+j=2p for a prime p and p|b_j}.        (7.1)
```
Every prime involved is between `n/2` and `n`, so `log p~log n`. Hence the following are equivalent up to absolute constants:
```plain text
sum_{j in S_-(n)} log(n-j)
 + sum_{j in S_+(n)} log((n+1+j)/2)
 = o(n);                                              (7.2)
```
```plain text
|S_-(n)|+|S_+(n)|=o(n/log n);                         (7.3)
```
```plain text
log rad_(n/2,n](C_n^fold)=o(n).                       (7.4)
```
By `(V)`, any one of these proves the full weighted `q=1` contribution to `log G_n` is `o(n)`.
A clean sufficient theorem with quantitative slack is:
```plain text
There exists delta>0 such that, for every n,
|S_-(n)|+|S_+(n)| << n/log^(1+delta)n.                (7.5)
```
This is the weakest natural new statement exposed by the fold. It is much narrower than a full multi-prime collision theorem: it concerns two explicit linear prime forms and one Apéry value at the complementary index. But it is not supplied by present sieve theory, because the congruence `p|b_j` is an arithmetic moving-target condition, not an independent residue restriction with a known local density.
For the stronger integer statement
```plain text
log C_n^fold=o(n),                                    (7.6)
```
one must add a depth condition such as
```plain text
sum_{n/2<p<=n}
  (v_p(C_n^fold)-1)_+ log p = o(n).                   (7.7)
```
The original Apéry gcd problem does not need `(7.7)`: its Wronskian already replaces it with the uniform bound `v_p(G_n)<=6`.

# Final assessment
The folded integer target is a valuable reduction because it turns the `q=1` cross-prime condition into the old-prime part of one explicit integer. But the exact support identity (1.5) also shows the limitation:
> **At the top-half support level, ****`C_n^fold`**** contains no extra condition beyond ****`p|b_n`****.**
The binomial formula shows these primes arise by hypergeometric cancellation; the Wronskian/continuant gives a `p^2` certificate whose aggregate height is quadratic; reflection resultants are tautological; and existing primitive-divisor or Subspace-Theorem gcd machinery lacks both the divisibility-sequence structure and the aggregate old-part control.
What survives unconditionally is the `O(n/log n)` edge contribution. What remains is precisely the large-old-prime radical theorem `(OLD)`—or, equivalently, the moving-linear-form count `(LIN)`. Proving that statement would close the entire `q=1` slice without returning to cyclotomic norms or to a full collision-energy theorem.
