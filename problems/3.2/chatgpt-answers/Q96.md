## Executive verdict

1. Proved algebraically: the Plücker and restart descents reduce every genuine regular four-return pattern ({0,h,j,k}) to the common-root condition

In that case the two cascade polynomials are reflection-conjugate, and the resultant is an explicit central factor times a square of a resultant of roughly half the degree. The cases ((1,3,4)) and ((2,3,5)) below illustrate this exactly.

1. Conditional on the universal cascade-coprimality statement: if the experimentally verified rule

1. Not proved: nothing presently forces (I(p)=O(p)) for (Kasymp p), and the cascade does not imply an absolute maximum multiplicity. In fact a naive random-resultant model predicts (I(p)asymp p^2), not (p). Thus one must distinguish the necessary resultant-bad set from actually realized four-return patterns.

```python
R.<x> = PolynomialRing(ZZ)

def P(t):
    return (2*t + 1)*(17*t^2 + 17*t + 5)

def Ns(H):
    N = [R(0), R(1)]
    for r in range(1, H):
        N.append(P(x+r)*N[r] - (x+r)^6*N[r-1])
    return N

def Q(h):
    if h <= 1:
        return R(1)
    return prod((x+r)^3 for r in range(2, h+1))

def D(h,k,N):
    return (
        N[h]*(Q(k)//Q(h)) - N[k]
        + (x+1)^3*Q(h)*N[k-h](x=x+h)
    )

def primitive_tilde(h,k,N):
    f = D(h,k,N)
    forced = []
    if h % 2 == 0:
        forced.append(2*x+h+1)
    if k % 2 == 0:
        forced.append(2*x+k+1)
    if (k-h) % 2 == 0:
        forced.append(2*x+h+k+1)
    for L in forced:
        q,r = f.quo_rem(L)
        assert r == 0
        f = q
    f = f // gcd(f.list())
    if f.leading_coefficient() < 0:
        f = -f
    return f

def Rcert(h,j,k,N):
    A = primitive_tilde(h,j,N)
    B0 = primitive_tilde(j-h,k-h,N)
    B = B0(x=x+h)
    return A.resultant(B)

N = Ns(7)
for T in [(1,3,4),(1,3,5),(2,3,5),(1,4,6)]:
    r = Rcert(*T,N)
    print(T)
    print(r)
    print(factor(abs(r)))
```

# 3. Structure of bad patterns for a fixed prime

A crucial distinction is needed.

Define

[

mathcal B_p

]

and let (mathcal G_psubseteqmathcal B_p) be the patterns actually realized by a regular four-return orbit. The resultant condition is necessary, not sufficient. Consequently, even if realized patterns have closure properties, the larger set (mathcal B_p) need not have them.

## 3.1 Operations that are genuinely valid for realized return sets

Let

[

T_x={t:U_t=U_0}

]

for one fixed regular orbit segment.

1. Subset closure. Every subset of a return set is again a return configuration.

1. Restart/difference closure with base shift. If (ain T_x), then

1. Reversal. If (0,kin T_x), reversing the endpoint-conditioned solution gives the reflected return set

1. Anchor changes. A four-set ({a,a+h,a+j,a+k}) yields all of its anchored difference patterns after restart at one of its elements.

These operations explain the lattice/simplicial cascade of certificate vanishings.

## 3.2 What is not valid

There is no implication

[

a,bin T_xLongrightarrow a+bin T_x

]

and no implication that (a-b) is a return time at the original base (x). Restart changes the base parameter. Therefore (T_x) is not a subgroup, coset, approximate subgroup, or Freiman homomorphism image on present evidence.

The correct combinatorial object is a clique in a growing algebraic hypergraph:

- vertices are return times;

- every four vertices force a cascade-resultant incidence;

- restart and reversal identify certain anchored hyperedges.

Classical additive-combinatorial structure theorems do not apply unless one separately proves small doubling or additive energy for (T_x).

## 3.3 Relation between (I(p)) and maximum fiber size

If a fiber contains

[

0=t_0<t_1<cdots<t_{r-1},

]

then every choice of three positive gaps gives a distinct bad triple. Hence

[

boxed{

binom{r-1}{3}le I(p).

}

tag{3.1}

]

Thus the desired bound (I(p)=O(p)) would imply only

[

r=O(p^{1/3}),

]

not an absolute or logarithmic maximum-fiber bound. It would nevertheless be a genuine power saving.

A warning: if the integers (R_{h,j,k}) behaved randomly modulo a fixed (p), then among (asymp p^3) triples one would expect

[

I(p)asymp p^2,

]

because a random integer is divisible by (p) with probability (1/p). Therefore (I(p)=O(p)) requires an additional codimension-one structure beyond generic resultant divisibility. It may be false for the necessary-resultant set even if actual four-return collisions are Poisson-sparse. This should be tested directly before making (I(p)=O(p)) the central conjecture.

# 4. Five-fold and higher collisions

## 4.1 What is proved for a fixed pattern

For a fixed finite return pattern

[

S={0=t_0<t_1<cdots<t_{r-1}},qquad rge4,

]

choose any four-subset. If its primitive cascade resultant is nonzero, every regular realization modulo (p) forces (p) to divide that fixed nonzero integer. Hence every fixed pattern is excluded for all but finitely many primes.

For five returns, the ten triple certificates are highly redundant. The Plücker identities say that once two endpoint minors vanish, the remaining minors descend. The number ten does not by itself create ten independent equations.

## 4.4 Why five-fold certificates do not improve the product method

Any (rge5) collision already contains a four-collision. To exclude all (r)-patterns of diameter (K) by multiplying integer obstructions, the number of patterns grows as (K^{r-1}), while the height of each obstruction remains at least of resultant scale. This worsens, rather than improves, the exponent in the logarithmic window.

Five-fold information would improve matters only if one proves a joint Bézout collapse, for example:

- several of the ten certificates generate the unit ideal over (mathbf Z[x]) with a very small integer constant;

- or their primitive resultants have a uniformly bounded gcd;

- or every five-return pattern forces a fixed finite set of primes independent of the gaps.

No such theorem follows from Plücker alone, and the new prime (151) in (1.7) is evidence against a universal unit obstruction.

Hence the cascade does not currently prove that (R)-fold collisions are impossible for any absolute (R_0), nor does it give (R_0=O(log p/loglog p)). The strongest rigorous statements are:

1. fixed pattern (Rightarrow) finitely many bad primes;

1. universal nonzero resultants (+) height (Rightarrow) (4.3);

1. the same hypotheses on average over primes (Rightarrow) (4.4).

# 5. Recommended next lemmas

The shortest path to a theorem is:

1. Prove the universal cascade gcd theorem after removal of the parity-forced line. This is the one missing algebraic input needed to make every (R_{h,j,k}) nonzero.

1. Formalize the height lemma

1. Deduce the product-obstruction theorems (4.3) and (4.4). These require no distributional conjecture about prime divisors.

1. Compute (I(p)) itself for moderate (p), separately from actual four-return counts. If (I(p)) empirically scales like (p^2), the resultant family is too coarse for the desired second moment; one must count realized common roots or impose one more independent certificate.

1. For a possible stronger result, study the integer gcd of the several cascade resultants attached to one five-set. A uniform small-gcd theorem, not the mere existence of ten vanishings, is the higher-Plücker statement that could materially improve the exponent.
