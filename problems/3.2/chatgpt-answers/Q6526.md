# 3. 各存活路线的最小引理与工具归属

## A. ATR / mesoscopic Q

最小引理： 对 (Delta=sqrt plog p)，证明 (Q_p(Delta)ll p)；完整 ATR 则把 (Delta) 推到全程并控制总 (T_3)。

已有工具： 两滞后消元、continuant addition、renewal、resultant、Casoratian、镜像剥离、短-gap 因式分解。

新机制： 需要把逐 ((h,k)) 的最坏次数和，从 (O(Delta^3)) 压成平均共同根 (O(1)) 或至少得到临界窗口 packing。它仍是新定理，但没有更换范畴。

## B. GPRV

最小引理： growing-degree root-count large sieve at one fixed prime。

已有工具： 小 (h) 的 (S_m) Galois 证书、镜像强制根、Chebotarev 平均主项、判别式/高度数据。

新机制： unbounded-rank/degree 的 quenched Chebotarev variance。现有 family Chebotarev通常固定次数或在素数上平均；这里要固定素数、对不同 splitting fields 的 Frobenius 同时求方差。

## C. GAP-TIME-FEJER

最小引理： 对 mirror quotient 后的特定碰撞 observable，证明超临界低频带的矩阵元/Fejér 配对小；不是全 Koopman 谱隙。

已有工具： 精确时间 Fourier 恒等式、全 gap 数据、FFT、clock skew product。

新机制： deterministic nonautonomous product 的 observable-specific decorrelation。Bourgain--Gamburd 固定生成元卷积不适用。

## D. GAP-2D-SQRT / bilinear 2D

最小引理有前后端之分。

- 前端：构造复杂度对 (p,H) 一致的 sheaf/complex，使其 trace 表示 ((r,h)mapsto e_p(tDelta_{r,h}))，并分类 Artin--Schreier、self-twist、镜像等退化；

- 后端：对所得对象应用 bilinear/trace-product 相消。

已有数学。 若前端真的完成，后端工具很强：Fouvry--Kowalski--Michel 的 sums-of-products（arXiv:1405.2293）、Sawin--Forey--Fresán--Kowalski 的 quantitative sheaf theory（arXiv:2101.00635），以及 Fouvry--Kowalski--Michel--Sawin 2026 版 bilinear trace-function 定理（arXiv:2511.09459）都提供 bounded-complexity sheaf 的稳健相消框架。

没有的部分。 (h) 是迭代长度，不是普通代数参数；目前没有 fixed-complexity realization。Forey--Fresán--Kowalski 的 arithmetic Fourier/convolution 理论（arXiv:2109.11961）也不能凭空把非自治时间 cocycle 变成其所需的固定 perverse sheaf。

## E. rank-4 mixed cocycle

最小引理： mixed Frobenius extension coordinate must be energy-visible。

已有数学： Beukers--Vlasenko（arXiv:2302.09603）、Asakura（arXiv:1811.03770）、Asakura--Hagihara（arXiv:2307.08940）支持构造/计算 Frobenius 与 regulator extension。

## F. bispectral 低秩对象

最小引理： 找到一个阶数与 (h,p) 无关的双向闭合系统，能够同时演化 time frequency 与 projective return observable；或证明 clock-twisted 最小状态维数必须随 (H) 增长。
