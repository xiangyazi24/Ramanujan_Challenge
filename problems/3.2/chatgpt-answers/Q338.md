# The Apéry gap continuants: exact structure and the finite-field root wall

## Verdict

The family

```plain text
N_0(x)=0,
N_1(x)=1,
N_{h+1}(x)=P(x+h)N_h(x)-(x+h)^6N_{h-1}(x),
P(x)=34x^3+51x^2+27x+5,
```

has a clean exact identification, but it is not a Racah/Wilson/dual-Hahn orthogonal-polynomial family in the useful positive-measure sense.

The strongest exact description I obtain is:

(N_h) is the Dirichlet determinant and discrete Casoratian kernel of the second-order Apéry difference operator. Equivalently, it is the generalized continuant/J-fraction numerator built from the balanced contiguous ({}_4F_3) Apéry solution and its companion solution.

Concretely, if

```plain text
B(z) = _4F_3(-z,-z,z+1,z+1; 1,1,1; 1)
```

and (A(z)) is a second solution normalized by

```plain text
A(z+1)B(z)-A(z)B(z+1) = 6/(z+1)^3,
```

then

```plain text
N_h(x)
 = [prod_{j=1}^h (x+j)^3 / 6]
   [A(x+h)B(x)-B(x+h)A(x)].                         (C)
```

At nonnegative integral (x=m), this becomes the entirely elementary identity

```plain text
N_h(m)
 = ((m+h)!/m!)^3 / 6 · (a_{m+h}b_m-b_{m+h}a_m).     (C_int)
```

This is the exact structural answer. It also produces transfer, addition, Dodgson, and resultant identities useful in the zero-gap argument.

However, the identification does not yield a nontrivial all-(p) root bound in the triangular regime (hasymp p^alpha). The obstacles are exact:

1. the usual Wilson/Racah recurrence has a fixed spectral variable, whereas matching it to the Apéry recurrence would require a spectral variable depending on the degree index;

1. already (N_3), after centering, has four nonreal complex roots, ruling out a positive Wilson/Racah orthogonality measure;

1. even a genuine fixed-degree orthogonal-polynomial identification would not stop complete splitting modulo infinitely many primes;

1. for (hle H), the unconditional degree bound is only

1. the exact continuant/resultant identities control repeated or clustered roots across nearby gaps. They do not control the dominant empirical regime of isolated roots, so they reproduce the existing (p^{2/3}) zero bound but do not improve its exponent.

I found no named theorem whose checked hypotheses turn the formula below into an (O(Hp^arepsilon)), (o(H^2)), or even (o(p)) aggregate root bound for (Hasympsqrt p).

# 1. First algebra and normalization

Two factorizations of the Apéry coefficient are useful:

```plain text
P(x) = (2x+1)(17x^2+17x+5),
P(x) = 34(x+1/2)^3 + (3/2)(x+1/2).                  (1.1)
```

At integer (n),

```plain text
P(n) = (n+1)^3+n^3+4(2n+1)^3.                       (1.2)
```

The first three continuants are as follows.

## (h=1)

```plain text
N_1(x)=1.
```

This is the empty Dirichlet determinant. It satisfies

```plain text
N_1(-1)=1=(0!)^3 b_0.
```

## (h=2)

```plain text
N_2(x)=P(x+1)
      =34x^3+153x^2+231x+117
      =(2x+3)(17x^2+51x+39).                         (1.3)
```

Thus the forced central factor for even (h) is already visible. Also

```plain text
N_2(-1)=P(0)=5=(1!)^3 b_1.
```

If (y=x+3/2), then

```plain text
N_2(x)=34y^3+(3/2)y.
```

## (h=3)

Set (y=x+2). Since

```plain text
P(y)   =34y^3+51y^2+27y+5,
P(y-1) =34y^3-51y^2+27y-5,
```

we get

```plain text
N_3(x)
 =P(x+2)P(x+1)-(x+2)^6
 =1155y^6-765y^4+219y^2-25.                          (1.4)
```

At (x=-1), (y=1), so

```plain text
N_3(-1)=1155-765+219-25=584=8·73=(2!)^3b_2.
```

These three cases fix the normalization in every formula below.

# 2. The symmetry and the forced even-(h) factor

The stated reflection law can be rewritten as

```plain text
N_h(-x-h-1)=(-1)^(h-1)N_h(x).                        (2.1)
```

Define the centered polynomial

```plain text
R_h(y):=N_h(y-(h+1)/2).
```

Then

```plain text
R_h(-y)=(-1)^(h-1)R_h(y).                             (2.2)
```

Consequently:

```plain text
h=2s+1 odd:
  R_h(y) is a polynomial in y^2 of degree 3s;

h=2s even:
  R_h(y)=y·S_h(y^2),  deg S_h=3s-2.                  (2.3)
```

Thus every even (h) has the exact rational factor

```plain text
2x+h+1.                                               (2.4)
```

This explains the observed “one forced central factor times an irreducible factor” pattern. The remaining irreducibility is empirical at present; the parity factor is theorem-level and automatic.

The leading coefficient (L_h=[x^{3(h-1)}]N_h) obeys

```plain text
L_{h+1}=34L_h-L_{h-1},
L_0=0, L_1=1.
```

Hence

```plain text
L_h=U_{h-1}(17)
   =[(17+12sqrt(2))^h-(17-12sqrt(2))^h]/(24sqrt(2)).  (2.5)
```

The appearance of the Apéry growth constant here is another indication that these are Green/transfer determinants for the same difference operator, rather than an unrelated polynomial family.

# 3. Exact Dirichlet determinant and matching expansion

Let (J_{h-1}(x)) be the symmetric tridiagonal matrix indexed by (j=1,ldots,h-1):

```plain text
J_{jj}       = P(x+j),
J_{j,j+1}    = J_{j+1,j}=-(x+j+1)^3.                 (3.1)
```

Then

```plain text
N_h(x)=det J_{h-1}(x).                                (3.2)
```

Indeed, expansion at the last row gives exactly

```plain text
D_m=P(x+m)D_{m-1}-(x+m)^6D_{m-2},
D_0=1, D_1=P(x+1),
```

with (D_{h-1}=N_h).

This is the finite Dirichlet determinant of the symmetric Apéry difference expression

```plain text
(Lu)(z)=P(z)u(z)-(z+1)^3u(z+1)-z^3u(z-1).            (3.3)
```

It is a polynomial eigenvalue problem of degree three, not the characteristic polynomial of a fixed linear Jacobi pencil (J-lambda I). Standard polynomial-eigenvalue linearization can turn it into a (3(h-1))-dimensional matrix pencil, but that pencil is not a positive self-adjoint Jacobi problem; Section 6 below gives a direct root obstruction.

The determinant gives the exact path-matching formula. Let (mathcal M_{h-1}) be the matchings of the path on vertices (1,ldots,h-1). Then

```plain text
N_h(x)
 = sum_{M in M_{h-1}} (-1)^|M|
     prod_{(j,j+1) in M} (x+j+1)^6
     prod_{j unmatched} P(x+j).                      (3.4)
```

This is an explicit finite closed form. It is not a one-dimensional hypergeometric summation: the summation is over nonadjacent subsets/tilings, and the shifted cubic factors prevent the matching weights from having one hypergeometric term ratio.

The corresponding finite J-fraction is

```plain text
N_{h+1}(x)/N_h(x)
 = P(x+h)
   - (x+h)^6 /
     [P(x+h-1)
      - (x+h-1)^6 /
        [... - (x+2)^6/P(x+1)]].                     (3.5)
```

So “Apéry J-fraction continuant” is an exact concise name for the family.

For general continuants and their determinant/matching identities, see the Encyclopedia of Mathematics entry on continuants.

# 4. Exact hypergeometric-Casoratian formula

The classical Apéry solution has the balanced hypergeometric continuation

```plain text
B(z)
 = _4F_3(-z,-z,z+1,z+1; 1,1,1; 1)
 = sum_{k>=0} [(-z)_k^2(z+1)_k^2/(k!)^4].            (4.1)
```

For (z=ninmathbb Z_{ge0}), the series terminates and gives

```plain text
B(n)=sum_{k=0}^n binom(n,k)^2binom(n+k,k)^2=b_n.
```

Richard Askey and J. A. Wilson explicitly identify this balanced ({}_4F_3) and derive its three-term recurrence by balanced contiguous relations in “A recurrence relation generalizing those of Apéry,” J. Austral. Math. Soc. 36 (1984), 267–278, especially the discussion surrounding their equation (13).

Thus (B) satisfies, meromorphically in (z),

```plain text
(z+1)^3B(z+1)=P(z)B(z)-z^3B(z-1).                    (4.2)
```

Choose a second meromorphic solution (A(z)) with Casoratian normalization

```plain text
A(z+1)B(z)-A(z)B(z+1)=C/(z+1)^3.                     (4.3)
```

Taking (C=6) and the integer initial data (A(0)=0,A(1)=6) recovers the Apéry companion (a_n).

A completely explicit reduction-of-order description is obtained by writing (A=B S):

```plain text
S(z+1)-S(z)
 = C / [(z+1)^3B(z)B(z+1)].                          (4.4)
```

Now put

```plain text
R_h(x):=prod_{j=1}^h(x+j)^3.
```

Eliminating the two boundary values from the two solutions gives

```plain text
N_h(x)
 = R_h(x)/C · [A(x+h)B(x)-B(x+h)A(x)].               (4.5)
```

This is formula (C) from the verdict. It is valid wherever the meromorphic expressions are defined and extends identically to all (x), since its left side is a polynomial.

## Integer specialization

For (mge0), (C=6),

```plain text
N_h(m)
 = ((m+h)!/m!)^3 / 6
   · [a_{m+h}b_m-b_{m+h}a_m].                        (4.6)
```

Since

```plain text
a_{j+1}/b_{j+1}-a_j/b_j
 = 6/[(j+1)^3b_jb_{j+1}],                            (4.7)
```

we also have the positive formula

```plain text
N_h(m)
 = ((m+h)!/m!)^3 b_mb_{m+h}
   · sum_{j=m}^{m+h-1} 1/[(j+1)^3b_jb_{j+1}].        (4.8)
```

This proves, among other things, that (N_h(m)>0) for every integer (mge0).

Formula (4.5), not a Racah polynomial, is the natural hypergeometric closed form: a (2	imes2) Casoratian of two contiguous balanced-({}_4F_3) solutions.

I did not find a published single terminating ({}_7F_6) formula for this exact polynomial in (x). Associated Wilson polynomials do have ({}_7F_6) representations, but their recurrence is different; the comparison is made explicitly next.

# 5. Why this is not a Wilson/Racah/dual-Hahn polynomial

The connection to Wilson polynomials is real but easy to overread.

For the Wilson parameters

```plain text
a=b=c=d=1/2,
```

the standard birth-death coefficients are

```plain text
lambda_n=(n+1)^3/[2(2n+1)],
mu_n=n^3/[2(2n+1)].                                   (5.1)
```

The Wilson recurrence with a fixed spectral variable (lambda) is therefore

```plain text
(n+1)^3y_{n+1}+n^3y_{n-1}
 -[(n+1)^3+n^3]y_n
 = -2(2n+1)lambda y_n.                                (5.2)
```

But by (1.2), the Apéry recurrence requires

```plain text
P(n)-[(n+1)^3+n^3]=4(2n+1)^3.                        (5.3)
```

Matching (5.2) to Apéry would force

```plain text
lambda=-2(2n+1)^2,                                    (5.4)
```

which depends on (n). That is not an orthogonal-polynomial recurrence at a fixed spectral point.

The associated Wilson construction shifts the recurrence coefficients (nmapsto n+gamma) while retaining one fixed spectral variable. Ismail, Letessier, Valent and Wimp derive ({}_7F_6) formulas precisely for that setting in “Two Families of Associated Wilson Polynomials,” Canad. J. Math. 42 (1990), 659–695. It does not match (5.4), and it does not turn the gap length (h) continuant into a Wilson polynomial in (x).

## Direct root refutation

The mismatch is not merely terminological. From (1.4), with (t=y^2),

```plain text
N_3(x)=q(t),
q(t)=1155t^3-765t^2+219t-25.
```

Its derivative is

```plain text
q'(t)=3465t^2-1530t+219,
Disc(q')=1530^2-4·3465·219=-694440<0.                 (5.5)
```

Since the leading coefficient of (q') is positive, (q'(t)>0) on (mathbb R). Also (q(0)=-25) and (q(t)	o+infty) as (t	o+infty). Therefore (q) has exactly one real root, which is positive.

Consequently (N_3(x)=q((x+2)^2)) has exactly two real roots and four nonreal roots.

A positive-measure Wilson/Racah/dual-Hahn family has all zeros real and simple in the appropriate real spectral variable. See Koekoek–Lesky–Swarttouw, Hypergeometric Orthogonal Polynomials and Their q-Analogues, Chapters 9–10. Thus the useful positive-orthogonality premise is already false at (h=3).

One could always manufacture a nonpositive or complex moment functional for a polynomial sequence, but that would supply neither real interlacing nor a finite-field root bound, so it does not help the present problem.

# 6. Transfer matrix and addition formula

Set

```plain text
T(z) = [[P(z), -z^6],
        [1,       0]].                                (6.1)
```

Then

```plain text
[N_{h+1}(x)]   = T(x+h)T(x+h-1)...T(x+1) [1],
[N_h(x)    ]                                  [0].    (6.2)
```

A direct multiplication gives the exact block formula

```plain text
T(X+d-1)...T(X)
 = [[N_{d+1}(X-1), -X^6N_d(X)],
    [N_d(X-1),     -X^6N_{d-1}(X)]].                 (6.3)
```

Hence, for (dge1),

```plain text
N_{h+d}(x)
 = N_d(x+h)N_{h+1}(x)
   -(x+h+1)^6N_{d-1}(x+h+1)N_h(x).                  (6.4)
```

This is the exact gap-composition identity. In particular, away from singular indices,

```plain text
N_h(x)=N_{h+d}(x)=0,
N_{h+1}(x) != 0
    => N_d(x+h)=0.                                    (6.5)
```

Thus two zeros separated by gap (d) are certified by a root of the shorter shifted continuant. This is the algebra behind the existing pair-gap root bound.

# 7. Dodgson identity and an exact adjacent resultant

Desnanot–Jacobi condensation for the tridiagonal determinant yields

```plain text
N_{h+1}(x)N_{h-1}(x+1)
 -N_h(x)N_h(x+1)
 = -prod_{j=2}^h(x+j)^6.                              (7.1)
```

For (h=2), this is simply

```plain text
N_3(x)-N_2(x)N_2(x+1)=-(x+2)^6.
```

It follows immediately that a common root of (N_h) and (N_{h+1}) can occur only at the explicit singular points

```plain text
x=-2,-3,...,-h.                                       (7.2)
```

There is also an exact resultant formula. With the convention

```plain text
Res(f,g)=lead(f)^(deg g) prod_{f(alpha)=0} g(alpha),
```

recurrence reduction at the roots of (N_h) gives

```plain text
Res_x(N_h,N_{h+1})
 = (-1)^(h(h-1)/2)
   prod_{j=1}^{h-1} [(j!)^3 b_j]^6.                  (7.3)
```

Proof: at a root (alpha) of (N_h),

```plain text
N_{h+1}(alpha)=-(alpha+h)^6N_{h-1}(alpha),
```

so the resultant recurses by the factor (N_h(-h)^6); reflection gives

```plain text
N_h(-h)=(-1)^(h-1)N_h(-1)
       =(-1)^(h-1)((h-1)!)^3b_{h-1}.
```

Iterating gives (7.3), including its sign.

This formula is useful information, but it also diagnoses the obstruction. For (p>h), adjacent continuants can share a root modulo (p) only if (p) divides one of (b_1,ldots,b_{h-1}). Thus generic root sets for neighboring (h)'s are disjoint. Disjointness does not reduce the total number of root pairs ((h,x)); if anything, it shows why a gcd/resultant argument alone cannot control a population of isolated roots.

# 8. Generating function in the gap length

Let

```plain text
F_x(t):=sum_{h>=0}N_h(x)t^h,
theta:=t d/dt.
```

Multiplying the recurrence by (t^{h+1}) and summing over (hge1) gives the exact differential equation

```plain text
[1-tP(x+theta)+t^2(x+1+theta)^6]F_x(t)=t.            (8.1)
```

This is a sixth-order inhomogeneous D-finite equation in (t). It is a useful uniform encoding of all gaps.

But it is not a bounded-degree bivariate algebraic relation in ((h,x)). The discrete length (h) enters through coefficient extraction from a sixth-order D-finite function. Consequently one cannot directly put the set

```plain text
{(h,x): N_h(x)=0}
```

on one fixed bounded-degree algebraic curve and invoke Lang–Weil or a standard two-variable Deligne theorem.

Equation (8.1) is therefore a genuine alternative identity to bank, but not yet a finite-field root theorem.

# 9. What the exact identification proves over finite fields

For (h<p), the existing continuant lemma in the project proves that (N_h) is not the zero polynomial modulo (p). See the self-contained development in working_notes/Q3.2_density_theorem.md.

Therefore the unconditional individual bound is exactly

```plain text
R_h(p):=#{x in F_p:N_h(x)=0}
       <= min(p,3(h-1)).                              (9.1)
```

Summing degrees gives

```plain text
sum_{h=1}^H R_h(p)
 <= sum_{h=1}^H 3(h-1)
 = (3/2)H(H-1).                                       (9.2)
```

At (Hasympsqrt p), this is (O(p)), with no saving.

The parity symmetry supplies a lower calibration: for every even (h<p), the central factor gives one root

```plain text
x=-(h+1)/2 mod p.
```

Hence

```plain text
sum_{h<=H}R_h(p) >= floor(H/2)                        (9.3)
```

for odd (p). The empirical target should therefore be (O(Hp^arepsilon)), not (O(1)).

## Fixed-(h) Chebotarev obstruction

Suppose the observed irreducible factor of a fixed (N_h) is separable over (mathbb Q). Its splitting field is a fixed finite extension. Chebotarev gives infinitely many primes splitting completely in that field. At those primes the factor has its full degree worth of roots.

Thus even perfect irreducibility over (mathbb Q) cannot imply an all-prime (O(1)) root bound. It predicts the opposite: rare exceptional primes with (R_h(p)) as large as the degree.

Effective Chebotarev—classically Lagarias–Odlyzko and modern refinements such as Thorner–Zaman, “A unified and improved Chebotarev density theorem”—is a theorem for a fixed number field with constants depending on its degree and discriminant. Here the field changes with (h), its defining degree is (3(h-1)), and no uniform control of its splitting-field degree or discriminant is available. At (pasymp h^2), even GRH-scale errors involving the field degree are already too large, before accounting for a potentially factorial Galois degree.

So fixed-(h) Chebotarev does not interpolate into the critical triangular regime.

# 10. Why standard finite-field hypergeometric bounds do not close the gap

Assume optimistically that (N_h(x)) is treated merely as a degree-(d_h=3(h-1)) polynomial. Additive orthogonality gives

```plain text
R_h(p)
 = 1 + (1/p) sum_{t != 0} sum_{x in F_p} e_p(tN_h(x)). (10.1)
```

The usual Weil bound for a non-Artin–Schreier polynomial gives, at best,

```plain text
|sum_x e_p(tN_h(x))| <= (d_h-1)sqrt(p).               (10.2)
```

After summing over (t),

```plain text
R_h(p)=1+O(h sqrt(p)),                                (10.3)
```

which is much worse than the elementary degree bound (O(h)) in the range (h<sqrt p).

A trace-function formulation with conductor (O(h)) has the same problem. Deligne gives cancellation in a sum over (x), but the zero indicator requires an additional sum over all additive characters (t), and the result loses the square-root factor.

A useful theorem would have to exploit cancellation simultaneously in (h), (x), and the zero-detecting character, not one fixed-(h) Weil bound.

# 11. Recovery of the existing (p^{2/3}) exponent

Let

```plain text
r_1<r_2<...<r_z<p
```

be first-block Apéry zeros modulo (p), and let

```plain text
d_i=r_{i+1}-r_i.
```

The no-consecutive-zero lemma gives the required nonzero neighboring state, and the addition/gap formula yields

```plain text
N_{d_i}(r_i)=0 mod p.                                 (11.1)
```

Choose a cutoff (K).

For gaps (d_ile K), the degree bound gives

```plain text
#short gaps
 <= sum_{d<=K} 3(d-1)
 < (3/2)K^2.                                          (11.2)
```

For gaps (d_i>K), disjointness of intervals gives

```plain text
#long gaps < p/K.                                     (11.3)
```

Thus

```plain text
z-1 < (3/2)K^2+p/K.                                  (11.4)
```

The optimum satisfies (K^3=p/3), yielding

```plain text
z <= (3/2)·3^(1/3)p^(2/3)+O(1)
  < 3p^(2/3)+O(1).                                    (11.5)
```

This shows exactly what the continuant family currently buys.

Higher fixed-gap tuples do not improve the exponent. An (r)-tuple certificate consumes (r-1) independent gap parameters, and the corresponding degree count grows at least like a power of the cutoff; balancing against long gaps leads to (p^{(r-1)/r}), which is worse for (rge3). This agrees with the project’s computational/resultant audit in Q32_RUN_LOG.md.

The method is strongest for detecting clusters. The data say the zeros are typically isolated; that is precisely the regime in which these certificates carry the least information.

# 12. What an aggregate breakthrough would actually require

The exact formulas above narrow the viable next inputs.

## 12.1 A genuinely two-parameter cancellation theorem

One would like, for (Hle p^{1/2}), a bound such as

```plain text
sum_{h<=H} #{x:N_h(x)=0}
 << H p^epsilon.                                      (12.1)
```

By additive orthogonality this asks for cancellation in

```plain text
sum_{h<=H} sum_{t != 0} sum_x e_p(tN_h(x)),           (12.2)
```

or an equivalent bilinear form formed from the transfer matrices (T(x+j)). No existing bounded-conductor theorem applies because the polynomial/transfer complexity grows with (h).

## 12.2 A transfer-matrix orbit theorem

Formula (6.2) says that roots are the parameters (x) for which a product of noncommuting (2	imes2) matrices sends ((1,0)) into a coordinate hyperplane. A sum-product/expander theorem for this nonautonomous polynomial matrix product could in principle give (12.1). Standard expansion theorems concern repeated products from a fixed bounded generating set; here every factor varies with (x+j), so their hypotheses are not presently met.

## 12.3 Resultant dispersion, not merely resultant nonvanishing

Equations (6.4), (7.1), and (7.3) completely control nearby common roots. To improve the first moment, one would need a theorem saying that many different isolated roots for many (h)'s force a resultant/product contradiction. The adjacent resultant does not do this: it is compatible with all root sets being disjoint.

Moreover, (7.3) expresses the resultant through the Apéry numbers (b_j), so using its prime divisors horizontally tends to reintroduce the original divisibility problem rather than eliminate it.

## 12.4 A closed form with explicit roots

A Krawtchouk/Chebyshev-type formula with roots parameterized by a bounded-degree equation would change the situation. The Casoratian formula (4.5) is not of that type: its roots are equality points of two Apéry solution ratios,

```plain text
A(x+h)/B(x+h)=A(x)/B(x),                              (12.3)
```

and the degree of that equality grows linearly with (h). No bounded-complexity parametrization emerges.

# 13. Direct answers

## Exact closed form / identification

Yes, in the following precise sense:

```plain text
N_h = generalized continuant
    = Dirichlet determinant of the Apéry difference operator
    = finite Apéry J-fraction numerator
    = normalized Casoratian of two balanced contiguous _4F_3 solutions.
```

The exact formulas are (3.2), (3.4), (3.5), and especially (4.5)/(4.6).

I did not find a valid identification with a classical Racah, Wilson, dual-Hahn, or positive associated-Wilson polynomial. The fixed-spectral-variable comparison (5.2)–(5.4) and the nonreal roots of (N_3) refute that premise.

## Can this prove a nontrivial root bound for (h) growing with (p)?

Not with a currently available named theorem.

- Fixed-(h) irreducibility is compatible with complete splitting at infinitely many primes.

- Standard finite-field polynomial/trace bounds are weaker than degree counting here.

- Effective Chebotarev has no useful uniformity as the field changes with (h).

- Orthogonality/interlacing is archimedean and, in fact, unavailable.

- Continuant/resultant identities control clustered roots and recover the (p^{2/3}) theorem, but isolated roots escape them.

## Best identities to retain for the next attack

```plain text
1. Hypergeometric Casoratian:             (4.5)
2. Integer ratio-difference formula:      (4.6)–(4.8)
3. Transfer/addition law:                 (6.4)
4. Dodgson/Christoffel-Darboux analogue:  (7.1)
5. Exact adjacent resultant:              (7.3)
6. Gap-length generating ODE:             (8.1)
7. Matching expansion/J-fraction:         (3.4)–(3.5)
```

The most promising genuinely new direction is not further recognition inside the Askey scheme. It is a horizontal cancellation theorem for the nonautonomous transfer-matrix/Casoratian family, or a resultant-dispersion theorem that controls isolated roots rather than only clusters.
