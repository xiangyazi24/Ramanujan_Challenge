# The uniform object is the relation-product map, not the quadratic character field’s norm

## Executive verdict

There are two different extensions/maps which coincide in degree only in the sextic pair lane and must now be separated.

For a relation word w, put

```plain text
K = K12 = L^H,
D = Stab_Q(w),
F = F_w = L^D,
chi = chi_w : D -> F2,
U = ker(chi),
E_chi = L^U.
```

Then:

```plain text
E_chi/F is quadratic.
```

This quadratic extension determines the target square class

```plain text
[d_chi] in F*/F*2,
F(sqrt(d_chi)) = E_chi.
```

But the element delta must still lie in K, and it reaches that character through the multiplicative relation-product map

```plain text
Phi_w : K*/K*2 -> F*/F*2,
Phi_w([delta]) = [P_w(delta)],
P_w(delta) = product_i sigma_i(delta)^(w_i).
```

The exact reachability criterion is

```plain text
Phi_w([delta]) = [d_chi].
```

Equivalently,

```plain text
P_w(delta) = d_chi * s^2          for some s in F*.
```

Then

```plain text
gamma_w = s * sqrt(d_chi) in L
```

satisfies gamma_w^2=P_w(delta) and transports by chi because s is fixed by D.

This gives the decisive corrections:

1. For a clean orbit-size-3 block, F is cubic and P_w=N_{K/F} is a quartic norm, but the condition is a norm modulo squares:

1. The quadratic field E_chi/F specifies [d_chi]; it is not the extension from which the production column is normed. Running rnfisnorm(E_chi/F,d_chi) is irrelevant: it returns an element of E_chi, not the required delta in K.

1. For orbit size 12 there is no nontrivial relative extension K/F when F is the same embedded degree-12 field. The word map is direct—identity for a singleton word, or a genuine monomial map for another H-invariant word.

The sextic lane is the special case where [K:F]=2; only there does the squareclass-norm condition reduce to the exact norm equation used in Q174.

# 1. Exact algebraic criterion

Let

```plain text
Omega = Q/H,
P_w(delta) = product_{xH in Omega} x(delta)^(w_x).
```

Since D=Stab_Q(w), the product is fixed by D, hence lies in F=L^D.

The character chi defines the quadratic subextension

```plain text
E_chi = L^ker(chi) = F(sqrt(d_chi)).
```

## Proposition

A candidate delta in K* realizes the relation word w with transport character chi if and only if

```plain text
[P_w(delta)] = [d_chi] in F*/F*2.
```

### Proof

If the classes agree, write

```plain text
P_w(delta) = d_chi * s^2,  s in F*.
```

Then

```plain text
gamma_w = s * sqrt(d_chi)
```

lies in L, squares to P_w(delta), and for g in D,

```plain text
g(gamma_w)/gamma_w
  = g(s)/s * g(sqrt(d_chi))/sqrt(d_chi)
  = (-1)^chi(g).
```

Conversely, if gamma_w^2=P_w(delta) and gamma_w has character chi, then

```plain text
F(gamma_w) = E_chi,
```

so P_w(delta) and d_chi define the same quadratic extension and therefore the same square class.

Thus the exact obstruction group for a word is

```plain text
C_w = F*/(F*2 * P_w(K*)).
```

The target is reachable exactly when [d_chi] is trivial in C_w.

# 2. When the word map is an honest relative norm

Orbit size alone is insufficient. Before arithmetic, GAP must classify the word.

Choose the representative so that its support contains the distinguished point H. Put D=Stab_Q(w).

The word is a clean block word precisely when

```plain text
H <= D
and
supp(w) = D/H inside Q/H.
```

Then

```plain text
F=L^D is a subfield of K=L^H,
[K:F] = [D:H] = 12/[F:Q],
P_w(delta) = N_{K/F}(delta).
```

If H<=D but the support is a union of several D-orbits, or if H is not contained in D, the map is not one relative norm. It is a monomial-resolvent map and must be compiled directly as Phi_w.

Production route record:

```plain text
word_orbit_size
D = Stab_Q(w)
H_le_D
support_equals_D_over_H
clean_block_flag
relative_degree = [D:H] if clean
word_map_backend = NORM | TOWER_NORM | MONOMIAL
```

# 3. Orbit size 3: the quartic clean-block case

Assume the clean-block test passes. Then

```plain text
[F:Q] = 3,
[K:F] = 4,
P_w(delta) = N_{K/F}(delta).
```

The target equation is

```plain text
[N_{K/F}(delta)] = [d_chi] in F*/F*2.
```

Define the induced linear map

```plain text
Nbar_K/F : K*/K*2 -> F*/F*2,
[delta] |-> [N_{K/F}(delta)].
```

It is an F2-linear map. The production implementation should compute this map on the same finite squareclass source used by the outer delta solver.

## 3.1 Why exact rnfisnorm(d_chi) is too strong

Suppose a valid column satisfies

```plain text
N_{K/F}(delta) = d_chi * s^2.
```

For a quadratic extension, multiplying delta by s^-1 in F changes its norm by s^-2, because

```plain text
N_{K/F}(s) = s^2.
```

Hence in relative degree 2, a norm modulo squares can always be converted to an exact norm. This justifies Q174.

For relative degree 4,

```plain text
N_{K/F}(s) = s^4.
```

Multiplying by base-field elements changes the norm only by fourth powers; it cannot generally remove the factor s^2. Therefore

```plain text
d_chi exact norm from K     => valid squareclass column,
```

but the converse can fail.

Consequently:

```plain text
rnfisnorm(T_KF,d_chi)[2] == 1
```

is a sufficient fast success, but failure of that exact norm equation is not a reachability certificate for an orbit-size-3 word.

# 4. Executable cubic-column recipe

Use two complete squareclass contexts:

```plain text
X_K = K(S_K,2),  basis x_1,...,x_a,
X_F = F(S_F,2),  basis y_1,...,y_b.
```

Each context must include:

```plain text
S-units modulo squares,
real-sign coordinates when relevant,
lifts of the S-class-group 2-torsion.
```

The existing Q174 character solver supplies

```plain text
d_chi in F*,
b = coords_F(d_chi) in F2^b.
```

Compile once per (base_id, word-field embedding, S_K, S_F):

```plain text
M_N[:,j] = coords_F(N_{K/F}(x_j)).
```

Then solve

```plain text
M_N z = b over F2.
```

For a solution z, set

```plain text
delta_col = product_j x_j^(z_j).
```

Audit

```plain text
q = N_{K/F}(delta_col)/d_chi,
nfeltissquare(F,q,&s) == 1.
```

The coherent relation root is

```plain text
gamma_w = s * sqrt(d_chi).
```

## GP 2.17-style pseudocode

The helpers selmer_coords and selmer_product denote the exact coordinate encoder/decoder already present in the Q174 implementation.

```javascript
rank2(M) = matrank(M * Mod(1,2));

/* Convert an absolute K element to the relative K/F representation using
   the exact cached embedding.  In a concrete implementation this normally
   wraps rnfeltabstorel or the registry's conversion matrix. */
K_to_rel(KFctx, x) = KFctx.to_relative(x);

compile_norm_squareclass_map(KFctx, Kctx, Fctx) =
{
  my(a = Kctx.dim, b = Fctx.dim);
  my(M = matrix(b,a));

  for(j=1,a,
    my(xrel = K_to_rel(KFctx,Kctx.gens[j]));
    my(nj = rnfeltnorm(KFctx.rnf,xrel));
    my(c = selmer_coords(Fctx,nj));
    if(#c != b, error("F Selmer coordinate length mismatch"));
    for(i=1,b, M[i,j] = lift(c[i]) % 2);
  );
  M
};

solve_norm_squareclass_column(KFctx,Kctx,Fctx,MN,dchi) =
{
  my(b = selmer_coords(Fctx,dchi));
  my(sol = matsolvemod(MN,2,b,1));
  if(sol == 0,
    return(["NOT_IN_CURRENT_NORM_SQUARECLASS_IMAGE"]);
  );

  my(z = lift(sol[1]) % 2);
  my(delta = selmer_product(Kctx,z));
  my(drel = K_to_rel(KFctx,delta));
  my(ndelta = rnfeltnorm(KFctx.rnf,drel));
  my(q = nfeltdiv(Fctx.bnf.nf,ndelta,dchi));
  my(s);

  if(!nfeltissquare(Fctx.bnf.nf,q,&s),
    error("norm-squareclass audit failed"));

  return(["OK",delta,z,ndelta,q,s]);
};
```

The returned delta is the production norm column. It need not satisfy Norm(delta)=dchi exactly; the square quotient q=s^2 is harmless and must be retained in the relation-root provenance.

## 4.1 Optional use of rnfisnorm

You may retain an exact-norm fast path:

```javascript
T = rnfisnorminit(Fctx.bnf, KFctx.relpol, 2);
N = rnfisnorm(T,dchi);
if(N[2] == 1, return exact preimage N[1]);
```

Also, if the returned correction N[2] is itself a square in F, then N[1] already gives a valid squareclass preimage. But a nonsquare correction from one run is not a proof that no squareclass preimage exists; the compiled matrix is the decision procedure.

# 5. What support must be used?

For the target radicand context over F, use the Q174 support:

```plain text
primes over 2,
primes ramified in E_chi/F,
class-group 2-torsion support,
plus probe primes only as unramified symbol tests, not support.
```

For the source context over K, start with

```plain text
primes over S_F,
primes ramified in K/F,
primes supporting the current outer delta source,
K-side S-class-group 2-torsion lifts.
```

If the norm-squareclass solve is empty, enlarge S_K, not the already-fixed character class. Add prime-ideal directions whose norm columns increase the rank or reduce the target cokernel.

A no-solution result has two possible strengths:

```plain text
NO_SOLUTION_IN_CONTEXT:
  target outside the image of the currently compiled K(S_K,2).

CERTIFIED_WORD_UNREACHABLE:
  target nontrivial in F*/(F*2 N_{K/F}K*), after a complete relative
  norm-squareclass/cokernel computation.
```

Do not promote the first status to the second merely because a large S-unit list was tried.

# 6. Cyclic C4, V4, and the Hasse norm principle

Compute on the GAP side:

```plain text
relative_galois = IsNormal(D,H),
relative_group  = D/H when normal.
```

For clean cubic blocks, the relative degree is four.

- If D/H = C4, the exact Hasse norm theorem applies: an element of F* is an exact norm from K iff it is an exact norm everywhere locally.

- If D/H = V4, the Hasse norm principle can fail; local norm tests are not sufficient in general.

- If H is not normal in D, K/F is non-Galois quartic and there is no general local-global norm theorem.

This distinction matters only if you try to replace the global computation by local exact-norm tests. The matrix built from actual global elements and rnfeltnorm does not rely on a Hasse principle.

PARI 2.17's rnfisnorm solves the exact equation N(x)=a; its documentation guarantees the q=1 decision when the relative extension is Galois, and gives a GRH-dependent completeness condition for a non-Galois extension with a sufficiently large prime set. That still concerns exact norms, not the weaker norm-modulo-squares equation required here.

If K/F has an intermediate quadratic field M, you may compile the map as

```plain text
Nbar_K/F = Nbar_M/F o Nbar_K/M.
```

This is a useful optimization for both C4 and V4 towers, but it does not remove the need to solve the composed squareclass map.

# 7. Orbit size 12

A degree-12 F_w cannot be a proper subfield of a degree-12 K. Thus the phrase

```plain text
K12/F_w quadratic
```

is impossible. There are three cases.

## 7.1 Clean singleton word

After coordinate transport, suppose

```plain text
D=H,
F_w=K,
w=e_H.
```

Then

```plain text
P_w(delta)=delta,
Phi_w = identity on K*/K*2.
```

The target column is simply

```plain text
delta_col = d_chi in K*/K*2.
```

This is not automatically degenerate. It means sqrt(delta) lies in L, so K(sqrt(delta)) is a quadratic subfield extension of K inside the existing normal closure. It is degenerate only if [d_chi]=1 in K*/K*2 or the resulting degree-24 field fails the transitivity/irreducibility gate.

## 7.2 Conjugate singleton

If w=q(e_H) and F_w=q(K), then

```plain text
P_w(delta)=q(delta).
```

Transport the target class back through the cached embedding:

```plain text
delta_col = q^-1(d_chi).
```

No norm equation is involved.

## 7.3 Other orbit-size-12 words

An H-invariant word can be a union of nontrivial H-orbits rather than a singleton. Its product still lies in K, but the map can be genuinely nontrivial.

Example: for the complement of the distinguished singleton,

```plain text
w = all_ones + e_H,
P_w(delta) = N_{K/Q}(delta)/delta.
```

Modulo squares,

```plain text
Phi_w([delta]) = [N_{K/Q}(delta)/delta].
```

Compile this map on the K-Selmer basis exactly as for the norm matrix. Thus size-12 words are not a generic zero column; they are direct or monomial endomorphisms of squareclass spaces.

If D is an index-12 subgroup not aligned with H, F_w is a sibling degree-12 field, not a subfield of K. Use the explicit monomial-resolvent map into that embedded sibling field.

# 8. Uniform recipe for every word orbit

The correct universal algorithm is:

```plain text
A. Character stage
   chi_w : D_w -> F2
   U_w = ker chi_w
   E_w = L^U_w
   compute [d_w] in F_w*/F_w*2 with E_w=F_w(sqrt(d_w)).

B. Word-map stage
   compile Phi_w : K(S_K,2) -> F_w(S_w,2),
   [delta] |-> [P_w(delta)].

C. Column solve
   solve Phi_w(z) = [d_w].

D. Audit
   P_w(delta(z))/d_w is a square in F_w;
   use its square root times sqrt(d_w) as gamma_w.
```

Backend selection:

```plain text
if clean block:
    Phi_w = norm on squareclasses K -> F_w
elif word decomposes through a certified subfield ladder:
    Phi_w = composition/product of norm maps
else:
    Phi_w = compiled monomial-resolvent map
```

The quadratic extension E_w/F_w is always used in Stage A. It is not, in general, the norm source in Stage B.

# 9. Clean-block table for m dividing 12

Let

```plain text
m = [F_w:Q],
n = [K:F_w] = 12/m.
```

For a clean block:

```plain text
m=1,  n=12: absolute norm to Q modulo squares; nontrivial obstruction.
m=2,  n=6:  norm modulo squares; use a compiled matrix.
m=3,  n=4:  quartic norm modulo squares; use the cubic recipe above.
m=4,  n=3:  automatically surjective on squareclasses.
m=6,  n=2:  Q174; exact rnfisnorm is equivalent to squareclass reach.
m=12, n=1:  direct identity/transport for a singleton block.
```

The odd-degree case n=3 is automatically surjective because for a in F* viewed inside K,

```plain text
N_{K/F}(a)=a^3 = a * a^2,
```

so [N(a)]=[a]. More generally, restriction followed by norm is multiplication by n, hence the identity on F*/F*2 when n is odd.

For even n, the norm-squareclass image can be proper and must be computed.

# 10. Mixed routes

For a route with relation representatives w_1,...,w_r, do not solve each column independently and then hope they coexist. Compile all maps against one common K-squareclass coordinate vector z:

```plain text
Phi_w1(z) = d_1,
Phi_w2(z) = d_2,
...
Phi_wr(z) = d_r,
plus signature and exact-code equations.
```

In matrix form, stack the blocks:

```plain text
[ M_w1 ]       [ b_1 ]
[ M_w2 ] z  =  [ b_2 ]
[  ... ]       [ ... ]
[ sign ]       [ s   ]
```

For (3,12) routes, this is exactly a quartic norm-squareclass matrix stacked with a direct or monomial degree-12 map. For (3,6), stack the quartic map with the quadratic Q174 map.

Only one representative per Q-orbit is needed after the transported-character compatibility checks; all conjugate words are audits of the same equation.

# 11. Routes with orbit size not dividing 12

The live histogram contains orbit sizes such as 8, 24, 48, and 64. In those cases F_w cannot be a subfield of the degree-12 K merely from degree considerations. There is no relative polynomial K/F_w and no rnfisnorm(K/F_w,...) call.

They are not algebraically impossible. They require the general monomial map

```plain text
Phi_w([delta])=[P_w(delta)] in F_w*/F_w*2,
```

implemented by one of:

```plain text
- a cached closure packet;
- a custom monomial resolvent for the word orbit;
- a lower-degree subfield tower that computes the same product.
```

Thus the genuine boundary is not “non-sextic”; it is

```plain text
clean/tower-computable word map
versus
uncompiled monomial-resolvent word map.
```

# Implementation-critical warning

The most dangerous bug is to identify the two quadratic-looking objects:

```plain text
E_chi/F_w = L^ker(chi_w)/F_w       character field,
K/F_w or Phi_w                     column-producing word map.
```

In the sextic pair lane, K/F_w also has degree two, which hides the distinction. For cubic words, replacing the quartic norm-squareclass equation by rnfisnorm(E_chi/F_w,d_chi) constructs an element in the wrong field and proves nothing about the existence of delta in K.

The second most dangerous bug is to use q!=1 from rnfisnorm(K/F,d_chi) as a cubic-route rejection. For relative degree four, exact norm failure does not imply norm-modulo-squares failure. The authoritative gate is the F2 norm-squareclass matrix and the final nfeltissquare(N(delta)/d_chi) audit.
