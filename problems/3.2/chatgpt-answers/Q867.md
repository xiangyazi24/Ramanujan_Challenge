# Executive verdict

The proposed candidate-window radical is a valid sufficient carrier, but the single-a=1 route does not presently prove it and is probably overstrong. The exact local analysis reveals a forced multiplier-pollution term that has nothing to do with the moving target node.

The main new point is sharper than the current working-note Section 159:

```plain text
For every prime p>H, let e_s=v_p(A_s), 0<=s<=H, and let

e_(1) >= e_(2) >= ... >= e_(H+1)

be these valuations in decreasing order, including zeros. Then

v_p(m_H)=e_(2).
```

Consequently,

```plain text
p | m_H
iff
p divides A_s at at least two distinct nodes 0<=s<=H.
```

Thus the multiplier support in the candidate window is exactly the set of candidate primes having at least two prefix Apéry zeros. It is not merely bounded below by that set.

A unique prefix zero is completely cancelled from m_H, even if it has higher p-adic multiplicity. This corrects the sentence in current Section 159 saying that higher multiplicity leaves a residual condition.

The exact candidate support splits into three disjoint classes:

```plain text
(i)  at least two prefix zeros: forced multiplier support;
(ii) exactly one prefix zero, at the moving node j=3H+1-p:
     target support through z_H(3H+1);
(iii) no prefix zero, but the primitive projective line has root j mod p:
      zero-free root pollution.
```

The first class is the obstruction. At H=50000, the repository's exact modular scan reports 317 candidate primes with at least two prefix zeros and logarithmic weight

```plain text
0.07427438645 * H,
```

while the moving target set at that height is empty. By the theorem above, this is the exact candidate-window multiplier support, not merely a lower bound. Hence all 317 primes are good-prime multiplier pollution. This does not disprove an eventual o(H) asymptotic, but it refutes the strongest false intermediate implication

```plain text
p | m_H  ==>  p | A_(3H+1-p)
```

and overturns the sparse-support heuristic through the current scan range.

The strongest honest weakening obtainable from this one certificate is stated in Section 8 below. It removes automatic good multiplier pollution but still leaves two genuine estimates: a primitive-root estimate and a target-conditioned double-zero estimate. Neither follows from current Lucas/Dwork congruences.

# 4. Exact second-largest-valuation theorem

## Theorem

Let p>H, and order the numbers e_s=v_p(A_s) as

```plain text
e_(1)>=e_(2)>=...>=e_(H+1)>=0.
```

Then

```plain text
v_p(m_H)=e_(2).                                  (4.1)
```

## Proof: lower bound

The primitive polynomial z_H is a nonzero linear polynomial modulo every prime: its two integer coefficients are coprime, so they cannot both vanish modulo p.

Therefore z_H has at most one root in F_p.

If e_(2)=0, the lower bound is trivial. Suppose e_(2)>0. There are two distinct nodes r,t with

```plain text
p|A_r,
p|A_t,
min(e_r,e_t)>=e_(2).
```

At most one of r,t is a root of z_H modulo p. At the other node, say u,

```plain text
v_p(z_H(u))=0.
```

Equation (3.1) then gives

```plain text
v_p(m_H)>=e_u>=e_(2).                            (4.2)
```

## Proof: upper bound when the maximum is repeated

If

```plain text
e_(1)=e_(2),
```

then (3.1) immediately gives

```plain text
v_p(m_H)<=max_s e_s=e_(1)=e_(2).
```

Together with (4.2), equality follows.

## Proof: upper bound when the maximum is unique

Assume

```plain text
e_(1)>e_(2),
```

and let r be the unique node with e_r=e_(1)=E.

Then

```plain text
v_p(T_r)=0,

v_p(T_s)=E-e_s>=E-e_(2)
for s!=r.
```

Hence

```plain text
X_H=T_r+p^(E-e_(2))a
```

for some p-adic integer a. In particular,

```plain text
p does not divide X_H,
p does not divide h_H.
```

Also

```plain text
Y_H-rX_H
 =sum_(s!=r)(s-r)T_s,
```

so

```plain text
v_p(z_H(r))
 =v_p(Y_H-rX_H)
 >=E-e_(2).
```

Therefore the deficiency at r is at most

```plain text
e_r-v_p(z_H(r))
 <=E-(E-e_(2))
 =e_(2).
```

At every other node s!=r,

```plain text
e_s-v_p(z_H(s))<=e_s<=e_(2).
```

Using (3.1),

```plain text
v_p(m_H)<=e_(2).
```

Together with the lower bound, this proves (4.1).

## Corollaries

For every p>H,

```plain text
p|m_H
iff
e_(2)>0
iff
#{s in [0,H]:p|A_s}>=2.                         (4.3)
```

More strongly, the full exponent of p in m_H is the second-largest prefix valuation.

This removes z_H entirely from the large-prime multiplier ledger.

# 5. A unique zero is cancelled at every multiplicity

Let

```plain text
Z_p(H)={s in [0,H]:p|A_s}.
```

Suppose

```plain text
Z_p(H)={r},
E=v_p(A_r)>=1.
```

Then r is the unique maximum-valuation node, and all other A_s are p-units. The preceding calculation improves to

```plain text
X_H=T_r+p^E a,
Y_H=rT_r+p^E b,
```

with T_r a p-adic unit. Hence

```plain text
p does not divide h_H,
v_p(z_H(r))>=E=v_p(A_r),
p does not divide m_H.                            (5.1)
```

Modulo p,

```plain text
z_H(x)=u(r-x)
```

for some u in F_p^*. Thus r is the unique root of z_H modulo p.

This proves that the simple-zero hypothesis in current Section 159 is unnecessary. The sentence

```plain text
Higher p-adic multiplicity leaves the exact residual condition
```

is too weak: uniqueness alone forces complete cancellation from m_H.

# 6. Exact local classification in the candidate window

Now assume

```plain text
2H<p<=n,
j=n-p.
```

Since

```plain text
P_H^prim(n)=m_H z_H(n),
```

we separate the multiplier and root cases.

## Case A: at least two prefix zeros

If

```plain text
#Z_p(H)>=2,
```

then (4.3) gives

```plain text
p|m_H,
```

and therefore

```plain text
p|P_H^prim(n)
```

regardless of the moving node j and regardless of whether p|z_H(n).

This prime is a target exactly when

```plain text
j in Z_p(H).
```

If j is not a zero, it is forced good-prime multiplier pollution.

## Case B: exactly one prefix zero

Suppose

```plain text
Z_p(H)={r}.
```

By Section 5,

```plain text
p does not divide m_H,
z_H(x)=u(r-x) (mod p).
```

Since

```plain text
n=p+j=j (mod p),
```

we get the exact equivalence

```plain text
p|P_H^prim(n)
iff
p|z_H(n)
iff
j=r.                                               (6.1)
```

Thus a unique zero contributes if and only if it is the moving target zero. A unique zero at any other prefix node contributes neither through m_H nor through z_H(n).

## Case C: no prefix zero

If

```plain text
Z_p(H)=empty,
```

then p does not divide m_H. The prime lies in the radical exactly when

```plain text
p|z_H(n).
```

In terms of the unprimitive cleared moments, this is the exact condition

```plain text
v_p(Y_H-nX_H)
 > min(v_p(X_H),v_p(Y_H)).                         (6.2)
```

Equivalently, after dividing [X_H:Y_H] by its common p-power, the resulting projective point has affine root j modulo p.

These are zero-free root-pollution primes. Lucas congruences for A_s do not see them because every A_s, 0<=s<=H, is a p-unit.

# 7. Exact product decomposition

Define three disjoint candidate-prime sets:

```plain text
M_H={p: 2H<p<=n, p prime, #Z_p(H)>=2},

S_H={p: 2H<p<=n, p prime, Z_p(H)={n-p}},

R_H^0={p: 2H<p<=n, p prime, Z_p(H)=empty,
       v_p(Y_H-nX_H)>min(v_p(X_H),v_p(Y_H))}.
```

Then the radical in the question has the exact factorization

```plain text
W_H
=rad_(2H<p<=n) gcd(P_H^prim(n),B_H)
=product_(p in M_H) p
 * product_(p in S_H) p
 * product_(p in R_H^0) p.                         (7.1)
```

The direct target set is

```plain text
T_H
=S_H
 union
 {p in M_H:n-p in Z_p(H)}.                         (7.2)
```

Thus T_H is contained in the support of W_H, as required, but (7.1) also shows the two extra pollution classes:

```plain text
{p in M_H:n-p notin Z_p(H)}
```

and

```plain text
R_H^0.
```

Because all weights are nonnegative, the proposed statement implies separately

```plain text
sum_(p in M_H) log p=o(H),                          (7.3)

sum_(p in S_H) log p=o(H),                          (7.4)

sum_(p in R_H^0) log p=o(H).                        (7.5)
```

The multiplier condition (7.3) is a new horizontal double-zero theorem. It is not a consequence of the original moving-node theorem and is not supplied by Q850's lower bound on the total size of m_H.

# 8. Strongest honest weakening of the carrier

The exact classification gives a smaller sufficient carrier that removes automatic inclusion of good multiplier primes.

Define W_H^sharp by the candidate support condition

```plain text
p divides W_H^sharp
iff
p|z_H(n)

or

[p|A_(n-p) and there exists s!=n-p, 0<=s<=H,
 p|A_s].                                            (8.1)
```

Then

```plain text
T_H divides W_H^sharp,
W_H^sharp divides W_H.                              (8.2)
```

Indeed, a target prime with a unique prefix zero lies in the root factor by (6.1), while a target prime with at least two prefix zeros satisfies the second condition in (8.1).

Therefore the following single statement is sufficient for the direct q=1 theorem and is strictly less polluted than the original window radical:

```plain text
Sharp carrier lemma.

sum_(2H<p<=n, p prime,
     [p|z_H(n)] or
     [p|A_(n-p) and exists s!=n-p with p|A_s])
  log p
=o(H).                                              (8.3)
```

This is the strongest faithful weakening produced by the one-certificate local analysis. It separates the remaining work into:

```plain text
(a) candidate-window support of the primitive root factor z_H(n);

(b) target primes that have a second prefix Apéry zero.
```

Neither estimate is currently proved. If one removes the target condition from (b), one returns to the forced pollution term M_H and the original overstrong statement.

# 9. Why Lucas, Dwork, and root uniqueness do not close the estimate

## Root uniqueness works in the opposite direction

A tempting but false inference is:

```plain text
z_H has at most one root mod p,
therefore several Apéry zeros cannot contribute to m_H.
```

The exact implication is the reverse:

```plain text
several Apéry zeros force p|m_H,
```

because p-integrality would otherwise require z_H to vanish at all of them.

## Reflection leaves every prefix zero outside the prefix

For s<p, the Apéry reflection congruence gives

```plain text
A_(p-1-s)=A_s (mod p).
```

Since p>2H, a zero s<=H reflects to

```plain text
p-1-s>=p-1-H>=H,
```

and, except for the degenerate midpoint endpoint, the reflected zero is outside [0,H].

Distinct prefix zeros therefore correspond to distinct reflected zero orbits; reflection does not merge or exclude them.

For the moving node j=n-p,

```plain text
p-1-j=3H-2j,
```

which is outside [0,H] for j<H. Thus the special relation p=3H+1-j does not force a second prefix zero and does not identify other prefix zeros with the target.

## Dwork digit propagation does not count lower-half zero orbits

The Apéry Lucas/Dwork congruence

```plain text
A_(ap+b)=A_a A_b (mod p)
```

propagates a known digit zero to larger indices. Here all interpolation nodes satisfy 0<=s<=H<p, so the local question is precisely how many base digits s in the lower half are zeros. The digit congruence does not bound that count.

## The recurrence only forbids adjacent zeros

For 0<s<H<p, the Apéry recurrence shows that

```plain text
p|A_s and p|A_(s+1)
```

would propagate backward to p|A_0, impossible. Hence prefix zeros are nonconsecutive. This gives only a linear spacing bound and is far too weak for (7.3).

# 10. Exact obstruction and counterexample to the false intermediate claim

The current C++ scan counts candidate primes having at least two prefix zeros. At H=50000 it reports:

```plain text
#M_H=317,

sum_(p in M_H) log p / H = 0.07427438645.
```

Over 25000<=H<=50000, the maximum observed ratio is

```plain text
0.07430410809 at H=49980.
```

The exact moving target set at H=50000 is empty.

By theorem (4.1), the scan's former "unavoidable lower bound" is exactly the candidate-window multiplier radical. Therefore, at H=50000, every one of those 317 primes satisfies

```plain text
p|m_H,
p does not divide A_(3H+1-p).
```

This is an exact computational counterexample to

```plain text
p|m_H  ==>  p is a direct target.
```

It also shows why a lower bound on m_H is logically irrelevant: the issue is an upper bound on the logarithmic support of m_H in one moving prime window, and that support contains many non-target primes.

The computation is exact modular arithmetic, not floating-point evidence. It does not prove that the ratio stays positive asymptotically, so it does not formally refute log W_H=o(H). It does prove that the single-certificate route has acquired a separate double-zero problem whose finite behavior is adverse.

# 11. Final audit

The implications that are valid are:

```plain text
p target
=>
p|P_H^prim(n)
=>
p|W_H.
```

More locally:

```plain text
#Z_p(H)>=2
<=>
p|m_H;

Z_p(H)={r}
=>
p does not divide m_H and root(z_H mod p)=r;

Z_p(H)={r}
=>
p|P_H^prim(n) iff r=n-p;

Z_p(H)=empty
=>
p|P_H^prim(n) iff the primitive projective root is n-p.
```

The following implications are false:

```plain text
p|m_H  ==>  p is a target;

p|A_r at a unique higher-multiplicity node
         ==> p may remain in m_H;

z_H has at most one root
         ==> multiplier support is sparse.
```

The first is contradicted by the exact H=50000 scan. The second is disproved by Section 5. The third reverses the correct logic: multiple zeros force the multiplier prime.

Accordingly:

```plain text
The exact local classification is closed.

The proposed W_H=o(H) statement is not proved and should be regarded as
an overstrong, likely false route rather than a simplification of q=1.

Its multiplier part is exactly the weighted candidate-window double-zero
problem sum_(#Z_p(H)>=2) log p=o(H).

The strongest faithful one-certificate weakening is the sharp carrier
lemma (8.3).

A genuinely effective route needs either a second independent certificate
that removes good multiplier pollution, or new horizontal estimates for
both the primitive root factor and target-conditioned double zeros.
```
