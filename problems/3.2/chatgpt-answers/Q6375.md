# R4. Monodromy, Mellin, and self-twists for the Apéry–Franel pullback identity

## 0. Sheaf packaging
b_r = M(χ^{-r}; G) − M(χ^{-r}; G⊗L_q), where G = t_!(F⊗F), F = "Franel sheaf" (claimed rank-3 hypergeometric 3F2 with parameters (1/3,2/3,1;1,1), pure weight 0, G_geom = SL_3), t(x) = x(1−8x)/(1+x), q(t) = t²−34t+1, L_q = quadratic-twist sheaf χ₂(q(t)).

## 1. Monodromy claims
- F⊗F = Sym²(rank 6) ⊕ ∧²(rank 3), total 9; no accidental reducibility.
- t(x) is degree-2; branch locus disc = (t−1)²−32t = t²−34t+1, roots t± = (1±√2)^4 — EXACTLY the Apéry ODE singular points. [MACHINE-VERIFIED on our side: sympy discriminant + roots + identity of the two quadratic forms.]
- G = t_!(F⊗F): generic rank 18 = 2·9; exactly 4 singular points {0, ∞, t±} matching Apéry ODE; local monodromy at t± = reflection involution (Jordan blocks size 2 after pushforward); G_geom(G) ≅ ⟨SL₃, σ⟩ ⊂ GL₁₈ (deck involution semidirect); large, non-abelian, almost simple.
- Twist companion G⊗L_q: same rank, same G_geom up to central ±1, local monodromy differs exactly at t±.

## 2. FFK application
- FFK (Forey–Fresán–Kowalski arXiv:2109.11961): Mellin transforms of a FIXED bounded-conductor sheaf equidistribute; degenerate characters lie in finitely many cosets of a finite subgroup.
- Applies to each of G, G⊗L_q separately (bounded conductor ✓ fixed ✓).
- FFK does NOT control correlations/cancellation between the two Mellin transforms — the difference M₁−M₂ is outside the theory.
- Answer's claim: "provable: #{χ : M(χ)=0} = O(1)" per sheaf, hence #{r : M₁(χ^r)=0} = O(1). [⚠️ CRON AUDIT: REJECTED as stated — conflates exact ℓ-adic vanishing with mod-𝔭 vanishing; see ledger appendix P.4.]

## 3. Self-twists
- Inversion symmetry (from b_{p−1−r} = b_r): G ≅ G^∨, Mellin symmetry χ ↦ χ^{-1}.
- Quadratic-twist symmetry G ↔ G⊗L_q.
- Expected full self-twist group ≤ {1, inversion} × {1, quad twist}, size ≤ 4; "no unexpected self-twists" is a conjectural theorem needing a Katz-style rigidity argument not yet in the literature for this sheaf.

## 4. Verdict
- Missing core theorem ("bad diagonal inverse theorem" in canonical sheaf form): if two bounded-conductor trace functions f, g satisfy Σf(t)χ(t) = Σg(t)χ(t) for many χ, then f, g come from the same sheaf up to finite self-twists. Multiplicative analogue of additive inverse theorems; currently OPEN.
- With independence of the two Mellin transforms assumed: H(n) ≤ n^{1−δ} pointwise would follow. Unconditionally: only second-moment/density-type bounds.
