# Horizontal trace functions for the moving Apéry character: what the fixed K3 sheaf changes, and what it does not

## Verdict

The new sheaf-theoretic input is genuinely valuable, but it does not currently yield the pointwise power-saving

[

K(n;X):=#{pin(X,2X]:b_{nbmod p}equiv0pmod p}ll X^{1-delta}

]

through any existing Katz, Fouvry–Kowalski–Michel, Fouvry–Michel, Polymath8, or Duke–Friedlander–Iwaniec theorem.

The correct verdict is:

[

boxed{

begin{array}{c}

text{The fixed sheaf reopens the geometric and averaged problems,}\

text{but the pointwise horizontal prime-count problem remains behind the same wall.}

end{array}}

]

The exact obstruction is a combination of four facts:

1. the finite field itself varies with the outer prime (p);

1. only one character is sampled in each field;

1. that character has typically unbounded order as (ptoinfty);

1. the event being counted is reduction modulo the same prime (p), a (p)-adic shrinking-target condition not controlled by complex Sato–Tate equidistribution.

The new input supplies a fixed geometric source for the entire family

[

chilongmapsto T_p(chi),

]

but it does not turn the diagonal sequence

[

plongmapsto T_p(chi_p),qquad chi_p=omega_p^{,nbmod p},

]

into the Frobenius trace of one fixed finite-dimensional Galois representation over (mathbf Q).

---

# 0. A necessary normalization of the counting problem

If (n) is literally fixed while (Xtoinfty), then for every prime (p>n),

[

nbmod p=n.

]

Hence the condition becomes

[

pmid b_n,

]

where (b_n) is one fixed integer. Therefore (K(n;X)=0) for all sufficiently large (X). In that literal interpretation, every power-saving is trivial.

The meaningful gcd problem is uniform in a growing (n), with (Xlesssim n). The object should therefore be written

[

K(n;X)

=

#left{pin(X,2X]:ple n, b_{nbmod p}equiv0pmod pright},

]

with (n) and (X) tending to infinity in a specified relation.

Everything below concerns this uniform interpretation.

# 1. Two different meanings of “a fixed sheaf”

This distinction is the heart of the matter.

## 1.1 What the new input gives

Assume there is a fixed arithmetic sheaf (mathcal K) over (mathbf Z[1/N]), whose reduction (mathcal K_p) over (mathbf F_p) has a Mellin transform

[

T_p(chi)

=

operatorname{Tr}!left(operatorname{Frob}_p

mid

H_c^1(mathbf G_{m,overline{mathbf F}_p},

mathcal K_potimesmathcal L_chi)

right),

]

and suppose the relevant primitive part has rank (2), weight (3), and geometric monodromy (mathrm{SL}_2).

This is a fixed family-producing object. It provides:

- uniform conductor bounds in each characteristic;

- Deligne bounds for (T_p(chi));

- vertical monodromy and vertical Sato–Tate as (chi) ranges through many characters of one finite field;

- correlation estimates among many character values in one field;

- a precise geometric explanation of the finite hypergeometric formula.

That is a major improvement over having only an isolated congruence.

## 1.2 What would be needed for an immediate horizontal theorem

A much stronger object would be a fixed compatible system

[

rho_ell:operatorname{Gal}(overline{mathbf Q}/mathbf Q)

longrightarrow operatorname{GL}2(Eell)

]

with a fixed coefficient field (E), such that

[

T_p(chi_p)=operatorname{Tr}rho_ell(operatorname{Frob}_p)

]

for all good primes (p).

The fixed Mellin sheaf does not automatically provide this after the specialization (chi=chi_p), because the Kummer twist (mathcal L_{chi_p}) changes with (p), usually with order comparable to (p). The specialized cohomology groups form a diagonal sequence through a family; they are not automatically the fibers of one fixed arithmetic representation.

Thus there are two notions of fixedness:

[

boxed{

begin{aligned}

&text{fixed input sheaf, varying Kummer twist;}\

&text{fixed global Galois representation.}

end{aligned}}

]

The new input establishes the first. The horizontal Chebotarev machinery would naturally require the second, or at least a finite-type arithmetic parameter space together with a fixed algebraic section selecting the points.

# 2. The character exponent is not actually linear in (p) on a quotient block

Let

[

q=leftlfloorfrac nprightrfloor,

qquad

z_p=nbmod p=n-qp.

]

The selected character is

[

chi_p=omega_p^{z_p}.

]

Character exponents are taken modulo (p-1). Since

[

(n-qp)-(n-q)=-q(p-1),

]

one has the exact identity

[

boxed{

chi_p=omega_p^{n-qp}=omega_p^{n-q}.

}

]

Therefore, on every interval on which (q=lfloor n/prfloor) is constant, the exponent is a fixed integer

[

a_q=n-q.

]

So the expression is not an arithmetic progression in the character group in the sense required by a vertical equidistribution theorem. There is only one character per field, and on a (q)-block it is

[

chi_p=omega_p^{a_q}.

]

The remaining obstruction is that its order is

[

boxed{

operatorname{ord}(omega_p^{a_q})

=

frac{p-1}{gcd(p-1,a_q)},

}

]

which is typically of size comparable with (p). Thus the Kummer twist has unbounded order, even though the exponent (a_q) is fixed on the block.

This is the opposite of the fixed-order situation. If instead one fixed an integer (m) and used characters of order (m), for example

[

omega_p^{a(p-1)/m},qquad pequiv1pmod m,

]

then one can often attach a fixed hypergeometric motive or compatible system. The moving Apéry character does not have this form.

# 3. What Katz’s Mellin equidistribution theorem actually gives

Katz’s Convolution and Equidistribution studies a fixed perverse sheaf over a fixed finite field and the Frobenius conjugacy classes obtained as the multiplicative character varies. Its main theorem gives equidistribution of

[

{theta_{E,chi}:chitext{ good}}

]

as one ranges over all good characters in larger finite extensions (E/k), with the limiting measure determined by the arithmetic and geometric monodromy groups.

For an (mathrm{SL}_2) Mellin transform, this produces the expected (mathrm{SU}(2)) Sato–Tate law for the normalized complex traces when the character is averaged over a large family.

This does not imply anything about an arbitrary diagonal choice

[

chi_pinwidehat{mathbf F_p^times}

]

with one chosen character for each prime (p). Equidistribution of an entire row of an array does not imply equidistribution of a selected diagonal entry.

Schematically, Katz controls

[

frac1{p-1}sum_{chi}

Phi!left(frac{T_p(chi)}{p^{3/2}}right),

]

or analogous extension-field averages. The pointwise gcd problem asks about

[

Phi_p!left(T_p(chi_p)right)

]

for one (chi_p) and a test function (Phi_p) which itself changes with (p) and detects divisibility by (p).

Katz explicitly separates the equicharacteristic results from the more delicate “situation over (mathbf Z)” in Chapters 28–29. Those chapters do not contain a theorem covering arbitrary unbounded-order diagonal character choices of the present kind.

Reference: Nicholas Katz, Convolution and Equidistribution: Sato–Tate Theorems for Finite-Field Mellin Transforms, especially the main theorem and Chapters 28–29.

# 4. Why Fouvry–Kowalski–Michel does not apply

The main theorem of Fouvry–Kowalski–Michel fixes a prime modulus, say (P), and a bounded-conductor trace function

[

K_P:mathbf F_Plongrightarrowmathbf C.

]

It then estimates sums in which ordinary primes (ell) are inserted as arguments of that one trace function:

[

sum_{ell mathrm{prime}}

K_P(ell)V(ell/Y).

]

The field (mathbf F_P), the sheaf, and the modulus (P) remain fixed throughout each sum. The theorem obtains power saving when the length (Y) is sufficiently large relative to (P), using Type I/II decompositions and complete correlation estimates over (mathbf F_P).

Our sum has a completely different shape:

[

sum_{pin(X,2X]}

mathbf1_{{T_p(chi_p)equiv0bmodmathfrak p_p}}.

]

Here the outer prime (p):

- is the summation variable;

- is also the characteristic of the finite field;

- is also the modulus of the reduction condition;

- changes the character group and the selected character.

There is no long list of prime arguments inside one fixed (mathbf F_P). There is one value from each of many different finite fields.

Therefore the fixed-sheaf input does not bring the problem inside the hypotheses of FKM Theorem 1.5.

The earlier Fouvry–Michel theorem has the same fixed-modulus architecture: it estimates exponential sums over primes inside one fixed residue field. It likewise does not treat a diagonal family whose modulus is the prime being summed.

References:

- Étienne Fouvry, Emmanuel Kowalski, Philippe Michel, Algebraic trace functions over the primes, Duke Math. J. 163 (2014), especially Theorem 1.5.

- Étienne Fouvry, Philippe Michel, Sur certaines sommes d’exponentielles sur les nombres premiers, Ann. Sci. ENS 31 (1998), 93–130.

# 5. Why Polymath8 and cohomological-transform technology do not close the gap

The Polymath8 distribution estimates and the related cohomological-transform machinery exploit averaging in arithmetic progressions and complete finite-field correlation sums. The geometric input controls conductors after Fourier transforms and other cohomological operations.

This technology is powerful when, for each fixed modulus, one has sums over many internal variables such as

[

sum_msum_nalpha_mbeta_n K_P(mn),

]

or complete correlations of several translates of one trace function over (mathbf F_P).

The pointwise Apéry condition supplies no such internal averaging. For each (p), it supplies one selected character and one yes/no event.

The cohomological-transform results ensure that if one performs an algebraic transform of a bounded-conductor sheaf inside a fixed finite field, the resulting conductor remains controlled. They do not provide cancellation over the characteristics (p) themselves.

References:

- Étienne Fouvry, Emmanuel Kowalski, Philippe Michel, On the conductor of cohomological transforms, including the applications motivated by Polymath8.

- D. H. J. Polymath, New equidistribution estimates of Zhang type.

# 6. Why DFI-style varying-modulus estimates are not automatic

Duke–Friedlander–Iwaniec do allow the modulus to vary, but they exploit a very special explicit phase: Kloosterman fractions such as

[

e!left(frac{aoverline m}{n}right),

]

combined with bilinear averaging in (m) and (n), reciprocity, completion, and spectral or exponential-sum estimates.

A generic Frobenius trace

[

T_p(omega_p^{a_q})

]

is not presented in this form. The fact that it comes from a fixed sheaf does not automatically give:

- a reciprocity law exchanging the modulus with another summation variable;

- two long bilinear variables;

- a Voronoi/Kuznetsov transform;

- or a complete-sum formula to which the DFI dispersion mechanism applies.

To use a DFI-type method, one would need an additional explicit identity converting the selected Mellin trace into a bilinear or multilinear sum with enough independent averaging variables. This would be a new theorem specific to the Apéry/K3 sheaf, not a formal consequence of monodromy (mathrm{SL}_2).

Reference: W. Duke, J. Friedlander, H. Iwaniec, Bilinear forms with Kloosterman fractions, Invent. Math. 128 (1997), 23–43.

# 7. The zero condition is (p)-adic, not Sato–Tate

This is a second independent wall.

Let (T_p(chi_p)) be the complex/cyclotomic Frobenius trace, and let (mathfrak p_p) be the Teichmüller prime above (p) through which the finite hypergeometric congruence is reduced. The condition is

[

boxed{

T_p(chi_p)equiv0pmod{mathfrak p_p}.

}

]

Sato–Tate describes the distribution of complex conjugacy classes, or equivalently normalized archimedean traces. It does not control reduction at the residue characteristic.

Even in the simpler hypothetical case that (T_p(chi_p)) were an ordinary integer (t_p) with

[

]

the condition (pmid t_p) would say

[

frac{t_p}{p^{3/2}}

in

p^{-1/2}mathbf Z.

]

That is a shrinking lattice whose mesh tends to zero. Ordinary effective Sato–Tate controls fixed intervals or sufficiently smooth fixed test functions. It does not resolve exact membership in a (p)-dependent lattice at spacing (p^{-1/2}).

For the actual cyclotomic trace, the coefficient field and the chosen prime above (p) also vary, making the condition still further from an archimedean Sato–Tate statement.

A random-residue heuristic would assign probability about (1/p) to the congruence. Since there are about (X/log X) primes in ((X,2X]), this predicts roughly

[

sum_{psim X}frac1pasympfrac1{log X}

]

solutions. That heuristic is far stronger than the requested power saving, but no cited Sato–Tate theorem proves the needed mod-(p) randomness.

# 8. Why cancellation of traces would not bound the zero count

Suppose, optimistically, one proved

[

sum_{psim X}frac{T_p(chi_p)}{p^{3/2}}

ll X^{1-eta}.

]

This still would not imply a bound for the number of zeros. A signed first moment can be small while many terms vanish.

The exact additive detector is

[

mathbf1_{{x=0text{ in }mathbf F_p}}

=

frac1psum_{hinmathbf F_p}e_p(hx).

]

Applying it would require estimates for

[

sum_{psim X}

frac1p

sum_{hbmod p}^{*}

]

Now both the modulus and the range of (h) vary with (p), and the phase is the additive character of a Frobenius trace value, not a standard bounded-conductor trace function in a fixed finite field.

The alternative identity

[

mathbf1_{{x=0}}=1-x^{p-1}

quad(xinmathbf F_p)

]

introduces a power (p-1), so the algebraic complexity grows with (p). Neither detector enters the bounded-conductor framework of FKM.

Thus even a hypothetical horizontal first-moment theorem for (T_p(chi_p)) would not settle the zero-density problem.

# 9. Why standard Chebotarev and the large sieve for Frobenius still miss the event

Suppose one had a truly fixed compatible system with integer traces (t_p). Standard Chebotarev or a large sieve for Frobenius can study congruences

[

t_pequiv0pmodell

]

for a fixed auxiliary prime (ell), or for many auxiliary primes (ell) chosen independently of (p).

The desired condition is diagonal:

[

t_pequiv0pmod p.

]

The reduction modulus is the same prime whose Frobenius is being sampled. This is not a conjugacy condition in any fixed finite quotient of a global Galois representation.

Hence even upgrading the Mellin specialization to a genuine compatible system would not by itself prove the desired estimate. It would solve the “moving representation” problem, but the “moving residue characteristic” problem would remain.

References:

- Emmanuel Kowalski, The large sieve, monodromy and zeta functions of curves.

- Emmanuel Kowalski, The principle of the large sieve.

# 10. What the fixed K3/Mellin sheaf genuinely reopens

Although it does not solve the pointwise problem, the new input creates several serious avenues that were unavailable before.

## 10.1 Averaging over (n)

If (n) ranges over a long interval, then for each fixed (p), the residues (nbmod p) sample many character indices. One can reverse the order of summation:

[

sum_{nin I}K(n;X)

=

sum_{psim X}

#{nin I:b_{nbmod p}equiv0pmod p}.

]

When (|I|) is large compared with (p), the inner set samples the full Mellin family. Vertical geometric information can then become useful. This may yield average-in-(n) results even though the pointwise problem remains open.

## 10.2 Averaging over characters

One can attack quantities such as

[

sum_{psim X}

frac1{p-1}sum_{chi}

Phi!left(T_p(chi)/p^{3/2}right).

]

This is aligned with Katz’s framework. The fixed sheaf and (mathrm{SL}_2) monodromy are exactly the right input.

## 10.3 Restricting to fixed-order characters

If the moving character is replaced by a character of one fixed order (m), then the corresponding hypergeometric datum is often a fixed motive over a cyclotomic field. Horizontal Chebotarev and Sato–Tate questions become standard compatible-system questions.

This is a useful model problem, but it is not the Apéry selector (z=nbmod p).

## 10.4 Searching for a reciprocity or bilinear formula

The explicit K3/hypergeometric realization may permit a transformation of

[

T_p(omega_p^{a_q})

]

into a bilinear sum involving variables independent of (p). If such a formula exposes Kloosterman fractions, complete character sums, or an automorphic transform, then DFI/Polymath-style technology could become relevant.

This would be a genuinely new arithmetic identity, not a generic consequence of sheaf existence.

## 10.5 A (p)-adic or Hasse-invariant interpretation

The residue (b_zbmod p) may be a Hasse invariant, unit-root obstruction, or ordinarity invariant of a geometric family. If one can identify

[

b_{nbmod p}equiv0pmod p

]

with supersingularity or non-ordinarity at an algebraically defined point, the problem may be attacked by (p)-adic geometry rather than complex trace equidistribution.

This is probably more closely matched to the congruence than archimedean (mathrm{SU}(2)) monodromy.

# 11. The exact new theorem that would be needed

A direct pointwise solution would require a theorem resembling the following.

Let (mathcal K/mathbf Z[1/N]) be a fixed arithmetic Mellin sheaf. For a fixed integer (a), let (chi_{p,a}=omega_p^a). Prove, uniformly in the relevant (a), that

[

#{pin(X,2X]:T_p(chi_{p,a})equiv0pmod{mathfrak p_p}}

ll X^{1-delta}.

]

This is a horizontal large-sieve theorem on an unbounded-order character tower with a residue-characteristic target.

None of the cited results has this form.

A weaker but still new theorem would be cancellation for the additive detectors

[

sum_{psim X}

]

uniformly for suitable nonzero (h_pbmod p). Again, the modulus, the character, and the additive phase all change with (p).

# 12. Direct answers to the three questions

## (i) Does an existing theorem now give a power saving for the zero count?

[

boxed{text{No.}}

]

Katz gives vertical character equidistribution. FKM and Fouvry–Michel fix one finite field and sum prime arguments inside it. Polymath8 controls averaged progression or bilinear problems with internal finite-field variables. DFI handles explicit Kloosterman-fraction phases with bilinear structure. None controls one unbounded-order Mellin character in each varying field, followed by reduction modulo the same outer prime.

## (ii) Does the “linear in (p)” exponent match a known theorem?

No. On a block where (q=lfloor n/prfloor) is fixed,

[

omega_p^{n-qp}=omega_p^{n-q}.

]

Thus there is no long arithmetic progression of characters within one field. There is one character per field, with fixed exponent but typically unbounded order. Known character-aspect equidistribution requires averaging over many characters; known horizontal compatible-system results require fixed-order or algebraically parameterized twists.

## (iii) Does the moving-character/moving-modulus coupling still block the pointwise estimate?

[

boxed{text{Yes.}}

]

The exact mechanism is:

[

boxed{

begin{array}{l}

text{fixed input sheaf};notRightarrow;text{fixed specialized compatible system};\

text{vertical }mathrm{SL}_2text{ monodromy};notRightarrow;text{diagonal horizontal equidistribution};\

text{complex Sato–Tate};notRightarrow;text{reduction modulo the residue characteristic};\

text{first-moment cancellation};notRightarrow;text{a zero-count bound}.

end{array}}

]

So the new K3 sheaf is a genuine reopening of the averaged and structural problem, but not yet of the pointwise prime-counting problem in the form needed for the Apéry gcd conjecture.

# 13. Practical research recommendation

The most promising next steps are, in order:

1. Prove an average-in-(n) theorem by exploiting the full character family for each (p).

1. Determine whether (b_zbmod p=0) has a geometric ordinarity/supersingularity interpretation.

1. Search for an explicit reciprocity formula for (T_p(omega_p^a)) with (a) fixed on a (q)-block.

1. Study the fixed-order-character analogue as a model horizontal compatible system.

1. Formulate a horizontal large sieve on the universal Kummer tower; this is the genuinely new analytic theorem the pointwise problem appears to demand.
