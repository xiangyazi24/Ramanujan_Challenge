```python
# sage: sage apery_pcurvature.sage

def is_zero_matrix(M):
    return all(z == 0 for z in M.list())

def apery_pcurvature(p):
    k = GF(p)
    R.<t> = PolynomialRing(k)
    K = R.fraction_field()

    a3 = K(1 - 34*t + t^2)
    a2 = K(-51*t + 3*t^2)
    a1 = K(-27*t + 3*t^2)
    a0 = K(-5*t + t^2)

    # theta-vector v=(y,theta*y,theta^2*y), theta*v=B*v.
    B = matrix(K, [
        [0, 1, 0],
        [0, 0, 1],
        [-a0/a3, -a1/a3, -a2/a3],
    ])
    A = B / t                    # d/dt connection matrix

    def dmat(M):
        return matrix(K, M.nrows(), M.ncols(),
                      [z.derivative() for z in M.list()])

    # Column convention: nabla(f)=d(f)/dt + A*f.
    # M_n is the matrix of nabla^n on the constant basis.
    M = identity_matrix(K, 3)
    for _ in range(p):
        M = dmat(M) + A*M

    Psi = M                     # (d/dt)^p=0 on F_p(t)
    ranks = []
    Q = identity_matrix(K, 3)
    for j in range(1, 4):
        Q = Psi*Q
        ranks.append(Q.rank())

    print("p =", p)
    print("charpoly =", Psi.charpoly('Z'))
    print("ranks(Psi,Psi^2,Psi^3) =", ranks)
    print("Psi^3 zero?", is_zero_matrix(Psi^3))
    return Psi

for p in [5,7,11,13,17,19,23,29,31]:
    apery_pcurvature(p)
```

def polynomial_part(e, R):
    num = e.numerator()
    den = e.denominator()
    q, rem = num.quo_rem(den)
    assert rem == 0
    return R(q)

def shift_curvature(p):
    k = GF(p)
    R.<x> = PolynomialRing(k)
    K = R.fraction_field()

    P = 34*x^3 + 51*x^2 + 27*x + 5
    G = matrix(K, [
        [P/(x+1)^3, -1/(x+1)^3],
        [(x+1)^3, 0],
    ])
    assert G.det() == 1

    def shift_matrix(M, j):
        return matrix(K, M.nrows(), M.ncols(),
                      [z.subs({x: x+j}) for z in M.list()])

    Psi = identity_matrix(K, 2)
    for j in range(p):
        Psi = shift_matrix(G, j) * Psi

    u = x^p - x
    raw = (u^3)*Psi
    C = matrix(R, 2, 2, [polynomial_part(e, R)
                          for e in raw.list()])

    assert C.det() == u^6
    print("p =", p,
          "deg entries =", [f.degree() for f in C.list()])
    print("trace mod (x^p-x) =", C.trace().mod(u))

    bad = []
    for a in k:
        Ca = matrix(k, 2, 2, [f(a) for f in C.list()])
        if Ca*Ca != 0:
            bad.append(a)
    print("non-nilpotent rational fibres =", bad)
    return C

解释：若 D_p(r,s) 真来自一族导子绝对有界、无退化 Artin–Schreier 子商的二维迹层，则二维平方根尺度正是 O(p)，所以最后两个归一化最大值应保持有界。若它们明显按 p^eta 增长，则不能再用“可能存在有界导子层”作抽象希望，必须寻找别的压缩或接受导子墙。

1. 先从和中删去 s=r 与 s=-1-r；

1. 在反射商 lambda=r(r+1) 上合并两个代表后重算。

第二种才是测试 primitive/new 单值群的正确版本。

# 9. 一条实际可执行的研究路线

## Gate 1：先商掉确定性对称

在函数环

# 10. 两个必答审计

## (a) 本轮最没把握的一步

最没把握的是：碰撞系数函数 (r,s) -> D_p(r,s) 是否存在一个自然、与插值无关、导子次多项式甚至有界的 l-adic 实现。

形式上总能用次数 <p 插值造一个 Artin–Schreier 层，但那只是把任意函数几何化，导子约为 p，没有内容。真正需要的“Cartier/K3 来源的低复杂度实现”目前只是研究目标，不是已知事实。

因此我不把 Rq_!IC(C_p) 的有界导子当结论；它是最精确的待证接口。

## (b) 双方共同盲点可能在哪

我认为有三个相互嵌套的盲点。

1. 把生成变量几何误当成系数指标几何。 B(t) 的 K3 单值群、holonomic characteristic variety 和 p-curvature 都在 t-方向；目标是模 p Taylor 系数在 (r,h) 指标平面的零集。中间缺的是 arithmetic Fourier/Cartier 变换。

1. 只看 full-cycle 或只看单个 gap。 full-cycle 忘掉 prefix；单个 M_h 忘掉跨 h 组织。真正对象是“初值敏感的 prefix determinant section”的 Radon 推前。

1. 没有先商掉反射。 原轨道天然有二元 imprimitivity。若直接追求 S_d，会把确定性镜像误判为小单值群；若直接算能量，又会让已知镜像主项污染新部分。

最可能的真盲点是：反射商后，ordered prefix cocycle 的某个 Cartier/Fourier 商也许具有固定秩，而这个商既不出现在 N_h 的次数/判别式中，也不出现在完整周期迹中。若它存在，二变量 holonomic 结构才会真正超越 Q6525 的 degree/resultant 框架。

# 最后一行结论

“二变量单值性”不是一句空泛口号；其精确形式是：反射商后的 pair/triple collision fiber products 与差映射推前具有大几何单值群，同时其 Betti/导子足够小。 大群给 Poisson 主项，小导子给 quenched 误差。当前已见前者的固定-gap 影子，完全没有后者；p-curvature 幂零可以验证几何来源，却不能替代小导子或 prefix 反集中。
