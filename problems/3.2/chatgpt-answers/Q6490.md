## 3.4 No Galois deformation in h

The data S_{m_h} for h\leq11 strongly support maximality, but there is no known deformation carrying it from h to h+1:

- the recurrence is additive in N_h,N_{h-1}, not a composition law on roots;

The natural exact conjecture is therefore:

Conjecture K. There is an absolute C such that \kappa(M_h)\leq C for every h\geq2.

No current rigidity theorem for deterministic tridiagonal matrices implies either conjecture. ## 3.5 Machine-verifiable Dedekind certificates

For a fixed primitive f=M_h of degree m, a certificate can contain only factor-degree lists at good primes.

1. A prime p_0 for which f\bmod p_0 is irreducible proves irreducibility over \mathbf Q and gives an m-cycle.

1. A good prime whose factor degrees contain a prime q-cycle with m/2<q\leq m-3, together with an explicit block-size elimination, proves primitivity; Jordan’s theorem then gives A_m.

1. A good prime with exactly one even cycle of length 2 and all other cycle lengths odd yields a transposition after taking an odd power.

1. A_m plus a transposition gives S_m.

For small m, an exact group computation is cheaper. The certificate must store the exact polynomial hash, the primes, the squarefreeness check, and the factor-degree lists; no floating-point root computation is needed.

## 4.2 Why Hilbert irreducibility does not hit the target

For fixed h, Hilbert irreducibility says that most integer specializations t=t_0 preserve irreducibility and often the generic Galois group, with effective versions such as Paredes–Sasyk, arXiv:2202.10420. But the target is the single distinguished specialization t_0=0. Hilbert irreducibility gives no mechanism to certify that this one point avoids the exceptional set.

Moreover, there is no single bounded-degree variety whose fibers over an h-line are all the M_h:

- the degree and matrix dimension grow with h;

- the number of coefficient parameters grows with h;

- the coefficient height and discriminant grow rapidly.

Consequently Bertini or effective Hilbert irreducibility can at best show that many auxiliary deformations of each fixed h are irreducible. It does not show that every original fiber is irreducible, or that all but finitely many values of the discrete size parameter h work.

The phrase “geometric irreducibility of the univariate polynomial over an algebraic closure” should also be avoided: a degree->1 univariate polynomial splits over an algebraic closure. The meaningful geometric statement is irreducibility of a total space such as (4.1), or arithmetic irreducibility over a function field.

# 7. Machine-checkable certificates for the proved identities

The following Sage script is a finite auditor for the all-h identities proved above. The mathematical proofs are the inductions in Sections 1 and 3; the script provides regression certificates for any requested range.

```python
# SageMath
R.<X> = PolynomialRing(ZZ)
P = lambda u: 34*u^3 + 51*u^2 + 27*u + 5

def continuants(H):
    N = [R(0), R(1)]
    for d in range(1, H):
        N.append(P(X+d)*N[d] - (X+d)^6*N[d-1])
    return N

def apery(H):
    b = [ZZ(1), ZZ(5)]
    for n in range(1, H):
        num = P(ZZ(n))*b[n] - n^3*b[n-1]
        b.append(num // (n+1)^3)
    return b

def audit(H=30):
    N = continuants(H)
    b = apery(H)

    # Reflection and endpoint.
    for h in range(1, H+1):
        assert N[h](-h-1-X) == (-1)^(h-1)*N[h]
        assert N[h](-h) == (-1)^(h-1)*factorial(h-1)^3*b[h-1]

    # Exact adjacent resultant.
    for h in range(2, H+1):
        rhs = (-1)^((h-2)*(h-1)//2)
        for j in range(1, h-1):
            rhs *= (factorial(j)^3*b[j])^6
        assert N[h].resultant(N[h-1]) == rhs

    # Mod 3 Frobenius cube.
    F3.<x> = PolynomialRing(GF(3))
    RR = [F3(0), F3(1), x]
    for d in range(2, H):
        RR.append((x+d-1)*RR[d] - (x+d)^2*RR[d-1])
    for h in range(1, H+1):
        assert F3(N[h]) == RR[h]^3

    # Mod 2 four-cycle.
    F2.<x> = PolynomialRing(GF(2))
    q = x^2+x+1
    a = x^6
    c = (x+1)^6
    D = a*c
    assert q^2 == a+c
    for h in range(1, H+1):
        k, r = divmod(h-1, 4)
        expected = [D^k, q*D^k, c*D^k, F2(0)][r]
        assert F2(N[h]) == expected

    return True
```

# 9. Final verdict and recommended target

The evidence \operatorname{Gal}(M_h)=S_{m_h} is exceptionally strong, but full irreducibility for every h remains open. The proposed routes do not currently yield even \kappa(M_h)=O(1) unconditionally. The exact resultant and generic irreducibility are useful structural facts, not an induction.

The most promising next target is the following sharply formulated local theorem.

Uniform higher-order 3-adic target. After primitive normalization, the complete 3-adic type tree associated with the Frobenius-cube reduction (1.9) has O(1) leaves uniformly in h; ideally it has one leaf. Any exceptional factor degrees are excluded by the complete 2-adic and 17-adic type data.

This target is both machine-decidable for each h and mathematically capable of proving the desired global statement. It uses the genuine congruence structure discovered above rather than repeating the already-failed one-edge Newton-polygon test.

If this target fails computationally—if the number of local leaves grows with h—then the next realistic theorem is Conjecture S via deterministic Galois expansion, not prime values. The prime-value route asks for a theorem at least as hard as the irreducibility statement and therefore is best treated as a certificate generator, not as the primary proof mechanism.
