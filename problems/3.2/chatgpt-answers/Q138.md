# Round 6 verdict: large Apéry prime factors

Let

```plain text
B_n = sum_{j=0}^n binom(n,j)^2 binom(n+j,j)^2
```

be the Apéry numbers for zeta(3), and for a prime p put

```plain text
Z_p := {0 <= r < p : B_r = 0 mod p},
z_p := |Z_p|.
```

The target is

```plain text
W(n) := sum_{sqrt(n) < p <= n} v_p(B_n) log p = o(n)
```

for every n.

## Executive assessment

Bottom line: none of the three mechanisms proves the pointwise target today. The cleanest sufficient missing theorem is not a better first moment, but a four-prime “small CRT representative” estimate for the zero sets. The cleanest arithmetic research direction is a multi-zero transfer-polynomial/resultant theory, not ordinary gcd estimates.

# 0. Zeroth audit: support versus valuation

All three proposed mechanisms count distinct bad primes. The target counts valuations. Write

```plain text
W_rad(n) := sum_{sqrt(n)<p<=n, p|B_n} log p,
W_mult(n) := sum_{sqrt(n)<p<=n} (v_p(B_n)-1)_+ log p.
```

Then W = W_rad + W_mult.

The inference

```plain text
W(n) >= epsilon n
  => at least c epsilon n/log n distinct bad primes
```

is valid only after proving W_mult(n)=o(n), or at least a uniform bound on the relevant valuations. From the weighted inequality alone it is false: one prime with valuation of order n/log n could carry linear weight.

The analysis below therefore concerns the squarefree main term. It applies to the full target if the stated O(n^(2/3)) correction theorem also controls the total weighted excess valuation, not merely the number of exceptional primes. If it only counts exceptional primes, a separate p^2-divisibility lemma is still required.

For the rest, I use the known reduction

```plain text
p | B_n,  p > sqrt n
  <=> n mod p belongs to Z_p
```

outside a total o(n) weighted correction.

The Lucas congruence behind this is classical:

```plain text
B_{qp+r} = B_q B_r mod p,    0 <= r < p.
```

Gessel proved the Lucas property; a convenient modern source is Malik–Straub, Divisibility properties of sporadic Apéry-like numbers, especially their introduction and Section 3.

# 1. What a pointwise counterexample would have to look like

There is a useful deterministic localization before any moment method.

Let

```plain text
theta(x) := sum_{p<=x} log p.
```

For large x, theta(x) <= 2x. Suppose the squarefree target fails at n:

```plain text
W_rad(n) >= epsilon n.
```

Take

```plain text
eta := epsilon/4.
```

Then

```plain text
sum_{p <= eta n} log p <= 2 eta n = epsilon n/2.
```

Hence primes p > eta n contribute at least epsilon n/2. Since each contributes at most log n, there are at least

```plain text
K_top(n) >= epsilon n/(2 log n)
```

distinct bad primes with p > eta n.

For each such prime,

```plain text
q := floor(n/p) < 1/eta = 4/epsilon,
r := n-qp,
0 <= r < p,
p | B_r.
```

There are at most Q := ceil(4/epsilon) possible quotients. Therefore one fixed quotient slice satisfies, for large n,

```plain text
#{p : n/(q+1) < p <= n/q,
      p | B_{n-qp}}
  >= epsilon^2 n/(10 log n)
```

for some 1 <= q <= Q.

This is the strongest clean pointwise reduction I see:

A failure of the target forces a bounded quotient q=O_epsilon(1) for which a positive proportion, on the prime scale, of the linear candidates p=(n-r)/q divide the corresponding Apéry term B_r.

Thus the hard range is not p near sqrt n. It is p comparable to n, with q bounded. Any future proof can discard p <= eta n at cost O(eta n) and focus on finitely many quotient slices.

The same count recovers the known density statement. For n in [N,2N], each pair (p,r) with r in Z_p and each bounded q creates at most one integer n=qp+r. Using z_p <= 3p^(2/3), the total number of such incidences is

```plain text
<<_epsilon sum_{eta N < p <= 2N} z_p
<<_epsilon N^(5/3)/log N.
```

Each counterexample requires >>_epsilon N/log N incidences, so the number of counterexamples in [N,2N] is

```plain text
O_epsilon(N^(2/3)).
```

This is a strong density-zero result but still allows an infinite exceptional sequence.

# 2. Mechanism (1): greedy/entropy and growing CRT moments

## 2.1 Exact falling-moment formula

Fix a dyadic prime block

```plain text
P_X := {p prime : X < p <= 2X}.
```

For 0 <= m < Y, define

```plain text
K_X(m) := #{p in P_X : m mod p in Z_p},
T_X := sum_{p in P_X} z_p,
A_X := sum_{p in P_X} z_p/p.
```

For an integer k >= 1, let

```plain text
(K)_k := K(K-1)...(K-k+1).
```

Then

```plain text
S_k(Y,X) := sum_{m<Y} (K_X(m))_k
```

has the exact expansion

```plain text
S_k(Y,X)
 = sum_{ordered distinct p_1,...,p_k in P_X}
     sum_{r_i in Z_{p_i}}
       #{m<Y : m = r_i mod p_i for every i}.
```

Put P=p_1...p_k. By CRT, each residue tuple determines one class modulo P, so

```plain text
#{m<Y : all congruences hold} <= 1 + Y/P.
```

Consequently

```plain text
S_k(Y,X)
 <= sum_{distinct p_i} product_i z_{p_i}
    + Y sum_{distinct p_i} product_i (z_{p_i}/p_i)
 <= T_X^k + Y A_X^k.                    (2.1)
```

In binomial-moment form,

```plain text
sum_{m<Y} binom(K_X(m),k)
 <= e_k((z_p)_p) + Y e_k((z_p/p)_p)
 <= (e T_X/k)^k + Y (e A_X/k)^k.        (2.2)
```

Thus

```plain text
#{m<Y : K_X(m) >= K}
 <= [e_k(z)+Y e_k(z/p)] / binom(K,k).   (2.3)
```

These are the strongest bounds available from CRT and the cardinalities alone.

## 2.2 Why k ~ log X does not help

Suppose Y=X^2 and k>=3. Then

```plain text
P = p_1...p_k > X^k >> X^2 = Y.
```

So every residue tuple has at most one representative below Y. This does not imply dispersion. It merely turns its contribution into the first term of (2.1):

```plain text
sum_{distinct p_i} product z_{p_i}.
```

A single integer m satisfying K prime conditions contributes

```plain text
(K)_k
```

different ordered prime subsets. CRT injectivity is only within a fixed prime tuple. It does not stop all those different tuples from having the same small representative m.

The exact adversarial model is decisive. Fix m_0<Y. For every prime p not dividing m_0, set

```plain text
Z_p^adv := {m_0 mod p, p-1-(m_0 mod p)}
```

with duplicates removed. Then:

```plain text
|Z_p^adv| <= 2,
Z_p^adv is invariant under r -> p-1-r,
its two distinct elements are never consecutive,
m_0 mod p belongs to Z_p^adv for every p.
```

Hence

```plain text
K_X(m_0) = #P_X ~ X/log X,
T_X ~ 2X/log X.
```

This model satisfies far more sparsity than 3p^(2/3), the palindrome symmetry, and the no-consecutive-zero condition, while concentrating every available prime at one integer.

Therefore:

No argument using only |Z_p|, no-consecutive zeros, reflection symmetry, CRT injectivity, and any number of moments can prove a pointwise bound.

The place where injectivity fails to imply dispersion is exactly the uncontrolled count of residue tuples whose least CRT representative is unusually small.

## 2.3 The minimal missing input

Define the four-prime small-CRT statistic

```plain text
C_4(Y,X)
 := sum_{ordered distinct p_1,...,p_4 in P_X}
      #{(r_1,...,r_4) in Z_{p_1} x ... x Z_{p_4} :
        CRT_{p_1...p_4}(r_1,...,r_4) < Y}.
```

This is exactly S_4(Y,X) when p_1...p_4>Y, as it is throughout the target range X>sqrt Y.

A sufficient arithmetic statement is

```plain text
C_4(Y,X) <= C Y A_X^4                 (D4)
```

uniformly for

```plain text
sqrt Y < X <= Y.
```

This says that four zero-residue conditions have the expected number of small simultaneous representatives, up to a constant.

### Why the fourth moment is enough

At any fixed n<Y,

```plain text
(K_X(n))_4 <= S_4(Y,X).
```

Under (D4),

```plain text
K_X(n) <= 3 + C^(1/4) Y^(1/4) A_X.   (2.4)
```

The proved zero-set bound gives

```plain text
A_X
 <= 3 sum_{X<p<=2X} p^(-1/3)
 << X^(2/3)/log X.                    (2.5)
```

Therefore the squarefree weighted contribution of this block is

```plain text
sum_{X<p<=2X, p bad for n} log p
 <= K_X(n) log(2X)
 << Y^(1/4) X^(2/3) + log Y.          (2.6)
```

Summing over dyadic X from sqrt Y to Y, the geometric sum is dominated by X~Y:

```plain text
sum_X Y^(1/4) X^(2/3)
 << Y^(1/4+2/3)
 = Y^(11/12).
```

Thus (D4) would give

```plain text
W_rad(n) << n^(11/12) + log^2 n = o(n),
```

and hence the full target after the valuation correction.

More generally, a dispersed kth factorial moment gives exponent

```plain text
2/3 + 1/k.
```

The least integer with 2/3+1/k<1 is k=4. So the answer to the proposed “let k grow like log X” experiment is:

- growing k is useless under the trivial CRT estimate because T_X^k remains;

- once the small-CRT term is genuinely dispersed, k=4 already suffices.

## 2.4 What type of theorem could imply (D4)?

It must use arithmetic across different primes. Examples of sufficient inputs are:

1. a four-modulus large-sieve/discrepancy theorem for the coefficient-zero sets Z_p;

1. Fourier bounds for 1_{Z_p} strong enough after expanding the CRT indicator;

1. a direct bound on four-prime alignments

1. a multi-prime geometric/Galois relation that forbids the adversarial alignment above.

A standard large sieve for arbitrary sparse residue sets cannot do this: the adversarial family is an explicit obstruction.

Assessment for (1):

- exact moment algebra: proved-reachable;

- deriving a pointwise bound from current inputs: hopeless;

- proving the four-prime dispersion (D4): plausible-hard and sufficient.

# 3. Mechanism (2): divisor structure and pair gcds

## 3.1 Apéry numbers are not a divisibility sequence

The first terms are

```plain text
B_0=1, B_1=5, B_2=73, B_3=1445.
```

Already

```plain text
1 divides 2, but B_1 does not divide B_2,
gcd(B_1,B_2)=1 != B_1.
```

So neither ordinary nor strong divisibility is present.

A targeted search found no published law comparable to

```plain text
gcd(B_m,B_n)=B_gcd(m,n)
```

or a useful general upper bound for gcd(B_m,B_n). Luca–Shparlinski, Arithmetic properties of Apéry numbers, prove lower bounds for the number and size of prime factors of individual terms on a density-one set; they do not provide pair-gcd control.

## 3.2 For the target pair, the common factor is automatic

Let

```plain text
n=qp+r, 0<=r<p.
```

Lucas gives

```plain text
B_n = B_q B_r mod p.
```

Outside the known correction p|B_q, the condition p|B_r immediately gives

```plain text
p | B_n and p | B_r,
```

hence

```plain text
p | gcd(B_n,B_r).
```

Thus p | gcd(B_n,B_{n mod p}) is not an extra arithmetic coincidence. It is merely a restatement of the Lucas propagation that created the bad prime.

Any theorem that bounds these particular gcds strongly enough to prove the target would therefore have to encode essentially the same missing cross-prime information as the target itself.

## 3.3 One fixed remainder already serves at most one large prime

For a fixed n, the map

```plain text
p -> r_p := n mod p
```

is injective on primes p>sqrt n.

Indeed, if two distinct such primes have the same remainder r, then

```plain text
p_1 p_2 | n-r.
```

But

```plain text
0 < n-r < n < p_1 p_2,
```

which is impossible.

Therefore a theorem saying “a fixed B_r has few prime divisors in the relevant interval” does not solve the pointwise problem: for a fixed n, each remainder already has only one candidate prime.

The problem is that there may be many different remainders, each serving one different prime.

## 3.4 Even gcd(B_n,B_m) <= exp(o(m)) would not be enough

For the difficult primes p~n, the remainder m=n mod p can be a positive fraction of n. A bound

```plain text
gcd(B_n,B_m) <= exp(o(m))
```

still permits a factor p~n, because every polynomial-sized number is much smaller than, for example, exp(sqrt m).

To rule out one prime of size n for each of >>n/log n different remainders, one needs an aggregate large-prime gcd-product bound, not an individual subexponential bound.

But the natural aggregate statement

```plain text
sum_{sqrt n<p<=n} 1_{p|gcd(B_n,B_{n mod p})} log p = o(n)
```

is exactly the squarefree target again.

## 3.5 Large primes can divide several first-block terms

The claim “p>r, so p is new at index r” is false if r is not the first zero. For example,

```plain text
5 | B_1,
5 | B_3.
```

More systematically, the first Apéry block has the reflection congruence

```plain text
B_r = B_{p-1-r} mod p.
```

This is discussed in Malik–Straub’s divisibility paper. Hence every noncentral zero is automatically paired with another zero in the same first block. Pair-gcd largeness is not accidental folklore; it is built into the modulo-p structure.

## 3.6 The real recurrence-based gcd information: fixed gaps

The Apéry recurrence is

```plain text
(k+1)^3 B_{k+1}
 = P(k) B_k - k^3 B_{k-1},
P(k)=34k^3+51k^2+27k+5.
```

For p>=5, two consecutive zeros in the first block are impossible. If

```plain text
B_r=B_{r+1}=0 mod p,
0<=r<r+1<p,
```

then the recurrence propagates the zero backward to B_0=0, contradicting B_0=1.

More generally, start with a zero at r and normalize B_{r+1} to 1. Define transfer polynomials

```plain text
F_1(x)=1,
F_2(x)=P(x+1),
F_{h+1}(x)=P(x+h)F_h(x)-(x+h)^6 F_{h-1}(x).
```

After clearing the invertible denominators, if

```plain text
r, r+h belong to Z_p,
r+h<p,
```

then

```plain text
F_h(r)=0 mod p.
```

Moreover

```plain text
deg F_h = 3(h-1),
```

with leading coefficients satisfying

```plain text
c_1=1, c_2=34, c_{h+1}=34c_h-c_{h-1}.
```

Thus, after the nonzero/content clause already required in the proof of z_p<=3p^(2/3), a fixed gap h has at most 3(h-1) starting positions.

This is valuable, but it controls the spacing of zeros inside one modulus. It does not control the cross-prime alignment r_p=n mod p.

Assessment for (2):

- local recurrence/gap lemmas: proved-reachable;

- ordinary pair-gcd statistics as a route to the pointwise target: hopeless;

- a genuinely new aggregate shifted-gcd-product theorem: sufficient but essentially target-equivalent.

# 4. Mechanism (3): p-adic rigidity and the total pair count

Define

```plain text
T_X := sum_{X<p<=2X} z_p
     = #{(r,p): X<p<=2X, 0<=r<p, p|B_r}.
```

## 4.1 Correcting the “7X^2/log X versus mean 0.1” calculation

The standard Apéry asymptotic gives

```plain text
log B_r = kappa r + O(log r),
kappa = log(17+12 sqrt 2)
      = 4 log(1+sqrt 2)
      approximately 3.52549.
```

For fixed r, every counted prime is larger than X, so

```plain text
#{p in (max(X,r),2X] : p|B_r}
 <= log B_r/log X.
```

Summing gives the column-wise bound

```plain text
T_X
 <= (1/log X) sum_{r<2X} log B_r
 <= (2 kappa+o(1)) X^2/log X
 approximately 7.051 X^2/log X.        (4.1)
```

This is only an upper bound. It assumes, in the worst possible way, that almost all of the logarithmic mass of every B_r is packed into primes of size X. There is no contradiction with the empirical count.

Each pair (r,p) serves about Y/p integers n<Y. Therefore

```plain text
sum_{n<Y} K_X(n)
 = Y A_X + O(T_X),
A_X=sum z_p/p.                           (4.2)
```

For Y=X^2, if empirically

```plain text
T_X ~ c X/log X,
```

then

```plain text
A_X ~ c/log X,
```

so the average K_X(n) is of order 1/log X, which can easily look like 0.1 at computational scales.

## 4.2 The strongest unconditional first-moment bound from the proved zero theorem

Using

```plain text
z_p <= 3p^(2/3),
```

we obtain

```plain text
T_X
 <= 3 sum_{X<p<=2X} p^(2/3)
 << X^(5/3)/log X,                       (4.3)
```

and

```plain text
A_X
 <= 3 sum_{X<p<=2X} p^(-1/3)
 << X^(2/3)/log X.                       (4.4)
```

With the prime number theorem, the leading comparison constants are

```plain text
T_X
 <= [(9/5)(2^(5/3)-1)+o(1)] X^(5/3)/log X,

A_X
 <= [(9/2)(2^(2/3)-1)+o(1)] X^(2/3)/log X.
```

The weighted pair count satisfies

```plain text
sum_{X<p<=2X} z_p log p << X^(5/3).      (4.5)
```

This is genuinely stronger than the integer-size bound (4.1). I do not see a further unconditional exponent saving from the recurrence alone.

## 4.3 Why averaging the fixed-gap proof reproduces 5/3

Let

```plain text
D_h(p) := #{r : r,r+h in Z_p, r+h<p}.
```

The transfer-polynomial lemma gives, schematically,

```plain text
D_h(p) <= 3h.                            (4.6)
```

Let z_p=z. Order the zero positions. Their adjacent gaps have total less than p, so at least z/2 adjacent gaps are at most 2p/z.

Fix a threshold U. For p in (X,2X] with z_p>U, at least z_p/2 zero pairs have gap

```plain text
h <= 4X/U.
```

Summing (4.6) over primes and these gaps gives

```plain text
sum_{p:z_p>U} z_p
 << sum_{h<=4X/U} h * pi(2X)
 << X^3/(U^2 log X).                     (4.7)
```

The primes with z_p<=U contribute

```plain text
<< XU/log X.                             (4.8)
```

Hence

```plain text
T_X
 << XU/log X + X^3/(U^2 log X).          (4.9)
```

Optimizing at

```plain text
U=X^(2/3)
```

gives exactly

```plain text
T_X << X^(5/3)/log X.                    (4.10)
```

So the averaged recurrence-spacing method does not hide a better first moment. Its natural optimization is precisely the already-known exponent.

## 4.4 Even an average O(1) fixed-gap root bound only reaches 3/2

Suppose, very optimistically, one could improve the sum over primes for every fixed gap from the degree bound to

```plain text
sum_{X<p<=2X} D_h(p) << X/log X
```

uniformly in h. Then the high-z_p part would be

```plain text
<< X^2/(U log X),
```

and

```plain text
T_X << XU/log X + X^2/(U log X).
```

Optimizing at U=sqrt X yields only

```plain text
T_X << X^(3/2)/log X.
```

Thus a one-gap Chebotarev/root-count improvement is not enough for the conjectural X^(1+epsilon) scale. One needs information about configurations of several zeros at once.

## 4.5 Concrete multi-gap next step: resultants

If

```plain text
r, r+h, r+k belong to Z_p,
```

then

```plain text
F_h(r)=F_k(r)=0 mod p.
```

If F_h and F_k are coprime over Q, such a prime must divide the resultant

```plain text
R_{h,k} := Res_x(F_h,F_k).
```

This suggests a real research program:

1. determine gcd_Q[x](F_h,F_k) and classify exceptional (h,k);

1. bound the size and prime support of R_{h,k};

1. count three-zero and four-zero configurations uniformly for growing gaps;

1. combine those bounds with the adjacent-gap compression.

This would be new arithmetic input. The obstacles are serious: the gaps grow with X, resultants grow rapidly, and uniform control of their dyadic prime factors is much harder than a degree bound modulo one prime.

A recent structural result is Caruso–Fürnsinn–Vargas-Montoya–Zudilin, Galois Groups of Apéry-like Series Modulo Primes (revised March 2026). They prove that the first-block generating polynomial

```plain text
A_p(t)=sum_{r=0}^{p-1} B_r t^r
```

is either a square or (t^2-34t+1) times a square, according to p mod 24. This is valuable structure, but it is a factorization of a polynomial whose coefficients are the Apéry residues; it does not presently give an upper bound for the number or cross-prime alignment of zero coefficients.

## 4.6 Why T_X=O(X^(1+epsilon)) still would not prove the pointwise target

Such a theorem would be major progress on the first moment. It would improve (4.2) and the density bounds. It would not, by itself, exclude one exceptional integer.

The adversarial symmetric construction in Section 2 has

```plain text
T_X << X/log X
```

but

```plain text
K_X(m_0)=pi(2X)-pi(X).
```

Therefore the true empirical first moment and even the conjectural Poisson scale are compatible, at the level of first-moment data, with complete concentration at a single n.

For the every-n target, first moment must be paired with cross-prime correlation control. The four-prime estimate (D4) is one precise sufficient form.

Assessment for (3):

- T_X << X^(5/3)/log X: proved-reachable now;

- T_X << X^(3/2+o(1)): plausible-hard via uniform average fixed-gap theory;

- T_X << X^(1+epsilon): requires multi-gap/multi-zero arithmetic and is presently out of reach;

- pointwise target from T_X alone: impossible in principle.

# 5. Strongest theorem package actually available today

The following statements can be recorded without conjectural input.

## Theorem A: bounded-quotient localization of any failure

Assuming excess valuations contribute o(n), if

```plain text
W(n) >= epsilon n
```

for arbitrarily large n, then for those n there is an integer

```plain text
1 <= q <= ceil(4/epsilon)
```

such that

```plain text
#{p prime : n/(q+1)<p<=n/q,
              p | B_{n-qp}}
 >> epsilon^2 n/log n.
```

## Theorem B: exact CRT factorial moments

For all Y,X,k,

```plain text
sum_{m<Y}(K_X(m))_k <= T_X^k + Y A_X^k.
```

The first term cannot be removed by combinatorics, even under reflection symmetry and no-consecutive-zero constraints.

## Theorem C: a fourth dispersed moment would solve the target

If

```plain text
sum_{m<Y}(K_X(m))_4 << Y A_X^4
```

uniformly for sqrt Y<X<=Y, then

```plain text
W_rad(n) << n^(11/12)+log^2 n.
```

Thus the minimal moment order compatible with the known exponent 2/3 is four.

## Theorem D: total first-block incidence

```plain text
sum_{X<p<=2X}|Z_p| << X^(5/3)/log X,

sum_{X<p<=2X}|Z_p|/p << X^(2/3)/log X.
```

## Theorem E: fixed-gap recurrence rigidity

For each gap h, simultaneous zeros r,r+h force a zero of the explicit transfer polynomial F_h of degree 3(h-1). In particular, consecutive zeros are impossible, and the fixed-gap root count is linear in h after the standard nonzero clause.

## Theorem F: density consequence

For each fixed epsilon>0, the number of n in [N,2N] for which the squarefree large-prime weight is at least epsilon n is

```plain text
O_epsilon(N^(2/3)).
```

This is the natural ceiling of the current first-moment method.

# 6. Recommended next attack order

## 1. Formalize the four-prime statistic, not higher raw moments

Compute and prove identities for

```plain text
C_4(Y,X)
```

from Section 2. Empirically compare

```plain text
C_4(Y,X) / (Y A_X^4).
```

If it remains bounded or mildly growing, this is directly aligned with a theorem that proves the target. A k~log X experiment is less informative: the fourth moment is already the threshold forced by the 2/3 exponent.

## 2. Separate small-CRT excess from ordinary moment mass

For each four-prime tuple, measure the least CRT representative. The exact obstruction term is

```plain text
#{residue tuples with CRT representative <Y}
```

rather than the raw number of residue tuples. Any Fourier or large-sieve argument should target this statistic explicitly.

## 3. Build transfer polynomials and resultants

Compute F_h, factor them over Q, and test

```plain text
gcd(F_h,F_k),
Res(F_h,F_k),
```

for moderate gaps. Questions worth answering experimentally before proving anything:

- Are F_h,F_k generically coprime?

- Do resultants have predictable small-prime factors only?

- Is the number of primes p~X supporting a three-zero pattern much smaller than the degree bound?

- Are there exceptional gap relations analogous to divisibility-sequence rank phenomena?

## 4. Work quotient slice by quotient slice

Because any failure localizes to bounded q, begin with

```plain text
q=1:
  p=n-r,
  p prime,
  p|B_r.
```

Then q=2, and so on. Search for cancellation or modular transformations special to

```plain text
B_{n-qp} mod p
```

that are invisible in the unrestricted zero-set count. A theorem uniform in all q<sqrt n is unnecessary at first.

## 5. Do not invest in generic pair-gcd computations as the main line

They may be empirically interesting, but the selected pairs (n,n mod p) are conditioned by Lucas congruence to share p. Average pair-gcd behavior will not see this exceptional geometry.

# 7. Final answers to the three proposed mechanisms

## (1) Greedy/entropy

Verdict: hopeless from current inputs; plausible-hard with a new fourth-order dispersion theorem.

The exact CRT moment is

```plain text
S_k <= T_X^k + Y A_X^k.
```

For k~log X, the first term remains and allows one integer to carry all prime constraints. CRT injectivity fails to disperse because different prime subsets can all point to the same integer. The minimal sufficient extra input is a four-prime small-CRT estimate (D4); it would yield the explicit power saving O(n^(11/12)).

## (2) Divisor structure

Verdict: hopeless in ordinary gcd form.

The condition

```plain text
p | gcd(B_n,B_{n mod p})
```

is automatic from Lucas congruences. The remainder map is injective for p>sqrt n, so an individual bound on how many primes divide one B_r is redundant. No useful published pair-gcd law was found, and a generic exp(o(r)) gcd bound would still allow a factor of size n for each r~n.

The only real reusable piece is fixed-gap recurrence rigidity, already embodied in the p^(2/3) zero bound.

## (3) p-adic rigidity / total incidence

Verdict: plausible-hard, but first moment alone cannot prove an every-n theorem.

The strongest unconditional estimate is

```plain text
sum_{X<p<=2X}|Z_p| << X^(5/3)/log X.
```

The fixed-gap recurrence argument averages to the same exponent. An O(X^(1+epsilon)) theorem would be major density progress, but even the empirical O(X/log X) scale permits complete concentration at one integer unless accompanied by cross-prime correlation control.

The most concrete new arithmetic direction is multi-gap transfer-polynomial resultants, followed by a four-prime small-CRT theorem.
