## 1.1 The toric rational function and its one-dimensional Cartier block

Use the project’s Apéry Laurent polynomial

```plain text
L(x,y,z)
 = (1+x)(1+y)(1+z)((1+y)(1+z)+xyz)/(xyz),

b_n = CT L^n,
F(t) = Σ_(n≥0) b_n t^n = CT 1/(1−tL).
```

Put

```plain text
f_t(x,y,z) = 1 − t L(x,y,z).
```

The Newton polytope is the reflexive Apéry polytope and has the origin as its unique interior lattice point. In the notation of Beukers–Vlasenko, take the open set μ=Δ°. Then

```plain text
μ_Z = {0},
Q_(f_t)(Δ°) has rank 1,
ω_0 = [1/f_t]
```

is the standard basis of the unit-root quotient.

Beukers–Vlasenko define, for every m≥1,

```plain text
(β_m)_(u,v) = coefficient of x^(mv−u) in f_t^(m−1).
```

Here there is only u=v=0, so the matrix is the scalar

```plain text
β_m(t)
 = CT f_t^(m−1)
 = Σ_(k=0)^(m−1) (−1)^k C(m−1,k) b_k t^k.          (1.1)
```

For m=p, the elementary congruence

```plain text
(−1)^k C(p−1,k) ≡ 1 mod p
```

gives the exact Hasse–Witt identity

```plain text
β_p(t) ≡ A_p(t) := Σ_(k=0)^(p−1) b_k t^k mod p.    (1.2)
```

This is the first concrete Package-A output: the complete residue row is one Hasse–Witt entry.

The source is Beukers–Vlasenko, Dwork Crystals I, especially the definition of β_m in the introduction and Theorems 4.3 and 5.3. Their Cartier operator is

```plain text
C_p(Σ_a c_a x^a) = Σ_a c_(pa) x^a.                (1.3)
```

Let the coefficient ring be the p-adic completion of

```plain text
R_p = Z_p[t, β_p(t)^(−1)]
```

and choose the Frobenius lift σ(t)=t^p. On the ordinary locus, Theorem 5.3 gives the scalar Frobenius matrix

```plain text
Lambda_p^BV(t)
 = lim_(s→∞) β_(p^s)(t) / β_(p^(s−1))(t^p),        (1.4)
```

with the finite approximations

```plain text
Lambda_p^BV(t)
 ≡ β_(p^s)(t) / β_(p^(s−1))(t^p) mod p^s.          (1.5)
```

In the basis ω_0, the Cartier action is

```plain text
C_p(ω_0) = Lambda_p^BV(t) · ω_0^σ
           modulo the formal-derivative submodule. (1.6)
```

Equations (1.1), (1.4), and (1.5) are the requested finite truncated-sum formula. Equivalently, every coefficient is a toric residue / p-adic period coefficient:

```plain text
b_k = CT L^k
    = Res_(x=y=z=0) L(x,y,z)^k dx/x dy/y dz/z.     (1.7)
```

The nearest companion references are Dwork Crystals II, which treats truncated periods and rational Cartier images, and Dwork Crystals III, which uses Cartier filtrations and excellent Frobenius lifts to prove supercongruences for rational-function coefficients. Adolphson–Sperber’s p-adic refinement of the Hasse–Witt matrix gives a related A-hypergeometric matrix F(Λ^p)^(−1)F(Λ) for unit roots.

### Important limitation

Lambda_p^BV(t) exists as a unit-root Frobenius scalar only after inverting β_p(t). At a geometric parameter t_0 with A_p(t_0)=0, the ordinary quotient is not defined by this inversion. The mod-p polynomial (1.2), however, is globally meaningful. Therefore:

- coefficient extraction b_r=[t^r]β_p mod p is unconditional;

- interpreting the scalar ratio (1.4) at a nonordinary geometric fiber is not.

This distinction is essential because Z_p is a zero set of coefficients, not the nonordinary divisor in the geometric t-line.

## 1.5 Why there are p−1 blocks

Let pi_N:z↦z^N=t be the degree-N Kummer cover. Since N=p−1 is a p-adic unit, the integral idempotents

```plain text
e_r = (1/N) Σ_(zeta∈mu_N) zeta^r [zeta]           (1.21)
```

exist over the unramified coefficient ring containing mu_N. They give

```plain text
H^1_(rig,c)(pi_N^* A_-)
  = direct-sum_(r mod N)
      H^1_(rig,c)(A_- tensor K_r).                 (1.22)
```

Frobenius commutes with mu_N, so its matrix is block diagonal:

```plain text
bold(Lambda)_p = direct-sum_(r mod N) Lambda_(p,r). (1.23)
```

The generic total rank is 2N+O(1). This is not a defect of the construction. It is the correct geometry: mu_(p−1) is finite étale and its characters are disconnected tame components.

Therefore the honest answer to the “one matrix or one matrix per r?” question is:

- one scalar 1×1 BV matrix uniformly generates the coefficient vector in the geometric variable t;

- one separate generic 2×2 rigid Mellin block per tame character computes the integral Frobenius trace;

- packaging all blocks requires rank Theta(p) or a Kummer cover of degree p−1.

There is no bounded-size common Frobenius operator carrying all tame twists as graded pieces.

## 1.6 Torsion and exceptional-character ledger

The implementation must record four caveats.

1. Ordinary localization. The scalar limit (1.4) uses β_p(t)^(−1). Coefficients of β_p remain valid without this localization, but the unit-root quotient does not.

1. Cohomological torsion. The image of nabla_r in the finite prebasis must be saturated. Compute the Smith normal form over the chosen integer ring; a nonsaturated quotient can change the trace modulo p.

1. Tame projectors are harmless. The denominator 1/(p−1) in (1.21) is a p-adic unit, so the tame character decomposition itself introduces no p-torsion.

1. Nongeneric characters. Define

```plain text
E_p = {r mod N:
       H_c^i(A_- tensor K_r) is nonzero for i≠1,
       or dim H_c^1 differs from 2}.                (1.24)
```

r=0 is certainly exceptional and r=N is its duplicate. The project’s local-monodromy/self-twist analysis gives a safe order-at-most-four envelope, so the first implementation should separately audit

```plain text

```

when integral, without claiming that all four are genuine rank exceptions. The central and quarter characters are arithmetically special even when their cohomology rank remains generic. The exact set E_p should be computed from the local exponents and then printed.

# 2. Transfer matrices and the local-limit attack

## 2.1 Exact SL_2 cocycle

Let

```plain text
P(n)=34n^3+51n^2+27n+5,
B_n=(n!)^3 b_n.
```

The recurrence becomes

```plain text
B_(n+1)=P(n)B_n−n^6B_(n−1).                       (2.1)
```

Set

```plain text
A_n = [ P(n)  −n^6 ]
      [ 1       0   ],

G_n = n^(−3) A_n
    = [ P(n)/n^3  −n^3 ]
      [ n^(−3)      0   ] ∈ SL_2(F_p).             (2.2)
```

For 1≤r≤p−1, one has the exact orbit formula

```plain text
G_(r−1) ... G_2 G_1 (5,1)^T
   = (r^3 b_r, b_(r−1))^T.                        (2.3)
```

Hence

```plain text
b_r=0  iff  the first coordinate in (2.3) is zero. (2.4)
```

The cocycle is deterministic and inhomogeneous: the step matrix is the rational function G_n evaluated at the clock value n.

## 2.2 What the standard frameworks do and do not provide

### Chung–Diaconis–Graham type mixing

Chung, Diaconis, and Graham study random affine recurrences such as

```plain text
X_(n+1)=2X_n+epsilon_n mod p
```

with independent random increments. See “Random walks arising in random number generation,” Annals of Probability 15 (1987), 1148–1165, DOI 10.1214/aop/1176992088.

Mismatch: the Apéry process has no independent increments and no averaging over choices of generators. Replacing the deterministic clock by random n would prove a theorem about a different process.

### Products of random matrices / nonhomogeneous Markov chains

Furstenberg-type products and finite-state Markov-chain local limits assume independent, stationary, or at least genuinely mixing randomness in the factors. Time-inhomogeneous Markov-chain estimates still average over transition kernels.

Mismatch: (2.3) is one fixed word. Its transition operator on the skew product

```plain text
(n,x) ↦ (n+1,G_n x)
```

is a permutation of the finite state space, hence unitary; it has no spectral gap by itself.

### Bourgain–Gamburd expansion

Bourgain–Gamburd prove uniform expansion for Cayley graphs of SL_2(F_p) arising from a fixed non-elementary generating set; see Annals of Mathematics 167 (2008), 625–642. Their related congruence-level work is JEMS 10 (2008), 987–1011.

Potential use: if one forms an averaged measure from many sliding blocks

```plain text
T_(s,L)=G_(s+L−1)...G_s,
```

product-growth and flattening may show that this averaged block measure acts expansively on P^1(F_p).

Mismatch: expansion of a random word or convolution measure does not control the ordered diagonal sequence T_(s,L)x_s, because the incoming state x_s is the entire previous history and is maximally correlated with the block start s.

### Polynomial dynamical systems and orbit exponential sums

Ostafe–Shparlinski bound exponential sums along orbits of multivariate polynomial systems; see “On pseudorandom numbers from multivariate polynomial systems,” FFA 16 (2010), 320–328, and the related permutation-system paper DOI 10.1016/j.ffa.2009.12.003.

The Apéry cocycle can be made autonomous by adding the clock coordinate. After clearing denominators it is a rational map on a three-dimensional state (n,[x:y]).

Mismatch: the available orbit bounds require hypotheses on orbit length, degree growth, exceptional subvarieties, or averages over initial points that are not presently verified here. The available p steps in an ambient state space of size about p^2 or p^3 are not automatically in the nontrivial range.

### Deligne/Weil bounds for fixed sliding blocks

For fixed L, every entry of T_(s,L) is a rational function of s of degree O(L). Once one proves that a chosen phase is not constant and not an Artin–Schreier form, ordinary Weil bounds give

```plain text
Σ_s e_p(a · linear_entry(T_(s,L))) = O(L sqrt(p)). (2.5)
```

This part is feasible now. It is a useful warm-up and should be proved symbolically for small L, then uniformly in fixed L.

The remaining obstruction: the phase defining b_(s+L) also contains the incoming state at time s. Fixed-block Weil cancellation does not decouple the block from that history.

## 2.3 The single statement that beats 2/3

For a∈F_p, let

```plain text
N_p(a)=#{1≤r≤p−2:b_r=a}.
```

Define the ordered off-diagonal collision energy

```plain text
E_p^off
 = Σ_(a∈F_p) N_p(a)(N_p(a)−1)
 = #{(r,s):1≤r≠s≤p−2, b_r=b_s}.                  (2.6)
```

The first lemma to attack is:

```plain text
TRANSFER-ENERGY LEMMA TE_(5/4).
There is an absolute constant C such that for every prime p≥7,

E_p^off ≤ C p^(5/4).                               (2.7)
```

This is strictly weaker than the observed random-map scale E_p^off=O(p).

It immediately gives the desired defining-characteristic anti-concentration. Since all distinct pairs of zero indices are included in (2.6),

```plain text
|Z_p|(|Z_p|−1) ≤ E_p^off,
```

and therefore

```plain text
|Z_p| ≤ 1+sqrt(C)p^(5/8).                          (2.8)
```

Thus TE_(5/4) gives (DRS) with alpha=5/8<2/3 and improves the current fiber exponent. More generally,

```plain text
E_p^off ≪ p^(4/3−eta)
  ==> |Z_p| ≪ p^(2/3−eta/2).                       (2.9)
```

The Fourier form is

```plain text
S_p(h)=Σ_(r=1)^(p−2) e_p(hb_r),

Σ_h |S_p(h)|^2
 = p Σ_a N_p(a)^2.                                 (2.10)
```

Therefore (2.7) is an averaged additive-character cancellation theorem, much weaker than demanding a square-root bound for every S_p(h).

## 2.4 Hardest step

The hardest step is ordered-cocycle history/future decoupling:

convert square-root cancellation for bounded-length rational block products into cancellation after inserting the actual incoming state generated by the preceding deterministic product.

Neither random-walk expansion nor Deligne’s theorem supplies this. In algebraic terms, direct elimination writes a long product whose degree grows linearly with the gap, causing the conductor/degree in a one-shot Weil bound to grow with p. In probabilistic terms, the future block and past state share the deterministic clock and are not independent.

A successful proof of TE_(5/4) will need one of the following genuinely new inputs:

1. an ordered-block flattening theorem for the measures s↦T_(s,L) that remains valid on the correlated graph s↦x_s;

1. a multiscale van der Corput argument in which every higher difference collapses to fixed-degree continuants;

1. a new bounded-complexity sheaf/automaton representing pair collisions of the recurrence orbit;

1. a sum-product estimate specialized to the rational cocycle (2.2), with all parabolic/dihedral trapping subvarieties classified.

The first fixed-block Weil lemma is feasible now. The passage from it to history/future decoupling is the load-bearing new theorem.

# 3. Gross–Koblitz and the proposed phase/modulus factorization

## 3.1 Exact carry decomposition

Let N=p−1 and s_r=min(r,N−r). Reindexing the verified Jacobi-sum formula and applying Gross–Koblitz gives a sum of the shape

```plain text
b_r
 = Σ_(u=0)^(N−1) p^(2c_+(r,u)+2c_−(r,u)) U_p(r,u),   (3.1)
```

where

```plain text
c_+(r,u)=1 iff u>r,
c_−(r,u)=1 iff u>N−r,
```

and each U_p(r,u) is a p-adic unit given by a bounded product of Morita gamma values. In one standard convention, the valuation-zero part is

```plain text
U_p(r,u)
 = [ Gamma_p((r−u)/N)
     Gamma_p((N−r−u)/N)
     Gamma_p(u/N)^2
     /
     (Gamma_p(r/N)Gamma_p((N−r)/N)) ]^2,            (3.2)
```

up to a common harmless unit/sign fixed by the Gauss-sum convention.

Only

```plain text
0≤u≤s_r                                                   (3.3)
```

survive modulo p. Reduction gives exactly

```plain text
b_r
 ≡ Σ_(u=0)^(s_r) C(r,u)^2 C(N−r,u)^2 mod p
 ≡ Σ_(u=0)^r C(r,u)^2 C(r+u,u)^2 mod p.              (3.4)
```

The primary source for the Gauss-sum/gamma conversion is Gross–Koblitz, “Gauss sums and the p-adic Gamma-function,” Annals 109 (1979), 569–581.

## 3.2 The natural factorization is circular

Choose any one nonzero gamma unit as a proposed phase, for example

```plain text
Phase_p(r)=U_p(r,0).
```

Then (3.1) becomes

```plain text
b_r = Phase_p(r) · Mod_p(r),                         (3.5)

Mod_p(r)
 = Σ_u p^(2c_++2c_−) U_p(r,u)/U_p(r,0).             (3.6)
```

Modulo p,

```plain text
Mod_p(r)
 ≡ Σ_(u=0)^(s_r) U_p(r,u)/U_p(r,0)
 ≡ Phase_p(r)^(−1)b_r.                              (3.7)
```

Since Phase_p(r) is a unit, its extraction does not change the zero set. The proposed “modulus factor” is exactly the original Apéry cancellation written in gamma notation. It contains 1+s_r, generically Theta(p), unit summands.

Therefore:

- a termwise Gross–Koblitz formula does exist;

- a common p-adic unit phase can always be extracted;

- the remaining factor has no proved lower complexity and, in the natural construction, is literally b_r divided by a unit.

Verdict: provably circular for the natural gamma/Jacobi factorization. This does not logically rule out a miraculous independent identity for a special character order, but Gross–Koblitz alone does not supply it.

The underlying reason is addition: the zeros come from cancellation among many valuation-zero Gauss/Gamma terms, not from a gamma factor vanishing. Morita gamma values at the relevant rational arguments are units.

## 3.3 The genuine order-four/quarter exception

There is a real noncircular special evaluation for the branch coefficient, not for a generic Apéry coefficient.

For p≡1 mod 4, the project proves

```plain text
tau_((p−1)/4) ≡ [Q^p] M(Q) mod p,                  (3.8)
```

where

```plain text
M(Q)
 = Q D(Q^4)
   product_(n≥1)
   [(1−Q^(4n))(1−Q^(8n))(1−Q^(12n))(1−Q^(24n))]^(1/2),

D(q)
 = (E_2(q)−2E_2(q^2)−3E_2(q^3)+6E_2(q^6))/2.      (3.9)
```

This is the fixed weight-three eta-multiplier form on the cyclic four-cover of the level-six curve recorded in Q6360. In the project’s Gauss normalization it also splits as an oriented quartic Jacobi/Hasse unit 2A times an order-24 residual multiplier. The quartic Jacobi unit is a genuine Gross–Koblitz gamma phase after a quartic character is chosen.

The apparition theorem then gives the exact vanishing laws

```plain text

sigma_((p−3)/4)=0 mod p iff p≡23 mod 24.            (3.10)
```

This is genuine compression: one distinguished character-order block is governed by a fixed modular/CM object.

It does not extend automatically to b_r. The structure theorem says

```plain text
A_p(t)=S_p(t)^2
or
A_p(t)=q(t)S_p(t)^2.                                (3.11)
```

Consequently a coefficient b_r is a convolution of many branch coefficients. Even at a quarter index,

```plain text

```

in the tau branch, with the analogous q sigma^2 expression in the other branch. Knowing the single central branch coefficient does not factor this convolution. Beyond character orders dividing 24, the self-twist classification supplies no bounded-order symmetry that could force a comparable collapse.

Verdict: genuine for the isolated quarter branch block; circular for generic b_r; no presently justified interpolation from order 4 to growing character order.

## 5.1 First lemma

The recommended first attack is exactly TE_(5/4):

```plain text
For every prime p≥7, let
N_p(a)=#{1≤r≤p−2:b_r≡a mod p}.
Then there is an absolute C such that

Σ_a N_p(a)(N_p(a)−1) ≤ C p^(5/4).                 (5.1)
```

Reasons for choosing it:

- it directly improves the exponent from 2/3 to 5/8;

- it is weaker than a residue local limit and weaker than uniform Fourier cancellation;

- it naturally incorporates the forced reflection pairs r↔p−1−r, whose total contribution is only O(p);

- it can be expressed both as transfer-orbit collisions and as the averaged Fourier identity (2.10);

- the random/Poisson model predicts a much stronger O(p) answer, so p^(5/4) leaves a large safety margin.

A useful warm-up, but not a substitute, is:

```plain text
For each fixed L and every nonzero linear functional ell on M_2(F_p),
```

## 5.2 Fastest numerical falsification

One pass through the recurrence suffices for each prime.

```plain text
INPUT: prime p.
1. Compute b_0,…,b_(p−2) mod p by the three-term recurrence.
2. Build the histogram N_p(a).
3. Compute
       E_p^off = Σ_a N_p(a)(N_p(a)−1).
4. Record
       E_p^off/p,
       E_p^off/p^(5/4),
       max_a N_p(a),
       |Z_p|.
5. For every value a, store its position list.
   For each ordered pair of distinct positions with the same value,
   increment the gap counter C_p(h).
   This costs O(p+E_p^off), not O(p^2), when the observed energy is linear.
6. Separate the forced reflection gap pairs and inspect the remaining
   largest C_p(h) and dyadic sums Σ_(h in block) C_p(h).
```

The fastest falsifier is a dyadic scan of the normalized maxima

```plain text
M(X)=max_(X<p≤2X) E_p^off/p^(5/4).                 (5.3)
```

Run all already-known worst primes for |Z_p| and maximum fiber first, then random primes in dyadic ranges up to the current 10^6 boundary. The lemma is in serious danger if a log–log regression of the dyadic maxima has stable slope above 1.25, or if one non-reflection gap contributes p^(1/4+epsilon) collisions across growing ranges.

For a sharper one-day pilot, test the stronger envelope

```plain text
E_p^off ≤ 100 p (log p)^2.                         (5.4)
```

A violation of (5.4) does not disprove (5.1), but it immediately identifies the resonant prime/gap that any proof must explain. If (5.4) survives and E_p^off/p remains tight, the data support attacking the stronger p^(1+epsilon) energy theorem rather than stopping at 5/4.

## 5.3 What to inspect when a spike occurs

For the worst (p,h) print:

```plain text
- all r with b_(r+h)=b_r;
- whether r and r+h are reflection partners;
- the continuant N_h(r);
- the sliding block T_(r,h);
- the projective incoming state [B_r:B_(r−1)];
- whether T_(r,h) lies in a Borel, torus, or dihedral normalizer;
- the orders of the corresponding tame characters.
```

A repeated concentration in a proper subgroup would point toward a Bourgain–Gamburd/sum-product proof after classifying the subgroup obstruction. Diffuse spikes with no subgroup concentration would instead favor multiscale van der Corput or a defining-characteristic trace formalism.
