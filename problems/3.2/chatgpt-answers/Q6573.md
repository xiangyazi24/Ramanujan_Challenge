# The family-compatibility wall: one master formulation

## Executive conclusion

The six coordinates in the prompt are not literally equivalent. They are six projections of one stronger missing statement.

The correct master statement is not merely a root-count bound and not merely the existence of a geometric realization. It is a quenched, two-parameter, all-level L2 large-sieve estimate for the determinant map

```plain text
Delta_p(r,h) = b_r c_(r+h) - c_r b_(r+h).
```

I propose the following as the canonical wall.

```plain text
[WALL]  Quenched triangular all-level L2 sieve.
```

For every epsilon > 0 there is C_epsilon such that, for every sufficiently large prime p, every intervals

```plain text
I subset {1,...,p-2},
J subset {0,...,p-2},
```

and every complex coefficient vectors u=(u_r) and v=(v_h), the following holds.

Let

```plain text
Omega(I,J)
 = {(r,h): r in J, h in I, 0 <= r < r+h <= p-2},

nu_(u,v)(a)
 = sum_((r,h) in Omega(I,J), Delta_p(r,h)=a) u_r v_h,

W_(u,v) = sum_((r,h) in Omega(I,J)) u_r v_h,

E_(u,v) = sum_((r,h) in Omega(I,J)) |u_r v_h|^2,

X = 2 + |I| + |J|.
```

Then

```plain text
sum_(a in F_p) |nu_(u,v)(a) - W_(u,v)/p|^2
 <= C_epsilon X^epsilon E_(u,v).                 (WALL)
```

The epsilon-free version, with C_epsilon X^epsilon replaced by an absolute constant, will be called [WALL-sharp].

The main conclusions of this chapter are:

1. [WALL] rigorously implies coordinates (1)-(4) and (6), and implies the p^(1+epsilon) form of GPRV in coordinate (5).

1. [WALL-sharp] gives the exact O(p) form of GPRV and the sharp random-scale form of COINC.

1. The zero-fiber restriction of [WALL] already implies coordinates (1)-(5), but it does not imply COINC. This is why the master statement must be all-level.

1. A fixed-complexity mixed F-crystal realization is a proposed mechanism for proving [WALL], not the wall itself. Realization alone is insufficient without product-monodromy, bounded-complexity, and defining-characteristic local-limit inputs.

1. The weakest mechanism-bearing next target is an averaged near-neighbor codegree saving. Any positive saving there breaks the present 5/2 box barrier.

This formulation is quantitative, normalization-visible, machine-testable, and independent of which geometric technology eventually proves it.

# 1. Exact setup

Put

```plain text
N = p-1,
X_p = {0,...,N-1} = {0,...,p-2},
v_n = (b_n,c_n) in F_p^2.
```

The Casoratian shows that v_n is never the zero vector on the working range. Define the non-wrapping triangle

```plain text
Omega_p = {(r,h): 0 <= r, 1 <= h, r+h <= p-2}.
```

The determinant map is

```plain text
Delta_p : Omega_p -> F_p,
Delta_p(r,h)=det(v_r,v_(r+h)).
```

The projective collision identity is exact:

```plain text
Delta_p(r,h)=0  <=>  pi(r)=pi(r+h).
```

This determinant formulation is the authoritative one. When one translates it to gap polynomials, all denominator-clearing and cut-edge factors must be saturated away. The true mirror section is retained; it is an actual orbit collision, not an artifact.

The known mirror section has bounded incidence degree:

```plain text
r+h = p-1-r,
or equivalently 2r+h=p-1,
```

up to the endpoint convention already fixed in the project. It contributes one deterministic edge in every admissible even-gap column and has operator norm O(1). Thus it is harmless for [WALL]; one may subtract it to improve constants, but no exponent depends on doing so.

The same applies to any fixed finite list of small-gap columns, including the -51 splitting law at gap 2. They contribute finite-rank or O(1)-column corrections.

# 2. Why the reference measure is uniform

The exact determinant distribution of two independent nonzero vectors is not perfectly uniform:

```plain text
Prob(det=0)=1/(p+1),
Prob(det=a)=p/(p^2-1) for a != 0.
```

Nevertheless the uniform reference 1/p is the correct analytic normalization because it makes additive Fourier inversion exact. The difference between the projective reference law and the uniform law is O(1/p^2) per value and produces only rank-one lower-order corrections in every estimate below.

One may replace W/p in [WALL] by the exact nonzero-vector reference law if desired. The two formulations have the same exponent content.

Let

```plain text
B_s(u,v)
```

```plain text
sum_(a in F_p) |nu_(u,v)(a)-W_(u,v)/p|^2
```

```plain text
(1/p) sum_(s != 0) |B_s(u,v)|^2
```

This is the precise family-compatibility input. It asks for average square-root cancellation over the additive frequency s, simultaneously in the start coordinate r and the gap coordinate h.

It is weaker than a pointwise bound for every s, and stronger than separate fixed-h Weil estimates. It is exactly at the level where the six current approaches meet.

# 4. Two alternative formalizations and why they are not selected

## 4.1 Zero-fiber spectral packing

Define the collision incidence matrix

```plain text
A_(r,h)=1_(Delta_p(r,h)=0),
B_(r,h)=A_(r,h)-1/p.
```

A natural narrower wall is

```plain text
[WALL-zero]
|sum_((r,h) in Omega(I,J)) u_r v_h B_(r,h)|^2
 <= C_epsilon X^epsilon E_(u,v).                   (4.1)
```

Equivalently, every rectangular restriction of B has l2-to-l2 operator norm X^(o(1)).

This is already sufficient for MESO-PAIR, T3-2MINUS, every sigma target, BLOCK-SUBQUAD, and GPRV. It is the most economical formulation if one only cares about zero collisions.

It is not sufficient for COINC. Two maps can have exactly the same zero set while one distributes its nonzero values uniformly and the other maps every nonzero pair to a single value. Their zero-fiber matrices are identical, but the second map has maximal value-collision energy.

Thus [WALL-zero] does not unify all six coordinates.

## 4.2 Fixed-complexity geometric realization

A geometric implementation would assert the existence of a fixed-dimensional algebraic parameter space and a bounded-rank lisse sheaf or overconvergent F-isocrystal whose trace or period coordinate recovers

```plain text
(r,h) -> Delta_p(r,h),
```

with the following additional properties:

1. the clock/gap variable h is an actual algebraic parameter, not an external iteration length;

1. conductor and Betti complexity are bounded or at most (pH)^(o(1));

1. tensor products attached to distinct gaps have no trivial constituents except the explicit mirror and fixed-gap skeleton;

1. product monodromy is maximal in the needed range;

1. specialization to the defining characteristic controls exact residual values, not only normalized complex traces.

Call this package [WALL-geo].

It is a plausible proof architecture, but it is not a clean master conjecture. The existence of a realization by itself does not imply [WALL]. One still needs a family large-sieve theorem and a defining-characteristic local-limit comparison.

This distinction is supported by the standard literature:

- Deligne's Weil II gives square-root cancellation for a fixed bounded-complexity object, not automatically for a growing deterministic family.

- Fouvry-Kowalski-Michel, A study in sums of products, obtains cancellation after a fixed trace-function realization and a Goursat-Kolchin-Ribet independence analysis.

- Kowalski, The large sieve, monodromy and zeta functions of curves, gives a Frobenius large sieve for genuine algebraic families with controlled monodromy.

- Katz, Convolution and Equidistribution, treats fixed Mellin objects and fixed-complexity test functions.

The present difficulty is precisely that the recurrence length h has not yet been converted into such a fixed-complexity parameter.

## 4.3 Selection

[WALL] is the preferred formalization because it states the exact quantitative output needed by the campaign while remaining agnostic about the eventual proof technology.

The logical relation is

```plain text
[WALL-geo]
 + bounded family complexity
 + product monodromy/no exceptional tensors
 + defining-characteristic local limit
        |
        v
      [WALL]
        |
        +--> [WALL-zero].
```

The upper arrow is open. The lower arrow is immediate.

# 13. Why the six old routes stopped at the same place

The common obstruction is now visible as an operator-norm problem.

## 13.1 Fixed h is free

For a fixed h, the gap polynomial or transfer object has finite complexity. Degree, Weil, Chebotarev, and resultant methods control one column.

## 13.2 Growing h creates an assembly problem

When h ranges through a power-sized interval, the columns must be assembled into one operator. Columnwise bounds do not control its largest singular value.

The six coordinates test different vectors or norms of the same operator:

- MESO-PAIR tests the row wedge count for the all-one h-vector.

- T3 tests the full-scale third factorial moment of row degrees.

- the sigma ladder tests truncated row wedges.

- BLOCK-SUBQUAD tests a translated local all-one rectangle.

- GPRV tests the column-sum vector, equivalently the adjoint applied to the all-one r-vector.

- COINC tests the Hilbert-Schmidt defect of the full value pushforward.

The missing theorem is therefore not another bound for an individual polynomial. It is a family large-sieve statement controlling the assembled triangular operator.

# 16. What a proof through the mixed F-crystal would have to construct

The verified mod-p^7 depth tower and rank-4 mixed extension are important, but they do not yet give [WALL].

A successful crystal route needs the following additional objects.

## 16.1 Algebraize the gap clock

The current depth tower describes block transport in the coefficient index. It does not identify the iteration length h with an algebraic coordinate on a fixed base.

One needs a relative mixed F-isocrystal M on a fixed-dimensional space with a specialization map

```plain text
(r,h) -> M_(r,h)
```

whose trace or period coordinate recovers Delta_p(r,h).

## 16.2 Construct the two-copy object

For COINC one needs a tensor product or correspondence whose trace detects

```plain text
Delta_p(r,h)=Delta_p(r',h').
```

The desired object is not just the rank-4 extension itself. It is a two-copy pushforward along the difference map

```plain text
Delta_p(r,h)-Delta_p(r',h').
```

with all diagonal and mirror constituents explicitly split off.

## 16.3 Prove no exceptional constituents

One must show that, outside the explicit skeleton, the two-copy object has no geometrically constant summand and no growing family of self-twists. This is the exact analog of the Goursat-Kolchin-Ribet step in trace-function product estimates.

## 16.4 Bound family complexity

The total compactly supported cohomology must have rank or Betti complexity X^(o(1)). A realization whose rank grows linearly with h merely repackages the wall.

## 16.5 Defining-characteristic local limit

Finally, the trace formula must control exact residual values in F_p. Archimedean or auxiliary-l equidistribution alone does not imply [WALL].

Thus the direct bridge from the mod-p^7 tower to [WALL] remains open. The tower identifies the plausible category; it has not yet supplied the assembled two-parameter large sieve.

# 17. If the wall is false: the counterexample worlds

Failure of [WALL] need not be visible in current global statistics. There are several distinct failure modes.

## 17.1 A localized heavy row

Take a sparse sequence of primes and let

```plain text
H=p^(1/3).
```

In one translated h-window of length H, plant one start point r_0 with

```plain text
d_I(r_0) about H^(2/3).
```

This saturates the proved window multiplicity bound but does not violate it.

Its extra contributions are

```plain text
row variance       about H^(4/3)=p^(4/9),
energy increment   about p^(4/9),
T3 increment       about H^2=p^(2/3).
```

Both global increments are o(p). Therefore one can still have

```plain text
E^pi/p -> 3,
T3/p -> 4,
```

while [WALL-zero] fails by the factor

```plain text
H^(4/3)/H=H^(1/3)=p^(1/9).
```

This world is compatible with every current global random constant. It must hide in a translated mesoscopic window or at primes beyond the scan.

## 17.2 A thin p-dependent resonance class

There may be a congruence class or apparition-rank class of gaps

```plain text
h in H_p subset (H,2H]
```

with |H_p|=H^(o(1)) or H^theta, on which the primitive gap fields acquire a common quotient, self-twist, or resultant factor. Its total density in h can vanish while its operator singular value grows.

Fixed-h Chebotarev and unweighted all-h means would not see this mode.

## 17.3 A nonzero-level concentration

The zero collision set may remain perfectly Poisson while, on a thin rectangle, all nonzero determinant values fall in a set of size p^(1-kappa).

Then MESO-PAIR, T3, BLOCK-SUBQUAD, and GPRV can all remain true, but COINC and the all-level wall fail.

This is the exact reason the zero-fiber wall and the all-level wall are distinct.

## 17.4 A weighted singular vector

Current experiments mostly test all-one weights, prefix intervals, low moments, and a few dyadic scales. An incidence matrix can have random row and column sums but still possess a large signed singular vector supported on a sparse translated box.

[WALL] quantifies over weights precisely to exclude this possibility.

## 17.5 High-degree closed-point resonance

A raw gcd scan over M_h mod p can show common irreducible factors of degree greater than one even when there are no common F_p roots. Such a phenomenon attacks an algebraic strengthening of the wall but does not directly affect the orbit determinant wall.

Every numerical report must separate

```plain text
deg gcd(M_h,M_k)
```

from

```plain text
deg gcd(M_h,M_k,X^p-X).
```

## 17.6 Where a genuine bad world must hide

Given the existing data, a counterexample cannot be a positive-density macroscopic effect at small or fixed h. It must be localized in at least one of the following directions:

1. a very sparse sequence of primes;

1. translated h-windows not tested by prefix statistics;

1. a p-dependent thin congruence or self-twist class;

1. a localized r-window;

1. a signed spectral mode invisible to unweighted counts;

1. a nonzero determinant level invisible to collision-only data;

1. the mixed-crystal normalization rather than the current recurrence gauge.

This list is a falsification protocol for the next experimental campaign.

# 21. Least-confident point

My least-confident point is not any of the formal reductions. Those are elementary consequences of [WALL].

The uncertain point is whether the all-level determinant map in the present gauge is the geometrically canonical object. Multiplying Delta_p(r,h) by an h-dependent nonzero scalar preserves every zero-collision statement but changes COINC completely. The mixed F-crystal may provide a different canonical normalization.

Before investing heavily in COINC geometry, the project should test several natural normalizations of Delta and determine which one has stable all-level L2 statistics.

# 22. Shared blind spot

The likely shared blind spot is still the choice of coordinates.

We have treated h as an external iteration length and Delta as a recurrence determinant. The correct low-complexity object may instead be a Frobenius coordinate of the rank-4 mixed extension / syntomic regulator class. In that coordinate:

1. h may become an algebraic character or convolution parameter;

1. the mirror and fixed-gap skeleton may become invariant summands;

1. the family large sieve may become a standard tensor-product monodromy statement;

1. the correct normalization of nonzero determinant levels may become automatic.

Conversely, if no such coordinate exists, then [WALL] is genuinely a new quenched theorem for a deterministic nonautonomous cocycle, outside the current fixed-object trace-function framework.

That dichotomy is the central conceptual question of the next campaign.
