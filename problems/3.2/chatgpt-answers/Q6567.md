# MESO-PAIR: exact shifted-resultant reduction, pollution audit, and the balanced-pair wall

## 0. Executive verdict

The two-lag elimination is valid, but the raw bad-pair set proposed in the question is not the right arithmetic object.

The main conclusions are:

1. There is an exact sequential-gap identity

```text
Q_D = sum_(a,g >= 1, a+g <= D) C_p(a,g),

C_p(a,g)
 = #{ r : pi(r)=pi(r+a)=pi(r+a+g) }.
```

Thus MESO-PAIR is already a local third-factorial-moment problem. Renewal does not convert it into a lower moment; it only changes coordinates from two returns based at r to two consecutive return edges.

2. The same-base resultant factors exactly into an adjacent resultant and the shifted resultant that detects the second edge:

```text
Res(N_h(X),N_k(X))
 = Adj_h * Res(N_h(X),N_(k-h)(X+h))
```

up to the repository's harmless one-step normalization. The second factor is the genuine regular two-return eliminant. The first factor is mostly cut-edge pollution.

3. The exact adjacent-resultant formula does produce a triangular closure of raw resultant divisibility, but it is the wrong closure. A single low Apéry zero p | b_j forces p to divide all adjacent resultants above level j, and then all same-base resultants in an entire upper triangle. These common roots are endpoint/cut-edge roots and need not contribute one point to Q_D.

Therefore the proposed raw target

```text
|B_D(p)| << N/D
```

can fail for a completely understood reason even when the regular Q_D is small. One must use shifted and saturated resultants, or count the actual regular common roots directly.

4. The supplied height estimate gives only

```text
|B_D(p)| << D^4 log D / log p
```

for nonzero resultants. At

```text
D = sqrt(N) L,
```

this is of size

```text
N^2 L^4,
```

whereas the crude support target is

```text
N/D = sqrt(N)/L.
```

The missing saving is a factor of about

```text
N^(3/2) L^5.
```

This is not a height refinement. It is a fixed-p nonconcentration theorem for a deterministic triangular array of shifted resultants.

5. The recurrence does not yield a useful bounded-order recurrence for the shifted resultants. After reducing modulo N_h, the shifted continuants form a rank-2 recurrence over an algebra of dimension about 3h. Taking the norm to obtain a resultant raises the natural state dimension with h. The exact recurrence gives root repulsion and renewal, not a low-rank closure of the bad-pair set.

6. There is one genuine unconditional refinement that should be banked. Let

```text
M_D = max_r d_D(r) <= 4 D^(2/3).
```

For an internal-gap cutoff G,

```text
sum_(a+g<=D, min(a,g)<=G) C_p(a,g)
 << D^(2/3) G^2.
```

Taking

```text
G asymp N^(1/3) L^(-1/3)
```

makes this contribution O(N). Hence the only remaining part of MESO-PAIR is the balanced core

```text
G <= a, g,

a+g <= D.
```

Adjacent resultants, R_1=0, the h=2 law, and every fixed-small-h certificate live in the already harmless axis strips.

7. The minimal remaining statement is therefore not an unweighted raw bad-pair count. It is the weighted shifted-incidence estimate

```text
[MESO-BALANCED-PAIR]

sum_(G<=a,g, a+g<=D)
 #{ r regular : N_a(r)=0 and N_g(r+a)=0 }
 << N.
```

An algebraic strengthening is

```text
sum_(G<=a,g, a+g<=D)
 deg gcd_Fp( N_a(X), N_g(X+a) )
 << N.
```

This is another exact face of the fixed-p family-compatibility theorem. The resultant language has not reduced its mathematical depth.

8. After this attack, my proof-priority ordering for a first strict improvement over p^(3/2) is:

```text
(1) T3-2MINUS: T3 << p^(2-delta) for any fixed delta>0;
(2) MESO-BALANCED-PAIR at D=sqrt(p)L;
(3) block subquadratic S_p(H) << H^(2-epsilon);
(4) full ATR;
(5) GPRV / SAME-LAG-BDH.
```

MESO-PAIR remains a correct and useful target, but the hoped-for cheap resultant closure does not materialize. T3-2MINUS now has the smaller explicitly measured exponent gap.

# 1. Exact notation and the sequential-chain identity

Let the projective orbit have length N:

```text
pi(0),...,pi(N-1).
```

For nonwrapping gaps put

```text
I(r,h) = 1 if r+h<N and pi(r)=pi(r+h), else 0,

R_h = sum_r I(r,h),

d_D(r) = sum_(1<=h<=D) I(r,h),

S_D = sum_r d_D(r) = sum_(h<=D) R_h,

Q_D = sum_r binom(d_D(r),2).
```

For h<k define

```text
J(h,k)
 = #{ r : r+k<N,
           pi(r)=pi(r+h)=pi(r+k) }.
```

Then, with no estimate and no recurrence,

```text
Q_D = sum_(1<=h<k<=D) J(h,k).                       (1.1)
```

Now put

```text
a=h,

g=k-h.
```

Define the consecutive-edge count

```text
C_p(a,g)
 = #{ r : r+a+g<N,
           pi(r)=pi(r+a),
           pi(r+a)=pi(r+a+g) }.
```

Transitivity of equality gives the exact identity

```text
J(a,a+g)=C_p(a,g).                                  (1.2)
```

Therefore

```text
Q_D
 = sum_(a,g>=1, a+g<=D) C_p(a,g).                  (1.3)
```

This is the clean renewal coordinate. It should replace every informal phrase such as "one bad pair produces a chain". Each element of Q_D is exactly one two-edge chain, and every two-edge chain is exactly one element of Q_D.

In the positional gap-polynomial gauge used in the question,

```text
pi(r)=pi(r+a)       <=> N_a(r)=0,
pi(r+a)=pi(r+a+g)   <=> N_g(r+a)=0.
```

Thus

```text
C_p(a,g)
 = #{ r regular : N_a(r)=0 and N_g(r+a)=0 }.        (1.4)
```

The word "regular" is load-bearing: the whole transfer interval must avoid the singular clock value. Raw polynomial common roots at endpoint factors do not necessarily represent orbit collisions in the nonwrapping interval.

# 2. Formal two-lag resultant theorem

## 2.1 The necessary-condition theorem

Fix a,g. Define

```text
E_(a,g)
 = Res_X( N_a(X), N_g(X+a) ).                       (2.1)
```

If E_(a,g) is a nonzero integer and a regular r in F_p is counted by C_p(a,g), then

```text
p | E_(a,g).                                        (2.2)
```

This is the standard resultant criterion and is fully formal.

There are two caveats.

First, if

```text
E_(a,g)=0 in Z,
```

then the two polynomials share a characteristic-zero factor. Such structural pairs must be counted separately. Adjacent coprimality does not prove all-pair coprimality. The finite irreducibility certificates through small h do not settle this for D growing with p.

Second, E_(a,g) may contain endpoint factors that create mod-p common roots outside the regular orbit window. These give false positives for Q_D.

A completely safe reduction is therefore

```text
Q_D
 <= sum_(a+g<=D, E_(a,g)=0) C_p(a,g)
    + sum_(a+g<=D, E_(a,g)!=0, p|E_(a,g)) C_p(a,g). (2.3)
```

The first term is a characteristic-zero common-factor obligation. The second is the prime-divisibility obligation.

## 2.2 The support-only bound in the question is sufficient but not minimal

For a fixed pair,

```text
C_p(a,g)
 <= deg gcd_Fp(N_a(X),N_g(X+a))
 <= 3 min(a,g)
 <= 3D.                                             (2.4)
```

Therefore the crude implication

```text
Q_D <= 3D |B_D^sat(p)|                              (2.5)
```

is valid for a correctly saturated bad-pair set.

Hence

```text
|B_D^sat(p)| << N/D                                 (2.6)
```

would imply MESO-PAIR.

But (2.6) is stronger than necessary. The more natural support statement is dyadic and weighted:

```text
sum_((a,g) in B_D^sat(p)) min(a,g) << N.            (2.7)
```

The genuinely minimal quantity is not support at all; it is the common-root weight

```text
sum_(a+g<=D)
 deg gcd_Fp(N_a(X),N_g(X+a)).                        (2.8)
```

Even (2.8) is stronger than Q_D because it counts all F_p common roots, not only roots in the allowed nonwrapping time interval.

## 2.3 A p-adic valuation strengthening

Away from leading-coefficient degree drops, the Sylvester-matrix argument gives

```text
number of distinct F_p common roots
 <= deg gcd_Fp(f,g)
 <= v_p(Res(f,g)).                                   (2.9)
```

Thus a still stronger arithmetic interface is

```text
sum_(a+g<=D) v_p(E_(a,g)^sat) << N.                 (2.10)
```

Here `sat` means that the known endpoint and content factors have first been removed. Degree-drop rows must either be treated with subresultants or placed in a separate explicit stratum.

Statement (2.10) is useful as a precise p-adic target, but it is not a consequence of the archimedean height bound.

# 3. What the exact adjacent resultant actually says

The cleanest formula uses the restart normalization from `Q6496.md`.

Define

```text
K_0(X)=1,
K_1(X)=P(X),
K_(m+1)(X)=P(X+m)K_m(X)-(X+m)^6 K_(m-1)(X).         (3.1)
```

Then

```text
deg K_m=3m,
K_m(-m)=(-1)^m (m!)^3 b_m.                          (3.2)
```

Let

```text
A_m = Res_X(K_m,K_(m+1)).                            (3.3)
```

## Theorem 3.1: exact adjacent resultant

For every m>=0,

```text
A_m
 = (-1)^(m(m+1)/2)
   product_(j=1)^m ( (j!)^3 b_j )^6.                (3.4)
```

### Proof

Modulo K_m, recurrence (3.1) gives

```text
K_(m+1) = -(X+m)^6 K_(m-1).                         (3.5)
```

Consequently

```text
A_m
 = (-1)^m
   Res(K_m,X+m)^6
   Res(K_m,K_(m-1)).                                 (3.6)
```

The degree product `3m * 3(m-1)` is even, so reversing the last resultant introduces no sign. Also

```text
Res(K_m,X+m)=(-1)^(3m) K_m(-m)=(m!)^3 b_m.          (3.7)
```

Thus

```text
A_m=(-1)^m ((m!)^3b_m)^6 A_(m-1),
A_0=1,
```

which gives (3.4).

This rederives the qI adjacent-resultant formula without relying on any stripped display equation.

## 3.2 Exact renewal factorization of every same-base resultant

The banked renewal identity is

```text
K_(m+g+1)(X)
 = K_(m+1)(X) K_g(X+m+1)
   -(X+m+1)^6 K_m(X) K_(g-1)(X+m+2).                (3.8)
```

Taking the resultant with K_m and using multiplicativity gives the exact factorization

```text
Res_X(K_m,K_(m+g+1))
 = A_m * Res_X(K_m(X),K_g(X+m+1)).                  (3.9)
```

There is no missing leading-coefficient power: both second arguments in (3.8) have the same total degree.

In the positional gap gauge

```text
N_h(r)=K_(h-1)(r+1),
```

formula (3.9) becomes

```text
Res_X(N_h(X),N_k(X))
 = A_(h-1)
   * Res_X(N_h(X),N_(k-h)(X+h)).                    (3.10)
```

This is exactly the algebraic form of the sequential-chain identity (1.2).

# 4. Fatal pollution of the raw bad-pair set

Formula (3.10) answers the question about a recursive closure, but not in the hoped-for way.

Suppose

```text
p | b_j,

j < D < p.
```

Then (3.4) gives

```text
p | A_m for every m>=j.                              (4.1)
```

Hence (3.9) gives

```text
p | Res(K_m,K_k)

for every j<=m<k<=D.                                (4.2)
```

Thus one low zero produces about

```text
(D-j)(D-j+1)/2
```

raw bad pairs. This can be Theta(D^2).

The common root is explicit. The endpoint formula from `Q6496.md` gives, for m>=j,

```text
K_m(-j)
 = (-1)^j b_j b_(m-j)
   (j!)^3 ((m-j)!)^3.                               (4.3)
```

Thus X=-j is a common mod-p root of every K_m above level j. It is a cut-edge root. It lies on the singular clock divisor and is not a regular nonwrapping orbit collision.

## Minimal exact check

```text
b_3=1445=5*17^2.
```

Therefore for p=17 and every m>=3,

```text
17 | A_m.
```

For 3<=m<k<=8, all 15 same-base resultants are divisible by 17. The common root is X=-3 mod 17. This is a ten-line Sage or SymPy check, but it already follows symbolically from (3.4) and (4.3).

This proves:

```text
The raw set
  {(h,k): p | Res(N_h,N_k)}
can be quadratically large for a completely understood singular reason.
```

Therefore the proposed raw support target is not merely hard; it is the wrong statement.

## Correct cleanup

Let

```text
C_m(X)=product_(j=0)^m (X+j).
```

The regular two-block ideal is

```text
I_(m,g)^reg
 = ( K_m(X), K_g(X+m+1) )
   : ( C_m(X) C_g(X+m+1) )^infinity.                (4.4)
```

Since Z is a principal ideal domain, if

```text
I_(m,g)^reg intersect Z
```

is nonzero, let e_(m,g) be its positive generator. Apart from explicit content and degree-drop primes, a regular common root modulo p implies

```text
p | e_(m,g).                                        (4.5)
```

Equivalently, one may work with the rational transfer quantities

```text
D_h(X)=N_h(X)/product_j(X+j)^3
```

in the localized ring. This removes the same cut-edge factors. It does not by itself count the remaining intersections.

# 5. The height ledger and its true obstruction

Assume the supplied estimate

```text
log |e_(h,g)| << h g log(h+g)                        (5.1)
```

for every nonzero saturated eliminant.

Then for one fixed prime p,

```text
1_(p|e) <= v_p(e) <= log|e|/log p.                  (5.2)
```

Summing over the triangle h+g<=D gives

```text
# { (h,g): p|e_(h,g) }
 <= sum_(h+g<=D) v_p(e_(h,g))
 << D^4 log D / log p.                              (5.3)
```

The same bound holds for the total p-adic valuation.

At

```text
D=sqrt(N)L,

p asymp N,
```

this becomes

```text
D^4 logD/logp
 = O(N^2 L^4).                                      (5.4)
```

Compare the two possible targets:

```text
support-only target from J<=3D:
  N/D = sqrt(N)/L;

weighted valuation target:
  N.
```

The deficits are respectively

```text
N^(3/2)L^5
```

and

```text
N L^4.
```

So the missing input cannot be described as a small improvement to the height estimate. It must assert that one specified prime p cannot occupy more than a tiny share of the prime-factor budget of this entire deterministic family.

Archimedean height gives information after summing over prime divisors. It gives no pointwise restriction on one prime. A statement such as

```text
sum_(h+g<=D) v_p(e_(h,g)) << N                       (5.5)
```

is already a quenched large-sieve/nonconcentration theorem. It is a stronger arithmetic version of MESO-PAIR, not a consequence of known height technology.

# 6. Does the recurrence close the bad-pair grid?

## 6.1 Raw grid: yes, but only through pollution

Formula (3.9) says that every same-base resultant contains A_m. Hence a prime dividing A_m makes the entire row above m raw-bad.

This is a recursive/upward-closed set, but it is precisely the cut-edge triangle from Section 4. It must be divided out.

## 6.2 Regular shifted grid: no useful closure follows

Fix m and work in the quotient algebra

```text
A_m = Q[X]/(K_m(X)).
```

Put

```text
u_g = K_g(X+m+1) mod K_m.                            (6.1)
```

The pair `(u_g,u_(g-1))` satisfies a rank-2 recurrence over A_m. However A_m has Q-dimension 3m. The shifted resultant is, up to the leading-coefficient convention,

```text
Norm_(A_m/Q)(u_g).                                  (6.2)
```

If alpha_1,...,alpha_(3m) are the roots of K_m, then

```text
Res(K_m,K_g(X+m+1))
 = constant * product_i K_g(alpha_i+m+1).           (6.3)
```

A product of 3m rank-2 recurrence coordinates does not satisfy the same rank-2 recurrence. The natural tensor linearization grows with m; generically its dimension is exponential in m even in the constant-coefficient toy model. In the present nonautonomous model there is not even a fixed scalar recurrence in g with bounded-order coefficients.

Thus the continuant recurrence does not supply a bounded-complexity recurrence for the resultant grid.

## 6.3 Root repulsion, not propagation

At a regular root of K_m,

```text
K_(m+1) != 0.                                       (6.4)
```

Likewise, if K_k vanishes at the endpoint of a regular return, the neighboring continuant does not also vanish. Therefore a regular bad point `(m,k)` does not force `(m,k+1)` or `(m+1,k)` to be bad.

This is the opposite of a period-divisibility lattice. In an autonomous system, periods h and k may force a gcd or difference period at the same base point. Here the difference return occurs at the shifted clock `r+h`, not at r. The clock shift destroys Euclidean closure in the pair indices.

## 6.4 Consecutive resultant formulas control the wrong region

The exact adjacent formula controls g=1 and the thin region near the pair-grid axes. Casoratian rigidity already gives R_1=0. The h=2 splitting law and the finite irreducibility certificates similarly control only finitely many strips.

The hard contribution has both internal gaps large. Section 8 makes this precise.

# 7. Renewal and chain decomposition: what can actually be solved

## 7.1 Q_D is already the local T3 object

For each color v, list its occurrence times. Every unordered same-color triple whose diameter is at most D has a unique earliest point r and two positive return gaps at most D. Hence

```text
6 Q_D
 = number of ordered same-color triples
   whose maximum time minus minimum time is <=D.     (7.1)
```

For the full scale D=N-1,

```text
6 Q_(N-1)
 = T3
 = sum_v (m_v)_3.                                   (7.2)
```

Therefore "control chains of length at least three by a T3 object" does not add a new inequality. Q_D is the span-truncated T3 object.

## 7.2 Exact elementary relations

Let

```text
M_D=max_r d_D(r).
```

Then

```text
S_D <= N+Q_D,                                       (7.3)
```

because

```text
d <= 1_(d>0)+binom(d,2).
```

Also

```text
Q_D
 = sum_r d_D(r)(d_D(r)-1)/2
 <= (M_D-1)S_D/2.                                   (7.4)
```

Using the banked theorem

```text
M_D <= 4D^(2/3),                                    (7.5)
```

and the degree bound

```text
S_D <= (3/2)D^2,                                    (7.6)
```

recovers

```text
Q_D << D^(8/3).                                     (7.7)
```

Trying to combine (7.3) and (7.4) gives no bootstrap because M_D is larger than 1.

The Cauchy identity from Q6554 is

```text
S_D^2 <= N(S_D+2Q_D).                               (7.8)
```

It converts an upper bound for Q_D into an upper bound for S_D. It does not convert an upper bound for S_D into the desired upper bound for Q_D without using (7.4), which returns the current D^(8/3) scale.

## 7.3 Reindexing by the second edge

For fixed g,

```text
sum_(a<=D-g) C_p(a,g)
```

counts a gap-g collision ending a previous return chain. Since each chain maps injectively to its second edge,

```text
sum_a C_p(a,g)
 <= R_g * M_D^- ,                                   (7.9)
```

where M_D^- is the maximum number of backward returns in a D-window. Strong reflection gives

```text
M_D^- <= 4D^(2/3)+O(1).                             (7.10)
```

Similarly, for fixed a,

```text
sum_g C_p(a,g) <= R_a M_D.                          (7.11)
```

Summing (7.11) and using (7.6) is another derivation of (7.7). No independent term appears.

## 7.4 Higher chains do not close the system

Put

```text
H_D=sum_r binom(d_D(r),3).                          (7.12)
```

For d>=3,

```text
binom(d,2) <= 3 binom(d,3).
```

The d=2 bases contribute at most N, so

```text
Q_D <= N+3H_D.                                      (7.13)
```

Thus a linear bound for local four-point stars would prove MESO-PAIR. But this is a strictly higher-moment problem. A configuration with d_D(r)=2 at many disjoint bases has large Q_D and H_D=0. Renewal does not force a fourth return.

## 7.5 Relation with T3-2MINUS

Since

```text
Q_D <= T3/6,                                        (7.14)
```

an estimate

```text
T3 << N^(2-delta)
```

gives only

```text
Q_D << N^(2-delta).
```

It implies Q_D<<N only when delta>=1, far stronger than T3-2MINUS.

The value of T3-2MINUS is different: the interpolation lemma gives a direct energy improvement

```text
T3 << N^(2-delta)
 => Epi << N^(3/2-delta/2).                         (7.15)
```

So T3-2MINUS is a weaker route to improving the energy, even though it does not prove MESO-PAIR.

## 7.6 A conditional bridge from SAME-LAG-BDH

If one had the banked empirical statement as a theorem,

```text
sum_(h<=D) R_h^2 << D N^epsilon,                    (7.16)
```

then Cauchy would give

```text
S_D << D N^(epsilon/2).                             (7.17)
```

Combining with (7.4) and (7.5) gives

```text
Q_D << D^(5/3) N^epsilon.                           (7.18)
```

At D=sqrt(N)L with polylogarithmic L,

```text
D^(5/3)=N^(5/6)L^(5/3)=o(N).                        (7.19)
```

Thus SAME-LAG-BDH would prove MESO-PAIR comfortably. But SAME-LAG-BDH is itself a quenched family theorem; this is not an unconditional closure.

# 8. A new unconditional reduction: remove both axis strips

This is the one concrete advance obtained from the available tools.

Let

```text
Q_D^axis(G)
 = sum_(a+g<=D, min(a,g)<=G) C_p(a,g).               (8.1)
```

For a<=G, (7.11) gives

```text
sum_(a<=G) sum_g C_p(a,g)
 <= M_D sum_(a<=G) R_a
 <= 4D^(2/3) * (3/2)G^2
 <= 6D^(2/3)G^2.                                    (8.2)
```

The same bound for g<=G follows from (7.9)-(7.10). Therefore

```text
Q_D^axis(G)
 <= 12D^(2/3)G^2 + lower-order boundary terms.       (8.3)
```

Choose

```text
G
 = floor( sqrt( N/(24D^(2/3)) ) ).                 (8.4)
```

Then

```text
Q_D^axis(G) << N.                                   (8.5)
```

For

```text
D=sqrt(N)L,
```

this cutoff has size

```text
G asymp N^(1/3)L^(-1/3).                            (8.6)
```

Hence MESO-PAIR is reduced, up to an already controlled O(N) term, to

```text
Q_D^bal
 = sum_(G<a,g, a+g<=D) C_p(a,g).                    (8.7)
```

This is the balanced-pair core.

Consequences:

- R_1=0 lies inside the removed strip.
- The exact adjacent resultant lies inside the removed strip.
- The h=2 field Q(sqrt(-51)) lies inside the removed strip.
- Every fixed-small-h irreducibility certificate lies inside the removed strip.
- Any proof using only those inputs cannot touch the remaining asymptotic mass.

This is the sharpest formal version of the statement that the present algebraic tools control the axes but not the interior of the pair triangle.

# 9. The minimal fixed-p bad-pair statement

The exact regular target is

```text
[MESO-BALANCED-PAIR]

sum_(G<a,g, a+g<=D)
 rho_p(a,g)
 << N,                                               (9.1)

rho_p(a,g)
 = #{ r regular : N_a(r)=0 and N_g(r+a)=0 }.
```

By (1.3) and Section 8, this is equivalent to MESO-PAIR up to O(N).

A clean algebraic strengthening is

```text
[MESO-SHIFTED-GCD]

sum_(G<a,g, a+g<=D)
 deg gcd_Fp( N_a(X), N_g(X+a) )
 << N.                                               (9.2)
```

A p-adic strengthening is

```text
[MESO-SHIFTED-VALUATION]

sum_(G<a,g, a+g<=D)
 v_p(e_(a,g))
 << N.                                               (9.3)
```

The logical hierarchy is

```text
MESO-SHIFTED-VALUATION
  => MESO-SHIFTED-GCD
  => MESO-BALANCED-PAIR
  => MESO-PAIR
  => MESO-TOTAL
  => Epi << N^(3/2)/L + N.                           (9.4)
```

The first implication requires the usual degree-drop/content exceptions to be separated explicitly.

An unweighted support target such as

```text
|B_D^sat(p)| << N/D
```

is only one coarse sufficient condition. It is not the minimal statement, and the raw unsaturated version is false for the cut-edge reason in Section 4.

## Verdict on mathematical depth

Statement (9.1) is exactly a fixed-p, two-clock, growing-family incidence theorem. Statement (9.2) is its polynomial-gcd face. Statement (9.3) is its p-adic-resultant face.

No current banked theorem supplies a saving in the balanced region. Therefore MESO-PAIR has now been reduced to a clean interface, but not to easier existing technology. It should be placed in the single-point convergence map as another coordinate of the family-compatibility wall.

# 12. Direct answers to the three requested attacks

## (1) Can exact consecutive resultants make the bad-pair set recursively countable?

Only before saturation, and that recursion is useless.

The exact formulas are (3.4) and (3.9). They show that raw divisibility is upward-closed whenever p divides a low b_j. That closure is generated by singular endpoint roots. After those factors are removed, the remaining shifted resultant is the norm of a rank-2 recurrence over an algebra of dimension 3h. No bounded-order scalar recurrence or monotone closure of its zero set follows.

At a regular common root, neighboring continuants are nonzero, so the regular bad-pair set is locally repulsive rather than closed.

## (2) What does renewal plus chain decomposition solve?

It gives the exact identities (1.3), (7.1), and the unconditional axis-strip theorem (8.3).

It does not close Q_D because Q_D is already the local T3 count. A higher-chain count is a higher moment and can vanish on configurations with many isolated d_D=2 bases. The relations with S_D are one-way or circular at the current maximum-multiplicity scale.

The one useful conditional bridge is SAME-LAG-BDH, which would imply Q_D=o(N) through (7.18), but that is itself an unproved family theorem.

## (3) What is the minimal nontrivial fixed-p statement?

The minimal exact statement is (9.1), MESO-BALANCED-PAIR. The clean algebraic version is (9.2), MESO-SHIFTED-GCD. The p-adic version is (9.3), MESO-SHIFTED-VALUATION.

Yes: these are another face of the same family-compatibility theorem. The resultant language supplies a precise eliminant and a useful pollution factorization, but it does not reduce the pointwise growing-family quantifiers.

# 13. Final two questions

## (a) Least certain point

The least certain part is the completeness of the no-low-rank verdict for the saturated shifted resultants.

The exact formulas above rule out the naive rank-2 recurrence for the scalar resultants, and they show that the natural norm construction has state size growing with h. They do not prove that no hidden Plucker, bispectral, or mixed-crystal identity compresses the balanced family to fixed rank. Such an identity would overturn the current wall diagnosis.

All elementary identities, the pollution example, the height ledger, and the axis-strip reduction are independent of that uncertainty.

## (b) Likely shared blind spot

The most likely shared blind spot has two layers.

First, experiments may be measuring raw resultant divisibility, which is dominated by endpoint rays from low Apéry zeros. That can create apparent rows, triangles, and p-adic concentration having no relation to regular Q_D.

Second, after correct saturation, the family may admit a two-clock low-rank carrier not visible in the individual high-degree polynomials. The balanced shifted incidence

```text
N_a(r)=0,
N_g(r+a)=0
```

is the exact place to search for it. A fixed-rank carrier here would be a real breakthrough; absent such a carrier, MESO-SHIFTED-GCD is simply the family-compatibility wall in its cleanest algebraic coordinate.
