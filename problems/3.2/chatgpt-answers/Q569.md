# 11. Exact computation recipe

The following pseudocode computes the matrix reduction and provides regression checks.

```plain text
J = floor((n-3)/7)
P = product(primes p with n/4 < p <= n/3)

m[0,i] = L(n,i)

for d = 1..n:
    for i = 0..J:
        if max(0,J-d+1) <= i <= min(J,n-d):
            m[d,i] = (-1)^(J-i) * L(n,i+d)
                     * binom(i+d,i) * binom(d-1,J-i)
        else:
            m[d,i] = 0

    a[d] = m[d,0]

    for i = 1..J:
        assert (m[d,i] - a[d]*m[0,i]) % P == 0
        W[d,i] = (m[d,i] - a[d]*m[0,i]) // P

S = sum_i m[0,i]*F[i]
H[d] = sum_{i=1}^J W[d,i]*F[i]

Gamma = gcd(C[0],...,C[n])
assert Gamma == gcd(S, P*gcd(H[1],...,H[n]))
```

For every non-midpoint candidate prime p, also check

det(W[rows 1..J, cols 1..J]) mod p != 0,

Without one of those inputs, the exact Smith form retains the full linear candidate primorial and cannot prove \log\Gamma_n=o(n).
