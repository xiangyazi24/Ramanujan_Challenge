# Fixed numerator degree a=1: exact primitive lattice formula and the remaining lower-bound lemma

## Executive verdict

The primitive-integrality attack can be reduced completely to an exact one-dimensional lattice index. This removes the apparent Smith-normalization ambiguity.

Let

```plain text
A_s = sum_k binom(s,k)^2 binom(s+k,k)^2,

U_H = sum_(s=0)^H (-1)^s binom(H,s)/A_s,

L_H = lcm(A_0,...,A_H),

X_H = L_H U_H,
Y_H = L_H H(U_H-U_(H-1)).
```

Then X_H,Y_H are integers and the rational numerator direction is

```plain text
P_H^rat(x) = (Y_H-X_H x)/L_H.
```

Put

```plain text
h_H = gcd(X_H,Y_H),

z_H(x) = (Y_H-X_H x)/h_H.
```

Thus z_H(x) is a primitive integer linear polynomial. The exact primitive multiplier is

```plain text
m_H
 = lcm_(0<=s<=H)
     A_s / gcd(A_s,z_H(s)).
```

The primitive integral Padé numerator is exactly, up to a global sign,

```plain text
P_H^prim(x) = m_H z_H(x).
```

The denominator is the Newton interpolation of

```plain text
Q_H(s)=P_H^prim(s)/A_s,
```

and its Newton coefficients are integers. Moreover the total gcd of all coefficients of P_H^prim and Q_H is one. Hence no additional hidden Smith divisor remains.

Consequently, at the requested evaluation point

```plain text
n_H=3H+1,

|P_H^prim(n_H)|
 = m_H |Y_H-(3H+1)X_H|/h_H
 = m_H |z_H(3H+1)|.
```

Since z_H(3H+1) is an integer, the following precise lemma would close the fixed-a=1 route without any projective asymptotic:

```plain text
Primitive-index lemma.
There are constants c>0 and H_0 such that, for H>=H_0,

    Y_H != (3H+1)X_H

and

    lcm_(0<=s<=H)
      A_s/gcd(A_s,(Y_H-sX_H)/gcd(X_H,Y_H))
      >= exp(cH).
```

Under this lemma,

```plain text
|P_H^prim(3H+1)| >= exp(cH).
```

I do not know how to prove that index bound from presently established Apéry gcd results. It is substantially weaker and more exact than asking for a positive projective rate, but it is still a new cross-index gcd theorem. The same-sign root argument does prove the desired exponential lower bound on every index for which U_H and U_(H-1) have the same sign. The unresolved indices are precisely the sign-change indices, or more generally those for which the root lies to the right of 2H+1/2.

So the outcome is:

```plain text
a=1 is closed conditionally on one explicit primitive-index lemma;
all same-sign indices are already closed unconditionally;
the remaining gap is not Smith normalization but an Apéry-specific
lcm/gcd or sign-control theorem.
```

# 1. Exact rational direction

Write

```plain text
V_0(H)=sum_(s=0)^H (-1)^s binom(H,s)/A_s = U_H,

V_1(H)=sum_(s=0)^H (-1)^s binom(H,s)s/A_s.
```

The elementary identity

```plain text
s binom(H,s)=H binom(H-1,s-1)
```

gives

```plain text
V_1(H)=H(U_H-U_(H-1)).
```

Indeed,

```plain text
V_1(H)
 = H sum_(s=1)^H (-1)^s binom(H-1,s-1)/A_s
 = H(U_H-U_(H-1)).
```

For a linear numerator

```plain text
P(x)=a+bx,
```

the top Newton coefficient of P(s)/A_s is, up to the harmless sign (-1)^H,

```plain text
Delta^H(P(s)/A_s)|_(s=0)
 = a U_H+b H(U_H-U_(H-1)).
```

Therefore the one-dimensional rational kernel is generated by

```plain text
(a,b)
 = (H(U_H-U_(H-1)),-U_H).
```

After multiplying by L_H, this becomes the integral direction

```plain text
(Y_H,-X_H).
```

Removing its coefficient gcd gives the primitive integer direction

```plain text
(z_0,z_1)
 = (Y_H/h_H,-X_H/h_H),

gcd(z_0,z_1)=1.
```

Thus

```plain text
z_H(x)=z_0+z_1 x.
```

# 2. Newton integrality is equivalent to nodewise divisibility

Let

```plain text
q_s=P(s)/A_s,
0<=s<=H.
```

The Newton coefficient vector is

```plain text
c_k=Delta^k q_0,
0<=k<=H.
```

The transformation

```plain text
(c_0,...,c_H) -> (q_0,...,q_H)
```

is the lower-unitriangular Pascal matrix

```plain text
q_s=sum_(k=0)^s binom(s,k)c_k.
```

Its inverse is also integral:

```plain text
c_k=sum_(s=0)^k (-1)^(k-s)binom(k,s)q_s.
```

Hence

```plain text
all Newton coefficients c_k are integers
iff
all node values q_s are integers.
```

For the a=1 direction the top coefficient is zero by construction, so c_H=0 and the denominator degree is at most H-1. Therefore an integer multiple m z_H(x) gives an integral Padé pair exactly when

```plain text
A_s | m z_H(s)
for every 0<=s<=H.
```

This is the key simplification: primitive denominator integrality is a one-dimensional system of elementary congruences.

# 3. Exact primitive multiplier

For one fixed s, the least positive integer m satisfying

```plain text
A_s | m z_H(s)
```

is

```plain text
A_s/gcd(A_s,z_H(s)).
```

Satisfying all nodes simultaneously therefore requires and is implied by

```plain text
m multiple of
lcm_(0<=s<=H) A_s/gcd(A_s,z_H(s)).
```

Thus the least positive admissible multiplier is exactly

```plain text
m_H
 = lcm_(0<=s<=H)
     A_s/gcd(A_s,z_H(s)).
```

This proves

```plain text
P_H^prim(x)=m_H z_H(x)
```

up to sign, provided the full pair is primitive. That final assertion is automatic from minimality.

Suppose a prime ell divided every coefficient of P_H^prim and every Newton coefficient of Q_H. Then division by ell would leave an integer linear numerator and an integer Newton denominator. Equivalently,

```plain text
A_s | (m_H/ell) z_H(s)
for all s.
```

This contradicts the minimality of m_H. Hence the total coefficient gcd is one.

This is the exact primitive-integrality theorem. It does not use asymptotics, total positivity, or a guessed Smith factor.

# 4. Formula in terms of the original common-denominator clearing

The implementation at commit cd41433 first forms all rational coefficients, takes their denominator lcm, and then divides the gcd of the resulting integers. The preceding formula is exactly equivalent to that procedure.

Let

```plain text
D_H
 = lcm(
     den(X_H/L_H),
     den(Y_H/L_H),
     den((Y_H-sX_H)/(L_H A_s)) for 0<=s<=H-1
   ).
```

Equivalently,

```plain text
D_H
 = lcm(
     L_H/gcd(L_H,X_H),
     L_H/gcd(L_H,Y_H),
     L_H A_s/gcd(L_H A_s,Y_H-sX_H)
       for 0<=s<=H-1
   ).
```

After multiplication by D_H, the integer node values are

```plain text
w_s=D_H(Y_H-sX_H)/(L_H A_s).
```

Because the Pascal value-to-Newton map is unimodular, the gcd of the Newton coefficients equals

```plain text
gcd(w_0,...,w_(H-1)).
```

Hence the total clearing gcd is

```plain text
g_H
 = gcd(
     D_H X_H/L_H,
     D_H Y_H/L_H,
     w_0,...,w_(H-1)
   ).
```

The primitive scaling of the rational pair is

```plain text
D_H/g_H.
```

The identity with the one-dimensional formula is

```plain text
(D_H/g_H) * (Y_H-X_H x)/L_H
 = m_H * (Y_H-X_H x)/h_H.
```

Thus

```plain text
D_H h_H = g_H L_H m_H.
```

This equality is an exact audit relation between the direct denominator-clearing implementation and the primitive lattice index.

# 5. Local prime formula

For each prime ell, put

```plain text
e_s=v_ell(A_s),

r_s=v_ell(z_H(s)).
```

Then

```plain text
v_ell(m_H)
 = max_(0<=s<=H) max(0,e_s-r_s).
```

Equivalently, in terms of X_H,Y_H,h_H,

```plain text
v_ell(m_H)
 = max_(0<=s<=H)
     max(0,
         v_ell(A_s)
         -v_ell(Y_H-sX_H)
         +v_ell(h_H)).
```

Therefore

```plain text
log m_H
 = sum_ell log(ell)
     max_s max(0,
       v_ell(A_s)-v_ell(Y_H-sX_H)+v_ell(h_H)).
```

This is the exact local-gcd ledger. Any proposed lower bound must control this sum. In particular, it is not valid to replace m_H by lcm(A_0,...,A_H) without controlling the local gcds gcd(A_s,z_H(s)).

The only unconditional general inequality of this form is

```plain text
1 <= m_H <= lcm(A_0,...,A_H).
```

The upper bound is immediate. A lower bound such as

```plain text
m_H >= lcm(A_0,...,A_H)^(1-o(1))
```

or even

```plain text
m_H >= exp(cH)
```

requires new information about those local gcds. It does not follow from P-recursiveness.

# 6. Exact two-dimensional congruence-lattice index

There is a related exact formula that clarifies what an lcm theorem would need to prove.

Define

```plain text
Lambda_H
 = {(a,b) in Z^2:
      A_s | a+s b for every 0<=s<=H}.
```

For a prime ell, put

```plain text
E_ell=max_s v_ell(A_s).
```

Choose an index r_ell with

```plain text
v_ell(A_(r_ell))=E_ell.
```

Set

```plain text
F_ell
 = max_(0<=s<=H)
     max(0,v_ell(A_s)-v_ell(s-r_ell)),
```

with v_ell(0)=+infinity, so the s=r_ell term contributes zero.

In the local coordinates

```plain text
a'=a+r_ell b,
```

the congruence at r_ell gives

```plain text
a' in ell^(E_ell) Z_ell.
```

For any other s, the term a' is already divisible by ell^(v_ell(A_s)), because E_ell is maximal. The remaining condition is

```plain text
(s-r_ell)b in ell^(v_ell(A_s)) Z_ell.
```

Hence

```plain text
Lambda_H tensor Z_ell
 = ell^(E_ell) Z_ell
   x ell^(F_ell) Z_ell
```

in the coordinates (a',b). Consequently

```plain text
[Z^2:Lambda_H]
 = product_ell ell^(E_ell+F_ell).
```

Since

```plain text
product_ell ell^(E_ell)=lcm(A_0,...,A_H),
```

we obtain the exact factorization

```plain text
[Z^2:Lambda_H]
 = lcm(A_0,...,A_H)
   * product_ell ell^(F_ell).
```

This is a genuine lcm/index theorem, but it does not by itself lower-bound the particular primitive vector on the Padé line. A rank-two lattice may contain a short vector even when its determinant is large. The one-dimensional order m_H is the necessary refinement.

For completeness, the ideal of all evaluations at an integer n is also explicit. In the same local coordinates,

```plain text
a+n b = a'+(n-r_ell)b.
```

Therefore

```plain text
gcd{a+n b:(a,b) in Lambda_H}
 = product_ell ell^(delta_ell(n)),
```

where

```plain text
delta_ell(n)
 = min(E_ell,F_ell+v_ell(n-r_ell)).
```

This formula shows exactly why generic lcm growth is insufficient. A prime power that occurs at only one node contributes to every evaluation only when the evaluation point is congruent to that node to adequate ell-adic order. For n=3H+1, those are precisely moving linear congruences of the same type as the original Problem 3.2 obstruction.

# 7. Same-sign indices are closed unconditionally

The rational root is

```plain text
x_H
 = Y_H/X_H
 = H(1-U_(H-1)/U_H),
```

provided U_H!=0.

Assume

```plain text
U_H U_(H-1)>0.
```

Then

```plain text
U_(H-1)/U_H>0,
```

and therefore

```plain text
x_H<=H.
```

Let

```plain text
P(x)=P_H^prim(x).
```

Because its denominator has integral Newton coefficients,

```plain text
A_s | P(s)
for every 0<=s<=H.
```

Take s=H-1. If P(H-1)!=0, then

```plain text
|P(H-1)|>=A_(H-1).
```

For every real x_H<=H,

```plain text
|3H+1-x_H| >= |H-1-x_H|.
```

Indeed, if x_H<=H-1 both quantities are nonnegative and the first is larger; if H-1<x_H<=H, the right side is at most one while the left side is at least 2H+1.

Since a nonzero linear polynomial is proportional to x-x_H, this gives

```plain text
|P(3H+1)|>=|P(H-1)|>=A_(H-1).
```

If instead

```plain text
P(H-1)=0,
```

then the root is exactly H-1. Writing

```plain text
P(x)=b(x-(H-1)),
```

we have

```plain text
P(H)=b.
```

Since A_H|P(H), either b=0, which is impossible, or

```plain text
|b|>=A_H.
```

Thus

```plain text
|P(3H+1)|=(2H+2)|b|>A_H.
```

Hence in all same-sign cases,

```plain text
|P_H^prim(3H+1)|>=A_(H-1).
```

No projective lower bound was used.

# 8. Explicit exponential constant

The single k=s summand in the Apéry number gives

```plain text
A_s>=binom(2s,s)^2.
```

The elementary central-binomial bound

```plain text
binom(2s,s)>=4^s/(2s+1)
```

follows because the largest of the 2s+1 binomial coefficients in

```plain text
sum_(k=0)^(2s) binom(2s,k)=4^s
```

is the central one. Therefore

```plain text
A_s>=16^s/(2s+1)^2.
```

For every same-sign index H>=2,

```plain text
|P_H^prim(3H+1)|
 >= A_(H-1)
 >= 16^(H-1)/(2H-1)^2.
```

Equivalently,

```plain text
log |P_H^prim(3H+1)|
 >= 4(H-1)log 2-2log(2H-1).
```

Since n_H=3H+1,

```plain text
liminf
  log |P_H^prim(n_H)|/n_H
 >= (4/3)log 2
```

along the same-sign subsequence. This is a fully unconditional positive exponential rate on that subsequence.

# 9. Sign-change indices

If

```plain text
U_H U_(H-1)<0,
```

then

```plain text
x_H>H.
```

A modest strengthening still closes the index. If

```plain text
|U_(H-1)|<=|U_H|,
```

then

```plain text
x_H
 = H(1+|U_(H-1)|/|U_H|)
 <=2H.
```

For every x_H<=2H,

```plain text
|3H+1-x_H|>=|H-x_H|.
```

Therefore, if P(H)!=0,

```plain text
|P(3H+1)|>=|P(H)|>=A_H.
```

The root case P(H)=0 is handled as before using P(H-1).

Thus the following sign lemma is sufficient:

```plain text
Sign-transition lemma.
For all sufficiently large H with
U_H U_(H-1)<0,

    |U_(H-1)|<=|U_H|.
```

Under it, every large sign-change index also has

```plain text
|P_H^prim(3H+1)|>=A_H.
```

I do not know an unconditional proof of this monotonicity-at-sign-change statement. Nor does it follow merely from the Apéry recurrence, because U_H is a high alternating reciprocal moment rather than a solution of the original second-order recurrence.

The exact geometric threshold is slightly weaker. The node interval [0,H] can control the value at 3H+1 whenever

```plain text
x_H<=2H+1/2.
```

Indeed, 2H+1/2 is the midpoint of H and 3H+1. Thus the weakest root-location statement of this type is

```plain text
H(1-U_(H-1)/U_H)<=2H+1/2.
```

At an opposite-sign index this is equivalent to

```plain text
|U_(H-1)|/|U_H|<=1+1/(2H).
```

Any uniform proof of that inequality closes the sign-change branch by the same node-divisibility argument.

# 10. Why the Apéry recurrence and Casoratian do not yet prove the index bound

The recurrence

```plain text
(s+1)^3 A_(s+1)
 =(34s^3+51s^2+27s+5)A_s-s^3 A_(s-1)
```

implies strong restrictions on consecutive common zeros modulo primes exceeding the relevant indices. In particular, two consecutive Apéry values cannot both vanish modulo such a prime unless the initial value also vanishes.

This controls

```plain text
gcd(A_s,A_(s+1))
```

at large primes. It does not control

```plain text
gcd(A_s,z_H(s)),
```

because z_H(s) is built globally from all reciprocal values 1/A_t. It is not another fixed Apéry solution and is not known to satisfy a second-order recurrence in s with coefficients independent of H.

Likewise, Lucas congruences describe

```plain text
A_(qp+r) mod p
```

in terms of lower digits. They do not give a cross-index bound for the numerator

```plain text
Y_H-sX_H.
```

The local formula for m_H shows exactly what would be required: for enough prime powers occurring in the Apéry values, the same prime powers must fail to divide the specialized global reciprocal moment Y_H-sX_H after the common factor h_H is removed.

No published common-divisor theorem for P-recursive sequences currently supplies this statement.

# 11. Audited lcm claims

The following statements are valid:

```plain text
L_H=lcm(A_0,...,A_H)>=A_H.
```

Therefore, using the elementary Apéry lower bound,

```plain text
L_H>=16^H/(2H+1)^2.
```

Also

```plain text
[Z^2:Lambda_H]>=L_H.
```

The following inference is invalid without an extra gcd estimate:

```plain text
L_H exponential
therefore
m_H exponential.
```

The quotient between them is exactly controlled by the nodewise gcds:

```plain text
m_H
 = lcm_s A_s/gcd(A_s,z_H(s)).
```

It is logically possible for every large prime-power component of A_s to be absorbed by z_H(s), even while L_H is huge. Ruling that out is the entire remaining primitive-integrality problem.

Likewise, a large determinant

```plain text
[Z^2:Lambda_H]
```

does not force every one-dimensional rational section of Lambda_H to have a large primitive generator. The exact order of the Padé direction in Z^2/Lambda_H is m_H; that is the quantity that must be bounded.

# 12. Weakest precise new lemma

The cleanest single missing theorem is the following.

```plain text
Apéry reciprocal-line index lemma.

Let

L_H=lcm(A_0,...,A_H),
X_H=L_H U_H,
Y_H=L_H H(U_H-U_(H-1)),
h_H=gcd(X_H,Y_H).

There exist absolute constants c>0 and H_0 such that,
for every H>=H_0,

(1) Y_H-(3H+1)X_H != 0,

and

(2) log lcm_(0<=s<=H)
        A_s/gcd(A_s,(Y_H-sX_H)/h_H)
    >= cH.
```

This lemma implies immediately

```plain text
|P_H^prim(3H+1)|
 = m_H |(Y_H-(3H+1)X_H)/h_H|
 >= exp(cH).
```

It is weaker than a positive projective asymptotic in three ways:

```plain text
- it asks only for an integral index, not a limit;
- it permits arbitrary oscillation of U_H;
- it permits the projectively normalized value to be exponentially small,
  provided primitive clearing contributes exp(cH).
```

A still more targeted version, sufficient together with the already proved same-sign branch, is:

```plain text
For every sufficiently large H with U_H U_(H-1)<0,

Y_H!=(3H+1)X_H

and

log m_H>=cH.
```

This is the weakest faithful lcm/gcd target isolated by the primitive analysis.

# 13. Final conclusion

The primitive normalization can be computed exactly and does not require projective asymptotics:

```plain text
h_H=gcd(X_H,Y_H),

z_H(x)=(Y_H-X_Hx)/h_H,

m_H=lcm_s A_s/gcd(A_s,z_H(s)),

P_H^prim(x)=m_H z_H(x).
```

The exact evaluation is

```plain text
|P_H^prim(3H+1)|=m_H|z_H(3H+1)|.
```

Every same-sign index is already unconditionally exponential:

```plain text
U_H U_(H-1)>0
implies
|P_H^prim(3H+1)|
 >= A_(H-1)
 >= 16^(H-1)/(2H-1)^2.
```

The same holds at an opposite-sign index whenever

```plain text
|U_(H-1)|/|U_H|<=1+1/(2H).
```

For the remaining sign-change indices, the exact new requirement is an exponential lower bound on the order of the primitive direction in the congruence lattice, namely m_H, together with nonvanishing at 3H+1. Current Apéry recurrence, Casoratian, Lucas, and generic P-recursive gcd results do not prove that bound.

Accordingly, fixed numerator degree a=1 is not fully closed, but the gap is now reduced to one explicit, local-prime lcm/gcd lemma. Primitive integrality is completely audited; no untracked clearing or Smith factor remains.
