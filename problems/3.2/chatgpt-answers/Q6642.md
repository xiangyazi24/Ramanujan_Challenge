```text
(1) Harmonic-sum step

Claim:
    sum_{d <= H} d/d^2 <= 1 + log H.

Verification:
    Since d/d^2 = 1/d, the left side is

        sum_{d=1}^H 1/d.

    For H >= 1, use the standard integral comparison:

        1 + sum_{d=2}^H 1/d
        <= 1 + integral_{1}^{H} (1/x) dx.

    Therefore

        sum_{d=1}^H 1/d
        <= 1 + log H.

    This is exactly the harmonic bound used in the clique-energy
    estimate.
```

```text
(2) Double-Cauchy chain

Assume:
    g_1,...,g_k > 0
    sum_i g_i <= H.

Need to prove:

    sum_i 1/g_i^2 >= (sum_i 1/g_i)^2 / k >= k^3/H^2.

First inequality:

Apply Cauchy-Schwarz to the sequences

    a_i = 1/g_i
    b_i = 1.

Then

    (sum_i a_i b_i)^2 <= (sum_i a_i^2)(sum_i b_i^2).

Hence

    (sum_i 1/g_i)^2
    <= (sum_i 1/g_i^2) * k.

Rearranging gives

    sum_i 1/g_i^2 >= (sum_i 1/g_i)^2/k.

Second inequality:

Apply Cauchy-Schwarz again:

    (sum_i g_i)(sum_i 1/g_i) >= (sum_i 1)^2 = k^2.

Therefore

    sum_i 1/g_i >= k^2/(sum_i g_i).

Because

    sum_i g_i <= H,

we get

    sum_i 1/g_i >= k^2/H.

Squaring:

    (sum_i 1/g_i)^2 >= k^4/H^2.

Substitute into the first inequality:

    sum_i 1/g_i^2
    >= (k^4/H^2)/k
    = k^3/H^2.

Edge case k=1:

    sum_i g_i = g_1 <= H.

The claimed inequality becomes

    1/g_1^2 >= 1/H^2.

This is true because

    g_1 <= H  =>  1/g_1 >= 1/H.

So the chain also holds for k=1.
```

```text
(3) Ceiling inequality

Claim:
    For m >= 4,

        ceil(m/2) - 1 >= m/4.

Check small cases:

m = 4:
    ceil(2) - 1 = 1
    m/4 = 1
    equality holds.

m = 5:
    ceil(2.5) - 1 = 3 - 1 = 2
    m/4 = 1.25
    true.

m = 6:
    ceil(3) - 1 = 2
    m/4 = 1.5
    true.

m = 7:
    ceil(3.5) - 1 = 4 - 1 = 3
    m/4 = 1.75
    true.

General proof:

Case 1: m is even.

Write

    m = 2n.

Then

    ceil(m/2) - 1
    = n - 1.

Need:

    n - 1 >= 2n/4 = n/2.

This is equivalent to

    n/2 >= 1,

which holds because m >= 4 implies n >= 2.

Case 2: m is odd.

Write

    m = 2n + 1.

Then

    ceil(m/2) - 1
    = (n+1) - 1
    = n.

Need:

    n >= (2n+1)/4.

Multiplying by 4:

    4n >= 2n + 1,

equivalent to

    2n >= 1,

which holds for all positive n.

Therefore for every m >= 4,

    ceil(m/2) - 1 >= m/4.
```
