## 0. 总裁决

(8.7) 可以完整写成一个保留真实时间顺序的有限维算子，但写完以后会出现一个重要修正：

1. `pi(n)=[b_n:c_n]` **本身不是**由单步 Möbius 映射 `F_u` 推进的一阶轨道。单个解的 Riccati 状态 `[y_n:y_{n-1}]` 才是。对 `pi`，正确的一阶状态是 fundamental frame
   
   \[
   \Gamma_n=
   \begin{pmatrix}b_n&c_n\\ b_{n-1}&c_{n-1}\end{pmatrix}\in\mathrm{GL}_2(\mathbf F_p),
   \]
   
   或者等价地，时钟与 `PGL_2/B` 上的 cocycle。
2. 精确保序的 skew-product 是一个**确定性置换**（非回绕版本是部分移位）。因此：
   - 循环化 Koopman 算子是酉算子，任意非零不变子空间的谱半径都是 `1`；
   - 非回绕算子是幂零的，谱半径 `0`，但这个“谱隙”完全是边界造成的，resolvent 范数仍随区间长度增长；
   - 所以普通意义的
     
     \[
     r(T_k)\le1-c\qquad(k\ne0)
     \]
     
     **不是本题可成立的最小引理**。
3. 时钟 Fourier 字符也不形成不变分块。由于矩阵 `M_u` 随 `u` 变化，单步算子会把一个 clock mode 泄漏到所有 mode。真正的有序对象是
   
   \[
   \mathcal T_q^{(h)}
   =\frac1L\sum_u e_L(qu)\,\rho(A_{u+h-1}\cdots A_u),
   \]
   
   而且一般
   
   \[
   \mathcal T_q^{(h)}\ne(\mathcal T_q^{(1)})^h.
   \]
4. Q6515 中 `A_p(k)` 的 `k` 是**lag Fourier 频率**；上式的 `q` 是**起点时钟频率**。这两者不能混同。`A_p(k)` 是完整 skew Koopman 的谱测度/Dirichlet 多项式矩阵元，不是某个单步 `T_k` 的特征值。
5. 正确的最小算子命题是**特殊观测向量的 Fejér 平方函数界**，或等价的**局部谱质量平坦化**，不是全算子谱隙。一个干净的充分命题是：对所有长度至少 `p/H` 的频率弧 `J`，
   
   \[
   \frac1p\sum_{k\in J}A_p(k)
   \le \frac{N|J|}{p}+C_\varepsilon p^\varepsilon.
   \tag{LSF}
   \]
   
   它通过 Fejér 核的 dyadic majorant 直接推出 `[GAP-TIME-FEJER]`。
6. 无条件方面：
   - `R_1=0` 精确成立，但只给谱的一个 Fourier 矩，不能控制任何频带；
   - 固定-gap 次数界给 `sum_{h<=H}R_h=O(H^2)`，所以 `[GAP-TIME-FEJER]` 只在 `H=p^{o(1)}`（例如任意固定 polylog）范围免费成立；
   - 镜像可精确剥离 `1_{2|h}`，只省常数，不给幂次；
   - 仓库最新版本已经无条件证明 `E^pi(p) << p^{3/2}`（当前 LaTeX 的修正常数为 `2 sqrt(3)`），所以 `[GAP-TIME-FEJER]` 若只经能量指数机器兑现，仍落在 `sigma=1`、`p^{3/2}` 这一档。它真正的新价值是首返回：取 `H=sqrt(p)` 会给 `|Z_p|<<p^{1/2+epsilon}`。

因此本轮的结论不是“(8.7) 死亡”，而是更精确的改靶：

> **普通 Koopman 谱隙路线死亡；保序 clock 构造仍然有价值，但应攻击特殊 Borel/Steinberg 观测的局部谱质量 `(LSF)`、Fejér 平方函数或标量 resolvent，而不是全空间谱半径。**

# 2. 为什么 `pi(n)` 不能直接作为一阶 fiber

定义 fundamental frame

\[
\Gamma_u=
\begin{pmatrix}
b_u&c_u\\
b_{u-1}&c_{u-1}
\end{pmatrix}.
\tag{2.1}
\]

Casoratian 给

\[
\det\Gamma_u=b_uc_{u-1}-b_{u-1}c_u=-u^{-3}\ne0
\tag{2.2}
\]

（在 regular block 上），并且

\[
\Gamma_{u+1}=A_u\Gamma_u.
\tag{2.3}
\]

`pi(u)=[b_u:c_u]` 是 `Gamma_u` 第一行的射影类。递推的下一行是当前行与前一行的线性组合，所以只知道 `pi(u)` 并不足以推进；需要 `Gamma_u`，或至少需要连续两行及其相对尺度。

这也给出最干净的碰撞判据。令

\[
A_{r,h}=A_{r+h-1}\cdots A_r.
\tag{2.4}
\]

则

\[
\Gamma_{r+h}=A_{r,h}\Gamma_r.
\]

因为 `Gamma_r` 可逆，

\[
\begin{aligned}
\pi(r+h)=\pi(r)
&\Longleftrightarrow
[e_1^TA_{r,h}\Gamma_r]=[e_1^T\Gamma_r]\\
&\Longleftrightarrow
[e_1^TA_{r,h}]=[e_1^T]\\
&\Longleftrightarrow
(A_{r,h})_{12}=0.
\end{aligned}
\tag{2.5}
\]

令

\[
B=\{g\in\mathrm{PGL}_2(\mathbf F_p):g_{12}=0\}.
\tag{2.6}
\]

这是稳定行 `[1:0]` 的 Borel 子群，于是

\[
\boxed{\pi(r)=\pi(r+h)\Longleftrightarrow [A_{r,h}]\in B.}
\tag{2.7}
\]

这是 clock transfer 构造的正确入口。

同一事实在 restart gauge 中写成：设 `s=r+1,m=h-1`，

\[
G_m(s)=M_{s+m-1}\cdots M_s.
\]

仓库已证

\[
N_h(r)=U_{h-1}(r+1),
\]

且

\[
\pi(r)=\pi(r+h)
\Longleftrightarrow
G_{h-1}(r+1)(0)=\infty.
\tag{2.8}
\]

所以有两个等价的最小 fiber 模型：

- **frame/Borel 模型**：`PGL_2/B ~= P^1` 上的 return `x_0 -> x_0`；
- **restart 模型**：`P^1` 上的 transition `0 -> infinity`。

直接把 `pi(n)` 当成 `F_u` 的 orbit 会把这两个模型混在一起。

# 3. 精确保序的 skew-product/Koopman 算子

## 3.1 状态空间

取

\[
\mathcal X_p=I_p\times X,
\qquad
X=\mathrm{PGL}_2(\mathbf F_p)/B\simeq\mathbf P^1(\mathbf F_p),
\tag{3.1}
\]

基点为 `x_0=B`。对 `1<=u<=p-3` 定义部分 skew map

\[
\mathsf S(u,x)=(u+1,[A_u]x).
\tag{3.2}
\]

它保留了真实顺序

\[
u,u+1,\ldots,u+h-1.
\]

对应 Koopman pullback 在

\[
\mathscr H_p=\ell^2(I_p\times X)
\]

上为

\[
(\mathscr Uf)(u,x)=
\begin{cases}
f(u+1,[A_u]x),&u\le p-3,\\
0,&u=p-2.
\end{cases}
\tag{3.3}
\]

于是

\[
(\mathscr U^hf)(u,x)
=\mathbf1_{u+h\le p-2}\,
 f(u+h,[A_{u,h}]x).
\tag{3.4}
\]

令

\[
f_0(u,x)=\mathbf1_{x=x_0}.
\]

由 (2.7)，精确地

\[
\boxed{
R_h=\langle f_0,\mathscr U^hf_0\rangle
}
\tag{3.5}
\]

（内积取 counting measure，并采用 nonwrapping `r` 范围）。

若中心化

\[
\phi_0(x)=\mathbf1_{x=x_0}-\frac1{p+1},
\qquad
f_\circ(u,x)=\phi_0(x),
\]

则

\[
\langle f_\circ,\mathscr U^hf_\circ\rangle
=R_h-\frac{L-h}{p+1}.
\tag{3.6}
\]

这把均匀 Borel 命中基准剥离出来；镜像强制项仍需另行剥离。

## 3.2 矩阵元

把 (3.2) 看成状态转移矩阵，点态矩阵元是

\[
\mathsf S_{(u,x),(v,y)}
=\mathbf1_{v=u+1}\mathbf1_{y=[A_u]x}.
\tag{3.7}
\]

`h` 步矩阵元为

\[
(\mathsf S^h)_{(u,x),(v,y)}
=\mathbf1_{v=u+h}\mathbf1_{y=[A_{u,h}]x}.
\tag{3.8}
\]

这就是“真实顺序不可打乱”的最直接有限矩阵实现。

restart gauge 的同类构造把 `[A_u]` 换成 `[M_u]`，并把 (3.5) 换成 source-target 矩阵元

\[
R_h=
\sum_r
\langle\delta_\infty,
\rho(M_{r+h-1}\cdots M_{r+1})\delta_0\rangle.
\tag{3.9}
\]

# 4. clock Fourier 后真正得到什么

令

\[
e_j(u)=L^{-1/2}e_L(ju),\qquad j\in\mathbf Z/L\mathbf Z,
\]

并令 `P_j` 是 clock 方向到 `e_j` 的投影。把边界用指标 `u<=L-h` 保留，定义有序 `h` 步 twisted block

\[
\boxed{
\mathcal T_q^{(h)}
=\frac1L\sum_{u=1}^{L-h}e_L(qu)\,K(A_{u,h}),
}
\tag{4.1}
\]

其中

\[
[K(g)\varphi](x)=\varphi(gx).
\]

其 fiber 矩阵元为

\[
\boxed{
[\mathcal T_q^{(h)}]_{x,y}
=\frac1L\sum_{u=1}^{L-h}
 e_L(qu)\mathbf1_{y=[A_{u,h}]x}.
}
\tag{4.2}
\]

直接代入 (3.4) 得

\[
P_{j'}\mathscr U^hP_j
=e_L(jh)\,\mathcal T_{j-j'}^{(h)}
\tag{4.3}
\]

（右端理解为对应的 fiber block，并保留 boundary cutoff）。

这里有三个关键结论。

### 4.1 clock modes 不封闭

一般

\[
P_{j'}\mathscr UP_j\ne0
\qquad(j'\ne j),
\]

因为 `u -> K(A_u)` 有非零 clock Fourier 系数。只有 `A_u` 与 `u` 无关时，clock character 才真正分块。

### 4.2 `h` 步 block 不是一步 block 的幂

\[
\mathcal T_q^{(2)}
=\frac1L\sum_u e_L(qu)K(A_{u+1}A_u),
\]

而

\[
(\mathcal T_q^{(1)})^2
=\frac1{L^2}\sum_{u,v}e_L(q(u+v))K(A_vA_u),
\]

后者把所有非连续 `(u,v)` 路径也平均进去。因此

\[
\boxed{\mathcal T_q^{(h)}\ne(\mathcal T_q^{(1)})^h}
\]

是结构事实，不是技术误差。

### 4.3 Q6515 的 `k` 不是这里的 `q`

- `q` 是 starting-clock 变量 `u` 的 Fourier 频率；
- (8.4) 中的 `k` 是 lag `h` 的 Fourier 频率。

后者满足

\[
\sum_h e_p(-kh)R_h
=\sum_h e_p(-kh)\langle f_0,\mathscr U^hf_0\rangle,
\tag{4.4}
\]

所以它是完整 `mathscr U` 的 Dirichlet/resolvent 矩阵元。它不是 `mathcal T_k^{(1)}` 的谱。

这一步是本题最重要的记号修正。

# 5. 为什么普通“统一谱隙”不可能

## 5.1 非回绕模型：谱半径 `0` 但没有混合信息

(3.3) 是有限链上的部分移位，所以

\[
\mathscr U^L=0,
\qquad r(\mathscr U)=0.
\]

然而这只表示所有路径最终撞到右边界。即便最简单的单边 shift，

\[
(I-\mathscr U)^{-1}=I+\mathscr U+\cdots+\mathscr U^{L-1}
\]

的范数随 `L` 增长；谱半径 `0` 并不产生任何短时相关衰减。因此在部分算子上要求 `r<1-c` 是空洞的。

## 5.2 循环完成：算子酉，谱半径必为 `1`

若为做谱论而添加一个可逆 boundary matrix，把 clock 循环化，则

\[
(u,x)\mapsto(u+1,A_ux)
\]

是有限集合的置换。对应 Koopman 算子是酉矩阵。每个 `A_u` 都保持 fiber 常数及 fiber mean-zero 子空间，因此在非平凡 centered 子空间上仍有

\[
r(\mathscr U)=1.
\]

更强地，设循环长度为 `L`，一圈 monodromy 为

\[
\mathcal M=A_{L}\cdots A_1.
\]

在一个 clock 截面上，`mathscr U^L` 等于 `rho(mathcal M)`。若 `lambda` 是后者任一特征值，则 `mathscr U` 含所有满足

\[
z^L=\lambda
\]

的根；其中必有一个离 `1` 的角距离 `O(1/L)`。所以即使没有精确特征值 `1`，也不可能有与 `p` 无关的 angular gap 或 resolvent 界。

把算子乘以 `e_p(k)` 只旋转这些根；对每个 `k`，仍有根在 `O(1/L)` 内靠近 `1`。因此

\[
\|(I-e_p(k)\mathscr U)^{-1}\|=O(1)
\]

不能对全部 `k\ne0` 成立。

## 5.3 为什么现有 expander / time-inhomogeneous random-walk 定理不救场

Bourgain--Gamburd 的固定生成元扩张定理处理的是由一个**概率测度**反复卷积产生的随机游走，而不是每步一个确定 Dirac 矩阵的单路径：

- J. Bourgain and A. Gamburd, [*Uniform expansion bounds for Cayley graphs of SL_2(F_p)*](https://doi.org/10.4007/annals.2008.167.625), Ann. of Math. 167 (2008), 625--642.

时间非齐次随机游走的最新一般形式仍要求每步是概率测度，并用卷积算子的第二奇异值控制收敛：

- E. Gorokhovsky, [*Time-inhomogeneous random walks on finite groups and cokernels of random integer block matrices*](https://arxiv.org/abs/2405.11435), Theorems 1.1 and 2.1（2026 版本）。

本题每一步的测度是 `delta_{A_u}`。其卷积算子就是置换，所有奇异值都是 `1`；上述定理给零收缩。

若把若干 `A_u` 平均成

\[
\frac1W\sum_{u\in I}\rho(A_u),
\]

确实可能得到谱隙，但其幂会对所有 `u_1,...,u_h` 分支求和，而不是只保留对角路径

\[
u,u+1,\ldots,u+h-1.
\]

这正是 annealed codegree 与 quenched 保序问题的差别。恢复对角路径会把所获平均重新损失掉。

# 6. 正确的最小引理：Fejér 平方函数，而非谱半径

沿用 Q6515 的零延拓口径。令

\[
q(n)=\delta_{\pi(n)}\in\ell^2(\mathbf P^1(\mathbf F_p)),
\]

并定义

\[
\widehat q(k)=\sum_nq(n)e_p(kn),
\qquad
A_p(k)=\|\widehat q(k)\|_2^2.
\tag{6.1}
\]

则

\[
A_p(k)=\sum_{m,n}\mathbf1_{\pi(m)=\pi(n)}e_p(k(m-n)),
\]

且题面 (8.4) 为

\[
L_p(H):=
\frac1p\sum_k(A_p(k)-N)F_H(k)
=2\sum_{h\le H}\left(1-\frac{h}{H+1}\right)R_h.
\tag{6.2}
\]

## 6.1 精确平方函数形式

令 `V` 是 time shift，

\[
D_H(V)=I+V+\cdots+V^H.
\]

Fejér 恒等式等价于

\[
\frac1{H+1}\|D_H(V)q\|_2^2
=N+L_p(H).
\tag{6.3}
\]

因此最小的 operator-shaped lemma 是

> **[OBS-FEJER]** 对 `H<=sqrt(p)`，
> \[
> \boxed{
> \|D_H(V)q\|_2^2
> \le (H+1)N+C_\varepsilon H(H+1)p^\varepsilon.
> }
> \tag{6.4}
> \]

它立即给 `[GAP-TIME-FEJER]`。

注意 (6.4) 是一个**特殊向量的近正交平方函数界**。要求整个 centered 空间上的 operator norm 谱隙既不需要，也不可能。

## 6.2 一个干净的局部谱质量充分条件

定义离散谱测度

\[
\mu_p(J)=\frac1p\sum_{k\in J}A_p(k).
\]

它的总质量是 `N`，均匀基准在含 `|J|` 个频率的弧上为 `N|J|/p`。

下列条件比目标稍强，但是真正可攻击的 theorem-shaped statement：

> **[LOCAL-SPECTRAL-FLATNESS]** 对每个 `H<=sqrt(p)` 和每个长度至少 `p/H` 的圆周频率区间 `J`，
> \[
> \boxed{
> \mu_p(J)
> \le \frac{N|J|}{p}+C_\varepsilon p^\varepsilon.
> }
> \tag{6.5}
> \]

证明它推出 (6.2) 很短。Fejér 核满足

\[
F_H(k)\ll
\frac{H}{1+(H\|k\|_p/p)^2}.
\tag{6.6}
\]

把频率分成

```text
|k| <= p/H,
2^{j-1}p/H < |k| <= 2^j p/H.
```

在第 `j` 个壳上，核至多 `O(H 4^{-j})`。均匀部分的总贡献精确为 `N`；(6.5) 的误差贡献为

\[
O\!\left(Hp^\varepsilon\sum_{j\ge0}4^{-j}\right)
=O(Hp^\varepsilon).
\]

减去 `N` 即得 `[GAP-TIME-FEJER]`。

这就是题面“低频带质量控制”的精确最小版本。

## 6.3 resolvent 版本

令 `mu_q` 是 `V` 关于向量 `q` 的谱测度。Poisson 核满足

\[
P_\rho(\theta)=
\operatorname{Re}\frac{1+\rho e^{i\theta}}{1-\rho e^{i\theta}},
\]

且

\[
\int P_\rho\,d\mu_q
=
\operatorname{Re}
\left\langle q,
\frac{I+\rho V}{I-\rho V}q
\right\rangle.
\tag{6.7}
\]

一个足够强的标量 resolvent 命题是：当 `1-rho` 与 `1/H` 同阶时，

\[
\boxed{
\operatorname{Re}
\left\langle q,
\left(\frac{I+\rho V}{I-\rho V}-I\right)q
\right\rangle
\ll_\varepsilon Hp^\varepsilon.
}
\tag{6.8}
\]

对 `rho=e^{-c/H}`、`c` 在固定紧区间内一致成立，则由 Poisson/Fejér 正核比较推出 (6.4)。

这里必须是**标量矩阵元**或特殊向量谱测度。全算子范数

\[
\|(I-\rho V)^{-1}\|=(1-\rho)^{-1}\asymp H
\]

本来就不会小。

# 7. 镜像如何进入算子，而不产生免费谱隙

强反射给

\[
\pi(p-1-n)=\pi(n).
\]

对 nonwrapping gap，镜像 involution 是

\[
r\mapsto p-1-h-r.
\]

因此在 regular 口径中

\[
\boxed{R_h=\mathbf1_{2\mid h}+2Y_h.}
\tag{7.1}
\]

强制部分对 Fejér 和的贡献满足

\[
2\sum_{h\le H}
\left(1-\frac h{H+1}\right)\mathbf1_{2\mid h}
=O(H),
\tag{7.2}
\]

已经在目标允许范围内。于是只需对 residual `Y_h` 证明同样的界。

但 forward shift 不在镜像商上良定义。若 `J` 是时间反射、`V` 是前移，则

\[
JVJ=V^{-1}.
\tag{7.3}
\]

所以 `J`-orbit quotient 不是一个有向的一步 dynamical quotient。好消息是 Fejér 多项式只含对称组合 `V^h+V^{-h}`，故

\[
JF_H(V)=F_H(V)J.
\]

因此镜像可以在**Fejér/二次型层面**作 even/odd 分解并剥离强制项；它不能把单步 Koopman 变成有谱隙的较小算子。

# 8. 三个无条件切入点的精确收获与死因

## 8.1 (a) Casoratian 刚性 `R_1=0`

由

\[
b_{r+1}c_r-b_rc_{r+1}=-r^{-3}\ne0
\]

可得

\[
\boxed{R_1=0.}
\tag{8.1}
\]

在 start-clock twisted 坐标中，这甚至给

\[
\sum_r e_p(qr)\mathbf1_{\pi(r)=\pi(r+1)}=0
\]

对每个 `q` 都成立。

但在 lag spectrum 中，它只表示

\[
\frac1p\sum_k(A_p(k)-N)e_p(-k)=0,
\tag{8.2}
\]

即谱超额的**一个 Fourier 矩**为零。它不对应“最高频段”。最高频带需要所有 `h` 的交替组合，而不是只需 `h=1`。

一个最小反模型是

\[
A(k)=N\left(1+\cos\frac{4\pi k}{p}\right).
\]

它非负、均值为 `N`、`h=1` Fourier 系数为零，但 `h=2` 系数为 `N/2`，低频 Fejér 超额可以很大。这个模型不是 Apéry 轨道；它严格说明仅凭 `C_1` 无法推出任何 band bound。

**裁决：** `C_1` 是全 `q` 一致的单层刚性，不给任何 `p`-幂频带控制。

## 8.2 (b) fixed short window 的 Weil/Postnikov 想法

对固定 `h`，仓库已证

\[
R_h\le\deg N_h=3(h-1)
\tag{8.3}
\]

（剥离 forced factor 后常数更小）。因此

\[
\sum_{h\le H}R_h\ll H^2.
\tag{8.4}
\]

于是对任意固定 `A`，当 `H<=log^A p` 时，

\[
H^2\le Hp^\varepsilon
\]

对充分大的 `p` 成立。也就是说 `[GAP-TIME-FEJER]` 在任意固定 polylog clock range 无条件成立。

若对 root set 再作起点 twist，

\[
S_{h,q}=\sum_{r:N_h(r)=0}e_p(qr),
\]

则最强的免费界其实仍是

\[
|S_{h,q}|\le R_h\le3h,
\tag{8.5}
\]

对所有 `q` 一致。普通 Weil 把零指示写成

\[
\mathbf1_{N_h(r)=0}
=\frac1p\sum_t e_p(tN_h(r))
\]

后，每个 `t` 的完整和至多 `O(h\sqrt p)`，反而弱于 (8.5)（在 `h<sqrt p` 时）。

更本质地说，这仍是 `r`-Fourier，而 (8.4) 需要 `h`-Fourier。固定 `h` 的 Weil 相消不能把不同 `h` 的 singleton 根位置联系起来。Kurlberg--Rosenzweig 的 fixed-extension incomplete Chebotarev（Theorem 1、Proposition 2）也有同样的固定复杂度限制：

- P. Kurlberg and L. Rosenzweig, [*The Chebotarev density theorem for function fields—Incomplete intervals*](https://arxiv.org/abs/1901.06751).

**裁决：** 可执行的无条件收获是 `H=p^{o(1)}`；任何 `H=p^theta` 都重新撞到 growing-family wall。没有免费的“部分 k 频段谱隙”。

## 8.3 (c) mirror quotient / primitive half-orbit

由 (7.1) 可以：

- 把强制贡献精确写成 `O(H)`；
- 将 primitive 多项式次数和线性代数规模约减半；
- 将 residual 根计数除以 `2`。

但恢复到原 orbit 时真碰撞也乘回 `2`。并且由于 (7.3)，half-orbit 不是一个 forward-invariant Markov 状态空间。

**裁决：** 它是免费常数约化和表示分解，不是谱隙来源。

# 9. 与 `sigma` 指数机器的精确逻辑关系

令

\[
d_H(r)=\#\{1\le h\le H:\pi(r)=\pi(r+h)\},
\]

\[
S_p(H)=\sum_r d_H(r)=\sum_{h\le H}R_h,
\]

\[
P_p(H)=\#\{r:d_H(r)>0\},
\qquad
Q_p(H)=\sum_r\binom{d_H(r)}2.
\]

## 9.1 `[GAP-TIME-FEJER]` 与 `S_p(H)` 等价（常数/尺度变换）

因为 Fejér 权重非负，并且当 `h<=H/2` 时

\[
2\left(1-\frac h{H+1}\right)\ge1,
\]

有

\[
S_p(H/2)\le L_p(H)\le2S_p(H).
\tag{9.1}
\]

所以对所有尺度的 `[GAP-TIME-FEJER]` 与

\[
\boxed{S_p(H)\ll_\varepsilon Hp^\varepsilon}
\tag{9.2}
\]

只差 `H -> 2H`。

## 9.2 TIME-FEJER 推出 `sigma=1`，但不推出更高 `sigma`

显然

\[
P_p(H)\le S_p(H).
\]

又因 `d_H(r)<=H`，

\[
Q_p(H)
\le\frac H2\sum_rd_H(r)
=\frac H2S_p(H).
\]

故 (9.2) 推出

\[
\boxed{Q_p(H)\ll H^2p^\varepsilon.}
\tag{9.3}
\]

在

\[
Q_p(H)\ll H^{3-\sigma}p^\varepsilon
\]

的记号中，这正是 `sigma=1`。

它一般不推出 `Q<<Hp^epsilon`（`sigma=2`）：一个 base point 可以承担 `H` 个返回而仍不违反 `S<<H`。

## 9.3 TIME-FEJER 给全能量 `p^{3/2}`

把长度 `N` 的序列分成约 `N/H` 个连续块。若 `m_{v,j}` 是第 `j` 块中颜色 `v` 的重数，则 Cauchy 给

\[
\sum_vm_v^2
\le\left\lceil\frac NH\right\rceil
\sum_{j,v}m_{v,j}^2.
\]

块内同色 pair 的 gap 小于 `H`，故

\[
\sum_{j,v}m_{v,j}^2
\le N+2S_p(H).
\]

因此

\[
E^\pi(p)
\ll\left(\frac NH+1\right)(N+2S_p(H)).
\tag{9.4}
\]

取 `H=sqrt(p)` 并用 (9.2)，

\[
\boxed{E^\pi(p)\ll p^{3/2+\varepsilon}.}
\tag{9.5}
\]

这正是 `sigma=1` 指数机器的输出。仓库最新 `FABLE_SECTION_orbit_energy.tex` 已经通过次数界+块分割无条件得到同一指数（并修正领先常数为 `2 sqrt(3)`），所以仅从能量角度看，TIME-FEJER 不会再改善当前 `3/2`。

## 9.4 但 TIME-FEJER 给 pointwise `sqrt(p)`，这是它的真正价值

restart inequality 为

\[
|Z_p|\le1+S_p^{reg}(H)+O(p/H).
\tag{9.6}
\]

若 TIME-FEJER 在 `H=sqrt(p)` 成立，则

\[
\boxed{|Z_p|\ll_\varepsilon p^{1/2+\varepsilon}.}
\tag{9.7}
\]

这严格改善现有 `p^{2/3}`，而单独的 `E^pi<<p^{3/2}` 做不到。

## 9.5 `Q_sigma` 不能反推 TIME-FEJER

即使 `Q_p(H)=0`，所有 `N_h` 的根集仍可两两不交，每层有 `Theta(h)` 个全新 singleton 根，从而

\[
S_p(H)\asymp H^2.
\]

Q6515 §3.3 已给出满足镜像、次数界和全结果式非零的可运行证书。因此：

- 任意 `sigma` 的 `Q_sigma` 单独都不推出 TIME-FEJER；
- 即使 `sigma=2`、甚至 `E^pi=O(p)`，仍不推出 short-gap 线性界；Q6515 §6 有双向反模型。

若另加首返回支撑界，则有

\[
d\le1+\binom d2\qquad(d\ge1),
\]

从而

\[
S_p(H)\le P_p(H)+Q_p(H).
\tag{9.8}
\]

所以仓库的 `[GAP-QRLL]`

\[
P_p(H)+Q_p(H)\ll Hp^\varepsilon
\]

确实推出 TIME-FEJER；反向不成立，因为 TIME 只给 `Q<<H^2p^epsilon`。

### 逻辑表

| 输入 | 对 `P` | 对 `Q` | 全能量 | pointwise zero |
|---|---:|---:|---:|---:|
| TIME-FEJER | `<<Hp^eps` | `<<H^2p^eps` (`sigma=1`) | `<<p^{3/2+eps}` | `<<p^{1/2+eps}` |
| `Q_sigma` 单独 | 无控制 | 定义输入 | `p^{2-1/(3-sigma)+eps}` | 无控制 |
| `E^pi<<p` | 无 short-gap 控制 | 无局部控制 | 最优 | 不由此自动得出 |
| QRLL (`P+Q<<Hp^eps`) | 有 | 有 (`sigma=2` 级) | 至少最优方向 | `<<p^{1/2+eps}` |

所以两条路线不是谁简单包含谁：

- TIME-FEJER 比 `sigma<=1` 的重复返回界强，并直接击中 singleton；
- `sigma>1` 在重复返回上更强，但仍对 singleton 全盲；
- `sigma=2`/E1 是全能量靶，TIME-FEJER 是首返回/低频靶。

# 10. 建议的下一步：不再测“谱隙”，改测三种可区分量

现有 FFT 并行实验应输出以下三组对象；它们能区分“特殊向量谱平坦”与“全算子无隙”。

## 10.1 直接检验 `[LOCAL-SPECTRAL-FLATNESS]`

对每个 dyadic `H`，计算

\[
D_p(H,K)=
\max_{|J|=K}
\left(
\frac1p\sum_{k\in J}A_p(k)-\frac{NK}{p}
\right),
\qquad K\asymp p/H.
\]

目标是

\[
D_p(H,K)=p^{o(1)},
\]

而不是 `max_k A_p(k)=O(p)`。后者对随机 periodogram 也通常太强。

## 10.2 检验 Fejér square function，而不是单频峰值

直接输出

\[
\frac{\|D_H(V)q\|^2-(H+1)N}{H(H+1)}.
\]

目标是 `p^{o(1)}`。这与题面目标完全同口径，没有 band-window 解释误差。

## 10.3 分开测 start-clock leakage

对少量 `h`，构造 (4.1) 的特殊矩阵元

\[
\langle\phi_0,\mathcal T_q^{(h)}\phi_0\rangle,
\]

同时测所有 `q`。若 `q\ne0` 小而 `q=0` 大，说明起点方向有 flattening，但它仍未自动控制 lag spectrum；若所有 `q` 都出现同一低秩峰，则可能存在真正的 bispectral closure。

## 10.4 最小机器锁

对 `p=101`、小 `h` 应逐项断言：

```text
Gamma[u+1] == A[u] * Gamma[u]
(pi[u] == pi[u+h]) == ((A[u,h])[0,1] == 0)
R_h_direct == <f0, U^h f0>
clock_block_DFT == (1/L) sum_u e_L(q u) K(A[u,h])
T_q^(2) != (T_q^(1))^2    # 一般应严格不等
U_cyclic^* U_cyclic == I  # 任意可逆边界完成
```

这些断言能防止后续再次把 `pi`、Riccati state、clock frequency 和 lag frequency 混为一谈。

# 11. 路线优先级

1. **第一优先：特殊观测的 local spectral flatness / Fejér square function。** 它直接命中 `P`/singleton，并且不会要求不可能的全 Koopman 谱隙。
2. **第二优先：[GAP-2D-SQRT] 与其 `t`-方向 L1 flattening。** 它是目前唯一经过泄漏测试的二维相消坐标；它可能成为证明 (6.5) 的 van der Corput 输入。
3. **第三优先：start-clock twisted blocks 的低秩/表示论分类。** 目标是发现特殊 Borel 向量的闭包，而不是证明 `||T_q||<1-c`。

# 12. 最后两问

## (a) 我最没把握的一步

我最没把握的是：**能否把 Q6515 的零延拓 `A_p(k)` 谱测度，规范地实现成上述 transfer skew-product 的一个特殊向量谱测度，同时不因循环边界产生 `O(H^2)` 误差。**

- frame/Borel 构造、clock block 公式、酉性 no-go 都是有限矩阵恒等式；
- (8.4) 本身也是已固定的 Fourier 恒等式；
- 真正敏感的是把二者接成一个适合代数几何/表示论处理的**同一个**循环算子。最安全的做法是保留 clock cutoff，直接证明 (6.4)；不要先任意补一个 boundary matrix 再声称谱等价。

## (b) 双方共同盲点可能在哪

最可能有两个相反方向的共同盲点。

1. **特殊向量可以平坦，而全算子绝不混合。** 我们此前可能把“需要谱隙”说得太强。`U` 的谱必在单位圆上，但 Borel/Steinberg 观测向量可能对近 `1` 特征向量几乎正交；这正是 `(LSF)`，也是一个真正可能成立的低秩/bispectral 现象。
2. **奇异 clock 可能是唯一的非酉来源。** regular block 删掉了 `u=-1`；restart gauge 在该点发生 rank-one collapse。把整个 `p`-cycle 连同奇异散射纳入，可能产生一个非酉 monodromy/transfer 对象。不过每个周期只有一个奇异时刻，而 `H<=sqrt(p)` 的绝大多数窗口不穿过它，所以它不可能仅靠“每步收缩”解释目标；若它有作用，必须通过一个全局 Frobenius/digit 或 mixed-extension 关系把影响传播到所有起点。

换言之，真正的盲点很可能不是一个普通 expander，而是：

> **一个带 singular scattering 的特殊 Borel/Steinberg spectral measure，其全算子无隙，但指定观测向量具有 quenched local Weyl law。**

这正好给下一轮一个可证伪的双靶：算子层面先证明 no-gap；观测层面直接测并攻击 `(LSF)`。
