# Canonical Apéry gauge: scalar endomorphisms, quantitative conjugacy cost, and the remaining cross-row theorem

## Executive verdict

I followed the canonical repository after Q800, in particular the current Problem 3.2 resume, Q800, Q778, Q340, and Q338. The canonical low-height integral model does have substantially more rigidity than Q800's constant-gauge countermodel, but that rigidity is negative rather than a new source of synchronized solutions.

The main results are:

1. The rational endomorphism ring of the canonical Apéry difference module is scalar. Over (overline{mathbf Q}(t)), every horizontal endomorphism is (lambda I). Over (mathbf Q(t)), (lambdainmathbf Q); an endomorphism preserving the standard integral initial-state lattice has (lambdainmathbf Z), and an integral automorphism is (pm I).

1. All forward contiguous intertwiners are generated by the transfer product. A rational intertwiner from the module to its (h)-shift is a scalar multiple of the canonical product (T(t+h-1)cdots T(t)). The adjoint/self-duality map is likewise unique up to scalar and is just the determinant pairing. Neither construction sends the Apéry state to an independent section.

1. The modular/symmetric-square origin gives no hidden second section. The rank-two modular local system has scalar commutant, and so does its symmetric square. Any Atkin–Lehner or Hecke correspondence that becomes a same-base horizontal endomorphism is therefore scalar; the actual correspondences move the base point or level structure. The four singular fibers of the canonical (Gamma_1(6)) elliptic surface have distinct types, so no nontrivial base automorphism preserves the marked family.

1. A noncanonical integral conjugacy encoding an independent synchronized state has radical-sized height. If (Ginmathrm{SL}_2(mathbf Z)) and (G(1,5)^T) vanishes at every folded zero in a star, then either it is proportional to ((1,5)^T), or

```plain text
||G||_infinity >= R_1(n)/36.
```

Moreover the first two conjugated transfer matrices already satisfy

```plain text
max(||G^(-1)T(1)G||_infinity,
    ||G^(-1)T(2)G||_infinity)
    >= R_1(n)/72.
```

Thus the CRT conjugacy from Q800 cannot preserve bounded-height canonical coefficients unless the desired radical is already subexponential.

1. There is an exact canonical off-diagonal detector. If (mathbf r_m=(r_m,s_m)) is the canonical integral transfer row, then

```plain text
det(row_a,row_b) = (a!)^6 * N_(b-a)(a),   0 <= a < b,
```

where (N_h) is the Apéry gap continuant. If (p>b) and (pmid A_a), then

```plain text
p divides det(row_a,row_b)  <=>  p divides A_b.
```

This is the fixed-gauge integer that detects a genuinely second zero under the same prime.

1. Bounded coefficients plus the determinant law still do not force correlation. For every finite prescribed reflection star, one can construct a single recurrence with the fixed initial state ((1,5)), coefficient bound (O(n^3)), off-diagonal coefficient (-m^6), and the exact adjacent determinant ((m!)^6), whose only zeros modulo each star prime are the prescribed reflection pair. What this model loses is precisely the exact cubic diagonal coefficient

```plain text
P(m)=34m^3+51m^2+27m+5
```

and therefore the modular/Picard–Fuchs origin. Consequently neither bounded coefficient height nor the adjacent determinant can by itself prove expansion.

I do not obtain the q = 1 bound. The sharpest surviving theorem is now a canonical-row correlation statement. Let (S_1(n)) be the q = 1 star, (K_1(n)=|S_1(n)|), and (j_p) its folded indices. Define

```plain text
C_A(n)
 = #{(p,q) in S_1(n)^2 : p != q and p divides A_(j_q)}
 = #{(p,q) : p != q and
       p divides det(row_(j_p),row_(j_q))}.
```

A lower bound

```plain text
C_A(n) >= K_1(n)^(1+delta) * n^(-o(1))
for some fixed delta > 2/3
```

would imply (K_1(n)=o(n/log n)), hence (log R_1(n)=o(n)). The countermodel proves that such a theorem must use the exact cubic (P(m)), not merely its degree, size, determinant, reflection pairs, or generic recurrence identities.

## 1. The canonical difference module

Put

```plain text
P(t) = 34 t^3 + 51 t^2 + 27 t + 5,

T(t) = [[P(t), -t^6],
        [1,       0 ]].
```

For arbitrary initial data (u_0=x,u_1=y), scale by

```plain text
X_m = (m!)^3 u_m.
```

Then

```plain text
X_0 = x,
X_1 = y,
X_(m+1) = P(m) X_m - m^6 X_(m-1).
```

Equivalently, with (Y_m=(X_m,X_{m-1})^T),

```plain text
Y_(m+1) = T(m) Y_m.
```

Let (K=overline{mathbf Q}(t)), with shift (sigma f(t)=f(t+1)). The associated rank-two difference module is

```plain text
sigma(Y)(t) = T(t)Y(t).
```

Q800 writes

```plain text
X_m = r_m x + s_m y,
row_m = (r_m,s_m),
```

and proves

```plain text
det(row_m,row_(m+1)) = (m!)^6.
```

The theorem below classifies all same-base rational symmetries of this canonical module.

## 2. Scalar-centralizer theorem for the Apéry difference module

### Theorem 2.1

Let (E(t)inmathrm{Mat}_2(overline{mathbf Q}(t))) satisfy the horizontal endomorphism equation

```plain text
E(t+1) T(t) = T(t) E(t).
```

Then

```plain text
E(t) = lambda * I
```

for some constant (lambdainoverline{mathbf Q}).

Consequently,

```plain text
End_(Q(t),sigma)(M) = Q,
```

and the endomorphisms preserving the standard integral initial-state lattice are precisely (mI), (minmathbf Z). The integral automorphisms are (pm I).

### Proof

The endomorphism equation gives

```plain text
E(t+1) = T(t) E(t) T(t)^(-1).
```

Therefore (operatorname{tr}E) and (det E) are rational functions of period one. A rational function in characteristic zero with period one is constant: a finite pole would generate infinitely many translated poles, and a pole-free rational function is a polynomial, hence a constant if periodic.

Suppose (E) is not scalar. Its characteristic polynomial has constant coefficients. Over (overline{mathbf Q}(t)), either it has two distinct eigenspaces or it has a nontrivial Jordan kernel. In either case the difference module has a rational invariant line.

Represent that line generically by the vector ((z(t),1)^T). Invariance under (T(t)) gives the Riccati equation

```plain text
z(t+1) = P(t) - t^6/z(t).                    (2.1)
```

We now prove that (2.1) has no solution in (overline{mathbf Q}(t)). Write (z=A/B) with coprime (A,Binoverline{mathbf Q}[t]). Cross-multiplication gives

```plain text
A(t+1)A(t)
 = B(t+1)(P(t)A(t)-t^6B(t)).                 (2.2)
```

Since (A(t+1)) and (B(t+1)) are coprime, (2.2) implies

```plain text
B(t+1) divides A(t).
```

Write (A(t)=B(t+1)C(t)). Rearranging (2.2) also gives

```plain text
A(t) divides t^6 B(t)B(t+1).
```

Because (A) and (B) are coprime, (C) is coprime to (B), and hence

```plain text
C(t) divides t^6.
```

Thus

```plain text
z(t) = c t^k B(t+1)/B(t),
0 <= k <= 6.                                  (2.3)
```

Degree comparison in (2.1) forces (k=3). Put (d=deg B). At infinity,

```plain text
B(t+1)/B(t) = 1 + d/t + O(t^(-2)),

z(t) = c t^3 (1+d/t+O(t^(-2))),

z(t+1) = c t^3 (1+(d+3)/t+O(t^(-2))),

t^6/z(t) = c^(-1)t^3(1-d/t+O(t^(-2))).
```

Comparing the coefficients of (t^3) and (t^2) in (2.1) yields

```plain text
c + c^(-1) = 34,

c(d+3) = 51 + c^(-1)d.
```

The first equation gives (c-c^{-1}=2(c-17)). The second then gives

```plain text
d = (51-3c)/(c-c^(-1)) = -3/2,
```

which is impossible for the degree of a polynomial. Hence there is no rational invariant line and (E) is scalar. ∎

### 2.2 Constant centralizer check

There is also a short exact check for constant matrices. The first two transfer matrices are

```plain text
T(1) = [[117,-1],
        [  1, 0]],

T(2) = [[535,-64],
        [  1,  0]].
```

If (C=begin{pmatrix}a&b\c&dend{pmatrix}) commutes with both, the lower-right entry of (CT(m)=T(m)C) gives

```plain text
b = -m^6 c
```

for (m=1,2). Hence (b=c=0), and the remaining entries give (d=a). Thus even the constant centralizer is exactly scalar.

## 3. Classification of contiguous and adjoint transformations

### 3.1 Forward shifts

For (hge0), define

```plain text
F_h(t) = T(t+h-1) ... T(t+1)T(t),
F_0(t) = I.
```

It satisfies

```plain text
F_h(t+1)T(t) = T(t+h)F_h(t).                 (3.1)
```

### Theorem 3.1

Every nonzero rational intertwiner (G(t)) satisfying

```plain text
G(t+1)T(t) = T(t+h)G(t)
```

is of the form

```plain text
G(t) = lambda F_h(t)
```

for a constant (lambda).

Indeed, a nonzero rank-one intertwiner would produce an invariant line, already excluded. Thus (G) is generically invertible, and (F_h^{-1}G) is an endomorphism of the original module. Theorem 2.1 makes it scalar.

Therefore every rational contiguous transformation is just the canonical shift of the same solution. It does not create a second comparison section.

### 3.2 Adjoint and self-duality

Let

```plain text
J = [[ 0, 1],
     [-1, 0]].
```

For every two-by-two matrix (M), one has (M^TJM=(det M)J). Hence

```plain text
T(t)^T J T(t) = t^6 J.                       (3.2)
```

This is the canonical determinant-twisted self-duality of the Apéry module. It identifies (M) with (M^veeotimesdet M), not with a new independent copy of (M). Any other rational adjoint intertwiner differs from (J) by an endomorphism of (M), and is therefore a scalar multiple of (J).

The classical companion solution is not produced by an endomorphism. It is a chosen second solution with nonzero Casoratian. At a large folded zero the Casoratian is a unit, so it is specifically not synchronized with the Apéry solution.

### 3.3 Reflection

The coefficient polynomial satisfies

```plain text
P(-t-1) = -P(t).
```

This gives a reversal isomorphism between the module and the pullback under (tmapsto-t-1); it is not a same-time endomorphism. The balanced hypergeometric continuation

```plain text
B(z) = _4F_3(-z,-z,z+1,z+1;1,1,1;1)
```

is invariant under (zmapsto-z-1), because the numerator parameters are merely interchanged. Thus reflection sends the distinguished Apéry section to itself. Its two zero positions are two evaluations of the same local scalar, exactly as Q715 and Q778 found; reflection creates no independent section.

## 4. The modular and K3 origin has scalar endomorphism ring

The Apéry generating function satisfies the order-three operator

```plain text
L3 = theta^3
     - x(2theta+1)(17theta^2+17theta+5)
     + x^2(theta+1)^3.
```

Equivalently, in ordinary derivatives,

```plain text
x^2(1-34x+x^2)y'''
 + x(3-153x+6x^2)y''
 + (1-112x+7x^2)y'
 + (x-5)y = 0.
```

This is the symmetric square of the rank-two Picard–Fuchs equation

```plain text
x(x^2-34x+1)y''
 + (2x^2-51x+1)y'
 + (x-10)y/4 = 0.                            (4.1)
```

At the level of local systems,

```plain text
H_K3  = Sym^2(H_elliptic)   (up to the usual Tate normalization).
```

The elliptic local system is the one attached to the semistable elliptic surface over the modular curve for (Gamma_1(6)), with singular fibers of types

```plain text
I_6, I_3, I_2, I_1.
```

The modular identification and these four fiber types are recorded in G. Almkvist and D. van Straten, “Calabi–Yau operators of degree two”; the K3 and monodromy origins go back to Beukers–Peters and Peters.

### Theorem 4.1

The commutant of the rank-two modular monodromy over (mathbf Q) is scalar, and so is the commutant of its symmetric square.

### Proof

The group (Gamma_1(6)) contains

```plain text
U = [[1,1],
     [0,1]],

V = [[1,0],
     [6,1]].
```

A matrix commuting with (U) has the form

```plain text
[[a,b],
 [0,a]].
```

Commuting also with (V) forces (b=0). Therefore

```plain text
End_Q(H_elliptic) = Q.
```

The group (Gamma_1(6)) is Zariski dense in (mathrm{SL}_2), and (operatorname{Sym}^2) of the standard representation is absolutely irreducible. Schur's lemma gives

```plain text
End_Q(Sym^2 H_elliptic) = Q.                 (4.2)
```

∎

### 4.2 Atkin–Lehner and Hecke audit

A same-base automorphism of the marked elliptic surface must preserve Kodaira fiber type. Since (I_6,I_3,I_2,I_1) are pairwise distinct, it fixes all four singular points; a Möbius transformation fixing three points is the identity. Thus the canonical marked family has no nontrivial base automorphism from which a second horizontal section could arise.

Atkin–Lehner involutions naturally act on (X_0(6)), while the canonical marked family is over (X_1(6)). After pullback they either move the base point/level structure or cease to preserve the chosen marked family. Hecke operators are likewise correspondences between different fibers. If any such correspondence descends to a horizontal endomorphism over the identity of the base, (4.2) forces it to be scalar.

The same applies to modular self-isogenies: multiplication-by-(m) acts as a scalar on the rank-two rational local system, and as (m^2) on its symmetric square. It cannot send the holomorphic Apéry period to an independent period.

### 4.3 No hidden holomorphic section

At the maximally unipotent point (x=0), equation (4.1) has one holomorphic period and one logarithmic period. Its symmetric square has one holomorphic solution, one logarithmic solution, and one log-squared solution. Hence there is no second canonical holomorphic Taylor section with integral coefficients at (x=0). The modular/K3 origin supplies the polarization and the logarithmic companions, but not a second synchronized integral sequence.

## 5. Quantitative height of a noncanonical synchronized gauge

Let

```plain text
v = (1,5)^T,
G = [[a,b],
     [c,d]] in M_2(Z).
```

Suppose the solution with initial state (Gv) vanishes at the folded zero for every prime in a subset (S) of the q = 1 star. Q800's local-line theorem says that, for each (pin S),

```plain text
Gv is proportional to v modulo p.
```

Therefore (p) divides

```plain text
Delta(G) = det(v,Gv)
         = c + 5d - 5a - 25b.                (5.1)
```

Writing (R_S=prod_{pin S}p), we have

```plain text
R_S divides Delta(G).                         (5.2)
```

If (Gv) is independent of (v), then (Delta(G)ne0), and

```plain text
R_S <= |Delta(G)| <= 36 ||G||_infinity.
```

Thus

```plain text
||G||_infinity >= R_S/36.                    (5.3)
```

The same statement holds for a rational matrix after multiplying by a primitive common denominator, provided the star primes do not divide that denominator. In particular, denominators supported on primes at most (n/2) cannot hide the q = 1 radical.

For a finite family (G_1,ldots,G_k) whose synchronized subsets cover the star,

```plain text
R_1(n) divides product_i Delta(G_i),
```

so

```plain text
sum_i log^+(||G_i||_infinity)
 >= log R_1(n) - k log 36.                   (5.4)
```

This is the quantitative form of the statement that a finite canonical family cannot have subexponential determinant product unless it already proves the desired bound.

## 6. The conjugated recurrence itself must become radical-sized

The preceding estimate concerns the conjugating matrix. The next lemma shows that the coefficient height of the conjugated transfer system also becomes large immediately.

Let (Ginmathrm{SL}_2(mathbf Z)), and set

```plain text
B_i = G^(-1) T(i) G,    i=1,2,
B = max(1, ||B_1||_infinity, ||B_2||_infinity).
```

Use the matrix units (E_{ij}). Direct calculation gives

```plain text
X = T(2)-T(1) = 418 E_11 - 63 E_12,

Y = T(2)T(1)^(-1)-I
  = 63 E_11 - 6953 E_12.
```

The coefficient determinant is

```plain text
det([[418,-63],
     [ 63,-6953]]) = -2902385.
```

Therefore

```plain text
E_11 = (-6953 X + 63 Y)/(-2902385),

E_12 = (-63 X + 418 Y)/(-2902385).           (6.1)
```

Conjugating (6.1) and using the max-entry norm gives

```plain text
||Ad_G(E_11)||_infinity <= 0.00486 B^2,

||Ad_G(E_12)||_infinity <= 0.00048 B^2.
```

Since

```plain text
E_21 = T(1)-117E_11+E_12,
```

we also get

```plain text
||Ad_G(E_21)||_infinity <= 1.57 B^2.          (6.2)
```

For (G=begin{pmatrix}a&b\c&dend{pmatrix}), (det G=1),

```plain text
G^(-1) E_12 G
 = [[ dc,  d^2],
    [-c^2,-cd ]],

G^(-1) E_21 G
 = [[-ab,-b^2],
    [ a^2, ab ]].                             (6.3)
```

Equations (6.2)–(6.3) imply

```plain text
||G||_infinity <= 1.26 B,
```

and hence the safe bound

```plain text
B >= ||G||_infinity/2.                       (6.4)
```

Combining (5.3) and (6.4), any integral conjugacy that sends the Apéry state to an independent section synchronized with a star subset (S) satisfies

```plain text
max(||G^(-1)T(1)G||_infinity,
    ||G^(-1)T(2)G||_infinity)
 >= R_S/72.                                  (6.5)
```

Thus Q800's CRT conjugacy necessarily encodes the star radical in the very first transfer coefficients. Constant-gauge monodromy countermodels cannot preserve the canonical bounded-height model cheaply.

## 7. A canonical off-diagonal determinant lemma

Recall

```plain text
X_m = r_m x+s_m y,
row_m=(r_m,s_m).
```

Let (N_h(x)) be the gap continuant normalized by

```plain text
N_0(x)=0,
N_1(x)=1,
N_(h+1)(x)=P(x+h)N_h(x)-(x+h)^6N_(h-1)(x).
```

### Theorem 7.1

For (0le a<b),

```plain text
det(row_a,row_b) = (a!)^6 N_(b-a)(a).        (7.1)
```

### Proof

For fixed (a), put (D_h=det(mathrm{row}a,mathrm{row}{a+h})). Then

```plain text
D_0=0,
D_1=(a!)^6,
```

and the row recurrence gives

```plain text
D_(h+1)=P(a+h)D_h-(a+h)^6D_(h-1).
```

This is exactly the recurrence and initial data of ((a!)^6N_h(a)). ∎

### Corollary 7.2: exact second-zero detector

Let (p>b) and assume (pmid A_a). Q800 gives

```plain text
row_a = lambda*(-5,1) modulo p,
lambda != 0 modulo p.
```

Therefore

```plain text
det(row_a,row_b)
 = -lambda*(r_b+5s_b)
 = -lambda*(b!)^3 A_b     modulo p.
```

Since (p>b), all scalar factors are units, and

```plain text
p divides det(row_a,row_b)
  <=> p divides A_b.                          (7.2)
```

This equivalence is symmetric in (a,b) once one of the two Apéry values is known to vanish.

Equation (7.2) is the exact canonical-gauge integer divisibility lemma missing from the varying-state countermodel. It does not yet give a lower bound on how often it occurs.

## 8. The precise canonical correlation theorem that would finish q = 1

For fixed (n), let

```plain text
S_1(n) = {p : n/2 < p <= n, p prime,
               p divides A_(j_p)},

j_p = min(n-p,2p-1-n),

K_1(n) = |S_1(n)|.
```

Define the ordered canonical cross-incidence count

```plain text
C_A(n)
 = #{(p,q) in S_1(n)^2 : p != q,
                              p divides A_(j_q)}.
```

By Corollary 7.2,

```plain text
C_A(n)
 = #{(p,q) : p != q and
       p divides det(row_(j_p),row_(j_q))}

 = #{(p,q) : p != q and
       p divides N_|j_q-j_p|(min(j_p,j_q))}.  (8.1)
```

The map (qmapsto j_q) has multiplicity at most two: a folded index (j) can come only from

```plain text
q = n-j
or
q = (n+1+j)/2.
```

The unconditional vertical bound (|Z_p^+|ll p^{2/3}) therefore gives

```plain text
C_A(n) <= 2 sum_(p in S_1(n)) |Z_p^+|
       << K_1(n) n^(2/3).                    (8.2)
```

Suppose one could prove, for some fixed (delta>2/3),

```plain text
C_A(n)
 >= K_1(n)^(1+delta) n^(-o(1)).              (8.3)
```

Combining (8.2) and (8.3) yields

```plain text
K_1(n)^delta <= n^(2/3+o(1)),

K_1(n) <= n^(2/(3delta)+o(1)).
```

Since (delta>2/3), the exponent is strictly less than one. Hence

```plain text
log R_1(n) <= K_1(n) log n = o(n).
```

Thus (8.3) is one explicit theorem sufficient to close the q = 1 target. It is formulated entirely in the canonical integral transfer rows and gap continuants.

## 9. Bounded coefficients and the adjacent determinant do not imply (8.3)

The next construction includes the fixed initial state and the exact determinant law. It shows precisely what additional arithmetic (8.3) must use.

### Proposition 9.1: fixed-state polynomial-height star model

Fix (n) and a finite set (S) of odd primes in ((n/2,n]). For each (pin S), prescribe the reflected pair

```plain text
t_p^- = n-p,

t_p^+ = 2p-1-n.
```

Discard the possible central duplication and assume, as for actual large Apéry stars, that none of the prescribed times is (0) or (1). Then there exist integers (c_1,ldots,c_{n-1}) with

```plain text
|c_m| <= 2 n^3
```

such that the sequence

```plain text
U_0=1,
U_1=5,
U_(m+1)=c_m U_m-m^6U_(m-1)                  (9.1)
```

has, modulo each (pin S), zeros in ([0,p-1]) exactly at the prescribed reflected pair and nowhere else.

### Proof

Choose (c_m) successively. Suppose all values through (U_m) have been fixed.

If (U_mnotequiv0pmod p), exactly one residue class of (c_mpmod p) makes (U_{m+1}equiv0):

```plain text
c_m = m^6 U_(m-1)/U_m   modulo p.            (9.2)
```

Impose (9.2) when (m+1) is a prescribed zero for (p), and avoid it otherwise.

If (U_mequiv0pmod p), then (m) is a prescribed zero. The prescribed zeros are nonconsecutive, and induction gives (U_{m-1}ne0). Since (m<p),

```plain text
U_(m+1) = -m^6 U_(m-1) != 0 modulo p,
```

independently of (c_m).

For a fixed time (m+1), at most two primes require a residue: the equations are

```plain text
p=n-(m+1)
```

or

```plain text
p=(n+m+2)/2.
```

Let (M) be the product of these required primes, so (Mle n^2), and choose one CRT solution (c_0pmod M). Every other star prime forbids at most one value of (kpmod p) in

```plain text
c_m=c_0+Mk.
```

There are at most (K=|S|) forbidden primes, while every (pin S) satisfies (p>n/2ge K). Among (k=0,1,ldots,K), each prime excludes at most one value, so at least one choice remains. This gives

```plain text
|c_m| <= M(K+1) <= 2n^3.
```

The induction proves the proposition. ∎

For the transfer rows of (9.1), the off-diagonal coefficient is still (-m^6), so exactly as in Q800,

```plain text
det(row_m,row_(m+1))=(m!)^6.
```

The model also has no consecutive zeros and all generic continuant, addition, and Casoratian identities of a second-order recurrence. Yet its star can be arbitrarily large and its leaves can remain isolated.

What it does not preserve is

```plain text
c_m = 34m^3+51m^2+27m+5,
```

nor the resulting modular Picard–Fuchs equation and exact polynomial reflection symmetry. Therefore:

The fixed state, coefficient bound (O(n^3)), off-diagonal term (-m^6), adjacent determinant ((m!)^6), no-consecutive-zero property, and prescribed reflected zero pairs do not imply off-diagonal expansion. Any proof of (8.3) must exploit the exact cubic law or an equivalent modular/Dwork identity.

## 11. Sharp reopen condition

The endomorphism and modular classifications rule out a canonical second section. The fixed-state polynomial-height model rules out any theorem based only on coarse coefficient height and the adjacent determinant. The remaining load-bearing feature is the exact arithmetic of

```plain text
P(m)=34m^3+51m^2+27m+5.
```

A concrete theorem that would close q = 1 is:

```plain text
Canonical cross-row expansion theorem.

There exists delta > 2/3 such that, for every n,

  sum_(p in S_1(n))
    #{q in S_1(n), q != p :
       p divides
       N_|j_q-j_p|(min(j_p,j_q))}

  >= K_1(n)^(1+delta) * n^(-o(1)).
```

Equivalent formulations may use the row determinants in (8.1), the actual Apéry values (A_{j_q}), or the off-diagonal leaf count from Q778. A proof must be sensitive to the exact canonical cubic and cannot be invariant under arbitrary bounded-height changes of the diagonal coefficient.

A weaker but still useful alternative is a direct low-height determinant theorem:

```plain text
Construct nonzero integers C_n with

  R_1(n) divides C_n,
  log|C_n| = o(n),

where C_n is built canonically from the rows row_j and
its construction is not preserved under replacing P(m)
by arbitrary O(n^3) coefficients.
```

No endomorphism, modular correspondence, fixed finite family of comparison sections, or constant conjugacy supplies such an integer.
