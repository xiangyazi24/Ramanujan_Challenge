# Determinant content: the (pge5) theorem is true; the stated (3)-criterion is not

## Main theorem

Let (1le h<j), and let (D_{h,j}(x)inmathbf Z[x]) be the reduced bordered certificate from Q38/Q90. Then:

[

boxed{

text{For every prime }pge5text{ with }j<p,

qquad

D_{h,j}(x)notequiv0pmod p.

}

tag{T}

]

Consequently no prime (pge5) divides the content of (D_{h,j}). Thus the odd prime support of the content is contained in ({3}):

[

boxed{

operatorname{rad}{rm odd}(operatorname{cont}D{h,j})mid3.

}

tag{C}

]

This is exactly the input needed in Q90 to remove the term (pE_p(k)) and obtain the unconditional regular-locus bound

[

sum_{1le h<rle k-1}

#{x:D_{h,k}(x)=D_{r,k}(x)=0, N_kQ_hQ_rne0}

=O(k^3)

qquad(k<p, pge5).

]

There are two corrections to the claim as stated.

1. The sentence “odd part of the content divides (3)” is stronger than (T): it also asserts (v_3(operatorname{cont}D)le1). The proof below excludes all primes (pge5), but it does not establish the exponent of (3).

1. The assertion “(3) occurs only when (h,j) are both even” is false globally. In fact

[

boxed{D_{1,18}(x)equiv0pmod3,}

]

although (h=1) is odd. A complete mod-(3) classification is given in Section 8. The computations through (jle8) do not see the period-(18) phenomenon.

The proof of (T) has two stages:

- reflection plus the Q90 Plücker identity performs a subtractive Euclidean descent from an arbitrary bad pair ((h,j)) to a central pair ((d,2d));

- a second-order expansion at (x=infty) of the two consecutive length-(d) transfer blocks proves that (D_{d,2d}) cannot vanish identically modulo any (pge5) with (2d<p).

## 1.1 Reflection

Reversing the bordered Jacobi matrix gives, up to the harmless sign ((-1)^{j-1}),

[

boxed{

D_{h,j}(x)

=(-1)^{j-1}D_{j-h,j}(-x-j-1).

]

Only the implication

[

D_{h,j}equiv0

Longleftrightarrow

D_{j-h,j}equiv0

]

will be used.

The three forced reflection factors are:

[

2x+h+1mid D_{h,j}quad(htext{ even}),

]

[

2x+j+1mid D_{h,j}quad(jtext{ even}),

]

[

2x+h+j+1mid D_{h,j}quad(j-htext{ even}).

]

Thus the criterion in the question for the third factor is exactly (hequiv jpmod2). When both (h,j) are even, all three factors occur. Each displayed linear polynomial is primitive, so dividing these factors out does not change the content.

## 1.2 Plücker identity

For (a<b<c), the three (2times2) minors of

[

begin{pmatrix}

-N_bQ_aD_{a,c}

}

tag{1.3}

]

This is the identity proved in Q90.

# 2. The continuant (N_j) is nonzero modulo (p)

We need this only for (j<p).

## Lemma 2.1

Let (pge7) be prime and (1le j<p). Then

[

N_j(x)notequiv0pmod p.

]

### Proof

For (j=1) this is immediate. Suppose (jge2) and (N_jequiv0).

The exact special value is

[

N_j(-1)=((j-1)!)^3b_{j-1},

]

where (b_n) is the Apéry sequence. Since (j<p), the factorial is a unit modulo (p), so

[

b_{j-1}equiv0pmod p.

tag{2.1}

]

Now evaluate the recurrence for (N_j) at (x=1-j):

[

N_j(1-j)=P(0)N_{j-1}(1-j)=5N_{j-1}(1-j).

]

Because (pne5), this gives

[

N_{j-1}(1-j)=0.

]

Using

[

N_{j-1}(-(j-1))

=(-1)^{j-2}((j-2)!)^3b_{j-2},

]

we obtain

[

b_{j-2}equiv0pmod p.

tag{2.2}

]

But two consecutive Apéry numbers among (b_0,ldots,b_{p-1}) cannot both vanish modulo (p): the second-order recurrence propagates such a pair backwards to (b_0=0), contradicting (b_0=1). Equations (2.1)–(2.2) are therefore impossible. ∎

For (p=5) and (j<5), nonvanishing is direct:

[

N_1=1,

[

operatorname{lc}(N_4)=39236equiv1pmod5.

# 3. Euclidean descent to (D_{d,2d})

Assume that for some prime (pge5), (j<p),

[

overline D_{h,j}=0

qquadtext{in }mathbf F_p[x].

tag{3.1}

]

By reflection,

[

overline D_{j-h,j}=0.

tag{3.2}

]

If (hne j-h), put

[

a=min(h,j-h),

qquad

b=max(h,j-h).

]

Apply (1.3) to (a<b<j). The two outer minors vanish by (3.1)–(3.2), hence

[

overline N_j,overline Q_a,overline D_{a,b}=0.

]

The polynomial ring is a domain, (Q_ane0), and Section 2 gives (N_jne0). Therefore

[

overline D_{a,b}=0.

]

In terms of the two positive segment lengths

[

(h,j-h),

]

this replaces the pair by one subtractive Euclidean step. Repeating, the maximum index strictly decreases until the two segment lengths become equal. The gcd is preserved. Thus, with

[

d=gcd(h,j),

we eventually obtain

[

boxed{

overline D_{d,2d}=0,

qquad

2dle j<p.

}

tag{3.4}

]

It remains to rule out (3.4).

# 4. Transfer matrix for two consecutive blocks

For a solution (y_r) of the local recurrence, define

[

v_r=binom{y_r}{y_{r+1}}.

]

The normalized one-step transfer is

[

T_r(x)=

begin{pmatrix}

0&1\[1mm]

-left(dfrac{x+r+1}{x+r+2}right)^3

&dfrac{P(x+r+1)}{(x+r+2)^3}

end{pmatrix},

]

so that

[

v_{r+1}=T_r(x)v_r.

]

Let

[

A_d(x)=T_{d-1}(x)cdots T_0(x),

qquad

B_d(x)=T_{2d-1}(x)cdots T_d(x)=A_d(x+d).

]

Then

[

v_d=A_dv_0,

qquad

v_{2d}=B_dA_dv_0.

]

Set

[

Delta_d(x)

=det

begin{pmatrix}

e_1(A_d-I)\

e_1(B_dA_d-I)

end{pmatrix}.

]

The first row is the condition (y_d=y_0), and the second is (y_{2d}=y_0). From the explicit continuant formula for the first coordinates,

[

e_1(A_d-I)=frac1{Q_d}(-L_d,N_d),

]

[

e_1(B_dA_d-I)=frac1{Q_{2d}}(-L_{2d},N_{2d}).

]

Hence

[

boxed{

Delta_d(x)=frac{D_{d,2d}(x)}{Q_{2d}(x)}.

}

tag{4.1}

]

Thus (D_{d,2d}equiv0) implies (Delta_dequiv0) as a rational function.

# 6. The leading obstruction forces (C^d=pm I)

Define the Pell/Lucas sequence

[

u_0=0,

Let

[

t_d=operatorname{tr}(C^d)=u_{d+1}-u_{d-1}.

For any (2times2) determinant-one matrix (M=(m_{ab})),

[

detbigl(e_1(M-I),e_1(M^2-I)bigr)

[

operatorname{lc}D_{d,2d}=2u_d-u_{2d}=u_d(2-t_d).

# 7. The first non-scalar block coefficient

Assume (6.3).

## 7.1 The coefficient (S) is scalar

First,

[

CS-SC=C^dE-EC^d=0,

]

so (S) belongs to the centralizer of (C), which is the two-dimensional algebra (mathbf F_p[C]).

[

=3u_{d-1-r}(u_r-17u_{r+1}).

From (C^d=varepsilon I),

[

[

# 9. Consequence for content

If a prime (pge5) divided every coefficient of (D_{h,j}), then

[

D_{h,j}equiv0pmod p,

]

contradicting Theorem (T) whenever (j<p). For a fixed pair ((h,j)), any prime divisor of the content larger than (j) is therefore impossible directly. The transfer proof actually gives the same nonvanishing for every (pge5) for which the descent continuants remain nonzero; the range (j<p) is exactly the range needed in the application and avoids all endpoint-factorial exceptional primes.

In the stated application one obtains

[

boxed{

E_p(k)=0

qquad(pge5, k<p),

}

]

in the notation of Q90. Hence the Q90 bound becomes unconditionally

[

boxed{

sum_{1le h<rle k-1}C_{h,r;k}(p)

le

frac{(k-2)(k-1)(2k-3)}2

=O(k^3).

}

]

# 10. Exact mod-(3) analysis and the counterexample to the parity claim

Modulo (3),

[

P(t)equiv t^3-1.

]

Let

[

X=x^3.

]

The recurrence becomes

[

(X+r+1)y_{r+1}

=(X+r-1)y_r-(X+r)y_{r-1}.

tag{10.1}

]

## 10.1 A universal alternating solution

The sequence

[

y_r^{(1)}=(-1)^r

]

satisfies (10.1) identically.

For a second solution write

[

y_r^{(2)}=(-1)^rz_r.

]

Substitution into (10.1) gives

[

(X+r+1)(z_{r+1}-z_r)

=(X+r)(z_r-z_{r-1}).

]

Choose

[

z_0=0,

qquad

z_1=1.

]

Then

[

z_r=(X+1)sum_{m=1}^{r}frac1{X+m}.

tag{10.2}

]

The two solutions have independent initial vectors

[

(1,-1),

qquad

(0,-1).

]

The return values are

[

a_r=y_r^{(1)}-y_0^{(1)}=(-1)^r-1,

]

[

b_r=y_r^{(2)}-y_0^{(2)}=(-1)^rz_r.

]

Since the determinant of the two return functionals differs from (Q_hQ_jD_{h,j}) only by a nonzero scalar, one has

[

D_{h,j}equiv0pmod3

Longleftrightarrow

quadtext{in }mathbf F_3(X).

tag{10.3}

]

## 10.2 Period (9) for (z_r)

In a block of nine consecutive integers, each residue class modulo (3) occurs three times, so (10.2) gives

[

z_{r+9}=z_r.

]

Moreover

[

z_r=0

Longleftrightarrow

9mid r,

]

and

[

z_j=z_h

Longleftrightarrow

9mid(j-h).

]

Indeed, the rational functions (1/X,1/(X+1),1/(X+2)) are linearly independent over (mathbf F_3), and a consecutive interval has all three residue counts divisible by (3) exactly when its length is a multiple of (9).

Using (10.3), the complete criterion is:

[

boxed{

D_{h,j}equiv0pmod3

}

]

if and only if one of the following holds:

1. (h,j) are both even;

1. (h) is even, (j) is odd, and (18mid h);

1. (h) is odd, (j) is even, and (18mid j);

1. (h,j) are both odd, and (18mid(j-h)).

In particular,

[

D_{1,18}equiv0pmod3.

]

Thus the experimental rule “(3) occurs only for (h,j) both even” is valid only in the initial range before the period-(18) phenomena appear.

This mod-(3) analysis determines when (3) divides the content. It does not by itself determine whether (9) can divide the content. Establishing

[

v_3(operatorname{cont}D_{h,j})le1

]

requires a separate mod-(9) lifting argument. That exponent statement is not needed for the (pge5) nonconcentration theorem.
