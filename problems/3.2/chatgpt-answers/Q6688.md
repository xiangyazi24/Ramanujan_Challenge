# ARCH-CELL-ORDER audit

## (1) Uniform two-sided cell expansion

Verdict: not yet automatic from strip localization; the remaining input is a uniform asymptotic theorem.

The required statement is of the form: for the two fundamental solutions u_+(n,z),u_-(n,z) of the parameter-dependent recurrence, uniformly for z in a fixed compact cell coordinate range and uniformly in the cell index j,

N_h(-j+xi) = B_{h,j}(xi) K_infty(xi) (1+e_{h,j}(xi)),

with ||e_{h,j}||_{C^2} <= C(1/j+1/(h-j)).

Poincare-Perron gives the pointwise asymptotic expansion for each fixed solution. It does not by itself give the required uniform C^2 control in the moving parameter/cell family. The missing ingredient is an asymptotic integration theorem for difference equations with parameters: one needs uniform exponential dichotomy, parameter differentiability of the conjugating transformations, and summable variation of the coefficient perturbation.

A usable lemma is:
if A_n(z)=A_inf+E_n(z), sup_z ||partial_z^k E_n(z)|| <= C_k/n^2 for k<=2, and A_inf has separated eigenvalues lambda,lambda^-1, then there exists a C^2 parameter-dependent conjugacy with remainder O(1/n), uniformly in z.

This is the exact hypothesis needed; citation to general Poincare-Perron alone is insufficient.

## (2) Computing K_infty

The computation pipeline is:

1. Solve the asymptotic recurrence at infinity by substituting

u_n = lambda^n sum_{m>=0} a_m lambda^{-m n},

and similarly the recessive solution with lambda^{-n}.

2. Normalize phi_0=1 and gamma_0=1 by fixing the leading eigenvector.

3. Generate coefficients recursively by matching powers of lambda^{-n} in the limiting Apery recurrence.

4. Form

K_infty(z)=phi(-z)phi(z)+z^6 gamma(-z)gamma(z).

5. Compute K'_infty and K''_infty from the same series and locate roots of K'_infty by interval Newton.

The machine certificate required is:
- truncation error bound for K,K',K'';
- isolating intervals for every critical point;
- proof each critical point has K'' !=0;
- proof no two critical values overlap after interval enclosure.

Expected outcome: simple Morse critical points and distinct critical values. This is plausible because the two independent Perron solutions destroy the accidental symmetries, but it is not a theorem until the interval computation is done.

## (3) Large-h ordering

With h<=30 Morse certificates already available, the remaining theorem is a perturbative ordering statement.

For every cell (h,j), write

C_{h,j}=q_{h,j} K_infty + Delta_{h,j}.

Need bounds:

||Delta_{h,j}||_{C^2} <= eps_h |q_{h,j}|,

eps_h -> 0 effectively.

If critical values of K_infty have separation

delta_K=min_{a!=b}|K(a)-K(b)|>0,

then any resonance must satisfy either

|q_{h,j}/q_{h,k}-1| < O(eps_h)+O(delta_K^{-1} perturbation).

Thus only neighboring scale bands need checking.

A finite closure requires an explicit h_0 such that eps_h < delta_K/10 for all h>=h_0.

The required constants are:

1. lambda spectral gap;
2. C^2 coefficient perturbation constant;
3. global truncation constant for K_infty;
4. minimum critical-value separation delta_K;
5. explicit q_{h,j} separation bounds.

If these give h_0<=30, the existing certificate range closes all h. Otherwise extend the finite computation to h_0.

Blind spot:
