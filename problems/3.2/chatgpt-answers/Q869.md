# 3. Proof of the classification theorem

## 3.1 No prefix zero implies no multiplier support

If

```plain text
Z_p(H)=empty,
```

then

```plain text
v_p(A_s)=0
```

for every node. The local formula immediately gives

```plain text
v_p(m_H)=0.
```

This proves part (1).

## 3.2 Two prefix zeros force multiplier support

Assume there are distinct nodes

```plain text
r,t in Z_p(H).
```

Suppose for contradiction that

```plain text
p does not divide m_H.
```

Since p|A_r and p|A_t, nodewise integrality

```plain text
A_s | m_H z_H(s)
```

forces

```plain text
z_H(r)=z_H(t)=0 mod p.
```

But z_H is a nonzero linear polynomial modulo p: its two integer coefficients are coprime, so they cannot both vanish modulo the same prime. Also

```plain text
0<|r-t|<=H<p,
```

so r and t are distinct in F_p. A nonzero linear polynomial cannot have two distinct roots. Contradiction.

Therefore

```plain text
|Z_p(H)|>=2 => p|m_H.
```

This proves part (2). Notice that no simplicity assumption on the Apéry zeros is used.

## 3.3 One zero: cleared moments localize at that node

Assume

```plain text
Z_p(H)={r},

e=v_p(A_r)>=1.
```

Then e is the maximum p-adic valuation among A_0,...,A_H. Divide the cleared moments by the common p-adic unit L_H/p^e. Modulo p, every term except s=r vanishes, while the surviving term is a unit because

```plain text
p>H,

p does not divide binom(H,r),

p does not divide A_r/p^e.
```

Consequently

```plain text
X_H is a p-adic unit,

Y_H=r X_H mod p.
```

In particular

```plain text
p does not divide h_H,

z_H(r)=0 mod p.
```

Since z_H is nonzero linear modulo p, r is its unique root modulo p. Hence

```plain text
p|z_H(n)
iff
n=r mod p.
```

Now

```plain text
0<=r<=H,

2H<p<=n=3H+1,

0<n-r<2p.
```

Thus

```plain text
n=r mod p
iff
n-r=p
iff
r=n-p.
```

This proves the root statement in parts (3) and (4).

The multiplier statement is now exactly Q850's local formula. At every node other than r, v_p(A_s)=0; therefore

```plain text
v_p(m_H)=max(0,e-v_p(z_H(r))).
```

If e=1, the already proved congruence p|z_H(r) gives

```plain text
v_p(m_H)=0.
```

This proves parts (3) and (4).

## 3.4 Every target prime is supported

Let

```plain text
j=n-p,

p|A_j.
```

If there is another prefix zero, part (2) gives p|m_H. If j is the unique prefix zero, part (4) gives p|z_H(n), because j=n-p. Hence in all cases

```plain text
p|P_H^prim(n),
```

and the binomial-window lemma gives

```plain text
p|W_H.
```

This proves part (5).


Examples of logically possible tags are

A unique simple non-target zero has no tag at all:

```plain text

v_p(A_r)=1,
r!=n-p

=> p does not divide m_H and p does not divide z_H(n).
```

This is the strongest sparsification furnished by the a=1 structure.

# 5. Hostile audit of the proposed finite-range patterns

## 5.1 Content and root support are not interchangeable

The exact theorem separates them sharply.

```plain text
At least two prefix zeros:
    multiplier support is forced.

One simple prefix zero:
    multiplier support is absent;
    root support occurs exactly at the moving node.

No prefix zero:
    multiplier support is absent;
    root support remains an independent accidental congruence.
```

Thus neither factor can be discarded.

## 5.2 Support does not force a second Apéry zero

The assertion

```plain text
p|W_H => |Z_p(H)|>=2
```

is false for two independent reasons.

First, every direct target prime having one simple prefix zero is supported through z_H(n). Second, a zero-free prime can in principle divide z_H(n); the exact scan records such root pollution separately.

The valid replacement is

```plain text
p|m_H and |Z_p(H)|<=1

=>
Z_p(H)={r}, v_p(A_r)>=2,
and v_p(z_H(r))<v_p(A_r).
```

## 5.3 Uniqueness of a prefix zero is false

The current prime-centric modular scan finds hundreds of candidate primes with at least two zeros in the prefix by height 50000. Therefore any theorem assuming that a candidate prime has at most one Apéry zero in 0,...,H is already numerically false over a large exact range.

This is compatible with the reflection law for Apéry zeros modulo p: lower-half zeros commonly occur in distinct reflection orbits. The computation does not prove an asymptotic density, but it decisively prohibits using uniqueness as an unchecked lemma.

## 5.4 Sparse multiplier support is not observed

Define

```plain text

 = product_{2H<p<=3H+1, |Z_p(H)|>=2} p.
```

The classification theorem proves


The recorded exact scan gives

```plain text

```

This is a rigorous finite computation, not an asymptotic theorem. It does show that the hoped-for sparse multiplier support is absent throughout the largest scanned range.

## 6.3 Fail-closed full-classification extension

To classify M and R at much larger selected heights without global fractions, use the following local p-adic moment algorithm.

For one candidate prime, set

```plain text
e_s=v_p(A_s),

E=max_(0<=s<=H)e_s.
```

In Z_p, define

```plain text
B_s=p^E/A_s,

Xi_H=sum_(s=0)^H (-1)^s binom(H,s) B_s,

Eta_H=sum_(s=0)^H (-1)^s binom(H,s) s B_s.
```

The omitted factor

```plain text
L_H/p^E
```

is a common p-adic unit, so it does not affect valuations or the normalized root. Put

```plain text
t=min(v_p(Xi_H),v_p(Eta_H)).
```

Then the exact radical flags are

```plain text
R
iff
v_p(Eta_H-n Xi_H)>t,

M
iff
there exists s<=H such that

    e_s>v_p(Eta_H-s Xi_H)-t.
```

A modular implementation computes the Apéry orbit modulo p^K, doubles K whenever an observed valuation reaches the precision boundary, and accepts a classification only when every compared valuation is strictly below K. This is fail-closed: no prime is classified from truncated equalities.

The following pseudocode is sufficient to implement the extension in C++ using uint64_t plus __int128 for ordinary cases and boost::multiprecision::cpp_int only on precision escalation.

```plain text
for H in requested_heights:
    n=3*H+1
    for prime p in (2H,n]:
        K=2
        repeat:
            modulus=p^K
            compute A_0,...,A_H modulo modulus by the Apéry recurrence
            determine e_s, requiring e_s<K
            E=max e_s
            compute B_s=(A_s/p^e_s)^(-1)*p^(E-e_s) modulo p^K
            compute Xi_H,Eta_H by the binomial recurrence
            t=min(v_p(Xi_H),v_p(Eta_H))
            root_val=v_p(Eta_H-n*Xi_H)-t
            multiplier_val=max_s max(0,e_s-v_p(Eta_H-s*Xi_H)+t)
            if every valuation used is <K:
                emit T,G,M,R
                break
            K=2*K
```

For scanning all heights, the binomial transforms can be batched by convolution:

```plain text
Xi_H
 = H! * [x^H]
   (sum_s (-1)^s B_s x^s/s!)
   (sum_t x^t/t!),
```

with the analogous transform for Eta_H after replacing B_s by sB_s. Because H<p, all factorials are units modulo p^K. An arbitrary-modulus NTT/CRT convolution therefore reduces the per-prime transform from quadratic to quasi-linear time. This optimization is not needed for the already completed H=50000 multi-zero scan, but it is the correct route for a full M/R census at comparable range.

# 7. The strongest rigorous lower obstruction to log W_H=o(H)

Define

```plain text
D_2(H)
 = sum_{2H<p<=3H+1, |Z_p(H)|>=2} log p.
```

The forced multi-zero lemma gives the unconditional inequality

```plain text
log W_H >= D_2(H).
```

Therefore the proposed target implies the separate theorem

```plain text
D_2(H)=o(H).
```

This is a strictly necessary condition. It does not involve the Padé root, primitive scaling, reciprocal moments, or any projective asymptotics. It is purely a vertical zero-multiplicity statement in a moving prime window.

Presently there is no theorem proving it. The available continuant bound

```plain text
|Z_p(H)| <= |Z_p(p-1)| << p^(2/3)
```

is far too weak: it bounds the number of zeros for one prime, not the weighted number of primes having at least two zeros in one moving prefix.

The current scan suggests that D_2(H)/H may stay positive, but no positive lower limit has been proved. Thus the most honest status is

```plain text
log W_H=o(H) is open and empirically doubtful;
D_2(H)=o(H) is its first necessary missing lemma;
current exact data oppose, rather than support, that lemma.
```

# 8. Exact remaining gap, decomposed into three estimates

Let

```plain text
D_multi(H)
 = sum_{2H<p<=n, |Z_p(H)|>=2} log p,

D_high(H)
 = sum_{2H<p<=n, Z_p(H)={r},
        v_p(A_r)>=2,
        v_p(z_H(r))<v_p(A_r)} log p,

D_free(H)
 = sum_{2H<p<=n, Z_p(H)=empty,
        p|z_H(n)} log p.
```

The classification theorem gives

```plain text
log W_H
 <= D_multi(H)+D_high(H)+D_free(H)
    + sum_{target p} log p,
```

and, more precisely, the support is the union of those sets with the target roots, with overlaps counted only once.

A proof of

```plain text
D_multi(H)=o(H),
D_high(H)=o(H),
D_free(H)=o(H)
```

would reduce log W_H=o(H) to the original direct target weight. But using W_H to prove the original target requires proving the whole union is o(H), so these estimates are not automatic simplifications.

The first estimate is currently the dominant obstruction. The second is likely smaller but needs a uniform theorem on repeated prime divisibility of Apéry values. The third is an independent linear-moment congruence with no known Apéry-zero interpretation.

# 9. Why increasing numerator degree changes, but does not automatically solve, the obstruction

For the primitive Padé pair with

```plain text
deg P_(H,a)<=a,

deg Q_(H,a)<=H-a,
```

put

```plain text
z_p(H)=|Z_p(H)|.
```

Reduction modulo a candidate prime gives the exact zero-absorber lemma

```plain text
P_(H,a)=0 in F_p[x]
iff
z_p(H)>a.
```

The forward implication follows because a nonzero degree-a polynomial cannot vanish at more than a interpolation nodes. Conversely, if the reduced numerator is zero, the reduced denominator must vanish at every nonzero Apéry node; the degree bound forces at least a+1 zero nodes.

For a=1, this is exactly the forced multiplier phenomenon:

```plain text
|Z_p(H)|>=2
=>
P_(H,1)=0 mod p,
```

so the prime divides the numerator content.

A second certificate, or a family with numerator degree growing beyond the observed zero multiplicity, can separate this pollution. But a single fixed a always absorbs every prime with more than a prefix zeros into its content. Therefore the correct continuation is not another sparsity conjecture for one fixed numerator. It is a separation theorem using two or more certificates whose content supports do not align.

# Final conclusion

The a=1 primitive-integrality formula yields a complete and useful local theorem, but the new radical W_H does not presently close Problem 3.2.

The bankable theorem is

```plain text
For 2H<p<=3H+1:

|Z_p(H)|>=2 => p|m_H,

Z_p(H)={r}, v_p(A_r)=1
 => p does not divide m_H
    and p|z_H(3H+1) iff r=3H+1-p.
```

It proves every direct target prime is supported and gives an exact four-tag classification. It also identifies a forced pollution family whose measured logarithmic mass is approximately 0.0743H at height 50000.

Therefore the precise remaining gap is not an uncomputed Smith factor or a missing projective asymptotic. It is the new horizontal/vertical statement

```plain text
sum_{2H<p<=3H+1, |Z_p(H)|>=2} log p=o(H),
```

plus control of high-multiplicity residual support and zero-free root support. No known lemma proves these estimates, and the first one is contrary to the current finite data.

The route should be classified as follows:

```plain text
Exact support law: proved.
Efficient modular scan: implemented and reproducible.
Uniqueness/sparse-pollution heuristic: refuted over the scanned range.
log W_H=o(H): open and likely false as a standalone route.
Next viable move: use a second certificate to cancel or separate the
multi-zero multiplier support.
```
