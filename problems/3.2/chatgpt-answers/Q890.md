# Projective Padé resultants: exact prefix-zero saturation and loss of the moving root

## Verdict

```plain text
n = 3H+1,
Z_(H,a)(x) = P_(H,a)(x) / content(P_(H,a)),
Z_p(H) = {s in [0,H] : p divides A_s},
z_p(H) = |Z_p(H)|.
```

At main commit


the proved content theorem is

```plain text
v_p(content(P_(H,a)))
  = the (a+1)-st largest member of
    {v_p(A_s) : 0<=s<=H}
```

for every prime p>H and every numerator degree a.

The proposed common-root route has an exact structural answer.

```plain text
If a >= z_p(H), then Z_(H,a) is nonzero modulo p and

    product_(s in Z_p(H)) (x-s)

    divides Z_(H,a)(x) in F_p[x].

If a = z_p(H), then equality holds up to a nonzero scalar.
```

Consequently, once the starting degree is above the vertical zero-count threshold, every prime having any prefix Apéry zero divides every adjacent projective resultant, whether or not its moving node j=3H+1-p is a zero.

Define

```plain text
C_H = product over primes p with
        2H < p <= 3H+1
        and Z_p(H) nonempty
      of p.
```

For every pair a<b satisfying

```plain text
a >= max_(2H<p<=3H+1) z_p(H),
```

one has the exact saturation

```plain text
C_H divides rad Res_x(Z_(H,a), Z_(H,b)).
```

The same factor divides every gcd of pairwise resultants, every principal subresultant condition asserting a positive-degree common divisor, and every simultaneous univariate elimination ideal that forgets the location of the common root.

This is the first exact saturation factor. It is strictly larger than the target radical

```plain text
R_H = product over candidate primes p=3H+1-j
      with p divides A_j
      of p,
```

because C_H uses

```plain text
there exists s<=H with p|A_s,
```

whereas R_H uses the marked condition

```plain text
p|A_(3H+1-p).
```

Thus ordinary resultants reverse the purification accomplished by the family-value gcd: eliminating x discards precisely the marked-root information.

No unconditional o(H) bound is obtained. The route saturates before any Archimedean estimate becomes useful. The weakest surviving object is not a resultant but the first nonzero subresultant polynomial, evaluated at the moving node. Prime by prime, that polynomial is exactly the prefix-zero polynomial; globalizing it requires a p-dependent subresultant index and is equivalent to the original marked-root problem.

## 2. Primitive reductions above the zero count

Fix a prime p>H. Write

```plain text
e_s = v_p(A_s),
Z = Z_p(H),
z = |Z|.
```

Let

```plain text
c_a = content(P_(H,a)).
```

By the proved order-statistic theorem,

```plain text
v_p(c_a) = e_(a+1).
```

If a>=z, at most z valuations are positive, so

```plain text
e_(a+1)=0,
v_p(c_a)=0.
```

Therefore division by the global content does not alter the reduction modulo p:

```plain text
Z_(H,a)(x) = c_a^(-1) P_(H,a)(x) mod p,
```

with c_a a unit.

The primitive coefficient vector is nonzero modulo p, hence

```plain text
Z_(H,a) is a nonzero polynomial in F_p[x]
```

when a>=z. This is the exact point at which raw Padé determinants become legitimate locally; below this degree the raw numerator may be identically zero and its removed content must be tracked.

## 3. Exact common divisor of the projective tail

### Lemma 3.1 — prefix-zero divisor

For every a>=z,

```plain text
D_p(x) := product_(s in Z) (x-s)
```

divides Z_(H,a)(x) in F_p[x].

### Proof

At every interpolation node s,

```plain text
P_(H,a)(s)=A_s Q_(H,a)(s).
```

If s in Z, the right side is zero modulo p. Since p does not divide c_a,

```plain text
Z_(H,a)(s)=0 mod p.
```

The nodes 0,...,H are distinct modulo p because p>H. Hence their linear factors are pairwise coprime, proving

```plain text
D_p | Z_(H,a).
```

### Lemma 3.2 — exact divisor at degree z

If a=z, then

```plain text
Z_(H,z)(x) = u_p D_p(x) in F_p[x]
```

for some u_p in F_p^*.

### Proof

The polynomial is nonzero, has degree at most z, and has the z distinct roots in Z. Its degree cannot be less than z. Therefore it is a nonzero scalar multiple of D_p.

### Corollary 3.3 — exact tail gcd

In F_p[x],

```plain text
gcd_{a>=z} Z_(H,a)(x) = D_p(x)
```

up to a unit, provided the family includes a=z.

So the common-root polynomial is not mysterious. It is exactly the polynomial encoding all prefix zeros, not the moving zero.

## 4. Resultant saturation

Let a,b>=z, a<b. Lemma 3.1 gives a nonconstant common divisor whenever z>=1. Therefore

```plain text
z_p(H)>=1
  => Res_x(Z_(H,a),Z_(H,b)) = 0 mod p.
```

Equivalently,

```plain text
p divides Res_x(Z_(H,a),Z_(H,b)).
```

This proves:

### Theorem 4.1 — candidate-window saturation factor

Let A be at least the maximum prefix zero count among candidate primes, and choose any two degrees

```plain text
A <= a < b <= H.
```

Then

```plain text
C_H divides
rad_(2H<p<=3H+1) Res_x(Z_(H,a),Z_(H,b)).
```

The same conclusion holds for:

```plain text
- gcds of several pairwise resultants;
- the zeroth principal subresultant coefficient;
- the ideal of maximal Sylvester minors;
- compound-matrix/Fitting presentations of positive-degree common roots;
- any simultaneous Bezout eliminant that eliminates x and records only
  whether the tail family has a common root.
```

All these constructions vanish whenever D_p is nonconstant. None records which root of D_p equals j=3H+1-p.

### Marked versus unmarked support

```plain text
resultant support:
    exists s in [0,H] with p|A_s;

target support:
    p|A_(3H+1-p).
```

The first implication is exactly the loss of information caused by elimination.

## 5. A nodewise resultant divisibility lemma

There is also an integral formulation that makes the first saturation visible before reducing modulo p.

### Lemma 5.1

For integer polynomials F,G and any integer s,

```plain text
gcd(F(s),G(s)) divides Res_x(F,G).
```

### Proof

The resultant lies in the ideal (F,G) in Z[x] after multiplying by suitable leading-coefficient powers; equivalently, the Sylvester adjugate gives integer polynomials U,V and an integer normalization whose specialization is the resultant. More directly, reduce modulo any prime power dividing both F(s) and G(s): the reductions have the common root s, so the Sylvester determinant vanishes modulo that prime power. Taking all prime powers proves the claim.

For the primitive Padé numerators and a,b>=z_p(H), every large prime p>H is a unit in both removed contents. Thus, if

```plain text
e_s=v_p(A_s)>0,
```

then

```plain text
p^e_s divides Z_(H,a)(s),
p^e_s divides Z_(H,b)(s),
```

and hence

```plain text
v_p Res_x(Z_(H,a),Z_(H,b)) >= e_s.
```

In particular, the p>H part of

```plain text
lcm(A_0,...,A_H)
```

divides every adjacent tail resultant once a is above the corresponding zero count.

This is the first exact arithmetic saturation factor. It comes from actual Apéry values, not from a generic Hadamard estimate.

## 6. Subresultants do not rescue root location

Let

```plain text
S_k(F,G)
```

denote the k-th polynomial subresultant, with the convention that the first nonzero polynomial subresultant is a gcd up to a unit.

At a candidate prime with z=z_p(H) and for the adjacent pair

```plain text
F=Z_(H,z),
G=Z_(H,z+1),
```

Lemma 3.2 gives

```plain text
F = u_p D_p,
D_p | G.
```

Hence:

```plain text
- the resultant and all subresultants below gcd degree z vanish;
- the first nonzero polynomial subresultant is u'_p D_p(x);
- evaluating that subresultant at j detects the target exactly:

      D_p(j)=0  iff  j in Z_p(H).
```

This looks promising but is not a global certificate. Both choices are moving:

```plain text
subresultant index = z_p(H),
marked evaluation point = 3H+1-p.
```

A fixed integer resultant combines all roots and loses the second datum. A global product over every possible subresultant index and every candidate evaluation point recreates the raw family-value gcd or a larger object. Its support purification is no better than Section 160's exact formula

```plain text
p | gcd_(0<=a<=A) Z_(H,a)(3H+1)
iff
3H+1-p in Z_p(H),
```

once A exceeds the vertical threshold.

Thus the first nonzero subresultant polynomial is an exact reformulation, but not a height compression.

## 7. Why the Apéry recurrence does not cancel the saturation factor

The Apéry recurrence constrains the node values A_s, and it gives no consecutive zero modulo a candidate prime. This implies that D_p has no consecutive integer roots. It does not make D_p=1 and does not identify its roots with the moving node.

Any recurrence-derived linear relation among tail polynomials has the form

```plain text
sum_a R_a(x) Z_(H,a)(x) = B(x)
```

with integral or p-integral coefficient polynomials. Modulo a prime with prefix-zero polynomial D_p, every term on the left is divisible by D_p. Therefore

```plain text
D_p divides B(x) mod p.
```

Two possibilities remain:

```plain text
1. B keeps D_p:
   the relation retains the full unmarked prefix-zero saturation;

2. the construction divides by D_p or by a subresultant content:
   the division is p-dependent and requires knowing the zero set;
   evaluating the quotient at j is again the marked-root problem.
```

The recurrence can simplify coefficients or prove identities among minors, but it cannot remove a genuine common polynomial divisor without an operation that depends on that divisor.

This is the exact obstruction to a Christoffel--Darboux, Dodgson, or adjacent-resultant collapse in the present formulation.

## 8. First exact saturation in the adjacent identity

For adjacent primitive Padé pairs, the already proved cross identity has the form

```plain text
P_a(x) Q_(a+1)(x) - P_(a+1)(x) Q_a(x)
  = kappa_a * binom(x,H+1).
```

After primitive normalization, kappa_a has the exact Smith-square formula recorded in the archive:

```plain text
|kappa_a|
  = binom(H+1,a+1) * tau_a^2 / (delta_a delta_(a+1)),
```

where tau_a is the solid Newton minor and delta_a is the last determinantal divisor of the denominator-kernel matrix.

At every interpolation node s<=H, the right side vanishes identically. Therefore this identity places no restriction on a common numerator root at s; it is compatible with every prefix-zero divisor D_p.

Trying to use the identity to eliminate the denominators produces either:

```plain text
- a resultant containing the prefix-zero saturation C_H;
- powers of kappa_a and the binomial polynomial, whose height is positive
  linear or larger after Smith normalization;
- or a quotient by the common divisor, which is p-dependent.
```

So the first adjacent saturation factor is not a hidden small Apéry integer. It is the actual prefix-zero radical C_H, together with the explicit Smith factor kappa_a in raw cross-minor formulas.

## 9. Height audit

The universal upper bounds remain useless:

```plain text
Hadamard/Sylvester bound for a raw resultant:
    exp(O(H^2 log H)) or worse;

adjacent cross-minor carrier:
    contains binom(3H+1,H+1),
    logarithmic height ~ 3H * h(1/3), hence Theta(H);

prefix-zero saturation:
    log C_H = sum over candidate primes having any prefix zero of log p.
```

The last quantity is the exact obstruction. The repository's scan reported in Q867 gives, at H=50000,

```plain text
weight of candidate primes with at least one prefix zero
  / H
= 0.3452990877.
```

This is an exact finite computation, not an asymptotic theorem. It shows that the first saturation factor is already linear-sized in the largest audited sample, while the actual moving target at that same height is empty.

I do not claim that log C_H has a positive asymptotic lower density. No such theorem is currently proved. The rigorous conclusion is instead:

```plain text
Any o(H) bound for a projective resultant must first remove C_H.
Removing C_H requires retaining the location of the common root.
The location-aware object is the subresultant gcd polynomial evaluated at j,
which is exactly the original marked-root condition.
```

Thus the resultant route does not merely lack a good height estimate; its first exact factor has the wrong support.

```python
from math import gcd

# Inputs Z[a] are primitive integer polynomials from the repository's

for H in range(2, 23):
```

## 11. Weakest remaining theorem

The resultant formulation saturates. The narrow remaining theorem is location-aware:

```plain text
For A = ceil(C(3H+1)^(2/3)), prove

log rad_(2H<p<=3H+1)
    gcd_(0<=a<=A) Z_(H,a)(3H+1)
  = o(H).
```

Equivalently, using the exact tail gcd polynomial over each F_p:

```plain text
sum over candidate primes p of
  1_[ D_p(3H+1-p)=0 ] * log p
= o(H),

where
  D_p(x)=product_(s<=H, p|A_s)(x-s).
```

This is exactly the marked-root theorem. A strictly smaller Apéry-specific lemma would need to construct, uniformly over candidate primes, an integral lift of the first nonzero subresultant polynomial whose evaluation at 3H+1-p is represented by one nonzero integer of logarithmic height o(H). No such lift or height estimate is currently proved.
