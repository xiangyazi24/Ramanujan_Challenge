# FIX 1: GPRV center reconciliation

Let

```javascript
A_h = C_h - n_h/p
B_h = mu_h - n_h/p.
```

Then

```javascript
C_h - mu_h = A_h - B_h.
```

The exact inequalities are

```javascript
sum |C_h-mu_h|^2
<= 2 sum |C_h-n_h/p|^2 + 2 sum |mu_h-n_h/p|^2,
```

and conversely

```javascript
sum |C_h-n_h/p|^2
<= 2 sum |C_h-mu_h|^2 + 2 sum |mu_h-n_h/p|^2.
```

The deterministic center error satisfies

```javascript
|mu_h-(p-1-h)/p| <= 1/2 + O(h/p),
```

so

```javascript
sum_{h<=p-3} |mu_h-n_h/p|^2 = O(p).
```

Therefore

```javascript
sum |C_h-n_h/p|^2 << p^(1+eps)
iff
sum |C_h-mu_h|^2 << p^(1+eps)
```

up to additive O(p).

No parity cancellation is needed for eps>0. Parity only improves the explicit leading constant: the alternating +/-1/2 structure has mean square approximately p/4, but the equivalence uses only the uniform O(1) center displacement.

Verdict: CONFIRMED.

# FIX 2: mirror correction in Q_D

For

```javascript
Q_D=sum_{a+g<=D} C_p(a,g),
```

a mirror-forced edge occurs only for even a:

```javascript
r*(a)=(p-1-a)/2.
```

This forces

```javascript
pi(r*)=pi(r*+a),
```

but does NOT force the second edge. The second equality is

```javascript
pi(r*+a)=pi(r*+a+g),
```

which is random with probability about c/p.

A double mirror chain requires

```javascript
r*(a)+a=r*(g).
```

Solving gives

```javascript
(p-1+a)/2=(p-1-g)/2,
```

so

```javascript
a=-g mod p.
```

Inside the triangle

```javascript
a>=1, g>=1, a+g<=D<p,
```

this has no solutions.

Hence there are no exact two-edge mirror chains in the admissible triangle.

The mirror excess is therefore

```javascript
(number of even a<=D)*(c/p)
=O(D/p).
```

The corrected null model is

```javascript
E[Q_D]
= D^2/(2p) + O(D/p) + ordinary finite-size terms.
```

For the requested scales:

```javascript
p=10007, D=316:
random term = D^2/(2p) ~= 4.99
mirror excess = O(0.03)
observed Q=10.

p=30011, D=3162:
random term = D^2/(2p) ~= 166.6
mirror excess = O(0.11)
observed Q=1089.
```

The second observation is much larger than the pure independent null because D=3162 is no longer a sparse birthday regime; higher projective return correlations dominate. The mirror correction is not the explanation.
