# P3.2 Null-model prediction table for supercritical Q_D

```plain text
Setup:
N = p-1.
Triangle T_D = {(a,g): a>=1,g>=1,a+g<=D}.
M = |T_D| = D(D-1)/2.

Pure random-color model:
Each position has an independent color in F_p.
For one (a,g), C_p(a,g) counts positions r with three equal colors.

E[C_p(a,g)] = (p-2)/p^2 = 1/p + O(1/p^2).
Var(C_p(a,g)) = 1/p + O(1/p^2).

Therefore
E[Q_D] = D(D-1)/(2p) + O(D^2/p^2).

The leading variance comes from diagonal triple events:
Var(Q_D) = D(D-1)/(2p) + O(D^3/p^2).

Mirror-corrected model:
Reflection r -> p-1-r forces one partner collision for even gaps.
Let epsilon(a,g)=1 when the triangle is mirror-compatible, otherwise 0.
Then
E[C_p(a,g)] = 1/p + (epsilon(a,g))/2 + O(1/p).

Hence
E[Q_D]_mirror = D(D-1)/(2p) + N_even(D)/2 + O(D^2/p),
where N_even(D) is the number of mirror-forced pairs in the triangle.
For generic large D, N_even(D) is asymptotic to D^2/4, giving
E[Q_D]_mirror ~ D^2/8 + D^2/(2p).
```

Worked values:


## Individual C_p(a,g)

```plain text
Pure random:
C ~ Poisson(lambda), lambda=1/p.

For M=D(D-1)/2 samples, the maximum is obtained from
M * P(Poisson(lambda)>=t) ~= 1.

Using Stirling:
t log(t/(e lambda)) ~= log M.
Thus
C_max = log(M)/log(p log(M)) + lower order terms.

A 3-sigma anomaly is a value above the Gumbel tail threshold
M*P(C>=t_3sigma) < 0.00135.
```

With mirror forcing, subtract deterministic mirror contribution first and apply the same extreme-value law to the residual.

## Per-stratum predictions

```plain text
(i) Mirror-forced lags:
Mean: deterministic contribution ~1/2 per admissible lag.
Residual max: Poisson extreme law.

(ii) Axis strips min(a,g)<=G:
Number of pairs ~2GD.
Mean pure random ~2GD/p.
Mirror contribution ~GD/4.

(iii) a or g | p-1:
Number of divisor lags tau(p-1).
Mean enhancement = tau(p-1)/p before mirror correction.

(iv) a or g | p+1:
Same formula with tau(p+1).

(v) Parity classes:
(odd,odd),(odd,even),(even,odd),(even,even)
have the same random mean D^2/(8p).
Mirror excess occurs only in even-compatible classes.

(vi) Dyadic ratio classes a/g in [2^j,2^(j+1)):
Pair count is a fixed fraction of D^2.
Mean scales by the same fraction.
```

## Moving resonance detection

```plain text
A thin family with O(1) exceptional lags per prime has no visible effect on band means.

Best statistic ranking:
1. Per-prime stratum maximum standardized by its null quantile.
2. Count of primes whose stratum maximum exceeds the null 99% threshold.
3. Pooled stratum z-score.

For 150 independent primes:
If q=.01 is the null exceedance probability,
X~Binomial(150,.01),
E[X]=1.5,
SD(X)=sqrt(1.485)=1.22.
A count >=8 is already a strong anomaly.
```

## Raw resultant contamination

```plain text
Assume p|b_j has probability 1/p independently.
For a diameter D triangle, a zero at j pollutes approximately D-j edges.

Expected number of polluted triangles per prime:
E = D/p.

At D=sqrt(p) log(p):
E = log(p)/sqrt(p).

Expected raw-vs-regular gap:
Delta_raw ~= sum_{j<=D}(D-j)/p
          = D(D-1)/(2p).

For D=sqrt(p)log(p):
Delta_raw ~= (log(p))^2/2.

This is small compared with the full raw triangle size and is not a reliable
signal. Raw resultant counts are therefore non-diagnostic at these scales.
```

# Least-confident derivation

The least-confident step is the exact mirror correction constant. The 1/2 contribution assumes every even-gap collision has exactly one deterministic reflected partner; stabilizers and fixed points may change lower-order constants.

# Likely shared blind spot

The experiment design may underweight thin algebraic families. A resonance supported on O(1) lags per prime will disappear in averaged Q_D statistics. The primary audit should therefore include per-prime extreme statistics and pre-registered thin strata (p-1, p+1, CM splitting layers) rather than only global means.
