# 2. Exact Padé ledger

Let

```plain text
M_(k,l) = binom(k,l) Delta^(k-l) A_l,
0<=l<=k<=H.
```

For numerator degree a put

```plain text
b=H-a,
R_(H,a)=M[a+1..H,0..b].
```

This is a b x (b+1) integer matrix. Let delta_(H,a) be the gcd of its maximal minors. Its signed cofactor vector divided by delta_(H,a) is the primitive denominator coefficient vector q_(H,a).

For the evaluation point n=3H+1, define

```plain text
w_l(n)=sum_(k=l)^H binom(n,k) M_(k,l).
```

Then the exact primitive value is

```plain text
P_(H,a)(n)
 = (-1)^b det([R_(H,a);w(n)]) / delta_(H,a).       (2.1)
```

The original script recomputes all b+1 maximal cofactors separately for every a. A Bareiss determinant costs cubic arithmetic operations in a matrix of order about H; the family calculation therefore performs on the order of

```plain text
sum_(a=0)^A (H-a) separate large determinants,
```

before it evaluates any numerator. At A of order H^(2/3), this is the wrong repeated work.

# 3. One shared elimination for the whole family

Reverse the bottom rows once and form the master matrix

```plain text
K_(i,l)=M_(H-i,l),
0<=i<H,
0<=l<=H.                                           (3.1)
```

For b=H-a, the block R_(H,a) is exactly

```plain text
K[0..b-1,0..b].                                    (3.2)
```

Thus every member of the growing family is a nested prefix-kernel problem in one matrix.

## Lemma 3.1 — shared fraction-free elimination

Assume the nested flag minors

```plain text
tau_b=det K[0..b-1,0..b-1]
```

are nonzero for the required values of b. Perform one pivot-free Bareiss elimination on the full H x (H+1) matrix K, obtaining an upper trapezoidal matrix U.

For each b, set q_b=1 and solve backwards:

```plain text
q_i
 = -[sum_(l=i+1)^b U_(i,l) q_l] / U_(i,i),
0<=i<b.                                             (3.3)
```

Clear the common denominator of (q_0,...,q_b) and divide its integer coefficient gcd. The resulting vector is exactly the primitive denominator vector for the Padé pair of numerator degree a=H-b, up to one global sign.

### Proof

Bareiss elimination uses only preceding rows and columns. Therefore its first b elimination stages on the full matrix agree exactly with Bareiss elimination on the prefix in (3.2). Nonvanishing of tau_1,...,tau_b makes every displayed diagonal denominator nonzero.

Equation (3.3) gives a nonzero rational vector in the kernel of R_(H,a). Since tau_b is nonzero, the matrix has rank b, so its kernel is one-dimensional. Clearing denominators and dividing the coefficient gcd therefore gives the unique primitive integral kernel vector, which is the signed cofactor vector divided by delta_(H,a).

The numerator coefficients are

```plain text
p_k=sum_(l=0)^b M_(k,l)q_l.                        (3.4)
```

The kernel equations say p_k=0 for a<k<=H, so the resulting numerator has degree at most a. Since the denominator vector is coefficientwise primitive, the combined (P,Q) coefficient vector is primitive as well. This proves the claim.

## Complexity

Ignoring coefficient bit growth, the arithmetic-operation count becomes

```plain text
one elimination:             O(H^3),
A+1 back substitutions:      O(A H^2),
numerator/evaluation checks: O(A H^2).              (3.5)
```

The cofactor implementation instead has an extra factor of order H, because it computes every kernel coordinate as a separate determinant.

## Important normality caveat

The general Padé kernel has rank b, but that does not automatically prove that the particular flag minor tau_b is nonzero for every H,b. The signed Newton matrix is not totally positive; the repository already contains a negative consecutive order-six minor. The implementation therefore checks each pivot and stops rather than silently changing the answer.

A completely pivot-robust fallback is straightforward: for a failed prefix, run one pivoted exact nullspace elimination for that b. This still replaces b+1 cofactor determinants by one elimination, but that fallback was not exercised by the unavailable runner. Consequently the committed branch is correctly left as a draft rather than represented as validated production code.

# 4. Exact normalization and validation ledger

The committed scanner is designed to verify all of the following before accepting an output.

## 4.1 Primitive denominator

After denominator clearing it checks

```plain text
gcd(q_0,...,q_b)=1.                                (4.1)
```

This already proves primitivity of the whole pair, because a prime dividing every coefficient of P and Q would in particular divide every q_l.

## 4.2 Padé equations

For every family member it verifies the high Newton coefficients:

```plain text
sum_(l=0)^b M_(k,l)q_l=0,
a<k<=H.                                             (4.2)
```

For selected boundary members it also checks every node identity directly:

```plain text
P_(H,a)(s)=A_s Q_(H,a)(s),
0<=s<=H.                                            (4.3)
```

## 4.3 Two independent evaluations

It checks that

```plain text
P_(H,a)(n)
 = sum_(k=0)^a p_k binom(n,k)
 = sum_(l=0)^b w_l(n)q_l.                           (4.4)
```

## 4.4 Exact boundary formulas

For a=0, the primitive numerator is constant and one has the exact identity

```plain text
P_(H,0)(x)=L_H,
L_H=lcm(A_0,...,A_H),                               (4.5)
```

up to sign. The code checks (4.5).

For a=1, it independently recomputes Q850's exact primitive formula

```plain text
P_(H,1)(x)=m_H z_H(x)
```

and checks the evaluated integer up to sign.

## 4.5 Zero-absorber support

For every candidate prime it checks the exact theorem

```plain text
p | G_(H,A)(3H+1)
iff
[3H+1-p in Z_p(H)] or [z_p(H)>A],                  (4.6)
```

where

```plain text
Z_p(H)={s in [0,H]:p|A_s},
z_p(H)=|Z_p(H)|.                                    (4.7)
```

## 4.6 Factor ranges

The report script factors the resulting G and separates

```plain text
p<=H,
H<p<=2H,
2H<p<=3H+1,
p>3H+1.                                            (4.8)
```

The final fourth range was added deliberately: G|L_H, but a prime divisor of a prefix Apéry value need not be bounded by 3H+1.

# 5. Two exact global identities

The computation suggested two formulas that are symbolic and require no experiment.

## Lemma 5.1 — lcm upper carrier

For every A>=0,

```plain text
G_(H,A) divides L_H=lcm(A_0,...,A_H).               (5.1)
```

### Proof

The family gcd includes the a=0 member, and (4.5) gives

```plain text
G_(H,A) | P_(H,0)(3H+1)=L_H.
```

This is exact, but it does not explain the collapse: L_H is exponentially or worse larger than the observed gcd.

## Lemma 5.2 — exact candidate-window radical

For every candidate prime

```plain text
2H<p<=3H+1,
j=3H+1-p,
```

one has

```plain text
p | G_(H,A)
iff
[p|A_j] or [z_p(H)>A].                              (5.2)
```

Consequently, if

```plain text
z_p(H)<=A
for every candidate prime,                          (5.3)
```

then

```plain text
rad_(2H<p<=3H+1) G_(H,A)
 = product_{
     0<=j<=H,
     p=3H+1-j prime,
     p|A_j
   } p.                                             (5.4)
```

### Proof

This is Section 160's zero-absorber theorem. If p|A_j, every interpolation numerator vanishes at j, and every degree-at-most-H Newton polynomial has the same value at j and j+p=3H+1 modulo p. Hence p divides every family value.

Conversely, if p is not a target and z_p(H)<=A, use the family member with numerator degree a=z_p(H). Its nonzero reduction has exactly the prefix Apéry zero nodes as interpolation roots, so it does not vanish at j. Thus p cannot divide the family gcd.

Equation (5.4) is the reproducible invariant that explains the support collapse in the candidate window. It is already exact. It does not estimate the logarithm of that support, and it says nothing about the small-prime powers dominating the full gcd.

# 8. Exact refutations of proposed closed formulas

## 8.1 Not a divisor of A_(3H+1)

At H=25,

```plain text
G_(25,9)=5^2*17*19,
n=76.                                               (8.1)
```

Lucas gives

```plain text
A_76=A_4 A_0 mod 19.
```

Since

```plain text
A_4=33001=-2 mod 19,
```

one has

```plain text
19 does not divide A_76.                            (8.2)
```

Thus neither G nor its full radical is generally a divisor of A_(3H+1).

## 8.2 Not a divisor of the binomial carrier

At H=10,

```plain text
G_(10,5)=25,
B=binom(31,11).                                    (8.3)
```

Kummer's theorem gives one base-5 carry in 11+20, so

```plain text
v_5(B)=1.
```

Therefore

```plain text
25 does not divide binom(31,11).                   (8.4)
```

The full integer gcd is not a divisor of the usual binomial carrier.

## 8.3 Not equal to the direct Apéry core

At H=10, the direct candidate support is empty but

```plain text
G_(10,5)=25>1.                                     (8.5)
```

Thus the full gcd is not the direct q=1 radical. Only its candidate-window radical is purified by (5.4).

## 8.4 Not one ordinary Smith factor

Equation (2.1) gives

```plain text
v_l(G_(H,A))
 = min_(0<=a<=A) [
     v_l(det([R_(H,a);w(n)]))-v_l(delta_(H,a))
   ].                                               (8.6)
```

A single determinantal divisor records a minimum of unshifted minor valuations. Formula (8.6) is instead the lower envelope of valuations shifted by a different delta_(H,a) at every degree.

The first exact saturation data already vary irregularly:

```plain text
H=2: (delta_(2,0),delta_(2,1),delta_(2,2))
     =(1,8,1),

H=3: (delta_(3,0),delta_(3,1),delta_(3,2),delta_(3,3))
     =(5,8,8,1).                                    (8.7)
```

Therefore an identity for the raw bordered determinants cannot simply be divided by one common Smith factor.

## 8.5 Ordinary resultants and subresultants lose the marked root

After content removal, once a is at least the prefix zero count, every projective numerator has the common factor

```plain text
D_p(x)=product_(s in Z_p(H))(x-s)
```

modulo p. Consequently ordinary pairwise resultants vanish for every prime having any prefix Apéry zero, not only when the marked point j=3H+1-p is one of those zeros.

The first nonzero polynomial subresultant recovers D_p(x) up to a unit. Evaluating it at j detects the target exactly, but both the relevant subresultant index and the evaluation point depend on p. Globalizing that construction recreates the growing-family evaluation problem rather than compressing it.

## 8.6 The raw Apéry recurrence does not yield a primitive short recurrence

The later recurrence audit proves a fixed finite stencil for M and for raw compound minors. At the right boundary it introduces shifted minors outside R_(H,a). If

```plain text
sigma_(H,a)
 = gcd(delta_(H,a), all recurrence-boundary shifted minors),

q_(H,a)=delta_(H,a)/sigma_(H,a),                   (8.8)
```

then every recurrence for primitive bordered values acquires the quotients q_(H,a). No subexponential bound for these quotients is known.

Thus a low-displacement raw matrix does not imply a low-order recurrence for the primitive gcd. Any proposed recurrence that writes only raw minors and then divides by delta_(H,a) termwise without tracking (8.8) is invalid.

# 9. What the fast computation can and cannot discover

The fast scan is useful for three sharply separated tasks.

## It can determine

```plain text
- the full integer G_(H,A);
- its prime powers and the requested ranges;
- whether the target factors have exponent one or more;
- the sequence of low- and middle-prime remnants;
- failures of candidate closed formulas;
- empirical recurrences, if any, for those remnants.   (9.1)
```

## It cannot by itself prove

```plain text
log rad_(2H<p<=3H+1) G_(H,A)=o(H),
```

because by (5.4) that is exactly the original direct q=1 moving-prime theorem once the absorber is inactive.

Nor can finite few-bit data prove that the full integer gcd remains subexponential. Section 162 constructs sequences with the correct first-order Apéry-like growth for which every universal interpolation family retains a linear candidate-prime weight. Any proof must use the actual Apéry recurrence or Dwork geometry in a way that survives primitive saturation.

# 10. Precise remaining lemma

The support problem is already exact. The genuinely smaller unresolved arithmetic statement exposed by the family is the following.

```plain text
Primitive bordered-envelope lemma.

Let A_H=ceil(H^(2/3)), n=3H+1, and write

B_(H,a)=det([R_(H,a);w(n)]).

Prove either

sum_l log(l) *
  max(0,
      min_(0<=a<=A_H)
        [v_l(B_(H,a))-v_l(delta_(H,a))])
=o(H),

or only its restriction to primes l>2H.             (10.1)
```

The second version is exactly sufficient. By (5.4), after the zero-count threshold it is equivalent to the direct q=1 theorem, but it packages the target into the lower envelope of primitive bordered valuations rather than into one huge certificate.

A recurrence-specific version, strictly smaller than estimating the values directly, is:

```plain text
Recurrence-saturation transport lemma.

For 0<=a<=A_H, control the boundary quotients

q_(H,a)=delta_(H,a)/sigma_(H,a)

strongly enough that an integral recurrence combination of the
primitive bordered values has logarithmic height o(H) and is nonzero.   (10.2)
```

Q888's stencil proves that only a fixed-width shifted-minor family enters sigma_(H,a). What is missing is arithmetic control of the quotient, not another matrix identity.
