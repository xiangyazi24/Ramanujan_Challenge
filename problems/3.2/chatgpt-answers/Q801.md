# 8. Why the named determinant identities do not compress

## 8.1 Desnanot–Jacobi

Desnanot–Jacobi relates neighboring minors of a larger matrix:

[

det M,det M_{ij}^{ij}

=

det M_i^idet M_j^j-

det M_i^jdet M_j^i.

]

Applied here it can rewrite (D_2) as a quotient or difference of adjacent minors only after introducing additional minors.  At a bad prime every row carries one factor (A_j), so every order-two minor carries (A_j^2); at a good prime the selected minor is a unit.  Any integral cancellation of a common factor therefore removes either a universal factor, which good primes already rule out, or one of the desired selective factors.  The identity changes coordinates in the determinantal ideal; it does not lower its selective degree.

## 8.2 Christoffel–Darboux

A Christoffel–Darboux collapse requires a common three-term recurrence in the polynomial degree and the correct adjacent normalization.  Here the two columns are not adjacent orthogonal-polynomial evaluations: one is a positive prefix moment and the other is a cutoff-dependent alternating Hasse coefficient.  Their weights differ by the moving factor

[

(-1)^{J-1-k}binom{k+J}{k}binom{J-1}{k}.

]

The Legendre recurrence acts on (Q_N), but after truncation and multiplication by the Franel transform it produces boundary terms of exactly the same scale as (2.3).  No two-term boundary eliminating the exponential carrier follows.

## 8.3 Andreief

The Franel numbers admit a positive moment representation, so (2.2) is a positive moment.  But (2.3) uses a signed, (J)-dependent transform.  An Andreief determinant formula therefore yields a signed double integral whose kernel is positive by (4.5) but whose measure factor alternates.  It is not a square of a Vandermonde against a positive product measure.  Andreief supplies a representation, not a sign or small-height theorem.

## 8.4 WZ and creative telescoping

Every ordinary WZ relation is linear in the two ray rows.  Modulo a bad prime both rows have the same scalar factor (A_j); a primitive linear boundary therefore retains one selective factor, not two.  To retain (p^2) one must take an exterior square, determinant, resultant, or another degree-two invariant.  Its local degree and selective order are then both two.  A second factor from a linear telescope would require a new congruence modulo (p^2) for the quotient rows, exactly the escape isolated in Q777.

# 9. Recurrence status

Each entry (C_d(N,J)) is holonomic in (N) for fixed (J,d), because it is a finite hypergeometric–Franel sum and the Franel sequence is P-recursive.  Consequently (D_2(n,J)), for fixed (J), is P-recursive in (n) by closure of holonomic sequences under products and differences.

This abstract recurrence statement is not a compression theorem.  Its order and polynomial coefficients grow with (J), and in the moving range (Jasymp n) it is not a fixed recurrence.  A useful recurrence would have to be uniform in the diagonal pair ((n,J)) and expose a boundary of subexponential height.  No such recurrence follows from the current all-cutoff block identity.

# 11. Reproducible exact code

The following code constructs the four sums, the determinant, the local valuation test, and the prime-cutoff aggregate.

```python
from math import comb, gcd, isqrt


def C(n: int, k: int) -> int:
    return comb(n, k) if 0 <= k <= n else 0


def franel(k: int) -> int:
    return sum(C(k, a) ** 3 for a in range(k + 1))


def apery(k: int) -> int:
    return sum(C(k, a) ** 2 * C(k + a, a) ** 2
               for a in range(k + 1))


def L(n: int, k: int) -> int:
    return C(n, k) * C(n + k, k)


def coeff0(N: int, J: int) -> int:
    # [c^0] T_(N,J-1)
    return sum(L(N, i) * franel(i) for i in range(J))


def coeffJ(N: int, J: int) -> int:
    # [c^J] T_(N,J-1)
    hi = min(J - 1, N - J)
    if hi < 0:
        return 0
    return sum(
        (-1) ** (J - 1 - i)
        * L(N, i + J)
        * C(i + J, i)
        * C(J - 1, i)
        * franel(i)
        for i in range(hi + 1)
    )


def D2(n: int, J: int) -> int:
    return (
        coeff0(n, J) * coeffJ(n + J, J)
        - coeffJ(n, J) * coeff0(n + J, J)
    )


def vp(x: int, p: int) -> int:
    x = abs(x)
    if x == 0:
        return 10**18
    e = 0
    while x % p == 0:
        x //= p
        e += 1
    return e


def primes_upto(n: int) -> list[int]:
    sieve = bytearray(b"\x01") * (n + 1)
    if n >= 0:
        sieve[0] = 0
    if n >= 1:
        sieve[1] = 0
    for p in range(2, isqrt(n) + 1):
        if sieve[p]:
            sieve[p*p:n+1:p] = b"\x00" * (((n - p*p) // p) + 1)
    return [p for p in range(2, n + 1) if sieve[p]]


def folded_index(n: int, p: int) -> int:
    assert n // 2 < p <= n
    return min(n - p, 2 * p - 1 - n)


def check_local(n: int, p: int) -> None:
    assert n // 2 < p <= n and p > 4
    j = folded_index(n, p)
    d = D2(n, p)
    assert d % p == (4 * pow(apery(j), 2, p)) % p
    if apery(j) % p == 0:
        assert d % (p * p) == 0
    else:
        assert d % p != 0


def prime_aggregate(n: int) -> int:
    out = 1
    for p in primes_upto(n):
        if n // 2 < p <= n:
            out *= gcd(p * p, D2(n, p))
    return out


def bad_radical(n: int) -> int:
    out = 1
    for p in primes_upto(n):
        if n // 2 < p <= n and apery(folded_index(n, p)) % p == 0:
            out *= p
    return out


def regression() -> None:
    # Known q=1 bad triples from the canonical scan.
    for p in (179, 193, 211):
        check_local(321, p)
    for p in (8893, 9319, 11437):
        check_local(11576, p)

    # Exact saturation identity, ignoring only p <= 3.
    for n in range(10, 250):
        lhs = 1
        rhs = 1
        for p in primes_upto(n):
            if n // 2 < p <= n and p > 4:
                lhs *= gcd(p * p, D2(n, p))
                if apery(folded_index(n, p)) % p == 0:
                    rhs *= p * p
        assert lhs == rhs


if __name__ == "__main__":
    regression()
```

# 12. Final theorem-level conclusion

The order-two object is

[

D_2(n,J)=

detbigl([c^{aJ}]T_{n+sJ,J-1}(c)bigr)_{0le s,a<2},

]

with exact formulas (2.2)–(2.5) and double-sum kernel (3.2)–(3.3).  Its determinant kernel is positive, but the Franel/Hasse weight alternates, so no global sign follows from total positivity.  It is integral, has no removable universal (J)-content, is a unit at every q=1 good prime, and has valuation at least two at every q=1 bad prime.

After the strongest exact integral normalization available at prime cutoffs,

[

prod_{n/2<ple n}gcd(p^2,D_2(n,p))=R_1(n)^2cdot O_{{2,3}}(1).

]

Therefore selected constant Hasse minors do not presently cancel the exponential carrier in any proved way.  Their sharp normalized aggregate is exactly the original unknown bad radical squared.  A sub-(2n) or (o(2n)) height theorem for this object is neither weaker nor structurally easier than Problem 3.2’s q=1 moving-zero bound; it is an equivalent reformulation requiring new cross-characteristic arithmetic or a genuine mod-(p^2) quotient-row supercongruence.
