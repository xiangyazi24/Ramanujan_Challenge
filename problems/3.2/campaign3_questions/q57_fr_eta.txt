[q57 LASTSTAND — direct attack on [FR_eta]: any power saving in the dyadic family root count. life2]

TARGET: prove, for the actual Apery orbit and some fixed eta>0, uniformly for sqrt(N) <= D <= N/2:
  T(D) := sum_{D/2 < d <= D} C_d << D^(2-eta),   equivalently  A(D) := |union_{D/2<d<=D} Z_d| << D^(2-eta).
(Any such power saving breaks the 3/2 energy record via (4.12). The truth is T(D) = Theta(D) empirically.)

STATE OF THE ART you must beat (verify, then improve):
1. Degree budget: T(D) <= sum 3(d-1) ~ (9/8) D^2. Zero saving.
2. Cauchy-Schwarz + unconditional triangle bound: with j_r = #returns of row r in the dyadic block, T = sum j_r, sum j_r^2 = T + 2W where W = same-row return pairs, and each return pair (d<d') forces a triangle with gap d'-d, so W <= Q_{2D} <= 264 D^2 (1+log 2D). Then T <= A + sqrt(2 A Q_{2D}). This only converts the problem to bounding A, and A <= T. Net: L-factor savings at best (this is the known COINC/centered-count line), NOT a power saving.
3. Transpose duality: per fixed r, h |-> Delta_{r,h} solves the Apery recurrence (linear combination of solutions), so ZWIN-RESTART gives <= 1+(3/2)(D/2)^(2/3) returns per row. Summed: N D^(2/3) >> D^2. Worse.
4. Solution-space reformulation (verified this session, use freely): r has a return at gap d iff the distinguished solution u^(r) (the recurrence solution vanishing at time r) is proportional to u^(r+d). So T(D) counts self-coincidences of the projective orbit r |-> u^(r) in P^1. The "bad set" B of zero-carrying solutions is itself the image of a second orbit of the same walk; visit-counting of xi in B is IDENTICAL to the original coincidence problem. Naive sparse-set equidistribution is therefore CIRCULAR; you must find a non-circular input.

YOUR TASK (in order):
(i) Find any route to a power saving D^(2-eta) that uses at least one input the abstract padded/scattered word does NOT have. Candidate arithmetic inputs not yet exploited at growing gaps: the addition law N_{h+d}(x) = N_d(x+h)N_{h+1}(x) - (x+h+1)^6 N_{d-1}(x+h+1)N_h(x) (a bilinear rigidity across scales -- can it force root-set correlations between dyadic blocks that word-level constructions cannot mimic?); honest triple poles; the h-recursion of N_h with coefficients A(x+h), B(x+h) (nonautonomous linear recursion IN h -- amplification/Vandermonde over several h?); per-height complete additive character sums |S_h(t)| <= (4h-1) sqrt(p) COMBINED across h <= D via the h-recursion (a "horizontal" large sieve: the N_h are not independent, they satisfy a 3-term recursion -- does a recursion-driven large-sieve inequality exist for root counts of an orbit of polynomials?).
