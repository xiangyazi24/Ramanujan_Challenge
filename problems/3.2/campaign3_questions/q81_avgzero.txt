[q81 LASTSTAND — [AVG-ZERO]: prove sum_{p<=X} |Z_p| = o(X). The cleanest target in the whole campaign. life3]

DERIVED AND MACHINE-VERIFIED HERE TODAY (verify both steps yourself before working; they are short):

1. DIGIT CRITERION. For p prime, Gessel/Lucas b_{mp+r} == b_m b_r (mod p) for 0 <= r < p, iterated over the base-p expansion, gives b_n == prod_i b_{d_i} (mod p); since p is prime,
     p | b_n  <=>  some base-p digit of n lies in Z_p := {d < p : p | b_d}.
   (Verified for all n in [40,140) against every prime in the top window.)
2. EXACT AVERAGING IDENTITY. With TOP(n) := #{p in (n/2, n] : p | b_n} (the top-window prime-factor count of b_n, which is what the master sum of Problem 3.2 charges), writing n = p + r for p in (n/2,n] gives p|b_n <=> r in Z_p, and swapping the order of summation:
     sum_{n <= X} TOP(n)  =  #{ (p,r) : r in Z_p, r >= 1, p + r <= X }   (about sum_{p <= X/2} |Z_p|).
   (Machine-verified: both sides equal 82 at X = 600.)

CONSEQUENCE. The average-over-n version of the main conjecture's top window is EXACTLY the single scalar statement
     [AVG-ZERO]:  sum_{p <= X} |Z_p| = o(X).

STATE OF [AVG-ZERO]:
- TRUTH (measured): sum_{p<=X}|Z_p| = 109 = pi(X) exactly at X=600; mean |Z_p| = 0.912 over the 548 primes below 4000. The zero counts follow the Poisson random floor with mean of order 1, so the truth is ~ X/log X.
- HEURISTIC, exact: sum_{r<X} sum_{p in (r,X]} 1/p = sum_{p<=X} p * (1/p) = pi(X). So the heuristic prediction is exactly pi(X), leaving a full log X of margin below the target o(X) — a bound as weak as << X/log log X suffices.
- UNCONDITIONALLY PROVED: only |Z_p| <= 3 p^{2/3} per prime, which gives sum_{p<=X} 3p^{2/3} ~ X^{5/3}/log X. That is X^{2/3} ABOVE the target. Nothing between X^{5/3}/log X and X is proved. Note this also means the frequently-assumed "almost all n" version of the conjecture is NOT unconditionally known — any averaging argument needs exactly [AVG-ZERO] as input.

EQUIVALENT ARITHMETIC FORM (this is what makes it attractive):
     sum_{p <= X} |Z_p| = #{ (r,p) : r < p <= X, p | b_r } = sum_{r < X} #{ primes p in (r, X] dividing b_r }.
So it asks: on average over r, how many prime factors in the range (r, X] does the Apery number b_r have? Trivially at most log(b_r)/log r ~ 3.5255 r / log r each, giving the useless X^2/log X. The target says: on average O(1/log)-ish, i.e. most b_r have NO prime factor in (r, X].

WHY THIS TARGET IS WORTH YOUR FULL EFFORT: it is a scalar cross-prime counting statement — no mesoscopic scale, no strip, no cocycle, no monodromy. The entire multi-month campaign on this problem has worked at a FIXED prime (energy exponents, fibre multiplicities, gap polynomials, Weil bounds per height); this quantity has never been attacked. It is implied by the conjecture, it is the exact average version, and it has a log X of slack.
