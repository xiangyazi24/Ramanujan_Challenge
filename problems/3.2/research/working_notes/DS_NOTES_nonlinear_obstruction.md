# DS note: nonlinear-phase obstruction CONFIRMED empirically (2026-07-31)

## The question (from Claude's two-prime Weil route)
Claude proposed: the missing theorem is a bounded-conductor l-adic sheaf G_{p,q,d} on A^1
with trace Tr(Frob_m|G) = e_p(b_m)e_q(−b_{m+d}) ⟹ Deligne RH ⟹ two-prime Weil bound
(empirically |Corr| ≤ 2.09√M) ⟹ 4th-moment ⟹ conjecture. She asked DS to attack the
single-prime sheaf G_p (trace e_p(b_m)) from the Dwork/Cartier angle.

## The decisive experiment (Q6272's proposal, DS executed)
Compute the minimal linear-recurrence order of a_m = e_p(b_m) over C. A bounded-conductor
lisse sheaf of rank r has trace satisfying a constant-coefficient recurrence of order r = O(1).

**Result**: Berlekamp-Massey order GROWS with the data window (~T/2), NOT fixed:
- p=11: order 22 (44 terms), 33 (66), 44 (88)
- p=13: 26 (52), 39 (78), 52 (104)
- p=17: 34 (68), 51 (102), 68 (136)
⟹ a_m is NOT generated by any bounded-order linear recurrence over C. (It is eventually
periodic with period ≤ p² since b_m mod p is an order-2 sequence over F_p with state space
F_p² — but the minimal order is > p and grows, so certainly not O(1).)

## Conclusion
- **e_p(b_m) is NOT a bounded-conductor sheaf trace** (would need O(1) order; measured order
  grows with p). The nonlinear-phase obstruction (Q6272, Q6125: "additive character of a
  period = second-level operation, no bounded-conductor Artin-Schreier pullback") is
  CONFIRMED empirically.
- The Dwork/Cartier machinery gives a bounded-conductor object for the PERIOD FAMILY (b_m as
  Frobenius trace on middle cohomology), but NOT for the additive character of the period
  values (m ↦ e_p(b_m)).
- The two-prime correlation's √M bound is therefore NOT reducible to Deligne RH via a standard
  sheaf. It is consistent with the RANDOM-PHASE model (CLT: |random walk of length M| ~ √M;
  measured mean 0.88 ≈ 0.9), which is what all my moment/joint/Gumbel tests already showed.
- **The sheaf construction route (as proposed) is closed.** The √M bound is real but random,
  not sheaf-theoretic.

## What survives
The two-prime Weil bound is empirically true but needs a NON-sheaf proof (or a genuinely new
"nonlinear period phase" sheaf construction that doesn't exist). The random-phase model
remains the best description. The conjecture's proof still needs the missing cross-prime
decorrelation theorem (Apéry large sieve / SG1 small-ball), which is NOT the sheaf.
