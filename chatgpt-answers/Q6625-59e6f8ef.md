# 2. Exact box feedback: the logarithm survives

Use B for the offset-box length, to avoid confusing it with either local D or the global mesoscopic horizon X.

```plain text
Q_p(X)
 << (X/B) ( M(X,B) + S_X ),                         (2.1)
```

where S_X<<X^2 is the total incidence mass and M(X,B) is the same-box pair mass. The initial range and the dyadic long-gap ranges give

```plain text
M(X,B)
 << Q_p(O(B))
    + sum_{B<=H<=X, H dyadic} K_p(H,B).             (2.2)
```

In the only regime capable of preserving power X^2, namely B=X/polylog(X), one has B>>D_c(H) for every contributing top dyadic scale. Thus the Cauchy branch, not the pointwise branch, is the relevant one. The dyadic sum is geometric in H, so it does not introduce a further logarithm:

```plain text
sum_H K_p(H,B)
 << X B sqrt(ell(B)ell(X)).                         (2.3)
```

Together with Q_p(O(B))<<B^2 ell(B), (2.1) becomes

```plain text
Q_p(X)
 << X^2 sqrt(ell(B)ell(X))
    + X B ell(B)
    + X^3/B.                                        (2.4)
```

For example, taking

```plain text
B = X/ell(X)
```

gives

```plain text
first term    << X^2 ell(X),
initial term  << X^2,
incidence term<< X^2 ell(X).                        (2.5)
```

Taking B=X/ell(X)^t with any fixed t cannot improve the first term: since log B and log X are asymptotic, it remains X^2 ell(X). Thus the box conversion preserves exactly one logarithm.

# 4. The mesoscopic statement [MIDPOINT-AC']

## 4.1 Exact raw form

The cleanest bankable formulation is

```plain text
[MIDPOINT-AC']
For X=sqrt(N)L and G_0=cN/(X ell(X)),

B_p^gen(X,G_0)
 = sum_u sum_{h,d>G_0, h+d<=X}
     A_p^gen(u-h,h) A_p^gen(u,d)
 << N.                                               (4.1)
```

Here gen means that the explicit mirror section and the finite fixed-gap skeleton have been removed and estimated separately. Restoring them changes only the O(N) error in the standard slowly growing mesoscopic regime.

By (3.3)-(3.12), (4.1) closes

```plain text
Q_p(X) << N,
X=sqrt(N)L.                                         (4.2)
```

This is neither a restatement of the old K crossover nor a full [WALL-zero] theorem. It is a single positive zero-fiber hinge estimate on the remaining balanced region.

## 4.2 The exact saving required

The abstract clique theorem gives

```plain text
B_p(X,G_0) <= Q_p(X) << X^2 ell(X)
                         = N L^2 ell(X).             (4.3)
```

Therefore the exact relative saving needed over the current combinatorial majorant is

```plain text
Gamma_X = 1/(L^2 ell(X)).                           (4.4)
```

No fixed power is logically necessary. A logarithmic or subpower arithmetic gain of precisely this size would already suffice.

A convenient stronger power form is

```plain text
[MIDPOINT-AC'_rho]
B_p^gen(X,G_0) << X^(2-rho) ell(X).                 (4.5)
```

Substitution of X=sqrt(N)L gives

```plain text
B_p^gen(X,G_0)
 << N L^2 X^(-rho) ell(X).                          (4.6)
```

Thus (4.5) implies (4.1) exactly when (0.12) holds. For L=N^o(1), any fixed rho>0 wins. For a polynomial L=N^lambda, (0.13) is the precise threshold.

## 4.3 Correlation-coefficient implementation

Define the restricted forward and backward multiplicities

```plain text
nu_(G_0,X)^+(u)
 = #{G_0<d<=X : A_p(u,d)=1},

W_(G_0,X)^-(u)
 = #{G_0<h<=X : h<=u, A_p(u-h,h)=1}.               (4.7)
```

Then

```plain text
B_p(X,G_0)
 <= sum_u nu_(G_0,X)^+(u) W_(G_0,X)^-(u).          (4.8)
```

The global norm bounds give

```plain text
||nu_(G_0,X)^+||_2
 ||W_(G_0,X)^-||_2
 << X^2 ell(X).                                     (4.9)
```

Therefore the literal anti-correlation hypothesis

```plain text
sum_u nu_(G_0,X)^+(u) W_(G_0,X)^-(u)
 << X^(-rho)
    ||nu_(G_0,X)^+||_2
    ||W_(G_0,X)^-||_2                               (4.10)
```

implies (4.5), and hence closes MESO-PAIR under (0.12).

However, a statement only at

```plain text
D=D_c(H) asymp H^(1/3)ell(H)                       (4.11)
```

is insufficient by itself. The balanced core contains dyadic rectangles with D ranging from G_0 up to H. To deduce (4.10) from local estimates one needs either:

```plain text
uniform anti-correlation on every balanced dyadic hinge rectangle,
```

or a new reduction showing that all those rectangles feed into the critical face. No such reduction is presently banked. This is the exact correction to the old [MIDPOINT-AC_rho] formulation.

# 5. Comparison with [WALL-zero]

The banked zero-fiber wall gives, for every gap interval I, start interval J, and arbitrary coefficients, a centered operator estimate. Its row-variance corollary is

```plain text
sum_{r in J}
 |d_I(r)-q_I(r)/p|^2
 << p^epsilon |I|.                                  (5.1)
```

Taking the full start range and I=[1,X] gives

```plain text
Q_p(X)
 << X p^epsilon + X^2/p.                            (5.2)
```

At X=sqrt(N)L and L=N^o(1), this is far smaller than N. Thus [WALL-zero] proves [MIDPOINT-AC'] and MESO-PAIR with enormous room at the level of raw counts.

The quantifiers show the strict strength gap:

```plain text
[WALL-zero]:
  every interval,
  every translated rectangle,
  arbitrary signed/complex weights,
  centered operator norm,
  essentially random row variance.

[MIDPOINT-AC']:
  one mesoscopic horizon,
  one positive zero-fiber hinge geometry,
  only the balanced region,
  only enough aggregate saving to reach N.          (5.3)
```

So the raw statement (4.1) is strictly weaker; the converse is false even for abstract incidence arrays.

There is one normalization caveat. The literal uncentered coefficient (4.10) and the centered row variance (5.1) are not formally ordered solely from their displayed forms: [WALL-zero] can make both centered norms small, while an uncentered coefficient can be dominated by deterministic means. After subtracting the uniform 1/p main term and the mirror skeleton, or if one compares the raw count conclusions, [WALL-zero] is unequivocally stronger.

# 6. Attack (i): transitivity and self-reference

Fix a midpoint u. Let

```plain text
A_u = {u-h : backward collision to u},
B_u = {u+d : forward collision from u},

a_u = |A_u|,
b_u = |B_u|.                                        (6.1)
```

Every point in A_u union {u} union B_u has the same color. Transitivity therefore closes the star to a clique. But the cross edges are exactly the midpoint triples:

```plain text
a_u b_u
 = C(a_u+b_u,2)-C(a_u,2)-C(b_u,2).                 (6.2)
```

After summing over u, the left side is the correlation being estimated. Thus transitivity supplies an identity, not a contraction.

The same obstruction appears in every attempted feedback:

1. The internal terms C(a_u,2) and C(b_u,2) are precisely the two norm energies already bounded by Q_p(D) and Q_p(2H).

1. A cross triple maps to the endpoint collision at gap h+d, so

```plain text
K_p(H,D) <= Q_p(2H+D),                              (6.3)
```

but the available upper bound on the right is H^2 log H, much weaker than HD log H at the critical short scale.

1. In the inverse-square clique energy, a cross edge has length about H, so all cross edges contribute only about K/H^2. The global energy budget gives again

```plain text
K << H^2 log H,                                     (6.4)
```

not an anti-correlation gain.

1. If a translated short-gap norm is expanded, its pair term is itself a K-type count. Substituting this into Cauchy inserts K with a positive sign under a square root. The resulting inequality has the schematic form

```plain text
K <= A sqrt(B+K),                                   (6.5)
```

which yields an upper bound of the old size or worse; it does not produce theta<=f(theta)<theta for the correlation coefficient.

There is also an abstract obstruction. One can place the entire short-forward and long-backward multiplicity on the same small set of midpoints while preserving the separate one-sided norm bounds. Equality transitivity does not forbid correlation coefficient one. Any strict defect therefore needs arithmetic distribution, not another clique identity.

Verdict for route (i): no self-referential bootstrap closes. The feedback is tautological or has the wrong sign.

# 7. Attack (ii): mirror and parity

The explicit mirror collision has equation

```plain text
2r+s = p-1                                             (7.1)
```

for an edge from r to r+s, subject to the established endpoint/parity convention.

For a forward short edge from u to u+d, the mirror equation is

```plain text
2u+d = p-1.                                         (7.2)
```

For a backward long edge from u-h to u, it is

```plain text
2(u-h)+h = 2u-h = p-1.                              (7.3)
```

If both edges were mirror edges at the same midpoint, (7.2)-(7.3) would give

```plain text
d = -h,                                             (7.4)
```

impossible for positive gaps. Hence

```plain text
mirror x mirror contribution = 0 exactly.           (7.5)
```

This is a genuine structural saving.

The mixed mirror-generic terms are also lower order. There are only O(D) forward-mirror midpoints and O(H) backward-mirror midpoints. Using the pointwise window bounds on the opposite factor gives

```plain text
short-mirror x generic
 << D H^(2/3),                                      (7.6)

generic x long-mirror
 << H D^(2/3).                                      (7.7)
```

At the analytic crossover D asymp H^(1/3)ell(H), these are

```plain text
O(H ell(H)),
O(H^(11/9) ell(H)^(2/3)),                           (7.8)
```

whereas the Cauchy scale is

```plain text
H^(4/3) ell(H)^2.                                   (7.9)
```

For the global horizon X, the same argument bounds the entire mirror-generic contribution by

```plain text
O(X^(5/3)).                                         (7.10)
```

At X=sqrt(N)L with L=N^o(1), this is N^(5/6+o(1))=o(N). Thus the mirror skeleton can and should be removed before formulating [MIDPOINT-AC'].

Parity only makes this skeleton thinner. It does not force generic Z_d supports to be disjoint from generic backward windows. The reflection involution pairs positive incidences; because the count is nonnegative, it supplies no cancellation in the generic-generic term.

Verdict for route (ii): useful exact cleanup, but not the main arithmetic gain. It kills mirror-mirror and power-saves mirror-generic, leaving the generic balanced hinge untouched.

# 10. Required confidence audit

## (a) Least-confident step

The power/log fixed-point calculation and the exact midpoint identity are the most robust parts. The step I would audit first is the global reduction (3.3): both orientations of the adjacent-gap triangle, the dyadic boundary h+d<=X, and overlap at min(h,d)=G_0 must be written with the project's exact nonwrapping conventions. Positivity makes all boundary enlargements safe, and the exponents are stable, but this is the one place where a missing orientation or an extra dyadic factor could alter the displayed constant.

A second, conceptual warning is crucial: a local estimate only at D=D_c(H) does not imply the global [MIDPOINT-AC'] written here. Any claim of that implication needs a separate all-aspect-ratio reduction. I have deliberately not assumed one.

## (b) Likely shared blind spot

The shared blind spot is conflating three different objects:

```plain text
1. the norm-pointwise crossover D_c(H),
2. the largest near-wall width G_0 allowed by the target O(N),
3. the full balanced midpoint hinge left after removing that strip.  (10.1)
```

At q=16/7, it was natural to advertise the crossover face as the next target. At q=2, that face moves to H^(1/3)log H, but the stronger HD log H estimate already controls a much wider strip, up to G_0=X/(L^2log X) at the top mesoscopic scale. Therefore the true residual is not “more cancellation at the crossover.” It is uniform arithmetic incompatibility across the entire balanced hinge region.

A closely related blind spot is normalization. The uncentered positive correlation sum nu W, the centered [WALL-zero] row variance, and the raw balanced hinge count are not interchangeable without subtracting the uniform main term and the mirror skeleton. Once these are separated, the hierarchy is clear:

