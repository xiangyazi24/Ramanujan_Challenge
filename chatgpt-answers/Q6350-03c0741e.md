## 2.2 Removable singularity: use dslope

The weaker theorem

```javascript
Complex.integral_boundary_rect_eq_zero_of_differentiable_on_off_countable
```

is not enough for the raw Barnes expression: it still requires continuity on the closed rectangle. The integer is not merely an exceptional differentiability point under Lean's totalized division.

Suppose on the strip around the integer m one has

```plain text
Phi H z = (z-m)² B z
```

with B holomorphic. Define the divided sine by dslope:

```javascript
def sinSlope27 (m : ℤ) (z : ℂ) : ℂ :=
  dslope (fun w : ℂ => Complex.sin ((Real.pi : ℂ) * w)) (m : ℂ) z

def removableBarnesIntegrand27
    (m : ℤ) (B : ℂ → ℂ) (z : ℂ) : ℂ :=
  B z * (((Real.pi : ℂ) / sinSlope27 m z) ^ 2)
```

For z ≠ m, dslope_of_ne gives

```plain text
sinSlope27 m z = sin(pi z)/(z-m),
```

so the extension equals the raw integrand. At z=m, dslope_same gives the derivative

```plain text
pi * cos(pi m) = (-1)^m * pi ≠ 0.
```

The relevant exact Mathlib declarations are:

```javascript
Complex.differentiableOn_dslope
dslope_of_ne
dslope_same
continuousAt_dslope_same
Complex.sin_eq_zero_iff
Complex.sin_ne_zero_iff
```

The dslope construction is shorter than Function.update plus limUnder. Mathlib does have

```javascript

Complex.differentiableOn_update_limUnder_of_isLittleO
Complex.differentiableOn_update_limUnder_of_bddAbove
```

in RemovableSingularity.lean, but those create extra limit bookkeeping and are unnecessary here.

Recommended project lemmas:


# 4. Transfer the Zeilberger certificate to the integral

State the degree-six certificate first as a denominator-cleared polynomial identity over ℚ; prove it by ring. Then derive the rational identity on 0 < t.re, where all denominator factors t+j are nonzero.

Use the cancelled certificate


Recommended theorem stack:

```javascript

theorem zudilinR_telescoper27
    (n : ℕ) (hn : 2 ≤ n) {t : ℂ} (ht : 0 < t.re) :
  (alpha27 n : ℂ) * zudilinR27 (n + 1) t
    - (beta27 n : ℂ) * zudilinR27 n t
    + (gamma27 n : ℂ) * zudilinR27 (n - 1) t
    - (delta27 n : ℂ) * zudilinR27 (n - 2) t =
  zudilinS27 n (t + 1) - zudilinS27 n t

theorem zudilinPhi_telescoper27
    (n : ℕ) (hn : 2 ≤ n) {t : ℂ} (ht : 0 < t.re) :
  (alpha27 n : ℂ) * zudilinRPhi27 (n + 1) t
    - (beta27 n : ℂ) * zudilinRPhi27 n t
    + (gamma27 n : ℂ) * zudilinRPhi27 (n - 1) t
    - (delta27 n : ℂ) * zudilinRPhi27 (n - 2) t =
  zudilinPhiOp27 (zudilinS27 n) (t + 1) -
    zudilinPhiOp27 (zudilinS27 n) t
```

Do not assume the second theorem follows by simp [deriv]. Either:

- prove the value and derivative rational identities separately by denominator clearing and ring, or

- prove local equality near each positive-half-plane point and use the EventuallyEq.deriv_eq API.

The first option is more predictable.

Integrating the right side on Re t=1/2, substitute u=t+1 in the first term. It becomes the S_n integral on Re u=3/2. The cancelled expression for S_n contains (t-1)^3 for n≥2, so the one-strip theorem shifts it back to Re t=1/2; the difference is zero.

Thus:

```javascript

    (n : ℕ) (hn : 2 ≤ n) :
  (alpha27 n : ℂ) * zudilinCommonBarnes27 (n + 1)
    - (beta27 n : ℂ) * zudilinCommonBarnes27 n
    + (gamma27 n : ℂ) * zudilinCommonBarnes27 (n - 1)
    - (delta27 n : ℂ) * zudilinCommonBarnes27 (n - 2) = 0
```

Make a separate theorem matching these coefficients and indices to the existing source recurrence. This is worth an explicit ring lemma; an index or factor-of-two mismatch here would invalidate recurrence uniqueness.

## 5.1 Pole master integral

Define

```javascript

    ∫ y : ℝ,
```


```plain text
exp(-(r+1)x) * (x+x²/2)/(1-exp(-x)).
```

# Hidden-gap checklist

1. Raw removable singularity: mathematically removable does not mean continuous under Lean's totalized division. Use the dslope extension.

1. Existing shifted-coordinate derivative lemmas: their half-plane assumptions do not cover the common t line after translating back to s; define and differentiate R_n directly.

1. Log derivative at triple zeros: invalid as a proof device because numerator inverses appear. Use product differentiation or explicit rational derivatives.

1. Horizontal sides: the fixed-line cosh estimate is not a horizontal-strip estimate. Prove polynomial growth times exponential kernel decay.

1. Applying Phi to the certificate: requires a derivative certificate, not merely the value identity.

1. Certificate normalization: explicitly match alpha,beta,gamma,delta to the cleared recurrence in Problem27.lean, including the factor 2 and indexing.

1. Pole evaluation: Fourier transform still needs Laplace representations, absolute integrability, Fubini, geometric-series interchange, and zeta-tail rewriting.

1. Second moment: the piecewise Fourier closed form is not directly twice differentiable syntactically; patch ξ/sinh(pi ξ) at zero before differentiating.

1. Complex-to-real transfer: prove the equality in ℂ, then use Complex.tendsto_ofReal_iff or real parts to obtain the real decay theorem.

1. Build integration: add the Barnes normalization/closure import to RamanujanChallenge.lean.
