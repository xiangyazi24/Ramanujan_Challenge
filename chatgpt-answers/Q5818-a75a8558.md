## 1. Target final Lean theorem

The final theorem should not be an existential or abstract reconstruction statement. It should express the concrete knot statement:

```
∫_[alpha, beta] (log x * dy/y - log y * dx/x) = 4 * pi^2 / 85
```

with all objects defined internally.

Required concrete definitions:

1. **The knot curve**
   - Define the concrete `A_7_2(M,L)` polynomial.
   - Define the specified real branch `L = y(x)` on the interval.
   - Prove existence, uniqueness, and regularity of that branch on `[alpha,beta]`.

2. **The endpoints**
   - Define `alpha` as the selected root of the endpoint equation.
   - Define `beta` similarly.
   - Prove the ordering and isolation facts needed for the integral.

3. **The integral**
   - Define the real improper/ordinary integral of the differential form.
   - Prove integrability and identify it with the regulator difference.

4. **The regulator chain**
   - Define the tetrahedron shapes of the chosen triangulation.
   - Define the Rogers/Bloch regulator expression.
   - Prove the Neumann–Zagier differential identity for the concrete deformation.

5. **The arithmetic evaluation**
   - Prove the endpoint regulator value, not merely assume a torsion statement.
   - Prove the certified numerical enclosure or an exact alternative certificate.

A correct final theorem would have no parameters like `x`, `D`, `torsion`, or `numeric` unless those parameters are eliminated by preceding concrete definitions and proofs.

## 3. Route comparison

Verdict: infeasible as the shortest route.

This creates a large algebraic K-theory development: extended Bloch groups, flattenings, torsion of `K_3^ind`, and comparison with regulators. It is mathematically natural but not appropriate for closing this challenge theorem.

### Route B — Direct analytic/algebraic certificate

Verdict: preferred.

Avoid the general theorems and prove only the concrete identities needed for this knot:

- concrete algebraic number fields;
- concrete shape identities;
- concrete regulator differential identity;
- concrete certified numerical enclosure.

This sacrifices generality but matches Lean's strengths.

### Route C — Keep abstract regulator theorem and add assumptions

Verdict: rejected as final result.

It is useful infrastructure, but not a solution. The assumptions carry the mathematical burden.

### Route D — Vacuous witnesses / renamed assumptions

Verdict: rejected.

Examples that do not count:

- proving `∃ x, x = -4/85`;
- defining an abstract `x` as the integral value without proving the integral exists;
- replacing torsion/numerical hypotheses by renamed propositions.
