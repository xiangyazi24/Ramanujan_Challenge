# 0. Shared notation and the exact gauge-invariant return extractor

Let the pure rank-three block be A(t), the first extension source be u_plus(t), and a dual extension source be u_minus(t). A biextension is represented in a 1+3+1 filtration by a rank-five matrix.

At the index-transfer level write a return matrix in block form as

```plain text
R_(r,h) =
[
  [1, V_(r,h), W_(r,h)],
  [0, M_(r,h), U_(r,h)],
  [0, 0, 1]
].
```

Here:

```plain text
M_(r,h) = pure return matrix,
U_(r,h) = first-extension transport,
V_(r,h) = dual-extension transport,
W_(r,h) = central quadratic transport.
```

For local step matrices

```plain text
R_j =
[
  [1, V_j, W_j],
  [0, M_j, U_j],
  [0, 0, 1]
],
```

composition is completely explicit:

```plain text
M_21 = M_2*M_1,
U_21 = M_2*U_1 + U_2,
V_21 = V_1 + V_2*M_1,
W_21 = W_1 + W_2 + V_2*U_1.
```

The last term is the crucial nonlinear term. Iterating gives

```plain text
W_(r,h)
  = sum_j W_j
    + sum_{r <= i < j < r+h}
        V_j * transported(U_i).
```

This quadratic cross term is the first place where information can survive the linear death identity (D1).

Suppose a nonmirror base return gives an eigenline L of M_(r,h) with eigenvalue lambda. Let P_L be the projector onto L, and put

```plain text
Q_L = I - P_L.
```

Assume the complementary operator is invertible:

```plain text
Q_L*(M_(r,h)-lambda*I)*Q_L is invertible on im(Q_L).
```

Define the canonical split by solving

```plain text
x = -inverse_Q(M-lambda*I) * Q_L*U,

y = -V*Q_L * inverse_Q(M-lambda*I).
```

Conjugate R_(r,h) by the upper-unipotent gauge that uses x,y to kill the complementary parts of U,V. The remaining central entry is, by definition,

```plain text
Hol_(r,h) = CentralSplit(R_(r,h), L).
```

With one common sign convention this is the Schur-complement expression

```plain text
Hol_(r,h)
  = W_(r,h)
    - V_(r,h)*Q_L
      * inverse_Q(M_(r,h)-lambda*I)
      * Q_L*U_(r,h).
```

The implementation should define Hol by the conjugation algorithm, then verify this displayed formula. That avoids a sign mistake caused by row/column conventions.

This Hol is the common target for candidates (a), (b), and (d). It is invariant under changes of the local splitting, whereas U, V, and W separately are not.

Exceptional repeated-eigenvalue returns should be separated exactly as mirror/center returns are separated in the current energy theorem.

# 7. A fundamental obstruction every candidate must pass

Suppose a universal characteristic-zero expression J_h is built only from the same connection algebra as N_h, and suppose it vanishes at every algebraic return root. Then, after squarefree reduction,

```plain text
N_h^prim divides J_h.
```

Such a construction cannot yield a gcd saving.

Therefore a successful invariant must use at least one genuinely arithmetic ingredient:

```plain text
p-dependent Frobenius,
syntomic regulator normalization,
quantized period lattice,
or a nontrivial dual motivic class.
```

This is why the universal T-translation module dies and why the p-dependent version of candidate (c) is the only surviving contiguity variant.

# 8. What a positive result would imply

If one proves

```plain text
R_h(p)
  = #{r : nonmirror pi(r+h)=pi(r)}
  << h^(1-eta+o(1)),
```

then the existing block argument gives

```plain text
E^pi(p)
  << p^2/H + p*H^(1-eta) + p.
```

Optimizing at

```plain text
H = p^(1/(2-eta))
```

gives

```plain text
E^pi(p)
  << p^(2 - 1/(2-eta) + o(1)).
```

Calibration:

```plain text
eta=0      -> exponent 3/2
eta=1/2    -> exponent 4/3
eta>1/2    -> beats the 4/3 threshold
eta=1      -> exponent 1
```

For the small-image version, replace eta by eta-sigma as explained in the executive verdict.

The remaining proof chain is:

```plain text
geometric/motivic construction
  -> arithmetic Frobenius and gauge-invariant Hol
  -> index-side coefficient recurrence
  -> closure or small-image theorem for Hol on returns
  -> gcd/small-fiber bound
  -> block-energy optimization.
```

The third and fourth arrows are the principal walls. Constructing a beautiful height without a closure theorem does not improve energy.

# 9. Answers to the two required questions

## (a) Least certain step

The least certain step is the existence and normalization of an independent dual Apéry cycle whose p-adic syntomic realization pairs with the accepted companion C(t) and whose central residue can be calibrated by

```plain text
kappa_p = -2*zeta_p(3) mod p.
```

The complex/motivic Apéry-extension literature makes this plausible, but the project has not yet extracted the exact cycle, checked that its truncated normal function is the specific solution L(C)=t, or constructed the required integral overconvergent Frobenius lattice.

The second uncertainty is whether any resulting holonomy has a small image on coefficient-index returns. Geometry naturally produces a path-dependent value; it does not automatically quantize that value.

## (b) Likely shared blind spot

The shared blind spot is probably twofold.

1. We may still be treating the geometric parameter t and the recurrence index n as if a canonical comparison functor connected them. Coefficient extraction gives a bridge, but it may turn every finite-rank geometric invariant into another expression in the old return ideal.

1. We may be assuming that nonzero holonomy is useful merely because it is new. For counting, a new high-entropy label is useless. What is needed is a closure/quantization/small-image theorem. The arithmetic statement about the image of Hol_h is at least as important as constructing Hol_h itself.

A third related blind spot is that candidates (a), (b), and (d) may be three coordinate descriptions of one and the same biextension class. Running all three does not provide three independent chances unless an independent dual cycle or an independent arithmetic normalization is introduced.
