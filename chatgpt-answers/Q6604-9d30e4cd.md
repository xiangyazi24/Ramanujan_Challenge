
```text

```

Then

```text
pi(r)=pi(r+h)=pi(r+h+d)
```

```text
pi(u-h)=pi(u)=pi(u+d).
```

Define

```text
Z_d
 = {u : 0 <= u, u+d <= p-2, pi(u)=pi(u+d)},

W_(H,d)(u)
```


## 3.2 The backward-window multiplicity norm

Similarly,

```text
sum_u W_H(u)^2
 = sum_u W_H(u)
   + 2 sum_u choose(W_H(u),2).                      (3.3)
```

The first term satisfies

```text
sum_u W_H(u)
 <= sum_(H<h<=2H) R_h
 << H^2.                                            (3.4)
```

The key point is that every unordered pair counted by

```text
choose(W_H(u),2)
```

injects into the ordinary prefix pair count `Q_p(2H)`.

Indeed, take

```text
H < h_1 < h_2 <= 2H
```

with

```text
pi(u-h_1)=pi(u)=pi(u-h_2).
```

Put

```text
r = u-h_2,
g_1 = h_2-h_1,
g_2 = h_2.
```

Then

```text
0 < g_1 <= H,
H < g_2 <= 2H,
pi(r)=pi(r+g_1)=pi(r+g_2).
```

This is a term of `Q_p(2H)`. The map is injective, since

```text
u = r+g_2,
h_2 = g_2,
h_1 = g_2-g_1
```

recover the original data. Therefore

```text
sum_u choose(W_H(u),2) <= Q_p(2H).                  (3.5)
```

Using the banked `Q` theorem,

```text
sum_u W_H(u)^2 << H^(5/2).                          (3.6)
```

This is the step that looked like a blocker in the question. It is not a blocker: the global `Q_(2H)` estimate is already exactly the needed backward-window second moment.

## 5.2 Near-wall to a new global Q exponent

Partition the gap interval `[1,X]` into boxes of length `L`. For each base point `r`, let `a_(r,j)` be the number of returns whose gap lies in box `j`. The same Cauchy box inequality used in the banked `5/2` proof gives

```text

 << (X/L)
    (same-box pair mass + total incidence mass).    (5.7)
```

The total incidence mass is `O(X^2)`.

For the same-box pair mass:

- the initial range `h=O(L)` contributes `Q_p(O(L)) << L^q p^epsilon`;
- the remaining ranges are covered by `O(log X)` dyadic intervals;
- on each dyadic interval the same-box pairs have separation at most `L`, so (5.5) gives the required `K` bound.

Therefore

```text
same-box pair mass
 << X L^(2-eta(q)+epsilon)p^epsilon
    + L^(q+epsilon)p^epsilon.                       (5.8)
```

Substitution in (5.7) gives

```text
Q_p(X)
 << X^2 L^(1-eta(q)+epsilon)p^epsilon
    + X^3/L
    + X L^(q-1+epsilon)p^epsilon.                   (5.9)
```



The last term is lower order because


for `q>2`.

Thus one iteration sends


# 6. Route 1: fixed-d dispersion and the exact place it breaks

For fixed `d`, define

```text
A_d(h)
 = #{u in Z_d : pi(u-h)=pi(u)}.
```

Then

```text
K_p(H,D) = sum_(d<=D) sum_h A_d(h)
```

with the range restrictions from (1.1).

For fixed `(d,h)`, the count is

```text
#{u : N_d(u)=0, N_h(u-h)=0}.                        (6.1)
```

This is a zero-dimensional common-root problem in one variable `u`, not a curve with a `p`-sized main term. Bezout or gcd gives the already known estimate

```text
A_d(h) <= R_d <= 3(d-1).                            (6.2)
```

There is no Weil square-root gain to extract from a zero-dimensional complete intersection.

Cauchy in `h` gives

```text
(sum_h A_d(h))^2
 <= H sum_h A_d(h)^2.                               (6.3)
```

Expanding the second moment,

```text
sum_h A_d(h)^2
 = sum_(u,u' in Z_d) C_I(u,u'),                     (6.4)
```

where

```text
C_I(u,u')
 = #{h in (H,2H] :
      pi(u-h)=pi(u),
      pi(u'-h)=pi(u')}.                             (6.5)
```

For `u=u'`, this is a one-color backward-window count and is controlled by the window lemma.

For `u!=u'`, put

```text
t = u'-u,
n = u-h.
```

Then (6.5) becomes

```text
#{n in an interval of length at most H :
  pi(n)=pi(u),
  pi(n+t)=pi(u')}.                                  (6.6)
```

This is the exact obstruction: a locked-clock, two-color, one-lag correlation of the deterministic orbit.

For fixed `t` and fixed endpoint colors, the transfer relation gives a necessary rational equation of degree `O(t)`, but this does not close the dispersion:

1. `t` ranges over all differences of roots of `N_d` and can be as large as `p`;
2. there is no banked distribution theorem for those differences;
3. (6.6) is an incomplete interval count;
4. the orbit-value condition `pi(n)=pi(u)` is not removed by the transfer equation;
5. summing fixed-`t` degree or Weil bounds over `u,u'` loses the desired power.

The banked Q6455 codegree curve does not solve (6.6). Q6455 treats an annealed two-clock curve of fixed bidegree `(6,6)`, with the two clock variables independent. Here both orbit tests use the same shift `h`; equivalently, the two clocks are locked to one diagonal. Restricting to that diagonal removes the two-clock averaging that made the Q6455 curve tractable.

Thus route 1 reaches a precise residual, but route 2 bypasses it.

# 8. What remains after the win

The norm-and-box system has a fixed point:

```text
Q exponent      q = 16/7,
near-wall gain eta = 3/5.
```

To go beyond it, one must improve one of the inequalities that was used as a black box:

1. improve the pointwise window exponent `2/3`;
2. improve the global `Q` exponent below `16/7` by another mechanism;
3. prove a true anti-correlation gain in

```text
sum_u nu_D(u)W_H(u)
```

beyond Cauchy.

The critical aspect ratio at the fixed point is

```text
D about H^(5/9).                                    (8.1)
```

Indeed `1/(3eta)=5/9` when `eta=3/5`.

A minimal next residual is therefore:

```text
[MIDPOINT-AC_rho]
For some rho>0, when D is in the critical range
D=H^(5/9+o(1)),

sum_u nu_D(u)W_H(u)
 << H^(-rho)
    (sum_u nu_D(u)^2)^(1/2)
    (sum_u W_H(u)^2)^(1/2).                         (8.2)
```

This is a genuine short-forward versus long-backward anti-correlation at one shared midpoint `u`.

It is strictly weaker than a full `[MESO-BALANCED-PAIR]` theorem in the natural positive-count formulation: MESO-BALANCED-PAIR controls the entire balanced core, while (8.2) controls only one dyadic near-diagonal face with a common midpoint and one critical aspect ratio. The converse fails for abstract incidence arrays: one can make the midpoint faces pseudorandom while concentrating mass on other balanced rectangles or on two-base configurations.

# 11. Required final answers

## (a) Least-confident step

The least-confident part is not the first-step theorem `eta=3/7`; that proof is a direct chain of exact identities and banked inequalities.

The least-confident part is the iteration all the way to every `eta<3/5`, specifically the global covering step from dyadic `K_p(H,D)` to prefix `Q_p(X)`. I supplied the full box calculation, including the initial `h=O(L)` term, and the exponents close correctly. Still, this is the place where an indexing convention or an omitted cross-dyadic boundary family could hide a logarithmic bookkeeping error. Such an error would not affect the unconditional `eta=3/7` theorem; at worst it would weaken the endpoint bootstrap. The machine audit in Section 9 should include a direct global-box decomposition check.

## (b) Likely shared blind spot

The shared blind spot was treating the two factors

```text
nu_D(u)  = short forward return multiplicity,
W_H(u)   = long backward return multiplicity
```

as though no information about their norms was available until a new family theorem was proved.

In fact, the sigma=`1/2` theorem already controls both L2 norms. The backward norm was obscured only because its returns end at `u` rather than start at `u`; the injection (9.4) converts it back to the ordinary forward `Q_(2H)` count.

After this correction, the likely remaining blind spot is more geometric: the first truly new input is not another separate moment bound, but the Cauchy defect between these two multiplicity functions at the critical shared midpoint. That is exactly where a mixed F-crystal or syntomic-regulator realization could matter: it would need to prove that short forward collision bases do not align with long backward high-multiplicity colors.
