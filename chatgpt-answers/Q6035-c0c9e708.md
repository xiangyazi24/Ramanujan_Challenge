# P2.7 source error: an exact Barnes certificate with an explicit geometric bound

## Executive conclusion

Let `b_n,m_n` be the source sequences in the current P2.7 reduction, with

```text
b = (1, 7, 163, ...),
m = (0, 20, 7425/16, ...).
```

In Zudilin's notation, the project sequence `b_n` is his `a_n`, while

```text
m_n = tilde_b_n + double_tilde_b_n.
```

This notation warning matters: Zudilin also uses an undecorated `b_n` for the
irrelevant logarithm numerator. The exact source error required by Lean is

```text
E_n = (zeta(2) + zeta(3))*b_n - m_n
    = tilde_r_n + double_tilde_r_n.
```

For

```text
R_n(t) = ((t-1)(t-2)...(t-n))^3
         / ((n!)^2 * t(t+1)...(t+n))
```

and `c_n=n+1/2`, the exact one-dimensional Barnes representation is

```text
E_n = (pi/2) * integral_{y in R}
        [R_n(c_n+i*y) - (1/2) R_n'(c_n+i*y)]
        / cosh(pi*y)^2 dy.                            (B)
```

Equivalently, using conjugation symmetry,

```text
E_n = pi * integral_{0}^{infinity}
        Re[R_n(c_n+i*y) - (1/2) R_n'(c_n+i*y)]
        / cosh(pi*y)^2 dy.                            (B-real)
```

This is the shortest honest source certificate I found. It is not a positive
integral—the two recessive characteristic roots are non-real, and the source
error changes sign—but it has a completely elementary uniform majorant.
Without using Poincare asymptotics, creative telescoping, or Zudilin's printed
limsup, one obtains the explicit bound

```text
abs(E_n) <= 2048 * (1/2)^n                            (G)
```

for every `n>=0`. Consequently the error is absolutely summable and in
particular tends to zero.

The new proof has only one complex-analysis component: a specialized Barnes
residue lemma establishing (B). Everything after (B) is real-variable
calculus, finite products, and elementary inequalities. The exact bound (G)
is deliberately somewhat loose; its advantage is that it avoids formalizing
the Euler infinite product for `cosh`.

Primary source:

- Wadim Zudilin, [*Approximations to -, di- and tri-logarithms*](https://arxiv.org/pdf/math/0409023), Section 2 and Theorem 2, especially pp. 7–8 of the PDF.

Corroborating later source:

- Simon Dauguet and Wadim Zudilin, [*On simultaneous Diophantine approximations to zeta(2) and zeta(3)*](https://arxiv.org/pdf/1401.5322), Propositions 1 and 3. That paper prints the general Barnes constructions whose small-slope specialization is the 2007 example.

## 1. Exact source normalization

### 1.1 Zudilin's rational function and three series

Section 2 of arXiv:math/0409023 defines, for `n=0,1,2,...`,

```text
R_n(t) = product_{j=1}^n (t-j)^3
         / ((n!)^2 * product_{j=0}^n (t+j)).          (1.1)
```

For `abs(z)<1`, put

```text
r0_n(z) = sum_{nu>=1} z^nu R_n(nu),

r2_n(z) = -sum_{nu>=1} z^nu R_n'(nu),

r3_n(z) = (1/2) sum_{nu>=1} z^nu R_n''(nu).           (1.2)
```

The partial-fraction calculation in the paper gives

```text
r0_n(z) = a_n(z)*Li_1(z) - b0_n(z),
r2_n(z) = a_n(z)*Li_2(z) - b2_n(z),
r3_n(z) = a_n(z)*Li_3(z) - b3_n(z).                  (1.3)
```

At `z=1`, the common coefficient is

```text
a_n = (-1)^n * sum_{k=0}^n
        (-1)^k * binom(n,k) * binom(n+k,k)^3.         (1.4)
```

Whipple's terminating transformation gives the positive form

```text
a_n = sum_{k=0}^n
        binom(n,k)^2 * binom(n+k,n) * binom(n+2*k,n). (1.5)
```

Thus the project denominator is

```text
b_n = a_n.                                            (1.6)
```

The equivalent terminating hypergeometric forms are

```text
b_n = (-1)^n * 4F3(-n,n+1,n+1,n+1; 1,1,1; 1)

    = 5F4(-n,-n,n+1,(n+1)/2,(n+2)/2;
          1,1,1/2,1; 1).                              (1.7)
```

### 1.2 The endpoint is a Barnes regularization

For `n>=1`, the rational function `R_n(t)` has polynomial degree `2*n-1`.
Therefore the three raw series in (1.2), although convergent for `abs(z)<1`,
do **not** in general have termwise limits as `z` tends to `1`. The phrase
"non-sense case z=1" in the paper is literal: the endpoint values are obtained
by Barnes regularization.

The two finite combinations are

```text
L2_n(z) = r2_n(z) - log(z)*r0_n(z),                   (1.8)

L3_n(z) = r3_n(z) - (1/2)*log(z)*r2_n(z).             (1.9)
```

Their Barnes limits are

```text
lim_{z->1-} L2_n(z) = a_n*zeta(2) - b2_n,
lim_{z->1-} L3_n(z) = a_n*zeta(3) - b3_n.             (1.10)
```

It would be incorrect to argue that `log(z)*r2_n(z)->0`; for general `n` the
rational/polylogarithmic pieces diverge separately. The cancellation occurs
inside (1.9). This is the main endpoint subtlety that must be reflected in the
Lean statement.

Set

```text
m_n = b2_n + b3_n.                                    (1.11)
```

Then the desired source error is exactly the sum of the two regularized forms.

## 2. Derivation of the two omitted Barnes integrals

Zudilin prints the required residue mechanism as equation (8) in the preceding
section, then explicitly says that he omits writing the two analogous complex
integrals in Section 2. They can be recovered without guessing.

Let

```text
K(t) = (pi / sin(pi*t))^2.                             (2.1)
```

At an integer `nu`, writing `t=nu+w`,

```text
K(nu+w) = 1/w^2 + O(1).                               (2.2)
```

There is no `1/w` term. Hence, for a holomorphic function `f` near `nu`,

```text
Res_{t=nu} [f(t)*K(t)] = f'(nu).                       (2.3)
```

Fix `0<z<1` and any `C` with `0<C<n+1`. Close the vertical contour to
the right. Because the closure is clockwise, the vertical Barnes integral is
minus the sum of the residues at positive integers.

### 2.1 The zeta(2) form

Apply (2.3) to

```text
f(t)=R_n(t)*z^t.
```

Then

```text
f'(nu)=z^nu*(R_n'(nu)+log(z)*R_n(nu)).
```

Therefore

```text
I2_n(z)
 := 1/(2*pi*i) * integral_{C-i*infinity}^{C+i*infinity}
      R_n(t)*K(t)*z^t dt

  = -sum_{nu>=1} z^nu
      (R_n'(nu)+log(z)*R_n(nu))

  = r2_n(z)-log(z)*r0_n(z)

  = L2_n(z).                                           (2.4)
```

### 2.2 The zeta(3) form

Apply (2.3) instead to

```text
f(t)=R_n'(t)*z^t.
```

This gives

```text
J3_n(z)
 := 1/(2*pi*i) * integral_{C-i*infinity}^{C+i*infinity}
      R_n'(t)*K(t)*z^t dt

  = -sum_{nu>=1} z^nu
      (R_n''(nu)+log(z)*R_n'(nu))

  = -2*r3_n(z)+log(z)*r2_n(z).                        (2.5)
```

Thus

```text
L3_n(z) = -J3_n(z)/2.                                 (2.6)
```

This verifies both the minus sign and the factor `1/2`.

### 2.3 Passing to z=1

Choose the midpoint

```text
C=c_n=n+1/2.                                          (2.7)
```

For fixed `n`, on this line `R_n(t)` and `R_n'(t)` have polynomial growth in
`abs(Im t)`, while `K(t)` decays exponentially. For `1/2<=z<=1`,

```text
abs(z^(c_n+i*y)) = z^c_n <= 1.
```

A single integrable majorant therefore permits dominated convergence as
`z->1-`. Equations (2.4) and (2.6) yield

```text
E2_n := a_n*zeta(2)-b2_n
      = 1/(2*pi*i) * integral_{c_n-i*infinity}^{c_n+i*infinity}
          R_n(t)*K(t) dt,                              (2.8)

E3_n := a_n*zeta(3)-b3_n
      = -1/(4*pi*i) * integral_{c_n-i*infinity}^{c_n+i*infinity}
          R_n'(t)*K(t) dt.                             (2.9)
```

Adding gives

```text
E_n
 = 1/(2*pi*i) * integral_{c_n-i*infinity}^{c_n+i*infinity}
     (R_n(t)-R_n'(t)/2)*K(t) dt.                       (2.10)
```

This is the exact analytic input missing from Theorem 2; the paper prints the
residue mechanism but suppresses these two displayed formulas.

### 2.4 A fixed-contour form

For formalization it can be convenient to shift the contour. Put

```text
F_n(s)=R_n(s+n+1)
      =(s+1)_n^3 / ((n!)^2*(s+n+1)_(n+1)).            (2.11)
```

Since

```text
sin(pi*(s+n+1))^2 = sin(pi*s)^2,
```

(2.10) is equivalently an integral on the fixed line `Re(s)=-1/2`:

```text
E_n
 = 1/(2*pi*i) * integral_{-1/2-i*infinity}^{-1/2+i*infinity}
     (F_n(s)-F_n'(s)/2)*K(s) ds.                       (2.12)
```

The fixed-contour version reduces coercion and interval bookkeeping in Lean.

## 3. Exact real one-dimensional representation

For real `y`,

```text
sin(pi*(n+1/2+i*y)) = (-1)^n*cosh(pi*y).               (3.1)
```

Using `dt=i*dy` in (2.10),

```text
E_n = (pi/2) * integral_{-infinity}^{infinity}
        [R_n(c_n+i*y)-R_n'(c_n+i*y)/2]
        / cosh(pi*y)^2 dy.                             (3.2)
```

The values at `y` and `-y` are complex conjugates. Hence the imaginary part of
the integral is zero and

```text
E_n = pi * integral_0^infinity
        Re[R_n(c_n+i*y)-R_n'(c_n+i*y)/2]
        / cosh(pi*y)^2 dy.                             (3.3)
```

Formula (3.3) is the recommended theorem exposed to the real-variable bounding
layer.

As an independent sign audit, direct high-precision integration gives

```text
n=1:
E2_1 = 7*zeta(2)-23/2,
E3_1 = 7*zeta(3)-17/2,
E_1  = -0.07106320994525494689...,

n=2:
E_2  = 163*(zeta(2)+zeta(3))-7425/16
     = -0.002971888725222334839...
```

The numerical check is not part of the proof; it only confirms the contour
orientation, the derivative sign, and the factor `1/2`.

## 4. Midpoint value and its geometric decay

Define the positive midpoint value

```text
q_n = R_n(c_n).                                       (4.1)
```

This auxiliary `q_n` is unrelated to the project denominator notation. From
the finite product,

```text
q_n = product_{k=0}^{n-1}(k+1/2)^3
      / ((n!)^2 * product_{k=n}^{2*n}(k+1/2)).         (4.2)
```

Equivalently,

```text
q_n = Gamma(n+1/2)^4
      / (Gamma(1/2)^3*Gamma(2*n+3/2)*(n!)^2).          (4.3)
```

In particular,

```text
q_0=2.                                                (4.4)
```

The step ratio is elementary:

```text
q_(n+1)/q_n
 = (n+1/2)^4
   / ((2*n+3/2)*(2*n+5/2)*(n+1)^2).                   (4.5)
```

Moreover

```text
(4*n+3)*(4*n+5)*(n+1)^2 - (2*n+1)^4
 = 32*n^3+71*n^2+54*n+14 > 0.                         (4.6)
```

Equation (4.6) is exactly equivalent to

```text
q_(n+1)/q_n <= 1/4.                                   (4.7)
```

Thus, by induction,

```text
0 < q_n <= 2*4^(-n).                                  (4.8)
```

No Stirling formula is used.

## 5. An elementary uniform bound on the midpoint contour

The purpose of this section is to avoid requiring the Euler/Weierstrass product
for `cosh` in Lean.

### 5.1 Finite product expression

For `t=c_n+i*y`, division by (4.2) gives

```text
abs(R_n(t))/q_n
 = product_{k=0}^{n-1}
     (1+y^2/(k+1/2)^2)^(3/2)
   / product_{k=n}^{2*n}
     (1+y^2/(k+1/2)^2)^(1/2).                         (5.1)
```

Dropping the denominator,

```text
abs(R_n(c_n+i*y))
 <= q_n * P_n(abs(y))^(3/2),                           (5.2)
```

where

```text
P_n(y)=product_{k=0}^{n-1}
         (1+y^2/(k+1/2)^2),    y>=0.                  (5.3)
```

### 5.2 The logarithmic product envelope

For `y>=0`, define

```text
f_y(x)=log(1+y^2/x^2),    x>0.                         (5.4)
```

This is nonnegative and decreasing. For `k>=1`,

```text
f_y(k+1/2)
 <= integral_{k-1/2}^{k+1/2} f_y(x) dx.               (5.5)
```

Therefore

```text
log(P_n(y))
 <= log(1+4*y^2)+integral_0^infinity f_y(x) dx.        (5.6)
```

The remaining improper integral has the exact elementary value

```text
integral_0^infinity log(1+y^2/x^2) dx = pi*y.          (5.7)
```

For `y>0`, substitute `x=y*u`. The constant integral is

```text
I = integral_0^infinity log(1+1/u^2) du.
```

Integration by parts gives

```text
I = 2*integral_0^infinity 1/(1+u^2) du = pi.           (5.8)
```

The boundary term vanishes because

```text
u*log(1+1/u^2) -> 0
```

at both `0+` and `infinity`. Mathlib already contains the improper integral of
`1/(1+u^2)`; this is the only special improper integral needed here.

Combining (5.6) and (5.7),

```text
P_n(y) <= (1+4*y^2)*exp(pi*y).                         (5.9)
```

Since

```text
sqrt(1+4*y^2) <= 1+2*y,
```

we obtain

```text
P_n(y)^(3/2)
 <= (1+2*y)^3*exp(3*pi*y/2).                          (5.10)
```

### 5.3 Combining with the Barnes kernel

For `y>=0`,

```text
cosh(pi*y) >= exp(pi*y)/2.                             (5.11)
```

Consequently, from (5.2) and (5.10),

```text
abs(R_n(c_n+i*y))/cosh(pi*y)^2
 <= 4*q_n*(1+2*y)^3*exp(-pi*y/2).                     (5.12)
```

This is uniform in `n` apart from the explicit factor `q_n`.

## 6. Bounding the derivative and the combined error

On the midpoint line the logarithmic derivative is

```text
R_n'(t)/R_n(t)
 = 3*sum_{j=1}^n 1/(t-j)
   -sum_{j=0}^n 1/(t+j).                              (6.1)
```

Every real-part distance in (6.1) is at least `1/2`. Hence

```text
abs(R_n'(c_n+i*y)/R_n(c_n+i*y))
 <= 6*n+2*(n+1)
 = 8*n+2.                                             (6.2)
```

It follows that

```text
abs(R_n(c_n+i*y)-R_n'(c_n+i*y)/2)
 <= (4*n+2)*abs(R_n(c_n+i*y)).                         (6.3)
```

Let

```text
alpha = pi/2,
M = 1/alpha + 6/alpha^2 + 24/alpha^3 + 48/alpha^4.    (6.4)
```

Expanding `(1+2*y)^3` and integrating term by term gives

```text
integral_0^infinity (1+2*y)^3*exp(-alpha*y) dy
 = M.                                                  (6.5)
```

Indeed,

```text
integral_0^infinity y^k*exp(-alpha*y) dy
 = k!/alpha^(k+1),    k=0,1,2,3.                      (6.6)
```

Using (3.2), symmetry, (5.12), and (6.3),

```text
abs(E_n)
 <= 4*pi*q_n*(4*n+2)*M.                               (6.7)
```

Now apply (4.8):

```text
abs(E_n)
 <= 16*pi*(2*n+1)*M*4^(-n).                           (6.8)
```

The elementary induction

```text
2*n+1 <= 2^(n+1)                                      (6.9)
```

then yields

```text
abs(E_n) <= C*2^(-n),                                 (6.10)
```

where

```text
C = 32*pi*M
  = 64 + 768/pi + 6144/pi^2 + 24576/pi^3.             (6.11)
```

Finally, `pi>3` implies

```text
C
 < 64 + 256 + 6144/9 + 24576/27
 = 17216/9
 < 2048.                                               (6.12)
```

Thus the clean rational bound is

```text
boxed: abs(E_n) <= 2048*(1/2)^n.                      (6.13)
```

This proves more than requested:

```text
Summable (fun n => abs(E_n)),
Tendsto E_n atTop (nhds 0).                            (6.14)
```

### Optional sharper bound

If one is willing to formalize the half-integer Euler product

```text
product_{k=0}^infinity
  (1+y^2/(k+1/2)^2) = cosh(pi*y),                      (6.15)
```

then (5.2) immediately gives

```text
abs(R_n(c_n+i*y)) <= q_n*cosh(pi*y)^(3/2).
```

The same argument then yields the much smaller bound

```text
abs(E_n) <= 32*2^(-n).                                (6.16)
```

I do **not** recommend making (6.15) a dependency merely to improve an irrelevant
constant. The finite-product/integral proof above is more likely to close in
Lean 4.29 with existing analysis infrastructure.

### Layer B: specialized Barnes bridge

Suggested file:

```text
RamanujanChallenge/BarnesSquareKernel.lean
```

Do not build a general meromorphic-residue library. Prove the one lemma needed:

```lean
lemma barnes_sq_kernel_sum_deriv
    (f : ℂ → ℂ) (z : ℝ)
    (hz0 : 0 < z) (hz1 : z < 1)
    (hf : -- rational, no poles in the right half-plane,
          -- polynomial growth on vertical lines) :
  (1 / (2*pi*I)) * verticalIntegral C
      (fun t => f t * (pi / sin (pi*t))^2 * z^t)
    = -∑' ν : ℕ+, deriv (fun t => f t * z^t) ν
```

A specialized proof can be organized as follows:

1. Show `(pi/sin(pi*(nu+w)))^2 - 1/w^2` is holomorphic near `w=0`.
2. Deduce the local circle integral (2.3) from Cauchy's derivative formula.
3. Apply Cauchy–Goursat on a rectangle with small circles removed around the
   finitely many positive integers inside it.
4. Let the circle radii tend to zero.
5. Let the vertical height tend to infinity; the sine kernel gives exponential
   decay.
6. Let the right edge tend to infinity; `z^Re(t)` dominates the fixed polynomial
   growth of `f`.

Mathlib provides rectangle Cauchy–Goursat and Cauchy's derivative formula; this
specialized punctured-rectangle argument is finite and avoids depending on a
generic residue theorem that may not be available in the pinned version.

Apply the lemma twice:

```lean
lemma zeta2_error_barnes (n : ℕ) :
  (zeta2 * b n - b2 n : ℂ)
    = verticalIntegral ... (zR n)

lemma zeta3_error_barnes (n : ℕ) :
  (zeta3 * b n - b3 n : ℂ)
    = verticalIntegral ... (fun t => -(deriv (zR n) t)/2)
```

Then combine them and parameterize the midpoint line:

```lean
lemma sourceError_eq_real_integral (n : ℕ) :
  sourceError n =
    pi * ∫ y in Set.Ioi 0,
      ((zR n (c n + y*I) - zRPrime n (c n + y*I)/2).re) /
        Real.cosh (pi*y)^2
```

For easier rewriting, define `zRPrime` by the finite logarithmic derivative in
(6.1), and separately prove that it is the complex derivative on the midpoint
line.
