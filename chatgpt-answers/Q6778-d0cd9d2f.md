# Strip-separation reduction audit

## S1. Projective setup versus affine chart

Verdict: FLAWED as stated; the reduction needs a side condition.

The projective collision statement is exact:

xi_(r+d) = xi_r iff Delta_(r,d)=0.

Replacing it by equality of u=c/b is valid only on the finite chart b != 0 at both endpoints. Mixed pairs with one b-zero and one nonzero b are not lost, because they cannot collide projectively. The only missing contribution is the infinity fibre:

m_inf = #{r : b_r=0}.

A crude use of the known zero-set bound m_inf <= 3 p^(2/3) is insufficient. The strip contribution of the infinity fibre can be as large as

sum_blocks O((D^(2/3))^2) = O(N D^(1/3))

using only the window law, which is larger than the desired D^(2-eta) scale.

Therefore the affine reduction is not unconditional. It requires an additional bound on the infinity fibre (or a direct projective Weyl estimate that includes it).

A useful conditional form is:

if m_inf << D^(1-eta/2), then the chart correction is harmless.

The exact failure is not the number of b-zero rows alone; it is the unknown concentration of those rows into one projective fibre.

## S2. Character expansion of the strip

Verdict: CONFIRMED after normalization correction.

For a phase phi_r in F_p, the projective/affine collision indicator is represented by additive orthogonality:

1[phi_u=phi_r] = (1/p) sum_t e_p(t(phi_u-phi_r)).

Let I_D be the distance strip. A normalized majorant for I_D has Fourier coefficients W_hat(s) satisfying

1_I(u-r) <= sum_s W_hat(s)e_p(s(u-r)),

with W_hat(s) nonnegative and

sum_s W_hat(s) << p log p.

Substitution gives

T(D) <= (1/p^2) sum_s W_hat(s) sum_t |sigma(t,s)|^2

where

sigma(t,s)=sum_r e_p(t phi_r+s r).

The t=0 term is the expected density/main term. The diagonal r=u is not a problem because the strip has positive distance D/2, so it is absent.

The bookkeeping error in the earlier chain was treating the Fourier weight as O(p) without the logarithmic loss. The correct safe estimate is O(p log p).

## S3. Weyl bound exponent audit

Then the nonzero-frequency contribution is bounded by

So the threshold delta_0 is eta/4 (with the slowly varying L improving the boundary only by o(1)).

## Corrected headline

The statement

FR_eta reduces to a single-variable Weyl bound

is too strong.

Correct statement:

FR_eta reduces to a uniform twisted Weyl bound plus a control of exceptional projective fibres.

A sufficient theorem is:

1. for every t != 0 and every additive twist s,

1. every exceptional projective fibre has multiplicity at most D^(1-eta/2-o(1)),

then the strip collision count is O(D^(2-eta)).

The fibre condition may be partially absorbed into the Weyl hypothesis: Parseval gives

max_t |sigma(t,0)|^2 >= (p sum_v m_v^2-N^2)/(p-1),

so a very large fibre forces a large Fourier coefficient. But the exact equivalence still needs a projective formulation including the infinity fibre.
