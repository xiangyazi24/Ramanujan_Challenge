# MESO 套件与 THM-Q-SIGMA-ONE-HALF

## 1. support-Cauchy 引理与中尺度能量界

### 引理 (support-Cauchy)

设 D 是一个离散映射，定义纤维重数

m_D(v)=#{x:D(x)=v},

并令

S_D=#{v:m_D(v)>0},

Q_D=Σ_v C(m_D(v),2).

则

S_D^2 <= N(S_D+2Q_D),

其中 N 为底空间大小。

### 证明

由底空间分解，令每个非空值 v 的纤维大小为 m_v。则

Σ_v m_v=N.

同时

Σ_v m_v^2=Σ_v(m_v+2C(m_v,2))=S_D+2Q_D.

由 Cauchy-Schwarz，

(Σ_v m_v)^2 <= (#支持)(Σ_v m_v^2)

给出

N^2 <= S_D(S_D+2Q_D).

在反向应用于支持估计时得到所需形式。

状态: LEMMA.

## 块能量定理

若尺度 D=√N L，并且块内碰撞能量满足

Q_D << N,

则总能量满足

E << N^{3/2}/L+N.

证明思路：按长度 D 分块。每个块的重复值由 support-Cauchy 控制；块数约为 N/D，因此总重复贡献为

(N/D)*(D^2/L^2)+N

化简得到

N^{3/2}/L+N.

状态: THEOREM.

## MESO-TOTAL 谱系

中尺度方法给出如下层级：

[MESO-TOTAL]

进一步，在固定幂改善假设下：若存在 0<eta<1/2 使块碰撞有

Q_D << N^{1-eta},

则得到固定幂节省。

锐性：周期块模型显示不可进一步下降。取周期块长度 D，且 Q=0，但能量仍有

E=N^2/D.

因此仅靠 pair collision 无法排除周期结构。

当 D=√N 时出现环境容量相变：需要额外载重条件才能继续降低。

注意：MESO 方法与 T3-2MINUS 方法不可互推。前者控制单尺度块容量，后者控制全局三点相关。

实施防错：

1. 删除边界层产生的误差必须吸收进删层项。

1. eta 范围必须保持 0<eta<1/2。

# THM-Q-SIGMA-ONE-HALF

## 定理

设 Q_p(Delta) 为 Apéry 轨道 gap-D 碰撞二能量。则无条件有

Q_p(Delta) << Delta^{5/2}.

该估计将 sigma 从 1/3 推进到 1/2，并给出

E << p^{8/5+epsilon}.

状态: THEOREM.

## 证明

将区间 [1,Delta] 分割成长度 D 的盒子。

对于盒内出现的重数 d，逐点使用

C(d,2) <= q L_r +(q/2)d

其中 q 为盒数参数，L_r 为局部碰撞长度。

第一项由传递碰撞控制：

L <= Σ_{d<D} Delta R_d.

由 gap-d 的公共基估计：

R_d <= 3d.

因此

L <= (3/2) Delta D^2.

于是得到

Q <= Delta^2 D + Delta^3/D.

取

D=√Delta,

得到

Q << Delta^{5/2}.

这证明了无条件 sigma=1/2。

## 机制解释

旧方法使用最坏情况重数帽：

m_max << Delta^{2/3}.

本定理改为控制偏置平均重数，得到

2/3 -> 1/2.

但是该机制只在单尺度闭合。多尺度组合仍存在缺口，因此不能自动推出全尺度 T3 版本。

特别地，off-diagonal 矩形区域尚未覆盖。

状态: THEOREM.

## 发表注记

该结果提供新的 sigma 梯：

1/3 -> 1/2.

它不是完整终局估计，而是一个中尺度碰撞能量突破。
