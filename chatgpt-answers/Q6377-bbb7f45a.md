# 3. Three notions that must not be conflated

## 3.1 ℓ-adic Frobenius trace

For a fixed prime ℓ ≠ p, an ℓ-adic trace function is of the form

```plain text
t_F(x) = Tr(Frob_x | F_x̄) ∈ Q̄_ℓ,
```

where F is a constructible/middle-extension Q̄_ℓ-sheaf or complex. It comes with:

- traces at every closed point, equivalently compatible functions on every F_{p^m};

- local characteristic polynomials and power-sum relations across extensions;

- rank, singular support, tame/wild inertia, Swan conductors, weights, and monodromy;

- a characteristic-zero coefficient field.

For “fixed as p varies,” the correct formulation is not merely one formula for each prime. One needs a sheaf on an arithmetic scheme over Z[1/Nℓ], or a compatible system, whose specializations at good primes have uniformly bounded rank and ramification.

There is no canonical ring map Q̄_ℓ → F_p when ℓ ≠ p. To state a congruence between an ℓ-adic trace and H_p(x), one needs algebraic-integrality and a number field/compatible-system realization with a chosen prime above p.

## 3.2 Crystalline/Hasse–Witt data

A Hasse–Witt matrix or Hasse invariant is characteristic-p data describing Frobenius/Cartier action on de Rham, coherent, or crystalline cohomology. It often detects ordinarity and, on an ordinary locus, may control a unit root.

It is not automatically the full Frobenius trace. An exact statement must specify:

- the geometric family;

- the cohomological degree and subquotient;

- the basis/normalization in which H_p is the Frobenius scalar or matrix entry;

- how that scalar relates to the characteristic polynomial or trace;

- what happens at singular and nonordinary fibers.

For a semilinear one-step Frobenius scalar, the degree-m iterate generally involves a product of Frobenius conjugates, not naive evaluation of the same scalar once. Thus a base-field Hasse polynomial does not by itself provide the extension-field trace data required for an ℓ-adic trace function.

In standard Dwork-unit-root arguments, division by the Hasse invariant is valid on the ordinary locus. At a zero of the Hasse invariant—the locus relevant here—the unit-root quotient ceases to be defined. A division-free crystalline construction may still exist, but it is an additional theorem.

## 3.3 An F_p-valued polynomial identity

The scripts establish equalities in F_p after evaluating truncation polynomials. Such identities have no automatic weight, purity, conductor, extension-field compatibility, or monodromy content.

Every fixed-sheaf trace identity yields strong finite-field identities, but the converse is false without a geometric construction. A function on F_p can always be encoded by some p-dependent sheaf/complex of large complexity; the point is to prove a uniform fixed realization.

## 6.2 A rigorous conditional no-unbounded-self-twist lemma

One useful part of Task 2 does not require local-exponent guessing.

[CONDITIONAL-LEMMA] Let F be an actual lisse sheaf of fixed positive generic rank R on a dense open of G_m. If a Kummer sheaf L_χ satisfies

```plain text
F ⊗ L_χ ≅ F,
```

then taking determinants gives

```plain text
det(F) ⊗ L_χ^R ≅ det(F),
```

hence

```plain text
L_χ^R ≅ 1.
```

Therefore the order of the self-twist character divides R. In particular, a fixed finite-rank sheaf has no Kummer self-twists of unbounded order.

This argument requires an actual sheaf of fixed rank. It does not apply to an undefined symbol, a p-dependent polynomial function, or an arbitrary virtual rank-zero difference.

For mutual twists, if both χ and ψ satisfy

```plain text
F ≅ G⊗L_χ  and  F ≅ G⊗L_ψ,
```

then L_{χψ^{-1}} is a self-twist of G. Thus the set of mutual twists, if nonempty, is one coset of a bounded self-twist group.

This proves the “no unbounded order” conclusion conditionally once fixed rank is available. The classification of the remaining bounded-order twists still requires the actual local inertia and global monodromy.

# 7. Audit of Task 3: what Katz-style Mellin equidistribution gives

## 7.1 Katz’s input is characteristic-zero trace data

Katz starts with an ℓ-adic perverse/middle-extension object on a form of G_m over a finite field, with ℓ ≠ p. Twisting by multiplicative characters means tensoring with Kummer sheaves. For good characters, the Mellin cohomology carries Frobenius, and the finite sum of the input trace function against the character is obtained from a characteristic-zero Frobenius trace, up to the specified cohomological sign/normalization.

The book’s Theorem 7.2 assumes, among other things, purity and arithmetic semisimplicity and equidistributes normalized Frobenius conjugacy classes as finite extension fields grow. The book separately discusses “the situation over Z” and effectiveness in prime-field aspects. None of these theorems applies until an arithmetic sheaf/compatible system and the exact hypotheses are exhibited.

The word “finite-field” in “finite-field Mellin transform” refers to the summation domain. It does not make the Frobenius traces F_p-valued.

## 7.2 What monodromy plus Katz could imply

Suppose, conditionally, that Tasks 1 and 2 produce a pure, arithmetically semisimple Mellin object with identified geometric monodromy and with only a bounded exceptional set of bad characters.

Then Katz can give [CONDITIONAL-KATZ-1]:

- equidistribution of normalized Frobenius conjugacy classes in the relevant maximal compact group in the theorem’s stated aspect;

- convergence of averages of continuous class functions;

- corresponding fixed moments/character averages;

- if the pushforward trace distribution has no atom at zero, density zero for exact characteristic-zero trace equality τ(χ)=0.

The last point follows because exact zero is contained in every small neighborhood of zero and an atomless limiting measure gives arbitrarily small mass to such neighborhoods.

## 7.3 What Katz does not imply

The target event is not exact characteristic-zero zero. It is

```plain text
b_r ≡ 0 mod p,
```

or, after a hypothetical compatible lift,

```plain text
τ_p(r) ≡ 0 mod 𝔭
```

for a prime 𝔭 above the defining characteristic p.

This is [NEGATIVE-KATZ-ZERO] for four reasons.

1. No compatible reduction has been proved. A Q̄_ℓ trace has no canonical reduction modulo p.

1. Divisibility is not a continuous Sato–Tate test. It is a residue-class condition whose scale shrinks as p grows.

1. Divisible need not mean zero. Unless one proves a size range strictly smaller than p, a nonzero algebraic trace can be divisible by p. The natural one-dimensional Mellin construction is not shown in the commit to have such a small range.

1. Weak equidistribution does not give a local limit modulo a growing modulus. Multiples of p can become dense after the usual normalization even while the normalized values have an excellent continuous limiting distribution.

Therefore no zero-density bound for {r : b_r ≡ 0 mod p} follows from Katz’s standard equidistribution theorem alone, even after monodromy is known.

## 7.4 Teichmüller lifting does not bridge the gap

The varying multiplicative character t ↦ t^{-r} can be represented ℓ-adically by a Kummer sheaf; that part is standard.

By contrast, taking the pointwise Teichmüller lift of each value H_p(x)^2 ∈ F_p merely creates a p-adic-valued function. It does not show that the function is the trace of a fixed bounded-conductor sheaf. Nor does it turn Katz’s ℓ-adic equidistribution theorem into a theorem about reduction modulo p.

A crystalline realization and an ℓ-adic companion may coexist in a compatible system, but their compatibility is an additional deep theorem, not a formal consequence of Teichmüller lifting.

## 7.5 The extra hypothesis actually needed for zero-density

A rigorous conditional statement would have to append a defining-characteristic local-limit hypothesis, for example:

```plain text
# {r mod p-1 : τ_p(r) ≡ a mod 𝔭} = O(1)
```

uniformly in a, or at least

```plain text
# {r : τ_p(r) ≡ 0 mod 𝔭} = o(p).
```

One could replace this by a sufficiently strong p-adic monodromy/equidistribution theorem for the residual Mellin Frobenius module. But this is not a “standard hypothesis” already furnished by Katz; it is essentially the new arithmetic input sought by the project.

## 7.6 Correct Task-3 verdict

[NEGATIVE-TASK-3] From the present commit, Katz gives nothing because no input sheaf has been constructed. Even after a successful Task 1–2 construction, Katz would give characteristic-zero normalized-trace equidistribution, not defining-characteristic divisibility zero-density. A separate p-adic/local-limit theorem is mandatory.
