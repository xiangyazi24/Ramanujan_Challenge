# Q6627 near-wall -> global-Q box conversion audit

## Summary verdict

The claimed exponent conversion

    Q_p(X) << X^(q') p^eps,
    q' = 3 - 1/(2-eta)

is correct, but the original proof sketch has one genuine missing detail: the dyadic decomposition argument silently assumes that all length-L boxes are contained inside a single dyadic shell. This is false for O(log X) boundary-crossing boxes.

The repair is simple and costs only a constant factor (or at worst a logarithmic factor already absorbed into p^eps): split every straddling box at the dyadic boundary. After splitting, every sub-box lies inside one shell and the near-wall K_p estimate applies directly.

No exponent changes.

# (2) Correct treatment of straddling boxes

Let the length-L boxes be

    B_m = [mL,(m+1)L).

Consider dyadic shells

    I_j = (2^j L, 2^(j+1)L].

A box B_m can fail to lie in a single shell only if it crosses one boundary

    2^j L.

Because the box length is L, it can cross at most one such boundary.

For every straddling box, write

    B_m = B_m^- union B_m^+

where

    B_m^- subset I_{j-1},
    B_m^+ subset I_j.

Now replace the original partition by this refined partition.

Properties:

1. Number of pieces increases by at most a factor 2.

2. Every refined piece has length <= L.

3. Every refined piece lies inside one dyadic shell.

Therefore every same-piece pair satisfies

    h in (H,2H],
    k-h < L <= H,

and is counted by K_p(H,L).

Hence the shell estimate is valid.

The only extra cost is a constant factor.

If one does not explicitly split but instead assigns each straddling box to both adjacent shells, the cost is also only a factor 2.

    H = 2^j L,

    sum_{j<=log_2(X/L)} 2^j L^(3-eta)

    X L^(2-eta).

Thus

    same-box mass
    << L^q + X L^(2-eta).

VERDICT: OK after straddling repair.

The geometric domination is genuine:

ratio of consecutive terms is exactly 2.

No extra log factor is required here.

# (7) p^eps and logarithmic accounting

There are three possible logarithmic sources.

## Source A: dyadic shells

Number of shells:

    O(log X).

The shell sum is geometric, so it does NOT introduce log X.

If estimates are summed crudely:

    O(log X) p^eps

appears.

This is absorbed as follows.

For any fixed epsilon:

    log X <= X^delta

for every delta>0.

Hence one can replace

    p^eps log X

by

    p^(eps+delta)

whenever X is polynomially bounded in p.

In the P3.2 application, X is in the prime range, so this is legitimate.

---

## Source B: bootstrap iteration

Suppose the exponent improvement map is

    q -> F(q)

with

    F(q)=3-1/(2-eta).

The logarithmic losses at each iteration multiply finitely many times:

    p^eps (log X)^C.

For a fixed number of bootstrap rounds N:

    (log X)^N

is still

    X^o(1).

Equivalently, for any delta>0:

    (log X)^N <= X^delta

for sufficiently large X.

Therefore all finite bootstrap iterations preserve the p^eps notation.

---

## Source C: boundary boxes

The number of dyadic boundaries crossed is

    O(log X).

After splitting:

the total number of pieces increases by at most

    1 + O(log X)

relative to the original partition.

This produces only a logarithmic loss.

Again:

    log X = X^o(1).

VERDICT:

The eps bookkeeping is valid, but the proof should explicitly say:

"All logarithmic losses from dyadic decomposition and finite iteration are absorbed into p^eps."

# (8) Final corrected box-conversion lemma

BOX-CONVERSION LEMMA.

Assume:

1. For every dyadic H and every D<=H,

       K_p(H,D)
       << H D^(2-eta) p^eps.

2. There is an initial estimate

       Q_p(Y)
       << Y^q p^eps

   for all Y in the initial range.

3. X is in a range where logarithmic factors satisfy

       (log X)^C <= p^delta

   for arbitrary fixed delta>0.

Then for every epsilon>0,

       Q_p(X)
       << X^(3-1/(2-eta)) p^epsilon

provided

       q < 4-2eta.

Proof:

Choose

       L=X^(1/(2-eta)).

Partition [1,X] into length-L intervals.

Split every interval crossing a dyadic boundary.

The refined intervals lie inside dyadic shells, and the same-box contribution satisfies

       << L^q + X L^(2-eta).

The cross-box contribution satisfies

       << X^3/L.

Therefore

       Q_p(X)
       <<
       X L^(q-1)
       +X^2 L^(1-eta)
       +X^3/L.

With the chosen L,

       X^2 L^(1-eta)
       =
       X^3/L
       =
       X^(3-1/(2-eta)).

The initial-range term is lower order exactly when

       q<4-2eta.

All logarithmic factors are absorbed into p^epsilon.

QED.

The blind spot was:

The proof implicitly assumed the length-L partition was subordinate to the dyadic decomposition.

It is not.

A box crossing 2^j is not contained in either adjacent shell, so K_p(H,L) cannot be applied directly.

The repair costs only O(log X) bookkeeping and no exponent loss.
