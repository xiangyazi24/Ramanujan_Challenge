## 7. Quantitative Bézout audit

The Smith proof is constructive. It gives semilocal coefficients satisfying

[

sum_klambda_kdelta_k=1,

qquad

sum_{k<ell}eta_{k,ell}widehatDelta_{k,ell}=Q_n.

tag{7.1}

]

Using

[

widehatDelta_{k,ell}=delta_ell C_k-delta_kC_ell,

]

one obtains Q_n as a combination of the C_k, and then obtains S_H modulo Q_n from the first relation. Clearing denominators introduces only factors coprime to U_n; it does not change any candidate-prime valuation.

All input integers t_k, S_k, C_k, and the coefficient determinants have logarithmic height O(n). Standard extended-gcd or Hermite/Smith algorithms therefore give explicit integer combinations with finite, effectively controlled coefficients. What they do not give is a nonzero output of logarithmic size o(n).

The obstruction is intrinsic:

- every nonzero target-divisible output has absolute value at least R_n;

- the smallest candidate-supported generator available from the full family is exactly gcd(S_H,Q_n);

- proving that this generator has logarithm o(n) is equivalent to proving log R_n=o(n).

Hence quantitative Bézout manipulation changes representation size, not the arithmetic height barrier.

## 8. Exact programmability countermodel

The saturation theorem admits a stronger countermodel than Q5576's arbitrary-subset construction.

For each candidate prime choose an arbitrary exponent

[

qquad

mu_p=2+2mathbf1_{ple2H+1}.

By CRT choose X modulo Q_n so that

[

when e_p < mu_p, and X = 0 mod p^(mu_p) when e_p=mu_p. Choose the representative 1 <= X <= Q_n and define fake prefixes

[

qquad

widetilde S_k=X+sum_{j=H+1}^k t_j.

]

They have:

- the actual differences t_k;

- the exact prefix recurrence from Q5576;

- the same universal factorial/binomial content;

- the same coefficient rows and all the same 2 x 2 determinants;

- the same finite-difference and normalized-derivative data.

Their adjacent minors satisfy

[

(widetilde C_k:H<k<L)mathcal O_n

=(X,Q_n)mathcal O_n

=prod_{pinmathcal P_n}p^{e_p}mathcal O_n.

tag{8.2}

]

Thus the support and every exponent up to the exact Smith cap are independently programmable.

This countermodel can also preserve positivity for all sufficiently large n. The root threshold for the affine function C_k(X) is

[

X_k^*=frac{t_k}{rho_k-1}-T_{k-1}.

]

Q5576's strict decrease of rho_k gives uniformly on H<k<L

[

X_k^*ge t_k n^{-O(1)},

[

On the other hand,

Hence every CRT representative 1 <= X <= Q_n gives widetilde C_k>0 once n is large enough.

In particular:

- choosing e_p=1 for an arbitrary subset and zero elsewhere realizes any desired target radical;

- choosing e_p=1 for every candidate gives a positive model with gcd top part U_n, whose logarithm is (1/2+o(1))n;

- choosing e_p=mu_p gives gcd top part Q_n, whose logarithm is (4/3+o(1))n.

Therefore no argument using only the long block, all adjacent minors, all pairwise coefficient determinants, positivity, and bounded-height Bézout operations can force a subexponential gcd. The actual Apéry value of S_H is the only remaining nonprogrammable input.

## 9. Reproducible exact-arithmetic computation plan

The following plan uses only integer arithmetic.

```python
from math import comb, gcd, prod


def vp(x, p):
    x = abs(x)
    if x == 0:
        return 10**9
    e = 0
    while x % p == 0:
        x //= p
        e += 1
    return e


def audit(n, primes):
    H, L = n // 3, n // 2
    K = list(range(H + 1, L))

    t = {
        k: comb(n, k)**2 * comb(n + k, k)**2
        for k in range(L + 1)
    }
    S = {}
    acc = 0
    for k in range(L + 1):
        acc += t[k]
        S[k] = acc

    P = [p for p in primes if n/2 < p <= n]
    U = prod(P)
    V = prod(p for p in P if p <= 2*H + 1)
    Q = U*U*V*V

    delta, b, gamma, C = {}, {}, {}, {}
    for k in K:
        A = (n-k)**2 * (n+k+1)**2
        B = (k+1)**4
        d = gcd(A, B)
        a, b[k] = A // d, B // d
        delta[k] = a - b[k]

        g = gcd(t[k], t[k+1])
        assert t[k] == b[k] * g
        assert t[k+1] == a * g

        tail_prefix = S[k-1] - S[H]
        gamma[k] = b[k]*t[k] - delta[k]*tail_prefix
        C[k] = -delta[k]*S[H] + gamma[k]
        assert C[k] > 0

    det = {}
    for i, k in enumerate(K):
        for ell in K[i+1:]:
            det[k, ell] = delta[ell]*gamma[k] - delta[k]*gamma[ell]

    # Adjacent closed formula.
    for k in range(H+1, L-1):
        assert det[k, k+1] == t[k+1] * (
            b[k]*delta[k+1] - b[k+1]*delta[k]
        )

    G = 0
    for k in K:
        G = gcd(G, C[k])

    for p in P:
        mu = 4 if p <= 2*H + 1 else 2

        # First Smith invariant is 1 locally.
        assert min(vp(delta[k], p) for k in K) == 0

        # Second Smith invariant is p^mu locally.
        assert min(vp(z, p) for z in det.values()) == mu

        # Exact value-ideal formula.
        assert min(vp(C[k], p) for k in K) == min(vp(S[H], p), mu)
        assert vp(G, p) == min(vp(S[H], p), mu)

    top_part = prod(p**vp(G, p) for p in P)
    assert top_part == gcd(S[H], Q)

    target_radical = prod(p for p in P if S[H] % p == 0)
    assert prod(p for p in P if top_part % p == 0) == target_radical
```

For a finite verification, sieve the primes once and run audit(n, primes) for 60 <= n <= N. Additional assertions can check the all-pair formula (2.1), the valuation formula for t_k, and the CRT-programmed fake constants.

The proof above does not depend on such computation; the script is a regression test for floor endpoints, signs, determinant orientation, and the exact Smith exponents.
