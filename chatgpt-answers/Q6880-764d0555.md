# Apéry limiting-cell Casoratian: exact classification, the missing connection coefficient, and a zero-location correction

## Executive verdict

The meromorphic classification is correct, subject to a precise growth hypothesis, but it leaves one genuine scalar free:

```text
J_c(z)
 = pi^3 cot(pi z)csc^2(pi z) + c pi cot(pi z).
```

The functional equation, evenness, pole order, leading cubic Laurent coefficient, normalization `K_infty(0)=1`, and polynomial growth in vertical strips are all satisfied for every `c`. Therefore those data do **not** determine `c`.

The Apéry recurrence does canonically determine the missing scalar, but as a global Jost/connection coefficient. With the repository's limiting functions

```text
K_infty(z)=phi(-z)phi(z)+z^6 gamma(-z)gamma(z),
phi(0)=1,
```

one has the exact identity

```text
c = K_infty''(0)/2
  = phi''(0)-phi'(0)^2
  = (log phi)''(0).
```

Equivalently, if `mathcal K_n` denotes the integer continuant and

```text
F_n(z)=mathcal K_n(z)/(1+z)_n^3,
F_n(0)=b_n,
F_n(z)/b_n -> phi(z),
```

locally uniformly near zero, then

```text
c = lim_(n->infinity) [
      mathcal K_n''(0)/mathcal K_n(0)
      -(mathcal K_n'(0)/mathcal K_n(0))^2
      +3 H_n^(2)
    ].
```

Thus the desired value is exactly the still-missing connection theorem

```text
[APERY-JOST-CURVATURE]

(log phi)''(0) = -2pi^2/3 = -4 zeta(2).
```

The current repository inputs establish the two-block/Jost framework and isolate the required uniform asymptotic theorem, but they do not evaluate this connection coefficient. So `c=-2pi^2/3` is not presently a consequence of the stated data.

There is also a decisive algebraic correction. For `c=-2pi^2/3`, the off-real zeros are

```text
1/2 +/- i arcosh(2)/(2pi)
 = 1/2 +/- i log(2+sqrt(3))/(2pi),
```

not `1/2 +/- i log(2)/(2pi)`. The latter height corresponds instead to

```text
c=-8pi^2/9.
```

No numerical evidence is used anywhere below.

## 1. Symmetry reduction

Assume

```text
K(z+1)=((z+1)/z)^3 K(z),
K(-z)=K(z),
```

and define

```text
J(z)=K(z)/z^3.
```

Then, wherever the expressions are defined,

```text
J(z+1)
 = K(z+1)/(z+1)^3
 = K(z)/z^3
 = J(z),
```

so `J` is one-periodic. Also

```text
J(-z)=K(-z)/(-z)^3=-J(z),
```

so `J` is odd.

Conversely, every one-periodic odd meromorphic `J` produces an even `K=z^3J` satisfying the displayed cocycle. Thus the cocycle and parity have no further hidden content after this reduction.

If the leading Laurent normalization at zero is

```text
J(z)=z^(-3)+O(z^(-1)),
```

then

```text
K(z)=1+O(z^2),
```

and in particular `K(0)=1`. This fixes the cubic-pole coefficient but not the residue.

## 2. Rigorous periodic-meromorphic classification

Put

```text
A(z)=pi^3 cot(pi z)csc^2(pi z).
```

At every integer, `A` has a triple pole with leading coefficient one. It has zero residue, because

```text
cot(x)csc^2(x) = -(1/2) d/dx(csc^2(x)).
```

Let `J` be odd, one-periodic, with no poles except the integers, each of order at most three, and with cubic coefficient one. Set

```text
c=Res_(z=0) J(z).
```

Periodicity gives the same residue at every integer. Then

```text
E(z)=J(z)-A(z)-c pi cot(pi z)
```

is entire, one-periodic, and odd.

To conclude `E=0`, the growth hypothesis must be stated precisely. It is enough, for example, to assume

```text
sup_(0<=Re z<=1) |E(z)| <= C(1+|Im z|)^M
```

for some fixed `C,M`; more generally, exponential type strictly below `2pi` suffices.

For completeness, write the Fourier coefficient

```text
a_n(y)=integral_0^1 E(x+iy) exp(-2pi i n(x+iy)) dx.
```

Cauchy's theorem and periodicity make `a_n(y)` independent of `y`. For `n>0`, send `y` to `-infinity`; for `n<0`, send `y` to `+infinity`. The exponential factor defeats polynomial growth, so every nonzero Fourier coefficient vanishes. The remaining coefficient is constant, and oddness forces that constant to vanish. Hence

```text
J(z)=pi^3 cot(pi z)csc^2(pi z)+c pi cot(pi z).       (2.1)
```

### Growth caveat

Pole data and periodicity alone do not imply (2.1). Without a restrictive vertical-growth hypothesis, one may add arbitrary entire odd one-periodic functions, for example `sin(2pi z)`. Thus the growth assumption is load-bearing.

## 3. Exact Laurent audit

Let `w=z-m`, where `m` is any integer. The standard expansions are

```text
cot x
 = x^(-1)-x/3-x^3/45-2x^5/945+O(x^7),

csc^2 x
 = x^(-2)+1/3+x^2/15+2x^4/189+x^6/675+O(x^8),
```

and differentiation of `csc^2 x` gives

```text
cot x csc^2 x
 = x^(-3)-x/15-4x^3/189-x^5/225+O(x^7).
```

Substituting `x=pi w` into (2.1) gives, at every integer,

```text
J_c(m+w)
 = w^(-3)+c w^(-1)
   -(pi^4/15+c pi^2/3)w
   -(4pi^6/189+c pi^4/45)w^3
   -(pi^8/225+2c pi^6/945)w^5
   +O(w^7).                                             (3.1)
```

The consequences needed later are immediate:

```text
Res_(z=m) J_c(z)=c,                                    (3.2)

K_c(z)=z^3J_c(z)=1+c z^2+O(z^4),                      (3.3)

c=K_c''(0)/2.                                          (3.4)
```

Thus the free parameter is exactly the residue, exactly the quadratic Taylor coefficient of `K`, and exactly half its second derivative at the origin.

For the proposed value `c=-2pi^2/3`, (3.1) becomes

```text
J(m+w)
 = w^(-3)-(2pi^2/3)w^(-1)
   +(7pi^4/45)w
   -(2pi^6/315)w^3
   -(43pi^8/14175)w^5
   +O(w^7),                                             (3.5)
```

and therefore

```text
K(z)
 =1-(2pi^2/3)z^2
   +(7pi^4/45)z^4
   -(2pi^6/315)z^6
   -(43pi^8/14175)z^8
   +O(z^10).                                            (3.6)
```

## 4. Closed-form and zero audit

For `c=-2pi^2/3`, factor (2.1):

```text
J(z)
 = pi^3 cot(pi z)(csc^2(pi z)-2/3)
 = (pi^3/3)
   cos(pi z)(3-2sin^2(pi z))/sin^3(pi z).
```

Since

```text
3-2sin^2 x = 2+cos(2x),
```

this is exactly

```text
Phi(z)
 = (pi^3/3)
   cos(pi z)(cos(2pi z)+2)/sin^3(pi z).                 (4.1)
```

So the equivalence between `c=-2pi^2/3` and the displayed closed form is correct.

The zero claim in the question is not. Besides the real zeros

```text
z=1/2 mod Z,
```

from `cos(pi z)=0`, the nonreal zeros satisfy

```text
cos(2pi z)=-2.
```

Put `z=1/2+iy`. Then

```text
cos(2pi z)=cos(pi+2pi i y)=-cosh(2pi y),
```

so

```text
cosh(2pi y)=2.
```

Therefore

```text
y=+/- arcosh(2)/(2pi)
 =+/- log(2+sqrt(3))/(2pi).                             (4.2)
```

This is an exact symbolic contradiction to the stated `log 2` height.

### Which constant gives the `log 2` height?

For general negative `c`, the nonreal zeros on the line `Re z=1/2` obey

```text
sech^2(pi y)=-c/pi^2.
```

If `y=log(2)/(2pi)`, then

```text
cosh^2(log(2)/2)=9/8,
sech^2(log(2)/2)=8/9.
```

Hence the required constant is

```text
c=-8pi^2/9,                                             (4.3)
```

and its closed form is

```text
J(z)
 = (pi^3/9)
   cos(pi z)(4cos(2pi z)+5)/sin^3(pi z).                (4.4)
```

Thus one must choose between the proposed constant and the proposed zero height; they cannot both be true.

## 5. Exact proof that the current limiting data do not determine `c`

For every complex number `c`, define

```text
J_c(z)=pi^3 cot(pi z)csc^2(pi z)+c pi cot(pi z),
K_c(z)=z^3J_c(z).
```

Then all of the following hold:

```text
J_c(z+1)=J_c(z),
J_c(-z)=-J_c(z),
K_c(-z)=K_c(z),
K_c(z+1)=((z+1)/z)^3K_c(z),
K_c(0)=1.
```

Every `J_c` has exactly the same pole set, exactly the same pole order, exactly the same cubic Laurent coefficient, and the same bounded vertical-strip growth. Only the residue changes.

Therefore:

> The cocycle, evenness, triple-pole condition interpreted as pole order plus leading coefficient, normalization `K(0)=1`, and the stated growth class leave a one-dimensional solution space. They do not determine `c`.

If “triple-pole data” is intended to include the full principal part, then it already includes `c` by definition and the determination is tautological. Under the usual meaning—order three with normalized leading coefficient—the residue remains free.

Several one-scalar conditions would determine it:

```text
c = Res_(z=0)J(z),

c = K''(0)/2,

c = J(1/4)/pi - 2pi^2,

c = -pi^2 - J'(1/2)/pi^2,

c = (i/pi) lim_(y->+infinity) J(x+iy),
```

where the last limit is independent of fixed nonintegral `x`. For the desired constant these become, respectively,

```text
Res J=-2pi^2/3,
K''(0)=-4pi^2/3,
J(1/4)=4pi^3/3,
J'(1/2)=-pi^4/3,
lim_(y->+infinity)J(x+iy)=2i pi^3/3.
```

The forced real zero at `1/2` is useless for determining `c`: odd periodicity gives `J(1/2)=0` for every member of the family.

## 6. The Apéry connection coefficient

The repository's exact two-block identity has the form

```text
f_h(-j+z)
 = z^(-3)F_r(-z)F_s(z)+z^3G_r(-z)G_s(z),

K_(r,s)(z)
 = F_r(-z)F_s(z)+z^6G_r(-z)G_s(z),
```

with `r=j-1`, `s=h-j`. The limiting Jost statement is

```text
F_n(z)/b_n -> phi(z),
G_n(z)/b_n -> gamma(z),
```

and hence

```text
K_infty(z)=phi(-z)phi(z)+z^6gamma(-z)gamma(z).           (6.1)
```

The canonical normalization gives

```text
phi(0)=1.
```

Because the second term in (6.1) vanishes to order at least six, it does not affect the quadratic coefficient. Differentiating the first term gives

```text
K_infty''(0)/2
 = phi''(0)-phi'(0)^2
 = (log phi)''(0).                                      (6.2)
```

Combining (3.4) and (6.2) gives the exact connection formula

```text
boxed:

c=(log phi)''(0).                                       (6.3)
```

This is the correct place where the Apéry recurrence enters. The periodic-meromorphic classification reduces the whole problem to one global connection coefficient of the distinguished dominant Jost solution.

The desired theorem is therefore precisely

```text
[APERY-JOST-CURVATURE]

(log phi)''(0)=-2pi^2/3=-4zeta(2).                     (6.4)
```

A proof of (6.4) could come from any one of the following genuinely new inputs:

1. an explicit gamma-product or hypergeometric connection formula for `phi` near zero;
2. an exact Euler/Beukers integral for `phi(z)` whose second logarithmic derivative may be evaluated at zero;
3. a parameter-differentiated recurrence plus a summable Green-kernel identity that telescopes to `-4zeta(2)`;
4. one exact special value such as `J(1/4)=4pi^3/3`.

The functional equation of `K_infty` alone supplies none of these.

### A useful warning about candidate products

It is tempting to guess

```text
phi(z)phi(-z)=(sin(pi z)/(pi z))^4,
```

because its quadratic coefficient is `-2pi^2/3`. This cannot be the complete identity: its quartic coefficient is `pi^4/5`, while (3.6) requires `7pi^4/45`, and the `z^6 gamma(-z)gamma(z)` term cannot repair a quartic mismatch. Only the quadratic jet is currently at issue.

## 7. A completely explicit recurrence-only statistic

Let

```text
P(t)=34t^3+51t^2+27t+5,
```

and let the integer continuants be

```text
mathcal K_0(z)=1,
mathcal K_1(z)=P(z),
mathcal K_(n+1)(z)
 =P(z+n)mathcal K_n(z)-(z+n)^6mathcal K_(n-1)(z).       (7.1)
```

Define

```text
q_n(z)=(1+z)_n=product_(k=1)^n(z+k),
F_n(z)=mathcal K_n(z)/q_n(z)^3.                         (7.2)
```

At `z=0`, (7.1) is exactly the Apéry recurrence after multiplication by factorials, and induction gives

```text
mathcal K_n(0)=(n!)^3b_n,
F_n(0)=b_n.                                             (7.3)
```

Assume the local holomorphic convergence required by the Jost construction:

```text
F_n(z)/b_n -> phi(z)
```

uniformly on a fixed disk around zero. Cauchy's formula then also gives convergence of derivatives on smaller disks. Since the functions equal one at zero after division by `b_n`, logarithms may be chosen near zero for all sufficiently large `n`. Hence

```text
c=(log phi)''(0)
 =lim_(n->infinity)(log F_n)''(0).                      (7.4)
```

Now

```text
(log q_n)''(0)=-H_n^(2),
H_n^(2)=sum_(k=1)^n 1/k^2,
```

so (7.2)-(7.4) give

```text
boxed:

c=lim_(n->infinity) [
    mathcal K_n''(0)/mathcal K_n(0)
    -(mathcal K_n'(0)/mathcal K_n(0))^2
    +3H_n^(2)
  ].                                                    (7.5)
```

This is an exact arithmetic statistic, requiring no root computation and no numerical fitting.

For implementation or formal proof, put

```text
U_n=mathcal K_n(0),
V_n=mathcal K_n'(0),
W_n=mathcal K_n''(0).
```

Differentiating (7.1) gives the closed recurrences

```text
U_(n+1)
 =P(n)U_n-n^6U_(n-1),

V_(n+1)
 =P(n)V_n+P'(n)U_n
  -n^6V_(n-1)-6n^5U_(n-1),

W_(n+1)
 =P(n)W_n+2P'(n)V_n+P''(n)U_n
  -n^6W_(n-1)-12n^5V_(n-1)-30n^4U_(n-1),              (7.6)
```

with

```text
(U_0,V_0,W_0)=(1,0,0),
(U_1,V_1,W_1)=(5,27,102).                              (7.7)
```

Thus the desired constant is equivalent to the fully discrete limit

```text
lim_(n->infinity)
 [W_n/U_n-(V_n/U_n)^2+3H_n^(2)]
 =-2pi^2/3.                                             (7.8)
```

Since `H_n^(2)->zeta(2)`, it is also equivalent to

```text
lim_(n->infinity)
 [W_n/U_n-(V_n/U_n)^2]
 =-7zeta(2)
 =-7pi^2/6.                                             (7.9)
```

Equations (7.6)-(7.9) isolate the exact missing connection problem in recurrence language. They are stronger and cleaner than a numerical zero fit.

## 8. Why the current repository inputs stop here

The audited repository state supplies:

- the exact two-block factorization;
- the candidate two-sided limit `K_infty=phi(-z)phi(z)+z^6gamma(-z)gamma(z)`;
- the cocycle, parity, strip localization, and limiting-cell framework;
- an identified uniform asymptotic task of the `ARCH-CELL-ORDER` type.

These establish the correct object and, once the local convergence is proved, justify the limit formula (7.5). They do **not** supply any exact evaluation of the parameter derivative `(log phi)''(0)`.

In particular:

- ordinary Poincaré-Perron theory identifies the dominant exponential rate, not the parameter connection coefficient;
- the Casoratian fixes relative normalization between two solutions but does not evaluate the second parameter derivative of the distinguished solution;
- parity fixes `K_infty'(0)=0`, not `K_infty''(0)`;
- pole order fixes the `z^(-3)` coefficient of `J`, not its residue;
- knowing three roots per cell or their symmetry does not determine their exact imaginary height.

Therefore the remaining issue is not another local Laurent manipulation. It is the global connection problem (6.4), equivalently the discrete curvature limit (7.8).
