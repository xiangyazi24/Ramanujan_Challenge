```plain text
Delta_{r,h} = N_h(r) / prod_{j=1}^h (r+j)^3
```

on the regular nonwrapping window, with the positive sign shown.

# 1. Audit of D1-D6

## 1.1 D1: exact Green-kernel identity

Fix r and write

```plain text
z_h = Delta_{r,h} = b_r c_{r+h} - b_{r+h} c_r.
```

As a function of h, z_h satisfies the same recurrence as either solution:

```plain text
(r+h+1)^3 z_{h+1}
 = P(r+h) z_h - (r+h)^3 z_{h-1}.
```

The initial values are

```plain text
z_0 = 0,
z_1 = b_r c_{r+1} - b_{r+1} c_r
    = -W_{r+1}
    = 1/(r+1)^3.
```

Define

```plain text
d_h = prod_{j=1}^h (r+j)^3 z_h.
```

Then d_1 = 1, d_2 = P(r+1), and direct substitution gives

```plain text
d_{h+1} = P(r+h) d_h - (r+h)^6 d_{h-1}.
```

These are exactly the initial conditions and recurrence defining N_h(r). Therefore

```plain text
[PROVED-D1]
Delta_{r,h} = N_h(r) / prod_{j=1}^h (r+j)^3.
```

Every denominator is a unit when 1 <= r and r+h <= p-2. This also proves the collision equivalence without any unspecified unit factor.

## 1.2 D2 and D3: exact orthogonality and Parseval

Put

```plain text
S = #S_H,
B_t(H) = sum_{(r,h) in S_H} e_p(t Delta_{r,h}).
```

Additive orthogonality gives

```plain text
1_{Delta=0} = (1/p) sum_{t in F_p} e_p(t Delta),
```

hence

```plain text
[PROVED-D2]
sum_{h<=H} C_h = S/p + (1/p) sum_{t!=0} B_t(H).
```

Likewise,

```plain text
sum_t |B_t(H)|^2
 = p #{(a,b) in S_H^2 : Delta_a = Delta_b}
 = p N_coinc(H).
```

Since B_0(H)=S,

```plain text
[PROVED-D3]
sum_{t!=0}|B_t(H)|^2 = p N_coinc(H) - S^2.
```

## 1.3 D4: COINC implies the square-root family bound

Assume

```plain text
N_coinc(H) <= S^2/p + K S.
```

Then D3 gives

```plain text
sum_{t!=0}|B_t(H)|^2 <= p K S.
```

Cauchy-Schwarz in t gives

```plain text
|(1/p)sum_{t!=0}B_t(H)|
 <= (1/p) sqrt((p-1)pKS)
 <= sqrt(KS).
```

Therefore

```plain text
[PROVED-D4]
sum_{h<=H} C_h <= S/p + sqrt(KS)
                 << H + sqrt(K p H)
```

when H = o(p), since S is asymptotic to pH.

## 1.4 D5: right exponent, wrong sigma-ladder citation

The project's sigma ladder defines

```plain text
d_D(r) = #{h<=D : pi(r)=pi(r+h)},
Q_p(D) = sum_r binom(d_D(r),2).
```

This Q_p(D) counts two returns from the same base point, hence triple orbit coincidences. It is not

```plain text
sum_{h<=D} C_h.
```

Thus D5 cannot invoke the sigma ladder with the redefined Q_p(D) in the question.

The p^(4/3) conclusion nevertheless follows from the already proved block inequality. For every block length H,

```plain text
F_p <= ceil(M/H) (M + 2 sum_{h<H} C_h).
```

Under COINC with H = floor(p^(2/3)), D4 gives

```plain text
sum_{h<H}C_h << H + sqrt(pH) << p^(5/6).
```

Hence

```plain text
F_p << p^(1/3) (p + p^(5/6)) << p^(4/3).
```

So the corrected statement is:

```plain text
[PROVED-D5-CORRECTED]
COINC at H comparable to p^(2/3) implies F_p << p^(4/3)
through block energy, not through the paper's Q_p sigma ladder.
```

## 1.5 D6: corrected bidegree, genus, and exceptional components

Write

```plain text
f_h(r) = Delta_{r,h}
       = N_h(r)/D_h(r),
D_h(r) = prod_{j=1}^h(r+j)^3.
```

Over Q, the established absence of integer roots prevents cancellation with D_h, so f_h has degree 3h as a map P1 -> P1. The compactified equation

```plain text
f_h(r) = f_k(r')
```

is

```plain text
N_h(r)D_k(r') - N_k(r')D_h(r) = 0
```

in P1 x P1, of bidegree at most (3h,3k). A smooth irreducible curve of bidegree (a,b) in P1 x P1 has arithmetic genus

```plain text
g = (a-1)(b-1).
```

Therefore the generic genus here is O(hk), not O(h+k). A per-component Hasse-Weil bound has error

```plain text
O(hk sqrt(p)).
```

Summing absolutely over h,k <= H gives

```plain text
O(H^4 sqrt(p)).
```

The COINC allowance beyond S^2/p is O(S)=O(pH). Thus this route is useful only when

```plain text
H^4 sqrt(p) <= pH,
H <= p^(1/6),
```

before component complications. This is weaker than the p^(1/4) threshold claimed in D6.

There is a second correction. The main term is controlled by the number of F_p-defined irreducible components:

- for h=k, the diagonal r=r' is always a component;

- if the geometric monodromy of f_h is 2-transitive, there is generically one further off-diagonal component;

- for h!=k, extra components occur exactly when the two covers have a common nontrivial quotient over the generic value field.

Consequently the exceptional-strata theorem needed for COINC has two parts: a component-count theorem and cancellation of the sum of the Weil errors. Per-pair irreducibility of N_h(r) at the single value 0 does not prove either part.

# 2. The exact Chebotarev variance dictionary

For even h, remove the forced mirror factor and call the remaining primitive polynomial F_h. For odd h, put F_h=N_h. Let

```plain text
Omega_h = set of complex roots of F_h,
L_h = splitting field of F_h,
G_h = Gal(L_h/Q),
chi_h(g) = #Fix(g on Omega_h).
```

For every good prime p, the primitive root count R_h(p) is

```plain text
R_h(p) = chi_h(Frob_p).
```

Burnside's lemma gives the exact fixed-h moment identities

```plain text
mean_p R_h(p)
 = #orbits of G_h on Omega_h,

mean_p R_h(p)^2
 = #orbits of G_h on Omega_h x Omega_h.
```

If F_h is irreducible, the first number is 1. Put

```plain text
rank(G_h) = #orbits of G_h on Omega_h x Omega_h.
```

Then

```plain text
[PROVED]
mean_p (R_h(p)-1)^2 = rank(G_h)-1.
```

In particular, if G_h=S_d in its natural action, it is 2-transitive, rank(G_h)=2, and

```plain text
mean_p (R_h(p)-1)^2 = 1.
```

The deterministic mirror root for even h changes the mean by 1 but contributes no variance. The window mean in the question differs from 1+kappa_h by O(h/p), plus finitely many or explicitly controllable boundary primes for fixed h.

This is the precise meaning of the statement that GPRV is a root-count variance problem. It also identifies the actual algebraic input: irreducibility alone gives the mean; bounded permutation rank, preferably 2-transitivity, gives the variance.

# 3. A key quantifier correction: GPRV versus aggregate covariance

Define the truncated pointwise GPRV statistic

```plain text
V_H(p) = sum_{h<=H} (C_h(p)-mu_{p,h})^2,
```

where

```plain text
mu_{p,h} = kappa_h + (p-2-h-kappa_h)/(p+1).
```

Averaging V_H(p) over p gives

```plain text
sum_{h<=H} average_p (C_h(p)-mu_{p,h})^2.
```

There are no h != k cross terms. Hence:

```plain text
[PROVED-CORRECTION]
Prime-averaged diagonal GPRV does not require linear disjointness
between L_h and L_k.
```

Cross-field disjointness enters if one studies the stronger aggregate

```plain text
A_H(p) = sum_{h<=H}(C_h(p)-mu_{p,h})
```

and wants

```plain text
average_p |A_H(p)|^2 << H.
```

It also enters COINC, which sums mixed equal-value conditions for Delta_{r,h} and Delta_{r',k}.

This distinction matters because a common quadratic field can create visible synchronization across h without increasing the diagonal sum of the individual variances.

# 4. The precise common-quotient criterion

For h!=k, let

```plain text
Gamma_{h,k} = Gal(L_h L_k/Q) <= G_h x G_k,
chi_h^0 = chi_h - 1,
chi_k^0 = chi_k - 1.
```

The prime-averaged covariance is exactly

```plain text
Cov(h,k) = <chi_h^0 tensor chi_k^0, 1>_{Gamma_{h,k}}.
```

Let E=L_h intersect L_k. By Goursat's lemma, E corresponds to a common quotient Q of G_h and G_k. If

```plain text
q_h:G_h -> Q,
q_k:G_k -> Q,
```

put

```plain text
a_h(q) = average_{g:q_h(g)=q} chi_h^0(g),
a_k(q) = average_{g:q_k(g)=q} chi_k^0(g).
```

Then

```plain text
[PROVED]
Cov(h,k) = (1/#Q) sum_{q in Q} a_h(q)a_k(q).
```

Thus full linear disjointness is sufficient but not necessary. The minimal character-level condition is

```plain text
for every common quotient stratum Q,
one of the conditional centered means a_h or a_k is zero.
```

For an aggregate variance up to H, the exact sufficient condition is

```plain text
sum_{h!=k<=H} |Cov(h,k)| << H,
```

plus a uniform effective Chebotarev error whose sum is O(H pi(X)) in the prime range being averaged.

This is the correct formulation of the family compatibility theorem on the number-field side.

# 5. What all-h symmetric Galois groups would prove about intersections

Assume h,k >=3 and

```plain text
G_h = S_{d_h},
G_k = S_{d_k},
d_h != d_k,
d_h,d_k >=5.
```

The primitive degrees are strictly increasing with h, so d_h!=d_k. The intersection E=L_h intersect L_k is Galois over Q. Its Galois group is a common quotient of S_{d_h} and S_{d_k}.

For d>=5, the only proper nontrivial normal subgroup of S_d is A_d, and the corresponding quotient is C2. Since S_{d_h} and S_{d_k} are not isomorphic when d_h!=d_k, the intersection can only be

```plain text
E=Q
```

or the common sign/discriminant quadratic field. Therefore:

```plain text
[PROVED-CONDITIONAL]
Under all-h S_d, no positive-density tower of richer common Galois
factor fields can occur among distinct h>=3.
```

If the squareclasses of disc(F_h) and disc(F_k) differ, then E=Q and the two splitting fields are linearly disjoint.

The remaining possible C2 intersection is not harmful for natural root counts. For d>=4, count fixed points separately in the even and odd cosets of S_d. The stabilizer of one point is S_{d-1}, which has equally many even and odd elements, so

```plain text
average(Fix | sign=+1) = average(Fix | sign=-1) = 1.
```

For the second moment, count ordered pairs. The diagonal stabilizer is S_{d-1}, and the off-diagonal stabilizer is S_{d-2}; for d>=4 both have equal parity halves. Hence

```plain text
average(Fix^2 | sign=+1) = average(Fix^2 | sign=-1) = 2.
```

Thus the centered first and second moments have zero conditional bias on the sign quotient. Two S_d fields may share the same discriminant quadratic field and still have zero root-count covariance.

The h=2 primitive quadratic is genuinely exceptional: its centered root-count character is itself the quadratic character (-51/p). It should be isolated as one fixed stratum. One fixed h contributes O(1) to a diagonal variance and cannot by itself destroy an O(H) law.

The proved (-2/p) apparition or leading-sign law is another fixed quadratic stratification. It can be quarantined by splitting primes into its two Chebotarev classes. It does not prove all-h S_d, and in the natural S_d model its conditional fixed-point moments are again unchanged.

Verdict on the question's positive-density concern. A positive density of repeated discriminant quadratic fields is not ruled out today. Under the S_d conjecture it is the only possible common Galois field, and it is harmless for the root-count variance. A harmful positive-density stratum would require non-2-transitive or imprimitive G_h, or a common quotient that occurs nontrivially in the centered permutation characters.

# 6. Exact adjacent resultant and its limitation

Let

```plain text
R_h = Res(N_h,N_{h+1}).
```

Modulo N_h, the recurrence gives

```plain text
N_{h+1} = -(r+h)^6 N_{h-1} mod N_h.
```

Using multiplicativity and symmetry of the resultant, and noting that

```plain text
deg N_h * deg N_{h-1} = 9(h-1)(h-2)
```

is even, one obtains

```plain text
R_h = (-1)^(h-1) N_h(-h)^6 R_{h-1}.
```

Reflection and the endpoint evaluation give

```plain text
N_h(-h) = (-1)^(h-1) N_h(-1),
N_h(-1) = b_{h-1} ((h-1)!)^3.
```

Starting from R_1=1 yields

```plain text
[PROVED]
Res(N_h,N_{h+1})
 = (-1)^(h(h-1)/2)
   prod_{j=1}^{h-1} b_j^6 (j!)^18.
```

This proves adjacent coprimality over Q and lists the rational primes at which adjacent reductions can acquire a common root.

It does not imply that the splitting fields are disjoint. Coprime irreducible polynomials can have the same splitting field; for example, x^2-2 and x^2-8 are coprime and have a nonzero resultant but both split over Q(sqrt(2)). The transfer update likewise gives root repulsion at the value 0, not an inclusion or exclusion relation between normal closures.

Therefore no adjacent or coprime-shift linear-disjointness theorem follows from the current resultant identity alone.

# 7. Number-field strata versus function-field strata

Two distinct Galois problems must not be merged.

## 7.1 Number-field problem at value 0

The splitting field L_h of F_h(r)=0 controls the variation of C_h(p) as p varies. This is the field relevant to fixed-h Chebotarev and prime-averaged GPRV.

## 7.2 Function-field problem for all values

COINC concerns the covers

```plain text
f_h:P1 -> P1,
f_h(r)=Delta_{r,h}.
```

The components of

```plain text
f_h(r)=f_k(r')
```

are governed by geometric monodromy over Qbar(T), not by the number-field splitting field of the special fiber T=0.

For h=k, the number of generic components is the permutation rank of the geometric monodromy of f_h; 2-transitivity gives the diagonal and one off-diagonal component. For h!=k, geometric irreducibility of the fiber product is equivalent to the two covers having no common nontrivial quotient over Qbar(T).

Thus irreducibility of N_h, adjacent gcd(N_h,N_{h+1})=1, and disjointness of the number fields L_h do not by themselves prove COINC.

A precise thin-exceptional-strata package sufficient for COINC is:

```plain text
(A) For all but a set with total weight O(H), the self-cover f_h
    has permutation rank 2.

(B) For h!=k, the total excess number of geometric components of
    f_h x_{P1} f_k over the generic value 1 is O(H).

(C) After separating those components, the sum of all centered
    Frobenius point-count errors over h,k<=H is O(pH).
```

Conditions (A)-(C) imply

```plain text
N_coinc(H) <= S^2/p + O(S),
```

hence COINC. This is the exact exceptional-strata formulation on the difference-curve side.

# 8. What Chavdarov-Kowalski type theorems actually provide

The strongest general results nearby are large-sieve-for-Frobenius theorems for a genuine algebraic family with known large monodromy.

- Chavdarov proves generic irreducibility for zeta numerators in a family of curves with large monodromy; Kowalski identifies it as Chavdarov Theorem 2.3.

- Kowalski, Theorem 6.1, treats a fixed proper smooth family of genus-g curves over a geometrically irreducible finite-field base with full symplectic monodromy.

- Kowalski, Theorem 6.2, gives a special hyperelliptic family with some uniformity as g grows, but the paper states that nontriviality requires roughly g^2 smaller than log q.

These theorems require an actual family over a base variety, compatible l-adic sheaves, large monodromy modulo many auxiliary primes, and controlled cohomological complexity. The index h in the Apery continuant is a recurrence length; the degree, discriminant, and generic-cover complexity grow with h, and no fixed algebraic family carrying all F_h with product monodromy has been constructed.

Therefore there is no black-box Chavdarov/Kowalski theorem for GPRV. The minimal missing input is exactly a uniform monodromy-and-complexity theorem for the growing recursive family.

Primary locators:

- Kowalski, The large sieve, monodromy and zeta functions of curves, Theorems 6.1 and 6.2, printed pp. 18-19.

- Chavdarov, Duke Math. J. 87 (1997), 151-180, especially Theorem 2.3 as cited by Kowalski.

- Serre, Quelques applications du theoreme de densite de Chebotarev, Publ. Math. IHES 54 (1981), 123-201.

# 9. What is provable today over primes

## 9.1 Strict unconditional theorem from current certificates

For any fixed finite list of h, factor each primitive polynomial over Q, compute its permutation rank, and apply ordinary Chebotarev/Burnside. Therefore a fixed-H prime-averaged second-moment theorem is rigorous.

For the currently certified S_d range h<=11, each primitive root-count variance is exactly 1. Consequently, with H0<=11 fixed,

```plain text
[PROVED]
average_{p<=X} sum_{h<=H0}(C_h(p)-mu_{p,h})^2
 = H0 + o(1),
```

up to the explicitly finite bad-prime and window corrections. For h=12,13,14, irreducibility alone fixes the mean but does not by itself certify permutation rank 2.

This theorem is fixed-H. The actual finite certificates do not imply any H=H(X) tending to infinity. Hence the exponent reachable today from the stated project facts is

```plain text
delta = 0.
```

In particular, neither h<=log p nor h<=p^delta follows merely from GRH: GRH controls the zeros of the zeta functions of fields already constructed; it does not prove that F_h is irreducible, 2-transitive, or has bounded permutation rank for new h.

## 9.2 Conditional GRH theorem in a growing range

The following is a complete conditional theorem and is the strongest clean range I obtain.

[PROVED-CONDITIONAL: prime-averaged truncated GPRV under all-h S_d]. Fix eps>0. Assume for every h<=H:

```plain text
(i) F_h is irreducible with Gal(F_h)=S_{d_h};
(ii) the proved height bound log Height(F_h) << h log(2h);
(iii) GRH holds for the Dedekind zeta functions of the root field
      K_h=Q(alpha) and the ordered-distinct-pair field
      E_h=Q(alpha,beta), alpha!=beta.
```

Then, uniformly for

```plain text
H <= X^(1/6-eps),
```

one has over dyadic primes X<p<=2X

```plain text
sum_p sum_{h<=H}(C_h(p)-mu_{p,h})^2
 = (1+o(1)) H #{p:X<p<=2X}.
```

### Proof

For a good prime, let a_K(p) be the number of degree-one prime ideals of K above p. The root-field dictionary gives

```plain text
a_{K_h}(p)=R_h(p).
```

Since S_{d_h} is 2-transitive, the field E_h associated to an ordered pair of distinct roots has degree d_h(d_h-1), and

```plain text
a_{E_h}(p)=R_h(p)(R_h(p)-1).
```

Therefore

```plain text
(R_h(p)-1)^2
 = a_{E_h}(p)-a_{K_h}(p)+1.
```

The proved degree and height bounds give

```plain text
[K_h:Q] << h,
log D_{K_h} << h^2 log(2h).
```

The field E_h is the compositum of two conjugate root fields. The standard compositum-discriminant inequality gives

```plain text
[E_h:Q] << h^2,
log D_{E_h} << h^3 log(2h).
```

Grenie-Molteni's GRH prime-ideal estimate, Corollary 1.2, equation (1.5), gives for a field K an error of size

```plain text
sqrt(X) ((log X)log D_K + [K:Q](log X)^2)
```

at the Chebyshev level, and the same order is sufficient after partial summation for the present coarse calculation. Thus the total error after summing h<=H is

```plain text
<< sqrt(X) [H^4 log(2H) log X + H^3 (log X)^2].
```

Bad reduction and the excluded O(h) window residues contribute at most a polynomial error O(H^5 log(2H)), using the proved coefficient-height bound and the elementary bound on the number of prime divisors of the relevant integer evaluations.

The main term is

```plain text
H X/log X.
```

For H<=X^(1/6-eps), both displayed errors are o(H X/log X). The forced mirror root is deterministic, and mu_{p,h} differs from 1+kappa_h by O(h/p), so it does not change the asymptotic. This proves the theorem.

The primary effective source is Grenie-Molteni, Explicit versions of the prime ideal theorem for Dedekind zeta functions under GRH, Corollary 1.2, equation (1.5). Their later Chebotarev paper gives the analogous conjugacy-class estimate in Theorem 1.1, equation (1.5): arXiv:1709.07609.

### Interpretation

The first moment uses only K_h and reaches the familiar conditional range close to X^(1/4). The variance uses E_h, whose degree and discriminant are larger, and the range drops to X^(1/6). This is the exact second-moment cost.

This remains a prime-average theorem. It does not imply the fixed-p GPRV conjecture.

## 9.3 Without GRH

The strict theorem available from the current repository remains fixed H.

If an all-h S_d theorem were added, classical effective prime-ideal theorems would suggest a slowly growing polylogarithmic range. The relevant ordered-pair fields have

```plain text
n_E << h^2,
log D_E << h^3 log h.
```

A Lagarias-Odlyzko/Serre type zero-free range formally points to approximately

```plain text
h^4 (log h)^2 << log X,
```

or H below a constant times (log X/loglog X)^(1/4). However, turning this into a uniform summed asymptotic requires a careful non-Galois prime-ideal theorem, explicit exclusion or cancellation of exceptional zeros, and all-h S_d. That package is not currently written in the project, so I do not bank this polylogarithmic range as a theorem.

Thorner-Zaman's introduction, equations (1.2)-(1.5), and Theorem 1.1 display precisely the field-degree, discriminant, and exceptional-zero dependence: A unified and improved Chebotarev density theorem.

Thus the honest answer is:

```plain text
current unconditional growing range: none;
current unconditional certified range: fixed H;
conditional on all-h S_d plus GRH: H <= X^(1/6-eps).
```

# 10. The minimal named lemmas left

## 10.1 For prime-averaged diagonal GPRV

PAIR-FIELD-CHEBOTAREV. For every eps>0, uniformly for H<=X^(1/6-eps), the primitive root and ordered-pair fields satisfy

```plain text
sum_{X<p<=2X} sum_{h<=H}(R_h(p)-1)^2
 = (1+o(1)) H #{p:X<p<=2X}.
```

# Final verdict

The exceptional-strata audit changes the strategic picture in three useful ways.

First, the feared common discriminant-field tower is not automatically fatal. Under the natural S_d model, it is the only possible common Galois subfield for distinct large h, and the root-count first and second moments are conditionally unbiased on its two cosets.

Second, adjacent resultants cannot establish field independence. They certify common-root exclusion at value 0, while both GPRV covariance and COINC require common-quotient control at the level of splitting fields or generic covers.

Third, the best rigorous growing-range statement is conditional: all-h S_d plus GRH gives the prime-averaged truncated variance through H<=X^(1/6-eps). The present finite certificates give only fixed H, so the unconditional exponent available today is delta=0.

The smallest genuinely new theorem to target on this lane is not full linear disjointness. It is the character-level statement that all common quotient strata are harmless except for a total O(H) family, together with the analogous generic-cover component theorem for the rational maps f_h.
