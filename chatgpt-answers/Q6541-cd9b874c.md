There is a clean unconditional gain, and it is exactly the requested next rung after Q6521.

After removing the already known mirror factor and all mod-p cut-edge factors, and then taking squarefree parts, one has

```plain text
sum_{H < h < k <= 2H} deg gcd(M_h^reg mod p, M_k^reg mod p)
    << H^(5/2).
```

The same argument directly gives the actual regular F_p return statistic

```plain text

I = {H+1,...,2H}.
```

In fact the proof works on the full interval 1 <= h <= Delta and gives

```plain text
Q_p^reg(Delta) << Delta^(5/2).
```

Thus the sigma machine advances unconditionally from sigma=1/3 to

```plain text

```

The mechanism is a second-moment version of the continuant window argument. It combines:

1. the exact renewal identity, which gives the distance-sensitive codegree bound

```plain text
deg gcd_reg(N_h,N_(h+d)) <= deg N_(d-1) << d;
```

1. a partition of the h-window into boxes of length D;

1. Cauchy inside the boxes;

1. the choice D = sqrt(H).

This is the missing H^(1/6) saving. It is the local, truncated version of the same interpolation defect appearing in [T3-INTERP]: replace a worst-case 2/3 multiplicity cap by a pair-size-biased average of size 1/2.

Two important scope corrections are necessary.

- The literal identity

```plain text
deg gcd_Fp(M_h,M_k)
 = number of common roots in F_p
```

is false in general. The left side also counts common irreducible factors of degree greater than one, with their degrees. The exact F_p-root quantity is

```plain text
deg gcd(M_h,M_k,X^p-X).
```

- If M_h means only "remove the rational mirror factor", then raw gcds still contain p-dependent cut-edge roots. One early Apery zero can create one vertical root through an entire dyadic h-block and contribute about H^2 to the pair sum. The theorem below is therefore for the regular squarefree part. This is exactly the object relevant to the non-wrapping orbit-collision statistic. A theorem for the unsaturated raw M_h would require an additional bound for the cut-edge and inseparability defects and is substantially stronger.

Use the exact endpoint divisor in the normalization of the running script. Because the project has two h/r shifts in circulation, do not hard-code the list of linear factors until the script has checked it against the endpoint formula.


# 2. The exact distance-sensitive common-root bound

Use the restart normalization from Q6496:

```plain text
N_(-1)(s)=0,
N_0(s)=1,
N_1(s)=P(s),
N_(m+1)(s)=P(s+m)N_m(s)-(s+m)^6 N_(m-1)(s).
```

The proved renewal identity is

```plain text
N_(m+g+1)(s)
 = N_(m+1)(s) N_g(s+m+1)
   -(s+m+1)^6 N_m(s) N_(g-1)(s+m+2).             (2.1)
```

Set g=d-1. Then

```plain text
N_(m+d)(s)
 = N_(m+1)(s) N_(d-1)(s+m+1)
   -(s+m+1)^6 N_m(s) N_(d-2)(s+m+2).             (2.2)
```

At a regular root of N_m, adjacent coprimality gives

```plain text
N_(m+1)(s) != 0.
```

Therefore

```plain text
N_m(s)=N_(m+d)(s)=0
  implies N_(d-1)(s+m+1)=0.                       (2.3)
```

Translation preserves closed-point degree. Consequently

```plain text
deg gcd(F_m,F_(m+d))
 <= deg N_(d-1)
 <= 3(d-1).                                       (2.4)
```

The same bound holds for the number of common F_p roots. This is much sharper than the old generic bound 3 min(m,m+d) when d is small.

The indexing in the current qL notation is shifted by one from the Q6496 restart notation, but only the harmless replacement d-1 by d+O(1) changes. The usable invariant statement is

```plain text
regular codegree at separation d is O(d).          (2.5)
```

# 3. Direct proof of AVG-GCD_1/2

Let

```plain text
S = sum_x w(x)d_x = sum_{h in I_H} deg F_h.
```

Since deg F_h <= deg N_h << h and h as H on the dyadic block,

```plain text
S << H^2.                                          (3.1)
```

Choose an integer D with 1 <= D <= H. Partition I_H into q consecutive boxes of length at most D. Thus

```plain text
q <= H/D + 1 << H/D.                               (3.2)
```

For a fixed closed point x, let a_(x,j) be the number of h-values in box j for which F_h(x)=0. Define the number of same-box pairs

```plain text
L_x = sum_j choose(a_(x,j),2).
```

Cauchy gives

```plain text
d_x^2 = (sum_j a_(x,j))^2
      <= q sum_j a_(x,j)^2
      = q(2L_x+d_x).                                (3.3)
```

Hence

```plain text
choose(d_x,2) <= q L_x + (q/2)d_x.                 (3.4)
```

Sum (3.4) with weights w(x). Let

```plain text
L = sum_x w(x)L_x.
```

By exchanging the order of summation, L is the weighted common-root sum over pairs h<k lying in the same D-box. For a fixed separation d<D, there are at most H such pairs, and (2.4) gives codegree O(d). Therefore

```plain text
L << H sum_(1<=d<D) d
  << H D^2.                                         (3.5)
```

Combining (3.1)-(3.5),

```plain text
W_alg(H)
 << (H/D)(H D^2 + H^2)
 << H^2 D + H^3/D.                                  (3.6)
```

Choose

```plain text
D = ceil(sqrt(H)).
```

Then

```plain text
W_alg(H) << H^(5/2).                                (3.7)
```

Restricting x to rational points proves the same bound for W_Fp(H).

Exactly the same proof on the interval 1 <= h <= Delta gives

```plain text
Q_p^reg(Delta) << Delta^(5/2).                      (3.8)
```

Therefore:

```plain text
[THM-Q-SIGMA-ONE-HALF]
Q_p^reg(Delta) << Delta^(5/2),
sigma = 1/2.                                        (3.9)
```

No p^epsilon is needed. The inputs are only the already proved renewal identity, adjacent regular coprimality, and deg N_d << d.

# 4. Relation to the Q6521 window lemma

Q6521 used

```plain text
sum_r d_r << H^2,
max_r d_r << H^(2/3),
```

and obtained

```plain text
sum_r choose(d_r,2) << H^(8/3).                    (4.1)
```

The new proof does not improve the pointwise cap. It improves the second moment directly by proving that a high-degree fiber must create many close pairs in the h-variable, while close h-pairs have codegree only O(distance).

The incidence graph interpretation is useful. Its columns are h-values; its rows are regular roots x; an edge means F_h(x)=0.

Known degree data alone permit an abstract extremizer with

```plain text
H columns, each of degree about H,
H^(4/3) rows, each of degree about H^(2/3).
```

This has H^2 edges and H^(8/3) row wedges, so Q6521 was optimal from only mass plus maximum degree.

The renewal identity forbids this arbitrary incidence graph: pairs of columns at distance d have codegree O(d). The box argument converts precisely this new metric codegree information into the factor H^(1/6) saving.

# 5. The 1/6 ledger versus T3-INTERP

The two 1/6 gaps are the same interpolation defect in two coordinate systems.

## 5.1 Local gap-family side

Let

```plain text
A_1 = sum_x w(x)d_x << H^2,
A_2 = sum_x w(x)(d_x)_2 = 2W_alg(H).
```

The ratio


is the pair-size-biased mean of d_x-1 seen from a random incidence edge.

- The Q6521 cap gives at most H^(2/3).

- AVG-GCD_1/2 asks for at most H^(1/2).

The saving is exactly

```plain text
H^(2/3) / H^(1/2) = H^(1/6).                       (5.1)
```

The box proof establishes this average statement without improving the worst fiber.

## 5.2 Global color-fiber side

Let

```plain text
F_2 = sum_v (m_v)_2,
T_3 = sum_v (m_v)_3.
```

The ratio

```plain text
T_3/F_2
```

is the collision-pair-size-biased mean of m_v-2.

Using the unconditional bounds

```plain text
max_v m_v << p^(2/3),
F_2 << p^(3/2),
```

gives

```plain text
T_3 << p^(13/6).
```

To reach the threshold T_3 << p^2, the size-biased mean must fall from p^(2/3) to p^(1/2), again a factor

```plain text
p^(1/6).                                            (5.2)
```

Thus the two gaps are literally the same at full scale. Indeed the full non-wrapping identity is

```plain text
Q_p(p-2) = T_3/6.                                   (5.3)
```

At a truncated scale H, the saving is H^(1/6). If H=p^alpha, this is p^(alpha/6), so it is not numerically the full p^(1/6) unless H is of order p.

The statements are not theorem-equivalent. The dyadic gcd theorem controls a local h-window; T3 uses all gap rectangles and all color fibers. Reconstructing T3 from dyadic estimates requires also off-diagonal dyadic rectangles, not only comparable h,k.

# 7. Exact near-neighbor resultant staircase

The renewal identity also gives the desired d-uniform resultant factorization before mirror/cut-edge quotienting.

From (2.2), modulo N_m(s) one has

```plain text
N_(m+d)(s)
 == N_(m+1)(s) N_(d-1)(s+m+1) mod N_m(s).           (7.1)
```

The degrees of the two sides used in the resultant agree, so

```plain text
Res_s(N_m,N_(m+d))
 = Res_s(N_m,N_(m+1))
   * Res_s(N_m,N_(d-1)(s+m+1)).                     (7.2)
```

After the translation t=s+m+1 and reflection,

```plain text
Res_s(N_m,N_(d-1)(s+m+1))
 = +/- Res_t(N_m(1-t),N_(d-1)(t)).                  (7.3)
```

Thus the adjacent resultant is not an isolated miracle. Every distance-d resultant splits into:

1. the already known adjacent resultant;

1. a cross-resultant against the short continuant N_(d-1).

For d=1 this is the adjacent formula. For d=2 the second factor uses N_1=P. For fixed d, all nonadjacent common roots are controlled by one fixed small continuant. For d growing with H, the cross-resultant still grows, so (7.2) is a stratification theorem, not yet a closed scalar formula.

At the level of regular roots, (7.2) immediately gives (2.4), which is exactly the input used in the proof of sigma=1/2.

After removing mirror and cut-edge factors, the same statement holds up to explicit factors produced by those removals. A machine implementation should verify the raw identity first, then divide the known factors and compare the regular residual resultants.

A useful algebraic packaging is

```plain text
A_d = F_p[t]/(N_(d-1)(t)),
K_(m,d) = Norm_(A_d/F_p)(N_m(1-t)).                 (7.4)
```

The second factor in (7.3) is K_(m,d), up to leading coefficients. As m varies, N_m(1-t) follows a rank-2 recurrence over the algebra A_d. The catch is that dim A_d << d; taking norms produces scalar complexity growing with d. Fixed d is easy, but a d-uniform variance theorem remains a family problem.

Reference boundary: Wang and Jin, "Common zeros of polynomials satisfying a recurrence of order two", arXiv:1712.04231, characterizes common zeros in a fixed order-two recurrence setting. It does not provide the growing-d average needed here. The exact factorization (7.2) comes directly from the project renewal identity and should be cited as the primary Apery-specific statement.

# 8. Mixed F-crystal route

There are two different fixed-rank objects, and they must not be conflated.

## 8.1 A formal rank-4 difference object

Let A(r) be the 2 by 2 Apery transfer matrix and

```plain text
T(r,h)=A(r+h-1)...A(r).
```

A pair of gaps can be encoded in the rank-4 tensor state

```plain text
Z(r,h,k)=T(r,h)e_0 tensor T(r,k)e_0.                (8.1)
```

It satisfies the two shift laws

```plain text
Z(r,h+1,k) = (A(r+h) tensor I) Z(r,h,k),
Z(r,h,k+1) = (I tensor A(r+k)) Z(r,h,k).            (8.2)
```

This is a genuine fixed-rank bi-difference module. However, fixed rank alone is not enough. The coefficients contain the growing shifts r+h and r+k, and there is currently no bounded-conductor sheaf or overconvergent F-isocrystal whose Frobenius trace is the exact common-root indicator.

## 8.2 The geometric rank-4 mixed extension

Q6509 correctly identifies c as an inhomogeneous solution:

```plain text
L C = t,
```

not as a second homogeneous MUM logarithmic period. The natural geometric candidate is therefore a rank-4 mixed extension

```plain text
0 -> D_K3 -> E_mix -> L_source -> 0,                (8.3)
```

where D_K3 is the rank-3 Apery K3 connection and the last rank-one term records the source t. In a first-order basis its Frobenius matrix Phi should satisfy the semilinear compatibility equation already written in Q6509/Q6517.

A route from E_mix to AVG-GCD would require all of the following new bridges:

1. construct E_mix as an overconvergent F-isocrystal, not only as a formal differential module;

1. identify the discrete coefficient/gap parameter h with an algebraic Kummer or Mellin parameter;

1. realize M_h(r)=0 as a residual Frobenius matrix-coefficient condition;

1. form the two translated copies for h and k and prove product monodromy or an equivalent second-moment statement;

1. prove a defining-characteristic local limit, because exact equality mod p is not a continuous p-adic or complex trace statistic.

The mod-p^7 depth tower is strong evidence for step 1 near the MUM point, but it is not a direct bridge to steps 2-5.

There are two precise reasons.

- The verified tower concerns cross-block coefficients n=p+v, while the present gcd problem lives in the first-digit range h<p and varies the transfer length.

- AUDIT-4 is negative: an orbit collision does not force equality of the finite holomorphic jets D,E,F, and c is not in their finite linear span. Therefore the existing jet tower does not add an extra equation at a common root.

So the honest status is:

```plain text
depth tower = construction checksum and category clue;
AVG-GCD variance = still missing coefficient-to-Frobenius trace bridge.
```

Relevant primary literature:

- F. Beukers and M. Vlasenko, "Frobenius structure and p-adic zeta values", arXiv:2302.09603, Adv. Math. 480 (2025), 110512. It concerns Frobenius matrices in the standard MUM basis for Calabi-Yau type operators.

- M. Asakura, "New p-adic hypergeometric functions and syntomic regulators", arXiv:1811.03770. Theorem 1.1 gives Dwork-like congruences; Theorems 1.2 and 1.3 identify logarithmic-type p-adic hypergeometric values in syntomic regulators.

These papers support the category of (8.3). They do not state the two-gap residual variance theorem needed here.

## 9.1 Independent random-polynomial baseline

For two independent random monic polynomials over F_p of sufficiently large degree,

```plain text
Prob(deg gcd = d) = (1-1/p)p^(-d),  d>=0.
```

Hence

```plain text
E[deg gcd]     = 1/(p-1),
Prob(gcd != 1) = 1/p,
E[deg gcd | gcd != 1] = p/(p-1).                    (9.4)
```

There are H(H-1)/2 pairs in the dyadic block. Therefore

```plain text
E[weighted_alg] as H^2/(2p),
E[support_alg]  as H^2/(2p).                        (9.5)
```

The requested normalizations should therefore be tiny:

```plain text
E[weighted_alg/H^(5/2)] as 1/(2p sqrt(H)),
E[support_alg/H^(3/2)]  as sqrt(H)/(2p).             (9.6)
```

The theorem H^(5/2) is deliberately much weaker than the random prediction.

The Poisson mean for the number of bad pairs is

```plain text
lambda = H(H-1)/(2p).                               (9.7)
```

Thus a zero count is normal whenever H^2 << p. To obtain a visible random signal, choose some primes with p comparable to H^2 as well as primes much larger than H^2.


- The excess survives removal of mirror roots, cut edges, repeated factors, and extension-only factors.

If only weighted_raw is large, that is not evidence against the theorem. It is evidence that the scan is measuring the known cut-edge vertical rays.

# 12. Required final questions

## (a) Least confident step

The least confident part is not the H^(5/2) combinatorial proof; that proof is short and auditable. It is the claim that the project's current polynomial called M_h has already removed every cut-edge and multiplicity defect needed for the algebraic gcd identity. The repo has several shifted normalizations of h and r. The theorem is unquestionably correct for the regular squarefree factors F_h and for the actual non-wrapping return statistic, but the raw machine polynomial must be normalized against the exact endpoint formula before one labels its gcd sum [AVG-GCD_1/2].

## (b) Shared blind spot

The likely shared blind spot is extension-field geometry.

The empirical campaign has measured F_p orbit returns. A polynomial deg gcd scan also sees common closed points over F_(p^e), e>1. Those extension-only factors can obey a different family law and can make the algebraic gcd target look false even while the actual Q-statistic is perfectly random.

The cure is to keep g_alg and g_Fp separate from the first run. If the difference is negligible, the stronger algebraic target is justified. If it is large, the correct theorem is the rational-root/regular return version, and the mixed F-crystal object must be formulated with its residue degree explicitly rather than silently collapsing all closed points to F_p points.
