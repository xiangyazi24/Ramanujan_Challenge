# Big geometric monodromy for the Fourier sheaf attached to delta_h

## Executive verdict

[PROVED] The correct pure Fourier sheaf is not the full affine H_c^1 object of rank 4h-1. It is the projective-open, weight-one middle-extension sheaf of rank

```plain text
r_h = 4h-2.
```

With the usual Fourier-transform sign convention, its Frobenius trace at t != 0 is

```plain text
-Tr(Frob_t | G_h) = S_h(t)+1.
```

The extra 1 is the value at the regular point x=infinity. The affine rank-(4h-1) realization contains one weight-zero boundary class and is not the correct object for geometric monodromy.

[PROVED] The Apéry reflection gives more than conjugate symmetry. For

```plain text
iota_h(x) = -x-h-1,
delta_h(iota_h(x)) = -delta_h(x),
```

one has

```plain text
S_h(-t)=S_h(t)=conj(S_h(t)).
```

The pure sheaf G_h is geometrically self-dual, and the canonical pairing is alternating. Hence

```plain text
G_geom(G_h) is contained in Sp_(4h-2),
```

not in an orthogonal group and not generically in SL_(4h-2). In rank two, Sp_2=SL_2, but h=1 is an explicit finite/reducible exception.

[CORRECTION] The local expression

```plain text
U(2)^(h-1) + chi_3^h + chi_3^(-h)
```

must be read as multiplicities:

```plain text
U(2)^(direct-sum h-1)
 + L_chi3^(direct-sum h)
 + L_chi3inv^(direct-sum h).
```

Its rank is then

```plain text
2(h-1)+h+h=4h-2.
```

If the superscripts were tensor powers, the stated local type would have the wrong rank.

[OBSTRUCTION] The proposed all-h proof of big monodromy does not presently close. There are three independent gaps.

1. Connectedness, or transitivity of the degree-3h cover delta_h, is not enough to make G_h geometrically irreducible. The required input is 2-transitivity of the cover monodromy, equivalently geometric irreducibility of the off-diagonal same-fiber curve.

1. At t=0 the audited candidate contains h-1 copies of U(2), not one copy. After cubing tame monodromy, the nilpotent rank is h-1. It is a transvection only for h=2. Thus the standard one J_2 block criterion does not apply for h>2.

1. Irreducibility, self-duality, and the displayed wild type at infinity do not by themselves exclude tensor decomposition, tensor induction, finite exceptional groups, or proper irreducible connected subgroups of Sp_(4h-2).

[CONDITIONAL BIG-MONODROMY THEOREM] There is, however, a clean exact replacement. Let V_h be the standard representation of G_geom(G_h), and define

```plain text
M4_h = dim ((V_h tensor V_h tensor V_h^vee tensor V_h^vee)^G_geom).
```

Assume the local U(2) part is confirmed and h>=2. If

```plain text
M4_h = 3,
```

then

```plain text
G_geom(G_h)=Sp_(4h-2).
```

Indeed, Larsen's Alternative says that a symplectic group with fourth moment 3 is either the full symplectic group or finite. The nontrivial unipotent U(2) block has infinite order in characteristic zero and excludes the finite alternative.

Thus the exact all-h missing lemma is not a vague big local monodromy statement. It is

```plain text
[FOURIER-M4-3]
For every h>=2, the pure Fourier sheaf G_h has fourth moment 3.
```

This is a concrete four-variable point-count/component problem.

[EQUILIBRIUM CORRECTION] If G_geom=Sp_(4h-2), the compact group is

```plain text
USp(4h-2),
```

and its standard trace is real. In the large-rank limit it approaches a real N(0,1), not a complex Gaussian. The observed maximum near sqrt(2 log p) is therefore the correct real-Gaussian prediction in a double limit where h also grows. It is not a fixed-h consequence of Katz equidistribution.

[PRIZE-QUESTION VERDICT] Pairwise big monodromy gives product monodromy and the usual square-root correlation estimate for each fixed pair, but it does not prove

```plain text
sum_(k<=H) |Gamma_(h,k)|^2 << H p^3
```

uniformly in growing H. The fourth-moment invariant count 3 for one symplectic factor and 1 for two independent factors controls pointwise moments over t. It does not control the square of the global t-sum. The desired estimate is a second-level large-sieve theorem for the global correlation cohomology as k varies.

# 1. The correct Fourier sheaf and trace normalization

Fix h and a good prime p>3. Put

```plain text
q_h(x)=product_(j=1)^h (x+j),
f_h(x)=delta_h(x)=N_h(x)/q_h(x)^3.
```

Let

```plain text
X=P1,
D_h={actual poles of f_h},
U_h=X minus D_h.
```

At good reduction all candidate points -1,...,-h are actual poles of order 3, and x=infinity belongs to U_h with

```plain text
f_h(infinity)=0.
```

The rational map extends to a finite map

```plain text
f_h:X -> P1
```

of degree 3h. Restricting the target to A1 gives a finite map

```plain text
f_h:U_h -> A1_y.
```

Define the permutation direct image

```plain text
K_h = (f_h)_* Q_l[1].
```

On the generic y-fiber it is the permutation representation on the 3h sheets. It contains one constant summand. Let

```plain text
P_h = augmentation part of K_h
    = kernel(K_h -> Q_l[1]).
```

The Fourier-Deligne transform of the constant summand is punctual at t=0, so on G_m,t it disappears. Thus one may equivalently Fourier transform K_h or P_h and then restrict to t!=0. Define

```plain text
G_h = FT_psi(P_h)|_(G_m,t),
```

with the standard perverse shift. For t in F_q^*, proper base change gives

```plain text
(G_h)_t = H_c^1(U_h over Fbar_q, L_psi(t f_h))
```

for the pure projective-open part. Consequently

```plain text
-Tr(Frob_t | G_h)
 = sum_(x in U_h(F_q)) psi_q(t f_h(x))
 = S_(h,q)(t)+1.                                    (1.1)
```

Here S_(h,q)(t) is the affine sum that omits the finite poles, and the final 1 is the trace at x=infinity.

The Q6587 Euler-characteristic computation gives

```plain text
rank(G_h)=4h-2.                                      (1.2)
```

The affine-domain cohomology has dimension 4h-1 because deleting the regular point infinity adds one weight-zero boundary class. That odd-dimensional mixed object must not be used when discussing Sp versus SO.

After weight normalization, write

```plain text
tau_h(t) = -(S_h(t)+1)/sqrt(q).
```

Then tau_h is the trace of a pure weight-zero local system of rank 4h-2.

## 1.1 The explicit h=1 exception

For h=1,

```plain text
f_1(x)=1/(x+1)^3.
```

With y=1/(x+1), including x=infinity as y=0,

```plain text
S_1(t)+1 = sum_(y in F_q) psi_q(t y^3).
```

Over the geometric field this splits into the two cubic Kummer constituents chi_3 and chi_3^(-1). Thus G_1 has rank 2 but finite, reducible geometric monodromy. When q is 2 mod 3, arithmetic Frobenius interchanges the two constituents and the degree-one trace may vanish identically, but the geometric splitting remains.

Therefore any all-h statement must begin at h=2.

# 2. Self-duality and the symmetry type

## 2.1 Function-level symmetry

The proved reflection identity is

```plain text
N_h(-x-h-1)=(-1)^(h-1) N_h(x),
q_h(-x-h-1)=(-1)^h q_h(x).
```

Hence

```plain text
f_h(iota_h(x))=-f_h(x),
iota_h(x)=-x-h-1.                                    (2.1)
```

The involution iota_h permutes the complete pole complement U_h. Therefore, for every t,

```plain text
S_h(-t)
 = sum_x psi(-t f_h(x))
 = sum_x psi(t f_h(iota_h(x)))
 = S_h(t).                                          (2.2)
```

For the standard complex embedding of the additive character,

```plain text
conj(S_h(t))=S_h(-t).
```

Combining with (2.2),

```plain text
S_h(t) is real and even in t.                       (2.3)
```

The equality with the complex conjugate alone would only give a [-1]^*-duality. The reflection supplies the additional isomorphism needed to turn it into ordinary self-duality.

## 2.2 Sheaf-level duality

Verdier/Fourier duality gives, up to the standard Tate twist,

```plain text
D(FT_psi(P_h))
  isomorphic to [-1]^* FT_psi(D(P_h)).               (2.4)
```

The augmentation permutation sheaf P_h is orthogonally self-dual. The domain involution iota_h, together with f_h composed with iota_h = -f_h, gives

```plain text
[-1]^*P_h isomorphic to P_h.                         (2.5)
```

Equations (2.4) and (2.5) give

```plain text
G_h^vee isomorphic to G_h(1).                        (2.6)
```

After weight normalization, G_h is ordinarily self-dual.

## 2.3 The pairing is alternating

The sign can be determined directly on a stalk. Let

```plain text
L_t=L_psi(t f_h).
```

At every actual pole, L_t has nontrivial wild inertia and no inertia invariants. Thus the clean-extension map identifies the compactly supported and ordinary middle cohomology in degree one. Define

```plain text
B_t(a,b)
 = Trace_U(a cup iota_h^*(b))
```

for

```plain text
a,b in H_c^1(U_h,L_t).
```

Since

```plain text
iota_h^*L_t = L_(-t) = L_t^vee,
```

Poincare duality makes B_t nondegenerate. Also iota_h has degree one on the curve, so it acts trivially on the top trace map. Therefore

```plain text
B_t(b,a)
 = Trace_U(b cup iota_h^*a)
 = Trace_U(iota_h^*b cup a)
 = -Trace_U(a cup iota_h^*b)
 = -B_t(a,b).                                       (2.7)
```

The minus sign is graded commutativity in degree one. Hence the canonical form is alternating.

Thus, for h>=1,

```plain text
G_geom(G_h) is contained in Sp_(4h-2).              (2.8)
```

For h>=2 this rules out an orthogonal symmetry type. It also rules out a genuinely non-self-dual SL type. The only overlap is rank two, where Sp_2=SL_2, and h=1 is already exceptional.

## 2.4 Why the chi_3 pieces do not obstruct self-duality

Under the proposed local description at t=0,

```plain text
G_h|I_0
 = U(2)^(direct-sum h-1)
   + L_chi3^(direct-sum h)
   + L_chi3inv^(direct-sum h).                       (2.9)
```

Each chi_3 constituent is paired with a chi_3^(-1) constituent. The U(2) summands are self-dual and admit alternating forms. Thus (2.9) is compatible with (2.8).

At infinity, the proposed stationary-phase decomposition is

```plain text
T_h^(0)
 + direct_sum_(a in CV_h)
     (L_psi(a t) tensor L_chi2),                     (2.10)
```

where T_h^(0) has break zero and rank 2, and CV_h is the multiset of 4h-4 simple finite critical values. Reflection sends CV_h to -CV_h. The dual of the summand indexed by a is the summand indexed by -a. Thus the infinity type is also symplectically paired.

# 3. Audit of the proposed local monodromy package

The following package is coherent, but it is still conditional on the parallel local calculation.

```plain text
[LOCAL_h]

At 0:
  G_h|I_0
   = U(2)^(direct-sum h-1)
     + chi_3^(direct-sum h)
     + chi_3^(-1)^(direct-sum h),
  Swan_0=0.

At infinity:
  break-zero rank = 2,
  break-one rank  = 4h-4,
  Swan_infinity   = 4h-4,
  break-one characters are
    L_psi(a t) tensor chi_2
  for the simple finite critical values a of f_h.
```

The hypotheses needed for this exact form are:

1. all h denominator points remain genuine order-3 poles;

1. the 4h-4 remaining critical points are simple;

1. their critical values are nonzero and pairwise distinct;

1. no characteristic-p collision merges stationary-phase characters;

1. the rank-2 break-zero part is identified, not merely inferred from a rank count.

These are fixed-h algebraic conditions and fail only at finitely many primes once proved over characteristic zero. They are not currently proved uniformly for h growing with p.

## 3.1 The unipotent element is not a transvection for h>2

Let T_0 be a tame inertia generator at zero. Cubing kills the cubic characters in (2.9). Its unipotent part has Jordan form

```plain text
J_2^(direct-sum h-1) + J_1^(direct-sum 2h).          (3.1)
```

Therefore

```plain text
rank(T_0^3-1)=h-1.                                   (3.2)
```

It is a transvection only when h=2. For h>2, the phrase a single Jordan block of size 2 is false: there are h-1 such blocks.

The local type does prove that the geometric group is infinite, provided h>=2, because a nontrivial unipotent element in characteristic-zero linear algebra has infinite order. It does not identify the connected group.

## 3.2 Wild rank does not itself imply a big connected group

The break-one characters at infinity have finite p-power inertia image. A finite monodromy group can have large Swan conductor. Consequently the wild part alone cannot exclude finite monodromy.

Distinct stationary-phase characters are useful for proving:

```plain text
- absence of rank-one twists,
- absence of projective automorphisms,
- primitivity,
- tensor indecomposability,
- non-tensor-induction.
```

But each item requires a separate argument. For example, tensor decomposability would force the critical-value character multiset to be a nontrivial additive Minkowski sum. Tensor induction would force a nontrivial permutation structure on that multiset. Pairwise distinctness alone does not rule either out.

This is exactly the lesson of the Katz-Tiep Airy-sheaf criteria: local irreducibility, primitivity, tensor indecomposability, tensor induction, and Condition (S+) are separate hypotheses or separate theorems, not interchangeable slogans.

# 4. The exact irreducibility input

Let Omega_h be the generic fiber of f_h, with |Omega_h|=3h, and let M_h^cover be the geometric permutation monodromy of the cover. On the generic y-line,

```plain text
(f_h)_*Q_l = 1 + Aug(Omega_h).                       (4.1)
```

The source P1 is connected, so M_h^cover acts transitively. This proves only that the constant representation occurs once.

The augmentation representation is irreducible if and only if the permutation action is 2-transitive. Equivalently,

```plain text
Aug(Omega_h) irreducible
iff M_h^cover is 2-transitive
iff the off-diagonal fiber square
    {(x,y): f_h(x)=f_h(y), x!=y}
    is geometrically irreducible.                   (4.2)
```

Fourier transform is an autoequivalence of the perverse category and preserves direct sums and simplicity. Therefore

```plain text
G_h geometrically irreducible
iff the augmentation perverse sheaf P_h is simple
iff the cover monodromy is 2-transitive.             (4.3)
```

This corrects the proposed implication

```plain text
transitive cover monodromy => G_h irreducible.
```

That implication is false.

Full symmetric cover monodromy S_(3h) is more than enough. The current repository has finite-range evidence/certificates for the same-gap off-diagonal factor, but no all-h theorem. Thus all-h geometric irreducibility of G_h remains open.

The facts that N_h is nonzero at every pole and that f_h has degree 3h verify the map and its polar structure. They do not prove 2-transitivity.

# 5. Big monodromy: what can actually be proved

## 5.1 Why the quick Sp or SL classification is unavailable

Once Section 2 is established, the only classical candidate is Sp_(4h-2). But a proper irreducible subgroup of a symplectic group can be:

```plain text
- finite;
- imprimitive;
- tensor decomposable;
- tensor induced;
- the image of another simple group in a symplectic representation;
- an exceptional low-dimensional subgroup.
```

The local type in [LOCAL_h] does not automatically remove this list. In particular, for h>2 there is no transvection.

Therefore the statement

```plain text
irreducible + local U(2) blocks + Swan infinity=4h-4
implies Sp_(4h-2)
```

is not presently a theorem.

## 5.2 A rigorous conditional criterion via Larsen's Alternative

Let

```plain text
r=4h-2,
G=G_geom(G_h) in Sp_r,
V=standard r-dimensional representation.
```

Define the absolute fourth moment

```plain text
M4(G,V)
 = dim ((V tensor V tensor V^vee tensor V^vee)^G).   (5.1)
```

Katz's form of Larsen's Alternative states that for r>2, if

```plain text
M4(G,V)=3,
```

then either

```plain text
G=Sp_r
```

or G is finite.

Under [LOCAL_h], T_0^3 contains a nontrivial J_2 block for every h>=2, so G contains a nontrivial unipotent element and is not finite. Hence:

```plain text
[THEOREM-BIGMON-CONDITIONAL]

Assume h>=2, the pure sheaf G_h exists with [LOCAL_h],
and M4(G_geom(G_h),V_h)=3.
Then
  G_geom(G_h)=Sp_(4h-2).                              (5.2)
```

This criterion is stronger and cleaner than trying to force a transvection for every h.

## 5.3 The fourth moment as an explicit point-count target

Put

```plain text
A_h(t)=S_h(t)+1
      =sum_(x in U_h(F_q)) psi_q(t f_h(x)).
```

For q=p^n, define

```plain text
Z_h(q)
 = #{(x1,x2,y1,y2) in U_h(F_q)^4:
      f_h(x1)+f_h(x2)=f_h(y1)+f_h(y2)}.
```

Additive orthogonality gives the exact identity

```plain text
sum_(t in F_q^*) |A_h(t)|^4
 = q Z_h(q) - |U_h(F_q)|^4.                          (5.3)
```

Therefore

```plain text
M4_h
 = lim_(n->infinity)
   [q Z_h(q)-|U_h(F_q)|^4]/[(q-1)q^2].               (5.4)
```

The target M4_h=3 is equivalent to the centered point-count law

```plain text
q Z_h(q)-|U_h(F_q)|^4
 = 3(q-1)q^2 + O_h(q^(5/2)).                         (5.5)
```

The three symplectic Wick pairings are represented by the three obvious pairing patterns obtained from equality and the involution iota_h. However, one must prove that no additional top-weight primitive component survives after the universal constant contribution is removed. Ordinary irreducibility of the two-variable same-fiber curve does not prove (5.5).

This gives the correct all-h geometric target:

```plain text
[FOURIER-M4-3]
The centered four-variable additive fiber product (5.3)
has exactly the three symplectic top-weight modes.     (5.6)
```

It is a stronger compatibility theorem than 2-transitivity of the cover.

## 5.4 The transvection route for h=2

For h=2, equation (3.2) gives rank(T_0^3-1)=1, so the local monodromy contains a transvection. This is the one case where a transvection classification is genuinely available.

A proof of Sp_6 would still require:

```plain text
- geometric irreducibility;
- primitivity of the connected action;
- exclusion of tensor induction;
- confirmation that the transvection lies in the geometric group.
```

The first and last are plausible from the current certificates/local calculation, but the full package has not yet been banked. Thus even h=2 should presently be labeled conditional, not proved.

# 6. Equidistribution and the flat-law interpretation

Assume for this section that h>=2 is fixed, G_h is defined over a good finite field, and

```plain text
G_geom(G_h)=Sp_(4h-2).
```

Put

```plain text
2g=4h-2,
g=2h-1.
```

## 6.1 The standard vertical theorem

For a fixed characteristic p and extension fields F_q with q=p^n tending to infinity, Deligne-Katz equidistribution gives normalized Frobenius conjugacy classes in a maximal compact form of the geometric group. After the symplectic normalization, this compact group is

```plain text
USp(4h-2).                                          (6.1)
```

More precisely, after accounting for any finite arithmetic component or constant-field twist, the classes for t in F_q^* equidistribute in the corresponding compact coset. Absolute trace statistics are the same symplectic statistics.

The phrase fixed h, p -> infinity is horizontal across characteristics, not vertical. To obtain that limit one needs an integral compatible model over Z[1/B_h], stability of the geometric monodromy at good primes, and the uniform form of the trace formula. For fixed h this is a reasonable conditional theorem, but it is not a formal consequence of a monodromy calculation at one prime.

## 6.2 Exact fixed-moment consequences

Let

```plain text
tau_(h,q)(t)=-(S_(h,q)(t)+1)/sqrt(q).
```

For each fixed integer m with

```plain text
1<=m<=g=2h-1,
```

classical symplectic invariant theory gives

```plain text
Integral_USp(2g) Tr(U)^(2m) dU = (2m-1)!!,
Integral_USp(2g) Tr(U)^(2m+1) dU = 0.               (6.2)
```

Thus equidistribution gives

```plain text
1/(q-1) sum_(t in F_q^*) tau_h(t)^(2m)
 = (2m-1)!! + O_(h,m)(q^(-1/2)),                    (6.3)

1/(q-1) sum_(t in F_q^*) tau_h(t)^(2m+1)
 = O_(h,m)(q^(-1/2)).                               (6.4)
```

The constants in the errors are fixed when h and m are fixed. They are not uniform in a regime m or h grows with q.

## 6.3 A rigorous tail statement

For any lambda>0 and any integer 1<=m<=2h-1, Markov's inequality and (6.3) give

```plain text
#{t: |tau_h(t)|>=lambda}/(q-1)
 <= (2m-1)!!/lambda^(2m)
    + O_(h,m)(q^(-1/2)).                             (6.5)
```

Choosing m comparable to lambda^2, while m<=2h-1, yields

```plain text
proportion(|tau_h|>=lambda)
 <= C exp(-c lambda^2)+O_(h,lambda)(q^(-1/2))        (6.6)
```

through the Gaussian stable range

```plain text
lambda^2 << h.
```

This is the precise rigorous version of the qualitative flat trace law at fixed moments.

## 6.4 What equidistribution does not prove about the maximum

The deterministic bound remains

```plain text
max_(t!=0) |S_h(t)+1|/sqrt(q) <= 4h-2.               (6.7)
```

Equidistribution with an O(q^(-1/2)) discrepancy cannot resolve a tail event of probability about 1/q. Therefore it cannot prove the extreme-value law

```plain text
max_t |S_h(t)|/sqrt(q) approximately sqrt(2 log q).  (6.8)
```

There is a stronger conceptual correction. In a genuine fixed-h equidistribution limit, rank r=4h-2 is fixed. Every neighborhood of the identity in USp(r) has positive Haar measure, and its trace is arbitrarily close to r. Consequently, in any fixed-rank equidistribution regime,

```plain text
max_t |tau_h(t)| -> 4h-2,                            (6.9)
```

not sqrt(2 log q).

The empirical law (6.8) belongs to a double limit:

```plain text
h -> infinity,
q -> infinity,
rank 4h-2 large enough that the central trace law is Gaussian,
but q not large enough to sample the compact-group spectral edge.  (6.10)
```

For Haar USp(2g), Tr(U) tends to a real N(0,1) as g tends to infinity. The maximum of q independent such variables is near sqrt(2 log q). This explains the data, but proving it for the sheaf values would require all of the following:

```plain text
- monodromy Sp_(4h-2) uniformly in growing h;
- moment estimates up to m comparable to log q;
- trace-formula errors uniform in those tensor powers;
- high-order independence or a Poisson law for rare exceedances.
```

None is supplied by fixed-h Katz equidistribution. In particular, even a perfect one-point limiting distribution does not determine the maximum.

The user's complex-Gaussian model should be replaced by a real-Gaussian model, because the symmetry group is symplectic and the standard trace is real.

# 7. Pair monodromy and one fixed correlation

Let h,k>=2, h!=k, and assume

```plain text
G_geom(G_h)=Sp_(r_h),
r_h=4h-2,

G_geom(G_k)=Sp_(r_k),
r_k=4k-2.
```

Since r_h!=r_k, the simple algebraic groups PSp_(r_h) and PSp_(r_k) are nonisomorphic. A connected Goursat argument therefore gives

```plain text
G_geom(G_h direct_sum G_k)
 = Sp_(r_h) x Sp_(r_k).                              (7.1)
```

There is no nontrivial connected common quotient. The common center does not create a quotient to a finite group because a connected algebraic group has trivial image in a finite etale group.

Thus pair independence is automatic once both individual groups are full symplectic. The statement that the complete local type determines h is useful for ruling out rank-one twists or accidental isomorphisms, but for h!=k the rank already distinguishes the two standard representations.

## 7.1 The pure correlation sheaf

Define

```plain text
A_h(t)=S_h(t)+1,

Gamma^+_(h,k)
 = sum_(t in F_p^*) A_h(t) conj(A_k(t)).             (7.2)
```

The relevant sheaf is

```plain text
H_(h,k)=G_h tensor G_k^vee.                          (7.3)
```

Product monodromy implies that H_(h,k) has no geometric invariant vector. Hence

```plain text
H_c^2(G_m,H_(h,k))=0.                                (7.4)
```

The trace formula gives

```plain text
Gamma^+_(h,k)
 = -Tr(Frob_p | H_c^1(G_m_bar,H_(h,k))).             (7.5)
```

Under the proposed local type, let

```plain text
B_h=4h-4,
B_k=4k-4,
e_(h,k)=number of common critical values,
```

counted with multiplicity. At infinity, the tensor product has slope one in

```plain text
2B_h + 2B_k + B_h B_k - e_(h,k)
```

directions. At zero it is tame. Therefore

```plain text
Swan_infinity(H_(h,k))
 = r_h r_k - 4 - e_(h,k).                            (7.6)
```

If the critical-value sets are disjoint, e_(h,k)=0. Grothendieck-Ogg-Shafarevich, together with (7.4), gives

```plain text
dim H_c^1(G_m,H_(h,k))
 = r_h r_k - 4 - e_(h,k).                            (7.7)
```

Since H_(h,k) is pure of weight two, Deligne gives the fixed-pair estimate

```plain text
|Gamma^+_(h,k)|
 <= (r_h r_k-4-e_(h,k)) p^(3/2).                    (7.8)
```

This is the generic dimension times p^(3/2) bound. Big product monodromy removes a p^2 main term, but it does not remove the dimension factor.

## 7.2 Raw versus pure correlation

For the raw correlation in the question,

```plain text
Gamma_(h,k)=sum_(t!=0) S_h(t) conj(S_k(t)),
```

one has

```plain text
Gamma_(h,k)
 = Gamma^+_(h,k)
   -sum_(t!=0)A_h(t)
   -sum_(t!=0)conj(A_k(t))
   +(p-1).                                           (7.9)
```

Fourier orthogonality gives

```plain text
sum_(t!=0)A_h(t)
 = p * #{x in U_h(F_p): f_h(x)=0} - |U_h(F_p)|,
```

so this correction is O(ph) for fixed h. It is lower order than p^(3/2) when h is fixed, but it must be restored in a growing-h theorem.

# 8. Why pair big monodromy does not prove the requested k-average

The desired estimate is

```plain text
sum_(k<=H) |Gamma_(h,k)|^2 << H p^3.                (8.1)
```

After pure normalization, put

```plain text
C_(h,k)=sum_(t!=0) tau_h(t) tau_k(t).
```

Since A_j=sqrt(p) times tau_j,

```plain text
Gamma^+_(h,k)=p C_(h,k).
```

Thus (8.1) is equivalent, up to the explicit boundary corrections, to

```plain text
sum_(k<=H) |C_(h,k)|^2 << H p.                      (8.2)
```

This is a rowwise large-sieve bound for the trace functions tau_k.

## 8.1 The cohomological object

For each k define the global correlation space

```plain text
V_(h,k)
 = H_c^1(G_m_bar, G_h tensor G_k^vee).               (8.3)
```

Then

```plain text
Gamma^+_(h,k)=-Tr(Frob_p | V_(h,k)).                 (8.4)
```

Consequently

```plain text
sum_(k<=H)|Gamma^+_(h,k)|^2
```

is the Frobenius trace on the direct sum

```plain text
direct_sum_(k<=H)
  (V_(h,k) tensor V_(h,k)^conj).                     (8.5)
```

The dimensions in (7.7) are of order hk. Hence the rank of (8.5) is of order

```plain text
sum_(k<=H) (hk)^2
 comparable to h^2 H^3.                              (8.6)
```

Applying Deligne directly to (8.5) reproduces only

```plain text
sum_(k<=H)|Gamma^+_(h,k)|^2
 << h^2 H^3 p^3,                                    (8.7)
```

up to local constants. This is far from (8.1).

The point is structural: individual big monodromy acts on the stalk spaces of G_k. It does not give a random-matrix theorem for Frobenius acting on the different global cohomology spaces V_(h,k) as k varies.

## 8.2 What the standard fourth moments do compute

For one symplectic standard representation V of rank at least four,

```plain text
dim (V^(tensor 4))^Sp = 3.                           (8.8)
```

For two independent symplectic groups acting on V_h and V_k,

```plain text
average_USp x USp
  Tr(U_h)^2 Tr(U_k)^2 = 1.                           (8.9)
```

Therefore product equidistribution gives, for fixed h!=k,

```plain text
1/(p-1) sum_t |tau_h(t)|^2 |tau_k(t)|^2
 = 1 + O_(h,k)(p^(-1/2)),                            (8.10)
```

and for one h,

```plain text
1/(p-1) sum_t |tau_h(t)|^4
 = 3 + O_h(p^(-1/2)).                                (8.11)
```

These are pointwise fourth moments in the variable t. They do not evaluate

```plain text
|sum_t tau_h(t)tau_k(t)|^2.                          (8.12)
```

Expression (8.12) has two independent variables t,u after expansion and a global cohomology trace. The invariant count 3 or 1 is therefore not the required second moment.

## 8.3 The missing two-point kernel

Expanding (8.2) gives

```plain text
sum_(k<=H)|C_(h,k)|^2
 = sum_(t,u)
     tau_h(t) tau_h(u)
     K_H(t,u),                                       (8.13)
```

where

```plain text
K_H(t,u)=sum_(k<=H) tau_k(t) tau_k(u).               (8.14)
```

Individual or pair monodromy controls fixed products at one t. It gives no uniform control of the two-point kernel K_H(t,u) as the discrete recurrence length k grows.

To make (8.13) cohomological with bounded complexity, one would need an algebraic family

```plain text
G over G_m,t x T_k
```

whose fibers at the integer points k are the G_k, with rank/conductor controlled uniformly in the k-direction. No such bounded-complexity clock family is currently known. The addition law for delta_k is a recurrence identity, not an algebraic parameterization of the sheaves G_k by a fixed finite-type base.

Thus the prize estimate is a genuinely new family theorem.

## 8.4 Minimal named lemma

The precise next target is

```plain text
[FOURIER-CORR-LS]

For every epsilon>0, uniformly in the required range of p,h,H,

sum_(2<=k<=H, k!=h)
 |sum_(t in F_p^*) tau_h(t)tau_k(t)|^2
 <<_epsilon H p^(1+epsilon).                         (8.15)
```

In raw weight-one normalization this is

```plain text
sum_k |Gamma^+_(h,k)|^2
 <<_epsilon H p^(3+epsilon).                         (8.16)
```

Proving (8.15) would be the first genuine cross-h Fourier cancellation theorem. It is not a corollary of [FOURIER-M4-3], even if every G_h has full symplectic monodromy.

A sufficient second-level geometric input would be:

```plain text
- a bounded-complexity algebraization of k -> G_k;
- product monodromy for the correlation cohomology V_(h,k);
- fourth moment 2 or 3 for that second-level representation;
- uniform conductor bounds after the t-pushforward.
```

This is exactly the same family-compatibility wall that appears in COINC and GPRV, now expressed one categorical level higher.

# 9. Final theorem ledger

## 9.1 Proved now

```plain text
[A] Correct pure rank:
    rank G_h = 4h-2,
    trace = -(S_h(t)+1).

[B] Even real trace:
    S_h(-t)=S_h(t)=conj(S_h(t)).

[C] Symmetry type:
    G_h has a canonical alternating pairing,
    so G_geom is contained in Sp_(4h-2).

[D] h=1 exception:
    G_1 splits geometrically into cubic Kummer pieces.

[E] Irreducibility dictionary:
    G_h irreducible iff the degree-3h cover is 2-transitive,
    not merely transitive.

[F] Conditional Larsen implication:
    [LOCAL_h] + M4_h=3 + h>=2
    implies G_geom=Sp_(4h-2).

[G] Fixed-pair Goursat implication:
    full Sp for h and k, h!=k,
    implies product connected monodromy.
```

## 9.2 Conditional on the parallel local audit

```plain text
[LOCAL_h]
The exact inertia decompositions (2.9) and (2.10),
including the rank-2 tame part at infinity and all multiplicities.
```

## 9.3 Open all-h statements

```plain text
[AUG-2TRANS_h]
The off-diagonal same-fiber curve of f_h is geometrically irreducible.

[FOURIER-M4-3]
The pure Fourier sheaf has fourth moment 3.

[BIGMON_h]
G_geom(G_h)=Sp_(4h-2).
This follows from [LOCAL_h]+[FOURIER-M4-3].

[FOURIER-CORR-LS]
The rowwise cross-h correlation bound (8.15).
```

The correct strategic order is:

```plain text
1. Finish [LOCAL_h].
2. Prove the augmentation 2-transitivity input.
3. Attack the centered four-variable law (5.5).
4. Deduce Sp by Larsen's Alternative.
5. Treat [FOURIER-CORR-LS] as a separate second-level family theorem.
```

Big monodromy is a plausible and structurally well-motivated explanation of the observed flat trace distribution. It is not yet a proof of the flat maximum law, and even full pairwise big monodromy does not by itself cross the h-family correlation wall.
