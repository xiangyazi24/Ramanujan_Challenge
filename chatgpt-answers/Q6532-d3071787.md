(1) Correction of Q6530 T3 interpolation

The correction is right.

For general k>=3:

E = sum_v m_v^2
T_k = sum_v (m_v)_k

Use
m^k = (m)_k + O_k(m^{k-1})

For the high part m_v > M:

m_v^2 <= M^(2-k) m_v^k

therefore

E_high <= M^(2-k) sum_v m_v^k
       <= M^(2-k) (T_k + O_k(E) + O(N))

Set M = p^mu.

Low part:

E_low = sum_{m_v<=M} m_v^2
      <= M sum_v m_v
      <= p^mu * p
      = p^(1+mu).

Hence

E <= p^(1+mu) + p^(tau_k+(2-k)mu) + C p^((2-k)mu) E.

Absorb when

p^((2-k)mu) <= 1/2.

Balance:

1+mu = tau_k + (2-k)mu

(k-1)mu = tau_k-1

mu = (tau_k-1)/(k-1).

Exponent:

f_k(tau_k)=1+mu
          = (tau_k+k-2)/(k-1).

For k=4:

f_4=(tau_4+2)/3.

Need

(tau_4+2)/3 < 3/2

iff tau_4 < 5/2.

So the proposed correction is confirmed.

E_B <= min(M^(-1)T3, M^(-2)T4)

(3) Two-threshold strategy

Let M3=p^a, M4=p^b, with a<=b.

Ranges:

I: m<=M3
II: M3<m<=M4
III: m>M4

Bounds:

I:

E_I <= p^(1+a).

II:

use T3:

E_II <= M3^(-1) T3
      <= p^(tau3-a).

III:

use T4:

E_III <= M4^(-2) T4
      <= p^(tau4-2b).

Hence

E <= p^(1+a)+p^(tau3-a)+p^(tau4-2b).

The third term can be pushed down by b, subject only to the fact that the T4 estimate must cover III.
The optimizer sets

1+a = tau3-a

and chooses b large enough that

tau4-2b <= 1+a.

Thus

1+a=(tau3+1)/2

and the T4 term helps only if

b >= (tau4-(tau3+1))/2.

Therefore a genuine improvement over k=3 requires T4 strong enough that the required b is compatible with the available maximum multiplicity range.

With present data this is not the case.

Therefore T3 is the cheaper target.
