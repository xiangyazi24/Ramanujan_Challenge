## Verdict

The correct outcome is objective **(2)**.

The four-scalar construction is exact and useful, but it does not presently prove

```text
log C*_n = o(n).
```

For every prime `p > sqrt(n)`, write

```text
n = a p + r,   0 <= r < p,   a < p,
L = p Lambda_p,   p does not divide Lambda_p.
```

There is an exact local factorization

```text
X_0(n)  = Lambda_p^2 b_r C_a                         (mod p),
Y_0(n)  = Lambda_p^2 b_r D_a                         (mod p),
Y*_n    = Lambda_p^2 b_r kappa_(M,p) E_(a,b)         (mod p).
```

Here

```text
C_a = sum_(j=1)^a (-1)^(j+1) b_(a-j)/j^2,
D_a = sum_(j=1)^a (-1)^j b_(a-j) H_(j-1)/j,
M   = floor((n-1)/2),
M-1 = b p + s,   0 <= s < p,
```

and `kappa_(M,p)` and `E_(a,b)` are the explicit integers/rationals in Sections 4 and 5 below. All displayed denominators are `p`-units.

Consequently

```text
p | C*_n
iff
b_r = 0 (mod p)
    or
C_a = D_a = kappa_(M,p) E_(a,b) = 0 (mod p).
```

The second alternative is an outer-block nuisance. Its total logarithmic mass for `p > sqrt(n)` is unconditionally

```text
O(n^(2/3)).
```

Thus, if

```text
Rmov(n) = product of primes p > sqrt(n) with p | b_(n mod p),
```

then

```text
Rmov(n) | rad(C*_n),
rad(C*_n) | Rmov(n) Err_n,
log Err_n = O(n^(2/3)).
```

Since `C*_n | L^2`, every exponent is at most two in this range, and therefore

```text
log Rmov(n) <= log C*_n
             <= 2 log Rmov(n) + O(n^(2/3)).
```

In particular,

```text
log C*_n = o(n)
iff
sum_(sqrt(n)<p<=n, p|b_(n mod p)) log p = o(n).
```

The known Lucas comparison gives a second exact reduction:

```text
sum_(sqrt(n)<p<=n, p|b_(n mod p)) log p
=
log rad_{p>sqrt(n), p|b_n}(b_n) + O(n^(2/3)).
```

Therefore the four-scalar gcd is, up to a proved sublinear error and the harmless exponent-two cap, an exact carrier for the already isolated large-prime numerator problem. It does not create a new coprimality theorem.

The convolution identity `B(z) * 1/B(z) = 1`, the special Newton functional defining `Y*_n`, adjacent-`n` relations, and the Apéry recurrence do not alter this conclusion. Locally they modify only the outer vector `(C_a,D_a,kappa E)`; all three observations still contain the same scalar `b_r`. After primitive saturation, every exterior minor either vanishes identically on the rank-one observation module or retains the moving factor `b_r`.

## 2. The `p > sqrt(n)` localization

Fix an odd prime `p > sqrt(n)` and write

```text
n = a p + r,
0 <= r < p.
```

Since `n < p^2`,

```text
v_p(L) = 1.
```

Write

```text
L = p Lambda_p,
p does not divide Lambda_p.
```

Also

```text
a = floor(n/p) < p.
```

Thus every denominator involving an integer `1,...,a` is a `p`-unit.

Only indices divisible by `p` can survive in `X_0` modulo `p`. Indeed, if `p` does not divide `k`, then `(L/k)^2` is divisible by `p^2`. If `k=j p`, then

```text
L/(j p) = Lambda_p/j,
1 <= j <= a.
```

Similarly, only `k=j p` can survive in `Y_0` or `Y*_n` modulo `p`. For `p` not dividing `k`, the factor `L^2/k` has valuation two, while `H_(k-1)` has valuation at least `-1` because `k-1<n<p^2`; hence `g_k` is still divisible by `p`.

At a multiple `k=j p`, the exact harmonic reduction is

```text
p H_(j p-1) = H_(j-1)   (mod p).
```

The proof is termwise: nonmultiples of `p` disappear after multiplication by `p`, and multiples `p,2p,...,(j-1)p` contribute `1,1/2,...,1/(j-1)`.

Finally, Apéry Lucas gives

```text
b_((a-j)p+r) = b_(a-j) b_r   (mod p).
```

These three observations give the first two local formulas.

## 4. Exact reduction of the Newton interpolant at multiples of `p`

The nontrivial point is the evaluation of `Q*_M(jp)` when `p<=M`. It is not legitimate to replace it by `Q*_M(0)`; factorial denominators in a monomial interpolation formula would cross `p`. The integer-valued Newton basis resolves this exactly.

Write

```text
M-1 = b p + s,
0 <= s < p.
```

Recall

```text
Q*_M(x) = sum_(m=0)^(M-1) d_m binom(x-1,m),
d_m = Delta^m q_1.
```

For

```text
m = alpha p + beta,
0 <= beta < p,
```

Lucas gives

```text
binom(jp-1, alpha p+beta)
=
binom(j-1,alpha) binom(p-1,beta)
=
(-1)^beta binom(j-1,alpha)       (mod p).
```

Every complete block of `p` Newton coefficients vanishes. Precisely, for `alpha<b`,

```text
sum_(beta=0)^(p-1) (-1)^beta d_(alpha p+beta) = 0   (mod p).
```

To prove this, let `E` be the shift operator and `Delta=E-1`. In characteristic `p`,

```text
sum_(beta=0)^(p-1) (-1)^beta Delta^beta
=
E^(p-1).
```

Indeed the geometric sum is

```text
(1-(-Delta)^p)/(1+Delta)
=
(1+Delta^p)/E
=
E^p/E.
```

Therefore the complete block is

```text
Delta^(alpha p) E^(p-1) q_1
=
Delta^(alpha p) q_p
=
(E^p-1)^alpha q_p.
```

It is an integral linear combination of

```text
q_p, q_(2p), ..., q_((alpha+1)p),
```

and every one is divisible by `p` because

```text
q_(t p) = (-1)^(t p+1) t p h_(t p).
```

Only the final partial block remains. Define

```text
kappa_(M,p)
:=
sum_(beta=0)^s (-1)^beta d_(b p+beta) in Z.
```

Then the exact evaluation is

```text
Q*_M(jp)
=
kappa_(M,p) binom(j-1,b)      (mod p),
1 <= j <= a.
```

This identity includes every crossing of the interpolation range and every divided quotient variable implicitly present in the Newton construction. In particular it correctly gives zero for `j<=b`.

```text
E_(a,b)
:=
```

The binomial factor automatically removes `j<=b`. Combining Sections 2 and 4 gives

```text
Y*_n
=
Lambda_p^2 b_r kappa_(M,p) E_(a,b)      (mod p).
```

No denominator divisible by `p` occurs:

```text
a<p,
b<a,
Q*_M(jp) is an integer.
```

The complete base-`p` support condition is therefore

```text
p | C*_n
iff
b_r C_a = 0,
b_r D_a = 0,
```


## 7. Exact comparison with moving zeros and with `b_n`

Define

```text
Rmov(n)
=
product_(sqrt(n)<p<=n, p|b_(n mod p)) p.
```

Section 5 proves that every prime in `Rmov(n)` divides all three nontrivial scalars, and of course divides `L^2`. Thus

```text
Rmov(n) | rad(C*_n).
```

Section 6 proves the reverse inclusion up to an integer `Err_n` with

```text
log Err_n = O(n^(2/3)).
```

Hence

```text
rad(C*_n) | Rmov(n) Err_n
```

after the small-prime part is separated.

The small-prime part of `L^2` has logarithm `O(sqrt(n))`. Indeed

```text
sum_(p<=sqrt(n)) 2 floor(log_p n) log p
=
O(sqrt(n)).
```

For `p>sqrt(n)`, `v_p(L^2)=2`. Therefore

```text
log Rmov(n)
<=
log C*_n
<=
2 log Rmov(n)+O(n^(2/3)).
```

There is also an exact comparison with the single Apéry coefficient `b_n`. Lucas gives

```text
b_n = b_a b_r   (mod p).
```

Thus every moving zero prime divides `b_n`. Conversely, a prime `p>sqrt(n)` which divides `b_n` but not `b_r` must divide `b_a`. The same split at `a=n^(1/3)` gives

```text
sum_(p>sqrt(n), p|b_n, p not dividing b_r) log p
=
O(n^(2/3)).
```

Therefore

```text
log Rmov(n)
=
log rad_{p>sqrt(n), p|b_n}(b_n)
+O(n^(2/3)).
```

Combining the two comparisons gives the exact proof-level status:

```text
log C*_n=o(n)
iff
log rad_{p>sqrt(n), p|b_n}(b_n)=o(n).
```

No known theorem for nonconstant P-recursive coefficients proves the right-hand side. Constant-coefficient recurrence gcd theorems, fixed-torus Subspace-Theorem gcd results, and fixed-set-of-places statements do not match these hypotheses.

## 8. What the convolution identity does and does not do

The identity

```text
B(z)R(z)=1
```

gives exact coefficient relations

```text
sum_(i=0)^m b_i rho_(m-i) = delta_(m,0).
```

It is exactly what makes `h_t`, `q_t`, and `Q*_M` integral and what causes the complete Newton blocks in Section 4 to vanish modulo `p`.

It does **not** remove the common factor `b_r` from the localized observation vector. Over `F_p`, set

```text
z = b_r,
c = C_a,
d = D_a,
e = kappa_(M,p)E_(a,b).
```

The observation scheme is

```text
X = z c,
Y = z d,
Z = z e.
```

This is a rank-one scalar module.

All exterior `2x2` minors vanish identically:

```text
X d - Y c = 0,
X e - Z c = 0,
Y e - Z d = 0.
```

They vanish for every residue `z`, not only when `z=0`. They are therefore recurrence/convolution identities, not target selectors.

If one imposes the target `z=0` and eliminates `z,X,Y,Z`, the elimination ideal in the outer variables is zero:

```text
(z, X-zc, Y-zd, Z-ze) intersect F_p[c,d,e] = (0).
```

Thus no resultant or Fitting minor can produce a nonzero polynomial condition on `(c,d,e)` from targetness. Any nonzero coefficient obtained after clearing is coefficient content.

Conversely, if one proves that `(c,d,e)` generates the unit ideal for every relevant `p`, the gcd detects exactly `z=0`; this would improve the nuisance term from `O(n^(2/3))` to zero, but it would still leave the complete moving-zero radical `Rmov(n)`. It would not prove a height bound for that radical.

This is the precise four-scalar saturation theorem.

## 9. Adjacent-`n` and recurrence resultants do not supply a common factor

Suppose `p>sqrt(n)` and `p|b_r`, with `1<=r<=p-2`. The Apéry recurrence below `p` has unit leading and trailing coefficients, and consecutive Apéry values cannot both vanish modulo `p`. Hence

```text
p does not divide b_(r-1)b_(r+1).
```

At `n+1`, the localized scalar factor is `b_(r+1)`; at `n-1`, it is `b_(r-1)`. Therefore an adjacent gcd removes the target prime rather than preserving it.

The three-term recurrence

```text
(m+1)^3 b_(m+1) - P(m)b_m + m^3 b_(m-1)=0
```

determines neighboring coordinates from one free state coordinate at every regular row. Eliminating that coordinate gives the zero ideal. An Ore resultant concerns common shift-invariant solution modules; the event `p|b_r` at one moving index is not such a module condition.

Thus an adjacent-`n` resultant either

1. retains the current value carrying `b_r`, with exponential height, or
2. eliminates it and leaves only a universal recurrence identity.

There is no primitive third case inside this four-scalar module.

## 10. Exact quotient descent and why it is not a fixed carrier

A mesoscopic moving zero does descend to a top-half target, but at a prime-dependent outer index.

If

```text
p | b_r,
N_p := p+r,
```

then `p>N_p/2` and Lucas gives

```text
b_(N_p) = b_(p+r) = 5 b_r   (mod p).
```

Thus `p` is a top-half target for `N_p`.

This is an exact descent. It does not create one smaller characteristic-zero integer for the original `n`, because

```text
N_p = n-(a-1)p
```

varies with `p`. Multiplying carriers over all possible `N_p` loses the desired height, while taking a gcd has no common prime because the indices differ. The descent therefore converts the mesoscopic support into a moving family of top-half problems; it does not compress that family.

Descent to the small outer digit `a` is impossible for the same elementary reason: `p>a`, so `p` is absent from `lcm(1,...,a)` and cannot occur in `C*_a`.

## 11. Endpoint bookkeeping

The local derivation is valid for every odd `p>sqrt(n)`. The endpoint residues are harmless.

- If `r=0`, then `b_r=1`, so only the outer nuisance alternative can occur.
- If `r=p-1`, reflection gives `b_(p-1)=b_0=1 (mod p)`.
- A top prime cannot equal `n`: `b_p=5 (mod p)`.
- A top prime cannot divide `n+1` and be a target: the possible case `n=2p-1` gives `b_(2p-1)=5b_(p-1)=5 (mod p)`.

All harmonic and Newton denominators used above are units because `a<p`; the interpolation polynomial itself is integer-valued, so crossing `M>=p` introduces no hidden denominator.

## 12. Specific no-go theorem for the four-scalar module

Define the **inverse-Apéry four-scalar carrier class** to consist of expressions obtained from

```text
L^2, X_0(n), Y_0(n), Y*_n,
```

together with:

1. the coefficient identities from `B(z)R(z)=1`;
2. finite linear combinations with denominators that are units at the tested `p>sqrt(n)`;
3. determinants, exterior minors, Fitting minors, ordinary resultants, and subresultants of these linear identities;
4. gcds whose prime support is certified operandwise;
5. finite adjacent-`n` uses of the Apéry recurrence;
6. primitive saturation by coefficient content and universal powers coming from `L`.

### Theorem

For every `p>sqrt(n)`, every formally target-forced `p`-factor produced in this class has one of the following forms.

1. It remains in the common scalar `b_(n mod p)`, or in a characteristic-zero value such as `b_n` which carries that scalar by Lucas.
2. It lies in the outer coefficient content `C_a,D_a,kappa E`; the total logarithmic mass of such primes is `O(n^(2/3))`.
3. It belongs to an exterior or resultant identity which vanishes before targetness and becomes zero after primitive saturation.

There is no nonzero primitive determinant or resultant in this class that both removes the moving factor `b_r` and retains a target-derived `p`-factor.

### Proof

The exact local factorization in Sections 3--5 identifies the observation module as

```text
b_r times a single outer vector.
```

Primitive gcd support is therefore the union of the scalar-zero locus and the outer-content locus. Section 6 bounds the latter. Every exterior minor of a one-dimensional image is zero. Eliminating the scalar from the target fiber leaves the zero ideal in the outer variables. The adjacent recurrence has one free regular state coordinate and does not preserve a target prime at neighboring indices. These statements are stable under all operations in the class. This proves the theorem.

## Final conclusion

The four-scalar inverse-Apéry gcd is a correct exact carrier, and its mesoscopic local structure can be derived completely:

```text
(X_0,Y_0,Y*)
=
unit * b_(n mod p) * (C_a,D_a,kappa E)   (mod p).
```

The inverse-series Newton functional succeeds in two ways:

1. it is genuinely integral across the interpolation boundary;
2. complete base-`p` Newton blocks cancel exactly.

But it does not create a second lower-digit equation. The genuine moving-zero primes remain automatic common divisors of all four scalars. All non-moving-zero contamination has logarithmic mass `O(n^(2/3))`, which is the strongest unconditional aggregate bound obtained here.

Therefore

```text
log C*_n=o(n)
```

is equivalent, up to proved sublinear errors and an exponent-two cap, to the large-prime radical bound for the single Apéry number `b_n`. Proving it requires new arithmetic beyond the four-scalar convolution/recurrence module.
