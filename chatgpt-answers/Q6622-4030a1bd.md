# Q6622 — Dual Apéry normal function extraction

## Executive verdict

The viable candidate is not a new period satisfying the same rank-4 Picard–Fuchs equation. It must be the depth-2 unipotent coordinate of the mixed object. Concretely, introduce a second extension coordinate `J` by integrating the first normal function against the dual horizontal section.

The construction below is a computable rank-5 iterated-extension model. It is the version most suitable for machine tests.

## 1. Explicit rank-5 construction

Let the Apéry operator be

```
L = theta^3 - t(34 theta^3+51 theta^2+27 theta+5)+t^2(theta+1)^3.
```

Let `b(t)` and `c(t)` be the two previously constructed solutions/normal coordinates with

```
L(b)=0,
L(c)=source_c(b).
```

Define the dual normal coordinate by the inhomogeneous equation

```
L(J)=R(t;b,c),
```

where `R` is the canonical quadratic extension source obtained from the cup product of the two weight-graded pieces. In Frobenius-compatible coordinates it is represented by

```
R = <omega_b, nabla omega_c> - <omega_c, nabla omega_b>.
```

This antisymmetrization is essential: the symmetric part is killed by a splitting change.

At the coefficient level write

```
b(t)=sum b_n t^n,
c(t)=sum c_n t^n,
J(t)=sum J_n t^n.
```

Then `J_n` is computed by the same Apéry three-term recurrence with an added source:

```
(n+1)^3 J_{n+1}
 = (34 n^3+51 n^2+27 n+5) J_n
   - n^3 J_{n-1}
   + S_n(b,c),
```

where

```
S_n(b,c)=sum_{i+j=n} (i-j)(b_i c_j-b_j c_i).
```

Thus one computes `J_0,J_1,...,J_N` in O(N) recurrence steps after maintaining the convolution source.

## 2. Frobenius law and ambiguity

For a Frobenius lift `phi(t)=t^p` in the constant-source gauge, the rank-5 matrix has form

```
Phi_5 =
[ F   z   j ]
[ 0  p^3  e ]
[ 0   0  p^6 ]
```

with old extension coordinate `z` and new corner `j`.

The new coordinate transforms as

```
J(phi(t)) = p^6 J(t) + A(t)c(t)+B(t)b(t)+D(t),   mod p^4.
```

The terms `A c+B b+D` are coboundaries. They arise from changing the splitting of the two successive extensions.

Allowed gauge transformations are therefore

```
J -> J + u(t)b(t)+v(t)c(t)+constant.
```

## 3. Gauge invariant combination

The raw `J` is not invariant. The invariant depth-2 return is the alternating determinant

```
K_h(r)=J_h(r)-alpha_h(r)c_h(r)-beta_h(r)b_h(r),
```

where `alpha,beta` are uniquely fixed by the Frobenius normalization and vanish on the basepoint.

Equivalent formulation:

```
K = class(J) in Ext^2(Q,H^2)
```

rather than a representative in the chosen splitting.

This passes S1/S6: it is not generated by `(b,c)` unless the Ext^2 class vanishes. The previous Family I collapse corresponds exactly to the special case `K=0`.

## 4. Collision payoff

For a depth-h return define

```
N_h^prim(r)= numerator of the old mixed return,
J_h^prim(r)= numerator of K_h(r).
```

A collision gives

```
N_h^prim(r)=0,
J_h^prim(r)=0.
```

The hoped-for replacement of the one-equation argument is therefore

```
deg gcd(N_h^prim,J_h^prim) << h^(1-eta).
```

The gain comes only if `J_h^prim` is genuinely independent in the function field. If it factors through `(b,c)`, this route dies exactly like Family I.

## 5. Machine recursion mod p^4

For p=13,17 the direct test is:

```
J[0]=0
J[1]=0
for n=1..p-2:
    S=0
    for i=0..n:
        S += (i-(n-i))*(b[i]*c[n-i]-b[n-i]*c[i])
    J[n+1]=((34*n^3+51*n^2+27*n+5)*J[n]
             -n^3*J[n-1]+S)/(n+1)^3 mod p^4
```

Then test:

```
J(phi(t))-p^6 J(t)
```

against the span of `b,c,1` modulo `p^4`.

A successful test requires:

1. the residual is always in the coboundary span;
2. the normalized residual has nonzero depth-2 component;
3. collision fibers show smaller gcds after adjoining `J_h`.

## 6. Least-confident step

The least-confident step is the exact identification of the source term `S_n(b,c)` with the syntomic biextension cup product. The rank-5 formalism is standard, but the normalization matching the Apéry integral model still needs a regulator computation.

## 7. Likely shared blind spot

The likely blind spot is confusing a new representative with a new invariant. Many candidate coordinates look independent until quotienting by splitting changes. The decisive object is the Ext^2 class, not the fifth matrix entry itself.
