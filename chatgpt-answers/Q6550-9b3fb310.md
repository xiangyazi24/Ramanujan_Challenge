# Hostile audit of the Casoratian coincidence route

## Executive verdict

The audit has three separate conclusions.

1. [SURVIVES] D1, D2, D3, and the conditional estimate D4 are correct on the stated nonwrapping window.

1. [FATAL TO THE CLAIMED BYPASS, NOT TO THE CONDITIONAL IMPLICATION] The condition [COINC] is exactly an L2 equidistribution statement for all Casoratian values. Its zero coordinate is the desired small-gap collision count. More precisely, the excess in [COINC] contains the nonnegative term

```plain text
(sum_{h<=H} C_h - #S_H/p)^2.
```

Therefore [COINC] is not circular as a hypothesis, but any proof of [COINC] must already control the zero fiber at exactly the scale needed in D4. The Parseval step does not make the zero problem disappear; it embeds it as one coordinate of a stronger all-value variance problem.

1. [FORMAL ERROR, REPAIRABLE] D5 invokes the wrong object from the proved sigma ladder. In the paper, Q_p(Delta) is a triple-return quantity

```plain text
Q_p(Delta) = sum_r binom(d_Delta(r),2),
```

not the pair count sum_{h<=Delta} C_h. Thus [COINC] does not establish the sigma-ladder hypothesis. However, the advertised conditional conclusion

```plain text
[COINC] at H = p^(2/3)  ==>  F_p << p^(4/3)
```

is still correct by the original block-energy inequality, without using the sigma ladder.

1. [SECOND GEOMETRIC ERROR] The claimed per-pair Weil error O((h+h') sqrt(p)) does not follow from the displayed bidegree alone. A generic irreducible curve of bidegree O(h), O(h') in P1 x P1 has genus O(h h'), so the standard error is O(h h' sqrt(p)). The smaller O((h+h') sqrt(p)) requires a new special low-genus theorem. This only makes the small-H range weaker.

1. [NO UNCONDITIONAL IMPROVEMENT] Even granting the optimistic per-pair error and complete component control, the resulting [COINC] range H <= p^(1/4) gives a worse bound on sum C_h than the already proved polynomial-degree bound. No improvement over ENERGY-3/2 follows in any range H <= p^(1/3).

So the route is not logically false. Its honest status is:

```plain text
correct Fourier identity
+ genuinely new but stronger variance conjecture
+ no present reduction in difficulty
+ no unconditional exponent gain from per-pair Weil.
```

## 1. Exact audit of D1

Put

```plain text
Delta_{r,h} = b_r c_{r+h} - b_{r+h} c_r,
Q_h(r) = product_{j=1}^h (r+j)^3,
D_h(r) = Q_h(r) Delta_{r,h}.
```

The regular-window assumptions imply that every factor in Q_h(r) is nonzero modulo p.

For h=0,

```plain text
D_0(r) = 0.
```

For h=1, the Casoratian gives

```plain text
W_{r+1}
 = b_{r+1} c_r - b_r c_{r+1}
 = -1/(r+1)^3.
```

Hence

```plain text
Delta_{r,1} = -W_{r+1} = 1/(r+1)^3,
D_1(r) = 1.
```

For fixed r, apply the recurrence to the second endpoint r+h. One gets

```plain text
(r+h+1)^3 Delta_{r,h+1}
 = P(r+h) Delta_{r,h} - (r+h)^3 Delta_{r,h-1}.
```

Multiplying by Q_h(r) gives

```plain text
D_{h+1}(r)
 = P(r+h) D_h(r) - (r+h)^6 D_{h-1}(r).
```

The initial values and recurrence are exactly those of N_h(r). Therefore

```plain text
D_h(r) = N_h(r),
Delta_{r,h} = N_h(r) / product_{j=1}^h (r+j)^3.
```

Verdict:

```plain text
[D1 PROVED].
```

There is no sign error and no one-step index error in D1.


```plain text
m(a) = #{(r,h) in S : Delta_{r,h} = a}.
```

```plain text
sum_a m(a) = N,
m(0) = A,
```

```plain text
1_{Delta=0} = (1/p) sum_{t in F_p} e_p(t Delta).
```

Thus D3 is exact.

Verdict:

## 3. The decisive centered-variance identity

The most revealing form of D3 is not Fourier notation. It is the elementary identity

```plain text
N_coinc(H) - N^2/p
 = sum_{a in F_p} (m(a)-N/p)^2.
```

Indeed,

```plain text
sum_a (m(a)-N/p)^2
 = sum_a m(a)^2 - 2(N/p)sum_a m(a) + p(N/p)^2
 = N_coinc(H) - N^2/p.
```

Consequently [COINC]

```plain text
N_coinc(H) <= N^2/p + K N
```

is exactly equivalent to

```plain text
sum_a (m(a)-N/p)^2 <= K N.
```

In particular, selecting the a=0 term gives immediately

```plain text
(A-N/p)^2 <= K N,
A <= N/p + sqrt(KN).
```

Since

```plain text
N = H(p-2) - H(H+1)/2 = pH + O(H^2),
```

this is

```plain text
A << H + sqrt(K p H).
```

This is D4. The Cauchy-Schwarz argument through B_t is valid, but it is unnecessary: D4 is already one coordinate of the variance identity.

Verdict:

```plain text
[D4 PROVED CONDITIONALLY ON COINC].
```

## 4. Exact diagonal and forced-symmetry bookkeeping

### 4.1 Literal diagonal

The pairs

```plain text
(r,h) = (r',h')
```

contribute exactly N to N_coinc(H).

Write R_nonzero for the number of ordered distinct pairs in S with equal nonzero Casoratian value. Then the exact partition is

```plain text
N_coinc(H)
 = N + A(A-1) + R_nonzero.
```

Here A(A-1) is the off-diagonal zero-zero contribution; the A diagonal zero pairs are already included in N.

This shows at once that K must be at least an absolute positive constant. A random map with N samples in p boxes already has coincidence excess of order N because of the literal diagonal.

### 4.2 Reflection does not force equal nonzero values

For fixed h define the window involution

```plain text
rho_h(r) = p-1-h-r.
```

The continuant reflection gives

```plain text
N_h(rho_h(r)) = (-1)^(h-1) N_h(r).
```

The denominator transforms as

```plain text
product_{j=1}^h (rho_h(r)+j)^3
 = (-1)^h product_{j=1}^h (r+j)^3.
```

Therefore

```plain text
Delta_{rho_h(r),h} = -Delta_{r,h}.
```

This is important. The proved orbit reflection supplies an anti-symmetry of Casoratian values, not an equality symmetry. Since p is odd, reflection creates an equal-value pair only when the common value is zero.

For even h, rho_h has the fixed integer point

```plain text
r = (p-1-h)/2,
```

and anti-symmetry forces Delta_{r,h}=0 there. This is precisely the forced mirror collision represented by the linear factor of N_h.

For nonzero values, the reflection contributes no forced component to

```plain text
Delta_{r,h} = Delta_{r',h}.
```

### 4.3 Other self-correspondences

There can still be fixed-h self-correspondences unrelated to reflection. The simplest example is h=1:

```plain text
Delta_{r,1} = 1/(r+1)^3.
```

When p is 1 modulo 3, equality of two such values has three linear ratio components. This contributes O(p), which is compatible with the allowed O(N) excess.

For general h, [COINC] requires that the total number of extra positive-dimensional components over all pairs (h,h') be O(H), not O(H^2). Same-h diagonal components already contribute H of them. Adjacent coprimality of N_h and N_{h+1}, and irreducibility of the zero polynomial N_h, do not by themselves classify the fiber products

```plain text
Delta_h(r) = Delta_{h'}(r').
```

That component classification is a genuine additional gap.

## 5. The zero-zero term: self-consistent but not decoupled

The circularity warning can be resolved exactly.

Split the coincidence energy as

```plain text
N_coinc(H) = A^2 + sum_{a != 0} m(a)^2.
```

For fixed A, Cauchy-Schwarz over the p-1 nonzero values gives

```plain text
sum_{a != 0} m(a)^2 >= (N-A)^2/(p-1).
```

Hence

```plain text
N_coinc(H) - N^2/p
 >= A^2 + (N-A)^2/(p-1) - N^2/p
 = (p/(p-1)) (A-N/p)^2.
```

This lower bound is sharp when the nonzero values are perfectly equidistributed.

It has three consequences.

1. There is no logical circularity in assuming [COINC]. If

```plain text
A about sqrt(pH)
```

and N about pH, then

```plain text
(A-N/p)^2 about pH about N,
```

which exactly saturates, but does not violate, the allowed K N budget.

1. There is a strategic circularity in trying to prove [COINC] while ignoring the zero fiber. Even perfect control of every nonzero value leaves the term

```plain text
(p/(p-1))(A-N/p)^2.
```

Thus a proof of [COINC] must already rule out

```plain text
A >> N/p + sqrt(N).
```

1. Splitting Delta=0 off does not save the route. A theorem only about the nonzero coincidence energy cannot imply total [COINC] unless it is combined with an independent bootstrap bound on A. The zero-zero contribution is positive and cannot be erased by cancellation among nonzero fibers.

This is the main hostile-audit finding.

Verdict:

```plain text
[COINC IS SELF-CONSISTENT].
[COINC DOES NOT DECOUPLE THE ZERO FIBER].
```

## 6. Is N_coinc an alias of F_p?

No, not literally.

The zero fiber of the determinant map is

```plain text
A_H = sum_{h<=H} C_h,
```

the number of unordered projective collision pairs whose positive gap is at most H.

For the full range H=M-1,

```plain text
A_{M-1} = (F_p-M)/2.
```

Thus the target energy is one distinguished fiber of the Delta map.

But N_coinc also counts

```plain text
Delta_{r,h} = Delta_{r',h'} = a
```

for every nonzero a. Those coincidences are not projective orbit collisions. They can be numerous even when the projective orbit has low energy. Conversely, controlling F_p controls only a=0 and need not control concentration at a nonzero determinant value.

Therefore:

```plain text
E1 does not imply COINC.
COINC at one truncated H does not imply E1.
N_coinc is not determined by F_p.
```

The two statements are genuinely different.

However, [COINC] is stronger in the direction relevant to D4: it controls all p determinant fibers in L2 and thereby controls the target fiber. It is not an easier unsigned surrogate obtained for free from point counting.

### Comparison with the old affine Parseval death certificate

The old affine Parseval identity diagonalized the multiplicities of the affine vectors

```plain text
(b_n,c_n) in F_p^2.
```

That affine energy was essentially fixed by the reflection pairing and did not see projective scalar multiples. It was therefore the wrong fiber object for projective energy.

The present determinant identity is different:

```plain text
Delta_{r,h}=0
```

is exactly the projective collision condition. So the present route does not die for the old reason.

What remains tautological is the following narrower statement:

```plain text
Fourier transform converts the zero-fiber count into a character sum,
and Parseval converts the mean square into the variance of the same value distribution.
```

No cancellation has been proved by that conversion. [COINC] is the new substantive input.

Verdict:

```plain text
[NOT THE SAME AFFINE-PARSEVAL ALIAS].
[STILL A STRONGER VARIANCE REFORMULATION, NOT A BYPASS].
```

## 7. Formal flaw in D5 and the repaired p^(4/3) implication

The proved sigma machine in

```plain text
problems/3.2/FABLE_SECTION_orbit_energy.tex
```

uses

```plain text
d_D(r) = #{1<=h<=D : pi(r)=pi(r+h)},
Q_p(D) = sum_r binom(d_D(r),2).
```

This Q_p(D) counts two collision gaps with the same incoming base point. Equivalently, it is a triple-return quantity. It is not

```plain text
sum_{h<=D} C_h.
```

Thus the statement

```plain text
COINC gives the sigma=3/2 hypothesis
```

is formally false. COINC controls the first local moment

```plain text
S_p(H) = sum_r d_H(r) = sum_{h<=H} C_h,
```

not the second factorial moment Q_p(H).

This notation mismatch is fatal to the claimed use of the sigma ladder.

The p^(4/3) conclusion nevertheless survives by a different, simpler argument.

Partition I_p into

```plain text
B = ceil(M/H)
```

consecutive blocks. Let m_{v,j} be the multiplicity of color v in block j. Then

```plain text
m_v = sum_j m_{v,j},
m_v^2 <= B sum_j m_{v,j}^2.
```

Summing over v gives

```plain text
F_p <= B ( M + 2 A_H ),
A_H = sum_{h<=H} C_h.
```

Under [COINC],

```plain text
A_H <= N/p + sqrt(KN)
     << H + sqrt(K p H).
```

Therefore

```plain text
F_p
 << (p/H) (p + H + sqrt(pH))
 << p^2/H + p^(3/2)/sqrt(H) + p.
```

At

```plain text
H = floor(p^(2/3)),
```

this becomes

```plain text
F_p << p^(4/3) + p^(7/6) + p
    << p^(4/3).
```

So the correct ledger entry is

```plain text
[COINC at H=p^(2/3)]
    ==> [BLOCK ENERGY]
    ==> F_p << p^(4/3).
```

It is not a sigma-ladder implication.

More generally, if [COINC] holds at H=p^beta with 0<beta<1, then

```plain text
F_p << p^(2-beta) + p^(3/2-beta/2) + p.
```

The first term dominates for beta<1. Hence this route beats ENERGY-3/2 only when

```plain text
beta > 1/2.
```

The choice beta=2/3 gives the advertised exponent 4/3.

## 8. Geometric audit of D6

Write

```plain text
Delta_h(r) = N_h(r)/Q_h(r),
Q_h(r) = product_{j=1}^h (r+j)^3.
```

The numerator has degree 3(h-1), and the denominator has degree 3h. After clearing denominators, the difference curve is

```plain text
X_{h,h'}:
N_h(r) Q_{h'}(r') - N_{h'}(r') Q_h(r) = 0.
```

Its bidegree in P1 x P1 is at most

```plain text
(3h, 3h').
```

### 8.1 The generic Weil error from bidegree

A smooth irreducible curve of bidegree (d,e) in P1 x P1 has arithmetic genus

```plain text
(d-1)(e-1).
```

Thus bidegree alone gives genus

```plain text
O(h h'),
```

not O(h+h'). The standard Weil error is therefore

```plain text
O(h h' sqrt(p))
```

per pair, before component and singularity bookkeeping.

Summing over h,h'<=H gives

```plain text
O(H^4 sqrt(p)).
```

To fit the [COINC] excess budget

```plain text
K N about pH,
```

one would need

```plain text
H^4 sqrt(p) <= pH,
H <= p^(1/6).
```

The stated total O(H^3 sqrt(p)) and range H<=p^(1/4) are valid only if one first proves a special theorem reducing the total geometric complexity of X_{h,h'} from O(hh') to O(h+h'). That theorem is not a consequence of bidegree.

### 8.2 Component main terms

For a generic irreducible pair, one expects one p-sized main component. But:

- X_{h,h} always has the diagonal component r=r'.

- Fixed h may have additional deck correspondences.

- Cross-gap pairs may have exceptional functional relations.

If c_{h,h'} is the number of p-sized components, the main-term excess contains roughly

```plain text
p sum_{h,h'<=H} (c_{h,h'}-1).
```

[COINC] permits only O(pH). Therefore the total number of extra components must be O(H).

Irreducibility of N_h as a polynomial in r controls the zero fiber N_h(r)=0. It does not imply irreducibility, or bounded component number, of the fiber product

```plain text
Delta_h(r) = Delta_{h'}(r').
```

Adjacent coprimality likewise does not prove this. A uniform two-transitivity or fiber-product irreducibility theorem is still required.

### 8.3 Restricted-window boundary

The set S_H omits O(h) values of r for each h. Passing from a complete F_p curve count to the restricted window produces boundary terms whose naive total can grow polynomially in H. At H=p^(2/3), these terms are far larger than the O(pH) target unless they are incorporated into the main term or shown to cancel structurally.

This is secondary at H<=p^(1/4), but it becomes another real family-level obstacle in the range needed for a new energy theorem.

Verdict:

```plain text
[D6 AS WRITTEN UNDERCOUNTS GENERIC GENUS].
[THE P^(1/4) RANGE ALREADY ASSUMES A NEW LOW-GENUS THEOREM].
```

## 9. What per-pair Weil can actually deliver

Assume the optimistic version requested in the question:

```plain text
#X_{h,h'}(window)
 = expected main term
   + O((h+h') sqrt(p) + polynomial boundary error),
```

and assume all exceptional components have been classified with total excess O(pH).

Summing gives

```plain text
N_coinc(H)
 <= N^2/p + O(pH + H^3 sqrt(p) + lower-order terms).
```

Thus [COINC] follows only while

```plain text
H^3 sqrt(p) <= pH,
H <= p^(1/4).
```

Under the generic bidegree genus O(hh'), the corresponding range is only

```plain text
H <= p^(1/6).
```

Now compare the resulting D4 estimate with the already proved root-degree bound.

The new estimate would be

```plain text
A_H << H + sqrt(pH).
```

The existing estimate is

```plain text
A_H = sum_{h<=H} C_h
 <= sum_{h<=H} 3(h-1)
 = (3/2)H^2 + O(H).
```

For H<=p^(1/3),

```plain text
sqrt(pH) >= H^2,
```

because this inequality is equivalent to H^3<=p. Therefore throughout the entire range H<=p^(1/3), the [COINC] consequence is no better than the existing polynomial-degree estimate.

At the optimistic endpoint H=p^(1/4):

```plain text
COINC consequence:  A_H << p^(5/8),
trivial degree bound: A_H << p^(1/2).
```

The old bound is strictly better.

Feeding H=p^(1/4) into the block inequality gives at best

```plain text
F_p << p^(7/4),
```

which is much worse than the banked p^(3/2) theorem. Under the standard bidegree genus, the available H is smaller and the result is weaker still.

Verdict:

```plain text
[NO UNCONDITIONAL IMPROVEMENT FROM PER-PAIR WEIL].
[NO IMPROVEMENT OF sum C_h FOR ANY H<=p^(1/3)].
[NO NEW F_p EXPONENT].
```

A useful family theorem must cross the threshold

```plain text
H > p^(1/3)
```

to improve the small-gap root count, and it must reach

```plain text
H > p^(1/2)
```

to beat the global ENERGY-3/2 record through the block inequality. The proposed H=p^(2/3) range would indeed yield p^(4/3), but that is far beyond what pairwise Weil summation supplies.
