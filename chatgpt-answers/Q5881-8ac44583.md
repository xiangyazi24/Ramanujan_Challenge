# 2. Exact Newton interval-mask lemma

For an arbitrary sequence F, write

```plain text
G_(d,L)(F)=sum_(i=0)^L w_(d,L)(i) F_(d+i),

w_(d,L)(i)=(-1)^i binom(d+i,i)binom(d+L+1,L-i).
```

There is an exact barycentric form

```plain text
w_(d,L)(i)
 =(-1)^i binom(L,i)
   * ((d+1)binom(d+L+1,L))/(d+i+1).                 (2.1)
```

Let

```plain text
K_(d,L)=(d+1)binom(d+L+1,L).
```

## Lemma 2.1 -- one-carry mask

Let ell>sqrt(n) be prime and assume all row nodes are below ell^2. If

```plain text
v_ell(K_(d,L))=1,
```

then

```plain text
G_(d,L)(F)
 = sum_(q: d<=q*ell-1<=d+L)
     gamma_(d,L,ell)(q) F_(q*ell-1)              (mod ell),
```

where, with i_q=q*ell-1-d,

```plain text
gamma_(d,L,ell)(q)
 =(-1)^i_q binom(L,i_q)
   * (K_(d,L)/ell)/q                              (mod ell).     (2.2)
```

### Proof

Since the top row index is below ell^2, every denominator d+i+1 has ell-valuation at most one. Formula (2.1) is therefore zero modulo ell unless d+i+1=q*ell; at such an index the unique factor of ell cancels and gives (2.2).

The mask is singular only in the following cases:

```plain text
v_ell(K_(d,L))=0;
v_ell(K_(d,L))=2;
q*ell=d or d+L+1 for a boundary alias;
ell divides d+1 or d+L+1.
```

For the two adjacent diagonal margins, all boundary-alias exceptions divide the finite product

```plain text
S_mask(n)=product_(m in {m0,m1})
  (d_m+1)(d_m+L_m+1)(D+1)(D+L_m+1).               (2.3)
```

Because D,N,m0,m1 are period-20 affine floor functions, log|S_mask(n)|=O(log n).

This lemma explains why the range ell>sqrt(n) is the correct threshold for an exact mask analysis: there are no ell^2-spaced nodes, but there may be several nodes q*ell-1.


### Proof

Freshman's dream gives


A contribution to the coefficient at (q*ell-u)kappa, with u=1 or 2, has


Every coordinate of u*kappa+nu has absolute value below ell, so necessarily


For the q*ell shell one gets nu=0. Summation over the first-cell rays gives (3.2).

# 11. Final conclusion

The requested threshold theorem is not currently proved, and the committed order-five recurrence does not furnish the missing rank argument.

The exact logical ledger is

```plain text
ell|K_hyb
 =>
   [ell divides an explicit fixed-degree singular factor]
   or
   [a=1 and (ell|b_n or ell|Omega_top)]
   or
   [a>=2 and ell|Omega_(a,r)].
```

The first class has logarithmic weight O(log n). The second and third observability terms are the unresolved classes. The dense scan says they are empty through the stated central range; the exact Cartier-mask formulas show why their emptiness is not a formal consequence of the current recurrence.

Thus Casoratian bounds would close log G_n=o(n) after proving (9.1)--(9.2), but not before. The next proof-grade task is to derive a common annihilator or a nonzero low-height resultant for the finite family of packets B_(a,q),J_(a,q) and for the first divided top-half jet. Without that new identity, claiming the decisive threshold would overstate the current mathematics.
