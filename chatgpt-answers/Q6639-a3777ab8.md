## 1. Pole-pole singularities and the genus bound

### 1.1 Local expansion at a finite pole-pole point

PROVED.

Fix 1<=i<=h and 1<=j<=k, and write

```plain text
X=-i+u,
Y=-j+v.
```

The endpoint formula and good-reduction clause give

```plain text
A_i=N_h(-i) != 0,
B_j=N_k(-j) != 0.
```

Since the roots of q_h and q_k are simple,

```plain text
q_h(-i+u)=a_i u+O(u^2),   a_i!=0,
q_k(-j+v)=b_j v+O(v^2),   b_j!=0.
```

Therefore

```plain text
F_(h,k)(-i+u,-j+v)
 = A_i b_j^3 v^3 - B_j a_i^3 u^3
   + terms of total degree at least 4.
```

The tangent cone is

```plain text
A_i b_j^3 v^3 - B_j a_i^3 u^3.
```

Over the algebraic closure, and in characteristic different from 3, this factors into three distinct linear forms. Hence the point is an ordinary triple point: three smooth branches, every pair meeting transversely. Its delta-invariant is

```plain text
delta = C(3,2)=3.
```

Thus the hk finite pole-pole points contribute at least 3hk to the total delta-invariant. The local claim in the draft is correct.

### 1.2 The missing point at infinity

FIXABLE.

The draft's subtraction is not the complete generic singularity census. Put local parameters

```plain text
u=1/X,
v=1/Y
```

at (X,Y)=(infinity,infinity). Since

```plain text
deg N_h=3(h-1),
deg q_h^3=3h,
```

one has

```plain text
delta_h(1/u)=lambda_h u^3+O(u^4),   lambda_h!=0,
delta_k(1/v)=lambda_k v^3+O(v^4),   lambda_k!=0.
```

Thus the fiber-product equation has local tangent cone

```plain text
lambda_h u^3-lambda_k v^3,
```

again an ordinary triple point with delta-invariant 3.

This resolves the apparent discrepancy exactly. The arithmetic genus is

```plain text
p_a=(3h-1)(3k-1)
   =9hk-3h-3k+1.
```

Subtracting only the finite pole-pole points gives the valid but non-sharp upper bound

```plain text
g <= p_a-3hk
   =6hk-3h-3k+1.
```

Subtracting the additional point at infinity gives

```plain text
g <= p_a-3hk-3
   =6hk-3h-3k-2.
```

Under the generic branch-disjointness hypotheses already used in the banked Riemann-Hurwitz calculation, this is the exact genus. There is no contradiction: the missing 3 is precisely the delta-invariant at (infinity,infinity).

The coarse inequality

```plain text
g <= 6hk
```

is therefore correct, but its proof should mention the point at infinity and should preferably quote the sharper value.

### 1.3 Same-gap residual component

FIXABLE.

For h>=2, write

```plain text
F_(h,h)(X,Y)=(X-Y) H_h(X,Y).
```

The residual component has bidegree

```plain text
(3h-1,3h-1),
```

and arithmetic genus

```plain text
p_a(H_h)=(3h-2)^2.
```

Its local singularities are not identical to those of the full self-fiber product:

```plain text
At (-i,-j) with i!=j:
  the diagonal does not pass through the point;
  H_h retains the ordinary triple point, delta=3.

At (-i,-i):
  one of the three branches is the diagonal;
  after dividing by X-Y, the residual has two transverse branches,
  hence an ordinary node, delta=1.

At (infinity,infinity):
  the diagonal again removes one branch;
  the residual has an ordinary node, delta=1.
```

Therefore the displayed singularities alone contribute

```plain text
3h(h-1)+h+1 = 3h^2-2h+1.
```

Hence

```plain text
g(H_h)
 <= (3h-2)^2-(3h^2-2h+1)
 = 6h^2-10h+3
 <= 6h^2.
```

So the claimed coarse bound is true, but "similarly" must be replaced by this argument or by the equivalent Riemann-Hurwitz computation.

## 2. Weil bound and singular-point correction

### 2.1 Which object receives Hasse-Weil

FIXABLE.

Let C be an absolutely irreducible projective component over F_p, and let

```plain text
nu: C_tilde -> C
```

be its normalization. Hasse-Weil applies to C_tilde, not directly to the singular model:

```plain text
#C_tilde(F_p) <= p+1+2g sqrt(p).
```

Away from the singular locus, normalization is an isomorphism. For each rational singular point, the singular model can exceed the normalization count by at most one: a rational singular point may have no rational branch above it, but it is still only one rational point downstairs. Consequently

```plain text
#C(F_p)
 <= #C_tilde(F_p)+#Sing(C)(F_p)
 <= p+1+2g sqrt(p)+#Sing(C)(F_p).
```

A singular point cannot create a correction larger than one in this upper-bound direction. Multiple rational branches over one singular point make the normalization count larger, not smaller.

### 2.2 Bounding the number of singular points

FIXABLE; the stated crude term is safe.

The draft says only "bounded by Bezout." A rigorous justification can be given in either of two ways.

The cleaner method uses the arithmetic genus. For an integral curve on the smooth surface P^1 x P^1,

```plain text
p_a = g + sum_P delta_P.
```

Every singular point has delta_P>=1, so

```plain text
#Sing(C)(Fbar_p) <= p_a.
```

Thus, for a cross component,

```plain text
#Sing(C) < 9hk,
```

and for the residual same-gap component,

```plain text
#Sing(H_h) < 9h^2.
```

These are much stronger than the terms in the draft.

If the author wants to retain the displayed 36(hk)^2, one may instead argue as follows. The affine total degree is at most 3(h+k). Under the good-reduction and separability clause, choose a partial derivative or generic polar not sharing the irreducible curve as a component. Bezout then gives

```plain text
#Sing(C) < 9(h+k)^2 <= 36h^2k^2.
```

For the residual same-gap component the analogous bound is also far below 36h^4.

Therefore

```plain text
#C(F_p) <= p+1+12hk sqrt(p)+36(hk)^2
```

is a valid, extremely wasteful upper bound after the normalization argument is inserted. The lemma is not false; its proof is incomplete.

## 3. Pairwise bounds and window bookkeeping

### 3.1 Distinct gaps

PROVED.

For h!=k, the window count is a subset of the projective curve count, so

```plain text
R_(h,k)
 <= p+1+12hk sqrt(p)+36(hk)^2.
```

The random baseline used later is

```plain text
L_h L_k/p,
L_h=p-h-2,
L_k=p-k-2.
```

Exactly,

```plain text
p+1-L_h L_k/p
 = h+k+5 - ((h+2)(k+2))/p.
```

For distinct positive integers h,k,

```plain text
h+k+5 <= 4hk;
```

the minimal case (h,k)=(1,2) is equality before the negative final term. Hence

```plain text
R_(h,k)
 <= L_h L_k/p
    +12hk sqrt(p)
    +36(hk)^2
    +4hk.
```

The 4hk term is not really a "window restriction error." It reconciles the projective main term p+1 with the shorter-window baseline L_hL_k/p.

### 3.2 Same gap, h>=2

PROVED.

The diagonal contributes at most L_h, and the residual component contributes at most its complete projective count. Therefore

```plain text
R_(h,h)

```

Also

```plain text
p+1-L_h^2/p
 =2h+5-((h+2)^2)/p
 <=5h
```

## 4. Ordered summation and the main theorem constants

### 4.1 Summation

PROVED.

The count Ncoinc(H) sums ordered pairs (h,k). The cross bounds are symmetric, and the diagonal terms fill in the missing diagonal of the quadratic sums. Therefore

```plain text
sum_(h,k<=H) 12hk sqrt(p) = 12 A_1^2 sqrt(p),
sum_(h,k<=H) 36h^2k^2  = 36 A_2^2.
```

Replacing the cross-only lower-order sum by 4A_1^2 and the diagonal lower-order sum by 5A_1 is an upper bound. The formula

```plain text
Ncoinc(H)
 <= S^2/p + S + p
    +12A_1^2 sqrt(p)
    +36A_2^2
    +4A_1^2
    +5A_1
```

is correct.

The estimates

```plain text
A_1<=H^2,
A_2<=H^3
```

hold for every integer H>=1, giving the displayed error E.

### 4.2 Exact constant chase

PROVED.

One has

```plain text
S=H(p-(H+5)/2).
```

Under p>=4096 and H<=p^(1/6)/4, certainly H+5<=p, so

```plain text
S>=pH/2.
```

Therefore

```plain text
E/S
 <=24H^3/sqrt(p)
   +72H^5/p
   +8H^3/p
   +10H/p.
```

At H<=p^(1/6)/4, the four terms are bounded by

```plain text
24H^3/sqrt(p) <= 3/8,
72H^5/p       <= 9/(128 p^(1/6)) <= 9/512,
8H^3/p        <= 1/(8 sqrt(p))   <= 1/512,
```

Their sum is less than 0.397, hence certainly less than 1/2.

Also H>=1 gives

There is no arithmetic defect in the theorem proof.

## 5. Additive completion subsection

### 5.1 Nontrivial linear phases on the normalization

FIXABLE; the scale 40hk sqrt(p) is defensible.

For a distinct-gap irreducible component, let C_tilde be the normalization and consider

```plain text
ell=aX+bY,
(a,b)!=(0,0).
```

The function X on C_tilde has degree at most 3k, and Y has degree at most 3h. Hence the polar divisor of ell has total degree at most

```plain text
3(h+k).
```

The number of its poles is no larger than the same quantity. The Artin-Schreier conductor bound therefore gives

```plain text
dim H_c^1
 <= 2g-2 + sum_P(ord_P(ell)_infinity+1)
 <= 12hk-2+6(h+k)
 < 24hk.
```

For h,k>=1, h+k<=2hk. A constant such as 40hk is therefore safe after allowing for harmless deleted boundary points.

Two hypotheses must be written:

```plain text
1. ell is nonconstant on the component.
   Otherwise the component would lie in an affine line, impossible for the
   exact bidegrees occurring here.

2. ell is not of Artin-Schreier form g^p-g+c.
   In the p^(1/6) range every actual pole order is positive and <p;
   an Artin-Schreier pole order would be divisible by p.
```

Thus the Bombieri/Deligne estimate is valid, but the current statement suppresses the argument that makes it applicable.

### 5.2 The completion formula

For unnormalized Fourier coefficients,

```plain text
hat(1_I)(a)=sum_(x in I)e_p(-ax),
sum_a |hat(1_I)(a)| <= p(2+log p).
```

For a distinct-gap curve,

```plain text
R_(h,k)
 = p^(-2) sum_(a,b in F_p)
     hat(1_(I_h))(a) hat(1_(I_k))(b) T_(a,b),
```

where T_(a,b) is the additive sum over the curve. The zero frequency supplies L_hL_k/p plus its Hasse-Weil error, while the nonzero frequencies give an error of order

```plain text
hk sqrt(p) (2+log p)^2.
```

If singular points are removed before completion and counted once separately, their correction does not acquire an extra logarithmic factor. This is the clean way to justify a bound of the displayed shape

```plain text
R_(h,k)
 <= L_hL_k/p
    +64hk sqrt(p)(2+log p)^2
    +72(hk)^2
```

for h!=k. The numerical constants 64 and 72 are safely above the conductor and singularity estimates, but the decomposition must be stated.

### 5.3 Fatal ambiguity at h=k

BROKEN AS WRITTEN.

The phrase "This gives per-pair" cannot include h=k. The self-fiber product has the diagonal plus the residual component. Its main term is larger by a component contribution of size L_h. A valid diagonal completion bound must have the form

```plain text
R_(h,h)
 <= L_h^2/p + L_h
    +64h^2 sqrt(p)(2+log p)^2
    +72h^4
    +O(h).
```

The level h=1 must again be handled separately. Therefore the displayed completion formula must be explicitly restricted to h!=k, followed by the diagonal formulas.

### 5.4 Logarithmic range

PROVED.

After summing the cross errors, the leading completion loss is

```plain text
H^4 sqrt(p)(2+log p)^2.
```

Comparing with S of size pH gives

```plain text
H^3(2+log p)^2/sqrt(p) << 1.
```

Taking cube roots yields exactly

```plain text
H << p^(1/6)/(2+log p)^(2/3).
```

The exponent 2/3 on the logarithm is correct.

The sentence

```plain text
The log-loss is intrinsic to additive completion.
```

should be replaced by

```plain text
The log-loss is intrinsic to this sharp-cutoff L^1 completion estimate.
```

Smoothing, an L^2 large-sieve input, or cancellation among frequencies could alter the logarithmic loss. Adjusting numerical constants alone cannot remove it, but changing the analytic mechanism might.

## 6. Corollary constants

PROVED.

Parseval gives

```plain text

```

Cauchy-Schwarz then gives

```plain text
|(1/p)sum_(t!=0)B_t(H)|

```

Using orthogonality,

```plain text
sum_(h<=H) C_h
 <= S/p+2sqrt(S).
```

Since

```plain text
S/p<=H,
S<=pH,
```

one obtains

```plain text
sum_(h<=H) C_h <= H+2sqrt(pH).
```

In the theorem's range H=o(p),

```plain text
S/(pH)=1-(H+5)/(2p)=1+o(1),
```

so the final sqrt((4+o(1))pH) formulation is correct.
