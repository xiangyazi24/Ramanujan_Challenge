# Alternating quadratic level-two sum: a six-integral real certificate

## Verdict

The target is correct with the stated convention

```text
P_n = H_n + 2 * sum_{k=1}^n (-1)^k/k,
S_n = P_n^2 - H_n^(2).
```

The shortest route I recommend is not a second independent weight-four HPL calculation. It is:

1. derive one closed generating function
   `Q(x) = sum_{n>=1} S_n*x^n`;
2. use `Q(-x)`—with **no additional sign**—for the outer alternating series;
3. integrate by parts once with a primitive whose endpoint cancellation is manifest after Landen;
4. apply the Möbius map `t = 2*x/(1+x)`;
5. reduce the result to six real integrals `I_ab`;
6. evaluate those six integrals with the already-proved linear weight-four endpoint package.

The six-integral reduction yields the particularly small bridge

```text
Aquad = 11*Tminus + 2*Tplus
        - 12*L^2*Z2 - 14*L*Z3 + (41/10)*Z2^2,        (V)
```

where

```text
Tplus  = sum_{n>=1} P_n/n^3,
Tminus = sum_{n>=1} (-1)^n*P_n/n^3.
```

Using the available linear theorems

```text
Tplus  = -(7/2)*L*Z3 + (3/4)*Z2^2,

Tminus = -2*Li4(1/2) - L^4/12 + (1/2)*L^2*Z2
         + (7/4)*L*Z3 + (1/10)*Z2^2,
```

formula (V) gives

```text
Aquad = -22*Li4(1/2)
        - (11/12)*L^4
        - (13/2)*L^2*Z2
        - (7/4)*L*Z3
        + (67/10)*Z2^2.
```

No complex analysis, WZ theorem, general HPL library, or new special value is required.

```text

S_1 = 0,
```

# 2. The closed generating function

Throughout this section `|x|<1`. Set

```text
a(x) = log(1-x),
b(x) = log(1+x),
L    = log 2,
Z2   = zeta(2).
```

The available linear generating function, now with powers `x^n`, is

```text
F(x) := sum_{n>=1} P_n*x^n
      = -(a(x)+2*b(x))/(1-x).                         (2.1)
```

## 2.1 Increment of the quadratic coefficient

From (1.1),

```text
S_n-S_(n-1)
 = 2*c_n*P_(n-1)/n + (c_n^2-1)/n^2.                  (2.2)
```

Since

```text
c_n^2-1 = 4*(1+eps_n),                                (2.3)
```

the diagonal generating series is

```text
sum_{n>=1} (c_n^2-1)*x^n/n^2
 = 4*(Li2(x)+Li2(-x))
 = 2*Li2(x^2).                                        (2.4)
```

Define

```text
M(x) := sum_{n>=1} c_n*P_(n-1)*x^n/n.                 (2.5)
```

Differentiating its absolutely convergent power series gives

```text
M'(x) = F(x)-2*F(-x).                                 (2.6)
```

The sign in (2.6) is worth checking explicitly: after `m=n-1`,
`eps_(m+1)=-eps_m`, so the decorated part is `-2*F(-x)`.

## 2.2 Explicit primitive for `M`

The normalized primitive is

```text
M(x) = (1/2)*a(x)^2 + b(x)^2 + 2*a(x)*b(x)
       + 2*L*b(x) + Z2-L^2
       - 2*Li2((1+x)/2).                              (2.7)
```

This is a direct derivative certificate. On `-1<x<1`, use

```text
d/dx Li2((1+x)/2)
  = -log((1-x)/2)/(1+x)
  = -(a(x)-L)/(1+x).                                  (2.8)
```

Differentiating (2.7), the `1/(1-x)` terms give

```text
-(a+2*b)/(1-x) = F(x),
```

and the `1/(1+x)` terms give

```text
2*(2*a+b)/(1+x) = -2*F(-x).
```

At `x=0`,

```text
M(0) = Z2-L^2-2*Li2(1/2) = 0                         (2.9)
```

by the already proved half value

```text
Li2(1/2) = Z2/2-L^2/2.
```

## 2.3 Closed form for `Q`

Let

```text
Q(x) := sum_{n>=1} S_n*x^n.
```

For any sequence with zero initial term,

```text
(1-x)*Q(x) = sum_{n>=1}(S_n-S_(n-1))*x^n.
```

Using (2.2)-(2.5),

```text
boxed:
Q(x) = 2/(1-x) * J(x),                                (2.10)

J(x) = (1/2)*a^2+b^2+2*a*b+2*L*b+Z2-L^2
       -2*Li2((1+x)/2)+Li2(x^2).                      (2.11)
```

The coefficient audit is

```text
Q(x) = -x^2 -(4/3)*x^3 -(7/12)*x^4 -(19/20)*x^5+...
```

in agreement with (1.2).

# 3. The outer alternating sign and indexing

This is the place where an easy sign error occurs.

Because `Q` was defined with powers `x^n`,

```text
Q(-x) = sum_{n>=1} (-1)^n*S_n*x^n.                   (3.1)
```

There is **no extra minus sign**.

By contrast, if one instead uses the shifted series

```text
Q0(x) = sum_{m>=0} S_(m+1)*x^m,
```

then the alternating shifted coefficients are `-Q0(-x)`. These two facts are
consistent because `Q(x)=x*Q0(x)`.

The coefficient-integration moment is

```text
integral_0^1 (-log x)*x^(n-1) dx = 1/n^2.             (3.2)
```

Hence absolute convergence gives

```text
Aquad
 = integral_0^1 (-log x)/x * Q(-x) dx.                (3.3)
```

A robust Lean proof first inserts a radius `0<=rho<1`:

```text
sum (-1)^n*S_n*rho^n/n^2
 = integral_0^1 (-log x)/x * Q(-rho*x) dx,             (3.4)
```

then lets `rho -> 1-`. The target series is absolutely summable. It suffices
to use

```text
|S_n| <= 9*H_n^2+H_n^(2)
```

together with the harmonic `O(log n)` estimate already used elsewhere in the
Euler file. No conditionally convergent raw harmonic series is rearranged.

## 3.1 Safe closed form at `-x`

From (2.11),

```text
Jminus(x) := J(-x)
 = a^2+(1/2)*b^2+2*a*b+2*L*a+Z2-L^2
   -2*Li2((1-x)/2)+Li2(x^2).                          (3.5)
```

For endpoint work, use the cancellation-safe form

```text
Jminus(x)
 = a^2+(1/2)*b^2+2*a*b+2*L*a
   -2*(Li2((1-x)/2)-Li2(1/2))+Li2(x^2).               (3.6)
```

In particular, `Jminus(0)=Jminus'(0)=0`; thus
`Jminus(x)=O(x^2)` at zero.

Substituting (2.10) into (3.3),

```text
Aquad = -2*integral_0^1
          log(x)*Jminus(x)/(x*(1+x)) dx.              (3.7)
```

The first nonzero terms are

```text
n=2: -1/4,
n=3: +4/27,
n=4: -7/192,
n=5: +19/500,
```

which already checks the outer sign.

# 4. One integration by parts

Define on `0<x<=1`

```text
V(x) = (1/2)*log(x)^2
       -log(x)*log(1+x)-Li2(-x)-Z2/2.                 (4.1)
```

The derivative is

```text
V'(x) = log(x)/(x*(1+x)).                             (4.2)
```

Indeed,

```text
d/dx [log(x)*log(1+x)+Li2(-x)]
 = log(x)/(1+x).                                      (4.3)
```

The endpoint constant in (4.1) is essential: since `Li2(-1)=-Z2/2`,

```text
V(1)=0.                                               (4.4)
```

Landen gives a better form. Put

```text
u = x/(1+x).
```

Using

```text
Li2(-x) = -Li2(u)-(1/2)*log(1+x)^2,                   (4.5)
```

one obtains

```text
V(x) = Li2(u)+(1/2)*log(u)^2-Z2/2.                    (4.6)
```

Thus, with

```text
W(x) := -2*V(x),
```

```text
boxed:
W(x) = Z2-2*Li2(u)-log(u)^2.                          (4.7)
```

At `x=1`, `u=1/2`; both `W(1)=0` and `W'(1)=0`. This gives the
quadratic zero needed to kill the logarithmic growth of `Jminus`.

The derivative of `J` at `-x` is

```text
Dminus(x) := J'(-x)
 = -(b+2*a)/(1+x)
   +2*(a+2*b)/(1-x)
   +2*(a+b)/x.                                        (4.8)
```

On a truncated interval `[eps,1-eps]`, ordinary integration by parts gives

```text
Aquad = integral_0^1 W(x)*Dminus(x) dx.               (4.9)
```

The boundary products vanish:

```text
V(x)*Jminus(x) -> 0  as x -> 0+,
V(x)*Jminus(x) -> 0  as x -> 1-.                     (4.10)
```

At zero, use `Jminus=O(x^2)` and `x^2*log(x)^2 -> 0`. At one, use the
double zero of `V` and
`Jminus(x)=O(log(1-x)^2)`.

# 5. Möbius normalization to the fixed alphabet `{0,1,2}`

Use

```text
t = 2*x/(1+x),
x = t/(2-t),
0 <= x <= 1  <->  0 <= t <= 1.                       (5.1)
```

This is the same monotone Möbius substitution used in the linear weight-four
proof. In Lean 4.29 the robust transport theorem is

```text
intervalIntegral.integral_comp_mul_deriv_of_deriv_nonneg
```

applied to `x=t/(2-t)` or, equivalently, to `t=2*x/(1+x)`.

Define

```text
h(t)  = log(t/2),
r(t)  = log(t/(2-t)),
H1(t) = -log(1-t),
H2(t) = -log(1-t/2),

W0(t) = Z2-2*Li2(t/2)-h(t)^2.                         (5.2)
```

Notice carefully that `W0` contains `h(t)^2=log(t/2)^2`, **not** `r(t)^2`.
Moreover,

```text
W0'(t) = -2*r(t)/t.                                   (5.3)
```

A direct rational/logarithmic simplification of (4.8) gives

```text
Dminus(t/(2-t)) * 2/(2-t)^2
 = H1(t)*(-2/t-2/(1-t)+2/(2-t))
   +H2(t)*( 4/t+6/(1-t)-5/(2-t)).                     (5.4)
```

Therefore define

```text
I10 = integral_0^1 W0(t)*H1(t)/t dt,
I11 = integral_0^1 W0(t)*H1(t)/(1-t) dt,
I12 = integral_0^1 W0(t)*H1(t)/(2-t) dt,

I20 = integral_0^1 W0(t)*H2(t)/t dt,
I21 = integral_0^1 W0(t)*H2(t)/(1-t) dt,
I22 = integral_0^1 W0(t)*H2(t)/(2-t) dt.               (5.5)
```

Then the exact algebraic reduction is

```text
boxed:
Aquad = -2*I10-2*I11+2*I12+4*I20+6*I21-5*I22.        (5.6)
```

This is the only large coefficient identity in the analytic proof; after
(5.6), all work is in six reusable endpoint lemmas.

# 6. Explicit derivative witnesses for the six integrals

Let

```text
kappa0(t)=1/t,
kappa1(t)=1/(1-t),
kappa2(t)=1/(2-t).
```

Define six primitives:

```text
g10(t) = Li2(t),

g11(t) = H1(t)^2/2,

g12(t) = log(1-t)*log(2-t)+Li2(t-1)+Z2/2,

g20(t) = Li2(t/2),

g21(t) = -Li2(t-1)-L*log(1-t)-Z2/2,

g22(t) = H2(t)^2/2.                                  (6.1)
```

On `0<t<1`, direct differentiation gives

```text
g10' = H1*kappa0,
g11' = H1*kappa1,
g12' = H1*kappa2,

g20' = H2*kappa0,
g21' = H2*kappa1,
g22' = H2*kappa2.                                    (6.2)
```

The two cross derivatives are worth checking:

```text
d/dt Li2(t-1) = log(2-t)/(1-t),                       (6.3)
```

so the `log(2-t)/(1-t)` terms cancel in `g12'`; and

```text
d/dt[-Li2(t-1)-L*log(1-t)]
 = [-log(2-t)+L]/(1-t)
 = -log(1-t/2)/(1-t).                                 (6.4)
```

The constants in `g12,g21` make

```text
g_ab(0)=0                                             (6.5)
```

for all six pairs; here `Li2(-1)=-Z2/2`.

Using (5.3), integration by parts gives the common certificate

```text
boxed:
I_ab = 2*integral_0^1 r(t)*g_ab(t)/t dt.              (6.6)
```

All boundary terms `W0*g_ab` vanish. At zero each `g_ab` is
`O(t)` or `O(t^2)` while `W0=O(log(t)^2)`. At one, `W0` has a double zero;
this also kills the logarithmic divergence of `g21`.

Equation (6.6), together with the explicit six functions (6.1), is the
real derivative certificate. It replaces a general harmonic-polylogarithm
reducer.

# 7. Evaluation table, reduced to the available linear sums

Write

```text
Tplus  = sum_{n>=1} P_n/n^3,
Tminus = sum_{n>=1} (-1)^n*P_n/n^3.
```

The six endpoint values are

```text
I10 = Tminus -(3/2)*L^2*Z2 -(7/2)*L*Z3,               (7.1)

I11 = Tplus,                                           (7.2)

I12 = 3*Tminus +(3/2)*L^2*Z2
      -(21/2)*L*Z3 +(3/2)*Z2^2,                       (7.3)

I20 = Tminus+Tplus -(3/5)*Z2^2,                       (7.4)

I21 = 3*Tminus-3*L^2*Z2
      -(35/4)*L*Z3 +(9/4)*Z2^2,                       (7.5)

I22 = 3*Tminus -(21/2)*L*Z3 +2*Z2^2.                 (7.6)
```

These are not table citations. The derivations below use only the explicit
primitives (6.1), the already-proved linear endpoint integrals, Landen/
reflection, and quartic log integrals.

For coefficient auditing, substituting the known linear values gives the
fully expanded table

```text
I10 = -2*A4 -L^4/12 -L^2*Z2 -(7/4)*L*Z3 +(1/10)*Z2^2,

I11 =                    -(7/2)*L*Z3 +(3/4)*Z2^2,

I12 = -6*A4 -L^4/4 +3*L^2*Z2
      -(21/4)*L*Z3 +(9/5)*Z2^2,

I20 = -2*A4 -L^4/12 +(1/2)*L^2*Z2
      -(7/4)*L*Z3 +(1/4)*Z2^2,

I21 = -6*A4 -L^4/4 -(3/2)*L^2*Z2
      -(7/2)*L*Z3 +(51/20)*Z2^2,

I22 = -6*A4 -L^4/4 +(3/2)*L^2*Z2
      -(21/4)*L*Z3 +(23/10)*Z2^2,                    (7.7)
```

where `A4=Li4(1/2)`.

## 7.1 Row `I11`: no new polylogarithm

From (6.6),

```text
I11 = integral_0^1 r(t)*H1(t)^2/t dt.                 (7.8)
```

Put `y=1-t`. Then

```text
I11
 = integral_0^1 log((1-y)/(1+y))*log(y)^2/(1-y) dy

 = integral_0^1 log(y)^2*log(1-y)/(1-y) dy
   -integral_0^1 log(y)^2*log(1+y)/(1-y) dy.           (7.9)
```

The first integral is `-Z4/2`; the second is the already-proved mixed
integral

```text
E = (7/2)*L*Z3-(19/8)*Z4.
```

Thus

```text
I11 = -Z4/2-E
     = -(7/2)*L*Z3+(15/8)*Z4
     = Tplus.                                         (7.10)
```

Use `Z4=(2/5)*Z2^2` only in the last rewrite.

## 7.2 Row `I20`: only half values and `Li4'(x)=Li3(x)/x`

Put

```text
Y(t)=Li2(t/2).
```

Since `Y'=H2/t`,

```text
I20 = integral_0^1 (Z2-2*Y-h^2) dY.                  (7.11)
```

The boundary calculation gives

```text
I20
 = Z2*L2h-L2h^2-L^2*L2h-2*L*L3h-2*A4,               (7.12)
```

where

```text
L2h=Li2(1/2)=Z2/2-L^2/2,
L3h=Li3(1/2)=7*Z3/8-L*Z2/2+L^3/6.
```

For completeness, the two integrations by parts are

```text
integral h^2 dY
 = L^2*L2h-2*integral h*Y/t,

integral h*Y/t
 = [h*Li3(t/2)]_0^1-integral Li3(t/2)/t
 = -L*L3h-A4.                                        (7.13)
```

Substitution of the two half values proves (7.4).

## 7.3 Row `I22`: reuse `K` and `B3`

From (6.6),

```text
I22 = integral_0^1 r(t)*H2(t)^2/t dt.                 (7.14)
```

Put `t=2*x/(1+x)`. Then

```text
r(t)=log x,
H2(t)=log(1+x),
dt/t=dx/(x*(1+x)).                                    (7.15)
```

Hence

```text
I22 = integral_0^1 log(x)*log(1+x)^2/(x*(1+x)) dx.    (7.16)
```

Splitting `1/(x*(1+x))=1/x-1/(1+x)`, using the available

```text
K = integral_0^1 log(x)^2*log(1+x)/(1+x) dx
```

and integrating `log(1+x)^2/(1+x)` once gives

```text
I22 = -K-(1/3)*B3+L^4/12.                             (7.17)
```

Here

```text
B3 = integral_0^(1/2) log(1-u)^3/u du
   = 6*A4+L^4/2-(3/2)*L^2*Z2+(21/4)*L*Z3-6*Z4.
```

Equation (7.17) immediately yields (7.6).

## 7.4 Row `I10`: export one auxiliary from the linear minus proof

From (6.6),

```text
I10 = 2*integral_0^1 r(t)*Li2(t)/t dt.                (7.18)
```

Since `d Li3(t)=Li2(t)dt/t` and

```text
r'(t)=1/t+1/(2-t),
```

```text
I10 = -2*Z4-2*J3two,                                  (7.19)

J3two := integral_0^1 Li3(t)/(2-t) dt.                (7.20)
```

The linear alternating proof already contains exactly this endpoint after the

```text
J3two
 = -Tminus/2 +(3/4)*L^2*Z2 +(7/4)*L*Z3

```

This is not an extra special value. Its proof uses the already formalized

If the current linear file only exposes the final HasSum theorem, refactor its

## 7.5 The two cross rows

The explicit primitives satisfy

```text
g12+g21 = H1*H2,                                      (7.22)

 g12-g21
 = Z2+2*Li2(t-1)
   +log(1-t)*(log(2-t)+L).                             (7.23)
```

Therefore

```text
I12+I21
 = 2*integral_0^1 r(t)*H1(t)*H2(t)/t dt               (7.24)

 = 6*Tminus -(3/2)*L^2*Z2
   -(77/4)*L*Z3 +(15/4)*Z2^2,                         (7.25)
```

and

```text
I12-I21
 = 2*integral_0^1 r(t)/t *
     [Z2+2*Li2(t-1)
      +log(1-t)*(log(2-t)+L)] dt                      (7.26)

 = (1/2)*Tplus +(9/2)*L^2*Z2-(9/8)*Z2^2              (7.27)

 = (9/2)*L^2*Z2-(7/4)*L*Z3-(3/4)*Z2^2.               (7.28)
```

Equation (7.25) is a quartic-log endpoint already covered by the ordinary
reducer. For (7.27), put `y=1-t`, use

```text
Li2(-y) = -Li2(y/(1+y))-(1/2)*log(1+y)^2,             (7.29)
```

then use `v=y/(1+y)`. Every resulting integral is one of `B3`, `J12`, `E`,
or an elementary zeta/log endpoint from the linear file. No `Li4` value other
than `Li4(1/2)` appears, and it cancels from the difference.

Solving (7.25) and (7.28) gives (7.3) and (7.5). This is a much smaller formal
task than evaluating `I12` and `I21` independently.

# 8. Final coefficient algebra

Insert (7.1)-(7.6) into (5.6). A direct ring calculation gives

```text
Aquad
 = 11*Tminus+2*Tplus
   -12*L^2*Z2-14*L*Z3+(41/10)*Z2^2.                  (8.1)
```

Now substitute the two available linear values.

The coefficients are:

```text
Li4(1/2):  11*(-2)                         = -22,
L^4:        11*(-1/12)                     = -11/12,
L^2*Z2:     11*(1/2)-12                    = -13/2,
L*Z3:       11*(7/4)+2*(-7/2)-14           = -7/4,
Z2^2:       11*(1/10)+2*(3/4)+41/10        = 67/10.
```

Thus

```text
boxed:
Aquad = -22*Li4(1/2)
        -(11/12)*L^4
        -(13/2)*L^2*Z2
        -(7/4)*L*Z3
        +(67/10)*Z2^2.                                (8.2)
```

An optional consistency relation, after the nonalternating quadratic theorem
`Qplus` is available, is

```text
Aquad = Tplus+Tminus-Qplus-Z2^2/20.                   (8.3)
```

# 9. Endpoint and integrability audit

The raw displayed formulas use Mathlib's totalized `log` and division. Endpoint
values such as `log 0=0` are junk values and must not be used as continuity
proofs.

The exact asymptotics needed are:

```text
at t -> 0+:
  W0(t) = O(log(t)^2),
  H1(t) = O(t),
  H2(t) = O(t),
  the singular 1/t coefficients cancel in (5.4),
  so the master integrand is O(t*log(t)^2);

at t -> 1-:
  W0(1)=W0'(1)=0,
  W0(t)=O((1-t)^2),
  the worst remaining factor is log(1-t)/(1-t),
  so the master integrand is O((1-t)*|log(1-t)|).
```

Both bounds are integrable.

For a robust Lean proof:

1. prove all derivative identities on `Ioo 0 1`;
2. perform integration by parts on `[eps,1-eps]`;
3. pass `eps -> 0+` using the fixed-power limits
   `x^c*|log x|^k -> 0` and their `1-x` analogues;
4. only afterward identify the full interval integral.

For removable quotients such as `log(1-t)/t`, use a `dslope`-based continuous
extension. For genuine logarithms, do not force continuity; use the punctured
interval and one-sided limits.
