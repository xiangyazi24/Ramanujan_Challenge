# Pair-flat: the correct cohomological mechanism and the horizontal wall

## Executive verdict

The new data are mathematically coherent, but the proposed explanation needs one major correction.

The exact pair correlation is controlled by a new global cohomology group

```plain text
V_(h,k)
 = H_c^1(T, A_h tensor D(A_k))(1/2),
```

where A_h is the normalized augmentation Fourier sheaf whose trace is S_h(t)/sqrt(p) on the common good t-open. After the baseline and geometric-component terms are removed,

```plain text
E_(h,k)
 = -sqrt(p) * Tr(Frob_p | V_(h,k)) + boundary,
```

with the convention that V_(h,k) is weight zero after the displayed half twist. Equivalently, before the half twist, the Frobenius trace has weight one and size at most

```plain text
dim V_(h,k) * sqrt(p).
```

For a generic distinct pair,

```plain text
dim V_(h,k) = 2 g_(h,k) + O(h+k)
            = 12 h k + O(h+k).
```

Thus Deligne gives the honest deterministic bound

```plain text
|E_(h,k)| << h k sqrt(p) + h k.
```

This is the same hk sqrt(p) barrier seen from the fiber-product genus.

The observed law

```plain text
mean |E_(h,k)| approximately constant * sqrt(p)
```

is compatible with a random-matrix law for the second-level representation V_(h,k): if normalized Frobenius in that representation behaves like Haar in a large symplectic, orthogonal, or unitary group and the representation is irreducible, character orthogonality gives trace variance one, independent of the dimension. That is the correct conceptual explanation.

However:

1. V_(h,k) does not decompose by Kunneth into pairwise products of the global eigenvalues attached separately to A_h and A_k.

1. Big product monodromy of A_h and A_k removes the H_c^2 main term and proves fixed-pair quasi-orthogonality, but it does not give a rank-free error constant.

1. The provable effective constant grows like hk; therefore current methods give an absolute O(sqrt(p)) constant only for bounded gaps.

1. A literal uniform O(1) normalized bound over all H^2 pairs is not even the natural random extreme-value prediction. Random traces predict a bounded mean and RMS, but a maximum growing roughly like sqrt(log H).

1. The fixed-p, growing-h,k assertion remains a horizontal large-sieve/Sato-Tate problem for the family {V_(h,k)}. It is not a consequence of ordinary Deligne equidistribution.

The sharpest theorem presently available is therefore a fixed-pair theorem with constant O(hk). On the pairs whose component and monodromy census is already certified, this gives a genuine O(sqrt(p)) theorem with one fixed constant. No growing-gap range with an O(1) coefficient is currently proved.

## 1. Exact Fourier and cohomological accounting

Work first with the complete regular domains rather than the nonwrapping windows. Put

```plain text
U_h = P^1_r minus the poles of delta_h,
S_h(t) = sum_(r in U_h(F_p)) psi(t delta_h(r)).
```

The complete coincidence count satisfies additive orthogonality:

```plain text
N_(h,k)^comp
 = |U_h(F_p)| |U_k(F_p)| / p
   + (1/p) sum_(t != 0) S_h(t) conjugate(S_k(t)).
```

The window count differs from the complete count by boundary pieces. Deleting O(h) values of the first coordinate and O(k) values of the second coordinate changes the pair count by at most O(hk), because every deleted vertical line meets the other degree-3k cover in at most 3k points, and symmetrically. Thus the window restriction is lower order relative to hk sqrt(p).

Let F_h^aug be the augmentation Fourier object from Q6566, with the common punctual summand at t=0 removed. On the common lisse open T of the t-line, normalize by a half Tate twist and write

```plain text
A_h = F_h^aug(1/2),
a_h(t) = Tr(Frob_t | A_h) = S_h(t)/sqrt(p),
```

up to the harmless global sign imposed by the Fourier convention.

Then the centered pair correlation is

```plain text
E_(h,k)^comp
 = sum_(t in T(F_p)) a_h(t) conjugate(a_k(t))
   plus explicit punctual and boundary corrections.
```

Set

```plain text
H_(h,k) = A_h tensor D(A_k).
```

Grothendieck-Lefschetz gives

```plain text
sum_(t in T(F_p)) Tr(Frob_t | H_(h,k))
 = sum_i (-1)^i Tr(Frob_p | H_c^i(T_bar,H_(h,k))).
```

There is no H_c^0 term. The top cohomology is

```plain text
H_c^2(T_bar,H_(h,k))
  = Hom_geom(A_k,A_h)(-1).
```

This is the exact component/main-term dictionary.

For h != k, if the augmentation sheaves are geometrically irreducible and nonisomorphic, then

```plain text
Hom_geom(A_k,A_h)=0.
```

Equivalently, the primitive fiber product has no additional component. After the already classified component terms are removed, only H_c^1 remains:

```plain text
E_(h,k)
 = -Tr(Frob_p | H_c^1(T_bar,H_(h,k))) + O(hk).
```

The sheaf H_(h,k) is pure of weight zero. Therefore its compactly supported first cohomology has weights at most one, and Deligne gives

```plain text
|E_(h,k)|
 <= dim H_c^1(T_bar,H_(h,k)) * sqrt(p) + O(hk).
```

In the generic ramification situation of Q6601, the primitive pair curve has

```plain text
g_(h,k)=6hk-3h-3k-2.
```

The pair-curve and Fourier descriptions differ only by the explicitly removed constant, diagonal, punctual, and boundary pieces. Consequently

```plain text
dim H_c^1(T_bar,H_(h,k))
 = 2g_(h,k) + O(h+k)
 = 12hk + O(h+k).
```

This recovers the honest fixed-pair estimate

```plain text
|E_(h,k)|
 <= (12hk+O(h+k)) sqrt(p) + O(hk).
```

If the generic ramification hypotheses are not available, arithmetic genus still gives

```plain text
dim H_c^1 << hk,
```

so the same scale survives with a less sharp absolute constant.

## 2. The proposed Kunneth decomposition is false

At one fixed value of t, suppose the local Frobenius eigenvalues of A_h are

```plain text
alpha_1(t),...,alpha_(4h-2)(t)
```

and those of A_k are

```plain text
beta_1(t),...,beta_(4k-2)(t).
```

Then at the stalk level one certainly has

```plain text
a_h(t) conjugate(a_k(t))
 = sum_(i,j) alpha_i(t) conjugate(beta_j(t)).
```

But after summing over t, the resulting global cohomology is

```plain text
H_c^1(T, A_h tensor D(A_k)).
```

It is not

```plain text
H_c^1(T,A_h) tensor H_c^1(T,D(A_k)),
```

and its Frobenius eigenvalues are not pairwise products of two separately defined global angle sets.

Kunneth applies to the external product on T x T:

```plain text
H_c^*(T x T, A_h boxtimes D(A_k)).
```

The correlation uses the pullback to the diagonal t=t', hence the tensor product on the same curve. Diagonal pullback is precisely the operation that creates the new cohomology representation V_(h,k).

Therefore the sentence

```plain text
E_(h,k)/sqrt(p) is the sum of all pairwise products
of the individual global Frobenius eigenvalues
```

is false.

The correct statement is:

```plain text
E_(h,k)/sqrt(p)
 is the normalized Frobenius trace of one new
O(hk)-dimensional global cohomology representation V_(h,k).
```

## 3. Why random independent angles give the wrong scale

If the 2g normalized eigenangles of V_(h,k) were independent phases, their sum would have typical size

```plain text
sqrt(2g) approximately sqrt(hk),
```

which would predict

```plain text
|E_(h,k)| approximately sqrt(hk p).
```

The data reject that model.

There is a different random-matrix model which does predict the observed constant scale. Let K_(h,k) be a compact monodromy group and let rho_(h,k) be an irreducible representation whose underlying vector space is V_(h,k)(1/2). Character orthogonality gives

```plain text
integral_(K_(h,k)) |Tr rho_(h,k)(g)|^2 dg = 1.
```

This identity is independent of dim V_(h,k). For a Haar-random unitary, symplectic, or orthogonal matrix in the standard irreducible representation, the eigenangles are strongly correlated; they are not independent phases. Those correlations reduce the variance of the trace from the dimension to a constant.

Thus the clean random-matrix interpretation of the data is:

```plain text
V_(h,k) is essentially irreducible,
and the normalized Frobenius classes of the pair family
behave horizontally like Haar classes in their compact groups.
```

If V_(h,k) decomposes into m_(h,k) pairwise nonisomorphic irreducible constituents, the Haar second moment of its character is m_(h,k). The empirical coefficient near one is therefore evidence not merely for large monodromy, but for a one-constituent or bounded-constituent second-level cohomology.

This is a deeper assertion than product monodromy of A_h and A_k.

## 4. What product monodromy actually proves

Assume for one fixed distinct pair (h,k):

```plain text
1. A_h and A_k are geometrically irreducible and pure of weight zero.
2. They are not geometrically isomorphic after a rank-one twist,
   duality, or an allowed base automorphism.
3. Their connected geometric monodromy groups have no compatible
   common simple quotient.
```

Then the Goursat-Kolchin-Ribet criterion gives the product geometric monodromy group for the pair. In particular the standard characters are orthogonal:

```plain text
integral_(K_h x K_k)
 chi_h(g) conjugate(chi_k(g')) d(g,g') = 0.
```

The known local data make these hypotheses plausible:

```plain text
rank A_h = 4h-2
```

already distinguishes different h, and the complete local type records h, excluding accidental isomorphism or dual/Kummer twist. For almost-simple groups of different ranks, a common nonabelian simple quotient is also unlikely, apart from finite low-rank accidents which can be checked separately.

But two warnings are essential.

First, the full Fourier objects are not irreducible because they share a punctual summand at t=0; one must work with augmentation objects on the common lisse open. The level h=1 is also Kummer-reducible and must be handled separately.

Second, product monodromy proves that the Haar main term is zero. It does not bound the finite-field discrepancy with a rank-free constant. The trace formula still gives the error constant

```plain text
dim H_c^1(T,A_h tensor D(A_k)) << hk.
```

So Goursat removes H_c^2; it does not collapse H_c^1.

## 5. The precise vertical theorem that is provable

There are two different meanings of "vertical," and they must not be conflated.

### 5.1 Field-extension verticality

Fix a good prime p and fixed gaps h,k. Assume the product-monodromy hypotheses above. As

```plain text
q=p^n -> infinity
```

through the permitted extension degrees, Deligne-Katz equidistribution gives joint equidistribution of the local Frobenius classes

```plain text
(theta_(h,t),theta_(k,t)), t in T(F_q),
```

in the compact product K_h x K_k.

For the standard-character product, the Haar mean is zero for h != k, and the effective trace-formula statement is

```plain text
|(1/q) sum_(t in T(F_q))
  a_h(t) conjugate(a_k(t))|
 <= b_(h,k) / sqrt(q),
```

where

```plain text
b_(h,k)=dim H_c^1(T_bar,A_h tensor D(A_k)) << hk.
```

Multiplying by q in the normalization of the pair correlation gives

```plain text
|E_(h,k)(q)| << hk sqrt(q).
```

This theorem is fully compatible with Deligne and big product monodromy. It is the fixed-pair exponent 1/2 theorem, with a conductor-dependent constant.

### 5.2 Prime verticality

Fix h,k and reduce the rational maps modulo varying good primes p. Hasse-Weil or the sheaf trace formula gives

```plain text
E_(h,k)(p)=O_(h,k)(sqrt(p)).
```

This is also provable outside a finite bad-prime set.

However, an assertion that the normalized global errors

```plain text
E_(h,k)(p)/sqrt(p)
```

are Sato-Tate distributed as p varies is a Sato-Tate statement for the global compatible system V_(h,k). It is not an automatic consequence of Deligne's finite-field equidistribution theorem. For a general high-genus curve or motive, such prime-varying Sato-Tate is not known merely from knowing large geometric monodromy of the original local sheaves.

The project only needs the pointwise Hasse-Weil bound for fixed pairs, but the observed constant-one distribution belongs conceptually to this second-level Sato-Tate picture.

## 6. Effective dependence on h and k

The project already supplies the exact generic rank

```plain text
rank A_h = 4h-2.
```

The local Fourier construction has conductor O(h). For tensor products, the standard conductor inequality has the shape

```plain text
cond(A_h tensor D(A_k))
 << rank(A_k) cond(A_h)
    + rank(A_h) cond(A_k),
```

hence

```plain text
cond(A_h tensor D(A_k)) << hk.
```

Grothendieck-Ogg-Shafarevich then gives

```plain text
b_(h,k)=dim H_c^1 << hk.
```

The genus formula refines this to the leading value 12hk in the generic case.

Therefore the strongest deterministic theorem obtainable from ordinary Deligne equidistribution is

```plain text
|E_(h,k)| << hk sqrt(p).
```

For all h,k <= H, this becomes

```plain text
max_(h,k<=H) |E_(h,k)| << H^2 sqrt(p).
```

Consequences:

```plain text
H bounded:
  |E_(h,k)| << sqrt(p) with one absolute constant.

H=(log p)^A:
  |E_(h,k)| << sqrt(p) (log p)^(2A)
  = p^(1/2+o(1)).

H=p^delta:
  |E_(h,k)| << p^(1/2+2delta).
```

Equivalently, for every fixed epsilon>0, the current estimate is of pair-flat exponent form

```plain text
|E_(h,k)| <= p^(1/2+epsilon)
```

only in a range such as

```plain text
h,k <= p^(epsilon/2),
```

and the constant is still not O(1) in the gaps.

This formal consequence assumes that geometric irreducibility, component classification, and good reduction are already uniform in the stated range. They are not currently proved all the way through a growing range.

The actual project status is sharper to state:

```plain text
For every fixed certified pair h != k with h,k <= 8,
there is a finite exceptional set of primes and a constant C_(h,k)
such that |E_(h,k)(p)| <= C_(h,k) sqrt(p) for all other primes.
```

Because the certified set is finite, one may take one constant C_8 for all those pairs. This is the strongest completely bankable pair-flat theorem at present.

Any theorem with h,k tending to infinity with p requires new uniform geometry. Even if all-h characteristic-zero monodromy were proved, effective spreading out introduces another growing bad-reduction invariant. Bounds of the project type

```plain text
log |bad invariant_(h,k)| << (h+k)^2 log(h+k)
```

would naturally guarantee uniform good reduction only in a logarithmic range roughly

```plain text
H << sqrt(log p / log log p),
```

and would still yield only p^(1/2+o(1)), not an absolute constant.

## 7. Why ordinary joint equidistribution does not prove pair-flat

Let

```plain text
f_(h,k)(t)=a_h(t) conjugate(a_k(t)).
```

Product monodromy gives

```plain text
Haar mean(f_(h,k))=0,
Haar L2 norm(f_(h,k))=1
```

when the two standard representations are irreducible.

This says that a random local value has variance one. If the p samples indexed by t behaved as independent random samples, their average would fluctuate on scale p^(-1/2), and hence E_(h,k) would fluctuate on scale sqrt(p). This is the correct heuristic.

But Deligne equidistribution is a first-order discrepancy theorem. Its deterministic discrepancy is measured by the cohomology of the sheaf representing f_(h,k), whose dimension is O(hk). It supplies

```plain text
average = 0 + O(hk / sqrt(p)),
```

not

```plain text
average = 0 + O(1 / sqrt(p)).
```

To replace hk by one, one needs square-root cancellation inside the global cohomology trace itself. This is a second-order statement about the Frobenius eigenvalues of V_(h,k). Deligne controls their individual absolute values, but not cancellation in their sum.

This is the exact obstruction.

## 8. The literal uniform O(1) law is too strong as a random prediction

Suppose the normalized errors

```plain text
X_(h,k)=E_(h,k)/sqrt(p)
```

behave like independent centered random variables of bounded variance. Then

```plain text
mean |X_(h,k)| = O(1),
mean |X_(h,k)|^2 = O(1).
```

Those are the correct pair-flat statistics.

However, among approximately H^2/2 samples, the maximum should normally grow like

```plain text
sqrt(log H)
```

up to the tail law of the compact group. Therefore a statement

```plain text
max_(h<k<=H) |E_(h,k)| <= C sqrt(p)
```

with one fixed C for arbitrarily growing H is stronger than the natural random model and may eventually be false.

The empirically and theoretically natural formulations are instead

```plain text
average pair-flat:
  sum_(h<k<=H) |E_(h,k)|^2 << p H^2 p^epsilon,

or high-probability pair-flat:
  max_(h<k<=H) |E_(h,k)|
  << sqrt(p log H) p^epsilon.
```

The first is exactly the four-gap diagonal-scale target identified in Q6580.

## 9. Minimal hypotheses for the growing range

A mere uniform-in-conductor version of Deligne's theorem is not enough unless it is rank-free, and a rank-free theorem is false for arbitrary sheaves. Constant summands, repeated constituents, and highly reducible systems give immediate counterexamples. The hypothesis must be imposed on the second-level correlation systems.

The clean average hypothesis is:

```plain text
[HORIZONTAL-PAIR-ST2]
For every epsilon>0 and H<=p^(2/3), after deleting the classified
component and bad-reduction pairs,

sum_(2<=h<k<=H)
  |Tr(Frob_p | V_(h,k)(1/2))|^2
  << H^2 p^epsilon.
```

Equivalently,

```plain text
sum_(h<k<=H) |E_(h,k)|^2
  << p H^2 p^epsilon.
```

This is a rank-free horizontal Sato-Tate/large-sieve statement. It says that the standard characters of the varying second-level motives have bounded average second moment at one fixed Frobenius element.

A pointwise version is:

```plain text
[HORIZONTAL-PAIR-MAX]
max_(h<k<=H)
 |Tr(Frob_p | V_(h,k)(1/2))|
 << p^epsilon.
```

This gives

```plain text
|E_(h,k)| << sqrt(p) p^epsilon.
```

For a genuinely random family, the more realistic pointwise version includes sqrt(log H).

Neither hypothesis is a standard consequence of GRH, Deligne, or ordinary Sato-Tate. They are new growing-conductor, fixed-characteristic family statements. A useful way to view them is as a large sieve for the compatible systems V_(h,k), with the family indices (h,k) replacing the usual varying finite-field points.

A high-moment formulation would imply the maximum bound:

```plain text
For q up to c log p,

sum_(h<k<=H)
 |Tr(Frob_p | V_(h,k)(1/2))|^(2q)
 << H^2 (Cq)^q p^epsilon.
```

Markov then gives a sqrt(log H) maximum. This is the natural precise strengthening if future data measure extremes rather than means.

## 10. The two-stage route supported by the data

Assume average pair-flat:

```plain text
mean_(h<k<=H) |E_(h,k)| << sqrt(p) p^epsilon.
```

Then the total absolute pair error is

```plain text
sum_(h<k<=H) |E_(h,k)|
 << H^2 sqrt(p) p^epsilon.
```

The COINC budget is pH. Therefore pair-flat alone is sufficient while

```plain text
H^2 sqrt(p) <= pH,
```

namely

```plain text
H <= p^(1/2).
```

More precisely, for H<=p^(1/2-eta) it gives a power saving in the budget.

For

```plain text
p^(1/2) < H <= p^(2/3),
```

pair-flat magnitudes are no longer enough. One must use sign cancellation after grouping pairs into shells

```plain text
A_d(H)=sum_h E_(h,h+d).
```

If the H terms in a shell have random signs and individual size sqrt(p), the random prediction is

```plain text
|A_d(H)| approximately sqrt(Hp),
```

not H sqrt(p). Summing over O(H) shells then gives scale

```plain text
sqrt(p) H^(3/2),
```

which is below pH throughout H<=p. Thus the empirical two-stage picture is internally consistent:

```plain text
Stage 1:
  pair-flat magnitudes handle H up to p^(1/2-o(1)).

Stage 2:
  signed shell cancellation supplies the extra saving
  from p^(1/2) to p^(2/3).
```

This separation is cleaner than asking one uniform theorem to do both jobs.

## 11. Sharpest provable statement on this axis

The theorem that can be banked now is the following.

```plain text
[FIXED-PAIR-QUASI-ORTHOGONALITY]
Fix h != k. Assume the primitive difference correspondence X_(h,k)
is geometrically irreducible over Qbar, and remove every classified
geometric component and boundary term. Then there exists a finite set
Sigma_(h,k) of bad primes such that for p not in Sigma_(h,k),

|E_(h,k)(p)|
 <= (2g_(h,k)+O(h+k)) sqrt(p) + O(hk).

Under the generic ramification hypotheses,

g_(h,k)=6hk-3h-3k-2,

so

|E_(h,k)(p)|
 <= (12hk+O(h+k)) sqrt(p)+O(hk).
```

Proof sketch:

```plain text
1. Complete the windows and record the O(hk) boundary difference.
2. Apply additive orthogonality in the value variable.
3. Replace the complete sums by the normalized augmentation Fourier sheaves.
4. Use the components/Hom dictionary to eliminate H_c^2.
5. Apply Grothendieck-Lefschetz and Deligne weights to H_c^1.
6. Compute its dimension from the normalized fiber-product genus,
   or bound it by Grothendieck-Ogg-Shafarevich.
```

For the finite certified census h,k<=8, this gives one uniform constant after excluding the union of finitely many bad-prime sets.

No theorem currently proves

```plain text
|E_(h,k)| << sqrt(p) p^epsilon
```

uniformly for a genuinely growing range of gaps, and no theorem proves an O(1) normalized constant as h,k grow. Achieving either would be a new result. The exact missing object is the horizontal second moment of the second-level cohomology systems V_(h,k), not further analysis of the individual pair curves one at a time.

## Final verdict

```plain text
Exact Fourier/Hom/cohomology dictionary: PROVED.
Kunneth pair-of-angle decomposition: FALSE.
Fixed-pair exponent 1/2 with constant O(hk): PROVED conditionally on the certified component statement; fully bankable on the finite verified range.
Product monodromy of A_h,A_k: plausible and sufficient to remove the main term, but not sufficient for a rank-free error.
Observed O(1) normalized mean: naturally explained by Haar trace statistics of the new representation V_(h,k).
Uniform O(1) maximum over growing pairs: not the correct random prediction; expect at least sqrt(log H).
Growing-gap pair-flat: OPEN and equivalent to a horizontal large-sieve/Sato-Tate statement for V_(h,k).
Two-stage route H<=sqrt(p) by pair-flat, then shell signs to p^(2/3): coherent and is the right campaign decomposition.
```

Primary conceptual references are Deligne's Weil II for weights, Laumon's Fourier-Deligne transform, Katz's finite-field equidistribution and Goursat-Kolchin-Ribet machinery, and Fouvry-Kowalski-Michel's quasi-orthogonality/conductor formalism for trace functions. None of those results supplies the required fixed-p horizontal, rank-free family estimate.
