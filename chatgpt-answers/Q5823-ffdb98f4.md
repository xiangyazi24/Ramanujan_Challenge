# Analytic branch layer for Problem 3.1

## Verdict

The clean Lean route is **not** to invoke the implicit function theorem. The official theorem should be split into:

1. an existence/uniqueness certificate for the positive branch `y`;
2. the analytic integral identity assuming that branch.

If the official statement already quantifies:

```lean
∀ y : ℝ → ℝ, (∀ x ∈ Set.Icc α β, A72 x (y x) = 0 ∧ ... ) → integral = ...
```

then existence of `y` is not part of the theorem. The faithful Lean theorem should preserve this. A separate theorem can prove the branch hypotheses.

## Best transformation

Use reciprocal variables because the polynomial is palindromic. Put

```
s = x + x⁻¹
`t = y + y⁻¹
```

and divide `A_72(x,y)` by the appropriate monomial. The palindromic symmetry gives an equation

```
P(s,t)=0
```
with degree two in `t` (after the standard two-bridge normalization).

The branch is then the positive root

```
t(s) = (-B(s)+sqrt(B(s)^2-4C(s)))/(2C(s))
```

on the interval corresponding to `x ∈ [α,β]`.

The Lean proof obligation becomes polynomial inequalities for one variable, not a two-variable implicit curve.

## Existence certificate

The required finite certificate is:

```
1. α < β
2. P(s,t) = A72(x,y)/(x^m y^m)
3. discriminant Δ(s)=B(s)^2-4C(s) > 0 on [sβ,sα]
4. chosen root t(s)>2
5. recover y from y+y⁻¹=t:
      y=(t-sqrt(t²-4))/2
```

Then:

```
y(x)>0
A72(x,y(x))=0
```

is obtained by algebraic rewriting.

## Uniqueness

For the positive branch it is enough to prove the other root is outside the admissible interval.

If

```
F(x,y)=A72(x,y)
```

then along the reciprocal variable:

```
∂P/∂t ≠ 0
```

follows from the quadratic discriminant. Hence the selected root is unique.

This is stronger and more Lean-friendly than a generic IFT invocation.

## Derivative bound

Implicit differentiation gives

```
y'(x)= - F_x(x,y)/F_y(x,y)
```

or after the reciprocal substitution:

```
dt/ds = -P_s/P_t
```

and

```
dy/dt = y²/(y²-1)
```

so

```
y' = (dy/dt)(dt/ds)(ds/dx)
```

with

```
ds/dx = 1 - 1/x² < 0
```

on the interval. The final certificate is a rational interval enclosure:

```
-∞ < y'(x) ≤ -2
```

proved by clearing denominators and checking polynomial positivity.

## What not to do

Do not encode:

```
∃ y, Continuous y ∧ Differentiable y ∧ ...
```

and then try to prove it by Mathlib's general implicit-function machinery. That introduces unnecessary topology and local-chart obligations.

The natural formal object is:

```
def yBranch (x : ℝ) : ℝ :=
  (tBranch (x+x⁻¹) - sqrt(...))/2
```

followed by exact polynomial verification.

## First concrete computation

The first computation to run is:

1. Expand `A_72(x,y)/(x^m y^m)`.
2. Substitute `s=x+1/x`, `t=y+1/y`.
3. Compute the exact quadratic coefficients `B(s), C(s)`.
4. Use Sturm sequences to prove:


on the exact interval.

This produces the smallest certificate that Lean can consume.
