# Q5905: stronger finite pre-Bloch search after Abel/complement failure

## Verdict

The previous Abel-pair closure was not a certificate search. A rank defect after 732 generators means only that the chosen relation lattice was too small. It does not show that the target is outside the Bloch relation lattice.

The search must change from "generate many Abel pairs" to "generate relations adapted to the PGL2 action and target cokernel direction".

## 1. Work in the ordinary pre-Bloch group

The desired Rogers identity is

```javascript
R(a)+R(b)+R(c)+R(d)=pi^2/10
```

which corresponds to

```javascript
[a]+[b]+[c]+[d] = 1/10 [1]
```

at the Rogers level modulo the period lattice. Multiplying by the torsion bound 120 is NOT required to prove this identity in the ordinary pre-Bloch group. The number 120 enters only when using the K-theoretic torsion route to obtain a denominator bound.

For an explicit five-term certificate, search directly for

```javascript
5([a]+[b]+[c]+[d])-3[1]=0
```

or a relation differing by known complement pairs.

## 2. Use the full alternating five-term relation

Use

```javascript
[x]-[y]+[y/x]-[(1-1/x)/(1-1/y)]+[(1-x)/(1-y)]
```

rather than only Abel relations.

Represent every argument by a PGL2 orbit element:

```javascript
z -> (alpha*z+beta)/(gamma*z+delta)
```

with matrix in GL2(K).

The relation generator is then:

```javascript
R(M,x,y)=e_x-e_y+e_(y/x)-e_((x-1)y/(x(y-1)))+e_((1-x)/(1-y))
```

where every coordinate is reduced modulo the endpoint field polynomial.

## 3. Bidirectional meet-in-the-middle search

The missing direction should be attacked as a lattice problem.

Let V be the vector space generated by all orbit arguments. Let L be the row span of all discovered five-term relations and complement relations.

Compute the target residue:

```javascript
r = target mod L
```

Then search generators that have nonzero pairing with r.

Do not expand blindly. Use two directions:

Forward:

- start from {a,b,c,d,1};

- apply PGL2 transformations of bounded height;

- close under five-term arguments.

Backward:

- start from the missing cokernel basis vector;

- enumerate five-term relations whose support intersects it;

- solve the sparse matching problem.

The success condition is:

```javascript
target_vector = sum_i n_i * relation_i + sum_j m_j * complement_j
```

with exact integer coefficients.
