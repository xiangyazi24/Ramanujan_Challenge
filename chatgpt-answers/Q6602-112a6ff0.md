```plain text
Gamma(h,k) = Gamma_all(h,k) - L_h L_k
```

```plain text
||Gamma||_op <= p max_h sum_(k<=H) |E(h,k)|.
```

## 1. Exact normalization of the Gram matrix

Fix 1<=h<=H and put

```plain text
I_h = {1,...,M-h},
L_h = |I_h| = M-h,
f_h(r) = Delta_(r,h).
```

For a in F_p, define the value multiplicity and its centered version by

```plain text
nu_h(a) = #{r in I_h : f_h(r)=a},
q_h(a)  = nu_h(a) - L_h/p.
```

Then

```plain text
sum_a nu_h(a) = L_h,
sum_a q_h(a)  = 0.
```

Define the raw and centered pair counts

```plain text
J(h,k) = sum_a nu_h(a) nu_k(a),

E(h,k) = sum_a q_h(a) q_k(a)
       = J(h,k) - L_h L_k/p.                       (1.1)
```

Thus J(h,k) is exactly

```plain text
#{(r,r') in I_h x I_k : f_h(r)=f_k(r')}.
```

For t in F_p, let

```plain text
S_h(t) = sum_(r in I_h) e_p(t f_h(r)).
```

Since S_h(0)=L_h, additive orthogonality gives

```plain text
sum_(t in F_p) S_h(t) conjugate(S_k(t))
 = p J(h,k).                                       (1.2)
```

Define

```plain text
Gamma_all(h,k)
 = sum_(t in F_p) S_h(t) conjugate(S_k(t)),

Gamma(h,k)
 = sum_(t!=0) S_h(t) conjugate(S_k(t)).             (1.3)
```

Then the exact decomposition is

```plain text
Gamma_all(h,k) = p J(h,k),
Gamma_all(h,k) = L_h L_k + Gamma(h,k),
Gamma(h,k)     = p E(h,k).                          (1.4)
```

In matrix notation, with L=(L_1,...,L_H)^T,

```plain text
Gamma_all = L L^T + Gamma,
Gamma     = p E.                                    (1.5)
```

This is the complete baseline bookkeeping. The raw matrix has the large rank-one operator

```plain text
L L^T,
```

whose operator norm is

```plain text
sum_(h<=H) L_h^2 asymp p^2 H.
```

It is the uniform t=0 term and must be removed before any mixing statement is formulated.

### 1.1 The diagonal is part of the target

The centered diagonal is

```plain text
E(h,h)
 = sum_a q_h(a)^2
 = J(h,h) - L_h^2/p
 >= 0,                                               (1.6)
```

and

```plain text
Gamma(h,h) = p E(h,h).                              (1.7)
```

Here J(h,h) contains the literal diagonal pairs r=r' as well as all off-diagonal equal-value pairs. No diagonal term is absorbed into the rank-one baseline. Therefore any row criterion must include E(h,h) explicitly.

If one later removes an additional proved finite-rank structural component, such as a forced mirror component, its operator norm must be restored separately. Nothing of that kind is silently removed in the formulas above.

## 2. Exact Schur reduction

The matrix Gamma is Hermitian and positive semidefinite: it is the Gram matrix of the vectors

```plain text
(S_h(t))_(t!=0).
```

Therefore the Hermitian Schur bound gives

```plain text
||Gamma||_op
 <= max_(h<=H) sum_(k<=H) |Gamma(h,k)|
 =  p max_(h<=H) sum_(k<=H) |E(h,k)|.               (2.1)
```

Equivalently,

```plain text
||E||_op
 <= max_(h<=H) sum_(k<=H) |E(h,k)|.                 (2.2)
```

The precise sufficient condition is therefore

```plain text
[ROWWISE-E]

max_(h<=H) sum_(k<=H) |E(h,k)| <= C p.              (2.3)
```

In Fourier-Gram units this is

```plain text
[ROWWISE-GAMMA]

max_(h<=H) sum_(k<=H) |Gamma(h,k)| <= C p^2.        (2.4)
```

Under either form,

```plain text
||E||_op <= C p,
||Gamma||_op <= C p^2.                              (2.5)
```

### 2.1 Why this implies COINC

Put

```plain text
N_H = sum_(h<=H) L_h.
```

The total coincidence excess is

```plain text
X_H
 := N_coinc(H) - N_H^2/p
  = sum_(h,k<=H) E(h,k)
  = 1^T E 1
  = (1/p) 1^T Gamma 1.                              (2.6)
```

Hence

```plain text
0 <= X_H <= H ||E||_op.                            (2.7)
```

Under [ROWWISE],

```plain text
X_H <= C p H.                                      (2.8)
```

Since N_H asymp pH, this is exactly the desired COINC scale

```plain text
N_coinc(H) <= N_H^2/p + O(N_H).                    (2.9)
```

### 2.2 The general row-to-energy formula

It is useful not to specialize immediately to R_H=O(p). Define

```plain text
R_H = max_(h<=H) sum_(k<=H) |E(h,k)|.              (2.10)
```

Then

```plain text
X_H <= H R_H.                                      (2.11)
```

The additive-orthogonality and Parseval identities give

```plain text
sum_(h<=H) C_h
 <= N_H/p + sqrt(X_H)
 <= H + sqrt(H R_H) + O(H^2/p).                    (2.12)
```

Combining this with the proved block-energy inequality yields, uniformly for H<=p,

```plain text
F_p
 << p^2/H + p sqrt(R_H/H) + p.                     (2.13)
```

This formula is the exact exponent ledger for every row estimate below.

For the ideal row estimate R_H<<p, taking H=p^(2/3) gives

```plain text
p^2/H              = p^(4/3),
p sqrt(R_H/H)      = p^(7/6),
```

so

```plain text
F_p << p^(4/3).                                    (2.14)
```

The condition R_H<<p is sufficient, but it is stronger than what is necessary merely to improve energy.

## 3. Exact fixed-row square expansion

Fix h. The requested Cauchy inequality is

```plain text
sum_(k<=H) |E(h,k)|
 <= sqrt(H) [sum_(k<=H) E(h,k)^2]^(1/2).           (3.1)
```

Because the diagonal is nonnegative and normally has size comparable to p, the sharper useful form is

```plain text
sum_(k<=H) |E(h,k)|
 <= E(h,h)
    + sqrt(H-1) [sum_(k!=h) E(h,k)^2]^(1/2).       (3.2)
```

Without this split, the diagonal alone incurs an artificial factor sqrt(H).

### 3.1 Expansion as an exact tuple count

Write

```plain text
J(h,k) = #{(r,r') : f_h(r)=f_k(r')}.
```

Then

```plain text
E(h,k)=J(h,k)-L_hL_k/p.
```

Therefore

```plain text
sum_(k<=H) E(h,k)^2
 = T_h
   - (2L_h/p) sum_(k<=H) L_k J(h,k)
   + (L_h^2/p^2) sum_(k<=H) L_k^2,                 (3.3)
```

where

```plain text
T_h = sum_(k<=H) J(h,k)^2
```

is exactly the number of tuples

```plain text
(k; r,s,r',s')
```

with

```plain text
r,s in I_h,
r',s' in I_k,
f_h(r)=f_k(r'),
f_h(s)=f_k(s').                                  (3.4)
```

Thus the row-square is a centered four-point count with one family index k.

### 3.2 Joint-value third-moment form

Define the raw joint-value family moment

```plain text
M_3(a,b) = sum_(k<=H) nu_k(a) nu_k(b).             (3.5)
```

It counts

```plain text
#{(k,r',s') : f_k(r')=a and f_k(s')=b}.            (3.6)
```

Expanding the two inner products gives

```plain text
sum_(k<=H) E(h,k)^2
 = sum_(a,b) q_h(a) q_h(b)
     sum_(k<=H) q_k(a) q_k(b).                     (3.7)
```

Now expand

```plain text
q_k(a)q_k(b)
 = nu_k(a)nu_k(b)
   - (L_k/p)nu_k(a)
   - (L_k/p)nu_k(b)
   + L_k^2/p^2.                                    (3.8)
```

When contracted against q_h(a)q_h(b), every term except the first vanishes, because

```plain text
sum_a q_h(a)=sum_b q_h(b)=0.
```

Hence the exact raw-moment identity is

```plain text
boxed:

sum_(k<=H) E(h,k)^2
 = sum_(a,b) q_h(a) q_h(b) M_3(a,b).               (3.9)
```

This is the desired rowwise reduction. It also shows why estimates for M_3(a,b) must retain the signed weights. A large uncentered main term in M_3 is annihilated by centering, while an absolute-value estimate generally loses that cancellation.

## 4. What unconditional tools say about M_3

### 4.1 Degree and mass bounds

The rational map

```plain text
f_k(X)=N_k(X)/A_k(X),
A_k(X)=product_(j=1)^k (X+j)^3
```

has degree at most 3k. Therefore every finite value fiber satisfies

```plain text
nu_k(a) <= 3k.                                     (4.1)
```

Also

```plain text
sum_a nu_k(a)=L_k<=p.                              (4.2)
```

Consequently

```plain text
sum_a nu_k(a)^2 <= 3kp,                            (4.3)
E(k,k) <= 3kp.                                     (4.4)
```

For a pair (h,k),

```plain text
J(h,k)
 = sum_a nu_h(a)nu_k(a)
 <= 3k L_h,
```

and symmetrically

```plain text
J(h,k) <= 3h L_k.
```

Thus

```plain text
J(h,k) <= 3p min(h,k).                             (4.5)
```

The baseline satisfies

```plain text
0 <= L_hL_k/p <= p <= 3p min(h,k),                 (4.6)
```

so, because both terms are nonnegative,

```plain text
|E(h,k)|
 = |J(h,k)-L_hL_k/p|
 <= max(J(h,k),L_hL_k/p)
 <= 3p min(h,k).                                   (4.7)
```

Summing the row gives the explicit bound

```plain text
sum_(k<=H)|E(h,k)|
 <= 3p [ h(h+1)/2 + h(H-h) ]
 = 3p [ hH - h(h-1)/2 ].                           (4.8)
```

The right side is increasing for 1<=h<=H, so

```plain text
R_H
 <= (3/2)pH(H+1)
 << pH^2.                                           (4.9)
```

This is the best uniform row estimate obtained from the currently proved degree and mass inputs.

The same exponent appears directly from M_3. Namely,

```plain text
M_3(a,b)
 <= 9 sum_(k<=H) k^2
 = (3/2)H(H+1)(2H+1),                              (4.10)
```

and

```plain text
sum_a |q_h(a)| <= 2L_h <= 2p.                      (4.11)
```

Thus (3.9), after absolute values, gives

```plain text
sum_k E(h,k)^2 << p^2 H^3,                         (4.12)
```

and (3.1) again gives

```plain text
sum_k |E(h,k)| << pH^2.                            (4.13)
```

No power is gained by passing through the joint-value moment unless one proves signed cancellation in (a,b) or orthogonality in k.

### 4.2 Audit of the proved triple-return theorem

Import the proved theorem in the requested form:

```plain text
Q_p(H) <= (27/4) H^(5/2).                          (4.14)
```

Let

```plain text
A(r,k)=1_[f_k(r)=0].                               (4.15)
```

Then the theorem controls

```plain text
d_H(r)=sum_(k<=H) A(r,k),
Q_p(H)=sum_r binom(d_H(r),2)
      =sum_(k<l)sum_r A(r,k)A(r,l).                (4.16)
```

This is a same-base, two-family-index, zero-level moment.

By contrast,

```plain text
M_3(a,b)
 =sum_k [sum_r 1_[f_k(r)=a]]
        [sum_s 1_[f_k(s)=b]].                      (4.17)
```

This is a one-family-index, two-independent-base, arbitrary-level moment. The two moments are transposes of one another in the incidence tensor.

Even at (a,b)=(0,0),

```plain text
M_3(0,0)=sum_k C_k^2,                              (4.18)
```

whereas Q_p(H) is the second moment of the row degrees d_H(r). There is no general inequality from (4.16) to (4.18). An incidence matrix can have every row degree at most one, hence Q=0, while one column contains many ones and its squared column sum is large.

The box translation injection uses the implication

```plain text
f_k(r)=0  <=>  pi(r)=pi(r+k).                      (4.19)
```

Two returns from the same r therefore form an ordered triple on one projective orbit, and a difference of gaps remains a projective collision.

For a!=0, the equation

```plain text
f_k(r)=a                                           (4.20)
```

is not a projective return. Subtracting a A_k destroys the zero-return interpretation. Moreover, in M_3(a,b) the bases r and s are independent, so there is no common orbit point from which the translation injection can start.

Therefore the box/master argument does not adapt, even for typical (a,b), without a genuinely new affine-level family theorem. The proved bound (4.14) supplies no improvement to (4.9) or (4.12).

### 4.3 Exact missing theorem at the M_3 level

A row-square theorem would have to control the signed contraction

```plain text
sum_(a,b) q_h(a)q_h(b)M_3(a,b),                   (4.21)
```

not merely the total mass

```plain text
sum_(a,b)M_3(a,b)=sum_k L_k^2 asymp p^2H.         (4.22)
```

The sharp Poisson-scale target is

```plain text
[ROW-MIX4]

max_(h<=H)
 sum_(k!=h) E(h,k)^2
 << pH.                                            (4.23)
```

This is a mixed joint-value fourth moment. It is not contained in the proved zero-level triple-return theorem.

## 5. The individual fourth-moment hypothesis

Assume

```plain text
[FM4-IND]

max_(k<=H) sum_a |q_k(a)|^4 <= C_4 p.              (5.1)
```

Then Cauchy in the value variable gives

```plain text
E(k,k)=sum_a q_k(a)^2
 <= sqrt(p) [sum_a q_k(a)^4]^(1/2)
 <= sqrt(C_4) p.                                   (5.2)
```

Because E is a Gram matrix,

```plain text
|E(h,k)|^2 <= E(h,h)E(k,k),                        (5.3)
```

so

```plain text
|E(h,k)| <= sqrt(C_4) p,                           (5.4)
```

and hence

```plain text
R_H <= sqrt(C_4) pH.                               (5.5)
```

Equivalently,

```plain text
||E||_op << pH,
||Gamma||_op << p^2H.                              (5.6)
```

Substitution in (2.13) gives

```plain text
F_p << p^2/H + p^(3/2) + p.                       (5.7)
```

Thus choosing any H>=p^(1/2) only recovers

```plain text
F_p << p^(3/2).                                    (5.8)
```

There is no positive power saving.

### 5.1 What proving FM4-IND itself would require

The quantity in (5.1) is a centered linear combination of four-point fiber counts for one rational map. Its leading raw term counts

```plain text
(r1,r2,r3,r4) in I_k^4
```

with

```plain text
f_k(r1)=f_k(r2)=f_k(r3)=f_k(r4).                  (5.9)
```

A uniform proof for k as large as p^(2/3) would require a component census and cancellation for a growing-degree four-fold fiber product. Fixed-k Weil theory does not provide the required uniformity.

More importantly, even a proof of (5.1) would not settle the row problem. It controls each column separately and says nothing about relative orientation of the centered vectors q_k.

### 5.2 The genuinely mixed fourth moment

The Poisson-compatible hypothesis is (4.23):

```plain text
sum_(k!=h) E(h,k)^2 << pH.                         (5.10)
```

Together with E(h,h)<<p, the split Cauchy bound (3.2) gives

```plain text
R_H << p + H sqrt(p).                              (5.11)
```

At H=p^(2/3),

```plain text
R_H << p^(7/6).                                    (5.12)
```

This does not prove [ROWWISE], but (2.13) gives

```plain text
p^2/H         = p^(4/3),
p sqrt(R_H/H) = p^(5/4),
```

and therefore

```plain text
[ROW-MIX4 at H=p^(2/3)]
    ==> F_p << p^(4/3).                            (5.13)
```

So the mixed fourth moment would be a campaign win.

### 5.3 Why absolute ROWWISE is stronger than the flat law predicts

For independent Poisson-sized centered histograms, one expects

```plain text
E(h,k) has size about sqrt(p) for h!=k.            (5.14)
```

Then a typical absolute row has size

```plain text
p + H sqrt(p).                                     (5.15)
```

At H=p^(2/3), this is p^(7/6), larger than p. Thus the empirical flat law does not predict the absolute Schur condition [ROWWISE]. It predicts a Gram operator bound obtained through signed spectral cancellation, or at most the mixed square-row bound (5.10).

To force [ROWWISE] through Cauchy one would need

```plain text
sum_(k!=h) E(h,k)^2 << p^2/H.                      (5.16)
```

At H=p^(2/3), the right side is p^(4/3), while the Poisson scale in (5.10) is pH=p^(5/3). Condition (5.16) asks for an extra factor p^(-1/3) beyond the random model. It is therefore not the natural next conjecture.

The correct full-DLS target remains the signed operator statement

```plain text
||E||_op << p,                                     (5.17)
```

which is compatible with a Wishart/random-frame model even when absolute row sums exceed p.

## 6. Best unconditional row bound and exact exponent arithmetic

From (4.9), the unconditional row estimate is

```plain text
R_H << pH^2.                                       (6.1)
```

Therefore

```plain text
||E||_op << pH^2,
||Gamma||_op << p^2H^2.                            (6.2)
```

At the intended scale H=p^(2/3), this says only

```plain text
||E||_op << p^(7/3),
```

```plain text
F_p
 << p^2/H + p^(3/2)H^(1/2).                       (6.4)
```

Balancing the two terms gives

```plain text
H=p^(1/3),                                         (6.5)
```

and then

```plain text
F_p << p^(5/3).                                    (6.6)
```

Thus the row method with present unconditional inputs does not even reproduce ENERGY-3/2.

The direct degree/block argument already proved in the project gives

```plain text
F_p << p^(3/2).                                    (6.7)
```

Taking the better of (6.6) and (6.7), the best unconditional theorem today remains exactly

```plain text
F_p << p^(3/2).                                    (6.8)
```

There is no surviving positive delta in

```plain text
F_p << p^(3/2-delta).                              (6.9)
```

The imported theorem Q_p(H)<<(27/4)H^(5/2) does not change this conclusion because it controls the wrong incidence orientation for the row moment. Through its own sigma-ladder route it also does not beat the separately proved 3/2 energy theorem.

### 6.1 The single blocking term

Under the individual fourth-moment hypothesis, the row bound is R_H<<pH, and the second term in (2.13) becomes

```plain text
p sqrt(R_H/H) = p^(3/2).                           (6.10)
```

This term is independent of H; it is the exact ceiling.

In combinatorial language, the blocker is

```plain text
sum_(k!=h)|E(h,k)|.                                (6.11)
```

In second-moment language, it is

```plain text
sum_(k!=h)E(h,k)^2.                                (6.12)
```

In joint-value language, it is the signed contraction

```plain text
sum_(a,b)q_h(a)q_h(b)M_3(a,b) - E(h,h)^2.          (6.13)
```

No current theorem controls this quantity on the required growing range.
