# Boundary-symbol cancellation attack

## Verdict

The face-symbol calculation gives no cancellation. The lclm operator L does not annihilate the active boundary exponential contribution. The order-five combination leaves a nonzero face symbol, so the boundary sequence is not reduced to a bounded-width polynomial-height ghost carrier.

## 1. Symbol setup

Let the shell moment face contribution be represented by a boundary exponential mode

[

Y_D^{mathrm{face}}=lambda^D P(D),

]

with the Ore operators P,A acting in the D direction. For a shift operator E:f(D)\mapsto f(D+1), the principal symbol is obtained by replacing E with an indeterminate z and taking the top D-degree coefficient.

If

[

L=operatorname{lclm}(P,A),

]

then on the exponential face mode the symbol evaluation is

[

sigma_L(lambda)=operatorname{lc}(L)(lambda).

]

A cancellation would require this polynomial to vanish for every active boundary root \lambda.

## 2. Exact conclusion

The computed lclm symbol is nonzero on the supporting face. Therefore

[

L(Y_D^{mathrm{face}})neq0

for the active face contribution. The order-five combination only removes the recurrence presentation redundancy; it does not create a new small carrier.

Equivalently, the boundary term survives as a genuine solution of the lclm recurrence with nonzero principal symbol. There is no bounded-width polynomial-height residual obtained from this route.

Section 68.14 ghost quotients already show that the linear quotient lattice saturates to the scalar Newton gcd after primitive Smith reduction. The boundary-symbol calculation gives the complementary analytic obstruction:

- Smith saturation removes fake multiplicity.

- The lclm removes incompatible recurrence descriptions.

Thus no new target-preserving carrier is produced.
