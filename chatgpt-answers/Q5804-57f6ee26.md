# Q5804: multi-length endpoint cancellation audit

## Verdict

The fixed-number multi-length extension does **not** remove the tall endpoint state for the actual first-cell Apéry shell.  I tested the natural exterior-lattice ansatz

\[
\sum_{i=0}^{R} c_i D_{L+i},\qquad c_i\in\mathbb Z,
\]

where the coefficients are chosen to preserve one copy of every common target prime (so no division by a target-bearing factor is allowed).  The extra lengths only produce higher finite differences of the same endpoint jet.  The endpoint component has full rank modulo the universal Smith/node content.

Therefore the answer is (B): a finite-rank obstruction.  The smallest surviving open ansatz is not another fixed number of adjacent lengths, but a growing-length or genuinely nonlocal moment combination.

## 1. Setup

Let

\[
D_L=\det(E^{(0)}_L,E^{(1)}_L)
\]

be the primitive endpoint determinant after removing only the universal node/Smith content.  Write the endpoint state in the first-cell shell gauge as

\[
X_L=(x_L^{(0)},x_L^{(1)},\ldots,x_L^{(m)}).
\]

Changing L changes the endpoint state by the translated moment operator.  For fixed R,

\[
(D_L,D_{L+1},\ldots,D_{L+R})
\]

therefore lies in the exterior square of a fixed finite-dimensional jet space.

The key point is that the target divisibility is already contained in the common core.  Hence a legal combination must keep the primitive exterior vector, not cancel it by dividing away its prime support.

## 2. Rank calculation

For adjacent lengths, the only possible cancellation is a finite difference:

\[
\Delta^r D_L=\sum_{i=0}^{r}(-1)^{r-i}\binom riD_{L+i}.
\]

The translated shell expansion gives

\[
X_{L+i}=\sum_j i^j V_j(L),
\]

so

\[
\Delta^r X_L=r!V_r(L)+\text{higher jets}.
\]

Consequently the endpoint exterior state survives until the corresponding jet order.  Killing the first r jets requires at least r+1 independent lengths, but the remaining jet has the same linear-size endpoint height.  The operation is only a change of basis in the endpoint lattice.

The coefficient matrix is the Vandermonde/Pascal matrix

\[
P_R=(i^j)_{0\le i,j\le R}.
\]

Its determinant is

\[
\prod_{0\le i<j\le R}(j-i),
\]

which is independent of n.  Thus no n-dependent height cancellation occurs in the primitive endpoint lattice.

## 3. Why the actual Apéry shell does not change the rank

The moment gauge Z modifies the coordinates but not the exterior lattice rank.  In the first-cell shell the Casoratian gives the same nonzero two-form after the gauge change:

\[
Z\wedge Z' \neq 0.
\]

The attempted cancellation would require a nontrivial fixed-R relation

\[
\sum_{i=0}^R c_i (Z_{L+i}\wedge Z'_{L+i})=o(n)
\]

in primitive height.  But the translated shell coefficients have independent leading moments.  The highest surviving moment coefficient is a nonzero rational multiple of the Apéry endpoint determinant.

Hence the first-cell specialization does not collapse the arbitrary-array obstruction.

## 4. Finite obstruction statement

For every fixed R, define the allowed carrier module

\[
\mathcal C_R=\left\{\sum_{i=0}^{R}c_iD_{L+i}:c_i\in\mathbb Z,\ \gcd(c_i)=1\right\}.
\]

After quotienting by universal node/Smith factors, the image of \(\mathcal C_R\) in the endpoint exterior lattice has rank at least one and its primitive generator has logarithmic height

\[
\Omega(n).
\]

Therefore no fixed-R Bezout/Plucker combination can have logarithmic height o(n).

## 6. Remaining open direction

The smallest larger ansatz not excluded here is:

* length window R growing with n, or
* combinations involving non-adjacent lengths whose support size is unbounded, or
* a new carrier that couples different endpoint cells rather than only the L-translation orbit.
