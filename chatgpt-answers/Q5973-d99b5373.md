# 8. Lean-facing theorem layout

The following organization should splice cleanly into the present RamanujanChallenge.P23 namespace.

```javascript
noncomputable def rt2 : ℝ := Real.sqrt 2
noncomputable def kerC : ℝ := 2 - rt2

def kerP (x : ℝ) : ℝ := x * (1 - x)
def kerD (x : ℝ) : ℝ := 1 - kerC * kerP x

def kerIntegrand (n : ℕ) (x : ℝ) : ℝ :=
  kerP x ^ n / kerD x ^ (n + 1)

noncomputable def lambertK (n : ℕ) : ℝ :=
  ∫ x in (0 : ℝ)..1, kerIntegrand n x

def kerCert (n : ℕ) (x : ℝ) : ℝ :=
  (1 - 2 * x) * kerP x ^ (n + 1) / kerD x ^ (n + 2)
```

Recommended lemma order:

```javascript
lemma rt2_sq : rt2 ^ 2 = 2
lemma kerP_nonneg_of_mem_Icc
lemma kerP_le_quarter_of_mem_Icc
lemma kerD_pos_of_mem_Icc

lemma hasDerivAt_kerCert (n : ℕ) (x : ℝ) :
  HasDerivAt (kerCert n)
    ((n + 1 : ℝ) * kerIntegrand n x
      - rt2 * (2 * n + 3 : ℝ) * kerIntegrand (n + 1) x
      - 2 * (n + 2 : ℝ) * kerIntegrand (n + 2) x) x

lemma kerCert_zero : kerCert n 0 = 0
lemma kerCert_one  : kerCert n 1 = 0

lemma lambertK_rec (n : ℕ) :
  2 * (n + 2 : ℝ) * lambertK (n + 2)
    + rt2 * (2 * n + 3 : ℝ) * lambertK (n + 1)
    - (n + 1 : ℝ) * lambertK n = 0

lemma lambertK_zero : lambertK 0 = rt2 * (Real.pi / 4)
lemma lambertK_one  : lambertK 1 = 1 - Real.pi / 4
```

Then define the two sequences to compare:

```javascript
noncomputable def lambertError (n : ℕ) : ℝ :=
  (lambertA n : ℝ) * (Real.pi / 4) - (lambertB n : ℝ)

noncomputable def kernelError (n : ℕ) : ℝ :=
  (-1 : ℝ) ^ n * (n ! : ℝ) * rt2 ^ (n + 1) / 2 * lambertK n
```

Prove:

```javascript
lemma lambertError_rec ...
lemma kernelError_rec ...
lemma lambertError_zero : lambertError 0 = kernelError 0
lemma lambertError_one  : lambertError 1 = kernelError 1

theorem lambert_error_eq_kernel (n : ℕ) :
  (lambertA n : ℝ) * (Real.pi / 4) - (lambertB n : ℝ)
    = (-1 : ℝ) ^ n * (n ! : ℝ) * rt2 ^ (n + 1) / 2 * lambertK n
```

The recurrence equality proof should use Nat.factorial_succ, cast normalization, rt2_sq, and ring; the final equality is a two-base-value induction.
