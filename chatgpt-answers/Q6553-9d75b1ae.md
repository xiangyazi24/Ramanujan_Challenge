## 1. PROVED: exact sequential-return identity

For positive integers a,g with a+g<=D, define

```plain text
T_p(a,g)
= #{r : I(r,a)=1 and I(r+a,g)=1}.
```

### Proposition 1.1

```plain text
Q_p(D) = sum_(a>=1,g>=1,a+g<=D) T_p(a,g).
```

### Proof

A summand in Q_p(D) is a choice of two zero lags

```plain text
0 < h1 < h2 <= D
```

from one base r. Put

```plain text
a = h1,
g = h2-h1.
```

Then

```plain text
pi(r)=pi(r+a)=pi(r+a+g).
```

Hence

```plain text
I(r,a)I(r,a+g)=I(r,a)I(r+a,g).
```

The map

```plain text
(r,h1,h2) -> (r,a=h1,g=h2-h1)
```

is bijective. This proves the identity.

In continuant language, if N_a(r)=0, the restart identity gives

```plain text
N_(a+g)(r) = mu_a(r) N_g(r+a),
mu_a(r) = -(r+a)^6 N_(a-1)(r),
```

and mu_a(r) is nonzero at a regular return. Thus the same identity is also an exact renewal statement, not merely a projective tautology.

### Immediate consequences

For every a,g,

```plain text
T_p(a,g) <= R_a,
T_p(a,g) <= R_g,
T_p(a,g) <= min(R_a,R_g).
```

The last bound alone gives only

```plain text
Q_p(D) << sum_(a+g<=D) min(a,g) << D^3,
```

so it is weaker than the new D^(8/3) theorem.

## 2. Route (A): the strongest direct short/long-gap charging

Let

```plain text
M(D) = max_I,v (m_I(v)-1),
```

where I runs over index intervals of length at most D. The new theorem gives

```plain text
M(D) <= 4D^(2/3).
```

### Proposition 2.1: triangle charging

For every D,

```plain text
Q_p(D) <= 2 M(D) S_p(floor(D/2)).
```

### Proof

Take a same-color triple

```plain text
r < r+a < r+a+g,
a+g <= D.
```

At least one of a,g is at most D/2.

Case 1: a<=g.

Charge the triple to the first collision edge

```plain text
(r,r+a),
```

whose length is at most D/2. Once this edge is fixed, the possible third points lie in a forward interval of length at most D and have the same color. There are at most M(D) such extensions.

Case 2: g<a.

Charge the triple to the second collision edge

```plain text
(r+a,r+a+g),
```

again of length at most D/2. Once this edge is fixed, the possible first points lie in a backward interval of length at most D and have the same color. There are at most M(D) such extensions.

For each short gap h, there are R_h collision edges. Summing the two orientations proves

```plain text
Q_p(D) <= 2M(D) sum_(h<=D/2) R_h.
```

This is the claimed inequality.

### Corollary 2.2: exact recovery of the 8/3 exponent

Use

```plain text
S_p(K) <= sum_(h=2)^K 3(h-1)
       = (3/2)K(K-1).
```

With K=floor(D/2) and M(D)<=4D^(2/3), Proposition 2.1 gives

```plain text
Q_p(D)
<= 2 * 4D^(2/3) * (3/2)K(K-1)
<= 3D^(8/3).
```

This is exactly the banked theorem.

### Hostile conclusion for route (A)

The three collision events are not three independent constraints. They are the three edges of one same-color triangle. Transitivity is automatic for every color partition. Once the proof has reduced to

```plain text
total number of short edges
x
maximum number of extensions per edge,
```

the exponent is forced to be

```plain text
D^2 * D^(2/3) = D^(8/3).
```

A power saving requires an average extension theorem. Reusing the pointwise maximum cannot provide it.

## 3. Route (B): convolution and dyadic bootstrapping

### 3.1 Exact convolution form

Proposition 1.1 is the exact convolution-like identity

```plain text
Q_p(D)
= sum_(a+g<=D)
    #{r : N_a(r)=0 and N_g(r+a)=0}.
```

The important word is shifted: the second polynomial is evaluated at r+a, not at r. This is precisely the renewal geometry.

### 3.2 The natural dyadic recursion

Put K=floor(D/2). Triples whose outer span is at most K contribute Q_p(K). Every remaining triple has one adjacent gap at most K and can be charged as in Proposition 2.1. Hence

```plain text
Q_p(D)
<= Q_p(K) + 2M(D)S_p(K).
```

Iterating over D,D/2,D/4,... gives a geometric sum with top term

```plain text
M(D)S_p(D/2) << D^(2/3)D^2 = D^(8/3).
```

Thus the recursion gives no exponent improvement.

### 3.3 Why inserting Cauchy does not create a contraction

The exact second-moment inequality is

```plain text
S_p(K)^2
<= N ( S_p(K) + 2Q_p(K) ),
N = p+O(1).
```

In particular,

```plain text
S_p(K) <= N + sqrt(2NQ_p(K)).
```

Substituting this into the dyadic recursion gives

```plain text
Q_p(D)
<= Q_p(K)
   + 2M(D)(N + sqrt(2NQ_p(K))).
```

Even under the desired hypothesis Q_p(K)<<p, the term

```plain text
M(D)N
```

has size

```plain text
pD^(2/3).
```

At D=sqrt(p)L, this is

```plain text
p^(4/3)L^(2/3),
```

which is much larger than p. Therefore this recursion is not absorptive.

### 3.4 What adjacent coprimality contributes

The exact adjacent resultant and N_1=1 remove the boundary row

```plain text
g=1
```

from the triangular convolution. Equivalently, two consecutive zero levels are impossible in the regular domain.

This is valuable rigidity, but it removes only O(D) of the O(D^2) lag pairs. It cannot change the exponent.

### 3.5 Mirror peeling

Write

```plain text
d_D(r)=d_D^mir(r)+d_D^prim(r),
d_D^mir(r) in {0,1}.
```

Then

```plain text
binom(d_D(r),2)
= binom(d_D^prim(r),2)
  + d_D^mir(r)d_D^prim(r).
```

The pure mirror-mirror second moment vanishes, but the mirror-primitive cross term remains. With only the degree bound it can still be as large as S_p(D). Mirror peeling changes constants and identifies the forced component; it does not produce the needed power saving.

### Verdict for route (B)

```plain text
Exact convolution: PROVED.
Dyadic recursion: PROVED.
Power saving from current inputs: DEAD.
```

## 4. Route (C): fixed-r apparition theory

This is the main audit requested in the question.

### 4.1 What Lucas apparition theory actually uses

For a constant-coefficient Lucas sequence, the state evolves by one fixed matrix C:

```plain text
(U_(n+1),U_n)^T = C^n (U_1,U_0)^T.
```

The Binet formula turns U_n=0 mod p into a group-order condition. For strong divisibility Lucas sequences one has

```plain text
gcd(U_m,U_n)=U_gcd(m,n),
```

and, away from the discriminant and parameter primes,

```plain text
p divides U_n  <=>  alpha(p) divides n.
```

Both the fixed matrix and the strong divisibility identity are load-bearing.

### 4.2 The Apéry h-sequence is nonautonomous

For fixed r, put

```plain text
u_h=N_h(r).
```

Then

```plain text
u_(h+1)
= P(r+h)u_h - (r+h)^6u_(h-1).
```

The transfer matrix changes at every h:

```plain text
A_(r+h)
= [[P(r+h), -(r+h)^6],
   [1,        0       ]].
```

Thus there is no single matrix power, no Binet ratio raised to h, and no fixed cyclic subgroup whose order can be called the apparition rank.

### 4.3 PROVED: exact shifted-rank renewal law

Suppose N_m(r)=0 at a regular return. Then for every g>=1,

```plain text
N_(m+g)(r)=0
<=>
N_g(r+m)=0.
```

The future zero problem is restarted at the new base r+m.

Define the first-return function

```plain text
alpha(x) = min{g>=1 : N_g(x)=0},
```

when it exists. If

```plain text
0=z_0<z_1<z_2<...
```

are successive zero lags from base r, then the exact law is

```plain text
z_(j+1)-z_j = alpha(r+z_j).
```

The increment is recomputed at every shifted base. This is a skew renewal law, not a divisibility sequence.

### 4.4 PROVED: explicit death certificate for multiples of the first zero

Take

```plain text
r0=-3/2.
```

Then

```plain text
r0+1=-1/2,
P(-1/2)=0,
```

so

```plain text
N_2(r0)=0.
```

Using the recurrence,

```plain text
N_3(r0)
= P(r0+2)N_2(r0) - (r0+2)^6N_1(r0)
= -(1/2)^6
= -1/64.
```

Next,

```plain text
N_4(r0)
= P(r0+3)N_3(r0) - (r0+3)^6N_2(r0)
= P(3/2)(-1/64).
```

Now

```plain text
P(3/2)
= (2*(3/2)+1)
  (17*(3/2)^2+17*(3/2)+5)
= 4*(275/4)
= 275.
```

Therefore

```plain text
N_4(r0)=-275/64.
```

For every prime p>11, this is nonzero modulo p. The residue

```plain text
r0=(p-3)/2
```

is admissible for gaps 2 and 4. It is exactly the forced mirror collision for gap 2. Hence, for every prime p>11,

```plain text
N_2(r0)=0,
N_4(r0)!=0.
```

This kills the proposed implication

```plain text
first apparition at h0  =>  all multiples of h0 are zeros.
```

It also gives the polynomial certificate

```plain text
N_2(X) does not divide N_4(X).
```

Indeed, modulo N_2(X)=P(X+1),

```plain text
N_4(X) == -(X+2)^6 P(X+3),
```

and this remainder is coprime to P(X+1).

### 4.5 Periodic-coefficient theory is also ineffective at this scale

Modulo p, the coefficient word has period p:

```plain text
P(r+h+p)=P(r+h),
(r+h+p)^6=(r+h)^6.
```

A recurrence with period q coefficients can be blocked into q-step monodromy matrices. Thus, after fixing one clock phase, its zeros may be studied using a constant matrix in the block index.

Here q=p. For the MESO target

```plain text
D=sqrt(p)L(p),
L(p)=log log p or log p,
```

one has D<p for all sufficiently large p. No two h-values in the window have the same clock phase. The p-step Floquet reduction therefore gives no spacing information inside this first block.

There is also a singular determinant once per full period, when r+h=0 mod p, so even the full-period monodromy is not a uniform invertible Lucas torus.

### 4.6 The only surviving apparition-type statement

If d_D(r)>=2, let the first two zero lags be

```plain text
0<h1<h2<=D.
```

Then

```plain text
h1 <= D/2
or
h2-h1 <= D/2.
```

The second alternative is a first return after restarting at r+h1.

This deterministic dichotomy is exactly the short-edge charging used in Proposition 2.1. It does not imply equal spacing, divisibility, or a fixed rank.

```plain text
Lucas-style fixed rank: DEAD.
Periodic-coefficient/Floquet shortcut below p: DEAD.
Shifted-base renewal: PROVED, but it reproduces route (A).
```

## 5. What the remaining tools can and cannot add

### 5.1 Two-lag elimination and resultants

For fixed a,g, the exact object is

```plain text
T_p(a,g)
= #{r : N_a(r)=0 and N_g(r+a)=0}.
```

A resultant can show that a fixed pair has no common root for all but the primes dividing a fixed integer, or can give a degree bound for the common-root scheme.

But MESO-QRLL asks for the sum over the whole triangle

```plain text
a>=1,
g>=1,
a+g<=D.
```

There are about D^2/2 pairs. Nonvanishing of each resultant does not say that p divides only few of those resultants, and a degree bound summed over the triangle returns the D^3 wall. This is the exact family-compatibility gap.

### 5.2 The new one-fiber multiplicity theorem

The theorem

```plain text
M(D)<=4D^(2/3)
```

is already used optimally in Proposition 2.1. A better pointwise exponent would help, but to reach Q(D)<<p at D=sqrt(p)L using only

```plain text
Q(D) <= M(D) S(D/2),
S(D/2)<=O(D^2),
```

one would need essentially

```plain text
M(D) << 1/L^2,
```

which is impossible as a general integer bound. Therefore MESO-QRLL cannot be closed by improving only the maximum multiplicity while retaining the trivial first moment.

### 5.3 Deep p-adic layers

The mod-p first-block collision problem lies entirely before one full clock period when D<p. The proved depth tower controls cross-p blocks and p-adic valuations. Its lowest mod-p layer is rank one and supplies no additional independent first-block collision equation. Without a new mixed-cocycle bridge, it does not improve the present Q count.

## 6. The exact missing lemma exposed by this attack

For a short collision edge

```plain text
e=(x,y),
pi(x)=pi(y),
1<=y-x<=D/2,
```

define its extension count to be the number of third occurrences of the same color that form a triple of total span at most D, in either orientation.

Let

```plain text
A_p(D)
= sum over short collision edges e of ext_D(e).
```

Every same-color triple of span at most D has at least one adjacent edge of length at most D/2, and at most two such adjacent edges. Consequently

```plain text
Q_p(D) <= A_p(D) <= 2Q_p(D).
```

Thus MESO-QRLL is, up to a factor 2, the following average extension theorem:

```plain text
[MESO-AVG-EXT]
For D=sqrt(p)L(p),
A_p(D) << p.
```

The current proof replaces the average extension count by its maximum:

```plain text
A_p(D)
<= M(D) * 2S_p(D/2),
```

which is exactly the D^(8/3) loss.

This formulation is not a logical weakening of QRLL; it is a factor-2 equivalent reparameterization. Its value is tactical: it shows exactly what renewal and resultants must prove.

A support-oriented sufficient condition is also available. Let E_p(D) be the number of short collision edges that have at least one extension. Then

```plain text
Q_p(D) <= M(D)E_p(D).
```

Therefore the theorem would follow from

```plain text
E_p(D) << p/D^(2/3).
```

At D=sqrt(p)L, this reads

```plain text
E_p(D) << p^(2/3)L^(-2/3).
```

This is a concrete union-of-common-roots target for the resultant machinery. It is stronger than merely bounding the number of fixed lag pairs, but much more directly aligned with what resultants see than the original second moment.

## 11. Required final two answers

### (a) Least certain step

The least certain strategic judgment is whether the support target

```plain text
E_p(D) << p/D^(2/3)
```

is materially easier than Q_p(D)<<p. It is perfectly valid as a sufficient condition and is aligned with resultants, but it may merely move the family-compatibility difficulty from multiplicity to union support. I have proved the reduction, not its tractability.

### (b) Possible shared blind spot

The most plausible shared blind spot is an enriched clock-dependent rank law, not the naive Lucas rank law killed above.

The death certificate rules out:

```plain text
one scalar rank alpha(r),
zeros at multiples of alpha(r),
a fixed constant 2x2 matrix model in h.
```

It does not rule out a bounded-rank extension carrying an additional clock or mixed-cocycle coordinate in which shifted bases become conjugate and first returns acquire a group law. Such an object would be a genuine bispectral or clock-gauge discovery and could collapse the average-extension count.

Conversely, proving that every such gauge must have state dimension or algebraic degree growing at least linearly with D would turn the present negative audit into a route-closing theorem.
