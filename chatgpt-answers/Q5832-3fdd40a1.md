## Correct reciprocal reduction procedure

For the actual proof one must start from the explicit Laurent polynomial

```
A(x,y)
```
from the official statement and perform:

1. Multiply by a monomial `x^m y^n` to obtain an ordinary polynomial `Abar(x,y)`.
2. Verify reciprocal symmetry:

```
x^d y^e A(1/x,1/y)=±A(x,y).
```

3. Divide by the forced factors coming from the reciprocal variables:

```
x^k - x^{-k}, y^k-y^{-k}
```
only after proving they are factors.

4. Substitute

```
s=x+x^{-1},
t=y+y^{-1}.
```

A genuine quadratic reduction requires proving

```
Abar(x,y)/(x^m y^n)=Q(s,t)
```
with

```
deg_t Q = 2.
```

The missing certificate is the exact coefficient list of `Q` and the identity back in `QQ[x,x^{-1},y,y^{-1}]`.

## Branch construction if the quadratic certificate exists

If

```
Q(s,t)=a_2(s)t^2+a_1(s)t+a_0(s),
```

then define

```
t_±(s)=(-a_1(s) ± sqrt(a_1(s)^2-4a_2(s)a_0(s)))/(2a_2(s)).
```

For positive `x,y`, choose

```
s=x+x^{-1} >= 2,
```
and recover

```
y=(t+sqrt(t^2-4))/2
```

using the positive root. The Lean-friendly branch theorem would require finite certificates:

* `a_2(s) != 0` on `[s_alpha,s_beta]`;
* discriminant strictly positive;
* chosen root satisfies `t>2`;
* endpoint substitutions give

```
y(alpha)=sqrt(alpha)

y(beta)=beta;
```

The derivative follows by implicit differentiation:

```
y' = - Q_s(s,t) * s'(x) / (Q_t(s,t) * (1-1/y^2))
```

where

```
s'(x)=1-x^(-2).
```

The bound `y'<=-2` then reduces to polynomial sign certificates after clearing positive denominators.
