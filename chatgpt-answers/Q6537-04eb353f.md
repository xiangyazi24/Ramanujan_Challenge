# P3.2 clock-twisted mirror quotient construction

## (1) Half-orbit quotient state space

Let p be odd prime and N=(p-1)/2. Original orbit:

```javascript
Pi_u = [b_u:c_u], 0<=u<=p-2
Pi_{p-1-u}=Pi_u
```

The quotient index set is the folded clock interval:

```javascript
Ubar = {0,1,...,N}
```

with quotient states:

```javascript
X_u = Pi_u, u in Ubar
```

The two fixed points are:

```javascript
u=0
u=N
```

The first is the initial point. The second is the reflection center. The full orbit is reconstructed by:

```javascript
Pi_{N+j}=Pi_{N-j}, 1<=j<=N
```

Therefore the quotient dynamics is NOT a periodic cycle. It is a path with a reflecting endpoint:

```javascript
0 -- 1 -- ... -- N
              ^
              reflection boundary
```

For u<N the transition is the ordinary Mobius step:

```javascript
X_{u+1}=M_u X_u

M_u=[[P(u)/(u+1)^3,-u^3/(u+1)^3],[1,0]]
```

At u=N the outgoing step is replaced by the inverse mirror return:

```javascript
M_N^quot = R M_{N-1}^{-1} R
```

where R is the coordinate identification induced by

```javascript
u <-> p-1-u.
```

Thus the quotient transfer operator is a folded path transfer, not a shorter cyclic transfer.

## (2) Explicit clock-twisted operator T_k

Original clock character:

```javascript
chi_k(u)=e_p(k u)
```

Mirror action gives:

```javascript
chi_k(p-1-u)
 = e_p(k(p-1))e_p(-ku)
 = e_p(-k)e_p(-ku)
```

(up to the harmless global phase e_p(-k)). Hence k and -k modes form a coupled pair.

Define the doubled quotient vector:

```javascript
F_u=(f_k(u), e_p(-k) f_{-k}(u))^T
```

Then the quotient clock operator is the 2x2 block:

```javascript
T_k(u)=
[ e_p(ku)        0          ]
[ 0        e_p(-ku)         ]
```

with boundary reflection matrix:

```javascript
J_k=
[0  1]
[1  0]
```

and folded propagation:

```javascript
T_k^fold = T_k(N-1)...T_k(0) J_k T_k(0)^{-1}...T_k(N-1)^{-1}
```

Equivalently, the spectrum splits into mirror-even and mirror-odd channels:

```javascript
f_+=f_k+e_p(-k)f_-k
f_-=f_k-e_p(-k)f_-k
```

The quotient removes the independent k/-k duplication.

## (3) Fejer and (8.4) decomposition on quotient coordinates

Let

```javascript
Z_p={u: b_u=0 mod p}
```

and let the primitive quotient collision count be

```javascript
Cbar_k = #{(u,v):0<=u<v<=N, Pi_u=Pi_v, u,v not mirror-paired}.
```

The forced mirror pairs satisfy

```javascript
Pi_u=Pi_{p-1-u}
```

identically, hence they are not primitive collisions.

For Fejer kernel

```javascript
F_K(x)=sum_{|h|<=K}(1-|h|/(K+1))e_p(hx)
```

the full-space identity becomes the quotient identity:

```javascript
Sum_{u=0}^{p-2} F_K(b_u)
=
2 Sum_{u=0}^{N} F_K(X_u) - F_K(X_N)
```

because the center point is counted once.

The forced mirror contribution is exactly removed:

```javascript
E_full = E_primitive + E_mirror

E_mirror = Sum_u F_K(Pi_u-Pi_{p-1-u})
          = Sum_u F_K(0)
```

and after quotient normalization:

```javascript
E_quot = E_full - E_mirror
       = primitive Fejer mass.
```

For the h=2/8.4 spectral decomposition:

```javascript
S_2(k)=Sum_u e_p(2k Pi_u)
```

the even forced mode is:

```javascript
S_2^mirror = Sum_u e_p(2k(Pi_u-Pi_{p-1-u}))
           = p-1
```

and quotient subtraction gives:

```javascript
S_2^quot = S_2-(p-1)
```

The FFT check target is therefore:

```javascript
FFT_full[k] - (p-1) = FFT_primitive[k]
```

for all tested k and all 146 primes.

## (4) Random benchmark after mirror quotient

Original birthday energy has p-1 states with forced pairing. The quotient has

```javascript
L=N+1=(p+1)/2
```

states.

For iid random states in a set of size p, the collision energy is:

```javascript
E sum_a m_a^2 = L + L(L-1)/p
```

because:

```javascript
E[m_a^2]=E[m_a]+E[m_a(m_a-1)]
```

and each ordered pair collides with probability 1/p.

Substituting L=(p+1)/2:

```javascript
E_quot
= (p+1)/2 + ((p+1)(p-1))/(4p)
= 3p/4 + 1/2 - 1/(4p).
```

Therefore the exact quotient random baseline is:

```javascript
E_quot = 0.75*p + 0.5 - 0.25/p.
```

This is the number to compare against the 146-prime FFT spectrum.
