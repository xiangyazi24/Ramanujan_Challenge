# Q6741 q64 LASTSTAND

## (i) Literature audit

There is no existing theorem that directly gives the required joint zero-counting in this regime. The available contacts each control a projection of the problem, not the quenched two-variable family.

1. Derksen / characteristic-p recurrence zero sets.

The relevant theorem shape is for constant-coefficient linear recurrences over characteristic p: zero sets have a structured description (p-automatic / finite-union-of-progressions type after suitable formulation). This is powerful when the recurrence operator is fixed.

It does not survive here directly. The h-recursion for N_h(x) has coefficients depending on x+h, so the recurrence is nonautonomous. The parameter x is not a spectator constant coefficient. The hostile feature is exactly the moving coefficient field.

2. Multiplicity bounds for linear recurrences in characteristic p (Lech-Christol type phenomena).

These give restrictions on zero multiplicity and repeated vanishing for recurrence sequences. They are compatible with the fixed-x restart bound already available. They do not couple different x values, hence they do not yield a saving over summing O(D^(2/3)) rows.

3. Large sieve for thin polynomial families.

Classical large sieve and polynomial large sieve results control averages such as sums over parameters of character sums or root counts for bounded-degree polynomial families. Typical error terms depend on the degree.

Here degree(N_h)=3(h-1) grows to sqrt(p)L. A naive application loses exactly in the degree parameter. No bounded-conductor large sieve survives without exploiting additional recurrence structure.

4. Bilinear forms with polynomial root indicators.

These convert indicators of f(x)=0 into additive-character sums and can exploit cancellation. They require either bounded complexity or independent oscillation in the family parameter. For N_h the h-direction is a recursive deformation, not an independent polynomial family. The needed estimate is a new family cancellation statement.

5. Bombieri-Pila / determinant method over finite fields.

These methods control rational/integer points on low-degree varieties. For a fixed h the curve N_h(x)=0 is one-dimensional but the degree grows like D. The two-variable object obtained by including h has no known low-degree algebraization. Applying determinant bounds to the naive graph has degree too large.

6. Cilleruelo-Garaev and Shkredov-Shparlinski value-set/energy methods.

These control collisions and additive/multiplicative energy of polynomial maps or dynamical orbits. They are closest philosophically: the desired theorem is a collision-energy saving. However existing results generally require fixed-degree maps, polynomial maps, or autonomous dynamics. The Apery clock is nonautonomous with growing gap.

Conclusion: the missing theorem is not in the standard toolkit. The obstacle is not a lack of a one-dimensional estimate; both marginals are already available. The missing input is a two-parameter cancellation theorem for a growing-degree recursive family.

## (ii) Derksen/Lucas/jet route

The Lucas observation is structurally correct but insufficient in the current window.

The known p-Lucas property for Apery numbers gives digit factorization of b_n modulo p. In a range n<p, however, n has only one base-p digit. Therefore Lucas collapses to the trivial one-digit statement and does not describe the mesoscopic collision strip.

The possible new direction is the jet. The second solution c_n is not a pure Lucas sequence; it contains derivative/harmonic corrections. The pair (b,c) behaves like a first-order jet of the hypergeometric solution. A collision

Delta_{r,d}=0

is a vanishing Wronskian condition, not merely equality of two Lucas values.

A useful breakthrough would be a formula of the following type:

N_d(x) = Phi(x,d) evaluated in a single controlled two-variable algebra, where Phi has complexity o(D^2).

For example, if all N_d were controlled by a bounded-complexity jet of a truncated hypergeometric function, then one could attack the entire dyadic family at once. No such formula is currently banked.

The previous characteristic-zero H-algebraization obstruction does not rule this out, because the possible new structure is genuinely mod-p and digit/jet based.

## (iii) Sharp theorem available today

The strongest unconditional statement from the current toolkit is the transpose pair of marginal bounds:

For every fixed x, the number of d in an interval of length D with N_d(x)=0 satisfies

O(D^(2/3))

by the ZWIN-RESTART recurrence zero bound.

For every fixed d,

#{x : N_d(x)=0} <= 3(d-1)

by the polynomial degree budget.

Summing either marginal alone gives no power saving over the D^2 scale.

The closest provable reformulation of the missing step is:

MISSING LEMMA (quenched horizontal-large-sieve lemma):

For every dyadic interval D/2<d<=D,

sum_x #{d : N_d(x)=0} <= D^(2-eta)

for some absolute eta>0.

Equivalently, the growing-gap return set of the Apery projective clock has power-saving energy below the degree budget.

A slightly stronger usable version would be:

For every set A of primitive returns with D/2<d<=D,

|A| <= D^(2-eta)

unless the return set forces a nontrivial algebraic symmetry of the transfer cocycle.

This would directly defeat the scattered adversary because the padding construction avoids long runs, fixed gaps, and word-level obstructions.

## Confidence and blind spot

(i) Least confident step:

The least secure step is the claim that existing representation-theoretic rigidity cannot already imply a hidden orbit-level anti-concentration theorem. The argument above only says that no standard implication is known; a new bridge from monodromy to quenched return times would change the conclusion.

(ii) Possible blind spot:

The question may underestimate the ordered noncommutative transfer product. The scattered adversary matches all listed word constraints, but it may fail a deeper constraint involving products of varying companion matrices. The missing object may not be a scalar polynomial family at all, but a cocycle-level large sieve for the Apery transfer matrices.
