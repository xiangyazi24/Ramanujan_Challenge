## 3. Exact no-go for every fixed bounded polygon in u,v

### Proposition

There is no compact convex polygon P ⊂ R² with nonempty interior such that, for all sufficiently large n,

```plain text
T_n(P) ⊆ P
```

where T_n is the exact u,v projective map and its denominator is positive on P.

### Proof

On a compact P, the exact coefficient formulas imply uniform convergence T_n → T∞. Hence invariance for all large n implies

```plain text
T∞(P) ⊆ P.
```

The affine map T∞ has determinant 1, so

```plain text
area(T∞(P)) = area(P).
```

Inclusion and equality of area force T∞(P)=P. But the centered linear part has an expanding eigenvalue 17+12√2>1. Any point with a nonzero unstable component has an unbounded forward orbit, contradicting boundedness of P. A polygon with nonempty interior necessarily contains such a point. QED.

### Consequence

Cutting corners of Xiang's rectangle into a triangle or a finer fixed polygon cannot solve the problem. The obstruction is not a poor choice of facets; it is the hyperbolic, area-preserving limiting projective dynamics.

The same proof applies to any moving family whose image under a finite affine 1/n rescaling converges to a nondegenerate bounded polygon. In particular, it rules out all cones of the form

```plain text
fixed rational polytope in
u=(n+1)(5/4-x),  v=(n+1)^2(2-y),
```

and, after subtracting finitely many asymptotic terms, every further finite polynomial blow-up with a nondegenerate limiting polytope.

## 6. Why rational triangular wedges also fail

Center at (1/8,13/16) and consider the simplest one-sided wedge around the stable ray:

```plain text
p ≥ 0,
q ≤ -r p,
```

with rational r>0. The boundary vector (1,-r) maps under M to

```plain text
(17-12r, 24-17r).
```

For the image to remain below the same boundary, one obtains

```plain text
r^2 ≥ 2.
```

For the wedge to contain the stable ray q=-√2 p, one needs

```plain text
r^2 ≤ 2.
```

Hence exact invariance forces

```plain text
r=√2.
```

No rational facet slope works. A two-sided rational wedge has the same obstruction: the stable projective fixed point is repelling under the forward slope map, so any interval of slopes with nonzero width is expanded away from it.

This explains why a triangular cone does not repair the rectangular one. The only asymptotically invariant linear boundary has irrational slope.

## 8. The genuinely sharp coordinates: Lorentz/eigen coordinates

For residuals p,q after an exact or all-orders stable centering, define

```plain text
ξ = q + √2 p,
η = q - √2 p.
```

The limiting dynamics diagonalizes exactly:

```plain text
ξ' = (17+12√2) ξ,
η' = (17-12√2) η.
```

The Lorentz form

```plain text
L(p,q) = q^2 - 2p^2
```

is exactly preserved by the limiting matrix:

```plain text
(24p+17q)^2 - 2(17p+12q)^2 = q^2 - 2p^2.
```

So the plausible finite replacement for a polyhedral cone is a moving quadratic cone, not a triangle. One would seek rational pbar_n,qbar_n and a rational quadratic form L_n satisfying an identity of the shape

```plain text
L_{n+1}(T_n z) = positive_factor(n,z) * L_n(z),
```

together with the appropriate one-sided sign. I did not find such a finite-n rational covariant; the existing low-degree symmetric-square/gauge searches in the repository are consistent with its absence.

For a rational polyhedral approximation to the irrational eigenline, the canonical facets are Pell facets. Define integers

```plain text
R_0=1, S_0=0,
R_{k+1}=17R_k+24S_k,
S_{k+1}=12R_k+17S_k.
```

Then

```plain text
R_k + S_k√2 = (17+12√2)^k,
R_k^2 - 2S_k^2 = 1,
R_k/S_k → √2.
```

Facets built from S_k q ± R_k p approach the required irrational boundary exponentially. But to use them one still needs an exact moving apex, or an exponentially accurate bound for the unstable coordinate ξ. Producing that bound is essentially the missing dominant-connection cancellation; it is not obtainable from a finite polynomial cone.
