## What can be certified once the triangulation is supplied

The finite Lean-checkable certificate must have the following form.

### 1. Shape variables

For each tetrahedron `i=1,...,4`, record a shape `z_i` and a permutation choice

```
z_i,
z'_i = 1/(1-z_i),
z''_i = 1-1/z_i
```

with an orientation sign

```
e_i in {+1,-1}.
```

The chart matching problem is the exact algebraic identification

```
(z_1,z_2,z_3,z_4) = permutation/sign transforms of (T,U,V,W).
```

This must be solved at a nonsingular numerical point and then proved symbolically.

### 2. Edge equations

The SnapPy gluing matrix must provide integer rows

```
G_edge * (log z, log z', log z'')^T = 2*pi*i * m
```

or equivalently multiplicative equations

```
prod_i z_i^{a_i} (z'_i)^{b_i} (z''_i)^{c_i}=1
```

for every internal edge.

A Lean proof requires these to be converted into polynomial identities after clearing denominators.

### 3. Peripheral equations

The meridian and longitude rows must be explicit integer vectors:

```
M_row, L_row in Z^(12).
```

The certificate must prove

```
prod shapes^M_row = M
prod shapes^L_row = L
```

with the exact powers stated by the P3.1 claim.

### 4. Flattenings

A flattened tetrahedron requires integers

```
(p_i,q_i)
```

satisfying the flattening compatibility equations

```
sum edge flattenings = 0
```

and peripheral flattening equations. These integers cannot be guessed from the knot type.

### 5. Rogers dilogarithm identity

The final Lean object should be a finite algebraic identity of the form

```
Σ_i e_i R(z_i;p_i,q_i) = 4*pi^2/85
```

where all branch corrections have already been converted into integer multiples of `pi^2`.

The branch data is exactly what the flattenings encode.
