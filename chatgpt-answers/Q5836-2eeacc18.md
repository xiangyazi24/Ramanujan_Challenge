# Q5836 — Official statement fidelity audit for Problem 3.1

## 1. Source wording audit

The repository source available for Problem 3.1 is the problem note rather than a formal Lean specification. The statement encoded there says:

```text
Let A_{7_2}(M,L) be the A-polynomial for the prime knot 7_2.

Let α ≈ 0.349269 be the real root of A_{7_2}(α, α^{1/2}) = 0 closest to 0.349269.
Let β ≈ 0.406813 be the real root of A_{7_2}(β, β) = 0 closest to 0.406813.
Let y = y(x) be the curve satisfying A(x, y(x)) = 0 for α ≤ x ≤ β,
positive and decreasing with y'(x) ≤ -2.

Prove:

4π²/85 = ∫_α^β (log x · dy/y - log y · dx/x).
```

The wording does not introduce a formal quantifier over all possible branches. It is an informal mathematical description of the intended branch.

The exact logical status is therefore:

* α and β are intended as distinguished algebraic roots selected by numerical isolation.
* y is intended as the distinguished positive decreasing branch joining the endpoints.
* The statement does not explicitly say “for every differentiable y”.
* Differentiability of y is implicit from the differential notation, but not separately stated.
* Endpoint values y(α), y(β) are not explicitly given in the statement.

A faithful formalization must therefore make the branch data explicit, rather than silently replacing it by arbitrary hypotheses.

## 2. Is y universally quantified?

No. The phrase “Let y=y(x) be the curve satisfying ...” is a definition/selection phrase, not a universal quantifier.

A faithful Lean interpretation is:

```lean
∃ y : ℝ → ℝ,
  IsOfficialBranch y ∧
  integral_identity y
```

or, preferably, after defining the canonical branch:

```lean
let y := officialBranch
⊢ integral_identity y
```

It is not faithful to state:

```lean
∀ y, (A72 x (y x)=0 ∧ PositiveDecreasingBranch y) → ...
```

unless one separately proves uniqueness of that branch.

## 3. Recommended exact Lean headline

The headline should not assume endpoint equations separately. They should be consequences of the branch definition.

A statement-faithful shape is:

```lean
noncomputable def A72 : ℝ → ℝ → ℝ := ...

structure OfficialBranch where
  y : ℝ → ℝ
  contDiff : ContDiff ℝ 1 y
  positive : ∀ x ∈ Set.Icc alpha beta, 0 < y x
  curve : ∀ x ∈ Set.Icc alpha beta, A72 x (y x) = 0
  decreasing : ∀ x ∈ Set.Icc alpha beta, deriv y x ≤ -2

 theorem problem31_main :
   let b := officialBranch
   ∫ x in alpha..beta,
       (Real.log x * deriv b.y x / b.y x
        - Real.log (b.y x) / x) = 4 * Real.pi^2 / 85 := by
   ...
```

The integral is the resolved version of

```
log x dy/y - log y dx/x
```

because along x:

```
dy/y = y'(x)/y(x) dx
```

and

```
dx/x = 1/x dx.
```

The integrand is therefore:

```lean
Real.log x * deriv y x / y x - Real.log (y x) / x
```

## 5. Does y' ≤ -2 select the branch?

Not by itself.

The condition

```
y > 0,
A(x,y(x))=0,
y'(x)≤-2
```

is a branch selector but not a proven uniqueness theorem.

A complete formalization needs either:

### Route A: prove uniqueness

Show the implicit curve has exactly one positive component satisfying the derivative inequality.

Dependencies:

```
A72 polynomial
 └─ implicit derivative formula
      └─ sign analysis
           └─ uniqueness of branch
```

### Route B: define the branch explicitly

Construct the branch using an implicit-function theorem and isolating intervals.

For Lean this is probably shorter.

## 7. Current false headline risk

The existing cancellation/regulator-style theorems are not the official theorem. They prove statements of the form:

```lean
assuming x,y satisfy algebraic/regulator hypotheses,
then a regulator expression equals another expression
```

They do not define:

* the official A-polynomial branch,
* α,
* β,
* the actual integral in the challenge statement.

Therefore they should be documented as intermediate lemmas, not as `MainTheorem` for Problem 3.1.

The first faithful Lean milestone is not the final π² identity. It is:

```lean
lemma officialBranch_satisfies_curve :
  ∀ x ∈ Set.Icc alpha beta,
    A72 x (officialBranch x)=0
```

together with the derivative and positivity facts. Once that object exists, the integral statement has a mathematically faithful target.
