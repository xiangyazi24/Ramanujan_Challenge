# 2. Audit item (i): local exponents and the conifold reflections

Put

```text
alpha = 17 + 12 sqrt(2),
beta  = 17 - 12 sqrt(2),
alpha beta = 1,
alpha + beta = 34.
```

These are the roots of `t^2-34t+1`.

## 2.1 Exact rank-two indicial calculation

At `t=a`, where `a` is `alpha` or `beta`, write the rank-two equation as

```text
A(t)y'' + B(t)y' + C(t)y = 0,

A(t) = t(t^2-34t+1),
B(t) = 2t^2-51t+1.
```

Using `a^2=34a-1`, one obtains

```text
A'(a) = 2(17a-1),
B(a)  =   (17a-1),
B(a)/A'(a) = 1/2.
```

The indicial equation at a simple zero of `A` is

```text
rho [ A'(a)(rho-1) + B(a) ] = 0,
```

hence

```text
rho = 0, 1/2.
```

The exponent difference is nonintegral.  Therefore the rank-two local monodromy is semisimple with eigenvalues

```text
1, -1.
```

Taking the exact symmetric square gives rank-three local eigenvalues

```text
1, -1, 1.
```

Thus the rank-three inertia-invariant space has dimension two and the middle-extension drop is one at each of `alpha,beta`.

## 2.2 Correction to Q5572

Q5572 computed the rank-three exponents

```text
0, 1/2, 1
```

and then said that they were distinct modulo the integers.  That sentence is false: `0` and `1` are congruent modulo `Z`.  The rank-three exponents alone do not exclude a Jordan block on the eigenvalue-one subspace.

The semisimplicity conclusion is nevertheless correct **over the complex numbers**, because Peters gives the exact rank-two square root and its exponents `0,1/2` are nonresonant.  The valid proof must run through the rank-two equation and then take `Sym^2`.

```text
transcendental middle extension G_p is tame and its geometric inertia
```

This should be provable by spreading out the K3 family and its algebraic cycles and using tame local-monodromy comparison, but it is not quoted or proved in Q5572.  The collision of `alpha,beta` already forces the exclusion of characteristics dividing

Hence the local-drop calculation is a source-backed complex theorem and a plausible finite-characteristic lemma, not yet an archived all-good-prime l-adic theorem.

# 4. Audit item (iii): inversion does not automatically give an alternating arithmetic self-pairing

Let `G_p` be orthogonally self-dual of weight two.  Ordinary Poincare duality gives a perfect pairing

```text
M_p(chi) x M_p(chi^-1) -> Q_l(-3),

M_p(chi) = H_c^1(G_m,G_p tensor L_chi).
```

This is an inverse-character pairing.  It is source-backed once `G_p` exists.

To turn it into a self-pairing of `M_p(chi)`, one needs an **arithmetic** isomorphism

```text
G_p ~= inv^* G_p,
inv(t)=1/t,
```

with its Frobenius normalization and adjoint scalar controlled.

## 4.1 Katz's actual hypothesis

Katz defines arithmetic self-duality of a perverse object `N` by an arithmetic isomorphism

```text
N ~= inv^* D(N),
```

not by a reciprocal differential equation; see *Convolution and Equidistribution*, Chapter 9, printed p. 49.  Katz immediately notes that the induced duality can be either orthogonal or symplectic; its sign is an additional datum.

Thus the following inference in Q5572 is invalid as written:

```text
reciprocal Picard-Fuchs operator
+ symmetric K3 pairing
+ degree-one cup product
=> arithmetic alternating self-pairing.
```

The reciprocal operator proves a de Rham/complex-local-system symmetry.  It does not identify the arithmetic l-adic sheaf over the base field, does not determine the scalar by which the square of the inversion map acts, and does not determine the Frobenius-compatible sign.

## 4.2 Theorem 15.3 shows exactly what is missing

In Katz's worked example `N=Sym^2(Leg)(3/2)[1]`, Theorem 15.3, printed pp. 74--75, Katz separately records:

```text
  Sym^2(Leg) ~= inv^* Sym^2(Leg),

the unique singularity and its drop,
```

and only then invokes Theorem 14.1.  This explicit arithmetic inversion input is not present in Q5572 for the Apéry family.


is **unsupported**.  The safe statement is only

```text
pure of weight zero,
geometrically irreducible,
arithmetically self-dual,
of Tannakian dimension two.
```

Under those hypotheses the following are equivalent:

```text
(1) N is geometrically Lie-irreducible;

(2) N is not geometrically isomorphic to any nontrivial
    multiplicative translate;

(3) N is symplectically self-dual and
    G_geom,N = G_arith,N = SL_2.
```

Thus the theorem really does conclude equality of both arithmetic and geometric groups with `SL_2`, but only **after arithmetic self-duality has been proved**.

## 6.2 No-translate calculation

Assuming the arithmetic middle-extension sheaf has exactly the two interior singularities `{alpha,beta}`, the singular-support argument is plausible and nearly complete.

A multiplicative translation by `a` preserving the unordered set must either fix both points, giving `a=1`, or swap them.  A swap gives `a^2=1`; the nontrivial possibility `a=-1` would require

```text
alpha+beta = 34 = 0.
```

Thus outside characteristic `17` and the collision characteristics `2,3`, the singular set has no nontrivial multiplicative stabilizer.  Local labels must also be preserved, but here both conifolds have the same reflection label.

Conditional on the arithmetic sheaf construction, this proves the no-translate hypothesis and hence geometric Lie-irreducibility via Katz's Corollary 8.3, printed p. 47.

Theorem 15.3, printed pp. 74--75, treats the specific object

# 7. Audit item (vi): the trace congruence and the conifold correction

There are two exact finite-field identities which should be retained, and one unsupported identification which must be removed.

## 7.1 Exact Hasse-polynomial Mellin identity

Choose an integral Apéry Laurent polynomial `Phi` satisfying

```text
b_m = CT(Phi^m).
```

Define

```text
A_p(t) = CT((1-t Phi)^(p-1)) mod p.
```

Since

```text
binom(p-1,m)(-1)^m = 1 mod p,
```

one has the exact polynomial identity

```text
A_p(t) = sum_(m=0)^(p-1) b_m t^m mod p.
```

For `1 <= r <= p-2`, multiplicative orthogonality gives

```text
-sum_(t in F_p^*) A_p(t) t^(-r) = b_r mod p.
```

This is elementary and unconditional.

## 7.2 Exact raw toric Kummer trace

Let `omega_p` be the Teichmuller character and choose the Teichmuller prime `mathfrak p_(p,r)` so that

```text
omega_p(x) = x mod mathfrak p_(p,r).
```

Set

```text
S_(p,r)
 = sum_(x in (F_p^*)^3) omega_p^r(Phi(x)),
```

extending the character by zero at zero.  Then

```text
S_(p,r)
 = Tr_alt(Frob_p |
     R Gamma_c((G_m)^3_bar, Phi^* L_(omega_p^r))).
```

Reduction at the selected prime gives

```text
S_(p,r)
 = sum_x Phi(x)^r mod mathfrak p_(p,r).
```

For `r<p-1`, the unique-interior-lattice-point property prevents a nonzero exponent of `Phi^r` from becoming trivial modulo `p-1`.  Three-variable torus orthogonality therefore gives

```text
S_(p,r) = -CT(Phi^r) = -b_r mod mathfrak p_(p,r).
```

This is the strongest rigorously identified Frobenius object lifting the residue `b_r`: a fixed-dimensional **alternating toric Kummer complex**.  Its total cohomology has not been identified with the proposed two-dimensional primitive fibre.

## 7.3 Unsupported parameter-side trace comparison

Q5572 introduced a middle-extension trace function

```text
a_p(t) = Tr(Frob_t | G_(p,t))
```

and asserted

```text
a_p(t) = A_p(t) mod mathfrak p
```

for every `t`, including the conifold stalks.  The cited sources do not establish that assertion as stated.

* Stienstra--Beukers, *On the Picard--Fuchs equation and the formal Brauer group of certain elliptic K3-surfaces*, Math. Ann. 271 (1985), 269--304, studies the formal Brauer group, crystalline congruences, and the Apéry Picard--Fuchs crystal.  Q5572 cites Theorem 13.1 but does not quote a theorem or page giving equality of a relative l-adic middle-extension trace function with `A_p(t)` at every parameter.
* Katz--Messing, *Some consequences of the Riemann hypothesis for varieties over finite fields*, Invent. Math. 23 (1974), pp. 73--77, compares Frobenius characteristic polynomials between reasonable cohomology theories for smooth proper varieties.  It does not by itself identify a one-dimensional Hasse--Witt scalar with the trace of a selected rank-three relative summand, and it does not treat singular conifold middle-extension stalks.

Even if the congruence is known on the smooth locus, the difference at the conifolds is a punctual trace function.  Its Mellin transform is not automatically zero.  If

```text
delta_a = a_p(a)-A_p(a)
```

at a rational conifold point `a`, then the proposed primitive Mellin trace differs from `b_r` by a term of the form

```text
-delta_alpha alpha^(-r)
-delta_beta  beta^(-r).
```

Constant Tate summands on `G_m` have zero Mellin transform for nontrivial `chi`, but punctual conifold summands do not.  They contribute their stalk traces multiplied by `chi(alpha)` and `chi(beta)`.

Therefore the sentence in Q5572 that “the nonprimitive Tate summands have zero Mellin fibre” does not dispose of possible conifold corrections.

## 7.4 Source verdict

The exact congruence

```text
S_(p,r) = -b_r mod mathfrak p_(p,r)
```

for the raw toric Kummer trace is proved.

The exact congruence

```text
T_(p,r) = b_r mod mathfrak p_(p,r)
```

for a two-dimensional primitive middle-extension trace is **not proved** by the cited sources.

# 9. Does the torsion or low-height-container conclusion survive?

No.  In fact the negative structural conclusion of Q5572 remains correct **even if Proposition B is eventually proved**.

Grant a rank-two, weight-three symplectic polynomial

```text
X^2-TX+p^3
```

and suppose `p|T`.  Reduction at the same residue characteristic gives

```text
X^2 mod p,
```

because the determinant also vanishes.  This is a singular residual operator, not an invertible trace-zero element of `SL_2(F_p)`.  Dividing the eigenvalues by `p^(3/2)` gives an `SL_2` class over characteristic zero, but that normalization is not integral at `p`.

The abstract polynomial

```text
X^2-pX+p^3
```

has roots of complex absolute value `p^(3/2)`, determinant `p^3`, trace divisible by `p`, and Newton slopes `1,2`.  Its normalized trace is `p^(-1/2)`, so the normalized class is not torsion.  This is an abstract Weil-polynomial/matrix counterexample to any inference using only rank, weight, determinant, self-duality, and first trace divisibility.  It is not claimed to be an actual Apéry Frobenius polynomial.

The source audit reveals an earlier missing scalar than Q5572 acknowledged:

```text
first missing scalar:
  D_(p,r), the determinant/epsilon factor of the actual primitive fibre;

next missing scalar, after D_(p,r)=p^3 is proved:
  U_(p,r)=T_(p,r)/p mod p,
  or another Frobenius-jet scalar independent of T and D.
```

Neither the raw rank-three K3 monodromy nor Katz's group theorem gives a `p`-independent low-height container for these divided traces.
