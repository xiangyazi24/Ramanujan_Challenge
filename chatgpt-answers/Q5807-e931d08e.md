# Q5807 — audit of the proposed H_m recurrence route

## Status

The requested scalar recurrence cannot be derived from the stated data alone without an additional certified Ore identity. The existing shell/ray recurrences are sufficient to put H_m in a finite-dimensional holonomic state space, but the explicit scalar coefficients and singular factors require the actual eliminated Ore operator computation.

## What follows formally

For fixed retained core and margin, each Newton carrier is a finite linear functional of the shell arrays:

```
A_m(F)=G_{D-m+1,N+m-2}(F)
B_m(F)=G_{D,N+m-2}(F)
```

The shell arrays Y,W satisfy certified finite-order recurrences in the shell variable. Newton projection is a finite binomial transform, hence the pair

```
(A_m(Y),A_m(W),B_m(Y),B_m(W))
```
belongs to the holonomic closure of the underlying module. Therefore a finite-dimensional first-order shift state exists after enlarging the state by the necessary boundary moments.

Consequently H_m is a component of a finite-rank holonomic module.

## Missing certificate

A fitted recurrence for H_m is not enough. The required certificate would be an Ore identity of the form

```
U(m,S) * H_m = 0
```

with U obtained by elimination from the certified operators for Y and W after applying the Newton transform. The leading and trailing coefficients must be factored to identify singular propagation primes.

The minimal CAS target is not a direct scalar recurrence for H_m. It is:

```
state_m = (A_m(Y), A_m(W), B_m(Y), B_m(W), boundary moments)
```

and compute the transition matrix M(m) satisfying

```
state_(m+1)=M(m) state_m.
```

Then H_m is the determinant quadratic form in this state.

## Sufficient lemma for the P3.2 goal

A sufficient statement would be:

> There exists a fixed-rank state recurrence with polynomial transition matrix M(m), and an integer polynomial D(m) of subexponential logarithmic height, such that every prime dividing all admissible H_m in a block divides D at one boundary index.

This would convert propagation of modular zeros into an O(log n)-height obstruction.

## Main obstruction

Origin cancellation only removes the universal Apéry component. It does not imply that the remaining two-dimensional shell module has small determinant content. The possible obstruction is that the exterior-square module of the two-carrier state still has a generic exponential-height solution.

Equivalently, the needed statement is not merely holonomicity but a small-height invariant line in the exterior square.

## Recommended next computation

Compute the exterior-square Ore module:

```
ExteriorSquare(Module(Y,W,Newton boundaries))
```

and search for a rational invariant vector corresponding to H_m. If it exists, extract its denominator/content and factor its singular polynomial. If no invariant line exists at bounded degree, a finite-rank obstruction follows.

The decisive test is therefore an Ore elimination in the exterior-square module, not another numerical recurrence fit.
