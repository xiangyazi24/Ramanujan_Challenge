# Incidence geometry audit for the Apéry orbit fiber problem

## Summary verdict

The incidence-geometry reformulation is mathematically natural, but the standard finite-field point-curve incidence machinery does not currently break the p^(2/3) fiber barrier. The route is therefore not completely dead, but in its direct form it is too weak: it converts the problem into a high-multiplicity incidence problem where the available exponents lose exactly the power needed.

The obstruction is not the size of the point set. The obstruction is that the curve family has about p members and degree growing with the block length L, while a large fiber requires only T=p^(1/3) incidences per curve. Existing incidence bounds do not force such a family to have few rich curves at that threshold.

## (1) Point-curve incidence calculation

Set

S = {(r, pi(r)) : 0 <= r < p-1} subset A^1 x P^1(F_p).

Thus |S| = N approximately p.

For a fixed target value v, the condition

phi_j(pi(r),r)=v

is algebraic of degree O(j). If we truncate to blocks of length L, the relevant curve family has:

- number of curves: M approximately p (one for each v, up to repetitions),

- degree: D=O(L),

- points: N approximately p.

A fiber of multiplicity T means one v-curve has at least T incidences with S.

For bounded degree curves over F_p, the Stevens-de Zeeuw/Vinh type incidence philosophy gives bounds of Szemeredi-Trotter shape only under strong non-degeneracy assumptions. In the line model the strongest available exponents are roughly

I(P,C) <= (|P||C|)^(11/15)+|P|+|C|

in the balanced regime.

Plugging |P|=|C|=p gives

I <= p^(22/15)+p.

Average incidences per curve are therefore bounded by

p^(22/15)/p = p^(7/15).

A rich-curve estimate by dyadic decomposition gives approximately

# {C : |C intersect S| >= T}

<= p^(22/15) / T.

At the desired threshold

T=p^(1/3),

this gives only

p^(22/15-1/3)=p^(17/15),

which is larger than the total number p of curves. Hence the incidence theorem gives no nontrivial saving.

The missing saving required is approximately

p^(17/15) -> p^(1-c)

for some c>0.

Equivalently, the incidence exponent would need to improve by about

17/15-1 = 2/15

at this scale. Standard point-line/point-curve incidence is not strong enough.

## (2) Degeneracy analysis of the curve family

The family has serious structured degeneracy risks.

The curves are not arbitrary algebraic curves. They arise from the same cocycle:

phi_j(x,r)=M_{r+j-1}...M_r acting Mobiusly on x.

Therefore all curves share the same dynamical origin.

Possible degeneracies:

1. Common components.

For fixed j and varying v, the equation

phi_j(x,r)=v

is essentially

A_j(r)x+B_j(r)-v(C_j(r)x+D_j(r))=0.

For fixed j these are linear in x, so geometrically they are graphs over the r-line. Two different v values do not share a component unless the Mobius denominator degenerates identically. This particular degeneration is unlikely except at singular parameter values.

1. Common bad points.

There are forced special points where the projective orbit is singular, for example poles of the Mobius chart or points corresponding to invariant directions of transfer matrices. These can create large artificial incidence counts.

1. Frobenius/characteristic collapse.

Because the coefficients are polynomials modulo p, a degree-O(L) curve can collapse when L approaches p^(1/2) or larger. The incidence theorem hypotheses become increasingly fragile in exactly the regime needed for optimizing the block argument.

Thus the family is not maximally degenerate, but it is far from a generic curve family.

## Why the geometric picture still does not close the proof

The original fiber problem is not just:

"How many points of S lie on a curve?"

It is:

"Can the deterministic orbit S repeatedly hit the same member of a cocycle-generated curve family?"

The orbit constraint is the missing ingredient. Incidence geometry treats S as an arbitrary p-point set and therefore cannot exploit the recurrence.

The needed statement is closer to:

A nontrivial Mobius cocycle orbit cannot have p^(1/3) repeated hits against one target value.

That is an orbit rigidity theorem, not a generic incidence theorem.

## Final judgment

Status: alive as a reformulation, dead as a standalone attack.

The incidence route does identify the correct geometric object: the graph of the Apéry projective orbit in A^1 x P^1. It also explains why a large fiber is an abnormal intersection phenomenon.

However, the standard Bombieri-Pila/Vinh/Stevens-de Zeeuw machinery cannot beat the current p^(2/3) zero/fiber barrier because:

1. The rich threshold is only T=p^(1/3).

1. The curve family has size p.

1. The available incidence exponents lose about p^(2/15), exactly preventing a power saving.

1. The curves have shared cocycle structure, so generic non-degeneracy assumptions are not enough.

The only plausible resurrection is to add the missing dynamical input: a theorem controlling intersections of a single Mobius orbit with its own low-degree translates. Without such an orbit-rigidity theorem, incidence geometry alone is insufficient.
