# Lean-oriented finite-calculus certificate for I10

## Verdict

The shortest certificate I recommend is not a direct antiderivative of the raw W0(t) H1(t)/t kernel. Such an antiderivative is an HPL expression and is longer than the proof obligations it removes.

The economical proof is a finite chain with one auxiliary parameter:

1. Expand W0 and evaluate three elementary logarithmic moments with explicit Li2/Li3/Li4 primitives.

1. Reduce the only mixed term

```plain text
R0 := integral_0^1 Li2(t/2) H1(t)/t dt
```

to an endpoint of a one-parameter divided-difference integral.

1. Prove a two-step differential ladder D' = F1/a, R' = D/a by differentiation under the integral. Both derivatives have uniform elementary majorants on compact a-intervals.

1. Give one explicit classical-polylog primitive G with G' = F2/a.

1. Put both R0 and K into the same auxiliary B3 normal form. The B3 term cancels, so no value of Li4(1/2) and no Euler sum is needed in the final relation.

The final dependency is:

```plain text
I10  ->  R0
R0   ->  B3 + elementary constants
K    ->  B3 + elementary constants
-----------------------------------
I10  = -K/2 -(3/2)L^2 Z2 -(13/20)Z2^2.
```

There is no double sum and no use of

```plain text
S = sum H_n/(2^n n^3)
```

in the preferred route.

# 2. First reduction: I10 to R0

The three needed primitives are

```plain text
P0(t) = Li2(t)

P1(t) = log t * Li2(t) - Li3(t)

P2(t) = log(t)^2 * Li2(t)
        - 2 log t * Li3(t)
        + 2 Li4(t).
```

On 0<t<1, direct differentiation gives

```plain text
P0'(t) = H1(t)/t,

P1'(t) = log t * H1(t)/t,

P2'(t) = log(t)^2 * H1(t)/t.
```

The cancellations in P2' are exact:

```plain text
d[log^2 t Li2(t)]
 = 2 log t Li2(t)/t + log^2 t H1(t)/t,

d[-2 log t Li3(t)]
 = -2 Li3(t)/t - 2 log t Li2(t)/t,

d[2 Li4(t)]
 = 2 Li3(t)/t.
```

Every primitive tends to 0 at 0+; at 1- one gets

```plain text
integral_0^1 H1(t)/t dt                 = Z2,
integral_0^1 log t H1(t)/t dt           = -Z3,
integral_0^1 log(t)^2 H1(t)/t dt        = 2 Z4.
```

Since, almost everywhere on (0,1),

```plain text
log(t/2) = log t - L,
```

we have

```plain text
integral_0^1 log(t/2)^2 H1(t)/t dt
 = 2 Z4 + 2 L Z3 + L^2 Z2.
```

Expanding W0 therefore gives the first master identity:

```plain text
I10
 = Z2^2 - 2 R0 - 2 Z4 - 2 L Z3 - L^2 Z2.       (I)
```

This part is particularly cheap in Lean: three HasDerivAt lemmas, three endpoint limits, integral_sub, integral_const_mul, and a final ring.

# 4. Parameter ladder with no series

For 0 <= a <= 1/2, define the continuously extended divided differences

```plain text
DKer(a,t) =
  if t=1 then -log(1-a)
  else [Li2(a)-Li2(a t)]/(1-t),

RKer(a,t) =
  if t=1 then Li2(a)
  else [Li3(a)-Li3(a t)]/(1-t),
```

and

```plain text
D(a) := integral_0^1 DKer(a,t) dt,
R(a) := integral_0^1 RKer(a,t) dt.
```

Then (R0-IBP) is exactly

```plain text
R0 = R(1/2).
```

Also D(0)=R(0)=0.

## 4.1 Derivative of R

For t != 1, differentiation in a gives

```plain text
partial_a RKer(a,t)
 = [Li2(a)-Li2(a t)]/[a(1-t)]
 = DKer(a,t)/a.
```

At t=1, both sides extend to

```plain text
-log(1-a)/a.
```

Hence

```plain text
R'(a) = D(a)/a.                                      (4.1)
```

## 4.2 Derivative of D

For t != 1,

```plain text
partial_a DKer(a,t)
 = [log(1-a t)-log(1-a)]/[a(1-t)].
```

The apparent singularity at t=1 is removable, with value 1/(1-a).

For a proof-assistant-friendly domination bound, avoid l'Hopital. The exact finite identity is

```plain text
[log(1-a t)-log(1-a)]/[a(1-t)]
 = integral_0^1
     1/[1-a(t+s(1-t))] ds.                           (4.2)
```

Thus, on any local parameter interval a <= A < 1, the derivative is bounded by the constant 1/(1-A). This is the ideal majorant for

```plain text
hasDerivAt_integral_of_dominated_loc_of_deriv_le.
```

Now set

```plain text
u := a/(1-a).
```

Changing variables s=1-t in the unscaled logarithmic integral gives

```plain text
D'(a)
 = -Li2(-u)/a.
```

Use the already available dilogarithm Landen identity

```plain text
Li2(a) + Li2(-a/(1-a))
 = -(1/2)log(1-a)^2.
```

Therefore

```plain text
D'(a)
 = [Li2(a) + (1/2)log(1-a)^2]/a.                    (4.3)
```

Define

```plain text
F1(a) := Li2(a) + (1/2)log(1-a)^2.
```

Then (4.3) is D'=F1/a.

# 5. An explicit primitive for the first ladder step

Define

```plain text
p := log a,
q := log(1-a),

F2(a) :=
    Li3(a) - Li3(1-a)
  + Li2(1-a) q
  + (1/2) p q^2
  + Z3.
```

A direct derivative audit gives

```plain text
F2'(a) = F1(a)/a.                                    (5.1)
```

Indeed:

```plain text
d[Li3(a)]                    = Li2(a)/a,
d[-Li3(1-a)]                 = Li2(1-a)/(1-a),
d[Li2(1-a) q]
 = p q/(1-a) - Li2(1-a)/(1-a),
d[(1/2)p q^2]
 = q^2/(2a) - p q/(1-a).
```

All non-1/a terms cancel. Since D(a) and F2(a) both tend to zero at a -> 0+,

```plain text
D(a)=F2(a),
R'(a)=F2(a)/a.                                       (5.2)
```

In Lean, prove equality first on [epsilon,a] by the endpoint-limit FTC, then send epsilon -> 0+. This avoids requiring differentiability at a=0.

# 6. The classical-polylog primitive G

Define

```plain text
u(a) := a/(1-a),

Neg4(u) :=
    Li4(-u)
  - Li3(-u) log(1+u)
  - (1/2)Li2(-u)^2,

E(y) :=
   -log(y)^3 log(1-y)
   -3 log(y)^2 Li2(y)
   +6 log(y) Li3(y)
   -6 Li4(y),

G(a) :=
    Z4
  + 2 Li4(a)
  + Neg4(u(a))
  + (1/2)Li2(a)^2
  + (1/6)E(1-a).
```

## 6.1 Two elementary functional identities

Use Spence:

```plain text
Li2(a)+Li2(1-a)=Z2-log a log(1-a).
```

Use the trilogarithm Landen identity

```plain text
Li3(a)+Li3(1-a)+Li3(-a/(1-a))
 = Z3 + Z2 q - (1/2)p q^2 + (1/6)q^3.                (6.1)
```

This identity need not be imported. Define the difference of the two sides, differentiate, use the dilog Landen and Spence identities, and field_simp; ring closes the derivative.

The coefficient/sign audit is:

```plain text
derivative of the left side
 = (-Z2+p q)/(1-a) - q^2/[2a(1-a)],

derivative of the right side
 = (-Z2+p q)/(1-a) - q^2/[2a(1-a)].
```

Fix the constant at a=1/2 using the standard half and -1 trilog values.

Spence and (6.1) imply the exact rewrite

```plain text
F2(a)
 = 2 Li3(a)
   + Li3(-u(a))
   - q Li2(a)
   - q^3/6.                                          (6.2)
```

## 6.2 Differentiate G

Every coefficient is now forced:

```plain text
d[2 Li4(a)]/da = 2 Li3(a)/a.
```

For Neg4, first differentiate in u:

```plain text
Neg4'(u) = Li3(-u)/[u(1+u)].                         (6.3)
```

The two mixed terms cancel because

```plain text
d Li3(-u)/du = Li2(-u)/u,
d Li2(-u)/du = -log(1+u)/u.
```

Since

```plain text
u'(a)=1/(1-a)^2,
u(a)(1+u(a))=a/(1-a)^2,
```

we get

```plain text
d[Neg4(u(a))]/da = Li3(-u(a))/a.
```

Next,

```plain text
d[(1/2)Li2(a)^2]/da = -q Li2(a)/a.
```

Finally, direct differentiation of E gives

```plain text
E'(y)=log(y)^3/(1-y),
```

hence

```plain text
d[(1/6)E(1-a)]/da = -q^3/(6a).
```

Using (6.2), all four pieces combine to

```plain text
G'(a)=F2(a)/a.                                       (6.4)
```

Moreover G(a)->0 as a->0+: Li4(a), Neg4(u(a)), and Li2(a)^2 vanish, while E(1)=-6Z4 cancels the leading +Z4.

Equations (5.2) and (6.4) therefore give

```plain text
R(a)=G(a),
R0=G(1/2).                                           (6.5)
```

This is the core certificate. It uses only real log, Li2, Li3, and Li4.

# 7. Put R0 into B3 normal form

Let

```plain text
C := Li2(1/2) = Z2/2 - L^2/2,
T := Li3(1/2) = 7Z3/8 - L Z2/2 + L^3/6.
```

At u=1,

```plain text
Neg4(1)
 = Li4(-1)-Li3(-1)L-(1/2)Li2(-1)^2
 = -7Z4/8 + 3LZ3/4 - Z2^2/8.                        (7.1)
```

Also, by definition,

```plain text
E(1/2) = -L^4 - 3L^2 C - 6L T - 6A4.                (7.2)
```

Do not substitute a value for A4. Instead relate E(1/2) to B3.

Since E'(y)=log(y)^3/(1-y), E(0)=0, and E(1)=-6Z4, the substitution y=1-u gives

```plain text
B3
 = integral_(1/2)^1 log(y)^3/(1-y) dy
 = -6Z4-E(1/2).                                      (7.3)
```

Eliminate A4 from G(1/2) using (7.2), then replace E(1/2) using (7.3). Before the final ring, the expression is

```plain text
R0
 = 2Z4 + B3/6 + Neg4(1) + C^2/2
   - L^4/3 - L^2 C - 2L T.
```

Rewriting (7.1) and the half values gives

```plain text
R0
 = B3/6
   - L^4/24
   + (1/4)L^2 Z2
   - L Z3
   + (9/8)Z4.                                        (R)
```

Coefficient audit:

```plain text

L^2Z2:  -1/4 -1/2 +1 = 1/4,
LZ3:     3/4 -7/4 = -1,
```

# 8. Put K into the same B3 normal form

Start from the known elementary integration by parts

```plain text
K
 = - integral_0^1 log x log(1+x)^2/x dx.             (8.1)
```

Use

```plain text
u=x/(1+x),
x=u/(1-u),
0<=u<=1/2,
p=log u,
q=log(1-u).
```

Then

```plain text
log x = p-q,
log(1+x)=-q,
dx/x = du/[u(1-u)].
```

A finite expansion gives

```plain text
K = -J12 + (2/3)B3 + L^4/12.                         (8.2)
```

Here are all signs and coefficients.

First set

```plain text
D3 := integral_0^(1/2) p q^2/(1-u) du,
Q3 := integral_0^(1/2) q^3/(1-u) du.
```

From

```plain text
d[p q^3] = q^3/u du - 3p q^2/(1-u) du
```

and the endpoint value p q^3=L^4 at u=1/2,

```plain text
D3=B3/3-L^4/3.
```

Also

```plain text
Q3=-L^4/4.
```

Therefore

```plain text
integral_0^1 log x log(1+x)^2/x dx
 = J12-B3+D3-Q3
 = J12-(2/3)B3-L^4/12,
```

which proves (8.2).

The repository already has the required quartic-core/half-interval lemma privately. Its exact finite consequence is

```plain text
J12=L^4/4-Z4/4.                                      (8.3)
```

For completeness, (8.3) follows from one product derivative and reflection. Put

```plain text
C21 := integral_0^(1/2)
         log(u)^2 log(1-u)/(1-u) du.
```

Then

```plain text
d[(1/2)log(u)^2 log(1-u)^2]
 = [J12 integrand] - [C21 integrand],
```

so

```plain text
C21=J12-L^4/2.
```

Reflecting the upper half of the standard quartic core

```plain text
integral_0^1 log u log(1-u)^2/u du = -Z4/2
```

gives

```plain text
-Z4/2 = J12+C21 = 2J12-L^4/2,
```

hence (8.3).

Combining (8.2) and (8.3) yields

```plain text
K = (2/3)B3 - L^4/6 + Z4/4,                           (K)
```

or equivalently

```plain text
K/4 = B3/6 - L^4/24 + Z4/16.                         (8.4)
```

This is why B3 was the right normal form.

# 12. Fallback if parameter differentiation is awkward

There is a precise single-series fallback, still with no double sum.

From (R0-IBP) and the defining Li3 series,

```plain text
[T-Li3(t/2)]/(1-t)
 = sum_{n>=1} [1/(2^n n^3)] * [(1-t^n)/(1-t)].
```

The quotient is the finite polynomial

```plain text
(1-t^n)/(1-t)=sum_{j=0}^{n-1} t^j,
```

so termwise integration gives exactly

```plain text
R0=sum_{n>=1} H_n/(2^n n^3).
```

Do not open this into a double infinite sum. Define

```plain text
S3(a)=sum H_n a^n/n^3.
```

Starting from the standard generating function

```plain text
sum H_n a^n = -log(1-a)/(1-a),
```

three ordinary antiderivative steps give

```plain text
sum H_n a^n/n   = F1(a),
sum H_n a^n/n^2 = F2(a),
sum H_n a^n/n^3 = G(a).
```

The current ordinaryHarmonicCubicMoment24 and MeasureTheory.hasSum_integral_of_summable_integral_norm code is an exact template. This fallback is likely shorter in compiled Lean if the local domination proof for the parameter integral becomes inconvenient, but the preferred mathematical certificate above is entirely finite calculus and avoids S3 altogether.

## Final recommendation

Implement the R0/B3/K cancellation route. It is shorter than constructing a raw I10 primitive, it uses only the project’s real classical-polylog APIs, and it leaves the final theorem as rational algebra. The only genuinely new analytic component is the two-step divided-difference parameter ladder; all other ingredients are already present privately or follow from explicit one-line primitives.
