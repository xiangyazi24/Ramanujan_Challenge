1. the algebraic elimination theorem: A(X,L)=0 -> H(r)=0 ∧ E(r)=0 for r = -B/A;

The missing part is therefore a real-algebra certificate, not an identity manipulation.

## H-root analysis

Write

```javascript
H(r) = (L+X^3)(1-r^2)-X*r*(L+X).
```

The quadratic form is

```javascript
(L+X^3) r^2 + X(L+X) r - (L+X^3)=0.
```

For X>0,L>0, the product of the two roots is

```javascript
r_- * r_+ = -1.
```

The discriminant is strictly positive, and because the constant term is negative there is exactly one positive and one negative root. Hence:

```javascript
r_- < 0 < r_+,
```

and the product relation gives

```javascript
r_- = -1/r_+.
```

To prove r_-<-1, it is enough to prove 0<r_+<1. Substitution in H(1) gives

```javascript
H(1) = -X(L+X) < 0,
```

while H(0)>0; therefore the positive root lies in (0,1).

Consequently the negative root satisfies

```javascript
r_-<-1.
```

This part has a direct Lean proof with quadratic_eq_zero and sign lemmas.

## Rogers argument inequalities

Assume now the negative geometric root r<-1.

Set

```javascript
a = 1 - 1/r^2
b = (1-r^2)/r
c = (1-r^2)X/r
d = (1-r^2-rX)/(1-r^2).
```

For r<-1:

```javascript
r^2>1
1-r^2<0
```

Therefore:

```javascript
0 < 1-1/r^2 < 1
```

is immediate.

For b and c, use the sign decomposition

```javascript
(1-r^2)/r = (r^2-1)/(-r).
```

Since -r>1, this proves positivity and the identity

```javascript
1-b = (1+r-r^2)/r
```

reduces the upper bound to the quadratic sign condition.

For c, the same argument gives

```javascript
0<c<X<1
```

once 0<b<1 is established.

For d, the numerator must be compared with the negative denominator. The needed inequality is equivalent to

```javascript
0 < rX+r^2-1 < r^2-1.
```

The first inequality is the nontrivial branch inequality. It should be discharged by eliminating L from H=0 and E=0, producing the official A(X,L) component and applying a Sturm certificate on the positive decreasing arc.

## Excluding the positive H-root

The positive root cannot satisfy the Rogers branch inequalities because

```javascript
r_+ ∈ (0,1).
```

Then

```javascript
1-r_+^2 > 0,
```

and

```javascript
b=(1-r_+^2)/r_+ > 0.
```

However

```javascript
a=1-1/r_+^2 < 0.
```

Thus the first Rogers argument already leaves (0,1).

The exclusion certificate is therefore the simple polynomial identity

```javascript
r>0 ∧ H(r)=0 -> r<1
-> r^2<1
-> r^2-1<0
-> 1-1/r^2<0.
```

No positive root can represent the Rogers identity.
