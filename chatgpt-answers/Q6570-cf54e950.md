# qDLS: dynamical large sieve from the exact addition law

## Executive verdict

The exact addition law is structurally important, but it does not by itself create a large-sieve recursion.

There are five conclusions.

1. The Gram matrix in the question needs one correction. For fixed t, the vectors

```plain text
v_h^(t)(r)=e_p(t delta_h(r))
```

have same-base Gram entries

```plain text
sum_r e_p(t(delta_h(r)-delta_k(r))).
```

Those are not the COINC correlations, which use two independent bases r,r'. The exact COINC Gram vectors are the centered value histograms of delta_h, or equivalently their Fourier transforms over the variable t.

1. The correctly normalized dynamical large-sieve constant must be

```plain text
Lambda(H) << p.
```

This is optimal even on the diagonal. It gives [COINC] at once. A rowwise absolute correlation bound

```plain text
max_h sum_k |E_(h,k)| << p
```

is sufficient for the full weighted large sieve. The weaker total mass bound

```plain text
sum_(h,k<=H) |E_(h,k)| << pH
```

is sufficient only for the all-ones vector, which is all [COINC] needs.

1. One van der Corput step does not shorten the transfer length. After substituting the addition law, the differenced phase contains

```plain text
delta_h(x+l)-delta_h(x),
delta_(h+1)(x+l)-delta_(h+1)(x),
```

multiplied by shifted short-block factors. The exact overlap identity

```plain text
G_h(x+l)G_l(x)=G_l(x+h)G_h(x)
```

shows that a shifted long block is a short left-right conjugation of the same long block. The long state remains. The phase class becomes quadratic and twisted; it does not return to the original class t delta_m(x). Hence there is no closed recursion for a one-parameter bound T(m).

1. The proved one-variable estimate

```plain text
|sum_x e_p(t delta_h(x))| <= (4h+1)sqrt(p)
```

does not give useful family orthogonality. Even under an optimistic reset of every translated block of length L=p^(1/6), Cauchy-only gluing gives no better than

```plain text
sum_(h<=p^(2/3)) C_h << p^(4/3)
```

from the proved individual estimate. This is just the trivial degree scale. It would give energy exponent 5/3, worse than the proved 3/2 theorem.

1. If one grants a much stronger, optimal local large sieve on every translated block of length p^(1/6), then Cauchy-only gluing has the ceiling

```plain text
sum_(h<=p^(2/3)) C_h << p^(13/12),
F_p << p^(17/12).
```

This would be a new theorem, but it still misses the desired p^(5/6) short-gap bound and the p^(4/3) energy target. Reaching those targets requires cross-block quasi-orthogonality, not merely local block control.

The single best target is therefore the fixed-difference shell variance

```plain text
[DLS-SHELL]

sum_(0<=d<H) |A_d(H)|^2 <<_eps p^(2+eps) H,

A_d(H)=sum_(1<=h<=H-d) E_(h,h+d),
```

uniformly for H<=p^(2/3), after the explicit diagonal and forced components are removed and restored as main terms. This implies [COINC] with a p^eps loss and hence

```plain text
F_p <<_eps p^(4/3+eps).
```

The genuine obstruction is precise: the addition law is a coupled bilinear identity at the same base point. It is not a convolution identity for the value distributions. The long state (delta_h,delta_(h+1)) remains inside every short-block twist, so there is still no bounded-complexity object in the clock variable h.

# 1. The correct Hilbert-space object

For

```plain text
I_h={1,...,M-h},
L_h=|I_h|=M-h,
```

define the value histogram

```plain text
rho_h(a)=#{r in I_h:delta_h(r)=a},
q_h(a)=rho_h(a)-L_h/p,
```

for a in F_p. Thus sum_a q_h(a)=0.

Define the complete Fourier coefficient

```plain text
S_h(t)=sum_(r in I_h) e_p(t delta_h(r)).
```

For t!=0, the Fourier transform of q_h is exactly S_h(t).

Define the centered pair correlation

```plain text
E_(h,k)
 =sum_(a in F_p) q_h(a)q_k(a)
 =#{(r,r') in I_h x I_k:delta_h(r)=delta_k(r')}
  -L_h L_k/p.                                      (1.1)
```

Parseval gives

```plain text
E_(h,k)
 =(1/p) sum_(t!=0) S_h(t) conjugate(S_k(t)).         (1.2)
```

If

```plain text
N=sum_(h<=H)L_h=#S_H,
```

then

```plain text
N_coinc(H)-N^2/p
 =sum_(h,k<=H)E_(h,k)
 =||sum_(h<=H)q_h||_2^2
 =(1/p)sum_(t!=0)|sum_(h<=H)S_h(t)|^2.              (1.3)
```

This is the exact COINC Hilbert-space identity.

## 1.1 Correction to the fixed-t vectors

For fixed t, put

```plain text
v_h^(t)(r)=1_(r in I_h)e_p(t delta_h(r)).
```

Then

```plain text
<v_h^(t),v_k^(t)>
 =sum_(r in I_h intersect I_k)
    e_p(t(delta_h(r)-delta_k(r))).                   (1.4)
```

This is a same-base correlation. It is not (1.1). It can be useful in a van der Corput argument, but it is not the Gram matrix whose all-ones quadratic form is N_coinc-N^2/p.

The correct column vectors are either

```plain text
q_h in C^(F_p),
```

or, after Fourier transform,

```plain text
u_h=(p^(-1/2)S_h(t))_(t!=0) in C^(p-1).
```

Their Gram matrix is exactly

```plain text
<u_h,u_k>=E_(h,k).                                   (1.5)
```

# 2. The exact large-sieve constant required

The full dynamical large sieve is the assertion that for all complex coefficients alpha_h,

```plain text
[DLS]

||sum_(h<=H) alpha_h q_h||_2^2
 <= C_eps p^(1+eps) sum_(h<=H)|alpha_h|^2.           (2.1)
```

Equivalently,

```plain text
(1/p)sum_(t!=0)|sum_h alpha_h S_h(t)|^2
 <= C_eps p^(1+eps)sum_h|alpha_h|^2.                 (2.2)
```

Thus the required Gram operator norm is

```plain text
Lambda(H)=||(E_(h,k))_(h,k<=H)||_op
          <<_eps p^(1+eps).                          (2.3)
```

For the epsilon-free [COINC] in the question, one needs Lambda(H)<<p.

Taking alpha_h=1 gives

```plain text
N_coinc(H)-N^2/p
 <= Lambda(H)H
 << pH.                                              (2.4)
```

Since N is comparable to pH, this is exactly [COINC].

## 2.1 Necessary diagonal scale

A large sieve with constant O(p) necessarily requires

```plain text
E_(h,h)=||q_h||_2^2<<p                               (2.5)
```

for every h in the range. The component census same gap = diagonal plus one irreducible component predicts this scale. The individual additive estimate does not prove it at growing h: from

```plain text
|S_h(t)|<<(h+1)sqrt(p)
```

and Parseval one obtains only

```plain text
E_(h,h)<<p h^2.                                      (2.6)
```

Thus the one-variable square-root bound does not even supply the optimal diagonal of the desired large sieve.

## 2.2 Schur and total-correlation criteria

The block-free Schur criterion

```plain text
max_h sum_(k<=H)|E_(h,k)|<<p                         (2.7)
```

implies the full weighted large sieve (2.1).

For [COINC] alone, it is enough to prove the weaker scalar estimate

```plain text
|sum_(h,k<=H)E_(h,k)|<<pH.                           (2.8)
```

The absolute mass bound

```plain text
sum_(h,k<=H)|E_(h,k)|<<pH                            (2.9)
```

is a convenient sufficient condition for (2.8), but it is stronger than necessary. It does not by itself imply the full weighted large sieve unless the mass is also distributed rowwise.

The dual large-sieve form is

```plain text
sum_(h<=H)|<w,q_h>|^2
 <<p||w||_2^2                                        (2.10)
```

for every value profile w. This is equivalent to (2.1).

# 3. What the addition law actually gives

Write the proved addition law as

```plain text
delta_(h+d)(x)
 =(x+h+1)^3(
     delta_(h+1)(x) delta_d(x+h)
    -delta_h(x) delta_(d-1)(x+h+1)).                 (3.1)
```

Define

```plain text
L_h(x)=(delta_(h+1)(x),-delta_h(x)),
R_(d,h)(x)=(delta_d(x+h),delta_(d-1)(x+h+1)),
q_h(x)=(x+h+1)^3.
```

Then

```plain text
delta_(h+d)(x)=q_h(x) L_h(x) dot R_(d,h)(x).         (3.2)
```

This is a genuine bilinear state identity.

It is not a convolution identity for the histograms rho_h. Both factors on the right are sampled at the same x; the shifted short block is deterministically coupled to the long block. There is no summation over an independent intermediate state.

This distinction is decisive. In a Dirichlet convolution, the two factors are averaged over separate divisors and Cauchy can separate them. In (3.2), Cauchy sees one variable and two perfectly correlated functions of that variable.

A general counterexample shows why marginal square-root estimates cannot control the product. On F_p^*, take

```plain text
A(x)=x,
B(x)=x^(-1).
```

Then every nontrivial additive sum of A or B is bounded, indeed each is a permutation sum, while

```plain text
A(x)B(x)=1
```

and the additive sum of the product has size p-1. A cubic prefactor can be absorbed into B. Therefore no theorem based only on separate bounds for the two shorter blocks can control the bilinear composite.

The actual Apery family has much more structure, and the component census rules out some exact degeneracies for small lengths. But a quantitative all-length independence theorem is still required.

# 4. One full van der Corput iteration

Let

```plain text
Phi_(h,d)(x)=delta_(h+d)(x).
```

On a regular interval I of length N, put

```plain text
T_(h+d)(t;I)=sum_(x in I)e_p(t Phi_(h,d)(x)).
```

For an integer shift cutoff 1<=L<=N, van der Corput gives

```plain text
|T_(h+d)(t;I)|^2
 <=(N+L)/L * (
      N
      +2 sum_(1<=l<L)(1-l/L)|C_l|),                 (4.1)

C_l=sum_(x in I intersect (I-l))
       e_p(t(Phi_(h,d)(x+l)-Phi_(h,d)(x))).
```

Boundary and pole exclusions contribute only the standard explicit endpoint terms and do not affect the structural conclusion.

Put

```plain text
q=q_h(x),       q'=q_h(x+l),
A=delta_(h+1)(x),        A'=delta_(h+1)(x+l),
C=delta_h(x),            C'=delta_h(x+l),
B=delta_d(x+h),          B'=delta_d(x+l+h),
D=delta_(d-1)(x+h+1),    D'=delta_(d-1)(x+l+h+1).
```

Then the differenced phase is exactly

```plain text
Phi(x+l)-Phi(x)
 =(q'-q)(A'B'-C'D')
  +q((A'-A)B' + A(B'-B)
      -(C'-C)D' - C(D'-D)).                          (4.2)
```

This is the full first iteration.

## 4.1 The long block does not disappear

The phase (4.2) contains

```plain text
A'-A=delta_(h+1)(x+l)-delta_(h+1)(x),
C'-C=delta_h(x+l)-delta_h(x).
```

These are still length-h quantities.

The exact overlap law for transfer matrices is

```plain text
G_h(x+l)G_l(x)=G_l(x+h)G_h(x),                       (4.3)
```

or, on the invertible regular locus,

```plain text
G_h(x+l)=G_l(x+h)G_h(x)G_l(x)^(-1).                 (4.4)
```

Thus shifting the base does not replace a length-h transfer by a shorter transfer. It conjugates the same long transfer by two short boundary transfers. A selected matrix entry after conjugation becomes a rational linear combination of all entries of G_h(x); after multiplication by the other factors in (4.2), the phase is quadratic in the long state.

The proved cohomological theorem applies to the original one-coordinate phase

```plain text
t delta_h(x).
```

It does not apply uniformly to the enlarged class

```plain text
rational short twist
 times quadratic form in entries of G_h(x).
```

## 4.2 Twist accumulation

Trying to separate a bilinear phase by finite Fourier inversion introduces kernels of the form

```plain text
e_p(-uv/(t q_h(x))).
```

The cubic factor therefore creates inverse-cubic rational twists. A second split introduces further boundary inverses and more Fourier variables. After j iterations:

```plain text
- the number of shifted state coordinates grows exponentially;
- the degree in the long-state coordinates grows;
- the pole set contains the internal block boundaries;
- the phase is no longer in the class covered by the original bound.
```

The recursion is not closed.

## 4.3 No valid one-variable recurrence T(n)

Let

```plain text
T(n)=max_(t!=0)|sum_x e_p(t delta_n(x))|.
```

There is no inequality of the shape

```plain text
T(h+d) <= function(T(h),T(d),p)
```

obtained from (3.1) alone. The counterexample A(x)B(x)=1 shows that even perfect marginal cancellation of the two blocks does not bound the bilinear phase.

The unconditional result of one van der Corput step, using only |C_l|<=N, is again the trivial bound

```plain text
T(h+d)<=N<=p.
```

Applying a Weil bound to (4.2) does not produce a length reduction: its conductor still contains the long block and the new twists. Repetition increases the phase complexity faster than it decreases any endpoint length.

Therefore the plain iteration fails at the first analytic step. Algebraically, h+d has been split. Analytically, the one-variable coupling has not.

# 5. What the proved cohomological estimate can actually deliver

The proved estimate is

```plain text
|S_h(t)|<=(4h+1)sqrt(p)                              (5.1)
```

for every nonzero t, up to the explicit regular-window completion terms.

Summing absolutely over h<=H gives

```plain text
|sum_(h<=H)S_h(t)|<<H^2sqrt(p).                      (5.2)
```

Inserted into additive orthogonality, this gives only

```plain text
sum_(h<=H)C_h
 <<H+H^2sqrt(p),                                     (5.3)
```

which is weaker than the elementary degree bound

```plain text
sum_(h<=H)C_h<<H^2.                                  (5.4)
```

Thus the proved one-variable estimate by itself gives no family gain.

## 5.1 Block reset using only the proved individual estimate

Suppose, optimistically, that the addition law allowed every translated block of L consecutive lengths to be reset to a fresh short family without increasing the twist complexity. This reset is not proved.

Inside one block, (5.1) gives

```plain text
|block Fourier sum|<<L^2sqrt(p).                     (5.5)
```

There are B=H/L blocks. Triangle inequality, or the equivalent Cauchy calculation with no cross-block orthogonality, gives

```plain text
family error <<B L^2sqrt(p)=H L sqrt(p).             (5.6)
```

At

```plain text
H=p^(2/3),
L=p^(1/6),
```

this is

```plain text
H L sqrt(p)=p^(4/3).                                 (5.7)
```

The elementary degree bound is also p^(4/3). Hence this hybrid gives no improvement in the short-gap count.

The direct energy block inequality then gives at best

```plain text
F_p
 <<(p/H)(p+p^(4/3))
 <<p^(5/3),                                          (5.8)
```

which is worse than the proved p^(3/2) theorem.

This is the exact output from the stated cohomological input plus Cauchy-only gluing.

# 6. The optimistic local-large-sieve ceiling

There is a stronger idealization worth recording because it quantifies exactly what block gluing can and cannot do.

Assume that every translated block J of L consecutive lengths satisfies the optimal local large sieve

```plain text
||sum_(h in J)alpha_h q_h||_2^2
 <=C p sum_(h in J)|alpha_h|^2.                      (6.1)
```

This is not a consequence of (5.1). It requires local pair-correlation control. For a fresh family of lengths at most L, pairwise Weil plus uniform component control reaches the correct total scale only around L<=p^(1/6), which explains the proposed block length.

Partition {1,...,H} into B=ceil(H/L) blocks and put

```plain text
V_j=sum_(h in J_j)q_h.
```

Then (6.1) gives

```plain text
||V_j||_2^2<<pL.
```

With no cross-block information, Cauchy gives

```plain text
||sum_j V_j||_2^2
 <=B sum_j||V_j||_2^2
 <<(H/L)(pH)
 =pH^2/L.                                           (6.2)
```

Therefore

```plain text
N_coinc(H)-N^2/p<<pH^2/L.                            (6.3)
```

Using (D2)-(D3),

```plain text
sum_(h<=H)C_h
 <<H+sqrt(p)H/sqrt(L).                               (6.4)
```

For

```plain text
H=p^(2/3),
L=p^(1/6),
```

this becomes

```plain text
sum_(h<=H)C_h<<p^(13/12).                            (6.5)
```

The desired [COINC] consequence is p^(5/6), so Cauchy-only gluing misses by

```plain text
p^(1/4).                                             (6.6)
```

The direct energy consequence is

```plain text
F_p
 <<(p/H)(p+p^(13/12))
 <<p^(17/12).                                        (6.7)
```

This is below p^(3/2) and would therefore be a new theorem. It is still weaker than p^(4/3) by a factor p^(1/12).

More generally, with L=p^alpha, the Cauchy-gluing ceiling at H=p^(2/3) is

```plain text
sum C_h << p^(7/6-alpha/2),
F_p       << p^(3/2-alpha/2).                        (6.8)
```

To reach sum C_h<<p^(5/6), one needs alpha>=2/3: the local block must already span the full target range. Equivalently, one must prove cross-block orthogonality. No arrangement of a binary Cauchy tree improves the factor sqrt(H/L); it merely redistributes the same loss over the levels.

# 7. The correct dynamical large-sieve targets

## 7.1 Full weighted DLS

The strongest clean statement is (2.1):

```plain text
[DLS]

(1/p)sum_(t!=0)|sum_(h<=H)alpha_hS_h(t)|^2
 <<_eps p^(1+eps)sum_h|alpha_h|^2,
```

uniformly for H<=p^(2/3).

Taking all alpha_h=1 gives [COINC] with p^eps loss and hence

```plain text
sum_(h<=p^(2/3))C_h<<_eps p^(5/6+eps),
F_p<<_eps p^(4/3+eps).                               (7.1)
```

## 7.2 Minimal fixed-difference shell theorem

The full weighted inequality is stronger than required. Define

```plain text
A_d(H)=sum_(h=1)^(H-d)E_(h,h+d),
0<=d<H.                                              (7.2)
```

Since E_(h,k)=E_(k,h),

```plain text
N_coinc(H)-N^2/p
 =A_0(H)+2sum_(d=1)^(H-1)A_d(H).                    (7.3)
```

The minimal large-sieve-shaped theorem is

```plain text
[DLS-SHELL]

sum_(d=0)^(H-1)|A_d(H)|^2
 <<_eps p^(2+eps)H.                                  (7.4)
```

Cauchy in d gives

```plain text
|N_coinc(H)-N^2/p|
 <<_eps p^(1+eps)H.                                  (7.5)
```

Thus (7.4) is enough for (7.1). It is weaker than the full weighted DLS and is aligned exactly with the new addition law, because d is the short relative transfer length.

This is the single statement I would attack first.

# 8. A TT* form of the shell theorem

From (1.2),

```plain text
A_d(H)
 =(1/p)sum_(t!=0)R_d(t),                             (8.1)

R_d(t)
 =sum_(h=1)^(H-d)S_h(t)conjugate(S_(h+d)(t)).        (8.2)
```

Cauchy in t shows that (7.4) follows from

```plain text
[DLS-TT*]

sum_(d<H)sum_(t!=0)|R_d(t)|^2
 <<_eps p^(3+eps)H.                                  (8.3)
```

Expanding (8.3) counts solutions of

```plain text
delta_h(r)-delta_(h+d)(s)
 =delta_k(r')-delta_(k+d)(s')                        (8.4)
```

with h,k<=H-d and four independent base points. The addition law can be inserted into both long terms delta_(h+d) and delta_(k+d).

After this insertion, the short relative length d is isolated, but the long states

```plain text
(delta_h(s),delta_(h+1)(s)),
(delta_k(s'),delta_(k+1)(s'))
```

remain. Thus the TT* variety is fixed-dimensional in the base variables but still indexed by two discrete clock lengths h,k. The clock has not become algebraic.

# 9. Proof skeleton for DLS-SHELL

The following is the strongest viable skeleton.

## Step 1: exact centering and window completion

Retain the actual nonwrapping weights 1_(r in I_h). If complete sums are preferred, expand these interval weights in additive Fourier series. Their L1 Fourier norm contributes only logarithmic factors, absorbed into p^eps. The main term L_hL_k/p must be removed before every geometric estimate.

## Step 2: group by the relative length d

Use (7.2)-(7.3). This prevents triangle summation over all unrelated pairs (h,k) and places the exact addition law in its natural coordinate.

## Step 3: lift to the two-coordinate long state

Put

```plain text
Z_h(x)=(delta_h(x),delta_(h+1)(x)).                  (9.1)
```

The addition law expresses delta_(h+d)(x) as one rational bilinear functional of

```plain text
Z_h(x)
```

and the length-d shifted short state. Therefore every shell phase is a bilinear trace function in a long state and a short relative transfer.

## Step 4: remove geometric main terms

The component census supplies the expected list:

```plain text
- same-gap diagonal;
- the one same-gap irreducible component;
- no distinct-gap rational component;
- no mirror component in the difference curve;
- pairwise coprime critical-value resultants in the tested range.
```

For a proof, these statements are needed uniformly in all lengths in the range. They would classify constant sheaf summands and common geometric quotients. The finite census through 8 is evidence, not the required uniform theorem.

## Step 5: prove clock-state decoupling

The genuinely new lemma is:

```plain text
[CLOCK-MIX]

After the components in Step 4 are removed, the bilinear trace objects formed
from Z_h(x) and the shifted length-d state have a square-mean bound, jointly in
h and d, whose total Betti/conductor contribution is O(p^eps) on average up to
H=p^(2/3).
```

A concrete sufficient form is exactly (8.3).

## Step 6: standard finish

After [CLOCK-MIX], the remaining steps are standard:

```plain text
- Grothendieck-Lefschetz trace formula;
- Deligne square-root bounds for nonconstant components;
- Fourier completion of the moving windows;
- TT* in t;
- Cauchy in d;
- (D2)-(D4) and the direct block-energy inequality.
```

The addition law contributes to Steps 2-4. It does not prove Step 5.

# 10. The genuine obstruction

The obstruction can be stated in one sentence:

```plain text
The addition law isolates a short relative transfer, but its coefficients are
the long state Z_h(x), and Z_h(x) is not a bounded-degree algebraic function of
the clock h.
```

There are two standard algebraizations, and both grow with the clock:

```plain text
1. Eliminate the intermediate transfer states: degree and conductor grow with h.
2. Keep the intermediate states: the path variety and its Betti complexity grow
   with h.
```

The overlap identity (4.3) confirms that base differencing only conjugates the same long state by short boundary transfers. It does not erase it.

Therefore the new addition law is not yet a dynamical large sieve. It supplies the correct state-space factorization and the correct shell variable. The missing theorem is a quantitative mixing statement for the long state against all shifted short relative transfers.

If no bounded-complexity clock-state transform exists, [DLS-SHELL] is a genuinely new large-sieve theorem for a polynomial difference connection, not an application of an existing l-adic large sieve.

---

# 11. Final verdict

The plain van der Corput iteration fails. It does not reduce the effective transfer length, and the twist class is not closed.

The proved cohomological estimate plus Cauchy-only block gluing gives no improvement:

```plain text
sum_(h<=p^(2/3))C_h<<p^(4/3),
F_p<<p^(5/3).
```

Even the optimistic optimal-local-sieve version with block length p^(1/6) has the ceiling

```plain text
sum C_h<<p^(13/12),
F_p<<p^(17/12).
```

Thus local control alone cannot reach [COINC].

The most promising route is the fixed-difference shell variance [DLS-SHELL], proved through the TT target [DLS-TT]. The addition law is exactly the right algebraic input for organizing this shell. The one nonstandard step is [CLOCK-MIX], a uniform joint-state mixing theorem in the discrete clock variable.

If [CLOCK-MIX] dies, the reason is not the cubic prefactor by itself, nor a missing application of Cauchy. The reason is that the two blocks are sampled at one deterministically coupled base point, so the algebraic self-convolution does not become analytic convolution or quasi-orthogonality.
