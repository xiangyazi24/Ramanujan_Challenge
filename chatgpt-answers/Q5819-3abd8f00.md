# R2B analytic bridge audit

## 1. Source audit and verdict

The official statement in `problems/3.1/notes.md` defines the target as the branch integral
\[
I=\int_\alpha^\beta(\log x\,dy/y-\log y\,dx/x)=4\pi^2/85,
\]
where `y(x)` is required to satisfy `A(x,y(x))=0`, positivity, monotone decrease, and `y'<=-2`. The current submission follows this setup but its regulator reduction relies on named external formulas rather than proving the bridge internally.

The four-shape chart in `solution.tex` is not a rational parametrization of the A-polynomial curve. It is a coordinate map from the deformation variables `(M,L)` (or auxiliary `u,X`) to tetrahedron shapes `(T,U,V,W)`. It does not solve the implicit equation `A(M,L)=0`, nor does it provide a global parameter `t` with rational `M(t),L(t)`.

Therefore the shortest formal route should avoid proving existence/uniqueness of the analytic branch from scratch and instead prove a universal regulator identity for any branch satisfying the official hypotheses.

## 2. Desired universal theorem

The Lean headline should be a theorem of the following mathematical form:

```
For any continuous C^1 branch y : [alpha,beta] -> R satisfying
  A(x,y x)=0,
  y x > 0,
  y' x <= -2,
  endpoint conditions y alpha = sqrt(alpha), y beta = beta,
and for the four explicit shape functions produced from (x,y x),
if the differential regulator identity holds,
then
  integral (log x * dlog(y) - log y * dlog(x))
    = regulator(endpoint alpha)-regulator(endpoint beta).
```

The theorem should not quantify over an abstract unspecified curve without connecting it to the concrete A-polynomial data. It also should not hide the conclusion inside an existential witness.

## 3. Required differential identity

The first essential identity is the Neumann--Zagier type differential certificate:

\[
d\mathcal R(z_T,z_U,z_V,z_W)
=-(\log M\,d\log L-\log L\,d\log M).
\]

Equivalently along the actual path:

\[
\frac{d}{dt}\mathcal R(t)
=-(\log x(t)\frac{d}{dt}\log y(t)
-\log y(t)\frac{d}{dt}\log x(t)).
\]

After this identity is established, the integral is a fundamental theorem of calculus problem.

This is the first machine-checkable milestone: define the four shapes and prove the pullback differential identity symbolically.

## 5. Feasible routes ranked

### Route A: Direct analytic certificate (recommended)

Prove the differential identity directly from the explicit shape formulas. This avoids formalizing Suslin, Zickert, or Merkurjev--Suslin. It reduces the problem to algebraic identities plus standard real analysis.

Difficulty: high but bounded.

### Route B: Full extended Bloch group route

Formalize the Bloch group, extended Bloch group, flattenings, regulator, and torsion arguments.

Difficulty: extreme. Not appropriate for the first Lean completion target.

### Route C: Import Khoi/Neumann-Zagier as axioms

Rejected. This does not produce a faithful unconditional formalization.

## 6. Branch existence and uniqueness

Existence and uniqueness of the particular numerical branch can be avoided at the first layer. The theorem should be universal over a branch satisfying the official analytic conditions.

However, the final challenge theorem must eventually instantiate that branch. A universal theorem alone is not the final result.

Required eventual facts:

- existence of a branch on `[alpha,beta]`;
- continuity and differentiability;
- positivity of x and y;
- no crossing of logarithm branch cuts;
- nonvanishing of all denominators in the shape formulas;
- integrability of the pulled-back one-form.

## 7. Misleading current documentation

The following claims should be treated carefully:

1. "Reduction to a regulator difference" is not currently a proved reduction; it depends on external theorems.

2. The deformation chart is described as if it parameterizes the deformation. It only maps deformation coordinates to shapes.

3. Numerical endpoint shape checks do not establish the global path identity.

4. A regulator evaluation cannot replace the missing bridge from the A-polynomial integral to the regulator.

## 8. Recommended first formal milestone

Do not begin with Bloch groups. First formalize:

```
Given explicit shape formulas T,U,V,W,
prove the symbolic identity
pullback(d Regulator)
 = -(log M dlog L - log L dlog M).
```

A successful proof of this identity creates the correct bridge. All later endpoint arithmetic and regulator evaluation can then be attached without changing the theorem architecture.
