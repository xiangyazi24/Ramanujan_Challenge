# qSPEC: the true spectral mechanism for the Delta-family Gram matrix

Audited against xiangyazi24/Ramanujan_Challenge main commit e2f2e26beaa0a084b171dc47f695c68c474857f1 (Add Q6590 answer), including problems/3.2/DOCTRINE_SIGMA_STRIKE.md.

## Executive verdict

The corrected spectral route is mathematically coherent, and the random-model arithmetic in the question is correct. There are, however, three important corrections.

1. The natural random model is a thin Wishart/sample-covariance matrix, not literally an iid matrix after the Gram product is formed. It gives the same off-diagonal operator scale:

```plain text
entry size of O          ~ p^(3/2),
Schur row sum            ~ H p^(3/2),
operator norm of O       ~ sqrt(H) p^(3/2),
H = p^(2/3)              => ||O|| ~ p^(11/6) << p^2.
```

Thus Schur loses exactly p^(1/6) at the target scale, while the true spectral norm has exactly p^(1/6) of room.

1. Under the stated same-gap census normalization

```plain text
J_hh = n_h^2/p + p + lower-order terms,
```

the diagonal is

```plain text
D_hh = p J_hh - n_h^2 = p^2 + lower-order terms,
```

not 2p^2. In component language, if there are c_h rational main components, then the leading coefficient of D_hh/p^2 is c_h-1, not c_h. There is an explicit exceptional row at h=1: for p = 1 mod 3, it has leading size 2p^2 because the cube map has three rational branches. This row should be peeled off or simply absorbed into the absolute diagonal constant.

1. The proposed fourth-moment target

```plain text
Tr((O O*)^2) << H^2 p^6
```

is not the random-matrix scale. A random matrix with off-diagonal variance p^3 has

```plain text
Tr(O^4) ~ H^3 p^6.
```

The extra factor H is unavoidable: there are H eigenvalues, each typically of fourth power H^2 p^6. The corrected target

```plain text
[TR4-RMT]  Tr(O^4) << H^3 p^6
```

still gives

```plain text
||O|| <= H^(3/4) p^(3/2) <= p^2
```

when H <= p^(2/3). It is therefore exactly sufficient for COINC, but it uses all of the available p^(1/6) margin. The sixth moment is the first natural-scale moment that gives a genuine power saving over p^2.

The sharp logical endpoint is the one-vector estimate

```plain text
[ONES-GRAM]  1^T Gamma 1 << p^2 H.
```

The clean operator endpoint is

```plain text
[GRAM-OP]  ||Gamma||_op << p^2.
```

The clean decomposed endpoint is

```plain text
[DIAG-SUM]  sum_{h<=H} D_hh << p^2 H,
[OP-OFF-0]  ||O||_op << p^2.
```

No small constant is required in [OP-OFF-0]; any absolute constant gives COINC with an absolute K. A bound ||O||_op << p^(2-delta) is stronger than necessary and makes the off-diagonal contribution to K tend to zero.

## 1. Exact setup and exact identities

For 1 <= h <= H, put

```plain text
I_h = {1,...,M-h},
n_h = #I_h = M-h = p-2-h,
N   = sum_{h<=H} n_h
    = H(p-2) - H(H+1)/2.
```

Write

```plain text
Delta_h(r) = Delta_{r,h},
S_h(t)     = sum_{r in I_h} e_p(t Delta_h(r)),
nu_h(a)    = #{r in I_h : Delta_h(r)=a},
x_h(a)     = nu_h(a) - n_h/p.
```

Also define the cross-gap coincidence count

```plain text
J_hk = #{(r,r') in I_h x I_k : Delta_h(r)=Delta_k(r')}.
```

Then

```plain text
J_hk = sum_{a in F_p} nu_h(a) nu_k(a).
```

Finally,

```plain text
Gamma_hk = sum_{t != 0} S_h(t) conj(S_k(t)).
```

### 1.1 Audit of D1

D1 is correct on the regular nonwrapping window.

The initial determinant is

```plain text
Delta_{r,0} = 0,
Delta_{r,1} = -W_{r+1} = 1/(r+1)^3.
```

Taking the determinant of the Apery recurrence against the fixed vector v_r gives

```plain text
(r+h+1)^3 Delta_{r,h+1}
  = P(r+h) Delta_{r,h} - (r+h)^3 Delta_{r,h-1}.
```

Set

```plain text
Z_h(r) = Delta_{r,h} prod_{j=1}^h (r+j)^3.
```

Then

```plain text
Z_0 = 0,
Z_1 = 1,
Z_{h+1} = P(r+h) Z_h - (r+h)^6 Z_{h-1}.
```

This is exactly the defining recurrence for N_h(r). Hence

```plain text
[D1]
Delta_{r,h} = N_h(r) / prod_{j=1}^h (r+j)^3.
```

All denominators are nonzero because r+h <= p-2.

### 1.2 Exact Gram identity

Additive orthogonality gives

```plain text
sum_{t != 0} e_p(t(a-b)) = p 1[a=b] - 1.
```

Therefore

```plain text
Gamma_hk
  = p J_hk - n_h n_k
  = p sum_{a in F_p} x_h(a) x_k(a).
```

This identity has several immediate consequences.

First, Gamma is real symmetric and positive semidefinite. If X is the H x p matrix

```plain text
X_{h,a} = x_h(a),
```

then

```plain text
Gamma = p X X^T.
```

Second, if A is the H x (p-1) trace matrix

```plain text
A_{h,t} = S_h(t),  t != 0,
```

then

```plain text
Gamma = A A*.
```

Thus [GRAM-OP] is equivalently the singular-value estimate

```plain text
||A||_op << p.
```

Third, [GRAM-OP] is a finite-field large-sieve inequality. It is equivalent to

```plain text
sum_{a in F_p} |sum_{h<=H} alpha_h x_h(a)|^2
  << p sum_{h<=H} |alpha_h|^2
```

for all coefficient vectors alpha. By duality it is also equivalent to

```plain text
sum_{h<=H} |sum_{a in F_p} x_h(a) g(a)|^2
  << p sum_{a in F_p} |g(a)|^2.
```

This is the right deterministic operator formulation: the centered value distributions must form an almost-orthogonal family in l^2(F_p).

### 1.3 Exact relation to COINC

Let

```plain text
B_t(H) = sum_{h<=H} S_h(t).
```

Then

```plain text
1^T Gamma 1
  = sum_{t != 0} |B_t(H)|^2
  = p N_coinc(H) - N^2.
```

Consequently COINC is exactly equivalent to

```plain text
1^T Gamma 1 <= K p N.
```

Since

```plain text
N = pH - H^2/2 - 5H/2,
```

we have, uniformly for H=o(p),

```plain text
pH/N = 1 + O(H/p + 1/p).
```

Therefore [GRAM-OP] gives

```plain text
1^T Gamma 1
  <= ||Gamma||_op ||1||_2^2
  <= C p^2 H
  = (C+o(1)) p N.
```

So [GRAM-OP] implies COINC with

```plain text
K = C pH/N = C+o(1).
```

The actual weakest statement needed here is only the Rayleigh quotient in the all-ones direction:

```plain text
[ONES-GRAM]
1^T Gamma 1 << p^2 H.
```

The full operator norm is stronger, but it is structurally cleaner and is exactly what random-matrix behavior predicts.

### 1.4 Audit of D2, D3, and D4

D2 and D3 are exact:

```plain text
sum_{h<=H} C_h
  = N/p + (1/p) sum_{t != 0} B_t(H),

sum_{t != 0} |B_t(H)|^2
  = p N_coinc(H) - N^2.
```

Under COINC, Cauchy-Schwarz gives the precise bound

```plain text
sum_{h<=H} C_h
  <= N/p + sqrt(((p-1)/p) K N).
```

For H=o(p), this is

```plain text
sum_{h<=H} C_h << H + sqrt(K p H).
```

At H=p^(2/3), this is O(p^(5/6)), exactly as claimed. Thus the D1-D5 chain is arithmetically sound once COINC is supplied.

## 2. Exact diagonal/off-diagonal decomposition

Set

```plain text
D = diag(Gamma_11,...,Gamma_HH),
O = Gamma-D.
```

Then O is real symmetric with zero diagonal, and

```plain text
||Gamma||_op <= max_h D_hh + ||O||_op.
```

For the all-ones vector one can use the weaker average diagonal estimate:

```plain text
1^T Gamma 1
  = sum_h D_hh + 1^T O 1
  <= sum_h D_hh + H ||O||_op.
```

Hence the following pair is sufficient:

```plain text
[DIAG-SUM]
sum_{h<=H} D_hh <= C_D p^2 H,

[OP-OFF-0]
||O||_op <= C_O p^2.
```

Indeed,

```plain text
1^T Gamma 1 <= (C_D+C_O) p^2 H,
K <= (C_D+C_O) pH/N = C_D+C_O+o(1).
```

There is no need for C_O to be small. A small constant is relevant only if one wants a sharp numerical value of K, not for the theorem K=O(1).

The power-saving version

```plain text
[OP-OFF-delta]
||O||_op <= C p^(2-delta)
```

contributes only

```plain text
H ||O||_op /(pN) << p^(-delta)
```

to K. Thus any delta>0 makes the off-diagonal part asymptotically negligible, but no positive delta is logically required.

An even weaker scalar hypothesis is

```plain text
[ONES-OFF]
1^T O 1 <= C p^2 H.
```

Together with [DIAG-SUM], it is exactly enough. Numerics should measure the overlap of the top eigenvector of O or Gamma with the all-ones vector, because this reveals how much stronger the full operator target is than the actual COINC direction.

### 2.1 Exact diagonal formula and the component constant

The diagonal is

```plain text
D_hh
  = sum_{t != 0} |S_h(t)|^2
  = p J_hh - n_h^2
  = p sum_a x_h(a)^2.
```

Suppose the same-gap component census is normalized as

```plain text
J_hh = n_h^2/p + (c_h-1)p + R_h.
```

Then the exact identity is

```plain text
D_hh = (c_h-1)p^2 + p R_h.
```

Thus the stated census c(h,h)=2, together with

```plain text
J_hh = n_h^2/p + p + lower-order terms,
```

gives

```plain text
D_hh = p^2 + lower-order terms,
```

not 2p^2.

Equivalently, if one writes a Lang-Weil form

```plain text
J_hh = c_h p + E_h,
```

then, since n_h=p-(h+2),

```plain text
D_hh
  = (c_h-1)p^2
    + 2p(h+2) - (h+2)^2
    + p E_h.
```

Again the uniform-background component is canceled by -n_h^2; only the excess number c_h-1 survives at order p^2.

### 2.2 The explicit h=1 row

The first row is special and should be checked separately in every implementation. Here

```plain text
Delta_{r,1} = (r+1)^(-3),
r=1,...,p-3.
```

Let x=r+1, so x ranges over F_p^* with 1 and -1 deleted.

If p = 2 mod 3, cubing is bijective on F_p^*. Therefore

```plain text
J_11 = p-3,
D_11 = p(p-3) - (p-3)^2 = 3p-9.
```

If p = 1 mod 3, every full cube fiber has size three. Deleting 1 and -1 reduces two distinct fibers from size three to size two, so

```plain text
J_11 = 3(p-1) - 2(9-4) = 3p-13,
D_11 = p(3p-13) - (p-3)^2
     = 2p^2 - 7p - 9.
```

Thus

```plain text
D_11/p^2 -> 0  if p=2 mod 3,
D_11/p^2 -> 2  if p=1 mod 3.
```

This does not harm [GRAM-OP]; it only means the absolute diagonal constant must be at least two on the split subsequence. It also shows why one must distinguish geometric components from F_p-rational components.

### 2.3 What the existing census does and does not prove

For each fixed h, a component census plus Weil gives the expected leading diagonal constant. It does not automatically give

```plain text
max_{h<=p^(2/3)} D_hh << p^2
```

or even [DIAG-SUM], because the degree, genus, and conductor of the same-gap equality curve grow with h. The error constant in a fixed-curve Weil bound is not uniform in this growing family.

This is not a cosmetic issue. Since Gamma is positive semidefinite,

```plain text
D_hh = e_h^T Gamma e_h <= ||Gamma||_op.
```

Therefore any proof of [GRAM-OP] automatically contains a uniform diagonal theorem. Numerically, the diagonal must be tested before investing in the off-diagonal moment program.

## 3. Verification of the random-matrix arithmetic

### 3.1 Schur versus spectral norm

Assume the off-diagonal entries have typical magnitude

```plain text
|O_hk| ~ p^(3/2).
```

At H=p^(2/3), a rowwise absolute-value bound gives

```plain text
sum_k |O_hk|
  ~ H p^(3/2)
  = p^(2/3+3/2)
  = p^(13/6)
  = p^2 p^(1/6).
```

Thus Schur fails by the factor p^(1/6) even in the null random model.

For an H x H mean-zero Wigner matrix with off-diagonal variance sigma^2, the standard edge law is

```plain text
||W||_op = (2+o(1)) sigma sqrt(H)
```

under the usual finite-moment hypotheses. The same leading constant describes the largest singular value of a square iid matrix after the corresponding normalization.

Taking

```plain text
sigma = p^(3/2)
```

gives

```plain text
||O||_op
  ~ 2 p^(3/2) sqrt(H)
  = 2 p^(3/2+1/3)
  = 2 p^(11/6)
  = 2 p^2 p^(-1/6).
```

So the arithmetic in parts (a) and (b) of the question is exactly correct.

### 3.2 The more faithful Wishart model

The matrix before taking the Gram product is

```plain text
A_{h,t} = S_h(t).
```

The natural Gaussian surrogate is

```plain text
A = sqrt(p) G,
```

where G is an H x n random matrix with iid variance-one entries and n=p-1. Then

```plain text
Gamma = A A* = p G G*.
```

The sample-covariance edge is

```plain text
lambda_max(G G*) = (sqrt(n)+sqrt(H))^2 (1+o(1)).
```

Consequently

```plain text
lambda_max(Gamma)
  = p(n+H+2sqrt(nH))(1+o(1))
  = p^2 + 2p^(3/2)sqrt(H) + pH + lower-order terms.
```

After subtracting the diagonal, the leading fluctuating operator scale is

```plain text
||O||_op ~ 2p^(3/2)sqrt(H),
```

because the diagonal fluctuations are only about

```plain text
p^(3/2) sqrt(log H),
```

and H=o(p).

This Wishart calculation is the correct conceptual verification. The entries of O are not literally independent, because different entries share rows of A. Nevertheless the thin-Wishart edge reproduces the Wigner exponent and the p^(1/6) margin.

For the actual exponential sums there are further deterministic relations, notably

```plain text
S_h(-t) = conj(S_h(t)).
```

Therefore the random model is an exponent-and-scale benchmark, not a proof and not a claim about an exact constant two for the Apery family.

## 4. What deterministic structures can prove an operator bound?

There are four realistic deterministic formulations.

### 4.1 A direct large-sieve theorem

Prove directly that the centered histograms satisfy

```plain text
sum_a |sum_h alpha_h x_h(a)|^2
  << p sum_h |alpha_h|^2.
```

This is exactly [GRAM-OP]. It is the cleanest theorem statement and avoids entrywise bounds entirely. Geometrically it asks for almost orthogonality of the growing family of value distributions.

### 4.2 A high even-moment theorem

Since O is real symmetric,

```plain text
||O||_op^(2q) <= Tr(O^(2q)).
```

The trace is a closed 2q-cycle sum over gap labels. This is the most concrete bridge from the existing coincidence machinery to a spectral theorem.

### 4.3 Structured-exception plus regular-family decomposition

If some pairs (h,k) have an extra algebraic component or an exact alias, then Gamma_hk can be of order p^2, not p^(3/2). Such pairs cannot be hidden inside a random-entry model. One must write

```plain text
O = O_struct + O_reg
```

and prove one of the following:

```plain text
O_struct has bounded rank,
O_struct is supported on a bounded-degree graph,
||O_struct||_op << p^2,
```

while treating O_reg by moments or a large-sieve estimate. The component census is useful here because it identifies the pairs that must be removed before any random-scale statement can be true.

### 4.4 Nonbacktracking or Chebyshev moments

Ordinary low moments are dominated by immediate backtracking walks. A nonbacktracking trace polynomial can cancel these universal Catalan terms and recover a sharper norm from fewer geometric inputs. This is a possible refinement if the ordinary sixth moment is inaccessible, but it requires a new combinatorial identity. The ordinary fourth trace itself cannot have size H^2p^6 in a random model.

Entrywise Schur and the Frobenius norm are not viable. At random scale,

```plain text
Tr(O^2) ~ H^2 p^3,
||O||_F ~ H p^(3/2) = p^(13/6),
```

which is exactly the same p^(1/6) loss as Schur.

## 5. The exact fourth-moment identity

Because O is real symmetric with zero diagonal,

```plain text
Tr((O O*)^2) = Tr(O^4).
```

The exact closed-cycle expansion is

```plain text
Tr(O^4)
  = sum_{h,k,l,j:
          h!=k, k!=l, l!=j, j!=h}
      Gamma_hk Gamma_kl Gamma_lj Gamma_jh.
```

No conjugation symbols are needed in this form because Gamma is real symmetric. For a general complex matrix the always-correct nonnegative form is

```plain text
Tr((O O*)^2)
  = sum_{h,l} |sum_k O_hk conj(O_lk)|^2.
```

For the present matrix this becomes the useful exact decomposition

```plain text
Tr(O^4)
  = sum_h (sum_{k!=h} Gamma_hk^2)^2
    + sum_{h!=l}
        (sum_{k notin {h,l}} Gamma_hk Gamma_kl)^2.
```

This formula is manifestly nonnegative and separates row-energy from off-diagonal codegrees.

### 5.1 Centered coincidence form

For h!=k, define

```plain text
E_hk = J_hk - n_h n_k/p.
```

Then

```plain text
O_hk = Gamma_hk = p E_hk,
```

and hence

```plain text
Tr(O^4)
  = p^4 sum_{closed adjacent-distinct 4-cycles}
      E_hk E_kl E_lj E_jh.
```

If

```plain text
q(a,b) = 1[a=b] - 1/p,
```

then

```plain text
E_hk
  = sum_{r in I_h}
    sum_{s in I_k}
      q(Delta_h(r),Delta_k(s)).
```

Thus Tr(O^4) is exactly an eight-base-point sum of four centered equality kernels. It has four gap labels, but two independent base points attached to each label after full expansion. This is more complicated than a single four-variable curve.

### 5.2 Fourier form

The exact Fourier expansion is

```plain text
Tr(O^4)
 = sum_{h,k,l,j adjacent-distinct}
   sum_{t1,t2,t3,t4 != 0}
      S_h(t1) conj(S_k(t1))
      S_k(t2) conj(S_l(t2))
      S_l(t3) conj(S_j(t3))
      S_j(t4) conj(S_h(t4)).
```

### 5.3 Centered value-distribution form

Using Gamma_hk=p sum_a x_h(a)x_k(a), one gets

```plain text
Tr(O^4)
 = p^4 sum_{h,k,l,j adjacent-distinct}
   sum_{a,b,c,d in F_p}
      x_h(a)x_k(a)
      x_k(b)x_l(b)
      x_l(c)x_j(c)
      x_j(d)x_h(d).
```

This is the cleanest formulation for a deterministic large-sieve or histogram attack.

## 6. The corrected fourth-moment scale

Suppose, as in the null model,

```plain text
E |O_hk|^2 ~ p^3.
```

Then a Wigner calculation gives

```plain text
E Tr(O^4) ~ 2 H^3 p^6
```

up to the real/complex normalization and lower-order terms. The leading contribution comes from three-vertex backtracking patterns such as

```plain text
h -> k -> h -> j -> h
```

and their transpose analogues. These terms survive all pairwise centering. They are not unwanted algebraic main components; they are the universal spectral main term.

Therefore the proposed target

```plain text
Tr(O^4) << H^2 p^6
```

is false even for an ideal iid random matrix. It would require cancellation of a positive backtracking contribution.

The correct natural target is

```plain text
[TR4-RMT]
Tr(O^4) <= C H^3 p^6.
```

It implies

```plain text
||O||_op
  <= C^(1/4) H^(3/4) p^(3/2).
```

At H<=p^(2/3),

```plain text
H^(3/4) p^(3/2)
  <= p^(1/2) p^(3/2)
  = p^2.
```

Thus [TR4-RMT] is exactly sufficient for [OP-OFF-0] and hence for COINC, assuming the diagonal budget. It is a valid final target for the F_p << p^(4/3) theorem.

The stronger but random-model-false estimate H^2p^6 would have implied the random-optimal norm sqrt(H)p^(3/2). Ordinary fourth moments lose a factor H^(1/4) when converting the average fourth power of H eigenvalues into the maximum eigenvalue. At H=p^(2/3), that loss is exactly p^(1/6), consuming all of the random-model margin.

### 6.1 Higher moments and the first genuine power saving

For fixed q>=2, the natural Wigner-scale target is

```plain text
[TR-2q]
Tr(O^(2q)) <= C_q H^(q+1) p^(3q).
```

It gives

```plain text
||O||_op
  <= C_q^(1/(2q))
     H^((q+1)/(2q)) p^(3/2).
```

At H=p^(2/3), the exponent of p is

```plain text
3/2 + (q+1)/(3q)
  = 11/6 + 1/(3q)
  = 2 - delta_q,

delta_q = (q-2)/(6q).
```

Therefore:

```plain text
q=2, fourth moment:  delta_q = 0,
q=3, sixth moment:   delta_q = 1/18,
q=4, eighth moment:  delta_q = 1/12,
q -> infinity:       delta_q -> 1/6.
```

So the corrected hierarchy is:

```plain text
natural fourth moment  => ||O|| << p^2, exactly enough;
natural sixth moment   => ||O|| << p^(2-1/18);
higher fixed moments   => progressively approach p^(11/6).
```

A logarithmic moment, if constants can be controlled, recovers the random norm up to polylogarithmic factors.

## 7. What the existing machinery can compute

The current project machinery already supplies four pieces.

First, D1 and the transfer recurrence generate every value Delta_{r,h} without computing b_r,c_r separately.

Second, additive orthogonality supplies the exact centered identities for Gamma, COINC, and every even trace moment.

Third, the component census can identify fixed pairs (h,k) with extra main components. For generic off-diagonal pairs, the uniform n_hn_k/p term is already removed in

```plain text
Gamma_hk = p(J_hk-n_hn_k/p).
```

Fourth, fixed-pair Weil estimates can check individual rows and small gaps and can validate the predicted p^(3/2) entry scale.

What is not currently supplied is the growing-family cancellation needed after summing closed cycles over h,k,l,j<=H.

There are two distinct residual sectors.

### 7.1 Backtracking sectors

Patterns with repeated opposite vertices, such as h=l or k=j, produce the natural positive main term H^3p^6. They should be bounded, not canceled. They reduce largely to rowwise second moments such as

```plain text
sum_{k!=h} Gamma_hk^2.
```

These are already beyond a single pair, but they are simpler than the all-distinct sector.

### 7.2 All-distinct four-gap sector

The sum

```plain text
sum_{h,k,l,j all distinct}
  Gamma_hk Gamma_kl Gamma_lj Gamma_jh
```

is the genuine signed four-gap family correlation. In the random model it has mean zero after centering. Proving sufficient cancellation here is the new geometric or spectral input.

Thus the sentence "per-pair main terms cancel by centering" is correct but incomplete. Centering removes the uniform rank-one background from each off-diagonal entry. It does not remove universal backtracking pairings in Tr(O^4), and it does not prove cancellation among all-distinct cycles.

A realistic fourth-moment proof should therefore have this architecture:

```plain text
1. Classify and peel off exceptional component/alias pairs.
2. Prove a random-scale row-energy bound for the regular pairs.
3. Evaluate or bound the repeated-index backtracking sectors by H^3p^6.
4. Prove signed cancellation for the all-distinct four-gap sector.
5. Combine with a uniform or averaged diagonal budget.
```

Per-pair Weil followed by absolute summation cannot accomplish steps 2-4; it recreates Schur's loss.

## 8. Exact numerical protocol

The target range p=2000 to 5000, H=floor(p^(2/3)), is completely feasible. At p=5000, one has approximately

```plain text
H = 292,
pH = 1.46 million.
```

The histogram table has only about 1.46 million integer cells, under 6 MB with 32-bit counts.

### 8.1 Build the Delta histograms directly

Precompute modulo p:

```plain text
P(u),
u^3,
(u^3)^(-1)
```

for u=1,...,p-1.

For every r=1,...,p-3, initialize

```plain text
d_prev = 0,
d      = (r+1)^(-3).
```

For

```plain text
h=1,...,min(H,M-r),
```

increment

```plain text
nu[h,d] += 1,
```

and update by

```plain text
d_next
  = (P(r+h)d - (r+h)^3 d_prev)
    (r+h+1)^(-3) mod p.

d_prev = d,
d      = d_next.
```

This is exactly the determinant recurrence. It costs O(pH) field operations and avoids polynomial construction and FFTs.

Use the exact row sizes

```plain text
n_h = p-2-h.
```

Sanity checks:

```plain text
sum_a nu_h(a) = n_h,
nu_h(0) = C_h,
```

and the explicit h=1 formulas above must hold exactly.

### 8.2 Implicit Gamma matvec in O(pH)

Do not form the H x H Gram matrix during the first pass. For a vector v in R^H, compute

```plain text
z(a) = sum_h nu_h(a) v_h,
s    = sum_h n_h v_h,

y_h = p sum_a nu_h(a) z(a) - n_h s.
```

Then

```plain text
y = Gamma v.
```

Precompute

```plain text
D_hh = p sum_a nu_h(a)^2 - n_h^2.
```

The off-diagonal matvec is

```plain text
O v = Gamma v - D v.
```

Each matvec uses two dense passes through the H x p histogram table, hence O(pH) arithmetic and O(pH) memory.

### 8.3 Eigenvalue estimation

Use symmetric Lanczos, not rowwise Schur.

For each prime, estimate:

```plain text
lambda_max(Gamma),
lambda_max(O),
lambda_min(O),
||O||_op = max(|lambda_max(O)|,|lambda_min(O)|).
```

Power iteration is adequate for Gamma, which is positive semidefinite. For O, Lanczos is preferable because the largest-magnitude eigenvalue may be negative. A fallback is power iteration on O^2, using two implicit O matvecs per iteration.

Thirty to one hundred Lanczos steps are inexpensive at this size.

### 8.4 Compute COINC without Fourier transforms

Let

```plain text
V(a) = sum_h nu_h(a).
```

Then exactly

```plain text
N_coinc = sum_a V(a)^2,
K_emp   = (p N_coinc - N^2)/(pN).
```

Also compute

```plain text
K_diag = (sum_h D_hh)/(pN),
K_off  = (1^T O 1)/(pN).
```

The exact identity

```plain text
K_emp = K_diag + K_off
```

is a strong implementation check.

Record the actual zero-fiber count

```plain text
Csum = sum_h nu_h(0)
```

and verify the Cauchy consequence

```plain text
Csum
 <= N/p + sqrt(((p-1)/p) K_emp N).
```

### 8.5 Quantities to record for [OP-OFF]

For every prime, record at least:

```plain text
max_h D_hh/p^2,
the h attaining that maximum,
lambda_max(Gamma)/p^2,
||O||_op/(p^(3/2)sqrt(H)),
||O||_op/p^2,
K_emp,
K_diag,
K_off.
```

To expose the Schur failure, also record

```plain text
max_h sum_{k!=h}|Gamma_hk| /(H p^(3/2)),
max_h sum_{k!=h}|Gamma_hk| /p^2.
```

To test the entry-scale model, record

```plain text
RMS_off
 = sqrt(
     sum_{h!=k} Gamma_hk^2 /(H(H-1))
   ) / p^(3/2),

max_{h!=k}|Gamma_hk|/p^2.
```

List every pair with anomalously large |Gamma_hk|/p^2. Such a list is the fastest detector of hidden component aliases.

Finally, if u_max is a top unit eigenvector, record

```plain text
|<u_max,1/sqrt(H)>|^2.
```

A small overlap means [GRAM-OP] is substantially stronger than the one-vector COINC target; a large overlap means the top spectral obstruction is directly relevant.

### 8.6 Direct test of the corrected fourth moment

At H around 300, forming the matrix once is still feasible:

```plain text
Gamma = p nu nu^T - n n^T,
O     = Gamma with its diagonal set to zero.
```

The matrix multiplication costs O(H^2p), about 4.3 x 10^8 multiply-adds at p=5000. This is feasible in optimized BLAS, but the implicit Lanczos route is much cheaper when only the norm is wanted.

Once O is formed, compute its eigenvalues and use

```plain text
Tr(O^4) = sum_j lambda_j^4,
Tr(O^6) = sum_j lambda_j^6.
```

Record the corrected normalized ratios

```plain text
R4 = Tr(O^4)/(H^3 p^6),
R6 = Tr(O^6)/(H^4 p^9).
```

They should remain bounded under the random-scale moment conjecture.

Also record the deliberately wrong normalization

```plain text
R4_wrong = Tr(O^4)/(H^2 p^6).
```

In the random model R4_wrong grows linearly with H. This single statistic directly falsifies the original [TR4] normalization and protects the campaign from optimizing toward an impossible target.

If forming O is undesirable, use a Hutchinson estimator. For independent Rademacher vectors z,

```plain text
E ||O^2 z||_2^2 = Tr(O^4).
```

Each probe needs two implicit O matvecs. Thirty-two to sixty-four probes should be more than adequate for a first scaling test. Similarly,

```plain text
E ||O^3 z||_2^2 = Tr(O^6)
```

uses three matvecs per probe.

### 8.7 Null-model calibration

Run two surrogates with the same p,H,n_h.

The most faithful value-distribution null is multinomial:

```plain text
for each h, sample n_h independent uniform values in F_p,
build nu_h(a),
then form Gamma=pXX^T exactly as above.
```

This preserves the row-sum constraint and the occupancy fluctuations.

A secondary calibration is Gaussian Wishart:

```plain text
A = sqrt(p) G,
Gamma = A A*.
```

Compare the Apery data with both surrogates for all normalized statistics. The surrogate is not evidence by itself, but it tells whether an observed constant or outlier is generic Gram behavior or Apery-specific structure.

### 8.8 Scaling fits

Use a sequence of primes in several ranges, not only one large prime. With H=p^(2/3), the null exponents are

```plain text
RMS off-diagonal entry    ~ p^(3/2),
||O||_op                  ~ p^(11/6),
Tr(O^4)                   ~ H^3p^6 = p^8,
||Gamma||_op              ~ p^2.
```

Fit log-log slopes and inspect residue classes p mod 3 separately because the h=1 diagonal has different leading behavior.

## 9. Numerical dispatch order

The numerical worker should run the following in this order.

1. Verify D1 through the determinant recurrence and the exact h=1 formulas. This catches all indexing and sign errors.

1. Measure max_h D_hh/p^2. If it grows with p, the unmodified Gram-operator route is false or requires removal of exceptional rows.

1. Scan the largest off-diagonal entries and classify the corresponding (h,k). This detects structural component aliases before they contaminate a random-matrix fit.

1. Run implicit Lanczos and record both

```plain text
||O||/(p^(3/2)sqrt(H))
and
||O||/p^2.
```

The first should be order one under the null; the second should decay like p^(-1/6).

1. Compute K_emp,K_diag,K_off and the top-eigenvector overlap with the all-ones vector. This decides whether full operator control is genuinely needed or whether a one-direction theorem may be much cheaper.

1. Compute R4 with the corrected H^3p^6 normalization, and compute R4_wrong to document the missing factor H.

1. Compute R6. If R6 is stable while R4 is stable, the natural sixth-moment target becomes the best proof-level spectral object because it gives the explicit off-diagonal saving delta=1/18.

## 10. Final campaign formulation

The sharpest logical hypothesis is

```plain text
[ONES-GRAM]
For H=floor(p^(2/3)),
1^T Gamma 1 <= C p^2 H.
```

It is exactly COINC up to the harmless factor pH/N=1+o(1).

The sharpest clean spectral hypothesis is

```plain text
[GRAM-OP]
For H=floor(p^(2/3)),
||Gamma||_op <= C p^2.
```

The useful decomposed version is

```plain text
[DIAG-SUM]
sum_{h<=H} (pJ_hh-n_h^2) <= C_D p^2 H,

[OP-OFF-0]
||O||_op <= C_O p^2.
```

Any absolute C_O suffices. The stronger statement

```plain text
||O||_op <= C p^(2-delta)
```

makes the off-diagonal contribution to COINC o(1), but it is not required.

The minimal ordinary moment hypothesis is the corrected fourth trace bound

```plain text
[TR4-RMT]
Tr(O^4) <= C H^3 p^6.
```

At H=p^(2/3) this gives exactly ||O||_op<<p^2, hence COINC, hence the proposed sum_{h<=H}C_h<<p^(5/6), and then, through the banked sigma ladder, the new theorem

```plain text
F_p << p^(4/3+eps).
```

The first moment hypothesis that gives a power-saving off-diagonal norm is

```plain text
[TR6-RMT]
Tr(O^6) <= C H^4 p^9,
```

which yields

```plain text
||O||_op << p^(2-1/18)
```

at H=p^(2/3).

So the final verdict is:

```plain text
Schur failure: verified, loss p^(1/6).
Random spectral success: verified, room p^(1/6).
Diagonal constant from c(h,h)=2: p^2, not 2p^2.
Whole Gram target: ||Gamma||_op << p^2.
Minimal off-diagonal target: ||O||_op << p^2.
Correct fourth moment: H^3p^6, exactly sufficient.
First power-saving moment: sixth moment, H^4p^9.
Immediate numerical dispatch: diagonal scan, alias scan, implicit Lanczos,
corrected R4, then R6.
```

This is the true operator-norm mechanism. It does not ask for impossible rowwise cancellation, and it isolates the genuinely new object: signed cancellation of growing-family closed gap cycles after the pairwise uniform main term has been centered away.
