1. For the affine reflection x -> 1 - x, use

1. For the Möbius substitution u = x / (1 + x), use

1. Use intervalIntegral.integral_comp_mul_deriv' or the unprimed version only when the transformed integrand is genuinely continuous on the closed image interval.

1. Use an explicit antiderivative only for a concrete terminal integral, or when a removable endpoint singularity has already been packaged as a continuous extension. It is less reusable than the change-of-variables theorem and usually creates more endpoint obligations.

The most important warning is that Mathlib's real logarithm and division are totalized. # 2. Reflection x -> 1 - x

## 2.1 Exact API

The relevant theorem is

```javascript
@[simp] theorem intervalIntegral.integral_comp_sub_left
    (f : ℝ -> E) (d : ℝ) :
    (∫ x in a..b, f (d - x)) = ∫ x in d - b..d - a, f x
```

for a normed real vector space E in the usual interval-integral context.

The companion

```javascript
intervalIntegral.integral_comp_sub_right
```

is for translation x -> x - d, not reflection. It is not the preferred theorem here.

## 2.2 The two reusable reflection lemmas

For the lower half reflected to the upper half:

```javascript
lemma integral_reflect_zero_half (f : ℝ -> ℝ) :
    (∫ x in (0 : ℝ)..(1 / 2 : ℝ), f (1 - x))
      = ∫ x in (1 / 2 : ℝ)..1, f x := by
  convert intervalIntegral.integral_comp_sub_left
      (a := (0 : ℝ)) (b := (1 / 2 : ℝ)) f 1 using 1 <;>
    norm_num
```

For the form most often used in Euler-sum reductions:

```javascript
lemma integral_reflect_half_one (f : ℝ -> ℝ) :
    (∫ x in (1 / 2 : ℝ)..1, f x)
      = ∫ x in (0 : ℝ)..(1 / 2 : ℝ), f (1 - x) := by
  simpa using (integral_reflect_zero_half f).symm
```

A direct instantiation on [1/2,1] is equally valid:

```javascript
-- ∫ x in 1/2..1, f (1-x) = ∫ x in 0..1/2, f x
simpa using
  (intervalIntegral.integral_comp_sub_left
    (a := (1 / 2 : ℝ)) (b := 1) f 1)
```

## 2.3 Why this is preferable

integral_comp_sub_left already accounts for the derivative -1 and for reversal of endpoints. There is no need to prove differentiability of x -> 1-x, no need to invoke integral_comp_mul_deriv, and no need to manipulate integral_symm manually.

The theorem is unconditional because interval integrals are defined for all functions. Consequently, it is an equality of interval-integral values even before integrability is established. For a convergence proof, one must still prove that the relevant integrands are interval-integrable; the reflection equality alone is not an integrability certificate.

# 3. Möbius substitution u = x / (1 + x)

Put

```javascript
def mob (x : ℝ) : ℝ := x / (1 + x)
def mobDeriv (x : ℝ) : ℝ := 1 / (1 + x)^2

def invMob (u : ℝ) : ℝ := u / (1 - u)
def invMobDeriv (u : ℝ) : ℝ := 1 / (1 - u)^2
```

Then

```plain text
mob(0) = 0,       mob(1) = 1/2,
mob'(x) = 1/(1+x)^2,

invMob(0) = 0,    invMob(1/2) = 1,
invMob'(u) = 1/(1-u)^2.
```

Both derivatives are positive on the intervals in question.

## 3.1 Exact robust API

The monotone scalar theorem in Mathlib 4.29 is

```javascript
theorem intervalIntegral.integral_comp_mul_deriv_of_deriv_nonneg
    {f f' g : ℝ -> ℝ}
    (hf : ContinuousOn f [[a, b]])
    (hff' : ∀ x ∈ Ioo (min a b) (max a b),
      HasDerivAt f (f' x) x)
    (hf' : ∀ x ∈ Ioo (min a b) (max a b), 0 ≤ f' x) :
    (∫ x in a..b, (g ∘ f) x * f' x)
      = ∫ u in f a..f b, g u
```

Its key advantage is that it imposes no hypothesis on g. This is exactly what is wanted when g contains log u, log (1-u), or a quotient with a removable or integrable endpoint singularity.

The matching integrability theorem is

```javascript
lemma intervalIntegral.integrable_comp_mul_deriv_iff_of_deriv_nonneg
    {f f' g : ℝ -> ℝ}
    (hf : ContinuousOn f [[a, b]])
    (hff' : ∀ x ∈ Ioo (min a b) (max a b),
      HasDerivAt f (f' x) x)
    (hf' : ∀ x ∈ Ioo (min a b) (max a b), 0 ≤ f' x) :
    IntervalIntegrable (fun x => (g ∘ f) x * f' x) volume a b
      ↔ IntervalIntegrable g volume (f a) (f b)
```

Use the equality theorem and this iff together. The equality theorem by itself does not show either side is integrable.

There are corresponding ..._of_deriv_nonpos theorems for antitone maps.

## 3.2 Direct form

Applying the theorem to mob on [0,1] gives

```plain text
∫_0^1 g(x/(1+x)) / (1+x)^2 dx = ∫_0^(1/2) g(u) du.
```

A Lean-shaped wrapper is:

```javascript
lemma integral_mob (g : ℝ -> ℝ) :
    (∫ x in (0 : ℝ)..1,
        g (x / (1 + x)) / (1 + x)^2)
      = ∫ u in (0 : ℝ)..(1 / 2 : ℝ), g u := by
  have hcont : ContinuousOn mob [[(0 : ℝ), 1]] :=
    mob_continuousOn_zero_one
  have hderiv : ∀ x ∈ Ioo (0 : ℝ) 1,
      HasDerivAt mob (mobDeriv x) x :=
    mob_hasDerivAt_on_Ioo
  have hnonneg : ∀ x ∈ Ioo (0 : ℝ) 1, 0 ≤ mobDeriv x := by
    intro x hx
    positivity
  have h :=
    intervalIntegral.integral_comp_mul_deriv_of_deriv_nonneg
      (a := (0 : ℝ)) (b := 1)
      (f := mob) (f' := mobDeriv) (g := g)
      hcont hderiv hnonneg
  convert h using 1 <;>
    simp [mob, mobDeriv, Function.comp_def] <;>
    ring
```

This wrapper assumes the derivative and continuity helpers proved once as named lemmas in Section 3.4. No proof hole or additional analytic theorem is hidden in the wrapper.

## 3.3 Recommended inverse-map form

For most Euler-sum calculations, the inverse-map statement is syntactically cleaner:

```plain text
∫_0^1 h(x) dx
  = ∫_0^(1/2) h(u/(1-u)) / (1-u)^2 du.
```

Indeed, apply the theorem to invMob on [0,1/2] and take symmetry:

```javascript
lemma integral_invMob (h : ℝ -> ℝ) :
    (∫ x in (0 : ℝ)..1, h x)
      = ∫ u in (0 : ℝ)..(1 / 2 : ℝ),
          h (u / (1 - u)) / (1 - u)^2 := by
  have hcont : ContinuousOn invMob [[(0 : ℝ), (1 / 2 : ℝ)]] :=
    invMob_continuousOn
  have hderiv : ∀ u ∈ Ioo (0 : ℝ) (1 / 2 : ℝ),
      HasDerivAt invMob (invMobDeriv u) u :=
    invMob_hasDerivAt_on_Ioo
  have hnonneg : ∀ u ∈ Ioo (0 : ℝ) (1 / 2 : ℝ),
      0 ≤ invMobDeriv u := by
    intro u hu
    positivity
  have hs :=
    intervalIntegral.integral_comp_mul_deriv_of_deriv_nonneg
      (a := (0 : ℝ)) (b := (1 / 2 : ℝ))
      (f := invMob) (f' := invMobDeriv) (g := h)
      hcont hderiv hnonneg
  convert hs.symm using 1 <;>
    norm_num [invMob, invMobDeriv, Function.comp_def] <;>
    ring
```

This is the recommended reusable theorem for the P2.4 endpoint reducer. The original integrand remains h; all algebraic change is confined to the transformed side.

## 3.4 Derivative helpers: prove them explicitly once

Do not rely on fun_prop to solve all denominator side conditions. A stable pattern is:

```javascript
lemma hasDerivAt_mob (x : ℝ) (hx : 1 + x ≠ 0) :
    HasDerivAt mob (mobDeriv x) x := by
  have hnum : HasDerivAt (fun y : ℝ => y) 1 x := hasDerivAt_id x
  have hden : HasDerivAt (fun y : ℝ => 1 + y) 1 x := by
    simpa using (hasDerivAt_const (x := x) 1).add (hasDerivAt_id x)
  convert hnum.div hden hx using 1 <;>
    field_simp [mob, mobDeriv] <;>
    ring
```

The inverse-map lemma is identical with denominator 1-u and derivative -1 for that denominator:

```javascript
lemma hasDerivAt_invMob (u : ℝ) (hu : 1 - u ≠ 0) :
    HasDerivAt invMob (invMobDeriv u) u := by
  -- quotient rule, then `field_simp` and `ring`
  ...
```

After these are available, continuity on the closed interval is easy and avoids a second rational-function continuity proof:

```javascript
lemma invMob_continuousOn :
    ContinuousOn invMob [[(0 : ℝ), (1 / 2 : ℝ)]] := by
  intro u hu
  have hne : 1 - u ≠ 0 := by
    have : u ≤ (1 / 2 : ℝ) := by
      simpa [uIcc_of_le (by norm_num : (0 : ℝ) ≤ 1 / 2)] using hu
    linarith
  exact (hasDerivAt_invMob u hne).continuousAt.continuousWithinAt
```

This derivative-first method is usually more robust across Mathlib changes than a large fun_prop invocation on a quotient.

# 4. When the continuous change-of-variables theorem is appropriate

Mathlib 4.29 also has:

```javascript
theorem intervalIntegral.integral_comp_mul_deriv'
    {f f' g : ℝ -> ℝ}
    (h : ∀ x ∈ uIcc a b, HasDerivAt f (f' x) x)
    (h' : ContinuousOn f' (uIcc a b))
    (hg : ContinuousOn g (f '' [[a, b]])) :
    (∫ x in a..b, (g ∘ f) x * f' x)
      = ∫ x in f a..f b, g x
```

and the globally continuous specialization

```javascript
theorem intervalIntegral.integral_comp_mul_deriv
    {f f' g : ℝ -> ℝ}
    (h : ∀ x ∈ uIcc a b, HasDerivAt f (f' x) x)
    (h' : ContinuousOn f' (uIcc a b))
    (hg : Continuous g) :
    (∫ x in a..b, (g ∘ f) x * f' x)
      = ∫ x in f a..f b, g x
```

Use these only when their continuity hypotheses are naturally true.

For a polynomial or rational integrand with denominators bounded away from zero, the primed theorem can be convenient. For expressions containing log u at u=0, it is the wrong interface: log has no finite continuous extension there. Use the monotone theorem instead.

The more general theorem

```javascript
intervalIntegral.integral_comp_mul_deriv''
```

allows a continuous right derivative and continuity of g only on the image. It is useful for maps whose endpoint derivative is awkward, but it still requires a continuous transformed integrand on the closed image. It does not solve a genuine logarithmic endpoint singularity.

# 5. Endpoint logarithms: removable versus genuine singularities

## 5.1 Totalized values are not analytic extensions

Mathlib defines Real.log and division everywhere. Consequently:

```plain text
Real.log 0 = 0,
0⁻¹ = 0,
0 / 0 = 0.
```

These definitions make expressions syntactically total, but they do not prove continuity. For example, the raw function

```plain text
x -> log(1-x) / x
```

has raw value 0 at x=0, while its mathematical limit is -1.

## 5.2 Removable singularities: use dslope

A particularly robust extension is

```plain text
-log(1-x)/(-x) = -dslope Real.log 1 (1-x),
```

more transparently,

```plain text
log(1-x)/x = -dslope Real.log 1 (1-x)       for x ≠ 0.
```

The right-hand side is defined at x=0 with value -1, and continuity follows from

```javascript
continuousAt_dslope_same.mpr
  (Real.differentiableAt_log one_ne_zero)
```

composed with x -> 1-x.

This is better than an if x = 0 then -1 else ... definition because the derivative package already knows the endpoint value and continuity.

The same idea handles log x / (1-x) at x=1.

## 5.3 Products with x * log x

Mathlib 4.29 provides the global theorem

```javascript
Real.continuous_mul_log : Continuous (fun x : ℝ => x * Real.log x)
```

and the global continuous function Real.negMulLog.

Thus expressions such as

```plain text
(1-x) * log(1-x)
```

should be treated as a composition of Real.continuous_mul_log, not as a product of two functions each claimed continuous at x=1.

The current project uses exactly this technique for

```plain text
log x * log(1-x)
```

at x=1: it rewrites the first logarithm using dslope, leaves

(1-x)*log(1-x) bundled, and combines

continuousAt_dslope_same with Real.continuous_mul_log.

## 5.4 Genuine integrable singularities

Functions such as

```plain text
log x,
log(x)^2,
log(x)^k * bounded(x)
```

have no finite continuous extension at 0, although they can be integrable. Do not attempt to force them through integral_comp_mul_deriv'.

Use one of these routes:

1. the monotone substitution theorem plus a separate interval-integrability proof;

1. truncate to [ε,b], apply the ordinary theorem there, and pass to the limit ε -> 0+;

1. prove the integral by an explicit primitive with one-sided endpoint limits.

Also avoid splitting a convergent expression into individually nonintegrable pieces. For example, a factor log(1-x) may cancel a 1/x; establish the bound for the bundled expression before using integral linearity.

# 6. Explicit-antiderivative fallback

An explicit primitive is the right fallback when:

- the integral is a one-off terminal identity;

- a proposed substitution produces a large amount of rational normalization work;

- the primitive is already expressed in terms of log, Li2, Li3, or Li4 with derivative lemmas available;

- the primitive has controlled endpoint values.

For a genuinely continuous closed-interval situation, the core theorem is

```javascript
intervalIntegral.integral_eq_sub_of_hasDerivAt
```

in the standard shape

```javascript
(hderiv : ∀ x ∈ uIcc a b, HasDerivAt F (f x) x)
(hint : IntervalIntegrable f volume a b)
:
(∫ x in a..b, f x) = F b - F a
```

A typical wrapper is

```javascript
lemma integral_eq_primitive
    (hderiv : ∀ x ∈ uIcc a b, HasDerivAt F (f x) x)
    (hint : IntervalIntegrable f volume a b) :
    (∫ x in a..b, f x) = F b - F a := by
  exact intervalIntegral.integral_eq_sub_of_hasDerivAt hderiv hint
```

If F is differentiable only in the open interval but extends continuously to the endpoints, use the corresponding FTC theorem with ContinuousOn F (Icc a b) and interior derivative hypotheses. If the primitive itself is not literally continuous at an endpoint but has a finite one-sided limit, truncate the interval and pass to the endpoint limit; this is generally less fragile than trying to assign a junk endpoint value to the raw formula.

For the P2.4 Euler integrals, explicit primitives are excellent for the final finite table of half-interval integrals. They are not the preferred way to prove the generic reflection or Möbius transport lemmas.

1. simplify logarithms only after proving the arguments are positive;

1. keep endpoint-cancelling products bundled;

1. finish each half-interval integral with an explicit primitive or the existing Li2/Li3 derivative API.

# 8. Final comparison

## integral_comp_sub_left/right

- Best use: affine translation/reflection.

- For x -> 1-x: integral_comp_sub_left is exactly right.

- Hypotheses: none.

- Risk: none beyond endpoint arithmetic simplification.

- Verdict: always use it for the reflection step.

## integral_comp_mul_deriv

- Best use: smooth substitution with globally continuous transformed integrand.

- Problem for Euler sums: log at 0 or 1 usually violates the continuity hypothesis.

- Verdict: useful only for nonsingular subintegrals.

## integral_comp_mul_deriv' / ''

- Best use: continuity only on the image, or weaker derivative packaging.

- Problem: still require continuity on the closed image.

- Verdict: not a cure for genuine endpoint logarithms.

## integral_comp_mul_deriv_of_deriv_nonneg

- Best use: monotone Möbius substitutions, including integrable endpoint singularities.

- Hypothesis on transformed integrand: none.

- Companion: use the integrability iff theorem.

- Verdict: preferred Möbius API; apply it to invMob when possible.

## Explicit primitive

- Best use: final special-function evaluation after all interval transport is complete.

- Strength: avoids composition-normal-form issues and exposes endpoint constants directly.

- Cost: every primitive needs derivative, integrability, and endpoint proofs.

- Verdict: fallback for concrete terminal integrals, not generic transport.

The shortest reliable architecture is therefore:

```plain text
reflection: integral_comp_sub_left
Möbius:     integral_comp_mul_deriv_of_deriv_nonneg on invMob
endpoints:  dslope + Real.continuous_mul_log when removable
final value: explicit primitive / FTC
```
