It is not a shell coordinate. It is a cube state coordinate.

## 3. Same-K cancellation

Suppose two pairs (D_1,N_1) and (D_2,N_2) have the same

[

K=leftlfloor M/(D_i-1)rightrfloor.

]

Then their right sides are identical:

[

A_1+H_1=S(M,K)=A_2+H_2.

]

Therefore

[

boxed{A_1-A_2=H_2-H_1.}

]

This is a genuine cancellation unavailable to a single kernel.

The remaining question is whether this residual keeps all principal target primes.

## 4. Local q-ledger

Let q be a principal target prime in the first interval. The original kernel gives

[

qmid A_i

]

only when the corresponding interpolation node is present. For the difference

[

A_1-A_2,

we need both kernels to vanish at the same q.

Thus the surviving target set is

[

T_{rm survive}=T_1cap T_2.

]

A target appearing only in one packet is cancelled away with the packet constant and does not divide the residual.

For two kernels, the local valuation is therefore

[

qmid A_1 text{and} qmid A_2.

]

The determinant form is

[

Delta=A_1H_2-A_2H_1.

]

Using A_i+H_i=S,

[

boxed{Delta=S(A_1-A_2).}

]

Hence the common packet scalar remains as a factor. After dividing by S (when integral), the target divisibility is exactly the intersection condition above.

## 5. Can this give sublinear height?

The same-K construction removes the large cube packet exactly, but only by replacing one scalar problem with an intersection problem.

For m kernels with the same K:

[

A_i=S-H_i,

]

and every integer relation among the A_i is a relation among the H_i plus the common scalar S.

The local module at a prime q has rank one: every target-preserving linear combination must annihilate the non-target coordinates and retain the same marked scalar. Concretely, if q divides only one kernel evaluation, there is no forced q-divisibility after packet elimination.

Therefore same-K cancellation is useful only if one can prove a large overlap of target sets between different intervals. The Bezout identity itself does not provide this.

## 6. Exact obstruction specific to this distinguished state

This is not a generic CRT obstruction. It follows from the actual cube packet:

1. The RHS is the same distinguished coefficient functional S(M,K).

1. Eliminating it produces only differences of Newton carriers.

1. At a prime q, the difference loses q unless q is a common interpolation node.

1. The Apéry origin state contributes no additional q-zero in the top-target range.

Thus the first precise obstruction is:

[

boxed{

text{same-K packet cancellation preserves only common-node targets.}

}

]

No sublinear radical follows unless a new theorem proves that the same-K families have enough target overlap.
