## 4. Recurrence/generating-function status

The family (Phi_s(t)) is a diagonal correlation of a fixed finite Laurent polynomial with (Lambda^s). For fixed (t), it is a constant-term sequence and hence has a holonomic recurrence in (s).

However the requested recurrence in the shell variable (t) is different. The coefficient

[

c_s(tkappa)

]

changes the extraction direction with (t). The diagonal direction is not fixed as (t) varies. Therefore the standard diagonal D-finite closure does not give a fixed-order recurrence in (t).

The obstruction is geometric: the relevant lattice slice of (sP) changes with the ray (tkappa). For (|t|=O(1)), a bounded collection of rays can be used; for growing (|t|), the number of active face intersections grows with the shell geometry.

Thus the strongest proved statement is:

- fixed (t): bounded-order recurrence in (s);

- fixed (s): finite Laurent polynomial in the possible (t)-range;

- no uniform bounded-order recurrence in (t) follows from the shell definition alone.
