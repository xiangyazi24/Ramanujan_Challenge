## 2. Logical position

Relation to OP-OFF-0:

TR6-HORIZONTAL implies OP-OFF-0 once the cycle expansion identifies all off-diagonal contributions with the closed-cycle family. It is stronger: OP-OFF-0 only asks for the final operator norm, while TR6-HORIZONTAL specifies the cancellation mechanism.

COINC is a second-moment collision-count statement:

N_coinc(H) <= (#S_H)^2/p + K #S_H.

It implies strong q=2 control of unsigned energy. TR6-HORIZONTAL is not implied by COINC, because COINC does not see signs. Conversely TR6-HORIZONTAL(q=2) should imply a refined signed version of COINC, but not necessarily the raw collision estimate.

Relation to shell targets:

Relation to MESO-S1-2/3:
