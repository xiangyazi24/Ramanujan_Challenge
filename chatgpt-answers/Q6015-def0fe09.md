# Executive verdict

The shortest sound Lean architecture is a finite one-sided zeta split, followed by limits. Do not form the endpoint product as a product of two infinite series, and do not assert raw HasSum statements for the alternating harmonic sequence or for the outer sequence defining H.

There are two clean implementations:

1. Generic and safest: use Tendsto of natural partial sums for the two conditionally convergent sequences, while retaining ordinary HasSum for the absolutely summable diagonal and upper-triangular sequences.

1. Shortest when the existing project theorems are grouped: pair consecutive terms first. Every paired sequence is absolutely summable, so the final relation follows from one pointwise paired identity and HasSum.unique.

The second route is probably the shortest in the current file if the existing exact Euler-sum theorems already use grouped pairs. The first route is the canonical fallback and makes the endpoint legality completely explicit.

Abel regularization with r < 1 is sound but longer: it introduces separate endpoint-limit proofs for the lower triangle, diagonal, and upper triangle. The finite split below avoids all of that.

# 1. Why the naive endpoint HasSum product is invalid

With zero-based indexing, put

```javascript
private def altTerm (n : ℕ) : ℝ :=
  (-1 : ℝ) ^ (n + 1) / (n + 1 : ℝ)
```

The mathematical series is

This is conditionally convergent. Mathlib's ordinary HasSum over ℕ is convergence of the net of all finite subsums, not merely convergence of the initial segments Finset.range N. In the finite-dimensional real space ℝ, Summable f implies Summable (fun n => ‖f n‖) through Summable.norm. Therefore the following statement is false and must not appear:

```javascript
HasSum altTerm (-Real.log 2)
```

The same warning applies to the raw outer sequence for H: its magnitude is asymptotic to a nonzero constant divided by n, so it is not Summable in Mathlib's unconditional sense.

Use either

```javascript
Tendsto (fun N => ∑ n in Finset.range N, altTerm n)
  Filter.atTop (𝓝 (-Real.log 2))
```

or a HasSum theorem for the paired sequence

```javascript
fun r => altTerm (2 * r) + altTerm (2 * r + 1).
```

# 2. Canonical zero-based definitions

Use one indexing convention throughout. The following convention makes all shifts transparent:

```javascript
open scoped BigOperators Topology
open Filter Finset MeasureTheory Set

private def z2Term (n : ℕ) : ℝ :=
  1 / (n + 1 : ℝ) ^ 2

private def altTerm (n : ℕ) : ℝ :=
  (-1 : ℝ) ^ (n + 1) / (n + 1 : ℝ)

private def belowTerm (n : ℕ) : ℝ :=
  altTerm n * ∑ k in Finset.range n, z2Term k

private def diagTerm (n : ℕ) : ℝ :=
  altTerm n * z2Term n

private def tail2 (n : ℕ) : ℝ :=
  ∑' j : ℕ, z2Term (n + 1 + j)

private def aboveTerm (n : ℕ) : ℝ :=
  altTerm n * tail2 n
```

Here n = m - 1. Thus:

- belowTerm n is the summand of H, because Finset.range n represents the original indices 1 ≤ k < m;

- diagTerm n = (-1)^m / m^3;

- aboveTerm n represents m < k and will be identified with J.

The two easy off-by-one checks are

```plain text
n = 0  ↔  m = 1:
  belowTerm 0 = 0,
  diagTerm 0 = -1,
  aboveTerm 0 = -∑_{k≥2} 1/k².
```

# 3. Exact one-term and finite identities

Assume the shifted zeta-two series is available as

```javascript
hz2 : HasSum z2Term Z2
```

where eventually Z2 = Real.pi ^ 2 / 6.

The load-bearing tail split is:

```javascript
lemma zeta2_split (hz2 : HasSum z2Term Z2) (n : ℕ) :
    Z2 =
      (∑ k in Finset.range n, z2Term k) +
      z2Term n +
      tail2 n := by
  have h := hz2.summable.sum_add_tsum_nat_add (n + 1)
  rw [hz2.tsum_eq, Finset.sum_range_succ] at h
  simpa [tail2, Nat.add_assoc, Nat.add_comm, Nat.add_left_comm] using h.symm
```

The exact Mathlib API here is Summable.sum_add_tsum_nat_add. It gives

```plain text
sum over range (n+1) + tail beginning at n+1 = tsum.
```

After Finset.sum_range_succ, this is precisely “strictly below + diagonal + strictly above.”

Multiplying this finite identity at one fixed outer index gives:

```javascript
lemma term_stuffle (hz2 : HasSum z2Term Z2) (n : ℕ) :
    altTerm n * Z2 =
      belowTerm n + diagTerm n + aboveTerm n := by
  rw [zeta2_split hz2 n]
  simp only [belowTerm, diagTerm, aboveTerm]
  ring
```

Consequently, for every finite N:

```javascript
lemma finite_stuffle (hz2 : HasSum z2Term Z2) (N : ℕ) :
    (∑ n in Finset.range N, altTerm n) * Z2 =
      (∑ n in Finset.range N, belowTerm n) +
      (∑ n in Finset.range N, diagTerm n) +
      (∑ n in Finset.range N, aboveTerm n) := by
  rw [Finset.sum_mul]
  calc
    ∑ n in Finset.range N, altTerm n * Z2 =
        ∑ n in Finset.range N,
          (belowTerm n + diagTerm n + aboveTerm n) := by
      refine Finset.sum_congr rfl ?_
      intro n hn
      exact term_stuffle hz2 n
    _ =
        (∑ n in Finset.range N, belowTerm n) +
        (∑ n in Finset.range N, diagTerm n) +
        (∑ n in Finset.range N, aboveTerm n) := by
      simp only [Finset.sum_add_distrib]
```

This is the entire stuffle argument. No infinite double sum has been rearranged.

# 4. Generic endpoint theorem using natural partial sums

The following is the reusable theorem to put near the final proof:

```javascript
lemma endpoint_stuffle

        atTop (𝓝 (-Real.log 2)))

        atTop (𝓝 H))

    (hAbove : HasSum aboveTerm J) :
    (-Real.log 2) * Z2 = J + H - (3 : ℝ) / 4 * Z3 := by
  have hLeft :
      Tendsto
        (fun N => (∑ n in Finset.range N, altTerm n) * Z2)
        atTop (𝓝 ((-Real.log 2) * Z2)) :=
    hAlt.mul tendsto_const_nhds

  have hRight :
      Tendsto
        (fun N =>
          (∑ n in Finset.range N, belowTerm n) +
          (∑ n in Finset.range N, diagTerm n) +
          (∑ n in Finset.range N, aboveTerm n))
        atTop (𝓝 (H + (-(3 : ℝ) / 4 * Z3) + J)) :=
    (hBelow.add hDiag.tendsto_sum_nat).add hAbove.tendsto_sum_nat

  have hEq :
      (fun N => (∑ n in Finset.range N, altTerm n) * Z2) =ᶠ[atTop]
      (fun N =>
        (∑ n in Finset.range N, belowTerm n) +
        (∑ n in Finset.range N, diagTerm n) +
        (∑ n in Finset.range N, aboveTerm n)) :=
    Filter.Eventually.of_forall (finite_stuffle hz2)

  have hLeft' := hLeft.congr' hEq
  have h := tendsto_nhds_unique hLeft' hRight
  linarith
```

# 6. Identifying the upper triangle with J

This is the only analytic bridge required by the stuffle proof.

Define

```javascript
private def kernel (n : ℕ) (x : ℝ) : ℝ :=
  x ^ (n + 1) * Real.log x / (1 - x)

private def jFn (n : ℕ) (x : ℝ) : ℝ :=
  -altTerm n * kernel n x
```

The required reusable lemmas are

```javascript
lemma integral_kernel (n : ℕ) :

lemma integral_jFn (n : ℕ) :
```

# 11. Pitfalls that are likely to cause a false proof or a Lean failure

1. Do not assert raw HasSum altTerm (-log 2). Use natural partial sums or pair altTerm.

1. Do not assert raw HasSum belowTerm H. Again use natural partial sums or adjacent pairs.

1. In zero-based indexing the sign is (-1) ^ (n + 1), not (-1) ^ n.

1. belowTerm n uses Finset.range n, not Finset.range (n + 1).

1. tail2 n starts at z2Term (n + 1). Starting at n duplicates the diagonal.

1. integral_pow_mul_log26 q corresponds to exponent q and denominator (q + 1)^2.

1. Keep casts syntactically uniform. Prefer (n + 1 : ℝ) everywhere; avoid mixing it with ((n + 1 : ℕ) : ℝ) inside the same lemma unless norm_num or push_cast is used explicitly.

1. The pointwise logarithm series needs |x| < 1. Handle x = 1 separately; do not claim it there by continuity.

1. Real.log and division are totalized in Lean. The values at endpoints are harmless for integration but do not replace the required a.e. argument.

1. The diagonal is -3/4 * Z3, not +3/4 * Z3.

1. In the H integral, d/dx Li₂(-x) = -log(1+x)/x; losing this minus sign changes both the boundary term and the ζ3/4 term.
