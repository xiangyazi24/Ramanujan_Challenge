# Terminal first-cell carriers: an exact generating function and a rigorous Ore obstruction

I audited the definitions against `origin/main` at commit
`4e4fb9cc1b11ba25f76674f4953e2b8ed062f17f`, in particular Sections
54, 57, 60--63, and 68.13--68.18 of

## Verdict

There is a clean exact generating function for the whole terminal family.  It
also gives a precise obstruction to the most natural recurrence/Bezout route.
After the first-cell shell is extended by its 21 fixed rays, the transformed
terminal sequence has a **nonzero constant tail**.  Consequently every global
Ore annihilator produced from those fixed-ray recurrences is right-divisible by
`S-1`; equivalently, the sum of its coefficients is identically zero.  Such an
operator cannot give the nonzero-sum Bezout identity needed to turn

\[
 p\mid F_0,\ldots,F_J,\qquad p\nmid b_M
\]

into divisibility of a target-blind small integer.

The obstruction is independent of the Pascal node factors.  It occurs over
characteristic zero, before reduction modulo a target prime.  Letting
\(J\to\infty\) with \(J=o(M)\) does not remove it: the correction which breaks
the `S-1` factor first occurs at sequence index \(M+1\), whereas the terminal
packet is centered at \(\lfloor(M-1)/2\rfloor\), an exact distance
\(\lfloor M/2\rfloor+2\) away.

Thus I do **not** obtain \(\log\gcd(F_0,\ldots,F_J)=o(M)\).  I obtain:

1. an explicit Bernstein/constant-term generating function for \(F_j\);
2. an explicit rational constant-term generating function for \(B_j\);
3. a rigorous no-go theorem for every boundary-blind linear holonomic
   certificate generated from the Section-60 fixed-ray recurrences;
4. an exact description of the boundary term that any successful new
   certificate must use.

## 1. Reindex the terminal family

Put

\[
 r_*:=M-d_0=\left\lfloor\frac{M-1}{2}\right\rfloor,
 \qquad
 \Phi_r:=G_{M-r,r}(C_M),\qquad 0\le r\le r_*.
\]

Then the family in the question is simply

\[
 F_j=\Phi_{r_*-j}.
\tag{1.1}
\]

Let \(b=b_M=\operatorname{CT}\Lambda^M\), and, in the first cell, write

\[
 S_q:=C_M(M-q)-b
 =\sum_{\kappa\in P(\mathbb Z)\setminus\{0\}}
   c_M((M-q)\kappa),
 \qquad 0\le q\le r_*.
\tag{1.2}
\]

Substitute \(d=M-r,L=r\) in the definition

\[
 G_{d,L}=
 \sum_{i=0}^L(-1)^i
 \binom{d+i}{i}\binom{d+L+1}{L-i}C_M(d+i)
\]

and set \(q=r-i\).  This gives the exact terminal transform

\[
 \boxed{
 \Phi_r-b=
 \sum_{q=0}^r(-1)^{r-q}
 \binom{M-q}{r-q}\binom{M+1}{q}S_q .
 }
\tag{1.3}
\]

The constant part really is \(b\), because

\[
 \sum_{q=0}^M\binom{M+1}{q}z^q(1-z)^{M-q}
 =\frac{1-z^{M+1}}{1-z}=1+z+\cdots+z^M.
\tag{1.4}
\]

Hence the coefficient of \(z^r\) in the left side of (1.4) is one for
every \(0\le r\le M\).

## 2. Exact Bernstein and constant-term generating functions

For all \(0\le q\le M+1\), define the fixed-ray extension

\[
 S_q^\sharp:=
 \sum_{\kappa\in P(\mathbb Z)\setminus\{0\}}
 c_M((M-q)\kappa).
\tag{2.1}
\]

For \(q\le r_*\), this equals the actual first-cell correction in (1.2).
For larger \(q\), it is an algebraic extension by the same 21 rays; it is not
being identified with the full shell \(C_M(M-q)-b\).

Define \(E_r^\sharp\), \(0\le r\le M\), by the right side of (1.3), with
\(S_q\) replaced by \(S_q^\sharp\).  Then

\[
 E_r^\sharp=\Phi_r-b\qquad(0\le r\le r_*),
\tag{2.2}
\]

and coefficient extraction gives

\[
 \boxed{
 \mathcal E_M(z):=\sum_{r=0}^M E_r^\sharp z^r
 =\sum_{q=0}^M
   \binom{M+1}{q}S_q^\sharp z^q(1-z)^{M-q}.
 }
\tag{2.3}
\]

Now set

\[
 \begin{aligned}
 N_M(z)&:=
 \sum_{\kappa\in P(\mathbb Z)\setminus\{0\}}
 \operatorname{CT}\!\left[
   \Lambda^M X^{-M\kappa}
   (1-z+zX^\kappa)^{M+1}
 \right],\\
 A_M&:=
 \sum_{\kappa\in P(\mathbb Z)\setminus\{0\}}
 \operatorname{CT}[\Lambda^M X^\kappa]
 =\sum_{\kappa\ne0}c_M(-\kappa).
 \end{aligned}
\tag{2.4}
\]

For one fixed \(\kappa\), use

\[
 \sum_{q=0}^M\binom{M+1}{q}a^{M-q}z^q
 =\frac{(a+z)^{M+1}-z^{M+1}}{a},
 \qquad a=(1-z)X^{-\kappa}.
\tag{2.5}
\]

After multiplying by \(\Lambda^M\), taking the constant term, and summing
over the nonzero rays, (2.3) becomes

\[
 \boxed{
 (1-z)\mathcal E_M(z)=N_M(z)-A_Mz^{M+1}.
 }
\tag{2.6}
\]

At \(z=1\),

\[
 N_M(1)=
 \sum_{\kappa\ne0}
 \operatorname{CT}[\Lambda^M X^\kappa]=A_M,
\tag{2.7}
\]

so the numerator in (2.6) has the required zero at one.

The corresponding *uncancelled* fixed-ray series is

\[
 \widehat{\mathcal E}_M(z):=\frac{N_M(z)}{1-z}
 =\mathcal E_M(z)+A_M\frac{z^{M+1}}{1-z}.
\tag{2.8}
\]

Writing \(\widehat{\mathcal E}_M(z)=\sum_{r\ge0}\widehat E_rz^r\), we
obtain the exact tail law

\[
 \boxed{
 \widehat E_r=E_r^\sharp\quad(0\le r\le M),
 \qquad
 \widehat E_r=A_M\quad(r\ge M+1).
 }
\tag{2.9}
\]

This tail is nonzero.  Indeed, expanding

\[
 \Lambda=
 \frac{(1+x)(1+y)^2(1+z)^2}{xyz}
 +(1+x)(1+y)(1+z)
\]

shows

\[
 [x^0y^0z^0]\Lambda=5,
 \qquad
 [x^{-1}y^0z^0]\Lambda=4.
\]

All coefficients of \(\Lambda\) are nonnegative.  Choosing one
\(x^{-1}y^0z^0\) monomial and \(M-1\) constant monomials gives

\[
 c_M(-1,0,0)\ge 4M5^{M-1}.
\]

Since \((1,0,0)\in P(\mathbb Z)\setminus\{0\}\),

\[
 \boxed{A_M\ge4M5^{M-1}>0.}
\tag{2.10}
\]

This lower bound is used only to show that the bare correction \(A_M\)
cannot itself be an \(o(M)\)-height certificate.  It does not rule out a new
gcd or resultant cancellation involving \(A_M\).

## 3. The boundary packets also have an exact rational CT generating function

For \(0\le r\le r_*\), put

\[
 \mathcal B_r:=\Delta^rC_M(M-r).
\]

The zero-surplus constant-term identity in the question is

\[
 \mathcal B_r=
 \sum_{\kappa\in P(\mathbb Z)}
 \operatorname{CT}\!\left[
  \Lambda^M X^{-M\kappa}(1-X^\kappa)^r
 \right].
\tag{3.1}
\]

Extending its right side formally to all \(r\ge0\) and summing the geometric
series gives

\[
 \boxed{
 \mathcal B_M(z):=
 \sum_{r\ge0}\mathcal B_rz^r
 =\sum_{\kappa\in P(\mathbb Z)}
 \operatorname{CT}\!\left[
 \frac{\Lambda^M X^{-M\kappa}}
      {1-z(1-X^\kappa)}
 \right].
 }
\tag{3.2}
\]

The adjacent terminal identity is

\[
 \boxed{
 \Phi_r-\Phi_{r-1}
 =(-1)^r\binom{M+1}{r}\mathcal B_r,
 \qquad r\ge1.
 }
\tag{3.3}
\]

Thus the \(B\)-sequence determines the terminal \(F\)-sequence only up to an
additive constant.  Any linear identity made solely from the differences in
(3.3) has total coefficient sum zero.  The Ore theorem below shows that this is
not merely an artifact of writing adjacent differences: it is forced for the
whole global fixed-ray holonomic module.

## 4. What a useful Bezout recurrence would have to do

Let \(S\) denote the forward shift in \(r\), and let

\[
 P=\sum_{i=0}^s a_i(M,r)S^i
\tag{4.1}
\]

be a recurrence operator, cleared to primitive integral polynomial
coefficients at the evaluation point.  Define its augmentation

\[
 \sigma_P(M,r):=P(1)=\sum_{i=0}^s a_i(M,r).
\tag{4.2}
\]

Suppose \(P(E^\sharp)=0\) on a window contained in the first cell.  Since
\(E_r^\sharp=\Phi_r-b_M\),

\[
 \sum_{i=0}^s a_i(M,r)\Phi_{r+i}
 =b_M\sigma_P(M,r).
\tag{4.3}
\]

For a top-half target prime in that window, all the \(\Phi_{r+i}\) vanish
modulo \(p\).  Moreover Section 61.15 gives

\[
 p\nmid b_M\qquad(p>5).
\tag{4.4}
\]

For completeness, write \(M=p+s\).  Targetness is \(p\mid b_{s+1}\), while
Apéry--Lucas gives \(b_M\equiv b_1b_s=5b_s\pmod p\).  Two consecutive
Apéry values below \(p\) cannot both vanish, because the Apéry recurrence
would propagate such a pair backwards to \(b_0\equiv0\), contrary to
\(b_0=1\).  Hence (4.4).

Therefore a recurrence with \(\sigma_P\ne0\) would give the exact target
carrier

\[
 \boxed{p\mid\sigma_P(M,r),}
\tag{4.5}
\]

apart from explicitly recorded denominator and singular factors.  This is the
right linear-Bezout objective: find several such operators or placements whose
nonzero augmentations have sublinear total logarithmic height.

## 5. Rigorous obstruction: every boundary-blind annihilator has augmentation zero

Let

\[
 K=\mathbb Q(M,r),\qquad K\langle S\rangle,\qquad Sr=(r+1)S.
\]

Consider any global recurrence operator

\[
 P=\sum_{i=0}^s a_i(M,r)S^i\in K\langle S\rangle
\]

which annihilates the uncancelled sequence \(\widehat E_r\) for all
sufficiently large \(r\).  By (2.9), for all sufficiently large \(r\),

\[
 \widehat E_{r+i}=A_M\ne0.
\]

Hence

\[
 0=P\widehat E_r
 =A_M\sum_{i=0}^s a_i(M,r).
\]

The rational function \(\sum_i a_i(M,r)\) vanishes at infinitely many
integers \(r\), so it is identically zero.  Thus

\[
 \boxed{P(1)=0.}
\tag{5.1}
\]

Right division by the monic operator \(S-1\) now gives

\[
 \boxed{P=Q(S-1)\quad\text{for some }Q\in K\langle S\rangle.}
\tag{5.2}
\]

Equivalently,

\[
 \operatorname{Ann}(\widehat E)
 \subset K\langle S\rangle(S-1).
\tag{5.3}
\]

The right side is a left ideal.  Consequently every left combination of any
number of global fixed-ray annihilators still has the factor \(S-1\).  In
particular there is no Ore Bezout identity of the form

\[
 U_1P_1+\cdots+U_tP_t=\sigma(M,r)\ne0
\tag{5.4}
\]

inside this module.  Applying the augmentation map to (5.4) would give
\(0=\sigma\).

This applies exactly to the boundary-blind route suggested by Section 60:
creative telescope each fixed ray, take holonomic sums and Bernstein transforms,
and then form gcds/Bezout combinations of the resulting global operators.  The
operators may be nontrivial and of bounded order, but after the terminal
transform they all annihilate the nonzero constant tail (2.9), so they all lose
the distinguished additive scalar needed in (4.5).

### Why growing \(J=o(M)\) does not reach the missing correction

The target packet uses

\[
 r\in[r_*-J,r_*],
 \qquad r_*=\left\lfloor\frac{M-1}{2}\right\rfloor.
\]

The first index at which \(\widehat E\) differs from the polynomial sequence
\(E^\sharp\) is \(M+1\).  The exact gap is

\[
 M+1-r_*=\left\lfloor\frac M2\right\rfloor+2.
\tag{5.5}
\]

Thus, for every \(J=o(M)\), the whole packet remains separated from the
boundary correction by \((1/2+o(1))M\) shifts.  Merely adding more local
recurrence rows cannot see the term \(-A_Mz^{M+1}\) in (2.6).  To use that
term directly requires either

* a functional of width at least \(\lfloor M/2\rfloor+2\), or
* a genuinely boundary-sensitive identity which imports the terminal
  correction without being an annihilator of \(\widehat E\).

The first option is incompatible with the requested \(J=o(M)\).  The second is
not ruled out, but it is new arithmetic input, not a consequence of the
existing fixed-order ray recurrences.

## 6. Consequence for the requested gcd

Let

\[
 g_J=\gcd(F_0,\ldots,F_J).
\]

The argument above blocks the natural linear holonomic route to the part of
\(g_J\) coprime to \(b_M\): every useful target prime is in that part by
(4.4), but every boundary-blind annihilator has zero augmentation and therefore
yields no target-selective scalar.

There is also a separate issue for the *full* gcd.  Even if a new
nonzero-augmentation identity bounded all primes not dividing \(b_M\), one
would still need to control

\[
 \gcd\bigl(b_M,F_0,\ldots,F_J\bigr).
\tag{6.1}
\]

Sections 61--63 show that distinguished first-cell state content can be real;
recurrence primitivity alone does not bound (6.1).  Section 61.15 only proves
that actual top-half target primes do not lie in this state-content component.
Therefore a proof of the literal estimate
\(\log g_J=o(M)\) needs two inputs:

1. a boundary-sensitive, nonzero-augmentation certificate for the
   \(b_M\)-coprime part;
2. a separate distinguished-state bound for (6.1).

The exact finite \(J=4\) collapses are compatible with this verdict.  They show
that the evaluated integers have strong arithmetic cancellation.  They do not
produce a uniform nonzero-augmentation relation in the global fixed-ray Ore
module.

## 7. Dependency-free exact audit code

The following standard-library Python script checks, with exact integers:

* the first-cell ray reconstruction;
* the terminal transform (1.3);
* the boundary formula (3.1) and adjacent identity (3.3);
* the polynomial identity (2.6);
* the nonzero constant tail (2.9);
* the lower bound (2.10);
* the stated target divisibility for the first four terminal shifts in a finite
  audit range.

It deliberately distinguishes the actual first-cell shell from the fixed-ray
extension outside the first cell.

```python
#!/usr/bin/env python3
"""Exact audit for the Q5935 terminal-carrier identities.

Only Python's standard library is used.
"""

from functools import lru_cache
from math import comb


def C(n, k):
    return comb(n, k) if 0 <= k <= n else 0


# Representatives and multiplicities under y/z interchange.
# These are the 21 nonzero lattice points of P in 14 classes.
RAY_CLASSES = (
    ((-1, -1, -1), 1),
    ((-1, -1, 0), 2),
    ((-1, -1, 1), 2),
    ((-1, 0, 0), 1),
    ((-1, 0, 1), 2),
    ((-1, 1, 1), 1),
    ((0, -1, -1), 1),
    ((0, -1, 0), 2),
    ((0, -1, 1), 2),
    ((0, 0, 1), 2),
    ((0, 1, 1), 1),
    ((1, 0, 0), 1),
    ((1, 0, 1), 2),
    ((1, 1, 1), 1),
)
assert sum(multiplicity for _, multiplicity in RAY_CLASSES) == 21


@lru_cache(maxsize=None)
def apery(moment):
    return sum(
        C(moment, t) ** 2 * C(moment + t, t) ** 2
        for t in range(moment + 1)
    )


@lru_cache(maxsize=None)
def ray_value(moment, q, point):
    """c_M((M-q)*point), using the one-fold coefficient formula."""

    u, v, w = point
    node = moment - q
    return sum(
        C(moment, t)
        * C(moment, t - node * u)
        * C(2 * moment - t, moment - node * v)
        * C(2 * moment - t, moment - node * w)
        for t in range(moment + 1)
    )


@lru_cache(maxsize=None)
def ray_correction(moment, q):
    return sum(
        multiplicity * ray_value(moment, q, point)
        for point, multiplicity in RAY_CLASSES
    )


@lru_cache(maxsize=None)
def shell_fast(moment, node):
    """The exact shell C_M(node)."""

    assert 1 <= node <= moment
    quotient = moment // node
    out = 0
    for t in range(moment + 1):
        base = moment - t
        x_packet = sum(
            C(moment, base + node * u)
            for u in range(-quotient, quotient + 1)
        )
        yz_packet = sum(
            C(2 * moment - t, base + node * v)
            for v in range(-quotient, quotient + 1)
        )
        out += C(moment, t) * x_packet * yz_packet**2
    return out


def terminal_carrier(moment, r):
    """Phi_r = G_{M-r,r}(C_M)."""

    assert 0 <= r <= (moment - 1) // 2
    d = moment - r
    return sum(
        (-1) ** i
        * C(d + i, i)
        * C(moment + 1, r - i)
        * shell_fast(moment, d + i)
        for i in range(r + 1)
    )


def terminal_transform(moment, r):
    """Right side of (1.3), plus b_M."""

    return apery(moment) + sum(
        (-1) ** (r - q)
        * C(moment - q, r - q)
        * C(moment + 1, q)
        * ray_correction(moment, q)
        for q in range(r + 1)
    )


def boundary_from_shell(moment, r):
    """Delta^r C_M(M-r), evaluated from actual first-cell shells."""

    return sum(
        (-1) ** s
        * C(r, s)
        * shell_fast(moment, moment - s)
        for s in range(r + 1)
    )


def boundary_from_rays(moment, r):
    """The zero-surplus CT formula (3.1)."""

    out = apery(moment) if r == 0 else 0  # the kappa=0 ray
    for point, multiplicity in RAY_CLASSES:
        out += multiplicity * sum(
            (-1) ** s
            * C(r, s)
            * ray_value(moment, s, point)
            for s in range(r + 1)
        )
    return out


def add_bernstein_term(poly, coefficient, q, power):
    """Add coefficient*z^q*(1-z)^power to a coefficient list."""

    degree = q + power
    if len(poly) <= degree:
        poly.extend([0] * (degree + 1 - len(poly)))
    for i in range(power + 1):
        poly[q + i] += coefficient * (-1) ** i * C(power, i)


def normalized(poly):
    out = list(poly) or [0]
    while len(out) > 1 and out[-1] == 0:
        out.pop()
    return out


def multiply_by_one_minus_z(poly):
    out = [0] * (len(poly) + 1)
    for i, value in enumerate(poly):
        out[i] += value
        out[i + 1] -= value
    return normalized(out)


def E_polynomial(moment):
    """The fixed-ray Bernstein polynomial in (2.3)."""

    out = [0] * (moment + 1)
    for q in range(moment + 1):
        add_bernstein_term(
            out,
            C(moment + 1, q) * ray_correction(moment, q),
            q,
            moment - q,
        )
    return out


def N_polynomial(moment):
    """The CT numerator N_M(z) in (2.4), expanded exactly."""

    out = [0] * (moment + 2)
    for point, multiplicity in RAY_CLASSES:
        for q in range(moment + 2):
            add_bernstein_term(
                out,
                multiplicity
                * C(moment + 1, q)
                * ray_value(moment, q, point),
                q,
                moment + 1 - q,
            )
    return out


def primes_up_to(limit):
    out = []
    for p in range(2, limit + 1):
        if all(p % d for d in range(2, int(p**0.5) + 1)):
            out.append(p)
    return out


def audit_identities(max_moment=16):
    for moment in range(2, max_moment + 1):
        r_star = (moment - 1) // 2

        # First-cell shell = origin plus the 21 fixed nonzero rays.
        for q in range(r_star + 1):
            assert (
                shell_fast(moment, moment - q)
                == apery(moment) + ray_correction(moment, q)
            )

        for r in range(r_star + 1):
            # The constant kernel in (1.3) has sum one.
            assert sum(
                (-1) ** (r - q)
                * C(moment - q, r - q)
                * C(moment + 1, q)
                for q in range(r + 1)
            ) == 1

            assert terminal_carrier(moment, r) == terminal_transform(moment, r)
            assert boundary_from_shell(moment, r) == boundary_from_rays(moment, r)

            if r >= 1:
                assert (
                    terminal_carrier(moment, r)
                    - terminal_carrier(moment, r - 1)
                    == (-1) ** r
                    * C(moment + 1, r)
                    * boundary_from_shell(moment, r)
                )

        # Check (1-z)E = N - A*z^(M+1).
        E = E_polynomial(moment)
        N = N_polynomial(moment)
        A = sum(
            multiplicity * ray_value(moment, moment + 1, point)
            for point, multiplicity in RAY_CLASSES
        )
        assert sum(N) == A  # N_M(1)=A_M

        rhs = list(N)
        rhs[moment + 1] -= A
        assert normalized(multiply_by_one_minus_z(E)) == normalized(rhs)

        # Coefficients of N/(1-z): E_0,...,E_M,A,A,...
        running = 0
        for r in range(moment + 5):
            if r < len(N):
                running += N[r]
            expected = E[r] if r <= moment else A
            assert running == expected

        # A_M contains c_M(-1,0,0), with the explicit positive contribution.
        assert A >= 4 * moment * 5 ** (moment - 1)


def audit_targets(limit=110):
    """Finite exact audit of the J=4 target-carrier assertion."""

    records = 0
    primes = primes_up_to(limit)
    for n in range(10, limit + 1):
        moment = n - 1
        d0 = moment // 2 + 1
        r_star = moment - d0
        J = 4
        if r_star < J:
            continue

        for p in primes:
            if p > n or p - 1 < d0 + J:
                continue
            if apery(n - p) % p != 0:
                continue

            for j in range(J + 1):
                assert terminal_carrier(moment, r_star - j) % p == 0

            if p > 5:
                assert apery(moment) % p != 0
            records += 1
    return records


def main():
    audit_identities()
    records = audit_targets()
    print("TARGET_RECORDS", records)
    print("Q5935_TERMINAL_CARRIER_AUDIT=PASS")


if __name__ == "__main__":
    main()
```

## 8. Precise remaining opening

The fixed-ray recurrence route is exhausted only in the following precise
sense: no global linear Ore identity annihilating the uncancelled extension can
have nonzero augmentation.  This does **not** rule out:

* a boundary-sensitive identity which explicitly uses the correction
  \(A_Mz^{M+1}\);
* a nonlinear resultant/Casoratian special to the distinguished Apéry state;
* a direct arithmetic bound for the target-selected part of such a boundary
  invariant;
* an independent bound for the state-content gcd (6.1).

A useful next certificate must therefore exhibit, explicitly, one of the
following:

\[
 \sum_{i=0}^{J(M)}a_i(M)F_i=b_M\Sigma_M,
 \qquad \Sigma_M\ne0,
\tag{8.1}
\]

with all target-safe singular factors and \(\log|\Sigma_M|=o(M)\), or a
nonlinear analogue whose target-selected radical has that bound.  Formula
(2.6) says exactly where such a nonzero \(\Sigma_M\) must come from: it cannot
come from the fixed-ray annihilator ideal; it must come from the terminal
correction or from new distinguished-state arithmetic.
