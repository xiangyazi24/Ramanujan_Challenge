# Mixed Dwork collision audit: the exact trace formula, the category mismatch, and the surviving target

## 0. Verdict

The new reduction contains a real and useful bridge, but two corrections are essential.

1. [PROVED] Claims D1-D4 are correct. In particular, the companion coordinate disappears from every fixed-gap phase:

```text
Delta_(r,h)
  = b_r*c_(r+h) - b_(r+h)*c_r
  = N_h(r) / product_(j=1)^h (r+j)^3.
```

Thus a fixed-h exponential sum is governed by a rank-one Dwork isocrystal attached to one explicit rational function. The rank-four mixed crystal is not needed for that fixed-h trace formula.

2. [CORRECTION] D5 conflates two different quantities. The paper's sigma-ladder quantity

```text
Q_p(H) = sum_r binom(d_H(r),2)
```

counts two return gaps from the same base point, hence triple collisions. By contrast,

```text
sum_(h<=H) C_h = sum_r d_H(r)
```

counts ordinary collision pairs. There is no general inequality

```text
Q_p(H) <= sum_(h<=H) C_h.
```

Nevertheless, [COINC] at H=p^(2/3) still implies the new bound

```text
F_p << p^(4/3),
```

but through the already proved block-energy inequality, not through the sigma ladder.

3. [CORRECTION] The generic curve

```text
Delta_(r,h) = Delta_(r',h')
```

has bidegree at most (3h,3h'). Its generic arithmetic genus is O(h*h'), not O(h+h'). After removal of actual components, ordinary per-pair Weil therefore gives an error of size O(h*h'*sqrt(p)) in the absence of an additional genus collapse. Summing this absolute error over h,h'<=H gives O(H^4*sqrt(p)). To reach [COINC], whose admissible total error is O(pH), this only reaches H<=p^(1/6). It has no overlap with the range H>p^(1/3) where [COINC] would improve the trivial H^2 bound.

4. [NEGATIVE] The index shift n -> n+h is not the h-th power of crystalline Frobenius. Frobenius sends t to t^p and controls p-adic digit/depth relations. The h-shift is the h-th iterate of the nonautonomous translation difference cocycle over r -> r+1. These are different operators in different categories.

5. [NEGATIVE] Ordinary Frobenius traces of the rank-four mixed extension do not see the extension class. Trace is additive in exact sequences and depends only on the semisimplification. Hence the mixed normal-function entry containing c cannot enter an ordinary Lefschetz trace merely because the rank-four object exists.

6. [POSITIVE] There is an exact cohomological object that counts all coincidences at once. It is the fiber product of the disjoint union of the fixed-h rational maps, or equivalently the p-adic Fourier transform of their compactly supported direct image. This realizes D3 as geometric Plancherel. The missing theorem is a growing-family Fourier orthogonality and conductor-compression statement. Standard rigid cohomology supplies the trace formula, but not that compression.

There is therefore no unconditional exponent improvement in this answer. The precise surviving target is identified below.

## 1. Audit of D1-D4

### 1.1 D1 is an exact identity

Fix r and put

```text
z_h = Delta_(r,h).
```

The recurrence in the second index gives

```text
(r+h+1)^3*z_(h+1)
  = P(r+h)*z_h - (r+h)^3*z_(h-1).
```

The initial values are

```text
z_0 = 0,
z_1 = b_r*c_(r+1) - b_(r+1)*c_r
    = -W_(r+1)
    = 1/(r+1)^3.
```

Let

```text
D_h(r) = product_(j=1)^h (r+j)^3,
A_h(r) = D_h(r)*z_h.
```

Then

```text
A_0 = 0,
A_1 = 1,
A_2 = P(r+1),
A_(h+1) = P(r+h)*A_h - (r+h)^6*A_(h-1).
```

These are exactly the initial values and recurrence defining N_h. Hence

```text
A_h(r) = N_h(r)
```

and therefore

```text
Delta_(r,h) = N_h(r)/D_h(r).                  (1.1)
```

This proof works over Q as a rational-function identity and over F_p on the stated nonwrapping regular window.

### 1.2 D2 is exact additive orthogonality

Let

```text
S_H = {(r,h): 1<=h<=H, 1<=r<=M-h},
s_H = #S_H.
```

For x in F_p,

```text
1_(x=0) = (1/p)*sum_(t in F_p) e_p(t*x).
```

Summing over S_H gives

```text
sum_(h<=H) C_h
  = s_H/p + (1/p)*sum_(t!=0) B_t(H).           (1.2)
```

### 1.3 D3 is exact Parseval

Expanding the square and summing over t gives

```text
sum_(t in F_p) |B_t(H)|^2 = p*N_coinc(H).
```

The t=0 term is s_H^2, so

```text
sum_(t!=0) |B_t(H)|^2
  = p*N_coinc(H) - s_H^2.                      (1.3)
```

### 1.4 D4 follows with the stated scale

Assume

```text
N_coinc(H) <= s_H^2/p + K*s_H.                 (COINC)
```

Then (1.3) gives

```text
sum_(t!=0) |B_t(H)|^2 <= p*K*s_H.
```

By Cauchy-Schwarz in (1.2),

```text
sum_(h<=H) C_h
  <= s_H/p
     + (1/p)*sqrt((p-1)*p*K*s_H)
  <= s_H/p + sqrt(K*s_H).                       (1.4)
```

Since s_H is asymptotic to pH in the relevant range,

```text
sum_(h<=H) C_h << H + sqrt(K*p*H).              (1.5)
```

This part of the reduction is fully correct.

## 2. The corrected route from COINC to p^(4/3)

The exact energy identity and the proved block argument give, for a block length L,

```text
F_p
  <= ceil(M/L)
     * (M + 2*sum_(1<=h<L) C_h).                (2.1)
```

Apply (1.5) with H=L. For absolute K and L<=p,

```text
F_p
  << (p/L)*(p + L + sqrt(pL))
  << p^2/L + p^(3/2)/sqrt(L) + p.               (2.2)
```

For L=p^beta with beta<1, the first term dominates the square-root term. Therefore

```text
COINC at L=p^beta  ==>  F_p << p^(2-beta).       (2.3)
```

In particular,

```text
COINC at L=p^(2/3)  ==>  F_p << p^(4/3).         (2.4)
```

This is the desired new theorem once COINC is proved.

The same formula records the stronger endpoints:

```text
COINC at L=p^(1-epsilon)
  ==> F_p << p^(1+epsilon),

COINC at L comparable to p
  ==> F_p << p.
```

Thus the COINC target is stronger and cleaner than the erroneous D5 bridge. It does not need the sigma ladder.

The precise error in D5 is the following. In the paper,

```text
d_H(r) = #{1<=h<=H: pi(r)=pi(r+h)},
Q_p(H) = sum_r binom(d_H(r),2).
```

A single base point with d_H(r)=D contributes D to sum_h C_h but D(D-1)/2 to Q_p(H). Hence no inequality Q_p(H)<=sum_h C_h can hold uniformly.

## 3. The actual geometry of the difference curves

Put

```text
f_h(r) = Delta_(r,h)
       = N_h(r)/D_h(r),
D_h(r) = product_(j=1)^h (r+j)^3.
```

The equation f_h(r)=f_h'(r') is

```text
N_h(r)*D_h'(r') - N_h'(r')*D_h(r) = 0.          (3.1)
```

Because

```text
deg N_h = 3(h-1),
deg D_h = 3h,
```

its bidegree in P^1 x P^1 is at most

```text
(3h,3h').                                        (3.2)
```

A curve of bidegree (a,b) has arithmetic genus (a-1)(b-1). Thus the available generic upper scale is

```text
g_a = O(h*h'),                                   (3.3)
```

not O(h+h'). Singularities may lower the geometric genus, but that lowering is an additional theorem and has not been proved for this family.

After removing the diagonal component when h=h', and after removing any other genuine common-composition component, a componentwise Weil estimate has the generic scale

```text
#X_(h,h')(F_p) = main term + O(h*h'*sqrt(p)).     (3.4)
```

Summing absolute errors over h,h'<=H gives

```text
O(H^4*sqrt(p)).                                  (3.5)
```

There are two different thresholds to keep separate.

First, (3.5) is smaller than the total random main term pH^2 only for H<p^(1/4).

Second, COINC permits only an excess O(s_H)=O(pH). Requiring (3.5)<=pH gives

```text
H <= p^(1/6).                                    (3.6)
```

But (1.5) improves the trivial estimate sum_h C_h=O(H^2) only once H>p^(1/3). Hence ordinary per-pair Weil has no useful overlap with the desired range.

## 4. An exact pole formula that should drive the next computation

The continuant splits when one edge product vanishes. Let m=h-1 and 0<=k<=m. At s=-k,

```text
U_m(-k) = U_k(-k)*U_(m-k)(0).
```

Using continuant reflection and U_j(0)=(j!)^3*b_j,

```text
U_m(-k)
  = (-1)^k*(k!)^3*b_k*((m-k)!)^3*b_(m-k).        (4.1)
```

Since N_h(r)=U_(h-1)(r+1), take k=j-1. For 1<=j<=h,

```text
N_h(-j)
  = (-1)^(j-1)*((j-1)!)^3*b_(j-1)
    *((h-j)!)^3*b_(h-j).                         (4.2)
```

The coefficient of (r+j)^3 in D_h(r) is

```text
(-1)^(j-1)*((j-1)!)^3*((h-j)!)^3.
```

Therefore the cubic principal coefficient is exactly

```text
f_h(r)
  = b_(j-1)*b_(h-j)/(r+j)^3
    + lower pole terms at r=-j.                  (4.3)
```

Over Q all h poles are cubic. Modulo p, the pole at -j can drop precisely when the displayed Apéry product vanishes, followed by possible further cancellation in the lower principal parts.

Formula (4.3) is a new concrete local invariant of the family. It is the first item to feed into p-adic local Fourier transform and conductor calculations.

## 5. Three different operators that must not be identified

### 5.1 The pure differential F-isocrystal

The order-three Picard-Fuchs module attached to B(t) is a differential module on the geometric t-line. Its Frobenius is semilinear over

```text
t -> t^p.
```

It controls the p-adic variation of the period and the base-p digit/depth tower.

### 5.2 The rank-four mixed extension

Because L(C)=t, the state

```text
Y(t) = (C, theta*C, theta^2*C, t)^T
```

satisfies

```text
theta*Y = G(t)*Y,
theta(Phi) = G*Phi - p*Phi*G(t^p).
```

The block form of G gives an exact sequence

```text
0 -> M_Apery -> M_mix -> L_source -> 0.          (5.1)
```

This is the correct p-adic normal-function or syntomic-regulator category for c.

### 5.3 The translation difference module

The recurrence itself is a difference equation over the clock variable r. With tau(r)=r+1,

```text
V(tau r) = A(r)*V(r),
A^[h](r) = A(r+h-1)*...*A(r).                    (5.2)
```

The product A^[h](r), equivalently G_h(r), is the h-step transfer matrix. Thus h is an iterate of tau, not an iterate of absolute Frobenius.

The maps are categorically distinct:

```text
absolute Frobenius: r -> r^p,
clock translation:  r -> r+1.
```

On F_p-points, r^p=r, so absolute Frobenius does not advance the clock at all. Consequently the proposed identification

```text
h-shift = h-th power of crystalline Frobenius
```

is false.

A future low-rank realization of the growing h-family would have to be a tau-difference module, a skew-product transfer operator, or a hybrid object carrying both tau and Frobenius. It is not the existing rank-four F-isocrystal by itself.

## 6. The exact fixed-h Dwork and Monsky-Washnitzer setup

This is the most tractable version and is already standard once D1 is known.

Fix 1<=h<=p-3. Define

```text
Q_h(r) = product_(j=0)^(h+1) (r+j),
X_h = Spec F_p[r,Q_h(r)^(-1)].                    (6.1)
```

The F_p-points of X_h are exactly

```text
r = 1,...,p-h-2,
```

which is the required nonwrapping window. The two extra deleted points 0 and -h-1 impose the endpoint restriction; the points -1,...,-h remove the poles.

Let K_0=Q_p, choose varpi with

```text
varpi^(p-1) = -p,
```

and let K contain varpi and the values of the chosen nontrivial additive character psi. Let L_psi be the rank-one Dwork overconvergent F-isocrystal on A^1. For t in F_p^x define

```text
E_(h,t) = (t*f_h)^* L_psi                         (6.2)
```

on X_h.

Let

```text
A_h^dagger = K<r,Q_h(r)^(-1)>^dagger.
```

The corresponding twisted Monsky-Washnitzer complex is

```text
A_h^dagger
  --D_(h,t)--> A_h^dagger*dr,

D_(h,t) = d/dr + varpi*[t]*f_h'(r),               (6.3)
```

where [t] is the Teichmuller lift. A compatible Frobenius lift r->r^p acts through the Dwork multiplier

```text
Theta_(h,t)(r)
  = exp(varpi*([t]*f_h(r)-[t]^p*f_h(r^p))),       (6.4)
```

up to the harmless opposite-sign convention for L_psi. Equations (6.3)-(6.4) are the concrete connection and Frobenius operators to implement.

The compactly supported rigid trace formula is

```text
S_h(t)
  := sum_(r=1)^(p-h-2) psi(t*Delta_(r,h))

   = sum_i (-1)^i
       Tr(Frob_p |
          H^i_rig,c(X_h/K,E_(h,t))).              (6.5)
```

By D1 this is exactly the desired r-sum, not a surrogate.

For all sufficiently good p, E_(h,t) is geometrically nontrivial, so H_c^0 and H_c^2 vanish and

```text
S_h(t)
  = -Tr(Frob_p | H^1_rig,c(X_h/K,E_(h,t))).       (6.6)
```

There are h+3 boundary points in the compactification: 0,-1,...,-h,-h-1 and infinity. Only -1,...,-h are poles of f_h. Grothendieck-Ogg-Shafarevich gives the exact dimension formula

```text
dim H_c^1
  = h+1 + sum_(j=1)^h Swan_(-j)(E_(h,t)).         (6.7)
```

For p>3 and no cancellation at the poles, (4.3) gives Swan_(-j)=3, hence

```text
dim H_c^1 = 4h+1.                                (6.8)
```

In every case,

```text
dim H_c^1 <= 4h+1.                               (6.9)
```

Purity for overconvergent F-isocrystals then yields the standard fixed-h estimate

```text
|S_h(t)| <= (4h+1)*sqrt(p).                       (6.10)
```

This is the crystalline form of the usual fixed-h Weil bound.

The important negative conclusion is that fixed-h cohomology naturally has dimension linear in h. Therefore weight theory alone cannot improve (6.10) to o(h*sqrt(p)). Such an improvement would require cancellation inside the trace or additional monodromy, not merely the existence of rigid cohomology.

## 7. The exact object that counts all coincidences at once

### 7.1 Fiber-product formulation

Let

```text
Z_H = disjoint_union_(1<=h<=H) X_h,
```

and define

```text
f_H: Z_H -> A^1
```

by f_H|X_h=f_h. Form the fiber product

```text
Y_H = Z_H x_(A^1) Z_H.                           (7.1)
```

Then, with the stated windows,

```text
N_coinc(H) = #Y_H(F_p).                          (7.2)
```

Thus the rigid Lefschetz formula gives the exact all-collision identity

```text
N_coinc(H)
  = sum_i (-1)^i
      Tr(Frob_p | H^i_rig,c(Y_H/K)).              (7.3)
```

This answers the literal question of which cohomology computes all collisions. However, Z_H is a disjoint union of H objects whose complexity grows with h. Formula (7.3) is exact but, without a compression in the h-direction, is only a repackaging of the H^2 pairwise curves.

### 7.2 Fourier formulation

Work in the derived category of overholonomic arithmetic D-modules with Frobenius, or an equivalent constructible overconvergent category supporting the six operations. Put

```text
K_h = R(f_h)_! 1_(X_h),
K_H = direct_sum_(h<=H) K_h.                     (7.4)
```

Let

```text
F_H = FT_psi(K_H)                                (7.5)
```

be the p-adic Fourier transform, with the standard cohomological shift. Its Frobenius trace at t is, up to the fixed Fourier sign,

```text
Tr(Frob_t | (F_H)_t) = B_t(H).                   (7.6)
```

Let iota(t)=-t and put

```text
G_H = F_H tensor iota^*F_H.                      (7.7)
```

Under a complex embedding of the Frobenius traces,

```text
Tr(Frob_t | (G_H)_t)
  = B_t(H)*B_(-t)
  = |B_t(H)|^2.                                  (7.8)
```

The global rigid trace formula therefore gives geometric Plancherel:

```text
sum_(t in F_p) |B_t(H)|^2
  = sum_i (-1)^i
      Tr(Frob_p | H^i_rig,c(A^1/K,G_H))
  = p*N_coinc(H).                                (7.9)
```

Subtracting the t=0 term B_0(H)^2=s_H^2 recovers D3 exactly.

After the usual Verdier-dual and Tate normalization, G_H is the endomorphism/correlation object of F_H. This is the correct cohomological location of the diagonal, common-constituent, and cross-family obstructions.

## 8. What cohomological statement would actually prove COINC

Define F_h=FT_psi(K_h), so F_H is their direct sum. The needed package is not simply purity. A sufficient statement is the following.

### [TARGET-FOURIER-COINC]

For all H in the desired range, after removing the explicit uniform, endpoint, and forced mirror constituents:

```text
(a) each F_h is geometrically irreducible;

(b) Hom_geom(F_h,F_h')=0 for h!=h',
    except for an explicitly classified O(H) list;

(c) the total non-Tate Frobenius trace in
    H_c^*(A^1,F_H tensor iota^*F_H)
    is O(p^2*H).
```

Then (7.9) gives

```text
p*N_coinc(H)-s_H^2 = O(p^2*H).
```

Since s_H is comparable to pH,

```text
N_coinc(H)
  <= s_H^2/p + O(pH)
  =  s_H^2/p + O(s_H),                           (8.1)
```

which is COINC.

The roles of the clauses are distinct.

Clauses (a)-(b) control top-degree Tate classes. For pairwise nonisomorphic irreducible summands, only the H scalar endomorphisms survive, giving the permitted diagonal scale O(p^2 H).

Clause (c) controls the lower-degree error. It does not follow from (a)-(b). The direct sum has

```text
sum_(h<=H) rank(F_h) = O(H^2),
rank(End(F_H)) = O(H^4)
```

at the naive level. Standard conductor bounds therefore remain far too large. One must prove either a genuine conductor compression, cancellation of the total Frobenius trace across h,h', or a bounded-rank difference-module realization of the entire h-family.

This is the precise remaining gap.

## 9. Why the mixed extension is not a weight explanation for p^(3/2)

There are three separate reasons.

### 9.1 The record is an upper bound, not an observed p^(3/2) main term

The proved statement is

```text
F_p <= 2*sqrt(3)*p^(3/2)*(1+o(1)).
```

The project computations instead place F_p on a linear scale. Therefore there is no established p^(3/2) asymptotic that needs to be explained by competing weights.

### 9.2 Extension classes do not create new Frobenius eigenvalues

For an exact sequence of Frobenius modules

```text
0 -> A -> E -> B -> 0,
```

Frobenius on E is block upper triangular. Hence

```text
Tr(Frob|E) = Tr(Frob|A)+Tr(Frob|B),
```

and the eigenvalue multiset is the union of those on A and B. The extension class appears in off-diagonal matrix entries and periods, not in the ordinary character.

Thus even if the graded pieces of M_mix have different motivic weights, their ordinary trace does not contain an interference term encoding c.

### 9.3 D1 moves the fixed-h phase to a pure rank-one exponential object

Once

```text
Delta_(r,h)=f_h(r),
```

the relevant fixed-h cohomology is the rank-one Dwork twist E_(h,t). Its H_c^1 has weight-one square-root size and dimension O(h). The existing p^(3/2) bound comes from combining:

```text
C_h <= O(h),
block Cauchy-Schwarz,
optimization at block length about sqrt(p).
```

It is a degree/conductor-growth barrier, not interference between weights in the mixed rank-four crystal.

The useful weight statement occurs one level later, in the Fourier second moment. With the standard unnormalized Fourier convention, the diagonal Tate classes in the correlation object contribute at the allowed p^2 H scale, while the non-Tate part must have total trace no larger than that. Vanishing of cross-Hom classes plus control of the remaining conductor/trace would yield COINC and hence p^(4/3).

For stronger goals:

```text
TARGET-FOURIER-COINC up to H=p^(2/3)
  ==> F_p << p^(4/3),

TARGET-FOURIER-COINC up to H=p^(1-epsilon)
  ==> F_p << p^(1+epsilon),

TARGET-FOURIER-COINC up to H comparable to p
  ==> F_p << p.
```

## 10. The two-index generating function is geometric, but not in the needed sense

Let

```text
B(z)=sum_(n>=0) b_n*z^n,
C(z)=sum_(n>=0) c_n*z^n.
```

There is an exact constant-term identity

```text
sum_(r,h>=0) Delta_(r,h)*x^r*y^h

  = CT_z [
      ( C(z)*B(x/z) - B(z)*C(x/z) )
      /(1-y/z)
    ].                                             (10.1)
```

Indeed, the constant term in the first product imposes n=r+h and gives b_r*c_(r+h); the second gives b_(r+h)*c_r.

Identity (10.1) is a Hadamard/diagonal construction. In holonomic or arithmetic D-module language it can be represented by external tensor product followed by pullback and direct image. If B is a pure period and C is a mixed normal function, this gives a legitimate geometric origin for the bivariate generating series.

But it does not yet produce the finite-field exponential sum. The reasons are:

```text
- r and h are coefficient indices, not geometric F_p-point coordinates;
- coefficient extraction is a Cartier/diagonal operation;
- applying psi to a coefficient is nonlinear;
- the range h<=H is a growing discrete truncation.
```

Thus a geometric realization of (10.1) does not automatically turn B_t(H) into the trace function of a bounded-conductor object. The missing operation is precisely a low-complexity bridge from coefficient index to clock translation.
