# P2.2: an independent finite-moment certificate for harmonic concentration

## Executive verdict

There is a clean route which is genuinely independent of the ratio-tail proof.
Use the adjacent-ratio identity only once, to derive a **finite birth–death (Stein) identity**. With

\[
q_n=\sum_{k=0}^n w(n,k),
\qquad
G_n(k)=k^3-(n-k)^2,
\]

one obtains the explicit estimate

\[
\boxed{
\sum_{k=0}^n w(n,k)G_n(k)^2
\le 81\,n^3\sqrt n\;q_n
\qquad(n\ge1).
}
\tag{A}
\]

Consequently

\[
\boxed{
\left(
\frac{\sum_{k=0}^n w(n,k)|G_n(k)|}{n^2q_n}
\right)^2
\le \frac{81}{\sqrt n},
}
\tag{B}
\]

and hence

\[
\frac{1}{q_n}\sum_{k=0}^n w(n,k)
\left|\frac{k^3}{n^2}-\frac{(n-k)^2}{n^2}\right|
\longrightarrow0.
\]

This is the requested polynomial saddle concentration. It can replace the entire geometric-tail layer in the other proof. The separately developed harmonic/central-set transfer only needs the theorem `(B)` (or its Chebyshev corollary); it does not need the adjacent ratio again.

The constant `81` is deliberately loose. Every identity and inequality below was checked algebraically; the exact polynomial identities were also independently expanded in a CAS. No asymptotic or unverified special-function claim is used.

# 1. Put the adjacent ratio in cross-multiplied form

Throughout this note, casts to `ℝ` are implicit in displayed formulae. Define

\[
A_n(k)=(2n+k+2)(n-k)^2,
\qquad
B_n(k)=(2n+k)k^3.
\]

The given ratio is exactly equivalent, for `0 ≤ k < n`, to

\[
\boxed{A_n(k)w(n,k)=B_n(k+1)w(n,k+1).}
\tag{1}
\]

Indeed,

\[
B_n(k+1)=(2n+k+1)(k+1)^3.
\]

Use real subtraction in the auxiliary polynomials. This avoids `Nat.sub` in every later ring calculation:

```lean
private def birth22 (n k : ℕ) : ℝ :=
  (2 * (n : ℝ) + (k : ℝ) + 2) * ((n : ℝ) - (k : ℝ)) ^ 2

private def death22 (n k : ℕ) : ℝ :=
  (2 * (n : ℝ) + (k : ℝ)) * (k : ℝ) ^ 3

private def saddleErr22 (n k : ℕ) : ℝ :=
  (k : ℝ) ^ 3 - ((n : ℝ) - (k : ℝ)) ^ 2
```

The adapter from the already-proved quotient theorem should have the following shape:

```lean
lemma weight22_cross {n k : ℕ} (hk : k < n) :
    birth22 n k * weight22 n k =
      death22 n (k + 1) * weight22 n (k + 1) := by
  -- Rewrite the existing adjacent quotient theorem.
  -- Use `Nat.cast_sub hk.le`, positivity of all denominators,
  -- `field_simp`, then `ring`.
  ...
```

This is the last place where the explicit binomial/factorial formula is needed.

# 2. The finite Stein identity

For every function `f : ℕ → ℝ`, equation (1) telescopes to

\[
\boxed{
\sum_{k=0}^n w(n,k)
\left(
 A_n(k)(f(k+1)-f(k))
 +(A_n(k)-B_n(k))f(k)
\right)=0.
}
\tag{2}
\]

There are no boundary remainders:

\[
A_n(n)=0,
\qquad
B_n(0)=0.
\]

Equivalently,

\[
\sum_{k=0}^n w(n,k)A_n(k)f(k+1)
=
\sum_{k=0}^n w(n,k)B_n(k)f(k).
\tag{3}
\]

This should be the central reusable theorem in Lean:

```lean
lemma weight22_stein (n : ℕ) (f : ℕ → ℝ) :
    (∑ k in Finset.range (n + 1),
      weight22 n k *
        (birth22 n k * (f (k + 1) - f k) +
          (birth22 n k - death22 n k) * f k)) = 0 := by
  have hshift :
      (∑ k in Finset.range (n + 1),
          weight22 n k * birth22 n k * f (k + 1)) =
        ∑ k in Finset.range (n + 1),
          weight22 n k * death22 n k * f k := by
    -- Left side: `Finset.sum_range_succ`; the terminal term is zero.
    -- Right side: `Finset.sum_range_succ'`; the initial term is zero.
    -- Pair the remaining terms with `weight22_cross`.
    ...
  rw [← sub_eq_zero]
  calc
    _ =
      (∑ k in Finset.range (n + 1),
        weight22 n k * birth22 n k * f (k + 1)) -
      (∑ k in Finset.range (n + 1),
        weight22 n k * death22 n k * f k) := by
          rw [← Finset.sum_sub_distrib]
          apply Finset.sum_congr rfl
          intro k hk
          ring
    _ = 0 := sub_eq_zero.mpr hshift
```

The only Mathlib finite-sum APIs needed are

```lean
Finset.sum_range_succ
Finset.sum_range_succ'
Finset.sum_congr
Finset.sum_sub_distrib
```

plus `ring`.

# 3. The generating-polynomial differential equation

The same certificate has a compact generating-function form. Let

\[
W_n(z)=\sum_{k=0}^n w(n,k)z^k,
\qquad
\theta=z\frac{d}{dz}.
\]

Then coefficientwise equation (1) is exactly

\[
\boxed{
(2n+\theta)\theta^3 W_n(z)
=
z(2n+\theta+2)(n-\theta)^2W_n(z).
}
\tag{4}
\]

For a Lean proof it is shorter not to formalize `θ`. Record the equivalent finite-polynomial identity:

```lean

      birth22 n k * weight22 n k * z ^ k := by
```

Equation (4) is useful documentation, but all concentration estimates below are shorter from `(2)`.

# 4. An exact factorial-moment check

This subsection is not needed for the shortest proof of `(A)`, but it gives a strong independent check that the polynomial observable is the correct one.

Let

\[
s_n=\sum_{k=0}^n a(n,k),
\qquad
q_n=\sum_{k=0}^n w(n,k).
\]

The pointwise shift identities are

\[
k^3a(n,k)=n^2a(n-1,k-1),
\tag{5}
\]

and

\[
(n-k)^2a(n,k)=n^2a(n-1,k).
\tag{6}
\]

After shifting the finite sums, the linear factor in `w` gives

\[
\boxed{
\sum_{k=0}^n k^3w(n,k)
=n^2\bigl(q_{n-1}+3s_{n-1}\bigr),
}
\tag{7}
\]

\[
\boxed{
\sum_{k=0}^n (n-k)^2w(n,k)
=n^2\bigl(q_{n-1}+2s_{n-1}\bigr).
}
\tag{8}
\]

Thus

\[
\boxed{
\sum_{k=0}^n G_n(k)w(n,k)=n^2s_{n-1}.
}
\tag{9}
\]

Since `s_{n-1} ≤ s_n` and

\[
q_n\ge(2n+1)s_n,
\]

we get the exact one-sided mean estimate

\[
0\le \frac1{q_n}\sum_kG_n(k)w(n,k)
\le\frac{n^2}{2n+1}.
\tag{10}
\]

The general identity behind (7)–(8) is also neat. If `r+s≤n`, then

\[
\sum_k
 (k^{\underline r})^3((n-k)^{\underline s})^2w(n,k)
=
(n^{\underline{r+s}})^2
\left(q_{n-r-s}+(3r+2s)s_{n-r-s}\right).
\tag{11}
\]

Here `x^{\underline r}` is the descending factorial. Formula (11) follows by setting `j=k-r`; after cancelling factorials, the remaining linear factor differs from the one in `q_{n-r-s}` by exactly `3r+2s`.

For Lean, only (7) and (8) are worth formalizing. Use

```lean
Nat.choose_succ_right_eq
Nat.factorial_succ
Finset.sum_range_succ'
Nat.choose_le_choose
```

The general descending-factorial identity is mathematically exact but would add more cast and factorial-normalization work than it saves.

# 5. First moment bound: `E[K³] = O(n²)`

Set

\[
M_3=\sum_{k=0}^n k^3w(n,k).
\]

Taking `f=1` in `(2)` gives

\[
\sum_kB_n(k)w(n,k)=\sum_kA_n(k)w(n,k).
\tag{12}
\]

On the support `0≤k≤n`,

\[
B_n(k)=(2n+k)k^3\ge2n\,k^3,
\]

and

\[
A_n(k)\le(3n+2)n^2.
\]

Therefore

\[
\boxed{
2nM_3\le(3n+2)n^2q_n.
}
\tag{13}
\]

For `n≥1`, `3n+2≤5n`, so

\[
\boxed{M_3\le\frac52n^2q_n.}
\tag{14}
\]

# 6. Interpolation: `E[K²] = O(n√n)`

For every `x≥0` and `a>0`,

\[
\boxed{x^2\le a^2+\frac{x^3}{a}.}
\tag{15}
\]

Proof: if `x≤a`, use `x²≤a²`; if `a≤x`, use `x²≤x³/a`.

Take `a=√n`. For `n≥1`, `(√n)^2=n`, so summing (15) and using (14) gives

\[
\begin{aligned}
M_2
&:=\sum_kk^2w(n,k)\\
&\le nq_n+\frac{M_3}{\sqrt n}\\
&\le nq_n+\frac52n\sqrt n\,q_n\\
&\le\boxed{\frac72n\sqrt n\,q_n}.
\end{aligned}
\tag{16}
\]

This is where a square root enters. It is substantially easier in Lean than introducing an integer cube root, and its weaker exponent is still more than sufficient.

Reusable pointwise lemma:


# 7. Exact second-moment certificate

Now take `f(k)=G_n(k)` in the Stein identity.

Two pointwise polynomial identities are load-bearing:

\[
\boxed{
A_n(k)-B_n(k)
=2(n-k)^2-(2n+k)G_n(k),
}
\tag{17}
\]

and

\[
\boxed{
G_n(k+1)-G_n(k)=3k^2+k+2n.
}
\tag{18}
\]

Both are direct `ring` identities when `G`, `A`, and `B` use real subtraction.

Substituting (17)–(18) into `(2)` gives the exact finite identity

\[
\boxed{
\sum_{k=0}^n(2n+k)G_n(k)^2w(n,k)
=
\sum_{k=0}^n
\left[
2(n-k)^2G_n(k)
+A_n(k)(3k^2+k+2n)
\right]w(n,k).
}
\tag{19}
\]

Lean declarations:

```lean
lemma saddleErr22_succ (n k : ℕ) :
    saddleErr22 n (k + 1) - saddleErr22 n k =
      3 * (k : ℝ) ^ 2 + (k : ℝ) + 2 * (n : ℝ) := by
  simp [saddleErr22]
  ring

lemma drift22_eq (n k : ℕ) :
    birth22 n k - death22 n k =
      2 * ((n : ℝ) - (k : ℝ)) ^ 2 -
        (2 * (n : ℝ) + (k : ℝ)) * saddleErr22 n k := by
  simp [birth22, death22, saddleErr22]
  ring

lemma saddle_second_moment_exact (n : ℕ) :
    (∑ k in Finset.range (n + 1),
      weight22 n k *
        ((2 * (n : ℝ) + (k : ℝ)) * saddleErr22 n k ^ 2)) =
    ∑ k in Finset.range (n + 1),
      weight22 n k *
        (2 * ((n : ℝ) - (k : ℝ)) ^ 2 * saddleErr22 n k +
          birth22 n k *
            (3 * (k : ℝ) ^ 2 + (k : ℝ) + 2 * (n : ℝ))) := by
  have h := weight22_stein n (saddleErr22 n)
  -- Rewrite by `drift22_eq`, `saddleErr22_succ`, then `linear_combination h` or `linarith`.
  ...
```

No probability theory is involved: `(19)` is a finite polynomial identity certified by the adjacent relation.

# 8. Derivation of the explicit bound `(A)`

Let

\[
S_2=\sum_kG_n(k)^2w(n,k).
\]

For `n>0`, Young's inequality gives, pointwise,

\[
2(n-k)^2G_n(k)
\le nG_n(k)^2+\frac{(n-k)^4}{n}.
\tag{20}
\]

Since `2n+k≥2n`, equation (19) and (20) imply

\[
nS_2
\le
\frac1n\sum_k(n-k)^4w(n,k)
+
\sum_kA_n(k)(3k^2+k+2n)w(n,k).
\]

Hence

\[
S_2
\le
\frac1{n^2}\sum_k(n-k)^4w(n,k)
+
\frac1n\sum_kA_n(k)(3k^2+k+2n)w(n,k).
\tag{21}
\]

On the support,

\[
(n-k)^4\le n^4,
\]

\[
A_n(k)\le5n^3,
\]

and, since an integer `k≥0` satisfies `k≤k²`,

\[
3k^2+k+2n\le4k^2+2n.
\]

Using (16), the right side of (21) is at most

\[
\begin{aligned}
&n^2q_n
+20n^2M_2
+10n^3q_n\\
&\le n^2q_n
+70n^3\sqrt n\,q_n
+10n^3q_n\\
&\le81n^3\sqrt n\,q_n.
\end{aligned}
\]

This proves `(A)`.

The Young inequality can be proved without square roots:

```lean
lemma two_mul_le_mul_sq_add_sq_div

    2 * a * b ≤ c * a ^ 2 + b ^ 2 / c := by

  have hs2 : Real.sqrt c ^ 2 = c := Real.sq_sqrt hc.le
  field_simp [hs] at h ⊢
  nlinarith
```

Or prove it directly after multiplying by `c>0` and using `(c*a-b)^2≥0`; that version often elaborates more easily.

# 9. From `L²` to weighted `L¹`

Let

\[
M_n=\sum_kw(n,k)|G_n(k)|.
\]

Weighted Cauchy–Schwarz gives

\[
M_n^2
\le q_n\sum_kw(n,k)G_n(k)^2.
\tag{22}
\]

The cleanest Mathlib 4.29 API is

```lean
Finset.sq_sum_div_le_sum_sq_div
```

with

```lean
f k := weight22 n k * |saddleErr22 n k|
g k := weight22 n k
```

because every weight is strictly positive on `Finset.range (n+1)`. Its conclusion simplifies exactly to `(22)`.

# 10. Interface with the existing harmonic layer

Do not repeat the ratio-tail proof. The theorem to export from this file is simply

```lean
tendsto_saddle_mean22
```

or the stronger `saddle_mean_sq_le`.

The separately developed transfer argument can consume it as follows:

- Chebyshev from `(A)` gives, for every fixed `δ>0`,

  \[
  \frac{\sum_{|G_n(k)|>\delta n^2}w(n,k)}{q_n}
  \le\frac{81}{\delta^2\sqrt n}.
  \]

- The cubic moment bound also gives `K/n→0` under the weighted measures.
- Hence on the high-mass set,

  \[
  \frac{k^3}{(n-k)^2}\to1,
  \]

  so `3 log k - 2 log(n-k)→0`.
- `Real.tendsto_harmonic_sub_log` supplies the harmonic remainders once `k` and `n-k` tend to infinity.

That is exactly the point where the other central-set implementation should take over. This answer intentionally does not duplicate its finite-set decomposition or harmonic envelope estimates.

A useful stronger intermediate statement, obtained from `(14)`, `(16)`, and `(B)`, is

\[
\frac1{q_n}\sum_kw(n,k)
\left|\frac{k^3}{n^2}-1\right|\to0.
\]

Indeed,

\[
\left|\frac{k^3}{n^2}-1\right|
\le
\frac{|G_n(k)|}{n^2}
+\left|\left(1-\frac{k}{n}\right)^2-1\right|,
\]

and the second term is bounded by `2k/n+k²/n²`; weighted Cauchy–Schwarz plus `(16)` shows both averages tend to zero. This can simplify the downstream logarithm lemma.

# 12. Audit summary

The load-bearing exact formulae are:

\[
A_n(k)w_k=B_n(k+1)w_{k+1},
\]

\[
A_n-B_n=2(n-k)^2-(2n+k)G_n,
\]

\[
\Delta G_n=3k^2+k+2n,
\]

and therefore the exact second-moment identity `(19)`.

The only analytic input in the concentration certificate is the elementary interpolation

\[
x^2\le n+x^3/\sqrt n.
\]

Everything else is a finite `Finset` sum, positivity, and polynomial algebra. Thus this route is independent of log-concavity, mode location, geometric tails, Laplace estimates, and asymptotic recurrence theory.

The mathematical result I recommend formalizing is precisely `(A)` or `(B)`. It is strong enough to close the saddle-concentration obligation and is substantially shorter than constructing explicit left and right tails.
