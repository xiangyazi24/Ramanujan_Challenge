# 1. Exact recurrence coefficients and indexing

The existing recurrence is

```lean
def ZudilinSatisfiesRec (v : ℕ → ℚ) : Prop :=
  ∀ k : ℕ,
    v (k + 3) =
      zudilinM (k + 2) / zudilinA (k + 2) * v (k + 2)
        - (k + 2) * zudilinN (k + 2) / zudilinA (k + 2) * v (k + 1)
        + zudilinR (k + 2) * (k + 2) * (k + 1) ^ 3
            / (2 * zudilinA (k + 2)) * v k
```

Thus, with `n = k+2`, the homogeneous coefficients are exactly

```text
alpha_n = 2 A_n,
beta_n  = 2 M_n,
gamma_n = 2 n N_n,
delta_n = R_n n (n-1)^3.
```

Use step-indexed rational definitions to avoid every `Nat.sub` cast:


# 3. Direct `t`-coordinate products, `R_n`, and cancelled `S_n`

Use a pole product whose argument is the **number of factors**. This gives cleaner successor and shift lemmas.

```lean
open scoped BigOperators

/-- `∏_{r=1}^n (t-r)^3`. -/
def ctNumerator27 (n : ℕ) (t : ℂ) : ℂ :=
  ∏ r in Finset.range n, (t - (((r + 1 : ℕ) : ℂ))) ^ 3

/-- `∏_{j=0}^{m-1} (t+j)`. -/
def ctPoleProduct27 (m : ℕ) (t : ℂ) : ℂ :=
  ∏ j in Finset.range m, (t + (j : ℂ))

/-- Original `t`-coordinate Zudilin function. -/
def ctR27 (n : ℕ) (t : ℂ) : ℂ :=
  ctNumerator27 n t /
    (((n.factorial : ℂ) ^ 2) * ctPoleProduct27 (n + 1) t)

/-- The cancelled certificate
`Qhat_n(t-n) ∏_{r=1}^{n-1}(t-r)^3 / ((n!)² ∏_{j=0}^n(t+j))`. -/
def ctS27 (n : ℕ) (t : ℂ) : ℂ :=
  ctQhatC27 (n : ℂ) (t - (n : ℂ)) * ctNumerator27 (n - 1) t /
    (((n.factorial : ℂ) ^ 2) * ctPoleProduct27 (n + 1) t)
```

Do **not** define `S_n` as

```text
Qhat_n(t-n)/(t-n)^3 * R_n(t).
```

That expression has a totalized-division artefact at `t=n`. The cancelled definition above is a genuine rational function with no singularity at `t=n`.

One nonzero-prefix lemma is enough for every `field_simp` and differentiability proof:

```lean
theorem ctPoleProduct_ne_zero_of_le27

    (hM : ctPoleProduct27 M t ≠ 0) :
    ctPoleProduct27 m t ≠ 0 := by
  rw [ctPoleProduct27, Finset.prod_ne_zero_iff] at hM ⊢
  intro j hj
```

# 5. Common-denominator normal form

For `n=k+2`, use

```lean
def ctCommonDen27 (k : ℕ) (t : ℂ) : ℂ :=
  (((k + 2).factorial : ℂ) ^ 2) * ctPoleProduct27 (k + 4) t
```

If `hP : ctPoleProduct27 (k+4) t ≠ 0`, then

```lean
have hD : ctCommonDen27 k t ≠ 0 := by
  apply mul_ne_zero
  · exact pow_ne_zero _
      (Nat.cast_ne_zero.mpr (Nat.factorial_ne_zero (k + 2)))
  · exact hP
```

Set conceptually

```text
N = k+2,
x = t-N,
P = ∏_{r=1}^{n-2}(t-r)^3 = ctNumerator27 k t.
```

After multiplying by `ctCommonDen27 k t`, the six terms become:

```text
D * alpha R_(n+1)
 = alphaBar * P * (x-1)^3*x^3*(x+1)^3,

D * beta R_n
 = beta * P * (x+1)^3*x^3*(x+2N+1),

D * gamma R_(n-1)
 = gamma*N^2 * P*(x+2N)*(x+1)^3*(x+2N+1),

D * delta R_(n-2)
 = delta*N^2*(N-1)^2 * P
     *(x+2N)*(x+2N-1)*(x+2N+1),

D * S_n(t+1)
 = P*(N+x)^4*Qhat_N(x+1),

D * S_n(t)
 = P*(x+1)^3*(x+2N+1)*Qhat_N(x).
```

# 6. Final rational telescoper theorem

The proof now multiplies by the common denominator, rewrites the six normal forms, and invokes the one polynomial theorem.

```lean
theorem ctR_telescoper_step27
    (k : ℕ) (t : ℂ)
    (hP : ctPoleProduct27 (k + 4) t ≠ 0) :
    (ctAlpha27 k : ℂ) * ctR27 (k + 3) t
      - (ctBeta27 k : ℂ) * ctR27 (k + 2) t
      + (ctGamma27 k : ℂ) * ctR27 (k + 1) t
      - (ctDelta27 k : ℂ) * ctR27 k t =
    ctS27 (k + 2) (t + 1) - ctS27 (k + 2) t := by
  have hD : ctCommonDen27 k t ≠ 0 := by
    apply mul_ne_zero
    · exact pow_ne_zero _
        (Nat.cast_ne_zero.mpr (Nat.factorial_ne_zero (k + 2)))
    · exact hP
  apply mul_left_cancel₀ hD
  rw [mul_sub, mul_add, mul_sub, mul_sub]
  rw [← ctAlphaC_nat27, ← ctBetaC_nat27,
    ← ctGammaC_nat27, ← ctDeltaC_nat27]
  rw [ct_common_mul_alpha_R_next27 k t hP,
    ct_common_mul_beta_R27 k t hP,
    ct_common_mul_gamma_R_prev27 k t hP,
    ct_common_mul_delta_R_prev2_27 k t hP,
    ct_common_mul_S_shift27 k t hP,
    ct_common_mul_S27 k t hP]
  let N : ℂ := ((k + 2 : ℕ) : ℂ)
  let x : ℂ := t - N
  have hpoly := ctQhat_poly_identity27 N x
  dsimp only [N, x] at hpoly ⊢
  linear_combination ctNumerator27 k t * hpoly
```

```lean
    {n : ℕ} (hn : 2 ≤ n) (t : ℂ)
    (hP : ctPoleProduct27 (n + 2) t ≠ 0) :
    (2 * zudilinA n : ℚ) * ctR27 (n + 1) t
      - (2 * zudilinM n : ℚ) * ctR27 n t
      + (2 * n * zudilinN n : ℚ) * ctR27 (n - 1) t
      - (zudilinR n * n * (n - 1) ^ 3 : ℚ) * ctR27 (n - 2) t =
    ctS27 n (t + 1) - ctS27 n t := by
  obtain ⟨k, hk⟩ : ∃ k, n = k + 2 := ⟨n - 2, by omega⟩
  subst n
  simpa only [Nat.add_sub_cancel, Nat.cast_ofNat, Nat.cast_add,
    Nat.cast_mul, Nat.cast_pow] using ctR_telescoper_step27 k t hP
```

Because the target is an equality in `ℂ`, Lean may need explicit casts around the four rational coefficients in the wrapper. The step theorem avoids this elaboration nuisance.

# 7. Differentiability on the pole-free domain

The finite products are entire. Only the displayed pole product is a differentiability condition.

```lean
theorem ctNumerator_differentiableAt27 (n : ℕ) (t : ℂ) :
    DifferentiableAt ℂ (ctNumerator27 n) t := by
  unfold ctNumerator27
  exact DifferentiableAt.fun_finset_prod
    (u := Finset.range n) fun r _ =>
      (differentiableAt_id.sub_const _).fun_pow 3

theorem ctPoleProduct_differentiableAt27 (m : ℕ) (t : ℂ) :
    DifferentiableAt ℂ (ctPoleProduct27 m) t := by
  unfold ctPoleProduct27
  exact DifferentiableAt.fun_finset_prod
    (u := Finset.range m) fun j _ =>
      differentiableAt_id.add_const _
```

```lean
theorem ctR_differentiableAt27
    {n : ℕ} {t : ℂ}
    (hP : ctPoleProduct27 (n + 1) t ≠ 0) :
    DifferentiableAt ℂ (ctR27 n) t := by
  unfold ctR27
  apply DifferentiableAt.div
  · exact ctNumerator_differentiableAt27 n t
  · exact (differentiableAt_const _).mul
      (ctPoleProduct_differentiableAt27 (n + 1) t)
  · exact mul_ne_zero
      (pow_ne_zero _ (Nat.cast_ne_zero.mpr (Nat.factorial_ne_zero n))) hP

theorem ctS_differentiableAt27
    {n : ℕ} {t : ℂ}
    (hP : ctPoleProduct27 (n + 1) t ≠ 0) :
    DifferentiableAt ℂ (ctS27 n) t := by
  unfold ctS27
  apply DifferentiableAt.div
  · apply DifferentiableAt.mul
    · fun_prop
    · exact ctNumerator_differentiableAt27 (n - 1) t
  · exact (differentiableAt_const _).mul
      (ctPoleProduct_differentiableAt27 (n + 1) t)
  · exact mul_ne_zero
      (pow_ne_zero _ (Nat.cast_ne_zero.mpr (Nat.factorial_ne_zero n))) hP
```

# 8. Derivative identity

Define the derivative-level target directly:

```lean
theorem ctR_telescoper_deriv_step27
    (k : ℕ) (t : ℂ)
    (hP : ctPoleProduct27 (k + 4) t ≠ 0) :
    (ctAlpha27 k : ℂ) * deriv (ctR27 (k + 3)) t
      - (ctBeta27 k : ℂ) * deriv (ctR27 (k + 2)) t
      + (ctGamma27 k : ℂ) * deriv (ctR27 (k + 1)) t
      - (ctDelta27 k : ℂ) * deriv (ctR27 k) t =
    deriv (ctS27 (k + 2)) (t + 1)
      - deriv (ctS27 (k + 2)) t := by
```

The proof should use local eventual equality, not differentiate a theorem carrying a pointwise hypothesis manually.

```lean
  let L : ℂ → ℂ := fun z =>
    (ctAlpha27 k : ℂ) * ctR27 (k + 3) z
      - (ctBeta27 k : ℂ) * ctR27 (k + 2) z
      + (ctGamma27 k : ℂ) * ctR27 (k + 1) z
      - (ctDelta27 k : ℂ) * ctR27 k z
  let T : ℂ → ℂ := fun z =>
    ctS27 (k + 2) (z + 1) - ctS27 (k + 2) z

  have hpCont : ContinuousAt (ctPoleProduct27 (k + 4)) t :=
    (ctPoleProduct_differentiableAt27 (k + 4) t).continuousAt
  have hlocalP :
      ∀ᶠ z in 𝓝 t, ctPoleProduct27 (k + 4) z ≠ 0 :=
    hpCont.eventually_ne hP
  have hEq : L =ᶠ[𝓝 t] T :=
    hlocalP.mono fun z hz => ctR_telescoper_step27 k z hz
```

Derive all subproduct nonzero facts from `hP`:

```lean
  have hR3 := ctR_differentiableAt27
    (ctPoleProduct_ne_zero_of_le27 (by omega : k + 4 ≤ k + 4) hP)
  have hR2 := ctR_differentiableAt27
    (ctPoleProduct_ne_zero_of_le27 (by omega : k + 3 ≤ k + 4) hP)
  have hR1 := ctR_differentiableAt27
    (ctPoleProduct_ne_zero_of_le27 (by omega : k + 2 ≤ k + 4) hP)
  have hR0 := ctR_differentiableAt27
    (ctPoleProduct_ne_zero_of_le27 (by omega : k + 1 ≤ k + 4) hP)
  have hS0 := ctS_differentiableAt27
    (ctPoleProduct_ne_zero_of_le27 (by omega : k + 3 ≤ k + 4) hP)
  have hshiftP : ctPoleProduct27 (k + 3) (t + 1) ≠ 0 := by
    have h := hP
    rw [ctPoleProduct_shift_succ27 (k + 3)] at h
    exact (mul_ne_zero_iff.mp h).2
  have hS1 := ctS_differentiableAt27 hshiftP
```

Construct the two `HasDerivAt` proofs:

```lean
  have hL : HasDerivAt L
      ((ctAlpha27 k : ℂ) * deriv (ctR27 (k + 3)) t
        - (ctBeta27 k : ℂ) * deriv (ctR27 (k + 2)) t
        + (ctGamma27 k : ℂ) * deriv (ctR27 (k + 1)) t
        - (ctDelta27 k : ℂ) * deriv (ctR27 k) t) t := by
    dsimp only [L]
    exact (((hR3.hasDerivAt.const_mul _).sub
      (hR2.hasDerivAt.const_mul _)).add
      (hR1.hasDerivAt.const_mul _)).sub
      (hR0.hasDerivAt.const_mul _)

  have hScomp : HasDerivAt
      (fun z : ℂ => ctS27 (k + 2) (z + 1))
      (deriv (ctS27 (k + 2)) (t + 1)) t := by
    convert hS1.hasDerivAt.comp t
      ((hasDerivAt_id t).add_const 1) using 1 <;> ring

  have hT : HasDerivAt T
      (deriv (ctS27 (k + 2)) (t + 1)
        - deriv (ctS27 (k + 2)) t) t := by
    dsimp only [T]
    exact hScomp.sub hS0.hasDerivAt
```

Finish with Mathlib's exact local congruence theorem `Filter.EventuallyEq.deriv_eq`:

```lean
  calc
    _ = deriv L t := hL.deriv.symm
    _ = deriv T t := hEq.deriv_eq
    _ = _ := hT.deriv
```

If `const_mul` produces the factors in the opposite commutative order, insert `convert ... using 1 <;> ring` around `hL`.

# 9. `Phi` identity

Use direct operators on the two function families:

```lean
def ctRPhi27 (n : ℕ) (t : ℂ) : ℂ :=
  ctR27 n t - deriv (ctR27 n) t / 2

def ctSPhi27 (n : ℕ) (t : ℂ) : ℂ :=
  ctS27 n t - deriv (ctS27 n) t / 2
```

Then no further analysis is required:

```lean
theorem ctPhi_telescoper_step27
    (k : ℕ) (t : ℂ)
    (hP : ctPoleProduct27 (k + 4) t ≠ 0) :
    (ctAlpha27 k : ℂ) * ctRPhi27 (k + 3) t
      - (ctBeta27 k : ℂ) * ctRPhi27 (k + 2) t
      + (ctGamma27 k : ℂ) * ctRPhi27 (k + 1) t
      - (ctDelta27 k : ℂ) * ctRPhi27 k t =
    ctSPhi27 (k + 2) (t + 1) - ctSPhi27 (k + 2) t := by
  have h0 := ctR_telescoper_step27 k t hP
  have h1 := ctR_telescoper_deriv_step27 k t hP
  simp only [ctRPhi27, ctSPhi27]
  linear_combination h0 - h1 / 2
```

This is the exact identity needed before integrating against the squared-sine kernel.

# 10. Audit of hidden gaps

## A. Totalized division at numerator zeros

The Q6052 quotient ratios divide by `(t-n)^3` and `(t-n+1)^3`. In Lean they need hypotheses excluding precisely the positive integer zeros crossed by the contour. Do not formalize the main proof through those ratios. The common-denominator proof above requires only

```text
∏_{j=0}^{n+1}(t+j) ≠ 0,
```

so it remains valid at `t=1,...,n+1`.

## B. The theorem cannot be unconditional at negative poles

With `ctR27` and `ctS27` defined by ordinary field division, the rational-function identity should be stated on the pole-free domain. At a negative pole, Lean assigns junk value zero to a quotient, and the mathematical meromorphic identity need not survive pointwise. This is harmless: every Barnes contour used in the project lies in `Re t > 0`.

An alternative is to prove the identity first in `RatFunc ℚ`, but that is longer and gives no benefit for the later complex derivative theorem.

## C. Use the cancelled `S_n`

The uncancelled definition is not extensionally equal at `t=n`. The cancelled product is mandatory both for the algebraic identity at positive integers and for the later triple-zero theorem at `t=1`.

## D. Do not use the existing fixed-`s` log-derivative lemmas

`Problem27Barnes.lean` proves convenient derivative formulas only in the half-plane `Re s ≥ -1/2`, where all numerator factors are nonzero. In the original `t` coordinate the certificate deliberately crosses numerator zeros. The direct finite-product differentiability proof above is the correct API.

## E. Exact recurrence normalization

The homogeneous certificate coefficient is `2*zudilinA n`, not `zudilinA n`; the last coefficient has no leading `2`:

```text
2 A_n u_(n+1) - 2 M_n u_n + 2 n N_n u_(n-1)
  - R_n n(n-1)^3 u_(n-2) = 0.
```

This follows exactly by multiplying the existing source recurrence by `2*zudilinA n`.

## F. Derivative identity is local

`Filter.EventuallyEq.deriv_eq` requires equality in a neighborhood, not merely equality at `t`. The continuity-plus-`eventually_ne` step is load-bearing and should not be omitted.
