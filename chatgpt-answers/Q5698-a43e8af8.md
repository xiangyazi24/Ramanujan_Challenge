The primitive-shell route has a clean exact algebra, but it does **not** produce the requested small carrier.

1. If
   \[
   b_M=c_M(0),\qquad
   B_M(d):=C_M(d)-b_M,
   \]
   then
   \[
   B_M(d)=\sum_{j\ge1}A_M(jd)
   \]
   and exact Möbius inversion on the divisibility poset gives
   \[
   \boxed{
   A_M(k)=\sum_{j\le M/k}\mu(j)\bigl(C_M(jk)-b_M\bigr).
   }
   \]
   This is an integral unitriangular change of coordinates. It does not create new Smith content or an extra target equation.

2. Primitive normalization does not lower Archimedean height. For every
   \(1\le k\le M\),
   \[
   \boxed{
   A_M(k)\ge
   c_M(-k,0,0)
   \ge
   \binom Mk\binom{2M}{M}^{\!2}
   \ge
   \frac{16^M}{(2M+1)^2}.
   }
   \]
   Thus **every** nonzero primitive shell has logarithmic height
   \(\ge M\log16-O(\log M)\), uniformly even at the extreme boundary.

3. Let \(e=d+h\), \(p=d+1\), and \(\ell=e+1\). In a fixed quotient slice
   \(M=ad+r=ae+r'\), the target equations are
   \[
   p\mid L_d,\qquad \ell\mid L_e,
   \]
   where
   \[
   L_t:=C_M(t)=b_M+\sum_{j=1}^{a}A_M(jt).
   \]
   If \(d>ah\), the two primitive packets
   \(\{jd:1\le j\le a\}\) and
   \(\{je:1\le j\le a\}\) are disjoint.

4. The exact two-modulus consequence ideal is
   \[
   \boxed{
   (p,L_d)\cap(\ell,L_e)
   =(p\ell,\ pL_e,\ \ell L_d,\ L_dL_e).
   }
   \]
   After adjoining the quotient coordinates
   \(L_d=pU\), \(L_e=\ell V\) and saturating by \(p\ell\), the variables
   \(U,V\) remain free. The elimination ideal into the characteristic-zero
   parameter ring is zero.

5. Consequently, any **modulus-free**, location-independent polynomial carrier
   whose divisibility proof uses only the bounded primitive-shell window,
   Möbius inversion, root-of-unity filtering, and the two target equations is
   divisible by \(L_dL_e\). If its value is nonzero, then
   \[
   \boxed{
   \log|R|\ge 2M\log16-O(\log M).
   }
   \]
   This is linear in \(M\), far larger than \(o(H)\) for
   \(H=M^{1/3}\).

6. If the marked moduli are allowed, the familiar exact carrier is
   \[
   \boxed{
   \ell C_M(d)-pC_M(e)=p\ell(U-V).
   }
   \]
   Its raw height is \(O(M)\). After the explicit factor \(p\ell\) is divided
   out, the residue \(U-V\) is unrestricted. Primitive-shell resultants and
   Ore determinants do not add another factor.

7. There is no necklace/Dold or cyclotomic escape. Already at \(M=1\),
   \[
   C_1(1)=40,\qquad C_1(2)=5,
   \]
   so the order-two Dold congruence would require
   \(2\mid C_1(2)-C_1(1)=-35\), which is false. Also targetness is a
   **root-of-unity average**, not a common-root condition, so it does not force
   a cyclotomic resultant to vanish.

The route is therefore closed in the natural bounded-window class. A reopening
requires a genuinely new arithmetic theorem controlling the actual normalized
quotients \(C_M(d)/(d+1)\) at two different residue characteristics, or a global
fixed-gap resultant using more than the universal primitive-shell identities.

# 1. Exact primitive-shell decomposition

Use the correct Apéry Laurent polynomial
\[
\Lambda(x,y,z)=
\frac{(1+x)(1+y)(1+z)\bigl((1+y)(1+z)+xyz\bigr)}{xyz}.
\tag{1.1}
\]
Write
\[
\Lambda^M=\sum_{v\in\mathbf Z^3}c_M(v)x^{v_1}y^{v_2}z^{v_3},
\qquad c_M(v)\in\mathbf Z_{\ge0}.
\tag{1.2}
\]
The Newton box is contained in \([-M,M]^3\), and
\[
c_M(0)=\operatorname{CT}\Lambda^M=b_M.
\tag{1.3}
\]

For \(k\ge1\), define
\[
A_M(k):=
\sum_{\substack{v\in\mathbf Z^3\\
\gcd(|v_1|,|v_2|,|v_3|)=k}}
c_M(v),
\tag{1.4}
\]
where \(\gcd(0,0,0)=0\), so the origin is excluded. Define
\[
C_M(d):=\sum_{v\in d\mathbf Z^3}c_M(v),
\qquad
B_M(d):=C_M(d)-b_M.
\tag{1.5}
\]
Since a nonzero vector in \(d\mathbf Z^3\) has gcd equal to a positive
multiple of \(d\),
\[
\boxed{
B_M(d)=\sum_{j=1}^{\lfloor M/d\rfloor}A_M(jd).
}
\tag{1.6}
\]
This is finite because \(A_M(k)=0\) for \(k>M\).

## Theorem 1.1 — Möbius inversion on multiples

For every \(1\le k\le M\),
\[
\boxed{
A_M(k)=
\sum_{j=1}^{\lfloor M/k\rfloor}
\mu(j)B_M(jk)
=
\sum_{j=1}^{\lfloor M/k\rfloor}
\mu(j)\bigl(C_M(jk)-b_M\bigr).
}
\tag{1.7}
\]

### Proof

Substitute (1.6):
\[
\begin{aligned}
\sum_{j\ge1}\mu(j)B_M(jk)
&=
\sum_{j\ge1}\mu(j)
\sum_{t\ge1}A_M(tjk)\\
&=
\sum_{s\ge1}A_M(sk)
\sum_{j\mid s}\mu(j).
\end{aligned}
\]
The inner sum is \(1\) for \(s=1\) and \(0\) otherwise. Hence only
\(A_M(k)\) remains. ∎

## 1.1 Unimodularity

Order the coordinates \(A_M(M),A_M(M-1),\ldots,A_M(1)\) from large to small.
Equation (1.6) has the form
\[
B_M(k)=A_M(k)+\sum_{j\ge2}A_M(jk).
\tag{1.8}
\]
The coefficient matrix is upper triangular with every diagonal entry equal to
\(1\). Therefore the transformation
\[
(A_M(1),\ldots,A_M(M))\longleftrightarrow
(B_M(1),\ldots,B_M(M))
\tag{1.9}
\]
is an automorphism of \(\mathbf Z^M\).

Consequences:

- Möbius inversion does not create denominators;
- coefficient content and Smith/Fitting data are unchanged up to integral
  units when the complete finite packet is retained;
- any elimination theorem in the \(C_M\)-coordinates has an equivalent theorem
  in the \(A_M\)-coordinates, and conversely.

This is the first saturation mechanism: “primitive shell” is a better labeling,
not an extra equation.

# 2. Root-of-unity filtering and the exact generating polynomial

Define the primitive-shell polynomial
\[
P_M(T):=\sum_{k=1}^{M}A_M(k)T^k.
\tag{2.1}
\]
For every \(d\ge1\), the root-of-unity filter gives
\[
\boxed{
B_M(d)=
\frac1d\sum_{\zeta^d=1}P_M(\zeta).
}
\tag{2.2}
\]
Indeed, the average of \(\zeta^k\) is \(1\) when \(d\mid k\) and \(0\)
otherwise.

Thus targetness is
\[
(d+1)\mid
\left(
 b_M+rac1d\sum_{\zeta^d=1}P_M(\zeta)
\right).
\tag{2.3}
\]
It is a **trace/average condition**. It is not the assertion that
\(P_M\) and \(T^d-1\) have a common root.

## 2.1 Exact formal counterexample to a cyclotomic resultant implication

Work over a field of characteristic \(p=d+1\) and suppose \(b\ne0\). Take
\[
P(T)=-bT^d.
\tag{2.4}
\]
For every \(d\)-th root of unity \(\zeta\), one has \(P(\zeta)=-b\), so
\[
b+\frac1d\sum_{\zeta^d=1}P(\zeta)=0.
\tag{2.5}
\]
Nevertheless
\[
\operatorname{Res}(P(T),T^d-1)=(-b)^d\ne0.
\tag{2.6}
\]
Therefore even the exact target average does not imply any cyclotomic common
factor or resultant divisibility.

For close \(d,e\), the polynomials \(T^d-1\) and \(T^e-1\) have the universal
common factor \(T^{\gcd(d,e)}-1\). Removing it is a normalization depending only
on \(d,e\); it contains no Apéry target information. Resultants of cyclotomic
factors may contain primes coming from prime-power ratios of their indices, but
those are again universal index factors, not consequences of
\((d+1)\mid C_M(d)\).

## 2.2 Dirichlet series

The finite Dirichlet series of the shell sums satisfies
\[
\begin{aligned}
\mathcal B_M(s)
&:=\sum_{d=1}^{M}\frac{B_M(d)}{d^s}\\
&=
\sum_{k=1}^{M}A_M(k)
\sum_{d\mid k}d^{-s}\\
&=
\boxed{
\sum_{k=1}^{M}A_M(k)\sigma_{-s}(k).
}
\end{aligned}
\tag{2.7}
\]
There is no Euler product: for fixed \(M\), the sequence \(A_M(k)\) is not
multiplicative in \(k\). The transform is the zeta transform of the finite
opposite divisibility poset, not a multiplicative Dirichlet convolution that
would factor across primes.

# 3. Necklace and Dold congruences do not apply

A sequence \((F_n)\) of fixed-point counts of iterates must satisfy the Dold
congruences
\[
n\mid\sum_{d\mid n}\mu(n/d)F_d.
\tag{3.1}
\]
The shell-spacing sequence does not satisfy them.

At \(M=1\), the coefficient sum is
\[
C_1(1)=\Lambda(1,1,1)=40.
\tag{3.2}
\]
Since the support of \(\Lambda\) is contained in \([-1,1]^3\), the only vector
in \(2\mathbf Z^3\) occurring in \(\Lambda\) is the origin. Its coefficient is
\(5\), so
\[
C_1(2)=5.
\tag{3.3}
\]
The order-two Dold congruence would require
\[
2\mid C_1(2)-C_1(1)=-35,
\tag{3.4}
\]
which is false. The same failure occurs after separating the origin:
\[
B_1(1)=35,\qquad B_1(2)=0,\qquad B_1(2)-B_1(1)=-35.
\tag{3.5}
\]

Hence there is no universal necklace orbit count, no Dold divisibility, and no
integral Witt/cyclotomic factorization whose exponents automatically contribute
an extra factor of the shell index.

# 4. Primitive normalization has uniformly linear height

The repository's exact one-sum coefficient formula can be written as
\[
\boxed{
 c_M(\alpha,\beta,\gamma)
 =\sum_{t=0}^{M}
 \binom Mt
 \binom M{t-\alpha}
 \binom{2M-t}{M-\beta}
 \binom{2M-t}{M-\gamma},
}
\tag{4.1}
\]
with the convention that an out-of-range binomial coefficient is zero.

## Theorem 4.1 — every primitive shell is exponentially large

For every \(1\le k\le M\),
\[
\boxed{
A_M(k)
\ge \binom Mk\binom{2M}{M}^{\!2}.
}
\tag{4.2}
\]
Consequently
\[
\boxed{
M\log16-2\log(2M+1)
\le \log A_M(k)
\le M\log40.
}
\tag{4.3}
\]
The bounds are uniform in \(k\).

### Proof

The vector \((-k,0,0)\) has primitive gcd \(k\), so
\[
A_M(k)\ge c_M(-k,0,0).
\tag{4.4}
\]
In (4.1), take the single summation term \(t=0\). It equals
\[
\binom M0
\binom Mk
\binom{2M}{M}^{\!2},
\tag{4.5}
\]
which proves (4.2).

Also
\[
\binom{2M}{M}\ge\frac{4^M}{2M+1},
\tag{4.6}
\]
because the central binomial coefficient is the largest of the \(2M+1\)
coefficients whose sum is \(4^M\). This gives the lower bound in (4.3).
The upper bound follows from positivity and
\[
\sum_v c_M(v)=\Lambda(1,1,1)^M=40^M.
\tag{4.7}
\]
∎

This theorem is stronger than a generic entropy estimate. It shows that even
an extreme primitive shell cannot have deficit-controlled subexponential
height: the ray \((-k,0,0)\) alone carries a squared central-binomial factor.

The origin shell is equally large:
\[
b_M\ge\binom{2M}{M}^{\!2}
\ge\frac{16^M}{(2M+1)^2},
\tag{4.8}
\]
using the \(k=M\) term in the Apéry sum. Therefore
\[
C_M(d)\ge b_M\ge\frac{16^M}{(2M+1)^2}
\tag{4.9}
\]
for every \(d\).

# 5. Fixed quotient packets and close spacings

Suppose
\[
M=ad+r,\qquad 0<r<d.
\tag{5.1}
\]
Then \(\lfloor M/d\rfloor=a\), so (1.6) becomes
\[
\boxed{
C_M(d)=b_M+\sum_{j=1}^{a}A_M(jd).
}
\tag{5.2}
\]
For a close spacing
\[
e=d+h,
\tag{5.3}
\]
assume it remains in the same quotient slice:
\[
M=ae+r',\qquad 0<r'<e.
\tag{5.4}
\]
Then
\[
\boxed{
C_M(e)=b_M+\sum_{j=1}^{a}A_M(je).
}
\tag{5.5}
\]

## Proposition 5.1 — disjoint primitive packets

If \(d>ah\), then
\[
\{d,2d,\ldots,ad\}
\cap
\{e,2e,\ldots,ae\}
=\varnothing.
\tag{5.6}
\]

### Proof

Suppose \(jd=ke=k(d+h)\) with \(1\le j,k\le a\). Then
\[
(j-k)d=kh.
\tag{5.7}
\]
If \(j\ne k\), the left side has absolute value at least \(d\), while the
right side is at most \(ah\), contradiction. If \(j=k\), then \(kh=0\), also
impossible. ∎

For the LAC range \(h\ll\log n\), fixed \(a\), and
\(d\asymp M/a\), the inequality \(d>ah\) holds for all sufficiently large
\(M\). Thus Möbius inversion actually separates the two close hits into two
disjoint primitive-coordinate packets. It does not reveal a shared primitive
shell.

# 6. Exact two-modulus ideal

Put
\[
p=d+1,\qquad \ell=e+1=d+h+1,
\tag{6.1}
\]
and assume \(p,\ell\) are distinct primes. Define the two hit forms
\[
L_d:=b_M+\sum_{j=1}^{a}A_M(jd)=C_M(d),
\tag{6.2}
\]
\[
L_e:=b_M+\sum_{j=1}^{a}A_M(je)=C_M(e).
\tag{6.3}
\]
The target equations are
\[
p\mid L_d,\qquad \ell\mid L_e.
\tag{6.4}
\]
Equivalently, for integers \(U,V\),
\[
L_d=pU,\qquad L_e=\ell V.
\tag{6.5}
\]

Because \((p,L_d)\) and \((\ell,L_e)\) are comaximal after the distinct prime
specialization,
\[
\begin{aligned}
(p,L_d)\cap(\ell,L_e)
&=(p,L_d)(\ell,L_e)\\
&=\boxed{
(p\ell,\ pL_e,\ \ell L_d,\ L_dL_e).
}
\end{aligned}
\tag{6.6}
\]
This is the complete universal consequence ideal.

## 6.1 Saturated equality algebra

Adjoin the quotient variables and localize at the two moduli:
\[
\mathcal R=
\mathbf Z[\text{shell coordinates},d,h,U,V,1/(p\ell)]/
(L_d-pU,L_e-\ell V).
\tag{6.7}
\]
After the disjoint-packet identification of Proposition 5.1, solve for one
coordinate in each packet. The resulting ring is a polynomial ring in \(U,V\)
and all remaining coordinates. In particular it is a domain, and
\[
\boxed{
(L_d-pU,L_e-\ell V)\cap\mathbf Z[M,a,h]=(0).
}
\tag{6.8}
\]
Thus primitive-shell algebra, Möbius inversion, and the two hit equations do
not produce a nonzero characteristic-zero scalar independent of the unknown
location \(d\).

## 6.2 Modulus-free carrier theorem

The following is the strongest useful scoped no-go.

### Theorem 6.2

Let \(F\) be an integer polynomial in a bounded window of shell coordinates,
with coefficients independent of the two unknown moduli. Suppose its claimed
universal divisibility uses only:

- the exact primitive decomposition (1.6);
- Möbius inversion (1.7);
- root-of-unity filtering (2.2);
- fixed-support or Ore relations that do not add another cross-characteristic
  hit equation;
- and the two target conditions (6.4).

Then, in the universal shell algebra,
\[
\boxed{L_dL_e\mid F.}
\tag{6.9}
\]
If the evaluated integer \(F\) is nonzero, then
\[
\boxed{
\log|F|
\ge 2M\log16-4\log(2M+1).
}
\tag{6.10}
\]

### Proof

Modulo \(p\), only the equation \(L_d=0\) is imposed; all coordinates in the
second packet remain free. Therefore a modulus-free polynomial consequence
must vanish on the hyperplane \(L_d=0\), so \(L_d\mid F\). The same argument in
characteristic \(\ell\) gives \(L_e\mid F\). The two linear forms are primitive
and independent in the disjoint packets, hence \(L_dL_e\mid F\).

At the actual integral shell values, write \(F=L_dL_eG\). If \(F\ne0\), then
\(G\) is a nonzero integer, so \(|G|\ge1\). Using (4.9) for both hit forms gives
(6.10). ∎

This theorem applies to a bounded-window determinant or resultant after all
universal boundary factors and coefficient content have been removed. If the
normalized object still retains both target primes by the stated formal
mechanism, it contains \(L_dL_e\) and therefore has linear height. If the
normalization removes either hit form, it loses the corresponding guaranteed
prime.

For rational resultants, clear denominators first. Dividing any
\(\exp(o(M))\) universal denominator changes (6.10) only by \(o(M)\); the height
remains linear.

# 7. Marked carriers and why normalization loses selectivity

If the location \(d\) and hence the moduli are explicitly allowed in the
formula, there are two elementary exact carriers.

The product carrier is
\[
\boxed{p\ell\mid C_M(d)C_M(e).}
\tag{7.1}
\]
It has
\[
\log\bigl(C_M(d)C_M(e)\bigr)
\ge2M\log16-O(\log M).
\tag{7.2}
\]

The primitive linear carrier is
\[
\boxed{
D_{M,d,h}:=\ell C_M(d)-pC_M(e)=p\ell(U-V).
}
\tag{7.3}
\]
It satisfies the crude upper bound
\[
|D_{M,d,h}|\le (p+\ell)40^M,
\qquad
\log|D_{M,d,h}|\le M\log40+O(\log M).
\tag{7.4}
\]

After the explicit target factor is removed,
\[
\frac{D_{M,d,h}}{p\ell}=U-V.
\tag{7.5}
\]
The saturated ring (6.7) shows that \(U,V\) are independent coordinates.
Therefore neither
\[
p\mid U-V
\quad\text{nor}\quad
\ell\mid U-V
\tag{7.6}
\]
is a formal consequence. A small value of \(U-V\) would be a genuinely new
arithmetic cancellation theorem about the distinguished Apéry coefficient
array, not a consequence of primitive shells, Möbius inversion, or a bounded
Ore recurrence.

This is exactly the quotient-residue obstruction already found for the
22-shell formulation in `Q634.md`; the primitive-shell coordinates are related
to those shell coordinates by an integral finite change of basis, so the local
codimension remains one in each characteristic.

# 8. Why bounded-window resultants do not improve the ideal

Consider any bounded collection of nearby values
\[
C_M(d+s),\qquad |s|\le B,
\tag{8.1}
\]
or the corresponding primitive packets supplied by Möbius inversion. A
holonomic recurrence in the spacing variable gives relations among these
values, but at a target prime it kills only one scalar value. Neighboring shell
values remain free local-state coordinates.

A Sylvester determinant or subresultant can acquire \(p\) or \(\ell\) only
from:

1. the explicit hit rows \(L_d=0\) or \(L_e=0\);
2. explicit weights \(p,\ell\);
3. leading coefficients or boundary factors of the recurrence;
4. universal common cyclotomic factors depending only on \(d,e\).

After those factors are primitively saturated, the determinant is a polynomial
in the free quotient/state coordinates. Its elimination ideal is zero. Hence:

- if it is forced to retain both primes without marked weights, Theorem 6.2
  makes it a multiple of \(L_dL_e\), of linear height;
- if it uses marked weights, its normalized value is a free expression in
  \(U,V\) and neighboring state coordinates;
- if it eliminates those free coordinates completely, the resultant is either
  identically zero for a universal reason or a unit/nonvanishing scalar with no
  target divisibility.

This is the precise bounded-window primitive-shell resultant saturation
statement requested in the question.

# 9. Hostile fixed-moment example: \(n=321\)

For the top-half quotient \(a=1\),
\[
M=n-a=320.
\tag{9.1}
\]
The repository's exact scan and shell audit give the three hits
\[
p\in\{179,193,211\},
\qquad
d=p-1\in\{178,192,210\}.
\tag{9.2}
\]
Since each \(d>M/2\),
\[
C_{320}(d)=b_{320}+A_{320}(d).
\tag{9.3}
\]
Thus the three target equations are exactly
\[
A_{320}(178)\equiv-b_{320}\pmod{179},
\tag{9.4}
\]
\[
A_{320}(192)\equiv-b_{320}\pmod{193},
\tag{9.5}
\]
\[
A_{320}(210)\equiv-b_{320}\pmod{211}.
\tag{9.6}
\]
They involve three distinct primitive coordinates. Möbius inversion has made
the independence completely explicit.

For the pair \((179,193)\), \(h=14\), the marked carrier is
\[
193C_{320}(178)-179C_{320}(192),
\tag{9.7}
\]
divisible by \(179\cdot193\). Its normalized value is
\[
\frac{C_{320}(178)}{179}-
\frac{C_{320}(192)}{193},
\tag{9.8}
\]
with no further formal divisibility.

The committed exact routine `normalized_pair_residue` in
`problems/3.2/chatgpt-answers/Q634.md` computes (9.8) modulo the two primes by
working modulo \((179\cdot193)^2\); it is the regression test that rules out an
asserted extra factor. The same audit covers the pairs \((193,211)\) and
\((179,211)\).

The primitive values are not boundary-small. Theorem 4.1 gives, for example,
\[
A_{320}(178)
\ge
\binom{320}{178}\binom{640}{320}^{\!2},
\tag{9.9}
\]
and analogous inequalities for \(192\) and \(210\). Thus the hostile triple
already sits in the full linear-height regime.

A dependency-free exact check uses the repository's coefficient routine:

```python
# Existing repo ingredients: coeff(M,A,B,C,modulus), shell(M,d,modulus).
n = 321
M = 320
hits = (179, 193, 211)

for p in hits:
    d = p - 1
    assert shell(M, d, modulus=p) == 0

for p, q in ((193, 179), (211, 193), (211, 179)):
    d, e = q - 1, p - 1
    mod = (p*q)**2
    X = shell(M, d, modulus=mod)

    marked = (p*X - q*Y) % mod
    assert marked % (p*q) == 0
    normalized = (marked // (p*q)) % (p*q)
    print(n, p, q, p-q, normalized)
```

No floating-point or heuristic step is involved.

# 10. Universal versus target-selective statements

It is useful to keep the ledger explicit.

## Universal identities

These hold for every \(M,d\), with no target assumption:

- \(C_M(d)-b_M=\sum_{j\ge1}A_M(jd)\);
- Möbius inversion (1.7);
- the root-of-unity average (2.2);
- the exact coefficient formula (4.1);
- positivity and the height bounds (4.2)--(4.9);
- universal cyclotomic common factors determined by \(\gcd(d,e)\);
- fixed-support/Horn/Ore recurrences in the shell spacing.

None of these contains a factor \(d+1\) or \(e+1\) specifically when the Apéry
target occurs.

## Target-selective inputs

The only target equations are
\[
(d+1)\mid C_M(d),
\qquad
(e+1)\mid C_M(e).
\tag{10.1}
\]
They generate the ideal (6.6). The product and marked linear carriers in
Section 7 are exact consequences, but no normalized extra factor survives.

## False or unavailable upgrades

The following do not follow:

- Dold/necklace divisibility by the shell index;
- a cyclotomic common root of \(P_M(T)\) and \(T^d-1\);
- a multiplicative Euler product in the primitive index;
- divisibility of one primitive component \(A_M(jd)\) by the target prime;
- divisibility of a normalized close-shell determinant by either prime;
- sublinear height after Möbius or primitive-content normalization.

# 11. Consequence for the LAC frontier

Let a prime block have length \(H=n^{1/3}\), and let
\(1\le h\le A\log n\). For fixed quotient \(a\), the primitive-shell packet has
bounded dimension \(a\), and close packets are disjoint. This bounded dimension
does not compress the two target congruences: it exposes two independent
rank-one conditions in two residue fields.

Theorem 6.2 gives the quantitative obstruction
\[
\log|R|\ge cM-O(\log M)\asymp n
\tag{11.1}
\]
for every nonzero modulus-free bounded-window carrier in the scoped class. In
particular it is not merely larger than the desired \(o(H)\); it is larger by a
factor of order \(n^{2/3}\).

The standard Selberg upper-bound sieve still gives a nonselective ambient bound
for prime pairs of a fixed gap, and after summing \(h\le A\log n\) one obtains an
\(o(H)\) count of ambient close prime pairs in a length-\(H\) block. That fact
uses only primality and was already available before the shell construction.
It supplies no Apéry-specific compression and does not produce a characteristic-
zero carrier for the target subset.

The narrowest legitimate reopening statements are:

1. **Cross-quotient rigidity:** prove a nontrivial arithmetic relation between
   \[
   U=\frac{C_M(d)}{d+1},
   \qquad
   V=\frac{C_M(e)}{e+1}
   \]
   on actual double targets.

2. **Global fixed-gap resultant:** construct one integer \(R_{M,a,h}\),
   independent of \(d\), whose prime divisors contain every actual target pair
   of gap \(h\), with \(\log|R_{M,a,h}|=o(H/\log n)\).

3. **Normalized shell correlation:** prove cancellation or anti-concentration
   for the actual quotient sequence \(C_M(d)/(d+1)\) across prime values of
   \(d+1\).

Each is new cross-characteristic arithmetic. None follows from Möbius inversion,
primitive shells, necklace identities, cyclotomic factorization, or bounded-
window resultants.

# Final conclusion

The primitive-shell decomposition is exact and computationally useful, but it
sharpens the no-go:

- Möbius inversion is unimodular;
- every primitive shell has linear exponential height;
- close fixed-quotient packets are disjoint;
- the two target equations have independent quotient coordinates;
- modulus-free carriers contain the full product of the two hit forms and hence
  have linear height;
- marked carriers normalize to an unrestricted difference;
- necklace/Dold and cyclotomic-resultant mechanisms are inapplicable.

Therefore this route does not yield an \(o(H)\)-height carrier or a new Apéry
collision estimate. The exact remaining problem is horizontal control of the
normalized shell quotients at two different primes.
