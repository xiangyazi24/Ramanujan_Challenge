# Exact conductor audit for the complete sums of delta_h

## Verdict

The claimed coefficient 4h+1 is safe but is not the Euler-characteristic constant.

For

```plain text
q_h(X) = product_(j=1)^h (X+j),
f_h(X) = t N_h(X) / q_h(X)^3,
t != 0,
```

with p >= 7 and 1 <= h < p, infinity is regular and f_h(infinity)=0. If all h finite denominator points are actual poles of order three, then the exact statements are

```plain text
|S_h(t)+1| <= (4h-2) sqrt(p),
|S_h(t)|   <= (4h-2) sqrt(p) + 1,
```

where

```plain text
S_h(t) = sum_(r in F_p, q_h(r)!=0) e_p(f_h(r)).
```

Equivalently, if one insists on realizing the affine sum itself as one compactly supported cohomology trace, then

```plain text
dim H_c^1(A^1 minus {-1,...,-h}, L_psi(f_h)) = 4h-1
```

and hence

```plain text
|S_h(t)| <= (4h-1) sqrt(p).
```

Thus the answer to the three proposed candidates is:

- 4h-2 is the exact projective-open conductor coefficient, with the explicit affine correction +1.

- 4h-1 is the exact dimension for the affine-domain H_c^1, and is the cleanest bound of the form C sqrt(p) with no additive term.

- 4h+1 overcounts by two and is not the Euler-characteristic answer.

No H_c^0 or H_c^2 term occurs for t != 0. The only correction between the projective-open and affine sums is the explicit trace 1 at the regular point infinity.

## 1. Pole structure and Artin-Schreier nondegeneracy

Over F_p, reduce f_h as a rational function. Every actual finite pole lies among

```plain text
-1,-2,...,-h
```

and has reduced order at most three. The degree relation

```plain text
deg N_h = 3(h-1),
deg q_h^3 = 3h
```

shows that infinity is never a pole. In fact

```plain text
f_h(X) = O(X^(-3))
```

at infinity; if the leading coefficient of N_h drops modulo p, the vanishing order only increases.

Let the actual poles be x_1,...,x_m, with orders d_1,...,d_m. Then

```plain text
1 <= d_i <= 3 < p.
```

The function f_h cannot be of Artin-Schreier form

```plain text
g^p-g+c.
```

Indeed, every pole of a nonconstant function of that form has order divisible by p: if g has a pole of order a, then g^p-g has pole order pa. Since every pole of f_h has order at most three and p >= 7, this is impossible. There is at least one pole, because a nonzero polynomial of degree 3h-3 cannot cancel the denominator of degree 3h completely.

Consequently the rank-one Artin-Schreier sheaf

```plain text
L_t = L_psi(f_h)
```

is geometrically nontrivial. At an actual pole of order d_i, its Swan conductor is exactly d_i; multiplication by t != 0 does not change the order.

This already handles possible modular cancellations correctly: a canceled pole is simply omitted from the actual pole list, and the conductor becomes smaller.

## 2. The projective-open calculation: coefficient 4h-2

Let

```plain text
V = P^1 minus {x_1,...,x_m}.
```

Unlike the affine summation domain, V contains infinity. The sheaf L_t is lisse at infinity and its Frobenius trace there is

```plain text
psi(f_h(infinity)) = psi(0) = 1.
```

The rank-one Grothendieck-Ogg-Shafarevich formula gives

```plain text
chi_c(V,L_t)
 = chi_c(V,Q_l) - sum_i Swan_(x_i)(L_t)
 = (2-m) - sum_i d_i.
```

Because L_t is geometrically nontrivial,

```plain text
H_c^0(V_bar,L_t) = 0,
H_c^2(V_bar,L_t) = 0.
```

The first equality also follows directly from connectedness and nonproperness: a compactly supported locally constant section must vanish. The second follows from Poincare duality, since H_c^2 is dual to the geometric invariant space of L_t^vee, and that invariant space is zero.

Therefore

```plain text
dim H_c^1(V_bar,L_t)
 = m - 2 + sum_i d_i
 = sum_i (d_i+1) - 2.                       (2.1)
```

The trace formula is

```plain text
S_h(t) + 1
 = -Tr(Frob_p | H_c^1(V_bar,L_t)).           (2.2)
```

Deligne's weight bound gives

```plain text
|S_h(t)+1|
 <= (m-2+sum_i d_i) sqrt(p).                 (2.3)
```

If all h candidate points are genuine triple poles, then m=h and sum d_i=3h, so

```plain text
dim H_c^1(V_bar,L_t) = 4h-2,
|S_h(t)+1| <= (4h-2)sqrt(p).                 (2.4)
```

Removing the infinity term yields the sharp standard affine estimate

```plain text
boxed:
|S_h(t)| <= (4h-2)sqrt(p)+1.                 (2.5)
```

This is the direct specialization of the classical Bombieri conductor formula

```plain text
sum_i (d_i+1)-2.
```

## 3. The affine-domain calculation: dimension 4h-1

Now work directly on

```plain text
U = A^1 minus {-1,...,-h}
  = P^1 minus {-1,...,-h,infinity}.
```

Assume first that all h finite points are triple poles. Then

```plain text
chi_c(U,Q_l) = 2-(h+1) = 1-h,
sum Swan = 3h,
chi_c(U,L_t) = 1-4h.
```

Again H_c^0=H_c^2=0, hence

```plain text
dim H_c^1(U_bar,L_t) = 4h-1.                (3.1)
```

The affine trace formula has no local term:

```plain text
S_h(t) = -Tr(Frob_p | H_c^1(U_bar,L_t)).     (3.2)
```

Therefore

```plain text
boxed:
|S_h(t)| <= (4h-1)sqrt(p).                   (3.3)
```

The relation between Sections 2 and 3 is exact. Since U=V minus {infinity}, the localization sequence gives

```plain text
0 -> Q_l -> H_c^1(U_bar,L_t)
   -> H_c^1(V_bar,L_t) -> 0.                 (3.4)
```

Frobenius acts as 1 on the left-hand copy of Q_l. Thus the affine H_c^1 consists of one weight-zero boundary class plus the 4h-2 dimensional projective-open part. Equation (3.4) is precisely the identity

```plain text
S_h(t) = -1 - Tr(Frob_p | H_c^1(V_bar,L_t)).
```

This also explains why replacing the exact mixed-weight estimate by a uniform square-root estimate costs one in the coefficient.

If some denominator points become removable modulo p but the implementation still deletes all h points, the same affine calculation remains a valid upper bound. Such a removed regular point has Swan conductor zero but still contributes one boundary point. In general, if m of the h deleted points are actual poles, then

```plain text
dim H_c^1(U_bar,L_t)
 = h-1 + sum_(i=1)^m d_i
 <= 4h-1.                                      (3.5)
```

If instead the sum includes every removable point and deletes only actual poles, use the sharper formula (2.3).

## 4. Where the claimed 4h+1 came from

The claimed count

```plain text
h+1 + sum Swan = 4h+1
```

counts the h finite boundary points and infinity, but omits the Euler-characteristic subtraction by two.

For a rank-one sheaf on P^1 minus S, the correct dimension, once H_c^0 and H_c^2 vanish, is

```plain text
#S - 2 + sum Swan.                            (4.1)
```

For the affine domain, #S=h+1, so (4.1) gives

```plain text
(h+1)-2+3h = 4h-1.
```

If infinity is retained because the sheaf is regular there, #S=h, giving

```plain text
h-2+3h = 4h-2.
```

Thus 4h+1 is not a different convention; it is an Euler-characteristic bookkeeping error.

## 5. Exact trace-dictionary verdict

For t != 0, there are no hidden cohomological correction terms.

On the affine domain:

```plain text
H_c^0 = 0,
H_c^2 = 0,
S_h(t) = -Tr(Frob_p | H_c^1).
```

On the projective-open domain containing infinity:

```plain text
H_c^0 = 0,
H_c^2 = 0,
S_h(t)+1 = -Tr(Frob_p | H_c^1).
```

The +1 is the ordinary local Frobenius trace at infinity, not an H_c^0 or H_c^2 contribution.

The hypothesis t != 0 is essential. At t=0, the sheaf is constant, H_c^2 is nonzero, and the sum is simply the cardinality of the domain; none of the nontrivial-sheaf cancellation statements applies.

## 8. Final bankable statement

For every prime p>=7, every 1<=h<p, and every t in F_p^*, let x_1,...,x_m be the actual poles of

```plain text
t N_h(X) / product_(j=1)^h (X+j)^3
```

with reduced orders d_1,...,d_m. Then

```plain text
|S_h(t)+1|
 <= (m-2+sum_i d_i) sqrt(p),                         (8.1)
```

where S_h(t) sums over the affine regular points and the +1 is the value at infinity. Hence

```plain text
|S_h(t)|
 <= (m-2+sum_i d_i) sqrt(p)+1
```

If the implementation deletes all h denominator points whether or not they are actual poles, then uniformly

In particular, the parallel worker's (4h+1)sqrt(p) inequality is true but nonsharp; the corrected standard constant is (4h-2)sqrt(p)+1, or 4h-1 when a single coefficient multiplying sqrt(p) is required.
