# 0. Audit of the new Delta/COINC reduction

The algebraic part D1-D4 is correct, with one normalization caveat and two later corrections.

## 0.1 D1-D4

For

```plain text
Delta_(r,h) = b_r c_(r+h) - b_(r+h)c_r,
```

the h=1 value is

```plain text
Delta_(r,1) = -W_(r+1) = 1/(r+1)^3.
```

The cleared recurrence therefore gives

```plain text
Delta_(r,h)
 = N_h(r)/product_(j=1)^h (r+j)^3.
```

So D1 has the correct sign.

Orthogonality gives exactly

```plain text
sum_(h<=H) C_h
 = #S_H/p + (1/p) sum_(t!=0) B_t(H).
```

Parseval gives exactly

```plain text
sum_(t!=0) |B_t(H)|^2
 = p N_coinc(H) - (#S_H)^2.
```

Under COINC,

```plain text
N_coinc(H) <= (#S_H)^2/p + K #S_H,
```

Cauchy-Schwarz gives

```plain text
sum_(h<=H) C_h
 <= #S_H/p + sqrt(K #S_H).
```

These statements are correct.

## 0.2 The one-scale sigma claim needs an extra lemma

The pair count is actually an equality, with the stated nonwrapping convention:

```plain text
Q_p(D) = sum_(h<=D) C_h.
```

At the single scale H=p^(2/3), COINC gives

```plain text
Q_p(H) << p^(5/6).
```

This is stronger than H^(3/2)=p at that one scale. But it does not by itself establish

```plain text
Q_p(D) << D^(3/2) p^eps for every D.
```

The sigma-ladder theorem quoted in the question assumes the latter uniform-in-D statement. A one-scale version of the ladder may be true and useful, but it must be stated and proved separately. Therefore the implication

```plain text
COINC only at H=p^(2/3) => sigma=3/2
```

is not yet justified by the quoted all-D ladder.

## 0.3 The per-pair Weil error is generically quadratic in the degrees

For a curve of bidegree approximately

```plain text
(3h,3h'),
```

the arithmetic genus is approximately

```plain text
(3h-1)(3h'-1) = O(hh').
```

Therefore the generic per-pair Weil error is

```plain text
O(hh' sqrt(p)),
```

not O((h+h')sqrt(p)), unless a separate genus-collapse theorem is proved for this special family.

Summing over h,h'<=H gives the generic total error

```plain text
O(H^4 sqrt(p)).
```

To make this no larger than the COINC allowance K #S_H, which is of order pH, one would need

```plain text
H <= p^(1/6)
```

up to constants. This is even worse than the p^(1/4) range stated in D6. The death conclusion remains valid: per-pair Weil cannot reach the useful range and never beats the elementary small-H bound.

# 1. Exact fourth-moment dictionary

## 1.1 Use the pure trace T_h=S_h+1

Q6612 established that the pure rank-(4h-2) sheaf has trace

```plain text
-Tr(Frob_t | G_h) = T_h(t) = S_h(t)+1.
```

The affine sum S_h omits x=infinity. Since f_h(infinity)=0, the missing term is exactly 1.

For an exact finite-field identity attached to G_h, use T_h. If one uses S_h instead, the same orthogonality identity holds on the affine pole complement, but it is the mixed rank-(4h-1) realization. For fixed h, Weil bounds imply that replacing S_h by S_h+1 changes the normalized fourth moment by O_h(Q^(-1/2)), so the limiting moment is unchanged. The finite-p values 2.3 to 3.6 are therefore compatible with 3, but they are not an exact M4 computation.

## 1.2 Orthogonality

Let

```plain text
E_h(Q)
 = #{(x,y,z,w) in U_h(F_Q)^4 :
      f_h(x)+f_h(y)=f_h(z)+f_h(w)}.
```

Then

```plain text
sum_(t in F_Q) |T_h(t)|^4 = Q E_h(Q).
```

The t=0 term is

```plain text
|T_h(0)|^4 = n_h(Q)^4.
```

Removing t=0 and dividing by (Q-1)Q^2 gives

```plain text
A_h(Q)
 = (Q E_h(Q)-n_h(Q)^4)/((Q-1)Q^2).       (1.1)
```

This is the exact additive-energy formula.

## 1.3 Relation with geometric invariants

Put

```plain text
W_h
 = V_h tensor V_h tensor V_h^vee tensor V_h^vee,

I_h = W_h^G_geom.
```

The trace formula on G_m gives

```plain text
A_h(q^m)
 = Tr(Frob_q^m | I_h) + O_h(q^(-m/2)).    (1.2)
```

The arithmetic Frobenius action on I_h has finite-order eigenvalues. Hence, after restricting to extension degrees m divisible by their common order,

```plain text
lim A_h(q^m) = dim I_h = M4(G_h).         (1.3)
```

Equivalently, M4 is the total weight-6 multiplicity in the virtual sequence

```plain text
q^m E_h(q^m)-n_h(q^m)^4.                 (1.4)
```

The leading q^(4m) term cancels between the two terms. The surviving q^(3m) coefficient is the fourth moment.

This is the precise multiplicity/weight bookkeeping requested in Task 1.

# 2. Why V4 does not have three relevant irreducible components

The equation defining V4_h is one equation in four curve variables. Thus every hypersurface component has dimension 3.

The three universal loci are

```plain text
A_h = {z=x, w=y},
B_h = {z=y, w=x},
C_h = {y=rho_h(x), w=rho_h(z)}.
```

Each is isomorphic to U_h^2 and therefore has dimension 2. Consequently none can be an irreducible component of V4_h.

Their geometric roles are different.

```plain text
A_h and B_h:
  horizontal diagonal correspondences;
  the common sum f(x)+f(y) varies.

C_h:
  a vertical reflection cycle;
  both sums are identically zero.
```

The pairwise intersections have dimension at most 1, so the three cycle classes are distinct at the naive geometric level.

Thus the correct statement is not

```plain text
V4_h has exactly three components.
```

The correct statement is

```plain text
The weight-6 primitive correspondence space attached to V4_h
has dimension exactly 3.
```

That primitive qualification includes both operations that the raw component count misses:

```plain text
1. subtract the random bulk n_h(Q)^4/Q;
2. retain the codimension-1 weight-6 classes that survive the subtraction.
```

The diagonal and reflection surfaces live precisely at this codimension-1 level.

# 3. The clean convolution and representation-theoretic formulation

Let P_h be the augmentation perverse sheaf from Q6612:

```plain text
P_h = kernel((f_h)_* Q_l[1] -> Q_l[1]).
```

Let *mid denote middle additive convolution. Fourier transform gives, on the nonzero t-line,

```plain text
FT(P_h *mid P_h) = G_h tensor G_h.        (3.1)
```

Therefore

```plain text
M4(G_h)
 = dim End_G_geom(V_h tensor V_h)
 = dim End(P_h *mid P_h)                  (3.2)
```

in the semisimple convolution category after removing negligible objects.

Because V_h is symplectic,

```plain text
V_h tensor V_h
 = Sym^2(V_h)
   direct-sum Lambda^2_0(V_h)
   direct-sum 1.                          (3.3)
```

The last line is the symplectic form. Under inverse Fourier transform, that invariant line is the punctual summand at additive value 0. Geometrically it is represented by the reflection cycle C_h. The commutativity sign on the convolution side depends on the perverse/Fourier convention; on the representation side it is unambiguously the alternating line in Lambda^2(V_h).

Thus the exact missing lemma is equivalent to

```plain text
[SCONV(h)]

1. Sym^2(V_h) is geometrically irreducible.
2. Lambda^2_0(V_h) is geometrically irreducible.
3. The alternating invariant line has multiplicity exactly one.
```

Under geometric irreducibility of V_h, item 3 is automatic from Schur's lemma and the proved alternating self-duality. Hence the real open content is items 1 and 2.

If they hold, the three summands in (3.3) are distinct and multiplicity-free, so

```plain text
M4(G_h) = 1^2+1^2+1^2 = 3.
```

This is the honest replacement for the proposed component count.

# 5. Reflection gives the third contraction, not a fourth

This point can be settled completely.

Write the energy equation as

```plain text
+f(x) +f(y) -f(z) -f(w) = 0.
```

A universal two-by-two cancellation can pair the four signed terms in exactly three ways.

```plain text
Pairing 1:
  +f(x) with -f(z),
  +f(y) with -f(w).
  This gives z=x, w=y.

Pairing 2:
  +f(x) with -f(w),
  +f(y) with -f(z).
  This gives w=x, z=y.

Pairing 3:
  +f(x) with +f(y) using f(rho(x))=-f(x),
  -f(z) with -f(w) using f(rho(z))=-f(z).
  This gives y=rho(x), w=rho(z).
```

There is no fourth pairing of four objects.

A cross-reflection assignment such as

```plain text
z=rho(x), w=rho(y)
```

changes the right side to the negative of the left side. It satisfies the energy equation only on the additional curve

```plain text
f(x)+f(y)=0.
```

Hence it has dimension 1, not dimension 2.

Conclusion:

```plain text
The honest expected fourth moment is 3, not 4.
```

The reflection is exactly what changes the generic non-self-dual baseline M4=2 into the symplectic baseline M4=3.

# 6. What M4=4 would mean

Let

```plain text
r=4h-2 >= 6.
```

For any irreducible symplectic representation,

```plain text
V tensor V
 = Sym^2(V) direct-sum Lambda^2_0(V) direct-sum 1.
```

The three displayed pieces force M4>=3.

If M4=4, semisimplicity and the parity decomposition imply the following precise minimal failure:

```plain text
Exactly one of Sym^2(V) and Lambda^2_0(V)
splits as two distinct irreducible constituents,
while the other remains irreducible.
```

A common constituent between the symmetric and alternating blocks would contribute in both Hom directions and raise M4 by at least 2, not by 1. A repeated constituent would raise a square multiplicity by at least 3. Therefore the statement above is the only multiplicity pattern giving exactly 4.

Larsen's theorem still gives irreducibility of V because M4<=5. But the M4=3 symplectic alternative no longer applies. The proved nontrivial U(2) unipotent excludes a finite geometric group, so M4=4 would leave

```plain text
a proper positive-dimensional subgroup of Sp_r.
```

It would not, by itself, identify that subgroup as a tensor product, an imprimitive normalizer, or a product group. Those are candidates, not consequences. A refined classification using local monodromy or higher moments would then be necessary.

# 7. A useful resultant-only precomputation

Although resultants cannot by themselves certify M4=3, they can certify all local additive-relation data that a future Sidon/Picard-Lefschetz theorem would need.

Fix h and work over Q.

## 7.1 Basic polynomials

Compute

```plain text
q_h(X) = product_(j=1)^h (X+j),
f_h(X) = N_h(X)/q_h(X)^3.
```

Verify

```plain text
gcd(N_h,q_h)=1,
N_h(rho_h(X)) = (-1)^(h-1) N_h(X),
q_h(rho_h(X)) = (-1)^h q_h(X).
```

## 7.2 Critical polynomial

The finite critical points away from the poles are roots of

```plain text
C_h(X)
 = N_h'(X) q_h(X) - 3 N_h(X) q_h'(X).    (7.1)
```

The expected degree is

```plain text
deg C_h = 4h-4.
```

Check

```plain text
gcd(C_h,C_h')=1,
gcd(C_h,q_h N_h)=1.
```

These certify simple finite critical points, no critical pole, and no zero critical value.

## 7.3 Critical-value polynomial

Define the monic squarefree critical-value polynomial

```plain text
D_h(T)
 = monic Res_X(C_h(X), N_h(X)-T q_h(X)^3). (7.2)
```

After removal of any constant/pole artifacts, check

```plain text
deg D_h = 4h-4,
D_h(-T)=D_h(T),
gcd(D_h,D_h')=1,
D_h(0)!=0.
```

The evenness is the critical-value form of reflection.

## 7.4 Exact symmetric-Sidon test

Let

```plain text
m=4h-4.
```

Form

```plain text
R_h(S) = monic Res_T(D_h(T),D_h(S-T)).    (7.3)
```

If the roots of D_h are a_1,...,a_m, then

```plain text
R_h(S) = product_(i,j) (S-a_i-a_j).
```

Define the diagonal-sum polynomial

```plain text
D2_h(S) = 2^m D_h(S/2)
        = product_i (S-2a_i).             (7.4)
```

Then the quotient

```plain text
R_h(S)/D2_h(S)
```

must be an exact square. Let B_h(S) be its monic square root, so

```plain text
B_h(S)=product_(i<j)(S-a_i-a_j).          (7.5)
```

The critical-value set is symmetric Sidon exactly when

```plain text
ord_(S=0) B_h(S) = m/2,

B0_h(S) := B_h(S)/S^(m/2) is squarefree,

gcd(B0_h,D2_h)=1.                         (7.6)
```

Interpretation:

```plain text
- S^(m/2) records the allowed opposite pairs a+(-a)=0.
- squarefreeness of B0 excludes repeated nonzero unordered pair sums.
- gcd(B0,D2)=1 excludes a nontrivial off-diagonal sum equaling 2a.
```

This computation is resultant-only, exact over Z/Q, and practical for h<=8: m<=28 and deg R_h=m^2<=784.

It certifies that the stationary-phase characters have exactly the three expected pair-partition patterns. It does not, without an additional theorem, certify global irreducibility of Sym^2(V_h) and Lambda^2_0(V_h).

# 8. Exact machine certificate for M4 at a fixed h

Because the raw component formulation is false, there is no correct Groebner-free certificate of the form

```plain text
factor one four-variable polynomial and count three factors.
```

There are two correct exact routes.

## 8.1 Route A: tensor-square irreducibility

Construct the geometric local system G_h and certify

```plain text
dim End(Sym^2 G_h)=1,

dim End(Lambda^2_0 G_h)=1,

Hom(Sym^2 G_h,Lambda^2_0 G_h)=0.          (8.1)
```

Together with the already proved unique alternating line, (8.1) gives M4=3.

A computer implementation may use a Gauss-Manin/Fourier connection, form its symmetric and exterior square differential modules, split off the known invariant line in the exterior square, and run an exact absolute-irreducibility test on the two remaining modules. This is the smallest direct certificate, but it is not a mere resultant calculation.

## 8.2 Route B: virtual zeta function of the energy threefold

Choose one good prime p and put Q=p^m. Compute exactly

```plain text
D_m = Q E_h(Q)-n_h(Q)^4.                 (8.2)
```

Form the rational virtual L-function

```plain text
L_mom(T)
 = exp(sum_(m>=1) D_m T^m/m).             (8.3)
```

The trace formula implies rationality. The geometric fourth moment is the total net multiplicity of the weight-6 reciprocal roots/poles, namely those of complex absolute value p^3. The desired certificate is

```plain text
weight-6 part of L_mom(T)
 = 1/(1-p^3 T)^3                         (8.4)
```

after a finite constant-field extension if arithmetic Frobenius permutes invariant lines. More invariantly, the total weight-6 pole multiplicity must be exactly 3.

The point counts E_h(Q) can be computed without enumerating Q^4 tuples. Let

```plain text
mu_m(a) = #{x in U_h(F_Q): f_h(x)=a},
nu_m = mu_m additive-convolved with mu_m.
```

Then

```plain text
E_h(Q) = sum_(s in F_Q) nu_m(s)^2.        (8.5)
```

To make the computation finite, use any explicit Betti-number bound B_h for the compactified multidegree-(3h,3h,3h,3h) hypersurface and its boundary. The first 2B_h exact traces determine the numerator and denominator of (8.3) by Newton identities. In practice, p-adic/Dwork cohomology is preferable to extension-field enumeration.

This route is fully rigorous and directly certifies M4. It is heavier than the proposed component factorization because the moment really is cohomological.

# 10. Final theorem status

The strongest statement justified by the current bank is the following.

```plain text
[THEOREM, CONDITIONAL ON CRIT(h)]

Let h>=2. Assume CRIT(h), the proved reflection identity,
and the confirmed local U(2) unipotent.

Then G_h is a geometrically irreducible symplectic local system

Lambda^2(V_h).

Moreover,

M4(G_h)=3

if and only if both Sym^2(V_h) and Lambda^2_0(V_h) are
geometrically irreducible.

If these equivalent conditions hold, then Larsen's Alternative
and the infinite-order unipotent imply

G_geom(G_h)=Sp_(4h-2).
```

The exact remaining target is therefore

```plain text
[TENSOR-SQUARE_h]
Sym^2(V_h) and Lambda^2_0(V_h) are geometrically irreducible.
```

This is narrower and more accurate than a four-variable component count.
