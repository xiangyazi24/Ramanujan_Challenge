# Executive verdict

There is a substantial simplification.

1. The trace/residue route does give exact closed formulas for

```plain text
T_r(h) = sum_{C_h(x)=0} f_h(x)^(2r),  r=1,2.
```

The formulas are finite, exact, and compatible with the known recurrences. However, the proposed positivity route does not survive calibration: the noncollapse expression has signs +,-,- at h=2,3,4. The critical values are complex, so the variance-looking expression is not positive definite.

1. More importantly, [NONCOLLAPSE_h] has a much cheaper all-h proof under the standing critical-point Morse gate. If all squared critical values were equal, then all 4h-4 simple critical points would lie over only two values +t,-t. Reflection puts exactly 2h-2 critical points over each value, each with fiber multiplicity two. Since deg f_h=3h, this is impossible once

```plain text
2(2h-2) = 4h-4 > 3h,
```

i.e. for every h>=5. The exact W_h coefficients settle h=2,3,4. Thus [NONCOLLAPSE_h] is proved for every h>=2, conditional only on the same separability/Morse hypothesis already present in [PRIMITIVE-MORSE].

1. [BLOCK-PRIMITIVE_h] has a very cheap two-prime certificate protocol. Let n=2h-2=deg A_h. One good prime at which A_h mod q is irreducible proves transitivity. A second good prime whose factorization contains one irreducible factor of prime degree

```plain text
n/2 < p < n
```

proves primitivity. The remaining factor degrees may be arbitrary. Raising the Frobenius permutation to the lcm of the other cycle lengths isolates a pure p-cycle; such a cycle is incompatible with every nontrivial block system because both the block size and the number of blocks are at most n/2.

1. If no large-prime factor appears quickly, there is an exact dynamic-programming compatibility test for every candidate block size. This gives a complete modular certification protocol, not merely a heuristic.

1. There is not yet an all-h structural proof of primitivity from the h-recurrence. Irreducibility plus a squarefree or nearly squarefree discriminant is not enough. The recurrence is not a composition law, so it does not automatically exclude intermediate fields or block systems.

The strategic consequence is:

```plain text
[NONCOLLAPSE_h] is no longer a gap.
The remaining quotient-Galois gap is [BLOCK-PRIMITIVE_h].
```

The independent route [W-IRRED] remains stronger: irreducibility of W_h over Q directly gives squarefreeness and distinct nonzero squared critical values in characteristic zero.

# 1. Normalization and exact bookkeeping

Write

```plain text
q_h(X) = product_{j=1}^h (X+j),
D_h(X) = q_h(X)^3,
f_h(X) = N_h(X)/D_h(X),
C_h(X) = q_h N_h' - 3 q_h' N_h.
```

Then

```plain text
f_h'(X) = C_h(X)/q_h(X)^4,
deg C_h = 4h-4.
```

Put

```plain text
m = 2h-2.
```

After centering at z=X+(h+1)/2, the reflection quotient A_h(U) has degree m, with U=z^2. Its roots u_1,...,u_m parametrize the reflection pairs of critical points. For a critical point x above u_j, define

```plain text
w_j = f_h(x)^2.
```

This is independent of the choice between x and its reflection.

Normalize the mirror critical-value polynomial to be monic:

```plain text
W_h(S) = product_{j=1}^m (S-w_j)
       = S^m + a_1 S^(m-1) + a_2 S^(m-2) + ... .
```

There are two critical points in each reflection block, with values t and -t. Hence

```plain text
T_1(h) := sum_{C_h(x)=0} f_h(x)^2
        = 2 sum_j w_j
        = -2 a_1,                                      (1.1)

T_2(h) := sum_{C_h(x)=0} f_h(x)^4
        = 2 sum_j w_j^2
        = 2(a_1^2-2a_2).                               (1.2)
```

Therefore the two-coefficient noncollapse certificate is

```plain text
Delta_h := (m-1)a_1^2 - 2m a_2
         = m sum_j w_j^2 - (sum_j w_j)^2
         = (2m T_2(h) - T_1(h)^2)/4.                   (1.3)
```

Thus

```plain text
Delta_h != 0  =>  the w_j are not all equal.
```

The converse also holds only in the expected direction for this particular quadratic statistic: Delta_h=0 does not force equality over an arbitrary complex configuration. For the intended use, only nonvanishing is needed.

# 2. Closed trace formula for T_r(h)

Let

```plain text
d = deg C_h = 4h-4,
c_h = lc(C_h),
K_h = Q[X]/(C_h).
```

Because C_h(-j) != 0 at every pole, one has

```plain text
gcd(C_h,q_h)=1.
```

For r>=1, let E_{r,h}(X) be the unique residue class of degree <d satisfying

```plain text
q_h(X)^(6r) E_{r,h}(X) = 1 mod C_h(X).                 (2.1)
```

Define

```plain text
R_{r,h}(X)
  = rem_C_h( N_h(X)^(2r) E_{r,h}(X) ).                 (2.2)
```

Then in K_h, R_{r,h} is exactly the class of f_h^(2r). Therefore

```plain text
T_r(h) = Tr_{K_h/Q}(R_{r,h}).                          (2.3)
```

There is a coefficient-only formula for this trace:

```plain text
T_r(h)
  = (1/c_h) [X^(d-1)] rem_C_h( R_{r,h}(X) C_h'(X) ).   (2.4)
```

Proof: if alpha runs over the roots of C_h, Lagrange interpolation gives

```plain text
[X^(d-1)] rem_C_h(R C_h')
  = c_h sum_alpha R(alpha).
```

Equations (2.1)-(2.4) are a closed exact formula using only polynomial remainder and extended Euclid operations. They give both requested traces by taking r=1,2.

The recurrence-compatible algorithm is therefore:

```plain text
N_{h+1} = P(X+h)N_h - (X+h)^6 N_{h-1},
q_{h+1} = (X+h+1)q_h,
C_{h+1} = q_{h+1}N_{h+1}' - 3q_{h+1}'N_{h+1},
then apply (2.1)-(2.4).
```

This is an exact recurrence-driven computation, but it is not a fixed-order scalar recurrence for T_r(h). The modular inverse is taken in a quotient algebra whose dimension grows linearly with h.

# 3. Closed pole-residue formula

The same trace has a local formula that exposes exactly what the banked pole-value laws do and do not supply.

Since the roots of C_h are the finite critical points,

```plain text
T_r(h)
  = sum_{C_h(alpha)=0} Res_{X=alpha}
      f_h(X)^(2r) C_h'(X)/C_h(X) dX.                   (3.1)
```

At infinity,

```plain text
f_h(X) = O(X^-3),
C_h'(X)/C_h(X) = O(X^-1),
```

so the residue at infinity is zero for every r>=1. The residue theorem gives

```plain text
T_r(h)
  = - sum_{j=1}^h Res_{X=-j}
      f_h(X)^(2r) C_h'(X)/C_h(X) dX.                   (3.2)
```

Set

```plain text
X = -j+z,
Q_{h,j}(z) = q_h(-j+z)/z.
```

Then Q_{h,j}(0)=q_h'(-j) != 0, and (3.2) becomes

```plain text
T_r(h)
 = - sum_{j=1}^h [z^(6r-1)]
     { N_h(-j+z)^(2r) / Q_{h,j}(z)^(6r)
       * C_h'(-j+z)/C_h(-j+z) }.                       (3.3)
```

In particular,

```plain text
T_1(h): extract z^5,
T_2(h): extract z^11.                                  (3.4)
```

This is the requested residue closed form.

It also identifies the limitation of using only the special value

```plain text
N_h(-j)
 = (-1)^(j-1) ((j-1)!)^3 ((h-j)!)^3 b_{j-1}b_{h-j}.
```

That value supplies only the constant term in the analytic factor in (3.3). The residues require the full finite jet through order 5 for T_1 and order 11 for T_2; because C_h contains N_h', a safe recurrence implementation propagates N_h jets through orders 7 and 13, respectively. These jets are obtainable by differentiating the known N_h recurrence, but the pole values alone do not collapse the trace to a product of Apéry numbers.

Thus the residue route is exact and finite, but it does not presently produce a simple positive sum from the pole-value law alone.

# 5. A complete all-h proof of NONCOLLAPSE under the Morse gate

The trace computation is not needed for large h.

## Theorem [NONCOLLAPSE-ALL | MORSE]

Assume C_h is squarefree. Then the squared critical-value map on the reflection quotient is not constant for every h>=2.

For h>=5, the conclusion is purely geometric. For h=2,3,4, it follows from (4.2)-(4.4).

## Proof for h>=5

Suppose all squared critical values equal a single number a.

### Case 1: a=0

Then all 4h-4 simple critical points lie in the fiber f_h=0. At every simple critical point, the local mapping degree is two, so this fiber has total multiplicity at least

```plain text
2(4h-4) = 8h-8.
```

But deg f_h=3h, impossible for every h>=2.

### Case 2: a=t^2 != 0

Every critical value is either t or -t. Reflection exchanges the two values and pairs the 4h-4 critical points, so exactly

```plain text
m = 2h-2
```

critical points lie over each of t and -t. Each is a simple ramification point and therefore has multiplicity two in its fiber. Hence each of the two fibers has degree at least

```plain text
2m = 4h-4.
```

Since deg f_h=3h, one must have

```plain text
4h-4 <= 3h,
```

i.e. h<=4. This contradicts h>=5.

Combining this with the exact base cases proves [NONCOLLAPSE_h] for every h>=2 under the same separability/Morse condition already used by [PRIMITIVE-MORSE].

A useful strengthening is that no asymptotics, residue estimates, or Apéry-number inequalities are required.

Also, the new finite data provide an independent check: W_h is irreducible for 2<=h<=7, and an irreducible polynomial of degree m>=2 over characteristic zero cannot be a pure power (S-a)^m.

# 6. Exact block-system compatibility criterion

Let

```plain text
n = deg A_h = 2h-2.
```

Suppose a permutation sigma in S_n has cycle lengths

```plain text
lambda_1,...,lambda_r.
```

Fix a candidate block system consisting of

```plain text
k blocks, each of size b=n/k,
```

where 1<k<n and 1<b<n.

The following criterion is exact.

## [CYCLE-BLOCK-COMPATIBILITY]

The cycle type (lambda_1,...,lambda_r) is compatible with a block system of k blocks of size b if and only if the point-cycles can be partitioned into packets

```plain text
P_1,...,P_s,
```

and for each packet P_a one can choose an integer d_a such that

```plain text
d_a divides lambda_i for every i in P_a,

sum_{i in P_a} lambda_i/d_a = b,

sum_{a=1}^s d_a = k.                                  (6.1)
```

Interpretation: P_a consists of all point-cycles lying over one d_a-cycle of the induced permutation on blocks. A point-cycle of length lambda_i winds around those d_a blocks and contributes lambda_i/d_a points to each block.

Necessity follows by projecting each point-cycle to the induced block cycle. Conversely, data satisfying (6.1) can be arranged cyclically across d_a blocks, so the condition is sufficient.

This criterion is suitable for an exact dynamic program. For each proper divisor k|n, test whether any packet/divisor decomposition satisfying (6.1) exists. If not, that Frobenius cycle type excludes that block size.

# 7. Cheapest modular certificate protocol

Every modular row must first pass the usual good-reduction checks:

```plain text
q does not divide lc(A_h),
deg(A_h mod q)=n,
A_h mod q is squarefree.
```

Then the irreducible factor degrees of A_h mod q are the cycle lengths of a Frobenius element in the characteristic-zero Galois group.

## Protocol A: two-prime large-cycle certificate

This is the preferred path.

### Step A1: transitivity

Find one good prime q_0 such that

```plain text
A_h mod q_0 is irreducible of degree n.
```

Then A_h is irreducible over Q, and its Galois group is transitive.

### Step A2: primitivity

Find a good prime q_1 whose factorization degree list contains a prime

```plain text
p with n/2 < p < n.                                    (7.1)
```

The other factor degrees may be arbitrary.

Let sigma be the Frobenius permutation. Since all other cycles have total length n-p<p, none has length divisible by p. Raise sigma to the lcm of the other cycle lengths. The result is a pure p-cycle.

A transitive imprimitive group has k blocks of size b, with

```plain text
2<=k<=n/2,
2<=b<=n/2.
```

A pure prime p-cycle can interact with a block system in only two ways:

1. it acts trivially on blocks, so its support lies inside one block and p<=b;

1. it induces a p-cycle on blocks, so p<=k.

Both are impossible when p>n/2. Therefore the transitive group is primitive.

This proves:

```plain text
one irreducible modular specialization
+ one specialization containing a prime factor degree p>n/2
=> [BLOCK-PRIMITIVE_h].                                 (7.2)
```

The commonly quoted upper restriction p<=n-2 is not needed for primitivity. It becomes relevant only when applying stronger Jordan theorems to conclude containment of A_n. Once primitivity is known, a prime cycle with p<=n-3 gives the standard Jordan upgrade to A_n.

A related free shortcut is the cycle type

```plain text
(n-1,1).
```

Any transitive group containing such a permutation is primitive, even when n-1 is composite: the block containing the fixed point is invariant under the (n-1)-cycle and hence can contain either none or all of its support.

## Protocol B: complete divisor elimination

If Protocol A does not find a large prime cycle quickly:

1. Initialize the candidate set with every proper divisor k of n.

1. For each good auxiliary prime, factor A_h mod q and record the degree partition lambda(q).

1. For each surviving k, run the exact criterion (6.1) with b=n/k.

1. Delete k whenever lambda(q) is incompatible with such a block system.

1. Stop when no candidate remains.

The machine certificate should store

```plain text
h, n, q,
factor degrees,
degree-preservation and squarefreeness checks,
which candidate block sizes the pattern eliminates.
```

For independent verification, also store the modular factors or coefficient hashes.

## Protocol C: 2-transitivity fallback

A stronger but more expensive certificate is to prove that the point stabilizer is transitive. If alpha is a root of A_h, factor

```plain text
A_h(X)/(X-alpha)
```

over Q(alpha). Irreducibility of the degree n-1 factor proves 2-transitivity and hence primitivity.

Equivalently one can use an ordered-pair resolvent of degree n(n-1). This is deterministic but much more expensive than Protocol A or the divisor DP.

# 8. What discriminants and the recurrence do not prove

## 8.1 Irreducibility is not primitivity

The new exact result A_h irreducible for 2<=h<=7 proves transitivity only. A transitive group may preserve a nontrivial block system.

## 8.2 A transposition is not enough

A squarefree-discriminant or tame simple-ramification argument often produces a transposition in the Galois group. Transitivity plus a transposition does not imply primitivity. An imprimitive wreath product can contain transpositions supported inside its blocks.

The graph formed by the conjugates of that transposition may have its connected components equal to the unknown blocks. Thus “discriminant-adjacent squarefreeness” does not by itself close [BLOCK-PRIMITIVE_h].

## 8.3 The h-recurrence is not a composition law

The recurrence

```plain text
N_{h+1}=P(X+h)N_h-(X+h)^6N_{h-1}
```

propagates a fixed-rank marked state, but A_{h+1} is obtained after differentiation, centering, quotienting by reflection, and elimination. There is no known identity expressing A_{h+1} as a polynomial composition through A_h.

Therefore the recurrence does not currently imply that the field Q(root(A_h)) has no proper intermediate fields. Any structural primitivity theorem would need a new ingredient, for example:

```plain text
- a uniformly forced large prime inertia/Frobenius cycle;
- an indecomposability theorem for the quotient critical cover;
- a recurrence for block resolvents showing that none can acquire a rational root;
- a monodromy theorem for a larger parameterized family containing the discrete h-specializations.
```

The absence of any symmetry beyond reflection is strong evidence, but not a proof.

# 9. Interaction with W_h irreducibility

The two single-variable routes should be kept distinct.

## Quotient critical-point route

```plain text
A_h irreducible + primitive action + NONCOLLAPSE
=> the squared-value fibers are singleton blocks
=> W_h squarefree and nonzero
=> full Morse critical values.
```

After Section 5, the only missing item in this route is primitivity.

## Critical-value route

If W_h is irreducible over Q and deg W_h=m>=2, then in characteristic zero it is squarefree and cannot have zero constant term. Since its degree already equals the number of reflection blocks, its roots are exactly m distinct nonzero squared critical values. Thus

```plain text
W_h irreducible
=> full Morse directly.                                 (9.1)
```

No separate proof of A_h primitivity or noncollapse is needed on this route.

The new exact results A_h irreducible and W_h irreducible for h=2,...,7 therefore support two genuinely independent all-h programs.

The expected fast path is two primes per h, although that expectation is heuristic. The certificate verifier itself is completely deterministic.

# 12. Required self-audit

## (a) Least-confident step

The least-confident part is not the trace formula, the fiber-degree noncollapse proof, or the modular block criterion; those are exact. It is the prospect of deriving all-h primitivity structurally from the existing h-recurrence. I see no valid implication from the recurrence to the absence of intermediate fields. The proposed large-prime Frobenius protocol is a certification design, not an all-h existence theorem for the needed primes and cycle patterns.

A secondary implementation risk is normalization of the centered quotient A_h when powers of 2 and primitive contents are removed. The modular verifier must check degree preservation and work with the exact primitive integer polynomial used by the irreducibility certificates.

## (b) Likely blind spot

The main blind spot was treating

```plain text
Delta_h = m sum w_j^2 - (sum w_j)^2
```

as though it were a positive variance. It is not: the w_j are complex, and the exact signs at h=2,3,4 are +,-,-. Any successful positivity argument would need Hermitian quantities such as sum |w_j|^2, which are not algebraic traces over Q and do not directly control the coefficient identity.

A second blind spot to avoid is the false shortcut

```plain text
irreducible + transposition => primitive.
```

Imprimitive wreath-product groups show that this fails. The correct certificate must eliminate block sizes explicitly or produce a cycle, such as a prime cycle longer than n/2, that no nontrivial block system can support.
