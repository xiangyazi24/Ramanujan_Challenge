## 1. Conditional GRAM-OP proposition

### Status: PROVED

Write

```plain text
S_total = sum_(h<=H) L_h,
B_t(H)  = sum_(h<=H) S_h(t).
```

The Fourier normalization is exact:

```plain text
Gamma_(h,k)
 = sum_(t!=0) S_h(t) conjugate(S_k(t))
 = p E_(h,k).
```

Thus Gamma is positive semidefinite, being the Gram matrix of the column vectors (S_h(t))_(t!=0). For the all-ones vector,

```plain text
1^* Gamma 1
 <= ||Gamma||_op ||1||_2^2
 <= C p^2 H.
```

The centered variance identity is also exact:

```plain text
1^* Gamma 1
 = sum_(t!=0) |B_t(H)|^2
 = p N_coinc(H) - S_total^2.
```

Indeed, summing over all t counts equal Delta-values with weight p, while the removed t=0 term is exactly S_total^2. Therefore

```plain text
N_coinc(H)
 <= S_total^2/p + C p H.
```

For H=ceil(p^(2/3)) and p>=64, the estimate used in the manuscript is valid:

```plain text
H <= p/2 - 2.
```

Hence, for every h<=H,

```plain text
L_h = p-2-h >= p/2,
S_total >= pH/2,
C p H <= 2 C S_total.
```

So the advertised COINC form follows with K=2C:

```plain text
N_coinc(H)
 <= S_total^2/p + 2 C S_total.
```

The zero detector should be written with an absolute value at the intermediate step, although this does not alter the result:

```plain text
sum_(h<=H) C_h
 = S_total/p + (1/p) sum_(t!=0) B_t(H)
 <= S_total/p
    + (1/p) |sum_(t!=0) B_t(H)|
 <= S_total/p
    + (1/p) sqrt((p-1) sum_(t!=0)|B_t(H)|^2)
 <= S_total/p + sqrt(C p H).
```

This is exactly the displayed small-gap conclusion.

### Constant in the block-energy conclusion

The manuscript uses

```plain text
F_p
 <= ceil(M/H) (M + 2 sum_(1<=h<H) C_h).
```

Replacing the sum to H-1 by the proved upper bound through H is harmless. For p>=64,

```plain text

ceil(M/H) <= 2 p^(1/3),
S_total <= pH.
```

Therefore

```plain text

 <= 2 p^(1/3)
    (p + 2H + 2 sqrt(C p H))
 <= 2 p^(1/3)
    (p + 4 p^(2/3) + 2 sqrt(2C) p^(5/6)).
```

The last expression is bounded by

```plain text
(10 + 4 sqrt(2C)) p^(4/3).
```

The constant is coarse but correct. There is no missing factor of p, H, or 2.

### The new Delta identity

The proposition currently uses

```plain text
f_h(r) = Delta_(r,h) = N_h(r)/prod_(j=1)^h(r+j)^3
```

as though already proved. It is correct, but the section must bank it explicitly. Here is the complete proof.

For fixed r, set

```plain text
z_h = Delta_(r,h)
    = b_r c_(r+h) - b_(r+h) c_r.
```

Then

```plain text
z_0 = 0,
z_1 = b_r c_(r+1) - b_(r+1)c_r
    = -W_(r+1)
    = 1/(r+1)^3.
```

Applying the recurrence to the second index gives

```plain text
(r+h+1)^3 z_(h+1)
 = P(r+h) z_h - (r+h)^3 z_(h-1).
```

Define

```plain text
D_h = prod_(j=1)^h (r+j)^3 z_h.
```

Then D_1=1, D_2=P(r+1), and clearing denominators in the recurrence gives

```plain text
D_(h+1)
 = P(r+h) D_h - (r+h)^6 D_(h-1).
```

These are exactly the initial values and recurrence defining N_h(r). Hence

```plain text
D_h = N_h(r),
Delta_(r,h)
 = N_h(r)/prod_(j=1)^h(r+j)^3.
```

Thus item (1) is fully proved once this lemma is inserted.

### 3.1 Fatal d=0 shell error

The subsection defines

```plain text

```

It then claims


```plain text

```

and each diagonal entry is nonnegative:

```plain text
E_(h,h) = sum_a q_h(a)^2 >= 0.
```

The actual cross-correlation protocol defines signed shells only for

```plain text

```

and treats the same-gap diagonal separately. The reports producing the constants 0.80 and 0.049 likewise exclude d=0.

Mandatory replacement:

```plain text

A_d(H) = sum_(h=1)^(H-d) E_(h,h+d),

V_off(H)
 = (1/(p^2 H)) sum_(d=1)^(H-1) |A_d(H)|^2.

The exact computations give
max_(1<=d<H) |A_d(H)|/p <= 0.80,
V_off(H) <= 0.049.
```

The same correction is required in the final compatibility paragraph. The valid shell target is

```plain text

```

```plain text

```

Then

```plain text
sum_(h,k<=H) E_(h,k)
 = A_0(H) + 2 sum_(d=1)^(H-1) A_d(H)
```

and Cauchy-Schwarz gives

```plain text
|sum_(d=1)^(H-1) A_d(H)|
 <= sqrt(H) (sum_(d=1)^(H-1)|A_d(H)|^2)^(1/2)
```

## 4. Rowwise blocking term and the Q6602 verdict

### Status: FIXABLE

The following parts match Q6602 exactly.

For fixed h,

```plain text
R_h^abs(H)
 = sum_(k<=H,k!=h) |E_(h,k)|
```

is the absolute off-diagonal row obstruction, and

```plain text
M_h^off(H)
 = sum_(k<=H,k!=h) E_(h,k)^2
```

is its second-moment precursor. The exact signed contraction is

```plain text
M_h^off(H)
 = sum_(a,b in F_p)
   q_h(a) q_h(b) M_(3,h)^off(a,b),

M_(3,h)^off(a,b)
 = sum_(k<=H,k!=h) nu_k(a) nu_k(b).
```

The baseline terms vanish because

```plain text
sum_a q_h(a)=0.
```

The orientation mismatch with the proved triple-return theorem is stated correctly: the latter has two gaps at one base point and value zero, whereas the row contraction has one varying family index, two independent base points, and arbitrary values (a,b).

The general row-to-energy ledger also matches Q6602:

```plain text
R_H = max_(h<=H) sum_(k<=H)|E_(h,k)|,

F_p
 << p^2/H + p sqrt(R_H/H) + p.
```

The exponent verdicts are correct:

```plain text
R_H << pH^2  =>  F_p << p^(5/3) after optimization,
R_H << pH    =>  middle term p^(3/2).
```

Thus the unconditional row estimate does not reproduce the proved p^(3/2) theorem, and an individual fourth moment only reaches the existing ceiling.

### Equivalent forms is false

The text says the obstruction has three equivalent forms. They are not equivalent. The combinatorial formula for R_h^abs is exact, the signed-contraction formula for M_h^off is exact, but the bridge is only the one-way Cauchy inequality

```plain text
R_h^abs(H)
 <= sqrt(H-1) (M_h^off(H))^(1/2).
```

Small R_h^abs does not imply a corresponding small second moment. Replace three equivalent forms by

```plain text
three linked formulations: an exact absolute-row obstruction, a
sufficient second-moment control obtained by Cauchy-Schwarz, and an
exact signed joint-value expansion of that second moment.
```

### The diagonal must be displayed in the useful row ledger

The full Schur row is

```plain text
sum_(k<=H)|E_(h,k)|
 = E_(h,h) + R_h^abs(H),
```

because E_(h,h)>=0. The sharp Cauchy split is therefore

```plain text
sum_(k<=H)|E_(h,k)|
 <= E_(h,h)
    + sqrt(H-1) (M_h^off(H))^(1/2).
```

Applying Cauchy to the diagonal as well would introduce an artificial sqrt(H) loss. Insert this line before defining R_H.

### Missing sharp surviving Q6602 target

Q6602 did not stop at the negative fourth-moment verdict. Its sharp surviving row target is

```plain text
[ROW-MIX4]
max_(h<=H) M_h^off(H) << pH.
```

Together with the natural diagonal bound

```plain text
E_(h,h) << p,
```

this gives

```plain text
R_H << p + H sqrt(p).
```

At H=p^(2/3), the general row ledger yields

```plain text
p^2/H                     = p^(4/3),
p sqrt((p+Hsqrt(p))/H)   << p^(4/3),
```

and therefore

```plain text
F_p << p^(4/3).
```

This is important for route accounting. The operator target is a genuine spectral escape from absolute summation, but it is not the only surviving sufficient target. The mixed row second moment remains another exact route to the same exponent.
