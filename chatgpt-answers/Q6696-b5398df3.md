S_D <= D T_0 + M_2(D)/T_0.                         (0.1)

# 1. Verification of the wall-breaking chain

For integer-valued R_h>=0,

```plain text
S_D = sum_{h<=D} R_h
    = sum_{t>=1} A_D(t).                                (1.1)
```

Split at T_0:

```plain text
sum_{t<=T_0} A_D(t) <= D T_0.                           (1.2)
```

For t>T_0, the definition of Z_D gives

```plain text
A_D(t) <= Z_D/t^2,
```

and therefore

```plain text
sum_{t>T_0} A_D(t)
 <= Z_D sum_{t>T_0} 1/t^2
 <= Z_D/T_0.                                            (1.3)
```

This is [ZERO-TAIL-2]. Also

```plain text
t^2 A_D(t)
 <= sum_{h:R_h>=t} R_h^2
 <= M_2(D),                                             (1.4)
```

so Z_D<=M_2(D). Combining (1.1)-(1.4) gives (0.1).

With D=sqrt(N)L,

```plain text
T_0 approximately N^(1/4)L^(-1/2),
D T_0 approximately N^(3/4)L^(1/2),
N/T_0 approximately N^(3/4)L^(1/2).                    (1.5)
```

Thus the proposed implication is airtight, up to harmless ceiling constants.

A useful strengthening is worth recording:

```plain text
M_2(D) <= N H(N),
H(N)=N^o(1)
```

still gives

```plain text
S_D <= N^(3/4)L^(1/2)(1+H(N)),                          (1.6)
```

which is o(N) whenever L and H are subpolynomial. Hence the actual arithmetic target may carry polylogarithmic losses.

# 2. Exact clique decomposition

Let

```plain text
A_v = {r : pi(r)=v},
m_v = |A_v|,
```

and define the h-difference multiplicity inside the color v by

```plain text
r_v(h) = #{a : a,a+h in A_v}.                           (2.1)
```

Then

```plain text
R_h = sum_v r_v(h).                                     (2.2)
```

For one h,

```plain text
R_h^2
 = R_h
 + 2 sum_v C(r_v(h),2)
 + 2 sum_{v<w} r_v(h)r_w(h).                            (2.3)
```

Summing over h<=D gives the exact identity

```plain text
M_2(D) = S_D + 2W_D + 2X_D,                             (2.4)
```

where

```plain text
W_D = sum_{h<=D} sum_v C(r_v(h),2)                      (2.5)
```

counts distinct equal-lag edge pairs inside one clique, and

```plain text
X_D = sum_{h<=D} sum_{v<w} r_v(h)r_w(h)                 (2.6)
```

counts equal-lag edge pairs in different cliques.

This separates two genuinely different mechanisms.

- W_D is a short-difference additive-energy count inside individual color sets.

- X_D measures how many distinct colors reuse the same lag. It is not an additive-energy count of one set.

The B1 cross-correlation experiment from the earlier campaign measured intersections between different lag root sets. It does not control X_D, which keeps h fixed and varies both the base and the color.

# 3. Same-clique term: the near part is already controlled

Take two distinct h-edges in one clique,

```plain text
(a,a+h),
(c,c+h),
a<c,
t=c-a.                                                  (3.1)
```

Split W_D into

```plain text
W_D = W_D^near + W_D^far,                               (3.2)
```

according as t<=D or t>D.

## 3.1 Injection into Q_(2D)

Assume t<=D.

If t!=h, the three points

```plain text
a,
a+h,
a+t
```

have one color, and the two distinct gaps h,t are both at most D. Hence this edge-pair gives an object counted by Q_D.

If t=h, the two edges are

```plain text
(a,a+h),
(a+h,a+2h).
```

Then

```plain text
a,
a+h,
a+2h
```

have one color, and the distinct gaps h,2h are at most 2D. Hence this edge-pair is counted by Q_(2D).

A single Q-object can arise from at most two orientations of the same four-point rectangle: h may be the edge length and t the separation, or the two roles may be reversed. Therefore, independently of ordered/unordered normalization,

```plain text
W_D^near <= 2 Q_(2D).                                   (3.3)
```

The factor 2 is deliberately safe. If the project's Q convention fixes an orientation, it may be reducible to 1; no exponent depends on this constant.

Consequently

```plain text
S_D + 2W_D^near
 <= S_D + 4Q_(2D).                                      (3.4)
```

Using the banked estimates

```plain text
S_D <= (3/2)D^2,
Q_H <= 66 H^2(1+log H),                                 (3.5)
```

we obtain

```plain text
S_D + 2W_D^near
 << D^2 log(2D).                                        (3.6)
```

At D=sqrt(N)L with L=N^o(1), this is

```plain text
N^(1+o(1)).                                             (3.7)
```

Thus the diagonal and the nearby same-clique parallelograms are not the wall. They are already at a wall-breaking scale up to harmless subpolynomial factors.

# 4. What window 2/3-sparsity gives for the full same-clique term

Let

```plain text
M_D = 1 + 4D^(2/3)                                      (4.1)
```

be the banked upper bound for the number of points of one color in any interval of length D.

For one color A_v, every a in A_v has at most M_D-1 later points of A_v within distance D. Therefore

```plain text
P_v(D) := sum_{h<=D} r_v(h)
       <= M_D m_v.                                      (4.2)
```

Also

```plain text
max_{h<=D} r_v(h)
 <= min(m_v, max_{h<=D} R_h)
 <= min(m_v,3D).                                        (4.3)
```

Hence

```plain text
sum_{h<=D} r_v(h)^2
 <= (max_h r_v(h)) P_v(D)
 <= M_D m_v min(m_v,3D).                                (4.4)
```

Summing over colors gives

```plain text
S_D + 2W_D
 = sum_v sum_{h<=D} r_v(h)^2
 <= M_D sum_v m_v min(m_v,3D)
 <= M_D min(sum_v m_v^2, 3DN).                          (4.5)
```

The projective energy is

```plain text
E_pi = sum_v m_v^2 << N^(3/2).                          (4.6)
```

Therefore

```plain text
S_D + 2W_D
 << D^(2/3) min(N^(3/2),DN).                            (4.7)
```

At the hatch scale D=sqrt(N)L, the energy alternative is smaller and gives

```plain text
S_D + 2W_D
 << N^(11/6)L^(2/3).                                    (4.8)
```

This is much larger than N. Thus window sparsity and the global color energy do not prove the desired same-clique estimate.

Equation (4.5) is the cleanest unconditional consequence of those two inputs. It also explains the failure: window sparsity controls how many points one color places in one interval, but two h-edges with far-separated starts live in unrelated windows.

The near/far split improves the interpretation:

```plain text
W_D^near << D^2 log D,
```

while all loss in (4.8) may be placed in W_D^far.

# 5. Cross-clique term: no banked independent handle

For fixed h, put

```plain text
q_v = r_v(h),
k_h = #{v:q_v>0}.                                       (5.1)
```

Then

```plain text
X_h := sum_{v<w}q_v q_w
     = (R_h^2-sum_v q_v^2)/2.                           (5.2)
```

The facts

```plain text
k_h<=R_h,
sum_v q_v=R_h
```

do not save anything. In the generic configuration

```plain text
q_v in {0,1},                                           (5.3)
```

one has

```plain text
W_h=0,
X_h=C(R_h,2).                                           (5.4)
```

Thus the cross-clique count may contain essentially the entire off-diagonal part of R_h^2 while every individual color class is maximally sparse.

This is why neither the window lemma nor the global color energy sees X_D. Both are statistics internal to color classes; X_D measures reuse of one lag by many different colors.

Algebraically, a cross-clique pair is

```plain text
N_h(r)=0,
N_h(r')=0,
pi(r)!=pi(r').                                          (5.5)
```

If t=r'-r, then it is a common root of

```plain text
N_h(X),
N_h(X+t).                                               (5.6)
```

This produces the exact stronger interface

```plain text
C_h(t)
 := #{r : N_h(r)=N_h(r+t)=0}
 <= deg gcd_Fp(N_h(X),N_h(X+t)).                        (5.7)
```

No currently banked resultant or shifted-gcd theorem controls the sum of (5.7) over both h and t. The earlier [MESO-SHIFTED-GCD] involved different gap polynomials and a clock shift. Here the same polynomial is translated in the base variable; it is a new family problem.

# 6. A sharp abstract countermodel

The present combinatorial hypotheses do not merely fail quantitatively; they permit a one-lag obstruction.

Assume N is large, D=sqrt(N)L, and D=o(N). Choose one integer

```plain text
d in [D/2,D]
```

and let

```plain text
M = floor(3(d-1)/2).                                    (6.1)
```

Choose M disjoint pairs

```plain text
(a_j,a_j+d)
```

in a left interval of length O(d). This is possible by using alternating blocks of length d. Put the reflected pair

```plain text
(rho(a_j+d),rho(a_j))
```

near the right endpoint, and give these four points one new color. Choose the left and right supports far enough apart that every cross-mirror difference is greater than D. Give every unused point its own singleton color.

Then:

1. Reflection closure holds by construction.

1. Each nontrivial color class has size 4.

1. Each color contributes exactly two short edges, both of difference d.

1. Hence

```plain text
R_d = 2M <= 3(d-1),
R_d approximately 3d.                                  (6.2)
```

1. Every point has at most one forward same-color neighbor within D, so

```plain text
Q_D=0.                                                  (6.3)
```

1. Every interval of length W contains at most two points of one color on either side, so the banked 2/3 window inequality holds with enormous slack.

1. The color energy is

```plain text
sum_v m_v^2
 = 16M + (N-4M)
 = N+12M
 = O(N+D),                                              (6.4)
```

far below the allowed O(N^(3/2)).

Nevertheless

```plain text
M_2(D) >= R_d^2
         approximately 9d^2
         approximately N L^2
         >> N.                                          (6.5)
```

The construction uses only O(D) non-singleton points, so it fits whenever N>>D. Other differences inside a reflected four-point class are greater than D and do not affect the short profile.

This countermodel proves that the following inputs, even together, cannot imply [SAME-LAG-L2]:

```plain text
R_h<=3(h-1),
reflection closure,
window 2/3-sparsity,
sum_v m_v^2<<N^(3/2),
Q_D<<D^2 log D.                                         (6.6)
```

The missing fact is arithmetic: the actual Apéry root sets do not allow many colors to synchronize on one lag.

A useful necessary consequence is

```plain text
[SAME-LAG-L2] => R_h << sqrt(N) for every h<=D.          (6.7)
```

For h approximately D, the algebraic degree bound only gives

```plain text
R_h <= 3h approximately 3sqrt(N)L.                      (6.8)
```

Thus even excluding a single saturated high lag requires a factor-L improvement beyond degree. Pointwise R_h<<sqrt(N) is necessary but not sufficient; an L2 average over h is still required.

# 7. Best unconditional bound from the full current toolkit

The exact degree bound gives immediately

```plain text
M_2(D)
 <= 9 sum_{h=2}^D (h-1)^2
 = (3/2)D(D-1)(2D-1)
 < 3D^3.                                                (7.1)
```

At D=sqrt(N)L,

```plain text
M_2(D) << N^(3/2)L^3.                                   (7.2)
```

There is another bound from the row statistic Q_D. The banked identity and Cauchy inequality give

```plain text
S_D^2 <= N(S_D+2Q_D),                                   (7.3)
```

so

```plain text
S_D <= N + sqrt(2NQ_D)
     <= N + sqrt(132) D sqrt(N log D).                   (7.4)
```

Since R_h<=3D,

```plain text
M_2(D) <= 3D S_D
 <= 3ND + 3sqrt(132)D^2 sqrt(N log D).                   (7.5)
```

Thus the best clean unconditional statement is

```plain text
M_2(D)
 << min(
      D^3,
      ND + D^2 sqrt(N log D)
    ).                                                  (7.6)
```

At the hatch scale this is

```plain text
M_2(D)
 << N^(3/2)
    min(
      L^3,
      L + L^2 sqrt(log N)
    ).                                                  (7.7)
```

Both alternatives are far above N. The global edge bound obtained from the energy theorem is weaker at this scale.

For the decomposition, however, we have the sharper structural estimate

```plain text
M_2(D)
 <= S_D + 4Q_(2D)
    + 2(W_D^far+X_D).                                   (7.8)
```

The first two terms are N^(1+o(1)). Therefore the exact minimal residual is

```plain text
[PARALLEL-OFF]

W_D^far + X_D << N^(1+o(1)).                            (7.9)
```

This is strictly weaker than proving [SAME-LAG-L2] from scratch, because all diagonal and near same-color configurations have already been removed.

# 8. Arithmetic forms of the residual

## 8.1 Shifted self-gcd form

A sufficient, stronger theorem is

```plain text
[SELF-SHIFT-GCD]

sum_{h<=D} sum_{t=1}^{N-1}
  deg gcd_Fp(N_h(X),N_h(X+t))
<< N^(1+o(1)).                                          (8.1)
```

Each unordered distinct root pair of N_h contributes at its separation t, so (8.1) implies

```plain text
sum_{h<=D} C(R_h,2) << N^(1+o(1)),                      (8.2)
```

and hence [SAME-LAG-L2].

This statement is a family large-sieve theorem for translates of one gap polynomial. Per-h squarefreeness and absolute irreducibility of the value-collision curve do not imply it.

## 8.2 Lag-profile BDH form

Let kappa_h denote the forced root skeleton. The most natural sharp target is

```plain text
[SAME-LAG-BDH]

sum_{h<=D} (R_h-kappa_h)^2 << N.                        (8.3)
```

Indeed,

```plain text
sum_{h<=D} R_h^2
 <= 2 sum(R_h-kappa_h)^2 + 2 sum kappa_h^2
 << N+D
 << N.                                                   (8.4)
```

With a more precise expansion, the cross term is at most O(sqrt(DN))=o(N). This is exactly a quenched variance theorem over the growing h-family.

## 8.3 Tail-only form

The genuinely weakest wall-breaking statement remains [ZERO-TAIL-2]:

```plain text
max_{t>T_0} t^2 #{h<=D:R_h>=t} << N.                    (8.5)
```

Thus a proof need not control the small Poisson-scale values of R_h at all. It only has to exclude a heavy tail of exceptional lags.

# 10. Strategic conclusion

The new target is correctly identified as the lowest arithmetic wall face, but it does not fall to clique combinatorics.

What is now proved from the toolkit is:

```plain text
M_2(D)
 = automatic N^(1+o(1)) near part
 + 2[far same-color parallels]
 + 2[cross-color lag reuse].                            (10.1)
```

The automatic part consists of

```plain text
diagonal edges
+
near same-clique parallelograms,
```

and is controlled by S_D+Q_(2D).

The new arithmetic object is the return-difference multiset

```plain text
{h : pi(r)=pi(r+h)}
```

viewed simultaneously over all bases. The required theorem must prevent many colors, or many far-apart pieces of one color, from assigning excessive multiplicity to a common h.

The recommended next attack is not another window lemma. It is one of:

1. prove [SAME-LAG-BDH] by a family Frobenius large sieve over h;

1. prove [SELF-SHIFT-GCD] using the renewal identity plus cancellation over translations t;

1. prove only the tail estimate (8.5), perhaps by classifying lags with R_h>T_0 rather than estimating all h.

The third option is the weakest and best aligned with the empirical fact that max R_h=8 while

```plain text
T_0 approximately N^(1/4)L^(-1/2)
```

tends to infinity.

# Required self-audit

## (a) Least-confident step

The least-confident point is the exact constant in

```plain text
W_D^near <= 2Q_(2D).
```

The injection is structurally correct, but the factor is sensitive to whether Q counts ordered or unordered gap pairs and to whether the two orientations of a four-point rectangle are identified. A safe absolute constant is enough for every conclusion; no exponent or residual statement depends on whether the optimal factor is 1, 2, or 4.

The reflection-symmetric countermodel is also an abstract color-partition model, not an actual Apéry orbit. That is intentional: it proves only that the banked combinatorial constraints do not imply the theorem. It does not argue that the Apéry orbit is close to the countermodel.

## (b) Blind spot

The main blind spot is confusing three nearly orthogonal statistics:

```plain text
window multiplicity:
    one color inside one spatial interval;

cross-lag correlation:
    one base or root set compared at h_1 and h_2;

same-lag reuse:
    many bases and many colors realizing one fixed h.
```

The first two can be random-looking while the third is concentrated. The B1 cross-correlation evidence does not itself control [SAME-LAG-L2]. Conversely, the new orbit computation directly measures the correct statistic and shows that the actual Apéry orbit has enormous slack.

A secondary blind spot is expecting full monodromy of each fixed f_h to control the growing-family variance over h at one fixed prime. As in the higher-moment audit, fixed-h geometric randomness does not automatically supply cancellation of the errors as h varies.
