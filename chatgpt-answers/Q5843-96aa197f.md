# Audit of the P3.1 regulator one-form reduction

## 1. Setup

Use the logarithmic basis

```javascript
R = log|r|
T0 = log|t|
A = log|t-r|
X0 = log X
P = log|Xt-r|
Q = log|t-rX|
```

For

```javascript
T=t,
U=r/t,
V=r/(tX),
W=t/(t-rX),
```

write the Rogers differential as

```javascript
dRog(z)=1/2(log|z| dlog|1-z|-log|1-z| dlog|z|).
```

The calculation is purely logarithmic, so branch constants do not enter the differential on a fixed real chamber; they only affect additive constants in the regulator.

## 2. Coefficient table

For each shape, substitute the log variables.

### T=t

```javascript
log|T| = T0
log|1-T| = A-T0
```

Contribution:

```javascript
1/2[T0 d(A-T0)-(A-T0)dT0]
=1/2[T0 dA-A dT0].
```

### U=r/t

```javascript
log|U| = R-T0
log|1-U| = A-T0
```

Contribution:

```javascript
1/2[(R-T0)d(A-T0)-(A-T0)d(R-T0)].
```

### V=r/(tX)

```javascript
log|V| = R-T0-X0
log|1-V| = P-T0-X0
```

Contribution:

```javascript
1/2[(R-T0-X0)d(P-T0-X0)
 -(P-T0-X0)d(R-T0-X0)].
```

### W=t/(t-rX)

```javascript
log|W| = T0-(T0+X0+Q-P)
       = P-Q-X0

log|1-W| = R+X0-P
```

Contribution:

```javascript
1/2[(P-Q-X0)d(R+X0-P)
 -(R+X0-P)d(P-Q-X0)].
```

Adding the four rows and collecting exterior products gives

```javascript
2 sum dRogers
 = -(X0 d(2X0+P-Q)-(2X0+P-Q)dX0)
   +((R-T0)d(A+P+Q-4R-T0-X0)
     -(A+P+Q-4R-T0-X0)d(R-T0)).
```

Therefore with

```javascript
ell = 2X0+P-Q
 g   = A+P+Q-4R-T0-X0
```

we obtain exactly

```javascript
sum dRogers
 = -1/2(X0 dell-ell dX0)
   +1/2((R-T0)dg-g d(R-T0)).
```

The sign and factor 1/2 agree with the proposed identity.

## 3. Branch/sign caveat

The equality is an equality of real logarithmic differentials. It assumes the same absolute-value chamber for all six quantities:

```javascript
r,t,t-r,Xt-r,t-rX
```

Changing a dilogarithm branch adds constants of the form multiples of pi^2 and log terms; these disappear after differentiation but must be fixed separately when comparing endpoint values.

## 4. Translation to the official variable X=M^2

Since

```javascript
X=M^2,
X0=2 log|M|.
```

The first term becomes

```javascript
-1/2(X0 dell-ell dX0)
= -1/2(2log|M| dell-ell d(2log|M|)).
```

Hence

```javascript
dlog X = 2 dlog M
```

must be used in the final normalization. Missing this factor is the likely source of a factor-two discrepancy.

The second term is unchanged except that all occurrences of X are replaced by M^2.

## Conclusion

The proposed P3.1 identity is algebraically correct at the differential level. The required caveat is only the endpoint branch bookkeeping: the differential reduction fixes the regulator form, but the absolute Rogers dilogarithm normalization still requires the chosen real branches and endpoint constants.
