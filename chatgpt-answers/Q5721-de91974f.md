# The first-cell long sum: a Hahn norm, not a symmetric square

## Executive verdict

For

\[
B_M(r)=\sum_{k=0}^{M}\binom Mk^2\binom{M+k}{r}^2
\]

and the order-three operator

\[
L=p_0(M,r)+p_1(M,r)S+p_2(M,r)S^2+p_3(M,r)S^3,
\]

with the endpoint coefficients in the question, the answers are:

1. **The operator is not a symmetric square.** This remains false after an integer shift in \(r\), an arbitrary rational \(3\times3\) gauge, and a hypergeometric scalar twist. The obstruction is the divisor of the companion determinant modulo shift orbits. A symmetric-square rank-three module has orbit valuations divisible by \(3\); here the orbit of \(r-2M\) has valuation \(4\equiv1\pmod3\), and three other orbits also fail.

2. There is an exact classical explanation. Put

   \[
   F_{M,r}(z)=\sum_{k=0}^{M}\binom Mk\binom{M+k}{r}z^k.
   \]

   Then

   \[
   B_M(r)=\operatorname{CT}_z F_{M,r}(z)F_{M,r}(z^{-1}),
   \]

   and \(F_{M,r}\) is a terminating \({}_2F_1\), equivalently a Jacobi polynomial. More importantly, \(B_M(r)\) is the squared norm of the polynomial \(k\mapsto\binom{M+k}{r}\) for the **Hahn weight with the singular parameters**

   \[
   N=M,\qquad \alpha=\beta=-M-1.
   \]

   Thus Christoffel--Darboux and a self-adjoint second-order Hahn difference operator are available exactly. The order three is a quadratic-moment/tensor phenomenon, but the determinant obstruction proves it is not the literal symmetric-square Ore module.

3. The ordinary Casoratian has the exact first-order law

   \[
   p_3(M,r)W_{r+1}+p_0(M,r)W_r=0.
   \]

   The exterior square is again order three, with an explicit operator given below. All forward and backward singular factors are listed in Section 4.

4. A maximal run of at least three consecutive zeros modulo a prime has a **two-endpoint local certificate of logarithmic height \(O(\log M)\)**. A sufficiently long run of vanishing \(j\)-th differences has a nonzero determinant certificate of height

   \[
   8j\log M+O(j^2+j\log j).
   \]

   Hence for \(j=O(\log M)\) the exceptional integer has height \(O((\log M)^2)\). Two shifted flat segments can be coupled by a resultant of height \(O((\log M)^3)\).

5. This is potentially strong enough for the Section 54 ledger, but one bridge is missing: divisibility of overlapping **full shell/Newton carriers** must be shown to force the required flat segment in this \(B_M\)-part without cancellation against the boundary terms. The fixed-order recurrence alone does not supply that bridge.

# 1. Direct representations from the definition

## 1.1 A coefficient kernel

Define

\[
F_{M,r}(z)=\sum_{k=0}^{M}\binom Mk\binom{M+k}{r}z^k.
\tag{1.1}
\]

Since

\[
\binom{M+k}{r}=[x^r](1+x)^{M+k},
\]

we have the exact coefficient representation

\[
\boxed{
F_{M,r}(z)=[x^r](1+x)^M\bigl(1+z(1+x)\bigr)^M.}
\tag{1.2}
\]

Taking the constant term in \(z\) gives

\[
\boxed{
B_M(r)=\operatorname{CT}_z F_{M,r}(z)F_{M,r}(z^{-1}).}
\tag{1.3}
\]

This is an identity over \(\mathbf Z\), not merely a generating-function heuristic.

For \(0\le r\le M\),

\[
\boxed{
F_{M,r}(z)=\binom Mr
{}_2F_1\!\left(\begin{matrix}-M,M+1\\M-r+1\end{matrix};-z\right).}
\tag{1.4}
\]

Equivalently,

\[
\boxed{
F_{M,r}(z)=
\frac{(M!)^2}{r!(2M-r)!}
P_M^{(M-r,r-M)}(1+2z).}
\tag{1.5}
\]

Consequently

\[
\boxed{
B_M(r)=\binom Mr^2
{}_4F_3\!\left(\begin{matrix}
-M,-M,M+1,M+1\\1,M-r+1,M-r+1
\end{matrix};1\right).}
\tag{1.6}
\]

The parameters in (1.5) move with \(r\), so this is not one fixed Jacobi orthogonal family in the variable \(r\). It is nevertheless a compact explanation of the large Ore coefficients.

## 1.2 Legendre constant term

The elementary identity

\[
\sum_{k=0}^{M}\binom Mk^2u^k
=(1-u)^M P_M\!\left(\frac{1+u}{1-u}\right)
\tag{1.7}
\]

gives, with \(u=(1+x)(1+y)\),

\[
\boxed{
B_M(r)=[x^ry^r](1+x)^M(1+y)^M
(1-u)^MP_M\!\left(\frac{1+u}{1-u}\right).}
\tag{1.8}
\]

Thus both a one-variable reciprocal constant term and a bivariate Legendre coefficient are exact.

## 1.3 Exact Hahn interpretation and Christoffel--Darboux

Put

\[
w_M(k)=\binom Mk^2,
\qquad
\phi_r(k)=\binom{M+k}{r}.
\]

Then

\[
\boxed{B_M(r)=\sum_{k=0}^{M}w_M(k)\phi_r(k)^2.}
\tag{1.9}
\]

The weight is exactly a Hahn weight, up to one harmless global sign. Indeed, for

\[
N=M,\qquad \alpha=\beta=-M-1,
\]

\[
\binom{\alpha+k}{k}
\binom{\beta+M-k}{M-k}
=(-1)^M\binom Mk^2.
\tag{1.10}
\]

Its Pearson ratio is

\[
\boxed{(k+1)^2w_M(k+1)=(M-k)^2w_M(k).}
\tag{1.11}
\]

Hence the self-adjoint Hahn operator

\[
\boxed{
(\mathcal H_Mf)(k)
=(M-k)^2\{f(k+1)-f(k)\}
+k^2\{f(k-1)-f(k)\}}
\tag{1.12}
\]

has monic polynomial eigenfunctions \(H_n(k)\) with

\[
\mathcal H_MH_n=n(n-2M-1)H_n.
\tag{1.13}
\]

If \(h_n=\sum_kw_M(k)H_n(k)^2\), their exact Christoffel--Darboux kernel is

\[
\boxed{
\sum_{n=0}^{R}\frac{H_n(x)H_n(y)}{h_n}
=
\frac{H_{R+1}(x)H_R(y)-H_R(x)H_{R+1}(y)}
{h_R(x-y)}.}
\tag{1.14}
\]

Expanding \(\phi_r\) in this Hahn basis turns \(B_M(r)\) into a sum of squared connection coefficients. This is the cleanest classical explanation I found. It is stronger and more precise than saying merely that the summand is hypergeometric.

The \(r\)-evolution of the kernel is also only second order:

\[
\boxed{
(r+1)(1+z)F_{M,r+1}(z)
+(r-M)(1+2z)F_{M,r}(z)
+z(r-2M-1)F_{M,r-1}(z)=0.}
\tag{1.15}
\]

Equation (1.15) follows directly by logarithmically differentiating the polynomial in (1.2). The scalar \(B_M\) is a reciprocal norm/tensor contraction of this rank-two kernel. That makes order three natural. Section 2 proves that the resulting rank-three module is nevertheless not a symmetric square.

# 2. Exact obstruction to a symmetric square

Let \(K=\mathbf Q(M)(r)\), with shift \(\sigma(r)=r+1\). The companion determinant of

\[
p_0y_r+p_1y_{r+1}+p_2y_{r+2}+p_3y_{r+3}=0
\]

is

\[
\delta(r)=-\frac{p_0(M,r)}{p_3(M,r)}.
\tag{2.1}
\]

For an irreducible shift orbit \(\mathcal O=\{\sigma^j\varphi:j\in\mathbf Z\}\), define

\[
\nu_{\mathcal O}(f)
=\sum_{j\in\mathbf Z}v_{\sigma^j\varphi}(f).
\tag{2.2}
\]

The sum is finite for a rational function.

## Theorem 2.1 -- determinant-orbit obstruction

If a rank-three difference module is rationally gauge-equivalent to

\[
\chi\otimes\operatorname{Sym}^2(V)
\]

for a rank-two module \(V\) and a one-dimensional rational or hypergeometric twist \(\chi\), then

\[
\boxed{\nu_{\mathcal O}(\delta)\equiv0\pmod3}
\tag{2.3}
\]

for every shift orbit \(\mathcal O\).

### Proof

For a \(2\times2\) transition matrix \(A\),

\[
\det(\operatorname{Sym}^2A)=(\det A)^3.
\]

A one-dimensional twist multiplies the rank-three determinant by a cube. A rational \(3\times3\) gauge \(U(r)\) changes the determinant by

\[
\frac{\det U(r+1)}{\det U(r)},
\]

whose valuation sum on every shift orbit is zero. If \(y_r=g_rz_r\) with \(g_{r+1}/g_r=t(r)\in K^\times\), then

\[
\delta_z(r)=\frac{\delta_y(r)}{t(r)t(r+1)t(r+2)},
\]

which changes each orbit total by a multiple of \(3\). An integer shift only reindexes the orbit. This proves (2.3). \(\square\)

Now use the supplied factorizations. Constants and signs do not matter. The exact shift-orbit totals of \(p_0/p_3\) are

<tr><td>\(r-2M+\mathbf Z\)</td><td>\(3+1=4\)</td><td>\(1\)</td></tr>
<tr><td>\(r+\mathbf Z\)</td><td>\(1-1-2=-2\)</td><td>\(1\)</td></tr>

The first row alone is decisive.

\[
\boxed{
L\text{ is not a symmetric square after any rational gauge, shift,
or hypergeometric scalar twist.}}
\tag{2.4}
\]

This is an exact invariant obstruction; it does not depend on the bulky middle coefficients.

# 3. Ordinary Casoratian and exterior square

Let \(u,v,w\) be three solutions and set

\[
W_r=\det
\begin{pmatrix}
u_r&u_{r+1}&u_{r+2}\\
v_r&v_{r+1}&v_{r+2}\\
w_r&w_{r+1}&w_{r+2}
\end{pmatrix}.
\]

The companion determinant gives

\[
\boxed{W_{r+1}=-\frac{p_0(M,r)}{p_3(M,r)}W_r,}
\tag{3.1}
\]

or integrally

\[
\boxed{p_3(M,r)W_{r+1}+p_0(M,r)W_r=0.}
\tag{3.2}
\]

For two solutions \(u,v\), define

\[
X_r=u_rv_{r+1}-u_{r+1}v_r,
\]
\[
Y_r=u_rv_{r+2}-u_{r+2}v_r,
\]
\[
Z_r=u_{r+1}v_{r+2}-u_{r+2}v_{r+1}.
\]

Then the exact exterior system is

\[
\boxed{X_{r+1}=Z_r,}
\tag{3.3}
\]

\[
\boxed{p_3(M,r)Y_{r+1}=p_0(M,r)X_r-p_2(M,r)Z_r,}
\tag{3.4}
\]

\[
\boxed{p_3(M,r)Z_{r+1}=p_0(M,r)Y_r+p_1(M,r)Z_r.}
\tag{3.5}
\]

Eliminating \(Y,Z\) yields the scalar exterior-square operator

\[
\boxed{
\begin{aligned}
&p_0(r+1)p_0(r)X_r
-p_0(r+1)p_2(r)X_{r+1}\\
&\quad+p_1(r+1)p_3(r)X_{r+2}
-p_3(r+1)p_3(r)X_{r+3}=0.
\end{aligned}}
\tag{3.6}
\]

Here and below \(M\) is suppressed inside \(p_i\).

# 5. What a consecutive zero run forces

First note the fixed nonzero boundary value

\[
\boxed{B_M(2M)=1.}
\tag{5.1}
\]

Let a prime \(p\) divide a maximal consecutive run

\[
B_M(a),B_M(a+1),\ldots,B_M(b)
\]

with \(b-a+1\ge3\).

If \(a>0\), maximality gives \(B_M(a-1)\not\equiv0\pmod p\). Applying the recurrence at \(r=a-1\) gives

\[
\boxed{p\mid p_0(M,a-1)}
\tag{5.2}
\]

and explicitly

\[
\boxed{
p\mid a(2M-a)(2M-a+1)^3Q(M,a).}
\tag{5.3}
\]

Because of (5.1), \(b<2M\), and maximality gives \(B_M(b+1)\not\equiv0\pmod p\). Applying the recurrence at \(r=b-2\) gives

\[
\boxed{p\mid p_3(M,b-2)}
\tag{5.4}
\]

or

\[
\boxed{
p\mid
2(2b-2M+1)(b-M)b(b+1)^2Q(M,b-2).}
\tag{5.5}
\]

Thus every interior maximal zero run of length at least three forces the prime into the gcd of two explicitly displayed degree-eight integers. For \(a,b=O(M)\), each has logarithmic height \(O(\log M)\).

A non-maximal run can be enlarged to a maximal one. A run beginning at \(a=0\) still has the right-end condition (5.5).

## 5.1 Eliminating the location for a fixed run length

Let \(L=b-a+1\ge3\) and define

\[
\boxed{
\mathcal R_L(M)=
\operatorname{Res}_x\bigl(p_0(M,x-1),p_3(M,x+L-3)\bigr).}
\tag{5.6}
\]

For \(L\ne3\), the two polynomials are coprime over \(\mathbf Q(M)[x]\), so \(\mathcal R_L\ne0\), and every such run forces

\[
p\mid\mathcal R_L(M).
\tag{5.7}
\]

For \(L=3\), both endpoint polynomials contain \(Q(M,x)\), so the raw resultant is identically zero. This is a genuine common singular component, not a computational accident. Divide the common \(Q(M,x)\) before taking the resultant, and retain the alternative local factor \(Q(M,a)\).

The degree of (5.6) is bounded by an absolute constant and its coefficients have polynomial height in \(L\). Therefore, uniformly for \(L=O(\log M)\),

\[
\boxed{\log|\mathcal R_L(M)|=O(\log M).}
\tag{5.8}
\]

A product over \(O(\log M)\) possible lengths has height \(O((\log M)^2)\).

# 6. High finite differences

Suppose

\[
\Delta^jB_M(s)\equiv0\pmod p
\qquad(a\le s<a+L).
\tag{6.1}
\]

Then on the \(L+j\) values \(a,a+1,\ldots,a+L+j-1\), the sequence agrees modulo \(p\) with the Newton polynomial

\[
P(n)=\sum_{h=0}^{j-1}c_h\binom nh,
\qquad c_h=\Delta^hB_M(a).
\tag{6.2}
\]

For \(u,h\ge0\), define

\[
\boxed{
A^{(j)}_{u,h}(M,a)
=\sum_{i=0}^{3}p_i(M,a+u)\binom{u+i}{h}.}
\tag{6.3}
\]

If \(L\ge11\), the recurrence is valid for the \(j+8\) rows \(u=0,\ldots,j+7\). If the coefficient vector \(c=(c_0,\ldots,c_{j-1})\) is nonzero modulo \(p\), then

\[
A^{(j)}(M,a)c=0\pmod p,
\]

so every \(j\times j\) minor is divisible by \(p\).

## Theorem 6.1 -- the determinant is not identically zero

The matrix in (6.3) has rank \(j\) over \(\mathbf Q(M,a)\). Therefore one may choose, target-blindly, the lexicographically first nonzero \(j\times j\) minor

\[
\mathcal E_j(M,a),
\tag{6.4}
\]

and (6.1) with \(c\not\equiv0\) forces

\[
\boxed{p\mid\mathcal E_j(M,a).}
\tag{6.5}
\]

### Proof

If the rank were below \(j\), a nonzero polynomial \(P(n)\) of degree below \(j\) would satisfy \(LP(a+u)=0\) for \(j+8\) consecutive values of \(u\). The polynomial \(LP(a+u)\) has degree at most \(j+7\), so it would vanish identically.

But \(p_0\) has \(r^8\)-coefficient \(-9\), \(p_3\) has \(r^8\)-coefficient \(36\), and \(p_1,p_2\) have \(r\)-degree at most \(7\). If \(P\) has leading coefficient \(c\ne0\), the leading coefficient of \(LP\) is

\[
(-9+36)c=27c\ne0.
\]

Contradiction. \(\square\)

If \(c\equiv0\pmod p\), then the entire \(L+j\)-term segment is a zero run and Section 5 applies.

## 6.1 Height

Assume \(a\le M/2\) and \(j=O(\log M)\). For \(0\le u\le j+7\),

\[
|p_i(M,a+u)|\le C M^8
\]

for an absolute \(C\), while

\[
\binom{u+i}{h}\le2^{j+10}.
\]

Hadamard's inequality gives

\[
\boxed{
\log|\mathcal E_j(M,a)|
\le8j\log M+O(j^2+j\log j).}
\tag{6.6}
\]

Thus

\[
\boxed{j=O(\log M)\quad\Longrightarrow\quad
\log|\mathcal E_j(M,a)|=O((\log M)^2).}
\tag{6.7}
\]

If the same prime produces flat segments at \(a\) and \(a+h\), then, after removing their polynomial shift-gcd,

\[
\operatorname{Res}_x
\bigl(\mathcal E_j(M,x),\mathcal E_j(M,x+h)\bigr)
\tag{6.8}
\]

is a target-blind exceptional integer. Its degree is \(O(j^2)\); for \(h,j=O(\log M)\), its logarithmic height is

\[
O((\log M)^3).
\tag{6.9}
\]

A product over \(O(\log M)\) possible short gaps still has polylogarithmic height \(O((\log M)^4)\), hence is \(o(M^{1/3})\).

This is the precise sense in which the order-three recurrence can be useful. The remaining issue is not height.

# 7. Strategic obstruction for the Newton-carrier problem

The recurrence supplies a polylog-height exceptional integer **once** a common prime is known to create either

- a three-term zero run in \(B_M\), or
- an \(L\ge11\) flat run of \(\Delta^jB_M\).

However, the first-cell shell is \(B_M(r)\) plus explicit boundary terms. Divisibility of overlapping Newton carriers can arise by cancellation between the long \(B_M\)-part and those boundary terms. The recurrence of \(B_M\) does not by itself rule out that cancellation or force (6.1).

Therefore the smallest unresolved distinguished-shell statement is:

> **Bridge theorem needed.** Convert a prime common to the relevant overlapping full-shell/Newton carriers into a zero run or a long flat finite-difference segment of \(B_M\), with only a target-blind polynomial exceptional set of polylogarithmic height.

If that bridge is proved, (5.6) and (6.8) meet the Section 54 height ledger. Without it, a separate determinant chosen after each realized pair is not sufficient.

def C(n, k):
    return comb(n, k) if 0 <= k <= n else 0

    return sum(C(M, k)**2 * C(M + k, r)**2
               for k in range(M + 1))

    return [C(M, k) * C(M + k, r) for k in range(M + 1)]


def add(out, vec, scale, shift=0):
    for k, value in enumerate(vec):
        if 0 <= k + shift < len(out):
            out[k + shift] += scale * value

R.<M,r> = PolynomialRing(QQ)


def C(n,k):
    return binomial(n,k) if 0 <= k <= n else 0


def B(m,s):
    if s < 0 or s > 2*m:
        return ZZ(0)
    return sum(C(m,k)^2*C(m+k,s)^2 for k in range(m+1))


def Q(m,s):
    return (-6*m^3 + 24*m^2*s - 27*m*s^2 + 9*s^3
            + 29*m^2 - 57*m*s + 27*s^2
            - 26*m + 25*s + 7)

p0 = -(2*M-r-1)*(r+1)*(2*M-r)^3*Q(M,r+1)
p3 = 2*(2*r-2*M+5)*(r-M+2)*(r+2)*(r+3)^2*Q(M,r)

# At each fixed M solve for two degree-7 polynomials in r.
fixed = {}
for m in range(10,27):
    rows = []
    rhs = []
    for s in range(0,2*m-2):
        vals = [B(m,s+i) for i in range(4)]
        rows.append([vals[1]*s^j for j in range(8)]
                    + [vals[2]*s^j for j in range(8)])
        rhs.append(-p0(M=m,r=s)*vals[0] - p3(M=m,r=s)*vals[3])
    A = matrix(QQ, rows)
    b = vector(QQ, rhs)
    assert A.rank() == 16
    fixed[m] = A.solve_right(b)

# Total degree <=7: coefficient of r^j has M-degree <=7-j.
def recover(offset):
    ans = R(0)
    for j in range(8):
        d = 7-j
        pts = [(m, fixed[m][offset+j]) for m in list(fixed)[:d+1]]
        cj = R.lagrange_polynomial(pts)(M)
        assert cj.degree(M) <= d
        assert all(cj(M=m) == fixed[m][offset+j] for m in fixed)
        ans += cj*r^j
    return R(ans)

p1 = recover(0)
p2 = recover(8)
print("p1 =", p1)
print("p2 =", p2)

# Final assessment

The order-three operator is **provably not a symmetric square**. Its useful structure is instead:

- a reciprocal constant-term norm of a Jacobi \({}_2F_1\) kernel;
- an exact singular-parameter Hahn norm with a Christoffel--Darboux theory;
- a first-order Casoratian and an explicit order-three exterior square;
- local zero-run and flat-difference certificates of polylogarithmic height.

This is materially stronger than generic holonomicity. It reduces the arithmetic problem to one precise missing bridge between full-shell carrier divisibility and flatness of the distinguished Hahn norm \(B_M(r)\).
