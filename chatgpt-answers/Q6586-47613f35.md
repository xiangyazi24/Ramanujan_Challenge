# Annealed-to-quenched transfer for the Apery collision problem

## Executive verdict

The existing annealed theorems do not imply a quenched bound for the specific consecutive Apery schedule.

There are four different averages in the project, and they must not be merged:

1. The annealed Markov theorem averages an independent map parameter u at every step. A length-T path is averaged over (p-1)^T words.

1. The t-twist average in D3 is Fourier averaging over the p-1 nonzero additive frequencies of one fixed deterministic Delta-array.

1. The r-average in C_h, B_t(H), and N_coinc(H) is already part of the quenched target. It samples consecutive windows of the same orbit, not independent instances.

1. The prime average and the 9424-prime resonance scan are evidence across primes. They do not prove a statement for every fixed prime.

The exact conclusions are:

- The random-schedule Poisson law can leave the one consecutive word exceptional. An O(1/p) annealed error allows an enormous exceptional set because the schedule family has size (p-1)^T.

- Even a perfect Poisson law for visits to the zero fiber would not imply COINC. Poisson visits see only the value Delta=0; COINC is an all-value L2 statement for all a in F_p.

- D3 is already the exact annealed statement in the t variable:

```plain text
(1/(p-1)) sum_{t!=0} |B_t(H)|^2
  = (p/(p-1)) [N_coinc(H)-A_H^2/p],
A_H=#S_H.
```

Thus strong COINC is not a consequence of a separate t-average theorem. It is precisely the required second moment of that t family.

- If one had only an O(1/p) distributional approximation for the correct t family, with no stronger tail control, then a single exceptional frequency contributes enough to recreate the p^(3/2) barrier. It cannot yield a new energy exponent.

- One-step van der Corput in the r direction does not cross m=sqrt(p). The shifted correlation phase has the same O(m) conductor as the original gap phase. The A-process is nontrivial exactly in the range where the direct Weil bound is already better.

- Van der Corput in the m direction does not unlock the cocycle identity. After squaring, it contains two independent anchors r,r'; the identity G_{m+q}(s)=G_q(s+m)G_m(s) only relates products with the same anchor. Forcing the same anchor by Cauchy loses a factor p, which is fatal.

- Reflection gives reality and removes the sine sector, but only a constant-factor simplification, not a power saving.

The cheapest fully true transfer theorem is the exact two-step identity: the annealed two-step return and the full quenched h=2 root density are equal because both count roots of P after a translation. This works only because the annealed parameter space has dimension one at two steps. Starting at three steps, the annealed family has several independent parameters while the quenched family is their one-dimensional arithmetic-progression restriction.

The cheapest new theorem worth attacking is therefore not another Poisson theorem. It is a thin-progression restriction theorem:

```plain text
bounded-complexity short-block observables averaged over all map words
remain square-root orthogonal when restricted to
(u_1,...,u_L)=(r+1,...,r+L),
uniformly after a long deterministic prefix.
```

The named obstruction is:

```plain text
conductor growth under restriction to the deterministic prefix graph.
```

# 1. Identify the annealed family exactly

## 1.1 The random-schedule family

The annealed kernel in Q6456 is

```plain text
K_p(x,y)
 = (1/(p-1)) #{u in F_p minus {-1}: F_{p,u}(x)=y},

F_{p,u}(x)=(u+1)^6/(P(u)-x).
```

A Markov path of length T is generated by independent choices

```plain text
omega=(u_0,...,u_{T-1})
in (F_p minus {-1})^T.
```

The sample space has cardinality

```plain text
Q_schedule=(p-1)^T.
```

The theorem may be uniform in the initial projective state x, but it is still random in the schedule omega.

The actual Apery recurrence uses the single consecutive word

```plain text
omega_Apery=(r,r+1,...,r+T-1)
```

on each nonwrapping window. Uniformity in x does not say that this word is typical among random words.

This distinction survives every strengthening of the annealed theorem. Even an exact Poisson law for a uniform random word would not identify one prescribed word.

## 1.2 The dimension mismatch

After a return to infinity, the first step is deterministically

```plain text
infinity -> 0.
```

An annealed return after positional gap h then averages over approximately h-1 independent map parameters:

```plain text
(u_1,...,u_{h-1}) in (F_p minus {-1})^(h-1).
```

The quenched gap polynomial samples only the arithmetic-progression line

```plain text
(u_1,...,u_{h-1})=(r+1,r+2,...,r+h-1).
```

Thus the annealed average is over dimension h-1, whereas the quenched count C_h is a restriction to a dimension-one subvariety. For h>=3, this has codimension h-2.

An ambient average cannot control a thin subvariety without an additional restriction theorem. This is the exact annealed-to-quenched gap.

## 1.3 Why h=2 is exceptional

At two steps there is only one free parameter. Q6456 proves

```plain text
K_p^2(infinity,infinity)
 = #{u!= -1:P(u)=0}/(p-1)
 = (2+Legendre(-51,p))/(p-1).
```

On the quenched side,

```plain text
N_2(r)=P(r+1).
```

The translation u=r+1 identifies the two root problems. The excluded singular parameters are not roots:

```plain text
P(0)=5,
P(-1)=-5.
```

Hence the full-field quenched root count is exactly

```plain text
#{r in F_p:N_2(r)=0}
 = 2+Legendre(-51,p)
 = 1+2*[Legendre(-51,p)=1].
```

This is a genuine exact annealed-to-quenched transfer theorem.

Boundary warning: this statement concerns the full root count. The nonwrapping C_2 uses a shorter integer window and can differ by endpoint terms of size O(1).

For h>=3, the translation argument disappears because the ambient variables are independent while the quenched variables are constrained to an arithmetic progression.

## 1.4 The prime family

The 9424-prime zero-resonance scan is a cross-prime empirical family. A density-one or average-over-primes statement would still allow exceptional primes. The project target is every fixed prime, so an arithmetic exceptional-prime elimination theorem would be needed. No such monotonicity or rigidity principle is currently available.

# 2. What high annealed moments can and cannot do

## 2.1 A general finite-family transfer lemma

Let Omega be a finite family of size Q, and let X(omega) be a nonnegative integer. For k>=1, write

```plain text
(x)_k=x(x-1)...(x-k+1).
```

Then

```plain text
max_{omega in Omega} X(omega)
 <= k-1 + [Q E_omega (X)_k]^(1/k).                 (2.1)
```

Proof: if X(omega)>=k, then every factor in (X)_k is at least X-k+1, so

```plain text
(X(omega)-k+1)^k <= (X(omega))_k
                  <= sum_eta (X(eta))_k
                  = Q E(X)_k.
```

This proves (2.1).

If Poisson factorial moments hold in the strong form

```plain text
E(X)_k <= C^k,
```

then

```plain text
max X <= k-1 + C Q^(1/k).                            (2.2)
```

This is the correct deterministic consequence of annealed high moments. It uses the size of the family, not merely a positive-proportion typicality statement.

## 2.2 Application to a family of p members

If Q is polynomial in p, for example Q<=p^a, and moments are known up to

```plain text
k=c log p,
```

then

```plain text
Q^(1/k)<=exp(a/c),
```

and (2.2) gives a uniform O(log p) bound for every family member.

For raw Poisson moments rather than factorial moments, the k-th root is of size about k/log k, so k about log p gives a uniform bound of order

```plain text
log p/log log p.
```

Thus high moments can convert annealed to uniform when the target really is one member of a polynomial-size family.

## 2.3 Why this fails for the random-schedule family

For a length-T random schedule,

```plain text
Q=(p-1)^T,
log Q=T log(p-1).
```

Formula (2.2) contains

```plain text
Q^(1/k)=exp(T log(p-1)/k).
```

In the Poisson theorem T is of order p. Moments only up to k=O(log p) would give an exponentially enormous factor. To make Q^(1/k) bounded, one would need moments of order comparable to

```plain text
T log p,
```

not logarithmic order.

Therefore even a long range of annealed Poisson moments cannot certify the one consecutive schedule unless the moment range is nearly as large as the entropy of the whole path family.

## 2.4 Positive proportion is logically insufficient

Suppose a theorem says that all but an O(1/p) fraction of schedules have the desired property. Since the family has (p-1)^T members, it may still contain about

```plain text
(p-1)^T/p
```

bad schedules. The one consecutive word may be among them.

A positive-proportion argument becomes deterministic only if one also has one of the following:

- a transitive symmetry under which the statistic is invariant;

- an amplifier expressing the chosen member as an average of transformed members;

- a discrepancy theorem proving the chosen member samples the ambient family;

- an arithmetic theorem excluding the chosen member from the exceptional locus.

None is currently proved for the consecutive Apery word.

# 3. Poisson visits do not imply all-value COINC

## 3.1 Zero-fiber information is too weak

The annealed Poisson theorem controls visits to one state, infinity, equivalently one zero condition. COINC controls the complete value multiplicity function

```plain text
m_H(a)=#{(r,h) in S_H:Delta_{r,h}=a}
```

through

```plain text
N_coinc(H)=sum_{a in F_p} m_H(a)^2.
```

A zero-count law cannot determine the remaining p-1 fibers.

A simple countermodel makes this exact. Let labels Y_i in F_p be independent with

```plain text
P(Y_i=0)=1/p,
P(Y_i=1)=1-1/p.
```

The number of zeros is binomial and has the usual Poisson approximation in the rare-event range. Nevertheless almost all labels equal 1, so

```plain text
sum_a #{i:Y_i=a}^2
```

is quadratic in the sample size. Thus even an ideal Poisson law for zero visits is compatible with catastrophic all-value coincidence energy.

## 3.2 The Rayleigh law in the current notes is a different object

The vertical value-law note studies Fourier coefficients of the value multiplicities of the sequence b_m mod p. Its exact Parseval identity has the form

```plain text
sum_{frequency!=0}|C_p(frequency)|^2
 = p E_value(p)-p^2.
```

The measured Rayleigh variance 2p is explained by the reflection functional equation for that one value sequence.

The COINC object instead uses the triangular family

```plain text
{Delta_{r,h}:1<=h<=H, 1<=r<=M-h},
```

which has size

```plain text
A_H=H M-H(H+1)/2 about pH.
```

An analogous Rayleigh law for B_t(H) with variance about A_H would indeed imply strong COINC. But the existing Rayleigh statement is not about this triangular family, so it does not transfer.

# 4. D3 is already the exact t-annealed theorem

Put

```plain text
E_H=N_coinc(H)-A_H^2/p.
```

D3 says

```plain text
sum_{t!=0}|B_t(H)|^2=p E_H.                          (4.1)
```

Therefore, for uniform nonzero t,

```plain text
E_t |B_t(H)|^2
 = (p/(p-1)) E_H.                                    (4.2)
```

Strong COINC

```plain text
E_H<=K A_H                                             (4.3)
```

is equivalent, up to the harmless factor p/(p-1), to

```plain text
E_t |B_t(H)|^2<=K A_H.                                (4.4)
```

This is the precise relationship:

- a pointwise estimate for every t is stronger than needed;

- a typical-t statement is not enough unless it includes second-moment tail control;

- COINC itself is the required annealed L2 statement over t.

There is no distinguished t=1 whose typicality would solve the zero count. Additive orthogonality uses every t simultaneously in D2.

## 4.1 Markov consequence under COINC

From (4.4), for every Y>=1,

```plain text
#{t!=0:|B_t(H)|>Y sqrt(A_H)}
 <= K(p-1)/Y^2.                                      (4.5)
```

Thus COINC implies that almost all frequencies have random-size Fourier sums. This is a consequence of COINC, not a route to prove it.

## 4.2 Why an O(1/p) distributional law is dimensionally insufficient

Suppose, hypothetically, that the correct normalized t family had a Rayleigh or Gaussian model with bounded second moment and total-variation error

```plain text
delta=O(1/p).
```

Since trivially

```plain text
|B_t(H)|<=A_H,
```

a bad set of mass delta can contribute as much as

```plain text
delta A_H^2
```

to the average second moment. Hence such a distributional theorem yields at best

```plain text
E_H<<A_H+delta A_H^2.                                 (4.6)
```

With A_H about pH and delta=1/p, this is

```plain text
E_H<<pH+pH^2.                                         (4.7)
```

Strong COINC would require the second term to be O(pH), which forces

```plain text
H=O(1).
```

For the minimal one-scale p^(4/3) target at H=p^(2/3), Q6544 shows that it is enough to have

```plain text
E_H<<p^(2+epsilon).
```

But (4.7) has the outlier term pH^2. Requiring pH^2<=p^2 gives only

```plain text
H<=sqrt(p).
```

The same conclusion follows through the block-energy inequality. From (4.7),

```plain text
sum_{h<=H}C_h
 <= H+sqrt(E_H)
 << H+H sqrt(p).
```

Then

```plain text
F_p
 <= ceil(M/H)[M+2 sum_{h<=H}C_h]
 << p^2/H+p^(3/2).                                    (4.8)
```

No choice of H makes (4.8) strictly smaller than p^(3/2).

Thus an O(1/p) distributional error is exactly too weak by the amount needed to cross the current barrier, even in the hypothetical favorable case where it concerns the correct t family.

At H=p^(2/3), a total-variation-plus-trivial-tail argument would need roughly

```plain text
delta<=1/H^2=p^(-4/3)                                 (4.9)
```

for the minimal p^(4/3) result, and

```plain text
delta<=1/A_H=p^(-5/3)                                 (4.10)
```

for strong COINC.

High moment or subgaussian tail estimates could replace such tiny total-variation errors, but no such theorem is known for the deterministic Delta-array.

# 5. Burgess and van der Corput in the r direction

## 5.1 Exact one-step inequality

Fix a gap m, a nonzero frequency t, and write

```plain text
f_m(r)=Delta_{r,m},
S_m(t)=sum_{r=1}^{M-m} e_p(t f_m(r)).
```

For an integer 1<=Q<=M-m, van der Corput gives

```plain text
|S_m(t)|^2
 <= (N+Q-1)/Q^2
    [Q N
     +2 sum_{q=1}^{Q-1}(Q-q)|C_{m,q}(t)|],          (5.1)

N=M-m,

C_{m,q}(t)
 =sum_{r=1}^{N-q}
   e_p(t[f_m(r+q)-f_m(r)]).
```

This follows by writing the original sum as the average of its first Q translates and applying Cauchy-Schwarz. It is the standard A-process in exact finite form.

Primary Burgess reference:

- D. A. Burgess, On character sums and L-series II, Proc. London Math. Soc. 13 (1963), 524-536.

## 5.2 Conductor after differencing

D1 gives

```plain text
f_m(r)=N_m(r)/prod_{j=1}^m(r+j)^3.
```

Its rational degree and number of poles are O(m). Translation r->r+q does not lower this complexity. The difference

```plain text
f_m(r+q)-f_m(r)
```

still has rational conductor O(m); the union of the two pole sets has size at most O(m). The truncation of the near-complete interval adds an endpoint error O(m+q).

If the shifted phase is not an Artin-Schreier coboundary, the complete Weil bound gives

```plain text
|C_{m,q}(t)|<<m sqrt(p)+m+q.                          (5.2)
```

This is the best standard input. The important point is that differencing does not reduce m.

For bounded-conductor trace functions, van der Corput and Fourier transfer can go below the square-root range; see:

- E. Fouvry, E. Kowalski, P. Michel, C. S. Raju, J. Rivat, K. Soundararajan, On short sums of trace functions, especially Theorems 1.1 and 1.2.

Their hypotheses require pointwise and Fourier complexity bounded independently of p. Here the conductor is proportional to m, so the theorem ceases to be uniform precisely in the growing-gap range.

## 5.3 Optimization and the barrier

Choose Q<=sqrt(p). Then the endpoint term q in (5.2) is at most sqrt(p) and can be absorbed into the same scale. Substitution into (5.1) gives

```plain text
|S_m(t)|^2
 << p^2/Q + (m+1)p^(3/2).                            (5.3)
```

Taking Q of order sqrt(p) yields

```plain text
|S_m(t)|
 << sqrt(m+1) p^(3/4).                               (5.4)
```

This is nontrivial compared with the trivial bound p only when

```plain text
m<sqrt(p).
```

But in that same range direct completion and Weil give

```plain text
|S_m(t)|<<m sqrt(p),                                  (5.5)
```

and

```plain text
m sqrt(p) < sqrt(m)p^(3/4)
```

whenever m<sqrt(p). At m=sqrt(p), both methods reach the trivial size p.

Therefore one-step van der Corput gives no range in which it is both nontrivial and stronger than direct Weil. This is an exact barrier calculation, not merely a failure of optimization.

Repeated A-process differencing does not help unless differencing reduces algebraic complexity, as it does for a fixed-degree polynomial phase. Here each differenced phase remains an O(m)-conductor rational function, while the number of shifted copies grows. There is no degree descent to power the classical Weyl or Burgess iteration.

# 6. Why the m-aspect self-similarity does not supply a Burgess amplifier

## 6.1 What the cocycle identity really gives

For fixed r, put

```plain text
z_j=Delta_{r,j}.
```

The sequence satisfies the same second-order recurrence:

```plain text
(r+j+1)^3 z_{j+1}
 =P(r+j)z_j-(r+j)^3 z_{j-1}.
```

Using the transfer product, for every q>=1 there are explicit rational coefficients A_q(s),B_q(s), of complexity O(q), such that

```plain text
z_{m+q}
 =A_q(r+m)z_m+B_q(r+m)z_{m-1}.                       (6.1)
```

This is the precise self-similarity advantage: after lifting to the two-coordinate state (z_{m-1},z_m), a future block of length q has complexity depending on q, not on the age m of the state.

However, along the actual quenched sample the prefix-state map

```plain text
r -> (z_{m-1},z_m)
```

has rational complexity O(m). Pulling the local observable in (6.1) back to the r line restores total conductor O(m+q).

Thus self-similarity keeps the state dimension equal to two, but it does not keep the one-variable conductor bounded on the deterministic prefix graph.

## 6.2 Scalar van der Corput in m

Write

```plain text
A_m(t)=sum_{r=1}^{M-m} e_p(t Delta_{r,m}),
B_t(H)=sum_{m=1}^H A_m(t).
```

The scalar A-process gives

```plain text
|B_t(H)|^2
 <= (H+Q-1)/Q^2
    [Q sum_{m<=H}|A_m(t)|^2
     +2 sum_{q<Q}(Q-q)
       |sum_{m<=H-q}A_{m+q}(t) conjugate(A_m(t))|].   (6.2)
```

The correlation in (6.2) expands as

```plain text
sum_{m,r,r'}
 e_p(t[Delta_{r,m+q}-Delta_{r',m}]).                 (6.3)
```

There are two independent anchors r and r'. The cocycle identity (6.1) relates Delta_{r,m+q} to the prefix state with the same r; it says nothing about the independent value Delta_{r',m}.

Consequently (6.3) is again a two-anchor difference-curve problem. The A-process has repackaged COINC; it has not reduced it.

## 6.3 The tempting same-anchor Cauchy step is fatal

One may first use

```plain text
|B_t(H)|^2
 <= p sum_r |sum_{m<=H}e_p(t Delta_{r,m})|^2.         (6.4)
```

Now every correlation has the same anchor, so (6.1) applies. But the diagonal terms alone on the right of (6.4) have size

```plain text
p * A_H about p^2 H.                                  (6.5)
```

The random pointwise scale would be only A_H about pH. Thus (6.4) loses a full factor p before any cancellation is attempted.

After summing over t, this same-anchor route becomes an anchored triple-return or dispersion statistic, the route already identified as insufficient in the project. It cannot prove COINC.

This pinpoints why the m-recursion does not yield a cheap amplifier: the recursion is strongest after identifying the anchors, while the all-value second moment fundamentally requires two independent anchors.

## 6.4 Why Burgess has a symmetry and this problem does not

Burgess amplification averages a fixed character sum over many translations and dilations. Multiplicativity makes the transformed sums copies of the same target, and high moments reduce to complete character sums whose conductor depends on the fixed moment order, not on the interval length.

For the Apery phase there is no proved large group of transformations T satisfying

```plain text
Delta_{T(r),m}=simple_scalar(T)*Delta_{r,m}+simple_error(T)
```

with bounded complexity uniformly in m. The shift m->m+q stays inside a two-dimensional recurrence state, but it is not a symmetry of the additive phase on the quenched prefix graph.

Therefore the entropy-producing step in Burgess has no analogue yet.

# 7. Reflection is not an amplifier

The proved reflection involution is

```plain text
J(r,h)=(p-1-r-h,h),
Delta_{J(r,h)}=-Delta_{r,h}.
```

It gives

```plain text
B_t(H)=B_{-t}(H) in R,
```

and pairs the nonfixed terms as cosines. The fixed points are the forced even-gap collisions.

This removes the sine sector and halves the bookkeeping. It does not force cosine cancellation. A deterministic collection of cosines can all have the same sign. Hence reflection gives at most a constant-factor improvement, never a power of p.


For a polynomial-size family this is logarithmic. For random words of length p, it is of order p log p. This calculation is the definitive answer to the moment/concentration proposal.

Optimizing cannot cross m=sqrt(p), and below that point direct Weil is stronger. Thus the ordinary q-van der Corput axis is closed unless one proves a new correlation estimate that uses more than rational degree.

# 9. The first project-specific lemma worth proving next

The correct next target is an arithmetic-progression restriction lemma for a short local block after a long prefix.

Define the normalized two-coordinate prefix state

```plain text
Y_{r,m}=(r+m,z_{m-1},z_m),
z_j=Delta_{r,j}.
```

A local future block of length L defines bounded-state observables

```plain text
Phi_{t,L}(Y_{r,m})
```

whose intrinsic transfer complexity is O(L) by (6.1).

The desired first lemma is:

```plain text
[PREFIX-AP(L,H)]

For L<=p^(1/6), m<=H, H=p^(2/3), and every centered
nonexceptional local block observable Phi of conductor L^O(1),

|sum_{r regular} Phi(Y_{r,m})|
  << L^O(1) sqrt(p),                                  (9.1)

uniformly in m.
```

The full-state analogue, in which Y is averaged over the whole frame or state space, is accessible by finite-field orthogonality and standard Deligne estimates. Related positive precedents for deterministic sequences of polynomial maps average over all initial states; see:

- A. Ostafe and I. Shparlinski, Pseudorandom Numbers and Hash Functions from Iterations of Multivariate Polynomials, especially Theorem 8; published at DOI 10.1007/s12095-009-0016-0.

The nonstandard step in (9.1) is restriction to the single graph

```plain text
Gamma_m={Y_{r,m}:r in F_p}.
```

Naively pulling Phi back along Gamma_m produces a one-variable rational phase of conductor O(m+L), so standard Weil gives only

```plain text
O((m+L)sqrt(p)),
```

which is useless for m>sqrt(p).

This is the named obstruction:

```plain text
PREFIX-GRAPH CONDUCTOR GROWTH.
```

## 9.1 A reachable short-block precursor

Before attempting (9.1) for long prefixes, prove the two-short-block case with total prefix length O(L):

```plain text
[SHORT-AP-2(L)]

Every correlation of two consecutive L-block observables has
square-root cancellation, except for an explicit finite list of
reflection or recurrence degeneracies.                              (9.2)
```

After the exceptional phases are classified, (9.2) reduces to a standard complete Artin-Schreier Weil bound with conductor L^O(1). This is a realistic theorem and a useful diagnostic.

But it is not yet COINC. Iterating p^(1/2) such blocks makes the prefix conductor grow to H=p^(2/3). A sequential version of PREFIX-AP, not merely fixed-order block decorrelation, is required for the energy theorem.

# 10. Final answers to the three requested tasks

## Task 1: moment and concentration

The proved annealed Poisson theorem averages independent map schedules. The fixed Apery schedule is one word in an exponential-size family and is not known to be typical.

The exact finite-family moment lemma is (2.1). It shows that logarithmically many moments can control every member only when the family has polynomial size. For random words of length about p, moments of order about p log p would be required.

The t-twist family is different. D3 is already its exact second moment, and COINC is exactly the desired t-annealed L2 estimate. There is no separate Poisson theorem to unfold into it.

Even an O(1/p) approximation for the correct t distribution, without high-moment tail control, yields at best the existing p^(3/2) energy bound. It gives no useful H>sqrt(p) range.

## Task 2: deterministic amplification

The exact q-van der Corput inequality is (5.1). Standard shifted-correlation bounds lead to (5.3), which is nontrivial only for m<sqrt(p) and is then weaker than direct Weil.

The m-direction cocycle law keeps the abstract state dimension bounded but does not keep the quenched pullback conductor bounded. Scalar differencing retains two independent anchors; same-anchor vectorization loses a factor p.

Reflection supplies reality but no exponent gain.

Therefore no classical Burgess or q-van der Corput amplifier currently survives the degree/conductor growth.

## Task 3: verdict and first lemma

The cheapest complete theorem is the exact h=2 transfer (8.1).

The cheapest general principles proved inline are the finite-family moment-to-uniform lemma and the one-step A-process barrier.

The cheapest positive new project lemma is SHORT-AP-2(L). Its proof should end with a standard Weil bound after a finite exceptional-mode classification.

The first lemma capable of changing the energy exponent is PREFIX-AP(L,H). It is not a standard theorem. Its sole nonstandard step is uniform square-root sampling of bounded local observables on the long deterministic prefix graph.

If PREFIX-AP fails numerically or symbolically, the annealed-to-quenched and block-amplification axis has a precise death certificate. If it holds, it supplies the missing derandomization mechanism needed to turn the annealed short-block laws into quenched all-value mixing.
