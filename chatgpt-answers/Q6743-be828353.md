# Q6743: dyadic dispersion computation

## (i) Difference-closure recursion

Let I_D = {d: D/2 < d <= D} and T(D)=sum_{d in I_D} C_d. Define

W(D)=sum_r binom(a_r,2),

where a_r is the number of dyadic gaps d in I_D with r in Z_d. Equivalently W counts ordered rows with two distinct dyadic returns.

The exact difference-closure map is

(r,d,d') -> (s,g)=(r+d,d'-d).

Because d<d' and both returns occur from r,

s=r+d is in Z_g.

The important point is that this map is NOT injective. For fixed (s,g), the preimages are exactly

r=s-d, d in I_D,

with the condition s-d in Z_d. Therefore the exact identity is

W(D)=sum_{g<D/2} sum_{s in Z_g} M_D(s),

where

M_D(s)=#{d in (D/2,D] : s-d in Z_d}.

This is the precise multiplicity ledger. The right side is a weighted return count to s; it is not bounded by 1 from the available hypotheses.

Using only the marginal degree budget,

M_D(s) <= # {d in I_D} = D/2,

and hence

W(D) <= (D/2) sum_{g<D/2} C_g.

Writing U(D)=sum_{d<=D} C_d, this gives

W(D) <= (D/2) U(D/2).

Since C_d <= 3(d-1),

U(D)<=3D^2/2+O(D).

Therefore

W(D)<=3D^3/4+O(D^2).

This is the sharp inequality obtainable from difference-closure alone. The exponent is 3, not 2.

Iterating the recursion does not improve the exponent because every step introduces the factor D from the uncontrolled multiplicity M_D(s). The fixed point is therefore the degree-sum scale

T(D) ~ D^2.

The lossy step is exactly the passage

sum_s M_D(s) C_g(s) -> (max_s M_D(s)) sum_s C_g(s).

The difference map compresses the gap but does not compress the number of possible long returns landing at the same endpoint.

## (ii) Cauchy-Schwarz consequence

Let R_D be the number of active rows. Then

T(D)<=R_D+sqrt(2 R_D W(D)).

Using the proven restart estimate, each active row has at most O(D^(2/3)) returns, but this does not control R_D below the trivial N bound. Substitution of the previous estimate gives

T(D)<=N+sqrt(2N * (D/2)U(D/2)).

With U(D/2)<<D^2,

T(D)<<N+N^(1/2)D^(3/2).

At the mesoscopic choice D=N^(1/2)L this is

T(D)<<N+N^(5/4)L^(3/2),

which is larger than the desired D^(2-eta)=N^(1-eta/2)L^(2-eta). Hence this route loses before reaching the target.

The bottleneck is not the small-scale base case. Even perfect control for all g<D/2 leaves the multiplicity M_D(s). The obstruction is the many-to-one nature of difference closure.

## (iii) One-return dominance reduction

Let A_1 be the number of rows having exactly one dyadic return and A_2 the number having at least two.

Every row counted by A_2 gives a pair d<d' in its dyadic return set. Difference-closure gives a smaller return g=d'-d and endpoint s=r+d in Z_g. Thus

A_2 <= sum_{g<D/2} sum_{s in Z_g} 1_{M_D(s)>0}.

This is exact at the indicator level.

The weaker numerical inequality is

A_2 <= sum_{g<D/2} C_g * max_s M_D(s).

The known facts do not bound max_s M_D(s) by a power saving. The same multiplicity obstruction reappears.

If an independent arithmetic theorem supplied

A_2 << D^(2-eta'),

then

T(D)=A_1+O(D^(2-eta'))

and the entire remaining difficulty would indeed be the single-return stratum A_1. This matches the Strike2 primitive obstruction: all collision identities attack repeated returns, not isolated first returns.

## (iv) Final inequality chain and verdict

Exact:

W(D)=sum_{g<D/2} sum_{s in Z_g} M_D(s).

Banked input used:

C_g<=3(g-1).

Therefore:

W(D)<= (D/2)U(D/2)<<D^3.

Cauchy-Schwarz:

T(D)<=R_D+sqrt(2R_D W(D)).

With only R_D<=N:

T(D)<<N+N^(1/2)D^(3/2).

No iteration over dyadic scales gives a power saving. The recursion stabilizes at the degree-sum exponent 2 for T(D), because the difference map preserves too much multiplicity.

The exact missing statement is a quenched multiplicity theorem of the form

sum_{s in Z_g} M_D(s)=o(D U(g))

or, equivalently, a bound showing that a small-gap endpoint cannot be the landing site of many unrelated large gaps. That is precisely a new anti-coexistence statement, not a consequence of difference-closure itself.

Least confident step:

The extrapolation that no hidden arithmetic cancellation improves the multiplicity bound is the least confident part. The argument proves failure of the available identity ledger, not impossibility of a deeper Apéry-specific estimate.

Blind spot in the question:

The formulation treats difference-closure as if it were a dispersion mechanism. It is actually a transport identity with a potentially large fiber. The unresolved object is the distribution of the fibers of the difference map, not the existence of the difference relation itself.
