## 2. Exact computation of the true weighted-sum order

### 2.1 What must be computed

Let the verified class operators be

\[
L_a=\sum_{i=0}^{n_a}p_{a,i}(M,r)S_r^i,
\qquad n_a\in\{2,3\}.
\tag{2.1}
\]

The sum of orders is 38, but that is only the rank of the unsimplified direct presentation. Repeated operators, rational gauge-equivalent modules, and special relations between the distinguished class solutions can lower the rank.

For each class define its companion state

\[
x_a(r)=
(R_a(r),R_a(r+1),\ldots,R_a(r+n_a-1))^t
\]

and companion matrix \(A_a(M,r)\), so

\[
x_a(r+1)=A_a(M,r)x_a(r).
\]

Let

\[
A=\bigoplus_a A_a,
\qquad
c=(\mu_a e_1^t)_a.
\tag{2.2}
\]

For the direct-sum state \(x\), \(F_M(r)=cx(r)\). Define shifted output rows by

\[
c_0=c,
\qquad
c_{j+1}(M,r)=\sigma(c_j(M,r))A(M,r),
\tag{2.3}
\]

where \(\sigma f(M,r)=f(M,r+1)\). Then

\[
F_M(r+j)=c_j(M,r)x(r).
\]

The first linear dependence

\[
\sum_{j=0}^{R}a_j(M,r)c_j(M,r)=0
\tag{2.4}
\]

is an exact annihilator of the weighted sum. After quotienting gauge-equivalent blocks and verifying the distinguished initial relations, the least such \(R\) is the actual minimal order.

### 2.2 Gauge equivalence

Two class modules with companion matrices \(A_a,A_b\) are rationally gauge equivalent exactly when there is an invertible rational matrix \(T(M,r)\) satisfying

\[
\boxed{T(M,r+1)A_a(M,r)=A_b(M,r)T(M,r).}
\tag{2.5}
\]

It is not enough that the scalar operators have the same order or singular locus. Equation (2.5), followed by a check that the two distinguished ray solutions correspond under \(T\), is the required exact test.

### 2.3 Reproducer code

The following Sage code performs the exact cyclic-rank computation once the announced script exposes the 14 coefficient lists. It avoids taking the crude lclm of all operators.

```python
# SageMath.  Adapter requirement:
# ray_data = [(name, multiplicity, [p0,...,pn]), ...]
# with coefficients in K = QQ(M,r), representing sum p_i S^i.

from sage.all import *

P.<M,r> = PolynomialRing(QQ, 2)
K = P.fraction_field()


def sig(x):
    return K(x(M=M, r=r+1))


def companion(coeffs):
    n = len(coeffs)-1
    C = matrix(K, n, n)
    for i in range(n-1):
        C[i, i+1] = 1
    for i in range(n):
        C[n-1, i] = -coeffs[i]/coeffs[n]
    return C


def sigma_vector(v):
    return vector(K, [sig(x) for x in v])


def direct_sum_cyclic_operator(ray_data):
    blocks = [companion(cs) for _,_,cs in ray_data]
    A = block_diagonal_matrix(blocks)
    c = []
    for (_, mult, cs) in ray_data:
        c += [K(mult)] + [K(0)]*(len(cs)-2)
    c = vector(K, c)

    rows = []
    for j in range(1 + sum(len(cs)-1 for _,_,cs in ray_data)):
        rows.append(c)
        T = matrix(K, rows)
        ker = T.left_kernel()
        if ker.dimension():
            alpha = ker.basis()[0]
            # alpha[0]+...+alpha[j] S^j annihilates the weighted output.
            den = lcm([x.denominator() for x in alpha])
            aa = [P(den*x) for x in alpha]
            g = gcd(aa)
            aa = [x//g for x in aa]
            return j, aa
        c = sigma_vector(c) * A
    raise RuntimeError("no cyclic dependence")
```

## 6. The exact recurrence/margin determinant

Let \(L_Y\) be a primitive polynomial operator annihilating \(Y_d=b_M+F_M(M-d)\), and let its order be \(\widetilde R\). It may be obtained from \(L_F\) by reflection \(r=M-d\) and adjoining the constant mode:

\tag{6.1}

The union of all nodes in the rectangle is

\[
[d-S,d+L+T],

of length

\[
N+1=L+S+T+1.

Assume

\[
S+T+1\ge\widetilde R.
\tag{6.2}

Choose \(\widetilde R\) independent margin rows, and write their coefficients on the raw value vector

\[
\boxed{
\Delta_I(M,d,L,S,T)
=\det\begin{pmatrix}\mathcal M_I\\\mathcal R_I\end{pmatrix}.}
\tag{6.3}
\]

After clearing recurrence denominators and dividing the gcd of the coefficient rows, this is a concrete integer polynomial in the displayed parameters.

Let \(\Sigma_I\) be the product of the primitive leading/trailing and denominator factors required to make the recurrence valid throughout the node interval. Let \(\Delta_I^{\rm sat}\) denote saturation by **only** the known duplicate alias Smith factors.

### Theorem 6.1 — local prime dichotomy

Let \(p>B\) be prime and suppose \(p\mid H_{s,t}\) for every row in the rectangle. Then at least one of the following holds:

\[
\boxed{
\begin{array}{ll}
\text{(i)}&p\mid\mathcal A_{d,L;B},\\
\text{(ii)}&p\mid\Sigma_I(M,d,L,S,T),\\
\text{(iii)}&p\mid\Delta_I^{\rm sat}(M,d,L,S,T),\\
\text{(iv)}&\xi_M(d-S)\equiv0\pmod p
\text{ in the saturated actual }L_Y\text{-state lattice}.
\end{array}}
\tag{6.4}

### Proof

If \(p\) is not an alias and does not divide the singular factors, the selected margin rows and recurrence rows are valid over \(\mathbf F_p\). If the saturated determinant is a unit, the stacked square matrix is invertible. The recurrence equations and the vanishing margin equations then force the entire raw value vector—and hence the local saturated state—to be zero. This is (iv). The alias case is separated before determinant saturation, so one genuine alias factor is preserved. \(\square\)

This is the strongest correct result obtainable from the true rank alone. It is stronger than universal interpolation, but it has an actual-state exception.

## 7. The actual Apéry state really can vanish

The state exception in (6.4) is not formal.

### 7.1 Cyclic-orbit divisibility of every ray

Let \(P(X)=\sum_u\lambda_uX^u\) be any Laurent polynomial with integer coefficients. Expand \(P^M\) as weighted words of length \(M\) in the support alphabet. Cyclic rotation acts on the words and preserves their weights and total exponent.

If a word of total exponent \(v\in\mathbf Z^3\) has repetition number \(c\), then \(c\mid M\) and \(c\) divides every coordinate of \(v\). Its orbit size is \(M/c\), which is divisible by

\[
\frac{M}{\gcd(M,v_1,v_2,v_3)}.
\]

Summing orbit weights gives:

\[
\boxed{
\frac{M}{\gcd(M,v_1,v_2,v_3)}
\mid [X^v]P(X)^M.}
\tag{7.1}

For a primitive nonzero ray direction \(\kappa\in\{-1,0,1\}^3\) and \(v=(M-r)\kappa\),

\[
\gcd(M,v_1,v_2,v_3)=\gcd(M,r).
\]

Therefore every one of the 21 nonzero Apéry rays satisfies

\[
\boxed{
\frac{M}{\gcd(M,r)}\mid c_M((M-r)\kappa).}
\tag{7.2}

This is an exact content theorem for the distinguished ray state.

### 7.2 A 178-term actual zero segment

The verified \(n=321\) target gives

\[
179\mid b_{142}.
\]

Take

\[
M=142\cdot179=25418.
\]

Apéry–Lucas gives

\[
b_M=b_{142\cdot179}\equiv b_{142}b_0\equiv0\pmod{179}.
\tag{7.3}

For \(1\le r\le178\), \(179\mid M\) but \(179\nmid r\), so (7.2) shows that every nonzero ray coefficient at spacing \(M-r\) is divisible by \(179\). Adding the constant coefficient proves

\[
\boxed{C_M(M-r)\equiv0\pmod{179}
\quad(1\le r\le178).}
\tag{7.4}

Choose a margin rectangle whose corresponding \(r\)-range lies, for example, inside \([40,140]\). Then every \(H_{s,t}\) is zero modulo \(179\). The alias condition is

\[
M-r+1\equiv1-r\equiv0\pmod{179},
\]

which occurs only at \(r=1\) in this segment. Hence a rectangle inside \([40,140]\) has \(179\nmid\mathcal A_{d,L;B}\). The common factor is caused by the actual state, not by interpolation aliases.

This example works for every possible true rank \(R\le38\): there is ample room for \(S+T\ge R\) while keeping the full node range inside the 178-term zero segment.

### 7.3 General construction

Whenever \(p\mid b_a\), put \(M=ap\). For every interval of first-cell residues \(r\) avoiding multiples of \(p\), all nonzero rays are divisible by \(p\) by (7.2), and

\[

\[
M\equiv a_pp\pmod{p^2}
\]

for each prime and using CRT. This is an actual Apéry family, not a freely chosen recurrence solution.

## 8. The smallest extra determinant/content ideal

Let \(E_{M,r}\) be a saturated integral lattice for the true \(\widetilde R\)-dimensional \(Y\)-module at \(r\), and let

\[
\xi_M(r)\in E_{M,r}
\]

be the distinguished Apéry state. Define its content ideal by

\[
\boxed{
\mathfrak c_M(r)
=\{n\in\mathbf Z:\xi_M(r)\in nE_{M,r}\}.}
\tag{8.1}

Equivalently,

\[
\boxed{
(\mathfrak c_M(r))
=\operatorname{Fitt}_{\widetilde R-1}
(E_{M,r}/\mathbf Z\xi_M(r)).}
\tag{8.2}

In any unimodular basis this is the gcd of the coordinates of the state. Smith reduction sends

\[
\xi_M(r)\longmapsto(\mathfrak c_M(r),0,\ldots,0)^t.
\]

Thus the smallest additional scalar after the coefficient determinant is exactly \(\mathfrak c_M(r)\). A higher exterior power or another margin only repeats the same content.

For a state window of length \(w\), the cyclic theorem supplies the explicit divisor

\[
\boxed{
\gcd_{0\le u<w}\frac{M}{\gcd(M,r+u)}.}
\tag{8.3}

If a prime divides both \(M\) and \(b_M\), and the state window avoids residues \(0\pmod p\), that prime divides the complete ray-plus-constant state. The product of all such known primes divides \(\gcd(M,b_M)\), hence has logarithm at most \(\log M\).

Define the primitive unexplained quotient

\[
\boxed{
\mathfrak c_M^{\rm prim}(r)
=\mathfrak c_M(r)/\mathfrak c_M^{\rm known}(r),}
\tag{8.4}

where \(\mathfrak c_M^{\rm known}\) is the saturated product generated by the cyclic factors (8.3), the \(\gcd(M,b_M)\) factors valid on the window, and any explicitly verified packet factors.

No bound

\[
\log\operatorname{rad}\mathfrak c_M^{\rm prim}(r)=o(M^{1/3})
\]

is presently proved. This is the narrow actual-state gap.

### Recurrence/margin determinant

If the primitive full operator has fixed degree in \(M,r\), each recurrence coefficient on this local window has logarithmic size \(O_R(\log M)\). The square determinant (6.3) has fixed size \(N+1=O_R(\log M)\), giving

\[
\boxed{
\log|\Delta_I^{\rm sat}|=O_R((\log M)^2).}
\tag{9.1}

### Known state content

The explicit cyclic and \(\gcd(M,b_M)\) factors have logarithm \(O(\log M)\).

Consequently every part of the local theorem except \(\mathfrak c_M^{\rm prim}\) is \(o(M^{1/3})\).

## 10. Why one operator does not yet give one block certificate

Let

\[
H=M^{1/3}
\]

and let \(I\) be an \(H\)-long spacing block. Even though the recurrence operator is reused, the local determinant depends on the moving anchor \(d\).

Eliminating \(d\) against the literal interval polynomial gives

\[
\boxed{
\operatorname{Res}_X
\left(\Delta_I^{\rm sat}(M,X,L,S,T),
\prod_{d\in I}(X-d)\right)
=
\prod_{d\in I}\Delta_I^{\rm sat}(M,d,L,S,T).}
\tag{10.1}

This is an exact identity, not an estimate. Its unconditional logarithmic height is

\[
O_R(H\log M)
\]

(or \(O_R(H\log^2M)\) if all \(L\)-values up to \(A\log M\) are multiplied). This is not \(o(H)\).

The equivalent fixed-rank formulation is to transport the output covectors through the recurrence over the whole block. The matrix still has only \(\widetilde R\) columns, but its entries contain products of \(H\) transfer matrices. The Abel law (3.3) gives the same \(H\log M\) ledger.

The minimal block-level coefficient invariant is therefore not one arbitrarily selected local determinant. It is the \(\widetilde R\)-th determinantal divisor

\[
\boxed{
\mathfrak D_{M,I}
=\gcd\{\text{all }\widetilde R\times\widetilde R
\text{ minors of the propagated margin-observability matrix}\}.}
\tag{10.2}

The complete block obstruction is the pair

\[
\boxed{(\mathfrak D_{M,I},\ \mathfrak c_{M,I}^{\rm prim}).}
\tag{10.3}

A proof of

\[
\log\operatorname{rad}
(\mathfrak D_{M,I}\mathfrak c_{M,I}^{\rm prim})=o(H)
\tag{10.4}

would close this route after the harmless alias and small-prime factors are restored. No such theorem follows from the fixed order alone.

A banded determinant of size \(H+\widetilde R\), obtained by keeping all recurrence rows and all block margin rows, is an equivalent growing-order presentation. It has the same determinantal divisor and the same height barrier. Thus increasing determinant size without a new content theorem does not improve the ledger.

## 12. Final status

The new ray telescopers are a genuine advance: they replace Q5716's growing \(M+1\) Legendre-mode presentation by a fixed-rank Ore module of rank at most 38. Once the reproducer is visible, the exact cyclic computation in Section 2 will determine the true rank and operator.

But rank saturation by pair-preserving margins does not by itself finish the arithmetic. The exact corrected theorem is

\[
\boxed{
\text{common prime}
\Rightarrow
\text{alias}\ \lor\ 	ext{singular/resultant prime}\ \lor\ 	ext{actual-state prime}.}
\]

The actual-state alternative occurs in the Apéry shell itself, as the \(M=142\cdot179\) zero segment proves. Its known cyclic part is only logarithmic in height, but no sub-\(M^{1/3}\) theorem is known for the primitive state content or for the block determinantal divisor.

> **Primitive 14-ray block-content theorem.** For the true minimal saturated ray-plus-constant module, every \(M^{1/3}\)-block \(I\) satisfies
> \[
> \log\operatorname{rad}
> \bigl(\mathfrak D_{M,I}\mathfrak c_{M,I}^{\rm prim}\bigr)
> =o(M^{1/3}).
> \]
> Here all common-node aliases and all explicitly proved cyclic/packet factors are removed only as separately recorded factors of logarithmic height \(O((\log M)^2)\).

That is an exact, actual-state formulation. It neither discards the new order-38 theorem nor hides the remaining difficulty behind generic holonomicity.
