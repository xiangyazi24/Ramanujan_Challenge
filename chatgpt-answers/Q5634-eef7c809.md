# 9. What genuinely new input would be sufficient

The remaining theorem must see arithmetic discarded by reduction to the rational number a_n/b_n. Examples of sufficient new input include:

- a direct primitive-lattice theorem for the integral Apéry period vector (P_n,Q_n);

- a prime-support theorem showing that the d_n^3 part of the possible content is almost never simultaneously present in both coordinates;

- an arithmetic intersection or local monodromy statement bounding the sum of local content valuations pointwise;

- a two-index determinant whose reduced value is forced to have exponential absolute size, not merely to be a nonzero integer.

All of these go beyond irrationality/Padé theory alone. In the current project language, the exact unresolved information is the restricted-prime support of the common divisor, not the quality of the real approximation.
