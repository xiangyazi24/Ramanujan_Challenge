# 1. Two corrections to the formulation

Put

[

f_s(z)=int_0^1frac{dmu_s(t)}{z-t}

qquad s=2,3.

]

Then

[

f_2(1)=zeta(2),

qquad

f_3(1)=zeta(3).

]

## 1.1 The stated approximation orders are overdetermined

The conditions in the question require a degree-(n) polynomial to satisfy

[

A_n f_2-B_n=O(z^{-n-1}),

qquad

A_n f_3-C_n=O(z^{-n-1}).

]

These impose (2n) moment conditions on only (n) free lower coefficients after fixing a normalization. They are generically inconsistent.

The failure already occurs at (n=1). Write (A_1(t)=at+b). The two requested remainder orders force

[

frac a4+b=0,

qquad

frac a8+b=0,

]

hence (a=b=0). There is no nonzero approximating polynomial.

The standard type-II condition for a multi-index (mathbf n=(n_2,n_3)) is instead

[

deg P_{mathbf n}=|mathbf n|=n_2+n_3,

]

[

int_0^1 t^kP_{mathbf n}(t),dmu_s(t)=0,

qquad 0le k<n_s,

quad s=2,3.

tag{1.1}

]

For the step line of total degree (N), take

[

(n_2,n_3)=left(leftlceilfrac N2rightrceil,

tag{1.2}

]

The two remainders then have the different orders

[

P_Nf_2-Q_{2,N}=O(z^{-n_2-1}),

qquad

P_Nf_3-Q_{3,N}=O(z^{-n_3-1}).

tag{1.3}

]

A diagonal condition with equal order (m+1) for both functions would require degree (2m), not degree (m).

## 1.2 The target evaluation is (z=1), not (z=0)

As defined above, the Markov functions are expanded at infinity and satisfy

[

f_s(1)=zeta(s).

]

At (z=0), the integral (int dmu_s(t)/(z-t)) is singular. Therefore the natural denominator and numerator evaluations are

[

q_N^{rm HP}=P_N(1),

qquad

p_N^{rm HP}=Q_{2,N}(1)+Q_{3,N}(1),

tag{1.4}

]

not values at zero.

# 2. Exact type-II system and remainder formula

Normalize (P_N) to be monic. For (s=2,3), define the polynomial of the second kind

[

Q_{s,N}(z)=

int_0^1frac{P_N(z)-P_N(t)}{z-t},dmu_s(t).

tag{2.1}

]

Then

[

P_N(z)f_s(z)-Q_{s,N}(z)

=

int_0^1frac{P_N(t)}{z-t},dmu_s(t).

tag{2.2}

]

The orthogonality conditions (1.1) give (1.3) immediately.

Evaluating at (z=1) gives the exact simultaneous linear form

[

boxed{

P_N(1)bigl(zeta(2)+zeta(3)bigr)

-igl(Q_{2,N}(1)+Q_{3,N}(1)bigr)

]

Thus, in the P2.7 sign convention (e=p-Lq), the HP error would be the negative of the integral in (2.3).

If

[

P_N(t)=sum_{m=0}^N c_{N,m}t^m,

]

then

[

Q_{s,N}(1)=

sum_{m=1}^N c_{N,m}H_m^{(s)},

qquad

H_m^{(s)}=sum_{j=1}^mfrac1{j^s}.

tag{2.4}

]

## 2.1 Normality and the four-term recurrence

After putting (t=e^{-x}), the relevant Chebyshev family is

[

{e^{-kx}:0le k<n_2}

cup

{x e^{-kx}:0le k<n_3}.

]

This is an extended complete Chebyshev system, so the step-line indices are normal and the monic polynomials exist uniquely.

For two measures, the general step-line theorem gives

[

boxed{

xP_N(x)=P_{N+1}(x)+beta_NP_N(x)

+gamma_NP_{N-1}(x)+delta_NP_{N-2}(x).}

tag{2.5}

]

This is the standard ((r+2))-term recurrence for (r=2) measures; see Filipuk–Haneczok–Van Assche, Computing recurrence coefficients of multiple orthogonal polynomials.

A crucial qualification is that (2.5) only fixes the number of terms. The scalar sequences (beta_N,gamma_N,delta_N) are moment-determinant ratios and need not be rational functions of (N), much less the degree-18 coefficients of P2.7. “Both have four terms” is not an operator identification.

# 5. Why the error formula does not automatically prove recessiveness

Equation (2.3) is exact, but two further facts would be required before it could prove (c_0(e)=0) for any recurrence:

1. the evaluated HP numerator and denominator must first be proved to satisfy that recurrence with the required initial data;

1. the integral must be bounded strictly below the dominant Birkhoff scale.

Neither follows merely from type-II orthogonality.

The evaluation point (z=1) is the endpoint of the support and a branch point of

[

f_s(z)=operatorname{Li}_s(1/z).

]

Standard geometric Hermite–Padé convergence outside the support therefore does not directly supply an exponential estimate at this point. Moreover, the polynomial (P_N(t)) changes sign on ((0,1)); (2.3) is not a positive square integral of the Apéry–Beukers type.

For P2.7 the two distinct rates are

[

boxed{

=frac1{128sqrt{mu_0}}

=0.001053785ldots,}

tag{5.1}

]

and

[

boxed{

left|frac{p_n}{q_n}-Lright|^{1/n}

longrightarrowfrac{|r_pm|}{r_0}

=frac1{2mu_0^{3/2}}

=0.001227ldots .}

tag{5.2}

]

The value near 0.0012 is the relative approximation-error rate, not (|e_n|^{1/n}).

The first five simple-HP approximants above are nowhere near this behavior. A separate asymptotic analysis of their own four-term recurrence would be needed; it cannot be imported from P2.7.

Conditional statement: if an exact HP construction did produce the printed p_n,q_n, and if (2.3) were proved to satisfy a bound with limsup below r_0, then Birkhoff theory would indeed force the dominant coefficient to vanish. The missing quantitative bound is essential, not automatic.

The failure is also exponential. Since

[

including an additional (64^{-N}) gives base (2^{-26}), while the P2.7 denominator has base

[

For the present AT system all zeros of the monic (P_N) lie in ((0,1)), so

[

It cannot compensate for this exponential mismatch.

Finally, the displayed h_N comes from the companion determinant. Under a scalar gauge (u_N=g_Nv_N) of an order-three recurrence, the state determinant changes by

[

frac{g_{N+1}}{g_{N-2}},

]

not by (g_{N+1}/g_N). Hence the determinant identity never justified using h_N directly as a scalar prefactor of a one-polynomial HP sequence.

# 7. What remains viable

The direct fixed-measure proposal is now ruled out. A Hermite–Padé explanation of P2.7 would need additional structure, for example:

- varying measures whose weights depend on (N) through the Pochhammer slopes;

- a mixed type-I/type-II system derived from the two distinct Barnes rational functions in the Dauguet–Zudilin construction;

- a matrix-valued or vector-valued multiple-orthogonality problem rather than one common scalar polynomial;

- an algebraic three-sheeted or cubic-field trace system capable of producing the root-dependent irrational Birkhoff powers of P2.7;

- a nonlocal Cauchy/Hadamard transform followed by a genuinely global connection calculation.

Any successful replacement must pass four finite checks:

1. exact moment or contour identities;

1. the full P2.7 recurrence, not only a four-term count;

1. all three initial values for both numerator and denominator;

1. a rigorous decay estimate for the resulting error integral.

The current simple pair ((-log t)dt,frac12log^2t,dt) fails checks 2 and 3 immediately.

# 8. Exact Sage code for the computation

```python
from sage.all import QQ, PolynomialRing, matrix, vector

R.<x> = PolynomialRing(QQ)


def moment(s, k):
    return QQ(1) / QQ(k + 1)**s


def step_line_poly(N):
    """Monic type-II polynomial for (ceil(N/2), floor(N/2))."""
    n2 = (N + 1) // 2
    n3 = N // 2

    rows = []
    rhs = []
    for s, ns in [(2, n2), (3, n3)]:
        for k in range(ns):
            rows.append([moment(s, j + k) for j in range(N)])
            rhs.append(-moment(s, N + k))

    if N == 0:
        return R.one()

    coeff = matrix(QQ, rows).solve_right(vector(QQ, rhs))
    return x**N + sum(coeff[j] * x**j for j in range(N))


def second_kind(P, s):
    """Q_s(z)=integral (P(z)-P(t))/(z-t) dmu_s(t)."""
    N = P.degree()
    return sum(
        P[m] * sum(moment(s, ell) * x**(m - 1 - ell)
                   for ell in range(m))
        for m in range(1, N + 1)
    )


for N in range(6):
    P = step_line_poly(N)
    Q2 = second_kind(P, 2)
    Q3 = second_kind(P, 3)
    q = P(1)
    p = Q2(1) + Q3(1)
    print(N, P)
    print("  q_HP =", q)
    print("  p_HP =", p)
    print("  p/q  =", p/q if q else None)
```

## Bottom line

[

boxed{

text{The corrected two-measure step-line HP system is valid, but it is not P2.7.}}

]

Its four-term recurrence is a generic multiple-orthogonality recurrence, its first rational approximants disagree with P2.7 in a normalization-invariant way, and the proposed Pochhammer gauge fails both initially and exponentially. Therefore this construction does not establish (c_0(e)=0); a more structured Barnes/mixed/vector Hermite–Padé system is required.
