# Clock-compression master audit

## Executive verdict

No quotient currently on the table gives a bounded-complexity realization of the one-step Apéry clock. The four mechanisms do not have equal status.

```plain text
1. CARTIER / p-LINEAR:
   CONSTRUCTED for p-dilation and base-p digit recursion;
   KILLED as a direct MESO-BALANCED-PAIR input because D<p and the
   first-digit quotient collapses the low digit that carries the collision;
   REDUCED to [WITHIN-DIGIT-CARTIER].

2. MIXED FROBENIUS + dual J:
   the index shift is formally inner in the localized Weyl algebra
   (Ad_t(theta)=theta-1), but this localization removes the coefficient
   point t=0; on the local coefficient dual the shift is an infinite
   unilateral jet ladder, not an invertible finite-rank action;
   literal finite-rank innerness is KILLED;
   REDUCED to [FINITE-CARTIER-LOCAL-DUAL].

3. HIGHER-ORDER / MATRIX BISPECTRAL:
   the autonomous Chebyshev control really does compress the clock,
   but because both factors live over the same spectral point;
   ordinary or matrix bispectrality at fixed spectral point does not
   control the Apéry start translation X -> X+m+1;
   REDUCED to the strictly stronger [AFFINE-BISPECTRAL-QUOTIENT].

4. MELLIN CHARACTER:
   CONSTRUCTED in the autonomous control;
   KILLED for the nonautonomous Apéry cocycle by a rational-coboundary
   obstruction and, mod p, by the full finite Weyl algebra generated by
   clock multiplication and translation;
   the only surviving quotient is the already-known mirror character mu_2.
```

The survivor ranking is therefore:

```plain text
(1) Cartier semilinearity, upgraded by a local-dual/coefficient quotient;
(2) mixed-Frobenius + J as the possible source of that local-dual quotient;
(3) an affine-covariant higher-order bispectral quotient;
(4) Mellin/character linearization beyond mirror parity: dead.
```

The first two are best viewed as one p-typical program. The exact positive object already known is a bounded-state quotient for n -> pn+v. The missing object is a bounded-complexity quotient for the low digit v -> v+1 that still remembers the projective collision observable.

# 0. What a genuine clock quotient must mean

Q6593 found a fixed-rank carrier. That is not yet clock compression. To prevent the same ambiguity from recurring, use the following definition.

A bounded-complexity two-clock quotient consists of:

```plain text
- a fixed-dimensional algebraic variety or finite algebra Q;
- two clock operations S and R of bounded degree/conductor;
- a fixed observable zeta on Q;
- a point q_0;
```

such that, on every regular clock triple,

```plain text
K_m(X)=0
  <=> zeta(R^X S^m q_0)=0,                           (0.1)

K_g(X+m+1)=0
  <=> zeta(R^(X+m+1) S^g q_0)=0.                    (0.2)
```

The required boundedness is not merely dim Q=O(1). One needs one of:

```plain text
- S,R are translations/automorphisms on a fixed algebraic group;
- all relevant iterates have uniformly bounded algebraic degree;
- the associated sheaves have uniformly bounded rank and conductor;
- or the clock action factors through a fixed finite algebra with a
  quantitative mixing/nonconcentration theorem.
```

The flat GL_2 x GL_2 carrier of Q6593 satisfies fixed rank but fails this definition because its update matrices retain the absolute clocks X+m and X+m+g; pulling back the fixed Schubert divisors reproduces degrees 3m and 3g.

A positive solution of any mechanism below must therefore exhibit both:

```plain text
STATE COMPRESSION + CLOCK COMPRESSION.
```

# 1. Higher-order and matrix bispectrality

## 1.1 Scope correction on the classical literature

Duistermaat-Grunbaum classify the Schrödinger bispectral problem for a second-order differential operator in the physical variable and a differential operator in the spectral parameter. Wilson classifies rank-one commutative ordinary differential-operator algebras through the adelic Grassmannian. Grunbaum-Haine and later matrix-valued work construct higher-order, wider-recursion, and noncommutative bispectral examples.

None of these results classifies the Apéry Green kernel

```plain text
(m,X) -> K_m(X),
```

and none says that an order-3 Picard-Fuchs operator automatically gives a bispectral operator in the start clock X.

The project-variable distinction remains decisive:

```plain text
Apéry Picard-Fuchs L: acts in geometric t;
K_m(X): Green/continuant kernel in coefficient start clock X.
```

A bispectral statement about the period in t is not yet a statement about K_m(X).

## 1.2 Control case: autonomous Chebyshev really compresses the clock

Take the autonomous recurrence

```plain text
U_0(x)=1,
U_1(x)=2x,
U_(m+1)(x)=2x U_m(x)-U_(m-1)(x).
```

With x=(z+z^(-1))/2,

```plain text
U_m(x)=(z^(m+1)-z^(-(m+1)))/(z-z^(-1)).             (1.1)
```

Thus the m-clock is a torus character. In particular,

```plain text
gcd_Q[x](U_m,U_g)=U_(d-1),

d=gcd(m+1,g+1),                                    (1.2)
```

up to a nonzero scalar. Common zeros are controlled by a clock gcd/order condition. This is exactly the Lucas/Fibonacci-type rigidity one would want.

Why does it work? Both lengths act at the same spectral point x. The transfer is autonomous:

```plain text
A(x)^m,
A(x)^g.
```

After diagonalization, both are characters of one fixed torus.

This control therefore gives a positive answer:

```plain text
bispectrality + autonomy + common spectral point
DOES make the clock algebraic.
```

## 1.3 What Apéry changes

For Apéry, the second segment starts at the translated absolute clock:

```plain text
K_m(X),
K_g(X+m+1).                                         (1.3)
```

Even if K_m(X) were bispectral in (m,X), ordinary bispectrality only controls the m-recurrence with X fixed. It does not identify the spectral fibers over

```plain text
X  and  X+m+1.
```

The Chebyshev formula demonstrates the issue sharply. If one artificially replaces the second condition by

```plain text
U_g(x+m+1)=0,
```

one needs a second torus coordinate w satisfying

```plain text
w+w^(-1)=z+z^(-1)+2(m+1),

z^(2(m+1))=1,
w^(2(g+1))=1.                                       (1.4)
```

The torsion orders still grow with m,g, and the relation between the two tori still contains m. The ordinary bispectral involution has not compressed the translated start clock.

## 1.4 The exact strengthened statement needed

The surviving statement is not “there exists a higher-order bispectral operator.” It is:

```plain text
[AFFINE-BISPECTRAL-QUOTIENT]

There exists a fixed spectral variety C, bounded-degree automorphisms
sigma and tau of C, a fixed finite-rank kernel Psi, and a fixed divisor Z,
such that

  X -> X+1     is tau,
  m -> m+1     is sigma,
  K_m(X)=0     iff tau^X sigma^m(q_0) lies in Z,

with the second segment represented by tau^(X+m+1) sigma^g(q_0).
```

The important new word is affine-covariant: start translation must belong to the same bounded algebra as spectral/length translation.

A scalar, higher-order, or matrix-valued bispectral triple that lacks tau does not solve clock complexity.

## 1.5 Apéry verdict

The Q6593 rational scalar-gauge death certificate already rules out the standard Jacobi/Favard form. The order-3 Picard-Fuchs operator in t is the wrong-variable object. Matrix bispectrality can enlarge the state and the commuting algebra, but does not manufacture affine covariance in X.

Therefore:

```plain text
VERDICT: REDUCE.

KILLED:
  “ordinary/higher-order/matrix bispectrality by itself compresses the
   balanced clock.”

OPEN NAMED STATEMENT:
  [AFFINE-BISPECTRAL-QUOTIENT].
```

A finite ansatz search for a fixed-order operator

```plain text
sum_(j=-q)^q A_j(X) K_m(X+j)=Lambda(m)K_m(X)         (1.5)
```

is still worthwhile, but a positive hit must be followed by an independent affine-covariance test. An eigenoperator alone is not enough.

# 2. Cartier semilinearity and p-step translation

## 2.1 The actual constructed object

Beukers' p-linear scheme is exactly a bounded-state digit carrier. For fixed precision p^r, one has a state vector a_n of dimension depending on r but not on p, and matrices M_v, 0<=v<p, such that

```plain text
a_(ap+v)=M_v a_a mod p^r.                            (2.1)
```

Equivalently, for generating functions,

```plain text
F(t)=M(t)F(t^p) mod p^r,

deg M(t)<p.                                         (2.2)
```

This is a genuine fixed-state Cartier/Frobenius quotient for the p-dilation clock.

For the banked Apéry companion normalization, the first depth gives

```plain text
b_(ap+v)       = b_a b_v mod p,
p^3 c_(ap+v)   = c_a b_v mod p.                     (2.3)
```

Hence, whenever b_v!=0,

```plain text
[b_(ap+v) : p^3 c_(ap+v)] = [b_a:c_a].              (2.4)
```

Each p-block collapses projectively to its high-digit state. This is a strong and fully Apéry-specific construction.

## 2.2 Is n -> n+p a basepoint-independent bounded map?

Not in the needed sense.

Write n=ap+v. Then

```plain text
n+p=(a+1)p+v.
```

Equation (2.1) gives

```plain text
a_n       = M_v a_a,
a_(n+p)   = M_v a_(a+1).                             (2.5)
```

So the p-step map still requires the high-digit increment

```plain text
a -> a+1.
```

There is generally no single matrix S with a_(a+1)=S a_a for all a. Such an S would turn all state coordinates into constant-coefficient recurrence sequences.

What exists is a finite-state transducer with carries, not one basepoint-independent linear operator. The distinction is:

```plain text
finite automaton complexity:          yes;
uniform algebraic one-step action:    no.
```

In the explicit projective quotient (2.4), p-translation sends the block label

```plain text
pi(a) -> pi(a+1).
```

Thus the quotient is self-similar: it renormalizes the original nonautonomous clock rather than eliminating it.

## 2.3 Exact digit decomposition of a collision

Write

```plain text
n=ap+v,
h=h_0+p h_1,
0<=v,h_0<p.
```

Let

```plain text
kappa=1 if v+h_0>=p, else 0,
v'=v+h_0-kappa*p,
a'=a+h_1+kappa.                                     (2.6)
```

Then, away from low-digit zeros,

```plain text
W_n       := (b_n,p^3c_n)       = b_v  (b_a,c_a),
W_(n+h)                           = b_v' (b_a',c_a') mod p.
```

Therefore

```plain text
[W_n]=[W_(n+h)]
  <=> pi(a)=pi(a+h_1+kappa),                         (2.7)
```

provided b_v b_v'!=0.

This is a useful exact reduction for multi-block problems. Low-digit zeros form the exceptional stratum and require the next p-adic layer.

## 2.4 Why it is blind to the present mesoscopic problem

For the present orbit,

```plain text
N=p-1,
D=sqrt(p)*L<p
```

in the intended range. Every nonwrapping pair has

```plain text
a=0,
h_1=0,
kappa=0.
```

Then (2.7) becomes

```plain text
pi(0)=pi(0),
```

a tautology. The p-step quotient has collapsed precisely the low digit v whose variation defines the first-block collision.

This is not a technical loss. It is the categorical meaning of the rank-one block degeneration already observed in the depth tower.

## 2.5 What fixed state count does not give

The matrices M_v lie in a fixed-dimensional matrix algebra, but their dependence on the digit v can still have full complexity. In Beukers' formulation, the matrix polynomial M(t) has degree <p; fixed state number does not imply bounded conductor or bounded degree as a function of the digit.

The exact missing statement is:

```plain text
[WITHIN-DIGIT-CARTIER]

For the Apéry p-linear scheme at the precision needed by the collision
observable, the digit family v -> M_v factors through a fixed algebraic
variety and bounded-degree map, uniformly in p, and retains enough
information to test pi(v)=pi(v+h).
```

A practical equivalent test is to ask whether the entry sequences of M_v, or the relative matrices

```plain text
M_(v+h) M_v^(-1),                                   (2.8)
```

have bounded linear/Hankel complexity after all known mirror and zero strata are removed.

## 2.6 Verdict

```plain text
VERDICT: CONSTRUCT + KILL-DIRECT + REDUCE.

CONSTRUCTED:
  bounded-state p-dilation / digit recursion;
  exact high-digit collision reduction (2.7).

KILLED FOR MESO-BALANCED-PAIR:
  direct use when D<p; the quotient is constant on the relevant first block.

OPEN NAMED STATEMENT:
  [WITHIN-DIGIT-CARTIER].
```

This remains the strongest survivor because it is the only mechanism with a genuine Apéry-specific bounded-state object already in hand.

# 3. Mellin/character linearization

## 3.1 Autonomous control

For a constant matrix A,

```plain text
U_m=A^m.
```

Over a splitting field,

```plain text
matrix coefficient of A^m
  = sum_i c_i lambda_i^m.                            (3.1)
```

The clock is a multiplicative character of the eigenvalue torus. This is the exact Mellin control. If the same spectral point is used for two lengths, common returns reduce to multiplicative-order/gcd data.

## 3.2 The exact cocycle condition that would restore the control

A nonautonomous cocycle would become Mellin-linear if there were a rational/algebraic gauge G(X) and a constant matrix A such that

```plain text
T(X)=G(X+1) A G(X)^(-1).                             (3.2)
```

Then

```plain text
U_m(X)=G(X+m) A^m G(X)^(-1),                         (3.3)
```

and m would again be a character clock.

This is the precise coboundary condition behind the informal phrase “make h a character.”

## 3.3 Rational coboundary death certificate

For the polynomial transfer used in Q6593,

```plain text
det T(X)=X^6.
```

Taking determinants in (3.2), with f=det G and c=det A, gives

```plain text
f(X+1)/f(X)=X^6/c.                                   (3.4)
```

No nonzero rational function satisfies (3.4). Indeed, the divisor of a rational f has finite support. Along the integer translation orbit, the valuations of f(X+1)/f(X) telescope. The right side has a nonzero jump at X=0; propagating that jump forces infinitely many nonzero translated valuations, contradicting finite support.

A Gamma/factorial gauge solves the scalar determinant equation transcendently. It does not make the full matrix cocycle constant; after determinant normalization the trace and off-diagonal ratios still vary with X. A further finite algebraic constantization would imply hypergeometric/constant-coefficient solution structure, contrary to the banked irreducibility/no-hypergeometric-factor diagnosis of the Apéry recurrence.

Thus the ordinary torus coboundary is dead.

## 3.4 Additive Fourier does not rescue it

One may try additive characters of the clock instead of multiplicative Mellin characters. On functions on F_p, let

```plain text
S f(x)=f(x+1),
M f(x)=x f(x).
```

The algebra generated by S and M is the full matrix algebra End(F_p^(F_p)). A direct proof is:

```plain text
P_a(M)=1-(M-a)^(p-1)
```

is the projector onto the clock point a; shifts of these projectors give every matrix unit. Hence any faithful representation retaining both clock translation and polynomial dependence on the absolute clock has dimension at least p.

Fourier diagonalizes S, but turns M into the conjugate full operator. It does not produce an O(1) quotient.

This is the finite-field Weyl-algebra form of the clock-complexity wall.

## 3.5 Mirror is the only character quotient presently available

The reflection law

```plain text
K_m(-X-m)=(-1)^m K_m(X)                             (3.5)
```

becomes ordinary parity after centering Y=2X+m. Thus the clock has one genuine finite character quotient:

```plain text
m -> (-1)^m in mu_2.
```

It explains the forced mirror factor, halves the primitive degree, and changes constants. It does not linearize the balanced interior or provide characters of unbounded order.

## 3.6 Verdict

```plain text
VERDICT: KILL, except mirror parity.

CONSTRUCTED CONTROL:
  autonomous eigenvalue-character torus.

KILLED:
  rational/algebraic constant cocycle gauge;
  ordinary additive Fourier as a bounded-rank quotient.

SURVIVING QUOTIENT:
  the already-known mu_2 mirror character only.
```

# 4. Mixed-Frobenius quotient and the rank-5 dual coordinate J

## 4.1 The precise “index shift is inner” condition

Let W_p denote the proposed rank-5 object obtained from the rank-4 mixed crystal and the dual coordinate J. Let

```plain text
A_p subset End(W_p)
```

be the algebra generated by the connection, Frobenius, extension operators, and the rank-one tensors supplied by J.

A literal inner clock quotient would require an invertible element S_p in A_p and coefficient functionals ell_n such that

```plain text
sigma_clock = Ad_(S_p),

ell_(n+1)=ell_n o sigma_clock^(-1),                  (4.1)
```

and all quantities used in the collision test—b_n,c_n, or the Green minors—are fixed matrix coefficients of the orbit of sigma_clock.

Then one-step coefficient translation would be internal to one finite algebra.

## 4.2 A formal inner shift already exists—but in the wrong localization

In the localized Weyl algebra generated by t^(+-1) and

```plain text
theta=t d/dt,
```

one has

```plain text
Ad_t(theta)=t theta t^(-1)=theta-1.                 (4.2)
```

So shifting the theta-eigenvalue/index is formally inner after inverting t.

This is a genuine construction, but it removes the point where coefficients live. Taylor coefficient extraction is supported at the MUM point t=0, where t is not invertible.

Moreover,

```plain text
t L(theta,t) t^(-1)=L(theta-1,t),                   (4.3)
```

not L(theta,t). Multiplication by t does not preserve the horizontal solution space of one fixed Apéry module. It moves through a ladder of conjugate modules.

Thus operator-level innerness does not imply coefficient-level innerness.

## 4.3 The coefficient dual is an infinite jet module

Let

```plain text
ell_n(F)=[t^n]F.
```

Multiplication by t acts on the dual as the unilateral shift

```plain text
ell_n(tF)=ell_(n-1)(F),                              (4.4)
```

with a boundary at n=0. The family

```plain text
ell_0,ell_1,ell_2,...
```

is the infinite local-cohomology/jet ladder at t=0.

If an invertible operator on a fixed finite-dimensional space generated all ell_n, every scalar matrix coefficient would satisfy a constant-coefficient recurrence of bounded order by Cayley-Hamilton. In characteristic zero this is impossible for the Apéry numbers: their generating function is not rational, and their standard asymptotic contains the nonintegral power n^(-3/2), whereas constant-coefficient recurrence sequences are finite sums of P(n)lambda^n with polynomial P.

Therefore:

```plain text
no faithful characteristic-zero finite-rank inner one-step quotient exists.
```

A single additional dual coordinate J can add one local functional; it cannot by itself collapse the entire coefficient-dual tower.

## 4.4 Depth-tower consistency check

The banked formula is

```plain text
p^3 c_(p+v)=(p^3c_p) K_v(p) mod p^7,                (4.5)
```

with

```plain text
K_v(T)=b_v+2D_v T+E_v T^2+F_v T^3+...              (4.6)
```

Thus increasing p-adic precision reveals successive clock-jet sequences

```plain text
b_v, D_v, E_v, F_v, ...
```

rather than closing after the pure rank-4 state. This is exactly what the infinite local-dual picture predicts.

The first-block collision equation is independent of the mixed extension coordinate, and the banked tests show that collisions do not force the D,E,F minors. Adding J can help only if it supplies a genuinely new coefficient functional, not merely another fiber coordinate.

## 4.5 What remains logically open

The characteristic-zero linear inner quotient is dead. A p-dependent nonlinear or semilinear quotient modulo p is not ruled out. Frobenius/Cartier can collapse an infinite jet module because it keeps only indices divisible by p; this is precisely why p-linear schemes exist.

The correct survivor is therefore:

```plain text
[FINITE-CARTIER-LOCAL-DUAL]

There exists, uniformly in p, a finite quotient of the local coefficient
or distribution module at t=0 which

- is stable under Cartier/Frobenius;
- has a bounded-complexity low-digit transition;
- contains the functional represented by J;
- and through which the projective collision minor factors.
```

The one-step map in this statement should not be required to be invertible. Requiring an inner automorphism was too strong and is contradicted by the unilateral coefficient shift.

## 4.6 Exact falsification test for the rank-5 proposal

Once J_v is computed, form the vector sequence

```plain text
q_v=(b_v,D_v,E_v,F_v,J_v) mod p.                    (4.7)
```

Across several primes, compute:

```plain text
- Berlekamp-Massey order of every generic linear projection of q_v;
- block Hankel rank of (q_(i+j));
- rank of the algebra generated by relative transition maps q_v -> q_(v+1);
- the same quantities after mirror quotient and deletion of zero strata.
```

A uniform rank <=5 or another absolute constant is evidence for a finite inner/local-dual quotient. Rank growing proportionally to the tested window kills every linear rank-5 realization, while leaving a nonlinear Cartier quotient open.

## 4.7 Verdict

```plain text
VERDICT: CONSTRUCT-AT-OPERATOR-LEVEL + KILL-LITERAL-INNER + REDUCE.

CONSTRUCTED:
  Ad_t(theta)=theta-1 in the localized Weyl algebra.

KILLED:
  a faithful finite-rank invertible inner action on all coefficient clocks;
  the claim that two first-block collision equations recover the cancelled
  extension coordinate automatically.

OPEN NAMED STATEMENT:
  [FINITE-CARTIER-LOCAL-DUAL].
```

## 5.1 Rank 1: Cartier / p-linear + local dual

This route has an actual fixed-state object and an exact block formula. Its failure is sharply localized:

```plain text
p-dilation is compressed;
within-digit one-step motion is not.
```

The next proof target should combine

```plain text
[WITHIN-DIGIT-CARTIER]

```

This is also the most direct bridge to the parallel “index-Frobenius = t-Frobenius” line.

## 5.2 Rank 2: mixed-Frobenius + J

This is not independent of rank 1; it is the candidate source of the missing local-dual functional. The literal “inner automorphism” formulation should be abandoned. The useful target is a finite semilinear, noninvertible Cartier quotient of the coefficient dual.

## 5.3 Rank 3: affine-covariant bispectrality

The autonomous control proves that the idea could work. But classical, higher-order, and matrix bispectrality do not supply start-clock translation. A positive finite-order eigenoperator is only half a result; affine covariance is the load-bearing half.

## 5.4 Rank 4: Mellin character

Beyond the mirror mu_2 quotient, ordinary Mellin/Fourier linearization is structurally blocked. Any revival would have to pass through one of the first three mechanisms, not through a direct character transform of the raw clock.

# 8. Required final answers

## (a) Least-confident step

The least-confident part is the negative inference from the depth-tower shape to the rank-5 proposal. The characteristic-zero finite linear inner quotient is rigorously excluded, but a p-dependent nonlinear or semilinear quotient of the local distribution module could evade the C-finite argument. In characteristic p, divided powers, nilpotence, and Cartier projection can collapse structures that are infinite in characteristic zero. That is exactly why [FINITE-CARTIER-LOCAL-DUAL] remains open.

The higher-order bispectral route is also not classified: the control shows what extra covariance is needed, not that no Apéry-specific affine-covariant operator exists.

## (b) Likely shared blind spot

The likely shared blind spot is the local coefficient dual at the MUM point, not another fiber coordinate of the pure or mixed crystal.

We have repeatedly searched in:

```plain text
- period/crystal fibers;
- transfer states;
- Plucker minors;
- global Mellin characters.
```

But coefficient index n lives naturally in the distribution/jet module supported at t=0. Frobenius sees that module through Cartier and base-p digit selection; one-step translation sees it through the unilateral t-shift. The correct quotient may therefore be a finite p-typical quotient of this local dual, possibly generated jointly by the mixed extension and J, rather than a quotient of the crystal fiber itself.

If such a quotient exists, it would simultaneously explain:

```plain text
p-linear digit schemes,
the depth tower,
index-Frobenius comparison,
and clock compression.
```

If its Hankel/linear complexity grows with p even after adding J, then the last plausible bounded-complexity clock quotient is dead and the campaign should return to direct family-level transversality/dispersion.
