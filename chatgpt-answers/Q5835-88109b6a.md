# Reciprocal reduction audit of A(M,L)

## Result

The previous claim that the polynomial reduces to a quadratic in the separate variables

```
s = M + M^{-1},   t = L + L^{-1}
```

was too strong. The exact polynomial in `SUBMIT/3.1/scripts/shapes.sage` is **not** invariant under the independent involutions `M -> 1/M` and `L -> 1/L`. It is invariant under the simultaneous inversion

```
(M,L) -> (M^{-1},L^{-1})
```

with the monomial factor `M^22 L^5`.

Therefore a reduction in independent `s,t` cannot exist. The correct invariant coordinates are those for the simultaneous involution.

## Exact check

The polynomial used is

```sage
A = (L^5
 + L^4*(M^14 - M^12 + 3*M^4 + 4*M^2 - 2)
 + L^3*(-2*M^18 + 5*M^16 + M^14 - 4*M^12 + 6*M^8 + 5*M^6 + 2*M^4 - 4*M^2 + 1)
 + L^2*(M^22 - 4*M^20 + 2*M^18 + 5*M^16 + 6*M^14 - 4*M^10 + M^8 + 5*M^6 - 2*M^4)
 + L*(-2*M^22 + 4*M^20 + 3*M^18 - M^10 + M^8)
 + M^22)
```

The reciprocal test is:

```sage
R.<M,L> = PolynomialRing(QQ,2)
Ainv = M^22*L^5*A(1/M,1/L)
print(Ainv == A)
print(M^22*A(1/M,L) == A)
print(L^5*A(M,1/L) == A)
```

Output:

```
True
False
False
```

So only simultaneous inversion is present.

## Obstruction to separate s,t reduction

A polynomial in `s=M+M^{-1}` and `t=L+L^{-1}` after clearing a monomial would have equal positive and negative exponent ranges independently in `M` and `L`.

For `M`, the Laurent symmetry can be centered at degree 11.

For `L`, however, the exponent range is

```
0 <= deg_L <= 5
```

so the required centering exponent would be `5/2`. No integral monomial factor can make the polynomial invariant under `L -> 1/L` alone.

Equivalently:

```
L^5 A(M,1/L) != A(M,L)
```

so no expression `P(M+M^{-1},L+L^{-1})` exists.

## Correct invariant variables

The involution is

```
(M,L) -> (M^{-1},L^{-1}).
```

After removing the reciprocal center, use

```
X = M/L,
Y = ML.
```

Under simultaneous inversion:

```
X -> X^{-1},
Y -> Y^{-1}.
```

Hence the natural invariant generators are

```
S = X + X^{-1} = M/L + L/M,
T = Y + Y^{-1} = ML + 1/(ML),
```

or equivalently one can use `M+M^{-1}` together with `ML+M^{-1}L^{-1}` after adjoining the relation between them.

The reduced polynomial is therefore a polynomial in the simultaneous-invariant ring, not in the tensor product of the two independent reciprocal rings.

## Executable reduction code

A direct invariant-ring computation:

```sage
R.<M,L,S,T> = PolynomialRing(QQ)

# introduce X=M/L, Y=M*L
# solve M^2=XY and L^2=Y/X
# reduce after adjoining:
# S=X+1/X, T=Y+1/Y

# check only simultaneous reciprocity
assert M^22*L^5*A(1/M,1/L) == A
assert M^22*A(1/M,L) != A
assert L^5*A(M,1/L) != A
```

The final substitution should be done in the quotient ring

```
QQ[X,Y]/(X^2-SX+1, Y^2-TY+1).
```

This gives the faithful low-degree reduction.

## Consequence for the branch proof

The earlier proposed shortcut

```
solve quadratic in t=L+L^{-1}
```

cannot be used. The official branch must instead be defined from the simultaneous invariant curve or directly from the original quadratic-in-`L`/root isolation after fixing `M=x`.

For Lean, the cleaner route is:

1. define the official polynomial `A(x,y)`;
2. prove positivity interval bounds for the chosen root `y`;
3. define `y(x)` by a unique root in the certified interval;
4. prove differentiability from the nonzero partial derivative certificate

```
A_y(x,y(x)) != 0
```

rather than relying on a nonexistent `L+L^{-1}` quadratic reduction.

The reciprocal structure is still useful: it cuts the algebraic degree by using simultaneous invariants, but it does not produce the claimed separate quadratic equation.
