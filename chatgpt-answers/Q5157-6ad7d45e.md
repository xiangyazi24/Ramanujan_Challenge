The kernel (2.1) contains coefficients of dominant size. An absolute estimate gives only

Thus (2.1) is analogous to writing the desired identity into the integrand. It is valuable as a specification and as a unit test, but not as a Beukers decay certificate.

A genuinely useful kernel must be defined independently of p_n,q_n and satisfy all four conditions:

1. Arithmetic moments

1. Exact recurrence by coefficientwise identity or a WZ/Chyzak telescoping certificate.

1. Initial matching at three consecutive indices.

1. Strict subdominant bound

Only these four facts would make the proof unconditional.

    9525021973931919*t - 2833731372195759

    384303768976036377*t - 114331877231773977

# For a linear polynomial a+b*t,
# integral K(xy) w(x,y) dxdy = (a+b)*L - 2*b.
def mixed_integral_linear(P):
    a = P[0]
    b = P[1]
    return RL(a+b)*L - RL(2*b)

for n in range(3):
    assert mixed_integral_linear(K[n]) == RL(p[n]) - RL(q[n])*L

@cached_function
def H(k, r):
    return sum(Q(1)/Q(j)^r for j in range(1, k+1))

def mixed_integral_polynomial(P):

        P[k] * (H(k,2) + H(k,3))
