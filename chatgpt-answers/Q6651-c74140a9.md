# Verdict

CONFIRMED, with one graph-model qualification. The inequality is correct with the stated constant:

```plain text
Q_D <= (sqrt(2)/3) * S_1(D)^(3/2).
```

The correct graph has the orbit indices as vertices and the collision events (r,d) as edges. Also, the graph is not globally triangle-closed for every graph-theoretic wedge. What is true, and exactly what is needed, is that every forward same-base wedge counted by Q_D closes to a triangle. In fact Q_D is exactly the number of triangles in this graph, with no factor of 2, 3, or 6.

The coefficient sqrt(2)/3 follows from a standard spectral triangle bound and is asymptotically sharp even inside this interval-collision class.

# 1. The correct collision graph

Work first with an arbitrary finite sequence of colors or projective states

```plain text
x_1, x_2, ..., x_N.
```

For the Apery application, take x_n = pi(n) and N = M = p-2, or take the relevant nonwrapping subwindow. Fix an integer D >= 1; replacing D by min(D,N-1) changes nothing.

Define a simple undirected graph G_D by

```plain text
V(G_D) = {1,2,...,N},

{i,j} in E(G_D)
    iff
1 <= i < j <= N,
j-i <= D,
and x_i = x_j.
```

Thus a collision event (r,d) with

```plain text
1 <= d <= D,
r+d <= N,
x_r = x_(r+d)
```

is exactly the edge {r,r+d}. There are no parallel edges: (r,d) is recovered uniquely from the ordered endpoints r < r+d.

Let

```plain text
d_D(r) = #{d : 1 <= d <= D, r+d <= N, x_r = x_(r+d)}.
```

Then the number of graph edges is exactly

```plain text
E := |E(G_D)|
   = sum_r d_D(r)
   = sum_(d<=D) R_d
   = S_1(D).
```

So the graph vertices are indices, not collision events and not bases alone. The collision events are the graph edges.

# 2. Q_D is exactly the triangle count

By definition,

```plain text
Q_D = sum_r C(d_D(r),2).
```

Equivalently, Q_D counts triples (r,d,d') satisfying

```plain text
1 <= d < d' <= D,
r+d' <= N,
x_r = x_(r+d) = x_(r+d').
```

For such a triple, the two collision edges from the same base are

```plain text
{r,r+d},
{r,r+d'}.
```

Transitivity of equality gives

```plain text
x_(r+d) = x_(r+d').
```

Moreover, the third gap is

```plain text
d'-d,
```

and it satisfies

```plain text
1 <= d'-d <= D-1 <= D.
```

Therefore {r+d,r+d'} is also an edge of G_D. Hence

```plain text
{r,r+d,r+d'}
```

is a triangle.

Conversely, let {i,j,k} be a triangle of G_D, written uniquely as

```plain text
i < j < k.
```

Because {i,j} and {i,k} are edges,

```plain text
j-i <= D,
k-i <= D,
x_i = x_j = x_k.
```

Thus the triangle produces the unique same-base pair

```plain text
r = i,
d = j-i,
d' = k-i,
```

counted by C(d_D(i),2).

These two maps are inverse. Therefore

```plain text
Q_D = T(G_D),
```

where T(G_D) is the number of unordered graph triangles.

This is stronger and cleaner than merely injecting wedges into triangles.

## Important qualification on "triangle-closed"

The whole graph need not have the property that every wedge closes. A mixed wedge

```plain text
i -- j -- k,
```

with j-i <= D and k-j <= D can have k-i > D, so {i,k} need not be an edge. The closure statement applies to the co-oriented wedges counted by Q_D: two edges whose common vertex is their common smaller endpoint. Those wedges have their longest edge already present, and equality supplies the remaining short edge.

# 3. Spectral triangle bound and the exact coefficient

Let A be the adjacency matrix of an arbitrary finite simple graph with E edges and T triangles. Let its real eigenvalues be

```plain text
lambda_1 >= lambda_2 >= ... >= lambda_N.
```

The standard trace identities are

```plain text
tr(A^2) = sum_i lambda_i^2 = 2E,
tr(A^3) = sum_i lambda_i^3 = 6T.
```

For every i, since lambda_i <= lambda_1 and lambda_i^2 >= 0,

```plain text
lambda_i^3 <= lambda_1 * lambda_i^2.
```

This remains valid when lambda_i < 0, because then the left side is negative. Summing gives

```plain text
6T
 = sum_i lambda_i^3
 <= lambda_1 * sum_i lambda_i^2
 = 2E * lambda_1.
```

Also,

```plain text
lambda_1^2 <= sum_i lambda_i^2 = 2E,
```

so

```plain text
lambda_1 <= sqrt(2E).
```

Consequently,

```plain text
6T <= 2E * sqrt(2E),
```

and hence

```plain text
T <= (sqrt(2)/3) * E^(3/2).
```

Applying T = Q_D and E = S_1(D) proves

```plain text
Q_D <= (sqrt(2)/3) * S_1(D)^(3/2).
```

Thus the stated constant is correct.

# 4. Sharpness of the constant

The coefficient cannot be replaced by any smaller absolute constant in this abstract collision class.

Take k consecutive indices having the same color and take D >= k-1. The induced collision graph on those indices is K_k. Then

```plain text
E = C(k,2),
Q_D = T = C(k,3).
```

Therefore

```plain text
T / E^(3/2)
 = (sqrt(2)/3) * (k-2)/sqrt(k(k-1))
 -> sqrt(2)/3
```

as k -> infinity.

Kruskal-Katona gives the sharper exact integer envelope for a prescribed number of edges, but the spectral proof already gives the claimed coefficient, and the clique examples show that this coefficient is asymptotically optimal even for graphs arising from bounded-gap equality collisions.

# 5. Boundary and multiplicity audit

There is no window leakage.

Suppose (r,d) and (r,d'), with d < d', are admissible collision events. The closing collision has

```plain text
base = r+d,
gap  = d'-d.
```

The upper endpoint is

```plain text
(r+d) + (d'-d) = r+d' <= N,
```

and the new gap obeys

```plain text
1 <= d'-d <= D-1.
```

Thus the closing edge remains in the same nonwrapping window and remains under the same gap cutoff.

The multiplicity conventions also match exactly:

- Each (r,d) is one undirected edge.

- C(d_D(r),2) counts unordered pairs d < d' once.

- Each such pair gives one unordered triangle.

- Every triangle has a unique least vertex, so it is recovered from exactly one base r in Q_D.

Hence there is no missing factor from edge orientation, triangle orientation, cyclic ordering, or choice of a triangle vertex.

# 6. Consequence for the mesoscopic target

At the campaign scale

```plain text
D = sqrt(N) * L,
```

assume the proposed first-moment statement

```plain text
[MESO-S1-2/3]
S_1(D) <= C * N^(2/3)
```

with a uniform constant C in the permitted mesoscopic range. Then

```plain text
Q_D
 <= (sqrt(2)/3) * (C * N^(2/3))^(3/2)
 = (sqrt(2)/3) * C^(3/2) * N.
```

Therefore

```plain text
[MESO-S1-2/3] => [MESO-PAIR].
```

There is no circularity. The triangle inequality is a deterministic statement about equality collisions in any finite word; it uses neither the desired pair estimate nor an arithmetic estimate on the Apery orbit.

There is also a notation simplification that should be recorded explicitly. If the campaign's S_D denotes the total collision mass

```plain text
S_D = sum_r d_D(r),
```

then

```plain text
S_D = S_1(D).
```

Thus [MESO-S1-2/3] immediately gives the stronger total-mass estimate

```plain text
S_D << N^(2/3) << N.
```

So the same hypothesis gives both required pieces:

```plain text
MESO-TOTAL: S_D << N,
MESO-PAIR:  Q_D << N.
```

Using the exact factorial-moment identity

```plain text
sum_r d_D(r)^2 = S_D + 2Q_D,
```

one then gets the capacity bound

```plain text
sum_r d_D(r)^2 << N.
```

The logical chain is therefore

```plain text
S_1(D) << N^(2/3)
    |-- trivially --> S_D << N,
    |-- triangle --> Q_D << N,
    `-- together --> sum_r d_D(r)^2 << N.
```

The exponent 2/3 is the exact threshold for this black-box triangle mechanism: if

```plain text
S_1(D) <= N^(alpha),
```

then it yields

```plain text
Q_D <= N^(3alpha/2),
```

so alpha <= 2/3 is precisely what makes the resulting exponent at most 1. This is a statement about the sufficiency threshold of this mechanism, not a claim that an actual orbit with Q_D << N must satisfy S_1(D) << N^(2/3).

More generally, if

```plain text
S_1(D) <= C * N^(2/3) * A(N),
```

then

```plain text
Q_D <= (sqrt(2)/3) * C^(3/2) * N * A(N)^(3/2).
```

Thus an unbounded logarithmic or L-factor in the first moment is not erased; it is raised to the power 3/2.

# 7. What the mechanism gives unconditionally

Insert the degree-based trivial first moment

```plain text
R_d <= 3(d-1).
```

Then, for D within the nonwrapping range,

```plain text
S_1(D)
 <= 3 * sum_(d=1)^D (d-1)
 = (3/2) * D(D-1).
```

The triangle inequality gives

```plain text
Q_D
 <= (sqrt(2)/3) * ((3/2)D(D-1))^(3/2)
 = (sqrt(3)/2) * (D(D-1))^(3/2)
 < (sqrt(3)/2) * D^3.
```

So, as anticipated, the unconditional output is only

```plain text
Q_D << D^3.
```

This is worse than the banked

```plain text
Q_D << 22 D^2 (1 + log D)
```

for large D, and also worse than the existing D^(5/2) bound. The triangle mechanism is therefore not an unconditional improvement by itself. Its value is as a very efficient converter of a genuinely strong first-moment census into the mesoscopic pair bound.

# Final audited statement

For every finite sequence (x_n) and every bounded-gap nonwrapping collision system, define

```plain text
R_d = #{r : r+d <= N and x_r = x_(r+d)},
S_1(D) = sum_(d<=D) R_d,
d_D(r) = #{d <= D : r+d <= N and x_r = x_(r+d)},
Q_D = sum_r C(d_D(r),2).
```

Then the index collision graph has exactly S_1(D) edges and exactly Q_D triangles. Hence

```plain text
Q_D <= (sqrt(2)/3) * S_1(D)^(3/2).
```

The constant is correct and asymptotically sharp. At D = sqrt(N)L, the first-moment estimate S_1(D) << N^(2/3) is sufficient, without circularity, for both MESO-TOTAL and MESO-PAIR, and hence for the corresponding second-moment capacity bound.
