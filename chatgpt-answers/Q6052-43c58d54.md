# P2.7: exact finite normalization certificate

## Verdict

There is an exact finite bridge, with no index shift and no change to the
Barnes integrand stated in the question.

Write

```text
R_n(t) = prod_{r=1}^n (t-r)^3 /
         ((n!)^2 prod_{j=0}^n (t+j)),
Phi_n(t) = R_n(t) - R_n'(t)/2.
```

Under the project convention

```text
zudilinCombinedError n
  = (zeta(2)+zeta(3))*b_n - m_n,
```

the required identity is

```text
zudilinCombinedError n = zudilinBarnesErrorIntegral n.
```

The shortest exact certificate has three algebraic pieces:

1. a finite partial fraction expansion of `R_n`, including its polynomial
   part;
2. a finite Bernoulli functional giving the two Abel endpoint constants;
3. one explicit rational creative-telescoping identity for `R_n` itself.

The same telescoper proves the recurrence for the common coefficient, the
`Li_2` numerator, and the `Li_3` numerator.  Thus no separate harmonic-sum
Zeilberger calculation is needed.

The polynomial part is load-bearing.  Dropping it gives the wrong values
already at `n=1`: it would give `8,8` instead of `23/2,17/2`.

The formulas below are exact identities over `Q`; the only analytic input they
use is the Abel-to-Barnes theorem that the question says is now formalized.
The source normalization agrees with Zudilin, Section 2 and Theorem 2 of
[*Approximations to -, di- and tri-logarithms*](https://arxiv.org/abs/math/0409023).

# 1. Finite partial fractions

Put

```text
N_n(t) = prod_{r=1}^n (t-r)^3,
D_n(t) = prod_{j=0}^n (t+j).
```

For `0 <= j <= n`, define

```text
c(n,j) = (-1)^(n+j) * binom(n,j) * binom(n+j,j)^3.
```

Equivalently,

```text
c(n,j)
 = (-1)^(n+j) * (n+j)!^3 /
   ((n!)^2 * (j!)^4 * (n-j)!).
```

These are exactly the simple-pole coefficients:

```text
Res_{t=-j} R_n(t) = c(n,j).                         (PF-res)
```

Indeed,

```text
prod_{r=1}^n (-j-r)^3
  = (-1)^n ((n+j)!/j!)^3,

prod_{0<=ell<=n, ell!=j} (ell-j)
  = (-1)^j j! (n-j)!,
```

and division gives `(PF-res)`.

There is a unique polynomial `P_n in Q[t]` such that

```text
R_n(t) = P_n(t) + sum_{j=0}^n c(n,j)/(t+j).          (PF)
```

For `n>=1`, `deg P_n = 2*n-1`; set `P_0=0`.

The denominator-cleared certificate is

```text
N_n(t)
 = (n!)^2 D_n(t) P_n(t)
   + (n!)^2 sum_{j=0}^n c(n,j) D_n(t)/(t+j).          (PF-poly)
```

Every term in `(PF-poly)` is a polynomial.  It is particularly convenient in
Lean: subtract the finite residue sum from `N_n`; the result vanishes at each
`-j`, hence is divisible by `D_n`.  No infinite series and no analytic residue
API are involved.

Define the common endpoint coefficient

```text
aPF_n = sum_{j=0}^n c(n,j).                          (aPF)
```

Thus

```text
aPF_n
 = (-1)^n sum_{j=0}^n
     (-1)^j binom(n,j) binom(n+j,j)^3.
```

This is Zudilin's `a_n`, hence the project sequence to be identified with
`b_n`.  The positive Whipple transform is not needed anywhere in this bridge.

# 2. The exact `Li_2` and `Li_3` rational forms

For `s=1,2,3`, set

```text
H_j^(s)(z) = sum_{ell=1}^j z^ell/ell^s,
H_j^(s)    = H_j^(s)(1),
A_n(z)     = sum_{j=0}^n c(n,j) z^(-j).
```

For `0<z<1`, the elementary identity

```text
sum_{nu>=1} z^nu/(nu+j)^s
  = z^(-j) * (Li_s(z) - H_j^(s)(z))                 (tail)
```

gives the three exact decompositions

```text
r0_n(z) := sum_{nu>=1} z^nu R_n(nu)
         = A_n(z) Li_1(z) - B0_n(z),

r2_n(z) := -sum_{nu>=1} z^nu R_n'(nu)
         = A_n(z) Li_2(z) - B2_n(z),

r3_n(z) := (1/2) sum_{nu>=1} z^nu R_n''(nu)
         = A_n(z) Li_3(z) - B3_n(z),                (Li)
```

where

```text
B0_n(z)
 = sum_j c(n,j) z^(-j) H_j^(1)(z)
   - sum_{nu>=1} z^nu P_n(nu),

B2_n(z)
 = sum_j c(n,j) z^(-j) H_j^(2)(z)
   + sum_{nu>=1} z^nu P_n'(nu),

B3_n(z)
 = sum_j c(n,j) z^(-j) H_j^(3)(z)
   - (1/2) sum_{nu>=1} z^nu P_n''(nu).              (Bz)
```

Since a power sum of a polynomial is rational in `z`, all of
`A_n,B0_n,B2_n,B3_n` belong to `Q(z)`.  Thus `(Li)` is the requested explicit
pair of rational `Li_2`/`Li_3` approximants.

The raw functions in `(Bz)` need not have finite values at `z=1`.  The finite
source forms are

```text
L2_n(z) = r2_n(z) - log(z) r0_n(z),
L3_n(z) = r3_n(z) - (log(z)/2) r2_n(z).              (regularized)
```

These are exactly the two pieces obtained by differentiating the Abel factor
in the Barnes residue calculation.

# 3. The finite Bernoulli endpoint functional

Use the positive Bernoulli convention

```text
u/(1-exp(-u)) = sum_{d>=0} beta_d u^d/d!,
```

so

```text
beta_0=1, beta_1=1/2, beta_2=1/6, beta_3=0, ...
```

For `P(t)=sum_d p_d t^d`, define the finite rational functional

```text
EB(P) = sum_d p_d beta_d.                            (EB)
```

In Mathlib 4.29 this is the existing sequence `bernoulli'`, not `bernoulli`:

```lean
bernoulli' 0 = 1
bernoulli' 1 = 1/2
bernoulli' 2 = 1/6
sum_bernoulli' n :
  sum k in range n, (n.choose k : Q) * bernoulli' k = n
```

See
[`Mathlib/NumberTheory/Bernoulli.lean`](https://github.com/leanprover-community/mathlib4/blob/v4.29.0/Mathlib/NumberTheory/Bernoulli.lean).
Using `bernoulli` would introduce the wrong sign at degree one.

For every polynomial `P`, with `z=exp(-x)`, one has

```text
lim_{x->0+}
  [x sum_{nu>=1} exp(-x nu) P(nu)
   - sum_{nu>=1} exp(-x nu) P'(nu)]
 = EB(P),                                             (Abel-P)
```

and consequently

```text
lim_{x->0+}
  (1/2) sum_{nu>=1} exp(-x nu)
    [P''(nu)-x P'(nu)]
 = -(1/2) EB(P').                                    (Abel-P')
```

A short derivation is to test formally on `P(t)=exp(u t)`:

```text
(x-u)/(exp(x-u)-1) -> u/(1-exp(-u)),
```

then compare the finitely many coefficients needed for a polynomial.  For a
Lean proof, linearize over monomials; `sum_bernoulli'` is precisely the finite
coefficient identity needed below.

For the pole basis, the endpoint limits are simply

```text
lim L2[1/(t+j)] = zeta(2)-H_j^(2),
lim L3[1/(t+j)] = zeta(3)-H_j^(3).
```

Therefore define the finite rational numerators

```text
b2PF_n
 = sum_{j=0}^n c(n,j) H_j^(2) - EB(P_n),             (b2PF)

b3PF_n
 = sum_{j=0}^n c(n,j) H_j^(3) + (1/2) EB(P_n'),      (b3PF)

mPF_n = b2PF_n + b3PF_n.                              (mPF)
```

Then the exact endpoint identities are

```text
lim_{z->1-} L2_n(z) = aPF_n*zeta(2) - b2PF_n,
lim_{z->1-} L3_n(z) = aPF_n*zeta(3) - b3PF_n,         (endpoint)
```

and hence

```text
pfCombinedError_n
 := aPF_n*(zeta(2)+zeta(3)) - mPF_n
  = lim_{z->1-} [L2_n(z)+L3_n(z)].                    (PF-error)
```

This is the finite normalization of the existing Abel--Barnes theorem.

# 4. A finite shift lemma

The recurrence bridge is shortest if the endpoint normalizer is treated as a
linear functional on rational functions.

Suppose

```text
F(t) = P(t) + sum_{j=0}^N d_j/(t+j).
```

Define

```text
poleSum(F) = sum_j d_j,

lambda2(F)
 = poleSum(F)*zeta(2)
   - [sum_j d_j H_j^(2) - EB(P)],

lambda3(F)
 = poleSum(F)*zeta(3)
   - [sum_j d_j H_j^(3) + (1/2) EB(P')],

Lambda(F) = lambda2(F)+lambda3(F).                    (normalizer)
```

Thus

```text
poleSum(R_n)=aPF_n,
lambda2(R_n)=aPF_n*zeta(2)-b2PF_n,
lambda3(R_n)=aPF_n*zeta(3)-b3PF_n,
Lambda(R_n)=pfCombinedError_n.
```

Let `Delta F(t)=F(t+1)-F(t)`.  Then the exact finite identities are

```text
poleSum(Delta F) = 0,
lambda2(Delta F) = F'(1),
lambda3(Delta F) = -(1/2) F''(1),
Lambda(Delta F) = F'(1) - F''(1)/2.                  (shift)
```

No limit theorem is needed to prove `(shift)`.

For the polynomial part,

```text
EB(P(t+1)-P(t)) = P'(1),                             (EB-shift)
```

because on `P=t^d` it is exactly

```text
sum_{k=0}^{d-1} binom(d,k) beta_k = d,
```

i.e. Mathlib's `sum_bernoulli'`.

For a pole basis element,

```text
1/(t+j+1)-1/(t+j)
```

has coefficients `-1` at `j` and `+1` at `j+1`, so

```text
lambda2 = -(H_(j+1)^(2)-H_j^(2)) = -1/(j+1)^2
        = (1/(t+j))' at t=1,

lambda3 = -(H_(j+1)^(3)-H_j^(3)) = -1/(j+1)^3
        = -(1/2) (1/(t+j))'' at t=1.
```

Linearity proves `(shift)`.

This lemma is the key simplification: a telescoping difference is annihilated
by the combined source normalizer whenever its certificate has a triple zero
at `t=1`.

# 5. Explicit rational creative telescoper

Use the source recurrence coefficients

```text
alpha_n
 = 2*(946*n^2-731*n+153)*(2*n+1)*(n+1)^3,

beta_n
 = 2*(104060*n^6+127710*n^5+12788*n^4
      -34525*n^3-8482*n^2+3298*n+1071),

gamma_n
 = 2*n*(3784*n^5-1032*n^4-1925*n^3
        +853*n^2+328*n-184),

delta_n
 = (946*n^2+1161*n+368)*n*(n-1)^3.                  (rec-coeff)
```

Thus the recurrence is

```text
alpha_n u_(n+1) - beta_n u_n
+ gamma_n u_(n-1) - delta_n u_(n-2) = 0,
                                                      n>=2. (Rec)
```

## 5.1 Derivation of the telescoper ansatz

The finite-product ratios are

```text
R_(n+1)(t)/R_n(t)
 = (t-n-1)^3 / ((n+1)^2*(t+n+1)),

R_(n-1)(t)/R_n(t)
 = n^2*(t+n)/(t-n)^3,

R_(n-2)(t)/R_n(t)
 = n^2*(n-1)^2*(t+n)*(t+n-1)
   / ((t-n)^3*(t-n+1)^3),

R_n(t+1)/R_n(t)
 = t^4 / ((t-n)^3*(t+n+1)).                          (ratios)
```

Seek

```text
S_n(t) = C_n(t) R_n(t),
C_n(t) = Qhat_n(t-n)/(t-n)^3.
```

Substituting `(ratios)` reduces the desired identity to one polynomial
identity.  The denominator analysis forces this form of `C_n`; coefficient
comparison gives a unique solution of degree at most six for `Qhat_n`.

## 5.2 The degree-six polynomial

Write

```text
Qhat_n(x) = q0(n)+q1(n)x+...+q6(n)x^6,
```

where

```text
q0(n) =
 -4*(n-1)^2*n^4*(2*n-1)*(946*n^2+1161*n+368),

q1(n) =
  2*(n-1)*n^3*(10*n^2-2*n-1)*(946*n^2+1161*n+368),

q2(n) =
 -n^3*(38*n^2-n-5)*(946*n^2+1161*n+368),

q3(n) =
  2448 + 5440*n - 26056*n^2 - 43516*n^3
  + 69621*n^4 + 156993*n^5 + 74734*n^6,

q4(n) =
 -2*(612 + 2971*n - 12132*n^2 - 14629*n^3
     + 41538*n^4 + 45408*n^5),

q5(n) =
 -3*(2*n^2+6*n+3)*(946*n^2-731*n+153),

q6(n) =
  (2*n+1)*(946*n^2-731*n+153).                       (Qhat)
```

Let

```text
alphaBar_n = alpha_n/(n+1)^2
           = 2*(946*n^2-731*n+153)*(2*n+1)*(n+1).
```

The complete denominator-cleared certificate is

```text
(n+x)^4 Qhat_n(x+1)
- (x+1)^3*(x+2*n+1)*Qhat_n(x)

= alphaBar_n*(x-1)^3*x^3*(x+1)^3
  - beta_n*(x+1)^3*x^3*(x+2*n+1)
  + gamma_n*n^2*(x+2*n)*(x+1)^3*(x+2*n+1)
  - delta_n*n^2*(n-1)^2
      *(x+2*n)*(x+2*n-1)*(x+2*n+1).                 (CT-poly)
```

This is an identity in `Q[n,x]`.  After the definitions are expanded, Lean's
`ring`/`ring_nf` verifies it directly.

Using `(ratios)`, `(CT-poly)` is exactly

```text
alpha_n R_(n+1)(t) - beta_n R_n(t)
+ gamma_n R_(n-1)(t) - delta_n R_(n-2)(t)

= S_n(t+1)-S_n(t),                                   (CT)
```

with

```text
S_n(t)
 = Qhat_n(t-n)/(t-n)^3 * R_n(t)
 = Qhat_n(t-n) * prod_{r=1}^{n-1}(t-r)^3
   / ((n!)^2 prod_{j=0}^n(t+j)).                     (S)
```

The second expression in `(S)` is preferable as the Lean definition: the
factor `(t-n)^3` has already been cancelled, so there is no totalized-division
artifact at `t=n`.

For `n>=2`, `(S)` visibly contains `(t-1)^3`; its denominator is nonzero at
`t=1`.  Hence

```text
S_n'(1)=0,
S_n''(1)=0.                                           (triple-zero)
```

## 5.3 Recurrence consequences

Apply `poleSum` to `(CT)`.  By `(shift)`, the right side has pole sum zero, so

```text
alpha_n aPF_(n+1) - beta_n aPF_n
+ gamma_n aPF_(n-1) - delta_n aPF_(n-2) = 0.         (Rec-a)
```

Apply `lambda2` and `lambda3`.  By `(triple-zero)` and `(shift)`, both right
sides vanish.  Thus the two source errors satisfy `(Rec)`.  Combining with
`(Rec-a)` gives

```text
b2PF_n satisfies (Rec),
b3PF_n satisfies (Rec),
mPF_n  satisfies (Rec),
pfCombinedError_n satisfies (Rec).                   (Rec-all)
```

No irrationality or linear-independence statement about `zeta(2),zeta(3)` is
used: for example

```text
Rec(lambda2(R)) = zeta(2)*Rec(aPF) - Rec(b2PF) = 0,
Rec(aPF)=0,
```

so `Rec(b2PF)=0` purely algebraically.

This explicit `S_n` is the requested rational telescoper.  It replaces any
citation to creative telescoping.

# 6. Exact checks at `n=0,1,2`

The relevant positive Bernoulli values are

```text
beta_0=1, beta_1=1/2, beta_2=1/6, beta_3=0.
```

## `n=0`

```text
R_0(t)=1/t,
P_0(t)=0,
c(0,0)=1.
```

Therefore

```text
aPF_0=1,
b2PF_0=0,
b3PF_0=0,
mPF_0=0.
```

## `n=1`

Direct division gives

```text
R_1(t) = (t-4) - 1/t + 8/(t+1).
```

Thus

```text
P_1(t)=t-4,
(c(1,0),c(1,1))=(-1,8),
aPF_1=7.
```

Also

```text
EB(P_1)=1/2-4=-7/2,
EB(P_1')=1,

sum_j c(1,j) H_j^(2)=8,
sum_j c(1,j) H_j^(3)=8.
```

Hence

```text
b2PF_1 = 8-(-7/2)=23/2,
b3PF_1 = 8+(1/2)=17/2,
mPF_1  = 20.
```

## `n=2`

One obtains

```text
R_2(t)
 = t^3/4 - 3*t^2 + 67*t/4 - 60
   + 1/t - 54/(t+1) + 216/(t+2).
```

Thus

```text
P_2(t)=t^3/4-3*t^2+67*t/4-60,
(c(2,0),c(2,1),c(2,2))=(1,-54,216),
aPF_2=163.
```

The polynomial corrections are

```text
EB(P_2)
 = -3*(1/6)+(67/4)*(1/2)-60
 = -417/8,

EB(P_2')
 = (3/4)*(1/6)-6*(1/2)+67/4
 = 111/8.
```

Since

```text
H_1^(2)=1, H_2^(2)=5/4,
H_1^(3)=1, H_2^(3)=9/8,
```

we have

```text
sum_j c(2,j) H_j^(2)
 = -54+216*(5/4)=216,

sum_j c(2,j) H_j^(3)
 = -54+216*(9/8)=189.
```

Therefore

```text
b2PF_2 = 216-(-417/8)=2145/8,

b3PF_2 = 189+(1/2)*(111/8)=3135/16,

mPF_2  = 2145/8+3135/16=7425/16.
```

So the exact initial tables are

```text
aPF = (1, 7, 163),
b2PF = (0, 23/2, 2145/8),
b3PF = (0, 17/2, 3135/16),
mPF  = (0, 20, 7425/16).
```

They agree with the project vectors exactly.

# 7. Recurrence uniqueness and the project bridge

The leading coefficient never vanishes.  In fact

```text
4*946*(946*n^2-731*n+153)
  = (1892*n-731)^2 + 44591 > 0.
```

Hence `alpha_n>0` for every natural `n`, in particular for every recurrence
step `n>=2`.

By `(Rec-all)` and the exact initial table, recurrence uniqueness gives

```text
aPF_n = project b_n,
b2PF_n = project tilde_b_n,
b3PF_n = project double_tilde_b_n,
mPF_n = project m_n                                  (bridge)
```

for every `n`.

Combining `(PF-error)`, `(bridge)`, and the already formalized Abel--Barnes
identity yields the desired pointwise equality:

```text
zudilinBarnesErrorIntegral n
 = Lambda(R_n)
 = aPF_n*(zeta(2)+zeta(3)) - mPF_n
 = b_n*(zeta(2)+zeta(3)) - m_n
 = zudilinCombinedError n.                            (final)
```

This proves the exact direction requested in the question; symmetry gives the
stated equality in either rewrite direction.

```lean
def bernoulliEval (P : Polynomial Q) : Q :=
  P.sum fun d q => q * bernoulli' d

  (-1 : Q)^(n+j) * n.choose j * (n+j).choose j ^ 3

-- P_n is the quotient certified by (PF-poly).

  sum j in range (n+1), poleCoeff n j * harmonicPow 2 j
    - bernoulliEval (P n)
```

The last schematic line should of course mean
`bernoulliEval ((P n).derivative) / 2`.

variable `x`; after expanding `Qhat`, its proof is simply:

# 9. Normalization mismatch audit

The certificate above has no mathematical mismatch under the convention in
the question.  Four implementation traps remain worth checking explicitly:

1. **Error sign.**  The formula is for
   `b_n*(zeta2+zeta3)-m_n`.  If the local definition is
   `m_n-b_n*(zeta2+zeta3)`, the Barnes integral is its negative.
2. **Barnes orientation.**  The equality assumes the upward vertical line and
   the `1/(2*pi*i)` prefactor used in Q6044.  Reversing the line flips the sign.
3. **Bernoulli convention.**  Use Mathlib's `bernoulli'` with
   `bernoulli' 1=+1/2`; using `bernoulli 1=-1/2` breaks the `n=1` check.
4. **Polynomial part.**  The residue sum alone is insufficient.  The terms
   `-EB(P_n)` and `+(1/2)EB(P_n')` are mandatory.

A shift to `F_n(s)=R_n(s+n+1)` causes neither an index shift nor a sign change:
`sin^2(pi*(s+n+1))=sin^2(pi*s)`, and the substitution is translation only.
