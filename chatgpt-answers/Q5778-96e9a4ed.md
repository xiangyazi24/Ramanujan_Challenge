## (i) Does endpoint-only flattening control suffice?

Yes. The proof does not need a flattening continuously chosen along the entire character arc.

The quantity being reconstructed is

```
Re( Rhat(alpha) - Rhat(beta) )
```

so only the two endpoint flattenings enter. A path lift would matter if one were integrating a multivalued logarithm along the arc and claiming equality from analytic continuation alone. But after Step 3 has already identified the endpoint Rogers values, the ambiguity is an endpoint ambiguity.

A referee may nevertheless demand one sentence clarifying this:

> The arc is used only to identify the two endpoint representations and the sign convention for the integral; the extended Bloch representatives are evaluated independently at the endpoints. Therefore no continuous flattening lift along the interior arc is required.

The commit's self-audit reaches the same point: the lemma controls endpoints, and this is enough because Delta R contains only endpoint terms. fileciteturn0file0L1-L20

## (ii) Torsion step: is it now airtight?

Almost, but this remains the most mathematical place to tighten wording.

The correct chain is not literally:

```
all complex regulators vanish => extended Bloch element torsion
```

because the extended Bloch group has extra flattening information.

The safe formulation is:

1. Map the extended Bloch element

```
Bhat(F) -> B(F)
```

(or equivalently to the Bloch group after forgetting flattenings).

2. The Borel regulator on the Bloch group has kernel equal to torsion after tensoring with Q. This is the Suslin/Borel theorem: the Bloch regulator detects the rank of the Bloch group, and vanishing of all archimedean regulators implies the class is torsion in the Bloch group.

3. The kernel of the projection from the extended Bloch group to the ordinary Bloch group is controlled by roots of unity / Q/Z-type terms. This is exactly the additional torsion part of the extended group.

Therefore the conclusion should be stated as:

> The image of the extended class in B(F) is torsion, and the remaining flattening component is torsion. Hence the extended class is torsion.

Do not cite only "Borel regulator kernel = torsion" for Bhat(C); that statement is too compressed.

## (iii) Factor/sign calibration

This remains the convention-sensitive point.

The cleanest calibration is not an abstract theorem but one explicit known representation:

- take the discrete faithful complete structure of the cusp;
- compute the signed sum of tetrahedron Bloch-Wigner terms;
- compare with SnapPy's hyperbolic volume.

This fixes simultaneously:

* the tetrahedron orientation signs;
* the sign in the Rogers regulator;
* the conversion between regulator and Cheeger--Chern--Simons/GV normalization.

For the proof, state one calibration equation, for example:

```
4 Re(Rhat(class)) = GV(rho)
```

in your chosen normalization, verified on the complete hyperbolic structure. Then all later signs inherit that convention.
