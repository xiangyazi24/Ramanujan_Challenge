# Faithful plain-text recovery of Q6556, Sections 7-8

This is a transcription/recovery of the definitions and normalizations used in Q6556. It is not a new experiment design.

Conventions used below:

```text
F_p = the field with p elements.
psi_p(x) = exp(2*pi*i*x/p) = e_p(x).
All additions in subscripts such as r+h are cyclic in F_p.
```

Q6556 wrote `psi_p`; this is the same additive character as the `e_p` notation in the present question.

## 1. Section 7: central-binomial negative control

### 1.1 Sequence, zero plateau, scalar lift, and kernel

For an odd prime p and 0 <= r < p:

```text
a_p(r) = binom(2*r, r) mod p.
```

The exact zero plateau used in Q6556 was:

```text
a_p(r) = 0
if and only if
(p+1)/2 <= r <= p-1.

L = (p-1)/2
```

Thus the plateau interval has length L.

An equivalent recurrence used by the minimal implementation was:

```text
a_p(0) = 1,

a_p(r+1)
  = a_p(r) * 2 * (2*r+1) * (r+1)^(-1) mod p,

for r = 0,1,...,p-2.
```

The scalar projective lift and collision kernel were exactly:

```text
pi_bin(r) = [a_p(r) : 1],

D_bin,p(r,s)
  = det( (a_p(r),1), (a_p(s),1) )
  = a_p(r) - a_p(s).
```

The sign is therefore `a_p(r)-a_p(s)`, not the reverse.

### 1.2 Cyclic transform and exact factorization

Q6556 defined:

```text
F_bin,p(t,xi)
  = sum_{r,h in F_p}
      psi_p( t*(a_p(r)-a_p(r+h)) + xi*h ).
```

With `s=r+h`, the exact factorization is:

```text
F_bin,p(t,xi)
  = [ sum_{r in F_p} psi_p( t*a_p(r) - xi*r ) ]
    [ sum_{s in F_p} psi_p( -t*a_p(s) + xi*s ) ]

  = abs( sum_{r in F_p} psi_p( t*a_p(r) - xi*r ) )^2.
```

Consequences needed for implementation:

```text
F_bin,p(t,xi) is real and nonnegative.

The Fourier sign inside the one-dimensional factor is -xi*r.
The original two-dimensional phase has +xi*h.
```

### 1.3 Precise normalized raw control statistics

At `xi=0`, Q6556 used:

```text
sum_{t in F_p} F_bin,p(t,0)
  = p * #{(r,s) in F_p^2 : a_p(r)=a_p(s)}
  >= p*L^2.

F_bin,p(0,0) = p^2.
```

Hence:

```text
max_{t != 0} F_bin,p(t,0)
  >= (p*L^2 - p^2)/(p-1)
  = p*(p^2-6*p+1)/(4*(p-1)).
```

Under the raw normalization used throughout Q6556, this becomes:

```text
max_{t != 0} F_bin,p(t,0)/p
  >= (p^2-6*p+1)/(4*(p-1))
  ~ p/4.
```

For every `xi`, grouping by the common value gives the exact zero-push identity:

```text
sum_{t in F_p} F_bin,p(t,xi)
  = p * sum_{v in F_p}
        abs( sum_{r : a_p(r)=v} psi_p(-xi*r) )^2.
```

The zero plateau contributes:

```text
p * abs( sum_{r=(p+1)/2}^{p-1} psi_p(-xi*r) )^2.
```

At `xi=1`:

```text
abs( sum_{r=(p+1)/2}^{p-1} psi_p(-r) )
  = cos(pi/(2*p)) / sin(pi/p)
  ~ p/pi,

F_bin,p(0,1) = 0.
```

Therefore the named negative-control statistic was:

```text
R_bin(p)
  = max_{t != 0} F_bin,p(t,1)/p,

R_bin(p) >> p.
```

Equivalently, its predicted power exponent is `eta=1`. The displayed Q6556 conclusion was the `>> p` statement. The preceding displayed identities also give the exact lower bound:

```text
R_bin(p)
  >= [cos(pi/(2*p))/sin(pi/p)]^2 / (p-1)
  ~ p/pi^2.
```

This last line is a direct algebraic consequence of Q6556's displayed formulas, not a separately named statistic in Q6556.

### 1.4 Precise uncentered zero-push control

For the binomial control, define the raw collision count:

```text
C_bin,p(h)
  = #{ r in F_p : a_p(r)=a_p(r+h) }.
```

Then:

```text
C_hat_bin,p(xi)
  = sum_{h in F_p} C_bin,p(h)*psi_p(xi*h)
  = (1/p) * sum_{t in F_p} F_bin,p(t,xi).
```

The uncentered normalized zero-push L2 statistic matching Q6556's normalization is:

```text
B_bin,p^unc
  = (1/p^4) * sum_{xi in F_p}
      abs( sum_{t in F_p} F_bin,p(t,xi) )^2

  = (1/p) * sum_{h in F_p} C_bin,p(h)^2.
```

Q6556 stated that the zero-collision function contains the cyclic autocorrelation of the plateau interval, whose uncentered second moment is of order `p^3`, not `p`. Consequently:

```text
sum_h C_bin,p(h)^2 = Theta(p^3),

B_bin,p^unc = Theta(p^2).
```

For direct verification, if `A_I(h)` is the cyclic autocorrelation of an interval of length `L=(p-1)/2`, then:

```text
sum_{h in F_p} A_I(h)^2
  = L^2 + 2*sum_{j=1}^{L-1} j^2
  = (2*L^3 + L)/3.
```

Since `C_bin,p(h) >= A_I(h)`, one obtains the exact lower bound:

```text
B_bin,p^unc
  >= (2*L^3 + L)/(3*p)
  ~ p^2/12.
```

Q6556 did not specify a `circ` subtraction for the central-binomial control. Its Section 7 zero-push statement was explicitly about the uncentered second moment.

## 2. Section 8: cyclic Apéry transform

### 2.1 Cyclic determinant table

The Apéry table was:

```text
D_p(r,s) = b_r*c_s - b_s*c_r,

r,s in F_p.
```

The cyclic gap coordinate is:

```text
h = s-r mod p,

s = r+h mod p.
```

Equivalently:

```text
d_p(r,h) = D_p(r,r+h).
```

### 2.2 Raw two-dimensional transform, signs, and normalization

The raw transform was exactly:

```text
F_p(t,xi)
  = sum_{r,h in F_p}
      psi_p( t*D_p(r,r+h) + xi*h ).
```

Thus:

```text
phase sign in the value coordinate:  + t*D_p(r,r+h)
phase sign in the gap coordinate:    + xi*h
raw spectral normalization:          abs(F_p(t,xi))/p
```

The full cyclic sum is over all `r,h in F_p`. No nonwrapping triangular mask is part of this definition.

### 2.3 Deterministic modes and the meaning of `circ`

Q6556 listed the following pieces to be recorded separately and removed before interpreting the bulk spectrum:

```text
1. Diagonal mode h=0:
   D_p(r,r)=0 for every r.
   Its contribution to every raw F_p(t,xi) is p.

2. Constant-phase origin:
   F_p(0,0)=p^2.
   This is a fixed top-weight degeneracy.

3. Reflection mode:
   s=-1-r.
   Under h=s-r, this gives a fixed rank-one mode,
   concentrated at xi=0 after Fourier transform.

4. Singular/restart indices coming from the recurrence normalization.

5. Any other explicitly known deterministic modes.
```

Q6556 then defined only semantically:

```text
F_p^circ(t,xi)
  = F_p(t,xi) after subtracting the known diagonal,
    reflection, restart/singular, and other explicitly known modes.
```

Important fidelity point:

```text
Q6556 did NOT give a single explicit numerical formula for F_p^circ.
It did NOT specify overlap/inclusion-exclusion coefficients among those modes.
It described the subtraction initially in the Grothendieck-group/sheaf sense.
```

Therefore no additional center should be invented in code without a separately fixed convention.

### 2.4 Bulk parameter set and raw summary statistics

Q6556 described `Omega_p` as the good parameter set after deleting:

```text
- t=0;
- known diagonal/reflection degeneracies;
- reductions modulo p of a fixed finite collection of exceptional divisors.
```

The primary raw statistic was:

```text
A_p
  = max_{t != 0 and (t,xi) in Omega_p}
      abs(F_p^circ(t,xi))/p.
```

On the same bulk set, Q6556 required reporting:

```text
- median of abs(F_p^circ(t,xi))/p;
- 99th percentile of abs(F_p^circ(t,xi))/p;
- number of points for which abs(F_p^circ(t,xi))/p
  exceeds each fixed threshold.
```

The count was stated as a number of points; Q6556 did not prescribe division by `#Omega_p`.

The formula explicitly excludes `t=0`. It does not globally impose `xi != 0`. The line `xi=0` was instead listed as a candidate fixed exceptional locus to inspect and, if justified, include in the fixed exceptional set.

## 3. Zero fiber, zero-push, B_p, and B_p^max

### 3.1 Raw zero-fiber count and Fourier transform

For every `h in F_p`:

```text
C_p(h)
  = #{ r in F_p : D_p(r,r+h)=0 }.
```

With the same `+xi*h` Fourier convention:

```text
C_hat_p(xi)
  = sum_{h in F_p} C_p(h)*psi_p(xi*h).
```

Additive orthogonality gives the exact identity:

```text
C_hat_p(xi)
  = (1/p) * sum_{t in F_p} F_p(t,xi).
```

All sums here are over the full field:

```text
h in F_p,
t in F_p,
xi in F_p.
```

### 3.2 Centered/circ zero-push notation actually used in Q6556

Q6556 used:

```text
T_p(xi)
  = sum_{t in F_p} F_p^circ(t,xi).
```

This `T_p` is the notation Q6556 used for the zero-push numerator; it did not call it `Z_p`.

The corresponding centered collision transform is implicitly:

```text
C_hat_p^circ(xi)
  = (1/p) * T_p(xi).
```

The exact Parseval identity recorded in Q6556 was:

```text
sum_{h in F_p} abs(C_p^circ(h))^2
  = (1/p^3) * sum_{xi in F_p} abs(T_p(xi))^2.
```

Important fidelity point:

```text
Q6556 did NOT define C_p^circ(h) by a numerical formula such as
C_p(h)-1, C_p(h)-mean(C_p), or C_p(h)-p*delta_{h,0}.

Its `circ` notation means the collision function induced after removing
exactly the same known deterministic modes listed for F_p^circ.
No additional mean or constant center was specified.
```

### 3.3 Primary zero-push statistic

The primary GPRV diagnostic, formula (0.1) and Section 8.2, was:

```text
B_p
  = (1/p^4) * sum_{xi in F_p}
      abs( sum_{t in F_p} F_p^circ(t,xi) )^2

  = (1/p^4) * sum_{xi in F_p} abs(T_p(xi))^2.
```

By the preceding Parseval identity:

```text
B_p
  = (1/p) * sum_{h in F_p} abs(C_p^circ(h))^2.
```

Therefore:

```text
B_p = O(1)
```

is exactly equivalent to the cyclic L2 prediction:

```text
sum_h abs(C_p^circ(h))^2 = O(p).
```

### 3.4 Stronger pointwise zero-push statistic

Q6556 also defined:

```text
B_p^max
  = max_{xi in F_p}
      abs( sum_{t in F_p} F_p^circ(t,xi) ) / p^(3/2)

  = max_{xi in F_p} abs(T_p(xi)) / p^(3/2).
```

The intended interpretations were exactly:

```text
B_p = O(1)      is the exact L2 prediction.
B_p^max = O(1)  is stronger.
```

Unlike the raw `A_p` statistic, the inner zero-push sum includes every `t in F_p`; there is no `t != 0` restriction in `B_p` or `B_p^max`. The deterministic `t=0` contribution is handled through the `circ` subtraction, not by changing the summation domain.

## 4. Exceptional-locus coordinate convention

The value-gap map uses coordinates:

```text
u = D_p(r,r+h),
h = gap coordinate.
```

The Fourier-dual coordinates are ordered as:

```text
(t,xi) dual to (u,h),

phase = t*u + xi*h.
```

Thus `t` is the value-frequency and `xi` is the gap-frequency.

Q6556 suggested recording the largest values and testing the fixed line family:

```text
t = 0
xi = 0
xi = a*t + b
```

Here `a,b` are coefficients independent of p, reduced modulo p. Q6556 did not specify numerical values of `a` or `b`.

Growth confined to finitely many such fixed curves was to be treated as a possible fixed geometric summand; diffuse growth away from every fixed-degree exceptional locus was the stronger death signal.

## 5. Threshold values

Q6556 required threshold counts for the normalized raw values:

```text
abs(F_p^circ(t,xi))/p.
```

However:

```text
No numerical threshold values were specified in Q6556.
```

Therefore an implementation claiming fidelity to Q6556 must treat the threshold list as an external input and must not silently hard-code values such as 2, 4, 8, or any other choices.
