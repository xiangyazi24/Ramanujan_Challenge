# R2C hostile audit of Problem 3.1 (commit 845548a)

Audited `SUBMIT/3.1/solution.tex` and the claimed Lean/script support. Verdict: the computational algebra is largely coherent, but the proof has two fatal geometric gaps.

## Fatal findings

## F1. Neumann filling correction is not justified for the nondiscrete alpha representation

Location: the filling lemma and the remarks following it.

The submission itself correctly changed the earlier quadratic argument: the Neumann correction is linear in the core length, not quadratic. However the remaining proof still applies the Dehn-filling correction to `rho_alpha`, whose image is nondiscrete.

Neumann's theorem applies to decorated nondegenerate gluing data. For the alpha endpoint one must add one of:

1. an analytic continuation of the decorated solution from the complete structure to the alpha point, proving no shape crosses `0,1,infinity`, logarithm branches remain compatible, and flattenings survive the limit; or
2. an independent Ptolemy/bar-cycle construction producing the same extended Bloch class for the nondiscrete representation.

Numerical verification of a real A-polynomial arc is not a proof of either.

Smallest repair: insert a theorem giving the decorated continuation or an explicit filled extended Bloch cycle.

## F2. Relative exterior class versus closed filled class is not constructed

Location: the transition from the four tetrahedron shapes to the closed manifold torsion statement.

The four shapes naturally define a relative ideal-triangulation class. The closed manifold requires the solid-torus/filling contribution. The identity

```
[closed class] = [four shapes] + [filling term]
```

must be proved in the extended Bloch group, not only numerically.

Smallest repair: provide the actual filling flattening/core-chain construction and verify the extended Bloch relation.
