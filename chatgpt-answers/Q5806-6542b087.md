# Pure-cross Apéry pairs: exact twin-modulus dispersion and the missing BDH estimate

## Executive verdict

**No unconditional Apéry-specific factor `L(N) -> infinity` over the summed ambient prime-pair sieve is presently supplied by the available large-sieve, Bombieri--Vinogradov, trace-function, Kloosterman-dispersion, or resultant technology.** The obstruction is not merely that nobody has optimized a constant. After the exact Apéry zero indicators are expanded, the relevant off-diagonal term has all of the following features simultaneously:

1. two different characteristics `p` and `ell = p+h`;
2. a CRT Fourier modulus `p*ell` of size `N^2`, while the column variable has length only `N`;
3. a zero-indicator kernel whose available polynomial/sheaf realization has complexity comparable to the characteristic;
4. a family that changes with the characteristic;
5. exact vanishing of a Mellin coefficient, which is a nonlinear second-Fourier-layer condition, rather than evaluation of one fixed bounded-conductor trace function.

There is, however, a clean exact reduction. Define the Fourier transform of the Apéry zero indicator in each characteristic. The short-gap target count equals a negligible zero-frequency main term plus one explicit four-variable twin-modulus exponential sum. A single named estimate for the mean square of this off-zero sum closes PC.20 and PC.21 without replacing the pointwise claim by a density-one statement.

I call the needed estimate the **Apéry twin-modulus Barban--Davenport--Halberstam estimate**, abbreviated `AT-BDH`. Its exact statement is in Section 5. The reduction to it is unconditional and complete.

The logical status is:

- **proved below:** all reparametrizations, Fourier identities, main-term bounds, and the implication `AT-BDH => PC.20/PC.21 => pointwise P3.2`;
- **proved below:** precise theorem-hypothesis mismatches for the standard large sieve, Bombieri--Vinogradov, current trace-function bilinear bounds, the Laurent constant-term expansion, and resultants;
- **open:** `AT-BDH`, or any comparably strong vertical-in-characteristic cancellation theorem for the same explicit sum.

## 1. Exact zero-indicator notation

Write the Apéry numbers as

```text
b_m = sum_{k=0}^m binom(m,k)^2 binom(m+k,k)^2.
```

For a prime `p`, let

```text
Z_p = { r in {0,...,p-1} : b_r = 0 mod p },
z_p = |Z_p|,
rho_p(x) = 1_{x mod p in Z_p}.
```

Thus `rho_p` is a `{0,1}`-valued function on `F_p`, periodically extended to the integers. In the top half, for `p > 5`, Gessel--Lucas gives

```text
p in T_n  <=>  rho_p(n) = 1.
```

Indeed, if `n = p+r`, then `b_n = 5 b_r mod p`.

For a fixed quotient `q >= 1`, put

```text
J_q(n) = ( n/(q+1), n/q ],
T_{n,q} = { p in J_q(n) : rho_p(n)=1 }.
```

If `p in J_q(n)`, then `r=n-qp` lies in `[0,p)`, and `r` is the residue of `n` modulo `p`. Hence this definition is exactly the lower-digit channel used in PC.17:

```text
rho_p(n)=1  <=>  p | b_{n-qp}.
```

No approximation or Lucas reduction is used here; it is simply the residue identity `n-qp = n mod p` in the correct range.

## 2. Exact interchange of `n`, `p`, `h`, and `s`

### 2.1 The full dyadic falling second moment

For the top half,

```text
H_2(N) = sum_{N<n<=2N} K_n(K_n-1).
```

Order a target pair as `p < ell`, write

```text
ell = p+h,
s = n-ell.
```

Then

```text
n mod ell = s,
n mod p   = s+h.
```

The candidate inequalities `p,ell in (n/2,n]` become

```text
0 <= s,
s+h < p < ell.
```

Consequently the exact pair conditions are

```text
rho_ell(s)=1,
rho_p(s+h)=1,
```

which are precisely PC.1:

```text
ell | b_s,
p   | b_{s+h}.
```

For fixed `p,h`, define the exact dyadic `s`-interval

```text
I_{p,h}(N)
 = { s in Z :
       max(0, N-(p+h)+1) <= s
       <= min(p-h-1, 2N-(p+h)) }.
```

Then there is an exact identity

```text
H_2(N)
 = 2 sum_{h>=1}
       sum_{p, p+h prime}
       sum_{s in I_{p,h}(N)}
         rho_{p+h}(s) rho_p(s+h).                 (2.1)
```

The factor `2` changes unordered pairs to the ordered falling moment. Odd `h` contribute nothing once both primes are odd.

This is the requested exact interchange of `p,h,s`. It already displays the difficulty: the two factors are functions over two different finite fields whose characteristics are themselves summation variables.

### 2.2 The fixed-column short-gap count

For `H>=1`, define the all-pair short-gap count

```text
P_{q,H}(n)
 = sum_{1<=h<=H}
     sum_{
       ell=p+h,
       p and ell prime,
       p,ell in J_q(n)
     }
       rho_p(n) rho_ell(n).                       (2.2)
```

This counts all target pairs of gap at most `H` in the `q`-arc. It is deliberately stronger than PC.20/PC.21:

- it does not require adjacency;
- it does not delete degenerate pairs;
- it does not impose the nearly-primitive Kummer-order restriction.

Therefore

```text
A_{q,H}^{np,x}(n;F) <= A_{q,H}^x(n) <= P_{q,H}(n).  (2.3)
```

An upper bound for `P_{q,H}` automatically controls the quantities in PC.20 and PC.21.

### 2.3 Why an ordinary dyadic first moment is not calibrated to the pointwise problem

Section 30 already proves bounds such as

```text
H_{2,<=H}(N) << H N^(5/3) / log^2 N.
```

At `H=A log N`, this is

```text
H_{2,<=A log N}(N) << N^(5/3)/log N,
```

which is much smaller than `N^2/log^2 N`. Nevertheless it does **not** rule out a forbidden pointwise column. One column with

```text
K_n >= epsilon N/log N
```

forces only about `N/log N` adjacent short pairs, not `N^2/log^2 N` short pairs. The existing dyadic allowance `N^(5/3)/log N` can contain many such exceptional columns.

This is exactly why one may not replace PC.20/PC.21 by a density-one estimate. The missing estimate must be calibrated so that **one** forbidden column already violates it. The mean-square estimate in Section 5 has that calibration.

## 3. The exact additive Fourier expansion

For `a in F_p`, define

```text
rhohat_p(a) = sum_{r mod p} rho_p(r) e_p(a r),
e_p(x) = exp(2 pi i x/p).
```

Fourier inversion and Parseval give

```text
rho_p(n)
 = (1/p) sum_{a mod p} rhohat_p(a) e_p(-a n),     (3.1)

rhohat_p(0)=z_p,

sum_{a mod p} |rhohat_p(a)|^2 = p z_p.            (3.2)
```

### 3.1 Fourier form after the `s`-interchange

Let

```text
V_I(theta) = sum_{s in I} exp(-2 pi i s theta).
```

Applying (3.1) to the inner sum in (2.1) gives the exact formula

```text
sum_{s in I_{p,h}(N)} rho_{p+h}(s) rho_p(s+h)
 = 1/[p(p+h)]
   sum_{a mod p+h}
   sum_{b mod p}
     rhohat_{p+h}(a) rhohat_p(b)
     e_p(-b h)
     V_{I_{p,h}(N)}( a/(p+h) + b/p ).             (3.3)
```

The zero-frequency term is

```text
|I_{p,h}(N)| z_p z_{p+h}/[p(p+h)].                (3.4)
```

Everything genuinely horizontal is in the terms `(a,b)!=(0,0)`.

### 3.2 Fourier form at one fixed column

For fixed `q,H,n`, set

```text
M_{q,H}(n)
 = sum_{1<=h<=H}
     sum_{
       ell=p+h,
       p and ell prime,
       p,ell in J_q(n)
     }
       z_p z_ell/(p ell),                          (3.5)
```

and

```text
D_{q,H}(n)
 = sum_{1<=h<=H}
     sum_{
       ell=p+h,
       p and ell prime,
       p,ell in J_q(n)
     }
       1/(p ell)
       sum_{
         a mod p, b mod ell,
         (a,b)!=(0,0)
       }
         rhohat_p(a) rhohat_ell(b)
         exp[-2 pi i n(a/p+b/ell)].                (3.6)
```

Then

```text
P_{q,H}(n) = M_{q,H}(n) + D_{q,H}(n).              (3.7)
```

This identity is exact.

A useful point is that the phase is independent of the outer quotient `q`. If one starts with the actual lower indices `n-qp` and `n-qell`, then

```text
exp[-2 pi i a(n-qp)/p] = exp[-2 pi i a n/p],
exp[-2 pi i b(n-qell)/ell] = exp[-2 pi i b n/ell],
```

because the omitted factors are integral. Thus the same twin-modulus Fourier phase governs every fixed quotient arc. The quotient changes only:

- the prime interval `J_q(n)`;
- the index gap, which is `q h` in PC.18;
- the degeneracy and Kummer-order restrictions.

### 3.3 The zero-frequency main term is already negligible

Use only the proved vertical estimate

```text
z_p << p^(2/3).
```

This is used here solely to bound the deterministic Fourier zero mode, **not** as horizontal decorrelation.

For fixed `q`, primes in `J_q(n)` have size comparable to `N`. Hence

```text
z_p z_ell/(p ell) <<_q N^(-2/3).                  (3.8)
```

The dimension-two Selberg upper-bound sieve and the mean singular-series estimate give, for `H=A log N`,

```text
# { (p,ell): ell-p<=H, p,ell prime, p,ell in J_q(n) }
 <<_{q,A} N/log N.                                 (3.9)
```

Therefore

```text
M_{q,A log N}(n) <<_{q,A} N^(1/3)/log N
                         = o(N/log N),              (3.10)
```

uniformly for `N<n<=2N`.

Thus a forbidden short-gap spike must appear in the off-zero Fourier term `D`, not in the local-density main term.

## 4. The exact second-Fourier-layer exponential sums

The Fourier coefficients in (3.6) can themselves be expanded without approximation. Define

```text
S_p(a,u)
 = sum_{r mod p} e_p( a r + u b_r ),
 a,u in F_p.                                       (4.1)
```

Since

```text
1_{b_r=0 mod p} = (1/p) sum_{u mod p} e_p(u b_r),
```

we have

```text
rhohat_p(a) = (1/p) sum_{u mod p} S_p(a,u).         (4.2)
```

Substituting (4.2) into (3.6) gives the completely explicit exponential form

```text
D_{q,H}(n)
 = sum_{1<=h<=H}
     sum_{
       ell=p+h,
       p and ell prime,
       p,ell in J_q(n)
     }
       1/(p^2 ell^2)
       sum_{
         a mod p, b mod ell,
         (a,b)!=(0,0)
       }
       sum_{u mod p}
       sum_{v mod ell}
         S_p(a,u) S_ell(b,v)
         exp[-2 pi i n(a/p+b/ell)].                (4.3)
```

Equation (4.3) is the genuine bilinear/dispersion object. It is vertical in the characteristics `p,ell`, horizontal in the short prime gap `h`, and Fourier-analytic in the common column `n`.

It is important not to weaken (4.3) to an individual estimate for one `S_p(a,u)`. The complete `u`-sum is exactly what detects `b_r=0`; summing it loses any cancellation that holds only for generic `u`. Moreover, the theorem needed is cancellation **after coupling neighboring characteristics and summing the whole logarithmic gap range**.

## 5. The one named estimate that closes PC.20 and PC.21

### Definition: `AT-BDH(q,A)`

Fix integers `q>=1` and a real `A>0`. Put

```text
H = floor(A log N).
```

The **Apéry twin-modulus Barban--Davenport--Halberstam estimate** is the assertion that there is a function

```text
L_{q,A}(N) -> infinity
```

such that

```text
sum_{N<n<=2N} |D_{q,H}(n)|^2
 <<_{q,A} N^2 / [ L_{q,A}(N) log^2 N ].             (AT-BDH)
```

Here `D_{q,H}(n)` is exactly (3.6), equivalently (4.3), with the exact moving interval `J_q(n)`. A smooth version with upper and lower cutoff functions is equivalent for the application: for fixed `q`, finitely many smooth partitions handle the arc, and boundary strips of width `O(H)` contribute only `O_{q,A}(log^2 N)` possible adjacent edges.

This is a BDH-type statement because it is a mean square, over the column variable, of the deviation from the product of the two local zero densities. It is a **twin-modulus** statement because the two Fourier groups have moduli `p` and `p+h`.

### Theorem 5.1: `AT-BDH(q,A)` implies PC.20

Assume `AT-BDH(q,A)` for every fixed `q,A`. Then PC.20 holds.

#### Proof

Suppose PC.20 fails. Then for some fixed `q`, some `epsilon>0`, and infinitely many `N`, there is `n in (N,2N]` with

```text
A_{q,A log N}^x(n) >= epsilon N/log N
```

for a suitable fixed `A` chosen in the PC.20 adjacency argument. Since every adjacent pair counted there is also counted by `P_{q,H}(n)`,

```text
P_{q,H}(n) >= epsilon N/log N.                     (5.1)
```

By (3.10),

```text
M_{q,H}(n) = o(N/log N).                           (5.2)
```

Hence, for all sufficiently large `N`,

```text
|D_{q,H}(n)| >= (epsilon/2) N/log N.               (5.3)
```

The single summand indexed by this `n` then gives

```text
sum_{N<m<=2N} |D_{q,H}(m)|^2
 >= (epsilon^2/4) N^2/log^2 N,                     (5.4)
```

contradicting `AT-BDH`, because `L_{q,A}(N)->infinity`. Therefore PC.20 holds. QED.

This is not a density-one inference: one forbidden column by itself contradicts the mean-square bound.

### Theorem 5.2: `AT-BDH(q,A)` implies PC.21

PC.21 counts adjacent pure-cross pairs after the nearly-primitive Kummer-order pruning. Those pairs form a subset of the pairs counted in `P_{q,H}`. If PC.21 failed, the identical argument (5.1)--(5.4) would apply. Thus `AT-BDH` implies PC.21 as well. QED.

### Theorem 5.3: `AT-BDH` for every fixed `q` closes the pointwise middle-prime problem

Here is the full localization, included to keep the quantifiers explicit.

Assume the desired logarithmic-weight estimate fails. Then there are `epsilon>0` and arbitrarily large `n` for which the unresolved lower-digit primes have total weight at least `epsilon n`.

1. Choose a fixed small `eta>0`. All primes `p<=eta n` have total Chebyshev weight `O(eta n)`, independently of targetness. Choose `eta` so this is at most `epsilon n/4`.
2. Every remaining prime has quotient `q=floor(n/p) <= 1/eta`. There are only finitely many such `q`.
3. One fixed quotient arc therefore carries target logarithmic weight `>=c_{epsilon,eta} n` along an infinite subsequence.
4. Since all primes in that arc are comparable to `n`, the arc contains `>=c n/log n` targets.
5. The pointwise Kummer-order pruning KO.6 removes only `o(n)` logarithmic weight, hence only `o(n/log n)` vertices. The nearly-primitive residual still has `>=c' n/log n` vertices.
6. The arc has length `n/[q(q+1)]`. Ordering the residual primes, at most `n/[q(q+1)A log n]` adjacent gaps exceed `A log n`. Choose fixed `A` large enough that a positive proportion of the `c'n/log n` adjacent gaps are at most `A log n`.
7. PC.19 bounds all degenerate pairs in that gap range by

```text
sum_{h<=A log n} O_q(h) = O_{q,A}(log^2 n),
```

which is negligible compared with `n/log n`.
8. Therefore a forbidden pointwise spike forces `>=c'' n/log n` nearly-primitive adjacent pure-cross pairs of gap at most `A log n`, contradicting PC.21, and hence contradicting `AT-BDH` by Theorem 5.2.

Thus `AT-BDH` is exactly strong enough to close the pointwise theorem. It does not rely on a density-one substitution.

### Stronger but simpler uniform form

The following `L^infinity` statement is stronger than `AT-BDH` and also suffices:

```text
sup_{N<n<=2N} |D_{q,A log N}(n)|
 <<_{q,A} N/[L(N) log N],
L(N)->infinity.                                    (AT-FD-infinity)
```

The mean-square form is the more natural dispersion target because it is calibrated to exclude even one spike while still allowing ordinary fluctuations in the other columns.

## 6. Why the classical additive large sieve does not prove `AT-BDH`

For one edge `e=(p,ell)`, the frequencies in (3.6) are

```text
theta_{e,a,b} = a/p + b/ell
              = (a ell + b p)/(p ell) mod 1.       (6.1)
```

Because `p` and `ell` are distinct primes, the map

```text
(a mod p, b mod ell) -> a ell + b p mod p ell
```

is a CRT bijection. Thus a single edge already supplies the **full** set of additive frequencies modulo

```text
p ell ~ N^2.                                       (6.2)
```

There is no sparse-frequency gain hidden inside one edge.

The exact coefficient square norm for one edge is, by Parseval,

```text
sum_{a mod p, b mod ell}
 |rhohat_p(a) rhohat_ell(b)/(p ell)|^2
 = z_p z_ell/(p ell)
 << N^(-2/3).                                      (6.3)
```

There are `O_A(N/log N)` ambient short prime-pair edges, so the total coefficient square norm is at most

```text
O_A(N^(1/3)/log N).                                (6.4)
```

If the ordinary large sieve is applied to rational frequencies with denominators at most

```text
Q ~ N^2,
```

its factor is

```text
N + Q^2 ~ N^4.                                     (6.5)
```

Combining (6.4) and (6.5) gives a bound of order `N^(13/3)` before logarithms, whereas `AT-BDH` asks for `o(N^2/log^2 N)`. Even a very substantial improvement in the divisor-count bound `z_p<<p^(2/3)` would not bridge the `N^4` large-sieve constant.

Equivalently, distinct CRT frequencies from denominators of size `N^2` can be spaced as closely as `N^(-4)`, while the `n`-interval has length only `N`. Standard Fourier spacing cannot see orthogonality.

Applying separate large sieves in the `p` and `ell` variables does not repair this. The short-gap condition couples the two moduli, and Cauchy--Schwarz reintroduces at least one modulus-square loss. What is needed is arithmetic cancellation in the coefficients `rhohat_p(a)rhohat_ell(b)`, not generic spacing.

## 7. Why Bombieri--Vinogradov and ordinary dispersion do not apply

One can majorize the ambient primality condition by Selberg weights:

```text
1_{p prime} 1_{p+h prime}
 <= ( sum_{d | p(p+h)} lambda_d )^2.                (7.1)
```

After expansion, the new congruence conditions have small sieve moduli `d`, but the remaining sum is of the form

```text
sum_{p in an arithmetic progression mod d}
  rho_p(n) rho_{p+h}(n).                            (7.2)
```

The functions in (7.2) are not fixed sequences in `p` modulo `d`. The modulus of `rho_p` is the characteristic `p` itself, and its coefficient table changes with `p`. Bombieri--Vinogradov controls the distribution of primes in fixed residue classes to moduli up to about the square-root range; it supplies no cancellation for the vertical characteristic-dependent weights in (7.2).

If instead the two zero conditions are detected directly by additive characters, the natural combined modulus is `p(p+h)~N^2`, larger than the summation length and far beyond the Bombieri--Vinogradov range.

The powerful large-modulus dispersion results of Deshouillers--Iwaniec, Fouvry, Bombieri--Friedlander--Iwaniec, and Drappeau exploit special reciprocal phases and ultimately Kloosterman-sum estimates. In the present expansion the phase contains the Apéry values `b_r` or the characteristic-dependent transforms `rhohat_p`; no reciprocity converts it to a fixed-rank Kloosterman kernel. Thus those theorems do not merely miss the desired numerical exponent--their kernel hypotheses are absent.

## 8. Expanding the Apéry binomial sum does not create a bounded-complexity kernel

For `r in F_p`, extend the binomial formula by taking `k=0,...,p-1`; the terms with `k>r` vanish as polynomial binomial coefficients. Then

```text
b_r = sum_{k mod p}
        binom(r,k)^2 binom(r+k,k)^2 mod p.           (8.1)
```

The exact zero detector is

```text
rho_p(r)
 = (1/p) sum_{u mod p}
     e_p( u sum_k binom(r,k)^2 binom(r+k,k)^2 )

 = (1/p) sum_{u mod p}
     product_k
       e_p( u binom(r,k)^2 binom(r+k,k)^2 ).         (8.2)
```

The last expression is a product over `p` summation positions. Interchanging `r,k,u` does not turn it into a fixed-degree bilinear phase; it turns exact vanishing into a product whose number of factors grows with the characteristic.

Equivalently, the function `r -> b_r mod p` has a polynomial representative of degree at most `p-1`, and the exact spectral representative in Section 10 below has degree exactly `p-1` before the quadratic pullback. Standard Weil bounds therefore carry a constant of size comparable to `p`, yielding no nontrivial uniform estimate for the sums `S_p(a,u)` in (4.1).

This is the exact point where a formal interchange stops. The binomial expansion supplies a finite-field exponential sum, but not one of bounded degree or bounded conductor.

## 9. The Laurent constant-term model: exact first layer, unbounded second layer

The repository uses

```text
Lambda(x,y,z)
 = [(1+x)(1+y)(1+z)((1+y)(1+z)+xyz)]/(xyz),

b_r = CT Lambda^r.                                  (9.1)
```

### 9.1 Exact torus moment identity

The exponent of each variable in `Lambda^r` lies between `-r` and `r`. For `0<=r<=p-2`, the only multiple of `p-1` in that range is zero. Multiplicative orthogonality therefore gives

```text
sum_{(x,y,z) in (F_p^*)^3} Lambda(x,y,z)^r
 = - b_r mod p.                                    (9.2)
```

(The sign is `(-1)^3` from the three full multiplicative sums.)

Let

```text
N_p(t) = # { (x,y,z) in (F_p^*)^3 : Lambda(x,y,z)=t }.
```

Then

```text
b_r = - sum_{t in F_p} N_p(t) t^r mod p.            (9.3)
```

Thus `b_r` is a multiplicative Mellin coefficient of a bounded-dimensional geometric family. This is the valid **first Fourier layer**.

### 9.2 Exact zero detection is a second Fourier layer of growing complexity

Applying additive orthogonality to (9.3),

```text
rho_p(r)
 = (1/p) sum_{u mod p}
     e_p( -u sum_t N_p(t)t^r )

 = (1/p) sum_{u mod p}
     product_{t in F_p}
       e_p( -u N_p(t)t^r ).                         (9.4)
```

Again the exact-zero condition produces a product over all field elements. The ordinary K3/Picard--Fuchs monodromy governs the family whose Mellin coefficient is `b_r`; it does not automatically produce a bounded-conductor sheaf for the predicate that this coefficient is exactly zero.

This is not a philosophical objection. Formula (9.4) identifies the missing operation explicitly: one needs cancellation after a complete additive transform of a moving Mellin coefficient. Fixed-order Katz--Deligne correlation theorems do not handle a product with `p` factors.

## 10. The exact Racah spectral polynomial and its conductor growth

For an odd prime `p`, let `m=(p-1)/2` and define

```text
lambda_j = j(j+1),
phi_k(X) = product_{0<=j<k}(X-lambda_j)/(k!)^2,

H_p(X) = sum_{0<=k<=m} phi_k(X)^2 in F_p[X].        (10.1)
```

The repository proves

```text
H_p(r(r+1)) = b_r mod p                             (10.2)
```

on the folded nodes, with reflection extending the identity to all relevant residues.

The degree is exact:

```text
deg H_p = 2m = p-1,                                (10.3)
```

because the top summand `phi_m(X)^2` has nonzero leading coefficient and no other summand has that degree.

Therefore

```text
rho_p(r)
 = (1/p) sum_{u mod p}
     e_p( u H_p(r(r+1)) ).                          (10.4)
```

For `u!=0`, the displayed Artin--Schreier phase has degree `2(p-1)` in `r`. Its Swan conductor at infinity, in this direct representation, is comparable to `p`; in the `X`-variable it is already `p-1`. Hence the available exact sheaf has complexity growing linearly with the characteristic.

This blocks the modern trace-function bilinear theorems at their first quantitative hypothesis:

- Fouvry--Kowalski--Michel, *Algebraic trace functions over the primes* (`arXiv:1211.6043`), treats prime arguments of a trace function modulo one fixed prime modulus, with controlled conductor.
- Kowalski--Michel--Sawin, *Bilinear forms with Kloosterman sums and applications*, Annals of Mathematics 186 (2017), treats fixed Kloosterman/hyper-Kloosterman sheaves.
- Fouvry--Kowalski--Michel--Sawin, *Bilinear forms with trace functions* (`arXiv:2511.09459`, version dated March 22, 2026), greatly generalizes the allowed monodromy groups, but Theorem 1.3 still fixes one prime field and one sheaf; its constants depend on the sheaf complexity.
- Fouvry--Kowalski--Michel, *On the conductor of cohomological transforms* (`arXiv:1310.3603`), preserves boundedness only in terms of the input complexity and the transform complexity. It does not turn a complexity-`p` input into a uniform family.

There are actually two independent mismatches:

1. the exact zero-indicator representation has complexity growing with `p`;
2. `AT-BDH` varies the characteristic from one summand to the next and couples `p` to `p+h`, whereas the trace-function bilinear theorems work inside one fixed `F_q`.

Even a hypothetical alternative bounded-conductor representation of each individual `rho_p` would leave the second, vertical-family problem. No compatible bounded-conductor family across the characteristics has been constructed. Section 32's stabilization identity also rules out the most naive interpretation of `H_p(X)` as the Hasse invariant of one fixed elliptic family in the spectral parameter.

A degree-`z_p` zero-divisor polynomial does not fix the issue. Its degree is only known to be `O(p^(2/3))`, still unbounded, and its coefficients vary with `p`. It gives a sublinear lift in each separate characteristic, not one common horizontal trace family.

## 11. Why current bilinear trace-function bounds do not become applicable after Vaughan or Heath--Brown decomposition

A natural attempt is:

1. replace the two prime indicators by a Vaughan/Heath--Brown identity;
2. obtain Type I/II sums in variables whose product represents `p` or `p+h`;
3. apply a general trace-function bilinear theorem to the Apéry kernel.

The third step has no valid kernel. In the Fouvry--Kowalski--Michel--Sawin framework the kernel has the form

```text
K(m^b n^c) mod one fixed prime q,                   (11.1)
```

where `K` is the trace of one controlled-complexity sheaf over `F_q`. Here the summation variable `p` is itself the characteristic of `rho_p`; there is no fixed field in which the Type I/II variables range. The pair `p,p+h` would require two changing fields at once.

The title *Algebraic trace functions over the primes* can be misleading in this context: it sums a fixed-modulus trace function at prime integer arguments. It does not sum a family whose modulus equals the prime argument.

Thus a Vaughan decomposition changes the primality bookkeeping but leaves the vertical characteristic dependence untouched.

## 12. Resultants and continuants do not control the pure-cross term

For a pure-cross pair

```text
ell | b_s,
p   | b_{s+h},
p does not divide b_s,
ell does not divide b_{s+h},
```

PC.6 proves the same-characteristic gap continuant is a unit modulo both target primes:

```text
p   does not divide N_h(s),
ell does not divide N_h(s).                          (12.1)
```

Therefore the ordinary recurrence resultant is not merely too large; its selective factor is provably nonzero on the hard locus.

The spectral polynomials `H_p` and `H_ell` live over different fields and have different coefficients. The common characteristic-zero number `X=n(n+1)` gives

```text
H_p(X)=0 mod p,
H_ell(X)=0 mod ell,                                 (12.2)
```

but it does not make `H_p` and `H_ell` share a root over either one field. A resultant over `F_p` would require information about `H_ell mod p`, which targetness does not provide, and vice versa.

Choosing centered integer lifts and evaluating them at `X` merely creates two large integers separately divisible by `p` and `ell`. Their degrees and coefficient heights grow with the characteristics. Multiplying or taking a resultant reintroduces at least the full moving height; it is not a compression theorem.

This agrees exactly with the formal pure-cross conservation law in the repository: complete universal determinant contraction leaves coefficient content `p ell`, while primitive selectivity leaves an exponential Apéry slot.

## 13. A direct divisor-detection version of the same obstruction

For fixed `n,h`, put

```text
ell = n-s,
p   = n-s-h.
```

The exact pair indicator can be written as

```text
1_{ell | b_s} 1_{p | b_{s+h}}
 = 1/[ell p]
   sum_{a mod ell}
   sum_{b mod p}
     exp[2 pi i (a b_s/ell + b b_{s+h}/p)].         (13.1)
```

Adding primality gives the explicit vertical-modulus sum

```text
sum_s
  1_{n-s prime}
  1_{n-s-h prime}
  1/[(n-s)(n-s-h)]
  sum_{a mod n-s}
  sum_{b mod n-s-h}
    exp[2 pi i {a b_s/(n-s)+b b_{s+h}/(n-s-h)}].    (13.2)
```

This is the same object as (4.3) after changing variables. It makes the failure of standard dispersion especially transparent:

- both moduli vary linearly with `s`;
- the numerators are the exponentially growing, non-periodic integers `b_s,b_{s+h}`;
- no reciprocity turns the phase into a fixed rational function modulo one modulus;
- expanding `b_s` by either the binomial or constant-term formula creates a product of growing length.

Thus the obstacle survives the most literal divisor-switching setup.

## 14. What partial estimates would and would not suffice

### 14.1 A first-moment estimate over all columns is usually too weak

An estimate such as

```text
sum_{N<n<=2N} P_{q,A log N}(n) = o(N^2/log^2 N)     (14.1)
```

is compatible with isolated columns having `P(n)~N/log N`; one such column contributes only `N/log N` to (14.1). Therefore (14.1) is a density statement, not a pointwise closure.

### 14.2 The calibrated first-moment alternative

A much stronger estimate

```text
sum_{N<n<=2N} P_{q,A log N}(n)
 = o(N/log N)                                      (14.2)
```

would rule out one spike, but it is far stronger than the natural total mass and is not a realistic first target.

### 14.3 The calibrated mean square

`AT-BDH` is calibrated exactly:

```text
one forbidden column
  => |D(n)|^2 >> N^2/log^2 N
  => contradiction to a little-oh mean square.     (14.3)
```

This is why the mean square is the right analytic formulation of PC.20/PC.21.

### 14.4 Individual square-root bounds are not by themselves enough

Even if one could prove

```text
|S_p(a,u)| << C sqrt(p)
```

for every nontrivial pair `(a,u)` with an absolute `C`, substituting this termwise into (4.3) would sum over about `p^2 ell^2` parameter quadruples and lose all cancellation. One must exploit orthogonality/geometry across the complete parameter sums and across the neighboring characteristics. `AT-BDH` packages exactly that required collective cancellation.

## 15. A potentially useful stronger input, stated at the atomic level

The following weighted theorem would imply `AT-BDH` after expanding the square and applying the exact identities above.

### Atomic Apéry twin-characteristic bilinear estimate

For fixed `q,A`, smooth bounded weights `W_n` supported on `(N,2N]`, and `H=A log N`, prove a power or logarithmic saving in the complete correlation

```text
sum_n W_n
  sum_{h1,h2<=H}
  sum_{p1,p1+h1 prime}
  sum_{p2,p2+h2 prime}
  [1/(p1^2 ell1^2 p2^2 ell2^2)]
  sum_{a1,b1,u1,v1}
  sum_{a2,b2,u2,v2}
    S_{p1}(a1,u1) S_{ell1}(b1,v1)
    conjugate(S_{p2}(a2,u2) S_{ell2}(b2,v2))
    exp[-2 pi i n(
      a1/p1+b1/ell1-a2/p2-b2/ell2)]                (15.1)
```

with the two `(a,b)=(0,0)` terms removed and with the exact `q`-arc cutoff. The target bound is

```text
(15.1) <<_{q,A} N^2/[L(N) log^2 N],
L(N)->infinity.                                    (15.2)
```

This is simply `AT-BDH` written before the `u,v` sums are collapsed. It is not another conjecture hidden behind vague language: (15.1) is the exact exponential/bilinear sum whose estimate closes the argument.

A successful proof would need a new vertical trace-family or spectral reciprocity principle that couples the two characteristics. Possible mechanisms would include:

1. a compatible sheaf over an arithmetic base whose fibers realize the centered `rho_p` with uniformly controlled complexity;
2. a reciprocity formula converting the second-Fourier Apéry phases into fixed-rank Kloosterman-type phases;
3. a new large sieve for the characteristic-varying Mellin coefficients with a conductor saving after the short-gap average.

None of these structures is currently present in the repository or in the cited trace-function theorems.

## 16. Relation to the ambient Selberg scale

For one fixed `n`, the ambient number of short prime pairs is

```text
sum_{h<=A log N} S(h) N/log^2 N
 <<_A N/log N.                                     (16.1)
```

PC.16 says that multiplying the exact-gap ambient carriers has total logarithmic height `O_A(N)`. To gain `o(N)`, one needs a factor `L(N)->infinity` in the target-pair count after summing the gaps.

The direct uniform target would be

```text
P_{q,A log N}(n)
 <<_{q,A} N/[L(N) log N]                           (16.2)
```

for every `n`. `AT-BDH` is a weaker analytic route to the same pointwise conclusion: it permits ordinary columns to fluctuate, but one column at the ambient scale would violate the mean square.

Thus the answer to the question in the prompt is:

```text
Can current Apéry technology prove any unconditional L(N)->infinity
saving over the ambient summed prime-pair sieve?

No known theorem presently does so.

What exact estimate would do it?

AT-BDH, equations (3.6), (4.3), and (AT-BDH).
```

## 17. Facts, negative conclusions, and conjecture

### Facts proved in the repository or above

1. Pure-cross pairs satisfy the exact two-characteristic conditions PC.1.
2. Degenerate short pairs are `O_q(h)` at exact gap and `O_{q,A}(log^2 N)` across logarithmic gaps.
3. On pure-cross pairs, the same-characteristic continuant is a unit modulo both primes.
4. The short-gap count has the exact Fourier decomposition `P=M+D`.
5. The zero-frequency main term is `o(N/log N)` uniformly.
6. One forbidden pointwise spike forces `D(n)>>N/log N` for one column.
7. `AT-BDH` therefore excludes every forbidden spike.
8. The direct binomial, Laurent constant-term, and Racah representations all turn exact zero detection into a second Fourier layer whose available complexity grows with the characteristic.
9. The standard large sieve sees full frequency sets modulo `p ell~N^2` and incurs an `N^4` spacing factor.
10. The named current trace-function bilinear theorems fix one characteristic and require controlled complexity; those hypotheses are not met.

### Negative conclusion about current technology

Among the currently available large-sieve, Bombieri--Vinogradov, Kloosterman-dispersion, and bounded-conductor trace-function results checked here, none applies to (4.3) or (15.1). This is a theorem-hypothesis mismatch, not an assertion that no future method can prove the estimate.

### Open conjectural input

`AT-BDH(q,A)` for every fixed `q,A` remains open. It is the clean named bilinear/dispersion estimate isolated by this audit.

## 18. Recommended next attack

The most informative next computation is not another scan of `K_n`. It is to compute the centered Fourier coefficients

```text
rhohat_p(a) - 1_{a=0} z_p
```

for primes in several dyadic ranges and measure the actual off-diagonal quantity `D_{1,H}(n)` and its mean square for `H=A log N`. The key diagnostics are:

1. the ratio

```text
sum_n |D_{1,H}(n)|^2 / (N^2/log^2 N);
```

2. decomposition into mixed modes `(a=0,b!=0)` and genuinely two-sided modes `(a!=0,b!=0)`;
3. diagonal coincidences of CRT frequencies after expanding the square;
4. whether the main contribution comes from equal gaps, shared primes, or four distinct characteristics;
5. the effect of the nearly-primitive Kummer-order restriction.

This would identify whether `AT-BDH` is plausibly accessible through a diagonal/off-diagonal decomposition, and which complete finite-field correlation would need a geometric estimate. It would not be a proof, but unlike another zero-count histogram it measures the exact analytic object in the sufficient theorem.

The Apéry conditions have been reduced to an exact, non-generic twin-modulus Fourier dispersion problem, but they do **not** currently yield an unconditional averaged factor tending to infinity over the summed Selberg scale.
