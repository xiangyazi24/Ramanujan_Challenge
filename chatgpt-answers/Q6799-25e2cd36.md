# Audit: finite-field incidence tools versus the clock-ordered strip

## Verdict

The listed static hypotheses on the point set are insufficient to force any fixed power saving

`mean_{t != 0} |B(t)| <= p^(1-kappa)`

for the clock strip. The obstruction is not a missing optimization in Rudnev/Stevens-Zeeuw/Shkredov estimates: the strip statistic is a time-ordered correlation, while those tools see the unordered geometry of the support.

The countermodel below is a rigorous obstruction to any implication whose input consists only of support geometry, line incidence, and additive energy.

## Exact moment identities

Let

`nu(x) = #{(r,d) in Omega : delta_{r,d}=x}`

and

`B(t)=sum_x nu(x)e_p(tx)`.

Orthogonality gives

```
(1/(p-1)) sum_{t != 0} |B(t)|^2
 = (p sum_x nu(x)^2 - |Omega|^2)/(p-1).
```

The subtraction of the zero frequency is essential: replacing the left side by the full Fourier second moment introduces the main term `|Omega|^2`, which is much larger than the desired cancellation scale.

The fourth moment is

```
sum_t |B(t)|^4 = p * #{(a,b,c,d) in Omega^4 :
                         delta_a + delta_b = delta_c + delta_d}.
```

For nonzero frequencies,

```
(1/(p-1)) sum_{t != 0} |B(t)|^4
 = (p E_+(nu)-|Omega|^4)/(p-1),
```

where

`E_+(nu)=#{x1+x2=x3+x4 weighted by nu}`.

Again the `-|Omega|^4` term is not optional. The fourth moment is useful only after separating the zero-frequency contribution.

## What standard incidence estimates can and cannot use

Assume:

```
|A|=|{v_r}| ~ p,
max multiplicity = O(1),
max line intersection = O(1),
E_+(A)=O(p^2).
```

These are strong static hypotheses. They imply small additive structure of the set of points. They do not control the ordered family

```
(v_r,v_{r+d}),   D/2 < d <= D.
```

The number of strip pairs is

```
|Omega| ~ pD = p^(3/2+o(1)).
```

A target mean bound `p^(1-kappa)` would require substantial cancellation in a sum with this many terms. The second moment route would need approximately

```
sum_x nu(x)^2 = p^(1+o(1))
```

up to the correct normalization, because

```
mean |B(t)| <= sqrt(mean |B(t)|^2).
```

Equivalently one needs determinant-energy savings for the clock strip.

Static incidence theorems bound incidences such as

```
#{(a,b,c): determinant(a,b)=c}
```

or point-plane configurations, but they do not bound the restricted additive energy of the determinant values along one prescribed ordering of pairs.

A Rudnev point-plane estimate has the schematic form

```
I(P,Pi) << |P|^(3/2)+|P|+|Pi|
```

under its incidence-size hypotheses. Applying it requires encoding the determinant equation as a point-plane incidence problem. That counts all admissible pairs, not only the clock strip. The restriction `second index = first index + d` is external information not present in the point set.

Stevens-Zeeuw type point-line bounds similarly exploit Cartesian product structure and additive/multiplicative structure of sets of coordinates; they do not recover missing order information.

Shkredov higher additive-energy bounds improve consequences of small additive doubling/energy of a set. They do not prevent a labelling of the same set from creating long-range deterministic correlations.

## Countermodel

Take a primitive element `g` and define

```
v_r=(g^j,g^(-j)),  j=min(r,p-1-r).
```

The support is contained in

```
xy=1.
```

Properties:

1. Multiplicity is O(1), because only the reflection pair `r` and `p-1-r` can share the same `j`.

2. Every affine line meets `xy=1` in at most two points, hence the line condition holds.

3. Additive energy is minimal up to constants. A parabola-type curve with no large additive substructure has

```
E_+(A)=O(|A|^2)=O(p^2).
```

Now split the clock into one half. For indices before the reflection point,

```
v_r=(g^r,g^(-r)),
v_{r+d}=(g^(r+d),g^(-r-d)).
```

Therefore

```
det(v_r,v_{r+d})
 = g^r g^(-r-d)-g^(-r)g^(r+d)
 = g^(-d)-g^d.
```

The determinant depends only on `d`, not on `r`.

Hence for each admissible lag `d`, all approximately `p` points in that strip layer contribute the same phase. Consequently

```
B(t) contains layers of size ~p
```

with no square-root cancellation in the clock direction.

The construction therefore proves:

```
(static support geometry + low additive energy)
      does not imply
(clock-strip determinant Fourier cancellation).
```

## Is this an obstruction to all static implications?

Yes, for implications whose hypotheses are invariant under relabelling of the support.

The same support can be given different labels. The determinant multiset of unordered pairs may be excellent, while one specially chosen clock ordering makes every lag coherent. Therefore any theorem whose assumptions depend only on

```
support,
line intersections,
additive energy,
```

cannot distinguish the good ordering from the bad ordering.

A successful theorem must include genuinely dynamical information, for example:

```
- recurrence/cocycle information for v_r,
- mixing of the clock map r -> r+d,
- bounds on ordered determinant energy,
- a spectral gap for the transition operator.
```

## Exponent budget

Here `D=p^(1/2+o(1))` and

```
|Omega|=pD=p^(3/2+o(1)).
```

A random model predicts

```
nu(x) ~ |Omega|/p = p^(1/2+o(1)).
```

Then

```
sum_x nu(x)^2 ~ p * p = p^2,
```

and the second moment gives

```
mean |B(t)|^2 ~ p^2,
mean |B(t)| ~ p.
```

Therefore the desired estimate

```
mean |B(t)| <= p^(1-kappa)
```

requires an additional saving beyond the random occupancy second moment; it is not a consequence of merely having a generic determinant distribution.

For the fourth moment, a bound strong enough for a power saving would require an ordered additive energy estimate of the shape

```
#{delta1+delta2=delta3+delta4 in Omega^4}
 <= p^(6-epsilon)
```

with the correct normalization after subtracting the zero mode. Static support hypotheses do not provide this.

## Final audit conclusion

The finite-field incidence/additive-energy toolkit can estimate unordered determinant geometry. It cannot, from the stated hypotheses alone, prove any fixed kappa for the clock-ordered strip. The hyperbola countermodel is a rigorous relabelling obstruction: it satisfies all static hypotheses while making each lag deterministic. Any proof of the desired Fourier decay must use the special arithmetic dynamics generating the labelled sequence v_r, not only the geometry of its image.
