# Alternating cubic harmonic Euler sum

Let

```text
H_n = sum_{k=1}^n 1/k,
F   = sum_{n>=1} (-1)^(n-1) H_n/n^3,
L   = log 2,
Z_r = zeta(r),
A_4 = Li_4(1/2),
K   = integral_0^1 log(x)^2 log(1+x)/(1+x) dx.
```

The target is

```text
F = -2 A_4 + (11/4) Z_4 + (1/2) Z_2 L^2
    - (1/12) L^4 - (7/4) Z_3 L.                 (1)
```

Equivalently, using `Z_2=pi^2/6` and `Z_4=pi^4/90`,

```text
F = 11*pi^4/360 - 2*Li_4(1/2)
    + pi^2*L^2/12 - L^4/12 - 7*Z_3*L/4.
```

The shortest route for the current Lean development is:

```text
F  --one harmonic generating kernel-->  7 Z_4/8 - K/2
K  --one explicit real derivative certificate-->  D and E on [0,1/2]
D  --ordinary sum sum H_n/n^3-->          (L^4-Z_4)/4
E  --Li_2,Li_3,Li_4 derivative chain-->   explicit A_4,Z_4,Z_2 L^2,L^4,Z_3 L.
```

It uses no complex continuation, no general measure-theoretic substitution, and no special value beyond the already available lower-weight facts. The only nonlinear change of variable appears inside an explicitly differentiated function.

## 1. Exact harmonic kernel and the relation to `K`

For `N>=1`, put

```text
L_N(x) = sum_{k=1}^N (-1)^(k-1) x^k/k.
```

A finite rearrangement gives, for `x>0`,

```text
sum_{n=1}^N (-1)^(n-1) H_n x^(n-1)
 = [L_N(x) + (-1)^(N+1) H_N x^(N+1)]/[x(1+x)].  (2)
```

Indeed,

```text
sum_{n=1}^N H_n z^n
 = sum_{k=1}^N (1/k) sum_{n=k}^N z^n
 = [sum_{k=1}^N z^k/k - H_N z^(N+1)]/(1-z),
```

and (2) is the specialization `z=-x`, multiplied by `-1/x`.
For each `0<x<1`, letting `N->infinity` yields

```text
sum_{n>=1} (-1)^(n-1) H_n x^(n-1)
 = log(1+x)/[x(1+x)].                         (3)
```

The cubic moment is

```text
(1/2) integral_0^1 x^(n-1) log(x)^2 dx = 1/n^3.  (4)
```

One explicit antiderivative for (4) is

```text
x^n/n * (log(x)^2 - 2 log(x)/n + 2/n^2),
```

and `x^n log(x)^j -> 0` at `0+` for `j=1,2`.

Using (3), (4), and absolute summability of `sum H_n/n^3`,

```text
2F = integral_0^1 log(x)^2 log(1+x)/[x(1+x)] dx.
```

Since

```text
1/[x(1+x)] = 1/x - 1/(1+x),
```

we get

```text
2F = I - K,                                      (5)
I  = integral_0^1 log(x)^2 log(1+x)/x dx.
```

Expanding only the single logarithm,

```text
I = sum_{r>=1} (-1)^(r-1)/r
      * integral_0^1 x^(r-1) log(x)^2 dx
  = 2 sum_{r>=1} (-1)^(r-1)/r^4
  = 2(1-2^(-3)) Z_4
  = 7 Z_4/4.                                    (6)
```

Therefore

```text
F = 7 Z_4/8 - K/2.                              (7)
```

This is the key reduction.

### Convergence certificate for Lean

No global domination lemma is needed. For the finite kernel in (2),

```text
|(1/2) integral_0^1 log(x)^2
       * sum_{n>N} (-1)^(n-1) H_n x^(n-1) dx|
 <= sum_{n>N} H_n/n^3 -> 0.
```

For (6), the alternating Taylor remainder satisfies, on `0<=x<=1`,

```text
|log(1+x)-L_N(x)| <= x^(N+1)/(N+1),
```

hence

```text
|I - 2 sum_{r=1}^N (-1)^(r-1)/r^4|
 <= (1/(N+1)) integral_0^1 x^N log(x)^2 dx
 = 2/(N+1)^4.
```

## 2. A no-substitution derivative certificate for `K`

Define the two half-interval primitives

```text
D(y) = integral_0^y log(t) log(1-t)^2/t dt,
E(y) = integral_0^y log(1-t)^3/t dt,            (8)
```

for `0<=y<=1/2`.

For `x>0`, set

```text
u = x/(1+x),
a = log u,
b = log(1-u),
```

and define

```text
Q(x) = (1/2) a^2 b^2 - (2/3) a b^3 + (1/4) b^4
       - D(u) + (2/3) E(u).                    (9)
```

This is the certificate that avoids formalizing the substitution `x=u/(1-u)`.
On `0<x<=1`, FTC gives

```text
D'(u) = a b^2/u,
E'(u) = b^3/u.
```

Differentiate (9) first with respect to `u`. All `1/u` terms cancel, leaving

```text
dQ/du = -b (a-b)^2/(1-u).                      (10)
```

Also

```text
du/dx = (1-u)^2,
1-u   = 1/(1+x),
a-b   = log x,
b     = -log(1+x).
```

Thus (10) becomes exactly

```text
Q'(x) = log(x)^2 log(1+x)/(1+x).               (11)
```

At `x=1`, one has `u=1/2` and `a=b=-L`, so the polynomial part of (9) is

```text
(1/2 - 2/3 + 1/4)L^4 = L^4/12.
```

At `x->0+`, `Q(x)->0`. Therefore FTC on `[eps,1]`, followed by `eps->0+`, gives

```text
K = L^4/12 - D(1/2) + (2/3) E(1/2).           (12)
```

### Explicit endpoint bounds

For `0<t<=1/2`,

```text
0 <= -log(1-t) <= t/(1-t) <= 2t.              (13)
```

Consequently,

```text
|D(y)| <= 4 integral_0^y t |log t| dt -> 0,
|E(y)| <= 8 integral_0^y t^2 dt = 8y^3/3 -> 0.
```

The polynomial terms in (9) are bounded by constants times

```text
y^2 log(y)^2,  y^3 |log y|,  y^4,
```

and therefore vanish at `0+`.
The omitted piece of `K` also has the direct bound

```text
0 <= integral_0^eps log(x)^2 log(1+x)/(1+x) dx
   <= integral_0^eps x log(x)^2 dx
   = eps^2/2 * (log(eps)^2-log(eps)+1/2) -> 0.
```

Thus every boundary term in (12) is controlled explicitly.

## 3. Evaluation of `D(1/2)` from the already formalized ordinary Euler sum

Let

```text
W = integral_0^1 log(x) log(1-x)^2/x dx.       (14)
```

For `0<=x<1`,

```text
log(1-x)^2 = 2 sum_{n>=1} H_(n-1) x^n/n.      (15)
```

One quick proof of (15) is to integrate

```text
-log(1-x)/(1-x) = sum_{n>=1} H_n x^n.
```

Using

```text
integral_0^1 x^(n-1) log x dx = -1/n^2,
```

and absolute convergence,

```text
W = -2 sum_{n>=1} H_(n-1)/n^3
  = -2 (sum_{n>=1} H_n/n^3 - Z_4).            (16)
```

The already formalized ordinary Euler sum is

```text
sum_{n>=1} H_n/n^3 = 5 Z_4/4.
```

Hence

```text
W = -Z_4/2.                                    (17)
```

Split (14) at `1/2`. The second half, reflected by the affine map `x=1-t`, is

```text
C = integral_0^(1/2) log(1-t) log(t)^2/(1-t) dt.
```

Integrating by parts on `[eps,1/2]` with

```text
v(t) = -(1/2) log(1-t)^2
```

gives, after `eps->0+`,

```text
C = D(1/2) - L^4/2.                            (18)
```

The lower boundary is zero because, by (13),

```text
|log(eps)^2 log(1-eps)^2|
 <= 4 eps^2 log(eps)^2 -> 0.
```

Since `W=D(1/2)+C`, equations (17) and (18) imply

```text
-Z_4/2 = 2D(1/2)-L^4/2,
```

so

```text
D(1/2) = (L^4-Z_4)/4.                          (19)
```

This is the point at which the existing theorem `sum H_n/n^3=5Z_4/4` does all the weight-four work.

## 4. Evaluation of `E(1/2)` by one Li_4 primitive

Reflect the interval in (8):

```text
E(1/2)
 = integral_(1/2)^1 log(t)^3/(1-t) dt
 = -6Z_4 - J,                                  (20)

J = integral_0^(1/2) log(t)^3/(1-t) dt.
```

The full integral in (20) is elementary by the geometric series:

```text
integral_0^1 log(t)^3/(1-t) dt
 = sum_{n>=0} integral_0^1 t^n log(t)^3 dt
 = -6 sum_{n>=0} 1/(n+1)^4
 = -6Z_4.                                      (21)
```

For the lower-half integral `J`, define

```text
R(t) = -log(t)^3 log(1-t)
       -3 log(t)^2 Li_2(t)
       +6 log(t) Li_3(t)
       -6 Li_4(t).                             (22)
```

Using

```text
Li_2'(t) = -log(1-t)/t,
Li_3'(t) = Li_2(t)/t,
Li_4'(t) = Li_3(t)/t,
```

one obtains by direct cancellation

```text
R'(t) = log(t)^3/(1-t).                        (23)
```

Indeed, after differentiating (22):

```text
-3 log(t)^2 log(1-t)/t
```

from the first term cancels the corresponding term from differentiating `Li_2`; the `log(t) Li_2/t` terms cancel; the `Li_3/t` terms cancel; only `log(t)^3/(1-t)` remains.

At `t->0+`, `R(t)->0`. For example, on `0<t<=1/2`, the power-series bounds

```text
0 <= Li_r(t) <= t/(1-t) <= 2t  (r=2,3,4)
```

and (13) bound the four terms in (22) by constants times

```text
t |log t|^3,  t log(t)^2,  t |log t|,  t.
```

At `t=1/2`,

```text
J = -L^4 -3L^2 Li_2(1/2) -6L Li_3(1/2) -6A_4. (24)
```

Use the lower-weight half values

```text
Li_2(1/2) = Z_2/2 - L^2/2,                    (25)
Li_3(1/2) = 7Z_3/8 - Z_2 L/2 + L^3/6.        (26)
```

Then (24) reduces to

```text
J = -6A_4 + (3/2)Z_2 L^2 - (1/2)L^4
    - (21/4)Z_3 L.                             (27)
```

Combining (20) and (27),

```text
E(1/2) = 6A_4 - 6Z_4 - (3/2)Z_2 L^2
         + (1/2)L^4 + (21/4)Z_3 L.             (28)
```

### No hidden trilogarithm special value

If (26) is not already exposed under a convenient theorem name, it follows from the existing alternating weight-three block by a derivative certificate.

First prove the real dilogarithm identities on `0<x<1` by differentiating and checking the `x->0+` limits:

```text
Li_2(x)+Li_2(1-x) = Z_2-log(x)log(1-x),        (29)
Li_2(x)+Li_2(-x/(1-x)) = -(1/2)log(1-x)^2.    (30)
```

Then differentiation using (29)-(30) proves

```text
Li_3(x)+Li_3(1-x)+Li_3(-x/(1-x))
 = Z_3 + Z_2 log(1-x)
   -(1/2)log(x)log(1-x)^2
   +(1/6)log(1-x)^3.                           (31)
```

Both sides of (31) tend to `Z_3` at `0+`. At `x=1/2`, its third argument is `-1`, and

```text
Li_3(-1) = -sum_{n>=1} (-1)^(n-1)/n^3 = -3Z_3/4.
```

Equation (31) then gives (26). Equation (29) at `x=1/2` gives (25). Thus no literature special-value theorem is required.

## 5. Evaluation of `K`

Insert (19) and (28) into (12):

```text
K = L^4/12 -(L^4-Z_4)/4
    +(2/3)[6A_4-6Z_4-(3/2)Z_2L^2
           +(1/2)L^4+(21/4)Z_3L].
```

After collecting terms,

```text
K = 4A_4 - (15/4)Z_4 - Z_2 L^2
    + L^4/6 + (7/2)Z_3 L.                     (32)
```

As a secondary check, direct integration by parts gives the useful identity

```text
K = -integral_0^1 log(x) log(1+x)^2/x dx,     (33)
```

because

```text
d[(1/2)log(1+x)^2] = log(1+x)/(1+x) dx,
```

and

```text
log(x)^2 log(1+x)^2 -> 0
```

at both endpoints (`x=1` is immediate; at `0`, use `log(1+x)<=x`).

## 7. Independent numerical check

The summand magnitudes

```text
a_n = H_n/n^3
```

are strictly decreasing. Indeed, since `H_n>=1`,

```text
a_(n+1)/a_n
 = (H_n+1/(n+1))/H_n * n^3/(n+1)^3
 <= (1+1/(n+1))*n^3/(n+1)^3
 = n^3(n+2)/(n+1)^4 < 1.
```

Thus the alternating remainder after `N` terms is at most `H_(N+1)/(N+1)^3`.
For `N=2000`,

```text
F_2000 = 0.8592471574178103488302839698953888409459...
error <= H_2001/2001^3 < 1.021e-9.
```

The closed form (1) is

```text
0.8592471579285906155399099394757599807129...
```

and lies inside that certified interval. Independently,

```text
K = 0.1755713431373106040731865899955238684300...,
```

while (7) gives the same value from the series.

## 8. Lean 4.29 implementation order

The route can be formalized with the following small dependency chain.

1. **Finite harmonic kernel**: prove (2) by `Finset.sum_comm` and a finite geometric sum. Pass to (3) only for `0<x<1`.
2. **Moment bridge**: use the existing `log^2` moment lemma to prove (5), with the explicit absolute tail bound above.
3. **Eta-four integral**: prove (6) by finite Taylor sums and the `2/(N+1)^4` remainder.
4. **Define `Dfun`, `Efun`, and `Q`**: prove (10)-(11) on `0<x<=1` using the FTC derivative of interval integrals. Integrate on `[eps,1]`; use (13) to pass to `eps=0`. This entirely avoids a general substitution theorem.
5. **Whole `D` integral**: derive (16) from (15), then invoke the already proved ordinary Euler sum. Reflect only the affine second half and integrate by parts to get (19).
6. **Cubic-log lower half**: prove (23) with `convert`/`ring_nf` after rewriting the three polylog derivatives. Handle `0+` by the explicit `2t` polylog bounds. This gives (27)-(28).
7. **Final normalization**: `ring_nf` from (7), (19), and (28).

The only delicate endpoint is `0`; every required limit is reduced to one of

```text
x^a |log x|^b -> 0  (a>0),
```

with explicit exponents listed above. There are no branch cuts, improper substitutions, or unnamed connection constants.
