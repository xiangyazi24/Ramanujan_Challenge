# Thin compatibility for the delta_h covers: what is proved, what is conditional, and the exact p^(1/6) point-count lemma

## Executive verdict

PROVED: The addition law differentiates to an exact six-term identity for the critical polynomial A_{h+d}. The formula is written in Section 1.

OBSTRUCTION: That identity is not triangular in h and does not control critical values. A common finite branch value of delta_h and delta_k is equivalent to a singular point of the two-variable curve F_{h,k}. Neither adjacent coprimality nor the endpoint Apery-product formula rules out such a singular point. The h <= 8 calculation is strong evidence, but it does not induct to all h.

CONDITIONAL THEOREM: If the finite branch sets of delta_h and delta_k are disjoint and the two geometric monodromy groups are full symmetric groups, then F_{h,k} is absolutely irreducible. The proof uses the intersection of the two Galois closures: it can ramify only above 0 and infinity, hence is cyclic; full symmetric monodromy leaves only the sign quotient, whose branch set is the finite critical-value set, so disjointness kills it.

FINITE-RANGE CONSEQUENCE: For h <= 8, the supplied same-gap irreducibility and branch-disjointness data complete this argument after one explicit finite gate: each A_h must have a simple finite critical point, equivalently the finite critical-value polynomial must be squarefree in the normalization being used. If that gate is already part of the computation, the cross curves are absolutely irreducible over Qbar for all 1 <= h < k <= 8.

EFFECTIVITY CORRECTION: A characteristic-zero irreducibility theorem with a resultant of size exp(O(h^2 log h)) does not give a pointwise range h <= p^(1/6). To guarantee that p does not divide the resultant by size, one needs p > |R|, hence log p > O(h^2 log h). Even under that optimistic bound, only h << sqrt(log p / log log p) follows. For the pairwise critical-value resultant the natural bound is instead

```plain text
log |Res(C_h,C_k)| = O(h k (h+k) log(h+k)),
```

so the direct pointwise safe range is only about

```plain text
H << (log p / log log p)^(1/3).
```

The exponential height bounds are useful for a density-one statement over primes, not for every prime.

POINT-COUNT THEOREM: Under the all-p component census stated in Section 4, one has

```plain text
N_coinc(H) <= S_H^2/p + 4 S_H + C0 H^4 sqrt(p),
```

with an absolute C0. Therefore, for H <= c0 p^(1/6),


for an absolute c0 > 0. This is exactly COINC in the p^(1/6) range.

FINAL STATUS: The requested unconditional theorem for every prime and every H <= p^(1/6-eps) is not yet proved. The missing statement is not the Weil estimate; it is the uniform characteristic-p thinness/component theorem. The present h <= 8 data gives a fixed-H theorem outside a computable finite set of primes, and the general p^(1/6) theorem is rigorous conditional on the component census.

# 1. Exact derivative addition law

Put

```plain text
q_h(x) = prod_{j=1}^h (x+j),
delta_h(x) = N_h(x) / q_h(x)^3,
A_h(x) = N_h'(x) q_h(x) - 3 N_h(x) q_h'(x).
```

Then

```plain text
delta_h'(x) = A_h(x) / q_h(x)^4.
```

The supplied exact addition law is

```plain text
delta_{h+d}(x)
 = a^3 [delta_{h+1}(x) delta_d(x+h)
        - delta_h(x) delta_{d-1}(x+h+1)],
a = x+h+1.
```

Define, temporarily,

```plain text
f = delta_{h+1}(x),
g = delta_d(x+h),
u = delta_h(x),
v = delta_{d-1}(x+h+1).
```

Direct differentiation gives the exact identity

```plain text
PROVED-DERIVATIVE-ADDITION

delta_{h+d}'(x)
 = a^2 { 3(fg-uv)
         + a[f'g + f g' - u'v - u v'] }.
```

Equivalently, a point x is critical for delta_{h+d} exactly when

```plain text
3(fg-uv) + a[f'g + f g' - u'v - u v'] = 0.
```

There is also a denominator-free polynomial identity. Put

```plain text
Q = q_h(x),
R = q_{d-1}(x+h+1),
a = x+h+1.
```

Then

```plain text
q_{h+d}(x) = a Q R,
q_{h+1}(x) = a Q,
q_d(x+h) = a R.
```

The undifferentiated addition law becomes

```plain text
N_{h+d}(x)
 = N_{h+1}(x) N_d(x+h)
   - a^6 N_h(x) N_{d-1}(x+h+1).
```

Multiplying the differentiated identity by q_{h+d}^4 gives

```plain text
PROVED-A-ADDITION

A_{h+d}(x)
 = R A_{h+1}(x) N_d(x+h)
   + Q N_{h+1}(x) A_d(x+h)
   - a^7 R A_h(x) N_{d-1}(x+h+1)
   - a^7 Q N_h(x) A_{d-1}(x+h+1)
   + 3 Q R N_{h+d}(x).
```

This formula is useful, but it also displays the obstruction. Even after imposing A_h(x)=0, four generally nonzero terms remain. There is no divisibility implication such as

```plain text
A_h | A_{h+d}
```

and no induction on critical points.

The branch-locus question is harder still, because a common branch value uses two independent points x and y, not one common point x.

# 2. Forced branch values and the precise all-h obstruction

## 2.1 Polar data

For 1 <= j <= h, write q_h(x)=(x+j)q_{h,j}(x). The banked endpoint formula gives

```plain text
N_h(-j)
 = (-1)^(j-1) ((j-1)!)^3 b_{j-1} ((h-j)!)^3 b_{h-j},
```

while

```plain text
q_{h,j}(-j)
 = (-1)^(j-1) (j-1)! (h-j)!.
```

Therefore, over Q,

```plain text
delta_h(x)
 = b_{j-1} b_{h-j} / (x+j)^3
   + O((x+j)^(-2))
```

near x=-j. Also, if lambda_h is the leading coefficient of N_h,

```plain text
delta_h(x) = lambda_h x^(-3) + O(x^(-4))
```

at x=infinity.

Thus the two forced branch values are exactly

```plain text
infinity, from the h finite poles, each of ramification index 3;
0, from x=infinity, also of ramification index 3.
```

The degree of delta_h is 3h. Riemann-Hurwitz leaves

```plain text
(2*3h-2) - 2h - 2 = 4h-4
```

units of finite ramification, matching deg A_h=4h-4.

If A_h is squarefree and gcd(A_h,N_h q_h)=1, these are 4h-4 simple finite critical points, and their local monodromies are transpositions.

## 2.2 Common branch values are singularities of F_{h,k}

Define

```plain text
F_{h,k}(x,y)
 = N_h(x) q_k(y)^3 - N_k(y) q_h(x)^3.
```

Away from zeros and poles of the denominators,

```plain text
F_{h,k}(x,y)=0
```

is the equation delta_h(x)=delta_k(y). On this curve,

```plain text
partial_x F_{h,k}=0  iff  A_h(x)=0,
partial_y F_{h,k}=0  iff  A_k(y)=0.
```

Indeed, after using F_{h,k}=0,

```plain text
partial_x F_{h,k}
 = q_k(y)^3 A_h(x)/q_h(x),

partial_y F_{h,k}
 = -q_h(x)^3 A_k(y)/q_k(y).
```

Consequently:

```plain text
PROVED-SINGULARITY-DICTIONARY

A finite nonzero value t is a common branch value of delta_h and delta_k
iff F_{h,k}=0 has a singular point (x,y) above t
away from the forced boundary.
```

This explains why the critical-value resultant is the correct object.

## 2.3 Why the proposed induction does not close

The derivative addition law controls A_{h+d} at one base point x. A common branch value is the existence of x,y,t satisfying

```plain text
A_h(x)=0,
A_k(y)=0,
delta_h(x)=delta_k(y)=t.
```

The variables x and y are unrelated. The addition law supplies no equation identifying them.

The other available inputs also stop one level too low:

1. gcd(N_h,N_{h+1})=1 controls the zero fibers of consecutive maps, not their critical values.

1. The endpoint Apery products control the leading Laurent coefficient at the forced value infinity. They do not control any finite critical value.

1. Apparition and p-adic valuation laws can detect cancellation at a pole after reduction mod p. They do not rule out an equality between two unrelated finite critical values over Qbar.

1. A resultant Res_x(A_h,A_k) would only exclude a common critical point in the same x-coordinate. The needed object is Res_t(C_h,C_k), where C_h is the critical-value polynomial.

Therefore the all-h statement

```plain text
B_h^fin intersect B_k^fin = empty for h != k
```

is a new theorem, not a consequence of the current addition law.

Call it:

```plain text
GAP-BRANCH-DISJ
For all h != k, the finite nonzero branch loci of delta_h and delta_k
are disjoint over Qbar.
```

The h <= 8 computation is excellent evidence for GAP-BRANCH-DISJ, but it is not an induction seed because the recurrence for A_h is not triangular and does not descend to a recurrence for C_h(t).

# 3. Absolute irreducibility from branch disjointness

## 3.1 Common-cover lemma

Let K be an algebraically closed field of characteristic 0. Let

```plain text
f:X -> P1,
g:Y -> P1
```

be finite separable covers, and let L_f,L_g be their Galois closures over K(t).

Assume

```plain text
Branch(f) intersect Branch(g) is contained in {0,infinity}.
```

Put E=L_f intersect L_g. Then E/K(t) is Galois, and every place ramified in E ramifies in both Galois closures. Hence E is branched only over 0 and infinity.

A connected finite Galois cover of P1 branched over at most {0,infinity} is cyclic. This follows from the fact that the topological fundamental group of G_m is cyclic, or algebraically from the classification of tame covers of G_m.

Therefore:

```plain text
PROVED-COMMON-COVER-LEMMA

If the two geometric monodromy groups have no common nontrivial cyclic
quotient supported at 0 and infinity, then E=K(t), the two Galois closures
are linearly disjoint, and X x_{P1} Y is geometrically irreducible.
```

The last implication follows because the product monodromy acts transitively on the product of the two sheet sets.

## 3.2 Full symmetric monodromy is sufficient

For delta_h the degree is 3h. Assume h >= 2 and:

```plain text
(a) the off-diagonal same-gap factor H_h is irreducible over Q;
(b) delta_h has at least one simple finite critical point.
```

Irreducibility of H_h means that the arithmetic monodromy is 2-transitive on the 3h sheets. The geometric monodromy is a normal subgroup of the arithmetic monodromy and contains a transposition from the simple critical point.

Because the arithmetic group is 2-transitive, conjugating that transposition gives every transposition. Normality forces the geometric group to contain all transpositions. Hence

```plain text
G_h^geom = S_{3h}.
```

Now take h,k >= 2 with h != k. Since 3h and 3k are distinct and at least 6, the only possible common nontrivial quotient of S_{3h} and S_{3k} is C2, the sign quotient.

The local inertia at 0 and infinity is a product of 3-cycles, hence even. The inertia at a simple finite critical value is a transposition, hence odd. Thus the sign quadratic subcover is ramified exactly at the finite simple branch values.

If the finite branch sets of delta_h and delta_k are disjoint, their sign quadratic fields cannot coincide. Therefore the common quotient is trivial, and the common-cover lemma gives:

```plain text
CONDITIONAL-ABS-IRR

If h,k >= 2, h != k, both same-gap monodromies are full symmetric,
and the finite branch loci are disjoint, then F_{h,k} is absolutely
irreducible over Qbar.
```

## 3.3 The h=1 exception

One has

```plain text
delta_1(x)=1/(x+1)^3.
```

Thus the same-gap equation has three geometric line components after adjoining the cube roots of unity. This is the cube-root exception and must be treated separately.

For k>1, the cross equation is Kummer:

```plain text
(x+1)^3 = q_k(y)^3/N_k(y).
```

Over Qbar(y), it is irreducible exactly when N_k(y) is not a cube in Qbar(y). A squarefree N_k, or merely one root of multiplicity not divisible by 3, is sufficient.

## 3.4 What the h <= 8 data proves

For 2 <= h <= 8, the supplied irreducibility of H_h gives 2-transitive arithmetic monodromy. If the computed critical-value data also certifies that A_h has a simple finite root, the argument above upgrades the geometric monodromy to S_{3h}.

The supplied pairwise coprimality of the C_h then gives disjoint finite branch loci. Therefore all cross curves F_{h,k}, 2 <= h<k<=8, are absolutely irreducible over Qbar.

For h=1, the verified factorization data show that N_k is not a cube, so the Kummer argument handles F_{1,k}.

The only finite gate that must be made explicit in the certificate is:

```plain text
gcd(A_h,A_h')=1 and gcd(A_h,N_h q_h)=1 for 2<=h<=8,
```

or an equivalent statement that the finite critical values used above include a simple branch. If this was already checked when C_h was built, the finite-range absolute irreducibility theorem is complete.

# 4. Spread-out and the effectivity obstruction

## 4.1 The exact bad integer

For fixed h,k, all the characteristic-zero conclusions spread to every sufficiently large characteristic outside a computable finite set. One may take a nonzero integer B_{h,k} divisible by:

1. contents and leading coefficients of N_h,N_k,A_h,A_k;

1. Res(N_h,q_h) and Res(N_k,q_k), preserving the pole structure;

1. discriminants and pairwise resultants preserving simple critical points and distinct critical values;

1. Res_t(C_h,C_k), preserving branch disjointness;

1. the finite tame-monodromy specialization denominators.

For

```plain text
p > 3 max(h,k)
and
p does not divide B_{h,k},
```

the covers are tame, retain the same branch-cycle data, and the absolute irreducibility conclusion holds over Fbar_p.

## 4.2 Natural height size

The banked coefficient bounds give

```plain text
log H(N_h), log H(q_h), log H(A_h) = O(h log h).
```

The critical-value polynomial

```plain text
C_h(t)=Res_x(A_h(x),N_h(x)-t q_h(x)^3)
```

has degree at most 4h-4 in t and satisfies the natural Sylvester bound

```plain text
log H(C_h)=O(h^2 log h).
```

Therefore

```plain text
log |Res_t(C_h,C_k)|
 = O(h k (h+k) log(h+k)).
```

For h,k <= H this is O(H^3 log H). The discriminants needed for simple branching have the same general H^3 log H scale.

## 4.3 Why this does not give H <= p^(1/6) pointwise

To guarantee p does not divide B_{h,k} only from its size, a sufficient condition is

```plain text
p > |B_{h,k}|.
```

Thus one needs

```plain text
log p > C H^3 log H,
```

which gives at best

```plain text
H << (log p / log log p)^(1/3).
```

Even the more optimistic hypothetical bound

```plain text
log |B_{h,k}|=O(H^2 log H)
```

would give only

```plain text
H << sqrt(log p / log log p).
```

The comparison in the question,

```plain text
log bad(h) <= p^(1/3) log p,
```

is not the relevant inequality. The required comparison is log bad(h) < log p.

There is a second concrete bad-reduction mechanism. At x=-j the polar coefficient is b_{j-1}b_{h-j}. If p divides either Apery number, a nominal order-3 pole can cancel after reduction. The current pointwise zero bounds do not exclude such a cancellation for h <= p^(1/6).

## 4.4 What the height bound can give over primes

Suppose GAP-BRANCH-DISJ and the all-h monodromy theorem are proved over Q, with

```plain text
log |B_{h,k}| << H^3 log H
```

for h,k<=H. The total number of divisibility incidences

```plain text
(p,h,k), p in [X,2X], p divides B_{h,k}
```

is at most

```plain text
sum_{h,k<=H} log |B_{h,k}| / log X
 << H^5 log H / log X.
```

At H=X^(1/6), this is O(X^(5/6)), which is o(X/log X). Thus the height bounds would give the desired good reduction for a density-one set of primes in each dyadic interval.

They do not give it for every prime.

# 5. Conditional COINC theorem in the p^(1/6) range

Put

```plain text
I_h={1,...,p-2-h},
L_h=#I_h=p-2-h,
S_H=sum_{h<=H}L_h.
```

Assume the following component census over Fbar_p:

```plain text
GOOD_p(H)

1. For h!=k, 1<=h,k<=H, F_{h,k} has exactly one geometric component.
2. For h>=2, F_{h,h}=-(x-y)H_h and H_h is geometrically irreducible.
3. For h=1, the same-gap curve has at most three line components.
4. No vertical, horizontal, or two-dimensional degeneration occurs.
```

## 5.1 Cross-gap pairs

For h!=k, the compactification of F_{h,k}=0 in P1 x P1 has bidegree (3h,3k). The genus of its normalization is at most

```plain text
(3h-1)(3k-1) <= 9hk.
```

Hasse-Weil and the boundary divisors give

```plain text
#F_{h,k}(F_p) = p + O(hk sqrt(p)+h+k)
```

for the full affine curve.

The windows I_h and I_k are almost all of F_p. Their complements have sizes h+2 and k+2. Deleting the complement costs at most

```plain text
3k(h+2)+3h(k+2)=O(hk+h+k)
```

points, because a fixed x-fiber has degree at most 3k and a fixed y-fiber has degree at most 3h.

Therefore

```plain text
# {x in I_h,y in I_k: delta_h(x)=delta_k(y)}
 = L_h L_k/p + O(hk sqrt(p)+hk).
```

No Fourier completion is needed. If one uses additive-character completion, a log^2 p factor appears, but the co-large shape of the windows removes it completely.

## 5.2 Same-gap pairs

For h>=2, the diagonal contributes exactly L_h points. The irreducible component H_h has bidegree (3h-1,3h-1), genus at most (3h-2)^2, and hence contributes

```plain text
L_h^2/p + O(h^2 sqrt(p)+h^2)
```

inside the window. Intersections with the diagonal can only reduce the union count, so for an upper bound

```plain text
N_{h,h}
 <= L_h + L_h^2/p + O(h^2 sqrt(p)+h^2).
```

For h=1, the three possible Kummer lines contribute at most 3L_1=O(p), so the excess over L_1^2/p is O(p).

## 5.3 Summation

Summing the main terms over all ordered pairs (h,k) gives exactly

```plain text
S_H^2/p.
```

The forced same-gap diagonals contribute at most S_H. The h=1 exception contributes O(p), which is O(S_H). Finally,

```plain text
sum_{h,k<=H} hk
 = [H(H+1)/2]^2
 = O(H^4).
```

Hence there is an absolute constant C0 such that

```plain text
CONDITIONAL-COINC-1/6

N_coinc(H)
 <= S_H^2/p + 4 S_H + C0 H^4 sqrt(p)
```

whenever GOOD_p(H) holds.

For H<=p/4 one has S_H>=pH/2. Therefore

```plain text
C0 H^4 sqrt(p) / S_H <= 2 C0 H^3/sqrt(p).
```

Choose

```plain text
c0=(4C0)^(-1/3).
```

Then H<=c0 p^(1/6) gives

```plain text
N_coinc(H) <= S_H^2/p + 5 S_H.
```

Equivalently, COINC holds with K=5 in this range.

For every eps>0, the same conclusion holds for

```plain text
H<=p^(1/6-eps)
```

once p>=p0(eps), with no need to choose a small leading constant.

## 5.4 Thin exceptional version

Let nu_{h,k}(p) be the number of geometric one-dimensional components of the reduced cross curve, after removing the forced diagonal in the same-gap case. The general point-count argument gives

```plain text
N_coinc(H)
 <= S_H^2/p + 4S_H
    + p Xi_p(H)
    + C0 H^4 sqrt(p),
```

where Xi_p(H) is the total excess component count beyond the expected census.

Thus the exact thinness lemma needed is

```plain text
THIN-COMP
Xi_p(H) << H
uniformly for H<=p^(1/6-eps),
with no two-dimensional degeneration.
```

THIN-COMP plus the genus bound proves COINC in the p^(1/6-eps) range. Full branch disjointness and full symmetric monodromy give the stronger statement Xi_p(H)=0 for all cross-gap pairs.

```plain text
Let h,k>=2, h!=k. Assume:

1. delta_h and delta_k have full symmetric geometric monodromy;
2. their finite nonzero branch loci are disjoint.
```

## Theorem B: conditional small-scale COINC

```plain text
There are absolute constants C0,c0>0 such that, for every prime p>=7
```

```plain text
For every eps>0 there is K_eps such that, for every prime p and every
H<=p^(1/6-eps), the total excess geometric component count of the
family F_{h,k}, 1<=h,k<=H, after the forced same-gap components are
```

This is the exact compatibility statement that turns the new disjointness data into the first growing-scale COINC theorem.

The h<=8 data discovers the correct geometry: cross-gap fiber products appear connected, same-gap products have exactly the diagonal plus one off-diagonal component, and the only systematic exception is the h=1 Kummer map.

Differentiating the addition law does not prove branch disjointness, and characteristic-zero resultants of exponential size do not provide pointwise good reduction at polynomial h.
