# Q6790 audit: determinant Fourier reduction exponent budget

## 1. Setup and algebraic reduction

Let M be the number of ordered pairs in the strip

```
S_D = {(r,u): D/2 < u-r <= D, 1 <= r,u <= N}.
```

Then

```
M <= D N.
```

For a fixed pair, the projective collision condition is

```
xi_r = xi_u  <=>  det(u_r,u_u)=0 in F_p.
```

The additive-character identity gives exactly

```
1_{det=0} = (1/p) sum_t exp(2 pi i t det/p).
```

Therefore

```
T(D) = M/p + (1/p) sum_{t != 0} B(t),
```

with

```
|T(D)-M/p| <= (p-1)/p max_t |B(t)|
```

or the weaker mean form

```
T(D) <= M/p + (1/p) sum_{t != 0}|B(t)|.
```

The main term is not D automatically: at D=sqrt(N)L,

```
M/p <= ND/p * (1+o(1)) <= D(1+o(1)).
```

Thus the claimed target

```
T(D) << D^(2-eta)
```

is only interesting for eta<1. The main term is already acceptable because

```
D << D^(2-eta)
```

for every fixed eta<1.

## 2. Audit of the proposed mean exponent

The note's statement

```
required mean bound = N^(1-eta/2)L^(2-eta)
```

is correct up to harmless constants.

Indeed D=N^(1/2)L, hence

```
D^(2-eta)=N^(1-eta/2)L^(2-eta).
```

Since

```
T(D) <= D + mean_t |B(t)|,
```

the required sufficient estimate is exactly

```
mean_t |B(t)| << N^(1-eta/2)L^(2-eta).
```

No exponent loss is hidden here.

## 3. Square-root cancellation budget

The heuristic bound

```
|B(t)| << sqrt(ND)
```

gives

```
sqrt(ND)=N^(3/4)L^(1/2).
```

Comparing with the required size:

```
N^(3/4)L^(1/2) <= N^(1-eta/2)L^(2-eta)
```

requires

```
3/4 <= 1-eta/2,
```

hence

```
eta <= 1/2.
```

At eta=1/2 the power of N is equal and the L factor favors the required bound. Therefore the statement "square-root cancellation has margin for eta<1/2" is correct, with the endpoint eta=1/2 also acceptable if L does not decay.

## 4. Completion threshold audit

The claim

```
completion gives about p log p, exactly the trivial threshold
```

needs qualification.

A generic completion argument for a length-N incomplete sum over a finite field gives a bound of size roughly

```
O(p log p)
```

because the Fourier transform has p frequencies and harmonic summation contributes a logarithm. Since N~p, this is

```
O(N log N).
```

But the target mean is

```
N^(1-eta/2)L^(2-eta).
```

For any fixed eta>0,

```
N log N >> N^(1-eta/2)L^(2-eta)
```

for slowly growing L. Therefore completion is actually worse than needed, not exactly the same as the target. The phrase "trivial threshold" is false if interpreted as sufficient; it is only true in the sense that it reaches the natural size N.

## 5. If a power saving exists

Assume a genuine uniform estimate

```
mean_{t !=0}|B(t)| << p^(1-kappa)
```

for fixed kappa>0. Since p~N, this gives

```
T(D) << D + N^(1-kappa).
```

The second term must satisfy

```
N^(1-kappa) <= N^(1-eta/2)L^(2-eta).
```

Ignoring the favorable L factor gives the necessary power inequality

```
1-kappa <= 1-eta/2,
```

so

```
eta <= 2 kappa.
```

Because L may absorb a fixed logarithm but cannot absorb a positive power of N, the exact conclusion is:

```
any fixed kappa>0 closes FR_eta for every eta < min(1,2kappa),
```

and at eta=2kappa it closes only with enough slowly growing L.

Therefore the unqualified sentence "any fixed kappa>0 closes [FR_eta]" is FALSE. The correct statement requires choosing eta below 2kappa.

## 6. What is proved unconditionally?

The following is proved algebraically:

1. Character expansion for T(D).
2. Ordered pair count M<=ND.
3. Main term M/p<=D(1+o(1)).
4. Required mean exponent N^(1-eta/2)L^(2-eta).
5. Power-saving implication eta<2kappa.

No nontrivial kappa is currently proved for B(t).

## 7. Moment obstruction audit

Let

```
B(t)=sum_{(r,u) in S_D} psi(t det(u_r,u_u)).
```

The second moment is

```
sum_t |B(t)|^2
 = p * #{(r,u,r',u'): det(u_r,u_u)=det(u_r',u_u')}
```

by orthogonality.

Thus a useful second moment requires nontrivial control of the four-index determinant incidence variety. The generic diagonal contribution already has size comparable to the number of terms, and without additional structure this gives only the square-root barrier after Cauchy.

Likewise the fourth moment counts solutions to

```
det(u_r,u_u)+det(u_a,u_b)
 = det(u_c,u_d)+det(u_e,u_f).
```

A generic finite-field estimate would need geometric information on this eight-variable variety. The previous routes based only on size, scalar affine charts, or per-gap Weil estimates do not supply this.

Therefore:

* PROVED: moment identities reduce the problem to determinant incidence counts.
* NOT PROVED: these incidence counts have power-saving cancellation.

## 8. Why no bounded-conductor shortcut is available

A Deligne-style estimate would require an explicit sheaf or trace-function realization of

```
(r,u) -> psi(det(u_r,u_u)).
```

The Apery orbit is not currently represented by a constructed bounded-conductor lisse sheaf on the relevant two-variable parameter space. Invoking such a sheaf would assume the missing theorem.

Therefore the statement "completion plus a bounded conductor sheaf gives cancellation" is conditional, not a proof.

## 9. Final verdict

VERDICT:

- The Fourier reduction is correct.
- The main term audit is correct and harmless.
- The required mean exponent is correct.
- The square-root heuristic gives eta<=1/2.
- The statement "any kappa>0 closes FR_eta" is false as written. Correct range: eta<2kappa (endpoint depends on L).
- Generic completion does not close any fixed eta>0.
- Generic second/fourth moments do not currently give a kappa>0; they expose determinant incidence problems.
- A rigorous proof of any kappa>0 remains open unless one constructs additional arithmetic geometry of the Apery determinant phase.
