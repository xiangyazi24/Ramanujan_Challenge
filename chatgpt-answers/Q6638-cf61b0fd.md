# 0. Verdict

The correct variance-weighted replacement exists, but it is not either of the two proposed scalar inequalities.

The main conclusions are:

1. There is an exact basewise functional:

```plain text
Q_H = sum_r binom(d_H(r),2)
    = sum_(t>=2) (t-1) A_H(t),

A_H(t) = #{r : d_H(r)>=t}.
```

This is the cleanest multiplicity-tail formulation. It shows that the logarithmic endpoint is exactly a weak-L2 tail problem.

1. There is a genuine weighted refinement of the inverse-square clique proof. Each localized color clique is weighted by its actual diameter, not by the ambient H:

```plain text
Q_H <= F_diam(H)
     := 11 sum_(localized selected chains)
             (local diameter / chain gap)^2.
```

Every global collision edge occurs in at most two selected chains, and every local diameter is at most H. Hence

```plain text
F_diam(H) <= 22 H^2 sum_(d<=H) R_d/d^2,
```

which recovers the banked theorem. In spread-out data, the local aspect-ratio tail can be far smaller than the worst-case H/d tail.

1. A linear D_typ factor is false. The proposed form

```plain text
Q_H <= c H D_typ sum_(d<=H) R_d/d^2
```

fails even when D_typ is allowed to be the maximum local return count. A sparse arithmetic progression forces a coefficient of order H^2, not H times a typical multiplicity.

1. The proposed two-scale trade

```plain text
(H^2/W) sum R_d/d^2
+ correction involving only double returns below W
```

is also false. The same sparse progression can have no repeated color at any distance at most W, while its H-scale triple count exceeds the proposed main term by a factor tending to infinity.

1. The correct two-scale recursion is a positive-semidefinite Gram identity. If

```plain text
a(r) = number of returns in [1,W],
b(r) = number of returns in (W,H],
```

then

```plain text
Q_H = Q_[1,W] + Q_(W,H] + sum_r a(r)b(r).
```

The outer-shell diagonal Q_(W,H] and the cross-shell Gram term are indispensable. Iterating over dyadic shells gives

```plain text
2Q_H + S_H <= (sum_j sqrt(V_j))^2,

V_j = sum_r a_j(r)^2
    = S_j + 2 Q_j^shell.
```

1. Substituting only the currently proved inputs into this recursion gives exactly

```plain text
Q_H << H^2 log H.
```

It sheds neither the logarithm nor a power. The largest shell dominates. Thus this recursion alone yields no new unconditional theorem.

1. A bottom-scale condition alone cannot prove the mesoscopic target. There are explicit words with

```plain text
R_d <= 2d,
no equal-color pair at any distance below about sqrt(D),
Q_D >= c D^2,
word length O(D^(3/2)).
```

For D=sqrt(N)L and every slowly growing L=o(N^(1/6)), this word embeds in length N and gives

```plain text
Q_D >= c N L^2.
```

Thus even the strongest possible polylogarithmic bottom input - zero short returns - does not imply Q_D<<N.

1. The minimal clean arithmetic input is therefore a top-scale or all-scale variance statement. Two equivalent useful interfaces are:

```plain text
sum_(t>=2) (t-1) #{r:d_D(r)>=t} << N,
```

or, for dyadic shell vectors a_j,

```plain text
sum_j ||a_j||_2 << sqrt(N).
```

A convenient sufficient tail is

```plain text
#{r:d_D(r)>=t}
  << N / (t^2 (1+log t)^(1+eta)).
```

A convenient shell-quantile sufficient input is

```plain text
sum_j sqrt(T_j S_j + Heavy_j) << sqrt(N),

Heavy_j = sum_(r:a_j(r)>T_j) a_j(r)^2.
```

The arithmetic must control the heavy tail at every relevant shell, especially the top shells. Controlling only the bottom shell cannot close the recursion.

# 1. Notation lock and exact per-base identities

Let x_0,...,x_N be any word. Define

```plain text
E_d = {r : r+d<=N and x_r=x_(r+d)},
R_d = #E_d,

d_H(r) = #{1<=h<=H : r+h<=N and x_r=x_(r+h)},
S_H = sum_r d_H(r),
Q_H = sum_r binom(d_H(r),2).
```

Then

```plain text
S_H = sum_(d=1)^H R_d.                              (1.1)
```

Also, Q_H is exactly the number of monochromatic triples

```plain text
u < v < w,
x_u=x_v=x_w,
w-u<=H.                                               (1.2)
```

Each triple is counted once, at its least point u.

## Proposition 1.1: exact edge-weighted base functional

One has

```plain text
2Q_H
 = sum_(d=1)^H sum_(r in E_d) (d_H(r)-1).            (1.3)
```

Proof. For a fixed base r, the inner sum sees r once for each of its d_H(r) returns. Its total contribution is therefore

```plain text
d_H(r)(d_H(r)-1)=2 binom(d_H(r),2).
```

Summing over r proves (1.3).

This is the first exact weighted replacement. A collision edge from r is weighted by the number of other returns from the same base.

## Proposition 1.2: exact tail formula

Put

```plain text
A_H(t) = #{r : d_H(r)>=t}.
```

Then

```plain text
S_H = sum_(t>=1) A_H(t),                              (1.4)
Q_H = sum_(t>=2) (t-1) A_H(t).                        (1.5)
```

Proof. For every integer m>=0,

```plain text
m = sum_(t=1)^m 1,
binom(m,2) = sum_(t=2)^m (t-1).
```

Apply these identities to m=d_H(r) and interchange the finite sums.

Formula (1.5) identifies the exact logarithmic endpoint. A weak-L2 tail

```plain text
A_H(t) << H^2/t^2
```

gives Q_H<<H^2 log H, while any summable improvement over t^(-2) gives Q_H<<H^2.

## Corollary 1.3: quantile plus heavy-tail decomposition

For every threshold T>=1,

```plain text
Q_H
 <= (T/2) S_H
    + (1/2) sum_(r:d_H(r)>T) d_H(r)^2.                (1.6)
```

Proof. If d_H(r)<=T, then

```plain text
binom(d_H(r),2) <= T d_H(r)/2.
```

For a heavy base use binom(d,2)<=d^2/2.

This is the precise repair of a single D_typ quantile. A quantile alone is not enough: the exceptional bases must be paid with their second moment, not merely their cardinality.

A dyadic form, useful for machine checking, is

```plain text
Q_H
 <= 2 sum_(k>=0) 4^k
       #{r : 2^k < d_H(r) <= 2^(k+1)}.               (1.7)
```

# 2. Diameter-weighted refinement of the clique-energy chain

The banked proof uses half-open blocks

```plain text
B_j = [jH,(j+1)H),
W_j = [jH,(j+2)H).
```

Every triple is assigned to the unique j for which its least point lies in B_j. Its span is at most H, so the whole triple lies in W_j.

For a color a, let

```plain text
A_(j,a) = {n in W_j : x_n=a},
m_(j,a) = #A_(j,a),
q_(j,a) = number of assigned triples of color a.
```

Thus

```plain text
Q_H = sum_(j,a) q_(j,a),
q_(j,a) <= binom(m_(j,a),3).                         (2.1)
```

Split W_j into its two H-blocks. Choose one half containing at least ceil(m_(j,a)/2) points of A_(j,a). Write those selected points as

```plain text
y_1 < ... < y_n.
```

For n>=2 define

```plain text
L_(j,a) = y_n-y_1,
g_i = y_(i+1)-y_i,
e_(j,a) = sum_(i=1)^(n-1) 1/g_i^2.                   (2.2)
```

If n<2, put L=e=0.

## Lemma 2.1: local diameter clique inequality

For every (j,a),

```plain text
q_(j,a) <= 11 L_(j,a)^2 e_(j,a).                    (2.3)
```

Proof.

If m<3, then q=0.

If m=3, the chosen half contains at least two points. For those two points, L=g_1 and L^2 e=1, so q<=1<=L^2e.

Assume m>=4. Put k=n-1. Since n>=ceil(m/2),

```plain text
k >= m/2-1 >= m/4.                                  (2.4)
```

Also

```plain text
sum_i g_i = L.
```

Two applications of Cauchy give

```plain text
(sum_i 1/g_i^2) (sum_i g_i)^2 >= k^3.                (2.5)
```

Indeed,

```plain text
sum 1/g_i^2 >= (sum 1/g_i)^2/k,
(sum g_i)(sum 1/g_i) >= k^2.
```

Hence

```plain text
e >= k^3/L^2 >= m^3/(64L^2).                        (2.6)
```

Therefore

```plain text
binom(m,3) <= m^3/6
            <= (64/6)L^2e
            < 11L^2e.
```

This proves (2.3).

## Theorem 2.2: the exact diameter functional

Define

```plain text
F_diam(H)
 = 11 sum_(j,a) L_(j,a)^2 e_(j,a).                  (2.7)
```

Then

```plain text
Q_H <= F_diam(H).                                    (2.8)
```

Moreover,

```plain text
F_diam(H)
 <= 22 H^2 sum_(d=1)^H R_d/d^2.                     (2.9)
```

Proof. Equation (2.8) is Lemma 2.1 summed over (j,a).

Every edge used in e_(j,a) is a same-color pair of gap at most H. A fixed global pair can lie in at most two expanded windows W_j: if its left endpoint lies in B_t, then only j=t-1 and j=t are possible. Also L_(j,a)<=H. Thus every global collision pair of gap d contributes at most

```plain text
2 H^2/d^2
```

to the sum in (2.7), proving (2.9).

Under R_d<=Cd, (2.9) is exactly the banked bound

```plain text
Q_H <= 22 C H^2(1+log H).                           (2.10)
```

## Shape-tail form

For every selected chain-edge incidence define its aspect ratio

```plain text
rho = L_(j,a)/g_i.                                   (2.11)
```

Then

```plain text
Q_H <= 11 sum rho^2.                                 (2.12)
```

The number of selected incidences is at most 2S_H. Therefore, for every T>=1,

```plain text
Q_H
 <= 22 T^2 S_H
    + 11 sum_(selected incidences with rho>T) rho^2. (2.13)
```

This is a genuine typical geometry plus heavy tail inequality. The typical factor is necessarily quadratic. A linear factor is false, as the next section shows.

# 3. Counterexample to the linear D_typ candidate

Fix an integer s>=4 and put

```plain text
H=s^2.
```

Use one non-singleton color at the positions

```plain text
A = {0,s,2s,...,s^2},                                (3.1)
```

and give every other position a fresh singleton color.

For d=ks, 1<=k<=s,

```plain text
R_d=s+1-k<=s<=ks=d,                                  (3.2)
```

and all other R_d vanish. Thus R_d<=d for every d.

Every triple from A has span at most H, so

```plain text
Q_H = binom(s+1,3)
    = s(s^2-1)/6
    = (1/6+o(1)) H^(3/2).                            (3.3)
```

The global inverse-square energy is

```plain text
E_2
 = sum_(k=1)^s (s+1-k)/(ks)^2
 <= ((s+1)/s^2) sum_(k>=1) 1/k^2
 <= pi^2/(3s).                                       (3.4)
```

The maximum possible local return count is s. Hence even if D_typ is replaced by the maximum,

```plain text
H D_typ E_2 <= s^2 * s * pi^2/(3s) = O(s^2),        (3.5)
```

whereas Q_H is of order s^3.

Therefore no absolute c can make

```plain text
Q_H <= c H D_typ sum_(d<=H) R_d/d^2                 (3.6)
```

valid for any notion of D_typ bounded by the maximum local return count.

The same calculation gives the sharper obstruction

```plain text
Q_H/E_2 >= c H^2.                                    (3.7)
```

Thus the H^2 coefficient in a universal inverse-square-energy inequality is genuinely necessary, even for a color class whose consecutive gaps are all about sqrt(H).

# 4. Counterexample to the proposed H^2/W recursion

Use the same word and take

```plain text
W=s-1.
```

The minimum equal-color gap is s, so

```plain text
Q_W=0,
```

and every interval of length W contains at most one point of every color. In particular, any correction that only counts bases having at least two returns in a W-window is zero.

But by (3.4),

```plain text
(H^2/W) E_2
 <= (s^4/(s-1)) * pi^2/(3s)
 = O(s^2),                                           (4.1)
```

while Q_H is of order s^3.

Therefore an inequality of the form

```plain text
Q_H
 <= c (H^2/W) sum_(d<=H)R_d/d^2
    + Phi(Q_W, W-window double returns),             (4.2)
```

with Phi(0,0)=0, is false.

The missing object is the coarse skeleton. In this example all of the mass lies in an outer shell with spacing just above W. There is no bottom-scale double return to recurse on.

# 5. What a valid two-scale occupancy inequality looks like

The following proposition is not the final recursion, but it makes the missing coarse term explicit.

Partition the word into half-open blocks I_j of length W. For each color a put

```plain text
n_(j,a) = #{positions of color a in I_j},
B_W = max_(j,a) n_(j,a),
J = ceil(H/W)+1.                                     (5.1)
```

Let

```plain text
P_W = sum_(j,a) binom(n_(j,a),2).                    (5.2)
```

Every pair counted by P_W has gap below W, so

```plain text
P_W <= sum_(d<W)R_d.                                 (5.3)
```

## Lemma 5.1: weighted local clique inequality

Let an interval of coarse sites have length at most 2J, and let nonnegative site weights satisfy 0<=w_i<=B. Define

```plain text
T(w) = sum_(i<j<k) w_i w_j w_k,
E(w) = sum_(i<j, j-i<=J) w_i w_j/(j-i)^2.
```

Then

```plain text
T(w) <= 11 B J^2 E(w).                               (5.4)
```

Proof. Independently retain site i with probability w_i/B. For every realized subset, Lemma 2.1 with ambient diameter J gives

```plain text
number of triples <= 11J^2 times inverse-square energy.
```

Take expectations. The expected triple count is T(w)/B^3, and the expected energy is E(w)/B^2. Multiplying by B^3 proves (5.4).

## Proposition 5.2: coarse skeleton plus clustered correction

Assume R_d<=Cd for d<=H. Then

```plain text
Q_H
 <= K C B_W H^2 (1+log(2+H/W))
    + K C B_W H W,                                  (5.5)
```

for an absolute K.

Proof.

First count triples whose three points lie in distinct W-blocks. Their exact coarse weighted count is

```plain text
sum_a sum_(i<j<k, k-i<=J)
          n_(i,a)n_(j,a)n_(k,a).                    (5.6)
```

For a coarse gap k, the weighted pair count is

```plain text
Rbar_k = sum_(j,a)n_(j,a)n_(j+k,a).                 (5.7)
```

Every original pair contributing to Rbar_k has actual gap in

```plain text
((k-1)W, (k+1)W).
```

Therefore

```plain text
Rbar_k
 <= sum_((k-1)W<d<(k+1)W) R_d
 <= 4 C W^2 k.                                      (5.8)
```

Repeat the localization proof of Theorem 2.2 on the coarse line and use Lemma 5.1. This gives

```plain text
distinct-block triples
 << B_W J^2 sum_(k<=J) Rbar_k/k^2
 << C B_W W^2 J^2(1+log J)
 << C B_W H^2(1+log(2+H/W)).                         (5.9)
```

Now count triples with at least two points in one W-block. Choose one same-block pair. Its third point can lie in at most 2J+1 neighboring blocks, each with at most B_W occurrences of the same color. Thus

```plain text
clustered triples
 <= B_W(2J+1)P_W
 << C B_W H W.                                      (5.10)
```

Adding (5.9) and (5.10) proves (5.5).

This is the correct form of a linear typical-occupancy factor. It multiplies a coarse-skeleton term of size H^2 log(H/W). It cannot be replaced by H^2/W times the original inverse-square energy.

A quantile version is obtained by truncating n_(j,a) at a threshold T. The low part satisfies (5.5) with B_W=T. The exact heavy correction must retain the local cubic load. One convenient form is

```plain text
Heavy_T
 = (1/2) sum_(j,a) (n_(j,a)-T)_+
      (sum_(|i-j|<=J) n_(i,a))^2.                   (5.11)
```

Then the distinct-block weighted triple count is at most

```plain text
low-part bound + Heavy_T.                            (5.12)
```

A mere count of heavy blocks is not enough unless it is multiplied by a bound for their local mass squared.

# 6. The exact two-scale variance recursion

Fix 0<W<H. Put

```plain text
a(r) = #{1<=h<=W : x_r=x_(r+h)},
b(r) = #{W<h<=H : x_r=x_(r+h)}.                     (6.1)
```

Define

```plain text
S_a=sum_r a(r),
Q_a=sum_r binom(a(r),2)=Q_W,
V_a=sum_r a(r)^2=S_a+2Q_a,
```

and analogously S_b,Q_b,V_b for the outer shell (W,H].

## Proposition 6.1: exact two-scale identity

One has

```plain text
Q_H = Q_a + Q_b + X_(a,b),
X_(a,b) = sum_r a(r)b(r).                            (6.2)
```

Consequently,

```plain text
X_(a,b) <= sqrt(V_a V_b),                            (6.3)
```

and

```plain text
2Q_H+S_H
 = sum_r(a(r)+b(r))^2
 <= (sqrt(V_a)+sqrt(V_b))^2.                         (6.4)
```

Proof. Expand

```plain text
binom(a+b,2)=binom(a,2)+binom(b,2)+ab
```

at each base r. Equation (6.3) is Cauchy, and (6.4) is Minkowski in l^2(r).

This is the correct two-scale recursion. It contains three objects:

```plain text
inner diagonal Q_a,
outer diagonal Q_b,
cross-shell Gram term X_(a,b).
```

The proposed scalar recursion retains only the first. The arithmetic-progression counterexample has a=0, so the entire triple mass lies in Q_b; no bottom recursion can see it.

# 7. Full dyadic Gram recursion and its fixed point

Choose a bottom scale W_0>=1 and dyadic endpoints

```plain text
Y_0=W_0,
Y_j=min(2^j W_0,H).
```

Let I_0=[1,Y_0], and for j>=1 let

```plain text
I_j=(Y_(j-1),Y_j].
```

Define the shell vector

```plain text
a_j(r) = #{h in I_j : x_r=x_(r+h)},                 (7.1)
```

and its first and second moments

```plain text
S_j = sum_r a_j(r),
Q_j^shell = sum_r binom(a_j(r),2),
V_j = sum_r a_j(r)^2 = S_j+2Q_j^shell.               (7.2)
```

Define the Gram matrix

```plain text
G_(i,j) = sum_r a_i(r)a_j(r).                        (7.3)
```

## Theorem 7.1: exact Gram identity

One has

```plain text
2Q_H+S_H
 = sum_(i,j) G_(i,j).                                (7.4)
```

In particular,

```plain text
2Q_H+S_H
 <= (sum_j sqrt(V_j))^2.                             (7.5)
```

Proof. Since d_H(r)=sum_j a_j(r),

```plain text
2Q_H+S_H=sum_r d_H(r)^2
         =sum_(i,j)sum_r a_i(r)a_j(r).
```

This is (7.4). Since G is a Gram matrix,

```plain text
G_(i,j)<=sqrt(V_iV_j),
```

and summing gives (7.5).

This theorem is the full multiscale recursion requested in the question. The shorter-scale Q-object appears exactly as the diagonal correction Q_j^shell; the cross-scale coupling appears exactly as the off-diagonal Gram mass.

## Substitution of the current unconditional inputs

Since a_j(r)<=d_(Y_j)(r),

```plain text
V_j
 <= S_(Y_j)+2Q_(Y_j).                                (7.6)
```

The one-gap degree bound gives

```plain text
S_Y=sum_(d<=Y)R_d << Y^2.                            (7.7)
```

The banked inverse-square theorem gives

```plain text
Q_Y << Y^2(1+log Y).                                 (7.8)
```

Therefore

```plain text
sqrt(V_j) << Y_j sqrt(1+log Y_j).                    (7.9)
```

The Y_j grow geometrically, so

```plain text
sum_j sqrt(V_j)
 << H sqrt(1+log H).                                 (7.10)
```

Substitution into (7.5) gives

```plain text
Q_H << H^2(1+log H).                                 (7.11)
```

This is exactly the existing theorem. The recursion has no contracting coefficient; its largest shell already carries the full logarithmic loss. The bottom-scale facts R_1=0, adjacent coprimality, and any degree-only base case affect only the smallest terms in (7.10), which are geometrically negligible.

Hence the answer to the fixed-point question is negative:

```plain text
with only the current degree input at the bottom,
the multiscale recursion does not remove a log or a power.              (7.12)
```

# 8. A finite-environment counterexample to bottom-scale sufficiency

The previous sparse progression refutes the proposed inequality. The following packed construction also respects a finite ambient length and directly attacks the mesoscopic normalization.

## Proposition 8.1: packed sparse-progression word

For every sufficiently large D there is a word of length at most

```plain text
2 D^(3/2)+O(D)
```

such that

```plain text
R_q <= 2q                   for every 1<=q<=D,
no equal-color pair has gap below ceil(sqrt(D)),
Q_D >= c D^2,                                         (8.1)
```

for an absolute c>0.

Proof. Put

```plain text
S=ceil(sqrt(D)),
T={S,S+1,...,2S-1}.
```

For each s in T, reserve a private block of length D+1, use a private color c_s, and place it at

```plain text
B_s,
B_s+s,
...,
B_s+m_s s,

m_s=floor(D/s).                                      (8.2)
```

All unused positions get fresh singleton colors, and the private blocks are disjoint.

The length is at most S(D+1)=O(D^(3/2)). The minimum nonzero equal-color gap is at least S.

Fix q<=D. The class with step s contributes only if s divides q, and then contributes at most

```plain text
m_s+1 <= D/S+1 <= S+1                               (8.3)
```

pairs. The map s -> q/s is injective on the divisors of q in T, and q/s<=q/S. Hence there are at most q/S relevant steps. Therefore

```plain text
R_q <= (q/S)(S+1) <= 2q.                             (8.4)
```

For every s<2S,

```plain text
m_s >= D/(2S)-1 >= S/3
```

for all large D. Thus each private class contributes at least c_0 S^3 triples, all of span at most D. There are S step values, so

```plain text
Q_D
 >= S c_0 S^3
 >= c D^2.                                           (8.5)
```

This proves the proposition.

## Mesoscopic consequence

Let

```plain text
D=ceil(sqrt(N)L),
L=o(N^(1/6)),
L -> infinity.
```

Then

```plain text
D^(3/2)=N^(3/4)L^(3/2)=o(N),                         (8.6)
```

so the word from Proposition 8.1 embeds in an ambient word of length N after adding singleton fillers. It satisfies

```plain text
Q_D >= cD^2 >= c N L^2.                              (8.7)
```

It also has no equal-color pair at any distance below about

```plain text
sqrt(D)=N^(1/4)L^(1/2).                              (8.8)
```

Therefore each of the following bottom-scale hypotheses is insufficient by itself:

```plain text
- every base has O(1) returns in every polylogarithmic window;
- no base has two returns in any polylogarithmic window;
- the number of bases with at least two W_0-returns is zero;
- Q_(W_0)=0 for every W_0=o(sqrt(D)).                 (8.9)
```

Yet the mesoscopic target fails by a factor of order L^2.

This proves that the needed input is not a bottom seed. It must constrain the medium and top shells, or prove a propagation theorem that transfers bottom information to those shells.

# 9. Minimal arithmetic interfaces for Q_D<<N

## 9.1 Exact minimal tail criterion

Define

```plain text
A_D(t)=#{r:d_D(r)>=t}.
```

By (1.5),

```plain text
Q_D<<N
```

is exactly equivalent, up to the implied constant, to

```plain text
sum_(t>=2)(t-1)A_D(t) << N.                          (9.1)
```

This is the cleanest minimal arithmetic statement.

A convenient power-saving sufficient form is

```plain text
A_D(t) << N/t^(2+eta)                                (9.2)
```

for some fixed eta>0 and all t>=2.

A logarithmically minimal sufficient form is

```plain text
A_D(t)
 << N / (t^2 (1+log t)^(1+eta)).                    (9.3)
```

Indeed, substitution into (9.1) leaves the convergent series

```plain text
sum_(t>=2) 1/(t(1+log t)^(1+eta)).
```

The endpoint A_D(t)<<N/t^2 produces one logarithm and is not enough.

## 9.2 Exact multiscale variance criterion

For the dyadic shell vectors of Section 7, a sufficient condition is

```plain text
sum_j sqrt(V_j) << sqrt(N),                          (9.4)
```

because of (7.5).

Equivalently, it is enough to find summable nonnegative weights theta_j such that

```plain text
V_j <= N theta_j^2,
sum_j theta_j << 1.                                  (9.5)
```

This is a clean all-scale arithmetic target. It controls both the shorter-scale double-return diagonals and their possible cross-scale alignment.

## 9.3 Quantile version at every shell

For each shell choose a threshold T_j and put

```plain text
Heavy_j
 = sum_(r:a_j(r)>T_j) a_j(r)^2.                     (9.6)
```

Since a_j(r)^2<=T_j a_j(r) on the light set,

```plain text
V_j <= T_j S_j + Heavy_j.                            (9.7)
```

Therefore the following is sufficient:

```plain text
sum_j sqrt(T_j S_j + Heavy_j) << sqrt(N).            (9.8)
```

If one knows a shellwise maximum B_j and only counts the heavy bases

```plain text
E_j=#{r:a_j(r)>T_j},
```

then

```plain text
Heavy_j<=B_j^2 E_j,                                  (9.9)
```

so the checkable sufficient condition becomes

```plain text
sum_j sqrt(T_j S_j + B_j^2 E_j) << sqrt(N).          (9.10)
```

This is the rigorous version of the proposed D_typ idea. It requires:

```plain text
- a threshold at every scale;
- a first-moment bound for the light part;
- a second-moment payment for the exceptional part;
- summability across scales.
```

One bottom-scale estimate such as

```plain text
E_0 << N/polylog(N)
```

controls only one term in (9.10). Proposition 8.1 shows that all other terms can still carry N L^2 mass.

## 9.4 How much saving is required at the mesoscopic top shell

The current abstract theorem allows, at D=sqrt(N)L,

```plain text
V_top
 <= S_D+2Q_D
 << D^2 log D
 = N L^2 log D.                                      (9.11)
```

To make (9.4) possible, the top-shell contribution must be reduced to order N, up to a summable allocation among neighboring shells. Thus the exact missing factor is

```plain text
L^2 log D.                                           (9.12)
```

This is the same normalization deficit recorded in the project ledger, now expressed as a shell variance rather than a worst-case clique coefficient.

# 10. Recommended theorem targets

The following three statements are correctly ordered from exact to stronger but easier to use.

## [BASE-TAIL-N]

```plain text
sum_(t>=2)(t-1)#{r:d_D(r)>=t} << N.                  (10.1)
```

This is exactly [MESO-PAIR] in tail coordinates.

## [SHELL-CARLESON-N]

For dyadic shell return vectors a_j,

```plain text
sum_j ||a_j||_2 << sqrt(N).                          (10.2)
```

This implies [BASE-TAIL-N] by Theorem 7.1.

## [SHELL-TAIL-eta]

There are summable theta_j and some eta>0 such that

```plain text
#{r:a_j(r)>=t}
 << N theta_j^2/t^(2+eta)                            (10.3)
```

for every shell j and t>=1. This implies V_j<<N theta_j^2, hence [SHELL-CARLESON-N].

These targets explicitly demand distributional arithmetic. They are not consequences of the one-gap degree bounds and they are not bottom-scale statements.

# 11. Final assessment

The weighted clique route does produce a sharper object:

```plain text
F_diam(H)=11 sum(local aspect ratio)^2.
```

It exposes where the old H^2 was actually spent. The per-base route produces the exact multiplicity tail, and the multiscale route produces the exact shell Gram matrix.

However:

```plain text
- linear D_typ is false;
- H^2/W plus Q_W is false;
- bottom-scale double-return control is insufficient;
- the current inputs close the shell recursion at H^2 log H and no better.
```

The surviving arithmetic target is not a new worst-case clique inequality. It is a summable variance/tail statement for the medium and top return shells. At the mesoscopic scale, the clean win condition is either (9.1) or (9.4).

Least-confident point: Proposition 5.2 is intentionally stated with an unspecified absolute K because endpoint choices for the coarse blocks alter only that constant. None of the later conclusions uses this constant. The exact identities, the sparse-progression counterexamples, the fixed-point calculation, and the packed finite-environment construction do not depend on Proposition 5.2.

Likely shared blind spot: treating a short-scale Q-object as if it controlled the whole positive-semidefinite Gram matrix. It controls one diagonal block. The outer diagonal and the nonnegative cross-shell terms can contain all of the mass, and the sparse-progression examples realize exactly that failure mode.
