## 1. Exact derivative and ramification structure

### 1.1 Reduced critical polynomial

[PROVED] Put

```text
Delta_h = N_h / L_h^3,
L_h(r) = product_{j=1}^h (r+j).
```

Then

```text
Delta_h'(r)
 = [N_h'(r)L_h(r)^3 - 3N_h(r)L_h(r)^2L_h'(r)] / L_h(r)^6
 = K_h(r) / L_h(r)^4,
```

where

```text
K_h(r) = L_h(r)N_h'(r) - 3L_h'(r)N_h(r).              (1.1)
```

Since

```text
deg L_h = h,
deg N_h = 3h-3,
```

both terms in K_h have degree 4h-4. Their leading coefficients do not cancel: if the leading coefficient of N_h is a_h, then the leading coefficient of K_h is

```text
[(3h-3)-3h]a_h = -3a_h != 0.
```

Hence

```text
deg K_h = 4h-4.                                        (1.2)
```

The unreduced derivative numerator

```text
N_h'Q_h-N_hQ_h'
```

has the exact factor L_h^2. At each pole r=-j, this factor records the ramification contribution 3-1=2.

### 1.2 Universal ramification already forced by the denominator

Assume N_h has no common zero with L_h. This is true in the small cases below and is the natural noncancellation condition for the degree statement.

Then Delta_h has degree 3h and has:

```text
h poles r=-1,...,-h, each of ramification index 3;
infinity mapping to 0 with ramification index 3;
4h-4 remaining finite critical points, counted with multiplicity.
```

Indeed Riemann-Hurwitz gives total ramification

```text
2(3h)-2 = 6h-2.
```

The h triple poles contribute 2h and infinity contributes 2, leaving

```text
(6h-2)-(2h+2) = 4h-4,
```

exactly the degree in (1.2).

This is not Belyi behavior. A Belyi-type explanation would require these 4h-4 critical points to collapse onto a fixed finite set of target values. The explicit calculations below show that even the finite branch sets for h=2,3,4 are not fixed: the h=2 finite branch set is disjoint from the h=3 and h=4 finite branch sets.

### 1.3 Transfer-matrix derivative: h rank-one insertions

[PROVED] For

```text
G_m(s) = M_{s+m-1} ... M_s,
M_u = [[0,(u+1)^6],[-1,P(u)]],
```

ordinary differentiation gives

```text
G_m'(s)
 = sum_{j=0}^{m-1}
     G_{m-j-1}(s+j+1) M_{s+j}' G_j(s),                 (1.3)
```

where empty products are identities and

```text
M_u' = [[0,6(u+1)^5],[0,P'(u)]].
```

Every insertion M_u' has rank one, but there are m insertions. Thus differentiation does not stay inside the original two-dimensional transfer solution space.

The same failure appears directly in the continuants. Define K_h by (1.1), put

```text
a = r+h,
```

and differentiate

```text
N_{h+1} = P(a)N_h-a^6N_{h-1}.
```

A direct calculation gives the exact inhomogeneous recurrence

```text
K_{h+1}
 = (a+1)P(a)K_h
   -a^7(a+1)K_{h-1}
   +3L_h[(17a^2+16a+4)N_h-a^5N_{h-1}].                (1.4)
```

The last line is a genuine source term. Thus the usual hope

```text
"differentiate and remain in the span of N_h,N_{h-1}"
```

fails in its naive form. There may be additional special identities, but neither the transfer derivative nor the three-term recurrence supplies a bounded-rank derivative closure.

## 2. Fiber-product genus formula

Let f and g be separable rational maps P^1 -> P^1 of degrees m and n. For a target value a, write the ramification partitions as

```text
(e_1,...,e_r) for f^{-1}(a),
(f_1,...,f_s) for g^{-1}(a).
```

At a point with local equation

```text
u^{e_i} = v^{f_j},
```

the normalization has gcd(e_i,f_j) branches. The standard Riemann-Hurwitz calculation yields

```text
2g-2
 = -2mn
   + sum_a [mn - sum_{i,j} gcd(e_i,f_j)].               (2.1)
```

Equivalently, start with the disjoint-branch generic genus

```text
(m-1)(n-1)
```

and, for every common branch value a, subtract one half of

```text
D_a
 = sum_{i,j}
     [e_i f_j-e_i-f_j+gcd(e_i,f_j)].                    (2.2)
```

For Delta_h, under simple finite zeros, the two universal branch partitions are

```text
over infinity:  (3,3,...,3), with h entries;
over 0:         (3,1,...,1), with 3h-3 entries equal to 1.
```

For a pair of triple indices, the summand in (2.2) is

```text
3*3-3-3+gcd(3,3) = 6.                                  (2.3)
```

Therefore the common value infinity lowers the genus by

```text
(1/2)*6hh' = 3hh',
```

and the common value 0 lowers it by another 3. If there are no other common branch values, then

```text
g
 = (3h-1)(3h'-1)-3hh'-3
 = 6hh'-3h-3h'-2.                                      (2.4)
```

This is the universal 9-to-6 quadratic collapse announced above.

### 2.1 Connectedness

[PROVED FOR THE SMALL PAIRS] Once the common branch locus is exactly {0,infinity}, the fiber products below are geometrically connected.

If the function fields were not linearly disjoint over the target field, their intersection would give a nontrivial common intermediate cover. By Luroth, that intermediate curve is P^1. Its branch locus is contained in {0,infinity}, so after coordinate changes the intermediate map is z -> z^d for some d>1.

But then every zero of either Delta map would have multiplicity divisible by d. Each of Delta_2, Delta_3, and Delta_4 has a simple finite zero. Hence d=1, a contradiction. Thus the normalization is connected and (2.1) computes one curve genus, not a sum over disconnected components.

```text
6hh'-3h-3h'-2.
```

The continuant family does force a genus collapse, but the source is completely visible:

```text
all poles have order 3,
```

That universal ramification lowers the leading coefficient from 9 to 6. It does not remove the product hh'.

The modular branch certificates make a stronger negative point. The finite nonzero branch locus of Delta_2 is disjoint from that of Delta_3 and Delta_4. Thus the maps are not all pullbacks from one fixed Belyi-like branch configuration.

A general low-genus theorem would require approximately O(hh') additional shared ramification beyond 0 and infinity. Nothing in the derivative recurrence (1.4), adjacent coprimality, or the transfer-product identity provides such shared branch values.

## 6. Consequence for pairwise Weil

For a geometrically irreducible curve of genus

```text
g_{h,h'} = O(hh'),
```

Weil gives, after the usual finite boundary corrections,

```text
#X_{h,h'}(F_p) = p+O(hh' sqrt(p)+h+h').                 (6.1)
```

Summing the error in (6.1) over 1 <= h,h' <= H gives

```text
sqrt(p) * sum_{h,h'<=H} hh'
 = O(H^4 sqrt(p)).                                       (6.2)
```

The COINC error budget is O(#S_H)=O(pH). Therefore pairwise Weil reaches that budget only when

```text
H^4 sqrt(p) <= pH,
H <= p^(1/6).                                            (6.3)
```

At H<=p^(1/6), the elementary bound

```text
sum_{h<=H} C_h <= (3/2)H^2+O(H)
```

is already stronger than anything obtained from this coincidence estimate. Hence the exact genus computation does not yield an unconditional energy improvement.

Even the previously hoped-for linear genus O(h+h') would only change (6.2) to O(H^3 sqrt(p)) and the range to H<=p^(1/4), which is still below the H=p^(1/3) point where the trivial root-degree sum ceases to dominate.

## 7. Structured subfamilies

### 7.1 The h=1 strip really is low genus

[PROVED IN SHAPE] In centered coordinates,

```text
Delta_1(x) = 8/x^3.
```

It is branched only over 0 and infinity. Consequently the fiber product

```text
Delta_1(x) = Delta_h(y)
```

is a cyclic cubic cover of the y-line. If the finite zeros of N_h are simple, formula (2.4) with h=1 gives

```text
g(X_{1,h}) = 3h-5.                                      (7.1)
```

Without squarefreeness, the genus can only drop further; it remains O(h).

Thus, after component control, pairwise Weil gives the partial strip estimate

```text
sum_{h=2}^H #X_{1,h}(F_p)
 = (H-1)p+O(H^2 sqrt(p)+H^2).                            (7.2)
```

For H<=p^(1/2), the error in (7.2) is O(pH), exactly the COINC scale.

But this strip contains only H-1 lag pairs. Full N_coinc(H) contains H^2 lag pairs. Therefore (7.2) controls a vanishing fraction of the family and gives no bound for the total coincidence energy.

The same observation holds whenever min(h,h') is bounded: the genus is automatically O(h+h'), but there are only O(H) such pairs.

### 7.2 Same-lag diagonal components

For h=h', the fiber product always contains the rational diagonal

```text
r=r'.
```

Across h<=H, these H components contribute O(pH), which is exactly the literal diagonal term already allowed in COINC.

Any additional graph component would come from a nontrivial deck transformation of Delta_h. Classifying such transformations is useful bookkeeping, but after removing the diagonal and any finite deck graphs, the residual same-lag component is not forced to have low genus.

### 7.3 Adjacent gaps

The proved identity

```text
gcd(N_h,N_{h+1})=1
```

says that the zero fibers do not share a common polynomial factor. It does not produce a common composition of Delta_h and Delta_{h+1}, and it does not lower the genus of

```text
Delta_h(r)=Delta_{h+1}(r').
```

There are only O(H) adjacent pairs. Even a hypothetical O(h) genus theorem for them would provide only a partial strip estimate, not full COINC.

### 7.4 Doubling gaps

The transfer factorization

```text
G_{2m}(s)=G_m(s+m)G_m(s)
```

gives the exact continuant identity

```text
U_{2m}(s)
 = U_m(s+m)U_m(s)
   -(s+m)^6 U_{m-1}(s+m+1)U_{m-1}(s).                  (7.3)
```

This is bilinear in four shifted continuant values. It is not a composition law

```text
Delta_{2m} = R_m o Delta_m.
```

Therefore it does not force a graph component or a low-genus common quotient for X_{m,2m}. Again there are only O(H) doubling pairs, so even a special bound on them would not control the H^2 family.

### 7.5 Partial COINC conclusion

The currently justified structured pieces are:

```text
literal same-lag diagonals: O(pH),
bounded-min strips: main O(pH), controllable error through H<=p^(1/2),
forced zero reflection points: O(H).
```

All are compatible with the COINC budget, but together they cover only O(H) of the O(H^2) lag pairs. The unresolved mass remains the genuinely two-growing-parameter family.

## 8. The decisive next computation

The single most decisive computation is a branch-value gcd scan, not another point-count scan.

For each h define

```text
L_h(r) = product_{j=1}^h(r+j),
K_h(r) = L_hN_h'-3L_h'N_h,
```

and define the squared finite branch-value polynomial

```text

 = squarefree part in Z of
   Res_r(K_h(r), Z L_h(r)^6-N_h(r)^2),                  (8.1)
```

after removing the factors corresponding to Z=0 and the pole fiber.

Because Delta_h is odd in the centered coordinate, squaring removes the sign pairing, and the expected degree is at most 2h-2.

Run the exact computation for all 2<=h<h'<=20 and record

```text
gcd_Q[Z](V_h,V_h'),
factorization of X_{h,h'},
geometric genus of every normalization component.
```

The decisive falsifiable statement is:

```text
[BRANCH-DISJOINTNESS]
For all distinct h,h' >= 2,
gcd(V_h,V_h') = 1.                                       (8.2)
```

If (8.2) holds through h,h'<=20 and the computed genera equal


then the low-genus route has a strong exact death certificate: the only systematic common ramification is 0 and infinity, so the genus is quadratically large.

If a nontrivial gcd appears, its factor immediately identifies the exceptional common branch values and the precise subfamily worth studying. This is much more informative than observing a low point count at a few primes.

My expected result is that (8.2) holds generically, with only finitely many small or symmetry-forced exceptions.
