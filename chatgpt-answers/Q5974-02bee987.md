ANSWER Q5974 02bee987

```plain text
Definitions.

For k >= 1:
  C_k := binom(2*k, k)
  H2_(k-1) := sum_{j=1}^{k-1} 1/j^2

A := sum_{k=1}^infinity 1/(k^4 * C_k)
B := sum_{k=1}^infinity H2_(k-1)/(k^2 * C_k)

For n >= 0 define:
  P_u(n)  := product_{j=1}^{n} (j^2 - u)
  P_4u(n) := product_{j=1}^{n} (j^2 - 4*u)
with the empty product equal to 1.

------------------------------------------------------------
LESHCHINER IDENTITY
------------------------------------------------------------

For |u| < 1:

sum_{m=1}^infinity (-1)^(m-1)/(m^2 - u)
=
(1/2) * sum_{k=1}^infinity
  [ 1/(k^2 * C_k)
    * (3*k^2 + u)/(k^2 - u)
    * product_{j=1}^{k-1} (1 - u/j^2) ].

Equivalently, since
  product_{j=1}^{k-1} (1 - u/j^2)
  = P_u(k-1)/((k-1)!)^2,
the right-hand summand is

(1/2)
* (1/(k^2 * C_k))
* ((3*k^2 + u)/(k^2 - u))
* (P_u(k-1)/((k-1)!)^2).

Leshchiner WZ pair, for n,k >= 0:

F_L(n,k,u)
:=
  (-1)^k * k! * P_u(n) * (n+k+1)
  ------------------------------------------------------------
  (2*n+k+1)! * ((n+k+1)^2 - u)

G_L(n,k,u)
:=
  (-1)^k * k! * P_u(n)
  * (3*(n+1)^2 + u + k^2 + 4*k*(n+1))
  -----------------------------------------------------------------
  2 * (2*n+k+2)! * ((n+k+1)^2 - u).

Telescoping convention:

F_L(n+1,k,u) - F_L(n,k,u)
=
G_L(n,k+1,u) - G_L(n,k,u).

Boundary values:

F_L(0,k,u)
=
(-1)^k / ((k+1)^2 - u).

For m := n+1:

G_L(n,0,u)
=
(1/2)
* 1/(m^2 * C_m)
* (3*m^2 + u)/(m^2 - u)
* product_{j=1}^{m-1} (1 - u/j^2).

Finite-rectangle telescoping:

sum_{n=0}^{N-1} sum_{k=0}^{K-1}
  [F_L(n+1,k,u) - F_L(n,k,u)]
=
sum_{n=0}^{N-1} sum_{k=0}^{K-1}
  [G_L(n,k+1,u) - G_L(n,k,u)],

hence

sum_{k=0}^{K-1} [F_L(N,k,u) - F_L(0,k,u)]
=
sum_{n=0}^{N-1} [G_L(n,K,u) - G_L(n,0,u)].

After N -> infinity and K -> infinity, the outer boundary terms vanish,
and the displayed Leshchiner identity follows.

Derivatives at u = 0.

Let
  R_k(u) := (3*k^2 + u)/(k^2 - u),
  S_k(u) := product_{j=1}^{k-1} (1 - u/j^2).

Then
  R_k(0)  = 3,
  R_k'(0) = 4/k^2,
  S_k(0)  = 1,
  S_k'(0) = -H2_(k-1).

Therefore

d/du at u=0 of
  [(1/2) * 1/(k^2*C_k) * R_k(u) * S_k(u)]
=
(1/2) * 1/(k^2*C_k)
* [4/k^2 - 3*H2_(k-1)]
=
2/(k^4*C_k)
- (3/2)*H2_(k-1)/(k^2*C_k).

On the left:

d/du at u=0 of [(-1)^(m-1)/(m^2-u)]
=
(-1)^(m-1)/m^4.

Thus

sum_{m=1}^infinity (-1)^(m-1)/m^4
=
2*A - (3/2)*B.

Using
  sum_{m=1}^infinity (-1)^(m-1)/m^4
  = (1 - 2^(1-4))*zeta(4)
  = (7/8)*zeta(4),
we get

(L)   (7/8)*zeta(4) = 2*A - (3/2)*B.

------------------------------------------------------------
BAILEY-BORWEIN-BRADLEY IDENTITY
------------------------------------------------------------

For |u| < 1/4:

sum_{m=1}^infinity 1/(m^2 - u)
=
3 * sum_{k=1}^infinity
  [ 1/(C_k * (k^2 - u))
    * product_{j=1}^{k-1} ((j^2 - 4*u)/(j^2 - u)) ].

BBB WZ pair, for n,k >= 0:

F_B(n,k,u)
:=
  (n!)^2 * P_u(k) * P_4u(n)
  ----------------------------------
  (2*n)! * P_u(n+k+1)

G_B(n,k,u)
:=
  P_u(k) * P_4u(n) * n! * (n+1)! * (3*n+3+2*k)
  ---------------------------------------------------
  P_u(n+k+1) * (2*n+2)!.

Telescoping convention:

F_B(n+1,k,u) - F_B(n,k,u)
=
G_B(n,k+1,u) - G_B(n,k,u).

Boundary values:

F_B(0,k,u)
=
1 / ((k+1)^2 - u).

For m := n+1:

G_B(n,0,u)
=
3
* 1/(C_m * (m^2-u))
* product_{j=1}^{m-1} ((j^2 - 4*u)/(j^2 - u)).

Finite-rectangle telescoping:

sum_{n=0}^{N-1} sum_{k=0}^{K-1}
  [F_B(n+1,k,u) - F_B(n,k,u)]
=
sum_{n=0}^{N-1} sum_{k=0}^{K-1}
  [G_B(n,k+1,u) - G_B(n,k,u)],

hence

sum_{k=0}^{K-1} [F_B(N,k,u) - F_B(0,k,u)]
=
sum_{n=0}^{N-1} [G_B(n,K,u) - G_B(n,0,u)].

After N -> infinity and K -> infinity, the outer boundary terms vanish,
and the displayed BBB identity follows.

Derivatives at u = 0.

Let
  T_k(u) := 1/(k^2-u),
  Q_k(u) := product_{j=1}^{k-1} ((j^2 - 4*u)/(j^2-u)).

Then
  T_k(0)  = 1/k^2,
  T_k'(0) = 1/k^4,
  Q_k(0)  = 1.

For each j >= 1:

d/du at u=0 of [(j^2 - 4*u)/(j^2-u)]
=
-3/j^2.

Therefore
  Q_k'(0)
  = sum_{j=1}^{k-1} (-3/j^2)
  = -3*H2_(k-1).

Hence

d/du at u=0 of
  [3 * 1/C_k * T_k(u) * Q_k(u)]
=
3/C_k * [1/k^4 - 3*H2_(k-1)/k^2]
=
3/(k^4*C_k)
- 9*H2_(k-1)/(k^2*C_k).

On the left:

d/du at u=0 of [1/(m^2-u)]
=
1/m^4.

Thus

(BBB)   zeta(4) = 3*A - 9*B.

------------------------------------------------------------
SOLVING THE LINEAR SYSTEM
------------------------------------------------------------

Let Z := zeta(4).

(L):
  (7/8)*Z = 2*A - (3/2)*B.
Multiply by 8:
  7*Z = 16*A - 12*B.                         (1)

(BBB):
  Z = 3*A - 9*B.                              (2)

Multiply (2) by 4:
  4*Z = 12*A - 36*B.                          (3)

Subtract (3) from (1):
  3*Z = 4*A + 24*B.                           (4)

From (2):
  3*A = Z + 9*B,
  A = Z/3 + 3*B.

Substitute into (4):
  3*Z = 4*(Z/3 + 3*B) + 24*B
      = 4*Z/3 + 36*B.

Therefore
  5*Z/3 = 36*B,
  B = 5*Z/108.

Then
  A = Z/3 + 3*(5*Z/108)
    = 36*Z/108 + 15*Z/108
    = 51*Z/108
    = 17*Z/36.

Final values:

A = (17/36)*zeta(4).
B = (5/108)*zeta(4).

Check of the BBB combination:

3*A - 9*B
=
3*(17/36)*Z - 9*(5/108)*Z
=
17/12*Z - 5/12*Z
=
Z.
```
