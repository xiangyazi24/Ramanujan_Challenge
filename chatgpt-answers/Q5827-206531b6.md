# Verdict

The elementary reciprocal/palindromic route is worth isolating, but it does not currently replace the Bloch/extended-Bloch route. The exact A-polynomial has some reciprocal structure, and several useful finite algebraic identities exist, but the differential

[

omega=log x,dlog y-log y,dlog x

]

does not appear to be the differential of a single elementary algebraic potential in the endpoint variables. The remaining obstruction is a genuine dilogarithmic one.

The actionable Lean conclusion is:

- formalize reciprocal polynomial reductions and exact endpoint identities;

- do not pursue a full elementary antiderivative unless a new finite identity is found;

- keep the regulator proof interface as the realistic route.

# 1. Reciprocal variables

The endpoint minimal polynomials in SUBMIT/3.1/solution.tex are palindromic:

[

f(z)=z^d f(1/z).

]

Therefore the natural substitutions are

[

p=x+x^{-1},qquad q=y+y^{-1}.

]

For the endpoint fields this is already exploited: the alpha polynomial factors through

[

g_alpha(p)=p^6-3p^5-2p^4+10p^3-p^2-7p+1.

]

This is a genuine finite certificate:

```plain text
f_alpha(x) = x^6 g_alpha(x+x^{-1})
```

and similarly for beta.

Lean target:

```javascript
theorem falpha_reciprocal :
  f_alpha x = x^6 * g_alpha (x + x⁻¹)
```

under x ≠ 0.

Useful Mathlib:

- Polynomial.eval

- field_simp

- ring

- Polynomial.ext

This part is realistic.

# 2. Does the whole A-curve reduce to p,q?

The obstruction is that the full A-polynomial is not merely the endpoint minimal polynomial. The curve relation

[

A(M,L)=0

]

has reciprocal behavior, but after setting

[

p=M+M^{-1},qquad q=L+L^{-1},

]

one does not obtain a low-degree polynomial relation sufficient to remove both logarithms.

The form becomes

[

log M,dlog L-log L,dlog M,

]

while the reciprocal variables only retain the symmetric combinations. They lose the sign information of the logarithms.

A necessary extra variable is something like

[

r=M/L

]

or

[

M-L,

]

but then the curve no longer collapses to a simple rational parametrization.

Conclusion:

reciprocal symmetry helps with the endpoint field, not with the path integral.

# 3. Search for an elementary potential

Suppose there were an algebraic potential

[

F(x,y)

]

with

[

dF=log x,dlog y-log y,dlog x.

]

Locally this would require cancellation of the logarithmic periods. But

[

d(log x,dlog y-log y,dlog x)

=2,dlog xwedge dlog y,

]

so the form is not closed on the ambient two-dimensional torus.

Only after restriction to the algebraic curve can it become integrable. The resulting primitive is exactly the classical dilogarithmic regulator primitive, not an algebraic/rational one.

Therefore an elementary algebraic primitive is unlikely unless the curve has an exceptional parametrization.

# 4. Dilogarithm identities that actually exist

The viable elementary reductions are not for the whole integral, but for the endpoint Rogers terms.

The standard identities are:

[

D(bar z)=-D(z),

]

[

Dleft(frac1{1-z}right)=D(z),

]

[

D(z)=0quad(zinmathbb R).

]

For the endpoint shapes:

[

T,Uinmathbb R,

]

and

[

W=frac1{1-bar V},

]

so

[

D(V)+D(W)=0.

]

This is the real cancellation certificate.

It is finite and Lean-friendly if the Bloch-Wigner laws are imported as an interface.

# 7. Concrete next experiment

If continuing the elementary route, the only promising finite search is:


# Final assessment

The reciprocal/palindromic idea gives real progress:

- endpoint field reduction: YES;

- embedding analysis: YES;

- shape cancellation: YES;

- elementary integral evaluation: no evidence.

The remaining obstruction is not computational. It is structural: the primitive of the symplectic logarithmic form on an algebraic curve is a dilogarithmic object. The smallest Lean certificate is therefore a finite extended-Bloch cancellation certificate, not an elementary antiderivative.
