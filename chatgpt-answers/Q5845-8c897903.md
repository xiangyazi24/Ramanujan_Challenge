## 2. Symplectic coefficient calculation

For each shape define

\omega(z)=\frac12(\log|z|d\log|1-z|-\log|1-z|d\log|z|).

Using the four rows above and collecting coefficients in the basis

dR,dT_0,dA,dX_0,dP,dQ,

one obtains:

```javascript
T:  1/2*(T0 d(2R)-2R dT0)
U:  1/2*((R-T0)d(A-T0)-(A-T0)d(R-T0))
V:  1/2*((R-T0-X0)d(P-T0-X0)
       -(P-T0-X0)d(R-T0-X0))
W:  1/2*((T0-Q)d(R+X0-Q)
       -(R+X0-Q)d(T0-Q))
```

Expanding these antisymmetric terms gives the coefficient matrix. The six independent wedge coefficients are:

R\wedge T_0: 1,

R\wedge A: -\frac12,

R\wedge P: -\frac12,

R\wedge Q: -\frac12,

T_0\wedge P: \frac12,

T_0\wedge Q: -\frac12,

with the remaining entries determined by antisymmetry.
