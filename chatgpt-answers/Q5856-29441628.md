## Theorem 2.1 — exact top-half marked carrier

For every sufficiently large n—and directly for all four rows audited below—

```plain text

 = rad_(n/2 < p <= n) gcd(b_n,C_n).
```

Equivalently, let


Then

```plain text
R_n
 = rad_(n/2 < p <= n)
     gcd(F_h(n),binom(n,h+1)).
```

### Proof

For n=p+r with 0<=r<p, Apéry–Lucas gives

```plain text
b_n = b_(p+r) = b_1 b_r = 5 b_r mod p.
```

For p>n/2, the central binomial coefficient has valuation one, except at the reflected boundary n=2p-1; that boundary is never a target because

```plain text

```

This proves the first identity.

For the interpolation version, p>h makes every k!, k<=h, a p-unit. If p divides N_h(n), there is a unique r in [0,h] with n=r mod p, and

```plain text
F_h(n)=F_h(r)=b_r mod p.
```

This proves the second identity.

This is already a global fixed-state resultant/Fitting presentation. Its defect is height, not selectivity: b_n, F_h(n), and the binomial carrier all have positive linear exponential scale.

# 7. Arithmetic-dynamics attempt: singularity confinement, not apparition

Write the Apéry recurrence as

```plain text

 = (34r^3+51r^2+27r+5)b_r-r^3b_(r-1).
```

For a target prime p>r+1, reduction at b_r=0 gives


Neither neighbor can vanish: two consecutive zeros would propagate backward to b_0=0, contradicting b_0=1.

In the projective Riccati coordinate


```plain text

```

The singularity is confined in one step. There is no period, order, or rank-of-apparition condition on p that persists along the orbit. Different target primes correspond to different times r=n-p, so a canonical height at one orbit point cannot couple them without multiplying over all possible times, which is the quadratic-height construction in Section 4.2.

Every target in the four required rows satisfies this exact confinement identity. Thus the arithmetic-dynamics proposal is falsified at the mechanism level, not merely by a failed numerical fit.

```python
from fractions import Fraction
from math import comb, gcd, isqrt, prod


def primes_upto(limit):
    mark = bytearray(b"\x01") * (limit + 1)
    mark[:2] = b"\x00\x00"
    for p in range(2, isqrt(limit) + 1):
        if mark[p]:
            mark[p*p:limit+1:p] = b"\x00" * ((limit-p*p)//p + 1)
    return [p for p in range(2, limit + 1) if mark[p]]


def apery_and_companion(limit):
    b = [1, 5]
    a = [Fraction(0), Fraction(6)]
    for r in range(1, limit):
        P = 34*r**3 + 51*r**2 + 27*r + 5
        den = (r + 1)**3
        b.append((P*b[r] - r**3*b[r-1]) // den)
        a.append((P*a[r] - r**3*a[r-1]) / den)
    return b[:limit+1], a[:limit+1]


def newton_value(values, h, x):
    row = list(values[:h+1])
    coeffs = []
    while row:
        coeffs.append(row[0])
        row = [row[i+1] - row[i] for i in range(len(row)-1)]
    return sum(coeffs[k] * comb(x, k) for k in range(h + 1))


def top_radical_of_gcd(x, y, n, primes):
    out = 1
    for p in primes:
        if 2*p > n and x % p == 0 and y % p == 0:
            out *= p
    return out


ROWS = {
    200: {
        "targets": (139, 181),
        "H_extra": 2*3*5*7**2*17*29*101,
        "T_extra": 2**16*3**6*5**2,
        "hybrid_extra": 30,
    },
    272: {
        "targets": (191, 233),
        "H_extra": 2**3*5**2*11*137,
        "T_extra": 2**17*3**7*5**3*263*269*271,
        "hybrid_extra": 200,
    },
    300: {
        "targets": (191, 227),
        "H_extra": 2*3*11*61,
        "T_extra": 2**16*3**7*5**2*11,
        "hybrid_extra": 66,
    },
    321: {
        "targets": (179, 193, 211),
        "H_extra": 2**3*3*5,
        "T_extra": 2**16*3**8*5,
        "hybrid_extra": 120,
    },
}

limit = max(ROWS)
primes = primes_upto(limit)
b, a = apery_and_companion(limit + 1)

for n, expected in ROWS.items():
    targets = tuple(
        p for p in primes
        if 2*p > n and p <= n and b[n-p] % p == 0
    )
    assert targets == expected["targets"]
    R = prod(targets)

    # Central-binomial fixed-state carrier.
    central = comb(n, n // 2)
    assert top_radical_of_gcd(b[n], central, n, primes) == R

    # Marked Newton/resultant carrier.
    h = (n - 1) // 2
    F = newton_value(b, h, n)
    marked_binomial = comb(n, h + 1)
    assert top_radical_of_gcd(F, marked_binomial, n, primes) == R

    # Fixed companion: normalized Casoratian is 6 and every target is a unit.
    for p in targets:
        r = n - p
        cas = (r + 1)**3 * (a[r+1]*b[r] - a[r]*b[r+1])
        assert cas == 6
        assert a[r].denominator % p != 0
        assert a[r].numerator % p != 0
        assert b[r+1] % p != 0
        assert ((r+1)**3*b[r+1] + r**3*b[r-1]) % p == 0

    # Exact intersection of the two committed fixed-state audits.
    H = R * expected["H_extra"]
    T = R * expected["T_extra"]
    hybrid = gcd(H, T)
    assert hybrid == R * expected["hybrid_extra"]
    print(n, targets, R, hybrid, hybrid.bit_length())
```
