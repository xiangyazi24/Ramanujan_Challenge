# Audit verdict

## Setup and normalizations

The orthogonality identity is correctly normalized:

Z_W = sum_d W(d) sum_r 1[det(v_r,v_{r+d})=0]
    = sum_d W(d) + (1/p) sum_{t != 0} B_W(t),

because for each nonzero determinant value the additive character average over t vanishes, while zero determinant contributes p.

The cyclic majorization is valid provided the extension of v_r is genuinely defined for all r in F_p and W is supported as a function on the cyclic difference group. Since W >= 1_J and the original shell has only nonwrapping pairs, every physical collision is counted. Extra cyclic pairs only increase Z_W. No wrap flaw exists in the majorization itself.

The danger is elsewhere: one must not identify the cyclic count with the physical count after this step.

# (1) Sharp interval weight

For W=1_J, the standard interval Fourier estimate gives

||What||_1 = O(p log p).

Also

B_W(t) = (1/p) sum_xi What(-xi) F_t(xi).

Therefore a complete-transform estimate

max_xi |F_t(xi)| <= C p

would imply

|B_W(t)| <= C p^{-1} ||What||_1 p = O(p log p).

This implication is correct.

However the premise is the missing theorem. It is not a consequence of completion alone. Completion only changes the d-variable; it does not control the complete d-Fourier transform of the correlation family

F_t(xi)=sum_{r,d} psi(t det(v_r,v_{r+d})+xi d).

The trivial bound is p^2, giving only O(p^2 log p) after completion. Hence the bounded-conductor/Radon lemma is the actual missing input.

# (2) Smoothed convolution weight

The proposed construction is valid.

Take intervals A,C in the cyclic group with

|A|=2q-1, |C|=q,

chosen so that the convolution multiplicity

m(x)=1_A*1_C(x)

satisfies

m(x)=q on J.

Then

W=q^{-1}m

is nonnegative, W>=1_J, and

sum_x W(x)=q^{-1}|A||C|=2q-1.

The Fourier transform normalization gives

What(xi)=q^{-1} 1_Ahat(xi)1_Chat(xi).

By Parseval and Cauchy-Schwarz,

||What||_1 <= p (sum_xi |What(xi)|^2)^{1/2}

and

sum_xi |What(xi)|^2 = p sum_x W(x)^2.

For the interval convolution triangle, the claimed estimate

||What||_1 <= p sqrt((2q-1)/q) < sqrt(2)p

is consistent: it uses

sum W^2 <= (2q-1)/q.

No cyclic wrap error appears if A,C are chosen in the cyclic group and the interval containing J is allowed to wrap consistently. The only requirement is exact q-fold coverage on J; a naive integer convolution embedded in F_p without checking boundary can fail. The construction needs that check.

Under the same missing complete bound |F_t|<=Cp,

|B_W(t)| <= p^{-1} ||What||_1 Cp = O(p),

so the logarithm is removed conditionally.

# (3) Mean bound implies collision saving

Let

S = sum_{r,d} W(d)1[det=0].

Then

S <= sum W + (1/p) sum_{t!=0}|B_W(t)|.

If uniformly

mean_{t!=0}|B_W(t)| <= p^{1-kappa+o(1)},

then

sum_{t!=0}|B_W(t)| <= p^{2-kappa+o(1)}.

Hence

S <= O(q) + p^{1-kappa+o(1)}.

Since q~D, this gives

S <= D + p^{1-kappa+o(1)}.

The target is S=O(D^{2-eta}). Because D=p^{1/2+o(1)},

D^{2-eta}=p^{1-eta/2+o(1)}.

The error term is bounded by this when

1-kappa <= 1-eta/2,

so

eta <= 2kappa.

The main term D is bounded by D^{2-eta} whenever

1/2 <= 1-eta/2,

so

eta <= 1.

Therefore any fixed power saving gives

eta < min(1,2kappa)

(up to absorbing o(1) terms).

A logarithmic saving, for example p/(log p)^A, gives only

D^{2}(log p)^{-A},

which is not O(D^{2-eta}) for any fixed eta>0. It is insufficient.

# (4) Square-root scale comparison

The desired analytic scale is roughly

sqrt(pD)=p^{3/4+o(1)}

because D=p^{1/2+o(1)}.

The incidence target from the power-saving mean is

D^{2-eta}=p^{1-eta/2+o(1)}.

For a genuine saving, these scales are not competing in the same range: square-root cancellation is stronger whenever

3/4 < 1-eta/2,

namely

eta < 1/2.

Thus a square-root incidence estimate would imply the desired result for all eta<1/2. The L factors are subpolynomial and do not alter the exponent comparison.
