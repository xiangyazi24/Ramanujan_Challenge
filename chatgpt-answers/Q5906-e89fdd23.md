# Low-height certificate audit for K_{hyb}

## 1. Exact reduction

The six-column Smith reduction does not by itself give a height theorem. The rigorous reduction is:

[

K_{hyb}mid C_{norm},delta_m,rho_-rho_+,gcd(B_-,B_+),

]

where C_{norm} contains the fixed local normalizers and Pascal multipliers. The target-prime part is not carried by the normalizers: after saturation the only possible large target contribution is the primitive boundary content.

The key missing statement is therefore not a determinant bound but a primitive-content cancellation theorem:

[

operatorname{rad}gcd(B_-,B_+)mid R(n)

]

with \log R(n)=o(n).

## 2. Why naive resultant bounds fail

If one forms a resultant from the Ore syzygy

[

A_MU=QL,

]

or from exterior-state recurrences, the coefficient heights of transition products grow exponentially because the order is fixed but the shift length is O(n). Hadamard gives bounds of the form

[

exp(O(n))

]

which are too large. The required cancellation must happen before taking a determinant.

## 3. Correct candidate object

The useful object is a saturated Fitting ideal, not the raw resultant:

[

I=(E_{d,L},E_{d+1,L},ldots,E_{d+m-1,L}) : J^infty,

]

where J is generated by the universal Pascal/node factors.

A sufficient lemma is:

Primitive exterior-content lemma. After saturation by J, a fixed-size adjacent-margin Pluecker lattice has a generator

[

R(n,D,N)=prod_i ell_i(n,D,N)^{e_i}cdot c,

]

where c and the list of linear forms \ell_i are independent of the block width and

[

log |R|=O((log n)^2).

]

This lemma would imply the desired \log |K_{hyb}|=o(n).

## 4. Bezout/Pluecker route

The promising identity is not a high-degree resultant. One should construct an integral Bezout chain among adjacent minors:

[

sum_i a_i(n)E_i = R(n,D,N),

]

where the a_i are obtained from Pascal finite differences and the coefficient-height ledger satisfies

[

log max |a_i|=O(log n).

]

The current obstruction is proving this ledger. Without it the identity is only formal.

## 5. Status of the proposed theorem

Proved:

- every safe top-half target divides K_{hyb};

- ghost determinants remove the linear Ore alias;

- six-column Smith reduction isolates all non-target factors.

Not proved:

- the saturated primitive content has polynomial height;

- the ambient Pascal primorial cancels completely.

Thus the sharp terminal lemma is exactly the Primitive exterior-content lemma above. A counterexample would be a sequence of blocks where the saturated Pluecker generator retains a prime product of height \Omega(n); none is known from the supplied data, but no theorem currently excludes it.
