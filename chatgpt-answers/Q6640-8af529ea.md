# qSIX: sixth moment audit, exact expansion, and the fixed-index death certificate

Repo state inspected: xiangyazi24/Ramanujan_Challenge, including the merged COINC section in problems/3.2/FABLE_SECTION_coinc_target.tex at commit e54864f7967776a973215cadf17b8e3c1b5cd8c8, the cross-correlation experiment recording PAIR-FLAT behavior, and the full Q6613 spectral calibration.

## Executive verdict

The sixth moment is indeed the first natural Wigner-scale moment that gives a genuine power saving below p^2 at H=p^(2/3). The exact consequence is

```plain text
[TR6]  Tr((O O*)^3) << H^4 p^9

=> ||O||_op << H^(2/3) p^(3/2).
```

At H=p^(2/3) this is

```plain text
||O||_op << p^(35/18) = p^(2-1/18),
```

so the sixth moment leaves exactly a p^(1/18) margin below the p^2 COINC threshold. It remains sufficient all the way to H=p^(3/4), where it reaches p^2 exactly.

There are, however, two decisive corrections to the proposed geometry.

1. Tr((O O*)^3) does not produce a six-base, three-equation variety. Since O is the off-diagonal part of the Gram matrix, its sixth moment contains six Gram correlations. Each Gram correlation has two independent base variables. The exact object has twelve base variables and six value-equality constraints. For fixed gap indices it is a Cartesian product of six difference curves, of dimension six.

1. The natural trace bound does not imply the random-optimal norm sqrt(H) p^(3/2). It implies H^(2/3) p^(3/2), worse by H^(1/6). That loss is still small enough to leave p^(1/18) of room at H=p^(2/3).

The fixed-index question has a clean negative answer. Even granting the strongest conceivable conductor-free pair estimate

```plain text
|Gamma_hk| << p^(3/2)  for every h != k,
```

estimating every fixed closed cycle separately and then summing absolute values gives H^6 p^9, whereas [TR6] allows only H^4 p^9. It loses H^2. Generic Weil bounds lose much more. For the natural 2q-th moment, the corresponding loss is H^(q-1), even under perfect PAIR-FLAT. Thus no finite moment closes by fixed-index algebraic geometry plus the triangle inequality.

This is not a death certificate for the spectral moment method itself. It is the final death certificate for its fixed-index implementation. The surviving input is a genuinely horizontal, signed closed-cycle cancellation theorem over the gap labels.

## 1. Exact setup

For 1 <= h <= H, write

```plain text
I_h = {1,...,M-h},
n_h = |I_h|,
delta_h(r) = Delta_{r,h},
S_h(t) = sum_{r in I_h} e_p(t delta_h(r)).
```

Let

```plain text
J_hk = #{(r,s) in I_h x I_k : delta_h(r)=delta_k(s)}.
```

The Gram matrix is

```plain text
Gamma_hk
  = sum_{t != 0} S_h(t) conjugate(S_k(t))
  = p J_hk - n_h n_k.
```

It is real symmetric and positive semidefinite. Put

```plain text
D = diag(Gamma_11,...,Gamma_HH),
O = Gamma-D.
```

Thus

```plain text
O_hk = Gamma_hk  if h != k,
O_hh = 0.
```

Since O is Hermitian,

```plain text
Tr((O O*)^3) = Tr(O^6).
```

This equality is useful, but the alternating O O* form makes the index pattern completely explicit.

## 2. The exact closed six-cycle

For a general complex matrix, expansion gives

```plain text
Tr((O O*)^3)
 = sum_{a,b,c,u,v,w}
     O_au conjugate(O_bu)
     O_bv conjugate(O_cv)
     O_cw conjugate(O_aw).
```

Every displayed pair of indices must be distinct because O_hh=0.

Set

```plain text
h1=a, h2=u, h3=b, h4=v, h5=c, h6=w, h7=h1.
```

Hermitian symmetry turns the product into

```plain text
O_(h1,h2) O_(h2,h3) O_(h3,h4)
O_(h4,h5) O_(h5,h6) O_(h6,h1).
```

Therefore the exact gap-index formula is

```plain text
T6 := Tr((O O*)^3)
   = sum_{
       1<=h1,...,h6<=H,
       h_j != h_(j+1) cyclic
     }
       prod_{j=1}^6 Gamma_(h_j,h_(j+1)).
```

This is a signed sum over closed length-six walks on the loopless gap graph.

### 2.1 Exponential-sum expansion

For each edge of the cycle introduce an independent nonzero frequency t_j. Then

```plain text
T6
 = sum_{h-cycle}
   sum_{t1,...,t6 != 0}
   prod_{j=1}^6
     S_(h_j)(t_j) conjugate(S_(h_(j+1))(t_j)).
```

Expand every trace sum. For edge j, introduce

```plain text
x_j in I_(h_j),
y_j in I_(h_(j+1)).
```

There are twelve independent base variables. The phase is

```plain text
sum_{j=1}^6 t_j
  (delta_(h_j)(x_j)-delta_(h_(j+1))(y_j)).
```

Using

```plain text
sum_{t != 0} e_p(t z) = p 1[z=0]-1,
```

one obtains the exact centered-incidence identity

```plain text
T6
 = sum_{h-cycle}
   sum_{x_1,y_1,...,x_6,y_6}
   prod_{j=1}^6
   (
     p 1[delta_(h_j)(x_j)=delta_(h_(j+1))(y_j)]-1
   ).
```

This is the correct coincidence-variety form. It is a signed inclusion-exclusion expression, not a raw point count.

The top stratum imposes the six equations

```plain text
delta_(h1)(x1)=delta_(h2)(y1),
delta_(h2)(x2)=delta_(h3)(y2),
...
delta_(h6)(x6)=delta_(h1)(y6).
```

For a fixed gap six-tuple, the twelve base variables are independent across the six equations. Hence the top variety is

```plain text
V_(h1,...,h6)
 = X_(h1,h2) x X_(h2,h3) x ... x X_(h6,h1),
```

where

```plain text
X_(a,b) : delta_a(x)=delta_b(y).
```

It is a Cartesian product of six curves and has dimension six.

### 2.2 Histogram form

Let

```plain text
nu_h(z) = #{r in I_h : delta_h(r)=z},
x_h(z)  = nu_h(z)-n_h/p.
```

Then

```plain text
Gamma_hk = p sum_{z in F_p} x_h(z)x_k(z).
```

Consequently

```plain text
T6
 = p^6 sum_{h-cycle}
       sum_{z1,...,z6 in F_p}
       prod_{j=1}^6
       x_(h_j)(z_j)x_(h_(j+1))(z_j).
```

This version has six value variables, but still not six base variables. At each gap vertex h_j, the two histogram factors involve the incoming value z_(j-1) and outgoing value z_j.

### 2.3 Where the proposed six-base object actually occurs

A six-base, three-equality formula occurs for a cubic Gram expression such as

```plain text
Tr(Gamma^3)
```

or, after deleting diagonal terms, the signed quantity Tr(O^3). It has three Gram factors, hence six bases and three equality conditions.

It is not the sixth singular moment. Tr(O^3) can have large cancellation between positive and negative eigenvalues and does not bound ||O||_op. Tr(Gamma^3) is positive, but the diagonal Gamma_hh ~ p^2 forces

```plain text
Tr(Gamma^3) >= H p^6,
```

which yields only ||Gamma||_op <= H^(1/3)p^2. It cannot prove the required O(p^2) operator bound.

Thus identifying incoming and outgoing bases at a gap vertex would replace the actual sixth moment by a thin diagonal subvariety. It is not an exact expansion and cannot be used.

## 3. Random scale, forced lower scale, and [TR6]

In the calibrated random model,

```plain text
S_h(t)/sqrt(p)
```

behaves like an O(1) centered random variable, independently across h to first order. Hence an off-diagonal Gram entry has variance of order

```plain text
p terms x p^2 per term = p^3,
```

so

```plain text
|O_hk| typical ~ p^(3/2).
```

An H x H Wigner-type matrix with entry variance p^3 has spectral radius of order

```plain text
sqrt(H) p^(3/2).
```

Its sixth trace has scale

```plain text
H x (sqrt(H)p^(3/2))^6 = H^4 p^9.
```

For an ideal Wigner matrix the leading constant is the Catalan number 5; the thin-Wishart origin of the present Gram matrix can alter constants and lower-order contractions, but not the exponent H^4 p^9.

### 3.1 A deterministic diagonal lower bound

Let

```plain text
A = O O*,
R_h = A_hh = sum_{k != h}|O_hk|^2.
```

Since A is positive semidefinite, Schur-Horn plus convexity gives

```plain text
Tr(A^3) >= sum_h R_h^3.
```

Then Holder gives

```plain text
sum_h R_h^3
 >= H^(-2) (sum_h R_h)^3
 = H^(-2) (Tr(O O*))^3.
```

Therefore

```plain text
Tr((O O*)^3)
 >= H^(-2)
    (sum_{h != k}|O_hk|^2)^3.
```

If the observed pair-flat second moment has its random size

```plain text
sum_{h != k}|O_hk|^2 ~ H^2 p^3,
```

then this lower bound is already

```plain text
H^4 p^9.
```

Thus [TR6] is not merely a convenient upper target. It is the smallest possible scale compatible with the measured second moment.

By contrast, the Frobenius inequality gives only

```plain text
Tr((O O*)^3)
 <= (Tr(O O*))^3
 ~ H^6 p^9.
```

The sixth-moment theorem must save exactly H^2 over this automatic bound.

### 3.2 Exact target

The correct raw target is

```plain text
[TR6]
Tr((O O*)^3) <= C H^4 p^9
```

with an absolute constant C, uniformly in the desired range of H.

If classified off-diagonal component aliases produce entries of order p^2, use the robust version

```plain text
O = O_struct + O_reg,
||O_struct||_op << p^2,
Tr((O_reg O_reg*)^3) << H^4 p^9.
```

A single p^2 off-diagonal entry can already contribute at the p^12 sixth-power scale, larger than H^4p^9 when H=p^(2/3). Such entries must be peeled off rather than hidden in [TR6].

### 3.3 Operator consequence

From the Schatten bound,

```plain text
||O||_op^6 <= Tr((O O*)^3).
```

Hence [TR6] gives

```plain text
||O||_op
 <= C^(1/6) H^(2/3) p^(3/2).
```

This is not the random-optimal sqrt(H)p^(3/2). The moment conversion loses

```plain text
H^(2/3)/H^(1/2)=H^(1/6).
```

Nevertheless it is enough whenever

```plain text
H^(2/3)p^(3/2) <= p^2,
```

i.e.

```plain text
H <= p^(3/4).
```

For H=p^beta, the exponent is

```plain text
3/2 + 2 beta/3,
```

and the saving below p^2 is

```plain text
delta(beta)=1/2-2 beta/3=(3-4 beta)/6.
```

At the campaign scale beta=2/3,

```plain text
delta(2/3)=1/18,
||O||_op << p^(35/18)=p^(2-1/18).
```

The true random norm would be

```plain text
sqrt(H)p^(3/2)=p^(11/6)=p^(2-1/6).
```

Thus the sixth trace loses p^(1/9) relative to the random norm, but still retains p^(1/18) relative to the theorem threshold.

### 3.4 Consequence for COINC

Recall

```plain text
1^T Gamma 1
 = sum_h D_hh + 1^T O 1,
|1^T O 1| <= H ||O||_op.
```

Under the diagonal budget

```plain text
sum_{h<=H}D_hh << p^2 H,
```

[TR6] gives at H=p^(2/3)

```plain text
H ||O||_op << p^2 H p^(-1/18).
```

Hence the off-diagonal contribution to the COINC constant is o(1). The diagonal supplies the limiting absolute constant.

More generally, [TR6] plus the diagonal budget proves COINC for every H<=p^(3/4). At the endpoint H=p^(3/4) the off-diagonal contribution is merely O(1), still sufficient. Through the merged conditional COINC theorem, a hypothetical [TR6] theorem at H=p^(3/4) would yield

```plain text
F_p << p^(5/4+o(1)),
```

while the needed H=p^(2/3) case yields

```plain text
F_p << p^(4/3+o(1)).
```

## 4. Fixed-index geometry: the honest exponent calculation

For distinct gaps a,b, the difference curve

```plain text
X_(a,b) : delta_a(x)=delta_b(y)
```

has bidegree of order (3a,3b). Its generic genus is O(ab). After removing classified component main terms, a fixed-pair Weil estimate has the shape

```plain text
E_ab := J_ab-n_a n_b/p
       << ab sqrt(p),
```

and therefore

```plain text
Gamma_ab = p E_ab << ab p^(3/2).
```

For a fixed closed six-tuple, the product estimate is

```plain text
prod_{j=1}^6 |Gamma_(h_j,h_(j+1))|
 << p^9 prod_{j=1}^6 (h_j h_(j+1))
 =  p^9 prod_{j=1}^6 h_j^2.
```

Summing over all six gap labels gives

```plain text
sum_{h1,...,h6<=H} prod_j h_j^2
 = (sum_{h<=H}h^2)^6
 << H^18.
```

Thus generic fixed-pair Weil plus absolute summation gives

```plain text
T6 << H^18 p^9,
```

where [TR6] requires only H^4p^9. The loss is H^14.

At H=p^(2/3), these scales are

```plain text
generic fixed-pair bound: p^21,
[TR6] budget:             p^(35/3),
loss:                     p^(28/3).
```

### 4.1 Optimistic genus collapse still fails

Suppose, far more optimistically, that every pair correlation satisfies either

```plain text
|E_ab| << (a+b)sqrt(p)
```

or the random-angle improvement

```plain text
|E_ab| << sqrt(ab)sqrt(p).
```

In either case the six-edge absolute sum is at best

```plain text
T6 << H^12 p^9.
```

It still loses H^8 against [TR6]. At H=p^(2/3), it gives p^17, still far above p^(35/3).

### 4.2 Even perfect PAIR-FLAT still fails by H^2

Grant the strongest empirically supported pair estimate with no conductor cost:

```plain text
[PAIR-FLAT]
|E_ab| << sqrt(p),
|Gamma_ab| << p^(3/2),
```

uniformly for every pair a != b <= H.

Then each fixed six-cycle has size at most O(p^9), but there are O(H^6) cycles. Triangle inequality gives

```plain text
T6 << H^6 p^9.
```

This is still too large by exactly H^2.

At H=p^(2/3):

```plain text
PAIR-FLAT plus triangle: p^13,
[TR6] target:            p^(35/3),
loss:                    p^(4/3)=H^2.
```

This is the decisive calculation. Higher-dimensional fixed-index geometry cannot supply the missing H^2; only cancellation among different gap six-tuples can.

### 4.3 Why dimension does not buy extra square roots

For fixed gap indices, the top variety is the Cartesian product

```plain text
X_(h1,h2) x ... x X_(h6,h1).
```

Kunneth gives

```plain text
Tr(Frob on tensor product)
 = prod_j Tr(Frob on the j-th factor).
```

The centered factor

```plain text
p 1[delta_a(x)=delta_b(y)]-1
```

removes the trivial H^0 contribution of its curve. In the six-fold product, inclusion-exclusion removes every Kunneth tensor containing a trivial factor. The surviving top centered term is exactly the product of the six individual curve errors.

Therefore there is no new square-root cancellation created merely by placing the curves in a higher-dimensional product. The cohomology factorizes exactly.

A raw Lang-Weil estimate for the dimension-six product would read schematically

```plain text
#V = p^6 + O(B(h1,...,h6) p^(11/2)).
```

That estimate is much too coarse because it ignores the six-fold centering. After exact centering, the relevant Frobenius weight is the product of six weight-one curve traces, of size p^3 before the six exterior factors of p. Multiplying by those six factors gives the natural fixed-cycle scale p^9, exactly the same p-power as the global [TR6] budget. There is no spare power of p with which to pay for the H^6 index tuples.

### 4.4 The tempting dimension-three calculation and why it is irrelevant

If one incorrectly replaced the sixth singular moment by a six-base, three-equation complete intersection, then a fixed-tuple Lang-Weil error p^(5/2) and three orthogonality factors p^3 would give a per-tuple scale p^(11/2). Summed over H^6 tuples at H=p^(2/3), this is p^(19/2), apparently well below the [TR6] budget p^(35/3) before large degree costs.

That apparent gain is an artifact of using the wrong moment. The actual operator sixth moment has six Gram factors, six orthogonality sums, twelve bases, and six equations. Once the exact centering is performed, its fixed-tuple scale is p^9, not p^(11/2).

## 5. General even moments: no finite fixed-index closure

Let q>=1 and consider

```plain text
T_(2q)=Tr(O^(2q)).
```

The natural Wigner-scale target is

```plain text
[TR-2q]
Tr(O^(2q)) << H^(q+1) p^(3q).
```

It implies

```plain text
||O||_op
 << H^((q+1)/(2q)) p^(3/2)
 =  H^(1/2+1/(2q)) p^(3/2).
```

This reaches p^2 whenever

```plain text
H <= p^(q/(q+1)).
```

Thus

```plain text
q=1, second moment: range H<=p^(1/2),
q=2, fourth moment: range H<=p^(2/3),
q=3, sixth moment:  range H<=p^(3/4).
```

At H=p^(2/3), the saving supplied by the natural 2q-th moment is

```plain text
delta_q=(q-2)/(6q).
```

In particular

```plain text
q=2: delta_q=0,
q=3: delta_q=1/18,
q=4: delta_q=1/12,
q to infinity: delta_q to 1/6.
```

### 5.1 Exact fixed-index structure for general q

A fixed closed 2q-cycle contains

```plain text
2q gap labels,
4q independent base variables,
2q value-equality constraints.
```

Its top variety is a Cartesian product of 2q difference curves and has dimension 2q.

Even under perfect PAIR-FLAT, each fixed cycle has size O(p^(3q)). There are O(H^(2q)) cycles, so fixed-index bounds plus triangle inequality give

```plain text
Tr(O^(2q)) << H^(2q) p^(3q).
```

The natural target is H^(q+1)p^(3q). Their ratio is

```plain text
H^(2q-(q+1))=H^(q-1).
```

For every fixed q>=2, this diverges with H. Increasing the moment makes the fixed-index deficit worse.

With generic genus O(ab), the absolute sum is

```plain text
(sum_{h<=H}h^2)^(2q) p^(3q)
 << H^(6q)p^(3q),
```

which loses H^(5q-1) against the target.

With square-root-in-genus or linear-degree errors, the sum is at best

```plain text
H^(4q)p^(3q),
```

which loses H^(3q-1).

Therefore:

```plain text
[DEATH-FIXED-INDEX-MOMENTS]
For every finite q>=2, no argument that
  (i) fixes the 2q gap labels,
  (ii) applies algebraic geometry to that fixed tuple, and
  (iii) sums absolute values over the gap labels
can prove the natural [TR-2q] bound.
This remains false even if every fixed pair satisfies
conductor-free square-root cancellation.
```

The only exception is q=1, where PAIR-FLAT matches the natural second-moment scale H^2p^3; but the resulting Frobenius norm is Hp^(3/2), useful only for H<=p^(1/2). It cannot cross the campaign threshold.

This proves that no finite moment turns fixed-index Deligne theory into a proof of COINC.

## 6. The viable mixed strategy

There are two different meanings of a structured/bulk split. Both are useful, but neither removes the need for horizontal cancellation.

### 6.1 Matrix-level exceptional decomposition

If component aliases or exceptional rows exist, write

```plain text
O = O_struct + O_reg.
```

A sufficient pair of hypotheses at H=p^(2/3) is

```plain text
[TR4-STRUCT]
Tr((O_struct O_struct*)^2) << p^8,

[TR6-REG]
Tr((O_reg O_reg*)^3) << H^4 p^9.
```

Then

```plain text
||O_struct||_op << p^2,
||O_reg||_op << p^(2-1/18),
||O||_op << p^2.
```

Using the operator triangle inequality avoids all mixed noncommutative terms in (O_struct+O_reg)^6.

The fourth-moment statement for the structured part can be replaced by a direct graph or rank bound. For example, if its support graph has maximum degree d and entries have size at most M_struct, then

```plain text
||O_struct||_op <= d M_struct.
```

This is appropriate for a genuinely sparse classified exception set. It is not appropriate for a dense family.

### 6.2 Walk-pattern decomposition inside the sixth trace

Assume first the uniform PAIR-FLAT bound |O_hk|<<p^(3/2). Split closed six-walks according to the number of distinct gap labels.

Every walk using at most four distinct labels contributes, in absolute value, at most

```plain text
O(H^4 p^9),
```

because there are only O(H^4) such label patterns. This structured sector contains all Wigner-Catalan backtracking walks: the underlying graph is a tree with three edges, each edge traversed twice. These are exactly the patterns that produce the leading random sixth moment. There are five Catalan types at leading order.

The dangerous sector consists of walks with five or six distinct gap labels. There are O(H^5) and O(H^6) of them. Random centered entries make their expectations vanish, but a deterministic proof needs the signed estimate

```plain text
[CYCLE6-BULK]
abs(
  sum_{
    closed six-cycles with at least five distinct labels
  }
  prod_{j=1}^6 O_(h_j,h_(j+1))
)
<< H^4 p^9.
```

PAIR-FLAT plus [CYCLE6-BULK] implies [TR6].

A slightly weaker entrywise input can control the backtracking sector. It is enough to have the natural row-energy bound

```plain text
[ROW2]
max_h sum_{k != h}|O_hk|^2 << H p^3.
```

For example, the star backtracking contribution is

```plain text
sum_h
  (sum_{k != h}|O_hk|^2)^3
<< H^4 p^9.
```

The other Catalan patterns admit analogous row-energy estimates. The nonbacktracking bulk still requires signed family cancellation.

### 6.3 What the mixed strategy does and does not accomplish

The mixed strategy can isolate:

```plain text
classified p^2-scale aliases,
universal backtracking/Catalan terms,
low-distinctness gap patterns.
```

Those parts can plausibly be handled by the existing component census, PAIR-FLAT-type bounds, row energies, or a fourth moment.

It cannot control the dense five- and six-label sector by fixed-index geometry. That sector is precisely where the random-matrix mechanism uses independence across gap labels. Any proof must establish an arithmetic substitute for that independence.

```plain text
||O||_op << p^(2-1/18),
```

The corrected coincidence geometry is

```plain text
six gap labels,
twelve independent base variables,
six centered equality constraints,
a dimension-six Cartesian product of difference curves.
```

The proposed dimension-three object belongs to a cubic Gram expression and does not control the operator norm.

The final method verdict is

```plain text
Moment method: alive.
Fixed-index Deligne plus absolute summation: dead for every finite moment.
Surviving load-bearing input: horizontal signed cancellation of closed
gap cycles, already at the six-cycle level in [CYCLE6-BULK].
```

Thus the sixth moment does not convert the campaign into a higher-dimensional fixed-index Weil problem. It converts it into the cleanest possible family-compatibility problem: prove that non-Catalan closed six-cycles cancel down from H^6p^9 to H^4p^9.
