# P2.4: shortest rigorous certificate for the half-interval logarithmic integral

## Result

Write

\[
L=\log 2,
\qquad
\zeta_4=\zeta(4)=\frac{\pi^4}{90},
\]

and define

\[
T=\int_0^1 \frac{\log x\,\log^2(1-x)}{x}\,dx,
\qquad
J=\int_0^{1/2} \frac{\log x\,\log^2(1-x)}{x}\,dx.
\]

The exact values are

\[
\boxed{T=-\frac{\zeta_4}{2}=-\frac{\pi^4}{180}}
\]

and

\[
\boxed{
J=\frac{L^4-\zeta_4}{4}
 =\frac{\log^4 2}{4}-\frac{\pi^4}{360}.
}
\]

The shortest proof of the second formula uses only:

1. the already-proved value and interval integrability of the full integral `T`;
2. the affine reflection `x ↦ 1 - x`;
3. one integration-by-parts primitive with removable endpoint values;
4. `intervalIntegral.integral_eq_sub_of_hasDerivAt_of_tendsto`.

The available evaluation

\[
\int_0^{1/2}\frac{\log^3(1-x)}x\,dx
\]

is **not needed**. In particular, no `Li₄(1/2)` term should survive in `J`. Any route that produces `Li₄(1/2)`, `\zeta(3)\log 2`, or `\pi^2\log^2 2` in the final value of `J` has introduced terms which must cancel again.

# 1. The two linear equations for `J`

Define the reflected half-integral

\[
R=\int_0^{1/2}
 \frac{\log(1-x)\,\log^2 x}{1-x}\,dx.
\]

There are two exact equations:

\[
\boxed{J+R=T}
\tag{1}
\]

and

\[
\boxed{J-R=\frac12L^4.}
\tag{2}
\]

Solving them gives

\[
2J=T+\frac12L^4,
\qquad
J=\frac T2+\frac14L^4.
\tag{3}
\]

Substitution of `T = -ζ₄/2` then gives the claimed value.

## 1.1 Reflection gives `J + R = T`

Let

\[
f(x)=\frac{\log x\,\log^2(1-x)}x,
\qquad
g(x)=\frac{\log(1-x)\,\log^2x}{1-x}.
\]

The pointwise identity is

\[
f(1-x)=g(x).
\]

Therefore, using `x = 1-t`,

\[
\int_{1/2}^{1} f(x)\,dx
 =\int_0^{1/2} f(1-t)\,dt
 =R.
\]

Splitting the full integral at `1/2` gives (1).

No endpoint limit is hidden in this substitution. Mathlib's theorem

```lean
intervalIntegral.integral_comp_sub_left
```

implements the affine reflection directly and is valid for the totalized interval integral. The integrability hypothesis is needed only for the adjacent-interval split.

## 1.2 Integration by parts gives `J - R = L⁴/2`

Set

\[
P(x)=\frac12\bigl(\log x\,\log(1-x)\bigr)^2.
\]

For `0 < x < 1`,

\[
\begin{aligned}
P'(x)
&=\log x\,\log(1-x)
 \left(\frac{\log(1-x)}x-\frac{\log x}{1-x}\right)\\
&=\frac{\log x\,\log^2(1-x)}x
 -\frac{\log(1-x)\,\log^2x}{1-x}\\
&=f(x)-g(x).
\end{aligned}
\tag{4}
\]

The minus sign in the second term is load-bearing: it comes from

\[
\frac d{dx}\log(1-x)=-\frac1{1-x}.
\]

The endpoint values are

\[
\lim_{x\to0^+}P(x)=0
\tag{5}
\]

and

\[
P(1/2)
=\frac12\bigl((-L)(-L)\bigr)^2
=\frac12L^4.
\tag{6}
\]

Applying the endpoint-limit version of FTC-2 to (4) gives (2).

Equivalently, on every regular interval `[a,1/2]`, `0<a<1/2`, ordinary integration by parts says

\[
\begin{aligned}
\int_a^{1/2}f(x)\,dx
-\int_a^{1/2}g(x)\,dx
&=P(1/2)-P(a)\\
&=\frac12L^4
 -\frac12\log^2a\,\log^2(1-a).
\end{aligned}
\tag{7}
\]

Then (5) gives the limit. The Mathlib theorem used below packages exactly this truncation-and-limit argument, so no explicit epsilon sequence is required.

# 2. Endpoint audit

## 2.1 The lower endpoint

The nontrivial limit is

\[
\log x\,\log(1-x)\longrightarrow0
\qquad(x\to0^+).
\]

A Lean-friendly exact factorization is

\[
\log x\,\log(1-x)
=(x\log x)
 \left[-\operatorname{dslope}(\log;1,1-x)\right].
\tag{8}
\]

For `x ≠ 0`, this follows from

\[
\operatorname{dslope}(\log;1,1-x)
=\frac{\log(1-x)-\log1}{(1-x)-1}
=-\frac{\log(1-x)}x.
\]

At `x=0`, both sides of (8) are zero because Mathlib totalizes `Real.log 0 = 0`.

Now:

- `x * log x → 0` is `Real.continuous_mul_log.continuousAt`;
- the `dslope` factor tends to `-1` by
  `continuousAt_dslope_same.mpr (Real.differentiableAt_log one_ne_zero)`.

Hence the product tends to zero, and squaring proves (5).

This is the same endpoint technique already present privately in the current `Dilogarithm.lean`, where it is used at `x=1` for `log x * log(1-x)`.

## 2.2 The midpoint

The exact logarithm identity is

\[
\log(1/2)=\log1-\log2=-\log2.
\]

Also `1-1/2=1/2`, so (6) follows with no branch or sign issue. Both logarithms are negative, but their product is positive and is squared.

## 2.3 Sign check

On `(0,1)`,

- `log x < 0`;
- `log²(1-x) > 0`;
- `x > 0`.

Thus `T<0` and `J<0`. Numerically,

\[
T\approx-0.5411616168555691,
\]

\[
J\approx-0.2128720337820137,
\]

\[
R\approx-0.3282895830735554,
\]

and

\[
\frac12L^4\approx0.1154175492915417.
\]

These satisfy, independently,

\[
J+R=T,
\qquad
J-R=\frac12L^4.
\]

## 3.2 Removable continuity at zero

The following is a direct public version of the private `dslope` pattern already used in the repository.

```lean
private lemma continuousAt_logCross24_zero :
    ContinuousAt logCross24 0 := by
  have heq : logCross24 =
      fun x : ℝ =>
        (x * Real.log x) *
          (-(dslope Real.log 1 (1 - x))) := by
    funext x
    by_cases hx : x = 0
    · subst x
      simp [logCross24]
    · have hne : 1 - x ≠ 1 := by
        intro h
        apply hx
        linarith
      rw [logCross24, dslope_of_ne Real.log hne]
      rw [slope_def_field, Real.log_one]
      field_simp
      ring
  rw [heq]
  apply ContinuousAt.mul
  · exact Real.continuous_mul_log.continuousAt
  · exact
      ((continuousAt_dslope_same.mpr
          (Real.differentiableAt_log one_ne_zero)).comp
        (continuousAt_const.sub continuousAt_id)).neg

@[simp] private lemma jrPrimitive24_zero :
    jrPrimitive24 0 = 0 := by
  simp [jrPrimitive24, logCross24]

private lemma jrPrimitive24_tendsto_zero :
    Tendsto jrPrimitive24 (𝓝[>] (0 : ℝ)) (𝓝 0) := by
  have hp : ContinuousAt jrPrimitive24 0 := by
    change ContinuousAt
      (fun x : ℝ => (1 / 2 : ℝ) * logCross24 x ^ 2) 0
    exact continuousAt_const.mul
      (continuousAt_logCross24_zero.pow 2)
  simpa [jrPrimitive24, logCross24] using
    hp.tendsto.mono_left inf_le_left
```

## 3.4 Exact derivative

```lean
private lemma jrPrimitive24_hasDerivAt
    {x : ℝ} (hx0 : 0 < x) (hx1 : x < 1) :
    HasDerivAt jrPrimitive24
      (jKernel24 x - rKernel24 x) x := by
  have hx : x ≠ 0 := ne_of_gt hx0
  have h1x : 1 - x ≠ 0 := ne_of_gt (sub_pos.mpr hx1)

  have hlogx :
      HasDerivAt (fun y : ℝ => Real.log y) (1 / x) x := by
    simpa [one_div] using Real.hasDerivAt_log hx

  have hsub :
      HasDerivAt (fun y : ℝ => 1 - y) (-1) x :=
    (hasDerivAt_id x).const_sub 1

  have hlog1x :
      HasDerivAt (fun y : ℝ => Real.log (1 - y))
        (-1 / (1 - x)) x :=
    hsub.log h1x

  have hcross :
      HasDerivAt logCross24
        (Real.log (1 - x) / x -
          Real.log x / (1 - x)) x := by
    unfold logCross24
    convert hlogx.mul hlog1x using 1 <;> ring

  change HasDerivAt
    (fun y : ℝ => (1 / 2 : ℝ) * logCross24 y ^ 2)
    (jKernel24 x - rKernel24 x) x

  convert (hcross.pow 2).const_mul (1 / 2 : ℝ) using 1
  simp [jKernel24, rKernel24, logCross24]
  ring
```

The last algebraic goal is precisely

\[
\frac12\cdot 2ab
 \left(\frac ba-\frac a{1-x}\right)
=
\frac{ab^2}{x}-\frac{a^2b}{1-x}
\]

with `a = log x`, `b = log(1-x)`; `ring` treats the inverses as atoms, so no denominator clearing should be necessary. If local simplification leaves explicit divisions in a different normal form, insert

```lean
field_simp [hx, h1x]
ring
```

in place of the final `ring`.

# 6. Packaging the existing proof of `T`

The full-integral series proof should export two declarations, not merely the numerical equality:

```lean
lemma jKernel24_intervalIntegrable :
    IntervalIntegrable jKernel24 volume 0 1

lemma integral_jKernel24_full :
    (∫ x in (0 : ℝ)..1, jKernel24 x) = -Li4 1 / 2
```

The first declaration is needed by the reflection/FTC theorem. It is already a by-product of the absolute-convergence proof and should not require additional analysis.

For reference, the exact series certificate is

\[
\log^2(1-x)
=2\sum_{m\ge1}\frac{H_m}{m+1}x^{m+1}
\qquad(0\le x<1).
\tag{9}
\]

Hence

\[
\begin{aligned}
T
&=2\sum_{m\ge1}\frac{H_m}{m+1}
   \int_0^1x^m\log x\,dx\\
&=-2\sum_{m\ge1}\frac{H_m}{(m+1)^3}.
\end{aligned}
\tag{10}
\]

The sign in (10) comes from

\[
\int_0^1x^m\log x\,dx=-\frac1{(m+1)^2}.
\]

The existing Euler-sum theorem

\[
\sum_{m\ge1}\frac{H_m}{(m+1)^3}=\frac14\zeta(4)
\]

then gives `T = -ζ(4)/2`.

Absolute convergence is elementary:

\[
\frac{H_m}{(m+1)^3}
\le\frac{m}{(m+1)^3}
\le\frac1{(m+1)^2}.
\]

Thus the same proof which uses

```lean
MeasureTheory.hasSum_integral_of_summable_integral_norm
```

also supplies `jKernel24_intervalIntegrable`.

# 8. Final coefficient audit

Let `B = L⁴/2`. The exact equations are

\[
J-R=B,
\qquad
J+R=-\frac{\zeta_4}{2}.
\]

Adding and subtracting gives

\[
J=\frac12\left(B-\frac{\zeta_4}{2}\right)
 =\frac{L^4}{4}-\frac{\zeta_4}{4},
\]

\[
R=-\frac{L^4}{4}-\frac{\zeta_4}{4}.
\]

Therefore the coefficient of `log⁴ 2` in `J` is `+1/4`, the coefficient of `ζ(4)` is `-1/4`, and

\[
J=\frac{\log^4 2}{4}-\frac{\pi^4}{360}.
\]

These signs are forced simultaneously by the derivative (4), the positive midpoint boundary (6), and the negativity of the original integrand.
