# 结论先行

本轮把 LSF 分成两个部分：镜像强制谱可以完全解析；剩余真碰撞谱仍是开放项。

结论：

1. 仅用
\[
A_p(k)\ge0,\qquad \sum_k A_p(k)=pN,\qquad A_p(0)=E^\pi(p)
\]
不能得到目标弧界。最优免费界仍然是
\[
\sum_{k\in J}A_p(k)\le pN.
\]
知道一个点 k=0 的质量不能控制任意弧的质量。

2. 镜像 fiber 的贡献可以精确剥离，而且确实给出目标主项 + O(1) 级误差。令半轨道镜像对
\[
\{n,p-1-n\},\quad 0\le n<(p-1)/2.
\]
则其谱贡献是一个显式 Dirichlet 核，而不是未知随机量。

3. 因此 LSF 的真正剩余对象不是整个 A_p(k)，而是
\[
A_p^{res}(k)=A_p(k)-A_p^{mir}(k),
\]
即真碰撞修正。其总质量约为碰撞数 O(p)（经验），但局部弧平坦化仍需要新输入。

4. 若补上
\[
\sum_{k\in J}A_p^{res}(k)\ll p^{1+\epsilon}|J|/p
\]
级局部平坦化，则 GAP-TIME-FEJER 立即成立。

# 1. 非负测度能免费推出什么

定义
\[
A_p(k)=\sum_v|S_v(k)|^2,
\]
其中
\[
S_v(k)=\sum_{n:\pi(n)=v}e_p(kn).
\]

于是
\[
A_p(k)\ge0.
\]

Parseval 给
\[
\sum_{k\in F_p}A_p(k)=pN.
\]

并且
\[
A_p(0)=\sum_v m_v^2=E^\pi(p).
\]

对任意弧 J：

免费界：
\[
\sum_{k\in J}A_p(k)\le pN.
\]

这是最优，因为可以把全部质量集中到 J 内而保持非负和总质量。

知道
\[
A_p(0)\ll p^{3/2}
\]
只排除了 0 点附近极端集中：
\[
\sum_{k\in J}A_p(k)
\le A_p(0)+\sum_{k\in J\setminus\{0\}}A_p(k)
\]
而第二项仍无控制。

所以第一档真正非平凡输入必须是：

- Fourier 低频局部平坦化；或
- trace-function/large-sieve 型弧估计；或
- fiber-by-fiber 位置集合指数和估计。

# 2. 镜像主项精确计算

镜像 fiber：
\[
v_n=v_{p-1-n}.
\]

单个镜像对贡献
\[
|e_p(kn)+e_p(k(p-1-n))|^2
\]

展开：
\[
=2+2\cos\frac{2\pi k(2n+1-p)}p.
\]

令
\[
m=(p-1)/2.
\]

半轨道 n=0,...,m-1。

镜像谱：
\[
A_p^{mir}(k)
=\sum_{n=0}^{m-1}\left(2+2\cos\frac{2\pi k(2n+1-p)}p\right).
\]

第一项：
\[
2m=p-1.
\]

第二项：
\[
2\Re\left(e_p(k(1-p))\sum_{n=0}^{m-1}e_p(2kn)\right).
\]

若 k=0：
\[
A_p^{mir}(0)=2(p-1).
\]

若 k\ne0：等比求和
\[
\sum_{n=0}^{m-1}e_p(2kn)
=\frac{1-e_p(k(p-1))}{1-e_p(2k)}.
\]

由于
\[
e_p(k(p-1))=e_p(-k)=e_p(k)^{-1},
\]
故
\[
\left|\sum_{n=0}^{m-1}e_p(2kn)\right|
=\frac{|1-e_p(-k)|}{|1-e_p(2k)|}.
\]

而
\[
|1-e_p(-k)|=|1-e_p(k)|,
\]
\[
|1-e_p(2k)|=|1-e_p(k)^2|.
\]

所以
\[
|A_p^{mir}(k)-(p-1)|
\le
2\frac{|1-e_p(k)|}{|1-e_p(2k)|}.
\]

这不是随机平方根误差，而是显式 Dirichlet 核尾部。

对长度 L 的弧 J：

\[
\sum_{k\in J}A_p^{mir}(k)
=(p-1)L+O\left(\sum_{k\in J}\frac{|1-e_p(k)|}{|1-e_p(2k)|}\right).
\]

因此

\[
\boxed{
\sum_{k\in J}A_p^{mir}(k)
=(p-1)|J|+O(p\log p)
}
\]

为一般弧的安全界。

归一化后：
\[
\frac1p\sum_{k\in J}A_p^{mir}(k)
=\frac{N_{mir}|J|}{p}+O(\log p)
\]
（N_mir=p-1 的镜像点数口径）。

所以镜像层已经满足 LSF 主项。

# 3. 真碰撞修正

写
\[
A_p=A_p^{mir}+A_p^{res}.
\]

其中 residual 包含：

- fiber 大于 2 的部分；
- 非镜像重复点；
- Poisson 真碰撞。

若总额外碰撞数为 C_p，则粗略有
\[
\sum_kA_p^{res}(k)\ll p C_p.
\]

经验中 C_p=O(1) 或 O(p^0) 级，因此总 residual 质量应为 O(p)。

但注意：

总质量 O(p) 不推出弧平坦。

仍可能集中在一个小弧。

所以真正的新命题是：

(LR)
\[
\sum_{k\in J}A_p^{res}(k)
\ll |J|C_p p^\epsilon +p^\epsilon.
\]

这正是 LSF 剩余部分。

# 4. 对 GAP-TIME-FEJER 的影响

Fejer 恒等式：
\[
2\sum_{h\le H}(1-h/(H+1))R_h
=\frac1p\sum_k(A_p(k)-N)F_H(k).
\]

若镜像部分解析：

\[
A_p=A_p^{mir}+A_p^{res}
\]

则

- mirror 部分贡献显式主项；
- residual 决定误差。

若只有目前已知：
\[
\sum_kA_p^{res}(k)\ll pC_p,
\]

得到
\[
\text{Fejer error}\ll C_p\max F_H.
\]

因为
\[
\max F_H\asymp H+1,
\]

只给
\[
O(C_pH)
\]
级，不能关闭目标。

若证明 LSF：

对所有
\[
|J|\ge p/H
\]
有
\[
\frac1p\sum_{k\in J}A_p(k)
\le N|J|/p+Cp^\epsilon,
\]

则 dyadic Fejer 分解给
\[
\sum_{h\le H}R_h\ll Hp^\epsilon.
\]

# 5. 首返回收益

取
\[
H=\sqrt p.
\]

若 GAP-TIME-FEJER 成立：
\[
S_p(H)\ll Hp^\epsilon= p^{1/2+\epsilon}.
\]

这正是 Q6520 修改后的目标。

当前镜像分解把问题降为：

\[
\boxed{
\text{证明 residual collision spectrum 不低频聚集}
}
\]

而不是整个 Apéry orbit 的谱。

# 6. 可执行实验

直接从已有全谱输出：

```text
1. 构造 A_mirror(k)
2. 计算 A_res(k)=A(k)-A_mirror(k)
3. 对 dyadic arcs J:
      max_J sum_{k in J} A_res(k)/|J|
4. 比较 p^epsilon 平坦化
```

若 residual 仍表现为平坦：LSF 很可能是正确最小命题。

若 residual 有低频峰：说明真正障碍不是镜像，而是 clock-twisted residual mode。
