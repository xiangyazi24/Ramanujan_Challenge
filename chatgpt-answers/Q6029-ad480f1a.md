# 1. Independent evaluation of the auxiliary Euler integral `E`

Define four auxiliary integrals

```text
A = integral_0^1 log(1-x)*log(1+x)/x dx,
B = integral_0^1 log(1-x)*log(1+x)/(1+x) dx,
C = integral_0^1 log(1+x)^2/x dx,
D = integral_0^1 log(1+x)^2/(1+x) dx.
```

We will prove

```text
A = -(5/8)*Z,                                      (8)
B = (1/8)*Z - (pi^2/12)*L + (1/3)*L^3,            (9)
C = (1/4)*Z,                                       (10)
D = (1/3)*L^3.                                     (11)
```

## 1.1. Möbius substitution for `E`

Use

```text
t = phi(x) = 2*x/(1+x),       0 <= x <= 1.
```

It is increasing, with

```text
phi(0)=0,
phi(1)=1,
phi'(x)=2/(1+x)^2,
phi'(x)/phi(x)=1/(x*(1+x)).
```

For `0 < x < 1`, all logarithm arguments are positive and

```text
1-phi(x)   = (1-x)/(1+x),
1-phi(x)/2 = 1/(1+x).
```

Therefore

```text
log(1-phi(x))   = log(1-x) - log(1+x),
log(1-phi(x)/2) = -log(1+x),
```

and hence

```text
[log(1-phi(x))*log(1-phi(x)/2)/phi(x)]*phi'(x)
 = [-log(1-x)*log(1+x) + log(1+x)^2]/[x*(1+x)].
```

Since

```text
1/[x*(1+x)] = 1/x - 1/(1+x),
```

we obtain the exact decomposition

```text
E = -A + B + C - D.                                (12)
```

This is an ordinary change of variables for an absolutely integrable function.  There is no series rearrangement here.

## 1.2. Evaluation of `C` and `D`

The first is the existing theorem

```text
C = Z/4                                            (13)
```

(`logSquareOnePlusIntegral26`).

For `D`, use the primitive

```text
x |-> (1/3)*log(1+x)^3.
```

Its derivative is `log(1+x)^2/(1+x)`, so

```text
D = (1/3)*log(2)^3 = L^3/3.                        (14)
```

## 1.3. Evaluation of `A`

First record the companion log-square integral

```text
Kminus := integral_0^1 log(1-x)^2/x dx = 2*Z.      (15)
```

One finite-calculus proof uses

```text
P(x) = log(x)*log(1-x)^2.
```

For `0 < x < 1`,

```text
P'(x)
 = log(1-x)^2/x
   - 2*log(x)*log(1-x)/(1-x).
```

The endpoint limits are

```text
lim_(x->0+) log(x)*log(1-x)^2 = 0,
lim_(x->1-) log(x)*log(1-x)^2 = 0.
```

The second follows from `log x = O(1-x)`; the first from `log(1-x)=O(x)`.  Using

```text
integral_0^1 log(x)*log(1-x)/(1-x) dx = Z
```

(the public radial theorem), FTC gives (15).

Now substitute `u=x^2`:

```text
integral_0^1 log(1-x^2)^2/x dx
 = (1/2)*integral_0^1 log(1-u)^2/u du
 = Z.                                               (16)
```

For `0 < x < 1`,

```text
2*log(1-x)*log(1+x)
 = log(1-x^2)^2 - log(1-x)^2 - log(1+x)^2.          (17)
```

Integrating (17), and using (15), (16), and `C=Z/4`, gives

```text
2*A = Z - 2*Z - Z/4 = -(5/4)*Z,
A = -(5/8)*Z.                                      (18)
```

Every sign in (18) is forced: `log(1-x)<0`, `log(1+x)>0`, so `A<0`.

## 1.4. Evaluation of `B`

Use the affine substitution

```text
y = (1-x)/2,
x = 1-2*y.
```

The bounds `x=0,1` become `y=1/2,0`, and the minus sign from `dx=-2 dy` reverses them.  Since

```text
1-x = 2*y,
1+x = 2*(1-y),
```

we get

```text
B = integral_0^(1/2)
      (L+log y)*(L+log(1-y))/(1-y) dy.              (19)
```

Set

```text
U = integral_0^(1/2) log y/(1-y) dy,
V = integral_0^(1/2) log(1-y)/(1-y) dy,
W = integral_0^(1/2) log y*log(1-y)/(1-y) dy.
```

Expanding (19),

```text
B = L^3 + L*U + L*V + W.                           (20)
```

The first two elementary values are

```text
U = Li2(1/2) - Li2(1),                             (21)
V = -L^2/2.                                        (22)
```

Indeed,

```text
(d/dy) Li2(1-y) = log y/(1-y),
(d/dy) [-log(1-y)^2/2] = log(1-y)/(1-y).
```

To evaluate `W`, split the radial integral at `1/2`:

```text
Z
 = W
   + integral_(1/2)^1 log y*log(1-y)/(1-y) dy.      (23)
```

In the second integral substitute `u=1-y`.  This gives

```text
integral_(1/2)^1 log y*log(1-y)/(1-y) dy
 = integral_0^(1/2) log u*log(1-u)/u du.            (24)
```

A primitive for the last integrand is

```text
Q(u) = Li3(u) - log(u)*Li2(u),                     (25)
```

because

```text
Q'(u) = log(u)*log(1-u)/u.
```

The endpoint limit at `u=0+` is zero (`Li2(u)=O(u)` and `u*log u -> 0`).  Hence

```text
integral_0^(1/2) log u*log(1-u)/u du
 = Li3(1/2) + L*Li2(1/2).                          (26)
```

Combining (23)--(26),

```text
W = Z - Li3(1/2) - L*Li2(1/2).                    (27)
```

Substitute (21), (22), and (27) into (20).  The terms `L*Li2(1/2)` cancel **before** any special-value substitution:

```text
B
 = L^3 + L*(Li2(1/2)-pi^2/6) - L^3/2
   + Z - Li3(1/2) - L*Li2(1/2)
 = L^3/2 - (pi^2/6)*L + Z - Li3(1/2).              (28)
```

Use the existing value

```text
Li3(1/2)
 = (7/8)*Z - (pi^2/12)*L + L^3/6.                 (29)
```

Then

```text
B
 = L^3/2 - (pi^2/6)*L + Z
   - [(7/8)*Z - (pi^2/12)*L + L^3/6]
 = (1/8)*Z - (pi^2/12)*L + L^3/3.                 (30)
```

This proves (9).

## 1.5. Finish `E`

Insert (8)--(11) into (12):

```text
E
 = -[-(5/8)*Z]
   + [(1/8)*Z - (pi^2/12)*L + L^3/3]
   + (1/4)*Z
   - L^3/3
 = Z - (pi^2/12)*L.                                (31)
```

The zeta coefficient is

```text
5/8 + 1/8 + 1/4 = 5/8 + 1/8 + 2/8 = 1,
```

and the two `L^3/3` terms cancel exactly.

Thus (1) is proved independently of `R` and `J`.

# 2. The finite-interval product certificate for `R`

Define

```text
F(t) = Li2(t)*log(1-t/2).
```

For `0 < t < 1`,

```text
Li2'(t) = -log(1-t)/t,
(d/dt) log(1-t/2) = -1/(2-t).
```

Therefore

```text
F'(t)
 = -log(1-t)*log(1-t/2)/t - Li2(t)/(2-t).          (32)
```

The endpoint values are exact:

```text

F(1) = Li2(1)*log(1/2)
```

FTC applied to (32) gives

```text

E + R  =  (pi^2/6)*L.                              (34)
```

Using (31),

```text

 = (pi^2/6)*L - [Z-(pi^2/12)*L]
 = (pi^2/4)*L - Z.                                 (35)
```

This is the first proof of `R` in the dependency graph.  In particular, (35) is not imported from `J`.

# 3. Repair of Q6014: `J=-R`

Define

```text
G(x) = log(1+x)*Li2(1-x).
```

For `0 < x < 1`, the chain-rule sign is positive:

```text
(d/dx) Li2(1-x)
 = [-log(x)/(1-x)]*(-1)
 = log(x)/(1-x).
```

Hence

```text
G'(x)
 = Li2(1-x)/(1+x)
   + log(x)*log(1+x)/(1-x).                        (36)
```

The endpoints are

```text
G(0)=log 1*Li2(1)=0,
G(1)=log 2*Li2(0)=0.                               (37)
```

FTC gives

```text
J + integral_0^1 Li2(1-x)/(1+x) dx = 0.            (38)
```

Use the affine reflection `t=1-x`:

```text
integral_0^1 Li2(1-x)/(1+x) dx
 = integral_0^1 Li2(t)/(2-t) dt
 = R.                                               (39)
```

There is no residual minus sign in (39): `dx=-dt` reverses the bounds and the two signs cancel.  Therefore

```text
J=-R=Z-(pi^2/4)*L.                                 (40)
```

This repairs Q6014 without circularity.

# 4. Independent cubic remainder

Define

```text
M = integral_0^1 x^2*log(x)*log(1+x)/(1-x^3) dx.   (41)
```

The following derivation is the exact bridge from the already formalized ordinary/cubic alternating residue-class sums.

## 4.1. Absolutely convergent double sum

For `0 <= x < 1`,

```text
1/(1-x^3) = sum_{n>=0} x^(3*n),
log(1+x)  = sum_{m>=1} (-1)^(m+1)*x^m/m.
```

The integrated double series is absolutely convergent, since

```text
sum_{m>=1} sum_{n>=1} 1/[m*(m+3*n)^2]
 <= sum_{m>=1} (1/m)*(1/(3*m))
 = (1/3)*sum_{m>=1} 1/m^2 < infinity.              (42)
```

Here

```text
sum_{n>=1} 1/(m+3*n)^2 <= integral_0^infinity 1/(m+3*u)^2 du = 1/(3*m).
```

Thus Tonelli/Fubini and termwise integration are legal; this is not a rearrangement of a merely conditionally convergent double series.  Since

```text
integral_0^1 x^(m+3*n-1)*log x dx = -1/(m+3*n)^2,
```

one gets

```text
M
 = -sum_{n>=1} sum_{m>=1}
     (-1)^(m+1)/[m*(m+3*n)^2].                     (43)
```

## 4.2. The exact grouped cubic sum

For `N>=1`, define finite alternating harmonic numbers

```text
h1(N) = sum_{j=1}^N (-1)^(j+1)/j,
h2(N) = sum_{j=1}^N (-1)^(j+1)/j^2.               (44)
```

Keep the outer `n`-series grouped, and define

```text
C3 = sum_{n>=1} (-1)^n *
       [h1(3*n)/n^2 + 3*h2(3*n)/n].                (45)
```

The public ordinary/cubic alternating residue-class results assemble to

```text
C3 = (pi^2/4)*L - (43/12)*Z.                       (46)
```

For Lean, (46) should be exposed as one wrapper theorem (for example `cubicGroupedAlternating26`) proved by `simpa`/`ring` from the existing individual `HasSum` theorems.  Keeping (45) grouped avoids any question about separating two conditionally convergent series.

## 4.3. Partial fractions and sign audit

For positive integers `m,N`,

```text
1/[m*(m+N)^2]
 = (1/N^2)*(1/m - 1/(m+N))
   - (1/N)*1/(m+N)^2.                              (47)
```

Use

```text
sum_{m>=1} (-1)^(m+1)/m   = L,
sum_{m>=1} (-1)^(m+1)/m^2 = pi^2/12.               (48)
```

After shifting by `N=3*n` (so `(-1)^(3*n)=(-1)^n`), (47) gives

```text
sum_{m>=1} (-1)^(m+1)/[m*(m+3*n)^2]
 = L*(1-(-1)^n)/(9*n^2)
   + (-1)^n*h1(3*n)/(9*n^2)
   - (-1)^n*pi^2/(36*n)
   + (-1)^n*h2(3*n)/(3*n).                         (49)
```

The two elementary outer sums are

```text
sum_{n>=1} (1-(-1)^n)/n^2 = pi^2/4,                (50)
sum_{n>=1} (-1)^n/n = -L.                          (51)
```

Consequently, summing (49) while retaining the grouped expression (45),

```text
sum_{n,m>=1} (-1)^(m+1)/[m*(m+3*n)^2]
 = (pi^2/36)*L + (pi^2/36)*L + C3/9
 = (pi^2/18)*L + C3/9.                             (52)
```

The leading minus sign in (43) is essential.  Therefore

```text
M = -(pi^2/18)*L - C3/9.                           (53)
```

Insert (46):

```text
M
 = -(pi^2/18)*L
   - (1/9)*[(pi^2/4)*L-(43/12)*Z]
 = -(pi^2/18)*L -(pi^2/36)*L +(43/108)*Z
 = (43/108)*Z -(pi^2/12)*L.                        (54)
```

Numerically `M<0`, as it must: on `(0,1)`, `log x<0` and every other factor in (41) is positive.

No occurrence of `I`, `J`, or `R` was used in (41)--(54).

# 5. Finish the cyclotomic integral

For `0 < x < 1`,

```text
1+x+x^2 = (1-x^3)/(1-x),
```

and direct field algebra gives

```text
(1+2*x)/(1+x+x^2)
 = 1/(1-x) - 3*x^2/(1-x^3).                       (55)
```

Both sides multiply the same integrable factor `log x*log(1+x)`.  Hence

```text
I = J - 3*M.                                       (56)
```

Use (40) and (54):

```text
I
 = [Z-(pi^2/4)*L]
   -3*[(43/108)*Z-(pi^2/12)*L]
 = Z-(pi^2/4)*L -(43/36)*Z +(pi^2/4)*L
 = -(7/36)*Z.                                      (57)
```

The coefficient is

```text
1 - 43/36 = 36/36 - 43/36 = -7/36.
```

This is the required identity.
