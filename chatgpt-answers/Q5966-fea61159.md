# 9. Exact computational route

The existing repository objects are enough to construct the sequences directly. The following Sage skeleton uses the exact quadratic field and the certified integer_coefficients generated by q32_doubled_period_gauge_audit.sage.

```javascript
# Run from problems/3.2/research/scripts
load("q32_doubled_period_gauge_audit.sage")

K.<r> = QuadraticField(2)
zq = r/2
xq = 1 + r
lam = 17 + 12*r
assert lam * lam.galois_conjugate() == 1

# polytope_points is imported by the loaded audit.
critical_terms = []
for a, b, c in polytope_points(1):
    t = xq^a * zq^(b+c)
    if t == 1:
        # Includes the origin and the two nonzero labels with b+c=0.
        continue
    critical_terms.append(t)
assert len(critical_terms) == 19


def bracket(a, b):
    value = (
        a.galois_conjugate()*b
        - a*b.galois_conjugate()
    ) / r                       # r = 2*z
    assert value in QQ
    return QQ(value)


def determinant_value(s, chi):
    A = K(0)
    C = K(0)
    for t in critical_terms:
        tb = t.galois_conjugate()
        rho = t/(1-t)
        if chi == 1:
            weight = K(1)
        else:
            weight = (t/tb)^2 * (1-tb)/(1-t)
        A += weight * rho^s
        C += weight * (t + 1/t) * rho^s

    U = sum(
        ZZ(integer_coefficients[j](n=-s-1)) * lam^j
        for j in range(5)
    )
    D = bracket(A, lam*U*C)
    return D


def dseq(s, chi):
    return determinant_value(s, chi).numerator()


def reflected_counterexamples(Smax):
    out = []
    for s in range(Smax + 1):
        bs = ZZ(apery(s))
        for chi in (-1, 1):
            g = gcd(bs, abs(ZZ(dseq(s, chi))))
            for p, exponent in factor(g):
                p = ZZ(p)
                if p > max(7, s+1) and kronecker(2, p) == chi:
                    L = p-1-s
                    out.append((p, L, s, chi, exponent))
    return out
```

This search is logically stronger than scanning a rectangle in ((p,L)): every output is automatically a target degeneracy by (19), while absence through a given (s)-range is exact.

To prove a finite-index theorem, the next computation should not merely extend this scan. It should:

1. construct exact annihilators for (d_+) and (d_-) from (16);

1. test a bounded-degree ansatz for (25) or (27);

1. certify any candidate identity by reducing it with the Apéry recurrence and the exact annihilator of (d_chi);

1. factor the exceptional coefficient (c_chi(s)) or the right side of (27);

1. separately check the fixed bad primes 2 and 7 and the finitely many primes dividing coefficient contents.

If the neighbor/Bézout ansatz has no solution, the correct next object is the sequence (g_chi(s)=gcd(b_s,d_chi(s))). A single large prime factor satisfying the inequality and Legendre-sign test in (23) is a rigorous counterexample to the proposed finite reflected set.
