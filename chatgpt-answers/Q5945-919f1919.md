# P3.1 Lean 4 final calculus architecture audit

## Verdict

The minimal unconditional Lean route is not to formalize the geometric endpoint computation directly. The proof should split into:

1. a real-analysis layer proving that the four Rogers arguments are differentiable and remain in (0,1) on the official interval;

1. an algebraic shape layer proving the differential identity exactly;

1. an interval-integral layer converting the derivative identity into an endpoint difference;

1. an endpoint algebra layer rewriting the two endpoint Rogers values.

No numerical approximation, torsion hypothesis, or unproved positivity certificate is needed.

## Core objects

Use the official curve variable x : ℝ, interval Icc alpha beta, and a function

```javascript
y : ℝ → ℝ
```

with hypotheses:

```javascript
Continuous y
ContDiff ℝ 1 y
∀ x ∈ Set.Icc alpha beta, 0 < y x
∀ x ∈ Set.Icc alpha beta, HasDerivAt y (y' x) x
∀ x ∈ Set.Icc alpha beta, A72 x (y x) = 0
StrictMonoOn (fun x => - y x) (Set.Icc alpha beta)
```

The monotonicity/decreasing statement should be encoded as a derivative sign theorem rather than assumed as a black box:

```javascript
∀ x ∈ Set.Icc alpha beta, y' x < 0
```

## Rational shape functions

After X=x^2, L=y^2, define the four arguments:

```javascript
u₁ x := P₁ (x^2) (y x)^2 / Q₁ (x^2) (y x)^2
u₂ x := P₂ (x^2) (y x)^2 / Q₂ (x^2) (y x)^2
u₃ x := P₃ (x^2) (y x)^2 / Q₃ (x^2) (y x)^2
u₄ x := P₄ (x^2) (y x)^2 / Q₄ (x^2) (y x)^2
```

Required theorem:

```javascript
theorem shape_mem_Ioo
  (i : Fin 4) {x : ℝ} (hx : x ∈ Set.Icc alpha beta) :
  0 < u i x ∧ u i x < 1
```

This must be proved from polynomial inequalities. It cannot be supplied by the Rogers API.

## Differentiating Rogers functions

Define:

```javascript
noncomputable def Rogers (z : ℝ) : ℝ :=
  Real.dilog z + (1/2) * Real.log z * Real.log (1-z)
```

The derivative lemma needed:

```javascript
lemma hasDerivAt_Rogers
 {z z' : ℝ}
 (hz0 : 0 < z)
 (hz1 : z < 1)
 (h : HasDerivAt zfun z' x) :
 HasDerivAt (fun x => Rogers (zfun x))
   (RogersDeriv z * z') x
```

The proof uses:

- HasDerivAt.add

- HasDerivAt.mul

- Real.hasDerivAt_log

- HasDerivAt.const_mul

- the derivative theorem for the internally defined dilogarithm tsum.

Do not use a guessed Real.dilog derivative theorem unless verified in the target Mathlib version.

## Algebraic differential identity

The main bridge theorem should be:

```javascript
theorem four_Rogers_deriv
(x : ℝ) (hx : x ∈ Set.Icc alpha beta) :
deriv (fun t =>
  Rogers (u₁ t) + Rogers (u₂ t)
+ Rogers (u₃ t) + Rogers (u₄ t)) x
= omega x
```

where omega is the official logarithmic one-form pulled back through y.

The proof is entirely ring normalization after clearing denominators:

```javascript
field_simp
ring_nf
```

with side conditions:

```javascript
Qᵢ (x^2) (y x)^2 ≠ 0
```

proved from positivity.

## Orientation and X,L factor audit

The pullback is:

```javascript
X=x²
L=y²
```

so

```javascript
dX = 2x dx
 dL = 2y y' dx
```

The Lean statement should isolate the factor:

```javascript
theorem pullback_shape_form :
  omega x = 2*x*A x + 2*y x*y' x*B x
```

The sign is determined by the official decreasing branch:

```javascript
beta > alpha
```

and not by reversing interval orientation.

## Required nonvanishing obligations

The following facts must be proved:

1. Every denominator of every rational shape is nonzero.

1. Every Rogers argument satisfies 0 < uᵢ < 1.

1. 1-uᵢ ≠ 0 for logarithms.

1. x ≠ 0 when extracting factors from d(x²)=2x dx.

1. y x ≠ 0 from the official positive branch.

1. Continuity of every rational expression.

1. Continuity of the logarithmic one-form.

1. Differentiability of the composed rational maps.
