# Verdict

The near-origin packet

[

S_K(M)=sum_{|kappa|_inftyle K}c_M(kappa)

]

is a genuine constant-term/diagonal object, not the shell value C_M(K). For fixed K it has a fixed-order holonomic recurrence in M, exact symmetries, and clean Cartier congruences. However, the target congruence

[

qmid C_M(q-1)

]

does not force a useful divisibility or vanishing statement for S_K(M) in general. The packet records low Fourier modes of the same Laurent power, while the shell target is a root-of-unity filtered sum over the full q-1 torsion. The missing implication would require a new cross-characteristic identity.

# 1. Constant-term formulation

Write

[

Lambda(x,y,z)=frac{(1+x)(1+y)(1+z)((1+y)(1+z)+xyz)}{xyz}.

]

Then

[

Lambda^M=sum_nu c_M(nu)X^nu.

]

The coefficient symmetry comes from the Newton polytope involution. The polytope is centrally symmetric after the shift induced by the Laurent monomial factor, giving

[

c_M(nu)=c_M(-nu).

]

Hence

[

S_K(M)=c_M(0)+sum_{0<|kappa|_inftyle K}2c_M(kappa).

]

For fixed K, this is a finite sum of diagonals of the rational function \Lambda^M, hence a G-function sequence and therefore satisfies a linear recurrence with polynomial coefficients.

# 2. The K=1 packet

The cube \|\kappa\|_\infty\le1 has 27 lattice points. By symmetry only the orbit types matter:

- (0,0,0);

- axis points (\pm1,0,0) and permutations;

- edge points (\pm1,\pm1,0) and permutations;

- corner points (\pm1,\pm1,\pm1).

Therefore

[

S_1(M)=c_M(0)+6A_M+12B_M+8D_M,

]

where

[

A_M=c_M(1,0,0),quad B_M=c_M(1,1,0),quad D_M=c_M(1,1,1).

]

Each component is a fixed diagonal of \Lambda^M, so creative telescoping gives fixed order. The order is bounded independently of M; unlike the shell C_M(d), no growing residue parameter occurs.

# 3. Hypergeometric representation

For every fixed coefficient vector \kappa,

[

c_M(kappa)=operatorname{CT}left(Lambda^M X^{-kappa}right).

]

Expanding the two factors gives a finite multisum of binomial-hypergeometric type:

[

c_M(kappa)=

sum_{i,j,k,ldots}

prod_rbinom{M}{u_r}binom{M+v_r}{w_r},

]

with linear constraints determined by the exponent equations. For fixed \kappa the summand is proper hypergeometric, so Zeilberger/Ore telescoping produces an explicit recurrence.

For S_1 the recurrence order is finite because the orbit set is finite.

# 4. Cartier congruence

Let

[

M=a(q-1)+r.

]

Modulo a prime q, the freshman-dream factorization gives

[

Lambda^{q-1}equiv Lambda(x^q,y^q,z^q)/Lambda(x,y,z)pmod q,

]

so iterating yields the standard digit factorization

[

c_M(nu)equiv c_a(anu)c_r(nu)pmod q

]

in the admissible range where the digit splitting is valid.

Therefore

[

S_K(M)equiv

sum_{|kappa|le K}c_a(akappa)c_r(kappa)

pmod q.

]

This is the strongest general Cartier statement for the packet.

# 5. Relation to shell targets

The shell target is

[

C_M(q-1)=sum_{nuin(q-1)mathbb Z^3}c_M(nu).

]

Modulo q, the target condition selects the complete torsion-average sector. The packet S_K only selects finitely many Fourier coefficients.

There is no implication

[

qmid C_M(q-1)Rightarrow S_K(M)equiv0pmod q

]

for fixed K.

The reason is structural: the shell congruence imposes one condition on the full periodic sum, whereas S_K is a partial sum of Fourier modes.

# 6. Exact failed divisibility candidates

The following natural candidates are false in general:

## Candidate A

[

qmid C_M(q-1)Rightarrow qmid S_1(M).

]

False. The shell zero can occur through cancellation among nonzero Fourier sectors while the low packet remains a unit.

## Candidate B

[

qmid C_M(q-1)Rightarrow S_1(M)equiv S_1(r)pmod q.

]

Also false: Cartier gives coefficientwise digit factorization, but summing only the fixed packet does not commute with the shell torsion restriction.

# 7. Height analysis

Although S_K(M) has fixed recurrence order, this alone does not solve P3.2.

A recurrence of fixed order controls presentation complexity, not prime content. To use S_K as a carrier one would need

[

log operatorname{rad}gcd(S_K(M),text{target block})=o(M^{1/3}).

]

No such bound follows from holonomicity. A fixed-order sequence can have exponentially large common divisors.

# 8. Remaining viable use

The useful role of S_K is not as a direct target detector. It may serve as a secondary distinguished-state coordinate if one proves an Apéry-specific identity of the form

[

C_M(q-1)equiv0pmod q

Longrightarrow

alpha_0S_K(M)+alpha_1S_K(M+1)+cdotsequiv0pmod q

]

with coefficients independent of q.

No such identity is currently proved.

The exact obstruction is therefore:

The near-origin packet is a fixed-order low-frequency observable of the Laurent power, while the shell target is a moving torsion-average observable. A theorem connecting them would be a genuinely new cross-characteristic Apéry identity.
