The robust construction is:

1. Start from the existing horizontal Tendsto theorem for the raw kernel.

1. For all sufficiently large T—take T ≥ 1—prove raw = extension at every x ∈ [[left,right]].

1. Use intervalIntegral.integral_congr to identify the two horizontal integrals.

1. Transport the raw Tendsto with Tendsto.congr'.

1. Apply verticalIntegral_eq_of_horizontal_tendsto27 to the extension.

1. Rewrite the two vertical boundary integrals back to raw kernels.

The orientation is important:

```plain text
raw-left = ext-left = ext-right = raw-right.
```

The horizontal transport uses raw = extension directly. Only the last vertical rewrite uses symmetry, because it goes from extension back to raw.

The R theorem has hypotheses 1 ≤ m and m ≤ n. The S theorem has 1 ≤ m and the essential strict inequality m < n.

# Orientation audit

## Horizontal limits

For the top edge, hraw is a limit of raw horizontal integrals. The eventual equality constructed by intervalIntegral.integral_congr is

```plain text
raw horizontal integral = extension horizontal integral.
```

Therefore this is the correct direction:

```javascript
refine hraw.congr' ?_
```

There is no .symm here.

The bottom edge is identical, with + T·I replaced by - T·I.

## Vertical boundaries

The final calculation is deliberately:

```javascript
calc
  raw-left = ext-left := raw_eq_ext
  _ = ext-right := hshift
  _ = raw-right := raw_eq_ext.symm
```

The final .symm is necessary and is the only reversal in the one-strip theorem.

## Why T ≥ 1

Raw = extension fails to be available at the deleted center without the non-center premise. On a horizontal edge, T ≥ 1 forces nonzero imaginary part, so every point is distinct from (m : ℂ). The eventual filter is exactly:

```javascript
filter_upwards [eventually_ge_atTop (1 : ℝ)] with T hT
```
