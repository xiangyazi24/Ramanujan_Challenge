# Item audit

## R1 Fourier normalization

VERDICT: CONFIRMED.

With

```
nu(a)=sum_{r,h} u_r v_h 1_{Delta(r,h)=a}
```

and Fourier convention

```
hat nu(s)=sum_a nu(a)e_p(sa)=B_s(u,v),
```

Parseval gives

```
sum_a |nu(a)-W/p|^2
 = (1/p) sum_{s != 0} |B_s(u,v)|^2.
```

The zero frequency is exactly `W` and is removed by the centering.

## R2 WALL => row variance

VERDICT: ERROR (missing operator-norm hypothesis).

Taking `v_h=1` is legitimate only for obtaining one column-summed estimate:

```
||nu_u,1 - W/p||_2^2 <= C X^eps |I| |J|
```

because

```
E_{u,1}=sum_r |u_r|^2 * |J|.
```

The desired row statement is a dual operator estimate:

```
sum_r |d_I(r)-q_I(r)/p|^2 <= C X^eps |I|.
```

It does not follow by merely fixing `v=1`; dualizing requires that the bilinear form has norm bounded by `C X^eps |I|^{1/2}`, not by the Hilbert-Schmidt norm supplied by WALL.

Correction: either add a uniform operator-norm WALL, or accept an extra factor `|J|`.

## D2 gauge caveat

VERDICT: CONFIRMED.

Multiplying

```
Delta(r,h) -> lambda_h Delta(r,h)
```

with nonzero `lambda_h` preserves zeros but changes the nonzero value distribution. Therefore COINC and all-level Fourier statements are gauge-dependent.

Natural gauges:

1. raw determinant:

```
b_r c_{r+h}-c_r b_{r+h}
```

best for geometry;

2. determinant divided by leading coefficient of the gap polynomial:

best for comparing `h` families;

3. crystal/Frobenius normalization:

best if the object is later interpreted as a fixed p-adic family.

No normalization should be changed silently inside WALL proofs.
