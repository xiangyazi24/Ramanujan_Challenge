## 3. Honest triple poles

FIXABLE: the statement over Q is correct, but the written proof is not a proof.

The phrase

```plain text
Apply the addition law with (h,d)=(j-1+(h-j+1)) arranged ...
```

is not a well-formed substitution, and the subsequent block-factorization sentence does not determine either the sign or the factorial factors.

A complete proof is short.

First,

```plain text
N_q(-1)=U_(q-1)(0)=((q-1)!)^3 b_(q-1).
```

This follows directly by induction from the recurrence for U_m and the Apery recurrence.

For j=1, this is already the desired formula. For 2 <= j <= h, apply the addition law with first length j-1 and second length h-j+1:

```plain text
N_h(x)
 =N_(h-j+1)(x+j-1)N_j(x)
  -(x+j)^6 N_(h-j)(x+j)N_(j-1)(x).
```

At x=-j, the second term vanishes, hence

```plain text
N_h(-j)=N_(h-j+1)(-1)N_j(-j).
```

The already proved reflection identity gives

```plain text
N_j(-j)=(-1)^(j-1)N_j(-1).
```

Therefore

```plain text
N_h(-j)
 =(-1)^(j-1)
  ((j-1)!)^3 b_(j-1)
  ((h-j)!)^3 b_(h-j).
```

Since every b_n is a positive integer, this is nonzero over Q.

Now D_h has an exact triple zero at every x=-j, and the numerator is nonzero there, so every finite pole has exact order 3.

The assertion at infinity needs a separate degree argument. Write z=1/x. Since

```plain text
deg N_h=3(h-1),
deg D_h=3h,
```

and the leading coefficient of N_h is nonzero, one has

```plain text
delta_h(1/z)=lambda_h z^3+O(z^4),
lambda_h != 0.
```

Thus delta_h has an exact zero of order 3 at infinity. This also proves that the rational map has degree exactly 3h and that gcd(N_h,D_h)=1 over Q.

### Characteristic-p caveat

The lemma is only an honest-pole statement over Q, as written. Modulo p, the endpoint value can vanish when

```plain text

```

and the pole can cancel or its order can drop. The leading coefficient can also drop modulo exceptional primes. Any finite-field use must exclude or count these bad reductions; positivity over Z does not imply nonvanishing in F_p.

```plain text

```

It has gcd(e,f) branches, each of ramification index lcm(e,f) over the base. Its total Riemann-Hurwitz defect is

```plain text
gcd(e,f)(lcm(e,f)-1)=ef-gcd(e,f).
```

This formula should be stated; the present proof jumps directly to the defects.



### 5.2 The distinct-gap case

PROVED under MON_h and MON_k, with a small wording repair.

Let m=3h and n=3k, with m != n. The joint group is a subdirect product of S_m x S_n. Goursat gives normal subgroups and a common quotient.

For the degrees occurring here, the only common quotients are:

```plain text

```

For S_3 this follows from its normal-subgroup list, and for S_q, q >= 5, from the normal subgroups 1,A_q,S_q. The exceptional outer automorphism of S_6 is irrelevant: it is an automorphism, not an additional quotient, and m != n rules out a common full symmetric quotient.


### 5.3 The same-gap case

FIXABLE: the theorem is true, but the proof given is logically inadequate.

For the self-fiber product, the two monodromy representations are not merely two surjections with a common quotient. They are the same representation. With compatible sheet labels, the joint image is exactly

```plain text
diag(S_(3h))={(g,g):g in S_(3h)}.
```

With independently chosen labels it is the graph of an inner conjugation, which has the same orbit structure.

The diagonal action of S_n on ordered pairs has exactly two orbits:

```plain text
{(i,i):1 <= i <= n},
{(i,j):i != j}.
```

The second set is one orbit because the natural action is 2-transitive. This is an action on ordered pairs; there is no quotient by the involution interchanging the two factors. The involution preserves the off-diagonal component but does not split it.

The first orbit closes to the geometric diagonal x=y. The second orbit closes to one irreducible residual component. Since the full defining curve has bidegree (3h,3h), the residual has bidegree


The sentence "G contains the diagonal image of A_(3h)" is not enough: a larger subdirect group could contain pairs (g_1,g_2) that move a diagonal ordered pair off the diagonal and merge the two purported orbits. ## 7. The proposed route to full monodromy

BROKEN.

Several statements in the monodromy-status remark must be removed or rewritten.

### 7.1 Local inertia at the poles

All h poles lie over the same branch value t=infinity. A loop around that one base point has cycle type

```plain text
3^h,
```

that is, a product of h disjoint 3-cycles. The monodromy group does not receive h separately selectable 3-cycles from the h poles.

There is, however, a single 3-cycle at the other special branch value t=0, provided N_h is squarefree: the point x=infinity has index 3 and all finite zeros are unramified. This is the correct source of a 3-cycle.

### 7.2 Transpositions

A simple critical point gives a transposition only when its critical value is not shared by any other ramification point. The required statement is:

```plain text
there exists a branch value whose entire ramification profile is
(2,1,...,1).
```

Squarefreeness and distinctness of the reduced critical-value polynomial can establish this, but merely saying "a simple critical point supplies a transposition" suppresses the collision issue.

### 7.3 Primitivity

Primitivity of the sheet action is equivalent to indecomposability of the rational function:

```plain text
delta_h != a composed with q
```

for rational maps a,q of degrees greater than 1.

Irreducibility of the critical-value resultant C_h(T) does not imply this. It says, after removing multiplicities and extraneous factors, that the Galois group of the coefficient field acts transitively on a set of critical values. Blocks of imprimitivity are subsets of sheets, not subsets of critical values. These are different actions, and no implication has been proved.

Likewise, squarefreeness of N_h rules out a literal power representation with multiply occurring zeros, but it does not rule out a general rational decomposition. Generic compositions can have squarefree numerators.

Pairwise coprimality of the C_h(T) can help prove that two covers have disjoint non-special branch loci. It does not prove full monodromy of either cover.

### 7.4 Correct monodromy target

The correct sufficient package is:

```plain text
(MON-A) delta_h is indecomposable over Qbar.
        Equivalently, its geometric monodromy is primitive.

(MON-B) delta_h has an isolated simple branch value.
        Hence its monodromy contains a transposition.
```

A primitive subgroup of S_(3h) containing a transposition is the full symmetric group. Alternatively, the single 3-cycle at t=0 plus Jordan's theorem gives A_(3h) once primitivity is known, and an odd simple inertia element upgrades it to S_(3h).

The sharpest first lemma is therefore not irreducibility of C_h(T). It is:

```plain text
[DELTA-INDECOMPOSABLE]
For every h >= 2, the rational map delta_h is indecomposable over Qbar.
```

The critical-value resultant is useful only after that lemma, to certify an isolated simple branch value and branch disjointness.

The sentence

```plain text
The entire component theory of the family thus rests on one explicit
one-variable irreducibility family.
```

is unsupported and must be deleted.
