# qCASCADE: zero-set cascade closure theory audit

## 1. Definitions and the basic cascade lemma

Let R_p be the set of collision incidences

```
R_p(D) = {(r,d): 1 <= d <= D, pi(r)=pi(r+d)}.
```

For a base r define its return set

```
T(r) = {d >= 0 : pi(r)=pi(r+d)}.
```

The addition law for the gap matrices implies the following machine-checkable statement.

```
CASCADE_STEP:
if e,d in T(r) and 0 < e < d,
then d-e in T(r+e).
```

Proof sketch. The equalities pi(r)=pi(r+e) and pi(r)=pi(r+d) give
pi(r+e)=pi(r+d). Translating the second equality by e gives a collision of gap d-e at base r+e. No division by a vanishing denominator is needed because the projective statement is represented by determinants.

Therefore the directed graph on incidences

```
(r,d) -> (r+e,d-e)
```
for every smaller return e is closed inside the collision relation.

## 2. Difference-closed structure of a multi-return base

Suppose

```
T(r) contains {0,d_1,...,d_k}, d_1<...<d_k.
```

Then for every pair i<j the closure contains

```
(r+d_i, d_j-d_i).
```

Equivalently, the shifted return sets satisfy

```
d_j-d_i in T(r+d_i).
```

Thus the return pattern is not a single arithmetic progression; it is a partial difference-closed groupoid. The correct replacement for a Steiner-system statement is:

```
Every ordered difference of two returns is itself a return at the shifted base.
```

The closure does not imply that d_j-d_i is a return at the original base r. That stronger statement would require an additional translation invariance which is not present for the non-autonomous Apery cocycle.

## 3. Mass replication inequality

Let

```
S_D = sum_r |T(r) intersect [1,D]|,
P_D = #{r : |T(r) intersect [1,D]| > 0}.
```

If a base has k returns up to D, then it contributes at least k(k-1)/2 shifted difference incidences before truncation by the boundary. More precisely, for a return set A_r with k elements,

```
#{(i,j): i<j, d_i,d_j in A_r} = k(k-1)/2
```

and these pairs map injectively to closure incidences except when two translated bases coincide.

Hence the unconditional machine-checkable inequality is

```
sum_r binom(m_r,2) <= S_{2D} + boundary(D),
```

where m_r = |T(r) intersect [0,D]| and the boundary term counts shifted returns leaving the checked interval.

Using

```
Q_p(D) = sum_r binom(m_r,2),
```

we obtain

```
Q_p(D) <= S_{2D} + O(D^2).
```

Consequences:

* large collision multiplicity forces additional collision mass;
* isolated bases with many returns are impossible without creating a cascade of new incidences;
* this converts multiplicity control into a second-moment estimate.

However, closure alone does not bound the number of distinct bases P_D by S_D, because a single long chain can have many distinct translated bases.

## 4. Interaction with reflection symmetry

The reflection theorem gives

```
pi(p-1-n)=pi(n).
```

Hence every collision at gap d has a mirror collision at gap d:

```
(r,d) -> (p-1-r-d,d).
```

The mirror involution commutes with the cascade operation up to reversal:

```
mirror(r+e,d-e)=mirror(r)-e-(d-e).
```

Therefore the cascade graph decomposes into reflection-stable components.

The forced even-gap factor

```
N_h(r)=(2r+h+1)M_h(r)
```

is exactly the fixed-point contribution of this involution. It creates the unavoidable mirror branch but does not create arbitrary extra mass.

## 5. Machine-checkable lemma package

Recommended formal statements:

```
theorem cascade_step
  (h1 h2 : Nat) (h1_lt_h2 : h1 < h2)
  (hr1 : Return r h1)
  (hr2 : Return r h2) :
  Return (r+h1) (h2-h1)
```

```
theorem cascade_pair_count
  : sum r choose (return_count r D) 2
    <= collision_mass (2*D) + boundary D
```

```
theorem reflection_cascade_compat
  : mirror (cascade x y) = cascade (mirror x) (mirror y)
```

All three reduce to determinant identities using

```
Delta_{r,h}=0 iff pi(r)=pi(r+h).
```

## 6. Computational verification protocol

For each prime p in a test range:

1. Compute pi(n) for 1 <= n <= p-2 using the recurrence modulo p.
2. Build all return sets T(r) for d <= D.
3. For every pair of returns e<d verify that (r+e,d-e) is present.
4. Compute both sides of the pair-count inequality.
5. Apply the reflection map and verify component invariance.

Failure of any step is a direct counterexample to the cascade axioms.

## Final verdict

The cascade mechanism is real and gives a rigorous new constraint:

```
large local multiplicity => replicated collision mass.
```

It does not by itself prove E1 (F_p << p^(1+eps)). The remaining bottleneck is converting cascade replication into a global upper bound for the number of starting bases. The useful bridge is the pair-count inequality combined with an independent estimate for total short-gap mass Q_p(D).
