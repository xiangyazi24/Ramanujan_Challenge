# Q5740: second beta-Padé kernel analysis

## 1. Setup and the global identity

From Q5736, for

\[
A=G_{D-1,N}=\sum_{i=0}^N(-1)^i\binom{D-1+i}{i}\binom{D+N}{N-i}C_M(D-1+i),
\]

with

\[
B=\binom{D+N}{N},
\]

define

\[
Q_{D,N}(T)=\sum_{i=0}^{N}(-1)^i\binom{D-1+i}{i}\binom{D+N}{N-i}T^i .
\]

The exact Padé identity is

\[
T^DQ_{D,N}(T)+(1-T)^{N+1}R_{D,N}(T)=1.
\]

The important point is that this is an identity in the polynomial algebra; after inserting the constant term representation

\[
C_M(d)=\operatorname{CT}\Lambda^M(X)\sum_{\nu\in d\mathbb Z^3}[X^\nu]\Lambda^M,
\]

we obtain

\[
A+H_{M,D,N}=S_{M,D},
\]

where the terms are explicitly

\[
S_{M,D}=\operatorname{CT}\Lambda^M(X)\,\Bigl(\sum_{\nu\in(D-1)\mathbb Z^3}[X^\nu]\Lambda^M\Bigr),
\]

and

\[
H_{M,D,N}=\operatorname{CT}\Lambda^M(X)\sum_i h_i\Bigl(\sum_{\nu\in(D-1+i)\mathbb Z^3}[X^\nu]\Lambda^M\Bigr),
\]

with coefficients

\[
h_i=(-1)^{i+1}\binom{D-1+i}{i}\binom{D+N}{N-i}.
\]

Thus the Padé identity does not create a new arithmetic object; it moves the shell coordinates between two finite combinations.

## 2. Simplification of S using the Newton polytope

For

\[
\Lambda=\frac{(1+x)(1+y)(1+z)((1+y)(1+z)+xyz)}{xyz},
\]

all exponent vectors lie in the cube \([-1,1]^3\). Since

\[
M=a(q-1)+r,
\]

Cartier factorization gives

\[
\Lambda^M\equiv \Lambda^a(X^q)\Lambda^r(X)\pmod q.
\]

Therefore the origin shell is stable under Frobenius, but it is not a new coordinate: it is exactly the same fixed Apéry state coordinate that gives

\[
\operatorname{CT}\Lambda^M=b_M.
\]

The only possible simplification of S is

\[
S_{M,D}=C_M(D-1).
\]

It is not a bounded linear combination of lower shells. The first-cell decomposition gives bounded-order telescopers for individual rays, but the origin shell survives as the distinguished state coordinate.

## 3. Attempt at a second beta-Padé kernel

Take a shifted kernel

\[
Q'_{D,N}(T)=Q_{D+s,N+t}(T).
\]

A two-kernel determinant is

\[
\Delta=
\begin{vmatrix}
A&H\\
A'&H'
\end{vmatrix}
=A H'-A'H.
\]

Using the two Bezout identities gives

\[
\Delta
=\begin{vmatrix}
S-H&H\\
S'-H'&H'
\end{vmatrix}
=S H'-S'H.
\]

Hence cancellation of the large S terms requires

\[
\frac{S'}S=\frac{H'}H.
\]

The shifted shell calculation shows this is equivalent to a relation between distinct shell coordinates

\[
C_M(D-1),\ C_M(D+s-1).
\]

No such relation follows from the Newton support or Cartier factorization.

## 4. Precise distinguished-state obstruction

The obstruction is not the universal kernel obstruction. It is specific to the Apéry origin state:

For every candidate target prime p in the top interval,

\[
p\mid C_M(p-1),
\]

while

\[
p\nmid b_M.
\]

This means the shell target coordinate and the origin state coordinate are separated modulo p. However, every Padé shift still contains the same origin coordinate in its constant-term expansion.

The resulting two-kernel determinant has local form

\[
\Delta_p=u_p C_M(p-1)+v_p b_M,
\]

with

\[
u_p\in\mathbb Z_p^\times.
\]

Because \(b_M\not\equiv0\pmod p\), the determinant loses the target divisibility unless the coefficient of \(b_M\) is independently forced to vanish. The beta-Padé family supplies no such vanishing.

Therefore the exact obstruction is:

> Any finite shifted beta-Padé family has a nonzero projection onto the distinguished origin state, and top target primes are invisible to that projection.

## 5. Radical ledger

For a block \(D<q\le D+N\):

Single kernel:

\[
q\mid A\iff q\mid C_M(q-1),
\]

and

\[
q\mid B
\]

universally.

The two-kernel determinant has valuation ledger:

| source | q-valuation |
|---|---|
| shell target | 1 |
| binomial node factor | 1 |
| origin-state term | 0 |
| shifted determinant | not target selective |

The universal node factor can be removed only at the cost of removing the target divisor.

Hence the remaining radical is exactly the distinguished-state horizontal problem, not a beta-Padé problem.

## 6. Exact verification code

```python
from math import comb
from fractions import Fraction


def Q(D,N,T):
    return sum((-1)**i*comb(D-1+i,i)*comb(D+N,N-i)*T**i
               for i in range(N+1))


def check(D,N):
    # identity at T=0 and T=1
    assert Q(D,N,0)==comb(D+N,N)
    assert Q(D,N,1)==1

for D in range(3,20):
    for N in range(1,10):
        check(D,N)

print('Padé endpoint checks passed')
```

Conclusion: the second beta-Padé kernel does not produce the desired sublinear radical carrier. The surviving obstruction is the actual Apéry distinguished origin state coefficient, which remains a horizontal arithmetic problem.
