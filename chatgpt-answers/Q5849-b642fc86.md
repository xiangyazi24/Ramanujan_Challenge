# Pair-Palm moment attack audit

## Status

The required conclusion is not currently certified from the stated pair-palm data. The fixed Laurent constant-term model gives an exact moment expansion, but the missing step is a pointwise high-moment estimate strong enough to overcome the anchored-star configurations.

## Exact reduction

Let the Apéry shell be represented by

```
b_n = CT(Λ(X)^n)
```

(up to the fixed normalization used in the repository). For the pair-palm moment

```
HM_k = CT( product_{i=1}^k Λ(X_i)^{a_i} )
```

with the Lucas collapse applied modulo a prime p, the only available unconditional saving comes from configurations whose incidence graph has additional rank. The anchored-star family has one central vertex and k leaves; its constraint rank is minimal, so generic multilinear large-sieve cancellation does not apply.

## What a successful estimate would need

A sufficient inequality would have the form

```
Σ_{p in (n/2,n]} 1_{p | b_{n-p}}
 <= exp(o(n))
```

obtained from a moment bound such as

```
HM_7 <= exp(7(1-ε)n) · exp(O(log n))
```

for some fixed ε>0 uniformly over the admissible Lucas cells. The missing estimate is precisely a saving against the anchored-star contribution.

## Audit of proposed mechanisms

### Multilinear large sieve

Fails at the current level because the star incidence matrix has rank one less than the generic family. The large-sieve loss matches the main term.

### Determinant method

A determinant can kill repeated independent incidences, but the anchored star survives as a low-rank exceptional variety. A new determinant would need an additional shell-specific nondegeneracy lemma.

### Product formula

The product formula controls global norms, but does not distinguish the star locus from generic tuples without an auxiliary height drop.

## Precise missing lemma

A sufficient new theorem is:

> For k=7, the contribution of all anchored-star Lucas-compatible tuples satisfies
>
> ```
> Star_7(n) <= exp((7-δ)n)
> ```
> for some δ>0 independent of n.

This is the exact missing estimate. Existing constant-term and Lucas identities establish the decomposition but not this inequality.

## Checker

A dependency-free audit should verify:

```text
1. enumerate rank strata of the k=7 incidence matrices;
2. isolate the anchored-star stratum;
3. compute its Laurent coefficient dimension;
4. compare the resulting exponent with the required δ saving.
```

Until step 4 produces a strict exponent gap, the pair-palm route remains an exact reformulation with a single unresolved high-moment bound rather than a completed proof of log G_n=o(n).
