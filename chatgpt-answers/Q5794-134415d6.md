# Exact Kummer flat-cell formulas and a Lucas-only checker

I audited the project at commit `71192dbac8cbf24e27a7b48a8d1999b6f2b2ad41`, together with the exact shell and Newton identities in the current Problem 3.2 scripts. This note corrects one off-by-one from the earlier translated-stack discussion: the family requested here has `0 <= s <= m-2`, so its upper shell endpoint is `D+N+m-1`, not `D+N+m`.

The words "necessary and sufficient" below always refer to the termwise Kummer flatness mechanism. They do not assert necessity for the evaluated shell or minor to vanish, because an evaluated value can also vanish through targetness or a nontrivial cancellation.

## 1. General rectangle and the quotient-free primitive minor

```text
Fix integers

    s_minus <= s <= s_plus,
    t_minus <= t <= t_plus,
    L+t >= 0.

For one member of the rectangle put

    D = d+s,
    K = L+t.

The adjacent carriers in E_{D,K} use sequence indices

    D <= x <= D+K+1.

The Y sequence uses moment n-1.  The Z sequence uses moments n,...,n+4
and shifts every shell node x by -1 and +1.  Therefore the exact shell
support envelope for the whole rectangle is

    e_minus = d+s_minus-1,
    e_plus  = d+L+s_plus+t_plus+2,

and the exact moment range is

    M_minus = n-1,
    M_plus  = n+4.

Both endpoint pairs (M_plus,e_minus) and (M_plus,e_plus) really occur in
the coefficientwise Z expansion: use j=4 and respectively the -1 or +1
shell shift.

A sufficient uniform first-cell hypothesis for every shell in the
rectangle is

    2*e_minus > n+4,
    e_plus <= n-1.
```

The Newton formulas are:

```text
G_{D,K}(F)
  = sum_{i=0}^K (-1)^i
      binom(D+i,i) binom(D+K+1,K-i) F_{D+i}.

B_{D,K} = binom(D+K+1,K).

H_{D,K}(F)
  = sum_{i=0}^{K+1} (-1)^i binom(K+1,i) F_{D+i}
  = (-1)^(K+1) Delta^(K+1) F_D.

G_{D,K}(F)-G_{D+1,K}(F) = B_{D,K} H_{D,K}(F).
```

Substitution into the determinant gives an identity over the integers, before any modular reduction:

```text
E_{D,K}
  = [G_{D,K}(Y)G_{D+1,K}(Z)
       -G_{D+1,K}(Y)G_{D,K}(Z)] / B_{D,K}

  = H_{D,K}(Y)G_{D,K}(Z)
       -G_{D,K}(Y)H_{D,K}(Z).
```

Proof:

```text
Write A=G_{D,K}(Y), C=G_{D,K}(Z),
HY=H_{D,K}(Y), HZ=H_{D,K}(Z), and B=B_{D,K}.
The adjacent identity gives

    G_{D+1,K}(Y) = A-B*HY,
    G_{D+1,K}(Z) = C-B*HZ.

Hence the raw determinant is

    A(C-B*HZ) - (A-B*HY)C
      = B(HY*C-A*HZ).

Division by B is therefore performed integrally and gives the displayed
quotient-free formula.  This is the correct formula to reduce modulo q;
one must not divide a congruence by B modulo q.
```

For reference, the common prime-node interval for every minor in the general rectangle is

```text
    d+s_plus+2 <= p <= d+L+s_minus+t_minus+1.

Indeed, p-1 must lie in the overlap [D+1,D+K] of the two adjacent
carriers for every pair (s,t).
```

## 2. Exact one-shell Kummer lemma

The sigma convention is as follows.

```text
Let q >= 5 be prime.  Let alpha be 1 or 2 and write

    M = alpha*q+r,        0 <= r < q.

For the first-cell branch relevant here set

    c = alpha-1,
    e = c*q+sigma = (alpha-1)*q+sigma,
    0 < sigma < q.

Thus alpha=1 means e=sigma, while alpha=2 means e=q+sigma.
The value c is not an extra free parameter: the first-cell condition
M/2 < e <= M forces c=alpha-1 in these two branches.
```

### Lemma 2.1: termwise flatness

```text
Assume

    r < sigma < q-r.                                      (2.1)

Then, for every t for which binom(M,t) is nonzero modulo q, every
noncentral binomial in both packets

    X = sum_{u=-1}^1 binom(M,M-t+e*u),
    Y = sum_{v=-1}^1 binom(2M-t,M-t+e*v)

is divisible by q.  Consequently only the central terms survive and

    C_M(e) = b_alpha*b_r  (mod q).                         (2.2)

In particular

    C_{q+r}(e)  = 5*b_r   (mod q),
    C_{2q+r}(e) = 73*b_r  (mod q).
```

Proof and exact converse for the termwise mechanism:

```text
Lucas gives

    q does not divide binom(M,t)

if and only if

    t = beta*q+a,
    0 <= beta <= alpha,
    0 <= a <= r.

Condition (2.1) implies 2*r < q.

Use symmetry to write the X packet as

    binom(M,t) + binom(M,t-e) + binom(M,t+e).

For t+e, the low base-q digit is a+sigma.  It is less than q and greater
than r, so Lucas kills binom(M,t+e).

For t-e, borrowing gives low digit q+a-sigma.  It is greater than r
because sigma < q-r, so Lucas kills binom(M,t-e) whenever the index is
in range.

For the Y packet,

    2M-t = (2*alpha-beta)q + (2r-a),

with 0 <= 2r-a < q.  The +e lower index has low digit r-a+sigma, which
is greater than 2r-a because sigma > r.  The -e lower index, after one
borrow, has low digit q+r-a-sigma, which is greater than 2r-a because
q-sigma > r.  Lucas therefore kills both side terms.

The central contribution is

    sum_t binom(M,t)^2 binom(2M-t,M-t)^2 = b_M.

Lucas separates the beta and a sums, giving

    b_M = b_alpha*b_r (mod q).

No cancellation among surviving noncentral terms is used.

Conversely, if sigma <= r, take t=0.  Then binom(M,e) is a q-unit, so a
side term survives.  If q-sigma <= r, take t=alpha*q.  The outer
binomial is a q-unit and the side term binom(M,q-sigma) is a q-unit.
Therefore

    r < sigma < q-r

is necessary and sufficient for this termwise side-packet collapse.
It is not necessary for C_M(e)=0, C_M(e)=b_alpha*b_r, or E=0 after
arithmetic cancellation.
```

## 3. Exact coefficient-forced criterion for the whole rectangle

First require the six moments to have the same leading base-q digit:

```text
    alpha*q <= n-1,
    n+4 < (alpha+1)*q.                                    (3.1)
```

Set

```text
    r_star = n+4-alpha*q.
```

Since the flat interval shrinks as the residue r grows, the moment n+4 is the unique worst moment. Lemma 2.1 applied to the two shell endpoints gives:

```text
Every shell occurring coefficientwise in the rectangle is termwise flat
if and only if

    r_star < e_minus-(alpha-1)*q,
    e_plus-(alpha-1)*q < q-r_star.                        (3.2)

Equivalently, the two strict inequalities are

    q > n+4-e_minus,                                      (3.3a)
    2*alpha*q > n+4+e_plus.                               (3.3b)

Because all quantities are integral, the exactly equivalent weak integer
forms are

    q >= n+5-e_minus,                                     (3.4a)
    2*alpha*q >= n+5+e_plus.                              (3.4b)
```

These two inequalities, together with (3.1), are necessary and sufficient for coefficientwise termwise flatness of the entire rectangle. They are only sufficient for actual minor divisibility.

Let

```text
    k = n-alpha*q.
```

Under (3.1)-(3.4), every sequence value on the union of the stencils is constant modulo q:

```text
    Y_x = C_{n-1}(x)
        = b_alpha*b_{k-1}                                (mod q),

    Z_x = sum_{j=0}^4 u_j(n)
            [C_{n+j}(x-1)+C_{n+j}(x+1)]
        = 2*b_alpha*sum_{j=0}^4 u_j(n)b_{k+j}            (mod q).
```

Therefore:

```text
    H_{D,K}(Y) = 0 (mod q),
    H_{D,K}(Z) = 0 (mod q),
    E_{D,K}    = 0 (mod q)

for every (D,K) in the rectangle.
```

This is coefficient-forced divisibility. It does not use either distinguished congruence

```text
    b_{k-1}=0 (mod q)
```

or

```text
    sum_j u_j(n)b_{k+j}=0 (mod q).
```

The two constants may both be nonzero.

## 4. Exact alpha=1 and alpha=2 endpoints

For a completely general rectangle define

```text
    ceil_div(A,B) = the least integer z with B*z >= A.

    Q_alpha = max(
        ceil_div(n+5,alpha+1),
        n+5-e_minus,
        ceil_div(n+5+e_plus,2*alpha)
    ).

    U_alpha = floor((n-1)/alpha).
```

Then the exact coefficient-forced prime interval is

```text
    Q_alpha <= q <= U_alpha,
    q prime.
```

It is empty when `Q_alpha > U_alpha`. In offset form:

```text
    k = n-alpha*q,
    k_min = n-alpha*U_alpha,
    K_alpha = n-alpha*Q_alpha,

    k_min <= k <= K_alpha,
    k = n (mod alpha).
```

Thus for alpha=2 the parity restriction is part of the exact endpoint: only offsets k having the same parity as n occur.

Expanded forms are:

```text
alpha=1:

    K_top = min(
        e_minus-5,
        floor((n-e_plus-5)/2),
        floor((n-5)/2)
    ).

    1 <= k=n-q <= K_top.

alpha=2:

    K_half_raw = min(
        2*e_minus-n-10,
        floor((n-e_plus-5)/2),
        floor((n-9)/3)
    ).

    k=n-2q has the same parity as n.
    K_half is the largest integer <= K_half_raw having that parity.
    The smallest allowed positive k is 1 for odd n and 2 for even n.
```

The `-10` in the alpha=2 first bound is important. It comes from the weak integer inequality

```text
    q >= n+5-e_minus
```

and the identity `2q=n-k`; parity prevents replacing it by a weaker `-9` bound.

## 5. Fixed-core, increasing-margin family

Use exactly the family requested in the question:

```text
    I = [D,D+N-1],
    m >= 2,
    d0 = D-m+1,
    L  = N+m-2,

    E_{d0+s,L},       0 <= s <= m-2.                     (5.1)
```

This family contains `m-1` minors. Its exact shell envelope is

```text
    e_minus = D-m,
    e_plus  = D+N+m-1,                                  (5.2)

    M_minus = n-1,
    M_plus  = n+4.
```

The common prime-node interval is

```text
    D+1 <= p <= D+N.                                     (5.3)
```

Thus this `0 <= s <= m-2` family retains `N` integer prime-node slots. The earlier one-step-larger translated stack `0 <= s <= m-1` instead starts its common interval at `D+2`; the two families must not be conflated.

Substituting (5.2) into the two flatness inequalities gives the exact strict forms

```text
    q > n-D+m+4,                                         (5.4a)
    2*alpha*q > n+D+N+m+3.                               (5.4b)
```

and the exactly equivalent weak integer forms

```text
    q >= n-D+m+5,                                        (5.5a)
    2*alpha*q >= n+D+N+m+4.                              (5.5b)
```

The top and half offset bounds are therefore

```text
alpha=1, q=n-k:

    K_top(m) = min(
        D-m-5,
        floor((n-D-N-m-4)/2),

alpha=2, 2q=n-k:

    K_half(m) is the largest integer <= K_half_raw(m)
```

### The two natural first-cell margins

The full family remains inside the displayed first cell exactly while

```text
    2*(D-m) > n+4,
    D+N+m-1 <= n-1.
```

Hence the two natural width caps are

```text
    m_left  = D-floor((n+4)/2)-1,
    m_right = n-D-N,
    m_full  = min(m_left,m_right).                       (5.8)
```

The two flatness inequalities kill different branches:

```text
1. If the right margin is active, so m_full=m_right, then

       floor((n-D-N-m_full-4)/2) = -2.

   Inequality (5.5b), the right-end inequality, kills both the alpha=1
   near-n tail and the alpha=2 half tail.

2. If the left margin is active, so m_full=m_left, then the alpha=2
   first bound in (5.7) equals

       -4  when n is even,
       -5  when n is odd.

   Thus inequality (5.5a), the left-end inequality, kills the alpha=2
   half tail.

   The same left inequality does not kill the alpha=1 near-n tail.  Put

       delta = m_right-m_left.

   At m=m_left, the remaining alpha=1 bound supplied by the right
   inequality is

       floor((delta-4)/2).                               (5.9)

   Therefore the near-n tail is empty exactly when delta <= 5.  If
   delta=6, one coefficient-forced layer k=1 remains; if delta is larger,
   (5.9) gives the exact number of possible offset layers.
```

For the placement used with the Q5787 rectangle,

```text
    D = floor(13*n/20)-1,
    N = floor(n/5)+1.
```

Write `n=20*u+r`, `0 <= r < 20`. Then

```text
    delta
      = r-2*floor(13*r/20)-floor(r/5)+floor((r+4)/2)+2,

    delta is in {4,5,6}.
```

More precisely:

```text
    delta=6 exactly for r in {3,4,6,9,12,18}.
```

Consequently, for the family (5.1) at its admissible full left margin:

```text
    the alpha=2 half tail is always empty;

    the alpha=1 near-n tail is empty when delta is 4 or 5;

    when delta=6, the only possible coefficient-forced offset is k=1,
    namely q=n-1, and it contributes only when n-1 is prime.
```

This last one-layer residue is the exact off-by-one correction forced by the requested range `0 <= s <= m-2`. The earlier range `0 <= s <= m-1` has `e_plus` one unit larger and removes that layer.

## 6. What is coefficient-forced, target-forced, or accidental

```text
Coefficient-forced:
    Conditions (3.1), (3.4a), and (3.4b) hold.  Every shell side packet
    is killed termwise.  Divisibility is independent of all u_j(n).

Target-forced:
    q-1 lies in the common prime-node interval, the Newton stencil length
    is less than q, and b_{n-alpha*q}=0 modulo q.  This uses the
    distinguished Apéry/Ore-CRT values and is not a consequence of the
    flat-cell inequalities.

Accidental evaluated divisibility:
    All actual minors vanish modulo q outside both preceding mechanisms.
    This requires the actual five values u_j(n) and may come from a
    cancellation among nonzero shell or minor terms.

Extra universal cancellation:
    Every coefficient-basis minor E(Y,Z_j) vanishes even though the
    termwise inequalities fail.  This is independent of u_j but is still
    not termwise Kummer flatness.
```

The checker below never labels a converse without evidence. The coefficient-forced audit is performed in the five independent basis directions

```text
    Z_j(x) = C_{n+j}(x-1)+C_{n+j}(x+1),   0 <= j <= 4.
```

Since the primitive minor is linear in Z, vanishing of every basis minor proves vanishing for the actual

```text
    Z = sum_j u_j(n) Z_j
```

without knowing the degree-32 coefficients. An optional JSON file containing those coefficients activates exact actual-Z classification of target and accidental primes. The JSON format is a list of five coefficient lists, in ascending powers of n.

## 7. Standalone pure-Python checker

The program uses Lucas digits for every binomial coefficient and keeps every shell, carrier, and minor value reduced modulo q. It never constructs a large integer shell. By default it scans every stable alpha=1 and alpha=2 prime for every `50 <= n <= 400`, for both the 3 by 5 rectangle and the admissible full-margin family. The `--fast` option checks only predicted and target candidates. The optional `--all-widths` option checks every admissible translated width, not only the full margin.

```python
#!/usr/bin/env python3
"""Lucas-only audit of the Q5794 Kummer cross-minor formulas.

Default:
    n = 50,...,400
    all stable alpha=1 and alpha=2 primes
    the Q5787 3 by 5 rectangle
    the corrected full-margin family 0 <= s <= m-2

No large shell integer is formed.  All arithmetic is modulo q.

Optional actual Ore-CRT coefficients:
    --u-coeffs FILE.json

The JSON object must be a list of five lists.  The j-th inner list holds
coefficients of u_j(n) in ascending powers of n.
"""

from __future__ import annotations

import argparse
import json
from dataclasses import dataclass
from functools import lru_cache
from math import isqrt
from typing import Optional


def ceil_div(a: int, b: int) -> int:
    assert b > 0
    return -((-a) // b)


def primes_upto(limit: int) -> list[int]:
    if limit < 2:
        return []
    mark = bytearray(b"\x01") * (limit + 1)
    mark[0] = 0
    mark[1] = 0
    for p in range(2, isqrt(limit) + 1):
        if mark[p]:
            start = p * p
            count = (limit - start) // p + 1
            mark[start : limit + 1 : p] = b"\x00" * count
    return [p for p in range(2, limit + 1) if mark[p]]


class Lucas:
    """Binomial coefficients modulo one prime, with digit caching."""

    def __init__(self, prime: int) -> None:
        if prime < 2:
            raise ValueError("prime must be at least 2")
        self.p = prime
        self.fac = [1] * prime
        for i in range(1, prime):
            self.fac[i] = self.fac[i - 1] * i % prime
        self.ifac = [1] * prime
        self.ifac[-1] = pow(self.fac[-1], prime - 2, prime)
        for i in range(prime - 1, 0, -1):
            self.ifac[i - 1] = self.ifac[i] * i % prime
        self.cache: dict[tuple[int, int], int] = {}

    def small(self, n: int, k: int) -> int:
        if not 0 <= k <= n < self.p:
            return 0
        return (
            self.fac[n]
            * self.ifac[k]
            * self.ifac[n - k]
            % self.p
        )

    def choose(self, n: int, k: int) -> int:
        if k < 0 or k > n:
            return 0
        k = min(k, n - k)
        key = (n, k)
        saved = self.cache.get(key)
        if saved is not None:
            return saved
        nn = n
        kk = k
        out = 1
        while nn or kk:
            nd = nn % self.p
            kd = kk % self.p
            if kd > nd:
                out = 0
                break
            out = out * self.small(nd, kd) % self.p
            nn //= self.p
            kk //= self.p
        self.cache[key] = out
        return out


class ShellMod:
    """Exact first-cell shell values modulo one prime."""

    def __init__(self, prime: int) -> None:
        self.p = prime
        self.lucas = Lucas(prime)
        self.cache: dict[tuple[int, int], int] = {}

    def shell(self, moment: int, node: int) -> int:
        key = (moment, node)
        saved = self.cache.get(key)
        if saved is not None:
            return saved
        if not (0 < node <= moment and 2 * node > moment):
            raise ValueError(
                f"not in first cell: M={moment}, e={node}"
            )
        c = self.lucas.choose
        total = 0
        for t in range(moment + 1):
            outer = c(moment, t)
            if outer == 0:
                continue
            base = moment - t
            x_packet = (
                c(moment, base - node)
                + c(moment, base)
                + c(moment, base + node)
            ) % self.p
            y_packet = (
                c(2 * moment - t, base - node)
                + c(2 * moment - t, base)
                + c(2 * moment - t, base + node)
            ) % self.p
            total = (
                total + outer * x_packet * y_packet * y_packet
            ) % self.p
        self.cache[key] = total
        return total


@lru_cache(maxsize=None)
def apery_mod(index: int, prime: int) -> int:
    """Apéry b_index modulo prime; assumes 0 <= index < prime."""

    if not 0 <= index < prime:
        raise ValueError((index, prime))
    if index == 0:
        return 1
    b0 = 1
    b1 = 5 % prime
    if index == 1:
        return b1
    for k in range(1, index):
        p_k = (2 * k + 1) * (17 * k * k + 17 * k + 5)
        numerator = (p_k * b1 - k**3 * b0) % prime
        denominator = pow(k + 1, 3, prime)
        b2 = numerator * pow(denominator, prime - 2, prime) % prime
        b0, b1 = b1, b2
    return b1


@dataclass(frozen=True)
class Family:
    label: str
    kind: str
    minors: tuple[tuple[int, int], ...]
    e_minus: int
    e_plus: int
    target_q_lo: int
    target_q_hi: int


def rectangle_family(
    label: str,
    kind: str,
    d: int,
    length: int,
    s_minus: int,
    s_plus: int,
    t_minus: int,
    t_plus: int,
) -> Family:
    minors = tuple(
        (d + s, length + t)
        for s in range(s_minus, s_plus + 1)
        for t in range(t_minus, t_plus + 1)
    )
    if any(k < 0 for _, k in minors):
        raise ValueError("negative Newton length")
    return Family(
        label=label,
        kind=kind,
        minors=minors,
        e_minus=d + s_minus - 1,
        e_plus=d + length + s_plus + t_plus + 2,
        target_q_lo=d + s_plus + 2,
        target_q_hi=d + length + s_minus + t_minus + 1,
    )


def translated_family(D: int, N: int, m: int, kind: str) -> Family:
    if m < 2:
        raise ValueError("m must be at least 2")
    d0 = D - m + 1
    length = N + m - 2
    family = rectangle_family(
        label=f"translated(D={D},N={N},m={m})",
        kind=kind,
        d=d0,
        length=length,
        s_minus=0,
        s_plus=m - 2,
        t_minus=0,
        t_plus=0,
    )
    assert family.e_minus == D - m
    assert family.e_plus == D + N + m - 1
    assert family.target_q_lo == D + 1
    assert family.target_q_hi == D + N
    return family


def first_cell_ok(n: int, family: Family) -> bool:
    return (
        2 * family.e_minus > n + 4
        and family.e_plus <= n - 1
    )


def quotient_stable(n: int, q: int, alpha: int) -> bool:
    return alpha * q <= n - 1 and n + 4 < (alpha + 1) * q


def coefficient_forced(n: int, q: int, alpha: int, family: Family) -> bool:
    return (
        quotient_stable(n, q, alpha)
        and q >= n + 5 - family.e_minus
        and 2 * alpha * q >= n + 5 + family.e_plus
    )


def q_bounds(n: int, alpha: int, family: Family) -> tuple[int, int]:
    q_lo = max(
        ceil_div(n + 5, alpha + 1),
        n + 5 - family.e_minus,
        ceil_div(n + 5 + family.e_plus, 2 * alpha),
    )
    q_hi = (n - 1) // alpha
    return q_lo, q_hi


def carrier(
    values: dict[int, int],
    d: int,
    length: int,
    lucas: Lucas,
) -> int:
    q = lucas.p
    out = 0
    for i in range(length + 1):
        weight = (
            lucas.choose(d + i, i)
            * lucas.choose(d + length + 1, length - i)
        ) % q
        if i & 1:
            weight = -weight
        out = (out + weight * values[d + i]) % q
    return out


def high_difference(
    values: dict[int, int],
    d: int,
    length: int,
    lucas: Lucas,
) -> int:
    q = lucas.p
    out = 0
    for i in range(length + 2):
        weight = lucas.choose(length + 1, i)
        if i & 1:
            weight = -weight
        out = (out + weight * values[d + i]) % q
    return out


def primitive_minor_from_parts(
    gy: int,
    hy: int,
    z_values: dict[int, int],
    d: int,
    length: int,
    lucas: Lucas,
) -> int:
    gz = carrier(z_values, d, length, lucas)
    hz = high_difference(z_values, d, length, lucas)
    return (hy * gz - gy * hz) % lucas.p


def poly_eval_mod(coefficients: list[int], n: int, q: int) -> int:
    out = 0
    for coefficient in reversed(coefficients):
        out = (out * n + coefficient) % q
    return out


def load_u_coefficients(path: Optional[str]) -> Optional[list[list[int]]]:
    if path is None:
        return None
    with open(path, "r", encoding="utf-8") as handle:
        data = json.load(handle)
    if not isinstance(data, list) or len(data) != 5:
        raise ValueError("u coefficient JSON must contain five lists")
    out: list[list[int]] = []
    for row in data:
        if not isinstance(row, list) or not all(isinstance(x, int) for x in row):
            raise ValueError("every u_j row must be a list of integers")
        out.append(row)
    return out


@dataclass
class ExactResult:
    used_shells_equal_flat_residue: bool
    every_basis_minor_zero: bool
    every_actual_minor_zero: Optional[bool]


def exact_family_evaluation(
    n: int,
    q: int,
    alpha: int,
    family: Family,
    oracle: ShellMod,
    u_coefficients: Optional[list[list[int]]],
) -> ExactResult:
    x_lo = min(d for d, _ in family.minors)
    x_hi = max(d + length + 1 for d, length in family.minors)
    xs = range(x_lo, x_hi + 1)

    b_alpha = apery_mod(alpha, q)
    r_y = n - 1 - alpha * q
    if not 0 <= r_y < q:
        raise AssertionError((n, q, alpha, r_y))
    expected_y = b_alpha * apery_mod(r_y, q) % q

    y_values: dict[int, int] = {}
    flat_equal = True
    for x in xs:
        value = oracle.shell(n - 1, x)
        y_values[x] = value
        if value != expected_y:
            flat_equal = False

    z_basis: list[dict[int, int]] = []
    for j in range(5):
        moment = n + j
        residue = moment - alpha * q
        if not 0 <= residue < q:
            raise AssertionError((n, q, alpha, moment, residue))
        expected = b_alpha * apery_mod(residue, q) % q
        values: dict[int, int] = {}
        for x in xs:
            left = oracle.shell(moment, x - 1)
            right = oracle.shell(moment, x + 1)
            if left != expected or right != expected:
                flat_equal = False
            values[x] = (left + right) % q
        z_basis.append(values)

    u_values: Optional[list[int]] = None
    actual_z: Optional[dict[int, int]] = None
    if u_coefficients is not None:
        u_values = [poly_eval_mod(row, n, q) for row in u_coefficients]
        actual_z = {
            x: sum(u_values[j] * z_basis[j][x] for j in range(5)) % q
            for x in xs
        }

    basis_all_zero = True
    actual_all_zero: Optional[bool] = None if actual_z is None else True

    for d, length in family.minors:
        gy = carrier(y_values, d, length, oracle.lucas)
        hy = high_difference(y_values, d, length, oracle.lucas)

        basis_minors = [
            primitive_minor_from_parts(
                gy, hy, z_basis[j], d, length, oracle.lucas
            )
            for j in range(5)
        ]
        if any(value != 0 for value in basis_minors):
            basis_all_zero = False

        if actual_z is not None and u_values is not None:
            actual_minor = primitive_minor_from_parts(
                gy, hy, actual_z, d, length, oracle.lucas
            )
            multiplication_back = sum(
                u_values[j] * basis_minors[j] for j in range(5)
            ) % q
            assert actual_minor == multiplication_back
            if actual_minor != 0:
                actual_all_zero = False

    return ExactResult(
        used_shells_equal_flat_residue=flat_equal,
        every_basis_minor_zero=basis_all_zero,
        every_actual_minor_zero=actual_all_zero,
    )


def target_candidate(n: int, q: int, alpha: int, family: Family) -> bool:
    if not quotient_stable(n, q, alpha):
        return False
    if not family.target_q_lo <= q <= family.target_q_hi:
        return False
    if not all(length < q for _, length in family.minors):
        return False
    residue = n - alpha * q
    return apery_mod(residue, q) == 0


def append_sample(record: dict, category: str, item: tuple) -> None:
    record[category] = record.get(category, 0) + 1
    key = category + "_samples"
    samples = record.setdefault(key, [])
    if len(samples) < 20:
        samples.append(item)


def verify_newton_identity() -> None:
    for q in (5, 7, 11, 13):
        lucas = Lucas(q)
        for d in range(2, 9):
            for length in range(0, 6):
                values_y = {
                    x: (x**3 + 7 * x + 11) % q
                    for x in range(d, d + length + 2)
                }
                values_z = {
                    x: (3**x + x * x + 5) % q
                    for x in range(d, d + length + 2)
                }
                gy = carrier(values_y, d, length, lucas)
                gy1 = carrier(values_y, d + 1, length, lucas)
                hy = high_difference(values_y, d, length, lucas)
                gz = carrier(values_z, d, length, lucas)
                gz1 = carrier(values_z, d + 1, length, lucas)
                hz = high_difference(values_z, d, length, lucas)
                b = lucas.choose(d + length + 1, length)
                assert (gy - gy1 - b * hy) % q == 0
                assert (gz - gz1 - b * hz) % q == 0
                raw = (gy * gz1 - gy1 * gz) % q
                primitive = (hy * gz - gy * hz) % q
                assert raw == b * primitive % q


def first_prime_at_least(lower: int, primes: list[int]) -> int:
    for q in primes:
        if q >= lower:
            return q
    raise ValueError(lower)


def verify_q5787_table() -> None:
    expected = (
        (236, 151, 48, 13, 223, 223),
        (272, 174, 55, 16, 256, 257),
        (300, 193, 61, 17, 283, 283),
        (311, 200, 63, 18, 293, 293),
        (350, 225, 71, 21, 329, 331),
        (400, 258, 81, 25, 375, 379),
    )
    primes = primes_upto(500)
    for n, d0, l0, k0, p0, first0 in expected:
        d = 13 * n // 20 - 2
        length = n // 5 + 1
        k_raw = (n - d - length - 11) // 2
        endpoint = n - k_raw
        first = first_prime_at_least(endpoint, primes)
        family = rectangle_family(
            "table", "rect3x5", d, length, 0, 2, -2, 2
        )
        q_lo, _ = q_bounds(n, 1, family)
        assert (d, length, k_raw, endpoint, first) == (
            d0, l0, k0, p0, first0
        )
        assert n - q_lo == k_raw


def verify_full_margin_residues() -> None:
    residue_six = {3, 4, 6, 9, 12, 18}
    for n in range(50, 401):
        D = 13 * n // 20 - 1
        N = n // 5 + 1
        m_left = D - (n + 4) // 2 - 1
        m_right = n - D - N
        delta = m_right - m_left
        assert delta in {4, 5, 6}
        assert (delta == 6) == (n % 20 in residue_six)
        assert m_left >= 2
        assert m_left <= m_right
        family = translated_family(D, N, m_left, "translated_full")
        assert first_cell_ok(n, family)

        q_lo_top, _ = q_bounds(n, 1, family)
        k_top = n - q_lo_top
        assert k_top == (1 if delta == 6 else 0)

        q_lo_half, _ = q_bounds(n, 2, family)
        k_half = n - 2 * q_lo_half
        assert k_half < 1


def audit_range(
    n_min: int,
    n_max: int,
    scan_all: bool,
    all_widths: bool,
    u_coefficients: Optional[list[list[int]]],
    quiet: bool,
) -> None:
    primes = primes_upto(n_max)
    stats: dict[tuple[str, int], dict] = {}

    for n in range(n_min, n_max + 1):
        d = 13 * n // 20 - 2
        base_length = n // 5 + 1
        rectangle = rectangle_family(
            label=f"rect3x5(n={n})",
            kind="rect3x5",
            d=d,
            length=base_length,
            s_minus=0,
            s_plus=2,
            t_minus=-2,
            t_plus=2,
        )
        if not first_cell_ok(n, rectangle):
            raise AssertionError((n, rectangle))

        D = d + 1
        N = base_length
        m_left = D - (n + 4) // 2 - 1
        m_right = n - D - N
        m_full = min(m_left, m_right)
        if m_full < 2:
            raise AssertionError((n, D, N, m_left, m_right))

        if all_widths:
            translated = [
                translated_family(D, N, m, "translated_width")
                for m in range(2, m_full + 1)
            ]
        else:
            translated = [
                translated_family(D, N, m_full, "translated_full")
            ]

        families = [rectangle] + translated
        for family in families:
            if not first_cell_ok(n, family):
                raise AssertionError((n, family))

        n_primes = [q for q in primes if 5 <= q <= n]
        for alpha in (1, 2):
            for q in n_primes:
                if not quotient_stable(n, q, alpha):
                    continue

                work: list[tuple[Family, bool, bool]] = []
                for family in families:
                    predicted = coefficient_forced(n, q, alpha, family)
                    target = target_candidate(n, q, alpha, family)
                    if scan_all or predicted or target:
                        work.append((family, predicted, target))
                if not work:
                    continue

                oracle = ShellMod(q)
                for family, predicted, target in work:
                    result = exact_family_evaluation(
                        n=n,
                        q=q,
                        alpha=alpha,
                        family=family,
                        oracle=oracle,
                        u_coefficients=u_coefficients,
                    )
                    key = (family.kind, alpha)
                    record = stats.setdefault(key, {})
                    append_sample(record, "checked", (n, family.label, q))

                    if predicted:
                        append_sample(record, "predicted", (n, family.label, q))
                        assert result.used_shells_equal_flat_residue, (
                            "predicted shell-flat failure",
                            n,
                            q,
                            alpha,
                            family,
                        )
                        assert result.every_basis_minor_zero, (
                            "predicted basis-minor failure",
                            n,
                            q,
                            alpha,
                            family,
                        )
                        if result.every_actual_minor_zero is not None:
                            assert result.every_actual_minor_zero

                    if target:
                        append_sample(record, "target", (n, family.label, q))

                    if (
                        result.used_shells_equal_flat_residue
                        and not predicted
                    ):
                        append_sample(
                            record,
                            "extra_shell_equality",
                            (n, family.label, q, target),
                        )

                    if result.every_basis_minor_zero and not predicted:
                        append_sample(
                            record,
                            "extra_universal_minor",
                            (n, family.label, q, target),
                        )

                    actual = result.every_actual_minor_zero
                    if actual and not predicted:
                        if target:
                            category = "actual_target_not_flat"
                        else:
                            category = "actual_accidental"
                        append_sample(
                            record,
                            category,
                            (n, family.label, q),
                        )

        if not quiet and (n == n_min or n == n_max or n % 25 == 0):
            print("PROGRESS", n)

    print("Q5794_LUCAS_AUDIT=PASS")
    print("N_RANGE", n_min, n_max)
    print("SCAN_ALL_STABLE_PRIMES", scan_all)
    print("ALL_TRANSLATED_WIDTHS", all_widths)
    print("ACTUAL_U_COEFFICIENTS", u_coefficients is not None)
    for key in sorted(stats):
        kind, alpha = key
        record = stats[key]
        print("SUMMARY", kind, "alpha", alpha)
        for category in sorted(record):
            if category.endswith("_samples"):
                continue
            print(" ", category, record[category])
            samples = record.get(category + "_samples", [])
            if category not in {"checked", "predicted"} and samples:
                print("   samples", samples)


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--n-min", type=int, default=50)
    parser.add_argument("--n-max", type=int, default=400)
    parser.add_argument(
        "--fast",
        action="store_true",
        help="evaluate only predicted-flat or target candidates",
    )
    parser.add_argument(
        "--all-widths",
        action="store_true",
        help="audit every admissible translated width",
    )
    parser.add_argument(
        "--u-coeffs",
        type=str,
        default=None,
        help="optional JSON coefficient table for the five u_j",
    )
    parser.add_argument("--quiet", action="store_true")
    args = parser.parse_args()

    if args.n_min < 50 or args.n_max < args.n_min:

    u_coefficients = load_u_coefficients(args.u_coeffs)
    audit_range(
        n_min=args.n_min,
        n_max=args.n_max,
        scan_all=not args.fast,
        all_widths=args.all_widths,
        u_coefficients=u_coefficients,
        quiet=args.quiet,
    )


if __name__ == "__main__":

```

The decisive assertions are:

```text
For every predicted coefficient-forced prime:

    every used shell equals the flat residue b_alpha*b_r modulo q;
    every one of the five coefficient-basis primitive minors is 0 modulo q;
    if actual u_j coefficients are supplied, every actual primitive minor is 0.

Outside the predicted interval, the program does not infer nondivisibility.
It reports separately:

    extra_shell_equality,
    extra_universal_minor,
    target,
    actual_target_not_flat,
    actual_accidental.
```

This separation is the conservative one required by the question: failure of a strict carry inequality proves only failure of termwise Kummer flatness, not failure of the evaluated minor to vanish.
