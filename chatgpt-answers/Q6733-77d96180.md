# Q6733 run-rigidity audit

## Verdict first

The proposed run-rigidity mechanism is partially correct, but the requested [NO-RUN] theorem is not proved from the supplied ingredients. The two-run eigenvector reduction is valid. The three-run bounded-degree curve reduction is also valid after adding one missing exceptional-branch analysis. However, the amplification to an O(D) bound for all 3-runs and then to a full [NO-RUN] statement requires a uniform treatment of the c_r=0 branch and of the points where the explicit eigenvector formula degenerates. Those steps are not currently certified.

I therefore do NOT mark [NO-RUN] as PROVED-all-h. The strongest justified statement is a conditional run-rigidity reduction.

## Step 1: two consecutive elements of Z_d

Let

M_s = [[0,1],[-beta_s,alpha_s]].

For u=(u1:u2),

M_s u = (u2, -beta_s*u1 + alpha_s*u2).

The determinant of the two image vectors is

 det(M_r u, M_{r+d} u)
 = u2*((beta_r-beta_{r+d})u1 + (alpha_{r+d}-alpha_r)u2).

So the claimed collapse is correct.

Hence a 2-run has two branches:

1. u2 = 0, meaning c_r = 0.

2. The orbit point is forced to

 v(r,d)=(alpha_r-alpha_{r+d} : beta_r-beta_{r+d}).

This uses only the companion matrix formula.

## Degeneracy check

The second branch requires that the two coordinates of v do not both vanish.

The beta equality is

 r^3(r+d+1)^3 = (r+d)^3(r+1)^3.

Taking cube roots in the algebraic closure gives

 r(r+d+1) = z (r+d)(r+1),

where z is a cube root of unity.

The z=1 case gives

 r(r+d+1)-(r+d)(r+1) = -d = 0,

impossible for 1 <= d <= D < p.

The nontrivial cube-root cases are controlled by the cyclotomic factor x^2+x+1 and give only bounded-degree exceptional solutions for each d. Thus the bad locus is O(D), not an obstruction to the mechanism.

This confirms that v(r,d) is a valid rational point except for a bounded exceptional family.

## The c_r=0 branch

The gap-1 Casoratian gives

 b_r c_{r+1}-b_{r+1}c_r != 0.

Therefore c_r and c_{r+1} cannot both vanish. A run cannot contain adjacent points from this branch.

Using the supplied solution zero-count bound, the total number of c_r=0 positions in the window is O(p^(2/3)). This is enough to show the branch is sparse globally, but it does NOT by itself give the desired O(D) bound for all 3-runs at mesoscopic D.

This is the first real gap.

## Step 2: three consecutive elements

Away from the c=0 and degeneracy branches, three consecutive points in Z_d force

 M_r v(r,d) proportional to v(r+1,d).

Equivalently the determinant

 F(r,d)=det(M_r v(r,d), v(r+1,d))

vanishes.

Because alpha and beta are rational functions of r and r+d with fixed degrees, clearing denominators gives a polynomial F in Z[r,d] of absolute bounded degree.

The important point is not the exact constant but non-identity.

A direct coefficient comparison should be done in the final computer certificate: if F is not identically zero, then for fixed d the number of 3-run starts is O(1).

I have not verified a complete coefficient expansion here, so I do not claim the non-identity certificate as proved.

If the expansion gives F=0 identically, that would be a major discovery: it would mean the companion dynamics has an unexpected commuting orbit closure supporting interval runs. No such identity is expected.

## Mixed branches

There are finitely many patterns:

- c_r=0, then explicit branch at r+1;
- c_{r+1}=0, then explicit branch at r and r+2;
- c_{r+2}=0;
- degeneracy of v at one of the three locations.

Each gives an algebraic condition after clearing denominators.

The missing proof obligation is a simultaneous degree/count bound for all these mixed curves. They are finite in number, so they are plausible, but they are not supplied by the current inventory.

## Conditional NO-RUN theorem

The arithmetic statement that would follow from the missing certificates is:

[NO-RUN] For every d <= D, every 3-run start in Z_d lies on a fixed finite union of bounded-degree algebraic curves in (r,d). Consequently the total number of 3-run starts over d <= D is O(D), and

 sum_d (longest_run_length(Z_d)-2)_+ = O(D).

Status: conditional, not yet PROVED-all-h.

## Effect on the padded-word obstruction

If [NO-RUN] is proved, it kills exactly the interval-pairing clause of the padded construction:

"Z_{d_j} restricted to the block is an entire interval of length d_j."

Such an interval forces many consecutive elements in a single Z_d, producing many 3-runs.

However, [NO-RUN] does NOT kill the scattered construction:

(r, r+d_r), with d_r varying in (D/2,D].

A scattered primitive stratum with no long fixed-gap runs survives this test.

Therefore run-rigidity attacks the padding adversary but does not solve the full anti-coexistence problem.

## Numerical pre-flight

The correct experiment is:

1. For primes p up to about 10^5 compute all Z_d with
   d <= sqrt(p) log p.

2. Record:
   - maximum run length inside each Z_d;
   - number of 2-runs;
   - number of 3-runs.

3. Compare the 2-run counts against the bounded-degree curve prediction from F.

Prediction:

- maximal run length should be 2;
- 3-runs should be rare and O(D);
- 2-runs should track the explicit eigenvector locus with a small constant.

## Final answers

(i) Least confident step:

The least confident step is the unverified non-identity and degree certificate for the cleared polynomial F(r,d), together with the complete mixed c=0 branch count. The companion-matrix reduction is sound; the global arithmetic count is the fragile point.

(ii) Possible blind spot in the question:

The question may overestimate the value of killing interval padding. The Strike2 construction already identifies the real missing object: a quenched growing-gap anti-coexistence theorem. Scattered variable-gap pairings are not constrained by fixed-d run rigidity, so [NO-RUN] alone cannot reach (4.8), (4.9), or [FR_eta].
