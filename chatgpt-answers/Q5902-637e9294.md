# Six-column candidate coprimality: exact local normal form, and why the stated hypotheses do not prove it

## Verdict

The statement

```text
gcd(delta_m,Q_I)=1
```

is **not a formal consequence** of the safe-interior hypotheses, the Newton/Lagrange congruence, and the certified Ore identity

```text
A_M U = Q L.
```

Prime by prime, the statement is equivalent to a rank-two condition on six first divided Newton jets. I derive that condition exactly below. It contains two kinds of data which the order-two Apéry recurrence and the Ore identity do not determine:

1. the first divided marked values `F(p-1)/p mod p`;
2. off-marked maximal-boundary finite-difference packets.

There is therefore no reduction, from the currently proved identities alone, to the nonzero Apéry Casoratian.

More sharply, the advertised implication is false in the universal operator-compatible category. The smallest safe target-compatible countermodel is

```text
n=20, p=17, D=floor(13n/20)=13, N=floor(n/5)=4,
m=m_max=4, d=10, L=6, Q_I=17.
```

It uses the actual marked Apéry values `b_3` and `J_3,J_4,...`, satisfies all marked-node congruences and the exact Ore identity, but has all six quotient columns on one line modulo `17`; indeed in the simplest realization all fifteen minors vanish identically. Thus

```text
gcd(delta_m,Q_I)=17.
```

This countermodel does **not** replace the Laurent-shell values away from the marked node by the actual coefficients of `Lambda`. Consequently it does not disprove the distinguished Apéry-shell specialization. What it proves is the load-bearing point:

> Any proof for the actual shell must use the off-marked Laurent coefficients. Safe interior, Apéry recurrence, Casoratian, Newton interpolation, and `A_M U=Q L` are insufficient.

At commit `55a92bab68049110c9a7724cd89d5b4a6000323c` the actual-shell assertion remains an empirically verified, unproved nondegeneracy lemma. No actual-shell counterexample is committed, and I do not manufacture one.

The missing hypothesis is stated exactly in Section 6. A small Sage insertion below prints, for every actual candidate prime, an explicit pair of quotient columns whose determinant is a unit, or stops at the first actual counterexample.

## 2. Exact first divided Newton-jet formula

### Lemma 2.1 — local cardinal row

For either endpoint row,

```text
c^epsilon_e = 1 if e=j, and 0 otherwise, mod p. (2.1)
```

#### Proof

The `L+1` interpolation nodes are distinct modulo `p` because `L<p`. Evaluation is at `-1`, and

```text
j=p-1=-1 mod p.
```

Therefore the Lagrange evaluation row is the cardinal row at `j`. Formula (1.1) is the integral form of that row. This proves (2.1), including

```text
c^epsilon_j = 1 mod p.                            (2.2)
```

No division by a factorial modulo `p` is being hidden here.

### Divided coefficient rows

Define, in `F_p`,

```text
alpha^epsilon_e
 = (c^epsilon_e-delta_{e,j})/p mod p.             (2.3)
```

The numerator in (2.3) is an integer divisible by `p` by Lemma 2.1.

For each of the six shell arrays put

```text
zeta_i = F_i(j)/p mod p,
f_i(e) = F_i(e) mod p.                            (2.4)
```

Here `f_i(j)=0`.

Define two explicit first-jet coordinates

```text
A_i = zeta_i + sum_e alpha^-_e f_i(e) mod p,
B_i = sum_e (alpha^+_e-alpha^-_e) f_i(e) mod p.   (2.5)
```

### Theorem 2.2 — exact local normal form

After the unimodular row operation `(x,y)->(x,y-x)`, one has

```text
nu_p R_i = (A_i,B_i) mod p.                       (2.6)
```

Equivalently, before that row operation,

```text
nu_p R_i = (A_i,A_i+B_i) mod p.                  (2.7)
```

Consequently

```text
det(R_i,R_j)
 = nu_p^(-2) (A_i B_j-A_j B_i) mod p.            (2.8)
```

#### Proof

By (2.3), modulo `p^2`,

```text
c^epsilon = e_j+p alpha^epsilon.
```

Also `F_i(j)=p zeta_i mod p^2`. Hence

```text
G_epsilon(F_i)
 = p(zeta_i+sum_e alpha^epsilon_e f_i(e)) mod p^2.
```

Divide by

```text
Q_I=p nu_p,
```

where `nu_p` is a `p`-unit. This gives (2.6)--(2.7). The row operation has determinant one, so (2.8) follows.

### Corollary 2.3 — exact criterion for candidate coprimality

For the distinguished actual columns or for any other integral specialization satisfying (1.5),

```text
p does not divide delta_m
iff
there exist -1 <= i < j <= 4 such that
A_i B_j-A_j B_i != 0 mod p.                      (2.9)
```

Thus

```text
gcd(delta_m,Q_I)=1
```

is equivalent to the six finite rank conditions

```text
rank_Fp [ A_-1 A_0 A_1 A_2 A_3 A_4
          B_-1 B_0 B_1 B_2 B_3 B_4 ] = 2         (2.10)
```

for every prime `p|Q_I`.

This is the requested prime-by-prime formulation. It is stronger than restating Smith theory because (2.5) identifies the exact local entries which must be controlled.

## 3. The second row is an explicit high-difference boundary packet

The local coordinate `B_i` has a closed Pascal formula.

For

```text
a_s=d+s,       0 <= s <= m-2,
P_s=binom(a_s+L+1,L),                            (3.1)
```

the adjacent Newton identity is

```text
G_{a_s,L}(F)-G_{a_s+1,L}(F)
 =(-1)^(L+1) P_s Delta^(L+1)F(a_s).              (3.2)
```

Every common candidate node belongs to the overlap of these two adjacent stencils. Hence, under `L<p`,

```text
v_p(P_s)=1.                                      (3.3)
```

Telescoping (3.2) from `d` to `D` and comparing with (2.5) gives

```text
B_i
 =(-1)^L sum_{s=0}^{m-2}
      (P_s/p) Delta^(L+1)F_i(a_s) mod p.         (3.4)
```

Every `P_s/p` in (3.4) is a unit modulo `p`. Formula (3.4) tracks the complete binomial normalization: the one candidate factor has been divided, and no additional target factor is discarded.

For the five common-annihilator ghosts, define

```text
V_t(a)=Delta^(L+1) Phi_t(a).
```

Since time operators commute with differences in the shell node,

```text
B_k
 =(-1)^L sum_s (P_s/p)
      ( L V(a_s) )_{n+k} mod p,       0<=k<=4.   (3.5)
```

For the origin-cancelled column,

```text
B_-1
 =(-1)^L sum_s (P_s/p) [
       (U V(a_s))_n
       -M(n) Delta^(L+1)C_{n-1}(a_s)
   ] mod p.                                      (3.6)
```

The first row `A_i` contains the complementary first divided marked digit

```text
zeta_i=F_i(p-1)/p mod p                           (3.7)
```

and the left-end divided interpolation row in (2.5).

Equations (2.5), (3.4)--(3.7) are the exact terminal packet. A proof of (2.10) must show that two of these packets have nonzero wedge.

## 4. What the Ore identity does, and what it does not do

Write

```text
A_M=sum_{r=0}^2 a_r(s) S^r,
Q=q_0(s)+q_1(s)S,
U=sum_{r=0}^4 u_r(s)S^r,
L=sum_{r=0}^5 lambda_r(s)S^r.
```

The certified identity is

```text
A_M U=Q L.                                        (4.1)
```

Coefficient by coefficient, using `S f(s)=f(s+1)S`, this says

```text
sum_{r=0}^2 a_r(s) u_{t-r}(s+r)
 =q_0(s)lambda_t(s)+q_1(s)lambda_{t-1}(s+1),     (4.2)
```

for `0<=t<=6`, with out-of-range coefficients zero.

Applying (4.1) to either endpoint jet gives linear relations among the sequences `A_i`; applying it to (3.4) gives the same linear relations among the sequences `B_i`, together with the explicit multiplier-shell defect recorded in the note. In the notation of the Q5895 extraction, one gets

```text
Gamma_k=q_{0,k}R_k+q_{1,k}R_{k+1}
       =sum_{r=0}^2 a_{r,k}Z_{k+r}+Bdry_k.        (4.3)
```

If the leading `q_1` values are units modulo `p`, (4.3) is an invertible triangular column change and therefore preserves the rank in (2.10). If a leading coefficient is singular, it must be handled directly through (2.5); the fixed polynomial singular factor does not prove rank two either.

The key logical point is:

```text
linear operator relations preserve the rank-one locus.             (4.4)
```

If all vectors `(A_i,B_i)` lie on one line, every linear combination supplied by (4.1) still lies on that line. Therefore (4.1) can propagate a rank-two witness once one is known, but cannot create the first witness.

### No reduction to the ordinary Apéry Casoratian

The ordinary recurrence controls the zeroth marked sequences `b_r` and `J_r`. The matrix (2.10) also contains

```text
F_i(p-1)/p mod p
```

and the off-marked packets (3.4). These are not determined by `b_r,b_{r+1}` or by

```text
a_{r+1}b_r-a_r b_{r+1}=6/(r+1)^3.                (4.5)
```

The countermodel in the next section fixes the actual marked `b` and `J` sequences and keeps (4.5) a unit, while every determinant in (2.8) is zero. Thus no identity of the form

```text
one quotient-column minor
 = fixed unit * Apéry Casoratian                   (4.6)
```

can follow from the currently certified recurrence/Ore package.

## 6. Exact missing hypothesis for the actual Apéry shell

For the distinguished shell, define `A_i(p,m),B_i(p,m)` by (2.5), or equivalently compute `B_i` by (3.4).

The missing statement is the following.

### Local first-jet nondegeneracy lemma

For every safe candidate prime `p|Q_I`,

```text
rank_Fp [ A_-1 A_0 A_1 A_2 A_3 A_4
          B_-1 B_0 B_1 B_2 B_3 B_4 ] = 2.        (6.1)
```

Equivalently, for every such `p`, at least one of the fifteen explicit numbers

```text
Omega_{i,j}(p,m)=A_iB_j-A_jB_i                 (6.2)
```

is nonzero modulo `p`.

Under (6.1), Theorem 2.2 proves

```text
p does not divide delta_m.
```

Applying this to every `p|Q_I` proves

```text
gcd(delta_m,Q_I)=1.                             (6.3)
```

No weaker hypothesis stated in Sections 68.12--68.17 currently implies (6.1). In particular:

- `p` being a target is neither sufficient nor necessary for (6.1);
- the Apéry Casoratian controls only the zeroth marked recurrence state;
- `A_M U=Q L` gives linear syzygies among the columns but leaves the rank-one locus invariant;
- maximality exposes the boundary packets in (3.4), but does not prove a unit wedge among them.

The actual hostile computations prove eight instances of (6.1). They do not provide a symbolic formula for a fixed pair `(i,j)` valid for all candidates.

## 8. Reproducible check of the local normal form

The following Sage routines independently multiply back (2.5)--(2.8) and (3.4) for any actual six shell arrays supplied as dictionaries.

```sage
from itertools import combinations


def newton_weight_local(a, L, h):
    return ZZ((-1)^h * binomial(a + h, h)
              * binomial(a + L + 1, L - h))


def newton_row_local(a, L, lower, upper):
    row = {node: ZZ(0) for node in range(lower, upper + 1)}
    for h in range(L + 1):
        row[a + h] = newton_weight_local(a, L, h)
    return row


def forward_difference_local(F, a, order):
    return ZZ(sum(
        (-1)^(order - h) * binomial(order, h) * ZZ(F[a + h])
        for h in range(order + 1)
    ))


def local_jet_column(F, d, D, L, QI, p):
    j = p - 1
    nu = ZZ(QI // p)
    assert gcd(nu, p) == 1

    lower = d
    upper = D + L
    cm = newton_row_local(d, L, lower, upper)
    cp = newton_row_local(D, L, lower, upper)

    for row in (cm, cp):
        for e in range(lower, upper + 1):
            expected = 1 if e == j else 0
            assert (row[e] - expected) % p == 0

    assert ZZ(F[j]) % p == 0
    zeta = ZZ(F[j] // p) % p

    alpha_m = {
        e: ((cm[e] - (1 if e == j else 0)) // p) % p
        for e in range(lower, upper + 1)
    }
    alpha_p = {
        e: ((cp[e] - (1 if e == j else 0)) // p) % p
        for e in range(lower, upper + 1)
    }

    A = (zeta + sum(alpha_m[e] * (ZZ(F[e]) % p)
                    for e in range(lower, upper + 1))) % p
    B = sum((alpha_p[e] - alpha_m[e]) * (ZZ(F[e]) % p)
            for e in range(lower, upper + 1)) % p

    raw_m = sum(cm[e] * ZZ(F[e]) for e in range(lower, upper + 1))
    raw_p = sum(cp[e] * ZZ(F[e]) for e in range(lower, upper + 1))
    assert raw_m % QI == 0
    assert raw_p % QI == 0

    Rm = ZZ(raw_m // QI)
    Rp = ZZ(raw_p // QI)
    assert (nu * Rm - A) % p == 0
    assert (nu * (Rp - Rm) - B) % p == 0

    B_pascal = ZZ((-1)^L * sum(
        (binomial(a + L + 1, L) // p)
        * forward_difference_local(F, a, L + 1)
        for a in range(d, D)
    )) % p
    assert B_pascal == B

    return (A, B), (Rm, Rp)


def local_rank_witness(F_columns, d, D, L, QI, p):
    data = [local_jet_column(F, d, D, L, QI, p)[0]
            for F in F_columns]
    for i, j in combinations(range(len(data)), 2):
        residue = (data[i][0] * data[j][1]
                   - data[j][0] * data[i][1]) % p
        if residue:
            return i, j, residue, tuple(data)
    return None, None, 0, tuple(data)
```

The return value `None,None,0,...` is an exact local counterexample. For an actual hostile row, the returned pair is the requested explicit determinant witness.

## 9. Sage verification of the smallest operator-compatible countermodel

This code uses the certified actual `b` and `J` sequences and the actual operators. It changes only the off-marked shell entries.

# q32_ghost_quotient_audit.sage.
def primitive_integral_coefficients_local(operator):
    coefficients = [K(operator[i]) for i in range(operator.order() + 1)]
    polynomial_denominator = lcm(value.denominator() for value in coefficients)
    polynomials = [R(polynomial_denominator * value) for value in coefficients]

        coefficient.denominator()
        for polynomial in polynomials
        for coefficient in polynomial.list()

        ZZ(coefficient)
        for polynomial in polynomials
        for coefficient in polynomial.list()
