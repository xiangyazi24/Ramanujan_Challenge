# HLOAD selector-order audit

## Conclusion

No fixed-degree positive majorant of the HLOAD type (degree 3 or 4 included) yields a new criterion weaker than the existing fixed-q energy/HM nodes. The obstruction is not the choice of basis; it is the cost of detecting a single row of size K=delta P. Any nonnegative polynomial majorant that is small enough after averaging must pay at least the same moment scale as a second-moment energy estimate.

Thus:

* `t(t-1)/(K(K-1))` is essentially the sharp quadratic selector and already requires the available second incidence moment.
* Bonferroni truncations do not improve the height cost because the top positive term has degree equal to the truncation depth.
* Krawtchouk/Chebyshev constructions can reduce constants but cannot reduce the required moment order for a one-sided nonnegative majorant.

## 1. Setup

Let P be the number of candidate labels in one row and K=delta P. Let H_delta be the high-load event

```
t >= K.
```

A selector is a polynomial Q(t) in the falling-factorial basis

```
Q(t)=sum_{j=0}^d c_j (t)_j
```

with

```
Q(t)>=1 for t in {K,...,P},
Q(t)>=0 for t in {0,...,P}.
```

The expected contribution after summing rows is controlled by the factorial moments

```
M_j=sum_rows E[(t)_j].
```

The known incidence estimates provide M_1 and M_2 at the required scale. They do not provide a new saving for M_3 or M_4.

## 2. Quadratic selector

The canonical candidate is

```
Q_2(t)=(t)_2/(K)_2.
```

For every integer t>=K,

```
Q_2(t)>=1.
```

The contribution is therefore

```
Sum Q_2(t)=M_2/(K(K-1)).
```

Since K=delta P and P~N/log N, this is exactly the fixed-q energy scale. It is not a new HLOAD-M1 criterion.

The linear selector t/K is weaker for small t but gives

```
M_1/K,
```

which is insufficient: a single row with t=K contributes order one, so the first moment would have to exclude concentration at the same strength as the desired theorem.

## 3. Fixed degree obstruction

Suppose Q has degree d and is nonnegative on [0,P]. To have Q(K)>=1 while suppressing the zero-frequency contribution, its leading factorial coefficient cannot be arbitrarily small.

A Markov-type discrete inequality gives

```
max_{0<=t<=P} |Delta^d Q(t)| >= c_d/P^d.
```

The jump from values below K to values at least one above K requires a total variation of order one over an interval of length O(K). Consequently the d-th factorial coefficient must have size at least comparable to

```
K^{-d}.
```

After summing over rows this creates the term

```
M_d/K^d.
```

Hence degree d requires the d-th moment at the corresponding normalization. A degree 3 or 4 polynomial does not avoid the moment problem; it only replaces a second moment by higher moments.

## 4. Bonferroni and Krawtchouk attempts

### Bonferroni

Bonferroni gives alternating sums of

```
(t)_j/(K)_j.
```

A valid one-sided majorant must truncate with positive remainder. The final positive term has size controlled by M_j/(K)_j. Therefore truncation order j again determines the required moment.

No fixed truncation gives HLOAD-M1 without importing a new high moment estimate.

### Krawtchouk/Chebyshev

Orthogonal polynomial filters can optimize L2 constants, but the constraint

```
Q(t)>=1 on [K,P]
Q(t)>=0 everywhere
```

is stronger than approximation in an unweighted norm. The extremal polynomial still has squared mass comparable to the Christoffel-function bound, which is a second-moment quantity. It can improve constants but not the exponent in P.

## 5. Exceptional sparsity does not rescue fixed degree

The number of exceptional rows is O(log N). If a selector has baseline contribution

```
|H_delta| * Lambda^d,
```

then sparsity changes the logarithmic factor only. It does not change the required power of Lambda.

A single bad row contributes

```
Q(K) >= 1.
```

Therefore the selector must distinguish one spike from all ordinary rows. A fixed degree polynomial can do this only by paying its factorial moment.

The zero-frequency estimate from Z(p)<<p^(2/3) controls the average/background terms. It does not control the isolated spike because the spike is not a residue-average phenomenon.

## 6. Relation to existing nodes

The fixed-q energy criterion

```
E_q(N)=o(N^2/log^2 N)
```

already supplies the quadratic control needed for the sharp selector. HLOAD-M1 is not weaker unless it proves a genuinely new first-moment estimate for the exceptional high-load rows.

The LGTQ-AGG-BDH node is also not bypassed: its aggregate control is exactly what prevents many medium rows from accumulating. The selector polynomial cannot replace that aggregation.

## Final theorem

**Polynomial selector obstruction.** Fix delta>0. Let Q be a nonnegative polynomial majorant of 1_{t>=delta P} on integers 0<=t<=P. If Q has degree d, then any proof based only on summing Q(t) over rows necessarily requires control of a factorial moment of order at least d (or an equivalent bound of the same strength). In particular, degrees 3 and 4 cannot derive HLOAD-M1 from the existing first/second incidence bounds and exceptional sparsity alone.

Therefore the HLOAD selector-order route collapses to existing moment nodes; it does not produce a new weaker sufficient criterion.
