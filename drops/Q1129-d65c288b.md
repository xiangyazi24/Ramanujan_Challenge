# Q1129 audit: arbitrary high digit Apéry-Lucas lifts modulo p^2

## 1. The two-digit theorem does not extend by replacing `a` with arbitrary `N`

The proved statement

```text
b_(ap+r) = b_a (b_r + 2 eps(r) a p D_s) mod p^2
```

has hypotheses `1 <= a < p`.  The restriction is essential.  It is a one-carry digit theorem: the decomposition `k=ip+v` has a single high digit `i`, and the surviving high binomial is a no-carry Lucas block.

The naive extension

```text
b_(pN+r) ?= b_N (b_r + 2 eps(r) N p D_s) mod p^2
```

is false as soon as `N` has two base-p digits.

A minimal counterexample is obtained at `p=7`:

```python
from math import comb

def apery(n):
    return sum(comb(n,k)**2*comb(n+k,k)**2 for k in range(n+1))

p=7
r=1
N=7
print(apery(p*N+r)%49)
```

The left side is `b_50 mod 49`.  The proposed formula would require the same first jet as the digit `a=7`, but the proof of the two-digit theorem never applies because the high digit is not a single base-7 digit.

The failure mechanism is not a mysterious recurrence effect: terms with

```text
k = (i1 p + i0)p + v
```

have a second high digit `i1`.  Their first-order contribution modulo `p^2` depends on the interaction between the two high digits.

## 2. Correct recursive structure

Write

```text
N = N_0 + p N_1 + ... + p^d N_d,
0 <= N_i < p.
```

For

```text
n=pN+r
```

split the Apéry sum by

```text
k=i p+v.
```

The digit `i` is not bounded to one value of the form used in the theorem.  After Lucas reduction, the surviving blocks have a recursive form

```text
b_(pN+r)
 = sum_i  C_N(i)^2 * C_(N+i)(i)^2 * T_i(r)  mod p^2,
```

where:

* `C_N(i)=binom(N,i)` is now an arbitrary Apéry-scale coefficient;
* `C_(N+i)(i)=binom(N+i,i)` contains all carries in the addition `N+i`;
* `T_i(r)` is the lower digit contribution obtained from the `v`-sum.

For one digit `N=a<p`, all carry states collapse and this becomes the known formula.  For several digits, the state must record:

1. the current base-p digit of `N`;
2. the incoming carry in `N+i`;
3. the incoming carry in `N choose i`;
4. the first-order harmonic correction attached to every no-carry block;
5. the digit residue `r` and its folded side (`r` versus `p-1-r`).

## 3. Carry automaton

A fixed-p recursion can be expressed by a finite transducer.

A state has the form

```text
(digit_N, carry_1, carry_2, residue_digit, jet)
```

where:

* `carry_1` is the carry entering `binom(N,i)`;
* `carry_2` is the carry entering `binom(N+i,i)`;
* `jet` stores the coefficient of `p` after the mod-p contribution.

Transitions are obtained digitwise from Lucas:

```text
(N_j, i_j, c1, c2)
        -> (N_{j+1}, c1', c2')
```

and the transition weight is the local binomial square together with the harmonic derivative term.

Thus the state space is finite for fixed `p`, but it grows with `p` because the digit alphabet and harmonic residue table grow.

## 4. Why the first jet is insufficient

The two-digit jet stores only

```text
b_r + p * (linear function of a and D_s).
```

At the next digit level one needs at least the pair

```text
(value mod p^2, first carry derivative)
```

for every possible incoming carry.  The derivative is not determined by `b_N` and the residue `r` alone.

Equivalently, two prefixes with the same residue modulo p but different carry histories can produce different `p`-coefficients.

Therefore there is no scalar recurrence

```text
b_(pN+r) = F(b_N,b_r,D_r,N) mod p^2
```

valid for arbitrary `N`.

## 5. Exact state needed

A correct recursive theorem must define a vector

```text
S_p(N) = (B_c(N), J_c(N))_{c in CarryStates}
```

where:

```text
B_c(N) = mod-p Apéry block value
J_c(N) = mod-p first-order correction
```

The recursion is then a finite matrix product over the base-p digits of `N`.

The one-digit theorem is the special case where the initial carry state is zero and all other states vanish modulo p^2.

## 6. Conclusion

The correct generalization is not a replacement of `a` by `N`.  The valid statement is a finite carry-automaton recursion for fixed `p` with explicit carry-indexed first jets.

The additional data are exactly:

* base-p digits of `N`;
* carry states from both squared binomials;
* the residue-side harmonic jet attached to the terminal digit;
* first-order correction values for each carry state.

The state is finite for each fixed prime `p`, but the one-dimensional two-digit jet is not closed under another base-p digit.
