# P3.1 alpha endpoint finite pre-Bloch certificate search

## Verdict

A finite certificate search is possible, but the correct object to search is not the four numerical Rogers values. The target is an identity in the rational pre-Bloch group presentation:

```
5([a]+[b]+[c]+[d])-3[1] = 0
```

using only:

1. Abel five-term relations
2. complement relations `[z]+[1-z]=[1]` (with the chosen Rogers normalization)

The output should be a finite integer vector of relation coefficients which can be replayed by Lean.

No PSLQ step is part of the certificate.

## Exact number field construction

Let

```
f(q)=q^12-3q^11+4q^10-5q^9+6q^8-7q^7+7q^6-7q^5
     +6q^4-5q^3+4q^2-3q+1
```

and work in

```
K = QQ[q]/(f).
```

Define

```
u=(q+q^12)/(q^5+q^8)
r=(-1-sqrt(1+4*u^2))/(2*u)
```

The square root must be represented by adjoining `s` with

```
s^2 = 1+4*u^2.
```

Then the four arguments are exact elements of

```
K(s):

a=1-1/r^2
b=(1-r^2)/r
c=(1-r^2)*q^4/r
d=(1-r^2-r*q^4)/(1-r^2)
```

The certificate search happens in this field, not in floating point.

## Relation generators

Use the formal generators `[z]` for the finite set generated by the orbit of:

```
a,b,c,d,1-a,1-b,1-c,1-d,
1/(1-z), z/(z-1)
```

under the five-term transformations.

The lifted five-term relation is:

```
[x]-[y]+[y/x]-[(1-x^-1)/(1-y^-1)]+[(1-x)/(1-y)] = 0
```

whenever all arguments are in the field.

Complement gives:

```
[z]+[1-z]-[1]=0.
```

The search target vector is:

```
5*(A+B+C+D)-3*ONE
```

where `ONE` is the formal `[1]` generator.

## Practical Sage implementation

```python
K.<q> = NumberField(
 q^12-3*q^11+4*q^10-5*q^9+6*q^8-7*q^7+7*q^6
 -7*q^5+6*q^4-5*q^3+4*q^2-3*q+1)

u=(q+q^12)/(q^5+q^8)
L.<s> = K.extension(s^2-(1+4*u^2))

r=(-1-s)/(2*u)

a=1-1/r^2
b=(1-r^2)/r
c=(1-r^2)*q^4/r
d=(1-r^2-r*q^4)/(1-r^2)

args=[a,b,c,d]

# canonical key for exact field elements
def key(z):
    return tuple(L(z).vector())

# relation matrix rows are integer combinations of generators
G={}
relations=[]

def addgen(z):
    k=key(z)
    if k not in G:
        G[k]=len(G)
    return G[k]

# complement generator
one=addgen(L(1))
for z in args:
    addgen(z)
    addgen(1-z)

# Add five term relations for discovered pairs
for x in args:
    for y in args:
        if x!=y and x*y!=0:
            terms=[x,y,y/x,(1-1/x)/(1-1/y),(1-x)/(1-y)]
            if all(t in L for t in terms):
                row={}
                for coef,t in zip([1,-1,1,-1,1],terms):
                    j=addgen(t)
                    row[j]=row.get(j,0)+coef
                relations.append(row)

# Add complement rows
for z in list(args):
    row={addgen(z):1, addgen(1-z):1, one:-1}
    relations.append(row)

# target
row={one:-3}
for z in args:
    row[addgen(z)]=row.get(addgen(z),0)+5

A=matrix(ZZ, len(relations), len(G),
         lambda i,j: relations[i].get(j,0))
t=vector(ZZ,[row.get(j,0) for j in range(len(G))])

print(A.rank())
print(A.solve_right(t) if t in A.column_space() else 'need more orbit')
```

This is the first finite certificate search. In practice the orbit must be enlarged until the target lies in the relation lattice.

## Height control

Do not enumerate arbitrary field elements. Bound the orbit:

- start with four shapes;
- close under the five-term transforms involving pairs of existing generators;
- reduce every element modulo the primitive polynomial of `q` and the quadratic relation of `s`;
- discard duplicates by exact coefficient vectors.

The expected number of generators is small because the four arguments have many reciprocal/complement relations.

## Replay format

The final certificate should be stored as JSON:

```json
{
  "field": "q12 quadratic extension",
  "generators": ["a", "b", "c", "d", "..."],
  "target": {
    "a":5,"b":5,"c":5,"d":5,"one":-3
  },
  "relations":[
    {
      "type":"five_term",
      "x":"generator_i",
      "y":"generator_j",
      "coefficients":[1,-1,1,-1,1]
    }
  ],
  "combination":[...]
}
```

Lean only needs to verify:

1. each exact field equality;
2. each five-term relation instance;
3. integer addition of the relation combination.

## Current status

The certificate architecture is realistic. A complete proof requires actually running the lattice search to obtain the finite relation vector. A numerical identity

```
R(a)+R(b)+R(c)+R(d)=pi^2/10
```

is not a substitute: it only verifies the regulator image after evaluation.

The critical computational task is therefore:

```
find N such that
N*(5([a]+[b]+[c]+[d])-3[1])
```

is in the span of explicit Abel relations.

If found, this is a direct elementary Lean route avoiding hyperbolic geometry and K-theory.
