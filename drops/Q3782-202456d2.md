# 1. Exact q6 geometry

Write a q6 row as
\[
m=6q+u=6p+r,
\qquad q=p+d,
\qquad 0\le u<q,
\qquad 0\le r<p.
\]
Subtracting gives
\[
\boxed{r=u+6d.}
\tag{1}
\]
A true sign row includes lower selectedness
\[
p\mid b_r
\]
and its corresponding true secondary zero.

# 2. Minus sign

For minus put
\[
a:=L^-=d-1-u.
\]
Using (1),
\[
\boxed{a+r=7d-1.}
\tag{2}
\]
A true minus row supplies the **actual** zero divisibilities
\[
\boxed{p\mid b_a,\qquad p\mid b_r.}
\tag{3}
\]
Reflect the selected lower endpoint \(r\) in characteristic \(p\):
\[
c:=p-1-r.
\]
Pointwise Apéry reflection gives
\[
p\mid b_c.
\]
Subtracting (2),
\[
\boxed{c-a=p-7d.}
\tag{4}
\]
Therefore, with
\[
g:=|p-7d|,
\]
the row gives two actual \(p\)-zeros at positions \(x,x+g\), where
\[
x=\min(a,c).
\]
The transfer/gap theorem then gives
\[
\boxed{p\mid N_g(x).}
\tag{5}
\]

This implication is one-way for the purpose of counting: a root of \(N_g\) is a projective orbit collision and need not consist of two zeros of \(b\).  That distinction is explicit in `FABLE_SECTION_orbit_energy.tex:130-215`.  We use only
\[
\text{true row}\Longrightarrow\text{formal root},
\]
which is safe for an upper bound.

## Fixed \((p,d)\): row-to-root injectivity

There are two orientations.

If \(p>7d\), then \(c>a\), so
\[
x=a=d-1-u,
\qquad
u=d-1-x.
\]
If \(p<7d\), then \(a>c\), so
\[
x=c=p-1-u-6d,
\qquad
u=p-6d-1-x.
\]
Thus for fixed \((p,d)\), each oriented root \(x\) determines \(u\) uniquely.  No extra row-orientation multiplicity is lost.

For fixed \((p,g)\), however, (4) allows at most two values of \(d\):
\[
7d=p-g\quad\text{or}\quad7d=p+g.
\tag{6}
\]
This is the exact replacement for the false minus “\(d\)-to-gap injectivity” sentence.

\boxed{j+a=6d-1.}
\tag{8}

\[
\boxed{a^*-j=p-6d.}

Thus every true plus row gives

\boxed{p\mid N_g(x)}
\tag{10}

# 4. Boundary and diagonal audit

There is no problematic actual diagonal.

\[

### Plus: \(g=0\)

Lower legality already gives \(p-6d>u\ge0\), so \(g>0\).  Also \(p=6d\) would not be an asymptotically relevant prime pair.

### Gap \(g=1\)

A true row would produce two consecutive zeros modulo \(p\), impossible by `proof.tex:198-217`.  Thus actual rows have

### Reflection endpoints

I_p=\{1,\ldots,p-2\}.

Actual rows automatically lie there.  If one reflected endpoint were \(0\), the corresponding actual zero would require \(p\mid b_0=1\).  If it were \(p-1\), reflection would again give \(b_{p-1}\equiv b_0\equiv1\pmod p\).  Hence every actual reflected pair satisfies
\[

\tag{12}

In particular \(g\le p-3\), so the nonvanishing theorem for \(N_g\) is always in range.
