## Palindromic reflections

The involutions are

```
r17 -> 16-r17,
r19 -> 18-r19,
r31 -> 30-r31.
```

Thus the reflection orbits of every triple are obtained by independently replacing

```
3 <-> 13,
8 <-> 10,
8 <-> 22.
```

Because these are exactly the two-point zero sets, the eight reflections of any triple are precisely the eight triples listed above. Therefore the full 8×8 table of lifts is the same set of 8 CRT residues repeated for each starting triple.

| triple orbit representative | lift |
