# Q2636 — exact same-height Padé evaluation ideal

## Verdict

There is an exact answer, but it is **not** simply
\(\gcd(B_H(n),\Phi_H(n))\).

Write
\[
c_k=\Delta^k b_0,\qquad
B_H(X)=\sum_{k=0}^H c_k\binom Xk,
\qquad
\Phi_H(X)=\prod_{s=0}^H(X-s).
\]
For the split \(a=H-b\), the primitive pair is obtained from a rank-\(b\)
Newton multiplication block \(R_b\). If \(\delta_b\) is the gcd of its
maximal minors, then the primitive numerator evaluation is the **saturated
bordered subresultant**
\[
\boxed{
 P_{H-b}(n)=(-1)^b\,
 \frac{\det \widehat R_b(n)}{\delta_b}.
}
\]
Consequently the exact integer ideal is
\[
\boxed{
\mathfrak I_{H,n}
 :=(P_0(n),\ldots,P_H(n))
 =G_H(n)\mathbf Z,
\qquad
G_H(n)=
\gcd_{0\le b\le H}
\left|
\frac{\det\widehat R_b(n)}{\delta_b}
\right|.
}
\tag{1}
\]
Prime by prime,
\[
\boxed{
 v_p(G_H(n))
 =\min_{0\le b\le H}
 \left(
 v_p(\det\widehat R_b(n))-v_p(\delta_b)
 \right).
}
\tag{2}
\]
This is the requested exact Smith/subresultant formula.

There is a second, more conceptual Smith formula. Put
\(E_b=B_HQ_b-P_{H-b}\). Since \(E_b\) is integer-valued and vanishes at
\(0,\ldots,H\),
\[
 E_b(X)=\sum_{r=1}^{b} e_{b,r}\binom X{H+r},\qquad e_{b,r}\in\mathbf Z.
\]
Let \(T_H=(e_{b,r})_{1\le b,r\le H}\), with \(e_{b,r}=0\) for \(r>b\), and
\[
z_H(n)=
\begin{pmatrix}
\binom n{H+1}\\ \vdots\\ \binom n{2H}
\end{pmatrix}.
\]
Then
\[
\boxed{
\mathfrak I_{H,n}
 =\bigl(B_H(n),\;\text{entries of }T_Hz_H(n)\bigr).
}
\tag{3}
\]
If
\[
 U T_H V=\operatorname{diag}(\tau_1,\ldots,\tau_H),
 \qquad \tau_1\mid\cdots\mid\tau_H,
\]
is a Smith form and \(y=V^{-1}z_H(n)\), then
\[
\boxed{
\mathfrak I_{H,n}
 =\bigl(B_H(n),\tau_1y_1,\ldots,\tau_Hy_H\bigr).
}
\tag{4}
\]
Formula (3)/(4) is the cleanest explanation of why \(\Phi_H(n)\) can
contain a spurious factor: the primitive vanishing lattice is the binomial
tail \(\binom X{H+1},\binom X{H+2},\ldots\), not the single ordinary
polynomial \(\Phi_H=(H+1)!\binom X{H+1}\).

For the reported exception \((H,n)=(30,91)\), the extra \(29\) is exactly
such a fixed-divisor artifact. In fact it is killed already by the first
nontrivial split \(b=1\); no deep full-family cancellation is needed.
The \(37\) is different: it is a genuine congruent-node Apéry zero and
therefore survives the whole family.

One important qualification: the Smith identities give a sharp
**upper multiple** of \(G_H(n)\), but they do **not** give an unconditional
\(e^{o(H)}\) upper multiple in the project's strict sense. The natural
certificate is \(e^{O(H)}\), and at \(n=3H+1\) its binomial tail contains a
universal top-interval primorial. Thus a claim of a strict subexponential
upper divisor from Smith algebra alone would be an overclaim. I isolate the
exact obstruction below.

## 1. The Newton multiplication matrix

The current scripts use exactly the matrix
\[
 m_{k\ell}
 =\binom{k}{\ell}\Delta^{k-\ell}b_\ell
 =\binom{k}{\ell}
   \sum_{t=0}^{\ell}\binom{\ell}{t}c_{k-\ell+t},
 \qquad 0\le \ell\le k\le H.
\tag{5}
\]
This is `entry(k, ell, differences)` in
`q32_pade_total_positivity.py`.

Equivalently, if
\[
 T_\ell(X):=\operatorname{rem}_{\Phi_H}
 \left(B_H(X)\binom X\ell\right),
\]
then
\[
 T_\ell(X)=\sum_{k=0}^H m_{k\ell}\binom Xk.
\]
Thus the lower-triangular matrix
\[
 M_H=(m_{k\ell})_{0\le k,\ell\le H}
\]
is multiplication by \(B_H\) in the interpolation quotient, written in
the Newton/binomial basis.

For denominator degree \(b\) and numerator degree \(a=H-b\), write
\[
 R_b=
 \left(m_{k\ell}\right)_
 {\substack{a+1\le k\le H\\0\le\ell\le b}}
 \in M_{b,b+1}(\mathbf Z).
\tag{6}
\]
The Padé condition is precisely
\[
 R_bq=0.
\tag{7}
\]
The current `primitive_pade_kernel` / `primitive_pair_fast` code is doing
this exact nullspace computation.

Under the full-degree hypothesis, \(\operatorname{rank}_{\mathbf Q}R_b=b\).
Let
\[
 C_{b,j}=(-1)^j\det R_b^{\widehat j},
 \qquad 0\le j\le b,
\tag{8}
\]
where \(R_b^{\widehat j}\) is obtained by deleting column \(j\). Define
\[
 \delta_b:=\gcd_{0\le j\le b}|C_{b,j}|,
 \qquad \delta_0:=1.
\tag{9}
\]
Then
\[
 q_b=(q_{b,0},\ldots,q_{b,b})
 =\frac1{\delta_b}(C_{b,0},\ldots,C_{b,b})
\tag{10}
\]
is, up to sign, the primitive integral denominator vector.

This is exactly the normalization that matters. Using the raw cofactor row
instead of (10) computes an unsaturated subresultant lattice.

## 2. Smith interpretation of the primitive normalization

Take a Smith form
\[
 U_bR_bV_b=
 \begin{bmatrix}
 d_{b,1}&&&0\\
 &\ddots&&\vdots\\
 &&d_{b,b}&0
 \end{bmatrix},
\qquad
 d_{b,1}\mid\cdots\mid d_{b,b},
\tag{11}
\]
with \(U_b\in GL_b(\mathbf Z)\) and
\(V_b\in GL_{b+1}(\mathbf Z)\). Then
\[
\boxed{
 \delta_b
 =\Delta_b(R_b)
 =\prod_{i=1}^b d_{b,i},
}
\tag{12}
\]
the \(b\)-th determinantal divisor of \(R_b\), and
\[
\boxed{
 q_b=\pm V_be_{b+1}.
}
\tag{13}
\]
So division by \(\delta_b\) in (10) is not an ad hoc content removal: it is
exactly saturation of the rank-one integral kernel.

This is the right Smith invariant. A power-basis Sylvester matrix carries
extra factorial basis-change factors; those are precisely dangerous at
primes \(p\le H\). The Newton matrix (5) is the integral object used by the
repo scripts and should be kept as the canonical subresultant matrix.

## 3. Bordered subresultant evaluation formula

Define the evaluation row
\[
 w_b(n)=(w_{b,0}(n),\ldots,w_{b,b}(n)),
\qquad
 w_{b,j}(n)=\sum_{k=0}^{H}m_{kj}\binom nk.
\tag{14}
\]
Because \(R_bq_b=0\), the rows \(k>a\) vanish after pairing with \(q_b\),
so
\[
 w_b(n)q_b=P_{H-b}(n).
\tag{15}
\]
Now border \(R_b\) by this row:
\[
 \widehat R_b(n)=
 \begin{bmatrix}
 R_b\\ w_b(n)
 \end{bmatrix}
 \in M_{b+1}(\mathbf Z).
\tag{16}
\]
Laplace expansion along the last row gives
\[
 \det\widehat R_b(n)
 =(-1)^b\sum_{j=0}^b w_{b,j}(n)C_{b,j}
 =(-1)^b\delta_bP_{H-b}(n).
\tag{17}
\]
Hence (1).

Using the Smith form directly gives an even shorter coordinate formula:
\[
\boxed{
 P_{H-b}(n)=\pm\bigl(w_b(n)V_b\bigr)_{b+1}.
}
\tag{18}
\]
That is: **take the evaluation row, move it to Smith coordinates, and keep
the free-kernel coordinate**.

This is an exact characterization, not a height estimate.

## 4. Exact comparison with \(\gcd(B_H(n),\Phi_H(n))\)

Let
\[
 D_H(n)=\gcd(B_H(n),\Phi_H(n)),
\]
and put
\[
 s_b(n)=\det\widehat R_b(n).
\]
With the convention \(v_p(0)=+\infty\), define
\[
 g_p(H,n)=
 \min_{0\le b\le H}
 \left(v_p(s_b(n))-v_p(\delta_b)\right),
\tag{19}
\]
\[
 d_p(H,n)=
 \min\left(v_p(B_H(n)),v_p(\Phi_H(n))\right).
\tag{20}
\]
Then
\[
 v_p(G_H(n))=g_p(H,n),\qquad
 v_p(D_H(n))=d_p(H,n).
\tag{21}
\]
Therefore the exact two-sided correction is
\[
 C_{\rm drop}(H,n)
 =\prod_p p^{(d_p-g_p)_+},
\qquad
 C_{\rm add}(H,n)
 =\prod_p p^{(g_p-d_p)_+},
\tag{22}
\]
with
\[
\boxed{
 G_H(n)=D_H(n)\,
 \frac{C_{\rm add}(H,n)}{C_{\rm drop}(H,n)}.
}
\tag{23}
\]
This formulation is safer than assuming a priori that the family gcd
always divides the raw \(D_H(n)\). In the observed \(H=30,n=91\) case,
\[
 C_{\rm add}=1,\qquad C_{\rm drop}=29.
\]

The point is that the true correction is prime-by-prime Smith saturation,
not a universal scalar quotient of \(\Phi_H\).

## 5. Equivalent tail-Smith formula

There is a second exact formulation that makes the factorial correction
transparent.

For \(b\ge1\), let
\[
 E_b(X)=B_H(X)Q_b(X)-P_{H-b}(X).
\tag{24}
\]
It vanishes at \(0,1,\ldots,H\). Since \(B_H,Q_b,P_{H-b}\) are
integer-valued, \(E_b\in\operatorname{Int}(\mathbf Z)\). The binomial
polynomials are the integral basis of `Int(Z)`, so
\[
\boxed{
 E_b(X)=\sum_{r=1}^{b}e_{b,r}\binom X{H+r},
 \qquad e_{b,r}\in\mathbf Z.
}
\tag{25}
\]
No factorial denominators occur in (25).

The coefficients can be written explicitly. Extend \(c_j=0\) for \(j>H\)
and set
\[
 \widetilde m_{k\ell}
 =\binom{k}{\ell}
   \sum_{t=0}^{\ell}\binom{\ell}{t}c_{k-\ell+t}.
\tag{26}
\]
Then for \(1\le r\le b\),
\[
\boxed{
 e_{b,r}=\sum_{\ell=0}^{b}q_{b,\ell}
 \widetilde m_{H+r,\ell}.
}
\tag{27}
\]
In particular the tail matrix is triangular and
\[
\boxed{
 e_{b,b}=\binom{H+b}{b}\,c_H\,q_{b,b}.
}
\tag{28}
\]

At the integer \(n\), put
\[
 \varepsilon_b(n)=E_b(n)
 =\sum_{r=1}^b e_{b,r}\binom n{H+r}.
\]
Since \(P_H=B_H\) and
\(P_{H-b}=B_HQ_b-E_b\), elementary ideal operations give
\[
\boxed{
 (P_0(n),\ldots,P_H(n))
 =(B_H(n),\varepsilon_1(n),\ldots,\varepsilon_H(n)).
}
\tag{29}
\]
This is (3).

If \(UT_HV=S=\operatorname{diag}(\tau_i)\), then
\[
 U(T_Hz)=SV^{-1}z,
\]
and unimodular row operations do not change the generated integer ideal,
which proves (4).

This tail-Smith description is useful because the raw comparator uses only
\[
 \Phi_H(n)=(H+1)!\binom n{H+1},
\tag{30}
\]
whereas the true family sees the **primitive** tail coordinates in (25).

## 6. Why the \(29\) at \((H,n)=(30,91)\) disappears

This case can be explained completely by the first nontrivial pair.

Let \(c_k=\Delta^kb_0\). For \(b=1\),
\[
 R_1=
 \begin{bmatrix}
 c_H & H(c_{H-1}+c_H)
 \end{bmatrix},
\tag{31}
\]
so
\[
 \delta_1=\gcd\bigl(c_H,H(c_{H-1}+c_H)\bigr),
\tag{32}
\]
and a primitive kernel vector is
\[
 Q_1:
 \quad
 (q_{1,0},q_{1,1})
 =\frac1{\delta_1}
 \bigl(H(c_{H-1}+c_H),-c_H\bigr).
\tag{33}
\]
The degree-\(H+1\) error is therefore
\[
\boxed{
 B_HQ_1-P_{H-1}
 =\kappa_0\binom X{H+1},
\qquad
 \kappa_0=(H+1)c_Hq_{1,1}
 =-\frac{(H+1)c_H^2}{\delta_1}.
}
\tag{34}
\]
This is exactly the `q32_adjacent_pade_kappa.py` identity for the first
adjacent pair.

Now take \(H=30\), \(p=29\). Apéry Lucas gives
\[
 b_{29}\equiv b_1=5\pmod{29},
 \qquad
 b_{30}\equiv b_1^2=25\pmod{29}.
\]
Because all interior binomial coefficients of row \(29\) vanish mod \(29\),
\[
 c_{29}\equiv -b_0+b_{29}\equiv4\pmod{29}.
\tag{35}
\]
For row \(30=p+1\), only columns \(0,1,p,p+1\) survive mod \(p\), hence
\[
 c_{30}\equiv b_0-b_1-b_{29}+b_{30}
 \equiv1-5-5+25
 \equiv16\pmod{29}.
\tag{36}
\]
Therefore
\[
 30(c_{29}+c_{30})\equiv20\pmod{29},
\]
so \(29\nmid\delta_1\), \(29\nmid q_{1,1}\), and
\[
\boxed{29\nmid\kappa_0.}
\tag{37}
\]

On the other hand,
\[
 \Phi_{30}(91)=31!\binom{91}{31}.
\]
The \(29\)-valuations are
\[
 v_{29}(\Phi_{30}(91))=1,
 \qquad
 v_{29}(31!)=1,
 \qquad
 \boxed{v_{29}\binom{91}{31}=0.}
\tag{38}
\]
Thus the \(29\) in the raw \(\Phi\)-gcd is **entirely in the fixed divisor
\(31!\)**.

Since the observed raw gcd says \(29\mid B_{30}(91)\), (34) at \(n=91\)
gives
\[
 P_{29}(91)
 \equiv-\kappa_0\binom{91}{31}
 \not\equiv0\pmod{29}.
\tag{39}
\]
So \(29\) is killed already by \(b=1\).

This also explains why looking only at \(\Phi_H\) is misleading here.
Indeed
\[
 91\equiv4\pmod{29},
 \qquad
 b_4=33001\equiv-1\pmod{29},
\]
so \(29\) is not an Apéry zero at the congruent node. Because \(H=30\ge29\),
the binomial basis change contains a factor \(29\); an integer-valued
polynomial of degree \(30\) need not define a function of \(X\bmod29\).
The raw condition \(29\mid B_{30}(91)\) is therefore a characteristic-crossing
alias, not a node zero.

This is the precise correction mechanism.

A correction to my interim note while working on this question: the general
formula does require the determinantal divisors \(\delta_b\), but **the
specific factor \(29\) is not removed by a \(29\)-factor in \(\delta_1\)**;
\(\delta_1\) is a \(29\)-unit. Here the removal is the fixed-divisor passage
from \(\Phi_{30}\) to the primitive binomial vanishing generator in (34).

## 7. Why \(37\) survives

For \(p=37\), we have \(p>H=30\), so every \(k!\), \(k\le H\), is a
\(37\)-unit. Hence every degree-\(\le H\) integral-binomial polynomial
respects congruence of its input modulo \(37\).

Now
\[
 91\equiv17\pmod{37}.
\]
The reported raw gcd has \(37\mid B_{30}(91)\), hence
\[
 B_{30}(91)\equiv B_{30}(17)=b_{17}\equiv0\pmod{37}.
\tag{40}
\]
For every split,
\[
 P_a(91)
 \equiv P_a(17)
 =b_{17}Q_a(17)
 \equiv0\pmod{37}.
\tag{41}
\]
Therefore
\[
\boxed{37\mid G_{30}(91).}
\]
The exact computation gives no additional common factor, so
\[
\boxed{G_{30}(91)=37,\qquad
D_{30}(91)=29\cdot37.}
\tag{42}
\]
Thus the two primes have categorically different origins:

- \(29\): fixed-divisor / characteristic-crossing artifact, removed by the
  first primitive tail certificate;
- \(37\): genuine congruent-node Apéry zero, retained by every Padé
  numerator.

## 8. A useful exact upper multiple

Index the pairs by denominator degree:
\[
(P^{[b]},Q^{[b]})=(P_{H-b},Q_{H-b}).
\]
For adjacent pairs the current script verifies
\[
 P^{[b]}Q^{[b+1]}-P^{[b+1]}Q^{[b]}
 =\kappa_b\binom X{H+1},
\qquad 0\le b<H.
\tag{43}
\]
Let
\[
 K_H=\gcd_{0\le b<H}|\kappa_b|.
\tag{44}
\]
Every left side of (43), evaluated at \(n\), lies in
\(\mathfrak I_{H,n}\). Therefore
\[
\boxed{
 G_H(n)\mid
 U^{\rm adj}_{H,n}:=
 \gcd\left(
 B_H(n),
 K_H\binom n{H+1}
 \right).
}
\tag{45}
\]
This is often much sharper than
\(\gcd(B_H(n),\Phi_H(n))\), because the universal fixed divisor
\((H+1)!\) has disappeared.

The full tail Smith form gives another exact upper multiple. Assume
\(T_H\) has full rank and let \(\tau_H\) be its largest Smith invariant.
Then \(\tau_HT_H^{-1}\) is integral, so every
\(\tau_H\binom n{H+r}\) is an integer combination of the entries of
\(T_Hz_H(n)\). Hence
\[
\boxed{
 G_H(n)\mid
 U^{\rm Smith}_{H,n}:=
 \gcd\left(
 B_H(n),
 \tau_H\,
 \gcd_{1\le r\le H}\binom n{H+r}
 \right),
}
\tag{46}
\]
where the notation in (46) means
\[
U^{\rm Smith}_{H,n}
=\gcd\left(
 |B_H(n)|,
 \tau_H\cdot
 \gcd_{1\le r\le H}\binom n{H+r}
 \right).
\]
Formula (46) is the cleanest single Smith upper divisor.

## 9. About the requested “provably subexponential” upper divisor

There is a scale distinction that should not be blurred.

For fixed \(n=O(H)\), the elementary first-adjacent certificate satisfies
\[
 \log|\kappa_0|=O(H),
 \qquad
 \log\binom n{H+1}=O(H).
\tag{47}
\]
The first bound follows from the exponential growth of the Apéry numbers,
\(|c_H|\le2^H\max_{s\le H}b_s=e^{O(H)}\), and (34). Thus (45) is a
**subfactorial** certificate of size \(e^{O(H)}\), a major reduction from
the \(H\log H\) height of the raw product \(\Phi_H(n)\).

But the project has been using “subexponential” in the strict sense
\[
 \log U=o(H).
\]
In that sense, neither (45) nor (46) is presently provably subexponential.
There is a concrete reason, not just lack of optimization.

At the q=1 test scale \(n=3H+1\), for every prime
\[
 2H+1<p\le3H+1
\]
and every \(H+1\le k\le2H\), the numerator interval defining
\(\binom nk\) contains \(p\) while \(k!\) does not. Hence
\[
 p\mid\binom nk
 \quad\text{for all }H+1\le k\le2H.
\]
Therefore
\[
 \prod_{2H+1<p\le3H+1}p
 \mid
 \gcd_{1\le r\le H}\binom{3H+1}{H+r}.
\tag{48}
\]
The logarithm of this primorial is \(\Theta(H)\). So the purely binomial
part of (46) is genuinely exponential, not \(e^{o(H)}\).

Taking the gcd with \(B_H(n)\) is exactly what removes the good primes from
that universal primorial; proving that the remainder has logarithmic
height \(o(H)\) is arithmetic information not supplied by Smith normal
form. In particular, any unconditional \(e^{o(H)}\) upper multiple of the
full family gcd would already control every prime that divides every
\(P_a(n)\), so it cannot be obtained merely by re-normalizing the
subresultants.

So the precise status is:

1. **Exact ideal:** solved by (1)/(2), equivalently (3)/(4).
2. **Correction factor:** exactly the Smith saturation (19)–(23), with the
   \(29\) example explained explicitly by (34)–(39).
3. **Sharper unconditional upper multiple:** (45), and the full Smith
   version (46).
4. **Strict \(e^{o(H)}\) upper multiple:** not proved by this structure;
   claiming it from the Smith/subresultant identities alone would be
   false. The remaining rough factor is not a normalization artifact.

That last negative point is important: the exact Smith calculation does
remove the fake \(29\)-type factors, but it does not magically compress the
genuine common-root primes.

## 10. Exact verifier

The following verifier uses the same Newton matrix as the current scripts.
It checks:

- primitive cofactor kernel and its determinantal divisor \(\delta_b\);
- bordered determinant formula (17) for every split;
- exact family gcd;
- tail identity (25)–(29);
- adjacent \(\kappa_b\) identity and the upper divisor (45);
- optionally, Smith forms of every \(R_b\) and of \(T_H\);
- the exact \(H=30,n=91\) assertions \(D=29\cdot37\), \(G=37\), and
  immediate killing of \(29\) at \(b=1\).

Run it from `problems/3.2/research/scripts` so the existing imports resolve.

```python
#!/usr/bin/env python3
from __future__ import annotations

import argparse
from functools import reduce
from math import comb, gcd, prod

from sympy import Matrix, ZZ, factorint
from sympy.matrices.normalforms import smith_normal_form

from q32_pade_total_positivity import (
    apery_values,
    bareiss_determinant,
    entry,
    newton_coefficients,
)
from q32_adjacent_pade_kappa import evaluate_newton


def determinant(matrix: list[list[int]]) -> int:
    return bareiss_determinant(matrix)


def cofactor_pair(H: int, b: int, c: list[int]):
    """Return (a,R,delta,q,p) in the exact convention of the note."""
    a = H - b
    R = [
        [entry(k, ell, c) for ell in range(b + 1)]
        for k in range(a + 1, H + 1)
    ]

    cof = []
    for j in range(b + 1):
        minor = [row[:j] + row[j + 1 :] for row in R]
        cof.append((-1) ** j * determinant(minor))

    delta = reduce(gcd, (abs(x) for x in cof), 0)
    assert delta > 0
    q = [x // delta for x in cof]
    assert reduce(gcd, (abs(x) for x in q), 0) == 1

    # Bottom Padé rows vanish.
    for k in range(a + 1, H + 1):
        assert sum(q[ell] * entry(k, ell, c) for ell in range(b + 1)) == 0

    p = [
        sum(
            q[ell] * entry(k, ell, c)
            for ell in range(min(b, k) + 1)
        )
        for k in range(a + 1)
    ]
    return a, R, delta, q, p


def truncated_product_entry(
    k: int,
    ell: int,
    c: list[int],
    H: int,
) -> int:
    """Newton coefficient of B_H(X)*binom(X,ell), also for k>H."""
    if ell > k:
        return 0
    total = 0
    for t in range(ell + 1):
        j = k - ell + t
        if 0 <= j <= H:
            total += comb(ell, t) * c[j]
    return comb(k, ell) * total


def v_p(value: int, p: int) -> int:
    if value == 0:
        return 10**9
    value = abs(value)
    result = 0
    while value % p == 0:
        result += 1
        value //= p
    return result


def audit(H: int, n: int, do_smith: bool) -> None:
    values = apery_values(H + 1)
    c = newton_coefficients(values)
    Bn = evaluate_newton(c, n)
    phi = prod(n - s for s in range(H + 1))
    raw = gcd(abs(Bn), abs(phi))

    pairs = []
    pade_values = []
    bordered_values = []
    tail_rows = []

    for b in range(H + 1):
        a, R, delta, q, pcoeff = cofactor_pair(H, b, c)
        Pn = evaluate_newton(pcoeff, n)
        Qn = evaluate_newton(q, n)
        pade_values.append(Pn)
        pairs.append((pcoeff, q))

        w = [
            sum(comb(n, k) * entry(k, ell, c) for k in range(H + 1))
            for ell in range(b + 1)
        ]
        bordered = R + [w]
        det_border = determinant(bordered)
        assert det_border % delta == 0
        assert abs(det_border // delta) == abs(Pn)
        bordered_values.append(det_border // delta)

        # Interpolation check on the original nodes.
        for s in range(H + 1):
            assert evaluate_newton(pcoeff, s) == (
                values[s] * evaluate_newton(q, s)
            )

        if do_smith and b:
            S = smith_normal_form(Matrix(R), domain=ZZ)
            smith_delta = prod(abs(int(S[i, i])) for i in range(b))
            assert smith_delta == delta

        if b:
            row = [0] * H
            for r in range(1, b + 1):
                k = H + r
                row[r - 1] = sum(
                    q[ell] * truncated_product_entry(k, ell, c, H)
                    for ell in range(b + 1)
                )
            tail_rows.append(row)

            E_at_n = sum(
                row[r - 1] * comb(n, H + r)
                for r in range(1, b + 1)
            )
            assert Bn * Qn - Pn == E_at_n

    G = reduce(gcd, (abs(x) for x in pade_values), 0)
    assert G == reduce(gcd, (abs(x) for x in bordered_values), 0)

    # Exact ideal equality (B, Tz).
    tail_values = [
        sum(row[r - 1] * comb(n, H + r) for r in range(1, H + 1))
        for row in tail_rows
    ]
    G_tail = reduce(gcd, [abs(Bn), *(abs(x) for x in tail_values)], 0)
    assert G_tail == G

    # Adjacent cross identities.
    kappas = []
    C = comb(n, H + 1)
    for b in range(H):
        P, Q = pairs[b]
        P1, Q1 = pairs[b + 1]
        kappa = (
            evaluate_newton(P, H + 1) * evaluate_newton(Q1, H + 1)
            - evaluate_newton(P1, H + 1) * evaluate_newton(Q, H + 1)
        )
        assert kappa != 0
        cross_n = (
            evaluate_newton(P, n) * evaluate_newton(Q1, n)
            - evaluate_newton(P1, n) * evaluate_newton(Q, n)
        )
        assert cross_n == kappa * C
        kappas.append(kappa)

    K = reduce(gcd, (abs(x) for x in kappas), 0)
    upper_adj = gcd(abs(Bn), abs(K * C))
    assert upper_adj % G == 0

    print(f"H={H} n={n}")
    print(f"B_factor={factorint(abs(Bn)) if abs(Bn).bit_length() < 200 else 'large'}")
    print(f"raw_gcd={raw} factors={factorint(raw)}")
    print(f"family_gcd={G} factors={factorint(G)}")
    print(f"K_adj_factors={factorint(K)}")
    print(f"upper_adj={upper_adj} factors={factorint(upper_adj)}")

    if do_smith:
        T = Matrix(tail_rows)
        S = smith_normal_form(T, domain=ZZ)
        tau = [abs(int(S[i, i])) for i in range(H)]
        assert all(tau[i + 1] % tau[i] == 0 for i in range(H - 1))
        tail_gcd = reduce(
            gcd,
            (comb(n, H + r) for r in range(1, H + 1)),
            0,
        )
        upper_smith = gcd(abs(Bn), tau[-1] * tail_gcd)
        assert upper_smith % G == 0
        print(f"tau_max_bits={tau[-1].bit_length()}")
        print(f"tail_gcd_factors={factorint(tail_gcd)}")
        print(f"upper_smith_factors={factorint(upper_smith)}")

    if (H, n) == (30, 91):
        assert raw == 29 * 37
        assert G == 37

        # 29 is killed already by denominator degree b=1.
        assert Bn % 29 == 0
        assert pade_values[1] % 29 != 0
        assert c[29] % 29 == 4
        assert c[30] % 29 == 16
        _, R1, delta1, q1, _ = cofactor_pair(30, 1, c)
        assert R1[0][0] % 29 == 16
        assert R1[0][1] % 29 == 20
        assert delta1 % 29 != 0
        kappa0 = kappas[0]
        assert kappa0 % 29 != 0
        assert comb(91, 31) % 29 != 0

        # 37 is a genuine congruent-node zero and survives every split.
        assert 91 % 37 == 17
        assert Bn % 37 == 0
        assert values[17] % 37 == 0
        assert all(x % 37 == 0 for x in pade_values)
        assert v_p(comb(91, 31), 37) == 1

        print("H=30,n=91 anomaly verified exactly")


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("H", nargs="?", type=int, default=30)
    parser.add_argument("n", nargs="?", type=int, default=91)
    parser.add_argument("--smith", action="store_true")
    args = parser.parse_args()
    if args.n <= args.H:
        raise SystemExit("use an external evaluation point n>H")
    audit(args.H, args.n, args.smith)
```

## 11. Bottom line

The correct object is the **saturated Newton subresultant ideal**, not
\((B_H(n),\Phi_H(n))\) by itself:
\[
\boxed{
(P_a(n):0\le a\le H)
=\left(
\frac{\det\widehat R_b(n)}{\Delta_b(R_b)}:
0\le b\le H
\right).
}
\]
Equivalently it is the tail-Smith ideal
\[
\boxed{
(B_H(n),T_Hz_H(n)).
}
\]

At \(H=30,n=91\), the raw \(29\) is the \(29\)-part of the fixed divisor
of \(\Phi_{30}=31!\binom X{31}\) and is removed by the very first
primitive adjacent Padé certificate; \(37\) is a real congruent-node Apéry
zero and survives. That is the exact algebraic explanation of the observed
\(29\cdot37\to37\) correction.

The Smith formulas also isolate the best immediate upper multiples
(45)/(46). They remove factorial pollution exactly, but they stop at
\(e^{O(H)}\), not the strict \(e^{o(H)}\) scale. The remaining rough common
factor is therefore genuine arithmetic content, not an artifact of
subresultant normalization.
