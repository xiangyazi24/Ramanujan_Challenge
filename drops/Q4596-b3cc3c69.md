# 2. The scalar theorem is an operator-norm theorem

Fix the `a`-coefficients `\nu_a`, the dyadic boxes, the smooth separated
amplitudes and the permitted `C^1` phase.  Define the scalar matrix
\[
 T_\nu(m,n)
 =\mathbf 1_{(m,n)=1}
   \sum_{a\asymp A}\nu_a
   e\!\left(\vartheta a\frac{\bar m}{n}
             +f_{a,\vartheta}(m,n)\right),
\tag{2.1}
\]
with the harmless separated smooth factors absorbed into the three
coefficient sequences.

The scalar Bettin--Chandee theorem, because it holds for arbitrary complex
`\alpha_m` and `\beta_n`, is exactly the operator norm assertion
\[
 \boxed{
 \|T_\nu\|_{\ell^2_n\to\ell^2_m}
 \le \mathfrak C_{BC}(A,M_1,M_2,\vartheta,X)
      \|\nu\|_2,}
\tag{2.2}
\]
where
\[
\begin{aligned}
 \mathfrak C_{BC}
 ={}&N^\varepsilon
 \left(1+\frac{|\vartheta|A+X}{M_1M_2}\right)^{1/2}\\
 &\times\left\{
 (AM_1M_2)^{7/20}(M_1+M_2)^{1/4}
 +(AM_1M_2)^{3/8}(AM_1+AM_2)^{1/8}
 \right\}.
\end{aligned}
\tag{2.3}
\]
This observation is stronger and cleaner than guessing how a
noncommutative proof might behave: it determines the exact Hilbert-space
amplification of the **proved final scalar theorem**.

For any Hilbert space `\mathcal H`,
\[
 \|T_\nu\otimes I_{\mathcal H}\|
 =\|T_\nu\|.
\tag{2.4}
\]
Therefore
\[
 \boxed{
 \left|\sum_{m,n}T_\nu(m,n)
        \langle x_m,y_n\rangle_{\mathcal H}\right|
 \le \mathfrak C_{BC}\|\nu\|_2
 \left(\sum_m\|x_m\|^2\right)^{1/2}
 \left(\sum_n\|y_n\|^2\right)^{1/2}.}
\tag{2.5}
\]
There is no dimension loss in (2.5).

The issue is what coefficient norm (2.5) represents.

# 3. Exact matrix norm: Hilbert amplification is nuclear

Let `C=(c_{mn})` be an arbitrary finite scalar matrix.  Factor it as
\[
 c_{mn}=\langle x_m,y_n\rangle_{\mathcal H}.
\]
Equivalently, if `X` and `Y` have rows `x_m` and `y_n`, then
`C=XY^*`.  Applying (2.5) gives
\[
 \left|\sum_{m,n}c_{mn}T_\nu(m,n)\right|
 \le \mathfrak C_{BC}\|\nu\|_2
       \|X\|_{S_2}\|Y\|_{S_2}.
\tag{3.1}
\]
The exact factorization identity is
\[
 \boxed{
 \inf_{C=XY^*}\|X\|_{S_2}\|Y\|_{S_2}
 =\|C\|_{S_1}.}
\tag{3.2}
\]
Indeed, the SVD `C=U\Sigma V^*` gives equality by taking
`X=U\Sigma^{1/2}`, `Y=V\Sigma^{1/2}`; conversely Schatten Hölder gives
`\|XY^*\|_{S_1}\le\|X\|_{S_2}\|Y\|_{S_2}`.

Thus the automatic Hilbert-space extension of scalar Bettin--Chandee is
precisely
\[
 \boxed{
 \left|\sum_{m,n}c_{mn}T_\nu(m,n)\right|
 \le \mathfrak C_{BC}\|\nu\|_2\,\|C\|_{S_1}.}
\tag{3.3}
\]
It is **not** an `S_2` estimate and it is not an `S_p`, `p>1`, estimate.

This already settles the abstract vector-valued question: vectorization is
valid, but it supplies exactly the nuclear norm whose absence Q4545 had
identified.

# 4. Norm ledger through the Bettin--Chandee proof operations

The coefficient-norm conclusion above follows from the final scalar theorem,
so it does not depend on reconstructing unpublished intermediate notation.
Nevertheless the actual operations used in the scalar argument can be
norm-audited without inventing new arithmetic estimates.

## 4.1 Smooth dyadic separation

Dyadic cutoffs, Mellin/Fourier separation of the smooth amplitude, and
multiplication by unit-modulus phases are scalar diagonal operators.  On
`\ell^2(\mathcal H)` they become scalar operators tensored with
`I_{\mathcal H}`.  Their norm is unchanged.  The coefficient norm at this
stage is still the Hilbert square function.

## 4.2 First Cauchy step

For a scalar rank-one coefficient `\alpha_m\beta_n`, Cauchy in the first
variable produces
\[
 \|\alpha\|_2
 \left(\sum_m\left|\sum_n\beta_nK(m,n)\right|^2\right)^{1/2}.
\tag{4.1}
\]
After expansion, the coefficient in the `(n,n')` correlation is
\[
 \beta_n\overline{\beta_{n'}},
\tag{4.2}
\]
which is independent of `m`.  This independence is what allows the
subsequent arithmetic congruence/divisor analysis to be separated from the
coefficient sequence.

For a genuinely joint matrix `C=(c_{mn})`, the same Cauchy expansion gives
\[
 \sum_m\sum_{n,n'}
 c_{mn}\overline{c_{mn'}}K_m(n,n').
\tag{4.3}
\]
The coefficient now depends on the very variable `m` over which the
arithmetic correlation is being analyzed.  There is no common
`\beta_n\overline{\beta_{n'}}` to pull out.

**This is the first scalar step that fails for a raw nonfactorized matrix.**

If one first factors `C=XY^*`, then (4.3) is restored componentwise, but
Cauchy charges `\|X\|_{S_2}`.  The second coefficient side later charges
`\|Y\|_{S_2}`.  Optimizing is exactly (3.2), hence `S_1(C)`.

## 4.3 Amplification

The amplifier used in the scalar argument is built from scalar copying,
translations/congruence classes and scalar phases.  On Hilbert-valued
coefficients it is the same amplifier tensored with the identity.  It can
change the arithmetic size `\mathfrak C_{BC}` after the scalar parameter is
optimized, but it does not change
\[
 \|X\|_{S_2}\|Y\|_{S_2}.
\]
In particular it creates no orthogonality between singular directions of
`C`.

## 4.4 Second Cauchy and the `a`-coefficients

The second scalar Cauchy step produces the remaining `\ell^2` coefficient
norm and `\|\nu\|_2`.  With a Hilbert factorization this is again an ordinary
Hilbert square function.  No Schatten exponent below two appears.

## 4.5 Divisor/congruence sums

The divisor sums, gcd splits and complete/incomplete exponential-sum bounds
are scalar arithmetic inequalities applied after the coefficient has been
separated by the Cauchy steps.  Tensoring with `I_{\mathcal H}` does not alter
their constants.  Conversely, if one refuses the factorization and keeps
(4.3), those divisor sums are weighted by a different matrix row for every
`m`; the scalar counting lemma no longer has the stated coefficient
hypothesis.

So there are only two rigorous outcomes:

1. factor the matrix before the proof and pay `S_1` exactly; or
2. prove a genuinely new matrix-weighted divisor/amplification theorem that
   controls (4.3) by a smaller Schatten norm.

There is no hidden `S_2` theorem in the scalar proof.

# 5. Operator coefficients and noncommutative Cauchy

The same conclusion holds if one writes operator-valued coefficients
explicitly.  Noncommutative Cauchy--Schwarz replaces scalar square functions
by row/column square functions such as
\[
 \left\|\left(\sum_jB_jB_j^*\right)^{1/2}\right\|,
 \qquad
 \left\|\left(\sum_jB_j^*B_j\right)^{1/2}\right\|.
\]
When the final output is a scalar trace pairing, factoring the scalar
incidence matrix through those row/column spaces again gives
`\|X\|_{S_2}\|Y\|_{S_2}` and hence `S_1` after minimization.

Thus an “operator-valued Bettin--Chandee theorem” obtained merely by replacing
scalar Cauchy with noncommutative Cauchy does not solve the problem.  It is a
repackaging of (3.3).

# 7. Literal actual-Apéry matrix after TT*

For the second-pass norm audit it is convenient to use the Q4545/Q4573
semiprime-row matrix.  For a semiprime `P=pq` and CRT row `t`, put
\[
 A^\sharp_{P,t}
 =\sum_{\substack{pq=P\\
                   t\bmod p\in\mathcal Z_p\\
                   t\bmod q\in\mathcal Z_q}}
 u_pu_q\,
 \mathbf1_{\text{all surviving Q4533/Q4545/Q4573 masks}}.
\tag{7.1}
\]
Any harmless separated smooth scalar factor may be included in the entry;
it has bounded modulus and does not change the following power ledger.
There are at most two ordered presentations of a fixed semiprime `P`.
Therefore, row by row,
\[
 \sum_t|A^\sharp_{P,t}|^2
 \ll |u_p|^2|u_q|^2Z(p)Z(q).
\tag{7.2}
\]
This bound remains true after the masks: even though deleting terms need not
be monotone for the **nuclear** norm, the direct row counting proof of (7.2)
still applies to the surviving entries.

Summing over semiprimes gives the unconditional Frobenius estimate
\[
\begin{aligned}
 \|A^\sharp\|_{S_2}^2
 &=\sum_{P,t}|A^\sharp_{P,t}|^2\\
 &\ll\left(\sum_{p\asymp N}|u_p|^2Z(p)\right)^2
 =E_N^2
 \ll N^{-4/5}(\log N)^2.
\end{aligned}
\tag{7.3}
\]
There are
\[
 M_N\ll N/\log N
\]
primes in the fixed smooth box, hence at most `O(M_N^2)` semiprime rows.
Thus
\[
 \operatorname{rank}A^\sharp
 \le O(M_N^2)
 \ll N^2(\log N)^{-2}.
\tag{7.4}
\]
The nuclear norm is consequently
\[
\begin{aligned}
 \|A^\sharp\|_{S_1}
 &\le\sqrt{\operatorname{rank}A^\sharp}\,
       \|A^\sharp\|_{S_2}\\
 &\ll \frac N{\log N}\,
       N^{-2/5}\log N
 \ll N^{3/5}.
\end{aligned}
\tag{7.5}
\]
This is the strongest unconditional `S_1` bound obtained from the canonical
moment ledger.

\[
 \sum_{t<O(N^2)}\widetilde m_N(t)^4
 \ll N^5(\log N)^{-3}.
\tag{8.3}

\[
 \mathfrak D^{\rm row}\ll DN\log N.
\]
It is **not** the Schatten fourth moment

the surviving off-row singular vectors are formed.  Even a genuine upper
bound on `\|A\|_{S_4}` would be in the wrong direction for controlling
`S_1`: upper Schatten moments with exponent `>2` do not suppress a large
population of small singular values.

## 8.5 Common-index moment

The Q4530 high-column theorem deletes the equal-index subdiagonal with a
large power saving.  It removes a structured support slice but does not imply
that the remaining semiprime-row matrix has rank

## 8.6 Centered-offset moment

Q4545 proves
\[
 \sum_{k>0}m_N^{\rm cen}(k)^2

\tag{8.4}

and Q4573 extends the deletion to
`|g|\le N^{203/2000-\delta}` by signed Bettin--Chandee.  Again these are

matrix.

The distinction is essential: a sparse partial-permutation matrix can have
column degrees `0` or `1` (hence satisfy much stronger second/fourth
basis moments than (8.2)--(8.3)) while having nearly maximal rank and
`\|A\|_{S_1}=\sqrt{\operatorname{rank}A}\|A\|_{S_2}`.  This is a
method-level non-implication, not a claim that the actual Apéry matrix is a
partial permutation.

 \text{BC-cost}\times\sum_j\sigma_j
 =\text{BC-cost}\times\|A^\sharp\|_{S_1}.
\tag{10.2}
\]
Dyadically decompose the singular values.  If
\[
 \lambda<\sigma_j\le2\lambda
\]
for `r_\lambda` indices, triangle gives
\[
 O(r_\lambda\lambda).
\tag{10.3}
\]
Trying Cauchy across that block does not help from the scalar theorem alone:
\[
 \left|\sum_{j\in J_\lambda}B_j\right|
 \le\sqrt{r_\lambda}
      \left(\sum_{j\in J_\lambda}|B_j|^2\right)^{1/2}
 \le C\sqrt{r_\lambda}
      (r_\lambda\lambda^2)^{1/2}
 =Cr_\lambda\lambda.
\tag{10.4}
\]
The Frobenius moment only says
\[
 r_\lambda\lambda^2\le\|A^\sharp\|_{S_2}^2.
\]
It gives no summable improvement for small `\lambda` without an effective
rank theorem.  The periodic fourth moment does not supply
`\sum_j\sigma_j^4`, and even such an upper bound would not control the small
singular values that dominate `S_1`.

Therefore the dyadic-SVD strategy is exactly equivalent to paying the full
nuclear norm.

# 11. The exact new theorem an operator route would need

There are two equivalent ways to formulate the missing analytic/arithmetic
input.

## 11.1 Actual-Apéry coefficient theorem

Prove (R1):
\[
 \|A^\sharp\|_{S_1}
 \ll N^{59/100-\eta/2+o(1)}.
\]
This is a concrete affine zero-set **spectral** correlation theorem.  It is
strictly stronger than the canonical `S_2`/basis-moment information but much
weaker than forcing bounded rank.

## 11.2 Schatten Bettin--Chandee theorem

For a scalar BC kernel `T_\nu`, an inequality
\[
 \left|\operatorname{Tr}(C^*T_\nu)\right|
 \le \mathfrak C_{BC}\|\nu\|_2\|C\|_{S_p}
\tag{11.1}
\]
for **all** joint matrices `C` is dual to
\[
 \|T_\nu\|_{S_{p'}}
 \le\mathfrak C_{BC}\|\nu\|_2,
 \qquad \frac1p+\frac1{p'}=1.
\tag{11.2}
\]
The scalar theorem is only the endpoint `p=1`, `p'=\infty`.
To cross the present rank ledger while keeping the coefficient `S_p` at its
Frobenius scale requires
\[
 p<200/101,
 \qquad
 p'>200/99=2.020202\ldots.
\tag{11.3}
\]
So the genuinely useful operator upgrade is **not** an abstract
Hilbert-valued theorem.  It is a finite-Schatten theorem near `S_2`, with no
`N^{1/p'}` dimension loss, for the exact Kloosterman-fraction operator after
the affine actual-zero masks are inserted.

Such a theorem would have to create orthogonality between the singular
components at the amplification/divisor stage where (4.3) currently couples
the coefficient row to the arithmetic congruence.  It is not a formal
consequence of noncommutative Cauchy--Schwarz.

\begin{proposition}[Hilbert amplification and the nuclear coefficient norm]
\label{prop:ad-bc-nuclear}
Let $T_\nu=(T_\nu(m,n))$ be a dyadic Bettin--Chandee kernel, including
any smooth separated amplitudes and the $C^1$ perturbation allowed by
Bettin--Chandee, Remark~1.  Suppose the scalar theorem gives
\[
 \|T_\nu\|_{\ell^2\to\ell^2}
 \le \mathfrak C_{BC}\|\nu\|_2.
\]
Then for every Hilbert space $\mathcal H$ and every finitely supported
families $x_m,y_n\in\mathcal H$,
\[
 \left|\sum_{m,n}T_\nu(m,n)\langle x_m,y_n\rangle\right|
 \le \mathfrak C_{BC}\|\nu\|_2
 \left(\sum_m\|x_m\|^2\right)^{1/2}
 \left(\sum_n\|y_n\|^2\right)^{1/2}.
\]
Consequently, for every finite scalar matrix $C=(c_{mn})$,
\[
 \left|\sum_{m,n}c_{mn}T_\nu(m,n)\right|
 \le \mathfrak C_{BC}\|\nu\|_2\,\|C\|_{S_1}.
\]
The trace norm is exact in the sense that
\[
 \inf_{c_{mn}=\langle x_m,y_n\rangle}
 \left(\sum_m\|x_m\|^2\right)^{1/2}
 \left(\sum_n\|y_n\|^2\right)^{1/2}
 =\|C\|_{S_1}.
\]
\end{proposition}

\begin{proof}
The scalar theorem is the operator estimate
$\|T_\nu\|\le\mathfrak C_{BC}\|\nu\|_2$.  Tensoring with the identity
on $\mathcal H$ preserves the operator norm and proves the first display.
If $C=XY^*$, take the rows of $X,Y$ as the two Hilbert families.  This gives
\[
 \left|\sum c_{mn}T_\nu(m,n)\right|
 \le\mathfrak C_{BC}\|\nu\|_2\|X\|_{S_2}\|Y\|_{S_2}.
\]
The singular-value factorization gives
$\inf_{C=XY^*}\|X\|_{S_2}\|Y\|_{S_2}\le\|C\|_{S_1}$, while Schatten
H\"older gives the reverse inequality.  Hence equality holds and the
nuclear estimate follows.
\end{proof}

\begin{proposition}[Canonical Schatten ledger for the surviving semiprime rows]
\label{prop:ad-four-schatten-ledger}
Let $A^\sharp=(A^\sharp_{P,t})$ be the actual Ap\'ery semiprime-row matrix
after imposing any subset of the Q4533, Q4545 and Q4573 deletion masks,
with
\[
 A^\sharp_{P,t}
 =\sum_{pq=P}u_pu_q
   \mathbf1_{t\bmod p\in\mathcal Z_p}
   \mathbf1_{t\bmod q\in\mathcal Z_q}
   \mathbf1_{\rm surviving}.
\]
Then
\[
 \|A^\sharp\|_{S_2}^2
 \ll\left(\sum_{p\asymp N}|u_p|^2Z(p)\right)^2
 \ll N^{-4/5}(\log N)^2,
\]
and
\[
 \operatorname{rank}A^\sharp\ll N^2(\log N)^{-2}.
\]
Consequently
\[
 \boxed{\|A^\sharp\|_{S_1}\ll N^{3/5}.}
\]
\end{proposition}

\begin{proof}
For a fixed semiprime $P=pq$ there are at most two ordered
presentations.  Directly counting the surviving CRT rows gives
\[
 \sum_t|A^\sharp_{P,t}|^2
 \ll |u_p|^2|u_q|^2Z(p)Z(q).
\]
Summing over $P$ proves the Hilbert--Schmidt estimate.  The canonical
first zero moment gives
\[
 \sum_{p\asymp N}|u_p|^2Z(p)
 \ll N^{-2/5}\log N.
\]
There are $O((N/\log N)^2)$ semiprime rows, proving the rank estimate.
Finally
$\|A\|_{S_1}\le\sqrt{\operatorname{rank}A}\,\|A\|_{S_2}$ gives the
last display.
\end{proof}

\begin{lemma}[Rank-one decomposition does not improve the nuclear cost]
\label{lem:ad-bc-svd-cost}
Let $A=\sum_j\sigma_ju_jv_j^*$ be a singular-value decomposition.
Any argument which applies the same scalar Bettin--Chandee estimate
separately to each rank-one term and combines the resulting estimates only
by triangle inequality and Cauchy--Schwarz incurs the coefficient cost
\[
 \sum_j\sigma_j=\|A\|_{S_1}.
\]
The same remains true after dyadically grouping the singular values.
\end{lemma}

\begin{proof}
Triangle inequality gives the stated sum directly.  On a dyadic block
with $r$ singular values of size $\lambda$, Cauchy--Schwarz followed by
the individual scalar estimate gives
\[
 \sqrt r\,(r\lambda^2)^{1/2}=r\lambda,
\]
which is the same block contribution as triangle inequality.  Summing the
blocks is precisely the trace norm up to an absolute dyadic constant.
\end{proof}

# 14. Fully unconditional conclusion

The operator-valued avenue is now sharply classified.

- **Positive:** scalar Bettin--Chandee has a completely rigorous
  Hilbert-space amplification with no loss.
- **Negative:** the exact joint-matrix norm supplied by that amplification is
  `S_1`; after inserting the actual Apéry semiprime/CRT matrix, canonical
  moments give only the critical `N^{3/5}` nuclear size.
- **First noncommutative failure:** after the first Cauchy expansion the raw
  matrix coefficient is `c_{mn}\overline{c_{mn'}}` and depends on the
  arithmetic summation variable `m`; the scalar divisor/amplification step
  no longer sees a separable coefficient.  Factoring before that step
  restores the proof but costs nuclear norm exactly.
- **SVD alternative:** no gain; dyadic rank-one summation is again `S_1`.
- **Smallest spectral repair:** a fixed `N^{1/50+\eta}` improvement in
  nuclear effective rank/Frobenius mass, or a same-scale Schatten
  `p<200/101` theorem for the actual affine zero-set incidence matrix.
- **AD4-sharp:** still open.
- **Fully unconditional P3.2:** still open.

The next useful theorem is therefore not a generic “vector-valued
Bettin--Chandee” statement.  It must be a **finite-Schatten or effective-rank
estimate tied to the actual Apéry affine-correlation matrices**, while the
analytic kernel continues to retain the signed `d`-sum and both circular
`\Delta` branches.
