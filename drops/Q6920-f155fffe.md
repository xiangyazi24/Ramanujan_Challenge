# 7. The exact smallest remaining certificate

Let

```text
rho = 17 - 12 sqrt(2) = 1/lambda+.
```

The dominant normalized mode has coefficients `lambda+^n n^0`, hence its generating function has a simple-pole channel at `z=rho`. Let `C_rho(F)` denote the coefficient of this channel, equivalently

```text
C_rho(F) = lim_{z -> rho} (1-z/rho) F(z)
```

whenever the standard continuation supplied by `(D)` is used.

The requested connection theorem is exactly the one scalar identity

```text
C_rho(G Qhat - Phat) = 0.                    (CC)
```

Since `C_rho(Qhat) != 0`, `(CC)` is equivalent to

```text
G = C_rho(Phat) / C_rho(Qhat),
```

and therefore forces the common ratio limit to be Catalan's constant.

There is an entirely algebraic companion-adjoint form of the same certificate. Put

```text
Y(n) = (y(n), y(n+1), y(n+2))^T,
```

and

```text
C(n) = [[0, 1, 0],
        [0, 0, 1],
        [-p0(n)/p3(n), -p1(n)/p3(n), -p2(n)/p3(n)]].
```

Then `Y(n+1)=C(n)Y(n)`. The limiting companion matrix is

```text
C_inf = [[0,1,0],
         [0,0,1],
         [1,-35,35]].
```

For `lambda=lambda+`, a left eigenvector is

```text
w+ = (1, lambda^2-35 lambda, lambda),
w+ C_inf = lambda w+.
```

Let `ell+(n)` be the unique backward adjoint covector satisfying

```text
ell+(n) = ell+(n+1) C(n),
lim_{n->infinity} lambda^n ell+(n) = w+.
```

Then the dominant connection coefficient of any solution is proportional to `ell+(0) Y(0)`. Consequently `(CC)` is equivalent to the single scalar equality

```text

  (5295375/4) G - 475337925/392,
  (96943875/2) G - 33565362445/756
```

`(ADJ)` is the smallest remaining certificate I can justify exactly from the literal recurrence. It has one scalar unknown connection functional, not a 3x3 rational gauge, not a six-dimensional Lima elimination, and not a fitted order-6 differential operator.

A successful answer beyond this report must evaluate `ell+(0)` or `C_rho` exactly. The computations above prove that this evaluation cannot be supplied by a rationally gauged Catalan summand or a rationally gauged Lima paired term.
