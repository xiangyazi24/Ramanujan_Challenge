# No self-twist + bounded conductor: what it really gives

## Summary

The conjecture is very plausible as a heuristic, and the computation is detecting a real phenomenon, but it is **not a known theorem in this generality**. The missing point is that Katz's Mellin theory controls the geometry and cohomological dimension of the Mellin transform, but not the number of points where its trace function vanishes modulo p.

The correct statement is closer to:

```
no self-twist + bounded conductor
        => no forced positive-density Mellin zeros
        => expected O(1) zeros
```

but the final implication needs a new anti-concentration theorem.

## (A) Is the conjecture known?

Not in this form.

Known results give:

1. Mellin transform is a controlled sheaf on the dual torus.
2. Generic Mellin values satisfy square-root cancellation.
3. Self-twists explain systematic degeneracies.

But there is no theorem saying:

```
K(F)=1 and cond(F)<=C
    => #{chi : Mellin(F,chi)=0 mod p} <= f(C).
```

The obstruction is that a trace function can have many zeros without coming from an actual geometric self-twist.

Self-twist detects exact symmetry:

```
F tensor L_chi ~= F
```

but AFP requires detecting approximate symmetry after reduction modulo p:

```
Tr(Frob_chi | M(F)) = 0 mod p.
```

These are different phenomena.

## (B) Does scalar arithmetic monodromy improve O(sqrt(p)) to O(1)?

No.

Katz's result gives equidistribution:

```
#{chi : Frob_chi in C}
 = density(C)*(p-1) + O(sqrt(p)).
```

The presence of scalars in arithmetic monodromy removes exceptional character constraints. It prevents situations like Legendre where half the Mellin transform vanishes identically.

However, it does not improve the error term to O(1). The square-root error comes from H^1_c of the parameter space and is generally optimal.

The remaining gap is exactly the gap between:

```
no structural zeros
```

and

```
no accidental mod-p zeros.
```

## (C) Mellin transform sheaf viewpoint

This is the correct geometric reformulation.

Let

```
M(F)_chi = H^1_c(G_m, F tensor L_chi).
```

Then b_chi is the trace function of M(F) on the dual torus.

If F has no self-twist, M(F) should not descend through an isogeny of the dual torus. This explains why Legendre fails: its Mellin sheaf has a forced decomposition producing a large zero locus.

But even for a geometrically irreducible sheaf M of bounded conductor:

```
#{x in F_p : Tr(Frob_x|M)=0}
```

is not controlled by conductor alone.

A trace function is not an algebraic function whose zero divisor has bounded degree. Frobenius traces are much more flexible.

## (D) Kloosterman Mellin transform clarification

The identity

```
Kl_2 = AS_psi * AS_psi
```

is correct, but the Mellin transform statement needs care.

Multiplicative Fourier transform gives:

```
M(Kl_2)(chi)
  = M(AS_psi)(chi) * M(AS_psi)(chi)
```

and each factor is a Gauss sum up to normalization.

However:

```
complex Mellin value
```

and

```
mod-p reduction of the integer trace sum
```

live in different coefficient systems.

The equality is an equality of algebraic numbers after choosing compatible l-adic realizations. It does not mean that the naive integer Kloosterman Mellin sum is literally a square of an element in F_p.

The reduction modulo p requires choosing an integral model of the sheaf. Divisibility by p is a statement about the lattice inside the coefficient field, not about the complex value being zero.

Thus:

```
g(chi)^2 != 0 in characteristic zero
```

is compatible with

```
c_chi = 0 mod p.
```

The latter is an arithmetic congruence phenomenon.

## Why the Kloosterman data are important

The Kloosterman example suggests:

- no self-twist removes deterministic zeros;
- bounded conductor gives bounded complexity;
- remaining zeros behave randomly with probability about 1/p.

This is exactly the heuristic behind AFP.

But turning the heuristic into a theorem requires a mod-p equidistribution result, not ordinary l-adic equidistribution.

## The Legendre obstruction

Legendre is the model counterexample to any theorem ignoring self-twists.

The involution produces:

```
F tensor L_chi_-1 ~= F.
```

Therefore Mellin coefficients in the odd character sector vanish identically.

The zero set is not caused by random Frobenius behavior; it is caused by descent symmetry.

Apéry avoids this obstruction, which is a necessary condition.

## The likely correct theorem

A realistic conjectural theorem would need more than K(F)=1:

```
Let F be a geometrically irreducible middle-extension sheaf on G_m.
Assume:
  - bounded conductor,
  - trivial self-twist group,
  - primitive geometric monodromy,
  - no exceptional quotient representations.

Then the number of characters chi with

Tr(Frob_chi | M(F)) = 0 mod p

is O_F(1).
```

The extra condition is essentially a "mod-p large sieve" or "microscopic Mellin equidistribution" statement.

## Consequence for Apéry

The computation suggests the Apéry route is now much sharper:

```
Apéry sheaf
   |
   v
bounded conductor + SO_3 monodromy
   |
   v
trivial self-twist
   |
   v
Mellin sheaf has no forced zero component
   |
   ???
   |
   v
AFP
```

The missing theorem is the last arrow.

The breakthrough is that the obstruction is no longer geometric rigidity or overconvergence. It is specifically:

```
mod-p anti-concentration of Mellin trace functions
```

for primitive sheaves.

This is a natural new theorem target.
