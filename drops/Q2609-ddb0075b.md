# Hostile audit: the reciprocal signed Hankel zero-rate theorem is not covered by standard discrete RH/Fisher–Hartwig results

## Verdict

**The claimed theorem is not proved.**

The exact checkerboard determinant reduction is valid, and the half-integer reciprocal factor does change the fixed-order signed moments radically. For each fixed moment order, the pure asymptotic model has a logarithmic contribution rather than the positive-rate geometric Krawtchouk leading term. That is a real calculation.

It does **not** imply a determinant asymptotic when the determinant order grows like the two-thirds power of the lattice size. None of the standard discrete Riemann–Hilbert or Fisher–Hartwig theorems cited below directly covers the simultaneous combination of:

- an indefinite checkerboard functional;
- a finite lattice whose size tends to infinity;
- polynomial degree divided by lattice size tending to zero;
- a hard-edge half-power;
- an exact Apéry reciprocal weight rather than an exactly solvable deformation; and
- the need for a logarithmic error smaller than linear order in the lattice size for both a signed norm and an outside polynomial evaluation.

The recent project answer Q2598 in fact states the needed uniform signed-RH estimate as an **unproved lemma** and makes its zero-rate conclusion conditional on that lemma and on a second true-weight stability estimate. It cannot be cited as an unconditional theorem.

There is also a concrete analytic counterexample to the claimed transfer principle. An exponentially small, positivity-preserving perturbation of the reciprocal weight leaves the complete large-index asymptotic expansion unchanged to every algebraic order, yet its zeroth checkerboard binomial moment acquires a nonzero exponential term. Thus the half-integer tail alone does not determine even the first signed Hankel determinant, much less a determinant of growing order.

The honest status is therefore:

```plain text
fixed-order moment cancellation for the ideal half-power model: PROVED;
normality of the exact growing signed Hankel system: NOT PROVED;
uniform determinant/norm asymptotics through a <= C H^(2/3): NOT PROVED;
stability from the ideal model to the exact Apéry reciprocal weight: NOT PROVED;
log |P_hat(3H+1)| = o(H) for the exact ratio: OPEN.
```

No counterexample to the final exact Apéry zero-rate statement is established here. What is refuted is the assertion that standard theory or the fixed-order saddle cancellation already proves it.

# 2. Exact determinant ledger

Let the exact reciprocal weight and signed moments be

```plain text
w_H(j) = 1 / (b_j j! (H-j)!),

mu_k(H) = sum_{j=0}^H (-1)^j j^k w_H(j),

Z_m^-(H) = det[mu_{r+s}(H)]_{0 <= r,s < m}.
```

Let the low numerator degree and evaluation point be

```plain text
a = floor(H^(2/3)) + O(1),

n = 3H + 1.
```

For a weight multiplier `g`, write

```plain text
Z_m^-(g w_H)
 = det[
     sum_{j=0}^H (-1)^j j^(r+s) g(j) w_H(j)
   ]_{0 <= r,s < m}.
```

The exact reciprocal dual formula has the form

```plain text
P_hat_{H,a}(n)
 = +/- 1/(H-a)! *
   Z_a^-((n-j) w_H(j)) / Z_{a+1}^-(w_H(j)).
```

The sign is immaterial for the height question. This identity is exact, but it already exposes a prerequisite that positivity would normally hide:

```plain text
Z_{a+1}^-(w_H) != 0.
```

For a positive measure, nonvanishing follows from positive definiteness. Here the masses alternate, so it does not. A generic-rank expectation is not a normality theorem.

Assuming all preceding Hankel determinants are nonzero, define the signed functional

```plain text
L_H(f) = sum_{j=0}^H (-1)^j w_H(j) f(j).
```

Let `p_{m,H}` be the monic polynomial of degree `m` satisfying the signed orthogonality conditions, and let its signed norm be

```plain text
h_{m,H} = L_H(p_{m,H}^2)
        = Z_{m+1}^-(w_H) / Z_m^-(w_H).
```

The Christoffel identity gives

```plain text
Z_a^-((n-j)w_H(j))
 = p_{a,H}(n) Z_a^-(w_H).
```

Hence

```plain text
P_hat_{H,a}(n)
 = +/- p_{a,H}(n) / ((H-a)! h_{a,H}).
```

This is the cleanest exact reduction. The analytic problem is not an unsigned equilibrium measure. It is the simultaneous control of one **signed norm** and one **outside evaluation**.

# 3. What the half-integer calculation actually proves

Put

```plain text
alpha = 17 + 12 sqrt(2),

q = alpha^(-1).
```

The pure asymptotic reciprocal model for positive indices is

```plain text
1/b_j approximately C^(-1) q^j j^(3/2).
```

After multiplying a moment by `H!`, the model moment of order `k` is

```plain text
S_H(k+3/2; q)
 = sum_{j=0}^H
   (-1)^j binom(H,j) q^j j^(k+3/2).
```

More generally, for a complex parameter `rho`, there is the exact generating function

```plain text
sum_{H >= 0} S_H(rho; q) z^H
 = 1/(1-z) *
   Li_{-rho}(-q z/(1-z)).
```

For each **fixed** nonnegative integer `k`, singularity analysis at `z=1` gives

```plain text
S_H(k+3/2; q)
 = -1/Gamma(-k-1/2) *
   (log(qH))^(-k-3/2) *
   (1 + O_k(1/log H)).
```

Equivalently, the leading constant is

```plain text
-1/Gamma(-k-1/2)
 = (-1)^k Gamma(k+3/2)/pi.
```

This is a valid fixed-order statement for the ideal model. It explains why the dominant fixed-order asymptotic is not the pure-geometric Krawtchouk exponential.

It does not cover the moment matrix required here. That matrix contains orders through

```plain text
0 <= r+s <= 2a-2,

2a-2 asymptotic to 2 H^(2/3).
```

The subscript on the error term is therefore fatal: it is not a uniform error.

## 3.1 The first omitted coefficient is already nonuniform

The same large-argument polylogarithm expansion has the formal next term

```plain text
Li_{-rho}(-exp(L))
 = - L^(-rho)/Gamma(1-rho) *
   [
     1
     + pi^2 rho(rho+1)/(6 L^2)
     + higher terms
   ].
```

The next relative coefficient is therefore

```plain text
pi^2 rho(rho+1)/(6 L^2).
```

At the moment orders needed by the determinant,

```plain text
rho asymptotic to H^(2/3),

L asymptotic to log H,
```

so that coefficient has size

```plain text
H^(4/3)/(log H)^2.
```

It does not tend to zero. The fixed-parameter expansion ceases to be perturbative already when the moment order reaches the logarithmic scale. This locates the breakdown of the fixed-order proof, not necessarily a phase transition of the exact determinant:

```plain text
fixed-order expansion is perturbative only in a regime such as
rho = o(log H).
```

Thus one cannot insert the fixed-`k` formula entry by entry into a determinant whose order is the two-thirds power of `H`.

## 3.2 Entrywise asymptotics would still be insufficient

A Hankel determinant is highly cancellation-sensitive. Even a genuinely uniform relative approximation to every entry does not automatically imply a relative determinant approximation. One needs control after conjugation by the inverse model moment matrix, or a direct RH/recurrence analysis of the norms.

The formal Laguerre matrix suggested by the fixed moments is

```plain text
M_ref(r,s)
 = 1/pi * Gamma(r+s+3/2) *
   L_H^(-r-s-3/2).
```

Its determinant is

```plain text
det M_ref
 = pi^(-a) *
   L_H^(-a(2a+1/2)) *
   product_{j=0}^{a-1} j! Gamma(j+3/2).
```

The exact exponent on `L_H` is less important than the structural point: this determinant is the result of cancellation among many products of large moments. Replacing each entry by its fixed-order leading term without an operator-norm error estimate is not a determinant proof.

# 4. Concrete analytic counterexample to tail-to-determinant uniformity

The following construction is a rigorous counterexample to the inference that the half-integer large-index factor, even with a complete algebraic asymptotic expansion, determines the signed moments.

Fix numbers satisfying

```plain text
0 < r < q < 1.
```

Let `f_j` be any positive reciprocal sequence with Apéry-type decay,

```plain text
f_j = 1/b_j,

f_j = C^(-1) q^j j^(3/2) * (1 + O(1/j)).
```

Define a perturbed positive reciprocal sequence by

```plain text
f_0^* = f_0,

f_j^* = f_j + epsilon (-r)^j,

j >= 1,
```

where `epsilon` is a sufficiently small positive constant. Such an `epsilon` exists because

```plain text
f_j/r^j tends to +infinity,
```

so positivity needs to be checked only on finitely many initial indices.

The perturbation is exponentially smaller than the Apéry-type tail:

```plain text
(f_j^* - f_j)/f_j
 = O((r/q)^j j^(-3/2)).
```

Therefore `f_j^*` and `f_j` have exactly the same asymptotic expansion in every inverse power of `j`. The corresponding positive sequences

```plain text
b_j^* = 1/f_j^*
```

also have the same complete algebraic asymptotic expansion.

Now compare the scaled zeroth signed moments:

```plain text
M_0(H)
 = H! mu_0(H)
 = sum_{j=0}^H (-1)^j binom(H,j) f_j.
```

The perturbation changes this moment by the exact amount

```plain text
M_0^*(H) - M_0(H)
 = epsilon *
   sum_{j=1}^H
   (-1)^j binom(H,j) (-r)^j

 = epsilon ((1+r)^H - 1).
```

Hence

```plain text
log |M_0^*(H) - M_0(H)|
 = H log(1+r) + O(1).
```

But the two reciprocal sequences are indistinguishable to every algebraic order at infinity. Since

```plain text
Z_1^-(H) = mu_0(H),
```

this changes even the first signed Hankel determinant by a linear exponential scale.

This example proves exactly what is needed for the hostile audit:

> A half-integer Fisher–Hartwig tail, even together with its full formal inverse-power expansion, does not imply stability of checkerboard binomial moments. Exponentially small tail information can be exponentially amplified by the signed binomial transform.

The example does not assert that the exact Apéry reciprocal sequence contains this perturbation. It proves that a transfer theorem from the model tail to the exact Apéry determinant is a separate, load-bearing theorem and cannot be replaced by “the asymptotics have the same half-power.”

## 4.1 The hard-edge mismatch is already exact

The ideal tail model has

```plain text
j^(3/2) = 0 at j=0,
```

whereas the exact Apéry reciprocal value is

```plain text
1/b_0 = 1.
```

Thus even if the model were made exact at every positive node, the exact zeroth scaled moment would differ by one:

```plain text
M_0^exact(H)
 = 1 + S_H(3/2;q)/C.
```

A single hard-edge point mass is only a rank-one moment perturbation, so this observation alone does not force a linear change in the final rate. It does show that the exact determinant is not literally the formal Laguerre determinant. The exponentially small perturbation above shows that the missing stability can in fact be linear in `H`.

# 5. Why the standard primary references do not supply the theorem

## 5.1 Baik–Kriecherbauer–McLaughlin–Miller

The full discrete RH theory in Baik, Kriecherbauer, McLaughlin, and Miller treats polynomials orthogonal for **positive** weights on growing finite node sets. Its basic asymptotic regime ties polynomial degree to the number of nodes with a fixed filling fraction in the open interval between zero and one.

The present problem instead has

```plain text
weight sign = (-1)^j,

a/H tends to 0.
```

The positive-definite Gram form, real constrained equilibrium measure, automatic normality, and fixed-filling error estimates used there are therefore unavailable. The paper supplies a framework from which a new analysis might begin; it does not supply the required theorem by substitution.

Primary source:

- J. Baik, T. Kriecherbauer, K. T.-R. McLaughlin, P. D. Miller, [*Uniform Asymptotics for Polynomials Orthogonal With Respect to a General Class of Discrete Weights and Universality Results for Associated Ensembles*](https://arxiv.org/abs/math/0310278), full version; announcement DOI [10.1155/S1073792803212125](https://doi.org/10.1155/S1073792803212125).

## 5.2 Bleher–Liechty

Bleher and Liechty study a regular lattice with positive varying exponential weight

```plain text
w_N(x) = exp(-N V(x)),
```

where `V` is real analytic with growth at infinity, and they analyze the degree-`N` polynomial and its norm. Their existence, equilibrium, and RH analysis use the real positive weight. The exact checkerboard reciprocal weight is not in those hypotheses.

Primary source:

- P. Bleher, K. Liechty, [*Uniform Asymptotics for Discrete Orthogonal Polynomials with Respect to Varying Exponential Weights on a Regular Infinite Lattice*](https://arxiv.org/abs/0909.1985), DOI [10.1093/imrn/rnq081](https://doi.org/10.1093/imrn/rnq081).

## 5.3 Continuous Fisher–Hartwig Hankel theorems

Charlier’s theorem treats continuous real-line Hankel integrals with a one-cut regular real potential and finitely many fixed Fisher–Hartwig singularities. It is not a finite discrete checkerboard moment problem, and it does not address a signed Hankel determinant whose polynomial degree is sublinear in the number of lattice nodes.

Primary source:

- C. Charlier, [*Asymptotics of Hankel determinants with a one-cut regular potential and Fisher–Hartwig singularities*](https://arxiv.org/abs/1706.03579), DOI [10.1093/imrn/rny009](https://doi.org/10.1093/imrn/rny009).

The same mismatch applies to the continuous Toeplitz/Hankel Fisher–Hartwig theorem of Deift, Its, and Krasovsky:

- P. Deift, A. Its, I. Krasovsky, [*Asymptotics of Toeplitz, Hankel, and Toeplitz+Hankel determinants with Fisher–Hartwig singularities*](https://arxiv.org/abs/0905.0443).

## 5.4 Borodin’s discrete RHP

Borodin defines the discrete Riemann–Hilbert formalism and relates discrete integrable kernels to it. The paper solves particular Bessel-type examples. It is a representation method, not a black-box uniform asymptotic theorem for arbitrary signed varying finite-lattice weights.

Primary source:

- A. Borodin, [*Riemann-Hilbert problem and the discrete Bessel kernel*](https://arxiv.org/abs/math/9912093), DOI [10.1155/S107379280000026X](https://doi.org/10.1155/S107379280000026X).

## 5.5 Apéry tail information

Edgar proves that the Apéry numbers form a Stieltjes moment sequence and supplies the positive moment framework underlying their endpoint asymptotics. That controls the ordinary large-index tail; it does not control the checkerboard reciprocal finite differences or their growing Hankel determinants.

Primary source:

- G. A. Edgar, [*The Apéry Numbers as a Stieltjes Moment Sequence*](https://arxiv.org/abs/2005.10733).

## 5.6 Exact hypothesis mismatch in one table

| Standard result | Positivity | Support | Degree regime | Singularities | Covers exact ratio? |
|---|---:|---|---|---|---:|
| Baik–Kriecherbauer–McLaughlin–Miller | yes | finite growing lattice | fixed positive filling fraction | analytic varying weight | no |
| Bleher–Liechty | yes | regular infinite lattice | degree comparable to lattice scale | real analytic potential | no |
| Charlier Fisher–Hartwig | yes/controlled complex factors | continuous real line | large determinant size | finitely many fixed FH points | no |
| Borodin discrete RHP | model-dependent | discrete | model-dependent | integrable kernels | formalism, not theorem |
| Present Apéry reciprocal problem | no | finite lattice | vanishing filling fraction | hard edge plus checkerboard phase | target problem |

There is therefore no primary citation that directly establishes the Q2598 uniform lemma.

# 6. The first exact asymptotic statement that must be proved

The first item is normality:

```plain text
For all sufficiently large H and all
0 <= a <= C H^(2/3),

Z_a^-(w_H) != 0
and
Z_{a+1}^-(w_H) != 0.
```

After normality, the direct necessary-and-sufficient logarithmic target is

```plain text
sup_{0 <= a <= C H^(2/3)}
|
  log |Z_a^-((3H+1-j)w_H(j))|
  - log |Z_{a+1}^-(w_H(j))|
  - log((H-a)!)
|
 = o(H).
```

That is the exact determinant-ratio statement. To make the problem less tautological and compatible with an RH proof, split it into the norm and outside-evaluation assertions.

Let

```plain text
L_H = log(H/alpha).
```

The formal fixed-moment Laguerre prediction for the signed norm is

```plain text
h_ref(H,a)
 = 1/(C H! pi) *
   a! Gamma(a+3/2) *
   L_H^(-2a-3/2).
```

A sufficient uniform theorem would be

```plain text
sup_{0 <= a <= C H^(2/3)}
|
  log |h_{a,H}/h_ref(H,a)|
|
 = o(H),
```

and

```plain text
sup_{0 <= a <= C H^(2/3)}
|
  log |p_{a,H}(3H+1)/(3H+1)^a|
|
 = o(H).
```

These estimates must be for the **exact Apéry reciprocal functional**, not merely for the ideal tail model. Alternatively, one may first prove them for an exact Fisher–Hartwig model and then prove the stability estimates

```plain text
sup_{0 <= a <= C H^(2/3)}
|
  log |h_{a,H}^{Apery}/h_{a,H}^{model}|
|
 = o(H),
```

and

```plain text
sup_{0 <= a <= C H^(2/3)}
|
  log |p_{a,H}^{Apery}(3H+1)
        /p_{a,H}^{model}(3H+1)|
|
 = o(H).
```

The perturbation counterexample in Section 4 proves that these stability estimates do not follow from agreement of the two weights to all algebraic orders at infinity.

Under the norm and evaluation estimates, the exact identity gives

```plain text
log |P_hat_{H,a}(3H+1)|
 = log |p_{a,H}(3H+1)|
   - log((H-a)!)
   - log |h_{a,H}|

 = O(H^(2/3) log H
     + H^(2/3) log log H)
   + o(H)

 = o(H).
```

This implication is elementary. The two uniform inputs are the missing theorem.

# 7. What a genuine proof would have to add

A valid RH proof would be new work, not an invocation. It would have to do all of the following.

1. Formulate the exact meromorphic interpolation/RH problem for the checkerboard masses, including a normalization that remains meaningful when the Gram form is indefinite.
2. Prove normality, or equivalently nonvanishing of the relevant signed Hankel determinants, throughout the entire range of growing degrees.
3. Analyze a double-scaling regime in which the filling fraction tends to zero:

```plain text
a/H = O(H^(-1/3)).
```

4. Construct a hard-edge parametrix for the half-power while retaining the complex checkerboard phase.
5. Obtain a small-norm error estimate strong enough after integration in the degree parameter to yield an `o(H)` logarithmic error for the norm.
6. Control the outside evaluation at a point three times the lattice scale.
7. Prove stability under replacing the exact model weight by the exact reciprocal Apéry values, including exponentially small information that the signed binomial transform can amplify.

No cited standard theorem performs this package.

A recurrence approach would face the same first target in different language: it must produce uniform asymptotics for the signed recurrence coefficients and norms through degree two-thirds power, with a nonvanishing theorem and errors summable to `o(H)`.

# 8. Audit of the “exact Stokes cancellation” wording

For the ideal half-power model, the fixed-order logarithmic term is real and load-bearing. It is safe to state:

> For every fixed moment order, the nearest singular behavior relevant to ordinary coefficient asymptotics produces a logarithmic term that dominates the pure-geometric exponential term.

It is not safe, without a hyperasymptotic analysis uniform in the moment order, to state:

> The geometric Krawtchouk sector is identically absent from every quantity needed by the growing determinant.

The fixed-order expansion is a Poincaré expansion. Exponentially small sectors are invisible to it, and the counterexample in Section 4 shows that exponentially small changes in the reciprocal sequence can be promoted to linear-exponential changes by the checkerboard binomial transform.

Thus the phrase “the half-integer factor cancels the saddle” is acceptable only as shorthand for the leading fixed-order moment asymptotic. It is not a determinant theorem or a stability theorem.

# 9. Final disposition

The exact answer to the question is:

```plain text
Does standard discrete RH/Fisher-Hartwig theory prove
log |P_hat(3H+1)| = o(H)
for the exact reciprocal Apéry determinant ratio
when a = H^(2/3) + O(1)?

No.
```

The first missing theorem is not a contour choice. It is the uniform normality-plus-norm estimate in Section 6, together with the outside-evaluation estimate and exact-weight stability.

The fixed-order half-integer calculation is useful evidence and identifies a plausible reference parametrix. It cannot be extrapolated to determinant order `H^(2/3)`. The first correction in its own polylogarithm expansion is already nonuniform at that scale, determinant conditioning is uncontrolled, and exponentially small tail perturbations can alter the first signed moment at linear exponential scale.

Accordingly, the recent claim should be recorded as the following conditional statement, not as a theorem:

```plain text
If the exact signed Apéry reciprocal system is normal through
order C H^(2/3),
if its signed norms satisfy the uniform Laguerre-type logarithmic
asymptotic with o(H) error,
and if its outside monic polynomials satisfy the corresponding
o(H) evaluation estimate,
then
log |P_hat(3H+1)| = o(H).
```

Those hypotheses are presently the open analytic core.
