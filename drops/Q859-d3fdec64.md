# Q859 corrected hostile audit of short-arc => all-index

## 1. Verdict and retraction of Q857 claim

The previous Q857 objection that a nonnegative second-moment bound cannot yield a pointwise estimate was incorrect. The correction is accepted.

If

```
Σ_{N<k≤2N} |D_P(k)|² ≪ N^{1+o(1)} Q_P,
```

then every individual term satisfies

```
|D_P(k)|² ≤ Σ_{N<k≤2N}|D_P(k)|²,
```

and hence

```
|D_P(k)| ≪ N^{1/2+o(1)} Q_P^{1/2}.
```

Using the oracleA estimate

```
Q_P ≪ P^{2/3} log P,
```

we obtain

```
|D_P(k)| ≪ N^{1/2+o(1)}P^{1/3}.
```

For `P≤N` this gives

```
|D_P(k)| ≪ N^{5/6+o(1)}=o(N),
```

uniformly in k.

Therefore the earlier claimed fatal average-to-pointwise gap is retracted.

## 3. Uniformity of o(1)

The remaining condition is that the `o(1)` in

```
Σ |D_P(k)|² << N^{1+o(1)}Q_P
```

must be uniform over the allowed parameter range:

```
√M < P ≤ M.
```

For the dyadic application one uses

```
M=4N,
P∈(√N,2√N],
```

so

```
√M=2√N.
```

The short-arc hypothesis must therefore be available with the exact admissible interval after dilation, or after adjusting the dyadic block constants. If the theorem is stated only for `√M<P≤M`, then the boundary case must be checked because `P≤2√N=√M` is not literally inside that interval when `M=4N`.

The repair is either:

1. state short-arc for `P≫√M` with an absolute constant allowing `P>c√M`; or
2. use `M=N` normalization rather than `M=4N` in the relevant dyadic block.

This is a normalization issue, not a dispersion issue.

## 4. Dyadic summation audit

The pointwise estimate gives

```
W_P(k)=o(k)
```

inside one dyadic block. To conclude the global statement one still needs:

```
Σ_{dyadic blocks} contribution
```

with a convergent loss. The number of dyadic blocks up to X is logarithmic, so a uniform estimate of the form

```
W(n) ≤ ε n
```

for all sufficiently large blocks absorbs the dyadic summation.

If the `o(1)` depends on P without uniform control, this step fails. The required theorem must explicitly quantify the uniformity.
