# Q1120 audit: recursive Cartier factorization

## Verdict

The proposed recursion is **not an exact factorization in the stated generality**. The Lucas reductions for the two binomial factors and the sign are correct on the surviving residue class, but the surviving range is not the same as the outer Newton window in all endpoint cases. The first failure is an endpoint failure: the inner shifted window has an extra or missing term when the lower endpoint is transported through the base-p carry.

The obstruction already appears before any issue with the Apéry factor. Thus iterating the formula cannot produce a new characteristic-zero carrier; it only records the usual Cartier/Lucas extraction of the residue digit.

## 1. Lucas calculation

Write

```
n = qp+r,
M = Ap+t,
0 <= t < p,
H=n-M,
m=kp,
h=H-kp+1.
```

For a candidate surviving index

```
j=ap+r,
```

we have

```
j-h = ap+r-(H-kp+1)
```

and

```
h+M-1-j = n-kp-j = (q-a-k)p.
```

The second binomial is therefore

```
C(n-j-1, h+M-1-j)
 = C((q-a-1)p+(r-1), (q-a-k)p).
```

For r>0 Lucas gives

```
C(n-j-1, h+M-1-j) = C(q-a-1,q-a-k)
                 = C(q-a-1,k-1) (mod p).
```

The first binomial has

```
C(n-h,j-h)=C(n-h,E)
```

with E having the expected digit split. Carrying through the borrow at the p-digit gives

```
C(A+k,q-a)          if t>0,
C(A+k-1,q-a)        if t=0.
```

The sign is also correct:

```
(-1)^(h+M-1-j)=(-1)^(q-k-a).
```

So the local Lucas identities are valid.

## 2. Where the proposed recursion fails

The surviving residues are not determined only by Lucas non-vanishing. They must also satisfy the original finite summation range

```
h <= j <= h+M-1.
```

For j=ap+r this becomes a condition on a. The upper endpoint is harmless because

```
h+M-1=n-kp.
```

However the lower endpoint contains H and therefore depends on the borrow from

```
H=n-M.
```

When t=0 the decomposition

```
M=Ap
```
forces a borrow in H. The corresponding a-range is shifted by one compared with the claimed outer P-window. The claimed t=0 formula

```
b_r P_{q-A-k+1}^{(A)}(q)
```
uses the formal binomial identity but not the actual truncated support.

The same problem occurs at the extreme residues:

* r=0: the expression n-j-1 has a different last base-p digit; replacing r-1 by p-1 changes the Lucas carry condition.
* r=1: this is the first place where the second factor has lower digit zero and the boundary carry is exposed.
* r=p-1: the lower digit borrow is maximal and the naive cancellation of the residue digit fails.

Thus the statement “all other j have coefficient zero mod p” is false at the shifted endpoints. They may disappear by Lucas, but the surviving set is not exactly the translated outer carrier.

## 3. q=1 check

The q=1 case is decisive. Since n<p^2 and

```
n=p+r,
```

there is only one quotient digit. The claimed recursion would reduce a length-M shifted Newton value to an outer index determined by

```
q-A-k or q-A-k+1.
```

For admissible k near the upper boundary this index becomes zero or negative while the original window still contains a valid j. Therefore the asserted equality cannot hold without adding extra zero-extension conventions and boundary correction terms. Those conventions are not part of the definition of P.

## 4. Consequence for iteration

Even if one repairs the formula by inserting the missing endpoint correction terms, the iteration does not create a smaller characteristic-zero carrier.

At each digit step the mechanism is only:

```
b_{ap+r} = b_a b_r (mod p)
```

combined with Lucas selection of the residue class. Iterating gives a product of digit factors

```
b_r0 b_r1 ... b_rs
```

and a sequence of smaller-index congruences. It does not collapse the original Newton carrier to a new characteristic-zero object. The carrier remains the same Newton/Lagrange object with its support rewritten recursively.

This conclusion does not use recurrence dimension. It follows from the exact support calculation: Cartier extraction removes p-adic residue digits, but it does not remove the characteristic-zero interpolation data.

## Final assessment

The proposed identity is a correct formal Lucas shadow, but it is not an exact recursive factorization of the finite shifted Newton value. The missing ingredient is an endpoint correction depending on the p-digit borrow. Without that correction, r=0, r=1, r=p-1, and q=1 are not covered. With corrections, the recursion is a congruence decomposition of the existing carrier, not a new smaller carrier.
