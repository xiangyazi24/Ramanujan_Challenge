# P3.2 external-filter revisit covering: exact distance classification and scoped no-go

## Verdict

There is an exact structural reduction, and it is a no-go for a **distribution-free** sparse-height argument.

Put

\[
x=K+1.
\]

Then the cheap external factor is

\[
F_K(n)=(n-K-1)(n+K+2)=(n-x)(n+x+1).
\]

For a prime \(p\), writing \(n=qp+j\), \(0\le j<p\),

\[
p\mid F_K(n)
\iff x\equiv j\pmod p\quad\hbox{or}\quad x\equiv p-1-j\pmod p.
\tag{0.1}
\]

Thus the two “revisit lattices” are not a new carrier: they are exactly the two factors of the already banked two-sided affine carrier, with the affine label specialized to \(x=K+1\).  This matches the committed `q32_folded_boundary_carrier_audit.py`, whose carrier is

\[
(n-s)(n+s+1).
\]

So a sparse set of heights is literally a sparse set of labels in that same affine family.

The exact conclusions are:

1. the forward distances from \(h=\lceil n/3\rceil\) to the two revisit lattices admit a complete \(q\bmod 3\) formula below;
2. for \(q=3\), \(n=3p+s\), the direct/forward distance in the variable \(x=K+1\) is exactly
   \[
   \boxed{\left\lfloor\frac{2s}{3}\right\rfloor};
   \]
3. if \(T_n\) is any residual set of surviving target primes \(p>\sqrt n\), and \(\tau_n\) is the minimum number of admissible heights needed to hit one revisit for every \(p\in T_n\), then
   \[
   \boxed{\left\lceil\frac{|T_n|}{3}\right\rceil\le \tau_n\le |T_n|};
   \tag{0.2}
   \]
4. consequently
   \[
   \boxed{\tau_n=o(n/\log n)
   \iff |T_n|=o(n/\log n)
   \iff \log\prod_{p\in T_n}p=o(n)}.
   \tag{0.3}
   \]

Hence a proved sparse revisit set would already prove the desired residual affine target-radical estimate.  Conversely, the target-radical estimate gives a sparse **target-aware** revisit set by choosing one admissible revisit per target.  It does not produce a new target-oblivious deterministic formula for the heights.

So the correct scoped verdict is:

> **The external-filter revisit problem is asymptotically equivalent, up to an absolute factor 3 in covering number, to the original large-prime affine target radical.  The \(q\bmod3\) geometry locates the revisits exactly but does not compress the target set.**

It remains logically possible that some new Apéry-specific theorem constructs an explicit target-oblivious \(W_n\) and proves that every target lands in it.  But such a theorem is already strong enough to settle the residual radical, rather than being a free consequence of the long-window geometry.

## 2. Revisit congruence = affine divisibility

Let

\[
n=qp+j,\qquad 0\le j<p,
\]

and put

\[
s=\min(j,p-1-j).
\]

With \(x=K+1\),

\[
F_K(n)=(n-x)(n+x+1).
\]

Modulo \(p\), \(n\equiv j\), hence

\[
n-x\equiv0\pmod p \iff x\equiv j\pmod p,
\]

while

\[
n+x+1\equiv0\pmod p
\iff x\equiv -j-1\equiv p-1-j\pmod p.
\]

Since \(p\) is prime, this proves (0.1).

It is useful to record the identification in one line:

```text
x = K+1
revisit at height K
    <=> x == j or p-1-j (mod p)
    <=> p | (n-x)(n+x+1)
    <=> p | F_K(n).
```

Therefore, if a filtered residual can retain a target prime only after a revisit, then every residual-based cover is in particular a cover by the affine factors \(F_K(n)\).  Any further normalization of the residual can only reduce its prime support, so the no-go below still applies.

## 3. Exact \(q\bmod3\) distance theorem

We classify **forward distance in the variable \(x=K+1\)**.  This convention is important for the off-by-one at the Padé height itself.

Write

\[
q=3a+r,\qquad r\in\{0,1,2\}.
\]

Then

\[
h=\left\lceil\frac n3\right\rceil
=ap+c_r,
\qquad
c_r:=\left\lceil\frac{rp+j}{3}\right\rceil.
\tag{3.1}
\]

The two revisit lattices in the \(x\)-variable are

\[
\mathcal L_+=j+p\mathbf Z,
\qquad
\mathcal L_-=p-1-j+p\mathbf Z.
\tag{3.2}
\]

Consider the representatives

\[
x_+^{(0)}=ap+j,
\qquad
x_-^{(0)}=(a+1)p-1-j.
\]

Their signed offsets from \(h\) are

\[
\begin{aligned}
e_+
&=j-c_r
 =\left\lfloor\frac{2j-rp}{3}\right\rfloor,\\
e_-
&=p-1-j-c_r
 =\left\lfloor\frac{(3-r)p-3-4j}{3}\right\rfloor.
\end{aligned}
\tag{3.3}
\]

Let

\[
\delta_\pm=\min\{d\ge0:h+d\in\mathcal L_\pm\}.
\]

Because the displayed representatives differ from the next ones by exactly \(p\),

\[
\boxed{
\delta_\pm=
\begin{cases}
e_\pm,&e_\pm\ge0,\\
e_\pm+p,&e_\pm<0.
\end{cases}}
\tag{3.4}
\]

(The endpoint \(e_-=-p\) can occur; then the second line correctly gives \(\delta_-=0\).)

This already is a complete exact classification.  Expanding the wrap conditions gives the following table.

### 3.1 Explicit forward distances

For \(q\equiv0\pmod3\),

\[
\boxed{\delta_+=\left\lfloor\frac{2j}{3}\right\rfloor},
\tag{3.5}
\]

and

\[
\boxed{
\delta_-=
\begin{cases}
\left\lfloor\dfrac{3p-3-4j}{3}\right\rfloor,
   &4j\le3p-3,\\[1ex]
\left\lfloor\dfrac{6p-3-4j}{3}\right\rfloor,
   &4j>3p-3.
\end{cases}}
\tag{3.6}
\]

For \(q\equiv1\pmod3\),

\[
\boxed{
\delta_+=
\begin{cases}
\left\lfloor\dfrac{2j-p}{3}\right\rfloor,
   &2j\ge p,\\[1ex]
\left\lfloor\dfrac{2j+2p}{3}\right\rfloor,
   &2j<p,
\end{cases}}
\tag{3.7}
\]

and

\[
\boxed{
\delta_-=
\begin{cases}
\left\lfloor\dfrac{2p-3-4j}{3}\right\rfloor,
   &4j\le2p-3,\\[1ex]
\left\lfloor\dfrac{5p-3-4j}{3}\right\rfloor,
   &4j>2p-3.
\end{cases}}
\tag{3.8}
\]

For \(q\equiv2\pmod3\), the direct representative always lies below \(h\), so it always wraps once:

\[
\boxed{\delta_+=\left\lfloor\frac{p+2j}{3}\right\rfloor},
\tag{3.9}
\]

while

\[
\boxed{
\delta_-=
\begin{cases}
\left\lfloor\dfrac{p-3-4j}{3}\right\rfloor,
   &4j\le p-3,\\[1ex]
\left\lfloor\dfrac{4p-3-4j}{3}\right\rfloor,
   &4j>p-3.
\end{cases}}
\tag{3.10}
\]

No asymptotics enter these formulas.

### 3.2 Equivalent affine-representative table

The same classification can be read more geometrically.  The first revisit point \(x\ge h\) is:

| \(q\bmod3\) | direct lattice \(x\equiv j\) | reflected lattice \(x\equiv p-1-j\) |
|---|---|---|
| 0 | \(ap+j\) | \((a+1)p-1-j\) if \(4j\le3p-3\), otherwise \((a+2)p-1-j\) |
| 1 | \(ap+j\) if \(2j\ge p\), otherwise \((a+1)p+j\) | \((a+1)p-1-j\) if \(4j\le2p-3\), otherwise \((a+2)p-1-j\) |
| 2 | \((a+1)p+j\) | \((a+1)p-1-j\) if \(4j\le p-3\), otherwise \((a+2)p-1-j\) |

In each cell, substituting \(j=n-qp\) makes the revisit point an affine function of \(p\).  Thus fixing \(q\bmod3\) does **not** make the height independent of \(p\).

There is also a useful multiplier formulation.  Every direct revisit has

\[
x=n-tp,
\qquad n-x=tp,
\tag{3.11}
\]

for the corresponding integer \(t\), while every reflected revisit has

\[
x=tp-n-1,
\qquad n+x+1=tp.
\tag{3.12}
\]

So the revisit condition does nothing mysterious: one of the two affine factors becomes an explicit small-in-quotient multiple of the target prime.

## 4. Height variable versus revisit variable: the exact off-by-one

The Padé height is \(K=x-1\), whereas the distance formulas above are from \(h\) to the **revisit point \(x\)**.

If \(\delta_\pm>0\), then the corresponding height satisfies

\[
K-h=\delta_\pm-1.
\tag{4.1}
\]

If \(\delta_\pm=0\), the lattice point \(x=h\) corresponds to \(K=h-1\), which is one unit below a height window beginning at \(K=h\).  The next point on the same lattice is \(x=h+p\), corresponding to

\[
K-h=p-1.
\tag{4.2}
\]

Thus, for an admissible contiguous height interval

\[
h\le K\le H,
\]

the exact branchwise test is obtained by defining

\[
\delta_\pm^\sharp=
\begin{cases}
\delta_\pm,&\delta_\pm\ge1,\\
p,&\delta_\pm=0,
\end{cases}
\]

and checking

\[
\boxed{\delta_\pm^\sharp\le H+1-h.}
\tag{4.3}
\]

This is the exact way to plug the distance theorem into whatever precise Padé-height interval is banked locally.

## 5. Explicit audit of \(q=3\), \(n=3p+s\)

Now take the direct folded branch

\[
n=3p+s,
\qquad 0\le s\le\frac{p-1}{2}.
\]

Here \(a=1,r=0,j=s\), and

\[
h=p+\left\lceil\frac s3\right\rceil.
\]

### 5.1 Forward/direct revisit

The first direct revisit point is

\[
x_+=p+s.
\]

Therefore

\[
\begin{aligned}
\delta_+
&=x_+-h\\
&=s-\left\lceil\frac s3\right\rceil\\
&=\boxed{\left\lfloor\frac{2s}{3}\right\rfloor}.
\end{aligned}
\tag{5.1}
\]

This confirms the claimed value exactly.

In terms of \(n\) and \(p\),

\[
x_+=p+s=n-2p,
\tag{5.2}
\]

so the corresponding height is

\[
\boxed{K_+=p+s-1=n-2p-1}.
\tag{5.3}
\]

At this height,

\[
n-K_+-1=n-x_+=2p.
\tag{5.4}
\]

Thus the target prime is carried by the first factor for the completely transparent reason that the first factor is exactly \(2p\).

For \(s\ge2\), \(\delta_+\ge1\), so \(K_+\ge h\).  Moreover

\[
2K_+=2p+2s-2\le3p+s-2=n-2
\]

because \(s\le p\). Hence

\[
K_+\le\left\lfloor\frac{n-2}{2}\right\rfloor.
\tag{5.5}
\]

Therefore, if the admissible bulk interval is the natural
\([h,\lfloor(n-2)/2\rfloor]\), every direct \(q=3\) target with \(s\ge2\) has its forward revisit inside that interval.

The endpoints are worth auditing rather than hiding:

- \(s=0\) gives \(b_0=1\), hence no target prime at all;
- \(s=1\) gives \(b_1=5\), so the only target is \(p=5\).  In the corresponding case \(n=16\), the forward point has \(\delta_+=0\), but the reflected revisit below supplies an admissible height.

Thus the off-by-one at \(s=0,1\) does not create an asymptotic missing family.

### 5.2 Reflected revisit

Since \(s\le(p-1)/2\), the reflected representative does not wrap in the \(q\equiv0\) table.  It is

\[
x_-=2p-1-s,
\]

with

\[
\boxed{
\delta_-=p-1-s-\left\lceil\frac s3\right\rceil
=\left\lfloor\frac{3p-3-4s}{3}\right\rfloor.}
\tag{5.6}
\]

Equivalently,

\[
x_-=5p-n-1,
\tag{5.7}
\]

and at the corresponding height \(K_-=x_--1\),

\[
n+K_-+2=n+x_-+1=5p.
\tag{5.8}
\]

So the two \(q=3\) revisits are exactly the affine equations

\[
n-x=2p,
\qquad
n+x+1=5p.
\]

### 5.3 Why this does not compress the \(q=3\) targets

Within the direct \(q=3\) branch,

\[
p\longmapsto x_+=n-2p
\]

is injective.  Consequently, using only the forward revisit requires one distinct height for every distinct target prime in that branch.  Allowing the reflected revisit can create some collisions between different primes, but Section 6 shows that even with both branches a single height can absorb at most three primes \(>\sqrt n\).

Thus the exact \(\lfloor2s/3\rfloor\) distance is useful for proving **existence and location** of a revisit, but it does not give a quotient-cell compression.

## 6. The exact covering theorem

Let \(\mathcal A_n\subseteq\{0,1,\dots,n-2\}\) be the actual admissible Padé heights for which the nonzero external factor \(F_K(n)\) is available.  Let \(T_n\) be the residual surviving target primes under consideration, meaning:

- \(p\) is prime;
- \(p>\sqrt n\);
- with \(s_p=\min(n\bmod p,p-1-(n\bmod p))\), one has \(p\mid b_{s_p}\);
- the prime has survived the previously banked filters;
- at least one allowed height \(K\in\mathcal A_n\) satisfies the revisit condition.

The last clause is what “surviving” must mean for a revisit covering problem; if a target has no admissible revisit, then no height set can cover it and the proposed route fails even earlier.

Put

\[
R_n^{\rm res}=\prod_{p\in T_n}p,
\qquad t_n=|T_n|.
\tag{6.1}
\]

For \(W\subseteq\mathcal A_n\), define

\[
P_W(n)=\prod_{K\in W}F_K(n).
\tag{6.2}
\]

### Theorem 6.1 — exact radical/cover equivalence

The following are equivalent:

1. for every \(p\in T_n\), some \(K\in W\) hits one of the two revisit residues;
2. for every \(p\in T_n\), some \(K\in W\) has \(p\mid F_K(n)\);
3. \(R_n^{\rm res}\mid P_W(n)\).

#### Proof

The equivalence of 1 and 2 is (0.1).  Since \(R_n^{\rm res}\) is squarefree, 2 is equivalent to divisibility of the product (6.2) by every prime occurring in (6.1), which is exactly 3. \(\square\)

This is the promised exact equivalence to the affine target radical.

## 7. One height carries at most three primes \(>\sqrt n\)

This is the key structural bound.

For \(0\le K\le n-2\), write

\[
A_K=n-K-1,
\qquad
B_K=n+K+2.
\]

Then

\[
1\le A_K\le n-1,
\qquad
n+2\le B_K\le2n.
\tag{7.1}
\]

### Lemma 7.1

For \(n>4\), the integer \(F_K(n)=A_KB_K\) has at most three distinct prime divisors greater than \(\sqrt n\).

#### Proof

The factor \(A_K<n\) cannot contain two distinct primes both greater than \(\sqrt n\), since their product would exceed \(n>A_K\).  So \(A_K\) contributes at most one.

The factor \(B_K\le2n\) cannot contain three distinct primes greater than \(\sqrt n\), since their product would exceed

\[
n^{3/2}>2n
\]

for \(n>4\).  So \(B_K\) contributes at most two.

Hence \(F_K(n)\) contributes at most \(1+2=3\) such primes. \(\square\)

The constant 3 cannot be reduced for this bare affine family: for example the exact identity

\[
F_{41}(100)=58\cdot143=(2\cdot29)(11\cdot13)
\]

contains the three distinct primes \(11,13,29>\sqrt{100}\).  This example is only to show sharpness of the local constant; none of the asymptotic conclusions relies on finite computation.

## 8. Minimum-cover size is equivalent to target count

Let

\[
\tau_n=\min\{|W|:W\subseteq\mathcal A_n\text{ covers }T_n\}.
\]

Because each height covers at most three members of \(T_n\), Lemma 7.1 gives

\[
\tau_n\ge\left\lceil\frac{t_n}{3}\right\rceil.
\tag{8.1}
\]

Because every member of \(T_n\) is, by definition, a surviving prime with at least one admissible revisit, selecting one such height separately for each prime gives

\[
\tau_n\le t_n.
\tag{8.2}
\]

Together,

\[
\boxed{
\left\lceil\frac{t_n}{3}\right\rceil
\le\tau_n\le t_n.}
\tag{8.3}
\]

Now every \(p\in T_n\) satisfies \(\sqrt n<p\le n\), so

\[
\frac12\log n<\log p\le\log n.
\]

Summing gives

\[
\frac12 t_n\log n
<\log R_n^{\rm res}
\le t_n\log n.
\tag{8.4}
\]

Therefore

\[
\boxed{
\tau_n=o(n/\log n)
\iff t_n=o(n/\log n)
\iff \log R_n^{\rm res}=o(n).}
\tag{8.5}
\]

This is stronger than merely saying “a small cover would be useful”: the sparse-cover statement and the residual target-radical statement have exactly the same asymptotic content, up to absolute constants.

## 9. Cheap height bound: a sparse cover would immediately solve the residual radical

For every valid \(K\in\{0,\dots,n-2\}\),

\[
0<F_K(n)<2n^2.
\tag{9.1}
\]

Hence for any \(W\),

\[
\log|P_W(n)|
\le |W|(2\log n+\log2).
\tag{9.2}
\]

If one could construct a deterministic admissible set \(W_n\) with

\[
|W_n|=o(n/\log n)
\]

and prove that it covers every surviving target, Theorem 6.1 and (9.2) would give immediately

\[
\log R_n^{\rm res}
\le\log|P_{W_n}(n)|
=o(n).
\tag{9.3}
\]

So such a theorem is already the desired residual P3.2 estimate in another form.

Conversely, if \(\log R_n^{\rm res}=o(n)\), then (8.4) gives \(t_n=o(n/\log n)\), and choosing one admissible revisit for each target produces a set of that size.  But this converse construction is explicitly **target-aware**: it has used the target set itself.  It does not furnish an a priori height pattern extracted merely from \(q\bmod3\).

## 10. Distribution-free no-go

There are two logically different meanings of “deterministic \(W_n\) without already assuming the target distribution.”

### 10.1 Purely geometric / target-oblivious guarantee

Let

\[
C_n(\mathcal A_n)
=\{p:\sqrt n<p\le n,\ \exists K\in\mathcal A_n\text{ with }p\mid F_K(n)\}
\]

be the large-prime candidate set visible to the admissible affine factors, with no Apéry condition imposed.

A height set guaranteed by geometry alone to work regardless of which candidates happen to be targets must cover all of \(C_n(\mathcal A_n)\).  Lemma 7.1 then forces

\[
|W_n|\ge\frac13|C_n(\mathcal A_n)|.
\tag{10.1}
\]

For the unrestricted nonzero valid range \(\mathcal A_n=\{0,\dots,n-2\}\), every prime \(p\le n\) has a revisit:

- if \(j=n\bmod p\ge1\), take \(K=j-1\);
- if \(j=0\), take the reflected residue \(x=p-1\), i.e. \(K=p-2\).

Thus

\[
C_n=\{p:\sqrt n<p\le n\},
\]

and the prime number theorem yields

\[
|W_n|
\ge\frac13\bigl(\pi(n)-\pi(\sqrt n)\bigr)
=\left(\frac13+o(1)\right)\frac n{\log n}.
\tag{10.2}
\]

Hence **no purely geometric universal cover can have \(o(n/\log n)\) heights**.  The order \(n/\log n\) is also the right order from above, since choosing one revisit per prime gives at most \(\pi(n)-\pi(\sqrt n)\) heights.

For a narrower banked admissible interval, the exact lower bound is (10.1); one should insert the actual local interval into the distance test (4.3) to identify \(C_n(\mathcal A_n)\).  No claim about its density is needed for the target-radical equivalence (8.5).

### 10.2 Apéry-aware deterministic guarantee

One may instead seek an explicit rule \(n\mapsto W_n\), not obtained by enumerating the targets, and prove from the Apéry recurrence/congruences that every target prime lands in one of those heights.

This is **not ruled out**.  But the proof would establish

\[
R_n^{\rm res}\mid\prod_{K\in W_n}F_K(n),
\]

and if \(|W_n|=o(n/\log n)\), Section 9 immediately gives \(\log R_n^{\rm res}=o(n)\).  Therefore such a theorem is a genuine new target-distribution theorem of exactly the required strength.  It cannot be obtained merely from the banked statement \(s\le K\), because that statement contains no assertion that the external label \(K+1\) revisits either residue.

## 11. Why the \(q\bmod3\) classification does not itself supply \(W_n\)

The distance table has real content: it tells exactly how far the next direct and reflected residues lie from the canonical height \(h\).  What it does **not** do is make those distances depend only on \(q\bmod3\).

They still depend on \(j\) and \(p\).  Equivalently, the actual revisit points are affine functions of \(p\) inside each fixed quotient/wrap cell.  The \(q=3\) identity

\[
x_+=n-2p
\]

is the cleanest possible demonstration: fixing \(q=3\) leaves a different forward height for every different prime \(p\).

Thus a proposal such as “take one or finitely many heights per quotient \(q\)” cannot cover the whole candidate family.  It can cover the actual targets only if one proves an additional theorem forcing those targets onto the selected affine values.  By Sections 8–9, that additional theorem is already equivalent in strength to the residual target-radical bound.

## 12. Final theorem and project-level conclusion

### Theorem — residual external-filter revisit no-go

Assume the banked Padé setup of Q2004.  Let \(T_n\) be the surviving target primes \(p>\sqrt n\) for which at least one admissible revisit exists, and let \(R_n^{\rm res}=\prod_{p\in T_n}p\).  Then:

1. for each \(p\), the two revisit conditions are exactly
   \[
   p\mid(n-K-1)(n+K+2);
   \]
2. the forward distances from \(h=\lceil n/3\rceil\) to the two revisit lattices are given exactly by (3.3)–(3.10), classified by \(q\bmod3\);
3. in the audited case \(q=3,n=3p+s\), the direct forward distance in the revisit variable \(x=K+1\) is exactly
   \[
   \lfloor2s/3\rfloor,
   \]
   with direct revisit \(x=n-2p\) and factor \(n-x=2p\);
4. if \(\tau_n\) is the minimum number of admissible heights covering all residual targets, then
   \[
   \lceil|T_n|/3\rceil\le\tau_n\le|T_n|;
   \]
5. hence
   \[
   \tau_n=o(n/\log n)
   \iff
   \log R_n^{\rm res}=o(n).
   \]

### Consequence

The “external-filter revisit” route should **not** be banked as an independent compression theorem.  Its exact status is:

- the \(q\bmod3\) analysis successfully solves the **local geometry / location** problem;
- the remaining sparse-height covering problem is the **same asymptotic difficulty as the residual affine target radical**;
- a target-oblivious geometric cover of all large-prime candidates is impossible at \(o(n/\log n)\) scale;
- an Apéry-aware sparse cover remains a legitimate possible breakthrough, but proving its coverage is already a solution of the missing target-distribution problem, not a consequence of the long-window condition \(s\le K\).

That is the sharp scoped no-go; it does not overclaim that no special Apéry recurrence identity can ever produce such a sparse set.
