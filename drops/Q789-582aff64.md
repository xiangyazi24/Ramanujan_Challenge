# Q789: paired affine-diagonal carrier attack on LGTQ-2

## 1. Exact one-variable formulation

For fixed q and h=qd, write

```
p=(n-u)/q,
ell=(n-u-h)/q=p-d.
```

The LGTQ-2 packet count is over small-index residues u satisfying:

```
p prime,
ell prime,
p | b_u,
ell | b_{u+h},
ell ∤ b_u,
p ∤ b_{u+h}.
```

Equivalently define the two affine streams

```
P_q(u)=(n-u)/q,
L_{q,h}(u)=(n-u-h)/q.
```

A fixed-gap carrier would need an integer C(n,q,h) such that every fully transverse u contributes a prime divisor p or p ell.

The difficulty is that u is the variable, while p and ell are affine functions of u.

## 2. Naive product/resultant carriers saturate

Consider the obvious construction

```
C_1=prod_u gcd(b_u,P_q(u)),
C_2=prod_u gcd(b_{u+h},L_{q,h}(u)).
```

This does contain all target primes, but the height is essentially the height of the product of all target quotients.

The number of u-values is about n/q. The Apéry values satisfy exponential growth:

```
log |b_u| = Theta(u).
```

Therefore

```
log C_1,C_2 >= sum_{u<=n/q} Theta(u)
             = Theta(n^2).
```

This is much larger than the required o(n) height.

Taking resultants does not immediately help. A resultant of

```
X-P_q(u),
F_u(X)=b_u
```

has degree growing with the number of sampled u and coefficient height comparable to the eliminated product. The affine dependence reduces variables but does not reduce arithmetic complexity.

## 3. Continuant carriers

The Q8740 continuant identity gives relations of the form

```
C_h(u) * b_{u+h} - D_h(u) * b_u = N_h(u).
```

Reducing modulo a transverse pair gives

```
N_h(u) == C_h(u)b_{u+h} - D_h(u)b_u mod p,ell.
```

Because

```
p|b_u,
ell|b_{u+h},
```

one obtains

```
p|N_h(u),
ell|N_h(u)
```

only if the coefficients are integral in the relevant characteristic and no denominator introduces a unit obstruction.

The obstruction is exactly transversality: the quotient terms

```
b_u/p,
b_{u+h}/ell
```

cannot be discarded. The normalized relation becomes a unit equation, not a vanishing relation.

Hence the obvious continuant carrier usually gives only

```
N_h(u) ≡ 0 mod p ell
```

in aligned cases. For fully transverse pairs the same expression is generally a unit after normalization.

## 4. Scoped saturation statement

For the construction class

```
finite products of gcd streams,
resultants of affine Apéry streams,
fixed-order continuants,
```

there is no subexponential carrier without additional cancellation.

Reason:

1. Products accumulate Theta(n) independent exponential-size factors.
2. Resultants encode the same elimination product with comparable Mahler measure.
3. Fixed-order recurrence identities have determinant one and cannot remove independent transverse units.

Thus the proposed class saturates at either

```
height Omega(n)
```

or loses the divisibility information.

## 5. Remaining surviving construction

A viable carrier must use a genuinely global cancellation mechanism, not local recurrence elimination. The surviving possibilities are:

### (a) Characteristic-zero diagonal aggregate

Use the fixed-q diagonal aggregate from `franel_shell_content.tex` to construct a single integer sum over u:

```
S_{q,h}(n)=sum_u w(u,n) N_h(u).
```

The weights must force cancellation of the exponential Apéry scale while preserving divisibility.

### (b) Affine sieve with small conductor

Instead of a carrier integer, prove that the set of u satisfying

```
P_q(u)|b_u,
L_{q,h}(u)|b_{u+h}
```

has cancellation through a character sum with conductor polylogarithmic in n.

### (c) p-adic jet carrier

Use the normalized quotients

```
b_u/p,
b_{u+h}/ell
```

as variables and seek a relation among first jets. Any such relation must be proved; eliminating them is invalid.

## Conclusion

The paired affine-diagonal construction does not yield an o(n)-height carrier through naive products, resultants, or fixed-order continuants. The exact obstruction is not the affine relation p-ell=d; it is the independent transverse first-jet data. A successful LGTQ-2 carrier must exploit a new global cancellation identity or a genuinely small-conductor character estimate.
