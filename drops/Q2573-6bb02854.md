# 1. Exact fixed-`q` form of the target

Fix `q>=1`, and write

```text
P_q(n) = { primes p : n/(q+1) < p <= n/q and p | b_n }.
```

For `p` in this interval there is a unique decomposition

```text
n = q p + r,       0 <= r < p,
```

namely

```text
r = n-q p.
```

Since `q` is fixed, the primes dividing the fixed integer `b_q` eventually lie below `n/(q+1)`. Hence, for all sufficiently large `n`, every `p` in the interval satisfies `p` does not divide `b_q`. Apéry-Lucas then gives

```text
b_n = b_(q p+r) = b_q b_r  (mod p),
```

and therefore

```text
p | b_n  <=>  p | b_r.                         (1.1)
```

Equivalently, apart from the finite set of primes dividing `b_q`,

```text
P_q(n)
  <->
{ r :
    0 <= r < n/(q+1),
    r = n (mod q),
    p_r := (n-r)/q is prime,
    p_r | b_r }.
                                                        (1.2)
```

Formula (1.2) is the exact moving-diagonal problem. Merely rewriting the goal as (1.2) is not a proof; the point of the next sections is to audit proposed mechanisms against this exact form.

# 2. Reflection produces no second independent equation

For `0<=r<p`, put

```text
s = p-1-r.
```

Let

```text
D(m,k) = binom(m,k) binom(m+k,k).
```

For `0<=k<p`, with the convention that ordinary binomial coefficients vanish outside their natural range,

```text
binom(p-1-r,k)
  = (-1)^k binom(r+k,k)                         (mod p),

binom(p-1-r+k,k)
  = (-1)^k binom(r,k)                           (mod p).
```

Thus

```text
D(p-1-r,k) = D(r,k)                             (mod p),
```

and summing squares gives the exact reflection congruence

```text
boxed:  b_(p-1-r) = b_r                        (mod p).       (2.1)
```

Consequently every target prime gives the pair

```text
p | b_r,
 p | b_s,
 r+s+1=p.
```

For fixed `q`, eliminating `p` gives the exact affine line

```text
(q+1)r + q s = n-q.                             (2.2)
```

This may look like a two-coordinate gcd problem, but (2.1) shows that it is not: the divisibilities of `b_r` and `b_s` are the **same congruence**. Any Subspace-Theorem or resultant argument that counts them as two independent equations is double-counting a universal reflection identity.

This is an exact counterexample to the tempting mechanism

```text
p | gcd(b_r,b_s) with a linear relation between r and s
     => two independent arithmetic constraints.
```

At the relevant modulus `p=r+s+1`, there is only one constraint.

# 3. Modular `q`-expansion/Frobenius factorization: an exact countermodel

The Apéry-Lucas identity can be packaged as a Frobenius product. If

```text
B(X)   = sum_(n>=0) b_n X^n,
B_p(X) = sum_(0<=r<p) b_r X^r,
```

then formally modulo `p`,

```text
B(X) = B_p(X) B(X^p).                           (3.1)
```

Coefficient extraction at `n=qp+r` yields exactly `b_n=b_qb_r (mod p)`.

The following lemma shows why (3.1), even viewed as a modular `q`-expansion identity, cannot itself force a pointwise saving.

## Lemma 3.1 — arbitrary digit-block countermodel

Let `p` be prime and let

```text
C(X)=c_0+c_1X+...+c_(p-1)X^(p-1) in F_p[X],
 c_0=1,
```

be completely arbitrary. Define the formal series

```text
F_C(X) = product_(j>=0) C(X^(p^j)) in F_p[[X]].          (3.2)
```

Then

```text
F_C(X)=C(X)F_C(X^p),                                    (3.3)
```

and if

```text
m=m_0+m_1p+...+m_tp^t
```

is the base-`p` expansion of `m`, then

```text
[X^m]F_C(X)=product_i c_(m_i).                           (3.4)
```

In particular, for fixed `q<p` and `0<=r<p`,

```text
[X^(qp+r)]F_C(X)=c_q c_r.                               (3.5)
```

### Proof

In the product (3.2), choosing the monomial `c_(m_j)X^(m_jp^j)` from the `j`th factor is the unique way to obtain `X^m`; this proves (3.4). Separating the `j=0` factor proves (3.3). ∎

Now choose `c_q=1`. The set

```text
{r : [X^(qp+r)]F_C(X)=0}
```

is exactly the arbitrary set

```text
{r : c_r=0}.
```

It may have any cardinality from `0` to `p-1` while (3.3) and the exact Lucas digit law remain valid.

## Consequence

No proof that uses only

```text
- the Frobenius product F(X)=C(X)F(X^p),
- coefficient extraction,
- a fixed number of derivatives or U_p-type rewrites of that identity,
```

can establish the desired little-oh. A successful modular argument must use an additional Apéry-specific relation that severely constrains the first block `B_p(X)`—not merely its existence as a modular `q`-expansion or its Lucas factorization.

This does **not** rule out using the full Apéry modular parametrization together with a new theorem about its Hasse/Cartier coefficient array. It rules out the frequently proposed shortcut “the modular `q`-expansion plus Frobenius already makes the moving coefficient sparse.”

# 4. The one-integer carrier audit

## 4.1 The tautological carrier has exactly linear height

The integer `b_n` itself is a carrier:

```text
product_(p in P_q(n)) p  divides  rad(b_n).
```

The Apéry recurrence is

```text
(m+1)^3 b_(m+1)
 = (34m^3+51m^2+27m+5)b_m - m^3b_(m-1).        (4.1)
```

Since all `b_m` are positive and

```text
34m^3+51m^2+27m+5 < 34(m+1)^3,
```

(4.1) gives

```text
b_(m+1) < 34 b_m,
```

hence

```text
b_n < 34^n.                                    (4.2)
```

Conversely, the `k=n` summand gives

```text
b_n >= binom(2n,n)^2
    >= 16^n/(2n+1)^2.                           (4.3)
```

Therefore

```text
n log 16 - O(log n) <= log b_n <= n log 34.     (4.4)
```

Thus the tautological one-integer carrier has height `Theta(n)` and gives only the known `O(n/log n)` bound. The strict little-oh requires cancellation of the full linear term in its logarithmic height, not merely a better constant.

## 4.2 Exact Casoratian: the companion gives no local cancellation

Let `a_n` be the standard companion solution of the same recurrence, normalized by

```text
a_0=0,
 a_1=6.
```

For any two solutions of (4.1), the weighted Casoratian is constant. Direct substitution gives

```text
W_m := m^3(a_m b_(m-1)-a_(m-1)b_m)=6           (m>=1).      (4.5)
```

Indeed, the recurrence at index `m` gives `W_(m+1)=W_m`, and `W_1=6`.

Now let `p>=5`, `1<=r<p`, and suppose `p|b_r`. Every denominator introduced in computing `a_0,...,a_r` from the recurrence has prime factors at most `r`, so `a_r` is `p`-integral. Reducing (4.5) modulo `p` gives

```text
r^3 a_r b_(r-1)=6                              (mod p).      (4.6)
```

Since `p>r` and `p>=5`, every factor on the right and `r` is a unit. Therefore

```text
boxed:
 p | b_r  and p>r
   => p does not divide a_r
      and p does not divide b_(r-1).             (4.7)
```

In valuation language,

```text
v_p(a_r)=0,
 v_p(a_r/b_r)=-v_p(b_r).                         (4.8)
```

So a target prime survives with its **full** exponent in the reduced `p`-local denominator of `a_r/b_r`. There is no companion gcd cancellation to exploit.

## Consequence for a proposed denominator carrier

A carrier built from the reduced local denominators of the Apéry approximants does not compress the target radical: it contains precisely the primes one is trying to bound. Proving that such a denominator has logarithm `o(n)` is therefore equivalent to proving the desired radical estimate, not an independent route to it.

This is stronger than saying the carrier is currently unknown. It is an exact obstruction to the specific mechanism “the companion numerator cancels most large target primes from the denominator.” At the low digit `r`, it cancels none of them.

# 5. S-unit/Subspace-Theorem audit

There are two separate obstructions.

## 5.1 The reflected two-term setup is degenerate

The most immediate representation is

```text
p | b_r,
 p | b_s,
 (q+1)r+qs=n-q,
 p=r+s+1.
```

But Section 2 proves

```text
b_s=b_r (mod p)
```

identically on `r+s=p-1`. Hence a putative two-term S-unit equation obtained from `b_r` and `b_s` lies on a universal degenerate component. It does not satisfy the nondegeneracy condition that makes the Subspace Theorem useful.

## 5.2 No fixed-dimensional affine-exponent S-unit representation exists

A standard fixed-rank S-unit strategy would require an exact expression of the shape

```text
b_n = sum_(i=1)^M P_i(n) alpha_i^n,              (5.1)
```

or, equivalently, a fixed finite sum of S-unit monomials whose exponents are affine functions of `n`. Such a sequence is an exponential polynomial and satisfies a constant-coefficient recurrence.

The Apéry recurrence rules this out exactly.

Let

```text
lambda = 17+12sqrt(2),
 lambda^(-1)=17-12sqrt(2).
```

The limiting characteristic equation of (4.1) is

```text
x^2-34x+1=0.
```

Positivity selects the dominant root `lambda`. Write the ratio in the standard Poincare expansion

```text
b_(n+1)/b_n = lambda(1+c/n+O(1/n^2)).            (5.2)
```

Dividing (4.1) by `n^3b_n` and comparing the coefficients of `1/n` yields

```text
lambda(c+3)=51+c lambda^(-1).
```

Since

```text
lambda-lambda^(-1)=24sqrt(2),
 51-3lambda=-36sqrt(2),
```

we obtain

```text
c=-3/2.                                          (5.3)
```

Thus the dominant asymptotic has the form

```text
b_n=C lambda^n n^(-3/2)(1+O(1/n)),              (5.4)
```

with `C>0`.

On the other hand, if (5.1) held, then after grouping equal dominant roots, positivity and the existence of the ratio limit would give

```text
b_n=C' rho^n n^d(1+O(1/n))
```

for an integer `d>=0`, the degree of a dominant polynomial `P_i`. The exponent `d=-3/2` from (5.4) is impossible.

Therefore:

```text
boxed:
The Apéry sequence has no fixed finite affine-exponent
S-unit / exponential-polynomial representation.                 (5.5)
```

## 5.3 The actual hypergeometric sum has growing dimension and moving `S`

The exact summands are

```text
T_(n,k)=binom(n,k)^2 binom(n+k,k)^2,
 b_n=sum_(k=0)^n T_(n,k),
```

with ratio

```text
T_(n,k+1)/T_(n,k)
 = ((n-k)(n+k+1)/(k+1)^2)^2.                    (5.6)
```

Treating these terms as S-units requires

```text
number of terms = n+1,
 S contains primes up to 2n.
```

Both the dimension and the rank of the multiplicative group grow with `n`. Classical fixed-data S-unit/Subspace-Theorem finiteness does not provide a bound uniform enough to imply `o(n/log n)` in this regime. Any successful use of that theory would need a new quantitative theorem whose dependence on both the number of terms and the moving set `S` is sublinear after summing over the fixed-`q` diagonal.

The conclusion is scoped: it rules out the standard fixed-rank representation and the direct growing hypergeometric representation. It does not assert that every conceivable nonlinear Diophantine encoding is impossible.

# 6. What remains after the audits

For all sufficiently large `n`, the fixed-`q` target is exactly

```text
r = n (mod q),
0 <= r < n/(q+1),
p=(n-r)/q prime,
p | b_r,                                          (6.1)
```

with the marked local state

```text
b_r=0,
 b_(r-1) is a unit,
 a_r is a unit                              (mod p).             (6.2)
```

The tested mechanisms fail for precise reasons:

```text
Lucas / Frobenius q-expansion:
    first block can be arbitrary without extra Apéry input.

Reflection / two-index gcd:
    the second zero is universally identical to the first.

Companion denominator:
    exact Casoratian forces zero cancellation at a target prime.

Fixed-rank S-unit equation:
    impossible because the Apéry exponent is -3/2.

Growing hypergeometric S-unit equation:
    dimension and prime support both grow linearly.
```

A genuine proof must therefore supply one of the following new objects.

1. A nonzero integer `C_(q,n)` such that
   
   ```text
   product_(p in P_q(n)) p divides C_(q,n),
   log |C_(q,n)|=o_q(n),
   ```
   
   where the divisibility is not tautologically inherited from `b_n` or from a product of the local reduced denominators.
2. A pointwise inverse theorem: if `|P_q(n)|>=epsilon n/log n`, then the marked transfer states (6.2), across many different residue characteristics, satisfy one fixed bounded-complexity algebraic relation; then rule out that relation from the Apéry recurrence.
3. A same-characteristic coefficient theorem for the specific Apéry Hasse/Cartier block that controls the moving coefficient `r=n-qp`, not merely its average over `r` or over `n`.

This is the exact remaining frontier. The present answer does not replace it by a density-one statement or a renamed conjecture.

# 7. Self-contained exact verifier

The following script uses only Python's standard library. It verifies:

- integrality of the Apéry recurrence;
- the exact Casoratian `W_m=6`;
- the implication `p|b_r`, `p>r` => `a_r,b_(r-1)` are `p`-units;
- reflection `b_(p-1-r)=b_r (mod p)`;
- the fixed-`q` Lucas reduction on a finite exact range;
- the arbitrary digit-block Frobenius countermodel;
- the elementary linear-height bounds;
- the algebraic calculation giving the exponent `-3/2`.

```python
#!/usr/bin/env python3
from fractions import Fraction
from math import comb


def P(n: int) -> int:
    return 34*n**3 + 51*n**2 + 27*n + 5


def apery(N: int) -> list[int]:
    assert N >= 1
    b = [1, 5]
    for n in range(1, N):
        num = P(n)*b[n] - n**3*b[n-1]
        den = (n+1)**3
        assert num % den == 0
        b.append(num // den)
    return b


def companion(N: int) -> list[Fraction]:
    assert N >= 1
    a = [Fraction(0), Fraction(6)]
    for n in range(1, N):
        a.append((P(n)*a[n] - n**3*a[n-1]) / (n+1)**3)
    return a


def primes_upto(N: int) -> list[int]:
    out = []
    for m in range(2, N+1):
        if all(m % d for d in range(2, int(m**0.5)+1)):
            out.append(m)
    return out


def mod_fraction(x: Fraction, p: int) -> int:
    assert x.denominator % p != 0
    return (x.numerator % p) * pow(x.denominator, -1, p) % p


def digit_coeff(c: list[int], n: int, p: int) -> int:
    out = 1
    while n:
        out = out * c[n % p] % p
        n //= p
    return out


N = 140
b = apery(N)
a = companion(N)

# Exact Casoratian and elementary height bounds.
for n in range(1, N+1):
    assert n**3 * (a[n]*b[n-1] - a[n-1]*b[n]) == 6
    assert b[n] < 34**n
    assert b[n] >= comb(2*n, n)**2
    assert comb(2*n, n) * (2*n+1) >= 4**n

# Reflection and local unit theorem.
for p in primes_upto(97):
    if p < 5:
        continue
    assert len(b) >= p
    for r in range(p):
        s = p-1-r
        assert (b[r] - b[s]) % p == 0
        if r >= 1 and b[r] % p == 0:
            assert b[r-1] % p != 0
            assert mod_fraction(a[r], p) != 0
            lhs = (pow(r, 3, p)
                   * mod_fraction(a[r], p)
                   * (b[r-1] % p)) % p
            assert lhs == 6 % p

# Finite exact check of the fixed-q Lucas reduction.
# The Lucas identity is an input theorem; this checks it numerically here.
for n in range(8, 121):
    for q in range(1, 6):
        for p in primes_upto(n):
            if not (n/(q+1) < p <= n/q):
                continue
            r = n-q*p
            assert 0 <= r < p
            assert (b[n] - b[q]*b[r]) % p == 0
            if b[q] % p != 0:
                assert (b[n] % p == 0) == (b[r] % p == 0)
                s = p-1-r
                assert (q+1)*r + q*s == n-q

# Arbitrary first-block zero set with the same Frobenius/Lucas law.
for p in [5, 7, 11]:
    # An arbitrary digit polynomial with c_0=1.
    c = [1] + [0 if (j*j+1) % 3 == 0 else (2*j+1) % p
               for j in range(1, p)]
    for q in range(1, p):
        for r in range(p):
            assert digit_coeff(c, q*p+r, p) == c[q]*c[r] % p

# Algebraic 1/n coefficient: c=-3/2.
# Represent x+y*sqrt(2) by the pair (x,y).
def add(u, v):
    return (u[0]+v[0], u[1]+v[1])

def scale(c, u):
    return (c*u[0], c*u[1])

lam = (Fraction(17), Fraction(12))
lam_inv = (Fraction(17), Fraction(-12))
left = scale(Fraction(-3, 2),
             add(lam, scale(-1, lam_inv)))
right = add((Fraction(51), Fraction(0)), scale(-3, lam))
assert left == right == (Fraction(0), Fraction(-36))

print("Q2573_EXACT_AUDIT=PASS")
```
