# Pair-preserving placements cannot desaturate a target

## Executive verdict

Let `Y_j = C_M(j)` and let the Newton evaluation at `-1` on consecutive nodes `a,...,a+m` be

```text
G(a,m) = sum_{i=0}^m (-1)^i C(a+i,i) C(a+m+1,m-i) Y_{a+i}.
```

Fix prime endpoints

```text
q = d+1,
ell = d+L+1,
0 < L < q.
```

Every short Newton stencil containing both nodes `q-1` and `ell-1` satisfies

```text
G ≡ Y_{q-1}   mod q,
G ≡ Y_{ell-1} mod ell.
```

The pair-preserving margins `H_{s,t} = G(d-s,L+s+t)` are one instance. Moving the stencil, multiplying node values by target-blind weights, or taking a bounded family can change how an endpoint divides a row. It cannot create a second informative mod-p observation while retaining that endpoint in the evaluated gcd.

The exact conclusions are:

1. **Single-prime coefficient module.** If `V` is the localized recurrence-state lattice and `tau_p` is the primitive matched-shell functional, every linear observation universally preserving the target lies in

```text
P_p = R_p tau_p + p V*.
```

Therefore every target-preserving observation matrix has rank at most one modulo `p`. Every `k` by `k` minor is divisible by `p^(k-1)`.

2. **Two-endpoint coefficient module.** On a shell-coordinate window `J` containing both matched nodes,

```text
P_{q,ell}(J)
  = ell Z e_{q-1}
    direct-sum q Z e_{ell-1}
    direct-sum q ell Z^{J minus {q-1,ell-1}}.
```

After ordering the two matched columns first, every family matrix has the exact shape

```text
A = [ ell a | q b | q ell C ].
```

Hence it has rank at most one modulo `q` and at most one modulo `ell`. Every full `m`-row minor is divisible by `(q ell)^(m-1)`.

3. **The optimal two-placement CRT trick still fails.** Weight one placement by `j-(q-1)` and another by `j-(ell-1)`. The first row is coefficient-forced at `q` and aliases `ell`; the second aliases `q` and is coefficient-forced at `ell`. Their gcd retains `q ell` at a target pair, but their local Smith forms are exactly

```text
diag(1,q)   at q,
diag(1,ell) at ell.
```

The relevant determinant has valuation exactly one at each endpoint. Its quotient by `q ell` can be a unit, but the divided observations are no longer target-forced zeros.

4. **Rank at most 39 recurrence.** If the shell state rank is `rho ≤ 39`, every full observability determinant made only from target-preserving observations satisfies

```text
v_p(det O) ≥ rho-1.
```

For a pair,

```text
(q ell)^(rho-1) divides det O.
```

At rank 39 the forced factor is `(q ell)^38`. A p-unit observability determinant is impossible.

5. **Nonlinear bounded-degree no-go.** At every good prime, assume the target ideal is exactly the one unsaturated alias scalar `(tau_p)`. For fixed degree `D < p`, every polynomial observation vanishing on all target states is divisible by `tau_p`. Its Jacobian has rank at most one on the target hyperplane. Bounded-degree nonlinear combinations cannot evade the Smith obstruction.

6. **Block height.** If a target-blind determinant is assigned to every pair in a family `E`, then

```text
sum_{(q,ell) in E} log |D_{q,ell}|
  ≥ (m-1) sum_p deg_E(p) log p.
```

In the first cell, `p > M/2`. Making this total `o(H)`, where `H=M^(1/3)`, already requires the desired pair-incidence estimate `sum_p deg_E(p) = o(H/log M)`. The construction is circular. Dividing the forced endpoint factors destroys the target congruences.

Thus the answer is **no**. Different target-blind Newton placements can redistribute alias divisibility and coefficient divisibility, but they cannot make an endpoint non-alias in an informative target-preserving row. The next possible escape is a genuinely new second target equation or a p-squared theorem for a coefficient-forced row.

# 1. Newton coefficient rows

Let `J = {a,a+1,...,b}` and `m=b-a`. The coefficient of `Y_{a+i}` in interpolation at `-1` is

```text
lambda_J(a+i) = (-1)^i C(a+i,i) C(b+1,m-i).
```

Equivalently,

```text
lambda_J(j) = product over h in J, h != j, of (-1-h)/(j-h).
```

Assume `p` is prime, `p-1` belongs to `J`, and `m<p`. The nodes are distinct modulo `p`, and the evaluation point `-1` is the node `p-1`. Therefore

```text
lambda_J(p-1) ≡ 1 mod p,
lambda_J(j)   ≡ 0 mod p for j != p-1.
```

The product formula gives the stronger valuation statement. For a nonmatched node, the numerator contains exactly one factor `p`, arising from `h=p-1`. No denominator difference is divisible by `p`, since all differences have absolute value below `p`. Hence

```text
v_p(lambda_J(j)) = 1 for j != p-1,
v_p(lambda_J(p-1)) = 0.
```

Consequently

```text
G(a,m) ≡ Y_{p-1} mod p.
```

This is the alias mechanism before any recurrence is used.

## Weighted placements

For any target-blind integer weight `omega(j)`, define

```text
G(J,omega) = sum_{j in J} omega(j) lambda_J(j) Y_j.
```

Then

```text
G(J,omega) ≡ omega(p-1) Y_{p-1} mod p.
```

There are exactly two types.

- If `omega(p-1)` is a p-unit, the row is an alias row.
- If `omega(p-1)` is divisible by `p`, every coefficient of the row is divisible by `p`. The row is coefficient-forced and is zero as a mod-p observation.

After dividing a coefficient-forced row by `p`, the resulting row may be non-alias. But targetness supplies no congruence for that divided value. There is no third informative target-preserving type.

# 2. Exact coefficient modules

## One endpoint in free shell coordinates

Let

```text
V_J = direct sum over j in J of Z e_j.
```

A coefficient row `c = (c_j)` is universally target-preserving at `p` when

```text
Y_{p-1} ≡ 0 mod p  implies  sum_j c_j Y_j ≡ 0 mod p
```

for every coordinate vector `Y`. Testing vectors supported on one nonmatched coordinate proves

```text
c_j ≡ 0 mod p for every j != p-1.
```

Therefore

```text
P_p(J) = Z e_{p-1}* + p V_J*.
```

## One endpoint in the recurrence state

Let `R_p = Z localized at p`, let `V` be a free `R_p`-module, and let `tau_p` be primitive and nonzero modulo `p`. A row `lambda` preserves every target state precisely when its reduction annihilates `ker(tau_p mod p)`. The annihilator of a codimension-one hyperplane is its defining line, so

```text
lambda = a tau_p + p u
```

for some `a in R_p` and `u in V*`. Thus

```text
P_p = R_p tau_p + p V*.
```

This is the abstract form that survives compression to a recurrence state of rank at most 39.

## Two endpoints and CRT necessity

A shell-coordinate row preserving `q` must have every coefficient except the `q-1` coefficient divisible by `q`. Preserving `ell` imposes the analogous condition. Combining them gives:

- the `q-1` coefficient is divisible by `ell`;
- the `ell-1` coefficient is divisible by `q`;
- every other coefficient is divisible by `q ell`.

Hence the exact module is

```text
P_{q,ell}(J)
  = ell Z e_{q-1}*
    direct-sum q Z e_{ell-1}*
    direct-sum q ell Z^{J minus {q-1,ell-1}}.
```

For `m` rows, after ordering columns as `q-1`, `ell-1`, and the remaining nodes,

```text
A = [ ell a | q b | q ell C ],
```

where `a` and `b` are single columns. Modulo `q`, only `ell a` can survive. Modulo `ell`, only `q b` can survive. Therefore

```text
rank(A mod q) ≤ 1,
rank(A mod ell) ≤ 1.
```

This classifies both CRT mechanisms mentioned in the question:

- target alias through the matched shell;
- automatic divisibility because the complete row has a coefficient factor `p`.

There is no third mechanism in the universal coefficient algebra.

# 3. Local Smith forms

Let `A` be an integer matrix with `m` rationally independent rows, all target-preserving at `p`. Write its local Smith form as

```text
diag(p^e1, p^e2, ..., p^em),
0 ≤ e1 ≤ e2 ≤ ... ≤ em.
```

Since the mod-p row rank is at most one,

```text
ei ≥ 1 for every i ≥ 2.
```

If at least one row has a unit alias coefficient, then `e1=0`. Thus the minimal possible local form is

```text
diag(1,p,...,p).
```

Every `k` by `k` minor obeys

```text
v_p(minor) ≥ k-1.
```

Applying this at `q` and `ell` separately gives

```text
(q ell)^(k-1) divides every k by k minor.
```

For the independent boundary margins of Q5714, the divided difference directions are primitive, so equality holds:

```text
diag(1,p,...,p).
```

Adding different shifted or weighted placements may increase some Smith exponents. It can never lower the mod-p rank defect.

## Unweighted Newton placements

Every unweighted short placement containing `p-1` reduces to the same row `e_{p-1}*`. Hence

```text
lambda_{J1} - lambda_{J2} belongs to p V*.
```

If both endpoint nodes are preserved,

```text
lambda_{J1} - lambda_{J2} belongs to q ell V*.
```

That coefficientwise `q ell` divisibility is the exact source of the margin-family Smith factors.

# 4. The strongest two-placement CRT attempt

Take one short interval `J` containing both matched nodes and define

```text
R_q   = sum_{j in J} (j-q+1)   lambda_J(j) Y_j,
R_ell = sum_{j in J} (j-ell+1) lambda_J(j) Y_j.
```

Let `L=ell-q`. Then

```text
R_q   ≡ 0            mod q,
R_ell ≡ -L Y_{q-1}   mod q,
R_q   ≡ L Y_{ell-1}  mod ell,
R_ell ≡ 0            mod ell.
```

Since `0<L<q<ell`, `L` is a unit at both endpoints. At a target pair, both `R_q` and `R_ell` are divisible by `q ell`.

This realizes the most favorable possible redistribution:

- `R_q` is coefficient-forced at `q` and aliases `ell`;
- `R_ell` aliases `q` and is coefficient-forced at `ell`.

On the two matched columns, the matrix is

```text
[ 0                     L lambda_J(ell-1) ]
[ -L lambda_J(q-1)      0                 ].
```

Its determinant is

```text
L^2 lambda_J(q-1) lambda_J(ell-1).
```

Short-stencil valuation gives

```text
v_q(lambda_J(q-1)) = 0,
v_ell(lambda_J(q-1)) = 1,
v_q(lambda_J(ell-1)) = 1,
v_ell(lambda_J(ell-1)) = 0.
```

Therefore

```text
v_q(det) = 1,
v_ell(det) = 1.
```

The local Smith forms are exactly

```text
diag(1,q)   at q,
diag(1,ell) at ell.
```

The quotient of the determinant by `q ell` can be a unit. This does not produce observability. Modulo `q`, the equation `R_q=0` is an identity caused by its coefficients and says nothing about `R_q/q`. Modulo `ell`, the analogous statement holds for `R_ell/ell`. The unit determinant appears only after dividing away the factors that made the gcd retain the endpoints.

# 5. Rank at most 39 recurrence and observability

Let the full shell state after adjoining `b_M` have localized rank `rho ≤ 39`. Let `T_p` be the good-prime transition and `tau_p` the primitive target observation. The premise that the target remains one unsaturated alias scalar means that the target locus is the single hyperplane

```text
ker(tau_p mod p).
```

Any target-preserving observation `o_i` has the form

```text
o_i = a_i tau_p + p u_i.
```

Thus every observation matrix satisfies

```text
rank(O mod p) ≤ 1.
```

For a full `rho` by `rho` observability determinant,

```text
p^(rho-1) divides det O.
```

For two preserved endpoints,

```text
(q ell)^(rho-1) divides det O.
```

At rank 39,

```text
(q ell)^38 divides det O.
```

A p-unit full observability determinant is therefore impossible.

## Why recurrence shifts do not help

An observability matrix normally uses rows such as

```text
o, o T, o T^2, ...
```

There are only two cases.

1. Every shifted row included in the zero system is itself target-preserving. Then every row is still in `R_p tau_p + p V*`, so the mod-p rank is at most one.
2. A shifted row is not target-preserving. Then targetness does not imply that its evaluated value is zero, so it cannot be included among the common-zero equations.

A recurrence cannot extract an equation from a coefficient-forced row after division by `p` unless a separate theorem supplies one more p-adic digit.

## Fitting formulation

For every `k ≥ 1`, the determinantal ideal of a target-preserving observation matrix satisfies

```text
I_k(O) is contained in the ideal generated by p^(k-1).
```

The full Fitting determinant therefore carries the complete target saturation before any arithmetic information from the distinguished state is used.

# 6. Nonlinear bounded-degree no-go

Work over `F_p` and choose state coordinates

```text
x1 = tau_p, x2, ..., x_rho.
```

Let `F` be a polynomial of degree less than `p` in each variable. Suppose

```text
F(0,x2,...,x_rho) = 0
```

for every point of `F_p^(rho-1)`. Write

```text
F = f0(x2,...,x_rho) + x1 F1.
```

The polynomial `f0` has degree below `p` in each variable and vanishes at every point. Therefore `f0=0`, and

```text
F is divisible by tau_p.
```

For a fixed bounded degree, the condition `degree < p` holds for all sufficiently large target primes.

If `F_i = tau_p G_i`, then on the target hyperplane

```text
dF_i = G_i d(tau_p).
```

All Jacobian rows are proportional. Hence

```text
rank(J_F) ≤ 1 on tau_p=0,
```

and every Jacobian or exterior minor of order at least two vanishes.

This covers bounded-degree polynomial combinations of Newton rows, bounded-degree nonlinear observability maps, and target-blind resultants formed before specialization. A transverse unit determinant requires division by `tau_p` or by an explicit coefficient factor `p`; either operation removes the guaranteed target factor.

### Specialization scope

The coefficient-algebra theorem is unconditional. Its transfer to the rank-`rho` recurrence state uses the stated premise that the good-prime target ideal is scheme-theoretically the principal ideal `(tau_p)`. If “one alias scalar” were only a numerical observation at one actual state, then proving principality would still be required. Failure of principality would itself be the desired new arithmetic result: a second target equation.

# 7. Total-height ledger over an H block

Let `E` be a target-blind collection of short candidate pairs. Let `D_{q,ell}` be an `m`-row determinant made available for a pair before targetness is known. The local Smith theorem gives

```text
(q ell)^(m-1) divides D_{q,ell}.
```

Therefore

```text
sum_{(q,ell) in E} log |D_{q,ell}|
  ≥ (m-1) sum_{(q,ell) in E} (log q + log ell)
  = (m-1) sum_p deg_E(p) log p.
```

In the first cell, every relevant prime exceeds `M/2`, so

```text
sum log |D_{q,ell}|
  ≥ (m-1) log(M/2) sum_p deg_E(p).
```

To make the total family height `o(H)` for `H=M^(1/3)`, one already needs

```text
sum_p deg_E(p) = o(H/log M).
```

For adjacent pairs, the incidence sum is twice the number of pairs up to endpoint effects. This is the collision bound the determinant was intended to prove. The ledger is circular.

At recurrence rank `rho`, replace `m-1` by `rho-1`, at most 38. The obstruction is stronger.

## One global block determinant

If one global bounded family preserves every prime node in a block set `P`, then

```text
product_{p in P} p^(m-1) divides D.
```

Thus

```text
log |D| ≥ (m-1) sum_{p in P} log p.
```

If `P` is the actual target set, proving this is `o(H)` is already the desired radical theorem. If `P` is the full candidate set, the determinant is target-blind but carries all candidates. Neither gives compression.

## Why the normalized quotient cannot be charged

The quotient

```text
D_tilde = D_{q,ell}/(q ell)^(m-1)
```

may be a unit or have polylogarithmic height. But forming it corresponds locally to dividing the saturated observation directions by `q` or `ell`. The target hypothesis gives no zero congruence for those divided observations. Therefore `D_tilde` is not a target-divisible carrier and cannot be counted against the target radical.

A separate polylogarithmic certificate chosen after each realized pair is still insufficient.

# 8. Sharp local no-go theorem

## Theorem

Fix a good prime `p` and a free local recurrence-state module `V` of finite rank. Let `tau_p` be primitive. Let a bounded family be constructed from:

- short Newton placements containing `p-1`;
- target-blind integer weights;
- integer linear combinations;
- recurrence shifts that are themselves required to preserve the target;
- polynomial combinations of degree `D<p`.

Assume every member vanishes modulo `p` on every state satisfying `tau_p=0`. Then:

1. every linear member belongs to `R_p tau_p + p V*`;
2. every polynomial member belongs to the principal ideal `(tau_p)` modulo `p`;
3. every linear observation matrix has mod-p rank at most one;
4. every `k` by `k` linear minor is divisible by `p^(k-1)`;
5. every nonlinear Jacobian minor of order at least two vanishes on the target locus;
6. no coefficient, observability, Jacobian, or exterior determinant of order at least two can be a p-unit while all defining evaluated rows retain `p`.

For two endpoints, the conclusions hold simultaneously and every `k` by `k` linear minor is divisible by `(q ell)^(k-1)`.

## Proof

The linear assertion is the annihilator identity for the target hyperplane. Rank and Smith divisibility follow from reduction modulo `p`. The nonlinear assertion is divisibility by the hyperplane equation, followed by differentiation. The two-prime statement follows by applying the one-prime result separately and using coprimality.

# 9. Genuine remaining exits

The no-go leaves only arithmetic routes that add information rather than move coefficients.

1. **A second target equation.** Prove that the actual distinguished shell state lies in a proper subvariety of the formal target hyperplane. This enlarges the target ideal beyond `(tau_p)`.
2. **A p-squared lift for a coefficient-forced row.** If all coefficients contain `p`, prove that targetness forces the evaluated row to contain `p^2`. Division by `p` would then leave a new mod-p equation.
3. **A global many-prime identity.** It must amortize endpoint factors in one target-blind integer whose total height is `o(H)`, not assign a determinant to each realized pair.
4. **Degree comparable to p.** Finite-field functions of degree at least `p` can evade the bounded-degree hyperplane lemma, but their degree and height are incompatible with the required block ledger unless a new low-height structure is found.

Absent one of these, different Newton placements merely rearrange the same unsaturated alias scalar.

# Final assessment

A bounded family of different target-blind Newton placements can make an endpoint coefficient-forced in one row and alias-forced in another. It cannot make that endpoint an informative non-alias while retaining it in the evaluated gcd. Every preserved endpoint leaves only one mod-p observation line. All additional directions are p-saturated.

Consequently every observability determinant large enough to see the rank-at-most-39 recurrence carries each endpoint to exponent at least 38. Removing that content removes the target equations. The placement search is exhausted at the local-algebra level.

The next useful subproblem is to prove either a second distinguished-state target equation or one extra p-adic digit for a coefficient-forced placement.
