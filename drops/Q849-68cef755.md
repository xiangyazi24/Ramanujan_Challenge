# Q849 audit: soft exceptional proxies

## 1. Status of the proposed direction

The target is to replace the hard exceptional indicator

\[
1_{\{\log G_n>\epsilon n\}}
\]

by a softer weight while preserving enough information to kill a single bad row. The key restriction is that the proxy must not silently reintroduce the fixed-q second moment criterion.

The conclusion is:

* There is a useful conditional soft criterion, but it is not currently implied by the exceptional theorem.
* Every natural quadratic softening whose zero-frequency contribution is controlled by the available \(Z(p)\ll p^{2/3}\) machinery collapses to either the fixed-q energy criterion \(E_q(N)=o(N^2/\log^2N)\) or the aggregate LGTQ-AGG-BDH form.
* The only genuinely weaker candidate is a weighted first-moment carrier criterion; its missing ingredient is a new rigidity theorem for exceptional rows.

## 2. Fixed-q reduction

Fix q. Write the row load as

\[
T_q(n)=\sum_{p\in\mathcal P_q(n)}1,
\]

with expected term \(\mu_q(n)\). The desired exceptional elimination needs

\[
T_q(n)\gg N/\log N
\]

for a single \(n\in(N,2N]\) to be impossible.

A soft proxy has the form

\[
W_N(n)=\Phi\left(\frac{T_q(n)-\mu_q(n)}{\Lambda_N}\right),
\]

where \(\Phi\geq0\) is increasing. To exclude a spike one needs

\[
\sum_{N<n\le2N}W_N(n)=o(1)\text{ or }o(N/\log N)
\]

at a scale where one row with size \(N/\log N\) forces a contradiction.

## 3. Polynomial softening

Take

\[
\Phi(x)=x_+^r.
\]

Then

\[
\sum_{n\in E} (T_q(n)-\mu_q(n))_+^r
\]

contains a single spike of size

\[
(N/\log N)^r.
\]

However the available expansion is not first moment. Expanding gives correlation sums over r-tuples of prime constraints. The diagonal contribution already has size controlled by

\[
\sum_p Z(p)^r,
\]

and the existing bucket proof only supplies the needed savings for the second-moment geometry. For r=2 this is exactly the fixed-q energy node. For r>2 the off-diagonal analysis is stronger, not weaker.

Thus polynomial truncation does not create a new node.

## 4. Weighted first-moment candidate

The most promising non-equivalent proxy is

\[
M_{q,\epsilon}(N)=\sum_{N<n\le2N} a_n(T_q(n)-\mu_q(n)),
\]

with

\[
a_n=t(\log G_n/n),
\]

where \(t(x)=0\) near zero and grows only on large columns.

A sufficient criterion would be:

\[
\sum_{N<n\le2N}a_n(T_q(n)-\mu_q(n))=o(N/\log N)
\]

for every admissible nonnegative soft threshold \(t\), together with

\[
\log G_n>\epsilon n\implies a_n\gg1.
\]

This would detect a single exceptional row without paying for all rows.

But proving this requires a new estimate:

\[
\sum_n t(\log G_n/n)T_q(n)
\]

with the weight correlated to the same prime structure generating \(T_q\). The existing exceptional theorem only bounds the cardinality of rows after extracting bad prime sets; it does not control this correlation.

## 5. Comparison with existing nodes

### Fixed-q energy criterion

\[
E_q(N)=o(N^2/\log^2N)
\]

already gives the quadratic contradiction:

\[
(N/\log N)^2>E_q(N).
\]

Any choice \(t(x)=x\) or a smooth approximation that uses Cauchy-Schwarz immediately returns to this criterion.

### LGTQ-AGG-BDH

The aggregate criterion controls sums over q and h after singular-series averaging. A soft dyadic integral

\[
\int_0^\infty t(u)\#\{n:\log G_n/n>u\}\,du
\]

is only useful if the weighted correlations can be separated. The current BDH argument provides the unweighted aggregate bound, not the required exceptional-row weighted version.

## 6. What the codegree/bucket proof already gives

The exceptional theorem gives:

\[
|E_\epsilon(N)|\ll_\epsilon\log N
\]

through common bad-prime codegrees and residue buckets.

This proves:

1. Few exceptional rows.
2. Each row has a structured bad-prime witness.
3. Bucket collisions are limited.

It does not prove:

\[
\sum_{n\in E_\epsilon(N)}(T_q(n)-\mu_q(n))=o(N/\log N).
\]

The missing step is that a sparse set can still contain one row with maximal load.

## 7. Canonical divisor versus adversarial star model

A possible new lemma would exploit that all exceptional rows arise from canonical Apéry-style common divisors rather than arbitrary stars:

\[
B_n=\gcd\{\text{bad prime constraints of row }n\}.
\]

If ordering the exceptional rows forces

\[
\prod_{n\in E}B_n
\]

or an associated carrier integer to have height exceeding the available divisor budget, then a first-moment criterion could follow.

The present proof does not establish this. It treats rows through prime witnesses and buckets, not through a globally coupled canonical carrier.

## 8. Sharpest weaker lemma currently justified

A strictly weaker but meaningful target is:

> For every fixed q and epsilon, every exceptional row contains at least one fixed-q bucket whose multiplicity is \(o(N/\log N)\) after removing a polylogarithmic family of canonical prime carriers.

This is weaker than EXC-M1 because it does not bound the total exceptional contribution. It only rules out a single isolated maximal bucket.

If proved, it would directly attack the remaining single-spike obstruction.

## Final verdict

* Soft quadratic proxies: **not new**; they collapse to \(E_q\) or LGTQ-AGG-BDH.
* Polynomial higher moments: **stronger than needed but currently harder**.
* Weighted first moment: **genuinely new conditional criterion**, but not a consequence of the existing exceptional theorem.
* The missing theorem is a canonical-carrier rigidity statement connecting all exceptional rows through their actual prime-shell construction.

No unconditional EXC-SPARSE-M1 proof follows from the current codegree/bucket argument alone.
