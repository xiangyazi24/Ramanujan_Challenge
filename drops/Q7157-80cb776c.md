# Q7157 (rc6): P32 cluster combinatorics R2 correction

## 1. Correct deterministic bound

Let the occupied non-centered residues be a subset S of a cyclic palindrome orbit of odd ambient length p. Let

\[
A(h)=\#\{(x,x+h):x,x+h\in S\}
\]

(with the directed convention used in P32), and let

\[
E_H=\sum_{1\le h\le H}A(h).
\]

The previous pH^2 and H^4 estimates were not the correct deterministic scale. The available hypotheses already give

\[
A(h)\le 3(h-1),\qquad h\ge 2.
\]

There is no adjacency, so A(1)=0. Therefore

\[
E_H\le \sum_{h=2}^{H}3(h-1)
      =3\frac{H(H-1)}2.
\]

This is the sharp upper bound obtainable immediately from the stated caps. In particular,

\[
E_H=O(H^2).
\]

The four-window observation is consistent with this: every consecutive four-window contributes a unique endpoint pair of distance at most H, so the same counting cannot produce an H^4 quantity.

## 2. Can the quadratic bound be attained?

The requested construction would need a set S satisfying simultaneously:

1. palindrome symmetry;
2. no adjacent occupied residues;
3. for every 2<=h<p,
   \[
   A(h)\le 3(h-1);
   \]
4. after deleting centered windows, retain
   \[
   E_H=\Omega(H^2).
   \]

The previous packet argument does not work. A packet containing H points in a short interval creates many repeated differences and violates the small-gap caps. In particular, an interval-like packet has multiplicity roughly H for many small h, while the permitted multiplicity is only O(h).

A Sidon-separated or probabilistic packet construction is the only plausible route to a genuine lower bound, but it must prove the full difference multiplicity estimate for every h, not only the small h range. No such proof is currently available from the given hypotheses.

## 3. What is actually proved

The rigorous conclusion is therefore:

\[
\boxed{E_H\le \frac32H(H-1)}
\]

and the exponent 2 is an upper-bound scale, but quadratic sharpness has **not** been established.

The logical status is:

- proved: deterministic O(H^2) upper bound;
- disproved: the earlier H^4/H^2 packet heuristics as constructions;
- not proved: existence of infinitely many admissible palindromic configurations with E_H=Omega(H^2).

## 4. Extremal order

With only the axioms listed (palindrome, no adjacency, A(h)<=3(h-1)), the true extremal order remains open between the trivial lower constructions and the quadratic upper bound.

A valid Omega(H^2) example would require a near-saturation pattern

\[
A(h)\asymp h
\]

for a positive proportion of h<=H while keeping all other differences globally controlled. This resembles a constrained Golomb-ruler/Sidon-type extremal problem with additional reflection symmetry. The ordinary dense-block construction is impossible; any sharp example must be highly nonlocal.

Therefore the correct R2 correction is:

> Only logical insufficiency has been proved. The deterministic quadratic upper bound is sharp as a bound from the available inequalities, but quadratic attainability has not been demonstrated.
