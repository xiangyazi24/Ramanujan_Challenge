# Q862 Apéry polylogarithmic-moment carrier audit

## 1. Scope and verdict

The proposed route is a genuinely different consumer route from the fixed-q one-moment boundary carriers, but the implication chain has to be stated carefully.

The banked input is:

```
U_s(n) = c_q^s b_r S_s(a) mod q
```

when `q^e <= n` is the largest q-power below n, `n=a q^e+r`, and

```
S_s(a)=sum_{u=1}^a b_{a-u} u^{-s}.
```

For lower-digit bad primes with `p>sqrt(n)`, one has `e=1`, hence the bad condition is detected by the first digit. This gives a strong radical-support statement, but not automatically a valuation statement.

The corrected dependency graph is:

```
Apéry local Vandermonde criterion
          |
          v
prime-local support inclusion into C_n
          |
          v
consumer bound for log C_n
          |
          v
log C_n=o(n)
          |
          v
all-index conclusion
```

The route is not equivalent to AAT/QPF. It is a distinct carrier using Apéry moments.

## 2. Exact finite-space and moment notation

Let

```
Y_n = { y : y odd, 1 <= y < 4 n^2 }.
```

Let

```
K_n = #{ q : q prime, q <= n, q | y and local obstruction }
```

be the corresponding bad-prime count. The consumer uses

```
C_n = gcd(L_n,U_1(n),U_2(n),U_3(n)).
```

The prime-support question is whether every bad prime factor of the relevant boundary contribution appears in `C_n`.

## 3. Exact local formula and Vandermonde consequence

For a prime q with

```
n = a q + r
```

and q larger than sqrt(n), the residue structure gives

```
U_s(n) = c_q^s b_r S_s(a) mod q.
```

Therefore if

```
q | b_r
```

then

```
U_s(n)=0 mod q
```

for every available moment s.

For the first three moments:

```
q | L_n
q | U_1(n)
q | U_2(n)
q | U_3(n)
```

so

```
q | C_n.
```

For general q-adic digit blocks, the Vandermonde argument is stronger: if all moments

```
s=0,...,a-1
```

are available, then the matrix

```
(u^{-s})_{s,u}
```

is invertible whenever the residues u are distinct modulo q. Hence the vanishing of all moment sums forces the relevant coefficient vector to vanish.

This is a support statement.

## 4. Radical support versus valuations

A key correction:

```
q | C_n
```

is only radical information.

The gcd may contain:

- higher q-powers from accidental congruences;
- aliases caused by overlap of several local carriers;
- unrelated prime factors dividing all moments.

For the consumer estimate

```
log C_n
```

this is harmless because

```
log C_n >= sum_{q in forced support} log q.
```

But a proof cannot replace

```
q | C_n
```

by an exact valuation identity.

The correct node is:

```
local obstruction set subset rad(C_n)
```

not

```
C_n = exact obstruction product.
```

## 5. Lower-digit bad primes

For

```
p > sqrt(n)
```

we have `e=1`.

Write

```
n = a p+r,
0 <= r<p.
```

The lower-digit condition is

```
p | b_r.
```

The local theorem gives

```
p | C_n
```

already from the first moment whenever the stated divisibility applies.

Therefore the consumer does not need three moments for this implication.

Three moments are useful for the stronger statement involving simultaneous recovery of several Apéry coefficients through the Vandermonde system, but they are not necessary for the forward support implication in the large-prime lower-digit case.

## 6. Prime powers

Prime powers require separate treatment.

The statement

```
q^e <= n < q^{e+1}
```

controls the q-adic digit level, but

```
q | C_n
```

only records one q factor.

To obtain a valuation-sensitive estimate one would need a theorem of the form

```
min(v_q(L_n),v_q(U_1),v_q(U_2),v_q(U_3)) >= e'
```

with explicit e'.

The current carrier only proves support. Thus prime powers belong to a later strengthening, not to the basic all-index edge.

## 7. Consumer logarithmic estimate

Assume the separate consumer estimate:

```
log G_n <= O(sqrt(n)) + O(n^(2/3)) + 6 log C_n.
```

If the target index obstruction is bounded by `G_n`, then

```
log G_n/n
 <= O(n^{-1/2})+O(n^{-1/3})+6 log(C_n)/n.
```

Hence

```
log(C_n)=o(n)
```

implies

```
log(G_n)=o(n).
```

Therefore the remaining required theorem is a subexponential upper bound for the Apéry moment carrier gcd.

The carrier route is successful if it proves:

```
log C_n=o(n).
```

## 8. Three moments: needed or not?

For the direct implication

```
large bad prime p
      |
      v
p | C_n
```

one moment is enough provided the local congruence

```
U_1(n)=c_p b_r S_1(a) mod p
```

has a nonzero harmless factor outside `b_r`.

Three moments are not needed for this edge.

They are needed only for:

1. a Vandermonde recovery theorem;
2. cancellation of possible coefficient aliases;
3. higher-dimensional local reconstruction.

Thus:

```
one moment -> support carrier
three moments -> robust reconstruction carrier
```

## 9. Comparison with fixed-q boundary carriers

The routes differ.

Fixed-q boundary carriers:

```
fixed q
 |
boundary residue statistics
 |
one/few local moments
 |
prime obstruction
```

Apéry polylog carrier:

```
all q-adic scales
 |
Apéry moment identities
 |
Vandermonde/local gcd carrier
 |
C_n
```

They share a philosophy (turn arithmetic obstruction into a common divisor) but are not the same proof object.

## 10. Remaining connected ranks

The established rank is:

```
rank-1: individual prime support carrier
```

The unresolved ranks are:

```
rank-2: companion overlap between multiple bad primes
rank-3+: interaction of several q-adic digit constraints
valuation ranks: q^e rather than q support
```

The consumer only needs the aggregate logarithm, so full higher-rank independence is not required if overlap is controlled.

## 11. Concrete next lemma

A suitable next lemma for gap-polynomial or Cartier methods is:

```
Lemma (Apéry carrier overlap bound).

Let B_n be the set of primes q with the lower-digit obstruction
q | b_{n mod q}.
Then

sum_{q in B_n, q<=n} log q
    <= o(n).

Moreover the contribution from primes q with
q^2 <= n
is O(n^(2/3)) after separating q-adic blocks.
```

A stronger version would bound the number of simultaneous local coincidences:

```
#{q1,...,qk : all q_i satisfy the same Apéry boundary carrier}
```

through a gap-polynomial/Cartier estimate.

This is the missing connected-discrepancy edge.

Valid:


Final verdict: the polylogarithmic-moment carrier is a distinct and plausible route. The forward all-index implication needs only a radical-support carrier plus the consumer inequality; three moments are not logically necessary for the large-prime lower-digit implication, but they strengthen the local reconstruction framework.
