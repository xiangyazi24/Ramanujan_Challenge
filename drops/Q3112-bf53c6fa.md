# Verdict

For the Q3092 mirror setup

\[
0<s<\frac{p-1}{2},\qquad p\mid b_s,\qquad d=p-1-2s,
\]

the divided continuant is

\[
\boxed{
\frac{N_d(s)}p\equiv
\left(\frac{(p-1-s)!}{s!}\right)^3 c_s J_s\pmod p,
}
\tag{1}
\]

with `c_0=0,c_1=1` the canonical independent recurrence solution and

\[
\boxed{
J_s=2\sum_{k=0}^s
\binom{s}{k}^2\binom{s+k}{k}^2
(H_{s+k}-H_{s-k}).
}
\tag{2}
\]

The prefactor and `c_s` are `p`-units at a target. Hence

\[
\boxed{p^2\mid N_{p-1-2s}(s)\iff p\mid J_s.}
\tag{3}
\]

The derivative scalar has the following exact closed forms.

## 1. Canonical Apéry-index derivative

Define

\[
\mathcal B_s(X)=\sum_{k=0}^s
\frac{(-X)_k^2(X+1)_k^2}{(k!)^4}
=\sum_{k=0}^s\binom Xk^2\binom{X+k}{k}^2.
\]

Then

\[
\boxed{\mathcal B_s(s)=b_s,\qquad J_s=\mathcal B_s'(s).}
\tag{4}
\]

Indeed one summand `T_k(X)` satisfies

\[
\frac{T_k'(s)}{T_k(s)}
=2(H_{s+k}-H_{s-k}).
\]

Thus `J_s` is literally the first derivative of the truncated characteristic-zero Apéry interpolation.

## 2. Newton--Racah spectral derivative

Put `lambda_x=x(x+1)` and

\[
\mathcal R_s(T)=
\sum_{k=0}^s
\frac{(-s)_k(s+1)_k(-1)^k}{(k!)^4}
\prod_{a=0}^{k-1}(T-a(a+1)).
\tag{5}
\]

Since

\[
\prod_{a=0}^{k-1}(\lambda_X-\lambda_a)
=(-1)^k(-X)_k(X+1)_k,
\]

one gets

\[
\boxed{\mathcal R_s(\lambda_s)=b_s},
\qquad
\boxed{J_s=2(2s+1)\mathcal R_s'(\lambda_s).}
\tag{6}
\]

Because `p>2s+1`, all denominators are `p`-units. Conditional on targethood,

\[
\boxed{
p\mid J_s
\iff
\lambda_s\text{ is a repeated root of }\overline{\mathcal R_s}(T).}
\tag{7}
\]

So the Q3092 exceptional lift is exactly a repeated-node condition for a fixed characteristic-zero Newton--Racah polynomial.

## 3. Global Newton kernel

Write `p=2h+1`. Define

\[
P_k(T)=\prod_{a=0}^{k-1}(T-a(a+1)),\qquad
\phi_k(T)=P_k(T)/(k!)^2,
\]

\[
F_h(T)=\sum_{k=0}^h\phi_k(T)^2.
\tag{8}
\]

For every noncentral `s<h`, terms `k>s` have a double zero at `lambda_s`, while for `k<=s`

\[
\phi_k(\lambda_s)^2
=\binom{s}{k}^2\binom{s+k}{k}^2.
\]

Therefore

\[
\boxed{F_h(\lambda_s)=b_s,\qquad (2s+1)F_h'(\lambda_s)=J_s.}
\tag{9}
\]

Thus `p|b_s,J_s` is also exactly the statement that `lambda_s` is a multiple node of `F_h mod p`.

# Christoffel--Darboux meaning

The `R_m` satisfy

\[
T\mathcal R_m=A_m\mathcal R_{m+1}-(A_m+C_m)\mathcal R_m+C_m\mathcal R_{m-1},
\]

\[
A_m=\frac{(m+1)^3}{2(2m+1)},\qquad C_m=\frac{m^3}{2(2m+1)}.
\]

The diagonal Christoffel--Darboux identity at `m=s-1,T=lambda_s` is

\[
\sum_{k=0}^{s-1}(2k+1)\mathcal R_k(\lambda_s)^2
=\frac{s^3}{2}\left(
\mathcal R_{s-1}(\lambda_s)\mathcal R_s'(\lambda_s)
-\mathcal R_s(\lambda_s)\mathcal R_{s-1}'(\lambda_s)
\right).
\tag{10}
\]

At a target the second term vanishes mod `p`, and `R_{s-1}(lambda_s)` is a unit (otherwise backward recurrence forces `R_0=0`). Hence

\[
\boxed{
p\mid J_s
\iff
\sum_{k=0}^{s-1}(2k+1)\mathcal R_k(\lambda_s)^2\equiv0\pmod p.}
\tag{11}
\]

This is the isotropy/crossing-form interpretation of the repeated eigenvalue. Real positivity does not survive over `F_p`, so this identity alone does not prove nonvanishing.

# Relation to the suggested arithmetic objects

**Harmonic sum:** yes, exactly (2).

**Repeated root:** yes, exactly (7), equivalently (9)--(11).

**Fermat quotient:** no standard fixed-base Fermat-quotient reduction appears. The scalar is a binomially weighted sum of moving intervals

\[
H_{s+k}-H_{s-k}=\sum_{m=s-k+1}^{s+k}\frac1m.
\]

Half-range identities such as those involving `H_{(p-1)/2}` and `q_p(2)` concern the central index `s=(p-1)/2`; here that index gives `d=0` and no mirror bridge. I therefore do not identify the noncentral scalar with a known Fermat quotient.

**Hasse invariant derivative / supersingularity:** no. The current source's K3 Hasse--Witt polynomial is

\[
A_p(t)=\sum_{j=0}^{p-1}b_jt^j.
\]

Its evaluation roots in the family parameter `t` describe nonordinary/supersingular fibers. Here `p|b_s` is a **coefficient** zero, and `J_s` differentiates the index interpolation/spectral node, not `A_p(t)` in `t`. Thus no supersingularity equivalence follows.

**Reflection derivative:** yes. Q3092 proves the exact first reflection digit

\[
\boxed{b_{p-1-s}\equiv b_s-pJ_s\pmod{p^2}.}
\tag{12}
\]

So `J_s` is precisely the first `p`-adic defect of Hasse reflection.

# Integral scalar and height

Let `L_m=lcm(1,...,m)`. Then

\[
\widetilde J_s:=L_{2s}J_s\in\mathbf Z,
\]

and because `p>2s`,

\[
p\mid J_s\iff p\mid\widetilde J_s.
\tag{13}
\]

Also

\[
0<J_s\le2H_{2s}b_s.
\]

Using `b_s<=(s+1)64^s` and `log L_{2s}=2s+o(s)`,

\[
\boxed{\log|\widetilde J_s|\le(\log64+2)s+o(s).}
\tag{14}
\]

Thus a fixed-`q` exceptional prime `p\asymp_q n` must have `s>>_q log n`. This is a real but weak exclusion; targethood `p|b_s` already gives a comparable logarithmic lower bound.

# Fixed-q row counting

For `n=qp+r` let `s=min(r,p-1-r)`. The two folded branches are

\[
\boxed{p=(n-s)/q}\qquad(s=r),
\tag{15}
\]

and

\[
\boxed{p=(n+s+1)/(q+1)}\qquad(s=p-1-r).
\tag{16}
\]

Hence each integer `s` yields at most one candidate prime on each branch. For every `H`,

\[
\boxed{
\#\{p:\ s_p\le H,\ p\mid b_{s_p},\ p\mid J_{s_p}\}
\le2H+O_q(1),
}
\tag{17}
\]

and the logarithmic mass of this shallow part is `O_q(H log n)`. Therefore `H=o(n/log n)` is pointwise negligible.

This does **not** control the difficult proportional-depth range `s\asymp n`. A scalar-height charge fails because different candidate primes generally use different `s`; the Q3092 cancellation removed the private quotient `b_s/p`, but it did not remove the moving index.

# Exact arithmetic premise

The clean missing statement is the noncentral transversality theorem

\[
\boxed{
\text{(NCT)}\qquad
p>2s+1,\ p\mid b_s\Longrightarrow p\nmid J_s.
}
\tag{18}
\]

Equivalently,

\[
\boxed{P^+(\gcd(b_s,\widetilde J_s))\le2s+1.}
\tag{19}
\]

Equivalently, every distinguished target root `lambda_s` of `R_s mod p` is simple. By (3), (NCT) is also equivalent to saying that every noncentral mirror target has

\[
v_p(N_{p-1-2s}(s))=1.
\]

If (NCT) holds, the derivative-exceptional class is empty in every fixed-`q` row. This is the exact arithmetic premise isolated in the earlier Q3071 multiple-node audit; it is not currently proved.

This SageMath script checks the characteristic-zero formulas, Christoffel--Darboux specialization, and the two Q3092 fixtures. Finite output is verification only.

from sage.all import *
QX.<X> = PolynomialRing(QQ)
QT.<T> = PolynomialRing(QQ)

def rising(z,k):
    return prod(z+j for j in range(k))
def H(n):
    return sum(QQ(1)/j for j in range(1,n+1))
def lam(a):
    return a*(a+1)
def b(s):
    return ZZ(sum(binomial(s,k)^2*binomial(s+k,k)^2 for k in range(s+1)))
def J(s):
    return sum(QQ(2)*binomial(s,k)^2*binomial(s+k,k)^2*(H(s+k)-H(s-k))
               for k in range(s+1))
def Btr(s):
    return sum(rising(-X,k)^2*rising(X+1,k)^2/QQ(factorial(k)^4)
               for k in range(s+1))
def R(s):
    out=QT(0); pk=QT(1)
    for k in range(s+1):
        if k: pk *= T-lam(k-1)
        out += rising(QQ(-s),k)*rising(QQ(s+1),k)*((-1)^k)*pk/QQ(factorial(k)^4)
    return out
def F(h):
    out=QT(0); pk=QT(1)
    for k in range(h+1):
        if k: pk *= T-lam(k-1)
        out += (pk/QQ(factorial(k)^2))^2
    return out

for s in range(1,8):
    ls=lam(s); Rs=R(s)
    assert Btr(s)(s)==b(s)
    assert Btr(s).derivative()(s)==J(s)
    assert Rs(ls)==b(s)
    assert 2*(2*s+1)*Rs.derivative()(ls)==J(s)
    lhs=sum(QQ(2*k+1)*R(k)(ls)^2 for k in range(s))
    rhs=QQ(s^3)/2*(R(s-1)(ls)*Rs.derivative()(ls)-Rs(ls)*R(s-1).derivative()(ls))
    assert lhs==rhs

for p in [17,73]:
    h=(p-1)//2; FF=F(h)
    for s in range(1,h):
        assert FF(lam(s))==b(s)
        assert (2*s+1)*FF.derivative()(lam(s))==J(s)

# Cleared gap N_0=0,N_1=1.
def P(n): return 34*n^3+51*n^2+27*n+5
def Nval(s,d):
    if d==0: return ZZ(0)
    a,c=ZZ(0),ZZ(1)
    for h in range(1,d): a,c=c,ZZ(P(s+h))*c-ZZ(s+h)^6*a
    return c

def modq(x,p):
    x=QQ(x); den=ZZ(x.denominator())
    return ZZ(x.numerator())*den.inverse_mod(p)%p

# Build companion c_0=0,c_1=1.
def companion(N):
    c=[QQ(0),QQ(1)]
    for n in range(1,N):
        c.append((P(n)*c[n]-n^3*c[n-1])/QQ((n+1)^3))
    return c
c=companion(80)

for p,s in [(73,2),(17,3)]:
    d=p-1-2*s; Nd=Nval(s,d)
    Pi=prod(ZZ(s+j)^3 for j in range(1,d+1))
    assert b(s)%p==0 and Nd%p==0
    assert (Nd//p)%p == (Pi%p)*modq(c[s],p)*modq(J(s),p)%p
    assert modq(J(s),p)!=0 and Nd%(p^2)!=0

print('PASS Q3112')

# Bottom line

The derivative scalar is

\[
\boxed{J_s=\mathcal B_s'(s)=2(2s+1)\mathcal R_s'(s(s+1)).}
\]

Conditional on `p|b_s`, its vanishing is exactly a repeated Newton--Racah/Jacobi node, equivalently a vanishing Christoffel--Darboux crossing norm, equivalently a second mirror-continuant lift. It is a harmonic/reflection derivative, not presently a K3 Hasse-invariant derivative, Fermat quotient, or supersingularity criterion.

The first exact missing theorem is (NCT). Without such an Apéry-specific simplicity theorem, the scalar still moves with `s`, so its individual characteristic-zero height does not give a sublinear fixed-row aggregate.
