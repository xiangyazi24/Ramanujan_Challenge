# 6. Toeplitz rank-one determinant for Xi_r

There is a second exact classification which does not use the rank-five recurrence.

For `r>=0`, let `T_r` be the `(r+1) x (r+1)` lower-triangular Toeplitz matrix

```text
(T_r)_{i,j} = h_{i-j}  if i>=j,
              0        if i<j,                    (6.1)
```

with indices `0,...,r`. Since `h_0=1`,

```text
det T_r=1.                                        (6.2)
```

Because `C=1/W`, its inverse is the reciprocal Toeplitz matrix

```text
(T_r^{-1})_{i,j}=g_{i-j}  if i>=j.                (6.3)
```

Let

```text
e_0=(1,0,...,0)^T,
v_r=(0,b_0,b_1,...,b_{r-1})^T.                    (6.4)
```

Define the rank-one pencil

```text
Q_r(z)=T_r+z e_0 v_r^T.                            (6.5)
```

The matrix determinant lemma and (6.3) give

```text
det Q_r(z)
 =1+z v_r^T T_r^{-1} e_0
 =1+z sum_{m=1}^r g_m b_{m-1}.                    (6.6)
```

Therefore

```text
det Q_r(5)=-Xi_r.                                 (6.7)
```

This is an exact finite determinant representation of the entire cumulative transverse sum.

## 6.1 The singularity is always simple

Let `p!=5` and suppose `p|Xi_r`. From (6.6), at `z=5`,

```text
sum_{m=1}^r g_m b_{m-1} == -1/5 mod p.            (6.8)
```

Hence

```text
(d/dz) det Q_r(z) at z=5 == -1/5 != 0 mod p.      (6.9)
```

Thus `z=5` is a simple determinant root. Since `T_r` is invertible and (6.5) is a rank-one update, `Q_r(5)` has corank exactly one.

This proves a general discriminant no-go for the canonical local determinant: **an Xi-zero is never a multiple-root/discriminant event at a prime p!=5.**

# 9. Complete no-go for a second invariant from the same forced recurrence

This part is fully symbolic and does not use the finite counterexamples.

Let `lambda_r` be any rational sequence satisfying exactly the same forced recurrence as `kappa_r`:

```text

               -(r-1)^3 lambda_{r-2}-5g_r.       (9.1)
```

Then `u_r=lambda_r-kappa_r` satisfies the homogeneous Apery recurrence. Since `a,b` are independent by the nonzero Casoratian (1.1), there are unique constants `x,y in Q` such that

```text
lambda_r=kappa_r+x a_r+y b_r.                     (9.2)
```

Form the natural transverse Casoratian against `b`:

```text
Xi_r(lambda)
 := r^3(lambda_r b_{r-1}-lambda_{r-1}b_r).        (9.3)
```

Using (1.1),(1.2),(9.2),

```text
Xi_r(lambda)=Xi_r+6x.                              (9.4)
```

## Consequences

- If `x=0`, the supposed second invariant is exactly `Xi_r`; the `y b` direction contributes no Casoratian.
- If `x!=0`, clear the fixed denominator by writing `x=A/B` in lowest terms. Then

```text
B Xi_r(lambda)=B Xi_r+6A.                          (9.5)
```

At a common target/transverse prime with `p|Xi_r`, the right side is `6A mod p`. Thus, away from the fixed finite set of primes dividing `6AB`, the new invariant is a unit, not another zero.
- For two same-forcing solutions with parameters `x_1,x_2`, any prime simultaneously dividing both cleared Casoratians outside denominator primes must divide the fixed rational difference `6(x_1-x_2)`.

Therefore:

> **Same-forcing second-invariant no-go.** No independent solution of the same forced second-order recurrence can produce a new systematic vanishing condition on the locus `p|b_r, p|Xi_r`. The only member of the class that vanishes there for all admissible primes is the original Xi direction itself, up to the irrelevant homogeneous `b` shift.

For example the explicit independent shift

```text

```

has

```text

```

At every common prime `p>=7` except possibly `p=2,3`, it is exactly `48 mod p`, hence a unit.

This closes the most natural "second recurrence invariant" route completely.

Likewise, for every fixed rational `x`,

```text
log|Xi_r+6x|=2r log(alpha)+O(log r).               (11.6)
```

The Toeplitz determinant is exactly `-Xi_r`, so it has the same height.

Therefore any product over `r<=T` of one nonzero canonical local carrier from these classes has logarithmic height of order `T^2`. For the endpoint resultant itself,

```text
sum_{r<=T} log|E_r|
 = log(alpha) T^2 + O(T log T).                    (11.7)
```

This is a rigorous scoped no-go: the exact local elimination has not produced an `exp(o(r))` per-index carrier.

# 12. Aggregate M_T: exact reduction and unconditional height

Recall

```text
M_T = rad lcm_{1<=r<=T} gcd(b_r,Xi_r).             (12.1)
```

Split its prime support into `p<=T` and `p>T`.

All distinct primes `p<=T` together contribute at most

```text
theta(T)=sum_{p<=T} log p = O(T).                  (12.2)
```

For `p>T` and `r<=T`, automatically `p>r`; hence every theorem in Sections 5-9 applies.

Define the hard part

```text
M_T^hard
 = product over primes p>T such that
   p|b_r and p|Xi_r for some 1<=r<=T.              (12.3)
```

Then exactly at the level of radicals,

```text
log M_T <= O(T)+log M_T^hard.                      (12.4)
```

By the endpoint resultant theorem,

```text
p|M_T^hard
 iff p>T and p|b_r and p|E_r for some r<=T.        (12.5)
```

This is the corrected residual proposition: all hard common primes are common divisors of the target selector and a prefix-only resultant.

Unconditionally, every hard prime divides at least one `b_r`, so

```text
M_T^hard | rad(product_{r=1}^T b_r).               (12.6)
```

Using

```text
log b_r=r log(alpha)+O(log r),                     (12.7)
```

we obtain the real characteristic-zero height bound

```text
log M_T
 <= (log(alpha)/2) T^2 + O(T log T).               (12.8)
```

This is the best unconditional aggregate bound obtained here. It is quadratic, not subquadratic.

Trying instead to absorb the hard primes with the endpoint resultants gives the weaker raw height

```text
sum_{r<=T} log|E_r|
 = log(alpha) T^2+O(T log T).                      (12.9)
```

so the resultant's value is structural elimination, not archimedean compression.

# 13. Corrected residual theorem and remaining conjecture

The preceding sections prove the following clean theorem.

## Theorem 13.1 -- hard transverse residual

For every `r>=1`, define

```text
E_r=Xi_r-5b_{r-1}b_r.
```

Then:

```text
(a) gcd(b_r,Xi_r)=gcd(b_r,E_r) exactly.

(b) E_r is the exact resultant of the target and transverse affine
    selectors after eliminating the newest coefficient h_r of
    W=F^2 sqrt(Delta).

(c) For every prime p>r common to b_r and Xi_r, the rank-five
    endpoint pivot r^5, b_{r-1}, and 5 are p-units. The common
    endpoint is simple.

(d) The same common event is equivalent to the corank-one Toeplitz
    condition in Theorem 7.1; it is not a multiple-root determinant
    condition.

(e) Every same-forcing second Casoratian is Xi_r+6x, so no
    independent invariant in that class supplies another systematic
    zero.

(f) log|E_r|=2r log(alpha)+O(log r), so this exact resultant does
    not have subexponential height.
```

Consequently the requested `o(T^2)` bound is **not proved** by the present local algebra.

The remaining arithmetic statement can now be formulated without ambiguity as either

```text
Pointwise residual conjecture:
log rad_{p>r} gcd(b_r,E_r) = o(r),                 (13.1)
```

which is exactly equivalent to the old Xi formulation by (4.4), or the weaker aggregate statement actually needed here,

```text
Aggregate residual conjecture:
log M_T^hard = o(T^2).                             (13.2)
```

These are conjectures, not consequences of the endpoint/Toeplitz theory.

The theorem-level advance is that several tempting mechanisms are now closed:

- fixed level-6 ramification/discriminant;
- local transfer discriminant;
- determinant multiplicity of the canonical Xi pencil;
- recurrence-row content;
- another solution of the same forced second-order recurrence;
- the canonical newest-endpoint resultant as a low-height carrier.

Any proof of (13.1) or (13.2) must add genuinely cross-index arithmetic information. That is a scoped statement about what the exact local identities can and cannot do, not a heuristic independence claim.

The following script checks all algebraic identities that are numerical/finite in nature. The theorem proofs above do not depend on the scan.

```gp

/* b[k+1] is b_k */
b = vector(N+1);
b[1] = 1;
b[2] = 5;

/* Exact reciprocal series g and its inverse W. */

assert(vector(4,k,g[k]) == [1,7,192,5520]);

);

  assert(subst(Xr,X,h[r+1]) == xi[r+1]);

         gcd(abs(b[r+1]),abs(xi[r+1])));

  if(i>=j,h[i-j+1],0)

  if(i==1,z*Vrow(r)[j],0)
);
for(r=1,25,
  assert(matdet(Qmat(r,5)) == -xi[r+1])
);

/* Companion solution a and forced solution kappa. */
M = 80;
a = vector(M+1);
a[1] = 0;
a[2] = 6;
kap = vector(M+1);
kap[1] = 0;
kap[2] = -36;
for(r=2,M,
  a[r+1] = (P(r-1)*a[r] - (r-1)^3*a[r-1])/r^3;
  kap[r+1] = (P(r-1)*kap[r] - (r-1)^3*kap[r-1]

for(r=1,M,

cs = [-7,1,8];
for(ii=1,#cs,
```

# 15. Theorem / conjecture / data boundary

## Proved

- `b_r` is an affine unit-slope selector in the newest endpoint `h_r` of `W=F^2 sqrt(Delta)`.
- `Xi_r` is affine in the same endpoint, with slope `5b_{r-1}`.
- Their exact endpoint resultant is `E_r=Xi_r-5b_{r-1}b_r`, independent of `h_r`.
- `gcd(b_r,Xi_r)=gcd(b_r,E_r)` exactly.
- The exact rank-five recurrence produces the 3-by-2 resultant matrix (5.5) and syzygy (5.9).
- At every common prime `p>r`, all three endpoint pivots are units.
- `Xi_r=-det Q_r(5)` for the explicit Toeplitz rank-one pencil.
- Every `p!=5` Xi-zero is a simple determinant zero; no canonical discriminant multiplicity occurs.
- Theorem 7.1 gives a necessary and sufficient corank-one/null-endpoint classification of `p|b_r,Xi_r` for `p>r`, `p>=7`.
- Every same-forcing second Casoratian is `Xi_r+6x`; this entire natural second-invariant class is exhausted.
- The fixed level-6 discriminant, local transfer discriminant, and Hasse branch do not classify the exact exceptions.
- `log|E_r|=2r log(alpha)+O(log r)`; the exact endpoint resultant has no subexponential height saving.
- `log M_T <= (log(alpha)/2)T^2+O(T log T)`.

## Exact finite data, not promoted to an asymptotic theorem

- Through `r=5000`, the only common pairs with `p>r` are `(13,17)` and `(492,2237)`.
- No `p>5r` example occurs in that range.

## Not proved

- `log M_T=o(T^2)`.
- `log rad_{p>r}gcd(b_r,Xi_r)=o(r)`.
- Any universal constant `C` for which `p>Cr` excludes all common primes.
- A fixed algebraic discriminant outside the natural canonical classes ruled out above.

The corrected residual proposition is therefore exact but genuinely arithmetic: control the cross-index prime support of the prefix resultants `E_r` (equivalently of the original transverse gcds). The local Picard-Fuchs, rank-five Smith, endpoint resultant, and same-forcing Casoratian algebra by themselves do not supply the required aggregate saving.
