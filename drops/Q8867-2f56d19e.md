# Reimer inequality and CRT triple indicators: exact refutation and the surviving random-model statement

## Verdict

The proposed Reimer route **does not close Palm-3**. The common-space lift is a legitimate way to manufacture a product probability space, but two decisive claims fail:

1. the statistic called `N_S` in the question is only an **existence indicator**, whereas the deterministic third factorial moment counts **all** landed CRT root triples; and
2. after lifting to `Z/QZ`, the events for two triples have many **common global atoms**. Hence ordinary intersection is not disjoint occurrence. In fact the lifted triple indicators are positively, not negatively, correlated.

There is a useful exact salvage: the artificial common-lift model does have variance of order `M e_3` when the total complete-period density is bounded. That follows from an explicit positive-covariance calculation, not from negative association. It gives concentration for a random scattered subset of `Z/QZ`; it gives no information about the fixed initial interval `[0,M)`. Any transference or coupling strong enough to recover that interval is the original Palm-3/discrepancy problem.

## 1. First correction: a prime triple can contribute more than one row

Write

\[
\eta_p=\frac{|Z_p|}{p},\qquad
\Omega_p=\{0\le m<M:m\bmod p\in Z_p\},
\qquad f_p(m)=\mathbf 1_{\Omega_p}(m).
\]

For an unordered prime triple `S={p,q,r}`, let

\[
C_S:=|\Omega_p\cap\Omega_q\cap\Omega_r|.
\]

Equivalently,

\[
C_S=
\sum_{(z_p,z_q,z_r)\in Z_p\times Z_q\times Z_r}
\mathbf 1_{\{\operatorname{CRT}(z_p,z_q,z_r)<M\}}.
\]

Because `pqr>M`, a **fixed root triple** has at most one representative below `M`. This does **not** imply that the whole prime triple has at most one representative: two different root triples can yield two different integers below `M`. Thus in general

\[
0\le C_S\le |Z_p||Z_q||Z_r|,
\]

not merely `C_S in {0,1}`.

The unordered third factorial count is

\[
F_3^{\mathrm{unord}}
=\sum_{p<q<r}C_{\{p,q,r\}}
=\sum_{m<M}\binom{K(m)}3.
\]

The repository uses ordered tuples:

\[
F_3^{\mathrm{ord}}
=\sum_{m<M}(K(m))_3
=6F_3^{\mathrm{unord}}.
\]

By contrast, the question defines

\[
I_S:=\mathbf 1_{\{C_S>0\}},
\qquad H_3:=\sum_{|S|=3}I_S.
\]

Only

\[
H_3\le F_3^{\mathrm{unord}}
\]

is automatic. A concentration theorem for `H_3` does not control multiplicity in `F_3`. The gap disappears only under an additional theorem saying `C_S<=1`, or under a uniform bound on all `|Z_p|` strong enough for the desired application; neither is present in the current source.

This also separates two randomizations:

- If one assigns independent Bernoulli variables to each pair `(S, root tuple)`, then the random **count** is a binomial sum and different prime triples are independent by construction. This simply deletes all cross-triple CRT compatibility.
- If one lifts to one global residue space in order to retain compatibility, the events cease to be independent and acquire common witnesses.

## 2. The common lift is well-defined, but it changes the model

Let `P` be the set of shell primes under consideration and

\[
Q=\prod_{p\in\mathcal P}p,
\qquad \theta=\frac{M}{Q}.
\]

For a triple `S`, define its global cylinder

\[
U_S=
\{a\in\mathbb Z/Q\mathbb Z:
 a\bmod p\in Z_p\text{ for every }p\in S\}.
\]

CRT gives

\[
|U_S|=Q\eta_S,
\qquad
\eta_S:=\prod_{p\in S}\eta_p.
\]

Let `(B_a)_{a mod Q}` be independent Bernoulli variables with parameter `theta`, and put

\[
I_S^{\mathrm{lift}}
=\mathbf 1_{\{\exists a\in U_S:B_a=1\}}.
\]

Then, exactly,

\[
\mathbb P(I_S^{\mathrm{lift}}=1)
=1-(1-\theta)^{Q\eta_S}.
\tag{2.1}
\]

If

\[
\mu_S=M\eta_S,
\]

then (2.1) is

\[
1-e^{-\mu_S}+o(1),
\]

not exactly `mu_S`. In the rare-event regime `mu_S=o(1)` this is

\[
\mu_S+O(\mu_S^2).
\]

The enormous size of `Q` is not itself an obstruction: the tiny parameter `theta=M/Q` is balanced by the cylinder size `Q eta_S`. The structural problems are instead:

1. the selected set `{a:B_a=1}` is a random scattered subset of expected size `M`, not the consecutive interval `[0,M)`;
2. the lift does not exactly preserve the local law `Bernoulli(M/P_S)` for each root class; a root-class cylinder has hit probability
   \[
   1-(1-M/Q)^{Q/P_S},
   \]
   which is only asymptotic to `M/P_S`; and
3. different triple cylinders overlap heavily.

For the actual count rather than existence, one would need, for every local root class `c mod P_S`, the indicator that its whole cylinder contains a selected global atom, and then sum those indicators over all root classes. Taking one maximum over `U_S` again collapses multiplicity.

## 3. The witness claim is false: one global atom can witness both triples

Let `S` and `T` be distinct triples. The key identity is

\[
\boxed{U_S\cap U_T=U_{S\cup T}.}
\tag{3.1}
\]

If all involved zero sets are nonempty, CRT makes `U_{S union T}` nonempty, even when `S` and `T` are disjoint as sets of primes.

For the case in the question,

\[
S=\{p,q,r\},\qquad
T=\{p,q',r'\},
\]

choose one common root `z_p in Z_p` and arbitrary roots in

\[
Z_q,Z_r,Z_{q'},Z_{r'}.
\]

CRT gives a unique class modulo

\[
pqq'rr'
\]

satisfying all five congruences. Every extension of that class modulo `Q` lies in both `U_S` and `U_T`. Thus a single coordinate `B_a=1` can certify both events.

The sentence

```text
if the shared p-root is the same, then a and a' must differ because
one uses q,r and the other uses q',r'
```

has the direction reversed. A global residue has coordinates modulo **all** primes simultaneously, so it can satisfy the `q,r,q',r'` conditions at once.

For particular local root classes whose shared `p`-roots differ, the two lifted cylinders are disjoint. But the event `I_S` is a union over all root choices, and all pairs with the same shared `p`-root produce common global atoms.

## 4. Exact covariance: the lifted events are positively correlated

Put

\[
s=1-\theta,\qquad
u=|U_S|,\qquad v=|U_T|,\qquad
w=|U_S\cap U_T|.
\]

For the OR-events

\[
A=\{I_S^{\mathrm{lift}}=1\},
\qquad B=\{I_T^{\mathrm{lift}}=1\},
\]

inclusion-exclusion gives

\[
\mathbb P(A\cap B)
=1-s^\nu-s^v+s^{\nu+v-w}.
\]

Since

\[
\mathbb P(A)\mathbb P(B)
=1-s^\nu-s^v+s^{\nu+v},
\]

one obtains the exact formula

\[
\boxed{
\operatorname{Cov}(I_S^{\mathrm{lift}},I_T^{\mathrm{lift}})
=s^{\nu+v-w}(1-s^w)>0
}
\tag{4.1}
\]

whenever `w>0` and `0<theta<1`.

This also follows qualitatively from Harris-FKG: both events are increasing functions of independent Bernoulli coordinates, so their ordinary intersection is positively associated.

### Why Reimer does not contradict (4.1)

Reimer's theorem bounds

\[
\mathbb P(A\square B)
\le \mathbb P(A)\mathbb P(B),
\]

where `A square B` means occurrence with disjoint certificate coordinate sets. It does **not** replace `A intersection B` by `A square B`.

For these OR-events, `A intersection B` fails to be disjoint occurrence exactly when there is only one occupied coordinate in `U_S union U_T` and that coordinate lies in the overlap `U_S intersection U_T`. Consequently

\[
\mathbb P((A\cap B)\setminus(A\square B))
=w\theta s^{\nu+v-w-1}.
\tag{4.2}
\]

Reimer therefore yields only

\[
\operatorname{Cov}(I_S^{\mathrm{lift}},I_T^{\mathrm{lift}})
\le w\theta s^{\nu+v-w-1},
\]

not a nonpositive covariance statement. Directly from (4.1),

\[
\operatorname{Cov}(I_S^{\mathrm{lift}},I_T^{\mathrm{lift}})
\le \theta w.
\tag{4.3}
\]

Using (3.1),

\[
\theta w
=M\prod_{p\in S\cup T}\eta_p.
\tag{4.4}
\]

Thus the common-witness contribution is exactly a higher-order CRT density.

Reimer's inequality is perfectly valid here; it is simply an inequality for the wrong event if one substitutes ordinary intersection for disjoint occurrence.

## 5. A useful salvage: the artificial random model still has `O(M e_3)` variance

Although the covariance sign in the question is wrong, (4.3) gives an explicit variance bound.

Let

\[
H_3^{\mathrm{lift}}=
\sum_{|S|=3}I_S^{\mathrm{lift}},
\qquad
\Lambda=\sum_p\eta_p.
\]

The diagonal terms satisfy

\[
\operatorname{Var}(I_S^{\mathrm{lift}})
\le \mathbb E I_S^{\mathrm{lift}}
\le M\eta_S.
\]

For two distinct triples, their union has size `4`, `5`, or `6`. For a fixed union:

- a 4-set supports `6` unordered pairs of triples sharing two primes;
- a 5-set supports `15` unordered pairs sharing one prime;
- a 6-set supports `10` unordered disjoint pairs.

Therefore

\[
\boxed{
\operatorname{Var}(H_3^{\mathrm{lift}})
\le
M\bigl(e_3(\eta)+12e_4(\eta)+30e_5(\eta)+20e_6(\eta)\bigr).
}
\tag{5.1}
\]

The elementary-symmetric inequality

\[
(k+1)e_{k+1}(\eta)\le \Lambda e_k(\eta)
\]

gives

\[
\operatorname{Var}(H_3^{\mathrm{lift}})
\le
M e_3(\eta)
\left(1+3\Lambda+\frac32\Lambda^2+\frac16\Lambda^3\right).
\tag{5.2}
\]

Hence if `Lambda=O(1)`, and in particular in the observed sparse regime, the lifted existence statistic has variance `O(M e_3)`.

Its mean obeys

\[
0\le M e_3(\eta)-\mathbb EH_3^{\mathrm{lift}}
\le \frac12\sum_{|S|=3}(M\eta_S)^2.
\]

If

\[
\mu_*:=\max_{|S|=3}M\eta_S,
\]

then

\[
0\le M e_3(\eta)-\mathbb EH_3^{\mathrm{lift}}
\le \frac{\mu_*}{2}M e_3(\eta).
\tag{5.3}
\]

Thus, under `mu_*=o(1)`, Chebyshev indeed gives concentration of this random existence statistic near `M e_3(eta)`, with a `Lambda`-dependent constant.

This is not Palm-3. It is a complete-product model calculation.

### Equivalent iid-row interpretation

The same polynomial in (5.1) appears even more transparently if one samples `M` independent uniform residues `A_1,...,A_M mod Q`. For one random residue, the prime-hit indicators are exactly independent by CRT. If

\[
X(A)=\binom{K(A)}3,
\]

then

\[
\mathbb EX(A)=e_3(\eta)
\]

and

\[
\mathbb EX(A)^2
=e_3(\eta)+12e_4(\eta)+30e_5(\eta)+20e_6(\eta).
\]

Therefore the iid-row model has the natural variance scale. The real sequence

\[
0,1,2,\ldots,M-1
\]

is not an iid sample from `Z/QZ`; proving that it behaves like one for these zero cylinders is precisely the missing short-interval correlation theorem.

## 6. Why the random model does not transfer to the deterministic interval

Let

\[
y_a=\mathbf 1_{\{0\le a<M\}}
\]

be the deterministic interval configuration in `Z/QZ`, and let `B=(B_a)` have the product law above.

### 6.1 The observed configuration is astronomically atypical

The probability that the Bernoulli array equals the interval exactly is

\[
\mathbb P(B=y)
=\theta^M(1-\theta)^{Q-M}.
\]

This is negligible. Concentration for typical Bernoulli configurations says nothing about this one configuration.

### 6.2 The Hamming coupling error is macroscopic

Because `y` is deterministic, every coupling has

\[
\begin{aligned}
\mathbb E\sum_{a\bmod Q}|B_a-y_a|
&=M(1-\theta)+(Q-M)\theta\\
&=2M\left(1-\frac MQ\right)
\sim2M.
\end{aligned}
\tag{6.1}
\]

So the two selected sets are not close even as unweighted subsets.

### 6.3 There is no monotone domination

The deterministic interval cannot be stochastically dominated by the Bernoulli set coordinatewise: for `a<M`, its occupancy probability is `1`, whereas the Bernoulli occupancy is `theta`. Conversely, the Bernoulli set cannot be dominated by the interval, because for `a>=M` the interval occupancy is `0` and the Bernoulli occupancy is positive.

Thus no coupling can give

\[
y\le B
\quad\text{or}\quad
B\le y
\]

with probability one. An increasing-statistic comparison does not follow.

### 6.4 One changed row can have enormous influence

For the real third factorial statistic, adding or deleting a row `a` changes the row-sum model by

\[
\binom{K(a)}3.
\]

There is no uniform small-Lipschitz constant. A row hit by `L` primes has influence `binom(L,3)`.

This is exactly what the repository's anchored-star construction exploits. In `prop:hm3-anchored-star`, nearly `X/log X` active primes all mark one row `m_0`. Hence

\[
K(m_0)\asymp\frac{X}{\log X},
\qquad
F_3^{\mathrm{unord}}(y)
\ge \binom{K(m_0)}3
\asymp\frac{X^3}{(\log X)^3},
\]

whereas the independent baseline is only

\[
M e_3(\eta)
\asymp\frac{X^2}{(\log X)^3}.
\]

The Bernoulli lift includes the special coordinate `m_0` with probability only `theta=M/Q`, essentially zero. With overwhelming probability it deletes the entire deterministic hotspot. Thus the coupling discrepancy can be larger than the desired main scale by a factor of order `X`.

This anchored-star family is not asserted to be the true Apéry zero family. It proves that CRT, sparse root sets, reflection, the current second-moment estimate, bounded row codegrees, and the other coarse inputs in the source do not imply the proposed transference.

## 7. The natural randomization is a random interval shift—and it exposes the circularity

There is a random model that preserves interval geometry. Choose `T` uniformly in `Z/QZ` and let

\[
I_T=\{T,T+1,\ldots,T+M-1\}\pmod Q.
\]

Let `C_S(T)` count members of `I_T` lying in `U_S`. Double counting gives the exact average

\[
\frac1Q\sum_{T\bmod Q}C_S(T)
=M\eta_S.
\]

Consequently

\[
\mathbb E_T F_3^{\mathrm{unord}}(T)
=M e_3(\eta).
\tag{7.1}
\]

This is the cleanest probabilistic interpretation of the main term. But:

- the coordinate process `1_{a in I_T}` is not a product process;
- Reimer's product-space theorem does not apply;
- Chebyshev over shifts would at most show that most shifts are good;
- the actual interval is the single shift `T=0`, with probability `1/Q` in this ensemble.

Proving that `T=0` is typical, or bounding it uniformly over `T`, is exactly a short-interval discrepancy theorem. The anchored-star construction makes the shift containing `m_0` exceptional, showing why an average over shifts cannot be specialized for free.

## 8. A “deterministic negative association” hypothesis is Palm-3 itself

A single deterministic configuration does not possess a probabilistic covariance until one declares an averaging measure. The most relevant one is to choose `U` uniformly from `[0,M)` and define

\[
X_p=f_p(U).
\]

Then

\[
\mathbb EX_p=\frac{|\Omega_p|}{M}
\]

and

\[
\mathbb E(X_pX_qX_r)=\frac{C_{\{p,q,r\}}}{M}.
\]

If the family `(X_p)` were negatively associated strongly enough to give

\[
\mathbb E(X_pX_qX_r)
\le
\mathbb EX_p\,\mathbb EX_q\,\mathbb EX_r
\tag{8.1}
\]

for every triple, then summing (8.1) would immediately yield

\[
F_3^{\mathrm{unord}}
\le
M e_3\left(\left(\frac{|\Omega_p|}{M}\right)_p\right),
\]

which is stronger than the required Palm-3 upper bound after the one-column normalization comparison already proved in `hm3_result.tex`.

Thus a deterministic negative-association theorem is not a free analogue of Reimer; it is essentially a direct solution of the problem.

The anchored-star proposition also shows that (8.1) is false for general CRT zero sets satisfying all current coarse constraints. There each active triple has

\[
\mathbb E(X_pX_qX_r)\ge\frac1M\asymp X^{-2},
\]

while each marginal is of order `1/X`, so the product of three marginals is of order `X^{-3}`. The joint hit is larger by a factor of order `X`.

### Pairwise zero-zero conditions are not enough

The zero-zero count written in the question is ambiguous:

- if `c` and `c'` are sampled independently from two sets, the pair count factorizes tautologically;
- if they must be the same global atom, the statement is an intersection-discrepancy inequality.

In either interpretation it is not a consequence of CRT. Moreover, pairwise negative correlation alone would not control the third factorial moment. The source's anchored-star model has a natural global centered second moment and bounded codegrees but an excessive third moment. Palm-3 requires a third-order or conditional statement.

The exact conditional residual is already isolated in `thm:hm3-palm-characterization`. With ordered anchors,

\[
J_{p,q}=|\Omega_p\cap\Omega_q|,
\]

and

\[
T_{p,q}
=\sum_{m\in\Omega_p\cap\Omega_q}
  \sum_{\ell\ne p,q}f_\ell(m).
\]

The missing arithmetic is the aggregate overload

\[
\sum_{p\ne q}
\left(
T_{p,q}-J_{p,q}\mu_{p,q}
\right)_+,
\qquad
\mu_{p,q}
=\sum_{\ell\ne p,q}\frac{|\Omega_\ell|}{M}.
\]

The complete-product random model makes the conditional third-prime density equal to its marginal by construction. The fixed interval does not. Reimer supplies no bridge between them.

## 9. Direct answers to the six questions

### 1. Does the common-space lift work, despite enormous `Q`?

It works as a finite product probability space. Tiny atom probability is balanced by huge cylinder size, so event probabilities remain of order `M eta_S`. However, it is not an exact lift of the local Bernoulli model, it models a scattered random subset rather than an interval, and its `max` observable counts existence rather than the actual triple multiplicity.

The size of `Q` is not the fatal point; the change of geometry and the common-cylinder overlaps are.

### 2. Are witnesses for overlapping triples always disjoint, giving nonpositive covariance?

No. The identity

\[
U_S\cap U_T=U_{S\cup T}
\]

shows that one global residue can witness both triples. For nonempty zero sets this overlap is nonempty even for disjoint prime triples. The exact covariance is (4.1) and is strictly positive. Reimer bounds only the subset of configurations with two disjoint certificates.

### 3. Does negative covariance imply `Var(F_3)<=M e_3` in the random model?

The premise is false. Nevertheless, the explicit positive overlap terms give the valid bound (5.1), and hence `Var=O(M e_3)` when `Lambda=sum eta_p=O(1)`. Chebyshev then gives concentration for the artificial random model around its own mean.

This says nothing deterministic. It also concerns the existence statistic unless multiplicities are restored.

### 4. Does the random negative-association structure inform the deterministic CRT interval?

No. There is no such negative-association structure for the lifted OR-events; they are positively associated. More fundamentally, the product model samples typical residues from the full CRT product, whereas `[0,M)` is one fixed, highly structured short interval. Showing that this interval has typical complete-product statistics is the original discrepancy problem.

### 5. Is there a deterministic version of negative association for the CRT images?

Not from CRT alone. Full negative association of the prime-hit variables under the uniform measure on `[0,M)` would immediately imply Palm-3 and is therefore stronger than the target. Pairwise zero-zero inequalities are insufficient for a third moment. The repository's anchored-star proposition is an exact counterexample to any generic deterministic-NA theorem based only on the current local and pairwise inputs.

### 6. Can one couple the observed interval below the random model plus a small error?

No generic coupling has small error. The expected symmetric difference is asymptotic to `2M`, neither coordinatewise stochastic domination is possible, and one mismatched high-incidence row can change the third factorial count by `binom(K(m),3)`. Controlling that weighted coupling error requires precisely the high-incidence/Palm-3 estimate one is trying to prove.

Also, a variance estimate never proves the pointwise statement

\[
F_3^{\mathrm{rand}}\le M e_3
\]

for every random outcome. It proves only that most outcomes lie in a stated window. There is no reason the fixed interval is one of those outcomes.

## 10. Final route assessment

The proposed argument fails before the deterministic-transference step:

```text
ordinary intersection != disjoint occurrence,
Cov(I_S,I_T) > 0,
and the max-over-classes statistic is not the actual F_3.
```

The common lift does yield a clean random-model theorem:

\[
\operatorname{Var}(H_3^{\mathrm{lift}})
\le
M\bigl(e_3+12e_4+30e_5+20e_6\bigr),
\]

and therefore the expected `M e_3` scale is typical for complete-product random sampling. But that theorem merely records the exact independence of prime coordinates under a uniform full-period CRT residue.

The fixed short interval is the entire arithmetic difficulty. Any one of the following would close the gap, but each is a renamed or stronger form of Palm-3:

1. a uniform-shift discrepancy theorem placing `T=0` at the complete-product mean;
2. negative association of the prime-hit field under the uniform measure on `[0,M)`;
3. a coupling whose **weighted** error is `O(M lambda_X^3)`; or
4. the existing finite pair-Palm positive-excess bound from `thm:hm3-palm-characterization`.

Reimer's inequality supplies none of these. The source-faithful residual remains the aggregate conditional overload of third primes on actual landed two-prime CRT loci.
