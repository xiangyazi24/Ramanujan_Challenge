# Quotient-six C4: audit of the upper-window second moment

## Source and notation boundary

This audit uses the current `chatgpt-drop` Q7344 statement and its banked numerical ledger.  In particular,

```text
L       = log T,
B       = T^2/L^2,
F_0     <<_J T^(13/5)L^(-9/5),
U_0     <<_J T^(8/5)L^(-4/5).
```

Here `B` is the required **unweighted** Boolean marked-incidence scale.  The literal C4 sum carries one factor `log p asymp L`, so

```text
Cminus+Cplus=o_J(T^2/L)
```

follows from

```text
M_vee=o_J(B).
```

All factorial moments below use ordered pairs.  Replacing them by unordered pairs changes only an absolute factor.

For an upper prime `q`, let

```text
T(q) = {t:
        0<=t<q,
        q|b_t,
        all deterministic upper masks hold,
        and at least one numerical lower-p window is nonempty,
        before imposing any lower-p Apéry zero condition},

w(q)=#T(q).
```

Thus `w(q)` is Q7344's pre-lower-mark upper-window occupancy.  Let

```text
kappa(q,t) = Boolean-union lower-prime load of the state (q,t),
U_q        = #{t in T(q): kappa(q,t)>0},
M_q        = sum_t kappa(q,t),
F_q        = sum_t kappa(q,t)(kappa(q,t)-1).
```

Globally,

```text
U=sum_q U_q,
M=sum_q M_q,
F=sum_q F_q.
```

The full upper Apéry zero-set size is denoted by

```text
Z(q)=#{0<=t<q:q|b_t}.
```

Pointwise,

```text
U_q<=w(q)<=Z(q).                                      (0.1)
```

The banked zero-set moment named in the question is

```text
Z_2(T):=sum_(ell in I prime) Z(ell)^2
       << T^(11/5)L^(-3/5),
I=(T/7,T/3].                                           (0.2)
```

The variable `ell` in `(0.2)` is deliberately neutral.  For every quotient-six row,

```text
q=p+d>p>T/7,
q<=(2T-p)/6<(2T-T/7)/6=13T/42<T/3.
```

Hence the upper modulus `q` also lies in `I`.  Therefore, if `(0.2)` is literally the pure shell theorem stated in the question, it applies to the upper `q` variable without any change of marginal.  A warning about a “wrong marginal” would be justified only for a theorem containing additional lower-row conditioning not present in `(0.2)`.

## 1. First-principles state-adaptive closure

For one occupied state, `kappa>=1`, and

```text
(kappa-1)^2<=kappa(kappa-1).
```

Consequently

```text
(M-U)^2
 = (sum_(occupied states)(kappa-1))^2
 <= U sum_(occupied states)(kappa-1)^2
 <= UF.                                                (1.1)
```

Thus

```text
M<=U+sqrt(UF).                                         (1.2)
```

The banked bound `U<=U_0=o(B)` disposes of the first term.  If only the global factorial envelope `F<=F_0` is used, then a support carrier `V>=U` closes the gate whenever

```text
V=o_J(U_*),
U_*:=B^2/F_0.                                          (1.3)
```

Indeed,

```text
sqrt(UF)<=sqrt(VF_0)=o(B).
```

The scale in `(1.3)` is

```text
U_*
 = (T^4 L^(-4))/(T^(13/5)L^(-9/5))
 = T^(7/5)L^(-11/5).                                  (1.4)
```

There is no missing extra factor of `L`.  The one native prime-log weight was already removed when the target was converted from `T^2/L` to `B=T^2/L^2`.  The upper condition `q|b_t` is a Boolean state condition, not another automatic `1/L` factor.

Also

```text
U_*/B=T^(-3/5)L^(-1/5)->0,                             (1.5)
```

so `(1.3)` automatically implies the required singleton-support condition `V=o(B)`.

## 2. Derivation of the Q7344 exponent `9/5,-17/5`

Let

```text
Q_T={relevant upper primes q},
N=#Q_T <<_J T/L,
S_2^w=sum_(q in Q_T) w(q)^2,
V=sum_(q in Q_T) w(q).
```

Every actual occupied state is in the pre-lower carrier, so `U<=V`.  Cauchy gives

```text
V^2<=(sum_q 1)(sum_q w(q)^2)=N S_2^w.                 (2.1)
```

Combining `(1.3)` and `(2.1)`, the global `F_0` support route closes provided

```text
sqrt(N S_2^w)=o(U_*),
```

or equivalently

```text
S_2^w=o(U_*^2/N).                                      (2.2)
```

Using the worst-case shell count `N asymp T/L` in the exponent ledger,

```text
U_*^2/N
 = [T^(14/5)L^(-22/5)]/[T L^(-1)]
 = T^(9/5)L^(-17/5).                                  (2.3)
```

So the powers in Q7344 are correct.

The two-threshold derivation in Q7344 is the same Cauchy calculation.  If one splits at `Omega`, then

```text
V_low <= N Omega,
V_high<=S_2^w/Omega.                                   (2.4)
```

There exists an `Omega` for which both terms are `o(U_*)` exactly when

```text
N S_2^w=o(U_*^2).                                      (2.5)
```

One may take `Omega=sqrt(S_2^w/N)` up to a harmless slowly varying factor.  Conversely, multiplying the two required estimates in `(2.4)` recovers `(2.5)`.  Thus no logarithm is lost in passing between the split and `(2.1)`.

### What “exact” means here

The intrinsic second-moment scale is

```text
U_*^2/N_w,
N_w=#{q:w(q)>0},                                       (2.6)
```

not necessarily `U_*^2/(T/L)`.  Formula `(2.3)` is the uniform worst-shell version obtained by replacing the actual pre-window modulus support by `T/L`.

Likewise, if the actual factorial moment is substantially smaller than `F_0`, the exact joint global condition is

```text
F sqrt(N S_2^w)=o(B^2),                                (2.7)
```

rather than the stronger theorem obtained by substituting `F_0`.  Therefore `(2.3)` is exact only in the minimax interface consisting of

```text
N<<T/L,
F<=F_0,
and no information correlating the q-location of F with w.
```

It is not the weakest possible C4 theorem.

## 3. Sharpness of the coarse threshold

The scale `(2.3)` cannot be enlarged using only `N`, `F_0`, and the window second moment.  Define

```text
K_0:=U_*/N
    =T^(2/5)L^(-6/5),

K_1:=F_0/B
    =T^(3/5)L^(1/5).                                   (3.1)
```

These satisfy

```text
K_0 K_1=T/L.                                           (3.2)
```

Consider the following moment-interface profile on `N asymp T/L` upper primes:

```text
Z(q)   asymp K_1,
w(q)   asymp K_0,
U_q    =w(q),
kappa(q,t) asymp K_1 on every one of the U_q states.   (3.3)
```

This is not asserted to be an actual Apéry configuration.  It is the extremizer showing what the quoted inequalities alone permit.  It also respects the project pointwise scales: `K_1<T^(2/3)` and `K_1<T/L` for large `T`.

Its ledgers are

```text
sum_q Z(q)^2
 asymp N K_1^2
 =T^(11/5)L^(-3/5),                                   (3.4)

S_2^w
 asymp N K_0^2
 =T^(9/5)L^(-17/5),                                   (3.5)

U
 asymp N K_0
 =U_*,                                                 (3.6)

F
 asymp N K_0 K_1^2
 =F_0,                                                 (3.7)

M
 asymp N K_0 K_1
 =B.                                                   (3.8)
```

Thus equality at the scale in `(2.3)` permits marked mass of exact target order, not little-o.  The strict little-o in Q7344 is necessary for this coarse route.  The profile also lies on the exceptional-wedge boundary `kappa*w=T/L`.

## 4. Rigorous comparison with the banked `sum Z(p)^2`

Because `q in I` and `w(q)<=Z(q)`, the pure zero-set theorem `(0.2)` gives directly

```text
S_2^w<=sum_(q in Q_T)Z(q)^2
      << T^(11/5)L^(-3/5).                             (4.1)
```

The two sides have the same combinatorial dimension: each is a count of ordered pairs of upper indices in a common prime fibre.  What differs is the scale.  Dividing the banked scale by the required Q7344 scale gives

```text
[T^(11/5)L^(-3/5)]/[T^(9/5)L^(-17/5)]
 =T^(2/5)L^(14/5).                                    (4.2)
```

Therefore `(4.1)` misses `(2.3)` by

```text
T^(2/5)L^(14/5).                                      (4.3)
```

The square root of this factor is the familiar Q7287 miss factor

```text
R(T):=T^(1/5)L^(7/5).                                  (4.4)
```

Indeed the banked zero-set moment yields only

```text
V<=sqrt((T/L) T^(11/5)L^(-3/5))
  =T^(8/5)L^(-4/5)
  =U_0,                                                (4.5)
```

whereas the global `F_0` consumer needs

```text
V=o(U_*)=o(T^(7/5)L^(-11/5)).                          (4.6)
```

Their ratio is

```text
U_0/U_*=R(T).                                          (4.7)
```

Since an `L^2` moment controls an `L^1` support through a square root, reducing the support by `R` requires reducing the second moment by `R^2`; this is exactly `(4.2)`.

Equivalently,

```text
T^(9/5)L^(-17/5)
 = [T^(11/5)L^(-3/5)]/R(T)^2.                          (4.8)
```

### First failed implication

The current bank and the pointwise inclusion imply only the big-O statement `(4.1)`.  They do **not** imply

```text
sum_q w(q)^2=o(T^(9/5)L^(-17/5)).                      (4.9)
```

The profile `(3.3)` is already a countermodel: it saturates the banked `Z^2` scale while its window second moment is exactly of order, rather than little-o of, the proposed threshold.  An even simpler marginal counterprofile takes `w(q)=Z(q)=K_1` on `N` primes; then `(0.2)` is saturated and `(4.9)` is missed by the full factor `(4.2)`.

Thus the missing arithmetic content is a genuine upper-window localization or a joint statement correlating upper-window size with the marked lower-prime factorial mass.  It is not furnished by the existing zero-set second moment.

## 5. The weakest pure-window support condition

If one insists on using only the global factorial envelope `F_0`, the exact support-side requirement is not a second moment.  It is simply

```text
sum_q w(q)=o(U_*).                                     (5.1)
```

This is the weakest support-blind conclusion about the full pre-lower carrier that makes `(1.2)` close from `F<=F_0`.  The Q7344 theorem `(2.3)` is one Cauchy-sufficient proxy for `(5.1)`.

More generally, for any deterministic positive weights `a(q)`, put

```text
A_a=sum_q a(q),
W_a=sum_q w(q)^2/a(q).                                 (5.2)
```

Weighted Cauchy gives

```text
(sum_q w(q))^2<=A_a W_a.                               (5.3)
```

Hence the weighted support theorem

```text
A_a W_a=o(U_*^2)                                       (5.4)
```

is sufficient.  The unweighted choice `a(q)=1` gives Q7344:

```text
A_a=N,
W_a=S_2^w.
```

A choice matched to the available bank is

```text
a(q)=Z(q)^2.
```

With the convention `w/Z=0` when `Z=0`, `(5.4)` becomes

```text
(sum_q Z(q)^2)
(sum_q (w(q)/Z(q))^2)
=o(U_*^2).                                             (5.5)
```

Using `(0.2)`, a fixed-exponent sufficient form is

```text
sum_q (w(q)/Z(q))^2
=o(T^(3/5)L^(-19/5)),                                  (5.6)
```

because

```text
U_*^2/[T^(11/5)L^(-3/5)]
 =T^(3/5)L^(-19/5).                                   (5.7)
```

Condition `(5.6)` measures the squared fraction of each full Apéry zero set surviving the deterministic quotient-six upper window.  It is the natural `Z^2`-dual pure-window moment.  It and `(2.3)` are not universally comparable when the `Z(q)` are highly nonuniform; the exact condition remains `(5.1)`.

### Localization to the Q7344 exceptional wedge

Let `E_omega` be Q7344's intermediate-load/high-window remainder.  Outside it, the banked low-load, high-load, and product deletions already give `o(B)`.  Every state in `E_omega` lies over a prime satisfying

```text
w(q)>K_0/omega^2.                                      (5.8)
```

Therefore a strictly weaker pure-window support theorem is the tail condition

```text
sum_(q:w(q)>K_0/omega^2) w(q)=o(U_*),                  (5.9)
```

for a slowly growing `omega` compatible with the previous deletions.  No condition at all is needed on low-window primes.  A tail second-moment proxy is

```text
sum_(q:w(q)>H) w(q)^2=o(U_* H),                        (5.10)
```

with `H=K_0/omega^2`.  The unlocalized Q7344 scale `U_*K_0` is

```text
U_*K_0=T^(9/5)L^(-17/5),                               (5.11)
```

which explains why the same exponent appears when the split is balanced at the first dangerous window `K_0`.

## 6. The genuinely weakest q-window/factorial consumer

A pure support theorem spends the entire global `F_0` on every part of the window carrier.  The exact q-local inequality keeps the location of factorial mass.

For each q,

```text
M_q-U_q
 =sum_(t:kappa(q,t)>0)(kappa(q,t)-1).
```

Cauchy inside the q-fibre gives

```text
(M_q-U_q)^2
 <=U_q sum_t (kappa(q,t)-1)^2
 <=U_q F_q.                                            (6.1)
```

After summing q,

```text
M
 <=U+sum_q sqrt(U_q F_q)
 <=U+sum_q sqrt(w(q)F_q).                              (6.2)
```

Therefore the order-sharp localized consumer is

```text
sum_q sqrt(U_qF_q)=o(B),                               (6.3)
```

and the weakest support-blind replacement using the pre-lower window is

```text
sum_q sqrt(w(q)F_q)=o(B).                              (6.4)
```

For fixed local data `(U_q,F_q)`, `(6.3)` is sharp up to constants: put one constant load on all `U_q` occupied states.  Then `M_q-U_q` and `sqrt(U_qF_q)` are comparable.  Thus no power improvement follows from the local pairs `(U_q,F_q)` alone.

### The moment dual to the banked `Z^2` norm

The current bank can be paired with `(6.4)` without first forcing the entire support below `U_*`.  Define

```text
H_Z
 :=sum_(q:Z(q)>0) w(q)F_q/Z(q)^2.                      (6.5)
```

Then

```text
sum_q sqrt(w(q)F_q)
 =sum_q Z(q) sqrt(w(q)F_q/Z(q)^2)
 <=sqrt((sum_q Z(q)^2) H_Z).                           (6.6)
```

Consequently the sharp product condition associated with this `L^2` pairing is

```text
(sum_q Z(q)^2) H_Z=o(B^2).                             (6.7)
```

Using only the global bank `(0.2)`, the fixed-exponent version is

```text
H_Z=o(T^(9/5)L^(-17/5)),                               (6.8)
```

because

```text
B^2/[T^(11/5)L^(-3/5)]
 =T^(9/5)L^(-17/5).                                   (6.9)
```

The numerical coincidence between `(2.3)` and `(6.8)` should not obscure that their left sides are completely different:

```text
Q7344 support proxy:       sum_q w(q)^2;
Z-dual marked moment:      sum_q w(q)F_q/Z(q)^2.
```

The latter charges only q-fibres where marked factorial mass actually occurs and discounts by the already banked zero-set capacity.  It can close configurations for which the raw window second moment is far above `(2.3)`.

If actual occupied support is allowed in the theorem, replace `w(q)` in `(6.5)` by `U_q`; this is weaker still.  The pre-window version is preferable when one wants a support-blind arithmetic statement.

### Exceptional localization

For Q7344's remainder `E_omega`, define

```text
U_{E,q}=#{t:(q,t) in E_omega},
F_{E,q}=sum_((q,t) in E_omega) kappa(q,t)(kappa(q,t)-1). (6.10)
```

All sums in `(6.2)`--`(6.8)` may then be restricted to primes over which `E_omega` is nonempty.  The genuinely localized bank-matched moment is

```text
H_{Z,E}
 :=sum_(q:Z(q)>0) w(q)F_{E,q}/Z(q)^2.                  (6.11)
```

The least wasteful product condition is

```text
Z_{2,E} H_{Z,E}=o(B^2),
Z_{2,E}:=sum_(q:F_{E,q}>0)Z(q)^2.                      (6.12)
```

Using the full global bound for `Z_{2,E}` yields the clean but stronger fixed exponent

```text
H_{Z,E}=o(T^(9/5)L^(-17/5)).                           (6.13)
```

This is the first weighted/window-localized marked moment that uses the existing `Z^2` bank without discarding the q-location of the factorial mass.

## 7. Exact theorem after the audit

### Theorem — `Q6-C4-UPPER-WINDOW-LOCALIZED-CLOSURE`

Let `E` be a set of quotient-six marked states, and suppose the marked incidence outside `E` is `o_J(B)`.  For each relevant upper prime q, define `U_{E,q}` and `F_{E,q}` as in `(6.10)`.  Let `w(q)` be the pre-lower-mark upper-window occupancy and `Z(q)` the full Apéry zero-set size, so that

```text
U_{E,q}<=w(q)<=Z(q).
```

Assume also the already banked singleton carrier bound

```text
sum_q U_{E,q}=o_J(B).                                  (7.1)
```

Then:

1. The exact q-local sufficient condition is

   ```text
   sum_q sqrt(U_{E,q}F_{E,q})=o_J(B).                  (7.2)
   ```

2. A support-blind upper-window sufficient condition is

   ```text
   sum_q sqrt(w(q)F_{E,q})=o_J(B).                     (7.3)
   ```

3. For any deterministic positive weights `a(q)`, it is sufficient that

   ```text
   (sum_q a(q))
   (sum_q w(q)F_{E,q}/a(q))
   =o_J(B^2).                                          (7.4)
   ```

4. Taking `a(q)=Z(q)^2`, it is sufficient that

   ```text
   (sum_(q:F_{E,q}>0) Z(q)^2)
   (sum_(q:Z(q)>0) w(q)F_{E,q}/Z(q)^2)
   =o_J(B^2).                                          (7.5)
   ```

5. In particular, if the banked upper-shell moment

   ```text
   sum_q Z(q)^2 <<_J T^(11/5)L^(-3/5)                 (7.6)
   ```

   is available, then the concrete theorem

   ```text
   sum_(q:Z(q)>0) w(q)F_{E,q}/Z(q)^2
   =o_J(T^(9/5)L^(-17/5))                              (7.7)
   ```

   closes marked incidence on `E`, and hence closes the full C4 gate.

#### Proof

From `(6.1)`,

```text
M(E)
 <=sum_q U_{E,q}+sum_q sqrt(U_{E,q}F_{E,q}).           (7.8)
```

The first term is `o(B)` by `(7.1)`, proving part 1.  Since `U_{E,q}<=w(q)`, part 2 follows.  Weighted Cauchy gives

```text
sum_q sqrt(w(q)F_{E,q})
 =sum_q sqrt(a(q)) sqrt(w(q)F_{E,q}/a(q))
 <=sqrt((sum_q a(q))
         (sum_q w(q)F_{E,q}/a(q))),                    (7.9)
```

which proves parts 3 and 4.  Under `(7.6)`, the product in `(7.5)` is `o(B^2)` exactly when `(7.7)` holds at the displayed scale, because

```text
B^2/[T^(11/5)L^(-3/5)]
 =T^(9/5)L^(-17/5).
```

Thus `M(E)=o(B)`.  Adding the assumed `o(B)` contribution outside `E` gives `M=o(B)`.  Restoring the native factor `log p asymp L` yields

```text
Cminus(T,J)+Cplus(T,J)=o_J(T^2/L).
```

This proves the theorem.

### Sharpness of the theorem's consumer

The profile `(3.3)` has

```text
Z_{2}       asymp T^(11/5)L^(-3/5),
H_{Z}       asymp T^(9/5)L^(-17/5),
M           asymp B.
```

Indeed, for one q,

```text
F_q asymp w(q)K_1^2,

w(q)F_q/Z(q)^2
 asymp K_0 [K_0K_1^2]/K_1^2
 =K_0^2,
```

and summing gives `N K_0^2`.  Hence equality at the scale of `(7.7)` does not force little-o marked incidence.  The strict little-o, and the product form `(7.5)`, are order-sharp for an argument using only the banked `Z^2` norm and q-local Cauchy.

## Final audit verdict

The Q7344 exponent

```text
sum_q w(q)^2=o(T^(9/5)L^(-17/5))
```

is arithmetically and dimensionally correct as a **worst-case support-only corollary** of

```text
F<=F_0,
#Q_T<<T/L,
and U<=sum_q w(q).
```

Its exact origin is

```text
U_*       =B^2/F_0=T^(7/5)L^(-11/5),
S_2-scale =U_*^2/(T/L)=T^(9/5)L^(-17/5).
```

It is not the weakest theorem.  The pure-window requirement is only

```text
sum_q w(q)=o(U_*),
```

or its high-window tail version on the Q7344 exceptional wedge.  The order-sharp q-local marked consumer is

```text
sum_q sqrt(U_{E,q}F_{E,q})=o(B),
```

with the support-blind replacement `U_{E,q}<=w(q)`.  Paired optimally with the existing zero-set `L^2` bank, the clean new arithmetic target is the localized weighted moment `(7.5)`, or the fixed-exponent form `(7.7)`.

The banked theorem

```text
sum_p Z(p)^2 << T^(11/5)L^(-3/5)
```

is not dimensionally or marginally incompatible with the upper window: the upper q lies in the same shell and `w(q)<=Z(q)`.  It is simply too weak by

```text
T^(2/5)L^(14/5)=R(T)^2.
```

The first failed implication is therefore the attempted passage from the banked `O(Z_2)` bound to the required little-o window localization.  Closing C4 requires either that extra upper-window depletion, the exact exceptional-support bound, or the joint q-local weighted factorial theorem above.
