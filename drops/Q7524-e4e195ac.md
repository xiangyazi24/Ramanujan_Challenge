# Exact attack on the Q7506 Bezout remainder

## Result

There is a canonical exact Bezout remainder that is stronger than the interface stated in Q7506.

For any integer sequence Y = (Y_d), define

```text
G_{d,L}(Y)
  = sum_{i=0}^L (-1)^i C(d+i,i) C(d+L+1,L-i) Y_{d+i},
```

where C(x,k) denotes the binomial coefficient.

For one hard block B = (a,D,N), with M = n-a, set

```text
Y_d = C_M(d),
A_B = G_{D-1,N}(Y),
B_B = C(D+N,N).
```

Then the minimal-core remainder

```text
R_B^core := G_{D,N-1}(Y)
          = A_B + (-1)^(N+1) B_B Δ^N Y_{D-1}
```

is an exact Bezout remainder with

```text
U_B = 1,
V_B = (-1)^(N+1) Δ^N C_M(D-1).
```

It uses exactly the N shell nodes D,...,D+N-1, i.e. exactly the principal prime nodes q-1 for D < q <= D+N. Consequently

```text
rad_{(D,D+N]} gcd(A_B,B_B)
  = rad_{(D,D+N]} gcd(R_B^core,B_B).
```

This is the natural first exact object to test for the requested exp(o(n)) height.

The attack does not close the conjecture. What can be proved is a sharp no-go for the entire universal adjacent/translated Newton-contiguous class:

> If one tries to make R_B^core smaller by subtracting an adjacent core remainder, or more generally by Euclidean elimination in a finite translated stack of Newton stencils, every shared candidate prime occurs exactly once in the Pascal connection coefficient. Keeping that coefficient gives a nonzero remainder of at least full candidate-primorial height; dividing/saturating it removes the only universally guaranteed copy of the target prime. There is an explicit arbitrary-sequence counterexample after saturation. Hence this whole class cannot produce the Q7506 remainder with aggregate o(n) height.

This is an exact theorem, not a scan. It also explains why the very clean gcd collapses seen in the hostile finite rows do not by themselves turn into a low-height Bezout certificate.

## 1. Exact divisor-index contiguous relation on one quotient cell

Let

```text
c_M(u,v,w) = coefficient of x^u y^v z^w in Lambda(x,y,z)^M,
```

for the repository's Apery Laurent polynomial

```text
Lambda(x,y,z)
  = (1+x)(1+y)(1+z)((1+y)(1+z)+xyz)/(xyz).
```

The shell is

```text
C_M(d) = sum_{kappa in Z^3} c_M(d*kappa).
```

Fix a divisor quotient cell floor(M/e) = a. Equivalently,

```text
floor(M/(a+1)) + 1 <= e <= floor(M/a).
```

On that cell the set of possible lattice directions is fixed; it is the lattice-point set

```text
P_a = (a P) intersect Z^3
```

of the dilated Newton polytope P.

Whenever d,d+1,...,d+L all stay in this quotient cell,

```text
C_M(d+j)
  = sum_{kappa in P_a} CT[ Lambda^M X^{-(d+j)kappa} ].
```

Taking the L-th forward difference gives the exact contiguous formula

```text
Δ^L C_M(d)
  = sum_{kappa in P_a}
      CT[ Lambda^M X^{-d kappa} (X^{-kappa}-1)^L ].        (1)
```

This is precisely the constant-term identity independently checked in `q32_boundary_increment_audit.sage`; here it is the relevant divisor-index cofactor for the Q7506 block.

Formula (1) matters because every adjacent Newton connection below factors as

```text
Pascal connection coefficient  ×  the explicit CT cofactor (1).
```

So there is no unspecified remainder hidden in the contiguous relation.

A coarse exact height bound follows from nonnegativity of the coefficients of Lambda. Their sum is 40, hence

```text
|Δ^L C_M(d)| <= |P_a| 2^L 40^M.                         (2)
```

This is only an upper bound, but it already shows that the CT cofactor does not supply a sublinear Archimedean estimate by itself.

## 2. Small symbolic blocks: the minimal-core remainder emerges

The universal Newton identities in `q32_newton_gcd_audit.py` include

```text
G_{d,L}(Y) - G_{d+1,L-1}(Y)
  = (-1)^L C(d+L+1,L) Δ^L Y_d.                           (3)
```

Set d = D-1 and L = N. Since C(d+L+1,L) = C(D+N,N) = B_B, (3) gives

```text
A_B - G_{D,N-1}(Y)
  = (-1)^N B_B Δ^N Y_{D-1}.
```

Before proving the closed form, the first three block lengths make the pattern transparent.

### N = 1

```text
A = (D+1)Y_{D-1} - D Y_D,
B = D+1,
R^core = Y_D.                                             (4)
```

### N = 2

```text
B = (D+1)(D+2)/2,
R^core = (D+2)Y_D - (D+1)Y_{D+1}.                        (5)
```

### N = 3

```text
R^core
  = ((D+2)(D+3)/2) Y_D
    - (D+1)(D+3) Y_{D+1}
    + ((D+1)(D+2)/2) Y_{D+2}.                            (6)
```

These are not fitted identities; they are the first cases of the exact general formula below.

## 3. Closed form for the canonical remainder

Write

```text
B_{D,N} = C(D+N,N).
```

The coefficient of Y_{D+i} in G_{D,N-1} is

```text
(-1)^i C(D+i,i) C(D+N,N-1-i).
```

Direct factorial cancellation gives

```text
C(D+i,i) C(D+N,N-1-i)
  = C(D+N,N) * N*C(N-1,i)/(D+i+1).
```

Therefore

```text
R_{D,N}^core(Y)
  = B_{D,N} * sum_{i=0}^{N-1}
      (-1)^i [N*C(N-1,i)/(D+i+1)] Y_{D+i}.               (7)
```

Equivalently, as a weighted finite difference,

```text
R_{D,N}^core(Y)
  = (-1)^(N-1) N B_{D,N}
      Δ^(N-1) ( Y_d/(d+1) ) evaluated at d=D.             (8)
```

Although (8) is written with rational intermediate values, (7) proves that the result is integral.

This formula is useful for two reasons.

First, it is an explicit candidate for the Q7506 R_B, not merely an existence statement.

Second, it exposes the exact CRT mechanism: B_{D,N} is cancelled at precisely one summand by the moving denominator D+i+1.

## 4. Exact target preservation of the core remainder

Let q be prime with

```text
D < q <= D+N.
```

Because D>N, q>N, and q occurs exactly once in B_{D,N}. Put

```text
j = q-D-1,    0 <= j <= N-1.
```

In (7), if i != j, then D+i+1 != q. Also

```text
D+N < 2D < 2q,
```

so q cannot divide another node D+i+1. Hence every non-j coefficient in (7) is divisible by q.

For the distinguished coefficient,

```text
w_j = (-1)^j (B_{D,N}/q) N C(N-1,j).
```

Modulo q, removing the one q from the numerator interval gives

```text
B_{D,N}/q
  == (-1)^j j!(N-1-j)! / N!        (mod q),
```

so

```text
w_j == 1   (mod q).
```

Thus

```text
R_{D,N}^core(Y) == Y_{q-1}   (mod q).                    (9)
```

For Y = C_M, the Cartier packet law on a fixed hard quotient cell gives

```text
C_M(q-1) == b_{r_q}   (mod q),
```

so the principal-interval target radical is preserved exactly.

No folded-node statement is being made here: the equality remains support-restricted to the principal interval (D,D+N], exactly as in Q7506.

## 5. Nonvanishing and the first height test

The new remainder is canonical, but its nonvanishing is not a formal consequence of Newton interpolation.

For any principal prime q, (9) gives the sufficient condition

```text
q does not divide C_M(q-1)  =>  R_{D,N}^core != 0.        (10)
```

Hence any block containing at least one non-target principal prime has a nonzero core remainder.

Universal interpolation cannot prove nonvanishing in the worst case: for an arbitrary sequence one may set all core values Y_D,...,Y_{D+N-1} to zero. Then R^core=0 and every principal prime is a target. Thus proving R_B^core != 0 for the actual Apery shell in every hard block would already use genuinely Apery-specific information.

The available unconditional Archimedean estimate is also too large. Since C_M(d) is a sum of nonnegative coefficients of Lambda^M,

```text
0 < C_M(d) <= 40^M.
```

From (7),

```text
|R_{D,N}^core|
  <= 40^M B_{D,N} [N/(D+1)] 2^(N-1),                    (11)
```

hence

```text
log |R_{D,N}^core|
  <= M log 40 + log B_{D,N} + N log 2 + O(log N).       (12)
```

This retains the linear M-term and therefore does not prove the required aggregate o(n) bound.

There is an exact symbolic reason. On one quotient cell,

```text
C_M(d) = b_M + E_M(d),
```

where b_M = c_M(0,0,0) is the common origin coefficient. The Newton row has coefficient sum 1, so

```text
R_{D,N}^core
  = b_M + sum_{i=0}^{N-1} w_i E_M(D+i).                 (13)
```

Thus the minimal-core move does not cancel the large common origin packet. Any formal cancellation of that packet must move to a coefficient-sum-zero combination. That is exactly where the Pascal-content obstruction becomes unavoidable.

## 6. Adjacent core blocks: exact connection coefficient

Define

```text
R_D     = G_{D,N-1}(Y),
R_{D+1} = G_{D+1,N-1}(Y).
```

The horizontal Newton identity gives

```text
R_D - R_{D+1}
  = (-1)^N P_{D,N} Δ^N Y_D,                              (14)

P_{D,N} = C(D+N,N-1).
```

The connection coefficient has the revealing form

```text
P_{D,N}
  = [N/(D+1)] B_{D,N}
  = (D+2)(D+3)...(D+N)/(N-1)!.                           (15)
```

So the adjacent connection has removed exactly the leaving endpoint D+1 from the original Pascal mask and keeps the entire shared interval.

For every prime

```text
D+1 < q <= D+N,
```

we have q>N-1, the denominator (N-1)! is a q-unit, and the numerator interval in (15) contains q exactly once. Therefore

```text
v_q(P_{D,N}) = 1.                                        (16)
```

This is the requested exact adjacent-block connection coefficient, with its principal Pascal content completely classified.

## 7. Full Pascal saturation kills target preservation

Now saturate all of the binomial connection coefficient in (14). The primitive connection is simply

```text
(R_D - R_{D+1}) / P_{D,N}
  = (-1)^N Δ^N Y_D.                                      (17)
```

For an overlap target prime q, targetness gives only

```text
Y_{q-1} == 0   (mod q).
```

It does not force

```text
Δ^N Y_D == 0   (mod q).
```

There is a completely explicit general counterexample. Fix any overlap prime

```text
D+1 < q <= D+N
```

and define an integer sequence on the needed window by

```text
Y_D = (-1)^N,
Y_{D+1} = ... = Y_{D+N} = 0.
```

Then q-1 >= D+1, so Y_{q-1}=0, but

```text
Δ^N Y_D
  = sum_{k=0}^N (-1)^(N-k) C(N,k) Y_{D+k}
  = 1.
```

Hence

```text
Y_{q-1} == 0 (mod q),

but

(R_D-R_{D+1})/P_{D,N} != 0 (mod q).                      (18)
```

So the target prime in the unsaturated connection is entirely consumed by universal Pascal content. After full saturation it is gone.

This is a theorem for all integer sequences; no finite scan and no probabilistic statement is involved.

## 8. Keeping the Pascal factor is fatal on height

Could one keep P_{D,N} in (14) and use the nonzero connection difference itself as a Bezout remainder? No. If the right side is nonzero, its integer cofactor has absolute value at least 1, so

```text
|R_D-R_{D+1}| >= P_{D,N}.                                (19)
```

More sharply, let

```text
Pi_cap(D,N)
  = product of all primes q with D+1 < q <= D+N.
```

By (16),

```text
Pi_cap(D,N) divides P_{D,N}.
```

Thus every nonzero unsaturated connection satisfies

```text
log |R_D-R_{D+1}| >= log Pi_cap(D,N).                    (20)
```

Now use the canonical Q7506 hard-block cover. Its principal intervals partition the hard range p > n^(2/3+o(1)) up to O(n^(1/3)) block boundaries. Passing from each full block to the overlap in (20) deletes at most one candidate prime per block. Ordinary Chebyshev/PNT bookkeeping therefore gives

```text
sum_B log Pi_cap(B) = n - o(n).                          (21)
```

The loss from block boundaries is only O(n^(1/3) log n)=o(n).

Consequently, if one chooses a nonzero adjacent connection on every relevant block,

```text
sum_B log |R_{D_B}-R_{D_B+1}| >= n-o(n),                 (22)
```

which is exactly the wrong scale.

If a connection cofactor Δ^N C_M(D) vanishes, then the connection remainder is zero and cannot serve as the required canonical nonzero R_B. Thus there is no zero/nonzero loophole:

```text
nonzero unsaturated connection  => linear aggregate height;
saturated connection            => target prime not preserved;
zero connection                 => not an admissible nonzero remainder.
```

This closes the adjacent-core route in the precise form requested.

## 9. The same no-go for every finite translated Newton stack

The repository's `q32_translated_stack_audit.py` contains a more general Euclidean normal form. It extends the preceding argument from two adjacent core rows to an arbitrary finite translated stack.

Fix m>=2 and put

```text
d0 = D-m+1,
L  = N+m-2,
A_t = G_{d0+t,L}(Y),    0 <= t < m.
```

Every one of these stencils contains the entire core

```text
D,D+1,...,D+N-1.
```

The adjacent differences are

```text
A_t - A_{t+1}
  = (-1)^(L+1) P_t J_t,                                  (23)

P_t = C(D+N+t,L),
J_t = Δ^(L+1) Y_{d0+t}.                                  (24)
```

Repeated Euclidean subtraction gives the exact gcd normal form

```text
gcd(A_0,...,A_{m-1})
  = gcd(A_0, P_0 J_0, ..., P_{m-2} J_{m-2}).             (25)
```

This is an algebraic identity, not a heuristic explanation of the finite nuisance tables.

### Staying in one quotient cell

For Y=C_M, the entire translated union stays in the quotient-a cell provided

```text
D-m+1 >= floor(M/(a+1)) + 1
```

and

```text
D+N+m-2 <= floor(M/a).
```

Equivalently,

```text
m <= min(
       D - floor(M/(a+1)),
       floor(M/a) - D - N + 2
     ).                                                   (26)
```

This generalizes the first-cell margin cap encoded in the current script.

### Principal-prime content of every connection coefficient

Assume also the natural short-stack condition

```text
L < D+1.                                                  (27)
```

This holds in particular for m=2, and for any bounded enlargement of the original D>N block.

Every principal prime D<q<=D+N then satisfies q>L. The numerator interval of P_t contains q, while L! is a q-unit; because the interval length is L<q, there is exactly one multiple of q. Hence, for every t,

```text
v_q(P_t) = 1.                                             (28)
```

Thus the common Pascal prefactor

```text
H_m = gcd(P_0,...,P_{m-2})
```

has

```text
v_q(H_m) = 1
for every principal prime D<q<=D+N.                       (29)
```

This is the exact large-prime classification implemented by `prefactor_pascal_gcd` and `audit_large_prefactor_classification` in the translated-stack audit.

Now the same dichotomy is unavoidable. Before saturation, every connection generator P_t J_t contains the full principal candidate primorial independently of targetness. After dividing by H_m, the principal q-factor has been completely removed. Targetness of the single coordinate Y_{q-1} does not force the divided high difference J_t to vanish; the same one-coordinate counterexample used in (18) can be placed in any chosen difference window.

Therefore:

> **Translated-stack no-go.** No finite same-cell translated Newton stack satisfying (27) can produce a nonzero low-height target-preserving Bezout remainder solely by Euclidean subtraction followed by Pascal/binomial saturation. Unsaturated generators pay the full candidate primorial; saturated generators lose target preservation.

This is the strongest scoped no-go I can prove from the exact Q7506 interface without importing a new Apery-specific identity.

## 10. Broader linear-selector obstruction

The preceding phenomenon is not an accident of the Newton basis.

Let

```text
Q_B  = set of primes q with D<q<=D+N,
Pi_B = product of q in Q_B.
```

Consider any integer linear form on the core values

```text
L(Y) = sum_{i=0}^{N-1} c_i Y_{D+i}                       (30)
```

with the universal target-preservation property that, for every q in Q_B and every integer vector Y,

```text
Y_{q-1} == 0 (mod q)  =>  L(Y) == 0 (mod q).             (31)
```

Suppose q is not merely universal content of L, i.e. not every c_i is divisible by q. Put j=q-D-1. Testing the standard basis vectors in (31) gives

```text
q divides c_i for every i != j,
q does not divide c_j.
```

Therefore, if the node D+i+1 itself is a principal prime q_i,

```text
Pi_B/q_i divides c_i.                                    (32)
```

If D+i+1 is not prime, then either c_i=0 or Pi_B divides c_i.

In particular every nontrivial universal linear selector satisfies

```text
log max_i |c_i| >= log Pi_B - log(D+N).                  (33)
```

The core weights in (7) are one explicit CRT selector of exactly this type.

Across the Q7506 O(n^(1/3))-block cover, summing (33) gives the coefficient-height lower bound

```text
sum_B log max_i |c_{B,i}| >= n-o(n).                     (34)
```

This does not rule out a miraculous Apery-specific cancellation in the value of a large-coefficient form. It does rigorously rule out obtaining the desired o(n) height merely by finding a different universal integer-linear contiguous basis with small coefficients. Any such basis must encode the moving prime selectors somewhere, and (32) shows exactly where the primorial sits.

## 11. The p^2 escape hatch: exact first divided Newton digit

For completeness I also checked the other route requested in the question. The current `q32_fixed_minor_jet_audit.sage` contains an exact formula for the first divided Newton digit.

Suppose

```text
p-1 = d+j,
0 <= j <= L < p,
sigma = L-j,
F_{p-1} = p Z.
```

Then division of the Newton weights by their single forced p-factor gives, modulo p,

```text
G_{d,L}(F)/p
 == Z
    + sum_{i=0}^{j-1}
        (-1)^(j-i-1) C(j,i)
        [ sigma! (j-i-1)! / (sigma+j-i)! ] F_{d+i}
    + sum_{t=1}^{sigma}
        (-1)^t C(sigma,t)
        [ (t-1)! j! / (j+t)! ] F_{p-1+t}
       (mod p).                                           (35)
```

All factorial denominators in (35) are p-units because L<p.

Formula (35) makes the obstruction conceptual: after the first forced p, the divided digit is an affine linear form in the divided target coordinate Z and independent neighbouring shell coordinates. Mod-p targetness alone supplies no relation killing this form.

The mandatory regression case is exactly the one isolated in Q7506:

```text
(p,r,M) = (17,3,19),
b_3 = 5 * 17^2,
```

but

```text
C_19(16)/17 == 7 (mod 17).                               (36)
```

Thus even a depth-two Apery zero does not make the canonical singleton core remainder R^core=C_19(16) divisible by 17^2. The natural first cross-multiplication recorded in Q7506 also has nonzero divided digit 5 modulo 17.

So there is no hidden distinguished p^2 lift in the first divided shell/Newton coordinate. Any p^2 identity strong enough to beat the saturation theorem would have to impose a genuinely new relation among the neighbour terms in (35); it cannot be a consequence of the existing Cartier alias alone.

## 12. Final scoped verdict

The exact attack produces one new canonical remainder and one rigorous closure theorem.

### Exact remainder obtained

For every hard block,

```text
R_B^core
  = G_{D,N-1}(C_M)
  = A_B + (-1)^(N+1) B_B Δ^N C_M(D-1).
```

It preserves the desired principal-interval radical exactly, and its closed coefficient formula is (7)/(8).

### Exact class ruled out

The following class is now closed:

> Start from A_B and finitely many adjacent/translated Newton stencils in the same divisor quotient cell; use only their universal contiguous relations, Euclidean subtraction, and removal of Pascal/binomial content to obtain a target-preserving integer remainder.

For this class, the connection coefficient is explicitly (15), or (24) in a translated stack. Every shared principal prime occurs in it exactly once. Therefore:

```text
keeping the coefficient
  => every nonzero connection remainder carries full candidate-primorial height
     and the aggregate is at least n-o(n);

dividing/saturating the coefficient
  => the target factor is no longer forced, by the explicit counterexample (18);

vanishing connection
  => not the required nonzero remainder;

first p^2 lift
  => fails the exact (17,3,19) regression (36).
```

So the Q7506 remainder problem has been narrowed further: **universal divisor-index Newton recurrence is not enough.** The only part not ruled out by this argument is an actual Apery-specific cancellation in the value of the core selector (7), not a different Pascal/contiguous normalization of it. No density statement and no finite-scan inference is used in this verdict.
