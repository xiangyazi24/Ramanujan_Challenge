# Exact attack on the Q7506 Bézout remainder

## Result

There is a canonical exact Bézout remainder that is stronger than the interface stated in Q7506.  For any integer sequence \(Y=(Y_d)\), put

\[
G_{d,L}(Y)=
\sum_{i=0}^{L}(-1)^i
inom{d+i}{i}inom{d+L+1}{L-i}Y_{d+i}.
\]

For one hard block \(B=(a,D,N)\), with \(M=n-a\), write

\[
Y_d=C_M(d),\qquad
A_B=G_{D-1,N}(Y),\qquad
B_B=inom{D+N}{N}.
\]

Then the **minimal-core remainder**

\[
oxed{
R_B^{m core}:=G_{D,N-1}(Y)
=A_B+(-1)^{N+1}B_B\,\Delta^N Y_{D-1}
}
	ag{1}

\[
U_B=1,\qquad
V_B=(-1)^{N+1}\Delta^N C_M(D-1).
\]

It uses exactly the \(N\) shell nodes \(D,\ldots,D+N-1\), i.e. exactly the principal prime nodes \(q-1\) for \(D<q\le D+N\).  Consequently

\[
\operatorname{rad}_{(D,D+N]}\gcd(A_B,B_B)

	ag{2}
\]

This is the natural first object to test for the requested \(e^{o(n)}\) height.

The attack does **not** close the conjecture.  What can be proved is a sharp no-go for the entire universal adjacent/translated Newton-contiguous class:

> If one tries to make \(R_B^{m core}\) smaller by subtracting an adjacent core remainder, or more generally by Euclidean elimination in a finite translated stack of Newton stencils, every shared candidate prime occurs **exactly once in the Pascal connection coefficient**.  Keeping that coefficient gives a nonzero remainder of at least full candidate-primorial height; dividing/saturating it removes the only universally guaranteed copy of the target prime.  There is an explicit arbitrary-sequence counterexample after saturation.  Hence this whole class cannot produce the Q7506 remainder with aggregate \(o(n)\) height.

This is an exact theorem, not a scan.  It also explains why the very clean gcd collapses seen in the hostile finite rows do not by themselves turn into a low-height Bézout certificate.

## 5. Nonvanishing and the first height test

The new remainder is canonical, but its nonvanishing is not a formal consequence of Newton interpolation.

For any principal prime \(q\), (11) gives the easy sufficient condition

\[

	ag{12}

Hence any block containing at least one non-target principal prime has a nonzero core remainder.

e0\) for the actual Apéry shell in every hard block would already use genuinely Apéry-specific information.

## 8. Keeping the Pascal factor is fatal on height

Could one simply keep \(P_{D,N}\) in (16) and use the nonzero connection difference itself as a Bézout remainder?  No: if the right side is nonzero, its integer cofactor has absolute value at least \(1\), so

\[
|R_D-R_{D+1}|\ge P_{D,N}.
	ag{21}
\]

More sharply, let

\[
\Pi_{D,N}^{\cap}
=\prod_{\substack{D+1<q\le D+N\q\ {m prime}}}q.
\]

By (18),

\[
\Pi_{D,N}^{\cap}\mid P_{D,N},
\]

so every nonzero unsaturated connection satisfies

\[
oxed{
\log|R_D-R_{D+1}|
\ge \log\Pi_{D,N}^{\cap}.
}
	ag{22}
\]

Now use the canonical Q7506 hard-block cover.  Its principal intervals partition the hard range \(p>n^{2/3+o(1)}\) up to \(O(n^{1/3})\) block boundaries.  Passing from each full block to the overlap in (22) deletes at most one candidate prime per block.  Therefore ordinary Chebyshev/PNT bookkeeping gives

\[
\sum_B\log\Pi_B^{\cap}
=n-o(n).
	ag{23}
\]

(The loss from block boundaries is only \(O(n^{1/3}\log n)=o(n)\).)

Consequently, if one chooses a nonzero adjacent connection on every relevant block,

\[
oxed{
\sum_B\log|R_{D_B}-R_{D_B+1}|
\ge n-o(n),
}
	ag{24}
\]

which is exactly the wrong scale.

If a connection cofactor \(\Delta^N C_M(D)\) happens to vanish, then the connection remainder is zero and cannot serve as the required canonical **nonzero** \(R_B\).  Thus there is no zero/nonzero loophole in this argument:

* nonzero unsaturated connection \(\Rightarrow\) linear aggregate height;
* saturated connection \(\Rightarrow\) target prime not preserved;
* zero connection \(\Rightarrow\) not an admissible nonzero remainder.

This closes the adjacent-core route in the precise form requested.

## 12. Final scoped verdict

The exact attack produces one new canonical remainder and one rigorous closure theorem.

### Exact remainder obtained

For every hard block,

\[
oxed{

=A_B+(-1)^{N+1}B_B\Delta^NC_M(D-1).

It preserves the desired principal-interval radical exactly, and its closed coefficient formula is (9)/(10).

### Exact class ruled out

The following class is now closed:

> Start from \(A_B\) and finitely many adjacent/translated Newton stencils in the same divisor quotient cell; use only their universal contiguous relations, Euclidean subtraction, and removal of Pascal/binomial content to obtain a target-preserving integer remainder.

For this class, the connection coefficient is explicitly (17), or (26) in a translated stack.  Every shared principal prime occurs in it exactly once.  Therefore:

* keeping the coefficient makes every nonzero connection remainder carry full candidate-primorial height, giving aggregate \(\ge n-o(n)\);
* dividing/saturating it removes the only universally forced target factor, with the explicit counterexample (20);
* a vanishing connection is not the required nonzero remainder;
* moving to the first \(p^2\) digit does not repair the problem, as (37)--(38) show.

So the Q7506 remainder problem has been narrowed further: **universal divisor-index Newton recurrence is not enough.**  The only part not ruled out by this argument is an actual Apéry-specific cancellation in the value of the core selector (9), not a different Pascal/contiguous normalization of it.  No density statement or finite-scan inference is used in this verdict.
