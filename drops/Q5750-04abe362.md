# R3 correction: exact same-K packet cancellation and the saturation ledger

## 1. Corrected coefficient identity

The previous identification of the right side with a shell value was incorrect. For
\[
\Lambda(X)=\sum_\nu c_1(\nu)X^\nu,
\qquad
\Lambda(X)^M=\sum_\nu c_M(\nu)X^\nu,
\]
and a Laurent monomial test function \(T_\kappa=X^{-\kappa}\), the coefficient extracted after multiplying the Bezout identity by \(T^{-1}\) is
\[
S(M,K)=\sum_{\|\kappa\|_\infty\le K}c_M(-\kappa).
\]
This is a coefficient packet, not generally \(b_M=\operatorname{CT}\Lambda^M\).

If \(K\) exceeds the Newton radius of \(\Lambda^M\), then the packet contains every coefficient and therefore
\[
S(M,K)=\sum_\nu c_M(\nu)=\Lambda(1,1,1)^M=40^M.
\]
The constant term is only
\[
b_M=c_M(0).
\]
No origin-state interpretation is needed.

## 2. Same-K carriers

Let \(A_i=A(D_i,N_i)\) be carriers constructed from the same moment \(M\) and the same coefficient mask radius \(K\). The exact decomposition is
\[
A_i+H_i=S(M,K).
\]
The correction term \(H_i\) depends on the chosen endpoint interpolation, but the packet is identical.

For an interval prime \(q\) contained in the mask of every carrier, the Lagrange congruence gives
\[
A_i\equiv Y_{q-1}\pmod q,
\]
where
\[
Y_d=C_M(d)=\sum_{\kappa\in d\mathbb Z^3}c_M(\kappa).
\]
Therefore for
\[
E=\sum_i\lambda_iA_i
\]
we have the exact local ledger
\[
E\equiv\left(\sum_i\lambda_i\right)Y_{q-1}\pmod q.
\]

This is the entire same-K phenomenon.

## 3. Cancelling the packet

Using
\[
A_i=S-H_i,
\]
we obtain
\[
E=\left(\sum_i\lambda_i\right)S-\sum_i\lambda_iH_i.
\]
Hence exact packet cancellation requires
\[
\sum_i\lambda_i=0.
\]
But then for every common interval prime,
\[
E\equiv0\cdot Y_{q-1}\equiv0\pmod q.
\]
Thus a linear combination which removes the common packet also removes the marked shell congruence at every common target.

Conversely, if
\[
\sum_i\lambda_i\not\equiv0\pmod q,
\]
then the carrier retains the target scalar. The packet cannot be removed integrally without sacrificing the target residue.

## 4. Union targets versus intersection targets

For intersection targets (primes appearing in every carrier mask), the above argument is exact: the surviving observation space modulo q is one-dimensional, generated by \(Y_{q-1}\).

For union targets, there is no common congruence. A prime occurring only in carrier i satisfies
\[
A_i\equiv Y_{q-1}\pmod q,
\]
but the other carriers have no forced value modulo q. Therefore a linear combination can only preserve union information by retaining separate coefficients at each carrier. This is not a same-K cancellation mechanism.

In particular, two carriers can be arranged so that their packets cancel, but the remaining expression has no universal divisibility at a target appearing in only one mask unless an additional identity is supplied.

## 5. Primorial-weighted patching

Suppose one tries to clear denominators by choosing weights \(\lambda_i\) divisible by products of target primes. The same local calculation gives
\[
E\equiv L_qY_{q-1}\pmod q,
\]
where
\[
L_q=\sum_i\lambda_i\pmod q.
\]
If primorial weights force \(L_q=0\) for all q in a target block, they create the zero observation. If they force \(L_q\ne0\), they retain the full marked scalar and do not cancel the packet.

The height cost is also explicit: making \(L_q\) vanish independently over many q requires carrying the corresponding primorial factors in the coefficients. The saved packet height is replaced by coefficient height.

## 6. Exact dichotomy theorem

For same-K carriers with common target set \(T\):

**Theorem.** Let
\[
E=\sum_i\lambda_iA_i.
\]
Then for every \(q\in T\),
\[
E\equiv L\,Y_{q-1}\pmod q,
\qquad L=\sum_i\lambda_i.
\]
Therefore:

1. \(L=0\): packet cancels and every common target divisor disappears universally.
2. \(L\ne0\): packet survives and the only target information is the original scalar \(Y_{q-1}\).

There is no third same-K linear regime producing a lower-height target-preserving residual.

The corrected conclusion is therefore narrower than a generic saturation claim: **same-K exact packet cancellation is algebraically incompatible with retaining the common marked shell residue.** Any future escape must change the K-packet itself or introduce genuinely non-common target equations.
