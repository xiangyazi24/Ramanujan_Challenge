## Exact formula

Let

\[
R_H(x)=\sum_{i=0}^{H} c_i x^i
\]

be the unique monomial interpolation polynomial satisfying

\[
R_H(m)=1/A_m,\qquad 0\le m\le H.
\]

The signed Newton--Pade height-
`H` numerator is the least positive integer clearing the denominators of all `c_i`:

\[
C_H=\operatorname{lcm}\{\operatorname{den}(c_0),\ldots,\operatorname{den}(c_H)\}.
\]

Equivalently, in the integer kernel system

\[
(A_m-1)q_0+A_m\sum_{j=1}^{H}m^jq_j=0,
\]

the primitive kernel vector gives

\[
P=C_H,
\]

and every cofactor is divisible by the common denominator. The cofactor obtained by deleting the `q_0` column is

\[
D_H=\left(\prod_{m=1}^{H}A_m\right)\left(\prod_{k=1}^{H}k!\right).
\]

Therefore

\[
C_H=D_H/g_H,
\]

where

\[
g_H=\gcd(\text{all }H\times H\text{ cofactors}).
\]

This identity is exact; the missing issue is estimating `g_H`.

## Primewise valuation form

For every prime `\ell`,

\[
v_\ell(C_H)=\max_i\{-v_\ell(c_i)\}_+.
\]

The cofactor representation gives the equivalent Smith-normal-form expression:

\[
v_\ell(C_H)=v_\ell(D_H)-\min v_\ell(\text{cofactors}).
\]

Thus

\[
v_\ell(C_H)=\sum_{m=1}^{H}v_\ell(A_m)+\sum_{k=1}^{H}v_\ell(k!)-v_\ell(g_H).
\]

This is the rigorous cancellation accounting.

## Lower bound status

The product part satisfies

\[
\log D_H=\sum_{m=1}^{H}\log A_m+\sum_{k=1}^{H}\log(k!).
\]

Using Apéry growth `log A_m = Θ(m)` gives

\[
\sum_{m\le H}\log A_m=Θ(H^2),
\]

and Stirling gives

\[
\sum_{k\le H}\log(k!)=Θ(H^2).
\]

Hence

\[
\log D_H=Θ(H^2).
\]

But

\[
\log C_H=\log D_H-\log g_H
\]

requires a nontrivial upper bound on `g_H`. No such bound follows from integrality alone. The unresolved arithmetic lemma is:

> Prove that the primitive interpolation cofactor gcd satisfies
> \(\log g_H=o(H^2)\).

A weaker `O(H log H)` estimate would suffice, but it is not established here.

## Exact verification code

The following self-contained computation checks the interpolation formula and primitive normalization.

```python
from fractions import Fraction
from math import gcd, factorial


def apery(N):
    A=[1]
    for n in range(1,N+1):
        s=0
        for k in range(n+1):
            from math import comb
            s += comb(n,k)**2*comb(n+k,k)**2
        A.append(s)
    return A


def lagrange_denominator(H):
    A=apery(H)
    coeff=[Fraction(0) for _ in range(H+1)]
    for m in range(H+1):
        poly=[Fraction(1)]
        den=Fraction(A[m])
        for j in range(H+1):
            if j==m: continue
            new=[Fraction(0)]*(len(poly)+1)
            for i,x in enumerate(poly):
                new[i] -= x*j
                new[i+1] += x
            poly=[x/Fraction(m-j) for x in new]
        for i,x in enumerate(poly):
            coeff[i]+=x/den
    C=1
    for x in coeff:
        C=C*x.denominator//gcd(C,x.denominator)
    return C

for H in range(1,16):
    print(H, lagrange_denominator(H))
```

## Support implication

Let the primitive integer denominator polynomial satisfy

\[
Q(m)=C_H/A_m.
\]

Because `Q` has integral coefficients, if

\[
p\mid A_r
\]

and

\[
n\equiv r\pmod p,
\]

then

\[
Q(n)\equiv Q(r)\pmod p.
\]

Since

\[
A_rQ(r)=C_H,
\]

and the target prime divides `A_r`, we have

\[
C_H\equiv0\pmod p
\]

for every prime occurring in the cleared denominator. Therefore

\[
P(r)=P(n)\equiv0\pmod p.
\]

The support propagation law is preserved. The unresolved part is only the quantitative height after primitive cancellation.
