# Q773 cold audit: the claimed theorem is not established

## Verdict

The claimed exceptional-set bound does not follow from the listed banked inputs. The first fatal gap is the **codegree estimate is being applied to a prime universe that is not fixed across the exceptional points, and the incidence lower bound does not produce the required pair-count upper bound for the same prime labels**.

The argument can be repaired only after proving a uniformization lemma: every exceptional n must contribute a sufficiently large set of primes from one common bounded universe (depending only on the dyadic shell), or else the large-prime labels must be partitioned into controlled ranges and the codegree estimate must be summed over those ranges. The current statement skips this.

## Audit of the preliminary reductions

### 1. Small primes

The input

```
sum_{p <= sqrt(n)} v_p(G_n) log p = O(sqrt(n))
```

is not enough by itself unless the implied constant is uniform in the dyadic shell and the definition of G_n is already reduced to the small-prime channel. Assuming that uniformity, this part is harmless because for an exceptional n with log G_n > epsilon n the small-prime contribution is negligible for large n.

### 2. Large-prime valuation bound

The assertion

```
p > sqrt(n) => v_p(G_n) <= 6
```

is also only a per-prime multiplicity bound. To convert it into a count of bad primes one needs a lower bound of the form

```
number of contributing primes >= remaining logarithmic mass /(6 log(upper prime size)).
```

This gives the stated scale

```
t(n) >= epsilon n /(7 log n)
```

only after all other channels have been shown to contribute o(n), with constants checked. The companion-channel bound O(n^(2/3)) is sufficient for that purpose.

## Main fatal gap: the codegree argument

The proposed argument is:

- each exceptional n supplies at least

```
T = epsilon N/(7 log N)
```

bad primes in a dyadic shell;
- hence incidences satisfy

```
I >= epsilon N M/(4 log N).
```

The issue is the next step.

For each prime p let d_p be the number of exceptional n in J carrying p. Then

```
sum_p d_p = I
```

and Cauchy gives

```
sum_p binom(d_p,2) >= 1/2(I^2/L - I)
```

only if the number of possible prime labels is at most L. This requires a single prime universe containing all labels counted in I.

The claimed bound

```
L <= 4N/log N
```

does not follow from the supplied information. A prime contribution for n may range up to a quantity depending on n and the exact factorization channel. If the bad primes include primes larger than O(N), then the universe is not bounded by pi(4N). If they do not, that restriction must be proved from the definitions of the channels.

This is not a cosmetic constant issue: the Cauchy lower bound weakens linearly with the actual universe size.

## Audit of the codegree lemma

The proposed lemma says for m<n, h=n-m, primes p>P0 bad for both satisfy

```
# {p : p bad for m and n} = O(h log N/log P0).
```

The suggested proof splits:

1. no-wrap:

```
p | N_h(m)
```

2. wrap:

```
p | product_{j<=h}(m+j)
```

3. therefore

```
p <= h
```

The third implication is the problematic point. A prime dividing a short product of consecutive integers is not forced to be <= h. For example, if one factor in the interval is itself a large prime, that prime divides the product. The standard bound is instead obtained from the number of possible prime divisors of a polynomial/product after controlling the size of the product, not from p<=h.

A valid replacement would need an argument such as:

- in the no-wrap case, a nonzero integer N_h(m) has at most O(log |N_h(m)|/log P0) prime divisors above P0;
- in the wrap case, the product of h consecutive integers has at most O(h log N/log P0) prime divisors above P0.

But the current proof sentence "and p<=h" is false in general.

## Consequence for the interval argument

The upper bound

```
sum_p binom(d_p,2) <= C Y M^2
```

is plausible after a corrected codegree lemma, because two exceptional points in the same interval have h<=Y.

However the lower bound

```
sum_p binom(d_p,2)
 >= epsilon^2 N M^2/(128 log N)-I/2
```

depends on the missing uniform prime-universe bound. Without it, there is no contradiction from choosing c small.

Therefore the conclusion

```
M = O_epsilon(1)
```

is not proved.

## Density consequences

Even if the dyadic estimate

```
# {n in (N,2N] : exceptional} = O_epsilon(log N)
```

were proved, the stated consequences would follow:

- ordinary density one:

```
sum_{k<=log_2 N} O(k)=O((log N)^2)=o(N)
```

- finite harmonic weight:

```
sum exceptional 1/n
```

is bounded by dyadic shells with contribution

```
O(log N / N)
```

per shell.

- upper Banach density zero requires a stronger statement for arbitrary intervals, not only initial segments. A uniform estimate on every interval [X+1,X+H] with H comparable to X is not enough by itself; one needs the same bound relative to arbitrary long intervals. The dyadic result alone does not automatically imply upper Banach density zero.

## Required repairs

To obtain a valid theorem, the proof needs:

1. A precise definition of the bad-prime set B_n.
2. A proof that all p in B_n for n in (N,2N] lie in a common universe of size O(N/log N), or a decomposition into controlled prime ranges.
3. A corrected codegree lemma replacing the false implication p<=h.
4. A statement of constants uniform in epsilon and in all channel decompositions.
5. A separate argument for upper Banach density zero (not merely dyadic density).

With these repairs the incidence strategy may work, but the present proof has a fatal gap before the M=O_epsilon(1) conclusion.
