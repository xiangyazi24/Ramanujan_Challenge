# Q8601 — SCRT target-Apéry gate audit

## 1. Exact CRT residue statement

Fix signs `s=(s_1,s_2,s_3)` and defects `d_1=0,d_2,d_3`. Put

\[
 u_i(t)=s_i(t+d_i+\tau_i),\qquad \tau_i=(1-s_i)/2.
\]

For a regular hit with prime `p_i`, the folded zero condition gives an admissible folded root `u_i(t)` and a quotient coefficient `c_i` satisfying

\[
 c_i p_i-c_1p_1=d_i.
\]

After ordering `p_1<p_2<p_3`, the first coefficient satisfies

\[
 c_1p_1\equiv d_2\pmod {p_2},\qquad c_1p_1\equiv d_3\pmod {p_3}.
\]

Because `p_1` is coprime to `p_2p_3`, this determines a unique class

\[
 c_1\equiv \kappa\pmod {p_2p_3},
\]

where

\[
\kappa\in[0,p_2p_3),
\]

and

\[
\kappa\equiv d_2p_1^{-1}\pmod {p_2},\qquad
\kappa\equiv d_3p_1^{-1}\pmod {p_3}.
\]

Hence every physical target triple, since `1\le c_1\le X-1`, satisfies

\[
1\le \kappa\le X-1.
\]

Therefore

\[
T_{target}(E,s,d)\le SCRT_X(s,d)
\]

is valid provided `SCRT` is defined as the same ordered-prime sum with only this necessary condition retained.

## 2. No coefficient ambiguity

Suppose two coefficients `c,c'` both satisfy the congruences. Then

\[
(c-c')p_1\equiv0\pmod {p_2p_3}.
\]

Since `p_1` is invertible modulo `p_2p_3`,

\[
 c-c'\equiv0\pmod {p_2p_3}.
\]

But both possible physical coefficients lie in `[1,X-1]`, while

\[
p_2p_3>X^2>X-1.
\]

Thus `c=c'`. There is no hidden second coefficient branch.

## 3. Sign conventions and edge cases

The folded convention is

\[
z=s u-(1-s)/2.
\]

For `s=1`, `z=u` and

\[
m=cp+u,
\]

with targetness `m<X^2` and `p>X` forcing

\[
1\le c\le X-1.
\]

For `s=-1`, `z=-u-1` and

\[
m=cp-u-1,
\]

so

\[
m+1=cp-u.
\]

Since `u<X` and the smallest target negative branch has `c=1` excluded by the lower-root convention, the regular range is

\[
2\le c\le X-1.
\]

The exceptional cases are:

* `p=m`: then `q=1,r=0`; it is not represented by a regular negative branch and must be isolated in the endpoint correction.
* `r=0`: folded root `u=0`; this is the central endpoint and belongs only if `B_0=1` gives an actual zero condition (it does not).
* self-reflection `r=p-1-r`: this means `r=(p-1)/2`; it is a single folded root and has no doubled sign sector.
* The CRT uniqueness remains true because it only uses distinct primes.

For `X=1`, there are no shell primes and all counts vanish.
For `X=2`, shell primes are empty or isolated endpoints; the coefficient intervals are empty.
For `X=4`, the inequalities remain valid, with positive coefficients `1,2,3` and negative coefficients `2,3` when applicable.

## 4. Does SCRT imply DSEL3?

Yes as a conditional implication. Let a span be represented by the full defect vector. The six defect permutations/sign orderings give

\[
6\Delta
\]

physical realizations per unordered span. If

\[
SCRT_X(s,d)\le X^{o(1)}\lambda_X^3
\]

uniformly for all admissible `s,d`, then summing over the defect sectors gives

\[
DSEL3(X)
\ll
(14X-8)\cdot 6\cdot X^{o(1)}\lambda_X^3,
\]

with the same normalization as the selector count.

The implication is valid; the missing point is proving SCRT.

## 5. Can short CRT prove SCRT?

A reciprocal large-sieve argument would need a bound of the form

\[
\sum_t\sum_{p_1<p_2<p_3}
1_{u_i(t)\in Z_{p_i}}
1_{1\le\kappa\le X-1}
\ll X^{o(1)}\lambda_X^3.
\]

The CRT indicator is not independent: `t` simultaneously controls three folded roots. Existing reflection symmetry only gives

\[
Z_p=\{r:p-1-r\in Z_p\},
\]

and does not supply cancellation for the short interval condition on `\kappa`.

An Apéry recurrence input would need a new statement controlling the joint distribution of

\[
(B_{u_1(t)}\bmod p_1,
 B_{u_2(t)}\bmod p_2,
 B_{u_3(t)}\bmod p_3)
\]

along the CRT line. No such theorem is currently available.

## 6. Reflection-compatible obstruction

The known reflection involution preserves all folded-root membership conditions. Hence a countermodel can take each `Z_p` to be a union of reflection pairs with the same cardinality as the true Apéry sets, but align the CRT classes so that the same `t` supports many triples. This preserves:

* reflection;
* folded-root admissibility;
* the CRT residue definition;

while violating the required `\lambda^3` suppression.

Therefore reflection alone cannot prove SCRT.

## 7. Status

The SCRT reduction is mathematically exact as an upper-bound gateway. The unique CRT coefficient claim is proved. Sign ranges and edge cases introduce no off-by-one correction.

Missing theorem:

\[
SCRT_X(s,d)\ll X^{o(1)}\lambda_X^3.
\]

This requires genuinely new Apéry cross-characteristic information; it does not follow from equidistribution, reflection, or the shifted-gcd formulation.
