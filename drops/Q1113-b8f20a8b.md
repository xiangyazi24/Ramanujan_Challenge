# Q1113 audit: shifted even-q carrier

## 1. Verdict on the proposed even-q lemma

The stated carrier argument is essentially correct for the specified shift
\[
h=\lceil r/2\rceil+1,
\qquad E=h+M-1=Qp+r,
\]
provided the hypotheses are interpreted as \(0\le r<p\), \(p\ge7\), \(p^2>n\), and \(q=2Q\). The only delicate points are the lower endpoints \(r=0,1\) and the claim that the first binomial has exactly the same unit set.

There is no hidden carry from the second binomial once it is written in the correct form.

For
\[
W_j=\binom{n-h}{j-h}\binom{n-j-1}{E-j},
\]
we have
\[
(n-j-1)-(E-j)=n-E-1=Qp-1.
\]
In base \(p\), because \(Q<p/2\),
\[
Qp-1=(Q-1)(p-1)_p.
\]
Kummer says
\[
\binom{n-j-1}{E-j}
\]
is a \(p\)-unit exactly when subtracting \(E-j\) from \(n-j-1\) creates no borrow. The low digit of the top is \(p-1\), hence the low digit of \(E-j\) must be zero. Therefore
\[
E-j\equiv0\pmod p,
\]
so
\[
j\equiv r\pmod p.
\]
The higher digits introduce no further borrow because \(E-j\le Qp+r-h\) and \(2Q<p\).

Hence the candidates from the second factor are exactly
\[
j=ap+r.
\]
The node interval is
\[
h\le j\le E=Qp+r.
\]
Therefore:

* if \(r\ge2\), \(j=r, p+r,\ldots,Qp+r\), giving
  \[
  U_2=\{ap+r:0\le a\le Q\};
  \]
* if \(r=0,1\), the first candidate is below \(h\), giving
  \[
  U_2=\{ap+r:1\le a\le Q\}.
  \]

This endpoint loss is exactly the reason the \(r=0,1\) cases must be separated.

## 2. First binomial audit

The first factor is
\[
\binom{n-h}{j-h}.
\]
For \(j=ap+r\), Lucas gives a unit precisely when the base-\(p\) digits of \(j-h\) are bounded by those of \(n-h\).

Now
\[
h=\lceil r/2\rceil+1.
\]
The subtraction only affects the residue digit. The choice of \(h\) ensures that the residue digit of \(n-h\) is large enough exactly at the above candidates and no others. The possible carry into the \(Qp\)-digit is absorbed because
\[
2Q<p.
\]
Thus the first factor does not remove any member of the second-binomial unit set and does not add any new unit indices.

Therefore the complete \(p\)-unit support of \(W_j\) is:
\[
U=
\begin{cases}
\{ap+r:0\le a\le Q\},&r\ge2,\\
\{ap+r:1\le a\le Q\},&r=0,1.
\end{cases}
\]

## 3. Apéry Lucas step

For \(m<p\), Apéry Lucas gives
\[
b_{ap+r}\equiv b_a b_r\pmod p.
\]
For the surviving indices:

* If \(r\ge2\), the index \(a=0\) occurs and
  \[
  b_r\equiv b_0b_r\pmod p
  \]
  appears directly.

* If \(r=0,1\), the index \(a=1\) survives. Since
  \[
  b_1=5,
  \]
  is a unit modulo every \(p\ge7\), the factor \(b_1b_r\) detects exactly whether \(p\mid b_r\).

Therefore
\[
p\mid\gcd_j W_jb_j
\iff
p\mid b_r.
\]

The proposed shifted even-q carrier theorem is certified.

## 4. Arbitrary shifts: can nuisance primes occur?

For a general shift \(h\), the support is no longer a single residue class. The same Kummer analysis gives
\[
U_h=\{j:\binom{n-h}{j-h}\binom{n-j-1}{h+M-1-j}\not\equiv0\pmod p\}.
\]
The second condition forces
\[
j\equiv h+M-1\pmod p
\]
up to endpoint effects, but the first binomial may remove different endpoints depending on the carries in \(n-h\).

Thus a general shifted carrier may test a set
\[
\{ap+s_h\}
\]
where \(s_h\) is the residue determined by the shift, not necessarily \(r\).

Apéry Lucas gives
\[
b_{ap+s_h}\equiv b_a b_{s_h}\pmod p.
\]
Consequently a nuisance prime could only survive if every surviving multiplier \(a\) satisfies
\[
b_a b_{s_h}\equiv0\pmod p.
\]
Since \(b_a,b_{a+1}\) cannot both vanish for \(0\le a<p-1\), a consecutive pair of surviving \(a\)-values prevents this unless
\[
p\mid b_{s_h}.
\]

Therefore the correct general statement is:

* A shift with two consecutive surviving Lucas multipliers forces the prime support back to the residue class attached to that shift.
* The special shift \(h=\lceil r/2\rceil+1\) is strong enough because it gives the full block of multipliers needed for the \(r\)-class.
* An arbitrary shift need not individually satisfy \(p\mid b_r\); it can detect another residue class \(s_h\) if its support collapses to that class.

So the stronger statement "every shifted Gamma has only the target support" does not follow from the adjacent-nonvanishing lemma alone.

## 5. Consequence for the lcm over all shifts

Let
\[
C_n=\operatorname{lcm}_{0\le h\le\lceil n/2\rceil}\Gamma_{n,h}.
\]
The data \(n\le500,h\le8\) show no nuisance large primes, but a proof requires a global statement about all possible residue classes generated by shifts.

The adjacent nonvanishing property proves that each individual shift cannot have an arbitrarily large accidental support interval. It does **not** prove that all shifts collapse to the original \(r=n\bmod p\) class.

Hence:

* The equality between the large-prime radical of \(C_n\) and the all-q target radical is plausible and supported by the computations.
* The proposed proof via only \(b_a,b_{a+1}\) non-simultaneous vanishing is insufficient.
* A complete proof needs an additional classification of all reachable residues \(s_h\) from the Kummer support as \(h\) varies.

## 6. Height/divisibility bound

Each \(\Gamma_{n,h}\) divides a gcd of integer combinations of Apéry numbers with binomial coefficients of size at most
\[
\exp(O(n)).
\]
Therefore
\[
\log C_n\le\sum_h O(n)=O(n^2)
\]
from the trivial lcm bound.

For a sharper characteristic-zero estimate, one would need overlap between shifts. The present argument proves the large-prime radical structure of the special carrier but does not imply an exact divisibility or height bound below the general exponential scale.

The strongest justified conclusion is:

\[
\operatorname{rad}_{p>\sqrt n}(\Gamma_{n,h_{even}})
\subseteq \operatorname{rad}(b_r)
\]
for the certified even-q shift, while the full lcm statement remains open pending a complete shifted-support classification.
