# Q891 audit: denominator degree two signed Newton--Padé theorem

## Verdict

NOT VALID as stated.  The argument has a genuine unproved step before the determinant sign conclusion.  The first fatal gap is the passage from the Edgar endpoint representation to the claimed arbitrary-order expansion with enough controlled remainder to justify the later termwise differencing.

The numerical statements may be true, and the finite verifier does not repair this logical gap, but the supplied proof is not theorem-grade.

## Proof ledger

### 1. Newton basis identities

The operator identity is correct.

For the Newton basis `binom{x}{k}` one has

```
x binom{x}{k}=k binom{x}{k}+(k+1)binom{x}{k+1}
```

and therefore multiplication by `x` gives

```
(Mz)_k=k(z_k+z_{k-1}).
```

The formulas

```
u_k=(Mc)_k,
v_k=(M^2c)_k
```

are valid.  The determinant reduction using

```
r_k=(c_k,u_k,v_k)
```

is also valid whenever `c_k>0`.

### 2. Positivity of c_k

The displayed recurrence does prove positivity of the sequence `c_k` assuming it is indeed the correct recurrence for these differences.  This part is not the obstruction.

### 3. Endpoint/Stieltjes step

The claimed input from Edgar is stronger than what has actually been established in the proof text.

A Stieltjes representation gives an integral of the form

```
c_k = integral (t-1)^k phi(t) dt.
```

An endpoint singular expansion of `phi` can give a Watson expansion.  However, the proof needs all of the following:

1. a local expansion at the dominant endpoint `t=c` in a variable `s=c-t`;
2. analyticity of the remaining factor in a full complex neighborhood needed for coefficient extraction;
3. a remainder estimate uniform to arbitrary fixed order;
4. a proof that the other part of the interval is exponentially smaller after the sign change from `(t-1)^k` is accounted for.

The text asserts these from Propositions 13 and 25 but does not prove that those propositions have exactly these hypotheses and conclusions.

In particular, the statement

```
phi(c-s)=C s^(1/2)(1+beta_1 s+beta_2 s^2+...)
```

is not enough by itself.  One needs a proved asymptotic expansion with a controlled error term after integration.  The proof cites Edgar but does not supply the required translation from the Heun representation to Watson's lemma.

### 4. Watson expansion and differencing

The claimed expansion

```
c_k=kappa gamma^k k^(-3/2)(1+alpha_1/k+alpha_2/k^2+alpha_3/k^3+O(k^-4))
```

is plausible, but not proved from the previous paragraphs.

This matters because the later cancellation is delicate.  The formulas

```
x_k=k(1+rho_k)

y_k=k(x_k+rho_k*x_{k-1})
```

are exact, but deriving

```
x_k=a k+B+C/k+O(k^-2)

y_k=a^2 k^2+Dk+E+F/k+O(k^-2)
```

requires enough terms of the expansion of `rho_k`.  The proof does not show the algebra or the error propagation.

The same issue occurs in

```
s_{k+1}-s_k=2a+O(k^-2).
```

The conclusion is probably correct if a sufficiently high-order Watson expansion is established, but the submitted argument has not established it.

### 5. Convexity argument

Conditional on the expansions, the large-k convexity argument is basically correct.

However, one sentence needs repair:

```
the slope from (x_k,y_k) to (x_{H-1},y_{H-1}) is a weighted average of s_{k+1},...,s_{H-1}
```

This requires the increments `x_{i+1}-x_i` to be positive for the whole range under consideration.  The proof only establishes this eventually.  For `k>=K` this is fine, but it must explicitly use the finite initial exclusion.

The fixed-small-k argument is sound only after proving

```
L_H(x)=-a^2 H^2+O(H)
```

with the actual constants.  The supplied proof gives only a heuristic derivation from (3.6).

### 6. Determinant sign and normalization

If all determinant signs are established, then

```
d_k=det(r_{H-1},r_H,r_k)/gcd(cross product)
```

has a consistent sign.

But two additional claims are not proved:

* positivity of all Newton coefficients does not alone prove `q_2 != 0`;
* rank one of the integral solution space requires an independent rank argument for the two constraints.

The finite numerical checks do not replace these asymptotic facts.

### 7. Entropy constant

The last numerical constant is wrong for the stated parameter.

The proof takes

```
H/n -> 1/3
```

and uses

```
binomial(n,H/2).
```

Therefore the exponential rate is

```
-log(r)-log(1-r)
```

with `r=1/6`, namely

```
-(1/6)log(1/6)-(5/6)log(5/6).
```

That calculation is correct and equals approximately `0.450561...`.

The entropy step is not the problem.

## Required repair

A valid proof needs to insert a lemma of the following form:

```
For every fixed m, there exist constants A_0,...,A_m and C_m such that

c_k = gamma^k k^(-3/2)(A_0+A_1/k+...+A_m/k^m+R_m(k))

with |R_m(k)| <= C_m k^(-m-1).
```

Then explicitly compute the induced expansion of `rho_k`, `x_k`, `y_k`, and the slope differences.  After that, the determinant proof can be completed.

## Final assessment

The theorem is not currently proved.  The first unproved step is the claim that Edgar Propositions 13 and 25 directly imply the arbitrary-order Watson expansion needed for the convexity argument.  No contradiction with the theorem is exhibited; the repair appears feasible, but it requires a missing analytic lemma rather than a cosmetic edit.
