# 5. CRT surjectivity: the exact elimination no-go

Let

\[
\alpha\in\mathbf F_p,
\qquad
\beta\in\mathbf F_q
\]

be arbitrary.  Because `q` is a unit modulo `p` and `p` is a unit modulo `q`, the simultaneous system

\[
qC\equiv\alpha\pmod p,
\qquad
pC\equiv\beta\pmod q
\]

is equivalent to

\[
C\equiv q^{-1}\alpha\pmod p,
\qquad
C\equiv p^{-1}\beta\pmod q.
\]

CRT gives one and only one `C mod pq`.  This proves `(5)`.

Applied to `(4)`, this says:

> once the two actual recurrence jets `theta_(p,r)` and `theta_(q,s)` have been computed, the common equality `p+r=q+s=m` imposes no further congruence between them at the second cell.

This is stronger than saying merely that “a new correlation is needed.”  It proves that the direct elimination problem has zero cross-prime codimension: every local pair of second-cell values glues.

One can express the same fact at the `p^2,q^2` level.  If `R_p` and `R_q` are any chosen integer representatives of the two gauged right sides, the system

\[
X\equiv R_p\pmod{p^2},
\qquad
X\equiv R_q\pmod{q^2}
\]

always has exactly one solution modulo `p^2q^2`.  Thus the primitive elimination resultant/content of the two affine congruence classes is a unit.  Any nontrivial integer carrier must insert additional pair-dependent multiples of `p` or `q`, or reinsert the common endpoint value itself.

# 6. Why the exact recurrence between `s` and `r` does not change the conclusion

The previous section treats the two local jets as already computed.  It remains to audit whether their exact common characteristic-zero recurrence relation can itself create a large-prime determinant.

The ordinary Apéry transfer is

\[
Y_{j+1}=M(j)Y_j,
\]

with

\[
M(j)=
\begin{pmatrix}
P(j)/(j+1)^3&-j^3/(j+1)^3\\
1&0
\end{pmatrix},
\]

and

\[
\det M(j)=\frac{j^3}{(j+1)^3}.
\]

Differentiating the transfer identity gives

\[
Z_{j+1}=M(j)Z_j+M'(j)Y_j.
\]

Hence the augmented homogeneous block is

\[
\mathbb M(j)=
\begin{pmatrix}
M(j)&0\\
M'(j)&M(j)
\end{pmatrix},
\]

so

\[
\det\mathbb M(j)
=\left(\frac{j}{j+1}\right)^6.
\]

Multiplying from `s` through `r-1` gives `(6)`.

At a collision `q|b_s`, so `s!=0`; therefore

\[
1\le s<r<p<q.
\]

The determinant `(s/r)^6` is a unit modulo both primes.  Thus the augmented transfer from

\[
(b_s,b_{s-1},G_s,G_{s-1})
\]

to

\[
(b_r,b_{r-1},G_r,G_{r-1})
\]

is an isomorphism over both local rings.  No `p`- or `q`-elementary divisor is available to a Smith/Fitting/resultant argument.

The target conditions are in different characteristics:

\[
q\mid b_s,
\qquad
p\mid b_r.
\]

Modulo `p`, the integer `q` is a unit, so `b_s=q(b_s/q)` is simply a freely scaled quotient coordinate.  Modulo `q`, the integer `p` is a unit, so `b_r=p(b_r/p)` is likewise a quotient coordinate.  The differentiated transfer does not turn either one into a same-characteristic double zero.

This proves the recurrence-specific scope of the no-go: **the full rank-four first differentiated transfer is locally unimodular at both defining primes.**

# 7. Fixed-endpoint collapse via the arithmetic derivative

This section is not proposed as a new proof route; it identifies exactly what the second-cell information becomes after the moving lower indices are removed.

For

\[
B=\prod_\ell \ell^{e_\ell},
\]

define

\[
\partial_aB=\sum_\ell e_\ell\frac{B}{\ell}.
\]

It obeys the product rule

\[
\partial_a(XY)=X\partial_aY+Y\partial_aX.
\tag{21}
\]

If `p|B`, then modulo `p` all summands with `ell!=p` vanish.  If `e_p=1`, the `p`-summand is `B/p`; if `e_p>=2`, both the `p`-summand and `B/p` are zero modulo `p`.  Hence `(8)` holds for every multiplicity.

Now put `B=b_m`.  At a top hit, `(2)` gives

\[
\frac{b_m}{p}
\equiv
5\left(\frac{b_{m-p}}p+G_{m-p}\right)
\pmod p.
\]

Using `(8)` yields `(9)`.

Thus **all top-prime second cells in one row are just reductions of the one fixed integer `partial_a b_m`.**  This is the strongest fixed-endpoint compression supplied by the first differentiated block.

For a pair `b_m=pqC`, the product rule gives

\[
\partial_a(pqC)
=(p+q)C+pq\partial_aC,

because

\[
\partial_a(pq)=p+q.

Multiplying by `pq` and using `b_m=pqC` proves `(11)` exactly.

A slightly smaller equivalent carrier is

Again, all `pq` support is universal content.

# 8. Content and height audit

## 8.1 Primitive normalization loses the pair

From `(11)`,

\[
\frac{K_{m;p,q}}{p^2q^2}
=\partial_a(b_m/pq).
\]

There is no reason for the right side to be divisible by either `p` or `q`; indeed if `b_m=pq`, it equals zero, and for a generic additional factor it is a unit at both primes.  Thus saturation by the actual universal content destroys the target support.

## 8.2 Keeping the content exactly charges pair energy

Let

\[
P_m=\{p:N<p\le m,\ p\mid b_m\},
\qquad
\lambda=|P_m|.
\]

For every unordered pair in `P_m`, the tautological carrier `(11)` contains `p^2q^2`.  The product of those contents is

\[
\prod_{p<q\in P_m}p^2q^2.
\]

Each prime `p in P_m` occurs in exactly `lambda-1` pairs, with exponent `2`.  Therefore

\[
\log\prod_{p<q}p^2q^2
=2(\lambda-1)\sum_{p\in P_m}\log p,
\]

which is `(13)`.  Since all primes lie in `(N,2N]`, `(14)` follows.

Thus universal content does not compress the heavy row; it is quantitatively equivalent to its second factorial moment up to one factor `log N`.

## 8.3 Archimedean height

The Apéry asymptotic gives

\[
\log b_m=m\log\alpha+O(\log m),
\qquad \alpha=17+12\sqrt2.
\]

Also

\[
\partial_aB
=B\sum_\ell\frac{e_\ell}{\ell}
\le \frac B2\sum_\ell e_\ell.
\]

Since

\[
2^{\sum e_\ell}\le B,
\]

\[
\partial_aB\le \frac{B\log B}{2\log2}.
\]

For `m<=2N`, this gives

\[
\log^+|K_{m;p,q}|
\le2N\log\alpha+O(\log N).
\]

So a pair-by-pair product over all candidate prime pairs has logarithmic height at most only the useless scale

\[
O(N^3/\log^2N).
\]

No `o(N^2)` aggregate carrier emerges.

There is a second quantitative warning.  A `p^2q^2` divisor contributes only

\[
2\log p+2\log q=O(\log N)
\]

of logarithmic divisibility per collision.  Therefore even if one somehow produced total carrier height `o(N^2)`, this multiplicity alone would imply only

\[
F_{\rm top}=o(N^2/\log N),
\]

not the required

\[
o(N^2/\log^2N).
\]

To close the physical target by height, one would need either total height `o(N^2/log N)`, an additional `Omega(log N)` p-adic multiplicity per collision, or a shared carrier that compresses many collisions at once.

def apery_and_jet(M):
    b = [0] * (M + 1)
    G = [Fraction(0) for _ in range(M + 1)]
    b[0], b[1] = 1, 5
    G[0], G[1] = Fraction(0), Fraction(12)

    for j in range(1, M):
        num = P(j)*b[j] - j**3*b[j-1]
        den = (j + 1)**3
        assert num % den == 0
        b[j+1] = num // den

    for j in range(1, M):
        rhs = (
            P(j)*G[j]
            - j**3*G[j-1]
            + P1(j)*b[j]
            - 3*(j+1)**2*b[j+1]
            - 3*j**2*b[j-1]
        )
        G[j+1] = rhs / (j + 1)**3

    return b, G


def rat_mod(x, mod):
    x = Fraction(x)
    assert gcd(x.denominator, mod) == 1
    return (x.numerator * pow(x.denominator, -1, mod)) % mod


def gamma(j, G):
    x = factorial(j)**3 * G[j]
    assert x.denominator == 1
    return x.numerator


def factorint(n):
    n = abs(n)
    out = []
    p = 2
    while p*p <= n:
        if n % p == 0:
            e = 0
            while n % p == 0:
                n //= p
                e += 1
            out.append((p, e))
        p = 3 if p == 2 else p + 2
    if n > 1:
        out.append((n, 1))
    return out


def arithmetic_derivative(n):
    if n == 0:
        return 0
    ans = 0
    for p, e in factorint(n):
        ans += e * (n // p)
    return ans


def crt2(a, p, b, q):
    # x=a (mod p), x=b (mod q), gcd(p,q)=1
    t = ((b - a) * pow(p, -1, q)) % q
    return (a + p*t) % (p*q)


def check():

            - j**6*Gam[j-1]

# Final conclusion

The first recurrence-specific lift is exact:

\[
\boxed{b_{p+r}\equiv5(b_r+pG_r)\pmod{p^2}.}
\]

But for a physical cross-prime pair it reduces to

\[
\boxed{qC\equiv5\theta_{p,r}\pmod p,
\qquad pC\equiv5\theta_{q,s}\pmod q,
\qquad C=b_m/(pq),}
\]

and the map from `C mod pq` to the two local residues is a CRT bijection.  The exact differentiated recurrence transfer between `s` and `r` is `p,q`-unimodular, with determinant `(s/r)^6`, so it supplies no hidden large-prime content.

After eliminating the moving lower indices, the whole second cell is just

\[
5\theta_{p,m-p}\equiv\partial_a b_m\pmod p.
\]

For a pair, the canonical integer elimination is the universal identity

\[
\boxed{
pq\,\partial_a b_m-(p+q)b_m
=p^2q^2\,\partial_a(b_m/pq).}
\]

Thus every `p^2q^2` factor is generic content already forced by `pq|b_m`; primitive saturation removes all pair support.  Keeping the content charges the row by `Theta(lambda(m)(lambda(m)-1) log N)`, i.e. exactly the pair-energy scale.

So **the entire mod-`p^2` / first differentiated cell is terminal as a cross-prime carrier mechanism**.  A successful next attack must introduce genuinely new information not generated by this block: for example the second translation jet/mod-`p^3` cell, or a nonlinear two-characteristic invariant that is not a local-unit transform of the common quotient.
