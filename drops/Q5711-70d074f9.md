## 1. Setup

Write
\[
\Lambda^M=\sum_{\nu\in\mathbf Z^3}c_M(\nu)X^\nu,
\qquad
C_M(d)=\sum_{\nu\in d\mathbf Z^3}c_M(\nu).
\]
The one-fold coefficient formula from the current note is
\[
c_M(u,v,w)=
\sum_{t=0}^M
\binom Mt\binom M{t-u}
\binom{2M-t}{M-v}
\binom{2M-t}{M-w}.
\tag{1.1}
\]
For \(d>M/2\), the quotient is one and summing \(u,v,w\in\{-1,0,1\}\) gives
\[
C_M(d)=\sum_{t=0}^M\binom Mt X_{M,d}(t)Z_{M,d}(t)^2,
\tag{1.2}
\]
where
\[
X_{M,d}(t)=
\binom M{t-d}+\binom Mt+\binom M{t+d},
\tag{1.3}
\]
\[
Z_{M,d}(t)=
\binom{2M-t}{M-d}+\binom{2M-t}{M}
+\binom{2M-t}{M+d}.
\tag{1.4}
\]
All binomial coefficients outside their natural range are zero.

Put
\[
d=M-r,\qquad 0\le r<d.
\tag{1.5}
\]
For each \(t\), abbreviate
\[
A_t=\binom Mt,
\quad B_t=\binom{2M-t}{M},
\quad P_t=\binom{2M-t}{r},
\tag{1.6}
\]
\[
Q_t=\binom{2M-t}{r-t},
\qquad U_t=\binom M{r-t}.
\tag{1.7}
\]
Then

- \(P_t\) is the globally present \(M-d=r\) term in \(Z\);
- \(Q_t\) and \(U_t\) are supported only on \(0\le t\le r\);
- the remaining term \(\binom M{t-d}\) is supported only on \(d\le t\le M\).

The low and high supports are disjoint because \(r<d\).

## 2. The exact first-cell decomposition

### Theorem 2.1

For \(d=M-r>M/2\),
\[
\boxed{
C_M(M-r)=b_M+K_M(r)+L_M(r)+H_M(r),
}
\tag{2.1}
\]
where
\[
\boxed{
K_M(r)=
\sum_{t=0}^M A_t^2\bigl(2B_tP_t+P_t^2\bigr),
}
\tag{2.2}
\]
\[
\boxed{
L_M(r)=
\sum_{t=0}^r A_t
\left\{
 A_t\bigl(2(B_t+P_t)Q_t+Q_t^2\bigr)
 +U_t(B_t+P_t+Q_t)^2
\right\},
}
\tag{2.3}
\]
and
\[
\boxed{
H_M(r)=
\sum_{k=0}^r
\binom Mk\binom M{r-k}
\left(\binom{M+k}{k}+\binom{M+k}{r}\right)^2.
}
\tag{2.4}
\]

Thus the only sums whose length depends on the distance from the endpoint are \(L_M(r)\) and \(H_M(r)\), each with exactly \(r+1\) possible summands.

### Proof

The central part of (1.2) is
\[
\sum_{t=0}^M A_t^2B_t^2=b_M.
\tag{2.5}
\]
First insert the globally present term \(P_t\) into \(Z\):
\[
A_t\cdot A_t(B_t+P_t)^2
=A_t^2B_t^2+A_t^2(2B_tP_t+P_t^2).
\]
Summing gives \(b_M+K_M(r)\).

For \(t\le r\), the two extra terms are \(U_t\) in \(X\) and \(Q_t\) in \(Z\). Relative to the baseline \(A_t(B_t+P_t)^2\), the correction inside the outer factor \(A_t\) is
\[
A_t\bigl(2(B_t+P_t)Q_t+Q_t^2\bigr)
+U_t(B_t+P_t+Q_t)^2,
\]
which is (2.3).

For \(t\ge d=M-r\), only \(X\) has an additional term. Put \(k=M-t\). Then \(0\le k\le r\), and
\[
A_t=\binom Mk,
\qquad
\binom M{t-d}=\binom M{r-k},
\]
\[
B_t=\binom{M+k}{k},
\qquad
P_t=\binom{M+k}{r}.
\]
This gives (2.4). The two correction ranges are disjoint, so there is no missing overlap term. \(\square\)

### Plain ASCII form

```text
r = M-d, 0 <= r < d
A_t = C(M,t)
B_t = C(2M-t,M)
P_t = C(2M-t,r)
Q_t = C(2M-t,r-t)
U_t = C(M,r-t)

C_M(M-r) = b_M + K_M(r) + L_M(r) + H_M(r)

K_M(r) = sum_{t=0}^M A_t^2 * (2*B_t*P_t + P_t^2)

L_M(r) = sum_{t=0}^r A_t * (
    A_t*(2*(B_t+P_t)*Q_t + Q_t^2)
  + U_t*(B_t+P_t+Q_t)^2
)

H_M(r) = sum_{k=0}^r C(M,k)*C(M,r-k)
         * (C(M+k,k)+C(M+k,r))^2
```

## 3. Endpoint collapse and the surviving Apéry core

Define the \(\zeta(2)\)-Apéry number
\[
u_M=\sum_{k=0}^M\binom Mk^2\binom{M+k}{k},
\tag{3.1}
\]
and put
\[
B_M=\binom{2M}{M}.
\tag{3.2}
\]

### Corollary 3.1

At \(d=M\), equivalently \(r=0\),
\[
\boxed{
C_M(M)=b_M+2u_M+B_M^2+7B_M+11.
}
\tag{3.3}
\]

### Proof

At \(r=0\),
\[
K_M(0)=\sum_t\binom Mt^2(2B_t+1)=2u_M+B_M,
\]
using \(\sum_t\binom Mt^2=B_M\). The low boundary consists only of \(t=0\):
\[
L_M(0)=B_M^2+6B_M+7.
\]
The high boundary consists only of \(k=0\):
\[
H_M(0)=4.
\]
Adding gives (3.3). \(\square\)

This formula is already informative: the first-cell shell does not reduce to the original \(b_M\) plus a fixed number of binomial products. It contains the independent holonomic sequence \(u_M\).

## 4. Exact coefficient extraction for the long core

Define
\[
U_M(z)=\sum_{k=0}^M
\binom Mk^2\binom{M+k}{k}z^k,
\tag{4.1}
\]
and
\[
J_n(z)=\sum_{j=0}^n\binom nj^2z^j.
\tag{4.2}
\]
Write
\[
K_M(r)=2S_{1,M}(r)+S_{2,M}(r),
\]
with
\[
S_{1,M}(r)=\sum_t A_t^2B_tP_t,
\qquad
S_{2,M}(r)=\sum_t A_t^2P_t^2.
\]

### Theorem 4.1

The ordinary generating polynomial of the full-support core is
\[
\boxed{
\mathcal K_M(z):=\sum_{r\ge0}K_M(r)z^r
=2(1+z)^M U_M(1+z)
 +\sum_{k=0}^M\binom Mk^2J_{M+k}(z).
}
\tag{4.3}
\]

### Proof

Set \(k=M-t\). Then
\[
A_t=\binom Mk,
\qquad B_t=\binom{M+k}{k},
\qquad P_t=\binom{M+k}{r}.
\]
Hence
\[
\sum_rS_{1,M}(r)z^r
=\sum_k\binom Mk^2\binom{M+k}{k}(1+z)^{M+k}
=(1+z)^MU_M(1+z).
\]
Similarly,
\[
\sum_rS_{2,M}(r)z^r
=\sum_k\binom Mk^2\sum_r\binom{M+k}{r}^2z^r
=\sum_k\binom Mk^2J_{M+k}(z).
\]
This proves (4.3). \(\square\)

The polynomial \(J_n\) may equivalently be written using a Legendre polynomial,
\[
J_n(z)=(1-z)^nP_n\!\left(\frac{1+z}{1-z}\right),
\]
but that representation does not remove the remaining sum over \(k\).

## 5. Applying high finite differences

Let
\[
F_M(r)=C_M(M-r)-b_M=K_M(r)+L_M(r)+H_M(r).
\tag{5.1}
\]
Define the backward difference
\[
\nabla f(r)=f(r)-f(r-1),
\]
with \(F_M(r)=0\) for \(r<0\). Since increasing \(d\) by one decreases \(r=M-d\) by one,
\[
\boxed{
\Delta_d^jC_M(d)=(-1)^j\nabla_r^jF_M(r),
\qquad r=M-d.
}
\tag{5.2}
\]
For the long core, (4.3) gives
\[
\boxed{
\nabla^jK_M(r)=[z^r](1-z)^j\mathcal K_M(z).
}
\tag{5.3}
\]
Therefore the complete exact formula is
\[
\boxed{
\begin{aligned}
\Delta_d^jC_M(d)=(-1)^j\{&[z^r](1-z)^j\mathcal K_M(z)\\
&+\nabla^jL_M(r)+\nabla^jH_M(r)\}.
\end{aligned}}
\tag{5.4}
\]
Here
\[
\nabla^jL_M(r)=
\sum_{i=0}^j(-1)^i\binom jiL_M(r-i),
\tag{5.5}
\]
and the same formula holds for \(H_M\). Every term on the right is explicit; the two boundary pieces use only sums of length at most \(r+1\).

### Plain ASCII form

```text
F_M(r) = C_M(M-r)-b_M = K_M(r)+L_M(r)+H_M(r)

Delta_d^j C_M(d) = (-1)^j * nabla_r^j F_M(r), r=M-d

nabla^j K_M(r) = coeff(z^r, (1-z)^j * Kcal_M(z))

Kcal_M(z) = 2*(1+z)^M*U_M(1+z)
            + sum_{k=0}^M C(M,k)^2*J_{M+k}(z)

Delta_d^j C_M(d) = (-1)^j * (
    coeff(z^r,(1-z)^j*Kcal_M(z))
  + nabla^j L_M(r)
  + nabla^j H_M(r)
)
```

This is the strongest clean factorization I can prove. It inserts the expected high-difference factor \((1-z)^j\), but it does **not** turn the actual shell into a bounded number of endpoint values.

## 6. Rigorous Gosper obstruction

The first summand in the endpoint core is
\[
u_M=\sum_{k=0}^Mh_M(k),
\qquad
h_M(k)=\binom Mk^2\binom{M+k}{k}.
\tag{6.1}
\]
Its term ratio is
\[
\frac{h_M(k+1)}{h_M(k)}
=\frac{(M-k)^2(M+k+1)}{(k+1)^3}
=\frac{A(k)}{B(k)}.
\tag{6.2}
\]

### Theorem 6.1

There is no rational function \(R(M,k)\in\mathbf Q(M)(k)\) satisfying
\[
h_M(k)=\Delta_k\bigl(R(M,k)h_M(k)\bigr).
\tag{6.3}
\]

### Proof

Equation (6.3) is equivalent to
\[
A(k)R(k+1)-B(k)R(k)=B(k),
\tag{6.4}
\]
where
\[
A(k)=(M-k)^2(M+k+1),
\qquad B(k)=(k+1)^3.
\]
Over \(\mathbf Q(M)[k]\), \(A(k)\) is coprime to every nonnegative integer shift of \(B(k)\): the roots \(M,-M-1\) cannot equal a constant shifted root \(-j-1\). Thus the standard Gosper denominator lemma has dispersion zero and any rational solution of (6.4) must be a polynomial.

Let \(R(k)=ck^n+\cdots\). For \(n\ge2\), the coefficient of \(k^{n+2}\) on the left of (6.4) is
\[
c(n-M-2),
\]
which cannot vanish identically in \(\mathbf Q(M)\), whereas the right side has degree three. Hence \(n\le1\).

Put \(R(k)=ak+b\). Comparing the \(k^3\) and \(k^2\) coefficients gives
\[
a=-\frac1{M+1},
\qquad
b=\frac{M-1}{M+2}.
\]
The \(k\) coefficient then requires
\[
(M+1)(2M^2+1)=0,
\]
which is impossible over \(\mathbf Q(M)\). Therefore no rational solution exists. \(\square\)

### Scope

This proves that the \(u_M\) core has no first-order rational Gosper boundary certificate. It does **not** prove that every possible creative telescoper for the complete \(C_M(d)\) is impossible. In particular it leaves open:

- a higher-order telescoper in \(M\), \(d\), or \(r\);
- cancellation between the two long core pieces and the two boundary pieces;
- a determinant or resultant exploiting several adjacent \(d\)-values.

It does show that a claimed one-term Chu--Vandermonde/Gosper collapse must contain genuinely new cancellation; it cannot come from summing the most visible hypergeometric core term by itself.

## 7. Exact primitive residual for adjacent Newton carriers

Let
\[
Y_d=C_M(d),
\qquad
H_{d,L}=\Delta^{L+1}Y_d,
\qquad
B_{d,L}=\binom{d+L+1}{L}.
\tag{7.1}
\]
The exact adjacent identity is
\[
G_{d,L}-G_{d+1,L}=(-1)^{L+1}B_{d,L}H_{d,L}.
\tag{7.2}
\]
Define
\[
\rho_{M,d,L}=\gcd(G_{d,L},H_{d,L}).
\tag{7.3}
\]

### Theorem 7.1

One has the exact factorization
\[
\boxed{
\gcd(G_{d,L},G_{d+1,L})
=\rho_{M,d,L}
 \gcd\!\left(\frac{G_{d,L}}{\rho_{M,d,L}},B_{d,L}\right).
}
\tag{7.4}
\]

### Proof

Write
\[
G_{d,L}=\rho g,
\qquad H_{d,L}=\rho h,
\qquad \gcd(g,h)=1.
\]
Then by (7.2),
\[
\gcd(G_{d,L},G_{d+1,L})
=\gcd(\rho g,\rho(g\pm B_{d,L}h))
=\rho\gcd(g,B_{d,L}h).
\]
Since \(g\) and \(h\) are coprime, this is
\[
\rho\gcd(g,B_{d,L}),
\]
which is (7.4). \(\square\)

Thus:

- \(B_{d,L}\) carries the node-prime content forced by interpolation;
- \(\rho_{M,d,L}\) is the exact actual-shell residual not explained by that prefactor.

This is stronger than merely saying that the binomial prefactor is large: it separates the two sources of the gcd exactly.

## 8. Small rectangle boundary gcd

For \(w\ge1\), put
\[
D_w=\gcd(G_{d,L},G_{d+1,L},\ldots,G_{d+w,L}).
\tag{8.1}
\]
Successive Euclidean row operations using (7.2) give
\[
\boxed{
D_w=\gcd\left(
G_{d,L},
B_{d,L}H_{d,L},
B_{d+1,L}H_{d+1,L},\ldots,
B_{d+w-1,L}H_{d+w-1,L}
\right).
}
\tag{8.2}
\]
Define
\[
P_w=\prod_{s=0}^{w-1}B_{d+s,L}
\tag{8.3}
\]
and
\[
\boxed{
\rho^{(w)}_{M,d,L}=\gcd\left(
G_{d,L},H_{d,L},H_{d+1,L},\ldots,H_{d+w-1,L}
\right).
}
\tag{8.4}
\]
For an integer \(N\), write
\[
N^{(P)}=N\Big/\prod_{p\mid P}p^{v_p(N)}
\tag{8.5}
\]
for removal of all prime powers supported on \(P\).

### Theorem 8.1

\[
\boxed{
D_w^{(P_w)}=\left(\rho^{(w)}_{M,d,L}\right)^{(P_w)}.
}
\tag{8.6}
\]

### Proof

For every prime \(p\nmid P_w\), all \(B_{d+s,L}\) are \(p\)-adic units. Taking the minimum of the \(p\)-adic valuations in (8.2) gives exactly the minimum in (8.4). Removing primes dividing \(P_w\) proves (8.6). \(\square\)

This is the clean actual-shell replacement for the universal interpolation module: after all node-binomial content is removed, the rectangle problem is exactly the gcd of one Newton carrier and a short run of explicit high finite differences of the distinguished shell.

## 9. What can be bounded unconditionally?

The exact decomposition yields the elementary estimates
\[

\tag{9.1}

\[
|\Delta^{L+1}C_M(d)|\le2^{L+1}40^M.
\tag{9.2}

Consequently
\[
\log\rho^{(w)}_{M,d,L}=O(M+L),
\tag{9.3}

but this is still linear in \(M\) in the first cell. The formulas above do not currently improve it to \(o(M)\).

The obstacle is now precise rather than generic:

> Bound the prime support or logarithmic height of
> \[
> \rho^{(w)}_{M,d,L}
> =\gcd\left(
> G_{d,L},
> \Delta^{L+1}C_M(d),\ldots,
> \Delta^{L+1}C_M(d+w-1)
> \right)
> \]
> after removing primes dividing
> \(\prod_{s=0}^{w-1}\binom{d+s+L+1}{L}\), using the explicit decomposition (2.1)--(2.4).

A sufficient theorem for the adjacent-target application would be, uniformly for \(L,w=O(\log M)\) in a compact subinterval of \((M/2,M)\),
\[
\log\left(\rho^{(w)}_{M,d,L}\right)^{(P_w)}=o(M^{1/3}),
\tag{9.4}
\]
or even the stronger observed pattern
\[
\left(\rho^{(w)}_{M,d,L}\right)^{(P_w)}=1.
\tag{9.5}
\]
Neither statement is proved here.

    out = 0
    for t in range(M + 1):
        X = sum(C(M, t + d*u) for u in range(-a, a + 1))
        N = 2*M - t
        Z = sum(C(N, M + d*v) for v in range(-a, a + 1))
        out += C(M, t) * X * Z * Z
    return out


def first_cell_parts(M, d):
    assert M//2 < d <= M
    r = M - d
    core = 0
    low = 0
    for t in range(M + 1):
        A = C(M, t)
        N = 2*M - t
        B = C(N, M)
        P = C(N, r)
        core += A*A*(2*B*P + P*P)
        if t <= r:
            Q = C(N, r - t)
            U = C(M, r - t)
            low += A * (
                A*(2*(B + P)*Q + Q*Q)
                + U*(B + P + Q)**2
            )
    high = 0
    for k in range(r + 1):
        high += (
            C(M, k)*C(M, r-k)
            * (C(M+k, k) + C(M+k, r))**2
        )
    bM = apery(M)
    return bM, core, low, high, bM + core + low + high


def zeta2_apery(M):
    return sum(C(M, k)**2 * C(M+k, k) for k in range(M + 1))


def endpoint(M):
    B = C(2*M, M)
    return apery(M) + 2*zeta2_apery(M) + B*B + 7*B + 11


def delta_values(values):
    values = values[:]
    while len(values) > 1:
        values = [values[i+1] - values[i] for i in range(len(values)-1)]
    return values[0]


def delta(M, d, order):
    return delta_values([shell(M, d+i) for i in range(order + 1)])


def weight(d, L, i):
    return (-1)**i * C(d+i, i) * C(d+L+1, L-i)

    return sum(weight(d, L, i)*shell(M, d+i) for i in range(L + 1))

    split = sum(delta_values([row[j] for row in rows]) for j in (1, 2, 3))
    assert delta(M, d, order) == split

## 11. Narrowest unresolved lemma

The adjacent Newton-carrier route has now been reduced to the following actual-shell statement.

### Primitive first-cell boundary lemma

Let \(M/2<d\), let \(L,w=O(\log M)\), and suppose all indicated stencils remain in the first quotient cell. Put
\[
P_w=\prod_{s=0}^{w-1}\binom{d+s+L+1}{L}
\]
and
\[
\rho^{(w)}_{M,d,L}
=\gcd\left(
G_{d,L},
\Delta^{L+1}C_M(d),\ldots,
\Delta^{L+1}C_M(d+w-1)
\right).
\]
Prove
\[
\boxed{
\log\left(\rho^{(w)}_{M,d,L}\right)^{(P_w)}=o(M^{1/3})
}
\tag{11.1}
\]
uniformly in the hard adjacent-target range.

By Theorem 8.1, this is exactly the primitive shifted-carrier gcd after removing node-binomial content. Formula (5.4) makes every entry an explicit coefficient of the two known holonomic polynomial families \(U_M,J_n\), plus two short boundary sums. The missing input is now a common-prime theorem for those **actual** coefficient extractions—not another interpolation or Smith argument.

A stronger and computationally plausible version is
\[
\boxed{
\left(\rho^{(w)}_{M,d,L}\right)^{(P_w)}=1.
}
\tag{11.2}
\]
The \(M=320\) six-stencil collapse supports (11.2), but the surviving \(\zeta(2)\)-Apéry core and Theorem 6.1 show why a proof will require more than a direct Gosper telescope.
