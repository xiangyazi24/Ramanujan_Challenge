## 1. Exact lattice normalization: the target really is a one-dimensional quotient class

Write the genuine slope rows as

\[
z_i=(1,e_i,T_i)\in\mathbf Z^3,
\qquad
r_i=(e_i,T_i)\in\mathbf Z^2.
\]

Let

\[
M:=\langle r_i\rangle_{\mathbf Z},
\qquad
L:=\langle r_i-r_j\rangle_{\mathbf Z}.
\]

For the full primitive selector window, the first coordinates generate `1`, so the row lattice `M` has a primitive first coordinate.  Let

\[
\Delta_2=\gcd_{i,j}\det(r_i,r_j),
\]

let

\[
\delta=\gcd_{i,j}(e_i-e_j),
\]

and let

\[
\Theta_3=\gcd_{i,j,k}\det(z_i,z_j,z_k),
\qquad
\Gamma=\Theta_3/\delta.
\]

The identity

\[
\det(z_i,z_j,z_k)
=
\det(r_j-r_i,r_k-r_i)
\]

shows directly, without any numerical HNF computation, that `Theta3` is the top determinantal divisor of `L`.  Since the first-coordinate image of `L` is `delta Z`, there are integers `C` and a primitive first-coordinate vector `v0=(1,B) in M` for which

\[
L=\mathbf Z(\delta,C)+\mathbf Z(0,\Gamma).
\]

Now

\[
M=L+\mathbf Z v_0.
\]

Consequently

\[
\Delta_2
=
\gcd\bigl(\Gamma,\,C-\delta B\bigr).
\]

Indeed these are precisely the two determinants of `v0` against the displayed generators of `L`; the determinant of the two `L` generators is `delta Gamma` and adds no new gcd.

It follows that the order of the class of `delta v0` in `M/L` is **exactly**

\[
\operatorname{ord}_{M/L}(\delta v_0)
=
\frac{\Gamma}{\Delta_2}.
\]

Hence, for every positive integer `c`,

\[
\boxed{
 c\,\delta v_0\in L
 \iff
 \frac{\Gamma}{\Delta_2}\mid c.
}
\tag{1.1}
\]

Thus the Q3439 target is not merely “morally related” to the Gamma quotient.  It is exactly

\[
\boxed{\Gamma/\Delta_2\mid16.}
\tag{1.2}
\]

What the HNF scans do **not** provide is a proof that (1.2) holds on every genuine full window.  Equation (1.1) identifies the exact theorem obligation; it does not discharge it.

## 2. Exact selector identities on the q=6 branches

For slope `s in {4,7}`, write

\[
y_t^{(s)}=b_{\sigma_s+s t},
\qquad
X_s=\frac{m+1+\sigma_s}{s},
\]

and

\[
U_{s,K}=\binom{-X_s}{K}
=(-1)^K\binom{X_s+K-1}{K}.
\]

Let

\[
G_s=\gcd_{K\in I_s}|U_{s,K}|,
\qquad
e_{s,K}=U_{s,K}/G_s.
\]

The exact negative-binomial recurrence is

\[
\boxed{
(K+1)e_{s,K+1}=-(X_s+K)e_{s,K}.
}
\tag{2.1}
\]

For the Newton partial sums

\[
T_{s,K}
=\sum_{h<K}U_{s,h}\,d_{s,h},
\qquad
d_{s,h}=\Delta^h y^{(s)}_0,
\]

we also have the exact update

\[
\boxed{
T_{s,K+1}-T_{s,K}=G_s e_{s,K}d_{s,K}.
}
\tag{2.2}
\]

The q=6 slope alignment used in the predecessor work can be parametrized by

\[
\begin{aligned}
m&=28Q-\tau-1,\\
\sigma_4&=\tau+4\alpha,
&X_4&=7Q+\alpha,\\
\sigma_7&=\tau+7\beta,
&X_7&=4Q+\beta.
\end{aligned}
\]

At a common 28-grid sampled Apéry node

\[
N=\tau+28b
\]

put

\[
K=7b-\alpha,
\qquad
L=4b-\beta.
\]

Then

\[
\sigma_4+4K=N=\sigma_7+7L
\]

and, crucially,

\[
X_4+K=7(Q+b),
\qquad
X_7+L=4(Q+b).
\]

Applying (2.1) on the two slopes therefore gives the exact denominator-free cross-slope selector syzygy

\[
\boxed{
4(K+1)e_{4,K+1}e_{7,L}
=
7(L+1)e_{7,L+1}e_{4,K}.
}
\tag{2.3}
\]

This is a genuine symbolic q=6 identity.  Its coefficients have only logarithmic bit-height in `m`; there is no hidden factorial or lcm denominator in (2.3).

So the selector side is **not** the obstruction.

## 4. Actual Apéry recurrence and sampled transfer

The committed project uses

\[
\boxed{
(n+1)^3b_{n+1}
=P(n)b_n-n^3b_{n-1},
}
\tag{4.1}
\]

with

\[
P(n)=34n^3+51n^2+27n+5,
\qquad
b_0=1,
\quad b_1=5.
\]

This is in `q32_newton.py` and independently in several other audit scripts.

Introduce the state

\[
Y_n=\binom{b_n}{b_{n-1}}
\]

and

\[
M_n=
\begin{pmatrix}
P(n)/(n+1)^3&-n^3/(n+1)^3\\
1&0
\end{pmatrix}.
\]

Then

\[
Y_{n+1}=M_nY_n,
\qquad
\det M_n=\frac{n^3}{(n+1)^3}.
\]

For a slope-`s` sample, the one-step sampled transfer is

\[
A_s(n)=M_{n+s-1}\cdots M_n

and hence

\[
\boxed{
\det A_s(n)=\frac{n^3}{(n+s)^3}.
}
\tag{4.2}
\]

This is the exact sampled second-order dynamics.  Clearing one sampled step costs only

\[
\prod_{h=1}^{s}(n+h)^3,
\]

so a **fixed number** of sampled-transfer steps has polynomial height and is harmless.

The problem is not local transfer; it is solving the inhomogeneous Green problem across the whole Newton window.

\[
\boxed{
T_{s,K}
=
X_s\binom{X_s+K-1}{K-1}

This follows by evaluating the degree-`K-1` interpolant through

The Green solution constructs one rationally, but with the denominator growth described in Section 5; and after summation by parts a boundary term remains.

## 8. Exact modular criterion for a genuine full-window counterexample

There is a clean way to convert any suspicious exact HNF output into a proof that does **not** rely on the HNF computation.

Let `ell` be an odd prime not dividing `delta`.  Suppose one can exhibit `a,b,c in F_ell`, with `(a,b) != (0,0)`, such that for **every actual full-window row**

\[
\boxed{
a e_i+bT_i=c\pmod\ell.}
\tag{8.1}
\]

Then the linear functional

\[
\phi(x,y)=ax+by
\]

annihilates every row difference, hence

\[
L\otimes\mathbf F_\ell
\subseteq\ker\phi.
\]

If additionally `ell` does not divide `Delta2`, then the original row lattice `M` has full rank modulo `ell`, so (8.1) gives a genuine nontrivial quotient class.  Finally, evaluating `phi` on the chosen primitive `v0` gives a direct witness:

\[
16\delta v_0\notin L
\]

whenever

\[
16\delta\,\phi(v_0)\ne0\pmod\ell.
\]

For an odd `ell` outside `delta`, this is especially simple because `16 delta` is a unit modulo `ell`.

This is the correct replacement for “HNF says there is an odd factor.”  It is an exact one-line modular obstruction once (8.1) is proved from the recurrences.

### 8.1 Recurrence propagation test for (8.1)

For adjacent rows on one slope,

\[
0
\equiv
 a(e_{K+1}-e_K)
+b(T_{K+1}-T_K).
\]

Using (2.1)-(2.2) and multiplying by `K+1` gives

\[
\boxed{
e_K\Bigl(
-a(X+2K+1)
+bG(K+1)d_K
\Bigr)
\equiv0\pmod\ell.}
\tag{8.2}
\]

On a window where `e_K` is an `ell`-unit, this is equivalent to

\[
\boxed{
bG(K+1)d_K
\equiv
a(X+2K+1)\pmod\ell.}
\tag{8.3}
\]

Thus a genuine full-window odd obstruction is not mysterious: it is exactly a first-order congruence for the **actual sampled Apéry Newton differences**.  One must prove (8.3) across each legal slope window using the sampled Apéry recurrence, and check one cross-slope anchor equality

\[
a(e_{4,A_4}-e_{7,A_7})
+b(T_{4,A_4}-T_{7,A_7})
\equiv0\pmod\ell.
\tag{8.4}
\]

At selector zeros modulo `ell`, use the undivided form (8.2); no illegal division is needed.

Equations (8.2)-(8.4) are the exact symbolic certificate I would demand before accepting a numerical odd HNF factor as a genuine counterexample.

## 11. What would finish Q3449 decisively

There are now only two acceptable exits.

### A. Uniform proof

For each of the ten q=6 residue types, produce an integral identity in the full row-difference lattice of the form

\[
16\delta v_0
=
\sum_i c_i(r_i-r_{i_0}),
\tag{11.1}
\]

with the `c_i` given symbolically in the branch parameters, and verify:

- all denominators cancel integrally;
- any remaining denominator divides the already-certified universal factor (not an lcm over the full window);
- coefficient height is at most subexponential in the global parameter;
- the identity uses the actual sampled Apéry recurrence, not a generic order-two surrogate;
- the surviving divided/curvature residual cancels identically.

The present exact recurrence reduction reaches the last bullet but does not prove it.

### B. Genuine full-window counterexample

Exhibit one actual q=6 full window and an odd prime `ell` together with `(a,b,c)` satisfying (8.1) on the entire window, prove (8.2)-(8.4) by the actual sampled Apéry recurrence, and verify

\[
\phi(16\delta v_0)\ne0\pmod\ell.
\]

That is strictly stronger than printing an HNF with an odd invariant and directly meets the “no HNF-alone” requirement.
