# P2.7: exact finite partial-fraction normalization

## Verdict

There is an exact bridge, with no index shift and no change to the Barnes
integrand in the question.

Let

```text
R_n(t) = prod_{r=1}^n (t-r)^3 /
         ((n!)^2 prod_{j=0}^n (t+j)),
Phi_n(t) = R_n(t) - R_n'(t)/2.
```

Under the project convention

```text
zudilinCombinedError n
  = (zeta(2)+zeta(3))*b_n - m_n,
```

the desired equality is

```text
zudilinCombinedError n = zudilinBarnesErrorIntegral n.
```

The shortest certificate has three pieces:

1. the complete finite partial fraction expansion of `R_n`, including its
   polynomial part;
2. a finite positive-Bernoulli functional giving the two Abel endpoint
   constants;
3. one explicit degree-six rational creative telescoper for `R_n` itself.

The same telescoper proves the recurrence for the common coefficient, the
`Li_2` numerator, and the `Li_3` numerator.  No separate harmonic-sum
Zeilberger calculation is needed.

The polynomial part is load-bearing.  Omitting it gives, already at `n=1`,
`8,8` instead of the correct `23/2,17/2`.

All `n`-dependent normalization and recurrence work below is finite algebra
over `Q`.  Besides the Abel--Barnes theorem already formalized in the project,
the only endpoint fact needed is the generic polynomial Abel lemma `(Abel-P)`
below; it has the explicit monomial proof displayed here and is independent of
`n`.

The normalization agrees with Section 2 and Theorem 2 of Zudilin,
[*Approximations to -, di- and tri-logarithms*](https://arxiv.org/abs/math/0409023).

# 1. Complete partial fractions

Put

```text
N_n(t) = prod_{r=1}^n (t-r)^3,
D_n(t) = prod_{j=0}^n (t+j).
```

For `0 <= j <= n`, define

```text
c(n,j) = (-1)^(n+j) * binom(n,j) * binom(n+j,j)^3.   (c)
```

Equivalently,

```text
c(n,j)
 = (-1)^(n+j) * (n+j)!^3 /
   ((n!)^2 * (j!)^4 * (n-j)!).
```

These are exactly the pole coefficients:

```text
Res_{t=-j} R_n(t) = c(n,j).                          (PF-res)
```

Indeed,

```text
prod_{r=1}^n (-j-r)^3
  = (-1)^n ((n+j)!/j!)^3,

prod_{0<=ell<=n, ell!=j} (ell-j)
  = (-1)^j j! (n-j)!,
```

and division gives `(PF-res)`.

There is a unique polynomial `P_n in Q[t]` such that

```text
R_n(t) = P_n(t) + sum_{j=0}^n c(n,j)/(t+j).          (PF)
```

For `n>=1`, `deg P_n=2*n-1`; set `P_0=0`.

The denominator-cleared certificate is

```text
N_n(t)
 = (n!)^2 D_n(t) P_n(t)
   + (n!)^2 sum_{j=0}^n c(n,j) D_n(t)/(t+j).          (PF-poly)
```

Every term in `(PF-poly)` is a polynomial.  To prove it, subtract the finite
residue sum from `N_n`; the result vanishes at each `-j`, hence is divisible by
`D_n`.  This is the preferred Lean statement: it uses no infinite sum and no
analytic residue API.

Define

```text
aPF_n = sum_{j=0}^n c(n,j).                          (aPF)
```

Thus

```text
aPF_n
 = (-1)^n sum_{j=0}^n
     (-1)^j binom(n,j) binom(n+j,j)^3.
```

This is Zudilin's `a_n`, to be identified with the project sequence `b_n`.
The positive Whipple transform is not needed for this bridge.

# 2. Exact `Li_2` and `Li_3` rational forms

For `s=1,2,3`, set

```text
H_j^(s)(z) = sum_{ell=1}^j z^ell/ell^s,
H_j^(s)    = H_j^(s)(1),
A_n(z)     = sum_{j=0}^n c(n,j) z^(-j).
```

For `0<z<1`,

```text
sum_{nu>=1} z^nu/(nu+j)^s
  = z^(-j) * (Li_s(z)-H_j^(s)(z)).                   (tail)
```

Differentiating `(PF)` termwise therefore gives

```text
r0_n(z) := sum_{nu>=1} z^nu R_n(nu)
         = A_n(z) Li_1(z) - B0_n(z),

r2_n(z) := -sum_{nu>=1} z^nu R_n'(nu)
         = A_n(z) Li_2(z) - B2_n(z),

r3_n(z) := (1/2) sum_{nu>=1} z^nu R_n''(nu)
         = A_n(z) Li_3(z) - B3_n(z),                 (Li)
```

where

```text
B0_n(z)
 = sum_j c(n,j) z^(-j) H_j^(1)(z)
   - sum_{nu>=1} z^nu P_n(nu),

B2_n(z)
 = sum_j c(n,j) z^(-j) H_j^(2)(z)
   + sum_{nu>=1} z^nu P_n'(nu),

B3_n(z)
 = sum_j c(n,j) z^(-j) H_j^(3)(z)
   - (1/2) sum_{nu>=1} z^nu P_n''(nu).               (Bz)
```

Power-sum generating functions of polynomials are rational, so
`A_n,B0_n,B2_n,B3_n` all lie in `Q(z)`.  Equations `(Li)` are the explicit
rational `Li_2`/`Li_3` approximants.

The raw functions in `(Bz)` generally diverge at `z=1`.  The finite source
forms are

```text
L2_n(z) = r2_n(z) - log(z) r0_n(z),
L3_n(z) = r3_n(z) - (log(z)/2) r2_n(z).               (regularized)
```

They are exactly the two pieces produced by differentiating the Abel factor in
the Barnes residue formula.

# 3. Positive-Bernoulli endpoint functional

Use the positive Bernoulli convention

```text
u/(1-exp(-u)) = sum_{d>=0} beta_d u^d/d!,
```

so

```text
beta_0=1, beta_1=1/2, beta_2=1/6, beta_3=0, ...
```

For `P(t)=sum_d p_d t^d`, define

```text
EB(P) = sum_d p_d beta_d.                             (EB)
```

In Mathlib 4.29, `beta_d` is the existing `bernoulli' d`, not `bernoulli d`:

```lean
bernoulli' 0 = 1
bernoulli' 1 = 1/2
bernoulli' 2 = 1/6
sum_bernoulli' n :
  sum k in range n, (n.choose k : Q) * bernoulli' k = n
```

See
[`Mathlib/NumberTheory/Bernoulli.lean`](https://github.com/leanprover-community/mathlib4/blob/v4.29.0/Mathlib/NumberTheory/Bernoulli.lean).
Using `bernoulli` would flip the degree-one sign.

## 3.1 Generic polynomial Abel lemma

Put `z=exp(-x)`.  For every polynomial `P`,

```text
lim_{x->0+}
  [x sum_{nu>=1} exp(-x*nu) P(nu)
   - sum_{nu>=1} exp(-x*nu) P'(nu)]
 = EB(P),                                             (Abel-P)
```

and therefore

```text
lim_{x->0+}
  (1/2) sum_{nu>=1} exp(-x*nu)
    [P''(nu)-x P'(nu)]
 = -(1/2) EB(P').                                    (Abel-P')
```

Here is an exact monomial derivation.  Let

```text
f(x)=1/(exp(x)-1),
S_d(x)=sum_{nu>=1} exp(-x*nu) nu^d=(-1)^d f^(d)(x).
```

For `P(t)=t^d`, the left side of `(Abel-P)` is

```text
x*S_d(x)-d*S_(d-1)(x)
 = (-1)^d * (d/dx)^d [x/(exp(x)-1)].                 (monomial)
```

The Taylor coefficient of `x/(exp(x)-1)` at degree `d` is the usual
negative-convention Bernoulli number divided by `d!`; multiplication by
`(-1)^d` gives `beta_d=bernoulli' d`.  Taking `x->0+` in `(monomial)` gives
`beta_d`; finite linearity proves `(Abel-P)`.  Applying `(Abel-P)` to `P'` and
negating one half gives `(Abel-P')`.

This is the only generic polynomial-tail endpoint lemma required by the
normalization.

## 3.2 Endpoint numerators

For a pole basis element,

```text
lim L2[1/(t+j)] = zeta(2)-H_j^(2),
lim L3[1/(t+j)] = zeta(3)-H_j^(3).
```

Consequently define

```text
b2PF_n
 = sum_{j=0}^n c(n,j) H_j^(2) - EB(P_n),             (b2PF)

b3PF_n
 = sum_{j=0}^n c(n,j) H_j^(3) + (1/2) EB(P_n'),      (b3PF)

mPF_n = b2PF_n+b3PF_n.                                (mPF)
```

Then

```text
lim_{z->1-} L2_n(z) = aPF_n*zeta(2)-b2PF_n,
lim_{z->1-} L3_n(z) = aPF_n*zeta(3)-b3PF_n,           (endpoint)
```

and

```text
pfCombinedError_n
 := aPF_n*(zeta(2)+zeta(3))-mPF_n
  = lim_{z->1-} [L2_n(z)+L3_n(z)].                    (PF-error)
```

This is the finite normalization of the already formalized Abel--Barnes
identity.

# 4. Finite shift lemma

It is shortest to regard the endpoint normalizer as a linear functional.
Suppose

```text
F(t)=P(t)+sum_{j=0}^N d_j/(t+j).
```

Define

```text
poleSum(F)=sum_j d_j,

lambda2(F)
 = poleSum(F)*zeta(2)
   - [sum_j d_j H_j^(2)-EB(P)],

lambda3(F)
 = poleSum(F)*zeta(3)
   - [sum_j d_j H_j^(3)+(1/2)EB(P')],

Lambda(F)=lambda2(F)+lambda3(F).                      (normalizer)
```

Thus

```text
poleSum(R_n)=aPF_n,
lambda2(R_n)=aPF_n*zeta(2)-b2PF_n,
lambda3(R_n)=aPF_n*zeta(3)-b3PF_n,
Lambda(R_n)=pfCombinedError_n.
```

Let `Delta F(t)=F(t+1)-F(t)`.  Then

```text
poleSum(Delta F)=0,
lambda2(Delta F)=F'(1),
lambda3(Delta F)=-(1/2)F''(1),
Lambda(Delta F)=F'(1)-F''(1)/2.                       (shift)
```

This is purely finite.

For the polynomial part,

```text
EB(P(t+1)-P(t))=P'(1),                               (EB-shift)
```

because for `P=t^d` it is exactly Mathlib's identity

```text
sum_{k=0}^{d-1} binom(d,k) beta_k=d.
```

For a pole basis element,

```text
1/(t+j+1)-1/(t+j)
```

has coefficients `-1` at `j` and `+1` at `j+1`, hence

```text
lambda2 = -(H_(j+1)^(2)-H_j^(2)) = -1/(j+1)^2
        = (1/(t+j))' evaluated at 1,

lambda3 = -(H_(j+1)^(3)-H_j^(3)) = -1/(j+1)^3
        = -(1/2)(1/(t+j))'' evaluated at 1.
```

Linearity proves `(shift)`.  In particular, `Lambda` annihilates a telescoping
difference whenever its certificate has a triple zero at `t=1`.

# 5. Explicit rational creative telescoper

Use

```text
alpha_n
 = 2*(946*n^2-731*n+153)*(2*n+1)*(n+1)^3,

beta_n
 = 2*(104060*n^6+127710*n^5+12788*n^4
      -34525*n^3-8482*n^2+3298*n+1071),

gamma_n
 = 2*n*(3784*n^5-1032*n^4-1925*n^3
        +853*n^2+328*n-184),

delta_n
 = (946*n^2+1161*n+368)*n*(n-1)^3.                  (rec-coeff)
```

The recurrence is

```text
alpha_n u_(n+1)-beta_n u_n
+gamma_n u_(n-1)-delta_n u_(n-2)=0,                  (Rec)
```

for `n>=2`.

## 5.1 Reduction to a polynomial identity

Finite-product cancellation gives

```text
R_(n+1)(t)/R_n(t)
 = (t-n-1)^3/((n+1)^2*(t+n+1)),

R_(n-1)(t)/R_n(t)
 = n^2*(t+n)/(t-n)^3,

R_(n-2)(t)/R_n(t)
 = n^2*(n-1)^2*(t+n)*(t+n-1)
   /((t-n)^3*(t-n+1)^3),

R_n(t+1)/R_n(t)
 = t^4/((t-n)^3*(t+n+1)).                            (ratios)
```

Seek

```text
S_n(t)=C_n(t)R_n(t),
C_n(t)=Qhat_n(t-n)/(t-n)^3.
```

Substitution reduces the telescoping equation to one polynomial identity.
Equating coefficients gives a unique degree-at-most-six solution `Qhat_n`.

## 5.2 The degree-six polynomial

Write

```text
Qhat_n(x)=q0(n)+q1(n)x+...+q6(n)x^6,
```

with

```text
q0(n)=
 -4*(n-1)^2*n^4*(2*n-1)*(946*n^2+1161*n+368),

q1(n)=
  2*(n-1)*n^3*(10*n^2-2*n-1)*(946*n^2+1161*n+368),

q2(n)=
 -n^3*(38*n^2-n-5)*(946*n^2+1161*n+368),

q3(n)=
  2448+5440*n-26056*n^2-43516*n^3
  +69621*n^4+156993*n^5+74734*n^6,

q4(n)=
 -2*(612+2971*n-12132*n^2-14629*n^3
     +41538*n^4+45408*n^5),

q5(n)=
 -3*(2*n^2+6*n+3)*(946*n^2-731*n+153),

q6(n)=
  (2*n+1)*(946*n^2-731*n+153).                       (Qhat)
```

Let

```text
alphaBar_n=alpha_n/(n+1)^2
          =2*(946*n^2-731*n+153)*(2*n+1)*(n+1).
```

The denominator-cleared certificate is

```text
(n+x)^4 Qhat_n(x+1)
- (x+1)^3*(x+2*n+1)*Qhat_n(x)

= alphaBar_n*(x-1)^3*x^3*(x+1)^3
  - beta_n*(x+1)^3*x^3*(x+2*n+1)
  + gamma_n*n^2*(x+2*n)*(x+1)^3*(x+2*n+1)
  - delta_n*n^2*(n-1)^2
      *(x+2*n)*(x+2*n-1)*(x+2*n+1).                 (CT-poly)
```

This is an identity in `Q[n,x]`; after expanding the definitions, Lean verifies
it with `ring` or `ring_nf`.

Using `(ratios)`, `(CT-poly)` is precisely

```text
alpha_n R_(n+1)(t)-beta_n R_n(t)
+gamma_n R_(n-1)(t)-delta_n R_(n-2)(t)
 = S_n(t+1)-S_n(t),                                  (CT)
```

where

```text
S_n(t)
 = Qhat_n(t-n)/(t-n)^3 * R_n(t)
 = Qhat_n(t-n) * prod_{r=1}^{n-1}(t-r)^3
   /((n!)^2 prod_{j=0}^n(t+j)).                       (S)
```

Use the cancelled second expression as the Lean definition, avoiding any
artifact from totalized division at `t=n`.

For `n>=2`, `(S)` contains `(t-1)^3`, while its denominator is nonzero at
`t=1`.  Hence

```text
S_n'(1)=0,
S_n''(1)=0.                                           (triple-zero)
```

## 5.3 Recurrence consequences

Apply `poleSum` to `(CT)`.  By `(shift)`, the right side has pole sum zero, so
`aPF` satisfies `(Rec)`.

Apply `lambda2` and `lambda3`.  By `(triple-zero)` and `(shift)`, their right
sides vanish.  Since

```text
lambda2(R_n)=zeta(2)*aPF_n-b2PF_n,
lambda3(R_n)=zeta(3)*aPF_n-b3PF_n,
```

and `aPF` already satisfies `(Rec)`, both `b2PF` and `b3PF` satisfy `(Rec)`.
Therefore so do

```text
mPF_n=b2PF_n+b3PF_n,
pfCombinedError_n=aPF_n*(zeta(2)+zeta(3))-mPF_n.      (Rec-all)
```

No irrationality or linear-independence theorem for the two zeta values is
used.  The displayed `S_n` is the requested explicit rational telescoper.

# 7. Recurrence uniqueness and project bridge

The leading coefficient never vanishes, since

```text
4*946*(946*n^2-731*n+153)
 = (1892*n-731)^2+44591 > 0.
```

Thus `alpha_n>0`, in particular at every recurrence step `n>=2`.

By `(Rec-all)`, the initial table, and recurrence uniqueness,

```text
aPF_n = project b_n,
mPF_n = project m_n                                    (bridge)
```

for every `n`.  If the local development also names Zudilin's two decorated
numerator sequences, the same argument separately gives
`b2PF=tilde_b` and `b3PF=double_tilde_b`; those auxiliary equalities are not
needed for the project bridge.

Combining `(PF-error)`, `(bridge)`, and the existing Abel--Barnes identity gives

```text
zudilinBarnesErrorIntegral n
 = Lambda(R_n)
 = aPF_n*(zeta(2)+zeta(3))-mPF_n
 = b_n*(zeta(2)+zeta(3))-m_n
 = zudilinCombinedError n.                            (final)
```

This is the requested pointwise normalization.

def bernoulliEval (P : Polynomial Q) : Q :=
  P.sum fun d q => q * bernoulli' d

def poleCoeff (n j : N) : Q :=
  (-1 : Q)^(n+j) * n.choose j * (n+j).choose j ^ 3

def b2PF (n : N) : Q :=
  (sum j in range (n+1), poleCoeff n j * harmonicPow 2 j)
    - bernoulliEval (P n)

def b3PF (n : N) : Q :=
  (sum j in range (n+1), poleCoeff n j * harmonicPow 3 j)
    + bernoulliEval ((P n).derivative) / 2

after expanding `Qhat`, its proof is

# 9. Normalization mismatch audit

There is no mathematical mismatch under the convention in the question.
Check these four implementation traps:

1. **Error sign.**  The formula is for
   `b_n*(zeta2+zeta3)-m_n`.  If the local definition is the negative, the
   Barnes integral is also negated.
2. **Contour orientation.**  The equality assumes the upward vertical line
   and the `1/(2*pi*i)` prefactor audited in Q6044.  Reversing the line flips
   the sign.
3. **Bernoulli convention.**  Use `bernoulli' 1=+1/2`, not
   `bernoulli 1=-1/2`.
4. **Polynomial part.**  The terms `-EB(P_n)` and
   `+(1/2)EB(P_n')` are mandatory.

If the analytic file uses the shifted function `F_n(s)=R_n(s+n+1)`, there is
still no index or sign change:

```text
sin^2(pi*(s+n+1))=sin^2(pi*s).
```
