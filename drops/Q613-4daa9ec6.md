# Strassmann/Bézout approach to PHMA

## Summary

The Strassmann idea identifies the correct *shape* of a possible proof of PHMA, but the key assumption is not currently justified: the Apéry sequence \(r\mapsto b_r\) is not known to be a single p-adic analytic function on all of \(\mathbb Z_p\) with uniformly bounded Weierstrass degree. Dwork congruences give continuity and strong congruences, but not bounded degree.

The more promising object is the Dwork unit-root function on ordinary residue disks, where bounded degree may follow from overconvergence of the F-crystal.

## (A) Weierstrass degree of \(r\mapsto b_r\)

There is no known constant Weierstrass degree for the global interpolation
\[
r\mapsto b_r.
\]

The obstruction is that the Apéry sequence is a solution of a recurrence with singular coefficients at p-adic integers. Extending the recurrence from integers to all of \(\mathbb Z_p\) requires choosing a branch of a p-adic solution space.

A generic p-adic analytic function on \(\mathbb Z_p\) has a Mahler expansion
\[
f(r)=\sum_n a_n {r\choose n}.
\]

Strassmann requires bounds on the valuations
\[
v_p(a_n).
\]

Dwork congruences imply roughly
\[
r\equiv r'\pmod {p^s}\Rightarrow b_r\equiv b_{r'}\pmod {p^s},
\]
which gives continuity, but continuity alone allows arbitrarily large Weierstrass degree.

Therefore:

\[
\boxed{\text{Dwork congruences do not imply bounded Weierstrass degree.}}
\]

## (B) Mahler coefficients

The coefficients are
\[
a_n=\Delta^n b_0.
\]

For a bounded-degree Strassmann argument one would need a linear lower bound such as
\[
v_p(a_n)\geq c n
\]
for large n, together with a finite initial segment controlling the Newton polygon.

No such estimate is known for the Apéry sequence.

The difficulty is that the integer formula
\[
b_r=\sum_k {r\choose k}^2 {r+k\choose k}^2
\]
looks polynomial for fixed r, but the number of terms grows with r. It does not define one polynomial of bounded degree in the p-adic variable.

## (C) Dwork unit-root function

This is the more realistic route.

For the Apéry F-crystal, the slope-zero Frobenius eigenvalue \(\alpha(r)\) is a genuine p-adic analytic object on ordinary disks. One expects:

\[
\alpha(r)\in \mathcal O(\text{ordinary disk})
\]

and
\[
b_r\equiv \alpha(r)\pmod p
\]

when the twist is ordinary.

If one could prove that on each residue disk
\[
\alpha(r)=0
\]
has uniformly bounded order, then Strassmann would give the desired \(O(1)\) exceptional twists.

The missing theorem is therefore not about the raw Apéry sequence, but about the zero locus of the unit-root function.

## (D) What Dwork congruences actually give

Dwork congruences imply a Lipschitz-type condition:

\[
v_p(b_r-b_{r'})\geq v_p(r-r').
\]

In Mahler language this implies decay of coefficients, but not enough decay to bound the number of zeros.

Analogy:

- continuity controls convergence;
- overconvergence controls Newton polygons;
- bounded Weierstrass degree requires a finite-slope statement.

The required input is a stronger theorem about the Frobenius eigenfunction.

## Conclusion

The Strassmann strategy is conceptually correct only after replacing

\[
b_r
\]

by the Dwork unit-root function.

The strongest plausible PHMA theorem is:

> On each ordinary residue disk of the Apéry unit-root F-crystal, the unit-root function has uniformly bounded Weierstrass degree.

Then Strassmann gives

\[
|Z_p|=O(1).
\]

The raw Mahler expansion of the Apéry numbers does not currently provide this bound. The missing ingredient is a uniform overconvergent F-crystal zero estimate, not merely Dwork congruences.
