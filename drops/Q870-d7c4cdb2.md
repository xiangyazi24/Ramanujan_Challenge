# Q870 audit: verdict on the proposed exact reduction

## Executive verdict

The first claimed reduction `g_n | 6D_n` is correct. The determinant argument survives the lowest-term and prime-power audit. Consequently `D_n <= G_n <= 6D_n^2` is valid and `log G_n=o(n)` is equivalent to `log D_n=o(n)`.

The second claimed reduction `W(n) <= log D_n <= 3W(n)+O(n^(2/3))` is not established by the stated inputs alone. The lower bound is valid from the banked large-prime law. The upper bound has a missing valuation argument: the balanced block law controls occurrence of large primes in `b_{n mod p}`, but the transition from the alias weight estimate to the full denominator valuation requires a precise statement that every excess denominator prime contribution is charged to one of the three companion channels. That statement is not contained in the given hypotheses.

Therefore pair primitivity is not removed merely by the displayed facts.

## Line-by-line audit of the first theorem

### Definitions

Let

```
a_n=A_n/delta_n,
 gcd(A_n,delta_n)=1,
 d_n=L_n^3,
 D_n=d_n/delta_n,
 G_n=D_n gcd(A_n,b_n).
```

Since `d_n a_n=A_nD_n`, the original gcd is

```
gcd(d_n a_n,d_n b_n)=D_n gcd(A_n,b_n)=G_n.
```

This identity is exact.

### Step 1: prime dividing `g_n`

Let `p | g_n`, where

```
g_n=gcd(A_n,b_n).
```

Because `a_n=A_n/delta_n` is reduced,

```
gcd(A_n,delta_n)=1.
```

Hence

```
p | A_n => p does not divide delta_n.
```

Therefore

```
v_p(D_n)=v_p(d_n)-v_p(delta_n)=v_p(d_n).
```

This step is valid, including prime powers.

### Step 2: determinant divisibility

The banked identity gives

```
G_n | 6 d_n d_{n-1}/n^3.
```

For a prime `p|g_n`,

```
v_p(G_n)=v_p(D_n)+v_p(g_n).
```

Therefore

```
v_p(g_n)
 <= v_p(6)+v_p(d_n)+v_p(d_{n-1})-3v_p(n)-v_p(D_n).
```

Using `v_p(D_n)=v_p(d_n)` gives

```
v_p(g_n)
 <= v_p(6)+v_p(d_{n-1})-3v_p(n).
```

Since

```
v_p(d_{n-1}) <= v_p(d_n),
```

we obtain

```
v_p(g_n)<=v_p(6)+v_p(d_n)=v_p(6D_n).
```

Thus

```
g_n | 6D_n.
```

No endpoint exception occurs here.

## Audit of p=2,3

The proof above did not discard small primes. For `p=2,3`, the term `v_p(6)` remains present. Hence the conclusion is still

```
g_n | 6D_n
```

rather than `g_n|D_n`.

The factor 6 is necessary in the Wronskian normalization.

## Audit of p dividing n

The subtraction step includes

```
-3v_p(n).
```

If `p|n`, this only decreases the right side. No sign reversal occurs. The inequality remains valid.

## Audit of prime powers

All statements use valuations, not only prime support. Therefore the argument controls prime powers as well. The conclusion is a divisibility statement, not merely a radical statement.

## Consequence for heights

Because

```
G_n=D_ng_n,
```

and

```
g_n|6D_n,
```

we have

```
D_n <= G_n <= 6D_n^2.
```

Taking logarithms:

```
log D_n <= log G_n <= log 6+2log D_n.
```

Hence

```
log G_n=o(n) iff log D_n=o(n).
```

The first reduction is proved.

# Audit of the W(n) reduction

## Lower bound

For a prime

```
sqrt(n)<p<=n
```

with

```
p|b_{n mod p},
```

write

```
n=qp+r,
0<=r<p.
```

The balanced block law gives

```
p^3 a_{qp+r}=a_q b_r mod p.
```

Since `p>sqrt(n)`, the denominator contribution is at most one copy of `p`. The banked local law identifies exactly these large primes in `D_n`.

Therefore

```
W(n)<=log D_n
```

up to the already stated small-prime error.

## Missing step in the upper bound

To prove

```
log D_n<=3W(n)+O(n^(2/3)),
```

one must prove that every prime power contribution to `D_n` comes from one of three controlled channels:

1. denominator contribution forced by `b_r`;
2. companion numerator alias;
3. exceptional small-prime part.

The supplied hypothesis only states an alias weight estimate of size

```
O(n^(2/3)).
```

It does not state the required valuation decomposition

```
v_p(D_n) <= 3*1_{p|b_{n mod p}} + alias_p
```

for every prime power.

Without this inequality, a prime can in principle divide the reduced denominator `delta_n` in a way not represented by the three channels. The balanced congruence detects zeros of `b_r`, but it does not by itself prove exhaustion of all denominator valuations.

## Pair primitivity question

The proposed conclusion that pair primitivity is no longer an independent cut is therefore false from the stated premises.

Pair primitivity would follow if one additionally proved the missing charging lemma:

```
For every p>sqrt(n),
 v_p(D_n)<=3*1_{p|b_{n mod p}}+e_p,
```

with

```
Sum_p e_p log p = O(n^(2/3)).
```

That is exactly the missing bridge.
