# Correct lifted zero theorem: the Boolean OR law

## 1. Two-digit lift: exact statement

Let
\[
Z_p=Z(p)=\{r\in[0,p):b_r\equiv0\pmod p\},\qquad z_p=|Z_p|.
\]
For \(0\le q,r<p\), Lucas gives
\[
b_{qp+r}\equiv b_qb_r\pmod p.
\]
Therefore
\[
b_{qp+r}\equiv0\pmod p
\iff
(q\in Z_p)\ \text{or}\ (r\in Z_p).
\]

Hence the exact lifted zero set is
\[
\widetilde Z_2(p)=\{qp+r:q,r\in[0,p),\ q\in Z_p\text{ or }r\in Z_p\}.
\]
Its complement is the Cartesian product of two nonzero digits:
\[
\widetilde Z_2(p)^c=(Z_p^c)\times(Z_p^c).
\]
Therefore
\[
|\widetilde Z_2(p)|=p^2-(p-z_p)^2
=2pz_p-z_p^2.
\]

This is the strongest possible consequence of Lucas at the zero level.

## 2. d-digit theorem

Write
\[
n=n_0+n_1p+\cdots+n_{d-1}p^{d-1},\qquad 0\le n_i<p.
\]
Repeated Lucas gives
\[
b_n\equiv\prod_{i=0}^{d-1}b_{n_i}\pmod p.
\]
Thus
\[
b_n\equiv0\pmod p
\iff
\exists i,\ n_i\in Z_p.
\]

Equivalently, the only nonzero residues modulo \(p^d\) are those whose every base-p digit avoids \(Z_p\). There are exactly
\[
(p-z_p)^d
\]
nonzero residues. Hence
\[
\boxed{
\#\{0\le n<p^d:b_n\equiv0\pmod p\}
=p^d-(p-z_p)^d
}
\]
and the zero density is
\[
\boxed{
1-\left(1-\frac{z_p}{p}\right)^d.
}
\]

For fixed p this tends to 1 as d grows, but it contains no new information about the base atom \(Z_p\).

## 3. Singular branches

### (a) q=0

The block is just the base interval:
\[
m=r<p.
\]
There is no lifting information. This is precisely the original atom problem.

### (b) Singular q=j, q\neq r

If \(j\in Z_p\), then
\[
b_{jp+r}\equiv b_jb_r\equiv0\pmod p
\]
for every r. Thus a singular block is completely zero modulo p.

If \(q\notin Z_p\) is regular, then
\[
b_{qp+r}\equiv b_qb_r\pmod p,
\]
and the block contains a translated copy of the base atom:
\[
qp+Z_p.
\]
So regular blocks do not create new zeros; they replicate existing ones.

### (c) Diagonal q=r

The diagonal point is
\[
m=q(p+1).
\]
If \(q\in Z_p\), then
\[
b_{q(p+1)}\equiv b_q^2\equiv0\pmod p.
\]
This is only the intersection of the two digit conditions. It does not give an additional constraint.

## 4. Does the p^4 companion law improve this?

The regular formula
\[
p^3a_{qp+r}=C_{p,q}b_{qp+r}+p^3a_r/b_q\pmod{p^4}
\]
is valid only when \(b_q\not\equiv0\pmod p\). It provides extra information on regular blocks because division by \(b_q\) is possible.

For singular q, the second term is undefined. The singular branch cannot be recovered by a limiting argument. At the level of zeros it collapses to the Boolean OR condition.

The p^4 formula can therefore control valuations only after an independent classification of singular q. It does not itself bound \(|Z_p|\).

## 5. Fixed-depth Cartier/Frobenius towers

A tower through p^8 gives stronger congruence information for descendants of a residue, but a finite-depth tower is still a finite-state lifting rule. It does not automatically couple distinct base digits.

The obstruction is shown by a countermodel.

Choose arbitrary finite sets \(A_p\subset\{0,\ldots,p-1\}\). Define a formal digit sequence by requiring the p-adic zero condition at depth d to be
\[
(n_0,\ldots,n_{d-1})\text{ is zero }
\iff
\exists i\ n_i\in A_p.
\]
Then all finite-depth zero counts satisfy exactly
\[
1-(1-|A_p|/p)^d.
\]
The atom \(A_p\) can be chosen arbitrarily. Any finite collection of Cartier-style digit lifting rules that only propagates residue classes can be built into the same finite automaton.

Therefore finite-depth laws alone cannot imply a bound such as
\[
\sum_{p\mid b_j,\ j\le H}|Z(p)|\ll H^{1+o(1)}.
\]
They require an additional rigidity input linking different base residues.

## 6. Final theorem

The rigorous conclusion is:

1. Lucas gives the exact Boolean OR law:
\[
b_{\sum n_ip^i}\equiv0\pmod p
\iff
\bigvee_i(n_i\in Z_p).
\]

2. The exact density modulo \(p^d\) is
\[
1-(1-|Z_p|/p)^d.
\]

3. Singular blocks, including the diagonal \(q=r\), create no new base-atom restriction.

4. The p^4 companion law and any fixed-depth p^8 Cartier tower are insufficient by themselves to bound the weighted sum over small zeros. They describe descendants of atoms, not the atom distribution itself.

A nontrivial weighted bound therefore needs an ingredient beyond finite-depth Frobenius lifting: for example a cross-prime estimate, a distribution theorem for \(Z(p)\), or a valuation rigidity theorem that couples singular and regular branches.
