# P3.2 exact p-adic Smith filtration attack

## Status

The proposed prime-power Smith count is **not refuted**. There is a clean exact reduction which makes it much more plausible and shows that the global statement is no longer the hard part:

\[
\boxed{\#\{i:p^{3a}\mid d_i(J_n)\}\ge \Big\lfloor\frac{n}{p^a}\Big\rfloor}
\]

follows as soon as one proves, for every shifted full block of length \(s=p^a\), the local continuant congruence

\[
\boxed{
 v_p\!\left(K_s(js)\right)
 \ge 3v_p((s-1)!)+3a
 \qquad(j\ge0).
}
\tag{LC}_{p,a,j}
\]

This is exactly the congruence isolated in the preceding fixed-\(q\) attack. I do **not** see a proof of \((\mathrm{LC})\) from the currently established Jacobi/Lucas facts alone. Thus the stronger Smith statement is reduced to a single local congruence, but is not yet proved.

There is also an exact Bockstein formulation of the missing step: every shifted \(s\times s\) block must have a primitive kernel vector modulo \(p^{3a}\). That formulation is necessary and sufficient for the local Smith claim and avoids any misleading determinant-only rank inference.

## 1. Exact Smith-filtration interpretation

Let an integral square matrix \(A\) have \(p\)-adic Smith exponents

\[
0\le e_1\le\cdots\le e_N,
\qquad d_i(A)=p^{e_i}u_i,\quad p\nmid u_i.
\]

For \(t\ge1\), set

\[
\mathcal K_t(A)
:=\operatorname{im}\!\left(
\ker(A:(\mathbb Z/p^t)^N\to(\mathbb Z/p^t)^N)
\longrightarrow (\mathbb F_p)^N
\right).
\]

After Smith reduction this is diagonal, and in one coordinate \(p^{e_i}x=0\pmod{p^t}\) has a reduction mod \(p\) which can be nonzero iff \(e_i\ge t\). Hence

\[
\boxed{
\dim_{\mathbb F_p}\mathcal K_t(A)
=\#\{i:e_i\ge t\}.
}
\tag{1}
\]

This is the right Bockstein object. Raw nullity modulo \(p\) only counts \(e_i\ge1\); the image of the kernel modulo \(p^t\) counts the invariants which actually survive to level \(t\).

For Q2895 we take \(t=3a\).

## 2. Exact block decomposition modulo \(p^{3a}\)

Put

\[
s=p^a,\qquad n=qs+r,\qquad 0\le r<s.
\]

The Jacobi matrix has diagonal

\[
P(k)=34k^3+51k^2+27k+5
\]

and the edge joining indices \(k-1,k\) is \(k^3\). At every boundary \(k=ms\),

\[
(ms)^3\equiv0\pmod{p^{3a}}.
\]

Therefore, over \(\mathbb Z/p^{3a}\), \(J_n\) is **literally block diagonal**:

\[
J_n\equiv
B_{0,a}\oplus B_{1,a}\oplus\cdots\oplus B_{q-1,a}
\oplus R_{q,r}
\pmod{p^{3a}},
\tag{2}
\]

where \(B_{j,a}\) is the length-\(s\) block on indices
\(js,js+1,\ldots,(j+1)s-1\), and \(R_{q,r}\) is the final length-\(r\) block.

Using (1), kernel images add under (2). Thus, with

\[
\kappa_{a}(j):=\dim_{\mathbb F_p}\mathcal K_{3a}(B_{j,a}),
\qquad
\rho_a(q,r):=\dim_{\mathbb F_p}\mathcal K_{3a}(R_{q,r}),
\]

we get the exact identity

\[
\boxed{
\#\{i:p^{3a}\mid d_i(J_n)\}
=\sum_{j=0}^{q-1}\kappa_a(j)+\rho_a(q,r).
}
\tag{3}
\]

So the desired lower bound is reduced to the local statement

\[
\boxed{\kappa_a(j)\ge1\quad\text{for every }j\ge0.}
\tag{4}
\]

No fixed-\(q\) combinatorics remains here.

## 3. The local determinant is exactly the shifted continuant

For a block beginning at \(x\), define

\[
K_0(x)=1,\qquad K_1(x)=P(x),
\]
\[
K_{h+1}(x)=P(x+h)K_h(x)-(x+h)^6K_{h-1}(x).
\]

This is exactly the tridiagonal determinant recurrence, hence

\[
\det B_{j,a}=K_s(js).
\tag{5}
\]

Let \(\Delta_{s-1}(B_{j,a})\) be the gcd of all \((s-1)\times(s-1)\) minors. If
\(e_1\le\cdots\le e_s\) are the local Smith exponents, then

\[
e_s
=v_p(K_s(js))-v_p(\Delta_{s-1}(B_{j,a})).
\tag{6}
\]

Now use the **corner cofactor**. Deleting opposite endpoint row/column leaves the triangular product

\[
C_{j,a}:=\prod_{h=1}^{s-1}(js+h)^3.
\tag{7}
\]

For \(1\le h<s=p^a\), we have \(v_p(js+h)=v_p(h)\), so

\[
v_p(C_{j,a})=3v_p((s-1)!).
\tag{8}
\]

Since the determinantal divisor divides every cofactor,

\[
v_p(\Delta_{s-1}(B_{j,a}))
\le 3v_p((s-1)!).
\tag{9}
\]

Combining (6) and (9),

\[
\boxed{
e_s\ge
v_p(K_s(js))-3v_p((s-1)!).}
\tag{10}
\]

Consequently \((\mathrm{LC})_{p,a,j}\) implies \(e_s\ge3a\), hence \(\kappa_a(j)\ge1\). Applying this to all \(q\) full blocks in (3) proves

\[
\#\{i:p^{3a}\mid d_i(J_n)\}\ge q=\lfloor n/p^a\rfloor.
\]

This is the smallest rigorous bridge from the shifted-continuant lemma to the desired Smith selector.

### The unshifted block is already done

For \(j=0\), the known Apéry determinant identity gives

\[
K_s(0)=\det J_s=(s!)^3b_s.
\]

Therefore

\[
v_p(K_s(0))
=3v_p((s-1)!)+3a+v_p(b_s)
\ge3v_p((s-1)!)+3a.
\]

So the first block needs no new theorem. The unresolved content is precisely the **shifted** case \(j\ge1\).

## 4. Why the truncated Apéry kernel does not finish the proof

Let

\[
s_m=(-1)^m b_m,
\qquad
u^{(m)}=(s_0,\ldots,s_{m-1},0,\ldots)^T.
\]

The Apéry recurrence gives the exact two-endpoint defect

\[
J_nu^{(m)}
=m^3\bigl(s_{m-1}e_m-s_me_{m-1}\bigr)
\tag{11}
\]

(with the obvious endpoint convention). Hence for \(m=ts\),

\[
u^{(ts)}\in\ker(J_n\bmod p^{3a}).
\tag{12}
\]

This looks at first like it should give the \(q\) required classes. It does not, because (1) counts the **reductions modulo \(p\)** of these kernel vectors. The successive difference

\[
w_t:=u^{(ts)}-u^{((t-1)s)}
\]

is the global Apéry solution restricted to the \(t\)-th length-\(s\) block. When the relevant coarse Apéry residue vanishes modulo \(p\), that entire translated block can reduce to zero modulo \(p\) (this is exactly the Lucas-zero obstruction already present in the fixed-\(q\) analysis). Then the two prefix vectors have the same reduction and supply no new primitive Smith class.

So the prefix construction proves membership in the high kernel, but **not** the required primitive independence. This is the precise place where a raw-kernel argument overcounts.

The correct local object is a translated Dirichlet kernel vector for \(B_{j,a}\) whose first nonzero coordinate is a \(p\)-unit. Closing that vector at the right endpoint modulo \(p^{3a}\) is exactly the local high-Smith condition.

## 5. Bockstein formulation of the first missing theorem

The exact local statement, with no determinant strengthening, is

\[
\boxed{
\exists v_{j,a}\in(\mathbb Z/p^{3a})^s:
\quad B_{j,a}v_{j,a}=0,
\quad v_{j,a}\not\equiv0\pmod p.
}
\tag{BK}_{p,a,j}
\]

By (1), \((\mathrm{BK})\) is equivalent to

\[
\kappa_a(j)\ge1,
\]

or equivalently

\[
\boxed{
 v_p(K_s(js))-v_p(\Delta_{s-1}(B_{j,a}))\ge3a.
}
\tag{13}
\]

Equation (13) is the **necessary-and-sufficient local Smith congruence**.

The continuant estimate \((\mathrm{LC})\) is a convenient stronger scalar statement because the explicit corner cofactor supplies (9). Thus there are two exact ways to state the remaining obstruction:

1. minimal/necessary-and-sufficient:
   \[
   v_p(K_s(js))-v_p(\Delta_{s-1}(B_{j,a}))\ge3a;
   \]
2. source-friendly sufficient congruence already isolated in the fixed-\(q\) work:
   \[
   \boxed{
   K_{p^a}(jp^a)\equiv0
   \pmod{p^{\,3v_p((p^a-1)!)+3a}}.
   }
   \tag{14}
   \]

I do not see a derivation of (14) from the currently banked mod-\(p\) splitting/Lucas facts. A proof has to show that the local mod-\(p\) nullvector survives all Bocksteins through level \(3a\), or equivalently perform row/column elimination through the whole \(p^a\)-block while losing no more than the corner-product valuation.

**This is the first exact missing congruence.**

## 6. A useful normalized “shifted Apéry residual”

Define

\[
\mathscr A_{a}(j)
:=\frac{K_s(js)}{\prod_{h=1}^{s-1}(js+h)^3}
\in\mathbb Q_p.
\tag{15}
\]

By (8), (14) is exactly

\[
\boxed{v_p(\mathscr A_a(j))\ge3a.}
\tag{16}
\]

For \(j=0\),

\[
\mathscr A_a(0)
=\frac{(s!)^3b_s}{((s-1)!)^3}
=s^3b_s,
\]

so (15) really is the shifted analogue of the ordinary Apéry endpoint residual. This is the cleanest scalar target for a future explicit block-operation or Frobenius/Bockstein proof.

## 7. Exact characterization of the excess

Once (4) is known, (3) gives

\[
\boxed{
E_{p,a}(n)
:=\#\{i:p^{3a}\mid d_i(J_n)\}-\lfloor n/p^a\rfloor
=\sum_{j=0}^{q-1}(\kappa_a(j)-1)+\rho_a(q,r).
}
\tag{17}
\]

This is an exact characterization. It separates two possible sources of excess:

- exceptional full blocks with more than one Smith exponent reaching \(3a\);
- the final incomplete block.

For general \(a>1\), I do **not** think the current facts justify collapsing (17) to one ordinary condition such as \(p\mid b_r\). The residual block can itself contain many internal multiples of \(p\), so several lower Smith layers are already present, and the high-threshold residual depends on its determinantal divisors, not only its determinant.

### At height \(a=1\), however, the excess is a single shifted Apéry residual

Here \(s=p\). Every internal edge of a full \(p\)-block,

\[
jp+h,\qquad1\le h<p,
\]

is a \(p\)-unit. Hence the corner cofactor is a \(p\)-unit. Therefore

\[
v_p(\Delta_{p-1}(B_{j,1}))=0,
\]

so **at most one** Smith invariant of a full \(p\)-block is divisible by \(p\), and

\[
\kappa_1(j)=1
\iff p^3\mid K_p(jp).
\]

Likewise, the trailing block has length \(r<p\), all its internal edges are \(p\)-units, and

\[
\rho_1(q,r)
=\mathbf 1_{\{v_p(K_r(qp))\ge3\}}.
\]

Therefore, conditional only on the full-block local congruence \(p^3\mid K_p(jp)\), one gets the **exact** level-3 formula

\[
\boxed{
\#\{i:p^3\mid d_i(J_n)\}
=\Big\lfloor\frac np\Big\rfloor
+\mathbf 1_{\{v_p(K_r(qp))\ge3\}},
\quad n=qp+r,\ 0\le r<p.
}
\tag{18}
\]

This is the clean prime-level analogue of the already proved mod-\(p\) formula
\(\operatorname{corank}_{\mathbb F_p}J_n=q+\mathbf1_{p\mid b_r}\), but the residual is now the **shifted length-\(r\) continuant** \(K_r(qp)\), not merely \(b_r\).

For \(q=0\), \(K_r(0)=(r!)^3b_r\) and \(r<p\), so (18)'s residual reduces to \(p^3\mid b_r\).

## 8. Conclusion / next exact lemma

The global Q2895 statement has a very short proof **once the shifted block closes**:

1. boundaries at multiples of \(p^a\) vanish modulo \(p^{3a}\);
2. the Smith threshold count is the primitive-kernel dimension (1);
3. each full block contributes one class if its largest Smith exponent is at least \(3a\);
4. the explicit corner cofactor bounds the \((s-1)\)-st determinantal divisor by \(3v_p((s-1)!)\);
5. therefore the single scalar congruence (14) forces one \(p^{3a}\)-divisible invariant per full block.

So my verdict is:

- **No counterexample found/algebraically forced.** Finite scans remain evidence only.
- **The stronger count is not yet proved from the banked facts.**
- **The first exact missing congruence is**
  \[
  \boxed{
  K_{p^a}(jp^a)\equiv0
  \pmod{p^{3v_p((p^a-1)!)+3a}}
  \quad(j\ge1),
  }
  \]
  equivalently \(v_p(\mathscr A_a(j))\ge3a\).
- The truly minimal local statement is (13), i.e. survival of one primitive local class through the \(3a\)-th Bockstein level.
- At \(a=1\), once the full-block congruence is supplied, the **excess is exactly** the shifted Apéry residual indicator in (18).
- For \(a>1\), a one-scalar excess formula requires an additional theorem controlling the higher determinantal divisors of the incomplete block (and excluding multiple top-level survivors in a full block); that is not presently justified by the Jacobi source facts alone.
