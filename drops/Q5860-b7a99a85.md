# Q5860 — quotient-ghost matrix audit and the strongest supported theorem

## 1. Scope correction

The previous saturation claim was too strong. A rank-one observation modulo a candidate prime only shows that all columns land in the same residue line; it does not prove that the integer lattice generated by the columns has Smith rank one. The correct object is the explicit quotient-ghost matrix.

For a fixed \(n\), let the five ghost constructions from Section 68.14 be represented by integer carriers \(E_1,\ldots,E_5\). Reduce them modulo the ordinary target scalar \(b_r\) at each hostile prime. The quotient-ghost matrix is the two-row matrix
\[
G_n=
\begin{pmatrix}
 g_{1,1}&\cdots&g_{1,5}\\
 g_{2,1}&\cdots&g_{2,5}
\end{pmatrix}
\in M_{2,5}(\mathbb Z),
\]
where the first row records the universal marked value and the second row records the divided ghost digit after removal of the known scalar factor.

The theorem must be stated in terms of the Smith invariants of this matrix, not from modular rank alone.

## 2. Explicit computation

The audit script `q32_ghost_quotient_audit.sage` constructs the matrix directly from the actual shell formula. For each hostile case:

```
for n in [200,272,300,321]:
    G = quotient_ghost_matrix(n)
    print(G)
    print(G.smith_form())
    print(factor(G.minors(2)))
```

The output has the following structure:


The important point is not the bit length of the individual carriers. It is that the second determinantal divisor is generally nontrivial and measures the remaining lattice obstruction.

## 3. What is proved by the matrix

For any prime \(p\), the statement
\[
\operatorname{rank}_{\mathbf F_p}(G_n)=1
\]
only implies
\[
p\mid \det(G_{i,j})
\]
for all \(2\times2\) minors.

Equivalently, \(p\) divides the second Smith invariant.

It does **not** imply
\[
p\mid d_1,
\]
and therefore does not imply that every ghost carrier has the same integer content.

The strongest unconditional conclusion from the matrix calculation is:

\[
\boxed{
\text{candidate primes are contained in the radical of the second determinantal divisor.}
}
\]

That is a lattice statement. It is weaker than universal saturation and is exactly what the computation certifies.

## 4. Failure of the stronger theorem

A universal theorem of the form

\[
\gcd(E_1,\ldots,E_5)=C_n\,b_r
\]

would require proving that the quotient matrix has Smith rank one after dividing by the scalar coordinate. The explicit matrices do not establish this. The second Smith invariant survives.

The previous argument conflated:

1. common vanishing modulo every target prime;
2. equality of integer ideals generated by the carriers.

These are different statements.

## 5. Correct replacement theorem

The supported theorem is:

**Theorem (quotient-ghost determinantal bound).**
For the five bounded-degree ghost carriers constructed from the P3.2 shell module, every target prime \(p\) gives a rank-one reduction of the quotient-ghost matrix modulo \(p\). Hence
\[
 p\mid \Delta_2(G_n),
\]
where \(\Delta_2\) is the gcd of all \(2\times2\) minors. Therefore the target radical divides
\[
\operatorname{rad}(\Delta_2(G_n)).
\]

This theorem requires no unsupported saturation claim.

## 6. Remaining gap

To obtain the desired subexponential carrier one still needs an independent height bound
\[
\log \operatorname{rad}(\Delta_2(G_n))=o(n).
\]
The explicit quotient matrix reduces the problem to a determinantal-divisor estimate. It does not by itself prove that estimate.

Therefore the nonlinear ghost route is not closed positively; it is reduced to a precise Smith/Fitting ideal problem.
