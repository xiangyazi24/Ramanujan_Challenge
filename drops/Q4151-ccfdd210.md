# 1. Exact minus-fold geometry used by the deletion

For a minus q6 row write

\[
d=q-p>0.
\]

After reflection, the lower-zero gap is

\[
h=|p-7d|.
\]

The two actual orientations are

\[
\mathrm{M+}:\quad p=7d+h,\qquad q=8d+h,
\tag{1.1+}
\]

and

\[
\mathrm{M-}:\quad p=7d-h,\qquad q=8d-h.
\tag{1.1-}
\]

On the second branch actual digit legality also forces

\[
6d<p<7d,
\]

so the displayed reflected gap is nonwrapping and \(0<h<p\). Since \(p,q\) are odd primes, \(d\) is even and \(h\) is odd; these congruence restrictions only thin the sieve set.

For fixed \((p,h)\), the reflected local zero pair has the form

\[
x,\ x+h,
\qquad
p\mid b_x,\ b_{x+h},
\]

and the exact transfer is the conjunctive one

\[
\bigl(p\mid b_x\ \&\ p\mid b_{x+h}\bigr)
\iff
\bigl(p\mid b_x\ \&\ p\mid N_h(x)\bigr).
\tag{1.2}
\]

The cited local-capacity theorem therefore gives, uniformly on each actual minus branch,

\[
\#\{x:\text{one legal row at fixed }(p,h)\}
\ll h.
\tag{1.3}
\]

One may take the polynomial root bound \(3(h-1)\); the sharper width term in the local-capacity theorem can only reduce this. All q6 selectedness, shell, and later residual predicates are additional filters.

# 2. The two-prime sieve and every logarithmic factor

Fix \(h\le Z\). Parameterize \(d=2m\). The two minus orientations become two pairs of primitive affine linear forms

\[
(14m+h,\ 16m+h)
\quad\text{or}\quad
(14m-h,\ 16m-h).
\tag{2.1}
\]

Their determinant has absolute value \(2h\). Consequently the standard upper-bound two-linear-form sieve, uniformly in the fixed q6 shells, gives

\[
\#\{m:\ p,q\text{ prime in the required shells}\}
\ll_J
\frac{T}{L^2}\,\mathfrak S(h),
\tag{2.2}
\]

where one may take

\[
\mathfrak S(h)
\ll_J
\prod_{\substack{\ell\mid h\\ \ell>2}}
\left(1+\frac{C}{\ell}\right)
\tag{2.3}
\]

for an absolute fixed \(C\). The fixed coefficient primes are absorbed into the \(J\)-constant.

There is no hidden \(\log Z\) in summing (2.3). Expanding the Euler factors,

\[
\mathfrak S(h)
\ll
\sum_{a\mid h}
\frac{\mu^2(a)C^{\omega(a)}}a,
\]

and hence

\[
\begin{aligned}
\sum_{h\le Z}h\mathfrak S(h)
&\ll
\sum_{a\le Z}\frac{\mu^2(a)C^{\omega(a)}}a
 \sum_{m\le Z/a}am\\
&\ll
Z^2\sum_{a\ge1}\frac{\mu^2(a)C^{\omega(a)}}{a^2}\\
&\ll Z^2.
\end{aligned}
\tag{2.4}
\]

Combining (1.3), (2.2), and (2.4), and summing the two orientations, gives the **unweighted actual-row count**

\[
\boxed{
\#\mathcal R^-_{\le Z}
\ll_J \frac{T Z^2}{L^2}.
}
\tag{2.5}
\]

Now every relevant lower prime lies in a fixed macroscopic shell

\[
p\asymp_J T,
\]

so

\[
\log p\asymp_J L.
\]

Therefore the occurrence-sensitive logarithmic row mass is

\[
\boxed{
\mathsf M_{\log}(\mathcal R^-_{\le Z})
:=
\sum_{r\in\mathcal R^-_{\le Z}}\log p(r)
\ll_J
L\,\#\mathcal R^-_{\le Z}
\ll_J \frac{T Z^2}{L}.
}
\tag{2.6}
\]

This is the complete log ledger:

```text
two-prime sieve:                    L^(-2)
local reflected-gap capacity:       no log, contributes h
sum over h <= Z:                    Z^2, no log Z
one log p weight:                   L^(+1)
--------------------------------------------
logarithmic row mass:               T Z^2 / L
```

So there is exactly one surviving denominator \(L\).

# 3. What `logarithmic mass` must mean

For any finite occurrence family \(X\) whose members carry lower primes \(p_\xi\), the relevant mass is

\[
\boxed{
\mathsf M_{\log}(X)
=
\sum_{\xi\in X}\log p_\xi.
}
\tag{3.1}
\]

This is multiplicity-sensitive. If five different physical rows, support edges, or packed cycles have the same lower prime \(p\), they contribute \(5\log p\), not \(\log p\).

Equivalently,

\[
\mathsf M_{\log}(X)
=
\log\prod_{\xi\in X}p_\xi
\]

where the product is over occurrences, **with multiplicity**.

It is not

\[
\log\operatorname{rad}\prod_{\xi\in X}p_\xi.
\]

That distinction is essential because many packed C4s can lie in the same lower-prime graph.

There is a second distinction. If an edge is deleted because one row in its complete fibre is bad, the boundary cost used here is the mass of the deleted **edge/cycle occurrence**, not

\[
\sum_{r\in F(e)}\log p(r)
\]

over every good row that is physically removed together with the fibre. No theorem in this argument bounds that latter total row multiplicity by one bad witness.

# 4. Whole-fibre injection

Let \(A\) be the fixed deterministic-OR assignment from actual physical q6 rows to residual lower support edges, and write

\[
F(e):=A^{-1}(e).
\]

Because \(A\) is a function, the fibres \(F(e)\) are pairwise disjoint.

Define the bad support edges

\[
E^-_{\le Z}
:=
\{e:\ F(e)\text{ contains an assigned minus row of fold }h\le Z\}.
\tag{4.1}
\]

For each \(e\in E^-_{\le Z}\), choose the least bad row

\[
r(e)\in F(e)
\]

under the already-fixed lexicographic order. Pairwise disjointness of the assigned fibres gives

\[
\boxed{e\mapsto r(e)\text{ is injective}.}
\tag{4.2}
\]

The lower prime is preserved:

\[
p(e)=p(r(e)).
\]

Therefore

\[
\boxed{
\sum_{e\in E^-_{\le Z}}\log p(e)
\le
\sum_{r\in\mathcal R^-_{\le Z}}\log p(r).
}
\tag{4.3}
\]

No factor `4` appears, and the cardinality of the complete fibre never appears.

Now let \(\mathcal P\) be the fixed edge-disjoint C4 packing, and let \(\mathcal P^-_{\le Z}\) consist of cycles meeting \(E^-_{\le Z}\). Choose one deleted edge \(e(C)\in E(C)\cap E^-_{\le Z}\) for every such cycle. Since distinct packed cycles are edge-disjoint,

\[
\boxed{C\mapsto e(C)\text{ is injective}.}
\tag{4.4}
\]

Again the lower prime is preserved, hence

\[
\boxed{
\mathsf M_{\log}(\mathcal P^-_{\le Z})
\le
\mathsf M_{\log}(E^-_{\le Z})
\le
\mathsf M_{\log}(\mathcal R^-_{\le Z}).
}
\tag{4.5}
\]

This is the exact whole-fibre payment.

### Exact failure mode

If `F(e)` is a raw compatibility fibre rather than the deterministic assigned fibre, (4.2) is not justified: one physical row can have more than one raw support certificate. In that formulation the first exact correction is to replace the raw fibres by

\[
F(e)=A^{-1}(e)
\]

for the fixed deterministic assignment, or else prove a separate SDR/bounded-overlap theorem. The current assigned residual-support interface uses the former.

# 5. Heredity

Delete the entire bad assigned fibre/support edge for every

\[
e\in E^-_{\le Z}.
\]

Then every surviving support edge \(e\) satisfies

\[
F(e)\cap\mathcal R^-_{\le Z}=\varnothing.
\tag{5.1}
\]

Any later row restriction replaces \(F(e)\) by a subset

\[
F'(e)\subseteq F(e),
\]

so automatically

\[
F'(e)\cap\mathcal R^-_{\le Z}=\varnothing.
\tag{5.2}
\]

Likewise every later subgraph or subfamily of the already-pruned packing preserves the property. Thus the deletion is hereditary under all later **restrictions**.

This statement does not authorize recomputing a different pre-OR assignment or enlarging a fibre later. The deterministic assignment and the complete fibres must be fixed before the deletion. Under the current C4 setup they are.

\[

into (2.6):

\[
\mathsf M_{\log}(\mathcal R^-_{\le Z})

\frac{T}{L}\frac{T}{\omega(T)^2}

=o_J(T^2/L).
\tag{6.1}

By (4.5), the same is true for the deleted C4 logarithmic mass.

Finally, on the lower shell

\[
\log p(C)\ge c_JL

for all sufficiently large \(T\). Therefore

\[
\#\mathcal P^-_{\le Z}
\le
\frac{\mathsf M_{\log}(\mathcal P^-_{\le Z})}{c_JL}
\ll_J
\frac{T^2}{L^2\omega(T)^2}
=o_J(T^2/L^2).
\tag{6.2}
\]

So the two target scales are exactly

```text
weighted/logarithmic deletion:     o_J(T^2 / log T)
unweighted packed-cycle deletion:  o_J(T^2 / (log T)^2)
```

and the displayed cutoff is correct.

If an integer cutoff is required, replace \(Z\) by

\[
\left\lfloor T^{1/2}/\omega(T)\right\rfloor;
\]

this changes nothing.
