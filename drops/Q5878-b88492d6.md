# Q5878 exact operator-syzygy audit

## Result

The requested Ore identity is not obtained as a new small-height Bezout certificate. The exact distinction is:

* the certified gauge gives a relation between the doubled-period solution module and the Apéry module;
* this does not automatically give a finite Newton-shell integer syzygy with sublinear logarithmic height.

## Operator obstruction

The desired identity

```
A_M U = Q L
```

is a left-ideal divisibility statement in the Ore ring. It must be checked by exact right division:

```
remainder = right_remainder(A_M*U,L)
```

A zero remainder would provide the requested Q. A nonzero remainder means that the relation only holds on the distinguished solution, not on the full cyclic module.

The known relation `U(J)=M(n)b_n` is a solution-level identity. Since the multiplier is nonconstant, converting it into an annihilator identity introduces the commutator

```
[N,M]f = N(M(n+j)f_{n+j})-M(n)N(f)
```

for every finite Newton functional N.

## Newton-shell translation

For a shell carrier one obtains schematically

```
T(U(J)) = M(n)T(b)+[T,M](b).
```

The correction term is controlled by finite differences of the degree-30 polynomial M. It is not removed by the Ore identity. After clearing denominators its coefficients have polynomial growth in the block location.

Therefore the operator identity alone does not imply

```
log |Bezout residual| = o(n).
```

## Hybrid gcd consequence

For

```
K_hyb=gcd(gcd(H_{m-1},H_m)/c_safe,
         gcd_{k=0..4,i=m-1,m}T_{k,i})
```

a successful certificate would require an explicit integer combination whose value has both target divisibility and sublinear height. The Ore relation supplies only the module divisibility, not the height estimate after Newton projection.

## The strongest justified statement

The certified doubled-period operator proves a rational extension of the Apéry module. Linear Ore lifts cannot by themselves create a new target equation; after normalization they reduce to the same Apéry scalar plus commutator terms. Bounding the hybrid gcd therefore requires an additional arithmetic estimate on those commutator terms.

This is a module-level obstruction, not a generic WZ/Katz obstruction.
