# 1. Reduction to a one-variable moment problem

Put

\[
L=\log T,
\qquad
Q(T)=\frac{T^2}{L^2},
\qquad
h\asymp \frac{T^{2/5}}{L^{6/5}\Omega(T)},
\]

where \(\Omega(T)\to\infty\) and \(\log\Omega(T)=o(\log T)\).

For a fixed prime \(p\), there are \(2Z_p\) sign-tagged primary stars. Since every star has

\[
k_{p,z,\varepsilon}\le Z_p-1,
\]

one always has

\[
E_p
\le 2Z_p\,(Z_p-1-h)_+
\ll Z_p^2\mathbf 1_{Z_p>h}.
\tag{1.1}
\]

This is sharp in the abstract support category: set every degree equal to \(Z_p-1\).

Write the available bounds as

\[
A_1=T^{8/5}L^{-4/5},
\quad
A_2=T^{11/5}L^{-3/5},
\quad
A_3=T^{14/5}L^{-2/5},
\]

so that, up to constants,

\[
\sum_p Z_p\le A_1,
\qquad
\sum_p Z_p(Z_p-1)\le A_2,
\qquad
\sum_p Z_p^3\le A_3.
\]

The number of shell primes is \(P\asymp T/L\). On a dyadic block where \(Z_p\asymp s\), let \(N_s\) be the number of supported primes. The listed inputs imply only

\[
N_s\ll
\min\left(
P,\frac{A_1}{s},\frac{A_2}{s^2},\frac{A_3}{s^3}
\right).
\tag{1.2}
\]

The corresponding possible lower-star contribution is

\[
E_s\ll s^2N_s
\ll F(s):=\min\left(Ps^2,A_1s,A_2,\frac{A_3}{s}\right).
\tag{1.3}
\]

The threshold subtraction does not alter the dangerous scales, because all scales used below satisfy \(s/h\to\infty\).

# 2. Exact exponent and logarithm optimization

All four support bounds in (1.2) meet at one point:

\[
s_*:=\frac{A_1}{P}
=\frac{A_2}{A_1}
=\frac{A_3}{A_2}
=T^{3/5}L^{1/5}.
\tag{2.1}
\]

Indeed,

\[
P=\frac{A_1}{s_*}
=rac{A_2}{s_*^2}
=rac{A_3}{s_*^3}
=TL^{-1}.
\]

For \(s\le s_*\), the prime-support ceiling is the smallest term in (1.2), so

\[
F(s)=Ps^2,
\]

which increases with \(s\). For \(s\ge s_*\), the cubic-moment ceiling is the smallest term, so

\[
F(s)=A_3/s,
\]

which decreases with \(s\). Therefore

\[
\max_s F(s)=F(s_*)=A_2=T^{11/5}L^{-3/5}.
\tag{2.2}

Relative to the desired scale,

\[
\frac{F(s_*)}{Q(T)}
=T^{1/5}L^{7/5}\longrightarrow\infty.
\tag{2.3}

The pointwise estimate \(Z_p\ll T^{2/3}\) is inactive because

\[
\frac{s_*}{T^{2/3}}=T^{-1/15}L^{1/5}\to0.

The threshold is also inactive:

\[
\frac{s_*}{h}
\asymp T^{1/5}L^{7/5}\Omega(T)\to\infty.
\tag{2.4}
\]

Equivalently, in pure exponent form, write

\[

\qquad
s=T^\alpha L^\beta.

The polynomial constraints are

\[
\nu\le1,
\quad
\nu+\alpha\le\frac85,
\quad
\nu+2\alpha\le\frac{11}{5},

\nu+3\alpha\le\frac{14}{5},

The objective exponent for \(E\) is \(\nu+2\alpha\). Its maximum is \(11/5\), attained at

\[

At the logarithmic level the simultaneous optimizer is

\[
(\mu,\beta)=(-1,1/5),

which recovers (2.1)--(2.2). Thus the second-moment input is not merely a crude step in the proof: its exponent and logarithm are exactly realizable by the other listed constraints.

A cutoff interpolation gives the same answer. For any \(Y\),

\[
\sum_{Z_p\le Y}Z_p^2\le Y\sum_pZ_p\le YA_1,

\sum_{Z_p>Y}Z_p^2\le Y^{-1}\sum_pZ_p^3\le A_3/Y.

Y=(A_3/A_1)^{1/2}=s_*,

(YA_1)(A_3/Y)=A_1A_3,

\[
(A_1A_3)^{1/2}=A_2.

There is therefore no missing Hölder, Markov, or cutoff optimization that reaches \(Q(T)\).

The first is the strongest, and it is still too large by the factor in (2.3).

# 4. A support-minimal sub-resultant model

The following parameterized construction gives both the smallest constant-level obstruction at a prescribed safe degree scale and a power-excess variant.

Choose fixed parameters

\[
\varepsilon>0,
\qquad
\rho\ge0,
\qquad
2\varepsilon+\rho<\frac15.
\tag{4.1}
\]

Set

\[
s(T)=2\left\lfloor\frac{T^{3/5-\varepsilon}}2\right\rfloor,
\qquad
N(T)=\left\lfloor c\,rac{T^{4/5+2\varepsilon+\rho}}{L^2}\right\rfloor,
\tag{4.2}
\]

where \(c>0\) is fixed. Since (4.1) implies

\[
N(T)=o(T/L),
\]

there are enough shell primes to choose \(N(T)\) supported primes. Put \(Z_p=s(T)\) on those primes and \(Z_p=0\) on every other shell prime.

The model can be summarized as follows.

```text
active shell primes:      N = c T^(4/5+2 epsilon+rho) / L^2
zeros on each active p:   Z_p = s = T^(3/5-epsilon)
primary stars per p:      2s
selected degree per star: k = s-1
inactive primes:          Z_p = 0
```

## 4.1 Explicit reflection-closed, spaced zero supports

For each supported odd prime \(p\), let \(r=s/2\) and define

\[
\mathcal Z_p
=
\{3j:1\le j\le r\}
\cup
\{p-1-3j:1\le j\le r\}.
\tag{4.3}
\]

For sufficiently large \(T\), one has \(6r+2<p\), because \(s=o(p)\). Consequently:

* the two arms in (4.3) are disjoint;
* \(|\mathcal Z_p|=2r=s\);
* the involution \(x\mapsto p-1-x\) interchanges the two arms;
* points within either arm differ by at least \(3\);
* the gap between the two arms is \(p-1-6r>1\);
* even with cyclic adjacency understood, the endpoint gap from \(p-4\) to \(3\) is \(7\).

Thus the supports are reflection-closed and contain no consecutive residues. Empty supports on inactive primes have the same properties.

## 4.2 Degrees and affine injectivity

For every active \(p\), every primary \(z\in\mathcal Z_p\), and both signs \(\varepsilon\), set

\[
A_{p,z,\varepsilon}=\mathcal Z_p\setminus\{z\},
\qquad
k_{p,z,\varepsilon}=|A_{p,z,\varepsilon}|=s-1.
\tag{4.4}
\]

Apply the stipulated affine candidate map

\[
a\longmapsto q_{p,z,\varepsilon}(a)

to the elements of (4.4). By the imposed affine injectivity, the \(s-1\) images are distinct, so (4.4) respects the exact degree ceiling. If one also wants an abstract global row-uniqueness convention, use distinct affine intercepts for different \((z,\varepsilon)\); then a fixed sign-tagged triple \((p,a,q)\) is not reused.

This is an incidence-support declaration only. It does not assert that these formal affine images are prime, satisfy an Apéry zero condition, or obey any arithmetic condition not included among the premises being audited.

# 5. The genuinely missing information is selected-neighbor concentration

The ambient moments count possible zero supports. They do not control how many of those possible secondaries are **simultaneously selected as affine neighbors of the same primary star**. The model exploits exactly that gap by selecting essentially every available secondary at every primary.

Let

\[
\Sigma_T=\{(p,z,\varepsilon)\}
\]

be the actual sign-tagged primary stars, let \(A_\sigma\) be the actual selected affine-neighbor set of star \(\sigma\), and put \(k_\sigma=|A_\sigma|\).

There is no canonical literally weakest functional among all imaginable functionals: one can always define an ad hoc indicator that vanishes on every configuration except the displayed model. In the natural hierarchy of tail moments, however, the exact missing input can be stated sharply.

## 5.1 Arbitrarily weak superlinear selected tail moments

For any fixed \(\eta>0\), define

\[
\mathcal M_{1+\eta}^{\mathrm{sel}}(h)
:=
\sum_{\substack{\sigma\in\Sigma_T\\k_\sigma>h}}
 k_\sigma^{1+\eta}.
\tag{5.1}
\]

Since \(k>h\) implies \((k-h)_+\le k\le h^{-\eta}k^{1+\eta}\),

\[
E(T)\le h^{-\eta}\mathcal M_{1+\eta}^{\mathrm{sel}}(h).
\tag{5.2}
\]

Thus the selected-neighbor tail condition

\[
\boxed{
\mathcal M_{1+\eta}^{\mathrm{sel}}(h)
=o\!\left(h^\eta\frac{T^2}{L^2}\right)
}
\tag{5.3}
\]

forces the desired conclusion. Written with every power displayed, the right side is

\[
h^\eta\frac{T^2}{L^2}
\asymp
T^{2+2\eta/5}
L^{-2-6\eta/5}
\Omega(T)^{-\eta}.
\tag{5.4}
\]

Condition (5.3) is strictly more informative than restating \(E=o(Q)\): it records a superlinear moment of the actual selected affine-neighbor multiplicities. There is no smallest \(\eta>0\); one may take \(\eta\) arbitrarily small. This is the precise sense in which no unique weakest superlinear moment exists.

For the model in Section 4,

\[
\mathcal M_{1+\eta}^{\mathrm{sel}}(h)
\asymp 2Ns^{2+\eta}
\asymp
T^{2+\rho+\eta(3/5-\varepsilon)}L^{-2}.
\]

Its ratio to the required scale (5.4) is

\[
T^{\rho+\eta(1/5-\varepsilon)}
L^{6\eta/5}
\Omega(T)^\eta\to\infty.
\tag{5.5}
\]

Hence every fixed \(\eta>0\) version of (5.3) rules out the model by a power, with the displayed logarithmic and \(\Omega\)-gain.

## 5.2 Lowest combinatorial moment: selected neighbor-pair energy

If one wants an integer/factorial moment suitable for a resultant or double-extension certificate, the first nontrivial choice is the selected pair energy

\[
\mathcal C_{>h}^{\mathrm{sel}}(T)
:=
\sum_{\substack{\sigma\in\Sigma_T\\k_\sigma>h}}
 k_\sigma(k_\sigma-1).
\tag{5.6}
\]

This counts ordered pairs of distinct **actual selected affine neighbors belonging to the same primary star**. It is not the ambient quantity \(\sum_pZ_p^3\), although the latter gives the crude ceiling

\[
\mathcal C_{>h}^{\mathrm{sel}}\le 2\sum_pZ_p^3.
\]

Because \(h\to\infty\), for all sufficiently large \(T\) and every integer \(k>h\), one has \(k-1\ge h/2\), hence

\[
(k-h)_+\le \frac{2}{h}k(k-1).
\]

Therefore

\[
E(T)\le \frac{2}{h}\mathcal C_{>h}^{\mathrm{sel}}(T),
\]

and the clean factorial-moment closure condition is

\[
\boxed{
\mathcal C_{>h}^{\mathrm{sel}}(T)
=o\!\left(h\frac{T^2}{L^2}\right)
=o\!\left(
\frac{T^{12/5}}{L^{16/5}\Omega(T)}
\right).
}
\tag{5.7}
\]

Within the ordinary integer factorial-moment hierarchy, (5.7) is the weakest new selected-neighbor moment: order one is essentially the edge/excess count itself, while order two is the first statistic that detects concentration of several selected secondaries inside one star.

The listed ambient cubic moment is far too weak to give (5.7). Its permitted size divided by the required selected-pair size is

\[
\frac{T^{14/5}L^{-2/5}}
     {T^{12/5}L^{-16/5}\Omega(T)^{-1}}
=
T^{2/5}L^{14/5}\Omega(T).
\tag{5.8}
\]

Thus the missing theorem must exploit actual affine selection, not merely improve bookkeeping of the ambient \(Z_p\) moments.

For the power-excess concrete model \(\varepsilon=\rho=1/20\),

\[
\mathcal C_{>h}^{\mathrm{sel}}(T)
\asymp 2Ns^3
\asymp T^{13/5}L^{-2},
\]

whereas the right side of (5.7) is

\[
T^{12/5}L^{-16/5}\Omega(T)^{-1}.
\]

The model violates (5.7) by

\[
T^{1/5}L^{6/5}\Omega(T).
\tag{5.9}
\]

# 6. Final logical conclusion

The committed inputs permit the following simultaneous behavior:

```text
Z_p is reflection-closed and has no consecutive residues;

all first, second-factorial, and third ambient moments have polynomial slack;
```

The narrow missing information is a concentration estimate on the **actual selected affine neighbors inside one primary star**. The sharp superlinear tail family is (5.3); the lowest combinatorial version suitable for a two-neighbor certificate is the selected pair-energy bound (5.7). Neither is supplied by the committed numerical inputs.
