## Status

## Exact object audited

For an odd prime p=2m+1, define the Apéry sequence in F_p by

```text
b_0 = 1, b_1 = 5,
(j+1)^3 b_{j+1} = (34j^3+51j^2+27j+5)b_j - j^3 b_{j-1}.
```

The proposed certificate is

```text
Sigma_p = 1/3 - 2 b_m * sum_{j=0}^{m-2} (((m-j)^2-1)/b_j).
```

This expression is only defined under

```text
b_0,...,b_{m-2},b_m != 0.
```

The remaining gap is the implication

```text
b_{m-1}=0  ==>  Sigma_p != 0.
```

## What would be needed for a proof

The recurrence gives a second-order relation among consecutive values. To turn Sigma into a nonvanishing certificate one needs an identity of one of the following forms:

1. A full-cycle telescoping identity whose boundary term is Sigma and whose interior terms are manifestly nonzero.
2. A resultant statement showing the polynomial condition

```text
b_{m-1}=0 and Sigma_p=0
```

has no solutions modulo p.
3. An augmented transfer determinant showing that simultaneous vanishing of the endpoint coordinate and the reciprocal-weighted functional forces a forbidden rank drop.

None of these follows from the recurrence alone.

## Why the tempting recurrence-block argument does not close

The obstruction is that Sigma contains reciprocals of b_j. The recurrence evolves the vector

```text
(b_j,b_{j-1})
```

linearly, but it does not provide a linear recurrence for

```text
1/b_j.
```

Therefore a low-degree adjoint polynomial or ordinary transfer determinant cannot directly encode Sigma. Any successful determinant argument must enlarge the state space to include the reciprocal functional or eliminate denominators by a genuine resultant.

## Conditional lemma that narrows the gap

A sufficient next target is:

```text
Lemma (finite-field endpoint certificate).
For every odd prime p=2m+1, if
b_{m-1}=0 and b_0,...,b_{m-2},b_m !=0,
then
Res_p(b_{m-1}, Sigma_p) != 0.
```

Equivalently, after clearing denominators with

```text
D_p = product_{j=0}^{m-2} b_j,
```

prove

```text
b_{m-1}=0 and D_p*Sigma_p=0
```

has no solutions.

This is a concrete finite-field elimination problem. A verifier can compute:

```python
for p in odd_primes:
    m=(p-1)//2
    b=[1,5]
    for j in range(1,m):
        # solve the recurrence in F_p
        pass
    if b[m-1]==0 and all(b[j]!=0 for j in list(range(m-1))+[m]):
        S=pow(3,-1,p)
        S -= 2*b[m]*sum((((m-j)**2-1)*pow(b[j],-1,p)) for j in range(m-1))
        S %= p
        assert S != 0
```

The assertion is a verifier, not a proof.
