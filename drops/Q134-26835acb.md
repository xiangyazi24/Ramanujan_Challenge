# Q134: The projective calculation error

The contradiction is real: the claimed equivalence

```
p | b_N  iff  p | (5 b_{N-1}+a_{N-1})
```

is false. The error occurs in Step 5 when identifying the inverse image point in P^1.

## 1. The correct transfer matrix

The Apéry matrix is

```
Π_N = [[b_N, a_N], [b_{N-1}, a_{N-1}]].
```

The condition p | b_N means only that

```
Π_N e_1 = (b_N,b_{N-1})^T = (0,b_{N-1})^T mod p.
```

Because consecutive zeros do not occur, this projective point is

```
(Π_N e_1) = (0:1).
```

However, to recover the starting vector one must compute

```
Π_N^{-1}(0:1),
```

not use an adjugate column without tracking which column is involved.

## 2. Compute the inverse correctly

For

```
Π_N = [[b_N,a_N],[b_{N-1},a_{N-1}]],
```

we have

```
Π_N^{-1} = 1/det(Π_N) [[a_{N-1},-a_N],[-b_{N-1},b_N]].
```

Applying this to `(0:1)` gives

```
Π_N^{-1}(0:1)=(-a_N:b_N).
```

The previous argument incorrectly used

```
(-a_{N-1}:b_{N-1}).
```

That is the inverse image of a different projective vector.

Therefore the correct projective condition is

```
(5:1)=(-a_N:b_N) mod p.
```

Equivalently,

```
b_N + 5 a_N ≡ 0 mod p.
```

This is also not useful for the desired bound, because it gives a different large integer, not a small expression.

## 3. The contradiction disappears

The Casoratian is

```
b_N a_{N-1}-a_N b_{N-1}=-6/N^3.
```

If one incorrectly substitutes `a_{N-1},b_{N-1}` into the projective inverse, one obtains a fake common divisor relation with both `b_N` and `5b_{N-1}+a_{N-1}`, contradicting the Casoratian.

The Casoratian itself was already detecting the mistake: the fake identity would force a large prime divisor of b_N to divide 6.

## 4. What survives

There is a genuine projective reformulation:

```
p | b_N  ==>  (5:1)=(-a_N:b_N) mod p.
```

Thus large prime divisors of b_N are large prime divisors of

```
5a_N+b_N.
```

But

```
5a_N+b_N ~ (5ζ(3)+1)b_N,
```

so its size is still exponential of the same order as b_N. It gives only the usual

```
ω_{(N,2N]}(b_N) ≪ N/log N
```

scale and does not yield the required little-o.

## 5. Conclusion

The proposed many-prime/projective forcing route does not produce the theorem. The exact failure is:

```
Π_N^{-1}(0:1)=(-a_N:b_N),
```

not

```
(-a_{N-1}:b_{N-1}).
```

The apparent new identity with `5b_{N-1}+a_{N-1}` is an artifact of this index shift error. A successful proof still needs a mechanism beyond a single projective condition, such as genuine cross-prime independence, cancellation, or a stronger algebraic relation with subexponential right-hand side.
