## 1. Exact regular range and notation

Put

```text
M = p-2.
```

For the nonwrapping collision family define, for

```text
1 <= H <= M-1 = p-3,
```

```text
I_h = { r : 1 <= r <= M-h },
S_H = { (r,h) : 1 <= h <= H, r in I_h },
A_H = #S_H.
```

Then

```text
A_H = sum_{h=1}^H (M-h)
    = H M - H(H+1)/2.
```

Write

```text
D_h(r) = product_{j=1}^h (r+j)^3,
f_h(r) = Delta_{r,h}.
```

On S_H one has

```text
2 <= r+j <= r+h <= p-2.
```

Therefore every factor r+j is nonzero modulo p. This observation removes all wrapped and singular terms from D1-D4 when the definitions in the question are used literally.

Define

```text
Z_H = sum_{h=1}^H C_h
    = #{ (r,h) in S_H : Delta_{r,h}=0 }.
```

Also define the centered coincidence excess

```text
E_H = N_coinc(H) - A_H^2/p.
```

Parseval will show that E_H >= 0.

## 2. D1: exact determinant formula

### Verdict: PROVED on the full nonwrapping range

For fixed r define

```text
z_h = Delta_{r,h}
    = b_r c_{r+h} - b_{r+h} c_r.
```

Because z_h is a fixed linear combination of the two solution sequences b and c, it satisfies the same recurrence in the second index:

```text
(r+h+1)^3 z_{h+1}
  = P(r+h) z_h - (r+h)^3 z_{h-1}.              (2.1)
```

The initial values are

```text
z_0 = 0,
```

and, using the stated Casoratian convention,

```text
z_1
 = b_r c_{r+1} - b_{r+1} c_r
 = -W_{r+1}
 = 1/(r+1)^3.                                      (2.2)
```

The sign in (2.2) is positive. This is the first place where reversing the determinant convention would change the formula.

Set

```text
q_h = D_h(r) z_h.
```

Then

```text
q_1 = 1 = N_1(r),
q_2 = P(r+1) = N_2(r).
```

Using

```text
D_h(r) = D_{h-1}(r) (r+h)^3,
```

and multiplying (2.1) by D_h(r), one obtains

```text
q_{h+1}
 = P(r+h) q_h - (r+h)^6 q_{h-1}.                    (2.3)
```

This is exactly the defining recurrence for N_h. Hence induction gives

```text
Delta_{r,h}
 = N_h(r) / product_{j=1}^h (r+j)^3.                (D1)
```

This holds modulo p for every pair

```text
1 <= h <= p-3,
1 <= r <= p-2-h.
```

It also holds as an ordinary rational identity whenever the indicated denominators are nonzero.

### Wrapped or singular indices

If one replaces the nonwrapping interval by all r in F_p, then for a fixed h the singular residues are

```text
r = -1, -2, ..., -h mod p.
```

For h<p these are h distinct residues. Thus the number of singular pairs with 1<=h<=H is

```text
q_H = sum_{h=1}^H h = H(H+1)/2.                     (2.4)
```

But none of these pairs belongs to the actual S_H above.

A serious warning is needed. Deleting q_H terms changes the zero count and each raw B_t by at most q_H, but it need not change N_coinc by only O(q_H). If a deleted point lies in a fiber of size m, deleting it changes the squared fiber mass by about 2m. In the worst case the change can be O(q_H A_H).

Even if one assumes a COINC estimate for an enlarged set of size A_H+q_H, converting its main term to the regular set introduces

```text
((A_H+q_H)^2-A_H^2)/p
 = 2 A_H q_H/p + q_H^2/p,
```

whose first term is about H q_H, namely O(H^3), not O(q_H).

Therefore the correct procedure is not to add singular pairs and later discard them. Define S_H as the regular set from the beginning. Then D1-D4 are exact and no singular correction exists.

## 3. D2: additive orthogonality

### Verdict: PROVED exactly

Every vector v_n=(b_n,c_n) is nonzero on the regular window. Indeed, if b_n=c_n=0, the adjacent Casoratian would vanish, contradicting W_n=-1/n^3.

Therefore

```text
Delta_{r,h}=0
```

is equivalent to

```text
pi(r)=pi(r+h).
```

For x in F_p the standard additive orthogonality identity is

```text
1_{x=0} = (1/p) sum_{t in F_p} e_p(t x).
```

Summing over S_H gives

```text
Z_H
 = A_H/p + (1/p) sum_{t != 0} B_t(H).                (D2)
```

No correction term is present. Values with Delta=0 are not to be removed: they are exactly the quantity being counted.

Although the rightmost complex sum is in fact real after pairing t and -t, no reality argument is needed for the upper bound.

## 4. D3: Parseval

### Verdict: PROVED exactly

Expand

```text
|B_t(H)|^2
 = sum_{x,y in S_H} e_p(t(Delta_x-Delta_y)),
```

where x and y abbreviate pairs (r,h). Summing over all t in F_p yields p exactly when Delta_x=Delta_y and zero otherwise. Hence

```text
sum_{t in F_p} |B_t(H)|^2 = p N_coinc(H).
```

The t=0 term is A_H^2. Therefore

```text
sum_{t != 0} |B_t(H)|^2
 = p N_coinc(H) - A_H^2
 = p E_H.                                            (D3)
```

In particular E_H>=0.

### Exact role of the zero fiber

Let

```text
m_H(a) = #{ x in S_H : Delta_x=a }.
```

Then

```text
N_coinc(H) = sum_{a in F_p} m_H(a)^2,
Z_H = m_H(0).
```

Thus the zero value contributes

```text
Z_H^2
```

to N_coinc, not merely Z_H.

There is no circularity in the implication

```text
COINC -> bound on Z_H.
```

However, there would be circularity in a proposed proof of COINC that first removes the zero fiber and then pays for it using the desired estimate on Z_H.

The trivial degree estimate gives only

```text
Z_H <= sum_{h<=H} 3(h-1) = O(H^2).
```

Paying for the zero fiber with this estimate costs O(H^4) in N_coinc. To fit the original K A_H allowance, one would need

```text
H^4 <= p H,
```

that is H<=p^(1/3). This is below every range capable of improving the p^(3/2) energy exponent. Therefore a proof of COINC at a useful scale must count the zero fiber as part of the same global geometry; it cannot declare it exceptional.

## 5. D4: Cauchy-Schwarz and exact constants

### Verdict: PROVED

From D2,

```text
Z_H
 <= A_H/p + (1/p) |sum_{t != 0} B_t(H)|.
```

Cauchy-Schwarz and D3 give

```text
|sum_{t != 0} B_t(H)|
 <= sqrt((p-1) sum_{t != 0}|B_t(H)|^2)
 = sqrt((p-1)p E_H).
```

Therefore the exact general inequality is

```text
Z_H
 <= A_H/p + sqrt((p-1)E_H/p).                       (5.1)
```

Under the stated strong COINC hypothesis

```text
E_H <= K A_H,
```

this becomes

```text
Z_H
 <= A_H/p + sqrt((p-1)K A_H/p)
 <= A_H/p + sqrt(K A_H).                             (5.2)
```

Since

```text
A_H <= p H,
A_H/p <= H,
```

we obtain, with constant 1 in both displayed terms,

```text
Z_H <= H + sqrt(K p H).                              (D4)
```

Thus D4 has no missing factor sqrt(p).

The allowance K A_H is also of the right size to contain the zero-zero contribution after the conclusion is known: the second term in (5.2) has square O(A_H). But this is a consequence of COINC, not an independent proof of the zero-fiber part of COINC.

## 6. D5: the sigma-ladder mismatch

### Verdict: BROKEN as written

The current proved sigma-ladder in `FABLE_SECTION_orbit_energy.tex` defines

```text
d_D(r)
 = #{ 1<=h<=D : r+h<=M and pi(r)=pi(r+h) },

Q_p(D) = sum_r binom(d_D(r),2).                      (6.1)
```

This Q_p(D) counts unordered pairs of distinct return gaps from one left endpoint. Equivalently, it counts anchored triples

```text
pi(r)=pi(r+h)=pi(r+k),  h<k<=D.
```

By contrast,

```text
R_p(D) := sum_{h=1}^D C_h
        = sum_r d_D(r)                               (6.2)
```

counts ordinary collision pairs with one positive gap.

The proposed inequality

```text
Q_p(D) <= R_p(D)
```

is false.

A purely combinatorial counterexample is a color appearing m times inside an interval of diameter at most D. Its contribution is

```text
R_p(D) = binom(m,2),
Q_p(D) = binom(m,3).
```

For m>=6 one has binom(m,3)>binom(m,2).

The ordered-pair convention in the block energy does not repair this mismatch. It only inserts a factor 2 in front of R_p(D). Q_p(D) remains a triple-return statistic.

The universally valid crude relation is only

```text
Q_p(D)
 <= ((D-1)/2) R_p(D),                                (6.3)
```

because binom(d,2)<=((D-1)/2)d for d<=D. This loses a full factor D and does not produce a sigma>1 bound from D4.

For example, combining D4 with (6.3) gives roughly

```text
Q_p(H) <= H^2 + sqrt(p) H^(3/2),
```

which is far too large for the claimed sigma=3/2 input.

Therefore the statement

```text
Z_H <= H^(3/2)  implies the sigma=3/2 hypothesis
```

is invalid. Z_H and the sigma-ladder Q_p(H) are different moments.

## 7. D5 repaired: direct block energy

The energy conclusion survives by a shorter route.

Partition I_p into consecutive blocks of length at most H+1. Let J be the number of blocks:

```text
J = ceil(M/(H+1)).
```

Within all blocks, diagonal ordered pairs contribute M. Every unordered off-diagonal equal-color pair inside a block has a unique positive gap at most H and contributes twice. Therefore

```text
sum_{blocks j} sum_v m_j(v)^2
 <= M + 2 Z_H.
```

Cauchy-Schwarz across blocks gives the exact bound

```text
F_p
 <= ceil(M/(H+1)) (M + 2 Z_H).                       (7.1)
```

Combining (7.1) with the general second-moment inequality (5.1) gives the exact master reduction

```text
F_p <= ceil(M/(H+1))
       * ( M
           + 2 A_H/p
           + 2 sqrt((p-1)E_H/p) ).                   (7.2)
```

Under the original strong COINC hypothesis E_H<=K A_H,

```text
F_p <= ceil(M/(H+1))
       * (M + 2H + 2 sqrt(K p H)).                    (7.3)
```

This proves the intended p^(4/3) result at H about p^(2/3), without Q_p(D) and without the sigma machine.

Indeed, at

```text
H = p^(2/3+o(1)),
```

D4 gives

```text
Z_H <= p^(5/6+o(1)),
```

while the M term in (7.1) dominates. Hence

```text
F_p <= p^(1/3+o(1)) * p
    = p^(4/3+o(1)).
```

Thus the final energy exponent claimed in D5 is correct, but its stated route through the sigma-ladder hypothesis is not.

Therefore no improvement of the p^(3/2) exponent is possible through this one-scale block mechanism unless


## 10. D6: difference-curve audit

### Verdict: bidegree essentially correct, Weil-error ledger broken

On the regular open set define

```text
f_h(r) = N_h(r)/D_h(r),
D_h(r) = product_{j=1}^h(r+j)^3.
```

The equality f_h(r)=f_h'(r') is represented after clearing denominators by

```text
F_{h,h'}(r,r')
 = N_h(r) D_h'(r') - N_h'(r') D_h(r) = 0.            (10.1)
```

Over characteristic zero,

```text
deg N_h = 3h-3,
deg D_h = 3h.
```

Thus (10.1) has bidegree at most

```text
(3h,3h').
```

This part of D6 is sound as an upper bound.

### The genus is quadratic in the two degrees

A geometrically integral curve of bidegree (d,e) in P1 x P1 has arithmetic genus

```text
(d-1)(e-1).
```

With d=3h and e=3h', the generic genus is therefore

```text
O(h h'),
```

not O(h+h').

Accordingly, after component and singularity control, a safe per-pair Weil error is of size

```text
O(h h' sqrt(p)),                                     (10.2)
```

not O((h+h')sqrt(p)). Summing absolute values over h,h'<=H gives

```text
sum_{h,h'<=H} O(h h' sqrt(p))
 = O(H^4 sqrt(p)).                                   (10.3)
```

The H^3 sqrt(p) ledger in D6 is therefore one power of H too optimistic unless a special genus collapse is separately proved.

### Thresholds from absolute per-pair Weil

To prove the original strong COINC error E_H=O(pH), (10.3) would require

```text
H^4 sqrt(p) <= pH,
```

or

```text
H <= p^(1/6).                                        (10.4)
```

To prove only the minimal energy-level condition E_H<=p^2, it would require

```text
H^4 sqrt(p) <= p^2,
```

or

```text
H <= p^(3/8).                                        (10.5)
```

Both ranges lie below p^(1/2), so neither can improve the p^(3/2) energy exponent.

Even under the unproved optimistic error H^3 sqrt(p), the weak requirement E_H<=p^2 only reaches H<=p^(1/2), exactly the barrier and not beyond it.

Thus the strategic conclusion of D6 is certified:

```text
summing absolute per-pair Weil errors cannot produce a new energy exponent.
```

The numerical p^(1/4) threshold quoted in D6 is not the correct generic-genus threshold.

## 11. Components and main terms

A Weil bound is not enough without component bookkeeping.

For h=h', the curve f_h(r)=f_h(r') has the diagonal component

```text
r=r'.
```

This contributes about p points for each h. Summed over h, the contribution is O(pH)=O(A_H), so it fits the original K A_H error allowance.

A generic off-diagonal component for h=h' contributes another main term of order p, as expected for the second moment of one nonconstant map. Again, O(pH) total is allowed.

The dangerous case is a systematic common right-composition or another shared component for many cross pairs h!=h'. If a positive proportion of the H^2 cross curves acquire one additional F_p-rational component, the excess main term is order

```text
p H^2,
```

which is the same size as A_H^2/p and changes the leading constant rather than the error. Therefore an attack on COINC must prove an aggregate component theorem, not merely absolute irreducibility for a generic pair.

The continuant reflection gives the useful anti-symmetry

```text
f_h(-r-h-1) = -f_h(r).                                (11.1)
```

Indeed, N_h gains sign (-1)^(h-1), while D_h gains sign (-1)^h. Thus reflection does not create a full equality component f_h(r)=f_h(r_ref); it creates equality only at value zero. The forced mirror collision is therefore a structured zero-fiber point, not by itself a one-dimensional component of the equality curve.

## 12. Denominator saturation and spurious components

Equation (10.1) must be interpreted on the open set

```text
D_h(r) D_h'(r') != 0.
```

The affine curve obtained by cross multiplication can contain spurious points or even spurious vertical and horizontal components at poles.

There is an exact reason this is not a cosmetic issue. At a pole r=-j, 1<=j<=h, the continuant splits at its zero edge and gives, up to the displayed sign,

```text
N_h(-j)
 = (-1)^(j-1)
   ((j-1)!)^3 b_{j-1}
   ((h-j)!)^3 b_{h-j}.                               (12.1)
```

Over Q this is nonzero. Modulo p it can vanish when one of the smaller Apery numbers vanishes modulo p. If N_h(-j)=0 mod p, then the cleared equation (10.1) may contain the entire vertical line r=-j, although f_h is not defined there.

Therefore one must either:

- work with the fiber product on the open regular locus, or
- saturate the ideal by D_h(r)D_h'(r'), and then control the removed boundary.

Counting the naive cross-multiplied projective closure can reinsert the very zero-set arithmetic one is trying to bound.

## 13. Restricted windows versus full algebraic curves

For fixed h the allowed interval has length

```text
A_h = M-h = p-2-h.
```

It omits only O(h) residues from F_p, but this still matters at the centered second-moment scale.

### Full-field upper bound without completion

Since the box is a subset of F_p^2, one may upper-bound its point count by the full-field curve count. This uses no completion and hence no log^2 factor.

However, the natural full-field main term p differs from the desired box main term A_h A_h'/p by

```text
O(h+h'+1+h h'/p).
```

Summing this deterministic mismatch over h,h'<=H costs

```text
O(H^3 + H^4/p).                                      (13.1)
```

At H=p^(2/3), the H^3 term is p^2. Thus it is compatible with the weakened target E_H=O(p^2), but it is already too large for the original strong COINC error O(A_H)=O(p^(5/3)).

### Exact box main term by completion

To recover the exact interval main term, expand each interval indicator in additive Fourier modes. The L1 norm of one interval transform is O(p log p) in the unnormalized convention. Two coordinates therefore cost a factor

```text
(log p)^2
```

on the complete nonzero-frequency estimates.

For exponent statements with p^epsilon slack, this log^2 factor is harmless. It does not preserve an epsilon-free absolute-K statement unless the complete-sum estimate has corresponding logarithmic room or the long-complement structure is exploited more sharply.

Completion also enlarges the family: one must control complete sums with two additional additive frequencies, not only the zero-frequency projective curves.

## 14. Multiplicity of the pooled value map

For H=o(p), the rational map f_h has degree at most 3h<p for all sufficiently large p. Hence it is separable unless constant, and each regular geometric fiber contains at most 3h points.

For the pooled family this gives only

```text
m_H(a)
 <= sum_{h<=H} 3h
 = O(H^2).                                            (14.1)
```

Consequently the trivial multiplicity estimate yields

```text
N_coinc(H)
 <= A_H max_a m_H(a)
 <= O(p H^3),                                         (14.2)
```

which is one factor H above the random main term O(pH^2).

Thus bounded degree of each individual map is not enough. COINC is precisely a statement that different h-families do not pile up on the same values beyond random scale, except for O(A_H) structured mass.

At larger h comparable to p, degree reduction, inseparability, and p-dependent cancellations must also be audited. The proposed new-theorem ranges H=p^beta with beta<1 avoid inseparability for large p, but they do not avoid pole cancellations or common components.

## 15. Complete list of silent-loss points

A proof must explicitly close every item below.

1. Use H<=p-3 and the literal nonwrapping S_H. Do not mix it with a cyclic r-family.
2. Fix the determinant orientation. With the question's orientation, Delta_{r,1}=+1/(r+1)^3.
3. Define B_t and N_coinc on the same regular set. Deleting singular points after Parseval is not an O(#deleted) operation for N_coinc.
4. Keep Delta=0 in every moment. It contributes Z_H^2 to N_coinc.
5. Do not prove the nonzero-value fibers and then pay for zero values trivially at H>p^(1/3).
6. Distinguish R_p(H)=sum C_h from the sigma-ladder Q_p(H). The first counts pairs; the second counts anchored triples.
7. Retain the factor 2 for ordered off-diagonal pairs in block energy.
8. Use blocks of length H+1 when the controlled positive gaps are 1,...,H.
9. Saturate the difference-curve equation by its denominators.
10. Track all geometrically irreducible components and their fields of definition. The main term is component-sensitive.
11. Use the generic genus O(hh'), not O(h+h'), unless a special genus-collapse theorem is proved.
12. Distinguish the full F_p^2 count from the box I_h x I_h'. A full-field upper bound has an O(H^3+H^4/p) main-term mismatch.
13. If Fourier completion is used, include two frequency variables and the log^2 p L1 cost.
14. Control special-value multiplicities of the pooled map, especially value zero and values produced by common compositional factors.
15. For h=o(p), record separability. For h comparable to p, audit inseparability and degree drop separately.

## 16. Exact minimal target worth attacking

The recommended target is not the original absolute-K COINC statement.

### First prize: p^(4/3) energy

For each prime p, choose one integer H_p with

```text
c p^(2/3) <= H_p <= C p^(2/3).
```

Prove, for every epsilon>0,

```text
N_coinc(H_p)
 <= A_{H_p}^2/p + C_epsilon p^(2+epsilon).            (MIN-COINC-4/3)
```

Equivalently,

```text
sum_{t != 0}|B_t(H_p)|^2
 <= C_epsilon p^(3+epsilon).                          (MIN-FOURIER-4/3)
```

Then the exact master inequality (7.2) gives

```text
F_p <= O_epsilon(p^(4/3+epsilon)).
```

No Q_p estimate and no uniformity in every H are required.

### Cheapest strict improvement

It is enough to find any fixed delta>0 and one scale

```text
H_p = p^(1/2+delta+o(1))
```

for which

```text
N_coinc(H_p)
 <= A_{H_p}^2/p + p^(2+o(1)).                        (MIN-COINC-delta)
```

Then

```text
F_p <= p^(3/2-delta+o(1)).
```

This is the exact threshold at which the new second-moment program becomes a new theorem.

### Strong COINC remains a higher prize

The original estimate

```text
N_coinc(H) <= A_H^2/p + K A_H
```

at H=p^(2/3) would imply the stronger pair-count bound

```text
Z_H <= p^(5/6+o(1)),
```

but the energy argument does not need that much cancellation. It is a natural random-map theorem, not the minimal p^(4/3) certificate.

## Final referee decision

The second-moment idea is real, but the written chain conflates two distinct moments at D5.

The correct bankable chain is

```text
D1 + D2 + D3 + centered coincidence bound
 -> Z_H bound
 -> direct block-energy bound
 -> improved F_p exponent.
```

The chain

```text
Z_H bound -> sigma-ladder Q_p bound
```

is false and must be removed.

The precise attack target should be downgraded from absolute-K COINC to MIN-COINC-4/3 above. This both repairs the logic and substantially lowers the required family-averaged cancellation.
