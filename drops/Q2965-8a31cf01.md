# Q2965 — fixed-\(q\) global arithmetic audit

## Verdict

There is a very clean exact reduction which should be made first, before trying any large-sieve/Chebotarev geometry.

For fixed \(q\), put
\[
I_q(n)=\left(\frac{n}{q+1},\frac{n}{q}\right],\qquad
r_p=n-qp\quad(p\in I_q(n)).
\]
For all sufficiently large \(n\) (depending only on \(q\)), Gessel's Lucas congruence gives
\[
\boxed{\quad p\mid b_{r_p}\iff p\mid b_n\qquad(p\in I_q(n)).\quad}
\]
Hence the desired theorem is exactly
\[
\boxed{
\#\{p\in I_q(n):p\mid b_n\}=o_q(n/\log n).
}
\]
Equivalently, if
\[
R_q(n):=\prod_{\substack{p\in I_q(n)\\p\mid b_n}}p,
\]
then the remaining fixed-\(q\) theorem is
\[
\boxed{\log R_q(n)=o_q(n).}
\]
Thus the moving pair \((p,r=n-qp)\) does **not** become a useful fixed root problem after Lucas; it collapses to a pointwise large-prime-radical problem for the single integer \(b_n\).

I do **not** find an unconditional standard large-sieve, Chebotarev, or determinant-method theorem that improves the resulting elementary \(O_q(n/\log n)\) bound to little-\(o\). The obstruction is structural, not merely a missing citation:

1. a fixed bounded-degree polynomial in the index cannot represent \(b_r\bmod p\) as \(p\) varies;
2. the actual geometric realization in the repository is a **Mellin coefficient** / defining-characteristic Hasse coordinate, not an evaluation root;
3. ordinary \(\ell\)-adic monodromy and Katz's finite-field Mellin Sato--Tate theorem control complex Frobenius classes, while \(p\mid b_r\) is a \(p\)-adic/crystalline congruence at the same prime as the residue characteristic;
4. for the one character selected by \(r=n-qp\), its order is generally unbounded with \(p\), so fixed-order Chebotarev/modular descriptions cover only a negligible easy subfamily;
5. determinant-method complexity grows with \(p\) or \(n\), rather than staying in a fixed bounded-degree variety.

The smallest live geometric input is therefore a **one-character horizontal crystalline Mellin anti-concentration theorem, uniform in growing tame-character order**. Unlike the full two-prime P3.2 dispersion problem, product monodromy for two different primes/twists is not needed here; the fixed-\(q\) theorem only needs control of one marked character per prime.

## 2. Fixed-\(q\) Lucas collapse

### Proposition

Fix \(q\ge1\). There is \(N_q\) such that for every \(n\ge N_q\) and every prime
\[
p\in I_q(n)=\left(\frac n{q+1},\frac n q\right],
\]
one has
\[
p\mid b_{n-qp}\iff p\mid b_n.
\]

### Proof

For \(p\in I_q(n)\),
\[
q=\left\lfloor\frac np\right\rfloor,
\qquad n=qp+r,\qquad 0\le r<p.
\]
For fixed \(q\), once \(n\) is large enough we also have \(p>q\), so \((q,r)\) are exactly the two base-\(p\) digits of \(n\). Gessel gives
\[
b_n\equiv b_qb_r\pmod p.
\]
Now \(b_q\) is a fixed nonzero integer. Let \(S_q\) be the finite set of prime divisors of \(b_q\). If
\[
\frac n{q+1}>\max\bigl(q,S_q\bigr),
\]
then every candidate prime satisfies \(p\nmid b_q\). Hence
\[
b_n\equiv0\pmod p
\iff b_r\equiv0\pmod p.
\]
This proves the proposition. \(\square\)

So, asymptotically, there is no exceptional \(b_q\)-factor to track at all.

This is stronger conceptually than merely rewriting \(r=n\bmod p\): the entire fixed-\(q\) moving-zero problem is one window of prime divisors of \(b_n\).

## 3. Exact radical equivalence and the best immediate unconditional bound

Let
\[
T_q(n)=\#\{p\in I_q(n):p\mid b_{n-qp}\}.
\]
For large \(n\), by the proposition,
\[
T_q(n)=\#\{p\in I_q(n):p\mid b_n\}.
\]
Every \(p\in I_q(n)\) satisfies
\[
\log n-\log(q+1)<\log p\le \log n-\log q.
\]
Therefore
\[
T_q(n)(\log n-O_q(1))
\le \log R_q(n)
\le T_q(n)(\log n+O_q(1)).
\]
Consequently
\[
\boxed{
T_q(n)=o_q(n/\log n)
\iff
\log R_q(n)=o_q(n).
}
\]
This is an exact reformulation, not a heuristic.

### Elementary \(O(n/\log n)\)

From
\[
b_n=\sum_{k=0}^n\binom nk^2\binom{n+k}{k}^2
\]
and the crude bounds
\[
\binom nk\le2^n,
\qquad
\binom{n+k}{k}\le2^{n+k}\le4^n,
\]
we get
\[
0<b_n\le(n+1)64^n.
\]
Since \(R_q(n)\mid b_n\),
\[
\log R_q(n)\le n\log64+O(\log n),
\]
and hence
\[
\boxed{T_q(n)=O_q(n/\log n).}
\]
Using the known Apéry asymptotic improves only the constant:
\[
\log b_n=n\log(17+12\sqrt2)+O(\log n).
\]
It does not produce a little-\(o\) saving.

Indeed, by the PNT,
\[
\sum_{p\in I_q(n)}\log p
\sim \frac{n}{q(q+1)},
\]
while
\[
\log b_n\sim 3.52549\ldots\,n.
\]
Thus pure size leaves room for **every** candidate prime in the interval to divide \(b_n\). This is exactly the point made in the current `proof.tex` “anatomy of integers” discussion for dyadic windows: exponential height by itself cannot exclude a full proportional window of primes.

So any successful pointwise proof must exploit arithmetic structure of the large-prime radical, not merely the height of \(b_n\).

## 4. Can one replace the condition by roots of one fixed polynomial?

### 4.1 A fixed index polynomial is rigorously impossible

Suppose there were a fixed polynomial \(F\in\mathbb Z[X]\) such that, for all sufficiently large primes \(p\) and all \(0\le r<p\),
\[
F(r)\equiv b_r\pmod p.
\]
Fix an integer \(r\ge0\). For every sufficiently large prime \(p>r\),
\[
p\mid(F(r)-b_r).
\]
Infinitely many primes divide this fixed integer, so
\[
F(r)=b_r.
\]
This holds for every \(r\). But \(b_r\) has exponential growth whereas a fixed polynomial has polynomial growth. Contradiction.

The same argument rules out a fixed rational function over \(\mathbb Q\), away from finitely many poles.

Thus the raw map
\[
r\longmapsto b_r\bmod p
\]
cannot be the reduction of a fixed bounded-degree polynomial/rational function in the index.

This agrees with the current source: `proof.tex` records that the raw interpolation \(j\mapsto b_j\) already has degree \(p-2\) for \(p=11,13\), and gives an uncertainty-based linear lower bound on the degree of an unnormalised Mellin representative.

### 4.2 The known Hasse polynomial is the wrong kind of root problem

The repository has the genuine defining-characteristic polynomial
\[
A_p(t)=\sum_{j=0}^{p-1}b_jt^j.
\]
But
\[
p\mid b_r
\]
means that the **coefficient** of \(t^r\) vanishes. It does not mean that \(r\), or any canonical function of \(r\), is an evaluation root of \(A_p\).

The current `proof.tex` makes this exact using multiplicative orthogonality: for \(1\le j\le p-2\),
\[
b_j=-\sum_{t\in\mathbb F_p^\times}A_p(t)t^{-j}.
\]
So the zero set is a finite Mellin/spectral zero set.

This is the decisive coefficient/evaluation distinction. Ordinary results on the number of roots of a bounded-degree finite-field polynomial do not apply.

The fixed-\(q\) script `q32_fixed_q_content.py` uses a different polynomial carrier \(T_{n,q}\), but its degree/size grows with \(n\); it is not one fixed bounded-degree polynomial to which a uniform root-count theorem can be applied.

## 5. The trace-function route: what exists, and exactly where it stops

There is real geometry here, so it would be too pessimistic to say “no trace function exists.” The repository has already identified a bounded-complexity K3/elliptic local-system object whose Hasse/point-count function has the Apéry coefficients as finite Mellin coefficients.

The source summary in `proof.tex` is:

- the primitive toric-fiber trace is rank-three symmetric-square/Asai type;
- the defining-characteristic Hasse object has a fixed geometric origin;
- \(b_j\) is a finite Mellin coefficient;
- \(p\mid b_j\) becomes a **crystalline divisibility** condition on a twisted Mellin cohomology group.

So the natural marked object is schematically
\[
\mathscr M_{p,j}
=H_c^1\bigl(U_{\overline{\mathbb F}_p},
\mathcal V\otimes\mathcal K_{\omega_p^{-j}}\bigr),
\]
with a distinguished Hasse/crystalline coordinate whose reduction detects \(b_j\bmod p\).

### 5.1 Katz's cross-characteristic Mellin theorem is not the missing theorem

Nicholas Katz, *Convolution and Equidistribution: Sato--Tate Theorems for Finite-Field Mellin Transforms*, Theorem 28.1, is unusually relevant. It allows a sequence of finite fields \(k_i\), including prime fields of varying characteristics, and assumes for each \(i\):

- the same reductive Tannakian group \(G\) in the same representation;
- \(G_{\rm geom}=G_{\rm arith}=G\);
- uniformly bounded generic rank and number of bad characters;
- purity and semisimplicity.

It then gives equidistribution of the Frobenius conjugacy classes attached to **all good multiplicative characters** as \(|k_i|\to\infty\), with a square-root type error for fixed representations of \(G\).

A useful correction to a possible reading of the project map is that Katz Remark 28.3 explicitly says that the choices of the objects over the different \(k_i\) need no compatibility with each other once the uniform group/complexity hypotheses are verified. So cross-\(p\) compatibility is **not** needed merely to invoke Katz's complex Sato--Tate theorem.

But this still does not solve Q2965, for two independent reasons.

#### (a) Wrong local topology

The event of interest is
\[
\mathfrak p_p\mid\mathscr M_{p,j},
\]
a defining-characteristic \(p\)-adic/crystalline congruence. Katz's theorem controls the distribution of normalized \(\ell\)-adic Frobenius conjugacy classes after an embedding into \(\mathbb C\). Divisibility by the residue characteristic is not a fixed continuous conjugacy-invariant subset of the compact Sato--Tate group.

The current `proof.tex` states this obstruction explicitly as the missing “crystalline Mellin anti-concentration” problem. A bounded-rank sheaf alone cannot solve it; the source even records a rank-one Jacobi-sum counterexample with \(\gg p\) bad tame characters despite bounded geometric complexity.

#### (b) Wrong averaging variable

Katz averages over all good characters in each \(\mathbb F_p^\times\). Q2965 selects **one** character for each prime:
\[
j_p=r_p=n-qp.
\]
Vertical equidistribution of all \(p-1\) characters does not control an adversarial or arithmetic diagonal choice of one character per field.

Thus even if the defining-characteristic congruence were replaced by an ordinary trace-zero condition, vertical Mellin Sato--Tate alone would not imply the pointwise fixed-\(n\) prime count.

For comparison, Emmanuel Kowalski's *The large sieve, monodromy and zeta functions of curves*, J. reine angew. Math. 601 (2006), 29--69, DOI `10.1515/CRELLE.2006.094`, is likewise a Frobenius large sieve for algebraic families. Its power comes from fixed algebraic monodromy plus auxiliary reductions; it does not supply a defining-characteristic detector for the single diagonal Hasse coordinate here.

## 6. The selected tame-character order: an exact useful decomposition

There is a clean arithmetic fact which localizes the genuinely hard part.

Let \(\omega_p\) denote a generator/fundamental tame character, and consider the selected Mellin twist \(\omega_p^{-r_p}\). Its order is
\[
h_p
=\frac{p-1}{\gcd(p-1,r_p)}.
\]
Since
\[
r_p=n-qp\equiv n-q\pmod{p-1},
\]
we have the exact formula
\[
\boxed{
h_p=\frac{p-1}{\gcd(p-1,n-q)}.
}
\]

Now fix \(H\ge1\). If \(h_p\le H\), write
\[
d=\gcd(p-1,n-q).
\]
Then \(d\mid n-q\) and
\[
p-1=h_pd.
\]
Hence every such candidate prime is among the integers
\[
p=1+hd,
\qquad h\le H,\quad d\mid n-q.
\]
Therefore
\[
\boxed{
\#\{p\in I_q(n):h_p\le H\}
\le H\,\tau(n-q).
}
\]
Since \(\tau(m)=m^{o(1)}\), every fixed-order family contributes only \(n^{o(1)}\) primes. More strongly, taking for example \(H=n^{1/2}\),
\[
\#\{p:h_p\le n^{1/2}\}
\le n^{1/2+o(1)}
=o(n/\log n).
\]

This is important for route selection:

> **Any approach that treats only finitely many fixed-order Kummer twists, fixed modular forms, or fixed finite Galois extensions automatically addresses only the easy negligible part. The hard fixed-\(q\) primes have tame-character order tending to infinity.**

This matches the campaign map's diagnosis “low-order character law harmless; frontier = high-order Mellin diagonal.”

It also explains why one cannot sum a finite menu of Chebotarev theorems for fixed character orders and expect to close the theorem.

## 7. Why ordinary Chebotarev does not apply

There are two possible Chebotarev interpretations, and neither yields the desired pointwise saving.

### 7.1 After Gessel: target primes are divisors, not Frobenius primes

For fixed \(q\) and large \(n\), the target is simply
\[
p\mid b_n.
\]
Prime divisors of one fixed integer are naturally primes of bad reduction/ramification for algebraic constructions built from that integer, not an unramified Frobenius conjugacy condition in one fixed extension.

Effective Chebotarev (Lagarias--Odlyzko, *Effective versions of the Chebotarev density theorem*, in *Algebraic Number Fields*, 1977, pp. 409--464) counts unramified primes by conjugacy class. It does not give a nontrivial upper bound on the ramified support beyond what is already encoded in the discriminant.

If one manufactures an extension depending on \(b_n\), its discriminant/conductor necessarily carries the same large-prime support one is trying to bound. Since \(\log b_n=\Theta(n)\), a discriminant-height estimate returns at best the same \(O(n/\log n)\) scale. This is circular for the little-\(o\) objective.

### 7.2 A genuinely fixed polynomial root condition would have the wrong density

For fixed systems of polynomial congruences, the set of primes is governed by finite Galois data; see Jeffrey Lagarias, *Sets of primes determined by systems of polynomial congruences*, Illinois J. Math. 27 (1983), 224--239, DOI `10.1215/IJM/1256046492`.

A nonempty fixed Frobenius conjugacy condition normally has a fixed positive Chebotarev density. But Q2965 asks for a proportion tending to zero inside each fixed-\(q\) prime interval. Thus a fixed finite Galois condition is not even the expected shape unless the target subset itself varies and becomes thinner with \(n\), which returns us to a growing-complexity/uniformity problem.

The actual Apéry condition indeed varies: the relevant tame character has order \(h_p\) which is typically comparable to \(p\), and the event is a defining-characteristic Hasse-coordinate congruence.

## 8. Why the classical/monodromy large sieve does not give a pointwise bound

There are three distinct “large sieve” ideas one might try.

### 8.1 Classical large sieve over residue classes

For fixed \(n\), after Gessel every target prime imposes the single congruence
\[
b_n\equiv0\pmod p.
\]
If \(\mathcal P\) is a set of such primes, then
\[
\prod_{p\in\mathcal P}p\mid b_n.
\]
For one fixed integer, this is exactly the product/height argument already used above. Classical large-sieve strength appears when one averages over a large set of integer points; there is no ensemble left here once \(n\) is fixed.

Averaging over \(n\) is precisely how the existing density-one theorems succeed, but Q2965 is pointwise in \(n\).

### 8.2 Frobenius large sieve with auxiliary primes

Frobenius large-sieve theorems work by reducing a fixed compatible algebraic monodromy problem modulo auxiliary primes \(\ell\), with \(\ell\) distinct from the residue characteristic where Frobenius is taken. Here the condition to be detected is modulo the **same prime \(p\)** as the base field. That same-characteristic Hasse/crystalline event is not one of the auxiliary-\(\ell\) conjugacy conditions to which the standard sieve applies.

### 8.3 Vertical Mellin large sieve/equidistribution

Even a sharp uniform estimate saying that only \(O(1)\) or \(o(p)\) characters \(j\) are bad for each individual \(p\) would not by itself control the particular diagonal
\[
j=n-qp
\]
for every fixed \(n\). One can choose one marked element from each sparse set and align them unless there is **horizontal** arithmetic information tying the marked characters across different characteristics.

The current source makes the same distinction for the stronger all-index problem: deterministic \(O(1)\)-size zero sets can synchronize perfectly across primes; CRT is not a probability measure.

For fixed \(q\), Gessel prevents arbitrary synchronization by forcing all selected hits to divide the same nonzero integer \(b_n\), but quantitatively this gives only its exponential height, hence only \(O(n/\log n)\).

## 9. Why the determinant method does not presently apply

The determinant method in the sense of Heath-Brown (e.g. *The density of rational points on curves and surfaces*, Ann. of Math. 155 (2002), 553--598, DOI `10.2307/3062125`) gains from a **fixed bounded-degree algebraic variety** together with a height box.

There is no such fixed variety currently encoding Q2965.

Writing
\[
b_{n-qp}=pm
\]
introduces an integer \(m\) of exponential height, and the relation between \(p\) and \(b_{n-qp}\) is a P-recursive/hypergeometric coefficient relation, not a fixed polynomial equation of bounded degree in \((n,p,m)\).

Possible encodings all have growing complexity:

- interpolation of \(r\mapsto b_r\bmod p\) has degree \(\asymp p\);
- unrolling the Apéry recurrence uses \(\asymp r\) state constraints;
- continuant/Jacobi determinants have dimension growing with \(n\);
- the fixed-\(q\) Legendre--Euler content carrier has a number/degree of coefficients growing with \(n\).

A determinant-method theorem whose degree/dimension grows linearly with the height parameter does not supply the uniform constants needed for a pointwise little-\(o\) estimate.

So the determinant approach is not blocked by an overlooked application of a standard theorem; it needs a prior **compression identity** producing a bounded-complexity or subexponential-height carrier. The current Jacobi-Smith/content work is exactly an attempt to manufacture that compression.

## 10. Existing arithmetic-prime-factor theorems do not close the pointwise gap

There is relevant primary literature on prime factors of Apéry/holonomic sequences, but the quantifiers are different.

Florian Luca and Igor Shparlinski, *Arithmetic properties of Apéry numbers*, J. London Math. Soc. 78 (2008), 545--562, DOI `10.1112/jlms/jdn031`, prove lower bounds for the number/largest size of prime factors for a set of indices of asymptotic density one. This is valuable arithmetic information, but it is not a pointwise upper bound for the number of prime factors in a proportional interval \(p\asymp n\).

Likewise general “prime divisors of holonomic sequences” results typically concern the accumulation of prime divisors across many sequence terms, not the radical of one fixed coefficient in one moving prime window. They cannot be reversed into the needed pointwise statement.

Thus I do not see a theorem-level shortcut from general P-recursive/G-function arithmetic.

## 11. The smallest missing statement

There are two useful ways to state it.

### 11.1 Minimal arithmetic statement — exact and equivalent

For fixed \(q\), prove
\[
\boxed{
\log\operatorname{rad}_{I_q(n)}(b_n)=o_q(n),
}
\]
where
\[
\operatorname{rad}_{I_q(n)}(b_n)
=\prod_{\substack{p\in I_q(n)\\p\mid b_n}}p.
\]
This is literally equivalent to Q2965. It makes clear what any Smith/content construction must deliver: a carrier divisible by these primes whose logarithmic height is \(o(n)\).

### 11.2 Smallest live geometric/monodromy statement

To make a Katz/large-sieve style argument genuinely applicable, the missing input is not ordinary complex monodromy by itself. One needs an **integral, defining-characteristic horizontal statement**.

A clean sufficient package is:

> **Fixed-\(q\) horizontal crystalline Mellin anti-concentration (HCMA\(_q\)).**  There is a normalization of the Apéry Mellin objects \(\mathscr M_{p,j}\) with uniformly bounded geometric complexity and a distinguished integral/crystalline coordinate \(H_{p,j}\) such that
> \[
> H_{p,j}\equiv u_{p,j}b_j\pmod{\mathfrak p_p},
> \qquad u_{p,j}\in\mathbb F_p^\times,
> \]
> and, uniformly in \(n\), for the marked character
> \[
> j_p=n-qp,
> \]
> one has
> \[
> \#\left\{p\in I_q(n):
> H_{p,j_p}\equiv0\pmod{\mathfrak p_p}\right\}
> =o_q(n/\log n).
> \]

As written, the final line is of course the desired rare-event estimate. The genuinely structural sublemmas needed to get it from monodromy are smaller and identifiable:

1. **Integral/crystalline coordinate:** construct a normalization in which the Hasse coordinate detecting \(b_j\bmod p\) is a regular integral coordinate of the Mellin monodromy object, not merely an \(\ell\)-adic complex trace.
2. **Uniform nondegeneracy:** prove this coordinate is not identically zero on any relevant high-order monodromy component, uniformly as the tame-character order grows.
3. **Horizontal marked-character large sieve:** prove rare-event equidistribution for the single diagonal sequence
   \[
   (p,\omega_p^{-(n-qp)})
   \]
   as \(p\) ranges through \(I_q(n)\), with any saving tending to zero relative to \(\pi(I_q(n))\).

For this fixed-\(q\) problem, **product monodromy for two distinct twists is not required**. That extra ingredient belongs to the two-prime/all-index dispersion problem. Here one marked high-order twist per characteristic is enough.

The order decomposition in §6 further reduces the target: bounded- and moderately-low-order twists already contribute negligibly by
\[
\#\{h_p\le H\}\le H\tau(n-q).
\]
For instance \(H=n^{1/2}\) gives \(n^{1/2+o(1)}\). Therefore HCMA only needs to be proved for the genuinely high-order regime
\[
h_p>n^{1/2}.
\]
This is, in my view, the smallest useful uniformity statement left by the standard-tool audit.

## 12. What not to pursue, and what remains plausible

### Closed / nonproductive as a direct standard theorem

- **One fixed polynomial in the index:** impossible by the infinite-prime argument in §4.1.
- **Evaluation roots of the Hasse polynomial:** wrong Fourier side; the target is coefficient/Mellin vanishing.
- **Fixed finite-order Kummer/Hecke families:** pointwise negligible by the character-order divisor bound; they do not reach the high-order frontier.
- **Ordinary Chebotarev of a fixed finite extension:** wrong object and, if nonempty, usually positive-density rather than density zero.
- **Effective Chebotarev in an \(n\)-dependent extension:** discriminant/ramification height reintroduces the unknown radical and is circular.
- **Black-box bounded-conductor \(\ell\)-adic equidistribution:** does not detect the same-characteristic divisibility coordinate.
- **Classical large sieve at one fixed \(n\):** reduces to the product-of-prime-divisors height bound.
- **Off-the-shelf determinant method:** no fixed bounded-degree variety; complexity grows with \(n\).

### Still plausible

1. **Jacobi-Smith / determinantal-divisor compression:** prove a selected invariant/content divisible by every fixed-\(q\) target prime has logarithmic height \(o(n)\). This attacks the exact radical formulation directly.
2. **Normalized crystalline Mellin object:** discover a Gauss/Jacobi normalization that converts the raw degree-\(\asymp p\) Hasse coefficient detector into a bounded-complexity integral coordinate.
3. **Horizontal high-order anti-concentration:** once such an integral coordinate exists, prove a marked-character large-sieve theorem across varying characteristics. Katz 28.1 is relevant background for the complex monodromy side, but a defining-characteristic refinement is genuinely new input.

## Final conclusion

The fixed-\(q\) problem does have a decisive global simplification, but it points away from a standard Chebotarev solution:
\[
\boxed{
 p\mid b_{n-qp}
 \iff p\mid b_n
 \quad\text{for all sufficiently large fixed-\(q\) candidates.}
}
\]
Therefore
\[
\boxed{
\#\{p\in(n/(q+1),n/q]:p\mid b_{n-qp}\}
=o_q(n/\log n)
}
\]
is exactly the assertion that the proportional-window radical of the single Apéry integer \(b_n\) is subexponential.

The unconditional generic height argument stops at
\[
O_q(n/\log n),
\]
and that scale cannot be improved by size alone.

There is no applicable fixed finite-field polynomial root theorem: the raw index polynomial cannot be fixed, and the genuine Hasse polynomial places the target on the Mellin/coefficient side. Ordinary Chebotarev and Frobenius large sieve see unramified \(\ell\)-adic conjugacy data, whereas the target is a same-characteristic crystalline congruence. The determinant method lacks a fixed bounded-degree algebraic variety.

The smallest remaining geometric statement is therefore:

\[
\boxed{
\text{horizontal defining-characteristic anti-concentration for the one marked, high-order Apéry Mellin twist as }p\text{ varies.}
}
\]

A useful exact preliminary reduction is
\[
\operatorname{ord}(\omega_p^{-(n-qp)})
=\frac{p-1}{\gcd(p-1,n-q)},
\qquad
\#\{\operatorname{ord}\le H\}\le H\tau(n-q),
\]
so the bounded-order part is already negligible. The unresolved content is genuinely the **high-order horizontal crystalline Mellin diagonal**, not another fixed-order Chebotarev calculation.
