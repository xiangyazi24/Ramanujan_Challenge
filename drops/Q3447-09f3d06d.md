# 11. The quantifier correction: rational identity versus individual fibers

This is the point at which the proof must be scoped carefully.

For fixed `D`, define the exact endpoint defect

```text
E_D(q)
 := Delta^(D+1) V_0(q)
 = sum_(j=0)^(D+1)
     (-1)^(D+1-j) binom(D+1,j) V_j(q).                (11.1)
```

A degree-`D` polynomial on an individual fiber must satisfy `E_D(q)=0` whenever the first `D+2` endpoint points are legal.

By `(6.2)`, for `n<=D` the polynomial `f_n(j)` has degree at most `D`, hence its `(D+1)`st difference vanishes. At `n=D+1`,

```text
Delta^(D+1) f_(D+1)(0)
 = (D+1)! h_(D+1).                                    (11.2)
```

Therefore

```text
boxed:
E_D(q)
 = (D+1)! h_(D+1) q^(-(D+1))
   + O(q^(-(D+2))).                                   (11.3)
```

Since `h_(D+1) != 0`, `E_D(q)` is a **nonzero rational function**.

That proves two things, and only these two things:

1. `E_D` is not identically zero, so no uniform rational-function degree-`D` certificate exists.
2. A nonzero rational function has only finitely many zeros, so on each fixed branch/parity/fixed-`tau` ray there are only finitely many possible individual-fiber exceptions. Thus the degree-`D` ansatz fails for all sufficiently large legal `q`.

It does **not** prove that the numerator of `E_D` has no legal integer root.

The invalid inference would be

```text
E_D != 0 in Q(q)
therefore E_D(q0) != 0 for every integer q0.
```

That implication is false.

There is a second small-fiber issue: the argument `(11.1)` uses `j=0,...,D+1`, so one needs at least

```text
K >= D+2.                                              (11.4)
```

For fixed `D` this is automatic eventually, but not on every finite fiber.

Hence the maximal theorem supplied solely by the all-degree diagonal calculation is:

```text
UNIFORM RATIONAL IDENTITY:     NO, for every fixed D.
FIXED RAY, LARGE q:            NO, for every fixed D.
EVERY INDIVIDUAL FINITE q:     not from this proof alone.
ARBITRARY varying tau(q):      not from the fixed-tau eventual statement;
                               a uniform identity is still killed by
                               restricting to any fixed tau slice.
```

To close the finite-fiber quantifier for a particular `D`, factor the exact numerator of `E_D(q)`, list its integer roots, impose the legality conditions, and check the full finite recurrence at the surviving roots. That is a finite exact computation, not a scan theorem.

# SageMath
from sage.all import *

Rx = PolynomialRing(QQ, 'x')
x = Rx.gen()


def P(z):
    return 34*z^3 + 51*z^2 + 27*z + 5


# N_0=0, N_1=1,
# N_(h+1)(x)=P(x+h)N_h(x)-(x+h)^6N_(h-1)(x).
def build_gap_polys(Hmax):
    N = [Rx(0), Rx(1)]
    for h in range(1, Hmax):
        N.append(Rx(P(x+h)*N[h] - (x+h)^6*N[h-1]))
    return N


N = build_gap_polys(15)  # enough for s=4,7 and 2s


def gap_delta(h, z):
    return N[h](z) / prod((z+i)^3 for i in range(1, h+1))


def Lambda(s):
    L0, L1 = ZZ(2), ZZ(34)
    if s == 0:
        return L0
    if s == 1:
        return L1
    a, b = L0, L1
    for _ in range(1, s):
        a, b = b, 34*b-a
    return b


assert Lambda(4) == 1331714
assert Lambda(7) == 52205852194


# h_n from the proved coefficient formula.
def top_h(s, n):
    c = QQ(28 // s)
    d = QQ(Lambda(s) - 2)
    pos = sum(
        binomial(k, n-k) * d^(k-1)
        for k in range((n+1)//2, n+1)
    )
    return (-1)^n * pos / c^n


assert top_h(4, 1) == -QQ(1, 7)
assert top_h(7, 1) == -QQ(1, 4)
for s in (4, 7):
    c = QQ(28 // s)
    assert top_h(s, 2) == QQ(Lambda(s)-1) / c^2
    assert top_h(s, 3) == -QQ(Lambda(s)*(Lambda(s)-2)) / c^3
    for n in range(1, 20):
        assert top_h(s, n) != 0


Rq = PolynomialRing(QQ, 'q')
q0 = Rq.gen()
F = Rq.fraction_field()
q = F(q0)


def ray_functions(s, gamma, eta, eps, tau):
    c = ZZ(28 // s)
    X = 2*c*q + c*eta + gamma
    K = c*q + c*eps - gamma
    S = X + K
    Nphys = tau + 28*q + 28*eps

    def r(j):
        return F(-QQ(j) * (S-1-j) / ((K-j)*(S-j)))

    # A_j = A_(K-1-j), physical index N-s(j+1).
    def A(j):
        n = Nphys - s*(j+1)
        return F(gap_delta(2*s, n) / gap_delta(s, n))

    # B_j = B_(K-1-j).
    def B(j):
        n = Nphys - s*(j+1)
        return F(-gap_delta(s, n+s) / gap_delta(s, n))

    return c, X, K, S, Nphys, r, A, B


def endpoint_values(s, gamma, eta, eps, tau, upto):
    c, X, K, S, Nphys, r, A, B = ray_functions(
        s, gamma, eta, eps, tau
    )

    # Exact upper endpoint: V_0=0.
    V = [F(0)]
    for j in range(1, upto+1):
        value = r(j) + r(j)*A(j)*V[j-1]
        if j >= 2:
            # IMPORTANT: the third coefficient is B_(j-1), not B_j.
            value += r(j)*r(j-1)*B(j-1)*V[j-2]
        V.append(F(value))
    return K, V


def endpoint_defect(s, gamma, eta, eps, tau, D):
    K, V = endpoint_values(s, gamma, eta, eps, tau, D+1)
    E = sum(
        (-1)^(D+1-j) * binomial(D+1, j) * V[j]
        for j in range(D+2)

    return F(E)

    # E(q) ~ expected * q^(-(D+1)).
    assert den.degree() - num.degree() == D+1
    leading = num.leading_coefficient() / den.leading_coefficient()
    expected = factorial(D+1) * top_h(s, D+1)
    assert leading == expected, (leading, expected)
    return E


# The ten actual (alpha,beta) branch types.
branch_types = [
    (1,1), (2,1), (2,2), (3,2), (4,2),
    (4,3), (5,3), (6,3), (6,4), (7,4),
]

# Exact symbolic checks, not numerical scans.
for alpha, beta in branch_types:
    for eta in (0,1):
        for eps in (0,1):
            for tau in (-2, 0, 3):
                for D in range(0, 9):
                    audit_leading_term(4, alpha, eta, eps, tau, D)
                    audit_leading_term(7, beta, eta, eps, tau, D)


# D=1 must recover AFF1 exactly.
def check_aff1(s, gamma, eta, eps, tau):
    c, X, K, S, Nphys, r, A, B = ray_functions(
        s, gamma, eta, eps, tau
    )
    required = F((S^2 - 4*S - K + 5) / ((S-3)*(S-2)))
    assert F(2/r(2) - 1/r(1)) == required
    # A(2) is exactly A_(K-3).
    return F(A(2) - required)


for alpha, beta in branch_types:
    check_aff1(4, alpha, 0, 0, 0)
    check_aff1(7, beta, 0, 0, 0)

## 12.1 Exact finite-root audit

The next routine finds every integer `q` at which the first `D+2` endpoint values fail to witness the no-go. Since an integer root is a rational root, Sage's exact `roots(QQ)` is complete for this purpose.

```python
def possible_integer_exceptions(s, gamma, eta, eps, tau, D):
    E = endpoint_defect(s, gamma, eta, eps, tau, D)
    num = E.numerator()
    den = E.denominator()
    c = ZZ(28 // s)

    out = []
    for root, mult in num.roots(QQ):
        if root.denominator() != 1:
            continue
        qi = ZZ(root)
        if qi <= 0:
            continue
        K = c*qi + c*eps - gamma
        if K < D+2:
            continue
        if den(qi) == 0:
            continue
        out.append((qi, mult, K))
    return out
```

A root in this list is only a **possible** finite exception: it says the first `D+2` points lie on a degree-`D` polynomial. To decide the whole finite scalar WZ fiber exactly, reconstruct all endpoint values and test all `(D+1)`st finite differences:

```python
def finite_fiber_degree_D(s, gamma, eta, eps, tau, D, qi):
    c = ZZ(28 // s)
    X = QQ(2*c*qi + c*eta + gamma)
    K = ZZ(c*qi + c*eps - gamma)
    S = X + K
    Nphys = ZZ(tau + 28*qi + 28*eps)

    if K <= 0:
        return False

    def r(j):
        return -QQ(j)*(S-1-j) / ((K-j)*(S-j))

    def A(j):
        n = Nphys - s*(j+1)
        return QQ(gap_delta(2*s, n) / gap_delta(s, n))

    def B(j):
        n = Nphys - s*(j+1)
        return QQ(-gap_delta(s, n+s) / gap_delta(s, n))

    V = [QQ(0)]
    for j in range(1, K):
        value = r(j) + r(j)*A(j)*V[j-1]
        if j >= 2:
            value += r(j)*r(j-1)*B(j-1)*V[j-2]
        V.append(QQ(value))

    # A finite sequence is the restriction of a degree <= D polynomial
    # iff all (D+1)st forward differences vanish.
    diffs = V[:]
    for _ in range(D+1):
        if len(diffs) <= 1:
            return True  # too short to obstruct degree D
        diffs = [diffs[i+1]-diffs[i] for i in range(len(diffs)-1)]
    return all(z == 0 for z in diffs)


def audit_all_finite_exceptions(s, gamma, eta, eps, tau, D):
    cand = possible_integer_exceptions(s, gamma, eta, eps, tau, D)
    return [
        item for item in cand
        if finite_fiber_degree_D(
            s, gamma, eta, eps, tau, D, item[0]
        )
    ]
```

This is the finite exact computation required before claiming **every individual finite fiber**. It factors a nonzero exact numerator and checks only its finitely many legal integer roots.

# 13. Scope of the no-go

The audited theorem concerns the class

```text
after the natural Newton-kernel gauge,
the second two-state covector component is a polynomial
of one fixed degree D in j=K-1-t,
with coefficients rational in the external branch parameters;
the first component is forced by the other WZ equation.
```

It does not rule out:

- degree growing with the fiber length;
- a nontrivial denominator depending on `j`;
- arbitrary rational functions of `j` rather than polynomials;
- a mixed `Sigma/Pi` extension;
- additional state coordinates;
- a certificate chosen separately on finitely many exceptional fibers unless those fibers are checked as in Section 12.1.

This agrees with the older exact rational/hypergeometric audits: the sampled Apéry state is order two, but a restriction on the functional form of the covector is still a genuine restriction.

# Bottom line

The all-fixed-degree mechanism is real. The clean invariant is the positive diagonal sequence

```text
P_1=1,
P_2=Lambda_s-1,
P_n=(Lambda_s-2)(P_(n-1)+P_(n-2)),
```

with

```text
h_n=(-1)^n P_n/c^n != 0.
```

That forces the `q^(-(D+1))` coefficient of the endpoint WZ solution to acquire a genuine `j^(D+1)` term, impossible for any **uniform** degree-`D` rational-function certificate.

The correction is purely but importantly quantificational: a nonzero rational defect has finitely many zeros. To promote the theorem from “uniform / eventual” to “every individual finite fiber,” those finitely many exact numerator roots must be eliminated, and small fibers with `K<D+2` must be treated separately. The runnable Sage code above performs exactly that finite certification.
