# Q7151 (rc6): deterministic cluster bound audit

## 1. Setup and the exact combinatorial information available

Let \(Z\subset\{0,\ldots,p-1\}\) be ordered as
\[
z_1<\cdots <z_m.
\]
The only allowed inputs are:

1. no adjacent zeros;
2. reflection symmetry \(z\mapsto p-1-z\);
3. pair correlation bound
\[
A(h)=\#\{r:r,r+h\in Z\}\le 3(h-1),\qquad 2\le h<p.
\]

The quantity \(E_H\) counts consecutive quadruples
\[
z_i,z_{i+1},z_{i+2},z_{i+3}
\]
with span
\[
z_{i+3}-z_i\le H
\]
and excluding the centered-adjacent-pair case.

The question is therefore purely a consequence of a one-dimensional Sidon-type upper bound on differences, not of the Apéry recurrence.

## 2. Strongest unconditional consequence of the pair bound

For every interval \(I\) of length \(H\), let
\[
k_I=|Z\cap I|.
\]
Every unordered pair of points in \(Z\cap I\) contributes a difference at most \(H\). Hence
\[
\binom{k_I}{2}
\le \sum_{h\le H}A(h)
\le \sum_{h=2}^H3(h-1)
=\frac32H(H-1).
\]
Therefore
\[
k_I^2\ll H^2,
\qquad k_I\ll H.
\]
This is the only local density statement forced by the hypotheses.

A quadruple window with span at most \(H\) is contained in some interval of length \(H\). A charging argument gives
\[
E_H\le \sum_I \binom{k_I}{4},
\]
where the sum may be over a partition into \(H\)-blocks. Since
\[
k_I\ll H,
\]
this gives only
\[
E_H\ll \#\{\text{blocks}\}H^4.
\]
This is not useful globally because it ignores that the pair budget is already distributed among all gaps.

A sharper direct charge is:

Each four-window contains six internal pairs. In particular, it contains three consecutive gaps
\[
a=z_{i+1}-z_i,\quad b=z_{i+2}-z_{i+1},\quad c=z_{i+3}-z_{i+2}
\]
with
\[
a+b+c\le H.
\]
Fixing the first and last point gives a difference \(a+b+c\). The pair bound only controls the number of choices for the endpoints:
\[
\sum_{s\le H}A(s)\ll H^2.
\]
For each endpoint pair, however, the two interior points are not controlled by \(A(s)\). The trivial number of choices is \(O(s^2)\). Thus the worst bound from pair data is
\[
E_H\ll H^2\cdot H^2=O(H^4)
\]
from a single interval, and after using the total pair budget over all positions the effective short-window bound is at best
\[
E_H\ll pH^2
\]
(up to constants), not \(H^{1+o(1)}\).

## 3. Why \(O(H^{1+o(1)})\) cannot follow from these hypotheses

The obstruction is that \(A(h)\) is a second-order statistic. A four-point cluster is a fourth-order statistic. There is no general inequality converting a linear bound on every difference multiplicity into a near-linear bound on the number of 4-term clusters.

The interval-energy identity shows the limitation:
\[
\sum_h A(h)^2
\]
controls additive energy. The available hypothesis only gives
\[
A(h)^2\le 9(h-1)^2,
\]
so
\[
\sum_{h\le H}A(h)^2\ll H^3.
\]
This permits cubic-scale additive energy, whereas an \(H^{1+o(1)}\) four-cluster theorem would require essentially square-root cancellation or a genuine higher-order restriction estimate.

Fourier methods do not improve this: Parseval converts the same additive energy into
\[
\int |\widehat{1_Z}(\theta)|^4d\theta,
\]
and the supplied difference bound only gives the above \(H^3\)-scale estimate.

## 4. Palindrome does not rescue the estimate

The reflection condition pairs every cluster with a reflected cluster. It can at most divide the problem into two halves and eliminate centered configurations.

It does not decrease the local additive energy. Given a set \(S\subset[0,(p-1)/2]\), the symmetrization
\[
Z=S\cup(p-1-S)
\]
can preserve the difference multiplicity scale. Therefore palindrome contributes no new higher-order cancellation.

## 5. Extremal construction principle

The pair condition allows configurations with many short clusters.

Take a large interval-free Sidon-like skeleton \(S\) with difference multiplicities bounded by a constant multiple of the allowed budget. Replace selected points by short arithmetic packets of length \(L\), separated so that all new differences remain below the linear allowance \(3(h-1)\). Symmetrize:
\[
Z=S'\cup(p-1-S').
\]
For \(p>H^2\), the packets can be placed independently far apart.

Inside each packet of length \(H\) containing \(k\asymp H\) points, the number of consecutive four-windows is
\[
\asymp k=H,
\]
not \(H^2\), because consecutive windows count only sliding quadruples.

However, if one asks for all four-subsets (the M4R quantity), a packet gives
\[
\binom{k}{4}\asymp H^4.
\]
Thus the large gap between M4R and consecutive windows is real.

For the actual \(E_H\) definition (consecutive windows), the extremal scale allowed by the pair data is at least quadratic after placing many packets: with \(N\asymp H\) packets, each contributing \(H\) windows while respecting the global difference budget, one reaches
\[
E_H\asymp H^2
\]
in the abstract model.

Hence \(O(H^{1+o(1)})\) is false from the stated axioms alone.

## 6. Comparison with M4R

The M4R hypothesis
\[
\sum_p\log p\sum_{r:p|b_r}
\binom{R_{p,r}(H)}4
\ll X^{1+\epsilon}H
\]
controls every four-subset of every cluster.

It is much stronger than needed for consecutive windows. The deterministic audit shows:

* pair-degree bounds do not imply M4R;
* pair-degree bounds do not imply a consecutive-window bound of size \(H^{1+o(1)}\);
* the missing input is a genuine four-point correlation estimate.

The existing HM_k/AT style assumptions in the project are therefore not consequences of the verified degree-of-\(N_h\) statements. They are additional arithmetic hypotheses.

## 7. What uses the full Apéry recurrence

The following are beyond the pair bound:

* hypergeometric formula for \(b_n\);
* Frobenius/Lucas structure modulo \(p\);
* transfer-matrix constraints on multiple returns;
* algebraic relations among several continuants \(N_h\).

Any improvement from \(H^2\) toward \(H^{1+o(1)}\) must use one of these genuinely four-point structures. It cannot be obtained from the pair estimate \(A(h)\le3(h-1)\), palindrome, and no-adjacent-zero conditions alone.

## Final gate result

The deterministic kill-or-prove conclusion is:

\[
\boxed{\text{Pair caps + palindrome + no adjacency do not imply }E_H\ll H^{1+o(1)}.}
\]

The strongest clean statement from the given information is only a quadratic-scale short-window control (with global factor \(p/H\) depending on normalization), and the desired near-linear estimate requires an additional Apéry-specific higher correlation theorem. No such theorem follows from the current verified inputs.
