# Q6632: unconditional GOOD-POLE stratification and the exact limitation of GOOD-CRIT resultants

## Audit verdict

The restart argument does localize to an arbitrary interval.  The term
`p-3` in the paper's global proof may be replaced by the length of the
interval, because the telescoping is over consecutive zeros lying in that
interval.  Moreover, the short-gap roots may be counted in the corresponding
restricted start interval; the global quantity `R_rel(p,Y)` is not logically
forced.

The proposed cutoff argument therefore gives the correct order

```text
Z(H) << H^(2/3).
```

There is a cleaner and strictly sharper version.  Instead of choosing one
cutoff `Y`, retain the multiplicity of every consecutive-zero gap.  A gap with
`m` interior positions uses length `m+1`, and there are at most `3m` such gaps,
because their distinct restart points are roots of the nonzero polynomial
`U_m`, of degree `3m`.  A sharp fractional-knapsack calculation then gives

```text
Z(H) <= 1 + (3/2)(H-1)^(2/3).
```

The constant `3/2` is optimal for this degree-only restart bookkeeping.  In
particular, the same argument sharpens the currently stated global constant:

```text
|Z_p| <= 1 + (3/2)(p-3)^(2/3).
```

For the pole incidences, the exact endpoint law is

```text
N_h(-j) = (-1)^(j-1) ((j-1)!(h-j)!)^3 b_(j-1)b_(h-j).
```

Thus the claimed equivalence is correct whenever `h<p`.  The elementary
union bound gives `Bad(H) <= 2HZ(H)`, but summing the windowed estimate over
prefixes improves the constant and yields

```text
Bad(H) <= (9/5) H^(5/3) + 2H.
```

Consequently

```text
Bad(H) / (H(H+1)/2) <= (18/5)H^(-1/3) + 4/H.
```

At `H = floor(p^(2/3))`, this is

```text
Z(H) = O(p^(4/9)),
Bad(H) = O(p^(10/9)),
Bad(H)/(H(H+1)/2) = O(p^(-2/9)).
```

This is an unconditional pointwise negligible exceptional set for the
individual pole incidences `(h,j)`.

There is one important quantifier warning.  For a fixed `h`, GOOD-POLE means
that every one of the `h` pole incidences is good.  In fact

```text
GOOD-POLE_h(p)  <=>  b_m != 0 (mod p) for every 0 <= m < h.
```

Hence one early zero can make every larger `h` fail GOOD-POLE.  The theorem
proves that bad `(h,j)` incidences are sparse; it does not prove that the set
of wholly bad `h` is sparse.  The census/Gram argument must therefore be
organized incidence-by-incidence, or with an explicit allowance for bad
poles, rather than deleting every `h` having one bad pole.

The GOOD-CRIT resultant argument has a different outcome.  If a nonzero
integer certificate `D_h` has

```text
log |D_h| << h^2 log(2h),
```

then the number of its prime divisors in a dyadic prime range `[P,2P]` is at
most `O(h^2 log(2h)/log P)`.  For one fixed prime `p`, however, this only gives

```text
B_crit(p,H)
  <= sum_(h<=H) min(1, C h^2 log(2h)/log p)
  <= min(H, C' H^3 log(2H)/log p).
```

At `H=p^(2/3)` the minimum is the trivial term `H`.  Resultant height alone
therefore does not make the GOOD-CRIT exceptional set negligible at the
mesoscopic scale.  It guarantees an initial automatically good range only of
size

```text
h << sqrt(log p / log log p),
```

with the implied constant depending on the height constant.  A pointwise
GOOD-CRIT census for `h<=p^(2/3)` needs an additional cross-`h` divisibility or
dispersion theorem; it cannot be obtained by transposing the fixed-`h`
prime-divisor estimate.

## 1. Exact endpoint factorization

Let `T_h(x)` be the symmetric tridiagonal continuant matrix of size `h-1`,
with diagonal entries

```text
P(x+1), P(x+2), ..., P(x+h-1)
```

and off-diagonal entries

```text
(x+2)^3, (x+3)^3, ..., (x+h-1)^3.
```

Then `det T_h(x)=N_h(x)`.  At `x=-j`, the off-diagonal entry joining the
`(j-1)`st and `j`th blocks is zero.  Hence the determinant splits into two
continuants:

```text
N_h(-j) = N_j(-j) N_(h-j+1)(-1).
```

The continuant reflection and the value at `-1` give

```text
N_j(-j) = (-1)^(j-1) N_j(-1),
N_q(-1) = U_(q-1)(0) = ((q-1)!)^3 b_(q-1).
```

Therefore, for every `1<=j<=h`,

```text
N_h(-j)
 = (-1)^(j-1) ((j-1)!(h-j)!)^3 b_(j-1)b_(h-j).
```

If `h<p`, both factorials are units modulo `p`, so

```text
N_h(-j) = 0 (mod p)
 <=> p | b_(j-1)b_(h-j).
```

This proves the endpoint equivalence without any genericity assumption.

## 2. The localized restart inequality

Let `I` be an interval of `L` consecutive regular indices, and let its zeros
be

```text
z_1 < z_2 < ... < z_k.
```

There are no consecutive zeros.  Put

```text
s_i = z_i+1,
m_i = z_(i+1)-z_i-1 >= 1.
```

The restart identity in the paper gives

```text
U_(m_i)(s_i)=0.
```

For a fixed `m`, the starts `s_i` are distinct.  Since `U_m` is nonzero in
the banked regular range and has degree `3m`,

```text
n_m := #{i : m_i=m} <= 3m.
```

Also the actual positional lengths telescope:

```text
sum_m (m+1)n_m
 = sum_i (z_(i+1)-z_i)
 = z_k-z_1
 <= L-1.
```

This already proves the requested cutoff localization.  Define

```text
R_I(p,Y)
 = sum_(1<=m<=Y)
   #{s : s-1 and s+m lie in I, U_m(s)=0}.
```

Then

```text
Z_p(I)
 <= 1 + R_I(p,Y) + floor((L-1)/(Y+2))
 <= 1 + (3/2)Y(Y+1) + floor((L-1)/(Y+2)).
```

The denominator is `Y+2`, rather than `Y+1`, when one uses the positional
length `m+1`.  Choosing `Y` near `(L/3)^(1/3)` gives `Z_p(I)<<L^(2/3)`.
The short-gap term is genuinely local.  With only the degree estimate,
however, its unconditional bound is still `3m` for each `m`, so merely
restricting the start interval does not change the exponent.

## 3. The sharper all-gap optimization

The cutoff discards useful information.  The following elementary lemma uses
all gap lengths simultaneously.

```latex
\begin{lemma}[Capacitated gap inequality]
Let $(n_m)_{m\geq 1}$ be nonnegative real numbers satisfying
\[
        n_m\leq 3m,
        \qquad
        S:=\sum_{m\geq 1}(m+1)n_m<\infty.
\]
Then
\[
        \sum_{m\geq 1}n_m\leq \frac32 S^{2/3}.
\]
The constant $3/2$ is asymptotically sharp under these two constraints.
\end{lemma}

\begin{proof}
For $y\geq 0$ put
\[
 B_y:=\sum_{m=1}^y3m=\frac32y(y+1),
 \qquad
 D_y:=\sum_{m=1}^y3m(m+1)=y(y+1)(y+2).
\]
For a prescribed number of items, the least possible cost
$\sum(m+1)n_m$ is obtained by filling the capacities $3m$ in increasing
order of $m$.  Thus, if $D_y\leq S\leq D_{y+1}$, the fractional relaxation
gives
\[
 \sum_m n_m
 \leq B_y+\frac{S-D_y}{y+2}.
\]
On the interval $[D_y,D_{y+1}]$, the function
\[
 \frac32 S^{2/3}-B_y-\frac{S-D_y}{y+2}
\]
is concave, so its minimum is attained at an endpoint.  At either endpoint
we use
\[
 B_y=\frac32y(y+1)
 \leq \frac32\bigl(y(y+1)(y+2)\bigr)^{2/3}
 =\frac32D_y^{2/3},
\]
which is equivalent to $y(y+1)\leq(y+2)^2$.  The same calculation with
$y+1$ handles the other endpoint.  This proves the inequality.
Finally, at $S=D_y$ the ratio $B_y/S^{2/3}$ tends to $3/2$, proving the
sharpness assertion for the relaxed constraints.
\end{proof}
```

Applying this to the consecutive-zero gaps gives the desired window theorem.

```latex
\begin{theorem}[Windowed Ap\'ery zero bound]
Let $p\geq 7$ be prime, and let $I$ be an interval of $L$ consecutive
indices contained in the regular range $\{0,1,\ldots,p-2\}$.  Write
\[
 Z_p(I):=\#\{n\in I:b_n\equiv0\pmod p\}.
\]
Then
\[
 \boxed{
 Z_p(I)\leq 1+\frac32(L-1)^{2/3}.}
\]
In particular, for
\[
 Z(H):=\#\{0\leq m<H:b_m\equiv0\pmod p\},
\]
one has
\[
 Z(H)\leq 1+\frac32(H-1)^{2/3}.
\]
For the full regular zero set,
\[
 |Z_p|\leq1+\frac32(p-3)^{2/3}.
\]
\end{theorem}

\begin{proof}
If the zeros in $I$ are $z_1<\cdots<z_k$, define $m_i$ and $n_m$ as above.
The restart injection gives $n_m\leq3m$, while
\[
 S:=\sum_m(m+1)n_m=z_k-z_1\leq L-1.
\]
The capacitated gap inequality gives
\[
 k-1=\sum_m n_m\leq\frac32(L-1)^{2/3}.
\]
The displayed conclusions follow by taking $I=[0,H)$ and
$I=\{1,\ldots,p-2\}$, respectively.
\end{proof}
```

No global root count is needed in this proof beyond the per-polynomial degree
bound.  In particular, the localization is not an illicit replacement of
`p-3` by `H`; it follows from the exact identity

```text
sum_i (m_i+1)=z_k-z_1.
```

## 4. GOOD-POLE exceptional incidences

Put

```text
A_H = {m : 0<=m<H and p|b_m}.
```

The change of variables

```text
a=j-1,  b=h-j
```

is a bijection from `1<=j<=h<=H` to the lattice triangle

```text
a>=0, b>=0, a+b<=H-1.
```

The endpoint law says that an incidence is bad exactly when `a` or `b`
belongs to `A_H`.  Hence

```text
Bad(H)
 <= 2 sum_(m in A_H)(H-m)
 = 2 sum_(t=1)^H Z(t).
```

The last equality is a discrete layer-cake identity: a zero at `m` is counted
in `Z(t)` for `t=m+1,...,H`.

Using the window theorem and monotonicity of `x^(2/3)`,

```text
Bad(H)
 <= 2H + 3 sum_(u=0)^(H-1) u^(2/3)
 <= 2H + 3 integral_0^H x^(2/3) dx
 = 2H + (9/5)H^(5/3).
```

Thus the clean pointwise lemma is as follows.

```latex
\begin{corollary}[GOOD-POLE incidence census]
Assume $1\leq H<p$.  Define
\[
 \operatorname{Bad}_{\rm pole}(p,H)
 :=\#\{(h,j):1\leq j\leq h\leq H,
        \ p\mid b_{j-1}b_{h-j}\}.
\]
Then
\[
 \boxed{
 \operatorname{Bad}_{\rm pole}(p,H)
 \leq \frac95H^{5/3}+2H.}
\]
Consequently
\[
 \frac{\operatorname{Bad}_{\rm pole}(p,H)}{H(H+1)/2}
 \leq \frac{18}{5}H^{-1/3}+\frac4H.
\]
In particular, the bad pole incidences have density $O(H^{-1/3})$ in the
triangular $(h,j)$ census.
\end{corollary}
```

The simpler estimate requested in the question is also immediate:

```text
Bad(H) <= 2HZ(H) <= 3H(H-1)^(2/3)+2H.
```

The layer-cake form improves the leading constant from `3` to `9/5`.

Again, this is an incidence theorem.  If

```text
z_* = min{m>=0 : p|b_m}
```

exists below `H`, then GOOD-POLE fails for every `h>=z_*+1`.  Therefore no
bound of the form

```text
#{h<=H : GOOD-POLE_h(p) fails} = o(H)
```

follows from the window theorem.  The negligible object is the set of bad
pairs `(h,j)`.

## 5. GOOD-CRIT and the resultant certificate

Let

```text
A_h(X) = product_(j=1)^h (X+j)^3,
f_h(X) = N_h(X)/A_h(X).
```

The point at infinity lies above the value zero with local degree three, and
the poles `-1,...,-h` lie above infinity with local degree three when
GOOD-POLE holds.  Thus any phrase such as "zero is not a critical value" must
mean that there is no additional finite critical point above zero; the forced
point at infinity is not being removed by a resultant.

At a finite root `alpha` of `N_h` with `A_h(alpha)!=0`,

```text
f_h'(alpha)=N_h'(alpha)/A_h(alpha).
```

Hence, after GOOD-POLE, a sufficient certificate for the absence of an
additional finite critical point over zero is

```text
D_h = lc(N_h) Res(N_h,N_h').
```

This discussion requires `D_h!=0` in characteristic zero.  The nonvanishing
of the integer resultant is a separate geometric statement; a height bound
does not prove it.  More elaborate GOOD-CRIT conditions can be handled by
replacing `D_h` with the finite product of the relevant nonzero branch
resultants.

The coefficient estimate already proved in the project is

```text
log ||N_h||_1 = O(h log(2h)),
deg N_h = 3(h-1).
```

Hadamard's bound for the Sylvester determinant, together with
`||N_h'||_1 <= deg(N_h)||N_h||_1`, gives

```text
log |D_h| <= C h^2 log(2h)
```

for an absolute `C`.  The same order holds for any fixed finite product of
resultants between degree-`O(h)` polynomials of coefficient height
`exp(O(h log h))`.

The correct exceptional-prime lemma is the following.

```latex
\begin{lemma}[GOOD-CRIT resultant census]
Let $(\mathfrak D_h)_{h\geq1}$ be nonzero integers satisfying
\[
 \log|\mathfrak D_h|\leq C h^2\log(2h).
\]
For a prime $p$, put
\[
 B_{\rm crit}(p,H)
 :=\#\{1\leq h\leq H:p\mid\mathfrak D_h\}.
\]
Then
\[
 \boxed{
 B_{\rm crit}(p,H)
 \leq
 \sum_{h\leq H}
 \min\left\{1,\frac{C h^2\log(2h)}{\log p}\right\}
 \leq
 \min\left\{H,
       \frac{C_1H^3\log(2H)}{\log p}\right\}.}
\]
Moreover, for every $P\geq2$,
\[
 \sum_{P<p\leq2P}B_{\rm crit}(p,H)
 \leq \frac{C_1H^3\log(2H)}{\log P}.
\]
\end{lemma}

\begin{proof}
If $p\mid\mathfrak D_h$, then
$\log p\leq\log|\mathfrak D_h|$.  Therefore
\[
 {f1}_{p\mid\mathfrak D_h}
 \leq
 \min\left\{1,
       \frac{\log|\mathfrak D_h|}{\log p}\right\},
\]
and summing over $h$ proves the pointwise bound.  For the dyadic statement,
every prime divisor in $(P,2P]$ consumes at least $\log P$ from
$\log|\mathfrak D_h|$; sum first over the prime divisors of each
$\mathfrak D_h$, and then over $h$.
\end{proof}
```

The wording "there are `O(h^2 log h/log p)` bad primes per `h`" is correct
only after `p` is interpreted as a lower scale, for example primes in
`[p,2p]` or primes at least `p`.  It is not a pointwise statement about one
specified prime.

## 6. Evaluation of the GOOD-CRIT bound at the campaign scale

Let `T=T(p)` be a threshold satisfying

```text
C T^2 log(2T) < log p.
```

Then `|D_h|<p` for `h<=T`, so none of those `h` can be bad.  One may take

```text
T = c_C sqrt(log p/log log p)
```

for all sufficiently large `p`, with `c_C>0` small enough.  This is the only
automatically good pointwise range supplied by the height estimate.

For `H` much larger than `T`, the terms

```text
min(1, C h^2 log(2h)/log p)
```

are capped at one for essentially the whole interval `T<h<=H`.  Thus the
sum is only `O(H)`, not `o(H)`.  In particular, at

```text
H = floor(p^(2/3)),
```

one gets

```text
B_crit(p,H) <= H,
```

with no power saving and no vanishing exceptional fraction.

Averaging over primes in `[P,2P]` does not repair the mesoscopic scale.  By
the prime number theorem, the mean number of bad `h` per prime is at most

```text
O(H^3 log(2H)/P),
```

and the mean bad fraction is at most

```text
O(H^2 log(2H)/P).
```

This becomes negligible only in the range

```text
H^2 log H = o(P),
```

roughly `H=o(sqrt(P/log P))`.  It is useless at `H=P^(2/3)`.

Therefore the two exceptional-set lemmas have sharply different statuses:

```text
GOOD-POLE:
  pointwise and negligible for individual (h,j) incidences up to H=p^(2/3).

GOOD-CRIT from resultant height alone:
  fixed-h / prime-averaged information only; pointwise trivial at H=p^(2/3).
```

To make GOOD-CRIT negligible in the required pointwise growing family, one
needs a new assertion such as

```text
#{h<=H : p|D_h} << H^(1-delta)
```

uniformly for `H<=p^(2/3)`, or a suitable weighted version.  Such a theorem
must use cross-`h` structure of the critical resultants.  It is not a
consequence of their individual sizes.
