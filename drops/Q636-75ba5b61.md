# Q636: Greene hypergeometric formula, Gross–Koblitz, and Apéry zeros

## Executive summary

The Greene/Gross–Koblitz route is very useful for making the Apéry trace function explicit, but it does **not by itself** prove AFP. The obstruction is the same one identified in the self-twist discussion: explicit formulas and bounded conductor control the size of individual terms, but AFP requires an anti-concentration theorem for the whole character sum.

The key point is:

\[
 b_r\equiv0\pmod p
\]

is not caused by a single Jacobi sum having positive valuation. For the Apéry parameters the summands are typically p-adic units. The zero is a high-dimensional cancellation phenomenon.

---

# (A) Greene formula

Greene defines finite-field hypergeometric functions by

\[
 {}_{n+1}F_n\left(\begin{matrix}A_0,A_1,\ldots,A_n\\B_1,\ldots,B_n\end{matrix}\middle|x\right)_p
 =\frac{p}{p-1}\sum_{\chi}\binom{A_0\chi}{\chi}
 \prod_{i=1}^n\binom{A_i\chi}{B_i\chi}\chi(x).
\]

Here the sum is over all multiplicative characters \(\chi\) of \(\mathbf F_p^\times\), so there are exactly

\[
p-1
\]

terms.

The normalized binomial coefficient is

\[
\binom{A}{B}=\frac{B(-1)}{p}J(A,\bar B),
\]

where

\[
J(A,B)=\sum_{t\in\mathbf F_p}A(t)B(1-t)
\]

is the Jacobi sum.

Therefore for Apéry parameters:

\[
{}_4F_3
\left(
\begin{matrix}
\phi,\phi,\phi,\phi\\
\epsilon,\epsilon,\epsilon
\end{matrix}
\middle|x
\right)_p
=
\frac{p}{p-1}\sum_\chi
\binom{\phi\chi}{\chi}^4\chi(x),
\]

where \(\phi\) is the quadratic character and \(\epsilon\) is trivial.

Expanding the Greene coefficients:

\[
\binom{\phi\chi}{\chi}
=
\frac{\chi(-1)}{p}J(\phi\chi,\bar\chi),
\]

so the summand is

\[
\frac{\chi(-1)^4}{p^4}
J(\phi\chi,\bar\chi)^4\chi(x).
\]

Hence the trace is a sum of \(p-1\) Jacobi-sum terms.

# (B) Gross–Koblitz expression

Gross–Koblitz gives, for characters represented by exponents \(a,b\in\{0,\ldots,p-2\}\),

\[
J(\omega^{-a},\omega^{-b})
=
\frac{\tau(\omega^{-a})\tau(\omega^{-b})}
{\tau(\omega^{-(a+b)})},
\]

and

\[
\tau(\omega^{-a})
=-\pi^{a/(p-1)}\Gamma_p\left(\frac{a}{p-1}\right).
\]

Therefore

\[
J(\omega^{-a},\omega^{-b})
=
-\pi^{\{a/(p-1)\}+\{b/(p-1)\}-\{(a+b)/(p-1)\}}
\frac{
\Gamma_p(a/(p-1))\Gamma_p(b/(p-1))
}
{\Gamma_p((a+b)/(p-1))}.
\]

For

\[
J(\phi\chi,\bar\chi),
\]

write

\[
\chi=\omega^{-m}.
\]

Then

\[
\phi\chi=\omega^{-(m+(p-1)/2)},
\]

and each Greene factor becomes

\[
J(\omega^{-(m+(p-1)/2)},\omega^{m}).
\]

Thus the Apéry term is a fourth power of

\[
\frac{
\Gamma_p\left(\frac{m+(p-1)/2}{p-1}\right)
\Gamma_p\left(\frac{p-1-m}{p-1}\right)
}
{
\Gamma_p(1/2)
}
\]

up to the explicit Gross–Koblitz power of \(\pi\) and a root of unity.

This gives a completely explicit p-adic Gamma representation of every character summand.

# (C) Can the formula determine when \(b_r=0\)?

Not currently.

The formula reduces the problem to

\[
\sum_{m=0}^{p-2} U_m(r)=0,
\]

where each \(U_m(r)\) is essentially a p-adic unit:

\[
U_m(r)=G_m^4\omega^{-m}(r).
\]

The Stickelberger/Gross–Koblitz valuation computation shows that almost all \(G_m\) have valuation zero.

Therefore:

\[
b_r\equiv0\pmod p
\]

means

\[
\sum_m U_m(r)\equiv0\pmod p.
\]

This is cancellation among \(p-1\) unit terms.

The Greene formula transforms AFP into:

> prove that a bounded-complexity multiplicative Fourier transform has only O(1) zero fibers.

That is a genuine anti-concentration statement.

---

# (D) Stickelberger valuations

For Jacobi sums,

\[
v_p(J(\omega^{-a},\omega^{-b}))
=
\left\{\frac a{p-1}\right\}
+
\left\{\frac b{p-1}\right\}
-
\left\{\frac{a+b}{p-1}\right\}.
\]

For the Apéry term:

\[
a=m+(p-1)/2,
\]

\[
b=p-1-m.
\]

The fractional parts are

\[
\left\{\frac{m}{p-1}+\frac12\right\},
\]

and

\[
\left\{1-\frac m{p-1}\right\}.
\]

There is a strong simplification because

\[
a+b=p-1/2?\]

in the character indexing convention this corresponds to the quadratic shift. The valuation is therefore controlled only by whether the shifted exponent crosses the midpoint.

In particular the fourth power appearing in the Apéry formula has highly symmetric valuation distribution.

This explains why the zero phenomenon is not valuation-driven: the summands live mostly in the same valuation layer.

---

# (E) Does a theorem already prove O(1) zeros?

No known theorem gives this directly.

There are related results:

1. Deligne/Katz give square-root cancellation for trace functions:

\[
\left|\sum_x t(x)\psi(x)\right|\ll C\sqrt p.
\]

2. Katz proves equidistribution when the monodromy group is sufficiently large.

3. Finite-field hypergeometric functions have strong distribution results.

However, AFP asks a stronger question:

\[
\#\{r:{}_4F_3(r)=0\}=O(1).
\]

This is a zero-fiber estimate, not merely a value-distribution estimate.

The missing theorem would look like:

\[
\boxed{
\#\{x\in\mathbf F_p:t(x)=0\}
\ll 1
}
\]

for this particular Mellin/hypergeometric trace function.

No general theorem of this strength is known.

---

# Consequence for the Apéry GCD project

The Greene/Gross–Koblitz route is still valuable because it identifies the exact missing object:

\[
 b_r \bmod p
\]

is a finite-field hypergeometric trace function with:

- bounded rank;
- bounded conductor;
- Sp_4-type monodromy;
- trivial self-twist kernel.

The remaining step is not computation of the formula. That part is available.

The missing step is:

\[
\boxed{
\text{hypergeometric Mellin anti-concentration:}
\\
\#\{r:{}_4F_3(r)=0\}=O(1).
}
\]

A proof would likely require a new combination of Katz hypergeometric sheaf theory plus a mod-p zero-fiber theorem, rather than only Gross–Koblitz.
