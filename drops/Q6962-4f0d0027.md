# Correct scalar orientation audit

The previous inverse-sigma derivation is wrong. The correct identity is obtained without inverses.

Assume the three existing facts:

```lean
hTU : T n ⬝ U (n+1) = U n ⬝ C n
hAC : A n ⬝ C n.transpose = 1
hTM : T n.transpose ⬝ M n = sigma n • (1 : Matrix (Fin 3) (Fin 3) ℝ)
```

Transpose the Krylov identity:

```text
(T n * U(n+1) = U n * C n)^T
```

so

```text
U(n+1)^T * T(n)^T = C(n)^T * U(n)^T.
```

Left multiply by `A n`:

```text
A n * U(n+1)^T * T(n)^T
 = A n * C(n)^T * U(n)^T
 = U(n)^T.
```

Therefore

```text
U(n)^T = A(n) * U(n+1)^T * T(n)^T.
```

Right multiplying by `M(n)` gives

```text
U(n)^T * M(n)
 = A(n) * U(n+1)^T * T(n)^T * M(n)
 = sigma(n) • (A(n) * U(n+1)^T).
```

The scalar is `sigma`, not `sigma⁻¹`.

## Lean proof skeleton

The proof should keep matrix associativity explicit:

```lean
lemma krylov_pull_step (n : ℕ) :
    U nᵀ ⬝ M n = sigma n • (A n ⬝ U (n+1)ᵀ) := by
  have ht : U (n+1)ᵀ ⬝ T nᵀ = C nᵀ ⬝ U nᵀ := by
    simpa [Matrix.transpose_mul] using congrArg Matrix.transpose (hTU n)
  have hleft : A n ⬝ U (n+1)ᵀ ⬝ T nᵀ = U nᵀ := by
    rw [ht]
    simp [Matrix.mul_assoc, hAC]
  calc
    U nᵀ ⬝ M n
        = (A n ⬝ U (n+1)ᵀ ⬝ T nᵀ) ⬝ M n := by rw [hleft]
    _ = A n ⬝ U (n+1)ᵀ ⬝ (T nᵀ ⬝ M n) := by simp [Matrix.mul_assoc]
    _ = A n ⬝ U (n+1)ᵀ ⬝ (sigma n • 1) := by rw [hTM]
    _ = sigma n • (A n ⬝ U (n+1)ᵀ) := by simp [smul_mul_assoc]
```

No inverse or determinant lemma appears.

# Product telescope

Define chronological products:

```lean
def Mprod : ℕ → Matrix (Fin 3) (Fin 3) ℝ
| 0 => 1
| n+1 => Mprod n ⬝ M n

 def Aprod : ℕ → Matrix (Fin 3) (Fin 3) ℝ
| 0 => 1
| n+1 => Aprod n ⬝ A n
```

The recurrence is

```text
U(0)^T M(0) M(1) ... M(N-1)
 = (σ0 ... σN-1) A(0) A(1) ... A(N-1) U(N)^T.
```

Lean statement:

```lean
lemma telescope (N : ℕ) :
  U 0ᵀ ⬝ Mprod N
    = (∏ n in Finset.range N, sigma n) •
      (Aprod N ⬝ U Nᵀ) := by
  induction N with
  | zero => simp [Mprod, Aprod]
  | succ N ih =>
      rw [Mprod, Aprod]
      rw [Matrix.mul_assoc, ih]
      rw [krylov_pull_step]
      simp [Finset.prod_range_succ, Matrix.mul_assoc, mul_smul]
```

The important orientation point is that products are chronological on the right:

```text
M0 M1 ... M(N-1)
```

and the dual pull product is

```text
A0 A1 ... A(N-1).
```

Reversing these orders is the hidden orientation bug.
