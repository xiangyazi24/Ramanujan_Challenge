# Post-wrap shortest missing-edge audit

## Verdict

No new implication to the target follows from the currently proved carriers. The shortest surviving missing edge is:

```text
odd-quotient target support carrier
        +
shifted/central-binomial nuisance carrier
        => a second integer whose prime support is exactly the target support
```

No existing claim proves the required cancellation/intersection identity.

The obstruction is not clerical: the proved divisibility statements only give containment in the wrong direction for removing nuisance primes.

## 1. Available proved carriers

The current proved facts give:

```text
Gamma_n | b_n
Gamma_n | B_n
```

and hence

```text
Gamma_n | gcd(b_n,B_n).
```

The large-prime description gives, for `p^2>n`,

```text
p | Gamma_n iff q is odd and p | b_r,
```

where `n=qp+r`.

The shifted aggregate has exact squarefree support and removes small-prime/prime-power issues, but it does not identify its support with the characteristic-zero gcd support.

## 2. Attempted lcm/intersection coupling

The only possible immediate coupling would be to combine two divisors of `b_n`:

```text
Gamma_n | b_n
S_n | b_n
```

for a second carrier `S_n`.

However, from

```text
Gamma_n | b_n
```

and support information about `Gamma_n`, one cannot conclude

```text
rad(b_n) = rad(Gamma_n * something small).
```

A second divisor of `b_n` can only certify primes that occur in both carriers. It cannot remove primes that occur in one divisor unless an explicit coprimality or complementary-factor identity is proved.

No such identity exists among the currently proved claims.

## 3. Why the central binomial does not close the edge

The central binomial gives

```text
Gamma_n | B_n.
```

For large primes:

```text
p|B_n
```

contains the Kummer classes

```text
q odd and 1<=r<=p-2,
q even and r=1.
```

The first class overlaps the desired odd-quotient Apéry-Lucas support. The second class is nuisance support.

The existing support theorem for `Gamma_n` does not imply that the nuisance class disappears from `gcd(b_n,B_n)`; it only implies that the nuisance class is absent from `Gamma_n` unless it also satisfies the Apéry residue condition.

Therefore the missing implication is precisely a removal theorem for the extra central-binomial support.

## 4. Height audit

For `p>sqrt(n)` write

```text
q=floor(n/p)<sqrt(n).
```

The nuisance condition is

```text
p|b_q
```

with the Kummer restriction on `(q,r)`.

The obvious recursive charge is

```text
sum_{q<sqrt(n)} log(rad(b_q)).
```

Using only the Apéry growth bound

```text
log b_q = Theta(q),
```

gives

```text
sum_{q<=sqrt(n)} O(q)=O(n),
```

which is critical. No proved claim currently improves this to `o(n)`.

The Mellit--Vlasenko block decomposition controls divisibility and valuation structure of individual `b_q`, but does not provide a support sparsity estimate strong enough to replace the above sum by `o(n)`.

## 5. Missing edge after removing clerical dependencies

The shortest open edge is therefore:

```text
large-prime nuisance support
{p>sqrt(n): p|b_q, q=floor(n/p), Kummer(B_n) holds}

      must imply

log(product nuisance primes)=o(n).
```

Equivalently, one needs either:

```text
(A) a subcritical-height integer carrier divisible by every odd-quotient target
    and by no nuisance primes,
```

or

```text
(B) a characteristic-zero support theorem showing the nuisance primes have
    o(n) total logarithmic mass.
```

Neither follows from the current claim graph.

## Final result

The dependency audit closes all direct intersections that are already licensed. The remaining non-clerical missing edge is not another Gamma/Pade/block lemma. It is exactly the nuisance-prime elimination step for the half-cutoff central-binomial carrier.

No currently proved inequality or divisibility identity supplies that edge.
