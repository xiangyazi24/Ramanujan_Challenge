# Cold audit of the recovered full Padé minor carrier

## Executive summary

The proposed theorem is not correct as stated. The obstruction is not in the row-reduction idea for the maximal minors: that part gives the right *shape* of the minor gcd. The failures occur in the prime-support conclusions. In particular, the statements in (B) and the no-prime-above-`n` claim require extra hypotheses that are not present.

The correct audited status is:

* (A) is the correct determinant reduction, with the caveat that the phrase "all maximal minors" must be interpreted through the full Cauchy--Binet family after unimodular reduction.
* The claimed equivalence in (B) is not proved by Apéry--Lucas alone. The forward implication can be obtained under the usual Lucas hypotheses, but the converse and the valuation-one assertion need an additional nonvanishing and lifting argument. The endpoint `n=2p-1` is not automatically covered.
* The claim that no prime `ell>n` divides `D_n` is false without a separate argument controlling the common gcd of the binomial coefficients. The statement that every `L_j(n)` is an `ell`-adic unit is true for `ell>n`, but it is insufficient because the differences `b_n-b_j` can carry such a prime.

# 1. Audit of (A)

Let

```
A_x(k)=binom(x,k),
B_x(k)=b_x binom(x,k).
```

Perform the column operation

```
B_k <- B_k - b_n A_k
```

on the second block of `M` columns. This is unimodular over `Z`. The row indexed by `n` becomes

```
(b_n-b_n)binom(n,k)=0.
```

Therefore every maximal minor with the last row selected reduces to the determinant of an `M x M` Pascal block times one entry from the transformed last row. The Pascal block is unitriangular after ordering columns by `k=0,...,M-1`, hence has determinant `1`.

For a choice of omitted column in the transformed two-block matrix, the surviving coefficient is exactly

```
L_j(n)(b_n-b_j)
```

where

```
L_j(n)=(-1)^(M-1-j) binom(n,j) binom(n-j-1,M-1-j).
```

The signs arise from the Pascal determinant expansion. Thus the maximal minors generate the ideal generated by these numbers.

Hence

```
D_n = gcd_j L_j(n)(b_n-b_j)
```

provided that all maximal minors are included. This last qualification matters: proving one family of minors is not enough; the reverse divisibility follows only after showing every possible column choice reduces to the same generator family. The Pascal block argument supplies that.

Conclusion: (A) survives.

# 2. Audit of (B)

Let `p>=5` and `n/2<p<=n`.

Because `p>n/2`, write

```
n = p+r,   0<=r<p.
```

The relevant Apéry congruence is the Lucas-type relation

```
b_{p+r} == b_r (mod p).
```

Therefore

```
b_n-b_{n-p} == 0 (mod p).
```

This proves the easy direction:

```
p | b_(n-p) does not follow.
```

The missing step is that the congruence only identifies `b_n` and `b_r` modulo `p`; it does not say that the common value is zero modulo `p`.

So the proposed equivalence

```
p|D_n iff p|b_(n-p)
```

is not a consequence of Apéry--Lucas. The left side requires divisibility of every generator

```
L_j(n)(b_n-b_j).
```

For `j=r=n-p`, the Lucas congruence gives divisibility of the difference. For other `j`, one needs a second argument. That argument is absent.

The endpoint `n=2p-1` is especially delicate because

```
r=p-1
```

and reflection identities for Apéry numbers involve alternating binomial sums with possible extra factors of `p`. The usual Lucas statement does not automatically extend to the valuation statement.

Therefore the valuation claim

```
v_p(D_n)=1
```

is also unproved. It requires both:

1. at least one maximal minor having exact `p`-valuation one;
2. all maximal minors having valuation at least one.

The proposed proof only addresses (2).

Conclusion: (B) is not established and is false as a theorem in the stated generality.

# 3. Audit of primes `ell>n`

For `ell>n`, every factor

```
binom(n,j), binom(n-j-1,M-1-j)
```

has numerator and denominator involving integers smaller than `ell`. Hence

```
ell does not divide L_j(n).
```

However the claimed conclusion requires

```
ell ∤ L_j(n)(b_n-b_j)
```

for some `j`.

The missing point is that the argument never controls

```
b_n-b_j.
```

An arbitrary prime larger than `n` could divide all differences. The fact that the coefficients are units does not prevent this.

The proposed use of `j=0,1` is not sufficient: those generators are available only when the corresponding indices occur in the range `0<=j<M`. For the smallest cases the range must be checked separately.

Conclusion: the no-prime-above-`n` statement is not proved.

# 5. Possible strengthening for height

A useful weaker target is not the radical statement but a restricted support statement:

> For primes `p>n/2`, any contribution to `D_n` must arise from the Apéry difference part `b_n-b_j`; the Pascal coefficient contributes no such prime.

This follows from the `p>n/2` binomial-unit observation. It isolates the difficult arithmetic to Apéry congruence and lifting properties.

A second possible strengthening is:

> Bound the contribution of primes `p<=n/2` by separating the Pascal coefficient gcd from the Apéry difference gcd.

This is a meaningful route toward height estimates, but it does not imply

```
log D_n=o(n)
```

without an explicit estimate on the small-prime valuations.
