# 1. Universal proof of the even-gap mate factor

This factor does not need to be guessed from \(h=4,6,8\). It follows from an exact odd-dimensional anticommutation.

Let \(n=h-1\). Define the symmetric tridiagonal matrix

\[
A_h(r)=
\begin{pmatrix}
P(r+1)&(r+2)^3&&&\\
(r+2)^3&P(r+2)&(r+3)^3&&\\
&\ddots&\ddots&\ddots&\\
&& (r+h-2)^3&P(r+h-2)&(r+h-1)^3\\
&&&(r+h-1)^3&P(r+h-1)
\end{pmatrix}.
\]

The continuant recurrence gives

\[
\boxed{\det A_h(r)=N_h(r).}
\tag{1.1}
\]

Similarly, let

\[
B_h(r)_{jj}=Q_j(r),
\qquad
B_h(r)_{j,j+1}=B_h(r)_{j+1,j}=(r+j+1)^3.
\]

Then

\[
\boxed{\det B_h(r)=\mathcal R_{h-1}(r).}
\tag{1.2}
\]

Now suppose \(h\) is even and put

\[
r_0=-\frac{h+1}{2}.
\]

Then \(n=h-1\) is odd. Let \(J\) be the reversal permutation matrix on \(n\) coordinates.

For the Apéry diagonal, the identity

\[
P(-1-t)=-P(t)
\tag{1.3}
\]

and

\[
r_0+h-j=-1-(r_0+j)
\]

give reversal of every diagonal entry with a minus sign. For an edge indexed by \(j\),

\[
r_0+h-j=-(r_0+j+1),
\]

so the cubic off-diagonal entry also changes sign under reversal. Hence

\[
\boxed{J A_h(r_0)J=-A_h(r_0).}
\tag{1.4}
\]

For the Racah diagonal, write

\[
t_j=r_0+j.
\]

A direct rearrangement gives

\[
Q_j(r_0)
=(2t_j+1)
 \bigl(t_j(t_j+1)+2r_0(r_0+1)+1\bigr).
\tag{1.5}
\]

Under \(j\mapsto h-j\), one has

\[
t_j\mapsto -1-t_j.
\]

The quadratic factor in (1.5) is invariant, while \(2t_j+1\) changes sign. The off-diagonal entries change sign exactly as above. Therefore

\[
\boxed{J B_h(r_0)J=-B_h(r_0).}
\tag{1.6}
\]

Taking determinants and using odd \(n\),

\[
\det A_h(r_0)
=\det(-A_h(r_0))
=(-1)^n\det A_h(r_0)
=-\det A_h(r_0),
\]

and similarly for \(B_h\). Thus

\[
N_h(r_0)=\mathcal R_{h-1}(r_0)=0.
\]

Consequently

\[
\boxed{
2r+h+1\mid N_h(r),
\qquad
2r+h+1\mid\mathcal R_{h-1}(r)
\quad(h\text{ even}).
}
\tag{1.7}
\]

This proof is only a central-point argument for the Racah continuant; it does not require, and in general one does not have, the same global reflection identity for \(\mathcal R_{h-1}\) that \(N_h\) enjoys.

## 1.1 Why the mate factor is outside the stable half-range

Since \(s=r+h\),

\[
\kappa_h=2r+h+1=r+s+1.
\]

If

\[
0\le r<s\le\frac{p-1}{2},
\]

then

\[
1\le r+s+1\le p-h<p.
\]

Thus \(\kappa_h\not\equiv0\pmod p\) in the physical folded range.

Conversely, if \(\kappa_h\equiv0\pmod p\) and one takes the representative with \(\kappa_h=p\), then

\[
r=\frac{p-h-1}{2},
\qquad
s=r+h=\frac{p+h-1}{2}>rac{p-1}{2}.
\]

It is exactly the reflection/mate configuration, not a stable first-half pair.

This proves the existence and harmlessness of the structural factor for **every** even gap.

It does **not** by itself prove that no further common factor appears for some larger even \(h\). That additional reduced coprimality is verified below for \(h=4,6,8\), but remains a separate all-\(h\) theorem.

# 4. What the exact resultants prove for each fixed gap

Fix one of \(h=3,\ldots,8\). Let

\[
S_h=\operatorname{Res}(N_h^*,R_h^*)\ne0.
\]

For every prime \(p\nmid S_h\), the two reduced polynomials are coprime over

\[
\overline{\mathbf F}_p.
\]

Therefore they cannot have a common value \(r\) modulo \(p\). For even \(h\), the only deleted characteristic-zero common factor is \(\kappa_h\), which is nonzero in the stable folded range. Hence

\[
\boxed{
p\nmid S_h
\quad\Longrightarrow\quad
\text{no physical common root for gap }h.}
\tag{4.1}
\]

In particular, if \(P_h\) denotes the largest prime factor displayed in the table, then

\[
\boxed{p>P_h\Longrightarrow\text{gap }h\text{ is excluded}.}
\tag{4.2}
\]

Thus the individual eventual thresholds are exact.

A complete all-prime theorem for one fixed gap still requires checking the finite prime divisors of \(S_h\). It is unnecessary to scan every prime below \(P_h\): only the displayed finite factor set can matter. Q2355 already performs this endpoint audit for \(h=3\). The present calculation verifies the elimination/resultant part for \(h=4,\ldots,8\); it does not silently claim that every exceptional divisor in (3.1) has already undergone the separate Apéry endpoint-zero check.

This distinction matters because the largest exceptional factors for \(h=6,7,8\) are enormous, but the number of exceptional primes is only \(13,16,20\).

# 5. Growth of the reduced resultants

## 5.1 What the six exact values say

The decimal digit counts are

\[
\begin{array}{c|rrrrrr}
h&3&4&5&6&7&8\\ \hline
\#\text{digits}(|\widetilde S_h|)&21&54&123&197&331&449.
\end{array}

\]

They are not suggestive of polynomial-size integers or of a bound \(\exp(O(h))\). On this short range, the normalized quantities

\[
\frac{\#\text{digits}(|\widetilde S_h|)}{h^2\log h}
\]

are approximately

\[

\]

Thus the observed size is strikingly compatible with an

\[
\exp(\Theta(h^2\log h))
\]

scale.

This is evidence, not an asymptotic lower-bound proof. Six points cannot logically distinguish every possible polynomial or exponential law. What can be proved uniformly is the following upper bound.

## 5.2 Rigorous coefficient-height bound

Let \(n=h-1\). For \(1\le j\le n\), the coefficient \(\ell^1\)-norms satisfy

\[
\|P(r+j)\|_1\le C_1(h+1)^3,
\]

\[
\|Q_j(r)\|_1\le C_2(h+1)^3,
\]

and

\[
\|(r+j)^6\|_1=(j+1)^6\le(h+1)^6.
\]

Expand either continuant determinant by path matchings. A matching with \(m\) edges contributes \(n-2m\) diagonal cubic factors and \(m\) edge factors of degree six. Its norm is therefore at most

\[
\bigl(C(h+1)^3\bigr)^{n-2m}
\bigl((h+1)^6\bigr)^m
\le
\bigl(C'(h+1)^3\bigr)^n.
\]

The path has fewer than \(2^n\) matchings. Consequently

\[
\boxed{
\|N_h\|_1,
\ \|\mathcal R_{h-1}\|_1
\le
\bigl(C''(h+1)^3\bigr)^h,
}
\tag{5.2}
\]

and hence

\[
\log H(N_h),\quad
\log H(\mathcal R_{h-1})
=O(h\log h).
\tag{5.3}
\]

Deleting a linear factor and passing to a primitive factor changes this by at most another exponential-in-degree Mignotte factor, so the reduced primitive polynomials still have

\[
\log H(N_h^*),\quad\log H(R_h^*)=O(h\log h).
\tag{5.4}
\]

Their degrees are at most \(3(h-1)\). The Sylvester matrix has dimension \(O(h)\), and Hadamard's inequality, equivalently the standard resultant height bound, yields

\[
\begin{aligned}
|S_h|
&\le
\bigl(\sqrt{d_N+1}\,H(N_h^*)\bigr)^{d_R}
\bigl(\sqrt{d_R+1}\,H(R_h^*)\bigr)^{d_N}\\
&\le \exp\!\bigl(O(h^2\log h)\bigr).
\end{aligned}
\]

Therefore

\[
\boxed{
P_{\max}(h)
\le |S_h|
\le \exp\!\bigl(O(h^2\log h)\bigr).
}
\tag{5.5}
\]

In particular, one may weaken this to

\[
P_{\max}(h)\le \exp(O(h^3)),
\]

so the proposed phrase “exponential in a polynomial in \(h\)” is valid. A polynomial bound in \(h\), or the much stronger \(\exp(O(h))\), has not been proved and is not supported by the observed sizes.

# 6. The fixed-\(q\) threshold calculation

The algebra in the question omitted a factor of \((\log N)^{k-1}\).

Suppose

\[
P_{\max}(h)<\exp(C'h^k)
\]

and \(h<C\log N\). Then

\[
\begin{aligned}
P_{\max}(h)
&<\exp\!\left(C'C^k(\log N)^k\right)\\
&=N^{C'C^k(\log N)^{k-1}}.
\end{aligned}
\tag{6.1}
\]

There are three cases.

### \(k=1\)

One gets a fixed power

\[
N^{C'C}.
\]

Even then, a scan only through \(p<N\) covers the exceptional primes only if the constants are chosen so that

\[
C'C<1.
\]

### \(k>1\)

The exponent of \(N\) grows with \(N\). It is not a fixed power. Thus the conclusion written in the question is false.

### The proven height bound

From (5.5), with \(h=C\log N\),

\[
P_{\max}(h)
\le
\exp\!\bigl(O((\log N)^2\log\log N)\bigr)
=N^{O(\log N\log\log N)}.
\tag{6.2}
\]

This gives no exclusion for a prime \(p\in(N,2N]\).

To force the general height bound below \(N\), one needs approximately

\[
h^2\log h\ll\log N,
\]

or

\[
\boxed{
h\ll\sqrt{\frac{\log N}{\log\log N}}}
\tag{6.3}
\]

with a sufficiently small implied constant. This is substantially shorter than \(C\log N\).

Therefore the current fixed-gap resultant argument can support a sublogarithmic gap cutoff of the scale (6.3), but it does not by itself support the stated logarithmic cutoff.

# 7. Exact logical status of the proposed P3.2 closure

The requested checks establish:

\[
\boxed{
\begin{array}{ll}
\text{(i)}&\kappa_h=2r+h+1\text{ divides both continuants for every even }h;\\
\text{(ii)}&\kappa_h\text{ is outside the stable folded range};\\
\text{(iii)}&\gcd(N_h^*,R_h^*)=1\text{ for }3\le h\le8;\\
\text{(iv)}&\text{each of those six gaps has a completely finite exceptional-prime set};\\
\text{(v)}&P_{\max}(h)\le\exp(O(h^2\log h))\text{ uniformly}.
\end{array}}
\tag{7.1}
\]

They do **not** establish either of the two uniform statements needed by the proposed global proof:

1. for every \(h\), the primitive gcd has no factor beyond \(\kappa_h\); or
2. for every \(h<C\log N\), all exceptional primes are \(<N\).

The first remains an all-gap coprimality theorem. The second would follow from an explicit bound of the form

\[
\log P_{\max}(h)\le Ah
\]

combined with a sufficiently small logarithmic cutoff constant \(C<1/A\). The available general bound is quadratic-logarithmic in \(h\), and the exact \(h\le8\) values grow on that larger scale.

A different possible closure would be endpoint-sensitive: prove that every prime divisor of the reduced resultant gives only an extraneous common root and can never coexist with

\[
b_r=b_{r+h}=0
\]

in the physical range. That would eliminate the need to bound the exceptional prime itself. No such uniform endpoint theorem follows merely from the characteristic-zero resultant.

Hence the correct final ruling is:

> **The breakthrough is genuine at the fixed-gap level. The mate factor is universally structural and physically harmless, and the reduced pair is coprime for every tested gap \(3\le h\le8\). But the claimed logarithmic-range P3.2 closure does not follow from an \(\exp(\operatorname{poly}(h))\) exceptional-prime bound. The threshold substitution in part (c) is the remaining fatal gap.**

# 8. Reproducible exact PARI/GP audit

The following is the compact script used for the exact recurrence, gcd, resultant, and factorization computation. It follows the parser form already validated by the corrected Q2354 transcript.

```gp
\\ Exact Q2356 fixed-gap audit.
default(parisizemax, 8000000000);
allocatemem(1000000000);

P(t) = 34*t^3 + 51*t^2 + 27*t + 5;
Q(m,t) = (2*t + 2*m + 1) *
         (3*t^2 + 2*t*m + m^2 + 3*t + m + 1);

apery_gap(H,T) = {
  my(a = 1, b, c);
  if(H == 1, return(a));
  b = P(T + 1);
  if(H == 2, return(b));
  for(k = 2, H - 1,
      c = P(T + k)*b - (T + k)^6*a;
      a = b;
      b = c);
  b
};

racah_gap(M,T) = {
  my(a = 1, b, c);
  if(M == 0, return(a));
  b = Q(1,T);
  if(M == 1, return(b));
  for(k = 2, M,
      c = Q(k,T)*b - (T + k)^6*a;
      a = b;
      b = c);
  b
};

audit(H) = {
  my(A = apery_gap(H,X));
  my(B = racah_gap(H - 1,X));
  my(mate = 2*X + H + 1);
  my(Ar = A, Br = B, qa, qb, rawres, Ap, Bp, primres, fac, nf);

  print("H=", H);
  print("degrees=", poldegree(A), ",", poldegree(B));
  print("raw gcd=", gcd(A,B));

  if(H % 2 == 0,
     qa = divrem(A,mate);
     qb = divrem(B,mate);
     if(qa[2] != 0 || qb[2] != 0,
        error("mate division failed"));
     Ar = qa[1];
     Br = qb[1];
     print("mate=", mate));

  print("reduced contents=", content(Ar), ",", content(Br));
  print("primitive reduced gcd=",
        gcd(Ar/content(Ar), Br/content(Br)));

  rawres = polresultant(Ar,Br,X);
  print("raw reduced resultant digits=", #Str(abs(rawres)));
  print("raw reduced factorization=", factor(abs(rawres)));

  Ap = Ar/content(Ar);
  Bp = Br/content(Br);
  primres = polresultant(Ap,Bp,X);
  fac = factor(abs(primres));
  nf = matsize(fac)[1];
  print("primitive factorization=", fac);
  print("largest prime=", fac[nf,1]);
  print("---")
};

for(H = 3, 8, audit(H));
quit;
```

The uniform mate-factor proof in Section 1 is independent of this finite script. The script certifies the exact reduced gcds and integer factorizations for the requested six gaps.
