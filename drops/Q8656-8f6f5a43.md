# Verdict
The repeated-prime argument does not currently prove the desired bound $L=o(X/\log^3X)$ for one fixed full-defect key. The strongest unconditional consequence of the stated ingredients is an overlap-sensitive bound of order at best $O(X)$ (and in some regimes $O(X/\log X)$ after using the number of available shell primes). There is no valid independence gain from the repeated-prime structure alone.

# 1. Fixed key and reuse incidence

Fix signs and defects. A solution has translations $t$ and a triple of shell primes
\[
(p_1,p_2,p_3),
\]
with
\[
 p_i\mid N-d_i,\qquad p_i\mid B_{u_i(t)}.
\]
For fixed coordinate $i$, the folded anchor is affine:
\[
 u_i(t)=\operatorname{fold}(s_i(t+d_i+\tau_i)\bmod p_i).
\]
Away from the reflection midpoint this is injective in $t$.

If the same prime $p_i$ occurs at two translations $t,t'$, then
\[
 p_i\mid B_{u_i(t)},B_{u_i(t')}.
\]
The Casoratian/gap-polynomial estimates control such repeated roots. Writing $h=u_i(t')-u_i(t)$, a common zero forces divisibility of a transfer determinant such as
\[
N_h(u_i(t)),
\]
so the number of possible second anchors for one prime is bounded by the divisor structure of this determinant.

This is useful locally, but it is not a bound on the number of translations because the prime can be changed between solutions.

# 2. Split by prime-set overlap

Let the $L$ solutions be $S_1,\dots,S_L$, each with a three-prime set.

## Large disjoint subfamily

A greedy matching argument gives a subfamily with pairwise disjoint prime triples of size at least
\[
\frac{L}{3\Delta},
\]
where $\Delta$ is the maximum number of other solutions sharing one shell prime.

Thus one needs a strong bound for prime reuse. The Casoratian only controls reuse of one fixed prime in one coordinate; it does not control the number of different triples attached to the same translation key.

The trivial estimate is
\[
\Delta\leq \#\{p\in(X,2X]\}\ll X/\log X,
\]
which gives no useful saving.

## Overlapping subfamily

If many solutions share primes, charge to reused primes. For a fixed prime and coordinate, the number of possible anchors is controlled by common-root estimates. However summing over all possible primes gives
\[
\sum_{X<p\leq2X} O(\text{root reuse bound}),
\]
which is at least of order the number of shell primes unless a new uniform gap-divisor estimate is proved.

The current recurrence package does not supply this extra saving.

# 3. Why the three product differences do not close

For two solutions,
\[
D_i=(N'-d_i)B_{u_i(t)}-(N-d_i)B_{u_i(t')}
\]

satisfies
\[
 p_ip_i'\mid D_i.
\]

But this is exactly a two-dimensional endpoint relation. After primitive saturation the factors carrying the target primes are removed. Combining $D_1,D_2,D_3$ therefore produces only relations among saturated endpoint vectors, not new target divisibility.

Consequently no bounded-height integer is obtained whose divisor count would force bounded fibre multiplicity.

# 4. HM2 and folded-anchor distinctness

HM2 controls the number of pairs of hits over all rows:
\[
\sum_m(K(m))_2\ll X^2\lambda^2.
\]

A fixed fibre is much thinner information: it conditions on the same defects and signs. Applying HM2 gives only an averaged bound over keys. It cannot exclude one exceptional key with many translations.

Folded-anchor distinctness removes repeated anchors inside one prime coordinate, but it does not prevent different primes from supplying different anchors.

# 5. Coefficient lattice geometry

For a fixed prime triple, the CRT/product-difference equations give a lattice in the translation and quotient variables. This can save a factor of $X$ when counting all triples.

However for one fixed defect key, summing over possible prime triples leaves roughly
\[
\#\{(p_1,p_2,p_3)\}\sim (X/\log X)^3.
\]
The lattice determinant saves only the geometric volume factor already used in the triple count. It does not convert into a logarithmic prime-consumption bound.

# 6. Sharp conclusion from current ingredients

The available tools prove:

- fixed-prime repeated-root structure: yes;
- bounded reuse for a given prime and anchor gap: yes;
- exclusion of large fibre by a direct determinant: no;
- logarithmic saving from prime consumption: no.

The obstruction is that all current estimates are conditional on choosing a prime or a coordinate. They do not produce a global consumption law saying that every additional solution spends a new amount of Apéry root complexity.

A proof of
\[
J_X=o(X/\log^3X)
\]
would require a genuinely new ingredient, for example a uniform bound on the total multiplicity of shell primes across all three coordinates, a higher-dimensional Casoratian with target divisibility surviving saturation, or a mixed-coordinate anti-concentration theorem. The repeated-prime and matching arguments alone do not reach the required scale.
