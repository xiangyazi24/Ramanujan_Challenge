# Q780 fixed-origin obstruction audit

## Verdict

The requested fixed-origin upgrade is not currently derivable from the listed inputs. The random-translation argument controls the translation average of the relevant third factorial moment, but there is no established identity forcing the distinguished origin interval `[0,X^2)` to have the same L2 discrepancy as a random translate up to a lower-order error.

The first fatal gap is the missing boundary-control statement:

```
E_origin - E_translation_average = o(main term)
```

where `E` is the weighted pair/Palm or third-factorial discrepancy. None of the listed Apéry constraints implies this.

## 1. What the random-translation input actually gives

The ensemble argument has:

- exact share-0 independence;
- nonnegative share-1/share-2 covariance;
- bounded second zero mass;
- variance `O(X^2/log^3 X)` for most translates.

This proves that for most shifts `t`, the translated interval avoids excess clustering. It does not identify the translate `t=0`.

The distinction is not cosmetic. A translation average contains a smoothing over endpoints. The fixed interval has a deterministic remainder at every prime:

```
X^2 = q_p p + u_p,
0 <= u_p < p.
```

The contribution of a prime p therefore depends on the residue placement in the terminal block of length `u_p`.

## 2. Examination of proposed exact structures

### Floors and endpoints

The decomposition

```
floor(X^2/p),  u_p=X^2 mod p
```

is exact, but it only isolates the obstruction. It does not bound it. A third factorial moment involves pair and triple correlations of the residual sets, and endpoint errors can accumulate over many primes.

A needed lemma would be something like:

```
Sum_{p<=X} discrepancy_origin(p)
  <= O(X^2/log^3 X)
```

or a comparable bound. This is not a consequence of the floor identity alone.

### Apéry reflection

The symmetry

```
Z_p = -1-Z_p
```

gives reflection around `-1/2`. It pairs residues under `t -> -1-t`, not under translation by arbitrary amounts. The interval `[0,X^2)` is not invariant under this involution; it becomes an interval near `[-X^2-1,-1]`.

Hence reflection does not cancel the boundary term.

### Initial condition `b_0=1`

The recurrence initial condition determines the sequence normalization. It gives no direct estimate on the distribution of the zero set modulo varying primes.

### Pairing `t` with `-1-t`

This is the only plausible exact symmetry. However, it yields at most a relation between two opposite boundary intervals. It does not turn the fixed interval into the translation ensemble. One still needs a discrepancy estimate comparing those two boundary placements.

## 3. Countermodel showing insufficiency of local constraints

A model preserving the stated local constraints can be built as follows.

For every prime p choose a symmetric set

```
Z_p subset F_p,
Z_p=-1-Z_p,
|Z_p| = prescribed density.
```

Arrange the sets so that:

1. random translations have small covariance because the exceptional alignment occurs only at one translate;
2. the translate `t=0` places many elements of every `Z_p` inside `[0,X^2)`;
3. the recurrence normalization information is unchanged because it concerns the values `b_n`, not the artificial residue placement model.

Then the translation L2 norm is small while the origin third factorial moment is large.

Therefore no theorem using only the listed local constraints can prove the fixed-origin statement.

## 4. Relation to pair-Palm excess and LGTQ-3

The pair-Palm excess detects the same phenomenon: translation averaging suppresses rare alignments, while a distinguished origin may sit on an exceptional alignment.

The LGTQ-3 obstruction is logically prior: it asks for a deterministic control of higher-order clustering. The fixed-origin question is a stronger form because it requires controlling the actual interval rather than a random translate.

Thus:

```
random-translation variance bound
        !=
fixed-origin factorial moment bound
```

without an additional Apéry-specific estimate.

## 5. Smallest genuinely Apéry-specific missing inequality

The minimal missing input is a deterministic residue-discrepancy bound for the Apéry zero sets. One acceptable form would be:

```
For every X,
Sum_{p<=X} w_p * |#(Z_p intersect [0,X^2))
                 - X^2|Z_p|/p|
   <= o(X^2/log^2 X)
```

with weights strong enough to dominate the pair and triple terms.

A weaker but still sufficient replacement is a direct third-factorial estimate:

```
F_origin(X)
 <= F_translation_average(X)
    + O(X^2/log^{3+delta} X).
```

Proving either statement requires genuinely Apéry-specific arithmetic information about the zero sets. The currently listed reflection, recurrence, and endpoint identities do not provide it.

## Conclusion

The fixed-origin obstruction remains real. The random-translation ensemble result is a valid averaged statement, but there is no exact symmetrization reducing the origin case to it. The first fatal gap is the unproved boundary discrepancy estimate connecting the distinguished origin interval to the translation L2 norm.
