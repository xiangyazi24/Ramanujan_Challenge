# 1. The exact Newton row is a gauged high difference

The coefficient has the elementary barycentric form

```text
binom(d+i,i) binom(d+L+1,L-i)
 = binom(L,i)
   * (d+1) binom(d+L+1,L)/(d+i+1).                 (1.1)
```

Indeed, both sides equal

```text
(d+L+1)! / (d! i! (L-i)! (d+i+1)).
```

With the forward difference convention

```text
Delta^L h_d
 = sum_(i=0)^L (-1)^(L-i) binom(L,i) h_(d+i),
```

(1.1) gives the exact identity

```text
G_(d,L)(F)
 = (-1)^L (d+1) binom(d+L+1,L)
   Delta^L ( F_d/(d+1) ).                           (1.2)
```

This is the correct replacement for the false step in Q5923.  The factor `(d+i+1)^(-1)` is load-bearing.  In Ore notation, with `S d = (d+1) S`,

```text
T_L
 = sum_(i=0)^L (-1)^i binom(d+i,i)
                     binom(d+L+1,L-i) S^i

 = (-1)^L (d+1)binom(d+L+1,L)
   (S-1)^L (d+1)^(-1).                              (1.3)
```

The last product is noncommutative: `(d+1)^(-1)` acts first.  Treating (1.3) as an ordinary unweighted finite difference changes the operator and invalidates every subsequent end-factor calculation.

The Newton row also has coefficient sum one:


Hence the constant origin `b_M` survives as one constant state coordinate.

# 2. Exact Ore conjugation theorem

Let `K` be a characteristic-zero field with shift automorphism `sigma(d)=d+1`, and let

```text
P = p_0 + p_1 S + ... + p_rho S^rho
```

annihilate `f`.  Put `g=T_L f`.

## Theorem 2.1

There is an operator `Q` of order at most `rho` such that

```text
Q T_L = U P                                           (2.1)
```

for some Ore operator `U`.  Consequently `Q g=0`.

### Proof by left least common multiple

Take

```text
H = lclm(P,T_L).
```

Then

```text
H=U P=Q T_L.
```

The standard order bound for a left lcm gives

```text
ord(H) <= ord(P)+ord(T_L)=rho+L.
```

Since `ord(T_L)=L`,

```text
ord(Q)=ord(H)-L <= rho.
```

This is an identity in the Ore ring over the rational-function field, so it is exact and independent of the chosen solution.

### Equivalent companion-state proof

Let `A_P(d)` be the `rho` by `rho` companion transition of `P`, and let `c_L(d)` be the row obtained by reducing `T_L` on the state

```text
(f_d,f_(d+1),...,f_(d+rho-1))^T.
```

The `rho+1` rows

```text
c_L(d),
 c_L(d+1) A_P(d),
 ...,
 c_L(d+rho) A_P(d+rho-1)...A_P(d)
```

lie in a `rho`-dimensional row space.  Their exact left-kernel relation is the operator `Q`.  This version is useful because it exposes the determinant that blocks the height argument below.

# 4. What happens to target-prime end factors

```text

t_L=          binom(M-r+1,L).                       (4.2)
```


The second gcd is immediate from

```text
 =-(r+L-M+2)(r+L+2)(r+L+3):                        (4.5)
```

the first factor in (4.5) is one step beyond the last factor of the binomial numerator, and the other two have the opposite `M`-slope.

# 5. The exact characteristic-zero obstruction: the cyclic determinant

```text
D_(P,L)(d)=det O_(P,L)(d).                          (5.2)
```

```text
 =O_(P,L)(d+1) A(d) O_(P,L)(d)^(-1).                (5.3)
```


# 6. Why a bounded homogeneous recurrence gives no gcd-height bound

This is a characteristic-zero obstruction, not a finite-field rank argument.

Let `V` be any recurrence solution space and let `e(v)` be the scalar output obtained from a state `v`.  Every equation produced by the Section-60 operators, the true Newton conjugation, direct sums, tensor products, and exterior observations is homogeneous in `v`.  Therefore

```text
e(c v)=c e(v)                                       (6.1)
```

for every integer `c`.

Suppose recurrence coefficients alone implied a nonzero target-blind Bezout identity

```text
sum_j A_j(M,D,N) e_(d+j)=Q(M,D,N),                  (6.2)
```

where `Q` depended only on the operator data.  Apply (6.2) to the zero state, or replace `v` by `c v`.  The left side scales by `c`, while the right side does not.  Hence necessarily

```text
Q=0.                                                (6.3)
```

A nonzero Bezout right side can arise only after inserting a normalization of the **actual** Apéry state or actual boundary packets.  If a block of `R` initial values has common divisor `g`, every propagated value and every homogeneous Casoratian built from that state retains the corresponding power of `g`.  Regular recurrence coefficients do not divide it away.

For the present sequence, that state content contains the target radical by construction.  Thus proving that the actual primitive state has subexponential content is the original arithmetic problem in a new basis.  Bounded order alone supplies no height gain.

This also explains why a transfer matrix is not enough.  It can express every translated `E` as a rational combination of at most `7410` boundary values.  Clearing denominators gives a characteristic-zero identity, but its nonzero right side is a determinant or gcd of those actual boundary values.  The committed endpoint audits show those values on the full exponential scale; no polynomial-height cancellation is known.

# 7. The maximal-margin boundary is outside the 38-state module

There is an additional exact domain obstruction at the margin which numerically removes the moving Kummer tail.

For the maximal translated family, including the `d+-1` shifts in `Z`, Section 68.7 gives

```text
e_-=D-m,
e_+=D+N+m-1.                                     (7.1)
```

Let `M=n-1`.

## Left-active maximum

If the left margin is active,

```text
e_-=floor(M/2).                                     (7.2)
```

For every sufficiently large relevant moment `M,M+1,...,M+5`,

```text
floor((M+j)/e_-)=2.                                 (7.3)
```

The shell domain is therefore

```text
2P cap ZZ^3,
```

which has

```text
|2P cap ZZ^3|=100                                  (7.4)
```

lattice points, whereas the certified first-cell decomposition uses

```text
|P cap ZZ^3|=22.                                    (7.5)
```

There are 78 additional rays.  The active terminal row that breaks the Kummer flat cell is therefore not a value of the committed 38-state first-cell module.  It can be peeled off as a bounded number of terminal packets, or a new second-cell telescoper can be derived, but it cannot be silently propagated by the Section-60 operators.

## Right-active maximum

If the right margin is active, `e_+=n=M+1`.  For the old moment `M` this contributes only the origin packet, and for the shifted moments it remains in the first cell.  Thus the right-active case can be incorporated by adjoining a constant boundary coordinate.  The left-active `2P` packet is the genuine new module.

This boundary issue is not cosmetic.  Removing the active row restores precisely the near-`n` and half-scale Kummer factors that maximal saturation was designed to destroy.  Hence an interior recurrence plus a trivial boundary omission does not prove the full-margin gcd theorem.

# 8. Executable Sage/ore_algebra audit

The following script uses the repository's certified ray operators, constructs the **true** Newton observation, derives its exact bounded-order relation by companion-state elimination, and factors the cyclic determinant and recurrence ends.  It contains no numerical fitting.

```sage
#!/usr/bin/env sage
from pathlib import Path
from ore_algebra import *

ROOT = Path(__file__).resolve().parents[4]
load(str(ROOT / "problems/3.2/research/scripts/"
                "q32_first_cell_ray_telescopers.sage"))

# The loaded file defines
#   R.<M,r,t> = QQ[]
#   OA.<Sr,St> = OreAlgebra(R)
#   RAY_CLASSES, operators
K = R.fraction_field()


def sigma(x, k=1):
    return K(x)(M=M, r=r+k, t=t)


def sigma_matrix(A, k=1):
    return A.apply_map(lambda x: sigma(x, k))


def pbinom(x, k):
    out = K.one()
    for j in range(k):
        out *= (x-j)/(j+1)
    return K(out)


def true_newton_coefficients(L):
    """g_L(r)=G_(M-r-L,L)(f)=sum_j c_j(r) f_(r+j)."""
    d = M-r-L
    out = []
    for j in range(L+1):
        i = L-j
        direct = (-1)^i * pbinom(d+i, i) * pbinom(d+L+1, j)

        # Independent check of the gauged-difference identity (1.2).
        Krow = (d+1)*pbinom(d+L+1, L)
        gauged = (
            (-1)^L * Krow * (-1)^j * binomial(L,j)
            / (d+L-j+1)
        )
        assert K(direct-gauged) == 0
        out.append(K(direct))
    return vector(K, out)


def companion(P):
    rho = P.order()
    A = matrix(K, rho, rho, 0)
    for i in range(rho-1):
        A[i,i+1] = 1
    for j in range(rho):
        A[rho-1,j] = -K(P[j])/K(P[rho])
    return A


def observation_row(A, coeffs):
    """Reduce sum_j coeffs[j] f_(r+j) to the base state at r."""
    rho = A.nrows()
    e0 = vector(K, [1] + [0]*(rho-1))
    row = vector(K, [0]*rho)
    transition = identity_matrix(K, rho)
    for j,c in enumerate(coeffs):
        row += c*(e0*transition)
        transition = sigma_matrix(A,j)*transition
    return row


def shifted_observations(A, c):
    rho = A.nrows()
    rows = []
    transition = identity_matrix(K, rho)
    for j in range(rho+1):
        cj = vector(K, [sigma(x,j) for x in c])
        rows.append(cj*transition)
        transition = sigma_matrix(A,j)*transition
    return matrix(K, rows)


def primitive_relation(rel):
    den = lcm(K(x).denominator() for x in rel if x)
    polys = [R(den*K(x)) for x in rel]
    common = gcd([f for f in polys if f])
    polys = [R(f/common) for f in polys]

    qden = lcm(
        a.denominator()
        for f in polys for a in f.coefficients()
    )
    polys = [R(qden*f) for f in polys]
    content = gcd([
        ZZ(a) for f in polys for a in f.coefficients() if a
    ])
    return tuple(R(f/content) for f in polys)


def conjugate_ray(P, L):
    A = companion(P)
    c = observation_row(A, true_newton_coefficients(L))
    Oplus = shifted_observations(A,c)
    ker = Oplus.left_kernel()
    assert ker.dimension() >= 1
    relation = primitive_relation(ker.basis()[0])

    rho = P.order()
    O = Oplus.matrix_from_rows(range(rho))
    cyclic_det = K(O.det())

    active = [j for j,f in enumerate(relation) if f]
    assert active[-1]-active[0] <= rho

    # Exact coefficient identity Q*T = U*P can also be checked by lclm:
    T = sum(true_newton_coefficients(L)[j]*Sr^j for j in range(L+1))
    H = P.lclm(T)
    Q, remT = H.quo_rem(T)
    U, remP = H.quo_rem(P)
    assert remT == 0 and remP == 0
    assert Q*T == U*P
    assert Q.order() <= rho

    return {
        "input_order": rho,
        "output_order": active[-1]-active[0],
        "relation": relation,
        "cyclic_det": cyclic_det,
        "trailing": factor(relation[active[0]]),
        "leading": factor(relation[active[-1]]),
    }


def end_coprimality(P,L):
    rho = P.order()
    coeffs = true_newton_coefficients(L)
    t0 = K(coeffs[0])
    tL = K(coeffs[-1])
    return (
        gcd(R(P[0]), R(t0.numerator())),
        gcd(R(sigma(P[rho],L)),
            R(sigma(tL,rho).numerator())),
    )


# Exact audit for every certified ray and selected true Newton lengths.
for (point,multiplicity),P in zip(RAY_CLASSES,operators):
    for L in (0,1,2,3,5,8):
        record = conjugate_ray(P,L)
        print("RAY",point,"MULT",multiplicity,"L",L)
        print("  ORDER",record["output_order"])
        print("  END_GCDS",end_coprimality(P,L))
        print("  TRAILING",record["trailing"])
        print("  LEADING",record["leading"])
        print("  CYCLIC_DET",factor(record["cyclic_det"]))

print("Q5938_TRUE_NEWTON_CONJUGATION=PASS")
```

For a concrete full-margin `L`, replace the test tuple by `(L,)`.  The same `shifted_observations` routine constructs the scalar recurrence of the tensor observation.  If `A_Y,c_Y` and `A_Z,c_Z` are the already-conjugated state transitions and observations, the raw exterior row is

```sage
def row_kron(a,b):
    return vector(a.base_ring(), [x*y for x in a for y in b])


def one_shift(A,c):
    return vector(c.base_ring(), [sigma(x) for x in c])*A


def exterior_state(A_Y,c_Y,A_Z,c_Z,pascal_factor):
    cY1 = one_shift(A_Y,c_Y)
    cZ1 = one_shift(A_Z,c_Z)
    A_E = A_Y.kronecker_product(A_Z)
    c_E = (
        row_kron(c_Y,cZ1)-row_kron(cY1,c_Z)
    )/pascal_factor
    return A_E,c_E
```
