# Difference-Galois audit of the factorial-gauged Apéry recurrence

## 1. Normalization and determinant character

The recurrence

\[
B_{n+1}=P(n)B_n-n^6B_{n-1},\qquad P(n)=(2n+1)(17n^2+17n+5)
\]

has transfer matrix

\[
M(n)=\begin{pmatrix}P(n)&-n^6\\1&0\end{pmatrix},
\qquad \det M(n)=n^6.
\]

Let sigma be the shift operator on \(r\). A scalar gauge \(Y_n=g(n)Z_n\) changes the determinant by a coboundary. Choose \(g\) satisfying

\[
\frac{g(n+1)}{g(n)}=n^{-3}
\]

(up to a constant), giving a determinant-one system. The resulting rank-two difference module has determinant character trivial, so its difference Galois group is a subgroup of \(SL_2\), not merely \(GL_2\).

The finite computations in `factorial_gauge_orbit.py` are compatible with large finite projective images, but they do not prove the characteristic-zero group.

## 2. What must be proved for SL2

For a second-order irreducible difference module over \(\mathbb Q(r)\) with determinant one, the Hendriks/Arreche classification reduces the possibilities to:

1. reducible: a rational/algebraic Riccati solution;
2. imprimitive: dihedral/projectively reducible after a quadratic extension;
3. finite projective image;
4. special pullback/tensor cases;
5. full \(SL_2\).

The available recurrence data does not by itself constitute a complete certificate excluding cases 1--4. Therefore the unconditional conclusion is:

\[
\boxed{G\subseteq SL_2\text{ is established; }G=SL_2\text{ is not yet proved.}}
\]

## 3. Reducibility test: Riccati certificate

A Riccati solution would be a rational function \(u(r)\) satisfying

\[
u(r+1)=P(r)-\frac{r^6}{u(r)}.
\]

Equivalently there is a hypergeometric solution \(y_{n+1}=u(n)y_n\). An effective certificate is obtained by bounding poles and zeros.

If \(u=a/b\) in lowest terms, poles propagate under shifts unless canceled by zeros of \(r^6\). Since the only finite singular divisor is \(r=0\), pole propagation forces all poles into the orbit of zero, which is impossible for a nonconstant rational function. After this pole analysis one must check polynomial solutions for the numerator/denominator. This is a finite computation in Sage/Maple, but it has not been supplied here as a proof.

## 4. Imprimitive and finite projective cases

The imprimitive case would imply that after a quadratic extension the module splits into two rank-one modules exchanged by Galois. Computationally this can be tested by the symmetric square module: a dihedral subgroup has a one-dimensional invariant line in \(Sym^2(V)\).

The required certificate is:

```text
Compute Sym^2(M). Find rational invariant vector.
If none exists: imprimitive case excluded.
```

A finite projective image requires a polynomial relation of bounded degree among solutions (Schwarz list type obstruction). It is not ruled out by seeing many finite groups modulo p.

In particular:

- finite \(SL_2(\mathbb F_p)\) images are not Zariski dense statements;
- specialization groups cannot by themselves prove the generic group.

## 5. Hidden pullback/tensor reductions

The remaining exceptional cases are detected by the differential/difference invariants of the module. One computes:

- exterior square (already trivial after determinant gauge);
- symmetric square;
- adjoint module;
- possible invariant tensors.

A nonzero invariant in these modules would contradict generic \(SL_2\). No such invariant has been certified in the current data.

## 6. Exact computations needed for a proof

A publication-grade proof can be made algorithmic:

```sage
R.<r> = QQ[]
P=(2*r+1)*(17*r^2+17*r+5)
M=matrix(R,2,2,[P,-r^6,1,0])

# 1. Normalize determinant
# 2. Compute Riccati solutions using Abramov/Hendriks bounds
# 3. Compute Sym^2 invariant space
# 4. Compute projective finite candidates
# 5. Test tensor invariants
```

Maple's `DEtools`/difference-equation routines or the Arreche algorithm give the same finite list of certificates.

## 7. Consequences if SL2 is eventually certified

If the missing certificates establish

\[
G=SL_2,
\]

then outside a finite exceptional set of primes the reductions have Zariski-dense compatible monodromy. Integral strong approximation gives large reductions of the algebraic group modulo p.

However this does **not** imply that the single distinguished Apéry orbit

\[
z_r=[B_r:B_{r-1}]
\]

is equidistributed in \(\mathbb P^1(\mathbb F_p)\). Strong approximation concerns the full group orbit, not one deterministic starting vector under a nonautonomous cocycle.

Likewise it does not directly prove the HM3 cross-prime correlation estimate. That requires quantitative mixing/large-sieve input for the specific sequence, not only algebraic monodromy.

## Conclusion

The correct current theorem is:

\[
\boxed{\text{The factorial-gauged Apéry module has determinant-one Galois group }G\leq SL_2.}
\]

The assertion \(G=SL_2\) is plausible and consistent with all finite data, but a rigorous proof requires explicit exclusion certificates for Riccati solutions, dihedral reductions, finite projective image, and hidden tensor reductions. Finite specialization experiments alone cannot replace those certificates.
