# 1. Exact pair-to-gap reindexing

Write

```text
Z_p^- = {0 <= r < p/2 : p | b_r},
z_p = |Z_p^-|.
```

For `X<p<=2X`, every ordered lower pair `r<s` has `s<p/2`, hence `p>2s`. Put

```text
h = s-r >= 1.
```

The no-consecutive-zero theorem gives `h>=2`.

Let `N_h(r)` be the canonical Apéry continuant/gap polynomial. The recurrence gives, whenever `p>2(r+h)`,

```text
b_{r+h} = U_h(r) b_{r+1}  (mod p),
```

where the denominator of `U_h` is a `p`-unit and its numerator is `N_h(r)`. Since `p|b_r` and consecutive zeros are impossible, `b_{r+1}` is a unit. Therefore

```text
p | b_r and p | b_{r+h}
<=>
p | b_r and p | N_h(r),                    (1.1)
```

in the lower-orbit range relevant here.

Define the exact large-prime radical

```text
D_{r,h}(X)
 := product of primes p such that
      X < p <= 2X,
      p > 2(r+h),
      p | gcd(b_r, N_h(r)).                 (1.2)
```

Then there is no overcount and no missing multiplicity:

```text
S_2(X)
 = sum_{h>=2} sum_{r>=0, r+h<X} log D_{r,h}(X).       (1.3)
```

Indeed a prime in `D_{r,h}` gives by (1.1) the unique lower pair `(r,r+h)`, and every lower pair contributes to exactly one `(r,h)`.

This is the useful reindexing. It converts the problem from a vertical zero-count moment into a horizontal average of **actual Apéry gcd radicals**.

# 2. Fixed gaps are easy; growing gaps are the entire problem

For fixed `h`, the gap polynomial has

```text
deg N_h = 3(h-1)
```

and is nonzero modulo every relevant prime. Hence, for each `p`,

```text
A_p(h)
 := #{r : 0<=r<r+h<p/2, p|b_r, p|b_{r+h}}
 <= #{r mod p : N_h(r)=0}
 <= 3(h-1).                                  (2.1)
```

Consequently

```text
S_h(X)
 := sum_{X<p<=2X} A_p(h) log p
 << h X.                                      (2.2)
```

Thus any **fixed finite set of gaps** contributes `O(X)`. In particular `h=1` contributes zero, and `h=2` is controlled by the explicit cubic

```text
N_2(r) = P(r+1)
       = (2r+3)(17r^2+51r+39).
```

But summing (2.2) through `h<=H` gives

```text
sum_{h<=H} S_h(X) << X H^2.                  (2.3)
```

So the fixed-gap polynomial theorem has the wrong summation exponent by two powers of the gap cutoff.

Even an unrealistically strong “average one root per prime per gap” theorem would only give

```text
S_h(X) << X,
sum_{H<h<=2H} S_h(X) << X H,                 (2.4)
```

which still does not sum to `O(X)`. Therefore a polynomial/root large sieve for `N_h` **alone** is structurally insufficient. The distinguished condition `p|b_r` has to be used, not discarded.

# 4. Why reflection / “two borders” do not create a second fixed-gap equation

A lower pair `r<s=r+h<p/2` reflects to

```text
p-1-s < p-1-r,
```

another zero pair of the same gap `h`. It is tempting to use the lower and upper gap equations as two independent polynomial conditions. They are not independent.

The current gap-polynomial reflection identity is

```text
N_h(-x-h-1) = (-1)^(h-1) N_h(x).              (4.1)
```

The reflected start is

```text
p-1-s = p-1-r-h == -1-r-h (mod p),
```

so the upper gap equation is exactly (4.1) applied to the lower one. A resultant formed from these two “border equations” is therefore tautological; it contains no new codimension.

The four zeros can be written

```text
r, s, p-1-s, p-1-r
```

with gap word

```text
(h, g, h),
where g = p-1-2s.                              (4.2)
```

The middle pair gives `p|N_g(s)`, but now `g` moves with `p` and can be of order `X`. This is not a second fixed-degree polynomial in the fixed-gap family. In fact it is simply the reflection consequence of the distinguished zero `p|b_s` expressed through a moving-length transfer. This is exactly where a two-border M1 certificate fails to square automatically into a pair-mass certificate.

So the first genuinely new arithmetic would have to couple the two distinguished lower zeros, not merely duplicate the reflection border.

# 5. Resultants and cross-gap identities: exact mismatch

The existing fixed-gap/resultant machinery is powerful when **two different gap polynomials vanish at the same start**. But a two-zero pair gives only one gap polynomial:

```text
b_r=b_{r+h}=0  =>  N_h(r)=0.
```

A second gap polynomial at the same distinguished start requires a third zero. Thus cross-gap resultants naturally measure triple-zero / higher factorial information, not the second factorial moment requested here.

This is also why the scalar resultant route in `gcdtail_result.tex` does not repair the problem:

1. scalar resultants forget which root/component realizes the common divisibility;
2. the existing primitive examples show that common prime divisors of scalar resultants need not correspond to the same affine root;
3. for the present pair problem there is no second independent fixed-gap polynomial before a third zero is introduced.

Hence multiplying or gcd'ing the known `Res(N_h,N_k)` certificates cannot prove (1.3) at pair level. It starts one factorial moment too late.

# 6. Average-gcd attack: exact bound and where the height explodes

From (1.2), trivially

```text
log D_{r,h}(X)
 <= log rad_{>X} gcd(b_r,N_h(r))
 <= min(log|b_r|, log|N_h(r)|).                (6.1)
```

The Apéry growth gives `log|b_r|=O(r)`. The continuant recurrence gives, uniformly for `r+h<X`,

```text
log|N_h(r)| << h log X + O(h),                 (6.2)
```

because one performs `h` transfer steps with polynomial coefficients of size `X^{O(1)}`.

Using (6.2) for a fixed gap gives only

```text
sum_{r<X} log D_{r,h}(X) << X h log X,         (6.3)
```

and summing growing gaps is much worse than the root bound (2.2). The generic integer-gcd estimate therefore loses immediately.

What would be useful is not a pointwise gcd bound but a **large-prime average gcd theorem** with decay in the gap scale, for example

```text
sum_{H<h<=2H}
sum_{r+h<X}
 log rad_{X<p<=2X, p>2(r+h)} gcd(b_r,N_h(r))
 << X H^{-delta}                               (6.4)
```

for some fixed `delta>0`. That would be a true recurrence-specific advance. No generic gcd theorem for unrelated integers has the strength of (6.4); the distinguished Apéry recurrence has to enter.

# 7. Multirow Fitting certificate: why rank defect is too cheap

There is a precise linear-versus-quadratic obstruction to the suggested multirow Fitting approach.

For lower zero indices `r_1,...,r_z`, consider the Apéry state rows

```text
v_i = (b_{r_i}, b_{r_i+1}).
```

Modulo a prime that kills all `b_{r_i}`, no-consecutive-zeros makes the second coordinate a unit, and every row lies on the same one-dimensional line:

```text
v_i == (0, *) (mod p).                          (7.1)
```

Thus all `2x2` minors are divisible by `p`. But the Smith/Fitting invariant of the entire `z x 2` matrix only sees a rank drop from `2` to `1`: it forces **one** nontrivial Smith factor, independently of the number `binom(z,2)` of zero pairs.

In other words, a compressed Fitting presentation naturally records valuation on the scale

```text
O(z), or even O(1) for a fixed-width state matrix,
```

whereas the desired pair mass is

```text
binom(z,2) ~ z^2/2.                              (7.2)
```

To force one factor of `p` for every pair, one can of course form the direct sum/exterior list of all pair minors. But then the presentation has `Theta(z^2)` pair coordinates and its Archimedean height is the sum of the pair heights: the supposed compression has disappeared. This is the same saturation phenomenon seen in the current Fitting/resultant audits, now stated directly for the lower-orbit pair statistic.

So a fixed-width multirow Smith matrix cannot by itself prove the requested second factorial moment. It needs an additional theorem saying that one unit of rank defect represents many pair incidences only rarely/with controlled aggregate weight. That is again a distribution theorem, not formal Smith algebra.

# 8. Sharp reduction: the dyadic distinguished average-gcd tail

For dyadic `H`, set

```text
T_H(X)
 := sum_{H<h<=2H}
    sum_{r>=0, r+h<X}
       log D_{r,h}(X),                           (8.1)
```

with `D_{r,h}(X)` from (1.2). Then exactly

```text
S_2(X) = sum_{H dyadic, H<X} T_H(X) + O(X),     (8.2)
```

where the harmless `O(X)` absorbs the finite initial gaps/endpoints.

Therefore the following is a sufficient recurrence-specific theorem.

## DAGT(delta): distinguished average-gcd tail

There exists `delta>0` such that, uniformly for `2<=H<=X`,

```text
T_H(X) << X H^{-delta}.                         (DAGT_delta)
```

Then

```text
S_2(X)
 << X sum_{H dyadic} H^{-delta}
 = O(X).                                         (8.3)
```

One does not literally need a power saving. The exact minimal shape is

```text
T_H(X) << X omega(H),
sum_{H dyadic} omega(H) = O(1).                 (8.4)
```

This is, in my view, the right next theorem to attack. It is strictly sharper than “vertical M2”: it identifies the actual integers, the actual gap variable, the actual prime window, and the exact summability gain required.

# 10. What would constitute a real proof advance

I would rank the next attacks as follows.

1. **Prime-first average gcd / large sieve on the distinguished orbit.** Prove (8.4) directly. The useful input must be a correlation estimate for the actual Apéry orbit, not merely a root count for `N_h`.

2. **A cross-gap transfer identity of bounded complexity.** If the family `N_h(r)` admitted an Apéry-specific low-order relation in `h` whose primitive minors stayed small after saturation, one could large-sieve the pair `(b_r,N_h(r))` without paying `H` independent polynomials. Existing fixed-gap/resultant data do not yet give such a relation with a summable height.

3. **A Fitting certificate with multiplicity amplification.** A useful theorem would have to prove that a prime producing `z` collinear zero-state rows forces valuation `Omega(binomial(z,2))` in a *small-height* invariant. Plain determinantal divisors only give linear/fixed rank defect, so this needs extra Apéry arithmetic.

4. **Average large-prime gcd theorem.** Even the weaker dyadic statement

```text
T_H(X) << X / (log H)^(1+epsilon)
```

would be summable on an exponential/dyadic scale only with sufficient care; a power `H^{-delta}` is the clean target.
