# Short-difference energy of interval-sparse color classes

## 0. Verdict

The abstract hypotheses do not imply the proposed same-lag L2 bound.

In fact, there is an explicit infinite family of examples with one nontrivial
color class A and all remaining colors singletons such that

```text
A subset [0,N],
#(A intersect W) <= 4 |W|^(2/3) for every interval W,
sum_v |A_v| = N,
sum_v |A_v|^2 = O(N^(4/3)) <= O(N^(3/2)),
R_h := sum_v r_(A_v)(h) <= 3(h-1) for every h>=1,
```

but, at

```text
D = sqrt(N) L,
```

one has, for `1 <= L <= c N^(1/6)`,

```text
sum_v sum_(1<=h<=D) r_(A_v)(h)^2
  >= c D N^(2/3)
  = c N^(7/6) L.
```

Thus the desired `O(N)` estimate fails by the factor

```text
N^(1/6) L,
```

even when `L=1`.

Since the construction has only one non-singleton color,

```text
sum_v r_(A_v)(h)^2 = R_h^2
```

for every h. It therefore also disproves the stronger-looking abstract claim

```text
sum_(h<=D) R_h^2 << N.
```

The current project head inspected for this answer is
`b0a8f6f266d431123d55f299310480ac41dee67a`. That ledger already records the
qualitative verdict that `[SAME-LAG-L2]` is arithmetic rather than a consequence
of the window and energy constraints. The construction below sharpens that
verdict to a fully explicit counterexample satisfying all constraints in the
question.

The exact extremal order under all stated constraints is not determined here.
What is determined rigorously is enough for the wall decision:

```text
c D N^(2/3)
  <= maximum
  <= min(C E_0 D^(2/3), 3D^3),
```

along the displayed infinite sequence of N, and the lower bound is already
much larger than N at the hatch scale.

## 1. Conventions

All sets lie in the integer interval

```text
[0,N] = {0,1,...,N}.
```

For an integer interval W, `|W|` denotes its number of integer positions. The
same arguments work, with harmless constant changes, if `|W|` denotes diameter
plus one.

For `A subset [0,N]`, put

```text
m = |A|,
r_A(h) = #{a : a in A and a+h in A},
Q_A(D) = sum_(1<=h<=D) r_A(h).
```

Thus `Q_A(D)` is the number of unordered pairs of distinct points of A whose
positive difference is at most D.

---

## 2. What window sparsity gives for one set

Assume throughout this section that

```text
|A intersect W| <= 4 |W|^(2/3)                 (WS)
```

for every interval W.

### 2.1 Total number of short pairs

For every `D>=1`,

```text
Q_A(D) <= 4m D^(2/3).                           (2.1)
```

Proof. Fix `a in A`. Every b counted with

```text
a < b <= a+D
```

lies in the interval `[a+1,a+D]`, which has at most `4D^(2/3)` points of A.
Sum over the lower endpoint a. Every positive-difference pair is counted once.

This is the clean first-moment consequence of window sparsity.

### 2.2 A pointwise bound for one lag

For every `1<=h<=N`,

```text
r_A(h)
  <= min(m, 4((N+1)/h+2)h^(2/3))
  << min(m, N h^(-1/3)+h^(2/3)).                (2.2)
```

Proof. Partition the possible lower endpoints into consecutive blocks of h
integer positions. A pair `(a,a+h)` starting in one block requires `a in A` in
that block, so the number of such starts is at most `4h^(2/3)`. There are at
most `(N+1)/h+2` blocks. The bound `r_A(h)<=m` is trivial.

This is the best direct global pointwise estimate supplied by (WS). In
particular, (WS) does not give `r_A(h)=O(h^2)` globally.

### 2.3 What the chain argument really proves

The graph with vertex set A and edges

```text
x -> x+h
```

decomposes into chains inside residue classes modulo h. If one chain has k
vertices, then those vertices lie in an interval of length at most

```text
(k-1)h+1.
```

Therefore (WS) gives

```text
k <= 4((k-1)h+1)^(2/3)
  <= 4(kh)^(2/3),
```

hence

```text
k <= 64 h^2.                                   (2.3)
```

This controls the length of one chain. It does not control the number of
chains. There can be many widely separated two-point chains, so no global
bound `r_A(h)<<h^2` follows.

This distinction is important: the proposed local-interval argument controls
one connected h-progression, not the total number of h-pairs.

### 2.4 The elementary L2 bounds

Since `r_A(h)<=m`, equation (2.1) gives

```text
sum_(h<=D) r_A(h)^2
  <= m Q_A(D)
  <= 4m^2 D^(2/3).                              (2.4)
```

A second bound follows by combining (2.2) with (2.1) on dyadic h-blocks:

```text
sum_(h<=D) r_A(h)^2
  << min(m^2 D^(2/3), m N D^(1/3)).             (2.5)
```

Indeed, on `H<h<=2H`,

```text
max r_A(h) << min(m,NH^(-1/3)),
sum_(H<h<=2H) r_A(h) <= Q_A(2H) << mH^(2/3),
```

so

```text
sum_(H<h<=2H) r_A(h)^2
  << min(m^2 H^(2/3),mN H^(1/3)).
```

Summing geometrically over dyadic H gives (2.5).

For the hatch range `D=sqrt(N)L` and the largest window-sparse size
`m=O(N^(2/3))`, the first term in (2.5) is normally the smaller one. It is still
far too large to imply `O(N)`.

### 2.5 Sharpness of the exponent in (2.4)

The exponent in (2.4) cannot be improved using only (WS).

Let s be large and take the arithmetic progression

```text
A = {0,s,2s,...,(k-1)s},
k = floor(s^2).
```

Every interval containing q points of A has length at least `(q-1)s+1`; for
`2<=q<=k<=s^2`,

```text
q^3 <= 4q^2s^2 <= 16(q-1)^2s^2,
```

so, in particular,

```text
q <= 4((q-1)s+1)^(2/3).
```

Thus A satisfies (WS).

If

```text
D >= (k-1)s asymp s^3,
```

then

```text
sum_(h<=D) r_A(h)^2
  = sum_(j=1)^(k-1) (k-j)^2
  asymp k^3
  asymp s^6
  asymp D^2.
```

On the other hand,

```text
m^2D^(2/3) asymp s^4 s^2 = s^6.
```

Thus (2.4) has the correct exponents for window-sparse sets.

## 3. Arithmetic progressions under the global degree bound

Suppose

```text
A = {x,x+s,...,x+(k-1)s}.
```

An interval containing all k points has length at most ks, so (WS) necessarily
gives

```text
k <= 4(ks)^(2/3),
```

and hence

```text
k <= 64s^2.                                    (3.1)
```

This is only a necessary bound. A convenient sufficient condition is
`k<=16s^2`; the examples below use the much smaller range `k<=s`.

For

```text
q = min(k-1,floor(D/s)),
```

one has the exact formula

```text
sum_(h<=D) r_A(h)^2
  = sum_(j=1)^q (k-j)^2.                       (3.2)
```

Consequently

```text
sum_(h<=D) r_A(h)^2
  asymp k^2 min(k,D/s)                         (3.3)
```

away from harmless endpoint constants.

Now add the global difference constraint. At the first AP lag,

```text
r_A(s)=k-1 <= R_s <= 3(s-1),
```

so

```text
k <= 3s-2.                                     (3.4)
```

Thus the global degree bound reduces the allowed AP length from quadratic in s
to linear in s. It does not remove the obstruction.

For example, let

```text
s = k = floor(sqrt(N))/2
```

and place the AP inside `[0,N]`. It is window-sparse, satisfies
`r_A(js)=k-j<=3(js-1)`, and at `D=sqrt(N)L`, while `1<=L<=k/4`, equation (3.2)
gives

```text
sum_(h<=D) r_A(h)^2
  >= c L k^2
  >= c N L.                                    (3.5)
```

After adding singleton colors, this already disproves `O(N)` whenever L tends
to infinity.

However, APs are not the worst obstruction. The next construction gives a
polynomial failure even at `L=1`.

## 4. The strong explicit counterexample

### 4.1 Parameters

Let q be an odd prime and put

```text
N = 4q^3.
```

For an integer i, let

```text
rho(i) = the representative in {0,...,q-1} of (i mod q)^2 mod q.
```

Define

```text
A = {a_i : 0<=i<q^2},
a_i = 4qi + rho(i).                             (4.1)
```

Since

```text
0 <= rho(i) <= q-1,
```

one has

```text
0 <= a_i < 4q^3=N.
```

Also

```text
|A|=q^2 asymp N^(2/3).                         (4.2)
```

This is a block graph of the quadratic map over `F_q`: one point in each block
of length `4q`.

### 4.2 Window sparsity

Every block

```text
[4qi,4q(i+1)-1]
```

contains exactly one point of A. Hence an interval W of length w contains at
most

```text
w/(4q)+2                                             (4.3)
```

points of A.

If `w<4q`, this is at most 2, and

```text
2 <= 4w^(2/3).
```

If `4q<=w<=N+1`, then `w^(1/3)<=4q`, so

```text
w/(4q) <= w^(2/3),
2 <= 2w^(2/3).
```

Therefore

```text
|A intersect W| <= 3w^(2/3) <= 4w^(2/3).       (4.4)
```

Thus A satisfies the required window theorem with room to spare.

### 4.3 Exact difference decomposition

For `j>i`, put `d=j-i`. Then

```text
a_j-a_i = 4qd + rho(i+d)-rho(i).                (4.5)
```

The second term lies in `[-(q-1),q-1]`. Therefore every difference arising from
index gap d lies in

```text
J_d = [4qd-(q-1), 4qd+(q-1)].                   (4.6)
```

The intervals `J_d` are pairwise disjoint, because consecutive centers are
separated by `4q` while each interval has radius `q-1`.

Thus a numerical lag h determines at most one index gap d.

### 4.4 Difference multiplicities

Fix d and h in `J_d`, and write

```text
h=4qd+t,
|t|<=q-1.
```

We must count i such that

```text
rho(i+d)-rho(i)=t.                              (4.7)
```

If `q` does not divide d, reducing (4.7) modulo q gives

```text
2d(i mod q)+d^2 = t mod q.                      (4.8)
```

Since q is odd and `d!=0 mod q`, equation (4.8) has exactly one solution for
`i mod q`. Among `0<=i<q^2-d`, a fixed residue class occurs at most q times.
Hence

```text
r_A(h) <= q,             if q does not divide d.   (4.9)
```

If `q` divides d, then `rho(i+d)=rho(i)` for every i. Thus the only possible
lag in `J_d` is

```text
h=4qd,
```

and

```text
r_A(4qd)=q^2-d <= q^2.                           (4.10)
```

These two formulas give the required global degree bound.

If `d<q`, then by (4.6)

```text
h >= 4q-(q-1)=3q+1,
```

and (4.9) gives

```text
r_A(h) <= q <= (h-1)/3 <= 3(h-1).               (4.11)
```

If `d>=q`, then

```text
h >= 4q^2-(q-1) > 3q^2,
```

while (4.9)-(4.10) give `r_A(h)<=q^2`. Hence again

```text
r_A(h) <= 3(h-1).                               (4.12)
```

Also `r_A(1)=0`. Therefore

```text
r_A(h) <= 3(h-1) for every h>=1.                (4.13)
```

This is exactly the global constraint required in the question.

### 4.5 Many short lags with multiplicity q

Let

```text
D = floor(sqrt(N)L)=floor(2q^(3/2)L),
1 <= L <= q^(1/2),
H = floor((D-(q-1))/(4q)).                       (4.14)
```

For q sufficiently large,

```text
H >= D/(8q),
H<q.                                             (4.15)
```

Fix `1<=d<=H`. For every residue `r in {0,...,q-1}`, define

```text
t_(d,r)=rho(r+d)-rho(r),
h_(d,r)=4qd+t_(d,r).                             (4.16)
```

By the definition of H,

```text
1 <= h_(d,r) <= D.                              (4.17)
```

The q integers `t_(d,r)` are distinct. Indeed, equality of two of them implies
equality modulo q, and by (4.8) the map

```text
r -> 2dr+d^2 mod q
```

is bijective.

For every i with `i mod q=r`, periodicity of rho gives the exact equality

```text
rho(i+d)-rho(i)=t_(d,r).
```

Since `d<q`, each residue class occurs at least `q-1` times among
`0<=i<q^2-d`. Therefore

```text
r_A(h_(d,r)) >= q-1.                            (4.18)
```

The lags in (4.16) are all distinct: they are distinct for fixed d by the
previous paragraph, and different d lie in disjoint intervals `J_d`.

There are Hq such lags. Consequently

```text
sum_(h<=D) r_A(h)^2
  >= H q (q-1)^2
  >= c D q^2.                                   (4.19)
```

Since

```text
q^2=(N/4)^(2/3),
```

we obtain

```text
sum_(h<=D) r_A(h)^2
  >= c D N^(2/3)
  = c N^(7/6)L.                                 (4.20)
```

This is the promised polynomial counterexample.

## 5. Converting the single set into the required family

Take

```text
A_0=A.
```

Choose `N-q^2` distinct unused points of `[0,N]`, and put each one into its own
singleton color class. Call the resulting disjoint family `{A_v}`.

Then

```text
sum_v |A_v|
  = q^2+(N-q^2)
  = N.                                           (5.1)
```

Every singleton is window-sparse and contributes no positive difference.
Therefore

```text
R_h=sum_v r_(A_v)(h)=r_A(h)<=3(h-1).             (5.2)
```

The color energy is

```text
sum_v |A_v|^2
  = q^4+(N-q^2)
  = O(N^(4/3))
  = O(N^(3/2)).                                  (5.3)
```

Finally, only A_0 contributes to the short-difference square energy, so

```text
sum_v sum_(h<=D) r_(A_v)(h)^2
  = sum_(h<=D) r_A(h)^2
  >= c N^(7/6)L.                                 (5.4)
```

Moreover, because there is only one nontrivial color,

```text
sum_v r_(A_v)(h)^2=R_h^2.                       (5.5)
```

Thus the same example violates both the colorwise and aggregated versions of
`[SAME-LAG-L2]`.

## 6. General upper bounds for a family

Let

```text
m_v=|A_v|,
E_0=sum_v m_v^2.
```

Applying (2.1) color by color gives

```text
sum_(h<=D) r_(A_v)(h) <= 4m_vD^(2/3).
```

Since `r_(A_v)(h)<=m_v`,

```text
sum_v sum_(h<=D) r_(A_v)(h)^2
  <= 4D^(2/3) sum_v m_v^2
  = 4E_0D^(2/3).                                (6.1)
```

Independently, nonnegativity gives

```text
sum_v r_(A_v)(h)^2
  <= (sum_v r_(A_v)(h))^2
  = R_h^2.
```

Using `R_h<=3(h-1)`,

```text
sum_v sum_(h<=D) r_(A_v)(h)^2
  <= 9 sum_(h<=D)(h-1)^2
  <= 3D^3.                                       (6.2)
```

Therefore the universal abstract upper bound is

```text
sum_v sum_(h<=D) r_(A_v)(h)^2
  <= min(4E_0D^(2/3),3D^3).                     (6.3)
```

At

```text
E_0=O(N^(3/2)),
D=sqrt(N)L,
```

this is

```text
O(min(N^(11/6)L^(2/3), N^(3/2)L^3)).            (6.4)
```

Neither term is close to O(N). The example in Section 4 gives the rigorous
lower bound

```text
Omega(N^(7/6)L).                                (6.5)
```

Thus, under the listed constraints alone, the extremal value lies in the range

```text
c N^(7/6)L
  <= maximum
  <= C min(N^(11/6)L^(2/3),N^(3/2)L^3)          (6.6)
```

along `N=4q^3` and `1<=L<=cN^(1/6)`.

I do not claim that either endpoint in (6.6) is the exact maximum. Determining
the sharp extremal order is a separate additive-combinatorial problem. The
wall decision does not require that optimization: the lower bound already
rules out every O(N) consequence of the stated hypotheses.

## 7. Interpretation for `[SAME-LAG-L2]`

The construction explains exactly why window sparsity is nearly orthogonal to
lag concentration.

In (4.1), the set has only one point in each long block, so every physical
window is sparse. But the quadratic residue graph has highly repeated discrete
derivatives:

```text
rho(i+d)-rho(i).
```

For each short index gap d, every derivative value is repeated about q times.
Thus the set is spatially sparse but has a large same-lag second moment.

The three abstract controls measure different objects:

```text
window sparsity:   spatial concentration inside one color;
color energy:      sizes of the color classes;
R_h<=3(h-1):       first moment at one lag.
```

None controls the square of the derivative multiplicity profile. The missing
statement must be an arithmetic anti-concentration theorem for the actual
Apery return differences.

A suitable arithmetic input would have to rule out the quadratic-block
mechanism, for example by proving one of the following genuinely new facts:

```text
max_(h<=D) R_h << sqrt(N)/L^c,

sum_(h<=D) R_h^2 << N,

or a Barban-Davenport-Halberstam type variance estimate for the root counts
of the translated gap polynomials N_h(r).
```

The empirical campaign fact that `max R_h` remains about 8 is exactly this
kind of arithmetic information. It is vastly stronger than the formal degree
bound `R_h<=3h` near `h=D`.

Therefore:

```text
[SAME-LAG-L2] is not abstract additive combinatorics under the banked window
and energy hypotheses. It is an Apery-specific arithmetic theorem.
```

## 8. Answers to the requested sub-questions

### (1) Single set

The rigorous elementary bounds are

```text
r_A(h)
  << min(|A|,N h^(-1/3)+h^(2/3)),

sum_(h<=D) r_A(h)
  <= 4|A|D^(2/3),

sum_(h<=D) r_A(h)^2
  << min(|A|^2D^(2/3), |A|N D^(1/3)).
```

A single h-chain has at most `64h^2` vertices, but there may be many chains, so
this is not a global pointwise bound.

The exponent `|A|^2D^(2/3)` is sharp under window sparsity alone, as shown by
the AP construction in Section 2.5.

### (2) AP-heavy extremals

For an AP of length k and step s,

```text
k<=64s^2
```

is necessary from window sparsity, and

```text
sum_(h<=D)r_A(h)^2
  = sum_(j<=min(k-1,D/s))(k-j)^2
  asymp k^2 min(k,D/s).
```

The global condition `R_s<=3(s-1)` strengthens this to `k<=3s-2`.
Nevertheless, choosing `k asymp s asymp sqrt(N)` gives `Omega(NL)` at
`D=sqrt(N)L`.

The stronger quadratic-block example shows that APs are not the actual worst
mechanism: repeated discrete derivatives can create
`Omega(N^(7/6)L)` while preserving all constraints.

### (3) Family with energy and degree constraints

The estimate

```text
sum_v sum_(h<=D) r_(A_v)(h)^2 << N
```

is false. Sections 4-5 give an explicit family satisfying every listed
constraint with

```text
sum_v sum_(h<=D) r_(A_v)(h)^2
  >= cN^(7/6)L.
```

Because only one color is nontrivial, the example also has

```text
sum_(h<=D)R_h^2
  = sum_v sum_(h<=D)r_(A_v)(h)^2.
```

No cross-color sharing is needed.

## 9. Least-confident step and blind spot

### (a) Least-confident step

The least-confident point is the exact asymptotic maximum in (6.6). The
counterexample and every verification of the stated constraints are exact, but
there remains a large gap between the lower bound

```text
Omega(DN^(2/3))
```

and the general upper bounds

```text
O(min(E_0D^(2/3),D^3)).
```

I would not label the quadratic-block construction extremal without a new
inverse theorem for high short-difference energy in Frostman-sparse sets.

### (b) Blind spot

The blind spot would be an additional Apery-specific constraint not included
in the abstract problem: reflection, renewal, adjacent coprimality, or algebraic
relations among the root sets could forbid the quadratic derivative pattern.
That is precisely the point. Such a prohibition would be new arithmetic input,
not a consequence of window sparsity, total mass, color energy, or the bound
`R_h<=3(h-1)`.
