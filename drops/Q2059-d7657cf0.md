
This is the first decisive point: the new coordinate is not another marked zero.  It is a unit coordinate attached to the old zero coordinate.


## 8. Primitive Smith normalization: why the exponent does not improve

Work locally at a marked prime `p` over `Z_p`.  Let `M_p^(0)` be a primitive Q2055 presentation matrix for the B,D star/Smith carrier.  In the Q2055 saturation model write its Smith exponents as

```text
a_1 <= a_2 <= ... <= a_s,

a_s = lambda-1.
```

Now adjoin the predecessor state.

The facts proved above have two consequences.

First, every actual one-step transfer coefficient and the q=1 scalar `5` are p-units.  Hence all coordinate changes needed to pass between

```text
(b_r,b_(r-1)),
(b_(r+1),b_r),
(b_m,b_(m-1)) mod p
```

are unimodular for Smith purposes.  They contribute no p-power content.

Second, after those unit coordinate changes, the only new torsion relation is the predecessor Lucas error

```text
E_p = p^e * unit,     e >= 1.
```

Thus a compatible primitive local presentation is Smith-equivalent to

```text
M_p^(aug) ~ diag(M_p^(0), p^e).
```

The universal local-transfer axioms only force `e>=1`.  Therefore the strongest universally forced top Smith exponent is

```text
s_max(M_p^(aug))
  >= max(lambda-1,1),
```

and a first-order compatible model has equality

```text
e = 1,

s_max(M_p^(aug)) = max(lambda-1,1).
```

For the only regime relevant to a multi-mark height saving, `lambda>=2`,

```text
s_max(M_p^(aug)) = lambda-1.
```

This is the precise Smith no-go.  The new `[p]` elementary divisor is a **separate summand**; it does not concatenate with the old `p^(lambda-1)` elementary divisor to form `p^lambda` in one invariant factor.

Equivalently:

```text
v_p(det M_p^(aug))
  = v_p(det M_p^(0)) + 1
```

in the first-order model, but

```text
v_p(largest Smith invariant of M_p^(aug))
  = lambda-1.
```

The determinant sum of exponents went up because the rank went up.  The largest Smith exponent, which is the invariant that could have produced a strict Q2055 height saving without paying a new degree, did not.

For `lambda=1`, the old exponent is zero and the predecessor supplies a single `[p]`; that isolated case is real but irrelevant to the many-mark asymptotic mechanism.

## 9. Explicit compatible saturation construction

For each marked prime choose an arbitrary p-adic unit `t_p` and set



Choose the current local zero coordinate `x_p` divisible by `p`. This is always possible because `C` and `u_p` are units.

The denominator is a p-unit and the second term is a unit modulo `p`, so this gives a valid adjacent-transfer state.  The construction satisfies:

No relation between different marked primes has been imposed beyond the already-existing B,D data.  This is exactly what “local-transfer extension” means.

### 9.3 Smith form of the extension


If Q2055 is saturated at exponent `lambda-1`, so is the augmented largest invariant:

At the raw determinant level the new relation contributes exactly one more factor:

whenever the old star and the new predecessor error are both first order.  This is **saturation of all forced divisibility**, not a strict improvement: exponent and presentation degree rise in lockstep.


Theorem B is a no-go theorem about the **information content of the proposed extension**.  It is not a claim that the actual Apéry sequence can be freely chosen prime by prime.

## 12. Why the tempting `R^lambda` statement does not save height

It is worth isolating the exact trap, because otherwise the raw product in section 7 can look like an `EXTRA_FACTOR` result.

The old Q2055 Smith mechanism was designed precisely to avoid confusing determinant valuation with a useful invariant factor.  If a primitive rank-`s` presentation has Smith exponents

```text
a_1 <= ... <= a_s,
```

then

```text
v_p(det) = a_1+...+a_s,
```

whereas the strongest single cyclic divisibility is controlled by

```text
a_s.
```

Adjoining one new first-order relation changes

```text
(a_1,...,a_s)
```

to

```text
(a_1,...,a_s,1)
```

up to sorting.  Hence the determinant exponent goes up by one, but for `a_s=lambda-1>=1` the largest exponent does not move.

In height language, the same phenomenon is visible without Smith terminology.  The scalar carrier

```text
product_p J_p
```

has been multiplied by

```text
product_p E_p.
```

The latter is a genuinely new product of `lambda` predecessor errors.  The extra factor `R` is paid for by `lambda` new algebraic factors.  There is no exponent surplus relative to the new carrier's degree/height.

Therefore the statement

```text
R^lambda | product_p(J_p E_p)
```

is exact and useful as an audit identity, but it is **not** the missing strict-height inequality.  Treating it as such would repeat exactly the determinant-versus-largest-Smith error that Q2055's primitive normalization was meant to prevent.

## 13. What information would actually be new enough to escape the no-go?

The local predecessor coordinate has now been exhausted.  To improve the largest Smith exponent, one needs an input that prevents the new `[p]` relation from splitting off as an independent cyclic summand.

Concretely, one would need a cross-prime or cross-residue relation tying the first-order predecessor errors

```text
E_p/p
```

for distinct marked primes, or tying them back into the same old Q2055 cyclic factor.  Examples of genuinely stronger information would be an exact relation among two different transfer blocks `r_p` and `r_q`, a nontrivial p-adic second-digit law forcing `v_p(E_p)>=2` on all retained marks, or a low-height global minor in which the predecessor relation merges with the old `p^(lambda-1)` Smith factor without adding rank.

None of those is contained in the single-prime adjacent transfer state.  The recurrence at `r`, the q=1 Lucas law, and the unit determinant of `T_r` are all compatible with the split first-order model above.
