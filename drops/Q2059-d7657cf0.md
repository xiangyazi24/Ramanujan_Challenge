## Executive verdict

The adjacent state does **not** produce a free extra marked-prime Smith exponent beyond the Q2055 value `lambda-1`.

There is a useful distinction between raw divisibility and primitive Smith divisibility.

For a simple marked prime `p`, the predecessor supplies a new Lucas error

```text
L_p = b_(m-1) - 5 b_(m-p-1),
```

and exactly

```text
p | L_p.
```

Thus, if `J_p` is the Q2055 oriented star with `p^(lambda-1) | J_p`, the raw product has

```text
p^lambda | J_p L_p,
```

and consequently

```text
R^lambda | lcm_{p in P} |J_p L_p|.
```

That extra copy of `p` is not a height-saving gain. It is the first elementary divisor of a newly adjoined cyclic relation. The actual common predecessor `b_(m-1)` is a unit at every marked prime, the one-step Apéry transfer is `p`-unimodular, and the primitive two-coordinate state matrix has **no marked Smith torsion at all**. After adjoining the predecessor relation, the largest forced local Smith exponent is therefore

```text
max(lambda-1, 1) = lambda-1            (lambda >= 2).
```

A fully explicit marked-active B8 local-transfer model attains this bound simultaneously: its old Q2055 star exponent is exactly `lambda-1`, its predecessor Lucas error has exactly one copy of its own marked prime, its state minors are marked-prime units, and both adjacent recurrences hold exactly. Hence no theorem using only this local-transfer extension can force a larger primitive marked exponent.

So the correct answer is the second alternative: the extension **saturates**.

## 2. Exact marked set, q=1 indexing, and gap-one convention

Fix a surviving B8 row

```text
N < m <= 2N.
```

On its top-squarefree marked sector write

```text
P = { p prime : N < p < m, p | b_m, v_p(b_m)=1 },
lambda = |P|,
R = product_{p in P} p,
B = b_m,
C = b_(m-1).
```

The strict inequality `p<m` is automatic even if one starts with `p<=m`, because `b_p==5 (mod p)` for `p>=7`.

For `p in P`, put

```text
r_p = m-p.
```

Since `p>N` and `m<=2N`, this is the q=1 cell:

```text
m = p+r_p,
1 <= r_p < p.
```

The upper endpoint `r_p=p-1` is also impossible. From the binomial formula for `b_(p-1)`, every term with `k>=1` contains

```text
binom(p-1+k,k) == 0             (mod p),
```

so

```text
b_(p-1) == 1                    (mod p).
```

The q=1 Lucas law would then give

```text
b_(2p-1) == b_1 b_(p-1) == 5   (mod p),
```

contrary to markedness. Hence the exact nonwrapping range is

```text
1 <= r_p <= p-2.
```

This is the gap-one convention used below: the adjacent state is exactly the predecessor row `m-1`, with no centered or shifted reindexing.

The q=1 Lucas congruences are therefore

```text
B = b_m       == 5 b_(r_p)       (mod p),
C = b_(m-1)   == 5 b_(r_p-1)     (mod p).
```

## 3. Actual Apéry theorem: the predecessor is a simultaneous marked unit

### Theorem 3.1

For every actual top marked prime `p in P`,

```text
p does not divide C = b_(m-1).
```

Equivalently,

```text
gcd(C,R) = 1.
```

Because the sector is squarefree,

```text
(v_p(B), v_p(C)) = (1,0)         for every p in P.
```

### Proof

Markedness and q=1 Lucas give

```text
p | b_(r_p).
```

If also `p|C`, the predecessor Lucas congruence gives

```text
p | b_(r_p-1).
```

Thus there would be two consecutive zeros below `p`.

If `r_p=1`, this already says `p|b_0=1`, impossible. If `r_p>=2`, apply the recurrence at `n=r_p-1`:

```text
r_p^3 b_(r_p)
  = P(r_p-1) b_(r_p-1)
    - (r_p-1)^3 b_(r_p-2).
```

Both `r_p` and `r_p-1` are `p`-units. Two consecutive zeros force

```text
p | b_(r_p-2).
```

Backward descent reaches `p|b_0=1`, contradiction. QED.

This is the first key obstruction to an extra Smith factor: the newly adjoined actual coordinate is a marked-prime **unit**, not a second zero.

## 4. Exact adjacent transfer is marked-prime unimodular

With the state convention

```text
y_n = (b_n, b_(n-1))^T,
```

the recurrence gives

```text
             [ P(n)/(n+1)^3    -n^3/(n+1)^3 ]
T_n =        [       1                 0       ],

y_(n+1) = T_n y_n,

det(T_n) = n^3/(n+1)^3.
```

For `p in P`, the exact range `1<=r_p<=p-2` gives

```text
p does not divide r_p(r_p+1).
```

Hence

```text
T_(r_p) is in GL_2(Z_(p)),
v_p(det T_(r_p)) = 0.
```

Equivalently one may use the integral scaled step

```text
             [ P(n)   -n^3 ]
S_n =        [  1       0  ],

det(S_n) = n^3,
```

because multiplication of the first output coordinate by `(n+1)^3` is also a `p`-unit in this range.

At a marked zero the recurrence reduces to

```text
(r_p+1)^3 b_(r_p+1) == -r_p^3 b_(r_p-1)   (mod p),
```

so both adjacent nonzero coordinates differ only by a unit factor. The adjacent transfer contributes no `p`-primary elementary divisor.

## 5. Primitive two-coordinate state minor: exact Smith content zero

Q2055 already uses the first-order marked quotient

```text
z_p = B/p.
```

After adjoining the predecessor, the natural primitive marked column is

```text
w_p = (z_p, C)^T = (B/p, b_(m-1))^T.
```

Let `W_m` be the `2 x lambda` matrix with these columns.

For distinct marked primes `p,q`, its exact `2 x 2` minor is

```text
det(w_p,w_q)
  = (B/p) C - (B/q) C
  = C B (q-p)/(p q).
```

This minor is a unit at both endpoint primes. Indeed, in the top-squarefree sector:

```text
v_p(C) = v_q(C) = 0,
v_p(B/(pq)) = v_q(B/(pq)) = 0,
0 < |q-p| < N < min(p,q).
```

Therefore

```text
v_p(det(w_p,w_q)) = 0,
v_q(det(w_p,w_q)) = 0.
```

Fix any marked `ell`. Since `lambda>=2` on a marked-pair/B8 row, choose another marked `q`. The minor incident to `ell` is an `ell`-unit. Also `C` itself is an entry of every column and is an `ell`-unit. Hence both determinantal divisors of `W_m` are `ell`-units.

### Theorem 5.1: adjacent-state Smith invariant

If

```text
s_1(W_m) | s_2(W_m)
```

are the two nonzero Smith invariants, then

```text
gcd(s_1(W_m) s_2(W_m), R) = 1.
```

Equivalently, for every marked `p`,

```text
v_p(s_1(W_m)) = v_p(s_2(W_m)) = 0.
```

So the primitive two-coordinate state itself carries **zero** marked radical power.

This is stronger than merely saying that `C` is a unit: even the first nontrivial cross-mark state minors are marked-prime units.

## 6. The one genuinely new raw divisibility: predecessor Lucas error

The preceding theorem does not mean that the predecessor gives no new congruence. It gives exactly one new congruence per marked prime.

Define the low-index state

```text
x_p = b_(r_p),
u_p = b_(r_p-1),
```

and the two q=1 Lucas errors

```text
F_p = B - 5 x_p,
L_p = C - 5 u_p.
```

Then

```text
p | F_p,
p | L_p.
```

The new datum is `L_p`.

There is no second forced copy of `p` in `L_p`. The local recurrence only says that the neighboring nonzero state coordinates are related by a `p`-unit. Nothing above forces

```text
p^2 | L_p.
```

The exact checker below shows first-order saturation on actual Apéry examples and on the symbolic local model.

There is also a natural state determinant

```text
Delta_p
  = det [ B    C ]
        [ x_p  u_p ]
  = B u_p - C x_p
  = u_p F_p - x_p L_p.
```

Since `p|x_p` and `u_p` is a `p`-unit, this determinant lies in the ideal generated by the two Lucas errors; it does not create an independent second pin. Actual examples below have

```text
v_p(Delta_p) = 1.
```

## 7. Strongest raw simultaneous divisibility after adjoining the predecessor

Retain the Q2055 star

```text
J_p = product_{q in P, q != p} (D-z_p+z_q),
D = partial_a(B).
```

Q2055 gives

```text
v_p(J_p) >= lambda-1.
```

The new predecessor error gives

```text
v_p(L_p) >= 1.
```

Therefore the strongest immediate raw product statement is

```text
v_p(J_p L_p) >= lambda.
```

Consequently, for

```text
L_aug = lcm_{p in P} |J_p L_p|,
```

one has the exact simultaneous divisibility

```text
R^lambda | L_aug.
```

This is a real extra raw prime factor, and it is worth recording. It is **not** the desired extra factor in the primitive Smith carrier: `L_p` is a new scalar relation of its own, with its own height and its own presentation rank.

The distinction is visible already from heights. `J_p` is in the Q2055 factorization/interpolation algebra, whose point was to compress all marked incidence into one controlled row object. By contrast

```text
L_p = b_(m-1) - 5 b_(m-p-1)
```

contains an adjacent Apéry value of index comparable with the row index and is exponentially sized in general. Multiplying by `L_p` buys one `log p = O(log N)` divisor at a cost of an Apéry-sized integer; it cannot be the missing little-oh height contraction.

The Smith calculation below makes this rank/height loss exact rather than heuristic.

## 8. Augmented Smith exponent: no increase of the top elementary divisor

Let `M_m` be the Q2055 shifted-interpolation multiplication matrix, and let

```text
sigma_m = largest Smith invariant of M_m.
```

For each simple marked prime Q2055 proves

```text
v_p(sigma_m) >= lambda-1.
```

Now adjoin the predecessor information in primitive form.

* The state matrix `W_m` contributes two `p`-unit Smith factors by Theorem 5.1.
* The one new Lucas-error scalar `L_p` contributes a cyclic factor with forced exponent only `>=1`.
* Moving the state forward or backward one step multiplies it by a matrix in `GL_2(Z_(p))`, so no Smith exponent changes.

Thus, locally at `p`, the primitive extension has the same `p`-primary Smith multiset as the old Q2055 carrier, together with unit factors and one new exponent `v_p(L_p)>=1`. In particular the largest **forced** exponent is

```text
max(lambda-1, 1) = lambda-1.
```

On every surviving marked-pair row `lambda>=2`, and on the B8-heavy sector it is much larger.

A convenient global presentation is the block sum of the Q2055 matrix, the primitive state matrix, and the diagonal matrix of predecessor Lucas errors. Its raw determinant acquires one copy of every marked prime, but its largest local Smith exponent need not increase. This is exactly the difference between

```text
sum of Smith exponents
```

and

```text
largest Smith exponent.
```

The former increases because a new relation was added. The latter is the simultaneous carrier relevant to the Q2055 compression, and it stays at `lambda-1` in the saturation model below.

## 9. Abstract compatible local-transfer model that saturates

This section is deliberately **not** a theorem about the actual Apéry sequence. It is an abstract algebraic model satisfying the local data used by the extension: q=1 geometry, top-squarefree markedness, a marked-active B8 relation, the full arithmetic derivative `D`, a common predecessor unit, exact recurrence compatibility at both adjacent outer steps, and first-order predecessor Lucas errors.

Take

```text
N = 100,
m = 150,
P = {101,103,107,109},
lambda = 4,
R = 101*103*107*109.
```

All four primes lie in `(N,m)`, hence in the nonwrapping q=1 cell. They satisfy the primitive marked-active additive relation

```text
101 + 109 = 103 + 107.
```

Under Q2054's colored B8 convention, pad both sides with the same six colored selected-prime slots to obtain an `8+8` certificate; the four displayed labels remain active.

Put

```text
K = (m-1)^3 (m+1)^3,
B = K R,
C = K.
```

Then for every `p in P`,

```text
v_p(B) = 1,
v_p(C) = 0,
gcd(C,R) = 1.
```

Define the adjacent outer values by

```text
bprev2_syn = (m+1)^3 * ( P(m-1) - m^3 R ),
bnext_syn  = (m-1)^3 * ( P(m) R - m^3 ).
```

They satisfy the two exact recurrences

```text
m^3 B
  = P(m-1) C - (m-1)^3 bprev2_syn,

(m+1)^3 bnext_syn
  = P(m) B - m^3 C.
```

So the common two-coordinate state `(B,C)` is genuinely adjacent-transfer compatible.

Next define the full Q2055 arithmetic derivative

```text
D = partial_a(B)
  = sum_{ell | B} v_ell(B) * B/ell,
```

including the prime factors of `K`, and define `J_p` exactly as in Q2055.

Finally add abstract low-index predecessor states compatible with the q=1 congruence. For each marked `p`, put

```text
r_p = m-p,
x_p = p,
```

and choose the small integer `c_p in {1,2,3,4}` such that

```text
p c_p == C                     (mod 5).
```

Then set

```text
u_p = (C - p c_p)/5.
```

This gives exactly

```text
B == 5 x_p                    (mod p),
C == 5 u_p                    (mod p),
p | x_p,
p does not divide u_p,
L_p = C - 5u_p = p c_p,
v_p(L_p) = 1.
```

Thus the new predecessor relation is present but saturates at its first forced copy of `p`.

The exact checker gives

```text
v_101(J_101) = 3,
v_103(J_103) = 3,
v_107(J_107) = 3,
v_109(J_109) = 3,
```

and every cross-marked valuation of these four stars is zero. Since `D` is a unit at each marked prime, Q2055's nullity-one argument for its shifted multiplication matrix says that the unique nonunit local Smith exponent is exactly

```text
3 = lambda-1.
```

The primitive state matrix has no marked Smith factor, while the diagonal predecessor-error matrix has exactly one local exponent `1`. Therefore the largest augmented local Smith exponent is exactly

```text
max(3,1) = 3 = lambda-1
```

at all four marked primes.

This is the requested saturation construction. It rules out a universally forced exponent `lambda` in the primitive adjacent-transfer Smith carrier.

```text

    gcd(b_(m-1), R) = 1;

primitive state Smith carrier:
    marked exponent = 0;

new predecessor Lucas error:
    marked exponent >= 1, and 1 is sharp in a compatible model.
```

Combining this with Q2055 gives

```text
raw lcm/product exponent after adding the new error:  lambda,
primitive largest Smith exponent forced by the extension: lambda-1.
```

The raw `lambda` is rank/height inflation, not a strict compression. A compatible marked-active B8 local-transfer model realizes exact largest exponent `lambda-1` simultaneously at all marked primes. Therefore adjoining `b_(m-1)` and the full one-step transfer state does not escape the Q2055 saturation barrier.
