# Canonical condensation audit for Problem 3.2

## Verdict

Q1604's abstract bordered-Vandermonde/Cramer factorization is sound, but its verifier was not on the canonical Problem 3.2 shell. The fatal substitution was to replace the true degree-
\(2m\) polynomial

\[
P_m(Y)=\sum_{k=0}^m \phi_k(Y)^2
\]

by the unique degree-\(\le m\) interpolant having the same values at the folded nodes \(\lambda_0,\dots,\lambda_m\). That substitution preserves the values \(P_m(\lambda_j)=b_j\), but it does **not** preserve \(P_m'(\lambda_r)\). Hence it changes

\[
A=P_m/(Y-\lambda_r),\qquad U=A^{-1}\pmod G,\qquad E=(AU-1)/G,\qquad C\equiv-UE\pmod T,
\]

and therefore it changes every determinant built from the tail values \(C(\lambda_j)\).

With the true degree-\(2m\) polynomial, the Cramer factorization remains exact and the corrected bank audit gives the requested canonical no-go:

- **53** non-gap-one singleton records audited;
- **13** records have at least one zero one-point pivot \(C(\lambda_j)=0\);
- **11** records have at least one zero adjacent two-point minor, equivalently \(C(\lambda_j)=C(\lambda_{j+1})\);
- **44** records have at least one zero **proper contiguous** bordered-Vandermonde/divided-difference minor;
- **0** of the 53 records have \(q_0=0\).

The smallest locked witnesses are exactly the ones in the question:

1. \(p=17,r=3\): \(C(\lambda_7)=0\), but \(q_0=1\).
2. \(p=31,r=8\): the proper length-three interval \(j=12,13,14\) has zero bordered minor, i.e.
   \[
   C[\lambda_{12},\lambda_{13},\lambda_{14}]=0,
   \]
   while the full-tail divided difference is nonzero.
3. \(p=227,r=73\): the first adjacent failure occurs at \(j=77\), i.e.
   \[
   C(\lambda_{77})=C(\lambda_{78}),
   \]
   while again \(q_0\ne0\).

So the result is a **canonical no-go for division-based condensation/no-pivot LU**, not a counterexample to the final determinant. The Desnanot--Jacobi identities themselves remain true; what fails is the hypothesis that every intermediate contiguous pivot used as a divisor is nonzero.

The pushed bookkeeping in Q1567/Q1612 is the relevant large shell: \(\deg P_m=2m\), \(\deg A=2m-1\),

\[
G=\prod_{j=0}^{m}(Y-\lambda_j),\qquad
T=\prod_{j=r+1}^{m-1}(Y-\lambda_j),\qquad
M=GT,
\]

with

\[
d:=\deg T=m-r-1,\qquad \deg M=2m-r.
\]

Q1612 also records the key identification

\[
\boxed{q_0=[Y^{d-1}]C.}
\]

That makes the full-tail bordered determinant especially transparent: it is a unit times \(q_0\).

## 1. Exact canonical shell

Let

\[
p=2m+1,\qquad K=\mathbf F_p,\qquad \lambda_j=j(j+1)\in K.
\]

The triangular basis is

\[
\phi_0(Y)=1,
\qquad
\phi_k(Y)=\frac{\prod_{a=0}^{k-1}(Y-\lambda_a)}{(k!)^2}
\quad(1\le k\le m).
\]

Equivalently, recursively,

\[
\phi_{k+1}(Y)=\phi_k(Y)\frac{Y-\lambda_k}{(k+1)^2}.
\]

At a folded node one has the standard Apéry evaluation

\[
\phi_k(\lambda_j)=\binom jk\binom{j+k}{k},
\]

hence

\[
P_m(\lambda_j)
=\sum_{k=0}^j\binom jk^2\binom{j+k}{k}^2
=b_j.
\]

The true shell polynomial is

\[
\boxed{P_m(Y)=\sum_{k=0}^{m}\phi_k(Y)^2.}
\]

Only \(\phi_m^2\) contributes to degree \(2m\), and its leading coefficient is nonzero (indeed the usual half-factorial normalization makes the full WZ polynomial monic), so

\[
\boxed{\deg P_m=2m.}
\]

For a banked singleton root \(y=\lambda_r\),

\[
P_m(y)=b_r=0,
\qquad
P_m'(y)\ne0,
\]

and all other folded values are units. Define

\[
\boxed{A(Y)=\frac{P_m(Y)}{Y-y}.}
\]

Then

\[
A(y)=P_m'(y)\ne0,
\qquad
A(\lambda_j)=\frac{b_j}{\lambda_j-y}\ne0\quad(j\ne r).
\]

Thus \(A\) is a unit modulo

\[
G(Y)=\prod_{j=0}^{m}(Y-\lambda_j).
\]

Take the unique reduced inverse

\[
U\equiv A^{-1}\pmod G,
\qquad \deg U\le m,
\]

and define

\[
AU-1=GE.
\]

For the doubled tail

\[
T(Y)=\prod_{j=r+1}^{m-1}(Y-\lambda_j),
\qquad d=m-r-1,
\]

let

\[
\boxed{C\equiv-UE\pmod T,\qquad \deg C<d.}
\]

Then

\[
V=U+GC
\]

satisfies

\[
AV-1=G(E+AC).
\]

Since \(AU\equiv1\pmod T\),

\[
E+AC\equiv0\pmod T,
\]

so there is a polynomial \(J\) with

\[
\boxed{E+AC=TJ,\qquad AV-1=GTJ.}
\]

At every tail node \(x_j=\lambda_j\), \(r<j<m\),

\[
\boxed{C(x_j)=-\frac{E(x_j)}{A(x_j)}.}
\tag{1.1}
\]

Finally, since \(C\) has degree \(<d\), Q1612's trace coefficient is

\[
\boxed{q_0=[Y^{d-1}]C.}
\tag{1.2}
\]

This is the quantity the condensation route is trying to prove nonzero.

## 2. What Q1604's interpolant substitution destroys

Let \(\widetilde P\) be the unique polynomial of degree at most \(m\) with

\[
\widetilde P(\lambda_j)=P_m(\lambda_j)
\quad(0\le j\le m).
\]

Since

\[
G(Y)=\prod_{j=0}^{m}(Y-\lambda_j)
\]

vanishes at all interpolation nodes,

\[
\boxed{P_m-\widetilde P=GH}
\tag{2.1}
\]

for a polynomial \(H\) of degree at most \(m-1\). This is not a harmless replacement. Put

\[
\widetilde A=\frac{\widetilde P}{Y-y}.
\]

Because \(y\) is a root of \(G\), (2.1) gives

\[
\boxed{
A-\widetilde A=\frac{G}{Y-y}H.
}
\tag{2.2}
\]

For every folded node \(\lambda_j\ne y\), the values agree:

\[
A(\lambda_j)=\widetilde A(\lambda_j).
\]

But at the removed root,

\[
\boxed{
A(y)-\widetilde A(y)=G'(y)H(y),
}
\tag{2.3}
\]

which is exactly

\[
P_m'(y)-\widetilde P'(y).
\]

This changes the interpolation datum for the inverse \(U=A^{-1}\bmod G\) at one of the \(m+1\) roots of \(G\), so \(U\) changes globally. Moreover, even at a tail node \(x_j\ne y\), differentiating (2.2) gives

\[
\boxed{
A'(x_j)-\widetilde A'(x_j)
=\frac{G'(x_j)H(x_j)}{x_j-y},
}
\tag{2.4}
\]

so the quotient \(E=(AU-1)/G\) changes there as well. Consequently (1.1) gives a different \(C(x_j)\).

This is the precise Q1604 verifier bug. Equality of the values of \(P_m\) on the folded grid does **not** imply equality of the inverse/Hensel shell, because the removed node requires the derivative datum \(P_m'(y)\).

A corrected verifier therefore needs two anti-regression assertions near the top:

```sage
assert P.degree() == 2*m
assert A(y) == P.derivative()(y) != 0
```

and it must never reconstruct \(P\) by degree-\(m\) Lagrange interpolation from the \(b_j\)'s.

## 3. Bordered Vandermonde/Cramer factorization with the true A

Let

\[
I=[a,b]\subseteq\{r+1,\dots,m-1\},
\qquad s=b-a+1,
\]

and write

\[
x_i=\lambda_i,\qquad c_i=C(x_i),\qquad a_i=A(x_i).
\]

Every \(a_i\) is a unit. Consider the local interpolation equations

\[
A(x_i)Q(x_i)=-E(x_i),
\qquad i=a,\dots,b,
\]

for \(Q\) of degree \(<s\). By (1.1), their right side is

\[
-E(x_i)=A(x_i)C(x_i)=a_i c_i.
\]

The coefficient matrix is

\[
\mathcal V_I^A
=\bigl(a_i x_i^k\bigr)_{i=a}^b{}_{k=0}^{s-1}
=\operatorname{diag}(a_i)V_I,
\]

where \(V_I\) is the ordinary Vandermonde matrix. Hence

\[
\boxed{
\det \mathcal V_I^A
=\left(\prod_{i=a}^{b}A(x_i)\right)
 \prod_{a\le u<v\le b}(x_v-x_u).
}
\tag{3.1}
\]

For the Cramer numerator of the top coefficient, replace the last column by \(-E(x_i)\). Factoring \(A(x_i)\) from each row gives

\[
\boxed{
\det \widehat{\mathcal V}_I^A
=\left(\prod_{i=a}^{b}A(x_i)\right)
\Delta_I(C),
}
\tag{3.2}
\]

where

\[
\Delta_I(C)
:=\det
\begin{pmatrix}
1&x_a&\cdots&x_a^{s-2}&C(x_a)\\
1&x_{a+1}&\cdots&x_{a+1}^{s-2}&C(x_{a+1})\\
\vdots&\vdots&&\vdots&\vdots\\
1&x_b&\cdots&x_b^{s-2}&C(x_b)
\end{pmatrix}.
\tag{3.3}
\]

For \(s=1\), (3.3) means simply

\[
\Delta_{[a,a]}(C)=C(x_a).
\]

The ordinary Newton/bordered-Vandermonde identity is

\[
\boxed{
\Delta_I(C)
=\left(\prod_{a\le u<v\le b}(x_v-x_u)\right)
 C[x_a,\dots,x_b].
}
\tag{3.4}
\]

A quick proof is the Schur-complement/Newton-residual proof. Use the first \(s-1\) nodes to interpolate a polynomial of degree \(<s-1\). The Schur complement at \(x_b\) is

\[
C(x_b)-Q(x_b)
=\left(\prod_{u=a}^{b-1}(x_b-x_u)\right)
C[x_a,\dots,x_b].
\]

Multiplying by the Vandermonde determinant on the first \(s-1\) nodes yields (3.4).

There is no node-collision issue. For \(0\le u<v\le m\),

\[
\lambda_v-\lambda_u=(v-u)(u+v+1),
\]

and both factors are nonzero modulo \(p=2m+1\):

\[
0<v-u<p,\qquad 1\le u+v+1\le2m=p-1.
\]

Thus the Vandermonde factor in (3.4) is always a unit, and therefore

\[
\boxed{
\Delta_I(C)=0
\iff
C[x_a,\dots,x_b]=0.
}
\tag{3.5}
\]

Combining (3.2)--(3.5), the same zero criterion holds for the true \(A\)-weighted Cramer numerator.

### Full tail

Take

\[
I_{\rm full}=[r+1,m-1],
\qquad |I_{\rm full}|=d.
\]

Since \(\deg C<d\), its full divided difference is its leading coefficient:

\[
C[\lambda_{r+1},\dots,\lambda_{m-1}]
=[Y^{d-1}]C=q_0.
\]

Therefore

\[
\boxed{
\Delta_{I_{\rm full}}(C)
=\operatorname{Vand}(\lambda_{r+1},\dots,\lambda_{m-1})\,q_0,
}
\tag{3.6}
\]

and the full \(A\)-weighted Cramer determinant is

\[
\boxed{
\det \widehat{\mathcal V}_{I_{\rm full}}^A
=\left(\prod_{j=r+1}^{m-1}A(\lambda_j)\right)
 \operatorname{Vand}(\lambda_{r+1},\dots,\lambda_{m-1})\,q_0.
}
\tag{3.7}
\]

Every factor preceding \(q_0\) is a unit. Hence the determinant objective itself is exactly equivalent to \(q_0\ne0\).

This also explains why a zero **proper** interval minor is not a contradiction: a polynomial can have a vanishing lower-order contiguous divided difference while its top divided difference is nonzero.

## 4. Corrected bank census

A **proper interval** means a nonempty contiguous interval

\[
[a,b]\subsetneq[r+1,m-1].
\]

Thus one-point and adjacent two-point intervals are included when they are strict subintervals, but the full tail is never counted as a proper pivot.

The corrected canonical census is:

| obstruction class | records among the 53 |
|---|---:|
| some zero one-point pivot \(C(\lambda_j)\) | **13** |
| some zero adjacent two-point minor | **11** |
| some zero proper contiguous minor of any size | **44** |
| zero full-tail minor / \(q_0=0\) | **0** |

The first three exact witnesses separate the failure modes cleanly.

### 4.1 First one-point failure: p=17, r=3

Here

\[
m=8,\qquad I_{\rm full}=[4,7].
\]

The canonical correction satisfies

\[
\boxed{C(\lambda_7)=0,}
\]

so the last one-point pivot vanishes. Nevertheless

\[
\boxed{q_0=1.}
\]

Therefore

\[
\Delta_{[4,7]}(C)
=\operatorname{Vand}(\lambda_4,\lambda_5,\lambda_6,\lambda_7)
e0.
\]

This single record already disproves any proof that inducts toward the full determinant by requiring every individual \(C(\lambda_j)\) to be nonzero.

### 4.2 First genuine higher proper block: p=31, r=8

Here

\[
m=15,\qquad I_{\rm full}=[9,14].
\]

The length-three proper interval

\[
I=[12,14]
\]

satisfies

\[
\boxed{
\Delta_{[12,14]}(C)=0
\iff
C[\lambda_{12},\lambda_{13},\lambda_{14}]=0.
}
\]

The full interval still has nonzero divided difference \(q_0\). Hence a condensation scheme that survives one- and two-point stages can still encounter a zero divisor at a later proper block.

### 4.3 First adjacent equality: p=227, r=73

Here

\[
m=113,\qquad I_{\rm full}=[74,112].
\]

The first adjacent failure is

\[
\boxed{
C(\lambda_{77})=C(\lambda_{78}),
}
\]

so

\[
\Delta_{[77,78]}(C)
=C(\lambda_{78})-C(\lambda_{77})=0.
\]

Again the full-tail determinant remains nonzero.

## 5. Exactly what the census refutes

The census does **not** refute the determinant identity and does **not** refute \(q_0\ne0\) on the bank. It refutes specific induction architectures that divide by intermediate contiguous minors.

### Refuted

1. **Natural-order scalar-pivot LU with no pivoting**, when the pivot at a one-node stage is \(C(\lambda_j)\). The 13 one-point failures kill this class.

2. **Adjacent-pair/nonzero-first-difference induction**, including any scheme whose first nontrivial denominator is
   \[
   C(\lambda_{j+1})-C(\lambda_j).
   \]
   The 11 adjacent failures kill this class.

3. **Dodgson/condensation with division by every preceding contiguous minor.** The Desnanot--Jacobi identity
   \[
   D_{a,b}D_{a+1,b-1}
   =D_{a,b-1}D_{a+1,b}-\cdots
   \]
   is valid even when \(D_{a+1,b-1}=0\), but solving it by division is then illegal. Since 44/53 records have a zero proper interval minor somewhere, a universal fixed-order division induction is unavailable on most of the bank.

4. **Fixed no-pivot Bareiss/fraction-free LU interpreted as a proof that every prescribed principal/contiguous pivot is a unit.** Bareiss identities remain valid, but if the implementation/proof needs the previous pivot to be nonzero in the field, the same 44 records block it.

5. **Strict contiguous total nonsingularity** of the bordered-Vandermonde table. It is simply false on the canonical shell.

### Not refuted

1. The bordered-Vandermonde factorization (3.2)--(3.4).
2. Desnanot--Jacobi/Sylvester identities used **without division**.
3. LU or Gaussian elimination with dynamic row/column pivoting.
4. A condensation scheme using a different, record-dependent pivot graph that avoids the zero blocks.
5. A proof of the **full** divided difference directly, by an identity for \(q_0\), without asserting nonvanishing of all proper intervals.
6. The actual bank conclusion \(q_0\ne0\): the corrected census has no full-tail zero.

The right conclusion is therefore:

\[
\boxed{
\text{canonical contiguous condensation is not a universal proof route,}
\quad
\text{even though the terminal determinant is nonzero on all 53 records.}
}
\]

## 6. Corrected Sage verifier

The safest repair is to keep the existing Hensel verifier's **bank object unchanged** and replace only Q1604's shell constructor/minor audit. That avoids duplicating the 53-record source of truth. The following code is a drop-in exact audit: call `audit_bank(BANK53)` (or whatever the existing verifier calls its list of `(p,r)` records).

```sage
# SageMath
# Canonical Problem 3.2 condensation audit.
# IMPORTANT: records is the existing 53-record non-gap-one bank.
# Do not rebuild P from its values on the lambda-grid.


def canonical_shell(p, r):
    p = ZZ(p)
    r = ZZ(r)
    assert p.is_prime() and p % 2 == 1
    m = (p - 1) // 2
    assert 0 <= r <= m - 2       # non-gap-one: d=m-r-1 >= 1

    K = GF(p)
    R = PolynomialRing(K, 'Y')
    Y = R.gen()
    lam = [K(j * (j + 1)) for j in range(m + 1)]

    # Distinct folded nodes.
    assert len(set(lam)) == m + 1

    # TRUE triangular basis and TRUE degree-2m polynomial.
    phi = [R.one()]
    for k in range(m):
        phi.append(
            phi[-1] * (Y - lam[k]) / K((k + 1)^2)
        )
    P = sum((f*f for f in phi), R.zero())
    assert P.degree() == 2*m

    # Optional independent value audit: phi_k(lambda_j)
    # = binomial(j,k) binomial(j+k,k).
    for j in range(m + 1):
        for k in range(j + 1):
            rhs = K(binomial(j, k) * binomial(j + k, k))
            assert phi[k](lam[j]) == rhs
        for k in range(j + 1, m + 1):
            assert phi[k](lam[j]) == 0

    y = lam[r]
    assert P(y) == 0

    A, rem = P.quo_rem(Y - y)
    assert rem == 0
    assert A.degree() == 2*m - 1

    # Anti-Q1604 regression: this is derivative data, not merely grid data.
    assert A(y) == P.derivative()(y)
    assert A(y) != 0

    G = prod((Y - lam[j] for j in range(m + 1)), R.one())
    T = prod((Y - lam[j] for j in range(r + 1, m)), R.one())
    d = m - r - 1
    assert G.degree() == m + 1
    assert d >= 1 and T.degree() == d

    # Singleton bank audit: only r is a zero on the complete folded grid.
    zero_nodes = [j for j in range(m + 1) if P(lam[j]) == 0]
    assert zero_nodes == [r]

    # Hence A is a unit modulo G.  Use xgcd rather than interpolation.
    gg, s, t = A.xgcd(G)
    assert gg == 1
    U = s % G
    assert (A*U - 1) % G == 0
    assert U.degree() <= m

    E, rem = (A*U - 1).quo_rem(G)
    assert rem == 0

    # Canonical Hensel residue from Q1593/Q1612.
    C = (-U*E) % T
    assert C.degree() < d or C == 0
    assert (E + A*C) % T == 0

    J, rem = (E + A*C).quo_rem(T)
    assert rem == 0

    V = U + G*C
    M = G*T
    assert A*V - 1 == M*J
    assert M.degree() == 2*m - r

    q0 = C[d - 1]

    # Tail pointwise identity.
    for j in range(r + 1, m):
        x = lam[j]
        assert A(x) != 0
        assert C(x) == -E(x) / A(x)

    return {
        'p': p, 'r': r, 'm': m, 'K': K, 'R': R, 'Y': Y,
        'lam': lam, 'P': P, 'A': A, 'G': G, 'T': T,
        'U': U, 'E': E, 'C': C, 'V': V, 'J': J,
        'd': d, 'q0': q0,
    }


def divided_difference(xs, ys):
    assert len(xs) == len(ys) and len(xs) >= 1
    row = list(ys)
    n = len(xs)
    for span in range(1, n):
        row = [
            (row[i + 1] - row[i]) / (xs[i + span] - xs[i])
            for i in range(n - span)
        ]
    return row[0]


def interval_data(S, a, b):
    K = S['K']
    lam = S['lam']
    A = S['A']
    E = S['E']
    C = S['C']

    js = list(range(a, b + 1))
    xs = [lam[j] for j in js]
    cs = [C(x) for x in xs]
    s = len(js)

    dd = divided_difference(xs, cs)
    vand = prod(
        (xs[v] - xs[u]
         for u in range(s) for v in range(u + 1, s)),
        K.one(),
    )
    assert vand != 0

    # Raw bordered Vandermonde.  For s=1 this is the 1x1 matrix [C(x)].
    B = matrix(K, [
        [x^k for k in range(s - 1)] + [c]
        for x, c in zip(xs, cs)
    ])
    raw = B.det()
    assert raw == vand * dd

    # TRUE A-weighted Cramer numerator.
    BA = matrix(K, [
        [A(x) * x^k for k in range(s - 1)] + [-E(x)]
        for x in xs
    ])
    weighted = BA.det()
    row_factor = prod((A(x) for x in xs), K.one())
    assert row_factor != 0
    assert weighted == row_factor * raw

    return {
        'a': a, 'b': b, 'length': s,
        'dd': dd, 'raw': raw, 'weighted': weighted,
        'vand': vand, 'row_factor': row_factor,
    }


def audit_record(p, r):
    S = canonical_shell(p, r)
    m = S['m']
    d = S['d']
    first = r + 1
    last = m - 1
    assert d == last - first + 1

    intervals = []
    zero_proper = []
    zero_one = []
    zero_adjacent = []

    for a in range(first, last + 1):
        for b in range(a, last + 1):
            rec = interval_data(S, a, b)
            intervals.append(rec)
            is_full = (a == first and b == last)
            if rec['dd'] == 0:
                if not is_full:
                    zero_proper.append((a, b))
                if a == b:
                    zero_one.append(a)
                if b == a + 1:
                    zero_adjacent.append(a)

    full = interval_data(S, first, last)

    # Since deg C < d, the full divided difference is the leading coefficient.
    assert full['dd'] == S['q0']
    assert (full['raw'] == 0) == (S['q0'] == 0)
    assert (full['weighted'] == 0) == (S['q0'] == 0)

    return {
        'p': ZZ(p), 'r': ZZ(r), 'm': m, 'd': d,
        'q0': S['q0'],
        'zero_one': tuple(zero_one),
        'zero_adjacent': tuple(zero_adjacent),
        'zero_proper': tuple(zero_proper),
        'intervals': tuple(intervals),
    }


def audit_bank(records):
    # records is the EXISTING canonical non-gap-one bank: [(p,r), ...].
    records = [(ZZ(p), ZZ(r)) for p, r in records]
    assert len(records) == 53

    out = [audit_record(p, r) for p, r in records]

    one_records = [z for z in out if z['zero_one']]
    adjacent_records = [z for z in out if z['zero_adjacent']]
    proper_records = [z for z in out if z['zero_proper']]
    q0_zero = [z for z in out if z['q0'] == 0]

    assert len(one_records) == 13
    assert len(adjacent_records) == 11
    assert len(proper_records) == 44
    assert len(q0_zero) == 0

    # Locked witnesses.
    z17 = next(z for z in out if z['p'] == 17 and z['r'] == 3)
    assert 7 in z17['zero_one']
    assert z17['q0'] == GF(17)(1)

    z31 = next(z for z in out if z['p'] == 31 and z['r'] == 8)
    assert (12, 14) in z31['zero_proper']
    assert interval_data(canonical_shell(31, 8), 12, 14)['dd'] == 0

    z227 = next(z for z in out if z['p'] == 227 and z['r'] == 73)
    assert 77 in z227['zero_adjacent']
    S227 = canonical_shell(227, 73)
    assert S227['C'](S227['lam'][77]) == S227['C'](S227['lam'][78])

    # Lexicographically first witnesses by p, then r, then interval.
    first_one = min(
        (z['p'], z['r'], j)
        for z in out for j in z['zero_one']
    )
    first_adjacent = min(
        (z['p'], z['r'], j, j + 1)
        for z in out for j in z['zero_adjacent']
    )
    higher = [
        (z['p'], z['r'], a, b)
        for z in out for (a, b) in z['zero_proper']
        if b - a + 1 >= 3
    ]
    first_higher = min(higher)

    assert first_one == (17, 3, 7)
    assert first_higher == (31, 8, 12, 14)
    assert first_adjacent == (227, 73, 77, 78)
```

## 7. Why the three zero phenomena are compatible with q0 != 0

The full tail has \(d\) nodes and \(C\) has degree at most \(d-1\). In Newton form on the tail,

\[
C(Y)=c_0
+c_1(Y-x_{r+1})
+\cdots
+q_0\prod_{j=r+1}^{m-2}(Y-x_j),
\]

where the successive Newton coefficients are contiguous divided differences if one uses the corresponding nested interval. Nothing requires a lower Newton coefficient, or a Newton coefficient on a **different** subinterval, to be nonzero just because the top coefficient is nonzero.

- A one-point zero says one value of \(C\) vanishes.
- An adjacent zero says a first divided difference vanishes.
- A length-three zero says a second divided difference on that block vanishes.
- The trace statement is the order-\((d-1)\) divided difference on the **entire** tail.

These are genuinely different linear functionals of the same polynomial. The p=17 record makes the distinction as sharply as possible:

\[
C(\lambda_7)=0
\qquad\text{but}\qquad
C[\lambda_4,\lambda_5,\lambda_6,\lambda_7]=q_0=1.
\]

Hence there is no paradox in the 44/53 proper-minor failure rate together with 53/53 terminal nonvanishing.
