## 2. Common-`k` repair: retained and proved

Fix one literal unrefined radial datum

```text
theta = (q, eta, b, c0, eps),
C = b eta + eps q c0 = b n + rho,
b ~_v B,
1 <= B <<_v N.
```

For each literal occurrence, RR68c supplies one genuine common integer
`k` for the two source primes:

```text
|k| <<_v B,
gcd(k,b) = gcd(rho,b) = 1,
p k  == -rho (mod b),
p' k == -rho (mod b).
```

Let `P_k` be the actual restricted **set** of source primes for this exact
integer and define

```text
m_k = |P_k|,
z_k = sum_{p in P_k} Z(p),
w_k = |u_q| C_k,
W(theta) = sum_k w_k.
```

The literal positive factorization is

```text
C_k <= N^(o(1))
      (sum_{p in P_k} |u_p| Z(p))
      (sum_{p' in P_k} |u_p'|).
```

Using `|u_p| <= N^(-1+o(1))` on the active source shell gives

```text
w_k <= N^(-3+o(1)) z_k m_k.
```

For fixed `k`, invertibility modulo `b` fixes one source-prime class,

```text
p == -rho k^(-1) (mod b),
```

so the shell interval gives

```text
m_k <<_v 1 + N/B.
```

In the active range `B <<_v N`, this is

```text
m_k <= N^(1+o(1))/B.
```

For fixed `p`, the same congruence first forces `gcd(p,b)=1`, then fixes
one residue class for the physical integer:

```text
k == -rho p^(-1) (mod b).
```

The physical interval has length `O_v(B)` while `b ~_v B`, hence it
contains only `O_v(1)` lifts.  Therefore

```text
#{k : p in P_k} <<_v 1
```

and

```text
sum_k z_k
 = sum_{p ~ N} Z(p) #{k : p in P_k}
 <= N^(8/5+o(1)).
```

The zero-label overlap is counted exactly once: `Z(p)` is already the
weight inside `z_k`.  Source, sign, primitive, actual-zero, chart, radial,
and physical-lift masks remain deletions from nonnegative sums; no mask is
used to create multiplicity.

Consequently,

```text
W(theta)
 <= N^(-3+o(1)) (max_k m_k) sum_k z_k
 <= N^(-2/5+o(1))/B.
```

The exponent identity is

```text
-3 + 1 + 8/5 = -2/5.
```

Combining this with the staged positive first-carrier ledger

```text
sum_theta W(theta) <= N^(4/5+o(1)) M,
M = min(B, D/N^(2/5)),
```

gives

```text
sum_theta W(theta)^2
 <= N^(2/5+o(1)) M/B.
```

Thus the common-`k` average repair is unchanged by the bookkeeping
correction.

## 3. Correct scope of the weighted second-zero input

The old artifact stated

```text
sum_{r ~ N} |u_r| Z(r)^2 <= N^(6/5+o(1))
```

as though it were a global all-shell-prime theorem.  The corrected proof
does not make that claim.

Let `R_cen` be the exact masked central host-`r` layer consumed by RR68av.
The relevant canonical/staged input is the weighted factorial moment on
that layer:

```text

  <= N^(6/5+o(1)).
```

The diagonal comes from the weighted first moment, restricted by deletion
to the same layer:

```text

  <= N^(3/5+o(1)).
```

The exact identity


therefore yields only the required central-consumer consequence:

```text

 <= N^(6/5+o(1)) + N^(3/5+o(1))

```

Every host use in the corrected proof is explicitly over `R_cen`.

With that scope fixed, summing the host prime first still gives


```text

```

```text

12/5 + 1/15 = 37/15.
```

Since the first competitor decreases and the second increases,

```text

  = 37/15 at ell = 2/15.
```

The relevant fully-unconditional target in this staged ledger is


The exact high-corner residual is therefore


`4/15` and approaches `19/60` at the upper endpoint.

This is the smallest explicit remaining residual in this corrected staged
ledger.  The average repair restores the local host estimates but does not
