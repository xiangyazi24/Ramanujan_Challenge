# Q843: Dependency-edge audit of IQC8 and TP16 against LGTQ reductions

## Conclusion

Neither IQC8 nor TP16 is currently a theorem-level consequence of the existing LGTQ-AGG, LGTQ-2, rectangle, or matching-block hypotheses by a mere change of variables. The similarity is structural only: all of them compress a high-load configuration into a finite quotient packet with affine prime laws and Boolean selector data. The missing implication is not an algebraic normalization issue; it is a quantifier and geometry mismatch.

The existing LGTQ reductions control local target-prime geometry inside an explicitly fixed quotient/gap packet. IQC8 and TP16 require a statement about a physical Apéry column selected by the isolated-five-star decomposition, where the column variable is constrained simultaneously by the physical moment index, the prime shell, and isolation masks.

## Variable correspondence audit

Let the physical column variable be denoted by `m`.

* In the I5 route:
  * `m` is the common physical column carrying the high load.
  * The canonical Apéry output index is the folded index `j_p` obtained after the prime affine map.
  * The prime-shell scale is the dyadic parameter `X` (with regions `X <= m < 2X` and `2X <= m < Y_X`).
  * Gap variables arise from adjacent target primes through `h=q(p-lambda)` (equivalently the divisibility condition `q | h`).
  * Selector/isolation masks are physical masks: they delete non-isolated hits before the load estimate is applied.

In the LGTQ reductions:

* The base variable is not the physical column. It is a quotient packet coordinate.
* The prime variable is already restricted to a fixed affine branch.
* Rectangle and matching-block hypotheses describe a Boolean cube/tesseract of admissible local configurations after quotienting.
* The selector variables describe admissible packet choices, not the original isolated-column event.

Therefore the identification

```
physical column m = LGTQ quotient coordinate
```

is invalid without an additional lifting lemma.

## IQC8 audit

IQC8 applies on the range

```
2X <= m < Y_X
```

and compresses a large physical column load into a fixed quotient/branch packet.

The strongest available LGTQ-AGG/LGTQ-2 conclusion has the schematic form:

```
fixed q + fixed branch packet + affine prime law
    => small number of bad quotient configurations.
```

IQC8 needs:

```
large physical column load
    => one fixed quotient/branch packet with preserved isolation
    => small number of physical columns.
```

The first invalid inference is the quantifier order:

```
LGTQ: for every fixed packet, count configurations inside packet.
IQC8: for every high-load physical column, find a packet capturing it.
```

The missing direction is packet extraction from a physical column. Existing LGTQ hypotheses do not assert that a high-load column has bounded packet multiplicity or that all contributing primes lie in one packet.

Hence no implication follows.

## TP16 audit

TP16 applies on

```
X <= m < 2X.
```

The temptation is stronger here because the dyadic shell resembles the prime-shell normalization used by LGTQ.

However, the same obstruction remains. LGTQ rectangle/matching-block hypotheses control complete cross-unit Boolean cubes/tesseracts after quotient reduction. TP16 requires that the original physical column contributions survive all three transformations:

1. physical column -> affine prime branch;
2. affine branch -> canonical Apéry folded index;
3. folded index -> fully transverse isolated cube.

Existing LGTQ hypotheses begin after step 1 and therefore cannot guarantee steps 2 and 3.

The first mismatch is the isolation mask. LGTQ counts admissible local packets; TP16 counts isolated physical contributors. The implication would require preservation of the isolation predicate under the quotient map, which is not currently stated.

## Loss-factor audit

No valid loss factor can be stated for either implication because the required map has not been proved finite-to-one.

A valid implication would need constants

```
C_packet, C_branch, C_mask
```

such that every physical contributor in IQC8/TP16 maps into at most

```
C_packet * C_branch * C_mask
```

LGTQ packets. The existing hypotheses provide bounds after this map; they do not provide the map or its multiplicity.

## Weakest sufficient bridge lemma

The minimal missing statement is a physical-to-LGTQ lifting lemma.

> **Physical column packet lifting lemma.** Fix `q` and a prime shell. For every isolated physical column `m` in the I5 range, all contributing target-prime pairs can be partitioned into at most `C(q)` affine LGTQ branch packets. Each packet preserves:
>
> 1. the same quotient parameter;
> 2. the same gap divisibility condition `q | h`;
> 3. the same folded Apéry index law;
> 4. the isolation selector predicate;
> 5. the fully transverse Boolean cube/tesseract structure.
>
> Moreover the number of packets satisfies a loss bound independent of `m` and the dyadic scale.

With this lemma:

* IQC8 follows by applying LGTQ-AGG/LGTQ-2 to each packet and multiplying the final bound by `C(q)`.
* TP16 follows by applying rectangle/matching-block reduction packetwise and paying the same constant multiplicity loss.
