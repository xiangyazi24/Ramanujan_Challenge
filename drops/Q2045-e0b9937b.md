# 10. Exact pin-ideal theorem: no four-factor cancellation inside this interface

This is the main scope theorem.

Let

\[
R_i=(\alpha_i,\beta_i),
\qquad
D_i=R_iB=\alpha_i+5\beta_i,
\qquad 1\le i\le4.
\]

Work in the polynomial ring

\[
A=\mathbf Z[\alpha_1,\beta_1,\ldots,\alpha_4,\beta_4,\text{auxiliary parameters}],
\]

where the auxiliary parameters may include the indices and any coefficients that are independent of the four row coordinates.

## Pin-ideal lemma

Suppose a polynomial \\(\Phi\in A\\) has the following **formal** property for every \(i\): after imposing only the distinguished pin \(D_i=0\), with all other row variables arbitrary, \\(\Phi\\) vanishes identically. Then

\[
\boxed{D_1D_2D_3D_4\mid\Phi.}
\tag{10.1}
\]

### Proof

For fixed \(i\), \(D_i\) is a primitive linear polynomial. The hyperplane \(D_i=0\) has vanishing ideal \\((D_i)\\); hence formal vanishing on that hyperplane implies \(D_i\mid\Phi\). The four \(D_i\) involve disjoint row-variable pairs, so they are pairwise coprime prime elements of the UFD \(A\). Therefore divisibility by each \(D_i\) implies divisibility by their product. ∎

The nonzero condition \(R_iC\ne0\) from (7.3) does not change the conclusion: it removes a proper closed subset of the hyperplane, and a polynomial vanishing on the remaining dense open subset still lies in \\((D_i)\\).

## Scope

This lemma rules out a carrier whose proof of the four prime divisibilities uses only:

- the four individual distinguished row pins;
- \(2\times2\) matrix multiplication;
- determinant/exterior/Plücker identities;
- divided differences with the top-cell gap denominators (9.1), after clearing those unit denominators;
- multiplication by or division of structural factors known to be units at the corresponding \(p_i\).

It does **not** rule out a genuinely new polynomial relation among the actual four integer rows \(R_{r_i}\) that is not generated by this formal pin algebra. Such a relation would be new Apéry arithmetic, precisely what is still needed.

If a proposed carrier contains an explicit factor \(p_i=m-r_i\), that factor gives tautological \(p_i\)-divisibility and must be stripped before applying the lemma. The statement is about the primitive, non-modulus-supported part.

Thus, inside the natural transfer/divided-difference interface, the hoped-for cancellation

```text
four local selected-prime factors
        -> one smaller primitive cross-prime factor
```

cannot occur formally. The four local distinguished factors survive multiplicatively.

```python
#!/usr/bin/env python3
from __future__ import annotations

from collections import Counter
from fractions import Fraction
from math import factorial, isqrt


def P(n: int) -> int:
    return 34*n**3 + 51*n**2 + 27*n + 5


def apery_b(M: int) -> list[int]:
    b = [0] * (M + 1)
    b[0] = 1
    if M >= 1:
        b[1] = 5
    for n in range(1, M):
        num = P(n)*b[n] - n**3*b[n-1]
        den = (n+1)**3
        assert num % den == 0
        b[n+1] = num // den
    return b


def apery_a(M: int) -> list[Fraction]:
    a = [Fraction(0) for _ in range(M + 1)]
    if M >= 1:
        a[1] = Fraction(6)
    for n in range(1, M):
        a[n+1] = (P(n)*a[n] - n**3*a[n-1]) / (n+1)**3
    return a


def matmul(A, B):
    return [
        [A[0][0]*B[0][0] + A[0][1]*B[1][0],
         A[0][0]*B[0][1] + A[0][1]*B[1][1]],
        [A[1][0]*B[0][0] + A[1][1]*B[1][0],
         A[1][0]*B[0][1] + A[1][1]*B[1][1]],
    ]


def Avec(n: int):
    return [[0, 1], [-n**6, P(n)]]


def eye2():
    return [[1, 0], [0, 1]]


def segment(a: int, h: int):
    # A_{a+h-1} ... A_a
    M = eye2()
    for n in range(a, a+h):
        M = matmul(Avec(n), M)
    return M


def det2(A) -> int:
    return A[0][0]*A[1][1] - A[0][1]*A[1][0]


def wedge(u, v) -> int:
    return u[0]*v[1] - u[1]*v[0]


def W(h: int, x: int) -> int:
    assert h >= 0
    if h == 0:
        return 1
    if h == 1:
        return P(x)
    w0, w1 = 1, P(x)
    for j in range(1, h):
        w0, w1 = w1, P(x+j)*w1 - (x+j)**6*w0
    return w1


def row_R(r: int):
    assert r >= 1
    if r == 1:
        M = eye2()
    else:
        M = segment(1, r-1)
    return M[1], M


def dotrow(r, v):
    return r[0]*v[0] + r[1]*v[1]


def bareiss_det(A):
    A = [row[:] for row in A]
    n = len(A)
    if n == 0:
        return 1
    sign = 1
    prev = 1
    for k in range(n-1):
        if A[k][k] == 0:
            s = next((i for i in range(k+1, n) if A[i][k] != 0), None)
            if s is None:
                return 0
            A[k], A[s] = A[s], A[k]
            sign = -sign
        pivot = A[k][k]
        for i in range(k+1, n):
            for j in range(k+1, n):
                A[i][j] = (A[i][j]*pivot - A[i][k]*A[k][j]) // prev
        for i in range(k+1, n):
            A[i][k] = 0
        prev = pivot
    return sign*A[n-1][n-1]


def primes_upto(n: int) -> list[int]:
    if n < 2:
        return []
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[0:2] = b"\x00\x00"
    for p in range(2, isqrt(n) + 1):
        if sieve[p]:
            sieve[p*p:n+1:p] = b"\x00" * (((n-p*p)//p) + 1)
    return [i for i in range(2, n+1) if sieve[i]]


def verify_transfer_identities():
    # Segment matrix formula (6.3) and determinant (6.4).
    for a in range(1, 8):
        for h in range(2, 8):
            M = segment(a, h)
            rhs = [
                [-a**6 * W(h-2, a+1), W(h-1, a)],
                [-a**6 * W(h-1, a+1), W(h, a)],
            ]
            assert M == rhs, (a, h)
            d = 1
            for j in range(h):
                d *= (a+j)**6
            assert det2(M) == d

    # Fundamental initial vector and distinguished row pin.
    B = (1, 5)
    C = (0, 1)
    b = apery_b(100)
    ps = primes_upto(100)
    for r in range(1, 50):
        R, M = row_R(r)
        assert dotrow(R, B) == factorial(r)**3 * b[r]
        assert det2(M) == factorial(r-1)**6
        for p in ps:
            if p <= r or b[r] % p:
                continue
            assert b[r-1] % p != 0
            c = dotrow(R, C) % p
            assert c != 0
            # R == c*(-5,1) mod p.
            assert R[0] % p == (-5*c) % p
            assert R[1] % p == c

    # Four-row Pluecker identity: the entire exterior-four content in 2D.
    rows = [row_R(r)[0] for r in (3, 5, 7, 9)]
    d12 = wedge(rows[0], rows[1])
    d13 = wedge(rows[0], rows[2])
    d14 = wedge(rows[0], rows[3])
    d23 = wedge(rows[1], rows[2])
    d24 = wedge(rows[1], rows[3])
    d34 = wedge(rows[2], rows[3])
    assert d12*d34 - d13*d24 + d14*d23 == 0

    # Adding Vandermonde columns removes the dimensional collapse, but
    # also removes the pin-carrier property.  First row is exactly L=(-5,1)
    # modulo 7, yet determinant is 3 mod 7.
    aug = [
        [1, 1, -5, 1],
        [1, 2,  1, 0],
        [1, 3,  0, 1],
        [1, 4,  1, 1],
    ]
    assert bareiss_det(aug) == 3
    assert bareiss_det(aug) % 7 == 3


def verify_casoratian():
    M = 30
    b = apery_b(M)
    a = apery_a(M)
    for n in range(1, M+1):
        assert a[n-1]*b[n] - b[n-1]*a[n] == Fraction(-6, n**3)
        # Exact common-row companion collapse (14.2).
        assert (
            Fraction(n**3 * b[n-1], 1) * a[n] - 6
            == Fraction(n**3 * b[n], 1) * a[n-1]
        )
        # Factorial-gauged fundamental determinant (14.3).
        Xnm1 = factorial(n-1)**3 * b[n-1]
        Xn = factorial(n)**3 * b[n]
        Ynm1 = factorial(n-1)**3 * a[n-1]
        Yn = factorial(n)**3 * a[n]
        assert Xnm1*Yn - Ynm1*Xn == 6*factorial(n-1)**6


def verify_anchor_exponents(k: int = 8):
    # Abstract selected labels; exponents are what matter.
    S = list(range(101, 101+k))
    a, b = S[0], S[1]
    ex = Counter()
    records = 0
    for p in S[2:]:
        for q in S[2:]:
            if p == q:
                continue
            records += 1
            ex[a] += 1
            ex[b] += 1
            ex[p] += 1
            ex[q] += 1
    assert records == (k-2)*(k-3)
    assert ex[a] == records and ex[b] == records
    for t in S[2:]:
        assert ex[t] == 2*(k-3)


def scan_block(N: int):
    b = apery_b(2*N)
    ps = [p for p in primes_upto(2*N) if p > N]
    max_lambda = 0
    pair_rows = []
    four_rows = []

    for m in range(N+1, 2*N+1):
        S = [p for p in ps if p <= m and b[m] % p == 0]

        # Exact q=1 equivalence, not just one implication.
        for p in ps:
            if p > m:
                continue
            assert (b[m] % p == 0) == (b[m-p] % p == 0), (N, m, p)

        max_lambda = max(max_lambda, len(S))
        if len(S) >= 2:
            pair_rows.append((m, S))
        if len(S) >= 4:
            # Search every ordered marked pair and attach the canonical
            # two smallest other primes exactly as in Q2043/Q2045.
            recs = []
            for p in S:
                for q in S:
                    if p == q:
                        continue
                    others = sorted(set(S) - {p, q})
                    assert len(others) >= 2
                    u, v = others[:2]
                    recs.append((p, q, u, v))
            four_rows.append((m, S, recs))

    return max_lambda, pair_rows, four_rows


def main():
    verify_transfer_identities()
    verify_casoratian()
    verify_anchor_exponents()

    # Exact finite regressions.  Add 2000 and 5000 for the larger scan used
    # in the report; they take longer because b_n has thousands of digits.
    for N in (100, 200, 500, 1000):
        mx, pairs, fours = scan_block(N)
        print("N=", N, "max_lambda=", mx,
              "pair_rows=", len(pairs),
              "four_rows=", len(fours))
        if fours:
            print("canonical four-prime records:", fours[:10])

    print("all exact identities passed")


if __name__ == "__main__":
    main()
```
