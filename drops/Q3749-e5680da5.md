\[
\boxed{m+s=7q-1.}
\tag{0.3}

  b_{q-1-u}\equiv b_u\pmod q.

\[
\boxed{q\mid b_m,\qquad q\mid b_s.}
\tag{0.4}

\[
\gcd(\gcd(b_m,b_s),q)=q,

\[
\boxed{

Its valuation ledger is

\[
\boxed{
\log G(q,u)
=
\bigl(\min(v_q(b_m),v_q(b_s))-1\bigr)\log q
+
\sum_{\ell\ne q}
\min(v_\ell(b_m),v_\ell(b_s))\log\ell.

\tag{0.6}
\]

\[
\boxed{h=m-s=5q+2u+1=\Theta(q),}
\tag{0.7}
\]

so for most possible foreign primes the transfer crosses a singular recurrence pivot.

The smallest clean new theorem which would close the minus contribution is therefore a **valuation-weighted stripped growing-window return theorem** for the distinguished Apéry sequence. A selected-set-independent strong form is:

> **SGWR (stripped growing-window return).** For every fixed `J`, let `U_J(T)` be the deterministic set of prescribed upper states `(q,u)` satisfying the minus-star geometry, with

> \[
> \boxed{
> \sum_{(q,u)\in U_J(T)}\log G(q,u)

> }
> \tag{0.8}
> \]

## 2. Exact structural `q` factor

Let `(q,u)` be one prescribed upper state and set

\[
m=6q+u,
\qquad
s=q-1-u.
\tag{2.1}
\]

The range in the question gives

\[
0\le u<q/7<q/2,
\qquad
0<s<q.
\tag{2.2}

### 2.1 Lucas at the lifted index

The Apéry Lucas congruence gives

\[
b_{aq+r}\equiv b_a b_r\pmod q
\qquad(0\le r<q).
\tag{2.3}

Taking `a=6`, `r=u`,

\[
\boxed{
b_m=b_{6q+u}\equiv b_6b_u\pmod q.}

Thus `q|b_u` implies `q|b_m`.

\boxed{
b_s=b_{q-1-u}\equiv b_u\pmod q.}

Thus `q|b_u` also implies `q|b_s`.

Together, (2.4)-(2.5) prove (0.4). Therefore the denominator in the carrier from the minus-star proof is not an assumption:

\boxed{
\gcd(\gcd(b_m,b_s),q)=q.

\tag{2.6}

It removes exactly **one** copy of the unavoidable common endpoint prime. If `q^2` divides both Apéry values, the second copy is not structural and correctly remains in `G(q,u)`.

## 3. Exact first-divided `q`-primary test

This is the first place where the existing machinery stops one step short of what the aggregate height needs.

Write

\[
b_u=q a_{q,u},
\qquad a_{q,u}\in\mathbf Z.
\tag{3.1}
\]

The reflection script proves the exact congruence (1.1), hence

\[
\boxed{
\frac{b_s}{q}
\equiv a_{q,u}-\dot b_u
\pmod q.
}
\tag{3.2}
\]

Now use the exact quotient-six Lucas/Bockstein integer

\[
\boxed{
Y_q(u):=\frac{b_{6q+u}-b_6b_u}{q}\in\mathbf Z.
}
\tag{3.3}
\]

Then

\[
\boxed{
\frac{b_m}{q}=b_6a_{q,u}+Y_q(u),
}
\tag{3.4}
\]

and therefore

\[
\boxed{
\frac{b_m}{q}
\equiv b_6a_{q,u}+Y_q(u)
\pmod q.
}
\tag{3.5}
\]

Consequently

\[
\boxed{
q^2\mid\gcd(b_m,b_s)
\iff
\begin{cases}
 a_{q,u}-\dot b_u\equiv0\pmod q,\\
 b_6a_{q,u}+Y_q(u)\equiv0\pmod q.
\end{cases}}
\tag{3.6}
\]

This is an exact symbolic test for the first excess `q` factor.

### What is and is not known

The finite reflection scanner finds no reflected prime-square zero in its tested range, but the file itself correctly says this is not an all-prime theorem. An all-prime statement such as

\[
q\mid b_u,\quad 0\le u<q/7
\Longrightarrow
q^2\nmid b_{q-1-u}
\tag{3.7}
\]

would immediately kill the entire defining-prime excess in (0.6), regardless of `b_m`. But (3.7) is not currently proved by the recurrence/reflection machinery.

The exact weaker condition needed only for this carrier is

\[
\boxed{
\min\{v_q(b_m),v_q(b_s)\}=1.
}
\tag{3.8}
\]

Equivalently, the two residues in (3.6) are not simultaneously zero.

This already shows why “strip the obvious `q` and forget the defining prime” is not yet a theorem: stripping one copy is exact, but higher `q`-adic content is a genuine arithmetic residual.

## 4. Foreign-prime returns and the exact continuant criterion where it is legal

Put

\[
h:=m-s=5q+2u+1.
\tag{4.1}
\]

Use the exact project continuants

\[
N_1(X)=1,
\qquad
N_2(X)=P(X+1),
\]

\[
N_{r+1}(X)=P(X+r)N_r(X)-(X+r)^6N_{r-1}(X).
\tag{4.2}
\]

The transfer identity has the form

\[
\boxed{
Q_h(s)b_m
=N_h(s)b_{s+1}-S_h(s)b_s,
}
\tag{4.3}
\]

with

\[
Q_h(s)=\prod_{j=2}^{h}(s+j)^3.
\tag{4.4}
\]

### 4.1 Exact rough-prime return theorem

Let `ell` be a prime with

\[
\ell>m.
\tag{4.5}
\]

Then every factor of `Q_h(s)` is an `ell`-unit. Also `s<ell`; if `ell|b_s`, the ordinary recurrence shows `ell\nmid b_{s+1}` (otherwise backward propagation would force `ell|b_0=1`).

Taking valuations in (4.3) gives the exact equality

\[
\boxed{
\min\{v_\ell(b_s),v_\ell(b_m)\}
=
\min\{v_\ell(b_s),v_\ell(N_h(s))\}
\qquad(\ell>m).
}
\tag{4.6}
\]

Proof: if `k=min(v_ell(b_s),v_ell(b_m))`, then the right side of

\[
N_h(s)b_{s+1}=Q_h(s)b_m+S_h(s)b_s
\]

is divisible by `ell^k`, and `b_{s+1}` is a unit, so `v_ell(N_h(s))>=k`. Conversely, if `k=min(v_ell(b_s),v_ell(N_h(s)))`, both terms on the right after solving for `Q_h(s)b_m` are divisible by `ell^k`; `Q_h(s)` is a unit, so `v_ell(b_m)>=k`.

Thus the recurrence does give a perfect return criterion for primes beyond the whole growing window.

### 4.2 Why this does not prove the required height

Identity (4.6) is not a height saving. It merely replaces one Apéry value by a length-`h` continuant with

\[
h=\Theta(q).
\]

The denominator-free transfer coefficients have at least the factorial-scale coefficient ledger coming from (4.4); a direct recurrence bound is of order

\[
\log|N_h(s)|=O(q\log q),
\tag{4.7}
\]

which is worse than the trivial Apéry-side bound

\[
\log\gcd(b_m,b_s)\le \log b_s=O(q).
\tag{4.8}
\]

So the exact transfer theorem is useful for classifying return primes, but not for proving the desired aggregate Archimedean saving.

## 5. Why the same transfer argument breaks for `ell <= m`

For a foreign prime `ell<=m`, the interval

\[
[s+2,m]
\]

usually contains a multiple of `ell`, so `Q_h(s)` is no longer an `ell`-unit. The implication

\[
\ell\mid b_s,b_m
\Longrightarrow
\ell\mid N_h(s)
\]

cannot be obtained by dividing (4.3) modulo `ell`; the singular transfer pivot is exactly the obstruction.

One still has the unconditional integer relation

\[
\gcd(b_s,b_m)\mid N_h(s)b_{s+1},
\tag{5.1}
\]

but there is no legitimate cancellation of `b_{s+1}` at primes which also meet a singular pivot. This is the precise reason the tempting global assertion

\[
\boxed{
\frac{\gcd(b_m,b_s)}q\stackrel{?}{\mid}N_h(s)
}
\tag{5.2}
\]

is **not** a consequence of the continuant identity.

The Wronskian only tells us that simultaneous consecutive zeros are constrained by recurrence pivots; it does not turn all primes in the macroscopic interval into units.

### Lucas reduction is only radical-level

For these smaller primes, the Apéry Lucas theorem says that if

\[
n=n_0+n_1\ell+\cdots+n_r\ell^r,
\]

then

\[
b_n\equiv\prod_i b_{n_i}\pmod\ell.
\tag{5.3}
\]

Hence `ell|b_n` means at least one base-`ell` digit is an Apéry zero modulo `ell`. Applied simultaneously to `s` and `m`, this gives a genuine “return to digit zeros” picture.

But (5.3) controls only whether `v_ell(b_n)>=1`. The carrier height is valuation weighted:

\[
\min(v_\ell(b_s),v_\ell(b_m))\log\ell.
\]

No existing Lucas statement supplies the required higher-power bound uniformly over this growing family. Replacing the carrier by its radical would therefore lose exactly the multiplicity that the star argument was designed to preserve.

This is the central obstruction in the current toolkit.

## 6. Exact decomposition of the missing theorem

For a prescribed deterministic upper-state family `U_J(T)`, define

\[
E_q(T)
:=
\sum_{(q,u)\in U_J(T)}
\bigl(\min(v_q(b_m),v_q(b_s))-1\bigr)\log q,
\tag{6.1}
\]

and

\[
R_{\rm foreign}(T)
:=
\sum_{(q,u)\in U_J(T)}
\sum_{\ell\ne q}
\min(v_\ell(b_m),v_\ell(b_s))\log\ell.
\tag{6.2}
\]

Then by (0.6), identically,

\[
\boxed{
\sum_{(q,u)\in U_J(T)}\log G(q,u)
=E_q(T)+R_{\rm foreign}(T).
}
\tag{6.3}
\]

Therefore the desired aggregate estimate is **equivalent** to

\[
E_q(T)+R_{\rm foreign}(T)
=o_J(T^2/\log T).
\tag{6.4}
\]

A clean two-lemma route would be:

### Lemma A — reflected defining-prime excess is negligible

Either prove the pointwise statement

\[
q\mid b_u,\quad u<q/7
\Longrightarrow
\min(v_q(b_m),v_q(b_s))=1,
\tag{6.5}
\]

which makes `E_q(T)=0`, or prove only the aggregate form

\[
\boxed{E_q(T)=o_J(T^2/\log T).}
\tag{6.6}
\]

The first-divided criterion (3.6) is the exact local target.

### Lemma B — foreign growing-window return

Prove

\[
\boxed{
R_{\rm foreign}(T)
=o_J(T^2/\log T).
}
\tag{6.7}
\]

This is the genuinely new cross-characteristic theorem. It is not a reflection statement: every summand in (6.7) has `ell != q`.

If one wants a single theorem rather than a two-lemma package, SGWR (0.8) is precisely their valuation-weighted combination.

## 7. The trivial bound reaches only the critical scale

The Apéry asymptotic gives

\[
\log b_n=n\log(17+12\sqrt2)+O(\log n).
\tag{7.1}
\]

Since `G(q,u)|b_s/q`,

\[
\log G(q,u)
\le
s\log(17+12\sqrt2)+O(\log T)
\le Cq+O(\log T).
\tag{7.2}
\]

Thus any argument which uses only individual Apéry size gives

\[
\sum_{(q,u)\in U_J(T)}\log G(q,u)
\ll
\sum_{(q,u)\in U_J(T)}q
+|U_J(T)|\log T.
\tag{7.3}
\]

Even in the optimistic situation in which the prescribed family has only

\[
|U_J(T)|=O_J(T/\log T)
\]

states and every `q=Theta(T)`, (7.3) is merely

\[
O_J(T^2/\log T),
\tag{7.4}
\]

exactly the **critical** size. Stripping the single factor `q` saves only `O(log T)` per state, not the required little-o factor.

So a proof of (0.1) must use genuine arithmetic decorrelation/return sparsity. Pure size, prime counting, or the fact `u<q/7` is insufficient.

## 8. Tests of the natural proposed identities

### Test 1: strengthen reflection from `q` to `q^2`

A tempting shortcut is

\[
b_{q-1-u}\stackrel{?}{\equiv}b_u\pmod{q^2}.
\tag{8.1}

The exact reflection formula says instead

\[
b_{q-1-u}-b_u\equiv-q\dot b_u\pmod{q^2}.
\tag{8.2}

Thus (8.1) is equivalent to `dot b_u=0 mod q`. The connector-visible exact checker contains explicit counterexamples to the universal version of (8.1). Therefore no argument may silently promote the mod-`q` reflection to mod `q^2`.

For the restricted target range `u<q/7` with `q|b_u`, the desired noncoincidence remains a separate all-prime theorem; the finite scan is evidence only.

### Test 2: identify the two first-divided endpoint values

One might hope that Lucas plus reflection gives

\[
\frac{b_m}{q}
\stackrel{?}{\equiv}
 b_6\frac{b_s}{q}
\pmod q.
\tag{8.3}
\]

Substituting the exact formulas (3.2) and (3.5), (8.3) is **equivalent** to

\[
\boxed{
Y_q(u)+b_6\dot b_u\equiv0\pmod q.

Thus (8.3) is not a consequence of first-order Lucas/reflection; it is a new quotient-six Bockstein/index-derivative identity. Any proposed proof must verify (8.4) symbolically from the two inhomogeneous recurrences. No such identity is presently banked.

### Test 3: replace the stripped gcd by one continuant

A correct checker must classify every prime factor of `G(q,u)` by whether the transfer interval is `ell`-regular before using the continuant return criterion.

## 9. What the Wronskian actually contributes

Let `a_n` be the canonical independent Apéry companion. The project Wronskian has the usual nonzero form

\[
a_nb_{n-1}-a_{n-1}b_n=\frac{6}{n^3}
\tag{9.1}
\]

in the rational normalization (equivalently an integral constant after the factorial gauge).

For a prime `ell` not dividing the relevant denominator/pivot, this implies that an Apéry zero is projectively regular: the companion coordinate is nonzero and the neighboring Apéry state is nonzero. That is exactly what is needed to justify (4.6).

What it does **not** imply is that the same projective orbit cannot hit the zero line again after `Theta(q)` further steps. The return condition is one transfer-matrix entry vanishing, and the Wronskian determinant being nonzero does not prohibit that entry from vanishing.

Therefore the Wronskian is a regularity tool, not an aggregate return-height theorem.

## 10. A useful stronger selected-set-independent theorem

If one wants to remove all dependence on how the Smith reduction prescribes the upper states, the clean arithmetic target is the following stronger statement.

Let

\[
\mathcal A(T)
:=
\left\{(q,u):
q\text{ prime},\
T<6q+u\le2T,\
0\le u<q/7,\
q\mid b_u
\right\}.
\tag{10.1}

Then prove

\[
\boxed{
\sum_{(q,u)\in\mathcal A(T)}

=o(T^2/\log T).
}
\tag{10.2}

Every fixed-`J` compatible family is a subset of `A(T)`, so (10.2) immediately implies the required minus-star premise without any further combinatorial bookkeeping.

This is, in my view, the most reusable formulation of `Q32_GROWING_WINDOW_APERY_GCD_RETURN`: it is a theorem about the distinguished Apéry sequence alone, with the q6 geometry frozen into two affine indices whose sum is `7q-1`.

It is substantially narrower than a general statement about `gcd(b_m,b_n)`.

## 11. Reproducible exact check plan

The following is a **regression checker**, not a proof of SGWR.

1. For each prescribed `(q,u)`, set

```text
m = 6*q + u
s = q - 1 - u
h = m - s = 5*q + 2*u + 1
```

and assert the exact geometry

```text
m + s == 7*q - 1
0 <= u < q/7
```

2. Compute exact Apéry integers and assert the structural factor

```text
b[m] % q == 0
b[s] % q == 0
G0 = gcd(b[m], b[s])
assert G0 % q == 0
G = G0 // q
```

3. Compute the exact index derivative `dot_b[u]` from the differentiated recurrence and the exact quotient-six Bockstein integer

```text
Y = (b[m] - b[6]*b[u]) // q
A = b[u] // q
```

then assert the first-divided reflection identity

```text
(b[s]//q - (A - dot_b[u])) % q == 0
```

and the lifted first-divided identity

```text
b[m]//q == b[6]*A + Y
```

4. Check the `q`-excess criterion exactly:

```text
q2_common = (b[m] % (q*q) == 0 and b[s] % (q*q) == 0)
first_divided_zero = (
    (A - dot_b[u]) % q == 0
    and (b[6]*A + Y) % q == 0
)
assert q2_common == first_divided_zero
```

5. Build the exact continuant `N_h(s)` and transfer identity. For every prime factor `ell` of `G` with `ell>m`, verify

```text
min(v_ell(b[s]), v_ell(b[m])) \
    == min(v_ell(b[s]), v_ell(N_h(s)))
```

Do **not** make this assertion for `ell<=m` unless the exact transfer denominator is first proved to be an `ell`-unit.

6. For `ell<=m`, use Lucas only as a radical diagnostic: write `s` and `m` in base `ell` and verify that each contains an `ell`-zero digit. Do not infer the valuation of `G` from this radical check.

7. Finally print the exact decomposition

```text
q_excess = (min(v_q(b[m]),v_q(b[s])) - 1) * log(q)
foreign = sum(
    min(v_l(b[m]),v_l(b[s])) * log(l)
    for l != q
)
```

and verify that it equals `log(G)` up to the chosen exact/logarithmic representation.

The purpose of this checker is to prevent three common false positives: silently using reflection mod `q^2`, cancelling a singular continuant pivot, or replacing valuation multiplicity by a radical.

## 12. Sharp scope of the negative conclusion

What is proved here is **not** that SGWR is false. The conclusion is:

* the one structural factor `q` is proved exactly;
* the residual height decomposes exactly as (0.6);
* the current reflection machinery does not prove the all-prime `q`-excess lemma;
* the current Lucas theorem controls foreign returns only at radical level;
* the current recurrence/continuant theorem gives a valuation-exact return only in transfer-unit characteristics, e.g. `ell>m`;
* the Wronskian supplies projective regularity but no return-frequency/height estimate;
* the remaining trivial Archimedean estimate is critical, not subcritical.

Therefore a proof of the requested

\[
o_J(T^2/\log T)
\]

aggregate requires a genuinely new arithmetic input. It cannot be obtained by merely recombining the existing local identities without an additional average-return or first-divided theorem.

No currently banked recurrence/Lucas/reflection/Wronskian theorem makes the sum of these terms `o_J(T^2/log T)`.

The smallest complete new theorem is the valuation-weighted **stripped growing-window Apéry return estimate** SGWR (0.8), or equivalently the two-piece package (6.6)+(6.7). The genuinely new global content is (6.7); the `q`-primary piece has the exact first-divided local target (3.6).

That is the live arithmetic frontier: not another star-injectivity argument, not another radical carrier, and not a finite scan, but an average common-return theorem for the distinguished Apéry orbit along the affine anti-diagonal

\boxed{(s,m)=(q-1-u,\,6q+u),\qquad s+m=7q-1.}
