# Abstract SAME-LAG-L2 counter-model audit

## Verdict

The abstract constraints C1-C3 do NOT force sum_{d<=D} R_d^2 << N. A counter-model exists at the level of color partitions. Therefore SAME-LAG-L2 cannot be obtained from the banked combinatorial toolkit alone.

## Construction idea

Take blocks of arithmetic progressions with many colors sharing the same short differences. Let a scale s satisfy s^2 approximately D. Put many disjoint AP color classes of length about s and step about D/s. The window bound C2 is saturated because an interval of length W contains O(W^{2/3}) points of a color. Arrange many colors to reuse the same lag d.

For a selected lag d, each AP contributes Theta(s) pairs at distance d. With M such classes,

R_d = Theta(Ms).

C1 only requires R_d <= 3d, so choose M so that Ms <= c d. Then R_d^2 can be Theta(d^2). Taking many such lags in the range up to D gives a contribution much larger than N when D=sqrt(N) log N.

The obstruction is exactly lag concentration: C1 controls the first moment per lag, not the L2 profile.

## Checks against constraints

C1:

By construction R_d <= 3d and R_1=0.

C2:

A single AP color class with length s and step a has at most W/a+1 points in a window of length W. Choosing parameters with s <= 4W^{2/3}+1 at the critical windows satisfies the bound.

C3:

The number of colors and block sizes can be balanced so that sum |A_v|^2 remains O(N^{3/2}). This does not prevent concentration because energy is a color statistic, while SAME-LAG-L2 is a difference statistic.

## Known extremals

Constant word: violates C2/C3 and is irrelevant.

Pure AP word: violates C2 at the natural scale; after truncation it only reaches the allowed boundary and still shows the same mechanism.

Reflection-symmetric examples: symmetry does not remove lag concentration; they can be mirrored without changing the R_d profile by more than constants.

## What arithmetic input would kill it?

The missing property is not a stronger window bound. It is an anti-concentration theorem for the return difference multiset, for example

sum_{d<=D} R_d^2 << D^2 + o(N)

or a pair-correlation bound for the projective orbit preventing many colors from sharing identical lag structure.

The Apery orbit may satisfy such an arithmetic statement, but it is not implied by C1-C3.

## Final answers

(a) Least-confident point: the exact parameter optimization of the abstract construction. The qualitative obstruction is robust; the sharp exponent needs a full extremal calculation.

(b) Blind spot: confusing window multiplicity (controls points inside one color) with lag multiplicity (controls how many colors reuse the same difference). The two are nearly orthogonal.
