# P3.2 global-matrix attack: exact row-sharing obstruction and the smallest surviving lemma

## Verdict

**No `O(H^3 polylog H)` global Macaulay/evaluation complex is obtained from the presently proved recurrence and root-strip package.** More specifically:

1. The usual pair Sylvester complex already has only `Theta(H^3)` total row dimension. Its loss is coefficient height: expanding `N_h` makes each block have logarithmic row height `O(H log H)`, and Hadamard gives the known total `O(H^4 log H)` determinant-height budget.
2. The recurrence does provide a genuinely small-coefficient representation of each `N_h`: the tridiagonal continuant in `meso_result.tex`. But replacing expanded Sylvester coefficients by a strong linearization turns common-root detection into an **intertwiner/Kronecker problem** of dimension `d_h d_k`, not `d_h+d_k`. Summed over `h+k<H`, the dimension is exactly `9 binom(H-1,4)=Theta(H^4)`, with only `O(log H)` entry heights. Thus the same `H^4` returns on the dimension side.
3. A genuinely shared coefficient-row space cannot have corank equal to the **sum** of pair root multiplicities. In dual form, row sharing replaces a direct sum of pair annihilators by a compatibility/intersection subspace. If the same evaluation `ev_r` occurs for several pairs, it is one functional after sharing, whereas `T_p(H)` charges it once for every pair. Pair labels are therefore not optional: independence across pairs comes only from separate label directions.
4. The exact recurrence restart identity does not rescue the situation. It implies

```text
Res(N_h(X), N_{h+k}(X))
 = Res(N_h(X), N_{h+1}(X))
   * Res(N_h(X), N_k(X+h)).
```

Hence replacing the shifted pair by a shared endpoint pair preserves the entire original shifted resultant as a factor and adds an adjacent resultant. It cannot lower the product-height budget.
5. A higher determinantal-divisor/discriminant construction can recover pair multiplicity from shared root data, but then it is algebraically the cross-resultant product (or its square inside a discriminant) and again has `O(H^4 log H)` height. `lcm` reduces height only by replacing the needed **sum** of `p`-adic valuations by a **maximum**, so it loses exactly the multiplicity that `T_p(H)` asks for.

So the tactical classification is:

```text
shared scalar rows, first-order corank:     FALSE for the required sum
restart / shared endpoint resultants:       NO GAIN (exact factorization)
small-entry recurrence linearization:       VALID, but Theta(H^4) dimension
product/discriminant/Fitting amplification: VALID, but O(H^4 log H) height
O(H^3 polylog H) global certificate:        OPEN
```

The smallest viable new statement is a **pair-labelled low-height evaluation-lifting lemma** stated precisely in Section 9. The current source proves its within-pair independence but not its cross-pair directness; ordinary row sharing makes that cross-pair condition false.

## 1. Exact pair Macaulay map and why the direct sum has only `Theta(H^3)` rows

Put

```text
d_h := deg N_h = 3(h-1).
```

For one pair

```text
e=(h,k),
2 <= h,
2 <= k,
h+k < H,
```

write

```text
f_e(X) := N_h(X),
g_e(X) := N_k(X+h),
D_e    := d_h+d_k = 3(h+k-2).
```

Over any field `F`, the scalar Sylvester/Macaulay map is

```text
S_e : F[X]_{<d_k} (+) F[X]_{<d_h}  ->  F[X]_{<D_e},
S_e(A,B) = A f_e + B g_e.
```

The source and target have the same dimension `D_e`; in the monomial bases this is the usual Sylvester matrix.

Let

```text
R_e(F)
 := { r in F : f_e(r)=0 and g_e(r)=0 }.
```

For every `r in R_e(F)`, evaluation

```text
ev_r : F[X]_{<D_e} -> F
```

annihilates `im S_e`. Distinct common roots give independent evaluation functionals: if `r_1,...,r_m` are distinct, then `m <= d_h <= D_e`, and the matrix of evaluations on

```text
1,X,...,X^{m-1}
```

is the Vandermonde matrix. Therefore

```text
corank_F S_e >= #R_e(F).                       (1.1)
```

For the actual finite fields in the question, `p>H` and `h,k<H`; the proved nonzero-polynomial property rules out the pathological case `N_h == 0 mod p`.

Over `Q`, `meso_result.tex` proves that the roots of `N_h(X)` lie in

```text
-h < Re X < -1,
```

while the roots of `N_k(X+h)` lie in

```text
-h-k < Re X < -h-1.
```

The strips are disjoint, so `S_e` is invertible over `Q`.

Now form the direct sum

```text
S_dir := (+)_{e in J_H} S_e,
J_H := {(h,k): h,k>=2, h+k<H}.
```

Then

```text
corank_Fp S_dir
 = sum_e corank_Fp S_e
 >= T_p(H).                                     (1.2)
```

The total row dimension is not `H^4`; it is exactly cubic. If `s=h+k`, there are `s-3` pairs with that sum, hence

```text
sum_{e in J_H} D_e
 = 3 sum_{s=4}^{H-1} (s-3)(s-2).
```

Writing `m=H-4`,

```text
3 sum_{t=1}^m t(t+1)
 = m(m+1)(m+2),
```

so

```text
dim S_dir
 = (H-4)(H-3)(H-2)
 = Theta(H^3).                                  (1.3)
```

This exact count is important: **the present loss is not the number of Sylvester rows.** It is the height of those rows after the `N_h` are expanded.

## 2. Where the fourth power enters the expanded Sylvester height

Let `||F||_1` denote the coefficient `l^1` norm of an integral polynomial. From

```text
N_{h+1}
 = P(X+h) N_h - (X+h)^6 N_{h-1}
```

and the fact that the coefficients of `P(X+h)` are `O(h^3)` while

```text
||(X+h)^6||_1 = (h+1)^6,
```

one gets an elementary recurrence

```text
||N_{h+1}||_1
 <= C h^6 ( ||N_h||_1 + ||N_{h-1}||_1 ).
```

Therefore

```text
log ||N_h||_1 = O(h log h).                    (2.1)
```

A pair Sylvester matrix has `D_e=O(H)` rows and entries of bit height `O(H log H)`. Hadamard gives, for one pair,

```text
log |det S_e| = O(H^2 log H).                  (2.2)
```

There are `Theta(H^2)` pairs, so the direct-sum determinant satisfies the stated scale

```text
log |det S_dir| = O(H^4 log H).                (2.3)
```

This is exactly the `H` which one would like to remove.

## 3. Exact shared-row obstruction in dual form

The tempting operation is to identify equal monomial coefficient rows used by many pair blocks.

Abstract the situation. For each pair `e`, let

```text
S_e : U_e -> V_e
```

be its Macaulay map. A row-sharing construction chooses maps

```text
q_e : V_e -> V
```

into one common row space and forms

```text
S_sh : (+)_e U_e -> V,
S_sh((u_e)_e) = sum_e q_e S_e(u_e).            (3.1)
```

Dualizing gives the exact identity

```text
(coker S_sh)^*
 = { lambda in V^* : q_e^*(lambda) annihilates im S_e for EVERY e }.
                                                        (3.2)
```

Equivalently, the natural map

```text
(coker S_sh)^*
   -> product_e (coker S_e)^*,
lambda |-> (q_e^* lambda)_e
```

lands in a **compatibility subspace**, not in the direct sum of independently selectable pair annihilators.

For canonical monomial-row sharing, all `V_e` sit in one polynomial space. If the same field element `r` is a common root for `m` different pairs, then every one of the pair functionals is literally

```text
ev_r.
```

After rows are identified there is only one functional `ev_r`. Thus

```text
m pair defects  --->  1 shared-row defect.              (3.3)
```

This is not a dimension heuristic. It is the equality (3.2): row sharing changes a direct sum of annihilators into a compatibility/intersection condition.

The only way to keep the `m` copies independent is to attach independent pair labels. For example one may replace the common row space by

```text
V (+) labels
```

or, more canonically,

```text
V tensor L,
```

with vectors `ell_e in L`, so that the pair root is represented by

```text
ev_r tensor ell_e^*.
```

For all `m` copies at the same `r` to be independent, the relevant label directions must have rank at least `m`.

Hence:

> **Shared-row no-sum lemma.** A global corank argument can add the common-root multiplicities of different pairs only if those pair defects remain linearly independent in the global dual cokernel. Identifying their evaluation rows identifies the corresponding defect directions. Independence within each pair, which is what the Vandermonde argument proves, is not cross-pair independence.

This is exactly the missing logical step in any claim of the form

```text
"all pairs use the same polynomial/evaluation rows,
 therefore we may count all pair common roots with one corank".
```

The implication is backwards: sharing the rows is precisely what destroys the sum.

## 4. The recurrence gives a small-entry linearization -- but its common-root space is a tensor product

The preceding obstruction is not saying that the recurrence is useless. It gives a very clean **alternative certificate** whose entries have only polynomial size.

From `meso_result.tex`, `N_h` is the determinant of the `(h-1) x (h-1)` cubic matrix polynomial

```text
A_h(X)
```

with

```text
(A_h)_{ii}     = P(X+i),
(A_h)_{i,i+1}  = (A_h)_{i+1,i} = (X+i+1)^3.
```

All coefficients of this cubic matrix polynomial are `H^{O(1)}` for `h<=H`. A standard block companion linearization therefore gives a regular integral pencil

```text
L_h(X) = X E_h - F_h
```

of size

```text
3(h-1) = d_h,                                  (4.1)
```

with

```text
det L_h(X) = +/- N_h(X)
```

and entries of bit height `O(log H)`. The leading cubic coefficient matrix has diagonal `34` and off-diagonal `1`, hence is nonsingular over `Q`; there are no infinite eigenvalues over `Q`.

For the shifted polynomial `N_k(X+h)`, use the shifted pencil

```text
L_{k,h}(X)=X E_{k,h}-F_{k,h};
```

its entries are still `H^{O(1)}`.

Now common finite eigenvalues of two regular pencils are detected by the generalized Sylvester/intertwiner operator

```text
K_{h,k}
 := F_h tensor E_{k,h}
    - E_h tensor F_{k,h}.                       (4.2)
```

Indeed, if `r` is a common root, choose nonzero vectors `v,w` with

```text
F_h v       = r E_h v,
F_{k,h} w   = r E_{k,h} w.
```

Then

```text
K_{h,k}(v tensor w)=0.                          (4.3)
```

For distinct common finite roots, regular-pencil primary decomposition gives independent kernel directions. Hence

```text
corank_Fp K_{h,k}
 >= #{r in F_p : N_h(r)=N_k(r+h)=0}.            (4.4)
```

Over `Q`, the root strips are disjoint, so `K_{h,k}` is nonsingular.

This is a perfectly valid small-entry certificate. But its dimension is

```text
d_h d_k = 9(h-1)(k-1),                         (4.5)
```

because an intertwiner is an element of

```text
Hom(V_k,V_h) ~= V_h tensor V_k^*.
```

Summing exactly over the triangular pair range, put

```text
a=h-1 >=1,
b=k-1 >=1,
a+b <= H-3.
```

The elementary identity

```text
sum_{a,b>=1, a+b<=L} a b = binom(L+2,4)
```

gives

```text
sum_{h,k>=2, h+k<H} d_h d_k
 = 9 binom(H-1,4)
 = Theta(H^4).                                  (4.6)
```

Since the entries of every `K_{h,k}` are `H^{O(1)}`, Hadamard now gives

```text
log |det (+ K_{h,k})|
 = O(H^4 log H).                                (4.7)
```

So the recurrence trades

```text
small dimension + tall coefficients
```

for

```text
tall dimension + small coefficients,
```

but it does not change the fourth power.

This is the concrete algebraic reason the obvious recurrence-linearized Macaulay route does not produce the requested `H^3 polylog H` certificate.

## 5. Exact restart identity and why the shared-endpoint idea does not compress anything

There is a stronger identity than the bare recurrence. For all `h,k>=1`,

```text
N_{h+k}(X)
 = N_{h+1}(X) N_k(X+h)
   - (X+h+1)^6 N_h(X) N_{k-1}(X+h+1).          (5.1)
```

Proof: for fixed `h`, both sides as functions of `k` satisfy the same second-order recurrence in the tail variable; equality at `k=1,2` is immediate from `N_1=1`, `N_0=0` and the defining recurrence.

Therefore every pair common root satisfies

```text
N_h(r)=0,
N_k(r+h)=0
        =>
N_{h+k}(r)=0.                                  (5.2)
```

So one might try to replace the shifted pair by the two unshifted endpoint polynomials

```text
N_h(X), N_{h+k}(X)
```

and then share all `N_s` rows globally.

The exact resultant calculation shows that this gains nothing.

Let

```text
R_{h,k}
 := Res_X(N_h(X),N_k(X+h)).
```

Take the root product of (5.1) over the roots `alpha` of `N_h`. On those roots the second term vanishes, so

```text
N_{h+k}(alpha)
 = N_{h+1}(alpha) N_k(alpha+h).
```

Also

```text
deg N_{h+k}
 = deg N_{h+1} + deg N_k
 = 3(h+k-1).
```

Thus the leading-coefficient powers in the root-product definition of the resultant match exactly, and one obtains

```text
Res_X(N_h,N_{h+k})
 = Res_X(N_h,N_{h+1}) * R_{h,k}.               (5.3)
```

No omitted scalar occurs.

The adjacent resultant is a nonzero integer; the recurrence itself gives its familiar recursive formula. Hence

```text
|Res(N_h,N_{h+k})|
 >= R_{h,k}                                     (5.4)
```

because `meso_result.tex` proves `R_{h,k}>0` and the other factor has absolute value at least `1`.

Even globally, if

```text
m_h = #{ k>=2 : h+k<H } = H-h-2,
```

then

```text
product_{h,k} Res(N_h,N_{h+k})
 = [product_{h,k} R_{h,k}]
   * product_h Res(N_h,N_{h+1})^{m_h}.          (5.5)
```

So the endpoint packaging is not a compressed carrier. It is the original pairwise carrier multiplied by repeated adjacent factors.

This exact factorization is the first hard obstruction to a “reuse the row for `N_{h+k}`” argument.

## 6. Unshifted pairwise coprimality over `Q` does not improve the height

For completeness, the restart identity plus the root strip also proves that the unshifted family is pairwise coprime over `Q`.

Suppose `s>h` and a complex number `alpha` satisfies

```text
N_h(alpha)=N_s(alpha)=0.
```

Put `k=s-h`. Equation (5.1) gives

```text
0 = N_{h+1}(alpha) N_k(alpha+h).                (6.1)
```

The first factor cannot vanish together with `N_h`: if `N_h=N_{h+1}=0`, the recurrence propagates backwards because `alpha` is strictly inside the root strip and hence is not a singular boundary point; eventually one obtains `N_1(alpha)=0`, impossible.

The second factor cannot vanish either. From the root strip for `N_h`,

```text
-h < Re alpha < -1,
```

so

```text
Re(alpha+h) > 0.
```

But every root of `N_k` has real part `<-1`. Contradiction.

Therefore

```text
gcd_Q[X](N_h,N_s)=1 for h!=s.                  (6.2)
```

This permits one to form a nonzero global cross-resultant product, but (5.3) shows that on the relevant pairs it still contains every original shifted resultant. Thus `Q`-coprimality guarantees nonzero certificates; it does not compress their Archimedean height.

## 7. Why a product/discriminant or `lcm` does not beat the fourth power

There are two opposite ways to aggregate pair certificates. Each fails for an exact reason.

### 7.1 Product / discriminant: preserves the sum, preserves the height loss

Let

```text
F_H(X) = product_{j=2}^{H-1} N_j(X).
```

Its degree is

```text
D_H
 = sum_{j=2}^{H-1} 3(j-1)
 = 3(H-2)(H-1)/2
 = Theta(H^2).                                  (7.1)
```

Also, from (2.1),

```text
log ||F_H||_1
 <= sum_j log ||N_j||_1
 = O(H^2 log H).                                (7.2)
```

A discriminant/subresultant of `F_H` therefore has the generic deterministic height bound

```text
O(D_H * (log ||F_H|| + log D_H))
 = O(H^4 log H).                                (7.3)
```

More importantly, its cross part is exactly made of pairwise resultants:

```text
Disc(product_j N_j)
 = self-discriminant factors
   * product_{h<s} Res(N_h,N_s)^2
   * leading-coefficient factors.               (7.4)
```

Thus the reason a shared discriminant can see repeated root multiplicity is precisely that it reinstates all pair resultants. There is no hidden `H^3` compression.

One can avoid possible self-discriminant issues entirely and use only the nonzero cross product

```text
D_cross(H)
 := product_{2<=h<s<=H-1} |Res(N_h,N_s)|.
```

For the endpoint pairs `s=h+k`, (5.3) shows that `D_cross` contains the original shifted certificates. Again the height is not smaller.

### 7.2 `lcm`: lowers height by throwing away the required additive valuation

If instead one uses

```text
L_H := lcm_{(h,k) in J_H} |R_{h,k}|,
```

then for every prime `p`

```text
v_p(L_H) = max_{h,k} v_p(R_{h,k}).              (7.5)
```

But pairwise Sylvester gives

```text
T_p(H)
 <= sum_{h,k} v_p(R_{h,k}),                     (7.6)
```

and there is no implication from the sum to the maximum without a new overlap theorem. The whole target is precisely the possibility that one prime contributes to many pairs.

So:

```text
product  -> correct SUM of valuations, H^4 height;
lcm      -> smaller height, only MAX valuation;
gcd      -> even less information.
```

This is the exact valuation direction. Any argument that silently replaces the product by an `lcm` has changed the target.

## 8. Determinantal divisors do not bypass the independence issue for free

The question allows a determinantal-divisor valuation rather than literal corank, so this case must be separated carefully.

Let an integral matrix `M` have full column rank over `Q`, and let `Delta(M)` be its top determinantal divisor (the gcd of its maximal minors). Smith normal form gives the exact implication

```text
rank deficiency of M mod p = c
        =>
v_p(Delta(M)) >= c.                            (8.1)
```

Thus a rectangular global complex is sufficient if its **actual mod-p deficiency already contains one independent direction for every pair root**.

But a determinantal divisor cannot create those directions after row sharing. If `m` pair evaluations have been identified with one shared `ev_r`, the matrix has one defect direction, so (8.1) guarantees only one factor of `p`, not `p^m`.

One can deliberately amplify a shared defect by taking exterior/compound constructions. At a point where a shared kernel has dimension `z`, an exterior-square defect can contain

```text
dim wedge^2(kernel) = binom(z,2).
```

This is the right combinatorial shape for pair multiplicities. However, algebraically the exterior-square/common-eigenvalue construction is exactly the pair-labelled tensor/intertwiner space from Section 4, or equivalently the cross-resultant/discriminant product from Section 7. The missing factor of `H` reappears as either

```text
Theta(H^4) small-entry tensor dimension
```

or

```text
O(H^4 log H) expanded determinant height.
```

So higher Fitting/compound operations can restore the multiplicity, but not at zero complexity cost.

## 9. The smallest viable rank/corank lemma

A full `O(H^3 polylog H)` construction remains open. The exact minimal statement that would make it work is the following.

### Pair-labelled low-height evaluation-lifting lemma

For every `H`, construct free integral modules `U_H,V_H` and an integral map

```text
M_H : U_H -> V_H
```

such that:

```text
rank U_H, rank V_H <= C H^3 polylog(H);         (L1)
```

`M_H` has full column rank over `Q`, and its maximal row/minor height obeys

```text
log HadamardHeight(M_H) <= C H^3 polylog(H);   (L2)
```

and, for every prime `p>H`, for each triple

```text
(h,k,r),
h,k>=2,
h+k<H,
N_h(r)=0,
N_k(r+h)=0,
```

there is a dual cokernel class

```text
lambda_{h,k,r} in (coker(M_H mod p))^*          (L3)
```

whose restriction to the `(h,k)` pair is the usual evaluation `ev_r`, with the crucial global condition

```text
{lambda_{h,k,r}}_{all pair roots}
are linearly independent over F_p.             (L4)
```

Then immediately

```text
corank_Fp(M_H) >= T_p(H).                       (9.1)
```

If `M_H` is square,

```text
T_p(H) <= v_p(det M_H).
```

In the rectangular case, (8.1) gives

```text
T_p(H) <= v_p(Delta(M_H)).                      (9.2)
```

Hadamard plus (L2) then gives the desired global budget

```text
T_p(H) log p <= O(H^3 polylog H).               (9.3)
```

### What is already proved, and what is missing

For each **individual pair**, the current Sylvester/evaluation argument proves the analogue of (L3)-(L4): distinct roots inside that one pair give independent evaluations.

What is **not** proved is (L4) after different pairs are placed in a shared row space. Ordinary row sharing makes it false, because it sends

```text
(h,k,r) and (h',k',r)
```

to the same `ev_r` whenever the same base field element occurs.

Therefore the smallest new algebra is not another resultant estimate. It is a low-height mechanism which preserves **pair labels in the defect space** while sharing enough of the coefficient-generation machinery to remove one factor of `H` from the Archimedean height.

That is a genuine new determinantal-complex problem.

## 10. Tactical conclusion

The proposed global-matrix direction splits cleanly into three layers.

### Layer A: defect counting

The exact per-pair evaluation map works:

```text
one common root -> one independent dual defect,
```

but only within a fixed pair. Summing defects requires pair labels.

### Layer B: coefficient compression

The recurrence/tridiagonal continuant gives coefficient compression to `O(log H)` bits, but a common-root detector built without expanded coefficients naturally acts on the intertwiner space

```text
Hom(V_k,V_h),
```

whose dimension is the product `d_h d_k`. Summed over the triangular family this is `Theta(H^4)`.

### Layer C: attempted global sharing

Restarting the recurrence to a common endpoint does not quotient out the old pair certificate:

```text
Res(N_h,N_{h+k})
 = adjacent_resultant * shifted_pair_resultant.
```

A product/discriminant keeps the required sum and therefore keeps the fourth-power height; an `lcm` lowers height only by replacing the sum by a maximum.

Accordingly, **the present exact algebra gives an obstruction, not the requested global complex**. The obstruction is sharper than generic dimension counting:

```text
sharing evaluation rows changes direct-sum annihilators
into a compatibility/intersection space,
so repeated pair occurrences of the same evaluation lose multiplicity;
restoring that multiplicity forces pair-labelled tensor/exterior directions,
and every currently available low-coefficient realization of those directions
has Theta(H^4) total size.
```

The only viable next step is to prove the pair-labelled low-height evaluation-lifting lemma above, or a strictly stronger Apéry-specific theorem that bounds cross-pair overlap so that labels can safely be merged. Neither follows from the current recurrence, root-strip coprimality over `Q`, or within-pair evaluation independence.
