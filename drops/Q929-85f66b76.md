# Q929 — secondary Hecke-transverse frontier audit

## Conclusion

No unconditional block resultant/subresultant with the requested two properties is obtained from the stated data.  More precisely, in the natural algebraic closure generated by the finite set of row variables

```
K_R = Q(b_s, kappa_s : R < s <= 2R)
```

there is a valuation-coupling obstruction: every determinant whose vanishing detects the labeled pairs

```
p | b_r,   p | Xi_r,   R < r <= 2R,   p > 2R
```

must contain, after specialization, a factor carrying the same row content as the product of the row gcds, unless it introduces additional equations relating different rows.  The available canonical relation and the nonvanishing of

```
b_s Xi_r - b_r Xi_s
```

provide separation of rows but not a bounded-height elimination relation among all singleton primes.

Thus the desired object is not the ordinary resultant of the rows, nor a Gauss-content primitive part of such a resultant.

## 1. Why the obvious resultants fail

Let

```
G_r(X)=b_r X + Xi_r.
```

A block resultant

```
Res_X( product_{R<r<=2R} G_r(X), H(X) )
```

can only count common roots after a common auxiliary variable X has been imposed.  The condition

```
p | b_r and p | Xi_r
```

is a root condition modulo p for the individual polynomial G_r, but the singleton prime may occur at a different residue class for each r.  There is no common X forced by the Hecke contact law.  Consequently a determinant built only from the G_r has no valuation identity of the form

```
v_p(det) = sum_r min(v_p(b_r),v_p(Xi_r)).
```

unless the determinant has inserted row-wise content factors.

## 2. Gauss-content audit

Suppose a candidate block determinant D_R satisfies the desired valuation law.  Factor its entries over the UFD generated by the row data.  If a prime p divides only one row pair (the singleton case), then all p-adic divisibility of D_R must enter through that row's ideal

```
I_r=(b_r,Xi_r).
```

Without a cross-row algebraic relation, the p-primary part of the determinant ideal is therefore contained in the extension of I_r.  Taking primitive parts removes exactly this information; retaining it reproduces

```
product_r gcd(b_r,Xi_r).
```

Hence primitive Gauss removal and exact singleton valuation are incompatible in the row-independent closure.

## 3. The role of the canonical relation

The identity

```
Xi_r=r^3(b_(r-1) kappa_r-b_r kappa_(r-1))
```

and the nonvanishing relation

```
b_s Xi_r-b_r Xi_s != 0   (r != s)
```

prove that two rows cannot have proportional Hecke-transverse directions.  This is useful for excluding repeated-column concentration.  However it does not produce a polynomial relation of small degree in the singleton prime p, because the relation still contains independent values of the canonical solution at indices r and s.

Therefore a Sylvester determinant in the r-index direction has height controlled by the size of the Apéry data, not by the desired o(R^2) scale.

## 4. Scoped no-go statement

For the algebraic closure

```
Q(b_s,kappa_s : R < s <= 2R)
```

and for determinants constructed only by polynomial elimination in these row variables and the individual pairs (b_r,Xi_r), there is no known determinant D_R satisfying simultaneously:

```
(1) v_p(D_R) >= sum_{R<r<=2R} min(v_p(b_r),v_p(Xi_r))
    for every p>2R,

(2) log |D_R| = o(R^2),

(3) D_R is primitive after removal of explicit universal Hecke factors.
```

The obstruction is that (1) forces retention of singleton row ideals while (3) removes exactly those ideals.  A successful construction must use a genuinely new source relation, not merely elimination from the existing row coordinates.

## 5. What remains needed for the main theorem

Even a hypothetical bound

```
log F_R=o(R^2)
```

would only control the secondary aggregate.  The missing edge is a row-to-pointwise anti-concentration statement:

```
small total exceptional prime mass in dyadic blocks
    => each individual r has negligible exceptional contribution.
```

The block estimate alone permits concentration on a sparse set of rows.  One still needs a mechanism converting the aggregate Fitting control into a uniform or density-one statement for the original Apéry indices.

Therefore the correct frontier is not another repeated-column moment.  It is either:

1. a new canonical-source elimination identity coupling different r before taking content; or
2. a separate arithmetic anti-concentration theorem converting block Fitting mass into pointwise control.

Neither follows from the currently available recurrence, quotient-one contact law, or monotonicity relation alone.
