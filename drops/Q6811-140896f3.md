## 1. Normalization and no-wrap checks

Assume q=o(p). The intervals are interpreted in F_p but have their integer representatives because
2q-1<p.

Let

J=[a,a+q-1], C=[0,q-1], A=[a-q+1,a+q-1].

Then |C|=q, |A|=2q-1. Since the diameter of A+C is 3q-2<p, there is no cyclic collision in the sumset calculation. For x in F_p,

(1_A*1_C)(x)=#{c in C:x-c in A}.

For x in J, the q choices c=0,...,q-1 all satisfy x-c in A, hence

1_A*1_C=q on J.

Outside J, the convolution is a triangular taper, with values between 0 and q-1. Therefore

W=q^{-1}(1_A*1_C)

satisfies

W>=1_J,
0<=W<=1,

and the weighted incidence sum dominates the physical nonwrapping shell. There is no hidden wrap term under 2q-1<p.

The total mass is exact:

sum_x W(x)=q^{-1}|A||C|=2q-1.

## 2. Fourier normalization

Use the unnormalized transform

fhat(xi)=sum_x f(x)e_p(-xi x).

Then

What=q^{-1} Ahat Chat.

Parseval gives

sum_xi |Ahat(xi)|^2=p|A|=p(2q-1),
sum_xi |Chat(xi)|^2=pq.

Hence Cauchy-Schwarz gives the sharp displayed estimate

sum_xi |What(xi)|
<=q^{-1}(p(2q-1))^{1/2}(pq)^{1/2}
=p sqrt((2q-1)/q)
<sqrt(2)p.

This is the correct proof. Any argument using sum W^2 <= (2q-1)/q is invalid: W=1 on q points already forces sum W^2>=q.

## 3. Exact Fourier identity for the determinant kernel

For

F_t(xi)=sum_{r,d} e_p(t det(u_r,u_{r+d})+xi d),

and

B_W(t)=sum_d W(d)sum_r e_p(t det(u_r,u_{r+d})),

Fourier inversion gives exactly

B_W(t)=p^{-1}sum_xi What(-xi)F_t(xi).

No extra p factors appear: the factor p^{-1} is precisely the inversion normalization.

If

max_{t!=0,xi}|F_t(xi)|<=Cp,

|B_W(t)|<=p^{-1}(Cp)sum_xi|What(xi)|

Thus smoothing removes the previous logarithmic loss. It does not give power saving.

The obstruction is still the complete determinant estimate.

### (ii) Averaged-in-t bounds

The exact weighted Cauchy formula is

sum_t |B_W(t)|^2
<=p^{-2}(sum_xi |What(xi)|^2)(sum_{t,xi}|F_t(xi)|^2)

if one uses the two-dimensional Cauchy inequality.

Here

sum_xi |What(xi)|^2=p sum_d W(d)^2.

This is the correct weight norm. The smoothing gives

sum_d W(d)^2 <= q

(up to the exact triangular correction), not the earlier false expression. Therefore L2 control of F helps only if it beats the trivial determinant energy by a genuine amount.

An L1-in-t estimate similarly gives

sum_t |B_W(t)|
<=p^{-1}sum_xi |What(xi)|sum_t|F_t(xi)|.

The factorized weights help only by the Fourier L1/L2 norms above; no independence between t and xi is available.

### (iii) Power-saving complete bound

If

max_{t,xi}|F_t(xi)|<=p^{1-kappa},

then

|B_W(t)|<=p^{-1}p^{1-kappa} sqrt(2)p
=O(p^{1-kappa}).

This is a genuine saving over O(p), but only after converting the weighted incidence estimate into the final shell union bound.

## 5. Effect on the target union

The weighted count satisfies

Z_W=sum W + (1/p)sum_{t!=0}B_W(t).

The main term is O(q)=O(D). The error is controlled by the available t-average.

A bound O(p^{1-kappa}) uniformly for all t gives total error

O(p^{-1} p * p^{1-kappa})=O(p^{1-kappa})

(up to the nonzero t count normalization).

This is still an incidence bound. To imply

U_B<<D^{2-eta},

one needs p^{1-kappa}<<D^{2-eta}.

Since D=p^{1/2}L, this requires

p^{1-kappa} << p^{1-eta/2}L^{2-eta},
