# Rigid ancestor and symmetric square decomposition of the Apéry system

## Executive summary

The proposed `z ↦ z + 1/z` explanation is a useful symmetry observation, but it is not the correct decomposition of the Apéry motive.

The key points are:

1. The Apéry Picard-Fuchs equation is genuinely **order 3**, not order 2.
2. The order-3 system is the symmetric square of a rank-2 system (the elliptic/modular ancestor), up to the usual Tate normalization.
3. The involution `z ↦ 1/z` explains a symmetry of singularities, but it does not reduce the rank-2 ancestor to a rank-1 Kummer sheaf.
4. Therefore the Gauss-sum argument does not apply. The Mellin coefficients are not products of nonvanishing Gauss sums; they remain genuine hypergeometric character sums.

The missing AFP theorem is therefore still a rank-2/rank-3 hypergeometric monodromy anti-cancellation statement.

## (A) Order of the Apéry differential equation

The displayed operator

```
θ^3 - z(2θ+1)(17θ^2+17θ+5) + z^2(θ+1)^3
```

is the Apéry Picard-Fuchs operator. It has order 3.

The recurrence has length 2 because a scalar recurrence of order two corresponds to a third-order differential equation for the generating function. The generating function has three independent local solutions.

The associated local system therefore has rank 3.

The rank-2 object appears only after the symmetric-square decomposition:

```
Rank 3 Apéry local system ≅ Sym^2(Rank 2 system)
```

This is the crucial correction.

## (B) The `z + 1/z` map does not give a rank-1 ancestor

The identity

```
z^2 - 34z + 1 = z(z + 1/z - 34)
```

shows that the two finite singularities are exchanged by the involution.

However, quotienting by the involution does not lower the rank in this way:

```
rank 2 on z-line
     |
     f_* or pullback
     |
rank 1 on w-line
```

would require the original representation to be induced from a character. The Apéry monodromy is not induced from a character.

A rank-1 Kummer system has abelian monodromy. The Apéry ancestor has nonabelian monodromy (the relevant group is Zariski dense in SL_2 after normalization).

Thus the double cover is a geometric symmetry, not a Kummer descent.

## (C) Correct decomposition: symmetric square

The correct picture is:

```
rank-2 F-crystal V
        |
        v
Sym^2(V)
        |
        v
rank-3 Apéry crystal C
```

If the rank-2 Frobenius eigenvalues are

```
α, β
```

then the rank-3 eigenvalues are

```
α^2, αβ, β^2
```

(up to Tate twists).

The trace is therefore

```
Tr(C) = α^2 + αβ + β^2
```

not a single Gauss sum and not a product of Gauss sums.

Modulo p, cancellation can occur because

```
α^2 + αβ + β^2 = 0
```

has genuine solutions.

This explains why Apéry zeros exist.

## (D) What happens to the Mellin transform?

The Mellin coefficient is a hypergeometric character sum. Schematically:

```
b_r = Σ_t θ(t) χ_r(t)
```

where θ is the trace function of Sym^2(V).

Using the rank-2 ancestor, θ is built from products of rank-2 Frobenius data, but the character sum does not factor into independent Gauss sums.

The obstruction is the middle term:

```
αβ
```

and the interaction between the two eigenvalue sheets.

Only for induced rank-1 systems does one obtain a factorization into Gauss sums.

The Apéry motive is exactly outside that easy class.

## (E) Effect of ramification at z = ±1

The branch points of

```
w=z+1/z
```

are important, but they do not create the desired factorization.

They modify the local monodromy and add singularities in the quotient coordinate. In sheaf language, the pushforward acquires nontrivial local monodromy contributions at the branch points.

These contributions are responsible for the extra hypergeometric structure. They prevent the Mellin transform from collapsing to a Jacobi/Gauss-sum calculation.

## (F) What is the correct rigid ancestor?

The right ancestor is not rank 1. It is rank 2.

The expected chain is:

```
rigid rank-2 hypergeometric system
              |
              v
symmetric square
              |
              v
Apéry rank-3 system
              |
              v
Hasse-Witt trace / Mellin coefficients
```

The AFP problem should therefore be attacked through rank-2 monodromy and symmetric-square trace distributions.

## Consequence for AFP

The tempting theorem:

```
overconvergent + double-cover symmetry
=> bounded zeros by Stickelberger
```

is false because the Apéry system is not a Kummer-induced representation.

The stronger and plausible statement is:

```
For the symmetric square of a geometrically irreducible rank-2 hypergeometric sheaf
with large monodromy, the character Mellin transform has O(1)
vanishing characters.
```

This is a genuine monodromy/trace-function theorem, not a Gauss-sum theorem.

The rigid ancestor route survives, but the ancestor is `SL_2`, not `G_m`.
