# Spatial and frequency mollification for Apéry (HM)_3

## Executive conclusion

The proposed mollification idea is insightful, but frequency truncation cannot work in the present form. The obstruction is structural: Apéry zero indicators are sparse point masses on F_p, and point masses have flat Fourier spectra. A spatial mollification is more promising, but only if it is interpreted as an algebraic approximation (not analytic smoothing). The best route is likely a hybrid:

1. Construct a low-complexity algebraic majorant/minorant for 1_{Z_p} using the gap-polynomial description of Z_p.
2. Prove the third moment for these algebraic envelopes using trace-function technology.
3. Control the envelope error using the known |Z_p|=O(p^{2/3}) and gap bounds.

A naive smooth approximation does not reduce the conductor enough.

## 1. Why Fourier mollification fails

Write

$$g_p(x)=1_{Z_p}(x)=\sum_a \widehat g_p(a)e_p(ax).$$

For a singleton zero set Z_p={z},

$$\widehat g_p(a)=p^{-1}e_p(-az).$$

Hence

$$|\widehat g_p(a)|=p^{-1}\quad(a\ne0).$$

There is no decay at high frequencies. The indicator is maximally non-smooth. Truncating at A=p^{1/3} loses approximately a proportion 1-A/p of the L2 energy.

More generally, for |Z_p|=k,

$$\widehat g_p(a)=p^{-1}\sum_{z\in Z_p}e_p(-az).$$

Random cancellation gives size about sqrt(k)/p, but it does not produce decay in a. Thus frequency cutoff does not produce bounded conductor in the sense required by Deligne estimates.

The conductor is attached to the algebraic complexity of the sheaf, not merely to the number of retained Fourier modes.

## 2. Exact spatial mollification problem

We seek a function F_p(x) satisfying:

* F_p(x)≈1 on Z_p;
* F_p(x)≈0 away from Z_p;
* F_p has bounded algebraic degree/conductor.

The natural construction is interpolation.

If Z_p={z_1,...,z_k}, then the exact indicator is

$$1_{Z_p}(x)=1-\prod_i(1-(x-z_i)^{p-1})$$

on F_p.

This has degree roughly k(p-1), which is useless.

A low-degree approximation would require replacing the exact delta function by a polynomial of degree D. But over F_p a polynomial cannot sharply separate arbitrary k points from the complement unless D is large. This is the finite-field analogue of the uncertainty principle.

For a singleton, any exact polynomial indicator requires degree p-1.

Therefore arbitrary spatial smoothing also fails if the only input is sparsity of Z_p.

## 3. The missing Apéry structure

The reason spatial smoothing remains interesting is that Z_p is not an arbitrary sparse set.

The gap polynomial gives:

$$N_h(X)=0$$

whenever h consecutive shifts hit the zero orbit. Its degree is 3(h-1), and its endpoint factorization gives strong arithmetic constraints.

Therefore instead of approximating 1_{Z_p}, one should approximate the event

"x is a zero of the Apéry orbit"

by polynomial relations involving the recurrence.

The object is not a polynomial in x alone, but a trace condition on the recurrence monodromy:

$$M(x+h-1)\cdots M(x)v_0=(*)$$

The zero event is a rank condition. This is naturally algebraic.

## 4. A viable replacement: algebraic envelopes

Define a truncated zero detector

$$F_{p,H}(x)=\sum_{h\le H}c_h N_h(x)^2.$$

Because N_h has degree O(h), this has controlled degree O(H). Choose H=p^\theta.

Properties desired:

1. F_{p,H}(x)≥1_{Z_p}(x).
2. Average excess mass

$$\sum_x(F_{p,H}(x)-1_{Z_p}(x))$$

is small.

Then the third moment of the envelope becomes a bounded-degree algebraic correlation problem:

$$\sum_m\sum_{p,q,r}F_p(m)F_q(m)F_r(m).$$

This is the setting where Deligne/Katz machinery can apply.

## 5. Relation to the K3/sheaf approach

The Apéry recurrence defines a rank-two l-adic local system. The zero condition is hitting a special projective point.

The original indicator has a conductor growing with p because it is a delta condition. The algebraic envelope replaces the delta by a bounded-complexity test function.

The expected estimate is of the form

$$\sum_m F_p(m)F_q(m)F_r(m)
=\frac{|Z_p||Z_q||Z_r|X^2}{pqr}+O(X^{2-\delta})$$

uniformly after averaging over triples.

This avoids the fatal CRT discrepancy.

## 6. Why direct CRT cancellation is still unlikely

For three primes p,q,r>X,

$$pqr>X^2,$$

so each CRT box contains zero or one integer. The discrepancy is a boundary term depending on the fractional position of the CRT residue.

For arbitrary sets Z_p there is no cancellation theorem. The error is essentially a three-dimensional discrepancy problem for sparse subsets of varying finite fields.

The Apéry structure must enter through the algebraic description of the sets, not through CRT alone.

## 7. Recommended research path

The ranking of approaches is:

1. **Gap-polynomial algebraic envelope (most promising).** It uses the existing strongest Apéry-specific information.
2. **Sheaf-theoretic moment estimate after envelope construction.** The K3 structure supplies the needed cancellation.
3. **Direct Fourier mollification.** Fails because sparse indicators have flat spectra.
4. **Pure CRT cancellation.** Too weak without extra algebraic randomness.

The target is not to smooth the zero set geometrically in F_p. The correct smoothing is in the recurrence dynamics: replace the event of hitting a point by a bounded-degree polynomial condition detecting abnormal orbit behavior.
