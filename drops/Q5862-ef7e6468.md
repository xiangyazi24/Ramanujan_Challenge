# Q5862: five-term certificate search plan for the P3.1 endpoint Bloch relation

## Executive conclusion

A genuine machine-readable five-term certificate is not currently obtained by a blind numerical search. The available exact algorithms reduce the problem to a finite linear algebra computation in the Bloch group of the endpoint number field. The endpoint equations are suitable for this route because the positive solutions of the logarithmic system are algebraic and their Rogers sums are already known:

- alpha (k=4): `Rogers(a)+Rogers(b)+Rogers(c)+Rogers(d)=pi^2/10`.
- beta (k=2): `Rogers(a)+Rogers(b)+Rogers(c)+Rogers(d)=5*pi^2/34`.

The missing deliverable is not the regulator value but an explicit relation

```
[a]+[b]+[c]+[d] = torsion combination
```

in the Bloch group, expressed as a sequence of five-term relations.

## Available algorithms and references

### SageMath

Sage has infrastructure for number fields, units, embeddings, and exact algebraic arithmetic, but does not currently provide a complete public `BlochGroup.reduce()` routine that takes an arbitrary element `[x]` and emits a five-term chain.

Useful components:

```sage

K.places()
K.units()
K.ideal()
```

The missing layer is Bloch-group reduction.

### PARI/GP

PARI provides exact number field operations and regulators:

```gp
nfinit(P)
nfroots(P)
bnfinit(P)
bnfisunit(...)
```

but no direct Bloch-group five-term solver.

### SnapPy / SnapPy Bloch machinery

SnapPy implements extended Bloch group calculations for hyperbolic manifolds. The relevant method is the Neumann extended Bloch group formalism: represent elements by flattenings and solve the five-term relation lattice.

Useful objects:

```python
import snappy
M = snappy.Manifold(...)
M.chern_simons()
M.volume()
```

However, the endpoint field must be inserted manually as algebraic shapes.

### Published exact methods

The standard exact approach is:

1. Embed the algebraic numbers in a number field K.
2. Express the symbols in the pre-Bloch group P(K).
3. Compute the image under the Suslin/Bloch boundary map.
4. Reduce modulo the five-term relation subgroup.

Relevant methods:

- Zagier, "The dilogarithm function", in *Frontiers in Number Theory, Physics and Geometry II*.
- Goncharov, *The Classical Polylogarithms and Motivic Cohomology*.
- Neumann, "Extended Bloch group and the Cheeger-Chern-Simons class", Geom. Topol. 8 (2004).

## Exact computational pipeline

### Step 1: derive endpoint polynomial

For each k=4 and k=2 solve

```
log x = A(k) log(1-x)
```

where

```
A(k)=
[[k+1/2,k,2k,k-1],
 [k,k,2k,k-1],
 [2k,2k,4k,2k-1],
 [k-1,k-1,2k-1,k]]
```

Exponentiating gives four multiplicative equations:

```
x_i = product_j (1-x_j)^(A_ij)
```

Clear half-powers by squaring the first row. Eliminate three variables using resultants:

```sage
R = ideal(equations)
R.elimination_ideal([b,c,d])
```

This produces the minimal polynomial for the alpha/beta endpoint generator.

### Step 2: construct Bloch element

Create

```
xi = [a]+[b]+[c]+[d]
```

in the formal pre-Bloch group.

A five-term move has the form

```
[x]-[y]+[y/x]-[(1-x^-1)/(1-y^-1)]+[(1-x)/(1-y)] = 0
```

(or an equivalent sign convention).

Search for a relation matrix over the field embeddings:

```
columns = candidate five-term relations
row = xi
solve_integer_kernel(row)
```

The certificate is the integer vector of relation coefficients plus the explicit five-tuples.
