## Verdict

There are three useful exact conclusions.

1. **The secondary gate is an additive incidence in the same-prime zero set.** If
   \[
   m=6p+r=6(p+d)+u,\qquad q=p+d,
   \]
   is legal, then with `s=p-1-r`,
   \[
   \boxed{s+L_+=6d-1},\qquad
   \boxed{r+L_-=7d-1}.
   \]
   Hence a plus-secondary edge gives two `p`-zeros whose sum is `6d-1`, and a minus-secondary edge gives two `p`-zeros whose sum is `7d-1`.

2. **For one fixed common `m=T`, the current vertical bound is already strong enough to count the secondary-triggered edges.** For fixed `T,p`, the residue `r=T-6p` is fixed, and `d\mapsto L_+` and `d\mapsto L_-` are injective. Therefore
   \[
   \#\{\text{secondary edges at }p\}\le 2Z(p),
   \]
   whence, for `p\asymp T`,
   \[
   \boxed{E_{\rm sec}(T)\ll T^{5/3}/\log T
   =o(T^2/\log^2T).}
   \]
   Thus **if the macroscopic singleton argument only needs to exception-budget the secondary-zero edges for a fixed common `T`, the `2/3` vertical theorem closes that subproblem.**

3. **If the macroscopic object allows `r` (equivalently the common `m`) to vary before charging at a fixed endpoint `p`, the best bound obtainable from `Z(p)` alone is quadratic:**
   \[
   \boxed{\#E^{\rm sec}_p\le 2Z(p)^2.}
   \]
   With `Z(p)\ll p^{2/3}`, summing over `p\asymp T` gives only
   \[
   O(T^{7/3}/\log T),
   \]
   which is worse than the trivial `O(T^2/\log^2T)` candidate-pair scale. In that quantifier regime, vertical cardinality alone cannot close the target. The square-root threshold is sharp at this level: one would need essentially
   \[
   Z(p)=o\!\left(\sqrt{p/\log p}\right)
   \]
   uniformly, or a genuinely stronger additive-incidence theorem.

There is also an exact cross-characteristic transfer on the **minus** branch:

\boxed{

## 1. Legal q6 algebra and ranges

Write

\[
q=p+d,\qquad
m=6p+r=6q+u.
\]

Then

\[
\boxed{u=r-6d.}
\tag{1}
\]

For a legal digit pair,

\[
0\le r<p,\qquad 0\le u<q.
\]

From `u\ge0` and (1),

\[
r\ge6d.
\]

Since `r<p`, this gives the important short-gap fact

\[
\boxed{0<d<p/6.}
\tag{2}
\]

The two secondary indices are

\[
L_+=r+6d-p,
\qquad
L_-=7d-r-1.
\tag{3}
\]

Several exact rewritings are useful:

\[
\boxed{L_-=d-u-1},
\tag{4}
\]

and, if

\[
s:=p-1-r,
\]

then

\[
\boxed{L_+=6d-1-s.}
\tag{5}
\]

The stated seam identity is immediate:

\[
\boxed{L_++L_-=13d-p-1.}
\tag{6}
\]

The `q`-reflection identity is also exact:

\[
\begin{aligned}
q-1-u
&=p+d-1-(r-6d)\\
&=p+7d-r-1\\
&=\boxed{p+L_-}.
\end{aligned}
\tag{7}
\]

### Legal ranges of the secondary indices

A statement `p\mid b_{L_\pm}` only makes sense in the ordinary finite-digit gate when `0\le L_\pm<p`. In that regime:

- If `L_+\ge0`, then because `r<p`,
  \[
  0\le L_+<6d<p.
  \tag{8}
  \]
- If `L_-\ge0`, then from (4),
  \[
  0\le L_-\le d-1<p.
  \tag{9}
  \]

The sign conditions themselves are

\[
L_+\ge0\iff r\ge p-6d,
\tag{10}
\]

\[
L_-\ge0\iff r\le7d-1.
\tag{11}
\]

Thus both secondary indices can be legal only if

\[
13d\ge p+1.
\tag{12}
\]

Equivalently, when `13d<p+1`, the plus-valid and minus-valid `r`-bands are disjoint, and the central band

\[
7d\le r\le p-6d-1
\tag{13}
\]

has **no legal secondary index at all**. This is a genuine candidate-pruning statement coming just from the seam geometry; it does not use any zero estimate.

For a fixed common `T` with `p\le T/6`, the long-gap condition `d>T/J` implies `d/p>6/J`. Hence for fixed `J<78` and sufficiently large `T`, every long gap satisfies `13d>p`; for `J\ge78`, (12) is not automatic. This is only a geometric threshold, not a zero theorem.

## 2. Exact additive reformulation of the two secondary gates

Let

\[
Z_p:=\{j\in\{0,\ldots,p-1\}:p\mid b_j\}.
\]

The Apéry reflection gives

\[
j\in Z_p\iff p-1-j\in Z_p.
\tag{14}
\]

Assume the edge is selected at `p`, so `r\in Z_p`. Then `s=p-1-r\in Z_p`.

### Plus gate

By (5),

\[
L_+=6d-1-s.
\]

Therefore

\[
\boxed{
 p\mid b_{L_+}
 \quad\Longrightarrow\quad
 s,L_+\in Z_p,\qquad s+L_+=6d-1.
}
\tag{15}
\]

Conversely, once `p,s,L_+` are known, the gap is recovered exactly by

\[
\boxed{d=(s+L_++1)/6},
\tag{16}
\]

and then

\[
r=p-1-s,\qquad q=p+d,\qquad m=6p+r.
\]

Thus, within the legal q6 domain, the ordered pair `(s,L_+)` determines the plus-secondary edge.

Because `d<p/6`,

\[
0\le6d-1<p-1,
\tag{17}
\]

so this is an honest small integer sum, not merely a congruence modulo `p`.

### Minus gate

From (3),

\[
\boxed{r+L_-=7d-1.}
\tag{18}
\]

Hence

\[
\boxed{
 p\mid b_{L_-}
 \quad\Longrightarrow\quad
 r,L_-\in Z_p,\qquad r+L_-=7d-1.
}
\tag{19}
\]

Conversely,

\[
\boxed{d=(r+L_-+1)/7},
\tag{20}
\]

so the ordered pair `(r,L_-)` determines the minus-secondary edge.

These two formulas are the cleanest exact incidence description of the secondary gate.

## 3. Global incidence theorem at one endpoint

Let `E_p^{+}` be any family of legal plus-secondary q6 edges incident to a fixed endpoint prime `p`, with the common `m` allowed to vary. Map

\[
e\mapsto(s(e),L_+(e))\in Z_p^2.
\]

By (16), this map is injective: the pair determines `d`, then `r`, then `q` and `m`.

Therefore

\[
\boxed{|E_p^+|\le Z(p)^2.}
\tag{21}
\]

Likewise, by (20),

\[
\boxed{|E_p^-|\le Z(p)^2.}
\tag{22}
\]

and hence

\[
\boxed{|E_p^{\rm sec}|\le2Z(p)^2.}
\tag{23}
\]

This is an exact theorem. It uses no probabilistic heuristic and no finite scan.

The long-gap restriction `d>T/J` simply restricts the allowed sums in (15) and (19):

\[
s+L_+>6T/J-1,
\qquad
r+L_->7T/J-1.
\tag{24}
\]

But **cardinality alone** gives no improvement over (23) from those lower bounds on the sums. A sparse set can still have many ordered pairs in a prescribed macroscopic sum interval. Any improvement here must use additive structure of `Z_p`, not only `|Z_p|`.

## 4. Fixed-common-`m` injectivity: this is substantially stronger

Now fix the common integer

\[
m=T.
\]

For a fixed endpoint prime `p`, the selected digit is no longer free:

\[
r=T-6p
\tag{25}
\]

is fixed. Thus, as `q=p+d` varies,

\[
L_+(d)=r-p+6d,
\tag{26}
\]

\[
L_-(d)=-r-1+7d.
\tag{27}
\]

Both maps are injective as maps of integers `d` on their legal ranges. Consequently

\[
\boxed{
\#\{q:\text{fixed }T,p\text{ and plus-secondary}\}\le Z(p),
}
\tag{28}
\]

\[
\boxed{
\#\{q:\text{fixed }T,p\text{ and minus-secondary}\}\le Z(p),
}
\tag{29}
\]

and

\[
\boxed{
\#\{q:\text{fixed }T,p\text{ and any secondary gate}\}\le2Z(p).
}
\tag{30}
\]

This is the strongest unconditional incidence result I see from the gate itself.

### Quantitative consequence with the current vertical theorem

For a fixed q6 common `T`, `r\ge0` gives `p\le T/6`; in the macroscopic reduction one also has `p>T/7`. Hence `p\asymp T`.

Using the current vertical estimate

\[
Z(p)\le 3p^{2/3}+p^{1/3},
\tag{31}
\]

we obtain

\[
\begin{aligned}
E_{\rm sec}(T)
&\le 2\sum_{T/7<p\le T/6}Z(p)\\
&\le 6\sum_{T/7<p\le T/6}p^{2/3}
 +2\sum_{T/7<p\le T/6}p^{1/3}\\
&=O(T^{5/3}/\log T).
\end{aligned}
\tag{32}
\]

The last step needs only the usual prime-count upper bound in a fixed proportional interval.

The macroscopic Smith-capacity reduction wants singleton counts on the scale

\[
o(T^2/\log^2T)
\tag{33}
\]

when the total carrier height is `o(T^2/log T)`. Since

\[
\frac{T^{5/3}/\log T}{T^2/\log^2T}
=\frac{\log T}{T^{1/3}}\to0,
\tag{34}
\]

we get the clean conclusion:

> **Fixed-`T` secondary-edge theorem.** If the role of the secondary-zero gate is to identify an exceptional family that may be discarded or separately budgeted for one fixed common q6 integer `T`, the existing `Z(p)\ll p^{2/3}` theorem is already sufficient, with a power saving `T^{-1/3}` up to one logarithm.

This is a theorem-level reduction, not finite evidence.

What it does **not** prove is that every edge supplies a useful secondary direction. In fact it points the other way: it bounds how many neighbors can trigger such a zero. If the Smith construction needs the secondary direction for every singleton edge, (32) is not a completion; it says that such triggers form a sparse subfamily.

## 5. Why the same vertical theorem does not close a varying-`r` macroscopic union

If the target block allows `r` to vary at fixed `p` before charging edges to the same Smith carrier, then (30) is unavailable and the exact unconditional estimate is (23):

\[
|E_p^{\rm sec}|\le2Z(p)^2.
\]

With (31),

\[
Z(p)^2
\le 9p^{4/3}+6p+p^{2/3}.
\tag{35}
\]

Summing over `p\asymp T`,

\[
\boxed{
\sum_{p\asymp T}|E_p^{\rm sec}|
=O(T^{7/3}/\log T).
}
\tag{36}
\]

That is asymptotically larger than the trivial prime-pair scale `T^2/log^2T`; so (36) gives no global saving.

More generally, suppose all one knows is

\[
Z(p)\ll p^\alpha.
\]

Then the pair-incidence argument gives

\[
\sum_{p\asymp T}|E_p^{\rm sec}|
\ll \frac{T^{2\alpha+1}}{\log T}.
\tag{37}
\]

To make this `o(T^2/log^2T)` by cardinality alone one needs

\[
T^{2\alpha-1}\log T\to0,
\]

so any fixed exponent

\[
\boxed{\alpha<1/2}
\tag{38}
\]

would suffice, whereas `\alpha=2/3` cannot.

At the square-root boundary a logarithmic saving is needed. A convenient sharp sufficient form is

\[
\boxed{
Z(p)=o\!\left(\sqrt{p/\log p}\right)
}
\tag{39}
\]

uniformly over the relevant endpoints.

Thus there is a precise scoped no-go:

> **Vertical-cardinality no-go.** In a macroscopic union where the original selected residue `r` varies and secondary edges are counted through arbitrary ordered pairs of `p`-zeros, the current `Z(p)\ll p^{2/3}` input cannot by itself yield the required singleton saving. One needs either a sub-square-root vertical theorem or a new additive-incidence statement for the zero set.

The natural direct replacement is an estimate of the form

\[
\#\Bigl\{
 d:\ p+d\text{ prime},\ d>T/J,
 \ 6d-1\in Z_p+Z_p
 \text{ or }7d-1\in Z_p+Z_p
\Bigr\}
=o(p/\log p)
\tag{40}
\]

on average over `p\asymp T` (or any stronger pointwise power saving). This is exactly the horizontal/additive theorem missing from a cardinality-only argument.

## 6. Exact minus-branch cross-characteristic transfer

The minus branch has an additional structure not present in the bare pair count.

Let

\[
\ell:=L_-.
\]

From (4),

\[
\boxed{u+\ell=d-1.}
\tag{41}
\]

If `\ell\ge0`, then `\ell\le d-1`, hence

\[
p+\ell< p+d=q.
\tag{42}
\]

By (7),

\[
\boxed{p+\ell=q-1-u.}
\tag{43}
\]

Since the edge is selected at `q`,

\[
q\mid b_u.
\]

The exact Apéry reflection modulo `q` gives

\[
\boxed{q\mid b_{q-1-u}=b_{p+\ell}.}
\tag{44}
\]

Now use the ordinary Apéry Lucas congruence at `p`, valid for `0\le\ell<p`:

\[
\boxed{b_{p+\ell}\equiv b_1b_\ell=5b_\ell\pmod p.}
\tag{45}
\]

Therefore, for `p>5`, a minus-secondary zero `p\mid b_\ell` implies

\[
p\mid b_{p+\ell}.
\]

Combining with (44) and `p\ne q`,

\[
\boxed{
 p\mid b_{L_-},\ q\mid b_u
 \Longrightarrow
 pq\mid b_{p+L_-}.
}
\tag{46}
\]

This is the cleanest exact cross-characteristic transfer I find.

### Why (46) does not by itself solve the Smith-capacity problem

The `p`-factor in `b_{p+L_-}` is not a new independent `p` event. It is exactly the Lucas lift (45) of the same zero `b_{L_-}`. Thus (46) gives a common integer carrying both endpoint primes, but it does not automatically give two independent mod-`p` kernel directions.

Also the carrier index is still macroscopic:

\[
p\le p+L_-<q\asymp T.
\]

The characteristic-zero size of `b_n` is exponential in `n`; even the elementary lower bound `b_n\ge5^n` already shows `\log b_n\gg n`. Hence attaching an independent scalar `b_{p+L_-}` to each edge is a high-height route, not the desired `O_J(1)` shared Smith carrier.

For fixed `m`, (43) can be rewritten

\[
\boxed{p+L_-=7q-m-1,}
\tag{47}
\]

so distinct `q` give distinct common-divisor indices. This is useful for exact checking, but it does not compress the characteristic-zero height.

## 7. What the seam identity `L_++L_-=13d-p-1` does and does not buy

Equation (6) has two exact uses.

### 7.1 Branch-overlap threshold

As already noted, if both secondary indices are legal then

\[
13d\ge p+1.
\]

So for `13d<p+1` at most one complete branch can even have a secondary Apéry zero.

### 7.2 Double-secondary edges are another pair-sum incidence

If both secondary gates fire, then

\[
L_+,L_-\in Z_p,
\qquad
L_++L_-=13d-p-1.
\tag{48}
\]

Thus

\[
\boxed{d=(p+1+L_++L_-)/13.}
\tag{49}
\]

The pair `(L_+,L_-)` determines the gap. This is an exact incidence reduction, but cardinality still gives only `O(Z(p)^2)`. The identity does not, by itself, manufacture a subquadratic additive-energy bound for `Z_p`.

In particular, reflection symmetry and no-consecutive-zeros do not imply a useful upper bound for the number of represented sums in (15), (19), or (48). Such a statement would be genuinely new arithmetic information about the Apéry zero set.

## 8. A narrowly targeted rank-independence lemma to check against Section 6

Because the actual Section 6 seam-vector formula is not visible through the connected repository, I will not claim that the following hypotheses hold. But this is the smallest exact criterion that would turn the fixed-`m` index injection into the full rank statement the Smith argument wants.

Suppose the secondary seam direction attached to a zero `L\in Z_p` is a vector

\[
\eta_L\in\mathbb F_p^N
\]

with coordinates indexed by seam positions and has the **suffix-pivot property**

\[
\eta_L(j)=0\qquad(j<L),
\tag{50}
\]

and

\[
\eta_L(L)=c_L b_{L-1}
\tag{51}
\]

for a `p`-unit `c_L` (the same argument works with a unit multiple of `b_{L+1}`).

A secondary zero cannot occur at `L=0`, since `b_0=1`, nor at `L=p-1`, since reflection gives `b_{p-1}\equiv b_0\equiv1`. For `1\le L\le p-2`, the repository's no-consecutive-zeros theorem gives

\[
p\nmid b_{L-1},\qquad p\nmid b_{L+1}.
\tag{52}
\]

Hence every pivot in (51) is nonzero.

Now order distinct secondary indices

\[
L_1<\cdots<L_k.
\]

Take the coordinate minor with rows `L_1,\ldots,L_k` and columns `\eta_{L_1},\ldots,\eta_{L_k}`. By (50) it is triangular, and by (51)--(52) its diagonal is nonzero. Therefore

\[
\boxed{\eta_{L_1},\ldots,\eta_{L_k}
\text{ are linearly independent over }\mathbb F_p.}
\tag{53}
\]

This is a genuine theorem **conditional only on the suffix-pivot formula (50)--(51)**.

Thus the exact Section 6 audit question should be reduced to one line:

> Does its secondary seam kernel vector have a branch-fixed support order with a first nonzero seam coordinate equal to a `p`-unit times `b_{L-1}` or `b_{L+1}`?

If yes, then for fixed `m,p`, the injectivity of `d\mapsto L_+` (respectively `d\mapsto L_-`) immediately gives joint independence of all same-branch secondary directions. That would be much stronger than pairwise nonproportionality: it gives a full triangular minor.

If Section 6 instead transports every local zero-state into the same two-dimensional recurrence state without retaining a seam-indexed pivot, distinct `L` values do **not** imply independence; the order-two state space then caps the rank. The actual support formula is therefore essential.

## 10. Reproducible exact-arithmetic checker plan

The checker should not try to prove the asymptotic statement by scanning. Its role is to verify the algebra, locate actual secondary triggers, and test the Section 6 suffix-pivot hypothesis once the local file is available.

A minimal Python skeleton is:

```python
#!/usr/bin/env python3
from math import comb


def P(n):
    return 34*n**3 + 51*n**2 + 27*n + 5


def apery_exact(N):
    b = [1, 5]
    for n in range(1, N):
        num = P(n)*b[n] - n**3*b[n-1]
        den = (n+1)**3
        q, rem = divmod(num, den)
        assert rem == 0
        b.append(q)
    return b[:N+1]


def primes_upto(N):
    s = bytearray(b"\x01")*(N+1)
    if N >= 0: s[0] = 0
    if N >= 1: s[1] = 0
    for a in range(2, int(N**0.5)+1):
        if s[a]:
            s[a*a:N+1:a] = b"\x00"*((N-a*a)//a+1)
    return [a for a in range(2, N+1) if s[a]]


def zero_set(b, p):
    return {j for j in range(p) if b[j] % p == 0}


def edge_record(b, m, p, q):
    d = q-p
    r = m-6*p
    u = m-6*q
    assert 0 <= r < p
    assert 0 <= u < q
    assert u == r-6*d
    assert 0 < d < p/6
    assert b[r] % p == 0
    assert b[u] % q == 0

    Lp = r + 6*d - p
    Lm = 7*d - r - 1
    assert Lp + Lm == 13*d - p - 1
    assert p + Lm == q - 1 - u

    Zp = zero_set(b, p)
    s = p-1-r
    assert s in Zp                  # p-reflection

    plus = 0 <= Lp < p and Lp in Zp
    minus = 0 <= Lm < p and Lm in Zp

    if plus:
        assert s + Lp == 6*d - 1
        assert d == (s + Lp + 1)//6

    if minus:
        assert r + Lm == 7*d - 1
        assert u + Lm == d - 1
        n = p + Lm
        assert n == q-1-u
        assert b[n] % q == 0         # q-reflection
        # Apéry Lucas lift b_(p+Lm) = 5 b_Lm (mod p)
        assert (b[n] - 5*b[Lm]) % p == 0
        if p > 5:
            assert b[n] % p == 0
            assert b[n] % (p*q) == 0

    return (d, r, u, Lp, Lm, plus, minus)
```

For a fixed `m`, the checker should additionally group true edges by endpoint `p` and assert:

```python
plus_L = [rec.Lp for rec in edges_at_p if rec.plus]
minus_L = [rec.Lm for rec in edges_at_p if rec.minus]
assert len(plus_L) == len(set(plus_L))
assert len(minus_L) == len(set(minus_L))
assert len(plus_L) <= len(Zp)
assert len(minus_L) <= len(Zp)
```

For a varying-`m` audit, record the pair keys

```python
plus_key  = (p, p-1-r, Lp)
minus_key = (p, r, Lm)
```

and verify that no two distinct edges have the same same-branch key. This checks the exact injections behind (21)--(23).

Finally, once the actual Section 6 vector constructor is available, output each secondary vector `eta_L`, sort by `L`, and compute the seam-coordinate minor at rows `L_i`. The decisive test is not a random rank computation but the exact triangular assertions

```python
eta[L][j] == 0                 for j < L
eta[L][L] % p != 0
```

and then the determinant of the selected `L_i x L_j` minor. A finite scan supporting these formulas is evidence; the rank theorem (53) comes only after the support/pivot identities are proved symbolically.

## 11. Theorem versus evidence

### Exact theorems derived here

- `u=r-6d`, `d<p/6`.
- `L_-=d-u-1`.
- `L_+=6d-1-(p-1-r)`.
- `L_++L_-=13d-p-1`.
- `p+L_-=q-1-u`.
- Plus-secondary additive incidence `s+L_+=6d-1` with `s,L_+\in Z_p`.
- Minus-secondary additive incidence `r+L_-=7d-1` with `r,L_-\in Z_p`.

## Bottom line

The secondary-zero gate has a much cleaner exact structure than a generic extra zero:

\[
\boxed{
\text{plus: } Z_p+Z_p\ni6d-1,
\qquad
\text{minus: } Z_p+Z_p\ni7d-1.
}
\]

For a **fixed common q6 integer `T`**, this collapses further to one injective zero index per gap and the current `Z(p)\ll p^{2/3}` theorem is already enough to exception-budget all secondary-triggered singleton edges with size

\[
O(T^{5/3}/\log T).
\]

For a block where the original selected residue varies, however, the exact injection is only into an ordered pair of `p`-zeros, giving `2Z(p)^2`; the current `2/3` exponent is on the wrong side of the square-root threshold and cannot close the macroscopic singleton target by vertical counting alone.

The most promising exact next check in the actual Section 6 file is therefore **not another zero census**. It is the seam-vector support formula: if distinct secondary indices have distinct suffix pivots with unit diagonal, then fixed-`T` injectivity upgrades immediately to full finite-field rank independence. If that pivot structure is absent, the remaining live arithmetic problem is the additive incidence estimate (40), not the existing vertical bound.
