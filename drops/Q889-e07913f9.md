# 1. First reduce the full gcd target to finitely many fixed-\(q\) slices plus a uniform tail

Let

\[
H(n):=\log\gcd(L_n,b_n).
\]

For primes \(p\le\sqrt n\),

\[
v_p(L_n)=\lfloor\log_p n\rfloor,
\]

so, by the elementary Chebyshev bound \(\pi(x)\ll x/\log x\),

\[
\sum_{p\le\sqrt n}v_p(L_n)\log p
\le \pi(\sqrt n)\log n
\ll \sqrt n=o(n).
\tag{1.1}
\]

For \(p>\sqrt n\), one has \(v_p(L_n)=1\).  Put

\[
q=\left\lfloor\frac np\right\rfloor.
\]

Then

\[
\frac{n}{q+1}<p\le\frac nq.
\]

Define the logarithmic fixed-\(q\) slice

\[
S_q(n):=
\sum_{\substack{n/(q+1)<p\le n/q\\p\mid b_n}}\log p.
\tag{1.2}
\]

For any fixed integer \(Q\ge1\), the large-prime part splits as

\[
\sum_{\sqrt n<p\le n\atop p\mid b_n}\log p
\le
\sum_{1\le q\le Q}S_q(n)
+\sum_{\sqrt n<p\le n/(Q+1)}\log p.
\]

The last term is at most \(\vartheta(n/(Q+1))\ll n/Q\).  Hence

\[
H(n)
\le o(n)+\sum_{q\le Q}S_q(n)+O(n/Q).
\tag{1.3}
\]

Consequently the quantifier order needed for the asserted equivalence is exactly:

1. fix \(\varepsilon>0\);
2. choose fixed \(Q\) so that the tail in (1.3) is \(<\varepsilon n/3\);
3. for each of the **finitely many** \(q\le Q\), use the pointwise statement \(S_q(n)=o_q(n)\);
4. then take the maximum of the finitely many thresholds in \(n\).

Thus no uniformity in growing \(q\) is required.  This is important: one cannot interchange “for every fixed \(q\)” with a sum over \(q\le\sqrt n\) without the tail estimate (1.3).

So it is enough to close one arbitrary fixed \(q\).

# 2. Exact Lucas conversion of a fixed-\(q\) slice into the Oracle-A zero incidence

Fix \(q\).  For a target prime

\[
\frac n{q+1}<p\le\frac nq
\]

write

\[
n=qp+r,\qquad 0\le r<p.
\]

For all sufficiently large \(n\), the prime \(p\) is larger than both \(q\) and every prime divisor of the fixed integer \(b_q\).  Gessel's Apéry--Lucas congruence therefore gives

\[
b_n=b_{qp+r}\equiv b_q b_r\pmod p,
\]

with \(b_q\not\equiv0\pmod p\).  Hence

\[
\boxed{
p\mid b_n\iff p\mid b_r,
\qquad r=n\bmod p.
}
\tag{2.1}
\]

Let

\[
\mathcal Z_p=\{0\le r<p:p\mid b_r\},
\qquad Z(p)=|\mathcal Z_p|.

Then, eventually in \(n\),

\[
S_q(n)=
\sum_{n/(q+1)<p\le n/q}
(\log p)\mathbf1_{\mathcal Z_p}(n\bmod p).
\tag{2.2}
\]

This is exactly the moving-target incidence appearing in `oracleA_result.tex`; no companion denominator or additional local quotient variable remains.

# 7. Why the nearest standard bilinear theorems do not currently prove (5.7)

Expanding the exact form gives

\[
\mathcal B_{P,M}
 =\sum_{p\ne\ell}
   \frac{(\log p)(\log\ell)}{p\ell}
   \sum_{0<|h|<p\ell/M}
   w_{p,\ell}(h)
   F_p(h\bar\ell)F_\ell(h\bar p),
\]

where \(0\le w_{p,\ell}(h)\le1\).

This looks extremely close to classical bilinear forms in Kloosterman fractions.  The obstruction is not the Farey geometry; that part has already been normalized exactly.  It is the coefficient system.

Writing

\[
F_p(a)=\sum_{r\in\mathcal Z_p}e_p(ar)
\]

shows that the first factor contains phases

\[
e_p(hr\bar\ell)
\]

with \(r\) ranging over an Apéry zero set depending on the same characteristic \(p\).  The second factor has the analogous independently moving set for \(\ell\).

The repository has already removed one apparent mismatch: on the doublet sector,

\[
\mathcal Z_p=\{r_p,p-1-r_p\}
\]

gives

\[
F_p(a)=e_p(ar_p)+e_p(-a(1+r_p)),
\]

which is a rank-2 bounded-conductor trace function **for that fixed prime**.  But the slope \(r_p\) itself is selected by the Apéry zero condition and moves with \(p\).  There is no single fixed sheaf over a fixed characteristic whose extension-degree traces produce the horizontal family.

This is precisely why a black-box Fouvry--Kowalski--Michel / DFI / Kuznetsov invocation is unavailable: those theorems need a coefficient system whose arithmetic complexity is controlled uniformly in the horizontal modulus variables, not a new same-characteristic zero set at each prime.

More decisively, `oracleA_result.tex` constructs the reflected anchored family

\[
\mathcal Z_p^*=\{2N\bmod p,-2N-1\bmod p\},
\]

which has:

- two points per prime;
- reflection symmetry;
- no adjacent residues;
- the same local rank-2 bounded-conductor description;
- the same generic prime spacing;

but every prime shares a common hit at \(2N\), so the desired short-arc/dispersion estimate fails by a polynomial factor.

Therefore no theorem depending only on those generic local properties can prove (5.7).  The missing estimate must use an **Apéry-specific horizontal relation among the moving slopes/zero sets**.

That is why (5.7), rather than a generic large-sieve statement, is the closest honest edge to a standard theorem.

### Why a direct Cauchy/Parseval attack still stops

For fixed \(p,\ell\), multiplication by \(\bar\ell\) merely permutes residues modulo \(p\).  Full Parseval gives

So the exact remaining task is a horizontal cancellation theorem for the moving inverses and moving Apéry slopes.  This is not hidden in any currently proved vertical node.
