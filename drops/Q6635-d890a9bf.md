```

```

```

```

```
E_p <= (p/Delta) * Delta^2 log Delta = p Delta log Delta.
```

```
E_p << p^(3/2) log p.
```

This is weaker than the direct theorem


because of the logarithmic loss. There is no Delta range where T1 improves the already explicit direct energy bound.
