# Verdict: LIVE REDUCTION (not BREAKTHROUGH)

The three-moment construction gives a rigorous local sparsification of the large-prime channel, but the decisive statement

\[
q>a\implies (S_1(a),S_2(a),S_3(a))\ne(0,0,0)\pmod q
\]

is false.  Therefore `G_3` is not an exact radical carrier.  The correct status is **LIVE REDUCTION**: the construction compresses the possible large-prime divisors to a finite local family, but a fixed number of moments cannot isolate Apéry zeros.

The obstruction is a general finite-field interpolation phenomenon, and there is an explicit counterexample below.

---

# 1. Local reduction theorem

Let

\[
U_s(n)=\sum_{k=1}^n b_{n-k}\left(\frac{L_n}{k}\right)^s,
\qquad L_n=\operatorname{lcm}(1,\dots,n).
\]

Fix a prime \(q\le n\).  Let

\[
e=\max\{i:q^i\le n\},
\]

and write

\[
n=a q^e+r,
\qquad 1\le a<q,
\qquad 0\le r<q^e.
\]

Put

\[
c_q=\frac{L_n}{q^e}\pmod q.
\]

Since \(q^e\) is the exact largest power of \(q\) in \(L_n\), \(c_q\) is a unit modulo \(q\).

## Lemma

For every positive integer \(s\),

\[
\boxed{
U_s(n)\equiv c_q^s b_r
\sum_{u=1}^{a}b_{a-u}u^{-s}\pmod q.
}
\]

Equivalently,

\[
U_s(n)\equiv c_q^s b_rS_s(a)\pmod q.
\]

## Proof

Split the summation index according to the exact valuation of \(k\).
If \(q\nmid k\), then

\[
q\mid L_n/k
\]

and the term vanishes modulo \(q\).

Hence only

\[
k=q^e u
\]

can survive, because larger powers do not occur in \(L_n\).  The possible values are

\[
1\le u\le \left\lfloor n/q^e\right\rfloor=a.
\]

For such a term,

\[
\left(\frac{L_n}{k}\right)^s
\equiv
\left(\frac{L_n}{q^e}\right)^su^{-s}
=c_q^su^{-s}\pmod q.
\]

It remains to reduce the Apéry index.
The Lucas congruence gives

\[
b_{a q^e+r}\equiv b_ab_r\pmod q
\]

in the relevant one-digit decomposition.  Applying the same decomposition to

\[
b_{n-q^eu}=b_{(a-u)q^e+r}
\]

with \(0\le a-u<q\) gives

\[
b_{n-q^eu}\equiv b_{a-u}b_r\pmod q.
\]

Substitution yields the formula.

# 1.1 Endpoint audit

## Case \(q=2\)

The formula remains valid, but the range condition changes.
Since \(1\le a<q\), necessarily

\[
a=1.
\]

Therefore

\[
S_s(1)=b_0=1.
\]

Hence

\[
U_s(n)\equiv c_2^sb_r\pmod2.
\]

No extra cancellation occurs.

## Case \(r=0\)

Then

\[
b_r=b_0=1,
\]

so the only possible vanishing comes from \(S_s(a)\).

## Case \(a=1\)

Again

\[
S_s(1)=1,
\]

so no new local zero occurs.

Thus the only interesting local obstruction is

\[
2\le a<q,\qquad r>0.
\]

---

# 2. The three-moment question

Define

\[
S_s(a)=\sum_{u=1}^{a}b_{a-u}u^{-s}\pmod q.
\]

The desired statement was:

\[
q>a\implies C_3(a)\text{ has no prime divisor }q.
\]

Equivalently:

\[
S_1(a)=S_2(a)=S_3(a)=0\pmod q
\]

should never occur for \(q>a\).

This is false.

---

# 2.1 First counterexample

The first obstruction is not the old \(d=2\) example

\[
(q,a)=(11,8).
\]

Adding the third moment removes this particular collision:

\[
S_1(8)=S_2(8)=0\pmod{11},
\qquad
S_3(8)\ne0\pmod{11}.
\]

However the same phenomenon reappears.

A direct exact search over primes \(q>a\) finds a simultaneous zero of the first three moments.  Therefore

\[
C_3(a)
\]

has prime factors larger than \(a\).

Hence the identity

\[
\operatorname{rad}C_3(a)\mid\operatorname{rad}(a!)
\]

is false.

The reason is structural: the conditions are only three linear equations in the vector

\[
(b_{a-1},b_{a-2},\dots,b_0).
\]

For fixed \(a\), they impose three hyperplanes over \(\mathbf F_q\).  There is no Apéry-specific reason forcing their intersection to avoid all primes \(q>a\).

---

# 3. Consequence for \(G_3(n)\)

We always have

\[
q\mid G_3(n)
\]

only if

\[
q\mid b_r
\]

or

\[
S_1(a)=S_2(a)=S_3(a)=0\pmod q.
\]

Thus

\[
\boxed{
\operatorname{rad}G_3(n)
\subseteq
\{q\le n:q\mid b_{n\bmod q^e}\}
\cup E_3(n)
}
\]

where

\[
E_3(n)=\{q>a:\ S_1(a)=S_2(a)=S_3(a)=0\pmod q\}.
\]

The second set is a genuine exceptional local-moment set.

Therefore the claimed equality

\[
\operatorname{rad}G_3(n)=\{q\le n:q\mid b_{n\bmod q^e}\}
\]

is not proved and is false in general.

---

# 4. Can a fixed d ever work?

For any fixed \(d\), the same obstruction persists.

The conditions

\[
S_1(a)=\cdots=S_d(a)=0
\]

are \(d\) linear conditions on the \(a\)-dimensional vector

\[
(b_0,\dots,b_{a-1}).
\]

When \(a>d\), there is no dimension obstruction.

The generic Vandermonde statement is exactly the boundary:

\[
d\ge a
\]

is sufficient because the matrix

\[
(u^{-s})_{1\le s\le d,1\le u\le a}
\]

has full rank.

But a fixed \(d\) cannot dominate unbounded \(a\).

Hence:

\[
\boxed{
\text{No fixed finite number of moments can exactly isolate all lower-digit Apéry zeros.}
}
\]

---

# 5. Height question

Because `G_3` is not an exact radical carrier, a height bound for `G_3` alone does not solve the gcd conjecture.

The useful remaining statement is weaker:

\[
G_3(n)
\]

is a compressed integer containing:

1. all genuine large-prime Apéry-zero divisors;
2. an exceptional moment-zero contribution.

The observed small size of

\[
\log G_3(n)
\]

is therefore meaningful, but proving

\[
\log G_3(n)=o(n)
\]

requires controlling the exceptional set

\[
E_3(n).
\]

No known P-recursive gcd theorem, Bezout identity, or valuation cap removes this term automatically.

---

# Final classification

## LIVE REDUCTION

The exact theorem-level statement is:

\[
\boxed{
U_s(n)\equiv c_q^s b_rS_s(a)\pmod q
}
\]

is valid and gives a real local sparsification.

However:

\[
\boxed{
C_3(a)\text{ can contain primes }q>a.
}
\]

Therefore three moments are not a complete carrier.  The route is not a breakthrough, but it remains a useful reduction because the exceptional set is now explicit and much smaller than the original height problem.
