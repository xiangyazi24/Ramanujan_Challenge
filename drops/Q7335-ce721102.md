## 2. Proof-quality sparse inversion lemma

### Lemma 2.1 — exact inverse enumeration

Fix \(T,J\) and a lower prime \(p\in\mathcal P_T\).

1. Every minus occurrence is recovered uniquely from its ordered lower-zero pair \((a,r)\in\mathcal Z_p^2\) by

   \[
   d=\frac{a+r+1}{7},
   \qquad
   t=d-a-1=\frac{r-6a-6}{7},
   \qquad
   q=p+d.
   \tag{2.1}
   \]

   Such a pair is admissible exactly when \(7\mid a+r+1\) and all predicates (1.1), (1.3) hold.

2. Every plus occurrence is recovered uniquely from its ordered lower-zero pair \((z,w)\in\mathcal Z_p^2\) by

   \[
   d=\frac{z+w+1}{6},
   \qquad
   t=p-1-z-6d,
   \qquad
   q=p+d.
   \tag{2.2}
   \]

   Such a pair is admissible exactly when \(6\mid z+w+1\) and all predicates (1.1), (1.9) hold.

Consequently the complete unmarked C4 occurrence set is enumerable in

\[
O\!\left(\sum_{p\in\mathcal P_T}Z(p)^2\right)
\tag{2.3}
\]

after the zero tables are available.

### Proof

For minus, add the two defining indices:

\[
a+r+1
=a+(7t+6a+6)+1
=7(a+t+1)=7d.
\]

This gives the first formula in (2.1), and then \(t=d-a-1\). Conversely,

\[
6d+t=7d-a-1=a+r+1-a-1=r,
\]

so the reconstructed variables satisfy the exact source identities. Thus the map between legal occurrences and admissible ordered zero pairs is inverse in both directions.

For plus,

\[
z+w+1=z+(6d-1-z)+1=6d,
\]

which gives (2.2). With the reconstructed \(t\),

\[
t+6d=p-1-z,
\]

and

\[
t+12d-p=6d-1-z=w.
\]

Also

\[
q-1-t=p+d-1-(p-1-z-6d)=z+7d=v.
\]

Hence the reconstruction preserves both literal lower indices and the actual upper index. Uniqueness follows from the displayed inverse formulas. Each lower prime contributes at most \(2Z(p)^2\) ordered-pair trials, proving (2.3). ∎

### Why this matters

A direct loop over \((p,q,t)\) is cubic at the ambient scale and easily hides endpoint errors. Lemma 2.1 changes only the enumeration order; it does not relax any mask. The supplied code performs both enumerations at small \(T\) and requires exact set equality before accepting a shell.

=\sum_q\sum_{t\bmod q}1_{\mathcal Z_q}(t)A_{\rm raw}(q,t).
\tag{4.1}

For either load \(A\), let

\[
A_q=\sum_{t\bmod q}A(q,t),
\qquad
V(A)=\sum_q\sum_{t\bmod q}
\left(A(q,t)-\frac{A_q}{q}\right)^2.
\tag{4.2}

\[
g_q(t)=1_{\mathcal Z_q}(t)-\frac{Z(q)}q,

\left|\sum_{q,t}g_q(t)\left(A(q,t)-\frac{A_q}{q}\right)\right|

\left(\sum_q Z(q)-\frac{Z(q)^2}{q}\right)^{1/2}V(A)^{1/2}

qV_q(A)=q\sum_tA(q,t)^2-A_q^2\in\mathbb Z_{\ge0}.
\tag{4.4}

It therefore never needs to materialize the \(q-O(Z(p)^2)\) zero-load coordinates.

## 5. Exact affine marginal lemma and first failed implication

### Lemma 5.1 — exact unrestricted two-zero density

Fix a prime \(p>7\). In the minus channel the literal lower residues are

\[
(a,r)\equiv(q-t-1,\,6q+t)\pmod p.
\]

The affine linear part has matrix

\[
\begin{pmatrix}1&-1\\6&1\end{pmatrix}
\]

of determinant \(7\). In the plus channel,

\[
(z,w)\equiv(-1-6q-t,\,12q+t)\pmod p,
\]

whose linear part has determinant \(6\). Therefore both maps are bijections of \(\mathbb F_p^2\), and in either sign

\[
\#\{(q,t)\bmod p:\text{both lower coordinates lie in }\mathcal Z_p\}
=Z(p)^2.
\tag{5.1}
\]

This statement uses the literal lower indices, so it does not require dividing by a fixed Lucas coefficient such as \(b_6\) or \(b_{12}\). ∎

### The invalid transfer

For distinct lower primes \(p_1,p_2\), let \(X_{p_i,\sigma_i}\) be the literal candidate-state set after all C4 windows and primality restrictions for sign \(\sigma_i\). A tempting argument applies (5.1) to assert

\[
\frac{
 \#\{(q,t)\in X_{p_1,\sigma_1}\cap X_{p_2,\sigma_2}:
       q\mid b_t\}
}{
 \#\{(q,t)\in X_{p_1,\sigma_1}:q\mid b_t\}
}
\stackrel{?}{\ll}
\frac{Z(p_2)^2}{p_2^2}.
\tag{5.2}
\]

Nothing in (5.1) implies (5.2). The denominator is an adaptive subset selected simultaneously by the first lower prime, interval geometry, the shifted-prime equation \(q=p+d\), and the upper Apéry zero. Marginal cardinality permits that subset to lie entirely in the second pair-zero locus. This is the first exact failed implication in the proposed derivation.

The exponent loss is not cosmetic. There are \(\asymp T/L\) possible partner lower primes. If \(\rho_T\) denotes the average conditional probability that a partner supplies both its lower pair and the upper mark, then the banked mass gives schematically

\[
F_\vee\ll_J\frac{T}{L}M_0\rho_T.
\tag{5.3}
\]

The threshold requires

\[
\rho_T
=o\!\left(\frac{F_0L}{TM_0}\right)
=o\!\left(T^{-4/5}L^{-8/5}\right).
\tag{5.4}
\]

The two-zero marginal from (5.1) and \(Z(p)\ll p^{2/3}\) gives only

\[
\rho_T\lesssim T^{-2/3},
\]

which inserted in (5.3) misses by

\[
T^{2/15}L^{8/5}.
\tag{5.5}
\]

The heuristic product

\[
T^{-2/3}\cdot T^{-1/3}=T^{-1}
\]

would give

\[
F_\vee\ll_J M_0/L
=T^{11/5}L^{-8/5}
=o(F_0),
\]

with ratio \(T^{-1/5}L^{8/5}\). Proving that extra \(T^{-1/3}\) against the adaptive lower-pair intersection is exactly the new cross-characteristic selected-state mixing lemma. It cannot be imported from the affine bijection, a same-characteristic resultant, or separate marginal bounds.

def sha256_file(path: Path) -> str:
    h = hashlib.sha256()
    with path.open("rb") as f:
        for block in iter(lambda: f.read(1 << 20), b""):
            h.update(block)

def write_json(path: Path, obj: Any) -> None:

def primes_upto(n: int) -> list[int]:
    if n < 2:
        return []
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[0:2] = b"\x00\x00"
    for p in range(2, math.isqrt(n) + 1):
        if sieve[p]:
            start = p * p
            count = (n - start) // p + 1
            sieve[start : n + 1 : p] = b"\x00" * count
    return [i for i in range(2, n + 1) if sieve[i]]


def in_shell(T: int, p: int) -> bool:
    # Exact T/7 < p <= T/3 and fixed small-prime exclusion.
    return p > 13 and 7 * p > T and 3 * p <= T


def absolute_t_range(T: int, q: int) -> tuple[int, int]:
    # T < 6q+t <= 2T, 0 <= t < q.
    lo = max(0, T - 6 * q + 1)
    hi = min(q - 1, 2 * T - 6 * q)
    return lo, hi


def apery_values_mod_p(p: int) -> list[int]:
    """Return b_0,...,b_{p-1} modulo p from the exact recurrence."""
    b = [0] * p
    b[0] = 1
    if p == 1:
        return b
    b[1] = 5 % p
    for n in range(1, p - 1):
        Pn = (34 * n**3 + 51 * n**2 + 27 * n + 5) % p
        rhs = (Pn * b[n] - pow(n, 3, p) * b[n - 1]) % p
        inv = pow(n + 1, p - 2, p)
        inv3 = (inv * inv % p) * inv % p
        b[n + 1] = rhs * inv3 % p
    return b


def apery_literal_mod(n: int, p: int) -> int:
    total = 0
    for k in range(n + 1):
        total += math.comb(n, k) ** 2 * math.comb(n + k, k) ** 2
    return total % p


def validate_zero_set(p: int, zeros: Iterable[int]) -> None:
    z = set(zeros)
    if 0 in z or p - 1 in z:
        raise AssertionError(f"endpoint zero at p={p}")
    for x in z:
        if p - 1 - x not in z:
            raise AssertionError(f"reflection failure p={p}, x={x}")
        if x + 1 in z:
            raise AssertionError(f"consecutive zeros p={p}, x={x}")

            if got != want:
                raise AssertionError(
                    f"literal Apéry mismatch p={p}, n={n}: {got} != {want}"
                )
    zeros = tuple(i for i, x in enumerate(values) if x == 0)
    validate_zero_set(p, zeros)

    payload = {"version": ZERO_VERSION, "p": p, "zeros": list(zeros)}
    text = json.dumps(payload, sort_keys=True, separators=(",", ":")) + "\n"
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(path.name + f".tmp.{os.getpid()}")
    tmp.write_text(text, encoding="utf-8")
    os.replace(tmp, path)
    return p, zeros, sha256_file(path)


def zero_worker(args: tuple[int, str, bool, int]) -> tuple[int, tuple[int, ...], str]:
    p, cache_dir, force, literal_max = args
    return load_or_compute_zeros(p, Path(cache_dir), force, literal_max)


@dataclass(frozen=True, order=True)
class Event:
    sign: str
    p: int
    q: int
    t: int
    d: int
    lower_left: int
    lower_right: int

    def key(self) -> tuple[Any, ...]:
        return (
            self.sign,
            self.p,
            self.q,
            self.t,
            self.d,
            self.lower_left,
            self.lower_right,
        )


def common_legal(
    T: int,
    J: int,
    shell_set: set[int],
    p: int,
    q: int,
    t: int,
    d: int,
) -> bool:
    return (
        p in shell_set
        and q in shell_set
        and q == p + d
        and d > 0
        and J * d > T
        and 0 <= t < q
        and T < 6 * q + t <= 2 * T
    )


def enumerate_inverse_events(
    T: int,
    J: int,
    shell: list[int],
    zeros: dict[int, frozenset[int]],
) -> list[Event]:
    shell_set = set(shell)
    events: list[Event] = []

    for p in shell:
        zp = sorted(zeros[p])

        # Minus inverse: d=(a+r+1)/7, t=d-a-1.
        for a in zp:
            for r in zp:
                numerator = a + r + 1
                if numerator % 7:
                    continue
                d = numerator // 7
                t = d - a - 1
                q = p + d
                if not common_legal(T, J, shell_set, p, q, t, d):
                    continue
                if r != 6 * d + t:
                    raise AssertionError("minus inverse algebra failure")
                if not (0 <= t <= min(d - 1, p - 6 * d - 1)):
                    continue
                events.append(Event("-", p, q, t, d, a, r))

        # Plus inverse: d=(z+w+1)/6, t=p-1-z-6d.
        for z in zp:
            for w in zp:
                numerator = z + w + 1
                if numerator % 6:
                    continue
                d = numerator // 6
                t = p - 1 - z - 6 * d
                q = p + d
                if not common_legal(T, J, shell_set, p, q, t, d):
                    continue
                r = t + 6 * d
                if r != p - 1 - z or w != t + 12 * d - p:
                    raise AssertionError("plus inverse algebra failure")
                if not (max(0, p - 12 * d) <= t <= p - 6 * d - 1):
                    continue
                events.append(Event("+", p, q, t, d, z, w))

    # Fail closed: the quotient-six chart should have one witness for
    # each (state, sign, lower prime).
    seen: dict[tuple[str, int, int, int], Event] = {}
    for ev in events:
        k = (ev.sign, ev.q, ev.t, ev.p)
        if k in seen and seen[k] != ev:
            raise AssertionError(f"multiple literal witnesses for {k}: {seen[k]} / {ev}")
        seen[k] = ev
    return sorted(set(events))


def enumerate_direct_events(
    T: int,
    J: int,
    shell: list[int],
    zeros: dict[int, frozenset[int]],
) -> set[tuple[Any, ...]]:
    """Independent small-T direct (p,q,t) enumeration."""
    out: set[tuple[Any, ...]] = set()
    for p in shell:
        zp = zeros[p]
        for q in shell:
            d = q - p
            if d <= 0 or J * d <= T:
                continue
            lo, hi = absolute_t_range(T, q)
            if lo > hi:
                continue
            for t in range(lo, hi + 1):
                a = d - t - 1
                r = 6 * d + t
                if 0 <= a < p and 0 <= r < p and a in zp and r in zp:
                    out.add(Event("-", p, q, t, d, a, r).key())

                r_plus = t + 6 * d
                z = p - 1 - r_plus
                w = t + 12 * d - p
                if (
                    0 <= r_plus < p
                    and 0 <= z < p
                    and 0 <= w < p
                    and z in zp
                    and w in zp
                ):
                    out.add(Event("+", p, q, t, d, z, w).key())
    return out


def dec_string(x: Decimal) -> str:
    return format(x, ".40g")


def run_shell(
    T: int,
    J: int,
    shell: list[int],
    zeros: dict[int, frozenset[int]],
    out_dir: Path,
    top_n: int,
    write_events_flag: bool,
    verify_direct_max: int,
) -> tuple[dict[str, Any], dict[str, float]]:
    events = enumerate_inverse_events(T, J, shell, zeros)

    direct_verified = False
    if T <= verify_direct_max:
        inverse_keys = {ev.key() for ev in events}
        direct_keys = enumerate_direct_events(T, J, shell, zeros)
        if inverse_keys != direct_keys:
            only_inverse = sorted(inverse_keys - direct_keys)[:20]
            only_direct = sorted(direct_keys - inverse_keys)[:20]
            raise AssertionError(
                "inverse/direct mismatch\n"
                f"only inverse: {only_inverse}\n"
                f"only direct: {only_direct}"
            )
        direct_verified = True

    by_minus: dict[tuple[int, int], dict[int, Event]] = defaultdict(dict)
    by_plus: dict[tuple[int, int], dict[int, Event]] = defaultdict(dict)
    for ev in events:
        target = by_minus if ev.sign == "-" else by_plus
        bucket = target[(ev.q, ev.t)]
        if ev.p in bucket and bucket[ev.p] != ev:
            raise AssertionError("occurrence multiplicity collapsed")
        bucket[ev.p] = ev

    qstats: dict[int, dict[str, Any]] = {}
    for q in shell:
        qstats[q] = {
            "q": q,
            "Z": len(zeros[q]),
            "pre_minus": 0,
            "pre_plus": 0,
            "pre_union": 0,
            "pre_raw": 0,
            "sq_minus": 0,
            "sq_plus": 0,
            "sq_union": 0,
            "sq_raw": 0,
            "fact_minus_pre": 0,
            "fact_plus_pre": 0,
            "fact_union_pre": 0,
            "fact_raw_pre": 0,
            "marked_minus": 0,
            "marked_plus": 0,
            "marked_union": 0,
            "marked_raw": 0,
            "F_minus": 0,
            "F_plus": 0,
            "F_union": 0,
            "F_sign": 0,
            "F_labelled": 0,
            "occupied_pre_states": 0,
            "occupied_marked_states": 0,
        }

    states = sorted(set(by_minus) | set(by_plus))
    fibre_rows: list[dict[str, Any]] = []
    weighted_pre_union = 0.0
    weighted_pre_raw = 0.0
    weighted_marked_union = 0.0
    weighted_marked_raw = 0.0
    selected_overlap_prime_count = 0

    for q, t in states:
        minus_events = by_minus.get((q, t), {})
        plus_events = by_plus.get((q, t), {})
        p_minus = set(minus_events)
        p_plus = set(plus_events)
        p_union = p_minus | p_plus
        p_overlap = p_minus & p_plus

        km = len(p_minus)
        kp = len(p_plus)
        ku = len(p_union)
        kr = km + kp
        fm = km * (km - 1)
        fp = kp * (kp - 1)
        fu = ku * (ku - 1)
        flabel = kr * (kr - 1)
        selected = t in zeros[q]
        if selected != ((q - 1 - t) in zeros[q]):
            raise AssertionError(f"upper reflection failure q={q}, t={t}")

        qs = qstats[q]
        qs["occupied_pre_states"] += 1
        for name, value in (
            ("pre_minus", km),
            ("pre_plus", kp),
            ("pre_union", ku),
            ("pre_raw", kr),
            ("sq_minus", km * km),
            ("sq_plus", kp * kp),
            ("sq_union", ku * ku),
            ("sq_raw", kr * kr),
            ("fact_minus_pre", fm),
            ("fact_plus_pre", fp),
            ("fact_union_pre", fu),
            ("fact_raw_pre", flabel),
        ):
            qs[name] += value

        w_minus = sum(math.log(p) for p in p_minus)
        w_plus = sum(math.log(p) for p in p_plus)
        w_union = sum(math.log(p) for p in p_union)
        weighted_pre_union += w_union
        weighted_pre_raw += w_minus + w_plus

        if selected:
            qs["occupied_marked_states"] += 1
            qs["marked_minus"] += km
            qs["marked_plus"] += kp
            qs["marked_union"] += ku
            qs["marked_raw"] += kr
            qs["F_minus"] += fm
            qs["F_plus"] += fp
            qs["F_union"] += fu
            qs["F_sign"] += fm + fp
            qs["F_labelled"] += flabel
            weighted_marked_union += w_union
            weighted_marked_raw += w_minus + w_plus
            selected_overlap_prime_count += len(p_overlap)

        fibre_rows.append(
            {
                "T": T,
                "J": J,
                "q": q,
                "t": t,
                "selected_upper": int(selected),
                "N6": 6 * q + t,
                "Nminus": q - 1 - t,
                "Nplus": 12 * q + t,
                "K_minus": km,
                "K_plus": kp,
                "K_union": ku,
                "K_raw": kr,
                "overlap_primes": sorted(p_overlap),
                "p_minus": sorted(p_minus),
                "p_plus": sorted(p_plus),
                "F_minus": fm,
                "F_plus": fp,
                "F_sign": fm + fp,
                "F_union": fu,
                "F_labelled": flabel,
            }
        )

    # Exact per-q variance numerators and density predictors.
    V_minus = Decimal(0)
    V_plus = Decimal(0)
    V_union = Decimal(0)
    V_raw = Decimal(0)
    mean_M_union = Decimal(0)
    mean_M_raw = Decimal(0)
    mean_F_union = Decimal(0)
    mean_F_raw = Decimal(0)

    q_rows: list[dict[str, Any]] = []
    for q in shell:
        qs = qstats[q]
        for kind in ("minus", "plus", "union", "raw"):
            total = int(qs[f"pre_{kind}"])
            sq = int(qs[f"sq_{kind}"])
            vnum = q * sq - total * total
            if vnum < 0:
                raise AssertionError(f"negative variance numerator q={q}, {kind}")
            qs[f"Vnum_{kind}"] = vnum

        V_minus += Decimal(qs["Vnum_minus"]) / Decimal(q)
        V_plus += Decimal(qs["Vnum_plus"]) / Decimal(q)
        V_union += Decimal(qs["Vnum_union"]) / Decimal(q)
        V_raw += Decimal(qs["Vnum_raw"]) / Decimal(q)

        Zq = Decimal(qs["Z"])
        dq = Decimal(q)
        mean_M_union += Zq * Decimal(qs["pre_union"]) / dq
        mean_M_raw += Zq * Decimal(qs["pre_raw"]) / dq
        mean_F_union += Zq * Decimal(qs["fact_union_pre"]) / dq
        mean_F_raw += Zq * Decimal(qs["fact_raw_pre"]) / dq

        q_rows.append(dict(qs))

    # Add occupied-coordinate centered-square scores after q means are known.
    for row in fibre_rows:
        q = int(row["q"])
        qs = qstats[q]
        mu_union = Decimal(qs["pre_union"]) / Decimal(q)
        mu_raw = Decimal(qs["pre_raw"]) / Decimal(q)
        row["centered_union_sq"] = dec_string(
            (Decimal(row["K_union"]) - mu_union) ** 2
        )
        row["centered_raw_sq"] = dec_string(
            (Decimal(row["K_raw"]) - mu_raw) ** 2
        )

    M_pre_minus = sum(qstats[q]["pre_minus"] for q in shell)
    M_pre_plus = sum(qstats[q]["pre_plus"] for q in shell)
    M_pre_union = sum(qstats[q]["pre_union"] for q in shell)
    M_pre_raw = sum(qstats[q]["pre_raw"] for q in shell)
    M_marked_union = sum(qstats[q]["marked_union"] for q in shell)
    M_marked_raw = sum(qstats[q]["marked_raw"] for q in shell)
    F_minus = sum(qstats[q]["F_minus"] for q in shell)
    F_plus = sum(qstats[q]["F_plus"] for q in shell)
    F_union = sum(qstats[q]["F_union"] for q in shell)
    F_sign = sum(qstats[q]["F_sign"] for q in shell)
    F_labelled = sum(qstats[q]["F_labelled"] for q in shell)
    sum_Z = sum(len(zeros[q]) for q in shell)

    # Exact Cauchy regression checks.
    if M_marked_union**2 > sum_Z * (F_union + M_marked_union):
        raise AssertionError("union Cauchy identity failed")
    M_marked_minus = sum(qstats[q]["marked_minus"] for q in shell)
    M_marked_plus = sum(qstats[q]["marked_plus"] for q in shell)
    if M_marked_minus**2 > sum_Z * (F_minus + M_marked_minus):
        raise AssertionError("minus Cauchy identity failed")
    if M_marked_plus**2 > sum_Z * (F_plus + M_marked_plus):
        raise AssertionError("plus Cauchy identity failed")

    # Exact sign/union overlap inequalities.
    if F_sign > 2 * F_union:
        raise AssertionError("F_sign <= 2 F_union failed")
    if F_union > 2 * F_sign + M_marked_union:
        raise AssertionError("F_union <= 2 F_sign + M_union failed")
    if not (F_union <= F_labelled <= 4 * F_union + 2 * M_marked_union):
        raise AssertionError("labelled/union comparison failed")

    L = math.log(T)
    B = T**2 * L ** (-2)
    U0 = T ** (8 / 5) * L ** (-4 / 5)
    M0 = T ** (11 / 5) * L ** (-3 / 5)
    F0 = T ** (12 / 5) * L ** (-16 / 5)
    weighted_target = T**2 / L

    def ratio_int(x: int | float, y: float) -> float:
        return float(x) / y if y else math.nan

    def ratio_dec(x: Decimal, y: float) -> float:
        return float(x / Decimal(str(y))) if y else math.nan

    marked_rows = [r for r in fibre_rows if r["selected_upper"]]
    top_selected = sorted(
        marked_rows,
        key=lambda r: (-r["K_union"], -r["F_union"], r["q"], r["t"]),
    )[:top_n]
    top_collisions = sorted(
        marked_rows,
        key=lambda r: (-r["F_union"], -r["K_union"], r["q"], r["t"]),
    )[:top_n]
    top_pre = sorted(
        fibre_rows,
        key=lambda r: (-r["K_union"], -r["K_raw"], r["q"], r["t"]),
    )[:top_n]
    top_variance = sorted(
        fibre_rows,
        key=lambda r: (
            -Decimal(r["centered_raw_sq"]),
            -r["K_raw"],
            r["q"],
            r["t"],
        ),
    )[:top_n]

    top_collision_mass = sum(r["F_union"] for r in top_collisions)
    max_K_union = max((r["K_union"] for r in marked_rows), default=0)
    max_K_raw = max((r["K_raw"] for r in marked_rows), default=0)

    summary: dict[str, Any] = {
        "T": T,
        "J": J,
        "shell": "T/7 < p,q <= T/3",
        "shell_prime_count": len(shell),
        "sum_Z_upper_states": sum_Z,
        "candidate_event_count": len(events),
        "occupied_pre_states": len(fibre_rows),
        "occupied_marked_states": len(marked_rows),
        "direct_enumeration_verified": direct_verified,
        "M_pre_minus": M_pre_minus,
        "M_pre_plus": M_pre_plus,
        "M_pre_union": M_pre_union,
        "M_pre_raw": M_pre_raw,
        "M_marked_union": M_marked_union,
        "M_marked_raw": M_marked_raw,
        "F_minus": F_minus,
        "F_plus": F_plus,
        "F_sign": F_sign,
        "F_union": F_union,
        "F_labelled": F_labelled,
        "selected_sign_overlap_prime_count": selected_overlap_prime_count,
        "V_minus": dec_string(V_minus),
        "V_plus": dec_string(V_plus),
        "V_sign_sum": dec_string(V_minus + V_plus),
        "V_union": dec_string(V_union),
        "V_raw": dec_string(V_raw),
        "upper_density_predictor_M_union": dec_string(mean_M_union),
        "upper_density_predictor_M_raw": dec_string(mean_M_raw),
        "upper_density_predictor_F_union": dec_string(mean_F_union),
        "upper_density_predictor_F_raw": dec_string(mean_F_raw),
        "marked_to_density_M_union": (
            float(Decimal(M_marked_union) / mean_M_union)
            if mean_M_union
            else None
        ),
        "marked_to_density_F_union": (
            float(Decimal(F_union) / mean_F_union) if mean_F_union else None
        ),
        "weighted_pre_union": weighted_pre_union,
        "weighted_pre_raw": weighted_pre_raw,
        "weighted_marked_union": weighted_marked_union,
        "weighted_marked_raw": weighted_marked_raw,
        "max_K_union_marked": max_K_union,
        "max_K_raw_marked": max_K_raw,
        "top_collision_share": (
            top_collision_mass / F_union if F_union else None
        ),
        "thresholds": {
            "B_marked_mass": B,
            "U0_selected_states": U0,
            "M0_unmarked_mass": M0,
            "F0_collision_or_variance": F0,
            "weighted_gate": weighted_target,
        },
        "normalized": {
            "sum_Z_over_U0": ratio_int(sum_Z, U0),
            "M_pre_union_over_M0": ratio_int(M_pre_union, M0),
            "M_pre_raw_over_M0": ratio_int(M_pre_raw, M0),
            "M_marked_union_over_B": ratio_int(M_marked_union, B),
            "M_marked_raw_over_B": ratio_int(M_marked_raw, B),
            "F_union_over_F0": ratio_int(F_union, F0),
            "F_sign_over_F0": ratio_int(F_sign, F0),
            "F_labelled_over_F0": ratio_int(F_labelled, F0),
            "V_union_over_F0": ratio_dec(V_union, F0),
            "V_raw_over_F0": ratio_dec(V_raw, F0),
            "V_sign_sum_over_F0": ratio_dec(V_minus + V_plus, F0),
            "weighted_marked_raw_over_target": ratio_int(
                weighted_marked_raw, weighted_target
            ),
        },
        "heaviest_marked_union": top_selected[0] if top_selected else None,
    }

    shell_dir = out_dir / f"T_{T}"
    write_json(shell_dir / f"summary_T{T}.json", summary)

    fibre_fields = [
        "T",
        "J",
        "q",
        "t",
        "selected_upper",
        "N6",
        "Nminus",
        "Nplus",
        "K_minus",
        "K_plus",
        "K_union",
        "K_raw",
        "overlap_primes",
        "p_minus",
        "p_plus",
        "F_minus",
        "F_plus",
        "F_sign",
        "F_union",
        "F_labelled",
        "centered_union_sq",
        "centered_raw_sq",
    ]
    write_csv(shell_dir / f"fibres_T{T}.csv", fibre_rows, fibre_fields)
    write_csv(
        shell_dir / f"heaviest_selected_T{T}.csv", top_selected, fibre_fields
    )
    write_csv(
        shell_dir / f"heaviest_collisions_T{T}.csv", top_collisions, fibre_fields
    )
    write_csv(shell_dir / f"heaviest_pre_T{T}.csv", top_pre, fibre_fields)
    write_csv(
        shell_dir / f"heaviest_variance_T{T}.csv", top_variance, fibre_fields
    )

    q_fields = [
        "q",
        "Z",
        "occupied_pre_states",
        "occupied_marked_states",
        "pre_minus",
        "pre_plus",
        "pre_union",
        "pre_raw",
        "marked_minus",
        "marked_plus",
        "marked_union",
        "marked_raw",
        "F_minus",
        "F_plus",
        "F_sign",
        "F_union",
        "F_labelled",
        "Vnum_minus",
        "Vnum_plus",
        "Vnum_union",
        "Vnum_raw",
    ]
    write_csv(shell_dir / f"q_stats_T{T}.csv", q_rows, q_fields)

    if write_events_flag:
        event_rows = []
        for ev in events:
            row = asdict(ev)
            row["selected_upper"] = int(ev.t in zeros[ev.q])
            row["N6"] = 6 * ev.q + ev.t
            row["Nminus"] = ev.q - 1 - ev.t
            row["Nplus"] = 12 * ev.q + ev.t
            event_rows.append(row)
        event_fields = [
            "sign",
            "p",
            "q",
            "t",
            "d",
            "lower_left",
            "lower_right",
            "selected_upper",
            "N6",
            "Nminus",
            "Nplus",
        ]
        write_csv(shell_dir / f"events_T{T}.csv", event_rows, event_fields)

    fit_values = {
        "T": float(T),
        "sum_Z": float(sum_Z),
        "M_pre_union": float(M_pre_union),
        "M_pre_raw": float(M_pre_raw),
        "M_marked_union": float(M_marked_union),
        "M_marked_raw": float(M_marked_raw),
        "F_union": float(F_union),
        "F_sign": float(F_sign),
        "F_labelled": float(F_labelled),
        "V_union": float(V_union),
        "V_raw": float(V_raw),
        "V_sign_sum": float(V_minus + V_plus),
        "weighted_marked_raw": float(weighted_marked_raw),
        "max_K_union": float(max_K_union),
        "B": B,
        "U0": U0,
        "M0": M0,
        "F0": F0,
        "weighted_target": weighted_target,
    }
    return summary, fit_values


def solve_linear(A: list[list[float]], b: list[float]) -> list[float] | None:
    n = len(b)
    aug = [A[i][:] + [b[i]] for i in range(n)]
    for col in range(n):
        pivot = max(range(col, n), key=lambda r: abs(aug[r][col]))
        if abs(aug[pivot][col]) < 1e-12:
            return None
        aug[col], aug[pivot] = aug[pivot], aug[col]
        scale = aug[col][col]
        aug[col] = [x / scale for x in aug[col]]
        for r in range(n):
            if r == col:
                continue
            factor = aug[r][col]
            if factor:
                aug[r] = [
                    aug[r][c] - factor * aug[col][c]
                    for c in range(n + 1)
                ]
    return [aug[i][n] for i in range(n)]


def ols(
    X: list[list[float]], y: list[float], names: list[str]
) -> dict[str, Any] | None:
    n = len(y)
    k = len(names)
    if n <= k:
        return None
    gram = [[0.0] * k for _ in range(k)]
    rhs = [0.0] * k
    for row, yi in zip(X, y):
        for i in range(k):
            rhs[i] += row[i] * yi
            for j in range(k):
                gram[i][j] += row[i] * row[j]
    beta = solve_linear(gram, rhs)
    if beta is None:
        return None
    fitted = [sum(a * c for a, c in zip(row, beta)) for row in X]
    rss = sum((yi - fi) ** 2 for yi, fi in zip(y, fitted))
    mean_y = sum(y) / n
    tss = sum((yi - mean_y) ** 2 for yi in y)
    rmse = math.sqrt(rss / n)
    aic = n * math.log(rss / n) + 2 * k if rss > 0 else None
    return {
        "n": n,
        "coefficients": dict(zip(names, beta)),
        "rmse_log": rmse,
        "r_squared": 1.0 - rss / tss if tss > 0 else None,
        "aic": aic,
    }


def fit_metric(
    records: list[dict[str, float]],
    metric: str,
    threshold: str | None,
    fixed_alpha: float | None,
) -> dict[str, Any]:
    points = [r for r in records if r.get(metric, 0.0) > 0.0]
    result: dict[str, Any] = {
        "metric": metric,
        "positive_shells": len(points),
        "warning": (
            "Finite-shell regression is descriptive only. Use at least five "
            "positive shells and compare rolling/holdout stability."
        ),
    }
    if len(points) < 3:
        result["status"] = "insufficient nonzero shells"
        return result

    logT = [math.log(r["T"]) for r in points]
    logL = [math.log(math.log(r["T"])) for r in points]
    logy = [math.log(r[metric]) for r in points]

    result["pure_power"] = ols(
        [[1.0, x] for x in logT], logy, ["log_C", "alpha_T"]
    )
    if len(points) >= 4:
        result["power_times_log"] = ols(
            [[1.0, x, z] for x, z in zip(logT, logL)],
            logy,
            ["log_C", "alpha_T", "beta_log"],
        )

    if threshold is not None:
        logr = [math.log(r[metric] / r[threshold]) for r in points]
        result["threshold_ratio_power"] = ols(
            [[1.0, x] for x in logT],
            logr,
            ["log_C_ratio", "delta_T"],
        )

    if fixed_alpha is not None:
        adjusted = [y - fixed_alpha * x for y, x in zip(logy, logT)]
        result["fixed_T_power_fit_log"] = ols(
            [[1.0, z] for z in logL],
            adjusted,
            ["log_C", "beta_log"],
        )
    return result

## 8. How to read the fitted laws

For each nonzero statistic the scanner fits competing models

\[
Y(T)=CT^\alpha
\]

and

\[
Y(T)=CT^\alpha(\log T)^\beta.
\]

It also fits the theorem-normalized ratio

\[
Y(T)/Y_0(T)=CT^\delta
\]

and, with the theorem's \(T\)-power fixed, estimates only the logarithmic exponent. The output includes log-RMSE, \(R^2\), and AIC where defined.

These regressions are descriptive only. The correct protocol is:

```text
- require at least five positive shells;
- never replace a zero collision count by 1 or another pseudocount;
- compare pure-power and power-log residuals;
- repeat on trailing windows of shells;
- hold out the largest shell and predict it;
- inspect the top-fibre share before interpreting a global exponent;
- report instability rather than selecting the visually preferred law.
```

The key competing empirical scenarios are:

1. **Diffuse Poisson-like load:** bounded or very slowly growing `max_K_union`, actual/predicted marked collision ratio near a stable polylogarithmic scale, and top-fibre share tending downward.
2. **Rare heavy fibres:** modest total mass but growing `max_K_union` and a top-fibre share bounded away from zero. This points to a pointwise carrier lemma rather than a global variance theorem.
3. **Upper-mark resonance:** pre-upper \(V\) is small or threshold-compatible, but `marked_to_density_F_union` grows. This isolates failure specifically in the upper selected-state test.
4. **Lower adaptive concentration:** \(V_{\rm up}\) itself grows above \(F_0\), with identifiable \((q,t,N_6,N_-,N_+)\) rows. This points to a pre-upper load theorem before any upper-zero analysis.

## 9. Concise structurally testable conjecture

The scan suggests testing a pointwise statement before attempting another global large sieve.

### Conjecture — selected fixed-carrier shell sparsity

For every fixed \(J\) and every \(\varepsilon>0\), uniformly over literal quotient-six states satisfying all source masks,

\[
\boxed{
\max_{\substack{q\asymp_JT,\ 0\le t<q\\q\mid b_t}}
K_\vee(q,t)
\ll_{J,\varepsilon}T^\varepsilon.
}
\tag{9.1}
\]

Equivalently, after retaining the exact windows, the number of lower primes \(p\in(T/7,T/3]\) for which either literal pair

\[
(a,r)=(q-p-t-1,\,6(q-p)+t)
\]

or

\[
(z,w)=(p-1-t-6(q-p),\,t+12(q-p)-p)
\]

lies in \(\mathcal Z_p^2\) is subpolynomial at every selected upper state.

This is stronger than the aggregate target but closes it from the current endpoint. Indeed,

\[
F_\vee
\le(\max K_\vee)M_\vee
\le T^\varepsilon M_0,
\]

and therefore

\[
\frac{F_\vee}{F_0}
\ll T^{\varepsilon-1/5}L^{13/5}\to0
\]

for any fixed \(\varepsilon<1/5\).

Conjecture (9.1) is not an independence assertion and is directly falsifiable by the `heaviest_selected` output. It also points to a concrete arithmetic object: each exceptional fibre supplies many shell primes simultaneously dividing one of the two role-marked carrier pairs

\[
(b_{N_6},b_{N_-})
\quad\text{or}\quad
(b_{N_6},b_{N_+}),
\qquad
(N_6,N_-,N_+)=(6q+t,q-1-t,12q+t),
\]

with \(q\mid b_t\). A successful proof would need an occurrence-preserving shell-prime sparsity theorem for these three linked Apéry indices, not raw integer height alone.

## Final conclusion

The exact sparse inversion lemma is proved and supplies a complete reproducible census design. The first derivational failure is also exact:

```text
unrestricted affine pair density
        does not imply
conditional pair density inside an anchored, prime, windowed,
upper-selected C4 state set.
```

Quantitatively, even a legally transferred two-zero density \(T^{-2/3}\) misses by \(T^{2/15}(\log T)^{8/5}\). The missing theorem must recover an average factor stronger than \(T^{-2/15}(\log T)^{-8/5}\); the natural upper-zero density \(T^{-1/3}\) is more than enough, but multiplying it into the adaptive lower-pair mask is precisely the unproved cross-characteristic statement.

The scanner separates the two plausible closure mechanisms without circularity:

```text
post-selected marked collisions:
    F_vee = sum_(q|b_t) (K_vee(q,t))_2

pre-upper centered load:
    V_up = sum_(q,t) (A(q,t)-A_q/q)^2,
    with q|b_t absent from A
```

It preserves the literal windows, both primality tests, all zero conditions, sign overlap, distinct-lower-prime convention, and event witnesses. The first empirical question is now unambiguous: does the maximum selected fibre remain subpolynomial, or do a few carrier triples dominate the theorem-normalized collision mass?
