# CONCRETE PARTIAL

The corrected exterior-minor family is valid only in the following form:

```text
W_h(n)=b_n B_{n+h}-B_n b_{n+h},
```

and therefore

```text
d_n=gcd(b_n,B_n) | W_h(n)
```

for every admissible shift h.  The previous Q1364-style attempt using determinants with different origins is invalid: the common divisor is not preserved when the base point changes.

## 1. Exact parity recurrences for B

Let

```text
E_m=B_{2m},   O_m=B_{2m+1}.
```

From the binomial definition one obtains

```text
(m+1)E_{m+1}=2(2m+1)E_m,
```

and

```text
m(m+2)O_{m+1}=(2m+2)(2m+1)O_m.
```

Equivalently, the one-step ratios are

```text
E_{m+1}/E_m = 2(2m+1)/(m+1),

O_{m+1}/O_m = (2m+2)(2m+1)/(m(m+2)).
```

These are the only parity recurrences used below.

## 2. Exterior minors with a shift set

For a finite shift set S_n define

```text
I(S_n)=gcd({W_h(n):h in S_n}).
```

Then

```text
d_n | I(S_n).
```

The remaining question is whether a primitive Ore/Bézout reduction of I(S_n) can remove all exponential common content.

The obstruction is that the B-side content is controlled by Kummer carries.  For a prime p,

```text
v_p(B_t)=# carries when subtracting floor(t/2)-1 from t-1 in base p.
```

Hence a prime p dividing B_n can persist over an interval of neighboring shifts.  On such an interval

```text
p | B_{n+h}
```

for every h in the interval, so every W_h(n) has the same forced p-content:

```text
W_h(n)=b_n B_{n+h}-B_n b_{n+h} == 0 (mod p).
```

Increasing |S_n| does not automatically remove this content; the exterior minors only see the rank-one relation modulo these primes.

## 3. Current obstruction status

## 4. Exact verification code (n <= 100)

```python
from math import comb, gcd


def b(n):
    return sum(comb(n,k)**2*comb(n+k,k)**2 for k in range(n+1))


def B(n):
    return comb(n-1,n//2-1)


def W(n,h):
    return b(n)*B(n+h)-B(n)*b(n+h)

# verify parity recurrences and exterior divisibility
for m in range(2,50):
    assert (m+1)*B(2*m+2)==2*(2*m+1)*B(2*m)
    assert m*(m+2)*B(2*m+3)==(2*m+2)*(2*m+1)*B(2*m+1)

for n in range(4,101):
    d=gcd(b(n),B(n))
    for h in [-3,-2,-1,1,2,3]:
        assert W(n,h)%d==0

# counterexample to shifted-origin gcd inference
assert gcd(504,504)==504

print('checks passed')
```
