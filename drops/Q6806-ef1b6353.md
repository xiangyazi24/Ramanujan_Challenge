## Correct convolution construction

Write

    J = [a,a+q-1] subset F_p,

with q < p/2 (in the application q~D/2 and D=o(N), so eventually this holds). Define

    C = [0,q-1],
    A = [a-q+1,a+q-1].

Then |C|=q and |A|=2q-1. Also 2q-1<p, so these are genuine cyclic intervals with no ambiguity in their listed representatives.

Define

    W = q^{-1} 1_A * 1_C.

For x in J, the number of representations

    x = y+z, y in A, z in C

is exactly q.

Proof: write x=a+s with 0<=s<=q-1. For every z in [0,q-1],

    y=x-z=a+s-z.

The minimum is a-(q-1), and the maximum is a+(q-1), hence y is always in A. Thus all q choices of z give representations.

Conversely, if x is outside J, the representation count is at most q and nonzero only on the interval

    A+C=[a-q+1,a+2q-2],

so W is nonnegative and majorizes 1_J, because W=1 on J. The extra support is intentional; no wrap-around creates additional representations because 2q-1<p. The interval sums are injective in the chosen coordinate window.

The total mass is

    sum_x W(x)=q^{-1}|A||C|=2q-1.

## Correct Fourier L1 estimate

With the unnormalized finite Fourier transform,

    What(xi)=q^{-1} Ahat(xi) Chat(xi).

Therefore

    sum_xi |What(xi)|
      <= q^{-1}(sum_xi |Ahat(xi)|^2)^{1/2}
              (sum_xi |Chat(xi)|^2)^{1/2}.

Parseval gives

    sum |Ahat|^2 = p|A| = p(2q-1),
    sum |Chat|^2 = pq.

Hence

    ||What||_1 <= q^{-1} p sqrt(q(2q-1))
                = p sqrt((2q-1)/q)
                < sqrt(2)p.

This is the claimed estimate. It does not use, and is not implied by, any L2 bound on W itself.
