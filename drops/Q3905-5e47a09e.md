## 4.2 Strict positivity of `N_h(x)`

\[
y_0=0,
\qquad y_1=1,
\tag{4.1}

=P(n)y_j-n^3y_{j-1}.
\tag{4.2}

The exact identity

\[
\boxed{
P(n)-n^3-(n+1)^3=4(2n+1)^3>0

\tag{4.3}

\[
\begin{aligned}
(n+1)^3y_{j+1}
&=P(n)y_j-n^3y_{j-1}\\
&>(P(n)-n^3)y_j\\
&>(n+1)^3y_j.
\end{aligned}

Hence

\[
0=y_0<y_1<y_2<\cdots.
\tag{4.4}

With the normalization (0.1),

\boxed{N_h(x)>0
\quad(x\ge0,\ h\ge1).}
\tag{4.6}

There is therefore no hidden integer fibre with `N_h(x)=0` in which every prime would divide the value.

# 7. Squarefreeness and the exact `rho` height inequality

For fixed `(d,v)`, the map

\[
p\longmapsto q'=p+d
\tag{7.1}
\]

is injective. The product ranges over a set of lower primes once each and retains only prime values `q'`. Hence

\[
\boxed{S_d(v)\text{ is squarefree}.}
\tag{7.2}
\]

Therefore every common gcd (1.7) is also squarefree. The valuation of `N_h(x)` at a lower prime may exceed one, but the carrier records only the corresponding upper prime once.

Let

\[
\rho_{J,T}
:=
\max
\left\{
\frac{\log q'}{\log p}:
 p\in\mathcal P_{\mathrm{low}}(J,T),
 q'\in\mathcal P_{\mathrm{up}}(J,T)
\right\}.
\tag{7.3}
\]

Equivalently one may use the safe shell endpoint ratio

\[
\rho_{J,T}
=
\frac{\log Q_{\max}(J,T)}{\log P_{\min}(J,T)}.
\tag{7.4}
\]

This is finite and

\[
\rho_{J,T}=1+O_J(1/\log T).
\]

Let

\[
P_d^*(v):=
\prod_{p\in\mathcal P^{\mathrm{rev}}_{d,v}(T)}p.
\]

The factors are distinct prime divisors of the positive integer `N_h(x)`, so

\[
P_d^*(v)\mid N_h(x)
\quad\Longrightarrow\quad
\sum_p\log p\le\log N_h(x).
\tag{7.5}
\]

Consequently

\[
\begin{aligned}
\log S_d(v)
&=
\sum_p\log(p+d)\\
&\le
\rho_{J,T}\sum_p\log p\\
&\le
\boxed{\rho_{J,T}\log N_h(x)}.
\end{aligned}
\tag{7.6}
\]

Together with (4.10),

\[
\boxed{
\log S_d(v)\ll_J h\log T.
}
\tag{7.7}
\]

If the proof writes an abstract `rho`, it must be defined to dominate the logarithmic shell ratio in (7.3). If it takes `rho=1` exactly, (7.6) is false because `q'=p+d>p`. If it uses a fixed `rho_J>1` obtained from shell endpoints, the inequality is valid.

The fixed-term fibres are one:

- `(v,d,p)` determines `q'=p+d`;
- `(v,d,q')` determines `p=q'-d`;
- `(v,d_1,d_2,q')` determines both candidate lower primes `q'-d_i` and all four lower coordinates.

A fixed prime factor therefore reconstructs one raw continuant-return candidate. It need not reconstruct an actual event, by Section 6.

# 8. Exact centered factorial identity

Let

\[
0<d_1<\cdots<d_k
\]

be any ordered shift set. Let the capacity threshold be an integer

\[
H\in\mathbb Z_{\ge0}.
\]

Define the unordered centered wedge

\[
\mathcal W_H
:=
\{(i,j):1\le i<j\le k,\ j>H\}.
\tag{8.1}
\]

Then

\[
\begin{aligned}
|\mathcal W_H|
&=
\sum_{j=H+1}^{k}(j-1)\\
&=
\left(\binom{k}{2}-\binom{H}{2}\right)_+\\
&=
\boxed{
\frac{(k-H)_+(k+H-1)}2
}.
\end{aligned}
\tag{8.2}
\]

Equivalently, in falling-factorial normalization,

\[
\bigl(k(k-1)-H(H-1)\bigr)_+
=(k-H)_+(k+H-1),
\tag{8.3}
\]

which is twice the unordered count.

If the project parameter `lambda` is already declared integral, take `H=lambda`. If `lambda` is real, the exact centered condition `j>lambda` is

\[
j>\lfloor\lambda\rfloor,
\]

so every occurrence of `lambda` in (8.2) must be replaced by

\[
H:=\lfloor\lambda\rfloor.
\tag{8.4}
\]

Using `binom(lambda,2)` with a nonintegral `lambda` is not an exact counting identity. Asymptotically `H~lambda` is harmless only after `lambda->infinity` has been stated.

Phantom continuant shifts can only increase the rank of an actual shift in an overcarrier-ordered list. Therefore an actual second endpoint whose actual rank exceeds `H` also has overcarrier rank exceeding `H`; using the larger raw list is a safe centered overcount.

# 9. `(FURC)_lambda`: correct weighted scale, but not a theorem

For a raw pair of shifts define the squarefree common-upper overcarrier

\[
C^{\uparrow}_{v;d_1,d_2}
=\gcd\bigl(b_v,S_{d_1}(v),S_{d_2}(v)\bigr).
\tag{9.1}
\]

Let `B_H^raw(T)` be any predetermined raw pair family containing every shift pair underlying an actual `H`-centered residual plus wedge. It may be the full raw-legal pair set; that only makes the hypothesis stronger. Define the logarithmic aggregate

\[
\mathcal G^{\mathrm{cont}}_H(T)
:=
\sum_{(v,d_1,d_2)\in\mathcal B_H^{\mathrm{raw}}(T)}
\log C^{\uparrow}_{v;d_1,d_2}.
\tag{9.2}
\]

Because the common gcd is squarefree, its logarithm is exactly the sum of `log q'` over its upper-prime factors. For every actual centered wedge, its actual upper prime `q` divides the corresponding term by (5.7). Fixed `(v,d_1,d_2,q)` reconstructs the two lower primes and the actual upper state, so there is no unbounded forward fibre. Multiple upper primes in one gcd are all paid separately by its logarithm.

Hence

\[
\boxed{
\sum_{w\in\mathcal W_H^{\mathrm{actual}}(T)}
\log q_w
\le
\mathcal G^{\mathrm{cont}}_H(T).
}
\tag{9.3}
\]

Every shell upper prime satisfies

\[
\log q_w\asymp_J L,
\qquad L:=\log T.
\tag{9.4}
\]

Therefore

\[
|\mathcal W_H^{\mathrm{actual}}(T)|
\ll_J
\frac{\mathcal G^{\mathrm{cont}}_H(T)}{L}.
\tag{9.5}
\]

The desired centered unweighted scale is

\[
o_J\!\left(H\frac{T^2}{L^2}\right).
\tag{9.6}
\]

Thus the correctly normalized logarithmic hypothesis is

\[
\boxed{
\mathcal G^{\mathrm{cont}}_H(T)
=o_J\!\left(H\frac{T^2}{L}\right).
}
\tag{FURC}_H
\]

If `lambda` is integral, this is precisely

\[
\boxed{
\mathcal G^{\mathrm{cont}}_\lambda(T)
=o_J\!\left(\lambda\frac{T^2}{\log T}\right).
}
\tag{FURC}_\lambda
\]

The scale is correct. There is one fewer logarithm on the right than in the unweighted wedge target because the left side already weights each upper prime by `log q\asymp log T`.

Two normalization warnings are essential:

1. If the left side were instead
   \[
   \sum\omega(C^{\uparrow}),
   \]
   an unweighted prime-factor count, the correct target would be
   \[
   o_J(H T^2/L^2),
   \]
   not `o_J(H T^2/L)`.
2. If ordered wedges are used, both the actual factorial count and the carrier aggregate acquire the same factor `2`; the asymptotic scale is unchanged.

Most importantly, `(FURC)_lambda` is **not proved** by the pointwise estimate

\[
\log S_d(v)\le\rho\log N_h(x).
\]

The same upper prime can occur in many products and in many shift pairs. Summing pointwise heights pays that prime once per reuse and gives no off-diagonal saving. `(FURC)_lambda` is exactly the missing repeated cross-characteristic correlation between

\[
q'\mid b_v
\]

and

\[
q'-d_i\mid N_{h_{d_i}(v)}(x_{d_i}(v)),
\qquad i=1,2.
\]

A checker cannot establish this asymptotic estimate by finite enumeration.
