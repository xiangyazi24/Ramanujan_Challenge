Q6648 - complete reissue of the [COLL-2H] attack, with the h <= 30 update

# 1. Verdict

The symmetry analysis does not prove the original linear estimate

  #Sigma_h <= 2h - 3.

What it does is more structural.

1. After the Morse/nonzero gate, collisions are controlled by an algebraic
   equivalence relation on the 2h-2 reflection-pairs of critical points.

2. Reflection and complex conjugation force every generic collision into a
   four-value packet, and every nonzero real critical value into a four-point
   collision packet.

3. The correct Galois object is not the full set of 4h-4 critical points. That
   action is necessarily imprimitive because reflection gives rational blocks
   of size two. The correct object is the quotient set of 2h-2 reflection
   blocks.

4. On that quotient, equality of squared critical values is a Galois-invariant
   partition. If the quotient Galois action is primitive and the squared-value
   map is not constant, then the partition must be discrete. Therefore

     Sigma_h = empty,
     V_h is squarefree,
     s_h = 4h - 4.

   Thus the natural Galois theorem is stronger than [COLL-2H]: it gives full
   Morse behavior, not merely a linear upper bound for collisions.

5. The fact that C_h has no real roots has a clean consequence. A nonzero real
   critical value would be attained at two conjugate nonreal critical points;
   reflection then produces two more critical points over the opposite value.
   Hence a real value forces a four-point collision packet and forces both t and
   -t to be repeated roots of V_h. Therefore

     C_h has no real roots
     + V_h is squarefree
     + V_h(0) != 0

   implies that f_h has no real critical values.

The last implication is an explanation of the observed absence of real critical
values. It is not, by itself, an all-h proof of either the no-real-root theorem
or squarefreeness of V_h.

# 2. Exact setup and the collision count

Use

  q_h(X) = prod_{a=1}^h (X+a),
  D_h(X) = q_h(X)^3,
  f_h(X) = N_h(X) / D_h(X),

and

  C_h(X) = q_h(X) N_h'(X) - 3 q_h'(X) N_h(X).

Then

  f_h'(X) = C_h(X) / q_h(X)^4,
  deg C_h = 4h - 4.

The critical-value resultant is

  V_h(T) = Res_X(C_h(X), N_h(X) - T D_h(X)).

No root of C_h is a pole, so

  deg_T V_h = 4h - 4.

Let

  Omega_h = {x in Qbar : C_h(x)=0}.

The Morse/nonzero gate is

  gcd(C_h,C_h') = 1,
  gcd(C_h,N_h) = 1.                                    (2.1)

Under (2.1), Omega_h has exactly 4h-4 points, every critical point is
simple, and every critical value is nonzero.

For a critical value t define

  m_t = #{x in Omega_h : f_h(x)=t}.

Define

  Sigma_h
    = {x in Omega_h : there exists y != x with f_h(y)=f_h(x)}.

Then

  #Sigma_h = sum_{m_t >= 2} m_t,

and the number s_h of simple nonzero critical values is exactly

  s_h = (4h-4) - #Sigma_h.                              (2.2)

Thus

  [COLL-2H]
  #Sigma_h <= 2h-3

implies

  s_h >= 2h-1.

There is already a small parity improvement. Put

  rho(x) = -h-1-x.

The midpoint fixed by rho has f_h=0 because f_h is odd about that midpoint.
The nonzero gate therefore excludes a critical point fixed by rho. Since
Sigma_h is rho-stable, rho acts freely on Sigma_h, and hence

  #Sigma_h is even.                                    (2.3)

Consequently [COLL-2H] is equivalent, under the gate, to the slightly stronger
looking integer bound

  #Sigma_h <= 2h-4.                                    (2.4)

This parity is useful bookkeeping, but it is nowhere near enough to prove the
bound.

# 3. Reflection, conjugation, and the quadruple structure

The two involutions are

  rho(x) = -h-1-x,
  c(x)   = conjugate(x).

They commute, and

  f_h(rho(x)) = -f_h(x),
  f_h(c(x))   = conjugate(f_h(x)).                      (3.1)

Also the critical set is stable under both involutions. Thus the Klein four
set

  K = {1,rho,c,rho*c}

acts on Omega_h.

If

  t = f_h(x),

then the four associated values are

  x              -> t,
  c(x)           -> conjugate(t),
  rho(x)         -> -t,
  rho(c(x))      -> -conjugate(t).                      (3.2)

Assume now the machine-supported real-root statement

  C_h has no real roots.                                (3.3)

Then c has no fixed point on Omega_h. The involution rho also has no fixed
critical point, because its only fixed point is the real midpoint. The only
possible two-element K-orbits are points fixed by rho*c, namely points on the
vertical symmetry line

  Re(x) = -(h+1)/2.

For such a point rho(x)=c(x), and (3.1) gives

  conjugate(t) = -t,

so its critical value is purely imaginary. All other K-orbits have four
points and value packet

  {t, conjugate(t), -t, -conjugate(t)}.                 (3.4)

This is the basic quadruple structure.

# 4. Exact real-value obstruction

Here is the cleanest consequence of the quadruple structure.

[REAL-VALUE-QUADRUPLE]

Assume (2.1) and (3.3). If a critical point x has a real critical value

  t = f_h(x) in R,

then t != 0 and there are four distinct critical points

  x, c(x), rho(x), rho(c(x))

with values

  t, t, -t, -t.                                        (4.1)

Proof.

Because C_h has no real roots, x != c(x). Since the midpoint is not critical,
x != rho(x). If c(x)=rho(x), then

  t = f_h(c(x)) = f_h(rho(x)) = -t,

so t=0, contradicting the nonzero gate. The same argument excludes all other
unwanted identifications among the four points. Equation (3.1) gives the values
in (4.1).

Therefore x and c(x) are two distinct points over t, while rho(x) and rho(c(x))
are two distinct points over -t. Hence t and -t are both repeated roots of
V_h, and all four points lie in Sigma_h.

Corollary.

If

  C_h has no real roots,
  V_h is squarefree,
  V_h(0) != 0,

then f_h has no real critical values.                    (4.2)

This is a complete explanation of the observed real-value exclusion once the
two algebraic inputs are known. It is important not to overstate it:

- Squarefreeness of V_h alone does not exclude a simple real critical value
  coming from a real critical point.

- The no-real-root theorem alone does not exclude real critical values; it says
  that any such value would be repeated.

- The combination excludes them.

There is a similar, but slightly less rigid, statement for purely imaginary
values. If t is purely imaginary and x is not on the vertical symmetry line,
then the K-orbit itself produces two collisions over t and -t. If x lies on the
vertical symmetry line, its K-orbit has only two points and no collision is
forced. Thus the vertical-line locus is the unique symmetry exception to a
uniform four-point statement for imaginary values.

# 5. Collision packets beyond the real axis

Suppose x != y and

  f_h(x) = f_h(y) = t.                                  (5.1)

Applying c and rho gives collision fibers over

  t,
  conjugate(t),
  -t,
  -conjugate(t).                                        (5.2)

If t is neither real nor purely imaginary, these four values are distinct.
Moreover y cannot belong to the K-orbit of x, because the four points in that
orbit have the four distinct values in (3.4). Thus a single off-axis collision
produces two distinct K-orbits, hence at least eight distinct points of Sigma_h.

For a nonzero real value, the packet collapses from four values to two values,
but Section 4 still gives four distinct colliding points.

For a purely imaginary value, the packet also collapses to two values. Away from
the vertical symmetry line it again gives four colliding points. On the vertical
line one must treat fixed blocks separately.

Therefore the safe packet conclusions are

  - #Sigma_h is always even under the nonzero gate;

  - a nonzero real critical value contributes at least four points to Sigma_h;

  - a generic off-axis collision contributes at least eight points;

  - the only place where four-packet divisibility can degenerate is the
    purely-imaginary/vertical-line locus.

These are lower bounds on the size of a collision packet. They do not give the
needed upper bound on the total collision set. In particular, symmetry alone
cannot prove [COLL-2H].

# 6. Quotient by reflection: the correct collision object

The reflection pairing should be removed before doing Galois theory.

Put

  z = X + (h+1)/2.

Then rho is z -> -z, and f_h is odd in z. Its derivative is even. After clearing
an irrelevant rational scalar and powers of 2, there is a polynomial

  A_h(U) in Q[U],
  deg A_h = 2h-2,                                       (6.1)

such that the roots of A_h parametrize the reflection pairs

  {x,rho(x)}

of critical points, with

  U = z^2.

The nonzero gate excludes U=0, so every root of A_h corresponds to exactly two
distinct critical points.

Let

  B_h = roots(A_h),
  #B_h = 2h-2.

For u in B_h, choose either critical point x above u and define

  w_h(u) = f_h(x)^2.                                    (6.2)

This is independent of the choice between x and rho(x), because their values
are t and -t.

The mirror critical-value polynomial W_h is, up to a nonzero scalar,

  W_h(S) = prod_{u in B_h} (S - w_h(u)),                (6.3)

and

  V_h(T) = W_h(T^2).                                    (6.4)

Define an equivalence relation on B_h by

  u ~ v  iff  w_h(u)=w_h(v).                            (6.5)

A block u belongs to a nontrivial class in (6.5) exactly when both critical
points above u lie in Sigma_h. Consequently

  #Sigma_h
    = 2 * #{u in B_h : the class of u has size >= 2}.   (6.6)

Thus the original collision problem is exactly the failure of injectivity of the
squared critical-value map on the reflection quotient.

This formulation removes the forced sign symmetry completely. In particular,
full Morse is equivalent to

  w_h : B_h -> Qbar is injective,

or equivalently

  W_h is squarefree and W_h(0) != 0.                    (6.7)

# 7. The Galois block theorem

Let L_h be the splitting field of A_h and let

  G_h = Gal(L_h/Q)

act on B_h.

The equality relation (6.5) is G_h-invariant. Indeed, if w_h(u)=w_h(v), then for
any sigma in G_h,

  w_h(sigma u)
    = sigma(w_h(u))
    = sigma(w_h(v))
    = w_h(sigma v).                                     (7.1)

Therefore the fibers of w_h form a G_h-invariant partition of B_h.

This gives the key theorem.

[PRIMITIVE-MORSE]

Assume the Morse/nonzero gate. Suppose

  (i)  G_h acts primitively on B_h;

  (ii) w_h is not constant on B_h.

Then

  w_h is injective,
  W_h is squarefree,
  V_h is squarefree,
  Sigma_h = empty,
  s_h = 4h-4.                                           (7.2)

Proof.

The fibers of w_h are a G_h-invariant partition. In a primitive action, every
invariant partition is either the discrete partition or the indiscrete
one-block partition. Condition (ii) excludes the indiscrete partition. Hence all
fibers are singletons.

This is the strongest useful conclusion of the Galois analysis. It does not try
to prove the numerical bound 2h-3. It proves the zero-collision statement.

A crucial warning is that one must not seek a primitive or symmetric Galois
action on the original 4h-4 critical points. The rational involution rho gives a
Galois-invariant system of blocks

  {x,rho(x)}.

Hence the original action is necessarily imprimitive, contained in a wreath-type
group. The correct large-group conjecture concerns the degree-(2h-2) quotient
polynomial A_h. A full S_{2h-2} or A_{2h-2} group would be more than enough, but
primitivity alone is the exact group-theoretic input needed by (7.2).

# 8. How to certify the two Galois inputs

## 8.1 Primitivity

The practical target is

  [BLOCK-PRIMITIVE_h]
  Gal(A_h/Q) acts primitively on its 2h-2 roots.          (8.1)

This is cheaper than determining the full Galois group. A certificate can be
built from

  - irreducibility of A_h over Q, giving transitivity;

  - modular factorization patterns excluding every proper block size dividing
    2h-2;

  - or stronger cycle-pattern certificates proving A_{2h-2} or S_{2h-2}.

The reflection quotient is essential before running these tests.

## 8.2 Noncollapse

The second input is only

  [NONCOLLAPSE_h]
  the values w_h(u) are not all equal.                  (8.2)

Equivalently, W_h is not a pure power

  W_h(S) = constant * (S-a)^(2h-2).                     (8.3)

This can be certified much more cheaply than squarefreeness. For a monic
polynomial

  W_h(S) = S^m + a_1 S^(m-1) + a_2 S^(m-2) + ...,
  m = 2h-2,

constancy of all roots would force

  (m-1) a_1^2 - 2m a_2 = 0.                            (8.4)

Thus nonvanishing of the left side is an exact two-coefficient noncollapse
certificate. A single good-prime reduction displaying two distinct roots also
suffices.

For an all-h theorem, (8.4) suggests a much smaller symbolic target than the full
discriminant of V_h.

# 9. Relation to [COLL-2H]

The Galois theorem changes the strategic picture.

Under [BLOCK-PRIMITIVE_h], the collision partition has only two possibilities:

  (a) every reflection block has its own squared critical value, so
      #Sigma_h=0;

  (b) every reflection block has the same squared critical value, so
      #Sigma_h=4h-4.

The second case is exactly the collapse excluded by [NONCOLLAPSE_h]. Therefore,
under primitivity, any nontrivial upper bound

  #Sigma_h < 4h-4

already forces Sigma_h=0. The special threshold 2h-3 is no longer intrinsic.

This shows why a direct proof of the linear codegree bound may be aiming at the
wrong level. The computations suggest not a sparse collision locus of size
O(h), but no collision locus at all.

The direct saturated-resultant target remains valid:

  deg gcd(C_h,R_h^off) <= 2h-3.

But the quotient-Galois route replaces it by the stronger and conceptually
cleaner pair

  [BLOCK-PRIMITIVE_h] + [NONCOLLAPSE_h]
      => deg gcd(C_h,R_h^off)=0.                         (9.1)

The latter is now the preferred structural attack if the quotient Galois groups
show large or primitive behavior.

# 10. What the zero-real-root fact does and does not explain

The empirical statement

  C_h has no real roots

is itself stronger than merely saying that no real critical value appears. It
says that f_h has no finite real critical point. Since q_h(x)^4>0 away from the
poles, this is equivalent to f_h' having a constant sign on every real pole
cell. The pole expansion has

  f_h(-j+z) = b_{j-1} b_{h-j} z^(-3) + O(z^(-2)),

with positive leading coefficient, so

  f_h'(-j+z) = -3 b_{j-1} b_{h-j} z^(-4) + O(z^(-3))

is negative near every pole. Thus the natural all-h strengthening is

  [REAL-MONO]
  f_h'(x) < 0 for every real x not equal to a pole.      (10.1)

A proof of (10.1) probably requires an Apery-specific positivity identity:
for example a Green, Christoffel-Darboux, total-positivity, or sum-of-squares
formula for -f_h'. The quadruple/Galois argument does not prove (10.1).

What it does prove is the next logical step:

  [REAL-MONO] + full Morse
      => no real critical values.                       (10.2)

More precisely, only the no-real-root consequence of [REAL-MONO] and the
squarefreeness/nonzero part of full Morse are needed, by Section 4.

So the explanation separates into two independent mechanisms:

  - real analysis/positivity excludes real critical points;

  - algebraic Morse squarefreeness then excludes real critical values, because
    conjugation would otherwise create a repeated value;

  - reflection completes the repeated pair into the four-point packet over
    t and -t.

# 11. Recommended all-h conjecture

The evidence now supports replacing [COLL-2H] as the primary conjecture by the
following stronger statement.

[FULL-MORSE-ALL]

For every h >= 2:

  1. C_h has degree 4h-4 and is squarefree;

  2. gcd(C_h,N_h)=1, equivalently V_h(0) != 0;

  3. V_h is squarefree;

  4. hence s_h=4h-4 and Sigma_h=empty.                  (11.1)

A separate real strengthening is

[REAL-MONO-ALL]

For every h >= 2, C_h has no real roots, equivalently f_h is strictly decreasing
on every component of R minus {-1,...,-h}.              (11.2)

The quotient-Galois mechanism gives a plausible reason for (11.1): after the
forced reflection symmetry is removed, any repeated squared value would define
a nontrivial Galois block system. Primitive quotient monodromy forbids such a
system unless all squared values collapse, and the latter can be ruled out by a
very small coefficient certificate.

This is not yet a proof. The two genuine all-h tasks are

  [GAP-A] prove primitive Galois/monodromy on the reflection quotient A_h;

  [GAP-B] prove noncollapse uniformly in h, preferably from a low coefficient
          identity or from the exact two-block recurrence;

and, independently for the real statement,

  [GAP-C] prove the positivity/monotonicity theorem (10.1).

# 12. Updated finite-range conclusion

The new machine certificates prove full Morse behavior for every

  2 <= h <= 30:

  s_h = 4h-4,
  V_h is squarefree,
  V_h(0) != 0.

The certificates are exact through h=12 and use triple-prime modular
squarefreeness certificates through h=30. Therefore, throughout this entire
range,

  Sigma_h = empty,

so [COLL-2H] holds with the maximal possible margin:

  #Sigma_h = 0 <= 2h-3.

This materially changes the interpretation of the earlier audit. The data no
longer suggest merely that the collision projection has degree at most about
2h. They suggest that the saturated off-diagonal collision scheme is empty for
every h>=2. Accordingly, full Morse for all h is now the right primary
conjecture, with [COLL-2H] retained as an immediate weaker corollary.

The quadruple/Galois analysis also gives the precise explanation for the observed
absence of real critical values in the certified range. Because C_h has no real
critical points, any nonzero real critical value would force the four distinct
points

  x, conjugate(x), rho(x), rho(conjugate(x))

with values

  t, t, -t, -t,

contradicting squarefreeness of V_h. Thus no real critical value can occur once
the no-real-root and full-Morse certificates are combined. What remains open is
not this implication, but the uniform all-h source of the two inputs: a
positivity theorem explaining why C_h never meets the real axis, and a primitive
quotient-Galois or equivalent structural theorem explaining why the squared
critical-value map never identifies two reflection blocks.
