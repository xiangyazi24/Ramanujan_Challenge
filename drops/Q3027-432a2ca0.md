# Q3027 — symbolic audit of the stated toric rank

## Verdict

There is a decisive definition mismatch before the proposed `8q-2` rank can be attacked.

The Laurent polynomial written in Q3027 is

\[
\Lambda_D=(1+x+y+z)(1+x^{-1}+y^{-1}+z^{-1}).
\tag{0.1}
\]

The current repository file `problems/3.2/oracleC_exploration.md` instead uses the Apéry toric polynomial

\[
\Lambda_A=
\frac{(1+x)(1+y)(1+z)((1+y)(1+z)+xyz)}{xyz},
\tag{0.2}
\]

and proves `CT Lambda_A^n=b_n`.  These are not the same Laurent polynomial.  Already

\[
\operatorname{CT}\Lambda_D=4,
\qquad
\operatorname{CT}\Lambda_A=b_1=5.
\tag{0.3}
\]

So the asserted convolution identity in the question,

\[
\sum_u c_q(u)c_{r-q}(-u)=b_r,
\tag{0.4}
\]

is false for the project Apéry numbers when `c_k(u)` is defined from (0.1).  Its exact right-hand side is instead `CT Lambda_D^r`, the sequence beginning

\[
1,4,28,256,2716,\ldots.
\tag{0.5}
\]

More strongly, the observed rank `8q-2` cannot belong to (0.1): for `q=1` the exact rank is **2**, not 6.  I prove this below, together with an all-`k` Bessel/DFT-free certificate and a uniform linear upper bound.

For the Laurent polynomial actually written in Q3027, put

\[
d_q:=\dim_{\mathbf Q}\operatorname{span}_{\mathbf Q}
\{(c_k(u))_{k\ge0}:u\in\operatorname{supp}\Lambda_D^q\}.
\]

The theorem-level conclusions proved here are

\[
\boxed{d_1=2,\qquad d_2=5,}
\tag{0.6}
\]

and, for every `q>=2`,

\[
\boxed{q+1\le d_q\le 5q-4.}
\tag{0.7}
\]

The upper bound is characteristic-zero, exact for all `k`, and comes from an explicit modified-Bessel contiguous module; it is not finite extrapolation.  In particular

\[
5q-4<8q-2\qquad(q\ge1),
\]

with the separately proved `d_1=2`, so the claimed `8q-2` pattern is incompatible with the stated `Lambda_D` at every tested `q`.

I do **not** claim an exact formula for `d_q` for all `q` from the present argument.  The exact `8q-2` question for the repository's actual Apéry Laurent polynomial (0.2) is a different symbolic problem and must not be inferred from the calculation below.

Finally, even if one temporarily renames `CT Lambda_D^r` as the target, the low-dimensional module does not formally force a second independent linear relation from its vanishing.  At `q=1` this can be proved exactly: the whole profile has dimension two and the convolution zero is a single nonzero row on that two-dimensional profile, hence its degree-one consequence ideal contains no second independent row.

# 1. Homogenization and the exact support metric

Introduce four homogeneous torus coordinates

\[
X_0=1,\qquad X_1=x,\qquad X_2=y,\qquad X_3=z.
\]

Then

\[
\Lambda_D=
\left(\sum_{i=0}^3X_i\right)
\left(\sum_{i=0}^3X_i^{-1}\right)
=\sum_{i,j=0}^3\frac{X_i}{X_j}.
\tag{1.1}
\]

For `u=(u_1,u_2,u_3) in Z^3`, define its root-lattice lift

\[
\widetilde u=(-u_1-u_2-u_3,u_1,u_2,u_3)\in\mathbf Z^4,
\qquad \sum_i\widetilde u_i=0.
\tag{1.2}
\]

Writing

\[
A=\sum_iX_i,\qquad B=\sum_iX_i^{-1},
\]

we have

\[
c_k(u)=[X^{\widetilde u}]A^kB^k.
\tag{1.3}
\]

Define the transportation length

\[
s(u):=\sum_{\widetilde u_i>0}\widetilde u_i
      =\frac12\sum_{i=0}^3|\widetilde u_i|.
\tag{1.4}
\]

## Lemma 1.1 — exact support

For every integer `q>=0`,

\[
\boxed{u\in\operatorname{supp}\Lambda_D^q\iff s(u)\le q.}
\tag{1.5}
\]

### Proof

A monomial in `A^qB^q` has exponent `a-b`, where `a,b in Z_{>=0}^4` and

\[
\sum_i a_i=\sum_i b_i=q.
\]

Thus the positive part of `a-b` has total mass at most `q`, proving necessity.

Conversely, if `s=s(u)<=q`, let

\[
a_i^{(0)}=\max(\widetilde u_i,0),\qquad
b_i^{(0)}=\max(-\widetilde u_i,0).
\]

Both have total mass `s`.  Choose any `gamma in Z_{>=0}^4` of total mass `q-s` and put

\[
a=a^{(0)}+\gamma,\qquad b=b^{(0)}+\gamma.
\]

Then `a-b=\widetilde u` and both totals equal `q`, so the coefficient is positive.  QED.

This exact support description will be used in the Bessel rank bound.

# 2. Exact factorial-Borel transform: product of four Bessel functions

Define

\[
\widehat F_u(z):=
\sum_{k\ge0}\frac{c_k(u)}{(k!)^2}z^k.
\tag{2.1}
\]

The map

\[
(c_k)_{k\ge0}\longmapsto (c_k/(k!)^2)_{k\ge0}
\]

is a `Q`-linear injection, so it preserves all `Q`-linear dependence and therefore preserves the rank `d_q`.

## Theorem 2.1 — Bessel certificate

For every `u in Z^3`,

\[
\boxed{
\widehat F_u(z)=
\prod_{i=0}^3 I_{|\widetilde u_i|}(2\sqrt z),
}
\tag{2.2}
\]

where `I_n` is the modified Bessel function of integral order `n`.

### Proof

Start with the formal identity

\[
\exp(sA+tB)
=\prod_{i=0}^3\exp(sX_i+tX_i^{-1}).
\tag{2.3}
\]

For one coordinate,

\[
[X_i^m]\exp(sX_i+tX_i^{-1})
=(s/t)^{m/2}I_m(2\sqrt{st}),
\tag{2.4}
\]

with `I_{-m}=I_m` for integer `m`.  Therefore

\[
[X^{\widetilde u}]\exp(sA+tB)
=(s/t)^{\frac12\sum_i\widetilde u_i}
\prod_i I_{|\widetilde u_i|}(2\sqrt{st}).
\]

The prefactor is one because `sum \widetilde u_i=0`.

On the other hand, expanding the left side as

\[
\sum_{a,b\ge0}\frac{s^at^b}{a!b!}[X^{\widetilde u}]A^aB^b,
\]

the exponent sum zero forces `a=b`; hence it is

\[
\sum_{k\ge0}\frac{(st)^k}{(k!)^2}c_k(u).
\]

Set `z=st`.  QED.

This is the main all-`k` symbolic certificate.  No interpolation in `k`, modular computation, or Berlekamp--Massey step enters.

# 3. A common contiguous module and the upper bound `d_q<=5q-4`

Write

\[
x=2\sqrt z,\qquad T=x^{-1},
\qquad I_n=I_n(x).
\]

The exact integral-order Bessel recurrence is

\[
I_{n+1}=I_{n-1}-2nT I_n.
\tag{3.1}
\]

Define polynomials `P_n,Q_n in Q[T]` recursively by

\[
P_0=1,\ Q_0=0,\qquad
P_1=0,\ Q_1=1,
\tag{3.2}
\]

\[
P_{n+1}=P_{n-1}-2nTP_n,
\qquad
Q_{n+1}=Q_{n-1}-2nTQ_n.
\tag{3.3}
\]

Then, identically for every integer `n>=0`,

\[
\boxed{I_n=P_n(T)I_0+Q_n(T)I_1.}
\tag{3.4}
\]

For `n>=2`, direct induction in (3.3) gives

\[
\deg P_n=n-2,
\qquad
\deg Q_n=n-1,
\tag{3.5}
\]

and every monomial of `P_n` has parity `n mod 2`, whereas every monomial of `Q_n` has parity `n-1 mod 2`.

Let

\[
M_j:=I_0^{4-j}I_1^j,\qquad 0\le j\le4.
\tag{3.6}
\]

For a fixed `u`, put `n_i=|\widetilde u_i|` and

\[
S=\sum_i n_i=2s(u)\le2q.
\]

Expanding the four factors in (2.2) via (3.4), any term contributing to `M_j` chooses `Q` in exactly `j` factors and `P` in the other `4-j` factors.

There are two elementary restrictions.

1. A chosen `Q` factor must have `n_i>=1`; each such choice lowers the maximal `T`-degree by one.
2. A chosen `P` factor with positive index cannot have `n_i=1` because `P_1=0`; hence a positive `P` index is at least two and lowers maximal degree by two.

Because a nonzero root-lattice vector has at least two nonzero absolute coordinates, we obtain the following degree maxima for a nonzero contribution to `M_j`:

\[
\begin{array}{c|ccccc}
j&0&1&2&3&4\\ \hline
\max\deg_T& S-4&S-3&S-2&S-3&S-4.
\end{array}
\tag{3.7}
\]

For `j=0`, the exceptional vector `u=0` contributes just `M_0`, which is already the `T^0M_0` basis element.

Also, since `S` is even, the parity rule implies

\[
T^mM_j\text{ can occur only when }m\equiv j\pmod2.
\tag{3.8}
\]

Therefore, for every `q>=2`, all the Borel transforms with `u in supp Lambda_D^q` lie in the explicit `Q`-space

\[
\mathcal M_q=
\operatorname{span}_{\mathbf Q}
\{T^mM_j:(j,m)\text{ satisfies (3.7)--(3.8) with }S\le2q\}.
\tag{3.9}
\]

Counting the allowed pairs gives

- `j=0`: even `m`, `0<=m<=2q-4`: `q-1` choices;
- `j=1`: odd `m`, `1<=m<=2q-3`: `q-1` choices;
- `j=2`: even `m`, `0<=m<=2q-2`: `q` choices;
- `j=3`: odd `m`, `1<=m<=2q-3`: `q-1` choices;
- `j=4`: even `m`, `0<=m<=2q-4`: `q-1` choices.

Hence

\[
\boxed{d_q\le\dim\mathcal M_q\le5q-4\qquad(q\ge2).}
\tag{3.10}
\]

This is an all-`k` theorem.  It does not assume that the displayed Laurent-Bessel generators are independent; any further identities only lower the rank.

## Explicit rational differential-system certificate

The five basic monomials satisfy a closed first-order system.  From

\[
I_0'=I_1,
\qquad
I_1'=I_0-TI_1,
\]

one gets, with `Y=(M_0,M_1,M_2,M_3,M_4)^t`,

\[
\frac{dY}{dx}=A(x)Y,
\tag{3.11}
\]

where

```text
A(x) =
[ 0      4       0       0       0 ]
[ 1    -1/x      3       0       0 ]
[ 0      2     -2/x      2       0 ]
[ 0      0       3     -3/x      1 ]
[ 0      0       0       4     -4/x]
```

and, for every integer `m>=0`,

\[
\frac d{dx}(x^{-m}Y)
=\left(A(x)-\frac m x I_5\right)x^{-m}Y.
\tag{3.12}
\]

Thus one may stack the finitely many gauges `0<=m<=2q-2` into an explicit block-diagonal rational connection.  Every Borel transform in (2.2) is a constant `Q`-linear combination of its components.  Elimination therefore gives a common P-recursive certificate for all coefficient sequences.  Passing back from `c_k/(k!)^2` to `c_k` merely multiplies shifted recurrence coefficients by explicit products of `(k+i)^2`; no analytic or finite-data assumption is involved.

There is also a literal common rational/constant-term denominator for the ordinary generating functions:

\[
\boxed{
F_u(t):=\sum_{k\ge0}c_k(u)t^k
=\operatorname{CT}_{X_0/X_0}
\frac{X^{-\widetilde u}}
{1-t(\sum_iX_i)(\sum_iX_i^{-1})}.
}
\tag{3.13}
\]

After setting `X_0=1`, this is the usual three-variable constant-term representation.  The denominator is independent of `u`; only the monomial numerator changes.

# 4. Lower bound and exact ranks for `q=1,2`

## Proposition 4.1 — universal lower bound

For every `q>=0`,

\[
\boxed{d_q\ge q+1.}
\tag{4.1}
\]

### Proof

For every `0<=s<=q`, take

\[
\widetilde u^{(s)}=(s,-s,0,0).
\]

It lies in the support by Lemma 1.1.  Its Borel transform is

\[
I_s(2\sqrt z)^2 I_0(2\sqrt z)^2.
\tag{4.2}
\]

Since

\[
I_s(2\sqrt z)=\frac{z^{s/2}}{s!}+O(z^{s/2+1}),
\]

the series in (4.2) has exact `z`-adic valuation `s`.  The `q+1` distinct valuations force linear independence over `Q`.  QED.

## Proposition 4.2 — exact `q=1`

For `q=1`,

\[
\boxed{d_1=2.}
\tag{4.3}
\]

Indeed, by (1.1), the support consists of `0` and the 12 roots `e_i-e_j`.  The `S_4` permutation symmetry makes every nonzero root coefficient sequence identical.  Their Borel transforms are

\[
I_0^4,
\qquad
I_1^2I_0^2,
\]

respectively.  Their `z`-adic valuations are 0 and 1, so they are independent.

This alone disproves the proposed `8q-2` pattern for the Laurent polynomial stated in Q3027, because `8*1-2=6`.

## Proposition 4.3 — exact `q=2`

For `q=2`, the absolute-value multisets of root-lattice lifts, modulo permutation and sign, are exactly

\[
0000,\quad1100,\quad2200,\quad2110,\quad1111.
\tag{4.4}
\]

Hence there are at most five distinct coefficient sequences.  Their Borel transforms are

\[
I_0^4,
\quad I_1^2I_0^2,
\quad I_2^2I_0^2,
\quad I_2I_1^2I_0,
\quad I_1^4.
\tag{4.5}
\]

The first two have valuations 0 and 1.  The last three have valuation 2.  To separate those three, write

\[
I_0(2\sqrt z)=1+z+\frac{z^2}{4}+O(z^3),
\]

\[
z^{-1/2}I_1(2\sqrt z)=1+\frac z2+\frac{z^2}{12}+O(z^3),
\]

\[
z^{-1}I_2(2\sqrt z)=\frac12+\frac z6+\frac{z^2}{48}+O(z^3).
\]

After dividing the last three series by `z^2`, their coefficient vectors in degrees `0,1,2` are

\[
\left(\frac14,\frac23,\frac{109}{144}\right),
\]

\[
\left(\frac12,\frac76,\frac{19}{16}\right),
\]

\[
\left(1,2,\frac{11}{6}\right).
\]

The determinant is

\[
-\frac1{216}\ne0.
\tag{4.6}
\]

Thus all five functions in (4.5) are independent and

\[
\boxed{d_2=5.}
\tag{4.7}
\]

Again, this is incompatible with `8*2-2=14`.

I stop the exact-rank claim here.  The contiguous module proves the uniform linear upper bound (3.10), but I do not have a theorem-grade proof in this pass that identifies the exact quotient dimension for every `q`.

# 5. The constant term is not the Apéry sequence

The mismatch can be seen without naming any external sequence.  From

\[
\Lambda_D^r=A^rB^r,
\]

we obtain

\[
D_r:=\operatorname{CT}\Lambda_D^r
=\sum_{a_0+a_1+a_2+a_3=r}
\left(\frac{r!}{a_0!a_1!a_2!a_3!}\right)^2.
\tag{5.1}
\]

Grouping `a_0+a_1=k` and using Vandermonde twice gives the exact one-sum formula

\[
\boxed{
D_r=
\sum_{k=0}^r
\binom rk^2
\binom{2k}{k}
\binom{2r-2k}{r-k}.
}
\tag{5.2}
\]

Thus

\[
D_0=1,\quad D_1=4,\quad D_2=28,\quad D_3=256.
\]

By contrast, the project Apéry numbers are

\[
b_r=\sum_k\binom rk^2\binom{r+k}{k}^2,
\]

with

\[
b_0=1,\quad b_1=5,\quad b_2=73.
\]

So `D_r` and `b_r` are genuinely different characteristic-zero sequences.

For completeness, the ordinary generating function

\[
D(t)=\sum_{r\ge0}D_rt^r
\]

is the exact diagonal/constant term

\[
D(t)=\operatorname{CT}\frac1{1-t\Lambda_D}.
\tag{5.3}
\]

The familiar third-order telescoper for this diagonal can be written with `theta=t d/dt` as

\[
\mathcal L_D
=\theta^3
-2t(2\theta+1)(5\theta^2+5\theta+2)
+64t^2(\theta+1)^3,
\tag{5.4}
\]

which is equivalent coefficientwise to

\[
(r+1)^3D_{r+1}
=2(2r+1)(5r(r+1)+2)D_r
-64r^3D_{r-1}.
\tag{5.5}
\]

The rank proof above does not depend on (5.4); (2.2) and the explicit recurrence (3.1) are already a complete all-`k` certificate.

# 6. Exact convolution identity

For every `r>=q`, Cauchy multiplication gives

\[
\begin{aligned}
\sum_u c_q(u)c_{r-q}(-u)
&=[X^0]\Lambda_D^q\Lambda_D^{r-q}\\
&=[X^0]\Lambda_D^r\\
&=D_r.
\end{aligned}
\tag{6.1}
\]

Therefore the exact statement is

\[
\boxed{
\sum_u c_q(u)c_{r-q}(-u)=D_r,
}
\tag{6.2}
\]

not `b_r` for the Apéry sequence used in P3.2.

Consequently this `Lambda_D` module cannot supply a target-forced second congruence for a prime satisfying `p|b_r`: it does not even encode the first target congruence.

This is not a subtle failure of the primitive-DFT orbit method.  It occurs before Mellin descent: the wrong characteristic-zero constant term has been inserted.

# 7. Even for `D_r`, rank compression alone gives no second forced row

It is still useful to ask the purely formal question with `D_r` replacing `b_r`.

Let

\[
v_k=(c_k(-u))_{u\in\operatorname{supp}\Lambda_D^q},
\qquad
\ell_q(v)=\sum_u c_q(u)v(u).
\]

Then

\[
\ell_q(v_{r-q})=D_r.
\tag{7.1}
\]

The low-dimensional Bessel module gives many **universal** linear relations among the coordinate sequences `u -> c_k(u)`.  Those relations hold for every `k`; they do not appear only at a target zero.

After quotienting by all such universal relations, equation `D_r=0` is one nonzero linear functional on the quotient module.  A dimension bound by itself does not make a second independent functional vanish on that hyperplane.

The hardest possible objection can already be killed exactly at `q=1`.

## Proposition 7.1 — exact `q=1` no-second-row certificate

Let

\[
A_k=c_k(0),
\]

and let `R_k=c_k(alpha)` for any of the 12 roots `alpha=e_i-e_j`; all roots give the same sequence by `S_4` symmetry.  Then

\[
\boxed{
D_{k+1}=4A_k+12R_k.
}
\tag{7.2}
\]

### Proof

From (1.1),

\[
\Lambda_D=4+\sum_{\alpha\in\Phi(A_3)}X^\alpha,
\]

with 12 roots.  Therefore

\[
[X^0]\Lambda_D^{k+1}
=4[X^0]\Lambda_D^k
+\sum_\alpha[X^{-\alpha}]\Lambda_D^k
=4A_k+12R_k.
\]

QED.

The profile space has exact dimension two by Proposition 4.2.  Hence, in formal coordinates `(A,R)`, the target equation is the one row

\[
4A+12R=0.
\tag{7.3}
\]

Its degree-one ideal is

\[
(4A+12R)_1
=\mathbf Q\,(4A+12R).
\tag{7.4}
\]

Thus no second `Q`-linearly independent linear form can be a formal consequence of the target zero.  Any second congruence would have to use extra arithmetic information about the **particular** point `v_k` modulo `p`, not merely the low-dimensional characteristic-zero sequence module.

This is the precise scoped no-go requested in the last part: rank compression supplies universal relations, but target vanishing adds only one hyperplane unless one proves an additional target-specific invariant.

# 8. Consequences for the intended P3.2 attack

There are two separate problems and they should not be conflated.

### A. Polynomial actually stated in Q3027

For

\[
\Lambda_D=(1+x+y+z)(1+x^{-1}+y^{-1}+z^{-1}),
\]

we now have exact symbolic facts:

\[
d_1=2,\qquad d_2=5,
\]

\[
q+1\le d_q\le5q-4\quad(q\ge2),
\]

with the Bessel product (2.2), contiguous recurrence (3.1), rational system (3.11)--(3.12), and common rational constant-term denominator (3.13) as certificates.

Its convolution is `D_r`, not the project Apéry number `b_r`.  Therefore it cannot force an additional relation at an Apéry target prime.

### B. Repository Apéry polynomial

The current source `oracleC_exploration.md` uses (0.2), not (0.1).  The experimentally observed `8q-2` may concern that different Laurent polynomial or a different carrier built from it.  Nothing in this note disproves an `8q-2` theorem for that object.

But it also cannot be imported from the present calculation: the Bessel factorization (2.2) relies crucially on the separable product

\[
(\sum X_i)(\sum X_i^{-1}),
\]

which the Apéry Laurent polynomial (0.2) does not have.

So the next correct symbolic task, if `8q-2` is genuinely observed for the Apéry carrier, is to restate it with the exact `Lambda_A` (or the exact transformed carrier used in the computation) and derive its own Griffiths--Dwork/diagonal module.  The present Q3027 definitions do not support the claimed rank or the claimed convolution target.
