## 1. What constitutes evidence for APUC

### 1.1 Zero marked events are censored

If no candidate coordinate is an upper zero, then `M_q=0` for every nonempty fibre and

\[
a_q=-\mu_qA_q^0\le0,
\qquad
E_q^{\rm APUC}=0.
\]

Hence both quantities in (2) vanish algebraically. This proves only that the scan has not entered the selected regime. It gives no evidence for depletion of positive upper/lower alignment.

### 1.2 The discriminating pattern

The experiment becomes informative only when the upper-marked mass is no longer abnormally small under a declared null. The theorem-facing pattern is

```text
marked inverse mass:       ordinary relative to the conditional null;
positive APUC cut/energy:  unusually small relative to the same null.
```

Concretely, report

\[
\frac{M_{\rm mark}}{\mathbf E_0M_{\rm mark}},
\qquad
\frac{\operatorname{APUC}_A^+}
     {\mathbf E_0\operatorname{APUC}_A^+},
\qquad
\frac{\mathcal E_A^+}
     {\mathbf E_0\mathcal E_A^+},
\tag{4}
\]

along with conditional randomization percentiles. A small APUC value accompanied by severely deficient marked mass is still compatible with simple upper-mark avoidance; it does not isolate the centered-cut mechanism.

### 1.3 Discovery is not confirmation

The first marked event is useful because it proves that the pipeline is no longer algebraically censored. It is not a valid confirmatory sample if the search stops exactly when that event appears.

Use this fixed rule:

```text
Discovery stage:
  continue complete closure stages until the first actual marked
  reflection orbit appears; publish it, but do not use its stage for
  a lower-tail APUC p-value.

Confirmation stage:
  freeze the next one or two complete new lower-prime/T shells before
  examining their upper marks; evaluate the predeclared statistic and
  conditional null there.
```

An alternative is to simulate the entire stopping rule inside every null replicate. The holdout-shell rule is simpler and easier to audit.

## 3. Scalable modular recurrence

The Sage verifier computes `b_n mod p` by dividing by `(n+1)^3` at every step. For a search into the multi-million-prime range, remove those inversions.

Define

\[
c_n=(n!)^3b_n\pmod p.
\]

For `0<=n<p`, `n!` is invertible modulo `p`, so

\[
c_n=0\iff b_n=0\pmod p.
\tag{7}
\]

Multiplying the Apéry recurrence by `(n!)^3` gives

\[
\boxed{
c_{n+1}=P(n)c_n-n^6c_{n-1}\pmod p,
\qquad
P(n)=34n^3+51n^2+27n+5,
}
\tag{8}
\]

with

\[
c_0=1,\qquad c_1=5.
\]

This recurrence needs only modular additions and multiplications. Apéry reflection

\[
b_{p-1-n}\equiv b_n\pmod p
\]

allows a complete zero table to be reconstructed from `0<=n<=(p-1)/2`.

A production C++ kernel is:

```cpp
using u64 = std::uint64_t;
using u128 = unsigned __int128;

static inline u64 mul_mod(u64 a, u64 b, u64 p) {
    return static_cast<u64>((static_cast<u128>(a) * b) % p);
}

static inline u64 add_mod(u64 a, u64 b, u64 p) {
    a += b;
    return a >= p ? a - p : a;
}

static inline u64 sub_mod(u64 a, u64 b, u64 p) {
    return a >= b ? a - b : a + p - b;
}

std::vector<std::uint32_t> apery_zeros(std::uint32_t p) {
    if (p < 3) throw std::invalid_argument("odd prime required");

    std::vector<std::uint32_t> lower;
    const u64 center = (p - 1ULL) / 2ULL;
    u64 cm1 = 1 % p;  // c_0
    u64 c = 5 % p;    // c_1

    if (cm1 == 0) lower.push_back(0);
    if (1 <= center && c == 0) lower.push_back(1);

    for (u64 n = 1; n < center; ++n) {
        const u64 n2 = mul_mod(n, n, p);
        const u64 n3 = mul_mod(n2, n, p);
        const u64 n6 = mul_mod(n3, n3, p);

        u64 poly = 0;
        poly = add_mod(poly, mul_mod(34 % p, n3, p), p);
        poly = add_mod(poly, mul_mod(51 % p, n2, p), p);
        poly = add_mod(poly, mul_mod(27 % p, n, p), p);
        poly = add_mod(poly, 5 % p, p);

        const u64 cp1 = sub_mod(mul_mod(poly, c, p),
                                mul_mod(n6, cm1, p), p);
        cm1 = c;
        c = cp1;
        if (c == 0) lower.push_back(static_cast<std::uint32_t>(n + 1));
    }

    std::vector<std::uint32_t> out;
    out.reserve(2 * lower.size());
    for (std::uint32_t z : lower) out.push_back(z);
    for (auto it = lower.rbegin(); it != lower.rend(); ++it) {
        const std::uint32_t z = *it;
        const std::uint32_t mirror = p - 1U - z;
        if (mirror != z) out.push_back(mirror);
    }
    std::sort(out.begin(), out.end());
    out.erase(std::unique(out.begin(), out.end()), out.end());
    return out;
}
```

Mandatory kernel checks are

```text
c_0=1, c_1=5, c_2=584;
0 and p-1 are never zeros;
Z_p is reflection-invariant;
no two consecutive residues are zeros;
small-prime hashes match the existing Sage recurrence exactly.
```

The recurrence is embarrassingly parallel in `p`. Shard by the estimated work `sum p` rather than by the number of primes.

## 6. Exact conditional null and expected exposure

The primary null must preserve everything currently banked about an upper zero set while randomizing only its alignment with the lower inverse profile:

```text
q;
Z(q);
reflection symmetry t <-> q-1-t;
no-consecutive-zero law;
actual A_q(t) profile, event intervals, p multiplicities, and signs.
```

### 6.1 Reflection/no-consecutive parameterization

Let

\[
c=\frac{q-1}{2},\qquad
r=Z(q)\bmod2,\qquad
k=\frac{Z(q)-r}{2}.
\]

Reflection forces the center to be selected exactly when `r=1`. The orbit `\{0,q-1\}` is forbidden because `b_0=b_{q-1}=1`.

After accounting for the center, selectable noncentral reflection orbits form a path of length

\[
n=c-1-r.
\tag{14}
\]

The conditional null is uniform over nonadjacent `k`-subsets of this path. Their exact number is

\[
D_q=\binom{n-k+1}{k}.
\tag{15}
\]

Uniform sampling is simple. Choose an ordinary uniform `k`-subset

\[
1\le y_1<\cdots<y_k\le n-k+1
\]

and set

\[
x_j=y_j+j-1.
\tag{16}
\]

Then `x_1<...<x_k` is a uniform nonadjacent `k`-subset of `1,...,n`.

For a pair orbit `i`, define its load

\[
L_{q,i}=A_q(i)+A_q(q-1-i).
\]

A null draw has marked mass

\[
M_q^{(0)}
=rA_q(c)+\sum_{i\in S_q^{(0)}}L_{q,i}.
\tag{17}
\]

From this value recompute `m1`, `m0`, `(a_q)_+`, and (1). Never randomize a precomputed sign or energy.

### 6.2 Expected orbit and mass exposure

The exact inclusion probability of a path vertex `i` is

\[
\pi_{q,i}
=\frac1{D_q}
 \sum_j
 \binom{i-1-j}{j}
 \binom{n-i-k+j+1}{k-1-j},
\tag{18}
\]

with invalid binomial terms interpreted as zero. Hence the exact conditional expected marked mass is

\[
\boxed{
\mathbf E_0M_q
=rA_q(c)+\sum_{i=1}^{n}\pi_{q,i}L_{q,i}.}
\tag{19}
\]

Let `S_q` be the set of reflection orbits on which the inverse profile is nonzero. The expected number of marked candidate orbits is

\[
\Lambda_{{\rm orb},q}
=r\,1_{\{c\in S_q\}}
 +\sum_{i\in S_q}\pi_{q,i},
\tag{20}
\]

and

\[
\Lambda_{\rm orb}=\sum_q\Lambda_{{\rm orb},q}.
\]

Report also the simpler marginal-density predictors

\[
\Lambda_{\rm mass}^{\rm flat}
=\sum_q\mu_qA_q^0,
\qquad
\Lambda_{\rm coord}^{\rm flat}
=\sum_q\mu_q\#\{t:A_q(t)>0\}.
\tag{21}
\]

The conditional quantity (19), not (21), is primary.

### 6.3 Null probability and energy distribution

Use at least `100000` fixed-seed conditional draws per complete confirmation shell; use `1000000` when reporting a tail below `10^-3`. Randomize different `q` independently conditional on their preserved data. For every draw recompute:

```text
marked coordinate/orbit count;
marked occurrence mass;
linear APUC sum;
quadratic APUC energy sum;
maximum single-q energy;
share contributed by the largest q.
```

Use the finite-randomization p-value

\[
p_{\rm low}
=\frac{1+\#\{b:S_b\le S_{\rm actual}\}}{1+N_{\rm rep}}
\tag{22}
\]

for an APUC-depletion alternative. Marked mass should lie in a predeclared central null region—e.g. above its 5th percentile—before a low APUC tail is interpreted as anti-alignment.

### 6.4 Do not count T repeatedly as independent exposure

One intrinsic `(q,orbit)` upper mark is reused over all `T` in its activation interval. Therefore:

```text
wrong: count every active T as a fresh upper-zero trial;
right: deduplicate hit exposure by (q, reflection orbit).
```

For a shell-level statistic evaluated over many event breakpoints, either:

1. predeclare a fixed endpoint such as `T=3P`, or
2. compute the same maximum/integral over all geometry-determined breakpoints inside every null replicate.

The recommended primary confirmation statistic is the value at the predeclared complete endpoint. A maximum over breakpoints is a useful secondary statistic if its look-elsewhere effect is simulated exactly.

## 7. Stopping rules

Use three levels of completion.

### Pipeline-valid

```text
at least one actual marked reflection orbit;
its full q fibre and all active lower primes are closed;
identities in Section 11 pass.
```

This proves only that the censoring wall has been crossed.

### First informative

```text
conditional expected marked-orbit exposure >= 10;
at least 10 distinct marked q fibres or 25 marked reflection orbits;
marked occurrence mass is not below the null 5th percentile;
one complete holdout shell after discovery.
```

At exposure `10`, a no-hit outcome has proxy probability about `e^-10`; the APUC distribution is finally populated enough to compare tails.

### Strong finite stress test

```text
conditional exposure >= 25;
at least three predeclared complete new shells;
at least 25 marked reflection orbits and 20 marked q fibres;
no single q contributes more than 25% of total null-expected energy,
or report a leave-one-q-out analysis if it does.
```

The thresholds are finite-experiment design choices, not theorem hypotheses. Their purpose is to prevent another formally exact but statistically empty zero result.

### 10.3 Why a schema-neutral adapter is necessary

The only file-specific function should be

```cpp
void for_each_lower_zero_pair(
    const PairManifest& manifest,
    const std::function<void(std::uint32_t p,
                             std::uint32_t u,
                             std::uint32_t v)>& emit);
```

All order expansion, reflection expansion, inverse formulas, primality, and q6 masks belong after this adapter. This prevents the production mathematics from depending on an undocumented binary/CSV layout.

### 11.4 Exact identities

Reject the run unless all applicable identities hold:

\[
qM_q-Z(q)A_q^0
=qG_q(m_{1,q}-m_{0,q}),

\[

=G_q(m_{1,q}-m_{0,q})_+^2

and

```text
sum_t A_q(t) equals the number of active distinct (p,q,t) keys;

event active at T_lo and T_hi, inactive at adjacent exterior integers;

```

On a small complete box, require byte-for-byte equality with a literal `q,t,p` implementation, not floating tolerance.

## Final assessment

The smallest immediate computation is the `p<=1M` candidate-q closure, but it should be described as a **censoring check**, not as a likely informative experiment. Its calibrated expected exposure is only about `0.08` in the complete range.

The most discriminating finite experiment is an exposure-stopped, fixed-`J`, inverse-event search with these features:

```text
actual Boolean A_q(t), not C=A-R;
division-free half recurrence;
inverse zero-pair generation and exact activation intervals;
Boolean union by numerical lower prime;
upper q tables computed only on candidate fibres;
reflection-orbit rather than raw-event exposure;
exact row load and p-multiplicity records;
G_q(m1-m0)_+^2 evaluated only after the whole q row is closed;
conditional null preserving Z(q), reflection, and no-consecutive zeros;
discovery followed by a predeclared complete holdout shell.
```

A credible finite conclusion requires ordinary marked mass together with depleted positive APUC cut/energy. Another all-unmarked table—even a much larger exact one—remains censored and should be reported only as a bound on where the selected regime has not yet appeared.
