# P3.2 cold audit: the oriented endpoint rectangle and the failed `q -> 2q+1` cascade

## Verdict

The corrected **oriented** rectangle is substantially cleaner than the single-height endpoint gate, but the proposed theorem needs one explicit scope restriction.

Let

```text
m  = 2q+1,
H0 = floor((n-q)/m),
A  = H0+1 = floor((n+q+1)/m),
U  = floor(n/(q+1)).
```

Use heights

```text
H0 <= K <= U-1,
```

or equivalently endpoint indices

```text
A <= k=K+1 <= U.
```

For each height take the direct and reflected endpoint gcds, intersect the heights **inside each orientation**, and only then take their lcm. For primes

```text
sqrt(2n) < p <= n
```

this gives the following exact radical classification after removing the fixed primes dividing `8q+7`.

Write

```text
n = t*p+r,       0 <= r < p,
r* = p-1-r,
s  = min(r,r*).
```

Then a prime surviving the oriented rectangle is exactly one of:

```text
(I)  1 <= t <= q,
     s < A,
     p | b_s;

(II) t = 2q+1,
     the reflected branch is active,
     (2q+2)*s < p-q,
     p | b_s.
```

Case (II) has lower Newton multiplier

```text
B_1(-t-1) = -(8q+7).
```

Thus, without saturating the fixed divisor, its exact Newton condition is

```text
p | (8q+7)*b_s.
```

The direct branch never occurs in case (II).

The endpoint `p=U+1` is preserved. Indeed the height range stops at `K=U-1`, so its largest endpoint index is `k=U=p-1`. Including `K=U` would insert `k=p`, whose least base-`p` digit is zero and would destroy both endpoint gates. The upper endpoint in the corrected theorem is therefore sharp.

There is one literal correction:

> If “every survivor” includes primes `p>n`, the stated dichotomy is incomplete.

There is an additional reflected `t=0` family

```text
p = n+s+1,
0 <= s < A,
p | b_s.
```

It survives every reflected height. The dichotomy in the question is exact only after the natural fixed-quotient restriction `p<=n` (equivalently `t>=1`), or after separately removing the `t=0` reflected sector.

The strategic cascade does **not** prove `log R_q(n)=o(n)`. The strongest valid squarefree integer identity is, after removing earlier quotient slices and fixed primes,

```text
N_q(n) = R_q(n) * E_q(n),
```

where `E_q(n)` is only the thin subset of the `(2q+1)`-slice satisfying

```text
(2q+2)*s < p-q.
```

Although

```text
E_q(n) | R_(2q+1)(n),
```

this is a subset relation in the wrong direction for telescoping. In logarithms,

```text
y_q = x_q + e_q,
0 <= e_q <= x_(2q+1),
```

where `x_q=log R_q`, `e_q=log E_q`, and `y_q=log N_q`. Hence

```text
x_q >= y_q - x_(2q+1),
x_q <= y_q.
```

The later slice gives only a **lower** bound for `x_q`, not an upper bound. The unconditional tail estimate

```text
sum_(t>Q) log R_t(n) = O(n/Q)
```

therefore cannot be pulled back along the cascade.

A valid telescoping consumer would need the genuinely new coverage inequality

```text
log(R_(2q+1)(n) / E_q(n)) = o_q(n),
```

or equivalently an integer `T_q(n)` of logarithmic height `o_q(n)` such that

```text
R_(2q+1)(n) | E_q(n) * T_q(n).
```

Nothing in the rectangle proves this. The rectangle produces a **union of supports**, not a pairing, injection, norm map, or quotient from the `q`-slice to the whole `(2q+1)`-slice.

An explicit private-prime support model satisfying every local property used by the rectangle—reflection, one isolated zero pair per characteristic, no consecutive zeros, and Lucas propagation—can have linear logarithmic mass in one fixed `q`-slice, no exceptional `(2q+1)` primes at all, and zero tail. Thus the proposed dependency edge is invalid even at the exact theorem-interface level.

```text
E_q(n)
```

## 10. Why the cascade does not telescope

Let

```text
q_0=q,
q_(j+1)=2q_j+1.
```

Thus

```text
q_j=2^j(q+1)-1.
```

Put

```text
x_j = log R_(q_j)^rough(n),
e_j = log E_(q_j)(n),
y_j = log N_(q_j)(n).
```

The exact carrier identity and the support inclusion give only

```text
y_j = x_j+e_j,
0<=e_j<=x_(j+1).
```

Consequently

```text
x_j = y_j-e_j <= y_j,
```

and

```text
x_j = y_j-e_j >= y_j-x_(j+1).
```

The later slice appears in a **lower bound** for `x_j`. There is no upper estimate of `x_j` by `x_(j+1)`.

Multiplying the integer carriers makes the situation worse rather than telescoping:

```text
product_(j<J) N_(q_j)
 = (product_(j<J) R_(q_j))
   (product_(j<J) E_(q_j)).
```

The exceptional factors are multiplied; they are not cancelled. A formal alternating quotient would require division by the whole next radical, but only

```text
E_(q_j) | R_(q_(j+1))
```

is known. In general

```text
R_(q_(j+1)) / E_(q_j)
```

is a nontrivial integer of completely uncontrolled height.

The unconditional tail estimate is

```text
sum_(t>Q) log R_t(n)
 <= theta(n/(Q+1))
 = O(n/Q).
```

It says that `x_J=o(n)` after first choosing a large fixed `Q` and iterating until `q_J>Q`. But the relations above do not propagate this estimate backward.

### Exact missing inequality

One of the following genuinely new statements would be sufficient:

```text
log(R_(2q+1)(n)/E_q(n)) = o_q(n),
```

or, in carrier form, a nonzero integer `T_q(n)` with

```text
R_(2q+1)(n) | E_q(n) T_q(n),
log|T_q(n)|=o_q(n).
```

This is a **coverage theorem** for the thin reflected wedge. The rectangle proves only

```text
E_q(n) | R_(2q+1)(n),
```

which is the reverse divisibility.

Alternatively, a direct estimate

```text
log N_q(n)=o_q(n)
```

would solve the `q`-slice immediately, without any cascade. No such estimate follows from the support classification itself.

The exceptional wedge is genuinely thin. If `m=2q+1`, then its condition is approximately

```text
s < p/(m+1) ~ n/(m(m+1)),
```

whereas the full `m`-slice folded range has scale

```text
n/(2m+1).
```

Their ratio is approximately

```text
(2m+1)/(m(m+1)) ~ 2/m.
```

There is no deterministic reason for almost all `m`-slice logarithmic mass to lie in this wedge.

## 11. Abstract Apéry-compatible obstruction

The failure is logical, not merely a missing estimate in the calculations.

Fix a quotient `q` and a sequence of large `n`. Choose a set `S_q(n)` of private primes in the `q`-slice with logarithmic weight

```text
sum_(p in S_q(n)) log p >= c_q n
```

for some fixed `c_q>0`. For each selected characteristic use exactly one isolated reflected zero pair

```text
Z_p={s_p,p-1-s_p},
```

with `s_p<A_q`, avoiding the midpoint and consecutive positions. Put no zeros in any other characteristic in the rough range.

This support model has all properties used by the rectangle proof:

```text
* reflection symmetry;
* no consecutive zeros;
* only one reflected pair in each characteristic;
* no local nonmate collision;
* Lucas propagation from the selected first digit;
* no shared cross-characteristic prime is required.
```

It is therefore compatible with the complete local theorem interface used in the derivation. It is not asserted to be the actual Apéry sequence; it is a countermodel to the proposed **dependency edge**.

In this model,

```text
R_q(n) = product_(p in S_q(n)) p,
E_q(n) = 1,
R_t(n) = 1 for every t>q.
```

Hence

```text
sum_(t>Q) log R_t(n)=0
```

for every `Q>=q`, while

```text
log R_q(n) >= c_q n.
```

The oriented carrier identity is still perfectly true:

```text
N_q(n)=R_q(n)E_q(n)=R_q(n).
```

Thus the local rectangle theorem plus the unconditional quotient tail cannot logically imply `log R_q(n)=o(n)`. Any successful consumer must add a cross-slice coverage or height theorem not present in the current package.

## 12. Exact regression checker for the floor geometry

The proof above is algebraic. The following standard-library script is only a regression checker for floor and strict-boundary mistakes; no finite scan is used as an asymptotic conclusion.

```python
#!/usr/bin/env python3
from math import isqrt


def primes_upto(limit: int) -> list[int]:
    sieve = bytearray(b"\x01") * (limit + 1)
    sieve[:2] = b"\x00\x00"
    for p in range(2, isqrt(limit) + 1):
        if sieve[p]:
            sieve[p*p:limit+1:p] = b"\x00" * (
                (limit - p*p) // p + 1
            )
    return [p for p in range(2, limit + 1) if sieve[p]]


def audit(q: int, n: int) -> None:
    m = 2*q + 1
    H0 = (n-q) // m
    A = H0 + 1
    U = n // (q+1)

    assert A == (n+q+1) // m
    if A > U:
        return

    for p in primes_upto(n + U + 1):
        if p*p <= 2*n:
            continue

        t, r = divmod(n, p)
        rstar = p - 1 - r
        s = min(r, rstar)

        direct = all((k % p) > r for k in range(A, U+1))
        reflected = all((k % p) > rstar for k in range(A, U+1))

        if p <= n:
            predicted_direct = (
                1 <= t <= q
                and r < A
            )
            predicted_reflected = (
                (1 <= t <= q and rstar < A)
                or (
                    t == 2*q+1
                    and (2*q+2)*s < p-q
                )
            )

            assert direct == predicted_direct, (
                q, n, p, A, U, t, r, "direct"
            )
            assert reflected == predicted_reflected, (
                q, n, p, A, U, t, r, "reflected"
            )

            if t == q:
                assert s <= H0
                assert p >= U+1
                if p == U+1:
```
