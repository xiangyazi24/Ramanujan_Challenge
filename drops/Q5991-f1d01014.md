# Verdict

The proposed identity is **false as stated**. In fact, the two facts

```text
A = -(1/8)*zeta(3)
C >= A
```

imply the strict lower bound

```text
3*C - 8*A >= (5/8)*zeta(3) > (5/12)*zeta(3).
```

Equivalently, the claimed equality has the exact positive gap decomposition

```text
(3*C - 8*A) - (5/12)*zeta(3)
  = 3*(C - A) + (5/24)*zeta(3)
  > 0.
```

Thus no Nielsen identity, branch convention, or convergence argument can prove the requested statement. At least one coefficient, sign, or kernel in the upstream reduction has been transcribed incorrectly.

The rest of this note gives a fully real, Lean-friendly proof of `A = -zeta(3)/8`, the pointwise comparison `C >= A`, all endpoint values, and an independent numerical/series audit.

# 1. Notation and convergence

Write

```text
Z = zeta(3) = trilog(1)
L = log(2)

A = integral from 0 to 1 of
      log(r)*log(1+r)/(1+r) dr

C = integral from 0 to 1 of
      log(r)*log(1+r)/(1+r+r^2) dr.
```

Both integrals converge absolutely. For `0 < r <= 1`,

```text
0 <= log(1+r) <= r,
1+r >= 1,
1+r+r^2 >= 1,
abs(log(r)) = -log(r).
```

Hence each absolute integrand is bounded by

```text
-r*log(r).
```

This dominating function is integrable on `[0,1]`; an explicit primitive on `(0,1]` is

```text
G(r) = r^2/4 - (r^2/2)*log(r),
G'(r) = -r*log(r),
lim_{r -> 0+} G(r) = 0,
G(1) = 1/4.
```

This domination also justifies all endpoint limits and interval-integral manipulations below. No complex logarithm occurs anywhere.

# 2. The only extra trilogarithm identity needed

The special value `trilog(1/2)` is needed to evaluate `A`. It follows from one real three-term identity. This identity is valid on `0 < x <= 1/2`; every polylogarithm argument then lies in `[-1,1]`:

```text
x                 is in (0, 1/2],
1-x               is in [1/2, 1),
-x/(1-x)          is in [-1, 0).
```

There are therefore no branch cuts.

## 2.1 Real dilogarithm Landen identity

For `0 < x <= 1/2`,

```text
dilog(-x/(1-x))
  = -dilog(x) - (1/2)*log(1-x)^2.                 (L2)
```

Proof by differentiation on `0 < x < 1/2`:

```text
y(x) = -x/(1-x),
y'(x) = -1/(1-x)^2,
y'(x)/y(x) = 1/(x*(1-x)),
1-y(x) = 1/(1-x).
```

Using

```text
d/dz dilog(z) = -log(1-z)/z,
```

we get

```text
d/dx dilog(y(x))
  = -log(1-y(x)) * y'(x)/y(x)
  = log(1-x)/(x*(1-x)).
```

On the other hand,

```text
d/dx [-dilog(x) - (1/2)*log(1-x)^2]
  = log(1-x)/x + log(1-x)/(1-x)
  = log(1-x)/(x*(1-x)).
```

Both sides tend to `0` as `x -> 0+`, so they are equal. Continuity extends the identity to `x=1/2`, where its left argument is `-1`.

## 2.2 Restricted three-term trilogarithm identity

For `0 < x <= 1/2`,

```text
trilog(x) + trilog(1-x) + trilog(-x/(1-x))
  = Z
    + (pi^2/6)*log(1-x)
    - (1/2)*log(x)*log(1-x)^2
    + (1/6)*log(1-x)^3.                           (L3)
```

This is the smallest non-elementary identity needed here, and it has a direct derivative proof.

Let the left side be `N(x)`. Since

```text
d/dx trilog(x) = dilog(x)/x,
```

and `y'(x)/y(x) = 1/(x*(1-x))` for `y=-x/(1-x)`, we have

```text
N'(x)
  = dilog(x)/x
    - dilog(1-x)/(1-x)
    + dilog(-x/(1-x))/(x*(1-x)).
```

Insert `(L2)` and then the given dilogarithm reflection formula

```text
dilog(x) + dilog(1-x)
  = pi^2/6 - log(x)*log(1-x).
```

A direct common-denominator simplification gives

```text
N'(x)
  = -pi^2/(6*(1-x))
    + log(x)*log(1-x)/(1-x)
    - log(1-x)^2/(2*x*(1-x)).                     (D)
```

Now differentiate the right side of `(L3)`. Its derivative is exactly `(D)`:

```text
d/dx [(pi^2/6)*log(1-x)]
  = -pi^2/(6*(1-x)),

d/dx [-(1/2)*log(x)*log(1-x)^2]
  = -log(1-x)^2/(2*x)
    + log(x)*log(1-x)/(1-x),

d/dx [(1/6)*log(1-x)^3]
  = -log(1-x)^2/(2*(1-x)).
```

The two squared-log terms combine as

```text
- log(1-x)^2/(2*x)
- log(1-x)^2/(2*(1-x))
= -log(1-x)^2/(2*x*(1-x)).
```

The endpoint constant is fixed at `x -> 0+`:

```text
trilog(x)                    -> 0,
trilog(1-x)                  -> trilog(1) = Z,
trilog(-x/(1-x))             -> 0,
log(1-x)                     -> 0,
log(x)*log(1-x)^2            -> 0.
```

For the last limit, on `0 < x <= 1/2`,

```text
abs(log(1-x)) <= x/(1-x) <= 2*x,
```

so

```text
abs(log(x)*log(1-x)^2) <= 4*x^2*abs(log(x)) -> 0.
```

Thus `(L3)` follows by equality of derivatives plus this one endpoint.

# 3. Exact half-argument values

The given dilogarithm reflection formula at `x=1/2` gives

```text
2*dilog(1/2) = pi^2/6 - log(1/2)^2
             = pi^2/6 - L^2,

dilog(1/2) = pi^2/12 - L^2/2.                    (H2)
```

Set `x=1/2` in `(L3)`. Then

```text
log(x) = log(1-x) = -L,
-x/(1-x) = -1,
trilog(-1) = -(3/4)*Z.
```

The right side becomes

```text
Z - (pi^2/6)*L + (1/2)*L^3 - (1/6)*L^3
= Z - (pi^2/6)*L + (1/3)*L^3.
```

Therefore

```text
2*trilog(1/2) - (3/4)*Z
  = Z - (pi^2/6)*L + (1/3)*L^3,

trilog(1/2)
  = (7/8)*Z - (pi^2/12)*L + (1/6)*L^3.           (H3)
```

Every sign in `(H3)` follows from the displayed substitution; in particular the cubic-log coefficient is `+1/6`.

# 4. A direct real primitive for A

The useful substitution is

```text
t = r/(1+r),
r = t/(1-t),
dr = dt/(1-t)^2,
1+r = 1/(1-t),
dr/(1+r) = dt/(1-t),
log(r) = log(t) - log(1-t),
log(1+r) = -log(1-t),
r=0 maps to t=0,
r=1 maps to t=1/2.
```

It leads to the following particularly Lean-friendly primitive in the original variable. For `0 <= r <= 1`, define

```text
u(r) = 1/(1+r),
ell(r) = log(1+r),

F_A(r)
  = ell(r)*dilog(u(r))
    + trilog(u(r))
    + (1/3)*ell(r)^3.                             (P)
```

For `0 < r < 1`,

```text
u'(r)/u(r) = -1/(1+r),
1-u(r) = r/(1+r),
log(1-u(r)) = log(r) - log(1+r).
```

Differentiate `(P)`:

```text
d/dr [ell*dilog(u)]
  = dilog(u)/(1+r)
    + ell*log(1-u)/(1+r),

d/dr [trilog(u)]
  = -dilog(u)/(1+r),

d/dr [(1/3)*ell^3]
  = ell^2/(1+r).
```

The `dilog(u)` terms cancel, and

```text
F_A'(r)
  = [ell*(log(r)-ell) + ell^2]/(1+r)
  = log(r)*log(1+r)/(1+r).
```

The endpoint values are exact:

```text
F_A(0)
  = log(1)*dilog(1) + trilog(1) + (1/3)*log(1)^3
  = Z,

F_A(1)
  = L*dilog(1/2) + trilog(1/2) + L^3/3.
```

Therefore the fundamental theorem of calculus gives

```text
A
  = F_A(1) - F_A(0)
  = L*dilog(1/2) + trilog(1/2) + L^3/3 - Z.
```

Insert `(H2)` and `(H3)`:

```text
A
  = L*(pi^2/12 - L^2/2)
    + [(7/8)*Z - (pi^2/12)*L + L^3/6]
    + L^3/3
    - Z.
```

Coefficient audit:

```text
pi^2*L coefficient:  1/12 - 1/12 = 0,
L^3 coefficient:    -1/2 + 1/6 + 1/3 = 0,
Z coefficient:       7/8 - 1 = -1/8.
```

Hence

```text
A = -(1/8)*Z.                                      (Aexact)
```

# 5. Pointwise comparison of C and A

For `0 < r < 1`, put

```text
N(r) = log(r)*log(1+r).
```

Then

```text
log(r) < 0,
log(1+r) > 0,
N(r) < 0.
```

Moreover,

```text
1+r+r^2 >= 1+r > 0.
```

The exact difference of the two integrands is

```text
N(r)/(1+r+r^2) - N(r)/(1+r)
  = -r^2*N(r) / ((1+r+r^2)*(1+r))
  >= 0.                                             (Cmp)
```

At the endpoints the inequality holds after assigning any finite representative values; endpoints have measure zero. Since both functions are integrable, integral monotonicity yields

```text
C >= A.                                             (CA)
```

Now combine `(Aexact)` and `(CA)`:

```text
3*C - 8*A
  = 3*(C-A) - 5*A
  = 3*(C-A) + (5/8)*Z
  >= (5/8)*Z.
```

Since `Z > 0`,

```text
(5/8)*Z > (5/12)*Z.
```

Equivalently,

```text
(3*C - 8*A) - (5/12)*Z
  = 3*(C-A) + (5/24)*Z
  >= (5/24)*Z
  > 0.
```

This is an exact algebraic contradiction to the requested identity.

There is also a branch-free real double series for `C`. On `0 <= r < 1`,

```text
1/(1+r+r^2)
  = (1-r)/(1-r^3)
  = sum over k>=0 of (r^(3*k) - r^(3*k+1)),

log(1+r)
  = sum over m>=1 of (-1)^(m+1)*r^m/m.
```

Using

```text
integral from 0 to 1 of r^q*log(r) dr = -1/(q+1)^2,
```

one obtains

```text
C
  = - sum over m>=1 of [(-1)^(m+1)/m]
      * sum over k>=0 of
          [1/(m+3*k+1)^2 - 1/(m+3*k+2)^2].        (Cseries)
```

Termwise integration is justified absolutely after integration, because

```text
sum over m>=1,k>=0 of (1/m)
  * [1/(m+3*k+1)^2 + 1/(m+3*k+2)^2]
```

converges: the inner sum is `O(1/m)`, so the outer summand is `O(1/m^2)`. Formula `(Cseries)` reproduces the numerical value above without complex roots or branch choices.

One further diagnostic is useful. If the right side `(5/12)*Z` and the coefficient `-8*A` were correct, then `(Aexact)` would force

```text
3*C + Z = (5/12)*Z,
C = -(7/36)*Z
  = -0.233733286725476666605504642516115275982...
```

This is far from the actual `C`. Thus changing only a tiny sign convention at an endpoint cannot repair the reduction.

# 8. Recommended correction step

Do not attempt to formalize the requested equality. First re-audit the upstream reduction that produced

```text
3*C - 8*A = (5/12)*zeta(3).
```

The fastest invariant check is the sign comparison `(Cmp)`: because both integrands are negative and the quadratic denominator is larger,

```text
C >= A = -zeta(3)/8.
```

Any corrected formula retaining the left side `3*C - 8*A` must therefore have a right side at least `(5/8)*zeta(3)`, not `(5/12)*zeta(3)`. Numerically,

```text
(3*C - 8*A)/zeta(3)
  = 0.664415991066830555227560025464043087384...
```

so the current left side is not merely off by a simple endpoint sign.
