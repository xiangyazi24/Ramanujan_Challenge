# A fresh attack: Apéry numbers as a norm and a finite-field torus problem

## 1. The small-prime periodicity idea

The observation that small primes give periodic information is correct but cannot directly control large prime divisors. If q is fixed, the recurrence modulo q has eventually periodic coefficients and hence b_n mod q is periodic. This describes the q-adic profile.

However, a large prime p dividing b_n is a condition on the integer value b_n itself. Congruence information modulo finitely many small q only restricts the residue class of b_n in a finite product ring. It does not impose a restriction on prime factors p much larger than all q.

Therefore the small-prime sieve cannot by itself prove

ω_(n/2,n](b_n)=o(n/log n).

The relevant structure must couple the index n with the large prime p.

## 2. The norm interpretation

Write

c_{n,k}=binom(n,k)binom(n+k,k).

Then

b_n=Σ_k c_{n,k}^2.

Modulo a prime p, this is the quadratic form

Q(x_0,...,x_n)=Σ x_k^2

on the special vector

v_n=(c_{n,0},...,c_{n,n}).

Thus

p|b_n ⇔ Q(v_n)=0 in F_p.

For a random vector this would have probability about 1/p, matching the heuristic that each large prime hits with probability about 1/p times the size of the zero set correction.

The missing point is that v_n is not random: it lies on a very rigid hypergeometric orbit.

## 3. The useful reformulation

The entries satisfy

c_{n,k+1}/c_{n,k}=((n-k)(n+k+1))/(k+1)^2.

Over F_p this means the sequence is generated by a first-order multiplicative recurrence. For p>n/2 the reduction has a special form because k,n are small compared with p.

The vector is therefore not an arbitrary point of F_p^{n+1}; it is a point on a hypergeometric curve.

The problem becomes:

How often does a hypergeometric point land on the quadric Q=0 modulo p?

This is an arithmetic intersection problem.

## 4. The stronger object: the generating polynomial

Define

B_n(X)=Σ c_{n,k}^2 X^k.

Then b_n=B_n(1). The condition p|b_n is the specialization condition

B_n(1)=0 mod p.

The Hadamard-square structure is important. The polynomial C_n(X)=Σc_{n,k}X^k is related to Jacobi/Legendre-type hypergeometric polynomials. The diagonal Hadamard product is a period of the tensor square of the corresponding hypergeometric motive.

Hence b_n is not an arbitrary integer value: it is a special value of a hypergeometric motive.

## 5. Why a product formula cannot exist

The relevant hypergeometric value is

_4F_3(-n,-n,n+1,n+1;1,1,1;1).

Classical product evaluations (Dixon, Watson, Dougall) require balancing conditions. Dixon applies to balanced _3F_2, Dougall to very-well-poised _5F_4. This _4F_3 is the Apéry period and is outside those product-formula families.

There is no Gamma quotient evaluation. If there were one, the Apéry recurrence would collapse to a first-order hypergeometric sequence, contradicting the irreducible order-two recurrence and the known modular interpretation.

So the hoped-for complete factorization does not occur.

## 6. A more promising new direction: Chebotarev on the Apéry motive

For p>n/2, the condition is

p|b_n ⇔ b_{n-p}=0 mod p.

This is not merely a divisibility event. It says the Frobenius trace of the Apéry motive at a moving parameter vanishes.

The correct geometric object is the rank-two Apéry sheaf. The zeros Z_p correspond to Frobenius trace-zero points. Bounding the number of p with n-p in Z_p is therefore a moving-Frobenius zero-density problem.

The norm viewpoint suggests the same conclusion from a different side: Q(v_n)=0 is a special Frobenius condition on a hypergeometric period.

## 7. Conclusion

The genuinely new information from the norm structure is:

1. p|b_n is a quadratic isotropy condition.
2. The vector is constrained by a hypergeometric recurrence, so the problem is an arithmetic intersection problem, not a random quadratic-form problem.
3. There is no hidden Gamma-product formula for b_n.
4. The right replacement for a factorization theorem is a monodromy/zero-density theorem for the Apéry hypergeometric sheaf.

The fresh route is therefore not to factor b_n, but to prove that the hypergeometric orbit has low intersection with the isotropic quadric for moving primes. This is the geometric form of the desired bound.
