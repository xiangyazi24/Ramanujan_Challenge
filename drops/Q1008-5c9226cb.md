# Line-numbered hostile audit

## 1. Index reversal: PASS

Put `r=n-k`. Then `0 <= r <= n-1`, and the claimed reversed flag is

\[
\beta_r=\beta_{n-k}=\frac{k}{(n,k)}.
\]

The coefficient of `T^k=T^{n-r}` in `P` is

\[
[T^k]P
=cq_k
=\frac Ln\frac{n}{(n,k)}
=\frac{L}{(n,k)}.
\]

On the other hand the standard lcm-cleared coefficient shape is

\[
\frac{L}{k}\beta_{n-k}
=\frac Lk\frac{k}{(n,k)}
=\frac{L}{(n,k)}.
\]

Equivalently, in the `r` indexing,

\[
(n-r)[T^{n-r}]P=L\beta_r.
\]

So the reversal is not cosmetic: it is exactly the one required to identify denominator `k=n-r` with flag `\beta_r`.

There is no divisibility problem in `L/k`, since every `1<=k<=n` divides `L`.

## 2. Dense positivity: PASS

For every `1<=k<=n`,

\[
q_k=n/(n,k)>0,
\qquad
[T^k]P=cq_k>0.
\]

Thus every coefficient in degrees `1,...,n` is nonzero and positive. If “dense” is meant in this coefficient range, the assertion is exact.

A source should explicitly state the sum range `1<=k<=n`; a bare unbounded `\sum q_kT^k` is only a notation omission, not a mathematical defect in the construction.

## 3. `Q` is primitive: PASS

At the top index,

\[
q_n=\frac{n}{(n,n)}=1.
\]

Hence

\[
\operatorname{cont}(Q)=\gcd(q_1,\dots,q_n)=1.
\]

No finite experiment is needed.

## 4. `cont(P)=c`: PASS

Since `P=cQ` and `Q` is primitive,

\[
\operatorname{cont}(P)
=c\operatorname{cont}(Q)=c.
\]

This is exact for every `n>=2`.

## 5. The requested proof `gcd_k(k q_k)=n`: PASS

The derivative is

\[
Q'(T)=\sum_{k=1}^n kq_kT^{k-1}.
\]

For every `k`,

\[
kq_k
=k\frac{n}{(n,k)}
=n\frac{k}{(n,k)},
\]

so every derivative coefficient is divisible by `n`. Therefore

\[
n\mid \operatorname{cont}(Q').
\]

But the `k=1` derivative coefficient is

\[
1\cdot q_1=n.
\]

Therefore any common divisor of all derivative coefficients divides `n`. Combining both directions,

\[
\boxed{\operatorname{cont}(Q')=\gcd_{1\le k\le n}(kq_k)=n.}
\]

Consequently

\[
\boxed{c\operatorname{cont}(Q')=(L/n)n=L.}
\]

Also, since `P'=cQ'`,

\[
\operatorname{cont}(P')=c\,n=L.
\]

This is a theorem for every `n`, not a finite-test observation.

## 6. `B | U`: PASS

\[
U=P(1)=c\sum_{k=1}^nq_k,

we have `c|U`. By definition `B=rad(c)|c`. Hence

\[
\boxed{B\mid U.}
\]

Also `c|L`, hence `B|L`.

## 7. `K=J=B`: PASS

\[
K=(L,B)=B.

## 8. Exact two-denominator union identity: PASS

\[

\[

\[

\frac{L}{(L,U)}

\boxed{\frac LJ}.

This proof is primewise valid and does not assume `(L,U)=B`.

## 9. Primes missing from `rad(L/n)`: PASS

\[

\boxed{M_n\mid \operatorname{rad}(n)\mid n.}

\[

## 11. Asymptotic `log B=n+o(n)`: PASS

Since

\[

\[

From `rad(L)=B M_n` and `M_n|n`,

\[
\log B
=\vartheta(n)-\log M_n
=\vartheta(n)+O(\log n)
=\boxed{n+o(n)}.

Since `J=K=B`,

\[
\boxed{\log J=\log K=n+o(n)}.

```python
from math import gcd, lcm
from functools import reduce


def gcd_all(xs):
    return reduce(gcd, xs, 0)


def primes_upto(n):
    sieve = bytearray(b"\x01") * (n + 1)
    if n >= 0:
        sieve[0] = 0
    if n >= 1:
        sieve[1] = 0
    p = 2
    while p * p <= n:
        if sieve[p]:
            sieve[p*p:n+1:p] = b"\x00" * (((n - p*p)//p) + 1)
        p += 1
    return [p for p in range(2, n + 1) if sieve[p]]


def rad_from_known_primes(x, ps):
    out = 1
    for p in ps:
        if x % p == 0:
            out *= p
    return out


def check(n):
    assert n >= 2

    L = 1
    for k in range(1, n + 1):
        L = lcm(L, k)
    assert L % n == 0
    c = L // n

    q = [None] + [n // gcd(n, k) for k in range(1, n + 1)]
    beta = [None] * n
    for k in range(1, n + 1):
        beta[n-k] = k // gcd(n, k)

    # P coefficients in degrees 1,...,n.
    P = [None] + [c * q[k] for k in range(1, n + 1)]

    # Exact reversed lcm-cleared coefficient identity.
    for k in range(1, n + 1):
        assert k * P[k] == L * beta[n-k]
        assert P[k] == (L // k) * beta[n-k]

    # Primitive Q and contents.
    assert q[n] == 1
    assert gcd_all(q[1:]) == 1
    assert gcd_all(P[1:]) == c

    deriv_Q = [k * q[k] for k in range(1, n + 1)]
    assert gcd_all(deriv_Q) == n
    assert c * gcd_all(deriv_Q) == L

    deriv_P = [k * P[k] for k in range(1, n + 1)]
    assert gcd_all(deriv_P) == L

    ps = primes_upto(n)
    B = rad_from_known_primes(c, ps)
    U = sum(P[1:])

    assert c % B == 0
    assert U % B == 0

    K = gcd(L, B)
    J = gcd(gcd(L, B), U)
    assert K == B
    assert J == B

    # Exact denominator-union identity.
    den_B = L // gcd(L, B)
    den_U = L // gcd(L, U)
    assert lcm(den_B, den_U) == L // J

    # Missing radical primes.
    rad_L = rad_from_known_primes(L, ps)
    assert rad_L % B == 0
    missing = rad_L // B
    assert n % missing == 0

    return {
        "n": n,
        "L": L,
        "c": c,
        "B": B,
        "U": U,
        "K": K,
        "J": J,
        "gcd_L_U": gcd(L, U),
        "missing": missing,
```
