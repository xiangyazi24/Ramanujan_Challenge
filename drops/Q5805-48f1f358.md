# Newton/beta--Pade transform of the original Apéry pair

## Verdict

The direct transform is an exact Casoratian collapse, but it is **not** a target carrier.

For the reversed pair

\[
 x_d^{(a)}=a_{n-d-1},\qquad x_d^{(b)}=b_{n-d-1},
\]

two adjacent Newton carriers have a raw exterior determinant divisible by every prime node in their common stencil. That factor is universal interpolation content: it is present for every pair of input sequences. After dividing by the primitive Newton factor, the determinant becomes

\[
 \frac{6\,\Theta_{n,D,N}}{((R!)/(S!))^6},
\]

where \(S=n-D-N-1\), \(R=n-D\), and \(\Theta_{n,D,N}\) is an explicit integer determinant formed only from the Apéry recurrence coefficients and the Newton weights. It is independent of whether any marked value \(b_r\) vanishes modulo its moving prime.

At a top-half target \(p=n-r\), the reversed marked vector is

\[
 (a_r,b_r)=(\text{unit},0)\pmod p,
\]

not \((0,0)\). Hence the raw determinant gets only one copy of \(p\), exactly the copy in the universal binomial normalization. The primitive exterior minor retains \(p\) if and only if the recurrence-only scalar \(\Theta_{n,D,N}\) happens to vanish modulo \(p\). Targetness does not force that.

For the shortest block the complete formula is

\[
 \boxed{
 \mathcal E_{p,r,1}
 =-
 \frac{6\left(
 32pr^3+(48p+3)r^2+(24p+3)r+4p+1
 \right)}{r^3(r+1)^3}.}
\]

It is nonzero for every \(p,r>0\). At a target prime \(p\ge7\), its primitive numerator is divisible by \(p\) exactly when

\[
 p\mid 3r^2+3r+1,
\]

an extra recurrence-geometric condition unrelated to \(p\mid b_r\).

Thus the answer is negative in the precise sense requested:

1. the normalized determinant does reduce to a small recurrence-only determinant/resultant;
2. the reduction removes the target condition along with the universal node factor;
3. retaining the unnormalized factor keeps all candidate primes, target and non-target alike;
4. using the global lcm-cleared pair only adds linear-height, target-blind normalization content.

This is the Route-A Casoratian defect in a Newton/beta--Pade basis, not a new block compression.

## 2. Reversed block and adjacent Newton carriers

 N\ge1,\qquad D>N,\qquad S:=n-D-N-1\ge0,

 R:=n-D.
\tag{2.2}

The candidate-node block is

\[
 I=[D,D+N-1].
\tag{2.3}

A prime candidate has

\[
 d=p-1\in I,

 p\in[D+1,D+N],

 r=n-p.
\tag{2.4}

The reversed sequence associated to any recurrence solution \(f\) is

 x_d^{(f)}=f_{n-d-1}.

 B_{D,N}=\binom{D+N}{N}

 \boxed{G_f^- -G_f^+=B_{D,N}H_f.}

## 3. Exact primitive exterior normalization

First form the rational raw determinant

\[
 \Delta_{n,D,N}
 =G_a^-G_b^+-G_a^+G_b^-.
\tag{3.1}
\]

Equation (2.9) gives the quotient-free identity

\[
 \boxed{
 \varepsilon_{n,D,N}
 :=\frac{\Delta_{n,D,N}}{B_{D,N}}
 =H_aG_b^- -G_a^-H_b.}
\tag{3.2}
\]

This is the correct primitive Newton normalization. It is a rational number because the companion column is rational.

Write it in lowest terms as

\[
 \varepsilon_{n,D,N}=\frac{U_{n,D,N}}{V_{n,D,N}},
 \qquad
 U_{n,D,N}\in\mathbb Z,
 \quad V_{n,D,N}\in\mathbb Z_{>0},
 \quad \gcd(U,V)=1.
\tag{3.3}
\]

Then \(U_{n,D,N}\) is the primitive integral exterior minor obtained by clearing **only** the denominator required for integrality. Any larger lcm normalization adds removable content.

For comparison, define the exact block denominator

\[
 Q_{S,R}
 =\operatorname {lcm}_{S\le k\le R}\operatorname {den}(a_k).
\tag{3.4}
\]

Then all values \(Q_{S,R}a_k\) used in the two carriers are integral, and (3.2) proves

\[
 Q_{S,R}\varepsilon_{n,D,N}\in\mathbb Z.
\tag{3.5}
\]

Consequently

\[
 \boxed{V_{n,D,N}\mid Q_{S,R}.}
\tag{3.6}
\]

Since the standard Apéry denominator theorem gives

\[
 \operatorname {den}(a_k)\mid\operatorname {lcm}(1,\ldots,k)^3,
\]

one also has

\[
 \boxed{
 V_{n,D,N}\mid Q_{S,R}\mid L_R^3,
 \qquad L_R=\operatorname {lcm}(1,\ldots,R).}
\tag{3.7}
\]

Thus no hidden factorial denominator is being ignored; Section 5 below gives its exact cancellation ledger.

## 4. Symbolic Casoratian reduction

The recurrence becomes integral after factorial scaling. Put

\[
 X_k^{(f)}=(k!)^3f_k.
\tag{4.1}
\]

Then

\[
 X_{k+1}^{(f)}=P(k)X_k^{(f)}-k^6X_{k-1}^{(f)}.
\tag{4.2}
\]

Define integer transfer vectors \(c_k=(u_k,v_k)\in\mathbb Z^2\) for
\(S\le k\le R\) by

\[
 c_S=(1,0),\qquad c_{S+1}=(0,1),
\tag{4.3}
\]

and

\[
 c_{k+1}=P(k)c_k-k^6c_{k-1}
 \qquad(S+1\le k<R).
\tag{4.4}
\]

For every recurrence solution \(f\),

\[
 X_k^{(f)}=u_kX_S^{(f)}+v_kX_{S+1}^{(f)}.
\tag{4.5}
\]

Let

\[
 w_i=(-1)^i
 \binom{D-1+i}{i}\binom{D+N}{N-i}
 \qquad(0\le i\le N),
\tag{4.6}
\]

and

\[
 h_i=(-1)^i\binom{N+1}{i}
 \qquad(0\le i\le N+1).
\tag{4.7}
\]

Define the two integer coefficient rows

\[
\begin{aligned}
 \bar g
 &=\sum_{i=0}^N
 w_i\left(\frac{R!}{(R-i)!}\right)^3c_{R-i},\\
 \bar h
 &=\sum_{i=0}^{N+1}
 h_i\left(\frac{R!}{(R-i)!}\right)^3c_{R-i}.
\end{aligned}
\tag{4.8}
\]

Then

\[
 G_f^-=\frac{\bar g_0X_S^{(f)}+\bar g_1X_{S+1}^{(f)}}{(R!)^3},
\qquad
 H_f=\frac{\bar h_0X_S^{(f)}+\bar h_1X_{S+1}^{(f)}}{(R!)^3}.
\tag{4.9}
\]

Set

\[
 \boxed{
 \Theta_{n,D,N}
 =\det\begin{pmatrix}
 \bar g_0&\bar g_1\\
 \bar h_0&\bar h_1
 \end{pmatrix}
 =\bar g_0\bar h_1-\bar g_1\bar h_0.}
\tag{4.10}
\]

The scaled base Casoratian is

\[
 X_{S+1}^{(a)}X_S^{(b)}-X_S^{(a)}X_{S+1}^{(b)}
 =6(S!)^6.
\tag{4.11}
\]

Substitution into (3.2) now gives the complete symbolic reduction:

\[
 \boxed{
 \varepsilon_{n,D,N}
 =\frac{6(S!)^6}{(R!)^6}\Theta_{n,D,N}
 =\frac{6\Theta_{n,D,N}}
        {\left((R!)/(S!)\right)^6}.}
\tag{4.12}
\]

This is the desired exact resultant/subresultant. It is just the determinant of the two Newton-operator remainders in the two-dimensional Apéry recurrence module.

Equivalently, if

\[
 F_{S,R}=\left(\frac{R!}{S!}\right)^6,
 \qquad
 c=\gcd(6\Theta_{n,D,N},F_{S,R}),
\tag{4.13}
\]

then the exact primitive numerator and denominator are

\[
 \boxed{
 U_{n,D,N}=\frac{6\Theta_{n,D,N}}c,
 \qquad
 V_{n,D,N}=\frac{F_{S,R}}c.}
\tag{4.14}
\]

Equations (3.7) and (4.14) show exactly how the apparent factorial denominator cancels down to a divisor of the genuine Apéry lcm denominator.

### Module interpretation

Let the Newton functional \(G^-\) and the divided-difference functional \(H\) be reduced modulo the order-two recurrence to first-order remainders

\[
 G^-\equiv g_0+g_1S,
 \qquad
 H\equiv h_0+h_1S.
\]

Then \(\Theta=g_0h_1-g_1h_0\). If \(\Theta=0\), the two transformed rows are dependent on the entire solution module and the exterior minor is zero for **every** solution pair. If \(\Theta\ne0\), the transformed rows are merely another basis of the same rank-two module, and their determinant is the original Casoratian multiplied by the recurrence-only change-of-basis determinant.

This is exactly the mechanism closed in Section 4, now written in the Newton/beta--Pade basis.

## 5. Exact target-local valuation ledger

Let \(p\) be a top-half candidate in the block:

\[
 p\in[D+1,D+N],
 \qquad p>n/2,
 \qquad p>N,
\tag{5.1}
\]

and put

\[
 r=n-p,
 \qquad d=p-1\in I.
\tag{5.2}
\]

Because \(p>n/2\) and \(D<p\), one has

\[
 R=n-D<p.
\tag{5.3}
\]

Hence every denominator of every \(a_k\) in the reversed block is a \(p\)-unit. In particular

\[
 p\nmid Q_{S,R},\qquad p\nmid V_{n,D,N},\qquad p\nmid F_{S,R}.
\tag{5.4}
\]

The common-node Newton selector gives, for either solution \(f\),

\[
 G_f^-\equiv G_f^+\equiv f_r\pmod p.
\tag{5.5}
\]

Also

\[
 v_p(B_{D,N})=1,
\tag{5.6}
\]

because \((D,D+N]\) contains the unique multiple \(p\) and \(N!\) is a \(p\)-unit.

### 5.1 Raw determinant

Equation (5.5) implies

\[
 \Delta_{n,D,N}\equiv0\pmod p
\tag{5.7}
\]

for **every** pair of recurrence solutions, and in fact for every pair of input sequences for which reduction is defined. This is universal node content, not targetness.

Since

\[
 \Delta_{n,D,N}=B_{D,N}\varepsilon_{n,D,N},
\]

and \(V\) is a \(p\)-unit,

\[
 v_p(\text{numerator of }\Delta)
 =1+v_p(U_{n,D,N}).
\tag{5.8}
\]

### 5.2 What targetness gives

Assume now that \(p\) is an actual top-half target:

\[
 p\mid b_r.
\tag{5.9}
\]

The Casoratian (1.2) shows first that

\[
 p\nmid b_{r+1}
\tag{5.10}
\]

and then

\[
 -a_rb_{r+1}\equiv\frac6{(r+1)^3}\pmod p.
\tag{5.11}
\]

Therefore

\[
 \boxed{p\nmid a_r.}
\tag{5.12}
\]

Thus the marked reversed vector has rank one, not rank zero:

\[
 (a_r,b_r)=(\text{unit},0)\pmod p.
\tag{5.13}
\]

From the quotient-free identity,

\[
 \varepsilon_{n,D,N}
 \equiv-a_rH_b\pmod p.
\tag{5.14}
\]

Reduce \(H_f\) to the marked state:

\[
 H_f=h_0^{(r)}f_r+h_1^{(r)}f_{r+1}.
\tag{5.15}
\]

Then (5.9)--(5.11) give

\[
 \boxed{
 \varepsilon_{n,D,N}
 \equiv
 \frac{6h_1^{(r)}}{(r+1)^3}\pmod p.}
\tag{5.16}
\]

Equivalently, using (4.12)--(4.14),

\[
 \boxed{
 p\mid U_{n,D,N}
 \quad\Longleftrightarrow\quad
 p\mid\Theta_{n,D,N}.}
\tag{5.17}
\]

The right side depends only on the recurrence and the block geometry. It does not contain the target condition \(p\mid b_r\).

This is the decisive difference from the Laurent-shell pair. For the shell construction, both marked coordinates \(Y_{p-1}\) and \(Z_{p-1}\) vanish, so the raw determinant has at least \(p^2\) and primitive division by the single node factor leaves one \(p\). For the original Apéry pair, only the \(b\)-coordinate vanishes, so the raw determinant has only the universal single \(p\), which primitive division removes.

## 6. The shortest block: complete closed formula

Take a one-node block

\[
 N=1,\qquad D=p-1,
\]

so \(r=n-p\), \(R=r+1\), and \(S=r-1\). Assume \(r\ge1\).

The two carriers and the divided difference are

\[
\begin{aligned}
 G_f^-&=pf_{r+1}-(p-1)f_r,\\
 G_f^+&=(p+1)f_r-pf_{r-1},\\
 H_f&=f_{r+1}-2f_r+f_{r-1}.
\end{aligned}
\tag{6.1}
\]

The three required Casoratians are

\[
\begin{aligned}
 a_{r+1}b_r-a_rb_{r+1}&=\frac6{(r+1)^3},\\
 a_rb_{r-1}-a_{r-1}b_r&=\frac6{r^3},\\
 a_{r+1}b_{r-1}-a_{r-1}b_{r+1}
 &=\frac{6P(r)}{r^3(r+1)^3}.
\end{aligned}
\tag{6.2}
\]

Expansion of (3.2) gives

\[
\begin{aligned}
 \varepsilon_{p,r,1}
 ={}&(p+1)
 (a_{r+1}b_r-a_rb_{r+1})\\
 &-p(a_{r+1}b_{r-1}-a_{r-1}b_{r+1})\\
 &+(p-1)(a_rb_{r-1}-a_{r-1}b_r).
\end{aligned}
\tag{6.3}
\]

Substituting (6.2) and simplifying yields

\[
 \boxed{
 \varepsilon_{p,r,1}
 =-
 \frac{6\left(
 32pr^3+(48p+3)r^2+(24p+3)r+4p+1
 \right)}{r^3(r+1)^3}.}
\tag{6.4}
\]

The numerator in parentheses is strictly positive, so

\[
 \varepsilon_{p,r,1}\ne0
\tag{6.5}
\]

for every \(p,r>0\).

Let

\[
 T_{p,r}=32pr^3+(48p+3)r^2+(24p+3)r+4p+1,
\]

and

\[
 g_{p,r}=\gcd(6T_{p,r},r^3(r+1)^3).
\]

The exact primitive integral minor and its exact denominator are

\[
 U_{p,r,1}=-\frac{6T_{p,r}}{g_{p,r}},
 \qquad
 V_{p,r,1}=\frac{r^3(r+1)^3}{g_{p,r}}.
\tag{6.6}
\]

For a top-half prime \(p\ge7\), the denominator is a \(p\)-unit and

\[
 T_{p,r}\equiv3r^2+3r+1\pmod p.
\]

Hence

\[
 \boxed{
 p\mid U_{p,r,1}
 \quad\Longleftrightarrow\quad
 p\mid3r^2+3r+1.}
\tag{6.7}
\]

This condition is present whether or not \(p\mid b_r\). The shortest transform therefore gives an explicit nonzero low-degree scalar, but it does not carry the moving target set.

## 7. Direct beta--Pade identity: why the upper-index divisibility cancels

Let \(\mathsf S\) be the forward shift in the candidate-node variable \(d\):

\[
 (\mathsf Sx)_d=x_{d+1}.
\]

The beta polynomial is

\[
 Q_{D,N}(T)
 =\sum_{i=0}^N(-1)^i
 \binom{D-1+i}{i}\binom{D+N}{N-i}T^i.
\tag{7.1}
\]

The exact incomplete-beta identity is

\[
 T^DQ_{D,N}(T)+(1-T)^{N+1}R_{D,N}(T)=1.
\tag{7.2}
\]

Apply it to the reversed sequence at \(d=-1\). Since

\[
 x_{-1}^{(f)}=f_n,
\]

one gets

\[
 \boxed{
 G_f^-+\mathcal B_f^-=f_n,}
\tag{7.3}
\]

where

\[
 \mathcal B_f^-
 =\bigl((1-\mathsf S)^{N+1}R_{D,N}(\mathsf S)x^{(f)}\bigr)_{-1}.
\]

Applying the same identity with \(D+1\) gives

\[
 \boxed{
 G_f^++\mathcal B_f^+=f_n.}
\tag{7.4}
\]

Subtracting (7.3) and (7.4) cancels the common upper-index packet \(f_n\):

\[
 G_f^- -G_f^+
 =\mathcal B_f^+-\mathcal B_f^-
 =B_{D,N}H_f.
\tag{7.5}
\]

For a target prime, the known simultaneous divisibility occurs at the **upper index** after the prime-dependent clearing \(p^3a_n\), not at the reversed marked companion value \(a_r\). Equations (7.3)--(7.5) show exactly what happens:

- keeping the common endpoint \(f_n\) does not cancel the beta boundary;
- cancelling the common endpoint produces the universal Newton factor \(B_{D,N}\);
- primitive division by \(B_{D,N}\) leaves the recurrence-only scalar (4.12).

This is the same-radius saturation theorem of Section 67.5, specialized to the original recurrence module.

## 8. Nonzeroness audit

The general statement is exact:

\[
 \boxed{
 U_{n,D,N}=0
 \quad\Longleftrightarrow\quad
 \Theta_{n,D,N}=0.}
\tag{8.1}
\]

If \(\Theta=0\), the two transformed rows are dependent on the entire two-dimensional solution space. The determinant then vanishes for every fundamental pair and supplies no nonzero certificate.

If \(\Theta\ne0\), the determinant is nonzero, but by (5.17) its prime support is recurrence-geometric rather than target-selective.

Equation (6.4) proves unconditional nonzeroness for the shortest block. For wider blocks, the repository contains no theorem excluding isolated zeros of \(\Theta_{n,D,N}\); the checker below computes \(\Theta\) exactly and treats zero as a failed certificate rather than assuming it away. This is sufficient for the route audit: either the minor is zero, or it is a target-blind Casoratian scalar.

## 9. Complete height and denominator ledger

### 9.1 Minimal primitive exterior minor

From (4.14),

\[
 \log V_{n,D,N}
 \le6\log\frac{R!}{S!}
 =6\sum_{k=S+1}^{R}\log k
 =O(N\log(n+2)).
\tag{9.1}
\]

The stronger lcm bound is

\[
 \log V_{n,D,N}
 \le\log Q_{S,R}
 \le3\psi(R)
 =O(R),
\tag{9.2}
\]

where \(\psi(R)=\log\operatorname {lcm}(1,\ldots,R)\).

A crude but rigorous transfer estimate from (4.4), (4.8) gives

\[
 \log|\Theta_{n,D,N}|
 =O(N\log(n+2))
\tag{9.3}
\]

whenever \(\Theta\ne0\): over \(N+1\) steps the integral transfer vectors grow by at most a fixed multiple of \((R+1)^6\) per step; the factorial ratios in (4.8) contribute at most \(3(N+1)\log R\); and the Newton weights contribute \(O(\log\binom{D+N}{N})=O(N\log(n+2))\).

Therefore

\[
 \log|U_{n,D,N}|=O(N\log(n+2)).
\tag{9.4}
\]

This is a genuine finite-height recurrence resultant. It is not, however, a target resultant.

### 9.2 Integralizing the companion column

Using the exact block denominator gives

\[
 Q_{S,R}\varepsilon_{n,D,N}
 =\frac{Q_{S,R}}{V_{n,D,N}}U_{n,D,N}\in\mathbb Z.
\tag{9.5}
\]

The multiplier \(Q/V\) is pure denominator-clearing content. It is a \(p\)-unit at every top-half candidate in the block and cannot restore target divisibility.

### 9.3 Retaining the raw Newton factor

The integral raw determinant obtained from the block-cleared companion column is

\[
 Q_{S,R}\Delta_{n,D,N}
 =B_{D,N}\frac{Q_{S,R}}V U.
\tag{9.6}
\]

If it is nonzero, then

\[
 \log|Q\Delta|\ge\log B_{D,N}.
\tag{9.7}
\]

Stirling gives

\[
\begin{aligned}
 \log B_{D,N}
 &=(D+N)\log(D+N)-D\log D-N\log N+O(\log n)\\
 &=N\log(D/N)+N+O(N^2/D+\log n)
 \qquad(N=o(D)).
\end{aligned}
\tag{9.8}
\]

This is the exact height/selectivity tradeoff:

- retain \(B_{D,N}\): every candidate prime appears, including every non-target;
- divide by \(B_{D,N}\): all guaranteed candidate factors disappear;
- no intermediate primitive normalization keeps precisely the targets.

### 9.4 Global lcm-clearing

Let

\[
 \mathcal L_n=\operatorname {lcm}(1,\ldots,n)^3.
\]

Scaling only the companion column by \(\mathcal L_n\) adds

\[
 \log\mathcal L_n=3\psi(n)=3n+o(n)
\tag{9.9}
\]

of target-blind content. Scaling both original columns adds twice that amount. Since every candidate prime \(p\le n\) already divides \(\mathcal L_n\), this normalization cannot be used as evidence of selective target divisibility.

The minimal normalization is (3.3)--(4.14), and under that normalization the target factor is absent.

## 10. Standalone exact checker

The following program uses only the Python standard library. It:

1. generates \(a_k,b_k\) exactly;
2. checks the Apéry recurrence and Casoratian;
3. builds the reversed adjacent Newton carriers;
4. verifies the quotient-free identity;
5. computes the exact recurrence determinant \(\Theta\);
6. verifies the factorial-denominator formula and the lcm-denominator divisibility;
7. checks the beta--Pade operator identity directly on both solutions;
8. classifies every candidate prime as universal raw content, actual target, and/or accidental primitive divisor;
9. verifies the closed shortest-block formula.

```python
#!/usr/bin/env python3
"""Exact audit for Q5805: Newton transform of the original Apery pair."""

from __future__ import annotations

from argparse import ArgumentParser
from fractions import Fraction
from math import comb, factorial, gcd, lcm, log


def P(k: int) -> int:
    return 34 * k**3 + 51 * k**2 + 27 * k + 5


def apery_pair(limit: int) -> tuple[list[Fraction], list[int]]:
    if limit < 0:
        raise ValueError("limit must be nonnegative")
    if limit == 0:
        return [Fraction(0)], [1]

    a = [Fraction(0), Fraction(6)]
    b = [1, 5]
    for k in range(1, limit):
        den = (k + 1) ** 3
        a.append((P(k) * a[k] - k**3 * a[k - 1]) / den)
        num = P(k) * b[k] - k**3 * b[k - 1]
        q, rem = divmod(num, den)
        assert rem == 0
        b.append(q)

    for k in range(limit):
        assert a[k + 1] * b[k] - a[k] * b[k + 1] == Fraction(
            6, (k + 1) ** 3
        )
    return a, b


def weight(d: int, length: int, i: int) -> int:
    return (
        (-1) ** i
        * comb(d + i, i)
        * comb(d + length + 1, length - i)
    )


def g_rev(seq, n: int, d: int, length: int):
    return sum(
        weight(d, length, i) * seq[n - (d + i) - 1]
        for i in range(length + 1)
    )


def h_rev(seq, n: int, D: int, N: int):
    # This is H_{D-1,N} on x_d=seq[n-d-1].
    R = n - D
    return sum(
        (-1) ** i * comb(N + 1, i) * seq[R - i]
        for i in range(N + 2)
    )


def is_prime(value: int) -> bool:
    if value < 2:
        return False
    if value % 2 == 0:
        return value == 2
    d = 3
    while d * d <= value:
        if value % d == 0:
            return False
        d += 2
    return True


def vp(value: int, prime: int) -> int:
    if value == 0:
        raise ValueError("vp(0) is not used in this audit")
    value = abs(value)
    out = 0
    while value % prime == 0:
        value //= prime
        out += 1
    return out


def vp_fraction(value: Fraction, prime: int) -> int:
    if value == 0:
        raise ValueError("valuation of zero is not finite")
    return vp(value.numerator, prime) - vp(value.denominator, prime)


def mod_fraction(value: Fraction, prime: int) -> int:
    den = value.denominator % prime
    assert den != 0
    return value.numerator % prime * pow(den, -1, prime) % prime


def block_denominator(a: list[Fraction], S: int, R: int) -> int:
    out = 1
    for k in range(S, R + 1):
        out = lcm(out, a[k].denominator)
    return out


def lcm_prefix(limit: int) -> int:
    out = 1
    for k in range(1, limit + 1):
        out = lcm(out, k)
    return out


def transfer_vectors(S: int, R: int) -> dict[int, tuple[int, int]]:
    """Integral transfer for X_k=(k!)^3 f_k."""
    assert 0 <= S < R
    c: dict[int, tuple[int, int]] = {
        S: (1, 0),
        S + 1: (0, 1),
    }
    for k in range(S + 1, R):
        u0, u1 = c[k - 1], c[k]
        c[k + 1] = (
            P(k) * u1[0] - k**6 * u0[0],
            P(k) * u1[1] - k**6 * u0[1],
        )
    return c


def scaled_theta(n: int, D: int, N: int) -> tuple[int, int, int, int]:
    R = n - D
    S = R - N - 1
    assert S >= 0
    c = transfer_vectors(S, R)
    fact_R = factorial(R)

    g0 = g1 = 0
    for i in range(N + 1):
        k = R - i
        scale = (fact_R // factorial(k)) ** 3
        w = weight(D - 1, N, i)
        g0 += w * scale * c[k][0]
        g1 += w * scale * c[k][1]

    h0 = h1 = 0
    for i in range(N + 2):
        k = R - i
        scale = (fact_R // factorial(k)) ** 3
        w = (-1) ** i * comb(N + 1, i)
        h0 += w * scale * c[k][0]
        h1 += w * scale * c[k][1]

    theta = g0 * h1 - g1 * h0
    factorial_denominator = (fact_R // factorial(S)) ** 6
    return theta, factorial_denominator, S, R


def state_vectors(
    r: int, S: int, R: int
) -> dict[int, tuple[Fraction, Fraction]]:
    """Write f_k=u_k f_r+v_k f_{r+1} exactly."""
    assert S <= r < R
    c: dict[int, tuple[Fraction, Fraction]] = {
        r: (Fraction(1), Fraction(0)),
        r + 1: (Fraction(0), Fraction(1)),
    }

    for k in range(r + 1, R):
        prev = c[k - 1]
        cur = c[k]
        den = (k + 1) ** 3
        c[k + 1] = (
            Fraction(P(k) * cur[0] - k**3 * prev[0], den),
            Fraction(P(k) * cur[1] - k**3 * prev[1], den),
        )

    for k in range(r, S, -1):
        cur = c[k]
        nxt = c[k + 1]
        den = k**3
        c[k - 1] = (
            Fraction(P(k) * cur[0] - (k + 1) ** 3 * nxt[0], den),
            Fraction(P(k) * cur[1] - (k + 1) ** 3 * nxt[1], den),
        )
    return c


def local_rows(
    n: int, D: int, N: int, r: int
) -> tuple[tuple[Fraction, Fraction], tuple[Fraction, Fraction]]:
    R = n - D
    S = R - N - 1
    c = state_vectors(r, S, R)

    g0 = g1 = Fraction(0)
    for i in range(N + 1):
        k = R - i
        w = weight(D - 1, N, i)
        g0 += w * c[k][0]
        g1 += w * c[k][1]

    h0 = h1 = Fraction(0)
    for i in range(N + 2):
        k = R - i
        w = (-1) ** i * comb(N + 1, i)
        h0 += w * c[k][0]
        h1 += w * c[k][1]
    return (g0, g1), (h0, h1)


# Minimal polynomial arithmetic for the beta--Pade identity.
Poly = dict[int, int]


def poly_add(left: Poly, right: Poly) -> Poly:
    out = dict(left)
    for k, value in right.items():
        out[k] = out.get(k, 0) + value
        if out[k] == 0:
            del out[k]
    return out


def poly_scale(poly: Poly, scalar: int) -> Poly:
    return {k: scalar * value for k, value in poly.items() if scalar * value}


def poly_shift(poly: Poly, shift: int) -> Poly:
    return {k + shift: value for k, value in poly.items()}


def poly_mul(left: Poly, right: Poly) -> Poly:
    out: Poly = {}
    for i, a in left.items():
        for j, b in right.items():
            out[i + j] = out.get(i + j, 0) + a * b
    return {k: value for k, value in out.items() if value}


def one_minus_power(power: int) -> Poly:
    return {i: (-1) ** i * comb(power, i) for i in range(power + 1)}


def q_poly(D: int, N: int) -> Poly:
    return {
        i: (-1) ** i * comb(D - 1 + i, i) * comb(D + N, N - i)
        for i in range(N + 1)
    }


def r_poly(D: int, N: int) -> Poly:
    out: Poly = {}
    for j in range(D):
        term = poly_shift(one_minus_power(D - 1 - j), j)
        out = poly_add(out, poly_scale(term, comb(D + N, j)))
    return out


def apply_poly(poly: Poly, seq, n: int, base_d: int):
    return sum(
        coeff * seq[n - (base_d + exponent) - 1]
        for exponent, coeff in poly.items()
    )


def beta_identity_check(seq, n: int, D: int, N: int) -> None:
    q = q_poly(D, N)
    rr = r_poly(D, N)
    bezout = poly_add(
        poly_shift(q, D),
        poly_mul(one_minus_power(N + 1), rr),
    )
    assert bezout == {0: 1}

    carrier = apply_poly(poly_shift(q, D), seq, n, -1)
    boundary = apply_poly(
        poly_mul(one_minus_power(N + 1), rr), seq, n, -1
    )
    assert carrier + boundary == seq[n]


def log_int(value: int) -> float:
    value = abs(value)
    if value <= 1:
        return 0.0
    # Avoid float overflow for large exact integers.
    shift = max(0, value.bit_length() - 53)
    return log(value >> shift) + shift * log(2.0)


def audit_block(n: int, D: int, N: int, verbose: bool = True) -> dict:
    R = n - D
    S = R - N - 1
    assert N >= 1 and D > N and S >= 0

    a, b = apery_pair(n)
    B = comb(D + N, N)

    ga_minus = g_rev(a, n, D - 1, N)
    ga_plus = g_rev(a, n, D, N)
    gb_minus = g_rev(b, n, D - 1, N)
    gb_plus = g_rev(b, n, D, N)
    ha = h_rev(a, n, D, N)
    hb = h_rev(b, n, D, N)

    raw = ga_minus * gb_plus - ga_plus * gb_minus
    epsilon = ha * gb_minus - ga_minus * hb
    assert raw == B * epsilon

    theta, factorial_den, S2, R2 = scaled_theta(n, D, N)
    assert (S2, R2) == (S, R)
    assert epsilon == Fraction(6 * theta, factorial_den)

    U = epsilon.numerator
    V = epsilon.denominator
    if theta == 0:
        assert U == 0
    else:
        c = gcd(abs(6 * theta), factorial_den)
        assert U == 6 * theta // c
        assert V == factorial_den // c

    Q = block_denominator(a, S, R)
    assert (Q * epsilon).denominator == 1
    assert Q % V == 0

    LR = lcm_prefix(R)
    assert (LR**3) % Q == 0
    for k in range(S, R + 1):
        assert (lcm_prefix(k) ** 3) % a[k].denominator == 0

    beta_identity_check(a, n, D, N)
    beta_identity_check(b, n, D, N)
    beta_identity_check(a, n, D + 1, N)
    beta_identity_check(b, n, D + 1, N)

    targets = []
    primitive_candidate_primes = []
    target_lost_after_primitive_division = []
    accidental_target_retained = []

    for p in range(D + 1, D + N + 1):
        if not is_prime(p):
            continue
        if not (p > n // 2 and p > N):
            continue

        r = n - p
        assert S < r < R
        assert p > R
        assert vp(B, p) == 1
        assert Q % p != 0 and V % p != 0 and factorial_den % p != 0

        # Common-node selector for both adjacent rows.
        assert mod_fraction(ga_minus, p) == mod_fraction(a[r], p)
        assert mod_fraction(ga_plus, p) == mod_fraction(a[r], p)
        assert gb_minus % p == b[r] % p
        assert gb_plus % p == b[r] % p

        # Local remainder determinant.
        grow, hrow = local_rows(n, D, N, r)
        g0, g1 = grow
        h0, h1 = hrow
        theta_local = h1 * g0 - h0 * g1
        assert epsilon == Fraction(6, (r + 1) ** 3) * theta_local
        assert mod_fraction(g0, p) == 1
        assert mod_fraction(g1, p) == 0
        assert mod_fraction(epsilon, p) == (
            6 * mod_fraction(h1, p) * pow((r + 1) ** 3, -1, p)
        ) % p

        # The primitive criterion is recurrence-only.
        assert (U % p == 0) == (theta % p == 0)
        primitive_candidate_primes.append((p, r, U % p == 0))

        if b[r] % p == 0:
            targets.append((p, r))
            assert b[r + 1] % p != 0
            assert mod_fraction(a[r], p) != 0

            if theta % p == 0:
                accidental_target_retained.append((p, r))
            else:
                target_lost_after_primitive_division.append((p, r))
                assert U % p != 0
                assert vp_fraction(raw, p) == 1

    if verbose:
        print("BLOCK", (n, D, N), "S,R", (S, R))
        print("THETA_ZERO", theta == 0)
        print("TARGETS", targets)
        print("ACCIDENTAL_TARGET_RETAINED", accidental_target_retained)
        print("TARGET_LOST_AFTER_PRIMITIVE_DIVISION", target_lost_after_primitive_division)
        print("PRIMITIVE_CANDIDATE_PRIMES", primitive_candidate_primes)
        print("LOG_FACTORIAL_DEN", log_int(factorial_den))
        print("LOG_REDUCED_DEN", log_int(V))
        print("LOG_BLOCK_LCM_DEN", log_int(Q))
        print("LOG_BINOMIAL_NODE_FACTOR", log_int(B))
        print("LOG_PRIMITIVE_NUMERATOR", log_int(U))

    return {
        "epsilon": epsilon,
        "theta": theta,
        "U": U,
        "V": V,
        "Q": Q,
        "targets": targets,
        "accidental": accidental_target_retained,
        "lost": target_lost_after_primitive_division,
    }


def audit_shortest(n: int, p: int) -> None:
    assert is_prime(p) and p > n // 2
    r = n - p
    assert r >= 1
    result = audit_block(n, p - 1, 1, verbose=False)
    poly = (
        32 * p * r**3
        + (48 * p + 3) * r**2
        + (24 * p + 3) * r
        + 4 * p
        + 1
    )
    expected = Fraction(-6 * poly, r**3 * (r + 1) ** 3)
    assert result["epsilon"] == expected
    assert result["theta"] != 0
    assert (result["U"] % p == 0) == ((3 * r * r + 3 * r + 1) % p == 0)
    print("SHORTEST_PASS", (n, p, r), expected)


def small_self_test() -> None:
    checks = 0
    for n in range(8, 61):
        for p in range(n // 2 + 1, n):
            if not is_prime(p):
                continue
            r = n - p
            if r < 1:
                continue
            audit_shortest(n, p)
            checks += 1
    print("SMALL_SHORTEST_CHECKS", checks)
```

## 11. Final conclusion

The transformed determinant has a complete exact description:

\[
 \frac{G_a^-G_b^+-G_a^+G_b^-}{\binom{D+N}{N}}
 =\frac{6\Theta_{n,D,N}}
        {\left((n-D)!/(n-D-N-1)!\right)^6}.
\]

This is a recurrence-only change-of-basis determinant. It is potentially small after factorial cancellation, and for \(N=1\) it is an explicit low-degree rational function. But its moving-prime divisibility is not the Apéry target condition.

At a target, the companion marked value is a unit, so the raw exterior determinant has exactly the universal node factor unless the recurrence-only scalar vanishes accidentally. Primitive normalization deletes the universal factor and leaves no guaranteed target prime. The common beta--Pade endpoint \((a_n,b_n)\) cancels into the same universal difference row; using its lcm-cleared integrality merely restores linear-height presentation content.

Therefore applying the Newton/beta--Pade transform directly to the two original Apéry recurrence solutions is rigorously the previously closed Casoratian defect in disguise. The small gcd phenomenon for the Laurent-shell pair relies on two distinguished target-vanishing columns; it does not transfer to the original fundamental pair.
