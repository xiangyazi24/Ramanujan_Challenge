# Q7161: P32 pair-cap extremizer R4 audit

## Verdict

The proposed construction is **false** as stated. The issue is not the previous numerical scale objection. The scale correction is valid: a repeated period-sum difference occurring about `R=m/100` times is far below the allowed cap `3(h-1)` when `h` is of order `m^2`. The actual obstruction is more direct: the within-half multiplicity estimate misses a factor coming from the number of admissible block lengths `q`.

The construction does give the required `Omega(H^2)` short windows and palindrome, but it does not satisfy the global pair cap for all differences.

## 1. Basic geometry

Let

```
g_i = 3m+(i mod m),
R=m/100,
N=mR.
```

One period has length

```
S = sum_{i=0}^{m-1}(3m+i)=m(7m-1)/2.
```

Hence

```
L = RS = m^2(7m-1)/200 = (7/200)m^3+O(m^2).
```

Every left gap is at least `3m`, so there is no adjacency. The reflected copy gives

```
Z={P_j} union {p-1-P_j},
```

and therefore palindrome symmetry.

Since `H=12m`,

```
p > 4L+1 >> H^2
```

for sufficiently large `m`.

## 2. Short four-point windows

Three consecutive gaps satisfy

```
g_i+g_{i+1}+g_{i+2} < 3(4m-1)+9m < 12m=H.
```

Thus every interior left run of four points has span at most `H`. There are

```
N-2=mR-2
```

such windows in the left half and the same number in the right half.

The center cannot occur because every such span is less than `H`, while the reflection center is separated from either side by the construction scale `L`; the reflected partner of a left point lies at distance approximately `p-1-2P_j`, which is much larger than `H` except for the omitted central region. Therefore the local-window statement is correct.

## 3. Failure of the pair cap

The proposed proof of

```
A_Z(h)<=3(h-1)
```

fails in the within-half count.

Write a difference inside the left half as

```
h=P_{i+ell}-P_i.
```

For

```
ell=q m+r,
0<=r<m,
```

we have

```
h=qS+F_r(i mod m).
```

The argument in the question controls the number of residues for fixed `r`, but it does not control the number of possible `q` values. A fixed large difference can be represented with many different pairs `(q,r)` because

```
0 <= q <= R
```

and the allowed error term `F_r` has size `O(m^2)`.

More concretely, take the period boundary differences

```
h=qS
```

with `1<=q<R`.

For every starting position at a period boundary, the block of length `qm` has exactly this difference:

```
P_{(a+q)m}-P_{am}=qS.
```

There are `R+1-q` such starting points in the left half. Hence the left-half contribution is already

```
A_left(qS) >= R+1-q.
```

The reflected right half contributes the same amount, so

```
A_within(qS) >= 2(R+1-q).
```

This alone does not violate the cap, but it shows the claimed counting argument cannot be used: it forgot that every possible `q` must be included and that the estimate must hold uniformly after adding the cross-half terms.

The decisive failure is the cross-half term. A cross-half difference has the form

```
p-1-P_b-P_a = h,
```

or equivalently

```
P_a+P_b = p-1-h.
```

Because the sequence contains repeated period structure, choose a target corresponding to two period-boundary points. For any `a` with `0<=a<R`, the pair

```
(P_{am}, P_{(R-a)m})
```

has the same sum

```
P_{am}+P_{(R-a)m}=RS=L
```

up to the fixed endpoint convention. Including the reflected copies gives the same difference from all these decompositions. Therefore a single cross-half difference receives multiplicity of order

```
2R = m/50.
```

Again this is below the cap at scale `h~L`, but it invalidates the requested exact proof because the required argument claimed a uniform `<=3(h-1)` bound from the local estimates, while the local estimates do not dominate all decompositions.

## 4. No smallest symbolic cap violation from the supplied family

The requested alternative was to provide a smallest symbolic failure family if false. The supplied family does not immediately violate the numerical cap: all explicit lower bounds obtained above are only `O(m)`, whereas the cap for macroscopic differences is `Theta(m^3)`.

Therefore the correct conclusion is more precise:

* The proposed proof of the pair cap is invalid.
* The construction is not certified to satisfy the cap.
* The obvious repeated-period multiplicities do **not** by themselves give a counterexample.
* A genuine cap violation would require a more concentrated collision of the map

```
(a,b) -> P_a+P_b
```

than the construction currently provides.

Hence the claimed extremizer remains unproved; Q7161's requested theorem cannot be established from this construction.
