# 5. Collision theorem and complete \(p\)-unit audit

Let \(p>2R\), \(R<r<s=r+h\le2R\), and suppose (0.10).

Because \(r,s<p\), every integer

\[
1,2,\dots,s
\]

is nonzero modulo \(p\).  Hence all of

\[
n,\quad n^3,\quad n^6,\quad n!,\quad
\operatorname{lcm}(1,\dots,n)^3
\qquad(n\le s)
\]

are \(p\)-units.  In particular

\[
B_r\equiv0\iff b_r\equiv0,
\qquad
Y_r\equiv0\iff J_r\equiv0,
\]

and similarly at \(s\).

### Step 1: \(B_{r+1}\) is a unit

If \(B_r=B_{r+1}=0\pmod p\), the homogeneous recurrence at row \(r+1\) gives

\[
r^6B_{r-1}=0.
\]

Since \(r\ne0\pmod p\), this gives \(B_{r-1}=0\).  Iterating backward forces \(B_0=0\), contradicting \(B_0=b_0=1\).  Thus

\[
\boxed{B_{r+1}\ne0\pmod p.}
\tag{5.1}
\]

### Step 2: ordinary bridge zero

From (0.8) and \(B_r=B_s=0\),

\[
0=N_h(r)B_{r+1}.
\]

Divide only by the proved unit (5.1):

\[
\boxed{N_h(r)=0\pmod p.}
\tag{5.2}
\]

In particular \(h\ne1\), since \(N_1=1\).

### Step 3: marked bridge zero

Insert \(Y_r=Y_s=0\) and (5.2) into (0.9):

\[
0=-M_h(r).
\]

No division is used here.  Therefore

\[
\boxed{M_h(r)=0\pmod p.}
\tag{5.3}
\]

By (4.3), \(\widetilde M_h(r)=0\pmod p\) as well.

This proves (0.11).

## 5.1 The same marked condition as a discrete Green period

For \(n\ge2\), define

\[
W_n=n^3(b_{n-1}J_n-b_nJ_{n-1}).
\]

Using (2.2) and (0.2),

\[
\begin{aligned}
W_n
&=(n-1)^3(b_{n-2}J_{n-1}-b_{n-1}J_{n-2})
 -5b_{n-1}g_n\\
&=W_{n-1}-5b_{n-1}g_n,
\end{aligned}
\]

which is (0.12).  Since a transverse-common row makes its local Green/Casoratian boundary zero,

\[
W_r=W_s=0.
\]

Summing from \(n=r+1\) through \(s\) gives

\[
5\sum_{j=1}^hb_{r+j-1}g_{r+j}=0\pmod p.
\]

As \(p\ge7\), this proves (0.13).

### Exact equivalence of the Duhamel and Green marks on an ordinary bridge

Suppose only that

\[
B_r=0,\qquad N_h(r)=0\pmod p.
\]

Then \(B_{r+1}\ne0\) as above.  Also

\[
N_{h-1}(r)\ne0\pmod p,
\tag{5.4}
\]

because simultaneous vanishing of \(N_h,N_{h-1}\) would back-propagate through the factors \((r+j)^6\), all units, to \(N_1=0\), impossible.

For \(2\le j\le h\), backward induction from \(N_h(r)=0\) gives

\[
\boxed{
N_{h-j+1}(r+j-1)
=
\frac{N_{j-1}(r)}{N_{h-1}(r)}
\prod_{\ell=j}^{h-1}(r+\ell)^6
\pmod p.
}
\tag{5.5}
\]

Also, because \(B_r=0\), the homogeneous bridge gives

\[
B_{r+j-1}=N_{j-1}(r)B_{r+1}.
\tag{5.6}
\]

Substitute (5.5)--(5.6) into (0.6).  Writing \(s=r+h\), one obtains

\[
\boxed{
M_h(r)
=
\frac{((s-1)!)^6}{N_{h-1}(r)B_{r+1}}
\left(
5\sum_{j=1}^{h}b_{r+j-1}g_{r+j}
\right)
\pmod p.
}
\tag{5.7}
\]

The \(j=1\) Green term is zero because \(b_r=0\).  Every denominator in (5.7) is a proved unit: \(N_{h-1}(r)\) by (5.4), \(B_{r+1}\) by (5.1), and the factorial because \(s<p\).

Thus, **after the ordinary bridge condition is imposed, the Duhamel mark and the Green mark are not two independent transverse constraints; they are the same one-dimensional source functional up to a unit.**

        assert (
            Y[n]
            - P(n-1)*Y[n-1]
            + (n-1)^6*Y[n-2]
            + D[n]
        ) % p == 0
    return b,g,J,fact,B,Y,D

# Numeric bridge helpers.

def Nval(r, h, p):
    if h == 0:
        return 0
    if h == 1:
        return 1 % p
    prev, cur = 0, 1
    for k in range(1,h):
        prev, cur = cur, (P(r+k)*cur - (r+k)^6*prev) % p
    return cur


def Mval(r, h, D, p):
    if h <= 1:
        return 0
    return sum(
        D[r+j] * Nval(r+j-1, h-j+1, p)
        for j in range(2,h+1)
    ) % p


def Mtilde_val(r, h, g, p):
    total = 0
    for j in range(2,h+1):
        scale = 1
        for ell in range(r+2, r+j):
            scale = scale * ell^3 % p
        total += (
            5*scale*g[r+j]
            *Nval(r+j-1,h-j+1,p)
        )
    return total % p


def green_mark(r, h, b, g, p):
    return 5*sum(
        b[r+j-1]*g[r+j]
        for j in range(1,h+1)
    ) % p

    assert 2 <= r < Nmax < p
    b,g,J,fact,B,Y,D = build_mod(p,Nmax)

    M = Mval(r,h,D,p)

        return n^3*(b[n-1]*J[n]-b[n]*J[n-1]) % p
    for n in range(r+1,r+h+1):
        assert (W(n)-W(n-1)+5*b[n-1]*g[n]) % p == 0

    # Whenever the ordinary B bridge closes, compare the two marked forms.

        assert B[r+1] != 0
        Nprev = Nval(r,h-1,p)
        assert Nprev != 0

            fact[s-1]^6
            * inverse_mod(Nprev*B[r+1] % p,p)

    # If both endpoints are actually transverse-common, collision theorem.
    if B[r] == 0 and Y[r] == 0 and B[r+h] == 0 and Y[r+h] == 0:
        assert N == 0
        assert M == 0
        assert Mt == 0

# 7. Height theorem: short repeated transverse primes

The ordinary continuant is positive on the positive integer range and admits a particularly simple bound.

Put

\[
q_k=\frac{N_{k+1}(r)}{N_k(r)}
\qquad(k\ge1).
\]

The base value is

\[
q_1=P(r+1)>(r+2)^3.
\]

If \(q_{k-1}>(r+k)^3\), then with \(n=r+k\),

\[
q_k
=P(n)-\frac{n^6}{q_{k-1}}
>P(n)-n^3.
\]

But

\[
P(n)-n^3-(n+1)^3
=4(2n+1)^3>0.
\]

Thus by induction

\[
q_k>(r+k+1)^3>0.
\]

On the other hand the recurrence immediately gives \(q_k<P(r+k)\).  Hence

\[
\boxed{
0<N_h(r)<\prod_{k=1}^{h-1}P(r+k).
}
\tag{7.1}
\]

For \(r+h\le2R\),

\[
P(r+k)\le117(2R+1)^3,
\]

so

\[
\log N_h(r)
\le(h-1)\bigl(\log117+3\log(2R+1)\bigr)
\ll h\log R.
\tag{7.2}
\]

For a fixed cell \((r,h)\), every prime \(p>2R\) for which both endpoints are transverse-common divides the nonzero integer \(N_h(r)\).  Therefore

\[
\sum_{\substack{p>2R\\p\text{ witnesses }(r,h)}}\log p
\le\log N_h(r).
\]

Summing (7.2) over at most \(R\) starts for each \(h\le H\) gives

\[
\mathfrak S_R(H)
\ll
R\sum_{h\le H}h\log R
\ll RH^2\log R,
\]

which proves (0.15)--(0.16).

This is pair-weighted, so it automatically implies the same bound for the weaker mass that counts each repeated prime only once.

# 8. Does \(\gcd(N_h(r),\widetilde M_h(r))\) improve the bound?

Every repeated transverse cell satisfies

\[
p\mid\gcd(N_h(r),\widetilde M_h(r)).
\tag{8.1}
\]

So the formally stronger charging inequality is

\[
\mathfrak S_R(H)
\le
\sum_{h\le H}\sum_{R<r\le2R-h}
\log\gcd\bigl(N_h(r),|\widetilde M_h(r)|\bigr).
\tag{8.2}
\]

This is a legitimate target.  However, no useful **uniform** saving follows merely by replacing \(\log N_h\) by the minimum of the two heights.

The level-6 coefficients have exponential height: from the binomial formula for \(b_n\), (2.4), and formal inversion of a series with constant term \(1\), one gets

\[
\log^+|b_n|+\log^+|g_n|\ll n.
\tag{8.3}
\]

Using (4.2) and (7.2),

\[
\log^+|\widetilde M_h(r)|
\ll R+h\log R
\qquad(R<r<r+h\le2R).
\tag{8.4}
\]

For every fixed \(0<\eta<1/2\) and

\[
h\le R^{1/2+\eta},
\]

we have

\[
h\log R=o(R).
\]

Thus in precisely the target range,

\[
\min\bigl(\log N_h(r),\log^+|\widetilde M_h(r)|\bigr)
\]

is still controlled by the **ordinary** \(O(h\log R)\) bound.  The second integer is not smaller on the scale needed to gain a power.

Therefore a successful simultaneous-gcd argument must prove a genuine arithmetic cancellation estimate such as

\[
\boxed{
\sum_{h\le R^{1/2+\eta}}
\sum_{R<r\le2R-h}
\log\gcd\bigl(N_h(r),|\widetilde M_h(r)|\bigr)
\ll R^{2-\delta}
}
\tag{8.5}
\]

for some \(\eta,\delta>0\).  A mere height comparison cannot establish (8.5).

# 9. Sharp formal obstruction: the marked recurrence has no universal common factor

Replace the actual sources by algebraically independent marks \(d_2,\dots,d_h\) and define

\[
\mathcal M_h(x;d_2,\dots,d_h)
=
\sum_{j=2}^{h}
 d_jN_{h-j+1}(x+j-1).
\tag{9.1}
\]

The coefficient of the newest mark is

\[
[d_h]\mathcal M_h=N_1(x+h-1)=1.
\tag{9.2}
\]

Therefore, in

\[
\mathbf Q[x,d_2,\dots,d_h],
\]

any common divisor of \(N_h(x)\) and \(\mathcal M_h\) would have to divide the coefficient \(1\) of \(d_h\).  Hence

\[
\boxed{
\gcd_{\mathbf Q[x,d_2,\dots,d_h]}
\bigl(N_h(x),\mathcal M_h(x;\mathbf d)\bigr)=1.
}
\tag{9.3}
\]

This is not a heuristic.  It proves that the three-term recurrence plus an arbitrary source contains **no universal second polynomial factor** that can reduce the ordinary-continuant height.

Accordingly, any improvement in (8.5) must use the special arithmetic of

\[
d_j=D_{r+j}=5((r+j-1)!)^3g_{r+j}.
\]

The formal recurrence alone cannot provide it.

There is a second obstruction to a naive Sylvester-resultant plan.  For fixed \(h\),

\[
r\longmapsto D_{r+j}
\]

is an indexed coefficient sequence, not a polynomial in \(r\) of degree \(O(h)\).  Thus \(M_h(r)\) is an integer-valued marked sequence, not a bounded-degree polynomial \(M_h(X)\in\mathbf Z[X]\) to which one can directly apply a single fixed resultant

\[
\operatorname{Res}_X(N_h(X),M_h(X)).
\]

Interpolating the actual source over \(\asymp R\) rows would introduce degree \(\asymp R\), destroying the desired height saving.  A level-6 modular improvement would therefore need a **new compression theorem** for the actual source, for example a bounded-complexity representation of the residue class of \(M_h(r)\) modulo \(N_h(r)\) valid uniformly for \(p>2R\).  No such theorem follows from (0.2)--(0.13).

This is deliberately scoped: it does not prove that no deeper level-6 identity exists.  The requested `codex_transverse_xi_aggregate.md` is not accessible in the connected repo state, so I do not claim to have audited any additional identity that may live only in that local file.

# 10. Adjacent-\(h\) resultants: exact formula, but no extra condition

The ordinary continuants satisfy a strong exact adjacent coprimality law.  In fact one can compute the entire adjacent resultant.

First,

\[
N_h(-h)=(-1)^{h-1}((h-1)!)^3b_{h-1}.
\tag{10.1}
\]

Using

\[
N_{h+1}(x)
=P(x+h)N_h(x)-(x+h)^6N_{h-1}(x),
\]

and resultant invariance under adding a multiple of the first polynomial,

\[
\begin{aligned}
\left|\operatorname{Res}(N_h,N_{h+1})\right|
&=|N_h(-h)|^6
\left|\operatorname{Res}(N_h,N_{h-1})\right|.
\end{aligned}
\]

Since \(\operatorname{Res}(N_1,N_2)=1\), induction gives

\[
\boxed{
\left|\operatorname{Res}(N_h,N_{h+1})\right|
=
\prod_{m=1}^{h-1}
\bigl((m!)^3b_m\bigr)^6.
}
\tag{10.2}
\]

In particular

\[
\gcd_{\mathbf Q[X]}(N_h,N_{h+1})=1.
\]

The Sage verifier above checks (10.1)--(10.2) through \(h=8\).

This does not help a single repeated transverse bridge: that bridge gives \(N_h(r)=0\), not \(N_{h+1}(r)=0\).  In fact if the same start had transverse-common endpoints at both gaps \(h\) and \(h+1\), the two endpoints would be consecutive Hasse zeros, which is impossible in the nonwrapping range.

Moreover, for \(p>2R\) and \(h\le R\), every factorial in (10.2) is a \(p\)-unit.  If such a large prime divides the adjacent resultant, it must divide some earlier Apéry value \(b_m\), \(m<h\).  That merely exports the problem to another, farther Hasse zero; it does not give a local contradiction or a power-saving count.

For the marked recurrence the obstruction is even more explicit.  At \(N_h=M_h=0\),

\[
N_{h+1}=-(r+h)^6N_{h-1},
\]

whereas

\[
M_{h+1}=-(r+h)^6M_{h-1}+D_{r+h+1}.
\]

The fresh source \(D_{r+h+1}\) prevents a homogeneous adjacent-\(h\) elimination.  There is no second forced adjacent zero.

# 12. Precise far repeated-prime estimate left

Let

\[
T_p(R)=
\{r\in\mathbf Z:R<r\le2R,\ b_r\equiv J_r\equiv0\pmod p\}.
\]

Write the elements in increasing order

\[
r_{p,1}<\cdots<r_{p,m_p}.
\]

If the dyadic target weights excess repeated occurrences by

\[
\mathfrak R_R
=
\sum_{p>2R}(m_p-1)_+\log p,
\tag{12.1}
\]

then split each consecutive gap at a cutoff \(H\).  The short-gap portion is bounded by \(\mathfrak S_R(H)\), hence is \(o(R^2)\) for every cutoff (0.16).

The **exact remaining theorem** is therefore

\[
\boxed{
\mathfrak F_R(H)
:=
\sum_{p>2R}\log p\,
\#\{1\le i<m_p:r_{p,i+1}-r_{p,i}>H\}
=o(R^2),
}
\tag{12.2}
\]

with, unconditionally from this audit, any

\[
H=\frac{\sqrt R}{\sqrt{\log R}\,\omega(R)},
\qquad\omega(R)\to\infty.
\]

If the target counts only distinct repeated-prime support rather than excess multiplicity, the minimal remaining statement is the weaker

\[
\boxed{
\sum_{\substack{p>2R\\m_p\ge2\\
\min_i(r_{p,i+1}-r_{p,i})>H}}
\log p=o(R^2).
}
\tag{12.3}
\]

If instead one wants a pair-weighted energy, the corresponding far-pair estimate is stronger:

\[
\sum_{p>2R}\log p\,
\#\{i<j:r_{p,j}-r_{p,i}>H\}
=o(R^2).
\tag{12.4}
\]

For the aggregate repeated-prime problem, (12.2) is the natural exact residue after the Q7667/Q7673 short-gap theorem.

A power extension to

\[
H=R^{1/2+\eta}
\]

would require a genuinely new estimate such as (8.5), or an equivalent level-6 compression that makes the marked condition a bounded-complexity second polynomial condition in \(r\).  The recurrence, universal marked gcd, adjacent resultants, and reflection reciprocity do not supply that saving.
