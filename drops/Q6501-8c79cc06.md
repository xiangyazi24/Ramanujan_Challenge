# Verdict

The Q6045 Stein/moment route is not the minimal route and, as stated, is not a complete proof. The final P2.2 theorem does not need the strongest form claimed there. The correct target is the exact `RivoalHarmonicConcentrationClaim22`, which only requires concentration of the weighted harmonic observable; it does not require a full Gaussian limit law.

The main issue in Q6045 is the jump from saddle-point information about an unweighted binomial model to the required weighted harmonic sum. Formulas (17)--(22) contain the right heuristic scale, but the following implications are not justified without an additional uniform error theorem:

* saddle location for the distribution of `k` does not automatically give concentration of `H_k + H_{n-k}`;
* the weighted observable has logarithmic derivatives near the endpoints;
* the constants in the claimed exponential tail are not enough to close the Lean theorem unless every truncation error is explicit.

Therefore Q6045 is a useful heuristic guide, not the minimal formal proof.

# Endpoint audit

The boundary cases are harmless if definitions are totalized explicitly.

For `k = 0`:

```text
H_k = 0
H_{n-k}=H_n
```

For `k=n`:

```text
H_k=H_n
H_{n-k}=0
```

They are exponentially suppressed by

```text
choose n 0 = choose n n = 1
```

against the total mass `2^n`.

The proof must not use a derivative estimate containing `1/k` or `1/(n-k)` without splitting off these endpoints.

# Relation to Lean totalization

The harmonic definitions already make the endpoint cases definitional. The missing lemmas should be stated with explicit bounds rather than hidden positivity assumptions.

Recommended theorem shapes:

```lean

    {a b : ℕ} (hab : a ≤ b) :
    harmonicNumber b - harmonicNumber a ≤
      (b-a : ℝ) / (a+1)
```

```lean
lemma binomial_expectation_center22 :
    ∑ k in Finset.range (n+1),
```

```lean
    ∑ k in Finset.range (n+1),
```

These are substantially easier to formalize than Stein bounds.

4. Constants in the moment estimates were not tied to the exact Lean normalization.
