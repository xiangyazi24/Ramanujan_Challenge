# Q1074 audit: odd-prime valuation identity for the full Pade carrier

## 1. Status of the proposed identity

The statement

```text
v_p(D_n)=v_p(Gamma_n)  (p>=5)
```

is not a consequence of

```text
gcd(D_n,Gamma_n)=gcd(D_n,b_n)=gcd(Gamma_n,b_n).
```

The gcd triangle only controls the common divisor with `b_n`; it does not identify the two minima

```text
min_j(v_p(L_j)+v_p(b_n-b_j))

and

min_j(v_p(L_j)+v_p(b_j)).
```

The missing input is a local statement about the indices where the cardinal coefficient has small p-adic valuation.

No counterexample was found in the checked range, but the available arguments do not prove the identity for all odd primes.

## 2. Exact valuation reduction

For every prime p,

```text
v_p(D_n)=min_{0<=j<M}(v_p(L_j(n))+v_p(b_n-b_j)),
v_p(Gamma_n)=min_{0<=j<M}(v_p(L_j(n))+v_p(b_j)).
```

Therefore equality would follow from the following stronger local lemma.

**Missing local residue lemma.** For every `p>=5`, `e>=1`, and every `n`, if

```text
v_p(L_j(n)) < e
```

for all indices contributing to the minimum, then the set of such indices contains a `j` satisfying

```text
v_p(b_j)=v_p(b_n-b_j)=min_j(v_p(L_j)+v_p(b_j))-v_p(L_j).
```

Equivalently, the low-cardinality-valuation strata must contain an Apéry residue representative matching the valuation of `b_n`.

This statement is not currently proved by Apéry--Lucas alone.

## 3. What Apéry--Lucas gives and what it does not give

Apéry--Lucas gives

```text
b_m mod p = product over base-p digits d_i of b_{d_i} mod p.
```

Together with Kummer,

```text
v_p(C(a,b)) = number of carries in b+(a-b),
```

it describes the set

```text
{j : v_p(L_j)=0}
```

through the two carry-free conditions

```text
C(n,j) != 0 mod p,
C(n-j-1,M-1-j) != 0 mod p.
```

However, this only gives information about which indices are available. It does not force the available indices to contain the required Apéry residue classes.

## 4. Case analysis

### Case p > n

This case is irrelevant for odd-prime equality because the cardinal coefficients have no p contribution and the known support results exclude new primes above n.

### Case n/2 < p <= n

The top-half geometry is the easiest case. The unique top-half condition gives the known equivalence with `p|b_(n-p)` for the difference carrier. Since `p` cannot divide the Apéry values in the same way for all low indices without additional residue control, this does not automatically imply the Gamma valuation.

### Case p <= n/2

This is the unresolved region. Multiple Kummer strata occur. Prime powers `p^a` can produce indices with positive but different `v_p(L_j)`, and the minimum can be achieved away from the unit-weight indices.

The mixed-depth example `(p,j)=(19,827)` already shows that a naive first-digit Lucas argument is insufficient.

## 5. Finite evidence

The computation through `n<=1200` supports the conjecture:

```text
v_p(D_n)=v_p(Gamma_n) for every p>=5.
```

A valid extended search should compute only residues modulo the needed prime powers, not full Apéry integers:

```python
for n in range(4,N):
    M=n//2
    for p in odd_primes_up_to(n):
        vd=min(vL(j,p)+vp(apery(n)-apery(j),p) for j in range(M))
        vg=min(vL(j,p)+vp(apery(j),p) for j in range(M))
        compare(vd,vg)
```

The code must retain the prime-power modulus when testing `b_n-b_j`; reduction modulo p alone is insufficient when the minimum valuation exceeds one.

## 6. Current obstruction

The exact obstruction is not a determinant-height issue. It is the absence of a proved correspondence:

```text
low p-adic weight cardinal indices
        <->
Apéry residue classes modulo p^e.
```

A successful proof needs either:

1. a finite-state automaton over base-p digits proving this correspondence for all lengths, or
2. a recurrence/reflection argument showing that every minimal cardinal stratum contains a matching residue representative.

Without such a lemma, the identity remains a strong conjectural pattern supported by computation, not a theorem.

## Conclusion

No counterexample is presently identified. The exact missing theorem is a quantified local matching lemma for the Kummer-defined low-weight index sets. The gcd triangle, radical containment, and Apéry--Lucas formulas alone do not close the argument.
