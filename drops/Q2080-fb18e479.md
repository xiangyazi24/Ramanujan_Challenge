# P3.2 hostile reconstruction: aligned four-polynomial gcd and MR2

## Verdict

The reflection graph contraction is valid, including the claimed `O(log N)` component length, but one fixed-loop exception must be kept separate: at a fixed edge the lower-index statement is only `p | b_a`, not `p^2 | b_a`.

After removing ordered pairs of edges in the same component, the surviving sector is indeed a two-disjoint-edge sector at cost

```text
O(N^(5/3)) = o(N^2/log^2 N)
```

from the banked first moment.

The exact algebraic contraction for two disjoint edges is a fourfold **monic polynomial gcd**.  If the two lower indices are `a,b` and we use the target prime of the `a`-edge as the common root label `p=m-a`, define the squarefree prime-divisor polynomial

```text
P_n(T) = product_(q prime, q | b_n) (T-q),
omega_n = deg P_n.
```

Then the four monic integral polynomials are

```text
A_a(T)      = P_a(T),
B_a(T)      = 2^omega_a P_a((T+2a+1)/2),
C_ab(T)     = P_b(T+a-b),
D_ab(T)     = 2^omega_b P_b((T+a+b+1)/2),
```

or, factor by factor,

```text
A_a(T)  = product_(q|b_a) (T-q),
B_a(T)  = product_(q|b_a) (T-(2q-2a-1)),
C_ab(T) = product_(q|b_b) (T-(q-a+b)),
D_ab(T) = product_(q|b_b) (T-(2q-a-b-1)).
```

Their monic gcd

```text
H_ab(T) = gcd_monic(A_a,B_a,C_ab,D_ab) in Z[T]
```

retains **one common root label**.  A filtered prime root `p` gives the row `m=p+a` and the four endpoint primes

```text
L_a   = p,
ell_a = (p+2a+1)/2,
L_b   = p+a-b,
ell_b = (p+a+b+1)/2.
```

With the explicit row/top/disjoint filter below, this is a bijection with ordered pairs of disjoint nonfixed reflection-active edges.

If the filtered roots are `p_1,...,p_s`, the smallest positive integer retaining all aligned prime labels is exactly

```text
C_ab(N) = product_i p_i.
```

Because every filtered root lies in `(N/2,2N]`,

```text
s log(N/2) <= log C_ab(N) <= s log(2N).
```

This exposes the main hostile point.

* The **filtered** aggregate height estimate

```text
sum_(a!=b) log C_ab(N) = o(N^2/log N)
```

is, up to the harmless `log N` factor, quantitatively equivalent to MR2.  It is not a genuine saving in analytic dimension.

* The honest two-index lower-dimensional theorem is the **unfiltered double-shift aligned-gcd estimate**

```text
[DSAG]

sum_(1<=a,b<N, a!=b) log |H_ab(0)|
  = o(N^2/log N).                              (DSAG)
```

Since `H_ab | P_a`, every root of `H_ab` is a positive prime and `H_ab(0)` is nonzero.  The filtered carrier divides `|H_ab(0)|`, so DSAG implies MR2.  DSAG is strictly stronger, not a renaming: it also pays for every aligned common root outside the dyadic row range, outside the strict-top range, and in fixed/overlapping configurations.

Nothing currently banked proves DSAG.  The elementary bound is only

```text
log |H_ab(0)| <= log b_a = O(a),
```

hence

```text
sum_(a,b<N) log |H_ab(0)| << N^3.              (0.1)
```

For the **filtered MR2 carrier**, the banked first moment plus the elementary prime-counting row maximum gives the stronger unconditional bound

```text
MR2(N) << N^(8/3)/log^2 N,

sum_(a!=b) log C_ab(N)
  << N^(8/3)/log N.                            (0.2)
```

The required bounds are respectively

```text
o(N^2/log^2 N),
o(N^2/log N),
```

so the unconditional loss is still a factor `N^(2/3)` at the level of the available exponents.

Thus the four-polynomial gcd is a correct label-preserving contraction, but no known Apéry or elementary height theorem closes MR2.  Scalar resultants do not fix this: they can be witnessed by different roots.  And multiplying one carrier per edge pair simply restores the quadratic edge-pair multiplicity.

# 2. The exact reflection graph

For one row `m`, define the active strict-top set

```text
V_m = {
  p prime : m/2 < p <= m,
            p | b_(m-p)
}.
```

Define

```text
f_m(p) = 2m+1-2p.                              (2.1)
```

A directed reflection edge is

```text
p --> f_m(p)
```

when both endpoints lie in `V_m`.

The map is an affine integer map, so every vertex has outdegree at most one.  Also

```text
f_m(q)=p
```

has at most one integer solution

```text
q=(2m+1-p)/2,
```

so every vertex has indegree at most one.

## 2.1 Exact expanding coordinate

Put

```text
Delta_m(p) = 3p-(2m+1).                        (2.2)
```

Then exactly

```text
Delta_m(f_m(p))
 = 3(2m+1-2p)-(2m+1)
 = -2 Delta_m(p).                              (2.3)
```

Hence the distance from the unique affine fixed point

```text
p_*=(2m+1)/3
```

doubles at every directed step:

```text
|Delta_m(f_m(p))| = 2 |Delta_m(p)|.            (2.4)
```

For a nonfixed integer vertex, `Delta_m(p)` is a nonzero integer, so

```text
|Delta_m(p)| >= 1.                             (2.5)
```

For every strict-top vertex `m/2<p<=m`, and `m>=4`,

```text
|Delta_m(p)| <= m-1.                           (2.6)
```

Indeed the right endpoint gives `Delta_m(m)=m-1`, while the negative side of the interval has smaller absolute size.

If a directed path has `e` edges

```text
p_0 -> p_1 -> ... -> p_e,
```

then (2.3) gives

```text
|Delta_m(p_e)| = 2^e |Delta_m(p_0)|.
```

Using (2.5)-(2.6),

```text
2^e <= m-1,

e <= floor(log_2(m-1)).                       (2.7)
```

Since `m<=2N`, every nonfixed component has at most

```text
L_N := floor(log_2(2N-1))
```

edges.

## 2.2 Why every nonfixed component is a directed path

Because indegree and outdegree are both at most one, each finite weak component is a directed path or a directed cycle.

A nonfixed directed cycle is impossible.  Going around a cycle of length `t>=1`, (2.4) would give

```text
|Delta| = 2^t |Delta|,
```

so `Delta=0`.  Thus the only possible cycle is the fixed point.

Therefore:

```text
Every nonfixed component is a directed path.    (2.8)
```

There is no branching.

The initial endpoint may fail to have an active/integer predecessor; the terminal endpoint fails to have an active successor.  Those are the only endpoint mechanisms needed for the counting argument.

# 3. Fixed-edge exception

A fixed edge satisfies

```text
p=f_m(p),
3p=2m+1,
p=(2m+1)/3.                                  (3.1)
```

So it can occur only when `(2m+1)/3` is an integer prime and is active.

It is isolated.  If some `q` pointed to the fixed vertex, then by (2.3)

```text
0=Delta_m(p)=-2Delta_m(q),
```

so `q=p`.

Thus a fixed component contains only its self-loop.

The lower index is

```text
a=m-p=(m-1)/3.
```

At a fixed edge the two nominal endpoint labels coincide:

```text
ell=L=p.
```

The active condition gives only

```text
p | b_a.                                      (3.2)
```

One must **not** replace this by

```text
p^2 | b_a.
```

So the prompt's product form

```text
ell L | b_a
```

is valid for a nonfixed edge, where `ell` and `L` are distinct primes.  It is not valid as written for the fixed loop.

For ordered pairs of **distinct** edges, fixed components contribute zero same-component pairs.  Even if one temporarily counts diagonal pairs, there is at most one fixed edge per row, hence at most `N+O(1)` over the dyadic block, which is already

```text
O(N)=o(N^2/log^2 N).                           (3.3)
```

# 4. Ordered pairs of edges in the same component

Let `E_m` be the number of directed reflection edges in row `m`.  Plainly

```text
E_m <= |V_m|.                                  (4.1)
```

Let the nonfixed path components have edge lengths

```text
e_(m,1), e_(m,2), ... .
```

For ordered pairs of distinct edges in the same component,

```text
S_m
 = sum_C e_C(e_C-1)
 <= L_N sum_C e_C
 <= L_N E_m.                                   (4.2)
```

If one instead includes the diagonal, the same estimate with `e_C^2` holds after increasing `L_N` by one.

Summing (4.2) and using (1.2),

```text
sum_(N<m<=2N) S_m
 <= L_N sum_m E_m
 <= L_N sum_m |V_m|
 << log N * N^(5/3)/log N
 << N^(5/3).                                   (4.3)
```

At the required scale,

```text
N^(5/3) / (N^2/log^2 N)
 = log^2 N / N^(1/3)
 -> 0.                                         (4.4)
```

Therefore

```text
same-component ordered edge pairs
 = o(N^2/log^2 N).                             (4.5)
```

This part is completely closed by the first moment.

Finally, two distinct edges in different weak components cannot share a vertex.  Therefore, after deleting the same-component sector, every surviving ordered pair of distinct edges is automatically a pair of **disjoint** edges.

That is the precise reduction to the two-disjoint-edge sector.

# 5. Exact lower-index form for one nonfixed edge

Let a nonfixed reflection edge in row `m` be

```text
ell --> L,
L=f_m(ell)=2m+1-2ell.                          (5.1)
```

Define its lower index by

```text
a=m-L.                                        (5.2)
```

Then

```text
L=m-a,
2ell=m+a+1,
ell=(m+a+1)/2.                                (5.3)
```

Since `L` is active,

```text
L | b_(m-L)=b_a.                               (5.4)
```

Since `ell` is active,

```text
ell | b_(m-ell).
```

Reflect the zero index `m-ell` modulo `ell`.  By (1.1),

```text
ell | b_(ell-1-(m-ell))
    = b_(2ell-m-1)
    = b_a,                                     (5.5)
```

where the last equality is (5.3).

Because the edge is nonfixed, `ell!=L`.  Hence the two distinct primes divide the same integer, and therefore

```text
ell L | b_a.                                   (5.6)
```

Also `L>m/2` implies

```text
0 <= a < m/2.
```

In fact `a=0` is impossible for an active nontrivial edge because `b_0=1`, so

```text
1 <= a < m/2.                                  (5.7)
```

This proves the prompt's lower-index form, with the fixed-edge caveat from Section 3.

For a second disjoint edge, write similarly

```text
ell'=(m+b+1)/2,
L'=m-b,
ell' L' | b_b.                                (5.8)
```

Because the two edges are disjoint, the four primes

```text
ell, L, ell', L'
```

are pairwise distinct.

# 6. One-common-prime-root normalization

The clean common root is not the row `m`; it is the target prime of the first edge:

```text
p := L = m-a.                                  (6.1)
```

Then

```text
m=p+a.                                         (6.2)
```

The four endpoint primes become

```text
L_a   = p,
ell_a = (p+2a+1)/2,

L_b   = p+a-b,
ell_b = (p+a+b+1)/2.                          (6.3)
```

This choice is useful because `p` itself is a prime divisor of `b_a`; the common roots of the four-polynomial gcd are therefore prime labels, not arbitrary row integers.

# 7. The four shifted squarefree prime-divisor polynomials

For every `n>=0`, define

```text
P_n(T)
 := product_(q prime, q | b_n) (T-q) in Z[T], (7.1)
```

with the empty product equal to `1`.

This is monic and squarefree.  Write

```text
omega_n = deg P_n.
```

For ordered lower indices `(a,b)`, define

```text
A_a(T)
 := P_a(T),                                    (7.2a)

B_a(T)
 := 2^omega_a P_a((T+2a+1)/2),                (7.2b)

C_ab(T)
 := P_b(T+a-b),                                (7.2c)

D_ab(T)
 := 2^omega_b P_b((T+a+b+1)/2).               (7.2d)
```

The powers of `2` are not denominator-clearing approximations: they give exact monic integer polynomials.  Factorwise,

```text
B_a(T)
 = product_(q|b_a) (T-(2q-2a-1)),             (7.3a)

C_ab(T)
 = product_(q|b_b) (T-(q-a+b)),               (7.3b)

D_ab(T)
 = product_(q|b_b) (T-(2q-a-b-1)).            (7.3c)
```

Every displayed polynomial is monic, integral, and squarefree.

Now define the monic gcd

```text
H_ab(T)
 := gcd_monic(A_a,B_a,C_ab,D_ab)
    in Z[T].                                   (7.4)
```

By Gauss's lemma, the monic gcd lies in `Z[T]`.

Because `A_a=P_a`, every root of `H_ab` is itself a positive prime divisor of `b_a`.

# 8. Why the four roots encode exactly the four endpoints

Let `p` be a root of all four polynomials.

From `A_a(p)=0`,

```text
p | b_a.                                       (8.1)
```

From `B_a(p)=0`, there is a prime divisor `q|b_a` such that

```text
p=2q-2a-1,
q=(p+2a+1)/2=ell_a.                            (8.2)
```

Hence

```text
ell_a | b_a.                                   (8.3)
```

From `C_ab(p)=0`,

```text
p+a-b | b_b,
```

and the left side is a prime divisor of `b_b`.  Thus

```text
L_b=p+a-b.                                     (8.4)
```

From `D_ab(p)=0`, there is a prime divisor `q'|b_b` such that

```text
p=2q'-a-b-1,
q'=(p+a+b+1)/2=ell_b.                          (8.5)
```

Thus the common root `p` simultaneously remembers all four endpoint labels in (6.3).

This is the alignment that scalar resultants lose.

# 9. The explicit row/top/disjoint filter

A common root of `H_ab` need not yet belong to the desired MR2 dyadic sector.  For a root `p`, set

```text
m=p+a,

L_a   = p,
ell_a = (p+2a+1)/2,
L_b   = p+a-b,
ell_b = (p+a+b+1)/2.                          (9.1)
```

Define the filter `Phi_N(a,b;p)` by all of the following.

### Row range

```text
N < p+a <= 2N.                                 (9.2)
```

### Distinct lower indices

```text
a != b.                                        (9.3)
```

### Strict-top targets

For `L_a=p`:

```text
p > (p+a)/2
iff
p>a.                                           (9.4a)
```

For `L_b=p+a-b`:

```text
p+a-b > (p+a)/2
iff
p > 2b-a.                                      (9.4b)
```

So require

```text
p>a,
p>2b-a.                                       (9.5)
```

The source endpoints are then automatically strict top:

```text
2ell_a-m = a+1 > 0,
2ell_b-m = b+1 > 0.                            (9.6)
```

Their integrality and primality are already guaranteed by being roots of `B_a,D_ab`.

### Pairwise disjoint endpoints

Require

```text
card {L_a,ell_a,L_b,ell_b} = 4.                (9.7)
```

Equivalently, given `a!=b`, exclude the four explicit root values

```text
p = 2a+1,          (a-edge fixed)
p = 3b+1-a,        (b-edge fixed)
p = a+b+1,         (L_a=ell_b)
p = 2b+1.          (ell_a=L_b)                 (9.8)
```

The other possible coincidences reduce to `a=b`.

Thus

```text
Phi_N(a,b;p)
```

is completely explicit.

Let

```text
R_ab(N)
 = {p : H_ab(p)=0 and Phi_N(a,b;p)}.            (9.9)
```

# 10. Bijection: filtered roots -> ordered disjoint active edges

Take

```text
p in R_ab(N).
```

Set `m=p+a` and the four primes by (9.1).

Because `L_a=p|b_a` and

```text
m-L_a=a,
```

`L_a` is active in row `m`.

For `ell_a`, (8.3) gives `ell_a|b_a`.  Reflection modulo `ell_a` sends the index `a` to

```text
ell_a-1-a
 = (p+2a+1)/2 - 1 - a
 = (p-1)/2
 = m-ell_a.                                    (10.1)
```

Therefore

```text
ell_a | b_(m-ell_a),
```

so `ell_a` is active.  Directly,

```text
f_m(ell_a)
 = 2(p+a)+1-(p+2a+1)
 = p
 = L_a.                                        (10.2)
```

Hence

```text
ell_a --> L_a
```

is a reflection edge.

For the `b`-edge, `C_ab(p)=0` gives

```text
L_b=p+a-b | b_b,
```

and

```text
m-L_b=b,
```

so `L_b` is active.

Similarly `D_ab(p)=0` gives `ell_b|b_b`, and reflection sends `b` to

```text
ell_b-1-b
 = (p+a+b+1)/2 - 1 - b
 = (p+a-b-1)/2
 = m-ell_b.                                    (10.3)
```

Thus `ell_b` is active and

```text
f_m(ell_b)=L_b.                                (10.4)
```

The filter (9.7) makes the two edges nonfixed and disjoint.

So every filtered root gives one ordered pair

```text
(ell_a --> L_a,
 ell_b --> L_b)                                (10.5)
```

of disjoint reflection-active edges in the dyadic row range.

# 11. Bijection: ordered disjoint active edges -> filtered root

Conversely, take an ordered pair of disjoint nonfixed reflection edges in one row `m`:

```text
ell_a --> L_a,
ell_b --> L_b.
```

Define

```text
a=m-L_a,
b=m-L_b,
p=L_a=m-a.                                    (11.1)
```

Section 5 gives

```text
p=L_a | b_a,
ell_a=(m+a+1)/2=(p+2a+1)/2 | b_a.             (11.2)
```

Hence

```text
A_a(p)=B_a(p)=0.                               (11.3)
```

Also

```text
L_b=m-b=p+a-b | b_b,
```

so

```text
C_ab(p)=0.                                     (11.4)
```

Finally

```text
ell_b=(m+b+1)/2=(p+a+b+1)/2 | b_b,
```

hence

```text
D_ab(p)=0.                                     (11.5)
```

Therefore

```text
H_ab(p)=0.
```

The row is in `(N,2N]`, the endpoints are strict top, and the two edges are disjoint, so `Phi_N(a,b;p)` holds.

This inverse construction is unique because the target label of each edge determines its lower index:

```text
a=m-L_a,
b=m-L_b.
```

Therefore there is an exact bijection

```text
filtered roots p of H_ab
<-->
ordered disjoint reflection-edge pairs
with lower indices (a,b).                      (11.6)
```

No prime labels have been forgotten.

# 12. The smallest aligned integer carrier

Let the filtered roots be

```text
R_ab(N)={p_1,...,p_s}.
```

They are distinct primes because `H_ab` is squarefree and divides `P_a`.

Define the filtered polynomial

```text
H_ab^N(T)
 := product_(i=1..s) (T-p_i).                  (12.1)
```

The least positive integer divisible by every aligned prime label is

```text
C_ab(N)
 := lcm(p_1,...,p_s)
  = product_i p_i
  = |H_ab^N(0)|.                               (12.2)
```

This is the smallest natural integer carrier that retains all aligned root labels exactly.

For a filtered root,

```text
p_i=L_a>m/2>N/2,
```

while `p_i<=m<=2N`.  Hence

```text
N/2 < p_i <= 2N.                               (12.3)
```

Therefore

```text
s log(N/2)
 <= log C_ab(N)
 <= s log(2N).                                 (12.4)
```

This elementary inequality is the complete height conversion from aligned roots to MR2 multiplicity.

# 13. MR2 in the aligned-root coordinates

Let

```text
MR2_disj(N)
```

be the number of ordered pairs of disjoint reflection-active edges in rows `N<m<=2N` after the already-negligible same-component sector is removed.

By the bijection (11.6),

```text
MR2_disj(N)
 = sum_(a!=b) |R_ab(N)|.                       (13.1)
```

The sum can be taken over `1<=a,b<N`; the filter makes all other pairs empty.

Summing (12.4) gives the exact quantitative comparison

```text
log(N/2) * MR2_disj(N)
 <= sum_(a!=b) log C_ab(N)
 <= log(2N) * MR2_disj(N).                     (13.2)
```

Consequently

```text
MR2_disj(N)=o(N^2/log^2 N)                    (13.3)
```

if and only if

```text
sum_(a!=b) log C_ab(N)
 = o(N^2/log N).                               (13.4)
```

Thus the **filtered** carrier-height statement is not a weaker theorem than MR2.  It is MR2 rewritten with a logarithmic weight.

This is the first place where a purported “dimension reduction” can be overstated.

# 14. The honest DSAG statement

To obtain a genuinely two-index algebraic theorem, do **not** factor the common gcd and then impose the dyadic root filter.  Use the whole common-root polynomial.

Since

```text
H_ab(T) | P_a(T),
```

all roots of `H_ab` are positive primes.  In particular

```text
H_ab(0) != 0.                                  (14.1)
```

Define

```text
DSAG(N)
 := sum_(1<=a,b<N, a!=b) log |H_ab(0)|.        (14.2)
```

The exact sufficient theorem is

```text
[DSAG]
DSAG(N) = o(N^2/log N).                        (14.3)
```

Why does this imply MR2?

Every filtered factor of `H_ab` is also a factor of the full polynomial, so

```text
C_ab(N) | |H_ab(0)|.                           (14.4)
```

Hence

```text
log(N/2) MR2_disj(N)
 <= sum_(a!=b) log C_ab(N)
 <= DSAG(N).                                   (14.5)
```

Thus (14.3) implies

```text
MR2_disj(N)=o(N^2/log^2 N).                    (14.6)
```

Together with the same-component estimate (4.5), this gives the full MR2 target.

## 14.1 In what sense DSAG is genuinely lower-dimensional

Its **external summation variables** are only the two lower indices

```text
(a,b).
```

There is no explicit sum over

```text
m, ell, L, ell', L'.
```

All endpoint-prime and row alignment is internalized into one polynomial gcd.

More importantly, DSAG is **strictly stronger** than MR2, so it is not merely the equality (13.2) with symbols renamed.  `H_ab(0)` pays for every common prime root of the four shifted polynomials, including roots which fail one or more of:

```text
N < p+a <= 2N,
strict-top inequalities,
nonfixedness,
disjointness.                                  (14.7)
```

MR2 sees none of those extra roots.

Therefore the reverse implication

```text
MR2 ==> DSAG
```

has no elementary reason to hold.

This is the precise, quantitative sense in which the **unfiltered** DSAG theorem is a lower-dimensional algebraic strengthening.

## 14.2 In what sense the filtered version is not lower-dimensional

If one first filters the roots and then takes the carrier `C_ab(N)`, (13.2) shows

```text
sum log C_ab(N)
asymp log N * MR2_disj(N).                     (14.8)
```

The missing row variable has simply moved into the degree/root multiplicity of `H_ab^N`.

So the filtered carrier statement is a repackaging, not a new estimate.

Both facts must be stated together; otherwise “two indices instead of five labels” is only rhetoric.

---

# 15. Known facts do not prove DSAG

Because `H_ab|P_a`, the constant term is a squarefree divisor of `b_a`:

```text
|H_ab(0)| | rad(b_a) | b_a.                   (15.1)
```

The elementary Apéry formula gives exponential growth

```text
log b_a = O(a).                                (15.2)
```

For example, directly from

```text
b_a=sum_k binom(a,k)^2 binom(a+k,k)^2,
```

one obtains a crude bound `b_a <= (a+1)2^(6a)`, more than enough for (15.2).

Hence

```text
log |H_ab(0)| <= C a.                          (15.3)
```

Summing over all ordered `a,b<N`,

```text
DSAG(N)
 <= C sum_(a<N) sum_(b<N) a
 << N^3.                                       (15.4)
```

This is the strongest direct bound from the monic-divisor observation plus elementary Apéry height alone.

It is far above the desired

```text
o(N^2/log N).                                 (15.5)
```

No current resultant, squarefreeness, reflection, or first-moment theorem lowers (15.4) to the DSAG scale.

---

# 16. Strongest unconditional bound for the filtered MR2 carrier

For the filtered sector one can do better than `N^3` because the banked first moment controls the total number of active top labels.

Let

```text
E_m = number of reflection edges in row m.
```

Then

```text
E_m <= |V_m|.                                  (16.1)
```

The number of ordered pairs of distinct edges in row `m` is at most

```text
E_m(E_m-1) <= E_m^2.                           (16.2)
```

Elementary prime counting gives the pointwise bound

```text
E_m
 <= # {p prime : m/2<p<=m}
 << N/log N.                                   (16.3)
```

Using the banked first moment,

```text
sum_m E_m
 <= sum_m |V_m|
 << N^(5/3)/log N.                             (16.4)
```

Therefore

```text
sum_m E_m(E_m-1)
 <= (max_m E_m) sum_m E_m
 << (N/log N)(N^(5/3)/log N)
 << N^(8/3)/log^2 N.                           (16.5)
```

In particular,

```text
MR2_disj(N)
 << N^(8/3)/log^2 N.                           (16.6)
```

By (12.4), the total filtered carrier height satisfies

```text
sum_(a!=b) log C_ab(N)
 << log N * MR2_disj(N)
 << N^(8/3)/log N.                             (16.7)
```

The target is

```text
sum log C_ab(N)=o(N^2/log N).                  (16.8)
```

Thus the exponent gap is exactly

```text
N^(8/3)/log N
--------------------------------
N^2/log N
 = N^(2/3).                                    (16.9)
```

No logarithmic sharpening of the existing elementary estimates repairs an `N^(2/3)` power loss.

The same-component sector already removed in Section 4 has size only `O(N^(5/3))`, so it is negligible relative to both the desired MR2 scale and the unconditional residual bound (16.6).

---

# 17. Why scalar resultants are not label-preserving

A scalar resultant answers:

```text
Do these two polynomials share some root?
```

It does not remember **which** root witnessed the vanishing.

For four polynomials, separate resultant conditions can therefore be witnessed by different roots.  The toy pattern

```text
F_1(T)=F_2(T)=T-x,
F_3(T)=F_4(T)=T-y,
x!=y,
```

has

```text
Res(F_1,F_2)=0,
Res(F_3,F_4)=0,
```

but

```text
gcd(F_1,F_2,F_3,F_4)=1.                       (17.1)
```

There is no common aligned root.

The same defect persists in more elaborate products or gcds of pairwise resultants: unless the common root label itself is retained, different endpoint constraints can be satisfied at different primes.

The monic fourfold polynomial gcd (7.4) is exactly what prevents this mixing.

---

# 18. Why products over edge pairs do not save height

Suppose a row has `E_m` residual edges and one constructs an integer carrier for every ordered edge pair.  Even if each individual carrier has only logarithmic height `O(log N)`, multiplying all of them costs

```text
O(E_m(E_m-1) log N).                           (18.1)
```

Summing over rows gives precisely the logarithmically weighted MR2 multiplicity.

This is the same obstruction as (13.2): the pair multiplicity has not disappeared; it has merely moved from a counting sum into the logarithm of a product.

The aligned gcd `H_ab` does one useful thing: for fixed `(a,b)` it combines all common row labels before taking height.  But its constant term is

```text
|H_ab(0)| = product_(common prime roots p) p,  (18.2)
```

so logarithms add the root multiplicities back exactly.

There is no automatic height compression from multiplication.

---

# 19. Exact theorem / obstruction package

The bankable reconstruction is:

```text
THEOREM (reflection-path and aligned-gcd contraction).

For N<m<=2N let V_m be the strict-top active prime set
p>m/2, p|b_(m-p), and put f_m(p)=2m+1-2p.

1. COMPONENT GEOMETRY.
   With Delta_m(p)=3p-(2m+1),

      Delta_m(f_m(p))=-2 Delta_m(p).

   Every nonfixed weak component is a directed path of at most

      floor(log_2(m-1))

   edges.  The only cycle is the isolated fixed loop

      p=(2m+1)/3.

2. SAME-COMPONENT PAIRS.
   Using the banked first moment

      sum_m |V_m| << N^(5/3)/log N,

   the number of ordered pairs of distinct active edges in the same
   component is

      O(N^(5/3))
      = o(N^2/log^2 N).

   Hence the residual distinct-edge sector consists of disjoint edges.

3. LOWER-INDEX FORM.
   A nonfixed edge ell->L with a=m-L has

      ell=(m+a+1)/2,
      L=m-a,
      ell L | b_a.

   For the fixed loop ell=L=p only p|b_a is forced; p^2|b_a is not.

4. FOUR-POLYNOMIAL ALIGNMENT.
   For two ordered disjoint edges with lower indices a,b, put
   p=L_a=m-a and define P_n(T)=prod_(q|b_n)(T-q).  Then p is a
   common root of exactly the four monic integral polynomials

      P_a(T),
      2^omega_a P_a((T+2a+1)/2),
      P_b(T+a-b),
      2^omega_b P_b((T+a+b+1)/2).

   After the explicit dyadic/top/disjoint filter, common roots are in
   bijection with ordered disjoint reflection-edge pairs.

5. SMALLEST FILTERED CARRIER.
   If the filtered common roots are p_1,...,p_s, then

      C_ab(N)=prod_i p_i

   is the least positive integer divisible by all aligned prime labels,
   and

      s log(N/2) <= log C_ab(N) <= s log(2N).

6. FILTERED HEIGHT IS MR2 IN DISGUISE.

      log(N/2) MR2_disj(N)
      <= sum_(a!=b) log C_ab(N)
      <= log(2N) MR2_disj(N).

   Thus the filtered carrier estimate at target scale is quantitatively
   equivalent to MR2.

7. GENUINE TWO-INDEX DSAG.
   Let H_ab be the unfiltered monic fourfold gcd.  The strictly stronger,
   genuinely two-index sufficient theorem is

      sum_(a!=b<N) log |H_ab(0)|
        = o(N^2/log N).

   It implies MR2 because C_ab(N)|H_ab(0), but it also controls aligned
   roots outside the MR2 filter and is therefore not equivalent to MR2.

8. CURRENT UNCONDITIONAL BOUNDS.
   Since H_ab|P_a and P_a(0) is a squarefree divisor of b_a,

      sum_(a,b<N) log |H_ab(0)| << N^3.

   For the filtered sector, the banked first moment and
   max_m E_m << N/log N give

      MR2_disj(N) << N^(8/3)/log^2 N,
      sum log C_ab(N) << N^(8/3)/log N.

   This misses the required scale by a power factor N^(2/3).
```

Therefore the proposed contraction is algebraically sound only up to the following endpoint:

```text
REFLECTION PATH CONTRACTION: CLOSED.
SAME-COMPONENT SECTOR: CLOSED.
FOUR-POLYNOMIAL LABEL ALIGNMENT: CLOSED.
MR2 FROM KNOWN HEIGHT FACTS: OPEN.
NEXT SUFFICIENT INPUT: DSAG.
```

The main negative conclusion is equally important: a filtered root-product carrier is **not** a new proof of MR2, and scalar resultants or products over edge pairs do not create the missing power saving.

# 20. Minimal exact checker skeleton

The following Wolfram Language skeleton checks the graph definitions and the four-polynomial root identities from exact Apéry integers.  It is intended for finite sanity checks only; none of the asymptotic conclusions above depends on it.

```wl
ClearAll[aperyB, activeTop, f, edgeQ, primeDivPoly,
  A, B, C, D, H, endpoints, filterQ];

aperyB[M_Integer] := Module[{b = ConstantArray[0, M + 1]},
  b[[1]] = 1;
  If[M >= 1, b[[2]] = 5];
  Do[
    b[[n + 2]] = Quotient[
      (34 n^3 + 51 n^2 + 27 n + 5) b[[n + 1]]
        - n^3 b[[n]],
      (n + 1)^3
    ],
    {n, 1, M - 1}
  ];
  b
];

activeTop[m_, b_] := Select[
  Prime[Range[PrimePi[m]]],
  # > m/2 && Mod[b[[m - # + 1]], #] == 0 &
];

f[m_, p_] := 2 m + 1 - 2 p;

edgeQ[m_, p_, b_] := Module[{v = activeTop[m, b]},
  MemberQ[v, p] && MemberQ[v, f[m, p]]
];

(* Exact expanding coordinate. *)
Delta[m_, p_] := 3 p - (2 m + 1);
Assert[Delta[m, f[m, p]] == -2 Delta[m, p]];

primeDivPoly[n_, b_, T_] := Times @@
  ((T - #[[1]]) & /@ FactorInteger[b[[n + 1]]]);

A[a_, bseq_, T_] := primeDivPoly[a, bseq, T];

B[a_, bseq_, T_] := Module[{fac = FactorInteger[bseq[[a + 1]]]},
  Times @@ ((T - (2 #[[1]] - 2 a - 1)) & /@ fac)
];

C[a_, bb_, bseq_, T_] := Module[{fac = FactorInteger[bseq[[bb + 1]]]},
  Times @@ ((T - (#[[1]] - a + bb)) & /@ fac)
];

D[a_, bb_, bseq_, T_] := Module[{fac = FactorInteger[bseq[[bb + 1]]]},
  Times @@ ((T - (2 #[[1]] - a - bb - 1)) & /@ fac)
];

H[a_, bb_, bseq_, T_] := PolynomialGCD[
  A[a, bseq, T],
  B[a, bseq, T],
  C[a, bb, bseq, T],
  D[a, bb, bseq, T]
];

endpoints[a_, bb_, p_] := {
  p,
  (p + 2 a + 1)/2,
  p + a - bb,
  (p + a + bb + 1)/2
};

filterQ[N_, a_, bb_, p_] := Module[{m = p + a, ep},
  ep = endpoints[a, bb, p];
  N < m <= 2 N &&
  a != bb &&
  p > a &&
  p > 2 bb - a &&
  VectorQ[ep, IntegerQ] &&
  And @@ (PrimeQ /@ ep) &&
  DuplicateFreeQ[ep]
];
```

A finite checker must test the **fourfold gcd root itself**.  Replacing it by separate scalar resultant tests is not equivalent, for the root-alignment reason in Section 17.
