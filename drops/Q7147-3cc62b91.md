## 1. The raw endpoint geometry is a translation, not a folding

Freeze one exact chart, orientation, sign cell, dyadic block, and unordered lower pair

```text
P={ell_1,ell_2}.
```

For the endpoint `J`, the fixed lower residue in the three quotient namespaces is

```text
S:       rho_i(J) = J - ell_i,
n/P,M-:  rho_i(J) = J - 6 ell_i,
N:       rho_i(J) = J - 13 ell_i.                  (1.1)
```

Thus in every namespace

```text
rho_i(J') - rho_i(J) = J' - J.                     (1.2)
```

Let the coarse `J` partition be half-open windows

```text
B_k=[J_0+kW, J_0+(k+1)W),
0<=k<K,
K=O(T/W+1).                                         (1.3)
```

For a fixed lower characteristic `ell_i`, the image of `B_k` under `(1.1)` is simply

```text
B_k - c_tau ell_i,

c_tau in {1,6,13},                                  (1.4)
```

an interval of exactly the same length `W`.  Consecutive half-open `J` windows therefore give consecutive half-open residue intervals.  There is no hidden many-to-one map in the endpoint coordinate.

The common-`P` endpoint condition requires the two translated residues, one modulo each `ell_i`, to be actual Apéry zeros.  The subinterval theorem is exactly what yields the banked `<2u` cap in one `J` window.  It is a cardinality bound; it does not identify zeros lying in different translated windows.

So the first factor is literally

```text

```

No overlap argument improves `(1.5)`.

## 2. Fixed-token affine `q` recovery is injective — in the wrong direction for a free saving

Write the fixed selected upper token in the Q7038 numerical coordinate as `z=t`.  The exact recovery from `(J,z)` is

```text
S:  J=q-1-z       => q = J+z+1,

n:  J=6q+z        => q = (J-z)/6,

N:  J=12q+z       => q = (J-z)/12.                 (2.1)
```

The `n/P` and `n/M-` typed cells have the same upper recovery in `(2.1)`; they differ only in the lower moving coordinate.

If the canonical `z` token in `OV-SETF-K` is a reflected/renormalized representative rather than literally `t`, the ledger's fixed affine change of coordinate only changes the additive constants.  The coefficient of `J` remains nonzero.  Hence the only property needed below survives:

```text
fixed token z + fixed chart:
    J -> q is one-to-one and order preserving.       (2.2)
```

In particular,

```text
J != J'  =>  q(J,z) != q(J',z).                      (2.3)
```

This kills a proposed *collision* argument.  Many restoring endpoints for one token do not force repeated `q`; they force many **distinct** selected `q`'s.

The correct way to exploit `(2.2)`, if one has an independent selected-prime support theorem, is exactly the minimum in `(V1)`.  Namely,

```text
J -> q
```

embeds the endpoint fibre into `Q_z`.  But the affine inverse itself gives no upper bound on `|Q_z|` beyond the macroscopic legal range.  The legal `q` interval has macroscopic length on the interior charts, so a fixed `z` can geometrically coexist with `Theta(T/W)` coarse `J` windows.

If the particular token is itself an actual upper zero index, then selectedness additionally gives `q|b_z`, and one may of course intersect `(V1)` with the already-authorized shell-prime divisor count of `b_z`.  That is an arithmetic support bound, not a consequence of `I_J` overlap or post-OR geometry.  No such numerical improvement over `(T/W)u` is supplied in the `OV-SETF-K` facts stated in this question, so I do not subtract a factor on that basis.

## 3. The prefix restoration contributes a genuine second factor `u`

Once `J` is fixed, the common prefix is reconstructed by its positive gap `c`:

```text
S,N:  c=m-J>0,   m=J+c,

n:    c=J-m>0,   m=J-c.                              (3.1)
```

For a lower characteristic, the corresponding prefix residue is

```text
S:  m-ell_i,
n:  m-6ell_i,
N:  m-13ell_i.                                       (3.2)
```

Thus at fixed `J`, varying `m` again moves through an ordinary interval with slope one.  The banked actual-prefix estimate `<2u` is therefore another genuine subinterval zero capacity.

Crucially, the map

```text
(J,c) -> (J,m)                                       (3.3)
```

is injective.  More importantly for post-OR semantics, the canonical numerical key contains `J`:

```text
(m,P,J,q).                                           (3.4)
```

Hence even if two different endpoint restorations happen to produce the same absolute integer `m`,

```text
m(J,c)=m(J',c'),  J!=J',                             (3.5)
```

they are **not** the same key:

```text
(m,P,J,q(J,z)) != (m,P,J',q(J',z)).                  (3.6)
```

There is therefore no legitimate map

```text
all prefixes over many J
   -> distinct absolute m
```

with fibre one.  Such a map would erase the endpoint coordinate whose occurrence multiplicity the proof is required to preserve.

The second factor `u` is real:

```text
#(J,m)(z)
  <= (max prefixes per J) * #J(z)
  < 2u * #J(z).                                      (3.7)
```

Combining `(3.7)` with the endpoint count gives

```text
#(J,m)(z)
  = O((T/W)u^2),                                     (3.8)
```

or the refined minimum `(V1)` if a separate `Q_z` bound is available.

## 4. Ordering does not create a crossing or a repeated prefix triple

By `(2.1)`, within one fixed chart

```text
J_1<J_2  =>  q_1<q_2.                                (4.1)
```

Thus the affine recovery is monotone.  There is no possibility that two different `J` values cross and recover the same selected prime after ordering.

The same monotonicity means that grouping endpoints by `J` windows simply groups the recovered `q` values into affine image intervals.  Adjacent `J` windows may map to adjacent `q` intervals; their endpoints can touch after floors/congruence restrictions, but this changes only an absolute boundary constant.

Nor does ordering force repeated prefix triples.  A prefix triple is at least

```text
(m,P,J),                                              (4.2)
```

and the full atom also remembers `q`.  Two different `J` values therefore give different triples even if they share `m` and `P`.

So the implication

```text
many ordered restoring endpoints
  => many repeated prefix triples
```

is false at the numerical source level.

## 5. Nonwrap, reflection representative, and raw-minus-first only thin

All four chart formulas are affine before the Boolean masks are imposed.  The nonwrap and ordering conditions are strict linear inequalities among the residues.

Consequently, after discarding the finitely many boundary pieces, one may work in an interior cell where every relevant inequality has a positive macroscopic margin.  Moving `J` inside one `W` window and moving `m` inside its allowed prefix interval preserve that cell until one reaches a boundary.  Boundary crossings can split a window into a bounded number of pieces; they do not replace `T/W` by `1` or replace `u` by `1`.

Reflection likewise chooses one representative of a physical pair.  It removes a factor at the **presentation** level; that factor has already been removed in the current post-OR singleton convention.  It does not identify records with different `J`.

Raw-minus-first has the same logical status.  On a numerical tuple where both raw signs are formally present, the rule assigns the occurrence to one sign.  It prevents plus/minus double counting of that one tuple.  It does not say

```text
(J,m) and (J',m') with J!=J'
```

are the same occurrence.

Thus all these masks are monotone deletions from `(3.8)`.  None gives a new inverse-fibre theorem.

## 6. Exact post-OR set semantics

The synchronized post-OR theorem is

```text
fixed (m,P,J,q)  ->  0 or 1 canonical atom.           (6.1)
```

This is the right place to test every proposed deduplication.

Suppose a fixed token `z` has two restorations

```text
(J,m), (J',m').                                      (6.2)
```

If `J!=J'`, then `(2.3)` gives `q!=q'`, so the full tuples differ.

If `J=J'` but `m!=m'`, the full tuples again differ.

Only

```text
J=J' and m=m'                                        (6.3)
```

can land on the same post-OR numerical key; and then the current proof is already counting it once.

Therefore set-valued OR packing cannot reduce either inverse factor after the numerical pair `(J,m)` has been restored.

## 7. Sharp interface packet

Here is the sharp packet showing why the exported geometry does not imply a better asymptotic inverse.  This is an **interface saturator**, not a claim that the actual Apéry sequence attains the caps in every window.

Freeze one interior chart, one lower pair `P`, and one token `z`.  Let

```text
K = floor(c T/W)
```

for a fixed small `c>0` chosen so all windows stay away from the chart and nonwrap boundaries.

For each coarse window `B_k`, choose `u` distinct endpoint labels

```text
J_(k,a),  1<=a<=u,                                   (7.1)
```

whose two lower endpoint residues are declared to be the actual common-`P` zero incidences supplied by the interface.  This respects the banked `<2u` cap.

Use the fixed-token affine inverse to assign

```text
q_(k,a)=q_tau(J_(k,a),z).                             (7.2)
```

Because `J -> q` is injective, all these selected-state labels are distinct whenever the `J` labels are distinct.  There is no source alias.

For every retained `J_(k,a)`, choose `u` distinct legal prefix gaps

```text
c_b, 1<=b<=u,                                        (7.3)
```

and set

```text
m_(k,a,b)=
  J_(k,a)+c_b   on S,N,
  J_(k,a)-c_b   on n.                                (7.4)
```

Declare the corresponding two lower prefix residues to be the actual prefix-zero incidences allowed by the `<2u` interface.  Again the cap is respected.

The resulting full labels

```text
(m_(k,a,b), P, J_(k,a), q_(k,a))                     (7.5)
```

are pairwise distinct: different `a,k` change `J` (and therefore `q`), while different `b` at fixed `J` change `m`.

Reflection, raw-minus-first, primitive/nonwrap masks, and set-valued OR can all be fixed once on the interior cell.  They contribute no multiplicity.

The packet has

```text
K * u * u
  = Theta((T/W)u^2)                                 (7.6)
```

literal canonical occurrences.

Again, `(7.1)` and `(7.3)` are a saturation of the **banked zero-count interfaces**; I do not assert that the real Apéry zero sets realize this packet.  Its rigorous purpose is to show that the interval bounds plus numerical source geometry do not logically imply a smaller inverse.  Any strict improvement must use an additional arithmetic correlation among the actual endpoint/prefix zero sets or a stronger already-banked selected-prime support bound `|Q_z|`.

## 8. The first failed injections

There are three tempting maps.  Two are invalid; one is valid but gives no free saving.

### 8.1 Invalid: interval overlap -> same occurrence

```text
z in I_J ∩ I_J'
  => same source / same post-OR atom.                 (8.1)
```

False.  The endpoint label remains part of the canonical key, and fixed-token affine recovery gives different `q` when `J!=J'`.

### 8.2 Invalid: repeated absolute prefix -> same prefix triple

```text
m(J,c)=m(J',c')
  => same prefix occurrence.                         (8.2)
```

False when `J!=J'`.  The key is `(m,P,J)` and the full atom also remembers the distinct recovered `q`.

### 8.3 Valid: endpoint -> selected prime

```text
J -> q_tau(J,z).                                     (8.3)
```

This is injective.  It yields exactly

```text
#J(z) <= |Q_z|,                                      (8.4)
```

and hence the minimum `(V1)`.  It removes a factor only if `|Q_z|` has already been proved smaller than `(T/W)u`.  The affine geometry itself does not prove that inequality.

This is the sharp distinction: the inverse map is injective, but its target is not known geometrically to be smaller than the source bound.

## 9. Final exact inverse

Let

```text
N_W := number of legal coarse J windows
     = O(T/W+1),

E_z := number of actual common-P endpoint restorations for token z,

Q_z := actual selected-prime support compatible with token z.
```

Then the literal source audit gives

```text
E_z < 2u N_W,                                        (9.1)
E_z <= |Q_z|,                                        (9.2)
```

so

```text
E_z <= min(2u N_W, |Q_z|).                           (9.3)
```

For each endpoint there are fewer than `2u` actual prefixes, hence

```text
K_z
 := # canonical post-OR restorations after m
 < 2u E_z
 <= 2u min(2u N_W, |Q_z|).                           (9.4)
```

Equivalently,

```text
K_z
 = O( u * min((T/W)u, |Q_z|) ).                      (9.5)
```

Without an additional bound making the second branch of the minimum smaller,

```text
K_z = O((T/W)u^2).                                   (9.6)
```

No factor can be removed by raw interval overlap, ordering, nonwrap, reflection, raw-minus-first, or post-OR set packing.

## Bottom line

`OV-SETF-K` is not hiding a free inverse-fibre collapse.  The `J`-window count and the per-`J` prefix count are two genuine numerical coordinates.  Fixed-token affine recovery is order-preserving and injective, so it prevents aliases rather than creating them.  Post-OR set semantics confirms this: only identical `(m,P,J,q)` presentations are deduplicated.

The strongest valid inverse is `(9.5)`.  On the state supplied here, its selected-prime branch is not known to beat the window/subinterval branch, so the current

```text
(T/W)u^2
```

load remains the sharp banked inverse.

The first invalid inference is to replace `I_J` overlap by equality of canonical occurrences.  The sharp interface packet `(7.1)`--`(7.6)` shows why that implication fails while preserving the full occurrence labels.
