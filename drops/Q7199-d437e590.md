# P32 unconditional bounds after dyadic stratification

## 1. Setup and the sharp decomposition

Write a primitive separated pair as two four-return windows with spans
\(s,t\leq H\), bridge \(G\), and use dyadic boxes
\[
 s\asymp S,\qquad t\asymp T,\qquad G\asymp K.
\]
The contribution is denoted \(E(S,T,K)\). The available information gives three different regimes.

The important point is that (F) gives one window per start, not one partner per window. Therefore the count is an incidence count of compatible starts; it is invalid to replace it by \(M_p(K)^2\) or to assume partners are separated by K.

## 2. Bounds from the available inputs

### Short-short regime

If both spans are small, the inverse-square clique bound (B) applies to each projective state:
\[
Q_p(S)\leq 66S^2(1+\log S).
\]
Summing over primes in \(p\sim X\), and using that the number of primes is \(\ll X/\log X\), gives only
\[
\sum_{p\sim X}E(S,T,K)
 \ll \frac{X}{\log X}(ST)^2\log X
\]
when applied independently. This is below the target only when
\[
ST\ll X^{1/2-o(1)}.
\]
It does not control the full separated range.

### Small-large regime

Suppose \(S\leq H\) but the second span is unrestricted. The near-bridge theorem (E) gives
\[
\sum_{p\sim X}E_{near}(K)\ll H^2K^2.
\]
This is effective only for the near bridge region. It does not extend to arbitrary large bridges because the theorem uses the canonical bridge condition.

The large-bridge part would need an estimate of the form
\[
\sum_{p\sim X}E(S,T,K)\ll \frac{H^2K^2}{p^{\delta}}
\]
for some \(\delta>0\), or after prime averaging an equivalent saving of \(X^{-\delta}\).

### Large-large regime

The only unconditional global input is orbit energy:
\[
F_p=\sum_qm_p(q)^2\ll p^{3/2}.
\]
After reflection quotient this becomes
\[
\bar V\leq 7\bar M+E_{sep}.
\]
This inequality is one-directional: it bounds the second moment by separated pairs; it does not bound separated pairs by the energy. Hence (C) cannot close the large-bridge contribution.

## 3. Why the tempting Cauchy argument fails

A common incorrect step is:

\[
E_{sep}(K)\stackrel{?}{\leq}\sum_q m_q m_{q,K}
\]
followed by Cauchy and (C).

This loses the defining property of primitive windows. The same chain can have many possible formal partners, and the partner set is not K-separated. The only available separation is between the two chains themselves. Therefore energy gives
\[
\sum_q m_q^2\ll X^{3/2},
\]
but not the required saving
\[
\frac{1}{X}\sum_qm_q^2
\]
that would be needed for the target \(X^2/\log X\).

## 4. Remaining exponent region

The covered region is:

* short-short: \(ST\leq X^{1/2-o(1)}\);
* near bridge: \(K\) in the range of theorem (E), giving \(\ll H^2K^2\);
* the already established resultant range \(K\leq \sqrt X/\sqrt{\log X}\).

The uncovered region is
\[
G\gg \frac{\sqrt X}{\sqrt{\log X}},
\]
with no usable bridge saving.

In exponent notation, writing
\[
S=X^a,T=X^b,G=X^c,
\]
the known arguments cover approximately
\[
a+b\leq \frac12,
\]
and the near-bridge strip, but leave
\[
a,b\leq \frac12,\qquad c>\frac12
\]
with no nontrivial saving.

## 5. Abstract obstruction model

An abstract word model shows that (A)-(C) alone cannot defeat this region.

Take a collection of projective states indexed by q. In each state place blocks of occurrences
\[
q: \quad 0, s, s+G, s+G+t
\]
with fixed \(s,t\ll H\) and many possible large bridges G.
Choose the occurrence set so that:

1. reflection is imposed by adding the reflected block;
2. pair distances are thinned so that
\[
R_d\leq 3(d-1);
\]
3. the number of states is chosen so that
\[
\sum_qm_q^2\asymp X^{3/2}.
\]

This satisfies the pair-cap and energy constraints but leaves many separated long bridges. Therefore the remaining estimate cannot follow formally from (A)-(C).

## 6. Minimal missing inequality

The weakest additional input needed is a genuine long-bridge nonconcentration estimate. One possible formulation is:

For dyadic \(S,T,K\), \(K>\sqrt X/\sqrt{\log X}\),
\[
\sum_{p\sim X}E_p(S,T,K)
 \ll \frac{H^2K^2}{K^{\eta}}\frac1{\log X}
\]
for some fixed \(\eta>0\).

Equivalently, after conditioning on the two endpoint short returns, the long transfer parameter must have average multiplicity
\[
\ll K^{-\eta}
\]
relative to the trivial bridge count.

This is precisely the missing long-transfer theorem: neither incidence bounds with generic \(p^{3/2}\) strength nor orbit energy provides this saving.

## Conclusion

The current package (A)-(F) improves the unconditional region substantially, but it does not close weak-DPLS. The obstruction is not a bookkeeping loss: the remaining long-bridge regime requires a new arithmetic nonconcentration theorem for Apéry transfer matrices. Standard Vinh/Rudnev incidence estimates stop at the wrong exponent because their square-root cancellation scale is weaker than the missing factor of p after conditioning on the two short-chain endpoints.
