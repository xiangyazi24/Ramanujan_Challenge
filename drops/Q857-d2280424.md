# Q857: Dependency-map recovery and hostile audit

## (1) Verdict

The proposed short-arc -> Fejer -> dispersion -> pointwise chain is **not valid as currently stated**. The obstruction is not the Fejer identity or the short-arc normalization; it is the transition from a weighted average over `k` to a pointwise estimate for every index `n`.

The chain has a genuine gap:

```
short-arc uniformity
        |
        v
Fejer identity
        |
        v
weighted dispersion average over k
        |
        X
pointwise W(n)=o(n)
        |
        v
all-index goal
```

The missing edge is average-to-pointwise conversion.

## (2) Normalization audit

### Short arc

The usable statement must have the form:

```
for every P,M with sqrt(M)<P<=M,
ShortArc(P,M) <= E(P,M)
```

with all constants uniform in both variables. A statement for a selected sequence of `(P,M)` is insufficient.

### Fejer identity

The Fejer step is an exact identity. It does not create savings. It converts the short-arc expression into a weighted Fourier/dispersion quantity. Therefore any later saving must come from the dispersion estimate, not from Fejer.

### Dilation

The substitution `M=4N` is only a scale normalization. It preserves the dyadic ranges but does not change quantifiers:

```
all k in (N,2N]
```

is still required after dilation.

## Weighted dispersion step

The claimed estimate has the shape

```
sum_{N<k<=2N} |D_P(k)|^2 << N^{1+o(1)} Q_P.
```

This is an L2 average in `k`.

It implies only:

```
number of exceptional k with |D_P(k)|>T
 <= N^{1+o(1)}Q_P/T^2.
```

It does not imply:

```
|D_P(n)|=o(n) for every n.
```

Taking one summand from an average is invalid. A single `k` can carry the whole allowed mass.

## Prime range audit

The delicate range

```
P in (sqrt(N),2 sqrt(N)]
```

is exactly where this failure matters. The condition

```
Z(p)<<p^(2/3)
```

controls the number of possible shifts/residues for an individual prime. It does not provide equidistribution of those shifts among every `k`.

Similarly:

* log weights can normalize the dyadic sum;
* dyadic summation combines shells;
* neither produces pointwise cancellation.

## Correct theorem statement

A corrected replacement is:

> For every dyadic `N` and every admissible prime parameter `P` with `sqrt(N)<P<=N`, assume the uniform short-arc estimate. Then the exact Fejer identity gives the weighted dispersion estimate
>
> ```
> sum_{N<k<=2N}|D_P(k)|^2 <= N^{1+o(1)} Q_P.
> ```
>
> Consequently, for every threshold `T`, the exceptional set satisfies
>
> ```
> #{k in (N,2N] : |D_P(k)|>T}
> <= N^{1+o(1)}Q_P/T^2.
> ```
>
> A separate exceptional-set elimination or higher-moment estimate is required to deduce an all-index statement.

This is the strongest statement supported by the chain.

## SDC and anchored counterexample audit

The anchored counterexample is valid against the claimed implication. Construct a sequence with one exceptional `k0` satisfying

```
|D_P(k0)|^2 ~ N^{1+o(1)}Q_P
```

and all other terms small. The L2 estimate still holds, but the pointwise claim fails.

Therefore SDC cannot be accepted as a proof of the missing edge unless it explicitly adds a pointwise or anti-concentration hypothesis.

## Fatal error

The fatal error is:

        |

(single fixed k bound)
```

This is an invalid quantifier swap.

The corrected dependency map must keep the dispersion theorem as an averaged statement and add a separate pointwise mechanism before claiming the all-index goal.
