# Cold audit of the CRT/Erdos-Turan load proposition

## Verdict

The proposition is **false as stated**. The first Fourier step is not a valid application of the classical Erdos-Turan inequality because the points do not form an arbitrary multiset of points with a common notion of additive discrepancy independent of the denominators. The later load consequences also contain a separate uniformity gap. Some parts (B,C,E) are correct observations, but they do not repair the main implication.

## A. Erdos-Turan with varying denominators

The Erdos-Turan inequality applies to a finite multiset of points
\[
\alpha_1,\dots,\alpha_N\in[0,1)
\]
with exponential sums
\[
S(h)=\sum_j e(h\alpha_j).
\]
The issue is not that the denominators vary: that alone is harmless. Here the CRT lifts do give a finite multiset of real points
\[
\alpha_{p,q,r,a,b,c}=y/(pqr).
\]
Thus Erdos-Turan can be applied to this multiset.

However, the proposed conclusion uses the geometric fact \(y<X^2\), while Erdos-Turan controls intervals in the circle. The correct bound is for
\[
\#\{\alpha<1/X\},
\]
which indeed gives
\[
\frac{N_{trip}}X+\frac{N_{trip}}H+\sum_{h\le H}|W(h)|/h.
\]
So the Fourier step itself is valid only after replacing the argument by the circle interval event. It does not prove anything about CRT structure beyond that event.

## B. Necessity versus equivalence

The implication
\[
y<X^2\implies y/(pqr)<1/X
\]
is correct because \(pqr>X^3\).

The reverse implication is false. The event \(\alpha<1/X\) means
\[
y<pqr/X,
\]
and since \(pqr/X\asymp X^2\) only up to constants, many CRT lifts with
\[
X^2\le y<pqr/X
\]
are counted by Erdos-Turan but are not in \(A_X\).

Therefore the displayed Erdos-Turan estimate is an upper bound for a larger set. This is acceptable for proving \(A_X=o(P^3)\), because
\[
A_X\le \#\{\alpha<1/X\},
\]
but it cannot identify the actual geometry of small lifts.

## C. Triple counting identity

This identity is correct.

For each unordered triple of distinct primes \(p,q,r\), and residues \((a,b,c)\), there is a unique CRT lift modulo \(pqr\). Since
\[
pqr>X^3>X^2,
\]
there is at most one representative below \(X^2\).

Now \(K_X(m)\) counts primes whose residue set contains \(m\bmod p\). The falling factorial
\[
(K_X(m))_3=K_X(m)(K_X(m)-1)(K_X(m)-2)
\]
counts ordered triples of distinct primes. Hence
\[
\sum_{m<X^2}(K_X(m))_3=6A_X
\]
provided \(A_X\) counts unordered prime triples and all residue choices. This part is exact.

## D. Maximum load does not splice automatically

From
\[
\sum_{m<X^2}(K_X(m))_3=o(P^3)
\]
one obtains only
\[
\max_{m<X^2}K_X(m)=o(P)
\]
for each fixed X, because a single value with load \(\delta P\) contributes \(\gg \delta^3P^3\).

The missing quantifier is uniformity. The required Apéry conclusion needs:

for every sufficiently large n and every relevant dyadic block X,
\[
\sup_{m<X^2}K_X(m)\le \varepsilon(X)P_X,
\qquad \varepsilon(X)\to0.
\]

Even granting this, the weighted splice is not automatic. The argument uses a sum of the form
\[
\sum_X \varepsilon(X)X.
\]
A pointwise little-o in X does not by itself imply the dyadic sum is \(o(n)\). One needs a quantitative rate or a summation lemma. For example \(\varepsilon(X)=1/\log\log X\) is still enough after a logarithmic number of blocks, but an arbitrary little-o sequence concentrated on selected blocks is not.

The block nearest \(\sqrt n\) is especially problematic because the number of blocks is not the only issue: the local error must be compared with the target linear scale n.

## E. M1 is insufficient for the claimed Fourier bounds

M1 says
\[
\sum_{p\in P_X}|Z_p|=O(P).
\]
Therefore
\[
N_{trip}=\sum_{p<q<r}|Z_p||Z_q||Z_r|=O(P^3).
\]
This is valid.

But it gives no pointwise bound
\[
|Z_p|=O(1).
\]
One prime may have \(|Z_p|\asymp P\) while others are tiny, without violating M1. Therefore any later argument requiring uniform control of individual local sets is not justified.

## Explicit countermodel to the full implication

Take a subsequence of dyadic intervals and choose a set of primes \(S_X\subset P_X\) of size \(P/\log X\). Define
\[
Z_p=\mathbb F_p\quad(p\in S_X),
\]
and \(Z_p=\varnothing\) otherwise.

Then
\[
\sum_p |Z_p|\asymp (P/\log X)X,
\]
so after thinning \(S_X\) further to size \(P/X\), M1 holds while a small exceptional family carries all local mass.

All CRT triples supported on this family create highly concentrated loads at many integers. Fourier cancellation can still hold because the exceptional family contributes only a negligible fraction of all triples after normalization, while the maximum load on exceptional integers is large.

Hence
\[
\text{Fourier smallness of }W(h)
\]
does not imply the uniform maximum-load statement needed later.

## What is repairable

The valid repaired proposition is:

If one assumes the quantitative bound
\[
\sup_{m<X^2}K_X(m)\le \epsilon(X)P_X
\]
with
\[
\sum_{j\ge0}\epsilon(2^jX)2^jX=o(X),
\]
then the dyadic splice follows.

This assumption is essentially a strong three-point anti-concentration theorem. It is not implied by the stated Fourier hypothesis plus M1.

Therefore the final verdict is:

**The CRT identity and Erdos-Turan upper bound are correct. The claimed route from them to the all-index Apéry gcd estimate is false because the needed uniform anti-concentration does not follow from the hypotheses.**
