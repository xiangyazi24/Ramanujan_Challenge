## Verdict

The combinatorial half of option **(A)** is available and is sharper than the fixed-block triple inequality: there is an exact shifted/sliding-window estimate that replaces the local triple count by a **marked two-zero mass**. But the present arithmetic inputs do not bound that mass. The first attempted arithmetic step fails exactly because a two-zero gap supplies only one moving-root equation; reflection supplies the same equation, not an independent eliminant. On the reflected seam the gap continuant has a forced linear factor, so the natural resultant is identically zero, and even dividing out that factor is not valid for genuine Apéry zero pairs.

Therefore the theorem-ready outcome is **(B), with the useful combinatorial half of (A) banked**:

1. For every prime `p` and window length `H`, define the triangularly weighted marked pair mass
   \[
   \mathcal M_p(H)
   :=\sum_{\substack{0\le r<s<p\\r,s\in Z_p\\s-r<H}}
      \left(1-\frac{s-r}{H}\right).
   \]
   Then
   \[
   \boxed{
   Z(p)(Z(p)-1)
   \ll \left(\frac pH+1\right)^2
      +\left(\frac pH+1\right)\mathcal M_p(H).
   }
   \tag{SW}
   \]
   This is a rigorous sliding-window/two-zero inequality.

2. Summing over `X<p<=2X`,
   \[
   \boxed{
   F_2(X)
   \ll \frac{X^3}{H^2\log X}
      +\frac XH\,\mathcal M_X(H),
   \qquad
   \mathcal M_X(H):=\sum_{X<p\le2X}\mathcal M_p(H).
   }
   \tag{SW-X}
   \]

3. Consequently, a genuine power improvement over the current
   \[
   F_2(X)\ll X^{11/5}(\log X)^{-3/5}
   \]
   would follow from **any** `H=X^alpha` with
   \[
   \frac25<\alpha\le\frac12
   \]
   together with the marked-pair estimate
   \[
   \boxed{
   \mathcal M_X(H)
   \ll X^{6/5+\alpha-\delta}(\log X)^{-3/5}
   }
   \tag{PAIR}_{\alpha,\delta}
   \]
   for some `delta>0`.
   At the maximal clean scale `H=X^{1/2}`, it is enough to prove
   \[
   \boxed{
   \mathcal M_X(X^{1/2})
   \ll X^{17/10-\delta}(\log X)^{-3/5}.
   }
   \tag{PAIR}_{1/2}
   \]
   A natural packing-scale theorem
   \[
   \mathcal M_X(H)\ll \frac{X^{2+o(1)}}{H\log X}
   \tag{PAIR-pack}
   \]

Reflection, no adjacency, the qualitative gap-polynomial implication, endpoint/window Boolean information, and the existing triple-resultant valuation ledger do **not** imply any estimate of this strength. There is an exact abstract countermodel with `T_p(H)=0` but `Z(p)asymp p/H` and hence `Z(p)(Z(p)-1)asymp p^2/H^2`, even after allowing every sliding window.

# 2. The marked two-zero/sliding-window inequality is rigorous

This is the positive part of option (A).

Fix one odd prime `p` and an integer `H>=2`. For each shift
\[
\theta\in\{0,1,\ldots,H-1\},
\]
partition the ordinary interval `[0,p)` by the integer grid
\[
\theta+jH
\]
and clip the two end pieces at `0` and `p`. Let the resulting blocks be
\[
I_{\theta,j},
\]
let
\[
z_{\theta,j}:=|Z_p\cap I_{\theta,j}|,
\]
and let
\[
B_\theta:=\#\{I_{\theta,j}\}.
\]
Uniformly,
\[
B_\theta\le \left\lceil\frac pH\right\rceil+1=:B_*.
\tag{2.1}
\]
Define the number of marked pairs captured by this shifted partition,
\[
D_{p,\theta}(H):=\sum_j\binom{z_{\theta,j}}2.
\tag{2.2}
\]

## Lemma 2.1 — fixed-shift pair inequality

For every shift `theta`,
\[
\boxed{
Z(p)(Z(p)-1)
\le B_\theta^2+4B_\theta D_{p,\theta}(H).
}
\tag{2.3}
\]

### Proof

For every integer `z>=0`,
\[
z^2\le1+4\binom z2,
\tag{2.4}
\]
because the difference of the right side and the left side is
\[
1+2z(z-1)-z^2=(z-1)^2\ge0.
\]
By Cauchy,
\[
Z(p)^2
=\left(\sum_jz_{\theta,j}\right)^2
\le B_\theta\sum_jz_{\theta,j}^2.
\]
Using (2.4),
\[
Z(p)^2
\le B_\theta
\left(B_\theta+4D_{p,\theta}(H)\right).
\]
Since `Z(Z-1)<=Z^2`, (2.3) follows. `square`

This inequality is already adapted to the singleton/doubleton issue: a singleton block costs only the baseline `B^2`; every doubleton or higher block contributes to an explicit marked pair count.

## Lemma 2.2 — exact shift average

For two marked zeros `r<s`, put `d=s-r`. If `d<H`, the pair lies in the same block for exactly `H-d` of the `H` shifts; if `d>=H`, it never lies in the same block. Therefore
\[
\boxed{
\frac1H\sum_{\theta=0}^{H-1}D_{p,\theta}(H)
=
\sum_{\substack{r<s\\r,s\in Z_p\\s-r<H}}
\left(1-\frac{s-r}{H}\right)
=:\mathcal M_p(H).
}
\tag{2.5}
\]

The clipping at `0` and `p` causes no correction: whether a pair is split is determined by whether an internal grid boundary occurs between the two integers, and over one complete residue class of shifts exactly `d` shifts have such a boundary.

Averaging (2.3) over `theta` and using `B_theta<=B_*` gives
\[
\boxed{
Z(p)(Z(p)-1)
\le
B_*^2+4B_*\mathcal M_p(H).
}
\tag{2.6}
\]
This is (SW).

# 3. Average consequence and exact exponent threshold

Put
\[
\mathcal M_X(H)
:=\sum_{X<p\le2X}\mathcal M_p(H).
\tag{3.1}
\]
For `H<=X`, one has `B_*<<X/H`. Summing (2.6) and using the same dyadic prime-count factor as the current proof gives
\[
\boxed{
F_2(X)
\ll
\frac{X^3}{H^2\log X}
+
\frac XH\mathcal M_X(H).
}
\tag{3.2}
\]

This is the exact place where a marked-pair arithmetic theorem would improve the current argument.

Take
\[
H=X^\alpha,
\qquad \frac25<\alpha\le\frac12.
\]
The singleton floor in (3.2) has power
\[
3-2\alpha<\frac{11}{5}.
\tag{3.3}
\]
If for some `delta>0`
\[
\mathcal M_X(H)
\ll
X^{6/5+\alpha-\delta}(\log X)^{-3/5},
\tag{3.4}

then the second term is
\[
\frac XH\mathcal M_X(H)
\ll
X^{11/5-\delta}(\log X)^{-3/5}.
\tag{3.5}
\]
Thus (3.2) gives a genuine power improvement over `11/5`.

At the largest clean scale `H=X^{1/2}`, the first term is only

\frac{X^2}{\log X},

\[
\boxed{
\mathcal M_X(X^{1/2})
\ll X^{17/10-\delta}(\log X)^{-3/5}

\tag{3.6}

\mathcal M_X(H)

\frac XH\mathcal M_X(H)

F_2(X)\ll X^{2+o(1)}.
\tag{3.8}

So there is no combinatorial obstruction to improving `11/5`; the missing object is exactly `M_X(H)`.

# 4. Why the existing triple ledger does not bound the marked-pair mass

For one block with `z` zeros,
\[
\binom z2
\ll
1+\binom z3^{2/3}.
\tag{4.1}
\]
Therefore, for any shifted partition,
\[
D_{p,\theta}(H)
\ll
B_\theta
+B_\theta^{1/3}
\left(\sum_j\binom{z_{\theta,j}}3\right)^{2/3}.
\tag{4.2}
\]
The triple argument bounds the last sum by `T_p(H)`. Substituting (4.2) into (2.3) gives
\[
Z(p)^2
\ll
B_\theta^2
+B_\theta^{4/3}T_p(H)^{2/3},
\tag{4.3}
\]
which is exactly the old triple-block shape.

After summing over primes and applying Holder to the `2/3` power, (1.1) reproduces (1.2). Thus **sliding the windows without a new pair estimate merely reconstructs the existing `11/5` proof**. It cannot change the power by itself.

This is the first exact failure of a purely combinatorial repair.

# 5. First failed arithmetic step: a doubleton gives only one equation

Suppose `r,r+d in Z_p`, with a nonsingular interval and `d>=2`. The current gap machinery gives
\[
\boxed{N_d(r)\equiv0\pmod p.}
\tag{5.1}
\]
No adjacency only says `d!=1`; it gives no second vanishing equation.

A three-zero pattern
\[
r<r+d<r+d+e
\]
is different. It gives
\[
N_d(r)=0,
\qquad
N_e(r+d)=0
\pmod p,
\tag{5.2}
\]
so the moving residue can be eliminated by the nonzero characteristic-zero resultant
\[
\operatorname{Res}_x(N_d(x),N_e(x+d)).
\]
That is why the current arithmetic ledger starts at triples.

For a doubleton, the obvious idea is to use reflection as the second row. But the pushed `meso_result.tex` proves the exact identity
\[
\boxed{
N_d(-x-d-1)=(-1)^{d-1}N_d(x).
}
\tag{5.3}
\]
If the reflected pair begins at
\[
r'=p-1-r-d\equiv-r-d-1\pmod p,
\]
then (5.3) says
\[
N_d(r')=(-1)^{d-1}N_d(r).
\tag{5.4}
\]
So reflection contributes **the same polynomial equation**. The two rows have rank one before reduction modulo `p`; their resultant is identically zero.

This is the precise reason reflection does not turn a marked two-zero event into a valuation certificate.

# 6. The reflected endpoint seam is even more degenerate

For a noncentral reflected zero pair, write the lower endpoint as `t` and the reflected gap as
\[
h=p-1-2t.
\]
Then `h` is even and
\[
2t+h+1=p.
\tag{6.1}
\]
The reflection identity forces a characteristic-zero factorization
\[
\boxed{
N_h(x)=(2x+h+1)C_h(x),
\qquad C_h(x)\in\mathbb Z[x].
}
\tag{6.2}
\]
Hence
\[
N_h(t)=pC_h(t)
\tag{6.3}
\]
for **every** integer `t` satisfying (6.1), whether or not `b_t` is zero modulo `p`.

Thus the most tempting endpoint eliminant
\[
\operatorname{Res}_x(N_h(x),2x+h+1)
\]
is exactly zero. The `p`-divisibility on the seam is structural and carries no Apéry-zero information.

Nor can one simply divide out the seam and assert another `p`. The already banked exact example
\[
(p,t,h)=(17,3,10)
\]
is a genuine Apéry zero pair: `17|b_3` and the reflected endpoint is also a zero. Yet the exact recurrence computation gives
\[
N_{10}(3)\equiv34=2\cdot17\pmod{17^2}.
\tag{6.4}
\]
Since `2t+h+1=17`, (6.2) implies
\[
C_{10}(3)\equiv2\not\equiv0\pmod{17}.
\tag{6.5}
\]
So a genuine two-zero reflection pair does **not** force the quotient seam factor to vanish modulo `p`.

This kills the smallest natural attempt to manufacture the missing pair certificate from reflection/endpoint data.

# 7. Endpoint Boolean information does not supply an algebraic row

A sliding block containing exactly two marked zeros knows additional Boolean facts, for example:

- the interval before the first mark contains no zero;
- the interval between the two marks contains no further zero;
- the interval after the second mark contains no zero;
- a chosen block endpoint itself is or is not marked.

These are useful for defining **first-return** or **adjacency** events, but they are nonvanishing/absence conditions. They do not produce a second polynomial vanishing at the moving residue `r`.

In algebraic language, a doubleton condition is locally closed:
\[
N_d(r)=0
\quad\text{plus several unit conditions}.
\]
A resultant eliminates simultaneous vanishing equations; it cannot turn the absence conditions into a new nonzero integer without an additional arithmetic identity. Reflection merely returns (5.3), and the seam factorization (6.2) shows that even the endpoint relation is already contained in the same component.

Therefore the first failed step is not Holder, block placement, or exponent optimization. It is:

one gap equation N_d(r)=0
        |
        X   no second independent characteristic-zero equation
        |
        v
no nonzero fixed integer resultant / valuation budget

# 8. Exact scoped countermodel

The following is a countermodel to any deduction that uses only

1. reflection symmetry of the marked set;
2. no adjacent marks;
3. the qualitative rule that a marked pair carries a gap-support label;
4. the reflection symmetry of that gap support;
5. triple witnesses only when two compatible gap labels meet with total span at most `H`;
6. the triple valuation ledger.

It is **not** claimed to be an actual Apéry zero set. Its purpose is to show that the listed information, by itself, cannot imply a better second-factorial bound.

Fix an odd `p` and `H>=4`, with `p>>H`. Put
\[
s:=\left\lfloor\frac H2\right\rfloor+1,
\qquad
c:=\frac{p-1}{2},
\qquad
m:=\left\lfloor\frac{c-1}{s}\right\rfloor,
\]
and define
\[
\boxed{
Z^*_{p,H}:=\{c-js,c+js:1\le j\le m\}.
}
\tag{8.1}
\]

## 8.1 Reflection and endpoints

The involution `r -> p-1-r` exchanges `c-js` and `c+js`, so `Z^*` is exactly reflection invariant. By the definition of `m`, neither `0` nor `p-1` is marked.

## 8.2 No adjacency

Since `s>=3`, distinct marks are never consecutive.

## 8.3 Every H-window contains at most two marks

On either side of the center, consecutive marks are separated by `s`. Across the omitted center the gap is `2s`. Any three marks therefore have outer span at least
\[
2s>H.
\tag{8.2}
\]
Hence no interval of `H` consecutive integers contains three marks.

This remains true for **every sliding window**, not just one fixed block partition.

## 8.4 Triple ledger is identically zero

Introduce the abstract gap-support relation
\[
R_d^*(r)\iff r,r+d\in Z^*_{p,H}.
\tag{8.3}
\]
It has the same reflection rule as the actual gap support:
\[
R_d^*(r)
\iff
R_d^*(p-1-r-d).
\tag{8.4}
\]
If there were compatible supports
\[
R_d^*(r),
\qquad
R_e^*(r+d),
\qquad
 d+e\le H,
\]
then `r,r+d,r+d+e` would be three marks of total span at most `H`, contradicting (8.2). Thus every triple-witness count is zero:
\[
\boxed{T_p^*(H)=0.}
\tag{8.5}
\]

## 8.5 But the second factorial moment has the full floor size

Since `s=H/2+O(1)`,
\[
|Z^*_{p,H}|=2m\asymp \frac pH.
\]
Therefore
\[
\boxed{
|Z^*_{p,H}|(|Z^*_{p,H}|-1)
\asymp \frac{p^2}{H^2}.
}
\tag{8.6}
\]
The short adjacent marked pairs on each side have gap `s<H`, and their triangular weight is
\[
1-s/H\asymp1.
\]
Consequently
\[
\mathcal M_p^*(H)\asymp \frac pH,
\tag{8.7}
\]
and the second term in (SW) is also
\[
\frac pH\mathcal M_p^*(H)
\asymp\frac{p^2}{H^2}.
\]
So the sliding inequality is sharp on this model.

At the aggregate level, inserting the same dyadic prime-count factor used in the present proof gives exactly the old floor
\[
\frac{X^3}{H^2\log X}.
\tag{8.8}
\]
At
\[
H\asymp X^{2/5}(\log X)^{-1/5},
\]
this is
\[
X^{11/5}(\log X)^{-3/5}.
\]
Thus the singleton/doubleton barrier can saturate the current exponent while the entire triple ledger is zero.

That is the desired scoped no-go.

# 9. Why no choice of shifted blocks repairs the countermodel

A possible objection is that the original floor uses one arbitrary partition, whereas a doubleton in one partition could become part of a triple after shifting the block boundaries.

The countermodel above was chosen to defeat exactly this idea. Because **every three marks have span greater than `H`**, no length-`H` interval in any shift contains a triple. Hence
\[
\sum_j\binom{z_{\theta,j}}3=0
\]
for every `theta`.

The pair mass is nevertheless nonzero for a positive proportion of shifts, exactly as (2.5) records. Therefore sliding windows expose the correct missing statistic `M_p(H)` but do not provide its arithmetic estimate.

# 10. The smallest extra arithmetic input

The exact missing estimate can be stated without introducing any new polynomial formalism.

For `2<=d<H`, define
\[
A_{p,d}
:=\#\{0\le r<p-d:r,r+d\in Z_p\}.
\tag{10.1}
\]
Then
\[
\mathcal M_p(H)
=\sum_{2\le d<H}\left(1-\frac dH\right)A_{p,d},
\tag{10.2}
\]
where `d=1` is absent by no adjacency.

Therefore the minimal new arithmetic problem is:

> **Marked two-zero average problem.** Bound
> \[
> \boxed{
> \sum_{X<p\le2X}
> \sum_{2\le d<H}
> \left(1-\frac dH\right)
> \#\{r:r,r+d\in Z_p\}
> }
> \tag{10.3}
> \]
> at a scale stronger than `H X^{6/5}` when `H>X^{2/5}`; equivalently prove (3.4) for some `alpha>2/5` and `delta>0`.

This is genuinely weaker than demanding a pointwise bound for every `A_{p,d}` and genuinely stronger than the current triple-resultant ledger.

An equivalent arithmetic input would be a characteristic-zero certificate `C_{d,r}` for each marked pair with the following two properties:

1. every marked two-zero event forces `p|C_{d,r}` (or contributes a controlled `p`-adic valuation);
2. the aggregate logarithmic height/valuation ledger for those certificates implies (3.4).

The present reflection equation cannot be that certificate because of (5.3), and the reflected seam quotient cannot be that certificate because of (6.5).

# 12. Scope of the no-go

The no-go proved here is deliberately narrow.

It rules out a power improvement obtained **only** by recombining:

```text
reflection of Z_p
+ no adjacent zeros
+ the one-gap implication N_d(r)=0
+ endpoint/sliding-window Boolean data
+ reflection of the gap polynomial
+ the existing triple-resultant valuation ledger
```

because those data permit the model in Section 8 and because reflection does not create a second algebraic row.

It does **not** rule out any of the following genuinely new inputs:

- a mod-`p^2` lift of a two-zero gap that survives division by the forced seam factor;
- a derivative/transversality theorem distinguishing genuine marked roots of `N_d` from structural roots;
- a first-return/adjacency arithmetic carrier with controlled height;
- an average theorem for the marked root counts `A_{p,d}`;
- a second independent polynomial attached to the same two endpoints;
- a global argument coupling different primes rather than eliminating the moving residue one prime at a time.

Any one of these could reopen option (A). What is excluded is the claim that the current qualitative identities already contain the needed pair certificate.

# 13. Theorem-ready statement to bank

## Theorem — sliding marked-pair reduction and singleton/doubleton no-go

Let
\[
Z_p=\{0\le r<p:p\mid b_r\},
\qquad
F_2(X)=\sum_{X<p\le2X}|Z_p|(|Z_p|-1).
\]
For `2<=H<=X^{1/2}` define
\[
\mathcal M_p(H)
=\sum_{\substack{r<s\\r,s\in Z_p\\s-r<H}}
\left(1-\frac{s-r}{H}\right),
\qquad
\mathcal M_X(H)=\sum_{X<p\le2X}\mathcal M_p(H).
\]
Then
\[
\boxed{
F_2(X)
\ll
\frac{X^3}{H^2\log X}
+
\frac XH\mathcal M_X(H).
}
\tag{13.1}
\]
Consequently, if for some `2/5<alpha<=1/2` and `delta>0`, at `H=X^alpha`,
\[
\mathcal M_X(H)
\ll X^{6/5+\alpha-\delta}(\log X)^{-3/5},
\]
then
\[
F_2(X)
\ll
X^{\max(3-2\alpha,\,11/5-\delta)+o(1)},
\]
which improves the current `11/5` power.

However, such a marked-pair estimate does not follow from reflection, no adjacency, one-gap polynomial support, endpoint/window Boolean information, and the triple-resultant ledger. Reflection satisfies
\[
N_d(-x-d-1)=(-1)^{d-1}N_d(x),
\]
so it provides no independent eliminant for a two-zero pair; on the reflected even-gap seam,
\[
N_h(x)=(2x+h+1)C_h(x),
\]
and the quotient is not forced to vanish modulo `p` even for genuine Apéry zero pairs. Moreover the reflected sparse model (8.1) has no triple of span at most `H`, hence zero triple ledger, while its second factorial moment is `asymp p^2/H^2` and its sliding marked-pair mass is `asymp p/H`.

Therefore the **first missing arithmetic input** is precisely a nontrivial average estimate for `M_X(H)` (or an equivalent independent two-zero certificate). The current triple-resultant framework alone cannot improve the `11/5` exponent.

# Bottom line

**Choose (B), but bank the sliding inequality from (A).** The singleton/doubleton loss is not a bad partition and is not cured by reflection or by averaging all shifts. Sliding windows identify the correct missing statistic, the triangular marked-pair mass `M_X(H)`. The present arithmetic gives no valuation ledger for it: two zeros provide one gap equation; reflection is the same equation; the endpoint seam is a forced factor; triples are the first place a second independent gap equation appears.

The smallest useful next theorem is therefore not another triple-resultant optimization. It is a marked two-zero estimate of the form
\[
\mathcal M_X(X^\alpha)
\ll X^{6/5+\alpha-\delta+o(1)}
\qquad
(2/5<\alpha\le1/2),
\]
or, ideally,
\[
\mathcal M_X(H)\ll X^{2+o(1)}/(H\log X).
\]
Without such new arithmetic, `11/5` is the exact barrier of the present reflection/no-adjacency/gap-support/triple-ledger package.
