# Q845 audit: sparse exceptional-set centered moment route

## Executive conclusion

The proposed sparse-exceptional-set route gives a valid **conditional reduction**, but no unconditional elimination of the exceptional set follows from the currently available codegree/bucket proof. The correction to Q842 is essential: the physical shell column is the canonical index `m=n`, and a PI5-selected column does not automatically satisfy the fixed-epsilon exceptional hypothesis.

The new route can only work if one proves a centered moment estimate on the actual exceptional support `E_epsilon(N)` with a baseline depending on `|E_epsilon(N)|`, not on the full interval length `N`. That estimate is not contained in the existing exceptional theorem.

---

## 1. Correct exceptional set formulation

Fix `epsilon>0` and define

```
E_epsilon(N) = { n in (N,2N] : log G_n > epsilon n }.
```

The available exceptional theorem gives

```
|E_epsilon(N)| = O_epsilon(log N)
```

per dyadic block (equivalently cumulative `O_epsilon(log^2 N)`).

The important point is that this controls only the number of indices whose shell amplification is macroscopically large. It does not imply that every PI5-selected shell index belongs to this set.

For a selected shell threshold

```
L = X^(14/15+eta),
```

one only gets approximately

```
(log G_m)/m <= X^(-1/15+eta) log X
```

for `m~X`, which tends to zero. Therefore fixed epsilon exceptional control does not directly remove all PI5 columns.

---

## 2. Conditional reduction that would suffice

A valid sufficient criterion would be:

For every fixed epsilon and fixed q, prove a centered order-k estimate on the exceptional support only:

```
 sum_{n in E_epsilon(N)} |D_q(n)|^k = o(N/log^k N)
```

(or the stronger form needed by the exact prime-shell reduction).

Here `D_q(n)` is the centered fixed-q shell contribution after the usual isolation step. The reduction pipeline is:

1. Split the physical consumer by prime shells and fixed q.
2. Isolate the bad shell columns where `log G_n > epsilon n`.
3. Center the fixed-q contribution around its singular-series mean.
4. Expand the k-th centered moment only over `E_epsilon(N)`.
5. Use the exceptional cardinality in the baseline:

```
|E_epsilon(N)| Lambda^k
```

instead of the ordinary full interval baseline

```
N^2 Lambda^k.
```

If this conditional estimate is proved with the required little-oh saving, then the exceptional contribution disappears and the remaining columns are handled by the ordinary shell estimates.

This is a genuine reduction because it changes the counting measure from all indices to the exceptional support.

---

## 3. Single-spike exponent audit

The relevant comparison is no longer

```
N^2 Lambda^k
```

but

```
|E_epsilon(N)| Lambda^k.
```

Since

```
|E_epsilon(N)| = O(log N),
```

the baseline is polylogarithmic in the number of exceptional columns.

However a single exceptional spike must also be bounded after centering. A spike of size roughly `S(N)` contributes

```
S(N)^k
```

and the criterion requires

```
S(N)^k = o(N/log^k N)
```

(or the corresponding fixed-q shell normalization).

Thus sparsity alone is not enough. The exceptional theorem supplies the support size but not the required magnitude cancellation of centered spikes.

---

## 4. Relation with prime-shell/fixed-q reduction

The fixed-q reduction remains valid:

- each bad physical column is indexed by the canonical `m=n`;
- prime shells are separated by fixed q;
- isolation removes non-isolated configurations;
- the centered variable is taken after subtracting the singular-series main term.

The missing statement is a high-moment estimate restricted to

```
n in E_epsilon(N).
```

Without it, replacing the full interval by the exceptional set is only a change of notation.

---

# A. Rigorously proved conditional part

The following implication is valid:

```
Exceptional centered moment bound on E_epsilon(N)
        +
ordinary non-exceptional shell bound
        +
fixed-q isolation reduction
        =>
all-index theorem.
```

The proof is a decomposition of the full sum into

```
(non-exceptional columns) + (exceptional columns).
```

The first part uses the existing shell estimates. The second part is reduced to the new sparse moment hypothesis.

This is conditional only; it is not an unconditional theorem.

---

# B. What follows from the current codegree/bucket exceptional proof?

Only the following pieces follow:

1. The support estimate:

```
|E_epsilon(N)| = O_epsilon(log N).
```

2. The bucket/codegree mechanism proving few large `G_n` values.

3. The isolation framework used to identify relevant shell interactions.

The existing proof does **not** provide:

- centered cancellation inside `E_epsilon(N)`;
- a kth moment estimate with baseline `|E| Lambda^k`;
- control of correlations between exceptional indices;
- elimination of single large centered spikes.

Therefore it cannot already prove the proposed criterion.

---

## Final status

- Sparse exceptional-set criterion: **VALID as a conditional reduction.**
- Claim that the criterion follows from the current exceptional theorem: **INVALID.**
- Claim that it automatically removes the exceptional set: **INVALID without a new centered moment theorem.**
- The route is genuinely new only if the proof exploits the `O(log N)` exceptional support together with centered recurrence/singular-series cancellation; otherwise it is a restatement of the existing exceptional bound.
