# 11. Does `q|b_t` define a usable trace function or Frobenius condition?

The answer from the current Apéry--Lucas source is **no, not in a form that yields the required horizontal estimate**.

## 11.1 The exact zero-set Fourier transform is tautologically trace-like only

The function

\[

can be represented as a direct sum of rank-one Artin--Schreier trace functions whose slopes are exactly the unknown zero locations `t in Z_q`.  This is a tautological sheaf realization. A singleton zero set already gives a rank-one conductor-`O(1)` trace function but can be placed on an anchored moving diagonal.  Thus “is a trace function” is not the missing theorem.

## 11.2 Exact indicator polynomial has degree `q-1`

\[
\delta_Z(X)=\sum_{a\in Z}\left(1-(X-a)^{q-1}\right),
\tag{11.1}

whose reduced degree is exactly `q-1`.  There is no bounded-degree polynomial indicator for `Z_q`.

## 11.3 The Hasse polynomial lives in the dual space

The project writes

A_q(X)=\sum_{t=0}^{q-1}b_tX^t.
\tag{11.2}

The condition `q|b_t` says

\tag{11.3}

Therefore the selected digit is a moving multiplicative-character/Mellin coordinate.  It is not an evaluation root of the Hasse polynomial and not an ordinary Frobenius trace condition on a fixed point of the family.
