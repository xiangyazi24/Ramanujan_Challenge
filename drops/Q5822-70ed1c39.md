# Q5822 direct-calculus audit of Problem 3.1

## Executive verdict

The shortest route that avoids Bloch groups, K-theory, and Suslin/Merkurjev--Suslin is **not** to prove a regulator theorem.  It is to prove a concrete four-shape Rogers differential identity on the actual deformation interval, then integrate it and evaluate endpoint values.

The existing `solution.tex` already writes the desired bridge in Neumann--Zagier language, but the Lean-relevant missing object is a fully explicit identity:

```
log x * dlog(y) - log(y) * dlog(x)
    = d( sum_i c_i * Rogers(z_i) )
```

for the four explicit shapes `z_i(x,y)` and explicit integer coefficients `c_i`.

No such coefficient-level identity is currently formalized. The current text jumps from the A-polynomial branch to a regulator statement.

## 2. Differential identity

For Rogers dilogarithm use

```
R(z) = Li_2(z) + 1/2 * log(z) * log(1-z)
```

on a fixed real domain where all logarithms are defined.

The derivative needed is

```
dR(z) = -1/2*( log(1-z) dlog(z) - log(z) dlog(1-z) ).
```

Therefore the desired certificate has the form

```
log(M) dlog(L) - log(L) dlog(M)
 = sum_i c_i dR(z_i)
```

with `i = T,U,V,W`.

After substituting `M=x`, `L=y(x)` this becomes the official one-form:

```
log(x) dy/y - log(y) dx/x
 = - sum_i c_i dR(z_i(x,y)).
```

The sign and coefficients cannot be guessed from the current repository state. They must be generated from the explicit tetrahedron shape equations and verified symbolically.

## 3. Required hypotheses

A Lean theorem needs the following explicit assumptions.

### Algebra

* `A_7_2(x,y)=0`.
* Definitions of the four shapes.
* Algebraic identities relating shapes to `(M,L)`.

### Domain

For every point of the interval:

* `0 < x`.
* `0 < y`.
* `z_i` avoid `0` and `1`.
* logarithm branches are the real principal branch.

### Analysis

* differentiability of `y`.
* differentiability of each `z_i`.
* integrability of each derivative.

### Endpoint

* exact endpoint values of all shapes.
* evaluation of the Rogers expression at endpoints.
