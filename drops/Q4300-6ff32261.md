# Q4300 — the polynomial common-radical bound

## Verdict

The full polynomial common-radical theorem is **not proved** for either sign, and therefore Q6-SLUNI remains open outside the already proved endpoint layers.

The round does, however, produce a sharp theorem and a sharper diagnosis.

1. The exact critical object is **not** the largest prime factor and not the size of the whole gcd. It is the squarefree product of common primes in a deterministic geometric shell containing the admissible lower primes.
2. The exact critical exponent of the q-free radical is **2**. A bound of order `q^(2-eta)` for any fixed `eta>0` is sufficient but stronger than necessary; the exact pointwise threshold is the product of the two smallest possible admissible primes, and the clean uniform threshold is `< P^2`.
3. A bound of this shape for the **actual selected-window radical** is asymptotically equivalent to Q6-SLUNI and is therefore only a reformulation. A genuinely new premise must control a support-blind object, for example every common prime in the entire geometric shell, before the raw masks and selected-leaf support are consulted.
4. The endpoint argument does extend layer by layer. After adding the arithmetic packing of primes, it gives an exact prime-diameter bound and the unconditional radical estimate
   
   ```text
   log R_actual  <<  (1 + W/log(2+W)) log q,
   ```
   
   where `W` is an explicit state-dependent upper bound for the diameter of the lower-prime set. At a polynomial offset `W=q^delta`, this becomes `log R_actual <<_delta W`.
5. This is still far from the required `2 log q+O(1)`. At the first deep scale `W` of order `J_*=T^(beta/6)`, the remaining multiplicative deficit in logarithmic size is
   
   ```text
   J_*/log T = T^(beta/6)/log T.
   ```
6. The old q-local unit-erasure and Fitting-height obstructions are still **not intrinsic** to the fixed-gcd statement. They return only if one tries to combine the prime-dependent local continuants into a common field or module. The direct standalone attack instead meets a different wall: the Apéry recurrence is cubic, and its first nontrivial continuant lands exactly at the critical quadratic q-free scale after the one forced q-factor is stripped.

The sharpest unconditional result of this round is stated next.

## 1. Fixed-state notation

Let

```text
b_n = sum_{k=0}^n binom(n,k)^2 binom(n+k,k)^2
```

be the Apéry numbers for zeta(3), satisfying

```text
(n+1)^3 b_{n+1}
  = (2n+1)(17n(n+1)+5)b_n - n^3 b_{n-1}.
```

Fix an odd prime `q` and a selected digit `0 <= t < q` with `q | b_t`. Put

```text
s = q-1-t.
```

Reflection gives `q | b_s`. Define the two fixed characteristic-zero gcds

```text
G_+(q,t) = gcd(b_{6q+t}, b_{12q+t}),
G_-(q,t) = gcd(b_{6q+t}, b_s),
```

and remove the complete q-primary part:

```text
G_sigma^circ(q,t)
  = G_sigma(q,t) / q^{v_q(G_sigma(q,t))}.
```

Let the relevant lower-prime interval be

```text
I = [P,P+L] subset (5,q),
P asymp_J q,
L=o(q),
D=q-P.
```

Retain all raw windows, inherited masks, primitive predicates, and the raw minus-first tie-break. Let

```text
P_sigma(q,t;I)
```

```text
K_sigma = #P_sigma(q,t;I),
R_sigma^act = product_{p in P_sigma(q,t;I)} p.
```

Every actual lower prime divides the corresponding fixed gcd, hence

```text
R_sigma^act | G_sigma^circ(q,t).
```

Finally set

```text
mu(P) = min{n >= 0 : b_n >= P},
mu_e(P) = min{n >= 0 : n == e (mod 2), b_n >= P}.
```

For the minus sign, `e == t+1 (mod 2)`.

## 2. Main theorem: critical radical exponent and endpoint-sieve bound

### Theorem (Q6-PCR-ES: polynomial-radical criticality and endpoint sieve)

With the notation above, define

```text
W_+ = min(L, max(0, (6D-2mu(P)-2)/13)),
W_- = min(L, max(0, D-t-1-mu_e(P))).
```

Let `h(k)` be the least diameter of an admissible k-tuple of integers; equivalently, the least possible diameter of the offset set of `k` sufficiently large primes. Thus

```text
h(1)=0,  h(2)=2,  h(3)=6,  h(4)=8.
```

Then the following hold pointwise for every selected state.

#### (A) Exact radical threshold

For all sufficiently large `q`,

```text
K_sigma <= 1   if and only if   R_sigma^act < P^2.
```

Consequently, for any fixed `0<eta<1`, the assertion

```text
R_sigma^act <<_J q^(2-eta)
```

is asymptotically equivalent to Q6-SLUNI. It is a useful numerical encoding, but it is not an independent mechanism.

#### (B) A genuinely stronger support-blind sufficient statement

Let `S_J(q)` be any deterministic prime shell containing every admissible lower prime and defined without using the actual leaf support. Put

```text
Rad_{S_J(q)}(G_sigma^circ)
  = product_{ell in S_J(q), ell | G_sigma^circ} ell.
```

Either of the following implies Q6-SLUNI:

```text
Rad_{S_J(q)}(G_sigma^circ) < P^2,
```

or, more strongly, for some fixed `eta>0`,

```text
Rad_{S_J(q)}(G_sigma^circ) <<_J q^(2-eta).
```

The conventional full-radical premise

```text
rad(G_sigma^circ) <<_J q^(2-eta)
```

also suffices, but is unnecessarily stronger because it charges small and geometrically irrelevant prime factors.

If one does not remove the known upper prime `q`, the corresponding critical exponent is `3` rather than `2`:

```text
rad(G_sigma) << q^(3-eta)
```

would suffice. The known q-factor therefore buys exactly one logarithmic prime unit and nothing more.

#### (C) Exact endpoint layers

For plus,

```text
K_+ <= max(0, 1 + floor((6D-2mu(P)-2)/26)),
```

with the stronger first-leaf statement

```text
6D < 2mu(P)+4  =>  K_+=0,
6D < 2mu(P)+28 =>  K_+<=1.
```

For minus,

```text
K_- <= max(0, 1 + floor((D-t-1-mu_e(P))/2)),
```

and

```text
D < t+1+mu_e(P) => K_-=0,
D < t+3+mu_e(P) => K_-<=1.
```

More generally, for every `k>=2`,

```text
K_+ >= k  =>  6D >= 2mu(P)+2+13 h(k),
K_- >= k  =>  D  >= t+1+mu_e(P)+h(k).
```

In particular, prime admissibility extends the second layer beyond the spacing-only estimate:

```text
6D < 2mu(P)+80       => K_+ <= 2,
D  < t+mu_e(P)+7     => K_- <= 2,

6D < 2mu(P)+106      => K_+ <= 3,
D  < t+mu_e(P)+9     => K_- <= 3.
```

#### (D) Sieve refinement and actual-radical bound

For `W_sigma >= 3`, Brun-Titchmarsh gives

```text
K_sigma <= 1 + 2 W_sigma/log W_sigma.
```

Uniformly, with an absolute implied constant,

```text
K_sigma << 1 + W_sigma/log(2+W_sigma).
```

Therefore

```text
log R_sigma^act
  << (1 + W_sigma/log(2+W_sigma)) log(P+L).
```

This may be combined with the fixed-gcd height bounds

```text
log R_+^act
 <= gamma(6q+t) - (3/2)log(6q+t) - log q + O(1),

log R_-^act
 <= gamma s - (3/2)log s - log q + O(1),
```

where

```text
gamma = log(17+12 sqrt(2)).
```

Thus the unconditional pointwise estimate is

```text
log R_sigma^act
 <= min(
      O((1+W_sigma/log(2+W_sigma)) log q),
      the corresponding Apéry height above
    ).
```

If `W_sigma=q^delta` with fixed `delta>0`, then

```text
log R_sigma^act <= (2/delta+o(1)) W_sigma.
```

On plus, if `D=q^delta` and the endpoint terms are negligible relative to `D`, then `W_+=(6/13+o(1))D`, so

```text
log R_+^act <= (12/(13 delta)+o(1))D.
```

On minus, in the analogous regime,

```text
log R_-^act <= (2/delta+o(1))D.
```

#### (E) Best unconditional support-blind shell radical

For the unfiltered common-prime radical in the whole interval `I`,

```text
R_sigma^shell
  = product_{ell in I, ell | G_sigma^circ} ell,
```

one always has

```text
log R_sigma^shell
 <= min(
      log G_sigma^circ,
      theta(P+L)-theta(P^-)
    )
 << min(
      Theta_J(q),
      L log q/log(2+L)
    ),
```

where `theta` is Chebyshev's function. For `L=q^delta`, this is

```text
log R_sigma^shell <<_delta L.
```

At the project cell scale `L=Lambda=T^(5beta/6)`, this gives only

```text
log R_sigma^shell <<_beta Lambda,
```

whereas Q6-SLUNI needs the two-prime threshold `2 log T+O_J(1)`.

### Proof

Every actual lower prime is a prime divisor of the fixed q-free gcd, so the divisibility `R_sigma^act | G_sigma^circ` is immediate.

Because every actual prime lies in `[P,P+L]`, two distinct actual primes have product at least `P^2`. Conversely, if there is at most one actual prime, then

```text
R_sigma^act <= P+L < P^2
```

for all sufficiently large `q`, since `P asymp_J q` and `L=o(q)`. This proves (A). Part (B) follows because the actual radical divides every support-blind shell radical that contains the admissible shell.

For the endpoint geometry, write `p=q-d`.

On plus, every actual leaf has the two lower-zero indices

```text
x=s-7d,
y=13d-s-1,
```

and hence

```text
x+y=6d-1.
```

List the actual primes as

```text
p_1 < ... < p_K,
d_i=q-p_i.
```

Then

```text
x_i=x_1+7(p_i-p_1),
y_i=y_1-13(p_i-p_1).
```

The divisibilities `p_1 | b_{x_1}` and `p_K | b_{y_K}`, with `p_i>=P`, imply

```text
x_1>=mu(P),
y_K>=mu(P).
```

The two indices have opposite parity. Since `p_K-p_1` is even, `x_1` and `y_K` also have opposite parity, and therefore

```text
x_1+y_K >= 2mu(P)+1.
```

Writing `S=p_K-p_1`,

```text
6d_1-1
  = x_1+y_1
  = x_1+y_K+13S
  >= 2mu(P)+1+13S.
```

Since `d_1<=D`,

```text
13S <= 6D-2mu(P)-2.
```

If there is one leaf, its two zero indices are opposite in parity and cannot be consecutive. Hence their sum is at least `2mu(P)+3`, giving the zero-free threshold `6D>=2mu(P)+4`.

On minus, the moving row-one zero is

```text
a=d-t-1=s-p,
a == t+1 (mod 2).
```

For the same ordering of primes,

```text
a_1-a_K=p_K-p_1=S.
```

Since `p_K | b_{a_K}` and `p_K>=P`,

```text
a_K>=mu_e(P).
```

Thus

```text
D >= d_1=t+1+a_1
  >= t+1+mu_e(P)+S.
```

This proves the displayed span bounds.

The offset set of any collection of sufficiently large primes is an admissible tuple. Therefore `S>=h(K)`. Substitution gives part (C). The values `h(2)=2`, `h(3)=6`, and `h(4)=8` are elementary: three odd primes cannot occupy offsets `0,2,4` because these cover every class modulo `3`, while the patterns `0,2,6` and `0,2,6,8` are admissible.

All primes lie in an interval of length at most `W_sigma`. Brun-Titchmarsh then gives part (D). Finally, `R_sigma^act | G_sigma^circ`, while

```text
G_+^circ <= b_{6q+t}/q,
G_-^circ <= b_s/q.
```

Using

```text
b_n = C_A (17+12sqrt(2))^n n^(-3/2)(1+O(1/n))
```

gives the height estimates. Part (E) is the same upper-bound sieve applied before any actual-leaf filtering. This completes the proof.

## 3. The exact sufficient bound: which formulation is weakest?

There are four superficially similar statements, but only two are useful as new premises.

### 3.1 Number of admissible prime divisors

```text
omega_I^act(G_sigma^circ) <= 1
```

is exactly Q6-SLUNI. It is the conclusion, not an input.

### 3.2 Product of actual admissible-window prime divisors

```text
R_sigma^act < P^2
```

is also exactly Q6-SLUNI for large `q`. Likewise, any fixed-power estimate

```text
R_sigma^act << q^(2-eta),  0<eta<1,
```

is equivalent to Q6-SLUNI because one actual prime costs `q^(1+o(1))` and two cost `q^(2+o(1))`.

This is the **equivalence trap**. Calling this estimate a premise does not explain why it is true.

### 3.3 Support-blind geometric-shell radical

The weakest clean premise that is genuinely stronger than Q6-SLUNI is

```text
Rad_{S_J(q)}(G_sigma^circ) < P^2,
```

where `S_J(q)` is fixed before the common-prime support and contains every geometrically admissible lower prime, but does not impose the two Apéry-zero conditions or the inherited masks.

This statement can fail even when Q6-SLUNI holds, because the fixed gcd may have several unselected common primes in the shell. It is therefore strictly stronger, not equivalent.

In exponent language, the critical exponent is `2`. Any of the following closes:

```text
Rad_{S_J(q)}(G_sigma^circ) = o_J(q^2),
Rad_{S_J(q)}(G_sigma^circ) <<_J q^2/log q,
Rad_{S_J(q)}(G_sigma^circ) <<_J q^(2-eta).
```

A fixed power saving is convenient but not necessary. The exact numerical threshold is `<P^2`.

### 3.4 Full q-free radical

```text
rad(G_sigma^circ) << q^(2-eta)
```

is a conventional polynomial common-radical theorem and is sufficient, but it may be much harder than needed. It charges small primes, primes far above the lower shell, and primes failing every q6 raw predicate.

### 3.5 Largest prime factor

An upper bound

```text
P^+(G_sigma^circ) < P
```

would prove complete fibre-freeness, not merely uniqueness, and is unnecessarily strong. A bound on the second-largest shell prime is just the shell-uniqueness conclusion in another form. A lower bound on the largest prime factor gives no control on the number of shell factors.

Hence the radical product, truncated to a deterministic shell and not to the actual support, is the correct weakest quantitative object.

## 4. How far is the desired polynomial theorem from what is known?

### 4.1 The trivial fixed-gcd height

For plus,

```text
log rad(G_+^circ)
 <= gamma(6q+t) - (3/2)log(6q+t) - log q + O(1).
```

For minus,

```text
log rad(G_-^circ)
 <= gamma s - (3/2)log s - log q + O(1).
```

On an actual minus leaf, `s>=p>=P asymp_J q`, so this is also `Theta_J(q)`.

Two admissible lower primes cost

```text
2 log P = 2 log q + O_J(1).
```

Thus the additive gap between the available fixed-gcd height and the two-prime cost is

```text
plus:  gamma(6q+t) - (9/2)log q + O_J(1),
minus: gamma s       - (9/2)log q + O_J(1),
```

which is `Theta_J(q)` in the hard range. In multiplicative terms on logarithmic size, the available bound is too large by a factor

```text
Theta_J(q/log q).
```

To prove a fixed-power PCRB with exponent `2-eta`, the required upper bound is

```text
log Rad <= (2-eta)log q+O_J(1).
```

The saving required from the trivial height is still an additive `Theta_J(q)`.

### 4.2 Even the repository's full subexponential gcd target is insufficient

The repository records the broad Apéry gcd target in the form

```text
G_n = e^{o(n)}.
```

Even gifting an analogous estimate for the present fixed gcd would not prove Q6-SLUNI. A quantity such as `exp(sqrt(q))` is subexponential but is much larger than every fixed power of `q`. The present theorem requires

```text
log Rad = O(log q),
```

not merely `o(q)`.

This is why Bugeaud-Corvaja-Zannier-type subexponential gcd bounds, even if they applied to the Apéry sequence—which they do not—would still miss the required scale.

### 4.3 Deficit after exploiting endpoint geometry

The endpoint-sieve theorem is substantially stronger in the mesoscopic sector.

If `W=q^delta`, it proves

```text
log R_actual <<_delta W,
```

while the desired pair-excluding scale is `2 log q+O(1)`. The remaining factor is

```text
W/log q.
```

At the first deep project scale

```text
W asymp J_* = T^(beta/6),
```

the missing factor is exactly

```text
T^(beta/6)/log T.
```

At the full cell scale `Lambda=T^(5beta/6)`, the support-blind shell estimate misses by

```text
T^(5beta/6)/log T.
```

For a logarithmic but nonconstant span `W asymp log q`, Brun-Titchmarsh gives

```text
log R_actual << (log q)^2/log log q,
```

so the remaining factor is `log q/log log q`.

Only when the allowed prime diameter is bounded—and in particular below `2`—does the endpoint argument reach uniqueness.

## 5. What exactly stops the layer-by-layer extension?

The endpoint theorem is not exhausted after its first layer. The prime-diameter form gives the complete continuation available from positivity, reflection, parity, no-consecutive zeros, and primality.

On plus, `K>=k` forces

```text
6D >= 2mu(P)+2+13h(k).
```

On minus,

```text
D >= t+1+mu_e(P)+h(k).
```

The first possible pair occurs at `h(2)=2`. At that point the radical has only the critical estimate

```text
R_actual <= (P+L)^2 = q^(2+o(1)).
```

There is no strict subquadratic margin.

The obstruction is not a long prime progression. It is a single admissible two-point pattern. On plus, the abstract extremal coordinates for a gap-two pair may be taken in the form

```text
x_1=mu,
y_1=mu+27,
x_2=mu+14,
y_2=mu+1,
```

which respect opposite parity and no-consecutive-zero spacing. On minus, two primes at distance `2` give two values of `a=s-p` at distance `2`, both compatible with the endpoint inequalities. These are interface configurations, not claimed actual Apéry leaves, but they prove that the endpoint data do not contradict a pair.

Prime admissibility helps only from the third prime onward: three large primes cannot fit into diameter `4`, so `h(3)=6`. That enlarges the `K<=2` layer but does not remove its possible pair. Thus the exact residual is a **two-prime horizontal support theorem**. No amount of generic prime packing can settle it.

The raw windows give slightly sharper state-dependent diameter intervals. Every plus leaf has

```text
(s+1+mu(P))/13 <= d <= (s-mu(P))/7,
```

and every minus leaf has

```text
t+1+mu_e(P) <= d <= s/7.
```

Intersecting these with the cell interval `d in [D-L,D]` can shrink `W_sigma`, but it does not change the pair barrier once the intersection has diameter at least `2`.

## 6. Recurrence and continuant attack

The fixed-gcd formulation genuinely escapes unit erasure, so the recurrence deserves a fresh standalone audit. The audit yields a precise critical-degree obstruction rather than the old formal one.

### 6.1 Exact transfer polynomial

The repository defines

```text
P(n)=34n^3+51n^2+27n+5,
N_0(x)=0,
N_1(x)=1,
N_{h+1}(x)=P(x+h)N_h(x)-(x+h)^6N_{h-1}(x).
```

For

```text
Y_h = ((r+h)!/r!)^3 b_{r+h},
```

the exact transfer identity is

```text
Y_h
 = N_h(r)Y_1
   -(r+1)^6 N_{h-1}(r+1)Y_0.
```

Hence, across a nonsingular interval, a prime dividing both endpoint Apéry values and not the adjacent value divides `N_h(r)`. This is the correct local common-divisor carrier.

### 6.2 The cubic critical barrier

The degree is

```text
deg N_h = 3(h-1).
```

The first legal nonconsecutive gap is `h=2`, and

```text
N_2(x)=P(x+1)
      =(2x+3)(17(x+1)(x+2)+5),
```

a cubic polynomial.

Suppose, in the most optimistic fixed-polynomial scenario, that the selected upper prime `q` also divides this same carrier. Evaluating at `x asymp q` and stripping the q-factor leaves only

```text
N_2(x)/q = O(q^2).
```

That is exactly the critical two-lower-prime scale. There is no `o(q^2)` margin. The explicit linear-times-quadratic factorization shows why: after one q-sized factor is removed, a q-sized linear factor and a q-squared quadratic factor can still support two q-sized primes.

For fixed `h>=3`, the optimistic q-free size is

```text
q^(3(h-1)-1),
```

which is worse. For growing `h`, the continuant has

```text
log |N_h(r)| << h log(r+h)+O(h),
```

so it is superpolynomial as soon as `h` grows.

This is an exact use of the cubic coefficients and the `n^3` term: one forced q-factor lowers degree `3` to the critical exponent `2`, not below it.

### 6.3 Casoratian identities do not lower the degree

Writing `B_h` for the companion transfer solution and

```text
Pi_h(x)=product_{j=1}^h (x+j)^3,
```

the repository proves

```text
N_h B_k - N_k B_h
  = -Pi_h^2 N_{k-h}(x+h).
```

The bordered determinant factors as

```text
D_{h,k}(x)=Pi_h(x) Delta_{h,k}(x),
```

but after the mandatory structural factor is removed,

```text
deg Delta_{h,k}=3(k-1).
```

The range-nonvanishing theorem confirms that this reduced certificate is genuinely nonzero for `1<=h<k<p`; it does not hide a further universal degree collapse. Thus the Casoratian moves common-divisor information among continuants but does not produce a subcritical polynomial carrier.

### 6.4 Why the affine q6 relation does not make one fixed polynomial

For one lower prime `p=q-d`, the two local zero indices are affine in `d`. Therefore the local common divisor can be placed on a continuant whose base and gap are affine functions of `d`.

The decisive problem is that the **order of the continuant also moves with `d`**. The expression is not the value of one fixed-degree polynomial in `p` or `d`. Replacing the family by a finite interpolation polynomial has degree comparable to the whole candidate grid and is precisely the support-adapted certificate collapse already identified in earlier rounds.

For a single preselected prime there is no difficulty. For two preselected primes there are two different local continuants. The recurrence supplies no cross-divisibility between them. Multiplying, taking resultants, or placing the two rows in one finite-presentation module is exactly where the packaging trap returns.

### 6.5 Wronskian and companion-solution route

The companion Apéry solution gives a nonzero Casoratian and exact ratios of companion values between two returns. Those formulas certify that a zero is a projective return and that the companion coordinate is nonzero. They do not constrain the rational prime support of two different reductions of the same integral solution.

At one prime, the Wronskian gives a scalar line. At a second prime, it gives another scalar line in another residue field. Comparing those lines requires the same cross-characteristic packaging that was already audited. In the fixed integer gcd, the lines have serialized as ordinary prime divisors, but the Wronskian supplies no upper bound on their radical.

### 6.6 The known q-factor

The selected mark gives one common prime `q`, hence one subtraction of `log q` from the available height. Radical multiplicity is irrelevant: `q` occurs only once in the radical. No banked theorem guarantees a second q-factor in the common carrier, and the divided upper jet is free after the universal q-copy is removed.

Therefore the fact that `G_sigma` already carries `q` changes the critical full-radical exponent from `3` to the q-free exponent `2`; it does not create an additional saving.

## 7. Other natural radical methods

### 7.1 Chebyshev counting

The elementary estimate

```text
omega_I(G_sigma^circ)
 <= log G_sigma^circ/log P
```

gives only `O_J(q/log q)` shell primes from the fixed-gcd height. The upper-bound sieve in the explicit endpoint span improves this to `O(W/log W)`, but a pair remains possible as soon as `W>=2`.

### 7.2 Polynomial abc / Mason-Stothers

Mason-Stothers applies to fixed polynomials in one function-field variable. The maps

```text
q -> b_{6q+t},
q -> b_{12q+t},
```

are not fixed polynomials, and in the selected problem `t` varies with `q`. The continuant polynomial has moving degree `3(h-1)`. Any interpolation over the finite candidate set is support-adapted and returns the equivalence trap.

The integer abc conjecture applied to

```text
(n+1)^3 b_{n+1} + n^3 b_{n-1} = P(n)b_n
```

has the wrong direction for this problem: large common prime factors enlarge the radical of the three terms, which helps the abc inequality rather than contradicting it. The terms also have uncontrolled common factors. No polynomial-radical upper bound follows from a direct abc application.

### 7.3 Primitive divisors and Baker methods

Primitive-divisor theorems exploit a divisibility-sequence law or a fixed multiplicative representation. The Apéry sequence has neither. Baker's method needs a small nonzero Archimedean linear form in fixed algebraic exponentials. The asymptotic

```text
b_n ~ C_A alpha^n n^(-3/2)
```

is not an exact Binet formula, and a factor of size `q^2` is exponentially negligible relative to `b_n`. It does not force a small linear form.

### 7.4 Subexponential gcd theorems

Bugeaud-Corvaja-Zannier and related results concern fixed-rank exponential, S-unit, or constant-coefficient recurrence structures. The Apéry recurrence is P-recursive with moving polynomial coefficients. More importantly, even a gifted estimate

```text
log gcd = o(q)
```

would not reach the required

```text
log Rad < 2 log q+O(1).
```

Thus these theorems miss both structurally and quantitatively.

## 8. The two standing checks

### 8.1 Equivalence trap

The following are target-complete and therefore do not count as mechanisms:

```text
#actual lower primes <= 1;
R_sigma^act < P^2;
R_sigma^act << q^(2-eta);
the second-largest actual prime is absent.
```

The proposed support-blind PCRB escapes the trap because it controls all common primes in a predetermined geometric shell, including primes that fail the actual q6 masks. Q6-SLUNI does not imply that stronger assertion.

The endpoint-sieve theorem also escapes the trap: its witness is not interpolated from the actual support. It follows uniformly from affine endpoint inequalities and a standard upper-bound sieve.

### 8.2 Packaging trap

The definitions of `G_sigma^circ`, its radical, and the endpoint-sieve proof never place different lower characteristics in one coefficient field or finite-presentation module. Unit erasure and the Fitting information floor do not apply to them.

The trap returns only in the recurrence attack at the following precise step:

```text
one tries to replace the p-dependent local continuants
by one object carrying all possible p.
```

A direct q-base change forgets the lower support; an integral product, resultant, CRT object, or Fitting module remembers it and pays additive prime height. The present report does not use that step as a proof.

Thus the correct conclusion is:

```text
The standalone theorem escapes the old formal obstructions.
The presently available recurrence identities still fail quantitatively,
and attempts to combine their local certificates re-enter the old packaging class.
```

## 9. Hostile audit of the result

1. **The full PCRB is not proved.** The theorem bounds the actual radical by endpoint geometry and bounds the unfiltered shell radical by generic prime packing and total height. Neither reaches `P^2` in the deep range.
2. **The support-blind PCRB may be substantially stronger than necessary.** Irrelevant common primes could make it false even if Q6-SLUNI is true. It is presented as a clean sufficient theorem, not as an equivalent restatement.
3. **The cubic-degree calculation is a height obstruction, not a radical impossibility theorem.** A cubic integer can have unusually small radical. Closing Q6-SLUNI could still come from an Apéry-specific factor-support theorem invisible to degree.
4. **The long fixed transfer is singular in the q6 range.** The continuant calculation is used only to diagnose the local certificate and degree bar. An honest q6 proof must cut at prime-dependent singular steps, which is exactly why no one fixed polynomial has emerged.
5. **Brun-Titchmarsh cannot eliminate a pair.** It gives the optimal generic order for many primes in a short interval but says nothing against one twin-sized pair.
6. **No finite scan enters the proof.** The empty computations through `2*10^6` remain corroboration only.
7. **No lower bound on marked mass is used.** Every statement is pointwise in a fixed selected state.

## 10. Sharp residual theorem and route selection

The clean conditional statement surviving this round is the following.

### PCRB_eta (unfiltered geometric-shell common radical)

For some fixed `eta>0`, uniformly for every actual selected state `(q,t)` and both signs,

```text
Rad_{S_J(q)}(G_sigma^circ(q,t)) <<_J q^(2-eta),
```

where `S_J(q)` is a deterministic shell containing all admissible lower primes and is defined before testing any lower Apéry zero or residual mask.

Then Q6-SLUNI holds pointwise, and therefore every selected pair statistic vanishes without any lower bound on `M_sigma(T)`.

The fixed-power form is stronger than necessary. The exact endpoint is

```text
Rad_{S_J(q)}(G_sigma^circ(q,t)) < P^2.
```

What remains to prove is not a subexponential gcd theorem. It is a horizontal assertion that the fixed q-free gcd has **subcritical quadratic radical in the large-prime shell**.

The current unconditional theorem reaches, in the first deep range,

```text
log R_actual <<_beta T^(beta/6),
```

while PCRB needs

```text
log R_shell < 2 log T+O_J(1).
```

The missing factor is therefore

```text
T^(beta/6)/log T
```

at the earliest deep scale, and `T^(5beta/6)/log T` at the whole-cell support-blind scale.

This is the precise quantitative frontier.
