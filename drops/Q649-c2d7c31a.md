# Overconvergent Strassmann for the Apéry function — concrete computation

## Executive answer

The proposed Dwork-Strassmann route is mathematically natural, but the concrete computation requested is not currently available in a closed form for the Apéry operator. More importantly, the hoped-for implication

\[
\text{bounded Dwork Strassmann index}\Rightarrow |Z_p|=O(1)
\]

requires a stronger object than the usual unit-root Frobenius at the fixed fiber \(z=1/16\). The fixed K3 fiber Frobenius controls the value of the period, while \(Z_p\) concerns the variation of the Mellin character parameter \(r\).

The main conclusion is:

* The rank-4 Dwork Frobenius \(\Phi_p(z=1/16)\) is not by itself the desired recurrence in \(r\).
* A character-side overconvergent Frobenius family would be needed.
* No known computation gives a uniformly bounded Strassmann index for the Apéry zeros.
* If such a bound existed, it would indeed essentially solve AFP, but proving the bound is the hard part.

---

## 1. What can be computed from the Apéry Picard-Fuchs operator?

The operator is

\[
\theta^4-z(2\theta+1)^2(17\theta^2+17\theta+5)+z^2(\theta+1)^4.
\]

At a good prime \(p\), Dwork theory gives a Frobenius action

\[
\Phi_p:H^3_{\mathrm{cris}}(X_{1/16})\rightarrow H^3_{\mathrm{cris}}(X_{1/16}).
\]

This is a 4 by 4 matrix after choosing a crystalline basis. Its characteristic polynomial has the K3 shape

\[
1-a_pT+p b_pT^2-p^3a_pT^3+p^6T^4,
\]

with a unit-root eigenvalue \(\alpha_p\) when the ordinary condition holds.

The relation

\[
b_{(p-1)/2}\equiv a_p(f)\pmod p
\]

with \(f=\eta(2\tau)^4\eta(4\tau)^4\) reflects this fixed-fiber Frobenius.

However, this only gives the central Mellin value. It does not give all

\[
b_r\pmod p,\qquad 0\le r<p.
\]

---

## 2. Why the naive Dwork basis does not immediately solve AFP

A Strassmann argument would require an analytic function

\[
F_p(r)=\widetilde M_{p,r}
\]

on a p-adic disk satisfying

\[
F_p(r)=\sum_n c_nf_n(r).
\]

If

\[
v_p(c_n)\to\infty
\]

quickly enough, then

\[
\#\{r:F_p(r)=0\}\leq S.
\]

The problem is that the standard Dwork Frobenius is in the variable \(z\), not in the character variable \(r\).

The Mellin transform introduces the family

\[
\mathcal H_r=FT_!(\mathcal H\otimes \mathcal L_{\omega^r}),
\]

so the required object is a Frobenius family over the character torus. This is a different overconvergent object.

---

## 3. Is there an explicit Dwork basis for the character side?

Not presently in the required form.

The expected construction would be:

1. Start from the hypergeometric/K3 crystal.
2. Apply the Mellin transform in the torus variable.
3. Obtain an overconvergent \(F\)-isocrystal on the character space.
4. Write the unit-root section as

\[
U_p(r)=\sum_n c_{n,p}\,f_n(r).
\]

The coefficients would involve Gross-Koblitz factors of the shape

\[
\pi^{h(r)}\Gamma_p(\cdots+r/(p-1))
\]

and Frobenius matrices of the Mellin crystal.

But this is not the same as the fixed Apéry recurrence.

---

## 4. Why the requested small-prime computation is misleading

For

\[
p=5,7,11,13,17,19,23,
\]

one can compute the finite-field Frobenius polynomial of the K3 fiber, and in ordinary cases extract the unit root.

But this does not determine the Strassmann index because the index depends on the entire function

\[
r\mapsto \widetilde M_{p,r}.
\]

The matrix

\[
\Phi_p(1/16)
\]

contains only the value at one fiber parameter.

The missing data is a Frobenius matrix varying with the tame character.

---

## 5. What zero-return theorem would be needed?

Suppose one had a genuine recurrence

\[
A(r)y_{r+1}=B(r)y_r-C(r)y_{r-1}
\]

with bounded degree coefficients.

This alone is insufficient.

Examples of order-2 recurrences can have many zeros modulo p because the recurrence evolves inside a finite field. A bounded-degree recurrence only gives bounded complexity over characteristic zero; modulo p the orbit can close.

The needed theorem is stronger:

> A character-side Apéry crystal has no long return of its projective Frobenius orbit to the zero section.

Equivalently, one needs an escape theorem for the projective dynamics generated by the recurrence.

This is closer to the existing transfer-matrix approach:

\[
\Pi_r e_1\in \mathbf P^1(\mathbf F_p).
\]

The zero event is a return to one point in the projective line.

---

## 6. Comparison with Kloosterman/Bessel

For

\[
K_p(t)=\sum_j\frac{t^j}{(j!)^2},
\]

one has the first-order recurrence

\[
(j+1)^2a_{j+1}=ta_j.
\]

The projective orbit is essentially one-dimensional, so zeros are rigid.

For Apéry:

\[
(r+1)^3b_{r+1}
=(2r+1)(17r^2+17r+5)b_r-r^3b_{r-1}.
\]

The state space is two-dimensional:

\[
(b_r,b_{r-1}).
\]

The coefficient degree three causes the projective transformation to vary nontrivially with \(r\).

Therefore order 2 versus order 1 is a real obstruction. It changes the problem from root counting of a function to recurrence orbit avoidance.

---

## 7. Relation to AFP

A bounded Strassmann index would imply

\[
|Z_p|=O(1),
\]

and therefore

\[
\sum_{p\le X}|Z_p|
\ll \pi(X),
\]

which is exactly AFP.

So the route is potentially decisive.

However, the missing theorem is not computation of \(\Phi_p\). It is construction and control of the **character-side Mellin crystal**.

The minimal realistic milestone is:

\[
\boxed{
\text{construct the overconvergent Mellin Frobenius family and prove bounded return index}
}
\]

rather than computing the fixed K3 Frobenius matrices.

---

## References / closest existing theory

Relevant frameworks are:

* Dwork theory for hypergeometric motives and unit-root crystals.
* Katz, *Exponential Sums and Differential Equations* (Fourier transform of \(F\)-crystals).
* Wan's work on Dwork families and unit-root zeta functions.
* Beukers–Peters on the Apéry differential equation and the associated K3 geometry.

No standard reference appears to compute the full character-side Dwork Frobenius for the Apéry Mellin sequence in the form required for a uniform Strassmann bound.
