# Audit of HM2 versus the FDTG3 density gate

## 1. What HM2 actually gives

Let
\[
R(m)=R_X^\dagger(m),\qquad \lambda=\sum_{X<p\le 2X}\frac{|Z_p|}{p}.
\]
The frozen input is
\[
\sum_{m<X^2}(R(m))_2\le 5X^2\lambda^2.
\]
This is a second factorial moment. It controls pairs of active prime incidences, but the desired pointwise gcd argument needs a third-order tail bound, because a bad row requires three distinct shell primes.

For any threshold T≥1,
\[
\#\{m:R(m)\ge T\}
\le \frac1{T(T-1)}\sum_m(R(m))_2
\le \frac{5X^2\lambda^2}{T(T-1)}.
\]
Thus HM2 alone gives the tail exponent
\[
N_T\ll X^2\lambda^2T^{-2}.
\]
There is no third-moment saving in this estimate.

## 2. What fibre injectivity supplies

The full-defect hypothesis says that for fixed signs and nonzero distinct defects, a translation fibre has multiplicity
\[
\ll X^{o(1)}.
\]
Therefore an ordered triple contribution satisfies schematically
\[
\sum_m(R(m))_3
\ll X^{o(1)}\cdot \#\{\text{admissible defect triples}\}.
\]
The missing factor is the density normalization \(\lambda^3\). Fibre injectivity bounds collisions; it does not create prime-zero mass.

The strongest conclusion obtainable from the stated hypotheses is therefore
\[
\sum_m(R(m))_3\ll X^{2+o(1)}\lambda^2
\]
only if one can independently prove a third incidence estimate. The implication
\[
X^{o(1)}\le X^{o(1)}\lambda^3
\]
is false when \(\lambda\) is small.

## 3. Sparse/dense split

### Dense regime

If
\[
\lambda\ge X^{-\varepsilon(X)},\qquad \varepsilon(X)\to0,
\]
then
\[
\lambda^{-3}=X^{o(1)},
\]
and a density-free fibre estimate of size X^{o(1)} can be rewritten as
\[
X^{o(1)}\lambda^3.
\]
Hence the original FDTG3 normalization is unnecessary in the dense regime.

### Sparse regime

Suppose instead
\[
\lambda=X^{-c}
\]
for fixed c>0. A single admissible triple has weight 1 in the unweighted triple moment but the desired normalization allows only
\[
X^{2+o(1)}X^{-3c}.
\]
For c>2/3 even one triple exceeds the global budget. Therefore no argument using only injectivity can remove the density factor.

Exact support counting does not fix this: HM2 permits isolated triples because a single row with R=3 contributes only
\[
(R)_2=6,
\]
which is compatible with
\[
5X^2\lambda^2
\]
whenever \(X^2\lambda^2\gg1\).

## 4. Abstract countermodel

Take a sequence of X with
\[
\lambda=X^{-1/2}.
\]
Create one row m with exactly three active prime incidences p1,p2,p3. Assign distinct coefficients ci in the allowed ranges and choose nonzero distinct defects satisfying
\[
d_2d_3(d_2-d_3)\ne0.
\]
Put every other row empty.

Then:

* HM2 holds, since
\[
\sum_m(R(m))_2=6\le 5X^2\lambda^2=5X.
\]
* The fibre multiplicity is one, hence the injectivity hypothesis holds.
* The triple moment is
\[
\sum_m(R(m))_3=6.
\]
But the FDTG3 target is
\[
X^{2+o(1)}\lambda^3=X^{1/2+o(1)},
\]
which eventually dominates 6, so this example alone does not violate it. To force violation take
\[
\lambda=X^{-1}.
\]
Then HM2 still allows a constant-size row after adjusting the number of active pairs, while
\[
X^{2}\lambda^3=X^{-1}
\]
so any isolated triple violates the normalized third moment.

This shows that HM2 plus fibre injectivity cannot imply FDTG3.

## 5. Pointwise consequence and dyadic summation

A triple tail estimate gives
\[
\sum_m(R(m))_3\le M_3.
\]
Rows with R≥3 satisfy
\[
\#\{m:R(m)\ge3\}\le M_3/6.
\]
If each bad row contributes at most O(log X) logarithmic gcd mass, the dyadic contribution is
\[
\ll M_3\log X.
\]
The required o(X^2) estimate needs
\[
M_3=X^{2-o(1)}.
\]
The FDTG3 form gives
\[
M_3\le X^{2+o(1)}\lambda^3,
\]
which is more than enough. HM2 alone gives no such decay.

An isolated triple at arbitrarily large X is harmless only if its logarithmic weight is itself summably negligible. For unweighted triple counting it is harmless, but for the normalized FDTG3 inequality it is a genuine obstruction when λ is tiny.

## 6. Weakest replacement hypothesis

The minimal additional input is not FDTG3 itself but a weighted third-correlation estimate. Any one of the following suffices:

\[
\sum_m(R(m))_3\ll X^{2+o(1)}\lambda^3,
\]
(the original gate), or the weaker directly relevant form
\[
\sum_{m:R(m)\ge3} w(m)\ll X^{2-o(1)},
\]
where w(m) dominates the logarithmic gcd contribution.

A possible intermediate theorem would be a logarithmic pair-to-triple inequality
\[
\sum_m(R(m))_3
\ll X^{o(1)}\lambda\sum_m(R(m))_2,
\]
which combined with HM2 gives the desired bound.

## Conclusion

The lambda^3 normalization is stronger than needed in dense ranges, because any density-free fibre bound can absorb \(\lambda^{-3}\) when \(\lambda^{-1}=X^{o(1)}\). It is not removable in general. Sparse abstract incidence models satisfy HM2, coefficient constraints, nonzero-defect geometry, and fibre injectivity while violating every density-free implication of FDTG3. A genuine weighted third-order correlation, or an equivalent logarithmic mass estimate, is necessary for the original all-n pointwise gcd theorem.
