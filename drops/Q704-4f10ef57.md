# Q713: Riccati ratio equidistribution and AFP

## 1. The ratio rho_r does not satisfy a scalar Riccati map in rho_r alone

Let the Apéry recurrence be

```text
(r+1)^3 u_{r+1}=P(r)u_r-r^3u_{r-1},
P(r)=(2r+1)(17r^2+17r+5).
```

For two solutions b,c define

```text
rho_r=b_r/c_r.
```

A first-order projective recurrence exists for the pair

```text
x_r=(b_r,b_{r-1})/(c_r,c_{r-1})
```

but not for rho_r alone. Indeed,

```text
rho_{r+1}=
(P(r)rho_r-r^3(b_{r-1}/c_r))/(r+1)^3
```

and the missing term is

```text
b_{r-1}/c_r=(b_{r-1}/c_{r})
```

which is not determined by rho_r.

Using the Wronskian

```text
W_r=b_r c_{r-1}-b_{r-1}c_r=-1/r^3,
```

we obtain

```text
b_{r-1}/c_r = rho_r*(c_{r-1}/c_r)+1/(r^3 c_r^2).
```

The extra quantities involving c_r remain. Therefore rho_r alone is not a closed Riccati variable. The closed object is the full projective state of the two-dimensional solution space.

---

## 2. The Riccati orbit is not the transfer orbit x_r

The transfer orbit used in the AFP reduction is

```text
x_r=b_r/b_{r-1}.
```

It is the projectivization of a single solution vector:

```text
(b_r,b_{r-1}) in P^1(F_p).
```

Its update is exactly the Möbius action of the recurrence matrix

```text
M(r)=[[P(r)/(r+1)^3, -r^3/(r+1)^3],[1,0]].
```

By contrast,

```text
rho_r=b_r/c_r
```

compares two different horizontal sections of the rank-two local system. It is a coordinate on the space of pairs of solutions, not the same projective orbit.

The relation is:

```text
rho_r=0  <=>  the b-solution line equals the c-kernel line at r.
```

Thus AFP is a hitting problem for the moving line determined by c, whereas the transfer orbit problem is a hitting problem for the fixed coordinate line of the recurrence state.

They live in the same SL_2 cocycle, but are different P^1 orbits.

---

## 3. The Wronskian curve gives a constraint, but not a low-genus curve

The pair

```text
(rho_r,rho_{r-1})
```

satisfies a relation coming from

```text
b_r c_{r-1}-b_{r-1}c_r=-1/r^3.
```

However, after dividing by c_r c_{r-1}, this becomes

```text
rho_r-rho_{r-1} = -1/(r^3 c_r c_{r-1}).
```

The right side contains the scale variable c_r c_{r-1}. Therefore there is no algebraic curve only in (rho_r,rho_{r-1}) with bounded genus. The projection forgets essential information.

The natural object is instead the rank-two vector bundle / SL_2 local system. Its projectivization is the same P^1-bundle already appearing in the transfer-matrix description.

Hence the Wronskian gives rigidity (no consecutive zeros, determinant control), but not a direct algebraic-curve equidistribution theorem.

---

## 4. The real-to-finite-field attraction argument does not transfer

Over R, the ratio satisfies

```text
b_r/c_r -> 1/(6 zeta(3))
```

because the Apéry recurrence has a dominant and a minimal solution. The error is exponentially small.

Over F_p this mechanism disappears. The reasons are:

1. There is no ordering on F_p, hence no notion of attraction.
2. The recurrence coefficients are periodic modulo p.
3. Every non-singular orbit of the induced finite dynamical system is eventually periodic.

A matrix in SL_2(F_p) can have attracting behavior over an extension field only in the sense of eigenvalue valuation in a p-adic or archimedean lift, not as a dynamical contraction inside F_p.

Therefore the statement

```text
rho_r spirals toward rho_infinity mod p
```

is not a valid finite-field statement.

The correct replacement is a monodromy statement: if the Mellin/Apéry sheaf has sufficiently large geometric monodromy, then Frobenius conjugacy classes become equidistributed, and zero hitting can be bounded by trace-function estimates.

---

## 5. The p-adic zeta interpretation does not directly give AFP

The quantity

```text
rho_infinity=1/(6 zeta_p(3))
```

is a plausible p-adic analogue of the real limiting ratio, but it is not the reduction of a finite-field attracting fixed point.

Kubota-Leopoldt gives a p-adic zeta value

```text
zeta_p(3) in Z_p,
```

so if zeta_p(3) is a p-adic unit then

```text
rho_infinity != 0 mod p.
```

However, this only says that the limiting p-adic period is nonzero. It does not imply that the finite sequence

```text
rho_0,rho_1,...,rho_{p-1}
```

avoids zero.

The AFP statement requires a uniform finite-field bound

```text
#{r<p:rho_r=0}=O(1),
```

which is an orbit-intersection estimate, not a p-adic convergence estimate.

---

# Conclusion for AFP

The ratio viewpoint is useful because it identifies zeros as intersections of two solution lines in an SL_2 local system:

```text
b_r=0 <=> [b]_r intersects the c-complementary line.
```

But the proposed shortcut

```text
real attraction => finite-field attraction => AFP
```

fails.

The strongest rigorous route remains the one suggested by the transfer/Mellin picture:

```text
large monodromy + Frobenius equidistribution
        => bounded intersection with a fixed projective divisor
        => AFP.
```

The Riccati ratio reformulation does not reduce AFP to a one-dimensional dynamical-system problem; it exposes the same SL_2 geometry from another coordinate system.
