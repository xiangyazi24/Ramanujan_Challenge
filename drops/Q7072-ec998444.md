# Apéry full-period monodromy and the orbit collision problem

The proposed monodromy idea is a natural one, but the key point is that the full-period matrix is not a generic random element of \(\mathrm{GL}_2(\mathbf F_p)\). It is a Frobenius/Hasse object, and the relevant question is not simply whether its eigenvalues have order \(\sim p\).

## 1. The transfer matrix

For the normalized Apéry recurrence one has a projective transfer
\[
\binom{B_{n+1}}{D_{n+1}}=T_n\binom{B_n}{D_n},
\]
with
\[
T_n=\begin{pmatrix}P(n)&-n^6\\1&0\end{pmatrix}
\]
(up to the harmless scalar normalization coming from multiplying by factorials). The full period is
\[
M_p=T_{p-1}\cdots T_1T_0.
\]
The orbit satisfies
\[
\pi_p=M_p\pi_0.
\]
Thus the return structure is controlled by the projective action of \(M_p\).

## 2. What computation suggests

For small primes, the empirical full-period product is not a generic matrix. The observed pattern in this project is
\[
M_p\equiv \begin{pmatrix}1&0\\5&0\end{pmatrix}\pmod p
\]
for several small primes \(p=7,11,13,17,19,23\).

This matrix is rank one, with eigenvalues \(1,0\), so it does **not** have multiplicative order \(\sim p\). Therefore the hoped-for "large order monodromy implies maximal spreading" mechanism is not the correct explanation for the Apéry orbit.

The reason is structural: the Frobenius-period product remembers the Hasse invariant of the differential equation, not a generic semisimple element.

## 3. Relation with the Hasse matrix

The Cartier-Frobenius viewpoint predicts exactly this type of degeneration. The Apéry operator has a unit-root part and a nilpotent/non-unit part modulo \(p\). The Hasse matrix controls the Frobenius action on the finite-dimensional de Rham quotient. In the ordinary case it has rank one; in supersingular/non-ordinary cases the rank drops further.

Therefore the rank-one phenomenon above is evidence for the Hasse structure, not evidence of random expansion.

## 4. Consequence for \(Z(p)\)

If \(M_p\) were semisimple with eigenvalue ratio of large order, then the projective orbit would indeed have long period and few collisions. But here
\[
M_p\sim \text{rank-one Frobenius projector},
\]
so this route cannot directly prove
\[
Z(p)=O(1).
\]

The collision problem is instead governed by the intermediate orbit before Frobenius collapse. The relevant objects remain:

* the transfer cocycle \(T_n\),
* the exceptional zeros \(b_r\equiv0\pmod p\),
* the gap polynomials controlling repeated visits.

## 5. What can still be extracted

The monodromy computation is still valuable. It gives a strong algebraic constraint:

1. The whole orbit is not an arbitrary subset of \(\mathbf P^1(\mathbf F_p)\).
2. The terminal state is controlled by a rank-one Frobenius projector.
3. The parity/ordinary behavior of \(Z(p)\) should be linked to the rank of the Hasse invariant.

A promising refinement is therefore not to prove large order of \(M_p\), but to study the factorization
\[
T_{p-1}\cdots T_0=H_p\cdot N_p
\]
where \(H_p\) is the Hasse-Frobenius piece. One would want an explicit formula relating zeros of the Hasse polynomial to the number of exceptional projective returns.

## Conclusion

The answer to the proposed test is negative: the full-period monodromy does not appear to have eigenvalues of order \(\sim p\); it collapses to the Hasse/Frobenius rank-one behavior. This explains why the orbit is structured rather than maximally random. The monodromy calculation is still useful, but the route to \(Z(p)=O(1)\) must exploit Frobenius/Hasse constraints together with the gap-polynomial zero geometry, rather than generic large-order dynamics.
