# Hostile audit of d-averaged shell variance

## Executive verdict

The d-average does not prove the stated SHELL VARIANCE target, but it exposes a weaker target that is exactly strong enough for a new p^(4/3) energy theorem.

The conclusions are:

1. The exact second moment T_2(D,H) is a centered seven-index count. In gap variables (h,k,h',k') it has the single linear shell constraint

```text
k-h = k'-h',
```

but it also has two independent nonlinear value-coincidence equations. Calling it merely a seven-parameter count with one linear constraint understates the geometry.

2. The Fourier formula is exact after the deterministic component subtraction is fixed exactly. It is a cross-frequency fourth moment in the one-variable sums S_h(t).

3. Markov gives A_d small for most d, but "most d" is not enough for the original COINC statement. Under the best unconditional trivial bound for one exceptional shell, even one uncontrolled d can exceed the entire p^(4/3) budget when H=p^(2/3).

4. The correct use of T_2 is Cauchy across d, not a good-d/bad-d split. Full COINC would require

```text
T_2(H,H) << p^2 H.
```

The natural diagonal scale of the four-gap Parseval object is instead

```text
p^2 H^2.
```

Thus d-averaging loses a factor H and cannot recover COINC by a diagonal/off-diagonal moment argument.

5. Crucially, the diagonal scale does not exceed the weaker budget needed for the energy exponent 4/3. It exactly saturates that budget. The sharp averaged target is

```text
[SHELL-L2-DIAGONAL]
T_2(H,H) <<_eps p^(2+eps) H^2,
H <= p^(2/3).
```

This implies directly

```text
F_p <<_eps p^(4/3+eps)
```

at H=p^(2/3), without first proving COINC.

6. None of the currently available estimates proves [SHELL-L2-DIAGONAL]. The pointwise bound

```text
|S_h(t)| <= (4h+1) sqrt(p)
```

is off by several powers of H. Pairwise Hasse-Weil and degree bounds are also far too weak. Proving diagonal-sized four-gap variance is a new quenched family theorem, not a consequence of fixed-d algebraicity.

Final classification:

```text
d-averaging -> full COINC: KILLED by the factor-H diagonal loss.
d-averaging -> direct p^(4/3): SURVIVES as a precise conditional route.
current tools -> [SHELL-L2-DIAGONAL]: NO; the four-gap off-diagonal problem is open.
```

The sharpest first lemma is [FOUR-GAP-DIAGONAL], stated in Section 7 below.

## 1. Exact setup

For each 1 <= h <= H, put

```text
I_h = {r : 1 <= r <= M-h},
n_h = #I_h = M-h,
f_h(r) = Delta_{r,h}.
```

Define the value histogram and its additive Fourier transform by

```text
nu_h(a) = #{r in I_h : f_h(r)=a},
S_h(t) = sum_{r in I_h} e_p(t f_h(r)).
```

Then

```text
S_h(0)=n_h,
overline(S_h(t))=S_h(-t).
```

For two gaps h,k, define the pair-curve coincidence count

```text
J_{h,k}
 = #{(r,r') in I_h x I_k : f_h(r)=f_k(r')}
 = sum_a nu_h(a) nu_k(a).
```

Additive orthogonality gives the exact identity

```text
J_{h,k}
 = (1/p) sum_{t in F_p} S_h(t) overline(S_k(t)).       (1.1)
```

Let g_{h,k} denote the exact contribution of all explicitly removed geometric components: diagonal components, mirror/forced components, and boundary components under the campaign's fixed convention. Put

```text
m_{h,k} = n_h n_k/p + g_{h,k},
E_{h,k} = J_{h,k} - m_{h,k}.                           (1.2)
```

The exact value of g_{h,k} matters. Since T_2 squares shell sums, an imprecise or overlapping subtraction is not harmless. Everything below assumes the campaign's component subtraction is an exact identity, not a semantic "circ" label.

For 1 <= d <= D <= H-1, define

```text
A_d(H) = sum_{1 <= h <= H-d} E_{h,h+d}.                (1.3)
```

Finally,

```text
T_2(D,H) = sum_{d=1}^D |A_d(H)|^2.                    (1.4)
```

All A_d are real because they are centered point counts.

## 2. What T_2 counts exactly

Write

```text
J_d = sum_{h<=H-d} J_{h,h+d},
m_d = sum_{h<=H-d} m_{h,h+d}.
```

Then

```text
A_d = J_d-m_d,
T_2(D,H) = sum_{d<=D} (J_d-m_d)^2.                    (2.1)
```

The raw term sum_d J_d^2 is exactly the count of all tuples

```text
(d,h,h',r,r',s,s')
```

satisfying

```text
1 <= d <= D,
1 <= h,h' <= H-d,
r in I_h,
r' in I_{h+d},
s in I_h',
s' in I_{h'+d},

f_h(r)     = f_{h+d}(r'),
f_h'(s)    = f_{h'+d}(s').                            (2.2)
```

Thus the exact centered expansion is

```text
T_2(D,H)
 = N_7(D,H)
   - 2 sum_{d<=D} J_d m_d
   + sum_{d<=D} m_d^2,                                (2.3)
```

where N_7(D,H) is the seven-index count in (2.2).

Equivalently, introduce independent gap labels k and k'. Then the shell condition is

```text
k-h = k'-h' = d.                                      (2.4)
```

There are eight labels/positions before eliminating k,k', one linear relation among the four gap labels, and two nonlinear rational equations. This is not a one-equation complete-intersection problem.

## 3. Exact Fourier fourth moment

First ignore g_{h,k}; or, equivalently, assume its exact Fourier representative has already been subtracted. Define

```text
R_d(t)
 = sum_{h<=H-d} S_h(t) overline(S_{h+d}(t)).           (3.1)
```

Then

```text
A_d
 = (1/p) sum_{t!=0} R_d(t)                            (3.2)
```

for the raw centered main term. With explicit forced terms one has instead

```text
A_d
 = (1/p) sum_{t!=0} R_d(t) - sum_{h<=H-d} g_{h,h+d}.  (3.3)
```

The exact fourth-moment expansion is

```text
T_2(D,H)
 = (1/p^2)
   sum_{d<=D}
   sum_{t,u!=0}
   sum_{h,h'<=H-d}
     S_h(t) overline(S_{h+d}(t))
     overline(S_h'(u)) S_{h'+d}(u),                   (3.4)
```

again with the explicit forced correction terms added if they have not been absorbed into a circ transform.

This is a cross-frequency fourth moment. It is not the single-frequency quantity

```text
sum_{d,t} |R_d(t)|^2.
```

The latter appears only after Cauchy in t and is therefore an upper-bound object, not an identity for T_2.

## 4. Markov, exceptional d, and why "most shells" is not enough

Chebyshev gives, for every Y>0,

```text
#{d<=D : |A_d|>Y} <= T_2(D,H)/Y^2.                   (4.1)
```

But the quantity entering the full coincidence variance is the sum of the shells, not the number of good shells. The immediately useful inequality is

```text
sum_{d<=D} |A_d|
 <= sqrt(D T_2(D,H)).                                 (4.2)
```

This is stronger than splitting d into good and bad sets.

To see how hostile the exceptional-shell issue is, use only the rational-map degree. Since f_h has degree 3h, for h<=k one has

```text
J_{h,k} <= 3h p.                                      (4.3)
```

Consequently an uncontrolled shell has the safe bound

```text
|A_d(H)| << p sum_{h<=H-d} h << p H^2.               (4.4)
```

Suppose, optimistically, that

```text
|A_d| << p
```

for all but R exceptional d. Then

```text
sum_{d<=H}|A_d|
 << pH + R pH^2.                                      (4.5)
```

At H=p^(2/3), the block-energy route to p^(4/3) can absorb total shell excess only up to order p^2. Equation (4.5) therefore requires

```text
R pH^2 <= p^2,
R <= p/H^2 = p^(-1/3).                               (4.6)
```

For large p this means R=0.

If the exceptional density is stated as

```text
R <= H p^(-delta),
```

then its contribution at H=p^(2/3) is

```text
R pH^2 <= p H^3 p^(-delta) = p^(3-delta).            (4.7)
```

Thus:

```text
to retain the p^(4/3) energy conclusion: delta >= 1;
to retain full COINC, whose budget is pH=p^(5/3): delta >= 4/3.
```

Since H p^(-1)<1 at H=p^(2/3), even delta=1 again means no exceptional shell.

Therefore:

```text
"A_d is small for most d" plus a trivial exceptional-shell bound
is not enough.
```

A graph-coloring salvage would require a hereditary shell estimate for every restricted subset of h-values. A bound only for the full sums A_d(H) does not imply such restricted estimates, so coloring the bad-difference graph is unavailable here.

## 5. Exact exceptional-tolerant block-energy chain

Let

```text
L_H = sum_{h<=H} n_h = #S_H,
V_H = N_coinc(H) - L_H^2/p.                           (5.1)
```

V_H is the exact nonnegative value-histogram variance of the triangular family. After the diagonal and forced components are separated, write

```text
V_H
 = V_forced(H) + A_0(H) + 2 sum_{d=1}^{H-1} A_d(H).  (5.2)
```

The campaign's intended deterministic bookkeeping must give

```text
V_forced(H)+A_0(H) << pH.                             (5.3)
```

Using T_2 with D=H-1 gives

```text
V_H
 << pH + sqrt(H T_2(H-1,H)).                         (5.4)
```

D2-D3 and Cauchy in t give

```text
sum_{h<=H} C_h
 <= L_H/p + sqrt(V_H)
 << H + sqrt(V_H).                                    (5.5)
```

The block-energy inequality is

```text
F_p
 <= ceil(M/(H+1))
    (M + 2 sum_{h<=H} C_h).                          (5.6)
```

Hence

```text
F_p
 << p^2/H
    + (p/H) sqrt(V_H)
    + p.                                              (5.7)
```

Two different T_2 budgets now appear.

### 5.1 Budget for full COINC

Full COINC asks for

```text
V_H << pH.
```

By (5.4), it is enough to have

```text
sqrt(H T_2) << pH,
T_2(H,H) << p^2 H.                                   (5.8)
```

This is the mean-square form of the uniform shell target |A_d|<<p.

### 5.2 Budget only for F_p << p^(4/3)

At H=p^(2/3), equation (5.7) gives p^(4/3) provided

```text
sqrt(V_H) << p,
V_H << p^2.                                          (5.9)
```

By (5.4), a sufficient T_2 condition is

```text
sqrt(H T_2) << p^2,
T_2(H,H) << p^4/H.                                   (5.10)
```

At H=p^(2/3), this is

```text
T_2(H,H) << p^(10/3) = p^2 H^2.                     (5.11)
```

This is a factor H weaker than the T_2 budget for COINC.

Thus the d-average can bypass COINC and still prove the desired new energy exponent.

```text
|S_h(t)| <= (4h+1) sqrt(p),
```

For fixed d,t,

```text
|R_d(t)|
```

Inserting this directly into (3.2) gives

```text
|A_d| << pH^3,
```

A better unconditional bound comes from the degree-fiber estimate (4.3):

```text
|E_{h,h+d}| << ph,
```

```text
|E_{h,h+d}| << h(h+d) sqrt(p),
|A_d| << H^3 sqrt(p),
T_2(D,H) << D p H^6.                                 (6.5)
```

```text
T_2(D,H)
 << D min(p^2 H^4, p H^6),                           (6.6)
```

subject to the component bookkeeping required for the second term.

For D comparable to H and H=p^(2/3), the degree bound gives



## 7. Parseval in t and the four-gap object

Cauchy in t gives

```text
|A_d|^2
 <= ((p-1)/p^2) sum_{t!=0}|R_d(t)|^2,               (7.1)
```

again ignoring only the already explicit forced correction.

Define the pair-difference histogram

```text
eta_d(a)
 = #{(h,r,r'):
       1<=h<=H-d,
       r in I_h,
       r' in I_{h+d},
       f_h(r)-f_{h+d}(r')=a}.                         (7.2)
```

Then

```text
R_d(t) = sum_a eta_d(a)e_p(ta).                       (7.3)
```

Put

```text
P_d = sum_a eta_d(a)
    = sum_{h<=H-d} n_h n_{h+d}.                       (7.4)
```

Exact Parseval gives

```text
(1/p) sum_{t!=0}|R_d(t)|^2
 = sum_a eta_d(a)^2 - P_d^2/p.                       (7.5)
```

The first term in (7.5) counts the four-gap equality

```text
f_h(r)-f_{h+d}(r')
 = f_h'(s)-f_{h'+d}(s'),                             (7.6)
```

summed over h,h',r,r',s,s'.

Thus a sufficient four-gap statement is

```text
sum_{d<=D}
  (sum_a eta_d(a)^2 - P_d^2/p)
 << p^(2+eps) H D.                                   (7.7)
```

When D is comparable to H, the right side is p^(2+eps)H^2.

### 7.1 The diagonal scale

The tautological diagonal in (7.6), obtained by taking

```text
h'=h,
s=r,
s'=r',
```

contains exactly P_d tuples. Since H=o(p),

```text
P_d
 = (H-d)p^2 + O(pH^2).                               (7.8)
```

Therefore

```text
sum_{d<=D} P_d
 = p^2(DH-D(D+1)/2) + O(p D H^2).                    (7.9)
```

For D comparable to H this has scale

```text
p^2 H^2.                                             (7.10)
```

A precision point: P_d is a diagonal term in the expansion of sum_a eta_d(a)^2. It is not, by itself, a formal lower bound for the centered variance in (7.5), because P_d^2/p subtracts the global random main term and an off-diagonal deficit can offset part of the diagonal. But any standard proof that retains the diagonal and estimates only an off-diagonal remainder has the baseline (7.10).

The answer to the user's diagonal-budget question is therefore split:

```text
For full COINC:
  needed T_2 scale = p^2 H;
  four-gap diagonal scale = p^2 H^2;
  the diagonal exceeds the budget by H.

For the direct p^(4/3) energy target:
  needed T_2 scale at H=p^(2/3) = p^2 H^2;
  four-gap diagonal scale = p^2 H^2;
  the diagonal exactly saturates, but does not exceed, the budget.
```

This is the central verdict.

## 8. The sharp averaged lemma and its consequence

The right replacement for uniform SHELL VARIANCE is:

```text
[FOUR-GAP-DIAGONAL]
For every eps>0 and H<=p^(2/3), after exact removal of all
forced and boundary components,

sum_{d=1}^{H-1} |A_d(H)|^2
  <<_eps p^(2+eps) H^2.                               (8.1)
```

Equivalently, it is enough to prove the diagonal-sized difference-histogram variance

```text
sum_{d=1}^{H-1}
  (sum_a eta_d(a)^2 - P_d^2/p - forced_d)
  <<_eps p^(2+eps) H^2.                               (8.2)
```

Here forced_d must be an exact component contribution, not an unsigned upper bound.

### Proposition

Assume (8.1), the known O(pH) bound for the d=0 and forced shells, and the exact D2-D3 identities. Then

```text
F_p <<_eps p^(4/3+eps).                               (8.3)
```

### Proof

By Cauchy in d,

```text
sum_{d<H}|A_d|
 <= sqrt(H T_2(H,H))
 <<_eps p^(1+eps/2) H^(3/2).                         (8.4)
```

Thus

```text
V_H
 <<_eps pH + p^(1+eps/2)H^(3/2).                     (8.5)
```

D2-D3 give

```text
sum_{h<=H}C_h
 <<_eps H + p^(1/2+eps/4)H^(3/4).                    (8.6)
```

Insert this into the block inequality:

```text
F_p
 <<_eps p^2/H
       + p^(3/2+eps/4)H^(-1/4)
       + p.                                           (8.7)
```

Choose

```text
H = floor(p^(2/3)).
```

The first two terms are both p^(4/3+O(eps)), proving (8.3).

This proposition is referee-safe and does not invoke the sigma ladder or misuse its triple-count variable.

## 9. What Markov would actually say under the sharp lemma

Under (8.1), Markov gives

```text
#{d<H : |A_d| > lambda p sqrt(H) p^(eps/2)}
 << H/lambda^2.                                      (9.1)
```

Thus the natural average-shell scale furnished by the four-gap diagonal is

```text
|A_d| about p sqrt(H),
```

not p.

At H=p^(2/3), this is p^(4/3). The sum over d is nevertheless controlled by Cauchy at scale pH^(3/2)=p^2, exactly what the block-energy argument can absorb.

So the new angle does produce a meaningful "most d" statement, but only at the p sqrt(H) scale. It does not produce the p-scale shell bound required for COINC.

## 10. Can fixed-d algebraicity prove [FOUR-GAP-DIAGONAL]?

Not with the current tools.

For fixed (h,h',d), equation (7.6) defines a three-dimensional hypersurface in four position variables after denominators are cleared. Its degree grows with h+h'+d. A separate Lang-Weil estimate for each triple has a complexity-dependent error of size at least a polynomial in H times p^(5/2). There are about H^3 triples. Summing these estimates is vastly larger than p^2H^2.

Even random-sign cancellation among those separate trace errors is not automatically enough unless one also proves a strong collapse of the cohomological rank across the full (h,h',d) family. This is the same family-compatibility obstruction at fourth-moment level.

The diagonal terms leave no power-saving margin: at D comparable to H, the entire admissible budget is already p^2H^2. The theorem must show that the centered off-diagonal four-gap contribution is at most the same scale, up to p^eps. Any positive power excess destroys the p^(4/3) conclusion.

Thus fixed-d algebraicity does not become stronger merely because d is averaged. The averaging has transformed the target from pair-curve Hasse-Weil to a quenched four-gap large-sieve statement.

## 11. Sharpest provable statement on this axis

What is proved unconditionally from the current inputs is:

```text
T_2(D,H) << D p^2 H^4,                               (11.1)
```

and, after pair-curve component control,

```text
T_2(D,H) << D p H^6.                                 (11.2)
```

Together:

```text
T_2(D,H) << D min(p^2H^4, pH^6).                     (11.3)
```

These do not improve the banked ENERGY-3/2 theorem.

The strongest useful conditional statement is [FOUR-GAP-DIAGONAL], which is exactly at the natural diagonal scale and implies p^(4/3).

No intermediate theorem of the form "all but p^(-delta) of the d-shells are good" is useful with the current trivial exceptional-shell bound unless the exceptional set is eventually empty. The second moment must be used globally through Cauchy.

## 12. Final verdict

The d-averaged second moment is not a free weakening of uniform SHELL VARIANCE.

It changes the target as follows:

```text
Uniform shell variance:
  |A_d| << p for every d
  -> T_2 << p^2H
  -> COINC
  -> potentially E1-scale behavior.

Diagonal-sized d-average:
  T_2 << p^2H^2
  -> V_H << pH^(3/2)
  -> F_p << p^(4/3) at H=p^(2/3).
```

The first arrow in the second line is sharp for the Cauchy-Parseval method because the four-gap diagonal already has size p^2H^2.

Therefore:

```text
As a route to COINC: dead.
As a direct route to a new p^(4/3) theorem: mathematically valid and sharply formulated.
As something currently provable from fixed-d Weil bounds: no.
```

The next attack should be only the following single lemma:

```text
[FOUR-GAP-DIAGONAL]
The centered four-gap difference histogram has no positive-power
excess above its tautological diagonal, uniformly for H<=p^(2/3).
```

That lemma is strictly weaker than uniform shell variance, exactly matched to the p^(4/3) goal, and no longer pretends that a density-one set of good d can absorb uncontrolled exceptional shells.
