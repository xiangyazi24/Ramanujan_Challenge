# Local Fourier data, Hom classification, and the exact weight barrier

## 0. Verdict

There are four conclusions.

1. [PROVED + STANDARD] The count

```text
dim H_c^1(X_h,L_psi(t*f_h)) = 4h+1
```

is correct on the good-pole locus, but it has a useful internal split:

```text
pure core rank       = 4h-2,
three endpoint lines = 3.
```

The three extra dimensions come from deleting `r=infinity,0,-h-1`; their phase values are `0,c_h,-c_h`. They are lower-weight, completely explicit, and harmless for the second-moment budget.

2. [CORRECTION] The Fourier sheaf is lisse on `G_m`. Its finite singularity set in the `t`-line is not the set of critical values of `f_h`. Every core Fourier sheaf has the same two singular points

```text
t=0 and t=infinity.
```

The critical values occur instead as formal exponential factors at `t=infinity`. This distinction is essential for the Hom argument.

3. [GAP] Complete local data distinguishes the full good core sheaves for different `h`, because their ranks and tame multiplicities differ. It does not by itself prove

```text
Hom_geom(F_h,F_h')=0.
```

That implication requires geometric irreducibility. Without irreducibility, two globally different sheaves may share a constituent. The exact unconditional Hom formula is

```text
dim Hom_geom(P_h,P_h')
  = number of dominant geometric components of
      f_h(r)=f_h'(r')
    minus 1.
```

Thus the proposed Hom classification is exactly the difference-curve component problem in another language. The previously predicted `O(H)` exception list is conditional, not proved.

4. [PROVED WEIGHT AUDIT] After the top Tate/Hom classes are removed, the generic core-core correlation still has a weight-3 parabolic space of dimension `Theta(h*h')`. Summed over `h,h'<=H`, this is `Theta(H^4)`. Deligne gives the generic error

```text
H^4*p^(3/2),
```

so the allowed `p^2*H` budget only reaches

```text
H <= p^(1/6).
```

Even the hypothetical assertion that all but `O(H^2)` dimensions have weight at most 2 reaches only `H<=p^(1/3)`. Therefore no sheaf-generic purity argument reaches the target `H=p^(2/3)`.

The most plausible missing feature is the exact order-two `h`-direction difference equation, not the mixed rank-four Frobenius crystal. The sharp target is an Apery tau-large-sieve inequality stated in Section 8.

## 1. Good reduction, actual pole orders, and reflection

Put

```text
f_h(r) = Delta_(r,h)
       = N_h(r)/D_h(r),

D_h(r) = product_(j=1)^h (r+j)^3.
```

The exact pole coefficient from Q6547 is

```text
N_h(-j)
  = (-1)^(j-1)*((j-1)!)^3*b_(j-1)
    *((h-j)!)^3*b_(h-j),
```

hence

```text
f_h(r)
  = a_(h,j)/(r+j)^3 + lower principal parts,

a_(h,j) = b_(j-1)*b_(h-j).                     (1.1)
```

This needs one finite-field qualification.

### 1.1 Pole drop is controlled by the Apery orbit itself

Over `Q`, all `h` poles have order 3. Modulo `p`, define

```text
d_(h,j) = actual pole order of f_h at r=-j,
```

so

```text
d_(h,j) in {0,1,2,3}.
```

If `a_(h,j)!=0 mod p`, then `d_(h,j)=3`. If `a_(h,j)=0`, the cubic term disappears and the pole can drop. Thus the assertion that all poles remain cubic for every `h<=H` is not uniform in one prime: the bad-pole set is encoded by the same residues `b_n mod p` that the collision project is trying to control.

Put

```text
s_h = #{j : d_(h,j)>0},
n_h = sum_(j=1)^h d_(h,j).
```

Then `n_h` is the degree of the reduced rational map `f_h:P^1->P^1`. On the good-pole locus,

```text
s_h=h,
n_h=3h.                                          (1.2)
```

All local Fourier formulas below first appear in this general `d_(h,j)` form and are then specialized to (1.2).

### 1.2 Exact antisymmetry

The continuant reflection identity gives

```text
f_h(-h-1-r) = -f_h(r).                           (1.3)
```

Indeed,

```text
N_h(-h-1-r) = (-1)^(h-1)*N_h(r),
D_h(-h-1-r) = (-1)^h*D_h(r).
```

The three regular points deleted to obtain the exact nonwrapping window satisfy

```text
f_h(infinity) = 0,
f_h(0)        = c_h,
f_h(-h-1)     = -c_h.                            (1.4)
```

The finite critical points are paired by `r -> -h-1-r`, and their critical values are paired by `a -> -a`.

## 2. The core and exact-window cohomology

Work first in the `ell`-adic category, where Laumon's local Fourier transform gives the most explicit local description. The same trace and weight bounds have the rigid-cohomological realization used in Q6547.

Let

```text
V_h = P^1 minus {actual poles of f_h}.
```

The map

```text
f_h:V_h -> A^1
```

is finite. For `t!=0`, let

```text
L_(h,t) = L_psi(t*f_h).
```

Assume `p>3`, `h<p`, and separability. Since `L_(h,t)` is geometrically nontrivial, `H_c^0` and `H_c^2` vanish.

### 2.1 Core dimension

[STANDARD] Grothendieck-Ogg-Shafarevich gives

```text
chi_c(V_h,L_(h,t))
  = 2-s_h-sum_j d_(h,j).
```

Therefore

```text
dim H_c^1(V_h,L_(h,t))
  = n_h+s_h-2.                                   (2.1)
```

On the good-pole locus this is

```text
dim H_c^1(V_h,L_(h,t)) = 4h-2.                 (2.2)
```

### 2.2 Exact-window dimension

The exact window deletes all labeled points

```text
infinity, 0, -1, ..., -h, -h-1.
```

Even if one of the labeled pole points becomes removable after reduction, it is still excluded from the combinatorial window. Thus

```text
X_h = P^1 minus {infinity,0,-1,...,-h,-h-1}.
```

The Euler characteristic is

```text
chi_c(X_h,Q_ell)=-(h+1).
```

Hence

```text
dim H_c^1(X_h,L_(h,t))
  = h+1+n_h.                                     (2.3)
```

In particular, when every pole remains cubic,

```text
dim H_c^1(X_h,L_(h,t)) = 4h+1.                 (2.4)
```

The difference between (2.3) and (2.1) is

```text
h-s_h+3.                                         (2.5)
```

It consists of three regular endpoints plus one additional punctual line for every labeled pole position that becomes removable modulo `p`.

On the good-pole locus, the long exact sequence for deleting the three regular points gives

```text
0 -> L_psi(0*t) direct_sum L_psi(c_h*t)
     direct_sum L_psi(-c_h*t)
  -> H_h^win
  -> H_h^core
  -> 0.                                          (2.6)
```

Here `H_h^win` and `H_h^core` denote the `t`-parameter cohomology sheaves `H_c^1` of `X_h` and `V_h`. Formula (2.6), or its corresponding distinguished triangle under another Fourier normalization, is the precise origin of the extra 3 in `4h+1`.

At the trace-function level there is no convention issue:

```text
S_h^win(t)
  = S_h^core(t)
    - 1 - psi(c_h*t) - psi(-c_h*t).              (2.7)
```

## 3. Local monodromy before Fourier transform

Let

```text
A_h = (f_h)_* Q_ell
```

on the `y`-line, and split off the global constant constituent:

```text
A_h = Q_ell direct_sum P_h.                      (3.1)
```

The rank of `P_h` is `n_h-1`.

### 3.1 At y=infinity

[STANDARD] Since every pole is tame for `p>3`, the geometric inertia representation is

```text
P_h | I_infinity
  = 1^(s_h-1)
    direct_sum_(j:d_(h,j)>0)
      direct_sum_(m=1)^(d_(h,j)-1)
        chi_(d_(h,j))^m.                         (3.2)
```

The leading coefficient `a_(h,j)` can change an arithmetic unramified twist, but over the geometric inertia group it can be absorbed by rescaling a local parameter. Thus the Apery products in (1.1) do not distinguish `Hom_geom` through the inertia type at `y=infinity`; the pole orders do.

On the good-pole locus, (3.2) becomes

```text
P_h | I_infinity
  = 1^(h-1)
    direct_sum chi_3^h
    direct_sum (chi_3^(-1))^h.                  (3.3)
```

The superscript `h` in (3.3) means multiplicity, not tensor power.

### 3.2 At a finite branch value

Let `a` be a finite branch value. For each ramification point `x` over `a`, let

```text
e_x = ramification index of f_h at x.
```

When `p` does not divide `e_x`, the nontrivial vanishing part is

```text
P_h^van | I_a
  = direct_sum_(x:f_h(x)=a, e_x>1)
      direct_sum_(m=1)^(e_x-1) chi_(e_x)^m.      (3.4)
```

All these finite local components are tame. In the Morse case, `e_x=2` and each critical point contributes one quadratic character.

## 4. Laumon local Fourier transform

Let

```text
G_h = FT_psi(P_h[1])
```

with the standard perverse shift; harmless Gauss-sum and Tate normalizations are suppressed. Its trace is the core exponential sum up to the one global Fourier sign.

### 4.1 The singularity-set correction

[STANDARD] `G_h` is lisse on `G_m`. Its only singularities on `P^1_t` are

```text
t=0 and t=infinity.                              (4.1)
```

The finite critical values of `f_h` are not finite singular points in the `t`-line. They occur as formal Artin-Schreier exponential factors inside the local representation at `t=infinity`.

This corrects the premise that different sets of critical values give different singularity sets. They give different formal types at the same singular point.

### 4.2 Local data at t=0

[STANDARD, Laumon local FT from infinity to 0] The semisimplified local type is

```text
G_h | I_0
  = U_2^(s_h-1)
    direct_sum_(j:d_(h,j)>0)
      direct_sum_(m=1)^(d_(h,j)-1)
        chi_(d_(h,j))^(-m).                      (4.2)
```

Here `U_2` is the rank-two tame unipotent Jordan block. Every summand in (4.2) has break 0, so

```text
Swan_0(G_h)=0.                                   (4.3)
```

The rank check is exact:

```text
2(s_h-1) + sum_j(d_(h,j)-1 over d_(h,j)>0)
  = n_h+s_h-2.                                   (4.4)
```

On the good-pole locus,

```text
G_h | I_0
  = U_2^(h-1)
    direct_sum chi_3^h
    direct_sum (chi_3^(-1))^h,                  (4.5)

rank(G_h)=4h-2.                                  (4.6)
```

The standard model for the `U_2` term is the Kloosterman phenomenon: two unramified branches over `y=infinity` leave one excess trivial inertia constituent, whose local Fourier transform is a rank-two unipotent block at `t=0`.

### 4.3 Local data at t=infinity

Let `Crit_h` be the ramification points of `f_h` lying in `V_h`, including the point `r=infinity`. Put

```text
a_x = f_h(x).
```

[STANDARD, stationary phase] Up to unramified Gauss twists, the formal local representation is

```text
G_h | I_infinity
  = direct_sum_(x in Crit_h)
      direct_sum_(m=1)^(e_x-1)
        L_psi(a_x*t) tensor chi_(e_x)^(-m).       (4.7)
```

Consequently:

```text
break = 1, Swan = 1
  for each rank-one factor with a_x!=0;

break = 0, Swan = 0
  for each factor with a_x=0.                    (4.8)
```

The rank in (4.7) is

```text
sum_(x in Crit_h)(e_x-1)=n_h+s_h-2.             (4.9)
```

Equation (4.9) follows directly from Riemann-Hurwitz: total ramification is `2n_h-2`, while the poles contribute `n_h-s_h`.

### 4.4 The good-Morse specialization

Assume now:

```text
- every pole remains cubic;
- r=infinity has ramification index 3 over value 0;
- the other critical points are simple;
- their critical values are nonzero.
```

Then there are exactly

```text
4h-4
```

finite Morse critical points, counted with multiplicity. Let their values be the multiset `A_h`. Formula (4.7) becomes

```text
G_h | I_infinity
  = chi_3 direct_sum chi_3^(-1)
    direct_sum_(a in A_h)
      (L_psi(a*t) tensor chi_2).                 (4.10)
```

Therefore

```text
rank break 0 at infinity = 2,
rank break 1 at infinity = 4h-4,
Swan_infinity(G_h)       = 4h-4.                (4.11)
```

Together, (4.5) and (4.10) verify the core rank `4h-2` from local Fourier data.

### 4.5 Exact-window local data

On the good-pole locus, (2.6) adds the three rank-one factors

```text
1,
L_psi(c_h*t),
L_psi(-c_h*t).                                   (4.12)
```

At `t=0` all three are unramified. At `t=infinity`, the first has break 0, and the last two have break 1 when `c_h!=0`.

Thus, when `c_h!=0`, the exact-window semisimplified break count is

```text
at t=0:
  break 0 rank = 4h+1;

at t=infinity:
  break 0 rank = 3,
  break 1 rank = 4h-2,
  total rank   = 4h+1.                           (4.13)
```

If `c_h=0 mod p`, all three endpoint lines are tame and the last line of (4.13) changes accordingly. In either case, the endpoint part is explicit and lower-weight.

## 5. What local data does and does not prove about Hom

### 5.1 Fourier equivalence reduces Hom to the finite covers

[STANDARD] Fourier transform is an autoequivalence on the relevant perverse category. Hence

```text
Hom_geom(G_h,G_k) = Hom_geom(P_h,P_k).           (5.1)
```

Let `c_(h,k)` be the number of geometric irreducible components of

```text
f_h(r)=f_k(r')                                   (5.2)
```

that dominate the common `y`-line. Since `(f_h)_*1` and `(f_k)_*1` are permutation sheaves, the dimension of their Hom is the number of orbits on the product of generic fibers, namely `c_(h,k)`. Splitting off the unique constant constituent on each side gives the exact formula

```text
dim Hom_geom(P_h,P_k) = c_(h,k)-1.              (5.3)
```

This is an unconditional classification, but it is a classification in terms of the component count of the difference curve.

In particular:

```text
h!=k:
  Hom_geom(G_h,G_k)=0
  iff f_h(r)=f_k(r') is geometrically irreducible;

h=k:
  dim End_geom(G_h)=1
  iff the fiber product has exactly the diagonal
     and one irreducible residual component.      (5.4)
```

Thus the Hom problem has not escaped the curve-family problem; it is the same problem expressed categorically.

### 5.2 The irreducible-sheaf shortcut is conditional

If `P_h` is geometrically irreducible, then the monodromy group of the degree-`n_h` cover acts 2-transitively on its sheets. Conversely, 2-transitivity makes the trace-zero permutation representation irreducible.

Under the hypothesis

```text
P_h is geometrically irreducible for every h>=2, (IRR)
```

one obtains immediately, on the good-pole locus,

```text
Hom_geom(G_h,G_k)=0 for h!=k,
```

because irreducible sheaves with different ranks `4h-2` and `4k-2` cannot be isomorphic. On the diagonal Schur gives one scalar endomorphism.

The case `h=1` is explicitly reducible: `f_1(r)=1/(r+1)^3`, and the core Fourier sheaf is the sum of the two nontrivial cubic Kummer lines. It can be isolated separately.

Therefore, conditional on (IRR), the only top-weight exception list is the diagonal, with the explicit `h=1` refinement. Its size is `O(H)`.

But (IRR) is open for the growing family. It does not follow from different total local data. A reducible sheaf of rank `4h-2` can share a smaller constituent with a reducible sheaf of another rank.

### 5.3 Full local types versus common local constituents

On the good-Morse locus, the local type at `t=0` already determines `h`: it contains `h-1` copies of `U_2` and `h` copies of each nontrivial cubic character. Hence

```text
complete local type of G_h
  = complete local type of G_k
  implies h=k.                                   (5.5)
```

This proves that different good `h` cannot give isomorphic full sheaves. It does not prove that they have no common summand.

The critical-value discriminator can be made exact. Remove the pole factors from the derivative numerator and define

```text
R_h(r)
  = (N_h'(r)*D_h(r)-N_h(r)*D_h'(r))
    / product_(j=1)^h (r+j)^2.                   (5.6)
```

On the good locus,

```text
deg R_h = 4h-4.
```

Define the finite branch-value polynomial

```text
Br_h(Y)
  = Res_r(R_h(r),N_h(r)-Y*D_h(r)).               (5.7)
```

Reflection (1.3) implies

```text
Br_h(-Y) = scalar*Br_h(Y).                       (5.8)
```

A common nonzero exponential factor at `t=infinity` requires

```text
gcd(Br_h(Y),Br_k(Y)) != 1
```

after retaining the tame labels and multiplicities. This is a necessary local condition for a common wild constituent. It is not a sufficient global Hom criterion.

No all-`h` theorem currently proves that the only pairs with common nonzero critical values form an `O(H)` set. In bad reduction, even the pole-order profiles are controlled by products of Apery residues, so an unconditional classification would already contain a substantial part of the original orbit problem.

### 5.4 Exact status of the requested O(H) list

The strongest honest statement is:

```text
[PROVED]
On the good-pole, good-Morse locus, equality of the full local
formal types occurs only on the diagonal h=k.

[CONDITIONAL ON IRR]
Hom_geom(G_h,G_k)=0 off the diagonal; the exception list is O(H).

[OPEN]
Prove IRR, equivalently the component formula
  c_(h,k)=1+1_(h=k)
for the growing family, with h=1 handled separately.
```

Local Fourier theory supplies excellent necessary invariants. It does not by itself prove the missing global component theorem.

## 6. The exact weight decomposition and budget

The explicit endpoint factors can be removed before doing the weight audit. This is not cosmetic; it isolates the only genuinely difficult pure part.

### 6.1 Endpoint factors are harmless by direct Fourier orthogonality

Let

```text
E_h(t)=1+psi(c_h*t)+psi(-c_h*t).
```

For arbitrary coefficients `alpha_h`, finite Fourier orthogonality gives the crude but sufficient bound

```text
sum_t |sum_(h<=H) alpha_h*E_h(t)|^2
  <= 9*p*H*sum_(h<=H)|alpha_h|^2.                (6.1)
```

The right side is below `p^2*sum|alpha_h|^2` whenever `H<=p`. Thus the endpoint lines do not create the missing barrier. Cross terms with a core bound are controlled by Cauchy-Schwarz.

We now work only with the pure cores `G_h`.

### 6.2 Rank and weight bookkeeping

On the good locus,

```text
q_h = rank(G_h)=4h-2,
sum_(h=1)^H q_h = 2H^2.                          (6.2)
```

The core `G_h` has trace weight 1: its pointwise Frobenius eigenvalues have size `p^(1/2)`. Therefore

```text
E_(h,k) = G_h tensor iota^*G_k,
iota(t)=-t,
```

has trace weight 2 and rank

```text
Q_(h,k)=(4h-2)(4k-2).                            (6.3)
```

After the standard self-duality normalization, `iota^*G_k` is the dual correlation factor. Thus `H_c^2` records geometric Hom classes.

For the full direct sum, the naive core-core rank is exactly

```text
(2H^2)^2=4H^4.                                   (6.4)
```

If one retains the endpoint filtration, its associated-graded ranks are

```text
core-core, weight 2:       4H^4,
core-endpoint, weight 1:  12H^3,
endpoint-endpoint, weight 0: 9H^2.               (6.5)
```

But (6.1) allows the last two lines to be removed analytically, so the load-bearing object is the first line.

### 6.3 Where each cohomological weight occurs

For a pure weight-2 lisse sheaf `E_(h,k)` on `G_m`:

```text
H_c^2:
  weight 4;
  dimension = global invariant/Hom dimension;

Gr_3^W H_c^1:
  pure weight 3;
  canonically the parabolic cohomology
    H^1(P^1,j_*E_(h,k));

W_2 H_c^1:
  weight at most 2;
  boundary kernel coming from the ! versus * gap. (6.6)
```

The endpoint punctual pieces and the `!/*` boundary gap explain lower weights. The rank-four mixed Apery crystal does not lower the weight of the pure core-core parabolic piece.

### 6.4 A quantitative local Euler calculation

Assume the good-Morse description (4.5), (4.10), and assume the finite critical values within each `A_h` are simple. Put

```text
A_h_size = 4h-4,

M_(h,k)
  = #{(a,a') in A_h x A_k : a=a'},
```

counted with multiplicity.

At `t=0`, the invariant dimension of `E_(h,k)` is

```text
I_0(h,k)
  = 2(h-1)(k-1)+2hk
  = 4hk-2h-2k+2.                                 (6.7)
```

The first term comes from `U_2 tensor U_2`, whose invariant space has dimension 2; the second comes from pairing `chi_3` with `chi_3^(-1)` in both orders.

At `t=infinity`, the two tame cubic factors contribute two invariants. A pair of Morse factors contributes an invariant exactly when their critical values agree. Hence

```text
I_infinity(h,k)=2+M_(h,k).                       (6.8)
```

All other factors have break 1. Therefore

```text
Swan_infinity(E_(h,k))
  = Q_(h,k)-4-M_(h,k),                           (6.9)

Artin_0
  = Q_(h,k)-I_0(h,k),

Artin_infinity
  = 2Q_(h,k)-6-2M_(h,k).                         (6.10)
```

Let `g_0(h,k)` and `g_2(h,k)` be the dimensions of global `H^0` and `H^2`. The Euler formula for the middle extension gives the exact top-weight dimension

```text
d_3(h,k)
  := dim Gr_3^W H_c^1(G_m,E_(h,k))

   = g_0(h,k)+g_2(h,k)
     + Q_(h,k)-I_0(h,k)-6-2M_(h,k)

   = g_0(h,k)+g_2(h,k)
     + 12hk-6h-6k-4-2M_(h,k).                  (6.11)
```

For an off-diagonal pair of nonisomorphic irreducible cores, `g_0=g_2=0`.

If each critical-value multiset has no internal repetition, then

```text
M_(h,k) <= 4*min(h,k)-4.
```

Thus (6.11) gives

```text
d_3(h,k)=Theta(h*k)                              (6.12)
```

for a generic pair. This is stronger than a naive conductor upper bound: it proves that the top weight-3 space is genuinely large under ordinary local behavior.

### 6.5 The p^(1/6) barrier

Summing (6.12) over `h,k<=H` gives

```text
sum_(h,k<=H) d_3(h,k)=Theta(H^4).                (6.13)
```

Weight 3 allows eigenvalues of size `p^(3/2)`, so the generic absolute trace bound is

```text
H^4*p^(3/2).                                     (6.14)
```

The COINC budget in Q6547 is

```text
p^2*H.                                           (6.15)
```

Comparing (6.14) and (6.15) gives

```text
H^3 <= p^(1/2),
H <= p^(1/6).                                    (6.16)
```

This recovers the geometric curve-genus barrier in the Fourier category.

### 6.6 The hypothetical weight-2 scenario

Suppose, unrealistically strongly, that only `O(H^2)` dimensions remained of weight 3, while all `O(H^4)` other dimensions had weight at most 2. The error would be

```text
O(H^2*p^(3/2) + H^4*p).                         (6.17)
```

The first term permits `H<=p^(1/2)`, but the second requires

```text
H^3<=p,
H<=p^(1/3).                                      (6.18)
```

Thus lowering the bulk by one full weight still does not reach `H=p^(2/3)`.

At `H=p^(2/3)`, the budget (6.15) allows at most

```text
effective weight-3 trace complexity O(H^(7/4)),
effective weight-2 trace complexity O(H^(5/2)).  (6.19)
```

These exponents are far below the actual dimensions `H^4`. The missing input must therefore be trace cancellation across the family or a genuinely smaller object, not ordinary purity.

### 6.7 What could force a weight drop

The possibilities in the question have the following exact status.

```text
Mixedness of the exact-window K_h:
  yes, but only through the explicit endpoint lines;
  it produces lower weights and is harmless.

The ! versus * gap:
  yes, but it creates the boundary W_2 part;
  it does not remove the pure parabolic Gr_3 part.

Punctual parts:
  yes, but they are precisely the endpoint Fourier lines.

Mixed rank-four crystal upstairs:
  no effect on this weight filtration;
  ordinary Frobenius trace does not see its extension class.
```

A sheaf-theoretic theorem strong enough for the proposed weight-2 scenario would have to assert

```text
sum_(h,k<=H)
  dim H^1(P^1,j_*E_(h,k)) = O(H^2).              (6.20)
```

Equivalently, almost every cross-correlation would have to be cohomologically rigid, or the normalizations of almost all fiber-product curves would have to lose essentially all of their expected genus.

Formula (6.11) shows that (6.20) is incompatible with generic good-Morse local data unless the branch values have `Theta(h*k)` systematic coincidences for almost every pair. No such degeneracy is known, and the numerical random-like behavior points in the opposite direction.

Therefore the realistic route is not dimension collapse. It is cancellation of Frobenius traces across the large weight-3 spaces.

## 7. Known Katz-style precedents

There are three nearby precedents, but none supplies the needed theorem.

1. Rank-one Kummer families have exact character orthogonality. Their aggregate correlation is diagonal and linear in the family size. Their ranks and conductors are fixed, so this is not a growing-rank precedent.

2. Kloosterman, hypergeometric, and Airy sheaves give growing-rank examples that are individually cohomologically rigid under their standard hypotheses. For each individual sheaf, the parabolic cohomology of its own End can vanish.

3. Fourier transform preserves the rigidity index in Katz-Laumon theory.

What is not known in a form applicable here is:

```text
an aggregate direct sum of H pairwise different Fourier sheaves,
with ranks growing like h,
whose complete cross-End cohomology over all H^2 pairs
has dimension or total Frobenius trace only O(H).
```

Individual rigidity controls the diagonal `h=k`. It does not control the `H^2-H` cross terms. I know no Katz-style theorem giving the required linear aggregate bound for a growing-rank family of this type.

## 8. The most plausible non-generic feature

The four proposed special structures do not have equal promise.

### 8.1 Reflection antisymmetry

Reflection gives

```text
f_h(-h-1-r)=-f_h(r).
```

It forces critical values into `+/-` pairs and explains a factor-two organization. It does not reduce `Theta(H^4)` to the budget scale.

### 8.2 Apery self-encoding of pole residues

The coefficients

```text
a_(h,j)=b_(j-1)*b_(h-j)
```

are highly special. But geometric local inertia forgets nonzero leading coefficients, while zero coefficients create pole drops controlled by the original zero problem. This is a useful diagnostic and a source of exceptional strata, not yet a cancellation mechanism.

### 8.3 The mixed rank-four crystal

The mixed crystal is the correct home of the companion coordinate and its syntomic extension class. Ordinary Fourier/Lefschetz traces see only the semisimplified Frobenius eigenvalues. Without a hybrid operator carrying both clock translation and Frobenius, the mixed crystal does not compress the `h`-family.

### 8.4 The three-term h-recurrence

This is the only feature that gives a fixed-order generator for the whole growing family. Since `f_h=Delta_(r,h)`, the recurrence is exactly

```text
(r+h+1)^3*f_(h+1)(r)
  = P(r+h)*f_h(r) - (r+h)^3*f_(h-1)(r).          (8.1)
```

Thus `(f_h,f_(h-1))` is a rank-two tau-difference state in the `h` direction. The additive character destroys literal linear recurrence, so (8.1) does not by itself give a recurrence for `psi(t*f_h)`. Nevertheless, it is the only available source of bounded displacement rank or bispectral compression for the Gram matrix.

### 8.5 Sharp target lemma

Define the exact-window sums

```text
S_h(t)
  = sum_(r=1)^(p-2-h) psi(t*f_h(r)),
  1<=h<=H,
  t in F_p^x.
```

The sharp family statement is:

### [APERY-TAU-LARGE-SIEVE]

For an absolute constant `C`, every sufficiently large prime `p`, every

```text
H<=p^(2/3),
```

and every complex coefficient vector `(alpha_1,...,alpha_H)`, one has

```text
sum_(t!=0)
  |sum_(h<=H) alpha_h*S_h(t)|^2
    <= C*p^2*sum_(h<=H)|alpha_h|^2.              (8.2)
```

Equivalently, the positive Gram matrix

```text
Gamma_(h,k)
  = sum_(t!=0) S_h(t)*conjugate(S_k(t))          (8.3)
```

satisfies

```text
||Gamma||_(op) <= C*p^2.                         (8.4)
```

Taking every `alpha_h=1` gives

```text
sum_(t!=0)|B_t(H)|^2 <= C*p^2*H.                (8.5)
```

By the proved Parseval identity D3,

```text
p*N_coinc(H)-(#S_H)^2 <= C*p^2*H,
```

hence

```text
N_coinc(H)
  <= (#S_H)^2/p + C*p*H
  =  (#S_H)^2/p + O(#S_H).                       (8.6)
```

This is COINC. At `H=p^(2/3)`, the proved block-energy argument then yields

```text
F_p << p^(4/3).                                  (8.7)
```

Statement (8.2) is stronger than the all-ones estimate needed for COINC, but it is the correct form for a recurrence-induced operator theorem. It says that the `h`-family is almost orthogonal at the optimal diagonal scale even though the direct-sum sheaf has `H^4` generic cohomological complexity.

This is a trace-cancellation theorem, not a weight-lowering theorem.

## 9. What to compute next

The following computations decide the route with minimal ambiguity.

### 9.1 Actual pole profiles

For each tested `p,h,j`, compute the full Laurent triple

```text
coefficients of
  (r+j)^(-3), (r+j)^(-2), (r+j)^(-1),
```

and record `d_(h,j)`. This separates genuine good-pole fibers from self-encoded pole drops.

### 9.2 Branch divisors

Compute `R_h` and `Br_h` from (5.6)-(5.7), verify the evenness (5.8), and tabulate exact resultants

```text
Res_Y(Br_h,Br_k).
```

This tests whether nonzero formal exponential factors are actually shared across gaps.

### 9.3 Fiber-product components

Factor

```text
N_h(r)*D_k(r')-N_k(r')*D_h(r)
```

over finite fields and over `Q` for feasible `h,k`. Test the exact target

```text
c_(h,k)=1 for h!=k,
c_(h,h)=2 for h>=2,                               (9.1)
```

with `h=1` separated. This is the actual Hom theorem.

### 9.4 Gram spectrum, not only the all-ones vector

For each prime, form the endpoint-subtracted matrix (8.3). Measure

```text
lambda_max(Gamma)/p^2,
```

not merely

```text
1^T Gamma 1.
```

The large-sieve target predicts a bounded top eigenvalue. A random all-ones test can pass even if another `h`-frequency direction carries a large obstruction.

### 9.5 Recurrence displacement test

Let `T` be the one-step shift in `h`. Search for low numerical rank, low stable rank, or low trace norm in recurrence-adjusted displacements of `Gamma`, with the rational coefficients from (8.1) included. A robust low-displacement phenomenon would be concrete evidence for a tau-difference compression. Its absence would be a strong death certificate for the present main line.
