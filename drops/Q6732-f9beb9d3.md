# (i) Scattered padding survives NO-RUN

Conclusion: [NO-RUN] does NOT reduce the extremal maximum. The q52 extremal value remains Theta(N) under the enlarged abstract constraint set.

The reason is that NO-RUN is a statement about each fixed gap class Z_d, while the extremal construction can move the mass across many gap classes. The padded interval construction is killed, but the scattered analogue survives.

Construction sketch. Let D = sqrt(N)L and choose gaps d_i in (D/2,D]. For each chosen gap d, place at most 3(d-1) starting points in Z_d. Choose them greedily with spacing >= 4 inside each individual Z_d. Give each pair (r_i,r_i+d_i) a private color/fiber. Then:

- each Z_d has no three consecutive elements;
- C_d <= 3(d-1) is automatic;
- reflection can be imposed by adding the reflected pair simultaneously;
- private colors make primitive status k_r=1;
- the clique constraint is satisfied because every color has multiplicity two.

There are Theta(N) available positions. Since the number of allowed gaps is Theta(D), and each gap supports Theta(D) scattered placements, the total capacity is Theta(D^2). In the mesoscopic regime D=sqrt(N)L this is much larger than N, so a Theta(N) primitive set can be embedded.

The hostile check is the 2/3 window law. It does not see this construction. That law bounds m_J(v)-1 for a fixed fiber/color v. Here every artificial fiber has size two globally, hence m_J(v)-1 <= 1 in every interval. The construction may be position-dense across many different colors, but the window law is not a statement about the union of many colors. Therefore there is no contradiction.

Q_D remains small. The scattered primitive pairs alone create essentially no triangles. Adding the same triangle-rich core as in the padded-word theorem gives Q_D = O(D^2 log D), while P_D = Theta(N). Thus P_D Q_D/N^2 still diverges in the abstract model.

Therefore the answer to (i) is: scattered padding exists; NO-RUN is insufficient.

# (ii) Testing candidate extra seeds

(a) NO-RUN

Fails. The construction above already satisfies it.

(b) Gap regularity inside each Z_d

Suppose every two points of Z_d satisfy |x-y| >= g(d). Then

|Z_d| <= 1 + D/g(d).

Summing over d <= D gives

P_D <= sum_d (1+D/g(d)).

To beat the degree sum D^2, one needs g(d) growing. If g(d) >= d^alpha uniformly, then

P_D << D + D * D^(1-alpha) = D^(2-alpha).

Any alpha>0 gives a power saving in the dyadic regime. For the target P_D << N/(L^2 log D) with D=sqrt(N)L, one needs approximately

D^(2-alpha) << N/L^2,

which requires alpha close to 0 only if logarithms are ignored; quantitatively a fixed alpha>0 is enough for FR_eta.

This is a plausible one-dimensional seed, but it is stronger than current transfer-matrix run rigidity. It asks for repulsion, not just absence of short runs.

(c) Additive energy bound on each Z_d

E(Z_d) << |Z_d|^{2+theta} is not enough by itself. The scattered construction can have Z_d with small energy because each Z_d is sparse. The enemy is not concentration inside one gap; it is distribution over many gaps.

A useful version would have to be summed over d:

sum_{d<=D} E(Z_d) << D^{3-epsilon}

or a comparable cross-gap statement. Per-gap energy alone does not kill Theta(N).

(d) Cross-correlation rigidity

This is the first candidate that directly attacks the real obstruction.

A condition of the form

|Z_d intersect (Z_{d'}+t)| << 1

uniformly for d != d'

prevents many primitive edges from sharing endpoints in a way that generates hidden triangles. Combined with clique counting, it gives a linear relation between triangle count and edge count.

This is essentially the missing quenched growing-gap anti-coexistence statement. It has the correct target shape.

# (iii) Minimal seed S*

The minimal useful seed is not NO-RUN. It is a cross-gap anti-coincidence statement.

A sufficient formulation is:

[S*] For D in the mesoscopic range,

sum_{d,d' in (D/2,D]} |Z_d intersect (Z_{d'}+t)| <= D^(3-eta)

uniformly over all relevant shifts t.

Why this works:

1. Primitive edges are the union of gap fibers.
2. Any excess over linear primitive growth must come from repeated endpoint reuse or triangle formation.
3. Cross-correlation controls endpoint reuse across different gaps.
4. The clique graph then has near-linear 2-path count.
5. The triangle inequality Q_D = O(P_D) replaces the current Q_D = O(S_D^(3/2)).
6. Capacity arguments then force P_D below the dangerous N/(L^2 log D) scale.

The likely hierarchy is:

NO-RUN < gap regularity < per-gap additive energy < cross-gap rigidity.

Only the last two can plausibly see the scattered adversary; only cross-gap rigidity directly targets the terminal obstruction.

Apery-specific prospects:

- NO-RUN has a realistic transfer-matrix/eigenvector proof mechanism. It studies consecutive positions.
- Gap regularity might follow from a stronger form of restart/zero-spacing in the h-direction.
- Additive energy requires controlling arithmetic spacing inside zero sets.
- Cross-gap rigidity needs a different mechanism: a family-averaged monodromy theorem, probably a two-gap correlation estimate for the cocycle, not a fixed-gap spectral argument.

The correct investment decision is therefore: proving NO-RUN alone is insufficient. It may be a useful lemma, but the main target must be a cross-gap seed.

Least confident step: the claimed sufficiency of the displayed S* formulation. The combinatorial route from cross-correlation to the exact P_D Q_D bound still needs a fully written incidence inequality; the direction is clear but constants/exponents are not audited.

Blind spot in the question itself: it assumes the adversary's only surviving freedom is scattered placement. A stronger hidden obstruction may be that genuine Apery arithmetic forbids the private-color model entirely through global monodromy constraints. The abstract extremal model cannot see that obstruction.
