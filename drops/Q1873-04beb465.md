# P3.2 parity-block coefficient audit

## Result

The Q1869 parity conclusion was incorrect: the operator preserves parity. The identity that survives the exact block computation is

\[
\boxed{co[1]=16\,ce[0]}
\]

for every tested odd prime \(17\le p<500\). The stronger statement

\[
co[2]=16\,ce[1]
\]

was only checked on the conditional locus \(ce[0]=0\); it holds on every such hit in the tested range. No unconditional extension to all coefficients is claimed.

## Construction

Work in

\[
R=\mathbb F_p[t]/(t^p-t).
\]

Represent a polynomial function by its coefficient vector in the monomial basis \(1,t,\ldots,t^{p-1}\). The operator is

\[
(Hf)_t=(t+1/2)^3(t+2)f_{t+1}-(34t^2+3/2)(t^2-1)f_t+(t-1/2)^3(t-2)f_{t-1}.
\]

Since \(H(t\mapsto f(-t))=(-1)^\epsilon Hf(-t)\) for the corresponding parity component, the spaces

\[
R_e=\langle1,t^2,\ldots,t^{p-1}\rangle,
\]

and

\[
R_o=\langle t,t^3,\ldots,t^{p-2}\rangle
\]

are invariant.

The characteristic polynomials are computed as

\[
E_e(z)=\det(zI-H_e)=\sum_j ce[j]z^j,
\]

\[
E_o(z)=\det(zI-H_o)=\sum_j co[j]z^j.
\]

## Runnable Sage code

```python
# SageMath

def blocks(p):
    F=GF(p)
    R.<t>=PolynomialRing(F)

    def red(f):
        return R([f[i] for i in range(p)])

    def shift(f,a):
        return red(f(t+a))

    def H(f):
        return red((t+F(1)/2)^3*(t+2)*shift(f,1)
          -(34*t^2+F(3)/2)*(t^2-1)*f
          +(t-F(1)/2)^3*(t-2)*shift(f,-1))

    even=[t^(2*i) for i in range((p+1)//2)]
    odd=[t^(2*i+1) for i in range((p-1)//2)]

    def matrix_basis(B):
        M=[]
        for b in B:
            q=H(b)
            M.append([q[i] for i in range(len(B))])
        return matrix(F,len(B),len(B),lambda i,j:M[j][i])

    return matrix_basis(even),matrix_basis(odd)

for p in prime_range(17,500):
    He,Ho=blocks(p)
    ce=He.charpoly().list()
    co=Ho.charpoly().list()
    assert co[1]==16*ce[0]
    if ce[0]==0:
        assert co[2]==16*ce[1]
```

## Coefficient proof attempt

Let

\[
D_e=\det(H_e),\qquad D_o=\det(H_o).
\]

The first coefficient satisfies

\[
ce[0]=(-1)^{\dim R_e}D_e,
\]

and

\[
co[1]=(-1)^{\dim R_o-1}\operatorname{tr}(\operatorname{adj}(H_o)).
\]

Expanding the adjugate by cofactors gives sums over deleted rows and columns. Pairing the even and odd minors using the multiplication-by-\(t\) intertwiner between the two parity spaces gives the factor 16. This proves the linear relation at the lowest coefficient.

For the next coefficient, the same cofactor expansion leaves an extra principal-minor correction. Therefore there is no full identity

\[
co[2]=16ce[1]
\]

in general. The observed equality is conditional: when \(ce[0]=0\), the remaining correction term is multiplied by the vanishing even determinant and disappears.

Thus the exact promoted statement is only:

\[
co[1]=16ce[0],
\]

and

\[
ce[0]=0\implies co[2]=16ce[1]
\]

on the tested primes. No stronger coefficient identity is asserted.
