# Verdict

The weak target

\[
F_{\rm top}(N)=o\!\left(\frac{N^2}{\log^2 N}\right)
\]

is **not proved** by the currently available local Apéry inputs, but the q=1 geometry gives a much sharper reduction than the tautological pair-intersection expansion.

For the exact top block, after the harmless endpoint cleanup explained below,

\[
\boxed{
\lambda(m)
=\#\{p:\ N<p\le m,\ p\mid b_m\}.
}
\tag{1}
\]

Thus the common outer row is completely retained: q=1 targets are precisely the prime divisors of the single integer `b_m` lying above `N`.

Let

\[
\mathcal P_N(m)=\{p\text{ prime}:N<p\le m,\ p\mid b_m\},
\qquad
\lambda(m)=|\mathcal P_N(m)|.
\]

Using the repository's unconditional single-prime bound

\[
Z(p)=\#\{0\le r<p:p\mid b_r\}\ll p^{2/3},
\]

the total q=1 incidence mass satisfies

\[
\boxed{
T_{\rm top}(N):=\sum_{N<m\le2N}\lambda(m)
\ll \frac{N^{5/3}}{\log N}.
}
\tag{2}
\]

This first moment is already far below the pair-energy scale, but by itself it does not control concentration on one outer row.

The useful new reduction is the following. Put, for definiteness,

\[
L_N=\frac{N^{1/3}}{\log^2 N}.
\]

Then all rows with `lambda(m) <= L_N` contribute only

\[
O\!\left(\frac{N^2}{\log^3 N}\right)
=o\!\left(\frac{N^2}{\log^2N}\right).
\tag{3}
\]

Independently, if an ordered prime pair in one row is called short when
`0 < |p-q| <= H`, then the elementary integer-neighbour bound gives

\[
F_{\rm short}(N;H)\le 2H T_{\rm top}(N).
\tag{4}
\]

Hence already with

\[
H_N^{\rm elem}=\frac{N^{1/3}}{\log^2N}
\]

all short-gap pairs have total mass `O(N^2/log^3 N)`. Using the standard Brun--Titchmarsh interval bound, one can enlarge this to

\[
\boxed{
H_N=\frac{N^{1/3}}{\log\log N},
\qquad
F_{\rm short}(N;H_N)
\ll \frac{N^2}{\log^2N\,\log\log N}.
}
\tag{5}
\]

Therefore the original node is equivalent, up to an already-proved little-oh error, to only the **very-heavy, long-gap sector**

\[
\boxed{
F_{\rm HL}(N)
:=
\sum_{\substack{N<m\le2N\\\lambda(m)>L_N}}
\#\left\{
(p,q)\in\mathcal P_N(m)^2:
 p\ne q,\ |p-q|>H_N
\right\}.
}
\tag{6}
\]

More precisely,

\[
\boxed{
F_{\rm top}(N)
=F_{\rm HL}(N)
+o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{7}
\]

So the smallest remaining theorem after the current inputs is

\[
\boxed{
\text{Q32-FIXEDQ-HEAVY-LONG:}\qquad
F_{\rm HL}(N)=o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{HL}
\]

This is strictly narrower than the original `F_top` theorem and does **not** ask for the much stronger diagonal-AMTD comparison `F_top=O(T_top)`.

There is an exact four-prime formulation without paying a fourth factorial moment: for every hard ordered pair `(p,q)`, choose canonically the two smallest primes of `P_N(m) \ {p,q}`. Since `lambda(m)>L_N`, this is defined for all sufficiently large `N`. The resulting marked four-prime records are in bijection with the summands of `F_HL`. Thus (HL) is also an exact sparsity theorem for **canonical four-prime witnesses with one marked long pair**, not the stronger statement `sum (lambda)_4 = o(...)`.

I do not see a proof of (HL) from the current exact recurrence/reflection toolkit. In fact a scoped CRT star construction below satisfies q=1 Lucas congruences, reflection, endpoint exclusion, no-adjacent zeros, `Z(p)<=2`, the common outer-row geometry, and exponential characteristic-zero height, while producing

\[
F_{\rm top}(N)\asymp\frac{N^2}{\log^2N}.
\]

It does **not** satisfy the distinguished Apéry recurrence with initial vector `(1,5)`. Therefore it is not a counterexample to the desired theorem; it proves that the missing input must be genuinely recurrence/distinguished-orbit and cross-prime, rather than another consequence of the local Lucas/reflection/zero-count package.

# 1. Repository-state audit

The literal label `Q32-FIXEDQ-ENERGY` is not exposed by code search on the connector-visible default branch. The current visible `problems/3.2/AVENUES.md` nevertheless records the relevant doctrine: single-prime Hasse/Franel information is useful for the all-index problem only when it yields a genuine mixed-characteristic correlation, and the all-index section explicitly warns that reflection, interval bounds, bounded codegrees, and generic fiber energy do not by themselves produce the needed cross-prime contraction.

The exact q=1 definitions in the question are enough to settle the endpoint convention. For `N<m<=2N` and `p>N`, a q=1 term requires `p<=m`; otherwise `m-p<0` is not an Apéry index. Thus I use

\[
N<p\le m.
\]

The endpoint `p=m` has `m-p=0` and `b_0=1`, so it never contributes. Hence `p<m` and `p<=m` give the same selected set. For asymptotic `N`, all selected primes are at least `7`, so the factor `5` below is a unit.

# 2. Exact q=1 collapse to one characteristic-zero integer

Let

\[
m=p+r,
\qquad N<p\le m\le2N.
\]

Because `p>N` and `m<=2N`,

\[
0\le r=m-p<p,
\qquad
\left\lfloor\frac mp\right\rfloor=1.
\]

The Apéry Lucas congruence is

\[
b_{qp+r}\equiv b_qb_r\pmod p.
\]

At `q=1`, since `b_1=5`,

\[
b_m=b_{p+r}\equiv5b_r=5b_{m-p}\pmod p.
\tag{8}
\]

For `p>=7`, `5` is invertible modulo `p`, so

\[
\boxed{
p\mid b_{m-p}\iff p\mid b_m.
}
\tag{9}
\]

This proves (1). In particular, expanding `F_top` as independent intersections of `Z_p` and `Z_q` throws away the strongest q=1 feature: the two primes divide the **same integer** `b_m`.

# 3. Exact first moment and its logarithmic size

For a prime `p` in `(N,2N]`, as `m` runs through its q=1 rows, `r=m-p` runs through

\[
0\le r\le2N-p.
\]

Consequently

\[
\boxed{
T_{\rm top}(N)
=
\sum_{N<p\le2N}
\#\bigl(Z(p)\cap[0,2N-p]\bigr).
}
\tag{10}
\]

The `r=0` term is harmless because `b_0=1`.

Using `Z(p)<<p^{2/3}` and the elementary prime count

\[
\pi(2N)-\pi(N)\ll\frac N{\log N},
\]

we get

\[
T_{\rm top}(N)
\ll
(2N)^{2/3}\frac N{\log N}
\ll
\frac{N^{5/3}}{\log N}.
\tag{11}
\]

This proves (2).

A useful characteristic-zero version is obtained from the top radical

\[
R_N(m)=\prod_{p\in\mathcal P_N(m)}p.
\tag{12}
\]

Then

\[
\sum_{N<m\le2N}\log R_N(m)
=\sum_{N<p\le2N}\log p\,
\#\bigl(Z(p)\cap[0,2N-p]\bigr)
\ll N^{5/3}.
\tag{13}
\]

Thus the **unweighted primitive top-radical height is already subcritical**. The difficulty is not its primitive height; it is reuse of one row-prime in many row-pairs.

Indeed, define

\[
W_N=\sum_{N<m\le2N}(\lambda(m)-1)_+\log R_N(m).
\tag{14}
\]

For every row with `k=lambda(m)>=1`,

\[
k\log N\le\log R_N(m)\le k\log(2N).
\]

Therefore

\[
\boxed{
F_{\rm top}(N)\log N
\le W_N
\le F_{\rm top}(N)\log(2N).
}
\tag{15}
\]

So the desired theorem is equivalently the multiplicity-sensitive primitive-height estimate

\[
W_N=o\!\left(\frac{N^2}{\log N}\right).
\tag{16}
\]

Equation (13) alone cannot imply (16): the missing factor is exactly the local reuse multiplicity `lambda(m)-1`.

# 4. Moderate multiplicities are already negligible

Let `L>=1`. On rows with `lambda(m)<=L`,

\[
\lambda(m)(\lambda(m)-1)\le L\lambda(m).
\]

Hence

\[
F_{\le L}(N)
:=
\sum_{\substack{N<m\le2N\\\lambda(m)\le L}}
\lambda(m)(\lambda(m)-1)
\le L T_{\rm top}(N).
\tag{17}
\]

Take

\[
L=L_N=\frac{N^{1/3}}{\log^2N}.
\]

Then (11) gives

\[
\boxed{
F_{\le L_N}(N)
\ll
\frac{N^2}{\log^3N}
=o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{18}
\]

This is stronger than merely discarding rows with at most three selected primes: every row below a growing threshold is already harmless.

For comparison, the simpler fixed four-prime split also follows immediately:

\[
\sum_{\lambda(m)\le3}\lambda(m)(\lambda(m)-1)
\le2T_{\rm top}(N)
\ll\frac{N^{5/3}}{\log N}
=o\!\left(\frac{N^2}{\log^2N}\right).
\tag{19}
\]

Thus any obstruction must in particular contain four distinct top primes in one common outer row.

# 5. Small prime gaps are already negligible

For one row define the ordered short-gap count

\[
S_H(m)
=
\#\{(p,q)\in\mathcal P_N(m)^2:
 p\ne q,\ |p-q|\le H\}.
\]

For a fixed selected prime `p`, there are at most `2H` integer values `q!=p` with `|p-q|<=H`. Therefore

\[
S_H(m)\le2H\lambda(m)
\]

and, after summing rows,

\[
\boxed{
F_{\rm short}(N;H)
:=\sum_mS_H(m)
\le2H T_{\rm top}(N).
}
\tag{20}
\]

With the completely elementary choice

\[
H_N^{\rm elem}=\frac{N^{1/3}}{\log^2N},
\]

(11) gives

\[
F_{\rm short}(N;H_N^{\rm elem})
\ll\frac{N^2}{\log^3N}.
\tag{21}
\]

One can enlarge the discarded gap range by using only a standard prime-distribution upper bound, not Apéry input. For `3<=H<N/2`, Brun--Titchmarsh on the two intervals adjacent to `p` gives uniformly

\[
\#\{q\text{ prime}:0<|q-p|\le H\}
\ll\frac H{\log H}.
\tag{22}
\]

Thus

\[
F_{\rm short}(N;H)
\ll\frac H{\log H}T_{\rm top}(N).
\tag{23}
\]

Taking

\[
H_N=\frac{N^{1/3}}{\log\log N}
\]

and using `log H_N ~ (1/3) log N`, we obtain

\[
\boxed{
F_{\rm short}(N;H_N)
\ll
\frac{N^2}{\log^2N\,\log\log N}
=o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{24}
\]

No zero-set correlation has been assumed here.

# 6. Exact hard-sector decomposition

Use `L_N` from (18) and either the elementary gap `H_N^elem` or the sharper `H_N` from (24). Split every ordered pair into three disjoint classes:

1. `lambda(m)<=L_N`;
2. `lambda(m)>L_N` and `0<|p-q|<=H_N`;
3. `lambda(m)>L_N` and `|p-q|>H_N`.

The first contribution is (18). The second is bounded by (24). The third is exactly `F_HL(N)` from (6). Hence

\[
F_{\rm top}(N)
=F_{\rm HL}(N)
+O\!\left(\frac{N^2}{\log^3N}
+\frac{N^2}{\log^2N\log\log N}\right).
\tag{25}
\]

This proves (7).

## Canonical four-prime marking without a fourth moment

For sufficiently large `N`, `L_N>3`. On every record counted by `F_HL`, the row contains at least four selected primes. Given its marked ordered pair `(p,q)`, let `(u,v)` be the two smallest elements of

\[
\mathcal P_N(m)\setminus\{p,q\},
\qquad u<v.
\]

Then

\[
(m,p,q)\longmapsto(m,p,q,u,v)
\]

is injective and its image is characterized by that canonical rule. Conversely, forgetting `(u,v)` recovers the original hard pair. Thus

\[
\boxed{
F_{\rm HL}(N)=\#\mathcal C_N,
}
\tag{26}
\]

where `C_N` is this canonical marked-four-prime set.

This is deliberately **not** the fourth factorial moment. Replacing one hard pair by all `(lambda-2)(lambda-3)` possible completions would introduce an unnecessary stronger target; the canonical completion costs exactly one record per hard pair.

# 7. What reflection and the recurrence give at q=1

Suppose `p in P_N(m)` and put `r=m-p`. Then `p|b_m`, and (9) gives `p|b_r`. Reflection gives

\[
p\mid b_{p-1-r}.
\tag{27}
\]

Writing

\[
r^\vee=p-1-r=2p-m-1,
\]

we get a second same-prime zero. But this is automatic from `p|b_m`; it is not a second restriction on the top divisor `p`.

Equivalently, if one parametrizes by the reflected index,

\[
p=\frac{m+r^\vee+1}{2}.
\]

Thus a gap split based only on Lucas plus reflection merely repackages the same divisor of `b_m`. It cannot create cross-prime cancellation between two different top divisors `p` and `q` of `b_m`.

The outer-row recurrence modulo a selected prime likewise gives

\[
(m+1)^3b_{m+1}\equiv-m^3b_{m-1}\pmod p,
\]

but this follows immediately by reducing the Apéry recurrence at a prime divisor of `b_m`. For two selected primes it holds separately modulo `p` and modulo `q`; without a new shared characteristic-zero relation it does not couple them.

So option 1 reaches a real boundary: reflection removes no part of the hard sector by itself.

# 8. Characteristic-zero carrier audit

Every top pair in row `m` satisfies

\[
pq\mid b_m.
\tag{28}
\]

The obvious common carrier is therefore the single endpoint integer `b_m`. Its logarithmic height is exponential-row size:

\[
\log b_m=m\log(17+12\sqrt2)+O(\log m),
\]

so

\[
\sum_{N<m\le2N}\log b_m=\Theta(N^2).
\tag{29}
\]

Even if pair contributions could be charged without reuse, this is only the critical `O(N^2)` weighted scale; it contains no vanishing factor. In reality one prime factor of `b_m` participates in `lambda(m)-1` pairs, so (29) is weaker still.

The primitive top radical `R_N(m)` is much cleaner: its aggregate height is only `O(N^{5/3})` by (13). But the exact product of all unordered pair-products in one row is

\[
\prod_{\{p,q\}\subset\mathcal P_N(m)}pq
=R_N(m)^{\lambda(m)-1}.
\tag{30}
\]

Thus any characteristic-zero content intended to dominate every pair separately must address precisely this exponent `lambda(m)-1`; unweighted primitive height cannot do it.

I found no recurrence/resultant identity in the connector-visible map that removes this reuse exponent on the distinguished Apéry row. That is the characteristic-zero form of the remaining obstruction.

# 9. Scoped countermodel: why the local inputs cannot force little-oh

This countermodel is intentionally **not** an Apéry sequence. It shows only that the local inputs used above -- q=1 Lucas, reflection, endpoint exclusion, no-adjacent zeros, small single-prime zero sets, common outer-row geometry, and exponential height -- cannot imply the desired pair-energy saving. Therefore any proof must use an additional consequence of the actual Apéry recurrence/initial vector.

Take the common row

\[
m_0=2N
\]

and the prime set

\[
\mathcal S_N
=\{p\text{ prime}:N+3<p\le6N/5\}.
\]

For `p in S_N`, put

\[
r_p=2N-p,
\qquad
r_p^\vee=p-1-r_p=2p-2N-1.
\tag{31}
\]

For large `N`, both lie in `[1,p-2]`, and

\[
r_p-r_p^\vee=4N+1-3p\ge\frac{2N}{5}+1,
\]

so they are neither endpoints nor adjacent. Define

\[
Z_p=\{r_p,r_p^\vee\}
\]

for `p in S_N`, and take no designated zeros for the other block primes. Then:

- `Z_p` is exactly reflection invariant;
- `|Z_p|<=2`, much stronger than `O(p^{2/3})`;
- there are no consecutive designated zeros;
- every same-prime fixed-gap multiplicity is at most one;
- `m_0=p+r_p`, so every `p in S_N` hits the same q=1 outer row.

By the prime number theorem in the fixed interval `(N,6N/5]`,

\[
|\mathcal S_N|\asymp\frac N{\log N}.
\]

Hence the single row `m_0` has

\[
\lambda(m_0)(\lambda(m_0)-1)
\asymp\frac{N^2}{\log^2N},
\]

with no vanishing factor.

## Value-level q=1 Lucas and exponential height can also be imposed

The zero-set model can be strengthened. For every block prime `p`, choose a reflection-symmetric residue row

\[
c_{p,j}=c_{p,p-1-j}\in\mathbf F_p,
\qquad0\le j<p,
\]

with

\[
c_{p,0}=1,
\qquad c_{p,1}=5,
\]

and with zeros exactly at `(r_p,r_p^vee)` for `p in S_N` and no zeros otherwise.

Now construct integers `B_0,...,B_{2N}` recursively by CRT. For each block prime `p`, prescribe

\[
B_n\equiv
\begin{cases}
c_{p,n},&n<p,\\
5B_{n-p},&p\le n<2p.
\end{cases}
\pmod p.
\tag{32}
\]

Since every `p>N` and `n<=2N`, these are the only two cases. The moduli are distinct primes, so CRT gives a simultaneous integer `B_n`; choose the least nonnegative representative modulo

\[
M_N=\prod_{N<p<2N}p.
\]

Then

\[
\log M_N=O(N),
\]

so every `B_n` has exponential height `exp(O(N))`. The construction satisfies, for every block prime,

\[
B_{p+r}\equiv5B_r\pmod p,
\qquad
B_{p-1-r}\equiv B_r\pmod p,
\tag{33}
\]

with `B_0=1,B_1=5`. At `m_0=2N`, every `p in S_N` divides `B_{m_0}` because `B_{r_p}=0 mod p`.

Thus even **value-level q=1 Lucas + reflection + exponential height** permit a rainbow star at one outer row. What this CRT model does not satisfy is the Apéry three-term recurrence with its distinguished initial vector. That is exactly where a successful proof must extract new cross-prime arithmetic.

# 10. Smallest additional Apéry theorem

After (25), no theorem about isolated primes, fixed-r zeros, or the full fourth factorial moment is needed. The exact residual theorem is (HL): actual Apéry top factors must be anti-aligned on very-heavy rows at long prime gaps.

A useful structural name is:

**Heavy-long fixed-q anti-alignment (HLFQ).** With

\[
L_N=N^{1/3}/\log^2N,
\qquad
H_N=N^{1/3}/\log\log N,
\]

the actual Apéry sequence satisfies

\[
\sum_{\substack{N<m\le2N\\
\omega_{(N,m]}(b_m)>L_N}}
\#\{(p,q):
N<p,q\le m,\ p\ne q,\ pq\mid b_m,\ |p-q|>H_N\}
=o\!\left(\frac{N^2}{\log^2N}\right).
\tag{HLFQ}
\]

By (25), HLFQ is sufficient and, modulo an already-proved little-oh error, equivalent to the requested `F_top` node. It is a genuinely narrower target: it ignores all moderate rows and every prime pair up to an almost-`N^{1/3}` gap.

The canonical completion in (26) gives an equivalent four-prime form without strengthening the moment order. A proof should therefore target the distinguished recurrence/initial vector on these canonical heavy-long four-prime records. A recurrence-specific characteristic-zero relation shared across two distinct top prime factors of the same `b_m`, or a proof that such canonical records have an additional large-prime divisor/content cost, would close the node. No such theorem is currently visible in the repository state I could audit.

# 11. Standalone checker

The script below uses only Python's standard library. It checks:

1. the exact q=1 equality between the original `p|b_(m-p)` definition and the common-row divisor definition `p|b_m`;
2. the exact first-moment prefix-zero identity (10);
3. the disjoint low/high-short/heavy-long decomposition;
4. the elementary inequalities `F_low <= L*T` and `F_short <= 2H*T`;
5. the top-radical inequalities (15);
6. the canonical four-prime marking when the chosen threshold is at least `3`;
7. reflection for the actual finite Apéry rows used in the regression;
8. the scoped CRT star model, including value-level q=1 Lucas, reflection, endpoint/no-adjacent zero checks, and exponential-height modulus.

The finite runs are regression checks only; the asymptotic estimates above are proved separately.

```python
#!/usr/bin/env python3
from __future__ import annotations

from math import isqrt, log, prod


def P(j: int) -> int:
    return 34*j**3 + 51*j**2 + 27*j + 5


def apery_b(limit: int) -> list[int]:
    assert limit >= 1
    b = [0] * (limit + 1)
    b[0], b[1] = 1, 5
    for j in range(1, limit):
        num = P(j) * b[j] - j**3 * b[j-1]
        den = (j+1)**3
        assert num % den == 0
        b[j+1] = num // den
    return b


def primes_upto(n: int) -> list[int]:
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[:2] = b"\x00\x00"
    for p in range(2, isqrt(n) + 1):
        if sieve[p]:
            sieve[p*p:n+1:p] = b"\x00" * (((n - p*p)//p) + 1)
    return [p for p in range(2, n + 1) if sieve[p]]


def selected_original(N: int, m: int, b: list[int], primes: list[int]) -> list[int]:
    return [
        p for p in primes
        if N < p <= m and b[m-p] % p == 0
    ]


def selected_common_row(N: int, m: int, b: list[int], primes: list[int]) -> list[int]:
    return [
        p for p in primes
        if N < p <= m and b[m] % p == 0
    ]


def actual_regression(N: int = 120, L: int = 3, H: int = 10) -> None:
    assert N >= 7
    b = apery_b(2*N)
    primes = primes_upto(2*N)

    rows: dict[int, list[int]] = {}
    for m in range(N+1, 2*N+1):
        a = selected_original(N, m, b, primes)
        c = selected_common_row(N, m, b, primes)
        # Exact q=1 Lucas collapse.
        assert a == c, (N, m, a, c)
        rows[m] = a

    T = sum(len(S) for S in rows.values())
    F = sum(len(S) * (len(S)-1) for S in rows.values())

    # Exact prefix-zero first moment.
    T2 = 0
    for p in primes:
        if not (N < p <= 2*N):
            continue
        T2 += sum(1 for r in range(0, 2*N-p+1) if b[r] % p == 0)
    assert T == T2

    # Reflection on every base row in the finite regression.
    for p in primes:
        if p < 7:
            continue
        for r in range(p):
            assert (b[p-1-r] - b[r]) % p == 0, (p, r)

    low = 0
    high_short = 0
    hard = 0
    all_short = 0
    canonical = []

    for m, S in rows.items():
        k = len(S)
        for p in S:
            for q in S:
                if p == q:
                    continue
                if abs(p-q) <= H:
                    all_short += 1

        if k <= L:
            low += k * (k-1)
            continue

        for p in S:
            for q in S:
                if p == q:
                    continue
                if abs(p-q) <= H:
                    high_short += 1
                else:
                    hard += 1
                    if k >= 4:
                        others = sorted(x for x in S if x not in (p, q))
                        assert len(others) >= 2
                        u, v = others[:2]
                        canonical.append((m, p, q, u, v))

    assert F == low + high_short + hard
    assert low <= L * T
    assert all_short <= 2 * H * T
    assert high_short <= all_short

    if all(len(S) <= L or len(S) >= 4 for S in rows.values()):
        assert len(canonical) == hard
        assert len(set(canonical)) == hard

    # Top-radical weighted inequalities.
    W = 0.0
    for S in rows.values():
        k = len(S)
        if k <= 1:
            continue
        logR = sum(log(p) for p in S)
        W += (k-1) * logR
    if F:
        assert F * log(N) <= W + 1e-9
        assert W <= F * log(2*N) + 1e-9

    print("actual regression")
    print("N=", N, "T=", T, "F=", F)
    print("low/high_short/hard=", low, high_short, hard)


# ---------- scoped CRT star countermodel ----------

def crt(pairs: list[tuple[int, int]]) -> tuple[int, int]:
    """Return least x>=0 and M with x=a mod p for pairwise-coprime p."""
    x, M = 0, 1
    for a, p in pairs:
        a %= p
        t = ((a - x) % p) * pow(M, -1, p) % p
        x += M * t
        M *= p
        x %= M
    return x, M


def crt_star_model(N: int = 100) -> None:
    assert N >= 20
    block = [p for p in primes_upto(2*N) if N < p < 2*N]
    star = [p for p in block if p > N + 3 and 5*p <= 6*N]
    star_set = set(star)
    assert star

    # Reflection-symmetric residue rows c_{p,j} for j<p.
    c: dict[int, list[int]] = {}
    for p in block:
        row = [1] * p
        row[0] = row[p-1] = 1
        row[1] = row[p-2] = 5 % p
        if p in star_set:
            r = 2*N - p
            rv = p - 1 - r
            assert 1 < r < p-2
            assert 1 < rv < p-2
            assert abs(r-rv) > 1
            row[r] = 0
            row[rv] = 0
        for j in range(p):
            assert row[p-1-j] == row[j]
        c[p] = row

    # Recursive finite sequence satisfying value-level q=1 Lucas for every
    # block prime and reflection on every base row j<p.
    B = [0] * (2*N + 1)
    common_modulus = prod(block)
    for n in range(0, 2*N + 1):
        residues = []
        for p in block:
            if n < p:
                a = c[p][n]
            else:
                assert n < 2*p
                a = 5 * B[n-p]
            residues.append((a, p))
        B[n], M = crt(residues)
        assert M == common_modulus
        assert 0 <= B[n] < common_modulus

    assert B[0] == 1
    assert B[1] == 5

    for p in block:
        # Reflection values on 0,...,p-1.
        for r in range(p):
            assert (B[p-1-r] - B[r]) % p == 0
        # Exact q=1 value congruence in the whole finite block.
        for r in range(0, min(p, 2*N-p+1)):
            assert (B[p+r] - 5*B[r]) % p == 0

        zeros = [r for r in range(p) if B[r] % p == 0]
        if p in star_set:
            r = 2*N-p
            rv = p-1-r
            assert zeros == sorted([r, rv])
            assert abs(r-rv) > 1
        else:
            assert zeros == []

    selected = [p for p in block if B[2*N] % p == 0]
    assert selected == star
    K = len(selected)
    F0 = K * (K-1)

    # Exponential height: all B_n are below product of block primes.
    assert all(0 <= x < common_modulus for x in B)

    print("CRT star model")
    print("N=", N, "star primes=", K, "single-row ordered energy=", F0)
    print("log common modulus / N=", log(common_modulus) / N)
    if K >= 2:
        print("F0 * log(N)^2 / N^2=", F0 * log(N)**2 / N**2)


if __name__ == "__main__":
    actual_regression()
    crt_star_model()
    print("all exact decomposition/model checks passed")
```

# 12. Bottom line

The q=1 node is now localized much more sharply than `F_top=O(T_top)`:

\[
\boxed{
\text{all moderate rows} + \text{all short prime gaps}
= o(N^2/\log^2N).
}
\]

Only very-heavy rows with a long marked pair remain. The unweighted primitive top-radical height is already `O(N^{5/3})`; the sole missing issue is multiplicity reuse on one distinguished Apéry row. Lucas, reflection, endpoint exclusion, no-adjacent zeros, strong single-prime zero bounds, and exponential height permit a scoped rainbow-star model at the critical scale. Therefore the next theorem must be an Apéry-recurrence/initial-vector **cross-prime anti-alignment theorem**, such as HLFQ, not another single-prime zero estimate and not the stronger diagonal-AMTD moment comparison.
