# Q923: corrected Lucas-propagation geometry audit

## Verdict

The high-digit propagation route does **not** close the Ramanujan Challenge 3.2 gap.  The repaired range restriction is essential and removes the invalid \(p\gg n\) configurations, but the remaining deterministic incidence estimate is not strong enough to imply either

\[
\sup_{n<m<n^2}H(m)=o(m)
\]

or the stronger polylogarithmic exceptional-value statement.

No admissible counterconfiguration with primes outside the allowed range exists; the obstruction is a genuine lack of a uniform incidence theorem for the allowed high-digit intervals.

## 1. Correct geometric setup

For

\[
\sqrt n<p\le n,
\qquad n=q_pp+r_p,
\]

with \(0\le r_p<p\), the high digit condition is

\[
\lfloor m/p\rfloor=r_p.
\]

Hence

\[
m\in I_{p,q_p}=[np-q_pp^2,\;np-q_pp^2+p).
\]

For fixed quotient \(q\), define

\[
f_q(x)=nx-qx^2.
\]

The intervals are unit-length perturbations of \(f_q(p)\), with

\[
f'_q(x)=n-2qx,
\qquad
f''_q(x)=-2q<0.
\]

The relevant quotient cells satisfy

\[
q=\lfloor n/p\rfloor,
\]
so \(p\) lies in

\[
\frac n{q+1}<p\le \frac nq.
\]

The number of possible q-values is only \(O(\sqrt n)\), because \(p>\sqrt n\).

## 2. Spacing away from the stationary point

For two primes \(p_1<p_2\) in the same q-cell,

\[
f_q(p_2)-f_q(p_1)
=(p_2-p_1)(n-q(p_1+p_2)).
\]

Therefore, away from the stationary point

\[
p_0=n/(2q),
\]

we have

\[
|f'_q(p)|\gg \Delta_q,
\]

and a unit interval can contain only

\[
O(1+1/\Delta_q)
\]

candidate primes from that cell.

This gives a useful bound on nonstationary cells, but it is not uniform in q because the derivative degenerates near \(p_0\).

## 3. Stationary-point obstruction

At the stationary point,

\[
f_q(p_0)=\frac{n^2}{4q}.
\]

The first derivative vanishes, so the relevant spacing is quadratic:

\[
f_q(p)-f_q(p_0)=-q(p-p_0)^2.
\]

Consequently an interval of length one may contain

\[
O(1+q^{-1/2})
\]

integer p-values near the vertex.  This is harmless for a fixed q, but summing uniformly over all quotient cells requires controlling how many q have their stationary point aligned with the same integer m.

The present argument supplies no such bound.

## 4. Boundary quotient cells

Near the endpoints

\[
p=\frac n{q+1},\quad p=\frac nq,
\]

one-sided derivative estimates replace the stationary analysis.  These cells do not create the missing estimate: the total contribution is bounded by the number of admissible p in boundary cells, but this remains too large for a linear-weight exclusion.

## 5. What the deterministic bound actually gives

The safe conclusion is only

\[
H(m)\le \sum_{p\in S}\log p=O(n),
\]

because the target set itself has total logarithmic mass \(O(n)\).

The previous least-digit argument is stronger: for \(m\ne n\), inherited primes divide \(m-n\), giving

\[
\sum_{p\mid m-n}\log p\le \log|m-n|.
\]

The high-digit contribution has no analogous divisor bound.  Membership in \(I_{p,q_p}\) is an additive quadratic alignment condition, not divisibility.

## 6. No valid counterconfiguration is needed

A counterexample using \(p>n\) is invalid and is explicitly excluded.  The admissible range

\[
\sqrt n<p\le n
\]

still permits the unresolved quadratic incidence problem.  The failure is not a bad construction but the absence of a theorem.

## 7. Missing input

The exact missing estimate is a uniform quadratic-curve incidence statement of the form

\[
\#\{p\in S:m\in I_{p,q_p}\}
\le o\left(\frac m{\log n}\right)
\]

uniformly for \(n<m<n^2\), or at least

\[
H(m)\ge \eta m
\implies
\#\{m:H(m)\ge\eta m\}=O_\eta((\log n)^C).
\]

Current spacing estimates prove this away from stationary regions but do not control the accumulation of stationary cells across q.
