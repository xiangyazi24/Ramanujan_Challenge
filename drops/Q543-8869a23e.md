# Q543 — Transfer-matrix test for pairs of Apéry zeros

## Bottom line

Write

\[
v_n=\binom{b_n}{b_{n-1}},\qquad v_s=T_{r\to s}v_r,
\qquad
T_{r\to s}=M(s-1)\cdots M(r)
 =\begin{pmatrix}t_{11}&t_{12}\\ t_{21}&t_{22}\end{pmatrix}.
\]

Then the relevant coefficient is the **top-right entry**

\[
\boxed{\beta_{r,s}:=(T_{r\to s})_{12}=t_{12}}.
\]

Indeed,

\[
b_s=t_{11}b_r+t_{12}b_{r-1}.
\]

For every odd prime \(p\), and every \(1\le r<s\le p-1\), the Apéry sequence has no two consecutive zeros modulo \(p\). Hence, conditional on \(b_r=0\), one has \(b_{r-1}\ne0\), and therefore

\[
\boxed{b_r\equiv0\pmod p\quad\Longrightarrow\quad
       \bigl(b_s\equiv0\pmod p\iff (T_{r\to s})_{12}\equiv0\pmod p\bigr).}
\]

The exact scan for every odd prime \(3\le p\le997\) gives:

- all \(6{,}168{,}151\) forward half-range matrices were computed;
- after removing the singular \(r=0\) family and the deterministically nonzero adjacent pairs, there are \(6{,}092{,}360\) clean forward pairs, of which exactly \(9{,}400\) have \((T_{r\to s})_{12}=0\);
- the \(1/p\) heuristic predicts \(9{,}351.808900\), while the exact uniform-fixed-determinant matrix heuristic \(1/(p+1)\) predicts \(9{,}332.353931\);
- all \(142\) actual full-range zero pairs satisfy \((T_{r\to s})_{12}=0\), with **zero failures**;
- more strongly, the script made \(38{,}363\) checks of the full equivalence above, over every later \(s\) for every actual zero start \(r\), again with **zero failures**.

So the answer to part (2) is unambiguously **yes**.

## 1. Why the top-right entry is the correct one

The recurrence is

\[
(n+1)^3b_{n+1}=P(n)b_n-n^3b_{n-1},
\qquad
P(n)=(2n+1)(17n^2+17n+5),
\]

so, as long as \(n+1\not\equiv0\pmod p\),

\[
\binom{b_{n+1}}{b_n}
=
\begin{pmatrix}
A(n)&-B(n)\\
1&0
\end{pmatrix}
\binom{b_n}{b_{n-1}},
\]

where

\[
A(n)=\frac{P(n)}{(n+1)^3},\qquad
B(n)=\frac{n^3}{(n+1)^3}.
\]

Thus the convention in the question maps \((b_r,b_{r-1})^T\) to \((b_s,b_{s-1})^T\). If

\[
T_{r\to s}=\begin{pmatrix}\alpha&\beta\\ \gamma&\delta\end{pmatrix},
\]

then

\[
b_s=\alpha b_r+\beta b_{r-1}.
\]

Suppose \(b_r=0\) with \(r\ge1\). If also \(b_{r-1}=0\), backward use of the recurrence would force all earlier values to vanish, contradicting \(b_0=1\). Equivalently, every \(M(n)\) with \(1\le n\le p-2\) is invertible because

\[
\det M(n)=B(n)=\frac{n^3}{(n+1)^3}\ne0.
\]

Therefore \(b_{r-1}\ne0\), and

\[
b_s=0\iff \beta=0.
\]

This also explains why the condition is symmetric under reversing the two endpoints. For \(r\ge1\),

\[
\det T_{r\to s}
 =\prod_{n=r}^{s-1}\frac{n^3}{(n+1)^3}
 =\left(\frac r s\right)^3\ne0,
\]

and the top-right entry of \(T_{r\to s}^{-1}\) is \(-\beta/\det T_{r\to s}\). Thus it vanishes exactly when \(\beta\) vanishes.

## 2. Two necessary corrections to the naive \(p/4\) comparison

Let

\[
h=\frac{p-1}{2}.
\]

For odd \(p\), the condition \(0\le r<s<p/2\) means precisely

\[
0\le r<s\le h.
\]

There are \(h+1=(p+1)/2\) positions, so the number of **forward** pairs is

\[
N_{\rm all}(p)=\binom{h+1}{2}=\frac{p^2-1}{8},
\]

not approximately \(p^2/4\). Consequently a \(1/p\) entry-zero heuristic predicts approximately \(p/8\) forward pairs. The scale \(p/4\) is obtained only after counting both orientations \((r,s)\) and \((s,r)\).

There are also two deterministic boundary effects.

### The entire \(r=0\) family is singular

Since \(B(0)=0\),

\[
M(0)=\begin{pmatrix}5&0\\1&0\end{pmatrix}.
\]

Its second column is zero, so

\[
(T_{0\to s})_{12}=0
\]

for every \(1\le s\le h\). These \(h\) zeros are automatic and must not be compared with a random \(1/p\) model. They have no bearing on actual pairs of Apéry zeros because \(b_0=1\).

After removing \(r=0\), the forward candidate count is

\[
N_{\rm nd}(p)=\binom h2=\frac{(p-1)(p-3)}8.
\]

### Adjacent pairs can never contribute

For \(r\ge1\),

\[
T_{r\to r+1}=M(r),\qquad
(T_{r\to r+1})_{12}=-B(r)\ne0.
\]

Removing these \(h-1\) adjacent pairs leaves the clean range

\[
N_{\rm clean}(p)
 =\binom{h-1}{2}
 =\frac{(p-3)(p-5)}8.
\]

The corresponding two-orientation count is \(2N_{\rm clean}(p)\), whose \(1/p\) expectation is asymptotic to \(p/4\). This is the precise version of the comparison proposed in the question.

### A finite-field correction: \(1/(p+1)\), not exactly \(1/p\)

For each nondegenerate pair, \(T_{r\to s}\) has prescribed nonzero determinant \((r/s)^3\). If a matrix were uniform among all \(2\times2\) matrices with a fixed nonzero determinant \(D\), then

\[
\Pr(T_{12}=0)=\frac1{p+1}.
\]

Indeed, the determinant fiber has \(p(p^2-1)\) elements. With top-right entry zero, one may choose the top-left entry in \(p-1\) ways and the bottom-left entry in \(p\) ways, after which the bottom-right entry is forced; hence there are \(p(p-1)\) such matrices. Their ratio is \(1/(p+1)\). This differs from \(1/p\) only at lower order, so the script reports both baselines.

## 4. Check on actual Apéry zero pairs

The computation verified all of the following for every odd prime \(p\le1000\):

1. palindromy \(b_{p-1-r}=b_r\pmod p\);

```python
#!/usr/bin/env python3
"""Q543: transfer matrices and pairs of Apéry zeros modulo primes.

For each odd prime p <= --limit, compute

    T_{r->s} = M(s-1) ... M(r),    0 <= r < s < p/2,

where M(n) is the 2x2 companion matrix for the Apéry recurrence.  Count
zeros of beta_{r,s} = (T_{r->s})[0][1], verify the palindromic reduction,
and verify

    b_r = 0  ==>  (b_s = 0 iff beta_{r,s} = 0).

Pure Python 3; no Sage or third-party package is required.
"""

from __future__ import annotations

import argparse
import csv
from contextlib import ExitStack
from dataclasses import dataclass
from math import isqrt, sqrt
from pathlib import Path
from typing import TextIO

Mat = tuple[tuple[int, int], tuple[int, int]]
I2: Mat = ((1, 0), (0, 1))


def choose2(n: int) -> int:
    return n * (n - 1) // 2 if n >= 2 else 0


def primes_upto(limit: int) -> list[int]:
    if limit < 2:
        return []
    sieve = bytearray(b"\x01") * (limit + 1)
    sieve[0] = 0
    sieve[1] = 0
    for q in range(2, isqrt(limit) + 1):
        if sieve[q]:
            start = q * q
            count = (limit - start) // q + 1
            sieve[start : limit + 1 : q] = b"\x00" * count
    return [p for p in range(2, limit + 1) if sieve[p]]


def matmul(x: Mat, y: Mat, p: int) -> Mat:
    (a, b), (c, d) = x
    (e, f), (g, h) = y
    return (
        ((a * e + b * g) % p, (a * f + b * h) % p),
        ((c * e + d * g) % p, (c * f + d * h) % p),
    )


def step_matrix(n: int, p: int) -> Mat:
    """Return M(n) modulo p; this is called only for 0 <= n <= p-2."""
    denominator = pow(n + 1, 3, p)
    inv_denominator = pow(denominator, -1, p)
    a = (
        (2 * n + 1)
        * (17 * n * n + 17 * n + 5)
        * inv_denominator
    ) % p
    b = (pow(n, 3, p) * inv_denominator) % p
    return ((a, (-b) % p), (1, 0))


def apery_mod_p(p: int) -> list[int]:
    """Return b_0,...,b_{p-1} modulo p from the Apéry recurrence."""
    values = [0] * p
    values[0] = 1
    for n in range(p - 1):
        previous = values[n - 1] if n else 0
        coefficient = (2 * n + 1) * (17 * n * n + 17 * n + 5)
        numerator = (
            coefficient * values[n] - pow(n, 3, p) * previous
        ) % p
        denominator = pow(n + 1, 3, p)
        values[n + 1] = numerator * pow(denominator, -1, p) % p
    return values


@dataclass
class PrimeResult:
    p: int
    h: int
    all_candidates: int
    raw_beta0: int
    nondeg_candidates: int
    nondeg_beta0: int
    clean_candidates: int
    clean_beta0: int
    zeros_half: list[int]
    zeros_full: list[int]
    half_actual_pairs: int
    full_actual_pairs: int
    mirror_pairs: int
    independent_pairs: int
    half_iff_checks: int
    full_iff_checks: int


def analyze_prime(
    p: int,
    matrix_writer: csv.writer | None,
) -> PrimeResult:
    if p == 2:
        raise ValueError("p=2 is the trivial exceptional prime")

    h = (p - 1) // 2
    values = apery_mod_p(p)
    matrices = [step_matrix(n, p) for n in range(p - 1)]

    if any(values[p - 1 - r] != values[r] for r in range(p)):
        raise AssertionError(f"palindromy failed for p={p}")
    if any(values[r - 1] == values[r] == 0 for r in range(1, p)):
        raise AssertionError(f"consecutive zeros found for p={p}")

    raw_beta0 = 0
    nondeg_beta0 = 0
    clean_beta0 = 0
    half_actual_pairs = 0
    half_iff_checks = 0

    # For fixed r, update T incrementally as s increases:
    # T_{r->s+1} = M(s) T_{r->s}.
    for r in range(h):
        transfer = I2
        for s in range(r + 1, h + 1):
            transfer = matmul(matrices[s - 1], transfer, p)
            beta_zero = transfer[0][1] == 0

            raw_beta0 += int(beta_zero)
            if r >= 1:
                nondeg_beta0 += int(beta_zero)
            if r >= 1 and s >= r + 2:
                clean_beta0 += int(beta_zero)

            if values[r] == 0 and values[s] == 0:
                half_actual_pairs += 1
                if not beta_zero:
                    raise AssertionError(
                        f"actual half zero pair failed: p={p}, r={r}, s={s}"
                    )

            # This is stronger than checking only actual pairs.
            if r >= 1 and values[r] == 0:
                half_iff_checks += 1
                if (values[s] == 0) != beta_zero:
                    raise AssertionError(
                        f"half iff failed: p={p}, r={r}, s={s}"
                    )

            if matrix_writer is not None:
                matrix_writer.writerow(
                    (
                        p,
                        r,
                        s,
                        transfer[0][0],
                        transfer[0][1],
                        transfer[1][0],
                        transfer[1][1],
                        int(beta_zero),
                        int(values[r] == 0),
                        int(values[s] == 0),
                    )
                )

    zeros_half = [r for r in range(1, h + 1) if values[r] == 0]
    zeros_full = [r for r in range(1, p) if values[r] == 0]

    if half_actual_pairs != choose2(len(zeros_half)):
        raise AssertionError(f"half-pair count mismatch for p={p}")

    # Verify the iff for every later s after every actual full-range zero r.
    full_actual_pairs = 0
    mirror_pairs = 0
    independent_pairs = 0
    full_iff_checks = 0

    for r in zeros_full:
        transfer = I2
        for s in range(r + 1, p):
            transfer = matmul(matrices[s - 1], transfer, p)
            beta_zero = transfer[0][1] == 0
            full_iff_checks += 1

            if (values[s] == 0) != beta_zero:
                raise AssertionError(
                    f"full iff failed: p={p}, r={r}, s={s}"
                )

            if values[s] == 0:
                full_actual_pairs += 1
                if r + s == p - 1:
                    mirror_pairs += 1
                else:
                    independent_pairs += 1

    if full_actual_pairs != choose2(len(zeros_full)):
        raise AssertionError(f"full-pair count mismatch for p={p}")

    all_candidates = choose2(h + 1)
    nondeg_candidates = choose2(h)
    clean_candidates = choose2(h - 1)

    # Exactly h top-right zeros come from the singular r=0 family.
    if raw_beta0 - nondeg_beta0 != h:
        raise AssertionError(f"r=0 baseline mismatch for p={p}")

    # Every adjacent top-right entry is -B(r) != 0.
    if nondeg_beta0 != clean_beta0:
        raise AssertionError(f"adjacent-pair mismatch for p={p}")

    return PrimeResult(
        p=p,
        h=h,
        all_candidates=all_candidates,
        raw_beta0=raw_beta0,
        nondeg_candidates=nondeg_candidates,
        nondeg_beta0=nondeg_beta0,
        clean_candidates=clean_candidates,
        clean_beta0=clean_beta0,
        zeros_half=zeros_half,
        zeros_full=zeros_full,
        half_actual_pairs=half_actual_pairs,
        full_actual_pairs=full_actual_pairs,
        mirror_pairs=mirror_pairs,
        independent_pairs=independent_pairs,
        half_iff_checks=half_iff_checks,
        full_iff_checks=full_iff_checks,
    )


def expected_and_variance(
    rows: list[PrimeResult],
    candidate_field: str,
    probability,
) -> tuple[float, float]:
    expected = 0.0
    variance = 0.0
    for row in rows:
        n = getattr(row, candidate_field)
        q = probability(row.p)
        expected += n * q
        variance += n * q * (1.0 - q)
    return expected, variance

    with path.open("w", newline="", encoding="utf-8") as handle:

                "full_actual_pairs",
                "mirror_pairs",
                "independent_pairs",
                "half_iff_checks",
                "full_iff_checks",
            )
        )
        for row in rows:
            out.writerow(

                    row.p,

                    row.half_iff_checks,
                    row.full_iff_checks,
                )
            )


def sum_field(rows: list[PrimeResult], field: str) -> int:
    return sum(getattr(row, field) for row in rows)

def print_report(rows: list[PrimeResult], print_all: bool) -> None:
    print(f"odd primes scanned: {len(rows)} ({rows[0].p} through {rows[-1].p})")
    print(f"all forward matrices: {sum_field(rows, 'all_candidates'):,}")
    print(f"raw top-right zeros: {sum_field(rows, 'raw_beta0'):,}")
    print(f"nondegenerate top-right zeros: {sum_field(rows, 'nondeg_beta0'):,}")
    print(f"clean top-right zeros: {sum_field(rows, 'clean_beta0'):,}")

    for label, candidate_field, observed_field in (
        ("nondegenerate", "nondeg_candidates", "nondeg_beta0"),
        ("clean nonadjacent", "clean_candidates", "clean_beta0"),
    ):
        observed = sum_field(rows, observed_field)
        expected_p, variance_p = expected_and_variance(
            rows, candidate_field, lambda p: 1.0 / p
        )
        expected_p1, variance_p1 = expected_and_variance(
            rows, candidate_field, lambda p: 1.0 / (p + 1)
        )
        print(f"\n{label}:")
        print(f"  candidates = {sum_field(rows, candidate_field):,}")
        print(f"  observed = {observed:,}")
        print(f"  expected under 1/p = {expected_p:.12f}")
        print(f"  expected under 1/(p+1) = {expected_p1:.12f}")
        print(f"  descriptive z under 1/p = {(observed - expected_p) / sqrt(variance_p):.12f}")
        print(
            "  descriptive z under 1/(p+1) = "
            f"{(observed - expected_p1) / sqrt(variance_p1):.12f}"

    print("\nactual-zero verification:")
    print(f"  half actual pairs = {sum_field(rows, 'half_actual_pairs')}")
    print(f"  full actual pairs = {sum_field(rows, 'full_actual_pairs')}")

    print(f"  independent nonmirror pairs = {sum_field(rows, 'independent_pairs')}")

    print(f"  full iff checks = {sum_field(rows, 'full_iff_checks')}")

        help="print every per-prime row rather than a representative subset",
    )
    return parser.parse_args()


def main() -> None:
    args = parse_args()
    if args.limit < 3:
        raise SystemExit("--limit must be at least 3")

    odd_primes = [p for p in primes_upto(args.limit) if p != 2]

    with ExitStack() as stack:
        matrix_writer = None
        if args.matrices_csv is not None:
            args.matrices_csv.parent.mkdir(parents=True, exist_ok=True)
            matrix_handle: TextIO = stack.enter_context(
                args.matrices_csv.open("w", newline="", encoding="utf-8")
            )
            matrix_writer = csv.writer(matrix_handle)
            matrix_writer.writerow(
                (
                    "p",
                    "r",
                    "s",
                    "t11",
                    "t12",
                    "t21",
                    "t22",
                    "t12_is_zero",
                    "b_r_is_zero",
                    "b_s_is_zero",
                )
            )

        rows = [analyze_prime(p, matrix_writer) for p in odd_primes]

    if args.limit == 1000:
        verify_known_limit_1000(rows)
    if args.summary_csv is not None:
        write_summary(args.summary_csv, rows)
    print_report(rows, args.print_all_primes)


if __name__ == "__main__":
    main()
```

## 6. Interpretation for P3.2

This experiment supports a precise limited statement: after removing the singular start and one-step deterministic obstruction, the first moment of the transfer-entry zero count is extremely close to the random-matrix prediction.

It does **not** by itself prove independence across \((r,s)\), nor does it turn the \(9{,}400\) transfer degeneracies into \(9{,}400\) Apéry zero pairs. The transfer criterion is conditional: a vanishing \(T_{12}\) produces a later zero only when the initial state lies on the line \(b_r=0\). Actual zero starts are much rarer. What the computation establishes exactly is that the proposed transfer-matrix detector is correctly indexed, that it detects every actual pair, and that its aggregate zero frequency is on the expected \(1/p\) scale.
