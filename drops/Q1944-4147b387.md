# Q1944: exact Gosper/Riccati certificate search

## Result

The bounded Gosper/Riccati search does not produce a telescoping certificate of the requested form with numerator and denominator degrees at most 6. The coefficient system after clearing denominators has no solution except the tautological zero representation. Therefore no verified identity of the form

\[
\frac{a_j}{b_j}=G(j+1)-G(j)+R(j)
\]

with a nontrivial endpoint Wronskian remainder was found in the degree-6 ansatz.

This is a finite algebraic certificate about the chosen ansatz space, not a proof that no higher-degree certificate exists.

## Correct recurrence data

The Apéry sequence is defined by

\[
(j+1)^3b_{j+1}-(34j^3+51j^2+27j+5)b_j+j^3b_{j-1}=0,
\]

with

\[
b_0=1,\qquad b_1=5.
\]

The search must use this recurrence for ratios

\[
r_j=\frac{b_{j+1}}{b_j},\qquad s_j=\frac{b_{j-1}}{b_j},
\]

only as rational expressions subject to the recurrence constraint. It must not introduce a recurrence for \(1/b_j\), which is not a valid consequence of the Apéry recurrence.

## Degree-6 ansatz

The searched certificate class was:

\[
G(j)=A(j)\frac{b_{j+1}}{b_j}+B(j)\frac{b_{j-1}}{b_j}+C(j),
\]

where all rational functions have numerator and denominator degree at most 6.

Substituting

\[
G(j+1)-G(j)-\frac{3(4j^2+4j-3)}{b_j}
\]

and clearing the common denominator gives a polynomial identity in \(j\) and the independent recurrence ratios. Equating coefficients gives a linear system over \(\mathbf Q\).

The resulting system has full rank in every nontrivial coefficient sector. The only solutions correspond to the zero numerator identity, hence no telescoper.

## Boundary condition check

The reversed trace situation imposes

\[
b_{m-1}=0,
\]

with

\[
b_0,\ldots,b_{m-2}\neq0.
\]

This condition changes the endpoint evaluation of any hypothetical certificate, but it does not create a missing degree-6 solution. The terminal zero can only be used after a genuine identity has been established.

## Interpretation

The previous unsupported shortcut would be to argue that a vanishing accumulated sum of reversed terms forces both initial Apéry data to vanish. That is invalid: the recurrence is second order, and one scalar endpoint condition does not annihilate the two-dimensional solution space.

The correct conclusion from this search is:

1. No degree <= 6 Gosper/Riccati endpoint certificate exists in the tested rational ansatz.
2. The obstruction is a genuine full-rank coefficient system, not an accidental missing normalization.
3. Any proof of the saturated gcd statement needs a different invariant, such as the division-free transfer argument using the exact reversed variables.

A higher-degree search or a different state augmentation remains possible, but is not covered by this certificate computation.
