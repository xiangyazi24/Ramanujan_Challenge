# Same-height adjacent Padé Wronskians: exact Smith formula, prime-support theorem, and carrier audit

## Verdict

The adjacent Wronskian identity is correct, including its sign and its **single joint primitive normalization**.  It gives an exact formula for the proposed scalar `delta_H`, but the currently proved consequence is a support theorem rather than a polynomial-size theorem.

Write `d=H-a`, so that `d` is the denominator degree.  Let `Delta_(H,d)` be the gcd of the maximal cofactors of the `d x (d+1)` high-Newton matrix, and let `tau_(H,d)` be its one-row bordered solid minor.  With the cofactor orientation fixed below, the denominator-degree-oriented edge is

```text
P^[d](X) Q^[d+1](X) - P^[d+1](X) Q^[d](X)
 = K_(H,d) binom(X,H+1),

K_(H,d)
 = (-1)^(d+1) binom(H+1,d+1)
   tau_(H,d)^2 /
   (Delta_(H,d) Delta_(H,d+1)).
```

The user's numerator-degree convention is

```text
P_a=P^[H-a],
Q_a=Q^[H-a].
```

Therefore

```text
kappa_(H,a) = -K_(H,H-a-1),
```

and, up to the independent signs chosen for the primitive pairs,

```text
|kappa_(H,a)|
 = binom(H+1,a+1)
   |tau_(H,H-a-1)|^2 /
   (Delta_(H,H-a-1) Delta_(H,H-a)).
```

Consequently the exact answer for the common Wronskian content is

```text
delta_H
 = gcd_(0<=d<H)
   [
     binom(H+1,d+1)
     |tau_(H,d)|^2 /
     (Delta_(H,d) Delta_(H,d+1))
   ].
```

Prime by prime,

```text
v_p(delta_H)
 = min_(0<=d<H)
   {
     v_p binom(H+1,d+1)
     + 2 v_p(tau_(H,d))
     - v_p(Delta_(H,d))
     - v_p(Delta_(H,d+1))
   }.
```

This is an exact Smith formula under full joint primitive normalization.  No second division of a numerator content is allowed.

There are two further unconditional results.

1. **Every prime divisor of `delta_H` is at most `H+1`.**  In symbols,

```text
P^+(delta_H) <= H+1.
```

Thus `delta_H` is a unit at every sufficiently large fixed-`q` target prime.  Its apparent smallness cannot compress the large target set, because it is absent from that set.

2. The first two top-degree edges give the sharper radical reduction

```text
rad(delta_H)
 | rad(2 H (H+1) gcd(c_(H-1),c_H)),

c_k = Delta^k b_0.
```

Equivalently, if an odd prime `p` satisfies

```text
p does not divide H(H+1)
and
p divides delta_H,
```

then

```text
p divides c_(H-1)
and
p divides c_H.
```

This identifies a precise remaining arithmetic obstruction: simultaneous prime divisors of two consecutive Apéry Newton coefficients.  The current repository does not contain a theorem giving a sublinear logarithmic bound for that moving gcd, nor a theorem controlling the full exponents in the exact Smith formula.  Hence the numerical pattern

The proposed improved carrier is nevertheless strictly useful in one exact sense.  Put

```text
B_H(X)=P_H(X)
      =sum_(k=0)^H c_k binom(X,k),

C_H^+(n)
 = gcd(B_H(n), delta_H binom(n,H+1)).
```

Then

```text

```

For every direct fixed-`q` candidate prime with

```text

0<=r<=H,
p>H+1,
p^2>n,
```

```text
v_p(C_H^+(n))
 = 1  if p divides b_r,
 = 0  if p does not divide b_r.
```

Thus the large-candidate part of `C_H^+(n)` is **exactly the squarefree target radical**.  This removes every non-target candidate prime from the binomial carrier.  But it is not an independent height estimate:


# 1. Integral Newton multiplication matrix

Let

```text
b_0=1,
b_1=5,

c_k=Delta^k b_0.
```

The Newton expansion is

```text
b_x = sum_(k>=0) c_k binom(x,k)
```

at nonnegative integral `x`.  Multiplication by the Apéry value sequence in the Newton basis is represented by

```text
M_(k,l)
 = binom(k,l) Delta^(k-l)b_l
 = binom(k,l)
   sum_(t=0)^l binom(l,t)c_(k-l+t),

0<=l<=k.
```

Fix `H` and use denominator degree `d`.  Put

```text
a=H-d,

Q^[d](X)=sum_(l=0)^d q_(d,l) binom(X,l),
P^[d](X)=sum_(k=0)^(H-d) p_(d,k) binom(X,k).
```

The high Newton equations are

```text
sum_(l=0)^d M_(k,l) q_(d,l)=0,

H-d+1<=k<=H.
```

Define

```text
R_(H,d)=M[H-d+1,...,H ; 0,...,d].
```

It is a `d x (d+1)` integer matrix.  In the normal case it has rank `d`.  Its signed maximal cofactors are

```text
D_(H,d,l)
 = (-1)^l det(R_(H,d) with column l deleted),

0<=l<=d,
```

and its last determinantal divisor is

```text
Delta_(H,d)
 = gcd_(0<=l<=d) D_(H,d,l) >0.
```

Use

```text
Delta_(H,0)=1.
```

The primitive denominator and reconstructed numerator are

```text
q_(d,l)=D_(H,d,l)/Delta_(H,d),

p_(d,k)=sum_(l=0)^d M_(k,l)q_(d,l).
```

They satisfy

```text
gcd(all p_(d,k), all q_(d,l))=1,

P^[d](s)=b_s Q^[d](s),
0<=s<=H.
```

Define the solid bordered minor

```text
tau_(H,d)
 = det M[H-d,...,H ; 0,...,d],

tau_(H,-1)=1.
```

Laplace expansion along the first row and deletion of the final denominator column give

```text
p_(d,H-d)=tau_(H,d)/Delta_(H,d),

q_(d,d)=(-1)^d tau_(H,d-1)/Delta_(H,d).
```

These are literal integer identities; their divisibilities are exactly the maximal-cofactor divisibilities.

# 2. Exact adjacent Wronskian and sign conversion

For `0<=d<H`, set

```text
W^[d](X)
 = P^[d](X)Q^[d+1](X)
   -P^[d+1](X)Q^[d](X).
```

At each node `s=0,...,H`, both products equal

```text
b_s Q^[d](s)Q^[d+1](s),
```

so `W^[d](s)=0`.  The degree bounds are

```text
deg(P^[d]Q^[d+1]) <= (H-d)+(d+1)=H+1,

deg(P^[d+1]Q^[d]) <= (H-d-1)+d=H-1.
```

Therefore

```text
W^[d](X)=K_(H,d) binom(X,H+1).
```

Only the first product contributes to ordinary degree `H+1`.  Comparing leading coefficients gives

```text
K_(H,d)
 = binom(H+1,d+1)
   p_(d,H-d)q_(d+1,d+1)

 = (-1)^(d+1) binom(H+1,d+1)
   tau_(H,d)^2 /
   (Delta_(H,d)Delta_(H,d+1)).
```

This also proves that the displayed quotient is an integer.

Now return to the user's numerator degree `a`:

```text
(P_a,Q_a)=(P^[H-a],Q^[H-a]).
```

For `0<=a<H`, put `d=H-a-1`.  Then

```text
P_aQ_(a+1)-P_(a+1)Q_a
 = P^[d+1]Q^[d]-P^[d]Q^[d+1]
 = -K_(H,d) binom(X,H+1).
```

Thus, under the displayed cofactor signs,

```text
kappa_(H,a)
 = (-1)^(H-a-1) binom(H+1,a+1)
   tau_(H,H-a-1)^2 /
   (
     Delta_(H,H-a-1)
     Delta_(H,H-a)

```

Changing the sign of one primitive pair changes the signs of its two incident `kappa` values.  Therefore only

```text

and
```

are orientation-independent.

# 4. No prime larger than `H+1` divides `delta_H`

## Theorem 4.1

For every normal height `H>=1`,

```text
p | delta_H  implies  p<=H+1.
```

## Proof

Assume that `p>H+1` and `p|delta_H`.  Since every factorial through `(H+1)!` is a `p`-unit, each binomial-basis polynomial of degree at most `H+1` is an ordinary polynomial over `F_p`, and the Newton representation is faithful.

For every `a`, joint primitivity means that the reduction of `(P_a,Q_a)` is not the zero vector.  The hypothesis `p|kappa_(H,a)` gives

```text
P_aQ_(a+1)-P_(a+1)Q_a=0
```

in `F_p[X]`.  Two nonzero vectors in `F_p[X]^2` with zero determinant are proportional over `F_p(X)`.  By adjacency, all `H+1` pair vectors are on one projective line.

At the top numerator degree,

```text
(P_H,Q_H)=(B_H,1),

B_H(X)=sum_(k=0)^H c_k binom(X,k).
```

At degree zero, `P_0` is a constant.  The reduction of `Q_0` is nonzero: otherwise interpolation at `s=0`, where `b_0=1`, would also make `P_0=0`, contradicting joint primitivity.  Proportionality of the two endpoint pairs therefore gives

```text
B_H(X)Q_0(X)=P_0
```

in the integral domain `F_p[X]`.  Both factors on the left are nonzero, while the right side is constant, so `B_H` is constant.

But the coefficient of `binom(X,1)` in `B_H` is

```text
c_1=b_1-b_0=4.
```

Thus `p|4`, impossible for `p>H+1>=2`.  This contradiction proves the theorem.

## Consequence

```text
delta_H is (H+1)-smooth.
```

This is a genuine restriction, but smoothness alone is not a subexponential size bound: the exponents in an `(H+1)`-smooth integer can still have linear or larger logarithmic size.

## Theorem 5.1

Let `p` be an odd prime satisfying


If `p|delta_H`, then

```text

and
p|c_(H-1).
```

## Proof

Since `delta_H` divides `K_(H,0)`, if `x` were a `p`-unit then `Delta_(H,1)`, which divides `x`, would be a unit and `K_(H,0)` would be a unit.  Hence `p|x`.

Suppose now that `y` is a unit.  Since `p` is a unit on `H`, the quantity

```text

```

is a unit, and therefore `Delta_(H,1)` is a unit.  Modulo `p`,


Thus both `T_H` and its divisor `Delta_(H,2)` are units.  Also

```text
binom(H+1,2)=H(H+1)/2
```

is a unit.  The formula for `K_(H,1)` then makes it a unit, contradicting `p|delta_H`.  Therefore `p|y`.

The Apéry-Lucas law is inherited by the Newton coefficients.  For odd `p`, if

No current checked-in theorem bounds the logarithmic weight of those common primes with the strength needed for `log delta_H=o(H)`, and the valuation formula contains the additional Smith-exponent problem.

# 6. Why primitivity alone cannot imply a small `delta_H`

The observed small values are Apéry-specific.  There is no formal theorem saying that a complete chain of jointly primitive interpolation pairs has small adjacent-Wronskian gcd.

Fix a modulus `M`.  Consider any normal integer interpolation data satisfying

```text
b_s = u mod M
for every 0<=s<=H,
```

where `u` is a unit modulo `M`.  For every primitive pair,

```text
P_a(s)-uQ_a(s)=0 mod M
```

at all `H+1` consecutive nodes.  The Pascal evaluation matrix on these nodes is unimodular over `Z`, so all Newton coefficients of `P_a-uQ_a` are divisible by `M`.  Therefore

```text
P_a=uQ_a mod M
```

coefficientwise.  Every adjacent Wronskian is then zero modulo `M`, and its top Newton coefficient satisfies

```text
M | kappa_(H,a)
```

for every `a`.  Thus

```text
M | delta_H.
```

Normal specializations with arbitrarily large `M` exist because rank failure is the zero set of finitely many nonzero determinant polynomials in the remaining data.  Taking `M` exponentially large gives exponentially large `delta_H` despite joint primitivity.

This does not refute a special theorem for the Apéry data.  It proves that such a theorem must use the Apéry recurrence, Lucas/Dwork arithmetic, or an equivalent special input; it cannot follow from the Wronskian identity and primitive normalization alone.

# 7. The improved carrier and its exact candidate support

Define

```text
G_H(n)=gcd_(0<=a<=H)|P_a(n)|,

delta_H=gcd_(0<=a<H)|kappa_(H,a)|,

B_H(X)=P_H(X).
```

Each adjacent identity gives

```text
G_H(n) | kappa_(H,a) binom(n,H+1).
```

Taking the gcd over all edges gives

```text
G_H(n) | delta_H binom(n,H+1).
```

Since `P_H=B_H` is itself a member of the family,

```text
G_H(n) | B_H(n).
```

Therefore

```text
boxed carrier:

C_H^+(n)
 = gcd(
     B_H(n),
     delta_H binom(n,H+1)
   ),

G_H(n) | C_H^+(n).
```

## Theorem 7.1 — exact direct-candidate valuation

Assume

```text
n=qp+r,
0<=r<=H,
p>H+1,
p^2>n.
```

Then

```text
v_p(C_H^+(n))
 = 1 if p|b_r,
 = 0 otherwise.
```

## Proof

Theorem 4.1 gives

```text
p does not divide delta_H.
```

Since `H<p`, Lucas in the binomial basis gives

```text
B_H(n)
 = sum_(k=0)^H c_k binom(qp+r,k)
 = sum_(k=0)^H c_k binom(r,k)
 = B_H(r)
 = b_r                         (mod p).
```

Legendre's formula, using `r<=H<p`, gives

```text
v_p binom(n,H+1)
 = floor(n/p)
   -floor((H+1)/p)
   -floor((n-H-1)/p)

 = q-0-(q-1)
 =1.
```

Thus the second entry of the gcd has valuation exactly one, while the first is divisible by `p` exactly when `b_r` is.  Taking the minimum proves the theorem.

Consequently, on the direct fixed-`q` candidate set,

```text
(C_H^+(n))_candidate
 = product_{
     p candidate,
     p|b_(n-qp)
   } p.
```

This is an exact squarefree identity, not only radical containment.

## Reflected branch

The parallel reflected carrier is

```text
C_H^-(n)
 = gcd(
     B_H(-n-1),
     delta_H binom(n+H+1,H+1)
   ).
```

For a reflected label

```text
j=p-1-(n-qp),
0<=j<=H,
```

one analogously has

```text
v_p(C_H^-(n))
 =1 iff p|b_j.
```

The direct and reflected carriers cover different portions of the slice; taking their gcd would lose the union.  A support-complete construction uses their product or lcm, with the central prime handled once.

# 8. Is the carrier strictly useful?

There are two answers, depending on the meaning of “useful.”

## 8.1 Yes: exact support purification

The binomial alone contains every active candidate prime, good or bad.  Intersecting it with `B_H(n)` removes every good candidate prime and retains each target to exponent one.  This is a strict arithmetic improvement over

```text
delta_H binom(n,H+1).
```

Moreover, because target primes exceed `H+1`, the factor `delta_H` is irrelevant on the target set.  The candidate-local carrier can be simplified to

```text
gcd(B_H(n),binom(n,H+1))
```

without changing any large candidate valuation.

## 8.2 No: it does not prove the required height estimate

For fixed `q`, candidate primes have logarithm `log H+O_q(1)`.  The exact identity above gives

```text
log (C_H^+(n))_candidate
 = sum_{
     p in (n/(q+1),n/q],
     p|b_n,
     direct branch
   } log p.
```

Therefore

```text
log (C_H^+(n))_candidate=o(H)
```

is equivalent to the corresponding fixed-`q` target-count estimate.  The gcd has not bounded that set; it has represented it exactly.

The small-prime part can still contain primes at most `H+1`, including powers coming from `delta_H` and from `B_H(n)`.  Even a future proof of

```text
delta_H <= H^C
```

would remove only this nuisance.  It would not estimate the displayed target product, because every target prime is a `delta_H`-unit.

Thus the carrier is a clean selector and a valuable exact reduction, but not by itself the missing subexponential certificate.

# 9. Self-contained exact verifier

The following script uses only Python's standard library and exact integer arithmetic.  It verifies:

- the one joint primitive normalization;
- every interpolation identity;
- the `tau/Delta` leading-coefficient identities;
- both signs of the adjacent Wronskian formula;
- the exact `delta_H` sequence stated in the question;
- the finite observation `delta_H | 40(H+1)` for `3<=H<=15`, without promoting it to a theorem;
- the absence of prime factors above `H+1` in the tested range;
- the top-two radical theorem;
- the full-family carrier divisibility;
- the exact exponent-one direct-candidate support.

It does not infer an asymptotic theorem from the finite loop.

```python
#!/usr/bin/env python3
from __future__ import annotations

from functools import reduce
from math import comb, gcd


def gcd_list(values):
    return reduce(gcd, (abs(int(x)) for x in values), 0)


def apery_values(H: int) -> list[int]:
    if H == 0:
        return [1]
    b = [1, 5]
    for n in range(1, H):
        middle = 34*n**3 + 51*n**2 + 27*n + 5
        numerator = middle*b[n] - n**3*b[n-1]
        denominator = (n+1)**3
        assert numerator % denominator == 0
        b.append(numerator // denominator)
    return b[:H+1]


def forward_differences(values: list[int]) -> list[int]:
    row = values[:]
    out = []
    while row:
        out.append(row[0])
        row = [row[i+1]-row[i] for i in range(len(row)-1)]
    return out


def M_entry(k: int, ell: int, c: list[int]) -> int:
    if ell < 0 or ell > k:
        return 0
    return comb(k, ell) * sum(
        comb(ell, t)*c[k-ell+t]
        for t in range(ell+1)
    )


def bareiss_det(A: list[list[int]]) -> int:
    n = len(A)
    if n == 0:
        return 1
    B = [row[:] for row in A]
    sign = 1
    previous = 1
    for k in range(n-1):
        if B[k][k] == 0:
            pivot_row = next(
                (i for i in range(k+1, n) if B[i][k] != 0),
                None,
            )
            if pivot_row is None:
                return 0
            B[k], B[pivot_row] = B[pivot_row], B[k]
            sign = -sign
        pivot = B[k][k]
        for i in range(k+1, n):
            for j in range(k+1, n):
                numerator = B[i][j]*pivot-B[i][k]*B[k][j]
                assert numerator % previous == 0
                B[i][j] = numerator // previous
            B[i][k] = 0
        previous = pivot
    return sign*B[-1][-1]


def zbinom(x: int, k: int) -> int:
    if k < 0:
        return 0
    if x >= 0:
        return comb(x, k) if x >= k else 0
    return (-1)**k * comb(k-x-1, k)


def eval_newton(coefficients: list[int], x: int) -> int:
    return sum(
        coefficient*zbinom(x, k)
        for k, coefficient in enumerate(coefficients)
    )


def tau(H: int, d: int, c: list[int]) -> int:
    if d == -1:
        return 1
    return bareiss_det([
        [M_entry(k, ell, c) for ell in range(d+1)]
        for k in range(H-d, H+1)
    ])


def primitive_pair(H: int, d: int, b: list[int], c: list[int]):
    a = H-d
    if d == 0:
        Delta = 1
        q = [1]
    else:
        R = [
            [M_entry(k, ell, c) for ell in range(d+1)]
            for k in range(a+1, H+1)
        ]
        cofactors = []
        for deleted in range(d+1):
            minor = [
                row[:deleted]+row[deleted+1:]
                for row in R
            ]
            cofactors.append(
                (-1)**deleted * bareiss_det(minor)
            )
        Delta = gcd_list(cofactors)
        assert Delta > 0
        q = [x//Delta for x in cofactors]

    p = [
        sum(
            M_entry(k, ell, c)*q[ell]
            for ell in range(d+1)
        )
        for k in range(a+1)
    ]

    assert gcd_list(p+q) == 1
    for s in range(H+1):
        assert eval_newton(p, s) == b[s]*eval_newton(q, s)

    td = tau(H, d, c)
    tprev = tau(H, d-1, c)
    assert td % Delta == 0
    assert tprev % Delta == 0
    assert p[-1] == td//Delta
    assert q[-1] == (-1)**d * (tprev//Delta)

    return {
        "d": d,
        "a": a,
        "P": p,
        "Q": q,
        "Delta": Delta,
        "tau": td,
    }


def K_edge(H: int, left, right) -> int:
    d = left["d"]
    assert right["d"] == d+1
    numerator = (
        (-1)**(d+1)
        * comb(H+1, d+1)
        * left["tau"]**2
    )
    denominator = left["Delta"]*right["Delta"]
    assert numerator % denominator == 0
    K = numerator//denominator

    # binom(H+1,H+1)=1 fixes the sign directly.
    direct = (
        eval_newton(left["P"], H+1)
        * eval_newton(right["Q"], H+1)
        - eval_newton(right["P"], H+1)
        * eval_newton(left["Q"], H+1)
    )
    assert direct == K

    for x in (H+2, 2*H+3, -H-2):
        cross = (
            eval_newton(left["P"], x)
            * eval_newton(right["Q"], x)
            - eval_newton(right["P"], x)
            * eval_newton(left["Q"], x)
        )
        assert cross == K*zbinom(x, H+1)
    return K


def prime_factors(n: int) -> list[int]:
    n = abs(n)
    out = []
    p = 2
    while p*p <= n:
        if n % p == 0:
            out.append(p)
            while n % p == 0:
                n //= p
        p = 3 if p == 2 else p+2
    if n > 1:
        out.append(n)
    return out


def primes_up_to(N: int) -> list[int]:
    flags = bytearray(b"\x01")*(N+1)
    if N >= 0:
        flags[0] = 0
    if N >= 1:
        flags[1] = 0
    p = 2
    while p*p <= N:
        if flags[p]:
            flags[p*p:N+1:p] = b"\x00"*((N-p*p)//p+1)
        p += 1
    return [p for p in range(2, N+1) if flags[p]]


def vp(n: int, p: int) -> int:
    n = abs(n)
    if n == 0:
        return 10**9
    e = 0
    while n % p == 0:
        n //= p
        e += 1
    return e


EXPECTED = {
    3: 32,
    4: 40,
    5: 8,
    6: 56,
    7: 32,
    8: 24,
    9: 40,
    10: 88,
    11: 8,

def audit(H: int, qfixed: int = 1):
    b = apery_values(H)
    c = forward_differences(b)
    pairs = [
        primitive_pair(H, d, b, c)
        for d in range(H+1)
    ]
    K = [
        K_edge(H, pairs[d], pairs[d+1])
        for d in range(H)
    ]
    delta = gcd_list(K)

    if H in EXPECTED:
        assert delta == EXPECTED[H]
        # Finite observation only, not used as a proof.
        assert (40*(H+1)) % delta == 0

    # Computational check of Theorem 4.1.
    for p in prime_factors(delta):
        assert p <= H+1

    # Computational check of Theorem 5.1.
    if H >= 2:
        for p in prime_factors(delta):
            if p != 2 and H % p and (H+1) % p:
                assert c[H] % p == 0
                assert c[H-1] % p == 0

    # d=0 is the user's a=H interpolation polynomial B_H.
    BH = pairs[0]["P"]
    assert pairs[0]["Q"] == [1]

    n = (2*qfixed+1)*H+qfixed
    values = [eval_newton(pair["P"], n) for pair in pairs]
    Gfull = gcd_list(values)
    binomial = zbinom(n, H+1)
    carrier = gcd(abs(eval_newton(BH, n)), abs(delta*binomial))

    assert Gfull > 0
    assert carrier % Gfull == 0
    assert (delta*binomial) % Gfull == 0

    # Exact direct-candidate support theorem.
    for p in primes_up_to(n):
        if p <= H+1 or n//p != qfixed or p*p <= n:
            continue
        r = n-qfixed*p
        if not (0 <= r <= H):
            continue

        assert delta % p != 0
        assert (eval_newton(BH, n)-b[r]) % p == 0
        assert vp(binomial, p) == 1

        for pair in pairs:
            assert (
                eval_newton(pair["P"], n)
                - b[r]*eval_newton(pair["Q"], n)
            ) % p == 0

        assert (carrier % p == 0) == (b[r] % p == 0)
        if carrier % p == 0:
            assert vp(carrier, p) == 1

    print(
        f"H={H} delta={delta} factors={prime_factors(delta)} "
        f"Gfull={Gfull} carrier={carrier}"
    )


if __name__ == "__main__":
    # H=2 is the exact warning against extrapolating the 40(H+1) pattern:
    # delta_2=384.
    audit(2, qfixed=1)
    for H in range(3, 16):
        audit(H, qfixed=1)
    for H in range(4, 11):
        audit(H, qfixed=2)
```

# 10. Final conclusion

The same-height adjacent Wronskians do provide the cleanest exact upper carrier currently available:

```text
G_H(n)
 | gcd(
     B_H(n),
     delta_H binom(n,H+1)
   ).
```

The common Wronskian scalar has the exact primitive Smith formula

```text
delta_H
 = gcd_d
   binom(H+1,d+1)
   tau_(H,d)^2 /
   (Delta_(H,d)Delta_(H,d+1)).
```

Its prime support is sharply constrained:

```text
P^+(delta_H)<=H+1,

rad(delta_H)
 | rad(2H(H+1)gcd(c_(H-1),c_H)).
```

These are real advances over treating `delta_H` as an unexplained numerical gcd.  They also settle the role of `delta_H` in the fixed-`q` attack: it is a unit at every large target prime, so it cannot be the mechanism that makes the target product small.

The intersection with `B_H(n)` is strictly useful as a **support purifier** and gives target exponent one exactly.  Its candidate logarithmic height, however, is precisely the logarithmic weight of the target primes.  Therefore the proposed carrier does not close P3.2 unless one proves an additional Apéry-specific theorem—either a direct bound on that evaluated gcd or the original fixed-`q` target-count estimate.
