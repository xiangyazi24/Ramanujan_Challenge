# Orthogonal-polynomial separability audit for the Apéry diagonal jet

## Executive verdict

There is a clean answer, but it splits sharply between an **adjacent-resultant theorem that does work** and the desired **pointed ordinary-derivative theorem, which is not supplied by standard orthogonal-polynomial theory**.

1. **Stieltjes–Markov/interlacing does not give the requested mod-​\(p\) separability.**  The polynomial in the question is, on the nose,
   \[
   R_n(\lambda_m)
   ={}_4F_3\!\left(\begin{matrix}-n,n+1,-m,m+1\\1,1,1\end{matrix};1\right),
   \qquad \lambda_m=m(m+1),
   \]
   hence the all-zero **Racah** polynomial and, equivalently, a Wilson polynomial with parameters \((\tfrac12,\tfrac12,\tfrac12,\tfrac12)\).  It is not a finite positive dual-Hahn/Racah system: none of the Racah truncation conditions is present.  Its genuine positive orthogonality is the continuous Wilson measure on \(Y\le-\tfrac14\), whereas \(\lambda_n>0\) is an interpolation/bispectral grid point outside that support.  Real positivity proves simple real zeros before reduction, but positivity disappears over \(\mathbb F_p\).  A nondegenerate Christoffel–Darboux quadratic form can be isotropic over a finite field.

2. **There is an exact Christoffel-number formula, but it is precisely the confluent CD identity already in hand and is circular for this purpose.**  If \(\xi\) is an actual zero of \(R_n\) in characteristic zero and \(\Lambda_{n,\xi}\) is its Gaussian quadrature weight for the normalized Wilson measure, then
   \[
   \Lambda_{n,\xi}
   =\frac{2}{n^3R_n'(\xi)R_{n-1}(\xi)},
   \qquad
   R_n'(\xi)
   =\frac{2}{n^3\Lambda_{n,\xi}R_{n-1}(\xi)}.
   \]
   The factor \(2n+1\) is the reciprocal norm \(h_n^{-1}\), and also the *formal* all-zero Racah lattice weight, but it is not a finite atom at \(\lambda_n\).  If \(R_n(\lambda_n)\equiv0\pmod p\), then the inverse Christoffel number exists exactly when the CD kernel is nonzero—the statement one is trying to prove.

3. **The adjacent resultant has a complete small-prime product, but the full discriminant does not.**  For the monic normalization \(P_n=R_n/\kappa_n\),
   \[
   \operatorname{Res}(P_n,P_{n-1})
   =(-1)^{n(n-1)/2}
     \prod_{j=1}^{n-1}
     \left(\frac{j^6}{4(4j^2-1)}\right)^j.
   \]
   Consequently it is a \(p\)-adic unit for every \(p>2n+1\).  This gives a short conceptual proof that \(R_n\) and \(R_{n-1}\) have no common root modulo such a prime, strengthening the backward-induction argument.

   By contrast, global separability is already false in the exact family.  One has
   \[
   18R_3(Y)=10Y^3+55Y^2+66Y+18,
   \]
   with
   \[
   \operatorname{Disc}(18R_3)
   =584460=2^2\,3^2\,5\,17\,191.
   \]
   The prime \(191>2\cdot3+1\), and modulo \(191\),
   \[
   18R_3(Y)=10(Y-148)^2(Y-176).
   \]
   Thus no Wilson/Racah discriminant theorem can say that all primes causing repeated roots are \(\le2n+1\).  The large cofactors seen computationally are not merely normalization noise.

4. The surviving assertion is genuinely **pointed**:
   \[
   \boxed{
   p>2n+1,\quad p\mid R_n(\lambda_n)
   \quad\Longrightarrow\quad
   p\nmid R_n'(\lambda_n).
   }
   \tag{PS}
   \]
   Equivalently,
   \[
   \operatorname{rad}\gcd(b_n,D_n)
   \mid\prod_{p\le2n+1}p.
   \tag{PJ}
   \]
   I did not find a published Stieltjes, Racah, Wilson, Christoffel, or discriminant theorem implying (PS).  This is a literature/no-go conclusion, not a proof that no such specialized result exists.  As presently formulated, (PS) is an Apéry-specific diagonal-jet theorem.

The best next target is therefore not the full discriminant.  It is a pointed contiguous/Bézout certificate that reduces the harmonic first jet modulo \(b_n\) to a known \(p\)-unit, ideally \(R_{n-1}(\lambda_n)\).

## 1. Exact identification: Racah analytically continued, Wilson genuinely orthogonal

From
\[
\lambda_m-a(a+1)=(m-a)(m+a+1)
\]
we obtain
\[
\prod_{a=0}^{k-1}(\lambda_m-a(a+1))
=(-1)^k(-m)_k(m+1)_k.
\]
Also
\[
\binom nk\binom{n+k}k
=(-1)^k\frac{(-n)_k(n+1)_k}{(k!)^2}.
\]
The two signs cancel, so
\[
R_n(\lambda_m)
=\sum_{k=0}^n
 \frac{(-n)_k(n+1)_k(-m)_k(m+1)_k}{(k!)^4}
={}_4F_3\!\left(\begin{matrix}-n,n+1,-m,m+1\\1,1,1\end{matrix};1\right).
\tag{1.1}
\]
This immediately gives the exact self-duality
\[
R_n(\lambda_m)=R_m(\lambda_n).
\tag{1.2}
\]

In standard Racah notation, (1.1) is
\[
R_n(\lambda(m);\alpha,\beta,\gamma,\delta)
\quad\text{with}\quad
\alpha=\beta=\gamma=\delta=0.
\]
However, finite Racah orthogonality requires one of
\[
\alpha+1=-N,
\qquad
\beta+\delta+1=-N,
\qquad
\gamma+1=-N.
\tag{1.3}
\]
Here all three left sides equal \(1\).  Thus there is no finite truncation parameter \(N\).  Calling (1.1) “dual Hahn on the quadratic grid” is useful descriptively, but the exact named family is Racah/Wilson, and it is **not** a finite dual-Hahn measure on \(\{\lambda_0,\ldots,\lambda_N\}\).

The genuine orthogonal realization is Wilson.  With the standard Wilson normalization,
\[
\boxed{
R_n(Y)=\frac{1}{(n!)^3}
W_n\!\left(-Y-\frac14;
\frac12,\frac12,\frac12,\frac12\right).
}
\tag{1.4}
\]
Indeed, setting \(x=i(m+\tfrac12)\) gives
\[
x^2=-\lambda_m-\frac14,
\qquad
\frac12+ix=-m,
\qquad
\frac12-ix=m+1.
\]

For real \(x>0\), put \(Y=-x^2-\tfrac14\).  The normalized Wilson measure is
\[
d\mu(x)
=\frac{1}{2\pi}
 \left|
 \frac{\Gamma(\frac12+ix)^4}{\Gamma(2ix)}
 \right|^2dx,
\tag{1.5}
\]
and Wilson orthogonality gives
\[
\int_0^\infty
R_m\!\left(-x^2-\frac14\right)
R_n\!\left(-x^2-\frac14\right)d\mu(x)
=\frac{\delta_{mn}}{2n+1}.
\tag{1.6}
\]
Thus
\[
h_n=\frac1{2n+1}.
\tag{1.7}
\]
The actual positive support in the \(Y\)-variable is \(( -\infty,-\tfrac14]\).  All characteristic-zero zeros of \(R_n\) are simple and lie there.  The point
\[
\lambda_n=n(n+1)>0
\]
is not a support point and not a Gaussian node.

This support mismatch is the first obstruction to importing a finite Racah endpoint formula.

## 2. What the formal weight \(w(m)=2m+1\) does—and does not—mean

If one formally substitutes \(\alpha=\beta=\gamma=\delta=0\) into the finite Racah weight, it simplifies to
\[
w(m)=2m+1.
\tag{2.1}
\]
This agrees beautifully with self-duality and (1.7): \(w(m)=h_m^{-1}\).  But without (1.3) there is no terminal point where the Racah difference operator closes.  The infinite sum is not an orthogonality relation: for fixed positive degree \(n\),
\[
R_n(\lambda_m)\asymp m^{2n},
\]
so
\[
(2m+1)R_n(\lambda_m)^2\asymp m^{4n+1},
\]
and the putative discrete norm diverges.

The exact finite partial-sum identity is instead the Christoffel–Darboux boundary formula
\[
\boxed{
\sum_{j=0}^{N}(2j+1)R_j(X)R_j(Y)
=\frac{(N+1)^3}{2}
 \frac{
 R_{N+1}(X)R_N(Y)-R_N(X)R_{N+1}(Y)
 }{X-Y}.
}
\tag{2.2}
\]
By self-duality, (2.2) can be read either as a degree sum or as a finite sum over quadratic-grid positions.  In a genuine finite Racah system, the terminal polynomial vanishes at every support point and the right side vanishes for distinct support points.  Here the boundary term remains.

This is the precise failure of the hoped-for finite orthogonality.  There is a formal weight, but no finite completeness identity
\[
K_N(\lambda_a,\lambda_b)=\frac{\delta_{ab}}{w(a)}.
\]
Consequently \(w(n)=2n+1\) cannot be inserted as a known mass in a Christoffel formula at \(\lambda_n\).

A related finite-field curiosity does not repair the argument.  Modulo \(p\), the upper coefficient \(p^3\) makes the recurrence close at the full interval \(0,\ldots,p-1\), but
\[
\lambda_{p-1-m}=\lambda_m,
\qquad
2(p-1-m)+1=-(2m+1),
\]
so reflected pairs cancel and the resulting form is highly degenerate.  On the folded half-grid the nodes are distinct for \(p>2n+1\), but the missing upper boundary term reappears.

## 3. Exact recurrence, leading coefficient, norm, and CD kernel

The polynomial sequence satisfies
\[
\boxed{
(n+1)^3R_{n+1}(Y)
=(2n+1)(2Y+n^2+n+1)R_n(Y)-n^3R_{n-1}(Y).
}
\tag{3.1}
\]
Its leading coefficient is
\[
\kappa_n=[Y^n]R_n(Y)=\frac{(2n)!}{(n!)^4}.
\tag{3.2}
\]
For the monic polynomial \(P_n=R_n/\kappa_n\), (3.1) becomes
\[
P_{n+1}(Y)=(Y-\alpha_n)P_n(Y)-\beta_nP_{n-1}(Y),
\tag{3.3}
\]
with
\[
\alpha_n=-\frac{n^2+n+1}{2},
\qquad
\boxed{
\beta_n=\frac{n^6}{4(4n^2-1)}.
}
\tag{3.4}
\]
Over \(\mathbb R\), \(\beta_n>0\), which is the Jacobi/Stieltjes input giving real simple interlacing zeros.

The norm ratio also follows directly from (3.1).  Writing
\[
YR_n=A_nR_{n+1}+B_nR_n+C_nR_{n-1},
\]
we have
\[
A_n=\frac{(n+1)^3}{2(2n+1)},
\qquad
C_n=\frac{n^3}{2(2n+1)}.
\]
Self-adjointness gives \(A_{n-1}h_n=C_nh_{n-1}\), hence
\[
\frac{h_n}{h_{n-1}}=\frac{2n-1}{2n+1}.
\]
With \(h_0=1\), this recovers (1.7).

Substituting \(h_j^{-1}=2j+1\) and the leading-coefficient ratio into the general CD formula gives
\[
\boxed{
K_{n-1}(X,Y)
:=\sum_{j=0}^{n-1}(2j+1)R_j(X)R_j(Y)
=\frac{n^3}{2}
 \frac{R_n(X)R_{n-1}(Y)-R_{n-1}(X)R_n(Y)}{X-Y}.
}
\tag{3.5}
\]
The confluent identity is
\[
K_{n-1}(X,X)
=\frac{n^3}{2}
\bigl(R_n'(X)R_{n-1}(X)-R_n(X)R_{n-1}'(X)\bigr).
\tag{3.6}
\]
At a root \(\xi\) of \(R_n\),
\[
\boxed{
K_{n-1}(\xi,\xi)
=\frac{n^3}{2}R_n'(\xi)R_{n-1}(\xi).
}
\tag{3.7}
\]
This confirms exactly the confluent identity used in the question.

For \(p>2n+1\), every denominator in (3.2)–(3.7) is a \(p\)-unit.  Thus all identities reduce without loss of degree modulo \(p\).

## 4. Answer to (a): why real interlacing does not imply finite-field separability

### 4.1 What survives modulo \(p\)

For \(0\le a<b\le n\),
\[
\lambda_b-\lambda_a=(b-a)(a+b+1).
\tag{4.1}
\]
Hence \(p>2n+1\) guarantees that the interpolation nodes
\(\lambda_0,\ldots,\lambda_n\) remain distinct modulo \(p\).  It also guarantees:

- the recurrence coefficients are defined and \(\beta_j\ne0\) for \(j<n\);
- the finite Jacobi matrix is unreduced/cyclic;
- the Gram matrix with diagonal entries \(1,3,\ldots,2n-1\) is nondegenerate;
- \(R_n\) and \(R_{n-1}\) are coprime.

What does **not** survive is positivity.

### 4.2 The exact finite-field obstruction is isotropy

In the \(R_j\)-basis, let \(J_n\) be the \(n\times n\) truncation of multiplication by \(Y\).  Its row recurrence has off-diagonal entries
\[
(J_n)_{j,j+1}=\frac{(j+1)^3}{2(2j+1)},
\qquad
(J_n)_{j+1,j}=\frac{(j+1)^3}{2(2j+3)}.
\]
Put
\[
G_n=\operatorname{diag}(1,3,5,\ldots,2n-1).
\tag{4.2}
\]
Then
\[
G_nJ_n=J_n^{\mathsf T}G_n.
\tag{4.3}
\]
If \(R_n(\xi)=0\), the evaluation vector
\[
v(\xi)=\bigl(R_0(\xi),R_1(\xi),\ldots,R_{n-1}(\xi)\bigr)^{\mathsf T}
\tag{4.4}
\]
is an eigenvector of \(J_n\) with eigenvalue \(\xi\), and
\[
v(\xi)^{\mathsf T}G_nv(\xi)
=K_{n-1}(\xi,\xi).
\tag{4.5}
\]
Because \(J_n\) is cyclic, a repeated root of its characteristic polynomial has geometric multiplicity one and produces a Jordan chain.  Self-adjointness with respect to (4.3) then forces its eigenvector to be isotropic.  Conversely, (3.7) and adjacent coprimality show that isotropy is equivalent to a repeated root:
\[
R_n(\xi)=R_n'(\xi)=0
\quad\Longleftrightarrow\quad
v(\xi)^{\mathsf T}G_nv(\xi)=0.
\tag{4.6}
\]

Over \(\mathbb R\), \(G_n\) is positive definite, so (4.6) is impossible.  Over \(\mathbb F_p\), it is merely nondegenerate.  Nonzero isotropic vectors are routine; in dimension at least three every nondegenerate quadratic form over a finite field of odd characteristic is isotropic.  The special issue is therefore whether the **particular Apéry evaluation eigenvector** can be isotropic, not whether the form is nondegenerate.

### 4.3 A two-dimensional counterexample to any general mod-​\(p\) Stieltjes theorem

Over \(\mathbb F_{13}\), consider the symmetric unreduced Jacobi matrix
\[
A=\begin{pmatrix}10&1\\1&0\end{pmatrix}.
\]
Its characteristic polynomial is
\[
T^2-10T-1=(T-5)^2\pmod{13}.
\tag{4.7}
\]
The corresponding monic recurrence is
\[
P_0=1,
\qquad
P_1=T-10,
\qquad
P_2=T(T-10)-1,
\]
with positive real recurrence coefficient \(\beta_1=1\).  A real lift has simple real roots, but reduction modulo the prime \(13>2\cdot2+1\) has a double root.  Therefore no theorem based only on “positive recurrence before reduction,” nonzero off-diagonal coefficients, or degree \(<p/2\) can imply separability modulo \(p\).

### 4.4 An exact Wilson-family counterexample to global separability

The degree-three example from the executive summary is even stronger:
\[
F_3(Y):=18R_3(Y)=10Y^3+55Y^2+66Y+18,
\]
\[
\operatorname{Disc}(F_3)=2^2\,3^2\,5\,17\,191,
\]
and
\[
F_3(Y)\equiv10(Y-148)^2(Y-176)\pmod{191}.
\tag{4.8}
\]
Thus repeated roots at primes larger than \(2n+1\) occur inside this exact polynomial family.  The requested diagonal theorem, if true, must use the special equality \(\xi=\lambda_n\); it cannot be a general separability theorem for \(R_n\).

**Conclusion for (a).**  Stieltjes, Markov, Sturm, and interlacing theory prove characteristic-zero simplicity.  They do not imply the desired finite-field statement.  The mod-​\(p\) replacement is an anisotropy assertion for one special evaluation vector, and that is additional arithmetic information.

## 5. Answer to (b): the exact Christoffel formula and why it does not close the argument

### 5.1 Correct general formula at a Gaussian node

Let \(\xi_{n,k}\) be a zero of \(R_n\) over \(\mathbb R\), and let \(\Lambda_{n,k}\) be the corresponding Gaussian quadrature weight for the normalized measure (1.5).  The Christoffel function gives
\[
\Lambda_{n,k}
=\frac{1}{K_{n-1}(\xi_{n,k},\xi_{n,k})}.
\]
Using (3.7),
\[
\boxed{
\Lambda_{n,k}
=\frac{2}{n^3R_n'(\xi_{n,k})R_{n-1}(\xi_{n,k})}.
}
\tag{5.1}
\]
Equivalently,
\[
\boxed{
R_n'(\xi_{n,k})
=\frac{2}{n^3\Lambda_{n,k}R_{n-1}(\xi_{n,k})}.
}
\tag{5.2}
\]
The often-quoted slogan that a derivative is the reciprocal of “weight times Christoffel number” suppresses the normalization and the indispensable adjacent-polynomial factor.  Formula (5.1) is the invariant statement.

### 5.2 Why \(\lambda_n\) is not covered

Over characteristic zero, \(R_n(\lambda_n)=b_n>0\), so \(\lambda_n\) is not a zero and has no Gaussian quadrature weight.  Modulo a prime dividing \(b_n\), one may formally regard \(\lambda_n\) as a zero, but then
\[
\Lambda^{-1}=K_{n-1}(\lambda_n,\lambda_n)=C_n.
\]
The Christoffel number is invertible precisely when \(C_n\ne0\), which is precisely the desired separability statement.  Thus (5.1) restates the criterion but does not independently evaluate it.

Nor can the formal Racah weight \(w(n)=2n+1\) be used as \(\Lambda_{n,k}\).  It is a lattice symmetrizer in a nontruncated difference equation, not an atom of a finite orthogonality measure.

### 5.3 The product formula that would hold in a genuine finite system

It is useful to display the nearby true theorem.  Suppose a finite orthogonal system has the \(N+1\) distinct support nodes
\[
\lambda_0,\ldots,\lambda_N,
\qquad \lambda_a=a(a+1).
\]
Its terminal monic polynomial is
\[
Q_{N+1}(Y)=\prod_{a=0}^{N}(Y-\lambda_a).
\tag{5.3}
\]
At a support point,
\[
\boxed{
Q_{N+1}'(\lambda_k)
=(-1)^{N-k}
\frac{(N-k)!(N+k+1)!}{2k+1}.
}
\tag{5.4}
\]
In particular,
\[
Q_{N+1}'(\lambda_N)=(2N)!.
\tag{5.5}
\]
For \(p>2N+1\), this derivative is a \(p\)-unit.  This is exactly the endpoint product mechanism suggested in the question.

But \(Q_{N+1}\) is the **degree \(N+1\) terminal nodal polynomial**.  The polynomial \(R_n\) is degree \(n\), has no truncation parameter, and is not (5.3).  The finite-Racah Christoffel formula therefore proves separability for the wrong polynomial.

### 5.4 Exact ordinary first jet at the diagonal

Differentiating the Newton-product definition at \(Y=\lambda_n\) gives an exact arithmetic formula.  The value of the \(k\)-th summand at \(\lambda_n\) is
\[
A_{n,k}
=\binom nk^2\binom{n+k}k^2.
\]
Moreover,
\[
\sum_{a=0}^{k-1}
\frac{1}{\lambda_n-\lambda_a}
=\sum_{a=0}^{k-1}
\frac{1}{(n-a)(n+a+1)}
=\frac{H_{n+k}-H_{n-k}}{2n+1}.
\]
Hence
\[
\boxed{
D_n=(2n+1)R_n'(\lambda_n)
=\sum_{k=1}^{n}
 \binom nk^2\binom{n+k}k^2
 \bigl(H_{n+k}-H_{n-k}\bigr).
}
\tag{5.6}
\]
For \(p>2n+1\), every harmonic denominator in (5.6) is a \(p\)-unit.  Formula (5.6) makes clear why an elementary product is not automatic: the ordinary derivative is a balanced hypergeometric **harmonic insertion**, not another unshifted Racah value.

### 5.5 Wilson lowering uses a divided difference, not \(d/dY\)

The natural Wilson operator is
\[
\mathcal D_W f(x^2)
=\frac{f((x+i/2)^2)-f((x-i/2)^2)}{2ix}.
\]
For Wilson polynomials,
\[
\mathcal D_W W_n(x^2;a,b,c,d)
=-n(n+a+b+c+d-1)
W_{n-1}\!\left(x^2;a+\tfrac12,b+\tfrac12,c+\tfrac12,d+\tfrac12\right).
\tag{5.7}
\]
At \(a=b=c=d=\tfrac12\), this is
\[
\mathcal D_W W_n(x^2;\tfrac12^4)
=-n(n+1)W_{n-1}(x^2;1,1,1,1).
\tag{5.8}
\]
This is a beautiful product/shift relation, but it concerns a central divided difference and shifts all four parameters.  It is not the ordinary derivative \(R_n'(Y)\).  Converting (5.8) to an ordinary derivative introduces further lower-degree terms; no two-term same-family identity results.

**Conclusion for (b).**  The exact Christoffel formula exists and equals the CD criterion already proved.  The endpoint product formula exists for a genuinely truncated terminal Racah polynomial, not for \(R_n\).  The useful unresolved object is the harmonic sum (5.6).

## 6. Answer to (c): adjacent resultants are smooth; discriminants are not

### 6.1 Schur’s adjacent-resultant formula

For monic polynomials satisfying
\[
P_{n+1}=(Y-\alpha_n)P_n-\beta_nP_{n-1},
\]
Schur’s recurrence argument gives
\[
\operatorname{Res}(P_n,P_{n-1})
=(-1)^{n(n-1)/2}\prod_{j=1}^{n-1}\beta_j^j.
\tag{6.1}
\]
Substituting (3.4),
\[
\boxed{
\operatorname{Res}(P_n,P_{n-1})
=(-1)^{n(n-1)/2}
\prod_{j=1}^{n-1}
\left(\frac{j^6}{4(4j^2-1)}\right)^j.
}
\tag{6.2}
\]
Every numerator and denominator prime in (6.2) is at most \(2n-1\).  The leading coefficients \(\kappa_n\) also involve only primes at most \(2n\).  Therefore
\[
p>2n+1
\quad\Longrightarrow\quad
\operatorname{Res}(R_n,R_{n-1})\not\equiv0\pmod p.
\tag{6.3}
\]
This proves globally that the two adjacent polynomials have no common root modulo \(p\).  In particular, under \(p\mid R_n(\lambda_n)\),
\[
R_{n-1}(\lambda_n)\ne0\pmod p.
\tag{6.4}
\]
Thus the interlacing/backward-induction lemma is not only correct; it has an exact resultant certificate with the desired prime support.

### 6.2 Why the same method does not automatically compute the discriminant

The discriminant is
\[
\operatorname{Disc}(P_n)
=(-1)^{n(n-1)/2}\operatorname{Res}(P_n,P_n').
\]
For Hermite, Laguerre, Jacobi, and related differential families, an ordinary derivative relation expresses \(P_n'\) through one adjacent or parameter-shifted polynomial in a way compatible with Schur’s formula.  That is why their discriminants often factor into small linear factors in the parameters.

Wilson/Racah polynomials are classical on a **quadratic lattice**.  Their natural structure relation is (5.7), a divided-difference identity.  Matsumura’s general discriminant framework, extending Schur/Ulas/Turaj, still requires an ordinary differential identity of the form
\[
F_n(Y)P_n'(Y)=G_{1,n}(Y)P_n(Y)+G_{2,n}(Y)P_{n-1}(Y)
\]
(or a controlled generalization).  The standard Wilson lowering formula does not supply such a two-term identity for \(d/dY\).

A useful global identity makes the obstruction transparent.  For monic \(P_n\), let \(H_j\) be its squared norm and let \(K_{n-1}\) be its CD kernel.  Up to the explicit sign,
\[
\operatorname{Disc}(P_n)
=H_{n-1}^{\,n}
\frac{
 \prod_{P_n(\xi)=0}K_{n-1}(\xi,\xi)
}{
 \operatorname{Res}(P_n,P_{n-1})
}.
\tag{6.5}
\]
The norm and adjacent resultant have only small-prime support here.  Large discriminant primes can—and do—come from vanishing Christoffel kernels at other roots.

### 6.3 Degree-three counterexample in full detail

For
\[
F_3(Y)=10Y^3+55Y^2+66Y+18,
\]
the cubic discriminant formula gives
\[
\operatorname{Disc}(F_3)
=55^2\,66^2
-4\cdot10\cdot66^3
-4\cdot55^3\cdot18
-27\cdot10^2\cdot18^2
+18\cdot10\cdot55\cdot66\cdot18
=584460.
\]
Factoring,
\[
584460=2^2\,3^2\,5\,17\,191.
\]
Modulo \(191\), direct substitution gives
\[
F_3(148)=18336=96\cdot191,
\]
\[
F_3'(148)=20246=106\cdot191,
\]
and hence (4.8).

This also shows why the **full** discriminant is too coarse for the diagonal question.  At the diagonal point \(\lambda_3=12\),
\[
R_3(12)=b_3=1445=5\cdot17^2,
\]
while
\[
F_3'(12)=5706\equiv11\pmod{17}.
\]
Thus \(17\) divides the global discriminant and \(b_3\), but \(Y=12\) is a simple root modulo \(17\); the repeated root occurs elsewhere.  Conversely, proving that the global discriminant is a unit would be much stronger than needed—and is false.

**Conclusion for (c).**  There is an exact small-prime factorization for the adjacent resultant.  There cannot be a small-prime-only factorization of the ordinary discriminant.  The computationally observed large cofactors are compatible with, and already forced by, the degree-three example.

## 7. The exact minimal surviving arithmetic statement

Let \(F_n\in\mathbb Z[Y]\) be any primitive integral multiple of \(R_n\).  For \(p>2n+1\), the clearing scalar and \(2n+1\) are \(p\)-units, so
\[
F_n(\lambda_n)\equiv0,\ F_n'(\lambda_n)\equiv0\pmod p
\]
is equivalent to
\[
b_n\equiv D_n\equiv0\pmod p.
\]
Define the pointed jet gcd
\[
\mathfrak J_n:=\gcd(b_n,D_n).
\tag{7.1}
\]
Then the desired theorem is exactly
\[
\boxed{
\text{every prime divisor of }\mathfrak J_n
\text{ is at most }2n+1.
}
\tag{7.2}
\]
This is strictly weaker than global separability of \(R_n\), and it is not contradicted by the prime \(191\) in \(\operatorname{Disc}(R_3)\).

A particularly clean sufficient certificate would be an identity in the localization \(\mathbb Z[1/(2n)!]\):
\[
A_n b_n+B_nD_n=S_n,
\tag{7.3}
\]
where \(S_n\) is a unit at every prime \(p>2n+1\).  Equivalently, the numerator and denominator of \(S_n\) should have prime support at most \(2n+1\).

An even sharper contiguous target would be
\[
D_n
=U_nR_{n-1}(\lambda_n)+V_nb_n,
\tag{7.4}
\]
with \(U_n\) a unit at every \(p>2n+1\).  Then (6.4) would immediately prove (PS).  Formula (7.4) need not literally exist in this two-term form, but it describes exactly what a successful WZ/contiguous reduction must accomplish: reduce the harmonic insertion (5.6), modulo the unweighted \({}_4F_3\) value \(b_n\), to an adjacent quantity already known to be nonzero.

The most plausible surviving routes are therefore:

- a creative-telescoping identity for the harmonic summand in (5.6), with boundary term supported only on primes \(\le2n+1\);
- a pointed conversion between the ordinary derivative and the Wilson divided difference at \(x=i(n+\tfrac12)\), with a residual multiple of \(b_n\);
- a direct obstruction to a Jordan chain at the special eigenvalue \(\lambda_n\), exploiting the self-dual vector \(R_j(\lambda_n)=R_n(\lambda_j)\), not merely nondegeneracy of the quadratic form;
- a \(p\)-adic unit-root or first-jet argument for the diagonal hypergeometric state.

The following routes, by themselves, are insufficient:

- real positivity/interlacing;
- distinctness of the quadratic grid modulo \(p\);
- the formal weight \(2m+1\) without Racah truncation;
- adjacent coprimality alone;
- a small-prime claim for the full discriminant;
- treating a finite-field sum of squares as positive.

## 8. Sage-style exact verifier

The code below verifies the normalization, recurrence, CD identity, adjacent resultant, the degree-three discriminant counterexample, and pointed diagonal gcds.  It is finite evidence only; the scan does not prove (7.2).

```python
from sage.all import *

QY.<Y> = PolynomialRing(QQ)
ZY.<Z> = PolynomialRing(ZZ)


def R(n):
    """The polynomial R_n(Y) in the Newton quadratic-grid basis."""
    ans = QY(0)
    basis = QY(1)
    for k in range(n + 1):
        if k:
            basis *= Y - (k - 1) * k
        ans += (
            binomial(n, k)
            * binomial(n + k, k)
            * basis
            / factorial(k)^2
        )
    return ans


def primitive_integer_poly(f):
    den = lcm([QQ(c).denominator() for c in f.list()] or [1])
    coeffs = [ZZ(den * c) for c in f.list()]
    content = gcd(coeffs)
    coeffs = [c // content for c in coeffs]
    if coeffs[-1] < 0:
        coeffs = [-c for c in coeffs]
    return ZY(coeffs)


def kappa(n):
    return QQ(factorial(2*n)) / factorial(n)^4


def monic_P(n):
    return R(n) / kappa(n)


def beta(n):
    return QQ(n^6) / (4 * (4*n^2 - 1))


def check_recurrence(limit):
    assert R(0) == 1
    for n in range(limit):
        lhs = (n + 1)^3 * R(n + 1)
        rhs = (2*n + 1) * (2*Y + n^2 + n + 1) * R(n)
        if n:
            rhs -= n^3 * R(n - 1)
        assert lhs == rhs
        assert R(n).leading_coefficient() == kappa(n)


def check_cd(n):
    lhs = sum((2*j + 1) * R(j)^2 for j in range(n))
    rhs = QQ(n^3, 2) * (
        R(n).derivative() * R(n - 1)
        - R(n) * R(n - 1).derivative()
    )
    assert lhs == rhs


def adjacent_resultant_formula(n):
    return (
        (-1)^(n*(n - 1)//2)
        * prod(beta(j)^j for j in range(1, n))
    )


def check_adjacent_resultants(limit):
    for n in range(2, limit + 1):
        actual = monic_P(n).resultant(monic_P(n - 1))
        assert actual == adjacent_resultant_formula(n)


def harmonic_first_jet(n):
    return sum(
        binomial(n, k)^2
        * binomial(n + k, k)^2
        * (harmonic_number(n + k) - harmonic_number(n - k))
        for k in range(1, n + 1)
    )


def diagonal_data(n):
    lam = n * (n + 1)
    b = ZZ(R(n)(lam))
    D = ZZ((2*n + 1) * R(n).derivative()(lam))
    assert QQ(D) == harmonic_first_jet(n)
    g = gcd(b, D)
    large = [(p, e) for p, e in factor(g) if p > 2*n + 1]
    return dict(n=n, lam=lam, b=b, D=D, gcd=g, large=large)


def repeated_diagonal(n, p):
    assert p > 2*n + 1 and is_prime(p)
    F = primitive_integer_poly(R(n))
    Fp.<y> = PolynomialRing(GF(p))
    f = Fp(F)
    x = GF(p)(n * (n + 1))
    return f(x) == 0 and f.derivative()(x) == 0


def discriminant_data(n):
    F = primitive_integer_poly(R(n))
    disc = ZZ(F.discriminant())
    return F, disc, factor(disc)


check_recurrence(15)
for n in range(1, 16):
    check_cd(n)
check_adjacent_resultants(12)

# Pointed finite scan.
for n in range(1, 16):
    print(diagonal_data(n))

# Exact degree-three global counterexample.
F3, disc3, fac3 = discriminant_data(3)
assert F3 == 10*Z^3 + 55*Z^2 + 66*Z + 18
assert disc3 == 2^2 * 3^2 * 5 * 17 * 191

Fp191.<y> = PolynomialRing(GF(191))
f191 = Fp191(F3)
assert f191 == 10 * (y - 148)^2 * (y - 176)
assert f191(148) == 0
assert f191.derivative()(148) == 0

# At the actual n=3 diagonal, p=17 is simple.
Fp17.<u> = PolynomialRing(GF(17))
f17 = Fp17(F3)
assert f17(12) == 0
assert f17.derivative()(12) == 11

# Generic finite-field no-go for a symmetric Jacobi matrix.
K = GF(13)
A = matrix(K, [[10, 1], [1, 0]])
cp = A.charpoly()
T = cp.parent().gen()
assert cp == (T - 5)^2
```

For a larger experiment, the quantity to tabulate is not merely \(\operatorname{Disc}(F_n)\), but
\[
\gcd\bigl(F_n(\lambda_n),(2n+1)F_n'(\lambda_n)\bigr),
\]
after removing the fixed clearing scalar.  Factoring the global discriminant answers a stronger and mostly irrelevant question.
