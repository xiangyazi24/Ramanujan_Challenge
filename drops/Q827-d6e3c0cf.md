# Q827: C4 four-characteristic sector audit

The given hypotheses already reduce the problem to the disjoint-edge C4 sector:

\[
\sum_{e,e':\, e\cap e'=\varnothing}X_e(n)X_{e'}(n),
\]

where four distinct primes occur. The remaining task is therefore a four-modulus correlation problem, not a diagonal or one-prime-dependency problem.

## Exact remaining exponential-sum object

After CRT expansion, the smallest unresolved object has the form

\[
\sum_{\substack{p_1,p_2,p_3,p_4\\\text{short prime edges }(p_1,p_2),(p_3,p_4)}}
 a_{p_1,p_2,p_3,p_4}
 \sum_{n\le N}
 \prod_{i=1}^4
 \left(1_{p_i\mid b_{n\bmod p_i}}-\mu_{p_i}\right),
\]

with the restrictions

* \(|p_1-p_2|,|p_3-p_4|\le C\log N/q\);
* \(\lfloor n/p_i\rfloor=q\) on the support of the corresponding edge weights;
* all four primes distinct.

The target is an aggregate bound of size

\[
o(N^2/\log^2 N).
\]

Any successful proof must exploit structure beyond independence heuristics.

## Subsector audit

### Equal gaps

If the two edges have equal gap size, this only gives a geometric coincidence of prime pairs. It does not by itself produce cancellation in the four-fold CRT phase. Equal-gap counting can reduce the number of configurations but does not close the C4 sum.

### Crossing/nested prime order

Ordering the four primes on the line separates combinatorial configurations. However, the CRT frequencies remain four independent residue frequencies. Crossing versus nested order alone is not an analytic estimate.

### Near CRT-frequency collisions

The possible useful mechanism is a Weyl-type argument after Fourier expansion. The required statement is a quantitative lower bound on frequency separation for the surviving four-modulus characters. Existing low-frequency CRT-Weyl ideas only control this if the frequency set is genuinely sparse; they do not automatically apply to all short prime-edge pairs.

### Fully transverse versus aligned configurations

The transverse case is the real obstruction. Alignment can potentially be handled by codegree or rectangle extraction arguments because repeated row/column constraints reduce entropy. The fully transverse case retains four independent prime constraints and is exactly where those arguments lose a dimension.

## Tests of proposed inputs

### Q8740 codegree

A codegree bound would control sectors where two edge constraints share a vertex or where many edges collide on the same prime. The Q827 C4 sector explicitly removes shared primes. Therefore codegree does not directly estimate the remaining sector.

### Weak low-frequency CRT-Weyl route

It would control a restricted Fourier spectrum if the truncation error were already below the target. The missing implication is a proven truncation statement uniform over the growing short-prime window. Without that, it is insufficient.

### Matching-block / rectangle extraction

This can potentially extract many correlated rectangles from repeated local structure. It cannot by itself prove cancellation for a collection of fully transverse four-prime configurations.

### Canonical common b_n output

A common output sequence can rule out some artificial independence models, but it does not provide the needed exponential cancellation unless an explicit correlation theorem for the b_n construction is available.

Then all one- and two-prime tests pass, while the C4 contribution is of main order. Hence none of those weaker inputs implies the required four-characteristic estimate.

## Minimal remaining cut

The smallest missing theorem is a four-distinct-prime correlation estimate:

> For short prime edges in one q-cell, the aggregate CRT/Fourier contribution of fully transverse disjoint edge pairs is \(o(N^2/\log^2 N)\).

Equivalent formulations:

1. a four-frequency CRT-Weyl estimate with the exact short-prime support;
2. a transverse rectangle theorem strong enough to force cancellation;
3. a direct fourth-moment bound for the centered edge variables.

No weaker previously listed input closes this cut.

No unconditional closure of the C4 sector follows from the currently listed mechanisms alone. The remaining obstruction is precisely the fully transverse four-distinct-prime exponential sum above. The strongest currently justified reduction is therefore:

\[
\boxed{\text{C4 closure} \Longleftrightarrow \text{new four-characteristic cancellation theorem}.}

Finite scans, Q8740-style codegrees, fixed-gap arguments, and pairwise controls do not prove this theorem without an additional genuinely four-way analytic input.
