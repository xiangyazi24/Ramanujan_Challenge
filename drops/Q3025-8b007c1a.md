\[

\end{aligned}
\tag{6.2}
\]

The bracket is an integer. Indeed the standard Apéry denominator theorem gives

\[

\[
Z_\alpha:=(n!)^3\sum_c\alpha_cc_{c-1}b_{c-1}\in\mathbf Z.
\tag{6.3}

\[
\boxed{
\sum_c\alpha_cM_c=-b_nZ_\alpha.

\tag{6.4}

This proves `(NG1)`.

If the scalar is nonzero, then

\[
\left|\sum_c\alpha_cM_c\right|\ge b_n,

\[
\boxed{
\log\left|\sum_c\alpha_cM_c\right|
\ge\lambda n+O(\log n).

\tag{6.5}

\[
\gcd_\alpha\left|\sum_c\alpha_cM_c\right|

\tag{6.6}

Thus even taking a gcd of arbitrarily many pure `D_n`-eliminating Green scalars cannot remove the `b_n` factor. At best it reduces the deterministic coefficient gcd to one and returns `b_n` itself.

This class includes:

- every integer linear combination of pair eliminants;
- every finite gcd of such scalars;

The conclusion is exact: a nonzero scalar in this class cannot have sublinear height.

dividing by factorial, lcm, or row content supported below K(n).
```

Therefore no construction in this class can use the numerical smallness of `g` to remove even one hard target prime. It sees only the same endpoint two-state content.

## 6.3 Precise scope

The two no-go statements do **not** claim that every conceivable use of the Green family is impossible.

They do not cover:

Gessel first-jet/energy extensions;
Cartier, Dwork, or Frobenius data;

primitive cyclotomic block products that are not obtained by identifying conjugates.
```

The point is narrower and exact: the presently proposed edge-content/low-kernel Green operations cannot create the missing aggregate cancellation.

# 7. The exact remaining small-kernel lemma

For each divisor `g|m`, put

\[
h=\frac mg.
\]

Define `\mathcal T_g(n)` to be the set of integers `N` satisfying

\[
\frac h2<N<h,
\qquad
(N,h)=1,
\qquad
N>D,
\tag{7.1}
\]

such that

\[
p=1+gN
\]

is prime, and, with

\[
t=\min(h-N,2N-h),
\qquad s=gt,
\]

one has

\[
s>H,
\qquad
p\mid b_s.
\tag{7.2}
\]

The surviving small-kernel weighted radical is

\[
\boxed{
S_{\rm sk}(n)
=
\sum_{\substack{g\mid m\\g\le G}}
\sum_{N\in\mathcal T_g(n)}\log(1+gN).
}
\tag{7.3}
\]

By construction, the map `(g,N)->p` is injective: `g=(p-1,m)` is exact. Equations (1.5) and (4.6) give

\[
S_{\rm sk}(n)
\le\log W_1(n)+o(n)
\le3S_{\rm sk}(n)+o(n).
\tag{7.4}
\]

Therefore

\[
\boxed{
\log W_1(n)=o(n)
\iff
S_{\rm sk}(n)=o(n).
}
\tag{7.5}
\]

This is not merely another support reformulation: every sector outside (7.3) has already been assigned a proved sublinear-height container in Section 4.

The packet geometry is now very rigid. Since `g<=G=n^{o(1)}` and `h/2<N<h`,

\[
N=n^{1-o(1)}.
\]

Since `s=gt>H`,

\[
t>\frac{H}{g}=n^{1-o(1)}.
\]

Also

\[
(t,N)=1.
\]

Thus the unresolved target is one nearly primitive Fourier/Mellin coordinate of order `N`, not a bounded-order character.

# 8. A concrete sufficient quantitative theorem

A useful per-stratum theorem is

\[
\boxed{
\sum_{N\in\mathcal T_g(n)}\log(1+gN)
\ll
\frac{n}{\varphi(g)(\log\log n)^2}
}
\tag{8.1}
\]

uniformly for

\[
g\mid n-1,
\qquad g\le G.
\]

To see that this suffices, use the elementary divisor Euler product

\[
\begin{aligned}
\sum_{d\mid m}\frac1{\varphi(d)}
&=
\prod_{p^a\parallel m}
\left(1+\sum_{j=1}^{a}\frac1{\varphi(p^j)}\right)\\
&\le
\prod_{p\mid m}
\left(1+\frac{p}{(p-1)^2}\right)\\
&\ll\log\log(3m).
\end{aligned}
\tag{8.2}
\]

Summing (8.1) over `g|m` gives

\[
S_{\rm sk}(n)
\ll
\frac{n}{(\log\log n)^2}
\sum_{g\mid m}\frac1{\varphi(g)}
\ll
\frac n{\log\log n}
=o(n).
\tag{8.3}
\]

Thus `(SKP1-u)` is a clean quantitative next lemma. In counting form it is enough to prove

\[
\#\mathcal T_g(n)
\ll
\frac{n}{\varphi(g)\log n\,(\log\log n)^2},
\tag{8.4}
\]

because every packet prime has `\log p\asymp\log n`.

The all-prime Brun--Titchmarsh scale is

\[
\sum_{\substack{h/2<N<h\\1+gN\text{ prime}}}
\log(1+gN)
\ll\frac n{\varphi(g)}.
\]

Hence (8.1) asks only for a vanishing target density, with a convenient explicit `\log\log` saving. No such uniform target anti-concentration theorem is currently banked.

# 9. Toric/Mellin form of the missing lemma

For the remaining packet, write

\[
p=1+gN,
\qquad s=gt,
\qquad(t,N)=1.
\]

The exact toric pushforward from the bounded-kernel audit gives

\[
U_{p,g,t}
=
\sum_{\zeta\in\mu_N}M_{p,g}(\zeta)\zeta^t,
\]

and

\[
\boxed{p\mid b_{gt}\iff U_{p,g,t}=0\quad\text{in }\mathbf F_p.}
\tag{9.1}
\]

Because `(t,N)=1`, this is a primitive `N`th Fourier coordinate. Quotienting by the kernel of size `g` does not reduce its order. The exact bounded toric coefficient packet Frobenius-reduces to the ordinary convolution for `b_{gt}` itself, so it supplies no second linear equation.

Thus `(SKP1)` can be stated equivalently as the primitive toric Mellin anti-concentration theorem

\[
\boxed{
\sum_{\substack{g\mid n-1,\ g\le G\\N\in\mathcal N_g(n)\\U_{1+gN,g,t}=0}}
\log(1+gN)
=o(n),
}
\tag{9.2}
\]

where `\mathcal N_g(n)` imposes the geometric and threshold conditions in (7.1)--(7.2) but not the target equation.

A stronger constructive alternative would be a fixed-parameter reciprocity carrier: for each `g|m`, `g<=G`, construct a nonzero integer `C_g(m)` satisfying

\[
\log|C_g(m)|=O(g\,\operatorname{polylog}n)
\]

and

\[
p\mid C_g(m)
\]

for every target prime in `\mathcal T_g(n)`. Then

\[
\log\prod_{\substack{g\mid m\\g\le G}}|C_g(m)|
\le
\tau(m)G\,\operatorname{polylog}n
=n^{o(1)}=o(n),
\]

which would immediately close `(SKP1)`. The primitive-orbit audit shows that such a scalar cannot be obtained merely by taking the full cyclotomic norm: the forced orbit has degree `\varphi(N)/2`, independent of `g` up to the inversion factor.
