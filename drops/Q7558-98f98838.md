# Problem 3.2 q6 C4 — exact integer upper-selector extremum and the adaptive-threshold no-go

## Executive verdict

**Integrality gives no logarithmic improvement.** For the optimization specified in the question, the integrality gap is exactly zero, not merely asymptotically small.

Fix an upper prime `q`. Let

```text
Z_q = {t mod q : q divides b_t}
n   = |Z_q| = Z(q)
z_q(t) = 1_{t in Z_q}
g_q(t) = z_q(t) - n/q
G_q = sum_t g_q(t)^2 = n(q-n)/q.
```

Let `kappa[q,t]` be the exact Boolean-unioned q6 candidate capacity at digit `t`, and prescribe

```text
M = A_q^0 = sum_t A_q(t),
0 <= A_q(t) <= kappa[q,t],
A_q(t) integral.
```

Put

```text
C1(q) = sum_{t in Z_q}     kappa[q,t],
C0(q) = sum_{t not in Z_q} kappa[q,t].
```

For `0 <= M <= C1(q)+C0(q)`, the exact optimum is

```text
E_int(q;M)
 = max_A (sum_t g_q(t) A_q(t))_+^2 / G_q
 = [q min(M,C1(q)) - nM]_+^2 / [q n (q-n)].          (E)
```

An optimizer fills actual upper-zero digits first, up to total `min(M,C1(q))`, and puts any remaining mass on nonzero digits. Because the capacities and `M` are integers, this optimizer is integral. The real relaxation has the same value.

In particular, whenever every upper-zero digit has capacity at least an integer `K`, the integral load

```text
A_q(t) = K z_q(t)
```

satisfies

```text
A_q^centered = K g_q,
sum_t g_q(t) A_q(t) = K G_q,
projected energy = K^2 G_q.
```

This is exact equality in the Hilbert projection.

At the state-adaptive transition, take

```text
B  = T^2 / (log T)^2,
G  = sum_q G_q,
K  = floor(B/G).
```

The banked estimate

```text
G <<_J U0,
U0 = T^(8/5) (log T)^(-4/5) = o(B)
```

implies `B/G -> infinity`. Integer rounding is therefore negligible. On the allowed saturated state scale `G asymp U0`, exact integer loads can give

```text
sum_q (d_q)_+ = (1+o(1)) B,
PRE-PAUC(A)   = (1+o(1)) B^2/G.
```

The exact q6 central-window capacity is of order `T/log T`, while

```text
B/G asymp T^(2/5) (log T)^(-6/5) << T/log T.
```

Thus capacity is nonbinding by a power of `T`. Increasing `K` by `sqrt(log T)` also gives an integral realization of the full one-log rectangle scale

```text
T^(12/5) (log T)^(-11/5)
 = (log T) B^2/U0.
```

Therefore

```text
The integer optimum can asymptotically saturate B^2/G.
It does not fall by a factor 1/log T.
```

The missing saving remains a genuinely mixed actual-Apéry anti-alignment, collision, or horizontal-distribution theorem. It is not a lattice consequence.

## 2. Exact local integer optimization

Fix `q` and abbreviate

```text
Z = Z_q,
n = |Z|,
kappa_t = kappa[q,t],
A_t = A_q(t),
M = A_q^0.
```

Assume `0<n<q`. If `n=0`, then `g_q=0` and the projected value is zero.

Define

```text
C1 = sum_{t in Z}     kappa_t,
C0 = sum_{t not in Z} kappa_t,
S  = sum_{t in Z}     A_t.
```

The selector cut is exactly

```text
a_q = S - (n/q) M.                                    (2.1)
```

Thus, for fixed `M`, maximizing the positive projection is exactly maximizing `S`.

### Theorem 2.1 — exact integer extremum

If

```text
0 <= M <= C1+C0,
```

then the possible selected totals are precisely the integers in

```text
max(0,M-C0) <= S <= min(M,C1).
```

Therefore

```text
S_max = min(M,C1),
max_A (a_q)_+ = [min(M,C1) - (n/q)M]_+,
```

and formula `(E)` follows:

```text
E_int(q;M)
 = [q min(M,C1)-nM]_+^2 / [q n (q-n)].
```

#### Proof

The inequalities `S<=M` and `S<=C1` are immediate. Conversely:

- If `M<=C1`, greedily fill selected integer bins until their total is `M` and put zero outside `Z`.
- If `M>C1`, fill every selected bin to capacity and place the remaining `M-C1<=C0` units outside `Z`.

Both constructions are integral. Equation `(2.1)` is increasing in `S`. This proves the theorem.

### Corollary 2.2 — zero integrality gap

The continuous relaxation

```text
0 <= A_t <= kappa_t,
sum_t A_t = M,
A_t real
```

has the same value. Equivalently,

```text
integer optimum = continuous optimum.
```

The feasible polytope is a box cut by one integral sum equation, and the linear objective has an integral greedy optimizer.

### Corollary 2.3 — maximum over the total load

The unsquared optimum increases until `M=C1` and decreases afterwards. Hence

```text
max_{M,A} (a_q)_+^2/G_q
 = C1^2(q-n)/(qn)
 = G_q (C1/n)^2.                                      (2.2)
```

Only the average q6 capacity on the actual upper-zero set matters locally.

## 3. If only the zero-set size is retained

Formula `(E)` uses the actual locations of `Z_q` through `C1`. If only `n=Z(q)` is retained, the worst placement is still a finite exact optimization.

Without reflection or spacing constraints, define

```text
C_star(q,n) = sum of the n largest capacities kappa[q,t].
```

Then replace `C1` by `C_star(q,n)` in `(E)`.

For actual Apéry reflection and no consecutive zeros, define the admissible family

```text
S subset {0,...,q-1},
|S|=n,
S is invariant under t -> q-1-t,
S has no consecutive residues,
0 and q-1 are excluded.
```

Let

```text
C_star_refl(q,n)
 = max over admissible S of sum_{t in S} kappa[q,t].
```

The exact size-only extremum is

```text
[q min(M,C_star_refl(q,n))-nM]_+^2 / [q n (q-n)].       (3.1)
```

This is a weighted independent-set knapsack on the reflection-orbit path. A noncentral orbit has cardinality cost `2` and weight

```text
kappa[q,t] + kappa[q,q-1-t],
```

while the center has cost `1`. The recurrence

```text
DP[i,k] = max(DP[i-1,k],
              DP[i-2,k-orbit_size_i] + orbit_weight_i)
```

computes it in `O(qn)` arithmetic operations. Reflection and spacing therefore change the finite capacity statistic, but they do not generate an analytic logarithm.

## 4. Uniform-cap formulas and exact Hilbert equality

If every digit has the same capacity `kappa`, then `C1=n kappa` and `(E)` becomes

```text
E_int(q;M) = M^2(q-n)/(qn),
             for 0 <= M <= n kappa;

E_int(q;M) = n(q kappa-M)^2/[q(q-n)],
             for n kappa <= M <= q kappa.              (4.1)
```

The maximum occurs at `M=n kappa` and equals

```text
max_M E_int(q;M) = kappa^2 G_q.                         (4.2)
```

More generally, if `kappa[q,t] <= kappa_q`, then

```text
E_int(q;M) <= kappa_q^2 G_q.                            (4.3)
```

This is sharp whenever every selected digit has capacity at least `kappa_q`: take

```text
A_q(t) = kappa_q z_q(t).
```

Then

```text
A_q^0 = kappa_q n,
M_q   = sum_t z_q(t)A_q(t) = kappa_q n,
(n/q)A_q^0 = kappa_q n^2/q,
a_q = M_q - (n/q)A_q^0 = kappa_q G_q.
```

### One-sided reflection orbits

For `J<=45`, exact plus legality can retain only one orientation of a reflected pair. This still gives no logarithm. Let `S_q` contain one member of each of `m_q` reflected zero pairs and put


If `m_q = theta n`, then exactly

```text

projected energy = theta^2 K^2 G_q.                    (4.4)
```

For one member per pair, `theta=1/2`. This is only a constant loss. Replacing `K` by `2K` restores the same adaptive scale. For `J>=46`, the double-legal central slab permits `theta=1`.

## 7. Raw PRE-PAUC(A) versus full owner PAUC(C)

The exact integer theorem applies to

```text
A_q(t) in nonnegative integers.
```

The owner defect is

```text
C_q(t) = A_q(t) - R_q(t),
```

where `R_q(t)` contains the rational `rho_p/tau_p` Boolean-union profile. Thus `C_q(t)` is generally rational and signed. Integrality of `A` does not make `C` integral and cannot directly sharpen the Hilbert projection for `C`.

This is a real, not merely formal, distinction. At the exact complete point `(J,T)=(46,3670)`, the synchronized reproduction contains a row `q=631` with

```text

M_mark = 0,
but d_631 > 0 and the full PAUC contribution positive,
```

because `C=-R` there. An integer extremal theorem for `A` neither captures nor dominates every full-PAUC contribution.

Conversely, the raw integer load already saturates under the current numerical and capacity interfaces. So integrality cannot supply the missing logarithm for the stronger full defect either.

## 8. Owner-safe theorem and claim boundary

> **Theorem (q6 integer selector-capacity extremum).** Fix `T,J`, an upper prime `q`, its actual Apéry zero set `Z_q` of size `n`, and exact Boolean-unioned capacities `kappa[q,t]`. For an integer `M` with `0<=M<=sum_t kappa[q,t]`, maximize over integral loads `0<=A_t<=kappa[q,t]` with `sum_t A_t=M`. Put `C1=sum_{t in Z_q}kappa[q,t]`. If `0<n<q`, then
>
> ```text
> max_A
>   (sum_t (1_{Z_q}(t)-n/q)A_t)_+^2 / [n(q-n)/q]
> = [q min(M,C1)-nM]_+^2/[q n(q-n)].
> ```
>
> The same value is obtained in the real relaxation, and an integral optimizer fills upper-zero bins first.

> **Corollary (sharp adaptive threshold).** Suppose a fixed positive fraction `theta` of the upper-zero digits has capacity at least `K=floor(B/(theta G))`. Then the integral choice `A_q=K 1_{S_q}`, with `|S_q|=theta Z(q)`, gives
>
> ```text
> sum_q(a_q)_+ = (1+o(1))B,
> P_A^+        = (1+o(1))B^2/G,
> ```
>
> provided `G=o(B)`. The current q6 banks have `G<<U0=o(B)`, and central q6 capacity exceeds the required `K` by a power of `T`.

> **No-go consequence.** No estimate `P_A^+=o(B^2/G)` follows from only integrality, nonnegativity, the totals `A_q^0`, exact q6 per-digit capacities, upper reflection, no-consecutive zeros, the banked upper zero-count moments, and the banked total pre-upper mass.

The theorem does **not** assert that actual lower-characteristic Apéry zero pairs realize the aligned load `A_q=Kz_q`. It establishes the logically relevant boundary: the listed interfaces do not exclude it and therefore cannot prove the missing logarithm.

## Final conclusion

The exact finite optimization is simple because the selector has only two values: all selected digits have coefficient `1-n/q`, and all unselected digits have coefficient `-n/q`. The prescribed total load should therefore be placed on selected bins first, and integer capacities permit the extremal selected total

```text
min(A_q^0,C1(q))
```

with no integrality gap.

The two-level integer vector

```text
A_q(t)=K 1_{Z_q}(t)
```

is already the sharp Hilbert equality vector. At the adaptive scale, `K=B/G` tends to infinity, while q6 per-digit capacity is of order `T/log T` and is much larger. The banked total-load and zero-count moments also permit the construction. Hence

```text
P_A^+ ~ B^2/G
```

is asymptotically attainable by exact integer loads, and the larger integer rectangle still gives

```text
P_A^+ asymp (log T) B^2/U0.
```

There is no hidden `1/log T` gain from integrality, discreteness, or q6 capacity. The first possible source of such a gain remains an actual-Apéry theorem coupling lower-prime support to the upper zero selector.
