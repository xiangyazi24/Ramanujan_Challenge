# Consecutive-four-zero and fully-deflated adjacent-equation audit

## Verdict

The proposed empirical statement

> every four **consecutive** Apéry zeros contains an adjacent reflection-centered pair

is **false** below \(10^6\).

* Among all primes \(p\le 10^6\), there are **7,132** primes with \(Z(p)\ge4\).
* They produce **9,606** genuine four-consecutive-zero windows.
* **9,306** windows contain an adjacent pair \(z_j+z_{j+1}=p-1\).
* **300** windows, belonging to **136** primes, do not.
* The smallest counterexample is \(p=3727\), with first failing window
  
  
  \[
  (99,868,1011,1294),\qquad (a,b,c)=(769,143,283).
  \]

The structural carrier changes the conclusion but does not eliminate every failure:

* Of the 300 failures, **264** have \(p\mid\mathfrak U_H\) for the minimal height
  \(H=a+b+c=z_{i+3}-z_i\).
* **36** failure windows, on **18** distinct primes, have
  \(p\nmid\mathfrak U_H\).
* The smallest such case is
  
  
  \[
  p=28933,\quad r=7602,\quad (a,b,c)=(3074,1166,253),\quad H=4493.
  \]

Thus the **adjacent primitive** version of the obstruction is already false at
\(p=28933\): the four displayed zeros are consecutive in the complete zero set,
none of the three adjacent pairs is centered, all three adjacent gap equations
survive central deflation, and \(p\nmid\mathfrak U_{4493}\).

There is an important qualification.  The repository's non-palindromic aligned
pencil uses the skipped equation \(N_{b+c}(r+a)=0\).  In the \(p=28933\) example
that skipped interval contains the intermediate zero \(r+a+b\), by construction.
Therefore this computation refutes the primitive **adjacent-equation** claim, but
it does not refute a narrower statement whose phrase “contains an intermediate
return” refers specifically to the deliberately skipped \(N_{b+c}\) equation.
That distinction is essential.

This is a finite exact computation, not a proof of any positive statement beyond
\(p\le10^6\).  It also does not identify or classify the characteristic-zero
reduced contents first seen at \(H=24\); the smallest outside-carrier modular
adjacent witness here has \(H=4493\).

## Definitions used in the audit

For a prime \(p\), write

\[
\mathcal Z_p=\{0\le z<p:b_z\equiv0\pmod p\},
\qquad Z(p)=|\mathcal Z_p|.
\]

If

\[
z_i<z_{i+1}<z_{i+2}<z_{i+3}
\]

are four successive entries of the **complete sorted set** \(\mathcal Z_p\), put

\[
(a,b,c)=(z_{i+1}-z_i,\ z_{i+2}-z_{i+1},\ z_{i+3}-z_{i+2}),
\qquad H=a+b+c.
\]

“Consecutive” in this report always means consecutive in the complete zero set,
not merely four chosen members of a larger orbit.  Hence each of the three
adjacent intervals has no intermediate Apéry zero.

For even \(h\), the reflection factor is

\[
L_h(x)=2x+h+1,\qquad N_h(x)=L_h(x)N_h^\circ(x),
\]

and \(N_h^\circ=N_h\) for odd \(h\).  For an adjacent pair
\((x,x+h)\subset[0,p-1]\),

\[
L_h(x)\equiv0\pmod p
\quad\Longleftrightarrow\quad
x+(x+h)=p-1.
\]

The minimal structural carrier tested for a window was exactly the one in
`problems/3.2/atom_tail_section.tex`:

\[
\mathfrak U_H=\prod_{j\le H} j!\,b_j\,V_{j+1},
\]

where \(V_0=0,V_1=1,V_{n+1}=34V_n-V_{n-1}\).  Since every audited
window has \(H<p\), its factorial factors cannot contribute \(p\).  The other two
checks are exact:

\[
p\mid\prod_{j\le H}b_j
\iff \min\mathcal Z_p\le H,
\]

and, with \(ho(p)\) the rank of apparition from the repository,

\[
p\mid\prod_{j\le H}V_{j+1}
\iff \rho(p)\le H+1.
\]

Using the minimal \(H=a+b+c\) is the strongest outside-carrier test.  If a larger
ambient height is selected, carrier membership can only increase.

## Smallest counterexample to the centered-adjacent assertion: \(p=3727\)

The complete zero set is

\[
\mathcal Z_{3727}=
\{99,868,1011,1294,2432,2715,2858,3627\}.
\]

It was reproduced directly from

\[
A_{m+1}=P(m)A_m-m^6A_{m-1}\pmod p,
\qquad A_m=(m!)^3b_m,
\]

for all \(0\le m<p\).  The reflection pairs are

\[
99+3627=868+2858=1011+2715=1294+2432=3726=p-1.
\]

All five genuine four-consecutive-zero windows are:

| start \(i\) | four consecutive zeros | \((a,b,c)\) | three adjacent sums | result |
|---:|---|---|---|---|
| 0 | \((99,868,1011,1294)\) | \((769,143,283)\) | \((967,1879,2305)\) | **fail** |
| 1 | \((868,1011,1294,2432)\) | \((143,283,1138)\) | \((1879,2305,3726)\) | pass |
| 2 | \((1011,1294,2432,2715)\) | \((283,1138,283)\) | \((2305,3726,5147)\) | pass |
| 3 | \((1294,2432,2715,2858)\) | \((1138,283,143)\) | \((3726,5147,5573)\) | pass |
| 4 | \((2432,2715,2858,3627)\) | \((283,143,769)\) | \((5147,5573,6485)\) | **fail** |

The first and last rows are mirror images.  Because the displayed set is the
complete zero set, neither is a skipped four-element subchain.

For either failing row, \(H=1195\).  This prime is absorbed by the carrier:

```text
min zero = 99 <= 1195, so 3727 divides b_99 and hence U_1195;
rho(3727) = 1863 > 1196, so the V-part is not needed.
```

All three gaps in both failing rows are odd, so their individual central
deflation is trivial: \(N_h^\circ=N_h\).

## Smallest failure outside the minimal structural carrier: \(p=28933\)

The complete zero set, again independently reproduced by the factorialized
recurrence, is

\[
\mathcal Z_{28933}=
\{7602,10676,11842,12095,16837,17090,18256,21330\}.
\]

Its reflection pairs all sum to \(28932=p-1\).  The two noncentered edge windows
are

\[
(7602,10676,11842,12095),
\qquad (a,b,c)=(3074,1166,253),
\]

and its reflected partner

\[
(16837,17090,18256,21330),
\qquad (a,b,c)=(253,1166,3074).
\]

For the first window,

```text
adjacent sums:       18278, 22518, 23937
p - 1:               28932
central factors:     18279, 22519, 23938  (mod 28933)
H = a+b+c:           4493
rho(28933):          14467
```

Thus none of the adjacent pairs is centered.  The exact scalar continuant
recurrence gives

\[
N_{3074}(7602)=N_{1166}(10676)=N_{253}(11842)=0\pmod{28933}.
\]

Since the first two reflection factors are nonzero and the third gap is odd,

\[
N_{3074}^{\circ}(7602)
=N_{1166}^{\circ}(10676)
=N_{253}^{\circ}(11842)=0\pmod{28933}.
\]

The reflected window gives the same result with gap vector reversed.  The direct
program output was

```text
first window raw adjacent N:          [0, 0, 0]
first window deflated adjacent Ncirc: [0, 0, 0]
mirror raw adjacent N:                [0, 0, 0]
mirror deflated adjacent Ncirc:       [0, 0, 0]
```

Carrier membership at the minimal height is exactly negative:

* \(H=4493<p\), so \(p\) divides no \(j!\) with \(j\le H\);
* the first Apéry zero is \(7602>4493\), so no \(b_j\), \(j\le H\), contributes;
* \(ho(28933)=14467>4494\), so no \(V_{j+1}\), \(j\le H\), contributes.

Therefore

\[
28933\nmid\mathfrak U_{4493}.
\]

In fact this remains outside \(\mathfrak U_H\) for
\(4493\le H\le7601\); at \(H=7602\) the factor \(b_{7602}\) enters.

### Adjacent versus skipped equations in this example

The three adjacent intervals are primitive because the four values are
consecutive in the complete zero set.  However, the non-palindromic aligned
pencil also uses

\[
N_{b+c}(r+a)=N_{1419}(10676)=0\pmod{28933}.
\]

That interval runs from 10676 to 12095 and contains the intermediate zero 11842.
For the reflected window the aligned skip is

\[
N_{4240}(17090)=0\pmod{28933},
\]

and contains the intermediate zero 18256.  Hence:

* the adjacent primitive system has no intermediate returns and violates the
  centered-pair assertion;
* the aligned skipped equation does have an intermediate return.

These are different statements and should not be merged.

## Fully-deflated adjacent equations: aggregate result

Every one of the 300 failure windows has three noncentered adjacent pairs.  If an
adjacent gap \(h\) is even, its factor \(2x+h+1\) is therefore a unit modulo
\(p\), and

\[
N_h(x)=0\quad\Longrightarrow\quad N_h^\circ(x)=0.
\]

Consequently:

```text
failure windows surviving individual adjacent deflation: 300 / 300
adjacent equation evaluations surviving deflation:       900 / 900
```

For the repository's **aligned** definition, every one of the 300 failures has
\(c\ne a\), so it uses the raw non-palindromic branch.  No failure is removed by
the palindromic middle deflation.  Saturation by the minimal
\(\mathfrak U_H\) then removes 264 windows and leaves the 36 windows reported
above.

This gives the precise empirical conclusion:

> Through \(p\le10^6\), central deflation alone does not force a centered adjacent
> pair in a genuine consecutive chain.  Even after minimal carrier saturation,
> 36 adjacent primitive chains survive, beginning at \(p=28933\).  The aligned
> skipped equation for each such chain must still be classified separately,
> because it contains an intermediate return by construction.

    for m in range(1, p - 1):

# Scalar gap-polynomial recurrence, used to check the smallest outside case.
def Pmod(n: int, p: int) -> int:
    return (34 * n**3 + 51 * n**2 + 27 * n + 5) % p

def N_eval(h: int, x: int, p: int) -> int:
    assert h >= 1
    if h == 1:
        return 1 % p
    Nm1 = 1 % p
    Ncur = Pmod(x + 1, p)
    if h == 2:
        return Ncur
    for k in range(2, h):
        y = (x + k) % p
        Nnext = (Pmod(x + k, p) * Ncur - pow(y, 6, p) * Nm1) % p
        Nm1, Ncur = Ncur, Nnext
    return Ncur
