# 2. Atomic rows and global anchors are different notions

Put

\[
\mathcal A_3(X)=\{0\le m<M:K_X(m)=3\}.
\]

Every \(m\in\mathcal A_3(X)\) selects one unordered triple of primes, and contributes exactly \(3!=6\) to \(H_3\). Thus

\[
H_3^{\rm atom}(X)=6|\mathcal A_3(X)|.
\]

If

\[
N_k(X)=\#\{m<M:K_X(m)=k\},
\]

then the exact decomposition is

\[
H_3(X)=6N_3(X)+\sum_{k\ge4}(k)_3N_k(X).
\]

For comparison, since \((k)_3\le(k)_4\) for \(k\ge4\),

\[
H_3(X)\le6N_3(X)+H_4(X).
\]

This explains why the atomic count is a genuine subfrontier, but not the whole of ACF3.

For an unordered pair \(\{p,q\}\),

\[
J_{p,q}=\#(\Omega_p\cap\Omega_q)
\]

and

\[
T_{p,q}
=\sum_{n\in\Omega_p\cap\Omega_q}(K_X(n)-2).
\]

These are **global below-\(M\)** quantities. An atomic row supplies one unit to \(T_{p,q}\) for each of its three unordered anchors, but the same pair may have other representatives below \(M\). Therefore

\[
K_X(m)=3
\quad\not\Longrightarrow\quad
J_{p,q}=T_{p,q}=1
\]

for the three anchors.

# 3. Exact CRT reflection-cube theorem

Let \(p,q,\ell\) be distinct odd primes in \((X,2X]\). Suppose each selected zero orbit is noncentral and write

\[
\{u_p,p-1-u_p\},\quad
\{u_q,q-1-u_q\},\quad
\{u_\ell,\ell-1-u_\ell\}.
\]

For \(\varepsilon=(\varepsilon_p,\varepsilon_q,\varepsilon_\ell)\in\{0,1\}^3\), let \(r_s(0)=u_s\), \(r_s(1)=s-1-u_s\), and let

\[
m_\varepsilon\in[0,P),\qquad P=pq\ell,
\]

be the unique CRT solution

\[
m_\varepsilon\equiv r_s(\varepsilon_s)\pmod s
\quad(s=p,q,\ell).
\]

## Theorem 3.1 — reflection-cube geometry

Assume \(X\ge3\) and put \(M=X^2\).

1. Full reflection satisfies
   \[
   \boxed{m_{1-\varepsilon}=P-1-m_\varepsilon.}
   \]

2. Two distinct sign choices of Hamming distance one cannot both have representatives below \(M\).

3. Two complementary choices of Hamming distance three cannot both have representatives below \(M\).

4. Consequently, if several sign choices land below \(M\), every pair among them differs in exactly two coordinates and there are at most four such choices.

5. Suppose \(\varepsilon\) and \(\varepsilon'\) differ at \(p,q\) and agree at \(\ell\), with both representatives below \(M\). Then
   \[
   \boxed{m_\varepsilon+m_{\varepsilon'}+1=pq,}
   \]
   and
   \[
   \boxed{m_{\varepsilon'}-m_\varepsilon=c\ell,\qquad |c|<X.}
   \]
   The analogous identities hold for the other two choices of unchanged prime.

### Proof

For every modulus \(s\), full reflection changes the residue of \(m\) to \(-1-m\). Hence

\[
m_{1-\varepsilon}\equiv-1-m_\varepsilon\pmod P,
\]

which proves item 1 in the standard interval \([0,P)\).

If two choices differ only at \(p\), their representatives agree modulo \(q\ell\). If both lie in \([0,M)\), their nonzero difference has absolute value less than \(M\), but is divisible by

\[
q\ell>X^2=M,
\]

a contradiction. This proves item 2.

Since \(P>X^3>2X^2=2M\), full complements cannot both lie below \(M\), proving item 3. A subset of the binary cube with no pair at Hamming distance one or three has size at most four; the parity classes attain four. This proves item 4.

For item 5, the two representatives are complementary modulo both \(p\) and \(q\), so

\[
pq\mid m_\varepsilon+m_{\varepsilon'}+1.
\]

The integer on the right lies strictly between 0 and \(2M\), while \(pq>M\). It must therefore equal \(pq\). The representatives agree modulo \(\ell\), so their difference is \(c\ell\), and

\[
|c|<\frac M\ell<X.
\]

This proves the theorem. \(\square\)

## Consequence

Every folded orbit with at least two physical sign landings lies on one of three explicit integer surfaces. This is the strongest automatic reflection geometry available from the physical cutoff. It gives a genuine target for a divisor, resultant, or lattice-point argument.

The remaining sign-simple sector—exactly one sign representative below \(M\)—has no second point from which to form this two-point carrier.

The witness rules out any proof whose mandatory covering step says that every atomic packet must have at least one of the following:

1. a second distinct folded coefficient root in one defining characteristic;
2. a second reflected sign representative below \(X^2\);
3. a repeated quotient digit \(\lfloor m/p\rfloor\);

## Not ruled out

The report does **not** prove or disprove:

- the cubic-density bound \(U_{222}^{(1)}(X)\ll X^{2+o(1)}\lambda_X^3\);
- an extra-density estimate with an unspecified sufficiently large constant or an \(X^{o(1)}\) factor;
- a mixed-characteristic identity attached to a single sign-simple packet;
- a modular-parametric or Cartier theorem controlling these packets in aggregate;
- the full atomic or full ACF3 estimates.

Cardinality two does not by itself prove that the coefficient zero is a simple zero of every auxiliary shell polynomial. The no-go is therefore scoped to methods requiring a second **distinct coefficient root** or a second physical sign landing, not to all possible derivative or discriminant constructions.

# 7. Exact surviving decomposition

Split the atomic ordered mass into three disjoint sectors:

\[
H_3^{\rm atom}(X)=U_X+V_X+R_X,
\]

where

- \(U_X\) is the \((2,2,2)\), sign-simple mass \(U_{222}^{(1)}(X)\);
- \(V_X\) is the \((2,2,2)\) mass with sign occupancy at least two;
- \(R_X\) contains every atomic packet with at least one defining column of cardinality different from two.

Theorem 3.1 gives a real structural reduction for \(V_X\): every pair of sign landings lies on one of

\[
m+m'+1=pq,\qquad m'-m=c\ell,\qquad |c|<X,
\]

and its permutations. The sector \(R_X\) has internal zero-set structure unavailable in \(U_X\).

The exact residual theorem isolated here is

\[
\tag{ATUP3}
U_X\ll X^{2+o(1)}\lambda_X^3.
\]

This is demonstrably smaller than atomic ACF3: it excludes every rich-column packet and every reflection-paired sign orbit. The \(X=256\) witness proves that this residual is nonempty and cannot be deleted by an automatic extra-density or pairing argument.

A future proof of `(ATUP3)` must control a unique short-prefix CRT landing for three different defining characteristics of the same Apéry sequence. The authoritative inputs supply exact enumeration and reflection, but no adelic discrepancy theorem of this form.

# 8. Standalone exact verifier

The following standard-library script independently checks both Apéry recurrences, reflection, the complete \(X=256\) bank, the atomic classification, the anchor normalization failure, the eight CRT representatives, and the strict rational failure of `(AG4)`. It uses no floating point.

```python
#!/usr/bin/env python3
from fractions import Fraction
from itertools import combinations, product
from math import isqrt, prod


def primes_upto(limit: int) -> list[int]:
    sieve = bytearray(b"\x01") * (limit + 1)
    sieve[0:2] = b"\x00\x00"
    for d in range(2, isqrt(limit) + 1):
        if sieve[d]:
            start = d * d
            sieve[start : limit + 1 : d] = b"\x00" * (
                (limit - start) // d + 1
            )
    return [n for n in range(2, limit + 1) if sieve[n]]


def P(n: int) -> int:
    return 34 * n**3 + 51 * n**2 + 27 * n + 5


def zeros_divided(p: int) -> tuple[int, ...]:
    values = [1 % p, 5 % p]
    for n in range(1, p - 1):
        numerator = (P(n) * values[n] - n**3 * values[n - 1]) % p
        denominator = pow(n + 1, 3, p)
        values.append(numerator * pow(denominator, -1, p) % p)
    return tuple(i for i, value in enumerate(values) if value == 0)


def zeros_cleared(p: int) -> tuple[int, ...]:
    previous, current = 1 % p, 5 % p
    out: list[int] = []
    if previous == 0:
        out.append(0)
    if current == 0:
        out.append(1)
    for n in range(1, p - 1):
        following = (P(n) * current - pow(n, 6, p) * previous) % p
        previous, current = current, following
        if current == 0:
            out.append(n + 1)
    return tuple(out)


def crt_pair(a: int, p: int, b: int, q: int) -> int:
    return a + p * (((b - a) * pow(p, -1, q)) % q)


def crt_three(residues: tuple[int, int, int], moduli: tuple[int, int, int]) -> int:
    a, b, c = residues
    p, q, ell = moduli
    x = crt_pair(a, p, b, q)
    pq = p * q
    return x + pq * (((c - x) * pow(pq, -1, ell)) % ell)
```
