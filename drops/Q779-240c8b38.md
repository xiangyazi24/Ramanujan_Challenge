# Hostile audit of LGTQ-3 versus LGTQ-MTD

## Verdict

The Opus synthesis claim is too strong. The banked logic proves only:

```
LGTQ-3 => all-index Apéry gcd goal.
```

It does not prove that the full conjectural route is equivalent to LGTQ-3, and the proposed LGTQ-MTD condition is not automatically equivalent to LGTQ-3. The two quantities differ by mixed terms and by the choice of carrier.

The correct relationship is:

* LGTQ-3 is a centered or uncentered count of fully transverse prime triples with three simultaneous Apéry divisibility conditions.
* LGTQ-MTD is a discrepancy statement for a product of lower-dimensional indicators. It can imply LGTQ-3 only if all mixed correlation terms are controlled.
* Without those mixed terms, LGTQ-MTD is either insufficient or stronger than needed, depending on the exact centering.

---

# 1. Exact LGTQ-3 definition

Fix q. For n in a dyadic interval and gaps h1,h2 <= C log n, write

```
p1 = p,
p2 = p+h1,
p3 = p+h1+h2.
```

All three primes must lie in the fixed-q boundary interval

```
n/(q+1) < pi <= n/q.
```

The fully transverse condition is that the three characteristics are distinct and the Apéry target residues are distinct after the fixed-q reduction. For each pi there is an affine residue target

```
ri(n) = alpha_q(n) + beta_q(n) * pi mod pi,
```

(or the equivalent Lucas/reflection branch representative). Define

```
Xi(pi,n)=1_{b_n = 0 mod pi at the prescribed target residue}.
```

Then LGTQ-3 has the form

```
max_{h1,h2 <= C log n}
 sum_n sum_p Xi(p,n)Xi(p+h1,n)Xi(p+h1+h2,n)
```

with the restrictions above and target scale below the main term.

The parameter summed over is therefore the starting prime p and the outer integer n. The gaps are not averaged away: the maximum over gap vectors is part of the statement.

---

# 2. Centered expansion

Suppose MTD uses centered variables

```
Yi(p,n)=Xi(pi,n)-mu(pi,n).
```

The triple product expands as

```
E[Y1Y2Y3]
=
E[X1X2X3]
-mu3 E[X1X2]
-mu2 E[X1X3]
-mu1 E[X2X3]
+mu2mu3 E[X1]
+mu1mu3 E[X2]
+mu1mu2 E[X3]
-mu1mu2mu3.
```

Therefore a bound on the centered triple is not the same as a bound on

```
E[X1X2X3].
```

The mixed pair terms are not negligible automatically. They are exactly the pair energies that remain uncontrolled in the fixed-q problem.

Hence:

```
MTD => LGTQ-3
```
requires separate pair-discrepancy estimates.

Conversely,

```
LGTQ-3 => MTD
```
is false in general because triple control does not imply pair cancellation.

---

# 3. Explicit countermodel

Take a model where for every prime p the indicator Xi(p,n) is generated by a hidden pair variable:

```
Xi(p,n)=A(n)B(p).
```

Choose A so that triples are rare because most n have A(n)=0, but choose B so that when A(n)=1 all primes in a short block fire together.

Then the triple count can satisfy a strong LGTQ-3 bound after choosing the active n set sparse enough, while pair correlations remain large.

The model preserves the formal shape:

* each characteristic has an affine target indicator;
* reflection branches can be imposed by defining paired variables symmetrically;
* dyadic nonvanishing of the underlying rational jet can be imposed independently because indicators only encode divisibility events.

Therefore the formal reductions do not force MTD from LGTQ-3.

# 4. The weakest useful aggregate statement

A strictly weaker sufficient statement than LGTQ-3 is not a pointwise maximum over gaps. The natural candidate is the averaged centered residual:

For every fixed q and every C,

```
Σ_{N<n<=2N}
Σ_{h1,h2<=C log N}
| Σ_p (Xi(p,n)-mu_p)
              (Xi(p+h1,n)-mu_{p+h1})
              (Xi(p+h1+h2,n)-mu_{p+h1+h2}) |
=o(N^2/log^2 N).
```

This is weaker because:

* no maximum over gap vectors;
* cancellation between different gaps is allowed;
* only the aggregate contribution needed for the energy argument is controlled.

It is still stronger than a cardinality estimate and directly targets the missing moving-target correlations.

---

# 5. Apéry-specific recurrence check

The order-two recurrence helps propagate a finite set of divisibility conditions, but it does not remove the missing mixed terms. A recurrence packet of fixed primes saturates to the product of those primes; it gives no saving against the number of possible moving target locations.

The first-jet formulas provide affine lifts, but the affine terms live in different characteristics. They identify the target residues; they do not provide independence between different primes.

Thus the recurrence can support a proof of LGTQ-3, but it cannot turn LGTQ-3 into MTD without an additional cross-characteristic correlation estimate.

---

# 6. Quantifier audit

The required hierarchy is:

```
Aggregate centered triple residual
        |
        v
LGTQ-3 (uniform maximum over O(log n)^2 gaps)
        |
        v
all-index gcd goal.
```

The reverse arrows are not established.

The exact missing arithmetic statement is a moving-target discrepancy estimate controlling mixed pair and triple correlations of affine Apéry residue events across nearby primes. It is not implied by root-count size, Poisson heuristics, or recurrence elimination.

Therefore the corrected conclusion is: LGTQ-MTD is a possible sufficient strengthening, not an equivalent reformulation of LGTQ-3.
