# Q5913 finite Rogers certificate audit

## Summary

The endpoint relations strongly resemble a positive Y-system, but the data given do not by themselves identify a standard finite Dynkin-type Y-system. The correct certificate target is not numerical equality of regulators but a finite relation in the pre-Bloch group.

Let

```
a^2=b^2(1-a)
c=b^2(1-d)
c=b*d*(1-a)*(1-b)*(1-c)
X=c/b
L=c^2*(1-c)/(b^3*d)
X=L^4
```

The first two relations give useful eliminations:

```
a = 1 - a^2/b^2
c/b = b(1-d)
```

and hence the multiplicative variables are generated by a rank-two unit system. This is consistent with a Y-system style parametrization, but it is not enough to claim a cluster realization.

## Candidate Y-system test

A genuine finite Rogers Y-system would require variables satisfying equations of the form

```
Y_i(t+1)Y_i(t-1)=prod_j (1+Y_j(t))^{B_ij}
```

with a finite Cartan matrix. The present equations only provide four static variables and one fourth-power relation. Solving for logarithms gives linear relations among

```
log a, log b, log c, log d, log(1-a), log(1-b), log(1-c), log(1-d)
```

but no finite mutation pattern is forced.

## What an exact certificate must prove

The desired statement

```
R(a)+R(b)+R(c)+R(d)=pi^2/10
```

can be obtained from

```
5([a]+[b]+[c]+[d])-3[1]=0
```

in the appropriate pre-Bloch quotient, together with

```
R(1)=pi^2/6.
```

A Rogers-only certificate can also work if the difference lies in the kernel of the real Rogers regulator, but that requires proving the kernel contribution is zero.

## Computable obstruction

The practical invariant is the image in the Bloch group quotient. Compute the class of

```
T = 5([a]+[b]+[c]+[d])-3[1]
```

inside the finite presentation generated by all conjugates of the endpoint field.

If its Smith normal form has a nonzero cokernel coordinate, then no pure Abel-five-term/complement certificate exists in that presentation.

The regulator vanishing alone is insufficient because torsion classes can have zero real Rogers value.

## Exact search design

Use the number field K containing a,b,c,d. Generate PGL2 orbit elements

```
(z,1-z,1/z,1/(1-z),z/(z-1),(z-1)/z)
```

and apply the alternating five term relation

```
[x]-[y]+[y/x]-[(1-1/x)/(1-1/y)]+[(1-x)/(1-y)]
```

with exact field arithmetic.

Store every relation as an integer vector over the generator basis. Solve

```
A*c = T
```

using exact Smith normal form.

## Expected outcome

A successful result is a finite vector c. A failure is not a proof that the Rogers identity is false; it proves only that the selected orbit span misses T. The next invariant is the exact residual class in the computed quotient.

## Lean boundary

The Lean certificate should contain:

1. the finite list of generators;
2. the finite list of five-term relations;
3. an integer coefficient vector;
4. a normalization theorem reducing complements to [1];
5. the final Rogers evaluation theorem.

Do not formalize the search. Formalize replay of the finite certificate.
