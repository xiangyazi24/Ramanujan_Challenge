# Q8688 Apéry quotient-one reduction audit

## Verdict

The reduction is mostly correct at the combinatorial level, with two corrections:

1. The constant in (i) comes from an exact ordered-triple count; the endpoint convention must use positive gaps \(0<a<b\le 2X-4\).
2. The bound in (ii) has the stated forward implication, but the converse as written has the wrong scale: \(K=o(X/\log^3 X)\) is sufficient, but not the converse of the implication. It is a stronger hypothesis, not an equivalent condition.

The top-quarter bound \(K=o(X/\log X)\) is a route-level arithmetic subproblem for this EPC3 argument, not a logically necessary consequence of the original gcd conjecture.

## (i) Triple-count constant

Let

\[
H_X\subset (3X/2,2X-2]\cap \mathbb P,
\qquad |H_X|=K.
\]

Every ordered triple of distinct primes

\[
(p,q,r)\in H_X^3
\]

with \(p,q,r\) distinct determines a translated pattern after ordering the three values:

\[
p_0<p_1<p_2.
\]

Write

\[
a=p_1-p_0,
\qquad b=p_2-p_0.
\]

Then

\[
0<a<b,
\]

and \(p_0,p_0+a,p_0+b\in H_X\), so it contributes to \(J_X(a,b)\).

The interval length is

\[
(2X-2)-(3X/2)=X/2-2.
\]

For fixed \(a,b\), the possible starting primes satisfy

\[
3X/2<p\le 2X-2-b,
\]

so all admissible gaps satisfy

\[
1\le a<b\le X/2-3.
\]

There are exactly

\[
\binom K3
\]

unordered triples and each contributes to exactly one gap pair \((a,b)\). Hence

\[
\sum_{0<a<b}J_X(a,b)=\binom K3.
\]

The number of possible pairs is bounded by

\[
\binom{X/2-3}{2}<\frac{X^2}{8}.
\]

Therefore

\[
\max_{a,b}J_X(a,b)
\ge
\frac{\binom K3}{X^2/8}
=
\frac{8K(K-1)(K-2)}{6X^2}
=
\frac{4}{3}\frac{K(K-1)(K-2)}{X^2}.
\]

Thus the claimed constant

\[
\frac{16}{3}
\]

is not the sharp constant under this endpoint convention. It is a valid weaker/stronger? comparison only if a smaller denominator estimate is justified. With the literal interval above, the direct count gives \(4/3\), not \(16/3\).

The discrepancy is a factor \(4\), coming from whether one counts the available translation range as length \(X/2\) or rescales by the shell normalization. The exact statement requires fixing that convention.

## (ii) Little-o algebra

Suppose

\[
M_X:=\max_{a,b}J_X(a,b)=o(X/\log^3X).
\]

From (i), using the valid constant \(c>0\),

\[
\frac{K^3}{X^2}\ll M_X.
\]

Hence

\[
K^3=o(X^3/\log^3X),
\]

and therefore

\[
K=o(X/\log X).
\]

So the forward implication is correct.

Conversely,

\[
K=o(X/\log^3X)
\]

implies

\[
\frac{K^3}{X^2}
=o(X/\log^9X),
\]

which is certainly

\[
o(X/\log^3X).
\]

Thus the stated converse is only a sufficient condition. The equivalent threshold would be

\[
K=o(X/\log X),
\]

not \(o(X/\log^3X)\).

## (iii) Logical role of the quotient-one reduction

Lucas gives

\[
B_{p+u}\equiv B_pB_u\pmod p.
\]

Using

\[
B_p\equiv5\pmod p,
\]

one gets

\[
B_{p+u}\equiv5B_u\pmod p.
\]

For quotient one, \(m=p+u\) with \(p>m/2\) gives \(u=m-p\), so

\[
p\mid B_u
\Longleftrightarrow
p\mid B_m.
\]

Therefore quotient-one shell hits on the row \(m\) are exactly controlled by primes dividing \(B_m\).

However, the implication is only:

\[
\text{gcd proof}\Longrightarrow\text{certain quotient-one bounds may be useful},
\]

not

\[
\text{gcd proof}\Longrightarrow K=o(X/\log X).
\]

The top-quarter bound is required because this particular majority/EPC3 argument needs to control many quotient-one hits on a fixed row. Another proof of the gcd conjecture could avoid this sector.

Hence it is a route necessity, not a theorem-level arithmetic necessity.

## (iv) Selberg upper bound role

A bound of the form

\[
J_X(a,b)\le (24+o(1))S(a,b)X/\log^3X
\]

with

\[
S(a,b)\ll(\log\log X)^2
\]

is an upper bound on each fixed gap fibre.

It is not used in:

- the triple-count lower bound in (i);
- the algebra converting \(J=o(X/\log^3X)\) into \(K=o(X/\log X)\) in (ii);
- the logical distinction in (iii).

It only supplies an external estimate for the size of the obstruction fibres. To combine with (i), it would need an additional argument controlling the singular series uniformly or showing that the maximum fibre is sufficiently small.

## Final corrected theorem-level statement

The exact combinatorial identity is

\[
\sum_{0<a<b}J_X(a,b)=\binom K3,
\]

with the number of possible gap pairs determined by the shell interval length. Under the literal interval \((3X/2,2X-2]\), the resulting constant is \(4/3\), not \(16/3\).

The implication

\[
\max J_X=o(X/\log^3X)
\implies
K=o(X/\log X)
\]

is valid. The condition \(K=o(X/\log^3X)\) is merely a stronger sufficient hypothesis.

The quotient-one Lucas reduction identifies the relevant EPC3 input but does not make it a logically necessary subproblem of the full Apéry gcd conjecture. The Selberg estimate is ancillary: it does not carry the reductions (i)-(iii).
