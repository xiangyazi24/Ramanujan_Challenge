# Finite-field Mellin / trace-function route for the all-index Apéry target radical

## Verdict

There **is** an exact bounded-complexity trace-function realization of the interior Apéry coefficient condition, but I do **not** find a currently available Katz/Fouvry--Kowalski--Michel/large-sieve theorem that converts it into the required pointwise prime saving.

The exact positive statement is this.  Let

\[
\Lambda(x,y,z)
=\frac{(1+x)(1+y)(1+z)\bigl((1+y)(1+z)+xyz\bigr)}{xyz}.
\tag{V1}
\]

The repository proves

\[
b_m=\operatorname{CT}\Lambda^m.
\tag{V2}
\]

For every prime \(p\ge5\) and every interior index \(1\le r\le p-2\), if

\[
\mu_p(a)=\#\{(x,y,z)\in(\mathbf F_p^\times)^3:\Lambda(x,y,z)=a\},
\]

then

\[
\boxed{
 b_r\equiv-\sum_{a\in\mathbf F_p^\times}\mu_p(a)a^r\pmod p.
}
\tag{V3}
\]

The fixed toric family \(\Lambda=a\) has a K3 compactification.  After removing the explicit Tate divisor classes, the repository constructs a generic rank-three weight-two primitive trace \(\theta_p(a)\) satisfying

\[
\boxed{
\mu_p(a)=p^2-6p+12+\theta_p(a)
}
\tag{V4}
\]

for every \(a\ne0\), with the two special loci \(a=1\) and \(a^2-34a+1=0\) handled explicitly.  On the quadratic cover

\[
8x^2+(a-1)x+a=0,
\tag{V5}
\]

this primitive rank-three object is obtained from the explicit elliptic family

\[
E_x:\quad Y^2+(1-2x)XY+x^2Y=X^3
\tag{V6}
\]

by the symmetric-square / Asai construction, with the exact \(-3\) twist and one Tate line removed.  Thus this is not a generic-monodromy guess: it is an explicitly identified \(\ell\)-adic geometric trace object.

For a multiplicative character \(\chi\) of \(\mathbf F_p^\times\), let \(\mathcal L_\chi\) be the Kummer sheaf.  The generic primitive K3 sheaf \(\mathcal T_\ell\) has fixed rank and a fixed finite singular locus, and \(\mathcal L_\chi\) is rank one and tame at \(0,\infty\).  Therefore

\[
\boxed{
\operatorname{cond}(\mathcal T_\ell\otimes\mathcal L_\chi)\le C_\Lambda
}
\tag{V7}
\]

with an absolute constant independent of \(p\) and of the order of \(\chi\).  This is exactly the bounded-conductor feature one would want.

Now choose a prime \(\mathfrak p_p\) of \(\mathbf Q(\mu_{p-1})\) above \(p\) and a Teichmüller/fundamental character \(\omega_p:\mathbf F_p^\times\to\mu_{p-1}\) whose reduction modulo \(\mathfrak p_p\) is \(a\mapsto a\).  Define the cyclotomic Mellin trace

\[
\mathfrak M_p(m)
:=\sum_{a\in\mathbf F_p^\times}\theta_p(a)\omega_p(a)^m.
\tag{V8}
\]

For \(m\not\equiv0\pmod{p-1}\), the constant term in (V4) has zero character sum, so \(\mathfrak M_p(m)\) is exactly the compactly-supported Frobenius trace of the fixed primitive K3 system twisted by \(\mathcal L_{\omega_p^m}\), up to the fixed punctual corrections at the explicitly known exceptional fibers.  Reducing modulo \(\mathfrak p_p\) and using (V3) gives

\[
\boxed{
\mathfrak M_p(m)\equiv-b_r\pmod{\mathfrak p_p}
\qquad(m\equiv r\pmod{p-1},\ 1\le r\le p-2).
}
\tag{V9}
\]

This is the desired exact \(\ell\)-adic Mellin representation.

The crucial all-index simplification is also exact.  If

\[
n=qp+r,\qquad 0\le r<p,
\]

then on \(\mathbf F_p^\times\)

\[
r\equiv n-q\pmod{p-1}.
\tag{V10}
\]

Hence, within one quotient class \(q=\lfloor n/p\rfloor\), the Kummer exponent is the **fixed integer**

\[
m=n-q,
\tag{V11}
\]

although the prime \(p\) varies.  In particular, in the top half \(n/2<p\le n\), one has \(q=1\), \(r=n-p\), and

\[
\boxed{
 p\mid b_{n-p}
\iff
\mathfrak M_p(n-1)\equiv0\pmod{\mathfrak p_p}.
}
\tag{V12}
\]

This is the cleanest formulation of the horizontal Mellin route.

What fails is the next step.  The character \(\omega_p^{\,m}\) has order

\[
\frac{p-1}{\gcd(m,p-1)},
\tag{V13}
\]

which usually grows with \(p\).  Thus the **underlying K3 system is compatible as \(p\) varies, but the prescribed Kummer twists are not a fixed compatible system**.  Moreover the bad event in (V9) is divisibility by the **defining characteristic itself**.  The standard large sieves for trace functions use a fixed defining finite field and average geometric arguments, or use auxiliary residual primes \(\lambda\ne p\) in a fixed compatible system.  They do not sieve the condition

\[
\mathfrak p_p\mid\mathfrak M_p(m)
\]

with both the defining characteristic and the Kummer character moving.

So the correct status is:

- **THEOREM:** exact bounded-conductor K3/elliptic-Asai Mellin representation (V8)--(V12).
- **THEOREM:** ordinary one-prime Deligne bounds, and the existing fixed-modulus trace-function large sieves, do not by themselves imply the defining-characteristic zero event.
- **LITERATURE NO-GO, scoped:** none of the named Katz/FKM/FKMS/large-sieve-for-Frobenius theorems I could verify has the quantifiers needed for (V12).
- **CONDITIONAL:** a parabolic defining-characteristic Mellin sieve with any fixed power saving immediately proves the all-index Apéry target radical.
- **CONCRETE NEXT LEMMA:** prove the top-half horizontal Mellin sieve (THMS) stated in §7.  It is already sufficient for the full conjecture; the bounded-quotient version is its natural robust extension.

# 1. Exact Mellin formula I: the fixed toric Laurent polynomial

The repository's fixed Laurent polynomial is

\[
\boxed{
\Lambda(x,y,z)
=\frac{(1+x)(1+y)(1+z)((1+y)(1+z)+xyz)}{xyz}.
}
\tag{1.1}
\]

Every exponent vector of \(\Lambda\) lies in \([-1,1]^3\), and exact expansion gives

\[
\boxed{b_m=\operatorname{CT}_{x,y,z}\Lambda(x,y,z)^m.}
\tag{1.2}
\]

For a prime \(p\) and integer \(M\), finite-torus orthogonality says

\[
\sum_{(x,y,z)\in(\mathbf F_p^\times)^3}
 x^{e_1}y^{e_2}z^{e_3}
=
\begin{cases}
(-1)^3,&p-1\mid e_1,e_2,e_3,\\
0,&\text{otherwise}
\end{cases}
\pmod p.
\tag{1.3}
\]

If \(1\le r\le p-2\) and

\[
M=A(p-1)+r,
\tag{1.4}
\]

then the repository's exact fixed-moment check gives

\[
\boxed{
 b_r\equiv
-\sum_{(x,y,z)\in(\mathbf F_p^\times)^3}\Lambda(x,y,z)^M
\pmod p.
}
\tag{1.5}
\]

Grouping by the value \(a=\Lambda(x,y,z)\) gives (V3):

\[
 b_r\equiv-\sum_{a\ne0}\mu_p(a)a^M
=-\sum_{a\ne0}\mu_p(a)a^r\pmod p.
\tag{1.6}
\]

For the all-index decomposition \(n=qp+r\), take

\[
M=n-q=q(p-1)+r.
\tag{1.7}
\]

Therefore

\[
\boxed{
 b_r\equiv-\sum_{(x,y,z)\in(\mathbf F_p^\times)^3}
 \Lambda(x,y,z)^{\,n-q}\pmod p.
}
\tag{1.8}
\]

The point of (1.8) is that **the exponent \(n-q\) is constant as \(p\) varies inside the quotient cell \(q=\lfloor n/p\rfloor\)**.  This is stronger than merely writing \(r=n\bmod p\).

There is, however, a tradeoff.  Treating \(\Lambda^{\,n-q}\) as an algebraic function gives degree/complexity growing with \(n\).  The bounded-conductor reformulation is obtained by moving the exponent into a Kummer character; that keeps local conductor bounded but makes the character itself vary with \(p\).  This tradeoff is the central seam of the route.

# 2. Exact Mellin formula II: the Hasse value vector

Let

\[
A_p(t)=\sum_{m=0}^{p-1}b_mt^m\in\mathbf F_p[t].
\tag{2.1}
\]

For \(1\le r\le p-2\), multiplicative orthogonality on \(\mathbf F_p^\times\) gives immediately

\[
\begin{aligned}
\sum_{t\ne0}A_p(t)t^{-r}
&=\sum_{m=0}^{p-1}b_m\sum_{t\ne0}t^{m-r}\\
&=-b_r,
\end{aligned}
\]

hence

\[
\boxed{
 b_r=-\sum_{t\in\mathbf F_p^\times}A_p(t)t^{-r}.
}
\tag{2.2}
\]

This is a coefficient/Mellin statement.  It is **not** the assertion that the geometric fiber at \(t=r\) is nonordinary.

The CFVZ square factorization used in the project is

\[
A_p(t)=\Delta(t)^{\varepsilon_p}B_p(t)^2,
\qquad
\Delta(t)=t^2-34t+1,
\tag{2.3}
\]

with

\[
\varepsilon_p=\frac{1-\left(\frac{-6}{p}\right)}2.
\tag{2.4}
\]

The normalized \(B_p\) is a truncation of one of two fixed characteristic-zero series satisfying the two fixed second-order operators

\[
L_+=4\vartheta^2
 -2t(68\vartheta^2+34\vartheta+5)+t^2(2\vartheta+1)^2,
\tag{2.5}
\]

\[
L_-=4\vartheta^2
 -2t(68\vartheta^2+102\vartheta+39)+t^2(2\vartheta+3)^2.
\tag{2.6}
\]

This gives a rank-two finite-field hypergeometric-looking cover, but it still does not turn the **coefficient** event \(b_r=0\) into a fiberwise Hasse event.  The exact trace-sheaf lift in §3 is cleaner because it keeps the coefficient as a genuine Mellin transform.

## Endpoints

The character \(r=0\) is trivial, and \(r=p-1\) is the same multiplicative character.  Therefore the \(\mathbf F_p^\times\) Mellin transform cannot distinguish the two endpoint coefficients.  Indeed

\[
\sum_{t\ne0}A_p(t)=-(b_0+b_{p-1})=-2\pmod p,

using the project reflection \(b_{p-1}\equiv b_0=1\pmod p\).  Thus neither endpoint is a target.  All nontrivial target work may, and below does, restrict to

The finitely many small primes \(2,3,5\) may likewise be removed from every asymptotic statement.

The displayed boundary and exceptional curves contain a Frobenius-stable Tate subspace of dimension \(19\) generically, with one further algebraic class at \(a=1\) or \(\Delta(a)=0\).

U=\mathbf G_m\setminus\{1,\ \Delta=0\}.

For a fixed auxiliary prime \(\ell\ne p\), let

\[
\mathscr H_\ell=R^2\pi_*\mathbf Q_\ell

\operatorname{Tr}(\operatorname{Frob}_a\mid\mathscr T_{\ell,\bar a})

## 3.2 Conductor after the moving Kummer twist

Let \(\chi:\mathbf F_p^\times\to\overline{\mathbf Q}_\ell^\times\) be nontrivial.  Its Kummer sheaf \(\mathcal L_\chi\) is rank one, lisse on \(\mathbf G_m\), tame at \(0\) and \(\infty\).  In the conductor convention used by Fouvry--Kowalski--Michel,

\[
\operatorname{cond}(\mathcal F)
=\operatorname{rank}(\mathcal F)
 +\#\operatorname{Sing}(\mathcal F)
 +\sum_x\operatorname{Swan}_x(\mathcal F).
\tag{3.10}
\]

The primitive K3 family is fixed over \(\mathbf Z[1/6]\), and its generic singular parameters lie among

\[
0,\infty,1,\quad \Delta(a)=0,
\tag{3.11}
\]

a fixed set of at most five geometric points.  Twisting by a tame rank-one Kummer sheaf adds at most \(0,\infty\) to the singular set and does not add wild Swan conductor.  Hence there is an absolute constant \(C_\Lambda\) such that

\[
\boxed{
\operatorname{cond}(\mathscr T_\ell\otimes\mathcal L_\chi)
\le C_\Lambda
}
\tag{3.12}
\]

for all good \(p\), all \(\ell\ne p\), and all nontrivial \(\chi\), independently of \(\operatorname{ord}(\chi)\).

This part of the proposed route is therefore genuinely positive: the moving exponent does **not** force conductor growth when it is encoded as a Kummer character.

# 4. Cyclotomic Mellin trace and reduction to \(b_r\)

Fix a generator-compatible prime ideal

\[
\mathfrak p_p\subset\mathbf Z[\mu_{p-1}]
\]

above \(p\), so that reduction gives an isomorphism

\[
\mu_{p-1}\longrightarrow\mathbf F_p^\times.
\tag{4.1}
\]

Let \(\omega_p\) be the corresponding Teichmüller character.  For \(m\not\equiv0\pmod{p-1}\), put

\[
\mathfrak M_p(m)
=\sum_{a\ne0}\theta_p(a)\omega_p(a)^m.
\tag{4.2}
\]

Since a nontrivial multiplicative character sums to zero,

\[
\sum_{a\ne0}(p^2-6p+12)\omega_p(a)^m=0
\tag{4.3}
\]

**as a cyclotomic integer**, not merely modulo \(p\).  Therefore

\[
\boxed{
\mathfrak M_p(m)
=\sum_{a\ne0}\mu_p(a)\omega_p(a)^m.
}
\tag{4.4}
\]

Grothendieck--Lefschetz gives the \(\ell\)-adic form

\[
\mathfrak M_p(m)
=
\sum_i(-1)^i
\operatorname{Tr}\!\left(
\operatorname{Frob}_p\mid
H_c^i(U_{\overline{\mathbf F}_p},
\mathscr T_\ell\otimes\mathcal L_{\omega_p^m})
\right)
+E_p(m),
\tag{4.5}
\]

where \(E_p(m)\) is the explicit bounded-complexity punctual contribution from \(a=1\) and the branch points; equivalently one may absorb it into a fixed constructible middle-extension complex.

Reduction modulo \(\mathfrak p_p\) sends \(\omega_p(a)^m\) to \(a^m\).  Thus (1.6) yields

\[
\boxed{
\mathfrak M_p(m)\equiv-b_r\pmod{\mathfrak p_p}
\quad\text{whenever}\quad
m\equiv r\pmod{p-1},\quad1\le r\le p-2.
}
\tag{4.6}
\]

This is the exact sheaf-theoretic target condition.

## 4.1 Fixed exponent on a quotient cell

For fixed \(n\), write

\[
n=qp+r,\qquad q=\lfloor n/p\rfloor.
\tag{4.7}
\]

Because \(p\equiv1\pmod{p-1}\),

\[
r=n-qp\equiv n-q\pmod{p-1}.
\tag{4.8}
\]

Therefore throughout the cell

\[
I_{n,q}:=\left(\frac n{q+1},\frac nq\right]
\tag{4.9}
\]

the same integer

\[
\boxed{m=n-q}
\tag{4.10}
\]

may be used in (4.6).  This is the precise sense in which the horizontal twist is fixed as \(p\) varies.

In the top half, \(q=1\), so

\[
\boxed{
 p\in(n/2,n],\quad r=n-p
\quad\Longrightarrow\quad
p\mid b_r
\iff
\mathfrak p_p\mid\mathfrak M_p(n-1).
}
\tag{4.11}
\]

For the Hasse-value representation (2.2), the corresponding fixed exponent is \(1-n\):

\[
b_{n-p}
=-\sum_{t\ne0}A_p(t)t^{1-n}.
\tag{4.12}
\]

# 5. What Deligne gives, and why it is not the requested theorem

After Tate-normalizing the weight-two primitive system, standard Deligne estimates give square-root cancellation in the **complete Mellin sum**, provided the twist has no geometric invariant quotient.  In unnormalized form this has the shape

\[
\boxed{
|\iota\mathfrak M_p(m)|\ll_{C_\Lambda}p^{3/2}
}
\tag{5.1}
\]

for every complex embedding \(\iota\), apart from any explicitly classifiable exceptional twists.  The fixed elliptic/Asai description reduces verification of the needed irreducibility/no-Kummer-constituent hypothesis to a concrete local-monodromy calculation; I do not need that calculation for the no-go below, because even granting the optimal bound (5.1) does not solve the problem.

The target is

\[
\mathfrak M_p(m)\in\mathfrak p_p,
\tag{5.2}
\]

not

\[
|\mathfrak M_p(m)|\text{ small}.
\]

A number of size \(O(p^{3/2})\) may be divisible by \(p\) with no contradiction.  Worse, \(\mathfrak M_p(m)\) generally lies in the cyclotomic field of the character \(\omega_p^m\), whose degree can grow with \(p\).  An archimedean norm argument therefore loses exactly where a defining-characteristic congruence is needed.

There is also a normalization seam: analytic trace-function theorems normally Tate-twist the rank-three system to weight zero, effectively dividing its eigenvalues by \(p\).  That is harmless over \(\overline{\mathbf Q}_\ell\), \(\ell\ne p\), but it is not an integral operation at the prime \(\mathfrak p_p\) whose divisibility is being tested.

Thus ordinary Deligne bounds are the correct one-prime analytic statement and still miss the arithmetic event.

# 6. Audit of the named large-sieve / trace-function theorems

## 6.1 Fouvry--Kowalski--Michel: trace functions over primes

[Fouvry--Kowalski--Michel, *Algebraic trace functions over the primes*, arXiv:1211.6043, Theorem 1.5](https://arxiv.org/abs/1211.6043) fixes a prime modulus \(p\), an isotypic nonexceptional trace sheaf \(\mathcal F/\mathbf F_p\), and estimates

\[
\sum_{q\ \mathrm{prime}}K(q)V(q/X)
\ll QX(1+p/X)^{1/6}p^{-\eta},
\qquad \eta<1/24,
\tag{6.1}
\]

with polynomial dependence on the conductor.  The result is nontrivial for bounded conductor when roughly \(X\ge p^{3/4+\varepsilon}\).

This theorem is extremely relevant to the **local complexity** point: the same paper records that Kummer sheaves are rank one and tame, and Corollary 1.12 treats multiplicative characters of arbitrary order with conductor controlled by the rational function rather than the character order.

But its quantifiers are wrong for (4.11).  In (6.1):

- \(p\) is one fixed defining modulus;
- the rational primes \(q\) are **arguments of one function on \(\mathbf F_p\)**.

In (4.11), by contrast, the rational prime \(p\) itself is the defining characteristic, and both the residue field and the prescribed Kummer character change at every term.  There is no substitution that turns (4.11) into Theorem 1.5.

## 6.2 Fouvry--Kowalski--Michel--Sawin 2026 bilinear theorem

The current version I checked is
[Fouvry--Kowalski--Michel--Sawin, *Bilinear forms with trace functions*, arXiv:2511.09459v3, revised 11 March 2026](https://arxiv.org/abs/2511.09459).
Its simplified Theorem 1.1 assumes a trace sheaf \(\mathscr F\) over **one fixed** \(\mathbf F_q\), with irreducible geometric monodromy whose identity component is simple (or finite quasisimple), and for

\[
q^\delta\le M,\qquad MN\ge q^{3/4+\delta}
\tag{6.2}
\]

gives a power saving for

\[
\sum_{m\sim M}\sum_{n\sim N}\alpha_m\beta_nK(m^bn^c).
\tag{6.3}
\]

The general Theorem 1.3 is likewise stated for a gallant/light \(\ell\)-adic sheaf over a **fixed prime field \(\mathbf F_q\)**.  Version 3 explicitly adds stability results under rank-one twists, which is useful for \(\mathscr T\otimes\mathcal L_\chi\) at one prime.

It still does not correlate the collection

\[
\left\{
\mathscr T_p\otimes\mathcal L_{\omega_p^{\,m}}
:\ p\in(P,2P]
\right\}
\tag{6.4}
\]

across defining characteristics.  The rank-one-twist stability is a **within-one-\(q\)** theorem, not a horizontal defining-characteristic sieve.

## 6.3 Perret-Gentil / large sieve for Frobenius

[Perret-Gentil, *Exponential sums over finite fields and the large sieve*, arXiv:1703.06965; IMRN 2020](https://arxiv.org/abs/1703.06965) uses a variant of Kowalski's large sieve for Frobenius in a coherent compatible system.  Its zero-density variable is a geometric argument

\[
x\in\mathbf F_q,
\tag{6.5}
\]

and the sieve reductions are at **auxiliary primes \(\lambda\)** of a coefficient field, distinct from the defining characteristic.  For Kloosterman sums, Proposition 1.1 obtains zero-density as \(q=p^e\to\infty\) under explicit lower bounds on \(e\); the paper notes that uniformity in \(p\) requires integral monodromy input.

This is not (4.11) for two independent reasons:

1. our variable is the prescribed point of the **character group** \(\widehat{\mathbf F_p^\times}\), not a geometric point \(x\in\mathbf F_p\);
2. our bad reduction prime is exactly \(\mathfrak p_p\mid p\), the defining characteristic, whereas the \(\ell\)-adic compatible-system sieve uses \(\lambda\ne p\).

The rank-three K3 system itself is compatible, but the twists \(\omega_p^{\,m}\) are not reductions of one fixed finite-order global character.

## 6.4 Kowalski and Zywina: sieve for Frobenius / Galois representations

Kowalski's large sieve for Frobenius averages Frobenius conjugacy classes of a **fixed family over a finite field**.  Zywina's [*The Large Sieve and Galois Representations*, arXiv:0812.2222](https://arxiv.org/abs/0812.2222) does vary rational primes, but it does so through a **fixed system of global Galois representations**, for example the torsion representations of a fixed abelian variety.

If there were a fixed global compatible representation \(\rho_m\) whose Frobenius trace at every \(p\) were \(\mathfrak M_p(m)\) and whose reduction mod \(p\) meant (5.2), this would be a genuinely promising framework.  The present Kummer factor prevents that: for fixed integer \(m\),

\[
\operatorname{ord}(\omega_p^m)
=\frac{p-1}{\gcd(m,p-1)}
\tag{6.6}
\]

is not bounded.  The character is not the reduction of one fixed finite-order Artin/Kummer character over \(\mathbf Q\).

## 6.5 Katz / hypergeometric sheaves

The repository does have an exact rank-two Euler/Kummer sum after the quadratic Franel pullback, and the audit verifies its Weil bound.  This is enough to put the local object squarely inside Katz-style trace-function geometry.

What is **not** currently established in the repository is an identification of the full global Mellin coefficient \(b_r\) with the value of one fixed standard Katz hypergeometric sheaf at a geometric parameter depending algebraically on \(r\).  More importantly, even such an identification would not solve the horizontal quantifier: the exponent \(r\) labels a character, not a geometric fiber.

### Summary table

| theorem/framework | what varies | defining modulus | why it misses (4.11) |
|---|---|---|---|
| Deligne/Katz one-prime bounds | geometric points/complete sums | fixed \(p\) | archimedean cancellation, not \(p\)-divisibility |
| FKM Thm. 1.5 | rational-prime arguments \(q\) | fixed \(p\) | our prime is the modulus itself |
| FKMS 2026 Thm. 1.1/1.3 | bilinear arguments \(m,n\) | fixed \(q\) | no cross-defining-characteristic coupling |
| Perret-Gentil | geometric \(x\), auxiliary \(\lambda\) | fixed finite-field characteristic in the compatible system | our sieve prime is \(p\) itself and the character point moves |
| Kowalski/Zywina Frobenius sieve | primes or family points of one fixed representation | fixed global compatible system | \(\omega_p^m\) is not one fixed global character |

I therefore find **no directly applicable published theorem among the named frameworks** that proves a power-saving count for (4.11).

# 7. The minimal parabolic large-sieve statement

The repository already proves that the full conjecture is equivalent to the top-half radical estimate

\[
\boxed{
\log\operatorname{rad}_{(n/2,n]}(b_n)=o(n).
}
\tag{7.1}
\]

For \(p\in(n/2,n]\), Lucas gives

\[
b_n\equiv b_1b_{n-p}=5b_{n-p}\pmod p,
\tag{7.2}
\]

and \(5\) is a unit for \(p\ge7\).  Combining (7.2) with (4.11) gives the exact horizontal reformulation

\[
\boxed{
 p\in(n/2,n],\ p\mid b_n
\iff
\mathfrak p_p\mid\mathfrak M_p(n-1).
}
\tag{7.3}
\]

This exposes a very small sufficient theorem.

## THMS\(_\delta\): top-half horizontal Mellin sieve

There exists an absolute \(\delta>0\) such that, uniformly in every integer \(n\ge2\),

\[
\boxed{
\#\left\{
 p\in(n/2,n]:p\ge7,
\ \mathfrak p_p\mid\mathfrak M_p(n-1)
\right\}
\ll n^{1-\delta}.
}
\tag{THMS}
\]

### THMS implies the full conjecture

Every prime in the top-half radical is at least \(n/2\) and at most \(n\), so

\[
\begin{aligned}
\log\operatorname{rad}_{(n/2,n]}(b_n)
&=\sum_{\substack{n/2<p\le n\\p\mid b_n}}\log p\\
&\le \log n\,
\#\{p\in(n/2,n]:p\mid b_n\}\\
&\ll n^{1-\delta}\log n=o(n).
\end{aligned}
\tag{7.4}
\]

By the proved equivalence (7.1), this yields

\[
\boxed{G_n=e^{o(n)}\quad\text{for every }n.}
\tag{7.5}
\]

So a \(P^{1-\varepsilon}\) bound is more than sufficient.  The genuinely minimal weighted statement is simply

\[
\boxed{
\sum_{\substack{p\in(n/2,n]\\\mathfrak p_p\mid\mathfrak M_p(n-1)}}\log p=o(n).
}
\tag{THMS}_0
\]

That statement is exactly the target radical in Mellin language.

## 7.1 Parabolic bounded-quotient version

For the broader hard region \(p>\sqrt n\), partition by

\[
q=\lfloor n/p\rfloor,
\qquad
I_{n,q}=\left(\frac n{q+1},\frac nq\right].
\tag{7.6}
\]

Inside \(I_{n,q}\), the exponent \(m=n-q\) is fixed.  A natural stronger statement is:

### PMLS\(_\delta\)

There exists \(\delta>0\) such that, uniformly for \(P\), \(n\), and \(q\) satisfying

\[
P<p\le2P,\qquad
p\in I_{n,q},\qquad
p>\sqrt n,
\tag{7.7}
\]

one has

\[
\boxed{
\#\left\{
 p\in(P,2P]\cap I_{n,q}:\
\mathfrak p_p\mid\mathfrak M_p(n-q)
\right\}
\ll P^{1-\delta}.
}
\tag{PMLS}
\]

This is exactly a **parabolic defining-characteristic Mellin large sieve**: \(n\lesssim P^2\), the exponent is fixed on each quotient cell, but the characteristic and the Kummer character order move.

Suppose PMLS holds for

\[
q<Q(n),\qquad Q(n)=n^{o(1)}
\tag{7.8}
\]

(for the project it is enough to take \(Q(n)=f(n)\log n\) with \(f\to\infty\) arbitrarily slowly).  Since \(p\asymp n/q\) on the \(q\)-cell, the weighted bad mass is

\[
\begin{aligned}
\sum_{q<Q(n)}
O\!\left((n/q)^{1-\delta}\log n\right)
&\ll n^{1-\delta}\log n\,Q(n)^\delta\\
&=n^{1-\delta+o(1)}=o(n).
\end{aligned}
\tag{7.9}
\]

The current quotient reduction in `proof.tex` handles the complementary smaller-prime range by prime counting alone.  Thus PMLS would also prove the full conjecture.

The top-half THMS is the smallest theorem worth attacking first: it already closes everything by (7.1), and it removes the nuisance of a moving quotient \(q\).

# 8. Why the current CHLS / HD-PC2 capacity obstruction does not answer THMS

The obstruction described in the current campaign is real but has different quantifiers.

A full-block estimate controls something like

\[
Z(p)=\#\{r<p:b_r\equiv0\pmod p\}
\tag{8.1}
\]

or a stronger absolute capacity of the whole zero set.  That does not control the graph

\[
r=n-p\quad(q=1)
\tag{8.2}
\]

for one fixed \(n\).  Even the fictitious bound \(Z(p)\le1\) permits adversarial sets

\[
Z_p=\{N-p\},\qquad p\in(N/2,N],
\tag{8.3}
\]

which align at one \(N\) and give the full prime count.  This is exactly the pointwise-gap example already recorded in `proof.tex`.

Conversely, unrestricted intervals are too flexible because Chinese remaindering can align prescribed residue conditions across finitely many moduli.  A theorem that averages over arbitrary \(n\) or over a complete CRT period therefore does not give THMS.

The parabolic condition changes the geometry of the question:

\[
n\lesssim p^2.
\tag{8.4}
\]

For many comparable primes, an arbitrary CRT prescription normally produces an integer of size comparable with their product, far outside (8.4).  Thus the parabolic graph is precisely where unrestricted CRT alignment stops being a formal counterexample.

But this observation is **not itself a sieve theorem**.  It only shows that THMS/PMLS is not ruled out by the usual CRT toy model.  One still needs arithmetic cancellation linking the defining-characteristic Mellin traces.

This is why CHLS/HD-PC2 full-block capacity is not the right next target: it pays for all \(r\) and discards the parabolic graph.  THMS asks only for the single prescribed Mellin character \(\omega_p^{n-1}\) at each \(p\).

# 9. Two precise structural obstructions to importing a fixed-modulus theorem

## 9.1 The moving character is not a fixed compatible twist

For fixed \(m\),

\[
\chi_{p,m}:=\omega_p^m
\]

has order

\[
d_{p,m}=\frac{p-1}{\gcd(m,p-1)}.
\tag{9.1}
\]

Although \(\mathcal L_{\chi_{p,m}}\) has conductor \(2\) for every \(p,m\), the orders \(d_{p,m}\) are generally unbounded.  A fixed Kummer cover \(y^d=a\) produces characters of order dividing one fixed \(d\); it does **not** produce \(\omega_p^m\) for fixed exponent \(m\) as \(p\) varies.

Thus one cannot simply say “the twist is fixed because \(m\) is fixed.”  The correct statement is:

> the **exponent** is fixed on a quotient cell, the **local conductor** is uniformly bounded, but the rank-one local system is not one fixed global compatible character.

This is the exact defining-characteristic compatibility break.

I do not claim that growing character order by itself proves impossibility.  The repository's exact Gauss/Jacobi audits show that some apparently large cyclotomic expressions collapse modulo \(p\) through Frobenius identities.  The claim is only that the standard fixed-compatible-system hypotheses are absent and must be replaced by a new horizontal theorem.

## 9.2 The zero detector is nonlinear in the trace sum

The exact event is

\[
\mathbf1_{\mathfrak M_p(m)\equiv0\;(\mathfrak p_p)}.
\tag{9.2}
\]

Using additive orthogonality gives formally

\[
\mathbf1_{u=0}
=\frac1p\sum_{h\in\mathbf F_p}e_p(hu),
\tag{9.3}
\]

but with

\[
u=\sum_a\theta_p(a)a^m
\tag{9.4}
\]

one obtains

\[
e_p\!\left(h\sum_a\theta_p(a)a^m\right),
\tag{9.5}
\]

not a linear complete sum of the individual pointwise trace functions.  One may not interchange “additive character after summation” with “summation after additive character.”

`codex_hgk_horizontal.py` contains an explicit \(\mathbf F_5\) counterexample to exactly this invalid interchange.  Hence the zero indicator is not automatically another bounded-conductor Deligne trace function.

The alternative identity \(\mathbf1_{u=0}=1-u^{p-1}\) over \(\mathbf F_p\) is no better: expanding the \((p-1)\)-st moment makes the complexity grow with \(p\), which destroys the bounded-complexity input of the standard trace-function technology.

# 10. Concrete next lemma

The most economical next theorem is not a monodromy computation over one finite field.  It is the following defining-characteristic statement.

## Horizontal K3--Kummer prime sieve

Let \(\mathscr T\) be the fixed primitive rank-three K3 system from §3, with the punctual corrections included, and define \(\mathfrak M_p(m)\) by (4.2).  Prove that there exists \(\delta>0\) such that

\[
\boxed{
\#\left\{
 p\in(n/2,n]:
\mathfrak p_p\mid
\operatorname{Tr}_c\bigl(\operatorname{Frob}_p,
\mathscr T_p\otimes\mathcal L_{\omega_p^{\,n-1}}\bigr)
\right\}
\ll n^{1-\delta}
}
\tag{HKKS}
\]

uniformly in \(n\).

Here `Tr_c` means the alternating compactly-supported trace including the finite punctual corrections, so HKKS is literally (THMS), not a heuristic surrogate.

This lemma has all the right features:

1. the geometric rank-three system is fixed over \(\mathbf Z[1/6]\);
2. every local Kummer twist has uniformly bounded conductor;
3. the exponent \(n-1\) is fixed across the whole top-half prime interval;
4. the condition being sieved is exactly \(p\mid b_{n-p}\);
5. its conclusion implies the full Apéry GCD conjecture by the three-line argument (7.4).

A useful intermediate theorem, weaker than HKKS but still new, would be a **pairwise horizontal correlation bound** for the defining-characteristic zero indicators on parabolic intervals, strong enough for a Selberg/dispersion argument.  What is not enough is a correlation of the complex Mellin traces themselves over complete character periods: the repository already verifies that such full-period correlations collapse to \(\gcd(p-1,q-1)\)-strata, while the nonlinear zero detector survives.

Thus the next algebraic task attached to HKKS is very specific:

> construct a horizontal, integral avatar of the twisted compactly-supported Mellin trace whose mod-\(p\) zero can be sieved across defining primes without replacing \(\omega_p^{n-1}\) by a fixed-order character and without applying an additive character after the completed Mellin sum.

That is the precise missing bridge between the exact K3/Asai sheaf and a parabolic large sieve.

# 12. Bottom line

The proposed route reaches a sharper point than “perhaps use trace functions.”  The exact object is already available:

\[
\boxed{
\mathfrak M_p(n-q)
=\operatorname{Tr}_c\left(\operatorname{Frob}_p,
\mathscr T_p\otimes\mathcal L_{\omega_p^{\,n-q}}\right),
\qquad
\mathfrak M_p(n-q)\equiv-b_{n-qp}\pmod{\mathfrak p_p}.
}
\tag{12.1}
\]

The primitive sheaf \(\mathscr T\) is the explicit rank-three K3/elliptic-Asai system attached to the fixed Laurent polynomial \(\Lambda\), and the Kummer twists have uniformly bounded local conductor.  So the **trace-sheaf construction succeeds**.

The large-sieve step does not.  The standard theorems I checked either

- fix the defining modulus and average arguments,
- average geometric points in a fixed finite-field family using auxiliary \(\ell\)-adic primes, or
- vary rational primes through one fixed global compatible Galois representation.

Our twists have moving order and our congruence is at the defining characteristic itself.  The character index is not a geometric fiber, and the zero detector is nonlinear after completing the Mellin sum.  Those are genuine hypothesis mismatches, not merely missing estimates.

Accordingly:

\[
\boxed{
\text{exact bounded-conductor Mellin sheaf: YES;}
\qquad
\text{known theorem giving the needed varying-}p\text{ zero density: NO found.}
}
\tag{12.2}
\]

The clean next lemma is HKKS/THMS.  Any fixed power saving there gives

\[
\log\operatorname{rad}_{(n/2,n]}(b_n)
\ll n^{1-\delta}\log n=o(n),
\]

and therefore proves \(G_n=e^{o(n)}\) pointwise.  The stronger PMLS formulation is the exact parabolic version compatible with the current bounded-quotient reduction and, unlike full-block CHLS/HD-PC2 capacity bounds, preserves the one-index graph on which CRT alignment is no longer formally unrestricted.
