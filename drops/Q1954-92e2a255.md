# Q1954 regularized-seam audit

## Verdict

The formal epsilon-seam computation does **not** produce a new independent relation of the required type. The linear epsilon coefficient is the same Casoratian information already encoded by the homogeneous transfer identity; after elimination it gives the derivative of the known two-solution pairing, not a second terminal support relation.

This means the proposed route does not close the localized terminal gcd argument.

## Formal epsilon expansion

Work in the polynomial ring `Z[epsilon]` and define

```
X_0(e)=1
X_1(e)=e
X_{n+1}(e)=4n(68n^2+3)X_n(e)-(2n-1)^6X_{n-1}(e)
```

Write

```
X_n(e)=a_n+e c_n+O(e^2).
```

The coefficients satisfy

```
a_0=1, a_1=0
c_0=0, c_1=1

a_{n+1}=4n(68n^2+3)a_n-(2n-1)^6a_{n-1}

c_{n+1}=4n(68n^2+3)c_n-(2n-1)^6c_{n-1}.
```

Thus the linearized solution is exactly the second fundamental solution of the same transfer matrix. No division by epsilon is involved.

For products

```
P_n(e)=prod_{2<=k<=n}X_k(e)=P_n(0)+e P'_n(0)+O(e^2),
```

with

```
P'_n(0)=sum_{r=2}^n c_r prod_{2<=k<=n,k!=r} a_k.
```

This formula is polynomial and remains valid when some `a_r=0`; it does not justify replacing `P_1` by `X_1P_0`.

## Why no second relation appears

The transfer determinant is constant. For two solutions `a,c`, the Casoratian

```
W_n=a_n c_{n+1}-a_{n+1}c_n
```

satisfies the standard first-order scaling determined by the recurrence coefficient. The epsilon coefficient of every terminal identity obtained by differentiating the affine family is therefore a multiple of this same Wronskian pairing.

The terminal quantity

```
H_m=rho_2+487 sigma_2
```

is obtained from the terminal vector at epsilon zero. Differentiating the terminal identity only replaces that vector by the tangent vector generated by `c`. It does not create a new support restriction on `3*d_m*P_m`.

Therefore the epsilon coefficient is algebraically dependent on (7aa5) and the known slope Casoratian.

## Exact verifier

The following SymPy code checks the constant/linear decomposition without epsilon inversion:

```python
from sympy import symbols, expand

e = symbols('e')

def scan(m):
    X=[1,e]
    for n in range(1,m):
        X.append(expand(4*n*(68*n*n+3)*X[n]-(2*n-1)**6*X[n-1]))
    const=[x.subs(e,0) for x in X]
    lin=[x.diff(e).subs(e,0) for x in X]
    return const,lin

for m in range(2,11):
    a,c=scan(m)
    print(m,a[m-1],c[m-1])
```

A successful proof of the gap-one theorem still needs a genuinely new arithmetic input: a terminal pairing whose weights differ from the Casoratian weights and whose support can be controlled modulo `p`. The regularized epsilon family alone does not provide it.
