## Decisive verdict

There is a stronger reduction than the previously named generic
“AP2-Palm” hypothesis.  For the **actual Apéry rows**, the whole pointwise
output-Palm discrepancy factors as

\[
\boxed{
 (\Delta_p)_+
 \ \le\ 7\lambda\,\eta_p+17\lambda^2
 \qquad (X\ge 8),
}
\tag{V1}
\]

where

\[
\boxed{
 \eta_p:=
 \frac{
  \displaystyle
  \sum_{q\ne p}\ \sum_{m\in\Omega_p\cap\Omega_q}
          \bigl(K_X(m)-2\bigr)
 }{
  \displaystyle
  \sum_{q\ne p}J_{p,q}
 }
}
\tag{V2}
\]

when the denominator is nonzero, and \(\eta_p=0\) otherwise.  Here

\[
K_X(m)=\sum_s f_s(m),
\qquad
J_{p,q}=|\Omega_p\cap\Omega_q|.
\]

Thus \(\eta_p\) is not an abstract incidence parameter.  It is the exact
mean number of **additional actual Apéry rows** through an actual Apéry
\((p,q)\)-intersection point, with the pair hits counted in their natural
multiplicity.

The first Palm level already has the required full power saving:

\[
\boxed{
 \frac1{|\Omega_p|}
 \sum_{m\in\Omega_p}\sum_{q\ne p}f_q(m)
 =\frac{\sum_{q\ne p}J_{p,q}}{|\Omega_p|}
 \le \frac{4X}{X-2}\lambda.
}
\tag{V3}
\]

A naive active-row bound is \(O(X\lambda)\); (V3) removes the entire factor
\(X\), uniformly in the output prime \(p\).  This is a genuine
exponent-saving inequality, proved below by the short-CRT geometry
\(pq>X^2\).

What remains is exactly one more conditional extension:

\[
\boxed{
 \eta_p\ \ll\ X^{o(1)}\lambda.
}
\tag{PE-pointwise}
\]

Under this one lemma, (V1) gives

\[
(\Delta_p)_+\ll X^{o(1)}\lambda^2,
\]

with no further loss.  For the weighted output square, the strictly weaker
sufficient condition is

\[
\boxed{
 \sum_p z_p\eta_p^2
 \ \ll\ X^{o(1)}\lambda^3.
}
\tag{PE-aggregate}
\]

Indeed,

\[
\boxed{
 \sum_p z_p^{-1}(E_p)_+^2
 \le
 M^2\left(
   98\lambda^2\sum_pz_p\eta_p^2+578\lambda^5
 \right)
 \qquad(X\ge8).
}
\tag{V4}
\]

Since \(M=X^2\), (PE-aggregate) gives the desired

# 1. Exact Apéry intersection statistics

Let

\[
\mathcal P_X=\{p:X<p\le2X\},
\qquad M=X^2,
\]

and retain the question's definitions

\[
\Omega_p=\{0\le m<M:m\bmod p\in\mathcal Z_p\},
\qquad
\mathcal Z_p=\{0\le r<p:p\mid b_r\},
\]

\[
Z(p)=|\mathcal Z_p|,
\qquad z_p=\frac{Z(p)}p,
\qquad f_p=1_{\Omega_p},
\qquad g_p=f_p-z_p,
\qquad \lambda=\sum_pz_p.
\]

Only active primes \(Z(p)>0\) need be retained whenever \(z_p^{-1}\)
appears.

Put

\[
A_p:=|\Omega_p|,
\qquad
J_{p,q}:=|\Omega_p\cap\Omega_q|,
\]

and, for three distinct primes,

\[
J_{p,q,\ell}:=|\Omega_p\cap\Omega_q\cap\Omega_\ell|.
\]

For a fixed output prime \(p\), define the actual anchored pair degree

\[
P_p:=\sum_{q\ne p}J_{p,q}.
\tag{1.1}
\]

If

\[
K_{-p}(m):=\sum_{q\ne p}f_q(m),
\]

then

\[
P_p=\sum_{m\in\Omega_p}K_{-p}(m).
\tag{1.2}
\]

Define the ordered actual third-extension count

\[
T_p:=
\sum_{\substack{q\ne\ell\\q,\ell\ne p}}J_{p,q,\ell}.
\tag{1.3}
\]

Equivalently,

\[
\boxed{
T_p
=\sum_{m\in\Omega_p}\bigl(K_{-p}(m)\bigr)_2
=\sum_{q\ne p}\ \sum_{m\in\Omega_p\cap\Omega_q}
       \bigl(K_X(m)-2\bigr).
}
\tag{1.4}
\]

The second equality is worth checking.  At a point \(m\in\Omega_p\), put
\(d=K_{-p}(m)\).  The rightmost expression chooses one of the \(d\)
other rows as \(q\), and then counts the remaining \(d-1\) rows.  Its
contribution is therefore \(d(d-1)=(d)_2\), exactly the ordered convention
in \(T_p\).

Now define

\[
\eta_p=
\begin{cases}
T_p/P_p,&P_p>0,\\
0,&P_p=0.
\end{cases}
\tag{1.5}
\]

If \(P_p=0\), then (1.2) implies \(K_{-p}=0\) on \(\Omega_p\), so also
\(T_p=0\); the convention is therefore harmless.

Two exact global identities will be useful.  Writing

\[
S_j:=\sum_{m<M}(K_X(m))_j,
\]

one has

\[
\boxed{
\sum_pP_p=S_2,
\qquad
\sum_pT_p=S_3.
}
\tag{1.6}
\]

Hence

\[
\boxed{
\frac{\sum_pP_p\eta_p}{\sum_pP_p}
=\frac{S_3}{S_2}.
}
\tag{1.7}
\]

This explains exactly what the existing `hm3_explore.py` diagnostic
“conditional extensions per pair hit” measures: it is the
\(P_p\)-weighted first moment of the actual output extension factors.
HM3 needs an \(L^\infty\) bound in the pointwise route or a
\(z_p\)-weighted \(L^2\) bound in the aggregate route.

# 2. The unconditional full-factor-\(X\) saving at the first Palm level

## Proposition 2.1: uniform actual-Apéry pair-degree bound

For every active \(p\in\mathcal P_X\) and every \(X>2\),

\[
\boxed{
\frac{P_p}{A_p}
\le c_X\lambda,
\qquad
c_X:=\frac{4X}{X-2}.
}
\tag{2.1}
\]

In particular, \(c_X=4+O(X^{-1})\), and \(c_X\le16/3\) for \(X\ge8\).

### Proof

Because \(p,q>X\),

\[
pq>X^2=M.
\]

Fix residues \(r\in\mathcal Z_p\) and \(s\in\mathcal Z_q\).  Their CRT
class has one representative in \([0,pq)\), so it has **at most one**
representative in \([0,M)\).  Therefore

\[
J_{p,q}\le Z(p)Z(q).
\tag{2.2}
\]

For each residue \(r\bmod p\), the interval \([0,M)\) contains either
\(\lfloor M/p\rfloor\) or \(\lceil M/p\rceil\) representatives.  Thus

\[
A_p\ge \left\lfloor\frac Mp\right\rfloor Z(p)
\ge \left(\frac Mp-1\right)Z(p).
\tag{2.3}
\]

Combining (2.2) and (2.3),

\[
\frac{P_p}{A_p}
\le
\frac{\sum_{q\ne p}Z(p)Z(q)}{(M/p-1)Z(p)}
\le
\frac{p\sum_qZ(q)}{M-p}.
\]

Since \(p\le2X\), \(M-p\ge X^2-2X\), and

\[
\sum_qZ(q)=\sum_qqz_q\le2X\lambda,
\]

we obtain

\[
\frac{P_p}{A_p}
\le
\frac{(2X)(2X\lambda)}{X^2-2X}
=rac{4X}{X-2}\lambda.
\]

This proves (2.1).  \(\square\)

## Why this is the right exponent saving

The completely naive bound is

\[
K_{-p}(m)\le R_X,
\qquad
R_X:=|\{q:Z(q)>0\}|\le2X\lambda,
\]

because every active row has \(z_q\ge1/(2X)\).  It would give
\(P_p/A_p\ll X\lambda\).  Proposition 2.1 gives \(P_p/A_p\ll\lambda\):
short CRT has saved exactly one full power of \(X\).

The second-Palm problem asks whether the same saving persists **after one
pair hit has already been selected**.  That is precisely the assertion
\(\eta_p\ll X^{o(1)}\lambda\).

# 3. Exact decomposition of the centered output-Palm discrepancy

For fixed \(p\), put

\[
\lambda_p:=\sum_{q\ne p}z_q=\lambda-z_p,
\qquad
\sigma_{2,p}:=\sum_{q\ne p}z_q^2.
\]

The ordered pair field is

\[
H_{-p}(m)=
\sum_{\substack{q\ne\ell\\q,\ell\ne p}}g_q(m)g_\ell(m).
\]

Expanding it in the uncentered row count gives the pointwise identity

\[
\boxed{
H_{-p}(m)
=\bigl(K_{-p}(m)\bigr)_2
-2\sum_{q\ne p}(\lambda_p-z_q)f_q(m)
+(\lambda_p^2-\sigma_{2,p}).
}
\tag{3.1}
\]

Define the ordered pair total not using \(p\),

\[
J_{2,-p}:=
\sum_{\substack{q\ne\ell\\q,\ell\ne p}}J_{q,\ell}.
\tag{3.2}
\]

Summing (3.1) over \(\Omega_p\), summing it over all \(m<M\), and using

\[
E_p=\sum_{m\in\Omega_p}H_{-p}(m)
-z_p\sum_{m<M}H_{-p}(m),
\]

one obtains the exact formula

\[
\boxed{
\begin{aligned}
E_p={}&T_p-z_pJ_{2,-p}\\
&-2\sum_{q\ne p}(\lambda_p-z_q)
       \bigl(J_{p,q}-z_pA_q\bigr)\\
&+(\lambda_p^2-\sigma_{2,p})(A_p-Mz_p).
\end{aligned}
}
\tag{3.3}
\]

This is the requested reduction to the actual pair intersections
\(J_{p,q}\).  It is exact; no probabilistic approximation has been made.

The four terms have distinct meanings.

1. \(T_p=\eta_pP_p\) is the actual pair-extension load.
2. \(-z_pJ_{2,-p}\le0\) is favorable for an upper bound.
3. The third line is a weighted sum of actual two-row discrepancies.
4. The last line is the finite-window endpoint term.

The third and fourth terms are already at \(O(Mz_p\lambda^2)\).  Thus all
possible excess above the desired scale is concentrated in \(T_p\).

# 4. Proof of the pointwise inequality

For every active \(p\), the interval counts satisfy

\[
\left(1-\frac2X\right)Mz_p
\le A_p\le
\left(1+\frac2X\right)Mz_p,
\tag{4.1}
\]

and

\[
|A_p-Mz_p|\le Z(p)=pz_p\le2Xz_p.
\tag{4.2}
\]

Also

\[
0\le\lambda_p^2-\sigma_{2,p}\le\lambda^2.
\tag{4.3}
\]

From Proposition 2.1,

\[
T_p=\eta_pP_p
\le c_X\eta_p\lambda A_p
\le
\left(1+\frac2X\right)c_XMz_p\eta_p\lambda.
\tag{4.4}
\]

For the linear pair-discrepancy term in (3.3), use
\(0\le\lambda_p-z_q\le\lambda\):

\[
\begin{aligned}
&\left|
\sum_{q\ne p}(\lambda_p-z_q)(J_{p,q}-z_pA_q)
\right|\\
&\qquad\le
\lambda P_p+z_p\lambda\sum_qA_q.
\end{aligned}
\tag{4.5}
\]

Now

\[
P_p\le c_X\lambda A_p
\le c_X\lambda\left(1+\frac2X\right)Mz_p,
\]

while

\[
\sum_qA_q
\le M\left(1+\frac2X\right)\sum_qz_q
=M\left(1+\frac2X\right)\lambda.
\]

Therefore

\[
\frac{2}{Mz_p}
\left|
\sum_{q\ne p}(\lambda_p-z_q)(J_{p,q}-z_pA_q)
\right|
\le
2\left(1+\frac2X\right)(c_X+1)\lambda^2.
\tag{4.6}
\]

Finally, by (4.2) and (4.3),

\[
\frac{|(\lambda_p^2-\sigma_{2,p})(A_p-Mz_p)|}{Mz_p}
\le\frac{2}{X}\lambda^2.
\tag{4.7}
\]

Divide (3.3) by \(Mz_p\), discard the nonpositive term
\(-J_{2,-p}/M\), and use (4.4), (4.6), and (4.7).  This gives the explicit
all-\(X\) inequality

\[
\boxed{
\begin{aligned}
(\Delta_p)_+
\le{}&
\left(1+\frac2X\right)c_X\lambda\eta_p\\
&+\left[
2\left(1+\frac2X\right)(c_X+1)+\frac2X
\right]\lambda^2,
\end{aligned}
}
\tag{4.8}
\]

where \(c_X=4X/(X-2)\).

For \(X\ge8\),

\[
\left(1+\frac2X\right)c_X\le7
\]

and

\[
2\left(1+\frac2X\right)(c_X+1)+\frac2X\le17.
\]

Hence

\[
\boxed{(\Delta_p)_+\le7\lambda\eta_p+17\lambda^2.}
\tag{4.9}
\]

This proves (V1).

## Pointwise consequence

The exact next pointwise lemma is

> **Actual-Apéry pair-extension lemma (PE).** Uniformly for active
> \(p\in(X,2X]\),
> \[
> \sum_{q\ne p}\ \sum_{m\in\Omega_p\cap\Omega_q}
>       (K_X(m)-2)
> \le X^{o(1)}\lambda
>       \sum_{q\ne p}J_{p,q}.
> \tag{PE}
> \]

This is exactly \(\eta_p\le X^{o(1)}\lambda\).  Substitution in (4.9)
gives

\[
(\Delta_p)_+\le(7X^{o(1)}+17)\lambda^2
=X^{o(1)}\lambda^2.
\]

No additional incidence or endpoint argument is needed.

# 5. Aggregate weighted overload square

Because the question's normalization is

\[
E_p=Mz_p\Delta_p,
\]

one has exactly

\[
S_+:=\sum_pz_p^{-1}(E_p)_+^2
=M^2\sum_pz_p(\Delta_p)_+^2.
\tag{5.1}
\]

For \(X\ge8\), square (4.9) using
\((a+b)^2\le2a^2+2b^2\):

\[
(\Delta_p)_+^2
\le98\lambda^2\eta_p^2+578\lambda^4.
\]

After multiplication by \(z_p\) and summation,

\[
\boxed{
S_+
\le M^2\left(
98\lambda^2\sum_pz_p\eta_p^2
+578\lambda^5
\right).
}
\tag{5.2}
\]

Thus it is enough to prove the following weaker theorem.

> **Weighted actual-Apéry pair-extension lemma.**
> \[
> \boxed{
> \sum_pz_p
> \left(
> \frac{
>  \sum_{q\ne p}\sum_{m\in\Omega_p\cap\Omega_q}(K_X(m)-2)
> }{
>  \sum_{q\ne p}J_{p,q}
> }
> \right)^2
> \ll X^{o(1)}\lambda^3,
> }
> \tag{WPE}
> \]
> with a zero summand when the denominator vanishes.

Then (5.2) gives

\[
S_+\ll M^2X^{o(1)}\lambda^5
=X^{4+o(1)}\lambda^5.
\]

The already established periodic-to-finite recentering error contributes
only the stated lower-order \(O(M^2\lambda^6/X)\) weighted square and does
not change this frontier.

## Pointwise versus aggregate, precisely

The logical implications are

\[
\text{(PE)}\Longrightarrow\text{(WPE)}\Longrightarrow\text{HM3 output square},
\]

but neither converse is required.

- **Pointwise PE** rules out every overloaded output row.
- **WPE** allows exceptional output rows provided their total
  \(z_p\)-weighted square is small.
- The existing identity (1.7) controls only a \(P_p\)-weighted first
  moment.  It does not imply WPE because the weighting and the power both
  change.

This is the exact remaining gap; no factor of \(X\), \(z_p\), or two from
the ordered-pair convention is hidden.

# 6. What reflection really gives

The repository proves the actual Apéry palindrome

\[
r\in\mathcal Z_p
\iff p-1-r\in\mathcal Z_p.
\tag{6.1}
\]

It has two exact consequences for the present problem, neither of which is
a decorrelation theorem.

## 6.1 Reflection within one output row

Write

\[
m=ap+r,
\qquad0\le r<p.
\]

If \(m\in\Omega_p\), then the reflected point in the same \(p\)-block is

\[
m^{(p)}=ap+(p-1-r)=(2a+1)p-1-m,
\tag{6.2}
\]

and, except for the already controlled final-window truncation,
\(m^{(p)}\in\Omega_p\).  Moreover

\[
|m^{(p)}-m|<p<2X.
\]

But the companion depends on \(p\).  If \(q\) and \(\ell\) also hit at
\(m\), there is no reason for them to hit at \(m^{(p)}\).  Thus the
reflection spray creates nearby one-row hits, not automatically nearby
\((p,q,\ell)\)-hits.  It does not bound \(\eta_p\).

## 6.2 Reflection of a complete two-prime CRT class

Fix \(q\ne\ell\), and let \(m\in[0,q\ell)\) be the CRT representative of
\((r_q,r_\ell)\in\mathcal Z_q\times\mathcal Z_\ell\).  Reflecting both
residues gives the representative

\[
m^\sharp=q\ell-1-m.
\tag{6.3}
\]

For a third prime \(p\), (6.1) gives

\[
f_p(m^\sharp)=f_p(m-q\ell).
\tag{6.4}
\]

Indeed,

\[
m^\sharp=-1-(m-q\ell).
\]

Consequently, a reflected pair samples the translate overlap of the output
row by

\[
t\equiv q\ell\pmod p.
\]

When both representatives lie in \([0,M)\), the two output samples are

\[
f_p(m),
\qquad f_p(m-t).
\]

Thus reflection converts part of the problem into autocorrelations

\[
|\mathcal Z_p\cap(\mathcal Z_p+t)|,
\tag{6.5}
\]

but it does not supply cancellation.  The shift

\[
t\equiv q\ell\equiv(q-p)(\ell-p)\pmod p
\]

ranges through long residues.  The gap-polynomial theorem bounds actual
short integer gaps, for example

\[
|\{r:r,r+h\in\mathcal Z_p\}|\le3(h-1),
\]

but it does not give the density-scale estimate
\(O(Z(p)^2/p)\) uniformly for the long, varying shifts (6.5).  Therefore
replacing PE by a sentence saying “use reflection” would leave the main
step unproved.

The useful exact reformulation is:

> A reflection-based proof of PE must establish averaged density-scale
> control of the translates \(q\ell\bmod p\) **on the pair-CRT set**, not
> merely fixed-gap repulsion inside each individual \(\mathcal Z_p\).

# 7. What Lucas really gives

For \(p>X\) and \(m<X^2\), write

\[
m=ap+r,
\qquad0\le a,r<p.
\]

The exact Apéry Lucas law is

\[
b_m\equiv b_ab_r\pmod p.
\tag{7.1}
\]

Therefore

\[
m\in\Omega_p
\quad\Longrightarrow\quad
p\mid b_m.
\tag{7.2}
\]

At an actual pair point,

\[
m\in\Omega_p\cap\Omega_q
\quad\Longrightarrow\quad pq\mid b_m,
\tag{7.3}
\]

and every additional row \(\ell\) counted in (V2) gives

\[
pq\ell\mid b_m.
\tag{7.4}
\]

Thus PE has a direct arithmetic interpretation:

> Among the actual integers \(m<X^2\) already known to have two window
> prime divisors of \(b_m\) through their low Lucas digits, the mean number
> of further window prime divisors through low digits is
> \(X^{o(1)}\lambda\).

This is much more specific than an arbitrary incidence statement.

However, Lucas is an implication, not a bound.  The converse of (7.2) can
also occur through the quotient digit \(a\in\mathcal Z_p\).  More
importantly, the Boolean OR law propagates a base zero; it does not restrict
how many distinct primes can have their low digit in their respective
Apéry zero sets at the same integer \(m\).  Bounding that multiplicity is
the repository's atom-tail frontier.

A generic bound on \(\omega(b_m)\) from the size of \(b_m\) is far too
large at \(m\asymp X^2\).  Hence Lucas identifies PE with a large-prime
factor problem for the actual Apéry numbers, but it does not prove the
required \(X^{o(1)}\lambda\) conditional mean.

# 9. Exact next computation, using the existing CRT enumeration

The next computation should be added to `hm3_explore.py`.  It does not need
to build \(H_{-p}(m)\) for every \((p,m)\), and it does not require an
\(O(MR^2)\) scan.  The existing lists `pairs`, `triples`, and
`active_counts` already contain everything.

The following block uses exact rational arithmetic.  It should be inserted
after `pairs`, `triples`, `active_counts`, `s2`, and `s3` have been computed.

```python
from fractions import Fraction

active_primes = [item.p for item in active]
M = m_limit

# Exact periodic densities.
zq = {
    item.p: Fraction(len(item.zeros), item.p)
    for item in active
}
lam_q = sum(zq.values(), Fraction(0))

# J_{p,q} and P_p = sum_q J_{p,q}.
J = {}
P = {p: 0 for p in active_primes}
for pair in pairs:
    j = len(pair.reps)
    J[pair.p, pair.q] = j
    J[pair.q, pair.p] = j
    P[pair.p] += j
    P[pair.q] += j

# T_p is ordered in the two non-output primes.
# One canonical triple contributes 2 to each of its three output anchors.
T = {p: 0 for p in active_primes}
for triple in triples:
    T[triple.p] += 2
    T[triple.q] += 2
    T[triple.s] += 2

# Exact combinatorial guards.
assert sum(P.values()) == s2
assert sum(T.values()) == s3

eta = {
    p: Fraction(T[p], P[p]) if P[p] else Fraction(0)
    for p in active_primes
}

# Exact E_p from equation (3.3).
# active_counts[p] is A_p.
A = active_counts
J2_total = 2 * sum(len(pair.reps) for pair in pairs)
E = {}
Delta = {}

for p in active_primes:
    lam_p = lam_q - zq[p]
    sigma2_p = sum(
        zq[q] * zq[q]
        for q in active_primes if q != p
    )

    # Remove the two orientations of every pair involving p.
    J2_minus_p = J2_total - 2 * P[p]

    linear = sum(
        (lam_p - zq[q])
        * (Fraction(J.get((p, q), 0), 1) - zq[p] * A[q])
        for q in active_primes if q != p
    )

    E[p] = (
        Fraction(T[p], 1)
        - zq[p] * J2_minus_p
        - 2 * linear
        + (lam_p * lam_p - sigma2_p)
          * (Fraction(A[p], 1) - M * zq[p])
    )
    Delta[p] = E[p] / (M * zq[p])

positive_delta = {
    p: max(Delta[p], Fraction(0))
    for p in active_primes
}

R_point = max(
    (positive_delta[p] / (lam_q * lam_q), p)
    for p in active_primes
)
R_eta = max(
    (eta[p] / lam_q, p)
    for p in active_primes
)
R_aggregate = (
    sum(zq[p] * positive_delta[p] ** 2 for p in active_primes)
    / (lam_q ** 5)
)
R_extension = (
    sum(zq[p] * eta[p] ** 2 for p in active_primes)
    / (lam_q ** 3)
)

print("max Delta_+/lambda^2, prime =", R_point)
print("max eta/lambda, prime =", R_eta)
print("sum z Delta_+^2/lambda^5 =", R_aggregate)
print("sum z eta^2/lambda^3 =", R_extension)
```

# 10. The exact next lemma and possible proof routes

The next theorem should be stated in the manuscript in the following form,

## Actual-Apéry pair-extension lemma

For the genuine Apéry sets \(\Omega_p\), uniformly for active
\(p\in(X,2X]\),

\[
\boxed{
\sum_{q\ne p}\sum_{m\in\Omega_p\cap\Omega_q}
       (K_X(m)-2)
\ll X^{o(1)}\lambda
   \sum_{q\ne p}J_{p,q}.
}
\tag{10.1}
\]

The exact proof target is now transparent.  A successful proof must control
actual third extensions of actual pair CRT representatives.  The repository
currently supplies three partial ingredients:

1. **Short CRT:** Proposition 2.1 proves the required first conditional
   density \(P_p/A_p\ll\lambda\).
2. **Reflection:** it converts paired CRT representatives into translates by
   \(q\ell\bmod p\), but a new averaged long-shift autocorrelation estimate is

3. **Lucas:** every extension is an additional window prime divisor of the
   same actual Apéry number \(b_m\), but a conditional atom-tail theorem is

Accordingly, there are two honest proof routes.

### Route A: translated-row estimate on the actual pair set

Prove, after summing over the pair representatives generated by
\(\mathcal Z_q\times\mathcal Z_\ell\), a density-scale estimate for

\[
1_{\mathcal Z_p}(m\bmod p)
\]

and its reflected translate by \(q\ell\bmod p\).  A theorem only for a fixed
short gap \(h\) is insufficient; the parameter substitution must cover the
full family

\[
t=(q-p)(\ell-p)\bmod p,
\qquad p,q,\ell\in(X,2X].
\]

### Route B: conditional atom-tail estimate

Use the Lucas implication \(pq\mid b_m\) at pair points and prove that the
additional low-digit window-prime multiplicity has conditional mean
\(X^{o(1)}\lambda\).  This is weaker than the global pointwise atom-tail
claim

\[
\max_mK_X(m)\ll X^{o(1)}\lambda,
\]

because it asks only for a mean over pair hits, and WPE asks only for its
\(z_p\)-weighted second moment.

The current general-purpose theorems in the repository do not supply either
parameterized statement.  In particular, citing a standard large sieve,
Deligne bound, or expander theorem without constructing a fixed bounded-
conductor object and substituting the moduli, interval length \(M=X^2\), and
the moving shifts above would not prove (10.1).
