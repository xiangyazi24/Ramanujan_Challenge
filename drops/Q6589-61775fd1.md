## Obstruction: no finite rational polygon in (u,w) alone

After expanding the exact positiveMatrix projective map, the induced map in these coordinates has the form

\[
 u' = u+37^{-1}h^{-2}+a(h)w+O(h^{-3}),
\]
\[
 w'=\lambda(h)w+c(h)u^2+O(h^{-3}),
\]

with \(\lambda(h)=1+\Theta(1/h)\). The transverse eigen-direction is neutral at first order and the second coordinate feeds back into it. Therefore any fixed finite-facet cone

\[
|u|\le C_1/h,\qquad |w|\le C_2/h^2
\]

is not invariant: the image of a facet acquires a nonzero quadratic drift term. Increasing the number of facets only changes the constants; it does not remove this drift.

The missing invariant is the next asymptotic coordinate. One must introduce

\[
z=h^3(w-987/(64h^2))
\]

(or an equivalent exact rationalized third coordinate) and control the graph of z. This is a nonlinear graph invariant, not a finite rational polyhedral cone in the original projective plane.

## Consequence for Lean certificate

The requested object with only finitely many rational facets in the original (X,Y) plane does not exist. The minimal certificate must be a curved/nested invariant region, for example:

\[
|h(X-5/4)+37/16|\le A/h,
\]
\[
|h^2(37(Y-2)-56(X-5/4))-987/64|\le B/h,
\]
\[
|z-z_0|\le C/h.
\]

The constants A,B,C can be chosen rational after a finite cutoff, but the resulting set is not polyhedral because the third constraint is a nonlinear graph condition.
