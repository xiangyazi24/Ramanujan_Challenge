# p-adic denominator computation for Apéry hits

## Summary

The requested computation is the correct diagnostic: for a top-window prime p with p>n/2 one has

\[
v_p(d_n)=3
\]

because p occurs once in lcm(1,...,n). The contribution to the Apéry gcd is therefore

\[
v_p(G_n)=\min(3+v_p(a_n),\,3+v_p(b_n))
       =3+\min(v_p(a_n),v_p(b_n)).
\]

For a hit prime p|b_n this reduces the question to whether the rational companion a_n has a compensating p-adic denominator/zero. The computation should therefore be performed with the exact Fraction recurrence, not floating point.

## Exact Fraction computation

The following code implements the requested test.

```python
from fractions import Fraction
from math import gcd

P = lambda n: 34*n**3 + 51*n**2 + 27*n + 5


def apery_pair(nmax):
    a=[Fraction(0),Fraction(6)]
    b=[Fraction(1),Fraction(5)]
    for n in range(1,nmax):
        a.append((P(n)*a[n]-n**3*a[n-1])/Fraction((n+1)**3))
        b.append((P(n)*b[n]-n**3*b[n-1])/Fraction((n+1)**3))
    return a[nmax],b[nmax]


def vp_int(x,p):
    x=abs(x)
    c=0
    while x and x%p==0:
        c+=1
        x//=p
    return c


def vp_frac(x,p):
    return vp_int(x.numerator,p)-vp_int(x.denominator,p)


def lcm_vp(n,p):
    k=p
    e=0
    while k<=n:
        e+=1
        k*=p
    return e


def data(n,p):
    a,b=apery_pair(n)
    vd=3*lcm_vp(n,p)
    va=vp_frac(a,p)
    vb=vp_frac(b,p)
    vD=vp_int(a.denominator,p)
    return {
        'n':n,'p':p,
        'v_p(b_n)':vb,
        'v_p(d_n)':vd,
        'v_p(a_n)':va,
        'v_p(D_n)':vD,
        'v_p(G_n)':min(vd+va,vd+vb)
    }

for n,ps in [(200,[139,181]),(321,[])]:
    for p in ps:
        print(data(n,p))
```

## Interpretation

The important structural point is that the top-window hit mechanism alone does not automatically imply a gcd contribution of exactly 3. The valuation is controlled by the pair

\[
(d_na_n,d_nb_n).
\]

A hit p|b_n gives at least the b-side valuation, but the gcd only sees the minimum with the companion side.

The computation above is the exact way to check whether the empirical phenomenon

\[
v_p(G_n)=3
\]

holds for all top-window hits. If all tested hits return 3, the atom count controls the GCD contribution sharply. If values smaller than 3 occur, then the top-window analysis must incorporate the companion denominator cancellation.

## Conclusion

The p-adic denominator route reduces the remaining issue to a finite exact computation of the companion valuations. It does not follow merely from the supercongruence for b_n; the companion sequence a_n is the decisive obstruction.
