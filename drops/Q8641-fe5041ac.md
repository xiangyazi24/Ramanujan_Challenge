# Fixed-fibre audit for the Apéry full-defect gate

## 1. Reduction and the actual target

For a fixed signed nondegenerate defect label \((s,d_2,d_3)\), a fibre element is determined by

\[
 n_i=N-d_i=c_i p_i,
\]

with \(p_i\in(X,2X]\), \(c_i\ll X\), and

\[
 p_i\mid B_{u_i(t)},\qquad u_i(t)=s_i(t+d_i+\tau_i)
\]

(after folding). The trivial parameter count is \(t\ll X\), hence the trivial fibre bound is \(J_X\ll X\). The required statement is only

\[
J_X=o(X/\log ^3X).
\]

This is substantially weaker than a density-normalized \(X^{o(1)}\) estimate, but it still requires a logarithmic saving uniformly in every fixed fibre.

## 2. What follows unconditionally from the frozen input

For each fixed \(t\), the three conditions are divisibility conditions

\[
N-d_i\mid c_iB_{u_i(t)}
\]

with the shell-prime part of \(N-d_i\) forced into the finite set

\[
\{p\in(X,2X]:p\mid B_{u_i(t)}\}.
\]

The Apéry input gives root information only after fixing the prime. It does not give a bound on the number of translations \(t\) for which a moving root condition holds simultaneously for three independent shell primes.

The available exact facts therefore imply:

* a fibre is contained in a set of translation indices \(t\);
* every accepted \(t\) has at least three shell divisibility incidences;
* the coefficient ranges only give \(O(X)\) possible quotients.

No logarithmic saving follows from these facts alone.

## 3. Why the elementary sieve attempt stalls

A natural approach is to define

\[
S_t=\{p\in(X,2X]:p\mid B_{u(t)}\}\cap\{p:p\mid N-d\}.
\]

A fixed fibre solution requires three compatible sets \(S_{t,i}\). Bounding

\[
\sum_t |S_{t,1}||S_{t,2}||S_{t,3}|
\]

would need a correlation estimate between moving folded zeros of different indices. HM2 controls row multiplicities:

\[
\sum_m(R_m^\dagger)_2\le 5X^2\lambda_X^2,
\]

but it is an aggregate second moment over rows, not a fixed defect-fibre estimate. A single fibre may concentrate its contribution without violating HM2.

## 4. Exact missing theorem

The missing statement needed is a fixed-fibre correlation theorem of the form:

\[
\#\{t:\exists p_i\in(X,2X],\ p_i\mid B_{u_i(t)},\ N-d_i=c_ip_i\}
\ll \frac{X}{\log^{3+\epsilon}X}
\]

uniformly in every admissible signed defect label.

This is not implied by:

* root-count bounds for individual primes;
* HM2;
* nondegenerate defect geometry;
* bounded multiplicity of translation fibres.

It is an additional three-fold correlation estimate.

## 5. Endpoint checks

The coefficient count

\[
P_X=468X^2-756X+288
\]

only counts possible defect/sign labels. If

\[
F_3\le P_XJ_X,
\]

then the required cubic moment estimate follows from

\[
J_X=o(X/\log^3X),
\]

because

\[
F_3=o(X^3/\log^3X).
\]

The obstruction is not the label count; it is the uniform fixed-label saving.

## 6. Why standard Apéry tools do not close the gap

The recurrence, Casoratian, and Lucas-type congruences relate nearby indices modulo a fixed prime. They do not produce a polynomial equation in the index variable whose roots are the possible translations.

In particular, there is no valid resultant argument in an index variable: \(B_u\) is a sequence, not a polynomial.

A recurrence determinant can compare two indices, but for a single fixed fibre it gives at most relations between already chosen roots; it does not bound the number of admissible translations.

## 7. Conditional route

If one assumes any one of the following additional inputs, the desired saving becomes plausible:

1. a three-fold moving-root correlation bound;
2. an Apéry trace estimate uniform in varying indices;
3. an entropy/sieve estimate showing that simultaneous divisibility by three translated values has density \(o(\log^{-3}X)\).

Without such an input, the fixed-fibre theorem remains open from the stated hypotheses.

## Conclusion

The reduction to \(J_X=o(X/\log^3X)\) is a genuine weakening of the previous FDTG3 requirement, but it is not currently derivable from HM2 plus exact selector geometry. The exact missing ingredient is a uniform three-condition correlation estimate for moving folded Apéry zeros inside one defect fibre. No endpoint inequality fails; rather, the available moments do not see concentration in a single fixed fibre.
