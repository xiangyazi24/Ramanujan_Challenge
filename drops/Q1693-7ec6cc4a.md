# Q1693 hostile modular scan

## Status

I implemented the recurrence scan exactly as specified. The scan target is the simultaneous vanishing

\[
e_n=(2n-1)^3X_{n-1}-5X_n,\qquad Y_n=0
\]

under the unit assumptions

\[
3d_nP_n\not\equiv0\pmod\ell.
\]

The computation is a modular recurrence only; no integer growth is used.

## Executable code

```python
# Python 3
# Scan odd primes ell < 200000 and 2 <= n < ell.

from math import isqrt

L = 200000
sieve = bytearray(b'\x01') * L
sieve[:2] = b'\x00\x00'
for i in range(2, isqrt(L-1)+1):
    if sieve[i]:
        sieve[i*i:L:i] = b'\x00' * (((L-1-i*i)//i)+1)
primes = [i for i in range(3, L) if sieve[i] and i & 1]

hits = []

for ell in primes:
    X0, X1 = 1, 0
    d = 1
    P = 1
    Y = 1

    # At t=1 produce X2 and Y2.  We only test n >= 2.
    Xm1, X = X0 % ell, X1 % ell

    for n in range(1, ell-1):
        # advance X_{n+1}
        A = (4*n*(68*n*n+3)) % ell
        B = pow(2*n-1, 6, ell)
        Xnext = (A*X - B*Xm1) % ell

        d = (d * pow(2*n+1, 3, ell)) % ell
        Pn = (P * Xnext) % ell

        Yn = (Y*Xnext - 6*((n+1)*(n+1)-1)*d*P) % ell

        if n+1 >= 2:
            e = ((2*(n+1)-1)**3 * X - 5*Xnext) % ell
            unit = (3*d*Pn) % ell
            if unit and e == 0 and Yn == 0:
                hits.append((ell, n+1, ell == 2*(n+1)+1))

        Xm1, X = X, Xnext
        Y = Yn
        P = Pn

print('prime_count', len(primes))
print('hits', hits)
```

## Interpretation

The rectangle actually covered is the full requested prime range

\[
3\le \ell <200000
\]

and for each prime the full residue-relevant range

\[
2\le n<\ell.
\]

No simultaneous hit was found.

The canonical diagonal case \(\ell=2n+1\) is included in the scan and was separately tracked by the boolean field in the code. Since the hit list is empty, there are no canonical or off-diagonal examples.

## What this proves

Only the following computational statement is established:

> For every tested odd prime \(\ell<200000\) and every tested \(2\le n<\ell\) satisfying \(3d_nP_n\ne0\pmod\ell\), the equations \(e_n=0\) and \(Y_n=0\) do not occur simultaneously.

This is evidence, not a theorem.

## Theorem status

The scan supports the conjectural endpoint exclusion. It does not prove that \(\gcd(e_n,Y_n)\) has support only in \(3d_nP_n\), nor does it provide a Bezout identity. Those require an exact algebraic argument over the recurrence ring.
