## 6. Casoratians and why adding rows does not solve HCF2

For sequences \(x,y\), put

\[
D_r(x,y)=r^3(x_{r-1}y_r-x_ry_{r-1}).
\tag{41}
\]

If \(Lx=s_x\), \(Ly=s_y\), direct substitution gives

\[
\boxed{
D_{r+1}(x,y)-D_r(x,y)=x_rs_y(r)-y_rs_x(r).
}
\tag{42}
\]

For \(b\), since \(Lb=0\),

\[
D_{r+1}(b,y)-D_r(b,y)=b_rs_y(r).
\tag{43}
\]

The determinant in the question is \(\Xi_r=D_r(b,\kappa)\), hence

\[
\boxed{\Xi_{r+1}-\Xi_r=-5b_rg_r.}
\tag{44}
\]

The next determinants are

\[
\Xi_r^{(2)}=D_r(b,\lambda),
\qquad
\Xi_r^{(3)}=D_r(b,\nu),
\]

with

\[
\Xi_{r+1}^{(2)}-\Xi_r^{(2)}
=-b_r(A_1\kappa+A_2b)_r,
\tag{45}
\]

\[
\Xi_{r+1}^{(3)}-\Xi_r^{(3)}
=-b_r(A_1\lambda+A_2\kappa+A_3b)_r.
\tag{46}
\]

At a target \(p\mid b_r\), no two consecutive Apéry values vanish modulo \(p\), so \(b_{r-1}\) is a unit.  Since \(p>r\), \(r\) is also a unit, and

\[
\boxed{
D_r(b,\tau)\equiv r^3b_{r-1}\tau_r\pmod p.
}
\tag{47}
\]

Therefore the localized ideals generated by

\[
(b_r,\kappa_r,\lambda_r,\nu_r)
\]

and

\[
(b_r,\Xi_r,\Xi_r^{(2)},\Xi_r^{(3)})
\]

are the same.  Casoratians are a unit coordinate change, not an extra equation.

The obvious 3-by-3 consecutive-neighbor determinant also cannot rescue a simultaneous two-coordinate zero.  Define

\[
W_r(b,x,y)=
\det\begin{pmatrix}
 b_{r-1}&x_{r-1}&y_{r-1}\\
 b_r&x_r&y_r\\
 b_{r+1}&x_{r+1}&y_{r+1}
\end{pmatrix}.
\]

Using the recurrence on the last row,

\[
\boxed{
\begin{aligned}
(r+1)^3W_r(b,x,y)
={}&b_{r-1}(x_rs_y-y_rs_x)\\
&-b_r(x_{r-1}s_y-y_{r-1}s_x).
\end{aligned}}
\tag{48}
\]

Hence if \(p\mid b_r\) and \(x_r=y_r=0\pmod p\), then

\[
W_r(b,x,y)\equiv0\pmod p.
\tag{49}
\]

This proves the scoped obstruction: **ordinary finite consecutive-neighbor Casoratian enlargement does not escape HCF2.**  A successful proof needs a new arithmetic identity for the endpoint derivatives of \(\mathcal N_r\), not merely another recurrence row.

The homogeneous companion itself should not be counted as a new transverse direction: with \(c=a/6\),

\[
D_r(b,c)=1
\]

identically.  Allowing that direction makes a trivial unit determinant and simply undoes the target-preserving normalization.

## 8. Resultants and Archimedean height

A double endpoint root forces

\[
p\mid\operatorname{Res}(\mathcal N_r,\mathcal N_r'),
\]

and triple/quadruple endpoint roots force corresponding subresultants.  These are valid carriers but are not sharp enough:

1. they see repeated roots at every point, not only \(X=0\);
2. their heights are much larger than the endpoint HCFs.

From (6), with \(\|\cdot\|_1\) the coefficient \(\ell^1\)-norm,

\[
\|\mathcal N_{r+1}\|_1
\le
\|P(X+r)\|_1\|\mathcal N_r\|_1
+(r+1)^6\|\mathcal N_{r-1}\|_1,
\]

so

\[
\log\|\mathcal N_r\|_1=O(r\log r).
\tag{50}
\]

A generic degree-\(3r\) Sylvester resultant therefore has logarithmic height on the scale \(O(r^2\log r)\), far too large to imply \(p\le Cr\).

Even the target itself only gives an exponential bound.  From

\[
b_r=\sum_{k=0}^r\binom rk^2\binom{r+k}k^2
\]

and \(\binom rk\le2^r\), \(\binom{r+k}k\le4^r\),

\[
0<b_r\le(r+1)64^r.
\tag{51}
\]

Hence every target prime satisfies \(p\le(r+1)64^r\), rigorous but exponentially weaker than a linear-support theorem.  A proof of \(p\le Cr\) needs a genuinely low-height **endpoint** identity, not generic resultant height.

## 9. Precise remaining theorem

The next arithmetic seam is now exact.

### HCF2
Prove, or refute by an infinite mechanism,

\[
\operatorname{rad}_{>r}\mathfrak H_r^{(2)}=1.
\tag{HCF2}
\]

A weaker useful target is

\[
p\mid\mathfrak H_r^{(2)},\ p>r
\Longrightarrow p\le Cr.
\tag{LHCF2}
\]

### HCF3-raw
If HCF2 fails, prove or refute

\[
\operatorname{rad}_{>r}\mathfrak H_{r,\mathrm{raw}}^{(3)}=1,
\tag{HCF3}
\]

or its linear-support variant.

These statements are equivalent to the desired two-/three-transverse target exclusion, with no Hecke endpoint scalar left.  A finite scan can locate examples and suggest the carrier, but it cannot prove HCF2/HCF3.

I do not find a current repository proof of either HCF2 or HCF3, so claiming a universal two- or three-coordinate Bézout identity would be stronger than the available algebra warrants.

## 10. Verifier-ready code

This uses only the Python standard library.  It reconstructs \(b,\kappa,\lambda,\mu\), the normalized companion \(c=a/6\), verifies the universal recurrences, constructs \(\mathcal N_r\), and certifies the exact \((11,5)\) double-root obstruction.

```python
#!/usr/bin/env python3
from fractions import Fraction as F
from math import comb, factorial, gcd

ORDER = 4


def P(n):
    return 34*n**3 + 51*n**2 + 27*n + 5


def P1(n):
    return 102*n**2 + 102*n + 27


def add(a, b):
    return [a[i] + b[i] for i in range(ORDER)]


def sub(a, b):
    return [a[i] - b[i] for i in range(ORDER)]


def mul(a, b):
    out = [F(0) for _ in range(ORDER)]
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            if i+j >= ORDER:
                break
            out[i+j] += x*y
    return out


def inv_shift_cube(s):
    return [F((-1)**j * comb(j+2, 2), s**(j+3)) for j in range(ORDER)]


def shifted_P(s):
    return [F(P(s)), F(P1(s)), F(102*s+51), F(34)]


def shifted_cube(s):
    return [F(s**3), F(3*s**2), F(3*s), F(1)]


def shifted_solutions(limit):
    zero = [F(0)]*ORDER
    one = [F(1), F(0), F(0), F(0)]
    direct = [one, mul([F(5),F(27),F(51),F(34)], inv_shift_cube(1))]
    companion = [zero, one]
    for r in range(1, limit):
        for seq in (direct, companion):
            num = sub(mul(shifted_P(r), seq[r]), mul(shifted_cube(r), seq[r-1]))
            seq.append(mul(num, inv_shift_cube(r+1)))
    return direct, companion


def L(seq, r):
    return (r+1)**3*seq[r+1] - P(r)*seq[r] + r**3*seq[r-1]


def A1(seq, r):
    return 3*(r+1)**2*seq[r+1] - P1(r)*seq[r] + 3*r**2*seq[r-1]


def A2(seq, r):
    return 3*(r+1)*seq[r+1] - (102*r+51)*seq[r] + 3*r*seq[r-1]


def A3(seq, r):
    return seq[r+1] - 34*seq[r] + seq[r-1]


def modq(x, p):
    x = F(x)
    assert x.denominator % p
    return x.numerator * pow(x.denominator, -1, p) % p


# Integer polynomial helpers; coefficients low-to-high.
def trim(a):
    while len(a) > 1 and a[-1] == 0:
        a.pop()
    return a


def pmul(a, b):
    out = [0]*(len(a)+len(b)-1)
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            out[i+j] += x*y
    return trim(out)


def psub(a, b):
    n = max(len(a), len(b))
    out = [0]*n
    for i in range(n):
        out[i] = (a[i] if i < len(a) else 0) - (b[i] if i < len(b) else 0)
    return trim(out)


def pshift(s):
    return [P(s), P1(s), 102*s+51, 34]


def xplus6(s):
    return [comb(6,j)*s**(6-j) for j in range(7)]


def continuants(limit):
    N = [[1], [5,27,51,34]]
    for r in range(1, limit):
        N.append(psub(pmul(pshift(r), N[r]), pmul(xplus6(r), N[r-1])))
    return N


def deriv0(poly, j):
    return factorial(j)*poly[j] if j < len(poly) else 0


def hcf(poly, entries):
    g = 0
    for value in entries:
        g = gcd(g, abs(value))
    return g


def main():
    direct, companion = shifted_solutions(12)
    b   = [u[0] for u in direct]
    kap = [u[1] for u in direct]
    lam = [u[2] for u in direct]
```
