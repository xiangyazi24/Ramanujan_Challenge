## 5. The endpoint multiplicity theorem

Because (25)--(28) are triangular in the \(n_{r,j}\), on a target they collapse successively:

* if \(n_{r,0}=0\), then \((r!)^3\kappa_r\equiv n_{r,1}\);
* if also \(n_{r,1}=0\), then \((r!)^3\lambda_r\equiv n_{r,2}\);
* if also \(n_{r,2}=0\), then \((r!)^3\mu_r\equiv n_{r,3}\).

Since \(j!\) is a unit for \(j\le3\) and \(p\ge5\), this proves (12).

It is useful to record the exact residual carriers

\[
\boxed{
\mathfrak H_r^{(m)}=
\gcd\left(
\mathcal N_r(0),\mathcal N_r'(0),\ldots,
\mathcal N_r^{(m)}(0)
\right),\qquad m=1,2,3.
}
\tag{32}
\]

After discarding prime factors \(\le r\), these are exactly:

* \(m=1\): failures of the single transverse coordinate \(\kappa\);
* \(m=2\): simultaneous failures of \(\kappa,\lambda\);
* \(m=3\): simultaneous failures of \(\kappa,\lambda,\mu\).

Thus the desired two-coordinate theorem is equivalent to

\[
\operatorname{rad}_{>r}\mathfrak H_r^{(2)}=1
\quad\text{for every }r,
\tag{HCF2}
\]

and a weaker linear-support version is

\[
p\mid\mathfrak H_r^{(2)},\ p>r
\Longrightarrow p\le Cr.
\tag{LHCF2}
\]

Similarly the three-coordinate targets are \((\mathrm{HCF3})\) and \((\mathrm{LHCF3})\) with \(\mathfrak H_r^{(3)}\).

This is a quantifier-preserving reduction: there is no scan, asymptotic approximation, or prime-dependent endpoint parameter left.

The continuant also has the exact reflection

\[
\boxed{
\mathcal N_r(-X-r)=(-1)^r\mathcal N_r(X).
}
\tag{33}
\]

Therefore an endpoint root of multiplicity \(m\) at \(0\pmod p\) is accompanied, for \(p>r\), by a distinct root of the same multiplicity at \(-r\).  This is real extra structure, but by itself it is not enough to rule out multiplicity 3 or 4: it consumes only \(2m\) roots of a degree-\(3r\) polynomial.

## 6. Casoratians: exact identities and the scoped obstruction

For any two sequences \(x,y\), define

\[
D_r(x,y)=r^3(x_{r-1}y_r-x_ry_{r-1}).
\tag{34}
\]

If

\[
Lx=s_x,\qquad Ly=s_y,
\]

then direct substitution of the recurrence gives the discrete Lagrange identity

\[
\boxed{
D_{r+1}(x,y)-D_r(x,y)=x_rs_y(r)-y_rs_x(r).
}
\tag{35}
\]

For \(x=b\), this becomes

\[
D_{r+1}(b,y)-D_r(b,y)=b_rs_y(r).
\tag{36}
\]

Hence the determinant in the question is

\[
\Xi_r=D_r(b,\kappa),
\]

and, because \(L\kappa=-5g\),

\[
\boxed{\Xi_{r+1}-\Xi_r=-5b_rg_r.}
\tag{37}
\]

The next two target-preserving determinants are naturally

\[
\Xi_r^{(2)}=D_r(b,\lambda),
\qquad
\Xi_r^{(3)}=D_r(b,\mu),
\tag{38}
\]

with

\[
\boxed{
\Xi_{r+1}^{(2)}-\Xi_r^{(2)}
=-b_r(A_1\kappa+A_2b)_r,
}
\tag{39}
\]

\[
\boxed{
\Xi_{r+1}^{(3)}-\Xi_r^{(3)}
=-b_r(A_1\lambda+A_2\kappa+A_3b)_r.
}
\tag{40}
\]

At a target \(p\mid b_r\), no two consecutive Apéry numbers vanish modulo \(p\), so \(b_{r-1}\) is a unit.  Since also \(r\) is a unit for \(p>r\),

\[
\boxed{
D_r(b,\tau)\equiv r^3b_{r-1}\tau_r\pmod p.
}
\tag{41}
\]

Thus the ideals generated by

\[
(b_r,\kappa_r,\lambda_r,\mu_r)
\]

and by

\[
(b_r,\Xi_r,\Xi_r^{(2)},\Xi_r^{(3)})
\]

are identical after localization at every target prime \(p>r\).  The Casoratians are excellent coordinate changes, but they do not manufacture an extra transverse equation.

There is a similarly sharp obstruction to the most obvious 3-by-3 rescue.  Let

\[
W_r(b,x,y)=
\det\begin{pmatrix}
 b_{r-1}&x_{r-1}&y_{r-1}\\
 b_r&x_r&y_r\\
 b_{r+1}&x_{r+1}&y_{r+1}
\end{pmatrix}.
\]

Using the recurrence to replace the last row gives

\[
\boxed{
\begin{aligned}
(r+1)^3W_r(b,x,y)
={}&b_{r-1}(x_rs_y-y_rs_x)\\
&-b_r(x_{r-1}s_y-y_{r-1}s_x).
\end{aligned}}
\tag{42}
\]

Consequently, on \(p\mid b_r\), if \(x_r=y_r=0\pmod p\), then

\[
W_r(b,x,y)\equiv0\pmod p.
\tag{43}
\]

So the natural 3-by-3 consecutive-neighbor Casoratian cannot become a unit precisely when both transverse coordinates vanish.  It is not a hidden Bézout certificate; it lies in the same local ideal.

This is the sharp scoped negative result: **ordinary finite consecutive-neighbor Casoratian enlargement does not escape the endpoint-HCF problem.**  A successful proof must use a genuinely new arithmetic identity for the integral continuant derivatives, not merely add another row of the same recurrence.

## 8. Resultants and Archimedean height

A repeated endpoint root certainly forces the ordinary discriminant/resultant to vanish:

\[
p\mid\mathfrak H_r^{(1)}
\Longrightarrow
p\mid\operatorname{Res}(\mathcal N_r,\mathcal N_r').
\tag{44}
\]

Triple and quadruple endpoint roots force the corresponding first subdiscriminants/subresultants to vanish as well.  These are valid global carriers, but they are badly non-sharp for the present purpose for two reasons.

First, they also see repeated roots at every other point, whereas (32) sees only the distinguished endpoint \(X=0\).

Second, their height is much too large to prove a support bound \(p\le Cr\).  From (10), with \(\|\cdot\|_1\) the coefficient \(\ell^1\)-norm,

\[
\|\mathcal N_{r+1}\|_1
\le
\|P(X+r)\|_1\|\mathcal N_r\|_1
+(r+1)^6\|\mathcal N_{r-1}\|_1,
\]

so

\[
\log\|\mathcal N_r\|_1=O(r\log r).
\tag{45}
\]

A degree-\(3r\) Sylvester resultant therefore has at best a generic logarithmic-height bound of order \(O(r^2\log r)\).  That is nowhere near a linear-support theorem.

Even the target itself only gives an exponential Archimedean support bound.  From

\[
b_r=\sum_{k=0}^r\binom rk^2\binom{r+k}k^2
\]

and the elementary estimates \(\binom rk\le2^r\), \(\binom{r+k}k\le4^r\),

\[
0<b_r\le(r+1)64^r.
\tag{46}
\]

Hence any target prime satisfies

\[
p\le(r+1)64^r,
\]

which is rigorous but exponentially weaker than \(p\le Cr\).

Therefore a successful `<= C r` theorem needs a genuinely low-height **endpoint** identity, not the global discriminant and not generic height theory.

## 9. What is proved, what remains

### Proved here

1. The next two universal transverse sequences are \(\lambda=[X^2]U\) and \(\mu=[X^3]U\).
2. Their exact inhomogeneous Apéry recurrences are (5) and (6).
3. Prime-specific endpoint parameters can be removed exactly by the direct/companion projector (20)--(21); the repository's direct/reflected identities (16)--(18) are compatible finite-depth eliminations.
4. The transverse conditions are exactly endpoint-root multiplicity for the single integral continuant \(\mathcal N_r\).
5. All two-neighbor target Casoratians are just unit multiples of the corresponding transverse coordinates.
6. The natural 3-by-3 consecutive Casoratian vanishes on a simultaneous two-transverse zero and therefore cannot rescue the argument.
7. The one-coordinate/unit claim is false at \((p,r)=(11,5)\), while \(\lambda_5\) is a unit there.

### Precisely reduced residual problem

The real next theorem is one of the following.

**Strong HCF2.** Prove

\[
\operatorname{rad}_{>r}\gcd(
\mathcal N_r(0),\mathcal N_r'(0),\mathcal N_r''(0))=1.
\]

If false, classify its prime support and prove

\[
p\mid\gcd(
\mathcal N_r(0),\mathcal N_r'(0),\mathcal N_r''(0)),\quad p>r
\Longrightarrow p\le Cr.
\]

If that also fails, move to **HCF3** with \(\mathcal N_r'''(0)\) included.

This is strictly narrower than searching arbitrary Hecke defects: it is a fixed integral-continuant endpoint problem with no \(p\)-dependent coefficients.

I do not see a proof in the current repository of HCF2/HCF3, and the identities above do not imply one.  Claiming that two or three transverse directions already give a global Bézout identity would therefore be premature.

## 10. Verifier-ready exact code

The following uses only the Python standard library.  It reconstructs the characteristic-zero shifted jets, verifies (4)--(6), constructs the integral continuant, and certifies the \((11,5)\) counterexample and its exact double-root multiplicity.

```python
#!/usr/bin/env python3
from fractions import Fraction as F
from math import comb, factorial

ORDER = 4


def P(n):
    return 34*n**3 + 51*n**2 + 27*n + 5


def P1(n):
    return 102*n**2 + 102*n + 27


def add(a, b):
    return [a[i] + b[i] for i in range(ORDER)]


def sub(a, b):
    return [a[i] - b[i] for i in range(ORDER)]


def mul(a, b):
    out = [F(0) for _ in range(ORDER)]
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            if i + j >= ORDER:
                break
            out[i+j] += x*y
    return out


def inv_shift_cube(s):
    return [
        F((-1)**j * comb(j+2, 2), s**(j+3))
        for j in range(ORDER)
    ]


def shifted_P(s):
    return [F(P(s)), F(P1(s)), F(102*s + 51), F(34)]


def shifted_cube(s):
    return [F(s**3), F(3*s**2), F(3*s), F(1)]


def direct_jets(limit):
    one = [F(1), F(0), F(0), F(0)]
    p_at_x = [F(5), F(27), F(51), F(34)]
    U = [one, mul(p_at_x, inv_shift_cube(1))]
    for r in range(1, limit):
        num = sub(
            mul(shifted_P(r), U[r]),
            mul(shifted_cube(r), U[r-1]),
        )
        U.append(mul(num, inv_shift_cube(r+1)))
    return U


def L(seq, r):
    return (r+1)**3*seq[r+1] - P(r)*seq[r] + r**3*seq[r-1]


def A1(seq, r):
    return 3*(r+1)**2*seq[r+1] - P1(r)*seq[r] + 3*r**2*seq[r-1]


def A2(seq, r):
    return 3*(r+1)*seq[r+1] - (102*r+51)*seq[r] + 3*r*seq[r-1]


def A3(seq, r):
    return seq[r+1] - 34*seq[r] + seq[r-1]


def modq(x, p):
    x = F(x)
    assert x.denominator % p
    return (x.numerator * pow(x.denominator, -1, p)) % p


# Integer polynomial helpers, coefficients low-to-high.
def trim(a):
    while len(a) > 1 and a[-1] == 0:
        a.pop()
    return a


def pmul(a, b):
    out = [0]*(len(a)+len(b)-1)
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            out[i+j] += x*y
    return trim(out)


def psub(a, b):
    n = max(len(a), len(b))
    out = [0]*n
    for i in range(n):
        out[i] = (a[i] if i < len(a) else 0) - (b[i] if i < len(b) else 0)
    return trim(out)


def pshift(s):
    return [P(s), P1(s), 102*s+51, 34]


def xplus6(s):
    return [comb(6, j)*s**(6-j) for j in range(7)]


def continuants(limit):
    N = [[1], [5, 27, 51, 34]]
    for r in range(1, limit):
        N.append(psub(pmul(pshift(r), N[r]), pmul(xplus6(r), N[r-1])))
    return N


def deriv0(poly, j):
    return factorial(j)*poly[j] if j < len(poly) else 0
```

## Bottom line

The next transverse layer is not mysterious:

\[
\boxed{
\kappa=[X]U,\qquad
\lambda=[X^2]U,\qquad
\mu=[X^3]U.
}
\]

The endpoint variables are removable before reduction, and the entire question is equivalent to the multiplicity of the distinguished root \(X=0\) of the explicit integral continuant \(\mathcal N_r\) modulo target primes.

The strongest justified conclusion at current repository state is therefore:

> **Transverse reduction theorem.**  For every prime \(p>r\), \(p\ge5\), the first \(m\le3\) post-grid transverse coordinates vanish on the Apéry target \(p\mid b_r\) iff \(X=0\) is a root of multiplicity at least \(m+1\) of \(\mathcal N_r(X)\bmod p\).  All standard two-neighbor Casoratians give an equivalent local ideal, and the consecutive 3-by-3 Casoratian supplies no additional equation.  The one-coordinate unit claim is false at \((11,5)\).  Proving that two or three coordinates suffice is exactly HCF2/HCF3 above.

That HCF problem is the next genuinely arithmetic seam.
