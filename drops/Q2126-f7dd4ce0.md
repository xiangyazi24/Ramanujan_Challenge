# 1. The exact cohomological form of a fundamental-cycle basis

Let `G` be one connected component of the physical multigraph.  Give every physical edge a reference direction and let

```text
sigma(e) in Z
```

be its signed orientation label in that direction.  Reversing the traversal changes the sign.

For an oriented cycle `C`, define the orientation imbalance by

```text
S(C) = sum_{e in C} epsilon_C(e)*sigma(e),
```

where `epsilon_C(e)=+1` or `-1` according to whether `C` traverses `e` with or against its reference direction.

Fix a spanning tree `T` and a root `o`.  There is a unique integer potential `phi_T` on the vertices, normalized by

```text
phi_T(o) = 0,
```

such that every tree edge is killed by the gauge transform:

```text
sigma(e) - (phi_T(head(e)) - phi_T(tail(e))) = 0
    for every e in T.
```

For a chord `e`, its fundamental cycle is the chord plus the unique tree path between its endpoints.  Therefore its imbalance is exactly the reduced cochain value on the chord:

```text
S(C_e)
 = sigma(e) - (phi_T(head(e)) - phi_T(tail(e))).          (1)
```

Hence

```text
U_T
 = { e notin T : S(C_e) != 0 }
 = supp(sigma - d phi_T).                                (2)
```

The last equality is literal because every tree edge has reduced value zero.

This gives an exact graph invariant for the optimization problem:

```text
delta_0(G,sigma)
 := min_T |U_T|
  = min_{phi : zero(sigma-d phi) contains a spanning tree}
      |supp(sigma-d phi)|.                               (3)
```

Thus the right abstraction is not ordinary low stretch.  It is the `l^0` distance of the signed edge cochain from the cut/coboundary space, with the zero-support graph required to span.

## Why `rank(S)=1` does not help

The cycle map

```text
S : H_1(G,Z) -> Z
```

has image of rank at most one simply because the target has rank one.  If it is nonzero, its rank is one.

But rank says nothing about the support norm in (3).  Algebraically one can choose a Smith-normal-form basis of the free abelian group `H_1` with only one basis vector mapping nontrivially to `Z`.  Such a basis is obtained by *subtracting integer cycle chains*.  The carrier inequality is positive-support bookkeeping; it does not permit those subtractions to cancel charge.

The unsafe inference is therefore

```text
rank(S)=1
  -/->
there is a fundamental-cycle basis with |U_T|<=1.        (4)
```

The family below makes the failure quadratic.

# 2. A physical dyadic-shell bidirected block

Fix a dyadic gap scale `D`, divisible by `8`, and choose

```text
1 <= m <= D/8.
```

Place two sets of physical vertices on the ordered line:

```text
A_i at x(A_i) = i,
B_j at x(B_j) = 3*D/4 + j,

1 <= i,j <= m.                                           (5)
```

For every cross-pair `(A_i,B_j)`, its physical gap satisfies

```text
d_ij = x(B_j)-x(A_i)
     = 3*D/4 + j-i.
```

Since `m<=D/8`,

```text
5*D/8 < d_ij < 7*D/8,
```

and in particular

```text
D/2 < d_ij < D.                                          (6)
```

So **every edge is in one dyadic shell**; there is no long/short mixing hidden in the construction.

For each cross-pair keep both physical opposite edges as distinct edges of the multigraph:

```text
e^+_{ij} : A_i -> B_j,
e^-_{ij} : B_j -> A_i.                                   (7)
```

Use `A_i -> B_j` as the canonical direction.  Then the signed cochain values are

```text
sigma(e^+_{ij}) = +1,
sigma(e^-_{ij}) = -1.                                    (8)
```

All vertices may be declared active.  Their carrier labels can be chosen in one common admissible `M`-shell; the obstruction below never uses variation in `h_i` or `M_i`.  If the physical DAP definition requires reflected mates, adjoin the reflected copy as well.  Adding reflected vertices/edges cannot remove the lower bound below, because the proof is pairwise on the preserved opposite edges.

This is a **DAP-geometry fixture**, not an assertion that the actual Apéry divisibility predicates select all these edges simultaneously.

A useful extra check is that even a standard linear per-gap capacity does not exclude the block.  For any fixed gap `d`, at most `m` cross-pairs in (5) have that gap.  Thus, for example, whenever the older P3.2 degree budget is relevant,

```text
multiplicity(d) <= m <= D/8 < 3*(d-1)                    (9)
```

for large `D`, because every used `d>D/2`.

So the obstruction is not created by putting quadratically many edges under one gap label.

# 3. Every spanning tree has `m^2` unbalanced fundamental chords

Let `T` be **any** spanning tree of the full multigraph, possibly after adding any extra physical/reflection/closure edges.  Let `phi_T` be its tree potential.

For one fixed cross-pair `(A_i,B_j)`, abbreviate

```text
t_ij = phi_T(B_j) - phi_T(A_i).
```

By (1), the two reduced cochain values are

```text
rho^+_ij =  1 - t_ij,
rho^-_ij = -1 - t_ij.                                   (10)
```

They differ by exactly two:

```text
rho^+_ij - rho^-_ij = 2.                                (11)
```

Therefore they cannot both vanish.  At least one of the two opposite physical edges has nonzero reduced value.

A nonzero reduced edge cannot be a tree edge, because every tree edge has reduced value zero by construction.  Thus for **each** of the `m^2` unordered cross-pairs, at least one physical edge is a chord in `U_T`.

Hence

```text
|U_T| >= m^2                                             (12)
```

for every spanning tree `T`.

This lower bound is sharp.  Set

```text
phi(A_i)=0 for every i,
phi(B_j)=1 for every j.                                  (13)
```

Then every forward edge has reduced value zero and every reverse edge has reduced value `-2`:

```text
rho^+_ij = 0,
rho^-_ij = -2.                                           (14)
```

The zero forward edges form the complete bipartite graph `K_{m,m}`, so they contain a spanning tree.  Choose such a tree.  Then precisely the `m^2` reverse edges are unbalanced, while every remaining forward chord is balanced.

Therefore the exact optimum is

```text
min_T |U_T| = m^2.                                      (15)
```

No shortest-path choice, BFS tree, DFS tree, low-stretch tree, ear ordering, or other spanning-tree optimization can beat (15).

## Betti-number check

The core has

```text
|V| = 2m,
|E| = 2m^2,

beta(G) = |E|-|V|+1
        = 2m^2-2m+1.                                    (16)
```

For the minimizing tree in (13)-(15), the exact decomposition required in Q2126 gives

```text
beta(H)
 = beta(G)-|U_T|
 = m^2-2m+1
 = (m-1)^2.                                              (17)
```

So there is no conflict with

```text
beta(G) = |U_T| + beta(H).
```

Both pieces are quadratic.

## Rank check

The two parallel opposite edges for any fixed pair form a physical two-edge cycle.  Traversing each edge in its own physical direction gives imbalance `2`.  Thus `S` is nonzero.  Since

```text
S : H_1(G,Z) -> Z,
```

its image has rank exactly one:

```text
rank(im S) = 1.                                         (18)
```

Combining (15) and (18):

```text
rank(im S)=1
but
min_T |U_T|=m^2.                                        (19)
```

This is the requested explicit certificate against the `rank(S)=1 => |U_T|<=1` mistake.

# 6. Why the natural graph-theoretic repairs do not close this

## 6.1 Shortest-path or low-stretch spanning trees

Low stretch controls path length.  The obstruction (10)-(12) is different: for each opposite pair, one of two physical edges is cohomologically defective under **every** potential.  Even a path of length one cannot make both signs gradient-compatible.

Thus a low-stretch theorem cannot change

```text
min_T |U_T| = m^2.
```

## 6.2 Ear decompositions

An ear decomposition changes the order in which cycles are exposed.  It does not change the fact that the two reduced values for an opposite pair differ by two.  One defect per pair remains.

## 6.3 A general cycle basis / Smith normal form

Because the map `S` has rank one, abstract homology does split as

```text
H_1(G,Z) ~= ker(S) + Z*z_0                            (34)
```

(up to the image-index normalization).  This is an algebraic statement about integer chains.

But obtaining the kernel generators in (34) uses additions and subtractions of physical cycles.  The carrier theorem is a one-sided positive inequality on the active support of an actual physical cycle.  There is no valid cancellation rule of the form

```text
carrier(C_1 - C_2)
 <= carrier(C_1) - carrier(C_2).                        (35)
```

Hence Smith reduction does not turn the positive fundamental-cycle ledger into a one-cycle ledger.

A new theorem would be needed saying that the kernel in (34) has a **simple, physical, positivity-compatible, low-overlap** generating set.  That theorem is not a consequence of rank one.

## 6.4 Inactive reflection vertices

The counterexample does not exploit an ambiguity about inactive reflections: its core can be taken active.  Therefore proving that some reflection vertices are inactive cannot repair (15).

If the actual DAP involution forces additional inactive reflected vertices, adjoining them only adds structure.  It does not alter the pairwise equation (10) on the retained active core.

# 7. The smallest additional lemma actually needed

There are two useful levels of statement.

## 7.1 Exact count-level statement: selected cochain sparsity

For the **actual Apéry-selected** DAP graph `G_N` and its signed cochain `sigma_N`, define

```text
delta_sel(N)
 := min_{phi}
      #{ e selected :
           sigma_N(e) != phi(head(e))-phi(tail(e)) },    (36)
```

where the minimum is restricted to potentials for which the zero-defect selected edges contain a spanning forest of every physical connected component.

By (1)-(3), this is not merely sufficient; it is exactly the optimized fundamental-cycle count:

```text
delta_sel(N) = min_T |U_T|.                             (37)
```

Thus the clean missing arithmetic lemma is

```text
[APERy-SELECTED-COCHAIN-SPARSITY]

delta_sel(N) = o(N/loglog N).                           (38)
```

This is the smallest count-level statement that closes the unbalanced part of the decomposition by this route.

It is **not prime geometry alone**.  It must use that an edge is genuinely Apéry-selected.  The bidirected block proves that shell location, opposite-edge bookkeeping, signs, and rank-one cohomology do not imply (38).

A dyadic version, often more natural for proof, is

```text
sum_{dyadic shells D} delta_sel(N;D)
  = o(N/loglog N),                                      (39)
```

with compatible potentials/forest gluing across the shell decomposition.

## 7.2 Exact carrier-level statement: weighted selected congestion

If one wants to close specifically by summing the normalized carrier inequalities, define

```text
K_5(N)
 := min_T sum_{i active} w_i^(5)*mu_T(i).               (40)
```

Then (30) shows that the exact sufficient target is

```text
[APERy-SELECTED-WEIGHTED-CONGESTION]

K_5(N)
 = o(N*log N/loglog N).                                 (41)
```

Indeed

```text
|U_T|
 <= K_5(N)/log N
 = o(N/loglog N).                                       (42)
```

If the local files already provide a single-copy budget

```text
W_5(N) := sum_{i active} w_i^(5) = O(N),                (43)
```

then a convenient stronger but more recognizable condition is

```text
there exists T such that
sum_i w_i^(5)*mu_T(i)
 <= kappa_N * W_5(N),

kappa_N = o(log N/loglog N).                            (44)
```

The bidirected block has `kappa_N = Omega(m)`, so it sharply identifies what must be ruled out.

## 7.3 The first arithmetic sublemma to attack

The smallest obstruction visible already at two physical edges is opposite-edge anti-coexistence.  Let

```text
B_sel(N;D)
 = # { unordered endpoint pairs {u,v} in shell D :
       both opposite physical DAP edges u->v and v->u
       are Apéry-selected }.                            (45)
```

For every tree/potential, one of the two is defective, so

```text
min_T |U_T| >= sum_D B_sel(N;D).                        (46)
```

Therefore (38) **requires**, at minimum,

```text
sum_D B_sel(N;D) = o(N/loglog N).                       (47)
```

This is a concrete first selectedness theorem to test.  But (47) alone is not the full repair: dense one-direction signed graphs can also be far from the cut space.  The genuinely route-closing statement is (38), or its weighted form (41).

So the hierarchy is

```text
prime/dyadic physical geometry
    does NOT imply low congestion;

opposite-edge selected anti-coexistence (47)
    kills the smallest two-edge obstruction only;

selected cochain sparsity (38)
    closes |U_T| exactly;

weighted selected congestion (41)
    closes the carrier-ledger route directly.           (48)
```

# 9. Final assessment

The sought low-congestion inequality does not follow from the graph/cycle machinery presently visible in Q2126.

The decisive exact identities are

```text
U_T = supp(sigma-d phi_T),

min_T |U_T|
 = min_{phi, zero graph spanning} |supp(sigma-d phi)|,   (58)
```

and the bidirected shell block has

```text
rank(im S)=1,
min_T |U_T|=m^2.                                        (59)
```

Thus the failure is not an unfortunate choice of tree path.  It is a genuine signed-cohomology support obstruction.

The normalized second-jet improvement changes

```text
(h_i-1)*log(311) + 7*log M_i
```

to

```text
(h_i-1)*log(311) + 5*log M_i,                           (60)
```

but positive reuse remains untouched.

So the next theorem should be arithmetic, not graph-theoretic:

```text
[APERy-SELECTED-COCHAIN-SPARSITY]
min_T |U_T| = o(N/loglog N),                            (61)
```

or, if one wants to preserve the carrier route explicitly,

```text
[APERy-SELECTED-WEIGHTED-CONGESTION]
min_T sum_{i active}
  ((h_i-1)*log(311)+5*log M_i)*mu_T(i)
    = o(N*log N/loglog N).                              (62)
```

A plausible first local test is the necessary opposite-edge anti-coexistence estimate (47).  But no prime/dyadic geometry statement should be promoted to an Apéry-selected theorem without proving the selection condition itself.

**Bottom line:** option **(B)**.  The physical signed-shell ledger admits an explicit quadratic obstruction, robust under every spanning-tree choice.  The missing repair is a selectedness theorem asserting that the actual DAP orientation cochain is sparse modulo coboundaries; rank one, reflection, and the `7 -> 5` local denominator improvement do not supply it.
