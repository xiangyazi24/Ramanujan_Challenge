# Q2576 — a global resolvent–Apéry content mechanism

## Verdict

There is a clean, genuinely cross-prime carrier that sees every private singleton prime in the fixed-
\(q\) slice without asking for a second zero, a collision, or any same-characteristic incidence:

\[
R_n:=\sum_{k=1}^{n}\frac{b_{n-k}}{k},\qquad
\Lambda_n:=\operatorname{lcm}(1,\dots,n),\qquad
N_n:=\Lambda_nR_n\in\mathbf Z,
\]

and

\[
\Gamma_n:=\gcd(b_n,N_n).
\]

For every fixed positive integer \(q\), and all sufficiently large \(n\), the complete bad-prime radical
in

\[
I_q(n):=\left(\frac{n}{q+1},\frac nq\right]
\]

divides \(\Gamma_n\). In fact, on that slice, divisibility by \(\Gamma_n\) is exactly divisibility by
\(b_n\). Therefore

\[
\#\{p\in I_q(n):p\mid b_n\}
\le
\frac{\log \Gamma_n}{\log (n/(q+1))}.
\]

Consequently the single, \(q\)-free estimate

\[
\boxed{\log\gcd\!\left(b_n,\Lambda_n\sum_{k=1}^{n}\frac{b_{n-k}}k\right)=o(n)}
\tag{RA-PC}
\]

would prove the requested target simultaneously for every fixed \(q\).

I prove the carrier theorem completely below. I do **not** prove (RA-PC). The exact remaining
algebraic task is the subexponential primitive-content/saturation estimate (RA-PC), equivalently the
valuation first moment

\[
\sum_{\ell\ \mathrm{prime}}
\min\{v_\ell(b_n),v_\ell(N_n)\}\log\ell=o(n).
\tag{RA-V}
\]

This is not another local resultant or local coprimality reformulation. It is one characteristic-zero
integer ideal whose index multiplies contributions from all characteristics, all quotient slices, all
prime powers, and possible nuisance primes at once. The private-singleton countermodel defeats any
attempt to deduce (RA-PC) from local zero/collision data; it does not defeat the implication
(RA-PC) \(\Rightarrow\) the required fixed-\(q\) estimate.

## 1. Normalization

Let

\[
P(m)=34m^3+51m^2+27m+5
\]

and let the Apéry numbers be normalized by

\[
b_{-1}=0,\qquad b_0=1,
\]

\[
(m+1)^3b_{m+1}=P(m)b_m-m^3b_{m-1}\qquad(m\ge0).
\tag{1.1}
\]

Equivalently,

\[
b_m=\sum_{j=0}^{m}\binom mj^2\binom{m+j}{j}^2\in\mathbf Z.
\]

I use the Apéry–Lucas congruence in its one-digit form:

\[
b_{ap+r}\equiv b_a b_r\pmod p,
\qquad 0\le r<p,
\tag{1.2}
\]

for every prime \(p\).

For \(n\ge1\), put

\[
\Lambda_n=\operatorname{lcm}(1,\dots,n),
\qquad
R_n=\sum_{k=1}^{n}\frac{b_{n-k}}k,
\qquad
N_n=\Lambda_nR_n
     =\sum_{k=1}^{n}\frac{\Lambda_n}{k}b_{n-k}.
\tag{1.3}
\]

Thus \(N_n\in\mathbf Z\). Set \(R_0=0\).

For fixed \(q\ge1\), define the exact set in the question:

\[
\mathcal S_q(n)
=
\left\{
 p\text{ prime}:
 \frac{n}{q+1}<p\le\frac nq,
 \ p\mid b_n
\right\}.
\tag{1.4}
\]

No other target will be substituted for (1.4).

## 2. The pole-extraction identity

The key point is that, for \(p\) in a fixed quotient slice, the \(p\)-part of the harmonic
convolution is supported at the finitely many indices \(p,2p,\dots,qp\), and Apéry–Lucas makes all
of those residues scalar multiples of the same private value \(b_r\).

### Lemma 2.1 — exact fixed-slice residue

Fix \(q\ge1\). Let \(p\) be prime and write

\[
n=qp+r,\qquad 0\le r<p.
\]

Assume \(p>q\) and \(p^2>n\). Put

\[
U_{n,p}:=\frac{\Lambda_n}{p}.
\]

Then \(p\nmid U_{n,p}\), and in \(\mathbf F_p\)

\[
\boxed{
N_n
\equiv
U_{n,p}\,b_r
\sum_{j=1}^{q}\frac{b_{q-j}}j
\pmod p.
}
\tag{2.1}
\]

Equivalently, in the \(p\)-local sense,

\[
pR_n\equiv b_rR_q\pmod p,
\qquad
R_q=\sum_{j=1}^{q}\frac{b_{q-j}}j.
\tag{2.2}
\]

#### Proof

Because \(p^2>n\), one has \(v_p(\Lambda_n)=1\); hence \(p\nmid U_{n,p}\).
From (1.3),

\[
N_n=\sum_{k=1}^{n}\frac{\Lambda_n}{k}b_{n-k}.
\]

If \(p\nmid k\), then \(\Lambda_n/k\) is divisible by \(p\), so that summand is zero modulo \(p\).
The multiples of \(p\) in \([1,n]\) are exactly \(k=jp\), \(1\le j\le q\). Therefore

\[
N_n
\equiv
\sum_{j=1}^{q}\frac{\Lambda_n}{jp}b_{n-jp}
\equiv
U_{n,p}\sum_{j=1}^{q}j^{-1}b_{(q-j)p+r}
\pmod p.
\]

Here \(j^{-1}\) is legitimate because \(p>q\ge j\). Applying (1.2) gives

\[
b_{(q-j)p+r}\equiv b_{q-j}b_r\pmod p,
\]

which yields (2.1). Dividing by the \(p\)-unit \(U_{n,p}\) gives (2.2). ∎

The important feature is not that (2.1) gives several local equations—it does not. The whole
principal part has rank one, exactly as the private-singleton and Franel/Smith analyses warn. The
important feature is that the cleared numerator \(N_n\) is one **common integer for all primes**.

## 3. The cross-prime carrier theorem

### Theorem 3.1 — all private singleton primes enter one integer gcd

For every fixed positive integer \(q\), there exists \(n_0(q)\) such that, for every
\(n\ge n_0(q)\),

\[
\boxed{
\prod_{p\in\mathcal S_q(n)}p
\ \Bigm|\ 
\Gamma_n:=\gcd(b_n,N_n).
}
\tag{3.1}
\]

Moreover, for every prime \(p\in I_q(n)\) and all \(n\ge n_0(q)\),

\[
\boxed{
p\mid b_n\quad\Longleftrightarrow\quad p\mid\Gamma_n.
}
\tag{3.2}
\]

Thus, on the fixed slice, the squarefree \(p\)-support of \(\Gamma_n\) is exactly the required bad-prime
set.

#### Proof

Since \(q\) is fixed and \(b_q\ne0\), choose \(n_0(q)\) so large that whenever \(n\ge n_0(q)\) and
\(p>n/(q+1)\), all of the following hold:

\[
p>q,\qquad p^2>n,\qquad p\nmid b_q.
\tag{3.3}
\]

For example it is enough to take \(n_0(q)\) larger than

\[
(q+1)^2
\quad\text{and}\quad
(q+1)P^+(b_q),
\]

where \(P^+(b_q)\) denotes the largest prime divisor of \(b_q\), with the harmless convention
\(P^+(1)=1\).

Take \(p\in\mathcal S_q(n)\). The slice inequalities imply

\[
\left\lfloor\frac np\right\rfloor=q,
\]

so write \(n=qp+r\), \(0\le r<p\). By Apéry–Lucas,

\[
0\equiv b_n\equiv b_qb_r\pmod p.
\]

The last condition in (3.3) gives

\[
b_r\equiv0\pmod p.
\tag{3.4}
\]

Substituting (3.4) into Lemma 2.1 gives \(N_n\equiv0\pmod p\). Hence \(p\) divides both \(b_n\)
and \(N_n\), so \(p\mid\Gamma_n\). Distinct primes are pairwise coprime, proving (3.1).

The forward implication in (3.2) is exactly the preceding argument. The reverse implication is
immediate from the definition of \(\Gamma_n\): \(p\mid\Gamma_n\) implies \(p\mid b_n\). ∎

### Corollary 3.2 — exact first-moment bound

For every fixed \(q\), all sufficiently large \(n\) satisfy

\[
\boxed{
|\mathcal S_q(n)|
\le
\frac{\log\Gamma_n}{\log(n/(q+1))}.
}
\tag{3.5}
\]

#### Proof

By (3.1),

\[
\sum_{p\in\mathcal S_q(n)}\log p
\le\log\Gamma_n.
\]

Every \(p\in\mathcal S_q(n)\) is greater than \(n/(q+1)\), so

\[
|\mathcal S_q(n)|\log(n/(q+1))
<
\sum_{p\in\mathcal S_q(n)}\log p.
\]

Combine the two inequalities. ∎

## 4. The single missing global estimate

The integer \(\Gamma_n\) has the exact product formula

\[
\Gamma_n
=
\prod_{\ell\ \mathrm{prime}}
\ell^{\min(v_\ell(b_n),v_\ell(N_n))},
\tag{4.1}
\]

and hence

\[
\log\Gamma_n
=
\sum_{\ell\ \mathrm{prime}}
\min(v_\ell(b_n),v_\ell(N_n))\log\ell.
\tag{4.2}
\]

This is a literal first moment over varying primes. It counts a private singleton prime once even if
that prime has no second zero, no collision, no restart, and no interaction with any other prime.

### Conjectural algebraic estimate (RA-PC)

For every \(arepsilon>0\), there exists \(n_1(\varepsilon)\) such that for all
\(n\ge n_1(\varepsilon)\),

\[
\boxed{
\gcd(b_n,N_n)\le e^{\varepsilon n}.
}
\tag{4.3}
\]

Equivalently, (4.2) is \(o(n)\).

### Proposition 4.1 — (RA-PC) proves the exact target

If (4.3) holds, then for every fixed positive integer \(q\),

\[
\#\left\{p\in\left(\frac{n}{q+1},\frac nq\right]:p\mid b_n\right\}
=o_q\!\left(\frac n{\log n}\right).
\tag{4.4}
\]

#### Proof

By Corollary 3.2,

\[
\frac{|\mathcal S_q(n)|}{n/\log n}
\le
\frac{\log\Gamma_n}{n}
\frac{\log n}{\log(n/(q+1))}.
\]

The first factor tends to \(0\) by (RA-PC), while the second tends to \(1\) for fixed \(q\). ∎

### Why this is not a renaming of the fixed-\(q\) target

The fixed-\(q\) target controls only the squarefree primes in one interval \(I_q(n)\). In contrast,
(RA-PC) controls simultaneously:

1. all quotient slices \(q\), including \(q=q(n)\to\infty\);
2. all small primes;
3. all prime-power multiplicities;
4. primes outside \([1,n]\) that happen to divide both integers;
5. all fixed \(q\) with one \(q\)-independent estimate.

Thus all fixed-\(q\) conclusions could hold while (RA-PC) failed because of small primes, moving
quotient classes, or high powers. The implication is strictly one-way. The gain is that (RA-PC) is a
single characteristic-zero primitive-content statement for an explicitly holonomic pair, rather than
a family of local zero-count assertions.

In ideal language,

\[
(b_n,N_n)=\Gamma_n\mathbf Z,
\]

so (RA-PC) says that the index

\[
[\mathbf Z:(b_n,N_n)]
\]

is subexponential. A successful proof can therefore be given by an explicit Bézout/adjoint
certificate

\[
U_nb_n+V_nN_n=H_n\ne0,
\qquad
|H_n|=e^{o(n)},
\tag{4.5}
\]

with \(U_n,V_n,H_n\in\mathbf Z\). Equation (4.5) is coefficientwise checkable; every private bad
prime divides its left side, and hence divides the single small integer \(H_n\).

## 5. Exact denominator saturation over the whole prefix

The resolvent is not an arbitrary auxiliary sequence. Its denominators retain the full harmonic
lcm globally.

### Lemma 5.1 — prefix denominator lcm is exactly maximal

Write \(R_m=A_m/D_m\) in lowest terms with \(D_m>0\). Then for every \(n\ge1\),

\[
\boxed{
\operatorname{lcm}(D_1,D_2,\dots,D_n)=\Lambda_n.
}
\tag{5.1}
\]

#### Proof

Let

\[
B(x)=\sum_{m\ge0}b_mx^m\in1+x\mathbf Z[[x]],
\qquad
H(x)=\sum_{k\ge1}\frac{x^k}{k}=-\log(1-x).
\]

Then

\[
F(x):=B(x)H(x)=\sum_{m\ge0}R_mx^m.
\tag{5.2}
\]

Because \(B(0)=1\) and \(B\in\mathbf Z[[x]]\), its formal inverse

\[
C(x)=B(x)^{-1}=\sum_{j\ge0}c_jx^j
\]

also lies in \(\mathbf Z[[x]]\). Hence

\[
H(x)=C(x)F(x).
\]

Taking the coefficient of \(x^m\) gives

\[
\frac1m=\sum_{j=0}^{m}c_jR_{m-j}.
\tag{5.3}
\]

Let \(E_n=\operatorname{lcm}(D_1,\dots,D_n)\). Since every term on the right side of (5.3) has
denominator dividing \(E_n\), the reduced denominator \(m\) of \(1/m\) divides \(E_n\). This holds
for every \(m\le n\), so \(\Lambda_n\mid E_n\).

Conversely, \(D_m\mid\Lambda_m\mid\Lambda_n\) follows directly from (1.3), giving
\(E_n\mid\Lambda_n\). Therefore \(E_n=\Lambda_n\). ∎

### Interpretation

For \(p>\sqrt n\), one has \(v_p(\Lambda_n)=1\). Such a prime is absent from the reduced
denominator of \(R_n\) exactly when \(p\mid N_n\). Theorem 3.1 therefore says:

> a bad prime in a fixed quotient slice is simultaneously a divisor of \(b_n\) and a missing
> denominator prime of \(R_n\).

Lemma 5.1 shows that denominator mass cannot disappear from the entire prefix. It must reappear at
some earlier coefficient. This is a genuine cross-index rigidity statement, but it is **not** by itself
enough for the pointwise target: a private singleton prime may disappear at the one prescribed index
\(n\) and reappear at a neighboring index. This is exactly where a global saturation estimate such as
(RA-PC), rather than a local zero-count argument, is required.

## 6. Exact Ore system for \(b_n\) and \(R_n\)

The remaining estimate (RA-PC) is attached to a completely explicit triangular Ore module. No
appeal to the generic slogan “D-finite implies a recurrence” is needed.

Let

\[
\theta=x\frac{d}{dx}
\]

and

\[
L
=
\theta^3
-x(2\theta+1)(17\theta^2+17\theta+5)
+x^2(\theta+1)^3.
\tag{6.1}
\]

Then \(LB=0\). Write

\[
L=a_3\theta^3+a_2\theta^2+a_1\theta+a_0,
\]

where

\[
a_3=1-34x+x^2,
\quad
a_2=-51x+3x^2,
\quad
a_1=-27x+3x^2,
\quad
a_0=-5x+x^2.
\tag{6.2}
\]

Since \(F=BH\) and \(LB=0\), the Leibniz rule gives

\[
LF=C_2(x)\theta^2B+C_1(x)\theta B+C_0(x)B,
\tag{6.3}
\]

with the explicit rational functions

\[
C_2(x)=\frac{3x(1-34x+x^2)}{1-x},
\tag{6.4}
\]

\[
C_1(x)=
\frac{3x(1-68x+37x^2-2x^3)}{(1-x)^2},
\tag{6.5}
\]

\[
C_0(x)=
\frac{x(1-111x+78x^2-35x^3+3x^4)}{(1-x)^3}.
\tag{6.6}
\]

Indeed,

\[
\theta H=\frac{x}{1-x},
\qquad
\theta^2H=\frac{x}{(1-x)^2},
\qquad
\theta^3H=\frac{x(1+x)}{(1-x)^3},
\]

and

\[
\begin{aligned}
L(BH)
={}&3a_3(\theta^2B)(\theta H)
 +(\theta B)\bigl(3a_3\theta^2H+2a_2\theta H\bigr)\\
&+B\bigl(a_3\theta^3H+a_2\theta^2H+a_1\theta H\bigr),
\end{aligned}
\]

which simplifies to (6.3)–(6.6).

Clearing the only extra denominator gives a polynomial Ore identity:

\[
\boxed{
(1-x)^3LF
=
\widetilde C_2(x)\theta^2B
+\widetilde C_1(x)\theta B
+\widetilde C_0(x)B,
}
\tag{6.7}
\]

where

\[
\widetilde C_2=3x(1-x)^2(1-34x+x^2),
\]

\[
\widetilde C_1=3x(1-x)(1-68x+37x^2-2x^3),
\]

\[
\widetilde C_0=x(1-111x+78x^2-35x^3+3x^4).
\]

Equivalently, the column \((B,F)^{\mathsf T}\) is annihilated by the explicit triangular block
operator

\[
\boxed{
\begin{pmatrix}
(1-x)^3L&0\\
-(\widetilde C_2\theta^2+\widetilde C_1\theta+\widetilde C_0)&(1-x)^3L
\end{pmatrix}.
}
\tag{6.8}
\]

All entries lie in \(\mathbf Z[x,\theta]\).

For direct coefficient checking, put

\[
E_m=[x^m]\bigl(C_2\theta^2B+C_1\theta B+C_0B\bigr)\in\mathbf Z.
\]

Then, for \(m\ge1\),

\[
\boxed{
 m^3R_m-P(m-1)R_{m-1}+(m-1)^3R_{m-2}=E_m,
}
\tag{6.9}
\]

with \(R_0=R_{-1}=0\). Multiplying (6.9) by the appropriate lcm gives an exact integer recurrence
for the normalized state. The unresolved issue is not recurrence existence; it is the subexponential
saturation of the two distinguished coordinates \(b_n\) and \(N_n\).

Thus (RA-PC) is a precise primitive-content theorem for the explicit integral Ore module (6.8).
A proof must use the characteristic-zero lattice/adjoint structure of (6.8), or an equivalent global
product formula, because the local reduction of (6.8) at one prime again has only the rank-one scalar
\(b_r\).

## 7. Companion and Casoratian audit

The companion solution and one-step Casoratians are natural possible second carriers. They do not,
by themselves, add an independent ideal.

Let \(a_n\) be the companion Apéry solution with

\[
a_0=0,\qquad a_1=6,
\]

satisfying the same recurrence (1.1). Its exact Wronskian is

\[
\boxed{
a_nb_{n-1}-a_{n-1}b_n=\frac6{n^3}.}
\tag{7.1}
\]

This proves local isolation of a zero of \(b_n\), but it cannot count private singleton primes.

### 7.1 The \(b\)–\(R\) Casoratian

Define

\[
\omega_n=b_nR_{n-1}-b_{n-1}R_n.
\tag{7.2}
\]

Using (1.1) and (6.9) gives the exact forced first-order identity

\[
\boxed{
(n+1)^3\omega_{n+1}
=n^3\omega_n-b_nE_{n+1}.
}
\tag{7.3}
\]

After lcm clearing,

\[
\Omega_n:=\Lambda_n\omega_n
=b_n(\Lambda_nR_{n-1})-b_{n-1}N_n\in\mathbf Z.
\tag{7.4}
\]

Every prime dividing both \(b_n\) and \(N_n\) divides \(\Omega_n\). However,

\[
\Omega_n\in(b_n,N_n),
\]

so

\[
\gcd(b_n,N_n,\Omega_n)=\gcd(b_n,N_n).
\tag{7.5}
\]

Thus the Casoratian is not a second independent carrier; equation (7.3) merely rewrites the same
content obstruction.

### 7.2 Convolving the companion

Let

\[
R_n^{(a)}=\sum_{k=1}^{n}\frac{a_{n-k}}k,
\]

and use the standard integrality \(\Lambda_n^3a_n\in\mathbf Z\). Then

\[
A_n:=\Lambda_n^3a_n\in\mathbf Z,
\qquad
M_n:=\Lambda_n^4R_n^{(a)}\in\mathbf Z.
\]

The companion determinant

\[
\Delta_n
:=A_nN_n-b_nM_n
=\Lambda_n^4\bigl(a_nR_n-b_nR_n^{(a)}\bigr)
\tag{7.6}
\]

is divisible by every target prime. But again

\[
\Delta_n\in(b_n,N_n),
\qquad
\gcd(b_n,N_n,\Delta_n)=\gcd(b_n,N_n).
\tag{7.7}
\]

Therefore the companion only becomes useful if one proves an **independent** subexponential bound
for a determinant/minor not already lying tautologically in the ideal \((b_n,N_n)\), or constructs a
small nonzero adjoint Bézout boundary as in (4.5). The bare Wronskian or companion convolution does
not supply that bound.

This audit rules out a tempting but invalid claim that “adding the companion gives a second
condition per prime.” It does not; locally the target remains one scalar \(b_r=0\), and globally the
obvious companion determinants remain in the same ideal.

## 8. Hostile audit against the private-singleton countermodel

The private-singleton countermodel must be applied at every implication, not merely mentioned.

### 8.1 What the countermodel destroys

It destroys any deduction of the desired first moment from data of the following forms:

- two-zero or multi-zero incidences at one prime;
- collision energies;
- gap counts;
- restart/cascade counts;
- same-characteristic rank amplification;
- a family of local resultants or coprimality statements.

One can assign each bad prime a private zero pair, make all intersections vanish, and still have
linear union mass.

The committed Franel/Legendre–Euler content and Smith calculations exhibit the same obstruction
algebraically: after removal of universal candidate-prime factors, the selective information has rank
one. A bad non-midpoint prime enters the content to exponent one. No collection of local coefficient
rows automatically supplies a second selective copy.

### 8.2 Why Theorem 3.1 survives

Theorem 3.1 never asks one prime to interact with another and never asks a prime to have a second
zero. A private singleton prime \(p\) is charged once by the literal divisibility

\[
p\mid b_n,\qquad p\mid N_n.
\]

All private primes are then multiplied in the ordinary integer ideal

\[
(b_n,N_n)=\Gamma_n\mathbf Z.
\]

If a private-singleton model has \(c\,n/\log n\) primes in a fixed slice, then, because every such
prime is \(\gg_q n\), it necessarily forces

\[
\log\Gamma_n\ge c_q n+o(n).
\]

Thus that model violates (RA-PC). This is exactly the point: (RA-PC) is a genuinely new global
arithmetic input absent from the local countermodel.

### 8.3 No circular implication

I do **not** infer (RA-PC) from the local singleton, reflection, M1, or collision packages. Doing so
would contradict the countermodel. The proved implication is only

\[
\text{global resolvent–Apéry content estimate (RA-PC)}
\Longrightarrow
\text{the fixed-}q\text{ target}.
\]

The remaining estimate must be proved from the characteristic-zero recurrence/Ore lattice,
denominator structure, a global product formula, or a genuinely cross-prime argument.

### 8.4 M1 simplicity is unnecessary

The proof of Theorem 3.1 uses only first-power divisibility. If a target prime occurs to higher
\(p\)-adic order in either \(b_n\) or \(N_n\), then its contribution to (4.2) is larger, which only
strengthens (3.5). Thus the exceptional-sparse/M1 reduction is compatible with the mechanism but is
not a premise of it.

## 9. A coefficientwise verification recipe

The following checks every algebraic statement above without fitting a recurrence or using a density
model.

### 9.1 Generate \(b_n\), \(R_n\), and \(N_n\)

Use exact rational/integer arithmetic:

```text
b[-1] = 0
b[0]  = 1
for m >= 0:
    b[m+1] = (P(m)*b[m] - m^3*b[m-1]) / (m+1)^3

Lambda[n] = lcm(1,...,n)
R[n]      = sum_{k=1}^n b[n-k]/k
N[n]      = Lambda[n]*R[n]
assert N[n] is integral
Gamma[n]  = gcd(b[n],N[n])
```

### 9.2 Verify the fixed-slice residue

For fixed \(q\), each prime \(p\in I_q(n)\), and \(n\) beyond the explicit threshold:

```text
assert floor(n/p) == q
assert p*p > n
r = n - q*p
U = Lambda[n] / p

lhs = N[n] mod p
rhs = U * sum_{j=1}^q inverse_mod(j,p) * b[n-j*p] mod p
assert lhs == rhs

rhs_lucas = U*b[r] * sum_{j=1}^q inverse_mod(j,p)*b[q-j] mod p
assert lhs == rhs_lucas

if b[n] mod p == 0:
    assert b[q] mod p != 0
    assert b[r] mod p == 0
    assert N[n] mod p == 0
    assert Gamma[n] mod p == 0
```

This verifies the carrier prime by prime, but the conclusion (3.1) is then an exact integer product,
not a local statistical assertion.

### 9.3 Verify prefix denominator saturation

Compute reduced denominators \(D_m\) of \(R_m\) and check

```text
lcm(D[1],...,D[n]) == lcm(1,...,n)
```

Independently compute the inverse coefficients \(c_j\) from

\[
\left(\sum b_mx^m\right)\left(\sum c_jx^j\right)=1
\]

and verify

\[
\frac1m=\sum_{j=0}^{m}c_jR_{m-j}
\]

for every \(m\) in the test range.

### 9.4 Verify the Ore identity

Truncate the formal series \(B,F\) to order \(N\), compute both sides of (6.7), and compare every
coefficient through degree \(N\). This independently verifies (6.9). No recurrence guessing is
involved.

### 9.5 What a successful final certificate would look like

An unconditional completion through this route would output, for every \(n\), exact integers
\(U_n,V_n,H_n\) satisfying

```text
U_n*b_n + V_n*N_n == H_n
H_n != 0
log(abs(H_n))/n -> 0
```

The first line is a finite exact check. The third line is the one missing global estimate.

## 11. Final status

What is proved unconditionally here is:

\[
\boxed{
\prod_{\substack{n/(q+1)<p\le n/q\\p\mid b_n}}p
\mid
\gcd\!\left(
 b_n,
 \Lambda_n\sum_{k=1}^{n}\frac{b_{n-k}}k
\right)
}
\]

for every fixed \(q\) and all sufficiently large \(n\), together with the quantitative consequence
(3.5), the exact prefix denominator theorem (5.1), and the explicit Ore system (6.7)–(6.9).

The one exact algebraic estimate still missing is

\[
\boxed{
\sum_{\ell}
\min\!\left(
 v_\ell(b_n),
 v_\ell\!\left(\Lambda_n\sum_{k=1}^{n}\frac{b_{n-k}}k\right)
\right)
\log\ell=o(n).
}
\]

A proof of this estimate is sufficient for the exact fixed-\(q\) target and is immune to the
private-singleton countermodel. The companion and elementary Casoratian constructions do not yet
prove it because their obvious determinants remain in the same ideal \((b_n,N_n)\).
