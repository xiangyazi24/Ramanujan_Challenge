# 9. Palindromy and primitive returns across the center

There is one useful exact first-return consequence of palindromy.

Let y<0<y+g be a primitive first-return pair in centered coordinates for one characteristic.  Palindromy gives zeros at both

\[
-y
\quad\text{and}\quad
-(y+g).
\]

If \(g>-2y\), then \(-y\) lies strictly between y and y+g, contradicting first-return minimality.
If \(g<-2y\), then \(-(y+g)\) lies strictly between y and y+g, again a contradiction.
Therefore

\[
\boxed{
y<0<y+g\text{ and primitive first return}
\Longrightarrow g=-2y.}
\tag{9.1}
\]

So a primitive return which crosses the center is exactly a palindromic pair.

Every nonpalindromic primitive return stays on one side of the center and can be reflected to the positive branch where (8.3)--(8.5) apply.

The palindromic branch (9.1) does not produce an extra independent divisor: once the first centered zero y is present, the second zero -y is automatic.  This explains why a radical-only attack can still saturate even though the resonance itself is now deleted by the host/moving Fubini argument.
