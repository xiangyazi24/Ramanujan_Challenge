# 2. Repair of the hard folded-coordinate rigidity lemma

Fix \(X\le m<X^2\) and a hard hit

\[
p\in\mathcal P_X,
\qquad p>2\sqrt m,
\qquad r:=m\bmod p\in\mathcal Z_p.
\]

Put

\[
s=s_p(m):=\min\{r,p-1-r\}.
\tag{2.1}
\]

Canonical palindromy gives \(p\mid b_s\), and \(s<(p/2)<X\).
There are two **actual orientations**.

### Orientation I: the row residue is canonical

Suppose

\[
r=s.
\]

Then \(p\mid m-s\).  Crucially,

\[
\boxed{m-s>0.}
\tag{2.2}
\]

Indeed, if \(m=s\), then \(r=m\) forces \(p>m\); but because \(r=s\) is the canonical half representative one also has

\[
p\ge2s+1=2m+1.
\]

This contradicts

\[
p\le2X\le2m
\]

because \(m\ge X\).

Therefore, if distinct hard primes \(p,q\) both have actual row residue equal to the same canonical \(s\), then

\[
pq\mid m-s,
\qquad
0<m-s<m<4m<pq,
\]

a contradiction.  Hence at most one hard hit prime has this orientation at a fixed \((m,s)\).

### Orientation II: the row residue is reflected

Suppose

\[
r=p-1-s.
\]

Then

\[
p\mid m+s+1.
\]

If distinct hard primes \(p,q\) had this same canonical \(s\) and orientation, then

\[
pq\mid m+s+1.
\]

Since \(s<X\le m\),

\[
0<m+s+1\le m+X\le2m<4m<pq,
\]

again impossible.

Thus

\[
\boxed{
\#\{p\text{ hard hit at }m:s_p(m)=s\}\le2.}
\tag{2.3}
\]

This is the statement Q4618 actually needs.

## 2.1 The defect in Q4618's stronger auxiliary sets

Q4618 introduced

\[
\mathcal Q^-_{m,s}
=\{p:p\text{ hard},\ p\mid b_s,\ p\mid m-s\}
\]

without requiring that \(m\bmod p=s\) be the canonical orientation, and asserted \(|\mathcal Q^-_{m,s}|\le1\) from size.

That proof has a literal zero-carrier hole: if \(m=s\), then \(m-s=0\), and the inequality \(pq>|m-s|\) does not contradict \(pq\mid m-s\).  The stronger auxiliary cardinality claim is therefore not established and should not be inserted.

The repair above avoids the problem because \(m=s\) is impossible in Orientation I for an actual **canonical** folded coordinate in the literal range \(m\ge X\), \(p\le2X\).

The reflected orientation has no analogous zero issue because \(m+s+1>0\).

# 3. Canonical-folded-far is weaker than full orbit-far

For one hard hit define the full reflected zero orbit

\[
\mathcal O_p(m)=\{s_p(m),\ p-1-s_p(m)\}.
\]

Q4618's actual far moment is defined by

\[
|s_{p_i}(m)-s_{p_j}(m)|>H
\qquad(i\ne j).
\tag{3.1}
\]

This is a useful canonical-half separation, but it does **not** imply

\[
\min_{u\in\mathcal O_p(m),\ v\in\mathcal O_q(m)}|u-v|>H.
\tag{3.2}
\]

Indeed, besides the canonical difference \(s_p-s_q\), the other orbit differences include

\[
(p-1-s_p)-(q-1-s_q)
=p-q-(s_p-s_q)
\]

and the two cross-reflected combinations.  These can be small even when \(|s_p-s_q|>H\).

This distinction matters for scope statements: an ordered tuple counted by Q4618's canonical-folded-far moment can still contain an exact common index or a near reflected pair.

It does **not** invalidate Q4618's extraction.  By (2.3), a canonical interval of \(2H+1\) integer coordinates supports only \(O(H)\) hard hits, so a large row still supplies many ordered six-tuples satisfying (3.1).

It also does not let the existing pair theorems close the sixth moment.  A common-index or centered-offset theorem controls the mass of an order-two anchor.  The missing quantity remains the positive fourth extension conditioned on that anchor.

There is a further reason not to silently replace (3.1) by full orbit separation while preserving the literal \(K_X^\sharp\): the definition includes primes \(p>m\), although such primes are irrelevant to \(G_m\).  For two such primes the actual row residue can equal the same integer \(m\), creating a common orbit point even though their canonical half representatives differ.  Adding the consumer-only condition \(p\le m\) would remove this degeneracy, but the present task explicitly asks to preserve the larger literal \(K_X^\sharp\), so I do not make that replacement.

# 4. The hard mask retains the natural first-moment scale

For a prime \(p\in\mathcal P_X\), let

\[
\Omega_p^\sharp
=\{m:X\le m<X^2,\ p>2\sqrt m,\ m\bmod p\in\mathcal Z_p\}.
\]

Because \(p\le2X\), the hard inequality is exactly

\[
m<p^2/4,
\]

and this upper endpoint lies below or at \(X^2\).

Fix \(r\in\mathcal Z_p\).  The representatives \(m\equiv r\pmod p\) in

\[
[X,p^2/4)
\]

form an arithmetic progression.  Its length divided by \(p\) is

\[
\frac{p^2/4-X}{p}
=\frac p4-\frac Xp.
\]

Since \(p>X\), the number of representatives satisfies, for all sufficiently large \(X\),

\[
\frac p4-2
\le
\#\{m\in[X,p^2/4):m\equiv r\pmod p\}
\le
\frac p4+1.
\tag{4.1}
\]

Summing over the distinct zero residues gives

\[
\left(\frac p4-2\right)Z(p)
\le|\Omega_p^\sharp|
\le\left(\frac p4+1\right)Z(p).
\tag{4.2}
\]

Now

\[
\sum_{p\in\mathcal P_X}pZ(p)
=\sum_p p^2\frac{Z(p)}p,
\]

so

\[
X^2\lambda_X
\le\sum_p pZ(p)
\le4X^2\lambda_X.
\tag{4.3}
\]

Consequently

\[
\boxed{
I_1^\sharp(X)
:=\sum_{X\le m<X^2}K_X^\sharp(m)
=\sum_p|\Omega_p^\sharp|
\asymp X^2\lambda_X.}
\tag{4.4}
\]

This is worth recording because it hostile-audits a tempting shortcut: the condition \(p>2\sqrt m\) does **not** make the hard row family sparse by a power.  It retains a constant-density prefix of each periodic column.

In particular, if \(\lambda_X\) is large, the hard pair-anchor scale is also genuinely quadratic in \(\lambda_X\).  Cauchy gives

\[
F_2^\sharp(X)+I_1^\sharp(X)
=\sum_m(K_X^\sharp(m))^2
\ge\frac{(I_1^\sharp(X))^2}{X^2},
\]

so for \(\lambda_X\gg1\),

\[
F_2^\sharp(X)\gg X^2\lambda_X^2,
\]

matching the canonical upper scale \(F_2^\sharp\le F_2\le4X^2\lambda_X^2\) up to constants.

# 5. New unconditional hard high-row tail

Let

\[
L_X=\#\{p\in\mathcal P_X:Z(p)>0\}.
\]

For \(t\ge1\), set

\[
S_t^\sharp
=\{m\in[X,X^2):K_X^\sharp(m)\ge t\}.
\]

The following is a direct hard-row adaptation of the metric high-column argument, but it uses the canonical twin theorem on the **integer rows** rather than on zero-index columns.

## Proposition 5.1 — hard high-row tail

There are absolute constants \(C_1,C_2\) such that, whenever

\[
t\ge C_1\sqrt{L_X},
\]

one has

\[
\boxed{
|S_t^\sharp|
\le C_2\left(
\frac{X^2L_X^2}{t^3}+\frac{L_X}{t}
\right).}
\tag{5.1}
\]

### Proof

The case \(L_X=0\) is empty.  Assume \(L_X>0\).

The canonical `thm:atomtail-twin` says that for

\[
0\le u<v<X^2,
\qquad h=v-u<X,
\]

the number \(W(u,v)\) of window primes hitting both rows satisfies

\[
W(u,v)\le C_0h
\tag{5.2}
\]

for an absolute \(C_0\).  A prime which is hard at both rows is in particular counted by this full \(W(u,v)\), so (5.2) remains a valid upper bound after applying the hard mask.

Choose

\[
\ell_t
=\left\lfloor\frac{t^2}{8C_0L_X}\right\rfloor.
\tag{5.3}
\]

For \(C_1\) large, \(\ell_t\ge1\).  If \(S_t^\sharp\ne\varnothing\), then \(t\le L_X\), and hence

\[
\ell_t\le\frac{L_X}{8C_0}<X
\]

for large \(X\), since \(L_X\le\pi(2X)-\pi(X)\ll X/\log X\).

Partition \([X,X^2)\) into consecutive intervals of length at most \(\ell_t\).  Fix one interval and let

\[
S=S_t^\sharp\cap I,
\qquad s=|S|.
\]

For each active prime \(p\), put

\[
z_p=\#\{m\in S:p\text{ is a hard hit at }m\},
\qquad
E=\sum_pz_p.
\]

Every row in \(S\) has degree at least \(t\), so

\[
E\ge ts.
\tag{5.4}
\]

Cauchy over the \(L_X\) active primes gives

\[
\sum_pz_p(z_p-1)
=\sum_pz_p^2-E
\ge\frac{E^2}{L_X}-E.
\tag{5.5}
\]

The same left side counts ordered triples \((p,u,v)\) with distinct rows \(u,v\in S\) and one hard prime common to both.  Therefore

\[
\sum_pz_p(z_p-1)
\le
\sum_{\substack{u,v\in S\\u\ne v}}W(u,v)
\le C_0\ell_t s(s-1)
\le\frac{t^2s^2}{8L_X}.
\tag{5.6}
\]

If \(E\ge2L_X\), (5.5) is at least

\[
\frac{E^2}{2L_X}
\ge\frac{t^2s^2}{2L_X},
\]

contradicting (5.6).  Hence

\[
E<2L_X,
\qquad
s<\frac{2L_X}{t}.
\tag{5.7}
\]

The number of intervals is

\[
\ll\frac{X^2}{\ell_t}+1
\ll\frac{X^2L_X}{t^2}+1.
\]

Multiplying by (5.7) proves (5.1).

### What this theorem does and does not say

It gives a genuine \(t^{-3}\) row tail from actual Apéry codegrees.  It still allows an isolated row of degree as large as \(L_X\).  That is exactly why it cannot by itself solve a pointwise problem.

# 6. New unconditional restricted sixth-moment envelope

Proposition 5.1 can be integrated by layer cake.

Since \(K_X^\sharp(m)\le L_X\),

\[
F_6^\sharp(X)
\le\sum_{X\le m<X^2}(K_X^\sharp(m))^6.
\tag{6.1}
\]

Use the exact discrete identity

\[
\sum_mK(m)^6
=\sum_{t=1}^{L_X}\bigl(t^6-(t-1)^6\bigr)|S_t^\sharp|.
\tag{6.2}
\]

Let \(T_0=C_1\sqrt{L_X}\).  For \(t\le T_0\), the trivial row count gives

\[
\sum_{t\le T_0}
\bigl(t^6-(t-1)^6\bigr)|S_t^\sharp|
\le X^2T_0^6
\ll X^2L_X^3.
\tag{6.3}
\]

For \(t>T_0\), use

\[
t^6-(t-1)^6\ll t^5
\]

and Proposition 5.1:

\[
\begin{aligned}
\sum_{t>T_0}t^5|S_t^\sharp|
&\ll
X^2L_X^2\sum_{t\le L_X}t^2
+L_X\sum_{t\le L_X}t^4\\
&\ll X^2L_X^5+L_X^6.
\end{aligned}
\]

Since \(L_X\ll X/\log X<X^2\), the \(L_X^6\) term is absorbed.  Thus

\[
\boxed{
F_6^\sharp(X)\ll X^2L_X^5.}
\tag{6.4}
\]

This is independent of \(\lambda_X\) and is therefore complementary to the canonical pair--Palm envelope

\[
F_6^\sharp(X)
\le F_6(X)
\le4X^2\lambda_X^2L_X^4.
\tag{6.5}
\]

Combining them gives

\[
\boxed{
F_6^\sharp(X)
\ll X^2L_X^4\min\{\lambda_X^2,L_X\}.}
\tag{6.6}
\]

up to an absolute harmless constant.

Using prime counting alone,

\[
L_X\ll\frac X{\log X},
\]

so (6.4) gives

\[
\boxed{
F_6^\sharp(X)
\ll\frac{X^7}{(\log X)^5}.}
\tag{6.7}
\]

At the current worst \(c=3/5\) envelope,

\[
\lambda_X\ll\frac{X^{3/5}}{\log X},
\]

(6.5) has worst scale

\[
\frac{X^{36/5+o(1)}}{(\log X)^6},
\]

whereas (6.7) has exponent \(7\).  The ratio is

\[
\frac{X^7/(\log X)^5}
     {X^{36/5}/(\log X)^6}
=\frac{\log X}{X^{1/5}}.

interval let $S$ be the high rows, $s=|S|$, and let $z_p$ count the
rows of $S$ at which the active prime $p$ is a hard hit.  With
$E=\sum_pz_p$ one has $E\ge ts$.  Cauchy gives
\[
 \sum_pz_p(z_p-1)\ge\frac{E^2}{L_X}-E.
\]
On the other hand, expansion by ordered row pairs and the twin theorem
give
\[
 \sum_pz_p(z_p-1)
 \le C_0\ell_t s(s-1)

\]

$s<2L_X/t$.  There are
$O(X^2L_X/t^2+1)$ intervals, proving the displayed tail.

Finally use the discrete layer-cake identity
\[
 \sum_mK_X^\sharp(m)^6
 =\sum_{t\le L_X}(t^6-(t-1)^6)|S_t^\sharp|.
\]
The levels below $C_1\sqrt{L_X}$ contribute $O(X^2L_X^3)$; inserting
the tail above that level gives $O(X^2L_X^5+L_X^6)$, and
$L_X^6$ is absorbed by $X^2L_X^5$.
\end{proof}

\label{prop:q4653-light-far-anchors}

# 16. Final status

The independently audited picture is sharper than Q4618 in two directions.

First, the Q4618 transfer is basically sound, but its folded-coordinate lemma must be stated orientation-aware and its “far” terminology must not be conflated with separation of all reflected orbit points.

Second, canonical main already yields more hard-row information than Q4618 used: the twin-atom theorem gives a \(t^{-3}\) high-row tail and the unconditional moment envelope

F_6^\sharp(X)\ll X^2L_X^5,
