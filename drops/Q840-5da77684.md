# Q840 audit: H-isolation versus physical I5

## Conclusion

The H-isolation input does not currently create a new implication edge from the physical isolated-five-star tail to the LGTQ aggregate pair/C4 target. It removes same-characteristic local collisions, but it does not supply the missing arithmetic relation between different characteristics. The remaining five-characteristic correlation is still a genuine transverse CRT correlation.

## What H-isolation actually proves

Let H=X^(7/15) log^(-1/3). The near-codegree estimate

```
K_X^near(m;H)=O(H^2)
```

implies that a bad fixed-q row with T much larger than X/log X cannot have many pairs of folded roots in the same characteristic within distance H. After discarding o(T) roots, one obtains H-isolated roots:

- each selected characteristic contributes a zero at its folded index;
- there is no second zero of the same characteristic within H.

This is a diagonal/off-diagonal pattern, not a cancellation theorem.

## Why it does not reduce I5 to LGTQ

The I5 term involves five distinct characteristics. For a tuple of characteristics p_1,...,p_5, the CRT condition couples five independent congruence classes. H-isolation only gives:

```
Z_{p_i} contains the selected index,
Z_{p_i} contains no nearby second index.
```

It gives no relation of the form

```
F_i(index_i)=F_j(index_j)
```

needed for a pair aggregate or a C4 rectangle extraction.

The LGTQ pair/C4 reductions control repeated pair structure among hit primes. I5 requires controlling a product of five different zero events after all pair coincidences have already been removed.

## Determinant/carrier possibility

The complete matrix of off-diagonal units is formally available: diagonal entries correspond to the chosen Apery zeros and off-diagonal entries correspond to nonzero gap-polynomial evaluations. However, H-isolation does not prove a determinant is nonzero modulo the relevant primes.

The missing statement would be a canonical determinant nonvanishing theorem:

```
For every sufficiently large isolated packet, the normalized gap-polynomial matrix has
nonzero determinant modulo the product of the packet characteristics.
```

No such theorem follows from the recurrence alone.

## Scale accounting

A bad row gives T=Omega(X/log X) hit primes. H-isolation removes only o(T), so the packet count remains

```
T-o(T)=Omega(X/log X).
```

The five-star tail therefore still contains macroscopically many possible packets. To close it, one needs either:

1. a carrier whose logarithmic height is o(X/log X) for the critical fibre, or
2. a direct I5 saving below the LGTQ aggregate threshold.

H-isolation provides neither.

## Exact missing lemma

The weakest useful new lemma is:

> Isolated-packet determinant lemma. For every fixed q and every H-isolated collection of canonical Apery zero indices arising from a bad row, the normalized multi-characteristic correlation matrix has rank deficiency bounded by o(T), equivalently the I5 contribution is o(N^2/log^2 N).

This is strictly stronger than transversality. Until proved, H-isolation is only a geometric separation input, not an arithmetic cancellation input.
