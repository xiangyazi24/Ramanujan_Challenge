# Q7217: conditioned Apéry incidence sum \(B_X\)

## Summary

The requested bound
\[
 B_X=\sum_{X<p\le 2X}\sum_{(x_0,x_1,x_2,x_3)}\#\{z:x_3+K<z<p,\ \pi_p(z)=\pi_p(x_3)\}
 \ll X^{2+o(1)}/\log X
\]

is not currently proved by the available continuant, carrier, reflection, or Lucas/Frobenius information. The strongest rigorous advance is a reduction to a genuinely arithmetic incidence theorem, together with several reductions showing exactly why the naive candidates fail.

The critical point is that \(B_X\) is a count of actual \(\mathbf F_p\)-valued projective states. A polynomial gcd degree is only an upper bound on geometric common roots over an algebraic closure and may contain nonsplit factors. Therefore no argument based only on \(\deg\gcd(N_s(x),N_G(x+s))\) proves the desired incidence estimate.

## 1. Correct transfer formulation

Let the Apéry pair be represented by the two independent solutions, but do not write
\[
\pi_{n+1}=A(n)\pi_n.
\]
This is invalid for the row of two solutions: the recurrence acts on a solution vector, while a projective state is obtained after quotienting by the solution space coordinates. In particular the \(n=0\) transfer is rank one, so there is no globally invertible monodromy argument.

For a fixed gap block \(g\), the valid statement is the two-time continuant identity. If a return condition at \(x\) and \(x+g\) is written using the scalar continuants \(N_g(x)\), then the second return is controlled by the exact polynomial relation
\[
N_g(x)=0.
\]
For a chain with gaps \((g_1,g_2,g_3)\), all later constraints are obtained by composing these two-time identities. They are not independent first-order transition equations.

## 2. Carrier-clean condition removes only the forced bad primes

Let \(U_s\) be the structural carrier polynomial attached to span \(s\). The condition
\[
p\nmid U_s
\]
removes primes where the continuant identity degenerates identically.

This gives the following valid lemma.

**Lemma (carrier-clean finiteness).** For fixed span \(s\), a prime \(p\nmid U_s\), and a fixed starting point \(x_0\), every selected return chain is represented by an actual root of the nonzero return polynomial attached to the gap vector.

**Proof.** The carrier condition prevents the complete vanishing of the transfer minors. The remaining equation is a genuine polynomial equation in the initial coordinate. 

**Limitation.** This gives only a polynomial root bound over an algebraic closure. It does not count the required affine points over \(\mathbf F_p\).

## 3. Why the gcd route is insufficient

A possible bound would be
\[
\#\{z:\pi_p(z)=\pi_p(x_3)\}
\leq \deg\gcd(N_s(z-x_3),N_G(z-x_3+\cdots)).
\]
This inequality is false as stated if the right hand side is interpreted as an equality. The gcd degree counts irreducible factors over \(\mathbf F_p[x]\), including factors with no roots in \(\mathbf F_p\).

The correct inequality is only
\[
\#\{z\in\mathbf F_p:\text{two return equations vanish at }z\}
\leq \deg\gcd(F,G).
\]
Using this inequality inside \(B_X\) loses the Apéry-specific splitting information and returns to the unresolved degree mass problem.

## 4. Reflection and Lucas blocks

Reflection gives an involution
\[
z\mapsto p-1-z.
\]
After excluding adjacent reflection-centered pairs, the selected chains are already in the nontrivial quotient. Reflection contributes at most a fixed factor of two and cannot give the missing logarithmic saving.

Lucas/Frobenius blocks similarly control periodicity of recurrence coefficients, but a periodic block estimate would have to prove a nontrivial trace cancellation for the actual projective fiber occupancy. A rank estimate on the Lucas leading coefficient is not enough: that rank is not the rank of the Apéry zero incidence matrix.

## 5. Exact irreducible estimate needed

A sufficient theorem is the following.

**Apéry separated fiber large-sieve conjecture.** Let \(\mathcal C_p(s)\) be the set of carrier-clean selected chains of span \(s\). Then
\[
\sum_{C\in\mathcal C_p(s)}
\#\{z:x_3(C)+K<z<p,\pi_p(z)=\pi_p(x_3(C))\}
\ll
p^{1+o(1)}\frac{s^2}{K^2}
\]
uniformly for \(s\leq\sqrt p\).

Summing over \(s\leq\sqrt p\), using \(K=\sqrt X/\sqrt{\log X}\), would give
\[
\sum_{X<p\le2X} B_p
\ll
\frac{X^{2+o(1)}}{\log X}.
\]

However, proving this estimate requires a new input: a trace/large-sieve estimate for actual Apéry projective fibers. It cannot be obtained from pair caps, reflection, or continuant degree alone.

## 6. Current rigorous conclusion

The conditioned incidence problem has been reduced to the following precise missing statement:

> Bound the average number of far projective returns of the endpoint of a carrier-clean non-AP short four-return chain.

The reductions achieved are:

1. first-order transfer arguments are discarded;
2. full-period invertible monodromy is discarded because of the rank-one initial step;
3. carrier-clean chains are reduced to genuine nonzero return equations;
4. reflection only changes constants;
5. polynomial gcd degree is separated from actual \(\mathbf F_p\)-root count;
6. the remaining obstacle is an Apéry-specific fiber large-sieve/trace estimate.

Therefore the requested asymptotic bound for \(B_X\) is not proved here. The strongest honest result is the above reduction: any completion must supply the separated fiber estimate (or an equivalent arithmetic theorem), not merely a restatement of \(B_X\) or a generic gcd-degree estimate.
