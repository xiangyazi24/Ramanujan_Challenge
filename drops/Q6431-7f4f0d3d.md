# 5. Height of the deep tensor and why truncation is exponent-neutral

From (4.4)–(4.5),


A `k`-minor of either Sylvester matrix has at most `k=O(H)` rows, each with logarithmic Euclidean norm `O(H log H)`.  Hadamard therefore gives, uniformly in `k`,




# 8. Physical root spacing does not recover the factor

Distinct starts of one balanced hard word are distinct `q0` occurrences.  The first gap of a hard word is `asymp H`, so two later hard starts in one ordered fiber are physically separated by `Omega(H)`.  Consequently

```text
m physical starts occupy length Omega(mH),

m <= 1 + P/H = H^(3/2+o(1)).                         (8.1)
```

The polynomial-degree/Smith bound is stronger:

```text
m <= rho_p(w) <= n_w = H^(1+o(1)).                   (8.2)
```

Therefore physical spacing does not lower the possible corank from `H` to `R_theta`.  A block of `H` starts separated by `4H` occupies only `O(H^2)`, while

```text
H^2 << P = H^(5/2+o(1)).                             (8.3)
```

The middle/terminal collars have scale at most `H R_theta=H^(3/2-2theta+o(1))`, also smaller than the unused physical room.

The Vandermonde determinant of the evaluation maps is a `p`-unit because the physical roots are distinct modulo `p`.  This proves independence; it does not supply an additional factor of `p`.  Likewise, simplicity makes the root discriminant a `p`-unit.  Neither fact lowers the common content of the Sylvester cofactors.

Hence a root-separation split has no stronger endpoint than (6.3).  A useful new spacing theorem would have to bound the **marked reuse** of one extra root by `R_theta`, not merely separate distinct roots.

## 9.5 Explicit polynomial/Sylvester model saturating the high–high tail

The failure of the generic Smith/subresultant argument can be realized by honest polynomial Sylvester matrices with simple, separated roots.

Let `M asymp H`, choose a squarefree integer

```text
Q = product_{p in S} p,

S subset (P,2P],
log Q asymp H,                                        (9.5)
```

and choose `M` distinct integers `r_i`, separated by at least `4H` and lying in an interval of length `O(H^2)<P`.  Put

```text
f(X) = product_{i=1}^M (X-r_i),
g(X) = f(X)+Q.                                        (9.6)
```

For every `p|Q`, the reductions satisfy `g=f`, so they have exactly `M` distinct simple common roots.  Both discriminants are `p`-units.

The integral Sylvester map is

```text
Phi(A,B) = A f + B g
         = (A+B)f + Q B.                              (9.7)
```

Change domain coordinates from `(A,B)` to `(A+B,B)`.  Since `f` is monic, monic division gives a unimodular codomain decomposition

```text
Z[X]_<2M = f Z[X]_<M direct_sum Z[X]_<M.
```

Under these two unimodular changes, `Phi` becomes

```text
diag(I_M, Q I_M).                                    (9.8)
```

Hence its Smith factors are

```text
1,...,1, Q,...,Q
  M times  M times,                                  (9.9)
```

and

```text
Delta_k = 1       for k<=M,
Delta_k = Q^(k-M) for M<k<=2M.                       (9.10)
```

Take two such modules, one for the fixed left word and one for the repeated companion word, using separated physical root blocks and the same `Q`.  At every `p|Q`,

```text
rho_p(alpha) = M,
rho_p(w)     = M,

v_p Xi_deep(alpha,w;R)
  = (M-R)(M-1-R).                                    (9.11)
```

Because `log Q asymp H`,

```text
log Sigma_alpha asymp H^2,
log Sigma_w     asymp H^2,
log Xi_deep     asymp H^3.                           (9.12)
```

Every root is simple and may be placed `Omega(H)` apart with ample deep, reflection, side, and terminal room.  At a root, `g-f=Q` has exact `p`-valuation one, so the local first-Witt transverse direction is also nondegenerate.  Mark every extra companion root as reusable by every left root; the physical marked count then has size `M(M-1)` per supporting prime and total logarithmic mass `asymp H^3`.

This is not the Apéry continuant family.  It is an exact Sylvester-model counterexample to any deduction using only:

```text
matrix size O(H),
coefficient-row height exp(O(H log H)),
full Smith divisibility chain,
simple split roots,
physical Omega(H) root spacing,
reflection/side room,
and absolute resultant height O(H^2).
```

A small Sage reproduction is:

```python
from sage.all import *

R.<x> = PolynomialRing(ZZ)
M = 4
Q = 101 * 103
roots = [0, 10, 20, 30]
f = prod(x-r for r in roots)
g = f + Q

S = f.sylvester_matrix(g)
D = S.smith_form()
diag = [abs(D[i,i]) for i in range(2*M)]
assert diag == [1]*M + [Q]*M

Delta = [prod(diag[:k]) for k in range(1, 2*M+1)]
assert Delta[:M] == [1]*M
assert Delta[M:] == [Q^j for j in range(1, M+1)]

for p in [101, 103]:
    F = f.change_ring(GF(p))
    G = g.change_ring(GF(p))
    h = gcd(F,G)
    assert h.degree() == M
    assert gcd(h, h.derivative()) == 1
```

# 10. Smallest falsifiable successors

There are two quantifier levels, and they must not be conflated.

## 10.1 Fixed exact repeated word: `REP-SUBRAD_theta(alpha,w;U,V)`

For dyadic `U,V>R_theta`, define the selected radical

```text
G_rep(alpha,w;U,V;P)
  = product p,
```

where the product runs over shell primes `p` satisfying all of the following:

```text
- some literal fixed-left side/terminal packet contains
  at least two physical occurrences of the exact word w;
- all q0, simplicity, consecutiveness, deep, nonwrapping,
  balanced, reflection, and retained hard masks hold;
- U < rho_p(alpha) <= 2U;
- V < (rho_p(w)-1)_+ <= 2V.
```

The smallest selected common-subresultant support theorem is

```text
REP-SUBRAD_theta(alpha,w;U,V):

log G_rep(alpha,w;U,V;P)
  << D R_theta/(U V) H^o(1),

uniformly for dyadic U,V>R_theta.                    (10.1)
```

By (6.3), (10.1) bounds every high–high box by `D R_theta`; summing over `H^o(1)` dyadic boxes and adding the already proved low boxes from (4.7) gives

```text
M_rep(alpha,w;P) << D R_theta H^o(1).                (10.2)
```

A stronger coefficient-only form replaces the selected radical by the shell gcd

```text
gcd_P(s_alpha,U, s_w,V)
```

from (6.7).  That form also implies (10.1), but it counts unselected, non-`q0`, nonsplit, or singular common factors and is therefore not equivalent to the physical target.

The currently proved bound is only

```text
log G_rep <= D/max(U,V) H^o(1),                      (10.3)
```

and the exact missing factor is `min(U,V)/R_theta`.

`REP-SUBRAD_theta` is strictly narrower than `REP-RICH_theta`: it concerns one fixed exact word, only simultaneous high–high corank, and only primes with a literal marked repetition.  It is not sufficient for the distributed corank-two packet (9.3), which is why a second branch-level statement is necessary.

## 10.2 Literal rich packets: `REP-SUBMIX_theta(alpha)`

For a literal packet define the selected subresultant excess

```text
RepHat(calP)
  = sum_{w : m_calP(w)>=2} (rho_p(w)-1)_+.           (10.4)
```

Physical evaluation independence gives

```text
Rep(calP) <= RepHat(calP).                            (10.5)
```

On a rich packet,

```text
n(calP) 1_{Rep(calP)>R_theta}
  <= n(calP) Rep(calP)/R_theta
  <= n(calP) RepHat(calP)/R_theta.                   (10.6)
```

Therefore the smallest coefficient-sensitive packet moment sufficient for the literal branch is

```text
REP-SUBMIX_theta(alpha):

sum_{P<p<=2P} (log p)
  sum_{calP : Rep(calP)>R_theta}
    n(calP) RepHat(calP)

  << D R_theta^2 H^o(1).                             (10.7)
```

Equations (10.6)–(10.7) imply

```text
REP-RICH_theta(alpha;P)
  << D R_theta H^o(1).                               (10.8)
```

The physically minimal sufficient observable is obtained by replacing `RepHat` with `Rep`; this is `REP-MIX_theta`.  The subresultant version (10.7) is a strict overcarrier and hence non-equivalent:

- it counts ordinary Smith directions at a selected prime which may be non-`q0`, nonsplit, singular, or removed by later masks;
- it retains the literal packet size and all side/terminal multiplicity instead of projecting to an unmarked word divisor;
- it may be large even when the actual rich-packet mass is small;
- conversely, the high–high fixed-word theorem (10.1) may be vacuous on the distributed corank-two rich packet (9.3).

At the RR16 closing value `theta=5sigma/2`, the exact successor exponents are

```text
R_theta                  = H^(1/2-5sigma+o(1)),
D R_theta                = H^(5/2-5sigma+o(1)),
D R_theta^2              = H^(3-10sigma+o(1)),
fixed-pair missing factor = H^(1/2+5sigma-o(1)).       (10.9)
```

No theorem currently supplies (10.1) or (10.7).

# 11. Why the proposed shortcuts are non-equivalent

The following implications are false at the exposed interface.

```text
Rep(calP)>R_theta
  => some exact word has more than R_theta repetitions.       FALSE
```

Counterconfiguration: (9.3), with `R_theta+1` words occurring twice.

```text
many exact-word repetitions
  => a repeated-root/discriminant prime.                       FALSE
```

Distinct simple roots make the discriminant a unit; the explicit model (9.6)–(9.12) has maximal corank with simple roots.

```text
physical Omega(H) root spacing
  => rho_p(w) <= R_theta.                                     FALSE
```

`H` roots occupy only `O(H^2)<P`.

```text
same rational prime in several word resultants
  => one higher-corank exact-word component.                  FALSE
```

Counterexample: `p=5683`, equation (9.2).

```text
many connected long returns through one component
  => many independent Smith directions.                      FALSE
```

The connected local ideal can remain length one.

```text
small global unmarked Smith mass
  => uniform marked fixed-left row bound.                     FALSE
```

A nonnegative coefficient matrix may concentrate all permitted mass in one fixed-left row, and one companion direction may be reused by all left roots.

```text
REP-RICH branch mass
  <= O(Rep duplicate mass).                                  FALSE
```

The sharp ratio is `Lambda/R_theta` after the rich threshold, as in (9.4).

None of these failures is repaired by dividing by the selected mass.  Such a division is not available and is not used here.
