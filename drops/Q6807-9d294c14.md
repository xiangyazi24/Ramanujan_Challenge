Status: PARTLY REFUTED. The corrected master-sum identity is narrower than the R_p(n) formulation. The q=1 top window is exact, but it is not the full pointwise criterion. Middle quotients q>=2 survive and must be controlled.

## 1. Exact expansion of M(n)

Let

M(n)=sum_{r<n/2} log rad_{>max(sqrt(n),r)} gcd(b_r,n-r).

Expanding the radical means summing over primes p with

p>max(sqrt(n),r), p|b_r, p|n-r.

The condition p>r is forced. Since r<n/2 and p|n-r, write

n-r = qp.

The congruence gives r = n mod p, but the representative is only allowed when r<p. Therefore the exact identity is

M(n)=sum_{sqrt(n)<p<=n} log p * 1[p|b_{n mod p} and (n mod p)<n/2].

For p>sqrt(n), the condition n mod p<n/2 is automatic except possibly when p<n/2 and the residue is large. Thus the commonly written form

M(n)=sum_{sqrt(n)<p<=n} log p * 1[p|b_{n mod p}]

is valid only after retaining the original representative restriction. It is not a free congruence-counting identity.

## 2. Refutation of R_p(n) multiplicity formula

The definition

R_p(n)={r<n/2:r congruent n mod p, p|b_r}

is not equivalent to the radical expansion.

It counts all representatives of the congruence class below n/2, including representatives r>=p. These are forbidden because the radical requires p>r.

Counterexample supplied:

n=101,p=31. The congruence class has r=8 and r=39. Both can be below n/2 and both may satisfy p|b_r, but only r=8 satisfies p>r. Therefore

log p |R_p(n)|

strictly overcounts M(n).

Verdict: FALSE.

## 3. Top window

For p>n/2, write n=p+r with 0<=r<p. Gessel gives

b_n=b_{p+r}=5b_r mod p.

Since r<n/2 and r<p automatically, the top-window condition is exactly

p|b_n iff p|b_{n-p}.

Verdict: TRUE for q=1.

## 4. Middle quotients are not absorbed

For p<=n/2 write

n=qp+r, 0<=r<p.

The master sum sees r only when r<p and r<n/2. For q>=2 these are genuine extra contributions.

Example:
n=37,p=17,q=2,r=3.

This is a real middle-window hit. There is no corresponding top-window prime because p is not >n/2.

The quotient reduction eliminating only

p<=n/(f(n)log n)

leaves all q<f(n)log n. It does not reduce the problem to q=1.

Verdict: FALSE that q>=2 disappears.

## 5. Exact pointwise criterion

The exact pointwise statement equivalent to

log G_n=o(n)

is:

For every epsilon>0, for all sufficiently large n,

sum_{p in (sqrt(n),n]} log p * 1[p|b_{n mod p}, n mod p<n/2] <= epsilon n,

plus the already-controlled small-prime contribution.

This is a one-residue-per-prime condition. It is not equivalent to any average over all zeros Z_p.

## 6. Top-window density is only necessary

The statement

sum_{n/2<p<=n} log p *1[p|b_n]=o(n)

is necessary because it is a sub-sum of the full master sum.

It is not sufficient.

Abstract alignment countermodel:

For each n assign a bad prime p_n<=n/2 with a permitted residue r_n=n mod p_n and put all mass on that middle residue. Make all top-window indicators zero. Then the top-window density statement holds identically, while the full master sum has size comparable to n along the chosen n.

Hence top-window control cannot imply the full gcd bound without an additional theorem controlling quotient layers.

Verdict: NECESSARY ONLY.

## 7. Weakest useful sufficient criterion

A sufficient condition is a cross-prime moment bound for the actual aligned residues:

For every dyadic interval N<n<=2N,

sum_{N<n<=2N} (sum_{sqrt(n)<p<=n, p|b_{n mod p}} log p)^2 = o(N^3).

Then Chebyshev gives that the exceptional set where the inner sum exceeds epsilon n has size o(N), and summing dyadic blocks yields density-one control.

For pointwise control, one needs the stronger statement that the maximum over the block is o(N), not merely the second moment.

## 8. Exceptional sets

A fixed exceptional set E must be measured by its logarithmic mass in dyadic blocks:

sum_{n in E, N<n<=2N} log n = o(N).

Equivalently, the contribution of E to log G_n is negligible at scale N.

The weaker statement

sum_p log p |Z_p|=o(X)

is invalid for this purpose: it samples every zero of every prime, while the master sum samples exactly one residue n mod p for each prescribed n.
