# Q848: Concrete GH1 exponent audit

## 1. Parameter normalization

Set

\[
\alpha=14/15+\eta,
\qquad 1/120<\eta<2/105.
\]

The quantities in (FG0) become

```
L = X^alpha
D = X^(7/15+eta/2)/log X
G = D^2 = X^alpha/log^2 X
Y-2X = X^(2-alpha)log^2 X
U ~ 2X
B ~ L^2 = X^(2alpha)
Lambda_iso = X^(8/15+o(1))
a = B/(2U)=X^(2alpha-1+o(1))
```

The GH1 target is

```
X^(14/3+o(1)).
```

Since

\[
2\alpha-1=2(14/15+\eta)-1=13/15+2\eta,
\]

we have

\[
a=X^{13/15+2\eta+o(1)}.
\]

The allowed interval gives

```
13/15+2eta in (3/4, 47/55).
```

So the truncation threshold is around X^0.75--X^0.854.

## 2. Sharp deterministic excess bound

Let

```
S_m subset [-X,X], |S_m|=k,
V_g = #{(s,t) in S_m^2 : t-s=g}
```

for nonzero distances g.

The total pair mass is exactly

\[
\sum_g V_g=k(k-1).
\]

Therefore for every a>0,

\[
\sum_g(V_g-a)_+
\leq \sum_gV_g
=k(k-1).
\]

This is the universal deterministic extremal bound.

A sharper bound uses the number of possible distances:

\[
|\{g\}|\leq 2X,
\]

hence

\[
\sum_g(V_g-a)_+
\leq k(k-1)-aN_+,
\]

where N_+ is the number of occupied distances with V_g>a. Consequently the largest possible excess is obtained by concentrating pair mass on as few distances as possible.

The extremal configuration is an arithmetic progression.

Take

\[
S=\{0,d,2d,\ldots,(k-1)d\}
\]

with kd\leq X. Then

\[
V_{jd}=k-j,
\quad 1\leq j\leq k-1.
\]

Hence

\[
E_a(S)=\sum_g(V_g-a)_+
=
\sum_{j=1}^{k-1}(k-j-a)_+.
\]

If k>a,

\[
E_a(S)=\frac{(k-a-1)(k-a)}2.
\]

Thus the sharp scale is

\[
E_a(S)\asymp (k-a)_+^2,
\]

and this is attained by progressions. Random-looking sets are smaller; no deterministic improvement below this scale is possible.

## 3. Insert into GH1 positive excess

The GH1 weighted quantity has the form

\[
\sum_m (k_D(m))_3\sum_g(V_g(m)-a)_+.
\]

The deterministic insertion gives only

\[
\sum_m(k_D(m))_3(k_m-a)_+^2.
\]

The progression example shows this cannot be replaced by a smaller universal expression.

The remaining question is whether existing first/second moment information controls this quantity.

---

## 4. What existing moments can and cannot do

A first moment estimate of the form

\[
\sum_m k_D(m)\ll X^{1+o(1)}
\]

only controls the average number of labels.

A second moment/codegree estimate controls

\[
\sum_m k_D(m)^2
\]

or fixed pair overlaps.

GH1 needs a third-order weighted quantity multiplied by a quadratic distance excess:

\[
(k_D)_3(k_m-a)^2.
\]

Even the formal replacement

\[
(k_D)_3\leq k_D^3
\]

shows that second moments do not close the estimate. They leave an uncontrolled cubic concentration term.

The worst deterministic case is a carrier m with

```
k_D(m) >> a
```

and arithmetic-progression signed support. This produces

\[
(k_D)_3E_a
\asymp k_D^3(k_D-a)^2.
\]

No currently listed first/second moment statement removes this configuration.

## 5. Ambient ceiling versus GH1 target

The trivial ambient estimate is obtained from

```
number of columns ~ X,
number of signed labels ~ Lambda_iso,
```

giving the ceiling

\[
X^{o(1)}(1+X^2\Lambda_{iso}^5).
\]

Since

\[
\Lambda_{iso}=X^{8/15+o(1)},
\]

this is

\[
X^{2+40/15+o(1)}
=X^{14/3+o(1)}.
\]

Thus the ambient ceiling is exactly the GH1 RHS.

There is no spare power. Any argument that only reproduces the ambient count cannot prove a little-o improvement.

The missing saving must come from eliminating the extremal carrier configurations.

## 6. Do the proposed fixes give a saving?

### Summing over g first

No automatic saving exists. The AP example already saturates

\[
\sum_g(V_g-a)_+\asymp(k-a)^2.
\]

Changing summation order does not alter the extremal geometry.

### Large sieve inequality

A large sieve estimate would require a spacing hypothesis on the signed support or on the corresponding characters. The current deterministic facts only give injectivity and uniqueness. They do not provide the needed Fourier separation.

Therefore no valid saving follows.

### Divisor bound for c_q q=c_p p±g

This bounds the number of algebraic representations of a fixed gap. It does not control how many retained labels can lie on the same physical carrier. The progression configuration is compatible with divisor multiplicity bounds.

Hence it does not close GH1.

## 7. First deficient exponent/configuration

The first obstruction is not an exponent calculation. It is the carrier geometry:

```
large k_D(m)
+
near-arithmetic-progression signed support
+
no proved Apéry cancellation
```

The ambient exponent is already tight:

\[
X^2\Lambda_{iso}^5=X^{14/3+o(1)}.
\]

The missing factor must be o(1) relative to this ceiling.

---

## 8. Weakest sufficient replacement lemma

A lemma strictly weaker than GH1 but sufficient for the far fifth tail is:

> **Normalized carrier-excess lemma.** Uniformly in the far region,
>
> \[
> \sum_m(k_D(m))_3\sum_g(V_g(m)-a)_+
> =o(X^2\Lambda_{iso}^5).
> \]
>
> It is enough to obtain this only after restricting to isolated signed carriers; no bound is required for all supports.

A more structural sufficient form is:

\[
\sum_m(k_D(m))_3(k_m-a)_+^2
=o(X^2\Lambda_{iso}^5).
\]

This is weaker than a full pairwise cancellation theorem because it only excludes high-multiplicity carriers after the GH1 weights are inserted.

---

## Final verdict

GH1 is not derivable from the present deterministic injectivity, uniqueness, pruning, spacing, and first/second moment facts alone.

The exact failure is:

```
proved facts: control individual pairs and codegrees
needed by GH1: control cubic carrier load times quadratic distance excess
```

The smallest missing ingredient is an Apéry-specific carrier estimate excluding arithmetic-progression concentration of the retained signed support at high-load columns.
