# P3.2 support-carrier optimization

## Verdict

The current \(11/5\) block/resultant proof genuinely uses **common-root multiplicity**, not merely the support bit \(p\mid c_{h,k}\). A single canonical triple per heavy block cannot be injected into supported gap pairs: distinct blocks may realize the same \((h,k)\) at different affine common roots.

There is a rigorous one-bit replacement, but the lost multiplicity must then be paid by the degree bound \(3(\min(h,k)-1)\). With only the present bound

\[
\log c_{h,k}\le \log|\mathcal R_{h,k}|\ll hk\log(h+k),
\]

this support route optimizes only to

\[
\boxed{X^{7/3}(\log X)^{-2/3}},
\]

worse than the current

\[
\boxed{X^{11/5}(\log X)^{-3/5}}.
\]

So the fact that the minimal affine Bézout constant can be much smaller than the resultant does **not** by itself improve the second moment.

The better algebraic target is a multiplicity-preserving **Smith radical**. If the full integer Sylvester matrix has Smith invariants \(d_1,\ldots,d_s\), define

\[
\Sigma_{h,k}:=\prod_i \operatorname{rad}(d_i).
\]

Then

\[
v_p(\Sigma_{h,k})
=\#\{i:p\mid d_i\}
=\operatorname{null}_{\mathbf F_p}(S_{h,k}\bmod p)
\ge m_{h,k}(p).
\]

Thus \(\Sigma_{h,k}\mid |\mathcal R_{h,k}|\): it removes redundant \(p\)-adic powers without discarding the nullity multiplicity used by the block proof.

A power-saving theorem

\[
\boxed{
\sum_{h+k<H}\log\Sigma_{h,k}\ll H^{4-\delta}
}
\]

for any fixed \(\delta>0\) would immediately beat \(11/5\), giving power

\[
\boxed{3-\frac4{5-\delta}<\frac{11}{5}}.
\]

For a pure support/Bézout-radical route, the sufficient theorem is stronger:

\[
\boxed{
\sum_{h+k<H}\min(h,k)\log\operatorname{rad}_X(c_{h,k})
\ll H^{4-\delta}.
}
\]

## 1. Why one canonical triple per heavy block is not enough

Partition \(0,1,\ldots,p-1\) into nonwrapping blocks \(I_j\) of at most \(H\) integers, and let

\[
z_j=\#(I_j\cap\mathcal Z_p),
\qquad
B_p=\lceil p/H\rceil.
\]

Every zero triple

\[
x<x+h<x+h+k
\]

inside one block has \(h,k\ge2\), \(h+k<H\), and gives

\[
N_h(x)=N_k(x+h)=0\pmod p.
\]

If one chooses only one canonical triple per block with \(z_j\ge3\), two different blocks may choose the same gap pair \((h,k)\). Their anchors are simply different common roots of the same two reduced polynomials. The bit

\[
p\mid c_{h,k}
\]

records existence, not how many blocks realize that pair.

So there is no block-to-support injection without a new Apéry-specific repetition theorem.

## 2. Exact multiplicity countermodel for a one-bit Bézout carrier

Fix a prime \(p\) and distinct residues \(a_1,\ldots,a_t\). Put

\[
F(x)=\prod_{i=1}^t(x-a_i),
\qquad
G(x)=F(x)+p.
\]

Then \(F,G\in\mathbf Z[x]\) are coprime over \(\mathbf Q[x]\), because \(G-F=p\). Also \(p\in(F,G)\cap\mathbf Z\).

Modulo \(p\),

\[
\bar F=\bar G=\prod_{i=1}^t(x-a_i),
\]

so there are \(t\) distinct affine common roots. Every integer Bézout constant is divisible by \(p\), while \(p\) itself is a certificate. Hence

\[
\boxed{c(F,G)=p}
\]

but the common-root multiplicity is \(t\).

Thus one support bit is compatible with arbitrarily many distinct common roots up to the degree. The roots can be placed in distinct blocks. This proves that generic Bézout-support algebra cannot recover the multiplicity needed by the block proof.

## 3. The strongest rigorous support-only charging available for free

For each block \(I_j\), let \(D_j\) be the number of **distinct ordered gap pairs** \((h,k)\) realized by some zero triple in the block.

There are \(\binom{z_j}{3}\) triples. For fixed \((h,k)\), at most \(z_j\) anchors can realize that pair. Hence

\[
\binom{z_j}{3}\le z_jD_j.
\]

For \(z_j\ge3\),

\[
\frac{(z_j-1)(z_j-2)}6\le D_j,
\]

so

\[
\boxed{z_j\le2+\sqrt{6D_j}.}
\tag{3.1}
\]

Summing and using Cauchy,

\[
Z(p)
\le2B_p+\sqrt{6B_p\sum_jD_j}.
\tag{3.2}
\]

Now fix \((h,k)\). Let \(q_{h,k}(p)\) be the number of blocks in which it is realized. Choosing one anchor in each such block gives distinct common roots, so

\[
q_{h,k}(p)\le m_{h,k}(p).
\]

Without using multiplicity we still have the degree cap

\[
m_{h,k}(p)
\le3(\min(h,k)-1).
\]

And occurrence implies \(p\mid c_{h,k}\). Therefore

\[
q_{h,k}(p)
\le
w_{h,k}\mathbf1_{p\mid c_{h,k}},
\qquad
w_{h,k}:=3(\min(h,k)-1).
\tag{3.3}
\]

Double counting block/pair incidences gives

\[
\sum_jD_j
\le
W_p(H):=
\sum_{h+k<H}w_{h,k}\mathbf1_{p\mid c_{h,k}}.
\tag{3.4}
\]

Thus

\[
\boxed{
Z(p)^2\ll B_p^2+B_pW_p(H).
}
\tag{3.5}
\]

This is the exact one-bit-support substitute for the multiplicity-sensitive Q2836 inequality.

## 4. Dyadic support theorem and exact averaging formula

Let

\[
\operatorname{rad}_X(c)
=\prod_{\substack{X<p\le2X\\p\mid c}}p
\]

and define

\[
\mathfrak C_w(H;X)
:=
\sum_{h+k<H}
w_{h,k}\log\operatorname{rad}_X(c_{h,k}).
\tag{4.1}
\]

Then

\[
\sum_{X<p\le2X}W_p(H)
\le
\frac{\mathfrak C_w(H;X)}{\log X}.
\tag{4.2}
\]

Since \(B_p\ll X/H\), summing (3.5) gives

\[
\boxed{
M_2(X)
:=\sum_{X<p\le2X}Z(p)(Z(p)-1)
\ll
\frac{X^3}{H^2\log X}
+
\frac{X}{H\log X}\mathfrak C_w(H;X).
}
\tag{4.3}
\]

Therefore a **weighted** support theorem is enough. If one has a direct bound

\[
\sum_{X<p\le2X}\sum_{h+k<H}
w_{h,k}\mathbf1_{p\mid c_{h,k}}
\le \mathcal W_X(H),
\]

then (4.3) becomes

\[
M_2(X)
\ll
\frac{X^3}{H^2\log X}
+\frac XH\mathcal W_X(H).
\]

An unweighted support theorem is enough only after paying the worst-case factor \(w_{h,k}\ll H\).

## 5. Current \(\log c\) bounds give only \(7/3\)

Since \(c_{h,k}\mid|\mathcal R_{h,k}|\),

\[
\log c_{h,k}\ll hk\log(h+k).
\]

Hence

\[
\begin{aligned}
\mathfrak C_w(H;X)
&\le
\sum_{h+k<H}w_{h,k}\log c_{h,k}\\
&\ll
\sum_{h+k<H}\min(h,k)hk\log(h+k)\\
&\ll H^5\log H.
\end{aligned}
\tag{5.1}
\]

Substituting into (4.3),

\[
M_2(X)
\ll
\frac{X^3}{H^2\log X}
+
\frac{XH^4\log H}{\log X}.
\tag{5.2}
\]

Balancing gives

\[
H^6\log H\asymp X^2,
\]

so

\[
H\asymp X^{1/3}(\log X)^{-1/6}
\]

and

\[
\boxed{
M_2(X)\ll X^{7/3}(\log X)^{-2/3}.
}
\tag{5.3}
\]

Thus the present one-bit carrier route is worse than \(11/5\).

## 6. General optimized exponent for a weighted support theorem

Suppose

\[
\mathfrak C_w(H;X)
\ll H^\beta(\log H)^\eta.
\tag{6.1}
\]

Then

\[
M_2(X)
\ll
\frac{X^3}{H^2\log X}
+
\frac{XH^{\beta-1}(\log H)^\eta}{\log X}.
\]

Balancing gives

\[
H^{\beta+1}(\log H)^\eta\asymp X^2,
\]

and the optimized power is

\[
\boxed{
\theta_{\rm supp}(\beta)
=3-\frac4{\beta+1}.
}
\tag{6.2}
\]

The logarithmic exponent is \(2\eta/(\beta+1)-1\).

Consequences:

- present support consequence: \(\beta=5,\eta=1\), giving \(7/3\);
- \(\beta=4,\eta=1\) recovers the current \(11/5,(\log X)^{-3/5}\) scale;
- any power improvement over \(11/5\) requires
  \[
  \boxed{\beta<4;}
  \]
- \(\beta=4,\eta<1\) improves only the logarithm;
- power \(2\) requires \(\beta\le3\).

Hence the smallest clean support theorem that beats \(11/5\) is

\[
\boxed{
\sum_{h+k<H}\min(h,k)\log\operatorname{rad}_X(c_{h,k})
\ll H^{4-\delta}
}
\tag{6.3}
\]

for some \(\delta>0\). A stronger unweighted sufficient statement is

\[
\sum_{h+k<H}\log\operatorname{rad}_X(c_{h,k})
\ll H^{3-\delta}.
\]

## 7. Better certificate: multiplicity-preserving Smith radical

Let the full integral Sylvester matrix \(S_{h,k}\) have Smith form

\[
U S_{h,k}V
=\operatorname{diag}(d_1,\ldots,d_s),
\qquad d_i>0.
\]

Define

\[
\boxed{
\Sigma_{h,k}:=\prod_i\operatorname{rad}(d_i).
}
\tag{7.1}
\]

Then

\[
v_p(\Sigma_{h,k})
=\#\{i:p\mid d_i\}
=\operatorname{null}_{\mathbf F_p}(S_{h,k}\bmod p).
\]

Therefore

\[
\boxed{
m_{h,k}(p)\le v_p(\Sigma_{h,k}).
}
\tag{7.2}
\]

Degree drops can add projective nullity, but never reduce this upper bound on affine roots. Also

\[
\boxed{\Sigma_{h,k}\mid|\mathcal R_{h,k}|.}
\tag{7.3}
\]

So the hierarchy is

```text
full resultant: multiplicity + all p-adic excess
Smith radical Sigma: multiplicity, p-adic excess removed
minimal Bezout c: support only, multiplicity can be lost
```

This is the natural stronger algebraic certificate.

## 8. Smallest Smith/radical theorem that beats \(11/5\)

Put

\[
\mathfrak S(H)
:=\sum_{h+k<H}\log\Sigma_{h,k}.
\]

Because (7.2) retains multiplicity, the original Q2836 proof works verbatim with \(\log|\mathcal R_{h,k}|\) replaced by \(\log\Sigma_{h,k}\):

\[
\sum_{X<p\le2X}\mathcal E_p(H)
\le
\frac{\mathfrak S(H)}{\log X}.
\]

If

\[
\mathfrak S(H)
\ll H^\gamma(\log H)^\eta,
\]

the optimized block power is again

\[
\boxed{
\theta_{\rm Smith}(\gamma)
=3-\frac4{\gamma+1}.
}
\]

The current determinant budget corresponds to \(\gamma=4,\eta=1\), hence \(11/5\). Therefore any fixed power saving

\[
\boxed{
\sum_{h+k<H}\log\Sigma_{h,k}
\ll H^{4-\delta}
}
\tag{8.1}
\]

gives

\[
\boxed{
M_2(X)
\ll
X^{\,3-4/(5-\delta)+o(1)},
}
\]

which is strictly better than \(11/5\).

This is a smaller arithmetic demand than the support theorem (6.3), because it retains multiplicity instead of paying an extra degree factor.

## Final decision

1. **No:** one canonical triple per heavy block charged only to \(p\mid c_{h,k}\) is not injective; repeated blocks may use the same gap pair.
2. The exact model \(F=\prod(x-a_i),\ G=F+p\) has minimal Bézout constant \(p\) but arbitrarily many common roots, proving generic one-bit support cannot recover multiplicity.
3. A rigorous support-only block proof exists after charging every distinct gap pair per block and weighting support by \(3(\min(h,k)-1)\).
4. With current \(\log c_{h,k}\) bounds it gives only \(7/3\), so it does not improve \(11/5\).
5. A weighted radical theorem of size \(H^{4-\delta}\) would make support-only charging beat \(11/5\).
6. The more economical next theorem is the multiplicity-preserving Smith-radical estimate
   \[
   \sum_{h+k<H}\log\Sigma_{h,k}\ll H^{4-\delta}.
   \]

So the true bottleneck is not simply “resultant versus minimal Bézout constant.” It is the **Smith-nullity radical mass**: compress the resultant while retaining one arithmetic unit for each independent common-root direction.
