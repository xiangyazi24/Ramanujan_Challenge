# Q912 audit: growing-degree signed Newton--Pade regime

## Verdict

**Not proved.** The fixed-degree argument does not currently extend to any
unbounded degree regime. I do not find a contradiction in the fixed-degree
statement, but the first missing step is a uniform-in-
`d` endpoint/total-positivity estimate. Therefore no growing-degree family
with subexponential `P(3H+1)` has been certified.

## 1. Quantifier audit

The fixed-degree statement has the form

```
for every fixed d, there exists H_0(d) such that for H >= H_0(d),
all normalized rows are strictly totally positive.
```

This does not imply

```
there exists a function d(H)->infinity such that the same positivity
holds for every H.
```

The missing dependency is the growth of `H_0(d)` and of the lower Neville
pivot constants as `d` increases.

The endpoint expansion being six orders deeper before three applications of
`M` removes the earlier local/operator objection, and the locality

```
(Mw)_k = k(w_k+w_{k-1})
```

is compatible with the argument. However, those facts only give a fixed-
d expansion unless the remainder and pivot gaps are bounded uniformly in
d.

## 2. Required uniform estimate

To obtain even `d=o(log H)`, one needs an estimate of the following form.

For the endpoint-normalized rows `R_j`, after the row subtraction identity
(the displayed equation (3.7)), one needs

```
R_{j+1}-R_j = positive weighted combination of previous row differences
```

with weights whose ratios are controlled uniformly as `d` grows.

Equivalently, if `\Delta_{i}` denotes the Neville pivot sequence, one needs

```
min_i \Delta_i(H,d) >= exp(-o(H))
```

uniformly for `d` in the proposed range, together with a remainder bound
of the form

```
error(H,d) < main_pivot(H,d).
```

The current fixed-degree proof only establishes positivity after taking `H`
large with `d` already fixed; it does not provide the dependence needed for
`d(H)`.

## 3. Finite scan

No finite scan is used as an asymptotic argument. A computation over
`1 <= d <= H` could only provide a diagnostic: first mixed-sign kernels,
and numerical values of

```
log |P(3H+1)|/(3H+1)
```

would not prove a surviving regime without the missing uniform estimate.

I therefore do not report numerical scan output as evidence.

## 4. Certificate issue

The primitive normalization point is valid: after choosing the integer
cofactor vector and dividing by its gcd, the resulting kernel is an integer
certificate. This removes scaling ambiguity but does not create cancellation
or prevent exponential growth.

A subexponential certificate would require an actual family with

```
log |P(3H+1)| = o(H),
```

and a proof that the primitive kernel satisfies the required annihilation
conditions. No such family is established here.
