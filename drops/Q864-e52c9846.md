# Polylogarithmic-moment carrier height audit

## Result

The experimentally observed containment

```
C_n | gcd(L_n,b_n)
```

is not a theorem from the stated local formula alone. The sharp remaining statement is a finite congruence lemma. If proved, it implies the required height bound. No unconditional counterexample is produced from the supplied identities.

## 1. Prime support reduction

Let q be prime and write

```
n = a q + r, 0 <= r < q
```

when q > sqrt(n). The banked local identity with e=1 gives

```
U_s(n) = c_q^s b_r S_s(a) mod q.
```

For q | L_n we have q<=n. For q>sqrt(n), q occurs in L_n with valuation one. Hence

```
q | C_n
```

requires

```
q | U_1(n), U_2(n), U_3(n).
```

Because c_q is nonzero modulo q, this requires

```
b_r S_s(a)=0 mod q,  s=1,2,3.
```

The only unconditional conclusion is:

```
q | b_r
```

or all the relevant S_s(a) vanish. Therefore the implication

```
q | C_n => q | b_n
```

is equivalent to excluding the second branch.

## 2. Exact missing congruence lemma

The containment would follow from the following explicit statement:

For every prime q<=n, with q^e the largest q-power <=n and n=aq^e+r,

```
q | c_q^s b_r S_s(a)  (s=1,2,3)
```

implies

```
q | b_n.
```

For q>sqrt(n), this reduces to:

```
q ∤ b_r  =>  at least one of S_1(a),S_2(a),S_3(a) is nonzero mod q.
```

This is the precise finite list of identities required. It is not implied by Vandermonde interpolation because the available moments are only three.

## 3. Radical support versus valuation

The consumer only needs

```
log rad(C_n)=o(n)
```

or stronger

```
log C_n=o(n).
```

A containment of radicals is insufficient for valuations. Prime powers q^v dividing C_n require controlling

```
min(v_q(L_n),v_q(U_1),v_q(U_2),v_q(U_3)).
```

The local formula modulo q controls only support. It does not bound higher q-adic valuations.

Thus even a proved

```
rad(C_n) | rad(b_n)
```

would not by itself give

```
C_n | b_n.
```

## 4. Companion overlap

The carrier is not independent of the Apéry sequence: q can enter C_n through lower-digit terms b_r. A proof must separate:

1. primes already dividing b_n;
2. primes dividing lower residues b_r;
3. accidental simultaneous zeros of S_1,S_2,S_3.

Only the third class is the genuine obstruction.

## 5. Reversed interpolation route

The recurrence

```
P_{a+1}(z+1)=zP_a(z)+b_a Q_a(z)
```

could yield a Bezout identity, but the required theorem is not a generic resultant bound. One needs an explicit statement:

```
log ||Res(P_a,Q_a)|| = o(n)
```

with the actual coefficient heights derived from the recurrence. No such estimate follows from the recurrence alone.

## 6. Sufficiency lemma for the consumer

The sharp remaining lemma is:

> There exists E(n)=o(n) such that every prime power q^v dividing C_n satisfies
>
> either q^v divides b_n,
> or q^v belongs to an exceptional set of total logarithmic weight at most E(n).

Then

```
log C_n <= log gcd(L_n,b_n)+E(n).
```

Since the consumer already proves

```
log G_n <= O(sqrt n)+O(n^(2/3))+6log C_n,
```

and any bound

```
log C_n=o(n)
```

finishes the index argument, this lemma is sufficient.

## Final status

- `C_n | gcd(L_n,b_n)`: unproved from the given identities; no counterexample established.
- Prime support reduction: proved up to the explicit nonvanishing lemma for the three local moments.
- q-adic valuation control: missing.
- Reversed interpolation/Bezout approach: a possible route, but requires an explicit coefficient-height theorem.
- Sharp next lemma: exclude simultaneous vanishing of the required local moment carrier or bound its exceptional prime-power contribution by o(n).
