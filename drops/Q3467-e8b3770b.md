# 11. Why the theorem does not yield an o(m)-height carrier

There are two distinct gains here.

First, `Gamma_even` is a single characteristic-zero integer ideal generator whose squarefree q=6 core support is exactly the target set. Second, when nonzero,

```text

```

Neither is a height estimate.

To use one global integer in the radical argument one still needs, uniformly,

```text
C_m != 0,
log |C_m| = o(m),
all target primes divide C_m.                       (11.2)
```

The lattice theorem gives the third property for `Gamma_even`. It does not give the first two.

## 11.1 Nonvanishing

If every core prime is a target, the residue test `(8.10)` gives no non-target prime at which `h20` is visibly nonzero. Abstractly the value ideal can be zero in rank-degenerate situations. A finite scan of nonzero gcds is not a uniform nonvanishing theorem.

In the nondegenerate regime one can of course prove nonzero if any explicit generator is proved nonzero over `Z`, but that is a separate statement.

## 11.2 Height

Even an explicit repair source with polynomially bounded **coefficients** can have a value

```text
H_Q = sum coefficient * Q_(s,K)                    (11.3)
```

of exponential height because the Newton values themselves have exponential size. The mod-8 division changes logarithmic height only by `O(1)`.

The sandwich

```text
Gamma(Q) | Gamma_even | 2 Gamma(Q)                  (11.4)
```

also does not provide an absolute bound: it only compares two currently unbounded lattice invariants.

Even if the finite MP40 family were proved to generate `Gamma_even`, one would still need at least one nonzero selected family value with

```text
log |H_MP40| = o(m)                                 (11.5)
```

or an independent proof that the gcd of those values has that height. A finite number of exponentially large values does not automatically have a subexponential gcd.

Thus the old Green/WZ/antidifference compression problem remains the height bottleneck.

> = Z u20 + Z u02 + K_f direct_sum K_e,
> ```
>
> where `K_f=ker(sum,f dot)` and `K_e=ker(sum,e dot)`. If
>
> ```text
> h20=H(u20),
> h02=H(u02),
> H(K_f,0)=kappa_f Z,
> H(0,K_e)=kappa_e Z,
> ```
>
> then
>
> ```text
> Gamma_even
> = gcd(h20,h02,kappa_f,kappa_e).
> ```
>
> If `D3_f,D3_e` are the top determinantal divisors of the one-slope augmented row matrices `(1,f,q)` and `(1,e,r)`, then
>
> ```text
> kappa_f=D3_f/d_f,
> kappa_e=D3_e/d_e,
> ```
>
> with `D3_s=kappa_s=0` allowed when the augmented one-slope rank is two.
>
> Let `g` be the nonnegative generator of `H(Lambda)`. Then
>
> ```text
> 2g Z subset Gamma_even Z subset g Z,
> ```
>
> hence
>
> ```text
> g | Gamma_even | 2g.
> ```
>
> In the q=6 mod-8 normalized Apéry setting, `g=Gamma(T)/8`. At every sufficiently large odd q=6 core prime,
>
> ```text
> H(A,B) == -c*2^(-1)b_(m-6p) (mod p),
> ```
>
> so for a `(2,0)` lift
>
> ```text
> h20 == -b_(m-6p) (mod p),
> ```
>
> while `h02`, the `f` kernel, and the `e` kernel vanish modulo every core prime. Consequently
>
> ```text
> p | Gamma_even iff p | b_(m-6p)
> ```
>
> on the sufficiently-large q=6 core.
>
> These conclusions do not assert that any prescribed finite H3 subfamily generates `kappa_f` or `kappa_e`, do not imply uniform nonvanishing, and do not imply an `o(m)` height bound.

For the actual negative-binomial full windows, the previously proved `d_f,d_e in {1,2}` supplies the divisibility hypotheses once the legal windows are in the nonconstant three-consecutive-index regime.
