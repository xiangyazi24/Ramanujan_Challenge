# Q7959 reference audit: one-node K3 degeneration and branch defect

## Scope

This audit separates three statements that are often conflated:

1. the local semistable/ADE resolution statement;
2. the l-adic invariant-cycle statement for a one-node K3 degeneration;
3. the endpoint middle-extension Mellin trace statement.

Only (1) and the consequences of (2) under its hypotheses imply the branch-defect cancellation. The endpoint statement remains separate.

## 1. Local one-node model

Assume a proper flat regular relative surface over a henselian trait with geometric generic fibre a K3 surface and special fibre having exactly one rational double point of type A1. Étale-locally the singularity is

```
xy-z^2=0
```

on the special fibre. The minimal resolution replaces the node by a single exceptional curve C with

```
C ~= P^1,   C^2=-2.
```

The exceptional curve is a divisor class in the resolved special fibre. It is not the vanishing quotient in cohomology; the latter is a one-dimensional quotient carrying the vanishing-cycle character.

## 2. Resolution sequence

For the special fibre S_0 and its resolution \tilde S_0, the divisor-class contribution is

```
0 -> NS(S_0) -> NS(\tilde S_0) -> Z[C] -> 0
```

under the stated single-A1 hypothesis.

For l-adic cohomology, the relevant weight-two correction is

```
0 -> H^2(S_0_bar,Q_l) -> H^2(\tilde S_0_bar,Q_l) -> Q_l(-1) -> 0
```

provided the singular fibre cohomology is interpreted via the proper comparison/resolution sequence. The quotient is generated by the exceptional curve class. The Tate twist is forced because divisor classes lie in H^2 with Frobenius weight 2.

The geometric Frobenius eigenvalue on Q_l(-1) is q (and arithmetic Frobenius convention gives q^{-1}); this convention must be fixed before comparing traces.

## 3. Invariant cycles

The invariant-cycle map is

```
H^2(S_0_bar,Q_l) --> H^2(X_bar_eta,Q_l)^I.
```

For a proper semistable degeneration, the invariant cycle theorem gives surjectivity. In the one-A1 K3 situation, the expected dimensions are:

```
dim H^2(generic)=22
rank invariant part =21
rank vanishing contribution=1.
```

The statement that

```
H^2(S_0_bar,Q_l) ~= H^2(X_bar_eta,Q_l)^I
```

requires the precise hypotheses of the chosen invariant-cycle theorem and the absence of additional singularities/monodromy pieces. It is not a consequence merely of knowing that one exceptional divisor exists.

## 4. Vanishing character and exceptional curve

The one-dimensional vanishing quotient carries the quadratic character of the node smoothing parameter. It is not the exceptional curve class.

The distinction is:

- exceptional curve: algebraic class in the resolution, contributes Q_l(-1);
- vanishing cycle: quotient/kernel term measuring failure of smooth specialization, carries monodromy character.

Confusing them leads to an incorrect trace correction.

## 5. Branch defect E_br

If the smooth K3 contribution has the expected divisor contribution 20p and the singular invariant contribution removes exactly one quadratic vanishing line, the bookkeeping is:

```
resolved special fibre divisor rank contribution: 19p
one-node correction: +p
expected smooth rank contribution: 20p
```

hence

```
E_br = 20p - (19p+p)=0.
```

This cancellation is conditional on the invariant-cycle identification and the exact one-node contribution. It is not implied by the local ADE resolution alone.

## 6. Endpoint middle extension

The two-dimensional middle-extension Mellin trace congruence requires additional endpoint hypotheses:

- correct extension across singular parameter values;
- local monodromy calculation;
- identification of the trace sheaf with the intended middle extension;
- absence/control of extra boundary skyscraper terms.

The local K3 degeneration result does not prove these.

## 7. Dependency table

| Input | Gives | Does not give |
|---|---|---|
| Regular proper flat model | valid specialization framework | endpoint trace formula |
| One A1 singularity | one exceptional (-2)-curve | full monodromy computation |
| ADE resolution | Q_l(-1) resolution quotient | middle extension theorem |
| Invariant cycles theorem | comparison with inertia invariants | endpoint purity automatically |
| Endpoint monodromy hypotheses | middle extension trace identity | local resolution |

## 8. Citations

Standard references include SGA 7 II (Picard-Lefschetz and invariant cycles) and Artin's theory of rational double points. Exact theorem numbering should be checked against the edition before insertion into a publication proof. No unverified theorem number is claimed here.

## Final conclusion

The unconditional conclusion available from the stated assumptions is:

- the exceptional divisor contributes a Tate-twisted one-dimensional resolution quotient;
- it cannot be identified with the quadratic vanishing quotient;
- under the one-node invariant-cycle hypotheses the missing branch contribution is exactly one p-dimensional correction, yielding E_br=0.

The endpoint middle-extension Mellin trace congruence remains conditional and must not be promoted to an unconditional theorem from this local calculation alone.
