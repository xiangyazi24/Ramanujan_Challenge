# P3.2 ATTACK audit: Christoffel–Darboux versus the Apéry zero set

## Verdict

**The diagonal Christoffel–Darboux kernel does not, by itself, improve the present global bound on**
\[
Z_p=\{0\le r<p:R_r(\lambda_r)=b_r\equiv0\pmod p\}.
\]

The obstruction is stronger than the loss of positivity over \(\mathbf F_p\). At a generic/simple Apéry zero, the *natural* diagonal kernel is not zero at all. In fact, for a good index \(1\le r<p\), putting \(a=\lambda_r\) and \(m=r-1\), the stated CD identity gives

```text
K_{r-1}(a,a)
 = sum_{k=0}^{r-1} (2k+1) R_k(a)^2
 = (r^3/2) R'_r(a) R_{r-1}(a),        because R_r(a)=0.
```

Away from the finitely/explicitly exceptional recurrence levels, consecutive Racah polynomials have no common zero. Hence \(R_{r-1}(a)\ne0\). Therefore
\[
K_{r-1}(\lambda_r,\lambda_r)=0
\quad\Longleftrightarrow\quad
R'_r(\lambda_r)=0
\]
for an Apéry zero \(r\). Thus CD detects **multiple/singular zeros of the fixed polynomial \(R_r(x)\)**; it does **not** detect ordinary Apéry zeros \(R_r(\lambda_r)=0\).

So the proposed RMT-style implication needed for root counting,

```text
r in Z_p  ==>  K_m(lambda_r,lambda_r)=0
```

is false for the two most natural choices \(m=r-1\) and \(m=r\): at a simple Apéry zero the kernel is instead a unit.

My disposition for P3.2 is therefore:

> **CD is worth keeping, but as a local transversality/simple-root tool, not as a direct global \(|Z_p|\) bound.** A global improvement would require one new bridge that converts the moving-degree condition \(R_r(\lambda_r)=0\) into zeros/rank loss of one *fixed* low-complexity kernel or polynomial.

I checked the current P3.2 repository state, including `problems/3.2/AVENUES.md`. The newest Session-1 Racah/CD derivation is not exposed by the repository search index I can access, so below I take the exact Racah identification and CD normalization stated in Q3582 as the proved input and do not alter its normalization.

## 1. The exact diagonal specialization at an Apéry zero

Take the proved identity from Session 1:
\[
K_m(x,y):=\sum_{k=0}^m(2k+1)R_k(x)R_k(y)
 =\frac{(m+1)^3}{2}\,
 \frac{R_{m+1}(x)R_m(y)-R_m(x)R_{m+1}(y)}{x-y}.
\]
On the diagonal,
\[
K_m(x,x)
=\frac{(m+1)^3}{2}
 \bigl(R'_{m+1}(x)R_m(x)-R'_m(x)R_{m+1}(x)\bigr).
\]

Now fix \(r\in Z_p\), set \(a=\lambda_r\), and choose \(m=r-1\). Since \(R_r(a)=0\),
\[
\boxed{
K_{r-1}(a,a)=\frac{r^3}{2}R'_r(a)R_{r-1}(a).
}
\tag{1}
\]
This is the decisive identity.

If \(p>2\), \(1\le r<p\), and the three-term recurrence is nondegenerate at level \(r\), then \(r^3/2\) is a unit and \(R_r\) and \(R_{r-1}\) cannot share a root. Indeed, if a common root existed, the three-term recurrence propagates the vanishing backwards (provided the backward coupling coefficients are units) until it contradicts \(R_0=1\). Consequently
\[
R_{r-1}(a)\ne0.
\]
Equation (1) then yields
\[
\boxed{
 r\in Z_p,\qquad
 K_{r-1}(\lambda_r,\lambda_r)=0
 \iff R'_r(\lambda_r)=0.
}
\tag{2}
\]
In particular, at every simple Apéry zero,
\[
K_{r-1}(\lambda_r,\lambda_r)\ne0.
\]

The choice \(m=r\) does not change this. Since the new summand is
\((2r+1)R_r(a)^2=0\),

```text
K_r(a,a) = K_{r-1}(a,a).
```

Therefore the kernel remains nonzero at a simple Apéry zero.

This already rules out the direct CD zero-count strategy.

## 2. Why the random-matrix/orthogonal-polynomial argument does not transplant

There are **three separate failures**, only one of which is the familiar failure of positivity over a finite field.

### 2.1 The degree moves with the point

In the classical orthogonal-polynomial use of CD, one fixes a degree \(n\), studies all roots
\[
x_1,\ldots,x_n\quad\text{of one polynomial }R_n(x),
\]
and evaluates one fixed kernel \(K_{n-1}\) on those points. At a root \(x_i\),
\[
K_{n-1}(x_i,x_i)
\propto R'_n(x_i)R_{n-1}(x_i),
\]
which is the reciprocal-quadrature-weight/nondegeneracy quantity. It is normally **nonzero**, not a polynomial whose zero set contains the roots.

Our condition is fundamentally different:
\[
R_r(\lambda_r)=0,
\]
with **both the degree \(r\) and the evaluation point \(\lambda_r\) moving together**. The set \(Z_p\) picks one distinguished diagonal entry from each different polynomial. There is no single \(R_n\), and no single \(K_{n-1}\), whose root set is \(Z_p\).

This moving-degree issue is the main obstruction.

### 2.2 Positivity is absent over \(\mathbf F_p\)

Over \(\mathbf R\),
\[
K_m(x,x)=\sum_{k=0}^m(2k+1)R_k(x)^2
\]
is a positive quadratic norm when the weights are positive. Over \(\mathbf F_p\), the same expression is merely a quadratic form. It may be isotropic, so many nonzero coordinate vectors can have zero norm.

Thus even if one knew that \(K_m(\lambda_r,\lambda_r)=0\) at many points, finite-field cancellation would prevent the real-variable interpretation “all the individual coordinates are small/zero.”

But this is secondary here: by (1), an ordinary simple Apéry zero does not even force kernel vanishing.

### 2.3 An Apéry zero kills only one summand

For a fixed \(m\ge r\), the condition \(R_r(\lambda_r)=0\) removes exactly the \(k=r\) term from
\[
K_m(\lambda_r,\lambda_r)
 =\sum_{k=0}^m(2k+1)R_k(\lambda_r)^2.
\]
All the other \(R_k(\lambda_r)\) are generically nonzero. There is no reason for their weighted sum of squares to vanish.

So for fixed \(m\), the basic logical relation is

```text
R_r(lambda_r)=0
   does NOT imply
K_m(lambda_r,lambda_r)=0.
```

Without such an implication, the fact that \(K_m(x,x)\) has controlled degree cannot count \(Z_p\).

## 3. Matrix formulation: CD controls Gram norms, whereas \(Z_p\) is a diagonal-entry condition

This makes the mismatch especially transparent.

For a fixed cutoff \(m\), form the evaluation rows
\[
v(x)=(R_0(x),R_1(x),\ldots,R_m(x))
\]
and the diagonal weight matrix
\[
W_m=\operatorname{diag}(1,3,5,\ldots,2m+1).
\]
Then
\[
K_m(x,y)=v(x)W_m v(y)^T.
\]
Thus \(K_m(x,x)\) is the weighted Gram norm of the entire row \(v(x)\).

By contrast, at the Apéry node \(x=\lambda_r\), the condition defining \(Z_p\) says only that the **single moving coordinate**
\[
[v(\lambda_r)]_r=R_r(\lambda_r)
\]
vanishes.

Under the self-dual Racah normalization used in Session 1, the evaluation matrix can equivalently be viewed as a symmetric Racah-transform matrix; then \(Z_p\) is a zero set on its diagonal, while CD produces a weighted Gram matrix. Even abstractly, zero diagonal entries of a matrix are not controlled by zero diagonal entries or rank loss of its Gram matrix over a finite field. An invertible permutation matrix with no fixed points is the elementary warning: its diagonal can vanish identically while its Gram matrix is nonsingular.

So a rank argument based only on the CD Gram factorization cannot turn many Apéry diagonal zeros into low rank.

## 4. The useful theorem CD *does* give: singular Apéry zeros are exactly kernel-zero points

Define, away from the recurrence-exceptional levels,
\[
Z_p^{\mathrm{sing}}
 :=\{r\in Z_p:K_{r-1}(\lambda_r,\lambda_r)=0\}.
\]
Then (2) gives
\[
\boxed{
Z_p^{\mathrm{sing}}
=\{r: R_r(\lambda_r)=0,\ R'_r(\lambda_r)=0\}.
}
\tag{3}
\]
So CD cleanly separates the zero set into
\[
Z_p=Z_p^{\mathrm{simple}}\sqcup Z_p^{\mathrm{sing}},
\]
where
\[
r\in Z_p^{\mathrm{simple}}
\Longrightarrow K_{r-1}(\lambda_r,\lambda_r)\ne0.
\]

That is genuinely useful information. The singular part can now be attacked by a resultant/discriminant condition for each degree:

```text
R_r(lambda_r) = 0
R'_r(lambda_r) = 0
        |
        v
Disc_x(R_r) = 0   (equivalently Res_x(R_r,R'_r)=0),
```

with appropriate leading-coefficient caveats. If the Racah recurrence permits the specialized discriminant/resultant to be rewritten as a low-complexity function of \(r\) modulo \(p\), then (3) could make the singular subset very small.

What it **cannot** do is bound the simple part, because simple zeros are precisely the points at which this CD kernel is a unit.

Hence even the strongest possible outcome “there are no singular Apéry zeros” would only prove that every Apéry zero is transversal; it would not reduce \(|Z_p|\).

## 5. The off-diagonal CD formula also confirms the obstruction

Again let \(a=\lambda_r\) with \(R_r(a)=0\), and take \(m=r-1\). For \(y\ne a\), CD gives
\[
K_{r-1}(a,y)
=-\frac{r^3}{2}\,R_{r-1}(a)\frac{R_r(y)}{a-y}
\]
with the sign corresponding to the orientation in Q3582.

So one row of the kernel becomes, up to a nonzero scalar, the divided polynomial
\[
\frac{R_r(y)}{y-a}.
\]
This is exactly the familiar Lagrange/Gaussian-quadrature structure: **once a root of a fixed \(R_r\) is known**, CD gives a very rigid interpolation row.

But if \(s\in Z_p\) is another Apéry zero, all we know is
\[
R_s(\lambda_s)=0,
\]
not
\[
R_r(\lambda_s)=0.
\]
Therefore
\[
K_{r-1}(\lambda_r,\lambda_s)
\]
is generically nonzero as well. Racah self-duality merely rewrites the cross-value; it does not turn a diagonal zero at \(s\) into the required cross-zero at \(r\).

This closes the most obvious pairwise-kernel route: two members of \(Z_p\) do not automatically give orthogonal kernel rows or a vanishing kernel minor.

## 6. Why a fixed-cutoff degree argument would be powerful — and exactly what is missing

For a **fixed** \(m\), the diagonal CD expression is the Wronskian-type polynomial
\[
D_m(x):=R'_{m+1}(x)R_m(x)-R'_m(x)R_{m+1}(x).
\]
If \(\deg R_j=j\), then
\[
\deg D_m\le 2m.
\]
Consequently, if one could prove a new implication of the form
\[
\boxed{
R_r(\lambda_r)=0
\Longrightarrow
D_m(\lambda_r)=0
\quad\text{for all }r\in Z_p
}
\tag{4}
\]
for **one fixed cutoff \(m\ll p\)**, then an immediate degree argument would become available. If the Racah spectral map \(r\mapsto\lambda_r\) has uniformly bounded fibers (as in the usual quadratic Racah coordinate, where the only collision is the standard involution), a root bound for \(D_m\) would translate into a comparable bound for \(|Z_p|\).

For example, a bridge with \(m\asymp p^{1/2+\varepsilon}\) would be of exactly the right scale to force a square-root-type estimate.

But (4) is **not** a consequence of CD. The natural variable cutoff \(m=r-1\) gives the opposite behavior:
\[
D_{r-1}(\lambda_r)\ne0
\]
at every simple zero.

Thus the research question should be sharpened from “can CD count the zeros?” to:

> **Is there an Apéry/Racah-specific transfer identity that sends the moving diagonal zero \(R_r(\lambda_r)=0\) into the zero set of one fixed-cutoff CD/Wronskian object?**

Without such a transfer identity, CD has no degree-counting leverage on total \(|Z_p|\).

## 7. Summing or tracing the kernel does not recover the count

One might try to sum the diagonal kernel over the Apéry nodes. This also fails at the formal level. For fixed \(m\),
\[
\sum_{r\in Z_p}K_m(\lambda_r,\lambda_r)
 =\sum_{k=0}^m(2k+1)
   \sum_{r\in Z_p}R_k(\lambda_r)^2.
\]
The defining zero \(R_r(\lambda_r)=0\) is on a *different coordinate* for each \(r\). It therefore does not remove one common \(k\)-slice from the trace; it removes a diagonal collection of individual entries.

Over \(\mathbf R\), positivity could sometimes turn a trace or energy into cardinality information after a uniform lower bound. Over \(\mathbf F_p\), there is neither an order nor a positive lower bound, and the quadratic sums can cancel. So there is no finite-field analogue of “each point contributes positive mass” available from the CD identity alone.

One would need a separate character-sum/Deligne estimate for these trace sums. At that point the cancellation is coming from the trace-function theorem, not from CD itself.

## 8. Terminal-level warning: the finite-field kernel is itself degenerate

There is also a normalization warning at the top of the range. The CD prefactor is
\[
\frac{(m+1)^3}{2}.
\]
At \(m=p-1\) this prefactor is divisible by \(p\). Thus the terminal CD formula is a singular level modulo \(p\). One should **not** use \(m=p-1\) as though it were a positive definite full reproducing kernel.

Formally the prefactor vanishes mod \(p\); whether one may literally conclude an identically vanishing full kernel depends on the integral/cleared-denominator normalization of the Session-1 Racah polynomials at the occurrence of \(R_p\). That check should be made before reducing the right side modulo \(p\). Independently, the weight \(2k+1\) itself vanishes at \(k=(p-1)/2\).

So the finite-field full kernel has precisely the sort of degeneracies that the real RMT intuition suppresses.

This is not the main no-go — the moving-degree issue already kills the argument — but it is another reason to avoid importing positivity/reproducing-kernel heuristics verbatim.

## 9. A precise lemma worth recording in the P3.2 notes

The following is the clean reusable output of this attack.

### CD transversality lemma

Let \(p>2\). Fix \(1\le r<p\) such that the Racah three-term recurrence and the Session-1 CD normalization are defined modulo \(p\) and the backward recurrence coupling at all levels needed to exclude a common root of \(R_r\) and \(R_{r-1}\) is a unit. If
\[
R_r(\lambda_r)=0,
\]
then
\[
K_{r-1}(\lambda_r,\lambda_r)
=\frac{r^3}{2}R'_r(\lambda_r)R_{r-1}(\lambda_r),
\]
with
\[
R_{r-1}(\lambda_r)\ne0.
\]
Hence
\[
K_{r-1}(\lambda_r,\lambda_r)=0
\iff
\lambda_r\text{ is a multiple root of }R_r(x),
\]
and in particular every simple Apéry zero has nonzero diagonal CD kernel.

The exceptional set to isolate explicitly in a formal statement is:

1. \(p=2\);
2. \(r=0\) (where the displayed prefactor is zero);
3. recurrence levels at which a leading/backward coefficient or chosen polynomial normalization has a pole/zero modulo \(p\);
4. any terminal level at which the characteristic-zero CD identity has not yet been put into a denominator-safe integral form.

For the core range in P3.2, these should be checked from the exact Racah normalization once and then removed from all later uses.

## 10. What would actually resurrect CD as a global \(|Z_p|\) weapon?

There are four concrete ways this could become useful. Each requires an **extra theorem beyond CD**.

### A. Fixed-degree bridge

Find \(m=m(p)\ll p\) and prove
\[
r\in Z_p\Longrightarrow K_m(\lambda_r,\lambda_r)=0
\]
or, equivalently away from the prefactor degeneracy,
\[
r\in Z_p\Longrightarrow D_m(\lambda_r)=0.
\]
Then degree immediately counts nodes. This would be decisive, but the natural choices \(m=r-1,r\) fail in the strongest possible way.

### B. Fixed low-degree annihilator

Use the Racah/Apéry structure to construct a polynomial \(Q_p(x)\) of degree \(O(p^{1/2+\varepsilon})\) such that
\[
Q_p(\lambda_r)=0\quad(r\in Z_p).
\]
CD could help construct \(Q_p\) through kernel interpolation, but the annihilation relation itself is the missing input.

### C. Rank-loss theorem for a selected kernel matrix

For a large subset \(T\subseteq Z_p\), prove that the Apéry diagonal zeros force a selected CD matrix
\[
(K_m(\lambda_r,\lambda_s))_{r,s\in T}
\]
to have rank substantially below \(|T|\), while an independent Vandermonde/orthogonality argument gives a lower rank bound. CD supplies the factorization, but, as Section 3 shows, diagonal zeros alone do not give this rank loss. A new Apéry-specific cross-zero relation would be needed.

### D. Trace-function cancellation for the CD energy

If one can express the specialized quantities
\[
K_m(\lambda_r,\lambda_r)
\]
as a bounded-conductor trace function in \(r\), then one might estimate moments over \(r\) and compare zero/nonzero strata. This can be useful, but the square-root cancellation would then come from the geometric trace-function input. CD would be a convenient algebraic packaging, not the source of the \(p^{1/2}\) bound.

Among these, **A** is the only genuinely “CD gives the count by degree” route. At present there is no evidence for the required implication, and (1) warns that it cannot arise from the local kernel identity alone.

## 11. Recommended disposition for the campaign

I would mark this attack as follows.

```text
CD diagonal -> total |Z_p|:      NO, not directly.
Reason:                         simple Apéry zeros give NONZERO K_{r-1}.
CD diagonal -> singular zeros:  YES, exact and clean.
CD off diagonal -> pair count:  NO without a new cross-zero/transfer law.
Fixed-cutoff CD -> |Z_p|:       POTENTIALLY YES, but only after a new bridge.
```

So this should **not** replace the current global zero-set avenues in `AVENUES.md`. The recurrence/short-window/transfer/resultant and trace-function routes remain the mechanisms that can plausibly control the total zero set. The CD identity should be retained as a secondary structural lemma because it packages the derivative/nondegeneracy at an Apéry zero extremely well.

A particularly useful next micro-task, if we want to exploit the new Racah structure rather than drop it entirely, is to derive the exact recurrence satisfied by the specialized derivative quantity
\[
d_r:=R'_r(\lambda_r)
\]
*on the locus* \(R_r(\lambda_r)=0\), and see whether the Apéry recurrence forces \(d_r\) to be a unit for all core indices. That would establish that all core Apéry zeros are transversal. It still would not improve \(|Z_p|\) by itself, but it would remove singular fibers from later elimination/trace arguments and can materially simplify them.

## Bottom line

**No direct \(|Z_p|\) improvement comes from the diagonal Christoffel–Darboux kernel.** The standard RMT mechanism fixes one degree and varies its roots; the Apéry condition is a moving-degree/moving-node diagonal condition. At a good Apéry zero,
\[
K_{r-1}(\lambda_r,\lambda_r)
=\frac{r^3}{2}R'_r(\lambda_r)R_{r-1}(\lambda_r),
\]
so the kernel vanishes exactly at the *multiple-root* Apéry zeros and is generically nonzero on the simple ones. Keep CD as a **transversality/singularity detector**. To turn it into a global zero-count theorem, we need a genuinely new fixed-degree transfer/annihilation identity; CD alone does not supply it.
