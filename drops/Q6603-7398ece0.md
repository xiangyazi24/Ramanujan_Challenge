# Adversarial audit of the local Fourier type

## Executive verdict

The parallel computation contains a correct cohomological core, but it is not paper-ready as stated.

The verdicts are:

```text
(C1) CONFIRMED, provided the h displayed denominator points remain exact
     cubic poles modulo p.  The GOS dimension is exactly 4h-2, and the
     three-point window correction is exact under the same hypothesis.

(C2) CORRECTED (+fix).  The rank, the local type at t=0, and the generic
     good-reduction type at t=infinity are correct.  However:
       - chi_3^h must mean h copies, not the h-th tensor power;
       - unramified Gauss twists and the Fourier-sign convention were omitted;
       - Riemann-Hurwitz gives 4h-4 residual ramification only with
         multiplicity, not 4h-4 simple nonzero critical points;
       - the asserted infinity type is false at bad reductions.  Already for
         h=2 it changes at p=13 and p=17.

(C3) CONFIRMED, after defining c_(h,k) as the number of dominant geometric
     components of the normalized generic fiber product.  It is not the
     number of all components of an uncleared projective equation.

(C4) CORRECTED (+fix), and this is GRAM-OP-sensitive.  The identity
     4h+1=(4h-2)+3 is a total-complexity count for a virtual/derived window
     correction.  There is no genuine lisse rank-(4h+1) window sheaf whose
     Hom space is still c_(h,k)-1.  The three endpoint lines create explicit
     p-sized Gram terms and must be split off or projected out.
```

Thus the core GRAM-OP chain survives only in the following form:

```text
core sheaves G_h:       rank/Hom/local-conductor package survives;
windowed trace family:  endpoint rank-one block must be handled separately;
all-p, all-h use:        requires a good-reduction stratification.
```

The most serious hidden issue is not a two-unit rank error.  It is the jump from
characteristic-zero branch data to an exact characteristic-p local type.  For
fixed h there are only finitely many bad primes, but that statement is not
uniform when h grows with p.

# 1. Precise setup and the required good-reduction hypotheses

Write

```text
Q_h(r) = product_(j=1)^h (r+j),
f_h(r) = N_h(r)/Q_h(r)^3,
d = deg(f_h) = 3h.
```

The earlier determinant and boundary calculation gives over Q

```text
N_h(-j)
 = (-1)^(j-1) * ((j-1)!*(h-j)!)^3
   * b_(j-1)*b_(h-j),
1 <= j <= h.
```

Hence over Q the points `-1,...,-h` are exact cubic poles and infinity is a
zero of order three.

For a characteristic-p local-type theorem, one must state at least:

```text
[GOOD-POLE_h(p)]
  p > 3, h < p, and N_h(-j) != 0 mod p for every 1 <= j <= h.
```

This guarantees h distinct exact cubic poles.  It is not automatic from the
characteristic-zero formula: an Apery factor b_(j-1) or b_(h-j) can vanish
modulo p.

For the full displayed infinity decomposition claimed by the worker, one needs
the stronger condition

```text
[GOOD-CRIT_h(p)]
  GOOD-POLE_h(p),
  ord_infinity(f_h)=3,
  and all remaining ramification consists of 4h-4 tame simple points whose
  critical values are nonzero.
```

The last line is a genuine additional theorem.  Riemann-Hurwitz alone does not
prove simplicity or nonzero critical values.

All exact local-type statements below are over Fbar_p and assume the relevant
good-reduction condition.  Unramified constant-field twists are suppressed
when discussing geometric inertia.

# 2. Claim (C1): GOS dimension and the three endpoint lines

## 2.1 [CONFIRMED] The dimension is 4h-2

Let

```text
V_h = P^1_r minus {-1,-2,...,-h},
L_t = L_psi(t*f_h),
t != 0.
```

Under GOOD-POLE, every deleted point has Swan conductor three.  Infinity lies
inside V_h and is regular for L_t.  The rank-one Grothendieck-Ogg-Shafarevich
formula gives

```text
chi_c(V_h,L_t)
 = chi_c(V_h,Qbar_l) - sum_(j=1)^h Swan_(-j)(L_t)
 = (2-h) - 3h
 = 2-4h.
```

The outside cohomology groups vanish:

```text
H_c^0(V_h,L_t)=0
```

because V_h is connected and nonproper, and

```text
H_c^2(V_h,L_t)=0
```

because Poincare duality identifies it with the dual of the geometric invariant
space of L_t^vee, while wild inertia at any cubic pole is nontrivial.

Therefore

```text
boxed:
dim H_c^1(V_h,L_t)=4h-2.
```

This also gives the generic rank of

```text
G_h = FT_psi(P_h[1])[-1]
```

on t != 0.  Indeed, with

```text
A_h=(f_h)_*Qbar_l = Qbar_l direct_sum P_h,
```

the Fourier transform of the constant summand has zero generic stalk on G_m,
and proper base change plus the projection formula identifies the remaining
stalk with H_c^1(V_h,L_t), up to the global Fourier shift/sign convention.

The worker's formula

```text
chi_c = 2 - s_h - n_h,
s_h=h, n_h=3h,
```

is therefore correct.

## 2.2 [CONFIRMED] There are no H_c^0 or H_c^2 trace corrections

For t != 0,

```text
S_core,h(t)
 := sum_(x in V_h(F_p)) psi(t*f_h(x))
 = -Tr(Frob_p | H_c^1(V_h,L_t)).
```

There is no hidden H_c^0 term and no H_c^2 main term.  The point infinity is
not a cohomological correction; it is an ordinary point of V_h(F_p), with

```text
f_h(infinity)=0,
psi(t*f_h(infinity))=1.
```

## 2.3 [CONFIRMED] The window removes exactly three regular points

The fixed-h nonwrapping window is

```text
1 <= r <= p-h-2.
```

Under GOOD-POLE, the affine points of V_h(F_p) are

```text
r=0,1,...,p-h-1.
```

Hence the projective core differs from the window at exactly

```text
r=infinity,
r=0,
r=-h-1 = p-h-1.
```

Put

```text
gamma_h = f_h(0).
```

The proved reflection identity gives

```text
f_h(-h-1)=-f_h(0)=-gamma_h.
```

Thus the raw sums satisfy the exact identity

```text
boxed:
S_win,h(t)
 = S_core,h(t)
   - 1 - psi(gamma_h*t) - psi(-gamma_h*t).
```

At the sheaf level this comes from a distinguished triangle obtained by deleting
three rational source sections.  It is safer to call it a distinguished triangle
or a Grothendieck-group identity, not a short exact sequence of lisse sheaves.

A Fourier convention may multiply every trace by one common sign because of the
perverse shifts.  The raw exponential-sum identity above has no ambiguity.

## 2.4 Necessary caveat

If a displayed pole cancels modulo p, then the full rational map is regular at
that point while the nonwrapping window still omits it.  The difference between
the true projective core and the window then contains additional punctual lines.
Consequently, both the exact rank 4h-2 and the exact three-line correction must be
stated under GOOD-POLE, or replaced by the actual-pole formula from Q6581.

# 3. Claim (C2): local monodromy of G_h

## 3.1 Source local monodromy at y=infinity

At each of the h cubic poles of f_h, tame inertia cyclically permutes three
sheets.  Therefore the local permutation representation of A_h at y=infinity is

```text
1^(oplus h)
direct_sum chi_3^(oplus h)
direct_sum chi_3^(-1, oplus h).
```

Removing the global constant summand gives

```text
P_h | I_y=infinity
 = 1^(oplus(h-1))
   direct_sum chi_3^(oplus h)
   direct_sum chi_3^(-1, oplus h).
```

This proves an important notation correction:

```text
"chi_3^h" must mean h copies of chi_3.
```

It cannot mean the h-th tensor power, which would have rank one and would destroy
the rank count.

## 3.2 [CONFIRMED] Local type at t=0

Laumon's stationary-phase sequence identifies

```text
G_h|I_0 / (G_h|I_0)^(I_0)
```

with the local Fourier transform FTloc(infinity,0) of the preceding tame source
representation.  On geometric tame characters this transform preserves the
rank-one Kummer character up to inversion and an unramified Gauss twist.  Since
the pair chi_3, chi_3^(-1) is stable under inversion, the quotient has geometric
semisimplification

```text
1^(oplus(h-1))
direct_sum chi_3^(oplus h)
direct_sum chi_3^(-1, oplus h),
```

of rank 3h-1.

The generic rank is 4h-2, so

```text
dim (G_h|I_0)^(I_0) = (4h-2)-(3h-1)=h-1.
```

It remains to justify the claimed U_2 blocks rather than merely the
semisimplification.  On the generalized eigenvalue-one part, the quotient by
invariants is trivial of dimension h-1 and the invariant subspace also has
dimension h-1.  If T is a tame inertia generator, then

```text
(T-1)^2=0,
ker(T-1) has dimension h-1,
the generalized 1-eigenspace has dimension 2h-2.
```

Thus rank(T-1)=h-1, and the Jordan form is exactly h-1 blocks of size two.
Therefore

```text
boxed:
G_h | I_0
 = U_2^(oplus(h-1))
   direct_sum chi_3^(oplus h)
   direct_sum chi_3^(-1, oplus h),
```

up to geometrically trivial unramified twists.  In particular,

```text
Swan_0(G_h)=0.
```

So this part of (C2) is confirmed under GOOD-POLE.

## 3.3 Source local monodromy at finite branch values

Under GOOD-CRIT, the branch value y=0 has one cubic ramification point, namely
r=infinity.  Modulo its invariant part, the source local representation is

```text
chi_3 direct_sum chi_3^(-1).
```

Each of the other 4h-4 critical points is simple.  At its critical value a_x,
the non-invariant source local representation is the quadratic character
chi_2.  Several critical points may have the same critical value; the local
representation at that value is then the direct sum of their chi_2 lines.  The
count is by critical points, not necessarily by distinct critical values.

## 3.4 [CONFIRMED UNDER GOOD-CRIT] Local type at t=infinity

Stationary phase at target infinity gives one local-Fourier contribution from
each finite source branch point.  The source singularity at y=infinity is tame
of slope zero and contributes nothing through FTloc(infinity,infinity).

The branch value y=0 contributes a tame rank-two piece

```text
chi_3 direct_sum chi_3^(-1).
```

A simple critical point x with nonzero critical value a_x contributes

```text
L_psi(epsilon*a_x*t) tensor chi_2 tensor alpha_x,
```

where

```text
epsilon is +1 or -1 according to the Fourier-kernel convention,
alpha_x is an unramified Gauss-sum twist.
```

Geometrically alpha_x is invisible.  Reflection pairs the phases even if the
Fourier sign is reversed.

Hence under GOOD-CRIT,

```text
boxed:
G_h | I_infinity
 = (chi_3 direct_sum chi_3^(-1))
   direct_sum
   direct_sum_(x critical, a_x != 0)
     (L_psi(epsilon*a_x*t) tensor chi_2),
```

with

```text
rank(G_h)=2+(4h-4)=4h-2,
Swan_infinity(G_h)=4h-4.
```

Every Artin-Schreier phase line has break one.  The cubic Kummer pair has break
zero.

The same stationary-phase description shows that G_h is lisse on G_m and has
no singularities other than t=0 and t=infinity.

## 3.5 The worker overclaimed what Riemann-Hurwitz proves

For a degree-3h map P^1 -> P^1, the total tame ramification degree is

```text
2*(3h)-2 = 6h-2.
```

The h cubic poles contribute 2h.  If infinity is a cubic zero, it contributes
two.  Therefore the remaining ramification divisor has degree 4h-4.

This proves only

```text
sum_(remaining points) (e_x-1) = 4h-4.
```

It does not prove that all these points are simple, that their critical values
are nonzero, or that the critical values are distinct.  Thus the explicit sum
of 4h-4 quadratic lines is conditional unless an independent discriminant and
critical-value resultant theorem is supplied.

A robust corrected formulation is available.  Assume exact cubic poles and
tame separable ramification, and define

```text
rho_0  = total ramification contribution away from the poles over y=0,
rho_nz = total ramification contribution over nonzero finite values.
```

Then tame Riemann-Hurwitz gives

```text
rho_0 + rho_nz = 4h-2,
```

and stationary phase gives

```text
rank of break-0 part at t=infinity = rho_0,
rank of break-1 part at t=infinity = rho_nz,
Swan_infinity(G_h)=rho_nz.
```

The worker's formula is the special case

```text
rho_0=2,
rho_nz=4h-4.
```

This corrected form is enough for many conductor upper bounds, but not for an
argument that uses the individual chi_2 summands.

# 4. Complete h=2 audit by hand

Put

```text
u=r+1,
z=u*(u+1).
```

Then

```text
P(u)=(2u+1)*(17z+5),
f_2(u)=P(u)/z^3.
```

The two points u=0,-1 are exact cubic poles for every p>=7, since the two polar
numerators are 5 and -5.

Differentiate.  Since

```text
P'(u)=102z+27,
(2u+1)^2=4z+1,
```

one obtains

```text
boxed:
f_2'(u)
 = -3*(34z^2+28z+5)/z^4.
```

## 4.1 Characteristic zero and generic good primes

The quadratic in z has discriminant

```text
28^2-4*34*5=104.
```

Its two roots are distinct.  Neither root is z=-1/4, so each has two distinct
preimages under u -> u(u+1).  Thus there are four simple critical points.

Their values are nonzero: a zero of P would require either z=-1/4 or
z=-5/17, and neither satisfies 34z^2+28z+5=0.

Hence at a generic good prime the worker's h=2 type is correct:

```text
V_2=P^1 minus {u=0,-1},
chi_c(V_2,L_t)=2-2-3-3=-6,
dim H_c^1(V_2,L_t)=6.
```

The source sheaf P_2 has rank five.  At y=infinity,

```text
P_2|I_infinity
 = 1 direct_sum chi_3^(oplus 2) direct_sum chi_3^(-1, oplus 2).
```

Therefore at t=0,

```text
G_2|I_0
 = U_2 direct_sum chi_3^(oplus 2) direct_sum chi_3^(-1, oplus 2),
```

of rank six and Swan zero.

At t=infinity there is one tame cubic pair plus four quadratic phase lines:

```text
rank=2+4=6,
Swan_infinity=4.
```

## 4.2 p=13: rank six and Swan four survive, but the chi_2 decomposition fails

Modulo 13, the discriminant 104 vanishes.  In fact

```text
34z^2+28z+5 = 8*(z-8)^2 mod 13.
```

The two points above z=8 are double zeros of f_2'.  Since p!=3, each is a cubic
ramification point, not two simple quadratic ramification points.  Their values
are nonzero.

Thus at target infinity the break-one rank is still four and

```text
Swan_infinity(G_2)=4,
```

but it is organized as two rank-two cubic tame quotients tensored with two
nonzero Artin-Schreier phases, not as four chi_2 lines.

There is a second p=13 warning for (C4):

```text
gamma_2=f_2(0)=P(1)/8=117/8=0 mod 13.
```

So the two endpoint phase lines coincide with the constant line.

## 4.3 p=17: Swan four is false

Modulo 17,

```text
P(u)=5*(2u+1).
```

Consequently f_2 has a zero of order five at u=infinity, not order three.  The
ramification contribution over y=0 is four.  The derivative equation becomes
linear in z and gives only two remaining simple critical points.

Therefore

```text
rho_0=4,
rho_nz=2,
rank(G_2)=rho_0+rho_nz=6,
Swan_infinity(G_2)=2.
```

The break-zero part is the four-dimensional nontrivial part of a tame degree-five
cycle, not chi_3 direct_sum chi_3^(-1).

This is an explicit counterexample to any statement of (C2) for every p>=7.
The rank-six GOS statement remains true because the two cubic poles remain exact.

# 5. Claim (C3): Hom dimension and fiber-product components

Let U be a common dense open subset of the y-line over which f_h and f_k are
finite etale.  The sheaves A_h and A_k on U are the permutation local systems on
the two geometric fibers.  Hence

```text
Hom_geom(A_h,A_k)
 = H^0(Ubar,A_h^vee tensor A_k)
```

is the space of invariant functions on the product of the two fibers.
Its dimension is the number of geometric pi_1(U)-orbits on that product.
These orbits are exactly the geometrically connected components of the
normalized generic fiber product

```text
P^1_r x_(P^1_y) P^1_r'.
```

Equivalently, they are the dominant geometric components of

```text
f_h(r)=f_k(r').
```

Call this number c_(h,k).  Since the two covers have connected source,

```text
A_h = 1 direct_sum P_h,
A_k = 1 direct_sum P_k,
P_h^(pi_1)=P_k^(pi_1)=0.
```

The cross Hom spaces from or to the constant summand vanish, so

```text
boxed:
dim Hom_geom(P_h,P_k)=c_(h,k)-1.
```

Fourier-Deligne transform is an equivalence on the relevant perverse category,
so the same dimension is

```text
dim Hom_geom(G_h,G_k).
```

Thus (C3) is confirmed.

Two precision clauses must enter the paper:

1. `c_(h,k)` means components of the normalization of the generic fiber
   product, or equivalently dominant components.  Vertical pole components and
   components created only by clearing denominators do not count.

2. The statement is characteristic-by-characteristic.  A component census over
   Qbar does not prevent extra components after reduction modulo an exceptional
   prime.  A growing-h application needs a uniform bad-reduction analysis.

# 6. Claim (C4): the 4h+1 count is not a lisse-sheaf rank

Define the explicit endpoint trace

```text
E_h(t)=1+psi(gamma_h*t)+psi(-gamma_h*t).
```

Then

```text
S_win,h(t)=S_core,h(t)-E_h(t).
```

The numerical identity

```text
4h+1=(4h-2)+3
```

is harmless as a total number of rank-one terms in a distinguished triangle or
as a triangle-inequality complexity bound.  It is not the rank of G_h, and it is
not the rank of a new lisse sheaf having the same Hom dictionary as G_h.

In the Grothendieck group the correct schematic identity is

```text
[K_win,h]
 = [G_h] - [1] - [L_psi(gamma_h*t)] - [L_psi(-gamma_h*t)],
```

up to the common Fourier shift/sign convention.  Negative signs are realized by
cohomological shifts, not by an ordinary direct sum of lisse sheaves.

## 6.1 The endpoint lines have different local conductors

At t=0 all three endpoint lines are unramified.

At t=infinity:

```text
the constant line has break 0;
L_psi(gamma_h*t) and L_psi(-gamma_h*t) have break 1
when gamma_h != 0.
```

Thus an auxiliary positive direct sum of absolute terms would add rank three but
also add Swan two at infinity when gamma_h != 0.  At primes such as h=2,p=13,
where gamma_h=0, all three lines are constant and the Swan addition is zero.

Therefore the phrase "+3 at each cusp" is not a complete local-conductor
statement.

## 6.2 The endpoint Gram block has p-sized main terms

The endpoint lines cannot be absorbed into an O(sqrt(p)) error.  Over G_m(F_p),
count the three frequencies with multiplicity:

```text
A_h={0,gamma_h,-gamma_h},
A_k={0,gamma_k,-gamma_k}.
```

Let n_eq(h,k) be the number of ordered pairs (a,b) in A_h x A_k with a=b.
Additive orthogonality gives the exact identity

```text
sum_(t!=0) E_h(t)*conj(E_k(t))
 = p*n_eq(h,k)-9.
```

In particular n_eq(h,k)>=1 because 0=0, so there is always a p-sized rank-one
constant block.  If gamma_h=plus_or_minus gamma_k, two more frequency matches
occur.  If gamma_h=gamma_k=0, all nine pairs match.

Core-endpoint terms can also be p-sized.  Fourier inversion identifies a
correlation of the core Fourier trace with L_psi(a*t) with p times the source
trace of P_h at y=a, up to the common sign and the omission of t=0.  Thus a
rank comparison alone does not control these terms.

## 6.3 Consequence for the GRAM-OP chain

The core implication

```text
component census
  -> dim Hom_geom(G_h,G_k)
  -> core-core Gram main term
```

is valid.

The passage from core traces to window traces must be written as an explicit
finite-rank perturbation.  A correct implementation has two options:

```text
Option A: project away the endpoint frequency vectors before forming the
          Gram operator;

Option B: expand all core-core, core-endpoint, and endpoint-endpoint terms,
          using the exact rank-one formulas above.
```

What is not valid is

```text
replace rank 4h-2 by rank 4h+1,
retain dim Hom = c_(h,k)-1,
and apply one black-box pure-sheaf Gram estimate.
```

That operation loses both the weights and the new rank-one Hom spaces.

Accordingly:

```text
If (8.2)-(8.7) already separates the three endpoint functions,
  no exponent changes; only constants/local-conductor lines need correction.

If (8.2)-(8.7) treats the windowed object as one lisse rank-(4h+1) sheaf and
uses c_(h,k)-1 as its Hom dimension,
  the chain is not proved and must be rewritten.
```

# 7. Paper-ready corrected local theorem

The following is safe to bank.

```text
THEOREM [LOCAL-FT-GOOD]
Fix h and a prime p satisfying GOOD-CRIT_h(p).  Let
A_h=(f_h)_*Qbar_l=Qbar_l direct_sum P_h and
G_h=FT_psi(P_h[1])[-1].  Then:

1. G_h is lisse on G_m of rank 4h-2 and is singular only at 0 and infinity.

2. At 0,
   G_h = U_2^(oplus(h-1))
         direct_sum chi_3^(oplus h)
         direct_sum chi_3^(-1, oplus h),
   up to unramified twists, and Swan_0=0.

3. At infinity,
   G_h = (chi_3 direct_sum chi_3^(-1))
         direct_sum_x
           (L_psi(epsilon*a_x*t) tensor chi_2 tensor alpha_x),
   where x runs through the 4h-4 simple critical points,
   epsilon depends only on the Fourier convention, and alpha_x is unramified.
   Hence Swan_infinity=4h-4.

4. For t!=0,
   dim H_c^1(V_h,L_psi(t*f_h))=4h-2,
   and H_c^0=H_c^2=0.

5. The window trace is the core trace minus the three explicit endpoint lines.
```

For an all-p theorem, replace item 3 by the ramification-divisor formulation
with rho_0 and rho_nz, and stratify failures of GOOD-POLE.  Do not claim the
quadratic-line decomposition uniformly.
