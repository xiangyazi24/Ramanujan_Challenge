
# 1. Positivity, integrability, and the geometric expansion

Put

```text
D = 1-(1-xy)z = 1-z+xyz,
A = x(1-x)y(1-y)z(1-z),
Q = D-A.
```

For `0<x,y,z<1`,

```text
D >= 1-z > 0.
```

Moreover,

```text
A/D
 <= x(1-x)y(1-y)z(1-z)/(1-z)
 = x(1-x)y(1-y)z
 <= 1/16.                                                (1.1)
```

Thus, almost everywhere on the closed cube,

```text
0 <= u:=A/D <= 1/16,
Q=D(1-u)>0.                                               (1.2)
```

The integrand satisfies

```text
(D+A)/Q^2
 = (1/D) (1+u)/(1-u)^2
 <= (272/225) * 1/D.                                     (1.3)
```

Also

```text
int_[0,1]^3 1/D dx dy dz = 2 zeta(3).                    (1.4)
```

Indeed, integrating first in `z`,

```text
int_0^1 dz/[1-(1-xy)z]
 = -log(xy)/(1-xy),
```

and Tonelli gives

```text
int_[0,1]^2 -log(xy)/(1-xy) dx dy
 = sum_(r>=0) int_[0,1]^2 (-log x-log y)x^r y^r dx dy
 = 2 sum_(r>=0) 1/(r+1)^3
 = 2 zeta(3).
```

Hence `J` is a genuine finite improper integral.

The elementary identity

```text
(1+u)/(1-u)^2 = sum_(n>=0)(2n+1)u^n                  (1.5)
```

holds for `|u|<1`. Since all terms are nonnegative, Tonelli yields

```text
J = sum_(n>=0)(2n+1) B_n,                               (1.6)
```

where

```text
B_n := int_[0,1]^3 A^n/D^(n+1) dx dy dz.                (1.7)
```

Equation (1.1) also gives the absolute bound

```text
0 < B_n <= 16^(-n) B_0 = 2 zeta(3) 16^(-n).             (1.8)
```

Thus the series in (1.6) converges absolutely.

A finite algebraic version of (1.5), useful for symbolic verification, is

```text
sum_(n=0)^N (2n+1)u^n
 = [1+u-(2N+3)u^(N+1)+(2N+1)u^(N+2)]/(1-u)^2.           (1.9)
```

# 2. Exact Beukers normalization: `B_n=2m_n`

Let `b_n,c_n` solve the homogeneous Apéry recurrence

```text
(n+1)^3 u_(n+1)-P(n)u_n+n^3u_(n-1)=0,
P(n)=(2n+1)(17n^2+17n+5),                               (2.1)
```

with

```text
b_0=1, b_1=5,
c_0=0, c_1=1.
```

Define

```text
m_n=b_n zeta(3)-6c_n.                                    (2.2)
```

The standard Beukers integral theorem states that

```text
m_n = (1/2) B_n.                                         (2.3)
```

Equivalently,

```text
B_n=2(b_n zeta(3)-6c_n)=2m_n.                            (2.4)
```

This factor `2` is load-bearing.

A modern source that writes the normalization exactly is Christoph Koutschan and Wadim Zudilin, *Apéry limits for elliptic L-values*, Bulletin of the Australian Mathematical Society 106 (2022), 273-279, DOI `10.1017/S0004972721001295`: in its opening Apéry example it writes

```text
I_n=v_n zeta(3)-u_n
   =(1/2) int_[0,1]^3
       x^n(1-x)^n y^n(1-y)^n z^n(1-z)^n
       /[1-(1-xy)z]^(n+1) dx dy dz,
```

with `I_0=zeta(3)` and `I_1=5zeta(3)-6`.

The original source is F. Beukers, *A note on the irrationality of zeta(2) and zeta(3)*, Bull. London Math. Soc. 11 (1979), 268-272, DOI `10.1112/blms/11.3.268`.

Our notation matches because the usual rational Apéry numerator has initial values `a_0=0,a_1=6`; hence `a_n=6c_n` by recurrence uniqueness.

The factor can also be checked at level zero without any citation:

```text
B_0=2zeta(3)=2m_0.
```

From (1.6) and (2.4),

```text
J=2 sum_(n>=0)(2n+1)m_n.                                (2.5)
```

# 3. The forced sequence and its exact zeta(2) limit

Let `q_n` be defined by

```text
q_0=0,
q_1=8,
(n+1)^3q_(n+1)-P(n)q_n+n^3q_(n-1)=8(2n+1).             (3.1)
```

We now give a self-contained proof that

```text
lim_(n->infinity) q_n/b_n=zeta(2).                       (3.2)
```

## 3.1 Positive Apéry remainder

For integers `n>=0` and `r>=1`, define

```text
W_n(r)
 := [ product_(j=1)^n (r-j) / product_(j=0)^n (r+j) ]^2
  = (1/r^2) product_(j=1)^n ((r-j)/(r+j))^2.             (3.3)
```

Let

```text
E_n := sum_(r=1)^infinity W_n(r).                        (3.4)
```

For `n>=1`, put

```text
C_n(r)=4(2n+1)[(2n+1)^2+r-2r^2],
G_n(r)=C_n(r)W_n(r).                                     (3.5)
```

The exact Gosper identity is

```text
(n+1)^3W_(n+1)(r)-P(n)W_n(r)+n^3W_(n-1)(r)
 =G_n(r+1)-G_n(r).                                       (3.6)
```

After division by `W_n(r)`, this is the explicit rational identity

```text
(n+1)^3 ((r-n-1)/(r+n+1))^2
-P(n)
+n^3 ((r+n)/(r-n))^2
=
C_n(r+1) r^4/[(r-n)^2(r+n+1)^2]-C_n(r).                 (3.7)
```

Multiplication by `(r-n)^2(r+n+1)^2` turns (3.7) into a polynomial identity in `n,r`.

Summing (3.6) over `r>=1` is legitimate by absolute convergence. For `n>=1`, `W_n(1)=0`, while

```text
W_n(r)=r^(-2)+O_n(r^(-3)),
C_n(r)=-8(2n+1)r^2+O_n(r),
```

so

```text
G_n(1)=0,
lim_(r->infinity)G_n(r)=-8(2n+1).                       (3.8)
```

Therefore

```text
(n+1)^3E_(n+1)-P(n)E_n+n^3E_(n-1)=-8(2n+1).            (3.9)
```

The initial values are

```text
E_0=zeta(2),
E_1=5zeta(2)-8.                                          (3.10)
```

For the second identity, use

```text
W_1(r)
=(r-1)^2/[r^2(r+1)^2]
=1/r^2+4/(r+1)^2-4/[r(r+1)].                            (3.11)
```

Hence the sequence

```text
zeta(2)b_n-E_n
```

satisfies (3.1) and has initial values `0,8`. By uniqueness,

```text
boxed:
zeta(2)b_n-q_n=E_n
=sum_(r=1)^infinity
 [ product_(j=1)^n (r-j) / product_(j=0)^n (r+j) ]^2.   (3.12)
```

The first `n` summands vanish. For `r>=n+1`, every product factor has absolute value below one, so

```text
0<zeta(2)b_n-q_n
<sum_(r=n+1)^infinity 1/r^2
<1/n.                                                    (3.13)
```

Since `b_n>0`,

```text
0<zeta(2)-q_n/b_n<1/(n b_n),                             (3.14)
```

which proves (3.2).

# 4. Discrete Lagrange summation with every sign fixed

Define

```text
(Lu)_n=(n+1)^3u_(n+1)-P(n)u_n+n^3u_(n-1).              (4.1)
```

For arbitrary sequences `u,v`, direct expansion gives

```text
u_n(Lv)_n-v_n(Lu)_n
=
(n+1)^3[u_n v_(n+1)-v_n u_(n+1)]
-n^3[u_(n-1)v_n-v_(n-1)u_n].                            (4.2)
```

This is the discrete Lagrange identity.

## 4.1 The `b,q` identity and the increment formula

Apply (4.2) with `u=b`, `v=q`. Since `Lb=0` and `Lq=8(2n+1)`, define

```text
T_n=n^3[b_(n-1)q_n-q_(n-1)b_n].                         (4.3)
```

Then

```text
T_(n+1)-T_n=8(2n+1)b_n.                                 (4.4)
```

Since `T_0=0`,

```text
T_n=8 sum_(k=0)^(n-1)(2k+1)b_k.                         (4.5)
```

Dividing by `n^3b_(n-1)b_n` gives exactly

```text
q_n/b_n-q_(n-1)/b_(n-1)
=
8 sum_(k=0)^(n-1)(2k+1)b_k
/[n^3b_(n-1)b_n].                                       (4.6)
```

The sign is positive.

## 4.2 The `m,q` identity

Since `Lm=0`, (4.2) with `u=m`, `v=q` gives, for every `N>=0`,

```text
8 sum_(n=0)^N (2n+1)m_n
=(N+1)^3[m_Nq_(N+1)-q_Nm_(N+1)].                        (4.7)
```

There is no minus sign on the right.

## 4.3 The homogeneous Casoratian and the factor 6

For the two homogeneous solutions `b,c`,

```text
Omega_(n+1)
:=(n+1)^3[b_n c_(n+1)-c_n b_(n+1)]                      (4.8)
```

is independent of `n`. At `n=0`,

```text
Omega_1=b_0c_1-c_0b_1=1.                                (4.9)
```

Thus

```text
(n+1)^3[b_n c_(n+1)-c_n b_(n+1)]=1.                    (4.10)
```

Using `m_n=b_nzeta(3)-6c_n`,

```text
(n+1)^3[m_n b_(n+1)-b_n m_(n+1)]=6.                    (4.11)
```

This fixes both the sign and the factor `6`.

Put

```text
r_n=q_n/b_n,
S_N=sum_(k=0)^N(2k+1)b_k.                               (4.12)
```

Rewrite the right side of (4.7):

```text
(N+1)^3[m_Nq_(N+1)-q_Nm_(N+1)]
=
6r_N+(N+1)^3m_Nb_(N+1)(r_(N+1)-r_N).                   (4.13)
```

Using (4.6) at index `N+1`, this becomes the exact finite identity

```text
boxed:
8 sum_(n=0)^N(2n+1)m_n
=6r_N+8(m_N/b_N)S_N.                                    (4.14)
```

The second term is positive.

# 5. The boundary error vanishes rigorously

From the binomial formula for Apéry numbers,

```text
b_n=sum_(k=0)^n binom(n,k)^2 binom(n+k,k)^2,             (5.1)
```

`b_n` is strictly increasing. Hence

```text
S_N
<=b_N sum_(k=0)^N(2k+1)
=(N+1)^2b_N.                                             (5.2)
```

By (2.3) and (1.8),

```text
0<m_N=B_N/2<=zeta(3)16^(-N).                             (5.3)
```

Therefore the error term in (4.14) satisfies

```text
0<=8(m_N/b_N)S_N
<=8zeta(3)(N+1)^2 16^(-N)
->0.                                                      (5.4)
```

Together with `r_N->zeta(2)`, equation (4.14) gives

```text
boxed:
8 sum_(n=0)^infinity(2n+1)m_n=6zeta(2).                 (5.5)
```

Absolute convergence is already guaranteed by (5.3).

# 6. Evaluation of the triple integral

Combining (2.5) and (5.5),

```text
J
=2 sum_(n>=0)(2n+1)m_n
=(1/4) [8 sum_(n>=0)(2n+1)m_n]
=(6/4)zeta(2)
=(3/2)zeta(2).                                           (6.1)
```

Finally,

```text
int_[0,1]^2 1/(1-xy) dx dy
=sum_(r>=0) int_0^1x^r dx int_0^1y^r dy
=sum_(r>=0)1/(r+1)^2
=zeta(2).                                                 (6.2)
```

Thus

```text
boxed:
J=(3/2) int_[0,1]^2 1/(1-xy) dx dy
 =(3/2)zeta(2)
 =pi^2/4.                                                 (6.3)
```
