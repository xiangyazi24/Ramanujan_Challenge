\tag{4.1}

The isomorphism sends

\[
Z_\nu\longmapsto X^{-1}F_\nu.
\tag{4.2}
\]

### Proof

\[

solves uniquely for `Z_nu` as `(4.2)`. Substitution gives inverse homomorphisms. \(\square\)

\[
\mathbb F_q[X,X^{-1},V_6,V_\sigma]

\boxed{

For a cell with actual fibre size `K`, an anchor at one actual prime has

# 9. Pure existence of CQRD is exactly the counting statement

The pre-support clause is essential, but it is not an intrinsic property of a polynomial.

## Lemma 9.1 — minimal vanishing degree

Let

\[
P\subset\mathbb F_q
\]

be a finite set of distinct elements. Then

\[
\min\{\deg\Phi:
0\ne\Phi\in\mathbb F_q[X],\ P\subset Z(\Phi)\}
=|P|.
\tag{9.1}
\]

### Proof

Every nonzero polynomial has at most its degree many distinct roots, giving the lower bound. The monic polynomial

\[
\prod_{p\in P}(X-p)
\tag{9.2}
\]

has degree `|P|` and vanishes exactly on `P`. For `P` empty, the constant polynomial `1` has degree zero. \(\square\)

Apply this to the actual partner set \(\mathcal P(\mathfrak a)\). For every `d`,

\[
\boxed{
\exists\Phi_{\mathfrak a}\ne0,
\quad
\deg\Phi_{\mathfrak a}\le d,
\quad
\mathcal P(\mathfrak a)\subset Z(\Phi_{\mathfrak a})
\iff
|\mathcal P(\mathfrak a)|\le d.
}
\tag{9.3}
\]

Thus, with

\[
d=H Y^{-\varepsilon},
\]

unrestricted existential CQRD is identical to the pointwise extension theorem

\[
|\mathcal P(\mathfrak a)|\ll_JH Y^{-\varepsilon}.
\tag{9.4}
\]

This has two consequences.

1. One cannot refute unrestricted actual CQRD without proving that some actual anchor has more than `d` partners. No such actual rich witness is banked.

2. One cannot regard the bare existence of `Phi` as an independent mechanism. The mathematical content must be in a specified support-free construction. In the natural growing recurrence-module class, Theorem 4.2 proves that construction impossible.

This is why the honest verdict is neither “actual CQRD is false” nor “CQRD remains an untouched module problem.” The named module problem is closed; the unrestricted existence statement is the original counting problem.

# 10. The first exact failed implication

The failure can be written without module language.

Let `F(p)` be any integer recurrence row which vanishes modulo an actual lower prime:

\tag{10.1}

\qquad Z_p\in\mathbb Z.

\[
\overline F(p)=p\overline Z_p\pmod q.
\tag{10.3}

Since `p` is a q-unit, `(10.3)` is true for the uniquely determined value

\[
\overline Z_p=p^{-1}\overline F(p)

for **every** candidate `p`, actual or not. Therefore

\[
\boxed{
q\mid b_t,\quad p\mid F(p)
\not\Longrightarrow
\Psi(p)=0\pmod q
}
\tag{10.4 bad}

for any nonzero q-polynomial `Psi` generated by algebraic elimination of the quotient `Z_p`.

The exact failed step is:

```text

       ↓ reduce modulo q
“a q-algebraic restriction on p”
```

After reduction modulo `q`, the quotient exists for every nonzero `p`, so the implication loses all content.

The upper mark is not absent. It is already used to make the fixed rows q-divisible and to form the divided pair `(C_6,C_sigma)`. What fails is transporting the **integrality** of division by `p` into characteristic `q`.
