## 4. Competing scale normalizations

Let \(L=\log T\).  Always report

\[
F_0=T^{12/5}L^{-16/5}.
\]

For `R2`, also report the following deliberately competing model scales:

\[
S_{m integer}=T^{8/3},\qquad
S_q=T^{8/3}L^{-1},\qquad
S_{p^2q}=T^{8/3}L^{-3}.
	ag{4.1}
\]

Their interpretation is:

* \(S_{m integer}\): integer \(p,q\) windows and only the pointwise \(Z(p)\ll p^{2/3}\) density scale;
* \(S_q\): only the upper-row \(q\)-primality density has appeared;
* \(S_{p^2q}\): one \(q\)-prime factor and two lower-prime factors in the squared baseline, giving the candidate \((\log T)^{-2}\) saving relative to \(S_q\).

These are **comparison models, not proved asymptotics**.  The exact data-driven discriminants are

```text
R2/S_integer
R2/S_q
R2/S_p2q
R2/F0
VR/F0
Vaff/F0
R2_cross/R2
R2/R2_diag
O_p,1, O_p,2, O_q,1, O_q,2
```

A stable `R2/S_p2q` is evidence for the proposed log bookkeeping only after both of the following hold:

1. `O_p,2` and the relevant `O_q` ratio are no longer governed by tiny denominators;
2. `R2_cross/R2` is appreciable, so the square really contains many distinct-prime cross terms.

Otherwise a small normalized `R2` can be entirely due to finite zero-set sparsity.

For cubic data, report

```text
sum_T3 / sum_(p) Z(p)^3/p
sum_gamma / sum_(p) Z(p)^3/p^3
sum_abs_gamma / sum_(p) Z(p)^3/p^3
windowed_tau3 / windowed_random3
number of p with Z>=3, Z>=5, Z>=10
```

Do not fit a power law to a ratio whose denominator is supported on only a few primes.

## 5. Complexity

Let \(\mathcal P_T=\{p:T/7<p\le T/3\}\).

1. **Prime sieve:** \(O(T\log\log T)\) time and \(O(T)\) bits/bytes.
2. **One-digit Apéry tables:**
   
   \[
   O\!\left(\sum_{p\in\mathcal P_T}pight)
   =O(T^2/\log T)
   \]
   modular operations, using the exact three-term recurrence.
3. **Cubic counts and sparse inverse events:**
   
   \[
   O\!\left(\sum_{p\in\mathcal P_T}Z(p)^2ight).
   \]
4. **Exact \(R\)-row scan:**
   
   \[
   O\!\left(\sum_{q\in\mathcal P_T}qight)
   =O(T^2/\log T),
   \]
   after prefixing \(ho_{2,p}\), \(	au_p^{(3)}\), their squares, and the prime indicator over the integer \(p\)-axis.
5. **Sampled absolute Fourier diagnostic:** \(O(pZ(p))\) per sampled prime with the direct sparse DFT used below.  It is intentionally not run for every prime.
6. **Memory:** compressed zero bitsets cost
   
   \[
   O\!\left(\sum_{p\in\mathcal P_T}p/8ight),
   \]
   plus sparse event storage \(O(\sum Z(p)^2)\) in the worst case.  Run one \(T\)-shell per process when memory is the limiting resource.

The \(O(T^2/\log T)\) row pass, not the sparse event enumeration, is the eventual bottleneck.  The implementation supports OpenMP for the independent prime-table and row loops only if the corresponding pragmas are enabled; the reference below is kept deterministic and single-writer.

struct Kahan {
    long double sum = 0.0L;
    long double corr = 0.0L;
    void add(long double x) {
        const long double y = x - corr;
        const long double t = sum + y;
        corr = (t - sum) - y;
        sum = t;

static std::vector<uint8_t> prime_sieve(int n) {
    std::vector<uint8_t> isp(n + 1, true);
    if (n >= 0) isp[0] = false;
    if (n >= 1) isp[1] = false;
    for (int p = 2; int64_t(p) * p <= n; ++p) {
        if (!isp[p]) continue;
        for (int64_t m = int64_t(p) * p; m <= n; m += p) isp[size_t(m)] = false;
    }
    return isp;

    uint64_t r = 1;
    while (e) {
        if (e & 1) r = mul_mod(r, a, p);
        a = mul_mod(a, a, p);
        e >>= 1;

    return r;
}

    if (k > n) return 0;

    for (unsigned i = 1; i <= k; ++i) {
        r = r * (n - k + i) / i;

        const u128 c1 = choose_u128(unsigned(n), unsigned(k));
        const u128 c2 = choose_u128(unsigned(n + k), unsigned(k));
        const uint64_t a = uint64_t(c1 % p);
        const uint64_t b = uint64_t(c2 % p);
        const uint64_t term = mul_mod(mul_mod(a, a, p), mul_mod(b, b, p), p);
        total += term;
        total %= p;
    }
    return int(total);
}

struct ZeroSet {
    int p = 0;
    std::vector<int> elems;
    std::vector<uint64_t> bits;
    bool contains(int x) const {
        if (x < 0 || x >= p) return false;
        return (bits[size_t(x) >> 6] >> (x & 63)) & 1ULL;
    }
};

static ZeroSet build_zero_set(int p, int validate_p_max) {
    if (p <= 13) throw std::runtime_error("scanner expects p>13");
    std::vector<uint32_t> b(size_t(p), 0);
    std::vector<uint32_t> inv(size_t(p), 0);
    b[0] = 1 % p;
    b[1] = 5 % p;
    inv[1] = 1;
    for (int i = 2; i < p; ++i) {
        inv[i] = uint32_t(p - (uint64_t(p / i) * inv[p % i]) % p);
    }
    for (int n = 1; n <= p - 2; ++n) {
        const uint64_t nn = uint64_t(n) % p;
        const uint64_t n2 = mul_mod(nn, nn, p);
        const uint64_t n3 = mul_mod(n2, nn, p);
        uint64_t coeff = 0;
        coeff = (coeff + 34 * n3) % p;
        coeff = (coeff + 51 * n2) % p;
        coeff = (coeff + 27 * nn + 5) % p;
        const uint64_t lhs1 = mul_mod(coeff, b[n], p);
        const uint64_t lhs2 = mul_mod(n3, b[n - 1], p);
        const uint64_t rhs = (lhs1 + p - lhs2) % p;
        const uint64_t iv = inv[n + 1];
        const uint64_t iv3 = mul_mod(mul_mod(iv, iv, p), iv, p);
        b[n + 1] = uint32_t(mul_mod(rhs, iv3, p));
    }

    if (p <= validate_p_max) {
        for (int n = 0; n <= std::min(12, p - 1); ++n) {
            if (int(b[n]) != apery_literal_mod_small(n, p)) {
                throw std::runtime_error("Apéry recurrence/direct mismatch p=" + std::to_string(p));
            }
        }
    }

    ZeroSet z;
    z.p = p;
    z.bits.assign((size_t(p) + 63) / 64, 0);
    for (int n = 0; n < p; ++n) {
        if (b[n] == 0) {
            z.elems.push_back(n);
            z.bits[size_t(n) >> 6] |= 1ULL << (n & 63);
        }
    }
    for (int n = 0; n < p; ++n) {
        if (z.contains(n) != z.contains(p - 1 - n)) {
            throw std::runtime_error("reflection failure p=" + std::to_string(p));
        }
    }
    return z;
}

struct CubicStats {
    uint64_t T3 = 0;
    uint64_t T3_distinct = 0;
    i128 gamma_num = 0;
    long double rho2 = 0;
    long double tau3 = 0;
    long double random3 = 0;
    long double gamma = 0;
};

static CubicStats cubic_stats(const ZeroSet& z, int validate_p_max) {
    const int p = z.p;
    const int inv7 = int(pow_mod(7, uint64_t(p - 2), p));
    CubicStats s;
    for (int a : z.elems) {
        for (int r : z.elems) {
            const int lin = mod_norm(int64_t(6) * a + int64_t(13) * r + 6, p);
            const int c = int(mul_mod(uint64_t(lin), uint64_t(inv7), uint64_t(p)));
            if (z.contains(c)) {
                ++s.T3;
                if (a != r && a != c && r != c) ++s.T3_distinct;
            }
        }
    }
    const uint64_t Z = z.elems.size();
    const long double pp = p;
    s.rho2 = (long double(Z) * Z) / (pp * pp);
    s.tau3 = long double(s.T3) / (pp * pp);
    s.random3 = (long double(Z) * Z * Z) / (pp * pp * pp);
    s.gamma_num = i128(p) * i128(s.T3) - i128(Z) * i128(Z) * i128(Z);
    s.gamma = s.tau3 - s.random3;

    if (p <= validate_p_max) {
        uint64_t sm = 0, sp = 0, so = 0;
        for (int d = 0; d < p; ++d) {
            for (int t = 0; t < p; ++t) {
                const int a = mod_norm(int64_t(d) - t - 1, p);
                const int r = mod_norm(int64_t(6) * d + t, p);
                const int c = mod_norm(int64_t(12) * d + t, p);
                const bool xm = z.contains(a) && z.contains(r);
                const bool xp = z.contains(r) && z.contains(c);
                sm += xm;
                sp += xp;
                so += xm && xp;
            }
        }
        const uint64_t Z2 = uint64_t(Z) * Z;
        if (sm != Z2 || sp != Z2 || so != s.T3) {
            throw std::runtime_error("complete-plane identity failure p=" + std::to_string(p));
        }
    }
    return s;
}

struct Window {
    int L = 1;
    int Um = 0;
    int Up = 0;
    int Uunion = 0;
    int Ucap = 0;
    bool union_nonempty() const { return Uunion >= L; }
};

static Window window_for(int T, int J, int q, int t) {
    const int A = T / 7 + 1;
    const int B = T / 3;
    const int h = T / J;
    Window w;
    w.L = std::max(A, (6 * q + t) / 7 + 1);
    const int cap = std::min(B, q - h - 1);
    w.Um = std::min(cap, q - t - 1);
    w.Up = std::min(cap, (12 * q + t) / 13);
    w.Uunion = std::max(w.Um, w.Up);
    w.Ucap = std::min(w.Um, w.Up);
    if ((q > 14 * t && w.Um < w.Up) || (q < 14 * t && w.Up < w.Um)) {
        throw std::runtime_error("window nesting/switch failure");
    }
    return w;
}

static std::pair<int,int> t_range(int T, int q) {
    const int lo = std::max(0, T - 6 * q + 1);       // T < 6q+t
    const int hi = std::min(q - 1, 2 * T - 6 * q);  // 6q+t <= 2T
    return {lo, hi};
}

struct Candidate {
    int q = 0, t = 0, p = 0;
    uint8_t sign = 0; // 1 minus, 2 plus
    bool operator<(const Candidate& o) const {
        return std::tie(q,t,p,sign) < std::tie(o.q,o.t,o.p,o.sign);
    }
    bool same(const Candidate& o) const {
        return q == o.q && t == o.t && p == o.p && sign == o.sign;
    }
};

static bool common_candidate_ok(int T, int J, int p, int q, int d, int t) {
    if (!in_shell(p, T) || !in_shell(q, T) || q <= 13) return false;
    if (d <= 0 || int64_t(d) * J <= T) return false;
    if (t < 0 || t >= q) return false;
    const int64_t n = int64_t(6) * q + t;
    return T < n && n <= int64_t(2) * T;
}

static std::vector<Candidate> inverse_candidates(
    int T, int J, const ZeroSet& z)
{
    const int p = z.p;
    std::vector<Candidate> out;
    out.reserve(2 * z.elems.size() * z.elems.size());

    // Minus: ordered pair (a,r).
    for (int a : z.elems) {
        for (int r : z.elems) {
            const int s = a + r + 1;
            if (s % 7) continue;
            const int d = s / 7;
            const int t = d - a - 1;
            const int q = p + d;
            if (!common_candidate_ok(T,J,p,q,d,t)) continue;
            const Window w = window_for(T,J,q,t);
            if (p >= w.L && p <= w.Um) out.push_back({q,t,p,1});
        }
    }

    // Plus: ordered pair (z,w).
    for (int zz : z.elems) {
        for (int ww : z.elems) {
            const int s = zz + ww + 1;
            if (s % 6) continue;
            const int d = s / 6;
            const int t = p - 1 - zz - 6 * d;
            const int q = p + d;
            if (!common_candidate_ok(T,J,p,q,d,t)) continue;
            const Window w = window_for(T,J,q,t);
            if (p >= w.L && p <= w.Up) out.push_back({q,t,p,2});
        }
    }
    std::sort(out.begin(), out.end());
    for (size_t i = 1; i < out.size(); ++i) {
        if (out[i].same(out[i-1])) {
            throw std::runtime_error("inverse fibre multiplicity failure");
        }
    }
    return out;
}

struct Incidence {
    int q = 0, t = 0, p = 0;
    uint8_t mask = 0;
    bool operator<(const Incidence& o) const {
        return std::tie(q,t,p) < std::tie(o.q,o.t,o.p);
    }
};

struct StateLoad {
    int q = 0, t = 0;
    int km = 0, kp = 0, ku = 0, kraw = 0;
};

static long double range_ld(const std::vector<long double>& pref, int l, int u) {
    if (u < l) return 0.0L;
    l = std::max(l, 1);
    u = std::min(u, int(pref.size()) - 1);
    if (u < l) return 0.0L;
    return pref[u] - pref[l - 1];
}

static uint64_t range_u64(const std::vector<uint64_t>& pref, int l, int u) {
    if (u < l) return 0;
    l = std::max(l, 1);
    u = std::min(u, int(pref.size()) - 1);
    if (u < l) return 0;
    return pref[u] - pref[l - 1];
}

struct SpectralStats {
    long double signed_real = 0;
    long double signed_imag = 0;
    long double abs_mass = 0;
    long double sq_mass = 0;
};

static SpectralStats spectral_stats(const ZeroSet& z) {
    const int p = z.p;
    const int inv7 = int(pow_mod(7, uint64_t(p - 2), p));
    const int alpha = int(mul_mod(6, inv7, p));
    const int beta  = int(mul_mod(13 % p, inv7, p));
    const int gamma = alpha;
    const long double pi = acosl(-1.0L);
    const long double twopi = 2.0L * pi;
    std::vector<std::complex<long double>> hat(size_t(p));
    for (int h = 0; h < p; ++h) {
        std::complex<long double> s(0,0);
        for (int x : z.elems) {
            const long double ang = -twopi * long double(h) * x / p;
            s += std::complex<long double>(cosl(ang), sinl(ang));
        }
        hat[h] = s / long double(p);
    }
    SpectralStats out;
    std::complex<long double> signed_sum(0,0);
    for (int h = 1; h < p; ++h) {
        const int ia = mod_norm(-int64_t(alpha) * h, p);
        const int ib = mod_norm(-int64_t(beta) * h, p);
        const long double ang = twopi * long double(gamma) * h / p;
        const std::complex<long double> phase(cosl(ang), sinl(ang));
        const auto term = hat[ia] * hat[ib] * hat[h] * phase;
        signed_sum += term;
        out.abs_mass += std::abs(term);
        out.sq_mass += std::norm(term);
    }
    out.signed_real = signed_sum.real();
    out.signed_imag = signed_sum.imag();
    return out;
}

int main(int argc, char** argv) try {
    const Args args = parse_args(argc, argv);
    const int T = args.T, J = args.J;
    const int B = T / 3;
    const long double logT = logl(long double(T));
    fs::create_directories(args.out);

    const auto isprime = prime_sieve(B);
    std::vector<int> shell;
    for (int p = 17; p <= B; ++p) if (isprime[p] && in_shell(p,T)) shell.push_back(p);
    if (shell.empty()) throw std::runtime_error("empty prime shell");

    std::vector<ZeroSet> zeros;
    std::vector<CubicStats> cubics;
    zeros.reserve(shell.size());
    cubics.reserve(shell.size());
    std::vector<int> pindex(B + 1, -1);

    for (int p : shell) {
        pindex[p] = int(zeros.size());
        zeros.push_back(build_zero_set(p, args.validate_p_max));
        cubics.push_back(cubic_stats(zeros.back(), args.validate_p_max));
    }

    // Exact sparse inverse candidates, including composite reconstructed q.
    std::vector<Candidate> candidates;
    for (const auto& z : zeros) {
        auto v = inverse_candidates(T,J,z);
        candidates.insert(candidates.end(), v.begin(), v.end());
    }
    std::sort(candidates.begin(), candidates.end());
    for (size_t i = 1; i < candidates.size(); ++i) {
        if (candidates[i].same(candidates[i-1])) {
            throw std::runtime_error("duplicate candidate after merge");
        }
    }

    std::vector<uint64_t> q_all_by_p(shell.size(),0), q_prime_by_p(shell.size(),0);
    std::vector<Incidence> incidences;
    uint64_t inverse_all_union = 0, inverse_prime_union = 0;
    for (size_t i = 0; i < candidates.size();) {
        size_t j = i + 1;
        uint8_t mask = candidates[i].sign;
        while (j < candidates.size() &&
               candidates[j].q == candidates[i].q &&
               candidates[j].t == candidates[i].t &&
               candidates[j].p == candidates[i].p) {
            mask |= candidates[j].sign;
            ++j;
        }
        const int p = candidates[i].p;
        const int pi = pindex[p];
        ++inverse_all_union;
        ++q_all_by_p[pi];
        if (candidates[i].q <= B && isprime[candidates[i].q]) {
            ++inverse_prime_union;
            ++q_prime_by_p[pi];
            incidences.push_back({candidates[i].q,candidates[i].t,p,mask});
        }
        i = j;
    }
    std::sort(incidences.begin(), incidences.end());

    u128 qocc_all_fac = 0, qocc_prime_fac = 0;
    for (size_t i = 0; i < shell.size(); ++i) {
        qocc_all_fac += u128(q_all_by_p[i]) * (q_all_by_p[i] ? q_all_by_p[i]-1 : 0);
        qocc_prime_fac += u128(q_prime_by_p[i]) * (q_prime_by_p[i] ? q_prime_by_p[i]-1 : 0);
    }

    // State loads.
    std::vector<StateLoad> states;
    for (size_t i = 0; i < incidences.size();) {
        size_t j = i;
        StateLoad s;
        s.q = incidences[i].q;
        s.t = incidences[i].t;
        while (j < incidences.size() && incidences[j].q == s.q && incidences[j].t == s.t) {
            ++s.ku;
            if (incidences[j].mask & 1) ++s.km;
            if (incidences[j].mask & 2) ++s.kp;
            s.kraw += std::popcount(unsigned(incidences[j].mask));
            ++j;
        }
        states.push_back(s);
        i = j;
    }

    std::vector<std::vector<StateLoad>> states_by_q(B + 1);
    uint64_t Mpre=0, Mmark=0, Mpre_raw=0, Mmark_raw=0;
    u128 Fpre=0, Fmark=0;
    for (const auto& s : states) {
        states_by_q[s.q].push_back(s);
        Mpre += s.ku;
        Mpre_raw += s.kraw;
        Fpre += u128(s.ku) * (s.ku ? s.ku-1 : 0);
        const int qi = pindex[s.q];
        if (qi < 0) throw std::runtime_error("prime q missing zero table");
        if (zeros[qi].contains(s.t)) {
            Mmark += s.ku;
            Mmark_raw += s.kraw;
            Fmark += u128(s.ku) * (s.ku ? s.ku-1 : 0);
        }
    }

    // Prime-axis values and prefixes.
    std::vector<long double> vrho(B+1,0), vtau(B+1,0), vrandom3(B+1,0);
    std::vector<long double> vrho2(B+1,0), voverlap2(B+1,0);
    std::vector<uint64_t> vpc(B+1,0);
    uint64_t sumZ = 0;
    u128 sumT3 = 0;
    long double random_T3_count = 0, tau_density_sum = 0, random_density_sum = 0;
    Kahan gamma_sum, gamma_abs_sum, gamma_sq_sum;
    int zge3=0,zge5=0,zge10=0;
    for (size_t i = 0; i < shell.size(); ++i) {
        const int p = shell[i];
        const uint64_t Z = zeros[i].elems.size();
        const auto& c = cubics[i];
        sumZ += Z;
        sumT3 += c.T3;
        random_T3_count += (long double(Z)*Z*Z)/p;
        tau_density_sum += c.tau3;
        random_density_sum += c.random3;
        gamma_sum.add(c.gamma);
        gamma_abs_sum.add(fabsl(c.gamma));
        gamma_sq_sum.add(c.gamma*c.gamma);
        zge3 += Z>=3; zge5 += Z>=5; zge10 += Z>=10;
        vrho[p] = c.rho2;
        vtau[p] = c.tau3;
        vrandom3[p] = c.random3;
        vrho2[p] = c.rho2*c.rho2;
        const long double overlap = 2*c.rho2-c.tau3;
        if (overlap < -1e-24L) throw std::runtime_error("negative overlap baseline");
        voverlap2[p] = overlap*overlap;
        vpc[p] = 1;
    }
    auto prefix_ld = [&](std::vector<long double>& v) {
        for (int i=1;i<=B;++i) v[i]+=v[i-1];
    };
    auto prefix_u64 = [&](std::vector<uint64_t>& v) {
        for (int i=1;i<=B;++i) v[i]+=v[i-1];
    };
    prefix_ld(vrho); prefix_ld(vtau); prefix_ld(vrandom3);
    prefix_ld(vrho2); prefix_ld(voverlap2); prefix_u64(vpc);

    // Row scan.
    Kahan gR1,gR2,gR2diag,gVR,gVA,gCov,gVC,gTauWin,gRandomTauWin;
    u128 pN1=0,pP1=0,pNfac=0,pPfac=0;
    long double totalA_from_rows = 0;

    for (int q : shell) {
        const auto [tlo,thi] = t_range(T,q);
        if (thi < tlo) continue;
        const auto& lv = states_by_q[q];
        size_t li=0;
        while (li<lv.size() && lv[li].t<tlo) {
            throw std::runtime_error("state below legal t-range");
        }
        Kahan sR,sR2,sDiag,sA,sA2,sAR,sC,sC2;
        for (int t=tlo;t<=thi;++t) {
            int Aval=0;
            if (li<lv.size() && lv[li].t==t) { Aval=lv[li].ku; ++li; }
            const Window w=window_for(T,J,q,t);
            long double R=0,diag=0;
            if (w.union_nonempty()) {
                const long double rho_union=range_ld(vrho,w.L,w.Uunion);
                const long double rho_cap=range_ld(vrho,w.L,w.Ucap);
                const long double tau_cap=range_ld(vtau,w.L,w.Ucap);
                R=rho_union+rho_cap-tau_cap;
                diag=range_ld(voverlap2,w.L,w.Ucap)
                    +range_ld(vrho2,std::max(w.L,w.Ucap+1),w.Uunion);
                const int N=w.Uunion-w.L+1;
                const uint64_t nu=range_u64(vpc,w.L,w.Uunion);
                pN1 += N; pP1 += nu;
                pNfac += u128(N)*(N-1);
                pPfac += u128(nu)*(nu?nu-1:0);
                gTauWin.add(tau_cap);
                gRandomTauWin.add(range_ld(vrandom3,w.L,w.Ucap));
            } else if (Aval!=0) {
                throw std::runtime_error("event in empty window");
            }
            const long double A=Aval;
            const long double C=A-R;
            sR.add(R); sR2.add(R*R); sDiag.add(diag);
            sA.add(A); sA2.add(A*A); sAR.add(A*R);
            sC.add(C); sC2.add(C*C);
        }
        if (li!=lv.size()) throw std::runtime_error("state above legal t-range");
        const long double qq=q;
        const long double VR=sR2.sum-sR.sum*sR.sum/qq;
        const long double VA=sA2.sum-sA.sum*sA.sum/qq;
        const long double Cov=sAR.sum-sA.sum*sR.sum/qq;
        const long double VC=sC2.sum-sC.sum*sC.sum/qq;
        const long double rhs=VA+VR-2*Cov;
        if (fabsl(VC-rhs)>1e-12L*(1+fabsl(VC)+fabsl(rhs))) {
            throw std::runtime_error("variance decomposition failure q="+std::to_string(q));
        }
        if (VR<-1e-12L || VA<-1e-12L || VC<-1e-12L) {
            throw std::runtime_error("negative variance beyond rounding tolerance");
        }
        gR1.add(sR.sum); gR2.add(sR2.sum); gR2diag.add(sDiag.sum);
        gVR.add(VR); gVA.add(VA); gCov.add(Cov); gVC.add(VC);
        totalA_from_rows += sA.sum;
    }
    if (llround(totalA_from_rows)!=int64_t(Mpre)) {
        throw std::runtime_error("row mass != inverse-event mass");
    }
    const long double R2cross=gR2.sum-gR2diag.sum;

    // Per-prime table.
    {
        std::ofstream f(args.out / ("prime_T"+std::to_string(T)+".csv"));
        f << "p,Z,T3,T3_distinct,gamma_num,rho2,tau3,random3,tau_over_random,gamma\n";
        f << std::setprecision(21);
        for (size_t i=0;i<shell.size();++i) {
            const auto& c=cubics[i];
            const uint64_t Z=zeros[i].elems.size();
            const long double ratio = Z ? (long double(shell[i])*c.T3)/(long double(Z)*Z*Z) : 0;
            f << shell[i] << ',' << Z << ',' << c.T3 << ',' << c.T3_distinct << ','
              << i128_string(c.gamma_num) << ',' << c.rho2 << ',' << c.tau3 << ','
              << c.random3 << ',' << ratio << ',' << c.gamma << '\n';
        }
    }

    // Sample largest |Gamma_p| for the absolute spectral diagnostic.
    {
        std::vector<size_t> order(shell.size());
        std::iota(order.begin(),order.end(),0);
        std::sort(order.begin(),order.end(),[&](size_t a,size_t b){
            return fabsl(cubics[a].gamma)>fabsl(cubics[b].gamma);
        });
        std::ofstream f(args.out / ("spectral_T"+std::to_string(T)+".csv"));
        f << "p,Z,gamma_exact,signed_real,signed_imag,absolute_mass,squared_mass\n";
        f << std::setprecision(21);
        int done=0;
        for (size_t i:order) {
            if (done>=args.spectral_sample) break;
            if (shell[i]>args.spectral_p_max) continue;
            const auto s=spectral_stats(zeros[i]);
            if (fabsl(s.signed_real-cubics[i].gamma)>1e-9L*(1+fabsl(cubics[i].gamma))
                || fabsl(s.signed_imag)>1e-9L) {
                throw std::runtime_error("Fourier/cubic identity numerical failure");
            }
            f << shell[i] << ',' << zeros[i].elems.size() << ',' << cubics[i].gamma << ','
              << s.signed_real << ',' << s.signed_imag << ',' << s.abs_mass << ','
              << s.sq_mass << '\n';
            ++done;
        }
    }

    const long double F0=powl(long double(T),12.0L/5.0L)*powl(logT,-16.0L/5.0L);

## 7. Mandatory validation identities

A run is invalid unless all applicable identities below pass.

1. **Recurrence versus literal Apéry sum** for small \(n,p\).
2. **Reflection**
   
   \[
   z_p(u)=z_p(p-1-u).
   \]
3. **Complete affine pair planes**
   
   \[
   \sum X^-=\sum X^+=Z(p)^2.
   \]
4. **Cubic direct/Fourier identity**
   
   \[
   \sum X^-X^+=T_3(p),\qquad
   \Gamma_p=(pT_3-Z^3)/p^3.
   \]
5. **Window nesting** with the exact switch \(q>14t\) versus \(q<14t\); equality is impossible for prime \(q>13\).
6. **Inverse reconstruction**
   
   \[
   d=(a+r+1)/7,\quad t=d-a-1
   \]
   and
   
   \[
   d=(z+w+1)/6,\quad t=p-1-z-6d.
   \]
7. **Union accounting**
   
   \[
   Y=\chi_-X^-+\chi_+X^+-\chi_-\chi_+X^-X^+.
   \]
8. **Factorial diagonal**
   
   \[
   \sum A^2=F_{m pre}+M_{m pre}.
   \]
9. **Variance decomposition** (0.1).
10. **Empty-event regression:** when \(M_{m pre}=0\), require \(V_{m up}=\operatorname{Cov}(A,R)=0\) and \(V_{m aff}=V_R\).
11. **Prime occupancy:** interval prime counts obtained from the prefix table must equal direct enumeration on all validation rows.
12. **Mass agreement:** sparse inverse state mass must equal the mass recovered during the full \(q,t\) row pass.

For a one-time small-\(T\) regression, add a direct \((p,q,t)\) enumerator and require exact equality of the complete event tuples.  That direct enumerator is deliberately not used in production because it reintroduces a cubic ambient loop.

## 8. How to interpret the first nonzero shells

The first shell with `Mpre>0` should not immediately be fitted.  Inspect, in order:

1. whether the event survives the reconstructed-\(q\) prime filter;
2. whether it is a singleton or creates `Fpre>0`;
3. whether its lower prime lies in the union-only or overlap window;
4. whether its \(p\) has anomalous `tau_over_random` or a large \(|\Gamma_p|\);
5. its contribution to \(V_{m up}\), \(V_R\), and `CovAR` separately;
6. whether `R2_cross/R2` is still essentially zero.

A small `Vaff/F0` caused by \(A=0\), diagonal-dominated `R2`, or one exceptional prime is finite sparsity, not evidence of a logarithmic theorem.  A more persuasive finite pattern would simultaneously show

```text
O_p,2 and O_q,2 stable away from zero;
R2_cross/R2 bounded away from zero;
windowed_tau/random stable on many p;
Vaff/F0 decreasing without Vaff=VR being forced by A=0;
no single p or (q,t) dominating the totals.
```

Even that would remain experimental evidence only.
