If the literal pre-upper load is identically zero, then

```text
Mpre = 0
A_q(t) = 0 for every q,t

```

Writing the affine defect as

```text
C_q(t) = A_q(t) - R_q(t),
```

one then has C = -R. Therefore

```text
Vaff = sum_(q,t) |C_q(t) - mean_q(C)|^2
     = sum_(q,t) |R_q(t) - mean_q(R)|^2
     = VR.
```

Thus Vaff > 0 in the current scans records variation of the deterministic comparison profile R. It is not evidence, positive or negative, for cross-characteristic mixing.

The next experiment must keep five quadratic quantities separate:

```text
R2      = sum_(q,t) R_q(t)^2
VR      = sum_(q,t) (R_q(t)-mean_q(R))^2
Vup     = sum_(q,t) (A_q(t)-mean_q(A))^2
CovAR   = sum_(q,t) (A_q(t)-mean_q(A))(R_q(t)-mean_q(R))
Vaff    = sum_(q,t) ((A_q(t)-R_q(t))-mean_q(A-R))^2.
```

The mandatory validation identity is

```text
Vaff = Vup + VR - 2 CovAR.                              (0.1)
```

There are also two different objects called tau on this proof line, and the scanner must not conflate them.

```text
tau_win(p;q,t) = chi_minus + chi_plus - chi_minus*chi_plus
```

is the Boolean union coefficient of the two nested prime windows. By Q7396 it is simply the indicator of the larger window.

The new local arithmetic quantity is instead the complete-plane cubic overlap density

```text
tau3(p) = p^(-2) sum_(d,t mod p) X_minus_p(d,t) X_plus_p(d,t).
```

It must be compared with the fixed-density model Z(p)^3/p^3. The union comparison profile is consequently

```text
rho2(p) = Z(p)^2/p^2

r(p,q,t) = rho2(p)*(chi_minus+chi_plus)
           - tau3(p)*chi_minus*chi_plus

R_q(t) = sum_p r(p,q,t).                               (0.2)
```

Using 2*rho2 on the overlap, or using rho2 squared, is wrong. The overlap contains three lower zero coordinates and is governed by tau3.

4. the baseline and centered WAUD moments R2, VR, Vup, CovAR, and Vaff.

## 1. Exact local pair and cubic objects

For a prime p > 13, write

```text
z_p(u) = 1 if 0 <= u < p and p divides b_u, else 0
Z(p)   = sum_(u mod p) z_p(u).
```

Use the common reflected upper coordinate t and d = q-p. The two complete-plane lower-pair indicators are

```text
X_minus_p(d,t) = z_p(d-t-1) z_p(6d+t),                 (1.1-)
X_plus_p(d,t)  = z_p(6d+t) z_p(12d+t),                 (1.1+)
```

where all arguments are reduced modulo p. The plus formula uses Apéry reflection to replace z_p(-1-6d-t) by z_p(6d+t).

The two affine maps have determinants 7 and 6, respectively. Hence, exactly,

```text
sum_(d,t mod p) X_minus_p(d,t) = Z(p)^2,
sum_(d,t mod p) X_plus_p(d,t)  = Z(p)^2.               (1.2)
```

### 1.1 Exact cubic overlap

The overlap is

```text
X_minus_p(d,t) X_plus_p(d,t)
 = z_p(d-t-1) z_p(6d+t) z_p(12d+t).
```

Put

```text
a = d-t-1,
r = 6d+t.
```

The determinant is 7, so this is a bijection of the complete residue plane. Its inverse gives

```text
d       = inv7*(a+r+1),
12d+t   = inv7*(6a+13r+6) mod p.
```

Therefore the exact cubic count is

```text
T3(p) = sum_(a,r in Z_p)
        z_p(inv7*(6a+13r+6)),                           (1.3)

tau3(p) = T3(p)/p^2.
```

It is computable in O(Z(p)^2) operations by sparse membership tests.

The fixed-size random-support comparator is

```text
delta3(p) = Z(p)^3/p^3.
```

The signed discrepancy has the exact integer numerator

```text
gamma_num(p) = p*T3(p) - Z(p)^3,
Gamma(p)     = gamma_num(p)/p^3
             = tau3(p)-delta3(p).                       (1.4)
```

This integer must be written to the output. It avoids mistaking floating-point Fourier error for a genuine cubic bias.

### 1.2 Remove coefficient diagonals

Let s = inv7*(6a+13r+6). Count separately

```text
T3_distinct(p) = # {(a,r) in Z_p^2 : s in Z_p,
                    a,r,s are pairwise distinct}.
```

The three coincidence conditions a=r, a=s, and r=s are affine lines meeting in one point. Thus the complete plane contains exactly

```text
(p-1)(p-2)
```

pairwise-distinct triples, and a uniformly random Z(p)-subset has expected distinct count

```text
(Z(p))_3 / p.
```

The exact diagnostic ratio is therefore

```text
cubic_distinct_ratio(p) = p*T3_distinct(p)/(Z(p))_3.   (1.5)
```

It is undefined when Z(p) < 3. Reporting T3 without T3_distinct lets a finite number of diagonal configurations imitate a cubic correlation.

### 1.3 Nonzero cubic Fourier mass

Use the normalized transform

```text
zhat_p(h) = p^(-1) sum_x z_p(x) exp(-2*pi*i*h*x/p).
```

Set, modulo p,

```text
alpha = 6*inv7,
beta  = 13*inv7,
gamma = 6*inv7.
```

Then

```text
tau3(p)
 = sum_(h mod p)
   zhat_p(-alpha*h) zhat_p(-beta*h) zhat_p(h)
   exp(2*pi*i*gamma*h/p).                               (1.6)
```

The h=0 term is delta3(p). Therefore the signed nonzero Fourier contribution is exactly Gamma(p).

The scan must distinguish this signed sum from its absolute spectral envelope:

```text
Lambda3(p) = sum_(h != 0)
             |zhat_p(-alpha*h) zhat_p(-beta*h) zhat_p(h)|,

Q3(p)      = sum_(h != 0)
             |zhat_p(-alpha*h) zhat_p(-beta*h) zhat_p(h)|^2.
```

The useful diagnostics are

```text
abs(Gamma)/Lambda3       cancellation ratio, at most 1;
Lambda3/delta3           available nonzero cubic mass;
Q3                       concentration of that mass;
FourierSigned-Gamma      numerical validation residual.
```

A direct sparse DFT costs O(p Z(p)), so Lambda3 and Q3 should be computed only for a deterministic sample of primes. Gamma itself remains exact for every p through gamma_num.

## 3. Statistics to emit by dyadic shell

### 3.1 Exact load statistics

For union loads, and separately for each sign, emit

```text
Mpre   = sum_(q,t) A_q(t)
Mmark  = sum_(q,t) z_q(t) A_q(t)
Fpre   = sum_(q,t) A_q(t)(A_q(t)-1)
Fmark  = sum_(q,t) z_q(t) A_q(t)(A_q(t)-1)
Vup    = sum_q [sum_t A_q(t)^2 - (sum_t A_q(t))^2/q].  (3.1)
```

The exact integer regression identity is

```text
sum_(q,t) A_q(t)^2 = Fpre + Mpre.                      (3.2)
```

Record the heaviest states (q,t), their K_minus, K_plus, K_union, and their complete lower-prime lists. Zero totals alone are not enough to diagnose when the first nonzero event appears.

### 3.2 Baseline and WAUD statistics

Emit

```text
R1       = sum_(q,t) R_q(t)
R2       = sum_(q,t) R_q(t)^2
R2diag   = sum_(q,t,p) r(p,q,t)^2
R2cross  = R2-R2diag
VR       = sum_q [sum_t R_q(t)^2-(sum_t R_q(t))^2/q]
CovAR    = sum_q [sum_t A_q(t)R_q(t)
                  -(sum_t A_q(t))(sum_t R_q(t))/q]
Vaff     = direct centered variance of A-R.             (3.3)
```

The scanner must validate (0.1) from a direct centered computation of Vaff, not merely define Vaff by the right-hand side.

The ratio

```text
R2diag/R2
```

is a central regime diagnostic. If it is close to one, the apparent R2 behavior is still dominated by one-prime diagonal terms. Such a run has not tested a two-distinct-prime, log-squared law.

When Mpre=0, require exactly, up to the stated floating tolerance,

```text
Vup=0, CovAR=0, Vaff=VR, C=-R.                         (3.4)
```

### 3.3 Local cubic table

For every lower prime p emit at least

```text
p, Z, T3, T3_distinct, gamma_num,
rho2, tau3, delta3,
p*T3/Z^3,
p*T3_distinct/(Z)_3,
expected_distinct=(Z)_3/p.
```

For the Fourier sample add

```text
Gamma, FourierSignedReal, FourierSignedImag,
Lambda3, Q3, abs(Gamma)/Lambda3.
```

Do not fit cubic ratios from primes for which

```text
expected_distinct = (Z)_3/p < 1.
```

In that range T3_distinct=0 is ordinarily a finite-sparsity observation, not evidence of asymptotic depletion. Report strata

```text
expected_distinct < 1,
1 <= expected_distinct < 8,
expected_distinct >= 8.
```

### 3.4 Lower-prime window occupancy on q-prime rows

Let N(q,t) be the exact number of integer slots in the union window and P(q,t) the number of primes in it. Emit

```text
OccP1 = log(T) * sum P(q,t) / sum N(q,t),               (3.5)

OccP2 = log(T)^2 * sum (P(q,t))_2 / sum (N(q,t))_2.    (3.6)
```

OccP2 is the discriminating statistic. It removes the same-prime diagonal. A stable OccP1 together with OccP2=0 merely says most finite windows contain at most one prime.

Stratify rows by the expected occupancy

```text
lambda_p = N(q,t)/log(T)
```

using at least

```text
lambda_p < 0.5,
0.5 <= lambda_p < 2,
2 <= lambda_p < 8,
lambda_p >= 8.
```

A genuine second-log test comes from the last two strata, not from a mass of empty or singleton rows.

### 3.5 Reconstructed q-prime occupancy

The affine inverse reconstructs an integer q before q primality is imposed. For every legal sign-labelled lower-zero-pair occurrence, retain that reconstructed q and record

```text
Qcand_occ   = number of legal reconstructed occurrences before q primality
Qprime_occ  = those occurrences with q prime
OccQ1       = log(T)*Qprime_occ/Qcand_occ.              (3.7)
```

To separate reuse from primality, group distinct reconstructed q values by the pre-primality bucket (p,sign). If m_b is the number of distinct candidates and k_b the number that are prime, emit

```text
OccQ2 = log(T)^2 * sum_b (k_b)_2 / sum_b (m_b)_2.      (3.8)
```

Also emit the occurrence-to-distinct-q reuse ratio. An occurrence-weighted prime rate can be distorted by many lower pairs reconstructing the same q.

This is the relevant q-prime occupancy. It is formed before q primality and does not assume a prime-number-theorem factor for the reconstructed values.

## 4. Competing normalization scales

Let L = log T. The canonical closing variance scale is

```text
F0 = T^(12/5) L^(-16/5).                               (4.1)
```

Always emit

```text
R2/F0, VR/F0, Vup/F0, Vaff/F0,
R2diag/F0, R2cross/F0.
```

Three additional reference scales distinguish finite diagonal behavior from a genuinely populated square:

```text
Sdiag  = T^(5/3)  L^(-2),
Scoh   = T^(8/3)  L^(-3),
Scrude = T^(16/5) L^(-8/5).                            (4.2)
```

They are reference envelopes, not asserted asymptotics.

Their origin is transparent under the pointwise Z(p) <= p^(2/3) scale:

```text
# q-prime residue rows        about T^2/L
# lower-prime slots per row   about T/L
rho2(p)                       at most T^(-2/3).
```

Keeping only p1=p2 terms in R2 gives Sdiag. Squaring the whole row mean gives Scoh. The old load-height estimate gives Scrude.

The comparisons are informative:

```text
Sdiag/F0 = T^(-11/15) L^(6/5),
Scoh/F0  = T^(4/15)  L^(1/5).
```

Thus a diagonal-dominated finite scan may already lie below F0 without testing the difficult cross terms, while a fully coherent row baseline can still exceed F0. This is why R2diag and R2cross must be reported separately.

For each metric X in {R2, VR, Vaff}, emit

```text
X/F0, X/Sdiag, X/Scoh, X/Scrude.                       (4.3)
```

For consecutive dyadic shells T and 2T, report normalized drift rather than a single raw log-log slope:

```text
drift_S(X;T) = log_2( [X(2T)/S(2T)] / [X(T)/S(T)] ).   (4.4)
```

Use S=F0, Sdiag, and Scoh. A zero value is compatible with that reference scale over the observed interval. It is not a proof of the corresponding exponent.

Do not compute a slope across zero-valued shells. Mark it as censored until both endpoints are nonzero and the relevant occupancy strata are populated.

## 5. What would discriminate a true second logarithm

A run begins to test the proposed mechanism only after all of the following occur in at least several consecutive dyadic shells:

1. Mpre is nonzero, so Vaff is not identically VR by construction.
2. The lambda_p >= 2 strata contain many rows and OccP2 is nonzero.
3. R2cross is a visible proportion of R2; otherwise the square is diagonal.
4. There are many p with (Z(p))_3/p >= 1, preferably >= 8.
5. The reconstructed q-prime denominator in (3.7) is large and not dominated by a few repeated q values.
6. The Fourier sample contains nonzero cubic mass; Gamma is compared with Lambda3 rather than only with delta3.

The following outcomes have different meanings:

```text
Mpre=0, Vaff=VR
  baseline-only finite sparsity; no WAUD test.

OccP1 stable, OccP2 near zero, lambda_p mostly below 1
  singleton-window sparsity; no evidence for a second-log law.

OccP2 stable in lambda_p >= 2 bins, but R2diag/R2 near 1
  prime windows are populated, but R2 still has no two-prime regime.

R2cross visible, tau3/delta3 stable, Vaff/F0 decreasing
  evidence that the proposed centering is numerically relevant;
  still not an asymptotic theorem.

Lambda3 large but abs(Gamma)/Lambda3 small
  strong cubic Fourier cancellation.

Lambda3 and Gamma both large
  a genuine local cubic obstruction that the tau baseline must retain.
```

## 7. Complexity and run plan

Let P_T be the primes in (T/7,T/3]. After the prime sieve:

```text
zero-table construction       O(sum_(p in P_T) p)
sparse cubic counts           O(sum_(p in P_T) Z(p)^2)
sparse inverse events         O(sum_(p in P_T) Z(p)^2)
R range additions             O(#P_T^2)
R prefix scans and occupancy  O(sum_(q in P_T) q)
sampled direct Fourier        O(sum_(sampled p) p Z(p)).
```

With only pointwise information, the two O(sum p) passes are of order T^2/log T and dominate at large T. Memory is

```text
O(max q + Mpre + reconstructed-q candidates),
```

because zero flags and R arrays are processed one prime at a time. Zero sets are cached on disk.

Recommended exact shells are

```text
T = 19200, 38400, 76800, 153600, ...
```

for one fixed J. Keep each shell independent. Stop increasing T when the exact zero-table pass, not the sparse event pass, becomes the bottleneck; then shard lower primes for T3/events and upper primes for R/occupancy. Shard outputs combine by addition, except that state-prime union records must first be merged by (q,t,p).

Fourier diagnostics should use a deterministic rule, for example all p <= fourier_max and every k-th prime thereafter. Record the rule in every output file.

static std::string big_string(const Big& x) {

static long double big_ld(const Big& x) {

static long double safe_ratio(const Big& a, const Big& b) {
    if (b == 0) return std::numeric_limits<long double>::quiet_NaN();

static i64 mod_norm(i128 x, i64 p) {
    i64 r = static_cast<i64>(x % p);
    if (r < 0) r += p;
    return r;
}

static i64 mod_mul(i64 a, i64 b, i64 p) {
    return mod_norm(static_cast<i128>(a) * b, p);
}

static i64 mod_pow(i64 a, i64 e, i64 p) {
    i64 r = 1;
    while (e > 0) {
        if (e & 1) r = mod_mul(r, a, p);
        a = mod_mul(a, a, p);
        e >>= 1;
    }
    return r;
}

struct PrimeTable {
    std::vector<std::uint8_t> is_prime;
    std::vector<int> prefix;
    std::vector<int> primes;

    explicit PrimeTable(int n) : is_prime(n + 1, 1), prefix(n + 1, 0) {
        if (n >= 0) is_prime[0] = 0;
        if (n >= 1) is_prime[1] = 0;
        for (int p = 2; static_cast<i64>(p) * p <= n; ++p) {
            if (!is_prime[p]) continue;
            for (int m = p * p; m <= n; m += p) is_prime[m] = 0;
        }
        for (int x = 0; x <= n; ++x) {
            if (is_prime[x]) primes.push_back(x);
            prefix[x] = (x == 0 ? 0 : prefix[x - 1]) + (is_prime[x] ? 1 : 0);
        }
    }

    bool prime(int n) const {
        return n >= 0 && n < static_cast<int>(is_prime.size()) && is_prime[n];
    }

    int count(int lo, int hi) const {
        if (hi < lo) return 0;
        lo = std::max(lo, 0);
        hi = std::min(hi, static_cast<int>(prefix.size()) - 1);
        if (hi < lo) return 0;
        return prefix[hi] - (lo == 0 ? 0 : prefix[lo - 1]);
    }
};

static Big choose_big(int n, int k) {
    if (k < 0 || k > n) return 0;
    k = std::min(k, n - k);
    Big r = 1;
    for (int j = 1; j <= k; ++j) {
        r *= n - k + j;
        r /= j;
    }
    return r;
}

static int apery_literal_mod(int n, int p) {
    Big s = 0;
    for (int k = 0; k <= n; ++k) {
        Big a = choose_big(n, k);
        Big c = choose_big(n + k, k);
        s += a * a * c * c;
    }
    return static_cast<int>((s % p).convert_to<int>());
}

static std::vector<int> build_zero_list(int p) {
    if (p <= 13) throw std::runtime_error("prime too small for q6 scan");
    std::vector<i64> b(p, 0);
    std::vector<i64> inv(p, 0);
    b[0] = 1;
    inv[1] = 1;
    for (int n = 2; n < p; ++n) {
        inv[n] = mod_norm(-static_cast<i128>(p / n) * inv[p % n], p);
    }
    for (int n = 0; n <= p - 2; ++n) {
        i64 x = n % p;
        i64 x2 = mod_mul(x, x, p);
        i64 x3 = mod_mul(x2, x, p);
        i64 coeff = mod_norm(static_cast<i128>(34) * x3
                           + static_cast<i128>(51) * x2
                           + static_cast<i128>(27) * x + 5, p);
        i64 previous = (n == 0 ? 0 : b[n - 1]);
        i64 rhs = mod_norm(static_cast<i128>(coeff) * b[n]
                         - static_cast<i128>(x3) * previous, p);
        i64 inv3 = mod_mul(mod_mul(inv[n + 1], inv[n + 1], p), inv[n + 1], p);
        b[n + 1] = mod_mul(rhs, inv3, p);
    }
    std::vector<int> zeros;
    for (int n = 0; n < p; ++n) if (b[n] == 0) zeros.push_back(n);

    for (int u : zeros) {
        if (b[p - 1 - u] != 0) throw std::runtime_error("reflection failure");
    }
    if (p <= 31) {
        for (int n = 0; n <= std::min(p - 1, 12); ++n) {
            if (b[n] != apery_literal_mod(n, p)) {
                throw std::runtime_error("recurrence versus literal Apéry failure");
            }
        }
    }
    return zeros;
}

static std::vector<int> load_zeros(int p, const fs::path& cache) {
    fs::create_directories(cache);
    fs::path file = cache / ("zeros_" + std::to_string(p) + ".txt");
    {
        std::ifstream in(file);
        int stored_p = 0;
        std::size_t n = 0;
        if (in >> stored_p >> n && stored_p == p) {
            std::vector<int> z(n);
            for (std::size_t i = 0; i < n; ++i) {
                if (!(in >> z[i])) throw std::runtime_error("truncated zero cache");
            }
            if (!std::is_sorted(z.begin(), z.end())) throw std::runtime_error("unsorted zero cache");
            return z;
        }
    }
    std::vector<int> z = build_zero_list(p);
    fs::path temp = file;
    temp += ".tmp";
    {
        std::ofstream out(temp);
        out << p << ' ' << z.size() << std::endl;
        for (int x : z) out << x << std::endl;
    }
    fs::rename(temp, file);
    return z;
}

static std::vector<std::uint8_t> zero_flags(int p, const std::vector<int>& z) {
    std::vector<std::uint8_t> flag(p, 0);
    for (int x : z) flag[x] = 1;
    return flag;
}

struct LocalStats {
    int p = 0;
    u64 Z = 0;
    u64 T3 = 0;
    u64 T3_distinct = 0;
    Big gamma_num = 0;
    long double rho2 = 0;
    long double tau3 = 0;
    long double delta3 = 0;
    long double gamma = 0;
    long double expected_distinct = 0;
};

static LocalStats local_stats(int p, const std::vector<int>& zeros, bool brute_validate) {
    LocalStats s;
    s.p = p;
    s.Z = zeros.size();
    auto flag = zero_flags(p, zeros);
    i64 inv7 = mod_pow(7, p - 2, p);
    for (int a : zeros) {
        for (int r : zeros) {
            int third = static_cast<int>(mod_mul(inv7,
                mod_norm(static_cast<i128>(6) * a + static_cast<i128>(13) * r + 6, p), p));
            if (!flag[third]) continue;
            ++s.T3;
            if (a != r && a != third && r != third) ++s.T3_distinct;
        }
    }
    long double P = p;
    long double Z = s.Z;
    s.rho2 = (Z / P) * (Z / P);
    s.tau3 = static_cast<long double>(s.T3) / (P * P);
    s.delta3 = (Z / P) * (Z / P) * (Z / P);
    s.gamma_num = Big(p) * s.T3 - Big(s.Z) * s.Z * s.Z;
    s.gamma = s.gamma_num.convert_to<long double>() / (P * P * P);
    if (s.Z >= 3) {
        s.expected_distinct = Z * (Z - 1) * (Z - 2) / P;
    }

    if (brute_validate) {
        u64 minus_total = 0;
        u64 plus_total = 0;
        u64 overlap_total = 0;
        for (int d = 0; d < p; ++d) {
            for (int t = 0; t < p; ++t) {
                int a = mod_norm(static_cast<i128>(d) - t - 1, p);
                int r = mod_norm(static_cast<i128>(6) * d + t, p);
                int w = mod_norm(static_cast<i128>(12) * d + t, p);
                bool xm = flag[a] && flag[r];
                bool xp = flag[r] && flag[w];
                minus_total += xm;
                plus_total += xp;
                overlap_total += xm && xp;
            }
        }
        if (minus_total != s.Z * s.Z || plus_total != s.Z * s.Z || overlap_total != s.T3) {
            throw std::runtime_error("complete-plane identity failure");
        }
    }
    return s;
}

struct FourierStats {
    long double signed_real = 0;
    long double signed_imag = 0;
    long double absolute_mass = 0;
    long double squared_mass = 0;
};

static FourierStats cubic_fourier(int p, const std::vector<int>& zeros, const LocalStats& local) {
    const long double pi = acosl(-1.0L);
    std::vector<std::complex<long double>> hat(p);
    for (int h = 0; h < p; ++h) {
        std::complex<long double> sum(0, 0);
        for (int x : zeros) {
            long double angle = -2.0L * pi * h * x / p;
            sum += std::complex<long double>(cosl(angle), sinl(angle));
        }
        hat[h] = sum / static_cast<long double>(p);
    }
    i64 inv7 = mod_pow(7, p - 2, p);
    int alpha = mod_mul(6, inv7, p);
    int beta = mod_mul(13, inv7, p);
    int gamma = alpha;
    std::complex<long double> signed_sum(0, 0);
    FourierStats out;
    for (int h = 1; h < p; ++h) {
        int h1 = mod_norm(-static_cast<i128>(alpha) * h, p);
        int h2 = mod_norm(-static_cast<i128>(beta) * h, p);
        long double angle = 2.0L * pi * gamma * h / p;
        std::complex<long double> phase(cosl(angle), sinl(angle));
        std::complex<long double> term = hat[h1] * hat[h2] * hat[h] * phase;
        signed_sum += term;
        long double mag = std::abs(hat[h1] * hat[h2] * hat[h]);
        out.absolute_mass += mag;
        out.squared_mass += mag * mag;
    }
    out.signed_real = signed_sum.real();
    out.signed_imag = signed_sum.imag();
    long double tolerance = 1e-8L * (1.0L + out.absolute_mass);
    if (fabsl(out.signed_real - local.gamma) > tolerance || fabsl(out.signed_imag) > tolerance) {
        throw std::runtime_error("cubic Fourier validation failure");
    }
    return out;
}

struct Interval {
    i64 lo = 1;
    i64 hi = 0;
    bool valid() const { return lo <= hi; }
    i64 size() const { return valid() ? hi - lo + 1 : 0; }
};

static Interval intersect(Interval a, Interval b) {
    return {std::max(a.lo, b.lo), std::min(a.hi, b.hi)};
}

static Interval t_band(i64 q, i64 T) {
    return {std::max<i64>(0, T - 6 * q + 1), std::min<i64>(q - 1, 2 * T - 6 * q)};
}

struct SignRanges {
    Interval minus;
    Interval plus;
};

static SignRanges sign_ranges(i64 p, i64 q, i64 T, i64 J) {
    i64 d = q - p;
    if (d <= 0 || static_cast<i128>(d) * J <= T) return {};
    Interval base = t_band(q, T);
    if (!base.valid()) return {};
    Interval minus{base.lo, std::min({base.hi, d - 1, p - 6 * d - 1})};
    Interval plus{std::max(base.lo, p - 12 * d), std::min(base.hi, p - 6 * d - 1)};
    return {minus, plus};
}

struct PrimeWindow {
    i64 lower = 1;
    i64 upper_minus = 0;
    i64 upper_plus = 0;
    i64 upper_union = 0;
};

static PrimeWindow prime_window(i64 q, i64 t, i64 T, i64 J) {
    i64 A = T / 7 + 1;
    i64 B = T / 3;
    i64 h = T / J;
    i64 lower = std::max(A, (6 * q + t) / 7 + 1);
    i64 cap = std::min(B, q - h - 1);
    i64 um = std::min(cap, q - t - 1);
    i64 up = std::min(cap, (12 * q + t) / 13);
    return {lower, um, up, std::max(um, up)};
}

static void range_add(std::vector<long double>& diff, Interval in, long double value) {
    if (!in.valid()) return;
    diff[in.lo] += value;
    if (in.hi + 1 < static_cast<i64>(diff.size())) diff[in.hi + 1] -= value;
}

static u64 state_key(int q, int t) {
    return (static_cast<u64>(static_cast<std::uint32_t>(q)) << 32)
         | static_cast<std::uint32_t>(t);
}

static int key_q(u64 key) { return static_cast<int>(key >> 32); }
static int key_t(u64 key) { return static_cast<int>(key & 0xffffffffu); }

struct StateEvents {
    std::vector<int> minus;
    std::vector<int> plus;
};

struct LoadRow {
    int t = 0;
    int minus = 0;
    int plus = 0;
    int uni = 0;
};

static int union_size(const std::vector<int>& a, const std::vector<int>& b) {
    std::size_t i = 0;
    std::size_t j = 0;
    int n = 0;
    while (i < a.size() || j < b.size()) {
        if (j == b.size() || (i < a.size() && a[i] < b[j])) {
            ++i;
        } else if (i == a.size() || b[j] < a[i]) {
            ++j;
        } else {
            ++i;
            ++j;
        }
        ++n;
    }
    return n;
}

struct Occupancy {
    Big rows = 0;
    Big integer_slots = 0;
    Big prime_slots = 0;
    Big integer_pairs = 0;
    Big prime_pairs = 0;
};

struct Args {
    int J = 0;
    int fourier_max = 0;
    int fourier_step = 1;
    fs::path cache = "q7409-zero-cache";
    fs::path out = "q7409-output";
    std::vector<int> T_values;
};

static Args parse_args(int argc, char** argv) {
    Args a;
    for (int i = 1; i < argc; ++i) {
        std::string s = argv[i];
        if (s == "--J" && i + 1 < argc) a.J = std::stoi(argv[++i]);
        else if (s == "--fourier-max" && i + 1 < argc) a.fourier_max = std::stoi(argv[++i]);
        else if (s == "--fourier-step" && i + 1 < argc) a.fourier_step = std::stoi(argv[++i]);
        else if (s == "--cache" && i + 1 < argc) a.cache = argv[++i];
        else if (s == "--out" && i + 1 < argc) a.out = argv[++i];
        else if (!s.empty() && s[0] == '-') throw std::runtime_error("unknown option " + s);
        else a.T_values.push_back(std::stoi(s));
    }
    if (a.J <= 0 || a.fourier_step <= 0 || a.T_values.empty()) {
        throw std::runtime_error("usage: q7409_tau_waud --J J [options] T...");
    }
    return a;
}

static long double rel_error(long double a, long double b) {
    return fabsl(a - b) / (1.0L + fabsl(a) + fabsl(b));
}

static int literal_weight(bool, int, int, int) {
    return 1;
}

static void scan_one(int T, const Args& args, const PrimeTable& table) {
    const int J = args.J;
    const int A = T / 7 + 1;
    const int B = T / 3;
    const long double L = logl(static_cast<long double>(T));
    fs::path dir = args.out / ("T" + std::to_string(T));
    fs::create_directories(dir);

    std::vector<int> shell;
    for (int p : table.primes) if (A <= p && p <= B) shell.push_back(p);

    std::unordered_map<int, LocalStats> local;
    local.reserve(shell.size() * 2 + 1);
    std::unordered_map<u64, StateEvents> states;
    std::unordered_map<u64, std::vector<int>> q_buckets;
    u64 q_candidate_occurrences = 0;
    u64 q_prime_occurrences = 0;

    std::ofstream local_csv(dir / "local_cubic.csv");
    local_csv << "p,Z,T3,T3_distinct,gamma_num,rho2,tau3,delta3,ratio_all,expected_distinct,ratio_distinct" << std::endl;
    std::ofstream fourier_csv(dir / "fourier.csv");
    fourier_csv << "p,Z,Gamma,signed_real,signed_imag,Lambda3,Q3,cancellation" << std::endl;

    int sampled_index = 0;
    for (int p : shell) {
        std::vector<int> zeros = load_zeros(p, args.cache);
        bool brute = p <= 211;
        LocalStats ls = local_stats(p, zeros, brute);
        local[p] = ls;

        long double ratio_all = std::numeric_limits<long double>::quiet_NaN();
        long double ratio_distinct = std::numeric_limits<long double>::quiet_NaN();
        if (ls.Z > 0) {
            long double z3 = static_cast<long double>(ls.Z) * ls.Z * ls.Z;
            ratio_all = static_cast<long double>(p) * ls.T3 / z3;
        }
        if (ls.Z >= 3) {
            long double f3 = static_cast<long double>(ls.Z) * (ls.Z - 1) * (ls.Z - 2);
            ratio_distinct = static_cast<long double>(p) * ls.T3_distinct / f3;
        }
        local_csv << p << ',' << ls.Z << ',' << ls.T3 << ',' << ls.T3_distinct << ','
                  << big_string(ls.gamma_num) << ',' << std::setprecision(20)
                  << ls.rho2 << ',' << ls.tau3 << ',' << ls.delta3 << ','
                  << ratio_all << ',' << ls.expected_distinct << ',' << ratio_distinct << std::endl;

        if (args.fourier_max > 0 && p <= args.fourier_max
            && sampled_index++ % args.fourier_step == 0) {
            FourierStats f = cubic_fourier(p, zeros, ls);
            long double cancellation = f.absolute_mass == 0 ? 0 : fabsl(ls.gamma) / f.absolute_mass;
            fourier_csv << p << ',' << ls.Z << ',' << std::setprecision(20)
                        << ls.gamma << ',' << f.signed_real << ',' << f.signed_imag << ','
                        << f.absolute_mass << ',' << f.squared_mass << ',' << cancellation << std::endl;
        }

        auto flag = zero_flags(p, zeros);
        auto add_candidate = [&](bool plus, int x, int y) {
            i64 d = 0;
            i64 t = 0;
            if (!plus) {
                i64 numerator = static_cast<i64>(x) + y + 1;
                if (numerator % 7 != 0) return;
                d = numerator / 7;
                t = d - x - 1;
            } else {
                i64 numerator = static_cast<i64>(x) + y + 1;
                if (numerator % 6 != 0) return;
                d = numerator / 6;
                t = static_cast<i64>(p) - 1 - x - 6 * d;
            }
            i64 q = static_cast<i64>(p) + d;
            if (q < A || q > B || t < 0 || t >= q) return;
            SignRanges ranges = sign_ranges(p, q, T, J);
            Interval required = plus ? ranges.plus : ranges.minus;
            if (!required.valid() || t < required.lo || t > required.hi) return;

            ++q_candidate_occurrences;
            u64 bucket = (static_cast<u64>(p) << 1) | (plus ? 1u : 0u);
            q_buckets[bucket].push_back(static_cast<int>(q));
            if (!table.prime(static_cast<int>(q))) return;
            ++q_prime_occurrences;

            int copies = literal_weight(plus, p, static_cast<int>(q), static_cast<int>(t));
            if (copies <= 0) return;
            StateEvents& e = states[state_key(static_cast<int>(q), static_cast<int>(t))];
            std::vector<int>& target = plus ? e.plus : e.minus;
            for (int copy = 0; copy < copies; ++copy) target.push_back(p);
        };

        for (int x : zeros) {
            for (int y : zeros) {
                add_candidate(false, x, y);
                add_candidate(true, x, y);
            }
        }
    }

    Big q_distinct_slots = 0;
    Big q_distinct_hits = 0;
    Big q_distinct_pairs = 0;
    Big q_prime_pairs = 0;
    for (auto& [bucket, values] : q_buckets) {
        std::sort(values.begin(), values.end());
        values.erase(std::unique(values.begin(), values.end()), values.end());
        i64 m = values.size();
        i64 k = 0;
        for (int q : values) if (table.prime(q)) ++k;
        q_distinct_slots += m;
        q_distinct_hits += k;
        q_distinct_pairs += Big(m) * (m - 1);
        q_prime_pairs += Big(k) * (k - 1);
    }

    std::unordered_map<int, std::vector<LoadRow>> loads_by_q;
    Big Mpre_minus = 0, Mpre_plus = 0, Mpre_union = 0;
    Big Fpre_minus = 0, Fpre_plus = 0, Fpre_union = 0;
    Big sum_A2_exact = 0;

    for (auto& [key, e] : states) {
        std::sort(e.minus.begin(), e.minus.end());
        std::sort(e.plus.begin(), e.plus.end());
        auto mend = std::unique(e.minus.begin(), e.minus.end());
        auto pend = std::unique(e.plus.begin(), e.plus.end());
        if (mend != e.minus.end() || pend != e.plus.end()) {
            throw std::runtime_error("duplicate same-sign event witness");
        }
        int km = e.minus.size();
        int kp = e.plus.size();
        int ku = union_size(e.minus, e.plus);
        int q = key_q(key);
        int t = key_t(key);
        loads_by_q[q].push_back({t, km, kp, ku});
        Mpre_minus += km;
        Mpre_plus += kp;
        Mpre_union += ku;
        Fpre_minus += Big(km) * (km - 1);
        Fpre_plus += Big(kp) * (kp - 1);
        Fpre_union += Big(ku) * (ku - 1);
        sum_A2_exact += Big(ku) * ku;
    }
    if (sum_A2_exact != Mpre_union + Fpre_union) {
        throw std::runtime_error("exact A-square identity failure");
    }

    for (auto& [q, rows] : loads_by_q) {
        std::sort(rows.begin(), rows.end(), [](const LoadRow& a, const LoadRow& b) { return a.t < b.t; });
    }

    Big Mmark_minus = 0, Mmark_plus = 0, Mmark_union = 0;
    Big Fmark_minus = 0, Fmark_plus = 0, Fmark_union = 0;
    Occupancy occ_all;
    Occupancy occ_bins[4];

    long double R1 = 0;
    long double R2 = 0;
    long double R2diag = 0;
    long double VR = 0;
    long double Vup = 0;
    long double CovAR = 0;
    long double Vaff = 0;
    long double Vaff_identity = 0;

    for (int q : shell) {
        std::vector<long double> diff(q + 1, 0);
        long double r1_formula = 0;
        long double diag_q = 0;

        for (int p : shell) {
            if (p >= q) break;
            SignRanges ranges = sign_ranges(p, q, T, J);
            if (!ranges.minus.valid() && !ranges.plus.valid()) continue;
            const LocalStats& ls = local.at(p);
            range_add(diff, ranges.minus, ls.rho2);
            range_add(diff, ranges.plus, ls.rho2);
            Interval both = intersect(ranges.minus, ranges.plus);
            range_add(diff, both, -ls.tau3);

            i64 lm = ranges.minus.size();
            i64 lp = ranges.plus.size();
            i64 li = both.size();
            r1_formula += (lm + lp) * ls.rho2 - li * ls.tau3;
            long double overlap_value = 2 * ls.rho2 - ls.tau3;
            diag_q += (lm + lp - 2 * li) * ls.rho2 * ls.rho2
                    + li * overlap_value * overlap_value;
        }

        std::vector<long double> r(q, 0);
        long double running = 0;
        for (int t = 0; t < q; ++t) {
            running += diff[t];
            r[t] = running;
        }

        std::vector<int> a(q, 0), am(q, 0), ap(q, 0);
        auto load_it = loads_by_q.find(q);
        if (load_it != loads_by_q.end()) {
            for (const LoadRow& row : load_it->second) {
                a[row.t] = row.uni;
                am[row.t] = row.minus;
                ap[row.t] = row.plus;
            }
        }

        std::vector<int> qzeros = load_zeros(q, args.cache);
        auto qflag = zero_flags(q, qzeros);
        for (int t = 0; t < q; ++t) if (qflag[t]) {
            Mmark_minus += am[t];
            Mmark_plus += ap[t];
            Mmark_union += a[t];
            Fmark_minus += Big(am[t]) * (am[t] - 1);
            Fmark_plus += Big(ap[t]) * (ap[t] - 1);
            Fmark_union += Big(a[t]) * (a[t] - 1);
        }

        Interval band = t_band(q, T);
        if (band.valid()) {
            for (int t = band.lo; t <= band.hi; ++t) {
                PrimeWindow w = prime_window(q, t, T, J);
                if (q > 14LL * t && w.upper_minus < w.upper_plus) {
                    throw std::runtime_error("minus/plus nesting switch failure");
                }
                if (q < 14LL * t && w.upper_plus < w.upper_minus) {
                    throw std::runtime_error("plus/minus nesting switch failure");
                }
                i64 n = std::max<i64>(0, w.upper_union - w.lower + 1);
                i64 k = n == 0 ? 0 : table.count(w.lower, w.upper_union);
                occ_all.rows += 1;
                occ_all.integer_slots += n;
                occ_all.prime_slots += k;
                occ_all.integer_pairs += Big(n) * (n - 1);
                occ_all.prime_pairs += Big(k) * (k - 1);
                long double lambda = n / L;
                int bin = lambda < 0.5L ? 0 : lambda < 2 ? 1 : lambda < 8 ? 2 : 3;
                Occupancy& ob = occ_bins[bin];
                ob.rows += 1;
                ob.integer_slots += n;
                ob.prime_slots += k;
                ob.integer_pairs += Big(n) * (n - 1);
                ob.prime_pairs += Big(k) * (k - 1);
            }
        }

        long double sum_a = 0, sum_r = 0, sum_a2 = 0, sum_r2 = 0, sum_ar = 0;
        long double sum_c = 0, sum_c2 = 0;
        for (int t = 0; t < q; ++t) {
            long double av = a[t];
            long double rv = r[t];
            long double cv = av - rv;
            sum_a += av;
            sum_r += rv;
            sum_a2 += av * av;
            sum_r2 += rv * rv;
            sum_ar += av * rv;
            sum_c += cv;
            sum_c2 += cv * cv;
        }
        if (rel_error(sum_r, r1_formula) > 1e-12L) {
            throw std::runtime_error("R range-add first-moment failure");
        }
        long double qVup = sum_a2 - sum_a * sum_a / q;
        long double qVR = sum_r2 - sum_r * sum_r / q;
        long double qCov = sum_ar - sum_a * sum_r / q;
        long double qVaff = sum_c2 - sum_c * sum_c / q;
        long double qIdentity = qVup + qVR - 2 * qCov;
        if (rel_error(qVaff, qIdentity) > 1e-11L) {
            throw std::runtime_error("WAUD variance identity failure");
        }

        R1 += sum_r;
        R2 += sum_r2;
        R2diag += diag_q;
        Vup += qVup;
        VR += qVR;
        CovAR += qCov;
        Vaff += qVaff;
        Vaff_identity += qIdentity;
    }

    if (Mpre_union == 0) {
        if (fabsl(Vup) > 1e-12L || fabsl(CovAR) > 1e-12L || rel_error(Vaff, VR) > 1e-11L) {
            throw std::runtime_error("zero-load baseline identity failure");
        }
    }
    if (Mmark_union > Mpre_union || Fmark_union > Fpre_union) {
        throw std::runtime_error("marked subset monotonicity failure");
    }

    long double F0 = powl(T, 12.0L / 5) * powl(L, -16.0L / 5);
    long double Sdiag = powl(T, 5.0L / 3) * powl(L, -2.0L);

### Code boundary

The reference program deliberately writes one row per state only after same-state numerical-prime union. If the active local theorem assigns multiple physically distinct source labels to the same `(q,t,p,sign)`, the `literal_weight` hook must be expanded so those labels are explicit. A scalar multiplicity must not be inserted after union if the theorem's Boolean consumer distinguishes the labels.

For very large shells, replace the in-memory `states` map by an external sort of records

```text
(q,t,p,sign,source_label)
```

and perform union/grouping in the merge pass. The mathematical statistics and validation identities are unchanged.

## 9. Concise structural conjecture suggested by the experiment

The experiment targets the following occurrence-preserving statement.

> **Q6-C4-WAUD-tau.** For each fixed J, form the literal pre-upper numerical-prime union load A_q(t), retaining q and lower-p primality, the exact clipped windows, both sign predicates, every source/lift label required by the consumer, and no upper test q divides b_t. Form R_q(t) from the exact complete-plane pair density rho2(p) and cubic overlap density tau3(p) as in (2.4). Then
>
> ```text
> sum_(q,t) |(A_q(t)-R_q(t))-mean_q(A-R)|^2
>   = o_J(T^(12/5) (log T)^(-16/5)).
> ```

A more local first sublemma, directly tested by the cubic table, is:

> On primes for which `(Z(p))_3/p` is genuinely large, the nonzero cubic Fourier contribution Gamma(p) has enough cancellation after the exact q6 overlap-window weights are applied that its centered square contribution is `o_J(F0)`.

This is mathematically falsifiable. A persistent large `abs(Gamma)/Lambda3`, concentrated on primes carrying most overlap-window weight, would reject the cubic-cancellation subroute even if the total finite census remained sparse.

The full WAUD statement also contains pair-plane defects; tau3 alone cannot prove it. The value of the proposed experiment is precisely that it reports the pair baseline, cubic correction, primality occupancy, diagonal square, cross square, and actual event load separately, so a failure can be assigned to its first exact component rather than hidden inside one positive Vaff number.
