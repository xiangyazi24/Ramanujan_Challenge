# Same-K beta-Pade cancellation: strategic audit

## Verdict

The same-K identity is a genuinely different object from the already ruled-out bounded local target-preserving observations, but it does **not** automatically escape the scalar obstruction. The exact distinction is:

- Smith-saturated local observations ask for a second equation at one prime.
- Same-K cancellation compares many characteristic-zero carriers that share the same near-origin packet.

The second direction is potentially new. However, the weakest theorem that would close the gcd problem is still a theorem about the remaining distinguished scalar, not merely about the holonomic recurrence.

## Exact reduction

Let

```
A_{D,N}+H_{D,N}=S_K,
K=floor(M/(D-1)).
```

For fixed K, all pairs (D,N) with that K share the same packet S_K. Therefore any integer linear combination satisfies

```
Σ c_i A_i = -Σ c_i H_i + (Σ c_i) S_K.
```

The only way to remove the common packet without paying its full height is to impose

```
Σ c_i = 0.
```

Then the resulting carrier is a difference of the H-packets. This is not a new target equation unless the H-family has a provable primitive-content collapse.

The exact remaining question is therefore:

```
Can the same-K family produce a target-preserving integer T_K with
log rad(T_K) = o(block size)?
```

where T_K is built from the H_{D,N} after eliminating S_K.

## Weakest sufficient theorem

A sufficient theorem is the following.

For every mesoscopic block and every fixed quotient packet K, let E_K be the set of distinct target primes in that packet. Construct a bounded-overlap family of same-K differences

```
T_{K,i}=Σ_j c_{i,j} A_{D_j,N_j}
```

with

1. every q in E_K divides at least one T_{K,i};
2. coefficients satisfy

```
Σ_i log ||c_i|| + Σ_i log |T_{K,i}| = o(H)
```

in total over the block cover.

Then

```
log rad gcd(b_n,lcm(1,...,n)) = o(n).
```

This is the weakest useful statement because it directly supplies the missing block ledger; any weaker recurrence statement must eventually imply this.

## Does recurrence in D plausibly prove it?

Only partially.

A recurrence in D gives:

- bounded state dimension;
- finite singular set per transition;
- possible observability determinants.

But it does not by itself give primitive content bounds for the distinguished H-family. The recurrence controls propagation of the vector state, not the arithmetic index of the actual state.

The known failure mode remains:

```
observability determinant = universal content × primitive target scalar.
```

Removing universal content returns exactly the original scalar.

## Why this is outside previous no-go theorems

It avoids the strongest local no-go because the construction is not required to preserve one prime independently. Same-K cancellation uses global relations among several carriers before reduction modulo q.

However, it still faces a new analogue of the old obstruction:

If all same-K combinations reduce modulo q to the same one-dimensional target coordinate, then the family only removes presentation content. The remaining primitive quotient is again

```
q | C_M(q-1)
```

in disguise.

## Height issue

The endpoint Newton/Padé carriers failed because their coefficients had linear height. Same-K cancellation can only win if the common packet S_K cancellation leaves a primitive H-family whose total height is sub-block.

The required theorem is therefore not:

```
H-family is holonomic.
```

It is:

```
primitive same-K H-content has sublinear logarithmic height.
```

Holonomicity is compatible with exponential primitive values.

## Final classification

| Question | Verdict |
|---|---|
| Is same-K cancellation literally covered by Smith rank-one no-go? | No |
| Does same-K cancellation automatically create a second prime equation? | No |
| Can D-holonomicity alone prove the needed bound? | No |
| What new theorem would close the route? | A primitive same-K content/nonconcentration theorem |
| Is the residual exactly the original scalar if that theorem fails? | Yes |

The strategic escape is real but narrow: it is the first route that attacks correlations between carriers rather than single-prime saturation. Its burden is a new horizontal primitive-content theorem, not another recurrence calculation.
