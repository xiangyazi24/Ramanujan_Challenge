# P3.2 — explicit second-moment calculation for the q=6 count

## Verdict

**No: the proposed conclusion is not rigorous, and the claimed off-diagonal size is not even the correct independence heuristic.**

The sum-order reduction is useful and can be made completely exact, but the step

\[
\mathbf 1\bigl[(r_2+6p_2)\bmod p_1\in Z_{p_1}\bigr]
\rightsquigarrow \frac{|Z_{p_1}|}{p_1}
\]

is a new **cross-prime shifted-zero-set equidistribution / pair-correlation hypothesis**. It does not follow from the cardinalities \(|Z_p|\), from \(\sum |Z_p|/p\), or from a first-moment bound.

There are also two counting corrections:

1. \(K_6(n)^2\) counts **ordered** pairs, so after restricting to \(p_1<p_2\) the off-diagonal contribution carries a factor \(2\).
2. For \(n\asymp 6p_2\), the prime window has length \(\asymp p_2\) (indeed the full q=6 window has width \(n/42\asymp p_2/7\)), not \(p_2/42\). After prime density is included, the random-model inner count is of order \(1/\log p_2\), not \(1/p_2\).

Thus, if the zero sets behaved independently across primes and had bounded average cardinality, the natural prediction is

\[
E_{2,\mathrm{off}}(N)\asymp \frac{N}{(\log N)^2}
\]

(up to constants / zero-set weights), **not** \(O((\log\log N)^2)\). That prediction would still be more than strong enough to obtain

\[
E_2(N)=E_1(N)+O\!\left(\frac{N}{(\log N)^2}\right)
=O\!\left(\frac{N}{\log N}\right)
\]

if the previously desired/available first-moment estimate \(E_1(N)=O(N/\log N)\) is granted. But the pair-correlation estimate is precisely the missing theorem.

## 1. Exact expansion

Write

\[
Z_p:=\{0\le r<p:p\mid b_r\}
\]

and

\[
K_6(n)=\#\left\{p\text{ prime}:\frac n7<p\le\frac n6,\ n-6p\in Z_p\right\}.
\]

For every \(p\) and \(r\in Z_p\), put

\[
n(p,r):=6p+r.
\]

Because \(0\le r<p\), one has

\[
6p\le n(p,r)<7p,
\]

hence automatically

\[
\frac{n(p,r)}7<p\le \frac{n(p,r)}6.
\]

Therefore the first moment has the exact representation

\[
\boxed{
E_1(N)
=\sum_{p\le N/6}
\#\{r\in Z_p:6p+r\le N\}.
}
\]

Now expand the square:

\[
\begin{aligned}
E_2(N)
&=\sum_{n\le N}K_6(n)^2\\
&=\sum_{p_1,p_2}\ \sum_{r_1\in Z_{p_1}}\sum_{r_2\in Z_{p_2}}
\mathbf 1_{\,6p_1+r_1=6p_2+r_2\le N}.
\end{aligned}
\]

If \(p_1=p_2\), equality forces \(r_1=r_2\), so the diagonal is exactly \(E_1(N)\).

For \(p_1<p_2\), equality is equivalent to

\[
\boxed{r_1-r_2=6(p_2-p_1).}
\]

Hence, defining the half-off-diagonal correlation

\[
\mathcal C_6(N)
:=
\sum_{\substack{p_1<p_2\\p_i\text{ prime}}}
\ \sum_{\substack{r_1\in Z_{p_1},\ r_2\in Z_{p_2}\\
 r_1-r_2=6(p_2-p_1)\\
 6p_2+r_2\le N}}
1,
\]

we obtain the exact identity

\[
\boxed{E_2(N)=E_1(N)+2\mathcal C_6(N).}
\]

This is the cleanest rigorous formulation of the problem.

Equivalently, eliminate \(r_1\). For fixed \((p_2,r_2)\), put

\[
n=6p_2+r_2.
\]

Then

\[
\boxed{
\mathcal C_6(N)
=
\sum_{\substack{p_2\le N/6\\p_2\text{ prime}}}
\ \sum_{\substack{r_2\in Z_{p_2}\\6p_2+r_2\le N}}
\ \sum_{\substack{n/7<p_1<p_2\\p_1\text{ prime}}}
\mathbf 1_{Z_{p_1}}\bigl(n-6p_1\bigr).
}
\]

Since \(p_1>n/7\), the integer

\[
n-6p_1=r_2+6(p_2-p_1)
\]

already lies in \([0,p_1)\). Thus there is no need to reduce it modulo \(p_1\); the congruence form

\[
(n-6p_1)\bmod p_1=(r_2+6p_2)\bmod p_1
\]

is true, but it does not create any averaging.

A useful automatic consequence is

\[
6(p_2-p_1)=r_1-r_2< p_1,
\]

so every collision has

\[
\boxed{\frac67p_2<p_1<p_2.}
\]

Thus the two primes really are in a fixed multiplicative short interval.

## 2. Where the proposed proof fails

For a fixed \((p_2,r_2)\), the inner sum is

\[
A(p_2,r_2)
:=
\sum_{\substack{(6p_2+r_2)/7<p_1<p_2\\p_1\text{ prime}}}
\mathbf 1_{Z_{p_1}}\!\left(r_2+6(p_2-p_1)\right).
\]

The proposed argument replaces each indicator by the density

\[
\frac{|Z_{p_1}|}{p_1}.
\]

That is a plausible **random-set heuristic**, but it is not an inequality. The point being tested is a very special moving point depending on both primes:

\[
r_2+6(p_2-p_1).
\]

Nothing about the cardinality \(|Z_{p_1}|\) says that this moving point hits \(Z_{p_1}\) with frequency \(|Z_{p_1}|/p_1\).

In fact, this is exactly what the second moment is measuring: whether the sets

\[
6p+Z_p\subset[6p,7p)
\]

pile up on the same integers \(n\). A first moment controls total mass

\[
\sum_p|6p+Z_p|,
\]

but a second moment controls the **multiplicity of overlaps** of these translated sets. Total mass alone cannot control overlap multiplicity.

This is consistent with the current project-level warning in `problems/3.2/AVENUES.md`: the existing deterministic pair caps / reflection-type set constraints do not by themselves yield the required energy compression; genuinely Apéry-specific correlation information is needed. The present q=6 calculation is a simpler manifestation of the same logical issue.

## 3. A concrete abstract counterexample to the cardinality argument

This does **not** claim to model the actual Apéry zero sets. It only proves that cardinality / first-moment information cannot justify the desired second-moment conclusion.

Fix a large integer \(n_0\). For every prime

\[
\frac{n_0}{7}<p\le\frac{n_0}{6},
\]

define an abstract singleton zero set

\[
Z_p^*:=\{n_0-6p\},
\]

and take \(Z_p^*=\varnothing\) for all other primes.

The window condition guarantees

\[
0\le n_0-6p<p,
\]

so these are legitimate subsets of \([0,p)\), and every set has cardinality at most \(1\).

But all translated sets meet at exactly the same integer:

\[
6p+Z_p^*=\{n_0\}.
\]

Consequently

\[
K_6^*(n_0)
=\pi(n_0/6)-\pi(n_0/7)
\asymp \frac{n_0}{\log n_0}
\]

by the prime number theorem, while \(K_6^*(n)=0\) otherwise. Therefore

\[
E_1^*(n_0)\asymp \frac{n_0}{\log n_0},
\qquad
E_2^*(n_0)\asymp \frac{n_0^2}{(\log n_0)^2}.
\]

Moreover

\[
\sum_p\frac{|Z_p^*|}{p}
\ll \frac1{\log n_0},
\]

which is even smaller than the reciprocal-mass hypothesis used in the proposed calculation.

So even

- \(|Z_p|\le1\),
- a first moment of order \(N/\log N\), and
- tiny \(\sum |Z_p|/p\)

are fully compatible, for arbitrary sets, with a second moment of order \(N^2/\log^2N\). The missing ingredient must constrain the **relative positions** of the actual Apéry zero sets across different primes.

## 4. Correct independence heuristic

Suppose heuristically that, after \(p_1,p_2,r_2\) are fixed, the moving point

\[
r_2+6(p_2-p_1)
\]

behaves like a random point of \([0,p_1)\). Then

\[
\mathbb E\,
\mathbf 1_{Z_{p_1}}\bigl(r_2+6(p_2-p_1)\bigr)
\approx \frac{|Z_{p_1}|}{p_1}.
\]

Thus the heuristic inner mean is

\[
\mathbb E A(p_2,r_2)
\approx
\sum_{\substack{(6p_2+r_2)/7<p_1<p_2\\p_1\text{ prime}}}
\frac{|Z_{p_1}|}{p_1}.
\]

If \(|Z_p|\asymp1\), then, replacing the exact lower endpoint by a fixed-ratio endpoint for scale estimation,

\[
\sum_{(6/7)p_2<p_1<p_2}\frac1{p_1}
\sim
\log\log p_2-\log\log(6p_2/7)
\sim
\frac{\log(7/6)}{\log p_2}.
\]

Hence

\[
\boxed{\mathbb E A(p_2,r_2)\asymp \frac1{\log p_2},}
\]

not \(1/p_2\).

Summing over \(p_2\) gives

\[
\sum_{p_2\le N/6}\frac1{\log p_2}
\asymp \frac{N}{(\log N)^2}.
\]

So the natural bounded-zero-set random model predicts

\[
\boxed{\mathcal C_6(N)\asymp \frac{N}{(\log N)^2}.}
\]

This is the correct scale behind the hoped-for second-moment saving.

A quick way to see the same correction is: a q=6 window contains \(\asymp p/\log p\) candidate primes, not \(O(1)\) candidates. Each candidate has zero-density about \(1/p\) when \(|Z_p|\asymp1\). Their product is therefore \(\asymp1/\log p\).

## 5. The sharp sufficient theorem to prove

Let

\[
z_p:=|Z_p|.
\]

For a dyadic scale \(X\), define

\[
\mathcal C_6(X,2X)
:=
\sum_{\substack{X<p_2\le2X\\p_2\text{ prime}}}
\sum_{r_2\in Z_{p_2}}
\sum_{\substack{(6p_2+r_2)/7<p_1<p_2\\p_1\text{ prime}}}
\mathbf 1_{Z_{p_1}}\bigl(r_2+6(p_2-p_1)\bigr).
\]

Ignoring only the harmless top boundary \(6p_2+r_2\le N\), the exact off-diagonal is a dyadic sum of these quantities.

A clean **averaged cross-prime transversality theorem** would be

\[
\boxed{
\mathcal C_6(X,2X)
\ll
\sum_{\substack{X<p_2\le2X}} z_{p_2}
\sum_{\substack{(6/7)p_2<p_1<p_2}}
\frac{z_{p_1}}{p_1}.
}
\tag{PC6}
\]

This says that, in aggregate, the actual shifted intersections are no larger than a constant multiple of the random-density main term. It is much more realistic than a pointwise estimate, since a pointwise bound by a quantity \(<1\) cannot hold when an actual collision occurs.

Now suppose the already-needed first-moment input gives, on dyadic prime blocks,

\[
\sum_{X<p\le2X}z_p\ll\frac{X}{\log X}.
\tag{FM}
\]

Then for \(p_1\asymp X\),

\[
\begin{aligned}
\sum_{X<p_2\le2X} z_{p_2}
\sum_{(6/7)p_2<p_1<p_2}\frac{z_{p_1}}{p_1}
&\ll
\frac1X
\left(\sum_{cX<p\le2X}z_p\right)^2\\
&\ll \frac1X\left(\frac{X}{\log X}\right)^2\\
&\ll\frac{X}{(\log X)^2},
\end{aligned}
\]

for a fixed \(c>0\) (say \(c=3/7\) after harmless enlargement of the block).

Therefore `(PC6)` + `(FM)` would imply

\[
\mathcal C_6(X,2X)\ll\frac{X}{(\log X)^2}.
\]

Dyadic summation then gives

\[
\boxed{
\mathcal C_6(N)\ll\frac{N}{(\log N)^2},
}
\]

and hence

\[
\boxed{
E_2(N)=E_1(N)+O\!\left(\frac{N}{(\log N)^2}\right).
}
\]

In particular, if \(E_1(N)=O(N/\log N)\), then

\[
\boxed{E_2(N)=O(N/\log N).}
\]

So this is the precise theorem-shaped missing input: **an averaged shifted intersection estimate for the family \(Z_p\) across distinct primes.**

## 6. Project-specific Lucas reformulation

For the core q=6 primes for which \(b_6\) is a p-unit, Lucas gives

\[
b_n\equiv b_6\,b_{n-6p}\pmod p
\qquad
(n=6p+r,\ 0\le r<p).
\]

Thus

\[
p\mid b_{n-6p}
\quad\Longleftrightarrow\quad
p\mid b_n.
\]

Up to the fixed exceptional primes dividing \(b_6\), one can therefore rewrite

\[
\boxed{
K_6(n)
=\#\left\{p\in(n/7,n/6]\text{ prime}:p\mid b_n\right\}.
}
\]

This makes the second-moment issue especially transparent: it asks how often a single Apéry number \(b_n\) has **several distinct prime divisors in the narrow size range \(p\asymp n/6\)**.

That is not an independent-residue question for free; all those prime events are divisibility events for the same integer \(b_n\). The Lucas identity is an exact reformulation, but it does not itself prevent clustering of such large prime divisors.

A crude size argument only gives

\[
K_6(n)\ll\frac{n}{\log n}
\]

because \(\log b_n=O(n)\), which is far too weak for the desired second moment. Likewise, from \(E_1(N)=O(N/\log N)\) alone one gets only the crude inequality

\[
E_2(N)\le \bigl(\max_{n\le N}K_6(n)\bigr)E_1(N)
\ll \frac{N^2}{(\log N)^2},
\]

not \(O(N/\log N)\).

## 7. Bottom line for Q3558

The exact reduction is

\[
\boxed{
E_2(N)=E_1(N)+2\mathcal C_6(N),
}
\]

where

\[
\boxed{
\mathcal C_6(N)=
\sum_{p_2,r_2}
\sum_{(6p_2+r_2)/7<p_1<p_2}
\mathbf 1_{Z_{p_1}}\bigl(r_2+6(p_2-p_1)\bigr)
}
\]

with the obvious primality, zero-set, and \(n\le N\) restrictions.

What is **not** justified is replacing the inner indicator by \(|Z_{p_1}|/p_1\). That replacement is the desired cross-prime pair-correlation theorem, not a consequence of the first moment.

The corrected random prediction, for bounded-average \(|Z_p|\), is

\[
\boxed{E_{2,\mathrm{off}}(N)\asymp N/(\log N)^2,}
\]

not \(O((\log\log N)^2)\).

Therefore the proposed proof does **not** currently establish

\[
E_2(N)=O(N/\log N).
\]

But it does identify an excellent next target: prove an averaged `(PC6)`-type shifted-intersection bound. Combined with the q=6 first-moment estimate, that would rigorously close the second moment, in fact with a full extra factor of \(1/\log N\) on the off-diagonal.
