# Q846: Far-region GH1 dependency audit

## Executive verdict

GH1 does **not** follow from the currently available deterministic LGTQ-style facts plus an ambient prime-pair sieve. The obstruction is not a missing logarithmic optimization; it is a missing Apéry-specific cancellation/carrier estimate. The deterministic ingredients control multiplicity of representations after fixing the arithmetic packet, but GH1 requires control of the positive weighted excess before cancellation is lost.

The first failing point is the transition

```
large weighted positive excess in one far-region column
        =>
small number of admissible affine prime packets
```

which is not supplied by injectivity, pruning, or spacing alone.

## Parameter audit

For

```
1/120 < eta < 2/105,
```

the exponent bookkeeping in GH1 gives the following scale hierarchy:

```
L       = X^eta
D       = X^(1/2-eta)
G       = X^(1/2-2eta)
Y       = X^(1/2+eta)
U       = X^(1/2-eta)
B       = X^(1-2eta)
Lambda  = X^eta
```

and the subtraction threshold is

```
(B+kappa)/(2U).
```

At exponent level this is

```
(1-2eta+kappa)/(1-2eta)
```

relative to the U-normalization. The positive contribution must therefore lose more than the residual linear-in-B carrier count in order for GH1 to close.

## Deterministic facts audit

The proposed ingredients are:

1. signed-lift injectivity;
2. uniqueness of the partner characteristic for fixed `(m,p,g,sign)`;
3. high-Kummer pruning;
4. quotient/folded spacing.

Each is valid as a local restriction, but none controls the weighted positive mass.

### Signed-lift injectivity

This gives

```
(fixed lift data) -> at most one arithmetic realization.
```

It removes duplicate counting but does not reduce the number of different lifts generated by a physical high-load column.

### Partner characteristic uniqueness

For fixed

```
(m,p,g,sign),
```

the partner characteristic is unique. This gives a multiplicity-one statement after the full characteristic is fixed. It does not imply that the number of characteristics attached to a column is small.

### High-Kummer pruning

This removes forbidden high-adic configurations. It improves the admissible support but does not create cancellation among the remaining positive weights.

### Quotient/folded spacing

Spacing bounds collisions of folded indices. It does not bound the number of separated positive carriers inside the far region.

Therefore the four facts give support sparsity, not a weighted excess estimate.

## Positive excess calculation

The GH1 positive term has the schematic form

```
Sum_g Sum_m W(m,g) * 1_{admissible(m,g)}.
```

The ambient sieve ceiling only gives

```
X^o(1)(1 + X^2 Lambda^5).
```

Substituting

```
Lambda = X^eta
```

gives

```
X^o(1)(1 + X^(2+5eta)).
```

The second term dominates in the range of eta under consideration.

The subtraction term has scale

```
X^((B+kappa)/(2U))
```

and the existing deterministic reductions do not force the positive part below the same exponent. Thus the comparison fails at the positive carrier count.

## First deficient configuration

The first bad configuration is:

```
many separated g-values,
all surviving the selector and Kummer masks,
with distinct folded carriers but the same physical far-region column.
```

None of the available facts forbids this. Injectivity actually confirms that these are distinct legal configurations rather than duplicates.

Hence the failure occurs before any prime-pair estimate: the ambient sieve is being applied to a support that has not yet been compressed enough.

## Do proposed repairs give a saving?

### Summing over g before taking the positive part

No proved saving follows. The issue is that positivity removes cancellation:

```
Sum_g |contribution_g|
```

cannot be replaced by

```
|Sum_g contribution_g|
```

without an Apéry sign/cancellation theorem.

### Large sieve inequality

No direct closure. A large sieve bounds averaged correlations over a family of characters/residue classes. GH1 requires a saving in the physical Apéry carrier family. No equidistribution statement connecting these families is available.

### Divisor bound from

```
c_q q = c_p p ± g
```

No sufficient saving. The divisor estimate controls the number of algebraic decompositions of a fixed relation. It does not control the number of relations generated as `(p,q,g)` vary over the whole far-region shell.

## Weakest sufficient missing lemma

A sufficient bridge is the following Apéry-specific carrier estimate.

> **Far-region Apéry carrier cancellation lemma.** For every admissible far-region physical column `m`, the total positive weighted contribution after signed lifting, Kummer pruning, quotient folding, and selector masking satisfies
>
> ```
> Sum_g W(m,g) 1_{admissible(m,g)}
>     <= X^o(1) * X^(2+5eta-delta)
> ```
>
> for some fixed `delta>0` in the full eta range.

Equivalently, one may replace this by a weaker global form:

```
number of surviving weighted carriers
    <= ambient ceiling - X^delta saving.
```

This is exactly the missing compression from arithmetic packet counting to Apéry-column counting.

## Final dependency status

```
signed-lift injectivity              YES (local only)
partner uniqueness                   YES (local only)
high-Kummer pruning                  YES (support reduction)
quotient/folded spacing              YES (collision reduction)
ambient prime-pair sieve             YES (ceiling only)

GH1 closure                          NO
```

The missing ingredient is not another generic sieve. It is an Apéry-specific cancellation or carrier estimate that creates a power saving in the weighted positive excess.
