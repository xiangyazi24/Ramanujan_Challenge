# p-adic L-functions and Iwasawa theory for Apéry AFP

## Executive conclusion

The Iwasawa analogy is suggestive, but the proposed route does not directly solve AFP. The main issue is that AFP is a statement about the **zero locus of the unit-root function over finite-order Kummer characters**, whereas classical p-adic L-functions interpolate **special values of motivic L-functions**. These are related objects but not identical.

The missing implication is:

```
overconvergent unit-root F-crystal
        =>
Iwasawa function with bounded lambda invariant
        =>
O(1) nonordinary characters
```

The first arrow is not a general Katz theorem.

## (A) Does a Katz p-adic L-function exist for the Apéry crystal?

For CM motives, modular forms, and certain automorphic motives, Katz-type constructions produce p-adic L-functions because there is an algebraic family of critical L-values and an Euler system/interpolation theory.

The Apéry motive is different. The existence of an overconvergent F-crystal gives a rigid analytic variation of Frobenius eigenvalues, but this does not automatically produce a measure on Z_p^×.

The unit root function

```
r |-> alpha(r)
```

is a character-space object. A Katz p-adic L-function is usually an interpolation of quantities such as

```
L(M, chi, s)
```

not directly of Frobenius unit roots.

Therefore there is no known general Katz p-adic L-function whose zeros exactly encode

```
b_r = 0 mod p.
```

## (B) Lambda invariant and AFP

Even if an interpolation function L_p existed, its Weierstrass degree would measure zeros of that p-adic analytic function on weight space.

AFP asks:

```
#{finite order characters chi of conductor p : alpha(chi) mod p = 0}
```

This is a local ordinarity condition, not the vanishing of a complex or p-adic L-value.

The analogy

```
lambda(L_p) = number of bad characters
```

is therefore false in general.

Lambda invariants count zeros of an interpolation function; they do not count slope jumps of a Frobenius crystal.

## (C) Why the Mahler obstruction remains

The naive Mahler expansion of

```
r -> b_r mod p
```

has large Weierstrass degree because the mod-p sequence genuinely has high oscillation.

Replacing b_r by alpha(r) may improve analytic behavior, but there is no theorem saying that the unit-root function has bounded Weierstrass degree independent of p.

The correct expectation is:

```
alpha(r) is analytic on weight space
```

but the number of zeros in a residue disk can still grow unless additional geometric constraints are available.

Analyticity alone gives no uniform O(1) bound.

## (D) The elliptic curve analogy

The analogy with elliptic curves is only partial.

For a fixed elliptic curve, quadratic twisting satisfies approximately

```
a_p(E twisted by chi) = chi(d) a_p(E)
```

so ordinarity is unchanged by the character.

The Apéry Kummer twist is fundamentally different:

```
C tensor chi^r
```

changes the Frobenius operator itself. The unit root is not a scalar multiple of one fixed unit.

Thus character variation creates genuine slope variation.

This is closer to a family of F-crystals over weight space than to the classical quadratic twist family.

## (E) Katz 1973 theorem and modular interpretation

The Apéry differential equation has connections with modular forms (including weight-4 modular phenomena), but this does not mean Katz's theorem applies directly.

Katz's unit-root results concern ordinary loci of modular schemes and modular forms where there is an established ordinary projector and p-adic modular family.

To apply the theorem directly one would need:

1. an identification of the Apéry crystal with a modular Galois representation;
2. a Hida/Katz family containing the Kummer twists;
3. a proof that the resulting weight variable is exactly the character variable r.

This identification is not currently available in the needed form.

## (F) What framework would actually prove AFP?

The closest analogue is not Iwasawa lambda theory but a slope-variation theorem for overconvergent F-isocrystals:

```
Apéry overconvergent F-crystal
        |
        v
weight-space rigid analytic family
        |
        v
Newton polygon variation theorem
        |
        v
uniform bound on nonordinary characters
```

The required theorem would be a character-direction version of Wan's slope theory:

```
For a fixed overconvergent hypergeometric F-crystal,
nonordinary finite-order characters have bounded complexity.
```

No theorem of this exact strength is known.

## Final assessment

The Iwasawa route gives a useful reformulation:

- overconvergence suggests alpha(r) should be rigid analytic;
- weight-space methods suggest studying zeros on character space;
- Weierstrass preparation is the correct local language.

However, AFP does not reduce to proving

```
lambda(L_p)=O(1).
```

The true missing ingredient is a **uniform bound on the zero/slope locus of the Apéry unit-root family in character space**. This is closer to a p-adic monodromy/rigidity theorem than to classical Iwasawa theory.
