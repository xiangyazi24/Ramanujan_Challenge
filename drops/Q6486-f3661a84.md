## 1. Third-order complex recurrence uniqueness

**Audit result: correct.**

The production recurrence is homogeneous:

```lean
def ZudilinSatisfiesRecC27 (u : ℕ → ℂ) : Prop :=
  ∀ k : ℕ,
    (ctAlpha27 k : ℂ) * u (k + 3)
      - (ctBeta27 k : ℂ) * u (k + 2)
      + (ctGamma27 k : ℂ) * u (k + 1)
      - (ctDelta27 k : ℂ) * u k = 0
```

The uniqueness theorem has exactly the required shape:

```lean
#check ZudilinSatisfiesRecC27.eq_of_initial
-- {u v : ℕ → ℂ}
-- (hu : ZudilinSatisfiesRecC27 u)
-- (hv : ZudilinSatisfiesRecC27 v)
-- (h0 : u 0 = v 0) (h1 : u 1 = v 1) (h2 : u 2 = v 2) : u = v
```

At the `k + 3` induction step, the proof rewrites the three lower `u` values in `hu k` to the corresponding `v` values, subtracts `hv k`, and obtains equality after cancelling the common leading coefficient. Rewriting only `hu k`, rather than both recurrence equations, is intentional and correct.

The nonzero coefficient proof is independent of uniqueness:

```lean
ctAlpha27 k = 2 * zudilinA (k + 2)
```

and `zudilinA_pos k` already states positivity at index `k + 2`. Thus

```lean
(ctAlpha27 k : ℂ) ≠ 0
```

is valid.

### Local mistakes to guard against

- Do not call `zudilinA_pos (k + 2)` here. Its argument is already shifted internally; doing so proves positivity at the wrong index.
- Preserve the exact coefficient/sign order `+α uₖ₊₃ - β uₖ₊₂ + γ uₖ₊₁ - δ uₖ` on both sequences.
- Keep the recurrence homogeneous. A uniqueness theorem written against the divided recurrence would unnecessarily reintroduce denominator and cast obligations.
- If this proof is refactored, test that cancellation is performed with `ctAlpha27 k`, not one of the universal polynomial coefficients at an incorrectly shifted complex argument.

## 2. Casting the rational source recurrence to `ℂ`

**Audit result: correct and coefficient-preserving.**

The source recurrence is first converted to the exact rational homogeneous form by

```lean
zudilinSatisfiesRec_iff_ct27
```

and only then cast:

```lean
theorem ZudilinSatisfiesRec.castComplex27
    {u : ℕ → ℚ} (hu : ZudilinSatisfiesRec u) :
    ZudilinSatisfiesRecC27 (fun n => (u n : ℂ)) := by
  intro k
  have hq := (zudilinSatisfiesRec_iff_ct27 u).1 hu k
  have hc := congrArg (fun q : ℚ => (q : ℂ)) hq
  push_cast at hc
  exact hc
```

This is the right coercion boundary. `push_cast` transports addition, subtraction, multiplication, zero, and the rational coefficients without changing their values. The resulting theorem was printed as

```text
ZudilinSatisfiesRec.castComplex27 {u : ℕ → ℚ}
  (hu : ZudilinSatisfiesRec u) :
  ZudilinSatisfiesRecC27 fun n ↦ ↑(u n)
```

The equivalence `zudilinSatisfiesRec_iff_ct27` clears the original rational denominator using `zudilinA_pos`; it does not use any Barnes equality or asymptotic theorem.

### Local mistakes to guard against

- Cast the homogeneous identity, not the original recurrence with division.
- After `congrArg`, inspect the goal after `push_cast`; the coefficients must be exactly
  `(ctAlpha27 k : ℂ)`, `(ctBeta27 k : ℂ)`, `(ctGamma27 k : ℂ)`, and `(ctDelta27 k : ℂ)`.
- Do not silently replace these values by `ctAlphaC27`, etc., unless the corresponding `*_nat27` simp theorem is explicitly applied with the correct `k + 2` argument.

## 3. Exact source/Barnes equality

**Audit result: correct and non-circular.**

The two sequences satisfy the same named predicate:

```lean

#check zudilinBarnesErrorIntegral_recC27
-- ZudilinSatisfiesRecC27 zudilinBarnesErrorIntegral27
```

The Barnes recurrence is not assumed. `Problem27BarnesRecurrence.lean` proves it from the common-half-line contour integrals and the telescoper. The normalization factor `1 / (2 * π)` is common to all four recurrence terms and is factored out explicitly, so the coefficients are unchanged.

The initial values also match exactly:

```text

zudilinBarnesErrorIntegral27 1 = 7 * zudilinL27 - 20
zudilinBarnesErrorIntegral27 2 = 163 * zudilinL27 - 7425 / 16
```

The denominator in the third value is **16**, not 8. The rational source initial value and the directly evaluated Barnes initial value use the same constant.

The final equality theorem has no hypotheses:

```lean
#check zudilinCombinedError_eq_barnes27
-- (n : ℕ) :
--   ↑(zudilinCombinedError n) = zudilinBarnesErrorIntegral27 n
```

Its orientation is correct. The recurrence uniqueness theorem first proves function equality


using initial equalities of the form

```lean

```

which indeed produce `source_value = barnes_value`. It then rewrites the real source error through


before using the function equality.
