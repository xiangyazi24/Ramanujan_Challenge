# Apéry atom tail and the order of the Frobenius unit eigenvalue

The proposed route identifies an important object, but the final implication is not currently available. The obstruction is that the relevant Frobenius eigenvalue is not a fixed integer whose order can be attacked by Artin's primitive root conjecture.

## 1. The period/order implication is correct in principle

For the projective orbit

```text
(b_{r-1}:b_r) in P^1(F_p)
```

a genuine lower bound on the order of the semisimple part of the transfer matrix would give a long orbit. A period bound of the form

```text
ord(alpha) >= p^(1-epsilon)
```

would indeed force few returns to the zero state and would improve the current `|Z_p| = O(p^(2/3))` bound.

So the dynamical idea is sound.

## 2. The Artin analogy breaks at the key point

For an elliptic curve or modular form, the Frobenius eigenvalues satisfy

```text
alpha_p + beta_p = a_p,
alpha_p beta_p = chi(p) p^(k-1).
```

They live naturally in a quadratic extension and are not elements of F_p^*. The expression

```text
alpha = a_p(f) / p^(3/2) mod p
```

is a heuristic normalization, not an actual element of F_p^* with a well-defined multiplicative order.

The ordinary/nonordinary distinction controls p-adic valuations of crystalline eigenvalues, but it does not produce a reduction modulo p of a unit root whose order is the order of `a_p(f)`.

In particular:

```text
unit root in D_cris
!= a_p(f) mod p
```

and the proposed reduction to Artin's conjecture is not valid.

## 3. Even an Artin-type statement would be much stronger than known results

Suppose one had a genuine sequence

```text
u_p in F_p^*
```

attached to the modular form. A theorem saying

```text
ord_p(u_p) >= p^(1-epsilon)
```

for almost all p would be a very strong new primitive-root theorem for Frobenius data. There is no known theorem of this strength for the Apéry modular form

```text
eta(2z)^4 eta(4z)^4.
```

Chebotarev controls splitting conditions in fixed extensions. It does not control the order of Frobenius elements in the varying groups F_p^*.

## 4. What remains potentially useful

The correct replacement is probably not an order bound but a monodromy/large-sieve statement.

The family of reductions gives a compatible Galois representation

```text
rho_l : Gal(Qbar/Q) -> GL_2(Z_l).
```

A successful argument would likely prove that the Frobenius conjugacy classes cannot repeatedly land in the exceptional subsets corresponding to short projective orbits.

The target statement is closer to:

```text
#{p <= X : projective Frobenius orbit is short} = o(pi(X))
```

rather than a lower bound for one multiplicative order.

## 5. Relation to the current Apéry zero-set bounds

The existing bound

```text
|Z_p| = O(p^(2/3))
```

comes from polynomial gap estimates and does not use Frobenius randomness. A true long-orbit theorem would improve this dramatically, but it would require new arithmetic input.

The most realistic formulation is:

```text
short projective orbit => Frobenius lies in a thin algebraic subset
```

followed by a Chebotarev/large-sieve estimate for that thin set.

## Conclusion

The eigenvalue-order idea identifies the right dynamical quantity, but the proposed identification

```text
order of unit eigenvalue = order of a_p(f) mod p
```

is the missing bridge and is generally false. There is currently no Artin-type lower bound available for this Apéry Frobenius sequence. A viable route would need a thin-Frobenius or monodromy argument rather than a primitive-root argument.
