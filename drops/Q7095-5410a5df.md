# Quadruple-zero resultant inequality for Apéry zeros

Let
\[
Z(p)=\{0\le r<p:b_r\equiv0\pmod p\},\qquad z(p)=|Z(p)|.
\]
Fix a block length \(H\). Partition \([0,p-1]\) into intervals of length \(H\). The key point is that four zeros in one block force a pair of resultant divisibilities, but the resulting bound is on the **number of quadruples**, not directly on \(z(p)\). The conversion from quadruples back to \(z(p)\) costs an optimization factor.

## 1. Quadruple counting inside blocks

Write a block as \(I=[a,a+H)\). If it contains zeros
\[
x_0<x_1<x_2<x_3,
\]
then the gaps
\[
h_1=x_1-x_0,\quad h_2=x_2-x_1,\quad h_3=x_3-x_2
\]
satisfy
\[
h_i\ge2,\qquad h_1+h_2+h_3\le H.
\]
The no-consecutive-zero theorem gives the lower bound \(h_i\ge2\).

For each admissible triple define the count
\[
T_{h_1,h_2,h_3}(p)=\#\{x:N_{h_1}(x)=N_{h_2}(x+h_1)=N_{h_3}(x+h_1+h_2)=0\pmod p\}.
\]
Then the number of ordered zero quadruples in blocks is bounded by
\[
Q_4(p;H)\le \sum_{h_1+h_2+h_3\le H}T_{h_1,h_2,h_3}(p).
\]

If a block contains \(m\) zeros, it contributes \(\binom m4\) quadruples. Hence
\[
\sum_I \binom{|Z(p)\cap I|}{4}\le Q_4(p;H).
\]
Using \(\binom m4\gg m^4\) for \(m\ge4\), this gives control only of the fourth moment of block occupancies.

## 2. Grouping by gap triples

For a fixed triple, the start \(x\) is a common root of
\[
S_{h_1,h_2}=\operatorname{Res}_X(N_{h_1}(X),N_{h_2}(X+h_1))
\]
and
\[
S_{h_2,h_3}=\operatorname{Res}_X(N_{h_2}(X),N_{h_3}(X+h_2)).
\]

The important correction is that these two resultants do **not** come from two independent polynomial systems: they share only the middle polynomial \(N_{h_2}\). Therefore the correct invariant is not a generic gcd of unrelated integers, but the prime divisors of the two-resultant ideal. Equivalently one needs
\[
G(h_1,h_2,h_3)=\gcd(S_{h_1,h_2},S_{h_2,h_3})
\]
only after removing structural content and zero-resultant cases.

For generic primes (leading coefficients units and no degree drops), if there are \(t\) distinct starts \(x\), then the reductions modulo \(p\) give \(t\) distinct common roots. Thus
\[
t\le \deg \gcd(\overline{S}_{h_1,h_2},\overline{S}_{h_2,h_3}),
\]
and the common-root contribution forces
\[
p^t\mid \operatorname{Res}(S_{h_1,h_2},S_{h_2,h_3})
\]
in the appropriate determinant sense. More invariantly, if \(R_{h_1,h_2,h_3}\) denotes the multivariate Sylvester/Macaulay determinant measuring common roots of the two resultants, then
\[
t\log p\le v_p(R_{h_1,h_2,h_3})\log p.
\]
A plain \(\gcd(S_{h_1,h_2},S_{h_2,h_3})\) records necessary but not always sufficient information; the determinant of the pair is the clean invariant.

## 3. Summing over primes

Summing over generic primes \(X<p\le2X\), and using \(\log p\asymp\log X\), gives
\[
\sum_{X<p\le2X}^{\rm gen}T_{h_1,h_2,h_3}(p)
\ll
\frac{1}{\log X}
\log |R_{h_1,h_2,h_3}|.
\]
Consequently
\[
\boxed{
\sum_{X<p\le2X}^{\rm gen}Q_4(p;H)
\ll
\frac1{\log X}
\sum_{h_1+h_2+h_3\le H}
\log |R_{h_1,h_2,h_3}|
}
\]
up to the excluded exceptional primes coming from leading coefficients, degree drops, and identically vanishing determinants.

If one insists on pairwise gcd notation, the weaker necessary bound is
\[
\sum_{X<p\le2X}^{\rm gen}Q_4(p;H)
\ll
\frac1{\log X}
\sum_{h_1+h_2+h_3\le H}
\log\gcd(S_{h_1,h_2},S_{h_2,h_3}),
\]
but the Macaulay determinant is the correct invariant.

## 4. Boundary loss and recovering \(z(p)\)

Let the blocks be \(B\asymp p/H\). A distribution with \(z(p)\) zeros and no block containing too many zeros satisfies
\[
z(p)\ll B+H^{3/4}Q_4(p;H)^{1/4}
\]
by the fourth-moment estimate. Summing gives
\[
\sum_{X<p\le2X}z(p)
\ll
\frac{X}{\log X}\frac{X}{H}
+
H^{3/4}
\left(
\sum_{X<p\le2X}Q_4(p;H)\right)^{1/4}
\left(\frac{X}{\log X}\right)^{3/4}.
\]
The first term is the boundary/block term:
\[
\asymp \frac{X^2}{H\log X}.
\]
The second is the quadruple term.

Therefore the strongest direct consequence is
\[
\boxed{
\sum_{X<p\le2X}^{\rm gen}z(p)
\ll
\frac{X^2}{H\log X}
+
H^{3/4}
\left(
\frac1{\log X}
\sum_{h_1+h_2+h_3\le H}
\log |R_{h_1,h_2,h_3}|
\right)^{1/4}
\left(\frac{X}{\log X}\right)^{3/4}
}
\]
with the same formula using the gcd sum as a weaker version.

## 5. Does \(\sum\log\gcd=H^{3+o(1)}\) give \(X^{3/2+o(1)}\) at \(H=\sqrt X\)?

No. Substituting
\[
H=X^{1/2},\qquad \sum\log R=H^{3+o(1)}=X^{3/2+o(1)},
\]
the quadruple term becomes
\[
H^{3/4}\left(\frac{H^3}{\log X}\right)^{1/4}\left(\frac X{\log X}\right)^{3/4}
\]
which is
\[
X^{3/8}X^{3/8}X^{3/4+o(1)}=X^{3/2+o(1)}.
\]
So the exponent is indeed consistent, but only because the fourth-root loss exactly balances the determinant growth. It does **not** give a pointwise \(z(p)\ll p^{1/2}\) result; it gives a global average bound of order \(X^{3/2+o(1)}\).

## 6. Hidden issues that must be closed

1. **Zero resultants.** If \(S_{h_i,h_j}=0\) identically, \(\log\gcd\) is meaningless. Such triples must be classified separately. They correspond to structural common factors, not rare prime divisibility.

2. **Degree drops.** The argument requires generic primes where leading coefficients remain nonzero modulo \(p\). The excluded primes contribute an additional exceptional term.

3. **Shared middle polynomial.** The two resultants are correlated through \(N_{h_2}\). Treating them as independent random integers overcounts the information. The true object is the common-root determinant of the pair.

4. **Distinct starts.** The valuation argument requires distinct starts modulo \(p\). This is valid in the nonwrapping block range because all starts lie in an interval of length \(H<p\).

Thus the quadruple resultant method is viable as an average-density argument, but the exact invariant is a two-resultant common-root determinant (or saturation thereof), not automatically the naive gcd of two shifted resultants.
