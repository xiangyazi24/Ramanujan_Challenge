# P3.2 fixed-slice prescribed-row attack: the exact final gate

## Verdict

The requested pointwise theorem is **not proved by the presently available diagonal/G-function, Newton--Lucas, density-one, neighboring-row, or norm inputs**.

What can be proved is a sharp final-gate theorem.

Fix `q>=1` and put

```text
T_q(n)
 = #{p prime : n/(q+1)<p<=n/q and p|b_n}.
```

For fixed `q`, the desired assertion

```text
T_q(n)=o(n/log n)
```

is equivalent to

```text
log R_q(n)=o(n),

R_q(n)
 = product_{n/(q+1)<p<=n/q, p|b_n} p.
```

The exact direct conclusions are:

1. The Newton/selector coordinates have a **one-dimensional candidate line**. After an integral unimodular change of coordinates there is one selective scalar and one block divisible by every candidate prime. Consequently every zero-order polynomial norm is either a multiple of the original target content or a universally saturated slice carrier.

2. Combining neighboring indices makes the situation worse, not better. For every polylogarithmic window, every `2 x 2` determinant of the natural fixed-`q` selector vectors is divisible by all but polylogarithmically many primes in the entire `q`-slice. Any nonzero neighboring determinant gcd therefore has logarithmic height

   ```text
   >= n/(q(q+1))+o(n).
   ```

   This is independent of whether the central row is a target.

3. Stacking all Newton--Lucas coordinates over neighboring rows gives an outer-product matrix of rank one modulo every candidate prime. At a target the central scalar becomes zero, but the neighboring scalar is a unit by the no-consecutive-zero theorem, so the rank remains one. Thus a target causes **no additional determinantal corank** after the universal rank-one factor has been removed.

4. The Apéry companion determinant also does not carry a private prime. It is exactly the gap continuant and detects a second zero of the same prime. The Casoratian correction that forces a private prime reintroduces the full endpoint factor `b_r`, restoring linear exponential height.

5. The current quadratic first-Bockstein/Veronese norm fails at the actual three-hit row `n=321`: before primitive normalization it retains only the arbitrarily chosen base prime `211`; after primitive normalization it is a unit at all three marked primes `179,193,211`.

6. The polylogarithmic exceptional-set theorem does not exclude a prescribed row. Reflection sends distinct private primes to distinct rows, and the codegree theorem shows that a polylogarithmic neighboring window can share only polylogarithmically many of the central row's primes.

7. There is nevertheless a concrete theorem which would finish the pointwise fixed-`q` problem. On the already-proved exceptional anchor set, it is enough to prove a very weak **different-characteristic centered covariance bound**. The same-prime diagonal part is already unconditionally below the required scale. The sole missing term is the off-diagonal correlation between a zero modulo `p` and an affine-shifted zero modulo a different prime `ell`.

For the pointwise theorem asked here, the exact missing bound is weaker by one logarithm than the global exceptional-anchor sum formulated in Q2668:

```text
|C_(q,delta)^exc(N)| = o_(q,delta)(N^2/(log N)^2).
```

No current same-characteristic carrier or norm estimates this quantity.

Thus the answer is not a proof of the requested all-`n` statement. It is an exact proof that the suggested zero-order neighboring/norm routes stop at a first-Bockstein and cross-characteristic covariance seam, together with the smallest sufficient theorem at that seam.

# 1. Exact fixed-`q` reduction

Let

```text
I_q(n)
 = {p prime : n/(q+1)<p<=n/q}.
```

For `p in I_q(n)`, write

```text
n=q*p+r,
0<=r<p.
```

Apéry--Lucas gives

```text
b_n = b_q*b_r (mod p).
```

The fixed integer `b_q` has only finitely many prime divisors. Hence, for fixed `q` and sufficiently large `n`, every `p in I_q(n)` is a `p`-unit on `b_q`, and

```text
p|b_n  <=>  p|b_r.
```

Put

```text
Z_p={0<=s<p:p|b_s}.
```

Then

```text
T_q(n)
 = #{p in I_q(n): n-q*p in Z_p}
```

for all sufficiently large `n`.

Every `p in I_q(n)` satisfies

```text
log p = log n+O_q(1).
```

Therefore

```text
T_q(n)*log(n/(q+1))
 <= log R_q(n)
 <= T_q(n)*log(n/q).
```

Consequently

```text
T_q(n)=o(n/log n)

<=>

log R_q(n)=o(n).
```

This is the exact pointwise height target.

# 2. The one-dimensional candidate line

Use the explicit fixed-`q` selector from Q2646. Put

```text
d=2*q+1,
H_q(n)=floor((n-q)/d),
F_q(n)=T_(n,H_q(n))(-1),
epsilon_q=(-1)^q.
```

The proved fixed-`q` congruence is

```text
F_q(n)=epsilon_q*b_r (mod p)
```

for every sufficiently large `p in I_q(n)`. Reflection has already been folded into this statement.

Together with Apéry--Lucas,

```text
(b_n,F_q(n))
 = b_r*(b_q,epsilon_q) (mod p).
```

Thus all candidate reductions lie on one fixed line.

Define the integral transverse coordinate

```text
U_q(n)=b_q*F_q(n)-epsilon_q*b_n.
```

Then

```text
p|U_q(n)
```

for **every** sufficiently large `p in I_q(n)`, whether or not `p` is a target.

Let

```text
Pi_q(n)=product_{p in I_q(n)} p.
```

After deleting a fixed `q`-dependent finite set,

```text
Pi_q(n)|U_q(n).
```

If `U_q(n)` is nonzero, the prime number theorem gives

```text
log|U_q(n)|
 >= theta(n/q)-theta(n/(q+1))+O_q(1)
 = n/(q(q+1))+o_q(n).
```

If `U_q(n)=0`, the selector gives no transverse coordinate at that row. Either outcome is useless for a sublinear-height carrier.

The coordinate change

```text
(b,F) -> (T,U)

T=F,
U=b_q*F-epsilon_q*b
```


Modulo a candidate prime the normal form is therefore

```text
T=epsilon_q*b_r,
U=0.
```

The target condition is exactly

```text
T=0.
```

The coordinate `U` is not a second target equation; it vanishes for the whole slice.

# 3. Exact polynomial-norm dichotomy

Let

```text
c_q(n)=gcd(b_n,F_q(n)).
```

The target radical divides `c_q(n)` up to the fixed exceptional primes.

Take any polynomial

```text
Phi(X,Y) in Z[X,Y]
```

which is supposed to vanish modulo every sufficiently large target prime by using only the zero-order pair `(b_n,F_q(n))`. Rewrite it in the unimodular coordinates:

```text
Phi(b,F)=Psi(T,U).
```

At a target both `T` and `U` are divisible by `p`. Therefore a fixed nonzero constant term would survive modulo every sufficiently large target prime. Hence a universally target-forced polynomial has

```text
Psi(0,0)=0,
```

and consequently

```text
Psi(T,U)=T*A(T,U)+U*B(T,U)
```

for integral polynomials `A,B`.

After characteristic-zero evaluation,

```text
Phi(b_n,F_q(n))
 = F_q(n)*A_n+U_q(n)*B_n.
```

This gives the exact dichotomy.

## 3.1 Selective part

Every term containing `T=F_q(n)` is divisible by the original common content `c_q(n)`. It does not create an integer smaller than the content to be bounded.

## 3.2 Transverse part

Every term containing `U_q(n)` is divisible by all candidate primes, targets and non-targets. If nonzero, it has positive linear logarithmic height.

There is no third zero-order coordinate.

For a homogeneous norm of degree `m`, the obstruction is quantitative. Since

```text
c_q(n)|b_n,
 c_q(n)|F_q(n),
```

one has

```text
c_q(n)^m | Phi(b_n,F_q(n)).
```

If the input coordinates have height `exp(C_q*n)` and the coefficient height of `Phi` is subexponential relative to its degree, then

```text
m*log c_q(n)
 <= log|Phi(b_n,F_q(n))|
 <= m*C_q*n+o(m*n).
```

After division by `m`, this is still only a linear bound. Raising the norm degree does not increase `p`-adic vanishing faster than algebraic degree.

Primitive normalization has the opposite failure. Replacing

```text
(b_n,F_q(n))
```

by

```text
(b_n/c_q(n),F_q(n)/c_q(n))
```

removes every target prime from the vector before the norm is taken.

Thus the raw/primitive dilemma is exact:

```text
raw norm       -> contains the unknown target content;
primitive norm -> deletes the forced target support.
```

# 4. Neighboring indices are universally saturated

The most natural neighboring determinant is

```text
D_h(n)
 = b_n*F_q(n+h)-b_(n+h)*F_q(n).
```

Let `L>=1` and define the interior slice

```text
I_q^int(n,L)
 = {p in I_q(n): L<=r<=p-1-L},

r=n-q*p.
```

For `p in I_q^int(n,L)` and `|h|<=L`, one has

```text
n+h=q*p+(r+h),
0<=r+h<p.
```

Thus the same fixed-`q` congruences apply at both rows:

```text
b_n       = b_q*b_r       (mod p),
F_q(n)    = epsilon_q*b_r (mod p),

b_(n+h)   = b_q*b_(r+h)       (mod p),
F_q(n+h)  = epsilon_q*b_(r+h) (mod p).
```

Taking the determinant gives

```text
D_h(n)=0 (mod p)
```

for **every** interior candidate prime, not only targets.

Equivalently, using the transverse coordinate from Section 2,

```text
D_h(n)
 = epsilon_q*(F_q(n)*U_q(n+h)-U_q(n)*F_q(n+h)).
```

Both transverse coordinates vanish modulo every interior candidate prime.

Define

```text
Pi_q^int(n,L)
 = product_{p in I_q^int(n,L)} p.
```

Then

```text
Pi_q^int(n,L)|D_h(n)
```

for every `|h|<=L`.

At most `2L` candidate primes are omitted. Indeed, `r<L` or `p-1-r<L` fixes one of only `2L` possible endpoint residues and hence at most `2L` possible primes. Therefore, for

```text
L=o(n/log n),
```

one has

```text
log Pi_q^int(n,L)
 = theta(n/q)-theta(n/(q+1))+O(L*log n)
 = n/(q(q+1))+o_q(n).
```

Consequently, if

```text
N_q(n,L)
 = gcd_{1<=|h|<=L}|D_h(n)|
```

is nonzero, then

```text
log N_q(n,L)
 >= n/(q(q+1))+o_q(n).
```

The nonzero issue does not rescue the construction. Q2646 proves

```text
sgn F_q(m)=(-1)^(m+H_q(m)).
```

Since `H_q` increases only once every `2q+1>=3` steps, at least one of `n-1,n+1` has the same cutoff as `n`. For that neighbor the two terms in `D_(+/-1)` have the same sign in absolute value, so

```text
|D_(+/-1)(n)|
 = b_n*|F_q(n+/-1)|+b_(n+/-1)*|F_q(n)|
 >0.
```

Thus a polylogarithmic neighboring determinant gcd is a nonzero integer with a **full-slice linear lower bound**. It cannot be the desired sublinear norm.

# 5. Lucas--Kronecker row matrices do not gain target corank

The preceding determinant is the `2 x 2` case of a general rank theorem.

Let

```text
V_m=(V_(m,1),...,V_(m,M))
```

be any current zero-order Newton/Padé/selector coordinate vector whose fixed-`q` block law has the form

```text
V_(q*p+t)=b_t*u_q (mod p)
```

for one fixed nonzero vector `u_q` after the usual finite exceptional primes are removed.

Stack a neighboring window:

```text
M_(p,L)
 = matrix with rows V_(n+h),  |h|<=L.
```

For an interior candidate prime,

```text
M_(p,L)
 = column(b_(r-L),...,b_(r+L)) * row(u_q)
   (mod p).
```

It is an outer product and hence has rank at most one for every candidate prime.

Suppose now that `p` is a target, so `b_r=0`. The no-consecutive-zero theorem gives

```text
b_(r-1)!=0 (mod p),
b_(r+1)!=0 (mod p).
```

Therefore, as soon as the window contains one neighbor,

```text
rank M_(p,L)=1
```

at a target as well.

So the central zero removes one row scalar but does **not** lower the matrix rank below the generic candidate rank. Every `2 x 2` or higher minor is already divisible by `p` for all candidates, and a target supplies no extra determinantal divisor at zero order.

This is the exact Smith/Fitting obstruction:

```text
generic candidate: rank 1;
target candidate:  rank 1;
```

not

```text
generic candidate: rank 1;
target candidate:  rank 0.
```

To retain a target after the universal rank-one factor is divided out, one would need a first-Bockstein rank drop.

Write a local lift schematically as

```text
V_(n+h)=b_(r+h)*u_q+p*W_h  (mod p^2).
```

Then

```text
det(V_n,V_(n+1))/p
 = b_r*det(u_q,W_1)
   +b_(r+1)*det(W_0,u_q)
   (mod p).
```

At a target this becomes

```text
det(V_n,V_(n+1))/p
 = b_(r+1)*det(W_0,u_q)  (mod p).
```

The factor `b_(r+1)` is a unit. Nothing in the zero-order Lucas--Kronecker law forces

```text
det(W_0,u_q)=0 (mod p).
```

That single first-Bockstein scalar is the exact seam. A proof that the determinant has a second factor of `p` at every target would be genuinely new arithmetic, not a consequence of the rank-one block.

# 6. The diagonal/G-function property does not add a finite-jet equation

The Apéry sequence satisfies

```text
(k+1)^3*b_(k+1)
 = P(k)*b_k-k^3*b_(k-1),

P(k)=34*k^3+51*k^2+27*k+5.
```

After inverting the finitely many recurrence pivots in a neighboring window, every jet coordinate is a linear expression in two free coordinates, for example

```text
b_n,
b_(n+1).
```

On the target locus `b_n=0`, the second coordinate remains a unit modulo every large target prime. Hence, modulo the recurrence ideal, a polynomial in a finite or polylogarithmic jet which vanishes for every target state is a multiple of the central coordinate `b_n`.

If instead the polynomial lies in the recurrence-residual ideal of an auxiliary selector jet, Q2606 proves that every interior candidate prime divides it. Such a nonzero cleared integer has positive linear height.

The same conclusion remains valid for a polylogarithmic window. The denominator-clearing product has

```text
log height = O(L*log n)=o(n)
```

when `L` is polylogarithmic, while the omitted boundary candidates have total logarithmic mass `O(L log n)=o(n)`.

Thus the diagonal/G-function input supplies holonomicity and fixed exponential coefficient height, but its finite contiguous jets have the exact two-coordinate normal form above. It does not supply the missing different-characteristic or first-Bockstein relation.

There is also an exact same-recurrence obstruction. Let `y_n` be another rational solution of the Apéry recurrence. Its Casoratian with `b` is constant:

```text
C
 = n^3*(b_n*y_(n-1)-b_(n-1)*y_n).
```

If a large target prime `p` divides both `b_n` and the cleared value of `y_n`, while the relevant denominators are `p`-units, then

```text
p|numerator(C).
```

A fixed nonzero Casoratian can therefore carry only finitely many moving large target primes. If `C=0`, then `y` is proportional to `b` and gives no independent carrier.

So a second solution of the same G-function differential/recurrence module cannot be the missing small-Casoratian selector.

# 7. The density theorem does not move a private spike to a good neighbor

The proved quantitative theorem is

```text
#{m<=N: log G_m>delta*m}
 = O_delta((log N)^2).
```

Its dyadic critical-window form gives

```text
|H_delta(N)|
 = O_delta(log N),

H_delta(N)
 = {N<m<=2N: log G_m>delta*m}.
```

Thus a fixed exceptional row has a nonexceptional neighbor within a polylogarithmic distance. The problem is that its private primes do not move with it.

For two rows separated by `h`, the proved codegree lemma gives

```text
# {large p : p|b_n and p|b_(n+h)}
 << h*log N/log P_0.
```

In a fixed-`q` slice one has `P_0 asy_q N`, so

```text
# {p in I_q(n): p|b_n and p|b_(n+h)}
 <<_q |h|.
```

For a window `|h|<=L`, the union bound gives

```text
# {central target primes recurring at some neighboring row}
 <<_q L^2.
```

Taking `L=O_delta((log N)^2)` produces only polylogarithmically many repeated primes, with total logarithmic mass `polylog(N)`. This is negligible compared with a forbidden spike of size `N/log N`.

Reflection does produce a second zero for every target prime. If

```text
n=q*p+r,
r*=p-1-r,
```

then the same-`q` reflected row is

```text
n_p* = q*p+r*
     = (2q+1)*p-n-1.
```

The map

```text
p -> n_p*
```

is injective. Hence distinct private primes are sent to distinct rows. Each reflected row is at linear scale and is forced to contain only its own original prime; a single contribution `log p=O(log N)` does not make that row exceptional.

The canonical reflection gap is

```text
h=p-1-2r.
```

For even `h`, the gap continuant has the proved forced factor

```text
N_h(X)=(2X+h+1)*N_h^circ(X).
```

At `X=r`,

```text
2r+h+1=p.
```

Thus reflection makes the gap polynomial vanish only through the already-known factor `p`. After deflation, no second condition remains.

Therefore the polylogarithmic exceptional-set theorem is fully compatible with one prescribed row having many private primes and all of its nearby or reflected descendants remaining density-good.

# 8. The companion determinant is a repeat detector, not a private-prime norm

Let `a,b` be the two Apéry solutions

```text
a_0=0, a_1=6,
b_0=1, b_1=5.
```

For `0<r<s`, define

```text
T_(r,s)=b_r*a_s-b_s*a_r.
```

Q2673 proves the exact factorial-gauged formula

```text
T_(r,s)
 = 6*C_(s-r)(r)
   / product_(j=r+1..s) j^3,
```

where

```text
C_0(x)=0,
C_1(x)=1,
C_(h+1)(x)
 = P(x+h)*C_h(x)-(x+h)^6*C_(h-1)(x).
```

If

```text
p>=7,
r<s<p,
p|b_r,
```

then `a_r` is a `p`-unit by the Apéry Casoratian, and

```text
T_(r,s)=-b_s*a_r (mod p).
```

Therefore

```text
p|T_(r,s)
 <=> p|b_s.
```

The companion determinant carries `p` exactly when the same prime has a second residual zero. A private incidence makes it a unit.

The smallest Casoratian correction that forces the endpoint prime is

```text
r^3*b_(r-1)*T_(r,s)+6*b_s
 = r^3*b_r*T_(r-1,s).
```

After clearing the same gap denominator, the right side is

```text
6*b_r*C_(s-r+1)(r-1).
```

The private prime is present only because the full factor `b_r` has returned. Since

```text
b_r>=binom(2r,r)^2
   >=16^r/(2r+1)^2,
```

this correction has positive linear exponential endpoint height. Dividing by `b_r` restores the small gap continuant and removes the forced private-prime support.

So the exact companion dichotomy is

```text
small gap determinant -> private prime absent;
force private prime    -> full b_r endpoint returns.
```

```text
T_q(n)=sum_p A_(p,q)(n),
```

and, with

```text
mu_q(n)
 = sum_p rho_p*1_(W_(p,q)(N))(n),
```

```text
T_q(n)-mu_q(n)=sum_p X_(p,q)(n).
```

The proved zero bound

```text
|Z_p|<<p^(2/3)
```

gives, uniformly for `N<n<=2N`,

```text
mu_q(n)
 <<_q N^(2/3)/log N
 = o_q(N/log N).
```

Define the full energy

```text
V_q(N)
 = sum_(N<n<=2N)(T_q(n)-mu_q(n))^2.
```

## Proposition 11.1 -- pointwise energy criterion

If

```text
V_q(N)=o_q(N^2/(log N)^2),
```

then

```text
sup_(N<n<=2N) T_q(n)=o_q(N/log N).
```

### Proof

Suppose for some fixed `eta>0` and infinitely many dyadic scales there is a row with

```text
T_q(n)>=eta*N/log N.
```

Since `mu_q(n)=o(N/log N)`, that one row contributes

```text
(T_q(n)-mu_q(n))^2
 >= (eta^2/4)*N^2/(log N)^2
```

for large `N`, contradicting the stated little-oh energy bound. QED.

This criterion is weaker by one logarithm than the Q2668 energy used to control the **sum over all exceptional anchors**. The present question asks only to exclude a prescribed row.

The density theorem permits an even more localized criterion. Put

```text
H_delta(N)
 = {N<n<=2N: log G_n>delta*n}.
```

The current theorem gives

```text
|H_delta(N)|=O_delta(log N)
```

in a dyadic critical window. Any row with

```text
T_q(n)>=eta*N/log N
```

lies in `H_delta(N)` for a fixed `delta=delta(eta,q)>0`, because its target radical already has logarithmic size comparable to `eta*N`.

Therefore it is enough to prove the restricted energy bound

```text
V_(q,delta)^exc(N)
 = sum_(n in H_delta(N))
   (T_q(n)-mu_q(n))^2
 = o_(q,delta)(N^2/(log N)^2).
```

This is the exact energy statement that excludes one prescribed exceptional row.

# 12. The same-prime diagonal is already below the pointwise threshold

Expand the restricted energy as

```text
V_(q,delta)^exc(N)
 = D_(q,delta)^exc(N)+C_(q,delta)^exc(N),
```

where


```text

   sum_(n in H_delta(N))
```


All relevant primes satisfy `p asy_q N`, so


And

```text

```

Hence

```text
D_(q,delta)^exc(N)
 = o_q(N^2/(log N)^2)
```

unconditionally.

Therefore the first exact missing estimate for the pointwise theorem is only


This is a correlation between two different characteristics. If one row is simultaneously bad for `p` and `ell`, write

