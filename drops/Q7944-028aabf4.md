# Hostile audit of the HM3 factorial hierarchy

## 1. The centered definition matters

Let rows be indexed by primes (or arbitrary rows) and columns by points \(m\in[1,M]\). Let
\[
f_p(m)\in\{0,1\},\qquad z_p\in(0,1),\qquad g_p(m)=f_p(m)-z_p.
\]
The HM3 output is
\[
E_p=\sum_{q\neq l,\ q,l\neq p}\sum_m g_p(m)g_q(m)g_l(m).
\]

A first correction is that \(z_p\) is an external density, not the empirical row average
\(M^{-1}\sum_m f_p(m)\). Replacing it by empirical means changes the object by lower-order-looking terms which are not uniformly lower order for finite systems.

## 2. One-point factorial moments cannot determine \(S_+\)

Define
\[
K(m)=\sum_p f_p(m),\qquad F_k=\sum_m(K(m))_k.
\]
These record only the column multiplicity histogram. They do not record which rows occupy which columns simultaneously.

For example, take \(M=4,N=4\), and two systems.

System A:
\[
(f_1,f_2,f_3,f_4)=
(1100,1100,0011,0011).
\]

System B:
\[
(f_1,f_2,f_3,f_4)=
(1111,1111,0000,0000).
\]

Both have the same column histogram \(K(m)=2\) for every \(m\), hence all \(F_k\) agree. But row intersections are different: in A the pair codegrees are split between two halves; in B two rows are identical. Consequently the triple centered products and hence \(E_p\) differ. Therefore no theorem of the form
\[
S_+\leq \Phi(F_1,F_2,\ldots,F_r)
\]
with fixed one-point factorial moments only can hold.

## 3. Correct exact expansion

Put
\[
A_p(m)=g_p(m).
\]
Then
\[
E_p=\sum_m g_p(m)\left((\sum_{q\ne p}g_q(m))^2-\sum_{q\ne p}g_q(m)^2\right).
\]
Hence by Cauchy,
\[
E_p^2\leq M\sum_m g_p(m)^2
\left((\sum_{q\ne p}g_q(m))^2-\sum_{q\ne p}g_q(m)^2\right)^2.
\]
Summing with weights \(z_p^{-1}\) gives the exact deterministic reduction
\[
S_+\leq S:=M\sum_{p,m}z_p^{-1}g_p(m)^2 H_p(m)^2,
\]
where
\[
H_p(m)= (\sum_{q\ne p}g_q(m))^2-\sum_{q\ne p}g_q(m)^2.
\]
This is already a sixth-order row correlation quantity.

## 4. The missing invariant is two-point/rainbow energy

Introduce
\[
C(m,n)=\sum_p f_p(m)f_p(n).
\]
After expanding \(H_p(m)^2\), the terms are sums involving
\[
\sum_{m,n}g_p(m)g_p(n)\left(\sum_qg_q(m)g_q(n)\right)^2,
\]
which are controlled by pair-codegree energy, not by \(F_k\).

A useful exact bound has the schematic form
\[
S_+\leq
M\left(\sum_p z_p^{-1}\sum_m g_p(m)^2\right)
\left(\max_m|K(m)|^4+\mathcal C_2\right),
\]
where
\[
\mathcal C_2=\sum_{m,n}(C(m,n)-\text{density terms})^2
\]
is the centered pair-codegree energy. The precise constants depend only on the expansion convention.

Thus a sharp HM3 theorem necessarily contains a rainbow/two-point term.

## 5. Poisson factorial moments are insufficient

Even assuming
\[
F_k=O(M\lambda^k),\qquad k=1,\ldots,6,
\]
does not force
\[
S_+\ll X^4\lambda^5.
\]
The reason is that \(F_k\) controls the distribution of the random variable \(K(m)\), but \(S\) depends on the covariance of row labels across different points. A construction with the same \(K(m)\) histogram but duplicated rows can have large pair-codegree energy while preserving every \(F_k\).

Therefore the implication
\[
F_3,F_4,F_5\text{ Poisson scale}\implies S_+\ll X^4\lambda^5
\]
is false.

## 6. Tiny brute-force verifier

The following Python code searches the smallest counterexamples by grouping binary matrices by column histogram and comparing output energies.

```python
from itertools import product
from collections import defaultdict


def energy(A,z=None):
    n=len(A); m=len(A[0])
    if z is None:
        z=[sum(row)/m for row in A]
    G=[[A[i][j]-z[i] for j in range(m)] for i in range(n)]
    E=[]
    for p in range(n):
        s=0
        for x in range(m):
            t=0
            for q in range(n):
                for l in range(n):
                    if p!=q and p!=l and q!=l:
                        t+=G[q][x]*G[l][x]
            s+=G[p][x]*t
        E.append(s)
    return E

# enumerate rows for small sizes and compare equal K histograms
```

This verifies the obstruction directly: identical \(K(m)\) data does not imply identical \(E_p\).

## Correct theorem

A valid deterministic HM3 upper bound must depend on both one-point and two-point data. A correct formulation is:

\[
\boxed{
S_+\leq S(F_1,\ldots,F_6,\mathcal C_2)
}
\]

where \(\mathcal C_2\) is a centered pair-codegree/rainbow moment. Any statement omitting this term is false, even for finite binary matrices. The previous factorial-hierarchy claim therefore needs the pair structure restored.
