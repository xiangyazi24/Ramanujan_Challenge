# 1. Exact minus geometry

Let a quotient-six edge have

\[
m=6p+r=6q+u,
\qquad q=p+d>p,
\]

with

\[
0\le r<p,\qquad 0\le u<q,
\qquad p\mid b_r,\qquad q\mid b_u.
\]

Then

\[
r-u=6d,
\qquad r=u+6d.
\tag{1.1}
\]

For the Q3727 minus secondary index,

\[
L_-=d-1-u.
\tag{1.2}
\]

Set

\[
k:=p+L_-.
\]

Then

\[
\boxed{k=p+L_-=q-1-u.}
\tag{1.3}
\]

Thus at fixed upper state `(q,u)` both the physical row and the lifted index are fixed:

\[
\boxed{m(q,u)=6q+u,\qquad k(q,u)=q-1-u.}
\tag{1.4}
\]

A lower prime `p` determines the entire edge in that star:

\[
d=q-p,
\qquad r=u+6(q-p),
\qquad L_-=q-p-1-u.
\tag{1.5}
\]

In particular there is **at most one edge with a given lower prime `p` in a fixed `(q,u)` star**.

The geometric legality can be written without referring to a selected edge set. From `r<p`,

\[
6q+u<7p
\iff
p>\frac{6q+u}{7}.
\tag{1.6}
\]

From `L_-\ge0`,

\[
p\le q-u-1=k.
\tag{1.7}
\]

The condition `L_-<p` is automatic once (1.6) holds, because

\[
\frac{6q+u}{7}\ge \frac{q-1-u}{2}.
\]

Hence the purely geometric lower-prime fibre is

\[
\boxed{
\frac{6q+u}{7}<p\le q-u-1.
}
\tag{1.8}
\]

If the macroscopic-gap sector is `q-p>T/J`, add the independent restriction

\[
\boxed{p<q-T/J.}
\tag{1.9}
\]

Every true minus-secondary edge also has `u\le d-1`, while (1.6) gives `7d<q`; hence

\[
\boxed{0\le u<q/7.}
\tag{1.10}
\]

# 2. The two-index common divisor

For a fixed upper state put

\[
G_{q,u}:=\gcd\!\left(b_{6q+u},b_{q-1-u}\right).
\tag{2.1}
\]

For every true minus edge in this star, both endpoint primes divide this gcd.

For the lower prime `p`, the original quotient-six hit gives, by Apéry--Lucas,

\[
p\mid b_{6p+r}=b_{6q+u}.
\tag{2.2}
\]

The minus-secondary condition `p\mid b_{L_-}` and `k=p+L_-` give

\[
b_k=b_{p+L_-}\equiv b_1b_{L_-}=5b_{L_-}\pmod p,
\]

hence

\[
p\mid b_k=b_{q-1-u}.
\tag{2.3}
\]

Therefore

\[
\boxed{p\mid G_{q,u}.}
\tag{2.4}
\]

For the upper prime `q`, `q\mid b_u` gives

\[
q\mid b_{6q+u}
\tag{2.5}
\]

by Apéry--Lucas, while reflection gives

\[
b_{q-1-u}\equiv b_u\pmod q,
\]

so

\[
q\mid b_{q-1-u}.
\tag{2.6}
\]

Thus

\[
\boxed{q\mid G_{q,u}.}
\tag{2.7}
\]

For every true edge,

\[
\boxed{pq\mid G_{q,u}.}
\tag{2.8}
\]

No existence statement is used in this derivation: it is an implication for any tuple satisfying the true-edge hypotheses.

# 3. Hostile point (i): is the family prescribed independently of selected edges?

Yes, **if and only if** the outer star family is defined before the selected edge set.

A clean fixed-`(J,T)` choice is as follows. Define the candidate lower-prime fibre

\[
\mathcal P^-_{J,T}(q,u)
:=
\left\{
 p\text{ prime}:
 \frac{6q+u}{7}<p\le q-u-1,
 \ q-p>\frac{T}{J}
\right\}.
\tag{3.1}
\]

Then define the prescribed upper-state family

\[
\boxed{
\mathcal U^-_{J,T}
:=
\left\{
(q,u):
\begin{array}{l}
q\text{ prime},\ 0\le u<q/7,\\
T<6q+u\le2T,\\
q\mid b_u,\\
\mathcal P^-_{J,T}(q,u)\ne\varnothing
\end{array}
\right\}.
}
\tag{3.2}
\]

This family depends only on:

- `J,T`;
- primality;
- the fixed quotient-six geometry;
- the canonical Apéry values `b_u`.

It does **not** depend on which true edges are retained, selected, singleton-labelled, or otherwise charged later.

One may make the theorem even simpler by omitting the final nonempty-fibre condition in (3.2), or even by using all shell states with `q|b_u`. That only enlarges the carrier and makes the height hypothesis stronger. It does not hurt validity.

By contrast, the definition

```text
U = {(q,u) : some selected edge has upper state (q,u)}
```

would be circular and would make the carrier selected-edge-dependent. The valid theorem uses (3.2), or an equivalent candidate-state family fixed in advance.

# 4. Hostile point (ii): is dividing one `q` layer enough?

Yes.

Define the stripped star carrier

\[
\boxed{
A_{q,u}
:=
\frac{G_{q,u}}{\gcd(G_{q,u},q)}.
}
\tag{4.1}
\]

On every state in (3.2), `q` is prime and `q|b_u`; hence (2.7) shows `q|G_{q,u}`. Therefore

\[
\boxed{\gcd(G_{q,u},q)=q,}
\tag{4.2}
\]

so `A_{q,u}=G_{q,u}/q`.

Now let `p` be any lower prime carried by a true edge in this star. Since `p<q`,

\[
p\ne q.
\]

Thus division by `q` does not reduce the `p`-adic valuation:

\[
\boxed{
v_p(A_{q,u})=v_p(G_{q,u})\ge1.
}
\tag{4.3}
\]

That is all the edge-counting argument needs.

It is **not necessary** to remove the entire `q`-primary part `q^{v_q(G_{q,u})}`. A full stripping

\[
G_{q,u}/q^{v_q(G_{q,u})}
\]

would also be prescribed and could only improve the height, but one forced `q` layer is sufficient to retain every lower-prime edge label. If the local proof says that (4.1) removes *all* `q`-adic valuation, that wording is false; it removes exactly one forced layer. This does not invalidate the carrier implication.

# 5. Hostile point (iii): multiplicity when the same `p` occurs across stars

There is no multiplicity leak.

Fix one star `(q,u)`. By (1.5), `(q,u,p)` determines the edge uniquely. Therefore a given lower prime `p` occurs at most once in that star.

Let `E^-_{J,T}` be any selected set of true minus edges and define

\[
E^-_{J,T}(q,u)
:=\{e\in E^-_{J,T}: e\text{ has upper state }(q,u)\}.
\]

Since distinct edges inside one star have distinct lower primes, (4.3) gives the stronger starwise divisibility

\[
\boxed{
\prod_{e\in E^-_{J,T}(q,u)}p_e
\mid A_{q,u}.
}
\tag{5.1}
\]

Now define the prescribed aggregate carrier

\[
\boxed{
\mathfrak A^-_{J,T}
:=
\prod_{(q,u)\in\mathcal U^-_{J,T}} A_{q,u}.
}
\tag{5.2}
\]

Suppose the same lower prime `p` occurs in `M_p` different selected edges, necessarily in `M_p` different stars. Each corresponding star contributes at least one `p` to its factor `A_{q,u}`. Hence

\[
\boxed{
M_p
\le
v_p(\mathfrak A^-_{J,T}).
}
\tag{5.3}
\]

This is the required multiplicity statement. A radical of the *whole aggregate* would lose this information, but the product of star carriers does not.

Equivalently,

\[
\prod_{e\in E^-_{J,T}}p_e
\mid
\mathfrak A^-_{J,T},
\tag{5.4}
\]

where the product on the left is an event product and therefore repeats `p` when `p` labels several edges. Statement (5.4) is valid precisely because the right-hand side is also a product over stars, so those repeated valuations accumulate.

# 6. Hostile point (iv): shell and fixed-`J` quantifiers

The clean quantifier order is

\[
\boxed{
\text{for every fixed }J>0,\quad T\to\infty.
}
\]

Define the shell by

\[
T<m\le2T.
\tag{6.1}
\]

The prescribed family (3.2) uses exactly the upper-state identity `m=6q+u`, so shell membership is fixed before edges are selected.

For any true quotient-six lower hit on such a row,

\[
p>m/7>T/7.
\tag{6.2}
\]

Therefore every selected edge satisfies

\[
\log p_e\ge\log(T/7).
\tag{6.3}
\]

Combining (5.3) over primes gives

\[
\begin{aligned}
|E^-_{J,T}|\log(T/7)
&\le \sum_{e\in E^-_{J,T}}\log p_e\\
&=\sum_p M_p\log p\\
&\le\sum_p v_p(\mathfrak A^-_{J,T})\log p\\
&=\log\mathfrak A^-_{J,T}.
\end{aligned}
\tag{6.4}
\]

Thus the exact height implication is

\[
\boxed{
\log\mathfrak A^-_{J,T}
=o_J\!\left(\frac{T^2}{\log T}\right)
\Longrightarrow
|E^-_{J,T}|
=o_J\!\left(\frac{T^2}{\log^2T}\right).
}
\tag{6.5}
\]

Nothing requires `J` to grow with `T`; doing so would change the theorem. The intended application is: fix `J`, take `T\to\infty`, establish the little-`o_J`, and only then use whatever outer argument sends `J` large.

If the selected sector has extra conditions—singleton status, sign/orientation, exclusion of a previously handled proximal range—those should occur only in the definition of `E^-_{J,T}`. They do not need to enter the carrier family unless doing so can be expressed as a selected-set-independent candidate condition.

is vacuous when `true_minus_edges` is empty. Therefore such a scan must **not** be described as validating a nonvacuous actual minus edge or proving existence. It is only regression evidence for the formulas surrounding the theorem.
