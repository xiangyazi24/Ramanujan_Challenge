# Finite-field Sturm theorem for the Apéry recurrence

## Summary

There is **no general finite-field Sturm theorem** saying that a rank-2 non-autonomous recurrence with polynomial coefficients of degree d has only C(d) zeros. In fact such a statement is false without additional arithmetic hypotheses. A polynomial-coefficient transfer system can encode essentially arbitrary projective dynamics over F_p.

The Apéry recurrence is special, but the special structure is not captured by degree alone. The useful replacement is a combination of:

1. the rank-2 differential equation behind the recurrence;
2. regular-singular/p-adic differential structure;
3. explicit Wronskian control;
4. arithmetic rigidity of the Apéry motive.

A finite-field Sturm theorem would have to be a theorem about this specific Picard-Fuchs system, not a theorem about polynomial recurrences in general.

---

## (A) Why degree bounds do not imply bounded zero count

Write the recurrence as

```
v_{n+1}=M_n v_n,
```

with

```
M_n = [[P(n)/Q(n), -R(n)/Q(n)], [1,0]].
```

The condition x_n=0 means that the projective orbit reaches a fixed point in P^1(F_p).

The problem is that the matrices M_n are not powers of one matrix. Even if every entry is a low-degree polynomial in n, the products

```
M_{n-1}...M_0
```

can have very complicated behavior modulo p.

One can construct degree-1 or degree-2 coefficient recurrences whose projective orbit is prescribed on a long interval. Therefore

```
degree <= d  ==>  O_d(1) zeros
```

is false.

The autonomous case is different because the orbit is generated by a single element of GL_2(F_p), hence is periodic. The non-autonomous case has p degrees of freedom.

---

## (B) The ratio-map interpretation

Let f,g be a basis of solutions and

```
R_n=f_n/g_n.
```

Then a solution alpha f+beta g has zeros exactly when

```
R_n=-beta/alpha.
```

Thus the universal zero problem is a multiplicity problem for the map

```
R : {0,...,p-2} -> P^1(F_p).
```

The computational observation that every value has multiplicity about 4 or 5 is much stronger than anything supplied by degree considerations.

The correct analogue of Sturm is therefore not an oscillation theorem but a **bounded fiber theorem for the projective Apéry orbit**.

## (C) Why the Apéry recurrence is unusually rigid

Several facts are genuinely relevant.

### 1. Explicit Wronskian

The Casoratian satisfies

```
W_n = f_n g_{n+1}-f_{n+1}g_n = (-1)^n/(n+1)^3.
```

Consequences:

* consecutive projective points are never equal;
* every return requires a separated algebraic relation;
* collisions are controlled by gap Wronskians.

This explains why the observed multiplicity is tiny, but does not alone prove it.

### 2. Gap Wronskians satisfy the same recurrence

For fixed r,

```
W(r,s)=f_r g_s-f_s g_r
```

is itself an Apéry solution in s.

Therefore a zero collision of the ratio map is equivalent to a zero of a distinguished Apéry solution. The computational bound of at most four zeros per gap-Wronskian is precisely a universal-zero theorem for a restricted family of solutions.

This is stronger structure than a generic recurrence has.

### 3. Picard-Fuchs origin

The recurrence is a discretization of a rigid hypergeometric differential equation. The differential Galois group being large (SL_2 on the relevant factor) prevents obvious algebraic periodicity.

However, SL_2 monodromy alone is not enough: many SL_2 differential systems have finite-field reductions with many zeros.

## (D) Is there a GL_2(F_p) orbit theorem?

For arbitrary matrices

```
g_1,...,g_N in GL_2(F_p),
```

there is no useful bound on

```
#{k : g_k...g_1 x = x}
```

independent of p.

The matrices may be chosen to force repeated returns.

Theorems from product-growth theory (Bourgain-Gamburd, Helfgott, etc.) concern random products or sufficiently rich subsets of a group. They do not apply to a deterministic sequence M_n unless one proves expansion/mixing of that sequence.

For Apéry one would need a statement like:

```
The set of partial products Π_n=M_{n-1}...M_0 has uniformly bounded intersection
with every projective stabilizer coset.
```

This is exactly the missing theorem.

## (E) Relation to Dwork, Robba, Christol, Kedlaya

These theories are close but do not immediately give the desired statement.

### Dwork theory

Dwork studies p-adic differential equations, Frobenius structures, and unit-root solutions. Index theorems bound dimensions of solution spaces or cohomological quantities.

They do not directly bound the number of zeros of one horizontal section after reduction modulo p.

### Christol

Christol theory gives algebraicity/automaticity criteria for sequences over finite fields. It controls the structure of sequences, not pointwise zero multiplicity at one prime.

### Robba/Kedlaya

p-adic differential equations give slope decompositions and Frobenius information. They are relevant for Apéry's crystalline realization, but a zero count requires a stronger statement about the reduction of a specific horizontal section.

The missing bridge is:

```
p-adic differential rigidity
        =>
finite-field projective orbit anti-concentration.
```

No general theorem of this form is currently available.

---

## (F) Can Dwork's index theorem become a finite-field Sturm theorem?

Not directly.

The analogy is:

Real Sturm:

```
differential operator + interval
        => zero count.
```

Dwork:

```
p-adic differential module + Frobenius
        => cohomological index.
```

The index controls dimensions of spaces of solutions, not zeros of a single solution on F_p.

A possible route would require a new theorem of the form:

```
For a rigid overconvergent F-isocrystal of rank 2 and bounded conductor,
any nonzero horizontal section has O(1) zeros after reduction mod p.
```

This is false for arbitrary overconvergent isocrystals (Jacobi/Kummer examples show related failures), so the theorem must use additional Apéry-specific hypotheses.

## Expected constant C

The computation suggests:

```
max multiplicity(R) <= 5
```

and therefore

```
|Z_p| <= 10
```

is a plausible target.

The likely mechanism is not a generic finite-field Sturm theorem. The realistic theorem would be:

**Apéry projective anti-concentration theorem.** For the Apéry transfer cocycle,

```
#{n : Π_n x = y} <= C
```

for all x,y in P^1(F_p), with an absolute C.

The computational evidence (Wronskians, gap recurrence, multiplicity <=5) strongly supports this formulation.

If proved, it would immediately imply the desired ZM_2 bound:

```
|Z_p|=O(1).
```

The key missing ingredient is therefore not Sturm theory in the classical sense, but a finite-field anti-concentration theorem for the deterministic Apéry transfer cocycle.
