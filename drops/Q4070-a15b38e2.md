## Theorem 4.1 — strict-pair support

For every odd prime `p`,

```text
p|A_{r,s}

p>2s+1, p|b_r, and p|b_s.                           (4.2)
```

Conversely, if `p>2s+1` and `p|b_r,b_s`, Theorem 1.1 and `p∤Y` give `p|gcd(b_r,N_h^prim(r))`, so `p|A_{r,s}`.  QED.

```text
Z_p^-={r:0<=r<(p-1)/2 and p|b_r},
```

# 6. What is only a refactor

## 6.2 The two-border determinantal divisor

# 7. Exact horizontal aggregation obstruction

The exact carrier `(4.3)` radicalizes **before** multiplying pair factors.  That order is forced by occurrence multiplicity.

Fix a left endpoint `r` and a finite set of admissible gaps `H`.  Put

```text
m_{p,r}(H)
 =#{h in H:p|b_r and p|N_h^prim(r)}.                 (7.1)
```

Consider the tempting horizontally compressed integer

```text
H_r
 =rad(gcd(b_r,product_{h in H}N_h^prim(r))).         (7.2)
```

Prime by prime,

```text
v_p(H_r)=
  1 if m_{p,r}(H)>0,
  0 if m_{p,r}(H)=0.                                (7.3)
```

But the number of pair occurrences with left endpoint `r` is

```text
m_{p,r}(H).                                          (7.4)
```

Thus `(7.2)` is a support carrier for “at least one partner,” not an occurrence carrier for the factorial moment.

The exact multiplicity-preserving object is instead

```text
product_{h in H}
  rad(gcd(b_r,N_h^prim(r))),                         (7.5)
```

for which

```text
v_p((7.5))=m_{p,r}(H).                               (7.6)
```

But `(7.5)` restores the sum of the individual logarithmic heights.  The same failure occurs if one first multiplies every pair carrier and takes one global radical: a prime supporting `binom(K_p,2)` pairs is reduced to exponent one.

One may try to retain valuations by replacing `(7.2)` with

```text
gcd(b_r^|H|,product_{h in H}N_h^prim(r)).            (7.7)
```

This is only an overcarrier.  Its logarithmic height is bounded by

```text
|H| log b_r,                                         (7.8)
```

which reinstates the same cubic aggregate cost; excess `p`-adic valuations can only make it larger.

Therefore, within the operations

```text
multiplication, gcd, lcm, radical, and deletion of
factors proved to be target-prime units,
```

there is an exact dichotomy:

```text
aggregate before radical  -> multiplicity is lost;
radical before aggregate  -> pairwise height is additive.
```

This is the rigorous horizontal no-go.  It does not rule out a new Apéry-specific identity that creates cancellation or a new average gcd theorem; it rules out obtaining that saving by rearranging the current gcd/radical operations.

```text
       = min(v_p(b_r),v_p(b_s)).

   In particular this holds for every strict lower pair.

B. Genuine lower-height occurrence carrier

   A_{r,s}=rad_{>2s+1}(gcd(b_r,N_{s-r}^prim(r))).

   Product over pairs has exact valuation binom(K_p,2).
   The elementary aggregate height improves from
   O(X^3 log X) for the raw continuant product to O(X^3).

C. Refactors

   M_h(Y)=Y^epsilon C_h(Y^2), the reflected bridge,
   and the large-prime part of Gamma_{r,s} have the same
   target prime-power content.  They provide normalization,
   not a new arithmetic restriction.

D. Precise obstructions

   Horizontal radicalization after multiplication loses
   occurrence multiplicity exactly.

   Reflection gives an associate bridge and a unit multiplier
   product, not a second equation.

   Deleting the center factor outside the strict sector is false;
   (p,r,h)=(5,1,2) is an exact counterexample.

E. Consequence for L2

   The shell part of the aggregate carrier has logarithmic
   height exactly L2(X).  Current coefficient-size bounds give
   only O(X^3), not O(X).  Any further power saving must be a
   genuinely new horizontal average-gcd/radical or dispersion
   theorem; it cannot come from reflection or centered
   normalization alone.
```
