# P3.2 exact denominator theorem: B5-beta is true, and B3-beta is sharp

## Verdict

The proposed `B5-beta` statement is true, but it is not sharp.  The exact principal-part bookkeeping proves the stronger theorem

```text
[B3-beta-integral]

For every h>=1 and every integer x>=0, if

  beta_h(x)
    = alpha_h(x) * (2*x+h+1)*(x+h)/(x+1)^2

is written in lowest terms, then

  den(beta_h(x)) | lcm(x+1,...,x+h)^3.
```

For `h=1`, `beta_1=2`.  For `h>=2`, this is the beta in the question:

```text
beta_h
 = N_h(x)*(2*x+h+1)
   /[(x+1)^2*(x+h)^2*prod_(j=2)^(h-1)(x+j)^3].
```

The exponent `3` is best possible uniformly.  Already

```text
x=0, h=4:

L = lcm(1,2,3,4)=12.
```


```text
[B3-beta-odd]

```

Again exponent `3` is sharp.  For

```text

```

one gets

```text

15435 = 3^2*5*7^3,
L_T=lcm(3,5,7,9)=315.
```

Hence the denominator divides `315^3` but not `315^2` because of the factor `7^3`.


The old exponent-five statement is a valid universal clearing bound, but it loses the correlation between pole order and coefficient-denominator order. Put

# 8. Mark retention in the actual physical target normalization

The centered special-residue test above is useful when the corner algebra forces `T` to one of `0,±h`.  For an actual target bridge there is a more direct and often stronger unit criterion.

Suppose the target characteristic is an odd prime `q`, and the two physical roots are

```text
r,
r+h,

0<=r<r+h<q.                                         (8.1)
```

Choose the odd-affine representative `z` as in Q2170 so that

```text
z == 2*r (mod q).                                   (8.2)
```

The beta denominator in (6.3) is supported on

```text
z+2*j,  1<=j<=h,                                   (8.3)
```

with endpoint exponents two and interior exponents three.

Modulo `q`,

```text
z+2*j == 2*(r+j) (mod q).                           (8.4)
```

Since `q` is odd and

```text
1<=r+j<=r+h<q,
```

every factor in (8.4) is a `q`-unit.  Therefore the entire beta denominator is a `q`-unit.

Consequently, if the raw/centered beta numerator has a designated valuation

```text
v_q(U_raw)>=e,                                      (8.5)
```

then numerical primitive reduction cannot remove any of it:

```text
v_q(U_reduced)>=e.                                  (8.6)
```

This applies prime by prime when one fixed bridge factor is marked by several distinct shell primes.

## Factorwise versus global rational reduction

The statement (8.6) is factorwise.  If several reduced beta factors

```text
u_i=U_i/V_i
```

are later multiplied and the **global rational product** is reduced, a different factor's denominator could in principle cancel a prime from `U_i` unless that prime is a unit in every denominator in the product.

Thus the safe integer marked carrier remains

```text
prod_i U_i,                                         (8.7)
```

or any integer combination whose mark divisibility is proved before a global rational cancellation step.

This distinction is exactly the one isolated in Q2169.  B3-beta improves the denominator height; it does not change the elementary valuation law for a later rational product.

# 11. Executable exact checker

The following SymPy script is only a regression check.  The proof is Sections 1--8.

It verifies:

```text
* the recurrence and beta definition;
* B3-beta on a finite integral and half-integral box;
* the two sharp exponent-3 examples;
* the symbolic cancellation formulas (3.4)--(3.6);
* the centered denominator pattern for small h.
```

```python
import math
import sympy as sp

x, T = sp.symbols('x T')


def P(z):
    return 34*z**3 + 51*z**2 + 27*z + 5


HMAX = 30
N = [sp.Integer(0), sp.Integer(1)]
for h in range(1, HMAX):
    N.append(sp.expand(P(x+h)*N[h] - (x+h)**6*N[h-1]))


def beta_expr(h):
    if h == 1:
        return sp.Integer(2)
    den = (x+1)**2 * (x+h)**2
    for j in range(2, h):
        den *= (x+j)**3
    return sp.cancel(N[h] * (2*x+h+1) / den)


def reduced_den(expr):
    return int(sp.denom(sp.cancel(expr)))


# Integral regression.
for xx in range(0, 101):
    for h in range(1, 21):
        v = sp.cancel(beta_expr(h).subs(x, xx))
        den = reduced_den(v)
        L = math.lcm(*range(xx+1, xx+h+1))
        assert L**3 % den == 0, (xx, h, v, L)


# Odd-affine / half-integral regression.
for n in range(0, 61):
    xx = sp.Rational(2*n+1, 2)
    for h in range(1, 21):
        v = sp.cancel(beta_expr(h).subs(x, xx))
        den = reduced_den(v)
        odd_factors = [int(2*(xx+j)) for j in range(1, h+1)]
        Lodd = math.lcm(*odd_factors)
        assert Lodd**3 % den == 0, (xx, h, v, Lodd)


# Sharp integral example.
v = sp.cancel(beta_expr(4).subs(x, 0))
assert v == sp.Rational(57123475, 432)
assert 12**3 % 432 == 0
assert 12**2 % 432 != 0


# Sharp half-integral example.
v = sp.cancel(beta_expr(4).subs(x, sp.Rational(1, 2)))
assert v == sp.Rational(1676349856, 15435)
assert 315**3 % 15435 == 0
assert 315**2 % 15435 != 0


# Symbolic principal-part cancellation.
m, q, C0, C1, C2 = sp.symbols('m q C0 C1 C2', nonzero=True)
D = m + q

A3 = -m**3*C0
A2 = 3*m**2*C0 - m**3*C1
A1 = -m**3*C2 + 3*m**2*C1 - 3*m*C0

r0 = q*(q-m)/m**2
r1 = (m+q)*(2*q-m)/m**3
r2 = 3*q*(m+q)/m**4

B3 = sp.expand(r0*A3)
B2 = sp.expand(r0*A2 + r1*A3)
B1 = sp.expand(r0*A1 + r1*A2 + r2*A3)

B3_expected = m*q*(m-q)*C0
B2_expected = (
    (m**2 - 4*m*q + q**2)*C0
    + m*q*(m-q)*C1
)
B1_expected = (
    3*(q-m)*C0
    + (m**2 - 4*m*q + q**2)*C1
    + m*q*(m-q)*C2
)

assert sp.expand(B3-B3_expected) == 0
assert sp.expand(B2-B2_expected) == 0
assert sp.expand(B1-B1_expected) == 0


# Centered reduced-denominator support predicted by Section 7.
def Qcenter(h):
    if h == 1:
        return sp.Integer(1)
    Q = (T**2 - (h-1)**2)**2
    if h % 2 == 0:
        for r in range(1, h-2, 2):
            Q *= (T**2-r**2)**3
    else:
        Q *= T**2
        for r in range(2, h-2, 2):
            Q *= (T**2-r**2)**3
    return sp.expand(Q)


for h in range(2, 11):
    bt = sp.cancel(beta_expr(h).subs(x, (T-h-1)/2))
    q_actual = sp.Poly(sp.denom(bt), T, domain=sp.QQ).monic().as_expr()
    q_expected = sp.Poly(Qcenter(h), T, domain=sp.QQ).monic().as_expr()
    assert sp.expand(q_actual-q_expected) == 0

print('Q2173 B3-beta exact regression: PASS')
```

# Bottom line

`B5-beta` is proved, but the correct theorem is stronger:

```text
den(beta) divides the cube of the actual interval lcm.
```

The two extra lcm powers in the old exponent-five budget are not intrinsic here.  They arise from forgetting that a cubic pole has an integral coefficient, a quadratic pole has only one `Lambda_D`, and only the simple-pole coefficient needs `Lambda_D^2`.  The beta endpoint factor preserves exactly that triangular profile after a nontrivial cancellation of all apparent `m^-2,m^-3,m^-4` terms.

Exponent `3` is uniformly sharp in both the integral and physical odd-affine settings.  The only additional caution for the centered mark transport is denominator support: at `T=0` odd gaps are genuine poles, and at `T=±h` the shell-prime unit condition is `2h<ell`, not merely `h<ell`.  In the actual nonwrapping target-root representation `z==2r (mod q)`, all beta denominator factors are automatically `q`-units, so the designated target marks survive factorwise primitive reduction.
