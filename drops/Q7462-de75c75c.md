## 2. Exact derivation of the event interval

Fix an inverse event after all `T`-independent arithmetic conditions have been checked.  Thus `p,q` are the intended primes, the sign-specific lower indices are integral and in range, the required lower Apéry zeros hold, and `t` denotes the unified upper coordinate.

Only three geometric conditions remain.

### 2.1 Lower-prime shell

The exact shell is

\[
\frac T7<p\le\frac T3.
\]

Because `p,T` are integers,

\[
\frac T7<p
\iff T<7p
\iff T\le7p-1,
\]

and

\[
p\le\frac T3
\iff 3p\le T.
\]

Hence

\[
\boxed{3p\le T\le7p-1.}
\tag{5}
\]

This is the precise location of the error in the proposed formula.  Replacing `3p` by `3q` silently imposes the extra false condition `q<=T/3` as a lower-shell requirement.  The upper row may imply a related inequality, but it is not the lower-prime shell and cannot replace `(5)` event by event.

### 2.2 Upper row

The common upper row is

\[
T<R_e\le2T,
\qquad R_e=6q+t.
\]

For integer `T,R_e`, this is equivalent to

\[
\boxed{
\left\lceil\frac{R_e}{2}\right\rceil
\le T\le R_e-1.}
\tag{6}
\]

### 2.3 Strict far-gap cutoff

The long-gap gate is

\[
d_e=q-p>\frac TJ.
\]

For positive integer `J`, this is

\[
T<Jd_e
\iff
\boxed{T\le Jd_e-1.}
\tag{7}
\]

Intersecting `(5)`, `(6)`, and `(7)` proves `(1)` and `(2)`.

There is no additional `T`-parity condition in this current unified inverse-event representation.  Any sign-specific integrality condition belongs to the construction of the event tuple and must be checked before applying `(1)`.

## 3. Intrinsic viability, activation, and saturation

Define

\[
A_e=\max\left\{3p,\left\lceil\frac{6q+t}{2}\right\rceil\right\},
\qquad
B_e=\min\{7p-1,6q+t-1\},
\qquad
d_e=q-p.
\]

### 3.1 Never-active events

An event is never legal if either

\[
d_e\le0
\]

or

\[
A_e>B_e.
\]

For an exact quotient-six inverse event the branch windows normally already force `q>p` and intrinsic viability, but a standalone interval implementation should test both rather than relying on undocumented upstream filtering.

### 3.2 Exact critical cutoff

Assume `d_e>0` and `A_e<=B_e`.  The interval first becomes nonempty precisely when

\[
A_e\le Jd_e-1,
\]

or

\[
Jd_e\ge A_e+1.
\]

Therefore

\[
J_e^{\rm crit}
 =\min\{J\in\mathbb Z_{\ge1}:Jd_e\ge A_e+1\}
 =\left\lfloor\frac{A_e}{d_e}\right\rfloor+1.
\]

This is event-specific: two events with the same lower endpoint can have different critical cutoffs because they have different gaps `q-p`.

### 3.3 Saturation cutoff

The far-gap cap ceases to truncate the intrinsic interval when

\[
Jd_e-1\ge B_e.
\]

Thus

\[
\boxed{
J_e^{\rm sat}
 =\left\lfloor\frac{B_e}{d_e}\right\rfloor+1.}
\tag{8}
\]

The exact number of legal integer scales for one event is

\[
|I_e(J)|
 =\left[\min\{B_e,Jd_e-1\}-A_e+1\right]_+,
\]

and hence

\[
|I_e(J)|=
\begin{cases}
0,&J<J_e^{\rm crit},\\
Jd_e-A_e,&J_e^{\rm crit}\le J<J_e^{\rm sat},\\
B_e-A_e+1,&J\ge J_e^{\rm sat}.
\end{cases}
\tag{9}
\]

The first legal scale is always `A_e`; `J` never changes that lower endpoint.

### 3.4 Literal implementation

A correct integer implementation is

```text
# t is already the unified coordinate.
R = 6*q + t
d = q - p
A = max(3*p, (R + 1)//2)     # ceil(R/2)
B = min(7*p - 1, R - 1)

if d <= 0 or A > B:
    event is never legal
else:
    Jcrit = A//d + 1
    Jsat  = B//d + 1
    legal_at_J = (J >= Jcrit)
    Tmax_at_J = min(B, J*d - 1)
```

For a plus event stored with the original coordinate `v`, replace the first line by

```text
t = q - 1 - v
R = 6*q + t
```

and retain the branch tag even though it no longer appears in the interval endpoints.

## 5. The finite first-hit staircase

Let `E_X` be the exact finite inverse-event bank used by the scan, restricted to prime `q` and whatever height bound `X` was imposed.  Define

\[
F_X(J)
 :=\min\{A_e:e\in E_X,\ A_e\le B_e,\ J\ge J_e^{\rm crit}\},
\]

with `F_X(J)=+infinity` when no event is active.

Then `F_X` is a nonincreasing integer staircase.  An event activation can do one of three things:

1. lower the staircase if its `A_e` is a new record;
2. leave the staircase unchanged if `A_e` is above the current record;
3. tie the staircase if another event has the same `A_e`.

Therefore a plateau does **not** mean that no events activated.  It says only that no newly active event had a smaller lower endpoint.

For the supplied values,

```text
J=22:   the first active record is A=95209;
J=32:   a lower record A=37462 has become active;
J=42:   a lower record A=22002 has become active;
J=50:   no active event has A<22002;
J=64:   a lower record A=3809 has become active;
J=100:  no active event has A<3809.
```

Nothing in the repeated values proves that the same literal event remains the unique winner.  There can be sign duplicates, several events with the same endpoint, or nonwinning activations inside either plateau.

## 9. Asymptotic meaning

### 9.1 What is asymptotically reusable

The following are exact, scale-uniform facts:

```text
correct event interval:          (1)-(2)
critical cutoff:                 Jcrit=floor(A/(q-p))+1
saturation cutoff:               Jsat=floor(B/(q-p))+1
uniform empty range:             J<=21
finite first-hit lower envelope: (4)
```

These formulas are legitimate inputs to a future asymptotic count.  In particular, the natural asymptotic statistic is the distribution of

\[
\frac{A_e}{q-p},
\]

because that ratio determines which inverse events survive at a fixed `J`.

### 9.2 What is not asymptotic

The six numerical observations are not asymptotic for several independent reasons.

1. **Finite box.** They are minima over one bounded event bank.  Enlarging the prime/height bound may introduce a new event with a smaller endpoint or a different critical ratio.
2. **Extreme-value statistic.** A first minimum records one event and suppresses the other event counts.  It gives no density, first moment, second moment, or covariance estimate.
3. **Artificial stabilization.** Every finite bank eventually admits all intrinsically viable events.  Its first-hit function then stabilizes at the smallest `A_e` in that finite bank.  The plateau from `64` to `100` may be only this finite-bank effect.
4. **One event has bounded `T` support.** A fixed event contributes only on the finite intrinsic interval `[A_e,B_e]`.  Its persistence as `J` increases does not produce a family as `T` tends to infinity.
5. **Prime-q versus marked incidence.** A prime upper characteristic without `q|b_t` is not an actual q6 upper-zero event.
6. **No uniform count.** The observations do not bound how many events have `Jcrit<=J`, how that number grows with the search height, or how upper marks distribute among them.

To obtain an asymptotic conclusion one would need, at minimum, an expanding and provably complete family `E_X`, quantitative control of

\[
\#\{e\in E_X:J_e^{\rm crit}\le J\},
\]

and—if actual q6 hits are intended—the upper-marked subcount.  A useful theorem would concern this count uniformly as `X` tends to infinity for fixed `J>21`, not the smallest `T` found in one finite box.
