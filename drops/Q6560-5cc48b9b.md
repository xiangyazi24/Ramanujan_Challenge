# Verdict

The proposed Radon spectrum has an unconditional L2 statement, but it is weaker than the desired local spectral flattening. The exact second moment reduces to a value-collision problem for the functions

```
D_h(r)=b_r c_{r+h}-b_{r+h}c_r.
```

For fixed small h, D_h is a rational-unit multiple of the gap continuant N_h. Weil bounds can therefore handle the fixed-h slices once the off-diagonal component of f_h(x)-f_h(y) is geometrically non-degenerate. The remaining obstacle is not the existence of trace cancellation but the uniform summation over h.

# 1. Exact second moment identity

Define

```
F(t,xi)=sum_{h=1}^{p-1} sum_{0<=r<p-h} e_p(t D_h(r)+xi h).
```

Orthogonality gives

```
sum_{t,xi}|F(t,xi)|^2
 = p^2 sum_h #{(r,r'): D_h(r)=D_h(r')}.
```

Proof:

Expanding the square gives

```
sum_h sum_r sum_{h',r'} e_p(t(D_h(r)-D_{h'}(r')))
                         e_p(xi(h-h')).
```

The xi sum forces h=h', and the t sum forces D_h(r)=D_h(r').

Thus the problem is exactly the collision energy of the value maps r -> D_h(r).

# 2. Relation between D_h and N_h

The projective orbit satisfies

```
pi(r)=[b_r:c_r].
```

The Casoratian is

```
b_{n+1}c_n-b_nc_{n+1}= -1/n^3.
```

The gap polynomial is the Dirichlet determinant

```
N_h(x)=P(x+h)N_{h-1}(x)-(x+h)^6N_{h-2}(x).
```

The exact propagation identity is

```
D_h(r)=b_r c_{r+h}-b_{r+h}c_r
     = U_h(r) N_h(r),
```

where the normalization factor is the reciprocal of the product of the transfer denominators:

```
U_h(r)= 1 / ((r+1)(r+2)...(r+h))^3
```

up to the fixed sign convention for the companion solution. Equivalently, after clearing denominators,

```
((r+1)...(r+h))^3 D_h(r)= +/- N_h(r).
```

Hence for r away from the transfer singularities, value collisions of D_h are value collisions of a rational function f_h(x), not just roots of N_h.

# 3. Fixed h Weil estimate

Let

```
f_h(x)=D_h(x).
```

Then

```
D_h(x)-D_h(y)=(x-y)G_h(x,y).
```

The diagonal contributes p points. If the residual curve

```
G_h(x,y)=0
```

has no absolutely irreducible component over F_p, the Weil bound gives

```
#{(x,y):D_h(x)=D_h(y)}
 <= p + O(deg(G_h)^2 sqrt(p)).
```

For Apéry gap polynomials the required check is finite for any fixed h. Symbolic computation can verify h<=6 directly by factoring G_h over Q and reducing mod p outside a finite exceptional set.

Therefore for fixed h:

```
Collision(h)=p+O_h(sqrt(p)).
```

Consequently any fixed set of h-values satisfies

```
sum_h Collision(h)= (#h)p + O(sum_h deg(h)^2 sqrt(p)).
```

If h<=p^delta and degree growth is polynomial, the error is lower order only for sufficiently small delta.

# 4. Large h and random prediction

For large h, D_h is not a bounded-degree polynomial family. The natural statistic is new: it is not projective collision energy.

Projective energy counts

```
pi(r)=pi(s).
```

Radon value energy counts

```
D_h(r)=D_h(s).
```

The second allows many pairs with different projective points, so it is independent information.

Random model:

For fixed h, treat D_h(r) as approximately uniform in F_p. There are p-h samples. Then

```
E Collision(h)
 = (p-h) + ((p-h)(p-h-1))/p
```

because the diagonal always contributes and off-diagonal pairs collide with probability 1/p.

Thus

```
E Collision(h)=2p-2h+O(1).
```

The total prediction is

```
sum_h Collision(h) ~ 2 sum_h(p-h).
```

This is the numerical test to run. Compare:

```
C_h = #{(r,r'):D_h(r)=D_h(r')}

C_h/(2(p-h))
```

against 1, separating the forced projective collisions.

# 5. What L2 buys

The L2 theorem is useful as evidence that a bounded-conductor trace layer may exist. It is a necessary consistency check for a future sheaf/trace-function interpretation.

It does NOT directly give the maximum Fourier bound needed for GAP-TIME-FEJER.

L2 gives

```
sum_k |F(k)|^2 <= M.
```

A maximum bound requires an amplification mechanism:

1. higher moments

```
sum_k |F(k)|^{2m}
```

with m large enough to beat the frequency count;

2. a Burgess-type iteration exploiting multiplicative/additive structure;

3. a genuine trace-function large sieve with bounded conductor.

Without one of these, a single exceptional frequency may carry the whole L2 mass.

# 6. Relation to GAP-TIME-FEJER

The LSF target requires local arc flattening:

```
(1/p) sum_{k in J} A_p(k)
 <= N|J|/p + Cp^eps.
```

The Radon L2 identity controls the global average of Fourier mass, not its distribution in short arcs.

The missing step is exactly:

```
energy bound -> local spectral flattening.
```

This is a local uncertainty statement and is not automatic from Parseval.

# Final answers

## (a) Least certain step

The weakest point is the uniform extension from fixed-h Weil geometry to the growing family h up to p^delta. Fixed h is algebraic geometry; growing h requires uniform control of degree, exceptional factors, and possible hidden components of D_h(x)-D_h(y).

## (b) Possible shared blind spot

The likely shared blind spot is assuming that the projective collision geometry and the Radon value geometry are the same object. They are not. The map

```
r -> pi(r)
```

controls zeros of determinants, while

```
r -> D_h(r)
```

is a scalar observable whose fibers can collide without projective return.

The Radon route is therefore a separate statistical layer. Its L2 theorem is plausible and useful, but the missing theorem remains a genuine local spectral flattening statement, not merely more collision counting.
