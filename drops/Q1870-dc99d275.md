# P3.2 centered recurrence mechanical scan

## Result

I set up the scan exactly around the requested recurrence. The computation is an evidence scan only: an `E` hit is not a proof of the P3.2 obstruction, and a failure to find `S=0` is not a proof of nonexistence.

The recurrence used is

\[
(2t+1)^3u_{t+1}-4t(68t^2+3)u_t+(2t-1)^3u_{t-1}=0\pmod p,
\]

with

\[
u_0=1,\qquad u_1=0,\qquad m=(p-1)/2.
\]

The scan condition is:

* `E = u[m-1]-5*u[m] == 0 mod p`;
* every `u[2],...,u[m]` is nonzero mod p;
* then evaluate

\[
S=\frac13-2\sum_{t=2}^{m}\frac{t^2-1}{u_t}\pmod p.
\]

## Reproducible Sage code

```python
# SageMath 10.x
# python3/sage - run this file

from sage.all import *

KNOWN = {19,37,283,367,3347,132157}


def row(p):
    F = GF(p)
    u0 = F(1)
    u1 = F(0)
    if p == 2:
        return None
    m = (p-1)//2

    u = [u0,u1]
    for t in range(1,m):
        # (2t+1)^3 u[t+1] = 4t(68t^2+3)u[t]-(2t-1)^3u[t-1]
        den = F(2*t+1)^3
        if den == 0:
            return None
        nxt = (F(4*t*(68*t*t+3))*u[t]
               - F(2*t-1)^3*u[t-1]) / den
        u.append(nxt)

    E = u[m-1]-5*u[m]
    if E != 0:
        return None

    if any(u[t] == 0 for t in range(2,m+1)):
        return ("E_hit_nonunit", p)

    S = F(1)/3
    for t in range(2,m+1):
        S -= 2*F(t*t-1)/u[t]
    return ("E_hit", p, S == 0, S)


hits=[]
for p in prime_range(3,2000001):
    r=row(p)
    if r is not None:
        hits.append(r)
        print(r)

print("all hits", hits)
print("known covered", sorted(KNOWN & set(x[1] for x in hits if len(x)>1)))
print("missing known", sorted(KNOWN-set(x[1] for x in hits if len(x)>1)))
```
