# 5. The actual-Apéry saturation theorem

Here is the precise class for which I claim saturation.

Call `L_loc` the class of deductions obtained as follows.

1. The sequence is always the **actual Apéry sequence** `b_n` with `b_0=1,b_1=5`.
2. At one marked prime `p`, one may use the exact recurrence at indices strictly below `p`, invert only factors known to be `p`-units, and use its exact transfer/continuant consequences.
3. At that same prime one may use Apéry reflection, the one-digit Cartier/Lucas law, and exact continuant/Casoratian/addition identities.
4. One may take arbitrary ring consequences inside that one residue field.
5. For pairwise distinct marked primes, one may combine already-proved integer divisibilities by ordinary addition/multiplication and CRT.  No theorem about correlations of prime supports at *different moduli* is inserted as an extra axiom.

This class includes all recurrence/reflection/Frobenius/Casoratian attacks explicitly requested in the question, but deliberately does not smuggle in the missing cross-prime distribution theorem.

### Saturation theorem

Let `Cycle_N(A,u,v,q)` be an actual selected alternating cycle in the physical range of Section 2.  In `L_loc`:

```text
at p_0: the saturated endpoint-return generator is N_v(A)
at p_1: the saturated endpoint-return generator is N_u(A)
at p_2: the saturated endpoint-return generator is N_v(A+u)
at p_3: the saturated endpoint-return generator is N_u(A+v).
```

Reflection replaces each generator by a unit multiple at the reflected interval.  Cartier adds no second digit.  Every connected continuant identity stays in the corresponding rank-one transfer module.  Consequently, after marking

```text
M = p_0*p_1*p_2*p_3,
```

the complete congruence algebra supplied by `L_loc` is componentwise under

```text
Z/MZ  ~=  F_(p_0) x F_(p_1) x F_(p_2) x F_(p_3).
```

Therefore any multi-prime divisibility obtained in `L_loc` is a CRT product of prime-local consequences (possibly applied to the same actual integer, as in the shared reflected source carrier).  There is no additional nonseparable marked-prime Fitting factor that can tell us, for example, that a prime factor of `gcd(b_A,b_(A+v))` must be separated by exactly `u` from a prime factor of `gcd(b_(A+u),b_(A+u+v))`.

### Proof

The principal local generator statement is Section 3.1: after recurrence elimination the endpoint equation is `N_h(r)*Y_1=0`, and saturation by the actual nonzero `Y_1` gives `(N_h(r))`.

Reflection preserves that principal ideal because

```text
N_h(p-1-r-h) == (-1)^(h-1)N_h(r) (mod p),
```

and the multiplier is a unit.  Cartier is the identity on one-digit indices.  Casoratian and addition identities are identities inside the already solved transfer module and hence cannot increase its rank.

Finally CRT is an isomorphism of rings.  Every permitted operation after passing to `Z/MZ` is performed coordinatewise.  Thus a derivation can multiply independently known prime factors into one integer divisibility, but it cannot create a relation between the *locations of prime factors in the four actual integer supports* unless such a relation was supplied before the CRT step.  This proves the stated saturation.

No fake sequence or arbitrary-multiple model occurs in this proof: all local equations are equations for the actual `b_n`.  The theorem is about the closure of a specified set of true Apéry identities.

# 6. Exact actual-Apéry prime-support gate for the full four-cycle

```text
Pi_(n,N)(T)

```

This is a monic squarefree polynomial in `Z[T]`.  For two indices put

```text
D_(r,s,N)(T) = gcd_monic(Pi_(r,N)(T), Pi_(s,N)(T)).
```

Its integer roots are exactly

```text
{ell prime : N < ell <= 2*N, ell | b_r, ell | b_s}.
```

For fixed `A,u,v`, define

```text
E0(T) = D_(A,       A+v,       N)(T)
E1(T) = D_(A,       A+u,       N)(2*T-2*A-1)
E2(T) = D_(A+u,     A+u+v,     N)(T+u)
E3(T) = D_(A+v,     A+u+v,     N)(2*T-2*A-2*v-1)

J_(A,u,v,N)(T) = gcd_monic_Q[T](E0,E1,E2,E3).
```

Although `E1,E3` need not be monic after the affine substitution, `J` is normalized monic over `Q`.  Because it divides `E0`, which splits into factors `T-q` with integer prime roots, `J` in fact lies in `Z[T]` and is a product of a subset of those linear factors.

### Exact gate theorem

For every integer quadruple satisfying `Geom_N(A,u,v,q)`,

```text
Cycle_N(A,u,v,q)
  <=>
J_(A,u,v,N)(q) = 0.
```

Proof, direction by direction:

- `E0(q)=0` means `q=p_0` is a shell prime dividing both `b_A` and `b_(A+v)`.
- `E1(q)=0` means `p_1=2q-2A-1` is a shell prime dividing both `b_A` and `b_(A+u)`.

# 9. Why this does not secretly prove (A)

There are c-free integer carriers, but their height is wrong.

The raw local product is

```text

 = N_v(A) * N_u(A) * N_v(A+u) * N_u(A+v),

p_0*p_1*p_2*p_3 | H_loc.
```

The checkerboard actual-Apéry carrier is

```text
D_square
 = b_A*b_(A+u+v) - b_(A+u)*b_(A+v),

p_0*p_1*p_2*p_3 | D_square.
```

Both are c-independent and retain all four primes, but both retain the base-label height.

The fixed-exponent normalization does not remove this for a balanced word.  Already at gap two,

```text

normalized gap-2 value = P(A+1)/(A+2)^3.
```

Writing `y=A+2`,

```text

```

Any common prime divisor of `P(A+1)` and `A+2` is `5`; a short 5-adic check gives

```text
gcd(P(A+1),(A+2)^3) | 5^3.
```

Hence the reduced denominator is at least

```text
(A+2)^3 / 125,
```

so clearing even this single normalized local return costs

```text
3*log(A+2) - O(1).
```

For the alternating rectangle the total label variation is only

```text

```

Thus the present normalization architecture cannot give the height required in (A), namely `O(u+v+1)`, uniformly in the free base `A`.  Actual selectedness may still imply a deeper prime-support theorem that effectively removes the base, but that theorem is exactly outside the saturated prime-local class and is represented by `[BAL-SOURCE]`/`J` above.

```python
# q2125_continuant_regression.py
import sympy as S

x,A,u,c = S.symbols('x A u c')
P = lambda z: 34*z**3 + 51*z**2 + 27*z + 5

N = [S.Integer(0), S.Integer(1)]
H = 7
for h in range(1,H):
    N.append(S.expand(P(x+h)*N[h] - (x+h)**6*N[h-1]))

for h in range(1,H+1):
    refl = S.expand(N[h].subs(x,-x-h-1) - (-1)**(h-1)*N[h])
    assert refl == 0, ('reflection',h,S.factor(refl))

for h in range(1,H+1):
    F = S.expand(N[h].subs(x,A+c-h-1))
    r0 = S.resultant(c+2*A,F,c)
    want0 = (-1)**(h-1)*N[h].subs(x,A)
    assert S.expand(r0-want0) == 0

    r2 = S.resultant(c+2*A+u,F,c)
    want2 = (-1)**(h-1)*N[h].subs(x,A+u)
    assert S.expand(r2-want2) == 0

print('Q2125 continuant reflection/resultant regressions: PASS')
```

## 10.3 Finite checker for the **actual-Apéry** support gate

This checker computes the actual Apéry integers, actual shell prime supports, and verifies the set-theoretic gate.  It does not replace the proof, and observing finitely many shells says nothing asymptotic.

```python
# q2125_actual_support_gate_check.py
from sympy import isprime, factorint


def P(n):
    return 34*n**3 + 51*n**2 + 27*n + 5


def apery(M):
    b = [1,5]
    for n in range(1,M):
        num = P(n)*b[n] - n**3*b[n-1]
        den = (n+1)**3
        assert num % den == 0
        b.append(num//den)
    return b


def shell_support(z,N):
    return {p for p in factorint(abs(z)) if N < p <= 2*N and isprime(p)}


def geom(N,A,u,v,q):
    ps = [q, 2*q-2*A-1, q+u, 2*q-2*A-2*v-1]
    return (
        A >= 0 and u > 0 and v > 0
        and len(set(ps)) == 4
        and all(N < p <= 2*N and isprime(p) for p in ps)
        and A+u+v < min(ps)
    )


def selected(b,A,u,v,q):
    p0,p1,p2,p3 = q,2*q-2*A-1,q+u,2*q-2*A-2*v-1
    return (
        b[A] % (p0*p1) == 0
        and b[A+u] % (p1*p2) == 0
        and b[A+u+v] % (p2*p3) == 0
        and b[A+v] % (p3*p0) == 0
    )


def gate(b,N,A,u,v,q):
    S0 = shell_support(b[A],N) & shell_support(b[A+v],N)
    S1 = shell_support(b[A],N) & shell_support(b[A+u],N)
    S2 = shell_support(b[A+u],N) & shell_support(b[A+u+v],N)
    S3 = shell_support(b[A+v],N) & shell_support(b[A+u+v],N)
    p0,p1,p2,p3 = q,2*q-2*A-1,q+u,2*q-2*A-2*v-1
    return p0 in S0 and p1 in S1 and p2 in S2 and p3 in S3


def source_gate(b,N,A,u,v,q):
    S0 = shell_support(b[A],N) & shell_support(b[A+v],N)
    S2 = shell_support(b[A+u],N) & shell_support(b[A+u+v],N)
    return q in S0 and q+u in S2

# Finite regression only.
N = 37
M = 2*N
b = apery(M)
for A in range(M):
  for u in range(1,M-A):
    for v in range(1,M-A-u):
      for q in range(N+1,2*N+1):
        if geom(N,A,u,v,q):
            assert selected(b,A,u,v,q) == gate(b,N,A,u,v,q)
            if selected(b,A,u,v,q):
                assert source_gate(b,N,A,u,v,q)

print('Q2125 actual-Apery support-gate finite regression: PASS')
```
