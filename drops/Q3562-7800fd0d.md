# P3.2 — shifted intersection as a cross-characteristic character sum

## Verdict

There is **no existing Katz / Fouvry–Kowalski–Michel theorem that directly bounds the q=6 two-prime sum at the scale needed here**.

The closest theorem is Fouvry–Kowalski–Michel, **“A study in sums of products”**, Theorem 1.5 / Corollary 1.6. It proves square-root cancellation for products of bounded-conductor trace functions

```text
sum_{x in F_p} K_1(gamma_1 x) ... K_k(gamma_k x) e_p(hx)
```

under the Goursat–Kolchin–Ribet independence condition, except for classified diagonal cases. But every factor in that theorem lives on the **same finite field F_p**. Our collision has one factor in characteristic `p` and one in characteristic `q`.

That mismatch is not cosmetic. There is no common geometric fiber on which one can form the tensor product used in the FKM proof:

```text
Spec(F_p) x_{Spec Z} Spec(F_q) = empty       (p != q),
```

because

```text
F_p tensor_Z F_q = 0.
```

One can package the two local functions arithmetically modulo `pq` by the Chinese remainder theorem, but `Spec(Z/pqZ)` is just the disjoint union of the `p`- and `q`-fibers. It creates **no mixed monodromy**. Complete sums factor into local complete sums; it does not create a new Deligne theorem coupling the two characteristics.

Moreover, there is an earlier obstruction before this cross-characteristic issue: Q2493's Mellin formula is linear in `b_r`, whereas the exact zero detector introduces

```text
e_p(u b_r).
```

The map

```text
b_r = Mellin_p(r)
        -->
exp(2 pi i u Mellin_p(r)/p)
```

is a nonlinear second Fourier layer. The fact that `b_r` is a Mellin coefficient of a bounded-geometric-complexity object does **not** imply that

```text
r |--> e_p(u b_r)
```

is itself a bounded-conductor trace function uniformly in `p`. The current repository in fact records the opposite for the natural direct realization: the Artin–Schreier sheaf associated with the interpolation polynomial for `r -> b_r mod p` has Swan conductor of order `p`, so its Deligne bound is essentially trivial.

Even under the optimistic fiction that both local factors were bounded-conductor trace functions, CRT completion gives only

```text
|S_{p,q}| << sqrt(pq) log(pq),
```

for an interval sum. In the collision range `p~q~X`, the interval length is at most `X`, while `sqrt(pq)~X`. Thus this is at the Pólya–Vinogradov barrier and gives **no power saving**. Near the geometric edge `q -> 7p/6`, the actual overlap interval is even shorter, so the situation worsens.

So the proposed route does identify the correct missing analytic object, but it does **not** fall under an existing tensor-product / Rankin–Selberg theorem. What is needed is genuinely new: an **averaged cross-characteristic pair-correlation theorem** for the actual Apéry zero/Mellin family.

# 1. First correct the exact q=6 collision orientation

Let

```text
Z_p = {0 <= r < p : b_r = 0 mod p}.
```

For `p<q`, a q=6 pair collision means

```text
6p + r_p = 6q + r_q,
```

with

```text
r_p in Z_p,
r_q in Z_q.
```

Hence

```text
r_p-r_q = 6(q-p).
```

Put

```text
d = 6(q-p) > 0.
```

Then the exact shifted intersection is

```text
C(p,q)
 = #{ r : 0 <= r < p-d,
          q | b_r,
          p | b_(r+d) }.
```

Equivalently, after reversing the role of the dummy variable,

```text
C(p,q)
 = #{ r : d <= r < p,
          p | b_r,
          q | b_(r-d) }.
```

So the formula in the question with

```text
p | b_r,
q | b_(r+d)
```

has the shift orientation reversed for `p<q`; this is harmless if one replaces `d` by `-d` or swaps `p,q`, but it matters for the physical support.

The overlap length is not `min(p,q)` in general. It is

```text
L_{p,q}=p-d=p-6(q-p)=7p-6q.
```

Thus

```text
C(p,q)=0 unless q<7p/6,
```

recovering the exact geometric restriction from Q3554.

# 2. Exact additive-character expansion

For an integer `x`,

```text
1_{p|x} = (1/p) sum_{u mod p} e_p(ux).
```

Therefore

```text
C(p,q)
 = 1/(pq)
   sum_{u mod p}
   sum_{v mod q}
   S_{p,q}(u,v),
```

where

```text
S_{p,q}(u,v)
 := sum_{0 <= r < L_{p,q}}
      e_q(u? b_r) e_p(v? b_(r+d)).
```

With variables assigned to their own characteristics, the clean convention is

```text
S_{p,q}(a,b)
 := sum_{0 <= r < L_{p,q}}
      e_q(a b_r)
      e_p(b b_(r+d)),

C(p,q)
 = 1/(pq) sum_{a mod q} sum_{b mod p} S_{p,q}(a,b).
```

The zero-zero frequency contributes

```text
L_{p,q}/(pq) ~ 1/X
```

when `p,q~X`. That is exactly the random pair-intersection scale. The one-zero frequencies measure the individual value biases. The nonzero-nonzero block is the genuinely new two-prime correlation.

This Fourier identity is exact. The difficulty is bounding the **whole frequency average**, not merely one `S_{p,q}(a,b)`.

# 3. Why a pointwise Weil bound for `S_{p,q}(a,b)` would still not be enough

Suppose unrealistically that for every nonzero pair `(a,b)` we had the very strong estimate

```text
|S_{p,q}(a,b)| << sqrt(L_{p,q}).
```

Taking absolute values in the zero-detector expansion gives

```text
C(p,q)
 <= L/(pq)
    + (1/pq) * (pq) * O(sqrt L)
 << sqrt L.
```

For `L~X`, this gives `C(p,q)<<sqrt X`, whereas the desired random scale is about `1/X` and even the trivial integrality-scale target is `O(1)`.

So **individual square-root cancellation in the r-sum is not remotely strong enough once all `pq` additive frequencies are summed absolutely**.

The same obstruction appears through Cauchy–Schwarz. Put

```text
S(a,b)=sum_r e_q(a b_r)e_p(b b_(r+d)).
```

Then orthogonality gives

```text
sum_{a mod q}
sum_{b mod p}
|S(a,b)|^2
 = pq * #{(r,s):
            b_r=b_s mod q,
            b_(r+d)=b_(s+d) mod p}.
```

The diagonal `r=s` already contributes `pq L`. Consequently Cauchy over the `pq` frequencies naturally loses at least a factor `sqrt L`. This is essentially another form of the collision-energy problem itself.

Thus the route needs cancellation **across the additive frequencies and/or across the prime pair `(p,q)`**, not merely Deligne cancellation for each fixed frequency.

# 4. The first major mismatch with Q2493: exponential of a Mellin coefficient

The current pushed Mellin formulation (`problems/3.2/ORACLE_COMM/chatgpt_q32_horizontal_mellin_sieve_corrected.md`) gives, for interior residues,

```text
M_p(m) = -b_r mod p,

m = q(p-1)+r,
```

where `M_p(m)` is a Mellin coefficient of the fixed primitive Apéry K3 trace system twisted by the Teichmuller/Kummer character of exponent `m`.

Schematically,

```text
b_r mod p
   = sum_{x in F_p^*} theta_p(x) omega_p(x)^r.
```

This is exactly the right linear Mellin organization.

However the zero detector does not ask for a linear expression in `b_r`. It asks for

```text
e_p(a b_r)
 = e_p(a M_p(r)).
```

Opening the Mellin sum inside the additive exponential does **not** produce a fixed four-dimensional character sum in the way opening a product `b_r b_s` does. In general

```text
e_p(a * sum_x F(x))
```

is not

```text
sum_x e_p(a F(x)).
```

It is an additive character applied to the **total trace value**. Equivalently, one has taken the residual Mellin trace and then applied a second Fourier transform to its value distribution.

That second transform is precisely the local-limit observable that the existing Katz theory does not control at `1/p` resolution.

So the implication

```text
b_r has a bounded-complexity Mellin formula
=> r |-> e_p(a b_r) is a bounded-conductor trace function
```

is false as a formal inference and is not presently a theorem in the project.

The current submission records the natural direct geometric realization of

```text
r |-> e_p(h b_r)
```

as an Artin–Schreier sheaf associated with the interpolation polynomial of the first block. Its Swan conductor is of order `p`, so Grothendieck–Ogg–Shafarevich gives only a bound on the order of `p^(3/2)` before normalization—the trivial scale. Thus the obvious one-prime sheaf already has growing conductor.

Q2493's Mellin reorganization is valuable because it replaces this large-degree interpolation polynomial by fixed geometry **before applying the zero detector**. But the nonlinear zero detector creates the same missing local-limit step again.

# 5. The closest Katz/FKM theorem: same-characteristic sums of products

The sharpest directly relevant classical statement is:

## Fouvry–Kowalski–Michel, “A study in sums of products”

Reference:

```text
É. Fouvry, E. Kowalski, Ph. Michel,
A study in sums of products,
arXiv:1405.2293.
```

Theorem 1.5 / Corollary 1.6 says, roughly, that if `K` is the trace function of a bounded-conductor “bountiful” sheaf on `A^1/F_p`, then outside explicitly classified diagonal configurations,

```text
sum_{x in F_p}^*
   K^{sigma_1}(gamma_1 x)...K^{sigma_k}(gamma_k x)
   e_p(hx)
   <<_{k,cond(K)} sqrt(p).
```

The proof forms the tensor product

```text
(gamma_1^* F^{sigma_1}) tensor ... tensor (gamma_k^* F^{sigma_k})
```

on `A^1/F_p`, uses the Goursat–Kolchin–Ribet criterion to show there is no geometric invariant, and then applies Deligne's Riemann Hypothesis over **that one finite field**.

This theorem is conceptually exactly what we would like: if both Apéry factors lived over the same `F_p`, it would be the natural tool for proving a shifted correlation bound.

But our factors are

```text
K_{p,a}(r) = e_p(a b_r),
K_{q,b}(r+d) = e_q(b b_(r+d)).
```

There is no sheaf on one `A^1/F_l` whose two tensor factors are these two functions for `p!=q`.

So FKM Theorem 1.5 is the **nearest theorem, and also the cleanest explanation of exactly why the present sum lies outside the standard formalism**.

Reference URL:

```text
https://arxiv.org/abs/1405.2293
```

# 6. Why the literal tensor product over `Spec Z` does not exist in the desired sense

Suppose `F_p` is a sheaf giving a local trace function in characteristic `p`, and `G_q` one in characteristic `q`.

The naive phrase

```text
F_p tensor G_q over Spec Z
```

suggests a common geometric fiber. But

```text
Spec(F_p) x_{Spec Z} Spec(F_q)
 = Spec(F_p tensor_Z F_q)
 = empty,
```

because for distinct primes

```text
Z/p tensor_Z Z/q = 0.
```

Thus there is no point `r` in a common finite-field fiber on which a Frobenius trace of `F_p tensor G_q` can be evaluated.

The arithmetic replacement is

```text
Z/pqZ ~= Z/pZ x Z/qZ.
```

Geometrically,

```text
Spec(Z/pqZ)
 = Spec(F_p) disjoint_union Spec(F_q).
```

A sheaf on this disjoint union is just the independent pair `(F_p,G_q)`. There is no Goursat monodromy group linking them. Deligne can be applied to the two prime pieces separately, but there is no new cross-characteristic Riemann Hypothesis.

This is why “horizontal Rankin–Selberg” is a useful analogy but not an available tensor construction here.

For a genuine compatible system over `Spec Z[1/S]`, one can compare Frobenius conjugacy classes at different primes statistically, and Frobenius large-sieve/Chebotarev methods exploit that. But our observable is not simply

```text
trace(Frob_p) * trace(Frob_q)
```

for one fixed compatible representation. It is

```text
b_{r_p} mod p
and
b_{r_q} mod q,
```

with the coefficient/Mellin index moving with the defining characteristic. The same prime is simultaneously the field characteristic, the modulus of the zero condition, and part of the moving index. That is the project’s defining-prime quantifier obstruction.

# 7. What CRT *can* do in an ideal bounded-conductor model

There is still a useful calculation because it shows that even an ideal same-quality local theorem would hit the wrong scale.

Assume for the moment that `K_p` and `K_q` are normalized bounded-conductor trace functions modulo `p` and `q`, with all additive Fourier transforms bounded by

```text
|Khat_p(h)| << sqrt(p),
|Khat_q(k)| << sqrt(q).
```

Define the CRT product modulo

```text
M=pq
```

by

```text
K_M(x)=K_p(x mod p)K_q(x+d mod q).
```

For a complete additive twist modulo `M`, CRT factorization gives

```text
sum_{x mod M} K_M(x)e_M(hx)
 = (local p complete sum)*(local q complete sum),
```

up to the usual CRT rescaling of `h` in the two local additive characters. Hence

```text
|complete sum| << sqrt(pq)=sqrt(M).
```

Completion of an interval of length `L` then gives the standard Pólya–Vinogradov-type estimate

```text
sum_{r<L} K_p(r)K_q(r+d)
 << sqrt(M) log M.
```

But for the q=6 collision range

```text
p~q~X,
M~X^2,
sqrt(M)~X,
L=7p-6q <= p~X.
```

Therefore

```text
sqrt(M) log M ~ X log X,
```

while the trivial bound for a bounded function is

```text
O(L) <= O(X).
```

Completion is therefore **not nontrivial**. It lands precisely at the square-root-of-modulus boundary.

Near `q=7p/6`, `L` can be much smaller than `X`, making completion still worse relative to the interval length.

So even if the Apéry zero-detector functions had uniformly bounded conductor—which they currently do not—plain CRT + Deligne would not prove the desired pair correlation.

# 8. Why the recent bilinear trace-function theorems still do not apply

There are two especially relevant later results.

## 8.1 Kowalski–Michel–Sawin: bilinear Kloosterman sums

Reference:

```text
E. Kowalski, Ph. Michel, W. Sawin,
Bilinear forms with Kloosterman sums and applications,
arXiv:1511.01636.
```

and the later stratification paper

```text
E. Kowalski, Ph. Michel, W. Sawin,
Stratification and averaging for exponential sums:
bilinear forms with generalized Kloosterman sums,
arXiv:1802.09849.
```

These beat Pólya–Vinogradov for certain bilinear sums, but the basic architecture is

```text
sum_m sum_n alpha_m beta_n K(mn; ell)
```

with **one fixed prime modulus `ell`**. The two long variables `m,n` provide analytic averaging, while all the geometric complete sums live in `F_ell`.

Our object has one short variable `r` and two different moduli `p,q`. The pair `(p,q)` labels the characteristics rather than giving two bilinear variables inside one finite field. The KMS theorem therefore does not type-check for the present sum.

## 8.2 Fouvry–Kowalski–Michel–Sawin 2025/2026

The newest general result is

```text
É. Fouvry, E. Kowalski, Ph. Michel, W. Sawin,
Bilinear forms with trace functions,
arXiv:2511.09459.
```

It obtains nontrivial bilinear bounds below the Pólya–Vinogradov range for very general trace functions, under robust geometric-monodromy hypotheses.

This is stronger and more flexible than the earlier Kloosterman-only work, but it still has the same essential shape: **one trace function modulo one fixed prime**, evaluated on a genuine two-variable bilinear configuration. It does not give a theorem for

```text
sum_r K_p(r) K_q(r+d),       p != q.
```

So even the 2025/2026 state of the art does not remove the cross-characteristic mismatch.

Reference URLs:

```text
https://arxiv.org/abs/1511.01636
https://arxiv.org/abs/1802.09849
https://arxiv.org/abs/2511.09459
```

# 9. Do not misread “Algebraic trace functions over the primes”

Another very close-looking title is

```text
É. Fouvry, E. Kowalski, Ph. Michel,
Algebraic trace functions over the primes,
Duke Math. J. 163 (2014),
arXiv:1211.6043.
```

This theorem studies sums of a trace function modulo a **fixed prime modulus** evaluated at integer arguments which are themselves prime, schematically

```text
sum_{n prime} K(n mod p).
```

The word “primes” refers to the **summation sequence**, not to a simultaneous pair of changing residue characteristics in the trace function. It does not control

```text
K_p(r)K_q(r+d)
```

with `p,q` varying as moduli.

Reference:

```text
https://arxiv.org/abs/1211.6043
```

# 10. Katz Mellin equidistribution is also one-characteristic

Katz's

```text
Convolution and Equidistribution:
Sato–Tate Theorems for Finite-Field Mellin Transforms
```

is structurally very close to the Apéry Mellin package. It constructs a Tannakian convolution category and proves equidistribution of Mellin Frobenius conjugacy classes as multiplicative characters vary.

But the entire family is over **one finite field characteristic at a time**. It gives correlations among character twists inside a fixed `F_p`, not a theorem coupling a twist over `F_p` to a different twist over `F_q`.

More importantly, its equidistribution is an ell-adic/complex distribution statement. Our zero event is the defining-characteristic condition

```text
M_p(r) = 0 mod p.
```

That is a lattice-scale residual event of expected probability `1/p`. Standard Sato–Tate equidistribution does not resolve it.

So Katz supplies the right monodromy language for a hypothetical local theorem, but not the required cross-characteristic/local-limit estimate.

# 11. The closest composite-modulus idea: CRT equidistribution

There is a genuinely relevant arithmetic analogue:

```text
E. Kowalski, K. Soundararajan,
Equidistribution from the Chinese Remainder Theorem,
Adv. Math. 385 (2021), 107776.
```

This develops equidistribution for sets modulo composite moduli assembled from local data by CRT. It is conceptually closer to a product of local prime conditions than the one-field FKM theorem.

However it does not solve the present problem for two reasons.

1. It needs suitable local exponential-sum input. For the Apéry zero detector, the bounded-conductor local input is exactly what is missing.
2. With only two comparable prime factors `p,q` and an interval of length `L<=sqrt(pq)`, the elementary completion calculation above is at the critical Pólya–Vinogradov scale. CRT by itself supplies factorization, not the missing short-interval cancellation.

Thus CRT is a packaging device, not the cross-characteristic independence theorem.

```text
https://doi.org/10.1016/j.aim.2021.107776
```

# 12. What a theorem that *would* solve the q=6 pair energy should look like

Q3554 already isolates the exact deterministic target. For `X` large define

```text
C_{p,q}
 = #{r : 0<=r<7p-6q,
          q|b_r,
          p|b_(r+6(q-p))},
```

for

```text
X<p<q<=2X,
q<7p/6.
```

A direct sufficient averaged theorem is

```text
sum_{X<p<q<=2X, q<7p/6} C_{p,q}
 << X/log^2 X.
```

Under bounded average vertical mass this is the random-position scale and would make the q=6 second moment diagonal-dominated.

The Fourier version that actually has a chance must retain the average over prime pairs and additive frequencies:

```text
sum_{X<p<q<=2X}
  1/(pq)
  sum_{a mod q}
  sum_{b mod p}
  S_{p,q}(a,b)
```

with enough cancellation in the **aggregate**, not after taking absolute values term-by-term.

A more realistic analytic target is therefore a cross-characteristic large-sieve / dispersion inequality, not a pointwise Weil bound for one `(p,q,a,b)`.

For example, one could seek a theorem of the schematic form

```text
sum_{X<p<q<=2X, q<7p/6}
  | C_{p,q} - |Z_p||Z_q|/X |
 << X/log^(1+delta) X,
```

or directly the averaged inequality banked in Q3554,

```text
sum_{X<p<q<=2X, q<7p/6} C_{p,q}
 << (1/X)
    (sum_{X<p<=2X}|Z_p|)^2.
```

This is exactly the missing **horizontal pair-decorrelation theorem**.

# 13. Is there any plausible route from Q2493 to such a theorem?

There are two conceivable routes, neither currently established.

## Route A — construct a genuinely global compatible family

One would need a characteristic-zero / integral object `F` with bounded complexity such that for every prime `p` and every relevant index `r`, the residual quantity

```text
b_r mod p
```

is read from a Frobenius/Mellin coordinate of `F` in a way compatible as `p` varies.

Then one could hope to apply a Frobenius large sieve or a two-place monodromy theorem to pairs `(p,q)`.

The current K3/Mellin theory gets close at the object level, but the character `omega_p^r` itself depends on `p`, and the condition is divisibility by the defining prime. There is no currently banked compatible-system theorem turning that moving character coordinate into a fixed global Frobenius observable.

## Route B — use the explicit Mellin character sums arithmetically, not geometrically

Instead of trying to tensor sheaves across characteristics, open the Q2493 formula all the way and study the prime-pair average as an integer analytic sum over

```text
p, q, internal Mellin variables, r.
```

One would then try Cauchy/Poisson/large-sieve steps until each geometric complete sum is returned to **one characteristic at a time**. This is the only way FKM/KMS technology could plausibly re-enter: after analytic manipulations, the hard complete sums would have to become same-field sums to which their theorems apply.

But there is no automatic four-dimensional Deligne theorem for the original mixed sum. The analytic decomposition itself would be the new theorem, and it must avoid losing the `pq` zero-detector frequencies and the `L~sqrt(pq)` completion barrier.

This is a legitimate research program, but it is not presently a corollary of Q2493.

# 14. Exact interpretation of “horizontal Rankin–Selberg”

The phrase is useful if interpreted carefully.

A classical Rankin–Selberg tensor product couples two representations over the same global Galois group and then studies local Frobenius traces of the global tensor representation.

Here one would need a global object whose local `p`-component carries the moving Mellin coordinate `r_p`, and whose local `q`-component carries `r_q`, with the arithmetic relation

```text
r_p-r_q=6(q-p).
```

No standard tensor product representation encodes this moving-index relation. The relation itself couples the **places** to the **local character labels**.

Thus the genuinely new object would be something like a two-place family

```text
(p,q) |--> (M_p(r_p), M_q(r_q))
```

with uniform product monodromy plus defining-characteristic residual anti-concentration.

That is substantially stronger than ordinary Rankin–Selberg theory and stronger than Katz's one-field Mellin equidistribution.

So I would call the desired theorem

```text
cross-characteristic Mellin pair dispersion
```

or

```text
defining-prime two-place local limit,
```

rather than a theorem already contained in Rankin–Selberg formalism.

# 16. Bottom line for P3.2

The proposed character-sum formulation is still valuable because it identifies the missing theorem in a form that is much closer to modern analytic machinery than a raw zero-set statement.

But the exact conclusion is:

```text
Q2493 linear Mellin formula
    + zero-detector Fourier expansion
    != existing FKM tensor-product theorem.
```

There are **three distinct barriers**:

```text
(1) nonlinear zero detector:
    e_p(a b_r) is not automatically a bounded-conductor Mellin trace;

(2) cross characteristic:
    p-factor and q-factor do not live on one finite-field fiber,
    so Goursat-Kolchin-Ribet/Deligne cannot be applied to their tensor product;

(3) short interval:
    after CRT the modulus is pq~X^2 but the collision interval is L<=X,
    exactly at or below the Pólya-Vinogradov threshold.
```

Therefore the best existing theorem to cite as the **model** is FKM Theorem 1.5, but the theorem actually needed for P3.2 is new:

```text
an averaged cross-characteristic / defining-prime pair-dispersion theorem
for the Apéry Mellin zero family.
```

If such a theorem gives

```text
sum_{X<p<q<=2X, q<7p/6} C_{p,q} << X
```

then Q3554 shows `E_2(N)=O(N)` and hence

```text
K_6(n)=O(sqrt n),
log R_6(n)=O(sqrt n log n)=o(n),
```

which closes the q=6 horizontal radical gate. The random-scale target `O(X/log^2 X)` for the off-diagonal sum would be much stronger, but only `O(X)` is needed for P3.2.
