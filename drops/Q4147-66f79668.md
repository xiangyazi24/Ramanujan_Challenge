# 1. Canonical upper state determines one assigned row/edge at fixed lower prime

Fix a lower prime `p` and one residual physical q6 row. Write its upper prime as `q`, its row index as `n`, and its canonical upper digit/state as

\[
t=n-6q,
\qquad 0\le t<q.
\tag{1.1}
\]

Thus `(q,t)` determines `n=6q+t`. The common natural-tail identity for both signs is

\[
6q+t=7p-z-1,
\]

so the natural lower tail is

\[
\boxed{z=7p-6q-t-1.}
\tag{1.2}
\]

At fixed `(p,q,t)`, the two raw sign candidates are affine and unique. In the reflected lower-support coordinates used by the fixed-state carrier they are

\[
\boxed{a_+=12q+t-13p}
\tag{1.3+}
\]

for plus, and

\[
\boxed{a_-=2p-q+t}
\tag{1.3-}
\]

for minus. These follow directly from the P/M inverse maps; equivalently the unreflected physical partner is reflected by `x -> p-1-x`.

The deterministic minus-first OR assignment makes the physical state `(p,q,t)` belong to exactly one assigned sign/edge when both certificates are formally available. Hence there is a well-defined map

\[
\boxed{
(p,q,t)\longmapsto r(p,q,t)\longmapsto e(p,q,t).
}
\tag{1.4}
\]

There is no extra sign multiplicity at fixed `(p,q,t)`.

This is the exact reason the old bounded physical-fibre issue does not insert a factor two here: the state is fixed *before* sign pooling, and OR assigns the state once.

# 2. Four distinct support edges give four distinct canonical upper states

Let `C` be one residual packed **simple** `C4` at lower prime `p`. Its support edges

\[
e_1,e_2,e_3,e_4
\]

are four distinct edges.

Assume, as required by the current all-occurrence object, that each residual support edge is in the image of the fixed assigned-row map. Choose one actual assigned row

\[
r_i\in A^{-1}(e_i)
\]

for each edge, and let its canonical upper state be

\[
s_i=(q_i,t_i).
\]

## Lemma 2.1 — state injectivity on one lower prime

The four `s_i` are pairwise distinct.

### Proof

Suppose

\[
(q_i,t_i)=(q_j,t_j).
\]

The lower prime is the same `p`, so by (1.2)--(1.4) this is the same physical row state and deterministic OR assigns it to the same support edge. Therefore

\[
e_i=e_j.
\]

Since the `C4` is simple, its four edges are distinct, so `i=j`. QED.

Every actual residual row has upper selectedness at its row digit, so

\[
q_i\mid b_{t_i}.
\]

Thus each `s_i=(q_i,t_i)` is itself an actual upper occurrence. Therefore

\[
\boxed{|N_U(C)|\ge4}
\tag{2.1}
\]

for every residual packed simple `C4`.

### The exact guard

The proof needs `r_i` to be **assigned to `e_i`**. It is not enough that a raw row is geometrically compatible with `e_i`. A raw physical row can in principle carry more than one sign/support certificate before OR; deterministic OR chooses only one assigned edge. Hence the implication

```text
distinct raw support edges
    => choose four raw rows
    => four distinct states
```

is not valid without assigned-fibre surjectivity.

The correct implication is

```text
distinct assigned residual support edges
    => choose one assigned row from each nonempty assigned fibre
    => four distinct states.
```

This is precisely the repaired all-occurrence setting. If the local definition of the residual support graph is the image of the assigned row family, the lemma passes. If it is a broader raw support graph, this would be the first fatal flaw.

# 3. Exact Hall constant: `1/4` and threshold `4R`

Let `\mathcal P` be the residual packed family and let `N_U(C)` be the set of upper occurrence labels available to `C`. For one occurrence `s=(q,u)`, write

\[
d_U(s)=\#\{C\in\mathcal P:s\in N_U(C)\}.
\tag{3.1}
\]

Define the capacity-`R` upper deficiency

\[
\delta_U
:=
\max_{A\subseteq\mathcal P}
\bigl(|A|-R|N_U(A)|\bigr)_+.
\tag{3.2}
\]

By (2.1), every cycle has at least four upper labels. For `A\subseteq\mathcal P`, put

\[
d_s(A)=\#\{C\in A:s\in N_U(C)\}.
\]

Then

\[
\sum_{s\in N_U(A)}d_s(A)
=
\sum_{C\in A}|N_U(C)|
\ge4|A|.
\]

Hence

\[
\begin{aligned}
4\bigl(|A|-R|N_U(A)|\bigr)
&\le
\sum_{s\in N_U(A)}(d_s(A)-4R)\\
&\le
\sum_s(d_U(s)-4R)_+.
\end{aligned}
\]

Taking the maximum over `A` gives

\[
\boxed{
\delta_U
\le
\frac14\sum_{(q,u)}(d_U(q,u)-4R)_+.
}
\tag{3.3}
\]

So both the prefactor `1/4` and the overload threshold `4R` are exact consequences of the four-label degree. No extra factor comes from sign, physical multiplicity, or orientation.

This is the same general inequality proved in Q4128 with `r=4`; the new content is that the upper-occurrence labels now supply `r=4` for every residual simple C4, not merely a directed perimeter.

# 4. Why `delta_LU <= delta_U` is correct

Let `N_{LU}(C)` be the later lower/upper label neighborhood and `N_U(C)` the upper-only neighborhood. On the current quotient, every upper label remains an available LU label, so for every family `A`

\[
|N_{LU}(A)|\ge |N_U(A)|.
\tag{4.1}
\]

With the same capacity `R`,

\[
|A|-R|N_{LU}(A)|
\le
|A|-R|N_U(A)|.
\]

Taking positive parts and maxima gives

\[
\boxed{\delta_{LU}\le\delta_U.}
\tag{4.2}
\]

There is no hidden multiplicity issue here; this is monotonicity under adding available labels.

# 5. Fixed occurrence `(q,u)`: exactly two possible row digits

Fix an actual upper occurrence `(q,u)`, so

\[
q\mid b_u,
\qquad 0\le u<q.
\]

The committed reflection involution is

\[
\iota_q(u)=q-1-u,
\]

with

\[
q\mid b_u
\iff
q\mid b_{q-1-u}.
\tag{5.1}
\]

A physical row which exposes occurrence `(q,u)` has canonical row digit

\[
\boxed{t=u\quad\text{or}\quad t=q-1-u.}
\tag{5.2}
\]

No third branch occurs.

Partition the cycles counted by `d_U(q,u)` according to a deterministic witnessing row and its value of `t`. On one fixed branch `(q,t)`, if two different packed cycles had the same lower prime `p`, then (1.2)--(1.4) would give the same assigned support edge. Edge-disjointness forbids this. Thus

\[
C\longmapsto p_C

is injective on each fixed `(q,t)` branch. This is the same fixed-state packing injection used in Q4145, now with the two signs already merged by deterministic OR.

If `\kappa_\vee(q,t)` is the exact q-free both-sign union carrier count for the same residual legality predicates, this gives

\boxed{
d_U(q,u)

\kappa_\vee(q,u)

\tag{5.3}
\]

There is no factor `2` for the two signs: `\vee` is a union at fixed physical state, and deterministic OR permits at most one assigned row/edge for fixed `(p,q,t)`.

# 6. Exact q-free two-sided union carrier and fixed exceptions

The carrier can be checked directly from the fixed-state affine formulas. Put

\[
n_t=6q+t.
\]

For a legal lower prime `p`, the common primary lower zero is

\[
z=7p-n_t-1,
\]

so

\[
n_t=6p+(p-1-z).
\tag{6.1}
\]

## 6.1 Plus arm

For plus, the reflected secondary zero is

\[
a_+=12q+t-13p,
\]

and therefore

\[
12q+t=13p+a_+.
\tag{6.2}
\]

Outside lower primes dividing `b_6b_13`, Lucas plus reflection gives the exact equivalence already audited in Q4145:

\[
\boxed{
(p\mid b_z\ \text{and}\ p\mid b_{a_+})
\iff
(p\mid b_{6q+t}\ \text{and}\ p\mid b_{12q+t}).
}
\tag{6.3+}
\]

## 6.2 Minus arm

For minus, the reflected secondary zero is

\[
a_-=2p-q+t.
\]

Put

\[
v_t=q-1-t.
\]

Then legality gives

\[
v_t=p+(p-1-a_-).
\tag{6.4}
\]

Therefore Lucas and reflection give

\[
\boxed{
(p\mid b_z\ \text{and}\ p\mid b_{a_-})
\iff
(p\mid b_{6q+t}\ \text{and}\ p\mid b_{q-1-t})
}
\tag{6.3-}
\]

outside the fixed coefficient primes from `b_6` and `b_1=5`.

Thus a safe finite exceptional set for the two-sided carrier is

\[
\boxed{
E_\vee=\operatorname{rad}(b_1b_6b_{13}).
}
\tag{6.5}
\]

The Q4145 plus audit used `E=rad(b_6b_13)`; the minus arm can add only the fixed `b_1` prime. On the macroscopic lower shell `p\asymp_JT`, every prime in this fixed set is absent for all sufficiently large `T`, so it contributes no asymptotic loss. A literal finite-`T` theorem should either exclude these primes in the carrier definition or add their finite contribution separately.

Combining the two arms, the q-free state support is exactly the union

\[
\boxed{
 p\mid b_{6q+t}
 \quad\text{and}\quad
 \bigl(
 p\mid b_{12q+t}
 \ \text{or}\ 
 p\mid b_{q-1-t}
 \bigr),
}
\tag{6.6}
\]

subject to the **same sign-specific legality, oriented-shell, deterministic-OR, and residual cutoff predicates** as the physical row family.

This last qualifier is important. The bare divisor condition (6.6) without the legality/orientation predicates is an overcarrier, not an exact physical support theorem. The named stripped union carrier is exact only when those predicates are retained. For the inequality (5.3), an overcarrier would still be sufficient, but the word “exact” should be reserved for the fully filtered q-free support.

Why is it legitimate to strip the upper condition `q|b_t`? Because `(q,u)` is already an actual upper occurrence and `t` is one of the two values in (5.2). Reflection (5.1) gives

\[
q\mid b_t
\]

on both branches. Thus in this application the q-free projection loses no actual row support.

# 7. Positive-part splitting: `4R` becomes two copies of `2R`

From (5.3), for every fixed occurrence `(q,u)`, write

\[
a=\kappa_\vee(q,u),
\qquad
b=\kappa_\vee(q,q-1-u).
\]

Then

\[
(d_U(q,u)-4R)_+
\le
(a+b-4R)_+.
\]

Since

\[
a+b-4R=(a-2R)+(b-2R),
\]

and `(x+y)_+\le x_++y_+`, we obtain

\[
\boxed{
(d_U(q,u)-4R)_+
\le
(\kappa_\vee(q,u)-2R)_+
+
(\kappa_\vee(q,q-1-u)-2R)_+.
}
\tag{7.1}
\]

This is the exact source of the threshold `2R`. No factor has been dropped.

# 8. Reflection summation and the final factor `1/2`

For each odd upper prime `q`, reflection

\[
u\longmapsto q-1-u
\]

is an involution of the actual upper-zero occurrence set. Define `\kappa_\vee(q,t)=0` whenever `t` is outside the oriented row shell. Then `\kappa_\vee` is a function on the full residue range

\[
0\le t<q,
\]

and no domain ambiguity remains.

Summing (7.1) over actual upper occurrences and relabeling the second sum by reflection gives

\[
\sum_{(q,u)}(d_U(q,u)-4R)_+
\le
2\sum_{(q,t)}(\kappa_\vee(q,t)-2R)_+.
\tag{8.1}
\]

Combining with (3.3),

\[
\boxed{
\delta_U
\le
\frac12
\sum_{(q,t)}(\kappa_\vee(q,t)-2R)_+.
}
\tag{8.2}
\]

and then (4.2) gives the claimed theorem (V).

### Exact shell guard

The relabeling is valid in either of the following equivalent forms:

```text
1. sum over the full actual occurrence set, which is reflection-invariant,
   with kappa_vee extended by zero outside the oriented t-shell; or

2. enlarge to all residues 0<=t<q, put d_U=0 off the actual occurrence set
   and kappa_vee=0 off its oriented shell, then use the full involution.
```

What would *not* be valid is to sum only over one non-reflection-stable oriented `t` interval and then replace `t` by `q-1-t` without zero extension or without enlarging the summation domain.

The proposal explicitly includes the zero extension, so this check passes.

Because `q` is odd, reflection has one fixed point

\[
m_q=\frac{q-1}{2}.

At this point the two possibilities in (5.2) coincide. Hence the sharper branch count is

\[
\boxed{d_U(q,m_q)\le\kappa_\vee(q,m_q).}
\tag{9.1}

The generic estimate (5.3) instead reads

\[
d_U(q,m_q)\le2\kappa_\vee(q,m_q),

\[
\frac14(2\kappa-4R)_+
=
\frac12(\kappa-2R)_+.

So the fixed point causes **no missing factor** and no failure of the `1/2` theorem. It merely means the displayed global bound is not midpoint-optimal.

If desired, the midpoint can be sharpened separately to

\boxed{
\frac14

\tag{9.2}

instead of the generic midpoint contribution

\[
\frac12(\kappa_\vee(q,m_q)-2R)_+.

That refinement is optional and does not affect the validity of the proposed theorem.

# 10. Physical multiplicity and occurrence injectivity

There are three different multiplicities here; none introduces another constant when the definitions are kept separate.

## 10.1 Several row states over one support edge

Allowed. We choose one row only to prove `|N_U(C)|>=4`. Extra rows only enlarge the occurrence neighborhood.

## 10.2 The same numerical upper occurrence used by several packed cycles

This is exactly what `d_U(q,u)` measures. For a fixed witnessing branch `t`, two such cycles cannot use the same lower prime, because fixed `(p,q,t)` gives one assigned support edge. Thus the branch is occurrence-injective into the `\kappa_\vee(q,t)` carrier.

## 10.3 Both sign certificates at one `(p,q,t)`

They are not two assigned rows. Deterministic OR retains one physical state in one assigned sign class. This is why `\kappa_\vee` is a union carrier and why (5.3) has no additional factor two for signs.

Therefore the physical multiplicity ledger is coefficient-one at both places needed by the proof.

# 11. Is the theorem genuinely new?

There are two answers, depending on what “new” means.

## 11.1 New structural content: YES

The statement

\[
\boxed{|N_U(C)|\ge4\quad\text{for every residual simple C4}}
\]

is genuinely stronger than the earlier generic signed-tail-star fact `|N(C)|>=2`. It also extends the `r=4` Hall constant beyond directed C4s: source/sink and mixed-orientation C4s still have four distinct upper states because the upper-state-to-assigned-edge map is injective at fixed lower prime.

That is a real new combinatorial/physical observation.

## 11.2 New Hall or arithmetic theorem: NO

Once `|N_U(C)|>=4` is established,

```text
1/4 overload inequality
    + two reflection branches
    + (x+y)_+ <= x_+ + y_+
    + reflection relabeling
```

is formal. Q4128 already proved the general `1/r` Hall-overload inequality. Likewise the q-free support description is the content of the stripped two-sided union carrier, not a new consequence of C4 packing.

Thus the final bound

\[
\delta_{LU}
\le
\frac12\sum_{q,t}(\kappa_\vee(q,t)-2R)_+
\]

is best described as a **new structural quotient/corollary**, not a new arithmetic estimate.

In particular it does not by itself prove that the right-hand side is `o_J(T^2/log^2 T)`. Any such closure still requires the aggregate `\kappa_\vee` excess estimate at threshold `2R`.
