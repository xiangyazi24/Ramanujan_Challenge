The affine cycle identity (2.18) supplies no missing inequality: it is simply the telescoping equality of the four already selected row primes.

\[
\boxed{
P(c,d)\text{ assigned}
\Longrightarrow
\bigl(\mu_3<0\bigr)
\lor
\bigl(p\mid b_{\mu_3}\ \text{is false}\bigr).

None is a committed consequence of the displayed geometry. This is a statement about the proof interface, not an assertion that an actual Apéry directed-perimeter example with `mu_3<0` has been found.

# 8. Occurrence-preserving PD--AC aggregate

A safe factorwise definition is

\[
H^{\rm PD\!-\!AC}_{a,c;\delta_1,\delta_3}
:=
\prod_{\substack{p\in\mathcal P^{\rm low}_{J,T}\\
 p\mid G^+_{a,\delta_1},\ p\mid G^+_{c,\delta_3}\\

There are three distinct choices, and they must not be conflated.

\[
\sum_{a,c,\delta_1,\delta_3}

\sum_{C\in\mathscr C_{\rm PD}}\log p(C),

up to only the fixed orientation convention already built into `a<b<c<d`.

# 9. Why the aggregate is not genuinely smaller than the PD/C4 gate

Let `mathscr C_PD(p)` be the actual directed-perimeter cycles at lower prime `p`, and let `N_PD(p)` be the maximum size of an edge-disjoint subfamily.

For the exact aggregate (8.2),

\[
\sum_pN_{\rm PD}(p)\log p
\le
\sum_{C\in\mathscr C_{\rm PD}}\log p(C).
\tag{9.1}
\]

Thus an aggregate over **all** parameter factors is a sufficient theorem for the packing gate, but it is generally a stronger theorem, not a smaller one.

One can instead form the product only over a chosen edge-disjoint packing. That retains one factor per cycle because the tuple in Section 7 has fibre one. However, the resulting carrier depends on the unknown chosen packing. Bounding it is simply the original packing problem unless a separate prescribed aggregate-height theorem is proved.

The first-hole filter does not alter this comparison:

- every actual directed-perimeter cycle already has `p|b_(mu_1)` false;
- therefore the filter deletes no event from `mathscr C_PD`;
- nondivisibility does not contribute an extra factor of `p` to any known fixed integer;
- the pointwise inequality “filtered radical <= raw radical” supplies no aggregate power or logarithmic saving.

The load-bearing multiplicity rule is also exact:

> The radical must be taken **inside each indexed factor**, and the indexed factors must then be multiplied or their logarithms summed.

If one replaces the factorwise product by

```text
rad(product of all cells),
lcm of all cells,
or one global radical of all gcd values,
```

then repeated cycles with the same lower prime `p` are charged only once. Edge-disjointness does not prevent different cycles from sharing the same lower characteristic. Such a collapse loses the occurrence multiplicity required by the C4 gate.

Accordingly, PD--AC has only the following honest statuses:

```text
exact filters:     equivalent all-cycle recoding, stronger than packing;
raw filters:       overcarrier, larger than the actual gate;
two-hole filter:   unsupported and not occurrence preserving.
```

It is not a genuinely smaller committed arithmetic premise.

# 10. Strongest unconditional aggregate bound

Every directed-perimeter cycle uses two distinct P support edges. In an edge-disjoint packing those plus edges are not reused. For fixed `p`, let `E_P(p)` be the number of actual P support edges on the actual `p`-zero set. Then

\[
2N_{\rm PD}(p)\le E_P(p).
\tag{10.1}
\]

A P edge is determined by an ordered increasing pair of distinct actual `p`-zeros, so

\[
E_P(p)\le\binom{Z(p)}2.
\tag{10.2}
\]

Hence

\[
\boxed{
N_{\rm PD}(p)
\le\frac14 Z(p)(Z(p)-1).
}
\tag{10.3}
\]

Using the corrected banked factorial moment,

\[
\sum_{p\asymp_JT}Z(p)(Z(p)-1)
\ll_J
\frac{T^{11/5}}{L^{3/5}},
\qquad L=\log T,
\tag{10.4}
\]

proves (V5). Multiplication by `log p asy L` gives (V6).

The comparison with the target is

\[
\frac{T^{11/5}L^{2/5}}{T^2/L}
=T^{1/5}L^{7/5},
\tag{10.5}
\]

or equivalently in the unweighted form,

\[
\frac{T^{11/5}L^{-3/5}}{T^2/L^2}
=T^{1/5}L^{7/5}.
\tag{10.6}
\]

The first forced hole does not improve (10.4), because no committed theorem bounds the number of actual zero pairs whose associated affine competing digit is a nonzero.

# 11. The first unsupported aggregate step

The exact local theorem stops at

\[
p\mid G^+_{a,\delta_1},
\qquad
p\mid G^+_{c,\delta_3},
\qquad
p\mid b_{\mu_1}\ \text{is false},
\tag{11.1}
\]

plus the conditional second selectedness disjunction.

The first unsupported aggregate step is any assertion of the form

\[
\text{the nonzero condition in (11.1) forces an extra }1/\log T
\text{ or }T^{-\epsilon}\text{ saving}.
\tag{11.2}
\]

A nondivisibility condition is not a prime-divisor carrier. It does not imply that `p` divides a new nonzero integer of smaller height. In particular, neither reflection, the gap continuant, nor the shifted-factor isolation theorem turns the failure of `p|b_(mu_1)` into an additional low-height factor.

A genuinely new sufficient theorem would be a hole-conditioned, factorwise shifted-divisor correlation estimate such as

\[
\boxed{
\sum_{a,c,\delta_1,\delta_3}
\log
\prod_{\substack{p\in\mathcal P^{\rm low}_{J,T}\\
 p\mid G^+_{a,\delta_1},\ p\mid G^+_{c,\delta_3}\\
 \mathsf{PD}^{\rm raw}(p;a,c,\delta_1,\delta_3)\\
 p\mid b_{\mu_1}\ \text{is false}\\
 (\mu_3<0\ \lor\ p\mid b_{\mu_3}\ \text{is false})}}
p
=o_J\!\left(\frac{T^2}{L}\right).
}
\tag{11.3}
\]

Here `mathsf PD^raw` must be a fixed, selected-set-independent predicate in the reconstructed integers, and it should omit at least one actual cross-minus upper-zero condition if (11.3) is to be stronger than a tautological restatement of the desired cycle theorem.

No such estimate is presently committed. Proving it would be a real cross-characteristic shifted-divisor correlation theorem.
