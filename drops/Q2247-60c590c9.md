# 6. Complete row-class statement on a simple marked root

Let `K` be the residue field at a stable marked point. Since `rank J=h-2`,

```text
im J = { w : w^T v = 0 }.                              (6.1)
```

Indeed `im J` is contained in the hyperplane `v^perp` because `Jv=0`, and both have dimension `h-2`.

Thus the quotient

```text
K^(h-1) / im J
```

is one-dimensional, with coordinate `w -> w^T v`.

If `N_h'(r) != 0`, then (4.4) says `[w^F]` is a nonzero generator. Consequently **every** border row `w` has the unique class

```text
[w]
 = (w^T v)/( (w^F)^T v ) * [w^F].                     (6.2)
```

Now ask for a row `w_R` whose `e_1`-bordered determinant equals the Mellin scalar `R_n(Z)`. By (5.3), this requires

```text
(w_R)^T v
 = - b_(r+1)/N_(h-1)(r+1) * R_n(Z).                   (6.3)
```

Divide by (4.4). The exact class is

```text
boxed:
[w_R]
 = - R_n(Z) / [b_(r+1) N_h'(r)] * [w^F].              (6.4)
```

Equivalently every such row is

```text
boxed:
w_R
 = - R_n(Z)/[b_(r+1)N_h'(r)] * w^F
   + J y                                                (6.5)
```

for an arbitrary vector `y`.

This is an exact theorem, not evidence. It also shows why an unrestricted request for a bordered realization is too weak: after localizing at `b_(r+1)N_h'`, the realization always exists and contains no new mathematics.

The nontrivial question is whether the multiplier in (6.5) belongs to the **pre-existing Pochhammer/lcm localization** and can be produced without using `R_n` itself. The answer is no already at `h=2`.

# 10. Symbolic checker

The following checker is self-contained. It has two logically separate parts:

1. exact symbolic verification of the first-Frobenius/Jacobi identities and the `h=2` no-go;
2. an **optional finite modular scan** for marked roots. The scan is evidence only and is not used in the proof above.

I have not executed this checker in this answer; it is supplied for the caller-local repo.

```python
from fractions import Fraction
from math import lcm
import sympy as sp


def P(x):
    return 34*x**3 + 51*x**2 + 27*x + 5


def Pp(x):
    return 102*x**2 + 102*x + 27


def apery_bg(M):
    """Exact b_0..b_M and first Frobenius jet g_0..g_M."""
    b = [0]*(M+1)
    g = [Fraction(0) for _ in range(M+1)]
    b[0] = 1
    if M == 0:
        return b, g
    b[1] = 5
    g[0] = Fraction(0)
    g[1] = Fraction(12)
    for k in range(1, M):
        num = P(k)*b[k] - k**3*b[k-1]
        assert num % (k+1)**3 == 0
        b[k+1] = num // (k+1)**3

        phi = (
            Pp(k)*b[k]
            - 3*(k+1)**2*b[k+1]
            - 3*k**2*b[k-1]
        )
        g[k+1] = (
            P(k)*g[k] - k**3*g[k-1] + phi
        ) / (k+1)**3
    return b, g


def N_value(r, h):
    prev, cur = 0, 1
    for m in range(1, h):
        prev, cur = cur, P(r+m)*cur - (r+m)**6*prev
    return cur


def N_poly(h):
    x = sp.symbols('x')
    prev, cur = sp.Integer(0), sp.Integer(1)
    for m in range(1, h):
        prev, cur = cur, sp.expand(P(x+m)*cur - (x+m)**6*prev)
    return x, sp.expand(cur)


def jacobi_symbolic(h):
    r = sp.symbols('r')
    n = h-1
    J = sp.zeros(n)
    for i in range(n):
        k = r+i+1
        J[i,i] = P(k)
        if i+1 < n:
            J[i,i+1] = J[i+1,i] = -(k+1)**3
    Jp = J.diff(r)
    x, Nh = N_poly(h)
    assert sp.expand(J.det() - Nh.subs(x, r)) == 0
    assert sp.expand(J.det().diff(r) -
                     sum((J.adjugate()*Jp)[i,i] for i in range(n))) == 0
    return r, J, Jp


def check_lagrange_exact(r, h):
    """Characteristic-zero identity, no marked hypothesis."""
    s = r+h
    b, g = apery_bg(s)
    total = Fraction(0)
    for k in range(r+1, s):
        phi = (
            Pp(k)*b[k]
            - 3*(k+1)**2*b[k+1]
            - 3*k**2*b[k-1]
        )
        # Verify Lg = Phi.
        lhs = (k+1)**3*g[k+1] - P(k)*g[k] + k**3*g[k-1]
        assert lhs == phi
        total += b[k]*phi

    def flux(k):
        return k**3 * (b[k-1]*g[k] - g[k-1]*b[k])

    assert total == flux(s) - flux(r+1)

    # Verify Jv = endpoint vector and the weighted exact version.
    n = h-1
    J = sp.zeros(n)
    Jp = sp.zeros(n)
    for i in range(n):
        k = r+i+1
        J[i,i] = P(k)
        Jp[i,i] = Pp(k)
        if i+1 < n:
            J[i,i+1] = J[i+1,i] = -(k+1)**3
            Jp[i,i+1] = Jp[i+1,i] = -3*(k+1)**2
    v = sp.Matrix([b[r+i] for i in range(1,h)])
    endpoint = [0]*n
    endpoint[0] += (r+1)**3*b[r]
    endpoint[-1] += s**3*b[s]
    assert J*v == sp.Matrix(endpoint)

    wf = Jp*v
    rhs = total + 3*(r+1)**2*b[r]*b[r+1] + 3*s**2*b[s]*b[s-1]
    assert sp.Rational((wf.T*v)[0]) == sp.Rational(rhs)


def mellin_R(h):
    """Q2247 formula for R_n(beta)=(beta)_h^2 O_n(beta)."""
    beta = sp.symbols('beta')
    n = h-1
    r = beta-1
    s = r+h
    b, gF = apery_bg(n)
    g = [sp.Rational(x.numerator, x.denominator) for x in gF]

    Pcal = sp.Integer(0)
    for j in range(n+1):
        Pcal += (
            -2 * (4*j + 2*r + 3) * b[j]*b[n-j]
            / ((2*j+1)**2 * (r+j+1)**2)
        )

    Wcal = sp.Integer(0)
    for i in range(n+1):
        j = n-i
        Wcal += (
            2*(j-i)*(b[i]*g[j] - g[i]*b[j])
            / ((2*i+1)*(r+i+1)*(2*j+1)*(r+j+1))
        )

    O = sp.cancel(2*Pcal/(2*s+1) - Wcal)
    poch = sp.prod(beta+j for j in range(h))
    R = sp.cancel(poch**2 * O)
    return beta, sp.factor(R)


def check_h2_no_go():

def b_mod_p(p):
    b = [0]*(p-1)
    b[0] = 1
    if p-1 > 1:
        b[1] = 5 % p
    for k in range(1,p-2):
        num = (P(k)*b[k] - k**3*b[k-1]) % p
        b[k+1] = num * pow((k+1)**3, -1, p) % p
    return b


def eval_rat_mod_p(q, p):
    q = sp.Rational(q)
    return int(q.p % p) * pow(int(q.q % p), -1, p) % p
```

# Final disposition

The direct first-Frobenius Green pairing is now closed:

```text
w^F_i
 = P'(r+i)b_(r+i)
   -3(r+i)^2 b_(r+i-1)
   -3(r+i+1)^2 b_(r+i+1)
```

(on the marked endpoints), and

```text
(w^F)^T v
 = b_(r+1)
   [ (r+1)^3 g_r
     + s^3 N_(h-1)(r)g_s/A_(h-1)(r) ]

 = b_(r+1)^2 N_h'(r)/N_(h-1)(r+1).
```

The corresponding bordered determinant is

```text
-b_(r+1)N_h'(r).
```

That is the exact boundary flux. The factor that survives is `N_h'(r)`.

What fails is the hoped identification of this source border with the actual Pochhammer-cleared Mellin `R_n`. The minimal `h=2` identity forces the new denominator `34Z+9`, so no Pochhammer/lcm-only multiplier can do it. A genuinely new Cauchy/Bailey row is required; finding and summing **that** row is the next direct theorem.
