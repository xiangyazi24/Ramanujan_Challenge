## A. Exact identities and partition formulas

Let

```
K(m)=sum_p 1_{m mod p in Z_p}
```

and write the third factorial moment as

```
Σ_m (K(m))_3 = Σ_{p,q,r distinct} Σ_m I_p(m) I_q(m) I_r(m).
```

The ordered expansion has three distinct-index classes:

* type 0: all three prime indices distinct;
* type 1: exactly one repeated prime index (pattern p,p,q);
* type 2: all three indices equal (pattern p,p,p).

For the ordinary cube:

```
Σ_m K(m)^3
 = Σ_{p,q,r distinct} Σ_m I_p I_q I_r
 + 3 Σ_{p≠q} Σ_m I_p I_q
 + Σ_p Σ_m I_p.
```

The coefficients 3 and 1 are exact multiplicities. They are not optional normalization factors.

If

```
|Z_p| = z_p,
λ = Σ_{X<p≤2X} z_p/p,
```

then the independent heuristic gives

```
E K ≈ λ,
E (K)_2 ≈ λ²,
E (K)_3 ≈ λ³.
```

These are factorial-moment statements. They do not imply bounds for the diagonal classes.

## B. Strongest bounds from stated inputs only

Assume only:

```
Σ_p z_p/p = λ,
Σ_m K(m)^2 ≤ C X² λ²,
```

with m ranging over `[0,X²)`.

Then the repeated-index contributions are bounded as follows.

### Type 2

Because `I_p(m)^3=I_p(m)`,

```
T2 = Σ_p Σ_m I_p(m).
```

For each p, CRT periodicity gives at most

```
X²/p + 1
```

copies of each residue. Hence

```
T2 ≤ Σ_p z_p(X²/p+1)
   = X² λ + Σ_p z_p.
```

The second term is not controlled by λ alone unless a separate estimate on Σ z_p is supplied.

### Type 1

The exact contribution is

```
T1 = 3 Σ_{p≠q} Σ_m I_p(m)I_q(m).
```

It is a subset of the second factorial moment, so

```
T1 ≤ 3 Σ_m K(m)(K(m)-1)
   ≤ 3 C X² λ².
```

This is the maximal conclusion from the second-moment hypothesis.

### Type 0

The all-distinct term is the desired triple-correlation object:

```
T0 = Σ_{p,q,r distinct} Σ_m I_p I_q I_r.
```

No estimate of size `X²λ³` follows from the second factorial moment alone.

## C. Exponent audit

For the Apéry regime:

```
λ ≈ X^{-1/3}
```

therefore:

```
X² λ       ≈ X^{5/3}
X² λ²      ≈ X^{4/3}
X² λ³      ≈ X
```

Consequences:

* Type 2 has expected scale `X^{5/3}`, larger than the desired third-moment scale.
* Type 1 is controlled by the existing second moment at scale `X^{4/3}`.
* Type 0 is the only term requiring a genuinely new estimate at scale `X`.

Therefore a claim that type-1/type-2 diagonal terms alone disprove the HM3 target must distinguish between the target factorial moment and a stronger incorrectly normalized statement.

## D. Anchored-star decomposition audit

An anchored star with fixed q contributes

```
Σ_m I_q(m) (Σ_{p≠q} I_p(m))².
```

Expanding gives:

```
Σ_{p,r≠q} Σ_m I_p I_q I_r.
```

The cases p=r and p≠r must be separated:

* p=r: diagonal in the two leaves; contributes type-1 behavior.
* p≠r: three-prime correlation with anchor q; contributes type-0 behavior.

A common bookkeeping error is to replace

```
Σ_q z_q/q
```

by a fixed integer number of active primes n. These are different quantities:

* n = number of selected primes in a construction;
* λ = weighted density over all primes;
* Σ_q weights depends on the exact expansion.

No interchange is valid without an explicit lemma.

## E. Counterexample claims

A finite anchored-star construction with n active primes can refute:

```
all configurations behave independently
```

or

```
all diagonal pieces have Poisson size.
```

It does not automatically refute the uniform HM3 target:

```
Σ_m (K(m))_3 ≪ X² λ³.
```

To refute that theorem one must exhibit a family with the correct global λ normalization and show a contribution larger than the theorem's right side.

In particular, fixing O(1) primes changes λ by a vanishing amount relative to the full prime family and is not by itself a counterexample to a uniform theorem over all primes.

## F. Scope corrections

The following statements are stronger than what follows from the available inputs:

1. "All types are uncontrollable." False as a theorem-level statement: type 1 is controlled by the second factorial moment.

2. "The minimal remaining input is a triple correlation." Too strong. The minimal missing input depends on which formulation is targeted. A weaker missing estimate may suffice, for example:

```
Σ_q Σ_{p,r≠q,p≠r} Σ_m I_p I_q I_r ≪ X²λ³
```

only for distinct-index terms, or a conditional anchored estimate after diagonal subtraction.

3. "Diagonal terms destroy HM3." Not established without comparing the exact diagonal scale to the factorial target.

## Final audit verdict

The safe theorem-level separation is:

* Type-1: exactly identifiable and controlled by the existing second factorial moment.
* Type-2: exactly computable, but needs a separate bound on Σ z_p beyond λ.
* Type-0: the true unresolved triple-correlation term.

Any verifier claiming more must explicitly show where it obtains control of Σ z_p, where it removes repeated-index multiplicities, and whether it is proving a factorial-moment statement or a stronger unnormalized output-energy statement.
