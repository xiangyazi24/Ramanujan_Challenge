# Q1128 audit: fixed-prime valuation induction

## Conclusion

The natural invariant is not a scalar valuation invariant for the Apéry sequence alone. The correct object is a paired witness invariant carrying the first nonzero Cartier row for both gcds.

For fixed prime p>=5 define the state at n with base-p digits

```
n = n_0 + n_1 p + ... + n_d p^d
```

by

```
S_p(n) = (g_n, U_n, V_n)
```

where:

* `g_n = v_p(Gamma_n) = min_{j<M} v_p(L_j(n)b_j)`;
* `U_n` is the set of residue classes of minimizing indices j modulo p;
* `V_n` records the normalized first jet

```
 p^{-g_n} L_j(n)b_j mod p
```

for j in `U_n`.

The required induction statement is:

```
(I_p)  min_j v_p(L_j(n)(b_n-b_j)) = min_j v_p(L_j(n)b_j)
```

provided the corresponding normalized residue vectors in the state agree under Cartier transition.

## Cartier transition

Write

```
n = pN+r, 0<=r<p.
```

For a witness index write

```
j = pJ+s.
```

The unit-cardinal decomposition gives three cases.

### Case 1: s is outside the admissible residue window

The cardinal coefficient has an extra factor p:

```
v_p(L_j(n)) >= 1.
```

These indices cannot create a new smaller valuation unless all surviving residues vanish. They are discarded by the carry automaton.

### Case 2: s is admissible

The first jet gives

```
b_{pN+r}=b_N(b_r+2 eps(r)pN D_s) mod p^2.
```

Similarly

```
b_{pJ+s}=b_J(b_s+2 eps(s)pJ D_t) mod p^2.
```

Subtracting gives the transition rule

```
T_p(N,r;J,s):

p^{-e}(b_n-b_j)
 ->
 b_r * p^{-e}(b_N-b_J) * b_s
   + first-jet correction.
```

The correction is controlled by the stored jet component. Therefore the state must include the derivative coordinate; tracking only `b_n mod p` is insufficient.

### Case 3: high digit collision

When the high digit reaches the carry boundary, the binomial cardinal contributes a forced p factor. The transition increases the valuation by at least one and cannot create a minimal witness.

## Obstruction to a smaller scalar invariant

A finite state consisting only of

```
(v_p(Gamma_n), b_n mod p)
```

fails. Two indices with the same lower residue can have different first jets because

```
D_s = sum_v W_{s,v}(H_{s+v}-H_{s-v})
```

is residue dependent. Thus the minimal countermodel is obtained by choosing two admissible residues s1,s2 with

```
b_{s1}=b_{s2} mod p
```

but

```
D_{s1} != D_{s2} mod p.
```

The complete first-jet state avoids this obstruction.

## Candidate invariant

The strongest uniform invariant is therefore:

```
For every n and every minimizing Newton index j, the pair

(v_p(L_j(n)b_j),
 p^{-v_p(L_j(n)b_j)}L_j(n)b_j mod p,
 p^{-v_p(L_j(n)b_j)}L_j(n)(b_n-b_j) mod p)

is preserved by the Cartier transition.
```

Induction on the number of base-p digits then reduces a minimal witness at n to one at floor(n/p), with the first-jet coordinate accumulated along the digit path.

## Scope

This does not prove the global equality without controlling the jet transition cancellation. It does, however, isolate the only remaining obstruction: cancellation of the accumulated first-jet coordinate. The obstruction is not recurrence dimension; it is the possibility that the jet coordinate vanishes for `Gamma` witnesses but not for `D` witnesses.

Thus the next required theorem is a non-cancellation lemma for the Cartier jet automaton, not a larger recurrence bound.
