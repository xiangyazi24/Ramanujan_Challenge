# P3.2 — direct attack on the actual sparse-row gate

## Verdict

There is a clean next theorem at the **actual final gate**, but I do not see an unconditional proof of it from the presently proved Apéry identities.

The useful conclusion is sharper than “the private-prime model is still possible”:

1. For fixed `q`, the deterministic baseline in the question has total mass `o(N/log N)` on the already-proved exceptional set `H_delta(N)`.  Thus on those `O_delta(log N)` actual anchors, the problem is literally to show that the total fixed-`q` incidence is `o(N/log N)`.

2. A private prime at an anchor `n=qp+r` has the reflected zero `r*=p-1-r`, but its same-`q` reflected descendant is
   \[
   n_p^*=(2q+1)p-1-n.
   \]
   Distinct private primes give distinct descendants.  More generally, **all bounded-quotient Lucas descendants form a bounded-degree cloud away from the original anchor**.  They cannot force a second linearly bad row.

3. The canonical gap between `n` and `n_p^*` is
   \[
   h=p-1-2r.
   \]
   The even-gap continuant has the forced factor `2X+h+1`; at `X=r` this factor is exactly `p`.  Hence the gap-polynomial vanishing supplied by reflection is tautological.  Deflating the factor removes the only guaranteed zero.  So the reflected pair supplies no non-forced determinant condition.

4. A determinant/resultant across the `O(log N)` actual anchors has the same blindness.  If a prime occurs at only one anchor, all presently proved pair/triple/codegree determinants have no second vanishing row in that characteristic on which to act.  The one-anchor Apéry-specific detector is simply `p|b_n` by Lucas, and `log b_n ~ 3.5255 n`; that height allows `Theta(N/log N)` private primes and therefore does not close the gate.

5. There is, however, one concrete **global energy inequality** that would close the requested fixed-`q` sum and would exclude even one private spike.  Define the fixed-`q` centered incidence variables below.  It is enough to prove
   \[
   \boxed{
   \mathcal V_q(N)
   :=\sum_{N<n\le2N}
      \left(T_q(n)-\mu_q(n)\right)^2
   =o_q\!\left(\frac{N^2}{(\log N)^3}\right),
   }
   \tag{E_q}
   \]
   where
   \[
   \mu_q(n)=
   \sum_{\substack{n/(q+1)<p\le n/q\\p\ {m prime}}}
   \frac{|Z_p|}{p}.
   \]
   This is much weaker than the Poisson-scale second moment predicted by the data.

6. The **diagonal prime contribution to `(E_q)` is already unconditionally small**:
   \[
   \mathcal D_q(N)
   \ll_q \frac{N^{5/3}}{\log N}
   =o\!\left(\frac{N^2}{(\log N)^3}\right),
   \]
   using only the proved `|Z_p|<<p^{2/3}` theorem.

7. Therefore the first exact missing estimate is only the characteristic-varying off-diagonal covariance
   \[
   \boxed{
   \left|
   \sum_{\substack{p\ne\ell}}
   \sum_{N<n\le2N} X_{p,q}(n)X_{\ell,q}(n)
   \right|
   =o_q\!\left(\frac{N^2}{(\log N)^3}\right).
   }
   \tag{CV_q}
   \]
   It is a correlation between a zero of `b_r mod p` and a shifted zero of `b_s mod ell` in **different characteristics**.  No current gap polynomial, reflection identity, Smith/resultant identity, or Cartier rank-one identity estimates it.

So the first missing estimate is not another same-characteristic zero-count lemma.  It is `(CV_q)`: a very weak power/logarithmic saving in a characteristic-varying centered bilinear form.  Proving `(CV_q)` would directly kill a private singleton spike and finish the fixed-`q` contribution on `H_delta(N)`.

# 2. Put the fixed-`q` gate on one common prime universe

Fix `q>=1` and put

\[
I_N=(N,2N]\cap\mathbb Z.
\]

For a prime `p`, define its fixed-`q` row window

\[
W_{p,q}(N)
:=I_N\cap[qp,(q+1)p).
\tag{2.1}
\]

It is nonempty only for

\[
\frac{N}{q+1}<p<\frac{2N}{q}.
\tag{2.2}
\]

For fixed `q` and large `N`, every such prime is `>>_q N`, hence in particular exceeds `sqrt(2N)`.

Write

\[
\rho_p:=\frac{|Z_p|}{p}
\tag{2.3}
\]

and define

\[
A_{p,q}(n)
:=\mathbf 1_{W_{p,q}(N)}(n)\,
  \mathbf 1_{Z_p}(n-qp),
\tag{2.4}
\]

\[
X_{p,q}(n)
:=\mathbf 1_{W_{p,q}(N)}(n)
 \left(\mathbf 1_{Z_p}(n-qp)-\rho_p\right).
\tag{2.5}
\]

Then, identically for `n in I_N`,

\[
T_q(n)=\sum_p A_{p,q}(n),
\tag{2.6}
\]

and the baseline in the question is

\[
\mu_q(n)
:=\sum_p\rho_p\mathbf 1_{W_{p,q}(N)}(n),
\tag{2.7}
\]

so

\[
\boxed{
T_q(n)-\mu_q(n)=\sum_pX_{p,q}(n).
}
\tag{2.8}
\]

No change of problem has occurred: (2.8) is exactly the summand appearing in the question.

# 3. On the actual exceptional anchors, the baseline is already negligible

The proved zero-count theorem gives

\[
\rho_p\ll p^{-1/3}.

\[
\begin{aligned}
\mu_q(n)
&\ll_q
\sum_{p\asymp_qN}p^{-1/3}\\
&\ll_q \frac{N^{2/3}}{\log N}.
\end{aligned}
\tag{3.1}
\]

The codegree theorem gives, by hypothesis of the question,

\[
|H_\delta(N)|\ll_\delta\log N.
\tag{3.2}

Therefore

\[
\boxed{
\sum_{n\in H_\delta(N)}\mu_q(n)
\ll_{q,\delta}N^{2/3}
=o\!\left(\frac N{\log N}\right).
}
\tag{3.3}
\]

Thus no probabilistic main-term subtlety remains on the actual anchor set.  If the desired centered sum fails, it fails because these `O(log N)` anchors carry `Omega(N/log N)` genuine incidences.

In particular, a single row with

\[
T_q(n_0)\ge c\frac N{\log N}
\tag{3.4}
\]
for fixed `c>0` is already the essential obstruction.

# 4. Reflection of one incidence: exact descendant geometry

Take one incidence at an anchor `n`:

\[
n=qp+r,
\qquad 0\le r<p,
\qquad r\in Z_p.
\tag{4.1}
\]

Reflection gives

\[
r^*=p-1-r\in Z_p.
\tag{4.2}
\]

The reflected zero at the **same quotient q** occurs at

\[
\begin{aligned}
n_p^*
&=qp+r^*\\
&=qp+p-1-r\\
&=(2q+1)p-1-n.
\end{aligned}
\tag{4.3}
\]

Hence

\[
\boxed{
n_p^*=(2q+1)p-1-n.}
\tag{4.4}
\]

For two distinct primes `p!=ell`,

\[
n_p^*-n_\ell^*=(2q+1)(p-\ell)\ne0.
\tag{4.5}
\]

So `M` private primes at one anchor create `M` **different** reflected rows, each carrying its own original prime.  Reflection duplicates the incidence mass, but spreads it into a matching.

The reflected rows remain at linear scale.  From

\[
\frac n{q+1}<p\le\frac nq
\]
one gets

\[
\frac q{q+1}n-1<n_p^*\le\frac{q+1}{q}n-1.
\tag{4.6}
\]

Thus reflection does not hide the mass at an astronomically remote scale one prime at a time; it simply fails to aggregate it.

At the central fixed point `r=(p-1)/2`, one has `n_p^*=n`, so reflection supplies **no new row at all**.  This only strengthens the ceiling.

# 5. All bounded Lucas descendants still have bounded row degree

Reflection is only the first descendant.  Apéry--Lucas gives, for every integer `a` with `0<=a<p`,

\[
b_{ap+r}\equiv b_a b_r\equiv0\pmod p,
\tag{5.1}
\]

and likewise

\[
b_{ap+r^*}\equiv0\pmod p.
\tag{5.2}
\]

Thus the complete two-orientation descendant family is

\[
D^+_{p,a}=ap+r=n+(a-q)p,
\tag{5.3}
\]

\[
D^-_{p,a}=ap+r^*=(a+q+1)p-1-n.
\tag{5.4}
\]

Now fix any bounded quotient range

\[
0\le a\le A,
\tag{5.5}
\]
where `A` is independent of `N` (it may depend on `q`).  This is exactly the range of descendants that stays in a fixed linear-size interval because `p asy_q N`.

For a row `m!=n` and a fixed `a!=q`, equation (5.3) determines at most one prime:

\[
p=\frac{m-n}{a-q}.
\tag{5.6}
\]

For a fixed `a`, equation (5.4) also determines at most one prime:

\[
p=\frac{m+n+1}{a+q+1}.
\tag{5.7}
\]

Therefore, for the private-prime set `P(n)` at the original anchor,

\[
\boxed{
\sup_{m\ne n}
\#\{p\in P(n):m=D^+_{p,a}\text{ or }D^-_{p,a}
\text{ for some }0\le a\le A\}
\le 2A+1.
}
\tag{5.8}
\]

The only unbounded-degree row in this bounded Lucas cloud is the deliberately retained direct descendant `a=q`, namely the original anchor itself.

This proves the ceiling requested in the question in an exact form:

> **One anchor plus all bounded Lucas/reflection descendants cannot force a second linearly bad row.**

A global first-moment argument over this descendant cloud therefore sees only `O_A(M)` incidences from an `M`-prime private spike.  That is perfectly compatible with `M asy N/log N`.

# 6. The formal common reflected row exists only modulo the product

There is another way to see the same obstruction.

For every private prime `p`, reflection says

\[
-n-1\pmod p\in Z_p.
\tag{6.1}
\]

Thus all primes formally share the row `-n-1`.  But that row is negative.

If

\[
P=\prod_{p\in P(n)}p,
\]
then a common **positive** all-reflected row must satisfy

\[
m\equiv-n-1\pmod P.
\tag{6.2}
\]

Since `P>n+1` as soon as the spike has more than a few large primes, the least nonnegative representative is

\[
m=P-n-1.
\tag{6.3}
\]

If `M=|P(n)|` is of the forbidden size `cN/log N`, then

\[
\log P
\ge M\log\frac{N}{q+1}
=(c+o(1))N.
\tag{6.4}
\]

So the canonical all-reflected common row lives at exponential, not linear, scale.

Mixed direct/reflected CRT orientations give other residue classes modulo `P`; an accidentally small mixed class would itself be a genuinely new cross-prime alignment.  Nothing in reflection or Lucas forces one.  The all-direct class is exactly the original anchor; the all-reflected class is (6.3).

This is the precise reason “use all descendants” does not automatically produce a second bad row.

# 7. The canonical reflection gap gives only the forced factor

Assume, after swapping the two zeros if needed, that

\[
r<r^*=p-1-r.
\]

Their gap is

\[
h=r^*-r=p-1-2r.
\tag{7.1}
\]

It is even.  The repository's gap-polynomial reflection law gives the structural factor

\[
N_h(X)=(2X+h+1)N_h^\circ(X)
\qquad(h\ {m even}).
\tag{7.2}
\]

At the actual starting zero,

\[
2r+h+1
=2r+(p-1-2r)+1
=p.
\tag{7.3}
\]

Hence

\[
N_h(r)\equiv0\pmod p
\]
for the completely formal reason that its forced factor is `p`.

Equivalently, at the integer row `n=qp+r`,

\[
2n+h+1=(2q+1)p.
\tag{7.4}
\]

Thus the codegree determinant between the anchor and its canonical reflected descendant merely recovers the prime already used to define the descendant.

After deflation, reflection supplies no implication

\[
p\mid N_h^\circ(r).
\]

This exact no-go is already recorded in the July 31 working note: the factor `2X+h+1` evaluates to `p`, so the reflected gap condition is tautological, not a second relation.

Therefore the very strongest same-characteristic determinant machinery in the current repository starts only when there is a **second non-reflection return**.  A private prime whose zero set in the relevant region is only one reflected doublet completely evades it.

# 8. Why a determinant across the actual `O(log N)` anchors is singleton-blind

Let

\[
H_\delta(N)=\{n_1,\ldots,n_J\},
\qquad J\ll_\delta\log N,
\tag{8.1}
\]

and for each prime put

\[
d_p
:=\#\{i:p\text{ is in the fixed-q slice of }n_i,
\ n_i\bmod p\in Z_p\}.
\tag{8.2}
\]

The total fixed-`q` incidence on the anchors is

\[
\sum_{n\in H_\delta(N)}T_q(n)=\sum_pd_p.
\tag{8.3}
\]

The codegree theorem and all current gap/resultant certificates control the part with

\[
d_p\ge2:
\]
there are two fixed rows in the same characteristic, hence a gap polynomial or a wrap divisor can be formed.

But if

\[
d_p=1,
\tag{8.4}
\]
then `p` appears in exactly one anchor row.  Reflection produces a second zero only at the `p`-dependent row (4.4), not at another member of the fixed anchor set, and Section 7 shows that the resulting pair determinant is the forced reflection factor.

So every determinant whose local rank drop is generated by the presently proved same-characteristic pair/triple identities is blind to the singleton term

\[
\#\{p:d_p=1\}.
\tag{8.5}
\]

There is one Apéry-specific one-anchor statement:

\[
n_i=qp+r,\quad r\in Z_p
\quad\Longrightarrow\quad
p\mid b_{n_i}
\tag{8.6}
\]
by Apéry--Lucas.  Hence the product of all private primes at `n_i` divides `b_{n_i}`.

But

\[
\log b_{n_i}
\sim \lambda n_i,
\qquad
\lambda=\log(17+12\sqrt2)=3.52549\ldots,
\tag{8.7}
\]
so this only gives

\[
T_q(n_i)
\le(\lambda+o(1))\frac{n_i}{\log N},
\tag{8.8}
\]
which is exactly the forbidden scale, not `o(N/log N)`.

Taking the product over `J=O(log N)` anchors gives an integer of logarithmic height `O(N log N)` and therefore loses another logarithm.  Pairwise gcds/resultants do not repair this because private primes are deliberately disjoint across the anchors.

This is the same “parity barrier” recorded in `atom_tail_section.tex`: all current small-height certificates require at least two vanishing conditions in one characteristic.  A singleton detector of genuinely sublinear height is not presently known.

# 9. A concrete energy inequality that kills even one private spike

Define

\[
S_q(n):=T_q(n)-\mu_q(n)
       =\sum_pX_{p,q}(n).
\tag{9.1}
\]

Consider the actual global second energy

\[
\mathcal V_q(N)
:=\sum_{n\in I_N}S_q(n)^2.
\tag{9.2}
\]

I claim that the following is sufficient:

\[
\boxed{
\mathcal V_q(N)
=o_q\!\left(\frac{N^2}{(\log N)^3}\right).
}
\tag{E_q}
\]

This is a genuine strengthening, not an equivalent reformulation of the desired anchor sum.

Indeed, by Cauchy--Schwarz and the proved anchor count,

\[
\begin{aligned}
\left|
\sum_{n\in H_\delta(N)}S_q(n)
\right|
&\le
|H_\delta(N)|^{1/2}\,\mathcal V_q(N)^{1/2}\\
&\ll_\delta
(\log N)^{1/2}
\,o_q\!\left(\frac{N}{(\log N)^{3/2}}\right)\\
&=o_{q,\delta}\!\left(\frac N{\log N}\right).
\end{aligned}
\tag{9.3}
\]

This is exactly the sum required in the question.

Moreover `(E_q)` excludes a single private spike automatically.  If for one row

\[
S_q(n_0)\ge c\frac N{\log N},
\]
then just that row contributes

\[
\mathcal V_q(N)
\ge c^2\frac{N^2}{(\log N)^2},
\tag{9.4}
\]
which is larger than the allowed scale in `(E_q)` by a factor comparable to `log N`.

Thus `(E_q)` is precisely the kind of global energy theorem that the final gate needs.

A stronger but aesthetically simpler target such as

\[
\mathcal V_q(N)\ll_q N^{2-\eta}
\tag{9.5}
\]
for any fixed `eta>0` would also close immediately.  For example `N^{5/3+o(1)}` would be more than enough.  The logarithmic threshold `(E_q)` records how little saving is actually required.

# 10. The entire diagonal of `(E_q)` is already proved

Expand

\[
\mathcal V_q(N)
=\mathcal D_q(N)+\mathcal C_q(N),
\tag{10.1}
\]
where

\[
\mathcal D_q(N)
:=\sum_p\sum_{n\in I_N}X_{p,q}(n)^2
\tag{10.2}
\]

and

\[
\mathcal C_q(N)
:=\sum_{p\ne\ell}\sum_{n\in I_N}
X_{p,q}(n)X_{\ell,q}(n).
\tag{10.3}
\]

For one prime `p`, put

\[
H_p:=\#\{n\in W_{p,q}(N):n-qp\in Z_p\}.
\]

Because the residue map `n -> n-qp` is injective on `W_{p,q}(N)`,

\[
H_p\le |Z_p|.
\tag{10.4}
\]

Also `|W_{p,q}(N)|<=p`.  Since for a zero-one variable `I` and `0<=rho<=1`,

\[
(I-\rho)^2\le I+\rho^2,
\]
we get

\[
\begin{aligned}
\sum_{n\in I_N}X_{p,q}(n)^2
&\le H_p+|W_{p,q}(N)|\rho_p^2\\
&\le |Z_p|+\frac{|Z_p|^2}{p}.
\end{aligned}
\tag{10.5}
\]

Using the proved Apéry zero bound

\[
|Z_p|\ll p^{2/3},
\]
this is

\[
\ll p^{2/3}+p^{1/3}\ll p^{2/3}.
\]

All relevant primes satisfy `p asy_q N`, so partial summation gives

\[
\boxed{
\mathcal D_q(N)
\ll_q\sum_{p\asymp_qN}p^{2/3}
\ll_q\frac{N^{5/3}}{\log N}.
}
\tag{10.6}
\]

And

\[
\frac{N^{5/3}/\log N}{N^2/(\log N)^3}
=\frac{(\log N)^2}{N^{1/3}}\to0.
\tag{10.7}
\]

Therefore

\[
\boxed{
\mathcal D_q(N)
=o\!\left(\frac{N^2}{(\log N)^3}\right)
}
\tag{10.8}
\]

**unconditionally**.

This is a useful simplification: there is no remaining same-prime/large-`Z_p` obstruction at the energy threshold required by the actual anchor set.

# 11. The first exact missing estimate

By (10.1) and (10.8), it is enough to prove

\[
\boxed{
|\mathcal C_q(N)|
=o_q\!\left(\frac{N^2}{(\log N)^3}\right),
}
\tag{CV_q}
\]

where

\[
\mathcal C_q(N)
=
\sum_{\substack{p\ne\ell\\
W_{p,q}(N),W_{\ell,q}(N)\ne\varnothing}}
\sum_{N<n\le2N}
X_{p,q}(n)X_{\ell,q}(n).
\tag{11.1}
\]

This is the **first exact missing estimate**.

It is characteristic-varying by construction.  To see its arithmetic content, suppose `p!=ell` and one row is simultaneously bad for both:

\[
n=qp+r=q\ell+s,
\qquad r\in Z_p,\ s\in Z_\ell.
\]
Then

\[
\boxed{r-s=q(\ell-p).}
\tag{11.2}
\]

Thus the uncentered common-row count for a prime pair is

\[
\#\left\{
 r\in Z_p:
 r-q(\ell-p)\in Z_\ell,
\ N<qp+r\le2N
\right\},
\tag{11.3}
\]
with the evident range conditions `0<=r<p` and
`0<=r-q(ell-p)<ell`.

The centered form `(CV_q)` asks for cancellation of these counts against the densities `|Z_p|/p` and `|Z_ell|/ell` after summing over `p!=ell`.

This is **not** a same-field additive correlation such as

\[
\#\{r:r,r+h\in Z_p\}.
\]
The two zero conditions in (11.3) live in different finite fields and involve two different recurrences modulo two different characteristics.

Using the Cartier diagonal representation, (11.3) is equivalently a correlation between

\[
[x^ry^rz^rw^r]F^{p-1}\equiv0\pmod p
\]

and

\[
[x^sy^sz^sw^s]F^{\ell-1}\equiv0\pmod\ell,
\qquad s=r-q(\ell-p).
\]

That is the genuinely Apéry-specific characteristic-varying object one would have to estimate.

# 12. Why every current same-characteristic identity misses `(CV_q)`

## 12.1 Gap polynomials

`N_h` controls

\[
r,r+h\in Z_p
\]
inside **one** field `F_p`.  In (11.3) the second zero belongs to `Z_ell`, not `Z_p`.  There is no integer `h` for which the proved implication produces one polynomial whose reduction modulo a single prime contains both conditions.

Reflection does not change this: it replaces each zero by another zero in its own characteristic.

## 12.2 Pair/triple resultants

Every current resultant/corank certificate begins with two or more returns of the same recurrence modulo one prime.  A private prime has only one fixed anchor incidence.  Its canonical reflected return is the forced factor from Section 7.  Hence no non-forced resultant is triggered.

## 12.3 Cartier rank one

The Cartier diagonal is very useful for expressing each zero event algebraically, but the current operator is `p`-semilinear and changes with the characteristic.  The repository's parity-barrier audit already records that its entries do not lift to one fixed small integer detector.  There is presently no determinant coupling the coefficient of `F^{p-1}` to the shifted coefficient of `F^{ell-1}` with height small enough to sum over `p,ell`.

## 12.4 The second p-adic digit

The current working-note audit records that the second digit gives a new coordinate but not a target-selective one: it can vanish at non-targets.  It therefore cannot be inserted as an independent factor in `(CV_q)` without a new theorem.

# 13. The `Q^2` barrier appears exactly in `(CV_q)`

For distinct large primes

\[
p,\ell\asymp_qN,
\]
the simultaneous congruence conditions have natural CRT modulus

\[
p\ell\asymp_qN^2.
\tag{13.1}
\]

But the row interval has length only `N`.

For a prescribed pair of residues `(r,s)`, CRT therefore gives at most one row in `(N,2N]`.  The expected main term has size

\[
\frac{N}{p\ell}\asymp\frac1N,
\]
whereas the endpoint error in a raw residue-class count is `O(1)`.

This is exactly the `Q^2` barrier already recorded in the repository working notes: the first moment is honest, while every cross-prime second moment has modulus larger than the available row range.

The codegree theorem bypasses this barrier in the **transpose direction**:

```text
two rows m,n fixed
    -> how many SAME primes are bad for both?
```

It does not estimate the direction needed in `(CV_q)`:

```text
one row n fixed / summed
    -> how often are TWO DIFFERENT primes simultaneously bad?
```

A private star is exactly the configuration on which this distinction is maximal.

# 14. Reflection descendants do not create extra energy

Suppose one anchor `n_0` has `M` private fixed-`q` primes.

At the anchor,

\[
S_q(n_0)^2\asymp M^2.
\]

This is the dangerous energy that `(E_q)` must rule out.

Reflection creates `M` descendants `n_p^*`, but by (4.5) they are distinct.  Ignoring accidental extra primes, their total added square mass is only

\[
\sum_{p\in P(n_0)}1^2=M.
\tag{14.1}
\]

Adding all bounded Lucas descendants multiplies this by only a bounded factor, by (5.8):

\[
O_A(M).
\tag{14.2}
\]

Thus descendant energy does not feed back an `M^2` contradiction elsewhere.  It turns the star into a matching.

This exactly explains why a global **uncentered first moment over descendants** cannot work.  The missing phenomenon has to be cancellation/anti-alignment across different primes at the original row scale, i.e. `(CV_q)` or something that implies it.

# 15. An anchor-side version of the same missing input

For completeness, there is an even more local sufficient inequality on the actual `O(log N)` anchors.

Put

\[
e_p
:=\sum_{n\in H_\delta(N)}
  \rho_p\mathbf1_{W_{p,q}(N)}(n).
\tag{15.1}
\]

Then

\[
\sum_{n\in H_\delta(N)}(T_q(n)-\mu_q(n))
=\sum_p(d_p-e_p).
\tag{15.2}
\]

Since the fixed-`q` prime universe has `O_q(N/log N)` elements, Cauchy gives closure from

\[
\boxed{
\sum_p(d_p-e_p)^2
=o_{q,\delta}\!\left(\frac N{\log N}\right).
}
\tag{AD_q}
\]

Indeed,

\[
\left|\sum_p(d_p-e_p)\right|
\ll_q
\left(\frac N{\log N}\right)^{1/2}
\left(\sum_p(d_p-e_p)^2\right)^{1/2}
=o\!\left(\frac N{\log N}\right).
\]

Now

\[
e_p\le |H_\delta(N)|\rho_p
\ll_\delta (\log N)N^{-1/3}=o(1)
\tag{15.3}
\]
uniformly for relevant `p`.

Therefore every private singleton `d_p=1` contributes

\[
(d_p-e_p)^2=1-o(1)
\]
to `(AD_q)`.

So the **first term** that must be beaten in an anchor determinant/energy proof is literally

\[
\boxed{
\#\{p:d_p=1\}=o_{q,\delta}(N/\log N).
}
\tag{15.4}
\]

The codegree theorem controls `d_p>=2` phenomena but says nothing forcing (15.4).  Reflection does not change this because it moves the second zero to a `p`-dependent row and the corresponding gap factor is forced.

`(AD_q)` is the anchor-local version of the obstruction; `(CV_q)` is the more promising global formulation because its diagonal part is already proved and it asks for a genuine characteristic-varying cancellation theorem rather than a direct singleton count.

# 16. What an Apéry-specific proof of `(CV_q)` would have to look like

The repository has already exhausted purely combinatorial, same-prime, and rank-one scalar mechanisms.  A proof of `(CV_q)` needs one of the following genuinely new phenomena.

### A. Characteristic-varying Cartier/Mellin bilinear large sieve

One would need a theorem whose local input is the actual Apéry Cartier coefficient and whose global output has the shape

\[
\sum_{p\ne\ell\asymp N}
\left(
C_q(p,\ell;N)-\text{local density}
\right)
=o\!\left(\frac{N^2}{\log^3N}\right),
\]

where `C_q(p,ell;N)` is (11.3).

This is substantially weaker than square-root cancellation in every prime pair; only aggregate cancellation is required.

### B. A cross-characteristic low-height determinant

Alternatively, for every common row one could attach an integer

\[
\Delta_q(p,\ell;n)\ne0
\]
which is divisible by one of `p,ell` (or by `p ell`) only when both Apéry zero events occur, with total logarithmic height over the relevant pairs `o(N^2/log^2 N)`.  No such determinant is present in the current recurrence/resultant theory, because all existing determinants reduce two returns in one characteristic.

### C. A genuinely selective second p-adic/Frobenius coordinate

A second coordinate would suffice if one proved a codimension-two statement **on the distinguished Apéry zero fiber**, not merely a new coordinate that sometimes also vanishes at non-targets.  The current audits explicitly do not have that selectivity.

Among these, (A) matches most closely the current repository diagnosis: a characteristic-varying local-limit/large-sieve theorem for the two-variable Mellin/Cartier family.

# 17. Why this is stronger than an “equivalent reformulation”

The question explicitly asks not to return another equivalent statement.  `(CV_q)` is not equivalent to the desired anchor sum.

It is a **global second-moment theorem over all `N` rows**, whereas the desired statement asks only for one signed first moment over `O(log N)` already-selected anchors.  `(CV_q)` is much stronger.

The point of isolating it is that most of it has now been proved:

```text
needed global energy threshold:
    V_q(N) = o(N^2/log^3 N)

same-prime diagonal:
    D_q(N) << N^(5/3)/log N
    = o(N^2/log^3 N)                     PROVED

remaining term:
    characteristic-varying p != ell covariance C_q(N)  MISSING
```

So this attack has reduced the global energy route to one exact bilinear term, not merely renamed the original pointwise count.

And `(CV_q)` has the right adversarial sensitivity: the private-singleton model contributes an `M^2` off-diagonal spike at the anchor and therefore cannot satisfy it.

## Bottom line

The reflected zero and the complete bounded Lucas descendant tree do **not** defeat the private-prime model.  They can be audited exactly: outside the original anchor they have bounded row degree, and the canonical reflection pair is absorbed by the forced linear factor of the gap polynomial.

The first place where a genuinely Apéry-specific identity could still win is therefore cross-characteristic.

A concrete inequality sufficient for closure is

\[
\mathcal V_q(N)
=o_q\!\left(\frac{N^2}{(\log N)^3}\right),
\]

and its diagonal is already unconditionally

\[
\ll_q N^{5/3}/\log N.
\]

Thus the first exact missing estimate is

\[
\boxed{
\left|
\sum_{p\ne\ell}
\sum_{N<n\le2N}
X_{p,q}(n)X_{\ell,q}(n)
\right|
=o_q\!\left(\frac{N^2}{(\log N)^3}\right).
}
\]

This is weak enough that one does **not** need pairwise square-root cancellation.  But it is strong enough to exclude even one `Theta(N/log N)` private spike.  None of the current same-characteristic Apéry identities supplies it.  Proving this characteristic-varying covariance estimate—or a low-height determinant that implies it—is the first exact missing step at the actual final gate.
