# Q3404 — exact constructive audit of the zero-sum selector source

## Verdict

The claimed theorem is **true**, and the stated constant `7` is not tight.  There is a completely explicit full-window construction, using only ordinary prefix Euclid plus adjacent recurrence reductions, for which

\[
\sum_{K=A}^B a_K=0,\qquad \sum_{K=A}^B v_Ka_K=2,
\]

and in fact, with

\[
M:=X+2B+3,
\]

one gets the stronger uniform estimate

\[
\boxed{\max_{A\le K\le B}|a_K|\le \frac92 M^2<7M^2.}
\]

No finite scan is needed.

The important support statement is exactly the one requested: the Bézout/Hermite part is allowed to use the **entire window** `[A,B]`; only the final parity corrector has three-site support, namely at `B-2,B-1,B`.  Nothing in the argument implies that the final vector `a` itself has bounded support.

The construction also handles `A=0` without any exception in the proof; in that case `U_0=1`, hence `G=1`, and the initial Bézout certificate can simply be the unit vector at `0`.

---

# 1. Setup and two elementary identities

Assume

\[
X\ge1,\qquad 0\le A\le B-2,
\]

and put

\[
U_K=(-1)^K\binom{X+K-1}{K},\qquad
G=\gcd(U_A,\ldots,U_B)>0,
\qquad
v_K=U_K/G.
\]

Then `gcd(v_A,...,v_B)=1`.

The signed negative-binomial recurrence is

\[
\boxed{(K+1)U_{K+1}=-(X+K)U_K,}
\tag{1.1}
\]

hence also

\[
\boxed{(K+1)v_{K+1}=-(X+K)v_K.}
\tag{1.2}
\]

For every `K=A,...,B-1`, define the adjacent null vector `r^(K)` by

\[
r^{(K)}_K=X+K,\qquad
r^{(K)}_{K+1}=K+1,
\]

with all other coordinates zero.  Then (1.2) gives

\[
\boxed{v\cdot r^{(K)}=0.}
\tag{1.3}
\]

Its ordinary coordinate sum is

\[
\boxed{\alpha_K:=\sum_i r^{(K)}_i=X+2K+1.}
\tag{1.4}
\]

Also

\[
\frac{|U_{K+1}|}{|U_K|}=\frac{X+K}{K+1}
=1+\frac{X-1}{K+1}\ge1.
\]

Therefore

\[
\boxed{|v_A|\le|v_{A+1}|\le\cdots\le|v_B|.}
\tag{1.5}
\]

This monotonicity is the only size fact about the selectors used below.

# 2. Exact prefix-Euclid construction of one Bézout vector

We first construct an integer vector `z=(z_A,...,z_B)` satisfying

\[
\boxed{U\cdot z=G,\qquad v\cdot z=1.}
\tag{2.1}
\]

No coefficient bound is claimed at this stage, and no generic “small Bézout coefficients” folklore is used.

Define prefix gcds

\[
g_A=|U_A|,
\qquad
g_K=\gcd(g_{K-1},|U_K|)\quad(K>A).
\]

Thus `g_B=G`.

Start with a vector `z^(A)` supported at `A`:

\[
z^{(A)}_A=\operatorname{sgn}(U_A),
\]

so that

\[
U\cdot z^{(A)}=|U_A|=g_A.
\]

Inductively, suppose `z^(K-1)` is supported in `[A,K-1]` and

\[
\sum_{j=A}^{K-1}U_j z^{(K-1)}_j=g_{K-1}.
\]

Run the ordinary Euclidean algorithm on the two positive integers
`g_(K-1)` and `|U_K|`, keeping the extended coefficients, to obtain exact integers `x_K,y_K` with

\[
x_Kg_{K-1}+y_K|U_K|=g_K.
\tag{2.2}
\]

Then set

\[
z^{(K)}_j=x_Kz^{(K-1)}_j\quad(A\le j<K),
\]

and

\[
z^{(K)}_K=y_K\operatorname{sgn}(U_K).
\]

Equation (2.2) gives

\[
\sum_{j=A}^K U_jz^{(K)}_j=g_K.
\]

At `K=B`, take `z=z^(B)`.  Since `g_B=G`, (2.1) follows.

A deterministic extended-Euclid implementation is:

```python
def xgcd_pos(a, b):
    # a,b > 0.  Returns d,x,y with x*a+y*b=d=gcd(a,b).
    old_r, r = a, b
    old_x, x = 1, 0
    old_y, y = 0, 1
    while r != 0:
        q = old_r // r
        old_r, r = r, old_r - q*r
        old_x, x = x, old_x - q*x
        old_y, y = y, old_y - q*y
    assert old_x*a + old_y*b == old_r
    return old_r, old_x, old_y
```

and the prefix update is exactly

```python
g = abs(U[A])
z = {k: 0 for k in range(A, B+1)}
z[A] = 1 if U[A] > 0 else -1

for K in range(A+1, B+1):
    d, x, y = xgcd_pos(g, abs(U[K]))
    for j in range(A, K):
        z[j] *= x
    z[K] = y * (1 if U[K] > 0 else -1)
    g = d

assert g == G
assert sum(U[k]*z[k] for k in range(A, B+1)) == G
```

### `A=0`

Here

\[
U_0=1,
\]

so automatically `G=1`.  One may skip prefix Euclid entirely and start from

\[
z_0=1,\qquad z_K=0\ (K>0).
\]

The rest of the construction below is unchanged.  The generic prefix algorithm also works verbatim.

# 3. Full-window Hermite reduction using the recurrence

The raw prefix Bézout coefficients may be enormous.  We now reduce them without changing `v dot z`.

Set `h=z`.  For `K=A,A+1,...,B-1` in increasing order, let

\[
m_K:=X+K>0.
\]

Choose the unique remainder `rho_K` with

\[
0\le\rho_K<m_K,
\qquad
\rho_K\equiv h_K\pmod{m_K},
\]

and define

\[
t_K:=\frac{\rho_K-h_K}{m_K}\in\mathbb Z.
\]

Replace

\[
h\leftarrow h+t_Kr^{(K)}.
\tag{3.1}
\]

Because `v dot r^(K)=0`, the invariant

\[
\boxed{v\cdot h=1}
\tag{3.2}
\]

is preserved.

At stage `K`, only coordinates `K,K+1` change.  All later reductions have index larger than `K`, so coordinate `K` is never changed again.  Hence after the sweep

\[
\boxed{0\le h_K<X+K\qquad(A\le K<B).}
\tag{3.3}
\]

This is the exact Hermite-style reduction needed for the coefficient bound.

For a verifier, the update is simply

```python
h = dict(z)
for K in range(A, B):
    mod = X + K
    rem = h[K] % mod          # Python: 0 <= rem < mod
    t = (rem - h[K]) // mod
    h[K]     += t * (X + K)
    h[K + 1] += t * (K + 1)

assert sum(v[k]*h[k] for k in range(A, B+1)) == 1
for K in range(A, B):
    assert 0 <= h[K] < X + K
```

No bound on the intermediate `t_K` is needed.

# 4. Bounding the reduced Bézout vector

Put

\[
C:=X+B-1,
\qquad
P:=\sum_{K=A}^{B-1}h_K.
\]

From (3.3), for every `K<B`,

\[
0\le h_K<X+K\le C.
\]

There are `B-A<=B` such coordinates, so

\[
\boxed{P\le BC.}
\tag{4.1}
\]

Now isolate the last term in `v dot h=1`:

\[
v_Bh_B=1-\sum_{K=A}^{B-1}v_Kh_K.
\]

Using (1.5),

\[
|v_B||h_B|
\le 1+\sum_{K=A}^{B-1}|v_K|h_K
\le 1+|v_B|P.
\]

Since `|v_B|>=1`,

\[
\boxed{|h_B|\le1+P\le1+BC.}
\tag{4.2}
\]

Let

\[
s:=\sum_{K=A}^B h_K.
\]

Then

\[
|s|\le P+|h_B|
\le1+2P
\le1+2BC.
\tag{4.3}
\]

The only potentially quadratic quantities are now the last coefficient and the total sum.

---

# 5. Reduce the total sum using one two-site null relation

Set

\[
J:=B-2.
\]

This is legal because `A<=B-2`.  Put

\[
\alpha:=\alpha_J=X+2B-3.
\tag{5.1}
\]

Since `X>=1` and `B>=2`,

\[
\alpha\ge2.
\tag{5.2}
\]

Choose `tau in Z` so that

\[
s':=s+\tau\alpha
\]

is the centered remainder modulo `alpha`:

\[
\boxed{|s'|\le\alpha/2.}
\tag{5.3}
\]

Define

\[
h':=h+\tau r^{(J)}.
\tag{5.4}
\]

Then

\[
\boxed{v\cdot h'=1,\qquad \sum h'_K=s'.}
\tag{5.5}
\]

A deterministic centered-remainder rule is:

```python
q, r = divmod(s, alpha)       # 0 <= r < alpha
if 2*r <= alpha:
    tau = -q
else:
    tau = -(q + 1)
s1 = s + tau*alpha
assert abs(2*s1) <= alpha
```

Now record the inequalities needed to bound `tau`.

First,

\[
C=X+B-1\le X+2B-3=\alpha,
\tag{5.6}
\]

because `alpha-C=B-2>=0`.

Second, from `|tau| alpha = |s'-s|`, (4.3), and (5.3),

\[
|\tau|
\le \frac{|s|}{\alpha}+\frac12
\le \frac{1+2BC}{\alpha}+\frac12.
\]

Using `alpha>=2` and `C<=alpha`,

\[
|\tau|
\le \frac12+2B+\frac12
=2B+1.
\tag{5.7}
\]

Finally define

\[
M:=X+2B+3.
\tag{5.8}
\]

Then

\[
2B+1\le M,
\]

hence

\[
\boxed{|\tau|\le M.}
\tag{5.9}
\]

# 6. Uniform coefficient bound for `h'`

For `K<B`, the Hermite-reduced coordinates satisfy `|h_K|<C<M`.

The update (5.4) changes only `J=B-2` and `J+1=B-1`.  The two nonzero coefficients of `r^(J)` are

\[
X+B-2,\qquad B-1,
\]

both less than `M`.  Therefore, using (5.9),

\[
|h'_J|,|h'_{J+1}|
\le M+M^2
\le2M^2.
\tag{6.1}
\]

All earlier coordinates remain `<M`.

The last coordinate `B` is not touched by (5.4).  From (4.2), and the trivial bounds `B<=M`, `C<=M`,

\[
|h'_B|=|h_B|
\le1+BC
\le1+M^2
\le2M^2.
\tag{6.2}
\]

Thus

\[
\boxed{\max_{A\le K\le B}|h'_K|\le2M^2.}
\tag{6.3}
\]

Also, from (5.3) and `alpha=M-6<M`,

\[
\boxed{|s'|\le\alpha/2<M/2.}
\tag{6.4}
\]

# 7. The three-site parity corrector

Take the difference of the two adjacent null relations at `B-2` and `B-1`:

\[
c:=-r^{(B-2)}+r^{(B-1)}.
\tag{7.1}
\]

It has support exactly on `B-2,B-1,B`, with coordinates

\[
\boxed{
(c_{B-2},c_{B-1},c_B)
=(-(X+B-2),\ X,\ B).
}
\tag{7.2}
\]

Indeed, at the middle coordinate,

\[
-(B-1)+(X+B-1)=X.
\]

Because both summands in (7.1) are `v`-null,

\[
\boxed{v\cdot c=0.}
\tag{7.3}
\]

Its coordinate sum is

\[
\sum c_K
=-(X+B-2)+X+B
=2,
\]

so

\[
\boxed{\sum c_K=2.}
\tag{7.4}
\]

Finally,

\[
\boxed{\max_K|c_K|\le M.}
\tag{7.5}
\]

This `c` is the only object in the proof for which a three-site support assertion is used.

# 8. Final vector and the claimed bound

Define

\[
\boxed{a:=2h'-s'c.}
\tag{8.1}
\]

Then, using (5.5), (7.3), and (7.4),

\[
v\cdot a
=2(v\cdot h')-s'(v\cdot c)
=2,
\]

and

\[
\sum a_K
=2s'-s'\cdot2
=0.
\]

Thus

\[
\boxed{\sum a_K=0,\qquad v\cdot a=2.}
\tag{8.2}
\]

Equivalently,

\[
\boxed{U\cdot a=2G.}
\tag{8.3}
\]

For the size, (6.3), (6.4), and (7.5) give, coordinatewise,

\[
|a_K|
\le2|h'_K|+|s'||c_K|
\le4M^2+\frac M2\,M
=\frac92M^2.
\]

Hence

\[
\boxed{
\max_K|a_K|
\le\frac92(X+2B+3)^2
<7(X+2B+3)^2.
}
\tag{8.4}
\]

So the proposed coefficient bound is valid, with substantial slack.

# 9. Exact parity audit

There is also a clean lattice explanation for why the target `2` is the right uniform target.

Define

\[
\delta:=\gcd_{K=A+1}^B(v_K-v_A)>0.
\tag{9.1}
\]

For every integer vector `x` with `sum x_K=0`,

\[
v\cdot x
=\sum_{K=A+1}^B(v_K-v_A)x_K.
\]

Conversely, every integer combination of the differences is realized by a zero-sum vector by putting the negative of the coefficient sum at `A`.  Therefore

\[
\boxed{
\{v\cdot x:x\in\mathbb Z^{B-A+1},\ \sum x_K=0\}
=\delta\mathbb Z.
}
\tag{9.2}
\]

Because all `v_K` are congruent to `v_A` modulo `delta`, the recurrence (1.2) gives, modulo `delta`,

\[
0
\equiv (X+K)v_A+(K+1)v_A
=\alpha_Kv_A.
\tag{9.3}
\]

Moreover

\[
\gcd(v_A,\delta)=1.
\tag{9.4}
\]

Indeed, any common divisor of `v_A` and `delta` divides `v_A` and every `v_K-v_A`, hence every `v_K`; primitivity of `v` forces that divisor to be `1`.

Thus (9.3) and (9.4) imply

\[
\delta\mid\alpha_K
\qquad(K=A,\ldots,B-1).
\]

Since there are at least two such adjacent indices and

\[
\alpha_{K+1}-\alpha_K=2,
\]

we obtain

\[
\boxed{\delta\mid2.}
\tag{9.5}
\]

The parity cases are therefore:

- If `X` is even, every `alpha_K=X+2K+1` is odd.  Hence `delta=1`.
- If `X` is odd, every `alpha_K` is even.  Then `delta` may be `1` or `2`, but in either case `delta|2`.

This is the abstract existence theorem.

The constructive proof above handles both cases uniformly.  The vector `2h'` always has even coordinate sum, and the three-site null vector `c` has sum exactly `2`.  Therefore `s'c` removes the sum with no need to construct a sum-one null vector.  In the odd-`X` case this is exactly the parity-safe correction one wants; in the even-`X` case it is still valid even though the zero-sum image has index `1`.

# 10. `A=0` endpoint audit

When `A=0`, the hypotheses force `B>=2`, so `J=B-2>=0` and all three corrector sites are in the window.

The special facts are

\[
U_0=1,\qquad G=1,\qquad v_0=1.
\]

Thus one may start Section 2 with `z=e_0` and omit prefix Euclid.  The first Hermite step uses

\[
r^{(0)}=(X,1,0,\ldots),
\]

which is valid even for `X=1`.  If `X=1`, the modulus in the first Hermite step is exactly `1`, so the reduced coordinate becomes `0`; there is no division-by-zero or exceptional parity issue.

At the shortest possible window `A=0,B=2`,

\[
J=0,
\qquad
\alpha=X+1\ge2,
\]

and

\[
c=(-(X),X,2)
\]

on the sites `0,1,2`, with sum `2` and `v dot c=0`.  Thus every endpoint in the proof remains legal.

# 11. Why this does **not** imply bounded support

The full-window character of the Bézout/Hermite part is essential to the theorem as proved.

The prefix-Euclid vector `z` can acquire a new nonzero coordinate whenever the prefix gcd drops.  The subsequent Hermite sweep only adds adjacent recurrence-null vectors; it bounds the coefficients, but it does not force the old coordinates to vanish.  The final vector

\[
a=2h'-s'c
\]

therefore may have support throughout `[A,B]`.

The fact that `c` has three-site support says only that the **last sum correction** is local.

There is a precise local obstruction.  Fix three sites `i<j<k`.  Any vector supported on these sites and having coordinate sum zero satisfies

\[
v\cdot x
=(v_i-v_k)x_i+(v_j-v_k)x_j.
\]

Hence the attainable selector values on that triple are exactly

\[
\boxed{
\gcd(v_i-v_k,v_j-v_k)\,\mathbb Z.
}
\tag{11.1}
\]

Global primitivity `gcd(v_A,...,v_B)=1`, and even the global theorem `delta|2`, do **not** imply that the local gcd in (11.1) divides `2` for a prescribed triple.

A symbolic family illustrates the issue without a finite scan.  Let `p>2` be prime and take

\[
X=p,\qquad A=1,\qquad B=p.
\]

For every `1<=K<=p-1`,

\[
U_K=(-1)^K\binom{p+K-1}{K}
\]

is divisible by `p`, because its numerator contains the single factor `p` while `K!` is a `p`-unit.  On the other hand

\[
U_p=(-1)^p\binom{2p-1}{p}
=(-1)^p\binom{2p-1}{p-1}
\equiv(-1)^p\pmod p,
\]

since

\[
\binom{2p-1}{p-1}
=\prod_{i=1}^{p-1}\frac{p+i}{i}
\equiv1\pmod p.
\]

Because `U_1=-p`, the gcd of the whole window divides `p`, while `U_p` is not divisible by `p`; hence

\[
G=1.
\]

Therefore every integer vector supported entirely in the early block
`{1,...,p-1}` has `v dot x` divisible by `p`, and so cannot have `v dot x=2`.

This does **not** prove that no cleverly chosen three nonconsecutive sites can ever work.  It proves the point needed here: the present theorem gives no uniform bounded-support conclusion, and one cannot replace the full-window Bézout step by an arbitrary fixed local block without an additional theorem.

# 12. Self-contained verifier skeleton

The following is a direct executable transcription of the proof.  It uses only exact integer arithmetic and the standard binomial function; it performs no search for small coefficients.

```python
from math import comb, gcd


def xgcd_pos(a, b):
    assert a > 0 and b > 0
    old_r, r = a, b
    old_x, x = 1, 0
    old_y, y = 0, 1
    while r:
        q = old_r // r
        old_r, r = r, old_r - q*r
        old_x, x = x, old_x - q*x
        old_y, y = y, old_y - q*y
    assert old_x*a + old_y*b == old_r
    return old_r, old_x, old_y


def construct(X, A, B):
    assert X >= 1
    assert 0 <= A <= B - 2

    U = {
        K: (-1 if K & 1 else 1) * comb(X + K - 1, K)
        for K in range(A, B + 1)
    }

    G = 0
    for K in range(A, B + 1):
        G = gcd(G, abs(U[K]))
    assert G > 0

    v = {K: U[K] // G for K in range(A, B + 1)}
    gv = 0
    for K in range(A, B + 1):
        gv = gcd(gv, abs(v[K]))
    assert gv == 1

    # Exact recurrence.
    for K in range(A, B):
        assert (K + 1) * v[K + 1] == -(X + K) * v[K]

    # Prefix Euclid: U dot z = G.
    z = {K: 0 for K in range(A, B + 1)}
    if A == 0:
        assert U[0] == 1 and G == 1
        z[0] = 1
    else:
        g = abs(U[A])
        z[A] = 1 if U[A] > 0 else -1
        for K in range(A + 1, B + 1):
            d, x, y = xgcd_pos(g, abs(U[K]))
            for j in range(A, K):
                z[j] *= x
            z[K] = y * (1 if U[K] > 0 else -1)
            g = d
        assert g == G

    assert sum(U[K] * z[K] for K in range(A, B + 1)) == G
    assert sum(v[K] * z[K] for K in range(A, B + 1)) == 1

    # Full-window Hermite reduction.
    h = dict(z)
    for K in range(A, B):
        mod = X + K
        rem = h[K] % mod
        t = (rem - h[K]) // mod
        h[K] += t * (X + K)
        h[K + 1] += t * (K + 1)
        assert h[K] == rem

    assert sum(v[K] * h[K] for K in range(A, B + 1)) == 1
    for K in range(A, B):
        assert 0 <= h[K] < X + K

    # Center the coordinate sum using r^(B-2).
    J = B - 2
    alpha = X + 2*B - 3
    assert alpha >= 2
    s = sum(h.values())

    q0, r0 = divmod(s, alpha)
    if 2*r0 <= alpha:
        tau = -q0
    else:
        tau = -(q0 + 1)

    hp = dict(h)
    hp[J] += tau * (X + J)
    hp[J + 1] += tau * (J + 1)
    s1 = sum(hp.values())

    assert s1 == s + tau*alpha
    assert abs(2*s1) <= alpha
    assert sum(v[K] * hp[K] for K in range(A, B + 1)) == 1

    # Three-site parity corrector c = -r^(B-2)+r^(B-1).
    c = {K: 0 for K in range(A, B + 1)}
    c[B - 2] = -(X + B - 2)
    c[B - 1] = X
    c[B] = B

    assert sum(c.values()) == 2
    assert sum(v[K] * c[K] for K in range(A, B + 1)) == 0

    # Final source.
    a = {K: 2*hp[K] - s1*c[K] for K in range(A, B + 1)}

    assert sum(a.values()) == 0
    assert sum(v[K] * a[K] for K in range(A, B + 1)) == 2
    assert sum(U[K] * a[K] for K in range(A, B + 1)) == 2*G

    M = X + 2*B + 3
    assert max(abs(a[K]) for K in range(A, B + 1)) <= 7*M*M

    return U, G, v, a
```

The final numerical assertion is justified symbolically by Sections 4–8; the verifier is only checking the implementation against those identities, not supplying evidence for the theorem.

# 13. Complete inequality ledger

For clarity, every size inequality used in the proof is listed here.

1. From `0<=A<=B-2` and `X>=1`:
   \[
   B\ge2,\qquad M=X+2B+3\ge8.
   \]

2. For `K<B`, Hermite reduction gives
   \[
   0\le h_K<X+K\le C:=X+B-1<M.
   \]

3. There are `B-A<=B` such terms, hence
   \[
   P=\sum_{K<B}h_K\le BC.
   \]

4. Monotonicity of `|v_K|` gives
   \[
   |h_B|\le1+P\le1+BC.
   \]

5. Therefore
   \[
   |s|\le1+2BC.
   \]

6. With `alpha=X+2B-3`,
   \[
   \alpha\ge2,
   \qquad
   C\le\alpha
   \]
   because `alpha-C=B-2>=0`.

7. Centering modulo `alpha` gives
   \[
   |s'|\le\alpha/2
   \]
   and
   \[
   |\tau|
   \le |s|/\alpha+1/2
   \le 1/2+2B+1/2
   =2B+1
   \le M.
   \]

8. The two coefficients of `r^(B-2)` are `<M`, so the two changed coordinates satisfy
   \[
   |h'_K|\le M+M^2\le2M^2.
   \]

9. The last coordinate satisfies
   \[
   |h'_B|\le1+BC\le1+M^2\le2M^2.
   \]

10. Hence
    \[
    \max|h'_K|\le2M^2.
    \]

11. Since `alpha=M-6<M`,
    \[
    |s'|<M/2.
    \]

12. The three nonzero corrector coefficients are
    \[
    -(X+B-2),\ X,\ B,

    so
    \[

# 14. Final theorem in compact form

> **Theorem.** Let `X>=1` and `0<=A<=B-2`.  For
> \[
> U_K=(-1)^K\binom{X+K-1}{K},\quad
> G=\gcd(U_A,\ldots,U_B),\quad
> v_K=U_K/G,
> \]
> there is an explicitly constructible integer vector
> `a=(a_A,...,a_B)` such that
> \[
> \sum a_K=0,
> \qquad
> v\cdot a=2,
> \qquad
> U\cdot a=2G,
> \]
> and
> \[
> \max_K|a_K|
> \le\frac92(X+2B+3)^2
> <7(X+2B+3)^2.
> \]
> One construction is: prefix extended Euclid for `U dot z=G`; full-window Hermite reduction by the adjacent null vectors `r^(K)`; one centered-sum adjustment by `r^(B-2)`; then the three-site corrector
> \[
> c_{B-2}=-(X+B-2),\quad c_{B-1}=X,\quad c_B=B,
> \]
> and `a=2h'-s'c`.
>
> The zero-sum image index satisfies `delta|2`; if `X` is even then `delta=1`, while for odd `X` one has `delta in {1,2}`.  The three-site corrector handles both cases uniformly.
>
> The theorem does **not** assert bounded support for `a`; only the final parity corrector is three-site.  The full-window Bézout/Hermite component is genuinely allowed to carry support across the whole cutoff window.

This proves the proposed statement, with a stronger coefficient constant and with all endpoint, parity, and Euclidean steps explicit.
