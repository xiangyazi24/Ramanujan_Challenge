# P3.2 exact combination audit: column factorial moments do **not** improve the BC row-autocorrelation ledger

## Verdict

The new column theorem

\[
\sum_{X<p\le 2X} Z(p)(Z(p)-1)
\ll \frac{X^{11/5}}{(\log X)^{3/5}}
\tag{1}
\]

does **not**, together with reflection, no-adjacent-zero, and the existing gap/resultant structure, yield any power-saving upper bound for

\[
A_h=\sum_x\sqrt{R_X(x)R_X(x-h)},
\qquad
R_X(x)=\#\{X<p\le2X:x\in Z_p\},
\tag{2}
\]

beyond the already-used

\[
\boxed{A_h\le T_X},
\qquad
T_X:=\sum_xR_X(x)=\sum_{X<p\le2X}Z(p).
\tag{3}
\]

Consequently, for every fixed \(\alpha>-1\), the sharp general weighted consequence of the currently proved incidence information is still

\[
\boxed{
\sum_{1\le h\le H}h^\alpha A_h
\le T_X\sum_{h\le H}h^\alpha
\ll_\alpha T_X H^{\alpha+1}.
}
\tag{4}
\]

There is no missing Cauchy--Schwarz interpolation that replaces the factor \(H^{\alpha+1}\) by a smaller power using (1). This is not merely a failure of the obvious proof: an explicit reflected, no-adjacency incidence family has

\[
D_h:=\sum_p\#\{x:x,x-h\in Z_p\}=0
\qquad(1\le h\le H)
\tag{5}
\]

while simultaneously

\[
A_h\gg T_X
\qquad(1\le h\le H),
\tag{6}
\]

so (4) is sharp up to constants throughout every power range \(H=X^\eta\) with \(\eta<1\) (and, with actual prime columns, certainly for \(H\ll X/\log X\)).

The same row/column mismatch blocks the TCUS common-state energy. There is an even simpler reflected star model with column sizes exactly two, hence column second factorial moment only \(O(X/\log X)\), but

\[
\sum_xR_X(x)(R_X(x)-1)\asymp \frac{X^2}{(\log X)^2}.
\tag{7}
\]

Thus the new theorem controls the **same-characteristic internal-pair diagonal**, whereas TCUS needs the **two-characteristic common-state off-diagonal**. The two-characteristic common-unit reduction is precisely the additional arithmetic layer needed; (1) does not supply its missing horizontal cancellation.

If one derives a first-moment estimate only from (1) and the prime count, then

\[
\boxed{
T_X\ll
\frac{X^{8/5}}{(\log X)^{4/5}}.
}
\tag{8}
\]

Hence one may insert

\[
\boxed{
\sum_{h\le H}h^\alpha A_h
\ll_\alpha
\frac{X^{8/5}H^{\alpha+1}}{(\log X)^{4/5}}.
}
\tag{9}
\]

But this is exactly what one gets by applying \(A_h\le T_X\) separately and summing. It gives **no enlargement whatsoever** of the Bettin--Chandee negligible region attributable to the column second moment. If the caller-local first-moment theorem gives a sharper \(T_X\), substitute that sharper value in (4); the conclusion about the \(H\)-exponent is unchanged.

# 1. Exact incidence matrix and the two incompatible signatures

Let

\[
\mathcal P_X=\{p\text{ prime}:X<p\le2X\},
\qquad P_X=|\mathcal P_X|,
\]

and extend every column by zero outside its natural state interval. Define the binary incidence matrix

\[
M_{x,p}:=\mathbf 1_{x\in Z_p}.
\tag{10}
\]

There are two marginals:

\[
z_p:=\sum_xM_{x,p}=Z(p),
\qquad
R_x:=\sum_{p\in\mathcal P_X}M_{x,p}=R_X(x).
\tag{11}
\]

The total incidence is

\[
T_X=\sum_pz_p=\sum_xR_x.
\tag{12}
\]

The new theorem is a statement about the **column factorial moment**

\[
C_X:=\sum_pz_p(z_p-1).
\tag{13}
\]

In matrix language,

\[
T_X+C_X
=\sum_pz_p^2
=\|M^T\mathbf 1_x\|_2^2.
\tag{14}
\]

By contrast, the common-state row energy is

\[
E_X:=\sum_xR_x(R_x-1),
\tag{15}
\]

so

\[
T_X+E_X
=\sum_xR_x^2
=\|M\mathbf 1_p\|_2^2.
\tag{16}
\]

Equivalently,

\[
C_X
=\sum_{x\ne y}(MM^T)_{x,y},
\tag{17}
\]

whereas

\[
E_X
=\sum_{p\ne q}(M^TM)_{p,q}
=\sum_{p\ne q}|Z_p\cap Z_q|.
\tag{18}
\]

These are **not the same off-diagonal mass**. The fact that \(MM^T\) and \(M^TM\) have the same nonzero singular spectrum does not equate their sums against the two different all-ones vectors.

This is the row/column signature distinction that must not be blurred:

```text
column factorial theorem:
    choose two STATES inside one fixed prime column p;

TCUS common-state energy:
    choose two distinct PRIME columns p,q sharing one state x.
```

One is \(p=q\) with \(x\ne y\); the other is \(p\ne q\) with the same \(x\).

# 2. What reflection and the gap resultant actually control

For a positive shift \(h\), define the same-column gap count

\[
D_h
:=\sum_{p\in\mathcal P_X}\sum_x
M_{x,p}M_{x-h,p}.
\tag{19}
\]

Every unordered pair of distinct states in one column has exactly one positive gap, hence

\[
\boxed{
\sum_{h\ge1}D_h=\frac12 C_X.
}
\tag{20}
\]

No adjacency says exactly

\[
D_1=0.
\tag{21}
\]

The continuant/gap-resultant certificate is also a statement about the summands of \(D_h\): if one column \(p\) contains \(x\) and \(x+h\), then (under the usual legal-window hypotheses) \(x\) is a root modulo \(p\) of the gap polynomial \(N_h\). The degree/resultant arguments therefore constrain **same-column gap incidences**.

Reflection remains column-local as well. Its involution is

\[
x\longmapsto p-1-x,
\tag{22}
\]

and crucially depends on \(p\). It is not one global permutation of the row set. Thus a state \(x\) shared by many prime columns may have a completely different reflected partner in every column.

The BC quantity is instead

\[
A_h=\sum_x\sqrt{R_xR_{x-h}}.
\tag{23}
\]

The exact expansion

\[
R_xR_{x-h}
=\sum_{p,q}M_{x,p}M_{x-h,q}
\tag{24}
\]

contains the same-column diagonal \(p=q\), counted by \(D_h\), but also the entire cross-characteristic part \(p\ne q\). The latter is not bounded by (20).

Indeed, pointwise

\[
\sum_pM_{x,p}M_{x-h,p}
\le \min(R_x,R_{x-h})
\le\sqrt{R_xR_{x-h}},
\]

so after summing,

\[
\boxed{D_h\le A_h.}
\tag{25}
\]

This is the **wrong direction** for the desired combination. The column theorem can bound a statistic lying below \(A_h\), not above it.

For \(\alpha\ge0\), (20) does give the legitimate weighted same-column estimate

\[
\boxed{
\sum_{h\le H}h^\alpha D_h
\le \frac{H^\alpha}{2}C_X
\ll
\frac{H^\alpha X^{11/5}}{(\log X)^{3/5}}.
}
\tag{26}
\]

But replacing \(D_h\) by \(A_h\) in (26) reverses (25) and is invalid.

# 3. The sharp upper bound for \(A_h\)

Put

\[
f_x:=\sqrt{R_x}.
\]

Then

\[
A_h=\langle f,\tau_hf\rangle.
\]

Cauchy--Schwarz gives

\[
A_h
\le \|f\|_2\|\tau_hf\|_2
=\sum_xR_x
=T_X.
\tag{27}
\]

Therefore for any nonnegative weights \(w_h\),

\[
\boxed{
\sum_{h\le H}w_hA_h
\le T_X\sum_{h\le H}w_h.
}
\tag{28}
\]

Taking \(w_h=h^\alpha\), \(\alpha>-1\), gives (4).

There is also an exact full-shift identity showing that no column statistic appears naturally:

\[
\sum_{h\in\mathbb Z}A_h
=\left(\sum_x\sqrt{R_x}\right)^2,
\tag{29}
\]

and hence

\[
\sum_{h\ge1}A_h
=\frac12\left[
\left(\sum_x\sqrt{R_x}\right)^2-T_X
\right].
\tag{30}
\]

The entire \(A_h\)-mass is determined by the **row marginal** \(R\). Knowing the factorial moment of the column marginal \(z\) does not determine it.

# 4. What the new theorem does imply for the first moment

Let \(P_X=|\mathcal P_X|\ll X/\log X\). From (14) and Cauchy--Schwarz,

\[
T_X^2
\le P_X\sum_pz_p^2
=P_X(T_X+C_X).
\tag{31}
\]

Thus

\[
T_X
\le P_X+\sqrt{P_XC_X}.
\tag{32}
\]

Using (1),

\[
\sqrt{P_XC_X}
\ll
\left(
\frac X{\log X}
\frac{X^{11/5}}{(\log X)^{3/5}}
\right)^{1/2}
=
\frac{X^{8/5}}{(\log X)^{4/5}}.
\]

Therefore

\[
\boxed{
T_X\ll\frac{X^{8/5}}{(\log X)^{4/5}}.
}
\tag{33}
\]

Combining with (28) gives (9).

This is the only unconditional route from the quoted second factorial theorem to the BC ledger that uses no additional arithmetic information. If the caller-local first-factorial theorem already gives (33), then the new second moment changes nothing in the BC calculation. If it gives something better, retain that better \(T_X\); the factor \(H^{\alpha+1}\) still cannot be improved from these inputs.

# 5. Countermodel I: the common-state star destroys any row-energy deduction

This model uses **actual prime labels** and exact reflection.

Let \(\mathcal P_X\) be the primes in \((X,2X]\), with \(P=P_X\). Choose a moving anchor

\[
a_X=\left\lfloor\frac X4\right\rfloor.
\]

For every \(p\in\mathcal P_X\), define the model column

\[
Z_p^{\rm star}:=\{a_X,\ p-1-a_X\}.
\tag{34}
\]

For sufficiently large \(X\):

- **reflection:** (34) is exactly invariant under \(x\mapsto p-1-x\);
- **no adjacency:** the two points have gap
  \[
  g_p=p-1-2a_X\gg X;
  \]
- **fixed-gap pileup:** \(g_p\) is distinct as \(p\) varies, so every fixed gap occurs in at most one column;
- **column size:** \(z_p=2\).

Hence

\[
T_X=2P,
\qquad
C_X=\sum_p2=2P.
\tag{35}
\]

So this family satisfies (1) with enormous room to spare, as well as any column first-moment upper bound weaker than \(O(X/\log X)\).

But the common anchor has

\[
R_{a_X}=P.
\]

The reflected partners are distinct, so

\[
E_X
=\sum_xR_x(R_x-1)
\ge P(P-1)
\asymp\frac{X^2}{(\log X)^2}.
\tag{36}
\]

Thus a column factorial moment of order only \(X/\log X\) is compatible with essentially maximal cross-column common-state energy.

This also explains why the fixed-anchor theorem from older P3.2 work does not save the argument: here the anchor \(a_X\) moves with the scale. In the actual Apéry problem, Lucas merely converts a star at a moving \(a_X\) into many prime divisors of the moving integer \(b_{a_X}\); its exponential height allows \(\asymp X/\log X\) primes of size \(X\) without contradiction.

# 6. Countermodel II: all short same-column gaps vanish, but every \(A_h\) is large

This is the exact obstruction to the proposed weighted aggregation.

Assume

\[
1\le H\le \min(X/8,P/4),
\]

and put \(L=2H\). Partition the actual prime columns as evenly as possible among the \(L\) anchor rows

\[
1,2,\ldots,L.
\]

Write \(a(p)\) for the anchor assigned to column \(p\), and set

\[
Z_p^{\rm flat}
:=\{a(p),\ p-1-a(p)\}.
\tag{37}
\]

Again reflection is exact. Also

\[
p-1-2a(p)
\ge X-1-4H
\ge X/2-1,
\tag{38}
\]

so there are no adjacent zeros and, much more strongly,

\[
\boxed{D_h=0\quad(1\le h\le H).}
\tag{39}
\]

Thus every short-gap incidence to which the BC range could apply is absent. Any bound supplied by the gap/resultant mechanism on those same-column short gaps is satisfied in its strongest possible form: zero.

Each column still has \(z_p=2\), so

\[
T_X=2P,
\qquad C_X=2P.
\tag{40}
\]

Let

\[
q=\left\lfloor\frac{P}{L}\right\rfloor.
\]

Every anchor row has \(R_a\ge q\). Hence for \(1\le h\le H\), using only anchor rows,

\[
A_h
\ge\sum_{a=h+1}^{L}\sqrt{R_aR_{a-h}}
\ge(L-h)q
\ge Hq.
\tag{41}
\]

Since \(P\ge2L\),

\[
q\ge\frac{P}{2L},
\]

and therefore

\[
\boxed{
A_h\ge \frac P4=\frac{T_X}{8}
\qquad(1\le h\le H).
}
\tag{42}
\]

Consequently, for every fixed \(\alpha>-1\),

\[
\boxed{
\sum_{h\le H}h^\alpha A_h
\gg_\alpha T_XH^{\alpha+1}.
}
\tag{43}
\]

Together with (4), this proves sharpness up to a constant.

Notice the mechanism: rows \(a\) and \(a-h\) are both popular, but their incidences are carried by **different prime columns**. No individual column contains the short gap \(h\). Hence no-adjacency and all same-column gap-resultant information are powerless against this configuration.

The model is an incidence countermodel, not a claim that these artificial columns are actual Apéry zero sets. Its role is precise: it proves that the stated row bound cannot be *deduced from the proven column moment plus the column-local structural signatures*. To rule it out for Apéry one needs an additional theorem that is genuinely cross-characteristic.

# 7. Why reflection does not turn the column theorem into a cross-column theorem

A tempting thought is that one common state \(x\in Z_p\) automatically gives the reflected second state \(p-1-x\), so perhaps a common-state star forces many column pairs and can be charged to \(C_X\).

The charge is only linear.

If one row \(x\) belongs to \(K\) prime columns, reflection produces one second zero in each of those \(K\) columns. Thus it creates \(O(K)\) ordered same-column zero pairs, which are seen by \(C_X\).

But the TCUS common-state energy contributed by that row is

\[
K(K-1),
\]

because it chooses two different prime columns. Therefore

```text
reflection charge to column second moment:   O(K)
TCUS common-state row energy:                 Theta(K^2)
```

The star model in §5 realizes this discrepancy exactly. The reflected gaps

\[
p-1-2x
\]

move with \(p\), so gap-resultant information at fixed \(h\) does not supply the missing extra factor of \(K\).

# 8. Consequence for Bettin--Chandee state expansion

Let

\[
S_\alpha(H):=\sum_{h\le H}h^\alpha A_h.
\]

The current pointwise ledger gives

\[
S_\alpha(H)\ll T_XH^{\alpha+1}.
\tag{44}
\]

The new column theorem does not change the power of \(H\). Inserting the first-moment consequence (33) gives

\[
S_\alpha(H)
\ll
X^{8/5}H^{\alpha+1}(\log X)^{-4/5}.
\tag{45}
\]

For \(H=X^\eta\), the exponent is

\[
\boxed{
\frac85+(\alpha+1)\eta.
}
\tag{46}
\]

This is exactly the exponent obtained by the old “\(A_h\le T_X\) separately” step once the same \(T_X\) is inserted. Therefore **the BC negligible region is not enlarged by this combination**.

Because the caller-local BC audit is not connector-visible, I will not invent its final comparison exponent. In general, if that ledger needs \(S_\alpha(H)=o(X^\beta)\), (45) only gives the pre-existing condition

\[
\frac85+(\alpha+1)\eta<\beta.
\tag{47}
\]

For example, against an \(X^2\) comparator this reads

\[
\eta<\frac{2}{5(\alpha+1)},
\]

but this last specialization should be used only if \(X^2\) is indeed the comparator in the caller-local ledger.

There is no legitimate extra \(3/5\)-saving from (1) in the \(h\)-sum.

# 9. Consequence for TCUS / the two-characteristic common-unit reduction

The common-unit reduction starts exactly where the column theorem stops. A common state for two different characteristics is an incidence

\[
M_{x,p}M_{x,q}=1,
\qquad p\ne q.
\]

Summing these gives the off-diagonal column Gram mass (18). The new theorem (1) instead sums internal pairs

\[
M_{x,p}M_{y,p},
\qquad x\ne y,
\]

inside one characteristic.

The two-characteristic common-unit parametrization may reorganize the \((p,q,x)\) triples, but without a genuine horizontal estimate it does not reduce their number. In particular, the column second moment supplies no covariance saving for the adaptive/common-state row.

So the correct status is:

\[
\boxed{
\text{column second factorial moment}
\not\Rightarrow
\text{two-characteristic common-state energy bound}.
}
\tag{48}
\]

What would be enough is a theorem of one of the following genuinely cross-column forms:

\[
\sum_xR_x(R_x-1)=o(T_X\cdot \text{relevant scale}),
\]

or a weighted version

\[
\sum_{h\le H}h^\alpha
\sum_x\sum_{p\ne q}
M_{x,p}M_{x-h,q}
\ll \text{desired BC threshold},
\]

or a spectral/coherence estimate for the column family that directly bounds the off-diagonal entries of \(M^TM\).

That is precisely a two-characteristic/horizontal statement, not another one-column resultant moment.

# 10. Sharpest valid combined statement

The exact theorem obtainable from the stated inputs is therefore:

> **Proposition (sharp incidence consequence of the new column theorem).**  Let \(M_{x,p}=1_{x\in Z_p}\), \(T_X=\sum_{x,p}M_{x,p}\), and suppose
> \[
> \sum_pZ(p)(Z(p)-1)\ll X^{11/5}(\log X)^{-3/5}.
> \]
> Then
> \[
> T_X\ll X^{8/5}(\log X)^{-4/5},
> \]
> and for every fixed \(\alpha>-1\),
> \[
> \sum_{h\le H}h^\alpha A_h
> \ll_\alpha X^{8/5}H^{\alpha+1}(\log X)^{-4/5}.
> \]
> The power \(H^{\alpha+1}\) cannot be reduced using only the column first/second moments, reflection, no adjacency, and column-local gap/resultant incidence constraints. Indeed there are reflected no-adjacency incidence families with \(D_h=0\) for every \(h\le H\) but \(A_h\gg T_X\) for every \(h\le H\).

And for TCUS:

> **Corollary (no common-state gain).**  The same inputs give no nontrivial upper bound for
> \[
> E_X=\sum_xR_X(x)(R_X(x)-1)
> \]
> beyond bounds coming from \(T_X\) and the number of columns. A reflected star with \(Z(p)=2\) has \(C_X=O(X/\log X)\) but \(E_X\asymp X^2/\log^2X\).

This is the first exact obstruction. The new \(11/5\) theorem is valuable column information, but it does **not combine with the BC fixed-state ledger in the desired direction**. The next theorem has to be horizontal/two-characteristic.
