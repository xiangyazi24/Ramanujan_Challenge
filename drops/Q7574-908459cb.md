## 2. Strip the selected q first: exact endpoint lattices

Because `q` is already known to divide both endpoints, define

```text
X_sigma,0 = E_sigma,0/q,
X_sigma,1 = E_sigma,1/q.
```

These are integers. Every lower prime is distinct from `q`, so

```text
P_sigma divides X_sigma,0 and X_sigma,1.                  (2.1)
```

Removing the forced `q` is mandatory for a noncircular audit. It changes logarithmic height by only `log q=O(log T)`.

### 2.1 Minus: the universal Lucas determinant is unimodular bookkeeping

Modulo `q`, reflection and Lucas give

```text
E_-1 - b_6 E_-0 = 0.
```

Thus

```text
R_-(q,t)
 := (E_-1-b_6 E_-0)/q
  = X_-1-b_6 X_-0                                      (2.2-)
```

is an integer. Every lower minus prime divides `R_-`. But

```text
(X_-0,R_-)
```

and this matrix has determinant one. Consequently

```text
gcd(X_-0,R_-) = gcd(X_-0,X_-1).                          (2.3-)
```

The determinant carrier is cleaner, but it contains exactly the same lower-prime ideal.

### 2.2 Plus: exact value/derivative factorization

Put

```text
X_6  = b_(6q+t)/q,
X_12 = b_(12q+t)/q.
```

The exact primitive carriers from Q7436 are

```text
R_+     = b_6 X_12 - b_12 X_6,
Gamma_+ = 2 b_12 X_6 - b_6 X_12.                         (2.2+)
```

They satisfy

```text
b_12 X_6  = R_+ + Gamma_+,
b_6  X_12 = 2R_+ + Gamma_+.                              (2.3+)
```

Hence, away from the fixed prime divisors of `b_6 b_12`, the ideals

```text
(X_6,X_12) and (R_+,Gamma_+)
```

are identical after localization. In particular,

```text
P_+ divides R_+ and Gamma_+.                              (2.4+)
```

This is an actual factorization of the high-load product into the two q-adic first-jet coordinates. It is not a rank reduction. Modulo `q`,

```text
R_+     = 6 b_6 b_12 D_q(t),
Gamma_+ =   b_6 b_12 C_q(t),                              (2.5+)
```

where

```text
C_q(t) = b_t/q mod q,
D_q(t) = the index-derivative jet mod q.
```

Since `gcd(P_+,q)=1`, writing `R_+=P_+R'` and `Gamma_+=P_+Gamma'` merely rescales `(C,D)` by the q-unit `P_+`. It does not force either coordinate to vanish.

### 2.3 Why taking products or minors gives no asymptotic gain

Trivially,

```text
P_sigma^2 divides X_sigma,0 X_sigma,1.
```

Likewise, in plus,

```text
P_+^2 divides R_+ Gamma_+.
```

But the logarithmic height of a product is the sum of the endpoint heights:

```text
log |X_0 X_1| = O_J(T),
log |R_+ Gamma_+| = O_J(T).
```

Thus the exponent two cancels on both sides and still yields only `(1.2)`. More generally, an `r`-homogeneous determinant or minor built from vectors already divisible by `P` gains `P^r`, while its height grows by the same factor `r`. This is a degree-multiplicity tautology, not compression.

## 3. Exact batched recurrence-transfer theorem

Write

```text
A(x) = 34x^3+51x^2+27x+5.
```

Define the Apéry continuants by

```text
K_0(X) = 1,
K_1(X) = A(X+1),
K_m(X) = A(X+m) K_(m-1)(X) - (X+m)^6 K_(m-2)(X).       (3.1)
```

For integers `r>=0` and `g>=2`, the exact cleared transfer is

```text
[product_(j=2)^g (r+j)^3] b_(r+g)
 = K_(g-1)(r) b_(r+1)
   - (r+1)^3 K_(g-2)(r+1) b_r.                          (3.2)
```

No denominator inversion is used in `(3.2)`.

### Theorem 3.1 — batched common-divisor return

Let `M` be squarefree. Assume

```text
M divides b_r and b_(r+g),
gcd(M,b_(r+1))=1.
```

Then

```text
M divides K_(g-1)(r).                                   (3.3)
```

#### Proof

Reduce `(3.2)` modulo `M`. The left side vanishes because `M|b_(r+g)`. The last term vanishes because `M|b_r`. Therefore

```text
K_(g-1)(r) b_(r+1) = 0 mod M.
```

The neighbor is a unit modulo `M`, so `(3.3)` follows. No pole-free hypothesis is needed. ∎

### 3.2 The neighbor is a unit for every factor of q P_sigma

Delete the fixed exceptional primes dividing `5 b_6 b_12 b_13`.

For minus, the start index is

```text
r_- = q-1-t = p+a.
```

Modulo a lower prime,

```text
b_(r_-+1) = b_(p+a+1) = 5 b_(a+1) mod p,
```

which is nonzero because `p|b_a` and Apéry zeros are not consecutive. Modulo `q`,

```text
b_(r_-+1) = b_(q-t) = b_(t-1) mod q,
```

again nonzero. Therefore `b_(r_-+1)` is a unit modulo `qP_-`.

For plus,

```text
r_+ = 6q+t = 6p+r_p.
```

Modulo a lower prime,

```text
b_(r_++1) = b_6 b_(r_p+1) mod p,
```

and modulo `q`,

```text
b_(r_++1) = b_6 b_(t+1) mod q.
```

Both are nonzero by the no-consecutive-zero law and the fixed exceptional-prime deletion.

### 3.3 Sign-specific batched divisibilities

For minus,

```text
r_- = q-1-t,
s_- = 6q+t,
g_- = s_--r_- = 5q+2t+1.
```

Theorem 3.1 gives

```text
q P_- divides K_(5q+2t)(q-1-t).                          (3.4-)
```

For plus,


Equations `(3.4±)` are the strongest genuinely batched consequences of the ordinary second-order recurrence.

## 5. What determinant/resultant saturation actually does

## 5.1 One projective return gives one equation

On any pole-free local chart over a field, write the transfer matrix in the basis `(b_(r+1),b_r)` as

```text
T = [[a,b],[c,d]].
```

At a zero start, the state line is generated by `(1,0)`. Requiring a zero at the endpoint says that the first coordinate of `T(1,0)` vanishes:

```text
a=0.                                                     (5.1)
```

This is one scalar equation. Reverse transfer asks that `T^(-1)` carry the endpoint zero line back to the start zero line. After inverting the determinant, that condition is again `a=0`. Therefore

```text
(forward return, reverse return) : det(T)^infinity
```

has the same radical as the principal ideal `(a)`.

Squaring a determinant, taking both orientations, or writing forward and backward resultants can increase formal multiplicity, but after saturation it does not produce a second independent prime factor.

## 5.2 Singular cuts are automatic determinant content

The long q6 intervals cross multiples of every modulus factor.

```text
plus modulo q:  six singular q-cuts;
minus modulo q: six singular q-cuts;
minus modulo p: a fixed number of p-block cuts;
plus modulo p:  a fixed number of p-block cuts.
```

The cleared transfer determinant contains high powers of those primes automatically. For example, in the plus q-transfer the denominator product has q-valuation 18. Nevertheless the event-specific continuant gains only one forced `q`:

```text
q divides K_(6q-1)(6q+t),
```

and its quotient is generically nonzero modulo `q`. The extra determinant valuation belongs to the singular block cuts, not to the zero return.

A global saturation has only three possibilities.

1. **Do not saturate.** One obtains `(3.4±)`, with height `O(T log T)`.
2. **Invert every singular determinant factor.** This removes the `p`- and `q`-components carrying the actual events.
3. **Desingularize prime by prime.** This preserves occurrence, but CRT separates the computation into one local return equation for each prime.

There is no fourth option in the current transfer algebra.

## 5.3 CRT prevents cross-prime rank gain

Since `P_sigma` is squarefree and coprime to `q`,

```text
Z/(qP_sigma)Z
  is isomorphic to F_q times product_(p|P_sigma) F_p.     (5.2)
```

Every recurrence matrix, determinant, and resultant is evaluated componentwise under `(5.2)`. The q-zero lives in the first component. Each lower zero pair lives in its own `F_p` component. The fact that the same characteristic-zero endpoint integer represents all components packages them into one scalar; it does not couple the local equations.

Chinese-remainder idempotents allow the residual local transfer coordinates to vary independently. Thus a determinant over `Z/(qP)Z` cannot force an additional q-adic jet condition from the lower-prime zeros, nor an additional p-adic lift from the upper mark.

## 5.4 Primewise saturated degrees grow with load

The local continuants make the growth explicit.

### Minus

For a lower minus prime, the two residual zeros are separated by

```text
r-a = 5d+2t+1,
m_p^- = r-a-1 = 5d+2t,
d=q-p>T/J.
```

The saturated local return has degree

```text
3m_p^- = 15d+6t > 15T/J.                                (5.3-)
```

For distinct odd lower primes, the values `m_p^-` are distinct and spaced by at least 10. Hence for a load `k_-`,

```text
sum_(p in S_-) m_p^-
  >= 5k_- T/J + 5k_-(k_--1),                             (5.4-)
```

up to harmless strict-endpoint rounding. Any occurrence-preserving product of the local saturated resultants therefore has total degree at least

```text
15k_- T/J + 15k_-(k_--1).                                (5.5-)
```

### Plus

Using the reflected residual pair `a<r`,

```text
r-a = p-6d,
m_p^+ = p-6d-1 = 7p-6q-1.                               (5.3+)
```

An actual pair cannot be consecutive, so `m_p^+>=1`; in fact the parity forces the positive values into one fixed class modulo 14. Distinct odd primes give spacing at least 14. Therefore

```text
sum_(p in S_+) m_p^+ = Omega(k_+^2),                     (5.4+)
```

and the total local continuant degree is `Omega(k_+^2)`.

For both signs, the logarithmic coefficient height of a product of local resultants is

```text
O( [sum_p m_p] log T ),                                  (5.6)
```

with leading-coefficient height at least linear in `sum_p m_p`.

Thus primewise saturation has the opposite of the desired behavior: its algebraic degree and height grow with the load. The global continuant compresses those many local equations to degree `Theta(T)`, but only by returning to the inferior scalar-height object `(3.4±)`.

## 5.5 Reflection does not add rank

For a lower zero pair, reflection creates a translated second pair. The exact continuant identity

```text
K_m(-X-m-2) = (-1)^m K_m(X)                              (5.7)
```

makes the reflected return the same equation after the center relation is imposed. The correctly saturated outer resultant still has degree `3m`; it does not square the occurrence prime.

This is the determinant/resultant analogue of the projective statement in Section 5.1.

## 6. Higher multiplicity audit

The only way determinant algebra could beat scalar height would be to force substantially more modulus multiplicity than expression degree.

### 6.1 A second q is not forced

In plus, Q7436 proves

```text
q divides R_+     iff D_q(t)=0,
q divides Gamma_+ iff C_q(t)=0 iff q^2 divides b_t.
```

Both stripped endpoints gain another q only on the smaller locus

```text
C_q(t)=D_q(t)=0.
```

Upper markedness alone gives neither condition. Therefore the transfer cannot count the selected q twice.

### 6.2 A second lower p is not forced

The lower leaves impose only

```text
p divides two residual Apéry values.
```

They contain no modulo-p^2 hypothesis. After local saturation the return is one reduced projective equation. Current recurrence/Lucas data therefore do not imply

```text
p^2 divides a primitive return carrier.
```

Some individual events may have accidental higher valuation; the point is that no uniform `P_sigma^2` divisibility follows from the owner interfaces.

### 6.3 Trivial powers do not help

If an expression `F` is degree `r` in endpoint coordinates that are each divisible by `P`, then `P^r|F`. But its logarithmic height is also `O(rT)`. Dividing the inequality by `r` returns the same scalar ceiling `k=O(T/log T)`.

To improve the relevant adaptive load using a carrier of logarithmic height `O(T)`, one would need a forced multiplicity tending roughly as

```text
T / (k log T),                                           (6.1)
```

not the fixed multiplicity one supplied here.

Then:

> 1. `qP_sigma` divides both sign-specific endpoint values.
> 2. After dividing both endpoints by the already-known factor `q`, `P_sigma` divides both quotients.
> 3. The cleared recurrence gives

> Consequently, the current recurrence/Lucas/reflection/determinant interfaces imply no high-load bound stronger than the direct scalar-height ceiling `|S_sigma|=O_J(T/log T)`.

The theorem does not exclude a new arithmetic factorization. It identifies exactly what that factorization would have to improve: either modulus multiplicity per unit height, or height per occurrence-preserving carrier.

## Final conclusion

The high-load product can be inserted into the recurrence exactly. The clean batched statement is

```text
qP_sigma divides one global zero-return continuant value.
```

This is genuine but not useful for C4: the continuant has degree `Theta(T)` and evaluated logarithmic height `O(T log T)`, while the original endpoint values already have the better height `O(T)`.

Determinant saturation exposes the real structure. After removing automatic singular-cut content, each prime contributes one projective return equation. CRT keeps those equations in separate characteristic components. Reflection repeats the same return, and the q-adic lift shows that the two plus endpoints retain a full two-coordinate value/derivative jet. No extra q or p multiplicity is forced.

The only actual factorization beyond the raw gcd is the fixed linear first-jet change of coordinates and the valuewise identity

```text
K_m(r)=qP_sigma H_sigma.
```

Neither lowers degree, coefficient height, or the modulus-to-height ratio. Therefore the matrix/resultant route does not supply the missing logarithm. A successful continuation must prove genuinely new arithmetic—most plausibly a theorem on primitive large-prime support, actual-zero-fibre return compression, or systematic higher p-adic multiplicity—not another saturation of the present endpoint transfer.
