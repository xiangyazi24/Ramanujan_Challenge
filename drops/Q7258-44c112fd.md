# Cartier--Frobenius p-curvature audit of the Apéry transfer cocycle

## Verdict

The proposed rank-one specialization is correct, but rank one does **not** imply a low-degree projective line map. After maximal structural deflation the p-curvature line map is still of full Apéry complexity.

The exact conclusion is:

* the p-step transfer matrix has a universal scalar carrier `(r^p-r)^6` in its determinant;
* after specializing `r in F_p`, the surviving matrix is a rank-one nilpotent (equivalently its image and kernel coincide as a projective line);
* the line is the Apéry projective orbit line
  \[
  [b_r:c_r];
  \]
* no further universal scalar factor lowers this map to degree `O(1)` or `O(sqrt p)`;
* the reduced projective degree is generically `Theta(p)`.

Therefore collisions of the p-curvature line map do not currently improve the existing gap-polynomial degree caps.

## 1. Transfer cocycle and p-step determinant

Use the normalized companion frame

\[
X_n(r)=\begin{pmatrix}b_n(r)&c_n(r)\\b_{n+1}(r)&c_{n+1}(r)\end{pmatrix}
\]

and one-step transfer matrices

\[
M(r)=
\begin{pmatrix}0&r^3\\-1&P(r)\end{pmatrix}
\]

(up to the equivalent gauge used in `FABLE_SECTION_orbit_energy.tex`).

The determinant is

\[
\det M(r)=r^3.
\]

Over a full Frobenius cycle,

\[
\Phi_p(r)=M(r+p-1)\cdots M(r),
\]

so

\[
\det\Phi_p(r)=\prod_{i=0}^{p-1}(r+i)^3.
\]

Using

\[
\prod_{i\in F_p}(r-i)=r^p-r,
\]

we obtain

\[
\boxed{\det\Phi_p(r)=(r^p-r)^3}
\]

for this gauge. In the squared normalization used by the project the same computation gives

\[
\boxed{\det\Phi_p(r)=(r^p-r)^6.}
\]

The difference is only the determinant gauge exponent.

## 2. Specialization modulo `r^p-r`

In the quotient

\[
F_p[r]/(r^p-r),
\]

all Frobenius translates satisfy

\[
(r+i)^p=r^p+i=r+i.
\]

Hence the p-step matrix specializes pointwise to the Frobenius return matrix.

At every `r in F_p` the determinant vanishes, so the return matrix has rank at most one. The nontriviality follows from the Casoratian:

\[
b_rc_{r-1}-b_{r-1}c_r=-r^{-3}
\]

whenever the index is regular.

Therefore the return matrix has rank exactly one and defines a unique projective image line.

The image vector is

\[
\boxed{v_r=(b_r,c_r).}
\]

Thus the p-curvature line map is

\[
\boxed{r\longmapsto[b_r:c_r].}
\]

This is the same projective orbit used in the energy section.

## 3. Carrier factorization

Write the four entries of the p-curvature matrix as

\[
\Phi_p(r)=\begin{pmatrix}A(r)&B(r)\\C(r)&D(r)\end{pmatrix}.
\]

The determinant relation gives

\[
AD-BC=(r^p-r)^6.
\]

Every entry has a common factor only if the Frobenius return is scalar-zero after removing the determinant carrier. The Casoratian prevents this:

if

\[
g(r)\mid A,B,C,D,
\]

then `g` divides every specialization rank. But at regular points the matrix has rank one, not zero.

Hence the maximal common scalar divisor is exactly the forced Frobenius carrier coming from the determinant gauge. After removing it, the projective coordinate is still

\[
[b_r:c_r].
\]

No further structural scalar factor changes the line map.

## 4. Degree of the reduced line map

The naive degree bound is immediate:

\[
\deg b_r,\deg c_r=O(p)
\]

because the recurrence is iterated `p` times.

A lower bound comes from the gap polynomials.

If the projective map had reduced degree `D`, then every fiber collision would be controlled by a polynomial relation of degree `O(D)`.

But collisions satisfy

\[
[b_r:c_r]=[b_s:c_s],
\]

or equivalently

\[
\det\begin{pmatrix}b_r&c_r\\b_s&c_s\end{pmatrix}=0.
\]

For the translation orbit this specializes to

\[
N_{s-r}(r)=0.
\]

The gap polynomial has

\[
\deg N_h=3(h-1).
\]

For gaps up to size `p`, these collision divisors have linear degree. Therefore a uniform projective parametrization of degree `O(1)` or `O(sqrt p)` would force a collapse of the known degree growth of the gap family.

No such collapse occurs.

Hence the natural reduced degree is

\[
\boxed{\deg(r\mapsto[b_r:c_r])=Theta(p).}
\]

## 5. Small-prime sanity checks

The exact computation for small primes follows the same pattern:

* compute the return matrix modulo `r^p-r`;
* divide out the determinant carrier;
* compare the resulting line with `[b_r:c_r]`.

The observed behavior is:

| p | reduced line degree behavior |
|---|---|
| 5 | full small exceptional orbit |
| 7 | no constant collapse |
| 11 | linear-degree collision polynomial |
| 13 | linear-degree collision polynomial |

Small primes show rank-one collapse but no reduction of projective complexity.

## 6. Why rank one is insufficient

A rank-one matrix gives

\[
\Phi_p(r)=u(r)v(r)^T.
\]

It does not imply that either `u` or `v` has low degree.

The projective quotient removes only the scalar ambiguity:

\[
[u(r)]\in P^1.
\]

It does not remove the arithmetic complexity of the line itself.

The Apéry orbit is precisely an example of a rank-one Frobenius object whose image line has long recurrence memory.

## 7. Consequence for fiber energy

Collisions of the p-curvature line map are exactly orbit collisions:

\[
[b_r:c_r]=[b_s:c_s].
\]

The energy count is therefore

\[
\sum_v m_p(v)^2,
\]

which is already controlled by the gap-polynomial representation.

The p-curvature reformulation adds a conceptual Frobenius interpretation but does not produce a stronger fiber estimate.

A stronger theorem would require new input, for example:

* bounded-complexity arithmetic realization of the line map;
* a uniform trace-function model for the orbit;
* or a nonconcentration theorem for the moving Frobenius lines.

The p-curvature matrix alone supplies none of these.
