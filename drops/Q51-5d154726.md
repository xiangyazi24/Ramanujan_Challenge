# Gap-polynomial envelope approach for Apéry zero detection

## Executive conclusion

The gap-polynomial idea is useful, but the proposed direction must be reversed. The polynomials `N_h` naturally detect *pairs* of zeros, not individual zeros. They give an excellent algebraic detector for clusters of zeros, but they cannot by themselves produce a low-degree majorant of `1_{Z_p}`. The correct construction is a hybrid:

1. use products of gap polynomials to remove the clustered part of `Z_p`;
2. handle the remaining isolated zeros using the projective orbit structure / recurrence polynomial rather than interpolation;
3. prove that the isolated contribution is negligible in the third-moment estimate.

A genuinely bounded-degree zero detector would amount to a much stronger theorem than currently available.

---

## 1. What the gap polynomials actually detect

Recall

```
N_h(x) = 0 mod p  iff  b_x = b_{x+h} = 0 mod p
```

(up to the known factorial normalization). Therefore:

- if `z` is a zero with another zero at distance `h`, then `N_h(z)=0`;
- if `z` is isolated, then generally `N_h(z) != 0` for all small `h`.

Thus the natural object

```
F_H(x)=prod_{h=2}^H N_h(x)
```

has the opposite behavior from a majorant:

```
F_H(z)=0       for clustered zeros
F_H(z)!=0      for isolated zeros
F_H(x)=?       for nonzeros
```

It is an *isolated-zero detector*, not a zero detector.

---

## 2. A correct hybrid envelope

Define

```
C_H = {z in Z_p : exists h<=H with z+h in Z_p or z-h in Z_p}
```

(the clustered zeros), and

```
I_H = Z_p \ C_H
```

(the isolated zeros).

For the clustered part define

```
A_H(x)=1-F_H(x)^{p-1}.
```

Because Fermat gives

```
y^{p-1}=0 if y=0,
          1 if y!=0,
```

we obtain

```
A_H(z)=1  for clustered zeros,
A_H(x)=0  where F_H(x) is nonzero.
```

The cost is degree:

```
deg(A_H)=(p-1)*sum_{h=2}^H 3(h-1)
       = O(p H^2).
```

This is too large for bounded conductor, but it is already much better structurally than the naive Fermat detector.

---

## 3. Improving the construction: avoid Fermat powering

The obstruction is the exponent `p-1`. We do not actually need an exact indicator. For moment bounds we need an upper envelope.

A better candidate is a rational envelope:

```
E_H(x)= sum_{h=2}^H w_h / (N_h(x)^2 + epsilon)
```

or over finite fields, using the projective recurrence coordinate

```
Q_x=(b_x:b_{x-1}) in P^1(F_p).
```

Zeros correspond to the single point `(0:1)`. A low-degree function on the orbit curve that has a pole at `(0:1)` can majorize the zero event after averaging.

This changes the problem from constructing a polynomial indicator to constructing a low-complexity test function on the recurrence orbit.

---

## 4. Is degree O(1) possible?

For arbitrary subsets of F_p of size p^{2/3}, no.

If a polynomial P has zero set containing exactly Z_p, then

```
deg(P) >= |Z_p|
```

unless P has additional zeros. Since |Z_p| can be as large as p^{2/3}, interpolation gives the generic barrier.

Therefore a bounded-degree detector requires exploiting special Apéry structure. It cannot follow merely from the cardinality estimate.

The needed statement would be something like:

```
There exists D=O(1) and rational functions R_p of degree <=D
such that Z_p is exactly the exceptional fiber R_p=0.
```

This is a strong geometric statement about the Frobenius orbit and is currently unproved.

---

## 5. The isolated-zero problem

The useful fact is not that isolated zeros are algebraically easy, but that they should be sparse.

The no-consecutive-zero property and the gap-polynomial counting argument imply that among zeros in a long interval, the number of points without nearby partners decreases as H grows.

Taking H=p^epsilon gives:

```
|I_H| << |Z_p|/H
```

heuristically.

Therefore the correct envelope is not expected to detect every zero exactly. It should satisfy:

```
1_Z <= E_cluster + E_isolated

sum_p,m E_isolated contribution = negligible.
```

The isolated term is the residual analytic problem.

---

## 6. Relation to HM_3

For the third moment, one does not need a pointwise detector. One needs:

```
sum_m K(m)(K(m)-1)(K(m)-2)
```

The clustered part can be expanded using the gap cloud:

```
N_h(r)=N_h(s)=0
```

which gives algebraic constraints and allows resultant / large sieve arguments.

The isolated triples are the dangerous contribution. They correspond to three independent orbit hits with no internal recurrence relation.

Thus the correct target is:

```
HM_3 = clustered contribution + isolated contribution
```

where

- clustered: gap-polynomial geometry;
- isolated: Frobenius randomness / K3 monodromy.

---

## 7. Final proposed construction

The realistic envelope is therefore:

```
E_{p,H}(x)=E_cluster(x)+E_iso(x)

E_cluster(x)=1-(prod_{h=2}^H N_h(x))^{p-1}

E_iso(x)=low-degree orbit test function
```

with parameters:

```
H=X^delta
```

chosen so that:

```
deg(E_cluster) is below the available p^{2/3} barrier,
and the isolated contribution is o(X^2 lambda^3).
```

The remaining missing theorem is precisely an anti-concentration statement for isolated Apéry zeros. This is likely where the K3/sheaf machinery must enter.

Hence the gap-polynomial envelope approach is promising, but the right endpoint is not a bounded-degree polynomial indicator. It is a decomposition of the zero set into an algebraically controlled clustered component and a genuinely arithmetic-random isolated component.
