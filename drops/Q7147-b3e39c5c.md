# P32 marked-initial-state R3 correction audit

## Summary verdict

The correction changes the conclusion of the previous audit in an important way: the marked covector is not annihilating the transported distinguished vector. At a distinguished zero it is encoded exactly by the return row.

The correct identity is

\[
\boxed{R_r=c_r L}
\]

whenever \(b_r=0\), where \(R_r=e_1^TM_r\), \(c_r=(C)_r\), and \(c_r\neq0\) by the Wronskian. This is a genuine marked statement. However, for a collection of returns it gives no new independent equation beyond the already-known zero conditions: all row identities are evaluations of the same one-dimensional kernel condition. The only possible surviving route is therefore not the row identity itself, but a genuinely nonlinear elimination in the start parameter or prime that uses the marked normalization.

The four-return transversality in \(q\) is real but, by itself, does not produce a square-root bound. The obstruction is that the Jacobian in the fibre direction has full rank for every ordinary return; it measures that the fibre crosses the zero hyperplane transversally, not that four crossings impose an extra arithmetic relation on the start index.

## 1. Exact row identity

Let

\[
S_n=(u_n,u_{n+1})^T,
\qquad S_r=M_rS_0,
\qquad M_r=T_{r-1}\cdots T_0,
\]

and define

\[
R_r=e_1^TM_r.
\]

For the distinguished basis

\[
B=(1,5)^T,\qquad C=(0,1)^T,
\]

we have

\[
b_r=R_rB,\qquad c_r=R_rC.
\]

Assume \(b_r=0\). Then \(R_r\) is a nonzero row vector with

\[
R_rB=0.
\]

Since the kernel of a nonzero row in dimension two is one-dimensional,

\[
\ker(R_r)=\mathbb F_pB.
\]

Now

\[
L(x,y)=y-5x
\]

satisfies

\[
L(B)=0,\qquad L(C)=1.
\]

Therefore \(L\) is the unique row vanishing on the line \(\mathbb F_pB\) and normalized by its value on \(C\). Hence

\[
R_r=\lambda L.
\]

Evaluating at \(C\) gives

\[
\lambda=R_rC=c_r.
\]

Therefore

\[
\boxed{R_r=c_rL.}
\]

The Wronskian

\[
 c_rb_{r-1}-c_{r-1}b_r=K/r^3
\]

with \(b_r=0\) gives

\[
 c_rb_{r-1}=K/r^3\neq0,
\]

so

\[
\boxed{c_r\neq0}.
\]

This proves the normalization is valid.

## 2. Two and four returns: what the row identity really gives

Suppose \(b_r=b_{r+h}=0\). Then

\[
R_{r+h}=e_1^TM_{r+h}
\]

and the transfer factorization gives

\[
R_{r+h}=e_1^TT_{r+h-1}\cdots T_rM_r.
\]

Using

\[
R_r=c_rL,
\]

we get

\[
R_{r+h}B=0
\]

which is exactly

\[
e_1^TT_{r+h-1}\cdots T_r(c_rB)=0.
\]

Because \(c_r\neq0\), this is the same as the usual return condition for the continuation from a zero.

Equivalently, if \(N_h\) denotes the cleared continuant, the identity reduces to

\[
N_h(r)=0.
\]

For several returns

\[
r_0<r_1<r_2<r_3,
\]

all equations are

\[
N_{r_{i+1}-r_i}(r_i)=0.
\]

Multiplying transport ratios gives the same cocycle identity as before. The row formulation adds the scalar factors \(c_{r_i}\), but they cancel because

\[
R_{r_i}=c_{r_i}L
\]

is merely a normalization of the same line. There is no new determinant equation among the four rows.

## 3. A sharply limited no-go theorem

### Lemma (marked-row no-go)

Let an expression be constructed only from:

1. the return rows \(R_{r_i}\),
2. their scalar normalizations \(c_{r_i}\),
3. transfer compositions between return points,
4. determinants of these two-dimensional rows,

and assume every occurrence of \(B\) enters only through the constraints

\[
R_{r_i}B=0.
\]

Then every resulting identity is generated by the continuant return equations

\[
N_{r_{i+1}-r_i}(r_i)=0
\]

and Wronskian normalizations. It cannot distinguish the marked fibre \(q=0\) from a projective fibre after imposing the same return equations.

### Proof

At a return,

\[
R_{r_i}=c_{r_i}L.
\]

Thus every row determinant involving a return row factors through \(L\). For example,

\[
\det(R_{r_i},R_{r_j})
=\det(c_{r_i}L,c_{r_j}L)=0.
\]

Any transfer composition between returns only reconstructs the same row equation at the endpoint. Hence elimination removes the intermediate scalars and leaves only the conditions that the transported distinguished vector returns to the kernel of \(R\), namely the continuant equations.

The proof does not apply to arbitrary marked expressions: an expression involving the fixed initial vector, the arithmetic value of \(B\), or derivatives in the initial condition is outside this class.

## 4. Fibre variation in q

For

\[
u(q)=B-qC,
\]

we have

\[
u_r(q)=b_r-qc_r.
\]

At a distinguished zero \(b_r=0\),

\[
\frac{d}{dq}u_r(q)\bigg|_{q=0}=-c_r.
\]

Since \(c_r\neq0\), every return is transverse:

\[
\boxed{u_r'(0)\neq0.}
\]

For four returns this gives a diagonal Jacobian

\[
J_q=(-c_{r_0},-c_{r_1},-c_{r_2},-c_{r_3}),
\]

whose entries are all nonzero.

However, this is only a statement about the one-dimensional fibre coordinate. It does not impose a relation on

\[
r_0,r_1,r_2,r_3.
\]

The four equations

\[
b_{r_i}-qc_{r_i}=0
\]

in variables \((q,r_i)\) have the obvious solution \(q=0\), and the nonzero Jacobian says that the solution is isolated in the q-direction. It does not say that the index parameters satisfy a codimension-one condition.

## 5. Could a resultant/Jacobian/discriminant give the square-root theorem?

Only if it uses extra information not contained in the row identities.

The proposed mechanism would need a polynomial in the start variable \(x\), such as

\[
\operatorname{Res}_q(F_0(x,q),F_1(x,q),F_2(x,q),F_3(x,q)),
\]

where

\[
F_i(x,q)=b_{x+s_i}-qc_{x+s_i}.
\]

But because \(q=0\) gives the distinguished zeros,

\[
F_i(x,0)=b_{x+s_i},
\]

the elimination contains the already-known common-zero locus. The q-Jacobian contributes only the unit factors

\[
\prod_i c_{x+s_i},
\]

which are nonzero at a clean zero and therefore do not reduce the degree or create a forced factor.

The exact algebraic reason is:

\[
\partial_qF_i(x,0)=-c_{x+s_i}
\]

is invertible in the local ring at a clean return. Hence the q-variable can be eliminated by the implicit function theorem algebraically; it does not create an additional vanishing equation.

A square-root route would require a second marked invariant whose vanishing is forced at q=0 but not forced by the return equations, for example a nontrivial arithmetic relation involving the initial lattice embedding of \(B\), not merely the projective orbit.

## 6. Finite obstruction

The existing projective phantom computations already give the correct warning. Nonzero fibres can have the same return pattern because the return equations only see the projective transfer orbit. The p=709,q=67 example shows that even a carrier-clean nonreflection repeat occurs away from q=0.

Thus any argument based solely on:

* return rows,
* companion ratios,
* q-transversality,
* transfer determinants,

cannot prove the adjacent-sum-to-\(p-1\) statement.

The remaining possible route must use genuinely arithmetic data attached to the distinguished initial vector, not just the marked covector representation of the same one-dimensional line.
