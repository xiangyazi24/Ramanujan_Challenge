# 2. Ratio proof of the sharp comparison

For `h>=2`, define

\[
R_h(x):=\frac{\alpha_h(x)}{\alpha_{h-1}(x)}.
\]

The base ratio is

\[
R_2(x)=a_{x+1}.
\]

By (1.5) and `b_t>0`,

\[
1<R_2(x)<34.
\tag{2.1}
\]

Assume `R_h>1`. Dividing (1.1) by `alpha_h` gives

\[
R_{h+1}=a_t-\frac{b_t}{R_h}.
\tag{2.2}
\]

Hence by (1.5),

\[
R_{h+1}>a_t-b_t>1.
\tag{2.3}
\]

Thus every `alpha_h` is positive and every ratio is greater than one.

Now set

\[
F(r):=34-\frac1r.
\]

For `r>1`, using (1.6),

\[
\begin{aligned}
F(r)-\left(a_t-\frac{b_t}{r}\right)
&=34-a_t-\frac{1-b_t}{r}\\
&>34-a_t-(1-b_t)\\
&>0.
\end{aligned}
\tag{2.4}
\]

Therefore

\[
\boxed{R_{h+1}<F(R_h).}
\tag{2.5}
\]

Now let

\[
C_h:=\frac{S_h}{S_{h-1}}\qquad(h\ge2).
\]

Since `S_1=1,S_2=34`,

\[
C_2=34,
\]

and the constant recurrence gives exactly

\[
C_{h+1}=34-\frac1{C_h}=F(C_h).
\tag{2.6}
\]

The map `F` is strictly increasing on `(0,infinity)`. From `R_2<C_2`, induction using (2.5)-(2.6) yields

\[
\boxed{1<R_h<C_h\qquad(h\ge2).}
\tag{2.7}
\]

Multiplying the ratios telescopes:

\[
\alpha_h
=\prod_{j=2}^hR_j
<\prod_{j=2}^hC_j
=S_h
\qquad(h\ge2).
\tag{2.8}
\]

Together with `alpha_1=S_1=1`, this proves the claimed theorem.

\[

\boxed{\lim_{x\to\infty}\alpha_h(x)=S_h.}

\boxed{\sup_{x\ge0}\alpha_h(x)=S_h.}

For `h>=2` the supremum is approached only at infinity, because (2.8) is strict at every finite `x`.

# 10. Exact arithmetic verification code

The following script uses exact `Fraction`/SymPy arithmetic. It verifies the algebraic identities in the ratio proof, the closed form for `S_h`, the inequality on a finite rational grid (including half-integral points), the odd-affine scaling recurrence, the exact `alpha=J/Q` identity, and the target-prime denominator-unit mechanism.

```python
from fractions import Fraction
from math import gcd, lcm
import sympy as sp


def P(t):
    return 34*t**3 + 51*t**2 + 27*t + 5


def N(h, x):
    if h == 0:
        return x*0
    if h == 1:
        return x*0 + 1
    nm1 = x*0
    n0 = x*0 + 1
    for j in range(1, h):
        n1 = P(x+j)*n0 - (x+j)**6*nm1
        nm1, n0 = n0, n1
    return n0


def alpha(h, x):
    den = x*0 + 1
    for j in range(2, h+1):
        den *= (x+j)**3
    return N(h, x) / den


def S(h):
    if h == 0:
        return 0
    if h == 1:
        return 1
    sm1, s0 = 0, 1
    for _ in range(1, h):
        sm1, s0 = s0, 34*s0-sm1
    return s0


# ------------------------------------------------------------
# 1. Symbolic identities used in the ratio proof
# ------------------------------------------------------------
t = sp.symbols('t')
Ps = 34*t**3 + 51*t**2 + 27*t + 5

assert sp.expand(Ps - t**3 - (t+1)**3 - 4*(2*t+1)**3) == 0
assert sp.expand(
    33*(t+1)**3 + t**3 - Ps - 4*(12*t**2+18*t+7)
) == 0
assert sp.expand(
    34*(t+1)**3 - Ps - (51*t**2+75*t+29)
) == 0


# ------------------------------------------------------------
# 2. Exact S_h closed form
# ------------------------------------------------------------
lam = 17 + 12*sp.sqrt(2)
for h in range(1, 15):
    closed = (lam**h - lam**(-h)) / (lam - lam**(-1))
    assert sp.simplify(closed - S(h)) == 0

assert [S(h) for h in range(1, 6)] == [1, 34, 1155, 39236, 1332869]


# ------------------------------------------------------------
# 3. Exact finite regression for the theorem
#    Includes every x=r/2 with 0<=r<=80.
# ------------------------------------------------------------
for h in range(1, 13):
    for r in range(0, 81):
        x = Fraction(r, 2)
        a = alpha(h, x)
        assert a > 0
        assert a <= S(h)
        if h >= 2:
            assert a < S(h)


# ------------------------------------------------------------
# 4. Reduced integral bridges and the banked L^5 denominator property
#    (finite regression only; the theorem is banked separately).
# ------------------------------------------------------------
def interval_lcm(x, h):
    L = 1
    for j in range(2, h+1):
        L = lcm(L, x+j)
    return L

for h in range(1, 9):
    for x in range(0, 25):
        a = alpha(h, Fraction(x, 1))
        U, V = a.numerator, a.denominator
        L = interval_lcm(x, h)
        assert (L**5) % V == 0
        assert U <= S(h) * V
        assert U <= S(h) * L**5


# ------------------------------------------------------------
# 5. Odd-affine target scaling
# ------------------------------------------------------------
def A(s):
    return 34*s**3 + 102*s**2 + 108*s + 40  # 8*P(s/2)


def J_direct(h, z):
    value = (2**(3*(h-1))) * N(h, Fraction(z, 2))
    assert value.denominator == 1
    return value.numerator


def J_rec(h, z):
    if h == 0:
        return 0
    if h == 1:
        return 1
    jm1, j0 = 0, 1
    for k in range(1, h):
        j1 = A(z+2*k)*j0 - (z+2*k)**6*jm1
        jm1, j0 = j0, j1
    return j0


def Qodd(h, z):
    out = 1
    for j in range(2, h+1):
        out *= (z+2*j)**3
    return out

for h in range(1, 10):
    for z in range(1, 41, 2):
        assert J_direct(h, z) == J_rec(h, z)
        assert Fraction(J_direct(h, z), Qodd(h, z)) == alpha(h, Fraction(z, 2))


# ------------------------------------------------------------
# 6. Exact target mark/unit mechanism
# ------------------------------------------------------------
def target_unit_audit(q, r, h):
    assert q % 2 == 1
    assert 0 <= r < r+h < q
    z = q + 2*r                 # z == 2r (mod q)
    D = 3*(h-1)
    lhs = J_direct(h, z)
    rhs = (2**D) * N(h, r)
    assert (lhs - rhs) % q == 0
    for j in range(2, h+1):
        assert (z + 2*j) % q != 0
        assert (2*(r+j)) % q != 0
    if N(h, r) % q == 0:
        assert lhs % q == 0
        assert gcd(q, Qodd(h, z)) == 1
        reduced = Fraction(lhs, Qodd(h, z))
        assert reduced.numerator % q == 0

# Q2143 geometry regression (selectedness is not asserted for this fixture).
q = 181
p1, p2 = 101, 103
h = p2-p1
r = p1 - (q+1)//2
assert r == 10
assert 2*p1-1 == q + 2*r
# This checks the fixed-polynomial congruence and denominator units.
target_unit_audit(q, r, h)


# ------------------------------------------------------------
# 7. Numerical constants (display only)
# ------------------------------------------------------------
print('lambda      =', sp.N(lam, 20))
print('log lambda  =', sp.N(sp.log(lam), 20))
print('c0          =', sp.N(sp.log(lam)/2, 20))
print('2log(1+rt2) =', sp.N(2*sp.log(1+sp.sqrt(2)), 20))
assert sp.simplify(sp.log(lam)/2 - 2*sp.log(1+sp.sqrt(2))) == 0
```
