# Gap-one branch: exact extrapolation telescope and the remaining endpoint obstruction

## Result

I do **not** get an all-prime proof of nonvanishing from the homogeneous Apéry/WZ data alone. I do get a strict reduction of the supplied scalar to a single endpoint value, together with a sharp no-go theorem for the direct homogeneous-companion/Casoratian telescoping class.

Write

\[
 p=2m+1,\qquad r=m-1,\qquad y=\lambda_r=\frac34,
 \qquad \lambda_j=j(j+1),
\]

and let the folded interpolation polynomial satisfy

\[
 P_m(\lambda_j)=b_j,\qquad P_m(Y)=(Y-y)A(Y).
\]

With the simple-zero normalization

\[
 D_r=P_m'(y)=A(y)\ne0,
\]

put \(t=Y+\tfrac14\), use the same letter \(A\) for the shifted polynomial \(A(t-\tfrac14)\), and define

\[
 G(t)=t^{m+1}-t,\qquad
 H(t)=\frac{G(t)}{t-1}=t(1+t+\cdots+t^{m-1}).
\]

Let \(V\), \(\deg V<m\), be the inverse of \(A\) modulo \(H\):

\[
 A(t)V(t)-1=H(t)\,\mathcal B(t).
\]

Then the gap-one scalar is exactly

\[
 \boxed{c_m=2\bigl(D_r^{-1}+V(1)\bigr)}
\]

and, because \(H(1)=m=-\tfrac12\) in \(\mathbf F_p\), equivalently

\[
 \boxed{c_m=\frac{4-\mathcal B(1)}{D_r}}.
\]

Thus the all-prime gap-one problem is reduced to the single endpoint theorem

\[
 \boxed{\mathcal B(1)\ne4.}
\]

This is strictly smaller than the reciprocal-sum formula: no interior sum remains.

There is also a useful full-inverse form. If \(U\), \(\deg U\le m\), is the inverse of \(A\) modulo the complete radical \(G\), then

\[
 \boxed{c_m=4U(1)+[t^m]U(t).}
\]

The direct WZ telescope with any fixed homogeneous companion cannot prove the required identity: for \(p\ge11\) it is already incompatible with the first three canonical Apéry values. That no-go is proved below.

No positivity is used anywhere, and no generic-tail argument enters.

## 1. The gap-one node is the missing root \(t=1\)

Shift by

\[
 t=Y+\frac14.
\]

At a folded node,

\[
 t_j=\lambda_j+\frac14
     =j(j+1)+\frac14
     =\frac{(2j+1)^2}{4}.
\]

As \(j=0,\dots,m\), these are exactly \(0\) together with the \(m\) nonzero quadratic residues in \(\mathbf F_p\). The latter form the subgroup of \(m\)-th roots of unity. Hence

\[
 \prod_{j=0}^{m}(t-t_j)=t(t^m-1)=t^{m+1}-t=G(t).
\]

For \(r=m-1\),

\[
 t_r=\lambda_{m-1}+\frac14=1,
\]

so deleting the unique zero node gives

\[
 H(t)=\prod_{j\ne r}(t-t_j)
     =\frac{t^{m+1}-t}{t-1}
     =t(1+t+\cdots+t^{m-1}).
\]

Because \(p=2m+1\), inside \(\mathbf F_p\)

\[
 m=-\frac12,
 \qquad H(1)=m=-\frac12.
\]

For every nonzero root \(\alpha\ne1\) of \(H\), \(\alpha^m=1\), and

\[
 G'(\alpha)=(m+1)\alpha^m-1=m,
 \qquad
 H'(\alpha)=\frac{m}{\alpha-1}.
\]

At the remaining root \(\alpha=0\),

\[
 H'(0)=1.
\]

These derivative values are the whole reason the reciprocal sum collapses.

## 2. A literal ratio/Riccati telescope exists, but its endpoint is nonlocal

Before using the sparse radical, one can telescope the requested reciprocal summand directly from ratios. For \(0\le j\le m-3\), all \(b_j,b_{j+1}\) are units, so put

\[
 R_j=\frac{b_{j+1}}{b_j},\qquad X_0=0,
\]

and transport

\[
 X_{j+1}=R_j\bigl(X_j+\lambda_j-y\bigr).
\]

Then

\[
 \frac{X_{j+1}}{b_{j+1}}-
 \frac{X_j}{b_j}
 =\frac{\lambda_j-y}{b_j},
\]

hence

\[
 \boxed{
 \sum_{j=0}^{m-3}\frac{\lambda_j-y}{b_j}
 =\frac{X_{m-2}}{b_{m-2}}.}
\]

This is an exact first-order discrete Riccati/ratio telescope. By itself it only renames the sum: the endpoint \(X_{m-2}\) remembers all previous ratios. The useful collapse comes from identifying that endpoint with a sparse-radical extrapolation value.

## 3. The inverse polynomial gives the exact global telescope

Since

\[
 P_m(Y)=(Y-y)A(Y),
\]

at every folded node \(j\ne r\),

\[
 A(\lambda_j)=\frac{b_j}{\lambda_j-y}.
\]

All those values are nonzero by the gap-one unit hypothesis. Therefore \(A\) is invertible modulo \(H\), and its unique inverse \(V\) of degree \(<m\) satisfies, at every root \(t_j\) of \(H\),

\[
 V(t_j)=\frac{1}{A(t_j)}
       =\frac{\lambda_j-y}{b_j}.
\]

Now interpolate \(V\) at the point \(t=1\). For a simple root \(\alpha\) of \(H\), the Lagrange weight is

\[
 w_\alpha=\frac{H(1)}{(1-\alpha)H'(\alpha)}.
\]

For every nonzero \(\alpha\ne1\),

\[
 w_\alpha
 =\frac{m}{(1-\alpha)m/(\alpha-1)}
 =-1.
\]

For \(\alpha=0\),

\[
 w_0=\frac{H(1)}{H'(0)}=m=-\frac12.
\]

The roots of \(H\) are exactly the folded nodes \(j=0,\dots,m-2\), together with \(j=m\) (the latter is \(t_m=0\)). Consequently

\[
 \boxed{
 V(1)
 =-\sum_{j=0}^{m-2}\frac{\lambda_j-y}{b_j}
   +m\frac{\lambda_m-y}{b_m}.}
\]

This is the desired reciprocal-sum telescope. It is not positivity and it is not a finite check; it is the exact Lagrange identity forced by the sparse radical \(t^{m+1}-t\).

## 4. Endpoint recurrence and the origin of the coefficient \(163/27\)

Use the canonical Apéry recurrence in the repository in the form

\[
 (j+1)^3b_{j+1}
 -(2j+1)(17j(j+1)+5)b_j
 +j^3b_{j-1}=0.
\]

At the zero \(j=r=m-1\), the middle term vanishes:

\[
 m^3b_m+(m-1)^3b_{m-2}=0.
\]

In \(\mathbf F_p\),

\[
 m=-\frac12,\qquad m-1=-\frac32,
\]

so

\[
 -\frac18 b_m-\frac{27}{8}b_{m-2}=0,
 \qquad
 \boxed{b_m=-27b_{m-2}}.
\]

Also

\[
 \lambda_{m-2}-y=3,
 \qquad
 \lambda_m-y=-1.
\]

Thus

\[
 \frac{\lambda_m-y}{b_m}
 =\frac{1}{27b_{m-2}},
\]

and the Lagrange endpoint becomes

\[
 \begin{aligned}
 V(1)
 &=-\sum_{j=0}^{m-3}\frac{\lambda_j-y}{b_j}
   -\frac{3}{b_{m-2}}
   -\frac{1}{54b_{m-2}}\\
 &=-\sum_{j=0}^{m-3}\frac{\lambda_j-y}{b_j}
   -\frac{163}{54b_{m-2}}.
 \end{aligned}
\]

Therefore

\[
 2V(1)
 =-2\sum_{j=0}^{m-3}\frac{\lambda_j-y}{b_j}
  -\frac{163}{27b_{m-2}}.
\]

Substitution into the scalar supplied in Q1610 gives the strict endpoint collapse

\[
 \boxed{c_m=2D_r^{-1}+2V(1).}
\]

This also audits the delicate sign/factor: the `163` is

\[
 163=162+1,
\]

where `162/27 = 6` is twice the \(j=m-2\) contribution \(3/b_{m-2}\), and `1/27` is twice the zero-node Lagrange contribution \(1/(54b_{m-2})\). In particular the zero-node contribution has the **same negative sign** as the \(j=m-2\) contribution in \(2V(1)\).

## 5. Smallest endpoint theorem: one Bézout value

Define the Bézout quotient \(\mathcal B\) by

\[
 A(t)V(t)-1=H(t)\mathcal B(t).
\]

At \(t=1\), \(A(1)=D_r\) and \(H(1)=m=-\tfrac12\), so

\[
 D_rV(1)-1=-\frac12\mathcal B(1).
\]

Hence

\[
 D_rV(1)=1-\frac12\mathcal B(1),
\]

and

\[
 \begin{aligned}
 c_m
 &=2\left(D_r^{-1}+V(1)\right)\\
 &=\frac{2}{D_r}\left(1+D_rV(1)\right)\\
 &=\frac{2}{D_r}\left(2-\frac12\mathcal B(1)\right).
 \end{aligned}
\]

Therefore

\[
 \boxed{c_m=\frac{4-\mathcal B(1)}{D_r}}.
\]

The simple-zero hypothesis already gives \(D_r\ne0\), so the gap-one trace problem is **exactly equivalent** to

\[
 \boxed{\mathcal B(1)\ne4.}
\]

This is the smallest terminal theorem I can obtain from the reciprocal-sum side: one scalar value of the Bézout quotient, with no sum and no generic tail.

### Equivalent complete-radical inverse form

Let \(U\), \(\deg U\le m\), be the unique inverse of \(A\) modulo

\[
 G(t)=H(t)(t-1)=t^{m+1}-t.
\]

Because \(U\equiv V\pmod H\) and \(\deg U\le m\), \(\deg V<m\), there is a scalar \(k\) with

\[
 U=V+kH.
\]

Then

\[
 AU-1=H(\mathcal B+kA).
\]

Divisibility by \(t-1\) forces

\[
 \mathcal B(1)+kD_r=0,
 \qquad
 k=-\frac{\mathcal B(1)}{D_r}.
\]

Since \(H\) is monic of degree \(m\),

\[
 [t^m]U=k=-\frac{\mathcal B(1)}{D_r}.
\]

And evaluating the full inverse at the missing root gives

\[
 U(1)=D_r^{-1}.
\]

Thus

\[
 \boxed{c_m=4U(1)+[t^m]U.}
\]

A future coefficient-recurrence attack on the sparse full inverse only has to exclude

\[
 [t^m]U=-4U(1).
\]

## 6. Sharp no-go: a fixed homogeneous WZ companion cannot telescope the reciprocal source

Let \(q_j\) be **any** homogeneous solution of the same Apéry recurrence. Its Casoratian with \(b_j\) is constant:

\[
 j^3\bigl(b_{j-1}q_j-b_jq_{j-1}\bigr)=C.
\]

For the canonical repository companion \(u_0=0,u_1=1\), \(C=1\); allowing arbitrary \(q\) merely changes the constant \(C\).

Whenever the relevant \(b\)'s are units,

\[
 \frac{q_j}{b_j}-\frac{q_{j-1}}{b_{j-1}}
 =\frac{C}{j^3b_{j-1}b_j}.
\]

Suppose the desired reciprocal summand came from a fixed homogeneous-companion telescope, i.e. there were a scalar \(\gamma\), independent of \(j\), such that on the interior

\[
 \frac{\lambda_j-y}{b_j}
 =\gamma\left(
   \frac{q_j}{b_j}-\frac{q_{j-1}}{b_{j-1}}
   \right).
\]

Then necessarily

\[
 \boxed{
 \gamma C=j^3(\lambda_j-y)b_{j-1}}
\]

for every such \(j\). The right side would have to be constant in \(j\).

For the canonical Apéry initial values

\[
 b_0=1,\qquad b_1=5,\qquad b_2=73,
\]

and \(y=3/4\), its first values are

\[
 K_1=\frac54,
 \qquad
 K_2=210,
 \qquad
 K_3=\frac{88695}{4}.
\]

Thus

\[
 4(K_2-K_1)=835=5\cdot167,
\]

while

\[
 4(K_3-K_1)=88690,
\]

and

\[
 \gcd(835,88690)=5.
\]

Consequences:

- For \(p=11\), the terms \(j=1,2\) are in range and \(835\not\equiv0\pmod{11}\), so the fixed homogeneous-companion telescope already fails.
- For every \(p\ge13\), \(j=1,2,3\) are in range; no prime \(p>5\) can make both displayed differences vanish because their gcd is \(5\).
- For \(p=7\), the gap-one reciprocal range is too short for this multi-index obstruction; this no-go deliberately says nothing about that weighted control.
- For \(p=5\), the interior reciprocal sum is empty, so this class is irrelevant.

This is a no-go for the **entire two-dimensional homogeneous solution space**, not just for the particular unit companion: adding a multiple of \(b\) to \(q\) adds a constant to \(q_j/b_j\), which disappears under the difference, and rescaling only changes \(C\).

The scope is intentionally sharp. It rules out telescopers of the form

\[
 \gamma\,\Delta(q_j/b_j)
\]

with \(q\) homogeneous and \(\gamma\) fixed. It does **not** rule out a variable-prefactor transform or an inhomogeneous/differentiated solution. Those acquire extra forcing terms and are exactly the discrete-Riccati/Green class represented by the \(X_j\) transport above. So the WZ Casoratian remains useful for normalization, but it cannot by itself turn this reciprocal source into a pure endpoint difference.

This obstruction uses the actual canonical recurrence and initial values; it does not alter or weaken reflection, the simple-zero assumption, or the unit hypotheses. Reflection is simply not needed for the contradiction.

## 7. What remains to prove all-prime nonvanishing

The remaining statement is no longer a summation problem. It is one of the equivalent endpoint exclusions

\[
 \mathcal B(1)\ne4,
\]

\[
 V(1)\ne-D_r^{-1},
\]

or

\[
 [t^m]U\ne-4U(1).
\]

The homogeneous WZ Casoratian cannot supply this by a direct quotient telescope, as Section 6 proves. Therefore an all-prime proof needs an additional **inhomogeneous** Apéry-specific identity, most plausibly one of:

1. a differentiated-recurrence identity that computes \(\mathcal B(1)\) (not merely a homogeneous Wronskian normalization);
2. a coefficient recurrence for the full inverse \(U\) modulo \(t^{m+1}-t\) that excludes \([t^m]U=-4U(1)\);
3. an endpoint relation coupling the derivative datum \(D_r\) to the extrapolation \(V(1)\).

The earlier Green audit in `drops/Q1593-eb80cfe0.md` is consistent with this diagnosis: after the homogeneous WZ part is normalized, a genuine forcing term remains. In gap-one language, that forcing has now been compressed to \(\mathcal B(1)\).

I therefore stop short of claiming \(c_m\ne0\) for every canonical gap-one prime. The exact theorem proved here is the reduction

\[
 c_m\ne0\iff\mathcal B(1)\ne4,
\]

plus the no-go above for the direct homogeneous-companion telescoping class.

The following Sage assertions are the exact audit I would run against each banked record. They check the old scalar against all three reduced endpoint forms and separately check every delicate sign/factor used above.

```sage
# Record contract:
#   p        odd prime, p = 2*m+1
#   b        list/dict with folded b_j for j=0,...,m
#   P        folded interpolation polynomial in Y with P(lambda_j)=b_j
# For the weighted p=7 control, feed its actual weighted P and b values.

def audit_gap_one_record(p, b, P, expect_zero=None):
    F = GF(p)
    RY.<Y> = PolynomialRing(F)
    Rt.<t> = PolynomialRing(F)

    m = (p - 1) // 2
    r = m - 1
    lam = lambda j: F(j*(j+1))
    y = F(3)/F(4)

    assert y == lam(r)
    assert P(y) == 0
    assert all(F(b[j]) != 0 for j in range(m+1) if j != r)

    D = P.derivative()(y)
    assert D != 0                    # simple zero

    q, rem = P.quo_rem(Y-y)
    assert rem == 0
    A = Rt(q(t-F(1)/F(4)))            # shifted A
    assert A(F(1)) == D

    G = t^(m+1) - t
    H, rem = G.quo_rem(t-1)
    assert rem == 0
    assert H == t*sum(t^k for k in range(m))
    assert H(F(1)) == F(m) == -F(1)/F(2)

    g, V, _ = A.xgcd(H)
    assert g.is_unit()
    V = (V/g) % H
    assert (A*V - 1) % H == 0

    Bez, rem = (A*V - 1).quo_rem(H)
    assert rem == 0

    # Endpoint recurrence and the two local folded differences.
    assert F(b[m]) == -F(27)*F(b[m-2])
    assert lam(m-2) - y == F(3)
    assert lam(m)   - y == -F(1)

    # Exact Lagrange extrapolation identity.
    Sfull = sum((lam(j)-y)/F(b[j]) for j in range(m-1))  # j=0,...,m-2
    assert V(F(1)) == -Sfull + F(m)*(lam(m)-y)/F(b[m])

    # The supplied reciprocal sum and its 163/27 terminal scalar.
    S = sum((lam(j)-y)/F(b[j]) for j in range(max(0,m-2)))  # j=0,...,m-3
    c_old = F(2)/D - F(2)*S - F(163)/(F(27)*F(b[m-2]))

    # Strict reductions.
    c_V   = F(2)*(F(1)/D + V(F(1)))
    c_Bez = (F(4)-Bez(F(1)))/D
    assert c_old == c_V == c_Bez

    # Full inverse modulo G.
    g, U, _ = A.xgcd(G)
    assert g.is_unit()
    U = (U/g) % G
    assert (A*U - 1) % G == 0
    assert U(F(1)) == F(1)/D
    assert U[m] == -Bez(F(1))/D
    c_U = F(4)*U(F(1)) + U[m]
    assert c_U == c_old

    # Explicit 163 decomposition/sign audit.
    assert F(2)*(-F(3)/F(b[m-2]) - F(1)/(F(54)*F(b[m-2]))) \
           == -F(163)/(F(27)*F(b[m-2]))

    if expect_zero is True:
        assert c_old == 0
        assert V(F(1)) == -F(1)/D
        assert Bez(F(1)) == F(4)
        assert F(4)*U(F(1)) + U[m] == 0
    if expect_zero is False:
        assert c_old != 0
        assert Bez(F(1)) != F(4)

    return {
        "p": p,
        "D": D,
        "V1": V(F(1)),
        "Bez1": Bez(F(1)),
        "c": c_old,
        "u_m": U[m],
    }
```

## Conclusion

The gap-one reciprocal sum is not intrinsically an interior object. In the shifted coordinate the missing node is \(t=1\), the other folded nodes are the roots of

\[
 H=t(1+t+\cdots+t^{m-1}),
\]

and their Lagrange weights at the missing node are all \(-1\), except the zero node, whose weight is \(-1/2\). That gives the exact telescope

\[
 V(1)
 =-\sum_{j=0}^{m-2}\frac{\lambda_j-y}{b_j}
  +m\frac{\lambda_m-y}{b_m},
\]

and after the endpoint recurrence it yields

\[
 \boxed{c_m=2(D_r^{-1}+V(1))
            =\frac{4-\mathcal B(1)}{D_r}
            =4U(1)+[t^m]U.}
\]

Therefore the correct next theorem for the gap-one branch is not another bound on the original sum. It is the single endpoint exclusion

\[
 \boxed{\mathcal B(1)\ne4.}
\]

The unit WZ Casoratian cannot prove that via a fixed homogeneous quotient telescope; the contradiction from \(b_0=1,b_1=5,b_2=73\) rules out that entire class for every relevant \(p\ge11\). Any successful all-prime closure must use the genuinely inhomogeneous differentiated recurrence or an equivalent coefficient identity for the full inverse \(U\).
