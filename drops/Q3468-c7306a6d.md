# 1. p-local setup and all necessary restrictions

Fix an odd prime `p`, and put

```text
R := Z_(p),
m := (p-1)/2,
abar := p-1-a,
0 <= a <= m.
```

We use only indices `0,...,p-1`.  This restriction matters for the companion: `c_n` is rational in general, but it is `p`-integral on this whole interval.

Indeed, starting from `c_0=0,c_1=1`, to construct `c_(n+1)` for `1<=n<=p-2` one divides by `(n+1)^3`, and every `n+1` is in `{2,...,p-1}`, hence is a `p`-unit.  Therefore

```text
c_0,...,c_(p-1) in R.                                 (1.1)
```

The same observation lets us reduce every recurrence step on `0,...,p-1` modulo `p` without crossing the singular step `(n+1)=p`.

If one allows support past `p-1` or transports across the step `n=p-1`, this clean rank-two `R`-module argument must be renormalized; it cannot simply be reused unchanged.

The midpoint is

```text
a=m  <=>  a=abar.                                     (1.2)
```

At the midpoint `delta_a-delta_abar=0`, so every nonzero-source/valuation claim must explicitly exclude it.

# 2. Reflection on the full two-dimensional solution space

The key polynomial symmetry is exact in characteristic zero:

```text
P(-1-x) = -P(x).                                      (2.1)
```

This follows immediately from

```text
P(x)=(2x+1)(17x^2+17x+5).
```

Let `y_0,...,y_(p-1)` be any `R`-valued solution of the recurrence on the interior indices `1,...,p-2`, and reduce modulo `p`.  Define the reflected sequence

```text
(Ty)_r := y_(p-1-r).                                  (2.2)
```

## 2.1 Reflection is an involutive endomorphism

Take `1<=r<=p-2` and apply the recurrence at `p-1-r`.  Modulo `p`, using `(2.1)`,

```text
(-r)^3 y_(p-r)
 = -P(r) y_(p-1-r) - (-(r+1))^3 y_(p-2-r).
```

Equivalently,

```text
(r+1)^3 (Ty)_(r+1)
 = P(r)(Ty)_r-r^3(Ty)_(r-1).                          (2.3)
```

Thus `T` maps the two-dimensional mod-`p` solution space to itself, and plainly

```text
T^2=1.                                                (2.4)
```

However, **this alone does not prove `T=1`**.  An involution on a two-dimensional vector space may have eigenvalues `+1,-1`; knowing that the Apéry solution `b` is fixed only proves that its line is in the `+1` eigenspace.

This is the first logical point at which a naive proof of (i) can fail.

## 2.2 The midpoint recurrence kills the `-1` eigenspace

Now use the actual Apéry coefficient.  At

```text
m=(p-1)/2
```

we have

```text
2m+1=p,
P(m) ≡ 0 mod p,
m+1 ≡ -m mod p.                                      (2.5)
```

The recurrence at `m` gives

```text
(m+1)^3 y_(m+1) = -m^3 y_(m-1) mod p.
```

Since `(m+1)^3 ≡ -m^3` and `m` is a `p`-unit,

```text
y_(m+1)=y_(m-1) mod p.                               (2.6)
```

For `v=Ty`,

```text
v_m     = y_m,
v_(m-1) = y_(m+1) = y_(m-1).                         (2.7)
```

A second-order recurrence on the interior has unique forward and backward continuation because every coefficient `r^3,(r+1)^3`, `1<=r<=p-2`, is a `p`-unit.  Hence `v=y` everywhere:

```text
boxed: y_(p-1-r) = y_r mod p     (0<=r<p).            (2.8)
```

So in this special recurrence the reflection involution is actually the identity on the whole solution space.

The argument also covers `p=3`: then `m=1`, and the single middle recurrence gives `y_2=y_0 mod 3`.

## 2.3 Apply to b and c

The Apéry sequence `b` is integral, and `(1.1)` makes `c` `p`-integral on the required interval.  Applying `(2.8)` to each gives

```text
boxed:
b_abar ≡ b_a mod p,
c_abar ≡ c_a mod p.                                   (2.9)
```

Thus statement (i) is correct.

The Casoratian is consistent with and strengthens the local two-solution picture.  From `(0.1)`, for every `0<=r<=p-2`,

```text
det [[b_r,b_(r+1)],
     [c_r,c_(r+1)]] = 1/(r+1)^3 in R^*.              (2.10)
```

Hence `b,c` form a basis of the local solution space modulo `p`.  But the Casoratian by itself does not replace the midpoint step `(2.6)`; an involution fixing one basis vector could still negate the other.

# 3. The reflected difference source

Define the finite-support source

```text
Omega := delta_a-delta_abar.                          (3.1)
```

For a source `Xi`, write

```text
B(Xi) := <Xi,b>,
C(Xi) := <Xi,c>.                                      (3.2)
```

Then

```text
B(Omega)=b_a-b_abar,
C(Omega)=c_a-c_abar.                                  (3.3)
```

By `(2.9)`,

```text
boxed:
B(Omega) in p Z,
C(Omega) in p R.                                      (3.4)
```

This holds for **every** `a` in the allowed interval; no target hypothesis `p|b_a` is needed.

Now use the assumed first-jet identity

```text
b_abar ≡ b_a-p g_a mod p^2.                          (3.5)
```

Then

```text
B(Omega)=b_a-b_abar ≡ p g_a mod p^2.                 (3.6)
```

Therefore

```text
boxed:
g_a != 0 mod p  ==>  v_p(B(Omega))=1.                (3.7)
```

In fact `(3.7)` is an equivalence whenever `(3.5)` is the full congruence being used:

```text
v_p(B(Omega))=1  <=>  g_a != 0 mod p.                (3.8)
```

## 3.1 Midpoint restriction

If `a=abar=m`, then

```text
Omega=0.                                              (3.9)
```

Moreover `(3.5)` becomes

```text
b_a ≡ b_a-p g_a mod p^2,
```

so necessarily

```text
g_a ≡ 0 mod p.                                       (3.10)
```

Thus the antecedent of `(3.7)` is automatically false at the midpoint.  There is no contradiction; the midpoint must simply be excluded from any nonzero-source formulation.

## 3.2 This is universal reflection divisibility, not target divisibility

A crucial interpretation point is that `p|B(Omega)` came from `(2.8)`, which holds for **every solution and every a**, not from `p|b_a`.

So even if one additionally assumes a genuine target

```text
p|b_a,                                                (3.11)
```

the single `p` in `(3.7)` is not a target-selective factor.  It is the universal reflection-return factor.  At a simple first jet `g_a!=0`, dividing it out leaves a `p`-unit:

```text
B(Omega)/p ≠ 0 mod p.                                 (3.12)
```

This construction therefore proves a clean local divided class, but not a target radical selector.

At a genuine target with `1<=a<p`, the Casoratian also gives the useful transverse unit

```text
a^3(b_(a-1)c_a-c_(a-1)b_a)=1,
```

hence

```text
p|b_a  ==>  c_a in F_p^*.                            (3.13)
```

That fact is not needed for `(3.7)`, but is needed in many companion-flux arguments.

# 4. Height audit: what (iii) really proves

The pushed `proof.tex` gives the positive integer formula for `b_n`.  We can prove the convenient growth bound directly from the recurrence.

## Lemma 4.1

For every `n>=0`,

```text
boxed: b_(n+1) >= 5 b_n.                              (4.1)
```

### Proof

The base case is `b_1=5b_0`.  Assume `b_n>=5b_(n-1)` for some `n>=1`.  Then

```text
(n+1)^3 b_(n+1)
 = P(n)b_n-n^3b_(n-1)
 >= (P(n)-n^3/5)b_n.
```

But

```text
P(n)-n^3/5-5(n+1)^3
 = (144/5)n^3+36n^2+12n
 >= 0.                                                (4.2)
```

Hence `b_(n+1)>=5b_n`.  Induction proves `(4.1)`.

In particular

```text
b_n >= 5^n.                                           (4.3)
```

Now suppose `a<abar`.  Since `p` is odd and `a` is strictly below the midpoint,

```text
abar-a = p-1-2a >= 2.                                 (4.4)
```

Thus

```text
b_abar >= 5^(abar-a)b_a >= 25 b_a,
```

and therefore

```text
|B(Omega)|
 = b_abar-b_a
 >= (24/25)b_abar
 >= (24/25)5^abar.                                    (4.5)
```

Since `abar>=m=(p-1)/2`,

```text
boxed:
log |B(Omega)|
 >= ((p-1)/2) log 5 + O(1).                           (4.6)
```

If `g_a!=0`, then `p|B(Omega)` exactly once, and

```text
log |B(Omega)/p|
 >= ((p-1)/2) log 5 - log p + O(1).                  (4.7)
```

## 4.1 What this rules out

Let `N` be the ambient P3.2/global parameter.  If the sector under discussion has

```text
p >= kappa N                                           (4.8)
```

for some fixed `kappa>0`, then `(4.6)` and `(4.7)` are `Omega(N)`.  Consequently neither the raw reflected scalar difference nor its divided-by-`p` scalar can be an `exp(o(N))` carrier.

This is the correct high-prime height obstruction.

## 4.2 What this does NOT rule out

The unqualified wording in (iii) is too strong for three reasons.

1. **Source coefficient height.**  The literal source `delta_a-delta_abar` has coefficients `+1,-1`; its coefficient height is constant.  The exponential lower bound concerns its evaluated Apéry moment, not the source vector itself.

2. **Ambient scale.**  If `p=o(N)`, then `Theta(p)` logarithmic moment height may still be `o(N)`.  The inequality `abar>=(p-1)/2` alone does not compare `p` with the global parameter.

3. **Midpoint.**  At `a=abar`, the source and both moments are zero.

Also, this is a per-`p`, per-`a` source.  It does not by itself rule out a different global construction using cross-prime cancellation, different supports, determinant combinations, or a genuinely target-sensitive unbalanced source.  Any such construction still has to pay its own characteristic-zero height, but `(4.6)` is not a universal no-go theorem for all source families.

# 5. Exact two-dimensional local source quotient

This makes statement (iv) precise and also shows exactly where “arbitrary divided class” is valid.

Let

```text
F := direct_sum_{r=0}^{p-1} R delta_r.
```

For `1<=r<=p-2`, define the recurrence source

```text
rho_r
 := r^3 delta_(r-1)-P(r)delta_r+(r+1)^3 delta_(r+1). (5.1)
```

Every homogeneous solution `y` satisfies

```text
<rho_r,y>=0.                                          (5.2)
```

Set

```text
S := F / <rho_1,...,rho_(p-2)>_R.                     (5.3)
```

Because `(r+1)^3` is a `p`-unit for every `r<=p-2`, the relations successively eliminate `delta_2,...,delta_(p-1)`.  Hence

```text
S is free of rank 2 over R, generated by delta_0,delta_1.  (5.4)
```

The moment map

```text
M : S -> R^2,
M(Xi)=(B(Xi),C(Xi))                                   (5.5)
```

is an isomorphism.  On the basis `delta_0,delta_1` its matrix is

```text
[[b_0,b_1],
 [c_0,c_1]]
=
[[1,5],
 [0,1]],                                              (5.6)
```

whose determinant is `1`.

Thus

```text
boxed:
Xi in pS  <=>  B(Xi) in pR and C(Xi) in pR.          (5.7)
```

This is the exact saturation statement needed in (iv).  It is stronger than a dimension count: there is no hidden `p`-torsion in this non-singular local quotient.

The equality `Omega=delta_a-delta_abar in pS` now follows immediately from `(3.4)`, even though the literal coefficients `+1,-1` are not multiples of `p` in `F`.  Divisibility occurs **after quotienting by recurrence coboundaries**.

# 6. Target-safe pairs and the arbitrary divided class

Define a local source class `Xi in S` to be **target-safe modulo p** if

```text
B(Xi) in pR.                                          (6.1)
```

Let `Omega_1,Omega_2 in S` both be target-safe.  Then

```text
B(Omega_1+Omega_2) in pR.                             (6.2)
```

Assume their companion moments cancel **modulo p**:

```text
C(Omega_1)+C(Omega_2) in pR.                         (6.3)
```

By `(5.7)`,

```text
boxed: Omega_1+Omega_2 in pS.                        (6.4)
```

Since `S` is free, there is a unique divided class

```text
Phi := (Omega_1+Omega_2)/p in S,                      (6.5)
```

and equivalently

```text
boxed: Omega_2=-Omega_1+p Phi.                       (6.6)
```

Now fix any target-safe `Omega_1`.  Conversely, for **every** `Phi in S`, define

```text
Omega_2 := -Omega_1+p Phi.                            (6.7)
```

Then

```text
B(Omega_2) = -B(Omega_1)+pB(Phi) in pR,
C(Omega_1)+C(Omega_2)=pC(Phi) in pR.                 (6.8)
```

So `Omega_2` is target-safe and the companion moments cancel modulo `p`.

Therefore:

```text
boxed:
Under MOD-p companion cancellation, the divided class Phi is arbitrary
in the full two-dimensional local source quotient S.                (6.9)
```

This is the precise valid form of statement (iv).

## 6.1 Exact companion cancellation is different

If instead one assumes the stronger condition

```text
C(Omega_1)+C(Omega_2)=0 in R                          (6.10)
```

exactly, then from `(6.6)`

```text
0 = C(Omega_1+Omega_2)=p C(Phi).
```

Since `R=Z_(p)` is torsion-free,

```text
boxed: C(Phi)=0.                                     (6.11)
```

Thus `Phi` is confined to the rank-one companion-zero line `ker C`, not arbitrary in `S`.

So the sentence “cancellation of their companion moments only says `Omega_1+Omega_2 in pS`, while the divided class can be arbitrary” is **false if cancellation means exact cancellation**.  It is correct if cancellation means cancellation modulo `p`.

More generally, if the companion sum is in `p^kR`, then the divided class satisfies

```text
C(Phi) in p^(k-1)R.                                  (6.12)
```

# 8. What the local quotient does and does not imply globally

The local calculation `(6.9)` has a useful negative consequence: **mod-`p` companion cancellation does not impose a canonical divided class, a zero divided class, or a fixed target character.**  Any argument asserting such a restriction from the two-dimensional local quotient alone is invalid.

But `(6.9)` is not a global construction theorem.

To turn arbitrary local classes `Phi_p` into a global P3.2 carrier one would still need, simultaneously:

```text
* one characteristic-zero source/certificate architecture valid for all
  relevant primes, rather than choosing Phi independently for each p;
* integral or p-unit denominator control at every target;
* support compatible with the actual cutoff/ray geometry;
* target-selective divisibility, not merely the universal reflection p;
* logarithmic height o(N) after all denominator/content saturation;
* compatibility across many primes without CRT coefficients of radical size.
```

The local freedom therefore rules out a **local linear-algebra no-go** based solely on mod-`p` companion cancellation.  It does not prove that a low-height global carrier exists.

Conversely, the growth estimate in Section 4 rules out only the naive scalar reflection difference in the high-prime sector; it does not rule out all possible two-source or unbalanced Green constructions.

# 9. Final corrected theorem

A clean theorem capturing exactly what is proved is the following.

> **Theorem (local reflected two-source audit).**
> Let `p` be an odd prime, `R=Z_(p)`, `0<=a<=(p-1)/2`, and `abar=p-1-a`.  Let `b,c` be the two solutions with initial states `(1,5)` and `(0,1)`.  Work only on indices `0,...,p-1`.  Assume
> `b_abar ≡ b_a-pg_a (mod p^2)`.
>
> 1. Every `R`-valued solution of the interior recurrence is reflection invariant modulo `p`; hence
>    `b_abar≡b_a` and `c_abar≡c_a (mod p)`.
> 2. For `Omega=delta_a-delta_abar`, both moments lie in `pR`, and
>    `B(Omega)/p≡g_a (mod p)`.  Thus if `g_a!=0`, then `v_p(B(Omega))=1`.
>    This `p` is universal reflection divisibility, not target-selective divisibility.
> 3. If `a=abar`, then `Omega=0` and necessarily `g_a=0 mod p`.
> 4. If `a<abar`, then
>    `log|B(Omega)| >= ((p-1)/2)log5+O(1)`; after division by the universal `p`, the same lower bound loses only `log p`.  Hence this scalar construction is not sublinear-height whenever `p` is a fixed positive fraction of the ambient parameter.
> 5. In the local source quotient `S` of `(5.3)`, the moment map `S -> R^2` is an isomorphism.  For target-safe `Omega_1,Omega_2`, companion cancellation modulo `p` is equivalent to `Omega_1+Omega_2 in pS`; the divided class is arbitrary and can be written through `Omega_2=-Omega_1+pPhi`.  Under exact companion cancellation, however, the divided class must satisfy `C(Phi)=0` and is not arbitrary.

That is the sharp cold-audit boundary.  No stronger global no-go or global positive carrier follows from these local facts alone.
