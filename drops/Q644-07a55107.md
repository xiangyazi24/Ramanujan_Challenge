# AFP via Katz equidistribution for the Apéry rank-2 sheaf

## Main conclusion

The proposed Katz equidistribution argument identifies the correct geometric mechanism, but the final step does **not** follow from Katz's theorem alone.

The observed near-constant discrepancy is real evidence for stronger arithmetic randomness, but the standard Katz/Deligne bound gives a square-root error after testing against a fixed family of trace functions. Turning this into a point-mass estimate on an orbit requires additional input.

The key distinction is:

```
large monodromy + purity  => cancellation for bounded-complexity observables

large monodromy + purity  !=  pointwise orbit discrepancy O(1)
```

---

# (A) Does Katz equidistribution give pointwise trace distribution?

No, not directly.

Katz's equidistribution theorem is formulated for averages of class functions on Frobenius conjugacy classes:

\[
\sum_{x\in U(F_p)} f(\theta_x).
\]

For a fixed irreducible representation \(\rho\), one obtains:

\[
\sum_x \mathrm{tr}(\rho(\theta_x))=O(C_F\sqrt p).
\]

This is extremely powerful, but the indicator

\[
1_{M(x)[v]=w}
\]

is not a class function. It is a matrix coefficient of the permutation representation of the finite group acting on \(\mathbf P^1(F_p)\).

Therefore one must decompose the permutation representation.

The identity is schematically:

\[
1_{g v=w}=\frac{1}{|G|}\sum_\rho d_\rho \mathrm{tr}(\rho(g)P_{v,w}).
\]

Katz controls each nontrivial \(\rho\), but the number and dimensions of representations grow with \(p\).

A naive summation gives something like:

\[
\sum_\rho d_\rho O(\sqrt p),
\]

which is much too large.

So the naive representation expansion does not prove O(1).

---

# (B) Vertical Sato-Tate / Chebotarev formulation

A vertical Chebotarev theorem gives a statement of the form:

\[
\#\{x\in F_p: \theta_x\in C\}
=
|F_p|\frac{|C|}{|G|}+O(\sqrt p\,\mathrm{complexity}).
\]

For conjugacy-invariant subsets C this is the correct framework.

However the event

\[
M(x)[5:1]=[0:1]
\]

is not conjugacy invariant. It depends on a vector in the standard representation.

Equivalently, it is a condition on a matrix coefficient, not on the characteristic polynomial of Frobenius.

Thus vertical Chebotarev applies only after passing to a larger representation (the projective orbit representation), and then the complexity of that representation becomes the issue.

---

# (C) Distribution in Sp_2 / SL_2

For a random element of \(SL_2(F_p)\), the probability that a fixed vector is mapped to a fixed projective point is exactly approximately:

\[
\frac1{p+1}.
\]

This matches the computational observation:

\[
\chi^2/(p+1)\rightarrow1.
\]

The expected number of visits in a length-p orbit is therefore:

\[
p\cdot\frac1{p+1}\approx1.
\]

This explains the Poisson(1) / Poisson(1/2) phenomenon.

But the expectation is not the same as a uniform bound for every p.

---

# (D) Why the mod-p trace issue is subtle

Katz's theory is fundamentally an \(\ell\)-adic theory with

\[
\ell\neq p.
\]

The Frobenius trace is an algebraic integer obtained from \(\ell\)-adic cohomology.

AFP asks about:

\[
b_r\equiv0\pmod p.
\]

This is reduction in the defining characteristic.

Deligne's bounds control the complex absolute value:

\[
|\mathrm{Tr}(\mathrm{Frob}_r)|\leq C p^{w/2},
\]

but they do not directly control divisibility of the trace by p.

This is the same obstruction identified earlier: geometric equidistribution does not automatically imply arithmetic anti-concentration modulo p.

---

# (E) Why the computation is much better than the naive Katz bound

The experimental fact

\[
D_2\approx p^{0.03}
\]

suggests that the Apéry family has extra structure.

The likely reason is that this is not a generic representation-theoretic phenomenon. The Apéry recurrence has:

1. bounded conductor;
2. rank 2;
3. geometric monodromy containing SL_2;
4. a single orbit in \(\mathbf P^1\);
5. strong rigidity of the local system.

The relevant object is not the full regular representation of \(SL_2(F_p)\), but the very small permutation representation:

\[
SL_2(F_p)\curvearrowright \mathbf P^1(F_p).
\]

This representation has only two irreducible constituents:

\[
1\oplus V_{\mathrm{Steinberg}}.
\]

This is the crucial simplification.

The indicator of a projective point is therefore not spread over all representations of GL_2. It only sees the Steinberg representation.

Hence the spectral expansion is:

\[
N_w=1+\frac{1}{p+1}\sum_x \mathrm{St}(M(x))_{v,w}.
\]

The error is governed by one bounded-complexity representation, not all irreducibles.

This explains why the observed discrepancy can be close to constant rather than \(\sqrt p\).

---

# What theorem is actually needed?

The missing theorem is a projective-orbit version of Katz equidistribution:

For a geometrically irreducible rank-2 sheaf with

\[
G^{geom}=SL_2,
\]

prove that for every projective point y:

\[
\#\{r:M(r)v=y\}
=1+O(1).
\]

Equivalently:

\[
\left|\sum_r \mathrm{St}(M(r))\right|=O(p).
\]

Standard Katz gives only:

\[
O(\sqrt p)
\]

for normalized traces, which is insufficient unless one exploits the special low-dimensional permutation representation.

---

# Consequence for AFP

If this projective equidistribution theorem is proved, then:

\[
Z_p=\#\{r:b_r=0\pmod p\}
\]

is exactly a return count to one point in \(\mathbf P^1(F_p)\).

The reflection law gives the factor of two, and projective mixing gives:

\[
Z_p=O(1).
\]

Therefore the computational breakthrough is pointing to a sharper statement than generic Katz:

\[
\boxed{
\text{Apéry AFP follows from projective SL}_2\text{ equidistribution, not full GL}_2\text{ representation expansion.}
}
\]

The special feature is the rank-2, SL_2, projective action: the orbit indicator lives in a bounded-complexity representation (Steinberg), avoiding the dimension explosion of the full representation ring.
