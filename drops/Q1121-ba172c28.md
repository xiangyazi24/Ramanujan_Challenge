# Audit of the mod-$p^2$ coefficient theorem

The proposed replacement for Q1118 is the correct piecewise statement. The previous constant-main-term expansion fails because the low base-$p$ digit is not uniform: the carry locus contributes a separate valuation-one branch.

## 1. The no-carry branch ($t>0$, $0\le u\le p-t$)

Write
\[
 s=t+u-1<p.
\]
Then
\[
 C_u=\binom{(A+k-1)p+s}{Ap+t-1}.
\]
Lucas gives immediately
\[
 C_u\equiv \binom{A+k-1}{A}\binom{s}{t-1}\pmod p.
\]

For the $p^2$ lift, split the factorial products into multiples of $p$ and units. The multiple-of-$p$ factors give the high digit binomial
\[
B=\binom{A+k-1}{A},
\]
while the unit parts give
\[
\prod_{i=1}^{s}\left(1+\frac{(A+k-1)p}{i}\right)
\left(\prod_{i=1}^{t-1}\left(1+\frac{Ap}{i}\right)\right)^{-1}
\left(\prod_{i=1}^{u}\left(1+\frac{(k-1)p}{i}\right)\right)^{-1}.
\]
Modulo $p^2$ this is
\[
1+p((A+k-1)H_s-AH_{t-1}-(k-1)H_u).
\]
Therefore
\[
\boxed{C_u=B\binom{t+u-1}{t-1}\left[1+p((A+k-1)H_{t+u-1}-AH_{t-1}-(k-1)H_u)\right]\pmod {p^2}.}
\]

The endpoint $u=p-t$ is still no-carry because $s=p-1$; no borrow occurs. This is the last value in the first branch.

## 2. The one-carry branch ($p-t<u<p$)

Put
\[
a'=t+u-1-p,
\]
so $0\le a'\le p-2$. Now
\[
(A+k-1)p+t+u-1=(A+k)p+a'.
\]
The denominator has low digit $t-1$, so the subtraction requires exactly one borrow. Hence $v_p(C_u)=1$.

The high digit after the borrow is $A+k$, and the low digit contribution is
\[
\frac{a'!}{(t-1)!u!}
\]
with the Wilson sign from replacing the missing block of length $p$:
\[
(-1)^{p-1-u}=(-1)^u.
\]
Combining with the high-digit carry gives
\[
\boxed{
\frac{C_u}{p}=-k\binom{A+k}{A}\frac{a'!}{(t-1)!u!}\pmod p .
}
\]

The boundary $u=p-t$ is excluded because $a'=-1$ there; it belongs to the previous branch. The boundary $u=p-1$ gives $a'=t-2$, and the factorial expression remains valid (including $t=1$ where $a'=p-2$).

No counterexample occurs for $r=0,1,p-1$ because those values concern the later digit factor and do not alter the carry classification above.

## 3. The $t=0$ branch

Now
\[
M=Ap,
\]
and
\[
C_u=\binom{(A+k-1)p+u-1}{Ap-1}.
\]
For $u=0$ the standard Jacobsthal/Wolstenholme lift gives
\[
\boxed{C_0=\binom{A+k-2}{A-1}\pmod {p^2}.}
\]

For $1\le u<p$, the denominator low digit $p-1$ forces exactly one borrow. The quotient by $p$ is
\[
\boxed{
\frac{C_u}{p}=(A+k-1)\frac{B_0}{u}\pmod p,
\qquad B_0=\binom{A+k-2}{A-1}.
}
\]

Thus formula (3) is also correct.

The smallest checks are:

* $p=7,A=k=1,t=0,u=1$: $C_1=\binom7 6=7$, and $C_1/p=1=(A+k-1)B_0/u$.
* $p=7,A=1,k=2,t=0,u=2$: $C_2/p=3$, matching $(2)B_0/2=3$ mod $7$.

No counterexample exists in the stated range.

# Correct coefficient polynomial split

Define
\[
F(X)=\sum_{u=0}^{p-1}C_uX^{p-1-u}.
\]
Write
\[
F=F_0+pF_1\pmod {p^2}.
\]

For $t>0$:

\[
F_0=\sum_{u=0}^{p-t}B\binom{t+u-1}{t-1}X^{p-1-u},
\]

and
\[
F_1=\sum_{u=0}^{p-t}B\binom{t+u-1}{t-1}
((A+k-1)H_{t+u-1}-AH_{t-1}-(k-1)H_u)X^{p-1-u}
\]

plus the carry contribution
\[
\sum_{u=p-t+1}^{p-1}
\left(-k\binom{A+k}{A}\frac{(t+u-1-p)!}{(t-1)!u!}\right)X^{p-1-u}.
\]

For $t=0$:

\[
F_0=B_0X^{p-1},
\]

and
\[
F_1=\sum_{u=1}^{p-1}(A+k-1)\frac{B_0}{u}X^{p-1-u}.
\]

This is the required exact piecewise Cartier split.

# Interaction with the short $p$-step lift

Use the corrected identity
\[
(E-1)^p=(E^p-1)+p\Theta_p(E)\pmod {p^2},
\]
where
\[
\Theta_p(E)=\sum_{i=1}^{p-1}\frac{E^i}{i}\pmod p.
\]
The sign is positive. The Q1118 sign error changes the defect by a nonzero Cartier correction.

Applying the operator to the coefficient polynomial gives
\[
(E-1)^pF=(E^p-1)F_0
+p\big((E^p-1)F_1+\Theta_p(E)F_0\big)\pmod {p^2}.
\]
The known short $p$-step lift removes the first term and the transported $F_1$ term. Therefore the normalized remaining defect is exactly
\[
\boxed{
\Delta_p(F)= (E^p-1)F_1+\Theta_p(E)F_0
\pmod p,
}
\]
with $F_0,F_1$ the piecewise polynomials above.

The defect is therefore not a constant Bernoulli correction: it contains the explicit carry polynomial. Iterating the decomposition over base-$p$ digits repeatedly extracts the low digit factors and their carry corrections. It does not create a new smaller characteristic-zero carrier by itself; the iteration reproduces the digitwise $b_r$ factor together with these explicit mod-$p$ Cartier defects. Any stronger compression would require an additional identity for the carry polynomials, not merely the recurrence dimension.
