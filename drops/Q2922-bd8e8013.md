## Verdict

**CONFIRMED, with one scope qualification on the prime-power sandwich.**

Assuming the banked exact corank formula

\[
c_N(p):=\operatorname{corank}_{\mathbf F_p}J_N
=\left\lfloor\frac Np\right\rfloor
+\mathbf 1_{p\mid b_{N\bmod p}}
\tag{1}
\]

for every prime \(p\), the proposed adjacent-size selector is correct:

\[
A=d_{n-q}(n),\qquad
B=d_{n-q-1}(n-1),
\]
\[
T=\operatorname{Sat}(A;B),\qquad
W=\operatorname{Sat}(T;n),
\]
with
\[
\operatorname{Sat}(x;y)=\frac{x}{\gcd(x,y^x)}
\]
satisfy

\[
\boxed{\operatorname{rad}(W)=R_q(n)},
\]
where
\[
R_q(n)=
\prod_{\substack{n/(q+1)<p\le n/q\\ p\mid b_{n-qp}}}p.
\]

There is no hidden endpoint failure at \(q=1\), no exception at \(p=2,3,5\), and the \(r=0\) contamination is exactly the lower-endpoint prime \(p=n/(q+1)\), when that number is prime; it is removed by the final saturation against \(n\).

Moreover \(W\) is not merely support-equivalent to the candidate part of \(A\): it is exactly its full candidate-supported prime-power part,

\[
\boxed{
W=\prod_{p\mid R_q(n)}p^{v_p(A)}.
}
\tag{2}
\]

Therefore, **if one imports the already-proved candidate DVR bound**
\[
1\le v_p(A)\le3
\qquad(p\mid R_q(n)),
\tag{3}
\]
then
\[
\boxed{R_q(n)\mid W\mid R_q(n)^3.}
\]
The radical theorem itself does not need (3). For the small primes, \(2\) and \(3\) are never candidate primes, so any candidate-DVR theorem stated for \(p\ge5\) is already enough; \(p=5\) is a genuine possible candidate and must be included in the DVR input.

The two suggested alternative neighboring Smith factors fail for exact threshold reasons:

- \(d_{n-q}(n-1)\) tests threshold \(q\), so **every prime supporting \(A\) also supports it**. A gcd with it cannot narrow the radical at all.
- \(d_{n-q-1}(n)\) tests threshold \(q+2\), so **every \(R_q\)-prime is absent from it**. A gcd with it deletes the entire target. If one instead saturates by it, one keeps all primes with corank exactly \(q+1\), which includes a large noncandidate strip and is therefore not selective.

## 2. Smith-index threshold audit

For an integer \(N\times N\) matrix with Smith factors \(d_1,\ldots,d_N\),

\[
\operatorname{corank}_{\mathbf F_p}J_N
=\#\{i:p\mid d_i(N)\}.
\]

Because the Smith factors form a divisibility chain, if the corank is \(c\), precisely the last \(c\) Smith factors are divisible by \(p\). Thus

\[
p\mid d_i(N)
\iff
c_N(p)\ge N-i+1.
\tag{4}
\]

For
\[
A=d_{n-q}(n),
\]
(4) gives
\[
p\mid A
\iff c_n(p)\ge n-(n-q)+1=q+1.
\tag{5}
\]

For
\[
B=d_{n-q-1}(n-1),
\]
the matrix size is \(n-1\), so
\[
p\mid B
\iff c_{n-1}(p)
\ge (n-1)-(n-q-1)+1=q+1.
\tag{6}
\]

Hence the claim that \(A\) and \(B\) test the **same threshold \(q+1\)** is exactly right. There is no off-by-one error.

The range \(1\le q\le n-2\) also makes both Smith indices legal:
\[
1\le n-q-1<n-q\le n-1.
\]

## 3. The two elementary Apéry residue facts needed

Write
\[
\varepsilon_p(s):=\mathbf 1_{p\mid b_s}.
\]

Two facts are needed.

### 3.1 Consecutive residues cannot both vanish for \(0<r<p\)

Suppose
\[
1\le r<p,
\qquad
p\mid b_r,
\qquad
p\mid b_{r-1}.
\]
If \(r=1\), this contradicts \(b_0=1\).

If \(r\ge2\), use the Apéry recurrence at index \(r-1\):
\[
r^3b_r=P(r-1)b_{r-1}-(r-1)^3b_{r-2}.
\]
Modulo \(p\), the first two terms vanish. Since \(1\le r-1<p\), the coefficient \((r-1)^3\) is a unit modulo \(p\), hence
\[
p\mid b_{r-2}.
\]
Iterating backwards forces \(p\mid b_0=1\), impossible. Therefore
\[
\boxed{
\varepsilon_p(r)=1\Longrightarrow \varepsilon_p(r-1)=0
\quad(1\le r<p).
}
\tag{7}
\]
This argument is valid for every prime, including \(2,3,5\).

### 3.2 Endpoint residue \(b_{p-1}\equiv1\pmod p\)

Using the standard Apéry sum
\[
b_m=\sum_{k=0}^m
\binom mk^2\binom{m+k}{k}^2,
\]
put \(m=p-1\). The \(k=0\) term is \(1\). For \(1\le k\le p-1\),
\[
\binom{p-1+k}{k}
=\frac{p(p+1)\cdots(p+k-1)}{k!}
\equiv0\pmod p,
\]
because \(k!\) is a \(p\)-unit. Hence
\[
\boxed{b_{p-1}\equiv1\pmod p}
\tag{8}
\]
for every prime \(p\), again including \(2,3,5\).

## 4. Exact support difference when \(r>0\)

Fix a prime \(p\), and write
\[
n=hp+r,
\qquad 0\le r<p.
\]
First assume \(r>0\). Then
\[
n-1=hp+(r-1),
\]
so (1) gives
\[
c_n(p)=h+\varepsilon_p(r),
\qquad
c_{n-1}(p)=h+\varepsilon_p(r-1).
\tag{9}
\]
By (5)--(6),
\[
p\in\operatorname{supp}(A)\setminus\operatorname{supp}(B)
\]
is equivalent to
\[
h+\varepsilon_p(r)\ge q+1,
\qquad
h+\varepsilon_p(r-1)<q+1.
\tag{10}
\]
There are only three possibilities for \(h\).

- If \(h\le q-1\), then
  \[
  h+\varepsilon_p(r)\le q,
  \]
  so \(p\nmid A\).
- If \(h\ge q+1\), then
  \[
  h+\varepsilon_p(r-1)\ge q+1,
  \]
  so \(p\mid B\).
- Therefore support difference can occur only at
  \[
  h=q.
  \]
  In that case (10) becomes
  \[
  \varepsilon_p(r)=1,
  \qquad
  \varepsilon_p(r-1)=0.
  \]
  By (7), the second condition is automatic once the first holds.

Thus for \(r>0\),
\[
\boxed{
p\in\operatorname{supp}(A)\setminus\operatorname{supp}(B)
\iff
h=q\text{ and }p\mid b_r.
}
\tag{11}
\]

This is the core selector identity.

## 5. Exact support difference when \(r=0\)

Now suppose
\[
r=0,
\qquad n=hp.
\]
Since \(b_0=1\),
\[
c_n(p)=h.
\tag{12}
\]
Also
\[
n-1=(h-1)p+(p-1),
\]
and by (8), \(p\nmid b_{p-1}\), so
\[
c_{n-1}(p)=h-1.
\tag{13}
\]
Therefore
\[
p\mid A\iff h\ge q+1,
\]
while
\[
p\mid B\iff h-1\ge q+1\iff h\ge q+2.
\]
Hence
\[
\boxed{
p\in\operatorname{supp}(A)\setminus\operatorname{supp}(B)
\iff
r=0\text{ and }h=q+1.
}
\tag{14}
\]
Equivalently, the only rollover contaminant is
\[
\boxed{n=(q+1)p.}
\tag{15}
\]
In particular it is a prime divisor of \(n\).

This verifies exactly the proposed \(r=0\) analysis. Note carefully that (8) says \(p\nmid b_{p-1}\), not that the indicator in (1) is one; therefore the corank drops from \(h\) to \(h-1\) across this rollover, which is precisely what creates (15).

## 6. Translation to the candidate prime interval

In the \(r>0\) support-difference case, \(h=q\), so
\[
n=qp+r,
\qquad 0<r<p.
\]
Thus
\[
qp<n<(q+1)p,
\]
or equivalently
\[
\boxed{
\frac{n}{q+1}<p<\frac nq.
}
\tag{16}
\]
Also
\[
r=n-qp,
\]
so (11) becomes exactly
\[
\frac{n}{q+1}<p<\frac nq,
\qquad
p\mid b_{n-qp}.
\tag{17}
\]

The definition in the question uses the harmless weak upper endpoint
\[
p\le n/q.
\]
If equality holds, then \(n=qp\), hence \(n-qp=0\) and
\[
p\nmid b_0=1.
\]
So the candidate condition itself automatically excludes the upper endpoint. Therefore
\[
\frac{n}{q+1}<p<\frac nq
\]
and
\[
\frac{n}{q+1}<p\le\frac nq,\quad p\mid b_{n-qp}
\]
select the same primes.

At the lower endpoint
\[
p=\frac{n}{q+1},
\]
one has \(r=0,h=q+1\), exactly the contaminant (15). The strict lower inequality in \(R_q(n)\) is therefore essential.

Finally, every candidate prime has \(r>0\), hence
\[
\boxed{p\nmid n.}
\tag{18}
\]

## 7. The saturation operator really removes complete prime support

For positive integers \(x,y\), define
\[
\operatorname{Sat}(x;y)
=\frac{x}{\gcd(x,y^x)}.
\]
Let \(\ell\) be prime. Then
\[
v_\ell(\operatorname{Sat}(x;y))
=v_\ell(x)-
\min\{v_\ell(x),xv_\ell(y)\}.
\tag{19}
\]

If \(\ell\nmid y\), the second valuation is zero and
\[
v_\ell(\operatorname{Sat}(x;y))=v_\ell(x).
\tag{20}
\]
If \(\ell\mid y\), then \(v_\ell(y)\ge1\). Also
\[
v_\ell(x)\le x
\]
for every positive integer \(x\). Hence
\[
xv_\ell(y)\ge x\ge v_\ell(x),
\]
and (19) becomes zero. Therefore
\[
\boxed{
\operatorname{supp}(\operatorname{Sat}(x;y))
=\operatorname{supp}(x)\setminus\operatorname{supp}(y).
}
\tag{21}
\]
More strongly, primes not dividing \(y\) retain their **entire** exponent from \(x\), while primes dividing \(y\) are removed completely.

Thus the use of \(y^x\) is mathematically valid. It is wildly overpowered computationally, but there is no theorem-level flaw. The positivity assumptions also avoid any \(0^0\) or sign issue. When \(x=1\), (21) is vacuous and still correct.

## 8. First saturation: exact contamination set

Combining (11), (14), and (21),
\[
\operatorname{supp}(T)
=
\{p:h=q,\ r>0,\ p\mid b_r\}
\cup
\{p:r=0,\ h=q+1\}.
\tag{22}
\]
The first set is exactly the candidate set in \(R_q(n)\). The second set consists exactly of the possible prime lower endpoint
\[
p=n/(q+1),
\]
and every such prime divides \(n\).

There are no primes \(p>n\) lurking here. Indeed for \(p>n\), \(h=0\) and (1) gives \(c_n(p)\le1\), whereas \(A\) requires corank at least \(q+1\ge2\).

## 9. Second saturation: exact candidate support

Now
\[
W=\operatorname{Sat}(T;n).
\]
By (21), this removes precisely the primes of \(T\) that divide \(n\).

- Every rollover contaminant from the second set in (22) divides \(n\), so it is removed.
- By (18), no candidate prime divides \(n\), so every candidate survives with its full exponent.

Therefore
\[
\boxed{
\operatorname{supp}(W)
=
\left\{p:\frac n{q+1}<p\le\frac nq,\ p\mid b_{n-qp}\right\}.
}
\tag{23}
\]
Since \(R_q(n)\) is the squarefree product of exactly these primes,
\[
\boxed{\operatorname{rad}(W)=R_q(n).}
\tag{24}
\]

This is a theorem-quality consequence of the corank formula alone.

## 10. Exact prime-power identity and the DVR sandwich

Because saturation removes prime support all-or-nothing, every candidate prime \(p\) survives both saturation steps with exactly its original exponent in \(A\). Every noncandidate prime is removed. Hence
\[
\boxed{
W=\prod_{p\mid R_q(n)}p^{v_p(A)}.
}
\tag{25}
\]
This identity is stronger than (24) and does **not** require a DVR valuation theorem.

If the banked candidate DVR law is
\[
1\le v_p(d_{n-q}(n))\le3
\qquad
\left(
\frac n{q+1}<p\le\frac nq,\ p\mid b_{n-qp}
\right),
\tag{26}
\]
then (25) gives immediately
\[
\boxed{R_q(n)\mid W\mid R_q(n)^3.}
\tag{27}
\]

The logical dependence should be stated this way: (24)--(25) are proved from the exact mod-\(p\) corank law; the upper bound in (27) additionally imports the candidate DVR law. The support argument by itself cannot bound \(v_p(A)\).

## 11. Small-prime audit: \(p=2,3,5\)

The support theorem is uniform in \(p\), but it is worth checking the smallest primes explicitly because of the proposed DVR handoff.

### \(p=2\)

The only positive residue is \(r=1\), and
\[
b_1=5\equiv1\pmod2.
\]
So \(2\) is never a candidate prime. It can only enter the support-difference mechanism through the rollover case \(2\mid n\), \(n/2=q+1\), and then the final saturation by \(n\) removes it.

### \(p=3\)

The possible positive residues are \(1,2\), and
\[
b_1=5\equiv2\pmod3,
\qquad
b_2=73\equiv1\pmod3.
\]
So \(3\) is never a candidate either. Again it can only be a removable rollover contaminant.

### \(p=5\)

Here
\[
b_1=5\equiv0,
\quad
b_2=73\equiv3,
\quad
b_3=1445\equiv0,
\quad
b_4=33001\equiv1
\pmod5.
\]
Thus \(5\) **can** be a genuine candidate, at residual positions \(r=1\) or \(r=3\). The zeros are nonconsecutive, in accord with (7). The support selector treats these cases correctly, and \(5\nmid n\) whenever it is selected as a candidate.

Consequently, if the previously proved DVR upper bound is stated only for \(p\ge5\), that is enough for (27): \(2\) and \(3\) never occur in \(R_q(n)\), while \(5\) must be included.

## 12. The case \(q=1\)

Nothing degenerates at \(q=1\). One has
\[
A=d_{n-1}(n),
\qquad
B=d_{n-2}(n-1),
\]
and both test corank at least \(2\).

For \(r>0\), the support difference is exactly
\[
h=1,\qquad p\mid b_r,
\]
which is
\[
\frac n2<p<n,\qquad p\mid b_{n-p}.
\]
The weak upper endpoint \(p=n\) contributes nothing because \(b_0=1\).

If \(n=2p\), then \(r=0,h=2=q+1\), so \(p=n/2\) is exactly the lower-endpoint rollover contaminant. It is removed by \(\operatorname{Sat}(T;n)\).

Thus the claimed formula remains exact for \(q=1\).

## 13. Why \(\gcd(A,d_{n-q}(n-1))\) cannot narrow support

Set
\[
C=d_{n-q}(n-1).
\]
Its threshold is
\[
(n-1)-(n-q)+1=q,
\]
so
\[
p\mid C\iff c_{n-1}(p)\ge q.
\tag{28}
\]
I claim
\[
\boxed{\operatorname{supp}(A)\subseteq\operatorname{supp}(C).}
\tag{29}
\]
Indeed, suppose \(p\mid A\), so \(c_n(p)\ge q+1\).

- If \(r>0\) and \(h\ge q+1\), then \(c_{n-1}(p)\ge h\ge q+1\).
- If \(r>0\) and \(h=q\), then \(p\mid A\) forces \(\varepsilon_p(r)=1\), while
  \[
  c_{n-1}(p)=q+\varepsilon_p(r-1)\ge q.
  \]
- If \(r=0\), then \(p\mid A\) implies \(h\ge q+1\), while
  \[
  c_{n-1}(p)=h-1\ge q.
  \]

Thus (29) holds. Therefore
\[
\boxed{
\operatorname{rad}\gcd(A,C)=\operatorname{rad}(A).
}
\tag{30}
\]
So this gcd does not narrow prime support even by one prime. Equivalently, saturating \(A\) by \(C\) would erase the entire radical of \(A\), including every target prime.

This failure is structural: changing the matrix size from \(n\) to \(n-1\) **without** shifting the Smith index lowers the threshold from \(q+1\) to \(q\), making the comparator too permissive.

## 14. Why \(d_{n-q-1}(n)\) loses every \(R_q\)-prime

Set
\[
D=d_{n-q-1}(n).
\]
Its threshold is
\[
n-(n-q-1)+1=q+2,
\]
so
\[
p\mid D\iff c_n(p)\ge q+2.
\tag{31}
\]
For a candidate prime, \(h=q\), \(r>0\), and \(p\mid b_r\), hence
\[
c_n(p)=q+1.
\]
Therefore
\[
\boxed{
p\mid R_q(n)\Longrightarrow p\nmid D.}
\tag{32}
\]
So \(D\) itself loses every target prime, and
\[
\gcd(A,D)
\]
loses every target prime as well.

Could one instead use \(\operatorname{Sat}(A;D)\)? That keeps precisely primes with
\[
c_n(p)=q+1,
\]
which is far too broad. Besides the desired case
\[
h=q,\quad \varepsilon_p(r)=1,
\]
it includes, for \(r>0\), the generic case
\[
h=q+1,\quad \varepsilon_p(r)=0.
\]
Those are ordinary primes in the next quotient strip
\[
\frac n{q+2}<p<\frac n{q+1}
\]
for which \(p\nmid b_{n-(q+1)p}\). They usually do not divide \(n\), so a subsequent saturation by \(n\) does not remove them. Hence the same-size one-index-left comparator cannot isolate \(R_q\).

This precisely explains why the adjacent-size/same-threshold pair \((A,B)\) is the right support selector.

## 15. What this does and does not buy for height

The construction is genuinely exact at the support level. It packages the candidate radical as a canonical arithmetic expression in neighboring Smith factors:
\[
R_q(n)=\operatorname{rad}
\operatorname{Sat}
\bigl(
\operatorname{Sat}(d_{n-q}(n);d_{n-q-1}(n-1));n
\bigr).
\]

But it does not create a new height saving. From (25) and the candidate DVR law,
\[
\log R_q(n)
\le\log W
\le3\log R_q(n).
\]
Thus \(W\) and \(R_q\) have equivalent logarithmic height up to an absolute factor. The selector removes contaminating prime support from \(A\), but it does not by itself produce a sublinear bound for the surviving candidate part. Any such bound still has to enter through an independent height estimate on \(W\), \(A/B\)-type arithmetic, or another genuinely compressive invariant.

## Final classification

- **Smith indices / threshold \(q+1\):** correct.
- **\(r>0\) support difference:** exactly \(h=q\) and \(p\mid b_r\); correct.
- **Use of nonconsecutive Apéry zeros:** correct and valid for all primes.
- **\(r=0\) rollover:** exactly \(h=q+1\); correct.
- **Identity \(b_{p-1}\equiv1\pmod p\):** correct for every prime.
- **Candidate interval endpoints:** lower endpoint must be strict; upper endpoint may be written weak because \(b_0=1\) kills equality.
- **Candidate primes divide \(n\):** they never do.
- **\(q=1\):** no exception.
- **\(p=2,3\):** never candidates; only possible rollover contaminants, removed by saturation against \(n\).
- **\(p=5\):** genuine candidates are possible; the support proof remains exact.
- **Use of \(y^x\) in `Sat`:** mathematically valid and removes the full \(y\)-supported prime-power part of \(x\); computationally extravagant but not logically flawed.
- **\(\operatorname{rad}(W)=R_q(n)\):** proved from the corank theorem.
- **Exact prime-power description of \(W\):** \(W=\prod_{p\mid R_q}p^{v_p(A)}\).
- **\(R_q\mid W\mid R_q^3\):** follows once the already-proved candidate DVR bound \(v_p(A)\le3\) is imported; it is not a consequence of the mod-\(p\) corank theorem alone.
- **`gcd(A,d_{n-q}(n-1))`:** radical equals \(\operatorname{rad}(A)\); no support narrowing.
- **`d_{n-q-1}(n)`:** contains no \(R_q\)-prime; gcd with it destroys the target, while saturation by it leaves a large next-strip contamination.

**Bottom line:** there is no counterfixture to the proposed radical identity. The adjacent-size, one-index-left comparison is exactly the threshold-preserving support difference needed to isolate the fixed-\(q\) candidate primes, with the sole rollover contaminant removed by saturation against \(n\). The construction is support-exact but height-neutral.
