# Q1118: aligned shifted-Newton p-block first defect modulo p^2

Let
\[
C_u=\binom{M+(k-1)p+u-1}{M-1},\qquad 0\le u<p.
\]
The first point is that the mod-p identity in Q1117 is correct only after collapsing the block. The defect modulo p^2 has two independent sources:

1. the Granville/Lucas defect of the coefficient block \(C_u\);
2. the fact that \((E-1)^p\) is not literally \(E^p-1\) modulo \(p^2\).

## 1. Coefficient block expansion

Write
\[
M=Ap+t,\qquad 0\le t<p.
\]
For \(t>0\), put
\[
N=A+k-1.
\]
The sharp first Granville expansion gives
\[
\binom{Np+t+u-1}{Ap+t-1}
=
\binom Nt\binom{N}{A}
\left(1+p\,\eta_{A,k,t}(u)\right)\pmod {p^2},
\]
where the finite correction is
\[
\eta_{A,k,t}(u)
=
H_{Np+t+u-1}-H_{Ap+t-1}-H_{(N-A)p+u}
\pmod p,
\]
with the harmonic sums interpreted only over terms prime to p:
\[
H_m=\sum_{\substack{1\le i\le m\\p\nmid i}}i^{-1}\pmod p.
\]
Equivalently the entire coefficient defect is the explicit finite sum
\[
C_u=C_0\left(1+p\eta_{A,k,t}(u)\right)\pmod {p^2}.
\]
This is the required Lucas/Granville lift; no unknown infinite term remains.

For \(t=0\), the surviving scalar is instead
\[
\binom{A+k-2}{A-1},
\]
and the same calculation gives
\[
C_u=C_0(1+p\eta^{(0)}_{A,k}(u))\pmod {p^2},
\]
where
\[
\eta^{(0)}_{A,k}(u)=
H_{(A+k-2)p+u-1}-H_{(A-1)p-1}-H_{(k-1)p+u}\pmod p.
\]

## 2. Defect of the p-step operator

The mod-p collapse used
\[
(E-1)^p\equiv E^p-1\pmod p.
\]
Modulo p^2,
\[
(E-1)^p-(E^p-1)
=\sum_{i=1}^{p-1}(-1)^{p-i}\binom piE^i.
\]
Since
\[
\frac1p\binom pi\equiv \frac{(-1)^{i-1}}i\pmod p,
\]
the normalized operator defect is
\[
\boxed{
\frac{(E-1)^p-(E^p-1)}p
\equiv
-\sum_{i=1}^{p-1}\frac{E^i}{i}\pmod p .
}
\]
For the shifted block, this contributes the finite operator
\[
\Theta_p(E)=-\sum_{i=1}^{p-1}E^i/i.
\]

## 3. Normalized first defect

For \(t>0\), the mod-p operator was
\[
S^{(0)}=inom{A+k-1}{A}E^{t-1}(E^p-1)^{A+1}b_h.
\]
Therefore
\[
\frac{S-S^{(0)}}p
\equiv
\binom{A+k-1}{A}
E^{t-1}(E^p-1)^{A+1}
\sum_{u=0}^{p-1}\eta_{A,k,t}(u)E^u b_h
\]
\[
\qquad+
\binom{A+k-1}{A}
E^{t-1}
\left((A+1)(E^p-1)^A\Theta_p(E)\right)b_h
\pmod p.
\]
This is the explicit first-defect formula. It separates the Granville coefficient defect and the Frobenius-operator defect.

For \(t=0\), replace the scalar and power by
\[
\binom{A+k-2}{A-1}E^{p-1}(E^p-1)^A,
\]
and the operator correction is
\[
\boxed{
\frac{S-S^{(0)}}p
\equiv
B_0E^{p-1}(E^p-1)^A
\sum_u\eta^{(0)}_{A,k}(u)E^u b_h
+
B_0E^{p-1}A(E^p-1)^{A-1}\Theta_p(E)b_h
}
\]
where
\[
B_0=\binom{A+k-2}{A-1}.
\]

## 4. Interaction with the Apéry first jet

Write
\[
n=qp+r,
\]
and assume \(p\mid b_r\). The aligned block has indices
\[
h+u=ap+r
\]
so the first Apéry jet has the form
\[
b_{ap+r}=b_ab_r+p\Lambda_{a,r}\pmod {p^2}.
\]
Substituting into the defect gives two terms:

\[
\frac{S-S^{(0)}}p
=
\mathcal A\,\frac{b_r}{p}
+
\mathcal B(\Lambda_{a,r})
\pmod p,
\]
where

\[
\mathcal A
\]
is obtained by applying the reduced short difference operator to the high-digit factor \(b_a\), and

\[
\mathcal B(\Lambda_{a,r})
\]
is the same finite operator applied to the independent first-jet term \(\Lambda_{a,r}\).

Hence the defect does **not** collapse to a multiple of \(b_r/p\) alone. The normalized defect has a genuine independent first-jet row.

The exact obstruction is therefore:
\[
\boxed{
\text{under }p\mid b_r,
\quad
(S-S^{(0)})/p
\text{ contains both }b_r/p\text{ and }\Lambda_{a,r}.
}
\]

This is why the mod-p block identity cannot by itself prove the prime-power content theorem. The first defect already sees the next Cartier/Dwork jet.

## Edge cases

- If \(t>0\), the correction exponent is \(A+1\) and the scalar is \(\binom{A+k-1}{A}\).
- If \(t=0\), the exponent drops to \(A\), the scalar becomes \(\binom{A+k-2}{A-1}\), and the operator defect has coefficient \(A\) rather than \(A+1\).
- No assumption of ordinary Lucas independence survives modulo p^2; the first defect explicitly couples the Newton block to the Apéry first jet.
