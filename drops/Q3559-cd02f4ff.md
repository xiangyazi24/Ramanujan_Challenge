# 2. Exact quotient-six window

Define

```text
H_6(n)
 := #{p prime : n/7 < p <= n/6,
                 p | b_(n-6p)}.
```

Write

```text
Z_p := {0<=r<p : b_r = 0 mod p}.
```

The window condition is

```text
n/7 < p <= n/6

6p <= n < 7p.
```

Thus for every prime counted by `H_6(n)` there is a unique integer

```text
r = n-6p,
0 <= r < p,
```

and the event is exactly

```text
r in Z_p.
```

Therefore

```text
H_6(n)
 = #{(p,r) : p prime,
             r in Z_p,
```

This last formula is the most useful one.  It says that if

```text
E := {(p,r): p prime, r in Z_p},
phi(p,r) := 6p+r,
```

then `H_6(n)` is the fibre multiplicity of `phi` over `n`.

# 6. Why the CRT count is not the right count

The proposed CRT step starts with

```text
n == 6p+r (mod p).
```

But since `6p == 0 mod p`, this is simply

```text
n == r (mod p).
```

If one ignores the quotient-six window, two such congruences indeed determine a class modulo `pq`.  However, in the q=6 slice one also has

```text
6p <= n < 7p,
0 <= r < p.
```

There is only one integer in that interval congruent to `r mod p`, namely

```text
n=6p+r.                                    (6.1)
```

So for two primes the two congruences plus the q=6 window become the exact equality

```text
6p+r = 6q+s.                               (6.2)
```

A fixed pair `(r,s)` therefore contributes either zero integers or one integer.

There is also a scale warning even if one temporarily drops the window.  Here `p,q` are of order `N`, so

```text
pq is of order N^2,
N/(pq) is of order 1/N.
```

The `O(1)` error in a CRT progression count is then much larger than the claimed main term.  Summing such `O(1)` errors over roughly `N^2/log^2 N` prime pairs destroys the calculation.  Thus the CRT route cannot justify the desired global estimate even as an approximation.

# 7. Where your product formula *is* correct: the random-model expectation

Let

```text
z_p := |Z_p|.
```

Now impose a heuristic model: for each prime `p`, choose `Z_p` independently as a uniformly random subset of `F_p` of size `z_p`.

For a fixed pair `p<q` and one integer `s` in the overlap range, the two required residues are prescribed:

```text
s in Z_q,
s+6(q-p) in Z_p.
```

Under the independent random-subset model,

```text
P(s in Z_q and s+6(q-p) in Z_p)
 = (z_q/q)(z_p/p).                         (7.1)
```

Summing over the exact `L_{p,q}(N)` possible `s` gives

```text
E C_{p,q}(N)
 = L_{p,q}(N) z_p z_q/(pq).                (7.2)
```

Therefore

```text
E E_2(N)
 = sum_{p<q}
   L_{p,q}(N) z_p z_q/(pq).                (7.3)
```

So the expression suggested in the question is **exactly the heuristic expectation `(7.3)`**, once the terminal truncation is included.  It is not the deterministic value of `E_2(N)`.

```text

     integral_x^(7x/6)
```
