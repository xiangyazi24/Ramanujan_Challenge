## 10.1 Valuation-two selected zero

\[
(q,t)=(17,3),\qquad v_{17}(b_3)=2.
\]
The two prefixes nevertheless have exact q-depth one because the prefix jet is nonzero. This kills the naive valuation transfer from \(b_t\) to \(G^{\rm pref}\).

## 10.2 Midpoint jet zero

\[
(q,t)=(3137,1568)=(3137,(3137-1)/2).
\]
Here the c=6 and c=12 divided prefix values agree modulo q, but both remain q-units after one q is removed. This kills a universal nonvanishing statement for the divided difference while preserving exact q-depth one.

## 10.3 Unsaturated carry false positive

Every post-remainder increment has \(\ell^2\) or \(\ell^4\) divisibility even when \(\ell\nmid b_r\). Any determinant/difference experiment that reports these factors before applying (3.4) is measuring carry, not Apéry-zero structure.

## 10.4 One-channel collision counterexamples

The explicit \(J_6,J_1,J_{13}\) records in Section 6 show that neither a quotient-six nor a secondary-channel exclusion is true separately. Any proof must use the joint two-prefix geometry.

## 10.5 Raw gcd content

The moderate exact pool contains gcds as large as
\[
5^3\cdot271.
\]
This is not a shell radical event; it is exactly the kind of fixed/state content that must be stripped before fitting a primitive law.

## 10.6 No actual counterexample to IPRD

No cell with a nontrivial translated shell radical was found. Hence the campaign supplies no lower-bound counterexample of the form
\[
\log\mathfrak Q\gg D/\log D
\quad\text{or}\quad
\log\mathfrak Q\gg D.
\]
The strongest limitation is statistical: the event count is too small to estimate the tail.

# 11. Symbolic identities worth proving

## 11.1 Exact carry valuation

Promote (3.4) to a lemma in the Q4178 prefix module. It removes all ambiguity about the first horizontal saturation.

## 11.2 Mod-p^2 prefix jet

Prove (4.2) in the repository. The derivation is short: for \(r+k<\ell\), logarithmically differentiate the two binomial products at \(M=r\); for \(r+k\ge\ell\), both relevant terms vanish modulo \(\ell^2\) by the squared carry.

## 11.3 Exact q-primary criterion

For fully covered plus prefixes and \(q>13\), prove
\[
\boxed{
q^2\mid\gcd\left(
\mathscr K_R(6q+t),
\mathscr K_S(12q+t)
\right)
\iff
q^2\mid b_t\ \text{ and }\ \mathcal J_q(t)=0
}
\tag{11.1}
\]
for \(R,S\ge t\). The forward direction follows immediately by subtracting the two instances of (4.2); the reverse direction is also immediate.

The computational frontier then becomes the transversality statement
\[
q\mid b_t,\quad t\ne(q-1)/2
\Longrightarrow
\mathcal J_q(t)\ne0.
\tag{11.2}
\]

## 11.4 Reflected mod-p^2 jet

Derive the analogue of (4.2) for
\[
M=\ell-1-z.
\]
This should explain the minus-side q-primary factor and determine whether the reflected prefix has an exceptional midpoint or endpoint jet.

## 11.5 Primitive two-prefix Smith row

After replacing every post-boundary difference by its quotient under (3.4), compute a Smith/Popov basis of the two simultaneous prefix modules. The success condition is a primitive partner-independent row \(C(q,t;p,D)\) with
\[
\mathfrak Q^{\rm sat}_\sigma(q,t;p,D)\mid C(q,t;p,D)
\]
and average logarithmic height \(O(D^{1-\delta}\log T)\). Q4166 and Q4178 show that an unsaturated scalar difference cannot work.

# 12. Precise conjectures

## 12.1 Recommended IPRD

Fix \(J\), a raw sign \(\sigma\), and \(0<\varepsilon<1\). There exists a fixed \(\delta=\delta(J,\varepsilon)>0\) such that uniformly for every hard dyadic scale
\[
T^{\alpha_0}\le D\le T^{3/5+o(1)},
\]
\[
\boxed{
\sum_{(q,t)}
\sum_{\substack{
p\in\mathcal P_\sigma(q,t)\\
B_6(p,D),B_\sigma(p,D)>D^{1-\varepsilon}}}
\log\mathfrak Q^{\rm sat}_\sigma(q,t;p,D)
\ll_{J,\varepsilon}
(\log T)D^{1-\delta}M_\sigma(T).
}
\tag{12.1}
\]
Repeated numerical primes in different states or base leaves are counted repeatedly. The radical includes every shell-prime divisor of the saturated prefix gcd, including factors later removed by tie-break or residual filters.

Together with Q4178's boundary theorem, (12.1) implies full APD with any
\[
0<\eta<\alpha_0\min(\varepsilon,\delta).
\]

## 12.2 Aggressive Poisson-strength conjecture

For every \(\eta>0\), replace \(D^{1-\delta}\) in (12.1) by \(D^\eta\). This is consistent with the two-slope finite-energy data but is not presently distinguishable from a finite-exception conjecture.

## 12.3 What should not be conjectured from this scan

Do not bank
\[
\mathfrak Q^{\rm sat}_\sigma=1
\quad\text{for all states and all }T.
\]
The predicted random main term through the current range is much smaller than one. The universal-zero statement is an overfit to pre-first-event data.

The following file is ordinary Python 3. It uses Sage when available for factoring, but the core census, prefix arithmetic, and campaign are pure Python. Run it with either

or


For the global Q4174 reproduction use `--row-hash 40000`. The exact-integer gcd campaign is deliberately capped by `--exact-cutoff` because the prefix operands grow rapidly.

```python
#!/usr/bin/env python3
"""Q4181 exact truncated-prefix radical campaign.

No floating point is used for any divisibility or zero decision.
Floating point appears only in reported natural logarithms.
"""

from __future__ import annotations

import argparse
import bisect
import csv
import json
import math
from collections import Counter, defaultdict
from dataclasses import asdict, dataclass
from itertools import combinations, product
from typing import Dict, Iterable, List, Mapping, Sequence, Set, Tuple

try:
    from sage.all import factor as sage_factor  # type: ignore
except Exception:  # pragma: no cover
    sage_factor = None


FIXED_EXCEPTION_PRIMES = (
    5,
    17,
    315493,
    858433,
    2720027329,
    12073365010564729,
)


def middle(n: int) -> int:
    return 34 * n**3 + 51 * n**2 + 27 * n + 5


def primes_upto(limit: int) -> List[int]:
    if limit < 2:
        return []
    sieve = bytearray(b"\x01") * (limit + 1)
    sieve[0:2] = b"\x00\x00"
    for p in range(2, math.isqrt(limit) + 1):
        if sieve[p]:
            sieve[p * p : limit + 1 : p] = b"\x00" * (
                (limit - p * p) // p + 1
            )
    return [i for i, flag in enumerate(sieve) if flag]


def apery_row_mod(p: int, power: int = 1) -> List[int]:
    """b_0,...,b_(p-1) modulo p**power."""
    mod = p**power
    b = [0] * p
    b[0] = 1
    if p > 1:
        b[1] = 5 % mod
    for n in range(1, p - 1):
        den = (n + 1) ** 3
        b[n + 1] = (
            (middle(n) * b[n] - n**3 * b[n - 1])
            * pow(den, -1, mod)
        ) % mod
    return b


def zero_set(p: int) -> Set[int]:
    return {i for i, value in enumerate(apery_row_mod(p, 1)) if value == 0}


def apery_exact(n: int) -> int:
    return sum(
        math.comb(n, k) ** 2 * math.comb(n + k, k) ** 2
        for k in range(n + 1)
    )


def prefix_exact(M: int, R: int) -> int:
    """Exact K_R(M), using exact multiplicative binomial updates."""
    if not (0 <= R <= M):
        raise ValueError((M, R))
    choose_left = 1
    choose_right = 1
    total = 1
    for k in range(R):
        choose_left = choose_left * (M - k) // (k + 1)
        choose_right = choose_right * (M + k + 1) // (k + 1)
        total += choose_left * choose_left * choose_right * choose_right
    return total


def prefix_mod(M: int, R: int, ell: int, power: int = 1) -> int:
    """K_R(M) modulo ell**power. Requires R < ell."""
    if not (0 <= R < ell):
        raise ValueError((M, R, ell))
    mod = ell**power
    choose_left = 1
    choose_right = 1
    total = 1
    for k in range(R):
        inv = pow(k + 1, -1, mod)
        choose_left = choose_left * (M - k) * inv % mod
        choose_right = choose_right * (M + k + 1) * inv % mod
        total = (
            total + choose_left * choose_left * choose_right * choose_right
        ) % mod
    return total


def vp(n: int, p: int) -> int:
    if n == 0:
        raise ValueError("vp(0) requires a cap")
    e = 0
    while n % p == 0:
        n //= p
        e += 1
    return e


def vp_capped(residue: int, p: int, cap: int) -> int:
    if residue == 0:
        return cap
    return min(vp(residue, p), cap)


def strip_prime(n: int, p: int) -> int:
    while n % p == 0:
        n //= p
    return n


def saturate_scalar(g: int, q: int) -> int:
    g = strip_prime(g, q)
    for e in FIXED_EXCEPTION_PRIMES:
        g = strip_prime(g, e)
    return g


def factor_for_report(n: int) -> str:
    if n == 1:
        return "1"
    if sage_factor is not None:
        return str(sage_factor(n))
    # Exact trial division is enough for the small gcds in the control pool.
    out: List[Tuple[int, int]] = []
    x = n
    d = 2
    while d * d <= x and d <= 1_000_000:
        if x % d == 0:
            e = 0
            while x % d == 0:
                x //= d
                e += 1
            out.append((d, e))
        d = 3 if d == 2 else d + 2
    if x > 1:
        out.append((x, 1))
    return " * ".join(f"{p}^{e}" if e > 1 else str(p) for p, e in out)


def carry_exponent(ell: int, r: int, R: int) -> int:
    if not (0 <= r < R < ell):
        raise ValueError((ell, r, R))
    return 2 + 2 * int(r + R >= ell)


def prefix_jet_mod(ell: int, r: int) -> int:
    """J_ell(r) from equation (4.1)."""
    limit = min(r, ell - r - 1)
    total = 0
    for k in range(1, limit + 1):
        term = (
            math.comb(r, k) ** 2 * math.comb(r + k, k) ** 2
        ) % ell
        harmonic = sum(pow(j, -1, ell) for j in range(r - k + 1, r + k + 1))
        total = (total + 2 * term * harmonic) % ell
    return total


def verify_prefix(pmax: int) -> Mapping[str, object]:
    primes = [p for p in primes_upto(pmax) if p > 13]
    quotients = (1, 6, 12, 13)
    exhaustive = pmax <= 120
    tested = 0
    failures: List[Tuple[int, int, int, int]] = []
    carry_tested = 0
    carry_failures: List[Tuple[int, int, int, int, int, int]] = []
    jet_tested = 0
    jet_failures: List[Tuple[int, int, int]] = []

    for ell in primes:
        residues = range(ell) if exhaustive else sorted(
            {0, 1, 2, (ell - 1) // 2, ell - 3, ell - 2, ell - 1}
            | zero_set(ell)
        )
        for r in residues:
            br = apery_exact(r)
            cutoffs = range(r, ell) if exhaustive else sorted(
                {r, min(ell - 1, r + 1), (r + ell - 1) // 2, ell - 1}
            )
            jet = prefix_jet_mod(ell, r)
            for c in quotients:
                for R in cutoffs:
                    tested += 1
                    if prefix_mod(c * ell + r, R, ell) != br % ell:
                        failures.append((ell, c, r, R))
                lhs = prefix_mod(c * ell + r, r, ell, power=2)
                coeff = ((lhs - br) % (ell * ell)) // ell
                jet_tested += 1
                if coeff % ell != c * jet % ell:
                    jet_failures.append((ell, c, r))

            if r + 1 < ell:
                for c in quotients:
                    for R in sorted({r + 1, min(ell - 1, r + 2), ell - 1}):
                        if R <= r:
                            continue
                        value = (
                            2 * vp(math.comb(c * ell + r, R), ell)
                            + 2 * vp(math.comb(c * ell + r + R, R), ell)
                        )
                        expected = carry_exponent(ell, r, R)
                        carry_tested += 1
                        if value != expected:
                            carry_failures.append((ell, c, r, R, value, expected))

    return {
        "pmax": pmax,
        "primes": len(primes),
        "prefix_cases": tested,
        "prefix_failures": failures[:20],
        "carry_cases": carry_tested,
        "carry_failures": carry_failures[:20],
        "jet_cases": jet_tested,
        "jet_failures": jet_failures[:20],
    }


def build_zero_data(qmax: int, pmin: int = 17) -> Tuple[List[int], Dict[int, Set[int]]]:
    primes = [p for p in primes_upto(qmax) if p >= pmin]
    zeros = {p: zero_set(p) for p in primes}
    return primes, zeros


def selected_states(primes: Sequence[int], zeros: Mapping[int, Set[int]]) -> List[Tuple[int, int]]:
    return [(q, t) for q in primes for t in sorted(zeros[q])]


def prime_slice(primes: Sequence[int], lo: int, hi: int) -> Sequence[int]:
    return primes[bisect.bisect_left(primes, lo) : bisect.bisect_left(primes, hi)]


def raw_sign_sets(
    q: int,
    t: int,
    primes: Sequence[int],
    zeros: Mapping[int, Set[int]],
) -> Tuple[Set[int], Set[int], Set[int], Set[int]]:
    """Return minus, plus-tiebroken, plus-raw, geometric-union candidates."""
    n = 6 * q + t
    N = 12 * q + t
    s = q - 1 - t
    candidates = prime_slice(primes, n // 7, q)
    minus: Set[int] = set()
    plus_raw: Set[int] = set()
    geometric: Set[int] = set()

    for p in candidates:
        if not (p < q and n < 7 * p):
            continue
        rho = n - 6 * p
        zset = zeros[p]

        a_plus = N - 13 * p
        if 0 <= a_plus < p:
            geometric.add(p)
            if rho in zset and a_plus in zset:
                plus_raw.add(p)

        a_minus = s - p
        if 0 <= a_minus < p:
            geometric.add(p)
            if rho in zset and a_minus in zset:
                minus.add(p)

    plus = plus_raw - minus
    return minus, plus, plus_raw, geometric


def row_hash_pairs(
    primes: Sequence[int],
    zeros: Mapping[int, Set[int]],
    k: int,
) -> Dict[Tuple[int, int], List[int]]:
    rows: Dict[int, List[Tuple[int, int]]] = defaultdict(list)
    for p in primes:
        for r in zeros[p]:
            rows[k * p + r].append((p, r))

    pairs: Dict[Tuple[int, int], List[int]] = defaultdict(list)
    for row, occurrences in rows.items():
        by_prime: Dict[int, int] = {}
        for p, r in occurrences:
            by_prime[p] = r
        for p, q in combinations(sorted(by_prime), 2):
            pairs[(p, q)].append(row)
    return pairs


@dataclass
class Cell:
    sign: str
    q: int
    t: int
    p: int
    D: int
    rho: int
    alpha: int
    B6: int
    Bs: int
    boundary_depth: int
    boundary: bool
    interior: bool
    shallow_base: bool
    actual_base: bool
    shell_primes: List[int]
    radical_primes: List[int]
    log_radical: float
    interior_partner_count: int
    exact_gcd_bits: int | None = None
    exact_gcd_factor: str | None = None
    saturated_gcd_factor: str | None = None


def campaign(
    qmax: int,
    Ds: Sequence[int],
    eps: float,
    exact_cutoff: int,
    include_geometric: bool,
) -> Tuple[Mapping[str, object], List[Cell]]:
    primes, zeros = build_zero_data(qmax)
    states = selected_states(primes, zeros)
    cells: List[Cell] = []
    leaf_totals = Counter()

    for q, t in states:
        n = 6 * q + t
        N = 12 * q + t
        s = q - 1 - t
        minus, plus, plus_raw, geometric = raw_sign_sets(q, t, primes, zeros)
        leaf_totals["minus"] += len(minus)
        leaf_totals["plus"] += len(plus)
        leaf_totals["plus_raw"] += len(plus_raw)

        for sign, actual_set in (("minus", minus), ("plus", plus)):
            if include_geometric:
                base_set = {
                    p for p in geometric
                    if (
                        (sign == "plus" and 0 <= N - 13 * p < p)
                        or (sign == "minus" and 0 <= s - p < p)
                    )
                }
            else:
                base_set = actual_set

            for p in sorted(base_set):
                rho = n - 6 * p
                alpha = N - 13 * p if sign == "plus" else s - p
                z = p - 1 - rho
                c = 13 if sign == "plus" else 1
                m2 = N if sign == "plus" else s

                for D in Ds:
                    if p + 2 * D >= q:
                        continue
                    B6 = rho - 6 * D
                    Bs = alpha - c * D
                    if min(B6, Bs) < 0:
                        continue
                    boundary_depth = min(B6, Bs)
                    boundary_threshold = int(D ** (1.0 - eps))
                    shell = list(prime_slice(primes, p + D, p + 2 * D))

                    radical_primes: List[int] = []
                    for ell in shell:
                        if ell == q or ell in FIXED_EXCEPTION_PRIMES:
                            continue
                        # Direct prefix test. Q4178 also permits replacing this
                        # by the equivalent two low-remainder zero tests.
                        if (
                            prefix_mod(n, B6, ell) == 0
                            and prefix_mod(m2, Bs, ell) == 0
                        ):
                            radical_primes.append(ell)

                    exact_bits = None
                    exact_factor = None
                    sat_factor = None
                    if max(B6, Bs) <= exact_cutoff:
                        k1 = prefix_exact(n, B6)
                        k2 = prefix_exact(m2, Bs)
                        g = math.gcd(k1, k2)
                        gs = saturate_scalar(g, q)
                        exact_bits = g.bit_length()
                        exact_factor = factor_for_report(g)
                        sat_factor = factor_for_report(gs)

                    actual_partners = [
                        ell for ell in actual_set if p + D <= ell < p + 2 * D
                    ]
                    cells.append(
                        Cell(
                            sign=sign,
                            q=q,
                            t=t,
                            p=p,
                            D=D,
                            rho=rho,
                            alpha=alpha,
                            B6=B6,
                            Bs=Bs,
                            boundary_depth=boundary_depth,
                            boundary=boundary_depth <= boundary_threshold,
                            interior=boundary_depth > boundary_threshold,
                            shallow_base=abs(z - alpha) <= 32 * D,
                            actual_base=p in actual_set,
                            shell_primes=shell,
                            radical_primes=radical_primes,
                            log_radical=sum(math.log(x) for x in radical_primes),
                            interior_partner_count=len(actual_partners),
                            exact_gcd_bits=exact_bits,
                            exact_gcd_factor=exact_factor,
                            saturated_gcd_factor=sat_factor,
                        )
                    )

    summary = {
        "qmax": qmax,
        "primes": len(primes),
        "selected_states": len(states),
        "leaf_totals": dict(leaf_totals),
        "cells": len(cells),
        "actual_cells": sum(c.actual_base for c in cells),
        "boundary_cells": sum(c.boundary for c in cells),
        "interior_cells": sum(c.interior for c in cells),
        "radical_hits": sum(len(c.radical_primes) for c in cells),
        "sum_log_radical": sum(c.log_radical for c in cells),
        "max_log_radical": max((c.log_radical for c in cells), default=0.0),
    }
    return summary, cells


def q_primary_scan(qmax: int) -> Mapping[str, object]:
    primes, zeros = build_zero_data(qmax)
    states = selected_states(primes, zeros)
    depth = Counter()
    double_zeros: List[Tuple[int, int]] = []
    jet_zero: List[Tuple[int, int, int, int]] = []

    for q in primes:
        row2 = apery_row_mod(q, power=2)
        for t in zeros[q]:
            if row2[t] == 0:
                double_zeros.append((q, t))
            x6 = prefix_mod(6 * q + t, t, q, power=2)
            x12 = prefix_mod(12 * q + t, t, q, power=2)
            d = min(vp_capped(x6, q, 2), vp_capped(x12, q, 2))
            depth[d] += 1
            divided_difference = ((x12 - x6) % (q * q)) // q
            if divided_difference % q == 0:
                jet_zero.append((q, t, x6, x12))

    return {
        "selected_states": len(states),
        "common_q_depth": dict(depth),
        "valuation_two_zeros": double_zeros,
        "divided_difference_zero": jet_zero,
    }


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--qmax", type=int, default=5000)
    parser.add_argument("--D", default="8,16,32,64,128,256")
    parser.add_argument("--eps", type=float, default=0.5)
    parser.add_argument("--exact-cutoff", type=int, default=220)
    parser.add_argument("--verify-pmax", type=int, default=100)
    parser.add_argument("--row-hash", type=int, default=0)
    parser.add_argument("--actual-only", action="store_true")
    parser.add_argument("--csv", default="")
    args = parser.parse_args()

    verify = verify_prefix(args.verify_pmax)
    print(json.dumps({"verify": verify}, indent=2, sort_keys=True))

    print(json.dumps({"q_primary": q_primary_scan(args.qmax)}, indent=2, sort_keys=True))

    Ds = [int(x) for x in args.D.split(",") if x]
    summary, cells = campaign(
        qmax=args.qmax,
        Ds=Ds,
        eps=args.eps,
        exact_cutoff=args.exact_cutoff,
        include_geometric=not args.actual_only,
    )
    print(json.dumps({"campaign": summary}, indent=2, sort_keys=True))

    if args.csv:
        with open(args.csv, "w", newline="") as handle:
            rows = [asdict(c) for c in cells]
            writer = csv.DictWriter(handle, fieldnames=list(rows[0]) if rows else [])
            if rows:
                writer.writeheader()
                writer.writerows(rows)

    if args.row_hash:
        primes, zeros = build_zero_data(args.row_hash, pmin=7)
        maps = {k: row_hash_pairs(primes, zeros, k) for k in (1, 6, 13)}
        joint61 = set(maps[6]).intersection(maps[1])
        joint613 = set(maps[6]).intersection(maps[13])
        report = {
            "row_hash_qmax": args.row_hash,
            "J1_pairs": sum(len(v) for v in maps[1].values()),
            "J6_pairs": sum(len(v) for v in maps[6].values()),
            "J13_pairs": sum(len(v) for v in maps[13].values()),
            "joint_6_1": len(joint61),
            "joint_6_13": len(joint613),
            "J6_records": [
                {"pair": pair, "rows": rows}
                for pair, rows in sorted(maps[6].items())
            ],
        }
        print(json.dumps(report, indent=2, sort_keys=True))


if __name__ == "__main__":
    main()
```

# 14. Exact continuation packet

The next computational round should be event-driven rather than another regression on zeros.

```text
A. Extend the global row hash until the first joint event
   J6(p,q)*J13(p,q)>0 or J6(p,q)*J1(p,q)>0.

   Use disjoint prime shells plus one overlap shell so cross-boundary
   pairs are not lost. Checkpoint every zero-set block.

B. On the first joint event
   reconstruct every candidate selected state from the two common rows;
   retain only q prime, 0<=t<q, q|b_t, and the exact raw filters;
   record whether it is plus, minus, or a raw sign overlap.
```
