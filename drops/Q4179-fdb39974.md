# 7. Second genuine-power theorem: dense-block incomplete IPRD

The cutoff occupancy theorem can be averaged over the actual marked base leaves without dropping any state or occurrence.

For each fixed selected state \(u=(q,t)\) and sign \(\sigma\), partition the lower-prime line into canonical half-open intervals

\[
J=[x,x+D)
\tag{7.1}
\]

of length \(D\). Let

\[
m_{u,J}
:=\#\{p:(q,t,p,\sigma)\in
\Omega_{\sigma,\varepsilon}^{\rm int}(D),\ p\in J\}.
\tag{7.2}
\]

Fix \(0<\kappa<1/3\). Call \(J\) dense when

\[
\boxed{m_{u,J}\ge D^{2/3+\kappa}.}
\tag{7.3}
\]

For a base leaf \(p\), a shell prime \(\ell\in I_\omega\) is called **incomplete in channel \(\nu\)** when

\[
B_\nu(p)<j_\nu(\ell).
\tag{7.4}
\]

By Lemma 2.1 this is exactly the nonplateau case. If at least one channel is incomplete, assign the incidence canonically to channel `6` if channel `6` is incomplete, and otherwise to channel \(\sigma\). This avoids double counting.

Fix a shell prime \(\ell\). As \(p\) varies in one block \(J\), the cutoff in channel \(\nu\) is

\[
B_\nu(p)=M_\nu-c_\nu(p+D),
\tag{7.5}
\]

an arithmetic progression of step \(-c_\nu\), with

\[
c_\nu\in\{1,6,13\}.
\]

All assigned incomplete incidences satisfy

\[
0\le B_\nu(p)<j_\nu(\ell)<\ell.
\tag{7.6}
\]

The span of the cutoffs is at most \(13D<\ell\) in the live range. Theorem 4.1 therefore gives

\[
\boxed{
\#\{p\in J:\ell\text{ is assigned as an incomplete divisor at }p\}
\ll_JD^{2/3}.
}
\tag{7.7}
\]

No primality or lower-zero condition on \(p\) was used to obtain the upper bound; intersecting with the exact actual marked base set only decreases it.

For \(p\in J=[x,x+D)\), every shell prime lies in

\[
[x+D,x+3D),
\tag{7.8}
\]

which contains \(O(D)\) integers. Hence the total logarithmic incomplete incidence from one block is

\[
\begin{aligned}
W_{u,J}^{\rm inc}
&:=
\sum_{\substack{p\in J\\(q,t,p,\sigma)\in\Omega^{\rm int}}}
\sum_{\substack{
\ell\in[p+D,p+2D)\cap\mathbb P\\
\ell\mid G_{(u,p)}^{\rm pref}\\
\ell\nmid qE_\sigma\\
\text{at least one channel incomplete}

\log\ell\\
&\ll_J
D\cdot D^{2/3}\cdot\log T.
\end{aligned}
\tag{7.9}
\]

Thus

\[
\boxed{W_{u,J}^{\rm inc}\ll_J(\log T)D^{5/3}.}
\tag{7.10}
\]

If \(J\) is dense, (7.3) gives

\[
D^{5/3}\le D^{1-\kappa}m_{u,J}.
\tag{7.11}
\]

We have proved the second power theorem.

## Theorem 7.1 — dense-block incomplete IPRD

For every fixed \(0<\kappa<1/3\),

\[
\boxed{

\ll_J
(\log T)D^{1-\kappa}

\tag{7.12}
\]

This is a fixed-power `IPRD_delta` estimate, with

\[

means


The theorem remains entirely inside the deep region (1.7); it is not a re-use of the accepted boundary-prefix deletion.
