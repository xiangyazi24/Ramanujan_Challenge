# Audit of the proposed finite-state certificate

## Verdict

The proposed construction is close to a valid finite-state reduction for the Kummer part, but it is not yet a certificate for the claimed Pade content bound. The first fatal gap is the final quantifier over all j: a BFS over paired words can verify local arithmetic states, but the proposed projection/determinization over j does not by itself prove that every accepting path corresponds to a valid j<M witness or that every rejecting path excludes all possible continuations. The missing ingredient is an explicitly constructed quotient automaton whose state invariant includes the comparison j<M and the target valuation bound.

## Kummer transducer audit

For

```
ell = v2(binomial(n,j)) + v2(binomial(n-j-1,M-1-j))
```

Kummer gives the two borrow counts. The first subtraction is ordinary:

```
borrow_0 = 0
for each bit i:
    borrow_{i+1}=1 iff j_i+borrow_i>n_i
```

The second subtraction must be delayed because

```
M_i = n_{i+1}
```

for M=floor(n/2). Therefore the transducer must store the previous input digit before emitting the h digit. The proposed one-column delay is correct, but the initialization must be:

```
borrow(N=n-j-1)=1
borrow(h=M-1-j)=1
```

because both '-1' operations are represented as initial borrows.

Flush requires appending zero digits until all of the following are stable:

```
borrow_j = 0
borrow_N = 0
borrow_h = 0
```

A fixed number of zeros is not sufficient unless a bound on the remaining carry chain is included in the state. Canonical termination is therefore a semantic state condition, not padding alone.

## Corrected pseudocode

```python
def step(state, ni, ji, next_ni):
    bj, bn, bh, delay_j, val = state

    # j subtraction from n
    bj2 = int(ji + bj > ni)
    val2 = min(5, val + bj2)

    # delayed h digit, h_i = n_{i+1}-j_i-borrow_h
    h = (next_ni - delay_j - bh) & 1
    bh2 = int(delay_j + bh > next_ni)

    # N=n-j-1 subtraction borrow
    bn2 = int(ji + bn > ni)

    val2 = min(5, val2 + int(h + bh > (ni - ji - bn)))
    return (bj2,bn2,bh2,ji,val2)
```

The production checker must additionally carry:

* comparison state for j<M;
* canonical leading-zero status;
* Apery residue state for n and j;
* current truncated value of v2(b_n-b_j).

## Apery residue state

The multiplier rule gives a finite automaton because the residue is determined by the sequence

```
(n mod 2, floor(n/2) mod 8)
```

windows. The state must store the last three bits and the accumulated residue modulo 64. Three high zero bits are only a termination convention; they must be processed explicitly.

## Required exact cross-check

A correct implementation should test:

```python
from math import comb

def direct(n,j):
    M=n//2
    x=comb(n,j)*comb(n-j-1,M-1-j)
    c=0
    while x%2==0 and x:
        x//=2
        c+=1
    return c

for n in range(4,50):
    for j in range(n//2):
        assert transducer(n,j)==direct(n,j)
```

Failure of this equality is a transducer bug, not a conjecture issue.

## Conclusion

The Kummer portion can be made into a genuine arbitrary-length finite-state proof after adding the missing semantic states. The currently proposed BFS is not yet a proof certificate because the state invariant does not contain the full canonical termination and j<M conditions. The residue automaton has the same requirement. No finite scan over n can replace the reachable-state argument.
