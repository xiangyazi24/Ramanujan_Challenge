# Verdict

The balanced-core restriction does not break the abstract H^2 clique barrier by itself. The inverse-square clique argument can be rerun on the G-separated skeleton, but it still produces a D^2 scale. The banked M_D bound does not improve the exponent either: it gives a weaker p-dependent estimate unless combined with a genuinely distributional input.

Overall verdict: REFUTED (the hoped-for conclusion Q_D^bal << N does not follow from the listed toolkit alone).

## 1. G-balanced inverse-square clique argument

Let A be one color class inside a 2D window. Define

```
E^{>G}(A)=sum_{u<v, G<v-u<=D} 1/(v-u)^2.
```

The balanced triples are triples whose three pairwise gaps exceed G. Collapse A into G-clusters. Let the separated representatives be

```
y_1<...<y_m'.
```

Every balanced triple projects to a triple of distinct representatives, so

```
T_bal <= C(m',3).
```

The reverse direction is not automatic: a representative triple is only a potential balanced triple. Therefore the correct inequality is

```
m' >= (6 T_bal)^{1/3}
```
only if every separated triple counted by the quotient corresponds to a balanced triple. In general we only get the upper bound on T_bal.

For a quotient class, consecutive gaps satisfy

```
g_i>G, sum g_i <= D.
```

The original clique proof applies with the same double Cauchy argument:

```
sum_i 1/g_i^2 >= (sum_i 1/g_i)^2/(m'-1)
                 >= (m'-1)^3/D^2.
```

Hence

```
E^{>G}(A) >= c (m')^3/D^2.
```

Since T_bal <= O((m')^3), this gives

```
T_bal <= c D^2 E^{>G}(A).
```

Now sum over windows. The multiplicity of a pair of gap d is bounded by R_d, hence

```
sum E^{>G} <= sum_{d=G+1}^D R_d/d^2
            <= C sum_{d=G+1}^D 1/d
            <= C log(D/G).
```

Therefore the balanced clique argument gives

```
Q_D^bal << D^2 log(D/G).
```

With D=sqrt(N)L this is

```
Q_D^bal << N L^2 log N.
```

The factor D^2 survives. The upper cutoff 1/G^2 does not help: it only bounds the same energy from above,

```
E^{>G} <= #(pairs)/G^2,
```
which does not relate the number of triples to the number of windows strongly enough.

Conclusion: balanced restriction alone does not defeat the clique extremizer.

## 2. Hybrid with the window multiplicity bound

The banked estimate is

```
M_D <= 4 D^(2/3).
```

A crude window argument gives for one window

```
C(m,3) <= m^3/6 <= (64/6)D^2.
```

There are about N/D windows, so

```
Q_D <= O(ND).
```

At

```
D=sqrt(N)L
```
this becomes

```
Q_D <= N^(3/2)L.
```

This is much worse than the clique bound

```
D^2 log D = N L^2 log N.
```

The M_D cap controls local maximum multiplicity but loses the inverse-square global averaging.

For balanced triples the same cap gives no new saving. Removing G-near pairs only decreases the local count by an unknown amount; the worst-case color class can have its allowed D^(2/3) representatives spread across the window and still produce the same exponent.

## 3. Sharpest unconditional bound from the listed toolkit

Combining:

```
R_d <= 3(d-1)
clique inverse-square energy
M_D <= 4D^(2/3)
axis-strip O(N)
```

gives

```
Q_D^bal << D^2 log(D/G) + O(N)
```

and therefore at the mesoscopic scale

```
Q_D^bal << N L^2 log N.
```

This does not imply O(N).

The missing input is not another clique estimate. The missing statement must be distributional, for example:

```
(G-BALANCED DISPERSION)
Sum over windows and colors of C(m_bal,3)
<< number_of_windows * constant
```

or equivalently a bound showing that G-separated color classes have bounded third moment:

```
Sum_{windows,color} (m_bal)_3 << N.
```

A weaker sufficient input is a balanced pair correlation estimate:

```
Sum_{G<d<=D} (# balanced returns of gap d)/d^2 << N/D^2.
```

This is precisely the information absent from R_d, which only controls first pair returns.

## 4. Final answers

(a) Least-confident step:

The least secure step is the assertion that no further use of the M_D cap plus axis-strip decomposition can lower the exponent. A more refined two-scale decomposition could exploit correlations between large multiplicity windows and the axis contribution. The current argument only tests the naive hybrid.

(b) Likely blind spot:

The shared blind spot is assuming that the correct state variable is the number of pairs R_d. The balanced-core problem asks for a three-point statistic after removing all short edges. A successful proof likely needs a new invariant controlling the G-separated skeleton (for example a projective-orbit mixing or higher-order energy statement), not a sharper version of pair counting.
