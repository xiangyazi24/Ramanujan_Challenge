# Integer-only route: sparsity, gap polynomials, and the Apéry GCD problem

## Executive conclusion

The integer route is not hopeless, but the naive product argument cannot work. The missing ingredient is not another size estimate; it is a quantitative control on *collisions of large prime divisors among nearby Apéry numbers*.

The strongest realistic unconditional theorem obtainable from this direction is likely a sublinear bound of the form

```
S(m) = #{p in (m/2,m] : p | b_m} <= m^(1-epsilon)
```

provided one proves a strong enough gap-polynomial collision theorem. The full conjecture `B(m)=o(m)` requires only a logarithmic saving, so this route attacks exactly the right object.

## 1. The top-window reduction

For p in (m/2,m], Lucas gives

```
p | b_m  <=>  p | b_{m-p}.
```

Let r=m-p. Then every hit gives a pair

```
r < m/2,   p=m-r prime,   p | b_r.
```

Thus

```
S(m)=#{r<m/2 : m-r is prime and m-r | b_r}.
```

This is a shifted prime-divisor problem for the sequence.

## 2. Why the size bound fails

The argument

```
prod p_i <= prod b_{r_i}
```
only gives

```
S log m <= C sum r_i,
```
which is compatible with S of order m/log m. It sees only the exponential growth of b_n and has no information about arithmetic sparsity.

The missing phenomenon is that the divisibility events are not independent: a large prime divisor of several b_r values forces algebraic constraints.

## 3. Large-prime collisions

Suppose

```
ell | b_r and ell | b_s,
```
with ell > max(r,s). Then r and s are both zeros of the Apéry polynomial modulo ell.

If h=|r-s|, the gap polynomial gives

```
N_h(r) == 0 mod ell.
```

Therefore every large common divisor with gap h must divide a fixed integer

```
N_h(r)
```
whose degree is O(h) and whose height is controlled.

This is the key possible bridge: collisions are converted into divisors of explicit integers.

## 4. What would be enough

A theorem of the following type would immediately imply progress:

```
GapCollision(m,H):
For all h<=H and r<m/2,
number of primes ell>m/2 dividing N_h(r)
    <= C H^alpha log(m).
```

Combined with dyadic decomposition of the gaps between the r_i, this would control how many of the p_i can share hidden arithmetic structure.

A stronger desired statement is:

```
For every m,
#{p in (m/2,m] : p|b_m} <= m^(1-epsilon).
```

Even

```
<= m/(log m)^(1+delta)
```
would imply the required o(m) contribution from the top window.

## 5. Role of the Casoratian

The Casoratian

```
a_n b_{n+1}-a_{n+1}b_n=-6/(n+1)^3
```

prevents excessive simultaneous vanishing of the two independent recurrence solutions modulo a prime. It is a rigidity statement, but by itself it does not count zeros of b_n. Its role is to strengthen collision estimates: a prime cannot make too many recurrence states degenerate without forcing a contradiction in the determinant relation.

## 6. The realistic theorem hierarchy

The most plausible sequence of results is:

1. Prove bounded multiplicity of large-prime collisions using gap polynomials and the Casoratian.

2. Deduce

```
S(m) <= m^(1-epsilon)
```

for some epsilon>0.

3. Improve the exponent until

```
S(m)=o(m).
```

4. Feed this into the existing reduction from top-window hits to the GCD conjecture.

## 7. Final assessment

This route is substantially different from the crystalline/Katz approach. It does not require defining-characteristic equidistribution. The obstacle is transformed from "randomness of zeros" into "repulsion of zero patterns".

The gap polynomial is the correct object, but the needed theorem is not merely that N_h has degree O(h). One needs an averaged arithmetic statement controlling the product of all collision primes over many possible gaps.

So the concrete target is:

```
Large-prime collision theorem for Apéry zeros:
The total contribution of primes ell causing two or more hits
among {b_0,...,b_R} is O(R^(1-delta)).
```

A proof of this would be a genuine new unconditional advance and would bypass the l-adic/crystalline gap entirely.
