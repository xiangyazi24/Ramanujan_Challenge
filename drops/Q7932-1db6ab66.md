# Q7932 — exact high-frequency truncation audit

## 1. Normalized half-range identity

The repository normalization is the centered real transform normalization:

```
F_p(a)=sum_{r in Z_p} e_p(ar)=e_p(-a/2)R_p(a),
R_p(a)=sum_{r in Z_p}e_p(a(r+1/2)).
```

Reflection gives `R_p(a) in R` and `R_p(-a)=R_p(a)`. Pairing the primitive CRT frequency `h` with `-h` therefore produces a real half-range sum. No factor of two is lost: the full unit sum is replaced by one representative from each pair and the kernel is the paired Dirichlet kernel. The relevant bound below uses the exact half-range coefficients.

For the output-prime compression write

```
E_p = sum_{q,l != p} T_{p,ql},
```

with the semiprime block containing frequencies `1 <= h <= (pql-1)/2`. Let `E_p^{>H}` retain only `|h|>H`.

## 2. What can be proved without cancellation

For

```
D_M(alpha)=sum_{m<M}e(alpha m)
```

we have the exact bound

```
|D_M(h/(pql))| <= min(M, ||h/(pql)||^{-1}).
```

Here `M=X^2` and `p,q,l~X`, so `Q=pql~X^3`. For the high range `H<h<=Q/2`,

```
|D_M(h/Q)| << Q/h.
```

The squared tail kernel satisfies

```
sum_{h>H}|D_M(h/Q)|^2
 << Q^2 sum_{h>H}h^{-2}
 << Q^2/H.
```

This is the sharp deterministic Dirichlet-kernel estimate. There is no extra saving from periodicity because the primitive restriction `(h,Q)=1` only removes terms.

## 3. Insert Parseval for the centered rows

Parseval gives

```
sum_{a mod p}|R_p(a)|^2 = p |Z(p)|.
```

After CRT permutation of frequencies, every individual prime row contributes at most this energy. Applying Cauchy to the ordered semiprime blocks gives

```
|E_p^{>H}|^2
 << (#blocks) * (tail kernel energy) * (row energies).
```

There are `~X^2` ordered `(q,l)` blocks. With three row energies and the weight `p/Z(p)`, the cancellation-free bound is

```
sum_p p/Z(p) |E_p^{>H}|^2
 << X^{4+o(1)} * X^3/H.
```

The exact exponent loss comes from the high-frequency kernel only: the available bound is

```
X^7/H
```
(up to logarithms and the zero-density factors), not `X^4 lambda^5`.

Therefore the deterministic Parseval/Dirichlet argument would require

```
H >> X^3 lambda^{-5}
```
which is larger than the full modulus range `Q~X^3`. Hence no nontrivial high-frequency truncation follows.

## 4. Cross-band terms

Splitting into dyadic bands `H<h<=2H`, the same argument gives

```
Band(H) << X^7/H.
```

Summing all bands gives a convergent geometric series dominated by the first retained band. There is no orthogonality between bands: the square expands as

```
sum_{H,H'} <E_H,E_H'>
```

and the absolute-value bound reproduces the largest band. The exact obstruction is that Parseval controls the row variables but not correlations between the modulus-dependent permutations

```
h -> h(q l)^{-1} mod p.
```

## 5. Finite-band theorem that survives

The strongest unconditional statement from the stated inputs is:

```
For any H>=1,
 sum_p (p/Z(p)) |E_p^{|h|>H}|^2
 << X^{7+o(1)}/H.
```

This is sharp for the available hypotheses.

A finite-band truncation to `H=X^{3-o(1)}` is necessary before this estimate reaches the HM3 target scale. Therefore a fixed number of width-`X` low bands cannot isolate the difficulty.

## 6. Countermodel obstruction

The row hypotheses allow the following deterministic model. Choose reflection-symmetric sets with size `Z(p)=X^{2/3}` and arrange their centered transforms to concentrate on a compatible set of frequencies. Parseval is saturated:

```
||R_p||_2^2=pZ(p).
```

The allowed row facts do not prohibit simultaneous alignment of the CRT pullbacks. Then the high-frequency kernel contributes at its maximal `Q/h` size and the bound above is attained up to logarithms. Thus reflection, sparsity, no-adjacent-zero, and pair-codegree information alone cannot produce the missing factor.

## 7. Executable identity check

A finite check of the normalization is:

```python
from cmath import exp, pi

def R(p,Z,a):
    return sum(exp(2j*pi*a*(r+0.5)/p) for r in Z)

def F(p,Z,a):
    return sum(exp(2j*pi*a*r/p) for r in Z)

p=11
Z=[1,9]
for a in range(p):
    assert abs(F(p,Z,a)-exp(-2j*pi*a*0.5/p)*R(p,Z,a))<1e-9
```

This checks only the exact Fourier convention, not the analytic estimate.

**Theorem:** the unconditional tail bound above follows from the exact kernel decay and Parseval.

**Finite evidence:** numerical centered-band concentration in HM3 may occur for the actual Apéry rows.

**Not proved:** that Apéry rows have the additional cross-frequency correlation needed to improve `X^7/H` to `X^{4+o(1)}lambda^5`.
