## 1. Why the obvious \(n\)-only Laurent invariant is not enough

There is already a trivial exact answer to the divisibility part:

\[
b_n=\operatorname{CT}\Lambda^n.
\]

If \(n=qp+r\), \(0\le r<p\), and \(p>\sqrt n\), then \(q<p\), so Apéry-Lucas gives
\[
b_n\equiv b_qb_r\pmod p.
\]
Hence
\[
p\mid b_r\quad\Longrightarrow\quad p\mid b_n.
\]
Thus \(b_n\) is a characteristic-zero, \(n\)-only, actual-Laurent invariant containing every target prime.

But its height is exactly at the wrong scale:
\[
\log b_n
=n\log(17+12\sqrt2)+O(\log n)
\sim 3.52549\,n.
\]
So the issue is not finding an \(n\)-only integer. The issue is **archimedean compression without losing target divisibility**.

The Hasse/Franel square does not compress this: it rewrites the same coefficients in a reciprocal square. The toric Mellin square also does not compress it: it rewrites the same coefficient as a finite-field quadratic cancellation.

## 2. The exact actual-Laurent Cartier lift

Write
\[
\Lambda(X)=\sum_{u\in\mathbb Z^3}\lambda_u X^u,
\qquad
\Lambda^M=\sum_{\nu\in\mathbb Z^3}a_M(\nu)X^\nu.
\]
Define the full \(e\)-Cartier shell
\[
C_M(e):=\sum_{\nu\in e\mathbb Z^3}a_M(\nu).
\]
This is an ordinary integer in characteristic zero. It is exactly the `shell_fast`/`C_M(d)` object in the current Cartier packet code.

### Lemma 2.1 — target-selective shell congruence

Let \(p\) be a prime with
\[
\sqrt n<p\le n,\qquad p\nmid n,
\]
put
\[
q=\left\lfloor\frac np\right\rfloor,\qquad
r=n-qp.
\]
If \(p\mid b_r\), then necessarily \(1\le r\le p-2\), and
\[
\boxed{
C_{n-q}(p-1)\equiv b_r\pmod p.
}
\]
In particular,
\[
p\mid b_r\quad\Longrightarrow\quad
p\mid C_{n-q}(p-1).
\]

### Proof

Set
\[
M=n-q=q(p-1)+r.
\]
For a Laurent polynomial \(F=\sum_\nu c_\nu X^\nu\), torus orthogonality gives
\[
\sum_{x,y,z\in\mathbb F_p^\times}F(x,y,z)
\equiv
-\sum_{\nu\in(p-1)\mathbb Z^3}c_\nu
\pmod p,
\]
because each one-variable sum is \(p-1\equiv-1\pmod p\), hence the three-variable sign is \((-1)^3=-1\).
Therefore
\[
\sum_{(\mathbb F_p^\times)^3}\Lambda^M
\equiv-C_M(p-1)\pmod p.
\]

Since \(M-r=q(p-1)\) and \(r\ge1\), pointwise on the torus (including points where \(\Lambda=0\)) one has
\[
\Lambda^M=\Lambda^r.
\]
For a genuine target \(r=p-1\) is impossible, because the reciprocal Hasse polynomial gives
\[
b_{p-1}\equiv b_0\equiv1\pmod p.
\]
Thus \(1\le r\le p-2\). The exponent coordinates of \(\Lambda^r\) lie in \([-r,r]\), so no nonzero exponent vector can lie in \((p-1)\mathbb Z^3\). A second application of torus orthogonality gives
\[
\sum_{(\mathbb F_p^\times)^3}\Lambda^r
\equiv-\operatorname{CT}\Lambda^r
=-b_r\pmod p.
\]
Comparing the two sums yields
\[
C_M(p-1)\equiv b_r\pmod p.
\]

This is the characteristic-zero lift that the Hasse and Mellin formulas do not provide: the moving target coefficient is represented by reduction of an **integer shell sum**.

### Important valuation warning

This is a radical-level statement, not a \(p\)-adic valuation identity. The current exact audit contains the explicit example
\[
v_{17}(b_3)=2,
\]
while the corresponding packet coordinate and first shell have only one factor of \(17\). So a single shell must not be used to infer \(v_p(b_r)\).

For the all-index GCD theorem that is not fatal: the existing Wronskian estimate gives
\[
v_p(G_n)\le3
\qquad(p>\sqrt n),
\]
so sublinear control of the large-prime radical is sufficient up to a factor \(3\).

## 3. One global characteristic-zero invariant: Cartier–Smith content

For a fixed quotient \(q\), let
\[
\mathcal P_{n,q}
=\left\{p:\sqrt n<p\le n,\ p\nmid n,
\left\lfloor\frac np\right\rfloor=q\right\},
\]
let
\[
P_{n,q}=\prod_{p\in\mathcal P_{n,q}}p,
\]
and put
\[
s_{n,p}:=C_{n-q}(p-1).
\]
Define the first Smith divisor
\[
\boxed{
\mathfrak C_{n,q}
:=\gcd_{p\in\mathcal P_{n,q}}
\left(\frac{P_{n,q}}p\,s_{n,p}\right).
}
\]
If the block is empty, set \(\mathfrak C_{n,q}=1\).
Finally set
\[
\boxed{
\mathfrak C_n:=\prod_q\mathfrak C_{n,q}.
}
\]
Only \(q<\sqrt n\) can occur.

This is one integer determined completely by \(n\) and the fixed Laurent polynomial \(\Lambda\). The individual primes are used only as the deterministic index set of the Smith vector; no target/non-target decision enters the definition.

### Theorem 3.1 — exact target projection

For every quotient block,
\[
\boxed{
\gcd(\mathfrak C_{n,q},P_{n,q})
=R_q(n)
:=\prod_{\substack{p\in\mathcal P_{n,q}\\p\mid b_{n\bmod p}}}p.
}
\]
Consequently every genuine target prime \(p>\sqrt n\) divides \(\mathfrak C_n\).

### Proof

Fix \(\ell\in\mathcal P_{n,q}\). For every generator indexed by \(p\ne\ell\), the factor \(P_{n,q}/p\) contains \(\ell\). Thus all those generators are automatically divisible by \(\ell\). The only generator that can prevent \(\ell\) from entering the gcd is its own generator
\[
\frac{P_{n,q}}\ell s_{n,\ell},
\]
whose prefactor is prime to \(\ell\). Hence
\[
\ell\mid\mathfrak C_{n,q}
\iff
\ell\mid s_{n,\ell}.
\]
By Lemma 2.1,
\[
\ell\mid s_{n,\ell}
\iff
\ell\mid b_{n\bmod\ell}.
\]
Since \(P_{n,q}\) is squarefree, intersecting with it gives exactly the target radical.

This is stronger than saying that an auxiliary object “mostly removes non-target primes”: **inside the candidate prime block its support is exactly the genuine target set.**

## 4. Why this is the right invariant but not yet a proof

Write
\[
R_{>\sqrt n}(n)=\prod_qR_q(n).
\]
The theorem gives
\[
R_{>\sqrt n}(n)\mid\mathfrak C_n,
\qquad
\log R_{>\sqrt n}(n)\le\log|\mathfrak C_n|.
\]
If one could prove
\[
\boxed{\log|\mathfrak C_n|=o(n),}
\]
then the all-index conjecture would follow immediately:
\[
\sum_{p>\sqrt n}v_p(G_n)\log p
\le3\log R_{>\sqrt n}(n)
\le3\log|\mathfrak C_n|=o(n),
\]
and the existing small-prime estimate contributes only \(O(\sqrt n)\).

Therefore a proved \(o(n)\) height bound for this invariant is not a minor lemma; it **is a complete solution route**.

What the current repository does establish is evidence that the height may collapse at the **content** level even though every individual carrier is enormous:

- `q32_newton_gcd_audit.py` checks the hostile \(n=321\) row. Six overlapping primitive Newton carriers have about \(529\) decimal digits each, but the gcd of the first two is already
  \[
  179\cdot193\cdot211,

That is exactly the phenomenon an \(o(n)\) theorem would need to make uniform.

## 5. Prime-free Newton realization of the same mechanism

The Smith-content definition above uses the complete deterministic prime block. There is also a prime-free characteristic-zero realization, already implicit in the current Newton code.

Fix \(q\), and put
\[
d_q=\left\lfloor\frac n{q+1}\right\rfloor,
\qquad
D_q=\left\lfloor\frac nq\right\rfloor-1,
\qquad
M_q=n-q.
\]
If \(p\) lies on the \(q\)-arc, then
\[
e_0=p-1\in[d_q,D_q].
\]
For an integer interval \([a,a+L]\), define the primitive Lagrange carrier at the external node \(-1\):
\[
G_M(a,L)
:=\sum_{i=0}^{L}
(-1)^i
\binom{a+i}{i}
\binom{a+L+1}{L-i}
C_M(a+i).
\]
The weights are precisely the integer Lagrange weights used by the current scripts.

If \(e_0=p-1\in[a,a+L]\) and \(L<p\), then modulo \(p\)
\[
w_e\equiv
\begin{cases}
1,&e=e_0,\\
0,&e\ne e_0.
\end{cases}
\]
Indeed, in the product formula for Lagrange evaluation at \(-1\), every other weight contains the numerator factor \(-1-e_0=-p\), while all denominator differences have absolute value \(<p\); for the \(e_0\)-weight, \(-1-j\equiv e_0-j\pmod p\).
Therefore
\[
G_{M_q}(a,L)\equiv C_{M_q}(p-1)\equiv b_r\pmod p.
\]
So every target prime whose node lies in the stencil divides the carrier.

A family of overlapping stencils all containing a subarc therefore gives an integer ideal
\[
(G_0,\ldots,G_S)\subset\mathbb Z
\]
whose positive generator
\[
\Gamma=\gcd(G_0,\ldots,G_S)
\]
is divisible by every target prime in that subarc. This is the prime-free form of the Cartier–Smith content. Partitioning the \(q\)-arc into deterministic subarcs and multiplying the corresponding contents gives one \(n\)-only integer containing every target prime.

The existing fixed-\(q\) Newton reduction
\[
R_q(n)\mid B_S\,c_{S,q}(n),
\qquad
\log B_S=O(S^2),
\]
should be understood exactly as an attempted **archimedean upper bound for this content ideal**: \(B_S\) is structural/Smith boundary cost; \(c_{S,q}\) is the remaining actual-shell nuisance.

Thus the sharp global target from Q7460 can be restated as:
\[
\sum_{q<Q(n)}
\bigl(O(S_q^2)+\log c_{S_q,q}(n)\bigr)
+O\!\left(\frac n{Q(n)}\right)
=o(n),
\]
with \(Q(n)\to\infty\). The last term is the deterministic prime-counting cost of throwing away all larger quotients. This is a characteristic-zero content theorem, not a single-prime zero-count theorem.

## 6. Exact Hasse-square no-go for bounded-degree norms/resultants

The Hasse/Franel descent gives
\[
A_p(a)=\Delta(a)^{\varepsilon_p}B_p(a)^2,
\]
with \(B_p\) the truncation of one of two universal characteristic-zero series. This is useful, but `hasse_square_no_go.tex` proves that the abstract square/reciprocity geometry is maximally flexible in the first half.

Here is the exact algebraic consequence relevant to the present question.

### Proposition 6.1 — moving-coordinate hyperplane no-go

Work over a characteristic-zero field \(K\). Let
\[
H(t)=\Delta(t)^\varepsilon B(t)^2
=\sum_jH_jt^j
\]
be the universal normalized reciprocal-square family of degree \(2d+2\varepsilon\). For \(m<d/2\), the coordinates
\[
(H_1,\ldots,H_m)
\]
are algebraically independent coordinates: the map from the free square-root coefficients is a triangular polynomial automorphism.

Let
\[
F\in K[H_1,\ldots,H_m]
\]
be any polynomial invariant such that, for every member of this reciprocal-square family,
\[
H_m=0\quad\Longrightarrow\quad F=0.
\]
Then
\[
\boxed{H_m\mid F.}
\]
More generally, if \(J\subset\{1,\ldots,m\}\) and \(F\) vanishes whenever \(H_j=0\) for any \(j\in J\), then
\[
\boxed{\prod_{j\in J}H_j\mid F.}
\]
In particular
\[
\deg F\ge |J|.
\]

### Proof

By triangular freedom, the \(H_i\) are polynomial coordinates on affine space. The condition \(H_m=0\) is therefore the ordinary coordinate hyperplane. A polynomial vanishing identically on that hyperplane lies in its prime ideal \((H_m)\). For several coordinates, the pairwise coprime coordinate functions each divide \(F\), hence their product divides \(F\).

### Consequence for norm/resultant constructions

A determinant, resultant, or norm from a bounded-rank finite algebra whose entries are polynomial expressions of bounded degree in the Hasse coefficients is itself a polynomial of bounded total degree in those coefficients. If its vanishing is supposed to follow **only** from “one moving Hasse coefficient is zero” plus reciprocity/squareness, then it must contain that moving coefficient as a factor. If the construction is required to work uniformly for a moving zero among \(\Theta(n)\) possible first-half coordinates, its degree must be \(\Omega(n)\).

So the reciprocal-square theorem does not create a bounded-degree norm whose zero detects the moving target. Reflection only copies the same equation to the reciprocal position; it does not add an independent codimension.

This is deliberately a **narrow** no-go. It does not rule out an Apéry-specific invariant using the arithmetic relation between the moving index and the residue characteristic. The Cartier shell \(C_{n-q}(p-1)\) is exactly such additional structure and therefore escapes this proposition.

## 7. The toric Mellin square and carry polygon do not give a norm either

The toric identity is
\[
b_j=-\sum_{t\in\mathbb F_p^\times}
 t^jA_j(t)A_{p-1-j}(t),
\]
and in the first half
\[
b_j=-\sum_{t\ne0}
 t^j(1-t)^{p-1-2j}A_j(t)^2.
\]
The repository correctly labels this a **quadratic collapse, not a saving**. Expanding it recovers the original Apéry binomial sum coefficient by coefficient. The pairing is indefinite over \(\mathbb F_p\); \(b_j=0\) is an isotropy/cancellation condition, not a statement that a factor or algebraic element has norm zero. The actual zero \((p,j)=(11,5)\) already shows that the weighted-square sum can vanish.

Therefore one cannot infer from this formula alone that any product or bounded-degree norm of the individual \(A_j(t)\) values vanishes. To get a norm argument one would need an additional Apéry-specific theorem making the relevant quadratic form anisotropic on the distinguished vector, or identifying the whole weighted sum as the norm of one bounded-degree algebraic integer. No such theorem is present, and the finite-field identity itself gives no reason for it.

The carry-polygon result is even sharper about what is unavailable. For \(j=5\), the complete termwise valuation vector is
\[
(0,0,0,0,0,0)
\]
for both \(p=11\) and \(p=13\), yet
\[
11\mid b_5,
\qquad
13\nmid b_5.
\]
Thus any construction depending only on slopes, termwise valuations, rank, determinant valuation, or conductor cannot decide the target event. A successful crystalline invariant must retain the **normalized slope-zero residue/trace**, not just its polygon.

Again the Cartier shell does exactly that at the congruence level: it is an integral characteristic-zero lift whose reduction is the target coefficient.

## 8. What Hasse reciprocity *does* give: an exact \(p\)-free radical identity, but no height gain

There is a useful exact reformulation showing precisely how far reciprocity alone gets.

For a target prime \(p>\sqrt n\), let
\[
r=n\bmod p,
\qquad
j=\min(r,p-1-r).
\]
Reciprocity gives
\[
p\mid b_j,
\]
and \(p>2j\). Moreover:

- if \(j=r\), then \(p\mid n-j\);
- if \(j=p-1-r\), then \(p\mid n+j+1\).

Conversely, if
\[
\sqrt n<p\le n,\qquad p>2j,\qquad p\mid b_j,
\]
and
\[
p\mid(n-j)(n+j+1),
\]
then either \(n\bmod p=j\) or \(n\bmod p=p-1-j\); in the second case reciprocity again gives a genuine target. Such a \(j\) automatically satisfies \(j\le(n-1)/3\).

Hence, with
\[
\operatorname{rad}_{\mathcal S}(m)
:=\prod_{\substack{p\in\mathcal S\\p\mid m}}p,
\]
one has the exact characteristic-zero identity
\[
\boxed{
R_{>\sqrt n}(n)
=
\operatorname{lcm}_{0\le j\le\lfloor(n-1)/3\rfloor}
\operatorname{rad}_{\{p:\sqrt n<p\le n,\ p>2j\}}
\gcd\!\left(b_j,(n-j)(n+j+1)\right).
}
\]

This is a clean all-characteristic reformulation using only the actual integer Apéry coefficients \(b_j=\operatorname{CT}\Lambda^j\) and the two linear forms forced by Hasse reciprocity. But its logarithmic height is **exactly the target radical mass**. It is therefore a restatement, not a bound.

This identity also explains why generic monodromy or bounded \(Z(p)\) cannot finish the problem: what remains is a large-prime gcd/alignment statement between the fixed characteristic-zero sequence \(b_j\) and the moving linear forms \(n-j\), \(n+j+1\).

## 9. Why a *proved* sublinear-height invariant would already solve the theorem

Suppose \(I_n\in\mathbb Z\setminus\{0\}\) is any characteristic-zero quantity such that every genuine target prime \(p>\sqrt n\) divides \(I_n\). Then
\[
R_{>\sqrt n}(n)\mid I_n.
\]
If additionally
\[
\log|I_n|=o(n),
\]
then
\[
\log R_{>\sqrt n}(n)=o(n).
\]
By the existing Wronskian valuation bound,
\[
v_p(G_n)\le3
\qquad(p>\sqrt n),
\]
so
\[
\sum_{p>\sqrt n}v_p(G_n)\log p=o(n).
\]
The already-proved small-prime estimate is \(O(\sqrt n)\). Therefore
\[
\log G_n=o(n).
\]

So there is no honest way to present a **proved** \(o(n)\)-height target-containing invariant here without announcing a proof of the conjecture. I do not have such a proof from the audited material.

## 10. The extra structure that would be enough

The narrow no-go above says what is missing. A successful invariant must use something beyond a single Hasse coordinate or a single finite-field quadratic sum. The most plausible forms are:

1. **Cartier–Newton content collapse.**  Prove that after removing explicit Lagrange/Smith boundary content, the gcd of several overlapping actual shell carriers has subexponential height, uniformly over the quotient arcs needed by Q7460. Concretely, a bound of the shape
   \[
   \sum_{q<Q(n)}
   \left(O(S_q^2)+\log c_{S_q,q}(n)\right)
   =o(n)
   \]
   with \(Q(n)\to\infty\), together with the \(O(n/Q(n))\) exceptional tail, is enough.

2. **A \(p\)-independent low-height syzygy in the shell variable.**  One needs a characteristic-zero relation among several values
   \[
   C_{n-q}(e),\ C_{n-q}(e+1),\ldots
   \]
   whose coefficient/Smith height is \(e^{o(n)}\) and whose reduction at \(e=p-1\) still sees \(b_{n\bmod p}\). A relation that holds for all shell sequences but whose determinant merely contains the structural factor \(p\) is not enough; it must use the actual Laurent values and make the **target zero** contribute an extra common divisor.

3. **A genuine bounded-degree anisotropic norm lift.**  This would require a bounded-degree number field/algebra and an algebraic integer 
   \(\alpha_n\) with \(h(\alpha_n)=o(n)\) such that every target \(p\) forces \(p\mid N(\alpha_n)\). The Hasse square and toric Mellin square do not supply such an \(\alpha_n\): triangular freedom and indefinite cancellation are the exact obstructions. Finding one would be a major new structural theorem and would immediately prove the conjecture.

4. **A characteristic-zero large-prime gcd theorem for the reflected formulation.**  It would suffice to prove directly
   \[
   \sum_{j\le(n-1)/3}
   \log
   \operatorname{rad}_{\{p:\sqrt n<p\le n,\ p>2j\}}
   \gcd\!\left(b_j,(n-j)(n+j+1)\right)
   =o(n).
   \]
   This is exactly cross-prime alignment in characteristic-zero language. The conclusion of `proof.tex` explains why present Subspace-Theorem methods do not apply: the Apéry numbers are P-recursive rather than a finite exponential-polynomial sequence.

## 11. Warning list

- **\(b_n\) is exact but too large.**  It contains every target prime by Lucas, but has linear logarithmic height.
- **A single Cartier shell is prime-specific and has no valuation fidelity.**  It gives the correct mod-\(p\) target, not \(v_p(b_r)\).
- **A single full Newton carrier is not enough.**  Current exact examples have linear exponential height despite primitive normalization.
- **Hasse squareness/reciprocity alone cannot yield a bounded-degree moving-zero norm.**  The moving zero is a free coordinate hyperplane; any universal polynomial consequence contains that coordinate as a factor.
- **Reflection is not an independent second equation.**  It maps \(H_j=0\) to the same coefficient equation at the reciprocal position.
- **The toric weighted square is not a positive norm.**  It can vanish by cancellation, and expanding it recovers the original Apéry coefficient tautologically.
- **The carry polygon does not detect zero.**  The actual \(p=11\) versus \(p=13\), \(j=5\) example has identical complete slopes but different zero behavior.
- **Bounded \(Z(p)\), monodromy, and single-prime anti-concentration do not control the needed alignment.**  The conclusion of `proof.tex` is correct on this point.
- **A small nuisance factor observed in finite Newton/Smith audits is evidence, not a theorem.**  The needed statement is uniform in \(n\) and across the growing quotient range.
- **Any proved \(o(n)\)-height integer containing all large target primes is already a proof of the all-index conjecture**, because the large-prime valuations are bounded by \(3\).

# Bottom line

The most defensible “one invariant” is the **Cartier–Smith content**
\[
\mathfrak C_n
=\prod_q
\gcd_{p\in\mathcal P_{n,q}}
\left(\frac{P_{n,q}}p C_{n-q}(p-1)\right).
\]
It is characteristic-zero, built from the actual Laurent polynomial, depends only on \(n\), and its candidate-prime projection is exactly the genuine target radical. It is therefore genuinely target-selective across characteristics.

What is missing is not another single-prime identity. It is an archimedean theorem saying that the **primitive common content** of these actual Cartier lifts is \(e^{o(n)}\). The current overlapping-Newton and Smith computations make that a plausible attack surface, but the audited Hasse/Mellin structures do not prove it. The narrow exact no-go above explains why a bounded-degree square/norm construction cannot replace that missing cross-characteristic content theorem.
