# Catalan/Wilson cross-products: exact reduction, parity correction, and the remaining obstruction

## Executive verdict

There is a normalization error in the proposed statement. With the matrix and row-vector convention printed in the question, the raw cross-product signs do **not** hold for every `N`. They already fail at `N=1`. The correct sign-conjugated cross-products are

```text
S = diag(1,-1,1),

pbar_N = (-1)^N p_N S,
qbar_N = (-1)^N q_N S,

E_N,j = pbar_N,j u_(N+2) - qbar_N,j v_(N+2)
      = (-1)^N s_j (p_N,j u_(N+2) - q_N,j v_(N+2)).
```

The experimentally correct theorem is therefore

```text
E_N,0 > 0,
E_N,1 < 0,
E_N,2 < 0.
```

This is exactly the convention already used by `positiveNumerator` and `positiveDenominator` in
`lean/RamanujanChallenge/Problem25.lean`.

I did not find a complete all-`N` proof of these three inequalities. In particular, I did not find a positive multiple integral or a finite invariant polyhedral cone whose facet inequalities all factor with nonnegative coefficients. It would be incorrect to claim otherwise.

What can be derived rigorously and concretely is:

1. the exact parity correction above;
2. an explicit order-two diagonal operator for the Wilson denominator `u_m`, with a fully printed WZ certificate;
3. the corresponding candidate common operator for the Wilson pair `(u_m,v_m)`;
4. an exact two-row cross-product evolution;
5. a triangular reformulation in which one half of the state is automatically positive;
6. an exact explanation of why a fixed-width cone around the Catalan ray is forward-unstable and why the missing cone must use the cross-product state.

Thus this answer gives a formalization-ready reduction of the sign problem, but not the requested final positivity theorem.

## 1. The statement as written is false

At `N=1`, direct multiplication gives

```text
p_1 = (-21390206625, 13063139595, -1590511050),
q_1 = (-23352603750, 14261609250, -1736437500).
```

The Wilson values at `m=3` are

```text

v_3 = 11319003701921/6147187200.
```

Consequently

```text
p_1,0 u_3 - q_1,0 v_3 = -6097725450/121 < 0,

p_1,2 u_3 - q_1,2 v_3 =  1448618275/121 > 0.
```

These are the opposite of the two raw signs asserted in the question. After the missing factor `(-1)^N`, the corrected values are

```text
E_1 = (6097725450/121,
      -921310425/121,
      -1448618275/121).
```

At `N=0` one has

```text
E_0 = (30495/49,
      -185985/784,
      -250275/784).
```

So the corrected sign pattern is already visible in the first two exact states.

The positive-row transition is

```text
P_N = -S A(N) S.
```

Every entry of `P_N` is positive for `N >= 0`; this is the matrix called `positiveMatrix` in the Lean development. The signed rows satisfy

```text
pbar_(N+1) = pbar_N P_N,
qbar_(N+1) = qbar_N P_N.
```

Since every component of `qbar_N` is positive, the corrected inequalities are equivalent to

```text
p_N,0/q_N,0 > v_(N+2)/u_(N+2),

p_N,1/q_N,1 < v_(N+2)/u_(N+2),
p_N,2/q_N,2 < v_(N+2)/u_(N+2).
```

This is the literal bracketing statement.


## 3. An explicit diagonal order-two operator for `u_m`

Define

```text
A4(m) = 12265 + 29296 m + 26176 m^2 + 10368 m^3 + 1536 m^4,

  + 9876373504 m^7
  + 3265527808 m^8
  + 628359168 m^9
  + 53477376 m^10.
```

Put

```text
a_m = 4 (m+1)^2 (4m+1)^2 (4m+3)^2 A4(m),

b_m = B10(m),

c_m = 4 (m+2)^2 (4m+5)^2 (4m+7)^2 C4(m).
```

Then the Wilson denominator satisfies

```text
a_m u_m - b_m u_(m+1) + c_m u_(m+2) = 0       (m >= 0).
```

```text
T(m,j) = binom(m,j)
```

Define

```text
G(m,j) = R(m,j) T(m+2,j),

R(m,j) =
  -4 j^3 P(m,j)
```

## 5. Exact cross-product evolution

Set `m=N+2` and define row vectors

```text
E_N = u_m pbar_N - v_m qbar_N,

F_N = u_(m+1) pbar_N - v_(m+1) qbar_N.
```

The first identity below is unconditional:

```text
E_(N+1) = F_N P_N.                              (5.1)
```

If `u` and `v` satisfy the common order-two recurrence, then

```text
F_(N+1)
  = ((b_m/c_m) F_N - (a_m/c_m) E_N) P_N.       (5.2)
```

Equations (5.1)-(5.2) are an explicit six-dimensional first-order recurrence for the desired cross-products. Every coefficient is a displayed rational function, and `P_N` is the printed polynomial matrix after the fixed sign conjugation.

This is the correct low-dimensional state. It records both the current Wilson value and its next contiguous value; an `E_N`-only cone loses precisely the information needed to compensate for the forward instability of the recessive ray.

## 6. Triangular positive-channel form

Define the Wilson Casoratian

```text
W_m = u_m v_(m+1) - u_(m+1) v_m,

rho_m = u_(m+1)/u_m.
```

If the common recurrence holds, then

```text
W_(m+1) = (a_m/c_m) W_m.
```

The initial value is

```text
W_1 = 2453/7840 > 0.
```

Hence `W_m>0` for every `m>=1`, and the Wilson quotients are strictly increasing:

```text
v_(m+1)/u_(m+1) - v_m/u_m
  = W_m/(u_m u_(m+1)) > 0.
```

Now put

```text
D_N = rho_m E_N - F_N.
```

A direct cancellation gives the exact identity

```text
D_N = (W_m/u_m) qbar_N.                         (6.1)
```

Thus every component of `D_N` is positive. Moreover, with

```text
kappa_m = a_m/(c_m rho_m) > 0,
```

(5.1)-(5.2) become the triangular system

```text
E_(N+1) = (rho_m E_N - D_N) P_N,                (6.2)

D_(N+1) = kappa_m D_N P_N.                      (6.3)
```

This is the strongest concrete structural reduction obtained here:

```text
- D_N is an independently propagated positive row;
- E_N is the desired signed row;
- the only subtraction is the explicit positive correction D_N;
- all later matrix multiplications use the entrywise-positive P_N.
```

Any successful invariant cone should be formulated for `(E_N,D_N)`, not for `E_N` alone.

## 7. Why the obvious cones fail

The target orthant is

```text
O = { (e0,e1,e2) : e0>0, e1<0, e2<0 }.
```

An entrywise-positive matrix does not preserve `O`. In (6.2), even knowing

```text
E_N in O,
D_N > 0
```

does not determine the signs of

```text
(rho_m E_N - D_N) P_N.
```

The missing inequalities must compare the sizes and projective directions of `E_N` and `D_N`.

The denominator direction is already controlled in Lean. If

```text
X_N = (N+1) qbar_N,1/qbar_N,0,
Y_N = (N+1)^3 qbar_N,2/qbar_N,0,
```

then `Problem25Connection.lean` proves

```text
1 <= X_N <= 3/2,
0 <= Y_N <= 2.
```

For the cross row, define

```text
x_N = -(N+2)^2 E_N,1/E_N,0,
y_N = -(N+2)^2 E_N,2/E_N,0.
```

The exact data approach the recessive direction `(x,y)=(5/4,2)`, but a fixed rectangle around that point cannot be invariant.

To see the obstruction algebraically, temporarily omit the `D_N` correction and write

```text
z_N = (1, -x/(N+2)^2, -y/(N+2)^2).
```

Let `z_N P_N` be renormalized in the same way, with coordinates `x',y'`. Direct expansion of the printed matrix gives

```text
x' = 12 (y-2)/(17-8y) * N + O(1),

y' = y/(17-8y) + O(1/N).
```

Thus any fixed-width interval with `y-2` bounded away from zero sends `x'` to size `Theta(N)`. The boundary must shrink.

More precisely, put

```text
x = 5/4 + alpha/(N+1),
y = 2   + beta /(N+1).
```

Then the homogeneous step has

```text
(N+2)(x' - 5/4)
  = 6(2 beta - 1) N
    + (-27 + 34 alpha - 27 beta + 192 beta^2)/2
    + O(1/N),

(N+2)(y' - 2)
  = 17 beta - 8 + O(1/N).
```

Therefore boundedness already forces

```text
beta = 1/2 + O(1/N).
```

This is a rigorous version of the warning in the question: a fixed-width cone around the recessive Catalan ray is forward-unstable. The positive correction `D_N` in (6.2) is not a nuisance; it is the datum that must select the shrinking stable boundary.

## 8. Formalization-ready exact map for a future cone certificate

The remaining search can be reduced to five scalar projective variables.

Write

```text
r = N+2,

E_N/E_N,0 = (1, -x/r^2, -y/r^2),

D_N/D_N,0 = (1, X/(N+1), Y/(N+1)^3),

eta = D_N,0/(rho_m E_N,0).
```

Then before multiplication by `P_N`, equation (6.2) is exactly

```text
(rho_m E_N - D_N)/(rho_m E_N,0)
 = (1-eta,
    -x/r^2 - eta*X/(N+1),
    -y/r^2 - eta*Y/(N+1)^3).
```

The next values `x',y'` are obtained by multiplying this displayed row by the explicit matrix `P_N` and taking the two indicated rational ratios. The denominator variables `X',Y'` are obtained by multiplying

```text
(1, X/(N+1), Y/(N+1)^3)
```

by `P_N`. Finally, `eta'` follows from (6.3).

A genuine polyhedral proof must therefore supply explicit rational bounds

```text
Lx(N) <= x <= Ux(N),
Ly(N) <= y <= Uy(N),
0 < eta <= Ueta(N),
1 <= X <= 3/2,
0 <= Y <= 2,
```

such that all five transformed bounds follow by checking finitely many vertices after clearing positive denominators. The asymptotic calculation above shows that `Ly,Uy` must track

```text
y = 2 + 1/(2(N+1)) + O(1/N^2),
```

rather than merely `y=2+O(1/N)`.

I tested natural fixed and first-order shrinking rectangles. They are not invariant at all vertices. No factorized finite cone certificate was obtained.

## 9. What is proved, what is conditional, and what remains open

### Proved here by exact identities

```text
1. The raw all-N sign statement in the question is false.
2. The missing normalization is (-1)^N s_j.
3. The corrected initial cross rows E_0 and E_1 have signs (+,-,-).
4. P_N=-S A(N) S is the positive transition already used in Lean.
5. The displayed order-two recurrence for u_m holds, with the printed WZ certificate.
6. E_(N+1)=F_N P_N holds identically.
7. D_N=rho_m E_N-F_N=(W_m/u_m)qbar_N holds identically.
8. Fixed-width projective cones around (5/4,2) are forward-unstable.
```

### Conditional on a symbolic proof of the common recurrence for `v_m`

```text
1. F_(N+1)=((b_m/c_m)F_N-(a_m/c_m)E_N)P_N.
2. W_(m+1)=(a_m/c_m)W_m and hence W_m>0.
3. D_(N+1)=kappa_m D_N P_N.
```

### Not proved

```text
E_N,0 > 0,
E_N,1 < 0,
E_N,2 < 0
for every N.
```

No positive sum/integral for these three cross-products, and no invariant finite polyhedral cone, was found. The numerical check through `N=41` remains evidence only.

## 10. Recommended theorem statement after correction

The theorem that should eventually be added to the Lean development is:

```text
Theorem (Wilson bracket, corrected normalization).
For every N>=0, let

  pbar_N,j = (-1)^N s_j p_N,j,
  qbar_N,j = (-1)^N s_j q_N,j,
  m = N+2.

Then qbar_N,j>0 and

  pbar_N,0 u_m - qbar_N,0 v_m > 0,
  pbar_N,1 u_m - qbar_N,1 v_m < 0,
  pbar_N,2 u_m - qbar_N,2 v_m < 0.
```

Equivalently,

```text
p_N,0/q_N,0 > v_(N+2)/u_(N+2)
              > max(p_N,1/q_N,1, p_N,2/q_N,2).
```

Together with Rivoal's convergence `v_m/u_m -> G` and the existing challenge envelope contraction, this would identify `commonLimit = catalanConstant`.

The exact system (6.2)-(6.3) is, at present, the smallest concrete state in which such a proof can plausibly close.
