# Q793: primary-literature audit for LGTQ-2

## Executive conclusion

The closest existing theorems do not currently close LGTQ-2. The obstruction is structural: LGTQ-2 asks for simultaneous divisibility conditions

```
p | b_{n-qp},   ell=p-d | b_{n-qell},   d=O(log n),
```

where the modulus varies with the candidate prime and the sequence index is an affine function of the same candidate. Existing prime-divisor and sieve results generally treat either fixed moduli, fixed recurrence coefficients, or averages over the sequence index. They do not provide a logarithmic saving for this moving-characteristic two-prime correlation.

## 1. Holonomic / P-recursive divisibility results

The Apéry numbers satisfy a fixed polynomial-coefficient recurrence. Standard results on P-recursive sequences control growth, zero sets, and reductions modulo a fixed prime.

Relevant theorem shape:

```
fixed recurrence + fixed prime p
        => information about b_n mod p as n varies.
```

LGTQ-2 requires the opposite arrangement:

```
index u=n-qp varies with p,
characteristic p varies with u,
then a second characteristic ell=p-d also varies.
```

The recurrence is fixed, but the reduction field is not. Therefore fixed-characteristic results do not apply.

## 2. Horizontal Frobenius / trace-function viewpoint

A possible reformulation is to regard

```
b_u mod p
```

as a Frobenius trace depending on both u and p.

However, the available trace-function estimates require a fixed sheaf over a fixed finite field or a controlled family with explicitly bounded conductor. Here the parameter p changes the base field and the affine point u=n-qp changes with p.

The missing theorem would need a statement of the form:

```
#{p in interval:
  Tr(Frob_p, F(n-qp))=0 and
  Tr(Frob_{p-d},F(n-q(p-d)))=0}
=o(n/log^2 n).
```

No primary theorem located has this moving-characteristic two-field form.

## 3. Shifted-prime sieve mismatch

Classical shifted-prime sieve results handle conditions such as

```
p | F(m), p+d | G(m)
```

with fixed integer polynomials or fixed algebraic forms.

Here the divisibility objects are

```
F_p = b_{n-qp},
G_{p-d}=b_{n-q(p-d)},
```

so the polynomial/trace object itself depends on the prime.

The conductor and coefficient height of a putative replacement object are not fixed. A uniform sieve level is therefore unavailable without a new input controlling this dependence.

## 4. What would actually close LGTQ-2

A sufficient theorem would be a moving-characteristic large sieve:

For fixed q and d=O(log n),

```
S(n,q,d)=#{p~n/q:
 p|b_{n-qp},
 p-d|b_{n-q(p-d)}}
```

satisfies

```
S(n,q,d)=o(n/log^2 n).
```

A weaker but still sufficient result would be a level-of-distribution estimate with error

```
O(n/log^{2+epsilon} n)
```

uniformly for d up to logarithmic size.

No theorem found gives this.

## 5. Closest hypothesis mismatches

### Fixed modulus congruence theorems

These average over n for a fixed p.

Mismatch:

```
known: fixed p, n varies
needed: p varies, n-qp varies.
```

### Polynomial prime divisor sieve

These require a fixed polynomial F.

Mismatch:

```
known: p|F(m)
needed: p|b_{n-qp}.
```

The index contains p itself.

### Twin/shifted prime correlation technology

These study

```
p and p-d both prime.
```

LGTQ-2 already conditions on this and additionally imposes two unrelated moving Apéry divisibility events. Prime correlation estimates do not address the sequence values.

## 6. No unconditional logarithmic saving from current literature class

The natural two-prime heuristic scale is

```
(n/log n)^2 / n = n/log^2 n
```

after the affine relation p-d is imposed.

The existing one-variable sieve inputs can at best recover this scale. They do not introduce cancellation because the two divisibility events are not represented by fixed characters with controlled conductor.

## 7. Required new input

The smallest missing estimate is an exponential/character sum of the form

```
max_{psi}
|Σ_{p~X} psi(b_{n-qp} mod p)
        psi'(b_{n-q(p-d)} mod (p-d))|
=o(X/log^2 X),
```

with both moduli varying and with conductor uniform in d=O(log n).

This is not a standard Deligne/Katz application because the family is not a single fixed sheaf over a fixed base field.

## Final audit result

No primary theorem currently matches LGTQ-2. The gap is not lack of a generic character-sum bound; it is the absence of a theorem for simultaneous divisibility of a holonomic sequence at affine complementary indices in two different characteristics.

A successful proof must either:

1. construct a genuinely bounded-conductor mixed-characteristic sheaf/sieve object, or
2. derive a new Apéry-specific cancellation identity beyond current recurrence and Lucas information.

Existing fixed-characteristic, fixed-polynomial, and shifted-prime sieve results do not provide the required little-oh saving.
