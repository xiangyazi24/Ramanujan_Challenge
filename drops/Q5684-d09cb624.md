# Growing Route A: exact Smith saturation and the terminal-window barrier

## Executive verdict

Growing the family of cross-Casoratians does **not** create a new low-height invariant. There are two exact regimes.

1. **Keep the indices near \(n\).** For a terminal window
   
   \[
   M_{n,H}=\{n-H,\ldots,n-1\},
   \]
   
   every top-half prime
   
   \[
   \frac n2<p\le n-H
   \]
   
   divides every cross-Casoratian to the sixth power for a completely universal lcm reason, independent of the Apéry target condition. Hence
   
   \[
   \prod_{n/2<p\le n-H}p^6
   \mid
   \gcd_{m\in M_{n,H}}(P_nQ_m-Q_nP_m),
   \]
   
   and
   
   \[
   \log \gcd_{m\in M_{n,H}}|P_nQ_m-Q_nP_m|
   \ge 3n-6H+o(n).
   \]
   
   In particular every \(H=o(n)\) window has logarithmic height \(3n+o(n)\) before any selective information is used. Dividing this universal factor out removes the only guaranteed \(p\)-adic factor at the corresponding targets.

2. **Saturate the recurrence lattice.** Put
   
   \[
   R_m=P_m/6=d_m^3(a_m/6),
   \qquad W_m=(R_m,Q_m)^T\in\mathbf Z^2.
   \]
   
   Then
   
   \[
   W_0=(0,1)^T,
   \qquad W_1=(1,5)^T,
   \qquad \det(W_0,W_1)=-1.
   \]
   
   Thus the distinguished initial orbit already spans the whole lattice \(\mathbf Z^2\). Consequently
   
   \[
   \boxed{
   \gcd_{m\ge0}\frac{P_nQ_m-Q_nP_m}{6}
   =\gcd(P_n/6,Q_n).}
   \]
   
   The same equality already holds using only \(m=0,1\). Since
   
   \[
   \frac{\gcd(P_n,Q_n)}{\gcd(P_n/6,Q_n)}\mid6,
   \]
   
   the primitive all-Casoratian gcd has exactly the same \(p\)-adic valuation as \(G_n\) for every \(p\ge5\), and
   
   \[
   \log\gcd(P_n/6,Q_n)=\log G_n+O(1).
   \]

Therefore the strongest possible Smith/Fitting saturation of Route A returns the original problem, not a smaller certificate. A growing defect dimension cannot beat the height/selectivity tradeoff because the underlying recurrence module has rank two and its full integral orbit lattice is already generated by the first two states. Exterior powers above two vanish, and marked subresultants reduce to the same determinant ideal.

The conclusion is not that a subexponential primitive gcd is impossible: proving it is exactly P3.2. The conclusion is that **growing Route A supplies no independent mechanism for proving it**. Near-\(n\) windows have a linear universal factor; full saturation removes that factor but contracts exactly to \(G_n\) away from \(2,3\).

# 4. Exact Smith formula for an arbitrary finite family

Let \(M\subset\{0,\ldots,n-1\}\) be finite and suppose the lattice

\[
L_M=\sum_{m\in M}\mathbf ZW_m
\tag{4.1}
\]

\[
s_1\mid s_2.
\tag{4.2}
\]

Thus there is \(U\in\operatorname {GL}_2(\mathbf Z)\) such that, after integral column operations, the generators of \(UL_M\) are

\[
s_1e_1,
\qquad s_2e_2.
\tag{4.3}
\]

Since \(U\) is unimodular,

\[
\gcd((UW_n)_1,(UW_n)_2)=g_n.
\tag{4.4}
\]

Write

\[
UW_n=g_n(x,y)^T,
\qquad \gcd(x,y)=1.
\tag{4.5}
\]

Define

\[
\Gamma_n(M)=\gcd_{m\in M}C_{n,m}.
\tag{4.6}
\]

Then

\[
\boxed{
\Gamma_n(M)
=g_n\gcd(s_1y,s_2x)
=g_ns_1\gcd\!\left(y,\frac{s_2}{s_1}\right).}
\tag{4.7}
\]

Indeed, after Smith reduction the determinant ideal is generated by

\[
\det(g_n(x,y),s_1e_1)=-g_ns_1y,
\tag{4.8}
\]

and

\[
\det(g_n(x,y),s_2e_2)=g_ns_2x.
\tag{4.9}

Because \(\gcd(x,y)=1\), (4.7) follows.

This formula separates the two factors exactly:

- \(g_n\) is the distinguished-state primitive gcd, equivalent to \(G_n\) away from \(2,3\);
- \(s_1\gcd(y,s_2/s_1)\) is lattice-index contamination.

Saturating \(L_M\) to \(\mathbf Z^2\) sets \(s_1=s_2=1\) and returns exactly \(g_n\). Increasing \(|M|\) can reduce the Smith contamination, but it cannot reduce the distinguished factor \(g_n\). Once the contamination is gone, Route A is precisely the original gcd problem.

If \(L_M\) has rank one, the construction contains only one endpoint functional and has even less elimination power; no second Smith invariant exists.

# 9. Why more exterior powers do not create more defect dimension

The recurrence state module has rank two. The vectors \(W_m\) lie in \(\mathbf Z^2\). Therefore

\[
\bigwedge^2\mathbf Z^2\cong\mathbf Z,
\qquad
\bigwedge^k\mathbf Z^2=0\quad(k\ge3).
\tag{9.1}
\]

Every nonzero exterior invariant involving the distinguished state and recurrence states is an integral combination of the pairwise determinants \(C_{n,m}\). There is no growing exterior defect space.

The distinguished initial state does not increase the rank. On the contrary, \(W_0,W_1\) already form a unimodular frame, so adding it performs the full saturation immediately and yields \(g_n\).

For a \(2\times |M|\) state matrix, the only nontrivial determinantal divisors are:

- the gcd of entries;
- the gcd of \(2\times2\) minors.

There is no higher Fitting layer. Increasing \(|M|\) changes the generators of the same rank-two lattice and can reduce its Smith index, but after the index is removed the fixed-vector determinant ideal is (3.3).

1. **Keep the marked index.** A marked subresultant or Fitting generator is in the determinant ideal generated by the \(C_{n,m}\). Full saturation returns \(g_n\), by Theorem 3.1.

A subresultant that retains the marked evaluation simply returns to case 1. A resultant that removes it loses selectivity. Growing order does not produce a third option.

# 11. Adaptive sparse families

An adaptive choice also splits into the same two regimes.

- If every chosen \(m\) remains \(n-o(n)\), the universal sixth-power primorial from Section 6 survives.
- If one inserts an index \(m\le n/2+o(n)\), the universal top-half factor can disappear, but the corresponding continuant has height \(\exp(\Omega(n\log n))\), and the individual cross-Casoratian still has height \(\exp(\Omega(n))\).
- If enough indices are inserted to saturate the state lattice, the primitive gcd is exactly \(g_n\).
- If the family is chosen using knowledge of the target primes, the construction is circular: it has encoded the unknown support in the choice of rows.

For a product rather than a gcd, assigning a different witness row to each target does not compress height. Each retained target contributes at least its own \(\log p\), and the long-continuant witnesses contribute much more. For a gcd, every selected normalized row must retain every target simultaneously; a single row in the \(m\ge p\) regime can lose \(p\) after universal normalization.

Thus adaptivity does not beat the exact rank-two saturation unless it imports a new Apéry-specific cross-prime theorem.

# Final conclusion

The growing-window idea closes cleanly.

- A window \(m\in[n-H,n]\) with \(H=o(n)\) is impossible as a low-height raw carrier: it contains a universal sixth-power primorial of logarithmic size \(3n+o(n)\).
- Dividing that content out loses the target prime because the large-prime target depth is at most six and the target does not force the residual continuant to vanish.
- Allowing a sparse family reaching back to \(n/2\) removes the universal layer but produces huge individual continuants. Taking their gcd can indeed collapse dramatically, but full Smith saturation proves that the collapsed primitive object is exactly \(\gcd(P_n/6,Q_n)\), hence \(G_n\) away from \(2,3\).
- There is no growing exterior or Fitting defect dimension: the state module is rank two and \(W_0,W_1\) are already a unimodular frame.

Thus the strongest rigorous verdict is:

\[
\boxed{
\text{Growing Route A is either universally large or exactly P3.2 after saturation.}}
\]

A genuine advance must prove an Apéry-specific block-compression or cross-prime cancellation theorem that is not encoded in the rank-two Casoratian lattice.
