L_n=\operatorname{lcm}(1,\dots,n),\qquad d_n=L_n^3.

For the Apéry companion use the standard two solutions of

(n+1)^3u_{n+1}

(b_0,b_1)=(1,5),\qquad (a_0,a_1)=(0,6).

The classical denominator clearing gives

\[
X_n:=d_na_n\in\mathbf Z,

Y_n:=d_nb_n\in\mathbf Z.

Let

\[
\mathcal T_n
 =\{p:\ p\ge7,\ n/2<p<n,\ p\mid b_n\},

W_n^{\rm top}=\sum_{p\in\mathcal T_n}\log p.

For `p in T_n` write

\[
t=t_p=v_p(b_n)\ge1,

Since `n/2<p<n`, one has exactly

v_p(L_n)=1,\qquad v_p(d_n)=3.

\[
d_n=p^3U_{n,p},\qquad U_{n,p}\in\mathbf Z_p^\times.

The supplied local amplification

v_p(5p^3a_n-6b_n)\ge e
\tag{1}

is equivalent, after multiplication by the `p`-adic unit `U_{n,p}`, to

\boxed{
 v_p(5X_n-6U_{n,p}b_n)\ge e.

\tag{2}

This has an immediate exact consequence for the cleared companion numerator.

### Lemma 1 — capped numerator valuation

For every `p in T_n`,

\[
\boxed{
 \min(v_p(X_n),3)=\min(t_p,3).
}
\tag{3}
\]

More explicitly,

\[
t=1\Longrightarrow v_p(X_n)=1,
\]

\[
t=2\Longrightarrow v_p(X_n)=2,

and

\[
t\ge3\Longrightarrow v_p(X_n)\ge3.
\]

**Proof.**  In (2), `6U_{n,p}` is a unit.  If `t=1`, the right-hand term has valuation one whereas the difference has valuation at least two; therefore `5X_n` has valuation exactly one.  The `t=2` case is identical with depth three.  If `t>=3`, both `6U b_n` and the difference are divisible by `p^3`, so `X_n` is divisible by `p^3`.  This proves (3).  `□`

The genuinely amplified *p-specific* integer is

\[
K_{n,p}

 =p^3(5X_n-6U_{n,p}b_n),

so

\boxed{
 v_p(K_{n,p})\ge3+e_p.
}
\tag{4}

Thus a single target prime gives depth at least five.  The only issue is that the coefficient `p^3` changes with `p`.

# 2. The varying `p^3` is not a loophole

Try to replace the prime-dependent scalar by one global integer `c_n` and form

\[
H_n(c)
 :=d_n(5c_na_n-6b_n)
 =5c_nX_n-6p^3U_{n,p}b_n.
\tag{5}
\]

This is the smallest possible mixed construction containing the local scalar.

There are two useful versions of the obstruction.

## 2.1 Merely asking for one excess depth

Suppose the desired local conclusion is only

\[
v_p(H_n(c))\ge4,
\tag{6}
\]

i.e. one depth beyond the universal top-window `d_n` depth three.

A proof based only on (1)--(3) must work in the worst allowed case

\[
v_p(X_n)=\min(t,3).
\]

The `b`-term in (5) has valuation exactly

\[
3+t\ge4.
\]

If

\[
v_p(c_n)+\min(t,3)<4,
\]

then the first term in (5) has strictly smaller valuation than the second, so no cancellation is possible and (6) fails.  Therefore a robust certificate must satisfy

\[
\boxed{
 v_p(c_n)\ge4-\min(t_p,3).
}
\tag{7}
\]

Thus

```text
t_p = 1  =>  p^3 | c_n
t_p = 2  =>  p^2 | c_n
t_p >= 3 =>  p   | c_n.
```

If

\[
W_j(n)=\sum_{\substack{p\in\mathcal T_n\\t_p=j}}\log p,
\qquad
W_{\ge3}(n)=\sum_{\substack{p\in\mathcal T_n\\t_p\ge3}}\log p,
\]

then any nonzero such `c_n` obeys the exact height charge

\[
\boxed{
 \log|c_n|
 \ge 3W_1(n)+2W_2(n)+W_{\ge3}(n)
 \ge W_n^{\rm top}.
}
\tag{8}
\]

So even for **one** excess depth, every target prime has to appear in the global scalar at least once.

This conclusion is robust: it uses only the guaranteed local filtration and does not assume accidental extra divisibility of `X_n` at a particular `n`.

## 2.2 Transporting the full local amplification

Now require the global form to inherit the actual strength of (4):

\[
v_p(H_n(c))\ge3+e_p.
\tag{9}
\]

Before any cancellation can raise the valuation, the first term must reach the lower of the desired depth and the `b`-term depth.  Hence necessarily

\[
v_p(c_n)+\min(t,3)
 \ge \min(3+e,3+t).
\]

For all three cases `t=1`, `t=2`, `t>=3`, the right side minus `min(t,3)` is exactly three.  Therefore

\[
\boxed{
 p^3\mid c_n
 \quad\text{for every }p\in\mathcal T_n.
}
\tag{10}
\]

If

\[
P_n:=\prod_{p\in\mathcal T_n}p,
\]

then

\[
\boxed{
 P_n^3\mid c_n,
 \qquad
 \log|c_n|\ge3W_n^{\rm top}.
}
\tag{11}
\]

This is the cleanest answer to the moving-`p^3` issue.  A single global scalar can imitate all the local scalars only by carrying all target primes cubically.

For the common cases `t=1` and `t=2` one can say more.  Write

\[
c_n=p^3\gamma_{n,p}.
\]

Then

\[
H_n(c)=p^3(5\gamma_{n,p}X_n-6U_{n,p}b_n).
\]

Using (2),

\[
5\gamma X-6Ub
 =\gamma(5X-6Ub)+6(\gamma-1)Ub.
\]

Since `e=t+1` for `t=1,2`, attaining the full depth forces

\[
\boxed{
 \gamma_{n,p}\equiv1\pmod p,
}
\]

or equivalently

\[
\boxed{
 c_n\equiv p^3\pmod{p^4}
 \qquad (t_p=1\text{ or }2).
}
\tag{12}
\]

Thus the exact CRT problem is even sharper than `P_n^3 | c_n`; but (11) is already enough for the height obstruction.

### Two instructive substitutions

1. `c_n=n^3` does **not** globalize the local scalar.  Since `p<n<2p`, `p` does not divide `n`, so `v_p(n^3)=0`.  For a target with `t=1`, the first term in (5) has valuation one while the second has valuation four, hence

\[
v_p(H_n(n^3))=1.
\]

2. `c_n=d_n=L_n^3` does have `v_p(c_n)=3` for every top-window prime, so it guarantees an excess depth.  But it pays

\[
\log c_n=3\psi(n)=3n+o(n),
\]

where `psi` is Chebyshev's function, before the Apéry values themselves are counted.  Moreover `c_n/p^3=U_{n,p}` need not be `1 mod p`, so it does not automatically reproduce the extra cancellation in (12).

# 3. Archimedean height of ordinary mixed forms

Let

\[
\alpha=17+12\sqrt2=(1+\sqrt2)^4.
\]

The Apéry recurrence has dominant characteristic root `alpha`, and the positive solution satisfies

\[
\log b_n=n\log\alpha+O(\log n).
\tag{13}
\]

Also `a_n/b_n -> zeta(3)`, hence

\[
\log|a_n|=n\log\alpha+O(\log n).
\tag{14}
\]

The lcm normalization has

\[
\log d_n=3\psi(n)=3n+o(n).
\tag{15}
\]

Therefore the two obvious integral channels have linear height:

\[
\boxed{
 \log|d_nb_n|
 =(3+\log\alpha)n+o(n),
}
\tag{16}
\]

and the same exponential scale holds for `d_n a_n` up to the denominator-defect content.

In particular, choosing `c_n=0` in (5) is not a loophole.  It gives

\[
H_n(0)=-6d_nb_n,
\]

which certainly has every target prime to depth `3+t_p`, but

\[
\boxed{
 \log|H_n(0)|
 =(3+\log\alpha)n+o(n),
}
\tag{17}
\]

not `o(n)`.

If `c_n` is any nonzero fixed-degree polynomial in `n`, then

\[
5c_na_n-6b_n
 =b_n\left(5c_n\frac{a_n}{b_n}-6\right).
\]

If `deg c_n>0`, the parenthesis has polynomial size.  If `c_n` is constant and nonzero, its limit is `5c zeta(3)-6`, which is nonzero because `zeta(3)` is irrational.  Hence

\[
\boxed{
 \log|H_n(c)|
 =(3+\log\alpha)n+O(\log n)
}
\tag{18}
\]

for every nonzero fixed polynomial scalar.  A fixed rational function is the same after clearing its fixed polynomial denominator.

Factorials are worse:

\[
\boxed{
 \log(n!)=n\log n-n+O(\log n).
}
\tag{19}
\]

Thus any uncancelled positive factorial power is immediately incompatible with `log|H_n|=o(n)`, and any uncancelled positive lcm power already costs `Theta(n)`.  If such factors cancel exactly in a determinant, they are **universal normalization** and must be removed before one claims target-specific excess depth.

# 4. The determinant escape attempt: exact Wronskian audit

Determinants are the natural way to cancel the common exponential growth of `a_n` and `b_n`.  Here the cancellation is completely explicit and shows the other side of the obstruction.

Define

\[
W_n=a_nb_{n-1}-a_{n-1}b_n.
\]

The recurrence gives

\[
W_{n+1}=\frac{n^3}{(n+1)^3}W_n,
\]

and `W_1=6`.  Hence

\[
\boxed{
 a_nb_{n-1}-a_{n-1}b_n=\frac6{n^3}.
}
\tag{20}
\]

The minimally cleared integral determinant is therefore

\[
\boxed{
 n^3W_n=6.
}
\tag{21}
\]

For every target `p>=7`, `p` does not divide this integer.  So the determinant has perfect archimedean cancellation and **zero target depth**.

If instead one clears both columns by the universal lcm envelope, one gets

\[
d_n^2W_n=\frac{6d_n^2}{n^3}.
\]

For `n/2<p<n`, `p` does not divide `n`, so

\[
\boxed{
 v_p(d_n^2W_n)=6.
}
\tag{22}
\]

But six is exactly the universal depth contributed by the two factors of `d_n`; the excess depth is zero.  Its archimedean height is

\[
\boxed{
 \log\left|\frac{6d_n^2}{n^3}\right|
 =6\psi(n)-3\log n+O(1)
 =6n+o(n).
}
\tag{23}
\]

Thus the two normalizations display the whole tradeoff:

```text
minimal primitive determinant:  H_n = 6,      height O(1), target depth 0;
lcm-cleared determinant:        H_n = 6d_n^2/n^3, height 6n+o(n), excess depth 0.
```

There is no hidden target mass in the Wronskian.

# 5. All fixed-width polynomial-coefficient rank-two mixed jets

The previous calculation is not special to adjacent indices.

Let

\[
R_m=(a_m,b_m).
\]

Fix a width `J`.  By the second-order recurrence, for each fixed `j` there are rational functions `u_j(n),v_j(n) in Q(n)`, of degrees and denominator degrees bounded in terms of `J` only, such that

\[
R_{n+j}=u_j(n)R_n+v_j(n)R_{n-1}.
\tag{24}
\]

Now take any two fixed-width polynomial-coefficient mixed jets

\[
J_i(n)=\sum_{|j|\le J}P_{ij}(n)R_{n+j},
\qquad i=1,2,
\]

where the degrees of the `P_ij` are fixed independently of `n`.  Equation (24) gives

\[
\begin{pmatrix}J_1(n)\\J_2(n)\end{pmatrix}
 =C(n)
 \begin{pmatrix}R_n\\R_{n-1}\end{pmatrix}
\]

for a `2 x 2` rational-function matrix `C(n)` of bounded degree.  Therefore

\[
\boxed{
 \det(J_1(n),J_2(n))
 =\det C(n)\,\frac6{n^3}.
}
\tag{25}
\]

After clearing the fixed rational-function denominator and removing common content, the primitive determinant is a fixed polynomial/rational function of `n`; consequently

\[
\boxed{
 h\bigl(\det(J_1,J_2)_{\rm prim}\bigr)=O_J(\log n).
}
\tag{26}
\]

For a regular top-window prime (one not hitting one of the finitely many fixed shift denominators), the factor `6/n^3` is a `p`-adic unit.  Hence any target-specific positive valuation of the primitive determinant must come from the numerator of `det C(n)`.

So if such a fixed jet determinant were divisible by **every** regular top target prime, then

\[
\prod_{p\in\mathcal T_n^{\rm reg}}p
 \mid \operatorname{num}(\det C(n)),
\]

and therefore

\[
\boxed{
 \sum_{p\in\mathcal T_n^{\rm reg}}\log p=O_J(\log n).
}
\tag{27}
\]

This would be much stronger than the desired `o(n)` estimate.  But it is not a consequence of the known `p^3` local relation: it would be a **new polynomial carrier identity**.

The shift-singular primes do not invalidate the conclusion.  With `J` fixed, a denominator can meet a top prime only through one of finitely many equations such as `n+j=p`; there are `O_J(1)` such candidates, contributing only `O_J(log n)` logarithmic mass.

Thus fixed shifts plus determinants do not manufacture a free carrier.  They reduce the problem to proving a new divisibility theorem for a fixed polynomial numerator.

# 6. General finite-witness height-per-depth lemma

The preceding rank-two calculation has a convenient abstract form that also covers fixed-rank Pluecker expansions.

### Lemma 2 — finite witness product bound

For each `n`, let

\[
c_{n,1},\dots,c_{n,M}\in\mathbf Z
\]

be a fixed finite family, with `M` independent of `n`.  Suppose that after all exact target-independent identities and universal normalization factors have been saturated, every target prime `p in T_n` for which a residual depth `q_p>=1` is claimed forces at least one **nonzero** witness to satisfy

\[
v_p(c_{n,j})\ge q_p.
\]

Then

\[
\boxed{
 \sum_{p\in\mathcal T_n}q_p\log p
 \le
 \sum_{j:c_{n,j}\ne0}\log|c_{n,j}|.
}
\tag{28}
\]

**Proof.**  Put

\[
C_n=\prod_{j:c_{n,j}\ne0}|c_{n,j}|.
\]

For every target `p`, the hypothesis gives `v_p(C_n)>=q_p`.  Therefore

\[
\prod_{p\in\mathcal T_n}p^{q_p}\mid C_n,
\]

and taking logarithms gives (28).  `□`

If all witnesses are values of fixed-degree integer polynomials (or primitive numerators of fixed-degree rational functions), then

\[
\sum_j\log|c_{n,j}|=O(\log n).
\tag{29}
\]

If they contain uncancelled powers of `L_n` or `n!`, their heights contain the explicit costs (15) or (19).  There is no intermediate free regime.

The caveat “nonzero witness” is essential.  If the local rank drop makes a Pluecker coordinate identically zero, that coordinate belongs to the **automatic identity ideal**.  It must first be saturated out; zero cannot be used as a finite-height integer certificate.

# 7. Fixed-rank polynomial-coefficient mixed jets and determinants

Here is the precise broad class to which I would apply Lemma 2.

Fix integers `R,J,D` independently of `n`.  Consider a rank-`R` rational difference module (possibly an upper-triangular normal-function extension of the Apéry rank-two module) with fundamental matrix `F_n` satisfying

\[
F_{n+1}=T(n)F_n,
\qquad
T(n)\in\operatorname{GL}_R(\mathbf Q(n)),
\tag{30}
\]

where numerator and denominator degrees of `T` are fixed.  Allow:

- shifts `F_{n+j}`, `|j|<=J`;
- left/right multiplication by matrices whose entries are rational functions of degree at most `D`;
- a fixed number of sums, products and exterior powers;
- determinants/minors of fixed order;
- fixed powers of factorial/lcm denominator-clearing factors, provided their local valuation is declared **universal** and subtracted before claiming target excess.

Every shifted fundamental matrix is

\[
F_{n+j}=T_j(n)F_n
\]

with `T_j(n)` a bounded-degree rational matrix.  Hence every full-rank mixed jet determinant has the exact factorization

\[
\boxed{
 \det J_n=\det C_n\,\det F_n,
}
\tag{31}
\]

where `C_n` is a bounded-degree rational matrix.

For lower minors, Cauchy--Binet expresses the result as a sum over only

\[
M=M(R,k)
\]

Pluecker coordinates, with `M` fixed.  After saturating exact identities, those coefficient minors are exactly the finite witnesses of Lemma 2.

The fundamental Casoratian satisfies

\[
\boxed{
 \det F_n
 =\det F_{n_0}\prod_{m=n_0}^{n-1}\det T(m).
}
\tag{32}
\]

If

\[
\det T(x)=\frac{P(x)}{Q(x)},
\qquad
\deg P=d_P,\quad \deg Q=d_Q,
\]

then, away from finitely many initial zeros/poles,

\[
\sum_{m<n}\log|\det T(m)|
 =(d_P-d_Q)n\log n
 +\bigl(\log|\operatorname{lc}(P)/\operatorname{lc}(Q)|
       -(d_P-d_Q)\bigr)n
 +O(\log n).
\tag{33}
\]

This follows directly from

\[
\sum_{m<n}\log m=\log(n!)
 =n\log n-n+O(\log n)
\]

and the expansion `log|P(m)|=d_P log m+log|lc(P)|+O(1/m)`.

Consequently a fixed-rank Casoratian has only two relevant possibilities after primitive denominator clearing:

1. it retains an `n log n` or linear-`n` archimedean term, in which case it cannot be the requested `o(n)` certificate; or
2. those universal terms cancel, leaving a polynomial-height primitive factor.  Then any target-specific excess valuation must be carried by a fixed polynomial/Pluecker witness, and Lemma 2 applies.

For the actual Apéry rank-two module, (32) is exactly (20), so the primitive Casoratian is the constant `6`.

This is the promised fixed-rank no-go scope.  It includes all fixed-width polynomial-coefficient mixed jets of the two Apéry solutions, their full determinants, and the corresponding constructions inside any fixed-rank rational difference extension whose target divisibility is proved solely from the current rank-one local law.

# 8. Why the endpoint/cubic rank-one extensions do not yet escape

The current committed endpoint audit records, modulo `p^4`, a rank-one endpoint defect of the form

\[
b_{mp}-b_m
 \equiv
 p^3e_p\,
 \frac{m^3(b_{m-1}-17b_m)}{12}
 \pmod{p^4},
\]

with the reflected companion carrying the same scalar, and

\[
e_p\equiv \frac23 B_{p-3}\pmod p.
\]

The cubic target audit similarly writes the target block in a fixed cubic jet plus a `p^3` companion term.  This is valuable local structure, but from the certificate point of view it is still **rank one**: the new rows share one local scalar rather than supplying an independent target-sensitive direction.

Taking a determinant of several such rows therefore has only two outcomes.

- If the determinant vanishes because all rows have collapsed to the same rank-one local direction, that vanishing belongs to the automatic rank-drop/Pluecker ideal.  After primitive saturation, it contributes only the fixed Casoratian/universal factor.
- If one perturbs the determinant so that it is nonzero in the quotient, one of finitely many Pluecker coefficients has to encode the local alignment.  The moving `p^3` then forces prime powers into those coefficients, and Lemma 2 charges their height.

A rank-one extension is therefore not enough merely because its local congruence is deeper.  What is needed is a new **primitive** minor with target divisibility after all automatic rank-one factors have been removed.

# 9. Explicit failure modes of the obvious certificate constructions

## 9.1 The direct companion numerator

`X_n=d_na_n` already has

\[
\min(v_p(X_n),3)=\min(v_p(b_n),3)
\]

at every top target.  So it is a perfectly real local carrier.  But it is the denominator-overclearance carrier itself: in lowest terms `a_n=A_n/D_n`,

\[
d_na_n=\frac{d_n}{D_n}A_n.
\]

Thus using its target content as the certificate simply repackages the denominator defect.  Its archimedean scale is linear, not `o(n)`.

## 9.2 The common `b_n` channel

`d_nb_n` has depth `3+t_p` at every target, but (16) gives linear height.

## 9.3 Replacing `p^3` by `n^3`

Fails locally: for `t=1`, its valuation is only one, as shown above.

## 9.4 Replacing `p^3` by `L_n^3`

Succeeds in putting `p^3` into the coefficient for every top prime, but pays `3n+o(n)` coefficient height before the Apéry growth; it also misses the residue condition (12) needed for the full amplified cancellation.

## 9.5 Adjacent or fixed-shift determinants

The adjacent determinant is exactly `6/n^3`; the minimally integral value is `6`.  All fixed-width mixed determinants factor as (25).  Any target divisibility left after primitive saturation is therefore a new fixed polynomial divisibility statement, not a consequence of the known local amplification.

## 9.6 Products of the `p`-specific local certificates

One could formally take a product over target primes of `K_{n,p}`.  This is excluded for the right reason: the construction needs the target set itself.  It is an equivalent target-prime scan/gcd carrier, and its integer height already contains

\[
\sum_{p\in\mathcal T_n}(3+e_p)\log p.
\]

Nothing has been compressed.

# 10. What the no-go does and does not prove

It does **not** prove that no normal function can ever solve Problem 3.2.  Such a theorem would be far too strong.

It proves that the current local scalar cannot be turned into a free global certificate by any construction whose target sensitivity enters only through a fixed finite coefficient tensor/Pluecker tensor.

The essential dichotomy is:

```text
ordinary/deep target channel
    -> target primes divide automatically
    -> archimedean size is exp(c n) (or worse);

alternating determinant / balanced jet
    -> archimedean exponential growth cancels
    -> primitive value is Casoratian/Pluecker-polynomial height
    -> known target divisibility cancels with the universal factor;

force local p^3 alignment back into a nonzero primitive determinant
    -> coefficient/Pluecker witnesses absorb the target primes
    -> height-per-depth payback (28), and p^3 alignment gives (11).
```

The fact that the scalar is `p^3` with `p` varying is therefore not a technical annoyance that a fixed-rank determinant can average away.  At the exact depths being used, it is a local basis scaling, and globalizing that scaling requires the corresponding coefficient minors to carry those prime powers.

# 11. The one mathematically precise surviving interface

A new fixed-rank normal-function route remains alive only if it produces an object outside the robust-certificate class above.

The clean target is the following.

Construct a fixed-rank integral extension `M` and, for each `n`, a **primitive** nonzero integer minor/regulator

\[
\mathcal R_n\in\mathbf Z\setminus\{0\}
\]

with a declared universal normalization depth `u_{n,p}`, such that:

\[
\boxed{
 p\mid b_n,\quad n/2<p<n
 \Longrightarrow
 v_p(\mathcal R_n)\ge u_{n,p}+1,
}
\tag{34}
\]

and

\[
\boxed{
 \log|\mathcal R_n|=o(n).
}
\tag{35}
\]

But two extra non-circularity conditions are essential:

1. after quotienting by all exact Casoratian/Pluecker/rank-one identities, `R_n` must remain nonzero; its extra `p` must not come from a universal lcm/factorial factor;
2. the implication (34) must arise from the **integral value of the extension class** (equivalently, from a new target-sensitive primitive minor), not from choosing a coefficient tensor that satisfies `p`-dependent congruences.  Otherwise Lemma 2 applies and the target mass reappears in the coefficient height.

For a first-order system this can be audited concretely.  Let `F_n` be a fundamental matrix and let `W_n^prim` be the primitive part of its Casoratian after all universal factorial/lcm factors are removed.  A surviving extension must satisfy, for a new minor `M_n^prim`,

```text
M_n^prim != 0,
log |M_n^prim| = o(n),
for every top target p:  p | M_n^prim,
and M_n^prim is not a fixed polynomial coefficient/Pluecker witness.
```

Equivalently, the first target-sensitive graded piece of the local extension must contain a `p`-adic **unit** coefficient multiplying the target condition; if its first nonzero graded coefficient is again `p^3` times a rank-one direction, the obstruction above repeats verbatim.

That is the precise remaining interface I would send back to the normal-function/p-adic side: **find a primitive target-sensitive Casoratian/minor with unit leading local coefficient and sublinear global height.**  The present rank-one endpoint Bernoulli scalar and cubic jets do not yet provide it.

# 12. Bottom line

The moving scalar can be audited exactly:

\[
K_{n,p}=d_n(5p^3a_n-6b_n),
\qquad
v_p(K_{n,p})\ge3+\min(t_p+1,3).
\]

For a single global replacement `c_n`, even one robust excess depth forces

\[
\log|c_n|
\ge3W_1+2W_2+W_{\ge3}
\ge W_n^{\rm top},
\]

while transporting the full local amplification forces

\[
P_n^3\mid c_n,
\qquad
\log|c_n|\ge3W_n^{\rm top},
\]

and for `t_p=1,2` even

\[
c_n\equiv p^3\pmod{p^4}.
\]

Ordinary `b_n`-type channels have height

\[
(3+\log(17+12\sqrt2))n+o(n),
\]

uncancelled lcm powers cost `Theta(n)`, and factorial powers cost `Theta(n log n)`.

Determinants can remove that exponential growth, but the exact Apéry Wronskian is

\[
a_nb_{n-1}-a_{n-1}b_n=6/n^3,
\]

so the primitive determinant is `6` and has no target prime.  Every fixed-width rank-two mixed determinant is `6/n^3` times a bounded-degree rational coefficient determinant.  The fixed-rank version is the same statement with Casoratians and finitely many Pluecker witnesses.

So the current local amplification does **not** furnish the requested `H_n`.  The viable next object is much narrower than “another jet”: it must be a new primitive normal-function minor whose target prime occurs in the extension value with a unit local coefficient and whose archimedean height is independently `o(n)`.  Anything still expressing target sensitivity by fixed-rank polynomial coefficient alignment falls under the height-per-depth payback above.
