# Independent audit of `[REG-RAD-8/3]`

## Verdict: REPAIRABLE

The literal proof quoted in the question is not valid as written. The raw quantity

```text
k_x(D) = #{2 <= h <= D : N_h(x)=0}
```

cannot be treated uniformly over every `x in Fbar_p` by the short-gap argument: at a cut column the recurrence can acquire two consecutive zero levels and then an entire linear tail of zeros. The tracked examples include

```text
p=73,   x=-3:  N_h(-3)=0 for every h>=3,
p=3331, x=-8:  N_h(-8)=0 for every h>=8.
```

Thus the restart injection used for consecutive zero levels is available only on a clock-regular interval. The displayed raw maximum is not proved by the proposed argument and would require additional arithmetic information about how early polluted cuts can occur.

The main radical-gcd conclusion **does survive** after a precise repair. There are two valid formulations.

1. **Global `D`-saturation.** Saturate every pair by the full divisor

```text
C_D(X)=product_{j=2}^D (X+j).
```

Then

```text
sum_{a,g>=2, a+g<=D}
  deg rad( gcd(N_a(X),N_g(X+a)) : C_D^infinity )
  << D^(8/3).
```

2. **Natural pair-local saturation.** For `e=a+g`, saturate the pair only by

```text
C_e(X)=product_{j=2}^e (X+j).
```

Then the same `D^(8/3)` bound holds, but the correct column count is cut-dependent:

```text
H_x(D) = D,                    if x is not -m with 2<=m<=D,
         m-1,                  if x=-m with 2<=m<=D,

k_x^reg(D)=#{2<=h<=H_x(D):N_h(x)=0}.
```

With this definition there is an exact identity

```text
sum_{a,g>=2, a+g<=D}
  deg rad( gcd(N_a(X),N_g(X+a)) : C_{a+g}^infinity )
 = sum_{x in Fbar_p} binom(k_x^reg(D),2),             (A)
```

and the right side is `O(D^(8/3))`.

The result is unconditional under the exact hypotheses

```text
p >= 7 prime,
2 <= D < p.
```

Leading-coefficient degree loss is harmless for this affine radical theorem. Zero-polynomial reduction is not harmless, but it cannot occur in the stated range. The restriction in height is load-bearing: outside it, zero-polynomial degenerations really occur, for example `N_21=0` over `F_7`.

The remainder of this report proves these assertions and records the required qualifications.

## 1. Setup

Work over

```text
k = Fbar_p
```

with `p>=7`. Reduce the integer continuants modulo `p`:

```text
N_0(X)=0,
N_1(X)=1,
N_2(X)=P(X+1),
N_{h+1}(X)=P(X+h)N_h(X)-(X+h)^6N_{h-1}(X),
P(u)=34u^3+51u^2+27u+5.
```

Over `Z[X]`,

```text
deg N_h = 3(h-1).
```

After reduction modulo `p`, the actual degree may be lower. All degree bounds below use only

```text
deg_k N_h <= 3(h-1).                                (1.1)
```

For `a,g>=2`, put `e=a+g` and

```text
F_{a,g}(X)=gcd_k[X](N_a(X),N_g(X+a)).
```

For a polynomial `C`, write

```text
F:C^infinity
```

for the factor of `F` obtained after deleting every irreducible factor shared with `C`. Since `k` is algebraically closed, the degree of the radical of this saturated gcd is exactly the number of distinct common affine roots outside `C=0`.

The affine theorem does not use nominal homogenizations or raw resultants. Therefore an intersection at projective infinity caused by leading-coefficient loss is absent automatically. If one insists on a homogeneous/resultant formulation, the maximal common `Z`-power must be divided out first.

## 2. Nonzero-polynomial lemma in the required range

### Lemma 2.1

For every prime `p>=7` and every `2<=h<p`, the reduction of `N_h` modulo `p` is not the zero polynomial.

### Proof

The repository's endpoint evaluations are

```text
N_h(-1) = ((h-1)!)^3 b_{h-1},
N_h(-2) = -5 ((h-2)!)^3 b_{h-2},                    (2.1)
```

up to the harmless recorded sign convention. Since `h<p`, both factorials and `5` are units modulo `p`. If `N_h` were identically zero, (2.1) would give

```text
b_{h-1}=b_{h-2}=0 mod p.
```

The Apéry recurrence/no-consecutive-zeros lemma forbids two consecutive zeros in the regular first block. Hence `N_h` is nonzero. QED.

### Consequence

For every `h<=D<p`, the set of distinct roots in `k` has size at most

```text
#roots_k(N_h) <= deg_k N_h <= 3(h-1).                (2.2)
```

This remains true when the leading coefficient vanishes modulo `p`. Degree loss only improves (2.2).

## 3. Where the raw maximum argument fails

The short-gap proof requires two facts at a lower zero level `r`:

```text
N_r(x)=0,
N_{r+1}(x)!=0.                                       (3.1)
```

At a cut value `x=-m`, the coefficient `(x+m)^6` vanishes. If also `p|b_{m-1}`, the endpoint factorization gives

```text
N_h(-m)=0 for every h>=m.                            (3.2)
```

Thus the zero-level gaps are repeatedly `1`, condition (3.1) fails, and no injection into roots of `N_1` or any short-gap polynomial exists.

The examples `p=73,m=3` and `p=3331,m=8` are exact instances of (3.2), recorded and checked in `meso_result.tex`, `energy_result.tex`, and `energy_verify.py`.

This does not by itself disprove the existence of some very large universal constant in a raw `O(D^(2/3))` maximum theorem; it shows that the proposed proof does not establish such a theorem and that a raw maximum would require new arithmetic excluding arbitrarily early polluted cuts. No such input is presently known or needed for the saturated result.

## 4. Regular columns have no adjacent zero levels

### Lemma 4.1

Let `2<=H<p`, and suppose

```text
x+j != 0 for every 2<=j<=H.                          (4.1)
```

Then the zero levels of the column

```text
{h:2<=h<=H, N_h(x)=0}
```

contain no consecutive integers.

### Proof

If `N_h(x)=N_{h+1}(x)=0`, the recurrence gives

```text
(x+h)^6 N_{h-1}(x)=0.
```

By (4.1), `x+h!=0`, so `N_{h-1}(x)=0`. Repeating descends to `N_1(x)=0`, contradicting `N_1=1`. QED.

The condition is exactly what pair-local cut saturation supplies up to the upper zero level.

## 5. Restart and the short-gap injection

### Lemma 5.1: exact restart

If

```text
N_r(x)=0,
N_{r+1}(x)!=0,
```

then for every `d>=0`,

```text
N_{r+d}(x)=N_{r+1}(x) N_d(x+r).                      (5.1)
```

### Proof

Divide the left side by the nonzero scalar `N_{r+1}(x)`. As a function of `d`, the quotient has initial values `0,1` and satisfies the same shifted recurrence as `N_d(x+r)`. QED.

This is a field argument and is valid over `Fbar_p`; no `F_p`-rationality of `x` is used.

### Lemma 5.2: injectivity for a fixed short gap

Assume `2<=H<=D<p` and (4.1). List the zero levels

```text
2<=h_1<...<h_t<=H.
```

For a fixed integer `d`, every consecutive pair

```text
h_{i+1}-h_i=d
```

maps to the root

```text
y_i=x+h_i
```

of `N_d`. These roots are distinct.

### Proof

By Lemma 4.1, `d>=2`. Since the pair is consecutive in the zero-level list, `N_{h_i+1}(x)!=0`; applying (5.1) gives

```text
0=N_{h_i+d}(x)=N_{h_i+1}(x)N_d(x+h_i),
```

so `N_d(y_i)=0`.

If `y_i=y_j`, then `h_i-h_j=0` in characteristic `p`. But

```text
0<|h_i-h_j|<D<p,
```

so this is impossible. QED.

This answers the first explicit question in the prompt: **yes**, the restart image is injective over `Fbar_p`, but only after restricting to a clock-regular interval. The hypothesis `D<p` is exactly what turns distinct integer levels into distinct translations in characteristic `p`.

## 6. Uniform regular-column bound

### Proposition 6.1

Under the hypotheses of Lemma 5.2,

```text
t <= 1 + floor((H-2)/(Y+1)) + 3Y(Y-1)/2            (6.1)
```

for every integer `2<=Y<H`. Consequently

```text
t << H^(2/3),                                        (6.2)
```

with an absolute constant.

### Proof

There are `t-1` consecutive zero-level gaps. A gap exceeding `Y` is at least `Y+1`, and their sum is at most

```text
h_t-h_1 <= H-2.
```

Hence there are at most `floor((H-2)/(Y+1))` long gaps.

For a fixed `2<=d<=Y`, Lemma 5.2 injects the consecutive gaps of length `d` into the distinct roots of the nonzero polynomial `N_d`. By (2.2), there are at most `3(d-1)` such gaps. Summing over `d` proves (6.1).

Choosing `Y` of order `H^(1/3)` proves (6.2). More precisely, the usual optimization gives

```text
t <= (3^(4/3)/2) H^(2/3)+O(H^(1/3)+1).              (6.3)
```

QED.

## 7. The exact radical-gcd/column-pair identity

This is the point at which Q6901 needs its main repair.

For `e>=2`, define the minimal full-interval cut divisor

```text
C_e(X)=product_{j=2}^e (X+j).                        (7.1)
```

The factor `X+1` may also be included for a physical-orbit convention; doing so only deletes extra roots and cannot worsen the estimate. Likewise one may use the broader boundary polynomial from Q6901.

For each `x in k`, define

```text
H_x(D)=
  m-1, if x=-m for some integer 2<=m<=D,
  D,   otherwise,                                    (7.2)

k_x^reg(D)=#{2<=h<=H_x(D):N_h(x)=0}.                 (7.3)
```

Because `D<p`, there is at most one such `m`.

### Lemma 7.1: root-level equivalence

Let `a,g>=2`, `e=a+g<=D`, and suppose `C_e(x)!=0`. Then

```text
N_a(x)=N_g(x+a)=0
  <=>
N_a(x)=N_e(x)=0.                                     (7.4)
```

### Proof

The addition law is

```text
N_e(X)
 =N_g(X+a)N_{a+1}(X)
 -(X+a+1)^6N_{g-1}(X+a+1)N_a(X).                    (7.5)
```

At a root of `N_a`, the second term vanishes. Also `N_{a+1}(x)!=0`: otherwise Lemma 4.1, applied on the interval through level `a+1`, would contradict `N_1=1`. Therefore

```text
N_e(x)=N_{a+1}(x)N_g(x+a),
```

with nonzero first factor, proving (7.4). QED.

### Proposition 7.2: exact identity

Define

```text
Gamma_p^loc(D)
 =sum_{a,g>=2, a+g<=D}
   deg rad( F_{a,g}:C_{a+g}^infinity ).              (7.6)
```

Then

```text
Gamma_p^loc(D)
 =sum_{x in k} binom(k_x^reg(D),2).                  (7.7)
```

### Proof

The radical degree in a summand of (7.6) is the number of distinct `x in k` satisfying the two equations and `C_e(x)!=0`. By Lemma 7.1 this is the number of regular pairs of zero levels

```text
a<e=a+g<=D
```

in one column.

If `x=-m` with `2<=m<=D`, then `C_e(x)!=0` is exactly the condition `e<m`, i.e. `e<=H_x(D)`. Otherwise all `e<=D` are regular. Hence the regular zero levels are precisely those counted by (7.3).

Lemma 4.1 excludes adjacent pairs, so every pair of distinct levels counted by `binom(k_x^reg,2)` has difference `g>=2`, and conversely every summand in (7.6) gives one such pair. Summing first over pairs or first over roots gives (7.7). Multiplicities cause no problem because both sides count each distinct algebraic root once; this is exactly why the radical is required. QED.

### Important qualifications

- The equality is over `Fbar_p`, not merely over `F_p`. If a common irreducible quadratic is nonsplit, its two conjugate roots contribute degree two to the left and two terms to the algebraic-root count on the right.
- If additional reflection-center factors are divided out, the result is no longer literally (7.7); it is bounded above by its right side. Reflection centers are genuine affine roots, not clock degeneracies.
- If every pair is instead saturated by `C_D`, then one may use the simpler count `k_x(D)` but only for `x` with `C_D(x)!=0`.

## 8. Proof of the repaired `D^(8/3)` theorem

### Theorem 8.1: local-saturation form

Let `p>=7` be prime and `2<=D<p`. Then

```text
Gamma_p^loc(D) << D^(8/3).                           (8.1)
```

The same bound holds after any further deletion of clock, projective-infinity, or chosen reflection factors.

### Proof

For each `x`, Proposition 6.1 applied with `H=H_x(D)` gives

```text
k_x^reg(D) << D^(2/3).                               (8.2)
```

The total distinct-root mass is bounded row by row:

```text
sum_x k_x^reg(D)
 <= sum_{h=2}^D #roots_k(N_h)
 <= sum_{h=2}^D 3(h-1)
 = 3D(D-1)/2.                                        (8.3)
```

Using (7.7),

```text
Gamma_p^loc(D)
 =sum_x binom(k_x^reg(D),2)
 <=(max_x(k_x^reg(D)-1)/2) sum_x k_x^reg(D)
 <<D^(2/3)D^2
 =D^(8/3).                                           (8.4)
```

QED.

### Corollary 8.2: global-saturation form

Let

```text
Gamma_p^glob(D)
 =sum_{a,g>=2,a+g<=D}
   deg rad(F_{a,g}:C_D^infinity).
```

Then

```text
Gamma_p^glob(D)<<D^(8/3).                            (8.5)
```

This is the formulation closest to the attempted proof in Q6901: replace its raw `max_x` by

```text
max_{x:C_D(x)!=0} k_x(D)<<D^(2/3).                   (8.6)
```

## 9. Cut, clock, leading coefficient, and reflection audit

### 9.1 Cut/clock factors

Saturating only by the lower-block divisor

```text
S_a(X)=product_{j=2}^a(X+j)
```

is not enough for the separated pair: the shifted block `N_g(X+a)` also has cut values

```text
X=-a-2,...,-a-g.
```

The full interval divisor `C_{a+g}` removes both blocks. This is the minimal clean saturation for identity (7.7). A broader physical boundary divisor is harmless.

### 9.2 Leading-coefficient degeneration

A vanishing leading coefficient lowers the affine degree but creates no affine root. Thus it does not affect (2.2), the restart argument, or the radical identity. It matters only if one uses nominal homogenizations or raw resultants, where a common point at infinity can appear. In that language one must remove the maximal `Z`-power before comparing with affine gcds.

The tracked example

```text
p=17, d=g=2
```

shows this distinction: both nominal cubics lose leading terms and the raw resultant sees an infinity intersection, although there is no common affine root. The affine theorem above is unaffected.

### 9.3 Reflection centers

For even `h`, the factor

```text
2X+h+1
```

is a genuine affine factor of `N_h`. It is not a clock or leading-coefficient artifact. It may be deleted if the intended statistic removes the deterministic mirror skeleton, but then (7.7) becomes an upper bound rather than an equality unless `k_x^reg` is redefined using the reduced polynomials.

### 9.4 Multiplicity

The theorem is about

```text
deg rad gcd.
```

Without the radical, a common root of high multiplicity is charged more than once on the polynomial side but only once by a zero-level pair. The proof does not yield the same estimate for the full gcd degree. This distinction is essential.

## 10. Zero polynomials and the exact height range

The proof uses the nonzero-polynomial property twice:

1. a nonzero `N_d` has at most `3(d-1)` distinct roots;
2. the radical gcd has finite degree and a finite algebraic root set.

Lemma 2.1 provides this uniformly for `d<D<p`. Therefore the theorem is unconditional in the stated range.

It cannot be extended indiscriminately to large heights. The repository records the exact degeneration

```text
p=7: N_21 is the zero polynomial modulo 7.
```

If a level polynomial is zero, every algebraic `x` is a zero at that level and the column/root-count formulation collapses. Thus a statement with no height restriction is false or undefined. The safe published statement should retain

```text
D<p.
```

The proof can likely be extended to `D=p` using the same endpoint nonvanishing and injectivity bounds, but that extension is unnecessary here and should not be claimed without separately checking the endpoint conventions.

## 11. Characteristic-zero versus fixed-prime claims

The following identities are integer-polynomial identities and survive reduction in every characteristic:

```text
continuant recurrence,
addition/restart identity,
Dodgson identity,
cut-saturated Bezout identity.                       (11.1)
```

The complex root-strip theorem and characteristic-zero separated coprimality say

```text
gcd_Q[X](N_a(X),N_g(X+a))=1.                        (11.2)
```

They do **not** imply fixed-prime coprimality. A nonzero integer resultant may vanish modulo `p`, producing regular affine common factors, including nonsplit factors.

The repaired theorem is a fixed-prime theorem. Its extra fixed-characteristic inputs are exactly

```text
D<p,
N_h mod p nonzero for h<=D,
distinct translations h_i mod p.                    (11.3)
```

No characteristic-zero root localization is used in the `D^(8/3)` proof.

These checks support the index conventions but are not used as asymptotic evidence.

### One missing algebraic regression

The existing pointwise scripts see only `F_p` roots. A minimal Sage/FLINT check for the present theorem should, for small primes and `D<p`:

```text
1. construct N_2,...,N_D in F_p[X];
2. assert each is nonzero;
3. for every a,g>=2, e=a+g<=D:
     q = gcd(N_a(X),N_g(X+a));
     delete factors shared with C_e(X);
     replace q by its squarefree radical;
     add deg(q);
4. factor the N_h over F_p and compute
     sum_q deg(q)*binom(number of regular levels containing q,2),
   truncating a linear cut factor X+m at level m-1;
5. assert equality with step 3.
```

The following regression points should be mandatory:

```text
p=73, x=-3:       raw linear zero tail, removed/truncated by saturation;
p=17, a=g=2:      leading-degree loss but no affine zero-polynomial failure;
p=110629,a=g=3:   a regular nonsplit quadratic gcd, proving that F_p-root
                   checks alone do not audit radical degree;
p=7,h=21:         zero-polynomial failure outside the permitted range.
```

The `p=110629` example is

```text
gcd(N_3(X),N_3(X+3))=X^2+7X-15495,
```

with nonsquare discriminant modulo `110629`. Its radical degree is two even though it contributes no `F_p` root. This is exactly consistent with (7.7), which is an algebraic-closure identity.
