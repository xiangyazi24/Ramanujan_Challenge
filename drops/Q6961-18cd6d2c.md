# P25 Miller endgame orientation audit

## 1. One-step algebra

The three exact identities are compatible, but the transpose orientation must be fixed carefully.

Given

```
T_n^T M_n = sigma_n I
```

and `sigma_n != 0`,

```
M_n = sigma_n (T_n^T)^(-1).
```

From

```
A_n C_n^T = I
```

we have

```
A_n = (C_n^T)^(-1).
```

Therefore

```
T_n U_{n+1}=U_n C_n
```
transposes to

```
U_{n+1}^T T_n^T = C_n^T U_n^T.
```

Multiplying by `A_n` gives the required cancellation:

```
A_n U_{n+1}^T T_n^T = U_n^T.
```

Hence the correct transfer identity is

```
U_n^T M_n = sigma_n⁻¹ A_n U_{n+1}^T
```

not `U_n^T M_n = A_n U_{n+1}^T` without the scalar. The scalar is harmless for projective ratios but must be retained in exact Lean statements.

## 2. Product order

For

```
P_N = M_0 M_1 ... M_(N-1)
```

right multiplication gives

```
U_0^T P_N
 = (prod n=0..N-1 sigma_n⁻¹)
   A_0 A_1 ... A_(N-1) U_N^T.
```

The pull matrices are in the same chronological order. Reversing them is the orientation error to avoid.

Equivalently:

```lean
lemma telescope_Miller :
  U 0 ⬝ P_N = (∏ n in Finset.range N, sigma n)⁻¹ •
      (A 0 ⬝ A 1 ⬝ ... ⬝ A (N-1) ⬝ (U N).transpose) :=
```

with the product order explicitly preserved.

## 3. Physical column identification

The physical challenge vector is not an arbitrary column of `U_N^T`. It is the column selected by the initial covector.

Since

```
U_N = [e0, T_N e0, T_N T_(N+1)e0],
```

we have

```
(U_N)^T e2
```

as the third Krylov covector. The terminal Miller calculation therefore uses the `e2` column. The other columns correspond to the companion directions and do not identify the Catalan branch.

## 4. Recessive cancellation

The needed cancellation is:

```
fastState_(n+1)=C_n^T fastState_n.
```

Thus

```
fastState_N=(C_(N-1)^T ... C_0^T) fastState_0.
```

Using

```
A_n C_n^T=I
```

we obtain

```
A_0 ... A_(N-1) fastState_N = fastState_0.
```

This is the minimal Miller invariant. No exterior solution is needed.

## 6. Circularity audit

No genuine circularity remains provided the following separation is maintained:

- The Miller box contraction proves existence and uniqueness of the pull graph.
- The fast solution proves the chosen graph is the recessive one.
- Existing challenge ratio convergence identifies the physical limit with `commonLimit`.
- The terminal certificate only proves the terminal point enters the box.

The forbidden circular step would be using `challengeRatio_tendsto_common` to prove the pull graph contraction or using the Catalan identification to prove the fast solution. Neither is required.

## 7. Correction summary

The only orientation correction is the missing scalar:

```
U_n^T M_n = sigma_n⁻¹ A_n U_(n+1)^T.
```

All later projective statements may discard the product of `sigma_n⁻¹`, but Lean equalities must carry it.

The pull order is:

```
A_0 A_1 ... A_(N-1) U_N^T e_j
```

not

```
A_(N-1) ... A_0 U_N^T e_j.
```

With this correction, the e2 terminal column and two-pull Miller certificate are aligned with the independent proof route.
