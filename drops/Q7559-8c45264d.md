## 1. Exact APUC threshold

For the exact Boolean-unioned lower-prime load, write

```text
A_q(t) = number of numerical lower primes in P^-_(q,t) union P^+_(q,t).
```

Thus A_q(t) is integer-valued: each numerical lower prime is counted once after the sign union, while distinct lower primes at the same state remain distinct. Put

```text
z_q(t) = 1 when q divides b_t, and 0 otherwise,
mu_q   = Z(q) / q,
g_q(t) = z_q(t) - mu_q,
a_q    = Σ_(t mod q) g_q(t) A_q(t).
```

The actual A-profile upper positive cut is

```text
APUC(T,J) := Σ_(q in Q(T,J)) (a_q)_+ .                         (1.1)
```

Let

```text
M^vee(T,J) := Σ_q Σ_(t in Z_q) A_q(t),
U(T,J)     := Σ_(q in Q(T,J)) Z(q),                            (1.2)
```

and retain the proved pre-upper factorial moment

```text
F_pre(T,J) := Σ_(q,t) A_q(t)(A_q(t)-1)
           ≪_J T^(13/5) (log T)^(-9/5).                       (1.3)
```

Since the density subtraction is nonnegative,

```text
(a_q)_+ ≤ Σ_(t in Z_q) A_q(t),
```

so

```text
APUC(T,J) ≤ M^vee(T,J).                                       (1.4)
```

Let

```text
S = {(q,t): t is an upper Apéry zero and A_q(t) > 0}.
```

Then |S| ≤ U. Moreover,

```text
M^vee
 = Σ_((q,t) in S) A_q(t)
 = |S| + Σ_((q,t) in S) (A_q(t)-1)
 ≤ U + sqrt( U · Σ_((q,t) in S) (A_q(t)-1)^2 ).
```

For every integer A ≥ 1,

```text
(A-1)^2 ≤ A(A-1).
```

Therefore the exact deterministic inequality is

```text
M^vee(T,J) ≤ U(T,J) + sqrt( U(T,J) F_pre(T,J) ).              (1.5)
```

Put

```text
L = log T,
B = T^2 / L^2.
```

Equation (1.5) shows that the zero-mass threshold supplied by the current bank is

```text
U(T,J) = o_J( B^2 / F_pre )
       = o_J( T^(7/5) L^(-11/5) ).                            (1.6)
```

The current unconditional zero-count exponent 8/5 does not reach (1.6). The conditional quadruple-corank exponent 3/2 also does not reach it. Hence proving the existing conditional H^3-content estimate would still leave actual APUC open.

Any genuinely new one-prime theorem giving

```text
U(T,J) ≪_J T^(theta+o(1)) with theta < 7/5                  (1.7)
```

closes APUC. The natural next exponent from four-zero local sparsity is

```text
theta = 4/3.
```

This is the block-count exponent produced by intervals of length p^(2/3).

## 2. Candidate ranking by mathematical novelty

The order is **in increasing novelty**: rank 1 is the smallest departure from the arithmetic already built in the repository and is the selected route.

### Rank 1 — actual-zero-fibre critical four-return mass

Prove an averaged H^(2+o(1)) bound for off-center sliding quadruples of consecutive actual zeros in blocks of length H ≤ X^(2/3). This is the theorem in Section 3.

Why it is the least novel viable candidate:

- the repository already constructs the three adjacent gap polynomials for a quadruple;
- it already removes reflection-center factors;
- it already converts distinct common roots into p-adic resultant or Fitting corank;
- it already isolates the remaining defect as formal projective roots not known to lie on the actual Apéry prefix;
- only one additional dimension of arithmetic compression is required: H^3 must become H^2.

It is zero-fibre-specific and averaged over p, so it asks for no pointwise equidistribution and no control of irrelevant projective fibres.

### Rank 2 — full projective critical fourth energy

Let

```text
pi_p(n) = [b_n : b_(n-1)] in P^1(F_p),
m_(p,I)(v) = number of n in I with pi_p(n)=v.
```

Define

```text
E4_p(H) = Σ_(H-blocks I) Σ_(v in P^1(F_p)) binom(m_(p,I)(v),4).
```

The stronger unconditional theorem would be

```text
Σ_(X < p ≤ 2X) E4_p(H) log p  ≪_ε  H^(2+ε),
for H ≤ X^(2/3).                                               (2.1)
```

It implies rank 1 because the zero line is one projective fibre and

```text
(m-3)_+ ≤ binom(m,4).
```

It is more novel because it controls every actual projective fibre, whereas APUC needs only the zero fibre. The existing projective second-energy theorem does not approach (2.1). This is a genuinely new fourth-return theorem, not the harmless q6 profile energy eliminated by Q7543/Q7545.

### Rank 3 — pointwise three-halves primitive support

A still stronger theorem would say that for every ε > 0 there is C_ε such that every off-center four consecutive actual zeros

```text
x < x+a < x+a+b < x+s < p
```

satisfy

```text
p ≤ C_ε s^(3/2+ε).                                            (2.2)
```

Taking blocks just below X^(1/(3/2+ε)) would give

```text
Z(p) ≪_ε p^(1/3+O(ε))
```

pointwise and close APUC. This is the most novel candidate because it replaces the needed prime average by a rigid support inequality for every primitive actual chain. It is substantially stronger than necessary and should not be attacked first.

No fourth candidate is warranted. Fourier or trace-function formulations either fail to see the lower masks or require a new sheaf construction more novel than all three statements above.

## 3. Selected theorem: critical actual four-return compression

For an odd prime p, write the complete ordered zero set as

```text
0 ≤ z_(p,1) < ... < z_(p,Z(p)) ≤ p-1.
```

Partition `{0,...,p-1}` into the half-open blocks

```text
I_(nu,H) = [nu H, min((nu+1)H,p)) intersect Z.
```

Inside each block, list its zeros in increasing order and select every sliding quadruple. Such a quadruple is also consecutive in the global zero set. Call an adjacent zero pair u < v **centered** when

```text
u+v = p-1.
```

There is at most one centered adjacent pair in the full increasing zero set, and it lies in at most three sliding quadruples.

Let E_p^off(H) be the number of selected sliding quadruples for which none of the three adjacent pairs is centered.

### Theorem A4R-2/3 — actual critical four-return mass

For every ε > 0, uniformly for X ≥ 2 and integers

```text
6 ≤ H ≤ X^(2/3),
```

one has

```text
Σ_(X < p ≤ 2X) E_p^off(H) log p  ≪_ε  H^(2+ε).               (3.1)
```

This is an arithmetic theorem about the actual Apéry coefficient-zero fibre. Its statement contains no q6 load, no cut, no selector covariance, no random model, and no unproved content-mass assumption.

### Why H^2 is the exact useful scale

Let m_(p,nu) be the number of zeros in I_(nu,H). The total number of selected sliding quadruples is

```text
Q_p(H) = Σ_nu (m_(p,nu)-3)_+.
```

Since at most three selected quadruples contain the unique centered adjacent pair,

```text
Q_p(H) ≤ E_p^off(H)+3.                                        (3.2)
```

Also,

```text
Z(p) = Σ_nu m_(p,nu)
     ≤ 3 ceil(p/H) + Q_p(H).
```

Therefore

```text
Z(p) ≤ 3 ceil(p/H) + 3 + E_p^off(H).                          (3.3)
```

Choose H = floor(X^(2/3)). Summing (3.3) with weight log p, using the elementary Chebyshev bound

```text
Σ_(X < p ≤ 2X) log p ≪ X,
```

and applying (3.1), gives

```text
Σ_(X < p ≤ 2X) Z(p) log p
  ≪ (X/H) Σ_(X < p ≤ 2X) log p + X + H^(2+ε)
  ≪_ε X^(4/3+ε).
```

Hence

```text
Σ_(X < p ≤ 2X) Z(p)  ≪_ε  X^(4/3+ε) / log X.                (3.4)
```

Dyadic summation over the fixed q6 upper-prime range gives

```text
U(T,J) ≪_(J,ε) T^(4/3+ε) (log T)^(-1).                       (3.5)
```

Substituting (3.5) and (1.3) into (1.5),

```text
M^vee
 ≪_(J,ε) T^(4/3+ε) (log T)^(-1)
          + T^(59/30+ε/2) (log T)^(-7/5).                    (3.6)
```

Relative to B = T^2 (log T)^(-2), the second term has ratio

```text
T^(-1/30+ε/2) (log T)^(3/5).
```

Thus every fixed

```text
0 < ε < 1/15
```

makes (3.6) o_J(B). Equations (1.4) and (3.6) prove

```text
APUC(T,J) = o_J(B).
```

So A4R-2/3 closes actual APUC with a genuine power margin. No logarithmic optimization is needed after the 4/3 exponent is reached.

## 4. First concrete lemma for A4R-2/3

The first lemma should not be another all-H content hypothesis. It should isolate the exact arithmetic compression that is missing.

For S ≥ 3, let Q_p^off(S) be the number of indices i such that

```text
S < z_(p,i+3)-z_(p,i) ≤ 2S,
```

and none of the three adjacent pairs in

```text
z_(p,i) < z_(p,i+1) < z_(p,i+2) < z_(p,i+3)
```

is centered.

### Lemma FSAC — dyadic fixed-span actual-chain compression

For every ε > 0,

```text
Σ_(prime p > 2S) Q_p^off(S) log p  ≪_ε  S^(2+ε).             (4.1)
```

This is the first concrete lemma to prove.

Every off-center sliding quadruple selected inside an H-block has total span below H. Decomposing the possible spans into dyadic shells and applying (4.1) gives

```text
Σ_(X < p ≤ 2X) E_p^off(H) log p
 ≤ Σ_(dyadic S < H) Σ_(p > 2S) Q_p^off(S) log p
 ≪_ε Σ_(dyadic S < H) S^(2+ε)
 ≪_ε H^(2+ε),
```

which is (3.1).

The dyadic-shell form is deliberately weaker and more realistic than demanding an O(s^(1+ε)) bound for each exact span s. It permits arithmetic interaction among all gap compositions in one shell while still removing exactly one dimension from the current H^3 formal-carrier bookkeeping.

## 5. Exact arithmetic content of FSAC

Write one counted quadruple as

```text
x, x+a, x+a+b, x+a+b+c,
```

where

```text
a,b,c ≥ 2,
S < a+b+c ≤ 2S.
```

The exact gap identity gives

```text
N_a(x)       = 0 mod p,
N_b(x+a)     = 0 mod p,
N_c(x+a+b)   = 0 mod p.                                      (5.1)
```

The existing root-strip and resultant theory proves that the formal common-root carriers in (5.1) are nonzero after the known center and progression deflations. What it does not prove is that a formal common root x lies on the distinguished actual Apéry orbit, namely

```text
b_x = 0 mod p.                                                (5.2)
```

That is precisely where the current H^3 route counts projective phantoms.

The first proof task for FSAC is therefore the following finite algebraic construction.

### Actual-prefix Fitting module at span S

Construct an integral finite-presentation module M_S with these properties:

1. Its generators encode gap compositions (a,b,c) with S < a+b+c ≤ 2S and the two possible normalized Hasse branches.
2. Its relations include the three transfer or continuant returns (5.1), all exact renewal syzygies among adjacent returns, and the second-order recurrence defining the normalized Hasse square-root series C_+ or C_-.
3. It is saturated by recurrence denominators, the reflection-center factors 2x+h+1, and the already-classified one-parameter progression factors.
4. Every off-center actual quadruple of span in (S,2S] gives an independent kernel functional modulo p, so

```text
Q_p^off(S) ≤ v_p(Fitt_0(M_S)).                                (5.3)
```

5. The primitive Fitting determinant is nonzero and satisfies

```text
log |Fitt_0(M_S)| ≪_ε S^(2+ε).                                (5.4)
```

Then (4.1) follows immediately from

```text
Σ_p v_p(D) log p ≤ log |D|.
```

Items 4 and 5 are the genuine new work. They must be proved for the normalized actual-prefix module. Replacing it by the direct product of scalar resultants merely reproduces the old S^3 or worse height.

### Why the normalized Hasse branch is essential

The exact factorization in `hasse_franel_descent.tex` is

```text
A_p(a) = Delta(a)^(epsilon_p) B_p(a)^2,
```

where B_p(0)=1 and B_p is the indicated truncation of one of two universal second-order series. This normalization removes the triangular freedom exhibited by `hasse_square_no_go.tex`. A generic reciprocal square can realize arbitrary early coefficient patterns and cannot distinguish (5.2); the normalized B_p can.

The role of the Hasse and Dwork input is therefore not to assert random Fourier cancellation. It is to supply a common actual-prefix relation across the O(S^3) formal gap words, allowing one composition dimension to be eliminated before the determinant is taken. That is exactly the S^3 to S^2 saving required by FSAC.

## 6. Why this is plausibly reachable

The claim is not that existing general theorems already imply FSAC. They do not. The plausibility comes from the unusually complete local arithmetic already available.

### 6.1 The recurrence side is exact

For x+h < p, the Apéry three-term recurrence gives a two-dimensional transfer system with nonvanishing denominators. At a zero b_x=0, no-consecutive-zero rigidity fixes the projective state line. The numerator of the return entry is the gap polynomial N_h(x). Thus every equation in (5.1) is exact, not heuristic.

### 6.2 Formal degeneracies are already classified

The repository has already separated:

- the reflection-center factor;
- the adjacent self-gcd;
- the arithmetic-progression slice a=b=c;
- structural carrier primes;
- skipped-return and endpoint degeneracies.

FSAC does not ask for another geometric classification. It asks that, after these classifications, the actual prefix cut the remaining formal carrier by one aggregate dimension.

### 6.3 The actual prefix has a canonical arithmetic model

The Hasse–Franel pullback identifies the Apéry coefficients as coordinates of a square in a cover-adapted basis, while the normalized Hasse factorization selects a unique square root. The Dwork and Franel files provide exact Frobenius and tail congruences rather than numerical fits. Related primary work supports the same arithmetic framework:

- Mellit and Vlasenko, *Dwork's congruences for the constant terms of powers of a Laurent polynomial*, arXiv:1306.5811.
- Gorodetsky, *New representations for all sporadic Apéry-like sequences, with applications to congruences*, arXiv:2102.11839.
- Caruso, Fürnsinn, Vargas-Montoya, and Zudilin, *Galois Groups of Apéry-like Series Modulo Primes*, arXiv:2510.23298.

Those papers do not prove coefficient-zero anti-clustering. They justify treating the actual prefix as a rigid Frobenius object rather than an arbitrary reciprocal square.

### 6.4 The requested saving is one dimension, not square-root cancellation

At fixed total-span shell S < a+b+c ≤ 2S, the raw gap triples have three scale parameters with one shell inequality. The current direct carrier bookkeeping has S^(3+o(1)) mass. FSAC asks for S^(2+o(1)), exactly what one common actual-prefix relation should produce. It does not demand cancellation among unrelated primes or a Weil bound for a presently nonexistent sheaf.

## 7. Cold-audit failure modes

A purported proof of FSAC must be rejected if it does any of the following.

### 7.1 Counts formal roots instead of actual zeros

Showing that the three polynomials in (5.1) have few common roots is insufficient unless the argument enforces b_x=0. This is the principal phantom-fibre defect already recorded by the project.

### 7.2 Multiplies scalar resultants over all gap triples

That reproduces the old content mass and loses at least the required factor S. The saving must occur before the norm or determinant is taken.

### 7.3 Uses generic squareness

The reciprocal-square factorization alone has triangular coefficient freedom. The proof must use B_p(0)=1, the correct C_+ or C_- branch, and its universal second-order recurrence.

### 7.4 Discards structural or progression primes without paying them

FSAC is unconditional. Saturated factors may be removed only after their complete prime-power contribution is bounded inside S^(2+o(1)). An empirical list through a fixed S is not such a bound.

### 7.5 Uses reflection as the main saving

Reflection may remove at most the unique centered adjacent pair, hence at most three sliding quadruples per prime. That harmless O(X) term is already absorbed at H=X^(2/3); it cannot provide the S^3 to S^2 compression.

### 7.6 Uses finite APUC=0 data

An all-unmarked finite box forces every centered fibre negative. It supplies no estimate for the first populated marked regime and no information toward (4.1).

### 7.7 Proves only the existing square-root zero count

An X^(3/2+o(1)) average, even if made unconditional, gives before logarithms

```text
sqrt( T^(3/2) · T^(13/5) ) = T^(41/20) = T^2.05.
```

It cannot yield o(B). The theorem must cross exponent 7/5; cosmetic improvements to the 3/2 route do not close APUC.

The decisive finite diagnostic is therefore not another APUC scan. It is the sequence

after actual-prefix saturation, together with an exact audit that every modular kernel corresponds to an actual prefix and not a formal projective root.
