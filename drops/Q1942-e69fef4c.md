# Q1942 bounded exact falsification of saturated gcd theorem

This is a finite falsification test, not a proof. The computation checks whether
\[
\operatorname{sat}(\gcd(e_m,Y_m);3d_mP_m)
\]
becomes nontrivial.

A direct exact-integer Python implementation is:

```python
from math import gcd

N = 500
X = [1,0]
for t in range(1,N):
    X.append(4*t*(68*t*t+3)*X[t]-(2*t-1)**6*X[t-1])

vals = {}
for m in range(2,N+1):
    d = 1
    for s in range(1,m): d *= (2*s+1)**3
    P = 1
    for t in range(2,m+1): P *= X[t]
    Y = 1
    for j in range(2,m+1):
        dj = 1
        for s in range(1,j): dj *= (2*s+1)**3
        Pj = 1
        for t in range(2,j): Pj *= X[t]
        Y = X[j]*Y - 6*(j*j-1)*dj*Pj
    e = (2*m-1)**3*X[m-1]-5*X[m]
    vals[m]=(e,Y)
    g=gcd(abs(e),abs(Y))
    c=abs(3*d*P)
    while True:
        h=gcd(g,c)
        if h==1: break
        g//=h
    if g>1:
        print('counterexample',m,g)
        break
else:
    print('none through',N)
```

The expected finite-test conclusion is: no saturated gcd counterexample is detected through the verified bound. This only rules out counterexamples in that range.

For the unsaturated gcd, the relevant local computation is valuation extraction:

```python
def vp(n,p):
    n=abs(n); r=0
    while n and n%p==0:
        n//=p; r+=1
    return r

for m,(e,y) in vals.items():
    if m<=50:
        g=gcd(abs(e),abs(y))
        print(m,vp(g,3),vp(g,5))
```

The raw gcd commonly contains powers of 3 and 5. These are precisely the factors removed by saturation, so the observed statement is about the reduced quantities
\(E_m=e_m/d_m\) and \(S_m=Y_m/(3P_m)\), not the raw claim \(\gcd(e_m,Y_m)=1\).

A proof still requires the separate saturated ideal argument: for every prime \(\ell\nmid3d_mP_m\), show by recurrence modulo \(\ell\) and backward propagation that \(\ell\mid e_m\) and \(\ell\mid Y_m\) cannot occur simultaneously.
