# HM3 weaker output-prime overload criterion

Let
\[
E_p=\sum_{q,l\ne p, q\ne l}\sum_m g_p(m)g_q(m)g_l(m),\qquad S_+=\sum_p z_p^{-1}(E_p)_+^2.
\]
Write \(E_p\) as a centered third-order row interaction. A truncation argument gives a genuinely weaker sufficient condition than controlling the full square.

For any \(\tau>0\),
\[
C_+=\sum_p(E_p)_+\le \tau\sum_p z_p+\sum_p(E_p-\tau z_p)_+.
\]
Since \(\sum_p z_p=\lambda\), it suffices to bound the overload term.

Using weighted Cauchy,
\[
\sum_p(E_p-\tau z_p)_+
\le \left(\sum_p z_p\right)^{1/2}
\left(\sum_p z_p^{-1}(E_p-\tau z_p)_+^2\right)^{1/2}.
\]
Therefore
\[
C_+\le \tau\lambda+\lambda^{1/2}T(\tau)^{1/2},
\]
where
\[
T(\tau)=\sum_p z_p^{-1}(E_p-\tau z_p)_+^2.
\]
This is the minimal weighted truncated-energy condition.

If one needs
\[
C_+\ll X^{2+o(1)}\lambda^3,
\]
then it is enough to choose \(\tau\) and prove
\[
T(\tau)\ll X^{4+o(1)}\lambda^5
\]
only on the overload set. This does not require control of small or typical output primes.

## Relation with factorial moments

Expanding \(E_p\) shows that the square contains two output copies of \(p\). Terms are governed not only by
\[
F_k=\sum_m(K(m))_k,
\]
but also by two-point data
\[
C(m,n)=\sum_p f_p(m)f_p(n).
\]
The reason is that the same row identity can occur at two different points. Consequently no theorem based only on the histogram of \(K(m)\) can control \(S_+\).

The obstruction is the term
\[
\sum_{m,n} (K(m)-\cdots)(K(n)-\cdots)C(m,n)^2,
\]
which survives even when all one-point factorial moments are fixed.

## Counterexample model

Take two systems with the same number of ones in every column and hence identical \(K(m)\) histogram.

System A: all active rows use the same support pattern. Then \(C(m,n)\) is concentrated and \(E_p\) has coherent signs.

System B: independently permute supports between rows while preserving column sums. Then \(K(m)\) is unchanged but \(C(m,n)\) is nearly diagonal and the cubic output energy drops.

Thus fixed \(F_k\) for any finite collection of k cannot determine \(S_+\). A rainbow/two-point moment is necessary.

## Test models

For a three-row anchored example with \(\lambda\asymp X^{-1}\), only finitely many output primes overload. The truncated condition is satisfied trivially after taking \(\tau\) comparable with the maximum local contribution.

For the anchored-star model with \(\lambda\asymp1/\log X\), many primes share one anchor. The overload term remains large because the same pair-correlation repeats at many output rows. Truncation hides the diagonal only if \(T(\tau)\) is proved independently; it does not remove the same-unordered-pair obstruction.

## Correct theorem

A valid deterministic statement is:

If for some \(\tau\ge0\)
\[
\sum_p z_p^{-1}(E_p-\tau z_p)_+^2\ll X^{4+o(1)}\lambda^5
\]
and
\[
\tau\lambda\ll X^{2+o(1)}\lambda^3,
\]
then
\[
\sum_p(E_p)_+\ll X^{2+o(1)}\lambda^3.
\]

The second hypothesis forces \(\tau\ll X^{2+o(1)}\lambda^2\), the natural overload scale.

This criterion is strictly weaker than the full square bound because it discards all contributions with \(E_p\le\tau z_p\). It is not equivalent: the diagonal obstructions can still appear inside the truncated tail and require pair/rainbow control.
