# One-column Miller connection for `challengeRatio N 2`

## Audit verdict

The one-column proof is algebraically short once four local certificates are available:

```text
(1) T(n)^T M(n) = sigma(n) I,
(2) T(n) U(n+1) = U(n) C(n),
(3) the corrected two-pull terminal formula for column 2,
(4) the fast-state identification U(0)^T w_0^T = kappa * lift(g 0), kappa != 0.
```

No matrix inverse is needed in Lean.  Use the explicit matrix

```text
A(n)=C(n)^(-T)
```

only through the polynomial identity

```text
A(n) C(n)^T = I.
```

Use an explicit `3 x 3` adjugate at the single fixed matrix `U(0)^T` to recover the two challenge row pairings.  This avoids `U(0)^{-T}` entirely.

There is one mandatory correction before implementation:

```text
Q6945 chart: lift(u,v) = (1,u,v),
              pull_n(u,v) = (1/d,u/d).
```

Therefore the terminal theorem required here is

```text
A(N-2) A(N-1) U(N)^T e2
  = scalarTau2(N) * (1,u2(N),0)^T.                   (T2)
```

The printed Q6947 line

```text
scalarTau2(N) * (u2(N),0,1)^T
```

uses the opposite normalization/order and is incompatible with the Q6945 pull map.  If `/tmp/p25_miller_lean_minimal.md` still contains `(u2,0,1)`, this is a genuine hidden gap: either permute the companion coordinates and recompute `A,pull`, or correct the terminal equality to `(1,u2,0)`.  The proof below assumes the corrected form (T2).

The other hidden obligations are listed in Section 10.

# 6. Fixed-time adjugate instead of `U(0)^{-T}`

Set

```lean
def V0 : Mat3 := (millerU 0).transpose
```

Use a generic explicit `3 x 3` adjugate:

```lean
def det3 (V : Mat3) : ℝ :=
  V 0 0 * (V 1 1 * V 2 2 - V 1 2 * V 2 1) -
  V 0 1 * (V 1 0 * V 2 2 - V 1 2 * V 2 0) +
  V 0 2 * (V 1 0 * V 2 1 - V 1 1 * V 2 0)

def adj3 (V : Mat3) : Mat3 :=
  !![V 1 1*V 2 2-V 1 2*V 2 1,
      V 0 2*V 2 1-V 0 1*V 2 2,
      V 0 1*V 1 2-V 0 2*V 1 1;
     V 1 2*V 2 0-V 1 0*V 2 2,
      V 0 0*V 2 2-V 0 2*V 2 0,
      V 0 2*V 1 0-V 0 0*V 1 2;
     V 1 0*V 2 1-V 1 1*V 2 0,
      V 0 1*V 2 0-V 0 0*V 2 1,
      V 0 0*V 1 1-V 0 1*V 1 0]

lemma adj3_mul (V : Mat3) :
    adj3 V * V = det3 V • (1 : Mat3) := by
  ext i j
  fin_cases i <;> fin_cases j <;>
    simp [adj3, det3, Matrix.mul_apply, Fin.sum_univ_three]
  all_goals ring
```

The only local numeric certificate needed here is:

```lean
def detV0 : ℝ := det3 V0
```

```lean
  -- First associate row/matrix/vector, then use adj3_mul.
```

A more reliable implementation is to prove two generic helpers first:

```lean
lemma dot_rowMul (x : Vec3) (A : Mat3) (y : Vec3) :
    dot (rowMul x A) y = dot x (A *ᵥ y) := by
  simp [dot, rowMul, Matrix.mulVec]
  rw [Finset.sum_comm]
  ring

lemma mulVec_assoc (A B : Mat3) (y : Vec3) :
    A *ᵥ (B *ᵥ y) = (A*B) *ᵥ y := by
  symm
  exact Matrix.mulVec_mulVec A B y
```

Then `compCov_pair` is a short rewrite by `dot_rowMul`, `mulVec_assoc`, and `adj3_mul`.
