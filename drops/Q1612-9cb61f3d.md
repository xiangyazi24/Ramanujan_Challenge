# Problem 3.2: doubling the ramified center does not manufacture a second trace equation

## Verdict

Let

\[
p=2m+1,\qquad \lambda_j=j(j+1),\qquad \lambda=\lambda_m,
\]

and use the full-inverse shell

\[
M=GT,\qquad V\equiv A^{-1}\pmod M,\qquad J:=\frac{AV-1}{M}.
\]

Here the pushed large-degree bookkeeping is

\[
\deg A=2m-1,\qquad \deg M=N=2m-r.
\]

The center \(\lambda_m\) is a simple root of \(M\), and \(T(\lambda_m)\ne0\). Put

\[
M_+=M(Y-\lambda),
\qquad
V_+=V+M\ell,
\qquad \deg V_+<\deg M_+=N+1.
\]

Then the unique scalar lift is

\[
\boxed{
\ell=-\frac{J(\lambda)}{A(\lambda)}
     =-\frac{(AV-1)'(\lambda)}{A(\lambda)M'(\lambda)}.
}
\tag{0.1}
\]

The key coefficient audit is equally simple but is the point that must not be skipped. Write

\[
G=Y^{m+1}+g_mY^m+\cdots,
\qquad
T=Y^d+t_{d-1}Y^{d-1}+\cdots,
\qquad d=m-r-1,
\]

so \(N=(m+1)+d=2m-r\), and use the canonical Hensel representation from Q1593

\[
V=U+GC,\qquad \deg U\le m,\qquad \deg C<d.
\]

If

\[
q_0=[Y^{d-1}]C
\]

(the leading coefficient of \(C\) in the full-degree case), then, because \(G\) is monic,

\[
\boxed{[Y^{N-1}]V=q_0.}
\tag{0.2}
\]

Thus \(q_0\ne0\) gives \(\deg V=N-1\), while \(q_0=0\) gives \(\deg V\le N-2\).

For the doubled-center lift,

\[
V_+=U+G(C+\ell T).
\]

Define

\[
C_+:=C+\ell T.
\]

Then

\[
\boxed{
C_+
=\ell Y^d+(q_0+\ell t_{d-1})Y^{d-1}+\cdots,
}
\tag{0.3}
\]

and, since \(M=GT\),

\[
\boxed{
[Y^N]V_+=\ell,
\qquad
[Y^{N-1}]V_+=q_0+\ell [Y^{N-1}]M.
}
\tag{0.4}
\]

In particular, a **one-degree drop of \(V_+\)** from degree \(N\) to at most \(N-1\) says only

\[
\ell=0.
\]

It does **not** say \(q_0=0\). Once \(\ell=0\), one has \(V_+=V\), and only a *second* drop to degree at most \(N-2\) is the old trace equation \(q_0=0\). This is the exact coefficient check requested in the question.

The WZ/Riccati side supplies no independent mechanism forcing that second drop. In fact the correct full-inverse source audited in Q1609 has only the structural midpoint order corresponding to **one** \((Y-\lambda_m)\) in \(M\). Doubling that factor would require two additional \(z\)-orders at the ramified midpoint. The existing WZ source does not contain them. Therefore the one-step inverse extension packages the missing center Hensel slope; it does not produce a new homogeneous trace equation.

So the conclusion is a no-go:

\[
\boxed{
\text{the doubled-center lift is canonical, but it does not force }q_0\ne0.
}
\]

# 2. Exact one-step Hensel lift at the ramified center

Let \(\lambda=\lambda_m\). Since \(V\) is an inverse of \(A\) modulo \(M\),

\[
AV-1=MJ.
\tag{2.1}
\]

Set

\[
V_+=V+M\ell.
\]

Then

\[
\begin{aligned}
AV_+-1
&=A(V+M\ell)-1\\
&=(AV-1)+AM\ell\\
&=M(J+A\ell).
\end{aligned}
\tag{2.2}
\]

Therefore

\[
M_+=M(Y-\lambda)\mid AV_+-1
\]

if and only if

\[
(J+A\ell)(\lambda)=0.
\tag{2.3}
\]

Because \(\lambda\) is a root of \(M\) and \(A\) is invertible modulo \(M\),

\[
A(\lambda)\ne0.
\]

Hence (2.3) has the unique solution

\[
\boxed{
\ell=-J(\lambda)A(\lambda)^{-1}.
}
\tag{2.4}
\]

This proves existence and uniqueness of the inverse representative of degree \(<N+1\).

### Derivative form

Differentiate (2.1) and evaluate at the simple root \(\lambda\):

\[
(AV-1)'(\lambda)=M'(\lambda)J(\lambda),
\tag{2.5}
\]

because \(M(\lambda)=0\). Since \(M'(\lambda)\ne0\),

\[
J(\lambda)=\frac{(AV-1)'(\lambda)}{M'(\lambda)}.
\]

Substitution into (2.4) gives

\[
\boxed{
\ell
=-\frac{(AV-1)'(\lambda)}{A(\lambda)M'(\lambda)}.
}
\tag{2.6}
\]

Equivalently, differentiating (2.2) directly,

\[
(AV_+-1)'(\lambda)
=M'(\lambda)(J(\lambda)+A(\lambda)\ell)=0.
\]

So the scalar \(\ell\) is literally the correction that makes the reciprocal contact second order at the center.

Finally, the new quotient is

\[
\boxed{
J_+:=\frac{AV_+-1}{M_+}
     =\frac{J+A\ell}{Y-\lambda}.
}
\tag{2.7}
\]

No additional condition has appeared: (2.7) is just the divided form of the same scalar equation (2.3).

# 3. Expressing \(\ell\) in the pushed Hensel coordinates

Q1593 uses

\[
AU-1=GE,
\qquad
V=U+GC,
\qquad
M=GT,
\]

and proves

\[
E+AC=TJ.
\tag{3.1}

Since \(T(\lambda_m)\ne0\), evaluation at the center gives

\[
J(\lambda_m)
=\frac{E(\lambda_m)+A(\lambda_m)C(\lambda_m)}{T(\lambda_m)}.
\]

Consequently

\[
\boxed{
\ell
=-\frac{C(\lambda_m)}{T(\lambda_m)}
 -\frac{E(\lambda_m)}{A(\lambda_m)T(\lambda_m)}.
}
\tag{3.2}

This is the precise sense in which the added center equation packages the contaminant. In particular, even under hypothetical trace failure \(q_0=0\), the value \(C(\lambda_m)\) need not vanish, and neither does the \(E(\lambda_m)\) term. Thus \(q_0=0\) does not imply \(\ell=0\).

J(\lambda_m)=0,

or equivalently

\[
(Y-\lambda_m)^2\mid AV-1.
\tag{3.3}
\]

That is a center reciprocal-slope condition, not the trace condition.

# 5. Why the WZ/Riccati divisibility does not give an independent equation

The corrected full-inverse identity audited in Q1609 has the shape

\[
\mathcal L\!\left(\frac{t}{V}\right)(z)
=
\frac{u(z)M(\lambda_z)W_V(\lambda_z)}
     {v_{z-1}v_zv_{z+1}},
\qquad
u(z)=2z+1,
\tag{5.1}
\]

with the actual modulus

\[
M(Y)
=(Y-\lambda_m)
 \prod_{i=0}^{r}(Y-\lambda_i)
 \prod_{i=r+1}^{m-1}(Y-\lambda_i)^2.
\tag{5.2}
\]

At the midpoint \(z=m\),

\[
\lambda_z-\lambda_m=(z-m)^2
\]

in the local coordinate, while \(u(z)\) has a simple zero. Thus the structural contribution of the simple center factor in (5.1) is

\[
1+2=3
\]

orders in \(z\). Q1609 checks exactly this midpoint order three.

If one replaced \(M\) by

\[
M_+=M(Y-\lambda_m),
\]

then the center factor would be squared in \(Y\), so after pullback it would contribute four \(z\)-orders, and the anti-invariant factor \(u\) would make the structural order

\[
1+4=5.
\]

The existing WZ source has only the order-three midpoint structure. Therefore the current WZ identity cannot imply a polynomial factor \(M_+\) in the same Riccati source. Such a factor would require two genuinely new center orders that are not present.

This is stronger than a degree count: the proposed extra divisibility already fails at the local multiplicity level.

What *is* available at higher jet order is quotient information. As Q1609 emphasizes, at doubled unramified nodes higher derivatives determine \(W_V\) and then \(W_V'\); at the midpoint the first nonzero ramified jet determines the quotient value \(W_V(\lambda_m)\). These are inhomogeneous quotient equations. They are not additional homogeneous zeros of the Riccati numerator.

Accordingly, forming \(V_+\) by Hensel lifting the inverse congruence does not promote the WZ modulus from \(M\) to \(M_+\). The lift solves the reciprocal derivative condition (2.6); that is all.

# 6. Converse / no-go statement

The algebra gives a clean converse that rules out obtaining \(q_0\ne0\) from this maneuver alone.

> **Proposition.** Let \(A,M\in k[Y]\), let \(\lambda\) be a simple root of \(M\), assume \(A(\lambda)\ne0\), and let \(V\) be the canonical inverse of \(A\) modulo \(M\). Then there is a unique canonical inverse \(V_+\) modulo \(M(Y-\lambda)\) reducing to \(V\) modulo \(M\), namely
> \[
> V_+=V-M\frac{J(\lambda)}{A(\lambda)},
> \qquad J=(AV-1)/M.
> \]
> This construction exists for every \(V\); it imposes no condition on any pre-existing coefficient functional of \(V\) (in particular on \(q_0\)).

In the Problem 3.2 Hensel coordinates, the map is simply

\[
\boxed{
C\longmapsto C_+=C+\ell T.
}
\tag{6.1}
\]

Reduction modulo \(T\) recovers \(C\):

\[
C_+\bmod T=C.
\tag{6.2}
\]

Hence the extension does not erase or constrain the old trace coefficient. It adds one new top coefficient \(\ell\), fixed by the center derivative mismatch.

A useful equivalent formulation is

\[
\boxed{
\ell=0
\iff J(\lambda_m)=0
\iff (Y-\lambda_m)^2\mid AV-1.
}
\tag{6.3}
\]

Thus any argument that first proves “one-degree drop of \(V_+\)” has proved exactly (6.3). It has not proved \(q_0=0\) or \(q_0\ne0\). To reach the trace coefficient it would still need an independent second coefficient equation.

This is the requested no-go.

def solve_P(p):
    F=GF(p)
    RY.<Y>=PolynomialRing(F)
    Rz.<z>=PolynomialRing(F)
    Y0=z*(z+1); Yp=(z+1)*(z+2); Ym=(z-1)*z; uz=2*z+1

    def comp(P,X):
        if P==0: return Rz(0)
        return sum(F(P[i])*X**i for i in range(P.degree()+1))

    def L(P):
        return ((z+1)^3*comp(P,Yp)
              - uz*(F(17)*Y0+F(5))*comp(P,Y0)
              + z^3*comp(P,Ym))

    rhs=-F(16)*uz*(z^p-z)^2
    nr=2*p+2
    cols=[]
    for i in range(p):
        q=L(Y^i)
        cols.append(vector(F,[q[k] for k in range(nr)]))
    Aop=matrix(F,cols).transpose()
    b=vector(F,[rhs[k] for k in range(nr)])
    c=Aop.solve_right(b)
    P=sum(c[i]*Y^i for i in range(p))
    assert L(P)==rhs
    assert P.degree()==p-1
    assert P.leading_coefficient()==1
    return F,RY,Y,P


def invmod_poly(A,M):
    g,s,t=A.xgcd(M)
    assert g.degree()==0
    return (s/g[0]) % M
