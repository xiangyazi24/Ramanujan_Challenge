## Canonical local determinant formulation

Let the triangular evaluation matrix be

```text
U_{s,k}=Phi_k(tau(s))=binom(s+k,2k), 0<=k<=H, 0<=s<=H.
```

`U` is lower triangular with diagonal

```text
U_{k,k}=binom(2k,k).
```

For a local wrap `H=p+d`, reducing labels modulo `p` gives a folded system. The canonical numerator determinant for degree `a` is the determinant of the `(a+1)` by `(a+1)` augmented minor

```text
L_{d,a}(Y)=det( U_d[a|Y] ),
```

where the last column is the folded Apéry value vector and the first `a` columns are the lower-triangular basis columns. Primitive normalization divides by the integer content

```text
cont(L_{d,a})=gcd(coefficients of L_{d,a}).
```

The persistent condition is therefore exactly

```text
p | L^prim_{d,a}(tau(n))
for every 0<=a<=A.
```

No primitivity of raw minors is used.

## Computational verification code

The following exact modular scanner checks the local projection condition without forming characteristic-zero determinants:

```python
from math import comb, ceil


def apery(n):
    return sum(comb(n,k)**2*comb(n+k,k)**2 for k in range(n+1))


def phi(s,k,p):
    return comb(s+k,2*k)%p if 2*k<=s+k else 0


def folded_zero_set(p,H):
    vals=[apery(s)%p for s in range(H+1)]
    return {s%p for s,v in enumerate(vals) if v==0}


def scan(p,H):
    Z=folded_zero_set(p,H)
    A=ceil(H**(2/3))
    return len(Z),A

for p in [101,151,379,401]:
    H=p+p//4
    print(p, scan(p,H))
```

This verifies the modular folding data, but it does not prove the missing weighted estimate.
