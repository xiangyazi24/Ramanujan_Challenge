## 1. First strip away everything that is already sublinear

Use the Apéry--Lucas congruence.  If
\[
 n=ap+r,\qquad 0\le r<p,
\]
then
\[
 b_n\equiv b_a b_r\pmod p.
\]

Put
\[
 A=\lceil n^{1/3}\rceil,\qquad y=n/A\asymp n^{2/3}.
\]
Split the prime divisors counted by \(K_n\) into

* \(p\le y\);
* \(p>y\) with \(p\mid b_a\), where \(a=\lfloor n/p\rfloor<A\);
* \(p>y\), \(p\nmid b_a\), and hence necessarily \(p\mid b_r\).

The first sector costs only
\[
 \vartheta(y)=O(n^{2/3}).
\]
For the second sector, all such primes divide
\[
 \prod_{0\le a<A}b_a.
\]
The Laurent polynomial used in the repository is
\[
 \Lambda(x,y,z)=
 \frac{(1+x)(1+y)(1+z)((1+y)(1+z)+xyz)}{xyz},
\]
with nonnegative coefficients and coefficient sum \(40\), and
\[
 b_m=\operatorname{CT}\Lambda^m.
\]
Therefore \(0<b_m\le40^m\), so
\[
 \log\operatorname{rad}\prod_{a<A}b_a
 \le\sum_{a<A}\log b_a
 \le \frac{A(A-1)}2\log40
 =O(n^{2/3}).
\]

Consequently, if
\[
 K_n^{\sharp}:=
 \prod_{\substack{p>y,\ p\le n\\
                   a=\lfloor n/p\rfloor<A\\
                   p\nmid b_a,\ p\mid b_{n-ap}}}p,
\]
then, exactly,
\[
 \boxed{\log K_n\le O(n^{2/3})+\log K_n^{\sharp}.}
\tag{1}
\]
There is no density statement here: (1) holds for every \(n\).

Two boundary residues are automatically harmless in the hard sector.  If \(r=0\), then \(b_r=1\); if \(r=p-1\), reflection gives \(b_{p-1}\equiv b_0=1\pmod p\).  Thus the hard primes sit in genuine interior quotient cells.

This reduction is useful because only \(a<n^{1/3}\) remains; it matches the project’s existing companion-height bookkeeping but is stated directly for the single-number radical \(K_n\).

## 2. The genuinely arithmetic constant-term carrier

Write
\[
 c_M(u,v,w)=[x^uy^vz^w]\Lambda^M
\]
and
\[
 C_M(d):=\sum_{(i,j,k)\in\mathbb Z^3}c_M(di,dj,dk).
\]
The exact coefficient formula implemented in `q32_cartier_packet_audit.py` is
\[
 c_M(u,v,w)=
 \sum_t
 \binom Mt\binom M{t-u}
 \binom{2M-t}{M-v}\binom{2M-t}{M-w}.
\tag{2}
\]

If \(n=ap+r\) and
\[
 M=n-a=a(p-1)+r,
\]
then the Cartier packet congruence gives, in particular,
\[
 \boxed{C_M(p-1)\equiv b_r\pmod p.}
\tag{3}
\]
Thus for the hard sector \(p\nmid b_a\), the original condition \(p\mid b_n\) is exactly the vanishing of one fixed-moment shell at the **moving divisor index** \(p-1\).

This is the right change of variables: the residue \(r=n-ap\) has disappeared from the value being interpolated.  It is encoded only by where the prime node \(p-1\) lies in the fixed shell sequence \(d\mapsto C_M(d)\).

### 2.1 Exact Newton--Pascal block identity

For any integer sequence \(Y=(Y_d)\), define
\[
 G_{d,L}(Y)=
 \sum_{i=0}^{L}(-1)^i
 \binom{d+i}{i}
 \binom{d+L+1}{L-i}Y_{d+i}.
\tag{4}
\]
If \(D>N\) and \(q\) is prime with \(D<q\le D+N\), then
\[
 G_{D-1,N}(Y)\equiv Y_{q-1}\pmod q.
\tag{5}
\]
Moreover \(q\) occurs exactly once in
\[
 B_{D,N}:=\binom{D+N}{N},
\]
because \(q>N\).  Therefore
\[
 \boxed{
 \operatorname{rad}_{(D,D+N]}
 \gcd\!\left(G_{D-1,N}(Y),\binom{D+N}{N}\right)
 =
 \prod_{\substack{D<q\le D+N\\q\mid Y_{q-1}}}q.
 }
\tag{6}
\]
This is the exact primitive-content identity isolated in commit `7b6abb...`; `q32_block_pascal_gcd_audit.py` independently encodes it.

Taking \(Y=C_M\) and keeping one quotient \(a\) fixed, (3) turns (6) into **exactly the desired hard target radical in that prime block**.

This is already much better than a raw resultant: it is one integer gcd involving only a fixed-moment shell carrier and a binomial coefficient, and it has no false positive from principal interval primes.

### 2.2 A canonical all-\(n\) block cover

For fixed \(a<A\), the primes with \(\lfloor n/p\rfloor=a\) lie in
\[
 \left(\frac{n}{a+1},\frac na\right].
\]
For \(a\ge2\) the cell width is smaller than its lower endpoint; after harmless endpoint rounding it is one admissible \(D>N\) block, or two if one wants strict inequalities uniformly.  The \(a=1\) cell can be split into two blocks.  Hence the hard range is covered by \(O(A)=O(n^{1/3})\) disjoint principal blocks with total width \(O(n)\).

For each block \(\mathcal B=(a,D,N)\), put
\[
 M=n-a,\quad
 A_{\mathcal B}:=G_{D-1,N}(C_M),\quad
 B_{\mathcal B}:=\binom{D+N}{N}.
\]
Then the exact every-\(n\) ledger is
\[
 \boxed{
 K_n^{\sharp}\mid
 \prod_{\mathcal B}
 \operatorname{rad}_{(D,D+N]}
 \gcd(A_{\mathcal B},B_{\mathcal B}).
 }
\tag{7}
\]
With a disjoint cover and the hard-sector definition, the right side is in fact the corresponding partitioned hard target product; divisibility is enough for the argument below.

So the original theorem is reduced to an explicit primitive-content estimate for (7).

## 3. Universal primorial content: why the obvious bound is fatal

Equation (6) is useful only with the support restriction \((D,D+N]\).  The binomial coefficient
\[
 B_{D,N}=\binom{D+N}{N}
\]
contains every prime \(q\in(D,D+N]\) exactly once.  Thus its principal-block radical contains the entire interval primorial.  Across a cover of a positive proportion of \((0,n]\), the logarithm of these node masks is linear by the Chebyshev/PNT scale
\[
 \sum\log q=\Theta(n).
\]
Hence
\[
 \gcd(A_{\mathcal B},B_{\mathcal B})\mid B_{\mathcal B}
\]
by itself proves nothing near \(o(n)\): it permits the entire candidate primorial.

This is the first mandatory accounting rule:

> **A prime obtained merely because it is in the interpolation mask is not a target prime.  Any construction whose target preservation is restored by multiplying missing mask primorials pays linear Chebyshev height.**

The beta--Padé audit below makes this exact.

## 4. Moving-index pollution: why the unrestricted gcd is also unsafe

There is a second exact trap in the same binomial coefficient.  Let \(q>N\) be any prime divisor of \(B_{D,N}\), not necessarily \(q>D\).  There is a unique multiple \(kq\in(D,D+N]\).  Modulo \(q\), the Newton row selects
\[
 Y_{kq-1},
\]
not necessarily \(Y_{q-1}\).  Thus primes below \(D\) can enter the full gcd through **folded nodes**.

`q32_block_pascal_gcd_audit.py` contains the exact concrete folded instance
\[
 (M,D,N,q)=(146,141,5,73),\qquad 2q=D+N.
\]
The point is not the finite example; the unique-multiple statement is the general theorem.  Therefore the unrestricted quantity
\[
 \operatorname{rad}\gcd(A_{D,N},B_{D,N})
\]
is not the target radical.  One must either support-restrict to the principal interval as in (6), or separately prune and charge folds.

This is the second mandatory accounting rule:

> **Never identify the full Newton--Pascal gcd with the target set.  Only its principal-interval radical has the exact target interpretation.**

## 5. The strongest scoped no-go: packet cancellation destroys target specificity

The most promising idea is to take several nearby carriers, exploit the fact that their constant-term/near-origin packet is the same, and cancel that enormous packet.  This does produce much smaller-looking formal expressions.  But the prime survives for the wrong reason.

### Theorem (same-packet target/cancellation dichotomy)

Let \(A_\alpha(Y)\) be any finite family of Newton--Padé carriers whose interpolation masks all contain a prime node \(q-1\), and let \(\lambda_\alpha\in\mathbb Z\).  Put
\[
 L=\sum_\alpha\lambda_\alpha.
\]
Then for every integer sequence \(Y\),
\[
 \boxed{
 \sum_\alpha\lambda_\alpha A_\alpha(Y)
 \equiv L\,Y_{q-1}\pmod q.
 }
\tag{8}
\]

**Proof.**  Each primitive Newton row is congruent modulo \(q\) to the coordinate vector selecting \(Y_{q-1}\).  Summing the rows gives (8).  No Apéry property is used.  \(\square\)

The beta--Padé identity in commit `f066893...` makes the height conflict explicit.  For
\[
 Q_{D,N}(T)=
 \sum_i(-1)^i
 \binom{D-1+i}{i}\binom{D+N}{N-i}T^i
\]
there is an exact polynomial Bézout identity
\[
 \boxed{
 T^D Q_{D,N}(T)+(1-T)^{N+1}R_{D,N}(T)=1.
 }
\tag{9}
\]
After pairing (9) with the Laurent coefficient array of \(\Lambda^M\),
\[
 \boxed{
 A_{D,N}+\mathcal H_{M,D,N}=\mathcal S_{M,K},
 }
\tag{10}
\]
where \(\mathcal S_{M,K}\) is a common near-origin coefficient packet.  It is important that \(\mathcal S_{M,K}\) is **not** the shell \(C_M(D-1)\); the audit has an explicit regression check for exactly that indexing mistake.

For a same-\(K\) family, summing (10) gives
\[
 \sum_\alpha\lambda_\alpha A_\alpha
 +\sum_\alpha\lambda_\alpha\mathcal H_\alpha
 =L\,\mathcal S_{M,K}.
\tag{11}
\]
Therefore there are only two formal choices.

* If \(L\not\equiv0\pmod q\), equation (8) retains the target scalar \(Y_{q-1}\), but the common packet in (11) remains.
* If \(L=0\), the common packet cancels exactly, but (8) is divisible by \(q\) for **every** sequence \(Y\).  The \(q\)-factor is presentation content, not evidence that \(Y_{q-1}=0\).
* If merely \(q\mid L\), the same loss of target specificity occurs locally at \(q\).

This is not a heuristic statement about likely cancellation.  It is coefficientwise.

### Local Smith form says the same thing

The exact adjacent identity is
\[
 G_{d,L}(Y)-G_{d+1,L}(Y)
 =(-1)^{L+1}\binom{d+L+1}{L}\Delta^{L+1}Y_d.
\tag{12}
\]
If \(q-1\) is common to a rectangle of stencils, `q32_newton_gcd_audit.py` verifies the general integer row algebra whose local Smith form is
\[
 \operatorname{diag}(1,q,\ldots,q).
\]
After one divides each successive row difference by the single forced \(q\), the divided rows have full rank modulo \(q\).  Thus the first copy of \(q\) in a packet-cancelling difference is exactly the universal Smith factor.  There is no hidden rank-one target condition left after primitive normalization.

### The second \(p\)-adic digit is not forced

For the shortest top-half stencil, targetness gives \(Y_{p-1}=0\pmod p\) and
\[
 G_{p-2,1}-G_{p-1,1}=p\,\Delta^2Y_{p-2}.
\]
After dividing the forced \(p\),
\[
 \frac{G_{p-2,1}-G_{p-1,1}}p
 \equiv Y_{p-2}+Y_p\pmod p,
\tag{13}
\]
and Cartier reduction gives
\[
 Y_p\equiv40b_s\pmod p.
\]
There is no target identity forcing (13) to vanish.

The sharp exact counterexample already recorded in the proof history is
\[
 (n,p,r,s,M)=(20,17,3,2,19),
\]
with
\[
 17^2\mid b_3,
 \qquad
 \frac{C_{19}(16)}{17}\equiv7\pmod{17}.
\tag{14}
\]
So even a depth-two Apéry zero does **not** lift the matched shell to depth two.  The natural cross multiplication also fails: the recorded divided digit of
\[
 5b_2C_{19}(16)-b_3b_{19}
\]
is \(5\pmod{17}\), not zero.

The universal localized jet description in the proof history is correspondingly
\[
 I=(p,\tau),
\]
where \(\tau\) is the matched-shell alias.  A bounded-degree observation that is universally zero after division by \(p\) lies in \(I^2\); its conormal direction is still the original \(\tau\).  This is the correct formal scope of the no-go.

### Scope

This theorem rules out the following strategy:

> derive finitely many carriers only from the universal Cartier factorization / Newton interpolation / beta--Padé Bézout identities, cancel their shared large packet formally, divide their universal node content, and hope that every target prime remains.

It does **not** rule out a new identity peculiar to the distinguished Apéry state, nor a genuinely new \(p^2\)-congruence transverse to \(\tau\).  That is exactly where any successful arithmetic construction must add information.

## 6. A genuinely diagonal attempt: use one extreme Cartier coefficient

The shell is not the only target-preserving quantity.  The Laurent polynomial has an extreme monomial of coefficient \(1\); for instance the \((-1,-1,-1)\) vertex has coefficient \(1\).  Hence the extreme coefficient of \(\Lambda^a\) at \((-a,-a,-a)\) is also \(1\).  The Cartier congruence therefore gives
\[
 c_{ap+r}(-ap,-ap,-ap)\equiv b_r\pmod p.
\tag{15}
\]
Thus a hard target prime divides a **single coefficient**, with no central-shell sum and no outer factor \(b_a\).

This is the cleanest genuinely arithmetic alternative I found.  It nevertheless fails the height/index test.

The index \((-ap,-ap,-ap)\) moves with \(p\).  Writing \(ap=n-r\), the terminal-ray formulas in `q32_terminal_ct_packet_audit.sage` express such coefficients as positive sums of binomial products whose parameters involve \(r\).  If \(r\) is a fixed positive fraction of \(n\), a single central binomial term already has \(\exp(cn)\) size for some \(c>0\).  So the coefficient itself does not have uniformly subexponential height.  Multiplying these coefficients over candidate primes is much worse.

To collect the moving indices into one integer, one is forced back to interpolation in the divisor index.  That is precisely what (4)--(6) accomplish, and then the primorial/Smith obstruction returns.

So the extreme coefficient solves **target preservation** but not **moving-index compression**.

## 7. Arithmetic Nullstellensatz, norm, and modular-polynomial routes

There is a short exact obstruction to the most obvious evaluation/elimination constructions.

Suppose a canonical one-parameter deformation produces an integral polynomial \(F_n(T)\) with
\[
 F_n(1)=b_n.
\]
Let \(Q(T)\in\mathbb Z[T]\) be an auxiliary polynomial.

### 7.1 If the auxiliary has the exact root \(1\)

If \(Q(1)=0\), then \(T-1\mid Q\), and multiplicativity of the resultant gives
\[
 \operatorname{Res}_T(F_n,Q)
 =\pm F_n(1)\,
   \operatorname{Res}_T\!\left(F_n,\frac{Q}{T-1}\right).
\tag{16}
\]
Thus the elimination norm contains \(b_n\) literally.  It cannot compress the height of the single integer whose small-prime radical we are trying to bound.

The same statement covers a fixed algebraic norm: if \(Q\) is the minimal polynomial of \(\alpha\) and \(\alpha=1\) is used to transfer the target condition, the norm contains the evaluation at \(1\).

### 7.2 If the auxiliary does not have the exact root \(1\)

For the congruence \(F_n(1)\equiv0\pmod p\) to give a common root \(T=1\) of \(F_n,Q\) modulo \(p\), one needs
\[
 p\mid Q(1).
\]
A fixed \(Q\) therefore catches only the finitely many primes dividing the fixed integer \(Q(1)\).  If \(Q=Q_n\) is made to catch every candidate prime in a moving block without knowing the target set in advance, then \(Q_n(1)\) must contain that block primorial.  Over the full hard cover this restores linear Chebyshev height.

A target-dependent choice of \(Q_n\) whose value at \(1\) contains only the actual target primes is just a restatement of \(K_n\) and is circular.

### 7.3 Adding a derivative does not help

A simple root congruence
\[
 F_n(1)\equiv0\pmod p
\]
does not imply
\[
 F_n'(1)\equiv0\pmod p.
\]
Thus a discriminant, first derivative, or two-equation Nullstellensatz destroys target preservation unless one has a new multiplicity theorem.  The exact first-divided-shell counterexample (14) is the Cartier-side analogue of this simple-root obstruction.

Hence the **evaluation-resultant/norm/modular-polynomial** route is closed in this natural scope: exact root transfer retains \(b_n\), while congruence-only transfer pays a primorial.

This does not rule out a completely different deformation where targetness imposes two independent geometric equations; no such equation is currently present in the Apéry constant-term packet modulo \(p\).

## 8. The canonical second Apéry solution and the product formula

There is a particularly tempting small rational identity.  Let \(a_n\) be the standard second solution with
\[
 a_0=0,\qquad a_1=6,
\]
and let \(b_n\) be the integral Apéry solution.  Both satisfy
\[
 n^3u_n-P(n)u_{n-1}+(n-1)^3u_{n-2}=0,
\]
where
\[
 P(n)=(2n-1)(17n^2-17n+5).
\]
For
\[
 W_n=a_nb_{n-1}-a_{n-1}b_n,
\]
the recurrence gives
\[
 n^3W_n=(n-1)^3W_{n-1}.
\]
Since \(W_1=6\),
\[
 \boxed{W_n=\frac6{n^3}.}
\tag{17}
\]

Equation (17) is exactly the kind of product-formula/Bézout identity one would like: tiny right side, canonical companion, and no large Archimedean height.  Unfortunately it is **transverse** to the target condition rather than divisible by it.  If \(p\mid b_n\) and the terms are \(p\)-integral away from the singular index, (17) says the companion determinant is a \(p\)-unit; it does not make it vanish.

Clearing all denominators does not save the argument.  The natural common denominator for the rational solution contains the cube of
\[
 d_n=\operatorname{lcm}(1,\ldots,n),
\]
and
\[
 \log d_n=\psi(n)\sim n.
\]
Thus turning (17) into an integer identity restores linear logarithmic content.  This is exactly the wrong trade: the tiny rational right side is achieved by denominators carrying the entire small-prime arithmetic.

So the canonical product formula is useful evidence that the second solution gives a genuinely independent direction, but it gives the independence with the **wrong sign of divisibility**.

## 9. Why one moment, bounded companions, and Baker do not produce a pointwise carrier

`q32_marked_scalar_character_sum.py` gives the exact marked-scalar identity
\[
 C_M(p-1)
 \equiv
 -\sum_{t\in\mathbb F_p^\times}t^rN_p(t)\pmod p.
\tag{18}
\]
Thus targetness is vanishing of one Mellin moment of the point-count function.  The inversion symmetry \(N_p(t)=N_p(t^{-1})\) gives the exact reflection law \(b_r\equiv b_{p-1-r}\pmod p\), but it does not create a second independent target equation.

At the coefficient level the same rank-one statement is
\[
 c_{ap+r}(p\mu)\equiv b_r c_a(\mu)\pmod p.
\tag{19}
\]
Every canonical \(p\)-spaced coefficient is therefore a known multiple of the **same** scalar \(b_r\) modulo \(p\).  A bounded number of such quantities is not a bounded number of independent conditions.

The repo’s failed one-moment/polylog routes are therefore not merely short of a better inequality: at the target prime they are observing one rank-one line.  A second independent congruence has to come from the first divided \(p\)-adic digit or another arithmetic structure, and (14) shows that the naive first digit is not target-selective.

The Baker route fails for a different exact reason, recorded in commit `4583f4a...`: linear forms in logarithms apply to an exact finite-rank multiplicative/power-sum description.  The moving Apéry gap does not have one.  Replacing the exact recurrence by its dominant asymptotic \(\rho^r\) is useless for divisibility modulo a moving prime; exactifying the approximation reintroduces a carrier of linear height.  Hence Baker does not turn the one moment into an every-\(n\) prime bound.

No density-one, average, or finite-moment statement substitutes for the missing pointwise identity.

## 10. Raw resultants: exact reasons they are too tall

The factorial/Strehl resultant audit gives a particularly clean death certificate.  For cutoff \(J\), after the natural denominator clearing, the resultant is exactly of the form
\[
 (J!)^{4(J+1)}\prod_{j=0}^{J}b_j^2
\tag{20}
\]
(up to the indexing normalization in `q32_factorial_resultant.py`).  Its logarithmic height is quadratic in the cutoff.  This is not a loose resultant-height estimate; the large product is the exact resultant.

Adjacent Padé pairs satisfy another exact identity,
\[
 P_bQ_{b+1}-P_{b+1}Q_b
 =\kappa_b\binom{x}{H+1}.
\tag{21}
\]
The extra common primes not coming from the target are carried by \(\kappa_b\) and the binomial node mask.  Taking more Padé numerators can make their gcd strikingly small in finite experiments (`q32_pade_family_gcd.py`), but the number of companions then grows with the interpolation height.  This is not the requested bounded-companion, every-\(n\) theorem, and the finite experiments prove no asymptotic estimate.

Thus the raw-resultant route has the same structural problem as the Newton block carrier, only with more height: it eliminates the moving node by multiplying over too much of the interpolation data.

## 11. The precise surviving arithmetic target

For every hard block \(\mathcal B=(a,D,N)\), define
\[
 \boxed{
 \begin{aligned}
  M&=n-a,\\
  A_{\mathcal B}&:=G_{D-1,N}(C_M),\\
  B_{\mathcal B}&:=\binom{D+N}{N}.
 \end{aligned}}
\tag{22}
\]
By (6), the desired block target radical is exactly
\[
 T_{\mathcal B}
 =\operatorname{rad}_{(D,D+N]}
   \gcd(A_{\mathcal B},B_{\mathcal B}).
\tag{23}
\]

The **minimal exact integer identity that would finish** is the following.

```text
For every hard block B=(a,D,N), construct canonical integers U_B,V_B and
R_B != 0 such that

    R_B = U_B A_B + V_B B_B,

and, over the canonical disjoint block cover of the hard primes,

    sum_B log |R_B| = o(n).
```

Indeed,
\[
 \gcd(A_{\mathcal B},B_{\mathcal B})\mid R_{\mathcal B},
\]
so
\[
 \log T_{\mathcal B}\le\log|R_{\mathcal B}|.
\]
Combining this with (1) and (7) gives
\[
 \boxed{
 \log K_n
 \le O(n^{2/3})+
 \sum_{\mathcal B}\log|R_{\mathcal B}|
 =o(n).
 }
\tag{24}
\]

A stronger sufficient local form is
\[
 \log|R_{\mathcal B}|=o(N)
\]
uniformly over the block cover.  Since the block widths have total \(O(n)\), that also gives (24).

The qualification “canonical” is important.  Bézout’s theorem always gives some \(U,V\) with
\[
 UA+VB=\gcd(A,B),
\]
but using that identity is exactly equivalent to knowing the unknown gcd and is therefore circular.  What is required is an identity derived from the Apéry differential/recurrence/diagonal arithmetic whose right side can be bounded **before** knowing its prime factors.

### Why (22)--(24) are preferable to a global \(b_n\) statement

They have already removed:

* all primes \(\le n^{2/3}\);
* all outer-digit primes \(p\mid b_a\) at a total \(O(n^{2/3})\) cost;
* residue motion inside each quotient cell;
* non-target principal interval primes, by the gcd with \(B_{D,N}\);
* folded-node pollution, by the support restriction in (23).

What remains is exactly the primitive common content of two canonical integers.  There is no density or zero-count statistic left in the statement.

## 12. Stronger scoped no-go in “bounded companion” language

It is useful to isolate what a successful bounded set of companion quantities would have to do.

Suppose \(X_{n,0}=b_n\) and \(X_{n,1},\ldots,X_{n,m}\) are a fixed number of canonical diagonal/derivative/companion quantities, and one seeks an integer polynomial combination
\[
 R_n=F_n(X_{n,0},\ldots,X_{n,m})
\]
with
\[
 K_n\mid R_n\ne0,
 \qquad \log|R_n|=o(n).
\tag{25}
\]
The current constant-term algebra leaves only three ways this can happen.

1. **All companions are rank-one Cartier aliases modulo \(p\).**  Then modulo a target prime they are multiples of the same \(b_r\); cancelling their common large part puts the prime into universal presentation content.  This is the theorem of Section 5.
2. **A companion is transverse modulo \(p\).**  The canonical second solution is the model case: its Wronskian is a unit, so targetness does not divide the combination.  Target preservation is lost.
3. **A second quantity vanishes only after lifting to \(p^2\).**  Then one needs a genuinely new first-digit theorem.  The universal Cartier lift does not supply it; (14) is an exact counterexample to the natural candidate.

Therefore a successful bounded-companion construction must contribute a new arithmetic equation that is neither a rank-one Cartier alias nor a generic transverse companion.  In geometric language it must cut the distinguished target fiber in a second direction **without** importing a candidate-prime mask.

That is a much narrower requirement than “find another resultant.”

## 13. What I would try next

The only route I would keep alive inside the constant-term framework is a genuinely Apéry-specific nonlinear identity for the pair in (22), not another universal interpolation identity.

Concretely, search for one of the following.

* A recurrence in the **divisor index** \(d\) satisfied by the fixed-moment shell \(C_M(d)\) after quotient-cell restriction, whose connection coefficient between two adjacent Newton blocks has logarithmic height \(o(N)\).  It must not be a formal finite-difference identity, because (12) is already saturated by universal Smith content.
* A \(p^2\) Cartier congruence for the distinguished Apéry Laurent polynomial in which targetness \(p\mid b_r\) forces a second scalar to vanish, contrary to the generic first-digit behavior but compatible with the special order-two Apéry recurrence.  Any candidate must immediately be tested against the exact \((p,r,M)=(17,3,19)\) obstruction.
* A modular correspondence that acts **within one fixed moment \(M\)** and relates the divisor indices \(q-1\) without requiring a polynomial whose value at the distinguished point contains the whole prime mask.  This would evade the evaluation-resultant lemma in Section 7.
* An Apéry-specific identity producing the Bézout remainder \(R_{M,D,N}\) in (24) directly.  Even \(\exp(O(N/\log N))\) per block would be enough; exact smallness matters, not small coefficients \(U,V\).

I would not spend more time on generic arithmetic Nullstellensatz height bounds, raw resultants, one-moment estimates, or packet-cancelling linear combinations unless they import one of those genuinely new structures.

## 14. Bottom line

The direct invariant \(K_n\) can be reduced, for every \(n\), to an exact fixed-moment primitive-content problem:
\[
 \log K_n
 \le O(n^{2/3})+
 \sum_{\mathcal B}
 \log\operatorname{rad}_{(D,D+N]}
 \gcd\!\left(
   G_{D-1,N}(C_{n-a}),
   \binom{D+N}{N}
 \right).
\tag{26}
\]
Every prime represented by the second term is a genuine moving-residue Apéry target in its principal block; folded primes are excluded by the support restriction.

What prevents the existing diagonal machinery from closing (26) is now exact:

* keeping the target coefficient keeps the common exponential packet;
* cancelling that packet makes the node prime universal presentation content;
* dividing the universal content leaves no target-forced first \(p\)-adic digit;
* restoring union target preservation with missing masks pays a linear primorial;
* evaluation norms/resultants either retain \(b_n\) or pay the same primorial;
* the canonical small-Wronskian companion is transverse rather than target-divisible;
* raw resultants have exact linear/quadratic carrier height.

Thus I cannot honestly claim \(\log K_n=o(n)\).  The smallest exact remaining theorem is the low-height Bézout remainder (24).  Proving that, or finding a genuinely transverse Apéry-specific \(p^2\) target equation from which it follows, would finish the pointwise problem without any density-one input.
