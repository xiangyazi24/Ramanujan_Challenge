# R1 strategic route audit: AC^tr and alternative routes

## 1. Verdict on AC^tr

The current invariant

\[
\mathcal C^*_{a,b,c}=\operatorname{cont}_T\operatorname{Res}_x(F_{a,b,c},G_{a,b,c}+TJ_{a,b,c})
\]

is the right *alignment-sensitive* invariant. It is not merely a repackaging of the old scalar gcd, because the Sylvester pencil forces the same-root condition through the rank drop of the evaluation map

\[
\mathbf Z_p[x]/(F)\longrightarrow \mathbf Z_p^2,
\qquad h\mapsto (h\bmod G,h\bmod J).
\]

After structural saturation and central palindromic deflation, AC^tr removes the known H^4 diagonals. The remaining conjecture is exactly the statement that the total Fitting mass of these simultaneous-root defects is H^{3+o(1)}. The AVENUES audit confirms that the fixed-depth Cartier route and scalar gcd routes do not attack this quantity.

The decisive point: AC^tr is a plausible invariant, but not yet a theorem. The remaining problem is proving a global height/corank bound for these finite-place Fitting ideals.

## 2. Ranking the four avenues

### Rank 1: (a0) local Fitting/intersection formula

This has the highest promise because it attacks the exact obstruction.

For

\[
A=\mathbf Z_p[x]/(F),\quad I=(G,J)\subset A,
\]

one expects

\[
v_p(\mathcal C)=\operatorname{length}_{\mathbf Z_p}(\operatorname{Fitt}_0(A/I))
\]

up to explicit leading-coefficient and non-flatness correction terms. The correct first lemma is:

> If F is primitive and A is finite flat over Z_p, then the T-content of the resultant pencil equals the valuation of the zeroth Fitting ideal of the cokernel of the two-column multiplication/evaluation map induced by G,J.

The immediate counter-test is to compute whether the formula survives:

1. repeated roots of F;
2. nonmonic F;
3. ramified extensions splitting F.

A false stronger statement would be

\[
v_p(\mathcal C)=\operatorname{length}_{\mathbf Z_p}(A/(G,J)).
\]

This fails whenever A/I is not cyclic or has non-flat torsion. The Fitting ideal is the correct invariant, not naive intersection length.

If a0 succeeds, the next target is an arithmetic Bézout/height estimate on these Fitting ideals.

### Rank 2: (c0) adelic arithmetic-intersection compression

This is the best possible global route after a0.

The desired shape is an arithmetic intersection inequality:

\[
\sum_p \log p\,v_p(\mathcal C^*)
\leq h(\text{intersection cycle})
\]

with height

\[
h(\text{cycle})=H^{3+o(1)}.
\]

Known methods to test:

- arithmetic Bézout (Bost-Gillet-Soulé);
- Arakelov intersection theory;
- determinant method normalization.

The fastest falsification is to compute the minimal adelic carrier after saturation. If every carrier necessarily contains

\[
\prod_{j\le H} U_j(17),
\]

then the height remains Ω(H^3 log H), and this route cannot close the gap. The previous saturation experiment suggests this obstruction is removable, so c0 remains viable.

### Rank 3: (d0) PGL2 transfer-matrix codegree

This is mathematically attractive but likely secondary.

The relevant object is the Apéry transfer matrix

\[
M_n=\begin{pmatrix}P(n)/ (n+1)^3&-n^3/(n+1)^3\\1&0\end{pmatrix}.
\]

A collision corresponds to two products of these matrices having equal projective action mod p.

The decisive lemma would be:

\[
\#\{(u,v):M_u\cdots M_v\text{ has prescribed projective value}\}
\ll H^{o(1)}.
\]

The fastest counter-test is search for families where the matrices commute modulo p or where the reflection involution creates unbounded projective stabilizers. Any such family kills a uniform codegree theorem.

Current census evidence is useful but not a proof.

### Rank 4: (b0) residual-prime rank amplification

This is the least promising of the four.

The hoped-for statement is:

one four-zero witness forces many descendants through rank-of-apparition growth.

The first lemma would have to be something like:

\[
(p\mid \mathcal C^*_{a,b,c})\Rightarrow
\#\{m\le Cp: p\mid b_m\}\gg H.
\]

The known obstruction is that Cartier lifting gives only the Boolean OR law:

\[
b_{\sum n_ip^i}=0\iff \exists i:n_i\in Z(p).
\]

Fixed depth copies the base atom and gives no amplification. The decisive counter-test is therefore to search for primes with isolated base atoms but no orbit growth. Existing computations already point in this direction.

## 3. A genuinely different avenue

The most plausible new route is a **derived determinant/cumulant invariant**, not another gcd.

Instead of counting simultaneous zeros, study the determinant of the full evaluation jet:

\[
\Delta_k=\det
\left(
\begin{array}{ccc}
G&G'&\cdots&G^{(k)}\\
J&J'&\cdots&J^{(k)}
\end{array}
\right)
\]

inside the local algebra A.

Repeated common roots force higher-order vanishing of this jet determinant. Unlike scalar gcds, it measures multiplicity rather than unrelated roots.

The falsifiable theorem target is:

\[
\sum_{a+b+c\le H}\log |\operatorname{Norm}(\Delta_k)|
=H^{3+o(1)}
\]

for the smallest k separating the residual intersections.

This avoids the documented obstructions:

- it is not a scalar gcd;
- it does not multiply cut-edge values;
- it is not fixed Cartier lifting;
- it uses multiplicity data rather than modular root counts.

The first test is computational: compare \(v_p(\Delta_k)\) with \(v_p(\mathcal C^*)\) on all existing H≤24 data. If the ratio is unbounded, discard immediately.

## 4. Strategic conclusion

The route ranking is:

1. **a0 Fitting formula** — most likely to reveal the missing theorem.
2. **c0 adelic compression** — most likely to convert that theorem into H^{3+o(1)}.
3. **d0 PGL2 codegree** — useful if a hidden rigidity theorem exists.
4. **b0 rank amplification** — currently contradicted by the Cartier behavior.

The conjecture is not proved. The conditional theorem under AC^tr remains the correct endpoint: the missing result is an actual H^{3+o(1)} bound for the saturated aligned Fitting/content mass, not another certificate-counting reformulation.
