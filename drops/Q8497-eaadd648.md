# 2. Exact local denominator theorem

Let

\[
h=m-X-1,
\qquad
T_X(m)=\sum_{k=X+1}^m\frac{b_{m-k}}k
      =\sum_{r=0}^h\frac{b_r}{m-r},
\]

and

\[
D=D_{X,m}=\operatorname{lcm}(X+1,\ldots,m).
\]

## Theorem 2.1 — one denominator cell per window prime

Let \(p\) be prime with \(X<p\le m\). Then

\[
\boxed{
p\mid D/\operatorname{den}(T_X(m))
\iff p\mid b_{m-p}.}
\tag{2.1}
\]

Here \(\operatorname{den}\) means the positive denominator in lowest terms.

### Proof

Since \(m<2X<2p\), among the integers \(X+1,\ldots,m\) the only multiple of
\(p\) is \(p\) itself. Also \(p^2>m\), so

\[
v_p(D)=1.
\]

Put \(r=m-p\). Because \(p>X\),

\[
0\le r=m-p\le m-X-1=h.
\]

Split the sum at its unique \(p\)-denominator:

\[
T_X(m)=\frac{b_r}{p}+U,
\qquad U\in\mathbf Z_{(p)}.
\]

If \(p\nmid b_r\), then \(v_p(T_X(m))=-1\), so the reduced denominator
contains \(p\). If \(p\mid b_r\), both summands are \(p\)-integral and the
reduced denominator does not contain \(p\). Since \(v_p(D)=1\), this is exactly
(2.1). \(\square\)

### Endpoint audit

If \(p=m\), then \(r=0\) and \(b_0=1\); thus the endpoint prime is never
canceled, exactly as (2.1) says. There is no second multiple \(2p\), because
\(m<2p\). No prime power is hidden in \(D\), because \(p^2>m\).

Consequently

\[
K_X^{(1)}(m)
=\#\{X<p\le m:p\mid b_{m-p}\}.
\tag{2.2}
\]

# 3. Removing the moving residue: one fixed-index logarithmic transform

Define the full logarithmic convolution

\[
\mathcal C_m=\sum_{k=1}^m\frac{b_{m-k}}k.
\tag{3.1}
\]

Its generating function and parameter realization are

\[
\boxed{
\sum_{m\ge0}\mathcal C_mz^m=-B(z)\log(1-z),}
\tag{3.2}
\]

and

\[
\boxed{
\mathcal C_m=
\left.\frac{\partial}{\partial s}
[z^m]\bigl((1-z)^{-s}B(z)\bigr)\right|_{s=0}.}
\tag{3.3}
\]

Indeed

\[
(1-z)^{-s}=\sum_{k\ge0}\frac{(s)_k}{k!}z^k,
\qquad
\left.\frac d{ds}\frac{(s)_k}{k!}\right|_{s=0}=\frac1k
\quad(k\ge1).
\]

Put

\[
L_m=\operatorname{lcm}(1,\ldots,m),
\qquad A_m=L_m\mathcal C_m\in\mathbf Z.
\tag{3.4}
\]

## Theorem 3.1 — fixed-index radical identity

For \(X\ge5\) and \(X<m<2X\),

\[
\boxed{
K_X^{(1)}(m)
=\omega_{X<p\le m}\bigl(\gcd(b_m,A_m)\bigr).}
\tag{3.5}
\]

Equivalently, the radicals agree as stated in (R).

### Proof

Fix \(p\in(X,m]\). The omitted lower-denominator prefix

\[
\mathcal C_m-T_X(m)=\sum_{k=1}^X\frac{b_{m-k}}k
\]

is \(p\)-integral. Hence

\[
T_X(m)\in\mathbf Z_{(p)}\iff\mathcal C_m\in\mathbf Z_{(p)}.
\tag{3.6}
\]

As above, \(v_p(L_m)=1\). Therefore

\[
p\mid A_m
\iff v_p(\mathcal C_m)\ge0
\iff p\mid b_{m-p}.
\tag{3.7}
\]

Write \(m=p+r\), where \(0\le r<p\). The Apéry numbers satisfy the Lucas
congruence

\[
b_{p+r}\equiv b_1b_r=5b_r\pmod p.
\tag{3.8}
\]

Because \(p>X\ge5\), one has \(p\ge7\), so \(5\) is a \(p\)-unit. Thus

\[
p\mid b_m\iff p\mid b_r=p\mid b_{m-p}.
\tag{3.9}
\]

Combining (3.7) and (3.9) proves (3.5) prime by prime. \(\square\)

## What (3.5) gains and what it does not

It gains a real quantifier simplification:

- no moving residue remains;
- no reduced rational denominator remains;
- the same physical integer \(m\) is retained;
- the entire target is the window-prime gcd of two explicit fixed-index
  integers.

It does **not** provide a height saving. The elementary bounds

\[
\binom{2n}{n}^2\le b_n\le(n+1)64^n
\tag{3.10}
\]

and the Chebyshev bound \(\log L_m=O(m)\) give

\[
\log b_m=O(m),\qquad \log A_m=O(m).
\]

Therefore (3.5) alone yields only

\[
K_X^{(1)}(m)
\le
\frac{\log\gcd(b_m,A_m)}{\log(X+1)}
=O\!\left(\frac X{\log X}\right),
\tag{3.11}
\]

far above \(X^{1/15+\eta}\).

# 4. The exact dense Wronskian identity

The most natural dense summation-by-parts object is obtained before taking
coefficients. Let

\[
H_X(z)=\sum_{k>X}\frac{z^k}{k},
\qquad C_X(z)=B(z)H_X(z).
\]

Then \([z^m]C_X=T_X(m)\), and

\[
\theta H_X(z)=\sum_{k>X}z^k=\frac{z^{X+1}}{1-z}.
\]

By the product rule,

\[
B\theta C_X-C_X\theta B
=B^2\theta H_X.
\]

This proves (W):

\[
(1-z)(B\theta C_X-C_X\theta B)=z^{X+1}B^2.
\tag{4.1}
\]

## Coefficient form

Set \(T_X(n)=0\) for \(n\le X\). Define

\[
F_X(n)=\sum_{a=0}^n(n-2a)b_aT_X(n-a).
\tag{4.2}
\]

Taking the coefficient of \(z^m\) in (4.1) gives the exact discrete identity

\[
\boxed{
F_X(m)-F_X(m-1)
=
\sum_{a=0}^{m-X-1}b_ab_{m-X-1-a}.}
\tag{4.3}
\]

This is a genuine dense summation-by-parts formula. It retains all earlier
transform values \(T_X(X+1),\ldots,T_X(m)\), rather than collapsing to the
single endpoint \(T_X(m)\).

## Boundary height

Write \(h=m-X-1\) and

\[
S_h=\sum_{a=0}^h b_ab_{h-a}.
\]

For \(h\ge1\), positivity and the \(a=0,h\) terms give

\[
S_h\ge2b_h\ge2\binom{2h}{h}^2
       \ge\frac{2\cdot16^h}{(2h+1)^2}.
\tag{4.4}
\]

On the other hand, (3.10) gives

\[
S_h\le(h+1)^3 64^h.
\tag{4.5}
\]

Hence

\[
\boxed{\log S_h=\Theta(h).}
\tag{4.6}
\]

For \(h\asymp X\), this is linear height, not the required
\(o(X^{1/15+\eta}\log X)\) boundary.

## Exact Apéry counterexample to target support

Take

\[
X=9,\qquad m=16,\qquad p=11.
\]

Then \(r=m-p=5\), and

\[
b_5=819005=11\cdot74455.
\]

In

\[
T_9(16)=\frac{b_6}{10}+\frac{b_5}{11}
       +\frac{b_4}{12}+\frac{b_3}{13}
       +\frac{b_2}{14}+\frac{b_1}{15}+\frac{b_0}{16},
\]

the only denominator divisible by \(11\) is \(11\), and its numerator is
itself divisible by \(11\). Thus \(11\) is a genuine canceled denominator
prime.

Here \(h=6\). Using

\[
(b_0,\ldots,b_6)
=(1,5,73,1445,33001,819005,21460825),
\]

one obtains

\[
\begin{aligned}
S_6
&=2b_6+2b_1b_5+2b_2b_4+b_3^2\\
&=58{,}017{,}871\\
&\equiv10\pmod {11}.
\end{aligned}
\tag{4.7}
\]

Therefore the target prime does not divide the exact dense boundary. This is
not a generic-sequence countermodel; it is a literal Apéry computation from

# 5. Why the logarithmic transform is not the Apéry logarithmic companion

The Apéry generating function satisfies

\[
\mathscr L B=0,
\]

where

\[
\mathscr L
=\theta^3
-z(34\theta^3+51\theta^2+27\theta+5)
+z^2(\theta+1)^3.
\tag{5.1}
\]

The natural Gessel formal derivative \(G(z)=\sum b'_nz^n\) has the property
that

\[
\log(z)B(z)+G(z)
\]

is a second homogeneous solution of \(\mathscr L\). The logarithm in the
present denominator problem is instead \(-\log(1-z)\), centered at \(z=1\),
which is an ordinary point of the Apéry operator because

\[
1-34z+z^2\bigm|_{z=1}=-32\ne0.
\]

The distinction is exact, not terminological.

For \(H=-\log(1-z)\) and \(\mathcal C=BH\), direct Euler-operator expansion
gives

\[
\boxed{
\begin{aligned}
\mathscr L\mathcal C={}&
 \frac{3z(1-34z+z^2)}{1-z}\,\theta^2B\\
&+\frac{3z(1-68z+37z^2-2z^3)}{(1-z)^2}\,\theta B\\
&+\frac{z(1-111z+78z^2-35z^3+3z^4)}{(1-z)^3}\,B.
\end{aligned}}
\tag{5.2}
\]

Thus \(\mathcal C_m\) satisfies an inhomogeneous scalar recurrence whose
source is a dense combination of the Apéry prefix. Applying the scalar
recurrence necessarily aggregates the target residue \(r=m-p\); it does not
produce a second homogeneous coordinate with a unit Casoratian.

More generally, for any scalar series \(H\),

\[
\begin{aligned}
\mathscr L(BH)-H\mathscr LB={}&
3(1-34z+z^2)(\theta H)\theta^2B\\
&+\bigl(3(1-34z+z^2)\theta^2H
       +(-102z+6z^2)\theta H\bigr)\theta B\\
&+\bigl((1-34z+z^2)\theta^3H
       +(-51z+3z^2)\theta^2H
       +(-27z+3z^2)\theta H\bigr)B.
\end{aligned}
\tag{5.3}
\]

Formula (5.2) is obtained from

\[
\theta H=\frac z{1-z},\quad
\theta^2H=\frac z{(1-z)^2},\quad
\theta^3H=\frac{z(1+z)}{(1-z)^3}.
\]

# 6. Exact no-go for a rational Green/Bezout boundary

The recurrence operator in the index variable is

\[
(\mathcal Ly)_j
=(j+1)^3y_{j+1}-P(j)y_j+j^3y_{j-1},
\qquad
P(j)=34j^3+51j^2+27j+5.
\tag{6.1}
\]

For any two sequences \(y,v\), define

\[
W_j(y,v)=(j+1)^3(y_jv_{j+1}-y_{j+1}v_j).
\]

A direct expansion gives the discrete Lagrange identity

\[
\boxed{
W_j-W_{j-1}=y_j(\mathcal Lv)_j-v_j(\mathcal Ly)_j.}
\tag{6.2}
\]

Therefore a rational solution of

\[
(\mathcal Lv)_j=\frac1{m-j}
\tag{6.3}
\]

would yield, for the Apéry solution \(\mathcal Lb=0\),

\[
\sum_{j=0}^h\frac{b_j}{m-j}=W_h(b,v)-W_{-1}(b,v)=W_h(b,v),
\tag{6.4}
\]

because the prefactor in \(W_{-1}\) is zero. This is precisely the desired
fixed-width rational summation-by-parts boundary.

## Theorem 6.1 — moving-pole obstruction

There is no rational function

\[
v(j,m)\in\mathbf Q(j,m)
\]

satisfying (6.3) identically.

### Proof

Regard \(m\) as transcendental over \(\mathbf Q\). Consider the finite set

\[
\mathcal S=\{s\in\mathbf Z:v(j,m)\text{ has a pole at }j=m+s\}.
\]

The set is nonempty: otherwise every shifted term in \(\mathcal Lv\) is
regular at \(j=m\), contradicting the pole of \(1/(m-j)\).

Let \(s_+=\max\mathcal S\). At

\[
j=m+s_++1,
\]

the term \(j^3v(j-1,m)\) has a pole. Neither \(v(j,m)\) nor \(v(j+1,m)\)
has a pole there, by maximality of \(s_+\). Its coefficient
\((m+s_++1)^3\) is nonzero in \(\mathbf Q(m)\), so the pole cannot cancel.
The right side has a pole only at \(j=m\). Hence

\[
s_++1=0,
\qquad s_+=-1.
\tag{6.5}
\]

Now let \(s_-=\min\mathcal S\). At

\[
j=m+s_--1,
\]

the term \((j+1)^3v(j+1,m)\) has an uncanceled pole. Its coefficient
\((m+s_-)^3\) is nonzero in \(\mathbf Q(m)\). Again the pole must be the sole
right-side pole at \(j=m\), so

\[
s_--1=0,
\qquad s_-=1.
\tag{6.6}
\]

But \(s_-\le s_+\), whereas (6.5)--(6.6) give \(1\le-1\), a contradiction.
\(\square\)

## Corollary 6.2 — fixed-width recurrence-algebra boundaries

No recurrence-universal identity of the form

\[
\frac{y_j}{m-j}
=\Delta_j\left(
 \sum_{t=-R}^{S}q_t(j,m)y_{j+t}
 \right),
\qquad q_t\in\mathbf Q(j,m),
\tag{6.7}
\]

holds for all solutions of the Apéry recurrence, for any fixed \(R,S\).
Indeed, the recurrence reduces every fixed collection of shifts to the
two-dimensional state, and the resulting coefficient equations are exactly
the adjoint/Green equation (6.3).

The same obstruction applies to an identity asserted only for the actual
Apéry solution if its coefficients are rational and the identity is to hold
symbolically for all sufficiently large \(j,m\). Otherwise the residual
coefficient relation would express \(b_j/b_{j-1}\) as a rational function of
\(j\). But the recurrence and positivity give

\[
\frac{b_j}{b_{j-1}}\longrightarrow17+12\sqrt2,
\tag{6.8}
\]

whereas a rational function over \(\mathbf Q\) with a finite nonzero limit has
rational limit.

## Scope

The theorem rules out:

- a rational discrete Green kernel;
- every fixed-width rational linear concomitant obtained from the Apéry
  recurrence;
- a two-endpoint rational Bezout certificate of the proposed type.

It does **not** rule out:

- a WZ certificate in the inner binomial index;
- a boundary with width or algebraic degree growing with \(X\);
- a genuinely modular identity involving additional periods;
- a nonlinear arithmetic carrier not lying in the rational difference module.

Thus this is a scoped algebraic no-go, not a universal impossibility theorem.

# 9. Independent executable verifier

The following script uses exact integer/rational arithmetic. It checks:

1. the Apéry recurrence values;
2. the denominator characterization (2.1);
3. the fixed-index radical identity (3.5);
4. the coefficient form (4.3);
5. the exact \((X,m,p)=(9,16,11)\) boundary counterexample;
6. the differential commutator (5.2)--(5.3) symbolically with SymPy.

```python
#!/usr/bin/env python3
from fractions import Fraction
from math import gcd, lcm


def primes_upto(n: int) -> list[int]:
    sieve = bytearray(b"\x01") * (n + 1)
    if n >= 0:
        sieve[0] = 0
    if n >= 1:
        sieve[1] = 0
    for p in range(2, int(n**0.5) + 1):
        if sieve[p]:
            sieve[p*p:n+1:p] = b"\x00" * (((n - p*p) // p) + 1)
    return [p for p in range(2, n + 1) if sieve[p]]


def apery_values(N: int) -> list[int]:
    b = [0] * (N + 1)
    b[0] = 1
    if N >= 1:
        b[1] = 5
    for n in range(1, N):
        P = 34*n**3 + 51*n**2 + 27*n + 5
        num = P*b[n] - n**3*b[n-1]
        den = (n + 1)**3
        assert num % den == 0
        b[n+1] = num // den
    return b


def L(a: int, b: int) -> int:
    out = 1
    for k in range(a, b + 1):
        out = lcm(out, k)
    return out


def T(b: list[int], X: int, m: int) -> Fraction:
    return sum((Fraction(b[m-k], k) for k in range(X + 1, m + 1)), Fraction(0))


def C(b: list[int], m: int) -> Fraction:
    return sum((Fraction(b[m-k], k) for k in range(1, m + 1)), Fraction(0))


def check_denominators(limit: int = 70) -> None:
    b = apery_values(2 * limit + 2)
    primes = primes_upto(2 * limit + 2)
    for X in range(5, limit + 1):
        for m in range(X + 1, 2 * X):
            D = L(X + 1, m)
            t = T(b, X, m)
            assert D % t.denominator == 0
            quotient = D // t.denominator

            window = [p for p in primes if X < p <= m]
            by_den = [p for p in window if quotient % p == 0]
            by_root = [p for p in window if b[m-p] % p == 0]
            assert by_den == by_root, (X, m, by_den, by_root)

            cm = C(b, m)
            Lm = L(1, m)
            Am = cm * Lm
            assert Am.denominator == 1
            Am = Am.numerator
            g = gcd(b[m], Am)
            by_gcd = [p for p in window if g % p == 0]
            assert by_gcd == by_root, (X, m, by_gcd, by_root)


def check_dense_identity(limit: int = 45) -> None:
    b = apery_values(2 * limit + 2)
    for X in range(2, limit + 1):
        c = [T(b, X, n) if n > X else Fraction(0)
             for n in range(2 * X + 1)]

        def f(n: int) -> Fraction:
            if n < 0:
                return Fraction(0)
            return sum(
                (Fraction(n - 2*a) * b[a] * c[n-a]
                 for a in range(n + 1)),
                Fraction(0),
            )

        for m in range(0, 2 * X):
            lhs = f(m) - f(m - 1)
            if m < X + 1:
                rhs = 0
            else:
                h = m - X - 1
                rhs = sum(b[a] * b[h-a] for a in range(h + 1))
            assert lhs == rhs, (X, m, lhs, rhs)


def check_counterexample() -> None:
    b = apery_values(16)
    X, m, p = 9, 16, 11
    assert b[m-p] % p == 0
    t = T(b, X, m)
    D = L(X + 1, m)
```
