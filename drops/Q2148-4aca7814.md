# P3.2 direct attack: sign-uniform residual rectangles

## Verdict

There is a genuine arithmetic gain here.

After removing the universal midpoint from every even continuant, the four local rectangle conditions do **not** remain four unrelated values.  In the monotone chamber

```text
p1 < p2 < q1 < q2,
A = (q2-q1)/2,
B = p2-p1,
x = (2*p1-q2-1)/2,
```

they compress to two common centered carriers:

```text
p1*p2 | F_A(Q),
q1*q2 | F_B(S),

Q = (q1+q2)/2,
S = p1+p2.
```

Here `F_h` is the midpoint-reduced centered integer continuant defined exactly below.  This is already stronger than keeping the four values separately.

There is then a second, exact Euclidean reduction.  Put

```text
P = p1*p2,
T = q1*q2,
c_h = F_h(h).
```

Because `F_h` is an even polynomial,

```text
T  | F_A(Q)-c_A,
4P | F_B(S)-c_B.
```

Combining these universal divisibilities with the two **selected** divisibilities above gives the four-marked integer

```text
R_{A,B}(S,Q)
  := c_A*F_B(S) + c_B*F_A(Q) - c_A*c_B,
```

and the exact lemma

```text
p1*p2*q1*q2 | R_{A,B}(S,Q).                 (R4)
```

Equivalently, if

```text
K_A = F_A(Q)/P,
L_B = F_B(S)/T,
H_A = (F_A(Q)-c_A)/T,
J_B = (F_B(S)-c_B)/(4P),
```

then

```text
R_{A,B}(S,Q)
  = P*T*(K_A*L_B - 4*H_A*J_B).               (R4-det)
```

This is a connected four-prime certificate, not the raw four-cycle determinant.  Its characteristic-zero degree is

```text
d_h = 3*(h-1) - 1_{2|h},

deg R_{A,B} = max(d_A,d_B)
```

when `c_A*c_B != 0`, whereas the obvious product determinant has product-scale degree.  Thus

```text
log |R_{A,B}(S,Q)|
  <= max(d_A,d_B)*log N + O_{A,B}(1),          (Hraw)
```

since `Q<2N` and `S<4N`.  The logarithmic height depends on the **variation** `(A,B)`, not linearly on the absolute start `x`.

This is enough to prove a concrete new exclusion:

```text
THEOREM.
There is no actual monotone rectangle with A=B=2 once N>=156.
```

Indeed, in that case

```text
R_{2,2}(S,Q) = 71*(17*S^2 + 17*Q^2 - 65),
```

so `0<R_{2,2}<24140*N^2`, while `(R4)` would force the product of four primes, which is `>N^4`, to divide it.

I do **not** claim that `(R4)` by itself closes the full sign-uniform residual.  For `(A,B)=(2,4),(2,6),(4,4),...` its raw degree is already at least `8`.  After importing the banked exponent-five interval normalization, the relevant local normalized height has a fixed `5 log M` contribution.  Four marked primes pay only `4 log N`.  I did not find an exact denominator-compatible cancellation of that fifth logarithmic unit.  That one-unit mismatch is now sharply isolated.

There is also a proved fixed-defect codegree consequence of the banked exponent-five normalization: for a fixed target pair `q1<q2` with `A=(q2-q1)/2`, the number of actual common monotone sources is at most

```text
floor( ((A-1)*log 311 + 5*log(2N))/log N ).      (CD5)
```

In particular it is at most `5` for fixed `A` and all sufficiently large `N` (and also for `A=o(log N)`).  For `A=2` the explicit polynomial improves this to **at most two common sources for `N>=69`**.

A constant codegree is not enough by itself to prove the global edge target: a bipartite graph can have bounded codegrees and still have far more than `N/loglog N` edges.  Thus the arithmetic advance is real but local.  The exact route-closing next statement is a **four-marked exponent drop**: produce the normalized analogue of `(R4)` with height `<(4-o(1))*log N` for the small-variation rectangles furnished by the folding-deficit reduction.  That would make each such actual rectangle impossible.  I do not claim that theorem here.

I also checked the most tempting reduced raw determinant.  It is saturated in the first unequal case: after removing both individual midpoint factors it has exactly one further universal factor, the total midpoint

```text
z = 2*x+A+B+1 = S-Q,
```

and for `(A,B)=(2,4)` the exact quotient is a degree-eight polynomial.  Thus the smallest unequal symbolic case already refutes the hope that midpoint removal makes the raw determinant variation-only of bounded degree.  This does **not** refute other rectangle attacks; `(R4)` is precisely a different, stronger Euclidean combination.

# 8. Fixed-A actual codegree from source reflection

This is a second proved consequence, useful independently of the four-prime carrier.

Fix primes

```text
N < q1 < q2 <= 2N,
A=(q2-q1)/2,
```

and let

```text

```

be the number of primes `p` with

```text

```

such that both actual edges


For every such `p`, source reflection (3.4) gives

```text

p | b_(u+A),

u=(q1-1)/2.                                       (8.1)
```

The entire interval `[u,u+A]` lies below `N`, hence below `p`.  Therefore every banked interval denominator is a `p`-unit, and `p` marks the same midpoint-reduced exponent-five normalized interval numerator for this **single fixed interval**.

Let that banked normalized integer be denoted here by

```text
U_A(u).
```

I use only the already-proved two properties of the banked normalization:

```text
p | U_A(u) for every common source p,              (8.2)

log |U_A(u)|
  <= (A-1)*log 311 + 5*log M,
```

with the safe physical-shell bound `M<=2N`.  Since the common sources are distinct primes `>N`, their product divides `U_A(u)`, hence

```text
c_A(q1,q2)*log N

 <= log |U_A(u)|
 <= (A-1)*log 311 + 5*log(2N).                    (8.3)
```

```text

      ((A-1)*log 311 + 5*log(2N))/log N
```

This is the requested explicit fixed-defect actual-rectangle codegree theorem.

Consequences:

```text
A fixed             => c_A(q1,q2) <= 5 eventually,
A=o(log N)          => c_A(q1,q2) <= 5 eventually.      (8.5)
```

### Why this still does not sum the whole bicore by itself

A bounded codegree does not force a bipartite graph to have `o(N/loglog N)` edges.  Even `C4`-free bipartite graphs can have on the order of `V^(3/2)` edges.  Here the prime-vertex population is on the order of `N/log N`, so that generic extremal scale is vastly larger than the desired residual threshold.

Thus (8.4) is a genuine arithmetic restriction but is not, by itself, a summation theorem for the sign-uniform bicore.

If the already-banked folding-deficit reduction gives an additional statement that every surviving excess edge participates in many small-`A` rectangles, then (8.4) can be inserted directly into that incidence count.  I do not assume such a quantitative multiplicity clause unless it is actually banked.

# 9. The tempting raw reduced determinant is saturated

Now audit the candidate closest to the one explicitly rejected in the question.

For even `h` put

```text
m_h(X) := N_h(X)/(2*X+h+1).                       (9.1)
```

Consider

```text
E_{A,B}(x)
 := m_A(x)*m_B(x+A)
    -m_B(x)*m_A(x+B).                              (9.2)
```

In the total centered coordinate

```text
z = 2*x+A+B+1,
```

Section 2 gives

```text
m_A(x)     ~ F_A(z-B),
m_A(x+B)   ~ F_A(z+B),
m_B(x)     ~ F_B(z-A),
m_B(x+A)   ~ F_B(z+A),                            (9.3)
```

where `~` hides only powers of two.

Since every `F_h` is even,

```text
E_{A,B}(-z) = -E_{A,B}(z).                         (9.4)
```

Therefore

```text
z | E_{A,B}.                                       (9.5)
```

This is a genuine **universal total-midpoint factor**.

If `A=B`, antisymmetry gives

```text
E_{A,A} == 0.                                      (9.6)
```

For unequal gaps, however, the smallest requested case already shows saturation.

## Smallest unequal case: (A,B)=(2,4)

Exact factorization gives

```text
E_{2,4}(x)
 = z/32 * (
      166753*z^8
    - 4899978*z^6
    + 31757712*z^4
    + 96780538*z^2
    + 16034975).                                   (9.7)
```

The degree-eight quotient is irreducible over `Q`.

Thus the candidate statement

```text
"after the two individual midpoints are removed,
 the four-cycle determinant loses all base dependence"
```

is false already at the smallest unequal pair `(2,4)`.  It retains degree eight in the total center after the one extra universal factor `z` is removed.

The next two exact factorizations are

```text
E_{2,6}(x)
 = z/2048 * (
      384865635*z^14
    - 27724294875*z^12
    + 481562163579*z^10
    + 2342854867205*z^8
    - 56527247937103*z^6
    + 262580024659895*z^4
    - 378549272071311*z^2
    - 74939965805025),                            (9.8)
```

and

```text
E_{4,6}(x)
 = z/131072 * (
      222067471395*z^20
    - 68549550207600*z^18
    + 8871145246214769*z^16
    - 624908662731553072*z^14
    + 26040782842067161598*z^12
    - 652361276854508913424*z^10
    + 9473028072548306355842*z^8
    - 70249138521812816248336*z^6
    + 154630511854782748499471*z^4
    + 531109632633005811056832*z^2
    + 88364005106951226095325).                   (9.9)
```

The reverse pairs change sign.  No further nonconstant rational factor occurs in these exact symbolic factorizations.

This is a **scoped saturation statement about this determinant only**.  It is not an impossibility theorem for rectangle methods.  Indeed, the Euclidean carrier `(R4)` is a rectangle method outside this saturated antisymmetric determinant and is strictly stronger in the equal-gap case.

# 10. Exact status relative to the residual target

The desired residual bound is

```text
E_res(N) = o(N/loglog N).                         (10.1)
```

The new arithmetic facts feed it as follows.

### What is now proved

For every actual monotone rectangle:

```text
four distinct shell primes mark one connected integer R_{A,B},
```

with raw height

```text
log |R_{A,B}|
 <= max(3(A-1)-delta_A,
        3(B-1)-delta_B)*log N + O_{A,B}(1).        (10.2)
```

For the smallest defect `(2,2)`, this is subcritical and eliminates the rectangle completely for `N>=156`.

For fixed target defect `A`, the banked exponent-five normalization also gives the actual codegree bound (8.4), asymptotically at most five.

### What is still missing

For four marked primes, a per-rectangle certificate closes immediately if one can prove a nonzero normalized connected integer `C_{A,B}` with

```text
p1*p2*q1*q2 | C_{A,B}
```

and

```text
log |C_{A,B}|
 <= (4-eta)*log N + O(A+B)                       (10.3)
```

for some fixed `eta>0` in the small-variation range supplied by the folding-deficit reduction.

The current exponent-five normalization naturally leaves a `5 log M` term.  Hence the exact next arithmetic target is:

```text
[RECT-4<]

Show that in the connected Euclidean determinant (4.8),
one additional absolute-scale denominator cancels after the four
midpoint/interval normalizations, so that the coefficient 5 drops
strictly below 4; equivalently obtain (10.3).
```

That is a one-unit exponent problem, not a request for another graph reformulation.

If `[RECT-4<]` holds, then every small-variation actual rectangle is impossible for large `N`, since its four marked primes contribute `>4 log N`.  To turn that into (10.1), one then plugs it into the already-proved residual combinatorial/folding statement that produces such rectangles from surviving excess edges.  If the existing folding-deficit theorem only says the component is sign-uniform but does **not** quantitatively force enough rectangles, an additional incidence step is still required; I do not hide that distinction.

### Why the fixed-codegree theorem is not enough

Even the stronger-looking statement

```text
c_A(q1,q2) <= 5
```

for every small `A` does not by itself imply (10.1).  It bounds how many source pairs can sit over one target pair, but bounded-codegree graphs may still be much denser than `N/loglog N`.

So the clean arithmetic frontier after this attack is not “prove codegree is finite.”  It is “make the four-marked connected determinant subcritical,” i.e. `[RECT-4<]`, or obtain an equivalent extra selected prime factor.

# 11. Bottom line

The direct actual rectangle does not collapse to the rejected raw determinant.

The useful exact identities are

```text
p1*p2 | F_A(Q),
q1*q2 | F_B(S),

q1*q2   | F_A(Q)-F_A(A),
4*p1*p2 | F_B(S)-F_B(B),
```

and therefore

```text
p1*p2*q1*q2
  | F_A(A)*F_B(S)
    +F_B(B)*F_A(Q)
    -F_A(A)*F_B(B).                                (11.1)
```

This is a proved four-marked connected carrier whose degree is controlled by the gaps, not by the absolute start.

It gives the concrete theorem

```text
A=B=2, N>=156  =>  no actual monotone rectangle.
```

The first unequal raw determinant `(2,4)` is exactly saturated after one total-midpoint factor, with the degree-eight quotient (9.7); that precise candidate is therefore dead, but rectangle attacks are not.

The banked exponent-five normalization gives the independent fixed-defect codegree theorem (8.4).  The remaining arithmetic obstruction is now one logarithmic unit: a four-marked rectangle supplies `4 log N`, while the current normalized interval architecture retains `5 log M`.  Proving an exact cancellation of that fifth unit in the connected determinant is the shortest arithmetic statement I see that would make the strict sign-uniform rectangle residual subcritical.
