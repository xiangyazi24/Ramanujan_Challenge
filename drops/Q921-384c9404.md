# Q921 corrected audit

## Verdict

The Q918 repair is correct in the localization point, but it does **not** close the argument.  The claimed missing hypothesis involving
\(\sum_{p\in S}\log p/p\) was not missing: for the actual anchored set
\[
S\subset\{p:\sqrt n<p\le n\},\qquad \sum_{p\in S}\log p\ge \varepsilon n,
\]
one immediately has
\[
\sum_{p\in S}\frac{\log p}{p}\ge \frac1n\sum_{p\in S}\log p\ge\varepsilon .
\]
Therefore the old paragraph allowing primes \(p\gg n\) is invalid and is retracted.

The remaining obstruction is propagation through the exceptional-index theorem.

## Correct propagation ceiling on \([n,2n]\)

For \(p>\sqrt n\), the progression
\[
m\equiv n\pmod p
\]
has spacing \(p\), hence contributes only \(O(1)\) indices in an interval of length \(n\).

If \(p,q>\sqrt n\) and \(p\ne q\), then
\[
pq>n.
\]
The simultaneous congruences
\[
m\equiv n\pmod p,\qquad m\equiv n\pmod q
\]
force
\[
m\equiv n\pmod{pq}.
\]
Inside an interval of length \(n\), the only possible solution is the anchor point \(m=n\). Therefore every propagated index
\[
m\in(n,2n]
\]
inherits at most one prime from the anchored set.

Hence outside the anchor,
\[
\log G_m^{\rm prop}\le \log p\le \log(2n).
\]
There is no multi-prime amplification at this first scale.

## Higher CRT intersections

A \(k\)-fold intersection requires a modulus product
\[
p_1\cdots p_k.
\]
For primes above \(\sqrt n\), the first possible nontrivial intersections occur only when the product exceeds the interval scale.  At such a point the inherited weight is at most
\[
O(k\log n),
\]
while the index scale is comparable to the product of the participating moduli.
Thus a fixed number of propagated primes cannot create a linearly large exceptional value.

However, converting this observation into the desired global theorem would require controlling the total number of indices receiving these inherited configurations across all scales.

## Interaction with the actual exceptional theorem

The available theorem is only:

\[
\#\{m\le N:\log G_m>\varepsilon m\}=O_\varepsilon((\log N)^2).
\]

This is a counting statement about linearly bad indices.  It is **not** a bound for
\[
\sum_m \log G_m,
\]
and it cannot by itself control a family of sublinear but numerous inherited contributions.

Likewise, the finite harmonic-weight corollary does not supply the missing deterministic estimate for the fixed anchored configuration.  It controls the exceptional set after aggregation, not the propagation mechanism required here.

Therefore the automatic lower bound
\[
\sum_{p\in S}\log p/p\ge\varepsilon
\]
does not combine with the current theorem to finish the cut.

## Valid anchored counter-configuration to the stronger propagation claim

The sharp valid construction uses only
\[
p\le n.
\]
Take any admissible anchored set
\[
S\subset(\sqrt n,n],
\]
with
\[
\sum_{p\in S}\log p\asymp n.
\]
The propagation to \([n,2n]\) gives disjoint progressions outside the anchor.  Therefore
\[
\sum_{m=n+1}^{2n}\sum_{p\in S\,:\,p\mid(m-n)}\log p
\le
\sum_{p\in S}O(1)\log p,
\]
but the contribution is distributed among different \(m\)'s rather than concentrated.

The sharp no-propagation inequality is:

\[
\boxed{
\max_{m\in(n,2n]}\sum_{\substack{p\in S\\p\mid m-n}}\log p
\le \log(2n).
}
\]

The only place where the full anchored mass \(\sum_{p\in S}\log p\) appears is the anchor \(m=n\) itself.
