# Q585 — Large sieve and Fourier anti-concentration for ZM₂

## Executive verdict

The Fourier calculation in the question identifies the correct obstruction, but the proposed route has one crucial mistake:

\[
|Z_p|^2 \neq C_2(p)/p.
\]

The collision energy \(C_2(p)\) controls the **second moment of the value distribution** of the map
\(r\mapsto b_r\bmod p\), not the mass of the zero fiber.  It gives at best the generic bound \(|Z_p|\ll \sqrt p\), not ZM₂.

The missing theorem is exactly a **fiber anti-concentration theorem** for the special value \(0\), stronger than ordinary Deligne bounds or trace-function large sieve.

---

## 1. Correct Fourier identities

Let

\[
N_p=p-1,\qquad f_p(r)=b_r\bmod p,
\]

and define

\[
S_p(a)=\sum_{r=0}^{p-2}e_p(a f_p(r)).
\]

The additive-character identity gives

\[
|Z_p|=\frac1p\sum_{a\in\mathbf F_p}S_p(a).
\]

This is a **linear** Fourier sum.  It is not an average of squared Fourier coefficients.

The tempting identity

\[
|Z_p|^2=\frac1{p^2}\sum_h |S_p(h)|^2
\]

is false.  The right side is Parseval energy:

\[
\frac1{p^2}\sum_h |S_p(h)|^2
=rac1p C_2(p),
\]

where

\[
C_2(p)=\#\{(r,s):b_r\equiv b_s\pmod p\}.
\]

This measures all collisions, not just collisions with zero.

---

## 2. What Parseval actually proves

By Cauchy–Schwarz,

\[
|Z_p|^2
=\frac1{p^2}\left|\sum_a S_p(a)\right|^2
\leq \frac1p\sum_a|S_p(a)|^2.
\]

Using Parseval,

\[
\sum_a|S_p(a)|^2=pC_2(p),
\]

so

\[
\boxed{|Z_p|^2\leq C_2(p).}
\]

For a random map \(\mathbf F_p\to\mathbf F_p\),

\[
C_2(p)\asymp p,
\]

which gives only

\[
|Z_p|\ll \sqrt p.
\]

This is exactly the same barrier as the individual Deligne estimate.

---

## 3. Deligne bounds do not prove ZM₂

Suppose

\[
|S_p(a)|\leq C\sqrt p\qquad(a\neq0).
\]

Then

\[
|Z_p|
\leq \frac1p\left(p+\sum_{a\neq0}|S_p(a)|\right)
\]

and hence

\[
|Z_p|\ll 1+C\sqrt p.
\]

The loss is the summation over \(p-1\) characters.

Therefore the implication

\[
\text{Deligne for every twist}\Longrightarrow |Z_p|=O(1)
\]

is false.

The required improvement is cancellation in the horizontal character sum

\[
\sum_{a\neq0}S_p(a).
\]

That is precisely the Fourier anti-concentration problem.

---

## 4. Large sieve formulation

ZM₂ asks for

\[
\sum_{p\le X}|Z_p|^2\ll \pi(X).
\]

This is naturally a large-sieve problem, but not the standard FKM form.

The FKM large sieve controls sums like

\[
\sum_p\left|\sum_n c_n\theta_p(n)\right|^2,
\]

where \(\theta_p\) is a trace function with a fixed geometric family.

Here the desired quantity is

\[
\sum_p\left|\frac1p\sum_a S_p(a)\right|^2.
\]

The additional averaging over the character parameter \(a\) is the hard part.  One needs a two-level large sieve:

\[
\sum_{p\le X}
\frac1{p^2}
\left|\sum_{a\in\mathbf F_p^\times}S_p(a)\right|^2
\ll \pi(X).
\]

This is not supplied by the usual Frobenius large sieve.

---

## 5. Can the Apéry geometry improve the character sum?

Potentially, yes, but this is exactly the missing theorem.

The Mellin/K3 interpretation says that \(b_r\) is a Fourier coefficient of a rank-three/rank-four geometric object.  The individual twists have bounded conductor, and Katz-style results can control each twist.

However, the quantity needed is not one twist:

\[
\sum_a S_p(a).
\]

It is a sum over all tame characters at the same prime.  Equivalently, it asks for a statement about the **whole tame parameter algebra** rather than each specialization.

A successful theorem would have the shape:

\[
\sum_{a\neq0}S_p(a)=O(p)
\]

or an averaged version over primes.

That would imply

\[
|Z_p|=O(1).
\]

No standard Deligne/Katz theorem gives this automatically.

---

## 6. Collision reformulation

The collision count is still useful:

\[
C_2(p)=\frac1p\sum_a|S_p(a)|^2.
\]

A strong collision theorem would say

\[
C_2(p)=p+O(1)
\]

or on average

\[
\sum_{p\le X}C_2(p)\ll X.
\]

But even this alone gives only an upper bound for the zero fiber through

\[
|Z_p|^2\le C_2(p).
\]

It does not exploit that the zero value is special.  One needs control of the **zero fiber**, not only the total collision energy.

---

## 7. The precise missing statement

The correct replacement for the failed argument is a zero-fiber large sieve:

\[
\boxed{
\sum_{p\le X}
\left|
\frac1p\sum_{a\in\mathbf F_p}S_p(a)
\right|^2
\ll \pi(X).
}
\]

Equivalently:

\[
\sum_{p\le X}|Z_p|^2\ll\pi(X).
\]

This is exactly ZM₂.

The missing ingredient is not a better application of Deligne.  It is a branch-coupling/anti-concentration theorem coupling all tame characters simultaneously.

---

## Final answers

1. **Is the Cauchy–Schwarz step optimal?**  For the available information, yes. It loses exactly because it replaces a structured sum over characters by character energy.

2. **Can geometry improve \(\sum_a S_p(a)\)?**  Possibly, and this is the right direction. It requires a theorem about the full tame-character family, not individual twists.

3. **Is there an identity avoiding the loss?**  The exact identity is the Fourier formula for \(|Z_p|\). There is no known Parseval identity turning a special fiber count into a second moment without losing the character correlation.

Therefore the project-level conclusion is:

\[
\boxed{
\text{ZM}_2 \text{ is a horizontal Mellin anti-concentration theorem, not a one-twist Deligne theorem.}
}

The large sieve framework is the correct language, but the missing input is a genuinely stronger large sieve over the tame parameter space.
