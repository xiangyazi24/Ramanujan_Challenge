# Q1706 audit: the seam residual is an indexing/sign error, not a closure

## Conclusion

The claimed implication `S=0 => Res=0` is false. The proposed residual formula leaves a nonzero seam term at the fixed point `m=(p-1)/2`. The failure is exactly the replacement of a boundary term by a vanished forward-difference term.

The summation-by-parts identity must be written with an explicit convention.

Let

```
nu_t = (t^2-1) C(t),
R(t)=1/C(t),
nu_t R(t)=t^2-1.
```

Define the forward difference

```
Delta F(t)=F(t+1)-F(t).
```

Then

```
(t+1/2)^3 nu_{t+1} R(t+1)
 -(t-1/2)^3 nu_{t-1} R(t-1)
```

is not a telescoping difference of the quantity indexed by `t` unless the two summands are aligned with the same shifted index. The centered factors belong to different lattice points.

## Correct index calculation

For `p=2m+1`, the centered gap is

```
t+1/2 = (2t+1)/2,
```

and at the endpoint `t=m`:

```
m+1/2 = p/2 = 0 mod p.
```

However the other endpoint is

```
m-1/2 = (p-2)/2 = -1 mod p/2,
```

which is a unit for p>3.

The remaining factor is

```
nu_{m-1}R(m-1)
 = (m-1)^2-1
 = m^2-2m
```

in F_p. Since `2m=-1`,

```
m^2-2m = m^2+1.
```

For the proposed residual

```
Res = ((m+1/2)^3 nu_{m+1}R(m)
      -(m-1/2)^3 nu_{m-1}R(m-1))/nu_m,
```

provided `nu_m` is nonzero, the first term vanishes and the second becomes

```
Res = -((m-1/2)^3 (m^2+1))/nu_m.
```

There is no general reason for this to vanish. In fact for the admissible primes tested below it is nonzero.

## Numerical checks

### p=19

Here

```
m=9,
1/2=10 mod 19.
```

The first centered coefficient:

```
m+1/2 = 0.
```

The second:

```
m-1/2 = 18 = -1 mod 19,
```

so

```
(m-1/2)^3 = -1.
```

Also

```
m^2+1 = 82 = 6 mod 19.
```

Hence the numerator seam term is

```
-((-1)*6)=6 mod 19,
```

not zero. Therefore the proposed residual cannot be zero unless the denominator introduces a zero, which is exactly a separate singular case and not a consequence of S=0.

### p=37

Here

```
m=18,
1/2=19 mod 37.
```

Again

```
m+1/2=0.
```

The other factor:

```
m-1/2=17.
```

and

```
m^2+1 = 325 = 31 mod 37.
```

The seam numerator is

```
-17^3*31 mod 37.
```

Since

```
17^3=4913=29 mod 37,
29*31=899=11 mod 37,
```

we get

```
Res numerator = -11 = 26 mod 37,
```

again nonzero.

## First failing equality

The first invalid step is the identification

```
Σ_t [A(t+1)-A(t)] = A(m+1)-A(0)
```

with the centered expression

```
(t+1/2)^3 nu_{t+1}R(t+1)
 -(t-1/2)^3 nu_{t-1}R(t-1).
```

Those are not `Delta A(t)` for a single sequence `A`. The second term is shifted by two indices relative to the first. Reindexing creates an interior cancellation plus an unavoidable seam contribution.

The seam contribution is precisely the nonzero term computed above.

## Verdict

Q1703 does not close the degree-drop argument. The statement `S=0 implies Res=0` is false for the displayed residual. The residual formula contains an indexing error: it treats a two-step centered difference as a one-step telescoping difference and loses the boundary seam. The computations at p=19 and p=37 already disprove the claimed closure.
