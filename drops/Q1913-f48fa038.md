# Q1913: Reciprocal-polynomial coefficient attack

## 1. Reduction to the polynomial-function Riccati equation

Let

```
r(t)=k(t)^{-1} in F_p,
```

with `p=2m+1`. Since `k` is even and every `k_t` is a unit, `r` is an even polynomial function on `F_p`. The contradiction assumption is

```
S=-sum_t r(t)=0.
```

Because the sum functional on polynomial functions over `F_p` kills all even degrees except the top degree `p-1`, the condition implies that the canonical representative of `r` has degree at most `p-3`.

Write

```
r(t)=A t^{2d}+a_{2d-2}t^{2d-2}+...+a_0,
```

where `2d <= p-3` and `A != 0` if `r` is nonconstant. The shifts are

```
r_+(t)=r(t+1),
r_-(t)=r(t-1).
```

The Riccati polynomial-function identity is

```
(t^p-t) | R(t),

R(t)=a r_- r + b r_- r_+ + c r r_+.
```

Here the divisibility is as polynomial functions, not necessarily as ordinary polynomials.

## 2. Exact leading coefficient computation

The leading parts are

```
a(t)=t^4 +(5/2)t^3 +(2)t^2 + ...,
b(t)=-34 t^4 +(37/2)t^2+3/2+...,
c(t)=t^4 -(5/2)t^3 +2t^2+...
```

and

```
r_-=A t^{2d}-2d A t^{2d-1}+..., 
r_+=A t^{2d}+2d A t^{2d-1}+... .
```

Therefore the degree `4d+4` coefficient in `R` is

```
A^2(1-34+1)=-32 A^2.
```

This term is not cancelled. Consequently, for a genuine top term of degree `2d`, the residual has leading coefficient

```
[t^{4d+4}]R=-32 A^2.
```

For `p>=7`, `-32` is nonzero only when `p != 2`, and in the present range the only exceptional prime is

```
p= ?
```

No odd prime `p>=7` divides `32`, so this coefficient is always nonzero.

Hence the Riccati residual has degree exactly

```
4d+4.
```

## 3. Top-down coefficient recurrence

Let

```
R(t)=sum_j C_j t^j.
```

The divisibility by `t^p-t` means that the canonical polynomial representative of `R` has zero coefficients in all degrees `p-1,...,p-2` after reduction modulo `t^p-t`.

For a term `t^n` with `n>=p`, reduction is

```
t^n = t^{1+((n-1) mod (p-1))}
```

as a polynomial function on `F_p`.

Thus the coefficient equations are

```
for every 1<=j<=p-2:

sum_{n>=1, 1+((n-1) mod (p-1))=j} C_n = 0,
```

and the constant coefficient condition is

```
sum_{n>=0, n mod (p-1)=0} C_n=0.
```

These are the exact coefficient recurrences forced by the Riccati divisibility.

The first equation at the top degree gives

```
C_{4d+4}=0
```

whenever `4d+4 < p`. But

```
C_{4d+4}=-32A^2,
```

so this is impossible.

Therefore a nonconstant reciprocal polynomial satisfying the assumptions cannot have degree

```
4d+4 < p.
```

## 4. Remaining degree range

The only remaining possibility is the wrap-around range

```
4d+4 >= p.
```

Here the leading term folds into a lower canonical degree. The top equation becomes a coupled recurrence involving all coefficients whose degrees are congruent to

```
4d+4 mod (p-1).
```

Explicitly, if

```
N=4d+4,
```
then the first folded equation is

```
-32 A^2
+ C_{N-(p-1)}
+ C_{N-2(p-1)}
+ ... =0,
```

where the additional terms are the coefficients of `R` in the same residue class modulo `p-1`.

This is the genuine remaining algebraic obstruction. It is not removed by the non-folded leading term argument.

## 5. Seam constraints

The point constraints are

```
r(0)=-1,

r(1)=r(-1)=1/3.
```

Since `r` is even, these give only two independent interpolation constraints. They do not determine the folded high-degree coefficients.

The seam condition inherited from the endpoint relation gives the same obstruction: it supplies a linear relation among the values of the reciprocal polynomial at the cyclic boundary, but not an immediate contradiction with the folded coefficient recurrence.

## 6. Classification of the premise

The exact conclusions are:

1. The claimed cancellation of the top Riccati term is false.
2. The top coefficient is exactly

```
-32 A^2.
```

3. If `deg(r)=2d` and `4d+4<p`, the assumptions are inconsistent.
4. The only unresolved case is

```
p <= 4d+4 <= 2p-6
```

(the maximal range allowed by `deg(r)<=p-3`).
5. Resolving the contradiction requires a proof that the folded coefficient recurrence together with

```
r(0)=-1,
r(±1)=1/3,
```

and the seam relation has no solution, or else an explicit algebraic countermodel in this folded range.

No finite scans are needed for this classification, and no claim that the `-32A^2` term vanishes is valid.
