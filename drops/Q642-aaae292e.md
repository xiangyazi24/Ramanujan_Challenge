# Sp4 equidistribution and AFP

## Main conclusion

The proposed Sp4 Sato--Tate route is very close to the right geometric picture, but the proof sketch has one decisive gap: **Katz equidistribution controls smooth test functions of Frobenius conjugacy classes, not exact trace fibers in the defining characteristic p.**

The desired implication

\[
\mathrm{Sp}_4\text{ monodromy}\Longrightarrow \#\{r:b_r\equiv0\pmod p\}=O(1)
\]

is not currently a direct consequence of Katz equidistribution.

The obstruction is exactly the mod-p anti-concentration issue identified in AFP.

---

# (A) Pointwise versus smooth equidistribution

The function-field Sato--Tate theorem has the form:

\[
\sum_{r\in U(\mathbf F_p)} f(\theta_r)
=
|U(\mathbf F_p)|\int_G f\,d\mu_{ST}+O(p^{1/2}\cdot C_f)
\]

for suitable class functions f.

The important point is that f is a test function on the compact monodromy group. Katz obtains this using character expansions and Deligne bounds.

The indicator

\[
f(g)=1_{\operatorname{tr}(g)=c}
\]

is not a smooth test function. Approximating it by smooth functions requires controlling the Sobolev norm of the approximation. The error then depends on the complexity of the approximation and does not automatically give an O(1) bound.

Therefore Step 5 of the sketch is not justified.

---

# (B) Vertical Chebotarev formulation

There is a Chebotarev-style statement for function fields, but the expected formula is more subtle.

For a fixed l-adic sheaf with finite-field monodromy group G, one expects approximately:

\[
\#\{r:\operatorname{tr}(\mathrm{Frob}_r)=c\}
\approx
|U(\mathbf F_p)|\frac{|\{g\in G(\mathbf F_q):\operatorname{tr}(g)=c\}|}{|G(\mathbf F_q)|}
\]

with square-root error under appropriate hypotheses.

However, this applies to the l-adic trace distribution, where l is different from p. It does not automatically imply statements about reduction of the trace modulo p.

---

# (C) Trace-zero density in Sp4

For a random element of Sp4 over a finite field of characteristic different from l, the heuristic is indeed:

\[
\frac{|\{g\in Sp_4(\mathbf F_q):\operatorname{tr}(g)=0\}|}{|Sp_4(\mathbf F_q)|}\asymp \frac1q.
\]

The reason is that trace is one algebraic coordinate on a high-dimensional group. A single trace value cuts out a codimension-one subvariety.

So the Sato--Tate heuristic predicts:

\[
\#\{r:\operatorname{tr}(\mathrm{Frob}_r)=0\}\approx O(1).
\]

This supports AFP.

But the actual AFP condition is:

\[
\operatorname{tr}(\mathrm{Frob}_r)\equiv0\pmod p,
\]

not equality of an l-adic trace to zero.

---

# (D) The defining-characteristic obstruction

This is the central issue.

The cohomological Frobenius representation is l-adic:

\[
\rho_l:\pi_1\rightarrow GL_4(\mathbf Q_l),\qquad l\neq p.
\]

Katz's equidistribution theorem concerns the eigenvalues of this representation.

The Apéry congruence is instead:

\[
b_r\equiv0\pmod p.
\]

That is a reduction modulo the characteristic of the base field.

There is no direct theorem saying:

\[
\operatorname{tr}(\rho_l(\mathrm{Frob}_r))\equiv0\pmod p
\]

has the same distribution as the l-adic trace values.

This is precisely why the problem is harder than ordinary vertical Sato--Tate.

---

# (E) Would this give an absolute constant?

Even if the Sp4 argument worked, the constant would initially depend on the conductor.

The effective equidistribution error is of the form:

\[
O(C_F p^{1/2})
\]

or after normalization:

\[
O(C_F p^{-1/2}).
\]

For a fixed sheaf with bounded conductor this is harmless, but for a family where the sheaf itself changes with p, one needs:

\[
C_F=O(1).
\]

Only then could one hope for an absolute constant.

For the Apéry family, bounded geometric conductor is plausible because the differential equation has fixed rank and fixed singularity structure. However, the remaining issue is still the mod-p reduction.

---

# Corrected proof strategy

The Sp4 route should be reformulated as:

1. Sp4 monodromy implies no self-twist and maximal geometric randomness.

2. Katz gives l-adic equidistribution of Frobenius classes.

3. One still needs a new theorem:

\[
\boxed{
\text{l-adic Frobenius equidistribution }+\text{ mod-p trace anti-concentration}
}
\]

4. This missing theorem would imply:

\[
\#\{r:b_r\equiv0\pmod p\}=O(1).
\]

The missing ingredient is therefore not Sp4 monodromy. The missing ingredient is a **vertical mod-p trace anti-concentration theorem for a bounded-conductor compatible system.**

This is exactly the arithmetic strengthening of Katz's philosophy required for AFP.
