# Q388: The top-half model — an easier target for P3.2?

## Executive verdict

The top-half model is genuinely easier, but it is not by itself sufficient unless one proves a theorem controlling the top-half contribution with a pointwise bound.

The correct conclusion is:

1. The top-half statement
\[
\omega_{(n/2,n]}(b_n)=o(n/\log n)
\]
is **not obviously equivalent** to the full P3.2 statement. It is only the top dyadic shell. It controls the primes that divide \(b_n\) directly through the leading digit \(1\), but the full problem also contains primes \(p\in(\sqrt n,n/2]\), where the quotient digit \(\lfloor n/p\rfloor\) can contribute.

2. The top-half model has a much cleaner geometry: it is a single suffix condition
\[
n-p\in Z_p.
\]
This removes the leading-digit channels and is an excellent test case.

3. CRT spacing does **not** automatically give equidistribution. The residues are sparse but adversarially indexed by \(p\). Farey spacing controls arbitrary fixed intervals, not arbitrary prime-indexed target sets.

4. The top-half second moment is likely the easiest missing theorem in the P3.2 program, but it is still a genuine moving-target anti-concentration statement.

---

# 1. Is the top-half model sufficient?

Let
\[
B_{top}(n)=\#\{p:n/2<p\le n,\ p\mid b_n\}.
\]

For \(p>n/2\), write
\[
n=p+r_p,\qquad 0\le r_p<p.
\]
Lucas gives
\[
b_n\equiv b_1b_{r_p}\equiv5b_{r_p}\pmod p.
\]
For \(p\ge7\), \(5\ne0\), hence
\[
p\mid b_n\iff r_p\in Z_p.
\]

Therefore
\[
B_{top}(n)=\#\{n-p\in Z_p:n/2<p\le n\}.
\]

This is exactly the suffix-suffix channel.

However, the full P3.2 quantity is
\[
B_{low}(n)=\#\{\sqrt n<p\le n:n\bmod p\in Z_p\},
\]
which contains all dyadic blocks
\[
(n/2^{j+1},n/2^j].
\]
The top block is only the first shell.

A bound
\[
B_{top}(n)=o(n/\log n)
\]
does not imply the same bound for all smaller shells. A proof of the top-half theorem would be a major partial result, not the full theorem.

---

# 2. Pair counting scale

For \(p,q>n/2\), one has
\[
pq>n^2/4>n.
\]
Hence each CRT class contributes at most one integer in \([1,n]\).

The expected pair count is
\[
\frac{z_pz_q n}{pq}.
\]
Summing the main terms gives
\[
 n\sum_{p\ne q}\frac{z_pz_q}{pq}
 \asymp n\lambda_{top}^2.
\]

With
\[
\lambda_{top}\approx0.053,
\]
this is approximately
\[
0.0028n,
\]
which is indeed tiny.

The small main term is an important advantage. But the issue is the error:

\[
R_{p,q}=\#\{n:n-p\in Z_p,n-q\in Z_q\}-\frac{nz_pz_q}{pq}.
\]

CRT only gives
\[
|R_{p,q}|\le z_pz_q.
\]
Summing this trivially gives the wrong scale:
\[
\sum_{p,q}|R_{p,q}|
\approx \left(\sum_pz_p\right)^2.
\]

For top-half primes this is still roughly
\[
\frac{n^2}{\log^2 n},
\]
far larger than \(n\).

Thus the small value of λ helps the probabilistic model, but it does not remove the need for cancellation.

# 3. Can pair dispersion be proved more easily here?

Yes, this is the most plausible place to attack pair dispersion.

Compared with the full window:

- there is only one Lucas channel;
- \(z_p\) is empirically very small;
- \(p,q\) are always in the CRT sparse regime;
- the mean is about one order of magnitude smaller.

A sufficient theorem would be:

\[
\sum_{n\le N}B_{top}(n)^2
\ll N.
\]

Equivalently,

\[
\sum_{p\ne q}
\left|
\#\{n\le N:n-p\in Z_p,n-q\in Z_q\}
-\frac{Nz_pz_q}{pq}
\right|
\ll N.
\]

This is a top-half HM2 theorem.

It is weaker than the full HM3 route and likely the best experimental target. It is not a consequence of the average bound on \(z_p\) alone.

The repository's previous CRT analysis applies unchanged: the obstruction is not the size of the expected term; it is possible coherent alignment of many sparse residue sets.

---

# 4. Does Farey spacing solve it?

No, but it is the right intuition to examine.

The top-half residues are
\[
r_p=n-p.
\]
Equivalently,
\[
\frac{r_p}{p}=\frac np-1.
\]

The quantities \(n/p\) for \(p\in(n/2,n]\) are indeed separated on a Farey scale. Neighboring primes have spacing roughly
\[
\frac{n}{p^2}\approx\frac1n.
\]

However, the event is not
\[
\frac{r_p}{p}\in I
\]
for a fixed interval \(I\). It is
\[
r_p\in Z_p,
\]
where the set \(Z_p\) changes with \(p\).

A malicious family could choose
\[
Z_p=\{n-p\}
\]
for every prime in the interval, producing a full aligned star while keeping
\[
z_p=1.
\]

Therefore Farey spacing alone cannot prove anything.

What would be needed is a statement that the Apéry zero sets \(Z_p\) behave independently of the affine trajectory \(n-p\). This is exactly the moving-target anti-concentration problem.

---

# 5. The best possible route

The top-half model suggests a cleaner intermediate theorem:

**Top-half atom-tail theorem.** For every \(N\),
\[
\max_{m\le N}
\#\{N/2<p\le N:m-p\in Z_p\}
=N^{o(1)}.
\]

Even a much weaker estimate
\[
O(N^{1/2+\epsilon})
\]
would already be enough for the top shell.

Possible tools:

1. **Top-half HM2:** exploit the single CRT channel.
2. **Mellin/tori:** use the existing marked toric coordinate for \(b_r\bmod p\).
3. **Large-prime divisor energy:** reinterpret hits as large primes dividing \(b_{n-p}\).
4. **Gap polynomials:** exploit that repeated hits impose multiple moving zero conditions.

The top-half model is therefore a good laboratory: it removes the quotient-digit complexity and isolates the true obstruction.

---

# Final answers

## 1. Is top-half sufficient?

No. It is a necessary shell of the full problem, not a replacement. It is a major simplification but does not control primes below \(n/2\).

## 2. Is the expected pair mass small?

Yes. The main term is \(O(n\lambda_{top}^2)\), numerically tiny. The difficulty is not the main term but cancellation of CRT discrepancies.

## 3. Is pair dispersion easier?

Very likely. The top-half shell is the cleanest HM2 target. It removes all leading-digit complications and has much smaller density.

## 4. Does Farey spacing give automatic equidistribution?

No. Spacing controls the sampling points, not the moving sets \(Z_p\). The missing ingredient is arithmetic independence between the Apéry zero sets and the affine residues \(n-p\).

The top-half model is therefore not the whole proof, but it is probably the correct first nontrivial attack surface for P3.2.
