# Q7074: Can palindromic CRT cancellation prove the third factorial moment?

## Short answer

The proposed reflection argument is a real structural phenomenon, but in its naive form it does not give the missing factor of `X`. The reason is that the CRT indicator error is not paired with its reflection in a way that produces an opposite sign. The reflected triple preserves membership in the Apéry zero sets, but the CRT cutoff region is not anti-symmetric under the reflection map.

The useful conclusion is weaker: palindromy can reduce the effective dimension of the CRT count and may improve constants, but it does not by itself force the required cancellation.

## CRT formulation

For primes `p,q,l` and residues

```
r_p in Z_p, r_q in Z_q, r_l in Z_l,
```

let `M` be the CRT solution in `[0,pql)`. The third factorial moment contains the count

```
#{ M < X^2 }.
```

The expected volume heuristic contributes

```
X^2/(p q l).
```

The error term is therefore

```
epsilon = 1_{M<X^2} - X^2/(p q l).
```

The difficulty is that the sign of the individual errors is not random enough under the available algebraic information. The desired estimate requires cancellation after summing over approximately `lambda^3 X^3` CRT configurations.

## Reflection symmetry

The Apéry zero set satisfies

```
r in Z_p  <=>  p-1-r in Z_p.
```

Hence a triple has a reflected triple

```
(r_p,r_q,r_l) -> (p-1-r_p,p-1-r_q,p-1-r_l).
```

However, if `M` is the CRT lift of the original triple, the reflected lift is not simply `C-M` with a fixed constant independent of the moduli. The congruences become

```
M' = -M - 1 (mod p),
M' = -M - 1 (mod q),
M' = -M - 1 (mod l),
```

so the reflection is centered around `-1/2` modulo the product modulus, not around `X^2` in the interval `[0,pql)`.

Therefore the implication

```
M<X^2  =>  M'>X^2
```

is false in general.

## What would be needed for a successful cancellation

A valid cancellation theorem would need a statement of the form

```
#{CRT triples with M<X^2 and M'<X^2}
```

is small, or an equidistribution statement for the CRT orbit inside the interval `[0,X^2]` after imposing the Apéry zero constraints.

The current palindromy only gives a pairing of residues; it does not give a pairing of signs.

## Possible salvage: use the pair sum

Instead of trying to pair individual errors, study

```
epsilon(M)+epsilon(M').
```

For a true anti-symmetry one would want

```
1_{M<X^2}+1_{M'<X^2} ~= 1.
```

But this requires information about the distribution of `M` relative to the CRT reflection center. Establishing such a statement is essentially a new equidistribution problem.

A promising route is to combine:

1. Apéry reflection `r -> p-1-r`;
2. the known small size of `Z_p`;
3. exponential sums over CRT lifts.

That would turn the cancellation question into a Fourier problem rather than a combinatorial pairing problem.

## Conclusion

The palindromic structure is not enough by itself to prove `(HM)_3`. It removes some asymmetry but does not create a sign-reversing involution on the CRT cutoff errors. The missing factor `X` requires an additional input: either quantitative equidistribution of the constrained CRT lifts or a genuinely stronger correlation estimate between the three Apéry zero sets.
