## 2. Exact proof of selector divisibility

\[

The primes are distinct, so `R|C`. Since `p_i|b_{h_i}`, write

\[
b_{h_i}=p_iq_i,
\qquad q_i\in\mathbf Z_{>0}.

Then

\[
C=\sum_i(R/p_i)p_iq_i=R\sum_iq_i.

This proves (1). Formula (2) follows because `R` is squarefree. Reducing `Q=sum q_i` modulo `p_i` gives (3).

## 6. Linear saturation theorem

### Theorem

Let `p_1,...,p_N` be distinct odd primes, `R=prod p_i`, and let

\[
L_A(x)=\sum_iA_ix_i.
\]

Assume the divisibility `p_j|L_A(x)` is to follow for every tuple satisfying

```text
p_i | x_i,
p_j does not divide x_i for j != i.
```

Then this universal divisibility holds for every `p_j` if and only if

\[
\boxed{R/p_i\mid A_i\quad\text{for every }i.}
\tag{16}
\]

### Proof

Sufficiency is immediate. For necessity, fix `j` and reduce modulo `p_j`. The own row vanishes, while each foreign row may vary through the nonzero residues. Vary one foreign residue between two distinct units, holding the rest fixed. The difference of the two universally zero sums is

\[
A_i(u-v)=0\pmod{p_j}.
\]

Choose `u-v!=0`, so `p_j|A_i`. This holds for all `j!=i`, hence `R/p_i|A_i`.

For sixteen primes, the universal coefficient lattice is

\[
\bigoplus_i(R/p_i)\mathbf Z e_i
\]

and has index

\[
\prod_i(R/p_i)=R^{15}.
\tag{17}
\]

Every universal linear selector is therefore

\[
R\sum_i c_i\frac{b_{h_i}}{p_i}.
\]

Cleared finite differences and Lagrange weights only change the `c_i`. If their coefficients do not contain `R/p_i`, target divisibility is not forced; if they do, the one `R` has returned.

This is the precise one-`R` Lagrange obstruction for the full packet.
