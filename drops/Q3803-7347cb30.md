# Verdict

The capacity amplification is mathematically sound, but its genuinely new content is narrower than the slogan “raise both carriers and gain an \(R\)-fold multiplicity theorem.”

For every integer \(R\ge 1\), replacing the lower and upper zero-occurrence carriers by \(V^R,U^R\) gives an exact **capacity-\(R\) edge-to-endpoint matching problem**. \[
\boxed{
D_{4,R}
 =\max_{F\subseteq E_4}
   \bigl(|F|-R|L(F)|-R|U(F)|\bigr)_+ .
}
\tag{1}
\]

Equivalently, after deleting exactly \(D_{4,R}\) rows, every remaining row can be oriented to one of its two zero occurrences so that every tagged occurrence receives at most \(R\) rows. This is the correct \(R\)-analogue of the \(R=1\) pseudoforest/Hall statement.

The valid q6 weighted inequality is

\[
\boxed{
\sum_{e\in E_4}\log p_e
 \le R(\log V+\log U)
      +D_{4,R}\,\max_{e\in E_4}\log p_e .
}
\tag{2}
\]

In the current macroscopic q6 shell, \(T/7<p_e<q_e<T/3\), so this becomes

\[
\boxed{
\sum_{e\in E_4}\log p_e
 \le O_J(RT^{5/3})+D_{4,R}\log(T/3).
}
\tag{3}
\]

and hence

\[
\boxed{
|E_4|
 \ll_J \frac{RT^{5/3}}{\log T}+D_{4,R}.
}
\tag{4}
\]

\[
\boxed{R=o\!\left(\frac{T^{1/3}}{\log T}\right).}
\tag{5}
\]

A convenient choice is

\[

\frac{T^{1/3}}{\log T\,\Omega(T)}
\right\rfloor,
\qquad \Omega(T)\to\infty,
\tag{6}
\]

\tag{8}

# 1. Exact capacity-​R Hall theorem

Let \(E_4\) be the surviving q6 far-row multiset under discussion. Each row \(e\in E_4\) has two **tagged occurrence anchors**:

\[
\ell(e)=L(e)=(p_e,x_e)\in\mathcal L,
\qquad
u(e)=U(e)=(q_e,u_e)\in\mathcal U,
\tag{13}
\]

where the tag records the characteristic and the actual zero index. The lower and upper copies are treated as disjoint vertex classes even if two numerical indices happen to agree.

For \(F\subseteq E_4\), write

\[
L(F)=\{L(e):e\in F\},
\qquad
U(F)=\{U(e):e\in F\}.
\tag{14}
\]

Now replace each occurrence vertex \(v\in\mathcal L\sqcup\mathcal U\) by \(R\) tagged clones

\[
(v,1),\ldots,(v,R).
\]

A row \(e\) is adjacent to all \(R\) clones of \(L(e)\) and all \(R\) clones of \(U(e)\). Hence for any row set \(F\), its clone-neighborhood has the **exact** cardinality

\[
|N_R(F)|=R|L(F)|+R|U(F)|.
\tag{15}
\]

Apply the deficiency form of Hall's theorem to this row-to-clone bipartite graph. If \(\nu_R\) is the maximum number of rows which can be matched to occurrence clones, then

\[
|E_4|-\nu_R
 =\max_{F\subseteq E_4}(|F|-|N_R(F)|)_+,
\]

which is exactly (1).

Therefore:

\[
\boxed{
D_{4,R}=\min\{|B|:
E_4\setminus B\text{ admits an endpoint assignment of load }\le R\}.
}
\tag{16}
\]

This is an equality, not merely an upper bound.

Equivalently there are a set \(B\subseteq E_4\) with

\[
|B|=D_{4,R}
\tag{17}
\]

and a map

\[
\phi:E_4\setminus B\to\mathcal L\sqcup\mathcal U
\tag{18}
\]

such that

\[
\phi(e)\in\{L(e),U(e)\}
\tag{19}
\]

and

\[
\#\phi^{-1}(v)\le R
\qquad\text{for every occurrence }v.
\tag{20}
\]

For \(R=1\), this is the ordinary edge-to-distinct-endpoint Hall theorem used in the pseudoforest discussion. For general \(R\), the correct object is an \(R\)-bounded orientation, not “a pseudoforest with \(R\) cycles.”

# 2. The weighted inequality: what is valid and what is not

The cardinality deficiency \(D_{4,R}\) by itself does **not** identify the lightest \(D_{4,R}\) rows. Therefore one must not write a weighted deletion estimate of the form

\[
\text{deleted weight}\le D_{4,R}\times\text{average row weight}
\]

without a separate argument.

There are two clean valid formulations.

## 2.1 Direct q6 logarithmic-weight formulation

Let

\[
w_e:=\log p_e.
\tag{21}
\]

For a matched row \(e\notin B\):

* if \(\phi(e)=L(e)=(p_e,x_e)\), then its weight is exactly the log-weight of that lower carrier occurrence;
* if \(\phi(e)=U(e)=(q_e,u_e)\), then \(q_e>p_e\), hence
  \[
  w_e=\log p_e\le\log q_e,
  \]
  so the upper carrier occurrence also pays the row weight.

Since each occurrence is used at most \(R\) times,

\[
\sum_{e\in E_4\setminus B}\log p_e
 \le R\sum_{\ell\in\mathcal L}\log p(\ell)
     +R\sum_{u\in\mathcal U}\log q(u)
 =R(\log V+\log U).
\tag{22}
\]

For the unmatched set, only the worst-row bound is automatic:

\[
\sum_{e\in B}\log p_e
 \le D_{4,R}\max_e\log p_e.
\tag{23}
\]

Adding gives (2).

In the current q6 shell, the delivered state uses

\[
T/7<p_e<q_e<T/3,
\tag{24}
\]

hence

\[
\log(T/7)|E_4|
\le \sum_{e\in E_4}\log p_e
\le R(\log V+\log U)+D_{4,R}\log(T/3).
\tag{25}
\]

With the stipulated occurrence-carrier height

\[
\log V+\log U=O_J(T^{5/3}),
\tag{26}
\]

this is exactly (3)-(4).

## 2.2 General nonnegative weights

There is also a useful layer-cake version which makes the weighted issue explicit. Let \(w_e\ge0\), put

\[
E_t=\{e\in E_4:w_e>t\},
\]

and define

\[
D_{4,R}(A)
 =\max_{F\subseteq A}
  (|F|-R|L(F)|-R|U(F)|)_+.
\tag{27}
\]

Since \(A\subseteq E_4\) implies \(D_{4,R}(A)\le D_{4,R}(E_4)\), Hall's inequality on \(E_t\) gives

\[
|E_t|
\le R|L(E_t)|+R|U(E_t)|+D_{4,R}.
\tag{28}
\]

Integrating in \(t\),

\[
\boxed{
\sum_e w_e
\le
R\sum_{\ell\in\mathcal L}\max_{e\ni\ell}w_e
+R\sum_{u\in\mathcal U}\max_{e\ni u}w_e
+D_{4,R}\,\|w\|_\infty.
}
\tag{29}
\]

For \(w_e=\log p_e\), the lower maxima equal \(\log p\), while an upper maximum is at most \(\log q\). Thus (29) specializes again to (2).

This is the safe weighted Hall statement. A sharper weighted deletion requires solving the weighted matching problem itself; it is not encoded by the cardinality deficiency alone.

# 4. Lower-prime multiplicity \(M_p\): exact consequence and non-consequence

Let

\[
E_p=\{e\in E_4:p_e=p\},
\qquad
M_p=|E_p|.
\tag{34}
\]

Apply (1) only to subfamilies of \(E_p\). Writing \(D_{p,R}\) for that restricted deficiency, we have

\[
D_{p,R}\le D_{4,R}
\tag{35}
\]

and

\[
\boxed{
M_p
\le R|L(E_p)|+R|U(E_p)|+D_{p,R}.
}
\tag{36}
\]

Since

\[
|L(E_p)|\le Z(p),
\tag{37}
\]

this yields the cross-characteristic expansion statement

\[
\boxed{
|U(E_p)|
\ge
\frac{M_p-D_{p,R}}R-Z(p).
}
\tag{38}
\]

(up to taking the obvious integer ceiling and positive part).

This is the strongest general statement about the **raw** \(M_p\) furnished by the two-sided Hall theorem: if a lower prime supports much more than \(RZ(p)\) row mass and those rows are not in the Hall deficiency, they must spread across many distinct upper zero occurrences.

What does **not** follow is

\[
M_p\le RZ(p)+D_{4,R}.
\tag{39 false}
\]

A purely graph-theoretic counterexample is a star with one lower occurrence and \(M\) pairwise distinct upper occurrence vertices. For \(R=1\), Hall deficiency is zero for every \(M\): orient every row to its distinct upper occurrence. Yet \(Z(p)\) could contribute only that one touched lower occurrence and \(M_p=M\) is arbitrary.

Therefore the two-sided capacity theorem does not replace the primewise fungible lower carrier of Q3799.

## 4.1 The separate one-sided \(V^R\) theorem

Q3799 already established the genuinely primewise statement

\[
v_p(V^R)=RZ(p).
\]

Because \(p\)-adic carrier capacity is fungible across all \(p\)-zero occurrences, independently of row endpoints, the exact primewise residual is

\[
\boxed{
\varepsilon_p^{(R)}=(M_p-RZ(p))_+.
}
\tag{40}
\]

and

\[
\sum_{e\in E_4}\log p_e
\le R\log V+\sum_p\varepsilon_p^{(R)}\log p.
\tag{41}
\]

This is **stronger for raw lower-prime multiplicity** than endpoint-respecting Hall matching, because it may assign a \(p\)-row to any unused \(p\)-zero occurrence, not necessarily one incident with that row.

Thus there are two different tools:

```text
V^R primewise fungible carrier:
    controls raw M_p by R Z(p), but forgets row endpoints.

V^R,U^R Hall carrier:
    controls endpoint-oriented occurrence loads by R,
    but does not pointwise control raw M_p.
```

They should not be identified.

# 6. Oriented stars \(k_{q,u}\)

Use the Hall matching after deleting \(B\), and orient each retained row toward its assigned occurrence \(\phi(e)\).

For an upper zero occurrence \((q,u)\), define its **oriented load**

\[
k^{\uparrow}_{q,u}
:=\#\{e\in E_4\setminus B:\phi(e)=(q,u)\}.
\tag{51}

Then by construction

\[
\boxed{k^{\uparrow}_{q,u}\le R.}
\tag{52}
\]

Similarly every lower occurrence \((p,x)\) has oriented load

\[
k^{\downarrow}_{p,x}\le R.
\tag{53}
\]

Consequently

\[
\boxed{
\sum_{u\in\mathcal Z_q}k^{\uparrow}_{q,u}
\le RZ(q),
\qquad
\sum_{x\in\mathcal Z_p}k^{\downarrow}_{p,x}
\le RZ(p).
}
\tag{54}

These are exact and simultaneous across all characteristics.

\[
d_{q,u}=\#\{e:U(e)=(q,u)\},

For a raw star \(S(q,u)\), the exact Hall inequality gives instead

\[
|S(q,u)|
\le R\bigl(|L(S(q,u))|+1\bigr)+D_{4,R}(S(q,u)).

Thus, outside the deficiency, a large raw upper star forces many distinct lower occurrence anchors:

\[
|L(S(q,u))|
\ge \frac{|S(q,u)|-D_{4,R}(S(q,u))}{R}-1.
\tag{56}
\]

This spread statement is often more useful than a false raw-star cap.

# 7. Row-anchor graph interpretation

Let \(G_4\) be the bipartite row-anchor multigraph with vertex set

\[
\mathcal L\sqcup\mathcal U
\]

and one edge for every row \(e\), joining \(L(e)\) to \(U(e)\).

After deleting the \(D_{4,R}\) exceptional rows, (1) says that every edge subfamily \(F\) satisfies

\[
\boxed{
|F|\le R|V(F)|
=R\bigl(|L(F)|+|U(F)|\bigr).
}
\tag{57}
\]

This is precisely the finite-multigraph criterion for an orientation of all surviving edges with indegree at most \(R\). In graph language, the surviving row-anchor graph has

\[
\boxed{\text{pseudoarboricity}\le R.}
\tag{58}
\]

For \(R=1\), each connected component is a pseudoforest and one recovers the usual “at most one cycle per component” statement.

For \(R>1\), do **not** translate (58) into a claim that each component has at most \(R\) cycles. A component may have cycle rank growing linearly with its number of vertices while still satisfying (57). The exact invariant is edge density / bounded indegree orientation.

One immediate corollary is that every surviving subgraph has average degree at most \(2R\), hence has a vertex of degree at most \(2R\). This does not bound the maximum raw degree.

\boxed{
\exists F:\quad

\tag{59}

The total excess of the worst such family is \(D_{4,R}\). This is a **joint lower/upper concentration** statement and is not reducible to \(M_p\) or \(Z(p)\) alone.

# 8. Relation to a collision second moment

There is a useful deterministic comparison which explains why a sufficiently strong already-proved row-anchor collision second moment can make the \(R\)-Hall deficiency asymptotically redundant.

For any row-anchor graph \(H\), define the shared-anchor collision count

\[
\mathcal C(H)
:=\sum_{v\in V(H)}\binom{d_H(v)}2.
\tag{60}
\]

Take a row subfamily \(F\) with

\[
e:=|F|,
\qquad
v:=|L(F)|+|U(F)|,
\qquad
e=Rv+s,\quad s>0.
\]

Since \(\sum_v d(v)=2e\), Cauchy gives

\[
\begin{aligned}
\mathcal C(F)
&=\frac12\left(\sum_v d(v)^2-2e\right)\\
&\ge \frac{2e^2}{v}-e\\
&=(2R^2-R)v+(4R-1)s+\frac{2s^2}{v}\\
&\ge(4R-1)s.
\end{aligned}
\tag{61}
\]

Therefore

\[
\boxed{
D_{4,R}
\le \frac{\mathcal C(E_4)}{4R-1}.
}
\tag{62}
\]

Likewise, for raw star loads \(d_v\), the exact integer inequality

\[
\binom{k}{2}\ge(2R-1)(k-R)
\qquad(k>R)
\tag{63}
\]

holds because the difference is

\[
\frac{(k-2R)(k-2R+1)}2\ge0.
\]

Thus

\[
\boxed{
\sum_v(d_v-R)_+
\le\frac1{2R-1}
\sum_v\binom{d_v}{2}.
}
\tag{64}
\]

These two formulas are the right way to compare an \(R\)-capacity theorem with an existing **collision second moment on the same row-anchor graph**.

If it is, then (62)-(64) show that the amplified Hall carrier gives at most an additional \(1/R\)-type deterministic conversion of that already-proved collision budget; it does not create a new arithmetic estimate.

* any other \(A_p\ll Z(p)(Z(p)-1)\) quantity.

Those are already subcritical at \(R=1\) on the visible bank.

Nor is the primewise formula

\[
(M_p-RZ(p))_+
\]

new here: that is already the one-sided \(V^R\) observation in Q3799.

The genuinely new statement is instead:

\[
\boxed{
\text{after }D_{4,R}\text{ deletions, there is one global orientation}
\text{ with every lower and upper occurrence load }\le R.
}
\tag{71}
\]

This simultaneously coordinates the two characteristics and localizes the only remaining combinatorial obstruction to a dense row-anchor subfamily (59).

If the local Q32 theorem has already proved that **this very shared-anchor collision mass** is subcritical, then even \(D_{4,R}\) is already subcritical by (62) with \(R=1\), and the new result is purely a cleaner structural certificate, not a stronger asymptotic deletion.

# 10. What the amplified carrier does not prove

The following implications are invalid without additional arithmetic input.

### 10.1 No raw \(M_p\le RZ(p)\) from two-sided Hall

As explained in Section 4, upper anchors can absorb arbitrarily many rows from one lower prime if they are sufficiently distinct.

### 10.2 No raw \(k_{q,u}\le R\)

Only the **oriented assigned load** is at most \(R\). Raw degree can be much larger.

### 10.3 No new pointwise zero-count theorem

The capacity construction does not improve the banked pointwise \(Z(p)\ll p^{2/3}\) or the average factorial moment. It merely says that a one-sided carrier residual forces \(Z(p)\gg R\), with the exact constants in (43)/(45).

### 10.4 No closure from small carrier height alone

The height condition (5) only says the matched part is cheap. The theorem still needs

\[
D_{4,R}=o(T^2/(\log T)^2)
\]

or another argument paying the unmatched rows.

### 10.5 No arithmetic independence from the matching

Hall matching is deterministic combinatorics. It does not create independent upper-prime zero conditions, a new resultant, or any product-probability saving.

# 11. Strongest clean theorem package

A theorem-ready formulation is the following.

```text
Capacity-amplified q6 occurrence-carrier lemma.

Fix a finite q6 far-row multiset E4.  For every row e let
L(e) be its tagged lower zero occurrence and U(e) its tagged
upper zero occurrence.  Let V and U be the corresponding products
of the lower and upper prime labels, one factor per tagged occurrence.
Assume q_e >= p_e for every row.

For every integer R >= 1 define

  D_(4,R) = max_{F subset E4}
              (|F|-R|L(F)|-R|U(F)|)_+.

Then:

(1) D_(4,R) is exactly the minimum number of rows which must be
    deleted so that the remaining rows admit an assignment to an
    incident lower/upper occurrence with load at most R at every
    occurrence.

(2) For w_e=log p_e,

      sum_e w_e
        <= R(log V+log U)+D_(4,R) max_e w_e.

(3) In the q6 shell T/7 < p_e < q_e < T/3 and with
    log V+log U = O_J(T^(5/3)),

      sum_e log p_e
        <= O_J(R T^(5/3))+D_(4,R) log(T/3),

      |E4|
        <<_J R T^(5/3)/log T + D_(4,R).

(4) Hence any R=o(T^(1/3)/log T) is carrier-admissible; if also

      D_(4,R)=o(T^2/(log T)^2),

    then the full weighted row mass is o_J(T^2/log T).

(5) After the deletion, the row-anchor multigraph has an orientation
    of indegree <=R at every tagged zero occurrence; equivalently its
    pseudoarboricity is <=R.
```

This is the exact reusable statement I would bank.

# 12. Bottom line

The proposed \(V^R,U^R\) amplification **passes**, with the exact Hall deficiency (1), the weighted inequality (2)-(3), and the sharp carrier range (5).

The main corrections are:

1. the unmatched-row target is \(o(T^2/(\log T)^2)\), because every far row carries weight \(\asymp\log T\);
2. the carrier-paid row count is \(O(RT^{5/3}/\log T)\), not \(O(RT^{5/3})\);
3. \(R=o(T^{1/3}/\log T)\), not merely \(o(T^{1/3})\), is required for the weighted \(o(T^2/\log T)\) goal;
4. two-sided Hall does **not** imply raw \(M_p\le RZ(p)\) or raw star \(k_{q,u}\le R\); it gives an orientation with occurrence loads at most \(R\);
5. with the full current reflected row multiplicity, \(M_p>RZ(p)\) only forces \(Z(p)>1+2R/3\). The older \(R+1\) threshold requires prior collapse of the two plus orientations;
6. every \(O(Z(p)^2)\) collision/excess sector is already subcritical from the banked second factorial moment (65), so re-proving that deletion with \(R>1\) is not new.

The only genuinely new strength is the global **cross-characteristic bounded-load orientation / Hall-density localization**. If a future theorem is needed, it should target the weighted dense core

\[
\boxed{
D_{4,R}\log T
\quad\text{or, more structurally, row subsets }F
\text{ with }
|F|>R(|L(F)|+|U(F)|),
}
\]

not another \(O(Z(p)^2)\) collision estimate already covered by the moderate-load second-moment bank.
