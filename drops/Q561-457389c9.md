# Pair-zero bounds from Dwork congruences and \(p\)-adic structure

## Executive verdict

Dwork congruences give a strong and completely useful **vertical** statement: a zero at an index \(r\) propagates to \(rp,rp^2,\ldots\), and low \(p\)-adic valuations stabilize along that tower. They do **not**, by themselves, compare two distinct residues \(r,s\in\{0,\ldots,p-1\}\), so they do not directly control

\[
D_p=\binom{u_p}{2},
\qquad
u_p:=\mathbf 1_{\{p\mid b_{(p-1)/2}\}},
\qquad
u_p^{\rm pair}:=\frac{Z(p)-\nu_p}{2}.
\]

Here I write \(u_p=\nu_p^{\rm pair}\) when discussing Target A; on ordinary primes this is exactly the question's \(u_p=Z(p)/2\). The central correction is necessary only for the rare self-paired zero at \(j=(p-1)/2\).

The proposed Strassmann route has two separate obstructions.

1. The displayed function with \(\exp(2\pi i rs/p)\) is a complex **additive Fourier transform**, not a \(p\)-adic interpolation of the Mellin coefficients \(b_r\). Its zeros are not \(Z_p\).
2. The relevant tame characters \(\omega^j\), \(0\le j<p-1\), lie one per connected component of \(p\)-adic weight space. Dwork/Weierstrass rigidity is vertical inside one component; \(Z_p\) is horizontal and samples all \(p-1\) components once. A bounded zero count on each component still permits \(O(p)\) total zeros.

The unit-root route is potentially real, but the relevant object is not one classical eigenvalue \(\alpha_p\). One needs the family of **Kummer-twisted crystals indexed by \(j\)**. A unique unit root in the \(j\)-twisted Frobenius module would force the corresponding normalized Mellin trace to be a \(p\)-adic unit, so zeros are contained in the exceptional-twist locus. Proving that only \(O(1)\) twists are exceptional would imply the much stronger pointwise bound \(Z(p)=O(1)\). Target A asks only for an averaged second factorial moment of that exceptional locus.

Finally, the proposed empirical test “are distinct zeros congruent modulo \(p^k\)?” is vacuous in the base window: if \(0\le r<s<p\), then \(v_p(s-r)=0\). The meaningful \(p\)-adic experiment is vertical—study \(v_p(b_{rp^m})\)—while the meaningful same-prime pair experiments are horizontal—gaps, tame-character ratios, normalized unit cancellations, and twisted Newton slopes.

The present data are already strikingly aligned with Target A. From `problems/3.2/zp_million_output.txt`, among all \(78{,}496\) primes \(5\le p\le10^6\), the noncentral pair count has

\[
\frac1{78496}\sum_p u_p
 =\frac{39231}{78496}=0.499783\ldots,
\]

and

\[
\frac1{78496}\sum_p\binom{u_p}{2}
 =\frac{9771}{78496}=0.124478\ldots,
\]

almost exactly the Poisson\((1/2)\) predictions \(1/2\) and \(1/8\). Thus the natural theorem is a **two-twist crystalline Mellin anti-concentration estimate**, not a scalar Strassmann theorem.

## (A) What Dwork congruences actually imply

### A.1. Exact vertical propagation

For \(p\ge5\), the Beukers–Gessel type supercongruence is

\[
b_{mp^s}\equiv b_{mp^{s-1}}\pmod{p^{3s}}
\qquad(s\ge1).
\tag{1}
\]

In particular,

\[
b_{rp^s}\equiv b_r\pmod p,
\qquad
p\mid b_{rp^s}\Longleftrightarrow p\mid b_r.
\tag{2}
\]

So every base zero produces a complete vertical tower

\[
r,\;rp,\;rp^2,\ldots.
\]

Conversely, divisibility at a tower point descends all the way to the base after stripping trailing base-\(p\) zero digits.

There is also a useful valuation statement. Put

\[
e_s=v_p(b_{mp^s}).
\]

Writing \(b_{mp^s}=b_{mp^{s-1}}+p^{3s}c_s\), one gets

\[
e_{s-1}<3s\quad\Longrightarrow\quad e_s=e_{s-1},
\tag{3}
\]

whereas \(e_{s-1}\ge3s\) only implies \(e_s\ge3s\). In particular, if \(v_p(b_m)<3\), then

\[
v_p(b_{mp^s})=v_p(b_m)
\qquad\text{for every }s\ge0.
\tag{4}
\]

This is genuine \(p\)-adic rigidity and is worth exploiting when constructing integral Frobenius normalizations.

### A.2. The question's premise \(r=mp\) does not occur inside \(Z_p\)

The base zero set is

\[
Z_p=\{0\le r<p:p\mid b_r\}.
\]

If \(r=mp\) and \(0\le r<p\), then \(r=0\). But \(b_0=1\), so \(0\notin Z_p\). Thus no nontrivial element of the base-window zero set is divisible by \(p\). Dwork's index-scaling congruence necessarily leaves the window \([0,p-1]\); it does not relate two elements of \(Z_p\).

### A.3. Translations \(r+kp\) are controlled by Lucas, not by (1)

For \(0\le r<p\), the Apéry Lucas congruence gives

\[
b_{kp+r}\equiv b_k b_r\pmod p.
\tag{5}
\]

Consequently:

* if \(r\in Z_p\), then \(p\mid b_{r+kp}\) for every \(k\ge0\);
* if \(r\notin Z_p\), then \(p\mid b_{r+kp}\) exactly when \(p\mid b_k\);
* if \(n=\sum_i n_i p^i\), then
  \[
  b_n\equiv\prod_i b_{n_i}\pmod p,
  \qquad
  p\mid b_n\Longleftrightarrow \text{some digit }n_i\in Z_p.
  \tag{6}
  \]

This gives the exact count already recorded in `proof.tex`:

\[
\#\{0\le n<p^s:p\mid b_n\}
 =p^s-(p-Z(p))^s.
\tag{7}
\]

Thus Dwork plus Lucas describes how the base set replicates through the \(p\)-adic digit tree. It does not constrain the initial set of marked digits \(Z_p\).

### A.4. Why this cannot directly bound \(D_p\)

For \(0\le r<p-1\),

\[
rp^s\equiv r\pmod{p-1}.
\tag{8}
\]

The corresponding tame Kummer character therefore remains \(\omega^r\). The Dwork tower is vertical over **one fixed tame branch**. By contrast,

\[
D_p
 =\sum_{\substack{r<s\\r,s\text{ lower-half orbit representatives}}}
  \mathbf1_{\{p\mid b_r\}}
  \mathbf1_{\{p\mid b_s\}}
\tag{9}
\]

counts simultaneous vanishing on two different tame branches. No estimate for (9) follows from the scalar congruence (1) unless one adds a theorem coupling distinct branches.

The right interpretation is therefore:

> Dwork congruences are normalization and vertical-control machinery. The missing arithmetic is horizontal cancellation among distinct tame twists.

## (B) Can \(Z_p\) be the zero set of a \(p\)-adic analytic function?

### B.1. The proposed \(B_p(s)\) is not the required interpolation

The expression

\[
B_p(s)=\sum_r b_r\exp(2\pi i rs/p)
\tag{10}
\]

has three problems.

First, \(\exp(2\pi i/p)\) is complex, not \(p\)-adic. Replacing it by a primitive \(p\)-th root \(\zeta_p\in\mathbf C_p\) gives a finite additive Fourier transform, but does not repair the next two problems.

Second, \(s\mapsto\sum_r b_r\zeta_p^{rs}\) is the Fourier transform of the vector \((b_r)\). It does not take the value \(b_s\), and its zero set need not have any relation to the indices at which \(b_s=0\). Fourier inversion recovers the coefficients only after summing all transform values; it does not identify coefficient zeros with transform zeros.

Third, the Apéry formula in the project is a **multiplicative Mellin transform** on \(\mathbf F_p^	imes\):

\[
b_j=-\sum_{t\in\mathbf F_p^	imes}A_p(t)t^{-j}
\qquad(1\le j\le p-2),
\tag{11}
\]

where \(A_p(t)\) is the Hasse–Witt/trace function. The index group has order \(p-1\), not \(p\). An additive character on \(\mathbf Z/p\mathbf Z\) is the wrong dual group.

A measure-theoretic reformulation does not change this. The Amice or Mellin transform of a measure produces its transform values; zeros of the transform are not zeros of the atoms or coefficients.

### B.2. The correct \(p\)-adic parameter space has \(p-1\) branches

The natural object is the twisted Mellin trace

\[
\mathscr M_p(\chi)
 =\operatorname{Tr}\!\left(
   \Phi_p\mid
   H^1_{\mathrm{rig},c}
   (U,\mathcal V\otimes\mathcal K_\chi)
  \right),
\tag{12}
\]

with

\[
b_j\equiv u_{p,j}\mathscr M_p(\omega^{-j})\pmod p
\tag{13}
\]

for a normalization unit \(u_{p,j}\), once the integral lattice and conventions are fixed.

The \(p\)-adic weight space is

\[
\mathcal W_p
 =\operatorname{Hom}_{\rm cont}(\mathbf Z_p^	imes,\mathbf C_p^	imes)
 =\coprod_{a\in\mathbf Z/(p-1)\mathbf Z}\mathcal W_{p,a},
\tag{14}
\]

where a character is written

\[
\kappa(x)=\omega(x)^a\langle x\rangle^s.
\]

The \(p-1\) tame characters \(\omega^j\) occurring in \(Z_p\) are the points with wild coordinate \(s=0\), one on each component \(\mathcal W_{p,j}\). Thus the horizontal sample

\[
\{\omega^j:0\le j<p-1\}
\tag{15}
\]

contains no two points on the same analytic disk.

This is the branch obstruction already isolated in §14 of `proof.tex`. Strassmann or Weierstrass preparation can control the number of zeros of a nonzero analytic function **within one disk**. Even a bound of one zero per disk gives \(p-1\) zeros after summing over all components.

For the naive finite-field Mellin sum, extension in the wild direction is even more degenerate: restriction of a weight character to the Teichmüller group \(\mu_{p-1}\) depends only on \(a\), so the finite sum is constant along each wild disk. A nontrivial vertical family must come from a deeper Dwork tower, not merely from re-evaluating the same \(\mathbf F_p^	imes\)-sum.

### B.3. Exact zeros versus divisibility zeros

Strassmann bounds points at which an analytic function is **exactly zero**. The event here is

\[
v_p(\mathscr M_p(\omega^j))>0,
\tag{16}
\]

not \(\mathscr M_p(\omega^j)=0\) in \(\mathbf C_p\). These are very different. The constant function \(F(s)=p\), for example, has no analytic zeros but is divisible by \(p\) at every point.

To use Weierstrass preparation one would need an integral analytic family whose reduction modulo \(p\) is nonzero and has uniformly bounded Weierstrass degree. Establishing that is already essentially the desired crystalline anti-concentration theorem; it does not follow from analyticity alone.

### B.4. Artificial interpolation gives only a linear bound

One can always interpolate the \(p-1\) values \(b_j\bmod p\) by a polynomial or Laurent polynomial of degree \(O(p)\). Strassmann would then return only \(O(p)\), which is tautological.

The project contains a sharper obstruction: the direct unnormalized tame-character interpolation has Laurent degree at least

\[
\frac{p-7}{4},
\tag{17}
\]

using the Sym\(^2\) factorization and the support size of the canonical interpolation. Thus the hoped-for bounded Newton polygon is not hidden in the obvious interpolation. A successful argument would require a genuinely nontrivial Gauss/Jacobi/unit-root normalization that collapses the horizontal complexity.

### B.5. The termwise Newton polygon is already known not to detect zeros

`problems/3.2/apery_mellin_carry_polygon.tex` gives the exact Morita form

\[
b_j=\sum_{k=0}^j p^{2\epsilon_{j,k}}U_{p,j,k}^2,
\qquad
\epsilon_{j,k}=\mathbf1_{\{j+k\ge p\}},
\qquad
U_{p,j,k}\in\mathbf Z_p^	imes.
\tag{18}
\]

Exactly

\[
1+\min(j,p-1-j)
\tag{19}
\]

terms have minimum valuation zero; every remaining term has valuation two. Hence every interior index \(1\le j\le p-2\) has at least two minimum-slope unit terms, and

\[
p\mid b_j
\Longleftrightarrow
\Theta_{p,j}:=
\sum_{k=0}^{\min(j,p-1-j)}\overline U_{p,j,k}^{\,2}=0
\quad\text{in }\mathbf F_p.
\tag{20}
\]

This is the exact horizontal unit-cancellation problem. The valuation polygon itself contains no separator: at \(j=5\), the complete termwise valuation vector is identical for \(p=11\) and \(p=13\), yet \(11\mid b_5\) and \(13\nmid b_5\). The Jacobi-skeleton calculation in `lemmaA_result.tex` reaches the same conclusion: the unique-minimum criterion never triggers on an interior tame character, and the surviving minimum terms reconstruct the original Apéry sum.

Therefore the correct verdict for Strassmann is:

> Analyticity and Newton slopes can organize the problem, but they do not bound \(Z_p\) until one proves a new theorem controlling the residues of the normalized unit terms across tame branches.

### B.6. A clean sufficient analytic theorem

A bounded tame-Hasse polynomial would solve the problem. Namely, suppose there were an absolute \(D\), units \(u_{p,j}\in\mathbf F_p^	imes\), and nonzero Laurent polynomials \(Q_p(X)\) of degree at most \(D\) such that

\[
b_j=u_{p,j}Q_p(\omega^j)
\qquad\text{in }\mathbf F_p
\tag{21}
\]

for all nontrivial tame characters. Then \(Z(p)\le2D+O(1)\).

The direct normalization does not have this property by (17). Thus (21) is not a repackaging of known facts; it precisely identifies the missing collapse. For Target A one may seek an averaged two-character version rather than a pointwise degree bound.

## (C) What the unit-root splitting can and cannot control

### C.1. A pointwise unit-root function does not control Mellin sparsity

Suppose the ordinary fibers of the Apéry K3 family have a unit-root eigenvalue \(\alpha_p(t)\in\mathbf Z_p^	imes\). Pointwise unitness says

\[
v_p(\alpha_p(t))=0.
\]

It does not imply that the Mellin coefficients of \(t\mapsto\alpha_p(t)\) are nonzero. A constant unit-valued function is the extreme counterexample: all its nontrivial Mellin coefficients vanish. More generally, nonvanishing of a function and nonvanishing of its Fourier coefficients are logically unrelated without an anti-concentration or monodromy theorem.

Thus the ordinary unit-root piece of the **fiber family** does not by itself bound \(Z(p)\).

### C.2. The relevant sufficient condition is a unique unit root after twisting

For each tame character \(\chi=\omega^{-j}\), consider the global Kummer-twisted rigid cohomology module

\[
\mathcal H_{p,j}
 =H^1_{\mathrm{rig},c}
   (U,\mathcal V\otimes\mathcal K_{\omega^{-j}}).
\tag{22}
\]

Assume the integral normalization is such that its Frobenius trace reduces to \(b_j\) up to a unit. If \(\Phi_{p,j}\) has exactly one slope-zero eigenvalue and every other eigenvalue has positive slope, then

\[
\operatorname{Tr}(\Phi_{p,j})
 \equiv \alpha_{p,j}\not\equiv0\pmod p.
\tag{23}
\]

Therefore

\[
p\mid b_j
\quad\Longrightarrow\quad
\mathcal H_{p,j}
\text{ does not have a unique unit root}.
\tag{24}
\]

This is a valid and strong sufficient route. It is not yet a theorem for the Apéry twists, and bounded rank/conductor alone cannot imply it: the Jacobi counterexample in `proof.tex` shows that a fixed-complexity family can have a positive proportion of nonunit Mellin twists.

### C.3. One classical \(\alpha_p\) controls only a special branch

The classical weight-four modular eigenvalue satisfies the special midpoint congruence

\[
b_{(p-1)/2}\equiv a_p(f)\pmod p.
\tag{25}
\]

This explains the exceptional self-paired central zero at nonordinary primes. It does not control the other \(p-2\) Mellin coefficients. Noncentral zeros correspond to distinct Kummer twists and require the collection

\[
\alpha_{p,j},
\qquad 1\le j\le p-2,
\tag{26}
\]

or an equivalent branch-coupled Frobenius object. A single untwisted eigenvalue \(\alpha_p\) cannot determine their density.

### C.4. The exact Target A formulation in crystalline language

Choose one representative from each noncentral reflection orbit \(j\leftrightarrow p-1-j\), for example

\[
1\le j<\frac{p-1}{2}.
\]

Then Target A is the estimate

\[
\boxed{
\sum_{p\le X}
\sum_{1\le r<s<(p-1)/2}
\mathbf1_{\{v_p(\mathscr M_{p,r})>0\}}
\mathbf1_{\{v_p(\mathscr M_{p,s})>0\}}
\ll \pi(X).
}
\tag{TCMA\(_2\)}
\]

I would name this **two-twist crystalline Mellin anti-concentration**. It is exactly

\[
\sum_{p\le X}\binom{u_p}{2}\ll\pi(X),
\tag{27}
\]

up to the central correction.

A stronger but cleaner sufficient theorem is

\[
\#\{j:\mathcal H_{p,j}\text{ lacks a unique unit root}\}=O(1)
\tag{28}
\]

for every \(p\), which would give \(Z(p)=O(1)\). But (TCMA\(_2\)) only asks for the average number of unordered pairs of bad twists to be bounded. It permits rare primes with several zero pairs, exactly as the data show.

This distinction matters strategically. The project should not insist on proving a pointwise uniform zero bound that is probably false in the long run; the Poisson model predicts \(\max_{p\le X}Z(p)\sim2\log\log X\). The second factorial moment is the right stable target.

### C.5. Where Dwork can still enter

Dwork theory can supply:

1. an integral Frobenius lattice for each twist;
2. a canonical normalization of \(\mathscr M_{p,j}\);
3. control of slope-zero versus positive-slope pieces;
4. congruences between deeper wild levels on a fixed tame branch.

What it does not supply automatically is a relation between the reductions of the slope-zero traces for two different tame characters. The missing step is a **branch-coupling theorem**—for example, a global Frobenius matrix over a tame parameter algebra whose reduction has controlled two-point vanishing. Without that extra structure, the scalar Dwork congruence cannot see \(D_p\).

## (D) What should be computed

### D.1. Base-window \(p\)-adic clustering is impossible

If \(r\ne s\) are both in \(\{0,\ldots,p-1\}\), then

\[
0<|r-s|<p,
\qquad
v_p(r-s)=0.
\tag{29}
\]

Therefore distinct zeros can never satisfy

\[
r\equiv s\pmod{p^k}
\qquad(k\ge1).
\]

Likewise, a statement \(r\equiv r_0\pmod{p^k}\) inside the base window merely singles out one residue. There is no nontrivial \(p\)-adic clustering statistic on \(Z_p\) itself.

Clustering modulo a fixed small prime \(\ell\ne p\) is a legitimate finite-statistics question, but it is not \(p\)-adic. It must be conditioned on \(p\bmod\ell\), because the forced reflection \(r\mapsto p-1-r\) already creates residue-class correlations.

### D.2. The genuine vertical experiment

For each \(r\in Z_p\), compute

\[
v_p(b_r),\quad
v_p(b_{rp}),\quad
v_p(b_{rp^2}),\ldots.
\tag{30}
\]

The predictions from (1) are:

* divisibility persists at every level;
* if \(v_p(b_r)<3\), the valuation is constant on the whole tower;
* more generally, valuation changes can occur only at the thresholds \(3,6,9,\ldots\).

One should also verify the Lucas cylinders

\[
b_{r+pk}\equiv0\pmod p
\qquad(r\in Z_p)
\tag{31}
\]

and, if interested in higher divisibility, classify

\[
Z_{p,m}^{(a)}
 =\{n\bmod p^m:v_p(b_n)\ge a\}.
\tag{32}
\]

This is where a genuine Hensel/Dwork tree may emerge. It is a different object from the base set \(Z_p\).

### D.3. The meaningful same-prime pair forensics

For Target A, use the lower-half representatives

\[
R_p=\{1\le r<(p-1)/2:p\mid b_r\}.
\]

For primes with \(|R_p|\ge2\), record:

1. **Gap data.** For \(r<s\), set \(h=s-r\), and test both fixed small gaps and normalized gaps \(h/(p-1)\). Every actual pair satisfies the gap-polynomial certificate \(N_h(r)=0\pmod p\); this connects directly to the existing recurrence machinery.
2. **Tame branch ratio.** Record the order of \(\omega^{s-r}\):
   \[
   \operatorname{ord}(\omega^{s-r})
   =\frac{p-1}{\gcd(s-r,p-1)}.
   \tag{33}
   \]
   An excess of small-order ratios would be real evidence that different zero branches are coupled through a low-order Kummer relation.
3. **Unit-cancellation fingerprints.** For every zero compute the minimum-unit vector or summaries of
   \[
   \Theta_{p,r}
   =\sum_{k=0}^{\min(r,p-1-r)}\overline U_{p,r,k}^{\,2}.
   \tag{34}
   \]
   For a pair \(r,s\), compare the two normalized unit packets: common multiplicative symmetries, correlated partial sums, and shared Gauss/Jacobi factors are more informative than the identical carry polygon.
4. **Twisted slope data.** When a crystalline implementation is available, record the Newton polygon of each \(\mathcal H_{p,r}\), the dimension of its slope-zero part, and the residue of its unit-root trace. The key empirical question is whether two zeros usually arise from two genuinely nonordinary twists or from cancellation inside ordinary slope-zero blocks.
5. **Correct null model.** Condition on the observed \(u_p\), reflection symmetry, the central-zero status, and the no-consecutive-zero constraint. Then place the \(u_p\) lower-half representatives uniformly. This avoids mistaking deterministic palindromic structure for clustering.

`scripts/e1_zero_forensics.py` already implements much of the correct null framework: it preserves reflection pairs, center status, and no-adjacency, and compares normalized positions, low-denominator rational neighborhoods, and distributional statistics. The most useful additions are the branch-ratio order (33), the gap-polynomial label, and the vertical valuation tower (30).

### D.4. Existing data already compute the second factorial moment

The million-prime histogram is

| \(Z(p)\) | number of primes | noncentral \(u_p\) | \(inom{u_p}{2}\) contribution per prime |
|---:|---:|---:|---:|
| 0 | 47,632 | 0 | 0 |
| 1 | 2 | 0 after central correction | 0 |
| 2 | 23,730 | 1 | 0 |
| 4 | 6,045 | 2 | 1 |
| 6 | 951 | 3 | 3 |
| 8 | 123 | 4 | 6 |
| 10 | 12 | 5 | 10 |
| 12 | 1 | 6 | 15 |

Hence

\[
\sum_{p\le10^6}u_p
 =23730+2(6045)+3(951)+4(123)+5(12)+6
 =39231,
\tag{35}
\]

and

\[
\sum_{p\le10^6}\binom{u_p}{2}
 =6045+3(951)+6(123)+10(12)+15
 =9771.
\tag{36}
\]

For a Poisson random variable \(U\sim\mathrm{Poisson}(1/2)\),

\[
\mathbf E U=\frac12,
\qquad
\mathbf E\binom U2=\frac{(1/2)^2}{2}=\frac18.
\tag{37}
\]

The observed values \(0.499783\ldots\) and \(0.124478\ldots\) are exceptionally close. This is direct evidence for Target A itself, not merely for M1. It also shows why an \(O(1)\)-exceptional-twist theorem may be unnecessarily strong: rare \(u_p=4,5,6\) events occur, but with precisely the frequency expected from a bounded second factorial moment.

## Recommended route for Target A

I would not invest further effort in constructing a scalar \(p\)-adic interpolation of \(j\mapsto b_j\) and applying Strassmann. The branch count, the exact-zero/divisibility mismatch, and the explicit linear-complexity obstruction make that route structurally misaligned.

The most promising Dwork-based program is instead:

### Step 1: Build the correctly normalized twisted Frobenius trace

For every tame character orbit \([j]=\{j,p-1-j\}\), define an integral quantity

\[
T_{p,[j]}\in\mathbf Z_p
\]

such that

\[
T_{p,[j]}\equiv c_{p,j}b_j\pmod p,
\qquad c_{p,j}\in\mathbf Z_p^	imes,
\tag{38}
\]

and whose slope-zero contribution is canonical. Dwork congruences are useful here: they should rigidify the lattice and remove normalization ambiguity.

### Step 2: Separate slope failure from unit cancellation

Partition zero twists into:

* twists whose Frobenius module lacks a unique unit root;
* twists with a slope-zero block of dimension at least two whose unit traces cancel modulo \(p\).

The exact Morita/Jacobi computations show that a termwise expansion always has many minimum units, but that expansion is not itself the crystalline slope decomposition. Computing the actual twisted Newton polygons is therefore decisive.

### Step 3: Prove a two-twist estimate, not a pointwise zero bound

The theorem to target is (TCMA\(_2\)). A sufficient version is

\[
\sum_{p\le X}
\binom{\#E_p}{2}\ll\pi(X),
\qquad
E_p=\{[j]:\mathcal H_{p,j}\text{ lacks a unique unit root}\},
\tag{39}
\]

plus the analogous estimate for cancellations inside the ordinary slope-zero locus. This is precisely the same-prime pair question. It is logically independent of AKD\(_3\), which concerns cross-prime decorrelation.

### Step 4: Search for branch coupling, not vertical regularity

The breakthrough object would be a Frobenius block over a tame parameter algebra that simultaneously contains all \(T_{p,[j]}\) and imposes algebraic relations between distinct branches. Candidate invariants to inspect computationally are:

* resultants or minors relating the \(j\)- and \(k\)-twisted unit-root blocks;
* dependence on the ratio character \(\omega^{j-k}\);
* low-order Kummer quotients;
* common factors in normalized Jacobi/Gross–Koblitz unit packets;
* a bounded-degree relation after dividing by explicit Gauss factors.

Without such a branch-coupling object, Dwork congruences remain vertical and cannot see \(D_p\).

## Direct answers to the four questions

**(A)** Yes, Dwork congruences imply exact vertical persistence:

\[
p\mid b_r\Longleftrightarrow p\mid b_{rp^s},
\]

and they stabilize low valuations. For \(b_{r+kp}\), the correct statement is the Lucas relation \(b_{r+kp}\equiv b_rb_k\pmod p\). Neither relation compares two distinct residues in \(Z_p\), so neither alone bounds the pair count.

**(B)** Not in the proposed form. The displayed exponential is an additive complex Fourier transform, not a \(p\)-adic Mellin interpolation whose zeros are \(Z_p\). The correct twisted Mellin traces live on \(p\)-adic weight space, but the tame sample hits each of the \(p-1\) components once. Strassmann controls vertical zeros within a component and exact zeros rather than mod-\(p\) divisibility. A uniformly bounded normalized tame-Hasse polynomial would work, but constructing it is essentially the missing theorem and the direct interpolation has degree \(\Omega(p)\).

**(C)** The pointwise unit-root eigenvalue of the ordinary fiber family does not control Mellin zero density. A **unique unit root in each Kummer-twisted global crystal** would force the corresponding Mellin coefficient to be a unit and is a valid sufficient mechanism. The classical \(\alpha_p\) or \(a_p(f)\) controls only the special midpoint branch. Target A should be formulated as a two-twist exceptional-unit-root/cancellation bound.

**(D)** Distinct base-window zeros cannot be \(p\)-adically close, so congruence clustering modulo \(p^k\) is not a meaningful test. Compute vertical valuation towers for genuine Dwork structure, and compute gaps, tame ratio orders, gap-polynomial certificates, normalized unit packets, and twisted Newton slopes for same-prime pair structure. The existing million-prime data already give \(\sum D_p/\pi(10^6)=0.124478\ldots\), essentially \(1/8\).

---

## Bottom line

Dwork congruences do not kill Target A, but they relocate it. They show that the sequence is extremely rigid **after a tame branch is chosen**. Target A asks why two different tame branches are simultaneously nonunit only \(O(1)\) times on average. That is a horizontal, two-character crystalline anti-concentration problem.

The best next theorem is therefore not “\(B_p(s)\) has bounded Strassmann degree,” but

\[
\sum_{p\le X}
\#\bigl\{\{[r],[s]\}: [r]\ne[s],\;
T_{p,[r]}\equiv T_{p,[s]}\equiv0\pmod p\bigr\}
\ll\pi(X),
\]

with \(T_{p,[j]}\) the correctly normalized twisted Frobenius trace. Dwork theory should be used to construct and normalize these traces; the breakthrough still needed is the mechanism coupling distinct tame branches.
