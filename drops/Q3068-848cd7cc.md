## 1. Exact proof of the Lucas globalization

Let `q>=1` be fixed. Let `p` be prime with `p>q`, and suppose

```text
n = q p + r,   0 <= r < p.
```

The current committed `problems/3.2/proof.tex` states Gessel's multiplicative Lucas theorem

```text
b_n == product_i b_{n_i} (mod p)
```

for the base-`p` digits `n_i`. Since the base-`p` digits of `n` are exactly `(r,q)` when `q<p`,

```text
b_n == b_q b_r (mod p).                                (10)
```

For every prime `p \nmid b_q`, `b_q` is a unit modulo `p`, so

```text
p | b_r  <=>  p | b_n.                                (11)
```

Now `r=n-q p` lies in `[0,p)` exactly when

```text
n/(q+1) < p <= n/q.
```

Thus, after discarding the fixed finite set of prime divisors of `b_q`,

```text
{ p prime : floor(n/p)=q, p | b_{n-q p} }
 =
{ p prime : n/(q+1)<p<=n/q, p | b_n }.                (12)
```

For fixed `q` and `T -> infinity`, every prime in the left shell tends to infinity, so eventually none divides the fixed number `b_q`; therefore (12) is literally exact for all `T` sufficiently large.

Under the half-strip condition `r<p/2`,

```text
n-q p < p/2
 <=>
n < (q+1/2)p
 <=>
p > n/(q+1/2),                                       (13)
```

so the same proof gives exact equality with `I_q^(1/2)(n)`.

This also matches the Q3062 `N=p-1` coordinates exactly. There `H=n-q` and

```text
a_N = H-qN
    = n-q-q(p-1)
    = n-q p
    = r.                                               (14)
```

So the Q3062 anchor is not an artifact of the `N=p-1` reparameterization: it is precisely the fixed-`n` Lucas digit `r=n-q p`.

## 2. Why this identity does not itself kill the star

The prime product of the star is, by (12),

```text
R_q(n)
 := product_{p in I_q(n), p | b_{n-q p}} p
  = rad_{I_q(n)}(b_n).                                 (15)
```

Therefore every elementary size argument gives only

```text
log R_q(n) <= log b_n = O(n),                          (16)
```

and consequently only

```text
M_q(n) = O(n/log n),                                   (17)
```

which is exactly one little-`o` factor short.

There is no hidden contradiction from the sheer size of a full star. Already the single `k=n` term in Apéry's positive binomial formula gives

```text
b_n >= binom(2n,n)^2,
```

so

```text
log b_n >= n log 16 - O(log n).                        (18)
```

On the other hand the logarithm of the product of *all* primes in any fixed quotient shell is only `Theta_q(n)`; for the full `q=1` shell `(n/2,n]` it is asymptotic to `n/2`. Thus height leaves ample room for the whole shell. This is the same quantitative point made in the committed anchored-star discussion.

So `(LUCAS-GLOBALIZE)` is the right exact identity, but `Lucas + height` cannot prove `(RAD_q)`.

## 3. The other current exact Apéry identities do not add an independent small carrier

### Pair/block law

The committed source also has the Cartier-Frobenius pair law

```text
(p^3 a_{q p+r}, b_{q p+r}) == b_r (a_q,b_q) (mod p).
```

If `p|b_r`, this promotes the same prime into the numerator channel after the standard `p^3` denominator clearing. At fixed global row `n`, this says that the star primes lie in the relevant gcd carrier as well as in `b_n`.

But that is the target phenomenon, not an upper bound. It gives no second fixed integer of subexponential height whose gcd with `b_n` would force the star product to be small.

### Wronskian

The exact Wronskian

```text
a_n b_{n-1} - a_{n-1} b_n = 6/n^3
```

bounds the common divisor only by the LCM denominator carrier. For primes in a fixed quotient shell this ambient carrier already contains every such prime (indeed with the available LCM power). Hence the Wronskian does not remove a positive fraction of the shell.

### No adjacent zeros

If `p|b_n` in the relevant range, no-adjacent-zero gives `p \nmid b_{n-1}b_{n+1}`. The recurrence at `n` merely yields the unit relation

```text
(n+1)^3 b_{n+1} == -n^3 b_{n-1} (mod p),              (19)
```

which is perfectly compatible with arbitrarily many distinct star primes. In fact the fixed integer obtained by clearing (19) is just `P(n)b_n` by the recurrence, so this does not produce an independent carrier either.

Thus there is no second current exact identity that turns (15) into an `e^{o(n)}` radical bound.

## 4. Exact quantitative consumer for the final all-index gate

The most economical new theorem to target is the pointwise weighted pair estimate

```text

```

hence

```text
sup_{T<n<=2T} W_q(n)=o(T).                             (20)
```

The fixed-quotient cross-`g` row-energy argument has already reduced the all-index problem to exactly this absence of a macroscopic positive hit at one row; its centered/background contribution is already `o(T)` at the final gate. Therefore (20) gives

```text

```

If one prefers a theorem with no supremum in its hypothesis, `(STAR2_q)` in (9) is sufficient because positivity gives `(ANTI-STAR2_q)` immediately.

This is quantitatively much weaker than an independence-scale asymptotic. It only asks that the total positive weighted pair incidence be `o(T^2)`, i.e. that no macroscopic atom survive. A Q3062 star contributes `Theta(T^2)` at one coordinate and is therefore exactly the excluded configuration.

## 5. Why this is not SKPMIX again

The distinction is structural.

SKPMIX / the banked row-energy machinery works with centered row functions and signed cross terms. A single anchor may contribute `Theta(P^2)` positive coincidence at one coordinate and still fit the global centered `L^2` budget because the theorem permits an exceptional set and the other centered coordinates supply the required balance.

`(ANTI-STAR2_q)` instead uses

```text
1_{p | b_{n-q p}} 1_{ell | b_{n-q ell}} >= 0
```

with no subtraction of densities. There is nothing available to cancel an aligned star. This is why Q3062 violates `(ANTI-STAR2_q)` while satisfying the current fixed-`g` mean-square theorem.

After Lucas globalization, the same premise can be stated without zero sets at all:

```text
sup_{T<n<=2T}
  sum_{p != ell; p,ell in I_q(n)}
    (log p)(log ell) 1_{p ell | b_n}
  = o(T^2).                                             (22)
```

That is a genuinely Apéry-specific two-prime factor-incidence theorem for the *single global row* `b_n`.
