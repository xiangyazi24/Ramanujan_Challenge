# Higher-dimensional aligned invariants: no free height reduction

## Summary

The proposed deformation

```text
Res_x(F, G + T J + U K)
```

and its determinantal/Fitting variants are mathematically meaningful, but they do **not** give a new primitive arithmetic invariant with smaller Gauss content. The missing H-factor cannot be recovered by adding deformation parameters alone.

The reason is structural: the one-parameter content already computes the gcd of the maximal minors of the relevant multiplication map after restricting to the pencil `G + T J`. Adding more parameters refines the coefficient presentation but does not decrease the underlying determinantal ideal. After saturation by the same structural carrier, the arithmetic support is monotone.

## 1. Algebraic setup

Let

```text
A = Z[x]/(F),   deg(F)=d.
```

Multiplication by `G,J,K` gives endomorphisms of the free Z-module A. A simultaneous common root modulo p is equivalent to the rank drop of

```text
A --(G,J,K)--> A^3
```

modulo p.

Equivalently, the ideal generated by the maximal minors of the block matrix

```text
M = [ mult(G)  mult(J)  mult(K) ]
```

vanishes modulo p at the corresponding local component.

The correct integral object is therefore the zeroth Fitting ideal

```text
Fit_0(coker M).
```

For a presentation matrix this is generated by all maximal minors. Its positive generator (the gcd of maximal minors) is the determinantal divisor.

## 2. Relation with the resultant pencil

For the one-parameter construction

```text
R(T)=Res_x(F,G+TJ),
C_1=cont_T R(T),
```

`C_1` is exactly the first determinantal divisor of the map obtained after adjoining the parameter T. A prime p divides C_1 iff the specialized algebra has a common root of F,G,J over an algebraic closure of F_p.

For the two-parameter deformation

```text
R(T,U)=Res_x(F,G+TJ+UK),
C_2=cont_{T,U}R(T,U),
```

we have

```text
C_2 = gcd { coefficients of R(T,U) }.
```

The coefficient ideal is the elimination ideal

```text
(F, G+TJ+UK) ∩ Z[T,U].
```

Setting U=0 gives the one-parameter elimination ideal. Hence

```text
C_2 | C_1.
```

However this divisibility is only because the two-parameter family asks for the stronger condition involving K. It is not a height-saving primitive normalization: the prime divisors detected are fewer because the geometric condition is stronger.

For the actual four-zero problem, K is not an independent condition. It is another translate polynomial. The simultaneous-root ideal is already generated by the original aligned equations. Introducing U only changes the presentation.

## 3. Fitting ideal monotonicity theorem

Let I be the determinantal ideal generated by maximal minors of a presentation matrix M. Any enlargement of the parameter ring

```text
Z[T] -> Z[T,U]
```

and any base change preserves Fitting ideals:

```text
Fit_0(M ⊗ Z[T,U]) = Fit_0(M) · Z[T,U].
```

Taking contents after specializing back to Z gives

```text
content(Fit_0 over Z[T,U])
```

which is the same primitive determinantal divisor, or a divisor when additional equations are imposed.

Therefore parameters cannot lower the existing arithmetic content while retaining the same zero-detection condition.

## 4. Explicit toy example

Take

```text
F=x(x-1),
G=x,
J=x-1.
```

The pencil resultant is

```text
Res(F,G+TJ)=T(T+1).
```

Its content is 1.

Adding K=x+2 gives

```text
Res(F,G+TJ+UK)=(T+2U)(T+1+2U).
```

Again the content is 1. The extra parameter changes the locus but does not create a smaller arithmetic invariant.

A nontrivial example can only arise by making K impose an additional independent congruence; then the reduction in prime support is paid for by proving a stronger statement, not by improving the height estimate.

## 5. Consequence for the Apéry aligned count

The current invariant from `aligned_corank_verify.py` computes

```text
C(F;G,J)=cont_T Res(F,G+TJ).
```

Its difficulty is not failure to detect simultaneous roots. The difficulty is bounding

```text
sum log |C(F;G,J)|
```

over all gap tuples.

Replacing it by

```text
cont_{T,U} Res(F,G+TJ+UK)
```

or a larger Fitting determinant does not remove the archimedean degree/height contribution. It either:

1. detects a strictly smaller set of primes because it imposes extra equations; or
2. represents the same determinantal ideal in a larger polynomial ring, with the same primitive arithmetic divisor.

Thus no H-factor is saved by parameter proliferation.

## 6. What would actually save a parameter

A successful improvement must exploit additional Apéry-specific structure, for example:

* a rank-of-apparition constraint;
* an independent bound on possible gap tuples from recurrence dynamics;
* a nontrivial codimension estimate for the aligned intersection variety;
* cancellation between translated gap polynomials.

The universal deformation/Fitting approach alone is exhausted by the determinantal divisor theorem.

## Final statement

There is an integral universal invariant: the zeroth Fitting ideal (equivalently the determinantal divisor of the multiplication block). It correctly measures simultaneous common roots and local intersection length. But after primitive normalization it is not smaller than the one-parameter Gauss content in a way that preserves the same condition. Multi-parameter resultants cannot supply the missing H saving in the quadruple count.
