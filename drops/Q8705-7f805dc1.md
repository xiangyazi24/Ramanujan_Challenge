# Cold audit: generalized Newton-content theorem for Apéry folded hits

## 1. Setup

Let

\[
K=X-1,\qquad A_i(t)=(-1)^{K-i}B_i\binom ti\binom{t-i-1}{K-i}.
\]

The relevant identity is the integer-valued Newton expansion identity. The coefficients are evaluated at an integer t, including negative t through generalized binomials.

Write

\[
t=cp+z,\qquad 0\le z\le K,
\]

for the positive branch, and

\[
t=-m-1=cp+z
\]

with the corresponding reflected residue for the negative branch.

The only claim that is universally true modulo p is the coefficient-survival statement. Stronger gcd statements require additional hypotheses.

## 2. p-adic valuations of the two binomial factors

For p>K and integer t, the first factor satisfies

\[
\binom ti=\frac{t(t-1)\cdots(t-i+1)}{i!}.
\]

Since i<K<p, the denominator is a p-adic unit. Therefore

\[
v_p\binom ti
\]

is exactly the number of terms in

\[
t,t-1,\ldots,t-i+1
\]

which are divisible by p.

If

\[
t\equiv z\pmod p,
\]

then this interval contains the residue z precisely when i>z. Hence

\[
v_p\binom ti\ge1 \iff i>z.
\]

For i\le z,

\[
v_p\binom ti=0.
\]

The second factor is

\[
\binom{t-i-1}{K-i}.
\]

Its numerator consists of

\[
t-i-1,t-i-2,\ldots,t-K.
\]

Modulo p, the unique possible zero term is the one congruent to z, namely the term t-K when z=K or the shifted terms when the interval reaches z. Therefore

\[
v_p\binom{t-i-1}{K-i}\ge1
\]

exactly when the interval

\[
\{i+1,i+2,\ldots,K\}
\]

contains z modulo p.

Because K<p, this happens precisely for i<z.

Hence for 0\le i\le K,

\[
v_p\left(\binom ti\binom{t-i-1}{K-i}\right)
\ge1
\]

for every i\ne z, while the valuation is zero for i=z, except at endpoint degeneracies where z=0 or z=K.

Therefore

\[
A_i(t)\equiv0\pmod p\quad(i\ne z),
\]

and

\[
A_z(t)\equiv B_z\cdot u_z\pmod p
\]

with u_z a nonzero unit.

## 3. Root case p|B_z

If

\[
p\mid B_z,
\]

then all coefficients satisfy

\[
A_i(t)\equiv0\pmod p
\]

including the surviving Newton coefficient. Thus

\[
v_p(\gcd_i A_i(t))\ge1.
\]

To conclude equality 1 one needs some i with valuation exactly one.

The no-consecutive-zero property gives the required nearby coefficient unless an endpoint collapse occurs. The generic statement is:

If

* 0<z<K,
* the quotient digit c is nonzero and non-endpoint,
* p is a genuine shell prime root,
* z and z+1 (or z-1) are not both Apéry zeros,

then

\[
v_p(\gcd_i A_i(t))=1.
\]

The reason is that a neighboring coefficient has exactly one factor p from the binomial part and no extra factor from B_i, while the distinguished coefficient contributes the Apéry zero.

## 4. Exceptions

The following cases must be separated:

1. **z=0.** The surviving index is the endpoint. There may be no lower neighbor coefficient, so the no-consecutive-zero argument does not force valuation one.

2. **z=K.** Symmetric endpoint failure.

3. **m\le K.** The interval may not contain a full shell digit. The quotient parameter is not in the regular range.

4. **quotient endpoints.** If c=0 or c reaches the maximal allowed value, extra p-adic valuation can enter through the integer t itself.

5. **negative branch endpoints.** The reflection t=-m-1 introduces the same exceptions after replacing z by the reflected digit p-1-z.

No other exceptions arise from the binomial factors.

## 5. Counterexample search: overstatements that fail

The following stronger statements are false without hypotheses:

\[
v_p(\gcd_iA_i(t))=1
\]

for every root p|B_z.

Endpoint roots can have larger valuation. A second failure occurs if an Apéry coefficient adjacent to z is also divisible by p; no-consecutive-zero only rules out adjacent indices, not all endpoint or reflected degeneracies.

The correct theorem must explicitly exclude these cases.

## 6. Correct all-X theorem

The strongest unconditional form suitable for a proof paper is:

> Let p be prime with K<p, t an integer with t mod p=z in [0,K]. Then
> \[
> A_i(t)\equiv0\pmod p
> \]
> for all i\ne z. Moreover, if p|B_z then p divides every coefficient A_i(t). If additionally z is interior, the quotient is regular, and the reflected/end-point degeneracies are excluded, then
> \[
> v_p(\gcd_iA_i(t))=1.
> \]

This is the maximal statement obtained from Newton-content and no-consecutive-root input alone. Any claim of universal exact valuation one requires an additional Apéry recurrence input controlling endpoint valuations.
