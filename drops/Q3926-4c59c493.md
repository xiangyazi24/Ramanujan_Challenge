# 2. Close endpoint count, including boundary intervals

# 3. Frozen nearest-earlier charge multiplicity

Fix one star and write its endpoint occurrences in the frozen original core order as

\[
e_1,e_2,\ldots,e_K,

which is also increasing order of the secondary coordinate \(a\). By hypothesis, every surviving high-row later endpoint \(e_j\) is charged to exactly its \(\lambda\) nearest earlier endpoints:

\[

\tag{3.1}

Thus:

- as a later endpoint, one occurrence belongs to exactly \(\lambda\) charges;
- as an earlier endpoint \(e_i\), it can be used only by later ranks
  \[

Hence every endpoint occurrence has total incident charge degree at most

A charge with two close endpoints may be counted twice in (3.3), which is harmless for an upper bound. There is no missing factor from endpoint orientation, row multiplicity, or reuse in different stars.
