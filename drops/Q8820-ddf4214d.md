The exponential-moment route is a **valid sufficient route**, but it is **not presently more tractable than `(HM)_8`**. It repackages the atom-tail problem rather than removing it.

The definitive points are:

1. A uniform bound

   ```math
   \frac1N\sum_{n\le N}e^{tS(n)}\le C(t)
   ```

   for even one fixed `t>0` would immediately imply the pointwise bound

   ```math
   \max_{n\le N}S(n)\le \frac{\log N+\log C(t)}t=O_t(\log N).
   ```

   Hence, using the shell-prime reduction in the question, it would prove

   ```math
   \log G_n=O(\sqrt n+(\log n)^2)=o(n)
   ```

   for **every** `n`. No Borel–Cantelli argument is needed.

2. The claim that the independent CRT product “diverges” is a category error. If

   ```math
   \mu_N=\mathbf E S(n)=O(1),
   ```

   then for fixed `t`

   ```math
   \prod_p\left(1+(e^t-1)\rho_p\right)
   \le \exp\!\left((e^t-1)\mu_N\right)=C(t),
   ```

   where `rho_p` is the marginal hit probability. This may grow extremely fast as `t→∞`, but `C(t)` is allowed to depend on `t`. No repulsion is needed in the independent model.

3. A bounded MGF already contains a new **first-moment theorem**. Since

   ```math
   e^{tS}\ge 1+(e^t-1)S,
   ```

   it implies `E S=O_t(1)`. For the Apéry shell this is essentially a weighted average-`Z(p)` statement of the strength suggested by Hypothesis `bar Z`; it is not currently proved unconditionally.

4. The MGF is exactly the generating function of all factorial moments. With

   ```math
   u=e^t-1,
   ```

   one has

   ```math
   \boxed{
   \frac1N\sum_n e^{tS(n)}
   =\sum_{k\ge0}\frac{u^k}{k!}
     \frac1N\sum_n(S(n))_k.
   }
   ```

   All coefficients are nonnegative. Therefore a bounded MGF forces an unscaled bound for **every** factorial moment, including the eight-prime term.

5. For a dyadic prime block `X<p≤2X` and rows `m<X^2`, the coefficient of `u^8` still needs the same `X^{-6}` short-CRT occupancy saving identified in Q8814. The MGF is one-dimensional only on the outside; its power-series coefficients reopen all the high-dimensional prime-tuple sums.

6. The high-`t` numerical discrepancy is not reliable evidence of arithmetic repulsion. Under a Poisson law of mean `lambda`, exponential tilting moves the dominant contribution to counts near

   ```math
   k\approx \lambda e^t.
   ```

   At `t=3,4`, this lies far beyond the maximum count normally visible in a sample of only `20000` rows. The relative variance of the empirical estimator is astronomical:

   ```math
   \frac{\mathbf E[e^{2tS}]}{\mathbf E[e^{tS}]^2}
   =\exp\!\left(\lambda(e^t-1)^2\right)
   ```

   for Poisson `S`. Thus the empirical high-`t` MGF can be orders of magnitude below its population value even when the Poisson model is exactly correct.

7. A second-moment or variance bound cannot imply the desired MGF. The repository's anchored rainbow star has the natural second-moment scale, bounded row codegrees, reflection symmetry, no adjacent residues, and small local zero sets, yet one row has `K≈X/log X`; its normalized MGF is at least

   ```math
   X^{-2}\exp(c tX/\log X),
   ```

   which diverges for every fixed `t>0`.

8. Standard Bernstein, Janson, negative-dependence, self-bounding, read-`k`, and Freedman inequalities require structural hypotheses not presently available. Here all prime-hit indicators are functions of the same integer `n`. After two shell-prime residues are fixed, their product modulus exceeds the row interval and `n` may already be determined; all later conditional hit probabilities can then become `0` or `1`.

9. The cleanest new sufficient residual is a **linear Palm-extension bound**. If, for the factorial moments

   ```math
   F_r(N)=\sum_{n\le N}(S(n))_r,
   ```

   one could prove

   ```math
   \boxed{F_{r+1}(N)\le A(r+1)F_r(N)\quad(r\ge0)}
   ```

   with an absolute `A`, then

   ```math
   F_r(N)\le N A^r r!
   ```

   and hence

   ```math
   \frac1N\sum_{n\le N}e^{tS(n)}
   \le \frac1{1-A(e^t-1)}
   ```

   for every sufficiently small fixed `t>0`. This is a precise martingale/Palm target, but its first genuinely new case is already the open third-moment pair-Palm overload in `hm3_result.tex`.

The net assessment is therefore:

> **A fixed-small-`t` MGF theorem would prove the Apéry GCD conjecture, but it does not bypass Stage C. It requires the same polynomial short-CRT saving at order eight, plus control of all higher orders and a bounded shell first moment. With current technology it is at least as difficult in its polynomial core as `(HM)_8`, although the linear Palm-extension formulation is a useful new residual worth testing.**

## 1. A clean deterministic formulation

The threshold `p>sqrt(n)` varies with `n`. On a dyadic row interval

```math
I_N=(N,2N],
```

this can be absorbed into the indicator. For every prime `p≤2N`, put

```math
f_p(n)
=
\mathbf1_{\{n\in I_N,\ p>\sqrt n,\ p\mid b_n\}},
```

or use the exact shell-hit indicator relevant to `G_n` after the already-proved companion/leading-channel reductions. Then

```math
S_N(n)=\sum_p f_p(n)
```

is defined using one fixed collection of Boolean functions on `I_N`.

Set

```math
M_N(t)=\frac1N\sum_{n\in I_N}e^{tS_N(n)}.
```

All arguments below apply equally to the cumulative average over `1≤n≤N`.

### 1.1 One bounded MGF gives a pointwise theorem

For every `n∈I_N`, positivity gives

```math
 e^{tS_N(n)}
 \le \sum_{m\in I_N}e^{tS_N(m)}
 =N M_N(t).
```

Hence

```math
\boxed{
\max_{n\in I_N}S_N(n)
\le \frac{\log N+\log M_N(t)}t.
}
```

Thus `M_N(t)≤C(t)` implies `S_N(n)=O_t(log N)` for every row in the block. A dyadic decomposition covers every positive integer.

Under the inequality asserted in the question,

```math
\log G_n
\le O(\sqrt n)+O(S(n)\log n),
```

this yields

```math
\log G_n
=O(\sqrt n+(\log n)^2)
=O(\sqrt n).
```

So the proposed MGF theorem is more than sufficient.

### 1.2 The Borel–Cantelli statement in the question is not correct

Markov gives

```math
\#\{n\le N:S(n)\ge k\}
\le C(t)N e^{-tk}.
```

If `k=c log log N`, the right side is

```math
\frac{C(t)N}{(\log N)^{ct}},
```

which is generally enormous, not zero. There is no monotonicity in `S(n)` that converts this density statement into an all-integer statement.

The direct maximum argument above gives `O(log N)` for all rows. To recover the Poisson extreme-value scale `log N/log log N`, one would need MGF control for a range of growing `t` with quantitative growth such as

```math
C(t)\le \exp(A(e^t-1)),
```

and then optimize `t`. Even an independent Poisson model predicts a maximum of order `log N/log log N`, not `log log N`.

### 1.3 A constant bound is stronger than necessary

For the all-`n` GCD theorem it would already suffice to prove, for some fixed `t>0`,

```math
M_N(t)\le N^{O_t(1)},
```

because the same argument still gives `S(n)=O_t(log N)`. More generally, any MGF estimate whose logarithm is `o(N/log N)` gives the pointwise shell bound needed for `log G_n=o(n)`.

The constant-MGF target is nevertheless the cleanest probabilistic formulation and is the one assessed below.

## 2. The independent product does not diverge for fixed `t`

Let

```math
\rho_{p,N}=\frac1N\sum_{n\in I_N} f_p(n),
\qquad
\mu_N=\sum_p\rho_{p,N}=\mathbf E_{n\in I_N}S_N(n).
```

If the indicators were independent, then with `u=e^t-1`,

```math
\begin{aligned}
M_N^{\rm ind}(t)
&=\prod_p(1+u\rho_{p,N})\\
&\le \exp\!\left(u\sum_p\rho_{p,N}\right)\\
&=\exp(u\mu_N).
\end{aligned}
```

Therefore a bounded independent MGF requires only

```math
\mu_N=O(1).
```

For the heuristic `Z(p)≈1`, the weighted prime mass in the complete shell is

```math
\sum_{\sqrt N<p\le N}\frac1p
=\log 2+o(1),
```

so the independent model has a finite limiting MGF for every fixed `t`.

The expression

```math
\exp(\text{constant}\cdot e^t)
```

“diverges” only when `t→∞`. The desired theorem permits `C(t)` to grow with `t`, so this is not an obstruction.

### 2.1 A bounded MGF contains the vertical first-moment problem

For `u=e^t-1>0`,

```math
 e^{tS}=(1+u)^S\ge1+uS.
```

Consequently

```math
\boxed{
M_N(t)\le C(t)
\quad\Longrightarrow\quad
\mu_N\le\frac{C(t)-1}{e^t-1}.
}
```

Thus the MGF route first has to prove a bounded shell mean. In the Apéry setting this is closely related to

```math
\sum_{\sqrt N<p\le N}\frac{Z(p)}p=O(1),
```

up to the exact quotient/endpoint bookkeeping. This follows from the conjectural average law `sum_{p≤x}Z(p)≪pi(x)`, but not from the current pointwise `Z(p)≪p^{2/3}` or the current corank-average exponents.

So the MGF route does not remove the vertical `Z(p)` issue; it assumes or proves a strong weighted version of it as its first derivative at the origin.

## 3. Why the high-`t` numerical transition is not evidence of repulsion

There are two separate objects that can both be called a “CRT prediction.”

### 3.1 The independent CRT main term

This is

```math
\prod_p(1+u Z(p)/p),
```

or the same expression with exact finite-interval marginals. It is Poisson-like when all local probabilities are small.

### 3.2 The absolute CRT error upper bound

After expanding over subsets of primes, the count for one residue vector is

```math
\frac NQ+O(1).
```

If every `O(1)` is replaced by `+1` and all errors are summed absolutely, the result becomes enormous at high order. That is a worst-case upper bound, not a probabilistic prediction.

This distinction explains why a “CRT value” can agree at `t=1,2` and explode at `t=3,4`: low `t` emphasizes the first few subset sizes, while high `t` magnifies the accumulated `+1` errors from very many high-order subsets.

### 3.3 Exponential tilting moves the relevant count far into the tail

For `S∼Poisson(lambda)`,

```math
\mathbf E e^{tS}=\exp(\lambda(e^t-1)).
```

The contribution from `S=k` is

```math
 e^{tk}\mathbf P(S=k)
 =e^{-\lambda}\frac{(\lambda e^t)^k}{k!}.
```

The ratio of consecutive contributions is

```math
\frac{\lambda e^t}{k+1},
```

so the MGF is dominated by values near

```math
\boxed{k\approx\lambda e^t.}
```

For a shell mean around `0.2–0.35`, this gives roughly:

| `t` | dominant `k≈lambda e^t` |
|---:|---:|
| 1 | `0.5–1` |
| 2 | `1.5–2.6` |
| 3 | `4–7` |
| 4 | `11–19` |

A sample of only `20000` rows can describe the body around `k=0,1,2` reasonably well, but it normally contains no observations near `k=11–19`.

### 3.4 The empirical high-`t` MGF has enormous variance even under exact Poisson data

For `Y=e^{tS}` with `S∼Poisson(lambda)`,

```math
\frac{\mathbf E Y^2}{(\mathbf E Y)^2}
=
\exp\!\left(\lambda(e^t-1)^2\right).
```

Thus the relative variance of a sample mean based on `N_0` independent observations is

```math
\frac{\exp(\lambda(e^t-1)^2)-1}{N_0}.
```

At `t=3` or `4` this is astronomical for any `lambda` in the observed range. Therefore an empirical value much smaller than the Poisson population MGF is expected from rare-event undersampling; it is not evidence that the true arithmetic distribution has a comparably small MGF.

A useful diagnostic for the existing data is the exponential-weight effective sample size

```math
\operatorname{ESS}(t)
=
\frac{\left(\sum_n e^{tS(n)}\right)^2}
     {\sum_n e^{2tS(n)}}.
```

If `ESS(3)` or `ESS(4)` is near `1`, the reported MGF is controlled by only a few rows and cannot support a tail conclusion.

### 3.5 The proposed local crossover criterion is not the right one

The condition

```math
 e^t Z(p)/p\approx1
```

is not the main transition for typical shell primes, since `Z(p)/p` is about `1/p`. The relevant transition is global:

```math
 \mu_N e^t
```

reaches or exceeds the largest hit count represented in the data. Equivalently, the tilted distribution asks for tail levels absent from the finite sample.

## 4. The MGF is the factorial-moment generating function

For an integer `S≥0`,

```math
 e^{tS}
 =(1+u)^S
 =\sum_{k=0}^{S}\binom Sk u^k
 =\sum_{k\ge0}\frac{u^k}{k!}(S)_k,
 \qquad u=e^t-1.
```

Averaging gives the exact identity

```math
\boxed{
M_N(t)
=
\sum_{k\ge0}\frac{u^k}{k!}\frac{F_k(N)}N,
\qquad
F_k(N)=\sum_{n\in I_N}(S_N(n))_k.
}
```

The sum is finite because `S_N(n)` is finite.

### 4.1 What a bounded MGF implies

All terms are nonnegative, so for every `k`,

```math
\boxed{
F_k(N)
\le
C(t)N\,\frac{k!}{(e^t-1)^k}.
}
```

Thus one fixed positive radius of convergence gives uniform factorial-moment bounds of **every order**, including orders growing with `N` up to the trivial maximum.

### 4.2 What `(HM)_8` implies

A single `(HM)_8` estimate controls only one coefficient:

```math
F_8(X)\ll X^{2+o(1)}\lambda_X^8.
```

It gives a polynomial eighth-order tail, not an exponential tail. It does not control the MGF, since `e^{tT}` eventually dominates `T^{-8}`.

### 4.3 What all high moments would need to imply an MGF

If one had the uniform Poisson-scale family

```math
\frac{F_k(N)}N\le A^k
\qquad\text{for every }k,
```

then

```math
M_N(t)\le\exp(A(e^t-1)).
```

But proving `(HM)_k` separately for each fixed `k`, with constants allowed to grow arbitrarily with `k`, does not yield a positive radius of convergence. Uniform control in `k` is essential.

### 4.4 Logical comparison

The two routes are therefore different:

- `(HM)_8` asks for one fixed factorial moment at the fine density scale `lambda_X^8`;
- a bounded MGF asks for all factorial moments, but only at an unscaled `O(N)` level with factorial/exponential constants.

The MGF loses the `lambda_X^k` normalization, which may save powers of `log X` in the expected regime. It simultaneously demands all orders and an exponential atom tail.

They are not formally equivalent. At the **polynomial** short-CRT scale, however, they face the same obstruction.

## 5. The `X^{-6}` factor is still present

Fix one dyadic prime block

```math
\mathcal P_X=\{p:X<p\le2X\},
\qquad 0\le m<X^2,
```

and let

```math
K_X(m)=\sum_{p\in\mathcal P_X}f_p(m).
```

Since `S(m)≥K_X(m)` whenever this block lies in the shell, a bounded shell MGF implies a bounded MGF for `K_X`.

The coefficient identity gives

```math
\frac1{X^2}\sum_{m<X^2}e^{tK_X(m)}
\ge
\frac{u^8}{8!X^2}
\sum_{m<X^2}(K_X(m))_8.
```

Hence a bounded MGF forces

```math
\sum_{m<X^2}(K_X(m))_8=O_t(X^2).
```

For eight primes `p_i≈X`, their product modulus is

```math
Q=p_1\cdots p_8\asymp X^8,
```

while the row interval has length `X^2`. Direct CRT uniqueness gives one possible row per residue vector and therefore only the bound

```math
\sum_{m<X^2}(K_X(m))_8
\ll
\left(\sum_{X<p\le2X}Z(p)\right)^8.
```

With `Z(p)` of constant average, this is approximately

```math
\frac{X^8}{(\log X)^8}.
```

The bounded-MGF coefficient needs `O(X^2)`. The missing polynomial saving is still

```math
\boxed{X^6.}
```

`(HM)_8` additionally asks for the expected logarithmic factor `lambda_X^8≈(log X)^{-8}`, but both routes require the same six powers of `X`.

Therefore the statement in part (e) that the MGF “does not require the short-CRT `X^{-6}` factor” is false.

## 6. Exact subset expansion and the CRT error

For a fixed prime set, Boolean idempotence gives

```math
 e^{tS(n)}
 =\prod_p e^{t f_p(n)}
 =\prod_p(1+u f_p(n)).
```

Expanding over subsets,

```math
\boxed{
M_N(t)
=
1+\frac1N
\sum_{\varnothing\ne A\subseteq\mathcal P}
 u^{|A|}I_A(N),
}
```

where

```math
I_A(N)
=
\#\{n\in I_N:f_p(n)=1\text{ for every }p\in A\}.
```

For a set `A` of distinct primes, write

```math
Q_A=\prod_{p\in A}p,
\qquad
Z_A=\prod_{p\in A}Z(p).
```

Ignoring the harmless shell-eligibility endpoint for notation, CRT gives

```math
I_A(N)
=
\frac N{Q_A}Z_A+E_A,
\qquad
|E_A|\le Z_A.
```

The main terms sum to the independent product

```math
\prod_p\left(1+u\frac{Z(p)}p\right).
```

But the absolute error bound is

```math
\frac1N\sum_Au^{|A|}Z_A
=
\frac1N\left(\prod_p(1+uZ(p))-1\right),
```

which is enormous. The one-dimensional MGF has not altered the error; it has merely summed all the prime-tuple errors with positive weights.

### 6.1 Complete-period independence versus short-interval conditioning

For a fixed set `A`, let `U` be uniform modulo `Q_A`. Under `U`, the residue coordinates modulo the primes in `A` are independent. Uniform sampling from `[0,N)` with `Q_A>N` is the full-period distribution conditioned on the event `U<N`, whose probability is `N/Q_A`.

The Radon–Nikodym derivative is

```math
\frac{d\mathbf P_{[0,N)}}{d\mathbf P_{\mathbf Z/Q_A\mathbf Z}}
=
\frac{Q_A}{N}\mathbf1_{[0,N)}.
```

Its relative entropy is

```math
D=\log(Q_A/N).
```

For `|A|=8`, this is

```math
6\log X+O(1).
```

Thus a generic change-of-measure, Hölder, or entropy argument pays the factor

```math
Q_A/N\asymp X^6,
```

which is exactly the missing CRT factor. A successful proof must show that the Apéry hit event is specifically anti-aligned with this short-interval conditioning; general information theory does not provide that fact.

### 6.2 There is no universal repulsion

The short interval can create under-dispersion or over-dispersion. It does not force repulsion.

The simplest counterexample chooses one row `m_0` and puts `m_0 mod p` in every local zero set. Then all events align at `m_0`, despite perfect CRT compatibility. The repository's anchored rainbow star adds the actual local symmetries and pairwise constraints and still has the same attraction.

So the observed high-order suppression, if it persists beyond finite-sample effects, is an Apéry-specific theorem to be proved—not a generic consequence of CRT.

## 7. Why the second moment cannot control the MGF

A purely probabilistic counterexample is enough. Let

```math
S_L=
\begin{cases}
L,&\text{with probability }L^{-2},\\
0,&\text{otherwise}.
\end{cases}
```

Then

```math
\mathbf E S_L^2=1,
```

but

```math
\mathbf E e^{tS_L}
=1+\frac{e^{tL}-1}{L^2}\longrightarrow\infty
```

for every fixed `t>0`.

The repository contains an arithmetic-incidence version of exactly this pathology.

### 7.1 The anchored rainbow star is a definitive no-go

The construction in `hm3_result.tex` has:

- local zero sets of size `0` or `2`;
- reflection invariance and no adjacent residues;
- the required interval-density bound;
- the universal second factorial-moment estimate;
- centered second moment at the natural scale;
- uniformly bounded row codegrees; and
- the necessary local gap certificate.

Nevertheless, at one row

```math
K_X(m_0)\asymp X/\log X.
```

Therefore

```math
\frac1{X^2}\sum_{m<X^2}e^{tK_X(m)}
\ge
\frac1{X^2}
\exp\!\left(c t\frac X{\log X}\right)
\longrightarrow\infty.
```

This proves that variance, pairwise codegrees, sparse local zero sets, and all currently available pairwise structure cannot imply a fixed-`t` MGF bound.

### 7.2 Why standard Bernstein-type theorems do not apply

Bernstein/Chernoff inequalities need independence or a substitute that controls all high-order dependencies. Existing extensions impose concrete structural hypotheses:

- Janson's dependency-graph bounds require a suitable sparse dependency graph ([Janson 2004](https://doi.org/10.1002/rsa.20008));
- read-`k` bounds require each independent input coordinate to influence only boundedly many output variables ([Gavinsky–Lovett–Saks–Srinivasan](https://arxiv.org/abs/1205.1478));
- self-bounding concentration starts from a function of independent coordinates with controlled marginal decreases ([Boucheron–Lugosi–Massart 2009](https://doi.org/10.1214/EJP.v14-690));
- negative-association bounds require the product inequalities of Joag-Dev and Proschan ([Annals of Statistics 1983](https://doi.org/10.1214/aos/1176346079)); and
- strong-Rayleigh concentration requires a stable/strongly negatively dependent measure ([Pemantle–Peres](https://arxiv.org/abs/1108.0687)).

For the Apéry incidence variables, all `f_p` are functions of the same integer `n`. In the natural representation their dependency graph is complete. Writing `n` in independent binary digits does not help: a change in one high binary digit can alter essentially every residue and every hit indicator, so the read multiplicity and Lipschitz influence are unbounded.

Pairwise covariance control is far weaker than any of these hypotheses.

## 8. The martingale route and its exact missing condition

Order the shell primes as `p_1,...,p_M`, let

```math
X_j=f_{p_j}(n),
```

and reveal them sequentially. Write

```math
\mathcal F_j=\sigma(X_1,\ldots,X_j),
\qquad
\pi_j=\mathbf E[X_j\mid\mathcal F_{j-1}].
```

For `u=e^t-1`,

```math
\mathbf E[e^{tX_j}\mid\mathcal F_{j-1}]
=1+u\pi_j
\le e^{u\pi_j}.
```

Therefore

```math
\exp\!\left(
 t\sum_{i\le j}X_i
 -u\sum_{i\le j}\pi_i
\right)
```

is a nonnegative supermartingale.

This gives an exact sufficient criterion:

```math
\boxed{
\sum_j\pi_j\le A\quad\text{almost surely}
\quad\Longrightarrow\quad
\mathbf E e^{tS}\le e^{A(e^t-1)}.
}
```

### 8.1 Why the predictable intensity is the whole problem

For two shell primes `p,q`, one has `pq>N` on a dyadic row interval. Once the two residue conditions are specified, there is at most one candidate row. Conditional on a two-hit history, the remaining `X_j` may therefore be deterministic: each subsequent conditional probability is `0` or `1`.

A high-hit row has a large predictable compensator, even though the martingale differences after the row is identified have zero variance.

This is why Freedman's inequality does not help automatically. Freedman controls deviation from the predictable compensator using bounded increments and predictable quadratic variation ([Freedman 1975](https://doi.org/10.1214/aop/1176996452)); it does not bound a compensator that is itself large because the hidden row has been identified.

Proving a bounded compensator is essentially proving that no anchored star exists.

### 8.2 Randomizing the prime order does not remove entropy exhaustion

A random order can postpone which two hits identify the row, but it cannot change the fact that two shell residues carry about `2 log X≈log N` bits, exhausting the entropy of a row in `[0,N)`. Later hits are certificates about that already-determined row, not fresh independent trials.

Thus a martingale proof needs a new arithmetic theorem controlling how many such certificates one row can possess.

---

## 9. The strongest concrete MGF strategy: linear Palm extension

The MGF can be obtained from a factorial-moment recursion substantially weaker than full Poisson independence.

Put

```math
F_r(N)=\sum_{n\in I_N}(S_N(n))_r,
\qquad F_0(N)=N.
```

### 9.1 Proposed residual `(LPE)`

Prove that there is an absolute constant `A` such that, uniformly in `N` and every `r≥0`,

```math
\tag{LPE}
\boxed{
F_{r+1}(N)\le A(r+1)F_r(N).
}
```

Induction gives

```math
F_r(N)\le N A^r r!.
```

Hence, for `uA<1`,

```math
\begin{aligned}
M_N(t)
&=\sum_{r\ge0}\frac{u^r}{r!}\frac{F_r(N)}N\\
&\le\sum_{r\ge0}(uA)^r\\
&=\frac1{1-uA}.
\end{aligned}
```

Thus `(LPE)` proves a bounded MGF for every

```math
0<t<\log(1+1/A).
```

Only one small positive `t` is needed for the GCD theorem.

### 9.2 Palm interpretation

Weight a pair `(n,p_1,...,p_r)` by choosing an ordered `r`-tuple of distinct hit primes at row `n`. Under this `r`-fold Palm measure,

```math
\frac{F_{r+1}}{F_r}
```

is exactly the average number of **additional** hit primes beyond the selected `r`.

Therefore `(LPE)` says:

> After conditioning in the size-biased sense on `r` distinct hits, the average number of extensions is at most linear in `r`.

It allows much more clustering than a Poisson recursion `F_{r+1}≤A F_r`; it only forbids superlinear Palm amplification and anchored stars.

### 9.3 The first new case is already open

At `r=2`, `(LPE)` asks for

```math
F_3(N)\le3A F_2(N).
```

The exact pair-Palm theorem in `hm3_result.tex` identifies `F_3` as the total number of third-prime extensions of occupied ordered prime pairs. The positive conditional overload of those third primes is precisely the current `(HM)_3` obstruction.

The MGF normalization is looser than `(HM)_3` by powers of the small mean, but the anchored-star example still violates it by a polynomial factor. No current theorem proves even this first extension step uniformly.

### 9.4 How an Apéry-specific proof would have to work

For `r≥2`, an occupied prime tuple usually determines a unique row `n`. An additional prime `q` is then a new divisibility certificate for the same Apéry value/marked period.

A proof of `(LPE)` would need to:

1. choose a bounded amount of anchor data from the selected hit primes;
2. attach every additional hit prime to an explicit nonzero arithmetic certificate of controlled height;
3. show that, after averaging over occupied anchors, each certificate is charged only `O(r)` times; and
4. sum the number of shell prime divisors of those certificates.

The current gap-polynomial/resultant machinery controls multiple zero positions **inside one characteristic**. Here each prime contributes only one position and the characteristics vary, so no such common certificate is presently known. This is exactly the certificate-parity/cross-prime obstruction recorded in the project.

`(LPE)` is nevertheless a useful new named residual because it is tailored exactly to a small-`t` MGF and is weaker than demanding Poisson-scale factorial moments at every order.

## 10. Two other possible strategies and their limitations

### 10.1 Negative association or strong Rayleigh

If the shell hit indicators were negatively associated, then for `u≥0`,

```math
\mathbf E\prod_p(1+u f_p)
\le
\prod_p(1+u\mathbf E f_p)
\le
\exp(u\mu_N).
```

Together with `mu_N=O(1)`, this would solve the problem immediately.

But this is a very strong all-subset inequality. The low-order numerical behavior is slightly super-Poisson rather than visibly negatively associated, and the anchored-star construction shows that none of the established local Apéry constraints implies it. There is no determinantal, stable-polynomial, exclusion-process, or other strong-Rayleigh structure presently attached to the cross-prime incidence vector.

### 10.2 Connected-cumulant/cluster expansion

One can write

```math
\log M_N(t)
=\sum_{r\ge1}\frac{t^r}{r!}\kappa_r(S_N),
```

or use a multivariate Ursell expansion over prime subsets. A bound

```math
|\kappa_r(S_N)|\le r! C^r
```

would give a uniform positive radius of convergence.

This route could in principle be easier than raw high moments because independent components exponentiate and only connected correlations remain. To make it work one would need a tree-graph/Dobrushin-type estimate showing that every connected cross-prime cluster is controlled by a summable collection of lower-order interactions.

No sparse interaction graph is currently available, and the prompt's positive higher cumulants provide no evidence for cancellation. The anchored star again shows that pair correlations alone cannot produce such a cluster bound.

### 10.3 A size-bias coupling

Choose a hit prime with probability proportional to its marginal and condition on that hit. If one could couple the resulting size-biased shell count `S^s` to the original `S` with

```math
S^s\le S+C
```

or with a uniformly exponentially integrable increment, standard size-bias arguments would give an MGF/tail bound.

For Apéry hits, conditioning on one prime leaves about `N/p` possible rows; conditioning on a second can isolate one row and expose all its remaining hits. Constructing the coupling is therefore another form of the Palm-extension problem, not a shortcut around it.

## 11. Direct answers to the questions

### (a) Why does the CRT product overestimate?

For fixed `t`, the independent product does **not** need to overestimate, and it does not diverge with `N` if the shell mean is bounded. It already gives a permissible constant

```math
C(t)=\exp((e^t-1)\mu).
```

The quantity that explodes is either:

- the product as `t→∞`, which is allowed; or
- a crude absolute CRT-error upper bound obtained by summing one `+1` for every residue vector and every prime subset.

There is no generic CRT repulsion. The actual short interval can underpopulate or overconcentrate the CRT points. Any persistent Apéry suppression is a new high-order anti-alignment theorem.

### (b) What tames the high-`t` empirical behavior?

The observed transition is primarily explained by exponential tilting and finite-sample truncation. Under a Poisson model the relevant count is `k≈lambda e^t`; for `t=3,4` the MGF is driven by events too rare to appear in `20000` rows. The empirical estimator then sits far below the population MGF and has huge relative variance.

The correct diagnostics are the tilted mean

```math
\frac{\sum_n S(n)e^{tS(n)}}{\sum_n e^{tS(n)}}
```

and the effective sample size `ESS(t)`, not the comparison of one unstable sample mean with an enormous population expectation.

### (c) Is the MGF route easier than `(HM)_8`?

Logically, it is different:

- one fixed MGF bound proves the full conjecture directly via `max S=O(log N)`;
- it implies unscaled factorial-moment bounds of every order;
- `(HM)_8` controls one order at the sharper `lambda^8` scale.

At the polynomial short-CRT level it is not easier. Its eighth coefficient still needs the same `X^6` saving, and it additionally requires all higher orders plus a bounded first moment.

### (d) Can variance plus a Bernstein inequality prove it?

No. A bounded variance alone permits an exponentially disastrous rare atom, and the repository supplies an incidence construction with exactly that behavior while preserving all currently proved pairwise constraints.

Bernstein/Freedman/Janson-type inequalities become relevant only after proving independence, a sparse dependency graph, negative association, self-bounding influences, read-`k` structure, or a bounded predictable compensator. None is currently available.

### (e) Does the one-dimensional average avoid the `X^{-6}` factor?

No. The exact identity

```math
M_X(t)
=\sum_{k\ge0}\frac{(e^t-1)^k}{k!}
  \frac1{X^2}\sum_{m<X^2}(K_X(m))_k
```

shows that the one-dimensional MGF is the generating function of all prime-tuple intersections. Its `k=8` coefficient is the eight-dimensional all-distinct CRT sum. Positivity prevents cancellation between different orders.

The MGF changes the normalization—allowing logarithmic losses—but not the six missing powers of `X`.

### (f) What is the most specific proof strategy?

The best precise target is `(LPE)`:

```math
F_{r+1}\le A(r+1)F_r
```

for every `r`. It directly gives a bounded MGF for small fixed `t` and has a clear Palm/extension interpretation.

A plausible research program is:

1. compute the ratios

   ```math
   R_r(N)=\frac{F_{r+1}(N)}{(r+1)F_r(N)}
   ```

   for the existing shell data and for each dyadic prime block;
2. compute the distribution of extension counts of occupied ordered prime pairs/triples, not just the global moments;
3. identify whether the largest extension counts are supported by a small number of rows or by a repeatable arithmetic pattern;
4. seek an Apéry-specific height certificate attached to an occupied pair that captures every further shell hit; and
5. prove an averaged divisor bound for those certificates.

If the ratios stay bounded and the extension mass is not concentrated on unexplained stars, `(LPE)` is a coherent new target. If `R_r(N)` grows rapidly with `r` or with `N`, the fixed-small-`t` MGF route should be abandoned.

Martingale, size-bias, and information-theoretic approaches all reduce to proving essentially the same extension bound.

---

## 12. Final feasibility assessment

The exponential-moment viewpoint contributes three useful clarifications:

1. **Sufficiency is very strong and simple.** One fixed positive `t` gives `S(n)=O(log n)` for every row directly from the average.
2. **The high-`t` numerics are not trustworthy tail evidence.** Exponential tilting makes them dominated by events absent from the sample.
3. **There is a clean new residual.** Linear growth of Palm extension counts yields a small-`t` MGF.

But it does not provide a current proof advantage:

- bounded MGF implies a bounded shell first moment, which is already unproved;
- its eighth coefficient requires the same `X^{-6}` cross-prime occupancy saving as `(HM)_8`;
- it must control every higher coefficient as well;
- the proved second moment and codegree structure permit an anchored star with divergent MGF; and
- standard martingale/concentration machinery has no applicable independence or predictable-intensity input.

Therefore the definitive verdict is:

> **The MGF route is a legitimate alternative formulation of the atom-tail problem, not a bypass. With current Apéry technology it is not more tractable than `(HM)_8`. The most promising version is not a direct Deligne, Bernstein, or martingale argument, but the explicit linear Palm-extension theorem `(LPE)`; proving even its first nontrivial step requires new cross-prime arithmetic.**
