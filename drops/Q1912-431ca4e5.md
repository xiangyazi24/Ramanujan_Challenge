# P3.2 independent determinant attack

## Status of the requested derivation

The five-diagonal/parity-block route does not currently give an independent proof of the nonvanishing of
\[
\det(H_IK^3H_I^T)\big|_{z=0}.
\]
The determinant reduction from the cyclic tridiagonal model already isolates the exact obstruction, but deriving the same expression from the recurrence reintroduces the same kernel information.

## What the recurrence supplies

The centered Apéry recurrence gives a two-dimensional solution space. The endpoint-normalized solution \(u\) determines the even kernel vector \(k\), with

\[
k_0=-1,\qquad k_{\pm1}=3,
\]

and the odd kernel vector

\[
s=\delta_1-\delta_{-1}.
\]

A five-diagonal representation therefore has two forced zero modes. Any block determinant obtained from the recurrence has the form

\[
\det(zI-H_{\mathrm{block}})=z^2G(z),
\]

where the remaining factor is a reduced determinant on the quotient by the kernel.

## Why the reduction is circular

The desired identity would need to identify the reduced determinant at zero with

\[
-\sum_t\frac1{k_t}.
\]

However, elimination of the recurrence block gives Schur complements involving the inverse of the reduced Jacobi operator. Those inverses depend on the same Green function entries whose diagonal trace is

\[
\operatorname{tr}(K^{-1})=\sum_t\frac1{k_t}.
\]

Thus the recurrence reduction does not produce a new invariant; it reproduces the existing Cauchy--Binet formula in disguised form.

## Conditional reduction

If one assumes an independent identity

\[
\det(H_IK^3H_I^T)=C\cdot R_p
\]

where \(R_p\) is a recurrence determinant computed without using the kernel vector, then

\[
R_p\ne0
\]

would prove \(S\ne0\). No such recurrence-only determinant formula has been obtained.

## Obstruction

The first exact obstruction is that the recurrence data determine the kernel vector only up to the same normalization used in the determinant attack. The quotient determinant therefore contains the missing quantity \(S\) through the Green function of the singular operator. Proving its nonzero value from the recurrence block alone requires an additional sign, positivity, or irreducibility statement over finite fields, none of which follows from the Apéry recurrence.

Therefore this route is presently a conditional reformulation, not an independent proof. It avoids the known generic Hasse and norm dead ends, but it does not yet break the circular dependence on the reciprocal trace.
