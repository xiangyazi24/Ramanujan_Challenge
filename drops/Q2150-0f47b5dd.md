# P3.2 direct attack: component cocycle and the balanced offset

## Verdict

The component-level cocycle observation is correct **after one important convention is fixed**, and it gives a useful exact decomposition of the residual graph, but it does not by itself convert one unbalanced cycle into a low-height carrier for all of the balanced cycle rank.

The correct graph is the **physical prime multigraph**, obtained after identifying the source and target copies of the same prime.  On that graph, let `omega` be the integer 1-cochain which is `+1` along every intrinsic arrow `p -> q` and `-1` against it.  Then for a connected component `G`:

```text
all closed-walk imbalances vanish
    <=>
there is ell : V(G) -> Z, unique up to an additive constant,
with ell(q)=ell(p)+1 for every intrinsic arrow p -> q.
```

The phrase “all cycles” must include the 2-edge cycles created by parallel edges.  In particular, if both intrinsic arrows `p -> q` and `q -> p` are present, their physical 2-cycle has imbalance `2`, so an all-balanced component contains no opposite intrinsic pair.

There is also a precise correction to the second half of the proposed dichotomy.  Write the edge labels and prime coordinates as

```text
a_e = X + t_e,
p_v = 2*X + C_v.
```

One unbalanced cycle fixes the **relative affine prime offset** `C_v` (equivalently one root offset such as the `c` used in the earlier cycle normal forms) from the label word.  It does **not** fix the common translation `X`.  Indeed

```text
a_e -> a_e + h,
p_v -> p_v + 2*h
```

preserves every DAP equation.  Once one unbalanced cycle fixes one root value `C_o`, all `C_v` in the connected component are fixed by a spanning tree, and every other chord, balanced or unbalanced, becomes a word-only compatibility equation.  So the proposed “one global affine offset” statement is correct if “offset” means `C_o`, not the absolute translate `X`.

The useful quantitative graph decomposition is the following.  Fix a spanning tree `T`, let `U_T` be the chords whose fundamental cycles have nonzero imbalance, and let

```text
H_T := T plus all zero-imbalance chords.
```

Then exactly

```text
H_T is integer-layered,

beta(G) = |U_T| + beta(H_T).                         (SPLIT)
```

This is the correct way to avoid multiplying one anchor-cycle height once per balanced generator.  Do **not** make every balanced cycle unbalanced by adding the anchor cycle.  Keep the defect chords and the exact layered kernel separate.

There is a sharp graph-theoretic obstruction to doing better from the cocycle alone.  Take the incidence graph of a projective plane of order `r`, orient every point-line incidence from level `0` to level `1`, and then add one extra intrinsic arrow between two level-0 vertices.  The exact incidence subgraph has

```text
M = r^2+r+1,
|V| = 2*M,
|E| = (r+1)*M,
beta = (r-1)*M + 1,
```

is `(r+1)`-regular, and has no `K_(2,2)`.  After adding the single defect edge the component has

```text
beta = (r-1)*M + 2,
min_T |U_T| = 1.
```

Every unbalanced cycle contains that one defect edge.  Hence any family of unbalanced physical cycles marking a constant fraction of the cyclomatic rank must reuse the same anchor edge `Omega(beta)` times.  This fixture has no parallel opposite pair and can be placed in a one-sign DAP shell geometrically.  It is **not** asserted to be Apéry-selected.  It proves only that the requested bounded-congestion conclusion is not a consequence of the cocycle/geometry package alone.

On the all-balanced side there is, however, a genuine arithmetic input.  The Q2148 source-reflection codegree argument actually does not require `p<q`.  If `q1<q2` are target primes in `(N,2N]`, put

```text
A = (q2-q1)/2.
```

Let `c_A(q1,q2)` be the number of shell primes `p` for which both actual arrows

```text
p -> q1,
p -> q2
```

are selected.  Then the same exponent-five interval numerator used in Q2148 gives

```text
c_A(q1,q2)
 <= floor(((A-1)*log 311 + 5*log(2*N))/log N).       (CODEGREE)
```

No numerical ordering between `p` and `q_i` is needed: source reflection sends the two source zeros to

```text
(q1-1)/2,
(q2-1)/2,
```

whose gap is `A` and whose whole interval lies below `N<p`.  Consequently

```text
A=1  => c_A=0,
A=2  => c_A<=2 for N>=69,
A=o(log N) => c_A<=5 eventually.
```

Therefore, if `R_D` denotes the number of actual oriented `K_(2,2)` rectangles whose two targets have defect `1<=A<=D`, then for

```text
D=o(log N)
```

one has, eventually,

```text
R_D
 = sum_(q1<q2, (q2-q1)/2<=D) binom(c_A(q1,q2),2)
 <= 10*D*pi(2*N)
 = O(D*N/log N).                                      (RECT-UP)
```

In particular, for

```text
D_N = o(log N / loglog N),
```

```text
R_(D_N) = o(N/loglog N).                              (RECT-o)
```

This is a proved quantitative input toward the desired cyclomatic bound.

What is still missing is now very sharply localized.  A pure graded graph need not contain any `K_(2,2)` at all: the projective-plane incidence graph is the standard arbitrarily-high-degree counterfixture (the order-2 case is the 3-regular Heawood graph, with `14` vertices, `21` edges, `beta=8`, and no 4-cycle).  Thus the needed extra input has to use actual Apéry selectedness/folding, not only graph degree.

A route-closing statement is:

```text
[SELECTED-LAYER-RECT]

Choose D_N=o(log N/loglog N).
For every exact layered subgraph H_T arising from the actual mate-free
residual after the established reductions,

    beta(H_T)
      <= C * R_(D_N)(H_T) + o(N/loglog N)

with an absolute C.
```

Combined with `(RECT-o)`, this gives `beta(H_T)=o(N/loglog N)`.  Combined further with the already-isolated selected cochain-sparsity / weighted-congestion input controlling `|U_T|`, `(SPLIT)` gives the full cyclomatic target.

So the component cocycle is useful, but in a more precise form than “one unbalanced cycle solves the component”: it splits the problem into a cochain-defect part and a genuinely graded selected-incidence part.  The latter is where actual Apéry arithmetic must rule out projective-plane-like high-girth incidence.

# 1. Which graph carries the cocycle?

This convention is essential.

## 1.1 Physical prime multigraph

Let `G_phys` have one vertex for each physical prime value appearing in the residual.  For every actual intrinsic DAP event

```text
p -> q,
a(p,q)=p-(q+1)/2,
p*q | b_(a(p,q)),
```

put one undirected geometric edge between the vertices `p` and `q`, remembering its intrinsic arrow `p -> q`.

Because the ordered pair `(p,q)` determines the label, there is at most one intrinsic DAP edge for a fixed ordered pair.  Both ordered pairs may in principle occur, so the physical graph can contain the two parallel geometric edges

```text
p -> q,
q -> p.
```

The residual is noncentral, so there are no loops `p -> p` in the present discussion.

Define the integer 1-cochain `omega` by

```text
integral of omega along p -> q = +1,
integral of omega along q -> p on the same edge = -1.
```

For an oriented closed walk

```text
W = v_0,e_0,v_1,...,e_(m-1),v_m=v_0,
```

put

```text
S(W) = integral_W omega
     = sum_i epsilon_i,
```

where `epsilon_i=+1` when the traversal follows the intrinsic arrow of `e_i` and `-1` otherwise.

This is the imbalance used by the existing cycle algebra.

## 1.2 The bare left/right-copy graph is the wrong object

If one keeps separate source and target copies,

```text
p_L,
p_R,
```

then every DAP edge is simply

```text
p_L -> q_R.
```

On that bare bipartite graph the sign cochain is always exact for the trivial reason

```text
ell(p_L)=0,
ell(q_R)=1.
```

Every bipartite cycle alternates between traversing an intrinsic edge with and against its arrow, so its imbalance is automatically zero.  Therefore doing the cocycle test before identifying physical copies destroys the information that Q2150 is trying to use.

There are two equivalent safe conventions:

```text
(A) contract p_L and p_R to one physical prime vertex p;
```

or

```text
(B) keep the copies but add a zero-cochain “identity edge”
    p_L -- p_R for every physical prime p,
    and require any level function to be equal across that identity edge.
```

Contracting those zero edges gives convention (A).  I use (A) below.

## 1.3 Parallel opposite pairs

Suppose both intrinsic arrows occur:

```text
p -> q,
q -> p.
```

Traverse the first from `p` to `q` and the second from `q` to `p`.  Both traversals follow their arrows, so the physical 2-cycle has

```text
S = 1+1 = 2.                                          (1.1)
```

Hence an all-balanced component cannot contain an opposite pair.

If one allowed duplicate parallel copies with the **same** intrinsic direction, the 2-cycle using one forward and the other backward would have imbalance `1-1=0`; but intrinsic DAP data do not create such duplicates for one ordered pair.

Thus “every cycle is balanced” must mean every closed walk, or equivalently every ordinary simple cycle **plus the parallel 2-cycles**.

# 2. Exactness theorem for an all-balanced component

## Proposition 2.1 — integral grading

Let `G` be a connected physical DAP multigraph.  The following are equivalent.

```text
(i)  S(W)=0 for every closed walk W in G.

(ii) There exists ell : V(G) -> Z such that

       ell(q)-ell(p)=1

     for every intrinsic arrow p -> q.
```

Such `ell` is unique up to an additive constant.

### Proof

`(ii) => (i)` is telescoping:

```text
S(W)
 = sum_edges (ell(next)-ell(previous))
 = 0.
```

For `(i) => (ii)`, choose a root `o` and set `ell(o)=0`.  For any vertex `v`, choose an undirected path `P` from `o` to `v` and define

```text
ell(v)=S(P).
```

If `P'` is another path, `P` followed by the reverse of `P'` is a closed walk, so

```text
S(P)-S(P')=0.
```

Thus `ell(v)` is path-independent and integral.  If `p -> q` is an intrinsic edge, take a root-to-`p` path and then that edge.  This gives

```text
ell(q)=ell(p)+1.
```

If `ell_1,ell_2` both satisfy the edge equations, their difference is constant on every edge and hence on the connected graph.  QED.

## Consequences

Normalize the minimum level to `0` and put

```text
V_j = {v : ell(v)=j}.
```

Then

```text
all intrinsic arrows go V_j -> V_(j+1),             (2.1)
```

and no other edges exist.  Since the component is connected, the nonempty levels form a consecutive interval of integers.

So an all-balanced component is not merely bipartite: it is an **integer-graded directed graph with unit level increment**.

In particular:

```text
- there are no directed cycles;
- every underlying cycle has equally many upward and downward traversals;
- opposite intrinsic pairs are impossible;
- parity of ell gives a canonical bipartition.
```

This is the strict layered classification requested in task 3.

# 3. Spanning-tree defect and the exact split in every component

The same construction works without assuming all cycles are balanced.

Fix a spanning tree `T` of a connected physical component and a root `o`.  Define the tree potential

```text
ell_T(v)=S(P_T(o,v)),                                  (3.1)
```

where `P_T(o,v)` is the unique tree path.

For a chord `e : p -> q`, define its cochain defect

```text
delta_T(e)
 := 1 - (ell_T(q)-ell_T(p)).                           (3.2)
```

Orient the fundamental cycle by traversing `e` from `p` to `q` and then returning along the tree path.  Then exactly

```text
S(C_e)=delta_T(e).                                     (3.3)
```

This is the Q2126 identity in the present intrinsic-arrow notation.

Put

```text
U_T = {e notin T : delta_T(e) != 0},                  (3.4)

H_T = T union {e notin T : delta_T(e)=0}.             (3.5)
```

Every edge of `H_T` satisfies

```text
ell_T(q)=ell_T(p)+1,
```

so `H_T` is all-balanced and exactly layered by `ell_T`.

Since every chord contributes one to the cyclomatic rank,

```text
beta(G) = |E(G)|-|V(G)|+1
        = # {chords of T},
```

and the balanced chords are precisely the chords of `H_T`.  Therefore

```text
boxed:

beta(G) = |U_T| + beta(H_T).                           (3.6)
```

This identity is stronger for Q2150 than merely saying that the cycle map has rank at most one.  It separates **positive cochain defects** from the exact graded cycle rank.

If `T` minimizes `|U_T|`, then Q2126's invariant is

```text
delta_0(G,omega)=min_T |U_T|,
```

and `H_T` is a maximum-edge exact subgraph containing a spanning tree.

# 4. One unbalanced cycle fixes the relative affine offset

Now insert the DAP affine geometry.

Choose a common label translate `X` and write

```text
a_e = X+t_e.                                           (4.1)
```

For every physical prime vertex write

```text
p_v = 2*X + C_v.                                       (4.2)
```

For an intrinsic edge

```text
u -> v
```

with label `a_e=X+t_e`, the DAP relation is

```text
X+t_e
 = (2*(2*X+C_u)-(2*X+C_v)-1)/2.
```

Equivalently,

```text
C_v = 2*C_u - 2*t_e - 1.                               (4.3+)
```

Traversing the same edge against its arrow gives the inverse relation

```text
C_u = (C_v + 2*t_e + 1)/2.                             (4.3-)
```

These are exactly the `+/-` transitions used in Q2125.

## 4.1 Composition along a walk

For a walk step of sign `epsilon=+1` or `-1`, write

```text
C_next = 2^epsilon * C_current + eta,

eta = -2*t-1              if epsilon=+1,
      (2*t+1)/2           if epsilon=-1.              (4.4)
```

After a walk `W` from `u` to `v`, composition gives

```text
C_v = 2^S(W) * C_u + D_W,                              (4.5)
```

where

```text
D_W in Z[1/2]
```

is an explicit dyadic rational depending only on the signed label word `(epsilon_i,t_i)`.

For a closed walk based at `u`, (4.5) becomes

```text
(1-2^S(W))*C_u = D_W.                                  (4.6)
```

Therefore:

```text
S(W)=0
  => D_W=0, with C_u free;                             (4.7)

S(W)!=0
  => C_u = D_W/(1-2^S(W)), uniquely.                  (4.8)
```

The actual physical component guarantees that the right side in (4.8) has the required integrality/parity after the harmless powers of two are cleared.

This proves the cycle-level dichotomy directly.

## 4.2 Spanning-tree form

For the tree path from `o` to `v`, write

```text
C_v = 2^ell_T(v) * C_o + D_v,                         (4.9)
```

with `D_v in Z[1/2]` determined by the tree label word.

Take a chord `e : u -> v`.  Substituting (4.9) into (4.3+) gives

```text
A_e * C_o = B_e,                                      (4.10)
```

where

```text
A_e = 2^ell_T(v) - 2^(ell_T(u)+1),                    (4.11)

B_e = 2*D_u - 2*t_e - 1 - D_v.                       (4.12)
```

All quantities are dyadic rationals; multiplying every row by a sufficient power of two gives an equivalent integer equation, and powers of two are units at every odd marked prime in the DAP shell.

By (3.2),

```text
A_e=0
  <=> ell_T(v)=ell_T(u)+1
  <=> delta_T(e)=0
  <=> C_e is balanced.                                (4.13)
```

Thus a balanced chord contributes the pure word equation

```text
B_e=0.                                                (4.14)
```

An unbalanced chord has `A_e!=0` and fixes

```text
C_o=B_e/A_e.                                          (4.15)
```

If some unbalanced cycle exists, at least one fundamental cycle is unbalanced, because any cycle is an integral combination of fundamental cycles and imbalance is additive.  Choose one such chord `e_0`.  Then (4.15) fixes `C_o`, and (4.9) fixes every `C_v` in the component.

Every other unbalanced chord gives the word-only compatibility

```text
A_e*B_(e_0) - A_(e_0)*B_e = 0,                        (4.16)
```

while every balanced chord gives (4.14).

This is the exact component-wide form of the proposed observation.

## 4.3 What remains free

Equation (4.15) fixes `C_o`, not `X`.

The simultaneous transformation

```text
X     -> X+h,
a_e   -> a_e+h,
p_v   -> p_v+2*h,
C_v   -> C_v
```

preserves (4.1)-(4.3).  Therefore the whole affine word has one unavoidable common translate.

This is exactly the distinction already visible in Q2125: a balanced four-cycle leaves the offset `c` free; an unbalanced word can fix that `c`, but the base label `A` or `X` still carries absolute-size height in local continuants.  The gap-2 denominator obstruction from Q2125 is therefore **not** removed merely by anchoring the relative offset elsewhere in the component.

So the corrected statement is:

```text
one unbalanced cycle + a spanning-tree relative label word
    fixes every relative prime constant C_v,

but it does not fix the common translation X
    unless one absolute label/prime is also supplied.                  (4.17)
```

# 5. Why the anchor must not be copied into every balanced generator

There is a tempting but wrong bookkeeping step:

```text
for each balanced cycle Z_i,
replace it by Z_i + k_i*Z_0
```

where `Z_0` is one unbalanced anchor.  Algebraically this can give a nonzero imbalance, but a positive carrier inequality does not permit cancellation of physical support.  Every such use pays the anchor support again.

The safe use of the anchor is only the scalar specialization

```text
C_o = B_(e_0)/A_(e_0).                                 (5.1)
```

Because the actual component makes this an actual integral relative offset, any subsequent balanced-cycle continuant can be evaluated at that same `C_o` **without multiplying by the anchor carrier again**.  In other words:

```text
anchor once to determine the parameter;
do not concatenate the anchor physical cycle to every kernel cycle.   (5.2)
```

This eliminates an artificial anchor-height factor.

However it does not produce the requested subcritical family from the current banked arithmetic.  The reason is structural: the imbalance homomorphism

```text
S : H_1(G,Z) -> Z
```

has image of rank one when nonzero, so

```text
rank ker(S) = beta(G)-1.                                (5.3)
```

Fixing the one scalar offset resolves the image direction.  It does not remove the `beta-1` balanced cycle directions.

The exact split (3.6) is therefore the correct positive-support bookkeeping device.

# 6. Sharp no-go for a constant-fraction unbalanced carrier family

The following graph fixture contains no parallel opposite pair and makes the obstruction exact.

## 6.1 Balanced projective-plane block

Let `r` be a prime power and let

```text
M=r^2+r+1.
```

Take the incidence graph `H_r` of the projective plane of order `r`:

```text
left vertices  = M points,
right vertices = M lines,
point -- line iff incident.
```

Orient every incidence

```text
point -> line.
```

Then

```text
ell(point)=0,
ell(line)=1
```

is an exact integer grading.  Thus every cycle is balanced.

The graph is `(r+1)`-regular and

```text
|V(H_r)|=2*M,
|E(H_r)|=(r+1)*M,

beta(H_r)
 = (r+1)*M - 2*M + 1
 = (r-1)*M + 1.                                      (6.1)
```

It has no `K_(2,2)`, because two distinct points lie on exactly one common line.

## 6.2 Add one defect edge

Choose two distinct point vertices `x,y` and add one new intrinsic arrow

```text
x -> y.                                               (6.2)
```

Call the resulting connected graph `G_r`.

The new edge joins two vertices of the same old level, hence its defect relative to `ell` is

```text
1-(ell(y)-ell(x))=1.                                   (6.3)
```

Choose a spanning tree `T` inside `H_r`.  Every old chord has defect `0`, while the single new edge has defect `1`.  Therefore

```text
U_T={x->y}.                                            (6.4)
```

Since `G_r` is not exact, `min_T |U_T|` cannot be `0`; hence

```text
boxed:

min_T |U_T|=1.                                         (6.5)
```

But

```text
beta(G_r)=beta(H_r)+1=(r-1)*M+2.                       (6.6)
```

This tends to infinity like `r^3`.

Moreover every unbalanced cycle of `G_r` contains the new edge: a cycle avoiding it lies entirely in `H_r` and is balanced.  Thus any family of `K` physical unbalanced cycles has congestion at least `K` on that single edge.

So no graph theorem of the form

```text
one unbalanced cycle
  => there is a bounded-congestion family of unbalanced cycles
     marking c*beta(G) generators
```

can be true, for any fixed `c>0`.  The anchor is forced to be reused `Omega(beta)` times.

The fixture has no parallel edges at all.  Thus deleting opposite pairs does not fix it.

## 6.3 DAP geometry versus selectedness

This obstruction is not an assertion that the actual Apéry divisibility predicates select a projective-plane incidence graph.

At the geometry-only level it can be embedded in a one-sign shell: assign the point vertices distinct primes in a lower subinterval of `(N,2N]`, assign the line vertices distinct primes in an upper subinterval, orient point-to-line, and choose the extra point edge in increasing prime order.  Every used pair then has `p<q`, and

```text
a=p-(q+1)/2 >= 0
```

throughout the shell.

Thus the affine DAP equation and one-sign orientation do not exclude the fixture.  What may exclude it is **actual Apéry selectedness** (and possibly any stronger caller-local definition of “mate-free” beyond deletion of opposite intrinsic arrows).  That is precisely the arithmetic layer which remains to be proved.

# 7. All-balanced components: exact local shape

Suppose now that `G` itself is all-balanced and use the grading `ell` from Proposition 2.1.

Every edge joins consecutive levels.  Therefore a simple 4-cycle has only two possible level words, up to reversing the cycle and translating all levels.

## Type R: two-level rectangle

```text
levels: j, j+1, j, j+1,
steps:  +, -, +, -.
```

There are two level-`j` source vertices and two level-`j+1` target vertices, with all four arrows from the lower level to the upper level.  This is an oriented `K_(2,2)` rectangle of the Q2125/Q2148 type.

## Type D: three-level diamond

```text
levels: j, j+1, j+2, j+1,
steps:  +, +, -, -.
```

There is one bottom source, two middle vertices, and one top target:

```text
        top
       /   \
    mid1  mid2
       \   /
      bottom
```

with arrows

```text
bottom -> mid1,
bottom -> mid2,
mid1   -> top,
mid2   -> top.
```

So even a 4-cycle need not be a same-layer Q2148 rectangle.  The layered theorem is therefore stronger and more precise than simply saying “the component is bipartite.”

For longer cycles, the level sequence is an arbitrary closed nearest-neighbor walk on `Z`.

This already explains why pure graph degree does not force Q2148 rectangles: a high-girth two-level incidence graph can have no 4-cycles at all, and multi-level graphs can route their cycle rank through longer level walks.

```text
p | b_(a_i).
```

Apéry reflection modulo the **source prime** `p` gives

```text
p | b_(p-1-a_i)
  = b_((q_i-1)/2).                                    (8.3)
```

Therefore every common source satisfies

```text
p | b_u,
p | b_(u+A).                                         (8.4)
```

The crucial point is that

```text
u+A=(q2-1)/2 < N < p.                                 (8.5)
```

Hence the entire return interval is below every common source prime, regardless of whether `p<q_i` or `p>q_i`.  All recurrence denominators in the interval are `p`-units.

Let `U_A(u)` denote the same banked exponent-five normalized interval integer used in Q2148.  The two properties needed here are exactly

```text
p | U_A(u) for every p in C(q1,q2),                    (8.6)

log |U_A(u)|
 <= (A-1)*log 311 + 5*log(2*N).                        (8.7)
```

The common sources are distinct primes `>N`, so their product divides `U_A(u)`.  Consequently

```text
|C(q1,q2)|*log N
 <= (A-1)*log 311 + 5*log(2*N).                        (8.8)
```

Thus:

## Proposition 8.1 — source codegree

```text
boxed:

c_A(q1,q2):=|C(q1,q2)|
 <= floor(
      ((A-1)*log 311 + 5*log(2*N))/log N
    ).                                                 (8.9)
```

This is Q2148's fixed-defect source bound with the unnecessary monotone ordering hypothesis removed.

### A=1

If `A=1`, (8.4) says

```text
p | b_u,
p | b_(u+1),
```

which is impossible for the shell primes by the no-consecutive-zero theorem.  Hence

```text
c_1(q1,q2)=0.                                          (8.10)
```

### A=2

Q2148's centered gap-2 calculation gives

```text

```

At the centered target midpoint

```text

```

every common source divides `F_2(Q)`, and

```text

```

Therefore three distinct common source primes would have product `>N^3`, impossible for `N>=69`.  Hence

```text
c_2(q1,q2)<=2    for N>=69.                            (8.11)
```

### Small growing A

If

```text

```

then the right side of (8.9) is

```text

```

but is strictly less than `6` for all sufficiently large `N`.  Thus

```text

```

This is an actual selectedness constraint that a generic layered graph does not satisfy for free.

# 9. Global upper bound for small-defect actual rectangles

Define `R_D(N)` to be the number of oriented actual `K_(2,2)` packets


with distinct shell primes, all four selected arrows

```text

```

and

```text

1 <= (q2-q1)/2 <= D.                                  (9.1)
```

No level hypothesis is needed for the upper bound.  In an exact layered graph, any such packet automatically has `p1,p2` in one level and `q1,q2` in the next level.

Fix the target pair `(q1,q2)`.  If its common-source codegree is `c_A`, then exactly

```text

```

unordered choices of two common sources produce a `K_(2,2)`.

Take

```text

```

By (8.12), eventually `c_A<=5` for every `A<=D`; hence

```text
binom(c_A,2)<=10.                                      (9.3)
```

For each `q1` and each integer `A` with `1<=A<=D`, there is at most one candidate

```text

```

Therefore the number of target pairs is at most

```text
D * # {primes q1 in (N,2N]}
 <= D*pi(2*N).                                         (9.4)
```

Combining (9.2)-(9.4),

```text
boxed:

R_D(N) <= 10*D*pi(2*N)
        = O(D*N/log N).                                (9.5)
```

Consequently, if

```text

```

then

```text
boxed:

R_(D_N)(N)=o(N/loglog N).                              (9.7)
```

This is a rigorous quantitative input toward the residual target.  It uses actual Apéry selectedness through source reflection and the exponent-five interval height.

Notice the direction: it is an **upper** bound on the number of small-defect actual rectangles.  To convert it into a cyclomatic bound, one needs a lower/charging statement saying that large graded excess would create many such rectangles.

# 14. Final assessment

The proposed dichotomy should be recorded in the following corrected form.

## Proven component cocycle theorem

For the **physical** connected DAP multigraph:

```text
all closed walks balanced
  <=>
there exists an integer level ell with
ell(q)=ell(p)+1 on every intrinsic p->q.               (14.1)
```

Opposite parallel arrows create imbalance `2` and therefore cannot occur in this branch.

## Proven affine-offset theorem

With

```text
a_e=X+t_e,
p_v=2X+C_v,
```

one has for every signed walk

```text
C_end=2^S*C_start+D_word.                              (14.2)
```

Hence

```text
S=0   => word compatibility only, relative offset free;
S!=0  => relative offset uniquely fixed.               (14.3)
```

One unbalanced fundamental cycle fixes `C_o` for the entire connected component.  It does **not** fix the common translate `X`.

## Proven no-reuse decomposition

For every spanning tree,

```text
beta(G)=|U_T|+beta(H_T),                               (14.4)
```

where `H_T` is exactly integer-layered.  This is the positive-support way to avoid multiplying one anchor height through the balanced kernel.

## Scoped counterexample

One unbalanced cycle does **not** force a constant fraction of the cycle rank to be represented by bounded-congestion unbalanced cycles.  The projective-plane incidence graph plus one same-level defect edge has

```text
min_T |U_T|=1,
beta -> infinity,
```

and every unbalanced cycle reuses the same defect edge.  This is a graph/geometry counterfixture, not an Apéry-selected counterexample.

## New arithmetic input

For any target pair with defect `A`, the actual common-source codegree satisfies

```text
c_A(q1,q2)
 <= floor(((A-1)*log311+5*log(2N))/log N),             (14.5)
```

without assuming `p<q`.  In particular

```text
c_1=0,
c_2<=2 for N>=69,
c_A<=5 for A=o(log N) eventually.                      (14.6)
```

Therefore actual small-defect rectangles satisfy

```text
R_D=O(D*N/log N),                                      (14.7)
```

and hence

```text
D=o(log N/loglog N)
   => R_D=o(N/loglog N).                               (14.8)
```

## Sharply isolated next statement

The all-balanced/high-degree branch closes if actual selectedness proves

```text
beta(H_T)
 <= C*R_(D_N)(H_T)+o(N/loglog N)
```

for some `D_N=o(log N/loglog N)`.  Pure graph theory cannot prove this because projective-plane incidence graphs are exact, high-degree, and rectangle-free.

So the component cocycle does materially advance the architecture: it converts the residual cyclomatic problem into the sum of a **cochain-defect problem** and a **graded selected-incidence problem**, and the latter now has an explicit small-defect rectangle upper bound at the correct `o(N/loglog N)` scale.  What remains is the genuinely arithmetic theorem excluding projective-plane-like selected incidence, not another renaming of the balanced offset.
