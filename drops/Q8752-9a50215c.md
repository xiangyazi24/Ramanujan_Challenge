# The sieve-theoretic saving for LGTQ-3

## Executive conclusion

The right framework is **not** GPY/Maynard with an Apéry weight. The Apéry-hit condition is a moving-modulus, recurrence-defined condition. The natural framework is a **new large-sieve/trace-function sieve for Frobenius conditions of a holonomic sequence**. A standard level-of-distribution statement would be sufficient, but it is not the ordinary Bombieri–Vinogradov input.

The key correction is that the naive independent probability is not the main obstacle. The hard issue is proving that nearby primes do not have anomalously large correlations.

## 1. Conditional probability heuristic

For a single prime p in the quotient cell q=floor(n/p), the condition is

```
n mod p in Z_p.
```

The heuristic density is

```
alpha_p = |Z_p|/p.
```

Using the current Apéry zero-density input |Z_p|=O(p^(2/3)), this is already much smaller than the random model 1. The expected triple density under independence is

```
alpha_{p0} alpha_{p1} alpha_{p2}.
```

If alpha_p≈1/p, then a fixed prime triple contributes about q^3/n^3. Multiplying by the number of prime triples gives a vanishing expectation.

However, this does not prove LGTQ-3 because the three events are not independent random choices.

## 2. The actual correlation mechanism

For p0=p, p1=p-h1/q, p2=p-(h1+h2)/q, one has

```
u1=u0+h1,
 u2=u0+h1+h2.
```

Thus the triple condition is a recurrence correlation:

```
p0 | b_u,
p1 | b_{u+h1},
p2 | b_{u+h1+h2}.
```

The same Apéry orbit is being sampled in three nearby characteristics. This is the only possible source of a large deviation from independence.

The relevant object is therefore not the distribution of the individual zero sets Z_p, but the shifted intersection

```
Z_p ∩ (Z_{p-d}-h) ∩ (Z_{p-d-e}-h-k).
```

## 3. Why ordinary sieves do not apply directly

Selberg sieve, GPY and Maynard–Tao start with congruence conditions or weights depending on fixed moduli. Here the condition

```
f_n(p)=1_{p|b_{n mod p}}
```

has a modulus equal to p itself and a target determined by n modulo p. Therefore it is not a fixed residue-class sieve.

There is no immediate Bombieri–Vinogradov theorem because there is no family

```
pi(X;q,a)
```

with fixed q and varying a.

## 4. The correct replacement: Apéry trace sieve

One needs an estimate of the form

```
Σ_{p in I} 1_{p|b_{n mod p}}
                 1_{p-h|b_{n mod(p-h)}}
                 1_{p-h-k|b_{n mod(p-h-k)}}
```

with cancellation after removing the diagonal main term.

Equivalently, define the local trace functions

```
F_p(n)=1_{n mod p in Z_p}.
```

The desired input is a correlation bound

```
Σ_n F_p(n)F_{p-d}(n)F_{p-d-e}(n)
```

matching the product of local densities plus an error smaller than the Hardy–Littlewood scale.

This is closer to a large sieve for compatible Frobenius conditions than to Maynard.

## 5. Character sums

The additive character expansion is formally correct:

```
1_{b_u=0 mod p}=1/p Σ_t exp(2πi t b_u/p).
```

The resulting sums are not generic exponential sums. The phase comes from the Apéry recurrence, so Deligne applies only after constructing the corresponding l-adic sheaf.

The required theorem would be a statement that the shifted Apéry sheaf has bounded conductor and no exceptional invariant subspace. Then one obtains square-root cancellation in the nontrivial characters.

The previous Katz/Asai direction is therefore relevant: the needed estimate is a geometric monodromy statement, not a classical sieve estimate.

## 6. Density-one versus all-n

An averaged statement

```
Σ_{n≤N} T_{q;h1,h2}(n)=o(N*n/(log n)^3)
```

is much weaker and should follow from second-moment bounds on the trace correlations.

The all-n statement requires a pointwise large sieve. One needs to prevent exceptional n where many nearby primes land simultaneously in shifted Apéry zero sets.

## 7. Answer to the multiple choice

(a) Ordinary level of distribution >1/2: no. The condition is not a fixed-modulus sequence of residue classes.

(b) GPY with Apéry weights: no. GPY weights detect primes; they do not control recurrence-defined moving targets.

(c) Maynard–Tao: no direct application.

(d) Yes. The correct framework is a new sieve adapted to moving moduli, most naturally:

```
trace-function / l-adic large sieve
        +
Selberg upper-bound sieve for the prime constellation
        +
Apéry recurrence monodromy estimates.
```

The missing theorem for LGTQ-3 is therefore not a stronger prime-tuple estimate. The prime tuple count is already small. The missing input is an anti-correlation theorem for the triple shifted Apéry-hit indicator.

A plausible target lemma is:

```
max_{h1,h2<=C log n}
Σ_{p in I_q(n)}
F_p(n)F_{p-h1/q}(n)F_{p-(h1+h2)/q}(n)
=o(n/(log n)^3).
```

Proving this requires controlling the geometric monodromy of the shifted Apéry recurrence, not importing an existing prime sieve.
