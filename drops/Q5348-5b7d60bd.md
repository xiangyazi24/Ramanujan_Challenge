## 2. Exact graph structure which really follows

I distinguish the global occurrence DAG, the fixed-pair path, and the fixed-J prime graph.  Conflating them is the easiest way to invent a false forest theorem.

Every marked edge has K>J.  Therefore the owner-occurrence digraph (1.3) is acyclic under the physical-time order.


Hence the p,q-colored graph is a directed path (or a disjoint subcollection of path edges after dyadic restriction), with pair-colored indegree and outdegree at most one.

## 3. Proposed stronger graph properties: exact verdicts

### 3.1 Global laminarity of medium edge intervals: FALSE

The medium edge interval is `[J,K]`, whose length is about D, not the short first-return interval of length `<H`.

For different foreign colors q,r sharing p, one may have

```text
J_1 < J_2 < K_1 < K_2,
```

with

```text
(p,q): J_1 -> K_1,
(p,r): J_2 -> K_2.                                      (3.1)
```

There is no contradiction: q need not be selected at J_2 or K_2, and r need not be selected at J_1 or K_1.  The short first-return intervals have length `<H<<D`, so they can remain disjoint while the D-sized graph intervals cross.

Thus the family of graph intervals is not laminar.

### 3.2 Forbidden diamonds: FALSE across different foreign colors

Take physical positions

```text
K_1 = J + 6D/5,
K_2 = J + 7D/5,
L   = J + 13D/5.                                        (3.2)
```

Then all four gaps

```text
K_1-J, K_2-J, L-K_1, L-K_2
```

lie in `(D,2D]`.

It is source-compatible to have

```text
common selected starts of p,q:  J, K_1, L
common selected starts of p,r:  J, K_2, L,              (3.3)
```

with q absent at K_2 and r absent at K_1.

The unique-next rule then gives the diamond

```text
          K_1
        /     \
       J       L
        \     /
          K_2                                             (3.4)
```

where the upper path is q-colored and the lower path is r-colored.

Nothing in literal first-return order forbids this: the relevant first returns have length `<H<<D`.

So “diamond-free” is true only if one freezes the same pair color, in which case the graph is already a path.  It is false for the full marked occurrence graph.

### 3.3 Indegree/outdegree tradeoff: FALSE at aggregate level

At one occurrence `(p,J)`, pair-colored indegree/outdegree are each at most one **for each fixed q**.  But the aggregate degree sums over q.

Different q's may have their previous p,q common start before J while different r's have their next common start after J.  There is no first-return inequality coupling those two foreign sets.

A stationary dense incidence model can therefore have simultaneously

```text

weighted outdegree(p,J) ~ C_J.                          (3.5)
```

The affine construction in Section 5 does exactly this away from the physical boundary.

### 3.4 Bounded arboricity: FALSE in every useful weighted sense

There are three possible skeletons.

**Fixed pair skeleton.** Arboricity is 1, because it is a path.  This is already the long cap and gives no new power.

**Owner-time skeleton for one p, with q labels forgotten.** A source J can have up to `m_D(p,J)` different target K in the D-window.  First-return packing gives the natural scale

```text

```

which is a positive power at the critical point.  Thus even the simple skeleton is not bounded-arboricity uniformly.

**Fixed-J prime graph with actual q multiplicity retained.** This is the graph relevant to edge mass.  Its degree can reach

```text

```

At the critical scale this permits a constant-density graph on `C_J` weighted vertices, whose arboricity is itself of order `C_J`.

So no bounded-arboricity theorem compatible with the present source can yield a P-power improvement.

### 3.5 Interval nesting across source/target first-return cells: already spent

The only genuine interval packing is for the short first-return cells.  It gives, for a fixed target K,


### Acyclicity

Thus there is no hidden bounded-arboricity theorem to exploit.

## Final conclusion

The literal unique-next-common-prefix mechanism has real graph structure, but it is the wrong kind of structure for a new power by itself.

For one fixed pair it is as rigid as possible — a path — and that path can still have `P/D` medium edges, exactly saturating the long cap.  For one fixed owner, unique-next makes the target foreign-prime fibres disjoint, but this permits the owner to fill all `m_D` available targets with disjoint D-sized imprimitive shell-prime blocks, exactly saturating U_D.  First-return interval packing limits the number of targets but has already been used at both ends in the replicated moment ladder.

The affine-hyperplane incidence construction shows these phenomena can coexist in one temporally ordered, pairwise-consecutive, source-label-compatible model at the critical scale.  It has many crossings and colored diamonds, full aggregate indegree and outdegree, and dense fixed-J prime graphs while every fixed pair remains a path.  It also respects the current per-target `q|N_d(J)` shell-radical allowance and the requirement that used q's have an earlier short selected return.

Therefore a new proof must violate the affine incidence **arithmetically**, not graph-theoretically.  The smallest such violation is a power defect in the exact weighted short-return-imprimitive foreign mass, i.e. `CCU_theta`, or a power defect in actual selected pair-chain codegree, `LC_zeta`, on the same marked sector.  No present CC2q marginal, first-return, gcd/resultant, primitive-divisor, or ordinary degree-incidence theorem supplies either fixed power.
