# R1 audit: dyadic incidence from intersection bounds

## Terminal verdict

The available intersection injection and shifted cocycle identity do not force a power saving in the dyadic incidence sum. They control pairwise overlap after a collision is already present, but they do not prevent a configuration where many distinct gaps have essentially disjoint root sets.

The correct deterministic conclusion from the supplied inputs is only the known D^2 scale. A new input must control multi-gap correlation in the ordered cocycle, not merely intersections of existing Z_d.

## 1. Cauchy-Schwarz / dispersion calculation

Let

T = sum_{D/2 < d <= D} C_d,

and for each position r define

j_r = #{d in (D/2,D] : r in Z_d}.

Then

T = sum_r j_r.

The second moment is

sum_r j_r^2 = T + 2 sum_{h<k} |Z_h cap Z_k|.

Using the supplied injection

|Z_h cap Z_k| <= 3|h-k|,

we obtain

W := sum_{h<k} |Z_h cap Z_k|
 <= 3 sum_{h<k, h,k~D} (k-h).

There are O(D-j) pairs with separation j, hence

W <= c D^3

for an absolute c. Therefore

sum_r j_r^2 <= T + O(D^3).

Cauchy gives

T^2 <= A (T+O(D^3)),

where A=|union_{d~D} Z_d|.

Equivalently

T <= A + O((A D^3)^{1/2}).

Since A<=T, this inequality is compatible with T as large as order D^2 (indeed the error term is then order D^(5/2), so it is not restrictive). Optimizing block sizes in the same dispersion decomposition only replaces D^3 by the corresponding block separation moment and never changes the fundamental loss: pairwise intersection information controls collisions between gaps but not the total number of distinct roots.

Thus no exponent saving follows.

A sharp obstruction is a family with disjoint Z_d of size proportional to d. Then

C_d ~ D,

T ~ D^2,

while all intersections vanish and the intersection inequality is satisfied maximally. The only additional constraint needed would have to forbid this ordered disjointness.

## 2. The false difference-closed claim

The statement

Gap(r) is difference-closed

is false.

The actual identity is:

if d<d' and

xi_{r+d}=xi_r,
xi_{r+d'}=xi_r,

then

xi_{r+d'}=xi_{r+d}.

After shifting the base point to r+d, this gives

xi_{r+d+(d'-d)}=xi_{r+d}.

Therefore

(d'-d) in Gap(r+d),

not generally in Gap(r).

The gap set is transported by the cocycle; it is a family Gap(r), not one additive subset of Z. A projective orbit with nontrivial transition matrices does not preserve a common stabilizer at every base point.

Consequently no AP-tail or modulus structure at a fixed base follows from this identity alone.

## 3. Can shifted differences plus degree budgets help?

The natural charging attempt is:

charge a pair of large gaps d<d' sharing r to the smaller shifted gap g=d'-d at the new base r+d.

The number of such charges of size g is controlled by the small-gap budget

C_g <= 3(g-1).

However this counts shifted bases separately. The same original base r can generate many shifted return chains, and the charge target is not a fixed Z_g but a translated family.

The resulting bound is of the form

number of pairs with difference g <= (# possible shifts) * C_g,

and the shift multiplicity is order D. Summing gives again order D^3 for pair correlations, which is too weak to improve the first moment T.

The obstruction is exactly the missing quenched statement: the small-gap budget is averaged over bases, while the desired theorem needs uniform control of how many large-gap returns can be generated from the same ordered orbit segment.

## Abstract countermodel

Take an abstract equivalence relation on positions generated by many independent pairs.

For each dyadic gap d assign a set Z_d of size about d, with all Z_d pairwise disjoint. Realize each point r in Z_d by declaring r and r+d to have the same color/projective value. Add enough fresh colors to avoid accidental additional equalities.

Then:

- C_d is at the allowed degree scale;
- |Z_h cap Z_k|=0, satisfying the intersection injection;
- the shifted difference identity is vacuous because every fiber has only the intended pair;
- T=sum C_d is Theta(D^2).

Therefore the listed identities alone cannot yield FR_eta.

## Cross-resultants over Q

Nonvanishing resultants over Q do not solve the fixed-p problem in the required regime.

For fixed m,g, a nonzero resultant says the two polynomial root sets cannot coincide over an algebraic closure. But when m,g grow like sqrt(p)L:

1. the degrees of the relevant continuant polynomials grow;
2. reduction modulo p can create many accidental intersections;
3. a resultant bound over Q does not give a quantitative bound on the number of F_p roots shared by the moving family.

To be useful one needs a uniform lower bound on resultant valuations or a family-level estimate after reduction modulo p. Plain nonvanishing is qualitative and does not survive the quenched large-gap regime.

## Minimal missing arithmetic input

The smallest repair is a genuine ordered-cocycle anti-correlation theorem, for example:

For D in the mesoscopic range,

sum_{r} (# {d in (D/2,D] : xi_{r+d}=xi_r})^2 << D^{2+epsilon},

or equivalently a family-averaged large-sieve estimate for the return cocycle.

Any such statement immediately converts the first moment into a power-saving bound.

The present inputs only say:

- individual gaps have degree budgets;
- pairs of gaps intersect sparsely;
- shifted differences move to another base.

They do not say that the same orbit cannot support many dispersed returns.

## Final inequality / countermodel

Proved from current inputs:

T^2 <= A(T+O(D^3)),

which gives no improvement over T=O(D^2).

There exists an abstract configuration satisfying the intersection and shifted-difference constraints with

T=Theta(D^2).

Hence no deterministic FR_eta follows from these inputs alone.

The required new ingredient is a quenched, family-level arithmetic cancellation statement for the ordered Apéry cocycle.
