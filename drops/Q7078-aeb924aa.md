# Palindromic CRT reflection test

## Conclusion

The claim is **not literally true**: the 8 reflected CRT lifts are not equidistributed in the interval `[0,pqℓ)` in the strong sense. They are translates of a fixed 3-dimensional reflection cube, and for a concrete Apéry zero-set example the gaps are highly structured rather than random.

What is true is weaker: if the three reflection increments are generic, the eight points can be well separated (no collisions and gaps of size comparable to `pqℓ/8`). This is a spacing statement, not equidistribution.

## Explicit computation

Take

```
p = 17, Z_p = {3,13}
q = 19, Z_q = {8,10}
ℓ = 31, Z_ℓ = {8,22}
```

The CRT modulus is

```
N = 17*19*31 = 10013.
```

For residues modulo `(17,19,31)`, the CRT idempotent coefficients are

```
C_p = 589*(589⁻¹ mod 17) = 589*14 = 8246
C_q = 527*(527⁻¹ mod 19) = 527*15 = 7905
C_ℓ = 323*(323⁻¹ mod 31) = 323*17 = 5491
```

Choose the base zero triple

```
(r_p,r_q,r_ℓ)=(3,8,8).
```

Then

```
m_1 = 3*C_p + 8*C_q + 8*C_ℓ mod 10013
    = 1737.
```

The three reflection translations are

```
Δ_p = (16-2*3)C_p = 10*C_p = 2356 mod 10013
Δ_q = (18-2*8)C_q =  2*C_q = 5797 mod 10013
Δ_ℓ = (30-2*8)C_ℓ = 14*C_ℓ = 6783 mod 10013.
```

Therefore the eight reflected lifts are:

```text
subset          lift
{}              1737
{p}             4093
{q}             7534
{ℓ}             8520
{p,q}           9890
{p,ℓ}            863
{q,ℓ}           4304
{p,q,ℓ}         6660
```

Sorted:

```text
863, 1737, 4093, 4304, 6660, 7534, 8520, 9890
```

Circular gaps modulo 10013 are:

```text
874, 2356, 211, 2356, 874, 986, 1370, 986
```

## Interpretation

The reflection cube has a lattice structure. Here the three generators are

```text
Δ_p = 2356,
Δ_q = 5797,
Δ_ℓ = 6783  (mod 10013).
```

They do produce eight distinct points and the minimum gap is `211`, so there is strong separation. However the gap pattern

```text
874, 2356, 211, 2356, 874, 986, 1370, 986
```

is visibly arithmetic, not an equidistribution pattern.

Thus the correct statement for the Apéry zero-set argument is:

* palindromic reflection gives an 8-point translate cube;
* generic nonzero reflection increments usually prevent collisions;
* the eight lifts are spread through the CRT interval;
* but one should not claim they are equidistributed.

The usable consequence is a separation/anti-clustering input, not a uniform distribution theorem.
