# Q2283 — Partial-sum Christoffel–Darboux audit

## Conclusion

The proposed partial-sum CD route has the right shape, but the decisive inference is not valid without one additional normalization check: the displayed CD identity is not automatic for the same nested sequence \(\Psi_k\) with arbitrary weights \(w_k\). It requires the exact three-term recurrence normalization relating \(w_k\), \(\Psi_k\), and \(\Psi_{k+1}\).

The endpoint substitution is algebraically correct **if** that CD identity has already been established:

\[
(T_0-U)K_{19}(T_0,U)=-w_{19}\Psi_{19}(T_0)\Psi_{20}(U).
\]

However, the implication \(K(r,s)=0\Rightarrow \Psi_{20}(T_1)=0\) only follows after verifying that

1. \(w_{19}\neq0\pmod{181}\),
2. \(\Psi_{19}(T_0)\neq0\pmod{181}\), and
3. \(T_0-T_1\neq0\pmod{181}\).

The supplied data gives (2) and (3):

\[
\Psi_{19}(\lambda_{19})=101\not\equiv0\pmod{181},
\]

and the nonmate condition gives \(\lambda_{19}\neq\lambda_{47}\). The missing point is the explicit recurrence verification of the CD coefficient.

## The p=181 check

Using the proposed formula one should compute

\[
K_{19}(T_0,T_1)
= -\frac{w_{19}\,101\,\Psi_{20}(T_1)}{T_0-T_1}.
\]

The direct partial sum is already known:

\[
\sum_{k=0}^{19}w_k\Psi_k(T_0)\Psi_k(T_1)=134\pmod{181}.
\]

The remaining equality to check is therefore the scalar identity

\[
-w_{19}\,101\,\Psi_{20}(\lambda_{47})
\equiv
(\lambda_{19}-\lambda_{47})\,134
\pmod{181}.
\]

This is the cleanest test because it avoids recomputing the whole kernel.

## Why the vanishing argument is not yet a proof

If the CD identity holds, then for every nonmate pair with \(r<s\):

\[
K(r,s)=0
\implies
\Psi_{s+1}(\lambda_s)=0
\]

in the analogous truncation with \(r\). Since

\[
\Psi_{r+1}(T)=\prod_{j=0}^{r}(T-\lambda_j),
\]

one would obtain a contradiction whenever \(s>r\), because \(\lambda_s\) is not among the first \(r+1\) roots.

But this conclusion depends entirely on the exact CD boundary term. The earlier Q2266 objection remains relevant: a kernel built from arbitrary nested polynomials does not automatically satisfy a two-term CD formula. The recurrence must be checked symbolically.

## Required next verification

The next algebraic step is not a numerical scan. It is to derive from the defining recurrence of \(\Psi_k\) the identity

\[
(T-U)\sum_{k=0}^{n}w_k\Psi_k(T)\Psi_k(U)
=
C_n(\Psi_{n+1}(T)\Psi_n(U)-\Psi_n(T)\Psi_{n+1}(U))
\]

with the exact constant \(C_n=w_n\) (or the corrected coefficient if the normalization differs).

Once that recurrence-level identity is pinned down, the p=181 computation becomes a certificate rather than evidence. If the coefficient is wrong, the smallest residual term will appear exactly in the mismatch

\[
R=(T-U)K_n-C_n(\Psi_{n+1}(T)\Psi_n(U)-\Psi_n(T)\Psi_{n+1}(U)).
\]

The attack is therefore promising, but the claimed universal nonvanishing theorem is one lemma away: the exact CD recurrence identity, not the endpoint specialization, is the critical gap.
