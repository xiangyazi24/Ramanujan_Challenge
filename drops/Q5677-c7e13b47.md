# Multi-target Racah cutoffs: exact Smith basis and primitive saturation

## Verdict

The correct alternative is **(2)**.

For every k >= 2, the triangular mixed-characteristic lattice can be solved exactly. Its unreduced Smith factors are nontrivial, but after the two actual long hypergeometric coordinates are eliminated, no product of k-2 target primes survives as a nonzero primitive scalar.

The decisive results are:

```text
P_i := p_1 ... p_i,   P_0 := 1.

Full prefix-lattice Smith factors:
    d_i = P_(i-1)^2 p_i,     1 <= i <= k.

Actual two-coordinate target lattice:
    SNF = diag(1, P_k).

Target presentation with all quotient variables:
    SNF = diag(1, ..., 1).
```

Thus the entire target product P_k remains attached to the two long coordinates. Eliminating them leaves only quotient-variable syzygies and identically zero rank-one determinants.

```text
R_2 c_1 - R_1 c_2 = 0.
```

It is an identity, not a nonzero carrier.



## 3. Exact abstract triangular lattice

First ignore the rank-one relation among the c_i and solve only the integer target lattice.

### Theorem 3.1

The integer vectors (S_1,...,S_k) satisfying

```text
p_i | S_i,
P_i^2 | S_(i+1)-S_i
```

are exactly

```text
S_i = P_k t - sum_(h=i)^(k-1) P_h^2 c_h,

t,c_1,...,c_(k-1) in Z.
```

A basis is

```text
v_0 = P_k (1,1,...,1),

v_h = -P_h^2 (1,...,1,0,...,0),
                   ^ h entries 1
```

for 1 <= h < k.

### Proof

S_1 is divisible by P_1. If P_i divides S_i, then P_i^2 divides S_(i+1)-S_i, so P_i divides S_(i+1). The target p_(i+1) divides S_(i+1), and coprimality gives P_(i+1) divides S_(i+1). Thus P_k divides S_k. Writing S_k=P_k t and subtracting the consecutive differences gives the formula. The converse is immediate.

### Smith form

The unimodular difference-coordinate map

```text
(S_1,...,S_k) -> (S_k, Delta_(k-1),...,Delta_1)
```

turns the lattice into

```text
P_k Z  direct-sum  P_(k-1)^2 Z  direct-sum ... direct-sum P_1^2 Z.
```

For a fixed p_j, the valuations of these k entries are

```text
0 repeated j-1 times, then 1, then 2 repeated k-j times.
```

Sorting primewise gives

```text
SNF = diag(
    p_1,
    P_1^2 p_2,
    P_2^2 p_3,
    ...,
    P_(k-1)^2 p_k
).
```

After quotienting by the long direction v_0, the boundary lattice has Smith form

```text
diag(P_1^2, P_2^2, ..., P_(k-1)^2).
```

Dividing the universal squared-node factors leaves

```text
diag(1,...,1).
```

In particular p_k occurs only in the long target direction.

## 4. Correct target quotient variables

Introduce one quotient variable for every target equation:

```text
s + W q_i = p_i t_i,      1 <= i <= k.
```

The presentation matrix, with columns s,W,t_1,...,t_k, is

```text
A_k =
[ 1  q_1  -p_1   0    ...   0  ]
[ 1  q_2    0   -p_2  ...   0  ]
[ .   .     .     .    .    .  ]
[ 1  q_k    0     0    ...  -p_k].
```

### Proposition 4.1

```text
SNF(A_k) = diag(1,...,1).
```

### Proof

The matrix contains a 1. A maximal minor using the s-column and all quotient columns except t_i has absolute value

```text
P_k/p_i.
```

Since the p_i are distinct,

```text
gcd_i(P_k/p_i) = 1.
```

Therefore the gcd of the maximal minors is 1, and all invariant factors are 1.

This is the first place where omitting the divided quotient variables gives a false impression. A selected minor can contain many target primes, but the primitive maximal Fitting content is one.

### Exact kernel basis

Choose CRT idempotents e_i modulo P_k:

```text
e_i = 1 mod p_i,
e_i = 0 mod p_j for j != i.
```

Set

```text
sigma = -sum_i e_i q_i.
```

Then sigma+q_i is divisible by p_i in R. Every solution is uniquely

```text
s   = P_k A + sigma B,
W   = B,
t_i = (P_k/p_i) A + ((sigma+q_i)/p_i) B,

A,B in R.
```

The projection of this basis to the two long coordinates is

```text
[ P_k  sigma ]
[  0     1   ].
```

Hence

```text
SNF(kernel projection to (s,W)) = diag(1,P_k).
```

This is exactly where the target product lives. It is attached to the two long hypergeometric coordinates. There is no additional k-2 factor after those coordinates are removed.

## 5. Correctly divided boundary presentation

The divided boundary equations are

```text
c_i = W R_i.
```

Their matrix, with columns W,c_1,...,c_(k-1), is

```text
B_k =
[ -R_1   1   0   ...  0 ]
[ -R_2   0   1   ...  0 ]
[   .    .   .    .   . ]
[ -R_(k-1) 0 0 ...  1 ].
```

It contains an identity block, so

```text
SNF(B_k) = diag(1,...,1).
```

Eliminating W gives only the rank-one identities

```text
R_j c_i - R_i c_j = 0.
```

These identities are not nonzero target carriers.

Let J_k be the ideal generated by all target equations and all divided boundary equations. The CRT parametrization above, together with c_i=R_i B, gives a solution for arbitrary short coefficients q_i,R_i. Taking B=1 also proves the same statement after saturation by W. Therefore

```text
J_k intersect R[q_1,...,q_k,R_1,...,R_(k-1)] = (0).
```

No resultant, subresultant, determinant, or Fitting elimination can produce a nonzero scalar in the short coefficients. A nonzero output must be coefficient content introduced during clearing.

## 6. Full k=3 calculation

Write

```text
p = p_1,   ell = p_2,   rho = p_3,
P = p ell rho.
```

Define

```text
c_1 = (S_2-S_1)/p^2,
c_2 = (S_3-S_2)/(p ell)^2.
```

The exact triangular lattice is

```text
S_3 = P t,
S_2 = P t - (p ell)^2 c_2,
S_1 = P t - (p ell)^2 c_2 - p^2 c_1.
```

Its Smith form is

```text
diag(p, p^2 ell, (p ell)^2 rho).
```

After removing the long direction and the universal squares, the boundary Smith form is diag(1,1).

For the actual rank-two graph, write

```text
q_1 = 0,
q_2 = p^2 R_1,
q_3 = p^2 R_1 + (p ell)^2 R_2.
```

Then

```text
S_1 = s,
S_2 = s + p^2 W R_1,
S_3 = s + p^2 W R_1 + (p ell)^2 W R_2,

c_1 = W R_1,
c_2 = W R_2.
```

The target quotients satisfy

```text
p t_1       = S_1,
ell t_2     = S_2,
rho t_3     = S_3,

ell t_2-p t_1       = p^2 c_1,
rho t_3-ell t_2     = (p ell)^2 c_2.
```

### Eliminating both long coordinates

The three target rows give the machine-checkable identity

```text
det([
    [1, 0,                         p t_1],
    [1, p^2 R_1,                   ell t_2],
    [1, p^2 R_1+(p ell)^2 R_2,     rho t_3]
]) = 0.
```

Subtracting the first row and using the two difference equations gives

```text
determinant = p^4 ell^2 (R_1 c_2 - R_2 c_1).
```

After all coefficient content and universal node factors are divided, the proposed scalar is

```text
R_1 c_2 - R_2 c_1 = 0.
```

It vanishes identically because c_i=W R_i. Thus three targets eliminate s and W only to a recurrence identity. They do not leave a nonzero primitive integer.

## 8. Primitive carrier-class saturation theorem

Use the multi-target extension of Q5674's carrier class.

Start with:

- the actual prefixes and summands in the cutoff intervals;
- the divided quotient variables t_i and c_i;
- optionally the actual neighboring Apéry state and the proved regularized companion coordinates from Section 37.

Allow:

1. finitely many linear operations over R;
2. determinants and Fitting minors;
3. ordinary resultants and subresultants of the resulting linear equations;
4. gcds only when prime support is certified operandwise;
5. division of all coefficient content and universal squared-node or regular-recurrence factors before calling an output primitive.

### Theorem 8.1

Within this class, every formally target-forced factor has one of three forms.

1. It remains attached to s, W, a full prefix, or b_n, and therefore retains an exponential coordinate.
2. It is target-prime coefficient content inserted during a linear combination or denominator clearing.
3. It is a rank-one identity R_j c_i-R_i c_j, or a consequence of those identities, and becomes zero after primitive saturation.

There is no nonzero primitive scalar of logarithmic height controlled only by the gaps that is formally forced to contain k-2 target primes.

### Proof

- The full integer target lattice is Theorem 3.1.
- Its universal boundary quotient has primitive Smith form diag(1,...,1).
- With quotient variables included, the target presentation has unit Smith form.
- The exact CRT kernel basis shows that the only target-derived index is P_k in the two-long-coordinate lattice.
- The boundary presentation has unit Smith form.
- The elimination ideal in the short coefficients is zero.
- Resultants, subresultants, and Fitting minors lie in this elimination ideal after primitive coefficient saturation.
- A prime is guaranteed in a gcd only if every operand lies in the target ideal, so operandwise gcd certification reduces to the same elimination statement.

This proves the theorem.

### Section 37 does not add a cross equation

Section 37 proves that, in one target characteristic, the divided Apéry and companion columns are multiples of the same scalar

```text
omega_(q,k,j) = b_j/q + k W_j mod q.
```

Thus the proved companion information remains projectively rank one. It gives no equation coupling distinct target characteristics. The stronger congruence (37.7) is explicitly conjectural at commit 11cd0de and cannot be used as input. Even if proved, Section 37 says it propagates one projective direction except on the thinner locus omega=0.

Therefore the proved companion jets do not change any Smith or elimination calculation above.
