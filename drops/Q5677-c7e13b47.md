# Multi-target Racah cutoffs: exact Smith basis and primitive saturation

## Verdict

The correct alternative is **(2)**.

For any number \(k\ge 2\) of top-half target primes, the triangular mixed-characteristic lattice can be solved exactly. Its unreduced Smith factors are nontrivial, but they do **not** produce \(k-2\) new primitive cross-prime factors after the two actual hypergeometric coordinates are eliminated.

There are two complementary exact statements.

1. If one temporarily forgets that all cutoff differences come from one hypergeometric boundary coordinate, the integer prefix lattice has Smith invariants
   
   \[
   oxed{d_i=P_{i-1}^{\,2}p_i\qquad(1\le i\le k),}
   \qquad P_i:=p_1\cdots p_i,\quad P_0=1.
   \]
   
   The factors \(P_i^2\) are the universal squared-node content. After quotienting by the long prefix direction and dividing these universal factors, the boundary lattice is primitive: its Smith form is the identity.

2. Restoring the actual cutoff recurrence makes the saturation stronger. All prefixes have the form
   
   \[
   S_i=s+Wq_i,
   \]
   
   with only two long coordinates \(s\) and \(W\). The target equations are
   
   \[
   s+Wq_i=p_it_i.
   \]
   
   Their exact solution lattice in the \((s,W)\)-plane has Smith form
   
   \[
   oxed{\operatorname{SNF}=\operatorname{diag}(1,P_k).}
   \]
   
   Thus the entire target product \(P_k\) remains attached to the two-dimensional long-coordinate lattice. Eliminating \(s,W\) leaves quotient-variable syzygies, not a scalar. The full target presentation matrix has unit Smith form, and its primitive maximal Fitting ideal is the unit ideal.

For \(k=3\), eliminating \(s,W\) gives a \(3	imes3\) determinant, but after the divided quotients are inserted correctly it reduces to

\[
oxed{R_2c_1-R_1c_2=0,}
\]

an identically vanishing rank-one boundary determinant. It is not a nonzero carrier.

At the genuine triple

\[

\]

the fully divided second boundary quotient satisfies

\[
oxed{rac{S_3-S_2}{(179\cdot193)^2}\equiv4\pmod{211},}

so the third target prime does not divide it. The normalized rank-one determinant vanishes exactly, as predicted, but no primitive \(211\)-factor remains.

This proves a multi-target saturation theorem for the same carrier class as Q5674: finite cutoff-recurrence linear operations, quotient variables, determinants/Fitting minors, ordinary resultants/subresultants, and operandwise-certified gcds, followed by removal of coefficient content and universal node factors. A carrier in this class either retains one of the two exponential coordinates, obtains its prime factor from coefficient content, or becomes zero after primitive saturation.

## 8. Primitive carrier-class saturation theorem

Use the multi-target extension of Q5674's carrier class.

Start with:

- the actual prefixes \(S_{M_1},\ldots,S_{M_k}\);
- all summands in the intervening cutoff intervals;
- the divided quotient variables \(t_i,c_i\);
- optionally the actual neighboring Apéry state and the proved regularized companion coordinates from Section 37.

Allow:

1. finitely many linear operations over \(\mathscr R\);
2. determinants and Fitting minors;
3. ordinary resultants and subresultants of the resulting linear recurrence equations;
4. gcds only when prime support is certified operandwise;
5. division of all coefficient content and every universal squared-node or regular recurrence factor before calling an output primitive.

### Theorem 8.1 — multi-target saturation

Within this class, every formally target-forced factor has one of the following forms.

1. It remains attached to \(s\), \(W\), a full prefix, or \(b_n\); hence it retains an exponential coordinate.
2. It is target-prime coefficient content inserted during a linear combination or denominator clearing.
3. It is one of the rank-one identities (5.4), or a consequence thereof, and becomes zero after primitive saturation.

There is no nonzero primitive scalar of logarithmic height controlled only by the gaps that is formally forced to contain \(k-2\) target primes.

#### Proof

- The full integer target lattice is Theorem 3.1.
- The universal boundary quotient has primitive Smith form (3.10).
- With quotient variables included, the target presentation has unit Smith form by Proposition 4.1.
- The exact kernel basis (4.8) shows that the only target-derived index is \(P_k\) in the two-long-coordinate lattice.
- The boundary presentation has unit Smith form (5.3).
- The elimination ideal in the short coefficients is zero by (5.5).
- Resultants, subresultants, and Fitting minors lie in this elimination ideal after primitive coefficient saturation.
- A prime is guaranteed in a gcd only if every operand lies in the corresponding target ideal, so operandwise gcd certification reduces to the same elimination statement.

This proves the theorem. ∎

### 8.1 Why Section 37 does not alter the result

Section 37 proves that at one target characteristic the first divided Apéry and companion columns are both multiples of the same scalar

\[
\omega_{q,k,j}=b_j/q+kW_j\pmod q.
\]

Thus the proved companion information remains projectively rank one in each characteristic. It supplies no second equation coupling two different target characteristics. The stronger congruence (37.7) is explicitly conjectural at commit `11cd0de` and cannot be used as input. Even if it were proved, Section 37 itself shows that it propagates one projective direction except on the thinner locus \(\omega_{q,k,j}=0\).

Hence adjoining the proved companion jets adds no row that changes (4.3), (4.10), or the elimination identity (5.5).

## 9. Dependency-free exact reproducer

The following script uses only exact Python integers. It verifies the triple, the complete universal divisibilities, the residues above, and the normalized determinant identity.

from math import comb

    a %= p
    assert a
    return pow(a, p - 2, p)

M1, M2, M3 = (p1 - 1) // 2, (p2 - 1) // 2, (p3 - 1) // 2
assert (M1, M2, M3) == (89, 96, 105)


def A(m):
    return comb(n, m) * comb(n + m, m)


def u(m):
    z = A(m)
    return z * z


S1 = sum(u(m) for m in range(M1 + 1))
S2 = sum(u(m) for m in range(M2 + 1))
S3 = sum(u(m) for m in range(M3 + 1))

assert S1 % p1 == 0
assert S2 % p2 == 0
assert S3 % p3 == 0

D1 = S2 - S1
D2 = S3 - S2
P1 = p1
P2 = p1 * p2
P3 = p1 * p2 * p3

assert D1 % (P1 * P1) == 0
assert D2 % (P2 * P2) == 0
assert S2 % P2 == 0
assert S3 % P3 == 0

c1 = D1 // (P1 * P1)
c2 = D2 // (P2 * P2)
W = u(M1 + 1) // (p1 * p1)
assert c1 % W == 0
assert c2 % W == 0
R1, R2 = c1 // W, c2 // W
assert R2 * c1 - R1 * c2 == 0

mod = p3

assert D2 % mod == 125
assert c1 % mod == 107
assert c2 % mod == 4

# The 3x3 determinant after target quotient substitution.

q1 = 0
q2 = p1 * p1 * R1

det = (
    q2 * (p3 * t3 - p1 * t1)
    - q3 * (p2 * t2 - p1 * t1)

assert det == 0
assert det == p1**4 * p2**2 * (R1 * c2 - R2 * c1)

print("triple audit passed")

## Final answer

The \(k\)-target triangular congruences do have a clean exact Smith theory, but they do not escape Q5674.

- The full prefix lattice has invariant factors \(P_{i-1}^2p_i\).
