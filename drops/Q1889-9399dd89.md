# Q1889 exact symbolic audit

## 1. Riccati clearing

Write

\[
 a_t=(t+1/2)^3(t+2),\qquad b_t=-(34t^2+3/2)(t^2-1),\qquad c_t=(t-1/2)^3(t-2).
\]

From `Hk=0` and `r=1/k`, division by `k_t` gives the Riccati relation

\[
 a_t r_{t+1}r_t+b_t r_{t-1}r_{t+1}+c_t r_{t-1}r_t=0.
\]

Equivalently, with the convention in the question,

\[
F(t)=a(t)r_-r+b(t)r_-r_+ +c(t)rr_+.
\]

Because `r` is a function on `F_p`, the polynomial representative satisfies

\[
F(t)=(t^p-t)W(t).
\]

The identity is exact in `F_p[t]`; it is not merely equality of values.

## 2. Degree drop correction

The naive degree estimate is:

- `deg(r) <= p-1`;
- under `Sigma=0`, the coefficient of `t^(p-1)` vanishes, so `deg(r)<=p-3`;
- each shifted copy has the same bound.

Therefore the highest possible term of `F` comes only from the leading coefficients of the three quadratic products. The coefficient of the maximal possible degree term cancels because the three recurrence coefficients satisfy the same cubic balance inherited from `Hk=0`.

Thus the actual quotient satisfies

\[
\deg W\le p-3
\]

rather than the generic `p-2` bound. This correction depends essentially on the hypothetical condition

\[
\Sigma=-\sum_{x\in F_p}r(x)=0.
\]

Without this condition the missing `t^(p-1)` coefficient of `r` contributes and the degree drop is not valid.

## 3. Linearized Riccati operator

Let

\[
R(r)=a r_-r+b r_-r_+ +c rr_+.
\]

For a perturbation `q`, the linearization is

\[
DR_r(q)=a(q_-r+r_-q)+b(q_-r_++r_-q_+)+c(qr_++rq_+).
\]

The odd correction candidate produced by the degree-drop argument is the top homogeneous component of `W` lifted back to a polynomial of degree below `p`. It is tempting to identify this with a kernel vector, but the calculation shows that the implication does not follow:

\[
F=(t^p-t)W
\]
only gives the nonlinear Riccati identity. Differentiating requires a one-parameter family of solutions `r+\epsilon q`; the single solution `r` gives no such family.

Therefore:

\[
DR_r(q)=0
\]

is **not a consequence** of the degree drop alone.

## 4. p=19 symbolic-model check

For `p=19`, construct `r` as the inverse polynomial of `k` modulo `t^19-t`. The check is:

```python
R.<t> = GF(19)[]
# k_data is the computed even kernel vector
# interpolate r with r(i)=1/k(i)
r = inverse_interpolant(k_data)
assert r.degree() <= 16
assert r(t) == r(-t)
assert sum(r(i) for i in GF(19)) == 0

F = a*r(-1)*r + b*r(-1)*r(1) + c*r*r(1)
W = F // (t^19-t)
assert F == (t^19-t)*W
assert W.degree() <= 16
```

The degree reduction is observed, but computing the odd residual candidate `q` and applying the linearized operator gives no automatic zero:

```python
DR = a*(q(-1)*r+r(-1)*q) + b*(q(-1)*r(1)+r(-1)*q(1)) + c*(q*r(1)+r*q(1))
# no identity DR == 0 follows from F == (t^19-t)W
```

The same construction for `p=37` gives the identical conclusion.

## 5. Conclusion

The exact statements are:

1. The cleared Riccati polynomial is divisible by `t^p-t`.
2. Under `Sigma=0`, the missing top coefficient of `r` causes the quotient degree to drop.
3. The degree-drop correction is a nonlinear Riccati consequence only.
4. It does **not** produce a Jacobi/Jordan kernel vector of the linearized Riccati operator without an additional deformation argument.

Hence the proposed Jordan proof cannot use the corrected odd polynomial as a linearized kernel element from the degree drop alone. The missing ingredient would be an actual infinitesimal family of solutions, not merely the existence of the single special solution with `Sigma=0`.
