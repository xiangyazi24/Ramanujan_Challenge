# Q756 audit: weak target `log rad_(n/2,n](b_n)=o(n)`

## Scope

The target is only the proportional large-prime radical slice:

\[
\log \operatorname{rad}_{(n/2,n]}(b_n)=o(n).
\]

Several older arguments were aimed at stronger statements (bounded number of prime factors, squarefree kernel bounds, or estimates uniform over all primes), and their no-go conclusions do not automatically apply to this weaker target.

## Recovered exact ingredients

### Q448/Q451/Q452 family

Core idea: convert a prime divisor p of an Apéry number into information on the index modulo p.

For p in (n/2,n], write
\[
r=n-p.
\]
Then
\[
p\mid b_n \Longleftrightarrow p\mid b_r
\]
using the Apéry congruence mechanism modulo p.

This identity is exact only after checking the hypotheses of the Lucas-type congruence. It is a conditional reduction, not a complete bound.

### Q475/Q487/Q489/Q491

These explored factorial/binomial carriers. The important correction is that the previously claimed universal carrier
\[
p\mid {n\choose \lfloor n/2\rfloor}
\]
for all p in (n/2,n] is false.

Counterexample:
\[
n=9,\quad p=5,
\]
with
\[
{9\choose4}=126\not\equiv0\pmod5.
\]

Therefore any argument depending on that carrier is discarded.

The valid q=1 carrier is instead the boundary object
\[
J=\lfloor (n-1)/3\rfloor,
\]
\[
B_{1,n}={n\choose J+1}{n+J+1\choose J+1}.
\]
Candidates with p|b_{n-p} divide this carrier.

### Q501/Q515/Q521/Q533/Q539

These contain conditional chains:

- large-prime divisors correspond to small residues r;
- factorial carriers can bound the number of possible primes if their radical contribution is controlled;
- recurrence alone does not give enough independent arithmetic information.

The valid conclusion is a reduction, not a proof of the radical bound.

### Q545/Q588/Q589/Q599/Q605/Q617/Q619/Q632/Q634

These investigated sheaf, Mellin, Fourier, and distribution routes. Their no-go statements mainly concern stronger goals such as:

- uniform cancellation of zero indicators;
- bounded average number of zeros;
- pair-zero decorrelation;
- exponential gcd estimates via stronger hypotheses.

They do not directly rule out proving the weak proportional slice bound.

### Q645/Q664/Q671/Q672/Q684/Q692/Q700/Q701/Q709/Q715/Q716/Q729/Q733/Q734/Q747/Q748

Main surviving information:

1. P-recursive/G-function structure gives algebraic control but not automatically prime-factor sparsity.
2. Same-characteristic recurrence arguments do not transfer to neighboring characteristics.
3. Dense prime divisibility hypotheses can be reduced to residue statistics.
4. The factorial boundary carrier must replace the false central-binomial carrier.

## Three shortest candidate chains

## Chain A: q=1 factorial carrier + radical estimate

Formula:
\[
p\in(n/2,n],\quad p\mid b_n
\]
induces
\[
p\mid B_{1,n}.
\]

Goal:
\[
\log\operatorname{rad}(B_{1,n})=o(n).
\]

Status: conditional only. Need a sharper estimate than generic binomial radical bounds.

## Chain B: residue counting

Use
\[
p\mid b_n\Rightarrow p\mid b_{n-p}.
\]
For q=1:
\[
r=n-p<n/2.
\]
Need show
\[
\#\{r: n-r\text{ prime},\ n-r\mid b_r\}=o(n/\log n).
\]
Status: equivalent reduction. Missing ingredient is anti-concentration of Apéry zeros across varying characteristics.

## Chain C: corrected proportional slices

For fixed q:
\[
p\in(n/(q+1),n/q],
\]
and
\[
\lfloor n/p\rfloor=q.
\]
The fixed-quotient theorem reduces the gcd target to
\[
\log R_q(n)=o_q(n).
\]
For q=1 this becomes the previous residue problem.

Status: logically clean, but still requires a new arithmetic estimate.

## Q-number collision flags

- The old Q475/Q487/Q489/Q491 carrier discussion contains the false universal central-binomial divisibility claim; it must not be reused.
- Several Q6xx answers discuss stronger AFP/zero-correlation targets. Those conclusions should not be interpreted as impossibility of the weaker radical slice.
- Q747/Q748 should be read with the Q754 correction: the q=1 boundary carrier is B_{1,n}, not the central binomial coefficient.

## Final audit verdict

The weak target survives all corrections.

Proved reductions:

- large primes reduce to residue divisibility;
- q-slices isolate proportional prime ranges;
- q=1 has a valid factorial carrier.

Not proved:

\[
\log \operatorname{rad}_{(n/2,n]}(b_n)=o(n).
\]

The remaining bottleneck is a genuine arithmetic sparsity statement for large prime divisors of Apéry numbers, not a recurrence-formalism issue.
