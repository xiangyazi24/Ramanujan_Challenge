## 1. Prime-local form of the problem

Fix a prime \(p\), and write

\[
V(m):=v_p(B_m),\qquad
W_i:=v_p\!\left(w_i(n,K)\right),
\]

and

\[
E=E_p(n,K):=\min_{0\le i\le K}\bigl(V(i)+W_i\bigr).
\]

The desired divisibility

\[
\gcd_{0\le i\le K}(B_iw_i)\mid B_n
\]

is equivalent to proving

\[
V(n)\ge E
\]

for every prime \(p\).

### 1.1 Exact weight factorization

Direct factorial cancellation gives

\[
\boxed{
 w_i(n,K)
 =\binom ni\binom{n-i-1}{K-i}
 =\frac{n}{n-i}\binom{n-1}{K}\binom Ki.}
\]

Set

\[
h:=v_p\binom{n-1}{K},\qquad d:=v_p(n),
\qquad c_i:=v_p\binom Ki,\qquad a_i:=v_p(n-i).
\]

Then

\[
\boxed{W_i=h+d+c_i-a_i.}\tag{1.1}
\]

In particular, the \(i=0\) term has \(V(0)=0\) and \(W_0=h\), so

\[
\boxed{E\le h.}\tag{1.2}
\]

### 1.2 The bare weights are primitive

Put

\[
\lambda_i:=(-1)^{K-i}w_i.
\]

Using coefficient extraction,

\[
\begin{aligned}
\sum_{i=0}^K\lambda_i
&=[x^K]\sum_{i=0}^K\binom ni x^i(1-x)^{n-i-1}\\
&=[x^K](1-x)^{-1}
\sum_{i=0}^{n}\binom ni x^i(1-x)^{n-i}\\
&=[x^K](1-x)^{-1}=1.
\end{aligned}
\]

Thus

\[
\boxed{\sum_{i=0}^K(-1)^{K-i}w_i=1,}\tag{1.3}
\]

and consequently \(\gcd_i w_i=1\). Any nontrivial content comes from an interaction between the Apéry valuations and the carry strata of the Lagrange weights, not from universal weight content.

## 2. The exact Dwork congruence available for these Apéry numbers

The \(\zeta(3)\) Apéry numbers are constant terms of the integral Laurent polynomial

\[
\Lambda(x,y,z)=
\frac{(1+x)(1+y)(1+z)\bigl((1+y)(1+z)+xyz\bigr)}{xyz}.
\]

Indeed, expanding the last factor and reindexing gives

\[
\begin{aligned}
[\Lambda^m]_0
&=\sum_{k=0}^m
 \binom mk^2\binom{2m-k}{m-k}^2\\
&=\sum_{j=0}^m
 \binom mj^2\binom{m+j}{j}^2
=B_m.
\end{aligned}
\]

The Newton polytope is the polytope used by the repository audit,

\[
-1\le x,y,z\le1,\qquad x-y\le1,\qquad x-z\le1,
\]

and the origin is its only interior lattice point. Hence the Samol--van Straten/Mellit--Vlasenko projective cross-congruence applies for every prime \(p\): for all \(u,m\ge0\) and \(s\ge1\),

\[
\boxed{
B_{u+mp^s}B_{\lfloor u/p\rfloor}
\equiv
B_uB_{\lfloor u/p\rfloor+mp^{s-1}}
\pmod{p^s}.}\tag{2.1}
\]

Primary source: Anton Mellit and Masha Vlasenko, [“Dwork's congruences for the constant terms of powers of a Laurent polynomial,” arXiv:1306.5811](https://arxiv.org/abs/1306.5811), equation (3), recording the Samol--van Straten congruence and deriving it from the same ghost-term machinery.

For an index \(i<n\), let

\[
I_i:=\left\lfloor\frac{i}{p}\right\rfloor,\qquad
N:=\left\lfloor\frac{n}{p}\right\rfloor.
\]

If \(a_i=v_p(n-i)\ge1\), write \(n=i+mp^{a_i}\). Then (2.1) becomes

\[
\boxed{
B_nB_{I_i}\equiv B_iB_N\pmod{p^{a_i}}.}\tag{2.2}
\]

This is the safe form. It is a projective determinant congruence and does **not** divide by \(B_{I_i}\).

## 3. An exact all-strata projective ladder

The following identity packages all carry strata at once and explains where a full induction would have to act.

For \(j\ge0\), define

\[
N_j:=\left\lfloor\frac{n}{p^j}\right\rfloor,\qquad
S_j:=\sum_{i=0}^K\lambda_i
 B_{\lfloor i/p^j\rfloor}.
\]

By the definition of \(E\), every term \(\lambda_iB_i\) is divisible by \(p^E\), so

\[
S_0\equiv0\pmod{p^E}.\tag{3.1}
\]

For \(0\le j<E\), apply (2.2) to the pair

\[
N_j,\qquad \left\lfloor i/p^j\right\rfloor.
\]

If the quotient difference has no factor \(p\), then (1.1) already gives enough valuation in \(\lambda_i\). If it has a factor \(p\), use the corresponding depth in (2.2). Since

\[
v_p\!\left(N_j-\left\lfloor i/p^j\right\rfloor\right)
\ge \max(a_i-j,0)
\]

whenever the two quotients differ, and

\[
W_i+a_i=h+d+c_i\ge h\ge E,
\]

every weighted error has valuation at least \(E-j\). Summing over \(i\) gives the exact ladder

\[
\boxed{
B_{N_j}S_{j+1}\equiv B_{N_{j+1}}S_j
\pmod{p^{E-j}}\qquad(0\le j<E).}\tag{3.2}
\]

At \(j=0\), (3.1) and (3.2) give

\[
\boxed{B_nS_1\equiv0\pmod{p^E}.}\tag{3.3}
\]

Thus the original theorem is immediate whenever \(S_1\) is a unit. When \(S_1\) is not a unit, the valuation can move into the quotient coordinate; (3.2) records that movement without an illegal division. This projective ladder is the aggregate form of the carry-state obstruction.

## 4. The one-step Dwork quotient-state theorem

The aggregate ladder can be converted into an explicit lower bound using individual indices.

Define

\[
R_i:=(E-W_i)_+=\max(0,E-W_i),
\]

and, when \(a_i\ge1\),

\[
L_i:=\min\bigl(a_i,\,V(N)+R_i\bigr).
\]

Put \(L_i=0\) when \(a_i=0\), and define

\[
\boxed{
\Phi_p(n,K;E):=
\max_{0\le i\le K}
\bigl(L_i-V(I_i)\bigr)_+.}\tag{4.1}
\]

### Theorem 4.1 — Dwork quotient-state lower bound

For every prime \(p\) and every \(0\le K<n\),

\[
\boxed{V(n)\ge\Phi_p(n,K;E).}\tag{4.2}
\]

### Proof

The definition of \(E\) gives

\[
V(i)+W_i\ge E,
\]

hence

\[
V(i)\ge R_i.
\]

Therefore

\[
v_p(B_iB_N)\ge R_i+V(N).
\]

The projective congruence (2.2) shows that both terms on the right-hand representation of \(B_nB_{I_i}\) are divisible by

\[
p^{L_i},\qquad
L_i=\min(a_i,V(N)+R_i).
\]

Consequently

\[
V(n)+V(I_i)\ge L_i,
\]

or

\[
V(n)\ge\bigl(L_i-V(I_i)\bigr)_+.
\]

Taking the maximum over \(i\) proves (4.2). \(\square\)

### Corollary 4.2 — named residual condition

The original local divisibility follows if

\[
\boxed{
\mathrm{DQSC}_p(n,K):\quad
\Phi_p(n,K;E)\ge E.}\tag{4.3}
\]

Equivalently, it is enough to find one \(i\le K\) satisfying

\[
a_i\ge E+V(I_i)
\]

and

\[
V(N)+(E-W_i)_+\ge E+V(I_i).
\tag{4.4}
\]

All Apéry valuations in (4.1)--(4.4), except the target \(V(n)\), occur at strictly smaller indices:

\[
N<n,\qquad I_i\le K/p<n.
\]

Thus this is a genuine quotient-state reduction rather than a restatement of the desired inequality.

Every counterexample must satisfy

\[
\boxed{
\delta_p(n,K):=E-\Phi_p(n,K;E)>0.}\tag{4.5}
\]

I call (4.5) the **positive Dwork-state defect**.

## 5. Compression to the last \(E\) borrow prefixes

The maximum in (4.1) can be reduced to an \(O(E)\) canonical family.

By Kummer's theorem,

\[
h=v_p\binom{n-1}{K}
\]

is the number of borrow boundaries in the base-\(p\) subtraction of \(K\) from \(n-1\). Define

\[
\mathcal J=
\left\{j\ge1:
K\bmod p^j>(n-1)\bmod p^j
\right\},
\]

and list it as

\[
j_1<j_2<\cdots<j_h.
\]

For each boundary put

\[
r_t:=n\bmod p^{j_t}.
\]

Then:

1. \(1\le r_t\le K\);
2. \(v_p(n-r_t)\ge j_t\);
3. \(\binom n{r_t}\) is a \(p\)-adic unit;
4. the borrows in \(\binom{n-r_t-1}{K-r_t}\) are exactly the original borrow boundaries above \(j_t\).

Hence

\[
\boxed{W_{r_t}=h-t.}\tag{5.1}
\]

The fourth point follows because the low \(j_t\) digits of \(n-r_t-1\) are all \(p-1\), and for every higher boundary the inequality after subtracting \(r_t\) is the same as the original inequality for \(K\) versus \(n-1\).

Since \(E\le h\), only the last \(E\) prefixes can have \(W_{r_t}<E\). For

\[
t=h-E+1,\ldots,h,
\]

set

\[
q_t:=E-h+t,\qquad
J_t:=\left\lfloor\frac{r_t}{p}\right\rfloor.
\]

Then \(q_t=E-W_{r_t}\), and Theorem 4.1 yields the compressed bound

\[
\boxed{
V(n)\ge \Phi_p^{\mathrm{bor}}(n,K;E),}\tag{5.2}
\]

where

\[
\boxed{
\Phi_p^{\mathrm{bor}}(n,K;E)=
\max_{h-E+1\le t\le h}
\left(
\min\bigl(j_t,V(N)+q_t\bigr)-V(J_t)
\right)_+.}\tag{5.3}
\]

This is weaker than or equal to \(\Phi_p\), because the actual depth \(v_p(n-r_t)\) can exceed \(j_t\), but it requires only the last \(E\) borrow states and quotient-prefix valuations

\[
J_t=N\bmod p^{j_t-1}.
\]

Thus a counterexample must already survive an explicit chain of at most \(E\le h\) lower-dimensional states.

## 6. Uniform cases that are completely closed

### 6.1 Exponent \(E=0\)

Trivial.

### 6.2 Exponent \(E=1\)

Assume \(E=1\). Let \(r_h=n\bmod p^{j_h}\) be the deepest borrow prefix. By (5.1),

\[
W_{r_h}=0,
\]

so the content hypothesis forces

\[
p\mid B_{r_h}.
\]

The ordinary Apéry Lucas congruence, which is the \(s=1\) case of the Dwork theorem, says that \(B_m\bmod p\) is the product of the digit values \(B_d\bmod p\). The base-\(p\) digits of \(r_h\) are an initial block of the digits of \(n\). Therefore a zero digit factor occurring in \(B_{r_h}\bmod p\) also occurs in \(B_n\bmod p\). Hence

\[
p\mid B_n.
\]

So the valuation theorem is unconditional for every local exponent \(E\le1\).

### 6.3 Arbitrary exponent with a unit canonical quotient

Again let \(r_h=n\bmod p^{j_h}\). Then

\[
W_{r_h}=0,\qquad V(r_h)\ge E,\qquad
v_p(n-r_h)\ge j_h\ge h\ge E.
\]

Put

\[
J_h=\left\lfloor\frac{r_h}{p}\right\rfloor.
\]

If

\[
p\nmid B_{J_h},
\]

then (2.2) at \(i=r_h\), to depth at least \(E\), gives

\[
B_nB_{J_h}\equiv B_{r_h}B_N\equiv0\pmod{p^E}.
\]

Since \(B_{J_h}\) is a unit,

\[
p^E\mid B_n.
\]

This proves every state whose deepest borrow-prefix quotient is a unit. The unresolved states are exactly those in which quotient zeros absorb projective valuation; DQSC records whether the other carry strata compensate.

Using ordinary Lucas,

## 8. Why the known relative-Lucas failure is harmless here

The proof does not use a lifted product assertion of the form

\[
B_{pm+r}\stackrel{?}{\equiv}B_mB_r
\pmod{p^{1+v_p(B_m)}}.
\]

The task records \(p=19,m=827\) as a depth-three counterexample to that kind of assertion. Nothing above requires it.

The only higher-power input is the determinant congruence

\[
B_nB_{I_i}-B_iB_N\equiv0\pmod{p^{a_i}},
\]

with its quotient multiplier retained. If \(B_{I_i}\) is not a unit, Theorem 4.1 subtracts its exact valuation and records a Dwork-state defect; it never divides an unverified congruence by that coordinate. This distinction is also consistent with the repository's \(p=17\) Cartier warning, where a depth-one extension loses one of two factors visible at the prefix.

## 9. Standalone exact verifier for the \(p=19\) state

This verifier uses only the exact Apéry recurrence

\[
(m+1)^3B_{m+1}
=(34m^3+51m^2+27m+5)B_m-m^3B_{m-1}.
\]

It recomputes the entire minimum over \(0\le i\le5351\), the three strata, the quotient residues, the three projective congruences, and the target divisibility. It is intentionally independent of the unavailable `.root/direct` probe.

```python
#!/usr/bin/env python3


def vp(x: int, p: int) -> int:
    if x == 0:
        return 10**18
    e = 0
    while x % p == 0:
        e += 1
        x //= p
    return e


def vp_fact(n: int, p: int) -> int:
    out = 0
    while n:
        n //= p
        out += n
    return out


def vp_binom(n: int, k: int, p: int) -> int:
    assert 0 <= k <= n
    return vp_fact(n, p) - vp_fact(k, p) - vp_fact(n - k, p)


def apery_stream(limit: int):
    yield 0, 1
    if limit == 0:
        return
    previous, current = 1, 5
    yield 1, current
    for m in range(1, limit):
        numerator = (
            (34 * m**3 + 51 * m**2 + 27 * m + 5) * current
            - m**3 * previous
        )
        denominator = (m + 1) ** 3
        following, remainder = divmod(numerator, denominator)
        assert remainder == 0
        yield m + 1, following
        previous, current = current, following


p, n, K = 19, 21404, 5351
wanted = {0, 2, 3, 5, 10, 43, 105, 827, 1126, 21404}
B = {}
E = 10**18

for m, value in apery_stream(n):
    if m in wanted:
        B[m] = value
    if m <= K:
        W = (
            vp_binom(n, m, p)
            + vp_binom(n - m - 1, K - m, p)
        )
        E = min(E, vp(value, p) + W)

assert E == 3

strata = [
    (
        i,
        vp(n - i, p),
        vp_binom(n, i, p) + vp_binom(n - i - 1, K - i, p),
        vp(B[i], p),
    )
    for i in (10, 105, 827)
]
assert strata == [
    (10, 1, 2, 1),
    (105, 2, 1, 2),
    (827, 3, 0, 3),
]

assert [B[j] % p for j in (2, 3, 5, 43, 1126)] == [16, 1, 10, 8, 8]

N = n // p
for i, depth in ((10, 1), (105, 2), (827, 3)):
    I = i // p
    assert (B[n] * B[I] - B[i] * B[N]) % (p**depth) == 0

assert vp(B[n], p) >= E
print("PASS", "E=", E, "v19(B_n)=", vp(B[n], p))
```

## 10. Scientific terminal condition

**Status:** partial strict reduction, not a complete proof and not a falsification.

**Established claim:**

\[
v_p(B_n)\ge\Phi_p(n,K;E),
\]

with the borrow-prefix compression (5.3), uniform closure at \(E\le1\), arbitrary-exponent closure under the canonical unit-quotient condition, and exact closure of the specified depth-three state.

**Named blocker / crux:**

```text
POSITIVE_DWORK_STATE_DEFECT
```

The remaining exact problem is:

> Prove that \(\delta_p(n,K)=E-\Phi_p(n,K;E)\le0\) for every prime-local state, possibly by iterating the projective ladder (3.2) through nonunit quotient coordinates; or locate the smallest state with \(\delta_p(n,K)>0\) and then check whether \(v_p(B_n)<E\).
