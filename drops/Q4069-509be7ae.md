Use \(\rho\) row labels. In each row place all \(P_0\) lower-prime labels and all \(P_0\) upper-prime labels. Partition each side into blocks of size \(m\) and put a complete bipartite graph \(K_{m,m}\) between corresponding blocks.

Every used lower or upper vertex has degree \(m\). The row divisor capacity is respected because the row uses only \(2P_0=O(T/L)\) distinct prime labels. Give every upper-prime label one selected zero in each row, so the upper first/second moments have the same admissible \((P_0,\rho)\) profile and each fixed selected state has occupancy

\[
m\le X/L.
\tag{7.8}
\]

For each edge impose the plus affine labels

\[
n=7p-1-x=6q+u,
\qquad
M=n+6q=14p-1-x-h.
\tag{7.9}
\]

Equivalently, \(h=7p-6q\) and \(u=h-x-1\). The abstract compatibility graph contains only edges whose formal labels satisfy these equations and the height interval. This is the precise feature not controlled by the marginal inputs.

## 7.4 Common-coefficient support and height

For each row coefficient \(B_n^*\), include every lower and upper prime label present in that row. Hence

\[
\log B_n^*\le 2P_0L=O(T).
\tag{7.10}
\]

For the second coefficient \(B_M^*\) attached to one selected upper state, include its upper label \(q\) and all \(m\) lower neighbors. Thus

\[
\log B_M^*\le(m+1)L
\le X+L
=O(T).
\tag{7.11}
\]

If several states have the same formal coefficient index, reuse the fixed global prime pools; every coefficient support remains a subset of at most \(2P_0\) labels and still has logarithmic height \(O(T)\).

Consequently every edge satisfies

\[
pq\mid\gcd(B_n^*,B_M^*),
\tag{7.12}
\]

and the lower support equality

\[
p\mid\Gamma_h^*(x)
\iff
p\mid\gcd(B_n^*,B_M^*)
\tag{7.13}
\]

on the prescribed edge set. Thus both the Gamma constraint and the two common coefficients are built into the saturation model.

# 8. Smallest additional theorem

## 8.1 Balanced plus moving-characteristic theorem

Define the geometry-only plus incidence set

\[
\mathscr W_X^+(T)
:=
\left\{(p,x,h):
\begin{array}{l}
p\in\mathcal P^{\rm low}_{J,T},\\
0\le x<x+h<p,\\
X\le h<2X,\\
7p-h\equiv0\pmod6,\\
q=(7p-h)/6\text{ lies in the upper shell}
\end{array}
\right\}.
\tag{8.1}
\]

For such a tuple put

\[
u=h-x-1,
\qquad
n=7p-1-x=6q+u,
\qquad
M=n+6q=12q+u.
\tag{8.2}
\]

The first genuinely new estimate is:

> **Gamma/common-coefficient selected dispersion** `GCC-SEL_epsilon`.  For fixed \(J\), there exist \(\varepsilon>0\) and \(C_J\) such that, for all sufficiently large \(T\) and every dyadic \(X\) in the current hard balanced range,
> \[
> \boxed{
> \begin{aligned}
> &\sum_{(p,x,h)\in\mathscr W_X^+(T)}
> \mathbf 1_{p\mid\Gamma_h(x)}
> \mathbf 1_{q\ \mathrm{prime}}
> \mathbf 1_{q\mid\gcd(b_n,b_M)}\\
> &\hspace{28mm}
> \le C_J B_1(T)X^{2/3-\varepsilon}.
> \end{aligned}
> }
> \tag{GCC-SEL_\varepsilon}
> \]

By `(1.6+)`, the final indicator is exactly \(q\mid b_u\). The left side drops assignment, terminal, high-row, balance-partner, and every later FURC filter, so every retained \(K_X\) occurrence injects into it. Therefore

\[
K_X\ll_JB_1(T)X^{2/3-\varepsilon}.
\]

An equivalent relative-density form is

\[
\sum_{\mathscr W_X^+}
\mathbf 1_{p\mid\Gamma_h(x)}
\mathbf 1_{q\ \mathrm{prime},\ q\mid b_u}
\ll_J
X^{-\varepsilon}
\sum_{\mathscr W_X^+}
\mathbf 1_{p\mid\Gamma_h(x)}.
\tag{8.3}
\]

This is the first missing **cross-characteristic** inequality: the right side is controlled by the lower local-capacity theorem, while the saving asserts anti-alignment with the affine selected upper zero.

A stronger, sometimes cleaner, common-coefficient-only version is

\[
\sum_{\substack{q\ \mathrm{upper\ prime}\\0\le u<q,\ q\mid b_u}}
\omega_{I_{q,u}^+(X)}
\operatorname{rad}
\gcd\left(
\frac{b_{6q+u}}{q^{v_q(b_{6q+u})}},
\frac{b_{12q+u}}{q^{v_q(b_{12q+u})}}
\right)
\ll_JB_1(T)X^{2/3-\varepsilon},
\tag{8.4}
\]

where \(I_{q,u}^+(X)\) is the exact legal lower-prime interval giving height in \([X,2X)\). This counts spurious common-gcd primes as well, so it is stronger than `GCC-SEL_epsilon`.

## 8.2 Global pair correlation theorem

For \(\mathrm{PC}_T\), `(2.3)` is already an exact equivalence. The minimal little-\(o\) theorem is

\[
\boxed{
\sum_{h\ge1}\sum_{x\ge0}
\log\mathcal R_T(x,h)
=o_J(T^2/\log T).
}
\tag{WRPC}
\]

A fixed-power strengthening is

\[
\sum_{h,x}\log\mathcal R_T(x,h)
\ll_J\frac{T^{2-\delta}}{\log T}
\qquad(\delta>0).
\tag{WRPC_\delta}
\]

The signed common coefficients do not reduce the quantifiers in `WRPC`: on their domain they have the same lower support, and outside their domain they supply no selected upper divisor. Thus the new theorem for \(\mathrm{PC}_T\) must genuinely control the window-radical family itself.
