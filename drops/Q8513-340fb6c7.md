# 2. Exact ordered normalization

Let

\[
\mathcal P_X=\{p\text{ prime}:X<p\le2X\},
\qquad M=X^2,
\]

\[
\Omega_p=\{0\le m<M:b_{m\bmod p}\equiv0\pmod p\},
\qquad f_p(m)=\mathbf1_{\Omega_p}(m),
\]

and

\[
K(m)=\sum_{p\in\mathcal P_X}f_p(m).
\]

For ordered \(p\ne q\), put

\[
J_{p,q}=|\Omega_p\cap\Omega_q|,
\]

\[
T_{p,q}
 =\sum_{m\in\Omega_p\cap\Omega_q}
    \sum_{\ell\in\mathcal P_X\setminus\{p,q\}}f_\ell(m).
\]

Let

\[
A_p=|\Omega_p|,
\qquad \rho_p=\frac{A_p}{M},
\qquad
\mu_{p,q}=\sum_{\ell\notin\{p,q\}}\rho_\ell,
\]

and

\[
\lambda=\lambda_X=\sum_{p\in\mathcal P_X}\frac{Z(p)}p.
\]

The ordered second and third factorial identities are

\[
F_2(X):=\sum_{p\ne q}J_{p,q}
       =\sum_{m<M}(K(m))_2,
\]

\[
\sum_{p\ne q}T_{p,q}
 =\sum_{m<M}(K(m))_3.
\]

There is no factor \(2\), \(3\), or \(3!\) missing. At a row of load \(k\), there are \((k)_2\) ordered anchors and \(k-2\) third labels, so the contribution is

\[
(k)_2(k-2)=(k)_3.
\]

If \(J_{p,q}=0\), then the defining sum for \(T_{p,q}\) is empty, so \(T_{p,q}=0\). Define

\[
\delta_{p,q}=
\begin{cases}
\displaystyle
\left(\frac{T_{p,q}}{J_{p,q}}-\mu_{p,q}\right)_+,
 &J_{p,q}>0,\\[2mm]
0,&J_{p,q}=0.
\end{cases}
\]

Then the positive part is retained **exactly**:

\[
\boxed{
\bigl(T_{p,q}-J_{p,q}\mu_{p,q}\bigr)_+
 =J_{p,q}\delta_{p,q}.}
\]

Therefore

\[
\boxed{
P^{\mathrm{fin}}_3(X)
 =\sum_{p\ne q}J_{p,q}\delta_{p,q}.}
\tag{2.1}
\]

For distinct window primes, \(pq>X^2=M\). A prescribed pair of zero residues therefore has at most one representative below \(M\), and

\[
J_{p,q}\le Z(p)Z(q).
\]

Summing over ordered pairs gives the deterministic bound

\[
\boxed{F_2(X)\le4M\lambda_X^2.}
\tag{2.2}
\]

Finally, each residue class has either \(\lfloor M/p\rfloor\) or \(\lceil M/p\rceil\) representatives below \(M\). Hence

\[
\left|A_p-\frac{MZ(p)}p\right|\le Z(p)
\]

and

\[
\sum_p\rho_p
 \le\lambda_X+\frac1M\sum_pZ(p).
\tag{2.3}
\]

No endpoint term is discarded: it remains inside the exact finite means \(\mu_{p,q}\).

# 3. Exact layer cake and dyadic shells

## Theorem 3.1 — finite ordered layer cake

Define

\[
V_X(u)=\sum_{p\ne q}J_{p,q}\mathbf1_{\{\delta_{p,q}>u\}}
\qquad(u\ge0).
\]

Then

\[
\boxed{
P^{\mathrm{fin}}_3(X)=\int_0^\infty V_X(u)\,du.}
\tag{3.1}
\]

**Proof.** The pair set is finite, so Tonelli is merely interchange of two finite nonnegative sums:

\[
\sum_{p\ne q}J_{p,q}\delta_{p,q}
 =\sum_{p\ne q}J_{p,q}
   \int_0^{\delta_{p,q}}du
 =\int_0^\infty V_X(u)\,du.
\]

Use (2.1). \(\square\)

Assume now \(\lambda>0\). Define the light set

\[
\mathcal S_{-1}=\{(p,q):\delta_{p,q}\le\lambda\}
\]

and, for \(j\ge0\), the exact dyadic shells

\[
\mathcal S_j
 =\{(p,q):2^j\lambda<\delta_{p,q}\le2^{j+1}\lambda\}.
\]

Put

\[
W_j=\sum_{(p,q)\in\mathcal S_j}J_{p,q}.
\]

The decomposition is finite. Indeed, if \(L_X\) is the number of active primes, then

\[
0\le\delta_{p,q}\le\frac{T_{p,q}}{J_{p,q}}\le L_X-2\le X.
\]

Also \(\lambda>0\) implies \(\lambda\ge1/(2X)\). Consequently

\[
\frac{\delta_{p,q}}\lambda\le2X^2,
\]

so only \(O(\log X)\) shells are nonempty.

For the light and shell contributions one has

\[
0\le
\sum_{(p,q)\in\mathcal S_{-1}}J_{p,q}\delta_{p,q}
\le\lambda F_2(X),
\]

and

\[
2^j\lambda W_j
 <\sum_{(p,q)\in\mathcal S_j}J_{p,q}\delta_{p,q}
 \le2^{j+1}\lambda W_j.
\]

Therefore

\[
\boxed{
P^{\mathrm{fin}}_3(X)
 \le\lambda F_2(X)+2\lambda\sum_{j\ge0}2^jW_j.}
\tag{3.2}
\]

When \(\lambda=0\), every zero set is empty and every displayed quantity is zero, so no division by a possibly vanishing parameter is hidden.

## Corollary 3.2 — a genuine fixed gain closes ACF3

Suppose that for some fixed \(\varepsilon>0\) and some \(C_X=X^{o(1)}\), one has, pointwise for every \(X\) and every \(j\ge0\),

\[
\tag{DOT_\varepsilon}
W_j\le C_X\,2^{-(1+\varepsilon)j}F_2(X).
\]

Then

\[
P^{\mathrm{fin}}_3(X)
 \le\left(1+\frac{2C_X}{1-2^{-\varepsilon}}\right)
       \lambda_XF_2(X)
 \ll X^{2+o(1)}\lambda_X^3.
\]

**Proof.** Substitute \((\mathrm{DOT}_\varepsilon)\) into (3.2):

\[
2\lambda\sum_{j\ge0}2^jW_j
 \le2C_X\lambda F_2
      \sum_{j\ge0}2^{-\varepsilon j}
 =\frac{2C_X}{1-2^{-\varepsilon}}\lambda F_2.
\]

Apply (2.2). \(\square\)

This is not a renamed ACF3 estimate. Conversely, ACF3 itself would give from the lower shell inequality only

\[
W_j
 \le\frac{P^{\mathrm{fin}}_3(X)}{2^j\lambda_X}
 \ll X^{2+o(1)}\lambda_X^2\,2^{-j},
\]

which has exponent \(1\), not \(1+\varepsilon\). A fixed positive gain is a strictly stronger distribution statement.

# 8. Scoped no-go and the surviving theorem

## What is ruled out

The exact Apéry packet rules out any argument whose decisive conclusion is one of the following coefficient-one statements:

\[
\sum_{p\ne q}J_{p,q}
 \left(\frac{\delta_{p,q}}{\lambda_X}\right)^3
 \le F_2(X),
\]

\[
W_j\le2^{-3j}F_2(X),
\]

or any constant-\(C\) cubic tail with

\[
C<\frac{3584}{1095}.
\]

This includes a putative local recurrence/Cartier estimate that first takes absolute values, forms a coefficient-one cubic conditional energy, and only afterward applies Markov. The failure is not generic-model evidence: the seven offending anchor loci are actual reductions of the one Apéry sequence and the explicit survivor is checked through both exact recurrences.

## What is not ruled out

The audit does not rule out:

- \((\mathrm{DOT}_\varepsilon)\) for a smaller fixed \(\varepsilon>0\) with an \(X^{o(1)}\) factor;
- a large enough absolute constant in a cubic tail;
- a quadratic overload energy;
- a theorem that first separates atomic \((J,T)=(1,1)\) packets and then proves stronger decay for the remaining pair loci;
- a genuinely mixed-characteristic determinant, diagonal, or Cartier identity controlling the total number of atomic packets;
- finite ACF3 itself.

The sharp residual theorem remains:

\[
\boxed{
\text{For some fixed }\varepsilon>0,
\quad
W_j\ll X^{o(1)}2^{-(1+\varepsilon)j}F_2(X)
\quad\text{for all }X,j.}
\tag{DOT}
\]

By Corollary 3.2, (DOT) closes finite ACF3. Unlike ACF3, it contains a real fixed gain in the overload level. The smallest packet shows that a successful proof must either tolerate atomic shells with an explicit correction or obtain its decay by a mechanism subtler than a coefficient-one cubic moment.

A useful atomic-aware split would be to prove separately

\[
\#\{(p,q)\text{ ordered}:J_{p,q}=T_{p,q}=1\}
 \ll X^{o(1)}M\lambda_X^3
\]

and a fixed-gain shell estimate for the complementary pairs. This pair of statements is sufficient, but neither part is proved here.

# 10. Why ordinary moment lifting is circular here

For every real \(s\ge1\), Jensen on each pair locus gives

\[
J_{p,q}\left(\frac{T_{p,q}}{J_{p,q}}\right)^s
 \le
\sum_{m\in\Omega_p\cap\Omega_q}(K(m)-2)^s.
\]

Summing ordered anchors yields

\[
\sum_{p\ne q}
J_{p,q}\left(\frac{T_{p,q}}{J_{p,q}}\right)^s
 \le
\sum_{m<M}(K(m))_2(K(m)-2)^s.
\tag{10.1}
\]

For integer powers, the right side is a positive combination of higher factorial moments. For example,

\[
(K)_2(K-2)^2=(K)_4+(K)_3,
\]

\[
(K)_2(K-2)^3=(K)_5+3(K)_4+(K)_3.
\]

Thus deriving overload decay from (10.1) by inserting unproved independence-scale bounds for \(F_4,F_5,\ldots\) merely moves the missing theorem to higher moments. It does not exploit the Apéry sequence. The cubic counterexample additionally shows that centering by \(\mu_{p,q}\) and normalizing by \(\lambda\) cannot make a coefficient-one third moment true automatically.

# 11. Standalone exact verifier

The following standard-library script recomputes both Apéry recurrences, every zero set, every two-prime CRT locus, every third-prime extension, the exact finite means, and the dyadic shells at \(X=256,512\). It also verifies the explicit \((857,953;659;m=98926)\) packet. All comparisons use `Fraction`; floating point is not used.

```python
#!/usr/bin/env python3
from __future__ import annotations

from collections import defaultdict
from fractions import Fraction
from math import isqrt


def primes_upto(limit: int) -> list[int]:
    sieve = bytearray(b"\x01") * (limit + 1)
    sieve[0:2] = b"\x00\x00"
    for d in range(2, isqrt(limit) + 1):
        if sieve[d]:
            start = d * d
            sieve[start : limit + 1 : d] = b"\x00" * (
                (limit - start) // d + 1
            )
    return [n for n in range(2, limit + 1) if sieve[n]]


def coeff(n: int) -> int:
    return 34 * n**3 + 51 * n**2 + 27 * n + 5


def apery_zeros_divided(p: int) -> tuple[int, ...]:
    values = [1 % p, 5 % p]
    for n in range(1, p - 1):
        numerator = (coeff(n) * values[n] - n**3 * values[n - 1]) % p
        denominator = pow(n + 1, 3, p)
        values.append(numerator * pow(denominator, -1, p) % p)
    return tuple(i for i, value in enumerate(values) if value == 0)


def apery_zeros_cleared(p: int) -> tuple[int, ...]:
    previous, current = 1 % p, 5 % p
    zeros: list[int] = []
    if previous == 0:
        zeros.append(0)
    if current == 0:
        zeros.append(1)
    for n in range(1, p - 1):
        following = (coeff(n) * current - pow(n, 6, p) * previous) % p
        previous, current = current, following
        if current == 0:
            zeros.append(n + 1)
    return tuple(zeros)


def representatives(M: int, p: int, roots: tuple[int, ...]) -> int:
    return sum((M - 1 - r) // p + 1 for r in roots)


def pair_representatives(
    M: int,
    p: int,
    roots_p: tuple[int, ...],
    q: int,
    roots_q: tuple[int, ...],
) -> tuple[int, ...]:
    inv = pow(p, -1, q)
    out = {
        rp + p * (((rq - rp) * inv) % q)
        for rp in roots_p
        for rq in roots_q
    }
    return tuple(sorted(a for a in out if a < M))


def audit(X: int):
    M = X * X
    primes = [p for p in primes_upto(2 * X) if p > X]
    zeros: dict[int, tuple[int, ...]] = {}
    for p in primes:
        divided = apery_zeros_divided(p)
        cleared = apery_zeros_cleared(p)
        assert divided == cleared
        root_set = set(cleared)
        assert all(p - 1 - r in root_set for r in cleared)
        zeros[p] = cleared

    active = [p for p in primes if zeros[p]]
    zero_sets = {p: set(zeros[p]) for p in active}
    lam = sum((Fraction(len(zeros[p]), p) for p in primes), Fraction(0))
    rho = {
        p: Fraction(representatives(M, p, zeros[p]), M)
        for p in primes
    }
    total_rho = sum(rho.values(), Fraction(0))

    records = []
    for i, p in enumerate(active):
        for q in active[i + 1 :]:
            reps = pair_representatives(M, p, zeros[p], q, zeros[q])
            J = len(reps)
            T = sum(
                sum(
                    m % ell in zero_sets[ell]
                    for ell in active
                    if ell not in (p, q)
                )
                for m in reps
            )
            mu = total_rho - rho[p] - rho[q]
            delta = max(Fraction(T, J) - mu, Fraction(0)) if J else Fraction(0)
            records.append((p, q, reps, J, T, mu, delta))

    F2 = 2 * sum(record[3] for record in records)
    F3 = 2 * sum(record[4] for record in records)

    shell_mass: dict[int, int] = defaultdict(int)
    for _, _, _, J, _, _, delta in records:
        if delta <= lam:
            continue
        j = 0
        while delta > (1 << (j + 1)) * lam:
            j += 1
        assert (1 << j) * lam < delta <= (1 << (j + 1)) * lam
        shell_mass[j] += 2 * J  # restore both ordered orientations

    return {
        "X": X,
        "M": M,
        "primes": primes,
        "active": active,
        "zeros": zeros,
        "lam": lam,
        "rho": rho,
        "records": records,
        "F2": F2,
        "F3": F3,
        "shell_mass": dict(shell_mass),
    }
```
