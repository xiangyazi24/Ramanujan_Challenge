# Audit of Q1594: the full-inverse Riccati source has orders 1, 2, 3 — not a global \(\Delta^2\)

## Verdict

Q1594's global factor premise is wrong.  For the **full** inverse

\[
V\equiv A^{-1}\pmod M,
\qquad AV-1=MS,
\]

the exact folded Riccati identity has the form

\[
\boxed{
\mathcal L\!\left(\frac{t}{V}\right)(z)
 =\frac{u(z)\,M(\lambda_z)\,W_V(\lambda_z)}
 {v_{z-1}v_zv_{z+1}},
}
\tag{0.1}
\]

where

\[
\lambda_z=z(z+1),\qquad u(z)=2z+1=\lambda'(z),\qquad
v_j=V(\lambda_j).
\]

For \(p=2m+1\), \(r<m\), the actual modulus is

\[
\boxed{
M(Y)=(Y-\lambda_m)
      \prod_{i=0}^{r}(Y-\lambda_i)
      \prod_{i=r+1}^{m-1}(Y-\lambda_i)^2.
}
\tag{0.2}
\]

Thus \(M\) has simple \(Y\)-roots \(\lambda_0,\dots,\lambda_r,\lambda_m\), and double roots only at \(\lambda_{r+1},\dots,\lambda_{m-1}\).  After pulling back by \(Y=\lambda_z\), the source in (0.1) has structural orders

\[
\boxed{
\operatorname{ord}_{z=r}=1,
\qquad
\operatorname{ord}_{z=r+1}=2,
\qquad
\operatorname{ord}_{z=m}=3,
}
\tag{0.3}
\]

provided the displayed quotient value \(W_V\) does not itself vanish at the node.  The midpoint order is three because a **simple** \(Y\)-root of \(M\) becomes quadratic under \(\lambda_z\), and the extra anti-invariant factor \(u=2z+1\) contributes one more zero.

So Q1594's premise

\[
LD=(z^p-z)^2\widetilde W
\tag{Q1594-false}
\]

cannot be used globally.  The correct global factor is only one copy of \(z^p-z\):

\[
\boxed{
u(z)M(\lambda_z)
=\frac{u(z)^2}{2}\,T_r(\lambda_z)\,(z^p-z),
}
\tag{0.4}
\]

where

\[
T_r(Y):=\prod_{i=r+1}^{m-1}(Y-\lambda_i).
\]

Equivalently, with

\[
H_r(Y):=\prod_{i=0}^{r}(Y-\lambda_i),
\]

\[
\boxed{
\frac{u(z)M(\lambda_z)}{(z^p-z)^2}
=\frac{u(z)}{H_r(\lambda_z)}
}
\tag{0.5}
\]

as a rational function.  The right side has poles at the simple lower/target nodes unless an unrelated zero of \(W_V\) cancels them.  That is exactly what the false global \(\Delta^2\) argument suppressed.

The third jet is useful as a **quotient-jet evaluation**, but it does not give a new homogeneous constraint on \(V\).  At a doubled tail node it determines \(W_V'\) after the second jet has determined \(W_V\); on the Bezout side the corresponding third derivative determines \(S'\) after the second derivative has determined \(S\).  These are quotient coefficients, not new zeros.  At the ramified midpoint the third \(z\)-jet does not even see \(W_V'\): it is the first jet that sees the value \(W_V(\lambda_m)\).

Therefore the corrected outcome is a **scoped no-go** for Q1594's proposed descent: the third jet by itself supplies no equation independent enough to turn the one-degree cancellation \(W_V+16cV\) into a second descent or a divisibility statement.

# 2. Exact factorization of the pulled-back modulus

Put

\[
K(Y):=\prod_{i=0}^{m-1}(Y-\lambda_i)
     =H_r(Y)T_r(Y).
\]

The standard folded-field identity is

\[
\boxed{
z^p-z=\frac{u(z)}2K(\lambda_z).
}
\tag{2.1}
\]

Also

\[
4\lambda_z+1=u(z)^2,
\qquad
4\lambda_m+1=0,
\]

hence

\[
\boxed{
\lambda_z-\lambda_m=\frac{u(z)^2}{4}.
}
\tag{2.2}
\]

From (0.2),

\[
M(Y)=(Y-\lambda_m)H_r(Y)T_r(Y)^2.
\]

Substituting \(Y=\lambda_z\) and using (2.1)--(2.2),

\[
\begin{aligned}
uM(\lambda_z)
&=u\frac{u^2}{4}H_r(\lambda_z)T_r(\lambda_z)^2\\
&=\frac{u^2}{2}T_r(\lambda_z)
   \left(\frac u2H_r(\lambda_z)T_r(\lambda_z)\right)\\
&=\frac{u^2}{2}T_r(\lambda_z)(z^p-z).
\end{aligned}
\]

This is (0.4).  It gives the local orders without any differentiation:

* at \(z=r\), \(u(r)\ne0\) and \(T_r(\lambda_r)\ne0\), so there is exactly the one field-polynomial zero;
* at \(z=r+1<m\), \(T_r(\lambda_z)\) contributes one further unramified zero, so the order is two;
* at \(z=m\), \(T_r(\lambda_m)\ne0\), while \(u^2\) contributes two zeros on top of the single zero of \(z^p-z\), so the order is three.

This is the fastest way to see why a uniform \(\Delta^2\) model is impossible.

# 3. Set up the quotient calculus once

Write

\[
R(Y):=M(Y)W_V(Y),
\qquad
D(z):=v_{z-1}v_zv_{z+1},
\]

so that

\[
F(z):=\mathcal L(t/V)(z)
=\frac{N(z)}{D(z)},
\qquad
N(z):=u(z)R(\lambda_z).
\tag{3.1}
\]

At every relevant node, \(D(z)\ne0\): the inverse congruence gives \(A(\lambda_i)V(\lambda_i)=1\) at every root of \(M\), and the folded neighboring values are roots of the same modulus in the range used below.

Since

\[
\lambda'=u,
\qquad u'=2,
\qquad \lambda''=2,
\qquad \lambda'''=0,
\]

a direct chain-rule calculation gives, at any point where \(R(\lambda_z)=0\),

\[
\boxed{
N'=u^2R',
}
\tag{3.2}
\]

\[
\boxed{
N''=u^3R''+6uR',
}
\tag{3.3}
\]

\[
\boxed{
N'''=u^4R'''+12u^2R''+12R'.
}
\tag{3.4}
\]

All \(R\)-derivatives here are \(Y\)-derivatives evaluated at \(Y=\lambda_z\).

For the denominator,

\[
D_j:=D(j)=v_{j-1}v_jv_{j+1},
\]

and

\[
\boxed{
\begin{aligned}
D'_j={}&
 a_{j-1}V'(\lambda_{j-1})v_jv_{j+1}\\
&+a_jV'(\lambda_j)v_{j-1}v_{j+1}\\
&+a_{j+1}V'(\lambda_{j+1})v_{j-1}v_j,
\end{aligned}}
\tag{3.5}
\]

where

\[
a_j:=2j+1.
\]

If \(N(j)=0\), then

\[
F'(j)=\frac{N'(j)}{D_j},
\tag{3.6}
\]

\[
F''(j)=\frac{N''(j)}{D_j}
       -2\frac{N'(j)D'_j}{D_j^2}.
\tag{3.7}
\]

If in addition \(N'(j)=0\), then

\[
\boxed{
F'''(j)=\frac{N'''(j)}{D_j}
        -3\frac{N''(j)D'_j}{D_j^2}.
}
\tag{3.8}
\]

These formulas keep every denominator factor visible; no logarithmic-derivative shorthand is needed.

# 4. Case (a): the target \(z=r\)

Let

\[
y:=\lambda_r,
\qquad a_r=2r+1\ne0.
\]

The target \(y\) is a **simple** root of \(M\).  Hence

\[
R(y)=0,
\qquad
R'(y)=M'(y)W_V(y).
\]

From (3.2) and (3.6),

\[
\boxed{
F'(r)
=\frac{a_r^2M'(y)W_V(y)}
       {v_{r-1}v_rv_{r+1}}.
}
\tag{4.1}
\]

This is the first derivative not killed by the actual source multiplicity.  In particular, if \(W_V(y)\ne0\), the target zero has exact order one.  A global \((z^p-z)^2\) factor would instead force \(F'(r)=0\).

The root derivative can be written entirely as a product:

\[
\boxed{
M'(\lambda_r)
=(\lambda_r-\lambda_m)
 \prod_{i=0}^{r-1}(\lambda_r-\lambda_i)
 \prod_{i=r+1}^{m-1}(\lambda_r-\lambda_i)^2
\ne0.
}
\tag{4.2}
\]

For completeness, the actual second jet at the target is

\[
\boxed{
\begin{aligned}
F''(r)
={1\over D_r^2}\Big(&D_r\big[
 a_r^3\{M''(y)W_V(y)+2M'(y)W_V'(y)\}
 +6a_rM'(y)W_V(y)\big]\\
&-2a_r^2M'(y)W_V(y)D'_r\Big).
\end{aligned}}
\tag{4.3}
\]

There is no homogeneous vanishing statement hidden in (4.3); it is already a quotient-value/slope formula after the simple zero has been removed.

# 5. Case (b): first doubled tail node \(j=r+1\)

Assume \(r+1<m\) and put

\[
j:=r+1,
\qquad x:=\lambda_j,
\qquad a:=a_j=2j+1\ne0.
\]

Now \(x\) is a double root of \(M\).  Therefore

\[
R(x)=R'(x)=0,
\]

\[
R''(x)=M''(x)W_V(x),
\tag{5.1}
\]

\[
R'''(x)=M'''(x)W_V(x)+3M''(x)W_V'(x).
\tag{5.2}
\]

Consequently

\[
F(j)=F'(j)=0
\]

and the first potentially nonzero derivative is

\[
\boxed{
F''(j)
=\frac{a^3M''(x)W_V(x)}
       {v_{j-1}v_jv_{j+1}}.
}
\tag{5.3}
\]

This is the precise full-inverse version of the second-jet statement.  It gives the **value of the quotient** \(W_V(x)\); it does not give another zero.

Here

\[
\boxed{
\begin{aligned}
M''(x)=2&(x-\lambda_m)
\prod_{i=0}^{r}(x-\lambda_i)
\prod_{i=r+2}^{m-1}(x-\lambda_i)^2
\ne0.
\end{aligned}}
\tag{5.4}
\]

The third derivative is the first place where \(W_V'(x)\) occurs.  Using (3.4), (3.8), (5.1), and (5.2),

\[
\boxed{
\begin{aligned}
F'''(j)
={1\over D_j^2}\Big(&D_j\big[
 a^4\{M'''(x)W_V(x)+3M''(x)W_V'(x)\}
 +12a^2M''(x)W_V(x)\big]\\
&-3a^3M''(x)W_V(x)D'_j\Big).
\end{aligned}}
\tag{5.5}
\]

Every denominator contribution is explicit in (3.5).  Solving (5.5) for \(W_V'(x)\) is legitimate because \(a\), \(M''(x)\), and \(D_j\) are nonzero.  But that operation **computes a quotient slope**; it does not force the slope to vanish.

If one prefers to remove \(M'''\), write

\[
M(Y)=(Y-x)^2M_x^*(Y).
\]

Then

\[
M''(x)=2M_x^*(x),
\qquad
M'''(x)=6(M_x^*)'(x).
\]

So (5.5) is completely explicit from the root list of \(M\), \(V\), and \(W_V\).

At the midpoint,

\[
a_m=2m+1=0\quad\text{in }\mathbf F_p,

and, exactly,

\[
\lambda_z-\lambda_m=(z-m)^2.

\[
F(m)=F'(m)=F''(m)=0,

while

\[
\boxed{

       {v_{m-1}v_mv_{m+1}}.

\tag{6.2}

Since

\[
\lambda_{m+1}=\lambda_{m-1},

this may also be written

\[
\boxed{

\tag{6.3}

For \(p\ge5\), \(12\ne0\) unless \(p=2,3\), which are outside the nontrivial regime here.  The product formula is

\boxed{

Notice what the midpoint third jet does **not** contain: it does not contain \(W_V'(\lambda_m)\).  The third derivative is merely the first quotient-value jet there.  Because of ramification, a \(W_V'\)-term only appears later.

# 7. Why the third jet is not the missing independent equation

There are two parallel quotient identities.

## 7.1 Riccati quotient

By definition after the established divisibility,

\[
R_V=MW_V.
\]

At a doubled tail root \(x\),

\[
R_V''(x)=M''(x)W_V(x),
\]

\[
\boxed{
R_V'''(x)=M'''(x)W_V(x)+3M''(x)W_V'(x).
}
\tag{7.1}
\]

Thus the second and third jets successively recover \(W_V(x)\) and \(W_V'(x)\).  They are exactly the Hermite quotient data of the already-known factorization \(R_V=MW_V\).

## 7.2 Bezout quotient

Likewise

\[
B:=AV-1=MS.
\]

At the same doubled root,

\[
B''(x)=M''(x)S(x),
\]

\[
\boxed{
B'''(x)=M'''(x)S(x)+3M''(x)S'(x).
}
\tag{7.2}
\]

Hence

\[
\boxed{
S(x)=\frac{B''(x)}{M''(x)},
\qquad
S'(x)=\frac{B'''(x)-M'''(x)S(x)}{3M''(x)}.
}
\tag{7.3}
\]

At a simple root \(y\), the analogous formulas are

\[
\boxed{
S(y)=\frac{B'(y)}{M'(y)},
\qquad
S'(y)=\frac{B''(y)-M''(y)S(y)}{2M'(y)}.
}
\tag{7.4}
\]

So a third differentiated WZ/Bezout identity can certainly be **new algebra relative to stopping at the second derivative**, but it is not a new homogeneous condition: it introduces the next quotient jets \(W_V'\) and \(S'\), and one equation solves for one of them.  It does not eliminate an already-existing degree of freedom.

There is an important logical nuance here.

* The WZ identity is additional structure beyond the bare congruence \(AV\equiv1\pmod M\), so a third-differentiated WZ identity is not literally a formal consequence of the congruence in isolation.
* But in the full Riccati identity (0.1), \(W_V\) is itself the quotient obtained from the folded Riccati numerator.  Therefore differentiating (0.1) does not impose a second independent condition on \(V\); it evaluates the next coefficient of that quotient.
* If one wants an actual contradiction from the third jet, one needs a second relation that eliminates \(W_V'\) or \(S'\) **without defining it**.  Q1594 did not have such a relation; \(\Delta^2\) was being used as a surrogate for it, and that surrogate is false.

This is the precise no-go.

# 9. Radical \(U\) versus full \(V\): do not transfer the false \(\eta=0\)

This distinction is essential.

For the complete radical modulus

\[
G(Y)=\prod_{i=0}^{m}(Y-\lambda_i),
\]

the radical inverse \(U\equiv A^{-1}\pmod G\) only matches values at the folded nodes.  It does **not** impose the derivative matching supplied by the doubled factors in \(M\).  Therefore a first-jet defect can be nonzero at an interior node.

For the full inverse \(V\), however, every \(\lambda_j\) with

\[
r<j<m
\]

is a double root of \(M\).  Hence

\[
(AV-1)(\lambda_j)=0,
\qquad
(AV-1)'(\lambda_j)=0.
\]

So the Hermite lift really does kill that first reciprocal mismatch at the doubled tail nodes.  This is why the radical and full-inverse calculations must not be conflated.

The supplied ground truth states that the radical computation already has a nonzero first-jet defect at

\[
\boxed{p=17,\qquad r=3.}
\]

That is the smallest actual counterexample relevant to the inherited Q1585 claim `eta = 0` in the current audit.  It refutes the radical premise; it is **not** an argument that the full \(V\) lacks its double tail contact.

The Sage verifier below reconstructs both inverses from the WZ polynomial and prints the radical first-jet defect exactly in \(\mathbf F_p\), so this can be checked without floating-point arithmetic or a hand-entered polynomial.

# 11. Reproducible Sage verifier

The following script needs only Sage.  It does four things from scratch:

1. reconstructs the degree-\(p-1\) WZ polynomial \(P_m\) by solving the exact polynomial recurrence;
2. builds \(A=P_m/(Y-\lambda_r)\), the actual Hermite modulus \(M\), and the full inverse \(V=A^{-1}\bmod M\);
3. constructs the folded Riccati quotient \(W_V\) and verifies (4.1), (5.3), (5.5), and (6.2) exactly;
4. constructs the radical inverse modulo \(G=\prod_{0\le j\le m}(Y-\lambda_j)\) and reports the first-jet defect.  A scan over primes identifies the first nonzero case instead of hard-coding it.

```sage
# SageMath 10.x

from sage.all import *


def nth_derivative(f, n):
    g = f
    for _ in range(n):
        g = g.derivative()
    return g


def solve_P(p):
    F = GF(p)
    RY = PolynomialRing(F, 'Y'); Y = RY.gen()
    Rz = PolynomialRing(F, 'z'); z = Rz.gen()

    lam0 = z*(z+1)
    lamp = (z+1)*(z+2)
    lamm = (z-1)*z
    u = 2*z+1

    def comp(P, X):
        return sum(F(P[i]) * X**i for i in range(P.degree()+1)) if P else Rz(0)

    def Lop(P):
        return ((z+1)**3 * comp(P, lamp)
              - u*(F(17)*lam0 + F(5))*comp(P, lam0)
              + z**3 * comp(P, lamm))

    rhs = -F(16)*u*(z**p-z)**2
    ncols = p                    # degree <= p-1
    nrows = 2*p + 2              # coefficients z^0,...,z^(2p+1)

    cols = []
    for i in range(ncols):
        q = Lop(Y**i)
        cols.append(vector(F, [q[k] for k in range(nrows)]))
    Aop = matrix(F, cols).transpose()
    b = vector(F, [rhs[k] for k in range(nrows)])
    c = Aop.solve_right(b)
    P = sum(c[i]*Y**i for i in range(ncols))

    assert Lop(P) == rhs
    assert P.degree() == p-1
    return F, RY, Y, Rz, z, P


def full_data(p, r):
    F, RY, Y, Rz, z, P = solve_P(p)
    m = (p-1)//2
    assert 0 <= r < m

    def lam(j):
        jj = F(j)
        return jj*(jj+1)

    def a(j):
        return F(2*j+1)

    y = lam(r)
    assert P(y) == 0
    qA, remA = P.quo_rem(Y-y)
    assert remA == 0
    A = qA
    assert A.degree() == 2*m-1

    M = (Y-lam(m))
```

# 13. Corrected theorem to reuse

A clean reusable statement is the following.

> **Full-inverse pulled-back Riccati jet theorem.**  Let \(p=2m+1\ge5\), \(0\le r<m\), \(\lambda_z=z(z+1)\), \(u=2z+1\), and let
> \[
> M=(Y-\lambda_m)\prod_{i=0}^{r}(Y-\lambda_i)
>                 \prod_{i=r+1}^{m-1}(Y-\lambda_i)^2.
> \]
> Suppose \(V\) is invertible at the roots of \(M\) and
> \[
> F(z)=\frac{u(z)M(\lambda_z)W(\lambda_z)}
> {V(\lambda_{z-1})V(\lambda_z)V(\lambda_{z+1})}.
> \]
> Then the source has pulled-back multiplicity one at \(r\), two at every unramified doubled tail node, and three at \(m\).  More precisely, (4.1), (5.3), (5.5), and (6.2) hold.  Globally,
> \[
> uM(\lambda_z)=\frac{u^2}{2}T_r(\lambda_z)(z^p-z),
> \]
> so no second global copy of \(z^p-z\) exists.  At a doubled node the third derivative determines the quotient slope \(W'\); it is not a homogeneous vanishing condition.  At the midpoint the third derivative determines only the quotient value \(W(\lambda_m)\).

Applied to the Problem 3.2 full inverse, this theorem removes the central premise of Q1594.  The surviving higher-jet route would need a genuinely new identity that relates the quotient slopes to the degree-descended combination; differentiating the existing Riccati/Bezout factorizations one more time does not provide it.
