# P3.2 square-branch root exclusion via augmented Apéry transfer

## Verdict

There is a useful transfer-matrix elimination which is genuinely different from clearing
\(D_r=N_r/h_r\) and writing the old \(\Theta\)-polynomial.

Let

\[
Q(X)=\alpha X^2+\beta X+\gamma,
\qquad \gamma\in\mathbf F_p^\times,
\]

and suppose \(b_r=0\) is the unique simple noncentral canonical zero.  For
\(1\le r<m\), write

\[
M=M_{m,r}=T_{m-1}\cdots T_r,
\qquad
K=\frac12\left.\frac{d}{dx}M_{m,r}(x)\right|_{x=0},
\]

where \(T_j(x)\) is the shifted Apéry transfer matrix defined below.  Put

\[
u=b_{r-1},\qquad
J_m=\binom{0}{3(b_{m-1}-b_m)},\qquad
v=Me_2,
\]

and define the single right-boundary minor

\[
\boxed{
A_{r,m}:=\det\!\left(J_m-uKe_2,\;Me_2\right).
}
\]

The homogeneous transfer determinant telescopes to the explicit unit

\[
\boxed{
\delta_{r,m}:=\det M=\left(\frac r m\right)^3.
}
\]

Then the canonical augmented transfer gives the exact Cramer identity

\[
\boxed{
\delta_{r,m}D_r=A_{r,m}.
}
\tag{T1}
\]

Consequently the quadratic gate has been eliminated without \(N_r\), \(h_r\),
or the old \(\Theta\) numerator:

\[
\boxed{
q_0=0
\iff
\mathscr B_{r,m}:=
\operatorname{Res}_X\!\left(
\alpha X^2+\beta X+\gamma,\;\delta_{r,m}X-A_{r,m}
\right)=0,
}
\]

with the explicit degree-two boundary resultant

\[
\boxed{
\mathscr B_{r,m}
=\alpha A_{r,m}^2
 +\beta\delta_{r,m}A_{r,m}
 +\gamma\delta_{r,m}^2.
}
\tag{T2}
\]

This is the sharp transfer reduction I can justify from the current sources.  It does
**not** by itself force nonvanishing.  The reason is structural: the transfer/Casoratian
identities determine the Cramer coordinate \(A/\delta=D_r\), but they impose no
additional relation on the external value-only quadratic \((\alpha,\beta,\gamma)\).
A contradiction therefore cannot be obtained from the homogeneous transfer determinant
and singleton simplicity alone.  One must use the actual Q1--Q7 formulas for
\(\alpha,\beta,\gamma\) to prove the new boundary resultant nonzero.

On the square-discriminant branch \(\Delta=s^2\), (T2) becomes two **linear
boundary-minor** exclusions.  Set

\[
\Xi_{r,m}:=2\alpha A_{r,m}+\beta\delta_{r,m}.
\]

Then

\[
\boxed{
4\alpha\mathscr B_{r,m}
=\Xi_{r,m}^2-\delta_{r,m}^2\Delta.
}
\tag{T3}
\]

If \(\alpha\ne0\), define

\[
\Lambda_\pm
:=\Xi_{r,m}\mp\delta_{r,m}s.
\]

The two branch conditions are

\[
\boxed{
\Lambda_\pm
=\det\!\left(
2\alpha R+(\beta\mp s)Me_1,\;Me_2
\right),
\qquad
R:=J_m-uKe_2.
}
\tag{T4}
\]

Thus the square-root branches have a precise transfer meaning: a hypothetical root forces
one center-corrected inhomogeneous boundary vector to become collinear with the fixed
homogeneous column \(Me_2\).  The smaller all-prime lemma is therefore

\[
\boxed{
\Lambda_+\ne0\quad\text{and}\quad\Lambda_-\ne0
}
\]

on every square-discriminant singleton record (equivalently \(\mathscr B_{r,m}\ne0\)
without choosing a square root).

Both required controls pass:

- \(p=17,r=3,m=8\): \(\delta=5\), \(A=11\),
  \(\mathscr B=4\ne0\), and for \(s=2\),
  \((\Lambda_+,\Lambda_-)=(8,11)\).
- \(p=31,r=8,m=15\): \(\delta=27\), \(A=8\),
  \(\mathscr B=19\ne0\), and for \(s=11\),
  \((\Lambda_+,\Lambda_-)=(10,15)\).

So the actual jets \(9\) and \(29\) are excluded from the two roots without identifying
the roots with a simple Apéry/Gessel/companion coordinate.

The main gain over \(\Theta\) is that \(A_{r,m}\) is a **single right-boundary
Casoratian/transfer derivative** whose denominator is the explicit unit \((r/m)^3\).
For fixed center gap \(g=m-r\), it is built from bounded-index restart Green functions,
so the remaining all-prime lemma has bounded transfer complexity even though the old
left source sum has length \(r\).

## 2. The exact augmented transfer cocycle

Introduce the shifted homogeneous matrix

\[
T_j(x)=
\begin{pmatrix}
\dfrac{C(j+x)}{(j+1+x)^3}
&-\dfrac{(j+x)^3}{(j+1+x)^3}\\[2mm]
1&0
\end{pmatrix}.
\]

Let

\[
B_j:=\binom{b_j}{b_{j-1}},
\qquad
J_j:=\binom{D_j}{D_{j-1}}.
\]

Differentiating the shifted recurrence and dividing the derivative by two gives

\[
J_{j+1}=T_j(0)J_j+S_jB_j,
\qquad
S_j:=\frac12T_j'(0).
\]

Explicitly, only the first row of \(S_j\) is nonzero:

\[
S_j=
\begin{pmatrix}
\dfrac{(j+1)C'(j)-3C(j)}{2(j+1)^4}
&-\dfrac{3j^2}{2(j+1)^4}\\[2mm]
0&0
\end{pmatrix}.
\]

Substitution of the homogeneous recurrence into the first component gives precisely

\[
(j+1)^3D_{j+1}-C(j)D_j+j^3D_{j-1}
=rac{C'(j)b_j-3(j+1)^2b_{j+1}-3j^2b_{j-1}}2.
\]

Thus the four-dimensional state has the block-triangular transfer

\[
\boxed{
\binom{B_{j+1}}{J_{j+1}}
=
\begin{pmatrix}
T_j&0\\
S_j&T_j
\end{pmatrix}
\binom{B_j}{J_j}.
}
\tag{2.1}
\]

For an interval \(a<b\), put

\[
M_{b,a}(x)=T_{b-1}(x)\cdots T_a(x),
\qquad
K_{b,a}=\frac12M_{b,a}'(0).
\]

The product rule gives the exact augmented interval transfer

\[
\boxed{
\begin{pmatrix}
M_{b,a}&0\\
K_{b,a}&M_{b,a}
\end{pmatrix}.
}
\tag{2.2}
\]

This is the useful transfer form of the inhomogeneous derivative orbit: the source has
been absorbed into the derivative block \(K\).

The determinant is elementary:

\[
\det T_j(x)=\left(\frac{j+x}{j+1+x}\right)^3,
\]

hence

\[
\boxed{
\det M_{b,a}(0)=\left(\frac a b\right)^3.
}
\tag{2.3}
\]

No Apéry value occurs in this denominator.

## 4. Exact center boundary for every noncentral target

The canonical shell has the folded symmetry

\[
b_{p-1-j}=b_j,
\qquad
D_{p-1-j}=-D_j.
\]

At the center \(m=(p-1)/2\), this gives

\[
\boxed{D_m=0.}
\tag{4.1}
\]

At the adjacent reflected pair,

\[
b_{m+1}=b_{m-1},
\qquad
D_{m+1}=-D_{m-1}.
\]

Insert these into the differentiated recurrence at \(j=m\).  Modulo \(p\),

\[
m=-\frac12,\qquad m+1=\frac12=-m,
\]

and

\[
C'(m)=102m^2+102m+27=\frac32.
\]

Therefore

\[
2m^3D_{m-1}
=\frac34b_m-3m^2b_{m-1}.
\]

Using \(m^2=1/4\) and \(2m^3=-1/4\) gives the exact value-only center jet

\[
\boxed{
D_{m-1}=3(b_{m-1}-b_m).
}
\tag{4.2}
\]

Thus the full terminal derivative state is

\[
\boxed{
J_m=
\binom{0}{3(b_{m-1}-b_m)}.
}
\tag{4.3}
\]

For the gap-one case \(r=m-1\), where \(b_{m-1}=0\), this specializes to
\(D_r=-3b_m\), exactly the center-boundary identity used in the previous gap-one
attack.

## 5. Right boundary: Cramer's rule gives an explicit-unit denominator

Now set

\[
M:=M_{m,r},\qquad K:=K_{m,r},\qquad u:=b_{r-1}.
\]

At the target,

\[
B_r=\binom0u.
\]

Applying (2.2) from \(r\) to \(m\) gives

\[
B_m=MB_r=uMe_2,
\]

and

\[
J_m=K B_r+M J_r=uKe_2+M J_r.
\]

Hence, with

\[
\boxed{R:=J_m-uKe_2,}
\tag{5.1}
\]

we have simply

\[
\boxed{M J_r=R.}
\tag{5.2}
\]

Write the columns of \(M\) as

\[
a:=Me_1,\qquad v:=Me_2.
\]

Then

\[
\delta:=\det(a,v)=\det M=\left(\frac r m\right)^3.
\]

Cramer's rule applied to (5.2) gives

\[
D_r=\frac{\det(R,v)}{\det(a,v)}.
\]

Thus, defining

\[
\boxed{A_{r,m}:=\det(R,v),}
\tag{5.3}
\]

we obtain (T1):

\[
\boxed{\delta D_r=A_{r,m}.}
\]

The crucial difference from \(D_r=N_r/(r^3b_{r-1})\) is that the denominator is now
\(\delta=(r/m)^3\), an explicit transfer determinant.  The canonical values enter only
in the boundary numerator \(A\).

For \(r=0\), no transfer inversion is needed: the canonical initial condition is
\(D_0=0\), while \(\gamma\) is a unit, so \(Q(D_0)=\gamma\ne0\) immediately.  Hence the
interesting generic case is \(1\le r<m\), where \(\delta\) is a unit.

## 6. Collapse of the right numerator to an endpoint/Green Casoratian

Since

\[
v=Me_2=\frac1u\binom{b_m}{b_{m-1}},
\]

and \(Ke_2=v'(0)/2\) for the fixed-boundary shifted column, (5.3) becomes

\[
A_{r,m}
=\det(J_m,v)-\frac u2\det(v',v).
\]

The first determinant is explicit from (4.3):

\[
\det(J_m,v)
=\frac{3b_m(b_m-b_{m-1})}{u}.
\]

Therefore

\[
\boxed{
A_{r,m}
=\frac{3b_m(b_m-b_{m-1})}{b_{r-1}}
+\frac{b_{r-1}}2\det(v,v').
}
\tag{6.1}
\]

This is already a sharp endpoint/Casoratian formula.

It can be written entirely in the pushed restart Green kernel of
`gap_kernel_green.tex`.  Put

\[
g:=m-r,
\]

and recall \(V_{-1}(a)=0,V_0(a)=1\).  The first homogeneous column is

\[
\boxed{
a=
\binom{V_g(r)}{V_{g-1}(r)}.}
\tag{6.2}
\]

The second fixed-boundary column is

\[
\boxed{
v=
-\left(\frac r{r+1}\right)^3
\binom{V_{g-1}(r+1)}{V_{g-2}(r+1)}.}
\tag{6.3}
\]

For the common shift \(x\), the exact formula is

\[
v(x)=
-\left(\frac{r+x}{r+1+x}\right)^3
\binom{V_{g-1}(r+1+x)}{V_{g-2}(r+1+x)}.
\]

The scalar prefactor drops out of the self-Casoratian \(\det(v,v')\).  Hence (6.1)
becomes

\[
\boxed{
\begin{aligned}
A_{r,m}
={}&\frac{3b_m(b_m-b_{m-1})}{b_{r-1}}\\
&+\frac{b_{r-1}r^6}{2(r+1)^6}
\Bigl[
V_{g-1}(a)V'_{g-2}(a)
-V_{g-2}(a)V'_{g-1}(a)
\Bigr]_{a=r+1}.
\end{aligned}
}
\tag{6.4}
\]

This is the sharpest source-free formula from the transfer attack: one endpoint term plus
one derivative Casoratian of two adjacent restart Green functions.  There is no sum over
\(j<r\).

For fixed gap \(g\), the indices \(g-1,g-2\) are fixed.  Therefore (6.4) has bounded
transfer complexity as \(p\) varies.  This is the concrete advantage of the right-boundary
form over the left variation-of-parameters numerator.

### Gap-one sanity check

If \(g=1\), then \((V_{g-1},V_{g-2})=(V_0,V_{-1})=(1,0)\), so the derivative
Casoratian vanishes.  Since \(b_{m-1}=0\),

\[
A_{m-1,m}=\frac{3b_m^2}{b_{m-2}}.
\]

The homogeneous recurrence at the zero gives

\[
b_m=-\left(\frac{m-1}{m}\right)^3b_{m-2}=-\delta b_{m-2},
\]

so

\[
A_{m-1,m}=-3\delta b_m=\delta D_{m-1},
\]

recovering \(D_{m-1}=-3b_m\) exactly.

## 8. Eliminate the jet against the quadratic gate

Let

\[
Q(X)=\alpha X^2+\beta X+\gamma.
\]

Because \(D_r=A/\delta\) and \(\delta\) is a unit,

\[
Q(D_r)=0
\iff
\delta^2Q(A/\delta)=0.
\]

Therefore

\[
\boxed{
\mathscr B_{r,m}
:=\alpha A^2+\beta\delta A+\gamma\delta^2
}
\tag{8.1}
\]

is the exact D-free boundary obstruction.

Equivalently,

\[
\boxed{
\mathscr B_{r,m}
=\operatorname{Res}_X\bigl(Q(X),\delta X-A\bigr).
}
\tag{8.2}
\]

This is necessarily equivalent to the original gate as a *vanishing condition*; any exact
elimination must be.  What is new is the coordinate being eliminated against it:
\(A\) is a right-boundary transfer/Casoratian minor with explicit denominator \(\delta\),
not the old left source sum \(N_r\) with denominator \(h_r=r^3b_{r-1}\).

For an all-prime proof, the smaller target is now simply

\[
\boxed{\mathscr B_{r,m}\ne0.}
\tag{8.3}
\]

## 9. Square discriminant: two linear transfer minors

Assume

\[
\Delta=\beta^2-4\alpha\gamma=s^2,
\qquad \alpha\ne0.
\]

Define

\[
\Xi:=2\alpha A+\beta\delta.
\]

A direct expansion gives the norm identity

\[
\boxed{
\Xi^2-\delta^2\Delta
=4\alpha\mathscr B_{r,m}.
}
\tag{9.1}
\]

Hence

\[
\boxed{
4\alpha\mathscr B_{r,m}
=(\Xi-\delta s)(\Xi+\delta s).
}
\tag{9.2}
\]

The two candidate roots are

\[
\rho_\pm=\frac{-\beta\pm s}{2\alpha}.
\]

Since \(D_r=A/\delta\),

\[
D_r=\rho_\pm
\iff
2\alpha A+(\beta\mp s)\delta=0.
\]

Set

\[
\boxed{
\Lambda_\pm:=2\alpha A+(\beta\mp s)\delta.
}
\tag{9.3}
\]

Now use \(A=\det(R,v)\) and \(\delta=\det(a,v)\):

\[
\boxed{
\Lambda_\pm
=\det\!\left(
2\alpha R+(\beta\mp s)a,\;v
\right).
}
\tag{9.4}
\]

This is the cleanest square-branch transfer interpretation I find.

A hypothetical root says that the vector

\[
2\alpha R+(\beta\mp s)a
\]

is collinear with \(v\).  Since \(a,v\) form a basis with determinant
\(\delta\ne0\), there is no *formal* linear-algebra contradiction: any prescribed Cramer
coordinate can produce such a collinearity.  The actual arithmetic content must therefore
be that the Q1--Q7 values of \(\alpha,\beta,s\) avoid these two special boundary slopes.

Thus the smallest square-branch lemma is

\[
\boxed{
\det\!\left(
2\alpha R+(\beta-s)a,v
\right)\ne0,
\qquad
\det\!\left(
2\alpha R+(\beta+s)a,v
\right)\ne0.
}
\tag{9.5}
\]

No target jet occurs in (9.5).

## 12. Why transfer/Casoratian alone cannot produce the contradiction

The obstruction (T2) is as far as the *generic* transfer identities go.

Indeed, because \(\delta\ne0\), the homogeneous columns \(a,v\) form a basis.  Equation
(5.2) says

\[
R=D_r a+D_{r-1}v.
\]

Therefore (9.4) is identically

\[
\Lambda_\pm
=\delta\,(2\alpha D_r+\beta\mp s).
\]

Nothing in the determinant identity \(\det(a,v)=\delta\) prohibits the coefficient of
\(a\) from taking either special value.  The Casoratian supplies invertibility; it does
not supply an order or a sign in \(\mathbf F_p\).

More abstractly, after the canonical transfer orbit has fixed some unit \(d=D_r\), the
formal system consisting only of

- the Apéry transfer equations,
- the singleton zero,
- the Casoratian determinant,
- canonical initial data, and
- “there is a quadratic with unit constant term”

is consistent with a gate having \(d\) as a root.  The transfer equations contain no
relation tying the quadratic coefficients to the orbit.  Thus a proof by homogeneous
transfer algebra alone is impossible; the special Q1--Q7 definitions of
\(\alpha,\beta,\gamma\) are essential.

This is not merely philosophical.  The two supplied controls already show that there is
no simple character obstruction coming from the transfer determinant: both discriminants
split, yet the boundary Cramer coordinates simply land away from the two roots.

## 13. The smaller all-prime lemma to attack next

The old target was a long left source sum followed by a quadratic substitution.  The new
target can be stated without \(D_r,N_r,h_r\):

> **Boundary-minor lemma.**  For every canonical unique simple noncentral singleton
> \(1\le r<m\), let \(a,v,R\) be the right transfer columns defined above.  Then
> \[
> \operatorname{Res}_X
> \left(
> \alpha X^2+\beta X+\gamma,
> \det(a,v)X-\det(R,v)
> \right)\ne0.
> \]

On the square branch \(\Delta=s^2\), this is equivalent to the pair

\[
\boxed{
\det\!\left(2\alpha R+(\beta-s)a,v\right)\ne0,
\qquad
\det\!\left(2\alpha R+(\beta+s)a,v\right)\ne0.
}
\tag{13.1}
\]

Using (6.2)--(6.4), every vector in (13.1) is an explicit combination of:

- \(b_{r-1}\), \(b_{m-1}\), \(b_m\);
- the fixed-gap Green functions \(V_g(r),V_{g-1}(r)\);
- \(V_{g-1}(r+1),V_{g-2}(r+1)\) and their parameter derivatives; and
- the value-only adjoint coefficients \(\alpha,\beta\) (plus one choice of \(s\)).

For fixed \(g=m-r\), this is a bounded-degree/bounded-order object.  That is the main
reason this resultant is potentially more useful than \(\Theta\): a fixed-gap proof can
now be attacked symbolically with the restart recurrence instead of carrying a source sum
of length \(r\).

A minimal exact verifier for an existing square-record bank should compute the transfer
minor **without using `D`**, then compare only afterward:

```sage
# F = GF(p); assume 1 <= r < m and b[r] == 0.
M = identity_matrix(F, 2)
K = zero_matrix(F, 2)
for j in range(r, m):
    T = Tj(j)
    S = half_dTj(j)
    K = S*M + T*K
    M = T*M

u = F(b[r-1])
Jm = vector(F, [0, 3*(b[m-1]-b[m])])
e2 = vector(F, [0, 1])
a = M*vector(F, [1, 0])
v = M*e2
R = Jm - u*(K*e2)

delta = M.det()
A = matrix(F, [[R[0], v[0]], [R[1], v[1]]]).det()
assert delta == (F(r)/F(m))^3

# Only here, as a regression check, compare with the separately computed jet.
assert A == delta*D

boundary_resultant = alpha*A^2 + beta*delta*A + gamma*delta^2
assert boundary_resultant == delta^2*(alpha*D^2 + beta*D + gamma)

if Delta.is_square() and alpha != 0:
    s = Delta.sqrt()
    lam_plus  = 2*alpha*A + (beta-s)*delta
    lam_minus = 2*alpha*A + (beta+s)*delta
    assert lam_plus*lam_minus == 4*alpha*boundary_resultant
```

For the two locks the expected transfer-only outputs are

```text
p=17 r=3  delta=5  A=11  boundary_resultant=4   branch_minors={8,11}
p=31 r=8  delta=27 A=8   boundary_resultant=19  branch_minors={10,15}
```

The proof target should be the nonvanishing of these boundary minors, not another
recognition formula for the two roots.

## Final assessment

The augmented transfer attack does not magically contradict the quadratic gate, but it
does give a cleaner and more local obstruction than the old \(\Theta\) clearing:

\[
\boxed{
D_r
=6c_r+\kappa_r
=\frac{A_{r,m}}{(r/m)^3},
}
\]

with

\[
\boxed{
A_{r,m}
=\frac{3b_m(b_m-b_{m-1})}{b_{r-1}}
+\frac{b_{r-1}r^6}{2(r+1)^6}
\left(
V_{g-1}V'_{g-2}-V_{g-2}V'_{g-1}
\right)_{a=r+1}.
}
\]

The square-branch obstruction is the pair of rank-one failures

\[
\boxed{
\det\!\left(2\alpha R+(\beta\mp\sqrt\Delta)a,v\right)\ne0.
}
\]

That is the smallest new all-prime lemma I can isolate from the exact transfer and
Casoratian structure without smuggling back the source numerator.  It passes both
\(p=17,r=3\) and \(p=31,r=8\) controls.  A universal proof must now exploit the actual
value-only Q1--Q7 formulas for \(\alpha,\beta,\gamma\); transfer invertibility and
singleton simplicity alone are insufficient.
