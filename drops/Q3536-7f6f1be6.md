# P3.2 — literature search for an FC-28 analogue

## Verdict

There **is** a very close precedent for the *mechanism* FC-28 needs, but I did **not** find a published construction that already gives the full FC-28 statement for a moving Apéry-zero-conditioned set of primes.

The closest literature object is not the ordinary Apéry Casoratian. It is the **Krattenthaler–Rivoal denominator-conjecture machinery**, especially Theorems 3–5 of

> C. Krattenthaler and T. Rivoal, *Hypergéométrie et fonction zêta de Riemann*, Memoirs AMS **186** (2007), no. 875, DOI 10.1090/memo/0875, arXiv:math/0311114.

Two ingredients in that memoir line up strikingly with FC-28:

1. an Andrews single-sum-to-multiple-sum transformation exposes a hidden factor **before denominator clearing**, so one fewer derivative/lcm factor is needed;
2. after the transformation, elementary hypergeometric “bricks” make an explicit **moving product of primes divide the resulting characteristic-zero coefficient**.

That is almost exactly the architecture “cancel the first-copy poles first, then clear denominators.”

There is a second construction which supplies the other half of what FC-28 needs: the **Fischler–Sprang–Zudilin generalized-Vandermonde elimination** chooses one set of prime-independent integer coefficients that kills prescribed nuisance coordinates while proving that one desired coordinate survives. This is the best analogue of the *cross-slope combination/nonvanishing* part of FC-28.

So the most promising literature blueprint is a hybrid:

```text
Krattenthaler–Rivoal:
    hypergeometric transform + arithmetic bricks
    => hidden divisibility before global clearing

Fischler–Sprang–Zudilin:
    generalized Vandermonde / Schur determinant
    => prime-independent elimination coefficients + nonvanishing

FC-28 would need:
    the same two devices, but with the extra prime factor activated by
    p | b_{m-6p}, not merely by factorial/floor geometry.
```

That last condition is the genuinely new part. I found no theorem in the cited literature that produces a subexponential characteristic-zero integer divisible **exactly because a moving Apéry coefficient vanishes modulo p**.

There is also one important correction to the wording of the question. If “q=6 core primorial” means the product of **all** q=6 core candidate primes, then an `exp(o(m))` nonzero carrier is impossible: the campaign already has

\[
\log \Pi_6(m)=\frac{m}{42}+o(m)
\]

(up to the current window error). The FC-28 carrier must be divisible by the **valuation-one target radical**

\[
R_6^{(1)}(m,H)
 =\prod_{\substack{p\text{ q=6 core}\\v_p(b_{m-6p})=1}}p,
\]

while remaining a unit with respect to the *unwanted* universal q=6 clearing factors. This selectivity is precisely why a literal Krattenthaler–Rivoal prime-product factor is not by itself enough.

# 2. The closest precedent: Krattenthaler–Rivoal’s hidden denominator gain

Write

\[
d_n=\operatorname{lcm}(1,2,\ldots,n).
\]

Krattenthaler–Rivoal study hypergeometric linear forms with rational coefficients
`p_{l,n}((-1)^A)` and `p_{0,C,n}((-1)^A)`. A direct partial-fraction analysis gives the expected lcm powers. Their first “denominator conjecture” theorem improves the naive power by **one full copy of `d_n`**:

\[
\boxed{
 d_n^{A-l-1}p_{l,n}((-1)^A)\in\mathbb Z
}
\qquad(1\le l\le A),
\tag{2.1}
\]

and

\[
\boxed{
2d_n^{A+C-1}p_{0,C,n}((-1)^A)\in\mathbb Z.
}
\tag{2.2}
\]

The key point is *how* this gain occurs. Their hypergeometric identity transforms the original one-dimensional expression into a multiple sum of the form

\[
\varepsilon\,\Sigma(\varepsilon),
\]

where the summands of `Sigma` are essentially products of binomial coefficients / elementary bricks. The original coefficient would require `A-l` derivatives at `epsilon=0`. After exposing the explicit factor `epsilon`, the transformed expression requires only

\[
A-l-1
\]

derivatives. Each derivative is what costs an lcm factor in the elementary-brick integrality lemma. Thus one lcm factor disappears **before** denominator clearing.

This is the cleanest literature analogue I found to “two simple poles must cancel before clearing them.” It is not an a posteriori gcd accident; the improved denominator is visible because the representation has been desingularized first.

### Why this is very close to FC-28

The current FC-28 obstruction says that separate backward transport sees simple factors `p` and `2p`; if one clears each independently, the full q=6 primorial comes back. What is needed is a representation in which the coupled object has already lost those poles before any common denominator is introduced.

Krattenthaler–Rivoal do exactly this structurally:

```text
bad representation:
    derivative order r
    -> lcm^r clearing

hypergeometric transformation:
    explicit vanishing factor epsilon appears

transformed representation:
    derivative order r-1
    -> lcm^(r-1) clearing
```

For FC-28 the hoped-for analogue is

```text
separate slope-4 / slope-7 transport:
    simple p-poles
    -> universal q=6 primorial if cleared separately

unknown cross-slope transformation:
    cancel the two first-copy residues internally

transformed cross-slope object:
    no target-p denominator
    -> only short/core-unit clearing remains.
```

That is a genuine structural match, not just an analogy to “Padé approximations have denominators.”

# 3. Even closer on divisibility: their explicit prime-product factor Phi

Krattenthaler–Rivoal also prove something unusually close to the desired carrier divisibility.

They define, in one of the uniform versions,

\[
\widetilde\Phi_n
=
\prod_{\substack{p<n\text{ prime}\\\{n/p\}\in[2/3,1)}}p.
\tag{3.1}
\]

Their Theorem 5 proves, for `r=1`,

\[
\boxed{
\widetilde\Phi_n^{-B+1}
 d_n^{A-l-1}p_{l,n}((-1)^A)\in\mathbb Z,
}
\tag{3.2}
\]

and

\[
\boxed{
2\widetilde\Phi_n^{-B+1}
 d_n^{A+C-1}p_{0,C,n}((-1)^A)\in\mathbb Z.
}
\tag{3.3}
\]

Equivalently, once the ordinary lcm normalization has made the coefficient integral,

\[
\widetilde\Phi_n^{B-1}
\mid d_n^{A-l-1}p_{l,n}((-1)^A)
\]

(and similarly for the constant coefficient, up to the harmless factor 2).

There is an even more transparent special case. Their `Phi_n` satisfies a lemma of the form

\[
\Phi_n\mid
\binom{n+j}{n}\binom{2n-j}{n}
\qquad(0\le j\le n),
\tag{3.4}
\]

because a direct p-adic floor-function calculation gives one unit of valuation whenever
`{n/p} in [2/3,1)`. They rewrite their coefficient `u_n` as

\[
u_n=
\sum_{j=0}^{n}
\binom{n+j}{n}\binom{2n-j}{n}C_{j,n},
\qquad C_{j,n}\in\mathbb Z,
\tag{3.5}
\]

so the prime product divides **every summand** and hence `u_n` itself.

This is very close in formal shape to FC-28:

\[
\text{one prime-independent integer }U_n,
\qquad
\prod_{p\in S_n}p\mid U_n.
\]

The decisive difference is the definition of the prime set. In (3.1)–(3.5), membership in `S_n` is determined by **factorial/floor geometry**, such as a condition on `{n/p}`. In FC-28, membership is determined by the arithmetic condition

\[
p\mid b_{m-6p}.
\tag{3.6}
\]

A factorial brick cannot see (3.6) by itself.

Indeed, this explains the project’s primorial obstruction beautifully. If one imported a brick that gave an extra factor for **every** q=6 prime merely because `m/p in [6,7)`, it would produce the full q=6 core primorial and therefore linear logarithmic height. FC-28 needs an **Apéry-decorated brick**: the extra factor has to switch on only when the one-digit Apéry residue in (3.6) vanishes.

So Krattenthaler–Rivoal contain the right *technology*, but not the target-selective input.

# 4. The Apéry/Ball/Zudilin “representation miracle” is also directly relevant

Zudilin’s *An elementary proof of Apéry’s theorem* makes another point that is almost a slogan for FC-28.

Let `D_n=lcm(1,...,n)`. Nesterenko’s rational-function representation gives

\[
F_n=u_n\zeta(3)-v_n,
\qquad
u_n\in\mathbb Z,
\qquad
D_n^3v_n\in\mathbb Z.
\tag{4.1}
\]

For Ball’s very-well-poised hypergeometric form, the arithmetic visible directly from the series is weaker:

\[
D_n\widetilde u_n\in\mathbb Z,
\qquad
D_n^4\widetilde v_n\in\mathbb Z.
\tag{4.2}
\]

Zudilin explicitly notes Rivoal’s question of proving the stronger

\[
\widetilde u_n\in\mathbb Z,
\qquad
D_n^3\widetilde v_n\in\mathbb Z
\tag{4.3}
\]

without returning to Apéry’s representation. A specialization of Bailey’s very-well-poised `7F6` identity identifies Ball’s series with the Apéry/Nesterenko one, thereby explaining why the better arithmetic is really present.

This is a second very close FC-28 lesson:

> A representation may display a spurious extra denominator. The correct hypergeometric transformation can show that the denominator was never intrinsic to the object.

That is exactly what the first-copy problem is asking for. Separate slope transport displays a `p^{-1}` loss. FC-28 asks for a coupled representation proving that this apparent pole is removable in the **right target-sensitive combination**.

I would therefore search for FC-28 first as a **Bailey/Whipple/Andrews-style transformation identity**, not as a stronger estimate on the already-cleared determinant.

# 5. Ball–Rivoal–Zudilin well-poised symmetry: good for killing coordinates, not yet for target primes

The Ball–Rivoal and Zudilin constructions use well-poised rational/hypergeometric functions with involutive symmetries such as

\[
R(-n-t)=\pm R(t).
\]

After partial fractions these symmetries force entire parity classes of zeta coefficients to vanish. Zudilin’s *Well-poised hypergeometric service for diophantine problems of zeta values* emphasizes that well-poised structure produces both:

- low-order Apéry-like recurrences;
- unexpectedly strong arithmetic and permutation-group symmetries.

This is conceptually close to cross-slope desingularization: one does not cancel individual terms prime by prime; one chooses an ambient hypergeometric object whose **global symmetry makes the offending coordinate disappear identically**.

But again the symmetry is characteristic-zero and uniform. It kills a fixed analytic coordinate (for example all even zeta values), not a moving coordinate selected by `p | b_{m-6p}`.

Thus the well-poised literature suggests *where to look for the identity*, but does not supply the target-selectivity theorem.

# 6. Higher Padé minors: there is an exact rank obstruction for the original recurrence

For the specific question about

\[
D_n=a_nb_{n+1}-a_{n+1}b_n
=\frac{\text{constant}}{(n+1)^3},
\]

the answer is sharp.

The Apéry recurrence is homogeneous of order two. Its solution space over the constant field is two-dimensional. Therefore

\[
\wedge^2 V
\]

is one-dimensional and is exactly the Casoratian line, while

\[
\boxed{\wedge^3V=0.}
\tag{6.1}
\]

Consequently, any `3 x 3` Casoratian made from **three genuine solutions of the same second-order recurrence** vanishes identically. There is no new “third Padé minor” hiding in the homogeneous Apéry solution space. Any pairwise determinant is only a scalar multiple of the same Abel/Casoratian law.

This agrees with the campaign’s earlier companion audit: another homogeneous companion cannot provide a genuinely independent gap/carrier coordinate.

### How the literature obtains meaningful higher minors

It enlarges the system.

Sorokin’s Hermite–Padé constructions for `zeta(3)` approximate a **vector of polylogarithmic/Markov functions** rather than asking for a third solution of the Apéry recurrence. The relevant space then has rank greater than two, so larger determinants and normality conditions become meaningful.

The paper

> V. N. Sorokin, *Hermite–Padé approximations for Nikishin systems and the irrationality of zeta(3)*, Russian Math. Surveys 49 (1994), 176–177, DOI 10.1070/RM1994v049n02ABEH002229

shows that Apéry-type irrationality can indeed be recast as a Hermite–Padé problem, and Sorokin found several other Hermite–Padé constructions leading to `zeta(3)` irrationality.

The more recent Arvesú–Soria-Lorente work on families of rational approximants to `zeta(3)` similarly uses simultaneous approximation and Casorati determinants to derive parameterized second-order recurrences.

But this literature contains a warning especially relevant here: one can have excellent analytic convergence while the extra denominator required to make the coefficients integral destroys the irrationality estimate. In other words,

```text
good Padé approximation
    !=
good arithmetic carrier.
```

That is exactly the distinction FC-28 is confronting.

So if a “higher minor” route is pursued, the system must be enlarged by something genuinely new—parameter derivatives/jets, multiple hypergeometric forms, or multiple functions—not by adding another solution of the old order-two recurrence.

# 7. Fischler–Sprang–Zudilin: the best determinant analogue for prime-independent coefficients

The 2019 paper

> S. Fischler, J. Sprang, W. Zudilin, *Many odd zeta values are irrational*, Compositio Math. 155 (2019), 938–952, DOI 10.1112/S0010437X1900722X, arXiv:1803.08905

contains an elimination mechanism that is highly relevant to FC-28’s **nonvanishing and coefficient-choice** problem.

They construct a family of related linear forms indexed by divisors `d` of an auxiliary integer `D`. The coefficient of `zeta(i)` depends on `d` in the simple form `d^i`. To eliminate prescribed coordinates, they use the generalized Vandermonde matrix

\[
[d^{i_j}]_{d,j}.
\]

A Schur-polynomial/generalized-Vandermonde lemma proves that this determinant is nonzero (indeed positive for ordered positive nodes). Therefore there are integers `w_d`, chosen **once in characteristic zero**, with

\[
\sum_{d\mid D}w_dd^{i_j}=0
\qquad(j=1,\ldots,t)
\tag{7.1}
\]

but

\[
\boxed{
\sum_{d\mid D}w_dd\ne0.
}
\tag{7.2}
\]

The combined form

\[
\widetilde r_n=
\sum_{d\mid D}w_d\widehat r_{n,d}
\tag{7.3}
\]

therefore kills all nuisance coordinates while preserving one nonzero direction.

This is very close to the algebraic shape one would like for FC-28:

```text
several related cross-slope forms
      + one fixed integral null-vector for nuisance boundary/pole modes
      + determinant proving desired mode survives
      = prime-independent nonzero combination.
```

But FSZ does not supply the required divisibility. Its determinant tells us **which linear combination is nonzero**; it does not say that every valuation-one q=6 target prime divides that combination.

This is why I view FSZ as complementary to Krattenthaler–Rivoal:

- K–R supplies the arithmetic-divisibility technology;
- FSZ supplies the prime-independent elimination/nonvanishing technology.

# 8. Nesterenko’s differential-equation/G-function route

Nesterenko’s *A few remarks on zeta(3)* constructs rational approximations through Meijer `G`-functions and recurrences, and his 2003 paper *Integral identities and constructions of approximations to zeta-values* gives a general Barnes-integral framework for linear forms in zeta values.

These constructions are very useful for:

- producing a differential/difference system;
- proving asymptotics and nonvanishing;
- transforming between integral and hypergeometric representations.

The elementary rational “bricks” later used by Zudilin and Krattenthaler–Rivoal are explicitly attributed to Nesterenko.

For FC-28, however, the differential equation by itself is not the missing ingredient. The current project already has the exact order-two recurrence and exact sampled transfer. What is missing is **integral structure at the singular first copy**. The part of Nesterenko’s technology that looks relevant is therefore the *brick/integral representation*, not simply the existence of another differential equation.

# 9. Dwork/supercongruence literature: a local analogue, not the global carrier

There is also a p-adic line of literature that is close to the *local* half of FC-28.

For example, Apéry numbers satisfy the Beukers–Coster/Gessel-type supercongruences

\[
A(mp^r)\equiv A(mp^{r-1})\pmod{p^{3r}},
\qquad p\ge5,
\]

and Straub proved multivariate extensions by viewing Apéry numbers as diagonal coefficients of a rational function:

> A. Straub, *Multivariate Apéry numbers and supercongruences of rational functions*, Algebra & Number Theory 8 (2014), 1985–2008, DOI 10.2140/ant.2014.8.1985, arXiv:1401.0854.

Dwork-crystal methods give a conceptual framework for such supercongruences.

This is relevant because FC-28’s first-Witt coordinate is also a first-order p-adic phenomenon. But Dwork congruences are **prime-by-prime**. They naturally prove

\[
\forall p:\ \text{a strong p-adic identity},
\]

not

\[
\exists E_m\in\mathbb Z\setminus\{0\}
\quad\forall p\in\mathcal T_m:\ p\mid E_m,
\qquad \log|E_m|=o(m).
\]

So Dwork can plausibly identify the correct local residue that a transformed brick must carry; it does not by itself solve the characteristic-zero globalization/height problem.

# 10. What I would try next: an “Apéry-decorated Krattenthaler–Rivoal brick”

The literature suggests a fairly specific FC-28 experiment.

The q=6 target condition is

\[
p\mid b_j,
\qquad j=m-6p,
\]

and

\[
b_j=
\sum_{k=0}^{j}
\binom jk^2\binom{j+k}{k}^2
\]

is itself a terminating hypergeometric object (`4F3` form). The aligned slope-4/slope-7 legal rows already specialize modulo a target prime to fixed multiples of this same `b_j`. Thus the target arithmetic is already present in the **numerator data**; it should not be reintroduced by a p-dependent coefficient.

I would look for a characteristic-zero identity of the following form.

### Step A — keep the two slopes together before clearing

Represent the aligned cross-slope first-Witt object (or a small finite family of contiguous versions of it) as a hypergeometric sum with one deformation parameter for each first-copy singular factor.

Schematically,

\[
L_{m,H}(\varepsilon_4,\varepsilon_7)
=\sum_k R_{m,H}(k;\varepsilon_4,\varepsilon_7).
\]

Do **not** first write separate rational slope-4 and slope-7 antidifferences.

### Step B — search for an Andrews/Bailey/Whipple transform with an explicit vanishing factor

The ideal identity would be

\[
L_{m,H}(\varepsilon_4,\varepsilon_7)
=\Delta(\varepsilon_4,\varepsilon_7)
\,\Sigma_{m,H}(\varepsilon_4,\varepsilon_7),
\tag{10.1}
\]

where `Delta` vanishes on the aligned specialization that corresponds to the two first-copy residues.

This is the direct analogue of Krattenthaler–Rivoal’s

\[
\varepsilon\Sigma(\varepsilon).
\]

If `Delta` removes the two simple first-copy poles, the final coefficient extraction may cost one fewer denominator factor on each singular direction.

### Step C — the new ingredient: target-selective brick valuation

A pure factorial brick will see only the quotient-six geometry and therefore risks forcing **every** q=6 prime. That reproduces the full primorial and is useless.

The needed transformed summand has to retain an Apéry factor whose target specialization is

\[
b_{m-6p}\pmod p
\]

(or the first-Witt quotient `b_j/p` after the p factor has been exposed). In other words, one wants a brick valuation theorem of the schematic form

\[
v_p(\mathcal B_{m,H})\ge1
\quad\text{when}\quad
p\text{ is q=6 and }b_{m-6p}\equiv0\pmod p,
\tag{10.2}
\]

without the same forced valuation for non-target q=6 primes.

That is the piece I did **not** find in the literature.

### Step D — use a small generalized Vandermonde if boundary modes remain

If the transformed construction yields finitely many related forms

\[
L^{(1)},\ldots,L^{(t)}
\]

whose nuisance first-copy/boundary coordinates depend algebraically on a small parameter, use an FSZ-style generalized Vandermonde to find integers `w_i` such that

\[
\sum_iw_i(\text{nuisance coordinate})=0,
\]

while a determinant proves

\[
\sum_iw_i(\text{target coordinate})\ne0.
\]

This would provide the prime-independent `u,E` side of FC-28 without p-dependent choices.

### Step E — height audit at the *evaluated* level

The classical K–R/Ball–Rivoal constructions are allowed exponential-size factorial products because their goal is an irrationality inequality with a favorable competing exponential decay. FC-28 is stricter: the final carrier itself must satisfy

\[
\log|E_{m,H}|=o(m).
\]

So only the **mechanism** should be imported. The actual FC-28 transform must live on the current mesoscopic/short aligned window, giving for example

\[
\log|E_{m,H}|=O(H\log m)+m^{o(1)},
\]

with `H=o(m/log m)` (or whatever exact campaign window is used), rather than using factorials of length `Theta(m)`.

# 11. What not to expect from “higher minors”

A useful way to rank possible routes is:

1. **3x3 determinant of homogeneous Apéry solutions:** impossible/new information = none, because the recurrence has rank 2.
2. **determinants of several parameterized Hermite–Padé forms:** mathematically real; good for eliminating coordinates and proving nonvanishing.
3. **hypergeometric transformation plus arithmetic bricks:** mathematically real; this is where hidden denominator savings and explicit prime products have actually been proved.
4. **Dwork/Frobenius congruence:** strong local p-adic information, but still needs a characteristic-zero globalization.

Thus the best search keyword is not “higher Apéry Wronskian.” It is closer to

```text
Andrews identity + denominator conjecture + elementary bricks
+ well-poised transformation + Hermite-Padé elimination
```

with the q=6 cross-slope object inserted as the hypergeometric input.

# 12. Direct answer to the question

### Is there a known construction in Zudilin / Krattenthaler–Rivoal / Ball–Rivoal / Nesterenko that already solves FC-28?

**No published one that I found.** Their divisibility gains are controlled by fixed hypergeometric/factorial geometry, not by a moving condition `p | b_{m-6p}`; and their height scales are normally exponential in the main hypergeometric parameter.

### Is there a known construction with essentially the same *shape*?

**Yes. Krattenthaler–Rivoal Theorems 3–5 are the closest.** They construct characteristic-zero coefficients which, after the usual lcm normalization, are divisible by an explicit moving product of primes, and the gain is proved only after a hypergeometric transformation exposes a hidden cancellation before denominator clearing.

### What is the closest analogue to Apéry’s “integrality miracle”?

**Ball’s form versus the Apéry/Nesterenko form, connected by Bailey’s very-well-poised identity.** The bad representation displays one extra lcm denominator; the transformed/equivalent representation displays the sharper integrality. This is exactly the conceptual pattern FC-28 needs.

### Are higher Padé minors likely to carry the missing arithmetic?

Not inside the original rank-two recurrence: `wedge^3=0`. Higher determinants become meaningful only after enlarging to a Hermite–Padé/direct-sum/jet system. In that enlarged setting, FSZ-type generalized Vandermonde determinants are promising for **prime-independent elimination and nonvanishing**, but a separate K–R-type arithmetic argument is still needed for target divisibility.

### Most relevant construction to import

My ranking is:

```text
1. Krattenthaler–Rivoal 2007, Theorems 3–5 + arithmetic bricks
   Role: hidden denominator cancellation + explicit prime-product divisibility.
   This is the closest FC-28 analogue.

2. Zudilin 2002 / Bailey identity for Ball vs Apéry forms
   Role: representation change removes a spurious lcm denominator.
   This is the closest “first-copy pole was removable all along” analogue.

3. Fischler–Sprang–Zudilin 2019 generalized Vandermonde elimination
   Role: one characteristic-zero integer coefficient vector kills nuisance
   coordinates and a determinant guarantees a surviving nonzero coordinate.

4. Sorokin Hermite–Padé / Nesterenko G-function constructions
   Role: show how to enlarge rank 2 and manufacture genuinely new determinant
   directions; useful for architecture/nonvanishing, not target divisibility.

5. Dwork/Straub Apéry supercongruences
   Role: possible source of the local first-Witt factor; no global small carrier.
```

The concrete new object suggested by the literature is therefore:

\[
\boxed{
\text{a short, cross-slope, Apéry-decorated Andrews/Bailey brick identity}
}
\]

whose transformation cancels the slope-4 and slope-7 first-copy poles **before** denominator clearing, and whose residual numerator reduces to the Apéry target factor `b_{m-6p}`. If a small family of such identities is needed, use a generalized-Vandermonde determinant to eliminate the remaining boundary modes while retaining one nonzero target direction.

That is substantially more specific than “try higher Padé approximants,” and it is the closest literature-supported design I can see for FC-28.
