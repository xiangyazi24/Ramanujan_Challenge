# Q6608: WALL adjudication and FAV/[WALL-geo] literature verdict

## A. Audit adjudication

### A1. [WALL] => row variance

The reduction is valid. The audit objection confuses an operator-norm dual argument with a Hilbert-Schmidt estimate.

Assume

```
for every complex u,v:
 sum_a |nu_{u,v}(a)-W/p|^2 <= C X^eps E_{u,v}.
```

Choose the legal specialization `v_h=1`. Then

```
E_{u,1}=|J| sum_r |u_r|^2.
```

The `a=0` summand is nonnegative, hence

```
|sum_r u_r z_r|^2 <= C X^eps |J| ||u||_2^2,
```

where

```
z_r=d_I(r)-q_I(r)/p.
```

Since this holds for every complex vector `u`, take the supremum over `||u||_2=1`. Complex phases are allowed, so choose `u` proportional to the conjugate phase of `z`. Therefore

```
||z||_2^2 <= C X^eps |J|.
```

No extra factor `|J|` appears. Such a factor would arise if one only knew a bound for a fixed `u` or averaged over `u`; here the quantifier is uniform in `u`.

Only caveat: the displayed `X^eps` must be uniform in the legal specialization. If the hidden constant in the WALL statement depends on `v` or on `|J|`, the inference fails. Under the stated quantifiers, A1 is correct.

### A2. [NEAR-WALL_eta] substitution

The audit objection is also incorrect for the stated containment argument.

For a dyadic interval

```
I=(H,2H]
```

partition into boxes of length `D`. The same-box contribution consists of pairs

```
H < h < k <= 2H,
k-h < D.
```

Therefore, ignoring the last shorter box only enlarges the set, and

```
L <= sum_{d<D} sum_{H<h<=2H-d} J_p(h,h+d)
   = K_p(H,D).
```

No weighted renewal localization is needed for this step. It is pure index-set containment.

The resulting estimate is

```
Q_I <= (H/D)K_p(H,D)+(H/D)S_I/2
```

and with

```
K_p(H,D) << H D^(2-eta),
S_I << H^2,
```

one obtains

```
Q_I << H^2 D^(1-eta)+H^3/D.
```

The only possible failure would be if the definition of `Q_I` contains pairs crossing the dyadic boundary while the master proof was applied to `[1,2H]`. For the stated dyadic version, there is no leakage.

# B. FAV and finite-rank lift literature

## B1. Fixed lisse sheaf: what Deligne/Katz actually gives

Let `F` be a fixed geometrically irreducible lisse sheaf on `G_m/F_p`, rank r, conductor c independent of p. Let

```
t(h)=Tr(Frob_{x_h}|F)
```

for a fixed finite-field orbit or a fixed algebraic parametrization.

Deligne's RH (Weil II, Theorem 3.4.1) gives square-root cancellation for complete sums of trace functions:

```
|sum_x alpha(x) t(x)| <= C(F) sqrt(p)
```

for nontrivial geometric components.

Katz's monodromy results (for example *Gauss sums, Kloosterman sums, and monodromy groups*, Annals 1988) compute the geometric group in many examples, converting this into equidistribution.

For a fixed sheaf, a second moment over a parameter interval is typically of the form

```
sum_{h<=H} |t(h)-ET|^2
 = H*Var(T)+O_F(sqrt(p)*poly(log p))
```

when the h-parameter itself is an algebraic family with bounded conductor. For `H<=p`, the error is lower order only when the sheaf is fixed and the parameter family is genuinely lisse.

Therefore:

If the Apery lift existed with:

1. one fixed rank sheaf;
2. conductor bounded independently of h and p;
3. h represented as the orbit of a fixed correspondence;
4. no exceptional invariant subrepresentation;

then GPRV would be a standard vertical equidistribution/second moment statement.

The present obstruction is exactly that no such comparison theorem is known.

## B2. Growing conductor families

Closest tools and failures:

### Kowalski, *The large sieve and its applications*, Ch. 8

The large sieve controls families of Frobenius parameters when the family size and conductor are explicit. The typical quantifier is:

```
sum_over_parameters |sum_trace|^2
```

with averaging over primes or characters.

Failure here:

```
prime p fixed;
h varies;
conductor grows like deg(M_h)~h.
```

The averaging direction is reversed.

### Fouvry-Kowalski-Michel trace function technology

Results such as *Algebraic trace functions over the primes* and the trace-function large sieve handle families where each trace function has controlled conductor and the prime variable is averaged.

Failure:

The Apery problem asks for a single residue characteristic p and a family indexed by h up to p.

### Katz exponential sums / stratification

Katz gives powerful monodromy and stratification results for algebraic families. The missing input is a uniform conductor bound. Here the natural polynomial family has degree and splitting fields growing with h.

### Wan / Adolphson-Sperber

Newton polygon and unit-root methods control p-adic variation in fixed geometric families.

Failure:

They control the p-adic slopes of one family parameter, not the fixed-p distribution of a growing list of independent splitting fields.

Conclusion: no cited theorem matches the quantifier pattern.

# B3. Index Mellin versus t-Frobenius

Closest results:

## Dwork unit-root formulas

Dwork's theory identifies Frobenius eigenvalues through coefficient ratios, e.g.

```
unit root = A(t)/A(t^p)
```

for suitable hypergeometric families.

This is the closest philosophy.

Missing Apery ingredient:

The collision count uses index shifts

```
h -> h+1
```

and gap polynomials `M_h`. The Dwork Frobenius acts on the geometric parameter

```
t -> t^p.
```

The missing theorem is an index-Mellin comparison:

```
M_h roots / C_h
 = trace of K o Phi^h on a fixed finite-rank F-crystal
 + controlled boundary error.
```

## Adolphson-Sperber

They express exponential sums and coefficients through cohomology of fixed Laurent polynomials.

Failure:

The cohomology rank is fixed, but the required h-iterate identification is absent.

## Christol theorem

Christol gives algebraicity/automata of coefficient sequences mod p.

Failure:

The automaton state may grow with p; it does not give bounded-conductor Frobenius statistics.

## Denef-Loeser motivic methods

They package point counts in definable families.

Failure:

They do not provide square-root variance for a triangular family with growing degree.

# B4. Sharp conditional theorem

The clean statement is:

> If there exists a finite-rank overconvergent F-isocrystal T and a correspondence K satisfying P1-P5 below, then GPRV follows from Deligne/Katz vertical trace-function theory.

Required properties:

```
P1. Rank(T) is bounded independently of h and p.

P2. The conductor of T is bounded independently of h.

P3. There exists an index-Mellin comparison:

    C_h-mu_h = Tr(K Phi_p^h | T_p) + e_h,

    sum_{h<=p}|e_h|^2 = O(p).

P4. Phi_p is the same Frobenius operator for all h, not a changing
    Frobenius on M_h splitting fields.

P5. The geometric monodromy has no exceptional invariant piece
    contributing to the centered trace.
```

Then

```
sum_{h<=p}|C_h-mu_h|^2 = O(p)
```

is a standard bounded-conductor second moment.

Thus the wall is not currently "prove cancellation in a huge polynomial family". It is first:

```
construct the bounded-rank lift.
```

After that, existing theory is close to sufficient.

# Final answers

## (a) Least confident step

The least certain step is the claim that bounded-conductor plus a fixed correspondence automatically gives exactly the needed h-range `h<=p` without extra endpoint terms. The fixed-sheaf second moment is standard, but matching the discrete h-iterate to a trace-function parameter uniformly up to the full residue-characteristic range needs careful treatment.

## (b) Shared blind spot

The likely shared blind spot is assuming the polynomial family `M_h` is the primary object. It may be only a sequence of shadows of one finite-rank mixed crystal. If so, attacking the splitting fields individually is the wrong category.

The sharp wall is therefore:

```
Index-Mellin comparison theorem for the Apery rank-4 crystal
        |
        v
bounded-conductor Frobenius realization of all C_h
        |
        v
Deligne/Katz variance machinery gives GPRV.
```

The unresolved theorem is the comparison, not the final variance estimate.
