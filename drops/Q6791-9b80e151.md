# A short real-variable certificate for `P + 2Q + T = 0`

## Verdict

Put

```text
A(x) = log x,
B(x) = log(1-x),
C(x) = log(1+x),

P = integral_0^1 A C^2 / x,
Q = integral_0^1 A B C / x,
T = integral_0^1 B C^2 / x,
R = integral_0^1 A B^2 / x.
```

The clean proof has two independent pieces:

```text
P + 2Q = -(3/4) R,                         (square replacement)
T       =  (3/4) R.                         (cubic replacement)
```

The first is one substitution `u=x^2`.  For the second, introduce only

```text
Jm = integral_0^1 log(t)^3/(1-t) dt,
Jp = integral_0^1 log(t)^3/(1+t) dt.
```

Then purely elementary substitutions give

```text
Jp = (7/8) Jm,
T  = (1/16) Jm,
R  = (1/12) Jm.
```

Therefore `T=(3/4)R`, and hence

```text
P + 2Q + T = 0.
```

No value of `Li_2`, `Li_3`, or `Li_4` occurs.  In fact the proof never needs the numerical value of `Jm` (although `Jm=-6*zeta(4)`).

For the current P2.4 development, the shortest Lean implementation should reuse the already-banked ordinary radial row `R=-zeta(4)/2` and the elementary log-cube moment `Jm=-6*zeta(4)`.  Then only Sections 1--3 below are new.  Section 4 gives a standalone proof of `R=Jm/12` in case a public wrapper for the radial row is not available.

---

## 0. Integrability and endpoint discipline

All integrals below are ordinary improper Lebesgue/interval integrals.

Near `x=0`, use

```text
0 <= log(1+x) <= x,
0 <= -log(1-x) <= 2x             (0 < x <= 1/2),
```

so the kernels of `P,Q,T,R` are bounded respectively by constant multiples of

```text
x*|log x|,  x*|log x|,  x^2,  x*|log x|.
```

Near `x=1`, `log(1+x)` is bounded, `log x=O(1-x)`, and powers of `log(1-x)` are integrable.  The two auxiliary kernels `log(t)^3/(1-t)` and `log(t)^3/(1+t)` are also integrable: at `t=0` this is the standard log moment, and at `t=1`, `log(t)^3/(1-t)=O((1-t)^2)`.

Thus every substitution below can be proved first on compact truncated intervals and then passed to the endpoint by dominated convergence.  No principal value is involved.

---

# 1. Square replacement: `P+2Q=-(3/4)R`

On `0<x<1`,

```text
B(x)+C(x) = log(1-x^2).
```

Hence

```text
R + 2Q + P
 = integral_0^1 log(x) * log(1-x^2)^2 / x dx.
```

Set `u=x^2`.  Then

```text
log x = (1/2) log u,
dx/x  = du/(2u),
log(1-x^2)=log(1-u).
```

Therefore

```text
R + 2Q + P
 = (1/4) integral_0^1 log(u)*log(1-u)^2/u du
 = (1/4)R.
```

Thus

```text
boxed:  P + 2Q = -(3/4)R.                    (1)
```

This is the complete proof of the first half; it is just `ring` after the substitution.

---

# 2. A substitution-only relation between `Jp` and `Jm`

Use the rational identity

```text
1/(1+t) = 1/(1-t) - 2t/(1-t^2).
```

Thus

```text
Jp = Jm - 2M,
M  = integral_0^1 t*log(t)^3/(1-t^2) dt.
```

In `M`, set `u=t^2`.  Since

```text
t dt = du/2,
log t = (1/2)log u,
```

we get

```text
M = (1/16) integral_0^1 log(u)^3/(1-u) du
  = (1/16)Jm.
```

Consequently

```text
boxed:  Jp = (7/8)Jm.                        (2)
```

This proof is preferable in Lean to expanding `1/(1+t)` as an alternating series: it needs only one algebraic rational identity and the monotone map `u=t^2`.

---

# 3. Cubic replacement: `T=Jm/16`

Use the elementary polynomial identity

```text
6 a b^2 = (a+b)^3 + (a-b)^3 - 2a^3.
```

Take

```text
a = B(x)=log(1-x),
b = C(x)=log(1+x).
```

After division by `x` and integration,

```text
6T = Eplus + Eminus - 2Ezero,                 (3)
```

where

```text
Eplus  = integral_0^1 log(1-x^2)^3/x dx,
Eminus = integral_0^1 log((1-x)/(1+x))^3/x dx,
Ezero  = integral_0^1 log(1-x)^3/x dx.
```

Each term is transformed exactly as follows.

### 3.1 The zero term

With `t=1-x`,

```text
Ezero = integral_0^1 log(t)^3/(1-t) dt = Jm.  (4)
```

### 3.2 The plus term

With `t=1-x^2`, one has `dx/x=-dt/(2(1-t))`, and reversal of the endpoints gives

```text
Eplus = (1/2) integral_0^1 log(t)^3/(1-t) dt
      = (1/2)Jm.                              (5)
```

### 3.3 The minus term

With

```text
t = (1-x)/(1+x),
x = (1-t)/(1+t),
-dx/x = 2 dt/(1-t^2)
```

(after accounting for the reversed endpoints),

```text
Eminus
 = 2 integral_0^1 log(t)^3/(1-t^2) dt
 = integral_0^1 log(t)^3/(1-t) dt
   + integral_0^1 log(t)^3/(1+t) dt
 = Jm + Jp.                                  (6)
```

Substituting (4)--(6) into (3), and then using (2), gives

```text
6T = (1/2)Jm + (Jm+Jp) - 2Jm
   = Jp - (1/2)Jm
   = (3/8)Jm.
```

Therefore

```text
boxed:  T = (1/16)Jm.                         (7)
```

This is the shortest elementary evaluation of `T`: one cubic algebra identity and three substitutions.  It is entirely logarithmic.

# 4. Standalone radial lemma: `R=Jm/12`

If the existing P2.4 theorem `R=-zeta(4)/2` is reused, this section can be omitted: the standard log-cube moment gives `Jm=-6*zeta(4)`, hence immediately `R=Jm/12`.

For completeness, here is a self-contained proof that does not evaluate `zeta(4)` and uses only a nonnegative double series.

Set `x=exp(-s)`.  Then

```text
R = - integral_0^infinity s * [-log(1-exp(-s))]^2 ds.     (8)
```

For `s>0`,

```text
-log(1-exp(-s)) = sum_{m>=1} exp(-m s)/m,
```

with nonnegative summands.  Tonelli (or monotone convergence applied to finite partial sums) and

```text
integral_0^infinity s*exp(-a s) ds = 1/a^2
```

give

```text
-R = S := sum_{m,n>=1} 1/[m n (m+n)^2].                 (9)
```

The only arithmetic identity needed is

```text
2/[m n (m+n)^2]
 = 1/(m^2 n^2)
   - 1/[m^2 (m+n)^2]
   - 1/[n^2 (m+n)^2].                                  (10)
```

Let

```text
Z4 = sum_{k>=1} 1/k^4,
U  = sum_{m,n>=1} 1/[m^2 (m+n)^2].
```

Summing (10), using symmetry in `m,n`, yields

```text
2S = (sum_{m>=1}1/m^2)^2 - 2U.                          (11)
```

On the other hand, split the square into its diagonal and its two strict triangles.  The change of variables `k=m+n` identifies one strict triangle with `U`, so

```text
(sum_{m>=1}1/m^2)^2 = Z4 + 2U.                          (12)
```

Equations (11) and (12) give

```text
S = Z4/2,
R = -Z4/2.                                               (13)
```

Finally, the geometric expansion of `1/(1-t)` and the elementary moment

```text
integral_0^1 t^n*log(t)^3 dt = -6/(n+1)^4
```

give

```text
Jm = -6Z4.                                               (14)
```

Combining (13) and (14),

```text
boxed:  R = (1/12)Jm.                                   (15)
```

No multiple-zeta identity is hidden here.  The cancellation is exactly the finite partial-fraction identity (10) plus the diagonal/off-diagonal partition (12).

For reference, explicit primitives for the two scalar moments are

```text
integral t^n log(t)^3 dt
 = t^(n+1) * [
     log(t)^3/(n+1)
     - 3log(t)^2/(n+1)^2
     + 6log(t)/(n+1)^3
     - 6/(n+1)^4
   ],

integral s exp(-a s) ds
 = -exp(-a s) * (s/a + 1/a^2).
```

The endpoint limits are `t^(n+1)|log t|^j -> 0` at `0+` and `exp(-a s)(s+1)->0` at infinity.

# 5. Finish

From (7) and (15),

```text
T = Jm/16 = (3/4)(Jm/12) = (3/4)R.            (16)
```

Together with (1),

```text
P + 2Q + T
 = -(3/4)R + (3/4)R
 = 0.
```

Equivalently,

```text
boxed:
integral_0^1
  [ log(x) log(1+x)^2
    + log(1-x) log(1+x)^2
    + 2 log(x) log(1-x) log(1+x) ] / x dx
= 0.
```

# 6. Lean-oriented implementation order

The shortest implementation in the present repository is:

1. Define `R`, `Jm`, and `Jp` as interval integrals.
2. Reuse the banked radial theorem `R=-zeta(4)/2` (expose a public wrapper if its local declaration remains private).
3. Prove `Jm=-6*zeta(4)` from the already-used geometric/log-moment package, or reuse that endpoint theorem too.
4. Prove `Jp=(7/8)Jm` by the rational identity and `u=t^2`; no alternating series is required.
5. Prove `T=Jm/16` from the cubic identity and the three substitutions in Section 3.
6. Prove `P+2Q=-(3/4)R` from the square substitution in Section 1.
7. Finish by `ring`/`linarith`.
