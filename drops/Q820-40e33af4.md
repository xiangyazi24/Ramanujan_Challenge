# Q820 canonical-cofactor attack audit

## Repository check and verdict

I attempted to inspect the requested proof files under `problems/3.2/research/proofs/`, but the named proof path was not available through the accessible repository snapshot. The audit below therefore treats the stated DD/RR identities as hypotheses and checks the proposed cofactor mechanism algebraically.

Verdict: the canonical-cofactor attack does not close from the current fixed-boundary and first-jet identities alone. The obstruction is not the shared carrier integer; it is the lack of a characteristic-independent cofactor congruence after removing the two prime factors.

## 1. Shared carrier and local formulas

Let

```
h = qd,
ell = p-d,
j=n-qp.
```

The proposed DD edge gives

```
p | b_n,
ell | b_n,
p | D_{q,n},
ell | D_{q,n},
p | B_{q,n},\ell | B_{q,n}.
```

The folded zero locations are separated by the fixed gap h:

```
Z_p = j,
Z_ell = j+h.
```

At characteristic p, the boundary-unit computation isolates the simple zero:

```
b_n = p * U_p * (b_j/p contribution),
```

where `U_p` is a p-adic unit determined by the nonzero factors. The first-jet identity records the derivative/nonvanishing residue class modulo p. The analogous formula at ell is independent:

```
b_n = ell * U_ell * (b_{j+h}/ell contribution).
```

These formulas prove two separate local divisibilities. They do not identify the quotients.

## 2. Why D/(pell), B/(pell) do not automatically eliminate the quotients

Consider

```
C_D = D_{q,n}/(p ell).
```

Reduction modulo p only gives information after dividing by ell modulo p:

```
C_D mod p = (D/ell) * p^{-1}  (formal local expression).
```

The missing datum is the value of the remaining factor at the other characteristic. The p-jet controls the vanishing direction at p; it does not control the ell-quotient.

Likewise modulo ell, the p-side quotient remains free.

The same issue occurs for

```
C_B = B_{q,n}/(p ell).
```

The existence of a common integer carrier does not imply that every DD edge contributes a prime divisor of a fixed characteristic-zero number of small height.

## 3. 2x2 determinant attempt

A determinant built from

```
D, S, B
```

can cancel one local quotient only if there is a proven linear relation between the p-jet and ell-jet evaluations. The current identities give two rows:

```
(p-local value, p-local derivative)
(ell-local value, ell-local derivative)
```

but no characteristic-zero compatibility relation. Therefore the determinant may vanish for one characteristic and not encode the other.

The missing statement would have to be a genuine interpolation/congruence identity, not merely the fact that p and ell divide the same three integers.

## 4. Scoped saturation countermodel

A countermodel preserving the shared carrier is immediate at the level of local constraints.

Choose integers with

```
D = p ell A,
B = p ell B0,
S = p ell S0,
```

and prescribe the p-adic and ell-adic first jets independently:

```
D/p mod p = alpha,
D/ell mod ell = beta,
```

with arbitrary compatible nonzero alpha,beta. The local divisibility and boundary-unit formulas are preserved, but the remaining cofactor can be chosen to avoid divisibility by any fixed small-height integer.

Thus the shared carrier alone cannot yield the required multiplicity collapse.

## 5. RR branch

For RR the folded gap is

```
(q+1)d
```

instead of qd. The same obstruction remains. The two characteristics provide separate local quotients and the canonical carriers do not couple them.

## 6. Weakest missing cofactor congruence

The minimal sufficient missing input is a cross-characteristic congruence of the following type:

```
For every transverse DD edge (p,ell),
Phi(D,S,B)/(p ell) mod p
and
Phi(D,S,B)/(p ell) mod ell
are determined by a single characteristic-zero integer Phi of height exp(o(n)).
```

Equivalently, one needs a canonical cofactor C_n with

```
p | C_n  and  ell | C_n
```

for every fixed-gap DD edge, together with

```
log |C_n| = o(n).
```

That is exactly the missing bridge needed for the n/log^2(n) multiplicity target.

## Conclusion

The canonical-cofactor direction is promising because the common carriers D,S,B are stronger than unrelated local congruences. However, the current boundary-unit and first-jet formulas remain characteristic-local. They do not produce a characteristic-zero cofactor divisible by all edges in a fixed-gap fibre. The first missing lemma is a cross-characteristic cofactor congruence, not another local valuation identity.
