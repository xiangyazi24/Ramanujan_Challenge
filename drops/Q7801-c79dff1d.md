# Exact moment-to-maximum exponents and invariant-tensor bookkeeping

## Verdict

There are **two different exponents** in this discussion, and they should not be conflated.

1. From the factorial-moment hypothesis \((\mathrm{HM})_k\), the exact pointwise consequence is
   \[
   \boxed{
   M_X:=\max_{m<X^2}K_X(m)
   \le k-1+X^{2/k+o(1)}\lambda_X.
   }
   \tag{A}
   \]
   Thus the exponent supplied by the moment is \(2/k\) **relative to \(\lambda_X\)**.  A pure power \(X^{\alpha(k)}\) exists only after one inserts a bound for \(\lambda_X\).

2. The exponent in the direct all-index bound for \(\log G_n\), using the original zero-mass exponent \(c=2/3\), is
   \[
   \boxed{\log G_n\ll n^{\,2/3+2/k+o(1)}.}
   \tag{B}
   \]
   Hence \(k=7\), not \(k=8\), is already the first integer order that closes the full theorem under that baseline.  Order \(8\) is merely a convenient even order.  With the stronger prime-average exponent \(c=3/5\) recorded in the current repository, \(k=6\) would already close the theorem.

Consequently, the statement in Q7786 that “\((\mathrm{HM})_5\) beats the square-root maximum” needs a qualification: it is true under the numerically predicted
\(\lambda_X=X^{o(1)}\) (in particular \(\lambda_X\asymp1/\log X\)), but it does **not** follow from the presently proved polynomial upper bounds for \(\lambda_X\).

For the tensor question, there is another important correction.  Two different geometric objects have appeared in the project:

- the irreducible rank-three K3/Sym\(^2\) object, whose connected group is of \(SO_3\)-type;
- the **marked Mellin stalk** used by the unit-root detector,
  \[
  (T-p)(T^2-a_{p,r}T+p^3),
  \]
  which has a fixed Tate line plus a moving rank-two symplectic quotient.

Their invariant tensors are not the same.  The recommended marked-unit-root route should first remove the Tate line and then use the rank-two \(SL_2\simeq Sp_2\) invariant list.  The familiar volume tensor at order three belongs to the rank-three \(SO_3\) formulation, not to the Tate-removed rank-two quotient.

# 1. Derivation of the pointwise exponent

Write

\[
F_k(X)=\sum_{m<X^2}(K_X(m))_k,
\qquad
(K)_k=K(K-1)\cdots(K-k+1),
\]

and recall that \((\mathrm{HM})_k\) means, for fixed \(k\),

\[
\boxed{F_k(X)\ll X^{2+o(1)}\lambda_X^k.}
\tag{1.1}
\]

Choose \(m_0\) with \(K_X(m_0)=M_X\).  If \(M_X<k\), there is nothing to prove.  Otherwise

\[
(M_X)_k\le F_k(X),
\]

while every factor in \((M_X)_k\) is at least \(M_X-k+1\).  Hence

\[
(M_X-k+1)^k\le (M_X)_k\le F_k(X).
\]

Taking the \(k\)-th root gives the exact one-spike estimate

\[
\boxed{
M_X\le k-1+F_k(X)^{1/k}
\ll_k 1+\lambda_X X^{2/k+o(1)}.
}
\tag{1.2}
\]

This is the strongest general \(L^k\)-to-\(L^\infty\) consequence of one fixed factorial moment.

## 1.1 The requested table

If one assumes the empirically supported scale

\[
\lambda_X=X^{o(1)}
\quad\text{(for example, }\lambda_X\asymp 1/\log X\text{)},
\]

then

\[
M_X\ll X^{\alpha(k)+o(1)},
\qquad
\boxed{\alpha(k)=\frac2k.}
\tag{1.3}
\]

| \(k\) | \(\alpha(k)=2/k\) | pointwise maximum under \(\lambda_X=X^{o(1)}\) |
|---:|---:|---:|
| 3 | \(2/3\) | \(M_X\ll X^{2/3+o(1)}\) |
| 4 | \(1/2\) | \(M_X\ll X^{1/2+o(1)}\) |
| 5 | \(2/5\) | \(M_X\ll X^{2/5+o(1)}\) |
| 6 | \(1/3\) | \(M_X\ll X^{1/3+o(1)}\) |
| 7 | \(2/7\) | \(M_X\ll X^{2/7+o(1)}\) |
| 8 | \(1/4\) | \(M_X\ll X^{1/4+o(1)}\) |

Thus:

- \((\mathrm{HM})_3\) reaches the \(2/3\) scale but does not improve it;
- \((\mathrm{HM})_4\) reaches the square-root scale;
- \((\mathrm{HM})_5\) is the first fixed moment giving a **strict power saving beyond square root**, provided \(\lambda_X=X^{o(1)}\).

More generally, if

\[
\lambda_X\ll X^{\theta+o(1)},
\]

then the pure exponent supplied by \((\mathrm{HM})_k\) is

\[
\boxed{\alpha_\theta(k)=\theta+\frac2k.}
\tag{1.4}
\]

The current manuscript records the unconditional average estimate
\(\lambda_X\ll X^{3/5+o(1)}/\log X\).  Substituting \(\theta=3/5\) gives

| \(k\) | \(3/5+2/k\) |
|---:|---:|
| 3 | \(19/15\) |
| 4 | \(11/10\) |
| 5 | \(1\) |
| 6 | \(14/15\) |
| 7 | \(31/35\) |
| 8 | \(17/20\) |

None of these improves the already proved twin-atom bound
\(M_X\ll X^{1/2+o(1)}\).  This is why the phrase “\((\mathrm{HM})_5\) beats square root” is conditional on the predicted subpolynomial size of \(\lambda_X\), not an unconditional deduction from the current zero-mass theorem.

If one uses only the older pointwise estimate \(Z(p)\ll p^{2/3+o(1)}\), then \(\theta=2/3\), and no fixed \(k\) gives a pure exponent below \(2/3\) through (1.4).

# 2. The separate exponent for the full Apéry theorem

The pointwise radical theorem in the repository has the general tradeoff

\[
\boxed{
(\mathrm{HM})_k
+\left(\sum_{p\le x}Z(p)\ll x^{1+c+o(1)}\right)
\Longrightarrow
\log G_n\ll n^{c+2/k+o(1)}.
}
\tag{2.1}
\]

With the original unconditional value \(c=2/3\), the exponents are:

| \(k\) | exponent \(2/3+2/k\) for \(\log G_n\) | closes \(G_n=e^{o(n)}\)? |
|---:|---:|:---:|
| 3 | \(4/3\) | no |
| 4 | \(7/6\) | no |
| 5 | \(16/15\) | no |
| 6 | \(1\) | no; critical only |
| 7 | \(20/21\) | **yes** |
| 8 | \(11/12\) | **yes** |

So \(k=7\) is the minimal integer order under the \(c=2/3\) baseline.  The use of \(k=8\) in Q7786 was a convenient even-order target, not a sharp threshold.

With the stronger repository value \(c=3/5\), the corresponding exponents are

\[
19/15,\quad 11/10,\quad 1,\quad 14/15,\quad31/35,\quad17/20
\]

for \(k=3,4,5,6,7,8\), respectively.  Thus \(k=6\) is then the first closing order.

This direct implication does **not** proceed by first proving a sharp maximum bound for \(K_X\).  That is why a fixed moment can close the Apéry theorem even when its one-spike bound (1.2) is weaker than the existing twin-atom maximum.

# 3. Partial converse to the collapse theorem

Yes.  Equation (1.2) is the exact partial converse:

\[
\boxed{
(\mathrm{HM})_k
\Longrightarrow
M_X\ll_k1+\lambda_X X^{2/k+o(1)}.
}
\tag{3.1}
\]

It is only a one-moment converse, not a converse to the full collapse theorem.

## 3.1 When does it give \(\beta<2/3\)?

If \(\lambda_X\ll X^{\theta+o(1)}\), then (3.1) gives

\[
M_X\ll X^{\beta+o(1)},
\qquad
\beta=\theta+\frac2k.
\tag{3.2}
\]

Therefore

\[
\beta<\frac23
\quad\Longleftrightarrow\quad
\theta+\frac2k<\frac23.
\tag{3.3}
\]

Examples:

- If \(\lambda_X=X^{o(1)}\), then every \(k\ge4\) gives \(\beta<2/3\); \(k=4\) gives \(\beta=1/2\), and \(k=5\) gives \(2/5\).
- With the current proved \(\theta=3/5\), one needs
  \[
  \frac2k<\frac1{15},
  \]
  hence \(k>30\).  No order \(k\le8\) gives a new pure pointwise exponent.
- With only \(\theta=2/3\), no finite fixed \(k\) can make (3.3) strict.

Thus the answer to “does one fixed \((\mathrm{HM})_k\) imply a maximum exponent below \(2/3\)?” is:

- **yes**, under the predicted subpolynomial bound for \(\lambda_X\), already from \(k=4\);
- **not from \((\mathrm{HM})_k\) alone**, without a quantitative bound on \(\lambda_X\).

## 3.2 Why this converse cannot be improved from moment information alone

The exponent \(2/k\) is sharp for a generic one-spike argument.  An abstract nonnegative sequence can have one value

\[
K(m_0)\asymp\lambda_X X^{2/k}
\]

and be zero elsewhere.  Then

\[
\sum_m(K(m))_k\asymp X^2\lambda_X^k,
\]

so \((\mathrm{HM})_k\) is saturated while the maximum is exactly of the size in (3.1).

Consequently a fixed moment cannot recover

\[
M_X\ll\lambda_X X^{o(1)}.
\]

For that, one needs either moment order tending to infinity, such as logarithmic-order ALCT, or an independent anti-tail theorem.  This is the precise asymmetry between the collapse theorem and its partial converse.

# 4. What “subtract the forced invariant tensors” means

There are three distinct layers that must not be merged:

1. **Disconnected set-partition terms**: these are removed by centering/cumulants or by the Palm baseline.
2. **Genuine monodromy invariants**: these remain even after connectedization and must be projected off and evaluated explicitly.
3. **Geometric diagonals**: repeated-prime diagonals and the Apéry reflection graph must also be removed from the trace formula.

Strictly speaking, one does not always “subtract” an invariant tensor as a scalar.  One projects the tensor sheaf onto its invariant rank-one summands, computes those main terms, and applies cancellation only to the complementary primitive summand.

## 4.1 Disconnected partition terms through tensor degree four

Let \(A_i\) denote hit indicators and put

\[
m_B=\mathbb E\prod_{i\in B}A_i,
\qquad \mu_i=m_{\{i\}}.
\]

At degree two, the connected part is

\[
\operatorname{cum}(A_1,A_2)
=m_{12}-\mu_1\mu_2.
\tag{4.1}
\]

At degree three,

\[
\begin{aligned}
\operatorname{cum}(A_1,A_2,A_3)
={}&m_{123}-m_{12}\mu_3-m_{13}\mu_2-m_{23}\mu_1\\
&+2\mu_1\mu_2\mu_3.
\end{aligned}
\tag{4.2}
\]

At degree four,

\[
\begin{aligned}
\operatorname{cum}(A_1,A_2,A_3,A_4)
={}&m_{1234}
-\sum_{i=1}^4m_{[4]\setminus\{i\}}\mu_i\\
&-(m_{12}m_{34}+m_{13}m_{24}+m_{14}m_{23})\\
&+2\sum_{\{i,j\}\subset[4]}m_{ij}\mu_k\mu_\ell
-6\mu_1\mu_2\mu_3\mu_4,
\end{aligned}
\tag{4.3}
\]

where \(\{k,\ell\}=[4]\setminus\{i,j\}\).

For centered variables \(\xi_i=A_i-\mu_i\), these simplify to

\[
\kappa_2=\mathbb E\xi_1\xi_2,
\qquad
\kappa_3=\mathbb E\xi_1\xi_2\xi_3,
\]

and

\[
\boxed{
\kappa_4
=\mathbb E\xi_1\xi_2\xi_3\xi_4
-\mathbb E\xi_1\xi_2\,\mathbb E\xi_3\xi_4
-\mathbb E\xi_1\xi_3\,\mathbb E\xi_2\xi_4
-\mathbb E\xi_1\xi_4\,\mathbb E\xi_2\xi_3.
}
\tag{4.4}
\]

The three terms in (4.4) are the forced Wick/disconnected pairings.  A Palm contraction that subtracts only \(J_{\mathbf p}\mu_{\mathbf p}\) removes the top-level \(t+1=t\mid1\) partition; a fully connected tensor argument must remove all lower set partitions as above.

# 5. Invariants for the marked unit-root object

The marked Frobenius factor proved in `problems/3.2/lemmaBprime_result.tex` is

\[
P_{p,r}(T)=(T-p)(T^2-a_{p,r}T+p^3).
\tag{5.1}
\]

Semisimply, write the corresponding three-dimensional stalk as

\[
L\oplus W,
\]

where

- \(L\) is the fixed Tate line with Frobenius eigenvalue \(p\);
- \(W\) is the moving rank-two quotient, equipped with an alternating perfect pairing
  \[
  \omega:W\otimes W\longrightarrow\mathbf1(-3).
  \]

After Tate normalization, the connected moving group is of \(SL_2=Sp_2\)-type.  The clean unit-root argument should first remove \(L\), because it is an explicit nonoscillating summand.

## 5.1 Full \(L\oplus W\) list in tensor degrees 2, 3, 4

Before removing \(L\), the forced rank-one sectors are:

### Tensor degree 2

\[
L_1L_2,
\qquad
\omega_{12}.
\tag{5.2}
\]

### Tensor degree 3

\[
L_1L_2L_3,
\qquad
L_1\omega_{23},\quad L_2\omega_{13},\quad L_3\omega_{12}.
\tag{5.3}
\]

There is no invariant in \(W^{\otimes3}\).

### Tensor degree 4

There are:

- the pure Tate line \(L_1L_2L_3L_4\);
- the six mixed sectors
  \[
  L_iL_j\omega_{k\ell},
  \qquad \{i,j,k,\ell\}=\{1,2,3,4\};
  \]
- the rank-two pairing sectors
  \[
  \omega_{12}\omega_{34},\qquad
  \omega_{13}\omega_{24},\qquad
  \omega_{14}\omega_{23}.
  \tag{5.4}
  \]

The last three satisfy the Plücker relation

\[
\boxed{
\omega_{12}\omega_{34}
-\omega_{13}\omega_{24}
+\omega_{14}\omega_{23}=0,
}
\tag{5.5}
\]

so \((W^{\otimes4})^{SL_2}\) is two-dimensional.

After projecting away the Tate line, the actual moving invariant list is therefore:

| tensor degree | forced invariant space on \(W\) |
|---:|---|
| 2 | one pairing \(\omega_{12}\) |
| 3 | none |
| 4 | two independent pair-pair contractions |

This is the invariant list most directly relevant to the marked slope-zero projector.

# 6. Alternative rank-three \(SO_3\) invariant list

If instead the argument is constructed before the marked degeneration, directly from the irreducible rank-three K3/Sym\(^2\) local system, let \(V\) denote the standard three-dimensional representation, \(Q\) its symmetric form, and \(\varepsilon\) its orientation tensor.

Then

### Tensor degree 2

\[
(V^{\otimes2})^{SO_3}
=\langle Q_{12}\rangle.
\tag{6.1}
\]

### Tensor degree 3

\[
(V^{\otimes3})^{SO_3}
=\langle\varepsilon_{123}\rangle.
\tag{6.2}
\]

This is the determinant/volume tensor mentioned in Q7786.  If the arithmetic monodromy is the full \(O_3\) rather than \(SO_3\), \(\varepsilon\) is not trivial: it lies in the determinant character.  It must then be isolated as a rank-one quadratic twist rather than silently treated as a cancelling term.

### Tensor degree 4

\[
(V^{\otimes4})^{SO_3}
=\left\langle
Q_{12}Q_{34},\quad
Q_{13}Q_{24},\quad
Q_{14}Q_{23}
\right\rangle.
\tag{6.3}
\]

These three pairings are independent.  There is no additional primitive four-leg invariant.

Thus the raw degree-\(2,3,4\) forced dimensions are

\[
1,\quad1,\quad3
\]

for the rank-three \(SO_3\) object, but

\[
1,\quad0,\quad2
\]

for the Tate-removed rank-two \(SL_2\) quotient.

This distinction is load-bearing.  One should not subtract an \(SO_3\) volume tensor in a proof that has already passed to the rank-two moving factor.

# 7. Palm-order indexing

In the notation of Q7786, the Palm contraction labelled by \(t\) conditions on \(t\) primes and adds one more prime.  Therefore it involves a tensor with

\[
n=t+1
\]

legs.  Under that convention the first three contractions are:

| Palm order \(t\) | total tensor legs | rank-two moving quotient \(W\) | rank-three \(SO_3\) alternative |
|---:|---:|---|---|
| 2 | 3 | no primitive invariant | \(\varepsilon_{123}\) |
| 3 | 4 | two independent \(\omega\omega\) pairings | three \(QQ\) pairings |
| 4 | 5 | no invariant, since the degree is odd | pair-plus-volume tensors \(Q_{ij}\varepsilon_{k\ell m}\) |

For the last entry, the \(SO_3\) five-leg invariants are generated by

\[
Q_{ij}\varepsilon_{k\ell m},
\qquad
\{i,j,k,\ell,m\}=\{1,2,3,4,5\}.
\tag{7.1}
\]

There are ten such pair/triple generators, subject to the three-dimensional antisymmetrization relations

\[
Q_{i[j}\varepsilon_{k\ell m]}=0.
\tag{7.2}
\]

The resulting invariant space has dimension six.

For the full marked object \(L\oplus W\), the numbers of explicit Tate/moving invariant sectors at total degrees \(3,4,5\) are respectively

\[
4,\qquad9,\qquad21,
\]

before grouping equal Tate weights.  Projecting away \(L\) reduces these to the clean \(W\)-column in the table.

# 8. Reflection and diagonal correspondences

The representation-theoretic list is still not the whole subtraction ledger.

## 8.1 Identity diagonal

When a completed square uses the same output prime twice, the ratio \(h=1\) is forced:

\[
M_p(1)=Z(p),
\qquad
T_p(1)=pZ(p)-Z(p)^2.
\tag{8.1}
\]

This is the local diagonal main term.  Factorial moments use distinct prime labels, but Cauchy--Schwarz and completion reintroduce this same-output-prime diagonal.

## 8.2 Reflection diagonal

In the odd coordinate

\[
y=2r+1,
\]

Apéry reflection is

\[
y\longmapsto-y.
\]

Thus the folded set \(\Omega_p\) satisfies \(\Omega_p=-\Omega_p\), and the ratio

\[
h=-1
\]

is also forced:

\[
M_p(-1)=|\Omega_p|.
\tag{8.2}
\]

In the original \(r\)-coordinate the same relation is the affine graph
\(r'=-1-r\), not a multiplicative ratio.  A trace formula must remove the graph of this involution separately.  It is not an additional \(SO_3\) or \(SL_2\) invariant tensor; it is a geometric correspondence on the parameter/index space.

At higher order, every pair contraction has direct and reflected graph versions

\[
y_i=y_j,
\qquad
y_i=-y_j.
\tag{8.3}
\]

If one works after reflection folding, these two versions collapse.  If one works in the unfolded index, they must both be included in the structural main term.

There can also be the central fixed point \(y=0\), corresponding to \(r=(p-1)/2\).  Its contribution is a separate bounded exceptional stratum.

## 8.3 Summary of the required projection

A valid Palm/tensor proof should proceed in this order:

1. subtract the one-leg density and, for the marked object, the fixed Tate eigenline;
2. remove every disconnected set-partition contribution;
3. project off the \(SL_2\) pairings, or the \(SO_3\) metric/volume sectors if using the rank-three formulation;
4. remove the identity and reflection graph components;
5. prove cancellation only for the remaining geometrically connected, tensor-primitive summand.

That is the precise meaning of “horizontal tensor primitivity” at fixed Palm order.

# Bottom line

The exact maximum consequence of \((\mathrm{HM})_k\) is

\[
\boxed{M_X\ll_k1+\lambda_X X^{2/k+o(1)}.}
\]

Therefore \(\alpha(k)=2/k\) only on the predicted scale \(\lambda_X=X^{o(1)}\), giving

\[
\frac23,\ \frac12,\ \frac25,\ \frac13,\ \frac27,\ \frac14
\]

for \(k=3,4,5,6,7,8\).  This is a genuine partial converse to the collapse theorem, but it is sharp for a single spike and cannot recover \(M_X\ll\lambda_XX^{o(1)}\) from any one fixed moment.

For the full GCD theorem, the distinct exponent is \(2/3+2/k\); \(k=7\) already closes the original baseline, while \(k=8\) is a convenient even choice.  Under the repository’s stronger \(3/5\) average exponent, \(k=6\) suffices.

Finally, the forced tensor list depends on the object.  For the recommended Tate-removed rank-two unit-root quotient it is

\[
\text{degree 2: one pairing},\qquad
\text{degree 3: none},\qquad
\text{degree 4: two pairings}.
\]

For the irreducible rank-three \(SO_3\) K3 object it is

\[
\text{degree 2: metric},\qquad
\text{degree 3: volume},\qquad
\text{degree 4: three metric pairings}.
\]

In either formulation, the set-partition baselines, same-prime diagonal, and Apéry reflection graph must also be removed before any primitive trace estimate is invoked.
