# Exact \(PP_3\) / pair-Palm experiment at \(X=512\)

## One correction before the code

For an interval of **cardinality**

\[
N_X=|I_X|=2X^2
\]

and distinct primes \(p,q\in(X,2X]\), one has \(pq>X^2=N_X/2\), not necessarily \(pq\ge N_X\). Therefore one residue class modulo \(pq\) can occur **twice** in \(I_X\). The unconditional bound is

\[
J_{p,q}=|A_{p,q}|
\le \left\lceil\frac{N_X}{pq}\right\rceil z_pz_q
\le 2z_pz_q.
\]

The stronger \(J_{p,q}\le z_pz_q\) is valid if \(|I_X|\le pq\), for example for an interval of length \(X^2\), or after restricting to pairs with \(pq\ge N_X\). The script below does **not** assume either bound: it constructs every pair fiber by CRT and counts all lifts in the chosen interval exactly. It also reports how many pairs violate \(J_{p,q}\le z_pz_q\).

The left endpoint of \(I_X\) affects only finite boundary terms. The default below is

\[
I_X=[0,2X^2)\cap\mathbb Z,
\]

and `--start s` changes it to `[s,s+2X^2)`. Thus the same program can reproduce a different half-open convention from Q7786/Q7798 without changing any formula. The anchored comparison uses \(y_0=1\), so the default interval contains the anchor.

---

## Exact identities used by the implementation

Let

\[
f_p(i)=1_{i\bmod p\in Z_p},\qquad K(i)=\sum_p f_p(i),
\]

and let all prime tuples be ordered. Then

\[
\begin{aligned}
\sum_{p\ne q}\sum_{i\in A_{p,q}}(K(i)-2)
&=\sum_i K(i)(K(i)-1)(K(i)-2)\\
&=:F_3.
\end{aligned}
\tag{1}
\]

So the quantity requested in the question is computed without a cubic prime loop:

\[
\boxed{
P_3^{(\lambda)}=\frac{F_3}{N_X\lambda^3},
\qquad
\lambda=\sum_{X<p\le2X}\frac{z_p}{p}.
}
\tag{2}
\]

A Poisson variable of mean \(\lambda\) has third falling factorial moment \(\lambda^3\), so the Poisson prediction for (2) is \(1\). The script also prints the exact finite-mean version

\[
\mu=\frac1{N_X}\sum_iK(i),\qquad
P_3^{(\mu)}=\frac{F_3}{N_X\mu^3},
\tag{3}
\]

and the independent non-identically-distributed Bernoulli prediction. If

\[
\rho_p=\frac1{N_X}\#\{i\in I_X:f_p(i)=1\},
\]

then independent columns predict

\[
F_3^{\rm Bern}
=N_X\left[
\left(\sum_p\rho_p\right)^3
-3\left(\sum_p\rho_p\right)\left(\sum_p\rho_p^2\right)
+2\sum_p\rho_p^3
\right].
\tag{4}
\]

### Output-prime decomposition

For a distinguished third prime \(\ell\), put

\[
T_\ell
=\sum_{\substack{p\ne q\\p,q\ne\ell}}
|A_{p,q}\cap A_\ell|
=\sum_{i:f_\ell(i)=1}(K(i)-1)(K(i)-2),
\tag{5}
\]

and

\[
D_\ell
=\sum_{\substack{p\ne q\\p,q\ne\ell}}J_{p,q}
=\sum_i(K(i)-f_\ell(i))(K(i)-f_\ell(i)-1).
\tag{6}
\]

Then

\[
\theta_\ell:=\frac{T_\ell}{D_\ell}
\]

is the observed probability that the output prime \(\ell\) hits a point sampled from the ordered pair fibers of the other primes. Under output-prime independence the finite prediction is

\[
\theta_\ell=\rho_\ell.
\tag{7}
\]

The script prints \(	heta_\ell\), \(ho_\ell\), and \(	heta_\ell/ho_\ell\) for **every** output prime. It verifies

\[
\sum_\ell T_\ell=F_3.
\tag{8}
\]

It also computes the pair-conditioned baseline

\[
B_{\rm Palm}=\sum_\ell \rho_\ell D_\ell
=\sum_{p\ne q}J_{p,q}\sum_{\ell\ne p,q}\rho_\ell,
\tag{9}
\]

so that \(F_3/B_{\rm Palm}\) is a direct aggregate \(PP_3\) contraction ratio. This is sharper than comparison only with \(N_X\mu^3\), because (9) keeps the **actual pair fibers** and randomizes only the third/output column.

Finally, for each pair the program computes

\[
E_{p,q}
=\sum_{i\in A_{p,q}}(K(i)-2)
-J_{p,q}\sum_{\ell\ne p,q}\rho_\ell
\tag{10}
\]

and reports the ordered positive excess

\[
\sum_{p\ne q}(E_{p,q})_+.
\]

#!/usr/bin/env python3
"""Exact Q7804 PP3 / pair-Palm experiment for Apéry zero sets.

Default experiment:
    X = 512
    I_X = [0, 2*X^2)
    anchored star y0 = 1

The program computes:
  * every Z_p for X < p <= 2X from the Apéry recurrence modulo p;
  * the exact finite incidence array K_X on I_X;
  * F2 and F3 falling-factorial moments;
  * the requested P3 = F3 / (N_X * lambda^3);
  * an explicit CRT audit of every pair fiber A_{p,q};
  * pairwise signed and positive Palm excesses;
  * an output-prime decomposition T_ell, D_ell, theta_ell;
  * the identical diagnostics for the reflection-invariant anchored star
        Z_p^* = {y0 mod p, -1-y0 mod p}.

Only NumPy and the Python standard library are required.
"""

from __future__ import annotations

import argparse
import csv
import math
import time
from dataclasses import dataclass
from pathlib import Path
from typing import Dict, List, Sequence, Tuple

import numpy as np


ZeroSets = Dict[int, Tuple[int, ...]]


@dataclass
class IncidenceData:
    name: str
    X: int
    start: int
    length: int
    primes: Tuple[int, ...]
    zero_sets: ZeroSets
    hit_indices: Tuple[np.ndarray, ...]
    K: np.ndarray
    alpha: np.ndarray  # complete-period densities z_p / p
    rho: np.ndarray    # exact finite densities on I_X

    @property
    def stop(self) -> int:
        return self.start + self.length


# ---------------------------------------------------------------------------
# Prime and Apéry-zero generation
# ---------------------------------------------------------------------------


def primes_in_dyadic_block(X: int) -> List[int]:
    """Return all primes p with X < p <= 2X."""
    if X < 2:
        raise ValueError("X must be at least 2")
    n = 2 * X
    sieve = np.ones(n + 1, dtype=np.bool_)
    sieve[:2] = False
    for p in range(2, math.isqrt(n) + 1):
        if sieve[p]:
            sieve[p * p : n + 1 : p] = False
    return [int(p) for p in np.flatnonzero(sieve) if X < int(p) <= n]


def apery_zero_set(p: int) -> Tuple[int, ...]:
    """Compute Z_p = {0 <= r < p : b_r == 0 mod p} in O(p) time.

    Uses
        (n+1)^3 b_{n+1}
          = (2n+1)(17n^2+17n+5)b_n - n^3 b_{n-1}.

    Every denominator used has 1 <= n+1 <= p-1 and is therefore a unit.
    """
    if p < 5:
        raise ValueError("This audit expects primes p >= 5")

    b = [0] * p
    b[0] = 1
    b[1] = 5 % p

    # All inverses 1,...,p-1 in linear time.
    inv = [0] * p
    inv[1] = 1
    for a in range(2, p):
        inv[a] = (-(p // a) * inv[p % a]) % p

    for n in range(1, p - 1):
        middle = ((2 * n + 1) * (17 * n * n + 17 * n + 5)) % p
        back = (n * n * n) % p
        rhs = (middle * b[n] - back * b[n - 1]) % p
        u = inv[n + 1]
        inv_cube = (u * u % p) * u % p
        b[n + 1] = rhs * inv_cube % p

    zeros = tuple(r for r, value in enumerate(b) if value == 0)

    # Cheap exact integrity checks from the banked Apéry theory.
    if b[p - 1] != 1 % p:
        raise AssertionError(("bad endpoint", p, b[p - 1]))
    if any(b[r] != b[p - 1 - r] for r in range(p)):
        raise AssertionError(("reflection failure", p))
    zero_mask = [value == 0 for value in b]
    if any(zero_mask[r] and zero_mask[r + 1] for r in range(p - 1)):
        raise AssertionError(("consecutive zeros", p))

    return zeros


def apery_zero_sets(primes: Sequence[int]) -> ZeroSets:
    return {int(p): apery_zero_set(int(p)) for p in primes}


def anchored_star_zero_sets(
    primes: Sequence[int], y0: int
) -> ZeroSets:
    """Reflection-invariant anchored star.

    The reflection is r -> p-1-r = -1-r mod p. Since y0 itself is
    one of the two residues, K(y0) equals the number of primes whenever
    y0 lies in the tested interval.
    """
    out: ZeroSets = {}
    for p0 in primes:
        p = int(p0)
        a = y0 % p
        z = tuple(sorted({a, (-1 - a) % p}))
        if any((p - 1 - r) % p not in z for r in z):
            raise AssertionError(("star reflection failure", p, z))
        out[p] = z
    return out


# ---------------------------------------------------------------------------
# Finite interval incidence arrays
# ---------------------------------------------------------------------------


def interval_hit_indices(
    start: int,
    length: int,
    p: int,
    residues: Sequence[int],
) -> np.ndarray:
    """Sorted zero-based indices j with start+j == r (mod p)."""
    stop = start + length
    chunks: List[np.ndarray] = []
    for r0 in residues:
        r = int(r0)
        first = start + ((r - start) % p)
        if first < stop:
            chunks.append(
                np.arange(first - start, length, p, dtype=np.int32)
            )

    if not chunks:
        return np.empty(0, dtype=np.int32)

    idx = np.concatenate(chunks)
    idx.sort()
    if idx.size > 1 and np.any(idx[1:] == idx[:-1]):
        raise AssertionError(("duplicate same-prime hit", p))
    return idx


def build_incidence_data(
    name: str,
    X: int,
    start: int,
    length: int,
    primes: Sequence[int],
    zero_sets: ZeroSets,
) -> IncidenceData:
    """Build K and retain sparse hit lists for all later contractions."""
    if length <= 0:
        raise ValueError("interval length must be positive")

    K = np.zeros(length, dtype=np.uint16)
    hit_lists: List[np.ndarray] = []
    alpha = np.zeros(len(primes), dtype=np.float64)
    rho = np.zeros(len(primes), dtype=np.float64)

    for j, p0 in enumerate(primes):
        p = int(p0)
        z = zero_sets[p]
        idx = interval_hit_indices(start, length, p, z)
        if idx.size:
            # idx has no repetitions, so ordinary fancy-index addition is exact.
            K[idx] += np.uint16(1)
        hit_lists.append(idx)
        alpha[j] = len(z) / p
        rho[j] = idx.size / length

    if int(K.max(initial=0)) > len(primes):
        raise AssertionError("incidence count exceeds the number of columns")

    return IncidenceData(
        name=name,
        X=X,
        start=start,
        length=length,
        primes=tuple(int(p) for p in primes),
        zero_sets=zero_sets,
        hit_indices=tuple(hit_lists),
        K=K,
        alpha=alpha,
        rho=rho,
    )


# ---------------------------------------------------------------------------
# Exact pair CRT fibers
# ---------------------------------------------------------------------------


def pair_crt_indices(
    start: int,
    length: int,
    p: int,
    zp: Sequence[int],
    q: int,
    zq: Sequence[int],
) -> Tuple[np.ndarray, int]:
    """Return the exact finite fiber A_{p,q} as zero-based indices.

    Also returns the maximum number of interval lifts seen for one CRT
    residue class. Distinct residue pairs give distinct classes modulo pq.
    """
    if p == q:
        raise ValueError("pair CRT requires distinct primes")
    if not zp or not zq:
        return np.empty(0, dtype=np.int32), 0

    stop = start + length
    modulus = p * q
    inv_p_mod_q = pow(p, -1, q)
    out: List[int] = []
    max_lifts = 0

    for r0 in zp:
        r = int(r0)
        for s0 in zq:
            s = int(s0)
            # x = r + p*t, t = (s-r)/p mod q.
            t = ((s - r) * inv_p_mod_q) % q
            x0 = (r + p * t) % modulus
            x = start + ((x0 - start) % modulus)
            lifts = 0
            while x < stop:
                out.append(x - start)
                lifts += 1
                x += modulus
            max_lifts = max(max_lifts, lifts)

    if not out:
        return np.empty(0, dtype=np.int32), max_lifts

    idx = np.asarray(out, dtype=np.int32)
    idx.sort()
    if idx.size > 1 and np.any(idx[1:] == idx[:-1]):
        raise AssertionError(("duplicate CRT lift", p, q))
    return idx, max_lifts


def exact_pair_audit(
    data: IncidenceData,
    K64: np.ndarray,
    F2: int,
    F3: int,
    mu: float,
) -> dict:
    """Enumerate every unordered pair, then restore ordered-pair factors."""
    ordered_J = 0
    ordered_T = 0
    baseline_finite = 0.0
    baseline_periodic = 0.0
    positive_finite = 0.0
    negative_finite = 0.0
    positive_periodic = 0.0

    max_class_bound = 0
    max_lifts_seen = 0
    pairs_with_two_lifts = 0
    pairs_J_gt_zprod = 0
    max_J_over_zprod = 0.0
    rows: List[dict] = []

    lam = float(data.alpha.sum())
    npr = len(data.primes)

    for a in range(npr):
        p = data.primes[a]
        zp = data.zero_sets[p]
        for b in range(a + 1, npr):
            q = data.primes[b]
            zq = data.zero_sets[q]
            idx, local_max_lifts = pair_crt_indices(
                data.start, data.length, p, zp, q, zq
            )
            J = int(idx.size)
            vals = K64[idx]
            if J and np.any(vals < 2):
                raise AssertionError(("pair point has K<2", p, q))
            T = int(np.sum(vals - 2, dtype=np.int64)) if J else 0

            remaining_finite = max(
                0.0, mu - float(data.rho[a]) - float(data.rho[b])
            )
            remaining_periodic = max(
                0.0, lam - float(data.alpha[a]) - float(data.alpha[b])
            )
            base_f = J * remaining_finite
            base_p = J * remaining_periodic
            excess_f = T - base_f
            excess_p = T - base_p

            # Convert this unordered pair to ordered-pair convention.
            ordered_J += 2 * J
            ordered_T += 2 * T
            baseline_finite += 2.0 * base_f
            baseline_periodic += 2.0 * base_p
            positive_finite += 2.0 * max(excess_f, 0.0)
            negative_finite += 2.0 * min(excess_f, 0.0)
            positive_periodic += 2.0 * max(excess_p, 0.0)

            modulus = p * q
            class_bound = (data.length + modulus - 1) // modulus
            max_class_bound = max(max_class_bound, class_bound)
            max_lifts_seen = max(max_lifts_seen, local_max_lifts)
            if local_max_lifts >= 2:
                pairs_with_two_lifts += 1

            zprod = len(zp) * len(zq)
            bound = class_bound * zprod
            if J > bound:
                raise AssertionError(("CRT class bound failed", p, q, J, bound))
            if zprod:
                max_J_over_zprod = max(max_J_over_zprod, J / zprod)
                if J > zprod:
                    pairs_J_gt_zprod += 1
            elif J != 0:
                raise AssertionError(("nonempty pair with an empty zero set", p, q))

            if J:
                rows.append(
                    {
                        "p": p,
                        "q": q,
                        "z_p": len(zp),
                        "z_q": len(zq),
                        "J": J,
                        "T": T,
                        "remaining_mean_finite": remaining_finite,
                        "baseline_finite": base_f,
                        "excess_finite": excess_f,
                        "remaining_mean_periodic": remaining_periodic,
                        "baseline_periodic": base_p,
                        "excess_periodic": excess_p,
                        "max_lifts_one_class": local_max_lifts,
                    }
                )

    # These are exact, integer-valued reconstructions of the factorial moments.
    if ordered_J != F2:
        raise AssertionError(("pair CRT does not reconstruct F2", ordered_J, F2))
    if ordered_T != F3:
        raise AssertionError(("pair CRT does not reconstruct F3", ordered_T, F3))

    return {
        "ordered_J": ordered_J,
        "ordered_T": ordered_T,
        "baseline_finite": baseline_finite,
        "baseline_periodic": baseline_periodic,
        "positive_finite": positive_finite,
        "negative_finite": negative_finite,
        "positive_periodic": positive_periodic,
        "max_class_bound": max_class_bound,
        "max_lifts_seen": max_lifts_seen,
        "pairs_with_two_lifts": pairs_with_two_lifts,
        "pairs_J_gt_zprod": pairs_J_gt_zprod,
        "max_J_over_zprod": max_J_over_zprod,
        "rows": rows,
    }

# Output-prime decomposition

def output_prime_decomposition(
    data: IncidenceData,
    K64: np.ndarray,
    F2: int,
    F3: int,
) -> Tuple[List[dict], float, float]:
    rows: List[dict] = []
    total_T = 0
    baseline_finite = 0.0
    baseline_periodic = 0.0

    for j, p in enumerate(data.primes):
        idx = data.hit_indices[j]
        vals = K64[idx]

        # Removing ell from K changes K(K-1) by 2(K-1) at ell-hit points.
        removed = int(np.sum(vals - 1, dtype=np.int64)) if idx.size else 0
        D = F2 - 2 * removed
        if D < 0:
            raise AssertionError(("negative pair exposure", p, D))

        # At an ell-hit point, the ordered pair (p,q) is selected among K-1
        # remaining columns, hence (K-1)(K-2).
        T = (
            int(np.sum((vals - 1) * (vals - 2), dtype=np.int64))
            if idx.size
            else 0
        )
        total_T += T

        rho = float(data.rho[j])
        alpha = float(data.alpha[j])
        expected_finite = rho * D
        expected_periodic = alpha * D
        baseline_finite += expected_finite
        baseline_periodic += expected_periodic

        conditional = T / D if D else float("nan")
        ratio_finite = (
            conditional / rho
            if D and rho > 0.0
            else float("nan")
        )
        ratio_periodic = (
            conditional / alpha
            if D and alpha > 0.0
            else float("nan")
        )

        rows.append(
            {
                "ell": p,
                "z_ell": len(data.zero_sets[p]),
                "finite_hits": int(idx.size),
                "rho_finite": rho,
                "alpha_periodic": alpha,
                "pair_exposure_D": D,
                "triple_output_T": T,
                "conditional_theta": conditional,
                "theta_over_rho": ratio_finite,
                "theta_over_alpha": ratio_periodic,
                "expected_finite": expected_finite,
                "excess_finite": T - expected_finite,
                "expected_periodic": expected_periodic,
                "excess_periodic": T - expected_periodic,
            }
        )

    if total_T != F3:
        raise AssertionError(("output-prime decomposition does not reconstruct F3", total_T, F3))

    return rows, baseline_finite, baseline_periodic

def ordered_distinct_cube(weights: np.ndarray) -> float:
    """Sum of w_p w_q w_l over ordered distinct p,q,l."""
    s1 = float(np.sum(weights))
    s2 = float(np.dot(weights, weights))
    s3 = float(np.sum(weights * weights * weights))
    return max(0.0, s1 * s1 * s1 - 3.0 * s1 * s2 + 2.0 * s3)


def ratio(num: float, den: float) -> float:
    return num / den if den > 0.0 else float("nan")


def fmt(x: float) -> str:
    if not math.isfinite(x):
        return "nan"
    return f"{x:.9g}"


def safe_tag(name: str) -> str:
    return "".join(c if c.isalnum() else "_" for c in name).strip("_")

    negative = sorted(pair_rows, key=lambda row: row["excess_finite"])[:top_n]

    print("    p     q      J      T     baseline       excess")

def analyze_dataset(
    data: IncidenceData,
    csv_prefix: str,
    top_pairs: int,
    show_output_table: bool,
) -> dict:
    t0 = time.perf_counter()
    K64 = data.K.astype(np.int64)
    N = data.length

    F1 = int(np.sum(K64, dtype=np.int64))
    F2 = int(np.sum(K64 * (K64 - 1), dtype=np.int64))
    F3 = int(np.sum(K64 * (K64 - 1) * (K64 - 2), dtype=np.int64))

    sparse_F1 = sum(int(idx.size) for idx in data.hit_indices)
    if sparse_F1 != F1:
        raise AssertionError(("sparse/dense F1 mismatch", sparse_F1, F1))

    lam = float(np.sum(data.alpha))
    mu = F1 / N
    poisson_periodic = N * lam**3
    poisson_finite = N * mu**3
    bernoulli_periodic = N * ordered_distinct_cube(data.alpha)
    bernoulli_finite = N * ordered_distinct_cube(data.rho)

    output_rows, output_base_f, output_base_p = output_prime_decomposition(
        data, K64, F2, F3
    )

    pair_t0 = time.perf_counter()
    pair = exact_pair_audit(data, K64, F2, F3, mu)
    pair_seconds = time.perf_counter() - pair_t0

    # The two ways of arranging the same finite Palm baseline must agree.
    tol_f = 1e-9 * max(1.0, abs(output_base_f), abs(pair["baseline_finite"]))
    tol_p = 1e-9 * max(1.0, abs(output_base_p), abs(pair["baseline_periodic"]))
    if abs(output_base_f - pair["baseline_finite"]) > tol_f:
        raise AssertionError(("finite Palm baseline mismatch", output_base_f, pair["baseline_finite"]))
    if abs(output_base_p - pair["baseline_periodic"]) > tol_p:
        raise AssertionError(("periodic Palm baseline mismatch", output_base_p, pair["baseline_periodic"]))

    max_K = int(K64.max(initial=0))

## What the output means

The principal lines are:

```text
P3_lambda = F3/(N*lambda^3)
P3_mu     = F3/(N*mu^3)
F3 / finite Bernoulli baseline
F3/B (aggregate output contraction ratio)
positive finite Palm excess / (N*mu^3)
```

For independent Poisson/Bernoulli columns, the first four ratios should be near \(1\), while the signed pair-Palm excess should be near \(0\). The positive-part statistic is not predicted to be exactly zero at finite \(X\), but it should remain of the natural \(N_X\mu^3\) scale rather than being driven by a small collection of overloaded pair fibers.

For the anchored star \(y_0=1\), the exact assertion

\[
K_X(1)=\#\{p:X<p\le2X\}
\]

is checked before any report is printed. Consequently its third factorial moment contains the single contribution

\[
(K_X(1))_3,
\]

and the output-prime ratios expose the deliberate failure of pair-Palm contraction. This makes the actual/star comparison a direct anti-alignment diagnostic rather than merely a comparison of the marginal values \(z_p\).

## Complexity and expected runtime

At \(X=512\):

- computing all \(Z_p\) costs \(O(\sum_{X<p\le2X}p)\), only tens of thousands of recurrence steps;
- building \(K\) costs \(O(N_X\mu)\) sparse slice updates;
- the output-prime decomposition costs \(O(\sum_p|\Omega_p\cap I_X|)\);
- the explicit pair audit costs
  \[
  O\!\left(\sum_{p<q}z_pz_q\left\lceil\frac{N_X}{pq}\right\rceil\right),
  \]
  and the actual Apéry \(z_p\)'s in this range are tiny;
- the dense arrays have length \(524{,}288\), and no \(\#\mathcal P_X\times N_X\) Boolean matrix is stored.

Thus the arithmetic workload is comfortably below the requested 60-second scale on an ordinary laptop. The script prints independent timers for zero-set construction, the explicit pair-CRT audit, each dataset, and the total run.
