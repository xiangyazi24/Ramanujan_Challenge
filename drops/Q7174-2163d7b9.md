## Verdict

There are two different counting functions hiding behind the notation `C_p(q)`.

1. **Raw/oriented count.** Count every start-indexed chain
   \(z_0<z_1<z_2<z_3\) separately.
2. **Reflection-quotient count.** Identify the chain with
   \[
   (z_0,z_1,z_2,z_3)\longleftrightarrow
   (p-1-z_3,p-1-z_2,p-1-z_1,p-1-z_0).
   \]

For the raw count, the proposed pointwise statement `C_p(q) <= 1` is not merely false empirically: it is incompatible with the proved strong reflection law. Every eligible off-center chain has a distinct reflected eligible chain **in the same projective state**. Thus the raw count is always even.

The first raw duplicate is

```text

q = 454                         # in the fixed basis [b_n:c_n]
state occurrence list = [360,365,385,395,901,911,931,936]

chain 1: start 360, gaps (5,20,10), positions (360,365,385,395)
chain 2: start 901, gaps (10,20,5), positions (901,911,931,936)

actual Apéry zero set (q=0) = [459,530,766,837]
```

The two chains are one reflection orbit. Their span is \(35\), and
\(35^2=1225<1297\). They are primitive, carrier-clean, non-all-equal, and off-center. The state is phantom: \(q=454\ne0\).

## 2. Exact reflection lemma and the counting correction

The proved strong-reflection theorem applies to every solution germ, hence separately to \(B\) and \(C\):

\[
B_{p-1-n}=B_n,\qquad C_{p-1-n}=C_n.
\]

Consequently

\[
\pi_p(p-1-n)=\pi_p(n).
\]

Define

\[
R(z_0,z_1,z_2,z_3)
=(p-1-z_3,p-1-z_2,p-1-z_1,p-1-z_0).
\]

Then:

1. `R` preserves the state \(q\).
2. It preserves consecutiveness in the fiber occurrence list: an intermediate occurrence in the reflected interval would reflect to an intermediate occurrence in the original interval.
3. It reverses the gap triple, preserves the span and the carrier condition, and preserves the non-all-equal condition.
4. It preserves off-centeredness, since a reflected adjacent sum equals \(p-1\) exactly when the original adjacent sum equals \(p-1\).
5. It has no fixed eligible chain. Indeed, a fixed chain would satisfy
   \(z_1+z_2=p-1\), making its middle adjacent pair centered.

Thus reflection acts freely on the eligible raw chains in each state. If
\(C_p^{\rm raw}(q)\) is the raw count and \(\overline C_p(q)\) is the count of reflection orbits, then the exact identity is

\[
\boxed{C_p^{\rm raw}(q)=2\overline C_p(q).}
\]

This is why a raw maximum of `1` is impossible as soon as any eligible chain exists.

The core algorithm is:

```cpp
// Compute B_n and C_n exactly modulo p.
for (int n = 1; n < p - 1; ++n) {
    int n2 = mul_mod(n, n, p);
    int n3 = mul_mod(n2, n, p);
    int Pn = (34LL*n3 + 51LL*n2 + 27LL*n + 5) % p;
    int inv3 = mul_mod(mul_mod(inv[n+1], inv[n+1], p), inv[n+1], p);
    B[n+1] = mul_mod(Pn*1LL*B[n] - n3*1LL*B[n-1], inv3, p);
    C[n+1] = mul_mod(Pn*1LL*C[n] - n3*1LL*C[n-1], inv3, p);
}

// State IDs: 0,...,p-1 plus p for infinity.
for (int n = 0; n < p; ++n) {
    state[n] = (C[n] == 0) ? p : mul_mod(B[n], inv[C[n]], p);
    ++count[state[n]];
}

// Counting-sort all indices into ordered projective fibers.
for (int q = 0; q <= p; ++q) offset[q+1] = offset[q] + count[q];
for (int n = 0; n < p; ++n) packed[cursor[state[n]]++] = n;

// Only consecutive four-windows can be primitive.
for (int q = 0; q <= p; ++q) {
    for (int j = offset[q]; j + 3 < offset[q+1]; ++j) {
        int z0 = packed[j], z1 = packed[j+1];
        int z2 = packed[j+2], z3 = packed[j+3];
        int a = z1-z0, b = z2-z1, c = z3-z2, s = z3-z0;
        bool eligible =
            a >= 2 && b >= 2 && c >= 2 &&
            !(a == b && b == c) &&
            z0+z1 != p-1 && z1+z2 != p-1 && z2+z3 != p-1 &&
            1LL*s*s <= p && !carrier_bad[s];
        if (eligible) record(q, z0, z1, z2, z3);
    }
}
```

## 6. Does the quotient maximum one look like a theorem?

Only weakly. The finite result is real, but there is a natural sparsity explanation.

Let \(H=\lfloor\sqrt p\rfloor\), and heuristically treat projective states at unrelated indices as roughly uniform among \(p+1\) states.

### One chain orbit

There are on the order of \(pH^3\) choices of a start and three positive gaps of total at most \(H\). Four prescribed positions have one common state with heuristic probability \(p^{-3}\). Thus the expected number of raw short chains is

\[
\frac{pH^3}{p^3}=\frac{H^3}{p^2}.
\]

At \(H=\sqrt p\), this is \(p^{-1/2}\). Summed over primes, this predicts only about square-root-over-log growth, consistent with seeing merely 10 reflection orbits by \(500000\).

### Two separated chain orbits in one state

For two separated four-tuples there are about \(p^2H^6\) choices. Requiring all eight positions to have one common state has probability about \(p^{-7}\), giving

\[
\frac{p^2H^6}{p^7}=rac{H^6}{p^5}=p^{-2}
\]

at \(H=\sqrt p\). This is summable over primes. Therefore the absence of a separated same-state double chain is unsurprising and may persist for a very long range.

### Overlap is the more dangerous route

Two consecutive four-windows in one fiber can share three positions, so their union has five projective returns. The number of such local five-position configurations is on the order of \(pH^4\), and the heuristic probability that all five positions have one state is \(p^{-4}\). Hence

\[
\frac{pH^4}{p^4}=rac{H^4}{p^3}=p^{-1}
\]

at \(H=\sqrt p\). The prime sum \(\sum_p1/p\) diverges, albeit only like \(\log\log P\). Six- and seven-position unions have smaller heuristic sizes \(p^{-3/2}\) and \(p^{-2}\).

Thus a random-orbit model predicts that, after deterministic reflection pairs are removed, an eventual failure of \(\overline C_p(q)\le1\) should most plausibly come from a five-return overlap, not from two widely separated chains. Carrier-clean, off-center, and non-all-equal filters change constants but not these exponents unless an Apéry-specific identity forces an additional vanishing.

This is a heuristic, not a proof: the nonautonomous Apéry orbit is not independent random data. But it means the computation should be interpreted as **strong finite-range sparsity**, not as persuasive evidence for a universal pointwise theorem.

## 7. Narrowest next statement

The empirically surviving statement is

\[
\boxed{\overline C_p(q)\le1}
\]

for every tested \(p,q\), where the bar is essential.

The narrow deterministic lemma that would attack the dominant prospective failure is a five-return exclusion:

> Let \(z_0<z_1<z_2<z_3<z_4\) be five consecutive occurrences of one projective state. If both four-windows \((z_0,z_1,z_2,z_3)\) and \((z_1,z_2,z_3,z_4)\) have span at most \(\sqrt p\), then the two windows cannot both be carrier-clean, primitive, non-all-equal, and off-center.

Nothing in the current computation proves that lemma. Without such an Apéry-specific overlap obstruction, the prudent conclusion is:

- **raw `C_p(q) <= 1`: exactly false;**
- **reflection-quotient `Cbar_p(q) <= 1`: certified through \(500000\), but presently an empirical sparsity pattern rather than a credible theorem.**
