## 2. Reflection forces raw chains to occur in pairs

The proved strong-reflection theorem applies to every solution germ. Applying it separately to `B` and `C` gives

```text
B_(p-1-n) = B_n,
C_(p-1-n) = C_n,
pi_p(p-1-n) = pi_p(n).
```

For a chain `Z=(z_0,z_1,z_2,z_3)`, define

```text
R(Z) = (p-1-z_3, p-1-z_2, p-1-z_1, p-1-z_0).
```

This involution has five relevant properties.

1. `R(Z)` lies in the same projective state as `Z`.
2. It preserves primitivity. Any intermediate return in the reflected interval would reflect back to an intermediate return in the original interval.
3. It reverses the gap triple `(a,b,c)` to `(c,b,a)` and preserves the span and carrier condition.
4. It preserves the non-all-equal and off-center conditions.
5. It fixes no eligible chain. A fixed ordered chain would have `z_1+z_2=p-1`, making the middle adjacent pair centered, which is excluded.

Therefore reflection acts freely on the eligible raw chains of every state. If `C_raw(p,q)` counts starts and `C_bar(p,q)` counts reflection orbits, then the exact relation is

```text
C_raw(p,q) = 2 C_bar(p,q).
```

Consequently, a nonzero raw maximum can never equal 1. The meaningful pointwise sparsity statement is the quotient claim `C_bar(p,q) <= 1`.

The main algorithm is:

```cpp
// 1. Compute the two exact recurrence solutions modulo p.
for (int n = 1; n < p - 1; ++n) {
    const int n2 = mul_mod(n, n, p);
    const int n3 = mul_mod(n2, n, p);
    int Pn = 5 % p;
    Pn = add_mod(Pn, 27LL * n, p);
    Pn = add_mod(Pn, 51LL * n2, p);
    Pn = add_mod(Pn, 34LL * n3, p);
    const int inv3 = mul_mod(
        mul_mod(inverse[n + 1], inverse[n + 1], p),
        inverse[n + 1], p);

    const int next_B_num = add_mod(
        1LL * Pn * B[n], -1LL * n3 * B[n - 1], p);
    const int next_C_num = add_mod(
        1LL * Pn * C[n], -1LL * n3 * C[n - 1], p);
    B[n + 1] = mul_mod(next_B_num, inv3, p);
    C[n + 1] = mul_mod(next_C_num, inv3, p);
}

// 2. Assign exact projective state IDs; p denotes infinity.
for (int n = 0; n < p; ++n) {
    state[n] = (C[n] == 0) ? p : mul_mod(B[n], inverse[C[n]], p);
    ++count[state[n]];
}

// 3. Counting-sort indices into ordered state occurrence lists.
for (int q = 0; q <= p; ++q) offset[q + 1] = offset[q] + count[q];
for (int n = 0; n < p; ++n) packed[cursor[state[n]]++] = n;

// 4. Primitive chains are exactly consecutive four-windows.
for (int q = 0; q <= p; ++q) {
    for (int j = offset[q]; j + 3 < offset[q + 1]; ++j) {
        const int z0 = packed[j];
        const int z1 = packed[j + 1];
        const int z2 = packed[j + 2];
        const int z3 = packed[j + 3];
        const int a = z1 - z0;
        const int b = z2 - z1;
        const int c = z3 - z2;
        const int s = z3 - z0;

        const bool eligible =
            a >= 2 && b >= 2 && c >= 2 &&
            !(a == b && b == c) &&
            z0 + z1 != p - 1 &&
            z1 + z2 != p - 1 &&
            z2 + z3 != p - 1 &&
            1LL * s * s <= p &&
            !carrier_bad[s];

        if (eligible) record(q, z0, z1, z2, z3);
    }
}
```

## 6. Is the quotient bound a plausible theorem?

The data support a finite-range statement but do not yet reveal a deterministic mechanism forcing it for every prime.

Let `H=floor(sqrt(p))` and, only as a heuristic, model unrelated projective states as approximately uniform among `p+1` values.

### A single chain

There are on the order of `p H^3` choices of a start and three positive gaps with total at most `H`. Four prescribed positions have one common state with probability about `p^(-3)`. The expected number is therefore

```text
p H^3 * p^(-3) = H^3/p^2 = p^(-1/2)  when H=sqrt(p).
```

This predicts very few chains per prime, consistent with only 10 reflection orbits through 500,000.

### Two separated chain orbits in one state

There are roughly `p^2 H^6` choices for two separated short four-tuples. Requiring all eight positions to have one state costs about `p^(-7)`, giving

```text
p^2 H^6 * p^(-7) = H^6/p^5 = p^(-2).
```

This is summable over primes, so the absence of a separated same-state double chain in a large finite range is not surprising.

### Two overlapping windows

Two consecutive primitive four-windows may share three positions, so their union has five projective returns and four short gaps. There are about `p H^4` local configurations, and a random five-position same-state condition costs about `p^(-4)`. The expected size is

```text
p H^4 * p^(-4) = H^4/p^3 = p^(-1).
```

The prime sum of `1/p` diverges, although only at logarithmic-logarithmic scale. Thus, after deterministic reflection pairs are removed, the first genuine quotient collision is heuristically most likely to be an overlapping five-return cluster. Six- and seven-position unions are smaller, and fully separated pairs are smaller still.

This random-fiber model is not a proof: the Apéry orbit is a structured nonautonomous recurrence. Its role is only to warn that `C_bar(p,q) <= 1` may be a long-lived small-range phenomenon rather than a universal law.

## 7. Narrowest next statement

The literal result is now settled:

```text
Raw pointwise claim C_raw(p,q) <= 1: false, first at p=1297, q=454.
Reflection quotient C_bar(p,q) <= 1: exact for every p<=500000.
```

The most focused deterministic lemma suggested by the computation is the following overlap exclusion.

> Let `z_0<z_1<z_2<z_3<z_4` be five consecutive occurrences of one projective state. Suppose both windows `(z_0,z_1,z_2,z_3)` and `(z_1,z_2,z_3,z_4)` have span at most `sqrt(p)`. Then they cannot both be carrier-clean, primitive, non-all-equal, and off-center.

The present computation does not prove this lemma. Even that lemma would address only the dominant overlap mechanism; a universal pointwise quotient theorem would still need a separate exclusion of two nonreflection separated chains. For the weak-DPLS program, it is therefore safer to retain an averaged separated-pair estimate rather than replace it by the unproved pointwise assertion.
