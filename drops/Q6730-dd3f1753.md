## (1) Quarter-value theorem

Input | What it controls | Why it does or does not bite

Quarter-value theorem | Pins the explicit orbit value tau_{(p-1)/4} through a weight-3 eta-multiplier form value on the level-6 four-fold cover | Does not presently bite the padded/scattered adversary. The theorem is a single distinguished time slice. The primitive padding adversary needs a mesoscopic population of paired incidences with gaps D/2 < d <= D. In particular it does not interact with the block mechanism except if one proves propagation from the quarter point to a growing family of rows. No such propagation is banked.

Verdict: negligible in the same structural sense as fixed-height laws. It is arithmetic, but not a quenched growing-gap constraint.

## (2) Self-twist rigidity

Input | What it controls | Why it does or does not bite

Self-twist rigidity | The conjugate-twist group of the local system is {1, delta}; Sym^2 has no self-twist; nontrivial 3+1 decompositions are only diagonal | Does not rule out the scattered primitive pairing. Twist rigidity gives restrictions on the geometric representation and its possible hidden automorphisms. At fixed p it can rule out a genuine global orbit symmetry coming from an automorphism/twist of the local system. It does not imply that the finite sequence xi_1,...,xi_N cannot contain many accidental or combinatorially organized pairs xi_r = xi_{r+d_r}.

The padded adversary does not require a geometric involution. It assigns private colours/fibres and only asks for equality at selected pairs. Therefore the required pairing is invisible to the twist group unless one upgrades rigidity to a statement about the distribution of return times of the Frobenius orbit.

Exact missing implication would be something like: a large set of primitive returns forces a nontrivial endomorphism or twist of the local system. That statement is not currently proved.

Verdict: blocks global hidden symmetry, not accidental quenched return structure.

## Best candidate for a provable separating statement

The current banked inputs do not separate Apery from the fully scattered adversary. The adversary remaining after all audits is:

- variable gaps d_i in (D/2,D];
- no long run in any fixed Z_d;
- private fibres;
- all word/clique constraints satisfied;
- no need for a visible geometric symmetry.

The most plausible next arithmetic statement is a quenched growing-gap anti-concentration theorem:

For every mesoscopic D and every set A of primitive returns with gaps in (D/2,D], the orbit arithmetic forces

|A| << D^(2-eta)

for some eta > 0.

A stronger but cleaner possible target is a return-energy inequality:

sum_{D/2<d<=D} |Z_d|_primitive << D^(2-eta).

The reason this is the right target is that all existing tools either control fixed d, special d, averaged Frobenius statistics, or word-level consequences. The scattered adversary is designed precisely to avoid those projections. The missing object is a family-averaged cancellation theorem for the ordered Apery clock.

The fresh run-rigidity observation is useful but insufficient by itself: it would kill interval padding inside a single Z_d, because a long run forces a projective eigenvector chain. It leaves the variable-gap scattered construction untouched.

(ii) Possible blind spot in the question:

A future theorem may need to attack exactly that noncommutative clock structure rather than individual collision polynomials.
