# Q3704 — exact audit of the quotient-six blind-wrap suffix carrier

## Cold verdict

There are three different statements here, and they must not be conflated.

1. **A genuine positive height theorem exists for endpoint occupancy.** For a prescribed gap block \(I=[A,B]\), the nested suffix gcds of
   
   \[
   Y_d^+(m):=N_{6d}(m),\qquad Y_d^-(m):=N_{7d}(-m-1)
   \]
   
   have prescribed integral quotient carriers whose total logarithmic height is
   
   \[
   O_J(T\log T)=o_J(T^2/\log T).
   \]
   
   Every sufficiently large lower endpoint prime whose wrap threshold lies in or below the block divides one of those quotient carriers. This part is exact and does not use a selected set.

2. **That positive theorem is only a one-copy endpoint carrier.** Outside a fixed finite set of primes, its target predicate is exactly
   
   \[
   p\mid b_t\quad	ext{on the \(6\)-wrap side},\qquad
   p\mid b_r\quad	ext{on the \(7\)-wrap side}.
   \]
   
   It is therefore a repackaging of the original endpoint zero. In fact every quotient-six target prime already divides \(b_m\), so a one-prime-per-endpoint carrier of logarithmic height \(O(T)\) was available before introducing continuants.

3. **After natural factorial/boundary-content removal, the carrier loses the target prime.** For every block containing at least three consecutive gaps, the part of the gcd away from the explicit Jacobi boundary divides one fixed resultant
   
   \[
   ho_6=\operatorname{Res}_Z(N_6(Z),N_6(Z+6))\quad	ext{or}\quad
   ho_7=\operatorname{Res}_Z(N_7(Z),N_7(Z+7)).
   \]
   
   The wrap prime itself occurs only through the singular boundary factor \(m+h=7p\) or \(-m-1+h=-6p\). Its common \(p\)-adic exponent is at most \(6\), exactly the exponent in the Jacobi boundary. Thus ordinary removal of the explicit boundary gcd already removes the whole target \(p\)-part.

Consequently the scalar suffix-gcd construction gives no Smith capacity proportional to the number of selected neighbors. It records that the endpoint exists, but is blind to how many gaps \(d\) are selected. The smallest remaining gate is a **boundary-primitive multiplicity lift**: either a prescribed matrix giving one independent kernel vector for every selected \(d\), or an independent theorem showing that the excess endpoint degree is negligible.

No finite computation is used in this verdict.

## 2. The two quotient-six wraps

Fix a row \(m\) and a quotient-six lower endpoint prime \(p\). Write

\[
r=m-6p,\qquad t=p-1-r.	ag{2.1}
\]

For a selected endpoint,

\[
p\mid b_r,\qquad p\mid b_t.	ag{2.2}
\]

Both \(r\) and \(t\) are nonzero for a selected prime, since \(b_0=1\).

### 2.1 Forward \(6\)-wrap

Set

\[
h_p^+=t+1=7p-m.	ag{2.3}
\]

Since \(m\equiv r\pmod p\), reflection (1.2) and (1.4) give

\[
egin{aligned}
N_{h_p^+}(m)
 &\equiv N_{t+1}(r)\\
 &\equiv (-1)^tN_{t+1}(-1)\\
 &\equiv (-1)^t(t!)^3b_t\pmod p.
\end{aligned}	ag{2.4}
\]

Hence \(p\mid b_t\) implies \(p\mid N_{h_p^+}(m)\). At this index

\[
m+h_p^+=7p,	ag{2.5}
\]

so (1.1) gives

\[
N_{h_p^++1}(m)\equiv P(0)N_{h_p^+}(m)=5N_{h_p^+}(m)\equiv0\pmod p.	ag{2.6}
\]

Two consecutive zeros then propagate forward. Therefore

\[
oxed{
p\mid N_h(m)\quad	ext{for every }h\ge h_p^+,
}	ag{2.7}
\]

and in particular

\[
oxed{
p\mid N_{6d}(m)\quad	ext{whenever}\quad d\ge a_p^+:=\left\lceilrac{t+1}{6}ightceil.
}	ag{2.8}
\]

### 2.2 Backward \(7\)-wrap

Set

\[
h_p^-=r+1=m-6p+1.	ag{2.9}
\]

Now \(-m-1\equiv t\pmod p\), so

\[
egin{aligned}
N_{h_p^-}(-m-1)
 &\equiv N_{r+1}(t)\\
 &\equiv (-1)^rN_{r+1}(-1)\\
 &\equiv (-1)^r(r!)^3b_r\pmod p.
\end{aligned}	ag{2.10}
\]

At the singular step,

\[
-m-1+h_p^-=-6p.	ag{2.11}
\]

Exactly as above,

\[
oxed{
p\mid N_{7d}(-m-1)\quad	ext{whenever}\quad d\ge a_p^-:=\left\lceilrac{r+1}{7}ightceil.
}	ag{2.12}
\]

### 2.3 Exact coverage of a gap

The two singular lengths satisfy

\[
h_p^++h_p^-=p+1.	ag{2.13}
\]

A gap \(d\) is seen by at least one of the two wraps precisely when

\[
6d\ge h_p^+\quad	ext{or}\quad7d\ge h_p^-.	ag{2.14}
\]

In particular,

\[
13d\ge p+1\quad\Longrightarrow\quad	ext{at least one wrap applies}.	ag{2.15}
\]

If \(13d<p+1\), neither wrap is forced in general. Thus this candidate, by itself, does not cover that subrange.

### 2.4 Reset law after the singularity

Let

\[
C_k:=(k!)^3b_k.	ag{2.16}
\]

The Apéry recurrence is equivalent to

\[
C_0=1,\quad C_1=5,\qquad C_{k+1}=P(k)C_k-k^6C_{k-1}.	ag{2.17}
\]

If \(X+h_0\equiv0\pmod p\), then for every \(k\ge0\), uniqueness for (2.17) gives

\[
oxed{
N_{h_0+k}(X)\equiv N_{h_0}(X)\,(k!)^3b_k\pmod p.
}	ag{2.18}
\]

For the forward wrap take \((X,h_0)=(m,h_p^+)\); for the backward wrap take \((X,h_0)=(-m-1,h_p^-)\).

In the legal same-row neighbor range there is no second singularity. Indeed, if \(q=p+d\) is another quotient-six prime in row \(m\), then \(r-6d\ge0\), hence \(d\le r/6\). The offsets occurring in (2.18) are then \(<p\), so the factorials remain \(p\)-units.

## 3. A genuine prescribed suffix-quotient height theorem

Let \(I=[A,B]\cap\mathbf Z\) be a prescribed gap block. Define

\[
Y_d^+(m)=N_{6d}(m),\qquad Y_d^-(m)=N_{7d}(-m-1).	ag{3.1}
\]

For either sign, define the suffix gcds

\[
G_a^\pm(m;B):=\gcd_{a\le d\le B}|Y_d^\pm(m)|,\qquad A\le a\le B.	ag{3.2}
\]

They satisfy

\[
G_{a-1}^\pm\mid G_a^\pm,	ag{3.3}
\]

because \(G_{a-1}^\pm=\gcd(|Y_{a-1}^\pm|,G_a^\pm)\).

Use the following prescribed carriers:

```text
baseline:    C_A^± := G_A^±,
flag at a:   C_a^± := G_a^± / G_(a-1)^±     (A < a <= B).
```

Every carrier is an integer depending only on \(m,A,B\), not on the selected primes or selected gaps.

### 3.1 The sampled predecessor is genuinely flagged

For fixed \(s\), put

\[
\mathcal F_s:=\prod_{\delta=1}^{s}|N_\delta(-\delta)|
 =\prod_{\delta=1}^{s}((\delta-1)!)^3b_{\delta-1}.	ag{3.4}
\]

This is a fixed nonzero integer. Let \(h_0\) be one of the singular lengths above and

\[
a_0=\left\lceilrac{h_0}{s}ightceil,\qquad
\delta=h_0-s(a_0-1)\in\{1,\ldots,s\}.	ag{3.5}
\]

Assume \(p
mid\mathcal F_s\). Then

\[
oxed{
p
mid N_{s(a_0-1)}(X).
}	ag{3.6}
\]

Proof: suppose the preceding sampled term and \(N_{h_0}(X)\) both vanished. Before \(h_0\), all recurrence determinants are \(p\)-units, so \(N_{s(a_0-1)-1}(X)\) is a \(p\)-unit. Apply (1.9) with

\[
n=s(a_0-1),\qquad s=\delta.
\]

The two endpoint zeros force

\[
p\mid N_\delta(X+s(a_0-1)).	ag{3.7}
\]

But \(X+h_0\equiv0\pmod p\), hence

\[
X+s(a_0-1)\equiv-\delta\pmod p,	ag{3.8}
\]

and therefore \(p\mid N_\delta(-\delta)\), contradicting \(p
mid\mathcal F_s\). This proves (3.6).

For the forward carrier \(s=6\); for the backward carrier \(s=7\). Since the target primes are macroscopic, the finitely many primes dividing \(\mathcal F_6\mathcal F_7\) disappear for all sufficiently large \(T\).

### 3.2 Exact occupancy cover

Suppose \(a_p^+\le B\). If \(a_p^+\le A\), then \(p\mid C_A^+\). If \(A<a_p^+\le B\), (2.8) gives

\[
p\mid G_{a_p^+}^+,	ag{3.9}
\]

while the flag lemma gives

\[
p
mid G_{a_p^+-1}^+.	ag{3.10}
\]

Hence

\[
oxed{p\mid C_{a_p^+}^+.}	ag{3.11}
\]

The identical statement holds for \(C_{a_p^-}^-\).

Thus one may orient a lower endpoint deterministically toward the smaller of \(a_p^+\) and \(a_p^-\). This orientation is prescribed from \(m,p\) and does not use the selected neighbor set.

### 3.3 Telescoping height

The carrier product telescopes exactly:

\[
oxed{
C_A^\pm\prod_{a=A+1}^{B}C_a^\pm=G_B^\pm=|Y_B^\pm|.
}	ag{3.12}
\]

From (1.1), uniformly for \(|X|+h\ll_JT\),

\[
\log|N_h(X)|=O_J(h\log T).	ag{3.13}
\]

Indeed each recurrence step increases the absolute value by at most a factor \(O_J(T^6)\).
Since \(B\le T/21\), (3.12) yields

\[
oxed{
\sum_{a=A}^{B}\log C_a^+\ +\ \sum_{a=A}^{B}\log C_a^-
 =O_J(T\log T)
 =o_J(T^2/\log T).
}	ag{3.14}
\]

This is a real, unconditional height theorem. It is stronger than summing a separate \(O(T)\) factorial envelope for every endpoint.

It pays for each covered endpoint prime **once**.

## 4. Why the positive theorem is still only a repackaging

The suffix construction has no new endpoint arithmetic. This can be made exact with a fixed resultant.

For \(s\ge1\), define

\[
oxed{
ho_s:=\operatorname{Res}_Z(N_s(Z),N_s(Z+s)).
}	ag{4.1}
\]

The banked root-strip theorem puts all roots of \(N_s(Z)\) in

\[
-s<\Re Z<-1,
\]

whereas the roots of \(N_s(Z+s)\) lie in

\[
-2s<\Re Z<-s-1.
\]

Hence the two polynomials are coprime over \(\mathbf Q\), so

\[
ho_s
e0.	ag{4.2}
\]

For the two cases at hand,

\[
ho_6=\det\operatorname{Syl}(N_6(Z),N_6(Z+6))\quad(30	imes30),	ag{4.3}
\]

\[
ho_7=\det\operatorname{Syl}(N_7(Z),N_7(Z+7))\quad(36	imes36).	ag{4.4}
\]

### 4.1 Exact post-wrap equivalence

Let a legal post-wrap block contain three consecutive gaps \(d,d+1,d+2\). Suppose first that the singular seed

\[
A=N_{h_0}(X)	ag{4.5}
\]

is a \(p\)-unit. By (2.18), three sampled zeros at step \(s\) give three zeros of the nonzero reset solution at offsets \(k,k+s,k+2s\). The first pair forces

\[
p\mid N_s(k),	ag{4.6}
\]

and the second pair forces

\[
p\mid N_s(k+s).	ag{4.7}
\]

Thus \(p\midho_s\). Consequently, for \(p
midho_s\), a three-term post-wrap sampled gcd is divisible by \(p\) **only if** the singular seed is divisible by \(p\).

Combining this with (2.4) and (2.10), for all sufficiently large target-scale primes,

\[
oxed{
egin{aligned}
p\mid\gcd_{d\in J}N_{6d}(m)&\iff p\mid b_t,\\
p\mid\gcd_{d\in J}N_{7d}(-m-1)&\iff p\mid b_r,
\end{aligned}
}	ag{4.8}
\]

whenever \(J\) consists of at least three consecutive legal gaps lying after the corresponding threshold.

This is the precise sense in which the suffix gcd is a repackaging of \(b_t\) or \(b_r\): away from the fixed exceptional primes dividing \(ho_6ho_7\), it detects exactly the original endpoint zero and nothing about the selected upper neighbors.

### 4.2 The even simpler row carrier already exists

Every quotient-six endpoint prime divides the single row value \(b_m\). Indeed, \(m=6p+r\), and the Apéry Lucas law gives

\[
b_m=b_{6p+r}\equiv b_6b_r\equiv0\pmod p.	ag{4.9}
\]

Moreover

\[
\log b_m=O(m)=O(T).	ag{4.10}
\]

Thus the product of the **distinct** endpoint primes already has \(O(T)\) logarithmic height. The suffix-quotient construction does not improve this one-copy endpoint statement. Its only potential value would have been extra \(p\)-adic or linear-algebraic capacity for multiple neighbors; the next sections show that it has none after primitive normalization.

## 6. Height accounting: what is positive, what is critical, and what disappears

### 6.1 Primitive height is excellent but target-free

By (5.4), every length-\(\ge3\) block has primitive common content at most \(|ho_6|\) or \(|ho_7|\). Therefore an endpoint-by-endpoint product of primitive block gcds would have logarithmic height only

\[
O_J(T/\log T),	ag{6.1}
\]

far below the requested scale.

But (5.18) says that this primitive product contains none of the asymptotically large wrap primes. It is an excellent height theorem for the wrong integer.

### 6.2 Summing raw boundary envelopes is only critical

The squarefree radical of a raw block gcd is supported, up to the fixed \(ho_s\), on the factorial interval (5.10) or (5.11). Chebyshev's bound gives

\[
\log\operatorname{rad}D_{s,n}(X)=O_J(T).	ag{6.2}
\]

If this \(O(T)\) envelope is paid separately for \(O(T/\log T)\) candidate endpoints, one obtains only

\[
O_J(T^2/\log T),	ag{6.3}
\]

not little-\(o\).

The criticality is not an artifact of a poor constant. With \(p/m=x\in(1/7,1/6]\), the two singular lengths are asymptotically

\[
h_p^+=m(7x-1),\qquad h_p^-=m(1-6x).	ag{6.4}
\]

The exact continuum integral for the cheaper side is

\[
\int_{1/7}^{1/6}\min(7x-1,1-6x)\,dx=rac1{1092}.	ag{6.5}
\]

Hence a prime-number-theorem summation of a per-endpoint estimate proportional only to the boundary length naturally lands at a positive constant times \(m^2/\log m\). A little-\(o\) conclusion would require a new sparsity theorem for which boundary primes actually survive; the Jacobi/resultant identities do not provide it.

### 6.3 Nested suffixes avoid the critical sum—but only by paying once

The telescoping system in Section 3 does avoid (6.3): all its raw carrier heights sum to \(O(T\log T)\). The reason is exactly that a lower endpoint enters the nested chain once, at its first forced suffix.

That is useful only for

\[
\sum_{p:\,k_I(p)>0}\log p,	ag{6.6}
\]

where

\[
k_I(p):=\#\{q=p+d:\ d\in I,\ q	ext{ is a selected quotient-six neighbor}\}.	ag{6.7}
\]

The P3.2 edge mass is instead

\[
\sum_p k_I(p)\log p.	ag{6.8}
\]

The unaccounted amount is

\[
oxed{
\sum_p (k_I(p)-1)_+\log p.
}	ag{6.9}
\]

The blind-wrap tail is identical modulo \(p\) whether \(p\) has one selected neighbor, ten selected neighbors, or no selected upper neighbor at all. It is activated solely by the lower endpoint zero. Thus no scalar suffix gcd can infer \(k_I(p)\) from this forced tail.

Even its \(p\)-adic common exponent is fixed by (5.16) and is at most \(6\), independent of \(k_I(p)\). Splitting into dyadic subblocks can at best pay once per subblock; it does not give one independent copy for each selected gap inside a block.

## 7. Exact scoped no-go

The following is the strongest justified negative statement.

### Scalar blind-wrap no-go

Fix \(s=6\) with \(X=m\), or \(s=7\) with \(X=-m-1\). Work in a legal post-wrap gap block containing at least three consecutive gaps, and exclude the fixed finite prime set dividing

\[
6\cdot7\cdot\mathcal F_6\mathcal F_7ho_6ho_7.	ag{7.1}
\]

Then:

1. a target endpoint prime divides the sampled gcd exactly when the corresponding original endpoint Apéry number \(b_t\) or \(b_r\) vanishes;
2. the common \(p\)-adic exponent is at most \(6\) and is independent of the number and positions of selected upper neighbors;
3. the entire target \(p\)-part is removed by the explicit Jacobi boundary gcd;
4. after boundary saturation, the remaining block gcd divides the fixed integer \(ho_6\) or \(ho_7\).

Therefore no construction using only

```text
scalar gcds of N_(6d)(m) or N_(7d)(-m-1),
nested suffix quotients of those scalar gcds,
renewal/Jacobi elimination, and
ordinary factorial/boundary-content removal
```

can provide boundary-primitive valuation \(v_p\ge k_I(p)\) for all selected neighbors.

This is deliberately scoped. It does **not** rule out:

- a matrix/Fitting carrier with gap-dependent independent vectors;
- a confluent or divided-state construction retaining a nontrivial Bockstein;
- an identity using the upper prime \(q=p+d\) and its selected zero, rather than only the lower endpoint wrap;
- a separate theorem controlling the degree excess (6.9).

## 8. The smallest remaining gate

The occupancy carrier pays the first neighbor of each lower endpoint. The exact missing statement can therefore be isolated as either of the following equivalent endgames.

### Arithmetic degree-excess gate

Prove, for every fixed \(J\) and every macroscopic dyadic block \(I\subset(T/J,T/21]\),

\[

\sum_p (k_I(p)-1)_+\log p=o_J(T^2/\log T).

Together with the suffix occupancy carrier, this closes the block.

### Boundary-primitive multiplicity carrier gate

Construct a prescribed integer matrix \(M_I(m)\), independent of the selected set, such that every selected gap \(d\) at lower endpoint \(p\) supplies a distinct independent kernel vector modulo \(p\), and

## 9. Final classification

- **Raw nested suffix quotients:** true, prescribed, selected-set-independent, aggregate height \(O_J(T\log T)\); carry endpoint occupancy once.
- **Arithmetic novelty:** none. Away from fixed primes, the wrap gcd condition is equivalent to \(p\mid b_t\) or \(p\mid b_r\), and every endpoint already divides \(b_m\).
- **Primitive block gcd:** fixed resultant height \(O(1)\), but all large target primes are removed with the explicit singular boundary.
- **Dyadic suffix blocks:** same obstruction; they can duplicate occupancy by block, not create gapwise independent capacity.
- **P3.2 status:** not closed. The unresolved object is precisely the multiplicity/degree-excess gate (8.1) or its Smith/Fitting realization (8.2)–(8.3).
