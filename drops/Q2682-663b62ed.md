# 2. Exact reciprocal form of the Dirichlet shell

Write

```text
K_N(t) = sum_(N<m<=2N) e(-m t).
```

The ordered unequal-prime shell is

```text
E_neq
 = sum_(p!=ell) (log p log ell)/(p ell)
   sum_(1<=a<p) sum_(1<=b<ell)
     F_p(a) conj(F_ell(b)) K_N(a/p-b/ell).
```

For distinct primes put

```text
k = < a*ell - b*p >_(p*ell),
```

the least absolute representative modulo `p*ell`.  Then the map

```text
(a,b)  <->  k
```

is a bijection between

```text
1<=a<p, 1<=b<ell
```

and the nonzero residues `k mod p*ell` satisfying

```text
gcd(k,p*ell)=1.
```

Indeed

```text
a = k*ell^(-1) mod p,
b = -k*p^(-1) mod ell.
```

Because the zero-set indicator is real,

```text
conj(F_ell(b)) = F_ell(-b).
```

Therefore the exact shell becomes

```text
E_neq
 = sum_(p!=ell) (log p log ell)/(p ell)
   sum_(0<|k|<=p*ell/2, gcd(k,p*ell)=1)
     F_p(k*ell^(-1)) F_ell(k*p^(-1))
     K_N(k/(p*ell)).                       (2.1)
```

This is the exact version of the reciprocal parametrization in the question.  The principal Dirichlet range is

```text
|k| < p*ell/N ~ N,
```

but keeping the full signed `k` range is useful for the dyadic normalization below.

For a dyadic block `K<|k|<=2K`, with `p,ell~N`,

```text
|K_N(k/(p*ell))|
  << H_K := min(N, N^2/K).                 (2.2)
```

Thus no information is lost by treating the full shell dyadically; the near range uses `H_K=N`, and the farther ranges acquire the harmonic factor `N^2/K`.

# 3. The same CRT unit occurs on both sides

There is a simple identity which is easy to miss:

```text
v := p + ell.
```

Since

```text
v = ell mod p,
v = p   mod ell,
```

we have

```text
ell^(-1) mod p = v^(-1) mod p,
p^(-1) mod ell = v^(-1) mod ell.
```

Hence

```text
F_p(k*ell^(-1)) F_ell(k*p^(-1))
 = F_p(k*v^(-1)) F_ell(k*v^(-1)),
 v=p+ell.                                  (3.1)
```

The reciprocal shell is therefore sampling two different finite-field functions at one **common CRT unit**.  The difficulty is that it samples only the special unit `p+ell`, rather than averaging over the entire group `(Z/(p*ell)Z)^*`.

This observation gives a natural exact centering.

# 4. Exact nonzero-frequency centering

Since `b_0=1`, one has

```text
0 notin Z_p.
```

Consequently, for every nonzero frequency set,

```text
sum_(a in F_p^*) F_p(a)
 = sum_(r in Z_p) sum_(a!=0) e_p(a r)
 = -Z(p).
```

Put

```text
mu_p = Z(p)/(p-1),
G_p(a) = F_p(a) + mu_p,       a in F_p^*.  (4.1)
```

Then exactly

```text
sum_(a in F_p^*) G_p(a) = 0.                (4.2)
```

Parseval also gives the sharp `L^2` normalization

```text
sum_(a!=0) |G_p(a)|^2
 = p*Z(p) - p*Z(p)^2/(p-1)
 <= p*Z(p).                                 (4.3)
```

Now fix distinct `p,ell` and nonzero `k`.  CRT factors the complete unit average:

```text
sum_(v in (Z/(p*ell)Z)^*)
  G_p(k*v^(-1) mod p)
  G_ell(k*v^(-1) mod ell)

 = [sum_(u in F_p^*) G_p(k*u^(-1))]
   [sum_(w in F_ell^*) G_ell(k*w^(-1))]
 = 0.                                       (4.4)
```

So the relevant product has **exact zero complete mean**.  Formula (3.1) says that the shell evaluates this zero-mean product only along the arithmetic section

```text
v=p+ell.                                   (4.5)
```

This is the cleanest formulation of the missing horizontal mixing.

For a dyadic `k` interval of length `K`, multiplication by `ell^(-1)` permutes residues modulo `p`; from (4.3), Cauchy gives

```text
sum_(k~K) |G_p(k*ell^(-1))|
 << sqrt( K*(K+p)*Z(p) ).                   (5.3)
```

Expand

```text
F_p F_ell
 = G_p G_ell - mu_p G_ell - mu_ell G_p + mu_p mu_ell.  (5.4)
```

Using (2.2), (5.2), and (5.3) over all dyadic `k` ranges gives

```text
mixed mean terms
```

# 6. Additive reciprocity: the exact Kloosterman-fraction phase

Expand one uncentered product first.  For `r in Z_p`, `s in Z_ell`, choose inverses

```text
ellbar*ell = 1 mod p,
pbar*p     = 1 mod ell.
```

The elementary CRT reciprocity identity is

```text
ellbar/p + pbar/ell = 1/(p*ell) mod 1.
```

Therefore

```text
e_p(k*ellbar*r) e_ell(k*pbar*s)
 = e(k*r/(p*ell))
   e_ell(k*(s-r)*pbar).                     (6.1)
```

Equivalently,

```text
F_p(k*ellbar) F_ell(k*pbar)
 = sum_(r in Z_p) sum_(s in Z_ell)
     e(k*r/(p*ell))
     e_ell(k*(s-r)*p^(-1)).                 (6.2)
```

This is a genuine Kloosterman fraction in the variable `p mod ell` whenever

```text
s-r != 0 mod ell.
```

The factor

```text
e(k*r/(p*ell))
```

is a slowly varying Archimedean phase: throughout `p,ell,k,r~N`, its derivatives at the natural dyadic scale are bounded.

So additive reciprocity **does** put the oscillatory core into the classical DFI/Bettin--Chandee shape.  The failure occurs in the coefficient structure, not in the phase.

There is also a real degenerate slice:

```text
s=r.
```

On that slice the Kloosterman phase in (6.1) disappears completely.  It records two large characteristics hitting the same coefficient index.  A blanket Kuznetsov claim which ignores this slice cannot be correct.

# 7. Why Bettin--Chandee / Kuznetsov does not close after (6.2)

For fixed integers `(r,s,k)` with `s!=r`, define

```text
L_r = #{p~N : r<p and p|b_r}.
```

Then

```text
sum_r L_r = T.                              (7.1)
```

For fixed `(r,s,k)`, (6.1) gives a balanced bilinear Kloosterman-fraction sum in `p,ell` with separated coefficient supports

```text
alpha_p = 1_{r in Z_p},
beta_ell = 1_{s in Z_ell}.
```

The classical Bettin--Chandee bound (and the DFI predecessor) therefore really is applicable **at this fixed `(r,s,k)` level**.  In the balanced range, with numerator `|k(s-r)|<=O(N^2)`, it gives schematically

```text
sum_(p,ell~N)
  alpha_p beta_ell e_ell(k(s-r)*p^(-1))

 << N^(19/20+eps) * sqrt(L_r L_s),          (7.2)
```

with the smooth factors from (6.1) handled by partial summation.

But summing (7.2) over the actual incidence variables is fatal.  There are `O(N)` relevant `k`, and

```text
(sum_r sqrt(L_r))^2 <= N*T.
```

Therefore the direct fixed-parameter use of Bettin--Chandee costs

```text
N * N^(19/20) * N*T
 = N^(59/20+eps) T,                         (7.3)
```

before the shell normalization.  This is nowhere near the incidence-scale bound needed below.

Trying the trilinear Bettin--Chandee theorem does not fix the quantifier problem.  For fixed `r,s`, the numerator is

```text
a = k*(s-r),
```

but after `r,s` are also summed, the coefficient of `a` depends on **both** moduli through the conditions

```text
r in Z_p,
s in Z_ell.
```

It is not a single coefficient sequence `nu_a` independent of `p,ell`, which is a required hypothesis of the trilinear theorem.

Recent improvements for bilinear Kloosterman fractions with arbitrary **separated** coefficient sequences do not change this conclusion.  They improve the exponent in (7.2), not the missing simultaneous cancellation over `(r,s)`.

Likewise, the very recent non-Abelian-amplification theorem for Type-II sums of classical Kloosterman sums with a **fixed composite modulus** (including a product of two equal-size primes) is not in the right aspect: here `p` and `ell` themselves are the two independently varying characteristics, and the coefficient-zero masks change with each characteristic.

# 8. Poisson is exactly at the self-dual length

There is a second exact way to see the obstruction.

For fixed `p,ell`, let

```text
Z_(p,ell)
 = {x mod p*ell : x mod p in Z_p,
                     x mod ell in Z_ell}.
```

CRT gives

```text
F_p(k*ell^(-1)) F_ell(k*p^(-1))
 = sum_(x in Z_(p,ell)) e_(p*ell)(k*x).     (8.1)
```

Thus the reciprocal product is simply the additive Fourier transform of the CRT product set.

But

```text
p*ell ~ N^2,
length in k ~ p*ell/N ~ N = sqrt(p*ell).
```

Poisson completion is therefore exactly at the square-root / Pólya--Vinogradov threshold.  The dual length is again

```text
(p*ell)/N ~ N.
```

So Poisson merely returns another shell-length sum.  Without extra information about the Fourier distribution of `Z_(p,ell)`, there is no length saving.

This also explains why the ordinary additive large sieve stops at the wrong scale: the Farey spacing is `~N^(-2)`, while the shell length is only `N`.

# 9. Conductor audit: `F_p` is not a fixed bounded-rank trace family

For one **fixed** prime, there is a tautological trace-function realization:

```text
F_p(a) = sum_(r in Z_p) e_p(a r)
```

is the trace of the direct sum

```text
oplus_(r in Z_p) L_psi(r X).
```

Hence its rank and conductor are

```text
O(Z(p)).                                    (9.1)
```

This is not uniform under the currently proved

```text
Z(p) << p^(2/3).
```

More importantly, this realization is tautological: its Artin--Schreier slopes are **the zero positions themselves**.  As `p` changes, the sheaf changes by precisely the horizontal data we are trying to control.  There is no compatible fixed family over one base whose varying-characteristic trace specializes to these `F_p`.

### The doublet check

On the actual doublet sector

```text
Z_p={r_p,p-1-r_p},
```

`oracleA_result.tex` correctly observes that `F_p` is rank `2`, uniformly bounded conductor: it is a direct sum of two Artin--Schreier traces.  Thus the growing-conductor objection disappears completely there.

Nevertheless the same file proves the **reflected anchored obstruction**: the artificial doublets

```text
Z_p^*={2N mod p, -2N-1 mod p}
```

have all of the following:

```text
size 2,
reflection symmetry,
no adjacent residues,
uniform rank-2 conductor,
the same generic large-sieve geometry,
```

but the short-arc target fails by a factor `N^(1-o(1))`, and the centered block dispersion is `>>N^2`.

Therefore no theorem whose hypotheses are only

```text
bounded rank/conductor
+ palindromy
+ no adjacency
+ local Fourier bounds
```

can prove the desired shell cancellation.  The actual Apéry horizontal motion is indispensable.

# 10. Why CFVZ does not provide the missing trace family

The CFVZ factorization in `hasse_franel_descent.tex` is exact:

```text
A_p(X) = sum_(r=0)^(p-1) b_r X^r
       = Delta(X)^epsilon_p B_p(X)^2.       (10.1)
```

But `Z_p` is the set of zero **coefficients** `b_r`, not the zero set of the function `A_p(X)` in `X`.

This distinction is decisive for conductor.

For `a!=0`, Fermat gives the exact coefficient-zero detector

```text
1_{b_r=0} = 1 - b_r^(p-1)
```

inside `F_p`, hence

```text
F_p(a)
 = - sum_(r=0)^(p-1) b_r^(p-1) e_p(a r).   (10.2)
```

Equivalently,

```text
1_{b_r=0}
 = (1/p) sum_(t mod p) e_p(t*b_r).         (10.3)
```

Neither formula has bounded geometric complexity in the coefficient index `r`: (10.2) uses the `(p-1)`st power, while (10.3) requires the nonlinear sequence `r -> b_r mod p`.  The Apéry recurrence makes that sequence highly structured, but it is not a bounded-degree rational function of `r`; the degree of its naive interpolation is `~p`.

Thus (10.1) does **not** verify the hypothesis needed by fixed-conductor trace-function large sieves.  It factors the Hasse polynomial, but coefficient-zero extraction is a defining-characteristic nonlinear operation.

The fixed primitive K3/Mellin system is useful for the Mellin coefficients themselves.  Passing from those coefficients to

```text
1_{coefficient=0}
```

is exactly the nonlinear step for which no bounded-complexity horizontal sheaf is currently available.

# 11. The exact unavailable estimate: TCUS(theta)

The preceding centering suggests a standard-scale target which is weaker than the old short-arc statement and tailored only to the requested `o(N^2)` shell bound.

Put

```text
T_N = sum_(p~N) Z(p).
```

For a dyadic signed `k` block `K<|k|<=2K`, set

```text
H_K = min(N,N^2/K).
```

Absorb all harmless dyadic ratios into the exact bounded weight

```text
omega_(p,ell,k)
 = [N^2/(p*ell)]
   [log p log ell/(log N)^2]
   [K_N(k/(p*ell))/H_K],                    (11.1)
```

and set it to zero unless

```text
p!=ell,
gcd(k,p*ell)=1,
|k|<=p*ell/2.
```

On `p,ell~N`, (2.2) gives

```text
|omega_(p,ell,k)| << 1.                     (11.2)
```

Define the centered common-unit correlation

```text
C_K
 = sum_(K<|k|<=2K)
   sum_(p!=ell)
     omega_(p,ell,k)
     G_p(k*(p+ell)^(-1) mod p)
     G_ell(k*(p+ell)^(-1) mod ell).         (11.3)
```

By Section 3 this is exactly the reciprocal centered product.

## TCUS(theta)

There exists a fixed `theta` such that, uniformly over every dyadic `K` occurring in the signed reciprocal decomposition,

```text
Re C_K
 << K * N^(theta+o(1)) * T_N.               (TCUS_theta)
```

Only this **one-sided** version is needed; no absolute pairwise bound is required.

### Why this closes the shell

The centered dyadic contribution is exactly

```text
E_K^cent
 = (log N)^2/N^2 * H_K * C_K.              (11.4)
```

For `K<=N`,

```text
H_K=N,
sum_dyadic K << N.
```

For `K>N`,

```text
H_K*K=N^2,
```

and there are only `O(log N)` dyadic blocks.  Thus `(TCUS_theta)` implies

```text
Re E_neq^cent
 << N^(theta+o(1)) * (log N)^3 * T_N.       (11.5)
```

Using (5.1),

```text
Re E_neq
 << N^(8/5+theta+o(1)).                     (11.6)
```

Therefore

```text
theta < 2/5
```

is sufficient for

```text
Re E_neq = o(N^2).                          (11.7)
```

There is a large margin: the random/square-root incidence scale corresponds morally to `theta=0` and would give a shell bound `N^(8/5+o(1))`.

If one uses only

```text
Z(p)<<p^(2/3)
```

and the prime number theorem, then

```text
T_N << N^(5/3)/log N,
```

so the same argument closes for every

```text
theta < 1/3.                                (11.8)
```

Thus the exact power threshold does not depend on the disputed fine logarithm in the first moment.

# 12. What TCUS is saying geometrically

For fixed `p,ell,k`, equation (4.4) says

```text
average over every CRT unit v = 0.
```

`TCUS(theta)` asks for a very weak quantitative substitute when one samples only

```text

```

as the two prime moduli vary.

It is also not merely the old `(SDC)` with a new name:

- the exact nonzero-frequency means have already been removed;
- the right side is the incidence mass `T_N`, not `Q_P`;
- a polynomial loss `N^theta` is allowed;

- the statement is explicitly a horizontal restriction/mixing estimate for the common-unit section.

This is the amount of cancellation actually needed at the competition scale, not independence-scale AMTD.

# 13. Why the current single-prime inputs do not imply TCUS

The strongest banked local Fourier theorem is, up to the harmless normalization variant,

```text
sum_(1<=|k|<=K) |F_p(k)|^2
 << K*Z(p) + p^2/K.                         (13.1)
```

This controls concentration inside one characteristic.  In `(TCUS_theta)`, however, multiplication by

```text
(p+ell)^(-1) mod p
```

changes with the *other* prime.  Parseval is invariant under each such multiplication and therefore does not correlate different values of `ell`.

The exact unit-group identity from `codex_result_002.md` becomes, after the centering (4.1), precisely (4.4): the **complete** unit average vanishes.  But the prime-pair section `p+ell` gives only one unit for each pair.  No current theorem compares that section with the complete unit average.

The multiplicative-Sidon / line-section computations in `codex_result_003.md` and `codex_result_004.md` are striking evidence that actual zero sets have the right internal geometry, but they are finite evidence.  Moreover they concern ratios *inside one* `Z_p`; `TCUS` couples two independently varying characteristics.  Promoting those scans to a theorem would still require a horizontal step.
