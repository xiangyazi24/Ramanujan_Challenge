# Q8812: Self-amplification and the isolated-spike barrier

## Executive conclusion

The isolated-spike barrier is real. The known codegree argument is fundamentally a statement about pairs of exceptional integers, while the desired conclusion requires a mechanism that turns one exceptional integer into another. None of the four proposed mechanisms currently gives this amplification. The strongest conclusion is:

* recurrence gives **repulsion**, not propagation;
* the Wronskian gives **anti-correlation**, not a contradiction;
* CRT resonance gives a rigid exceptional congruence class, but shifts away from it;
* Lucas carry propagation is probabilistically unfavorable for producing neighbors.

A new ingredient is required: either a long-range correlation theorem for the zero sets Z_p, or a global height/Diophantine argument that forbids isolated large gcd spikes.

## 1. Recurrence propagation

Suppose p divides b_n. The recurrence gives

b_{n+1} ≡ - n^3/(n+1)^3 b_{n-1} (mod p).

Therefore, away from the singular residue n ≡ -1 mod p,

p|b_n implies p|b_{n+1} iff p|b_{n-1}.

The known no-adjacent-zero theorem excludes this, so a bad prime for n is automatically not a bad prime for n+1. This is a local exclusion law.

However, it does not imply that another prime q divides b_{n+1}. The set of bad primes for n+1 is controlled by Z_q shifted by one, and there is no recurrence identity connecting unrelated primes.

Hence mechanism (A) fails in its naive form.

## 2. Wronskian constraint

The Apéry Wronskian gives

G_n G_{n+1} | Omega_n,

with log Omega_n = O(n). Therefore a large G_n forces a smaller adjacent G_{n+1}.

But the conjecture requires proving

log G_n=o(n),

not merely proving that two consecutive values cannot both be large. The inequality permits alternating spikes:

large, small, large, small, ...

Iterating does not improve the exponent because each step only transfers the available Wronskian budget.

So (B) is a barrier against clusters, not isolated spikes.

## 3. CRT resonance

If n has k bad primes p_i, then

n mod p_i in Z_{p_i}

for all i. Thus n belongs to a CRT class modulo

P = product p_i.

For n+1,

(n+1) mod p_i = r_i+1,

and the no-adjacent-zero theorem gives

r_i+1 not in Z_{p_i}.

Therefore the original k primes are eliminated at the next integer.

This is the opposite of self-amplification: exceptional n creates an exclusion neighborhood. The only possible rescue would be proving that the many excluded primes force many new primes. No known theorem gives such a replacement principle.

## 4. Lucas carry propagation

Write n in base p. Lucas gives

b_n = product b_{digits} (mod p).

A zero occurs when one digit lands in the forbidden set Z_p^(1). Passing to n+1 modifies digits through carries.

Because |Z_p^(1)| is expected bounded, carries usually move digits away from zero states rather than preserving them. This again predicts decorrelation, not amplification.

## 5. What would actually prove self-amplification?

A sufficient theorem would look like:

If M(n) >= c n/log n, then for some |h|<=C log n,

M(n+h) >= c' n/log n.

The needed object is therefore a stability theorem for the family of events

E_p(n) = [n mod p in Z_p].

One would need a statement that a dense intersection of E_p(n) cannot be isolated.

Current tools only prove the opposite direction:

* pairwise codegree bounds show dense intersections are rare;
* fourth moments control the average number of intersections;
* sieve estimates control typical n.

None control a single exceptional CRT intersection.

## 6. More promising replacement: propagation in scale, not in n

The right amplification may not be n -> n+1. A large M(n) involves many primes p > sqrt(n). These primes determine many small residues n mod p. Instead of neighboring integers, one could study:

* nearby quotient cells floor(n/p);
* base-p digit transitions;
* blocks n + h where h has many small prime factors.

The Apéry block congruence

(p^3 a_{qp+r}, b_{qp+r}) = b_r(a_q,b_q) mod p

suggests that exceptional behavior may propagate through quotient structure rather than additive shifts.

This is the direction where a genuine self-amplification theorem might exist.

## 7. Relation to large values estimates

A large deviation theorem such as

#{n<=N: M(n)>V} << N exp(-c V log V)

would bypass isolated spikes. It requires controlling all high moments or exponential moments.

The numerical Poisson/sub-Poisson evidence suggests this is plausible, but proving it requires high-order correlations of the sets Z_p.

The k-th moment involves k-tuples of primes and asks for control of intersections

Z_{p_1} x ... x Z_{p_k}.

The known pairwise method corresponds only to k=2. An exponential moment requires uniform control for growing k.

## Final assessment

The proposed self-amplification route is unlikely to work through (A)-(D) in their current form. All four mechanisms are exclusion mechanisms:

* recurrence: zero repulsion;
* Wronskian: adjacent anti-correlation;
* CRT: shifts destroy the same bad primes;
* Lucas: carries randomize digits.

The isolated-spike barrier is therefore not a missing local argument. It is the absence of a theorem converting many simultaneous modular coincidences into a contradiction.

The most promising next targets are:

1. an exponential-moment bound for S(n);
2. a high-order codegree theorem for Z_p;
3. a geometric description of Z_p^(1) giving bounded-complexity forbidden states.

Any one of these would eliminate isolated spikes. The direct recurrence-propagation strategy does not appear sufficient.
