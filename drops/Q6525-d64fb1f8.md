# Problem 3.2 — exact post-OR upper-zero deficit on the strict crossed fibre

## Verdict

The marked-incidence fibre-one theorem does **not** supply the missing estimate for `UPHITDEF_R`, even after the fixed-left Palm is retained. There are two independent obstructions.

1. A fibre-one theorem for a marked **hit incidence** is a row-degree statement. The desired inverse outer-star estimate is a column-degree statement after several outer coordinates have been forgotten. Retaining the fixed-left Palm removes only the reuse coming from that one coordinate; it does not bound reuse through the remaining outer coordinates.
2. Even if one grants the stronger, presently unverified statement that every actual upper zero has bounded inverse outer-star degree, this bounds the number of **hits from above**. `UPHITDEF_R` is a lower-tail/no-hit statement. On a dark fibre there is no marked hit incidence to invert, so hit-side fibre-one is vacuous there.

The exact affine/cycle incidence does nevertheless give a sharp proved subregion and a useful exact reduction. If

```text
F_xi = strict set of distinct candidate states,
U_xi = strict physical-OR support of actual upper zeros,
S_xi = exact ambient state set after all strict masks,
m_xi = #F_xi,
u_xi = #U_xi,
s_xi = #S_xi,
H_xi = # (F_xi intersect U_xi),
```

then

```text
H_xi >= m_xi + u_xi - s_xi.                          (V1)
```

Consequently

```text
m_xi + u_xi > s_xi       => H_xi > 0,
m_xi + u_xi >= s_xi + R  => H_xi >= R.               (V2)
```

These statements preserve the physical OR and every strict mask. They are also optimal from the three cardinalities alone.

The sharp non-equivalent successor I recommend is not another positive moment of `Z(q)`. It is the selected-miss lower-tail theorem

```text
UPSEL-MISS_R:

sum_(p) (log p)
  sum_(xi in strict crossed fibres) W_xi
    1_(m_xi>R) (R-H_xi)_+

  << R * RHS_Q6497(R).                                (V3)
```

Here `W_xi` and `RHS_Q6497(R)` are exactly the inherited weight and target from Q6497; no normalization or mask is changed. Pointwise,

```text
R * 1_(m_xi>R and H_xi=0)
  <= 1_(m_xi>R) (R-H_xi)_+,                          (V4)
```

so `(V3)` implies `UPHITDEF_R`. It is genuinely non-equivalent: a fibre with `1 <= H_xi < R` is bright and contributes nothing to `UPHITDEF_R`, but contributes to `(V3)`.

The correct dual route to `(V3)` would require a bounded-reuse map from **selected missed candidates** to exact complement certificates. The theorem in `Q32_Q6_C4_UPPER_MARKED_INCIDENCE_EQUIVALENCE.md`, insofar as it concerns marked hit incidences, is not such a map.

## 2. Exact polarity obstruction for the existing `Z(q)` moments

### Lemma 2.1 — every positive `Z`-moment vanishes on the dark support

Let `Phi` be any nonnegative function with `Phi(0)=0`. Define

```text
M_Phi(xi) = sum_(q in F_xi) Phi(Z_xi(q)).             (2.1)
```

If `H_xi=0`, then `Z_xi(q)=0` for every `q in F_xi`, hence

```text
M_Phi(xi)=0.                                          (2.2)
```

This includes all positive power moments

```text
sum_q Z_xi(q)^k,    k>=1,                             (2.3)
```

all factorial moments, and every nonnegative polynomial in the separate `Z_xi(q)` having zero constant term.

Therefore an upper bound for any collection of such moments cannot upper-bound the number of dark fibres. One may freely adjoin arbitrarily many all-zero fibres without changing any of the quantities in `(2.1)`–`(2.3)`.

This is not a numerical weakness in the currently proved estimates. It is an exact information-direction failure.

### Why fibre-one does not repair the polarity

Suppose the marked-incidence theorem makes every `Z_xi(q)` binary. Then

```text
Z_xi(q)=u_xi(q),
H_xi=sum_q Z_xi(q).                                   (2.4)
```

This removes upper multiplicity but changes no polarity: the moment in `(2.4)` is still zero on precisely the fibres that `UPHITDEF_R` must bound.

A constant term can of course make a moment nonzero on misses, but then it is explicitly counting the complement:

```text
1-u_xi(q) = 1-1_(Z_xi(q)>0).                          (2.5)
```

That is the correct lower-tail object, not a consequence of a positive `Z`-moment.

### Exact all-dark product

The Boolean can also be written

```text
1_(H_xi=0)
 = product_(q in F_xi) (1-u_xi(q)).                   (2.6)
```

Thus a moment expansion of darkness is an alternating inclusion-exclusion expansion of all orders. First and second positive moments of `Z` do not control `(2.6)` without an additional negative-dependence, covering, or expansion theorem on the same strict fibre.

## 3. Exact affine/cycle incidence and complement polynomials

This is the strongest unconditional replacement for a marginal-density argument.

### 3.1 Support-polynomial identity

Let `S_xi` be the exact finite ambient upper-state set in which both the strict candidate states and the strict actual-zero images live. Put

```text
s_xi = #S_xi,
u_xi = #U_xi.
```

Encode the states in a field containing their distinct affine coordinates. Define the monic squarefree support polynomials

```text
Psi_xi(T) = product_(a in S_xi) (T-a),
C_xi(T)   = product_(q in F_xi) (T-q),
A_xi(T)   = product_(z in U_xi) (T-z),
B_xi(T)   = product_(a in S_xi \ U_xi) (T-a).         (3.1)
```

Then

```text
Psi_xi = A_xi B_xi,
deg C_xi = m_xi,
deg A_xi = u_xi,
deg B_xi = s_xi-u_xi.                                 (3.2)
```

Because all three support sets are reduced,

```text
H_xi = deg gcd(C_xi,A_xi).                            (3.3)
```

Moreover,

```text
H_xi=0
  <=> gcd(C_xi,A_xi)=1
  <=> F_xi subset S_xi\U_xi
  <=> C_xi divides B_xi.                              (3.4)
```

This is the exact complement-polynomial reformulation of the post-OR dark Boolean.

It reveals both the useful fact and the obstruction:

```text
hit:   C_xi and A_xi have a common root;
dark:  the whole candidate polynomial divides the complement B_xi.
```

A resultant or common-divisor carrier detects the first condition by vanishing. The dark condition is generic coprimality between `C_xi` and `A_xi`, or equivalently divisibility into a generally high-degree complement polynomial. A nonzero resultant is not rare for arbitrary reduced supports.

### 3.2 Sharp incidence lower bound

From inclusion-exclusion inside the exact universe,

```text
H_xi
 = #(F_xi intersect U_xi)
 = m_xi+u_xi-#(F_xi union U_xi)
 >= m_xi+u_xi-s_xi.                                  (3.5)
```

This proves `(V1)`.

Equivalently, every missed candidate is a root of `B_xi`, so

```text
m_xi-H_xi
 = #(F_xi\U_xi)
 <= deg B_xi
 = s_xi-u_xi.                                        (3.6)
```

For every integer `R>=1`, `(3.5)` gives the hinge bound

```text
1_(m_xi>R) (R-H_xi)_+
 <= 1_(m_xi>R)
      (s_xi-u_xi-(m_xi-R))_+.                         (3.7)
```

Thus there are two exact zero-contribution regions:

```text
m_xi+u_xi>s_xi
  => H_xi>0
  => no UPHITDEF_R contribution;                     (3.8)

m_xi+u_xi>=s_xi+R
  => H_xi>=R
  => no selected-miss lower-tail contribution.       (3.9)
```

These are actual proved subregions, not heuristics.

### 3.3 Optimality of the incidence region

The inequality `(3.5)` is sharp using only `(s_xi,m_xi,u_xi)`. Whenever

```text
m_xi+u_xi<=s_xi,                                     (3.10)
```

one can choose an `m_xi`-element candidate set and a disjoint `u_xi`-element zero support inside an `s_xi`-element universe. Then `H_xi=0` and equality holds in `(3.5)` whenever the union fills the chosen portion of the universe.

If reflection-fixed states have already been deleted and the strict universe is a union of free two-cycles, the same model can be chosen as a union of whole reflection orbits whenever the relevant cardinalities have the required parity. Any residual fixed-point discrepancy is `O(1)` and supplies no power saving.

Hence no theorem depending only on the exact sizes of the candidate support, zero support, and ambient cycle can improve `(3.5)` outside an explicitly smaller structured subregion.

### 3.4 Why coefficient height of the complement does not yet help

The polynomial `B_xi` is an exact object, but its degree is the number of missing ambient upper states. In the full affine universe one may write, for example,

```text
B_xi = Psi_xi / A_xi.                                 (3.11)
```

This does not make `B_xi` a low-complexity carrier. Its coefficient height under an integer lift can be exponential in its degree, while over the finite field every nonzero coefficient is already bounded trivially. A proof that `C_xi | B_xi` is rare would require an additional theorem saying that the actual `B_xi` lies in a much smaller algebraic family than arbitrary reflection-compatible complements. No such restriction follows from the current `Z(q)` moments or from hit-incidence fibre-one.

The formal Bézout identity

```text
X_xi C_xi + Y_xi A_xi = 1                            (3.12)
```

on a dark fibre is likewise generic. Bounds on the degrees of `X_xi,Y_xi` are automatic and do not make the existence of `(3.12)` sparse.

## 4. Common-divisor support has the same polarity

In any Q6497 subcase where a candidate large prime `q` is hit exactly when it divides an integer carrier `G_xi`, let



The dark condition is

```text

```

The missed candidate product is

```text

 = Q_xi / gcd(Q_xi,rad(G_xi)),                       (4.4)
```

and

```text

```

If every candidate prime lies in one dyadic window `q asymp P`, then

```text

 = (m_xi-H_xi) log P + O(m_xi).                       (4.6)
```

This is exact support bookkeeping, but it gives a death certificate for the proposed height direction:

```text
H_xi log P
 <= log gcd(Q_xi,rad(G_xi))
 <= log |G_xi|.                                       (4.7)
```

An upper bound on `log |G_xi|` or on its radical bounds the number of hits from above. It does not bound the number of misses from above. On a dark fibre `(4.7)` reads `0<=log|G_xi|`, while `(4.6)` is maximal.

## 5. Apéry palindrome and reflection

Let `rho` denote the proved Apéry reflection on the relevant regular cycle. Before strict masking it has the form

```text
pi(N-r)=pi(r).                                        (5.1)
```

There are only three sound ways to use it here.

### 5.1 Exact forced-reflection subregion

If a strict candidate state and its reflected actual-zero witness both survive every orientation, chart, physical, sign, primitive, source, and range predicate, then that candidate is hit. Any such subregion is automatically bright and may be deleted.

This statement must be checked at the fully tagged level. A mirror collision from the unmasked orbit cannot be imported after one member fails a strict mask.

### 5.2 Reflection quotient

If `rho` preserves both `F_xi` and `U_xi`, then it preserves their intersection and complement:

```text
rho(F_xi intersect U_xi)=F_xi intersect U_xi,
rho(F_xi\U_xi)=F_xi\U_xi.                            (5.2)
```

After deleting fixed points, quotienting by `rho` divides

```text
s_xi, m_xi, u_xi, H_xi
```

by two. The normalized inequality `(3.5)` is unchanged. A dark fibre remains dark.

If reflection exchanges two tagged sides rather than preserving one side, the two sides must be retained as a reflected pair. One may canonicalize the charge at a factor at most two, but no hit is created.

### 5.3 Palindromic support polynomials

Reflection symmetry makes `A_xi`, `B_xi`, or `C_xi` reciprocal/palindromic after the appropriate coordinate change. This does not force a common factor. There are disjoint unions of reflection orbits of arbitrary permitted sizes, hence coprime reciprocal support polynomials of those sizes. Equivalently, `C_xi | B_xi` in `(3.4)` is fully compatible with palindrome symmetry.

Thus reflection supplies exact inherited hit atoms where the reflected witness survives all masks, and at most a constant-factor quotient elsewhere. It does not supply the missing lower-tail estimate on the residual strict crossed fibre.

where `c` is a complement certificate—possibly a complement-polynomial root datum, a common-divisor avoidance certificate, a reflected gap certificate, or another exact affine/cycle object.

```text
  every selected miss (xi,q) has at least one c;
```

A theorem whose premise is `E_gamma(xi,q,z)` cannot prove coverage in `(6.7)`, because on a miss there is no `z` satisfying that premise.

## 8. The sharp selected-miss successor

The full missed-candidate mass

```text
sum_xi W_xi (m_xi-H_xi)                              (8.1)
```

is sufficient but can be much stronger than necessary. A bright fibre with one hit and a huge candidate set pays almost its whole size in `(8.1)`.

There is a sharper exact object.

For every `xi` with `m_xi>R`, order its distinct candidate states by the inherited canonical state order. Among the missed candidates

```text
F_xi\U_xi,
```

select the first

```text
(R-H_xi)_+                                            (8.2)
```

states. This is possible because `m_xi>R` gives

```text
m_xi-H_xi >= R-H_xi
```

whenever `H_xi<R`. Denote this selected set by

```text
M_R(xi).                                              (8.3)
```

Then, exactly,

```text
#M_R(xi)
 = 1_(m_xi>R)(R-H_xi)_+.                              (8.4)
```

On a dark rich fibre, `#M_R(xi)=R`. Therefore

```text
R * 1_(m_xi>R and H_xi=0)
 <= #M_R(xi).                                         (8.5)
```

Define

```text
L_R(P)
 = sum_p (log p)
     sum_(xi in X_p^cross,strict) W_xi #M_R(xi).       (8.6)
```

The recommended successor is

```text
UPSEL-MISS_R:
  L_R(P) << R * RHS_Q6497(R).                         (8.7)
```

Combining `(8.5)` and `(8.7)` proves `UPHITDEF_R` with the unchanged right-hand side.

### Why this is not the target renamed

`UPSEL-MISS_R` also charges every bright fibre with fewer than `R` hit states. For example,

```text
m_xi>R,
H_xi=1
```

contributes zero to the dark deficit but `R-1` units to `(8.6)`. Thus `UPHITDEF_R` does not imply `(8.7)`.

At the same time, `(8.7)` is strictly narrower than bounding every miss in `(8.1)`: it selects at most `R` missed states from any fibre and selects none once `H_xi>=R`.

It also preserves physical OR exactly. The selection is made after the hit bits `u_xi(q)=1_(Z_xi(q)>0)` are formed; multiple actual zero occurrences at one candidate never create extra selected or unselected states.

### Incidence-only sufficient version

By `(3.7)`, a coarser purely complement-capacity theorem would be

```text
UPCOMP-HINGE_R:

sum_p (log p)
  sum_xi W_xi 1_(m_xi>R)
    (s_xi-u_xi-(m_xi-R))_+

  << R * RHS_Q6497(R).                                (8.8)
```

This also implies `UPHITDEF_R`, but it is stronger than `UPSEL-MISS_R` because it forgets where the actual candidate set lies inside the ambient complement. The exact chain is

```text
R * 1_(m_xi>R,H_xi=0)
 <= #M_R(xi)
 <= (s_xi-u_xi-(m_xi-R))_+.                          (8.9)
```

Thus `(8.7)`, not `(8.8)`, is the sharp next analytic target.

## 9. The correct bounded inverse outer-star lemma

A dual actual-zero/complement proof of `UPSEL-MISS_R` would have the following exact form.

For each fixed-left Palm `gamma`, choose a certificate set `C_gamma` and a map

```text
kappa_gamma:
  {(xi,q): Palm_L(xi)=gamma, q in M_R(xi)}
    -> C_gamma.                                       (9.1)
```

The certificates must retain every strict tag needed to make the map sound. Define the weighted inverse star

```text
Star_gamma(c)
 = sum_((xi,q): q in M_R(xi), kappa_gamma(xi,q)=c)
     W_xi.                                            (9.2)
```

Then the exact double count is

```text
L_R(P)
```


A uniform inverse-reuse estimate

```text
Star_gamma(c) <= B                                   (9.5)
```

would reduce `(9.4)` to a bound for the total number/weight of available certificates. More generally, nonuniform bounds `Star_gamma(c)<=B_gamma(c)` are enough if their total has the right size.

This is the precise place where inverse outer-star reuse belongs. The domain in `(9.1)` consists of selected **misses**, not marked hits.

Candidate certificate choices include, in principle,

```text
- a root occurrence of the complement polynomial B_xi;
- an avoided prime in the complement radical Q_xi^miss;
- a canonical zero-free cycle arc containing q;
- a reflected complement orbit;
- an affine/source obstruction certificate showing why the hit equation fails.
```

But none is useful until two things are proved simultaneously:

```text
(coverage) every selected miss produces such a certificate;
(reuse)    a fixed certificate has bounded weighted inverse star
           after retaining gamma and forgetting the remaining outer data.
```

The existing marked-incidence fibre-one theorem addresses neither condition for misses.

### Nearest-zero and zero-free-arc warning

A tempting choice is to send each missed state to the nearest actual zero on the cycle. This gives coverage whenever the strict zero set is nonempty, but its inverse star is the length of a zero-free arc. Reflection sends a zero-free arc to another zero-free arc of the same length; it does not bound that length. Thus nearest-zero duality merely renames the missing gap theorem.

### Full-key warning

One may always make `kappa` injective by putting the complete outer record into the certificate. Then `(9.5)` holds with `B=1`, but the number of certificates equals the number of selected misses and `(9.4)` is tautological. A useful certificate must forget enough outer data to have a separately bounded total while retaining enough data to have bounded inverse reuse. That compression theorem is the genuine missing input.
