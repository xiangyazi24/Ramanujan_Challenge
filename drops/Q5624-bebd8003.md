# Path D: exact recurrence, valuation propagation, and the local-resultant obstruction

## Executive verdict

The three-coefficient defect is an exact and useful repackaging of the top-half target set, but I do **not** obtain an unconditional proof of either

```text
log rad_(n/2,n] D_n = o(n)
```

or the stronger

```text
log D_n = o(n).
```

The exact outcome is more specific.

1. The normalized coefficients `h_n=b_n/C_n` satisfy an explicit primitive parity-dependent second-order recurrence. At every top-half prime `p>=7` that can be a target, both endpoint coefficients of this recurrence are `p`-units.

2. Consequently an isolated denominator hole is a regular cancellation phenomenon. If the endpoint denominator valuations are both strictly larger than the middle one, the recurrence forces the two endpoint valuations to be equal, but it places no prime divisor in a recurrence coefficient, discriminant, or local Fitting ideal.

3. After all common denominator content is removed, the exact primitive numerator-denominator identity does give an integer divisible by `D_n`. That integer is positive and has logarithmic height at least linear in `n`; the raw factorial transfer has `n log n` height, while the fully reduced local carrier still has linear height. Thus this route does not create a polynomial-height or sublinear-height carrier.

4. There is a simultaneous CRT countermodel. For any finite collection of regular primes and any prescribed hole depths, one rational triple satisfying the **actual local Apéry row** has those holes simultaneously. The model can be propagated through any fixed window of actual recurrence rows. It can also be embedded into an eventually identical P-recursive sequence with the exact initial values `(1,5)`, at the cost of changing two steering rows. This proves a no-go for coefficient-only discriminants, bounded-window resultants, generic D-finite denominator theorems, and local Fitting constructions. It does not refute a theorem that uses the exact Apéry recurrence at every row together with the exact initial vector; those data uniquely determine the actual sequence.

5. The exact comparison

```text
D_n | U_n * gcd(b_n,C_n),
U_n = 1                         if n is even,
U_n = gcd((n+1)/2,2) <= 2       if n is odd
```

shows why the small numerical values must not be overinterpreted. In the top half, `D_n` and `gcd(b_n,C_n)` have exactly the same prime support. Bounding `D_n` by the central Apéry-binomial gcd is therefore the original hard assertion in another form, not an independent compression theorem.

The sharp route-specific conclusion is:

```text
Path D closes top-half P3.2 if and only if one proves a new pointwise
horizontal theorem for the distinguished Apéry solution. The rational
recurrence, its local Newton polygon, standard G-function denominator
divisors, and coefficient-only determinant/Fitting algebra do not supply
that theorem.
```

## 2. Exact parity-dependent recurrence for `h_n`

The Apéry numbers satisfy

```text
(n+1)^3 b_(n+1) - P(n)b_n + n^3 b_(n-1) = 0,
P(n) = 34n^3 + 51n^2 + 27n + 5
     = (2n+1)(17n^2+17n+5).
```

Substituting `b_j=C_j h_j` gives

```text
(n+1)^3 C_(n+1) h_(n+1)
 - P(n) C_n h_n
 + n^3 C_(n-1) h_(n-1) = 0.
```

### 2.1 Even center

Let `n=2m`. The exact central-binomial ratios are

```text
C_(2m-1)/C_(2m) = 1/2,
C_(2m+1)/C_(2m) = (2m+1)/(m+1).
```

Hence

```text
(2m+1)^4 h_(2m+1)
 - (m+1)P(2m) h_(2m)
 + 4m^3(m+1) h_(2m-1) = 0.
```

Equivalently, for even `n`,

```text
A_n h_(n+1) - B_n h_n + E_n h_(n-1) = 0,

A_n = (n+1)^4,
B_n = ((n+2)/2) P(n),
E_n = n^3(n+2)/4.
```

This row is primitive. Indeed `A_n` is coprime to `E_n`, because `n+1` is coprime to both `n` and `n+2`.

### 2.2 Odd center

Let `n=2m+1`. The exact ratios are

```text
C_(2m)/C_(2m+1) = (m+1)/(2m+1),
C_(2m+2)/C_(2m+1) = 2.
```

The raw integral recurrence is

```text
16(m+1)^3 h_(2m+2)
 - P(2m+1) h_(2m+1)
 + (2m+1)^2(m+1) h_(2m) = 0.
```

Equivalently,

```text
2(n+1)^3 h_(n+1)
 - P(n)h_n
 + n^2(n+1)/2 h_(n-1) = 0.
```

There is a small content that must be removed. Since

```text
P(n) = 34(n+1)^3 - 51(n+1)^2 + 27(n+1) - 5,
```

one has

```text
gcd(n+1,P(n)) = gcd(n+1,5).
```

Because `P(n)` is odd for odd `n`, the complete row content is

```text
gamma_n = gcd(n+1,5).
```

Thus the primitive odd row is

```text
A_n h_(n+1) - B_n h_n + E_n h_(n-1) = 0,

A_n = 2(n+1)^3/gamma_n,
B_n = P(n)/gamma_n,
E_n = n^2(n+1)/(2 gamma_n),

gamma_n = gcd(n+1,5).
```

The initial vector is exactly

```text
(h_0,h_1) = (1,5).
```

This completes the parity and content audit. The factor `gamma_n` is irrelevant for the target primes `p>=7`, but omitting it would make the claimed primitive recurrence false at odd indices `n == 4 mod 5`.

## 3. Exact valuation propagation

Write every coefficient in lowest terms:

```text
h_j = a_j/q_j,
gcd(a_j,q_j)=1,
q_j>0.
```

Fix a prime `p` with

```text
p does not divide A_n E_n.
```

Put

```text
x = v_p(q_(n-1)),
y = v_p(q_n),
z = v_p(q_(n+1)).
```

### Lemma 3.1: equal-depth propagation

If

```text
min(x,z) > y,
```

then

```text
x=z.
```

#### Proof

The endpoint numerators are `p`-units because `x,z>0`. The endpoint terms in the recurrence have valuations `-x` and `-z`. The middle term has valuation at least `-y`, since `B_n` and the reduced middle numerator have nonnegative `p`-adic valuation. If `x!=z`, one endpoint term would have the unique smallest valuation, which cannot occur in a vanishing sum. Therefore `x=z`. 

More precisely, write

```text
q_(n-1) = p^x Q_-,
q_n     = p^y Q_0,
q_(n+1) = p^x Q_+,

p does not divide Q_- Q_0 Q_+.
```

Multiplication by `p^x` gives

```text
A_n a_(n+1)/Q_+ + E_n a_(n-1)/Q_-
 = B_n a_n p^(x-y)/Q_0.
```

Hence the exact leading cancellation is

```text
A_n a_(n+1) Q_- + E_n a_(n-1) Q_+ == 0 mod p^(x-y).
```

If the middle reduced numerator or `B_n` has extra `p`-adic valuation, the modulus is correspondingly stronger. There is still no divisibility conclusion for `A_n`, `E_n`, or a coefficient discriminant.

### 3.2 Application to a top-half target

Let `p>=7`, `n/2<p<=n`, and write

```text
n=p+r.
```

The endpoint congruences exclude `r=0,p-2,p-1`; therefore a target has

```text
1 <= r <= p-3.
```

For `j=-1,0,1`, the indices `n+j` lie between `p` and `2p-2`, and both factorials in the denominator of the central binomial coefficient are below `p`. Thus

```text
v_p(C_(n-1)) = v_p(C_n) = v_p(C_(n+1)) = 1.
```

Lucas gives

```text
b_(n+j) == 5 b_(r+j) mod p.
```

If `p|b_r`, nonconsecutivity of the Apéry zero set gives

```text
p does not divide b_(r-1)b_(r+1).
```

Consequently

```text
(v_p(q_(n-1)),v_p(q_n),v_p(q_(n+1))) = (1,0,1).
```

Conversely, in this interval positive `p`-curvature of the denominator triple forces the same pattern and hence `p|b_r`. Therefore

```text
p | D_n
    iff
p is a top-half target,

v_p(D_n)=1 for every such target.
```

At the same time, the recurrence coefficients are regular. Since

```text
n mod p = r,
1 <= r <= p-3,
```

none of `n,n+1,n+2` is divisible by `p`; also `p>=7` does not divide `2`, `4`, or `gamma_n`. Hence

```text
p does not divide A_n E_n.
```

The target pattern is therefore exactly the regular cancellation allowed by Lemma 3.1.

## 4. Why a recurrence discriminant or local Fitting ideal cannot carry the holes

### 4.1 Natural discriminants

For the primitive row

```text
A_n X_(n+1) - B_n X_n + E_n X_(n-1)=0,
```

its natural quadratic discriminant is

```text
Delta_n = B_n^2 - 4A_nE_n.
```

For even `n`,

```text
Delta_n
 = ((n+2)^2 P(n)^2)/4
   - n^3(n+2)(n+1)^4.
```

For odd `n`,

```text
Delta_n
 = (P(n)^2 - 4n^2(n+1)^4)/gamma_n^2.
```

The first nontrivial triple example already rules this out. At `n=321`, the top-half targets are

```text
p = 179, 193, 211.
```

Here `gamma_321=1`, and the primitive odd row has

```text
A_321 = 66,772,496,
B_321 = 1,129,853,237,
E_321 = 16,589,601.
```

The reductions are

```text
p      A_321 mod p   B_321 mod p   E_321 mod p   Delta_321 mod p
179        126            46             60              158
193         93           164             93               20
211         69           143            148               68
```

Every target prime is a unit for `A_321E_321Delta_321`. Thus

```text
D_321 does not divide Delta_321,
```

and the failure is not caused by a small-prime or endpoint exception.

### 4.2 Local Fitting module

Over `Z_p`, consider the row map

```text
phi_p : Z_p^3 -> Z_p,
phi_p(X_-,X_0,X_+) = E_n X_- - B_n X_0 + A_n X_+.
```

For a top-half candidate, `A_n` is a unit. Therefore `phi_p` is surjective. Its cokernel is zero and its kernel is a free rank-two `Z_p`-module. Equivalently,

```text
Fitt_0(coker(phi_p)) = Z_p.
```

There is no local torsion factor for a hole prime. The hole records the choice of a nonintegral vector in a free solution module whose middle coordinate happens to be integral. It is not a singularity of the coefficient module.

### 4.3 Bounded-window no-go

Fix any bounded number of neighboring recurrence rows. Form an integer from their primitive coefficients using polynomial arithmetic, determinants, resultants, subresultants, or Fitting ideals, and divide out every state-independent common content. Suppose that this integer were forced to be divisible by every regular hole prime for every rational solution.

That implication is impossible. Section 7 below constructs, for any prime avoiding the coefficient integer, a solution with a hole at that prime while preserving all recurrence rows in the chosen window. Hence a nonzero coefficient-only bounded-window resultant cannot be target-selective.

A resultant that spans from the initial vector all the way to index `n` is different: it is state-dependent global propagation. Its raw integral transfer has factorial `n log n` height, and after the universal factorial content is removed the surviving Apéry value still has linear logarithmic height. It is not a polynomial-height discriminant.

## 5. Primitive numerator-denominator identity and the evaluated-height obstruction

The recurrence does yield one exact state-dependent carrier. Let

```text
g = gcd(q_(n-1),q_n,q_(n+1)).
```

After dividing by `g`, write

```text
q_(n-1) = g D_n x,
q_n     = g y,
q_(n+1) = g D_n z,

gcd(x,z)=1,
gcd(D_n,y)=1.
```

Cross-multiplication of the primitive recurrence gives

```text
y [ A_n a_(n+1) x + E_n a_(n-1) z ]
 = B_n a_n D_n xz.
```

Therefore

```text
D_n | K_n,

K_n = A_n a_(n+1) x + E_n a_(n-1) z.
```

This identity has already removed

```text
- the common triple denominator g,
- the full hole factor D_n from both endpoint denominators,
- the coprime endpoint co-denominators x,z,
- the primitive coefficient-row content gamma_n.
```

No unexplained factorial gauge remains. Nevertheless `K_n` is not small. All quantities are positive, and

```text
a_(n+1) = h_(n+1) q_(n+1) >= h_(n+1).
```

Hence

```text
K_n >= A_n h_(n+1).
```

The standard Apéry and central-binomial asymptotics are

```text
alpha = 17+12sqrt(2),

b_n = Theta(alpha^n n^(-3/2)),
C_n = Theta(2^n n^(-1/2)),
h_n = b_n/C_n = Theta((alpha/2)^n n^(-1)).
```

Thus

```text
log K_n
 >= n log((17+12sqrt(2))/2) - O(log n).
```

This is the sharp scale distinction for this route:

```text
raw integral transfer:             Theta(n log n) height;
after factorial/binomial removal:  still Omega(n) evaluated height;
polynomial-height target:           O(log n) height;
desired carrier:                    o(n) height.
```

Dividing `K_n` by any state-independent polynomial content changes its logarithm by only `O(log n)`, so the linear obstruction survives. A further exponential divisor would have to depend on the actual Apéry state; proving that divisor large is again the horizontal problem.

This does not prove that every conceivable nonlinear multi-row expression has linear height. It proves the exact no-go for the primitive one-row denominator clearing and, together with the local Fitting argument, excludes any replacement depending only on a bounded set of recurrence coefficients.

## 6. Exact comparison with the central Apéry-binomial gcd

Put

```text
g_n = gcd(b_n,C_n),

U_n = gcd(C_(n-1),C_(n+1))
      / gcd(C_(n-1),C_n,C_(n+1)).
```

For a prime `ell`, write

```text
c_j = v_ell(C_(n+j)),
e_j = v_ell(gcd(b_(n+j),C_(n+j))).
```

Since `v_ell(q_(n+j))=c_j-e_j`,

```text
v_ell(D_n)
 = max(0,
       min(c_(-1)-e_(-1), c_1-e_1)
       - (c_0-e_0))

 <= e_0 + max(0,min(c_(-1),c_1)-c_0).
```

Therefore

```text
D_n | g_n U_n.
```

The central-binomial ratios make `U_n` explicit.

If `n=2m`, then `C_(2m-1)=C_(2m)/2`, so

```text
U_(2m)=1.
```

If `n=2m+1`, write the Catalan normalization

```text
C_(2m)   = (m+1)K,
C_(2m+1) = (2m+1)K,
C_(2m+2) = 2(2m+1)K.
```

Then

```text
U_(2m+1)=gcd(m+1,2).
```

Consequently

```text
D_n | 2 gcd(b_n,C_n),
D_n | gcd(b_n,C_n) when n is even.
```

This is an exact comparison, not a height theorem. In fact, for every top-half prime `p>=7`,

```text
p | D_n
 iff p | gcd(b_n,C_n).
```

Both valuations are exactly one on that support, so

```text
rad_(n/2,n] D_n
 = rad_(n/2,n] gcd(b_n,C_n)
 = product of all top-half targets.
```

Thus the statement that `D_n` is controlled by `gcd(b_n,C_n)` is tautological at the hard primes. It neither proves nor weakens the desired pointwise estimate.

### 6.1 Small versus medium primes in the stronger `log D_n` problem

Kummer's carry theorem gives, uniformly for `j=-1,0,1`,

```text
v_ell(C_(n+j)) <= 1 + floor(log_ell(n+1)).
```

Therefore

```text
sum_(ell <= sqrt(n+1)) v_ell(D_n) log ell = O(sqrt(n)).
```

For `ell>sqrt(n+1)`, every `C_(n+j)` has `ell`-valuation at most one. Hence the large-prime part of `D_n` is squarefree and

```text
log D_n
 = log rad_(sqrt(n+1),n+1] D_n + O(sqrt(n)).
```

So the stronger assertion `log D_n=o(n)` is not blocked by very small primes. Its additional difficulty lies in the medium interval

```text
sqrt(n) < ell <= n/2,
```

which contains the higher-quotient moving-digit channels. Calling the difference between `D_n` and the central gcd merely “small-prime factors” suppresses this unresolved medium-prime range.

## 7. Recurrence-compatible simultaneous-hole countermodels

### 7.1 Exact local row and arbitrary simultaneous holes

Fix `n` and use its actual primitive coefficients `A=A_n`, `B=B_n`, `E=E_n`. Let `S` be any finite set of primes satisfying

```text
p does not divide AE for every p in S,
```

and choose depths `s_p>=1`. Put

```text
R = product_(p in S) p^(s_p).
```

Choose integers `u,t` coprime to `R`, and define

```text
H_(n-1) = A u/R,
H_n     = A t,
H_(n+1) = B t - E u/R.
```

Then, identically over `Q`,

```text
A H_(n+1) - B H_n + E H_(n-1) = 0.
```

For each `p in S`,

```text
numerator(H_(n-1)) == Au              mod p,
numerator(H_(n+1)) == -Eu             mod p,
```

and both are units. Therefore the reduced denominator valuations are exactly

```text
(v_p(den H_(n-1)),
 v_p(den H_n),
 v_p(den H_(n+1)))
 = (s_p,0,s_p).
```

This realizes arbitrary simultaneous large-prime holes in the same local row. No CRT compatibility condition between different primes remains; the product `R` performs all congruences at once.

For the top-half `1,0,1` pattern, take `s_p=1` and `S` inside `(n/2,n]`. Every `p in S` divides both neighboring central binomial coefficients exactly once, so the two polar values can locally be written as

```text
H_(n-1)=B'_(n-1)/C_(n-1),
H_(n+1)=B'_(n+1)/C_(n+1)
```

with integral `B'_(n-1),B'_(n+1)`. Thus the countermodel also preserves the local “integer numerator divided by the central binomial coefficient” structure.

Starting from the pair `(H_(n-1),H_n)`, the actual recurrence can be propagated forward and backward through any prescribed fixed-width window around `n`. Hence every row in that window can be kept exactly equal to the Apéry `h`-recurrence while the arbitrary hole set survives at the center.

This proves the bounded-window coefficient-resultant and Fitting no-go stated above.

### 7.2 Preserving the exact initial values

There is an unavoidable uniqueness issue. If one insists simultaneously on

```text
- the exact recurrence coefficient functions at every index, and
- the exact initial vector (h_0,h_1)=(1,5),
```

then there is only one rational solution: the actual Apéry sequence. No countermodel with different holes can satisfy both requirements. Requiring such a model would be logically equivalent to requiring the actual target theorem in advance.

What can be preserved is the exact initial vector, any fixed initial prefix, and every recurrence row near the target. Choose a steering position `k_0` after the protected initial prefix. Back-propagate the desired local-hole state under the actual recurrence to obtain desired values `U_(k_0+1),U_(k_0+2)`. Keep the actual sequence through `k_0`, and alter only the two middle coefficients

```text
Btilde_(k_0)
 = [A_(k_0) U_(k_0+1) + E_(k_0) H_(k_0-1)] / H_(k_0),

Btilde_(k_0+1)
 = [A_(k_0+1) U_(k_0+2) + E_(k_0+1) H_(k_0)]
   / U_(k_0+1).
```

After those two rows, restore the exact Apéry coefficient `B_k` and propagate normally. The resulting sequence has

```text
(H_0,H_1)=(1,5),
```

agrees with the actual recurrence on the entire protected prefix and on the entire target window, and realizes the arbitrary simultaneous holes. The free parameters `u,t` can avoid the finitely many possible zero denominators in the steering formulas.

Because the recurrence is exactly the Apéry recurrence from some point onward, this is an eventually P-recursive, hence D-finite, sequence. It shows that generic D-finiteness, fixed initial values as isolated constants, and local recurrence geometry do not couple the target primes. The missing ingredient is enforcement of every exact row connecting the initial state to the target.

Once that full connection is enforced, one obtains the actual global transfer. Its canonical integral form is

```text
A_0=1,
A_1=5,
A_(k+1)=P(k)A_k-k^6A_(k-1),
A_k=(k!)^3 b_k.
```

The raw value has `Theta(n log n)` logarithmic height because of `(n!)^3`; after removing that universal factor, `b_n` still has `Theta(n)` logarithmic height. This is precisely why the fixed initial state does not by itself give a low-height horizontal carrier.

## 8. G-functions and local Newton polygons

The Hadamard construction in Section 16 correctly identifies each parity section of `h_n` as coefficients of an explicit G-function. It supplies exponential upper bounds for common prefix denominators. It does not supply a lower bound for the denominator of one selected coefficient, nor a bound on positive denominator curvature.

At a top-half target index, the primitive recurrence has

```text
v_p(A_n)=v_p(E_n)=0,
v_p(B_n)>=0.
```

The coefficient valuation polygon therefore has a horizontal lower edge between the two endpoint coefficients. The tropical recurrence condition says exactly that equal endpoint poles may cancel while the middle value is integral. There is no positive slope, singular factor, or forced coefficient divisor to exclude the pattern.

Globally, the `p`-singular recurrence step near index `p-1` is universal: it occurs for every candidate prime, target or not, and encodes the central-binomial denominator. Saturating that universal binomial content leaves the state-dependent congruence `p|b_r`. A global Newton polygon that retains the singular step therefore carries all candidates; one that removes it has no selective coefficient factor.

The exact prefix-lcm saturation proved in Section 16.1 reinforces this conclusion. The generic G-function denominator bound is already sharp on every residue section, yet individual coefficients may have isolated missing primes. A successful theorem would have to be a new **pointwise lower-denominator or curvature theorem for this distinguished G-function solution**, not a standard denominator-divisor result.

## 10. Final no-go theorem and the remaining reopen condition

The exact conclusions can be summarized as follows.

### Theorem 10.1: local recurrence no-go

For every fixed index `n`, every finite set of primes `S` with `p` not dividing `A_nE_n`, and every set of depths `s_p>=1`, there is one rational triple satisfying the actual primitive row at `n` whose reduced denominator valuations are `(s_p,0,s_p)` for every `p in S`.

Consequently no nonzero integer constructed solely from a bounded window of primitive recurrence coefficients—by discriminants, resultants, subresultants, determinants, or Fitting ideals after universal-content saturation—can be forced to contain all hole primes.

### Theorem 10.2: canonical evaluated-height obstruction

After complete primitive denominator reduction, the row identity produces

```text

K_n=A_n a_(n+1)x+E_n a_(n-1)z,
```


### Theorem 10.3: exact tautology boundary

The defect satisfies

```text

```

and its top-half radical equals the top-half radical of that gcd. Hence the observed smallness of `D_n` is genuine data about the original Apéry gcd. It is not implied by the comparison.

### Remaining route

A proof of top-half P3.2 through Path D must introduce one of the following genuinely new inputs:


No such input is produced by the present recurrence/discriminant/Fitting analysis. Therefore Path D remains a clean exact reformulation and a promising numerical observable, but it does not yet close top-half P3.2.
