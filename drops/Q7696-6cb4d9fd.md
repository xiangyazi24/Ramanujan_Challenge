# 1. Exact Green/Casoratian law

Put

\[
P(n)=34n^3+51n^2+27n+5=(2n+1)(17n^2+17n+5).
\]

The homogeneous recurrence is

\[
n^3b_n-P(n-1)b_{n-1}+(n-1)^3b_{n-2}=0.
\]

For the actual source

\[
F(t)=\sum b_nt^n,\qquad
\Delta(t)=1-34t+t^2,
\]

\[
G(t)=\frac1{F(t)^2\sqrt{\Delta(t)}}=\sum g_nt^n,
\]

take the canonically normalized companion

\[
\kappa_0=0,\qquad \kappa_1=-36,
\]

\[
n^3\kappa_n-P(n-1)\kappa_{n-1}+(n-1)^3\kappa_{n-2}=-5g_n.
\]

Define

\[
W_n=n^3(b_n\kappa_{n-1}-b_{n-1}\kappa_n).
\]

Subtracting the homogeneous and inhomogeneous recurrence after cross-multiplication gives

\[
W_n-W_{n-1}=5g_nb_{n-1}.
\]

Since `W_1=36` and `g_1=7`, telescoping gives the exact identity

\[
\boxed{
\Xi_n
=n^3(b_{n-1}\kappa_n-b_n\kappa_{n-1})
=-1-5\sum_{m=1}^n g_mb_{m-1}.}
\tag{1}
\]

If `0<n<p` and `b_n=0`, then `b_{n-1}` is a unit: two consecutive homogeneous zeros would propagate backwards to `b_0=0`, impossible because all factors before row `p` are units.  Therefore

\[
\boxed{b_n=0\Longrightarrow \Xi_n=0\iff\kappa_n=0.}
\tag{2}
\]

The new verifier checks (1) at every row for every prime with a Hasse zero in the scan and checks (2) at every Hasse-zero row.

# 2. Correct Duhamel shooting law — one equation, not two

Write

\[
v_n=\binom{\kappa_n}{\kappa_{n-1}},
\]

so

\[
v_{n+1}=T_nv_n+u_n,
\]

with

\[
T_n=
\begin{pmatrix}
P(n)/(n+1)^3&-n^3/(n+1)^3\\
1&0
\end{pmatrix},
\qquad
u_n=\binom{-5g_{n+1}/(n+1)^3}{0}.
\]

Thus, for `r<s<p`,

\[
\boxed{
v_s=\Phi(s,r)v_r+
\sum_{j=r}^{s-1}\Phi(s,j+1)u_j,}
\tag{3}
\]

where `\Phi(s,r)=T_{s-1}\cdots T_r`.

Suppose `b_r=b_s=0`, `h=s-r`.  The ordinary homogeneous return is the continuant equation

\[
N_h(r)=0.
\]

The Q7684 marked-return audit proves that the penultimate coefficient is a unit:

\[
\boxed{N_{h-1}(r)\ne0\pmod p.}
\tag{4}
\]

Hence, after imposing the ordinary return, the marked equation has exactly one terminal shooting coordinate.  In cleared form,

\[
M_h(r)=
\sum_{j=1}^{h-1}g_{r+j+1}N_j(r)
\prod_{q=j+1}^{h-1}(r+q)^3,
\]

and the coefficient of the final source value `g_s` is exactly the unit `N_{h-1}(r)`.

The Green form follows from (1).  At Hasse-zero endpoints,

\[
\boxed{
s^3b_{s-1}\kappa_s-r^3b_{r-1}\kappa_r
=-5\sum_{m=r+1}^{s}g_mb_{m-1}.}
\tag{5}
\]

If the first endpoint is common, `\kappa_r=0`, and therefore

\[
\boxed{
\kappa_s=0
\iff
\sum_{m=r+1}^{s}g_mb_{m-1}=0
\iff
g_s=-b_{s-1}^{-1}
\sum_{m=r+1}^{s-1}b_{m-1}g_m.}
\tag{6}
\]

The marked equation `M_h(r)=0` and the Green-period equation in (6) are the **same scalar endpoint condition**, expressed in two bases.  They cannot be counted as two independent equations.  The verifier checks (5) and (6) for every pair of Hasse-zero rows in the exact scan.

# 3. Formal source freedom is a theorem-level no-go

For a free forcing sequence `s_n`, keep the canonical initial line and solve

\[
n^3x_n-P(n-1)x_{n-1}+(n-1)^3x_{n-2}=-5s_n.
\]

Changing only `s_r` by `\delta` changes `x_r` by

\[
\Delta x_r=-\frac5{r^3}\delta.
\]

For `p>=7` this is a unit.  Later source changes cannot affect earlier rows, so the map from source perturbations supported at selected Hasse-zero rows to the corresponding companion values is triangular with unit diagonal.  One can force any prescribed finite set of Hasse returns to be companion zeros.

Q7684 already exhibited the exact same-scale countermodel `p=19`, rows `8,10`, with source perturbations forcing both marked values to zero.

Therefore none of the following can prove common-row uniqueness by itself:

```text
homogeneous transfer matrices;
ordinary continuants N_h;
unit denominator bookkeeping;
formal Green/Wronskian identities;
projective dynamics;
generic second-order recurrence theory;
generic marked-source resultants.
```

The actual source arithmetic is indispensable.

# 4. The actual level-six Eichler source and boundary line

The source is rigid.  On the level-six modular parametrization,

\[
t(\tau)=

\[
E(\tau)=
\frac{\eta(2\tau)^7\eta(3\tau)^7}

\]

For `K(t)=\sum\kappa_nt^n`, the canonical extension is normalized by the triple Eichler antiderivative of

\[
\mathcal M_4=
\frac{-3E_4(\tau)+4E_4(2\tau)-9E_4(3\tau)+108E_4(6\tau)}{20}.
\]

Equivalently, the prior audit records

\[
K(t(q))/E(q)=\mathcal E_{\mathcal M_4}(q).
\]

In characteristic `p`, with

\[
A_p(t)=\sum_{j=0}^{p-1}b_jt^j,

the first-block Cartier/Hasse relation is

\[
F(t)=A_p(t)F(t^p),
\]

and the reciprocal source satisfies

\[
\boxed{
G(t)=R_p(t)G(t^p),\qquad
R_p(t)=\frac{\Delta(t)^{(p-1)/2}}{A_p(t)^2}.}
\tag{7}
\]

Hence

\[
\boxed{g_m=[t^m]R_p(t)\qquad(0\le m<p).}
\tag{8}
\]

The Q7696 scan uses exactly `G=1/(F^2 sqrt(Delta))`, not a free source, and uses the exact boundary line `\kappa_0=0,\kappa_1=-36`.

The boundary line is essential in addition to the source.  If `a_n` is the second homogeneous solution normalized by `a_0=0,a_1=6`, then

# 5. Hasse reciprocity

The Apéry numbers have

\[
b_n=\sum_{k=0}^n\binom nk^2\binom{n+k}{k}^2.
\]

For `0<=n<p`, the usual negative-binomial congruences give

\[
\binom{p-1-n}{k}\equiv(-1)^k\binom{n+k}{k},
\]

\[
\binom{p-1-n+k}{k}\equiv(-1)^k\binom nk,
\]

with `k>n` terms vanishing modulo `p`.  Therefore

\[
\boxed{b_{p-1-n}=b_n\pmod p.}
\tag{9}
\]

This also matches the recurrence symmetry

\[
P(-n-1)=-P(n).
\]

The verifier asserts (9) for every row for every scanned prime.

This symmetry is useful but not enough.  Hasse zeros occur in mirror pairs `r <-> p-1-r`; nevertheless the actual Eichler coordinate need not separate them.  The required guard is itself a reflected pair:

\[
30=40-10,\qquad \Xi_{10}=\Xi_{30}=7\pmod{41}.
\]

So `Xi` is **not injective** on the Hasse-zero set, and no proof may use such an injectivity claim.

# 6. Second-order / Green-kernel route

The Apéry K3 Picard-Fuchs equation has the familiar rank-two/symmetric-square modular origin, and

\[
G=1/(F^2\sqrt\Delta)
\]

has the reduction-of-order/Green-kernel form explaining why the marked defect is one-dimensional after an ordinary return.

But this does not yield a finite-field Sturm theorem in the coefficient index:

- modulo `p` there is no real order/sign interlacing;
- the row `r` is a coefficient/Mellin index, not a point of the geometric `t`-line;
- free-source controllability preserves the homogeneous operator;
- `p=41` shows actual canonical Green values can repeat on distinct Hasse zeros.

Thus the second-order viewpoint correctly explains the **rank of the shooting condition**, but it does not exclude the distinguished value zero from occurring twice.

# 7. Marked-return resultants

For fixed gap `h`, the pair is

\[
N_h(r)=0,
\qquad
M_h(r)=C_{r,h}+N_{h-1}(r)g_s=0.
\]

Because `N_{h-1}(r)` is a unit at a return, the marked condition is transverse in the terminal source coefficient.  This is the right resultant structure: one ordinary equation and one marked equation.

Substituting the actual first-block source turns the endpoint condition into

\[
\boxed{
[t^s]R_p(t)=
-b_{s-1}^{-1}\sum_{m=r+1}^{s-1}
 b_{m-1}[t^m]R_p(t).}
\tag{10}
\]

The present obstruction is complexity: the reduced rational source has denominator/Cartier state of order `Theta(p)`; the previous audit records denominator degree between `p-1` and `2p-2`.  There is no currently justified bounded-degree polynomial in the row index whose roots are all common rows.  Short-gap continuant resultants remain useful for aggregate bounds, but do not prove a uniform pointwise multiplicity bound for arbitrary gaps.

# 8. What two actual common rows would force

If

\[
0<r<s<p,\qquad b_r=b_s=\Xi_r=\Xi_s=0,
\]

then

```text
N_h(r)=0;
N_{h-1}(r) is a unit;
M_h(r)=0;
the canonical Green period from r+1 to s vanishes;
the terminal g_s equals its unique shooting value;
κ_r=κ_s=0 on two Hasse-zero rows.
```

These are not several independent contradictions.  They are one source collision in different coordinates.

The `p=41` example proves that the canonical Green period can vanish between two distinct Hasse-zero rows.  It is not a common-zero counterexample only because the repeated value is `7`, not `0`.  Hence the missing contradiction must distinguish the canonical Eichler **zero fiber** from other fibers.

# 10. Exact theorem still missing

The data do not justify weakening the sharp conjecture.  The smallest source-specific theorem that would prove it is:

## EIS-2RET / zero-normalized endpoint avoidance

For every prime `p>=7` and `0<r<s<p`,

\[
\boxed{
 b_r=b_s=0,\quad \Xi_r=0
 \Longrightarrow
 \sum_{m=r+1}^{s}b_{m-1}g_m\ne0\pmod p.}
\tag{11}
\]

By (5), this is exactly `\Xi_s\ne0`.

It deliberately does **not** assert that the Green period between every pair of Hasse zeros is nonzero, so it is compatible with the `p=41` collision.

Using the actual source, (11) is equivalently

\[
\boxed{
[t^s]R_p(t)\ne
-b_{s-1}^{-1}\sum_{m=r+1}^{s-1}
 b_{m-1}[t^m]R_p(t),}
\tag{12}
\]

under `b_r=b_s=Xi_r=0`.

This is the precise finite-characteristic coefficient-avoidance theorem the modular/Eichler normalization still has to provide.

# 11. What is actually proved about multiplicity

Current structural results do **not** prove `O(1)` or even `p^{o(1)}` pointwise multiplicity.  The unconditional elementary fallback is only linear.  Since homogeneous zeros cannot be consecutive,

\[
\boxed{
|Z_{\rm common}(p)|
\le \#\{0<r<p:b_r=0\}
\le (p-1)/2.}
\]

So the status is:

```text
proved: one-dimensional Duhamel/Green shooting law;
proved: ordinary return N_h=0 and terminal N_{h-1} unit;
proved: Hasse reflection b_{p-1-r}=b_r;
proved computationally p<=20000: max common multiplicity 1;
not proved: uniform O(1);
not proved: p^{o(1)} pointwise multiplicity;
not proved: <=1 for all p.
```

Because no counterexample to `<=1` appeared, Requirement 5's fallback is not triggered.  If a future isolated double return appears, the next plausible target would still be an absolute constant bound

\[
|Z_{\rm common}(p)|\le C,
\]

and only if multiplicities grow would I retreat to

\[
|Z_{\rm common}(p)|\ll_\varepsilon p^\varepsilon.
\]

There is presently no evidence forcing that retreat.
