# Cold audit: exact lattice theorem for the integer Lagrange weights

## Verdict

The candidate theorem is correct, with one wording repair: the lower-bound claim must refer to a **nonzero resulting value** of a balanced combination, not merely to a nonzero balanced coefficient vector.

For every \(n\ge4\), set \(M=\lfloor n/2\rfloor\) and

\[
\lambda_j=(-1)^{M-1-j}\binom nj\binom{n-j-1}{M-1-j},\qquad 0\le j<M.
\]

Let \(b_j\) be the Apéry numbers, \(b_0=1,b_1=5\), and define

\[
v_j=\lambda_j(1,b_j)^t,\qquad L=\sum_{j=0}^{M-1}\mathbf Z v_j,
\]

\[
T=\sum_j\lambda_jb_j,\qquad c_j=\lambda_j(b_n-b_j),\qquad D=\gcd_j c_j,
\]

\[
R=\gcd_{0\le i<j<M}\lambda_i\lambda_j(b_j-b_i),
\]

with positive gcds.

Then

\[
\boxed{
L=\mathbf Z(1,T)^t\oplus\mathbf Z(0,R)^t
=\{(x,y)\in\mathbf Z^2:y\equiv Tx\pmod R\}.
}
\tag{0.1}
\]

Hence

\[
\boxed{\operatorname{SNF}(L)=(1,R),}
\qquad
\boxed{L\cap(\{0\}\times\mathbf Z)=\{0\}\times R\mathbf Z,}
\tag{0.2}
\]

and

\[
\boxed{D=\gcd(R,b_n-T).}
\tag{0.3}
\]

If

\[
K=\left\{u=(u_j)\in\mathbf Z^M:\sum_j u_j\lambda_j=0\right\},
\]

then the exact balanced-value image is

\[
\boxed{
\left\{\sum_j u_jc_j:u\in K\right\}=R\mathbf Z.
}
\tag{0.4}
\]

Therefore every nonzero balanced **value** has absolute value at least \(R\), and both \(R\) and \(-R\) are attained.

If instead “nonzero balanced combination” means only \(u\ne0\), that literal formulation is false for \(M\ge3\): the rank-two column matrix has an integer kernel of rank \(M-2\), so there are nonzero balanced \(u\) with value \(0\).

The current P3.2 map asks that inherited claims be re-verified exactly and records generic Smith/Fitting compression as exhausted without new Apéry-specific structure. The proof below is independent of the prior Q1998 drop and uses only the displayed weights, \(b_0=1,b_1=5\), and elementary integer linear algebra.

## 1. Lagrange weights and primitivity

The coefficients are exactly the Lagrange weights for evaluation at \(x=n\) from the nodes \(0,1,\ldots,M-1\):

\[
\boxed{
\lambda_j=
\prod_{\substack{0\le k<M\\k\ne j}}
\frac{n-k}{j-k}.
}
\tag{1.1}
\]

Indeed,

\[
\prod_{k\ne j}(n-k)=\frac{n!}{(n-M)!(n-j)},
\]

while

\[
\prod_{k\ne j}(j-k)=(-1)^{M-1-j}j!(M-1-j)!.
\]

Taking the quotient gives the stated binomial formula. Hence every polynomial \(f\) of degree at most \(M-1\) satisfies

\[
f(n)=\sum_{j=0}^{M-1}\lambda_jf(j).
\]

For \(f=1\),

\[
\boxed{\sum_j\lambda_j=1,}
\tag{1.2}
\]

so

\[
\boxed{\gcd_j\lambda_j=1.}
\tag{1.3}
\]

Also every \(\lambda_j\ne0\). In particular, since \(M\ge2\),

\[
\lambda_0=(-1)^{M-1}\binom{n-1}{M-1}\ne0,
\]

\[
\lambda_1=(-1)^{M-2}n\binom{n-2}{M-2}\ne0.
\tag{1.4}
\]

## 2. Rank and determinant-sign audit

Let

\[
A=[v_0\ v_1\ \cdots\ v_{M-1}]
=\begin{pmatrix}
\lambda_0&\lambda_1&\cdots\\
\lambda_0b_0&\lambda_1b_1&\cdots
\end{pmatrix}.
\]

For \(i<j\),

\[
\boxed{
\det(v_i,v_j)=\lambda_i\lambda_j(b_j-b_i).
}
\tag{2.1}
\]

Thus the sign used in \(R\) is correct. Since \(b_1-b_0=4\),

\[
\det(v_0,v_1)=4\lambda_0\lambda_1\ne0.
\tag{2.2}
\]

Therefore

\[
\boxed{\operatorname{rank}L=2,\qquad R>0.}
\tag{2.3}
\]

There is no rank-one exceptional case for \(n\ge4\).

If \(x_n=(1,b_n)^t\), then

\[
\boxed{\det(v_j,x_n)=c_j.}
\tag{2.4}
\]

Moreover

\[
\boxed{
\lambda_i c_j-\lambda_j c_i
=\lambda_i\lambda_j(b_i-b_j)
=-\det(v_i,v_j).
}
\tag{2.5}
\]

So pairwise elimination gives \(D\mid R\), with the minus sign in (2.5).

## 3. Smith invariants

For a rank-two integer matrix, let \(\delta_1\) be the gcd of all entries and \(\delta_2\) the gcd of all \(2\times2\) minors. Here

\[
\delta_1
=\gcd_j(\lambda_j,\lambda_jb_j)
=\gcd_j\lambda_j
=1,
\tag{3.1}
\]

and by (2.1)

\[
\delta_2=R.
\tag{3.2}
\]

The Smith invariant factors satisfy \(s_1=\delta_1\) and \(s_1s_2=\delta_2\), hence

\[
\boxed{s_1=1,\qquad s_2=R.}
\tag{3.3}
\]

Equivalently there exist \(U\in\operatorname{GL}_2(\mathbf Z)\) and \(V\in\operatorname{GL}_M(\mathbf Z)\) with

\[
UAV=
\begin{pmatrix}
1&0&0&\cdots&0\\
0&R&0&\cdots&0
\end{pmatrix}.
\]

Thus

\[
\boxed{
\mathbf Z^2/L\simeq\mathbf Z/R\mathbf Z,
\qquad
[\mathbf Z^2:L]=R.
}
\tag{3.4}
\]

This proves the Smith clause.

## 4. Exact vertical generator

Put

\[
T=\sum_j\lambda_jb_j.
\]

Because \(\sum_j\lambda_j=1\),

\[
\boxed{\sum_jv_j=(1,T)^t\in L.}
\tag{4.1}
\]

Define

\[
d_j:=\lambda_j(b_j-T).
\tag{4.2}
\]

Then

\[
v_j-\lambda_j(1,T)^t=(0,d_j)^t,
\tag{4.3}
\]

so

\[
L=\mathbf Z(1,T)^t\oplus\mathbf Z(0,g)^t,
\qquad
g:=\gcd_jd_j.
\tag{4.4}
\]

Now

\[
\begin{aligned}
d_j
&=\lambda_j\left(b_j-\sum_i\lambda_i b_i\right)\\
&=\sum_i\lambda_i\lambda_j(b_j-b_i)\\
&=\sum_i\det(v_i,v_j),
\end{aligned}
\tag{4.5}
\]

so \(R\mid d_j\) for all \(j\), hence \(R\mid g\).

Conversely,

\[
\lambda_i d_j-\lambda_j d_i
=\lambda_i\lambda_j(b_j-b_i)
=\det(v_i,v_j),
\tag{4.6}
\]

so \(g\mid R\). Therefore

\[
\boxed{
R=\gcd_j\lambda_j(b_j-T).
}
\tag{4.7}
\]

Substituting into (4.4),

\[
\boxed{
L=\mathbf Z(1,T)^t\oplus\mathbf Z(0,R)^t.
}
\tag{4.8}
\]

Since the shear below fixes vertical vectors, this also gives

\[
\boxed{
L\cap(\{0\}\times\mathbf Z)=\{0\}\times R\mathbf Z.
}
\tag{4.9}
\]

## 5. Exact congruence and HNF form

Equation (4.8) is equivalent to

\[
\boxed{
L=\{(x,y)\in\mathbf Z^2:y-Tx\equiv0\pmod R\}.
}
\tag{5.1}
\]

Indeed, if \(y-Tx=Rq\), then

\[
(x,y)=x(1,T)+q(0,R).
\]

Thus the surjective map

\[
\phi:\mathbf Z^2\to\mathbf Z/R\mathbf Z,
\qquad
\phi(x,y)=y-Tx\pmod R
\tag{5.2}
\]

has kernel \(L\), giving

\[
\boxed{
0\to L\to\mathbf Z^2\xrightarrow{\phi}\mathbf Z/R\mathbf Z\to0.
}
\tag{5.3}
\]

The unimodular shear is

\[
S_T=
\begin{pmatrix}
1&0\\
-T&1
\end{pmatrix}
\in\operatorname{SL}_2(\mathbf Z),
\tag{5.4}
\]

and

\[
\boxed{
S_TL=\mathbf Z(1,0)^t\oplus\mathbf Z(0,R)^t.
}
\tag{5.5}
\]

So the shear identifies \(L\) literally with the diagonal Smith lattice.

For an HNF statement with no convention ambiguity, let \(t\) be the unique residue with

\[
0\le t<R,\qquad t\equiv T\pmod R.
\]

Then

\[
L=\mathbf Z(1,t)^t\oplus\mathbf Z(0,R)^t.
\tag{5.6}
\]

Under the lower-triangular column-HNF convention (transpose of the usual upper-triangular row-HNF convention), a reduced basis matrix is

\[
\boxed{
H=
\begin{pmatrix}
1&0\\
t&R
\end{pmatrix},
\qquad 0\le t<R.
}
\tag{5.7}
\]

The convention-free statement is always (5.1).

## 6. Exact formula for \(D\)

Let

\[
E:=b_n-T.
\tag{6.1}
\]

By (4.2),

\[
\boxed{c_j=\lambda_jE-d_j.}
\tag{6.2}
\]

First,

\[
\sum_jc_j
=b_n\sum_j\lambda_j-\sum_j\lambda_jb_j
=b_n-T
=E,
\tag{6.3}
\]

so \(D\mid E\). By (2.5), \(D\mid R\). Hence

\[
D\mid\gcd(R,E).
\tag{6.4}
\]

Conversely, \(R\mid d_j\) for every \(j\) by (4.7), so every divisor of both \(R\) and \(E\) divides

\[
c_j=\lambda_jE-d_j
\]

for every \(j\). Thus

\[
\gcd(R,E)\mid D.
\]

Therefore

\[
\boxed{D=\gcd(R,b_n-T).}
\tag{6.5}
\]

This proves the candidate shear formula.

There is also a sharp augmented-lattice form. Since

\[
S_T(1,b_n)^t=(1,E)^t,
\]

we get

\[
S_T\bigl(L+\mathbf Z(1,b_n)^t\bigr)
=\mathbf Z(1,0)^t\oplus\mathbf Z(0,D)^t.
\tag{6.6}
\]

Hence

\[
\boxed{[\mathbf Z^2:L+\mathbf Z(1,b_n)^t]=D.}
\tag{6.7}
\]

In the cyclic group \(\mathbf Z^2/L\simeq\mathbf Z/R\mathbf Z\), the class of \((1,b_n)^t\) is \(E\bmod R\), so

\[
\boxed{
\operatorname{ord}\bigl((1,b_n)^t+L\bigr)=\frac{R}{D}.
}
\tag{6.8}
\]

## 7. Balanced combinations: the image is exactly \(R\mathbf Z\)

Let

\[
K=\left\{u\in\mathbf Z^M:\sum_j u_j\lambda_j=0\right\}.
\]

For \(u\in K\),

\[
\begin{aligned}
\sum_j u_jc_j
&=\sum_j u_j\lambda_j(b_n-b_j)\\
&=-\sum_j u_j\lambda_jb_j.
\end{aligned}
\tag{7.1}
\]

Meanwhile

\[
\sum_j u_jv_j
=\left(0,\sum_j u_j\lambda_jb_j\right)
=\left(0,-\sum_j u_jc_j\right).
\tag{7.2}
\]

The map

\[
K\to L\cap(\{0\}\times\mathbf Z),
\qquad
u(u)=\sum_j u_jv_j,
\tag{7.3}
\]

is surjective: any vertical vector of \(L\) has some integer column representation, and its first coordinate being zero is exactly the balance condition.

Using (4.9),

\[
\nu(K)=\{0\}\times R\mathbf Z.
\]

Therefore

\[
\boxed{
\left\{\sum_j u_jc_j:u\in K\right\}=R\mathbf Z.
}
\tag{7.4}
\]

So the strongest possible lower-bound statement is exact:

\[
\boxed{
\sum_j u_jc_j\ne0,\ \sum_j u_j\lambda_j=0
\quad\Longrightarrow\quad
\left|\sum_j u_jc_j\right|\ge R.
}
\tag{7.5}
\]

And \(R\) is attainable.

### Explicit Bézout witness

Choose integers \(\alpha_j\) with

\[
\sum_j\alpha_jd_j=R,
\tag{7.6}
\]

possible by (4.7). Put

\[
A_0:=\sum_j\alpha_j\lambda_j,
\qquad
u_j:=A_0-\alpha_j.
\tag{7.7}
\]

Then, using \(\sum_j\lambda_j=1\),

\[
\sum_j u_j\lambda_j=0.
\tag{7.8}
\]

Also

\[
\sum_jd_j
=\sum_j\lambda_j(b_j-T)
=0,
\tag{7.9}
\]

so

\[
\sum_j u_jd_j
=A_0\sum_jd_j-\sum_j\alpha_jd_j
=-R.
\tag{7.10}
\]

For balanced \(u\), (6.2) gives

\[
\sum_j u_jc_j=-\sum_j u_jd_j=R.
\tag{7.11}
\]

Thus the minimum positive balanced value is constructively attained.

## 8. The only defect: what “nonzero” modifies

If “nonzero balanced combination” means a nonzero **value**, the candidate claim is true by (7.4).

If it means a nonzero coefficient vector \(u\), it is false whenever \(M\ge3\). The column map

\[
A:\mathbf Z^M\to\mathbf Z^2
\]

has rank two, hence

\[
\operatorname{rank}\ker A=M-2.
\tag{8.1}
\]

For \(M\ge3\), choose \(0\ne u\in\ker A\). Then

\[
\sum_j u_j\lambda_j=0,
\qquad
\sum_j u_j\lambda_jb_j=0,
\]

and therefore

\[
\sum_j u_jc_j=0.
\tag{8.2}
\]

Since \(M=\lfloor n/2\rfloor\), this ambiguity first occurs at \(n\ge6\).

For \(n=4,5\), \(M=2\) and \(\ker A=0\), so no nonzero zero-valued balanced relation exists.

## 9. Strongest abstract theorem

The argument did not use the Apéry recurrence. It holds for arbitrary weighted integer points.

Let \(m\ge2\), let \(\lambda_0,\dots,\lambda_{m-1}\in\mathbf Z\) satisfy

\[
\sum_j\lambda_j=1,
\]

and let \(z_0,\dots,z_{m-1}\in\mathbf Z\). Assume that for some \(i<j\),

\[
\lambda_i\lambda_j(z_j-z_i)\ne0.
\]

Define

\[
w_j=\lambda_j(1,z_j)^t,
\qquad
\mathcal L=\sum_j\mathbf Zw_j,
\]

\[
T_z=\sum_j\lambda_jz_j,
\qquad
R_z=\gcd_{i<j}\lambda_i\lambda_j(z_j-z_i).
\]

Then \(R_z>0\) and

\[
\boxed{
\mathcal L
=\mathbf Z(1,T_z)^t\oplus\mathbf Z(0,R_z)^t
=\{(x,y):y\equiv T_zx\pmod{R_z}\}.
}
\tag{9.1}
\]

Its Smith invariants are \((1,R_z)\), its vertical subgroup is \(\{0\}\times R_z\mathbf Z\), and

\[
\boxed{R_z=\gcd_j\lambda_j(z_j-T_z).}
\tag{9.2}
\]

For any \(z\in\mathbf Z\), define

\[
e_j=\lambda_j(z-z_j),
\qquad
E_z=z-T_z.
\]

Then

\[
\boxed{\gcd_j e_j=\gcd(R_z,E_z).}
\tag{9.3}
\]

On the balanced module

\[
K_\lambda=\{u:\sum_j u_j\lambda_j=0\},
\]

one has

\[
\boxed{
\left\{\sum_j u_je_j:u\in K_\lambda\right\}=R_z\mathbf Z.
}
\tag{9.4}
\]

The Apéry theorem is the specialization \(z_j=b_j\), \(z=b_n\). Its rank assumption is automatic from \(b_1-b_0=4\) and \(\lambda_0\lambda_1\ne0\).

## 10. Small independent exact-verification algorithm

The following standard-library Python checker recomputes the Apéry numbers directly from

\[
b_m=\sum_{k=0}^m\binom mk^2\binom{m+k}{k}^2,
\]

uses exact integer arithmetic only, checks the determinant signs and all gcd identities, and constructs a balanced Bézout witness attaining \(R\).

It is only a finite regression checker; no finite run is used in the proof and no asymptotic conclusion follows from it.

```python
from math import comb, gcd


def gcd_all(xs):
    g = 0
    for x in xs:
        g = gcd(g, abs(x))
    return g


def xgcd(a, b):
    # g >= 0 and x*a + y*b = g
    r0, r1 = a, b
    s0, s1 = 1, 0
    t0, t1 = 0, 1
    while r1:
        q = r0 // r1
        r0, r1 = r1, r0 - q * r1
        s0, s1 = s1, s0 - q * s1
        t0, t1 = t1, t0 - q * t1
    if r0 < 0:
        r0, s0, t0 = -r0, -s0, -t0
    return r0, s0, t0


def bezout_list(vals):
    # returns g and a_i with sum a_i vals_i = g
    g = 0
    coeffs = []
    for a in vals:
        g2, x, y = xgcd(g, a)
        coeffs = [x * c for c in coeffs] + [y]
        g = g2
    return g, coeffs


def apery(m):
    return sum(comb(m, k)**2 * comb(m + k, k)**2
               for k in range(m + 1))


def verify(n):
    assert n >= 4
    M = n // 2
    b = [apery(j) for j in range(n + 1)]

    lam = [
        (-1)**(M - 1 - j)
        * comb(n, j)
        * comb(n - j - 1, M - 1 - j)
        for j in range(M)
    ]

    assert sum(lam) == 1
    assert gcd_all(lam) == 1

    def det(i, j):
        return lam[i] * lam[j] * (b[j] - b[i])

    assert det(0, 1) == 4 * lam[0] * lam[1] != 0

    minors = [det(i, j)
              for i in range(M)
              for j in range(i + 1, M)]
    R = gcd_all(minors)
    assert R > 0

    entries = []
    for j in range(M):
        entries += [lam[j], lam[j] * b[j]]
    assert gcd_all(entries) == 1

    T = sum(lam[j] * b[j] for j in range(M))
    d = [lam[j] * (b[j] - T) for j in range(M)]

    assert gcd_all(d) == R
    for j in range(M):
        assert d[j] == sum(det(i, j) for i in range(M))

    for j in range(M):
        x = lam[j]
        y = lam[j] * b[j]
        assert (y - T * x) % R == 0

    E = b[n] - T
    c = [lam[j] * (b[n] - b[j]) for j in range(M)]
    D = gcd_all(c)

    assert sum(c) == E
    assert D == gcd(R, abs(E))

    for i in range(M):
        for j in range(i + 1, M):
            assert lam[i] * c[j] - lam[j] * c[i] == -det(i, j)

    # Construct balanced u with sum u_j c_j = R.
    g, alpha = bezout_list(d)
    assert g == R
    assert sum(alpha[j] * d[j] for j in range(M)) == R

    A0 = sum(alpha[j] * lam[j] for j in range(M))
    u = [A0 - alpha[j] for j in range(M)]

    assert sum(u[j] * lam[j] for j in range(M)) == 0
    assert sum(u[j] * c[j] for j in range(M)) == R

    t = T % R
    return {
        "n": n,
        "M": M,
        "R": R,
        "D": D,
        "T": T,
        "column_HNF": ((1, 0), (t, R)),
        "balanced_witness": u,
    }


# Finite regression only, not a proof:
# for n in range(4, 50):
#     verify(n)
```

## Final theorem-grade conclusion

For every \(n\ge4\), the exact lattice theorem is

\[
\boxed{
L=\mathbf Z(1,T)^t\oplus\mathbf Z(0,R)^t
=\ker\bigl((x,y)\mapsto y-Tx\bmod R\bigr),
}
\]

\[
\boxed{
\operatorname{SNF}(L)=(1,R),
\qquad
L\cap(\{0\}\times\mathbf Z)=\{0\}\times R\mathbf Z,
}
\]

\[
\boxed{D=\gcd(R,b_n-T),}
\]

and

\[
\boxed{
\left\{\sum_j u_jc_j:\sum_j u_j\lambda_j=0\right\}=R\mathbf Z.
}
\]

So \(R\) is the exact positive generator of the balanced-value ideal and is constructively attainable. The only defect in the candidate wording is the ambiguity between a nonzero coefficient vector and a nonzero resulting value; the former can map to zero once \(M\ge3\). No asymptotic statement is inferred.
