# Cold audit: exact lattice theorem for the integer Lagrange weights

## Verdict

All substantive lattice clauses are correct, with one wording correction.

For \(n\ge 4\), \(M=\lfloor n/2\rfloor\), and

\[
\lambda_j=(-1)^{M-1-j}\binom nj\binom{n-j-1}{M-1-j},\qquad 0\le j<M,
\]

put

\[
v_j=\lambda_j(1,b_j)^t,
\qquad
L=\sum_{j=0}^{M-1}\mathbf Z v_j,
\]

\[
T=\sum_j\lambda_jb_j,
\qquad
c_j=\lambda_j(b_n-b_j),
\qquad
D=\gcd_j c_j,
\]

and

\[
R=\gcd_{0\le i<j<M}\lambda_i\lambda_j(b_j-b_i),
\]

where all gcds are positive.

Then the exact result is

\[
\boxed{
L=\mathbf Z(1,T)^t\oplus \mathbf Z(0,R)^t
=\{(x,y)\in\mathbf Z^2:y\equiv Tx\pmod R\}.
}
\tag{0.1}
\]

Consequently

\[
\boxed{\operatorname{SNF}(L)=(1,R),}
\tag{0.2}
\]

\[
\boxed{L\cap(\{0\}\times\mathbf Z)=\{0\}\times R\mathbf Z,}
\tag{0.3}
\]

and

\[
\boxed{D=\gcd(R,b_n-T).}
\tag{0.4}
\]

More strongly, if

\[
K=\left\{u=(u_j)\in\mathbf Z^M:\sum_j u_j\lambda_j=0\right\},
\]

then

\[
\boxed{
\left\{\sum_j u_jc_j:u\in K\right\}=R\mathbf Z.
}
\tag{0.5}
\]

Thus every **nonzero resulting value** of a balanced combination has absolute value at least \(R\), and both \(R\) and \(-R\) occur.

The wording caveat is important: if “nonzero balanced combination” means merely a nonzero coefficient vector \(u\), the claim is false once \(M\ge3\). In that range the integer relation module among the rank-two columns \(v_j\) has rank \(M-2\), so there are nonzero \(u\) satisfying both

\[
\sum_j u_j\lambda_j=0,
\qquad
\sum_j u_jc_j=0.
\]

The correct minimum statement is therefore about **nonzero values**, not nonzero coefficient vectors.

The current P3.2 map explicitly requires inherited claims to be re-verified algebraically and records generic Fitting/Smith compression as exhausted without new Apéry-specific structure. The proof below is independent of the previous Q1998 drop and uses only the displayed weights, \(b_0=1,b_1=5\), and exact integer linear algebra.

# 1. Lagrange identity and primitivity of the first row

The coefficients are exactly the Lagrange weights for evaluation at \(x=n\) from the nodes \(0,1,\ldots,M-1\):

\[
\boxed{
\lambda_j=
\prod_{\substack{0\le k<M\\k\ne j}}
\frac{n-k}{j-k}.
}
\tag{1.1}
\]

Indeed,

\[
\prod_{k\ne j}(n-k)
=\frac{n!}{(n-M)!(n-j)},
\]

while

\[
\prod_{k\ne j}(j-k)
=(-1)^{M-1-j}j!(M-1-j)!.
\]

Their quotient is

\[
(-1)^{M-1-j}
\frac{n!}{j!(n-j)(M-1-j)!(n-M)!}
=(-1)^{M-1-j}\binom nj\binom{n-j-1}{M-1-j}.
\]

Therefore every polynomial \(f\) of degree at most \(M-1\) satisfies

\[
f(n)=\sum_{j=0}^{M-1}\lambda_j f(j).
\tag{1.2}
\]

Taking \(f=1\),

\[
\boxed{\sum_j\lambda_j=1,}
\tag{1.3}
\]

hence

\[
\boxed{\gcd_j\lambda_j=1.}
\tag{1.4}
\]

All \(\lambda_j\) are nonzero. In particular, since \(M\ge2\),

\[
\lambda_0=(-1)^{M-1}\binom{n-1}{M-1}\ne0,
\]

\[
\lambda_1=(-1)^{M-2}n\binom{n-2}{M-2}\ne0.
\tag{1.5}
\]

# 2. Rank and determinant signs

Let

\[
A=[v_0\ v_1\ \cdots\ v_{M-1}]
=\begin{pmatrix}
\lambda_0&\lambda_1&\cdots\\
\lambda_0b_0&\lambda_1b_1&\cdots
\end{pmatrix}.
\]

For \(i<j\),

\[
\boxed{
\det(v_i,v_j)=\lambda_i\lambda_j(b_j-b_i).
}
\tag{2.1}
\]

The sign in the definition of \(R\) is therefore correct.

Because \(b_0=1\) and \(b_1=5\),

\[
\det(v_0,v_1)=4\lambda_0\lambda_1\ne0.
\tag{2.2}
\]

Hence

\[
\boxed{\operatorname{rank}_{\mathbf Z}L=2,\qquad R>0.}
\tag{2.3}
\]

There is no hidden rank-one endpoint for any \(n\ge4\).

For later sign checks, if

\[
x_n=(1,b_n)^t,
\]

then

\[
\boxed{
\det(v_j,x_n)=\lambda_j(b_n-b_j)=c_j,
}
\tag{2.4}
\]

whereas

\[
\boxed{
\lambda_i c_j-\lambda_j c_i
=\lambda_i\lambda_j(b_i-b_j)
=-\det(v_i,v_j).
}
\tag{2.5}
\]

Thus pairwise elimination gives \(D\mid R\), with the minus sign exactly as in (2.5).

# 3. Smith invariants are exactly [1m(1,R)[0m

For a rank-two integer matrix, the first determinantal divisor is the gcd of all entries and the second is the gcd of all \(2\times2\) minors.

Here

\[
\delta_1
=\gcd_j(\lambda_j,\lambda_jb_j)
=\gcd_j\lambda_j
=1
\tag{3.1}
\]

by (1.4), while

\[
\delta_2
=\gcd_{i<j}\det(v_i,v_j)
=R.
\tag{3.2}
\]

Since the invariant factors are

\[
s_1=\delta_1,
\qquad
s_1s_2=\delta_2,
\]

we obtain

\[
\boxed{s_1=1,\qquad s_2=R.}
\tag{3.3}
\]

Equivalently, there exist unimodular matrices

\[
U\in\operatorname{GL}_2(\mathbf Z),
\qquad
V\in\operatorname{GL}_M(\mathbf Z)
\]

such that

\[
UAV=
\begin{pmatrix}
1&0&0&\cdots&0\\
0&R&0&\cdots&0
\end{pmatrix}.
\tag{3.4}
\]

Hence

\[
\boxed{
\mathbf Z^2/L\simeq\mathbf Z/R\mathbf Z,
\qquad
[\mathbf Z^2:L]=R.
}
\tag{3.5}
\]

So the proposed Smith statement is correct.

# 4. Exact vertical generator and the one-row gcd formula

Put

\[
T=\sum_j\lambda_jb_j.
\tag{4.1}
\]

Because \(\sum_j\lambda_j=1\), summing the columns gives

\[
\boxed{
\sum_j v_j=(1,T)^t\in L.
}
\tag{4.2}
\]

Define

\[
d_j:=\lambda_j(b_j-T).
\tag{4.3}
\]

Then

\[
v_j-\lambda_j(1,T)^t=(0,d_j)^t.
\tag{4.4}
\]

Therefore

\[
L=\mathbf Z(1,T)^t+\sum_j\mathbf Z(0,d_j)^t
=\mathbf Z(1,T)^t\oplus
\mathbf Z(0,g)^t,
\tag{4.5}
\]

where

\[
g:=\gcd_j d_j.
\]

The equality \(g=R\) can be proved without invoking Smith form. First,

\[
\begin{aligned}
d_j
&=\lambda_j\left(b_j-\sum_i\lambda_i b_i\right)\\
&=\sum_i\lambda_i\lambda_j(b_j-b_i)\\
&=\sum_i\det(v_i,v_j),
\end{aligned}
\tag{4.6}
\]

so \(R\mid d_j\) for every \(j\), hence \(R\mid g\).

Conversely,

\[
\lambda_i d_j-\lambda_j d_i
=\lambda_i\lambda_j(b_j-b_i)
=\det(v_i,v_j),
\tag{4.7}
\]

so \(g\) divides every minor, hence \(g\mid R\).

Thus

\[
\boxed{
R=\gcd_j\lambda_j(b_j-T).
}
\tag{4.8}
\]

Substituting this in (4.5),

\[
\boxed{
L=\mathbf Z(1,T)^t\oplus\mathbf Z(0,R)^t.
}
\tag{4.9}
\]

Because the two displayed generators are linearly independent, the sum is direct.

It follows immediately that

\[
\boxed{
L\cap(\{0\}\times\mathbf Z)=\{0\}\times R\mathbf Z.
}
\tag{4.10}
\]

So the proposed vertical-subgroup clause is correct.

# 5. Exact congruence and HNF formulation

Equation (4.9) is equivalent to

\[
\boxed{
L=\{(x,y)\in\mathbf Z^2:y-Tx\equiv0\pmod R\}.
}
\tag{5.1}
\]

Indeed, every vector on the right has the unique form

\[
(x,y)=x(1,T)+\frac{y-Tx}{R}(0,R).
\]

Equivalently, the map

\[
\phi:\mathbf Z^2\longrightarrow\mathbf Z/R\mathbf Z,
\qquad
\phi(x,y)=y-Tx\pmod R,
\tag{5.2}
\]

is surjective and has kernel exactly \(L\). Thus there is a short exact sequence

\[
\boxed{
0\longrightarrow L\longrightarrow\mathbf Z^2
\xrightarrow{\ \phi\ }\mathbf Z/R\mathbf Z
\longrightarrow0.
}
\tag{5.3}
\]

This is the cleanest congruence formulation of the lattice invariant.

For the explicit unimodular shear, let

\[
S_T=
\begin{pmatrix}
1&0\\
-T&1
\end{pmatrix}
\in\operatorname{SL}_2(\mathbf Z).
\tag{5.4}
\]

Then

\[
S_T(x,y)^t=(x,y-Tx)^t,
\]

so (4.9) becomes

\[
\boxed{
S_TL=\mathbf Z(1,0)^t\oplus\mathbf Z(0,R)^t.
}
\tag{5.5}
\]

Thus the shear identifies \(L\) literally with the diagonal lattice underlying the Smith form.

For an HNF statement, let \(t\) be the unique integer with

\[
0\le t<R,
\qquad
t\equiv T\pmod R.
\tag{5.6}
\]

Then

\[
(1,t)^t=(1,T)^t-q(0,R)^t
\]

for a suitable integer \(q\), so

\[
\boxed{
L=\mathbf Z(1,t)^t\oplus\mathbf Z(0,R)^t.
}
\tag{5.7}
\]

Under the lower-triangular **column-HNF** convention (transpose of the usual upper-triangular row-HNF convention), a reduced basis matrix is

\[
\boxed{
H=
\begin{pmatrix}
1&0\\
t&R
\end{pmatrix},
\qquad 0\le t<R.
}
\tag{5.8}
\]

This avoids any convention ambiguity: regardless of HNF convention, the invariant statement is the congruence (5.1).

# 6. Exact formula for \(D\)

Let

\[
E:=b_n-T.
\tag{6.1}
\]

Using (4.3),

\[
\boxed{
c_j=\lambda_jE-d_j.}
\tag{6.2}
\]

We now prove

\[
\boxed{D=\gcd(R,E).}
\tag{6.3}
\]

First,

\[
\sum_j c_j
=b_n\sum_j\lambda_j-\sum_j\lambda_jb_j
=b_n-T
=E,
\tag{6.4}
\]

so \(D\mid E\).

Second, (2.5) shows \(D\) divides every \(2\times2\) minor, hence \(D\mid R\). Therefore

\[
D\mid\gcd(R,E).
\tag{6.5}
\]

Conversely, by (4.8), \(R\mid d_j\) for every \(j\). Hence any common divisor of \(R\) and \(E\) divides both terms on the right side of (6.2), and therefore divides every \(c_j\). Thus

\[
\gcd(R,E)\mid D.
\tag{6.6}
\]

Combining (6.5) and (6.6) proves (6.3).

So the candidate shear formula is correct.

There is also an exact augmented-lattice interpretation. Since

\[
S_T(1,b_n)^t=(1,E)^t,
\]

we have

\[
S_T\bigl(L+\mathbf Z(1,b_n)^t\bigr)
=\mathbf Z(1,0)^t
+\mathbf Z(0,R)^t
+\mathbf Z(1,E)^t
\]

\[
=\mathbf Z(1,0)^t
\oplus\mathbf Z(0,\gcd(R,E))^t.
\tag{6.7}
\]

Therefore

\[
\boxed{
[\mathbf Z^2:L+\mathbf Z(1,b_n)^t]=D.
}
\tag{6.8}
\]

In the cyclic quotient \(\mathbf Z^2/L\simeq\mathbf Z/R\mathbf Z\), the class of \((1,b_n)^t\) is exactly \(E\bmod R\). Consequently its order is

\[
\boxed{
\operatorname{ord}\bigl((1,b_n)^t+L\bigr)=\frac{R}{D}.
}
\tag{6.9}
\]

This is the sharp Smith/congruence meaning of the gcd \(D\).

# 7. Balanced combinations: exact image is \(R\mathbf Z\)

Let

\[
K=\ker\left(\mathbf Z^M\xrightarrow{\lambda}\mathbf Z\right)
=\left\{u:\sum_j u_j\lambda_j=0\right\}.
\tag{7.1}
\]

For \(u\in K\),

\[
\begin{aligned}
\sum_j u_j c_j
&=\sum_j u_j\lambda_j(b_n-b_j)\\
&=b_n\sum_j u_j\lambda_j-\sum_j u_j\lambda_jb_j\\
&=-\sum_j u_j\lambda_jb_j.
\end{aligned}
\tag{7.2}
\]

On the other hand,

\[
\sum_j u_jv_j
=\left(\sum_j u_j\lambda_j,\sum_j u_j\lambda_jb_j\right)
=\left(0,-\sum_j u_jc_j\right).
\tag{7.3}
\]

Thus the map

\[
K\longrightarrow L\cap(\{0\}\times\mathbf Z),
\qquad
u(u)=\sum_j u_jv_j,
\tag{7.4}
\]

has second coordinate equal to \(-\sum_j u_jc_j\).

It is surjective: every vertical vector in \(L\) has some representation \(\sum_j u_jv_j\), and its first coordinate being zero is exactly the balance condition \(u\in K\).

Using (4.10),

\[
\nu(K)=\{0\}\times R\mathbf Z.
\tag{7.5}
\]

Therefore

\[
\boxed{
\left\{\sum_j u_jc_j:u\in K\right\}=R\mathbf Z.
}
\tag{7.6}
\]

This is stronger than a lower bound.

Consequences:

1. If \(\sum_j u_jc_j\ne0\) and \(\sum_j u_j\lambda_j=0\), then
   \[
   \boxed{\left|\sum_j u_jc_j\right|\ge R.}
   \tag{7.7}
   \]
2. There exists a balanced \(u\) with
   \[
   \boxed{\sum_j u_jc_j=R,}
   \tag{7.8}
   \]
   and another with value \(-R\).
3. Hence \(R\) is the exact positive generator of the balanced-value ideal.

### Explicit Bézout witness attaining \(R\)

By (4.8), choose integers \(\alpha_j\) with

\[
\sum_j\alpha_jd_j=R.
\tag{7.9}
\]

Put

\[
A_0:=\sum_j\alpha_j\lambda_j,
\qquad
u_j:=A_0-\alpha_j.
\tag{7.10}
\]

Then

\[
\sum_j u_j\lambda_j
=A_0\sum_j\lambda_j-\sum_j\alpha_j\lambda_j
=0.
\tag{7.11}
\]

Also

\[
\sum_jd_j
=\sum_j\lambda_j(b_j-T)
=T-T=0,
\tag{7.12}
\]

so

\[
\sum_j u_jd_j
=A_0\sum_jd_j-\sum_j\alpha_jd_j
=-R.
\tag{7.13}
\]

For balanced \(u\), equation (6.2) gives

\[
\sum_j u_jc_j=-\sum_j u_jd_j=R.
\tag{7.14}
\]

Thus attainability is constructive, not merely existential.

# 8. The wording defect: nonzero coefficient vector versus nonzero value

The sentence

> every nonzero balanced integer combination has absolute value at least \(R\)

is correct only if “nonzero” modifies the **resulting integer value**.

If it means \(u\ne0\), it fails whenever \(M\ge3\). Indeed, the column map

\[
A:\mathbf Z^M\to\mathbf Z^2
\]

has rank two, so its integer kernel has rank

\[
\operatorname{rank}\ker A=M-2.
\tag{8.1}
\]

For \(M\ge3\), choose \(0\ne u\in\ker A\). Then simultaneously

\[
\sum_j u_j\lambda_j=0,
\qquad
\sum_j u_j\lambda_jb_j=0,
\tag{8.2}
\]

and therefore

\[
\sum_j u_jc_j=0.
\tag{8.3}
\]

Since \(M=\lfloor n/2\rfloor\), this ambiguity first matters at \(n\ge6\).

For \(n=4,5\), one has \(M=2\), \(A\) has rank two, and \(\ker A=0\), so no such nonzero zero-valued balanced relation exists.

The fully correct quantified statement is therefore exactly (7.6).

# 9. Strongest abstract form

Nothing in Sections 3--8 used the Apéry recurrence. The result is an elementary theorem about any primitive weighted set of points.

## Abstract rank-two lattice theorem

Let \(m\ge2\), let \(\lambda_0,\dots,\lambda_{m-1}\in\mathbf Z\) satisfy

\[
\sum_j\lambda_j=1,
\]

and let \(z_0,\dots,z_{m-1}\in\mathbf Z\). Assume that for some \(i<j\),

\[
\lambda_i\lambda_j(z_j-z_i)\ne0.
\]

Define

\[
w_j=\lambda_j(1,z_j)^t,
\qquad
\mathcal L=\sum_j\mathbf Zw_j,
\]

\[
T_z=\sum_j\lambda_jz_j,
\qquad
R_z=\gcd_{i<j}\lambda_i\lambda_j(z_j-z_i).
\]

Then \(R_z>0\) and

\[
\boxed{
\mathcal L
=\mathbf Z(1,T_z)^t\oplus\mathbf Z(0,R_z)^t
=\{(x,y):y\equiv T_zx\pmod{R_z}\}.
}
\tag{9.1}
\]

Its Smith invariant factors are \((1,R_z)\), its vertical subgroup is \(\{0\}\times R_z\mathbf Z\), and

\[
R_z=\gcd_j\lambda_j(z_j-T_z).
\tag{9.2}
\]

For any \(z\in\mathbf Z\), put

\[
e_j=\lambda_j(z-z_j),
\qquad
E_z=z-T_z.
\]

Then

\[
\boxed{
\gcd_j e_j=\gcd(R_z,E_z).
}
\tag{9.3}
\]

Moreover, on the balanced module

\[
K_\lambda=\{u:\sum_j u_j\lambda_j=0\},
\]

one has the exact image identity

\[
\boxed{
\left\{\sum_j u_je_j:u\in K_\lambda\right\}=R_z\mathbf Z.
}
\tag{9.4}
\]

The Apéry/Lagrange theorem is the specialization \(z_j=b_j\), \(z=b_n\). The rank assumption is automatic there from \(b_1-b_0=4\) and \(\lambda_0\lambda_1\ne0\).

# 10. Small independent exact-verification algorithm

The following standard-library Python is an independent finite checker. It recomputes the Apéry numbers directly from

\[
b_m=\sum_{k=0}^m\binom mk^2\binom{m+k}{k}^2,
\]

uses only exact integers, checks all determinant signs and gcd identities, and constructs an explicit balanced Bézout vector attaining \(R\).

It is a regression checker only; finite runs of it are not used anywhere in the proof and imply no asymptotic statement.

```python
from math import comb, gcd


def gcd_all(xs):
    g = 0
    for x in xs:
        g = gcd(g, abs(x))
    return g


def xgcd(a, b):
    # returns (g,x,y) with g>=0 and x*a + y*b = g
    r0, r1 = a, b
    s0, s1 = 1, 0
    t0, t1 = 0, 1
    while r1:
        q = r0 // r1
        r0, r1 = r1, r0 - q * r1
        s0, s1 = s1, s0 - q * s1
        t0, t1 = t1, t0 - q * t1
    if r0 < 0:
        r0, s0, t0 = -r0, -s0, -t0
    return r0, s0, t0


def bezout_list(vals):
    # returns g>=0 and coeffs a_i with sum a_i vals_i = g
    g = 0
    coeffs = []
    for a in vals:
        g2, x, y = xgcd(g, a)
        coeffs = [x * c for c in coeffs] + [y]
        g = g2
    return g, coeffs


def apery(m):
    return sum(comb(m, k)**2 * comb(m + k, k)**2
               for k in range(m + 1))


def verify(n):
    assert n >= 4
    M = n // 2
    b = [apery(j) for j in range(n + 1)]

    lam = [
        (-1)**(M - 1 - j)
        * comb(n, j)
        * comb(n - j - 1, M - 1 - j)
        for j in range(M)
    ]

    assert sum(lam) == 1
    assert gcd_all(lam) == 1

    def det(i, j):
        return lam[i] * lam[j] * (b[j] - b[i])

    # rank 2 and determinant sign
    assert det(0, 1) == 4 * lam[0] * lam[1] != 0

    minors = [det(i, j)
              for i in range(M)
              for j in range(i + 1, M)]
    R = gcd_all(minors)
    assert R > 0

    # first Smith determinantal divisor
    entries = []
    for j in range(M):
        entries += [lam[j], lam[j] * b[j]]
    assert gcd_all(entries) == 1

    T = sum(lam[j] * b[j] for j in range(M))
    d = [lam[j] * (b[j] - T) for j in range(M)]

    # one-row vertical gcd equals pairwise-minor gcd
    assert gcd_all(d) == R
    for j in range(M):
        assert d[j] == sum(det(i, j) for i in range(M))

    # HNF / congruence test on all generators
    for j in range(M):
        x = lam[j]
        y = lam[j] * b[j]
        assert (y - T * x) % R == 0

    E = b[n] - T
    c = [lam[j] * (b[n] - b[j]) for j in range(M)]
    D = gcd_all(c)

    assert sum(c) == E
    assert D == gcd(R, abs(E))

    # elimination sign audit
    for i in range(M):
        for j in range(i + 1, M):
            assert lam[i] * c[j] - lam[j] * c[i] == -det(i, j)

    # Construct a balanced coefficient vector attaining +R.
    g, alpha = bezout_list(d)
    assert g == R
    assert sum(alpha[j] * d[j] for j in range(M)) == R

    A0 = sum(alpha[j] * lam[j] for j in range(M))
    u = [A0 - alpha[j] for j in range(M)]

    assert sum(u[j] * lam[j] for j in range(M)) == 0
    assert sum(u[j] * c[j] for j in range(M)) == R

    t = T % R
    return {
        "n": n,
        "M": M,
        "R": R,
        "D": D,
        "T": T,
        "column_HNF": ((1, 0), (t, R)),
        "balanced_witness": u,
    }


# Example finite regression loop (not a proof):
# for n in range(4, 50):
#     verify(n)
```

The algorithm verifies exactly the finite integer identities proved above and does not use the Apéry recurrence or any floating-point arithmetic.

# Final theorem-grade conclusion

For every \(n\ge4\), the candidate lattice theorem is correct after interpreting “nonzero balanced combination” as a **nonzero value**. Precisely,

\[
\boxed{
L=\mathbf Z(1,T)^t\oplus\mathbf Z(0,R)^t
=\ker\bigl((x,y)\mapsto y-Tx\bmod R\bigr),
}
\]

\[
\boxed{
\operatorname{SNF}(L)=(1,R),
\qquad
L\cap(\{0\}\times\mathbf Z)=\{0\}\times R\mathbf Z,
}
\]

\[
\boxed{
D=\gcd(R,b_n-T),
}
\]

and

\[
\boxed{
\left\{\sum_j u_jc_j:\sum_j u_j\lambda_j=0\right\}=R\mathbf Z.
}
\]

Thus \(R\) is not merely a lower bound for nonzero balanced values: it is their exact positive generator and is constructively attainable. The only literal defect in the candidate wording is that nonzero balanced **coefficient vectors** can map to zero when \(M\ge3\). No asymptotic conclusion is needed or inferred.
