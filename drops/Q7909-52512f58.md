# Local vanishing-cycle descent at the toric K3 conifold branch

## 1. Setup and conventions

Let
\[
\Lambda(u,v,w)=\frac{uv(w-1)(1-uvw)}{w(u-1)(v-1)}.
\]
At the extra open singularity we have
\[
u=v=u_0,\qquad w=2-u_0,
\qquad u_0^2-2u_0-1=0,
\]
and the branch value is
\[
\alpha=12u_0+5,\qquad \alpha^2-34\alpha+1=0.
\]
The singularity is an ordinary double point in relative dimension two. Write the smoothing parameter as
\[
t=\Lambda-\alpha.
\]

I use geometric Frobenius throughout this answer. Arithmetic Frobenius is its inverse. For a Tate twist one has
\[
\operatorname{Frob}_{geom}|\mathbf Q_\ell(-1)=p,
\]
while arithmetic Frobenius acts by \(p^{-1}\). Thus the weight-two vanishing eigenvalue below is stated for geometric Frobenius.

## 2. Local Morse equation and the vanishing line

The logarithmic Hessian computation in the file gives
\[
\det(H_{log}\Lambda)=\frac{u_0-1}{2}.
\]
Because the critical point is nondegenerate, the formal Morse lemma over the residue field gives étale local coordinates \((x,y,z)\) in which the family is
\[
t=x^2+y^2+z^2
\]
up to multiplication by a unit. More invariantly the quadratic form is the Hessian quadratic form and its discriminant is the determinant of the Hessian matrix modulo squares.

For an A1 singularity of a relative surface, the vanishing cohomology is rank one and is described by the Picard--Lefschetz vanishing cycle. The relevant formula is the standard one in SGA 7, Exp. XV (vanishing cycles for isolated quadratic singularities), together with the explicit A1 computation in Katz--Laumon: the rank-one local system is the discriminant character of the quadratic form multiplied by the character of the smoothing parameter derivative.

In the present case the descent character is therefore
\[
\chi_{van}=\left(\frac{-\det(q)}{p}\right)\left(\frac{\partial t}{\partial s}\middle/p\right),
\]
where the first symbol is the quadratic-form discriminant character and the second records a possible change of smoothing coordinate.

## 3. The smoothing derivative

The family parameter is not an arbitrary coordinate: it is exactly the value of \(\Lambda\). Therefore a local parameter on the base satisfies
\[
 t=\Lambda-\alpha.
\]
Changing the base coordinate by \(t\mapsto ct\) changes the vanishing cycle generator by the quadratic character \((c/p)\). The derivative contribution is thus
\[
\left(\frac{dt}{d(\Lambda-\alpha)}\middle/p\right)=1.
\]
There is no hidden quadratic base change in this explicit toric family because the parameter itself is defined over the branch residue field and the local equation is obtained from the actual function \(\Lambda\), not from a chosen simultaneous resolution.

Hence
\[
\chi_{van}=\left(\frac{-\det(q)}p\right).
\]

The exceptional curve being split is a different statement: it concerns the resolution divisor. It does not identify the vanishing line with the exceptional class. The vanishing line is the quotient in nearby cycles; the exceptional curve appears after resolution.

## 4. Evaluation of the character

The local Hessian determinant differs from the logarithmic Hessian by squares of the coordinate Jacobian. Therefore the square class is unchanged. The conifold quadratic discriminant gives
\[
\det(q)\equiv \frac{u_0-1}{2}\pmod{(\mathbf F_p^\times)^2}.
\]
Consequently the explicit formula is
\[
\boxed{
 e_p(\alpha)=\frac{1-\left(\frac{-(u_0-1)/2}{p}\right)}2
}
\]
if one defines the defect as the indicator that the vanishing character is nontrivial.

Equivalently, the Frobenius eigenvalue on the geometric vanishing line is
\[
\boxed{
 p\left(\frac{-(u_0-1)/2}{p}\right).
}
\]

Thus the claim \(e_p(\alpha)=0\) is not a formal consequence of splitness of the exceptional conic. It requires the above Legendre symbol to be \(+1\).

## 5. Simplification using the branch equation

Since
\[
\alpha=12u_0+5,
\]
we have
\[
u_0-1=\frac{\alpha-17}{12}.
\]
Therefore
\[
 e_p(\alpha)=\frac{1-\left(\frac{-(\alpha-17)/24}{p}\right)}2.
\]
This is the explicit arithmetic formula.

There is no identity forcing this symbol to be always +1 for primes for which \(\alpha\in\mathbf F_p\). The branch condition only says
\[
\alpha^2-34\alpha+1=0,
\]
which controls the existence of the singular fiber, not the orientation of the vanishing cycle.

## 6. Comparison with the point-count trace

Let \(\widetilde X_\alpha\) be the minimal resolution. The extra exceptional \(\mathbf P^1\) contributes a Tate class with geometric Frobenius eigenvalue \(p\). This gives
\[
\operatorname{Tr}H^2(X_\alpha)
=\operatorname{Tr}H^2(\widetilde X_\alpha)-p.
\]
This identity is valid because the A1 resolution is split and the exceptional divisor is defined over \(\mathbf F_p\).

However the primitive trace used in the Mellin formula is not automatically the trace of the whole singular fiber. Removing the divisor lattice leaves the middle-extension stalk. At the branch point one has
\[
\theta_p(\alpha)=\operatorname{Tr}(\operatorname{Frob}|\mathcal P_\alpha),
\]
where \(\mathcal P\) is the primitive sheaf.

The rank-one vanishing summand contributes exactly
\[
 p\left(\frac{-(u_0-1)/2}{p}\right).
\]
Therefore the correction relative to the naive smooth-family specialization is
\[
\boxed{
E_{br}=p\left(\frac{-(u_0-1)/2}{p}\right)-p
}
\]
if the reference model inserts a split Tate line. Equivalently,
\[
\boxed{
E_{br}=0\iff \left(\frac{-(u_0-1)/2}{p}\right)=1.
}
\]

## 7. Conclusion

The proposed unconditional conclusion from Q7908 cannot be completed from the stated hypotheses. For the explicit toric family, the missing datum is the quadratic descent character of the A1 vanishing cycle. The exceptional conic being split proves that the resolution class is Tate; it does not prove that the vanishing cycle descends with trivial character.

The exact branch defect is the Legendre-symbol expression above. To claim \(e_p(\alpha)=0\) for every branch prime one must additionally prove
\[
\left(\frac{-(u_0-1)/2}{p}\right)=1
\]
for both roots \(u_0\) whenever they exist. Without that arithmetic identity, the defect is not zero in general.
