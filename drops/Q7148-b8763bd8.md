# P32 M4R minimality audit R2

## 1. Audit of the proposed M4R implication

The proposed marked return statement is

\[
\sum_{X<p\le 2X}\log p\sum_{b_r=0\pmod p}\binom{R_{p,r}(H)}{3}\ \ll_\epsilon X^{1+\epsilon}H,
\]

where \(R_{p,r}(H)\) is the number of later zeros within a window of length \(H\).

The combinatorial conversion is the first place to check. If a block contains \(k\) zeros, then

\[
\binom{k}{4}\le k-3+\binom{k-1}{3}
\]

is not the right direct estimate for the needed statistic: the exact identity needed is simply

\[
k\le 3+(k-3)_+.
\]

The usual M4R route pays for the excess through all four-subsets:

\[
(k-3)_+\le \binom{k}{4}
\]

for \(k\ge4\). This is true, but loses a factor of roughly \(k^3\) in dense clusters. Therefore M4R is a sufficient but much stronger marked statement than the zero-counting reduction actually uses.

The exponent bookkeeping is:

* number of blocks: \(\asymp p/H\);
* baseline contribution: at most \(3p/H\) per prime;
* excess contribution: supplied by marked quadruples.

With \(H=X^{1/2}\), an M4R bound \(X^{1+\epsilon}H\) gives total excess

\[
X^{3/2+\epsilon},
\]

and after summing over primes with the \(\log p\) weight one obtains

\[
\sum_{p\sim X}Z(p)\ll X^{3/2+o(1)}/\log X.
\]

The logarithmic factor is only the conversion from the Chebyshev weight \(\log p\) to the unweighted prime sum; no hidden extra saving appears.

## 2. Weakest clean marked statement

The correct minimal statement should not count all four-subsets. Define a deterministic sparse selector.

For each ordered zero list

\[
z_1<\cdots<z_k
\]

inside an H-block, select only

\[
Q(z_1,\ldots,z_k)=\{(z_i,z_{i+1},z_{i+2},z_{i+3}):1\le i\le k-3\}.
\]

This is the consecutive quadruple selector. It has exactly

\[
|Q|=\max(k-3,0)
\]

members and is deterministic, independent of any later collision property.

The required statement is therefore:

\[
\boxed{
\sum_{X<p\le2X}\log p
\sum_{b_r=0(p)}
\#Q_{p,r,H}
\ll_\epsilon X^{1+\epsilon}H
}
\]

with \(H=\lfloor\sqrt X\rfloor\).

This is enough because every block satisfies the exact inequality

\[
k\le3+\#Q.
\]

No cardinality of arbitrary four-subsets is involved.

## 3. Radical/gcd encoding issue

A consecutive condition is not naturally represented by a gcd or radical of the return polynomials. A gcd detects existence of common roots:

\[
N_a(r)=N_b(r)=N_c(r)=0,
\]

but does not know that there is no intermediate zero between the selected returns.

Therefore a radical encoding such as

\[
\operatorname{rad}(N_aN_bN_c)
\]

cannot isolate consecutive quadruples without adding exclusion factors. Those exclusion factors are essentially the missing sparsification rule and must be defined explicitly.

The deterministic selector above avoids this circularity: it is computed from the ordered zero set first, then the algebraic event is attached only to those selected quadruples.

## 4. Comparison with M4R and HM_k/AT

M4R controls

\[
\binom{k}{4}
\]

inside a dense block. The proposed consecutive statistic controls only

\[
k-3.
\]

Hence:

\[
\text{consecutive-M4R}\ \ll\ \text{M4R}
\]

is expected; M4R implies the weaker statement, but the converse is false.

The HM_k/AT hypotheses in the proof.tex framework are also higher-moment statements: they control algebraic collision multiplicities of return constraints. They are closer to M4R than to the sparse excess statistic. They pay for all configurations satisfying the chosen polynomial equalities, not only the configurations needed by the block partition.

The minimal target should therefore be an HM-type theorem for a selected chain, not a fourth moment over all tuples.

## 5. Status of proofs

No current theorem proves even the weaker consecutive marked statement.

The existing unconditional information gives only the generic finite-field bounds coming from degree/resultant arguments. They control individual collision varieties but do not give the required prime average with square-root window.

The missing factor is the arithmetic saving in the prime average. Existing bounds effectively treat the selected return equations as having no additional cancellation over primes. They leave a loss comparable to the number of possible starting states/parameter values, whereas the desired result requires an average saving down to

\[
X^{1+o(1)}H.
\]

At \(H=\sqrt X\), this is a square-root-level gain over the trivial dense enumeration.

## 6. Fail-closed conclusion

* M4R is not minimal. It proves much more than the reduction requires.
* The clean minimal replacement is the deterministic consecutive-quadruple marked sum above.
* Consecutiveness cannot currently be recovered from a plain gcd/radical condition without adding explicit exclusion data.
* No theorem currently establishes the weaker statement.
* The remaining obstacle is exactly the prime-averaged sparsity/cancellation estimate for selected return chains, not the combinatorial block reduction.
