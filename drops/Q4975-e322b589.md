# 1. Exact separation between local returns and global reachability

This is the decisive point.

For `1<=n<=p-2` introduce the integral projective transfer matrix

```latex
A_n=
\begin{pmatrix}
P(n)&-n^3\\
(n+1)^3&0
\end{pmatrix}.
\tag{1.1}
```

If

```latex
v_n=\binom{b_n}{b_{n-1}},
```

then the Apéry recurrence is exactly

```latex
A_nv_n=(n+1)^3v_{n+1}.
\tag{1.2}
```

Since

```latex
\det A_n=n^3(n+1)^3,
```

every `A_n` in the interior range is invertible in `PGL_2(F_p)`.

Let

```latex
Z=[0:1]\in\mathbf P^1
```

be the zero line. Because `b_0=1` and `b_1=5`, the distinguished initial line at state `v_1` is

```latex
L_A=[5:1].
```

For `x>=1` put

```latex
\Pi_x=A_{x-1}\cdots A_1
```

(with the empty product for `x=1`). Iterating (1.2) gives the **exact integer identity**

```latex
\boxed{
\Pi_x\binom51
=(x!)^3\binom{b_x}{b_{x-1}}.}
\tag{1.3}
```

Therefore, because `x<p`, the factorial is a `p`-unit and

```latex
\boxed{
b_x\equiv0\pmod p
\iff
\Pi_xL_A=Z.}
\tag{1.4}
```

This is global reachability.

Now define the local `h`-step cocycle

```latex
M_h(x)=A_{x+h-1}\cdots A_x.
```

Starting from the zero line at `x`, the usual gap-polynomial calculation says, up to explicit nonzero factors coming from the adjacent cubic coefficients,

```latex
M_h(x)Z=Z
\iff
N_h(x)\equiv0\pmod p.
\tag{1.5}
```

Hence the selected first-return chain gives

```latex
M_a(x)Z=Z,
```

```latex
M_b(x+a)Z=Z,
```

```latex
M_c(x+a+b)Z=Z,
\tag{1.6}
```

with the appropriate earlier return entries nonzero. Simplicity says that the corresponding scalar matrix entry defining each return has nonzero derivative with respect to the start coordinate. It makes the local root etale/transverse; it does **not** add another projective condition on the prefix.

The logical split is therefore exact:

```text
short local data:       M_a, M_b, M_c stabilize Z
actual Apéry data:      Pi_x sends L_A to Z
```

The first group is what all gap-polynomial resultants/Fitting ideals see. The second is what distinguishes the actual Apéry orbit from a different solution of the same second-order recurrence.

For every local root `x`, because `Pi_x` is invertible, there is a unique projective initial line

```latex
L_x:=\Pi_x^{-1}Z
\tag{1.7}
```

whose solution reaches zero at `x`. All the short return equations (1.6) then hold for that solution. Actuality is precisely the extra equality

```latex
\boxed{L_x=L_A.}
\tag{1.8}
```

Nothing in (1.6), including simplicity and literal first-return nonvanishing, forces (1.8).

This is the clean projective form of the obstruction.

# 2. Bezout/subresultant saturation by `b_x`

## 2.1 What the local algebra can do

On the simple core one may localize the local return algebra at the derivatives and at the earlier-return values. Schematically one is working with a finite etale local-return algebra generated by the class of `X` subject to equations such as

```latex
N_a(X)=0,
\qquad
N_b(X+a)=0,
\qquad
N_c(X+a+b)=0,
```

or any of the equivalent aligned/Fitting formulations from the canonical source.

This algebra is genuinely `H`-scale. Its coefficient heights are controlled by the continuants, and scalar resultants have the familiar bounds such as

```latex
\log|S_{u,v}|\ll uv\log H.
```

But it contains only **local return information**. Localizing further at the earlier `N_j`'s enforces literal first return, but pairwise coprimality/squarefreeness shows only that these are units on the chosen local branch; it does not manufacture the distinguished initial condition.

## 2.2 `b_X` is not an element supplied by this polynomial algebra

The notation `b_x` is a sequence value at the integer index `x`; there is no canonical fixed polynomial

```latex
B(X)\in\mathbf Z[X]
```

in the source whose reduction satisfies `B(r)=b_r` for all `r in F_p` and all residual primes. The Cartier formula expresses `b_r` as a **coefficient indexed by `r`** in `F^{p-1}`, not as a `p`-independent low-degree polynomial evaluation in the variable `r`.

For one fixed prime, of course, the function

```latex
r\mapsto b_r\pmod p,
\qquad 0\le r<p,
```

can be interpolated by a polynomial of degree at most `p-1`. But that polynomial depends on `p`; eliminating `X` against it produces a `p`-dependent object and therefore cannot serve as a nonzero characteristic-zero integer to which the ordinary product formula is applied.

Likewise, introducing all prefix recurrence states as elimination variables is exact but uses a chain of length `x`. It is no longer an `H`-scale construction.

## 2.3 The exact prefix scalar has absolute-index height

Equation (1.3) makes this especially transparent. The first coordinate of the integer prefix product is

```latex
(x!)^3b_x.
```

After removing the factorial, which is a unit modulo `p`, the minimal obvious integer reachability carrier is simply

```latex
b_x.
```

The canonical source uses

```latex
\log b_x\ll x.
```

Thus this carrier is much smaller than the fully cleared matrix product, whose entries have `O(x log x)` logarithmic height, but it is still controlled by the **absolute prefix length `x`**. The present balanced-core hypotheses constrain `a,b,c,s` and the room remaining in the length-`H` block; they impose no bound `x=H^{O(1)}` with an exponent useful here. The selected window can lie in an interior block of `[0,p-1]`.

Reflection only replaces `x` by `p-1-x`; the smaller of those two indices can still be of order `p`.

Therefore the direct Bezout idea reaches the following wall:

```latex
p\mid b_x
\quad\text{and}\quad
p\mid C_{a,b,c}
```

for some local `H`-scale resultant/Fitting carrier `C_{a,b,c}`. Hence

```latex
p\mid\gcd(b_x,C_{a,b,c}),
```

but the only unconditional height bound is

```latex
\log\gcd(b_x,C_{a,b,c})
\le \log|C_{a,b,c}|,
```

which is exactly the local-carrier budget already available. A power saving would require a new theorem saying that the distinguished sequence value `b_x` shares only a small part of the local carrier. No such gcd theorem is present in the canonical source.

So simple-root Bezout saturation is not false; it is simply unable to turn reachability into a new `H`-scale factor with the currently known identities.

# 3. Prefix-transfer monodromy

The same obstruction can be stated without mentioning interpolation.

Fix a simple local triple-return root `x`. Normalize a recurrence solution `q^{(x)}` by

```latex
q^{(x)}_x=0,
\qquad
q^{(x)}_{x+1}=1.
```

The three local first-return conditions determine its zero pattern on `[x,x+s]`; they do not use the left boundary at `0`.

For any two solutions `u,v` of the Apéry recurrence the discrete Wronskian

```latex
W_n(u,v)
=(n+1)^3\bigl(u_{n+1}v_n-u_nv_{n+1}\bigr)
\tag{3.1}
```

is independent of `n`. Hence the local solution `q^{(x)}` is proportional to the distinguished Apéry solution precisely when

```latex
W_0(b,q^{(x)})=0.
```

Since `b_0=1,b_1=5`, this boundary scalar is

```latex
\boxed{5q^{(x)}_0-q^{(x)}_1=0.}
\tag{3.2}
```

Computing `(q_0,q_1)` from `(q_x,q_{x+1})` requires the prefix cocycle of length `x`; (3.2) is just the Wronskian form of (1.8). Nothing in the three short return matrices cancels that prefix, because all three of them act **after** the state has already reached `Z`.

There is a useful way to see why concatenating the returns does not help. From (1.6),

```latex
M_s(x)Z=Z.
```

If the distinguished prefix happens to satisfy `Pi_x L_A=Z`, then automatically

```latex
M_s(x)\Pi_xL_A=Z,
```

which is merely `b_{x+s}=0`. Thus using both endpoint zeros does not yield a second prefix condition; the prefix factor cancels projectively because the local span stabilizes the zero line.

Simplicity does not change this. It says the equation `M_h(X)Z=Z` cuts the start coordinate transversely. It does not constrain which initial projective line lands on that transverse root.

Accordingly, a genuine monodromy proof would need a **new compression theorem** for the prefix line

```latex
\Pi_x^{-1}Z
```

in terms of only `O(H)` local data. That is exactly the missing actual-orbit information, not an identity currently implied by the continuant concatenation.

# 4. Two-sided reflection

Reflection is extremely useful for centered slices, but it does not remove the generic absolute prefix.

Let

```latex
D=\{0,a,a+b,s\}
```

be the four offsets. Reflecting the actual quadruple gives another actual four-zero cluster with start

```latex
x^\rho=p-1-(x+s)
\equiv -x-s-1\pmod p
```

and reversed gaps `(c,b,a)`.

## 4.1 The reflected local equations are algebraically redundant

For example,

```latex
N_c(x^\rho)
=N_c(-x-s-1)
=(-1)^{c-1}N_c(x+a+b),
```

and similarly

```latex
N_b(x^\rho+c)
=(-1)^{b-1}N_b(x+a),
```

```latex
N_a(x^\rho+c+b)
=(-1)^{a-1}N_a(x).
```

Thus adjoining the reflected local return equations to the original ideal gives no new equation in the absolute start. Differentiating the reflection identity gives

```latex
N_h'(-X-h-1)=(-1)^hN_h'(X),
```

so simplicity is reflected as well. The earlier-return nonvanishing string is likewise carried to the reversed string.

Therefore a resultant/subresultant built from “left local cluster + reflected local cluster” is just a repackaging of the original local carrier.

## 4.2 The actual palindrome is not a second reachability condition

The distinguished sequence satisfies

```latex
b_{p-1-x}\equiv b_x\pmod p.
```

Hence

```latex
b_x=0
\iff
b_{p-1-x}=0.
```

In prefix language the reflected reachability scalar is again the same zero condition. Indeed Wilson's theorem gives

```latex
x!\,(p-1-x)!\equiv(-1)^{x+1}\pmod p,
```

so the factorial clearings in the two prefix formulas differ by a unit. Taking a gcd of the left and right prefix conditions therefore does not create two independent prime divisibilities.

## 4.3 When reflection *does* eliminate `x`

There is one genuine exception. If a reflected zero coincides with one of the four displayed zeros, say

```latex
x+d=p-1-(x+e),
\qquad d,e\in D,
```

then

```latex
\boxed{2x+d+e+1\equiv0\pmod p.}
\tag{4.1}
```

Now the start is an `H`-scale affine expression modulo `p`, and one can substitute it into local continuants. These are exactly centered/overlap phenomena where reflection can produce a short certificate (with the usual need to deflate the genuine central factor when it is identically present).

For a canonical consecutive window, a reflected zero cannot lie strictly between two displayed zeros without being one of them, because that would be an additional Apéry zero inside the consecutive window. Hence outside the overlap/centered slices the reflected cluster is disjoint from the original cluster.

In that generic case, to use **solution symmetry** rather than merely polynomial reflection one has to compare the local solution at the original cluster with its reflected solution across the long complementary arc. That comparison is again a prefix/suffix monodromy of length `p-O(H)`. No `H`-scale cancellation is supplied by the current source.

So two-sided reflection gives an actual short eliminant only on the already special centered-overlap locus; it does not solve the generic large-prime core.
