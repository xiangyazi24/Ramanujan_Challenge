# 1. Replicate the selector by actual future selected starts

\[

Y_J:=\sum_a aR_D(J,a).
\tag{1.3}

## Lemma 1 — replicated first-return spacing

\[
\boxed{
\sum_JY_J\ll DM.}
\tag{1.4}
\]

### Proof

Fix one characteristic \(p\) and one target selected start \(K\in S_p\).  Reindex the left side by ordered selected pairs \((J,K)\) with

\[
D<K-J\le2D.
\]

The contributing source starts lie in

\[
K-2D\le J<K-D.
\]

For each such source define its literal first-return interval

\[
I_J=[J,J+a_p(J)).
\]

These intervals have pairwise disjoint interiors.  Indeed, if \(J_1<J_2\) are selected \(p\)-starts, then \(J_2\) is an actual \(p\)-zero after \(J_1\), so the literal first return from \(J_1\) occurs no later than \(J_2\):

\[
a_p(J_1)\le J_2-J_1.
\]

Thus \(I_{J_1}\) ends no later than \(J_2\).

Moreover, since every first gap is \(<H\), all the intervals belonging to this fixed target \(K\) lie inside

\[
[K-2D,\ K-D+H).
\]

In the current medium range \(D>H\), so this container has length

\[
D+H\ll D.
\]

Therefore

\[
\sum_{\substack{J\in S_p\\D<K-J\le2D}}
a_p(J)
\ll D.
\tag{1.5}
\]

Summing (1.5) over target starts \(K\in S_p\), multiplying by \(\log p\), and then summing shell primes gives

\[
\begin{aligned}
\sum_JY_J
&=
\sum_{P<p\le2P}(\log p)
\sum_{J\in S_p}a_p(J)m_D(p,J)\\
&\ll
D\sum_{P<p\le2P}(\log p)|S_p|\\
&=DM.
\end{aligned}
\]

This proves (1.4).  \(\square\)

The next useful theorem must be genuinely cross-characteristic: it must show that actual Apéry prime pairs cannot realize the balanced source/target transition block design or cannot sustain the full \(P/D\) consecutive common-prefix chain at the same time.
