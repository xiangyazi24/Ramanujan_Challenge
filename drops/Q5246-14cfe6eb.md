# 1. Replicated selector and exact spacing

For a selected source occurrence \((p,J)\), define

\[
m_D(p,J)
:=\#\{K\in S_p:D<K-J\le2D\}.
\tag{1.1}

This counts all later selected starts of the same characteristic in the dyadic band; it is a positive majorant of the endpoints actually used by the consecutive pair graph.

R_D(J,a)

\qquad
Y_J:=\sum_a aR_D(J,a).
\tag{1.2}
\]

## Lemma 1 — replicated first-return spacing

\[
\boxed{\sum_JY_J\ll DM.}
\tag{1.3}
\]

### Proof

Fix \(p\) and a target selected start \(K\in S_p\).  Reindex the contribution to the left side by ordered selected pairs \((J,K)\) with

\[
D<K-J\le2D.
\]

The source starts lie in \([K-2D,K-D)\).  Their literal first-return intervals

\[
I_J=[J,J+a_p(J))
\]

have pairwise disjoint interiors.  Indeed, if \(J_1<J_2\) are selected \(p\)-starts, then \(J_2\) is an actual \(p\)-zero after \(J_1\), so

\[
a_p(J_1)\le J_2-J_1.
\]

All these intervals lie inside

\[
[K-2D,K-D+H),
\]

whose length is \(D+H\ll D\).  Hence

\[
\sum_{\substack{J\in S_p\\D<K-J\le2D}}a_p(J)\ll D.
\tag{1.4}
\]

Summing over \(K\in S_p\), then weighting by \(\log p\) and summing shell primes,

\[
\begin{aligned}
\sum_JY_J
&=\sum_{P<p\le2P}(\log p)
  \sum_{J\in S_p}a_p(J)m_D(p,J)\\
&\ll D\sum_{P<p\le2P}(\log p)|S_p|\\
&=DM.
\end{aligned}
\]

No selected-pair multiplicity has been discarded: this is an exact reindexing of the multiplicity in \(m_D(p,J)\). \(\square\)

\begin{proof}
For each source $J$, let $G_{J,D}$ be the literal weighted simple graph

Graph simplicity gives

\]

$q$ has the two literal actual nonwrapping zero endpoints $J,J+d$.

\[
 \sum_{\substack{q\ \text{partner of }p\\
                  \text{at fixed offset }d}}\log q
 \le\log\operatorname{rad}_{(P,2P]}N_d(J)
 \ll DP^{o(1)}.
\]

\[

\]

\[

 \ll D^{1/2}C_J^{1/2}

\]

 &\ll
 D^{1/2}P^{1+o(1)}(DM)^{1/2}\\
 &=P^{1+o(1)}D\,M^{1/2}.
 \end{aligned}
\]
\end{proof}
