# 秩四 mixed Frobenius：可实现的形式算法、规范修正，以及路线 (iii) 的判决

## 执行摘要

本轮有一个先于所有计算的规范修正。

题面采用

```text
Y_t(t) = (C(t), theta*C(t), theta^2*C(t), t)^T
```

和给定的 `G(t)`。在这个规范里，最后一个秩一商的连接指数是 `1`。若该商的 Frobenius 权重由已证深度律固定为 `p^3`，则 Frobenius 矩阵的右下角必为

```text
p^3 * t^(1-p).
```

因此这个规范中的 `Phi(t)` 属于穿孔圆盘/Robba 环，`Phi(0)` **不存在**。要谈常数项和 extension entry，必须先换到

```text
Y_1(t) = (C(t), theta*C(t), theta^2*C(t), 1)^T.
```

在这个“常源规范”中，连接为

```text
G_tilde(t) = [[A(t), u(t)], [0, 0]],
```

其中

```text
q(t) = 1 - 34*t + t^2,

A(t) =
[[0, 1, 0],
 [0, 0, 1],
 [t*(5-t)/q(t), 3*t*(9-t)/q(t), 3*t*(17-t)/q(t)]],

u(t) = (0, 0, t/q(t))^T.
```

一个保持 mixed filtration、且在秩一商上取 Frobenius `p^3` 的矩阵必为

```text
Phi_tilde(t) = [[F(t), z(t)],
                [0,    p^3 ]],
```

其中纯 K3 块 `F` 和 extension 列 `z` 满足

```text
theta(F) = A*F - p*F*A(t^p),                         (P)

theta(z) = A*z + p^3*u - p*F*u(t^p).                (E)
```

这两条方程给出了一个完全可实现的形式幂级数算法。但是有两个必须明确的限制。

1. `F(0)` 中的纯 Frobenius 常数，以及 `z(0)=beta*e_1` 中的 `beta`，**不是**由局部微分方程或任意有限阶 `t`-展开决定的。它们必须来自全局 Cartier/Dwork reduction、一个已知基点的 Frobenius，或一个已构造的 overconvergent mixed `F`-isocrystal。
2. 当前秩四线性 extension 本身**不给第一块射影碰撞一个新独立方程**。事实上对所有 `0 <= n < p`，extension 列的系数精确满足

```text
[t^n] z_1(t) = p^3*c[n] + beta*b[n].                (D0)
```

所以

```text
b[r]*[t^s]z_1 - b[s]*[t^r]z_1
  = p^3*(b[r]*c[s] - b[s]*c[r]).                    (D1)
```

`beta` 自动消掉。这不是数值现象，而是一个形式恒等式。故路线 (iii) 在“秩四线性 Phi、mod p^4、第一块系数”这一精确口径下已经被代数地判死；它只是在新坐标中重写原碰撞。

要使路线 (iii) 真正存活，需要的不是同一个 `Ext^1` 的另一个线性坐标，而是以下之一：

- 一个 **index-side** 的 affine difference/Frobenius module，而不是 `t`-变量的 Gauss--Manin Frobenius；
- 一个 gauge-invariant 的非线性 biextension/syntomic height；
- 或一个能产生第二个 gap-return 多项式并给出小 gcd 的更高 mixed object。

下面先给完整算法，再给 `kappa_p` 的精确可检验关系和计数链条。

# 1. 两个规范及其 Frobenius 变换

## 1.1 常源规范

从

```text
L(C) = t
```

展开得到

```text
q(t)*theta^3(C)
  = t
    + 3*t*(17-t)*theta^2(C)
    + 3*t*(9-t)*theta(C)
    + t*(5-t)*C.
```

因此对

```text
Y_1 = (C, theta*C, theta^2*C, 1)^T
```

有

```text
theta(Y_1) = G_tilde(t)*Y_1,

G_tilde(t) =
[[0, 1, 0, 0],
 [0, 0, 1, 0],
 [t*(5-t)/q, 3*t*(9-t)/q, 3*t*(17-t)/q, t/q],
 [0, 0, 0, 0]].
```

这是在 `t=0` 可正规取值的 mixed connection。

## 1.2 与题面规范的关系

令

```text
D(t) = diag(1,1,1,t).
```

则

```text
Y_t = D(t)*Y_1,

G_t = theta(D)*D^(-1) + D*G_tilde*D^(-1).
```

这正给出题面矩阵，其中第三行第四列变为 `1/q(t)`，第四行第四列变为 `1`。

若 `Phi_tilde` 是常源规范的 Frobenius，则题面规范中

```text
Phi_t(t) = D(t)*Phi_tilde(t)*D(t^p)^(-1).
```

特别地，若

```text
Phi_tilde = [[F,z],[0,p^3]],
```

则

```text
Phi_t =
[[F(t),  t^(-p)*z(t)],
 [0,     p^3*t^(1-p)]].
```

所以：

> `Phi_t(0)` 不是一个有意义的对象。所有“哪个 `Phi(0)` entry 等于 extension class”的陈述，都必须在常源规范 `Phi_tilde` 中解释。

# 2. `Phi_tilde` 的块形与常数项

记

```text
N = A(0) = [[0,1,0],[0,0,1],[0,0,0]].
```

假设 Frobenius 保持三维纯子模块和一维商。则

```text
Phi_tilde(t) = [[F(t), z(t)],
                [0,    lambda ]],
```

其中 `lambda` 为常数。微分方程本身不决定 `lambda`；已证的

```text
p^3*c[a*p+v] == c[a]*b[v] (mod p)
```

和整数格的最低整性深度把正确 Tate 权重固定为

```text
lambda = p^3.
```

在 `t=0`，纯块满足

```text
N*F_0 = p*F_0*N.
```

其一般解为

```text
F_0 =
[[a, f_1, f_2],
 [0, p*a, p*f_1],
 [0, 0, p^2*a]].
```

把 holomorphic period 规范为 `alpha_0=a=1` 后，

```text
F_0 =
[[1, f_1, f_2],
 [0, p,   p*f_1],
 [0, 0,   p^2]].
```

Beukers--Vlasenko 的标准 MUM 数据提供 `f_1,f_2`；不能仅从 `G(t)` 算出它们。

extension 列在常数项满足

```text
N*z_0 = 0,
```

故

```text
z_0 = beta*e_1 = (beta,0,0)^T.
```

因此常源规范中的预测形状是

```text
Phi_tilde(0) =
[[1, f_1, f_2, beta],
 [0, p,   p*f_1, 0],
 [0, 0,   p^2,   0],
 [0, 0,   0,     p^3]].                              (2.1)
```

这里唯一的 mixed 常数是 `(1,4)` entry `beta`。但 `beta` 不是由局部连接自动产生的；它是“这个 differential extension 是否真正来自一个 arithmetic Frobenius extension”所携带的全局常数。

# 3. 可直接编码的形式幂级数算法

## 3.1 输入

```text
prime p > 5
p-adic output precision p^4
working precision p^M
Taylor cutoff N_t
pure constants F_0 mod p^M
mixed constant beta mod p^M
```

对本轮目标：

- 只提取 `kappa_p`：取 `N_t = p`；
- 检查固定 `0 <= v <= V` 的跨块式：取 `N_t = p+V`；
- 检查完整第一跨块 `0 <= v <= p-2`：取 `N_t = 2*p-2`。

## 3.2 展开连接系数

在 `Z_p[[t]]/(t^(N_t+1))` 中先算

```text
qinv(t) = 1/(1-34*t+t^2).
```

写

```text
A(t) = sum_{n=0}^{N_t} A_n*t^n,
u(t) = sum_{n=0}^{N_t} u_n*t^n.
```

其中 `A_0=N`，`u_0=0`，`u_1=e_3`。

## 3.3 纯块递推

写

```text
F(t) = sum_{n>=0} F_n*t^n.
```

`n=0` 的方程是

```text
A_0*F_0 = p*F_0*A_0.
```

对 `n>=1`，从 `(P)` 逐系数得到

```text
L_n(F_n) = RHS_F(n),

L_n(X) = n*X - A_0*X + p*X*A_0,

RHS_F(n)
  = sum_{i=1}^{n} A_i*F_(n-i)
    - p*sum_{j>=1, n-p*j>=0} F_(n-p*j)*A_j.          (3.1)
```

这是每一步一个 `9 x 9` 线性系统。可直接把 `3 x 3` 矩阵向量化后求解。

若只需 `F_0,...,F_(p-2)`，所有 `n` 都是 `p`-单位，所以不会因除以 `p` 丢精度。

## 3.4 extension 列递推

写

```text
z(t) = sum_{n>=0} z_n*t^n,

z_0 = beta*e_1.
```

对 `n>=1`，从 `(E)` 得

```text
(n*I_3 - A_0)*z_n = RHS_z(n),

RHS_z(n)
  = sum_{i=1}^{n} A_i*z_(n-i)
    + p^3*u_n
    - p*sum_{j>=1, n-p*j>=0} F_(n-p*j)*u_j.          (3.2)
```

由于 `A_0^3=0`，逆矩阵有闭式

```text
(n*I_3-A_0)^(-1)
  = n^(-1)*I_3 + n^(-2)*A_0 + n^(-3)*A_0^2.         (3.3)
```

这使实现不需要通用矩阵求逆。

## 3.5 精度预算

当 `N_t < p^2` 时，`z` 递推只在 `n=p` 处遇到一次 `p` 因子；由 `(3.3)` 最坏损失三位。因此：

```text
pure F already known through degree p-2:
    work mod p^7 to obtain z mod p^4 through degree 2p-2.
```

这正与已证母公式的 `mod p^7` 深度一致。

若还要把纯块 `F` 自己算过 `t^p`，则算子

```text
X -> A_0*X - p*X*A_0
```

的幂零指数至多 `5`；在 `n=p` 处保守地可能丢五位。因此联合递推时建议

```text
work mod p^9 for a guaranteed mod p^4 answer.
```

实现时不要在 `Z/(p^M)` 中直接对不可逆的 `n` 求逆。应保存 `p`-赋值和单位部分，或使用精确有理数后逐项检查最终整性。

## 3.6 伪代码

```text
build qinv, A[0..N_t], u[0..N_t]

F[0] = prescribed_pure_Frobenius_constant
for n in 1..min(N_t,p-2):
    rhs = sum(A[i]*F[n-i], i=1..n)
    rhs -= p*sum(F[n-p*j]*A[j], j>=1, n-p*j>=0)
    solve n*X - A0*X + p*X*A0 = rhs
    F[n] = X

z[0] = beta*e1
for n in 1..N_t:
    rhs = sum(A[i]*z[n-i], i=1..n)
    rhs += p^3*u[n]
    rhs -= p*sum(F[n-p*j]*u[j], j>=1, n-p*j>=0)
    z[n] = (nI-A0)^(-1)*rhs
```

对 `N_t=2p-2`，右端只需要 `F_0,...,F_(p-2)`，因为 `u(t^p)` 的首项在 `t^p`。

# 4. 什么能够、什么不能钉死 `Phi_tilde(0)`

## 4.1 局部递推永远不能钉死常数

对任意满足 `N*F_0=pF_0*N` 的 `F_0` 和任意 `beta`，上述递推都给出唯一形式解。因此：

> 不存在一个有限 `t`-adic 阶数，使微分兼容方程本身自动确定 `F_0` 或 `beta`。

`C_0=0,C_1=1` 固定的是局部 particular horizontal lift；它不等价于构造一个 arithmetic Frobenius。

## 4.2 真正的 Cartier/Dwork 算法还缺一个输入

若要从几何上确定 `beta`，必须先给出一个代表 mixed extension 的代数对象。例如：

```text
omega_0, theta*omega_0, theta^2*omega_0
```

是 Apéry K3 de Rham 模块的纯基底，再给一个具体 rational form / higher Chow cycle / normal-function class

```text
omega_ext
```

使其 Gauss--Manin 导数产生源项 `t`。然后执行：

```text
Cartier_p(omega_j)
  = sum_i Phi_tilde[i,j](t) * omega_i^(sigma)
    modulo exact forms,
```

并在 `mod p^4` 下做 Dwork reduction。这会同时给出 `F(t)`, `z(t)`, `beta`。

当前只有标量 differential extension `L(C)=t`，尚没有这样的 `omega_ext` 或 cycle。**连接矩阵本身不保证该 extension 具有 overconvergent Frobenius。** 这是从“形式算法”到“真实 mixed crystal”的第一个不可省略缺口。

另一种 deformation method 是在某个 ordinary Teichmüller 基点 `t_0` 先知道完整 mixed Frobenius，然后用 fundamental matrix 平行运输到 MUM 点。它仍需要同一个基点 mixed Frobenius 输入；`C_0,C_1` 不能代替它。

# 5. extension 列、`kappa_p` 与深度塔的精确一致性式

令

```text
bvec(t) = (B, theta*B, theta^2*B)^T,
h(t)    = (C, theta*C, theta^2*C)^T.
```

`bvec` 满足纯系统，`h` 满足

```text
theta(h) = A*h + u.
```

由 `(P)` 和 `(E)` 直接计算可知

```text
p^3*h(t) - F(t)*h(t^p)
```

也满足 extension 列的非齐次方程。两解之差是一个在 `t=0` 无对数的纯 horizontal section，因此必为 `beta*bvec(t)`。于是有精确恒等式

```text
z(t) = p^3*h(t) - F(t)*h(t^p) + beta*bvec(t).       (5.1)
```

等价地

```text
F(t)*h(t^p) + z(t)
  = p^3*h(t) + beta*bvec(t).                         (5.2)
```

这条式子是所有实现检查的主锚。

## 5.1 第一块系数

因为 `h(t^p)` 从 `t^p` 才开始，对 `0<=n<p`，

```text
[t^n] z(t)
  = (p^3*c[n] + beta*b[n]) * (1,n,n^2)^T.            (5.3)
```

这立即给出执行摘要中的死亡恒等式 `(D1)`。

## 5.2 `kappa_p` 的正确位置

令

```text
v1 = (1,1,1)^T,

R_v = e1^T * F_v * v1,
Z_v = [t^(p+v)] z_1(t).
```

对 `0<=v<=p-2`，由于 `h(t^p)=v1*t^p+O(t^(2p))`，从 `(5.2)` 得

```text
p^3*c[p+v] = R_v + Z_v - beta*b[p+v].                (5.4)
```

特别地，若

```text
F_0 = [[1,f_1,f_2],[0,p,p*f_1],[0,0,p^2]],
```

则

```text
R_0 = 1 + f_1 + f_2.
```

使用

```text
p^3*c[p] = 1 + p^3*kappa_p  (mod p^4)
```

得到规范无歧义的关系

```text
p^3*kappa_p
  == f_1 + f_2 + Z_0 - beta*b[p]  (mod p^4).          (5.5)
```

因此本轮最重要的修正是：

> `kappa_p` 不应在尚未指定全局 Frobenius gauge 时被认作某个单独的 `Phi_tilde(0)` entry。真正规范不变的是 `(5.5)` 的组合。

若额外证明某个规范中 `f_1=f_2=0`、`beta=0`，则才有

```text
Z_0/p^3 == kappa_p (mod p).
```

若选择另一规范把 `Z_0` 消掉，`kappa_p` 会转移到 `beta`。这些都是 gauge 选择，不是彼此矛盾的公式。

## 5.3 与 `K_v` 母公式的检查

已证

```text
p^3*c[p+v]
  == (p^3*c[p])*K_v(p)  (mod p^7).
```

所以一个完整 mixed Frobenius 实现必须逐 `v` 满足

```text
R_v + Z_v - beta*b[p+v]
  == (p^3*c[p])*K_v(p)  (mod p^7),                 (5.6)
```

`0<=v<=p-2`。

# 6. 路线 (iii) 的核心审计

## 6.1 为什么单个线性 `Ext^1` 不会自动产生新方程

一个一般的 index-side affine extension 若写成

```text
a[n+1] = mu_n(pi(n))*a[n] + nu_n(pi(n)),
```

沿 gap `h` 合成后为

```text
a[r+h] = Mu_(r,h)*a[r] + Nu_(r,h).                (6.1)
```

射影碰撞只说

```text
pi(r+h) = pi(r).
```

它**不**说 `a[r+h]=a[r]`。所以不能从碰撞推出

```text
(Mu_(r,h)-1)*a[r] + Nu_(r,h) = 0                  (6.2)
```

除非再证明 affine coordinate `a` 是射影状态 `pi` 的单值函数，或证明 normal function 在这个 return 上闭合。这正是一个新的定理，而不是 Frobenius 矩阵存在性的形式后果。

事实上 normal function 的用途往往恰好是记录路径/holonomy；同一基点返回后 affine 坐标可以改变一个 period。把“base return”自动提升成“extension return”是本路线目前最危险的隐含假设。

## 6.2 `t`-变量与 coefficient-index 的范畴错位

`Phi_tilde(t)` 是参数线 `t` 上 Gauss--Manin connection 的 Frobenius。碰撞

```text
pi(r)=pi(s)
```

发生在**系数指标** `r,s` 上。`r` 不是一个几何点 `t=r`，也不存在由 `Phi(r)` 与 `Phi(s)` 直接比较而来的关系。

把 `Phi(t)` 转成 index 信息只能通过 coefficient extraction / Cartier。到 `mod p^4`，这种提取给出的正是

```text
b[v], D[v], E[v], F[v], and c[v]+constant*b[v].
```

这些线性信息已经被 AUDIT-4 穷尽。故“求出 `Phi mod p^4` 后自动出现一个第一块新方程”这一期待不成立。

## 6.3 严格死亡命题

**命题。** 设 `Phi_tilde` 是任意满足 `(P),(E)` 的 filtration-preserving 形式 Frobenius，商标量为 `p^3`。则对 `0<=r,s<p`，

```text
b[r]*[t^s]z_1 - b[s]*[t^r]z_1
  = p^3*(b[r]*c[s]-b[s]*c[r]).
```

所以 extension 第一列在第一块上的所有 determinant-zero 条件与原碰撞条件完全相同。提高 `p`-adic 精度不会改变这个结论。

证明就是 `(5.3)`，其中 `beta` 项相消。

这说明路线 (iii) 不是“尚未证明”，而是其当前最自然的线性版本已被判死。

# 7. 真正可存活的最小候选引理

若要把 mixed 几何变成能量工具，最小可计数形式应直接写成 gap gcd 命题，而不是模糊的“每个碰撞多一个方程”。

先移除反射强制碰撞。记 `N_h(r)` 为 projective return/gap polynomial，`N_h^prim` 为除去 mirror/center 因子的部分。

## [MIXED-RETURN-eta]

存在一个由更高 mixed object 构造、对 gauge 不变的 return numerator

```text
J_h(r) in F_p[r]
```

和固定 `eta>0`，使得：

1. 每个非镜像 Apéry 射影碰撞 `pi(r+h)=pi(r)` 都满足

```text
N_h^prim(r)=0,
J_h(r)=0;
```

2. 不是只要求两个式子形式上不同，而是要求真正的 gcd 界

```text
deg gcd(N_h^prim, J_h) << h^(1-eta),              (7.1)
```

均匀于 `p,h<p`，例外 `(p,h)` 的总贡献可求和；

3. `J_h` 不能在碰撞 ideal 中，也不能因改变 `beta` 或改变 local splitting 而改变零集。

这才是“每碰撞一新方程”的精确、可证伪、可进入计数的版本。

- `eta=0` 没有改进；
- `eta=1/2` 给能量指数 `4/3`；
- `eta>1/2` 越过点态所需的 `4/3` 阈值；
- `eta=1`，即每个 gap 只有 `O(1)` 个 accidental mixed returns，给 `E^pi=O(p)`。

当前秩四线性 `Phi` 不能产生这样的 `J_h`。可尝试的下一对象是：

- syntomic **biextension height**；
- normal function 与其对偶的 cup product；
- 一个真正作用在 `z`/index 参数上的 contiguity `F`-module；
- 或至少一个秩五 iterated extension，使 return holonomy 的二次项成为 gauge invariant。

# 8. `p=101,211` 的可证伪测试设计

## 8.1 先做必须通过的规范测试

在常源规范计算 `F,z` 到 `t^(2p-2)`：

```text
T1: verify (P),(E) mod p^4.
T2: verify z[n] = (p^3*c[n]+beta*b[n])*(1,n,n^2) for n<p.
T3: verify kappa identity (5.5).
T4: verify K_v identity (5.6).
```

若 T1--T4 失败，是实现/规范错误，不是路线 (iii) 的反例。

## 8.2 线性路线的预期死亡测试

对所有碰撞对 `(r,s)`，算

```text
Q0(r,s) = b[r]*z1[s] - b[s]*z1[r].
```

它会逐点等于

```text
p^3*(b[r]*c[s]-b[s]*c[r]),
```

所以其消失率必为 `100%`，但这是**同一个方程**，不算新信息。

再改变形式参数

```text
beta -> beta + gamma*p^3
```

检查所有候选量。任何随 `gamma` 改变零集的量都不是 gauge-invariant mixed return invariant。

## 8.3 真正的 survival criterion

对任何提出的 nonlinear 候选 `H_p(v)` 或 gap invariant `J_h(r)`：

```text
S1. mirror pairs must be separated;
S2. on nonmirror true collisions, J_h(r)=0 with zero exceptions
    (or an explicitly classified summable exception set);
S3. on all roots of N_h^prim, the conditional zero fraction must be
    << h^(-eta), not merely the random 1/p baseline on arbitrary pairs;
S4. symbolically check gcd(N_h^prim,J_h) for h<=12;
S5. verify the zero set is unchanged under every allowed beta/gauge shift;
S6. verify J_h is not a multiple of N_h^prim and not an identity consequence
    of b[r]*c[s]-b[s]*c[r].
```

数值判定：

- **存活**：碰撞强制 `J_h=0`，且 `deg gcd` 相对 `deg N_h ~ h` 出现稳定幂节省；
- **死亡**：碰撞上的消失率与随机基线一致，或表达式只是原 determinant 的倍数，或依赖 `beta`；
- **无信息**：碰撞上全消失，但 `J_h` 在 `N_h` 的根集上恒消失，即没有 gcd 降维。

由于 AUDIT-4 已证明 `D,E,F` 的消失率为随机基线，`Phi mod p^4` 的线性 coefficient 数据预期会落入“死亡/无信息”两类。

# 9. 从 mixed-return gcd 到能量指数

令

```text
R_h(p) = #{r : nonmirror pi(r+h)=pi(r)}.
```

把长度约 `p` 的指标区间分成长度 `H` 的块。对每个 projective value 在各块上的重数作 Cauchy--Schwarz，得到标准块界

```text
E^pi(p)
  << (p/H + 1) * (p + 2*sum_{h<H} R_h(p)).          (9.1)
```

当前 gap degree 给

```text
R_h(p) << h,
```

故

```text
sum_{h<H}R_h << H^2,
E^pi << p^2/H + p*H.
```

取 `H=sqrt(p)`，即仓库已入账的 `E^pi << p^(3/2)`。

若 [MIXED-RETURN-eta] 给

```text
R_h(p) << h^(1-eta),
```

则

```text
E^pi(p)
  << p^2/H + p*H^(1-eta) + p.                       (9.2)
```

优化

```text
H = p^(1/(2-eta))
```

得到

```text
E^pi(p) << p^(2 - 1/(2-eta) + o(1)).                (9.3)
```

校准：

```text
eta = 0      -> exponent 3/2  (current theorem)
eta = 1/2    -> exponent 4/3
eta > 1/2    -> beats 4/3
eta = 1      -> exponent 1, hence O(p) up to logs/exceptions
```

因此真正需要证明的不是抽象“独立性”，而是 `(7.1)` 这种一元多项式 gcd 的幂节省。

# 10. 余下环节及难度分类

## 环节 A：构造 arithmetic mixed extension

**性质：代数几何 / rigid-syntomic。**

要从 `L(C)=t` 升级到真实 `F`-isocrystal，需要一个 cycle/form `omega_ext`。这是目前最先缺失的环节。形式微分方程的存在不够。

## 环节 B：确定纯常数与 mixed 常数

**性质：Cartier reduction / p-adic period。**

求 `F_0,beta`，并核验 `(5.5)`。`kappa_p=-2 zeta_p(3) mod p` 是强校准，但不能反过来代替构造。

## 环节 C：从 `t`-Frobenius 到 index-side return

**性质：范畴桥 / holonomic-contiguity。**

这是最容易被忽略、也最关键的一步。需要一个比较定理，把 normal-function Frobenius 的某个 gauge-invariant 非线性量转成 `r,h` 的低复杂度 return numerator。

## 环节 D：gcd/根计数

**性质：代数与有限域计数。**

即使得到第二式，也必须证明 `deg gcd` 小。两个一元方程“看起来独立”没有任何计数含义；它们可能共享整个 `N_h`。

## 环节 E：例外与镜像

**性质：组合/初等数论。**

反射强制对贡献 `O(p)`，可单列。奇异索引和少量坏素数也可求和；相较 A--D 这是较轻环节。

# 11. 最终判决

1. **可落地的正面结果**：常源规范下的 block Frobenius 方程 `(P),(E)`、系数递推 `(3.1),(3.2)`、精度预算和一致性式 `(5.5),(5.6)` 已具体到可直接用 Python/SymPy 或 Sage 实现。
2. **必须撤回的预言**：在未指定 global gauge 前，不能说某个单独的 `Phi(0)` entry 等于 `kappa_p`。在题面原规范里甚至没有 `Phi(0)`。
3. **路线 (iii) 当前判决**：秩四线性 mixed `Phi mod p^4` 不会给第一块碰撞新方程；`(D1)` 是严格死亡证书。AUDIT-4 的负结果并非偶然，而是这个块三角结构的必然结果。
4. **可存活的替代靶**：构造 index-side 非线性、gauge-invariant 的 mixed return invariant，并证明 [MIXED-RETURN-eta] 的 gcd 界。`eta>0` 首次改善当前 `3/2`，`eta>1/2` 过 `4/3`，`eta=1` 关闭 E1。

# 12. 两个必答问题

## (a) 本轮最没把握的一步

最没把握的是 **这个标量 differential extension `L(C)=t` 是否确实来自一个保持所选整数格、商 Frobenius 为 `p^3` 的 overconvergent mixed `F`-isocrystal**。`p^3` 权重与已证深度塔高度吻合，但目前没有实际 cycle/form 和 Cartier reduction。形式方程可解不等于 arithmetic Frobenius 存在。

其次不确定的是在某个最终几何规范里，`kappa_p` 的质量究竟落在 `beta`、`z_1` 的 `t^p` 系数，还是与纯块 `f_1,f_2` 的组合中；规范不变的只有 `(5.5)`。

## (b) 双方共同盲点

共同盲点很可能有两个。

1. **把几何参数 `t` 的 Frobenius 当成系数指标 `v` 的 Frobenius。** `Phi(t)` 控制 Gauss--Manin 参数线；射影轨道碰撞发生在 recurrence/index 线。没有 coefficient-extraction/contiguity 比较定理，两者之间没有“代入 `r,s`”这一步。
2. **把 base return 当成 extension return。** `pi(r)=pi(s)` 只让底层线返回；normal function 的 affine coordinate 可以积累非零 period/holonomy。若不先证明 affine section 对 `pi` 单值化，所谓“每个碰撞多一个方程”并不存在。

这两个盲点合起来解释了为何深度塔非常刚性、`kappa_p` 也非常漂亮，却在 AUDIT-4 中没有自动转化成第一块能量节省。
