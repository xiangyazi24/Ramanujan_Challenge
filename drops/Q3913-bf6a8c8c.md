# 6. Restoring lower-prime stars: the missing axis

The actual perimeter is `(3.3)`, not `(5.4)`. The row first moment controls

\[
\sum_nK_6(n),
\]

but it does not control

\[
\Gamma_{n,r}
\]

or its spacing-weighted sum. Consequently `(5.4)` cannot be asserted for the real charge family.

The exact effect of assigned-radical normalization can be displayed at every global row cut. Let

\[
D_{n,r}
:=
\#\{(q_i,q_j)\in D_{\rm hi}^{+}(n):i\le r<j\}
\tag{6.1}
\]

be the number of **distinct** selected upper-pair intervals crossing the cut. Then

\[
\mathfrak V_{\rm hi}^{+,\mathrm{dist}}

\sum_{n,r}\delta_{n,r}D_{n,r}.
\tag{6.2}

\right\}.

\tag{6.3}

The first term is the trivial number of distinct row pairs crossing the cut; the second is the occurrence-preserving nearest-witness bound. \boxed{
A(T)W(T)
=o\bigl(\xi(T)M_{\rm row}\bigr).
}
\tag{9.2}
\]

If

\[
M_{\rm row}=\mu(T)H^2,
\]

then `(9.2)` is

\[
\boxed{
A(T)W(T)
=o\!\left(
\frac{\mu(T)T^{4/5}}
     {\xi(T)L^{12/5}}
\right).
}
\tag{9.3}
\]

In the ideal row-collapsed case `A(T)=1`, the required physical width is

\[
\boxed{
W(T)
=o\!\left(
\frac{\mu(T)T^{4/5}}
     {\xi(T)L^{12/5}}
\right).
}
\tag{9.4}
\]

For example, a genuine occurrence-preserving localization with `A=O(1)` and `W\ll T^{2/3}` would make the ratio

\[
\ll
\frac{\xi(T)L^{12/5}}
     {\mu(T)T^{2/15}},
\]

which is `o(1)` for the intended sufficiently slow `xi`, provided `mu` does not erase the margin. This is only an illustration of the exact exponent interface, not a claim that the untracked centered theorem supplies `T^{2/3}`.

A pointwise statement such as

```text
one lower digit lies in a central range,
```

or

```text
the selected witness has bounded rank distance,
```

is insufficient unless it is converted into `(9.1)`. Rank distance does not upper-bound physical prime separation, and rowwise physical width does not account for repeated lower-prime stars. The exact useful centered theorem is instead

\[
\boxed{
\sum_{\substack{n:\ K_6(n)>M_{\rm row}}}
\sum_{p\ \mathrm{active}}
\operatorname{length}\!\left(
\bigcup_{(q_i,q_j)\in\mathcal C_{n,p}}
[q_i,q_j]
\right)
=o_J\!\left(\frac{B_0(T)}H\right),
}
\tag{CENTER-TV+}
\]

where `C_{n,p}` is the retained nearest-witness charge family in that lower-prime star. This union-length sum is exactly `mathfrak P_hi^+`.

# 10. Assigned-radical normalization: exact gain and exact limit

The normalized carrier contributes two indispensable improvements already used above:

1. it replaces the old huge fixed-value coefficient by the short-transfer height
   \[
   O_J((q_j-q_i)L);
   \]
2. for a fixed upper pair, one squarefree carrier simultaneously pays every distinct lower prime above that pair.

There is no further deterministic factor. In the cut notation, normalization replaces the occurrence coefficient

\[
\sum_p c_{n,p,r}
\]

by the number `D_{n,r}` of distinct upper-pair intervals. The exact inequality is `(6.3)`. To gain a power from normalization one would need a collision theorem showing that many lower-prime charge occurrences collapse onto comparatively few upper pairs, for example

\[
\sum_{n,r}\delta_{n,r}D_{n,r}
=o_J(HB_0(T)).
\]

That statement is precisely `(PAIR-TV+)`. Neither the row first moment, the lower-incidence first moment, nor Brun--Titchmarsh proves such a collision estimate.

Thus assigned-radical normalization is not a missing extra factor after `(4.7)`; it is the mechanism that makes `(PAIR-TV+)` the sharp distinct-pair target in the first place.

# 11. Smallest additional theorem and complete exponent ledger

There are two equivalent levels at which to state the remaining theorem.

## 11.1 Sharp distinct-pair theorem

Let `D_hi^+` be the distinct normalized-carrier pairs generated by all retained nearest-earlier charges after every trim, peel, assignment, and BT deletion. Prove

\[
\boxed{
\sum_{(n;q_i,q_j)\in D_{\rm hi}^{+}}
(q_j-q_i)
=o_J\!\left(
\frac{T^{12/5}}
     {\xi(T)L^{16/5}}
\right).
}
\tag{TV-PAIR-SHARP}
\]

Then Q3904 gives total carrier height

\[
o_J\!\left(
\frac{T^{12/5}}
     {\xi(T)L^{11/5}}
\right),
\]

and the frozen `theta H` charge multiplicity gives

\[
|F_{\rm hi}^{+}|=o_J(B_0(T)).
\]

This is the literally smallest aggregate aligned with the normalized carrier.

## 11.2 Occurrence-preserving nearest-star theorem

Prove

\[
\boxed{
\sum_{\substack{n:\ K_6(n)>M_{\rm row}}}
\sum_r
(Q_{n,r+1}-Q_{n,r})\Gamma_{n,r}
=o_J\!\left(
\xi(T)T^{8/5}L^{-4/5}
\right).
}
\tag{TV-STAR-PERIMETER}
\]

The exact coefficient `binom(H+1,2)` then implies `(TV-PAIR-SHARP)`.

The full exponent ledger is:

| Quantity | Scale |
|---|---:|
| Baseline final-edge target `B0` | `T^2 L^(-2)` |
| First upper-occurrence envelope `B1` | `T^(8/5) L^(-4/5)` |
| Frozen charge multiplicity `H` | `T^(2/5) xi^(-1) L^(-6/5)` |
| Weighted carrier target `H B0 L` | `T^(12/5) xi^(-1) L^(-11/5)` |
| Distinct-pair gap target `H B0` | `T^(12/5) xi^(-1) L^(-16/5)` |
| Star-perimeter target `B0/H` | `xi T^(8/5) L^(-4/5)` |
| Optimistic row perimeter | `T B1/M_row` |
| Optimistic TV height | `T^(17/5)/(xi^2 M_row L^(11/5))` |
| Exact optimistic miss | `T/(xi M_row)` |
| Miss for `M_row=mu H^2` | `xi T^(1/5)L^(12/5)/mu` |

No additional logarithm is hidden in the nearest-witness identity. The only `L` in the height step is the exact normalized-carrier factor `O(gap L)`; the charge lower bound also contributes `log p asymp L`, and those two logarithms cancel when converting carrier height to a final-edge count.

# 12. Final classification

| Component | Ruling | Exact reason |
|---|---:|---|
| Replace arbitrary witnesses by `H` nearest earlier witnesses | **PASS** | Frozen original-core order supplies them for every trimmed survivor |
| Later trim/peel | **PASS** | Witnesses need remain actual original-core rows, not final edges |
| Discrete total variation | **PASS** | Each star spacing coefficient is at most `H(H+1)/2` |
| Preserve all lower-prime occurrences | **PASS** | Pairwise squarefree carrier pays every distinct `p`; repeated pairs are handled factorwise |
| Apply `O(gap log T)` normalized height | **PASS** | Q3904 exact support and continuant height |
| Rowwise `O(H^2)` crossing without `p` multiplicity | **Not justified** | Must include `Gamma_(n,r)` or distinct-pair count `D_(n,r)` |
| First upper-occurrence moment alone | **Does not close** | Exact optimistic ratio `T/(xi M_row)` |
| `M_row asymp H^2` specialization | **Supercritical ledger** | Miss `xi T^(1/5)L^(12/5)` |
| Lower-incidence first moment | **Does not close** | Gives ratio at least the scale in `(7.6)` |
| Dyadic Brun--Titchmarsh | **Positive close-gap deletion only** | Dyadic envelope grows as `D^2` and does not bound the long-gap perimeter |
| Assigned-radical normalization | **Fully used, no automatic further factor** | Saves only actual collisions onto the same upper pair |
| Centered-rank localization | **Viable source of the missing factor** | Must prove `(CENTER-TV+)`, `(9.2)`, or `(TV-PAIR-SHARP)` |
| Smallest new aggregate | **`TV-PAIR-SHARP`** | Exact distinct normalized-pair gap moment |
| Smallest occurrence-preserving aggregate after TV | **`TV-STAR-PERIMETER`** | Retains every lower-prime star and closes by the exact `H(H+1)/2` identity |

# Bottom line

The nearest-earlier strategy is worth keeping: it converts arbitrary long-gap charge height into a clean one-dimensional total-variation problem and removes any dependence on the number of terminals inside a fixed lower-prime star. What remains is not another pointwise carrier problem. It is the spacing-weighted lower-prime cut-reuse moment `(TV-STAR-PERIMETER)`, or its sharper distinct-pair quotient `(TV-PAIR-SHARP)`.

With only the current high-row threshold and first upper-occurrence moment, the exact optimistic miss is `T/(xi M_row)`; at `M_row asymp H^2` it is `xi T^(1/5)(log T)^(12/5)`. Brun--Titchmarsh and assigned-radical normalization do not supply that factor on the long-gap residual. A centered-rank theorem does supply it precisely if it proves the aggregate physical-width/cut-multiplicity estimate `(9.2)`—equivalently `(CENTER-TV+)`.
