# Fixed-row top-quarter product: exact continuant telescope and factorial saturation

## Verdict

I audited repository `main` at commit
`3569093d36d1e53c148196579295f0802eed863e`.

Let n be even and set

```text
H   = floor(n/4),
rho = n - H.
```

Define

```text
A_n = {u : 2 <= u <= H, p = n-u is prime, and p divides B_u},
L_n = |A_n|,
Q_n = sum_{u in A_n} log(n-u),
R_n = product_{u=2}^H gcd(n-u, B_u).
```

There is an exact recurrence telescope, but the natural fixed-row carrier is
completely saturated by the moving factorial factors.

Define the cleared Apéry continuants by

```text
N_0(x) = 0,
N_1(x) = 1,
N_{r+1}(x) = P(x+r) N_r(x) - (x+r)^6 N_{r-1}(x),
P(t) = 34 t^3 + 51 t^2 + 27 t + 5.
```

Put

```text
C_s = N_{n-s}(s),
G_n = gcd(C_0, C_1, ..., C_{rho-1}).
```

Then, for every sufficiently large even n,

```text
exp(Q_n)
 = product of primes p such that
     rho <= p <= n-2
     and p divides G_n.
```

Moreover,

```text
G_n divides [ product_{j=rho}^{n-1} j ]^6
    = [ (n-1)! / (rho-1)! ]^6.
```

Every target prime p is greater than n/2, so

```text
v_p( (n-1)! / (rho-1)! ) = 1.
```

Thus, after removing all prime powers supported on the factorial tail, the
continuant carrier has no residual part:

```text
G_n / gcd(G_n, ((n-1)!/(rho-1)!)^infinity) = 1.
```

This is an exact no-go for the continuant gcd, its natural order-two
Casoratian/subresultant, and primitive or factorial saturation of that
carrier. It is not a claim that every conceivable new Apéry identity must
factor through this carrier.

The product proposed in the question has the exact target part

```text
(R_n)_{primes > n/2} = exp(Q_n).
```

Its full composite part is a strictly stronger object. It does not satisfy
the prime telescope because, for composite n-u, the endpoint factor (u!)^3
need not be invertible.

The uniform estimates supplied by this exact package remain

```text
L_n <= pi(n-2) - pi(rho-1)
    = (1/4 + o(1)) n/log n,
```

and

```text
Q_n <= theta(n-2) - theta(rho-1)
    = (1/4 + o(1)) n.
```

Neither is a little-o estimate.

The exact actual-Apéry residual left after saturation is the fixed-row pair
count

```text
C_n(h) = number of u such that
    2 <= u < u+h <= H,
    p = n-u and q = n-u-h = p-h are prime,
    p divides B_u,
    q divides B_{u+h}.
```

It satisfies

```text
sum_{h=1}^{H-2} C_n(h) = binom(L_n, 2).
```

Consequently the desired fixed-row theorem is equivalent to

```text
sum_{h=1}^{H-2} C_n(h) = o(n^2/log^2 n).          (FRQ1)
```

This residual concerns only two linked quotient-one primes on this one row;
it is narrower in scope than the full Problem 3.2 radical problem.

## 1. Exact interval, parity, and the radical inside R_n

The candidate range is

```text
2 <= u <= H,
p = n-u,
rho <= p <= n-2.
```

Since H <= n/4,

```text
p >= 3n/4 > n/2,
u < p.
```

For large even n, every candidate prime is odd. Hence every candidate
u = n-p is odd, and two target indices always have even difference.

The lower endpoint is exact.

If n = 4a > 4, then

```text
rho = 3a,
```

which is composite. If n = 4a+2, then

```text
rho = 3a+2 = (3n+2)/4,
```

and p = rho can be a genuine boundary prime. The carrier G_n ends at
C_{rho-1} precisely so that this possible boundary is included.

Factor by factor,

```text
R_n divides product_{u=2}^H (n-u)
    = product_{j=rho}^{n-2} j
    = (n-2)! / (rho-1)!.
```

Stirling gives

```text
log( (n-2)! / (rho-1)! ) = (n/4) log n + O(n),
```

so the ordinary height of the full product is much too large.

Its large-prime part is exact. Let a prime ell > n/2 divide one factor
n-u < n. Then n-u = ell, because 2 ell > n. This u is unique, and

```text
v_ell(gcd(n-u, B_u)) = 1 if ell divides B_u,
                        0 otherwise.
```

Therefore

```text
(R_n)_{primes > n/2}
 = product_{u in A_n} (n-u)
 = exp(Q_n).
```

This proves the asserted product identity.

## 2. Direct quotient-one Lucas calculation

Let p = n-u be a candidate prime. Since u <= n/4,

```text
2u < p.
```

Every index in the sum for B_{p+u} has a unique form

```text
k = a p + b,
a in {0,1},
0 <= b < p.
```

Lucas's binomial congruence gives

```text
binom(p+u, a p+b) = binom(1,a) binom(u,b)    mod p.
```

Thus only 0 <= b <= u survives. For those b, the inequality 2u < p gives
u+b < p, so there is no carry in the second binomial. Therefore

```text
binom(p+u+a p+b, a p+b)
 = binom(1+a,a) binom(u+b,b)                  mod p.
```

Hence

```text
B_{p+u}
 = sum_{a=0}^1 sum_{b=0}^u
     binom(1,a)^2 binom(1+a,a)^2
     binom(u,b)^2 binom(u+b,b)^2             mod p
 = (1+4) B_u
 = 5 B_u                                     mod p.
```

Since p > 5,

```text
p divides B_u  if and only if  p divides B_n.
```

Thus exp(Q_n) is also the squarefree [rho,n-2]-part of the one fixed integer
B_n. The question correctly assumes that the height of B_n alone is
saturated; the next argument gives a different exact saturation.

## 3. Continuants and the endpoint value

For r >= 1, N_r(x) is the determinant of the (r-1) by (r-1) symmetric
tridiagonal matrix whose diagonal is

```text
P(x+1), P(x+2), ..., P(x+r-1)
```

and whose off-diagonal entries are

```text
(x+2)^3, (x+3)^3, ..., (x+r-1)^3.
```

Right-edge expansion gives the defining recurrence. Left-edge expansion
gives

```text
N_r(x)
 = P(x+1) N_{r-1}(x+1)
   - (x+2)^6 N_{r-2}(x+2).                    (3.1)
```

The endpoint identity is

```text
N_{r+1}(-1) = (r!)^3 B_r                     (3.2)
```

for every r >= 0.

The cases r=0 and r=1 are

```text
N_1(-1) = 1 = B_0,
N_2(-1) = P(0) = 5 = B_1.
```

For r >= 2, induction gives

```text
N_{r+1}(-1)
 = P(r-1) ((r-1)!)^3 B_{r-1}
   - (r-1)^6 ((r-2)!)^3 B_{r-2}
 = ((r-1)!)^3 [ P(r-1) B_{r-1} - (r-1)^3 B_{r-2} ]
 = (r!)^3 B_r,
```

where the last equality is exactly the Apéry recurrence.

## 4. Exact telescope modulo the moving prime

Set

```text
C_s = N_{n-s}(s).
```

The left-edge recurrence becomes

```text
C_s = P(s+1) C_{s+1} - (s+2)^6 C_{s+2},       (4.1)
```

with

```text
C_n = 0,
C_{n-1} = 1.
```

Fix a candidate p = n-u. For 0 <= s <= p-3, write

```text
(C_s, C_{s+1})^T = M_s (C_{s+1}, C_{s+2})^T,

M_s = [ P(s+1)   -(s+2)^6 ]
      [   1           0     ].
```

Its determinant is (s+2)^6, a unit modulo p. Hence

```text
C_0 = C_1 = 0 mod p
    if and only if
C_{p-2} = C_{p-1} = 0 mod p.                  (4.2)
```

At the unique singular edge s = p-2,

```text
C_{p-2} = P(p-1) C_{p-1} - p^6 C_p.           (4.3)
```

Since

```text
P(p-1) = P(-1) = -5 mod p,
```

and p > 5,

```text
C_{p-2} = C_{p-1} = 0 mod p
    if and only if
C_{p-1} = 0 mod p.                             (4.4)
```

Finally,

```text
C_{p-1}
 = N_{n-p+1}(p-1)
 = N_{u+1}(p-1)
 = N_{u+1}(-1) mod p
 = (u!)^3 B_u mod p.
```

Because u < p, the factorial is a p-unit. Thus

```text
p divides B_u
    if and only if
p divides C_0 and C_1.                         (4.5)
```

If p divides B_u, then (4.4) and the invertible transfers also give

```text
p divides C_s for every 0 <= s <= p-1.         (4.6)
```

Every candidate has p >= rho, so p-1 >= rho-1. Therefore p divides G_n.
Conversely, if a prime p in [rho,n-2] divides G_n, then p divides C_0 and
C_1, and (4.5) gives p divides B_{n-p}. This proves the exact carrier
identity.

For the strict interior define

```text
G_n^circ = gcd(C_0, C_1, ..., C_rho).
```

It captures every target prime p > rho. The sole possible boundary p = rho,
corresponding to u = H, is retained by G_n and contributes at most one
logarithm.

## 5. Dodgson condensation and the factorial tail

The continuants satisfy

```text
N_{r+2}(x) N_r(x+1)
 - N_{r+1}(x) N_{r+1}(x+1)
 = - product_{j=2}^{r+1} (x+j)^6.              (5.1)
```

This holds for every r >= 0. At r=0, the empty product is one and the
identity is 0-1=-1.

For a direct proof, call the left side Delta_r(x). Substituting the defining
recurrence into N_{r+2}(x) and N_{r+1}(x+1) gives

```text
Delta_r(x) = (x+r+1)^6 Delta_{r-1}(x).
```

Since Delta_0(x)=-1, iteration proves (5.1), including the sign and every
endpoint factor.

Take

```text
x = rho-2,
r = H.
```

Since rho+H=n, identity (5.1) becomes

```text
C_{rho-2} N_H(rho-1)
 - N_{H+1}(rho-2) C_{rho-1}
 = - product_{j=rho}^{n-1} j^6.                (5.2)
```

The integer G_n divides both terms on the left, so

```text
G_n divides [ product_{j=rho}^{n-1} j ]^6.
```

Taking x=rho-1 and r=H-1 similarly gives

```text
G_n^circ divides [ product_{j=rho+1}^{n-1} j ]^6.
```

Thus the factor rho in the first carrier is needed only for the possible
boundary prime.

For a target prime p in [rho,n-2],

```text
v_p( (n-1)!/(rho-1)! )
 = floor((n-1)/p) - floor((rho-1)/p)
 = 1.
```

The extra determinant endpoint n-1 corresponds to u=1. If n-1 is prime,
(4.5) reduces its possible divisibility to B_1=5, so it is not a target
prime for large n.

Equation (5.2) is the canonical order-two Casoratian, or natural
subresultant analogue, of this transfer system. After saturation by its
cut-edge product, its residual is exactly the unit -1. This is the exact
obstruction for the recurrence/subresultant route.

## 6. Exact local Smith form

Over the p-adic integers, every M_s with s <= p-3 is invertible, so the
adjacent ideals generated by (C_s,C_{s+1}) are unchanged until the singular
edge. There

```text
M_{p-2} = [ P(p-1)   -p^6 ]
          [    1        0  ].
```

One entry is 1 and the determinant is p^6. Therefore

```text
SNF(M_{p-2}) = diag(1,p^6).                    (6.1)
```

Equivalently,

```text
(C_{p-2}, C_{p-1}) = (C_{p-1}, p^6 C_p)
```

as ideals over the p-adic integers. Hence

```text
v_p(gcd(C_0,C_1))
 = min( v_p(N_{u+1}(p-1)),
        6 + v_p(N_u(p)) ).                     (6.2)
```

The recurrence forces the support condition p divides G_n, but supplies no
second independent invariant that would force a higher p-adic valuation.
The exponent six is exactly the determinant loss already present in the
factorial carrier.

## 7. Reflection and the raw Wronskian are tautological

Strong reflection gives

```text
B_{p-1-u} = B_u mod p.
```

Since p >= 3u, and a large prime cannot equal 3u with u >= 2, the reflected
index v=p-1-u is greater than u. Put

```text
h = v-u = p-1-2u = n-3u-1.
```

The prime p is odd, so h is even, and

```text
2u+h+1 = p.                                    (7.1)
```

The continuant reflection identity is

```text
N_h(-x-h-1) = (-1)^{h-1} N_h(x).               (7.2)
```

For even h this forces

```text
N_h(x) = (2x+h+1) N_h^circ(x),
N_h^circ(x) in Z[x].                            (7.3)
```

Therefore

```text
N_h(u) = p N_h^circ(u).                         (7.4)
```

This divisibility follows from the affine reflection relation (7.1) alone;
it holds before imposing p divides B_u. After central deflation, the actual
zero condition does not imply p divides N_h^circ(u). Hence the raw
Wronskian or reflected resultant has no target-selective residual.

## 8. Exact obstruction for the full composite product

The prime telescope uses two facts:

1. The integers 1,...,u are units modulo p.
2. Every transfer determinant before s=p-2 is a unit modulo p.

For a composite modulus d=n-u, the endpoint relation is only

```text
C_{d-1} = N_{u+1}(d-1) = (u!)^3 B_u mod d.      (8.1)
```

Although d>u, a composite d can have prime factors at most u, so (u!)^3
need not be invertible modulo d. The transfer chain can also meet several
nonunit edges, one for each small prime factor. Consequently there is no
uniform equivalence

```text
d divides C_0 and C_1
    if and only if
d divides B_u.
```

This is the exact reason the full R_n does not collapse to a clean
continuant gcd. The target radical avoids the obstruction because its
modulus p=n-u is prime and exceeds u.

## 9. The standard diagonal does not shrink the carrier

The Apéry diagonal identity is

```text
B_u = [x^u y^u z^u w^u]
      1 / ( (1-x-y)(1-z-w) - x y z w ).        (9.1)
```

Indeed,

```text
1 / ( (1-x-y)(1-z-w) - x y z w )
 = sum_{j>=0}
   (x y z w)^j / [ (1-x-y)^{j+1} (1-z-w)^{j+1} ],
```

and the diagonal coefficient is

```text
sum_{j=0}^u [ (2u-j)! / (j! (u-j)!^2) ]^2
 = sum_{k=0}^u binom(u,k)^2 binom(u+k,k)^2.
```

This identity is coefficientwise in u. Multiplying it over 2<=u<=H
reproduces the same independent diagonal degrees and moving moduli n-u, and
therefore the same exact large-prime product. It does not alter the
factorial saturation. A successful diagonal or cohomological argument would
need an additional theorem coupling different diagonal degrees in different
residue characteristics; the standard diagonal identity itself is not such
a theorem.

## 10. Quantitative ceiling

The prime number theorem on the fixed-ratio interval [rho,n] gives

```text
L_n <= pi(n-2)-pi(rho-1)
    = (1+o(1)) (n-rho)/log n
    = (1/4+o(1)) n/log n,
```

and

```text
Q_n <= theta(n-2)-theta(rho-1)
    = n-rho+o(n)
    = (1/4+o(1)) n.
```

Since every target prime lies in [3n/4,n],

```text
L_n log(3n/4) <= Q_n <= L_n log n.
```

Therefore

```text
Q_n = o(n)  if and only if  L_n = o(n/log n).
```

The exact telescope reaches the linear ceiling and stops.

## 11. The remaining fixed-row Apéry correlation

Let

```text
a_n(u) = 1_{n-u prime} 1_{n-u divides B_u},
2 <= u <= H.
```

Then

```text
C_n(h) = sum_{u=2}^{H-h} a_n(u) a_n(u+h).
```

Every unordered pair of target indices has exactly one positive gap, so

```text
sum_{h=1}^{H-2} C_n(h)
 = sum_{2<=u<v<=H} a_n(u) a_n(v)
 = binom(L_n,2).
```

Only even h contribute.

Thus (FRQ1) is equivalent to the desired result. Quantitatively, if for some
fixed delta>0

```text
2 sum_{h=1}^{H-2} C_n(h)
 <= C n^{2-delta}/log^2 n,
```

then

```text
L_n <= 1 + sqrt(C) n^{1-delta/2}/log n,
```

and consequently

```text
Q_n <<_C n^{1-delta/2} + log n.
```

The two conditions in one summand are

```text
p = n-u,
q = p-h = n-u-h,
p divides B_u,
q divides B_{u+h}.
```

The continuant telescope at p and the one at q live in different residue
characteristics. Their one-prime factorial determinants do not couple.
Proving (FRQ1), or any power saving of the displayed form, is the exact
actual-Apéry input left after the fixed-row product and natural subresultant
have been saturated.

## Terminal conclusion

The fixed-row product attack has the exact theorem-level outcome

```text
exp(Q_n)
 = (R_n)_{primes > n/2}
 = product of primes p in [rho,n-2] dividing G_n,
```

and

```text
G_n divides [ (n-1)!/(rho-1)! ]^6,
G_n / gcd(G_n, ((n-1)!/(rho-1)!)^infinity) = 1.
```

The actual Apéry recurrence does telescope modulo every moving prime
p=n-u, but it telescopes exactly to the sixth power of the moving factorial
tail. Locally the singular transfer has Smith form diag(1,p^6), while
reflection contributes only the forced factor 2u+h+1=p. These are exact
algebraic obstructions, not heuristic failures.

No recurrence-free countermodel is used, and no claim is made that the
actual Apéry sequence attains the ceiling (1/4+o(1)) n/log n. The remaining
theorem is precisely the actual mixed-characteristic fixed-row correlation
(FRQ1).
