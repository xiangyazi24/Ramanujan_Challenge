# Q7103: arithmetic certificate analysis for small Apéry zeros

## 1. Exact transfer identity

Let the gap polynomial be normalized by the standard recurrence

```
N_h(x)=P(x+h)N_{h-1}(x)-(x+h)^6N_{h-2}(x),
```

with the endpoint normalization

```
N_h(-s)=(-1)^{s-1} b_{s-1} b_{h-s} ((s-1)!(h-s)!)^3.
```

The transfer matrix identity gives, for every integer j and h>=1,

```
b_{j+h} b_{j+1}-b_{j+h+1} b_j
   = ((j+1)!/(j+h+1)!)^3 N_h(j).
```

Equivalently, after clearing denominators,

```
(j+h+1)!^3 (b_{j+h}b_{j+1}-b_{j+h+1}b_j)
       =(j+1)!^3 N_h(j).
```

The precise factorial unit is irrelevant modulo p when p>j+h. Therefore, if

```
p|b_j,
 p|b_{j+h},
 p not| b_{j+1},
```

then reducing the identity modulo p forces

```
p|N_h(j).
```

Hence the certificate integer is

```
G_{j,h}=gcd(b_j,N_h(j)).
```

Every prime producing a second zero at distance h from a small zero j divides this fixed integer.

---

## 2. What the certificate buys

The exceptional weighted mass can be reorganized as

```
Σ_{p in (X,2X]} Z(p)
```

where the contribution of primes with a small zero j<=H is bounded by

```
Σ_{j<=H} Σ_{h<=X} ω_(X,2X](G_{j,h})
```

(up to the reflected branch r<j, which gives the same expression after applying the symmetry
`Z(p)=1-Z(p)` around `(p-1)/2`).

Thus the problem becomes a gcd-height problem, not a zero-count problem.

---

## 3. Structural computation of G_{j,h}

For small j, the endpoint formula gives strong restrictions. Since

```
b_j | N_h(-j)
```

only after a shift, one might hope that evaluating at the zero location gives a large forced gcd. This is not the case. The two factors share only the part explained by the recurrence propagation.

The generic situation is:

```
log G_{j,h} = O(j log h + log h)
```

rather than

```
min(log b_j, log N_h(j)) ~ min(j, h)·log(17+12√2).
```

Small exact experiments (j<=20, h<=100) show the following pattern:

* most `G_{j,h}` are 1 or have only small prime factors;
* large common factors occur only when the gap recurrence hits a secondary divisibility relation;
* there is no evidence of a deterministic factor such as `b_j`, `b_{h-j}`, or a large factorial component surviving in `gcd(b_j,N_h(j))`.

The endpoint identity explains why: it creates divisibility at endpoints, but evaluating at the interior point j does not preserve the endpoint factorization.

---

## 4. Why a naive height argument fails

A trivial estimate gives

```
ω(G_{j,h}) <= log G_{j,h}/log X
          <= min(log b_j,log N_h(j))/log X.
```

For `j<=sqrt(X)` this is too weak because

```
log b_j ≍ j ≍ sqrt(X),
```

and summing over h gives a potential barrier of size

```
Σ_j Σ_h j/log X
    ≍ X^2/log X.
```

Therefore the desired bound

```
Σ ω_(X,2X](G_{j,h}) <= X^(3/2+o(1))
```

requires cancellation or a genuinely stronger gcd estimate.

---

## 5. Reflection does not remove the barrier

The reflection identity

```
b_{p-1-r} ≡ b_r (mod p)
```

duplicates the certificate on the opposite side of the orbit. It does not create independent arithmetic restrictions. A prime dividing `b_j` and producing many reflected zeros can still correspond to a single large common factor in a family of `G_{j,h}`.

Thus reflection improves bookkeeping but not the height problem.

---

## 6. Weakest sufficient new lemma

The needed statement is not a full gcd theorem. A sufficient form is:

```
For every j<=H,
Σ_{h<=X} log gcd(b_j,N_h(j)) = X^(1/2+o(1))
```

uniformly in j.

Indeed, dividing by `log X` gives

```
Σ_{j<=H}Σ_{h<=X}ω_(X,2X](G_{j,h})
 <= X^(3/2+o(1)).
```

A stronger but cleaner equivalent target is

```
log gcd(b_j,N_h(j)) << j log h
```

with an average saving over h:

```
Σ_h log gcd(b_j,N_h(j)) << H log X + X^1/2+o(1).
```

This is the weakest arithmetic input that closes the weighted exceptional-prime estimate.

---

## 7. Conclusion

The certificate `G_{j,h}` is the correct arithmetic reformulation. It improves the problem substantially: instead of bounding arbitrary pairs of zeros, one studies prime divisors of fixed integers.

However, the current identities (Lucas, no-adjacent-zero, reflection, endpoint factorization) do not by themselves force a sufficiently small gcd. They control where zeros can occur, but not the arithmetic height of the common divisor.

The missing lemma is therefore a gcd-anti-concentration statement for the sequence

```
{N_h(j) : h>=1}
```

against the fixed Apéry integer `b_j`, with average logarithmic loss at most `X^(1/2+o(1))`. Proving this would immediately imply the desired `X^(3/2+o(1))` weighted bound.
