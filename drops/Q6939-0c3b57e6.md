# 1. Exact row/Hodge convention and recurrence

All vectors below are **rows**, and all transitions act on the right.

For rows

`x = (x_0,x_1,x_2)`, `y = (y_0,y_1,y_2)`,

define the standard orientation

```text
x cross y = (
  x_1 y_2 - x_2 y_1,
  x_2 y_0 - x_0 y_2,
  x_0 y_1 - x_1 y_0
).
```

Equivalently this is the coordinate vector of `x wedge y` in the Hodge basis dual to the volume form `e_0 wedge e_1 wedge e_2`. Reversing orientation negates all three coordinates and changes nothing in the proportionality tests below.

Let

```text
B_{n+1} = B_n A_n,
J_{n+1} = J_n A_n,
c_n       = B_n cross J_n.
```

For every invertible `3 x 3` matrix `A`,

```text
(x A) cross (y A) = det(A) (x cross y) A^(-T).
```

Therefore

```text
c_{n+1} = det(A_n) c_n A_n^(-T).
```

For the raw terminating-`4F3` theta-jet matrix in the local computations,

```text
det(A_n)
  = (n+1)^4 (2n+3)^6
    / (8 (n+4)^7 (2n+7)^2 (2n+9)).
```

Write

```text
sigma_n = -(n+1)^3 (2n+3)^4,
S_n     = sigma_n A_n^(-T).
```

Then the literal exterior recurrence is

```text
c_{n+1} = mu_n c_n S_n,

mu_n = det(A_n)/sigma_n
     = -(n+1)(2n+3)^2
       / (8 (n+4)^7 (2n+7)^2 (2n+9)).
```

This negative scalar must not be dropped.

Define

```text
Lambda_0     = 1,
Lambda_{n+1} = Lambda_n / mu_n
             = Lambda_n sigma_n/det(A_n),

d_n = Lambda_n c_n.
```

Then

```text
d_{n+1} = d_n S_n.
```

The cumulative scalar is exactly

```text
Lambda_n
 = product_{k=0}^{n-1} sigma_k/det(A_k)
 = (-16)^n (4)_n^7 (7/2)_n^2 (9/2)_n
   / ((1)_n (3/2)_n^2).
```

Now use the given gauge in its stated row orientation:

```text
M_n U_{n+1} = U_n S_n.
```

This is equivalent to

```text
S_n U_{n+1}^(-1) = U_n^(-1) M_n.
```

Thus

```text
w_n := d_n U_n^(-1)
```

satisfies the literal challenge recurrence

```text
w_{n+1} = w_n M_n.
```

Without the `Lambda_n` normalization, `c_n U_n^(-1)` instead satisfies

```text
(c_{n+1} U_{n+1}^(-1))
  = mu_n (c_n U_n^(-1)) M_n.
```

This resolves the determinant/scalar/orientation bookkeeping.

# 4. The sign/cone bridge is not closed

There are two independent failures.

## 4.1 The base-matching row loses the raw positivity property

The formalized lower bound also gives

```text
G - 377/630 > 0,
G - 983/1386 > 0,
```

because

```text
32972/36000 - 377/630 = 6667/21000 > 0,
32972/36000 - 983/1386 = 47737/231000 > 0.
```

Therefore

```text
s_1 = (754-1260G)/96768 < 0,
s_2 = (-4915+6930G)/96768 > 0.
```

Thus `J_0^alt` has mixed last-coordinate signs. In particular, `-J_0^alt` is not entrywise positive in the same theta-jet basis. The positivity statement proved for the raw derivative row cannot be applied to the base-matching row.

So the exact dichotomy is:

```text
raw derivative:     positivity available, initial challenge match false;
alternate solution: initial challenge match true, positivity premise false.
```

## 4.2 Positivity of two rows would not determine the wedge signs anyway

Even abstractly, `B > 0` and `-J > 0` do not determine the signs of `B cross J`.
For example,

```text
B  = (1,1,1),
J  = (-1,-2,-3)
```

satisfy `B > 0` and `-J > 0`, but

```text
B cross J = (-1,2,-1).
```

Replacing `J` by `(-3,-2,-1)` gives

```text
B cross J = (1,-2,1).
```

Hence no endpoint bracket follows from primal positivity alone. One needs an ordering of the coordinate ratios, total positivity/sign-regularity, or an explicit exterior-square cone.

The actual cofactor cocycle is not entrywise sign-stable. For instance, the `(2,2)` entry (zero-based) of

```text
det(A_n) A_n^(-T)
```

is

```text
(n+1)(2n+3)^2
  (8n^5+4n^4-556n^3-2994n^2-5595n-3342)
/
(4(n+4)^5(2n+7)^2(2n+9)).
```

Its numerator polynomial is `-74692` at `n=10` and `179775` at `n=11`. Thus even a fixed orthant argument cannot be read off from the compound matrix.

A valid polyhedral certificate would have to provide explicit rational facet matrices `V_n` and entrywise nonnegative matrices `H_n` such that, for row vectors,

```text
K_n = { x : x V_n >= 0 },
S_n V_{n+1} = V_n H_n,
H_n >= 0,
d_0 in K_0,
```

and the facets of `K_n`, after applying `U_n^(-1)` and the parity normalization, imply

```text
positiveCatalanError n 0 <= 0,
0 <= positiveCatalanError n 2.
```

No such `V_n,H_n` are present in Q6935 or in the supplied data. The moving half-space cone defined tautologically by the two desired signs is not a certificate; its invariance is exactly the theorem to be proved.

Therefore the exterior-wedge route is **not a completed independent proof**.

# 5. What the existing `2/3` contraction would do after a sign certificate

This final implication is unconditional and independent of `dualMoment`/Meijer-G.

Let

```text
r_{n,j} = positiveNumerator(n,j)/positiveDenominator(n,j),
E^+_{n,j} = G positiveDenominator(n,j)-positiveNumerator(n,j).
```

All positive denominators are strictly positive. Hence

```text
E^+_{n,0} <= 0  implies  G <= r_{n,0},
0 <= E^+_{n,2}  implies  r_{n,2} <= G.
```

`Problem25Connection.lean` already proves

```text
lowerEnvelope(n) <= r_{n,j} <= upperEnvelope(n)
```

for every column, and

```text
upperEnvelope(n)-lowerEnvelope(n)
 = (2/3)^n (upperEnvelope(0)-lowerEnvelope(0)).
```

It also proves both envelopes converge to `commonLimit`. Combining the endpoint signs with the envelope bounds gives

```text
lowerEnvelope(n)
 <= r_{n,2}
 <= G
 <= r_{n,0}
 <= upperEnvelope(n).
```

Thus the constant sequence `G` is squeezed between two sequences converging to `commonLimit`, so

```text
commonLimit = G.
```

Then all three challenge ratios converge to `G` by the already-proved projective contraction.

So the remaining independent bridge is exactly the all-`n` endpoint sign/cone theorem; contraction itself is not a gap.
