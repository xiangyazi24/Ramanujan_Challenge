# 5. Noncircular definition of R_m^dr

Q3120's prose definition can be made completely formal.

For sufficiently large `m`, set

\[
y=m/\log m.
\]

For each prime `p>y` with `p|t_m`, define uniquely

\[
q_p:=\left\lfloor\frac mp\right\rfloor,
\qquad
 a_p:=m-q_pp,
\qquad 0\le a_p<p.
\]

Since `p>m/log m`, for large `m`

\[
0\le q_p<\log m<p.
\]

Now use the following **priority classification**.

### H: high-digit branch

`p` is high-digit if

\[
p\mid b_{q_p}.
\]

### L: low-digit branch

Otherwise `p\nmid b_{q_p}`.  Since `p|t_m` implies `p|d_m`, the exact mod-`p` support descent gives

\[
p\mid d_{a_p}.
\]

The cases `a_p=0` and `a_p=p-1` are impossible (`b_0=1`, and reflection gives `b_{p-1}\equiv1`).  Hence

\[
1\le a_p\le p-2.
\]

Because `p>a_p`, the clean first-jet identity gives

\[
p\mid b_{a_p},\qquad p\mid g_{a_p}.
\]

### C: central low digit

The low-digit prime is central if

\[
a_p=(p-1)/2.
\]

### D: de-ramified low digit

Otherwise put

\[
s_p:=\min(a_p,p-1-a_p).
\]

Reflection gives

\[
p>2s_p+1,
\qquad
p\mid b_{s_p},
\qquad
p\mid g_{s_p}.
\]

Now define

\[
\boxed{
R_m^{\rm dr}
 :=\prod_{\substack{p>y,\ p\mid t_m\\
p\nmid b_{q_p},\ a_p\ne(p-1)/2}}p.
}
\tag{Rdr}
\]

The displayed first-jet conditions at `s_p` are **consequences**, not part of the definition.

This definition is noncircular in the ordinary mathematical sense:

1. `b_m,E_m,d_m,h_m,t_m` are already defined;
2. membership of `p` in `R_m^dr` is decided directly from `p|t_m`, `q_p`, `a_p`, and `b_{q_p}`;
3. `R_m^dr` is never used to define `t_m`.

It is nevertheless target-dependent: it is a subset of the support of `t_m`.  Therefore a bound on `R_m^dr` is not automatically easier than a bound on `t_m`.  This distinction is important when interpreting `(S14)`.

# 11. Does Q3120 advance the fully unconditional route?

**As an algebraic localization: yes.  As a route to an unconditional proof: no; it is primarily an obstruction diagnostic.**

The advance is real in one sense:

- first-layer common zeros `d_m` are too broad;
- second saturation `t_m` is the exact object governing `v_m`;

\[
\log t_m=\log b_m-o(m),

\Longrightarrow
v_p(E_{m+1})=v_p(b_m),

so there is no obvious propagation mechanism producing the enormous amount of second saturation demanded by SELF-SAT.

Therefore the current self-energy route does not presently move P3.2 toward a fully unconditional proof.  It gives a sharp dichotomy:


That is a stronger negative structural conclusion than the earlier generic common-zero premise.
