# 1. Rationalize the positive integral

Start with

```text
F_n = sqrt(pi)/(Gamma(n+1) Gamma(n+2))
      * integral x^(1/2) (1-x)^n (1-y)^(n+1) u^(n+1) v^(n+1)
        exp(-u-v-2 sqrt(uv/(xy))) du dv dx dy,
```

where `0<x,y<1` and `u,v>0`.

For fixed `x,y,u`, make the one-dimensional substitution

```text
v = w^2 x y / u,       dv = 2 w x y/u dw.
```

It is a bijection `(0,infinity) -> (0,infinity)`.  The powers simplify
exactly:

```text
u^(n+1) v^(n+1) dv
 = 2 (xy)^(n+2) w^(2n+3) u^(-1) dw.
```

Therefore

```text
F_n = c_n integral K_n(x,y,w,u) du dw dx dy,                 (1.1)

c_n = 2 sqrt(pi)/(Gamma(n+1) Gamma(n+2)),
```

with

```text
K_n = x^(n+5/2) y^(n+2) (1-x)^n (1-y)^(n+1)
      * w^(2n+3) u^(-1)
      * exp(-u - w^2 x y/u - 2w).                            (1.2)
```

This is the best coordinate system for creative telescoping:

```text
K_(n+1)/K_n = tau,

tau = x y (1-x)(1-y) w^2,                                  (1.3)

c_(n+1)/c_n = 1/((n+1)(n+2)).                               (1.4)
```

There are no radicals and the shift quotient is a polynomial.

For reference, the logarithmic derivatives are

```text
Lx = d_x log K_n
   = (n+5/2)/x - n/(1-x) - w^2 y/u,

Ly = d_y log K_n
   = (n+2)/y - (n+1)/(1-y) - w^2 x/u,

Lw = d_w log K_n
   = (2n+3)/w - 2wxy/u - 2,

Lu = d_u log K_n
   = -1/u - 1 + w^2xy/u^2.                                  (1.5)
```

# 4. Boundary terms

The factors in (3.1) were chosen so that all boundary terms vanish.

For `Px_j K_n`:

```text
x -> 0:  x^(n+7/2) -> 0,
x -> 1:  (1-x)^(n+1) -> 0.
```

For `Py_j K_n`:

```text
y -> 0:  y^(n+3) -> 0,
y -> 1:  (1-y)^(n+2) -> 0.
```

For `Pw_j K_n`:

```text
w -> 0:  w^(2n+4) -> 0,
w -> infinity: exp(-2w-w^2xy/u) dominates every polynomial.
```

For `Pu_j K_n`, the factor `u` cancels the `u^(-1)` in `K_n`:

```text
u -> 0:        exp(-w^2xy/u) -> 0   for x,y,w>0,
u -> infinity: exp(-u) -> 0.
```

The exceptional coordinate faces have measure zero and the other factors
already vanish there.

Absolute integrability of the differentiated terms is elementary.  Every
negative extra power of `u` occurs together with a factor

```text
A = w^2 x y.
```

For `r>=0`,

```text
(A/u)^r exp(-A/u) <= sup_(t>=0) t^r exp(-t) < infinity.
```

The remaining powers are controlled by beta integrability at `x,y=0,1` and by
`exp(-u-2w)` at infinity.  Hence one may apply one-dimensional integration by
parts iteratively and Fubini/Tonelli.  This is well suited to Lean: no
multidimensional divergence theorem is required.

Integrating (3.3) gives

```text
integral R_j K_n = 0,
```

and (1.3)--(1.4) then give the exact trajectory

```text
Y_(n+1) = Y_n T(n).                                          (4.1)
```

This proves the trajectory directly from the positive real integral.

# 7. Lean-sized proof plan

A formal replacement for the Barnes trajectory lemma can be organized as
follows.

1. **One-variable substitution in `v`.**  Prove (1.1) by applying the standard
   interval/set integral substitution to
   `v = (x*y/u)*w^2`, with the other variables fixed, then use Tonelli because
   the original integrand is nonnegative.

2. **Define the three moments.**  Define `b0,b1,b2`, `K`, and `Y` as in
   (1.2), (2.1), and (2.2).

3. **Polynomial certificate.**  Paste the 21 emitted rational polynomials.
   For each column, prove (3.2) with `field_simp` followed by `ring`.
   All denominators are products of positive linear factors in `n`.

4. **Iterated integration by parts.**  Apply the one-dimensional derivative
   integral theorem successively in `x`, `y`, `w`, and `u`.  The boundary
   lemmas above are elementary positivity/limit goals.  Use Fubini to move the
   derivative variable to the innermost integral.

5. **Trajectory and recurrence.**  Obtain (4.1), define `U` and `C`, and close
   the Krylov identities by rational normalization.

This route uses only real exponentials, powers, beta-type endpoint estimates,
Fubini/Tonelli, and polynomial algebra.  It does not invoke a Meijer function,
a Barnes contour, a differential equation imported from either, Miller's
algorithm, or numerical recurrence recognition.
