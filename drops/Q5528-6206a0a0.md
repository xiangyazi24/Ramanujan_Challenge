 C=b\eta+\varepsilon q c_0=bn+\rho.

 m_{\theta,k}=|\mathcal P_{\theta,k}|,

# 2. Audit A: fixed-prime overlap among the exact-`k` packets

For every literal occurrence,

\[
 pk\equiv-\rho\pmod b,
 \qquad
 p'k\equiv-\rho\pmod b,
\tag{2.1}
\]

with

\[
 (k,b)=(\rho,b)=1,
 \qquad
 |k|\le C_vB,
 \qquad
 b\asymp_vB.
\tag{2.2}
\]

## 2.1 Invertibility of the source prime

The congruence itself forces `(p,b)=1`. Indeed, if `d | (p,b)`, then `d | pk`, and (2.1) gives `d | rho`. Since `(rho,b)=1`, one has `d=1`. Thus

\[
 (p,b)=1.
\tag{2.3}
\]

The same holds for `p'`.

## 2.2 One residue class for `k`

For fixed `theta` and fixed source prime `p`, (2.1) becomes

\[
 k\equiv-\rho\,\overline p\pmod b.
\tag{2.4}
\]

The physical interval `[-C_vB,C_vB]` has length `O_v(B)`, while `b\asymp_vB`. Hence it contains at most

\[
 1+\frac{2C_vB}{b}=O_v(1)
\tag{2.5}
\]

integers in the residue class (2.4). Therefore

\[
 \boxed{
 \nu_\theta(p):=\#\{k:p\in\mathcal P_{\theta,k}\}\ll_v1.
 }
\tag{2.6}
\]

This proves the claimed bounded cover.

## 2.3 Multiplicity audit

The possible multiplicities do not alter (2.6):

- **Actual-zero labels.** A prime `p` may have `Z(p)` admissible zero labels, but all labels with the same `p,k` contribute to the single support membership `p in P_{theta,k}`. Their positive mass is already majorized by the one factor `Z(p)` in (1.5) and in `z_k`.
- **The quotient `n`.** It is derived from (1.2), and only `rho mod b` enters (2.1). It creates no new residue class for `k`.
- **Sign.** `epsilon` is fixed in `theta`. If both signs are summed, split them into two `theta`-pieces; this is a factor two.
- **Primitive/source masks.** These are `0`--`1` restrictions on the literal occurrences. They delete support points and cannot increase `nu_theta(p)`.
- **Physical representatives.** All representatives satisfy the same interval bound `|k|<=C_vB`. Different representatives can only be the `O_v(1)` lifts in (2.5).
- **Charts.** Refine by `chi` as in (1.1), or sum the `O_v(1)` pieces. There is no `B`-, `q`-, or `Z(p)`-sized chart family.
- **The outer prime `q`.** It is fixed in `theta` and contributes exactly one weight `|u_q|` to `w_k`.

Thus A is true with literal occurrence multiplicities preserved.

### Load-bearing warning

If `P_k` were an occurrence multiset rather than the support set (1.3), the first invalid line would be

\[
 \sum_k z_k
 =\sum_{p\asymp N}Z(p)\nu_\theta(p).
\tag{2.7}
\]

Extra occurrence labels would appear on the right. The quoted statement explicitly calls `P_k` a set and gives (1.5), so this counterfactual defect is not present.

# 3. Audit B: the four exact-`k` bounds

## 3.1 Bound for one `w_k`

From `|u_p|\ll N^{-1+o(1)}`,

\[
 \sum_{p\in\mathcal P_k}|u_p|Z(p)
 \ll N^{-1+o(1)}z_k,
\tag{3.1}
\]

and

\[
 \sum_{p'\in\mathcal P_k}|u_{p'}|
 \ll N^{-1+o(1)}m_k.
\tag{3.2}
\]

Substitution in (1.5) gives

\[
 C_k\ll N^{-2+o(1)}z_km_k.
\tag{3.3}
\]

Because `q asymp N` and its weight occurs once,

\[
 |u_q|\ll N^{-1+o(1)},
\]

so

\[
 \boxed{w_k\ll N^{-3+o(1)}z_km_k.}
\tag{3.4}
\]

## 3.2 Size of one source-prime packet

For fixed `k`, `(k,b)=1` makes (2.1) equivalent to

\[
 p\equiv-\rho\,\overline k\pmod b.
\tag{3.5}
\]

The source-prime shell has length `O_v(N)`. One residue class modulo `b` has at most `1+O_v(N/b)` integer representatives there. Therefore

\[
 m_k\ll_v1+\frac{N}{b}.
\tag{3.6}
\]

The staged radial range has `b\asymp_vB\ll_vN`, so the `1` is absorbed and

\[
 \boxed{m_k\ll_v\frac{N^{1+o(1)}}B.}
\tag{3.7}
\]

The more robust form is (3.6); if a future version allows `B>N`, it must not replace (3.6) by `N/B`.

## 3.3 Sum of the marked zero masses

Expand using the support-set definition:

\[
\begin{aligned}
 \sum_kz_k
 &=\sum_k\sum_{p\in\mathcal P_{\theta,k}}Z(p)\\
 &=\sum_{p\asymp N}Z(p)\nu_\theta(p).
\end{aligned}
\tag{3.8}
\]

By (2.6) and the canonical first zero moment,

\[
 \boxed{
 \sum_kz_k\ll_v\sum_{p\asymp N}Z(p)
 \ll N^{8/5+o(1)}.
 }
\tag{3.9}
\]

There is one `Z(p)`, not `Z(p)^2`.

## 3.4 Fixed-radial mass

All quantities are nonnegative, so (3.4), (3.7), and (3.9) give

\[
\begin{aligned}
 W(\theta)
 &=\sum_kw_k\\
 &\ll N^{-3+o(1)}\sum_kz_km_k\\
 &\le N^{-3+o(1)}\left(\max_km_k\right)\sum_kz_k\\
 &\ll N^{-3+o(1)}\frac NB N^{8/5}\\
 &=\boxed{\frac{N^{-2/5+o(1)}}B}.
\end{aligned}
\tag{3.10}
\]

The exponent is

\[
 -3+1+\frac85=-\frac25.
\]

## 3.5 The radial square

Let the banked positive ledger be on the same literal `theta`-index:

\[
 \sum_\theta W(\theta)\ll N^{4/5+o(1)}M.
\tag{3.11}
\]

Then

\[
\begin{aligned}
 \sum_\theta W(\theta)^2
 &\le \left(\sup_\theta W(\theta)\right)
       \sum_\theta W(\theta)\\
 &\ll \frac{N^{-2/5+o(1)}}B
       N^{4/5+o(1)}M\\
 &=\boxed{\frac{N^{2/5+o(1)}M}{B}}.
\end{aligned}
\tag{3.12}
\]

This max-times-`L^1` step is legal across all charts. It needs neither disjoint chart supports nor independence: it is the elementary inequality `sum x_i^2 <= (sup x_i) sum x_i` for nonnegative terms. If a coarse `theta_0` aggregates finitely many chart pieces, either keep the chart in `theta` or use

\[
 W(\theta_0)^2
 \le \#\{\chi\}\sum_\chi W(\chi,\theta_0)^2,
\]

and absorb `#chi=O_v(1)`.

Thus every assertion in B is unconditional at the quoted staged RR68 level.

## 4.2 Centered contribution

The second term gives

\[
 E_{\rm cent}
 \ll N^{-1+o(1)}K\sqrt F\,B S_2^{1/2}

\[

Then weighted Cauchy--Schwarz gives

\[
\begin{aligned}

   \bigl(|u_r|Z(r)\bigr)^{1/2}
   \bigl(|u_r|Z(r)^2\bigr)^{1/2}\\

Also

Substituting (4.9)--(4.11) into (4.8),

\begin{aligned}
