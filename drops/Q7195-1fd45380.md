# P32 periodic pair-cap strengthening audit

## Verdict

The proposed strengthening is **not a valid counterexample to weak-DPLS from the listed abstract filters**. The geometric construction and pair-cap properties are essentially correct, but the final quotient-energy count uses the wrong notion of support. The flaw is that reflection quotienting does not identify all left windows into a single state with multiplicity one: it identifies reflected copies of the same abstract orbit, but different left windows are distinct chains unless their projective labels coincide. The construction gives a large collection of abstract windows, not a large collection of chains in one actual state fiber.

Therefore the claimed lower bound

\[
(k-3)(k-4)\asymp p^{4/3}
\]

for a single quotient state does not follow.

## 1. Size and prime choice

Set

\[
m=100\lfloor p^{1/3}/1000\rfloor .
\]

For sufficiently large p this gives

\[
m=0.1p^{1/3}+O(100),
\]

and

\[
L=RS=\frac m{100}\frac{m(7m-1)}2
=\Theta(m^3)=\Theta(p).
\]

The condition

\[
4(D+L)+1<p
\]

is not automatic from the displayed choice. It requires the leading constant check. Since

\[
L\sim \frac{7}{200}m^3
\sim \frac{7}{200000}p,
\]

we have

\[
4L\sim \frac7{50000}p<p,
\]

so the inequality holds for sufficiently large p. The constant margin is genuine.

## 2. Packet geometry

The periodic gaps satisfy

\[
3m\le g_i\le4m-1.
\]

Hence there are no adjacent points. Three consecutive gaps satisfy

\[
 g_i+g_{i+1}+g_{i+2}
\le 12m-6<12m=H,
\]

so every internal four-point packet window has span below \(H\).

Because

\[
H=12m<\sqrt p
\]

for large p, these are short windows.

The endpoint-free translation by D=1 correctly removes 0 and p-1 from the set. Reflection preserves the endpoint exclusion.

## 3. Pair caps

The existing periodic proof of

\[
A_Z(h)\le3(h-1)
\]

survives the translation by D and reflection. Differences inside a packet are unchanged. Cross-reflection differences are shifted but retain the same uniqueness estimate because

\[
(p-1-D-P_a)-(D+P_b)=p-1-2D-P_a-P_b.
\]

The extra constant D does not create new collisions.

Thus the deterministic set really satisfies:

* palindrome;
* no adjacency;
* endpoint absence;
* Apéry pair-cap inequality;
* many short nonconstant-gap windows.

## 4. The fatal step: quotient support is not one state

Let a left window be

\[
\gamma_i=(D+P_i,D+P_{i+1},D+P_{i+2},D+P_{i+3}).
\]

Reflection gives the paired window

\[
(p-1-D-P_{i+3},\ldots,p-1-D-P_i).
\]

This only proves that each window has a reflection orbit of size two.

It does **not** prove

\[
q(\gamma_i)=q(\gamma_j)
\]

for different i,j.

The abstract periodic construction is a subset of integers. It does not carry the Apéry recurrence's projective labels. A window being a translated copy of a gap pattern does not imply that the corresponding four points occupy the same projective state in \(\mathbf P^1(\mathbf F_p)\).

The weak-DPLS quantity is a fiber count

\[
C_p(q)=\#\{\text{qualified chains with projective state }q\},
\]

not the number of combinatorial windows in the same difference pattern.

## 5. Ordered overlap calculation

The local overlap calculation is correct as a statement about interval supports.

If k consecutive windows are indexed by i, then two windows overlap as sets of indices when

\[
|i-j|\le3.
\]

The number of ordered separated pairs is indeed

\[
k(k-1)-2((k-1)+(k-2)+(k-3))
=(k-3)(k-4).
\]

But this counts pairs of integer windows, not pairs in a common projective fiber.

The missing implication is:

\[
\gamma_i,\gamma_j\text{ separated}\implies q(\gamma_i)=q(\gamma_j),
\]

which is false and has no analogue from pair caps.

## 6. Dyadic conclusion

Even if every prime admits this deterministic zero-set construction, it only proves that the abstract axioms allow many windows. It does not prove that the Apéry orbit realizes those windows in one state.

Therefore the claimed implication

\[
\sum_{p\sim X}V_p\gg X^{7/3}/\log X
\]

cannot be derived.

The correct publication statement is:

> Pair caps + reflection + endpoint exclusion + local filters are insufficient to bound the number of abstract short windows. However, weak-DPLS is a statement about projective orbit fibers, and the construction does not satisfy the required fiber collision axiom. The missing ingredient is precisely recurrence-specific projective-state information.

## Final classification

Verified:

* every-prime scale choice works;
* endpoint-free construction works;
* pair caps remain valid;
* short nonconstant windows exist;
* reflection quotient is valid as an involution.

Invalid:

* all quotient supports lie in one state;
* separated window pairs contribute to one \(C_p(q)^2\);
* the resulting abstract energy is a lower bound for weak-DPLS variance.

The exact flaw is the identification of **reflection orbit classes of integer windows** with **projective state fibers**.
