# qAP-FREE: mesoscopic triple structure and the limits of AP-rarity

Repository state audited: the current campaign state through commit `e54864f7967776a973215cadf17b8e3c1b5cd8c8`, especially the merged mesoscopic section, the inverse-square clique theorem, the axis-strip reduction, and the renewal/addition-law identities.

## Executive verdict

The proposed AP-free route does not close the mesoscopic wall.

The decisive points are these.

1. Large `Q_D` with `S_D << N` does not force one large fiber, a long arithmetic progression, small doubling, or even a single three-term arithmetic progression. It can be carried by `Theta(N)` disjoint three-point fibers, each contributing one triple and only three pair collisions.

2. The exact combinatorial structure is multiplicity concentration, not additive structure. For

```text
d_D(r) = #{1 <= h <= D : pi(r)=pi(r+h)},
S_D = sum_r d_D(r),
Q_D = sum_r binom(d_D(r),2),
```

one has

```text
2Q_D = sum_r d_D(r)(d_D(r)-1).
```

Thus `Q_D/S_D` is the collision-incidence-weighted mean of `(d_D(r)-1)/2`. When both `Q_D` and `S_D` are of order `N`, the typical contributing base may have only two returns. No large `K` is forced.

3. A same-fiber three-term AP

```text
r, r+d, r+2d
```

is exactly the shifted double-root event

```text
N_d(r)=0,
N_d(r+d)=0.
```

The addition law then gives `N_{2d}(r)=0`, but after substitution it becomes `0=0`. It is merely transitivity. It forces no neighboring gap, no fourth point, and no cascade.

4. Degree alone gives only

```text
#{r : N_d(r)=N_d(r+d)=0} <= 3(d-1),
```

hence after summing `d <= D/2`,

```text
# same-fiber 3-APs of span <= D << D^2.
```

At `D=sqrt(N)L`, this is `O(NL^2)`, exactly the wrong mesoscopic scale. It is not `O(N/D)` and does not yield `Q_D << N`.

5. Even a hypothetical sharp bound for all equal-step APs would control only the diagonal `a=g` in the exact renewal decomposition

```text
Q_D = sum_{a,g >= 1, a+g <= D} C_p(a,g),

C_p(a,g)
 = #{r : pi(r)=pi(r+a)=pi(r+a+g)}.
```

The off-diagonal shapes `a != g` can carry all of `Q_D`. There are explicit AP-free three-point-cluster words with `Q_D >> N` and no equal-step triple at all.

6. The minimal arithmetic input is therefore not AP-rarity. It is the already identified all-shape shifted-pair estimate on the balanced mesoscopic core:

```text
sum_{a>G, g>G, a+g<=D}
  #{r : N_a(r)=0 and N_g(r+a)=0}
<< N,
```

where

```text
D = ceil(sqrt(N)L),
G = ceil(N^(1/3)L^(-1/3)).
```

Together with the proved axis-strip bound, this is exactly sufficient for `Q_D << N`. Any lemma restricted to `a=g` is insufficient.

So the correct final label is:

```text
[NEGATIVE-AP-DIAGONAL]
Three-term-AP rarity is only a diagonal slice of the mesoscopic triple problem.
The addition law supplies transitivity but no cascade.
The surviving target is [MESO-BALANCED-PAIR], not [AP-FREE].
```

# 1. Exact combinatorial identities

Let `x_1,...,x_N` be any word. In the Apery application, `x_n=pi(n)`. Define

```text
d_D(r)
 = #{1<=h<=D : r+h<=N and x_r=x_(r+h)},

S_D = sum_r d_D(r),
Q_D = sum_r binom(d_D(r),2).
```

Then `S_D` counts monochromatic pairs of positive gap at most `D`, while `Q_D` counts monochromatic triples of span at most `D`, based at their least point.

## Proposition 1.1: exact triple identity

```text
Q_D
 = #{(r,a,g) :
      a>=1, g>=1, a+g<=D,
      x_r=x_(r+a)=x_(r+a+g)}.                       (1.1)
```

Proof. A term in `binom(d_D(r),2)` is a choice of two return offsets

```text
1 <= h < k <= D.
```

Put `a=h` and `g=k-h`. Conversely, `(a,g)` gives `(h,k)=(a,a+g)`. This is a bijection.

For the Apery orbit define

```text
C_p(a,g)
 = #{r : r+a+g<=M,
          pi(r)=pi(r+a)=pi(r+a+g)}.
```

Then

```text
Q_D = sum_(a,g>=1, a+g<=D) C_p(a,g).                (1.2)
```

This is the exact renewal decomposition used in the merged mesoscopic section.

## Proposition 1.2: the true high-multiplicity dichotomy

For every integer `K>=2`,

```text
Q_D
 <= ((K-1)/2) S_D
    + (1/2) sum_(r : d_D(r)>K) d_D(r)^2.            (1.3)
```

Proof. If `d_D(r)<=K`, then

```text
binom(d_D(r),2)
 <= ((K-1)/2)d_D(r).
```

For the remaining bases use `binom(d,2)<=d^2/2` and sum.

Equivalently, if

```text
S_D <= C_0 N,
Q_D >= A N,
```

then

```text
sum_(r : d_D(r)>K) d_D(r)^2
 >= (2A-(K-1)C_0)N.                                (1.4)
```

This is useful only when `2A>(K-1)C_0`. In particular, if `A` and `C_0` are comparable constants, one can force bases with two or three returns, but not a growing return count `K`.

## Proposition 1.3: exact tail form

Let

```text
A_D(t) = #{r : d_D(r)>=t}.
```

Then

```text
S_D = sum_(t>=1) A_D(t),
Q_D = sum_(t>=2) (t-1) A_D(t).                      (1.5)
```

This is the exact structural characterization. Large `Q_D` is a heavy-tail statement for the local return multiplicities. It says nothing by itself about additive relations among the return offsets.

# 2. Why AP structure is not forced

The question asks whether mesoscopic extremality is precisely a fiber with many returns arranged using few distinct gaps. It is not.

## 2.1 Private three-point clusters

Take any family of disjoint three-point sets

```text
A_j = {u_j, u_j+a_j, u_j+a_j+g_j},
```

with

```text
a_j>=1,
g_j>=1,
a_j+g_j<=D,
a_j != g_j.
```

Give the three positions in `A_j` a private color, different for each `j`, and give every unused position a singleton color.

Each cluster contributes

```text
S_D(A_j)=3,
Q_D(A_j)=1.
```

Indeed, its three unordered pairs all have gap at most `D`, and it has one monochromatic triple. Since `a_j != g_j`, it contains no three-term arithmetic progression.

With `J` disjoint clusters,

```text
S_D=3J,
Q_D=J.                                               (2.1)
```

Thus for `J=Theta(N)` one has simultaneously

```text
S_D=Theta(N),
Q_D=Theta(N),
```

while every nontrivial fiber has exactly three points and no fiber contains a three-term AP.

Therefore no dichotomy of the form

```text
Q_D >> N
=> one fiber has K -> infinity returns
```

is valid, and no dichotomy forcing many equal-step APs is valid.

The same construction can be placed blockwise at the mesoscopic scale and the gap pairs can be spread through the upper part of `[1,D]`. Because `D>=sqrt(N)`, a gap of size comparable to `D` may occur `O(N/D)<=O(D)` times without violating a bound of the form `R_d<=Cd`. Thus the obstruction is compatible with the one-gap degree scale; it is not an artifact of concentrating all clusters on one gap.

## 2.2 Small doubling is also not forced

For a fiber portion `A` of size `m` inside a `D`-window, the contribution to `Q_D` is simply

```text
binom(m,3),
```

provided the diameter is at most `D`. This number depends only on `m`, not on `|A-A|`.

A random `m`-point subset of a long interval can have

```text
|A-A| comparable to m^2
```

while contributing exactly the same `binom(m,3)` triples as an arithmetic progression of length `m`.

For `m=3`, every set has bounded doubling for the vacuous reason that there are only three points. Calling such a set "small doubling" gives no usable arithmetic information. The private-cluster obstruction above is therefore not removed by a small-doubling formulation.

## 2.3 What large Q_D really forces

There is one exact quantitative conclusion and no stronger purely combinatorial one:

```text
Q_D/S_D
 = (1/2)
   * weighted mean of d_D(r)-1,
```

where the weights are `d_D(r)`. Thus:

- if `Q_D >> S_D`, high local multiplicity is forced;
- if `Q_D` and `S_D` are both `Theta(N)`, constant-size three-point clusters suffice;
- additive structure of the offset sets is not forced in either case.

A window-count version follows from any upper bound `M_D` for the number of points of one fiber in a `D`-window. If triples are assigned to disjoint or bounded-overlap `D`-windows, then one window-color pair carries at most `binom(M_D,3)` triples. Therefore

```text
# triple-supporting window-color pairs
 >= Q_D / binom(M_D,3).                              (2.2)
```

With the proved `M_D<<D^(2/3)`, the denominator is `O(D^2)`. At `D=sqrt(N)L` and `Q_D=Theta(N)`, (2.2) gives only `Omega(1/L^2)`, which is vacuous. This confirms that the known window multiplicity bound does not force many structured windows.

# 3. Arithmetic translation of a three-term AP

Fix `d>=1` and a regular nonwrapping index `r` with `r+2d<=M`.

The event

```text
pi(r)=pi(r+d)=pi(r+2d)                               (3.1)
```

is equivalent to

```text
N_d(r)=0,
N_d(r+d)=0.                                          (3.2)
```

It also implies

```text
N_(2d)(r)=0                                          (3.3)
```

by transitivity.

Define the AP count

```text
A_p(d)
 = #{r : 1<=r<=M-2d,
          N_d(r)=0,
          N_d(r+d)=0}.                               (3.4)
```

Then the total same-fiber three-term-AP count of span at most `D` is

```text
AP_p(D) = sum_(d<=D/2) A_p(d).                       (3.5)
```

This is exactly the diagonal `a=g=d` of (1.2).

# 4. What the addition law says at a three-term AP

The relevant addition law is

```text
N_(2d)(r)
 = N_d(r+d) N_(d+1)(r)
   - (r+d+1)^6 N_(d-1)(r+d+1) N_d(r).                (4.1)
```

At a three-term AP, both `N_d(r)` and `N_d(r+d)` vanish. Therefore (4.1) gives

```text
N_(2d)(r)=0-0=0.                                     (4.2)
```

This is exactly (3.3), and nothing more.

There is no legal cancellation in (4.1): both summands vanish independently. In particular, (4.1) does not force

```text
N_(d+1)(r)=0,
N_(d-1)(r+d+1)=0,
or N_d(r+2d)=0.                                      (4.3)
```

Adjacent coprimality does not change this conclusion. The theorem

```text
gcd_Q[X](N_d,N_(d+1))=1
```

concerns common roots of two polynomials at the same argument over characteristic zero. The AP conditions use

```text
N_d(r),
N_d(r+d),
```

which are shifted evaluations of the same polynomial modulo `p`. No contradiction follows.

The transfer-matrix interpretation makes the absence of a cascade transparent. A three-term AP says:

```text
the length-d transfer starting at r returns pi(r),
and the length-d transfer starting at r+d returns the same point.
```

The product of these two transfers gives the length-`2d` return. It gives no information about the next length-d transfer starting at `r+2d`. A fourth point

```text
pi(r+3d)=pi(r)
```

would require the new independent condition

```text
N_d(r+2d)=0.                                         (4.4)
```

Only if (4.4) is separately assumed can one continue the progression. Inductively, an AP of length `ell` requires `ell-1` shifted zero conditions; the first two do not generate the rest.

Thus the hoped-for cascade is false.

# 5. The unconditional degree bound for AP events

For fixed `d`, the set counted by `A_p(d)` is contained in the root set of `N_d(r)`. Since

```text
deg N_d = 3(d-1),
```

and `N_d` is nonzero modulo `p` on the regular range under the banked nonvanishing hypotheses used for the gap bound,

```text
A_p(d) <= 3(d-1).                                    (5.1)
```

Equally, it is contained in the shifted root set of `N_d(X+d)`, which has the same degree. Degree alone does not improve the minimum of these two identical bounds.

Summing (5.1),

```text
AP_p(D)
 <= 3 sum_(d<=D/2)(d-1)
 << D^2.                                              (5.2)
```

At the mesoscopic scale

```text
D=sqrt(N)L,
```

this becomes

```text
AP_p(D) << N L^2.                                    (5.3)
```

This is larger than the target `O(N)` by the same `L^2` factor appearing in the abstract mesoscopic wall.

To obtain a bound of order `N/D` for the total AP count would require an enormous new saving:

```text
sum_(d<=D/2)
 deg gcd_Fp(N_d(X),N_d(X+d))
 << N/D.                                              (5.4)
```

Nothing in the current degree, reflection, adjacent-coprimality, or addition-law package implies (5.4).

Moreover, even (5.4) would not control `Q_D`, because it concerns only `a=g`.

# 6. Why AP-rarity cannot imply the mesoscopic pair bound

Split (1.2) into diagonal and off-diagonal shapes:

```text
Q_D
 = AP_p(D)
   + sum_(a,g>=1, a+g<=D, a!=g) C_p(a,g).            (6.1)
```

An AP-rarity lemma bounds only the first term.

The private-cluster construction can be chosen with `a_j!=g_j` for every color. Then

```text
AP_p(D)=0,
Q_D=Theta(N).                                        (6.2)
```

By taking more clusters in the allowed length range, the same construction gives `Q_D` at the largest scale permitted by the ambient one-gap constraints while the AP term remains zero.

Therefore the logical implication

```text
AP_p(D) << N
=> Q_D << N                                          (6.3)
```

is false in the abstract word class, and no current Apery identity converts off-diagonal triples into diagonal ones.

A Balog-Szemeredi-Gowers style conclusion is also unavailable. Such theorems require large additive energy, for example many solutions of

```text
a+b=c+d.
```

The quantity `Q_D` counts arbitrary three-element subsets of fibers. It is not additive energy. A large value of `Q_D` does not imply many equal sums or a small difference set.

# 7. The exact minimal arithmetic input

The correct arithmetic object is the all-shape shifted double-root count

```text
rho_p(a,g)
 = #{r regular : N_a(r)=0 and N_g(r+a)=0}.           (7.1)
```

Every triple count satisfies

```text
C_p(a,g) <= rho_p(a,g).                              (7.2)
```

At the mesoscopic scale put

```text
D = ceil(sqrt(N)L),
G = ceil(N^(1/3)L^(-1/3)).                            (7.3)
```

The proved axis-strip estimate gives

```text
sum_(a+g<=D, min(a,g)<=G) C_p(a,g) << N.             (7.4)
```

Therefore the following is the clean minimal surviving lemma.

## [MESO-BALANCED-SHIFTED-ROOT]

```text
sum_(a>G, g>G, a+g<=D) rho_p(a,g) << N.              (7.5)
```

By (7.2), (7.4), and the renewal identity,

```text
Q_D << N.                                             (7.6)
```

This is exactly the already banked `[MESO-BALANCED-PAIR]` target, written directly in gap-polynomial language.

One may replace (7.5) by either stronger arithmetic statement

```text
sum_(a>G,g>G,a+g<=D)
 deg gcd_Fp(N_a(X),N_g(X+a)) << N,                   (7.7)
```

or

```text
sum_(a>G,g>G,a+g<=D)
 v_p Res_X(N_a(X),N_g(X+a)) << N,                    (7.8)
```

with the existing leading-coefficient and regular-root caveats. But the raw resultant route was already shown to require saturation of cut-edge factors; (7.5) is the logically minimal point-count form.

## Why an AP lemma is strictly weaker

The AP count is

```text
AP_p(D) = sum_(d<=D/2) rho_p(d,d).                   (7.9)
```

Thus it samples only `O(D)` diagonal pairs out of `Theta(D^2)` possible `(a,g)` shapes. Even the ideal bound

```text
sum_d rho_p(d,d)=0                                   (7.10)
```

leaves the balanced off-diagonal sum in (7.5) completely uncontrolled.

# 8. A precise quantitative dichotomy that is actually true

Although additive structure is not forced, one can state a complete multiplicity dichotomy.

Fix `K>=2`. Let

```text
Q_D^light(K)
 = sum_(r : d_D(r)<=K) binom(d_D(r),2),

Q_D^heavy(K)
 = sum_(r : d_D(r)>K) binom(d_D(r),2).
```

Then

```text
Q_D^light(K) <= ((K-1)/2)S_D,                        (8.1)
```

and

```text
Q_D^heavy(K)
 >= Q_D-((K-1)/2)S_D.                                (8.2)
```

Consequently, if

```text
S_D<=C_0N,
Q_D>=AN,
```

then either

```text
A <= ((K-1)/2)C_0,                                   (8.3)
```

so constant-size clusters already explain the triple mass, or

```text
sum_(r:d_D(r)>K)d_D(r)^2
 >= (2A-(K-1)C_0)N.                                 (8.4)
```

This is the exact replacement for the requested AP/small-doubling dichotomy.

If one also uses the proved window multiplicity bound

```text
d_D(r)+1 <= M_D << D^(2/3),                          (8.5)
```

then (8.4) implies at least

```text
Omega((2A-(K-1)C_0)N / D^(4/3))                     (8.6)
```

heavy bases. At `D=sqrt(N)L`, this is only

```text
Omega(N^(1/3)L^(-4/3)),                              (8.7)
```

and it still gives no additive structure of their return sets.

No stronger statement follows from `Q_D,S_D`, and the one-gap bounds alone.

# 9. What an AP-sensitive theorem could still contribute

AP-rarity is not useless; it can remove one structured diagonal subfamily from the balanced core.

A meaningful theorem would be

```text
[AP-DIAGONAL-RARITY]

sum_(G<d<=D/2)
 #{r : N_d(r)=0 and N_d(r+d)=0}
 << N.                                                (9.1)
```

This would prove that the equal-step diagonal contributes acceptably to `Q_D`. It could be useful as one stratum in a future proof of (7.5), especially because equal-step triples are a natural locus of extra symmetry.

But after proving (9.1), the main remaining obligation would still be

```text
sum_(a>G,g>G,a+g<=D,a!=g)
 #{r : N_a(r)=0 and N_g(r+a)=0}
 << N.                                                (9.2)
```

Equation (9.2) is essentially the full wall.

The addition law does not reduce (9.2) to (9.1). For a general triple with gaps `(a,g)`, transitivity gives a return of gap `a+g`, but the renewal identity again vanishes tautologically after the two defining factors are set to zero. No equality `a=g` is created.

# 10. Final answers

## 10.1 Characterization of mesoscopic extremizers

No, mesoscopic `Q_D` mass is not characterized by AP-like fibers or by a fiber with many returns.

The exact characterization is the multiplicity-tail identity

```text
Q_D = sum_(t>=2)(t-1)#{r:d_D(r)>=t}.
```

With `S_D<<N`, large `Q_D` can arise either from a heavy multiplicity tail or from `Theta(N)` constant-size three-point clusters. The latter may be completely AP-free and need not have meaningful small doubling.

## 10.2 Addition-law verdict

At a three-term AP,

```text
N_d(r)=N_d(r+d)=0
```

makes both terms in the addition law vanish. It proves `N_(2d)(r)=0`, which is exactly transitivity. It forces no further zero and no cascade. Degree bounds give only `A_p(d)<=3(d-1)` and total AP count `O(D^2)`.

## 10.3 Minimal AP-rarity lemma and what remains

The strongest useful diagonal lemma is (9.1), but it is not sufficient for `Q_D<<N`.

The minimal sufficient arithmetic statement is the all-shape balanced shifted-root estimate (7.5):

```text
sum_(a>G,g>G,a+g<=D)
 #{r:N_a(r)=0,N_g(r+a)=0}
 << N.
```

What remains is precisely off-diagonal family compatibility for the shifted gap-polynomial family. This is the same mesoscopic wall already visible in the shifted-gcd, shifted-valuation, carrier-clock, and GPRV coordinates.

## Least-confident point

The only place where a future structural theorem could alter the negative verdict is an Apery-specific mechanism converting many off-diagonal triples into many diagonal triples. No such mechanism is present in the banked renewal/addition identities, and the identities as currently proved are tautological on the triple locus. The conclusion is therefore firm relative to the present repository state.
