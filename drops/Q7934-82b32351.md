# Fixed-frequency HM3 output-prime correlation audit

## 1. Exact normalization

Write the ordered triple sum exactly as in the HM3 reduction. For distinct primes p,q,l in (X,2X],

```
S_h = sum_{p,q,l distinct} K_{pql}(h)/(p q l)
      R_p(h (q l)^(-1)) R_q(h (p l)^(-1)) R_l(h (p q)^(-1)).
```

The inverse symbols are in the corresponding prime fields. No replacement by independent coefficients is allowed: the three R-factors share the Apéry zero sets and the inverses are modulus-dependent.

For ordered triples the conversion to unordered triples has factor 6. Any argument changing convention must carry this factor through the kernel K.

## 2. CRT reindexing

Fix h. For fixed p, set

```
a = h (q l)^(-1) mod p.
```

The pair (q,l) is not a free residue pair modulo p. The map from prime pairs to a is a many-to-one map with arithmetic constraints. CRT gives a representation only after retaining the q,l sums:

```
(q,l) -> (a mod p, b mod q, c mod l)
```

with the compatibility relation imposed by the same integer h. Thus the expression is not a classical bilinear Kloosterman sum with independent lengths.

## 3. What the existing inputs prove

The repository inputs give:

* reflection: R_p is real and even;
* Parseval: sum_a |R_p(a)|^2 = p |Z_p|;
* |Z_p| <= p^(2/3+o(1));
* no adjacent zeros;
* finite CRT/codegree facts for zero sets.

These imply only energy bounds. A direct Cauchy estimate gives, schematically,

```
|S_h| <= (number of triples)^(1/2)
         (sum |R_p R_q R_l|^2/(p q l)^2)^(1/2),
```

which has no saving over the tuple scale. The missing input is cancellation between different prime triples at the same h.

## 4. Failure of generic bilinear technology

Deshouillers-Iwaniec, Bettin-Chandee, Duke-Friedlander-Iwaniec, and Kuznetsov-type estimates require coefficient sequences independent of the modulus (or at least controlled by a norm independent of the summation modulus). Here the coefficient attached to q,l is

```
R_p(h(q l)^(-1)),
```

and changes with p. The conductor is also the product pql. Therefore the standard hypotheses do not match this fixed-h tensor.

A spectral large sieve could only be applied after proving a new trace-function description of the Apéry transforms with uniform conductor. That is not present in hm3_result.tex.

## 5. Minimal sufficient Apéry hypothesis

A sufficient replacement statement is the fixed-h trilinear correlation bound:

```
sum_{p,q,l distinct}
 K_{pql}(h)/(pql)
 R_p(h(q l)^(-1))R_q(h(p l)^(-1))R_l(h(p q)^(-1))
 << X^{-1+o(1)} lambda_X^3.
```

uniformly for the observed low-frequency h range. This is exactly one power of X below the absolute tuple bound and is the missing HM3 cancellation statement.

A weaker bilinear form would also suffice: for each p,

```
sum_{q,l} B_{q,l}^{(p)} R_q(h(pl)^(-1))R_l(h(pq)^(-1))
```

must have square norm smaller than the Parseval bound by X^{1-o(1)}. Existing rowwise facts do not imply this.

## 6. Anchored-star obstruction

The anchored-star model has a common forced point m0. Its Fourier transform has a deterministic coherent component at every fixed h. Therefore it violates the above fixed-h decorrelation hypothesis: the shared anchor produces a rank-one contribution whose size is the same scale as the tuple diagonal.

Hence the proposed fixed-h Apéry hypothesis is genuinely stronger than rowwise reflection/no-adjacent-zero information.

## 7. Status

Theorem: the exact reindexing and the energy obstruction above.

Finite evidence: low-frequency HM3 tables show cancellation for actual Apéry rows.

Not proved: a fixed-h Apéry correlation estimate strong enough to give the missing X saving.

The HM3 bottleneck is therefore localized: it is not the h-average or Dirichlet kernel, but the modulus-dependent fixed-frequency prime-triple correlation.
