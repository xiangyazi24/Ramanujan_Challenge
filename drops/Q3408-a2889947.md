# 1. Exact discrete Green identity

Let `u` be any homogeneous solution of the Apéry recurrence

\[

\[
\mathscr W_u(n;y)
:=(n+1)^3(u_ny_{n+1}-u_{n+1}y_n).
\tag{1.1}
\]

Then

\[
\boxed{
\mathscr W_u(n;y)-\mathscr W_u(n-1;y)
=u_n(Ly)_n.
}
\tag{1.2}
\]

Indeed,

\[
\begin{aligned}
&\mathscr W_u(n;y)-\mathscr W_u(n-1;y)\\
={}&(n+1)^3u_ny_{n+1}-(n+1)^3u_{n+1}y_n\\
&-n^3u_{n-1}y_n+n^3u_ny_{n-1}\\
={}&u_n\bigl((n+1)^3y_{n+1}+n^3y_{n-1}\bigr)\\
&-y_n\bigl((n+1)^3u_{n+1}+n^3u_{n-1}\bigr).
\end{aligned}
\]

Since `Lu=0`,

\[
(n+1)^3u_{n+1}+n^3u_{n-1}=P(n)u_n,

\boxed{

=\sum_{n=r}^s u_n(Ly)_n.
}
\tag{1.3}
\]

This identity contains **no division**.

Applying it to `u=b` and `u=c` gives the two Green rows used below.
