# Verdict

The proposed prime-saturation step is **correct as stated**, including the strict lower inequality

\[
n-M<p\le n,
\qquad M=\lfloor n/2\rfloor.
\]

For every prime in that interval,

\[
\lambda_j=L_j(n)\equiv \delta_{j,n-p}\pmod p
\qquad(0\le j<M),
\]

so every pair minor

\[
C_{ij}:=\lambda_i\lambda_j(b_j-b_i),\qquad 0\le i<j<M,
\]

is divisible by \(p\). Hence

\[
\prod_{n-M<p\le n}p\mid R,
\qquad
R:=\gcd_{i<j} C_{ij},
\]

and therefore

\[
\boxed{\log R\ge \vartheta(n)-\vartheta(n-M)
       =\left(\frac12+o(1)\right)n.}
\]

The parity-sharp statement is slightly stronger:

- if \(n=2M\), then **every prime \(M\le p\le n\)** divides \(R\); equality at the lower endpoint \(p=M=n-M\) also saturates;
- if \(n=2M+1\), then for every prime \(M\le p\le n\),
  \[
  p\mid R\quad\Longleftrightarrow\quad p\ne M+1.
  \]
  Thus the odd boundary
  \[
  p=M+1=\frac{n+1}{2}=n-M
  \]
  is, whenever prime, **always absent from \(R\)**.  The one-step-lower prime \(p=M=(n-1)/2\), when prime, saturates again.

So the strict inequality \(n-M<p\) is necessary for one uniform parity-independent interval: replacing it by \(p\ge n-M\) fails for every odd \(n=2p-1\) with \(p\ge3\) prime.

# 1. Exact cardinal weights

Let

\[
\ell_j(x)=\prod_{\substack{0\le k<M\\k\ne j}}
\frac{x-k}{j-k}
\qquad(0\le j<M)
\]

be the cardinal Lagrange polynomial for the nodes \(0,1,\ldots,M-1\), and put

\[
\lambda_j=\ell_j(n).
\]

Since

\[
\prod_{\substack{0\le k<M\\k\ne j}}(j-k)
=j!\,(-1)^{M-1-j}(M-1-j)!,
\]

we obtain

\[
\begin{aligned}
\lambda_j
&=(-1)^{M-1-j}
\frac{n!/(n-M)!}{(n-j)j!(M-1-j)!}\\
&=\boxed{(-1)^{M-1-j}
\binom nj\binom{n-j-1}{M-1-j}}.
\end{aligned}
\tag{1}
\]

Thus every \(\lambda_j\) is an integer.  Also \(n>M-1\), so none of the integer weights is zero.

For \(n\ge4\), \(M\ge2\), and the pair \((0,1)\) exists.  Since

\[
b_1-b_0=5-1=4\ne0,
\]

at least one pair minor is nonzero, so \(R\) is a positive integer when the gcd is taken in absolute value.

# 2. The cardinal delta lemma modulo a prime

## Lemma

Let \(p\) be prime with \(p\ge M\).  Then the nodes

\[
0,1,\ldots,M-1
\]

are distinct in \(\mathbf F_p\).  If

\[
r:=n\bmod p
\]

lies in \(\{0,\ldots,M-1\}\), then

\[
\boxed{\lambda_j\equiv\delta_{j,r}\pmod p}
\qquad(0\le j<M).
\tag{2}
\]

### Proof

For every \(j\), each denominator \(j-k\) occurring in \(\ell_j\) has

\[
0<|j-k|\le M-1<p,
\]

so it is invertible modulo \(p\).  Therefore the rational formula defining \(\ell_j\) may be reduced in \(\mathbf F_p\).  Since \(n\equiv r\pmod p\),

\[
\lambda_j=\ell_j(n)\equiv\ell_j(r)\pmod p.
\]

But \(r\) is one of the interpolation nodes, so the defining cardinal property gives

\[
\ell_j(r)=\delta_{j,r}.
\]

This proves (2). \(\square\)

# 3. Delta weights force every pair minor to vanish

Assume the hypotheses of the lemma.  For any pair \(i<j\), at most one of \(i,j\) can equal \(r\).

- If neither equals \(r\), then \(p\mid\lambda_i\) and \(p\mid\lambda_j\), so in fact \(p^2\mid C_{ij}\).
- If \(i=r\), then \(\lambda_i\equiv1\) but \(p\mid\lambda_j\), hence \(p\mid C_{ij}\).
- If \(j=r\), symmetrically \(p\mid\lambda_i\), hence \(p\mid C_{ij}\).

Thus

\[
\boxed{p\mid C_{ij}\quad\text{for every }i<j,}
\tag{3}
\]

with no use whatsoever of the values of the sequence \(b_j\).  Hence

\[
p\mid R.
\tag{4}
\]

The saturation is a property of the cardinal weights alone.

# 4. The proposed interval \(n-M<p\le n\)

Let

\[
n-M=\lceil n/2\rceil.
\]

Suppose

\[
n-M<p\le n.
\tag{5}
\]

Then \(p>n/2\), so \(n<2p\), and therefore

\[
n\bmod p=n-p.
\]

Moreover

\[
0\le n-p<M
\]

because \(p\le n\) and \(p>n-M\).  Also \(p>M\) in both parities under (5), so the delta lemma applies with

\[
r=n-p.
\]

Consequently

\[
\boxed{\lambda_j\equiv\delta_{j,n-p}\pmod p}
\]

and (3)--(4) give

\[
p\mid R.
\]

Since the primes in (5) are distinct, their squarefree product divides every pair minor and hence divides their gcd:

\[
\boxed{\prod_{n-M<p\le n}p\mid R.}
\tag{6}
\]

This proves the candidate saturation claim exactly.

# 5. Parity-sharp endpoint classification

The uniform interval is not the largest possible one.  At \(p=M\), the node set has exactly \(p\) elements and is all of \(\mathbf F_p\), so the delta lemma still applies.  The behavior at \(p=n-M\) depends on parity.

## 5.1 Even \(n=2M\)

Let \(p\) be prime with

\[
M\le p\le2M.
\]

If \(p=M\), then

\[
n=2p\equiv0\pmod p,
\]

and \(0\) is a node.  Hence

\[
\lambda_j\equiv\delta_{j,0}\pmod p,
\]

so \(p\mid R\).

If \(p>M\), then \(n<2p\) and

\[
r=n-p=2M-p,
\]

with

\[
0\le r\le M-1.
\]

Again the delta lemma gives \(p\mid R\).

Therefore

\[
\boxed{n=2M:\quad
p\mid R\text{ for every prime }M\le p\le2M.}
\tag{7}
\]

So in the even case the lower inequality can be weakened from \(p>M=n-M\) to \(p\ge M\).

## 5.2 Odd \(n=2M+1\): the lower prime \(p=M\)

If \(p=M\) is prime, then the nodes are

\[
0,1,\ldots,p-1=\mathbf F_p,
\]

and

\[
n=2p+1\equiv1\pmod p.
\]

Hence

\[
\lambda_j\equiv\delta_{j,1}\pmod p,
\]

so

\[
\boxed{p=M\implies p\mid R.}
\tag{8}
\]

This includes the small case \(n=5,M=p=2\).

## 5.3 Odd \(n=2M+1\): primes above the exceptional boundary

If

\[
p>M+1,
\]

then

\[
r=n-p=2M+1-p\le M-1,
\]

and again \(0\le r<M\).  Thus

\[
\lambda_j\equiv\delta_{j,r}\pmod p
\]

and

\[
p\mid R.
\tag{9}
\]

Only \(p=M+1\) remains.

# 6. Odd boundary \(p=M+1\): all weights are \(-1\), not a delta

Assume now

\[
n=2M+1,
\qquad
p=M+1
\]

and \(p\) is prime.  Because \(n\ge4\) and \(n\) is odd, actually \(n\ge5\), so \(M\ge2\) and

\[
p\ge3.
\]

Here

\[
n=2p-1\equiv-1\pmod p,
\]

while the interpolation nodes are

\[
0,1,\ldots,M-1=0,1,\ldots,p-2.
\]

Thus the residue \(-1=p-1\) is **exactly the one missing element of** \(\mathbf F_p\).

Let

\[
\Phi(x)=\prod_{k=0}^{p-2}(x-k)\in\mathbf F_p[x].
\]

Since

\[
x^p-x=\prod_{a\in\mathbf F_p}(x-a)
=(x+1)\Phi(x),
\tag{10}
\]

differentiate in characteristic \(p\).  Because

\[
(x^p-x)'=-1,
\]

evaluating (10)' at \(x=-1\) gives

\[
\Phi(-1)=-1.
\tag{11}
\]

At a node \(j\in\{0,\ldots,p-2\}\), differentiating (10) and evaluating at \(x=j\) gives

\[
-1=(j+1)\Phi'(j),
\]

so

\[
\Phi'(j)=-\frac1{j+1}.
\tag{12}
\]

The cardinal polynomial can be written as

\[
\ell_j(x)=\frac{\Phi(x)}{(x-j)\Phi'(j)}.
\]

Using (11)--(12),

\[
\begin{aligned}
\lambda_j
&\equiv\ell_j(-1)\\
&=\frac{-1}{(-1-j)(-1/(j+1))}\\
&=-1\pmod p.
\end{aligned}
\]

Therefore

\[
\boxed{\lambda_0\equiv\lambda_1\equiv\cdots\equiv\lambda_{M-1}\equiv-1\pmod p.}
\tag{13}
\]

This is the exact replacement for the false delta assertion at the odd boundary.

Now use only the supplied initial Apéry values

\[
b_0=1,\qquad b_1=5.
\]

The single pair minor \((i,j)=(0,1)\) satisfies

\[
\begin{aligned}
C_{01}
&=\lambda_0\lambda_1(b_1-b_0)\\
&\equiv(-1)(-1)(5-1)\\
&=4\pmod p.
\end{aligned}
\tag{14}
\]

Since \(p\ge3\) is prime,

\[
p\nmid4.
\]

Hence

\[
p\nmid C_{01},
\]

so it cannot divide the gcd of all pair minors:

\[
\boxed{n=2M+1,\ p=M+1\text{ prime}
\quad\Longrightarrow\quad p\nmid R.}
\tag{15}
\]

Thus the excluded odd boundary is **always absent**, not merely absent in finite computation.

Combining (8), (9), and (15) gives the exact high-prime classification

\[
\boxed{
 n=2M+1,\ p\ge M,\ p\le n,\ p\text{ prime}:
 \quad p\mid R\iff p\ne M+1.
}
\tag{16}
\]

No claim is made here about primes \(p<M\); such primes can occur in \(R\) for unrelated arithmetic reasons.

# 7. Small endpoints \(p=2,3\)

The small cases are fully consistent with the proof and are worth isolating because \(p=2\) is the only prime dividing the boundary witness \(4\).

## \(n=4\), \(M=2\)

The cardinal polynomials are

\[
\ell_0(x)=1-x,\qquad \ell_1(x)=x,
\]

so

\[
(\lambda_0,\lambda_1)=(-3,4).
\]

There is only one pair minor:

\[
R=|(-3)(4)(5-1)|=48.
\]

Thus both \(2\) and \(3\) divide \(R\).

Here \(p=2=M=n-M\) is the even lower endpoint, and

\[
(\lambda_0,\lambda_1)\equiv(1,0)=\delta_{j,0}\pmod2.
\]

The prime \(p=3\) lies in the strict interval \(2<p\le4\), with

\[
(\lambda_0,\lambda_1)\equiv(0,1)=\delta_{j,1}\pmod3.
\]

## \(n=5\), \(M=2\)

Now

\[
(\lambda_0,\lambda_1)=(-4,5),
\]

so

\[
R=|(-4)(5)(4)|=80.
\]

The lower prime \(p=M=2\) saturates:

\[
(\lambda_0,\lambda_1)\equiv(0,1)=\delta_{j,1}\pmod2,
\]

and indeed \(2\mid R\).

But the odd boundary is

\[
p=M+1=3,
\]

and

\[
(\lambda_0,\lambda_1)\equiv(-1,-1)\pmod3.
\]

The pair minor is \(-80\not\equiv0\pmod3\), so

\[
3\nmid R.
\]

This is the first exceptional-boundary instance.

## Further \(p=3\) lower-endpoint checks

For \(n=6,M=3,p=M=3\),

\[
(\lambda_0,\lambda_1,\lambda_2)=(10,-24,15)
\equiv(1,0,0)\pmod3,
\]

so \(3\mid R\), exactly as the even endpoint theorem predicts.

For \(n=7,M=3,p=M=3\), one has

\[
n\equiv1\pmod3,
\]

and the node set is all of \(\mathbf F_3\), so

\[
\lambda_j\equiv\delta_{j,1}\pmod3,

Finally, the putative odd exceptional boundary \(p=M+1=2\) would force \(M=1,n=3\), which lies outside the assumed range \(n\ge4\); moreover there would be no pair \(i<j\) at all.  Thus within the problem's range every prime odd boundary has \(p\ge3\), and the witness (14) is always nonzero.

# 8. Exact logarithmic lower bound

Let

\[
\vartheta(x)=\sum_{p\le x}\log p.
\]

From (6),

\[
\log R
\ge
\sum_{n-M<p\le n}\log p
=artheta(n)-\vartheta(n-M).
\tag{17}
\]

Since

\[
n-M=\lceil n/2\rceil\sim n/2,
\]

the prime number theorem in the equivalent Chebyshev form

\[
\vartheta(x)=x+o(x)
\]

gives

\[
\begin{aligned}
\vartheta(n)-\vartheta(n-M)
&=n-(n-M)+o(n)\\
&=M+o(n)\\
&=\left(\frac12+o(1)\right)n.
\end{aligned}
\tag{18}
\]

Therefore

\[
\boxed{\log R\ge\left(\frac12+o(1)\right)n.}
\tag{19}
\]

The parity refinements add at most one extra prime near \(n/2\), so they change the lower bound by only \(O(\log n)\) and do not alter the \(n/2\) main term.

More explicitly:

- for \(n=2M\), one may strengthen (17) by adding \(\log M\) when \(M\) itself is prime;
- for \(n=2M+1\), one may add \(\log M\) when \(M\) is prime, while \(M+1\), if prime, is provably absent.

# 9. Why the lower inequality must be strict in the uniform statement

The candidate uses

\[
n-M<p\le n.
\]

This is the correct parity-uniform form.

For even \(n\), equality \(p=n-M=M\) is harmless and actually saturates.  For odd \(n\), however, equality is precisely

\[
p=n-M=M+1.
\]

Whenever that integer is prime, (15) proves

\[
p\nmid R.
\]

This is not a sporadic edge case.  For every prime \(p\ge3\), choosing

\[
n=2p-1,
\qquad
M=p-1
\]

puts \(p\) exactly at the excluded odd boundary, and then \(p\nmid R\).  Thus no theorem with a uniform lower condition \(p\ge n-M\) can be true.

# 10. Independent exact verifier design

The following verifier is deliberately independent of the repository's cardinal recurrence and Apéry recurrence:

1. it computes each \(\lambda_j\) directly from the defining rational Lagrange product using `fractions.Fraction` and separately checks the closed integer formula (1);
2. it computes \(b_j\) independently from the Apéry binomial sum
   \[
   b_j=\sum_{k=0}^j\binom jk^2\binom{j+k}{k}^2;
   \]
3. it forms every pair minor and their exact integer gcd;
4. for every prime \(p\ge M\) it checks the parity-sharp classification (7), (16), including the weight vector itself modulo \(p\);
5. it separately asserts the small endpoint values \(R_4=48\), \(R_5=80\), the exceptional \(n=5,p=3\) failure, and the \(p=3\) equality cases.

No floating point, symbolic algebra, or recurrence assumptions are used.

```python
#!/usr/bin/env python3
from fractions import Fraction
from functools import reduce
from math import comb, gcd, isqrt, prod


def is_prime(p: int) -> bool:
    if p < 2:
        return False
    if p == 2:
        return True
    if p % 2 == 0:
        return False
    for d in range(3, isqrt(p) + 1, 2):
        if p % d == 0:
            return False
    return True


def cardinal_direct(n: int, M: int, j: int) -> int:
    """Definition: product_{k != j} (n-k)/(j-k)."""
    value = Fraction(1, 1)
    for k in range(M):
        if k != j:
            value *= Fraction(n - k, j - k)
    assert value.denominator == 1
    return value.numerator


def cardinal_closed(n: int, M: int, j: int) -> int:
    return ((-1) ** (M - 1 - j)
            * comb(n, j)
            * comb(n - j - 1, M - 1 - j))


def apery_b(j: int) -> int:
    """Independent closed binomial sum."""
    return sum(
        comb(j, k) ** 2 * comb(j + k, k) ** 2
        for k in range(j + 1)
    )


def data(n: int):
    M = n // 2
    assert M >= 2

    lam = [cardinal_direct(n, M, j) for j in range(M)]
    for j in range(M):
        assert lam[j] == cardinal_closed(n, M, j)

    b = [apery_b(j) for j in range(M)]
    minors = [
        lam[i] * lam[j] * (b[j] - b[i])
        for i in range(M)
        for j in range(i + 1, M)
    ]
    R = reduce(gcd, map(abs, minors), 0)
    assert R > 0
    return M, lam, b, minors, R


def audit(n: int) -> None:
    M, lam, b, minors, R = data(n)
    primes = [p for p in range(2, n + 1) if is_prime(p)]

    # Original uniform candidate.
    top = [p for p in primes if n - M < p <= n]
    top_product = prod(top)
    assert R % top_product == 0

    # Parity-sharp classification for every p >= M.
    for p in primes:
        if p < M:
            continue

        exceptional = (n % 2 == 1 and p == M + 1)

        if exceptional:
            # n = 2p-1, nodes are 0,...,p-2, evaluation is at -1.
            assert p >= 3
            assert all(x % p == (-1) % p for x in lam)

            witness = lam[0] * lam[1] * (b[1] - b[0])
            assert b[1] - b[0] == 4
            assert witness % p == 4 % p
            assert 4 % p != 0
            assert R % p != 0
            continue

        # Every other prime p >= M has n mod p inside the node set.
        r = n % p
        assert 0 <= r < M
        residues = [x % p for x in lam]
        delta = [1 if j == r else 0 for j in range(M)]
        assert residues == delta
        assert all(c % p == 0 for c in minors)
        assert R % p == 0


def main(limit: int = 80) -> None:
    for n in range(4, limit + 1):
        audit(n)

    # Explicit small endpoints.
    M4, L4, b4, C4, R4 = data(4)
    assert M4 == 2 and L4 == [-3, 4] and R4 == 48
    assert R4 % 2 == 0 and R4 % 3 == 0

    M5, L5, b5, C5, R5 = data(5)
    assert M5 == 2 and L5 == [-4, 5] and R5 == 80
    assert R5 % 2 == 0
    assert R5 % 3 != 0  # odd boundary p=M+1=3
    assert R5 % 5 == 0

    _, L6, _, _, R6 = data(6)
    assert [x % 3 for x in L6] == [1, 0, 0]
    assert R6 % 3 == 0  # even equality p=M=3

    _, L7, _, _, R7 = data(7)
    assert [x % 3 for x in L7] == [0, 1, 0]
    assert R7 % 3 == 0  # odd lower prime p=M=3

    print(f"verified exactly for every 4 <= n <= {limit}")


if __name__ == "__main__":
    main()
```

# 11. Final audit conclusion

The prime-saturation argument is sound and in fact gives an unconditional linear lower bound on the pair-minor gcd:

\[
\log R\ge\left(\frac12+o(1)\right)n.
\]

The exact endpoint picture is:

\[
\boxed{
\begin{array}{ll}
n=2M:& \text{all primes }M\le p\le n\text{ divide }R;\\[2mm]
n=2M+1:& \text{all primes }M\le p\le n\text{ divide }R\\
& \text{except }p=M+1,\text{ which, if prime, never divides }R.
\end{array}}
\]

For the candidate's parity-uniform interval, therefore, the lower inequality must remain **strict**:

\[
\boxed{n-M<p\le n.}
\]

The odd boundary is not merely “harmless” in the sense of being ignorable: it has the exact opposite behavior from saturation.  Its cardinal vector is the constant vector \((-1,\ldots,-1)\bmod p\), and the initial difference \(b_1-b_0=4\) forces \(v_p(R)=0\) for every such prime \(p\ge3\).
