# Q6691: qPD-SHARP extremal audit

## 1. Forced lower bounds on P_D

Let P_D denote the number of distinct collision bases forced by all gaps d <= D. The mirror family already gives, for every even d,

```
r = (p-1-d)/2
```

and these bases are distinct as d varies. Therefore

```
P_D >= floor(D/2) - O(1).
```

The h=2 quadratic layer contributes only when (-51/p)=1. The contribution is a positive-density subset of primes, but it does not create more than O(D) forced bases in a D-gap window because each gap contributes at most its Bezout degree many bases. Apparition arithmetic progressions from the recurrence similarly have bounded multiplicity per gap and hence contribute O(D).

Conclusion:

```
P_D >= D/2 - O(1),
P_D(forced families) = O(D).
```

Thus the currently visible arithmetic forcing is linear in D, not N.

## 2. Extremal problem under the banked abstract constraints

We maximize P_D subject to:

```
C_d <= 3(d-1),
reflection closure,
cascade closure,
capacity of P^1(F_p),
Q_p(D) <= 22*3*D^2*log D.
```

A collision base counted by P_D must be supported by at least one pair with gap <= D. Hence

```
P_D <= Q_p(D).
```

The available Q bound is quadratic:

```
P_D <= O(D^2 log D).
```

The sigma-ladder does not apply directly because it needs a bound on pair multiplicity after removing forced collisions, not only the number of bases.

The remaining constraints do not force a stronger bound. In particular, the degree constraints allow concentration:

```
C_d = 3(d-1)
```

for many d without contradicting reflection or adjacent coprimality. A compatible extremal configuration can assign essentially disjoint roots of N_d across the gap polynomials until the quadratic capacity bound is reached.

Therefore the abstract feasible region permits

```
P_D = Theta(min(N, D^2 log D)).
```

For the hatch scale

```
D = sqrt(N)*L,
```

this becomes

```
P_D = Theta(N*L^2*log D)
```

up to the ambient N cap. Therefore the constraint set alone does NOT imply

```
P_D << N/(L^2 log D).
```

That target requires an additional arithmetic input.

## 3. Exact missing lemma

The missing statement is not a better degree bound. It is a family anti-concentration statement:

```
For D = sqrt(N)*L,
number of distinct bases r with some collision gap h<=D
is O(N/(L^2 log D)).
```

Equivalently, one needs a bound on the union

```
Union_{1<=h<=D} {r : N_h(r)=0}
```

rather than individual bounds on each C_h.

A sufficient new theorem would be a family averaged version of (COINC):

```
N_coinc(H) <= (#S_H)^2/p + O(#S_H)
```

uniformly at the hatch scale.

This would imply

```
sum_{h<=H} C_h << H + sqrt(pH),
```

and at H=p^(2/3) gives

```
sum C_h << p^(5/6),
```

which yields the new energy exponent

```
F_p << p^(4/3+eps).
```

## 4. Final verdict

The extremal LP is not closed by the banked constraints.

The answer is:

```
max P_D under the abstract Apery-compatible constraints is Theta(N)
(at the hatch scale, after the ambient capacity cap).
```

Hence the proposed qPD-SHARP inequality is genuinely arithmetic, not a formal consequence of:

```
reflection,
Bezout degree,
cascade closure,
capacity,
Q bounds.
```

The precise missing ingredient is a family-averaged cancellation/anti-concentration theorem for the difference curves

```
Delta_{r,h}=Delta_{r',h'}.
```

Per-curve Weil estimates cannot supply it; the required input is cancellation of the aggregate Weil errors over the growing family of curves.
