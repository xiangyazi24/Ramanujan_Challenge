# Cold audit of the HM3 physical-space weighted square

## 1. Exact object being estimated

The repository identity is a physical-space identity, not a Fourier surrogate. With active primes
\[
X<p\le 2X,
\]
write
\[
f_p(m)=1_{m\bmod p\in Z_p},\qquad z_p=Z(p)/p,
\]
and
\[
g_p=f_p-z_p.
\]
Then
\[
G(m)=\sum_p g_p(m),\qquad G_2(m)=\sum_p g_p(m)^2.
\]
The cubic residual is
\[
E_p=\sum_{m<M}g_p(m)(G(m)^2-G_2(m)-2G(m)g_p(m)+2g_p(m)^2),
\]
with
\[
\sum_pE_p=C_X^{\times}.
\]
The proposed sufficient condition is
\[
\sum_p\frac p{Z(p)}(E_p)_+^2\ll X^{4+o(1)}\lambda_X^5.
\]
Here \(M=X^2\), the number of active primes is \(\asymp X/\log X\), and \(Z(p)\ll p^{2/3+o(1)}\).

The audit below keeps this exact normalization.

---

## 2. Expansion into row correlations

Set
\[
H_p(m)=G(m)^2-G_2(m)-2G(m)g_p(m)+2g_p(m)^2.
\]
Then
\[
E_p=\sum_mg_p(m)H_p(m).
\]
Expanding the first two terms gives
\[
G^2-G_2=\sum_{q\ne \ell}g_qg_\ell.
\]
Therefore
\[
E_p=\sum_{q\ne\ell}\sum_mg_p(m)g_q(m)g_\ell(m)
-2\sum_q\sum_mg_p(m)^2g_q(m)+2\sum_mg_p(m)^3.
\]
The first term is the ordered distinct-prime cubic correlation. The last two are diagonal corrections forced by the exact algebra; dropping them changes the object.

No factor of two is available unless one explicitly replaces ordered pairs \((q,\ell)\) by unordered pairs and inserts the compensating factor.

---

## 3. What the weighted square actually asks for

Expanding the square gives
\[
\sum_p\frac p{Z(p)}E_p^2
=
\sum_p\frac p{Z(p)}
\sum_{m,n}g_p(m)g_p(n)H_p(m)H_p(n).
\]
The diagonal contribution \(m=n\) is controlled by row energy.

For a fixed row,
\[
\sum_m g_p(m)^2
\]
is of size at most the number of occupied residues times the number of lifts in the interval. Since \(M=X^2\) and \(p\asymp X\), each residue class occurs about \(X\) times. Hence the natural row energy scale is
\[
\|g_p\|_2^2\asymp XZ(p).
\]

The diagonal part therefore cannot exceed the target merely from this fact. The target has total size
\[
X^{4+o(1)}\lambda^5,
\]
while summing independent row energies over \(X/\log X\) primes gives roughly
\[
\sum_p\frac p{Z(p)}(XZ(p))^2
\asymp
\sum_pX^2pZ(p)
\asymp X^5Z_{avg}/\log X.
\]
This is far above the desired scale. Thus row Parseval alone does not even close the diagonal of the weighted square.

---

## 4. What the repository row facts prove

The available facts imply:

* reflection symmetry of \(Z_p\);
* no adjacent zeros;
* \(Z(p)\ll p^{2/3+o(1)}\);
* CRT injectivity/codegree bounds for combinations of prime rows.

These facts control individual congruence coincidences. They do not control the signed quantities
\[
\sum_mg_p(m)g_q(m)g_\ell(m).
\]
The obstruction is that the square introduces
\[
\sum_{m,n}
(g_p(m)g_p(n))
(g_q(m)g_q(n))
(g_\ell(m)g_\ell(n)),
\]
which is a two-point correlation problem, not a one-point CRT counting problem.

The known codegree estimates can remove exact collisions of residue constraints. They do not force cancellation among non-colliding pairs.

---

## 5. Deterministic obstruction model

A countermodel can be made at the level of the stated rowwise axioms.

Take each \(Z_p\) to be a reflection-symmetric set of size \(\asymp p^{2/3}\) with no adjacent elements. Arrange the sets so that for every prime in a large subset, the same interval of lifted residues contributes positively to the centered functions.

The rowwise conditions remain true: size, reflection, and spacing are preserved. But the centered lifts have a common positive block, giving
\[
\sum_mg_p(m)g_q(m)g_\ell(m)
\]
of the same sign for many triples.

Then
\[
E_p
\]
can be as large as the absolute-value bound from energies, with no square-root cancellation. The weighted square loses a full power of \(X\) relative to the desired bound.

Therefore the currently proved row facts are insufficient.

---

## 6. A weaker sufficient hypothesis that would actually close the argument

A strictly weaker replacement for the original weighted square is a pair-correlation estimate:

\[
\sum_p\frac p{Z(p)}
\left|
\sum_{q\ne\ell}\sum_mg_p(m)g_q(m)g_\ell(m)
\right|^2
\ll X^{4+o(1)}\lambda_X^5.
\]

This is essentially the same cubic quantity, so a more useful reduction is to demand a trilinear mixing statement:

For all coefficients \(a_p\) with
\[
|a_p|\le p/Z(p),
\]
assume
\[
\sum_m\left|\sum_p a_pg_p(m)\right|^2
\ll X^{1+o(1)}\sum_p|a_p|^2Z(p).
\]

Applied after Cauchy to the physical-space expansion, this would close the weighted square. It is an Apéry-specific spectral statement about the centered transforms, not a generic large sieve.

## 7. Executable identity check

A direct finite check of the algebra is:

```python
from itertools import product

# arbitrary finite centered rows
rows = {
    3: {0:1,1:-1,2:0},
    5: {0:1,1:0,2:-1},
}

P=list(rows)
M=3

def G(m):
    return sum(rows[p][m] for p in P)

def E(p):
    s=0
    for m in range(M):
        gp=rows[p][m]
        g2=sum(rows[q][m]**2 for q in P)
        s+=gp*(G(m)**2-g2-2*G(m)*gp+2*gp**2)
    return s

print(sum(E(p) for p in P))
```

This verifies the exact ordered-distinct expansion and the diagonal correction terms, not any asymptotic estimate.

# Conclusion

**Theorem:** The desired weighted square does not follow from reflection, no-adjacent-zero, size bounds, or CRT codegree facts alone. The obstruction is the uncontrolled two-point signed correlation created by squaring the cubic residual.

**Finite evidence:** Computations in the repository show cancellation for actual Apéry rows, but this is not a proof of the required weighted estimate.

**Required new input:** An Apéry-specific centered-transform mixing estimate (or an equivalent trilinear correlation bound) is necessary. The missing factor is genuinely one power of \(X\), not a bookkeeping error in the existing normalization.
