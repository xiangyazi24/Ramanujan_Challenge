# 3. Tagged multilinear pre-extraction class

Let

```text
L = Z[u_1^+/-1, ..., u_d^+/-1]
```

be any Laurent polynomial module, and let

```text
eps(F) = CT(F).
```

The key direct splitting is

```text
L = Z*1  direct_sum  ker(eps).
```

A colored slot may first be sent into a common internal torus by any monomial substitution

```text
phi_i : L -> L_big.
```

A bounded tagged multilinear pre-extraction contraction is any expression obtained from the slot inputs F_i by finitely many applications of:

```text
- Z-linear monomial substitutions phi_i;
- multiplication of slot images, with each colored slot used once;
- constant-term or fixed coefficient extraction in shared internal variables;
- multiplication of contractions on disjoint subsets of slots;
- finite Z-linear combinations;
- coefficient extraction in independent source tags;
- partition-Mobius combinations, including joint connected cumulants.
```

After a coefficient c_j with |c_j|=2 is split into two colored copies, every canonical B8 certificate has at most 16 slots.  The marked coefficients are +/-1, so the two marked labels each occupy one slot.

Every expression in this class is Z-multilinear in each colored slot input.  Source tags may be kept in the target coefficient ring throughout.

The analogous transfer-tensor class replaces L by any finite free Z-module V (a row, state vector, or matrix module) and allows arbitrary fixed multilinear tensor contractions.

The important qualifier is the valuation proof.

Definition: a contraction T is PIN-ROBUST at slot a if its marked vanishing uses only the local pin, in the exact universal sense

```text
T(F_1,...,G,...,F_s) = 0
for every G with eps(G)=0,
with all other slot inputs arbitrary.
```

For transfer states, replace eps by the primitive marked linear functional.

This is the pre-extraction analogue of Q2057's formal pin condition, but it is imposed before any constant term or endpoint row has been extracted.

# 4. Pre-extraction pin-factor theorem

## Theorem 4.1: one marked slot

Let R be any torsion-free coefficient ring carrying the source tags and index parameters.  Let

```text
T : L^s -> R
```

be Z-multilinear.  If T is pin-robust at slot a, then there is a unique multilinear T_a on the other slots such that

```text
T(F_1,...,F_s)
 = eps(F_a) * T_a(F_1,...,F_(a-1),F_(a+1),...,F_s).
```

Proof.  Write

```text
F_a = eps(F_a)*1 + F_a^0,
eps(F_a^0)=0.
```

Multilinearity gives

```text
T(...,F_a,...)
 = eps(F_a)*T(...,1,...)
   + T(...,F_a^0,...).
```

The last term is zero by pin robustness.  This is the claimed factorization.  No endpoint extraction was used.  QED.

## Theorem 4.2: two marked slots

If T is pin-robust at two distinct marked slots p and q, then

```text
T(F_1,...,F_s)
 = eps(F_p) * eps(F_q) * T_pq(other slots).
```

This follows by applying Theorem 4.1 twice.

All source/color tags survive in T_pq because the proof is coefficientwise in the tag ring.

## Corollary 4.3: actual Apéry slots

Put

```text
F_i = Lambda^(r_i).
```

Then

```text
eps(F_i) = b_(r_i).
```

Therefore every nonzero integral pin-robust connected pre-extraction carrier satisfying both marked divisibilities has the exact characteristic-zero factorization

```text
J(W) = b_(r_p) * b_(r_q) * H(W).
```

After endpoint saturation there is no formally forced marked divisor left.

This proves that the desired gate-2 behavior is impossible throughout this class: connected internal contractions and source tags do not change the pin ideal when the valuation proof still uses only the two zero modes.

# 5. Why connectedness alone cannot replace pin robustness

A connected shared-variable contraction can avoid the factorization theorem only by reading nonconstant Laurent modes.  But those modes are not constrained by

```text
CT Lambda^r = 0 mod p.
```

There is a universal two-slot countermodel.

Define the diagonal pairing

```text
Pair(F,G) = CT_u [ F(u) * G(u^(-1)) ].
```

Take

```text
F(u)=u,
G(u)=u.
```

Then

```text
CT(F)=0,
CT(G)=0,
Pair(F,G)=CT(1)=1.
```

So a shared-variable diagonal can be genuinely connected and nonzero even when both local endpoint pins vanish.  Independent source tags can be attached as `t_p*t_q` without changing the example.

This is the precise alternative to endpoint factorization:

```text
Either the contraction is pin-robust,
    and it factors through the endpoint constant term;

or it uses nonconstant internal modes,
    and the marked zero alone supplies no divisibility theorem.
```

The actual four-slot cumulant values 78 mod 179 and 91 mod 193 show that this is not merely an artificial Laurent-polynomial pathology.

# 6. Transfer-tensor version

The same proof does not depend on Laurent polynomials.

Let V be a finite free Z-module and let

```text
ell : V -> Z
```

be a primitive linear form, meaning some e in V satisfies ell(e)=1.  Then

```text
V = Z*e  direct_sum  ker(ell).
```

For any multilinear tensor contraction

```text
T : V^s -> R,
```

if T vanishes universally whenever the marked slot lies in ker(ell), then

```text
T(...,v_a,...)=ell(v_a)*T_a(...).
```

Two marked robust pins give the product of the two linear forms.

For the factorial-gauged Apéry row module one may take

```text
v = (alpha,beta),
ell(v) = alpha + 5*beta.
```

This form is primitive.  Thus a connected transfer tensor whose p- and q-divisibility is certified only by the two marked endpoint linear pins again factors those pins exactly.

This statement is pre-extraction: the contraction may be formed first and the row functional applied only at the end.

It does NOT cover a new identity that uses the fact that the actual transfer matrices at several related indices share overlapping recurrence segments in a special nonlinear way.  Such a true multi-index transfer syzygy is outside the theorem.

# 8. Height gate

For a nonzero integral pin-robust carrier,

```text
J(W) = b_(r_p) * b_(r_q) * H(W),
H(W) != 0 integer.
```

Hence

```text
|J(W)| >= b_(r_p) * b_(r_q).
```

Q2057 banks the interior bound

```text
r_p >= Delta_N,
r_q >= Delta_N,
Delta_N asymp N^(1/3)/sqrt(loglog N),
```

and the elementary Apéry lower bound

```text
b_r >= 16^r/(2*r+1)^2.
```

Therefore every nonzero pin-robust carrier satisfies

```text
log |J(W)|
 >= (r_p+r_q)*log(16) - O(log N)
 >= 2*Delta_N*log(16) - O(log N).
```

This is much larger than the marked divisor budget

```text
log(p*q) = O(log N).
```

If F_B8(N) ordered marked records survive and each canonical certificate is reused at most 128 times, then the number C_N of distinct certificates obeys

```text
C_N >= F_B8(N)/128.
```

Thus an endpoint-factored family has the intrinsic lower ledger

```text
sum_W log |J(W)|
 >= (F_B8(N)/128) * (2*Delta_N*log(16)-O(log N)).
```

At the forbidden pair-energy scale

```text
F_B8(N) ~ N^2/log^2 N,
```

this is of order

```text
N^2 * Delta_N / log^2 N,
```

which is larger than `N^2/log N` by the growing factor

```text
Delta_N/log N -> infinity.
```

So the required aggregate height estimate cannot be obtained from this endpoint-factored class without first proving a stronger counting estimate than the target itself.

For comparison, the canonical raw/cumulant connected constructions have only the crude per-certificate upper bound O(N): the sum of the Laurent coefficients of Lambda is


so every constant term of Lambda^R is at most 40^R, and a cumulant of at most 16 slots has only a fixed Bell-number count of partition terms.  An O(N) per-certificate bound is still far too large at the natural `N^2/log^2 N` certificate scale.

Thus none of the audited candidates passes gate 4 in a way that closes B8-HCC.

# 10. First construction outside the theorem

The theorem deliberately treats the colored slot Laurent polynomials as independent formal inputs.  Therefore the first possible escape must use an identity that is false for arbitrary Laurent-polynomial replacements and true specifically for powers of the Apéry Laurent polynomial Lambda.

A concrete next search class is a coefficient-sensitive logarithmic-derivative / creative-telescoping network.

Choose non-identical monomial embeddings phi_i of the fixed Lambda into one common torus and a bounded Laurent kernel H_W.  Consider expressions generated by

```text
Theta = u*d/du
```

and the exact power identity

```text
Theta( phi_i(Lambda)^(r_i) )
 = r_i * phi_i(Lambda)^(r_i)
       * Theta(log(phi_i(Lambda))).
```

A representative connected template is

```text
T_H(W)
 = CT_U [
     H_W(U)
     * sum_i c_i * Theta(phi_i(Lambda)^(r_i))
       * product_(j != i) phi_j(Lambda)^(r_j)
   ].
```

If every phi_i is the same and H_W is trivial, the B8 balance makes this collapse to the total-exponent tautology.  With genuinely different embeddings or a nontrivial connected kernel it need not vanish identically.

This class is outside Theorem 4.2 because its hoped-for proof would have to use the special differential/coefficient relations of `Lambda^r`, not merely the zero constant term of an arbitrary slot input.

What remains missing is exactly a theorem of the following type:

```text
A Lambda-specific coupled toric/transfer identity at additively related
indices converts the two marked zero-mode conditions into divisibility of
a connected primitive residue, while that residue remains nonzero after
removing all local endpoint factors.
```

No such identity is supplied by the current constant-term, transfer, WZ, or Green formulas, and I do not claim one here.

An equivalent next branch is a genuinely nonlinear overlapping-transfer-segment syzygy whose proof uses the actual common recurrence word rather than treating each colored transfer state as an independent module input.
