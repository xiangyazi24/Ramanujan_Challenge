# Fixed-quotient Kummer-order pruning: corrected formulas, the L1/L2 barrier, and the exact primitive star

## Executive verdict

Fix a quotient `q >= 1`. The strongest unconditional shell-energy pruning currently available is:

```text
low-low:   both selected orders <= D
           negligible up to D = N^(1/2-o(1)) for fixed q;

low-any:   at least one selected order <= D
           negligible only up to D = N^(1/3-o(1)) for fixed q;

large-q:   the whole q-sector is negligible for
           q >= N^(2/11+epsilon),
           uniformly while q <= N^(1/2-delta).
```

Combining the first two estimates removes every ordered pair except pairs for which

```text
both orders are > N^(1/3-o(1)),
and at least one order is > N^(1/2-o(1)).
```

The quotient-adaptive pointwise lemma in `Q32_SEPARATION_ANALYSIS.md` is correct:

```text
L_(n,q) = tau(n-q) * log(n) * F(n),

removed logarithmic weight
  << n/F(n) + n^(1/2+o(1)).
```

Applied **before** taking pair energy, it reduces the sufficient theorem to pairs of nearly primitive characters, both of order `N^(1-o(1))`. It does not prove that the discarded vertices have small shell pair energy. An exact calculation shows that making their mixed energy negligible would require `F(N) >> N^(2/3)`; this merely returns the old order cutoff `D < N^(1/3-o(1))`. Cauchy--Schwarz and interpolation do not improve that exponent.

The proposed critical abstract star does exist. For infinitely many centers with `n-q` prime, one can put every prime in the `q`-arc into a reflected two-point zero row with

```text
gcd(p-1,n-q) = 1,
ord(omega_p^(n-q)) = p-1,
```

while retaining reflection, no adjacent distinct zeros, one Casimir root, and the universal reflected-continuant factor. This is an abstract zero-set adversary, not an actual Apéry construction. It proves that the remaining theorem must use arithmetic of the distinguished Apéry solution, not merely these local axioms.

## 1. Exact definitions

Let

```text
P_q(n) = { p prime : n/(q+1) < p <= n/q,
                     B_(n-q p) = 0 mod p }.

K_q(n) = #P_q(n).

E_q(N) = sum_(N<n<=2N) (K_q(n))_2,

(x)_2 = x(x-1).
```

For `p in P_q(n)`, put

```text
r = n-q p,

g_(p,n) = gcd(p-1,n-q),

d_(p,n) = (p-1)/g_(p,n).
```

Since `p = 1 mod (p-1)`,

```text
r = n-q p = n-q mod (p-1),

therefore

d_(p,n)
  = ord(omega_p^r)
  = ord(omega_p^(n-q))
  = (p-1)/gcd(p-1,n-q).
```

For a cutoff `D`, define

```text
K_L(n;D) = #{ p in P_q(n) : d_(p,n) <= D },
K_H(n;D) = K_q(n)-K_L(n;D).

E_q^LL(N;D) = sum_(N<n<=2N) (K_L(n;D))_2.

E_q^L*(N;D)
  = sum_(N<n<=2N)
      [ (K_q(n))_2 - (K_H(n;D))_2 ].
```

Thus `E_q^LL` counts ordered low--low pairs, and `E_q^L*` counts ordered pairs having at least one low-order member.

Write throughout

```text
M_N = max_(m<=2N) tau(m) = N^o(1).
```

## 2. Exact divisor parametrization

Write

```text
p-1 = d g,
r   = j g,

gcd(d,j)=1,
0 <= j <= d.
```

Then

```text
n-q
  = q(p-1)+r
  = (q d+j)g.
```

Set

```text
h = q d+j.
```

The exact parametrization is

```text
h | (n-q),
q d <= h <= (q+1)d,

p = 1 + d(n-q)/h.
```

For fixed `q,D`, put

```text
H = (q+1)D,

a_(q,D)(h)
  = #{ d <= D : q d <= h <= (q+1)d,
                  gcd(d,h)=1 }.
```

Every low-order candidate prime gives a unique pair `(h,d)`, so, with `m=n-q`,

```text
K_L(n;D) <= A_(q,D)(m),

A_(q,D)(m) = sum_(h|m, h<=H) a_(q,D)(h).
```

The interval for `d` has length `h/[q(q+1)]`, hence

```text
a_(q,D)(h) <= h/[q(q+1)] + 1.
```

Taking the maximum over divisors recovers Proposition 3.1:

```text
K_L(n;D) <= tau(n-q) * (D/q + 2).
```

A useful refinement for the shell error is

```text
sum_(h<=H) a_(q,D)(h)
  <= sum_(d<=D) (d+1)
  << D^2.
```

This improves the crude `O(D^2+qD)` accumulation in the current separation note; it replaces its final square error by `O(D^4)`.

## 3. Low--low energy, derived line by line

Because `(K_L)_2 <= K_L^2`,

```text
E_q^LL(N;D)
  <= sum_(N<n<=2N) A_(q,D)(n-q)^2.
```

Expanding by divisors gives

```text
sum_m A(m)^2
  = sum_(h,k<=H) a(h)a(k)
      #{ m in (N-q,2N-q] : lcm(h,k) | m }.
```

The number of multiples is at most

```text
N/lcm(h,k) + 1.
```

Therefore

```text
E_q^LL(N;D)
  <= N * sum_(h,k<=H) a(h)a(k)/lcm(h,k)
     + (sum_(h<=H) a(h))^2.
```

Use

```text
1/lcm(h,k) = gcd(h,k)/(h k),

a(h)/h <= 1/[q(q+1)] + 1/h.
```

The standard gcd sums are

```text
sum_(h,k<=H) gcd(h,k)             << H^2 log(2H),

sum_(h,k<=H) gcd(h,k)/h           << H log^2(2H),

sum_(h,k<=H) gcd(h,k)/(h k)       << log^3(2H).
```

For example they follow from

```text
gcd(h,k) = sum_(e|h, e|k) phi(e).
```

Substituting `H=(q+1)D` and the exact `sum a(h) << D^2` gives

```text
E_q^LL(N;D)
  << N * {
       (D^2/q^2) log(2(q+1)D)
       + (D/q) log^2(2(q+1)D)
       + log^3(2(q+1)D)
     }
     + D^4.
```

This is the strongest clean deterministic low--low estimate obtained from the divisor parametrization.

If

```text
(q+1)D <= sqrt(N),
```

then `D^4` is absorbed at the same scale as the least-common-multiple term. For any fixed `eta>0`, take

```text
D_2(N,q;eta)
  = min {
      sqrt(N)/(q+1),
      q sqrt(N)/(log N)^(3/2+eta)
    }.
```

Then

```text
E_q^LL(N;D_2)
  = o( N^2/(log N)^2 ).
```

In particular, for fixed `q`,

```text
D <= N^(1/2-epsilon)
  implies
E_q^LL(N;D) = o_q(N^2/(log N)^2).
```

So two low-order characters can be pruned almost to square-root order.

## 4. Low--any energy, derived line by line

First bound the full first moment. Each pair `(p,r)` with `r in Z_p` produces at most one integer

```text
n = q p+r
```

in the shell. The relevant primes satisfy `p << N/q`. Using the proved vertical bound

```text
|Z_p| << p^(2/3),
```

we obtain

```text
S_q(N)
  := sum_(N<n<=2N) K_q(n)
  <= sum_(p << N/q) |Z_p|
  << (N/q)^(5/3) / log(2+N/q).
```

At one row, write `K=K_L+K_H`. Then

```text
(K)_2-(K_H)_2
  = (K_L)_2 + 2 K_L K_H
  <= 2 K_L K.
```

Proposition 3.1 gives

```text
max_(N<n<=2N) K_L(n;D)
  <= M_N(D/q+2).
```

Hence

```text
E_q^L*(N;D)
  <= 2 max_n K_L(n;D) * sum_n K_q(n)

  << M_N(D/q+2)
       * (N/q)^(5/3)/log(2+N/q)

  << M_N(D+q) N^(5/3)
       / [ q^(8/3) log(2+N/q) ].
```

Therefore

```text
E_q^L*(N;D) = o(N^2/(log N)^2)
```

whenever

```text
D+q
  = o( q^(8/3) N^(1/3) log(2+N/q)
       / [ M_N (log N)^2 ] ).
```

An explicit logarithmically safe choice is

```text
D_1+q
  <= q^(8/3) N^(1/3) log(2+N/q)
     / [ M_N (log N)^(2+eta) ].
```

It yields

```text
E_q^L*(N;D_1)
  << N^2/(log N)^(2+eta).
```

For fixed `q`, since `M_N=N^o(1)`, this is exactly

```text
D_1 = N^(1/3-o(1)).
```

The exponent `1/3` is `1-2/3`; it comes directly from the present vertical exponent `|Z_p| << p^(2/3)`. A better mixed threshold requires either a better vertical exponent or genuinely horizontal information about the unrestricted partner.

## 5. The whole large-`q` sector

For `q <= N^(1/2-delta)`, Brun--Titchmarsh gives, uniformly in `n in (N,2N]`,

```text
K_q(n)
  <= # { p prime : n/(q+1)<p<=n/q }

  <<_delta N
       / [ q(q+1) log(N/q^2) ].
```

Using the first moment from Section 4,

```text
E_q(N)
  <= max_n K_q(n) * sum_n K_q(n)

  <<_delta N^(8/3)
     / [ q^(8/3)(q+1)
         log(N/q) log(N/q^2) ].
```

Thus

```text
E_q(N)
  <<_delta
  N^(8/3)
  / { q^(8/3)(q+1) log(N/q)log(N/q^2) }.
```

If

```text
N^(2/11+epsilon) <= q <= N^(1/2-delta),
```

then `q^(8/3)(q+1) >= q^(11/3)`, so

```text
E_q(N)
  <<_(delta,epsilon)
  N^(2-(11/3)epsilon)/(log N)^2

  = o(N^2/(log N)^2).
```

Therefore only

```text
q <= N^(2/11+o(1))
```

can matter at the shell pair-energy scale. For the pointwise contradiction argument, one eventually freezes a fixed `q`, so this large-`q` pruning is secondary but unconditional.

## 6. Strongest unconditional combination of the L2 bounds

Choose cutoffs `D_1 < D_2` satisfying the low--any and low--low conditions above. Let `E_q^res(N;D_1,D_2)` count ordered target pairs `(p,l)` for which

```text
d_(p,n) > D_1,
d_(l,n) > D_1,
max(d_(p,n),d_(l,n)) > D_2.
```

The complement is contained in the union of

```text
{ at least one order <= D_1 }

and

{ both orders <= D_2 }.
```

Consequently

```text
E_q(N)
  = E_q^res(N;D_1,D_2)
    + o(N^2/(log N)^2).
```

For fixed `q`, the choices above give the explicit qualitative residual

```text
both orders > N^(1/3-o(1)),

and at least one order > N^(1/2-o(1)).
```

Equivalently, the unconditional L2 pruning removes:

```text
1. every pair with one order below N^(1/3-o(1));
2. every pair whose two orders are both below N^(1/2-o(1)).
```

The hard mixed band is therefore not “both orders moderately small.” It is a pair with one very large order and a second order already above the `N^(1/3)` barrier.

## 7. Audit of the quotient-adaptive pointwise lemma

The lemma in `Q32_SEPARATION_ANALYSIS.md` is correct. Put

```text
L_(n,q) = tau(n-q) log(n) F(n),

F(n) -> infinity,
F(n) = n^o(1).
```

If

```text
gcd(p-1,n-q) > L_(n,q),
```

then

```text
d_(p,n)
  = (p-1)/gcd(p-1,n-q)
  < n/[q L_(n,q)].
```

Proposition 3.1, with

```text
D = n/[q L_(n,q)],
```

gives at quotient `q` at most

```text
tau(n-q) * { n/[q^2 L_(n,q)] + 2 }
```

candidate primes. Multiplying by `log n` and summing over `q<sqrt(n)` gives

```text
removed weight

  <= sum_(q<sqrt(n))
       { n/[q^2 L_(n,q)] + 2 }
       tau(n-q) log n

  <= [n/F(n)] sum_(q>=1) 1/q^2
     + 2 log n sum_(q<sqrt(n)) tau(n-q)

  << n/F(n) + n^(1/2+o(1)).
```

Thus all vertices with

```text
gcd(p-1,n-q) > tau(n-q)log(n)F(n)
```

have pointwise logarithmic weight `o(n)`. The surviving vertices satisfy

```text
gcd(p-1,n-q) <= tau(n-q)log(n)F(n),

d_(p,n)
  >= (p-1)/[tau(n-q)log(n)F(n)]
  = p^(1-o(1)).
```

This is a genuine and strong **pointwise** pruning.

### 7.1 Why it does not improve the mixed shell threshold

Let `R_q(n)` count the vertices discarded by this pointwise cutoff in one fixed quotient arc. On a dyadic shell, after replacing `F` by a monotone lower envelope if necessary, Proposition 3.1 gives

```text
R_q(n)
  << N/[q^2 log(N) F(N)] + 2 tau(n-q).
```

Hence

```text
max_n R_q(n)
  << N/[q^2 log(N) F(N)] + M_N.
```

The energy of pairs having at least one discarded vertex is therefore bounded by

```text
E_q^(R*)(N)
  <= 2 max_n R_q(n) * S_q(N)

  << N^(8/3)
       / [ q^(11/3) log(N)log(N/q) F(N) ]

     + M_N N^(5/3)
       / [ q^(5/3) log(N/q) ].
```

For fixed `q`, the second term is already negligible, but the first term is smaller than `N^2/(log N)^2` only if

```text
F(N) >> N^(2/3)
```

up to harmless logarithmic and fixed-`q` factors. This is impossible for the nearly-primitive choice `F(N)=N^o(1)`.

Even if one permits `F(N)=N^beta`, the condition is

```text
beta > 2/3.
```

But the discarded characters then satisfy only

```text
d_(p,n)
  < N/[q tau(n-q)log(N)F(N)]
  = N^(1-beta+o(1)).
```

Thus `beta>2/3` removes only

```text
d_(p,n) < N^(1/3-o(1)),
```

which is exactly the old mixed threshold. The quotient-adaptive cancellation of `tau(n-q)` does not change the exponent.

### 7.2 Cauchy--Schwarz is circular here

Write, over the shell,

```text
A = sum_n K_L(n)^2,
B = sum_n K_H(n)^2.
```

Then

```text
sum_n K_L(n)K_H(n) <= sqrt(A B).
```

The low--low theorem controls `A`, but `B` contains the unknown residual high--high energy. Therefore this inequality does not give an absolute bound for the mixed term. It merely rewrites the desired correlation in terms of the same unknown residual.

The obstruction can already occur in one row:

```text
K_L(n)=1,
K_H(n)=H.
```

Then the low--low falling energy at that row is zero, while the low--high energy is `2H`. No interpolation between the low--low and first-moment estimates rules this out.

### 7.3 Correct logical combination

The correct use of the L1 lemma is chronological, not interpolative:

```text
1. Assume a forbidden pointwise spike.
2. Apply the quotient-adaptive L1 pruning at that same n.
3. The removed weight is o(n), so a linear residual spike remains.
4. Only then invoke a pair theorem for the nearly primitive residual.
```

It does not prove a small pair energy for the discarded sector. It weakens the theorem one still has to prove.

## 8. Exact residual pair-energy theorem

Define

```text
K_q^np(n;F)
  = #{ p prime : n/(q+1)<p<=n/q,
                  B_(n-q p)=0 mod p,
                  gcd(p-1,n-q)
                    <= tau(n-q)log(n)F(n) }.
```

Set

```text
E_q^np(N;F)
  = sum_(N<n<=2N) (K_q^np(n;F))_2.
```

The exact remaining pair-energy theorem is

```text
For every fixed q,

E_q^np(N;F)
  = o_q( N^2/(log N)^2 ).
```

This is sufficient for the full pointwise lower-digit theorem. Indeed, a forbidden linear logarithmic weight loses only `o(n)` under the L1 pruning, then localizes to one fixed quotient with

```text
K_q^np(n;F) >> n/log n.
```

The single row forces

```text
E_q^np(N;F) >> N^2/(log N)^2,
```

contradicting the residual theorem.

This residual theorem treats two different-characteristic characters, each of order

```text
d_(p,n) = N^(1-o(1)).
```

It is not reached by the unconditional L2 estimates of Sections 3--6.

## 9. Carrier and CFVZ audit inside the order decomposition

The exact quotient carrier is

```text
C_(n,q) = binom(n, floor(n/(q+1))).
```

For every nonboundary candidate prime in the `q`-arc,

```text
v_p(C_(n,q)) = 1.
```

For fixed `q`, once `p` exceeds the fixed integer `B_q`, Gessel--Lucas gives

```text
B_n = B_q B_(n-q p) mod p.
```

Hence the exact interval-restricted identity is

```text
prod_{n/(q+1)<p<=n/q,
     B_(n-q p)=0 mod p} p

  = rad_(n/(q+1),n/q] gcd(B_n,C_(n,q)).
```

This carrier contains every nonboundary candidate prime independently of `d_(p,n)` or `g_(p,n)`. It therefore supplies no extra order restriction and no extra collision equation. Its logarithmic height is linear for fixed `q`.

Likewise, the CFVZ square/quadratic-times-square factorization is a characteristic-by-characteristic structural theorem. It does not relate the selected coefficient at prime `p` to the selected coefficient at prime `l`, and it supplies no additional divisor condition on `h | (n-q)`. Without a new cross-prime theorem, neither carrier nor CFVZ changes the bounds above.

The abstract star in the next section is only a no-go for reflection, spacing, Casimir, full order, and the universal continuant factor. It is not claimed to realize the entire CFVZ polynomial structure.

## 10. Exact critical abstract star with `n-q` prime

The construction works.

Fix `q>=1`. Choose odd primes `m_j -> infinity` recursively so fast that

```text
m_(j+1) > ((q+1)/q)m_j + 2.
```

Then the intervals

```text
I_j = ( (m_j+q)/(q+1), (m_j+q)/q ]
```

are pairwise disjoint. Put

```text
n_j = m_j+q,

so n_j-q = m_j is prime.
```

For every prime `p in I_j`, define

```text
r_p = n_j-q p,

Z_p^* = { r_p, p-1-r_p },
```

merging the two entries in the central case. Remove the at most `O_q(1)` boundary or central primes if desired, and set `Z_p^*=empty` for primes outside all selected intervals.

### 10.1 It is a critical `q`-arc star

The interval inequalities give

```text
0 <= r_p < p,

n_j = q p+r_p.
```

The prime number theorem in a fixed-ratio interval gives

```text
# { p prime : p in I_j }
  ~ m_j/[q(q+1)log m_j]
  ~ n_j/[q(q+1)log n_j].
```

Thus one column contains the critical number `asymp_q n_j/log n_j` of hits.

### 10.2 Every selected character is primitive

For `q>=2` and large `m_j`, the upper endpoint of `I_j` is below `m_j+1`, so

```text
1 <= p-1 < m_j.
```

For `q=1`, equality `p=m_j+1` cannot occur because `m_j+1` is an even integer greater than two. Hence the same strict inequality holds. Since `m_j` is prime,

```text
gcd(p-1,n_j-q)
  = gcd(p-1,m_j)
  = 1.
```

Therefore

```text
d_(p,n_j) = p-1.
```

This lies in the strongest possible nearly primitive sector.

### 10.3 Reflection and no adjacent zeros

The set is reflection invariant by definition. If its two elements are distinct, their difference is

```text
| (p-1-r_p)-r_p |
  = |p-1-2r_p|.
```

This is a positive even integer, hence at least two. Therefore there are no adjacent distinct zeros.

The two reflected indices also give one Casimir point:

```text
r_p(r_p+1)
  = (p-1-r_p)(p-r_p) mod p.
```

Thus the row is the zero set of the degree-one abstract Casimir polynomial

```text
X-r_p(r_p+1).
```

### 10.4 The forced continuant factor is preserved

Let

```text
a_p = min(r_p,p-1-r_p),

h_p = |p-1-2r_p|.
```

Outside the central case, `h_p` is positive and even, and

```text
2a_p+h_p+1 = p.
```

The Apéry gap continuant satisfies the reflection identity

```text
N_h(-x-h-1) = (-1)^(h-1) N_h(x).
```

For even `h`, this forces the integral factor

```text
2x+h+1 | N_h(x).
```

Consequently

```text
p = 2a_p+h_p+1 | N_(h_p)(a_p).
```

This divisibility is universal: it holds because the endpoints are reflected, not because they are actual Apéry zeros. Dividing the continuant by `2x+h+1` removes exactly this forced factor.

Therefore the abstract family simultaneously has

```text
critical column size,
full character order,
reflection,
no adjacent distinct zeros,
one Casimir root,
and the unsaturated reflected-continuant divisor.
```

There is no error in the construction. The only necessary qualification is that it is an abstract zero-set model, not a realization by the distinguished Apéry sequence.

## 11. The narrowest clean theorem that remains

The residual pair-energy theorem in Section 8 is sufficient, but the separation analysis gives a weaker target.

For `p<l` in one fixed `q`-arc, put

```text
h = l-p,
s = n-q l.
```

The two target conditions are

```text
p | B_(s+q h),

l | B_s.
```

Call the pair degenerate if

```text
p | B_s
or
l | B_(s+q h).
```

The gap continuant gives, for fixed `q,h`,

```text
M_(q,h)^deg(n) <<_q h.
```

Hence all degenerate pairs with `h<=H` contribute

```text
sum_(h<=H) M_(q,h)^deg(n) <<_q H^2.
```

On the complementary pure-cross locus, the relevant continuant is a unit modulo both moving primes. Define `A_(q,H)^(np,x)(n;F)` to be the number of adjacent pure-cross pairs in the ordered nearly primitive target set whose prime gap is at most `H`.

The following is already sufficient:

```text
For every fixed q and A>0,

sup_(N<n<=2N)
  A_(q,A log N)^(np,x)(n;F)

  = o_(q,A)(N/log N).
```

A forbidden residual star has `>>N/log N` vertices in an arc of total length `O_q(N)`, so for sufficiently large fixed `A` it has `>>N/log N` adjacent gaps at most `A log N`. Only `O_(q,A)(log^2N)` can be degenerate. Thus the displayed pure-cross estimate contradicts every forbidden spike.

This adjacent pure-cross theorem is strictly weaker than the full residual pair-energy estimate. The primitive abstract star shows that neither full character order nor any of the currently known row-local constraints proves it. What remains is a genuinely cross-characteristic theorem using the actual Apéry initial state, such as a pure-cross low-height certificate, moving-character dispersion, or the holonomic-gcd Path D theorem.
