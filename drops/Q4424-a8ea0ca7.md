## 7. Translate second moment: exact no-gain theorem

For two integer points `r,s`, define

\[
w_\tau(r,s)
:=1_{\{r\text{ and }s\text{ lie in one translated length-}\Lambda\text{ cell}\}}.
\tag{7.1}
\]

The banked first-moment identity is

\[
\boxed{
\frac1\Lambda\sum_{\tau\bmod\Lambda}w_\tau(r,s)
=
\left(1-\frac{|r-s|}{\Lambda}\right)_+.
}
\tag{7.2}
\]

**Frame: `[Exact]`.** This triangular kernel is the discrete Fejér autocorrelation and is nonnegative.

For arbitrary pair coefficients `b_e`, put

\[
Z_\tau:=\sum_e b_e w_\tau(e).
\tag{7.3}
\]

Then

\[
\boxed{
\frac1\Lambda\sum_\tau Z_\tau^2
=
\sum_{e,e'}b_eb_{e'}K_\Lambda(e,e'),
\qquad
K_\Lambda(e,e')
:=\frac1\Lambda\sum_\tau w_\tau(e)w_\tau(e').
}
\tag{7.4}
\]

**Frame: `[Exact]`.** The matrix `K_Lambda` is a Gram matrix, hence positive semidefinite, and every entry is nonnegative.

This is not an oscillatory large-sieve kernel. Translation supplies no phase with which exceptional support could cancel.

### 7.1 Cluster lower bound
