## 1. Newton data and the joint primitive normalization

The Apéry numbers are generated exactly by

```text
b_0=1,
b_1=5,

(m+1)^3 b_(m+1)
 = (34m^3+51m^2+27m+5)b_m - m^3 b_(m-1).
```

Put

```text
C_k = Delta^k b_0
    = sum_(s=0)^k (-1)^(k-s) binom(k,s)b_s.
```

Then

```text
b_x = sum_(k>=0) C_k binom(x,k)
```

at every nonnegative integer `x`.  For multiplication by the denominator Newton basis, define

```text
M_(k,l)
 = binom(k,l) Delta^(k-l)b_l
 = binom(k,l) sum_(t=0)^l binom(l,t) C_(k-l+t).
```

For denominator degree `d`, the high equations are

```text
sum_(l=0)^d M_(k,l)q_l = 0,
H-d+1 <= k <= H.
```

Let the signed maximal cofactors of this `d x (d+1)` matrix be

```text
Delta_(d,0),...,Delta_(d,d),
```

and put

```text
delta_d = gcd_l Delta_(d,l).
```

The primitive denominator is

```text
q_l = Delta_(d,l)/delta_d.
```

The numerator is then defined, without another content division, by

```text
p_k = sum_(l=0)^d M_(k,l)q_l,
0<=k<=H-d.
```

Because the denominator cofactor vector is primitive, the complete pair is jointly primitive.  Dividing the numerator again would change the family and destroy the zero-absorber normalization.

```text
sigma_0=1,

E_0(n):=P^[0](n)=sum_(k=0)^H C_k binom(n,k).
```

This identity is already enough to rule out an ordinary resultant of sublinear height.

## 3. The exact member `P_(H-1)`: denominator degree `d=1`

Define

```text
U_k := M_(k,1)=k(C_(k-1)+C_k),
C_(-1):=0.
```

The only high equation is

```text
C_H q_0 + U_H q_1=0.
```

Put

```text
g_1 := gcd(C_H,U_H).
```

A canonical primitive choice is

```text
q_0= U_H/g_1,
q_1=-C_H/g_1,

Q^[1](x)=(U_H-C_H x)/g_1.
```

The numerator coefficients are

```text
p_k^[1]
 = (U_H C_k-C_H U_k)/g_1,
0<=k<=H-1,
```

so

```text
P^[1](x)
 = sum_(k=0)^(H-1)
   (U_H C_k-C_H U_k)/g_1 * binom(x,k).
```

The primitive scale relative to the projective normalization `q_1=1` is

```text
sigma_1=|C_H|/g_1.
```

The top numerator coefficient is

```text
p_(H-1)^[1]=tau_1/g_1,
```

where

```text
tau_1
 := C_(H-1)U_H-C_HU_(H-1)

  = H C_(H-1)^2
    +C_(H-1)C_H
    -(H-1)C_(H-2)C_H.
```

Multiplication by `x` gives the exact Newton identity

```text
sum_(k=0)^H U_k binom(x,k)
 = x B_H(x)-(H+1)C_H binom(x,H+1).
```

Therefore

```text
P^[1](x)
 = Q^[1](x)P^[0](x)
   +rho_1 binom(x,H+1),

rho_1=(H+1)C_H^2/g_1.
```

Equivalently, the adjacent cross determinant is

```text
P^[0]Q^[1]-P^[1]
 = kappa_0 binom(x,H+1),

kappa_0=-rho_1.
```

At an arbitrary integer `n`, this gives the exact evaluation gcd

```text
gcd(E_0(n),E_1(n))
 = gcd(E_0(n),rho_1 binom(n,H+1)).
```

No divisibility implication has been lost here: it is the elementary identity

```text
gcd(X,XQ-Y)=gcd(X,Y).
```

The node resultant retains the primitive denominator values:

```text
Res(F_H,P^[1])
 = product_(s=0)^H P^[1](s)
 = (product_(s=0)^H b_s)
   (product_(s=0)^H Q^[1](s)).
```

There is also an exact rational pair-resultant formula.  If

```text
a_H=C_H/H!,
```

then, assuming the displayed degrees are exact,

```text
Res(P^[0],P^[1])
 = (rho_1/(H+1)!)^H
   * (product_(s=0)^H b_s)/a_H^2.
```

The factor `product b_s` is not an artifact of raw cofactor normalization; it remains after the joint primitive division.

## 5. Exact boundary formula for every high-degree tail member

For Newton basis products one has

```text
binom(x,r)binom(x,l)
 = sum_(t=0)^min(r,l)
   (r+l-t)!/[t!(r-t)!(l-t)!]
   * binom(x,r+l-t).
```

Let

```text
Q^[d](x)=sum_(l=0)^d q_l^[d] binom(x,l).
```

The coefficient of `binom(x,H+j)` in the product `P^[0]Q^[d]` is therefore

```text
rho_(d,j)
 = sum_(r=0)^H sum_(l=0)^d sum_(t=0)^min(r,l)
   1_(r+l-t=H+j)
   C_r q_l^[d]
   (H+j)!/[t!(r-t)!(l-t)!].
```

The coefficients through degree `H` are exactly the Newton coefficients of the tabulated product `b_sQ^[d](s)`.  The high equations kill degrees `H-d+1,...,H`, and the surviving lower coefficients are `P^[d]`.  Hence

```text
boxed:

P^[0](x)Q^[d](x)-P^[d](x)
 = sum_(j=1)^d rho_(d,j)binom(x,H+j).
```

This is an identity in the integer-valued polynomial ring.  In particular, the space of all degree-at-most-`H+D` integer-valued polynomials vanishing at `0,...,H` is exactly

```text
span_Z {
  binom(x,H+1),...,binom(x,H+D)
}.
```

For evaluation at `n`, set

```text
W_d(n)
 := sum_(j=1)^d rho_(d,j)binom(n,H+j).
```

Since

```text
P^[d](n)=P^[0](n)Q^[d](n)-W_d(n),
```

successively replacing each tail value by its cross difference gives the exact gcd identity

```text
boxed:

T_D(n)
 := gcd_(0<=d<=D) P^[d](n)
  = gcd(P^[0](n),W_1(n),...,W_D(n)).
```

No coefficient gcd, denominator lcm, or Smith factor is missing from this formula.

## 6. Prime-by-prime interpretation

Fix a prime `p>H+D` and write

```text
n=qp+r,
0<=r<p.
```

Because every Newton degree occurring above is below `p`, Lucas reduction gives

```text
binom(n,k)=binom(r,k) mod p,
0<=k<=H+D.
```

### 6.1 Genuine target residue

If

```text
0<=r<=H,
p|b_r,
```

then

```text
P^[0](n)=P^[0](r)=b_r=0 mod p,
```

and, for every `1<=j<=d<=D`,

```text
binom(n,H+j)=binom(r,H+j)=0 mod p.
```

Therefore

```text
p | T_D(n).
```

This proves that all target primes above `H+D` survive every selected high-degree tail.

### 6.2 Non-target residue in the training range

If

```text
0<=r<=H,
p does not divide b_r,
```

then `P^[0](n)` is a `p`-unit, so `p` does not divide even the two-member tail gcd.

### 6.3 Residue outside the training range

If `r>H`, the prime is not a genuine interpolation target.  Its presence in the tail is characterized exactly by

```text
p | P^[0](n),

p | W_d(n) for every 1<=d<=D.
```

This is the only part on which adding tail members can help.  It removes accidental middle-gap primes, not the target radical.

For every prime, including small primes, valuations are exactly

```text
v_p(T_D(n))
 = min(
     v_p(P^[0](n)),
     v_p(W_1(n)),...,
     v_p(W_D(n))
   ).
```

For a target prime at which every relevant binomial carrier has valuation one, the tail already forces the radical, while extra powers are governed by whether the boundary coefficients `rho_(d,j)` simultaneously vanish modulo `p`.

## 7. Why fixed and slowly growing tails do not close `log G=o(H)`

Let

```text
n=3H+c,
```

with fixed `c`.  Uniformly for `1<=j<=D=o(H)`, Stirling gives

```text
log binom(n,H+j)
 = H log(27/4)
   +O(D+D^2/H+log H).
```

Thus every nonzero canonical boundary coordinate has positive linear height.  Adding finitely many or `H^(2/3)` many adjacent identities only enlarges the boundary module

```text
span_Z{binom(x,H+1),...,binom(x,H+D)};
```

it does not produce a geometric coordinate of sublinear height.

The first adjacent scalar is independently exponential.  The binomial transform of the Apéry generating function gives

```text
C_H
 = Theta(gamma^H H^(-3/2)),

gamma=(17+12sqrt(2))-1=16+12sqrt(2).
```

Since `g_1<=|C_H|`,

```text
|kappa_0|=rho_1>=(H+1)|C_H|,
```

and therefore

```text
log|kappa_0|
 >= H log(16+12sqrt(2))+O(log H).
```

The resultant route is worse:

```text
log product_(s=0)^H b_s
 = (log(17+12sqrt(2))/2)H^2+O(H log H).
```

The only way an evaluated tail gcd can nevertheless be `exp(o(H))` is through the arithmetic fact that very few target primes divide `P^[0](n)` and the boundary carriers simultaneously.  But for `p>H+D`, that simultaneous divisibility is **exactly**

```text
p|b_(n mod p),
0<=n mod p<=H.
```

That is the fixed-quotient Apéry-zero theorem being sought.  The high-degree tail reformulates it; it does not prove it.

Hence the rigorous answer is:

```text
A fixed or slowly growing high-degree tail may empirically equal the
complete family gcd, and its extra middle-gap pollution is directly
computable from the W_d.  No uniform proof of exp(o(H)) follows from
its Newton, Plücker, Dodgson, or resultant identities.  Every such tail
retains the complete target radical above H+D, while the canonical
integer carriers have positive linear or quadratic logarithmic height.
```

There is no known exact infinite counterexample to the actual assertion `log G=o(H)`.

```python
#!/usr/bin/env python3
from __future__ import annotations

import argparse
from fractions import Fraction
from functools import reduce
from math import comb, factorial, gcd, lcm


def apery_values(maximum_index: int) -> list[int]:
    if maximum_index == 0:
        return [1]
    values = [1, 5]
    for m in range(1, maximum_index):
        numerator = (
            (34*m**3 + 51*m**2 + 27*m + 5) * values[m]
            - m**3 * values[m-1]
        )
        denominator = (m+1)**3
        assert numerator % denominator == 0
        values.append(numerator // denominator)
    return values[:maximum_index+1]


def forward_differences(values: list[int]) -> list[int]:
    row = values[:]
    result: list[int] = []
    while row:
        result.append(row[0])
        row = [row[j+1]-row[j] for j in range(len(row)-1)]
    return result


def evaluate_newton(coefficients: list[int], x: int) -> int:
    return sum(c*comb(x,k) for k,c in enumerate(coefficients))


def multiplication_matrix(height: int, C: list[int]) -> list[list[int]]:
    M = [[0]*(height+1) for _ in range(height+1)]
    for k in range(height+1):
        for ell in range(k+1):
            shifted = sum(
                comb(ell,t)*C[k-ell+t]
                for t in range(ell+1)
            )
            M[k][ell] = comb(k,ell)*shifted
    return M


def bareiss_eliminate(matrix: list[list[int]]) -> None:
    rows = len(matrix)
    if rows == 0:
        return
    assert len(matrix[0]) == rows+1
    previous = 1
    for pivot_index in range(rows):
        pivot = matrix[pivot_index][pivot_index]
        if pivot == 0:
            raise ArithmeticError(f"zero nested pivot at {pivot_index}")
        if pivot_index+1 == rows:
            break
        for row in range(pivot_index+1,rows):
            below = matrix[row][pivot_index]
            for col in range(pivot_index+1,rows+1):
                numerator = (
                    matrix[row][col]*pivot
                    - below*matrix[pivot_index][col]
                )
                assert numerator % previous == 0
                matrix[row][col] = numerator // previous
            matrix[row][pivot_index] = 0
        previous = pivot


def primitive_relation(eliminated: list[list[int]], d: int) -> list[int]:
    if d == 0:
        return [1]
    q = [Fraction(0) for _ in range(d+1)]
    q[d] = Fraction(1)
    for row in range(d-1,-1,-1):
        total = sum(
            Fraction(eliminated[row][col], eliminated[row][row])*q[col]
            for col in range(row+1,d+1)
        )
        q[row] = -total
    denominator = 1
    for value in q:
        denominator = lcm(denominator,value.denominator)
    integral = [
        value.numerator*(denominator//value.denominator)
        for value in q
    ]
    content = reduce(gcd,(abs(v) for v in integral),0)
    assert content
    integral = [v//content for v in integral]
    if integral[-1] < 0:
        integral = [-v for v in integral]
    assert reduce(gcd,(abs(v) for v in integral),0) == 1
    return integral


def numerator_from_denominator(
    height: int,
    d: int,
    M: list[list[int]],
    q: list[int],
) -> list[int]:
    a = height-d
    all_coefficients = [
        sum(M[k][ell]*q[ell] for ell in range(min(k,d)+1))
        for k in range(height+1)
    ]
    assert all(value == 0 for value in all_coefficients[a+1:])
    p = all_coefficients[:a+1]
    assert reduce(gcd,(abs(v) for v in p+q),0) == 1
    return p


def same_pair_up_to_sign(
    left: tuple[list[int],list[int]],
    right: tuple[list[int],list[int]],
) -> bool:
    lp,lq = left
    rp,rq = right
    return (lp == rp and lq == rq) or (
        lp == [-v for v in rp] and lq == [-v for v in rq]
    )


def closed_tail_012(height: int, C: list[int]):
    H = height
    assert H >= 2
    U = [
        k*((C[k-1] if k else 0)+C[k])
        for k in range(H+1)
    ]
    V = []
    for k in range(H+1):
        cm2 = C[k-2] if k >= 2 else 0
        cm1 = C[k-1] if k >= 1 else 0
        V.append(comb(k,2)*(cm2+2*cm1+C[k]))

    P0 = C[:]
    Q0 = [1]

    g1 = gcd(abs(C[H]),abs(U[H]))
    Q1 = [U[H]//g1,-C[H]//g1]
    P1 = [
        (U[H]*C[k]-C[H]*U[k])//g1
        for k in range(H)
    ]
    tau1 = C[H-1]*U[H]-C[H]*U[H-1]
    assert P1[-1] == tau1//g1
    sigma1 = abs(C[H])//g1
    rho1 = (H+1)*C[H]*C[H]//g1
    kappa0 = -rho1

    D0 = U[H-1]*V[H]-V[H-1]*U[H]
    D1 = V[H-1]*C[H]-C[H-1]*V[H]
    D2 = C[H-1]*U[H]-U[H-1]*C[H]
    assert D2 == tau1
    g2 = reduce(gcd,(abs(D0),abs(D1),abs(D2)),0)
    Q2 = [D0//g2,D1//g2,D2//g2]
    P2 = [
        (D0*C[k]+D1*U[k]+D2*V[k])//g2
        for k in range(H-1)
    ]
    tau2_matrix = [
        [C[H-2],U[H-2],V[H-2]],
        [C[H-1],U[H-1],V[H-1]],
        [C[H],U[H],V[H]],
    ]
    tau2 = (
        tau2_matrix[0][0]*(
            tau2_matrix[1][1]*tau2_matrix[2][2]
            -tau2_matrix[1][2]*tau2_matrix[2][1]
        )
        -tau2_matrix[0][1]*(
            tau2_matrix[1][0]*tau2_matrix[2][2]
            -tau2_matrix[1][2]*tau2_matrix[2][0]
        )
        +tau2_matrix[0][2]*(
            tau2_matrix[1][0]*tau2_matrix[2][1]
            -tau2_matrix[1][1]*tau2_matrix[2][0]
        )
    )
    assert P2[-1] == tau2//g2
    sigma2 = abs(tau1)//g2

    xi1 = (H+1)*C[H]
    eta1 = comb(H+1,2)*(C[H-1]+2*C[H])
    eta2 = comb(H+2,2)*C[H]
    A2 = (D1*xi1+D2*eta1)//g2
    B2 = D2*eta2//g2
    kappa1 = comb(H+1,2)*tau1*tau1//(g1*g2)

    data = {
        "pairs": [(P0,Q0),(P1,Q1),(P2,Q2)],
        "g1": g1,
        "g2": g2,
        "tau1": tau1,
        "tau2": tau2,
        "sigma1": sigma1,
        "sigma2": sigma2,
        "kappa0": kappa0,
        "kappa1": kappa1,
        "A2": A2,
        "B2": B2,
    }
    return data


def newton_product(left: list[int], right: list[int]) -> list[int]:
    size = len(left)+len(right)-1
    result = [0]*size
    facts = [factorial(k) for k in range(size+1)]
    for r,ar in enumerate(left):
        for ell,be in enumerate(right):
            for t in range(min(r,ell)+1):
                k = r+ell-t
                coefficient = facts[k]//(
                    facts[t]*facts[r-t]*facts[ell-t]
                )
                result[k] += ar*be*coefficient
    return result


def boundary_coefficients(
    height: int,
    d: int,
    P0: list[int],
    Pd: list[int],
    Qd: list[int],
) -> list[int]:
    product = newton_product(P0,Qd)
    a = height-d
    for k in range(height+1):
        expected = Pd[k] if k <= a else 0
        assert product[k] == expected
    return [product[height+j] for j in range(1,d+1)]


def factor_text(value: int) -> str:
    try:
        from sympy import factorint
    except ImportError:
        return "sympy unavailable"
    factors = factorint(abs(value))
    return "*".join(
        str(p) if e == 1 else f"{p}^{e}"
        for p,e in sorted(factors.items())
    ) or "1"


def resultant_checks(
    height: int,
    apery: list[int],
    pairs: list[tuple[list[int],list[int]]],
) -> None:
    import sympy as sp
    x = sp.symbols("x")

    def expression(coefficients: list[int]):
        result = 0
        falling = 1
        for k,c in enumerate(coefficients):
            if k:
                falling *= x-(k-1)
            result += sp.Rational(c,factorial(k))*falling
        return sp.expand(result)

    F = sp.prod(x-s for s in range(height+1))
    prefix = 1
    for value in apery:
        prefix *= value

    P0 = expression(pairs[0][0])
    assert sp.resultant(F,P0,x) == prefix
    for Pcoeff,Qcoeff in pairs:
        P = expression(Pcoeff)
        node_product = 1
        for s in range(height+1):
            node_product *= apery[s]*evaluate_newton(Qcoeff,s)
        assert sp.resultant(F,P,x) == node_product


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("H",type=int)
    parser.add_argument("n",type=int)
    parser.add_argument("--tail",type=int,default=2)
    parser.add_argument("--resultants",action="store_true")
    args = parser.parse_args()
    H,n = args.H,args.n
    if H < 2 or n <= H:
        raise SystemExit("require H>=2 and n>H")

    apery = apery_values(H)
    C = forward_differences(apery)
    M = multiplication_matrix(H,C)

    reversed_high = [M[H-row][:] for row in range(H)]
    bareiss_eliminate(reversed_high)

    pairs: list[tuple[list[int],list[int]]] = []
    evaluations: list[int] = []
    full_gcd = 0
    tail_gcd = 0

    for d in range(H+1):
        q = primitive_relation(reversed_high,d)
        p = numerator_from_denominator(H,d,M,q)
        pairs.append((p,q))
        value = evaluate_newton(p,n)
        evaluations.append(value)
        full_gcd = gcd(full_gcd,abs(value))
        if d <= args.tail:
            tail_gcd = gcd(tail_gcd,abs(value))

    closed = closed_tail_012(H,C)
    for d in range(3):
        assert same_pair_up_to_sign(pairs[d],closed["pairs"][d])

    boundaries: list[list[int]] = [[]]
    for d in range(1,args.tail+1):
        rho = boundary_coefficients(
            H,d,pairs[0][0],pairs[d][0],pairs[d][1]
        )
        boundaries.append(rho)
        cross_value = sum(
            rho[j-1]*comb(n,H+j)
            for j in range(1,d+1)
        )
        direct_cross = (
            evaluations[0]*evaluate_newton(pairs[d][1],n)
            -evaluations[d]
        )
        assert cross_value == direct_cross

    if args.tail >= 1:
        assert boundaries[1] == [closed["kappa0"]]
    if args.tail >= 2:
        assert boundaries[2] == [closed["A2"],closed["B2"]]
        P1,Q1 = pairs[1]
        P2,Q2 = pairs[2]
        for x in (H+1,H+2,n):
            adjacent_cross = (
                evaluate_newton(P1,x)*evaluate_newton(Q2,x)
                -evaluate_newton(P2,x)*evaluate_newton(Q1,x)
            )
            assert adjacent_cross == (
                closed["kappa1"]*comb(x,H+1)
            )

    cross_gcd = abs(evaluations[0])
    for d in range(1,args.tail+1):
        cross_value = sum(
            boundaries[d][j-1]*comb(n,H+j)
            for j in range(1,d+1)
        )
        cross_gcd = gcd(cross_gcd,abs(cross_value))
    assert cross_gcd == tail_gcd
    assert tail_gcd % full_gcd == 0

    if (H,n) == (66,200):
        assert full_gcd == 5*17*139*181

    print(f"H={H} n={n} tail_D={args.tail}")
    print(f"full_gcd={full_gcd}")
    print(f"full_factor={factor_text(full_gcd)}")
    print(f"tail_gcd_bits={tail_gcd.bit_length()}")
    print(f"full_divides_tail={tail_gcd % full_gcd == 0}")
    print(f"sigma_1={closed['sigma1']}")
    print(f"sigma_2={closed['sigma2']}")
    print(f"kappa_0_bits={abs(closed['kappa0']).bit_length()}")
    print(f"kappa_1_bits={abs(closed['kappa1']).bit_length()}")
    print(f"boundary_d1={boundaries[1] if args.tail>=1 else []}")
    print(f"boundary_d2={boundaries[2] if args.tail>=2 else []}")

    if args.resultants:
        if H > 10:
            raise SystemExit("use --resultants only for small H")
        resultant_checks(H,apery,pairs[:3])
        print("resultant checks passed")


if __name__ == "__main__":
    main()
```
