\[

\[
\boxed{

# 7. Prime-local equivalence and the new strictly smaller target

Let \(p>s+1\) be prime.  Then every integer in

\[
1,2,\ldots,s+1
\]

is a `p`-unit, so in particular

\[
p\nmid L,
\qquad
p\nmid D_{r,n}.
\tag{7.1}
\]

Assume first

\[
p\mid b_r,\qquad p\mid b_s.
\tag{7.2}
\]

Reducing `(6.2)` modulo \(p\) gives

\[
b_{r+1}N_{n+1}(r)\equiv0\pmod p.

The proved `no_consecutive_zeros` theorem in

\[
p\nmid b_{r+1}.
\]

Therefore

\[
\boxed{p\mid N_{n+1}(r).}
\tag{7.3}
\]

Now reduce `(5.1)` modulo \(p\).  Each summand is `p`-integral by `(4.2)`

\[
\boxed{
 p\mid m_{n+1}
 \quad\Longleftrightarrow\quad
 p\mid\sum_{j=1}^n\mathcal R_{r,n,j}.
}
\tag{7.4}
\]

This proves `(LP-equiv)`:

\[
\boxed{
 p\mid b_r,b_s,m_{n+1}
 \Longleftrightarrow
 p\mid b_r,b_s,\sum_j\mathcal R_{r,n,j}
 \qquad(p>s+1).
}
\tag{7.5}
\]

Crucially, this argument does **not** divide by \(O_n\).  Thus it remains
valid even if a large prime \(p>s+1\) happens to divide one of the odd
factors in \(O_n\).  This is why the cleared defect `(5.1)`, rather than the
rational value \(G_n(1/2)\), is the correct prime-local object.

Consequently the following is a sufficient, placement-sensitive replacement
for the original prime-local LP:

\[
\boxed{
2r+n+2
=A^\sharp_{r,n}b_r+B^\sharp_{r,n}b_s
+C^\sharp_{r,n}\sum_{j=1}^n\mathcal R_{r,n,j},
}
\tag{PR-WZ again}
\]

with

\[
\boxed{
\operatorname{den}(A^\sharp_{r,n}),
\operatorname{den}(B^\sharp_{r,n}),
\operatorname{den}(C^\sharp_{r,n})\mid L^2.
}
\tag{7.6}
\]

If `(PR-WZ)` is proved and \(p>s+1\) divides
\(b_r,b_s,m_{n+1}\), then `(7.5)` kills all three terms on the right modulo

# 9. What the finite contiguous module now is

The reduced summand uses only

```text
b_j, g_j, eta_j,
b_(n-j), g_(n-j), eta_(n-j)
```

and rational functions of \(r,n,j\).  There is no full `Y`-dependent Green
function left.

The coefficient extraction from

\[
(Y+k+1)^3G_{k+1}(Y)
=P(Y+k)G_k(Y)-(Y+k)^3G_{k-1}(Y)
\]

gives an exact triangular contiguous system.  Writing

\[
P'(k)=102k^2+102k+27,
\qquad
\frac12P''(k)=102k+51,
\]

we have

\[
(k+1)^3b_{k+1}=P(k)b_k-k^3b_{k-1},
\tag{9.1}
\]

\[
\boxed{
\begin{aligned}
(k+1)^3g_{k+1}={}&P(k)g_k+P'(k)b_k
-k^3g_{k-1}-3k^2b_{k-1}\\
&-3(k+1)^2b_{k+1},
\end{aligned}}
\tag{9.2}
\]

and

\[
\boxed{
\begin{aligned}
(k+1)^3\eta_{k+1}={}&P(k)\eta_k+P'(k)g_k+(102k+51)b_k\\
&-k^3\eta_{k-1}-3k^2g_{k-1}-3kb_{k-1}\\
&-3(k+1)^2g_{k+1}-3(k+1)b_{k+1}.
\end{aligned}}
\tag{9.3}
\]

Thus the six-component state

\[
J_k=(b_{k-1},b_k,g_{k-1},g_k,\eta_{k-1},\eta_k)
\]

has a rational first-order transfer of fixed dimension.  As \(j\mapsto j+1\),
the left state moves forward and the right state with \(q=n-j\) moves
backward by the same fixed triangular system.  Consequently
\(\mathcal R_{r,n,j}\) belongs to a fixed finite bilinear contiguous module;
there is no growing Taylor jet.

A concrete certificate search should therefore use the bilinear state

\[
J_j\otimes J_{n-j}
\]

(or a reduced basis generated by `C0,C1,C2` and their one-step neighbors),
with rational coefficient functions whose only natural pole factors are

```text
j, j+1, n-j, n-j+1, 2*j+1, r+j+1.
```

The denominator theorem in Section 4 says that after multiplying the summand
by \(D_{r,n}O_n^3\), all surviving arithmetic denominators from the jet state
are already bounded by \(L^2\).  Therefore an Ore/WZ search no longer has to
solve a denominator problem and a telescoping problem simultaneously: the
remaining issue is the **boundary syzygy with the two physical Apéry endpoint
sums**.

This is where \(r\) must enter.  A pure outer-`j` telescoper whose boundary
uses only the r-free jet convolution cannot manufacture the mate scalar;
Section 5 shows that the raw defect is universally centered at \(2r+1\).
The boundary ansatz must retain `b_r` and `b_s` (or equivalently their exact
finite Apéry sums) as external contiguous states.

# 10. A scoped obstruction: why the obvious local clearing is insufficient

There are two exact obstructions that prevent overstating the result.

First, as shown in Section 8.1,

\[
L^2O_n^3\Theta_{r,n,j}\in\mathbf Z
\]

is false already for `(r,n,j)=(0,1,1)`.  So one cannot obtain the desired
placement dependence merely by replacing `Phi` with `Phi-Pi` inside Q2204's
old termwise denominator proof.  The physical cut denominator \(D_{r,n}\) is
essential.

Second, the already banked Q2173 denominator theorem shows that a direct
endpoint-normalized physical Green evaluation can genuinely require a third
lcm power.  Its exact example is

```text
x=0, h=4:
beta_4 = 57123475/432,
L = lcm(1,2,3,4) = 12,
432 | 12^3 but 432 does not divide 12^2.
```

Thus a proof that evaluates the physical bridge term by term and asks each
value individually to lie at `L^2` is impossible in that normalization.
The present reduction avoids that trap: it forms the half-step/placement
difference, clears the actual physical product \(D_{r,n}\), and only then
uses the \(\Lambda^2\) jet theorem.

This is a scoped obstruction to the obvious termwise/local clearing, not a
no-go theorem for a broader WZ or contiguous identity.
