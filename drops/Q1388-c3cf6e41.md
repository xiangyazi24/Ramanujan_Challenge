# CONCRETE PARTIAL

The finite-family construction is not proved, and the proposed finite-slope no-go is also not established in full generality. The correct conclusion from the available Kummer analysis is a scoped obstruction for a restricted class of elementary binomial carriers: fixed rational slopes cannot uniformly realize the even-q target without leaving residue intervals on which all carriers are p-adic units.

## 1. Base-p valuation formula for one fixed carrier

Let

```text
C_n = binom(n+c, floor(alpha n)+d),
alpha=u/v in lowest terms.
```

Choose an even q divisible by v and choose a prime p>sqrt(n) with

```text
n=qp+r, 0<r<p.
```

Because q is a multiple of v, the floor term has stable linear part:

```text
floor(alpha(qp+r)+c') = alpha q p + floor(alpha r+c'')
```

away from finitely many endpoint residues. Hence the p-adic valuation is determined by the carry in adding the two base-p digits of the lower argument and its complement in the upper argument.

For sufficiently large p compared with all fixed shifts, this reduces to an interval condition on x=r/p. The possible carry intervals for one carrier are finite unions of rational intervals whose endpoints depend only on alpha,c,d.

## 2. Simultaneous finite-family obstruction (scoped)

For a finite family

```text
E_n=lcm_i binom(n+c_i,floor(alpha_i n)+d_i),
```

choose q even and divisible by all denominators of the alpha_i. The union of the carry intervals of the finite family is still a finite union of proper rational intervals unless one carrier covers every residue class.

For the complementary open intervals, choose x=r/p avoiding all endpoints. For p larger than every fixed numerator/denominator and every |c_i|,|d_i|, the endpoint perturbations are O(1/p), so the same interval remains carry-free. Therefore

```text
v_p(E_n)=0
```

for these residues.

This proves the obstruction only for families whose individual carry sets are not already the whole interval. It does not rule out a specially engineered finite family containing a universal carrier.

## 3. First missing implication

The unresolved implication is:

```text
finite rational-slope carriers cannot contain a universal even-q carry cover.
```

The interval argument proves gaps after assuming every carrier has a nontrivial complement. It does not prove that assumption from the definition of elementary binomial carriers.

Consequently no PROVED finite construction and no unconditional REFUTED theorem is obtained.

## 4. Exact checks

```python
from math import comb
from fractions import Fraction


def vp(x,p):
    s=0
    while x and x%p==0:
        x//=p
        s+=1
    return s


def carry_carrier(n,c,u,v,d,p):
    # alpha=u/v, floor(alpha*n)+d
    k=(u*n)//v+d
    if k<0 or k>n+c:
        return 0
    return vp(comb(n+c,k),p)

# check direct Kummer valuations against exact binomial valuations
for p in [101,103,107,109]:
    for q in range(2,10,2):
        for r in range(1,p):
            n=q*p+r
            if n>100:

            assert carry_carrier(n,0,1,2,0,p)==vp(comb(n,n//2),p)

print('small exact carrier checks passed')
```

## 5. Regime implication

The first plausible regime is a growing slope bank. A family of size O(log q) or O(log n) can adaptively refine the residue partition; however the height advantage over shifted Newton is not established. The current result only identifies why a fixed finite bank cannot be assumed to cover the even-q branch: its carry geometry leaves a possible persistent uncovered interval.
