# Weak-threshold Kummer repruning for the q=1 top strip

## 1. Setup

Assume the q=1 top strip contains
\[
K\ge \epsilon X/\log X
\]
target primes. For each such prime p we write the reflected index
\[
s=\min(r,p-1-r),\qquad g=(s,p-1),\qquad a=s/g,\qquad d=(p-1)/g.
\]
Then
\[
s=ga,\qquad p-1=gd,\qquad (a,d)=1,
\]
and the Kummer condition is encoded by the divisor packet
\[
g\mid n-1.
\]
The objective is not to obtain a uniform q estimate, but to exploit the macroscopic number of q=1 primes.

## 2. Sharp divisor-packet pruning

The old cutoff choice \(L=X^{14/15+\eta}\) was tuned for a much smaller exceptional set. Here it is wasteful. We instead choose a cutoff directly from the macroscopic lower bound.

For every prime p in the top strip,
\[
p=n-r,
\]
with \(r\) in the allowed residue range. The packet variable satisfies
\[
g\mid n-1.
\]
Hence the number of possible g values is bounded by
\[
\tau(n-1)=X^{o(1)}.
\]
Therefore after partitioning all K primes into g-packets, one packet has size
\[
K_g\ge K/X^{o(1)}=X^{1-o(1)}/\log X.
\]
Equivalently,
\[
K_g=X^{1-o(1)}
\]
in the exponent sense, but it is not literally \(X^{1-o(1)}\) elements: the guaranteed cardinality is only
\[
X/\log^{1+o(1)}X.
\]
This distinction matters.

## 3. Surviving a,d,g ranges

Because
\[
s=ga\le (p-1)/2,
\]
we have
\[
a\le d/2.
\]
Also
\[
gd=p-1\asymp X,
\]
so
\[
d\asymp X/g.
\]
The divisor pruning leaves:

* \(g\) restricted to divisors of \(n-1\): only \(X^{o(1)}\) possibilities.
* \(a\) unrestricted only subject to \((a,d)=1\) and \(a\le d/2\).
* \(d\) determined by \(g\), hence \(d\asymp X/g\).

Large g packets are small because d shrinks. For any cutoff G,
\[
g>G
\]
contributes at most
\[
\sum_{g|n-1,g>G} O(X/g)=X^{1+o(1)}/G.
\]
Thus choosing
\[
G=\log^A X
\]
loses only
\[
X/\log^{A-o(1)}X.
\]
Hence almost all surviving mass lies in
\[
g\le \log^A X,
\]
with
\[
d\ge X/\log^A X.
\]

## 4. Packet size after optimizing cutoffs

After removing large g:

1. divisor loss:
\[
X^{o(1)};
\]

2. large-g loss:
\[
X/\log^{A-o(1)}X;
\]

3. coprimality loss:
for fixed d, forbidden a have density
\[
1-\varphi(d)/d\le \sum_{\ell|d}1/\ell,
\]
which is at worst \(X^{o(1)}\) and does not destroy a macroscopic packet.

Therefore one surviving packet satisfies
\[
|P_g|\ge \frac{\epsilon X}{\log^{1+o(1)}X}.
\]
It is not justified to claim a single packet has \(X^{1-o(1)}\) literal elements. The sharp statement is only
\[
X/\log^{O(1)}X.
\]

## 5. Repeated-gap consequence

For fixed surviving g, the possible indices are
\[
s=ga.
\]
Since d is fixed up to the packet, the admissible a values lie in an interval of length
\[
\asymp d\asymp X/g.
\]
A packet of size
\[
M\gg X/\log^{1+o(1)}X
\]
inside a universe of size
\[
N\ll X/g
\]
has average gap
\[
N/M\ll \frac{\log^{1+o(1)}X}{g}.
\]
Hence there exists a repeated gap
\[
\Delta a\ll \log^{1+o(1)}X,
\]
and therefore
\[
\Delta s=g\Delta a\ll g\log^{1+o(1)}X.
\]
For the small-g surviving range this gives
\[
\Delta s\le \log^{A+1+o(1)}X.
\]

This is the strongest unconditional repeated-gap statement obtainable from the weak threshold alone.

## 6. Loss accounting

The complete losses are:

| source | loss |
|---|---|
| divisor packets | \(X^{o(1)}\) packets |
| large g removal | \(X/\log^{A-o(1)}X\) |
| gcd restriction | \(X^{o(1)}\) density factor |
| endpoint/top-strip truncation | \(O(X/\log X)\) scale |

No old \(14/15+\eta\) exponent is needed. The macroscopic hypothesis improves the packet size from a small exceptional set to
\[
X/\log^{O(1)}X.
\]

## Final rigorous statement

If
\[
K\ge \epsilon X/\log X,
\]
then there exists a divisor packet \(g|n-1\) such that
\[
|P_g|\ge X/\log^{1+o(1)}X,
\]
with
\[
g\le \log^A X,
\qquad d\ge X/\log^A X,
\qquad a\le d/2,
\qquad (a,d)=1.
\]
Moreover this packet contains two elements whose a-coordinates differ by
\[
\Delta a\ll \log^{1+o(1)}X,
\]
so the corresponding Kummer indices have repeated gap
\[
\Delta s\ll \log^{A+1+o(1)}X.
\]
This is a genuine weak-threshold repruning improvement; it does not by itself prove the final contradiction, but it isolates the only remaining obstruction: converting a polylogarithmic repeated Kummer gap into an Apéry recurrence collision.
