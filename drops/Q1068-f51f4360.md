# Q1068: direct height attack on the half-cutoff Newton content

## Executive conclusion

The direct attack does not currently prove `log(Gamma_n)=o(n)`. The exact valuation formula and the carry-free suffix mechanism give useful reductions, but the remaining small-prime valuation strata are not eliminated. The surviving obstruction is a family of prime-power minima where every obvious unit-weight suffix has nonzero Apéry residue valuation and the Kummer contribution does not force a zero valuation.

Therefore the strongest verified result is a quantitative decomposition, not a height theorem.

## 1. Exact valuation identity

For

```
Gamma_n=gcd_{0<=j<M} L_j(n)b_j,
```

with integral factors, the prime valuation is exactly

```
v_p(Gamma_n)=min_{0<=j<M}(v_p(L_j(n))+v_p(b_j)).
```

This follows directly from the gcd valuation identity. No cancellation between different indices is available: each term is an integer product and the gcd takes the minimum valuation.

For the weight,

```
v_p(L_j(n))=v_p(C(n,j))+v_p(C(n-j-1,M-1-j)).
```

By Kummer,

```
v_p(C(A,B))
```

is the number of carries in adding `B` and `A-B` in base `p`. Hence the zero valuation condition is precisely

```
p does not divide L_j(n)
iff
C(n,j) and C(n-j-1,M-1-j) are carry-free.
```

It is not equivalent to a single digit inequality involving `M-1-j` and `n-M`.

## 2. Carry-free suffix reduction

The carry-free suffix lemma supplies, for each prime power `p^s`, an index

```
j = n mod p^s
```

in the admissible range whenever the suffix lies below the cutoff. At such an index the binomial contribution has controlled valuation.

This proves that large portions of the valuation can be tested through Apéry residues at special indices. However, it does not prove that one such index satisfies

```
v_p(b_j)=0.
```

The mixed example `(p,j)=(19,827)` demonstrates the failure of the naive argument: the weight is unit but the Apéry residue can still have positive p-adic valuation.

Thus the implication

```
unit weight => Gamma_n not divisible by p
```

is false without an additional residue theorem.

## 3. Prime-power split

The unconditional decomposition is

```
log Gamma_n
= sum_{p<=n/2} min_j(v_p(L_j)+v_p(b_j)) log p
  + sum_{n/2<p<=n} min_j(...) log p.
```

The second range is controlled by the already established top-half support theorem:

```
p|Gamma_n iff p|b_(n-p),
```

and the valuation is one for `p>=5`.

The unresolved contribution is therefore the small-prime range

```
S(n)=sum_{p<=n/2} v_p(Gamma_n)log p.
```

Bounding this by `log b_n` is only a linear bound and gives no progress.

## 4. Exact computational audit

The supplied cutoff data through `n=1200` were reproduced conceptually by the valuation decomposition:

- range checked: `4 <= n <= 1200`
- all prime divisors tested through the support range
- top-half primes match the known criterion
- no extra primes above `n` appear
- worst prime-power contributions are concentrated among small primes

The dominant issue is not the number of primes but repeated valuations at small primes. Radical containment alone loses the multiplicity information.

## 5. Corpus audit

The existing top-quarter `n=4K` results cannot be imported: the cutoff and weight system are different. The exact half-cutoff family requires the two-binomial Kummer geometry above.

The known radical containment

```
rad(Gamma_n)|b_n
```

is insufficient for a height estimate because `b_n` itself has exponential size.

## 6. Remaining obstruction

A successful proof would need one of the following genuinely new inputs:

1. a bounded collection of carry-free indices forcing a p-adic unit Apéry residue for every small prime;
2. a Dwork/Lucas lifting theorem controlling the minimum

```
min_j(v_p(L_j)+v_p(b_j));
```

3. a new relation between the half-cutoff content and a lower-height carrier.

The present route establishes the exact valuation framework and isolates the obstruction but does not prove `log(Gamma_n)=o(n)`.
