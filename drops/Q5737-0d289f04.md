## Verdict

The bounded-order recurrence gives a clean, exact global reduction, but it does **not** give the required sublinear interval-prime radical.

Let

\[
Y_d=C_M(d),\qquad
A=G_{D-1,N}(Y),\qquad
B=\binom{D+N}{N}.
\]

For primes

\[
\mathfrak P_I=\{p\text{ prime}:D+1\le p\le D+N\},

\[
A\equiv Y_{p-1}\pmod p.

\[
\operatorname {rad}_{\mathfrak P_I}\gcd(A,B)
=
\prod_{\substack{p\in\mathfrak P_I\\p\mid Y_{p-1}}}p,
\tag{0.1}

exactly the target product.

\[
\boxed{\quad A=g_{\rm rec}\,E,\quad}
\tag{0.2}

* \(g_{\rm rec}\) is the exact determinantal divisor coming from the recurrence lattice and the Newton row;

There is then an exact gcd identity

\[
\boxed{
\gcd(A,B)
=c\,\gcd\!\left(E,\frac{B}{c}\right),
\qquad
c=\gcd(g_{\rm rec},B).

\tag{0.3}

After all recurrence and Newton presentation content is saturated, the surviving interval-prime condition is still

\[

# 5. Exact observability/controllability Smith identity

Let

\[
\delta_j(T)=\gcd\{j\times j\text{ minors of }T\}.
\]

Define the augmented matrix

\[
K_w=
\begin{pmatrix}
K\\w
\end{pmatrix}.
\tag{5.1}

## Theorem 5.1 — exact determinantal-divisor formula

Let \(K\in M_{m\times n}(\mathbb Z)\) have rank \(m<n\), and let \(w\in\mathbb Z^{1\times n}\). Put

\[
\boxed{
 g_{\rm rec}
 =
 \frac{\delta_{m+1}(K_w)}{\delta_m(K)}.
}
\tag{5.2}
\]

Then:

1. the quotient in (5.2) is an integer;
2. there is a primitive integral basis
   \[
   P\in M_{n\times(n-m)}(\mathbb Z)
   \]
   of \(\ker_{\mathbb Z}K\);
3. \(P\) can be completed to a unimodular matrix, hence has an integral left inverse \(Q\) with
   \[
   QP=I_{n-m};
   \tag{5.3}
   \]
4. there is a primitive row \(eta\in\mathbb Z^{1\times(n-m)}\) such that
   \[
   \boxed{\quad wP=g_{\rm rec}\beta.\quad}
   \tag{5.4}
   \]

Thus \(P\) is the full integral observability map from the free recurrence state to the \(N+1\) outputs, and \(Q\) is the exact integral state decoder/controllability left inverse.

### Proof

Take Smith form

\[
UKV=
\begin{pmatrix}
\operatorname {diag}(s_1,\ldots,s_m)&0
\end{pmatrix}
\tag{5.5}
\]

with \(U,V\) unimodular. Write

\[
wV=(a\mid b),\qquad b\in\mathbb Z^{n-m}.
\tag{5.6}
\]

The last \(n-m\) columns of \(V\) form \(P\), and \(wP=b\). Every nonzero \((m+1)\)-minor of

\[
\begin{pmatrix}
\operatorname {diag}(s_1,\ldots,s_m)&0\\
a&b
\end{pmatrix}
\]

must use all \(m\) pivot columns and one null column. Hence

\[
\delta_{m+1}(K_w)
=(s_1\cdots s_m)\gcd(b_1,\ldots,b_{n-m})
=\delta_m(K)\gcd(b).
\tag{5.7}
\]

This proves (5.2)--(5.4). ∎

Apply the theorem to the actual shell vector \(x\). Since \(x=Pz\) for a unique integral state coordinate \(z=Qx\),

\[
A=wx=wPz=g_{\rm rec}\beta z.
\tag{5.8}
\]

Define

\[
\boxed{E=\beta z.}
\tag{5.9}
\]

This proves the exact factorization (0.2).

Because \(eta\) is primitive, there exists \(U_0\in\operatorname {GL}_{n-m}(\mathbb Z)\) such that

\[
\beta U_0=e_1^T.
\tag{5.10}
\]

After this unimodular state change, \(E\) is literally the first coordinate of the distinguished recurrence state. This is the strongest possible integral Bezout normalization: no coefficient content remains in the observation.

# 7. Which interval primes can enter \(g_{\rm rec}\)?

Let \(p\in\mathfrak P_I\). Suppose every leading and trailing coefficient needed to move across the block is a \(p\)-unit:

\[
p\nmid\Sigma_+(M;J)\Sigma_-(M;J).
\tag{7.1}
\]

Then the companion transition is invertible modulo \(p\) in both directions. Every shell coordinate in the block is a nonzero linear functional on the free recurrence state. But modulo \(p\), the Newton row is exactly the coordinate \(Y_{p-1}\). Therefore it does not annihilate the full recurrence solution space, and

\[
p\nmid g_{\rm rec}.
\tag{7.2}
\]

Hence

\[
\boxed{
\operatorname {rad}_{I}(g_{\rm rec})
\mid
\operatorname {rad}_{I}
\bigl(\Sigma_+(M;J)\Sigma_-(M;J)\bigr).
}
\tag{7.3}
\]

This is the complete singular-factor classification supplied by bounded order. It is exact but not yet an \(o(N)\) estimate. Each recurrence endpoint polynomial has fixed degree and values of polynomial height \(M^{O(1)}\); over \(O(N)\) shifts the naive ledger is

\[
\log\left|
\Sigma_+\Sigma_-
\right|=O(N\log M).
\tag{7.4}
\]

Even its interval-restricted radical is only bounded a priori by \(O(N\log M)\). Factoring the endpoint polynomials is necessary to delete target-free shifts, but bounded degree alone gives no little-oh saving.

Importantly, even granting the strongest favorable conclusion

R_{\rm sing}=1,
\tag{7.5}

one is left with

\[
R_I=\operatorname {rad}_{I}\gcd(E,B).
\tag{7.6}

This is still the target product.

# 10. Height and radical ledger

Let \(ho_0\le39\) be fixed and \(N\to\infty\).

## 10.1 Recurrence matrix

The recurrence coefficients have fixed polynomial degree and fixed coefficient height as polynomials in \(M,d\). On a first-cell block their evaluated logarithmic height is \(O(\log M)\). The matrix \(K\) has \(O(N)\) rows and fixed bandwidth, so Hadamard gives

\[
\log|\det K_J|=O(N\log M)
\tag{10.1}
\]

for every maximal minor. The same bound holds for the minors of \(K_w\), because the Newton row has

\[
\log\|w\|_\infty=O(N\log M).
\tag{10.2}
\]

Thus

\[
\log g_{\rm rec}=O(N\log M)
\tag{10.3}
\]

is the natural generic determinant ledger. This is far above \(o(N)\).

The point of (7.3) is that the **restricted** interval radical of \(g_{\rm rec}\) can be charged only to explicitly factored recurrence singularities. But bounded degree alone still gives at best \(O(N\log M)\), and no uniform cancellation theorem for those singular values is currently proved.

## 10.2 Binomial endpoint integer

For \(D\asymp M\) and \(N=M^{1/3+o(1)}\),

\[
\log B
=
N\log(D/N)+O(N)
=\Theta(N\log M).
\tag{10.4}
\]

The interval-prime part is squarefree by (2.6). Controlling it is exactly controlling how many marked interval coordinates vanish.

## 10.3 Primitive residual

The residual \(E=\beta z\) is one primitive coordinate, but its integer height is not small. It can be as large as the original exponentially tall shell carrier:

\[
\log|E|=O(M)
\tag{10.5}
\]

is all that follows from the current coefficient bounds. Primitivity controls universal content, not prime support of the distinguished value.

Therefore the exact recurrence reduction changes the ledger from

\[
\gcd(A,B)
\]

to

\[
\text{explicit singular content}\times
\gcd(\text{one primitive state coordinate},B),
\]

but the second factor still has no sublinear radical theorem.

# 11. Why no observability determinant closes the target

Modulo a good interval prime \(p\), the target is one primitive linear equation

\[
\tau_p(z)=0.
\tag{11.1}
\]

After the Smith normalization above, \(E\) is exactly such a primitive linear coordinate. Adding recurrence rows does not add equations on \(z\); those rows merely define the recurrence solution space. Adding further universally target-preserving observations gives rows in

\[
\mathbb Z_{(p)}\tau_p+pV^\vee,
\]

so every \(k\)-row determinant carries \(p^{k-1}\), as proved in Section 63. Dividing those powers out removes target-forcedness.

The global matrix calculation therefore agrees exactly with the local rank-one no-go:

* recurrence rows compress the ambient \(N+1\) shell coordinates to at most \(39\) state coordinates;
* Smith saturation removes all universal recurrence content;
* one primitive marked coordinate remains;
* the target is the vanishing of that coordinate.

There is no contradiction between bounded order and the failure of the radical estimate. Bounded order is a dimension statement; the desired theorem is arithmetic anti-concentration for one distinguished state.

# 13. Exact audit code for the Smith identity

The following Sage code verifies Theorem 5.1 for any supplied scalar recurrence coefficient list. It uses exact integer arithmetic only.

```python
from itertools import combinations
from math import gcd, comb


def gcd_list(xs):
    g = 0
    for x in xs:
        g = gcd(g, abs(ZZ(x)))
    return g


def determinantal_divisor(A, k):
    """Exact gcd of all k-minors; intended for audit-size matrices."""
    if k == 0:
        return ZZ(1)
    vals = []
    for rows in combinations(range(A.nrows()), k):
        for cols in combinations(range(A.ncols()), k):
            vals.append(A.matrix_from_rows_and_columns(rows, cols).det())
    return gcd_list(vals)


def newton_row(D, N):
    return vector(ZZ, [
        (-1)**i * ZZ(comb(D - 1 + i, i)) * ZZ(comb(D + N, N - i))
        for i in range(N + 1)
    ])


def recurrence_matrix(coeff, D, N):
    """
    coeff(d) returns [c_0(d),...,c_rho(d)] for
        sum_j c_j(d) Y_{d+j}=0.
    """
    rho = len(coeff(D - 1)) - 1
    n = N + 1
    m = n - rho
    assert m > 0
    K = matrix(ZZ, m, n)
    for t in range(m):
        row = coeff(D - 1 + t)
        for j, c in enumerate(row):
            K[t, t + j] = ZZ(c)
    return K


def smith_observation_audit(coeff, D, N, shell_values):
    K = recurrence_matrix(coeff, D, N)
    w = newton_row(D, N)
    x = vector(ZZ, shell_values)
    assert K * x == 0
    A = w * x

    m = K.nrows()
    d0 = determinantal_divisor(K, m)
    Kw = K.stack(matrix(ZZ, 1, K.ncols(), list(w)))
    d1 = determinantal_divisor(Kw, m + 1)
    assert d1 % d0 == 0
    g_rec = d1 // d0

    # Exact integer kernel basis.  In Sage, the kernel lattice is saturated.
    P = K.right_kernel_matrix().transpose()
    b = w * P
    assert gcd_list(b) == g_rec

    beta = vector(ZZ, [ZZ(z // g_rec) for z in b])
    assert gcd_list(beta) == 1

    # Solve x=P*z over ZZ.
    z = P.solve_left(x)
    assert P * z == x
    E = beta * z
    assert A == g_rec * E

    B = ZZ(comb(D + N, N))
    c = gcd(abs(g_rec), abs(B))
    assert gcd(abs(A), abs(B)) == c * gcd(abs(E), abs(B // c))

    return {
        "A": A,
        "B": B,
        "g_rec": g_rec,
        "E": E,
        "c": c,
    }
```

For production-size \(N\), replace enumeration of minors by Smith/Hermite normal form; the identities are unchanged.

# Final conclusion

The proposed global bounded-order attack is worth carrying out because it gives the exact decomposition

\[
\gcd(A,B)
=
\text{recurrence singular content}
\times
\gcd(\text{one primitive distinguished-state coordinate},\text{remaining }B).
\]

But this is the cut line:

* **proved:** full recurrence compression, exact observability/controllability lattice, exact determinantal-divisor ratio, exact gcd/Bezout reduction, complete endpoint-factor classification, and target-prime removal from augmented state content;
* **not proved:** any \(o(N)\) bound for the interval-prime radical of the primitive residual \(E\);
* **explicit surviving non-target factor:** \(73\) for \(M=146\), arising simultaneously from Cartier state content and the endpoint multiple \(2p=146\) in \(B\).

So the bounded recurrence removes presentation dimension and universal content, but it does not remove the final marked scalar. A new distinguished-state arithmetic lemma of the form (12.1) is still necessary.
