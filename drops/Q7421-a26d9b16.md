## 2. Discriminant I: is the structured interface actually sharp?

The present `R2` and `V_R` alone do not distinguish a one-prime finite diagonal from a genuinely populated coherent square. Add the following four moments.

### 2.1 Uncentered diagonal and cross energies

Define

\[
R_{2,\mathrm{diag}}
 :=\sum_{q,t}\sum_p r_{p,q,t}^2,
\tag{2.1}
\]

and

\[
R_{2,\mathrm{cross}}
 :=\sum_{q,t}\sum_{p\ne p'}r_{p,q,t}r_{p',q,t}.
\tag{2.2}
\]

The implementation should accumulate only (2.1) and obtain (2.2) by subtraction:

```text
R2_cross = R2 - R2_diag.
```

This fixes the ordered/unordered convention automatically. Since the union-corrected baseline contributions are nonnegative, `R2_cross` must be nonnegative up to the existing numerical tolerance.

### 2.2 Centered diagonal and cross energies

For each fixed `(q,p)` accumulate

```text
rp_sum[q,p] = sum_t r[p,q,t]
rp_sq [q,p] = sum_t r[p,q,t]^2.
```

Then define

\[
V_{R,\mathrm{diag}}
 :=\sum_{q,p}
 \left(
   \sum_t r_{p,q,t}^2
   -\frac1q\left(\sum_t r_{p,q,t}\right)^2
 \right),
\tag{2.3}
\]

and

```text
VR_cross = V_R - VR_diag.
```

Unlike `R2_cross`, `VR_cross` can have either sign: centering can create negative covariance between two structured prime profiles. Its sign is itself informative and must not be clipped to zero.

### 2.3 Exact interface Cauchy envelope

On each row let

```text
n = nR[q,t]
s2 = sum_p r[p,q,t]^2.
```

Accumulate

\[
I_{\mathrm{face},2}
 :=\sum_{q,t} n\,s2.
\tag{2.4}
\]

The rowwise Cauchy inequality gives

\[
R(q,t)^2\le n\sum_p r_{p,q,t}^2,
\]

hence

\[
0\le V_R\le R2\le I_{\mathrm{face},2}.
\tag{2.5}
\]

Here `n` is the number of nonzero `r` contributions, not the number of all primes in the interval. There is an exact row identity

\[
n\sum_p r_p^2-\left(\sum_p r_p\right)^2
 =\sum_{p<p'}(r_p-r_{p'})^2,
\tag{2.6}
\]

where the pair sum ranges over the `n` nonzero contributions. Thus `Iface2-R2` measures precisely the loss in the first interface Cauchy step; it is not an arbitrary comparison scale.

Emit

```text
diag_share       = R2_diag/R2
cross_share      = R2_cross/R2
centered_share   = V_R/R2
cauchy_eff       = R2/Iface2
structured_eff   = V_R/Iface2
```

when the denominators are nonzero. The factorization

```text
structured_eff = centered_share * cauchy_eff
```

shows whether a loss comes from row centering or from incoherent nonzero prime weights.

### 2.4 Interpretation

A finite scan has entered an **interface-sharp structured regime** only if all three features are visible:

```text
R2_cross/R2 is not negligible;
V_R/R2 is not negligible;
R2/Iface2 is not negligible.
```

If `R2_diag/R2` is near one, the scan is still a one-prime diagonal experiment. If `V_R/R2` is small, most of `R` is a row mean and centering is already effective. If `R2/Iface2` is small, the current interface bound is loose before any arithmetic cancellation is invoked.

Do not fit an exponent to `V_R` until `R2_cross` is populated. A diagonal-dominated value can fall below a target normalization for a completely irrelevant finite reason.

## 3. Discriminant II: a real second-factorial prime-window saving

This addition is entirely combinatorial and exact. It requires no Apéry zero test.

### 3.1 Exact union-window endpoints

For fixed `T,J`, put

```text
A_T = floor(T/7)+1
B_T = floor(T/3)
h_T = floor(T/J)
```

and, for every q-prime row `(q,t)`, compute

```text
L      = max(A_T, floor((6*q+t)/7)+1)
Ccap   = min(B_T, q-h_T-1)
Uminus = min(Ccap, q-t-1)
Uplus  = min(Ccap, floor((12*q+t)/13))
Uunion = max(Uminus, Uplus).
```

The common lower endpoint and the proved nesting make

```text
N = max(0, Uunion-L+1)
P = # {prime p : L <= p <= Uunion}
```

exact. Here `P=Pgeom[q,t]`, whether or not the Apéry zero set modulo `p` is empty. Use a prime prefix table or `bisect` on the existing prime list; do not loop over the interval a second time.

Also compute the sign counts for validation:

```text
Pminus, Pplus, Pintersection.
```

Require rowwise

```text
Punion        = max(Pminus,Pplus)
Pintersection = min(Pminus,Pplus).
```

### 3.2 Four integer accumulators

For all rows and for each occupancy bin, accumulate

\[
S_{N,1}=\sum N,
\qquad
S_{P,1}=\sum P,
\tag{3.1}
\]

\[
S_{N,2}=\sum N(N-1),
\qquad
S_{P,2}=\sum P(P-1).
\tag{3.2}
\]

`S_P2` counts ordered pairs of **distinct numerical primes**. It removes the same-prime diagonal exactly; this is the quantity that a genuine second logarithm must affect.

Report both the conventional log-normalized diagnostics

\[
\mathrm{OccP1}
 =\log T\,\frac{S_{P,1}}{S_{N,1}},
\qquad
\mathrm{OccP2}
 =(\log T)^2\,\frac{S_{P,2}}{S_{N,2}},
\tag{3.3}
\]

and the log-free finite ratio

\[
\boxed{
\kappa_{\mathrm{win},2}
 :=
 \frac{S_{P,2}/S_{N,2}}
      {(S_{P,1}/S_{N,1})^2}
 =
 \frac{S_{P,2}S_{N,1}^2}
      {S_{N,2}S_{P,1}^2}.}
\tag{3.4}
\]

Emit the numerator and denominator in (3.4) as exact integers before converting to a decimal. This avoids creating an apparent second-log effect merely by choosing a normalization.

### 3.3 Necessary strata

A global `S_P2` can be dominated by many empty/singleton rows or by one large row. Use the same small set of bins as the earlier design:

```text
lambda = N/log(T)

lambda < 0.5
0.5 <= lambda < 2
2 <= lambda < 8
lambda >= 8.
```

For each bin emit

```text
rows
N1, P1, N2, P2
rows_with_P_ge_2
max_row_P2
max_row_P2/P2
OccP1, OccP2
pair_to_square_num, pair_to_square_den.
```

Only the `lambda>=2` bins meaningfully test a second-factorial law. A nonzero global `OccP1` with `P2=0` says only that finite windows are empty or singleton.

### 3.4 Exact validation identities

For every row and after aggregation require

```text
0 <= P <= N
0 <= P*(P-1) <= N*(N-1)

sum P^2 = S_P1 + S_P2
sum N^2 = S_N1 + S_N2.
```

On small validation shells compare the prefix-counted `P` with direct enumeration from the prime list.

### 3.5 Relation to the structured energy

The two ledgers answer different questions:

```text
S_P2 > 0
  says distinct geometric lower primes coexist in exact windows.

R2_cross > 0
  says at least two nonzero affine-density contributions coexist in
  the structured square.

VR_cross
  says whether that coexistence survives q-fibre centering.
```

A genuine prime-window second-factorial effect should first appear in `S_P2`, then in `R2_cross`. If `S_P2` is populated but `R2_cross` remains tiny, the loss is in zero-set availability, the Apéry density weights, or the overlap correction, not in prime-window occupancy.

## 4. Discriminant III: the actual Apéry upper-mark covariance

The scanner already knows the upper zero flag

```text
z[q,t] = 1_{q divides b_t}
```

and `Zq=sum_t z[q,t]`. Add direct centered covariances with all three vectors

```text
A, R, C=A-R.
```

### 4.1 Exact upper-selector energy

Define

\[
V_z
 :=\sum_q\left(Z(q)-\frac{Z(q)^2}{q}\right).
\tag{4.1}
\]

This is exactly

\[
\sum_{q,t}\left(z_q(t)-\frac{Z(q)}q\right)^2.
\]

### 4.2 Load covariance

For each q retain

```text
A1_q    = sum_t A[q,t]
Amark_q = sum_t z[q,t]*A[q,t].
```

The exact integer numerator of the q-block covariance is

\[
\boxed{
N_{zA}(q)
 :=q\,A^{\rm mark}_q-Z(q)A1_q.}
\tag{4.2}
\]

Then

\[
\mathrm{Cov}_{z,A}
 =\sum_q\frac{N_{zA}(q)}q
 =\sum_{q,t}
  \left(z_q(t)-\frac{Z(q)}q\right)A_q(t).
\tag{4.3}
\]

Store every `N_zA(q)` as an exact integer in the q-level CSV. The global sum can use the scanner's existing high-precision rational/decimal path.

The marked mass identity is

\[
M_{\rm mark}
 =\sum_q\frac{Z(q)}q A1_q
  +\mathrm{Cov}_{z,A}.
\tag{4.4}
\]

This is the direct finite measurement of actual Apéry marked covariance. It is not a variance proxy.

### 4.3 Structured and defect covariances

Similarly compute

\[
\mathrm{Cov}_{z,R}
 :=\sum_{q,t}
  \left(z_q(t)-\frac{Z(q)}q\right)R_q(t),
\tag{4.5}
\]

and

\[
\mathrm{Cov}_{z,C}
 :=\sum_{q,t}
  \left(z_q(t)-\frac{Z(q)}q\right)C_q(t).
\tag{4.6}
\]

The mandatory exact identity is

\[
\boxed{
\mathrm{Cov}_{z,A}
 =\mathrm{Cov}_{z,R}+\mathrm{Cov}_{z,C}.}
\tag{4.7}
\]

When the current scan has `A=0`, this reduces to

```text
CovZA = 0
CovZC = -CovZR.
```

That is a useful regression check immediately, even before a genuine event appears.

### 4.4 Correlations and Cauchy checks

Emit

\[
\mathrm{Corr}_{z,A}
 =\frac{\mathrm{Cov}_{z,A}}{\sqrt{V_zV_{\rm up}}},
\tag{4.8}
\]

\[
\mathrm{Corr}_{z,R}
 =\frac{\mathrm{Cov}_{z,R}}{\sqrt{V_zV_R}},
\qquad
\mathrm{Corr}_{z,C}
 =\frac{\mathrm{Cov}_{z,C}}{\sqrt{V_zV_{\rm aff}}},
\tag{4.9}
\]

whenever the denominators are positive. Validate

\[
|\mathrm{Cov}_{z,A}|^2\le V_zV_{\rm up},
\tag{4.10}
\]

\[
|\mathrm{Cov}_{z,R}|^2\le V_zV_R,
\qquad
|\mathrm{Cov}_{z,C}|^2\le V_zV_{\rm aff}.
\tag{4.11}
\]

Also emit

```text
CovZA_L1 = sum_q |N_zA(q)|/q
CovZA_cancel = |CovZA|/CovZA_L1
```

and the largest q-block contributions. This separates a genuinely small covariance from cancellation among a few large q-blocks.

### 4.5 Optional factorial marked covariance

Once `F_pre` becomes nonzero, add the identical two-line calculation for

```text
B[q,t] = A[q,t]*(A[q,t]-1).
```

Namely,

```text
Fmean  = sum_q Zq/q * Fpre_q
CovZF  = Fmark - Fmean.
```

Do not add this machinery before `F_pre>0`; it is identically zero in the current regime. The first-order `CovZA` is the earliest observable actual marked-covariance diagnostic.

## 6. Do not guess the next T: add an exact first-hit probe

The present inverse event generator already reconstructs `(d,t,q)` from an ordered lower-zero pair. Split its predicates into:

```text
T,J-independent arithmetic geometry;
T-shell conditions;
long-gap condition J*d>T.
```

This produces an exact first-hit calculation with very little code.

### 6.1 T-independent candidate

For minus, from zeros `(a,r)`:

```text
d = (a+r+1)/7
t = d-a-1
q = p+d.
```

For plus, from zeros `(z,w)`:

```text
d = (z+w+1)/6
t = p-1-z-6*d
q = p+d.
```

Before mentioning `T` or `J`, require exactly:

```text
integrality of d;
d>0;
q prime;
0<=t<q;
the sign-specific literal lower window.
```

These are the same predicates as the current inverse scanner, merely reordered.

### 6.2 Exact T interval for one event

Fix such an event `e=(p,q,t,d)`. Because `q>p`, the two prime-shell conditions

\[
T/7<p,q\le T/3
\]

are equivalent, for integral `T`, to

\[
3q\le T\le7p-1.
\tag{6.1}
\]

The q6 row condition

\[
T<6q+t\le2T
\]

is equivalent to

\[
\left\lceil\frac{6q+t}{2}\right\rceil
\le T\le6q+t-1.
\tag{6.2}
\]

Finally

\[
d>T/J
\]

is equivalent to

\[
T\le Jd-1.
\tag{6.3}
\]

Therefore the exact admissible interval is

\[
\boxed{
T_{\min}(e)
 =\max\left\{3q,
  \left\lceil\frac{6q+t}{2}\right\rceil\right\},}
\tag{6.4}
\]

\[
\boxed{
T_{\max}(e;J)
 =\min\{7p-1,\ 6q+t-1,\ Jd-1\}.}
\tag{6.5}
\]

The event occurs at parameter `(T,J)` exactly when

```text
Tmin <= T <= Tmax(J).
```

In Python:

```python
def event_T_interval(ev, J):
    n = 6*ev.q + ev.t
    lo = max(3*ev.q, (n+1)//2)
    hi = min(7*ev.p-1, n-1)
    if J is not None:          # None = no long-gap cap, diagnostic only
        hi = min(hi, J*ev.d-1)
    return lo, hi
```

For a fixed `T`, the smallest integral J admitting the event is exactly

\[
\boxed{J_{\rm enter}(e;T)=\left\lfloor\frac{T}{d}\right\rfloor+1.}
\tag{6.6}
\]

Thus one uncapped inverse enumeration gives every finite-J scan by thresholding; there is no reason to rerun the Apéry zero computation for each J.

## 7. Smallest practical T,J schedule

The cheapest schedule is adaptive rather than a Cartesian grid.

### Stage 0: use the existing T=9600 cache

First run the no-gap/first-hit probe using exactly the lower-prime zero tables already computed through the `T=9600` scan. If the cache reaches the natural lower-prime ceiling

```text
p <= floor(9600/3)=3200,
```

it can already discover events whose first legal shell parameter is above 9600; no new lower-prime Apéry table is required for that probe.

Query the finite-J grid

```text
J = 24, 32, 48, 64, 96, 128, 192, 256
```

plus a diagnostic no-gap value `J=None`. If the current theorem imposes a different minimum admissible J, replace `24` by its first allowed integer. The no-gap row is diagnostic only and must not be mixed into a fixed-J fit.

If a T=9600 event exists, choose

```text
J_hit = max(J_allowed_min, min_e (9600//d_e + 1))
```

and rerun the full moments once at `(9600,J_hit)`. This is the exact smallest finite J at the already scanned T.

### Stage 1: exact first T before a larger full scan

If no T=9600 event exists, minimize `Tmin` from (6.4) over the cached candidates for each J. Run the full scanner at the returned exact `(T_hit,J_hit)`, not at an arbitrary dyadic endpoint.

This can locate a first event just above 9600 that a coarse shell list would miss.

### Stage 2: only then enlarge the lower-prime cache

If the current cache has no no-gap candidate at all, extend the cached lower-prime bound in the small sequence

```text
pmax = 4000, 4800, 6400,
```

which corresponds to the familiar nominal shell checkpoints

```text
T = 12000, 14400, 19200.
```

After each cache extension, run only the cheap first-hit probe and stop at the first exact event. There is no need to compute full `R2/V_R/V_aff` at all three checkpoints if the event appears earlier.

If the implementation cannot yet support interval probing, the smallest reasonable fallback grid is

```text
T = 12000, 14400, 19200
J = 64, 128, 256, no-gap,
```

with events generated once per T and filtered by `J_enter`; do not recompute zero sets per J. If all remain zero, continue with

```text
T = 28800, 38400
```

at the same fixed finite J values.

This schedule is a search heuristic, not an asymptotic prediction. Its justification is purely computational: it reuses the current cache, tests whether J is the obstruction before increasing T, and stops at the first exact event.

### Stage 3: hold J fixed after the first hit

Once a finite `J_hit` is chosen, hold it fixed for all subsequent T comparisons. A J sweep is useful for locating finite events, but pooling different J values into one slope or trend would change the family being measured.

The first three milestones should be reported separately:

```text
first M_pre>0               at least one genuine pre-upper event
first M_mark>0              at least one actual upper-marked event
first F_pre>0               at least two distinct lower primes in one state.
```

Only the third milestone activates the actual collision statistic. Only the second activates a nontrivial observed marked mass. They need not occur at the same `(T,J)`.

## 8. Minimal Python patch shape

The extension should fit around the existing `Event` and `run_shell` logic.

### 8.1 Small accumulator records

```python
@dataclass
class WindowMoments:
    rows: int = 0
    n1: int = 0
    p1: int = 0
    n2: int = 0
    p2: int = 0
    rows_p_ge_2: int = 0
    max_row_p2: int = 0

    def add(self, n: int, p: int) -> None:
        assert 0 <= p <= n
        self.rows += 1
        self.n1 += n
        self.p1 += p
        self.n2 += n*(n-1)
```
