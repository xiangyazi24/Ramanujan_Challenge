## 5.3 Scope

The determinant `(5.5)` is a coefficient-module obstruction.  It rules out identities generated coefficientwise from a bounded part of the first ghost and the universal Strehl transform.

It does not prove that the fixed numerical Franel sequence admits no exceptional all-depth cancellation using its own P-recursive structure.  Such a cancellation would be genuinely new and is outside the fixed-depth ghost architecture audited here.

# 6. Height of the untruncated first ghost

A possible response to `(5.7)` is to retain the whole first ghost.  Its characteristic-zero coefficient height is already linear.

At the top degree \(R+p\), `(1.4)` gives

\[
[x^{R+p}]A_{R,p}
=rac{(-1)^{R+p}F_{R+p}+2(-1)^RF_R}{p}.
	ag{6.1}
\]

For odd \(p\),

\[
[x^{R+p}]A_{R,p}
=(-1)^Rrac{2F_R-F_{R+p}}p.

The elementary central-binomial bounds

\[

\le F_n

give

\[
oxed{

Consequently

\[
oxed{

=(R+p)\log8+O(\log(R+p)).

	ag{6.4}

On the q=6 core, \(p\asymp m\), so this is \(\Omega(m)\).

Thus the first ghost has a precise dichotomy:

- keep only a fixed number of coefficients: obtain the nonzero low-height scalar \(E_D(m)\), but miss the nonzero coordinate `(5.6)`;
- retain the whole ghost: the natural characteristic-zero ghost already contains coefficients of linear logarithmic height.

A successful \(o(m)\) theorem would therefore need a new cancellation theorem for the high ghost blocks after projection.  Dwork divisibility by itself supplies no such Archimedean cancellation.

# 7. Reproducible exact checker

The following standard-library checker verifies:

1. coefficientwise integrality of the corrected raw ghost;
2. the low-degree identity \(\mathfrak G_{R,p}\equiv D_R/P_R\);
3. the Franel-tail left inverse and the exact ghost projection `(3.10)`;
4. the quotient-six collapse `(2.11)`;
5. the prime-independent integer `(V4)`;
6. the nonzero top-coordinate determinant `(5.5)`.

It uses the actual target fixture

```text
m=105, p=17, j=3, H=1,
sigma4=2, sigma7=6,
X4=27, X7=16,
K4=15, K7=8,
```

for which \(17\mid b_3=1445\) and

\[
\sigma_4+4K_4=\sigma_7+7K_7=62.
\]

```python
from fractions import Fraction
from math import comb, factorial


def choose(n: int, k: int) -> int:
    return 0 if k < 0 or k > n else comb(n, k)


def franel(n: int) -> int:
    return sum(comb(n, a) ** 3 for a in range(n + 1))


def poly_mul(a, b):
    out = [Fraction(0)] * (len(a) + len(b) - 1)
    for i, x in enumerate(a):
        for j, y in enumerate(b):
            out[i + j] += x * y
    return out


def pad(a, n):
    return list(a) + [Fraction(0)] * (n - len(a))


def period(R: int):
    return [Fraction((-1) ** k * comb(R, k) * franel(k))
            for k in range(R + 1)]


def corrected_raw_ghost(R: int, p: int):
    left = period(R + p)
    p1xp = [Fraction(1)] + [Fraction(0)] * (p - 1) + [Fraction(-2)]
    right = poly_mul(period(R), p1xp)
    n = max(len(left), len(right))
    left, right = pad(left, n), pad(right, n)
    diff = [left[i] - right[i] for i in range(n)]
    assert all(x.denominator == 1 and x.numerator % p == 0 for x in diff)
    return [Fraction(x.numerator // p) for x in diff]


def series_div(num, den, N: int):
    num = pad(num, N + 1)
    den = pad(den, N + 1)
    assert den[0] == 1
    out = [Fraction(0)] * (N + 1)
    for n in range(N + 1):
        out[n] = num[n] - sum(den[i] * out[n - i]
                              for i in range(1, n + 1))
    return out


def theta(a):
    return [Fraction(n) * a[n] for n in range(len(a))]


def binom_parameter_derivative(R: int, k: int) -> Fraction:
    if k == 0:
        return Fraction(0)
    if k <= R:
        return Fraction(comb(R, k)) * sum(
            Fraction(1, R - u) for u in range(k)
        )
    return Fraction((-1) ** (k - R - 1), k * comb(k - 1, R))


def parameter_derivative_series(R: int, N: int):
    return [Fraction((-1) ** k * franel(k))
            * binom_parameter_derivative(R, k)
            for k in range(N + 1)]


def normalized_ghost(R: int, p: int, N: int):
    p1xp = [Fraction(1)] + [Fraction(0)] * (p - 1) + [Fraction(-2)]
    den = poly_mul(period(R), p1xp)
    return series_div(corrected_raw_ghost(R, p), den, N)


def mod_fraction(x: Fraction, p: int) -> int:
    assert x.denominator % p
    return x.numerator * pow(x.denominator, -1, p) % p


def lagrange_derivative_weight(K: int, r: int, t: int) -> Fraction:
    assert 0 <= r < K and 0 <= t < K
    if t == r:
        return (sum(Fraction(1, r - u) for u in range(K) if u != r))
    return Fraction(
        (-1) ** (r - t) * factorial(r) * factorial(K - 1 - r),
        factorial(t) * factorial(K - 1 - t) * (r - t),
    )


def strehl(n: int, k: int) -> int:
    return 0 if k > n else comb(n, k) * comb(n + k, k)


def psi(s: int, sigma: int, K: int, r: int, k: int) -> Fraction:
    return sum(
        lagrange_derivative_weight(K, r, t) * strehl(sigma + s * t, k)
        for t in range(K)
    )


def qpoly(k: int):
    q = [Fraction(1)]
    for a in range(k):
        q = poly_mul(q, [Fraction(-a * (a + 1)), Fraction(1)])
    den = factorial(k) ** 2
    return [x / den for x in q]


def poly_eval(a, x):
    out = Fraction(0)
    for c in reversed(a):
        out = out * x + c
    return out


def qprime(k: int, y: int) -> Fraction:
    q = qpoly(k)
    dq = [Fraction(i) * q[i] for i in range(1, len(q))]
    return poly_eval(dq, y)


def audit_row(m, p, sigma4, sigma7, K4, K7, R, D):
    assert m == 6 * p + (j := m - 6 * p)
    assert 0 <= j < p
    X4 = (m + 1 + sigma4) // 4
    X7 = (m + 1 + sigma7) // 7
    assert 4 * X4 == m + 1 + sigma4
    assert 7 * X7 == m + 1 + sigma7
    r4, r7 = 2 * p - X4, p - X7
    assert 0 <= r4 < K4 < p
    assert 0 <= r7 < K7 < p
    assert R < D < p
    assert 2 * D < min(K4, K7)

    # Corrected first ghost and its low-degree parameter derivative.
    ghost = normalized_ghost(R, p, D)
    dR = parameter_derivative_series(R, D)
    d_over_pR = series_div(dR, period(R), D)
    for k in range(D + 1):
        assert mod_fraction(ghost[k] - d_over_pR[k], p) == 0

    gamma = theta(ghost)
    hfull = theta(d_over_pR)
    dtrunc = [dR[k] if k <= R else Fraction(0) for k in range(D + 1)]
    chi = theta(series_div(dtrunc, period(R), D))
    z = [chi[k] - hfull[k] for k in range(D + 1)]
    assert all(z[k] == 0 for k in range(R + 1))
    assert all(x.denominator == 1 for x in z)
    for d in range(R + 1, D + 1):
        assert mod_fraction(z[d] + gamma[d] - chi[d], p) == 0

    # Exact Strehl rows and quotient-six collapse.
    rho = []
    for k in range(D + 1):
        rho_k = (
            psi(4, sigma4, K4, r4, k)
            - 5 * psi(7, sigma7, K7, r7, k)
        )
        rho.append(rho_k)
        expected = 31 * (2 * j + 1) * qprime(k, j * (j + 1))
        assert mod_fraction(rho_k - expected, p) == 0

    # Exact Franel-tail projection.
    lhs = sum(rho[k] * franel(k) for k in range(D + 1))
    rhs = sum(rho[k] * franel(k) for k in range(R + 1))
    rhs_ghost = rhs
    for d in range(R + 1, D + 1):
        alpha = sum(
            (-1) ** (R - i)
            * rho[i + d]
            * comb(i + d, i)
            * comb(d - 1, R - i)
            * franel(i)
            for i in range(min(R, D - d) + 1)
        )
        rhs += alpha * z[d]
        rhs_ghost += alpha * (-gamma[d] + chi[d])
    assert lhs == rhs
    assert mod_fraction(lhs - rhs_ghost, p) == 0

    # Prime-independent depth-D representative.
    ED = 31 * factorial(D) ** 2 * (2 * m + 1) * sum(
        qprime(k, m * (m + 1)) * franel(k)
        for k in range(1, D + 1)
    )
    assert ED.denominator == 1 and ED > 0
    assert mod_fraction(ED - factorial(D) ** 2 * lhs, p) == 0

    # Exact top-coordinate determinant in aligned geometry.
    assert sigma4 + 4 * K4 == sigma7 + 7 * K7
    N = sigma4 + 4 * K4
    a4 = lagrange_derivative_weight(K4, r4, K4 - 1) * comb(2 * (N - 4), N - 4)
    a7 = lagrange_derivative_weight(K7, r7, K7 - 1) * comb(2 * (N - 7), N - 7)
    assert a4 != 0 and a7 != 0 and a4 * a7 != 0
    assert psi(4, sigma4, K4, r4, N - 4) == a4
    assert psi(7, sigma7, K7, r7, N - 4) == 0
    assert psi(7, sigma7, K7, r7, N - 7) == a7


# Actual q=6 target: b_3=1445=17*85.
audit_row(
    m=105,
    p=17,
    sigma4=2,
    sigma7=6,
    K4=15,
    K7=8,
    R=1,
    D=3,
)
print("PASS: corrected ghost, Strehl projection, and top determinant")
```

The checker verifies identities for a concrete target, but the proofs above are symbolic and do not infer an all-row theorem from this fixture.
