# Q818: LGTQ-2 rectangle average reduction hostile audit

## Audit status

I could not verify the cited repository files (`problems/3.2/research/proofs/Q32_LGTQ2_RECTANGLE_AVERAGE_REDUCTION.md`, `Q32_LGTQ2_RECTANGLE_REDUCTION.md`, and `q32_lgtq2_rectangle_verify.py`) from the available GitHub view: the paths were not present in the accessible repository snapshot. Therefore I cannot certify the claimed proof as source-faithful. The following is a proof-level audit of the stated argument skeleton and identifies the exact obligations that must be discharged.

## 1. Path-forest matching skeleton

The intended reduction appears to be:

1. A rectangle contains two rows/columns of candidate transverse edges.
2. Consecutive selected starts form a path forest.
3. A large component supplies many adjacent gaps.
4. A variable-q-multiple gap `s` creates many consecutive matchings.
5. Counting rectangles containing a fully transverse configuration gives LGTQ-2.

The first numerical condition

```
J >= ceil(R/2)
```

is harmless if `J` is the number of usable starts after discarding one side of each collision. However it requires the discarded objects to be disjoint. A proof must explicitly state the matching graph and show maximum degree one (or bounded degree with the corresponding loss).

## 2. Adjacent gap estimate

The claim

```
there are at least (J-1)/2 gaps with s <= 2L/(J-1)
```

is valid only for gaps measured inside a path ordered by coordinate. If arbitrary selected edges are used, the argument fails: large jumps can be interspersed with short jumps. The proof must define the sorted path order.

The additional requirements are essential:

```
s > 0
s is a q-multiple
s != h
```

`s != h` cannot be treated as negligible. The forbidden value must remove at most one candidate gap per path component. Otherwise the matching family may collapse to the wraparound obstruction.

## 3. Four-corner distinctness

This is a nontrivial condition. A four-prime rectangle requires four distinct primes/corners. The proof must separately exclude:

```
p1=p2,
q1=q2,
p1=q2,
q1=p2.
```

The first two are usually ruled out by construction. The crossed equalities require a residue argument. They do not follow merely from selecting two adjacent gaps.

## 4. Non-transverse rectangle deletion

The statement:

> if a rectangle is not fully transverse it contains an aligned pair of gap <= h+s

is the critical combinatorial lemma.

It needs the exact meaning of aligned pair. In particular, the proof must show that every failure of transversality produces one of the counted aligned configurations; otherwise a rectangle can fail through a corner collision not represented by a gap.

## 5. Contamination multiplicity

The strongest claim is:

> within the selected variable-s consecutive-matching family a fixed aligned pair contaminates at most one rectangle.

This is the point where the argument is most fragile.

It is true only if rectangles are indexed by consecutive members of one fixed ordered matching chain. If rectangles may slide independently, the same aligned pair can lie in many rectangles.

A proof must exhibit an injection:

```
contaminated rectangle -> position of the aligned pair in the chain
```

with no two rectangles mapping to the same position.

Without this injection the deletion cost can be larger than O((h+S)^2).

## 6. O((h+S)^2) deletion

The deletion estimate requires a finite universe of possible bad gaps. The usual bound is plausible if:

```
0 < gap <= h+S
```

and each gap contributes O(1) aligned pairs.

However the quantifiers must be uniform:

```
for every admissible h,S,n,
#bad rectangles <= C(h+S)^2
```

A bound with C depending on the chosen matching family is insufficient for LGTQ-2.

## 7. Aggregate implication

The implication

```
aggregate o(n/log^2 n)  =>  LGTQ-2
```

requires a normalization check. The aggregate statement must count the same objects as the LGTQ-2 exceptional rectangles. If it only counts total aligned pairs, the conversion needs the contamination lemma above.

The missing factor is exactly the rectangle multiplicity of one aligned pair.

## 8. Pointwise versus averaged rectangle conditions

At abstract count scale:

```
pointwise LGTQ-RECT => averaged target
```

is true: a uniform bound on every rectangle immediately bounds the average.

The converse is false.

Counterexample: let there be M rectangles. Put all excess mass into one rectangle with value M, and zero elsewhere. The average remains O(1), while the pointwise maximum is unbounded.

Therefore averaged LGTQ-RECT cannot imply pointwise LGTQ-RECT without additional regularity.

## Verdict

The reduction is not yet certified from the stated outline. The likely first fatal gap is the contamination lemma:

```
a fixed aligned pair contaminates at most one rectangle
```

because it is exactly what converts pair counts into rectangle counts. If this is proved by a rigid consecutive-chain indexing argument, the remainder of the reduction is plausible after checking constants. If rectangles overlap in the original definition, the statement is false and an explicit multiplicity counterexample exists.

The sharpest improvement is to formulate and prove the missing injective charging lemma first. It should be isolated independently from LGTQ-2 and should include all quantifiers over h, S, q, and the chosen matching family.
