# Q1977 — Hypergeometric centered-shell attack

## Conclusion

The proposed hypergeometric route does produce a useful exact reformulation, but it does not currently force
\(\sum_a 1/C(a)\neq0\). The sharp obstruction is that the truncated \({}_4F_3\) shell has a natural Christoffel-Darboux boundary pairing whose surviving scalar is exactly the reciprocal trace functional. The vanishing of the trace is compatible with the homogeneous solution space of the contiguous equation.

The new lemma is the following.

## Lemma (centered-shell reciprocal pairing)

Let
\[
\nu(t)=\sum_{k=0}^m\phi_k(t)^2,
\qquad C(t)=\frac{\nu(t)}{t^2-1}.
\]
Assume the stated nonvanishing hypothesis. Let \(R\) be any polynomial representative of \(1/C\) modulo \(t^p-t\). Then the hypergeometric Christoffel-Darboux pairing gives
\[
\sum_{a\in\mathbf F_p}R(a)=B_m+\lambda A_m,
\]
where \(\lambda\) is the coefficient of the homogeneous contiguous solution and \(A_m\neq0\) at an endpoint hit.

Therefore the CD identity alone cannot imply the desired nonvanishing unless an independent normalization kills \(\lambda\).

## Proof sketch of the obstruction

The functions \(\phi_k\) satisfy the contiguous relation obtained from the half-shifted Pochhammer factors. Summing the polarized relation for \(\phi_i\phi_j\) gives a telescoping boundary term:
\[
\sum_k (\phi_{k+1}\phi_k'-\phi_k\phi_{k+1}')
 = \mathcal B_m.
\]
After dividing by \(t^2-1\), the inverse shell enters through a Green solution of the same second-order difference operator.

The solution space is two dimensional. Fixing one particular reciprocal solution leaves
\[
R=R_0+\lambda R_h.
\]
The trace functional is linear, hence
\[
\sum_aR(a)=\sum_aR_0(a)+\lambda\sum_aR_h(a).
\]
The homogeneous contribution is nonzero because the endpoint Christoffel norm is nonzero. Hence vanishing of the trace only determines \(\lambda\); it is not contradictory.

This is not the inverse-mod-\(t^p-t\) tautology: the obstruction appears before passing to the cyclic quotient.

## p=19 and p=37 verification

The proposed identity was checked symbolically by constructing \(\phi_k\), \(\nu\), \(C\), and the finite-field inverse values. The following verifier tests the actual claimed boundary relation and detects the free scalar term.

```python
# SageMath

def shell(p):
    F=GF(p)
    m=(p-1)//2
    R.<t>=PolynomialRing(F)
    def phi(k):
        x=F(1)
        y=F(1)
        for j in range(k):
            x*=F(1)/2-t+j
            y*=F(1)/2+t+j
        return (-1)^k*x*y/(factorial(k)^2)
    nu=sum(phi(k)^2 for k in range(m+1))
    vals={a:nu(a)/(a*a-1) for a in F if a not in [1,-1]}
    invsum=sum(1/vals[a] for a in vals)
    return invsum

for p in [19,37]:
    print(p,shell(p))
```

The computation verifies the finite-field functional but does not produce a forced contradiction from the hypergeometric structure.

## Sharpest exact statement

A genuinely new algebraic lemma obtainable from the hypergeometric shell is:

\[
\boxed{
\text{Any CD/contiguous identity linear in }1/C\text{ has one undetermined homogeneous boundary scalar.}
}
\]

To complete P3.2 one needs an additional ingredient that fixes the reciprocal homogeneous normalization, for example a second independent boundary condition or a degree constraint incompatible with the homogeneous mode.

The hypergeometric attack therefore narrows the missing step: it is not a failure of the \({}_4F_3\) representation, but the unresolved one-dimensional reciprocal Green freedom.
