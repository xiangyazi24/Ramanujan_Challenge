# Q6808: Logical downstream audit of FR_eta versus the fixed-n master bound

## Verdict

FR_eta is a within-prime statement. By itself it does not imply the fixed-n Apéry gcd theorem. The apparent contradiction disappears once the quantifiers are separated.

The fixed-prime statement has the shape

```text
for every prime p:
    the zero/collision set Z_p is vertically sparse inside F_p.
```

The master theorem needs

```text
for every n:
    the set of primes p > sqrt(n) with n mod p in Z_p is sparse.
```

The second statement is a diagonal intersection across different primes. No amount of information that only controls each vertical fibre separately prevents all those fibres from lining up on one diagonal.

Therefore:

```text
closing FR_eta alone would NOT prove G_n = exp(o(n)) for every n.
```

It can improve the within-prime energy exponent and can strengthen density-one arguments, but a genuine cross-prime input is still required for the pointwise theorem.

## 1. Abstract obstruction: vertical sparsity does not control diagonal alignment

Let P be a set of primes. For each p choose an arbitrary subset Z_p of residues modulo p satisfying any desired per-prime conditions:

```text
|Z_p| <= p^(1-epsilon)
reflection symmetry:
    r in Z_p iff p-1-r in Z_p
bounded fibre multiplicity:
    each residue has multiplicity at most M
```

These conditions are all vertical: they inspect one modulus at a time.

Fix a large integer N. For every prime p in a window (N/2,N], define

```text
r_p = N mod p,
```

and put r_p into Z_p, together with its reflected partner. This creates a family with

```text
N mod p in Z_p
```

for every selected p, while still keeping each individual Z_p very small. The construction is not an Apéry construction; it is an implication counterexample showing that the hypotheses do not logically force the desired conclusion.

Hence the missing ingredient cannot be another vertical estimate. It must couple different primes.

## 2. Where the existing FR_eta fits

The shell first-return quantity controls objects such as

```text
#{ r : det(v_r,v_{r+d}) = 0 for some d in (D/2,D] }
```

for one fixed p. Improving the exponent from an energy argument is valuable because it reduces the possible size of Z_p or collision moments.

However, the target quantity is

```text
H(n) = #{ p in (sqrt(n), n] : n-p in Z_p }.
```

The residue n-p is not sampled independently from Z_p; it is a prescribed moving residue depending on p. The missing question is whether these prescribed residues can repeatedly hit exceptional locations in many different Z_p.

FR_eta answers the wrong quantifier pattern:

```text
fixed p, many possible r
```

whereas the master theorem asks:

```text
fixed n, many possible p.
```

## 3. Density-one versus every-n

Per-prime estimates can still give density-one results. The mechanism is averaging.

For example, if one proves a suitable bound on

```text
sum_{p <= X} |Z_p|,
```

then Markov gives that most n have few bad primes. This is consistent with the existing density-one theorem.

But the exceptional n can concentrate on rare diagonals. To remove all exceptional n one needs a maximal, not average, estimate.

## 4. Exceptional primes in a dyadic interval

Suppose a bad collection of primes E satisfies

```text
|E intersect (X,2X]| << X^(1-delta).
```

Its direct contribution to a gcd logarithm in the top window is bounded by

```text
sum_{p in E, X<p<=2X} 3 log p
    << |E| log X
    << X^(1-delta) log X.
```

Since the full prime window contributes scale X, this is

```text
X^(1-delta) log X = o(X).
```

Therefore a power-saving exceptional-prime estimate is enough to make those primes harmless in aggregate. It does not by itself prove that no individual n receives an accumulation from the remaining non-exceptional primes.

## 5. A genuine sufficient cross-prime condition

A suitable replacement for FR_eta is a falling-moment estimate in the n-aspect.

Let

```text
H(n;X) = #{ p in (X,2X] : n mod p in Z_p }.
```

A sufficient condition for a pointwise bound is a high falling-moment estimate such as

```text
sum_{N<n<=2N} (H(n;X))_k << N * o((X/log X)^k)
```

for some fixed k growing enough to dominate the desired maximum range, where

```text
(H)_k = H(H-1)...(H-k+1).
```

Indeed, (H(n;X))_k counts k-tuples of distinct primes whose prescribed residues simultaneously land in their zero fibres. Expanding gives

```text
sum_{p_1,...,p_k} #{ n : n mod p_i in Z_{p_i} for all i }.
```

A nontrivial upper bound on these multi-prime intersections is exactly the missing cross-prime theorem.

Equivalently, one needs control of correlations of the form

```text
Z_{p_1} x ... x Z_{p_k}
```

against the Chinese-remainder diagonal.

## 6. Relation to the Apéry chain

The existing Apéry results already supply strong vertical inputs:

```text
reflection of Z_p
no consecutive zeros
|Z_p| = O(p^(2/3))
uniform fibre bounds
collision-energy bounds
```

They explain density-one cancellation and reduce the search space. They do not eliminate coherent cross-prime alignment.

The missing theorem would be something like:

```text
for fixed k >= 2,
all but a negligible family of prime k-tuples satisfy
#{n in [N,2N] : n mod p_i in Z_{p_i} for every i}
<< N * product_i (|Z_{p_i}|/p_i)
plus a power-saving error.
```

This is a genuine independence/anti-alignment statement.

## Final audit statement

The two claims are compatible:

```text
(A) Breaking the 3/2 within-prime energy record is a gateway.
```

True: it improves the vertical geometry and may feed into stronger averages.

```text
(B) Per-prime vertical distribution alone cannot prove the pointwise theorem.
```

Also true: singleton or small-set alignment across primes survives all such bounds.

The correct conclusion is:

```text
FR_eta alone is insufficient for the every-n theorem.
FR_eta + a cross-prime falling-moment / anti-alignment theorem could prove it.
FR_eta can contribute to density-one G_n = exp(o(n)), but not by itself to pointwise G_n = exp(o(n)).
```
