# Q119 — p-adic denominator matching: the right theorem and the obstruction

## Short answer

Yes: this is the right direction, but the exact statement needs to be sharpened. The strongest plausible theorem is not simply

```
p | b_n, p > C  ==>  v_p(D_n)=v_p(d_n).
```

because the denominator of `a_n` is controlled by harmonic-sum cancellation, not directly by the zero set of `b_n`. The more natural target is a **local denominator matching theorem**:

```
p > n/2, p | b_n, p > C  ==>  v_p(d_n a_n)=0.
```

Equivalently,

```
v_p(D_n)=v_p(d_n).
```

for the top-window primes. This is exactly the missing statement needed to kill the top contribution to `G_n`.

---

## 1. Why the theorem would solve the conjecture

Recall

```
G_n = gcd(A_n, d_n b_n)
```

with `a_n=A_n/D_n` reduced. For a prime `p|b_n`, `p>n/2`, the top-window law gives

```
v_p(G_n) <= min(v_p(b_n),3).
```

The proposed strengthening is

```
v_p(G_n)=0
```

for all sufficiently large top-window primes.

Then only finitely many exceptional primes contribute, and

```
G_n^{top} <= C^{omega(n)}.
```

Since `omega(n)=O(log n/log log n)`, this gives

```
log G_n^{top}=o(n).
```

So this theorem would actually prove a much stronger bound than required.

---

## 2. The key local computation

The Casoratian identity gives

```
a_n b_{n+1}-a_{n+1}b_n=-6/(n+1)^3.
```

For `p>3`, `p|b_n`, and `p` not dividing the adjacent term `b_{n-1}`, one obtains

```
a_n = 6/(n^3 b_{n-1}) mod p.
```

Therefore

```
a_n != 0 mod p.
```

This proves that the numerator `A_n` is a p-adic unit:

```
v_p(A_n)=0.
```

The entire question becomes whether the denominator contributes the full lcm factor:

```
v_p(d_n)-v_p(D_n)=0?
```

If yes, the p disappears from `G_n`.

---

## 3. What is known about the denominator of a_n

The Beukers companion formula writes `a_n` as a binomial square sum with harmonic corrections:

```
a_n = sum_k B(n,k) H(n,k).
```

The only possible large denominators come from the harmonic pieces. Since

```
D_n | lcm(1,...,n)^3,
```

for `p>n/2` we have

```
v_p(d_n)=3.
```

Thus the question is extremely concrete:

```
Does the harmonic correction always leave a p^{-3} denominator
when p divides b_n?
```

The empirical observation that all known prime divisors of `G_n` are tiny strongly suggests yes.

---

## 4. A more realistic intermediate theorem

The absolute version may be too strong. A weaker statement is enough:

For every `epsilon>0`,

```
#{p>n/2 : p|b_n and v_p(G_n)>0} <= n^epsilon.
```

This already gives

```
log G_n^{top} <= 3 n^epsilon log n=o(n).
```

This suggests studying the exceptional set

```
E_n={p>n/2 : p|b_n and p|d_n a_n}.
```

rather than all top-window primes.

---

## 5. Possible route: use the recurrence modulo p^3

The strongest route is likely the Apéry block law. For `p>n/2`, write

```
n=p+r.
```

The known congruence gives

```
p^3 a_{p+r} == 6 b_r (mod p).
```

and

```
b_{p+r} == 5 b_r (mod p).
```

If `p|b_{p+r}`, then `p|b_r`. The same zero forcing that controls the numerator may force the exact p-adic denominator of `a_{p+r}`.

The missing lemma should be a refinement from mod `p` to mod `p^3`:

```
p^3 a_{p+r} / b_r
```

should be a p-adic unit whenever `b_r=0 mod p`.

This would directly imply denominator matching.

---

## 6. Verdict

The denominator matching theorem is probably the correct attack. However the clean formulation should be:

```
For sufficiently large p>n/2,

p|b_n  ==>  v_p(d_n a_n)=0.
```

or equivalently

```
p|b_n ==> p not dividing G_n.
```

A proof would likely require a new p-adic refinement of the Apéry block law, not just the existing Casoratian identity.

This is a much sharper target than bounding `K_top(n)`: it bypasses the hard large-prime counting problem completely. The numerical evidence is exactly what one would expect if the true mechanism is not scarcity of large prime divisors, but automatic denominator absorption.
