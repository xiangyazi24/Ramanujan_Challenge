# 2. Universal direct-window support theorem

Fix `H`, `a+b=H`, and a jointly primitive interpolation pair

```math
P_{H,a}(s)=b_sQ_{H,a}(s),
\qquad 0\le s\le H.
```

Let `p>H` be prime and define

```math
Z_p(H)=\{s\in\{0,\ldots,H\}:p\mid b_s\},
\qquad z_p(H)=\#Z_p(H).
```

Because `0,...,H` remain distinct modulo `p`, reduction modulo `p` is an
ordinary polynomial interpolation problem.

## Lemma 2.1: zero absorber

For every `0<=a<=H`,

```math
P_{H,a}\equiv0\pmod p
\quad\Longleftrightarrow\quad
z_p(H)>a.
```

### Proof

Every `s` in `Z_p(H)` is a root of `P_{H,a}` modulo `p`, since

```math
P_{H,a}(s)=b_sQ_{H,a}(s).
```

If `z_p(H)>a`, a polynomial of degree at most `a` has too many distinct
roots, so it is the zero polynomial.

Conversely, suppose `P_{H,a}` is zero modulo `p`.  Joint primitivity implies
that `Q_{H,a}` is not also the zero polynomial modulo `p`.  For every node
outside `Z_p(H)`, the value `b_s` is a unit, so `Q_{H,a}(s)=0`.  It therefore
has at least

```math
H+1-z_p(H)
```

distinct roots.  If `z_p(H)<=a`, this number is strictly larger than

```math
H-a\ge\deg Q_{H,a},
```

a contradiction.  This proves the equivalence.

If `z_p(H)<=a`, the nonzero polynomial `P_{H,a}` has all nodes in `Z_p(H)`
as roots and at most `a-z_p(H)` additional interpolation-node roots.  In
particular, for `a=z_p(H)` its roots among `0,...,H` are exactly `Z_p(H)`.

## Theorem 2.2: exact common-support criterion

Let `0<=A<=H`, let `p>H`, and suppose

```math
r\equiv n\pmod p,
\qquad 0\le r\le H.
```

Then

```math
\boxed{
 p\mid G_{H,A}(n)
 \quad\Longleftrightarrow\quad
 r\in Z_p(H)\ \text{or}\ z_p(H)>A.
}
```

### Proof

For every `d<=A<=H<p`, Vandermonde gives

```math
\binom{r+p}{d}\equiv\binom rd\pmod p,
```

and the same holds for `n` with residue `r`.  Hence

```math
P_{H,a}(n)\equiv P_{H,a}(r)\pmod p.
```

If `r` is a zero node, interpolation makes every `P_{H,a}(r)` zero.  If
`z_p(H)>A`, Lemma 2.1 makes every numerator of degree at most `A` the zero
polynomial.

For the converse, assume `r` is not a zero node and `z_p(H)<=A`.  Take
`a=z_p(H)`.  The last clause of Lemma 2.1 says that `P_{H,a}` has exactly the
zero nodes as interpolation-node roots, so `P_{H,a}(r)` is nonzero.  Thus
`p` cannot divide the family gcd.

## Canonical direct window

For

```math
H=\left\lfloor\frac{n-1}{3}\right\rfloor,
```

put

```math
\mathcal P_{n,H}
 =\{p\text{ prime}:n-H\le p\le n\}.
```

For every `p` in this window,

```math
p>H,
\qquad r=n-p\in[0,H].
```

Thus Theorem 2.2 becomes

```math
p\mid G_{H,A}(n)
\quad\Longleftrightarrow\quad
p\mid b_{n-p}\ \text{or}\ z_p(H)>A.
```

For `p>=7`, Apéry Lucas gives

```math
b_n=b_{p+r}\equiv b_1b_r=5b_r\pmod p,
```

so `5` is a unit and

```math
p\mid b_n\quad\Longleftrightarrow\quad p\mid b_{n-p}.
```

Define the direct target radical and the absorber-exception radical by

```math
R_{n,H}
 =\prod_{\substack{p\in\mathcal P_{n,H}\\p\mid b_{n-p}}}p,
```

```math
E_{n,H,A}
 =\prod_{\substack{p\in\mathcal P_{n,H}\\p\nmid b_{n-p}\\z_p(H)>A}}p.
```

Then the exact radical relation is

```math
\boxed{
 \operatorname{rad}_{\mathcal P_{n,H}}G_{H,A}(n)
 =R_{n,H}E_{n,H,A}.
}
```

Here `rad_P` means the product of primes in the indicated set which divide
the integer.  In particular, if

```math
A\ge\max_{p\in\mathcal P_{n,H}}z_p(H),
```

then

```math
\boxed{
 \operatorname{rad}_{\mathcal P_{n,H}}G_{H,A}(n)=R_{n,H}.
}
```

This is the strongest general theorem supplied by the near-full family.
It is a radical theorem, not `G|b_n` and not a valuation theorem.

# 3. Exact valuation identity and why no stronger relation follows

Write

```math
P_{H,a}(z)=\sum_{d=0}^a p_{a,d}\binom zd
```

with integral Newton coefficients.  For a direct-window prime `p` and
`n=p+r`, Vandermonde gives the exact integer identity

```math
\binom{r+p}{d}-\binom rd
 =p\sum_{t=1}^d
   \frac1p\binom pt\binom r{d-t},
```

where

```math
\frac1p\binom pt=\frac1t\binom{p-1}{t-1}\in\mathbf Z
\qquad(1\le t<p).
```

Define the Newton wrap term

```math
W_{a,p,r}
 =\sum_{d=1}^a p_{a,d}
   \sum_{t=1}^d
   \frac1p\binom pt\binom r{d-t}.
```

Interpolation at `r` then gives the exact formula

```math
\boxed{
 P_{H,a}(p+r)=b_rQ_{H,a}(r)+pW_{a,p,r}.
}
```

Consequently

```math
\boxed{
 v_p(G_{H,A}(p+r))
 =\min_{0\le a\le A}
   v_p\bigl(b_rQ_{H,a}(r)+pW_{a,p,r}\bigr).
}
```

If `p|b_r`, this is

```math
v_p(G_{H,A}(p+r))
 =1+\min_{0\le a\le A}
 v_p\left(\frac{b_r}{p}Q_{H,a}(r)+W_{a,p,r}\right).
```

On the Apéry side one only has the exact decomposition

```math
b_{p+r}=5b_r+pE_{p,r},
\qquad
E_{p,r}=\frac{b_{p+r}-5b_r}{p}\in\mathbf Z.
```

There is no finite-difference identity equating `E_{p,r}` with all of the
wrap terms `W_{a,p,r}`.  Their reductions modulo `p` give the same target
decision, but their higher valuations are independent cancellation
questions.

The coefficient-content theorem in `q32_pade_zero_absorber.py` is also not
an evaluation theorem.  If

```math
e_1\ge e_2\ge\cdots\ge e_{H+1}
```

are the sorted valuations `v_p(b_0),...,v_p(b_H)` for `p>H`, it gives

```math
v_p\bigl(\operatorname{content}_{\mathrm{Newt}}P_{H,a}\bigr)=e_{a+1}.
```

The extra term `pW_{a,p,r}` can still add an evaluation factor even when the
Newton coefficient content is a unit, or can cancel a higher node
valuation.  At the counterexample `p=17,H=6`, the only prefix zero is `s=3`
and `v_17(b_3)=2`; nevertheless the common evaluation valuation at `n=20`
is only one.

The current level-six packet audit contains the same warning in another
form: a packet coordinate attached to `(p,r)=(17,3)` and its first shell
have valuation one although `v_17(b_3)=2`.  Thus the level-six selector is
also intrinsically a target-support device, not a valuation copy of the
Apéry sequence.

# 4. Franel-tail and half-cutoff content relations

Let

```math
L(n,k)=\binom nk\binom{n+k}k,
\qquad
F_k=\sum_j\binom kj^3.
```

Strehl's identity is

```math
b_n=\sum_{k=0}^n L(n,k)F_k.
```

For the canonical cutoff `H`, the two scalar prefixes currently used in the
repository are

```math
D_{n,H}=\sum_{k=0}^H L(n,k)^2,
```

```math
S_{n,H}=\sum_{k=0}^H L(n,k)F_k.
```

For every direct-window prime `p=n-r` with `0<=r<=H`, the exact
Franel-tail/Lucas calculation gives

```math
D_{n,H}\equiv S_{n,H}\equiv b_r\pmod p.
```

The full Legendre--Euler transform satisfies the stronger coefficientwise
congruence

```math
T_{n,H}(c)\equiv b_r(1+2c^p)\pmod p.
```

If

```math
\Gamma_{n,J}=\operatorname{content}T_{n,J},
```

then, in the safe direct window,

```math
p\mid\Gamma_{n,J}\quad\Longleftrightarrow\quad p\mid b_r
```

for every cutoff with `r<=J<p`.

Put

```math
M=\left\lfloor\frac n2\right\rfloor,
\qquad
I_n^{\mathrm{half}}=\gcd_{H\le J\le M}\Gamma_{n,J}.
```

The finite-difference identity from
`q32_multicutoff_content_intersection.py` is

```math
T_{n,J}-T_{n,J-1}=K_{n,J}g_J,
```

where `g_J` is primitive, and therefore

```math
\operatorname{content}(T_{n,J}-T_{n,J-1})
 =\kappa_{n,J},
```

```math
\kappa_{n,J}
 =\gcd_{J\le k\le n}
   \binom nk\binom{n+k}k\binom kJ.
```

Elementary ideal arithmetic yields the exact fast formula

```math
\boxed{
 I_n^{\mathrm{half}}
 =\gcd(\Gamma_{n,H},
       \kappa_{n,H+1},\ldots,\kappa_{n,M}).
}
```

The wider direct-safe interval is

```math
H\le J\le n-H-1,
```

and its intersection will be denoted `I_n^dir`.

Let `S_{6,n}` be any of the level-six shell/packet selectors whose current

```math

\qquad u_{p,n}\not\equiv0\pmod p,
```

or the corresponding coefficient-content equivalence.  Then, irrespective

```math
\boxed{
```

for direct-window primes `p>=7`.  A non-target prime is removed by `b_n`,

# 6. Height consequence: none beyond repackaging the target radical

The family always contains `a=0`.  Its primitive numerator is the constant

```math
P_{H,0}=\operatorname{lcm}(b_0,b_1,\ldots,b_H),
```

so trivially

```math
G_{H,A}(n)\mid\operatorname{lcm}(b_0,\ldots,b_H).
```

This gives only

```math
\log G_{H,A}(n)
 \le\sum_{j=0}^H\log b_j=O(H^2),
```

using exponential growth of `b_j`; it is not `o(n)` when `H` is linear in
`n`.  The hypothetical divisibility `G|b_n`, even if it were true, would
only give

```math
\log G\le\log b_n=\Theta(n),
```

which is still not the required sublinear estimate.

More importantly, after zero-absorber saturation the large-prime radical of
`G` is exactly `R_{n,H}`.  Therefore proving a small height for the family
gcd would already prove a small height for the original target radical; the
family has not produced an independent carrier of known smaller height.
The Franel and level-six selectors have exponential-size coefficients or
values as well.  Their common target congruence does not supply cancellation
of the characteristic-zero height.

The exact conclusion is therefore:

```math
G_{H,A}(n)
 =\bigl(\text{direct target radical, with unknown powers}\bigr)
  \times\bigl(\text{small/wrap and absorber factor}\bigr),
```

with neither factor given an independent `e^{o(n)}` bound by the present
identities.

# 7. Self-contained exact verification code

The following script uses only the Python standard library.  It constructs
the Q2615 reciprocal-difference matrix, takes signed maximal cofactors,
reconstructs the denominator by forward differences, performs one joint
clearing/gcd over `p` and `q`, verifies every interpolation equation, finds
the first counterexample, and reproduces the `n=200` content ledger.

```python
#!/usr/bin/env python3
from __future__ import annotations

from fractions import Fraction
from math import comb, gcd, lcm, isqrt


def C(n: int, k: int) -> int:
    return comb(n, k) if 0 <= k <= n else 0


def apery_values(limit: int) -> list[int]:
    """Return b_0,...,b_limit by the exact Apéry recurrence."""
    if limit == 0:
        return [1]
    b = [1, 5]
    for n in range(1, limit):
        polynomial = 34 * n**3 + 51 * n**2 + 27 * n + 5
        numerator = polynomial * b[n] - n**3 * b[n - 1]
        denominator = (n + 1) ** 3
        assert numerator % denominator == 0
        b.append(numerator // denominator)
    return b


def franel_values(limit: int) -> list[int]:
    return [
        sum(C(n, k) ** 3 for k in range(n + 1))
        for n in range(limit + 1)
    ]


def bareiss_det(matrix: list[list[int]]) -> int:
    """Exact determinant, including the 0-by-0 determinant."""
    size = len(matrix)
    if size == 0:
        return 1
    work = [row[:] for row in matrix]
    sign = 1
    previous = 1
    for pivot_index in range(size - 1):
        if work[pivot_index][pivot_index] == 0:
            swap = next(
                (
                    row
                    for row in range(pivot_index + 1, size)
                    if work[row][pivot_index] != 0
                ),
                None,
            )
            if swap is None:
                return 0
            work[pivot_index], work[swap] = (
                work[swap], work[pivot_index]
            )
            sign = -sign
        pivot = work[pivot_index][pivot_index]
        for row in range(pivot_index + 1, size):
            below = work[row][pivot_index]
            for column in range(pivot_index + 1, size):
                numerator = (
                    work[row][column] * pivot
                    - below * work[pivot_index][column]
                )
                assert numerator % previous == 0
                work[row][column] = numerator // previous
            work[row][pivot_index] = 0
        previous = pivot
    return sign * work[-1][-1]


def reciprocal_matrix(
    H: int, a: int, bvalues: list[int]
) -> list[list[int]]:
    """Row-cleared Q2615 matrix; row clearing preserves its kernel."""
    bdeg = H - a
    rows: list[list[int]] = []
    for k in range(bdeg + 1, H + 1):
        rational_row = [
            sum(
                Fraction(
                    (-1) ** (k - j) * C(k, j) * C(j, d),
                    bvalues[j],
                )
                for j in range(k + 1)
            )
            for d in range(a + 1)
        ]
        scale = 1
        for value in rational_row:
            scale = lcm(scale, value.denominator)
        integer_row = []
        for value in rational_row:
            cleared = value * scale
            assert cleared.denominator == 1
            integer_row.append(cleared.numerator)
        rows.append(integer_row)
    assert len(rows) == a
    return rows


def primitive_pair(
    H: int, a: int, bvalues: list[int]
) -> tuple[list[int], list[int]]:
    """One joint primitive Newton pair (P,Q)."""
    bdeg = H - a
    matrix = reciprocal_matrix(H, a, bvalues)

    # Signed maximal cofactors of the a by (a+1) matrix.
    p_rational: list[Fraction] = []
    for deleted in range(a + 1):
        minor = [
            [entry for column, entry in enumerate(row) if column != deleted]
            for row in matrix
        ]
        p_rational.append(
            Fraction((-1) ** deleted * bareiss_det(minor))
        )
    assert any(p_rational), (H, a, "rank defect")

    def P_at(j: int) -> Fraction:
        return sum(
            p_rational[d] * C(j, d)
            for d in range(a + 1)
        )

    # Newton coefficients of P(j)/b_j.
    q_rational = [
        sum(
            Fraction((-1) ** (k - j) * C(k, j), bvalues[j])
            * P_at(j)
            for j in range(k + 1)
        )
        for k in range(bdeg + 1)
    ]

    vector = p_rational + q_rational
    scale = 1
    for value in vector:
        scale = lcm(scale, value.denominator)
    integers = []
    for value in vector:
        cleared = value * scale
        assert cleared.denominator == 1
        integers.append(cleared.numerator)

    common = 0
    for value in integers:
        common = gcd(common, abs(value))
    assert common != 0
    integers = [value // common for value in integers]
    first = next(value for value in integers if value)
    if first < 0:
        integers = [-value for value in integers]

    check = 0
    for value in integers:
        check = gcd(check, abs(value))
    assert check == 1

    p = integers[: a + 1]
    q = integers[a + 1 :]
    for j in range(H + 1):
        assert newton_value(p, j) == (
            bvalues[j] * newton_value(q, j)
        )
    return p, q


def newton_value(coefficients: list[int], n: int) -> int:
    return sum(
        coefficient * C(n, degree)
        for degree, coefficient in enumerate(coefficients)
    )


def ceil_two_thirds(H: int) -> int:
    A = 0
    while A**3 < H**2:
        A += 1
    return A


PAIR_CACHE: dict[tuple[int, int], tuple[list[int], list[int]]] = {}


def cached_pair(
    H: int, a: int, bvalues: list[int]
) -> tuple[list[int], list[int]]:
    key = (H, a)
    if key not in PAIR_CACHE:
        PAIR_CACHE[key] = primitive_pair(H, a, bvalues)
    return PAIR_CACHE[key]


def family_gcd(
    H: int, A: int, n: int, bvalues: list[int]
) -> tuple[int, list[int]]:
    values = []
    common = 0
    for a in range(min(A, H) + 1):
        p, _ = cached_pair(H, a, bvalues)
        value = newton_value(p, n)
        values.append(value)
        common = gcd(common, abs(value))
    return common, values


def valuation(value: int, prime: int) -> int:
    value = abs(value)
    exponent = 0
    while value and value % prime == 0:
        value //= prime
        exponent += 1
    return exponent


def is_prime(value: int) -> bool:
    if value < 2:
        return False
    return all(value % d for d in range(2, isqrt(value) + 1))


def q1_scalar_prefixes(
    n: int, H: int, franel: list[int]
) -> tuple[int, int]:
    direct = 0
    strehl = 0
    for k in range(H + 1):
        kernel = C(n, k) * C(n + k, k)
        direct += kernel * kernel
        strehl += kernel * franel[k]
    return direct, strehl


def truncation_content(
    n: int, cutoff: int, franel: list[int]
) -> int:
    """Exact content of the Legendre--Euler transform T_(n,cutoff)."""
    result = abs(
        sum(
            C(n, k) * C(n + k, k) * franel[k]
            for k in range(cutoff + 1)
        )
    )
    for degree in range(1, n + 1):
        if result == 1:
            break
        lower = max(0, cutoff + 1 - degree)
        upper = min(cutoff, n - degree)
        residue = 0
        for index in range(lower, upper + 1):
            term = (
                C(n, index + degree)
                * C(n + index + degree, index + degree)
                * C(index + degree, index)
                * C(degree - 1, cutoff - index)
                * franel[index]
            )
            residue += (-1) ** (cutoff - index) * (term % result)
        result = gcd(result, residue % result)
    return result


def kappa_against(n: int, cutoff: int, modulus: int) -> int:
    result = modulus
    for index in range(cutoff, n + 1):
        if result == 1:
            break
        coefficient = (
            C(n, index)
            * C(n + index, index)
            * C(index, cutoff)
        )
        result = gcd(result, coefficient % result)
    return result


def cutoff_intersection(
    n: int, lower: int, upper: int, franel: list[int]
) -> int:
    result = truncation_content(n, lower, franel)
    for cutoff in range(lower + 1, upper + 1):
        result = kappa_against(n, cutoff, result)
    return result


def factor_small(value: int) -> str:
    value = abs(value)
    fields = []
    divisor = 2
    while divisor * divisor <= value:
        exponent = 0
        while value % divisor == 0:
            value //= divisor
            exponent += 1
        if exponent:
            fields.append(
                str(divisor) if exponent == 1
                else f"{divisor}^{exponent}"
            )
        divisor = 3 if divisor == 2 else divisor + 2
    if value > 1:
        fields.append(str(value))
    return "*".join(fields) if fields else "1"
```

# Final conclusion

The answer to the proposed theorem is negative:

```math
G_{H,A}(n)\nmid b_n
```

in general, with first canonical counterexample `n=20`.

The exact surviving theorem is the direct-window zero-absorber criterion and
its radical corollary.  At `n=200`, it identifies the large-prime part of the
family gcd with `139*181`; all remaining factors are small/wrapped.  The
coincidence that those remaining factors also divide `b_200` (and a chosen
scaled level-six selector) does not persist universally and supplies no new
height estimate.  After the wider direct-safe cutoff intersection, the
entire `n=200` nuisance is removed and one recovers exactly the original
direct target radical `139*181`; this is a purification identity, not an
independent bound on that radical.
