## 3. Why the order-six operator is genuinely minimal for this \(R\)

There are two points to certify: the rank-three Apéry part is minimal, and the six displayed functions are independent for the specific branch \(B,h\).

### 3.1 The Apéry operator is Ore-irreducible

Exact `ore_algebra` factorization returned the singleton list


with factor orders `[3]`. This is simply \(L\) written in \(D_x\)-form. Hence \(L\) has no proper positive-order right factor in \(\mathbb Q(x)\langle D_x\rangle\). Since \(B\ne0\), the minimal annihilator of \(B\) has order three. Equivalently,
\[

\]
are linearly independent over \(\mathbb Q(x)\).

### 3.2 Logarithmic monodromy doubles the rank

The point \(x=1\) is ordinary for \(L\), because \(\Delta(1)=-32\ne0\). A sufficiently small loop around \(x=1\) leaves every local solution of \(L\), and therefore \(B,\theta B,\theta^2B\), unchanged. It sends
\[
h\longmapsto h+2\pi i
\]
(up to orientation of the loop).

Suppose there were a rational relation among the six state functions. It can be written
\[
hU+V=0,
\qquad
U,V\in\operatorname{span}_{\mathbb Q(x)}\{B,\theta B,\theta^2B\}.
\]
Continue once around \(x=1\) and subtract the original relation. This gives
\[
2\pi i\,U=0,
\]
so \(U=0\), and then \(V=0\). The rank-three independence above now implies all six coefficients vanish.

Thus
\[
Bh,(\theta B)h,(\theta^2B)h,B,\theta B,\theta^2B
\]
are independent over \(\mathbb Q(x)\). Since the observability matrix is invertible, the six functions
\[
R,\theta R,\ldots,\theta^5R
\]
are also independent. Therefore no operator of order at most five annihilates this particular \(R\). The order-six scalarization is minimal.

## 7. Exact minimal recurrence

Because
\[
\theta^kR=\sum_{n\ge0}n^kR_nx^n,
\]
the coefficient of \(x^N\) in \(x^jp_j(\theta)R\) is
\[
p_j(N-j)R_{N-j}.
\]
Hence \(\mathcal PR=0\) is exactly
\[
\boxed{
\sum_{j=0}^{19}p_j(N-j)R_{N-j}=0
\qquad(N\ge0),
}
\]
with \(R_m=0\) for \(m<0\).

Equivalently, if \(S\) is the forward shift \((Su)_n=u_{n+1}\), Sage's operator is
\[
\boxed{
\mathcal R_S=
\sum_{j=0}^{19}p_j(n+19-j)S^{19-j}.
}
\]
The exact `to_S` audit returned

```text

REC_VALUATION = 0
```

and its printed coefficients agree with the displayed formula. For instance, its constant term is
\[
p_{19}(n)=363(n+1)^4(n+2)^2,
\]
and its \(S^{19}\)-coefficient is
\[
p_0(n+19)=-(n+19)^3(n+18)^3.
\]

### Why shift order nineteen is minimal

The primitive operator has normal \(x\)-support exactly \([0,19]\), since \(p_0\ne0\) and \(p_{19}\ne0\), and its polynomial coefficients have content one. In the Ore ring with relation
\[
\theta x^j=x^j(\theta+j),
\]
normal-form supports add under multiplication:
\[
\operatorname{width}_x(UV)
=
\operatorname{width}_x(U)+\operatorname{width}_x(V)
\]
for nonzero polynomial Ore operators. The Ore-Gauss lemma implies that every polynomial-coefficient annihilator of \(R\) is a polynomial left multiple of this primitive numerator of the minimal rational operator. Therefore every such annihilator has \(x\)-width at least nineteen.

Under coefficient extraction, the standard Laurent Ore correspondence sends \(x\)-width to shift width. Consequently no nonzero polynomial-coefficient recurrence of shift order below nineteen can annihilate \((R_n)\). Thus the displayed order-nineteen recurrence is minimal over \(\mathbb Q[n]\langle S\rangle\).

Since the coefficient of \(R_N\) is
\[
p_0(N)=-N^3(N-1)^3,
\]
the two initial values
\[
R_0=0,\qquad R_1=1
\]
determine the entire sequence. The further values above provide exact checks of the corrected normalization.

The recurrence was checked by exact rational arithmetic for every \(0\le N\le500\). This is finite evidence for the implementation, not part of the symbolic proof.

## 8. Rigorous comparison with the rank-four extension \(LC=x\)

Suppose \(C\) satisfies
\[
LC=x.
\]
With \(T=x\), the monic equation is
\[
\theta^3C=-a\theta^2C-b\theta C-cC+\frac{T}{\Delta},
\qquad \theta T=T.
\]
Thus the natural rank-four state
\[
W=(C,\theta C,\theta^2C,T)^T
\]
satisfies
\[
\boxed{
\theta W=M_4W,
\qquad
M_4=
\begin{pmatrix}
0&1&0&0\\
0&0&1&0\\
-c&-b&-a&\Delta^{-1}\\
0&0&0&1
\end{pmatrix}.
}
\]
Cyclic elimination from the first component has exact determinant
\[
\det\mathcal O_4=\Delta^{-1}\ne0.
\]
The resulting scalar operator has order four, and exact monic comparison gives
\[
\boxed{P_C=(\theta-1)L.}
\]
Indeed, this is also immediate from
\[
LC=x,\qquad (\theta-1)x=0.
\]
The Sage audit checked

```sage

```

coefficient by coefficient.

The two extensions are therefore different:

* \(LC=x\) is rank four: a rank-three Apéry module extended by the rank-one module generated by \(x\).
* \(R=Bh\) is rank six: the tensor of the rank-three Apéry module with the rank-two logarithm module \(\operatorname{span}\{1,h\}\), equivalently a nontrivial self-extension with two rank-three Apéry composition factors.
* Their first components have different certified minimal scalar orders, four and six respectively.

Hence \(R\) is not a component of the known rank-four normal-function extension.

## 9. Exact top-shell lemma—and no stronger denominator claim

Let
\[
\Lambda_n=\operatorname{lcm}(1,\ldots,n),
\qquad
U_n=\Lambda_nR_n
=
\sum_{j=1}^{n}b_{n-j}\frac{\Lambda_n}{j}\in\mathbb Z.
\]
Let \(p\) be prime with
\[
\frac n2<p\le n.
\]
Then \(p\) is the unique multiple of \(p\) among \(1,\ldots,n\): the only such denominator index is \(j=p\). Also \(v_p(\Lambda_n)=1\). Therefore, modulo \(p\), every term with \(j\ne p\) vanishes, while the \(j=p\) term survives:
\[
\boxed{
U_n\equiv b_{n-p}\frac{\Lambda_n}{p}\pmod p.
}
\]
Because \(p\nmid\Lambda_n/p\),
\[
\boxed{
p\mid U_n\iff p\mid b_{n-p}.
}
\]
If \(D_n\) is the reduced denominator of \(R_n\), then
\[
D_n=\frac{\Lambda_n}{\gcd(\Lambda_n,U_n)}
\]
and \(v_p(\Lambda_n)=1\), so equivalently
\[
\boxed{
p\mid D_n\iff p\nmid b_{n-p}.
}
\]
No step assumes \(p\mid n\). The mechanism is exactly the uniqueness of the denominator multiple \(j=p\).

**Finite evidence only.** Exact computation checked both equivalences for all \(11{,}166\) strict-top-shell pairs \((n,p)\) with \(1\le n\le500\), with zero failures.

No lower-bound theorem for the full reduced denominator is asserted here.

```sage
# ------------------------------------------------------------------

Dx = AK.gen()
AP = OreAlgebra(Rx, 'Dx')
Dp = AP.gen()

th = x*Dx
thp = x*Dp
Delta = 1 - 34*x + x^2

a = 3*x*(x - 17) / Delta
b = 3*x*(x - 9) / Delta

A3 = matrix(K, [
    [0, 1, 0],
    [0, 0, 1],
    [-c, -b, -a],

M6 = zero_matrix(K, 6, 6)

    for j in range(3):

        M6[i + 3, j + 3] = A3[i, j]

def dtheta(z):
    return K(x * diff(K(z), x))

    rows = [vector(K, selector)]
    for _ in range(count - 1):

    O = matrix(K, rows)
    ker = O.left_kernel()
    assert ker.dimension() == 1
    rel = vector(K, ker.basis()[0])
    assert rel[-1] != 0
    return rel / rel[-1]

    for k, coeff in enumerate(coeffs):
        out += K(coeff) * th^k
    return out

    return (K.one() / K(op[op.order()])) * op

def poly_lcm(values):

        q.denominator() for f in polys for q in f.coefficients()

        q for f in polys for q in f.coefficients()
    ])
    polys = [Rx(f/content) for f in polys]
    if polys[-1].leading_coefficient() < 0:

    return polys
```
