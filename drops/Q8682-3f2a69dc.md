# Combinatorial audit

The lemma is essentially correct, but there are two constant corrections. The main identity is an ordered-pair decomposition, and the final `J^2-7J` estimate needs a slightly more careful overlap count.

## 1. Ordered-pair to full-defect fibre decomposition

Fix a labelled triple `D=(d1,d2,d3)` with `d1=0`. For a row, let `alpha(t)` count compatible translations. Then

```
E = sum_m alpha(m)^2
  = J + sum_m sum_{t != t'} 1_{(t,t') is compatible}.
```

For an ordered pair `(t,t')`, write `h=t'-t`. The second copy has offsets

```
h+D={h+d1,h+d2,h+d3}.
```

The shared offsets are exactly

```
D ∩ (h+D),
```

so the union has

```
k = 6-r(h)
```

labelled positions. Scanning the union offsets in increasing prime order gives a unique merge word with letters:

```
A = first copy only,
B = second copy only,
X = shared.
```

Conversely, a compatible merge word reconstructs the two increasing prime chains and hence the ordered pair of occurrences. Therefore the off-diagonal part of `E-J` is exactly the sum of structured full-defect fibres over all admissible shifts `h`, with multiplicity one after the merge word is fixed.

There is no extra inverse factor: the fibre is ordered because `(t,t')` and `(t',t)` are different terms in `alpha^2`.

## 2. Word counts

For no overlap, `r=0`, there are three `A` positions and three `B` positions. The number of words is

```
C(6,3)=20.
```

For one shared point, `r=1`, there are four singletons and one shared rank. The shared rank is forced to be last in neither chain and the count depends on its two ranks `(i,j)`. The stated formula

```
C(i+j-2,i-1) C(6-i-j,3-i)
```

is the correct compatibility count once the two chain ranks are fixed.

However, the numerical conclusion needs care: summing over all directed rank pairs does not universally give 14. It depends on which directed difference corresponds to the shift and on whether the same offset configuration occurs more than once. The generic six directed differences of a non-AP labelled triple are distinct, but the aggregate constant must be obtained after this shift indexing, not simply from the rank sum.

Thus the statement "summing over i != j gives 14" is not a structural identity; it is a possible count for a particular normalization.

## 3. AP and endpoint cases

For a three-term AP there are indeed additional shifts with two overlaps. These produce `k=4` fibres. The claim that there are two adjacent-level shifts is correct.

The assertion that compatibility gives exactly one word per shift requires the monotonicity convention to be fixed. Without specifying whether prime ranks are increasing with offsets or with translated offsets, the word count is orientation-dependent.

Likewise, the endpoint `r=1` constants `2` and `6` are not universal until the orientation convention is frozen.

A safe universal statement is:

```
C4 = O(1), C5 = O(1), C6 = 20.
```

The exact values 2, 14 require a fixed merge orientation convention.

## 4. Correction to the six-sector lower bound

Let there be `J` translations in one row. The number of ordered off-diagonal pairs is

```
J(J-1).
```

A pair overlaps precisely when

```
h=t'-t ∈ (D-D)\{0}.
```

For a labelled three-point set, the number of nonzero directed differences is at most six.

For each fixed nonzero overlap shift `h`, the number of ordered pairs `(t,t')` with that difference is at most `J`. Hence the total number of overlap ordered pairs is at most

```
6J.
```

Therefore the number of disjoint ordered pairs is at least

```
J(J-1)-6J = J^2-7J.
```

This part is correct. The only qualification is that if some directed differences coincide, the actual overlap count is smaller, never larger.

## Final corrected statement

The decomposition `E=J+` structured 4/5/6-point fibres is correct. The disjoint six-point contribution has the lower bound

```
J^2-7J
```

in the one-row model.

The constants `20` for the disjoint sector is exact. The claimed overlap constants `C4<=2` and `C5<=14` are not invariant without fixing the orientation/rank convention; they should be treated as convention-dependent constants rather than unconditional combinatorial identities.
