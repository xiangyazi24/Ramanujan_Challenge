import sympy as S

a,m,d=S.symbols('a m d')

def P(j):
    return 34*j**3+51*j**2+27*j+5

def T(j):
    return S.Matrix([[S.Rational(1,1)*P(j)/(j+1)**3,
                      -S.Rational(1,1)*j**3/(j+1)**3],
                     [1,0]])

U=S.eye(2)
rows=[]
for i in range(5):
    if i:
        U=T(a+(i*d)-1)*U
    A=S.factor(U[0,0])
    B=S.factor(U[0,1])
    p=m-a-i*d
    rows.append(S.Matrix([[5*p**3,-6,-p**3*A,-p**3*B]]))

M=S.Matrix.vstack(*rows)
mins=[]
for omit in range(5):
    mins.append(S.factor(M[[j for j in range(5) if j!=omit],:].det()))

g=mins[0]
for z in mins[1:]:
    g=S.gcd(g,z)
print(S.factor(g))
for z in mins:
    print(S.factor(z/g))

## Local congruence logic

For its own prime p_i,

\[
p_i=m-a-id\equiv0\pmod {p_i},
\]

so

\[
R_i\equiv(0,-6,0,0)\pmod {p_i}.
\]

Because p_i>=5, -6 is a unit unless p_i=3 (excluded). Therefore the i-th equation is a nonzero local linear condition modulo p_i^4.

However, the other rows satisfy

\[
R_j=(5p_j^3,-6,-p_j^3A_j,-p_j^3B_j),
\]

and there is no implication that

\[
p_i\mid R_j
\]

for j!=i. Their p_j factors are unrelated. Hence a maximal minor formed from several rows is not automatically divisible by every p_i.

The only guaranteed divisibility is the tautological one coming from the p_i^3 factors appearing in columns involving endpoint coordinates. After removing those factors, there is no common local prime carrier supplied by the coefficient minors alone.
