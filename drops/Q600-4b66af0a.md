# Adolphson-Sperber generic ordinarity and the Apéry Kummer twist problem

## Executive summary

The proposed implication

\[
|\{r:NP(p,r)\neq HP\}|\le C
\]

is exactly the kind of statement needed for AFP, but it does **not** follow directly from Adolphson-Sperber generic ordinarity or Wan's slope conjecture. The obstruction is that the tame-character parameter is not a geometric parameter over a fixed base variety. It is a family of Frobenius eigenspaces indexed by characters of \(\mathbf F_p^\times\).

The closest rigorous framework is not "generic ordinarity of a one-parameter family" but rather **Hasse-Witt/Frobenius analysis of a hypergeometric sheaf under Kummer convolution**.

The expected answer is:

* Adolphson-Sperber gives generic ordinarity in the geometric parameter direction, not automatically in the Kummer-character direction.
* Wan's conjectural codimension heuristic is morally aligned with the desired \(O(1)\) exceptional twists, but the discrete character family is not covered directly.
* No general theorem currently gives a uniform constant \(C\) for all hypergeometric Kummer twists of the Apéry motive.
* The Hasse-Witt matrix route is the most concrete possible route, but one needs the twisted Hasse-Witt matrix, not only the untwisted polynomial \(H_p(t)\).

---

# (A) Applicability of Adolphson-Sperber

Adolphson-Sperber study exponential sums attached to a Laurent polynomial

\[
f(x)=\sum a_i x^{v_i}
\]

and prove that for nondegenerate Newton polyhedra the Newton polygon reaches the Hodge polygon for generic situations.

For the Apéry Laurent polynomial, this gives information about the fixed exponential sum family:

\[
NP(p,t)=HP
\]

for generic geometric parameter \(t\) and sufficiently good primes.

However the Kummer twist direction is different.

A tame character

\[
\chi_r:\mathbf F_p^\times\rightarrow \overline{\mathbf Q}_p^\times
\]

produces a twisted Frobenius object

\[
H^i_{cris}(X,\mathcal L_{\chi_r}).
\]

The parameter \(r\) is not a point of the original parameter variety. It belongs to the character group

\[
\widehat{\mathbf F_p^\times},
\]

whose size is \(p-1\).

Therefore Adolphson-Sperber does not directly imply

\[
\#\{r:NP(p,r)\neq HP\}=O(1).
\]

The theorem controls genericity in the Laurent polynomial coefficients, not uniformity across all Kummer local systems.

---

# (B) Wan slope conjecture and codimension heuristic

The heuristic is very attractive:

A one-dimensional family should have a codimension-one supersingular locus, hence finitely many exceptional parameters.

But there is a subtle mismatch.

Wan's setting:

\[
\text{geometric parameter variety }S/\mathbf F_p.
\]

The bad locus is an algebraic subvariety:

\[
\Sigma\subset S.
\]

For a curve,

\[
\dim \Sigma=0,
\]

so one expects \(O(1)\) points.

The Kummer family instead is:

\[
r\in \mathbf Z/(p-1)\mathbf Z.
\]

There is no fixed algebraic curve whose \(\mathbf F_p\)-points are these characters. The character group changes with \(p\).

Thus the codimension argument is only heuristic unless one constructs a geometric moduli space of Kummer sheaves and proves that the bad locus has bounded degree.

A possible rigorous formulation would be:

There exists a character-space compactification \(\mathcal M\) and a bad-locus divisor

\[
D_p\subset \mathcal M_{\mathbf F_p}
\]

of uniformly bounded degree such that

\[
NP(p,r)\neq HP \implies r\in D_p.
\]

No such theorem is currently available for the Apéry hypergeometric motive.

# (C) Explicit ordinarity bounds for hypergeometric Kummer twists

For hypergeometric motives one has strong results on:

* Hodge polygons;
* generic Newton polygons;
* unit-root subcrystals;
* Dwork cohomology.

But an explicit formula

\[
\{r:NP(p,r)\neq HP\}
\]

for

\[
{}_4F_3(1/2,1/2,1/2,1/2;1,1,1)
\]

is not known in the required strength.

There are special cases where the exceptional characters are described by congruence conditions involving:

* fractional parts of \(p\alpha_i\);
* Stickelberger valuations;
* Gross-Koblitz gamma factors.

For general hypergeometric motives, these determine expected slopes but do not automatically yield a bounded exceptional set.

The likely formula would involve the Dwork slope function:

\[
\nu_p(G(r+\alpha_i)/G(r+\beta_j))
\]

where \(G\) is the p-adic gamma function.

The nonordinary twists occur when these predicted slopes fail to realize the Hodge polygon.

A uniform bound on such failures is currently the missing theorem.

---

# (D) Does the desired bound imply AFP?

Yes.

If one proves

\[
E_p:=\{r:NP(p,r)\neq HP\}
\]

satisfies

\[
|E_p|\le C,
\]

then immediately

\[
\sum_{p\le X}|Z_p|
\ll
\sum_{p\le X}|E_p|
\le C\pi(X).
\]

This is exactly the AFP estimate needed in the Apéry GCD strategy.

However the missing implication is:

\[
\text{nonordinary twist}\Rightarrow\text{bounded-degree algebraic condition in }r.
\]

That is the hard part.

# (E) Hasse-Witt matrix approach

This is the most promising concrete route.

For ordinary reduction, the crystalline Frobenius has maximal possible rank modulo \(p\). Equivalently, the Hasse-Witt matrix is nonsingular.

For hypergeometric motives the untwisted Hasse-Witt object is related to

\[
H_p(t)=\sum_{k=0}^{(p-1)/2}\left(\frac{\binom{2k}{k}}{4^k}\right)^4t^k.
\]

But this polynomial controls variation in the geometric fiber parameter \(t\).

The twist problem asks instead for

\[
HW_p(\chi_r),
\]

the Hasse-Witt matrix after tensoring with the Kummer sheaf.

The correct object is a Mellin transform of the Hasse-Witt matrix:

\[
HW_p(\chi_r)
=
\sum_{t\in\mathbf F_p^\times}
H_p(t)\chi_r(t).
\]

Therefore zeros of \(H_p(t)\) alone do not determine nonordinary twists.

The desired statement becomes a Fourier nonvanishing theorem:

\[
\#\{r:\widehat H_p(r)=0\}=O(1).
\]

This connects directly with AFP.

---

# Recommended next target

The right intermediate theorem is not full ordinarity classification but a Mellin anti-concentration statement:

For the Apéry Hasse-Witt trace function \(h_p(t)\), prove

\[
\#\{r:\sum_t h_p(t)\chi_r(t)=0\}=O(1).
\]

This is a Fourier statement over \(\mathbf F_p^\times\), exactly matching the observed bounded zero multiplicity of the ratio map.

Possible tools:

1. Katz middle-extension sheaves for the Mellin transform.
2. Deligne bounds for Fourier transforms.
3. Large geometric monodromy of the Apéry hypergeometric sheaf.
4. Exclusion of exceptional rank-one constituents.

The computational evidence (bounded multiplicity and Poisson-like \(|Z_p|\)) is consistent with this picture: the obstruction is not a large geometric exceptional locus, but a small set of accidental Mellin zeros.

Conclusion:

Adolphson-Sperber and Wan provide the correct philosophy, but not the required theorem. The strongest realistic route is to reinterpret AFP as a **Mellin transform nonvanishing problem for the twisted Hasse-Witt matrix** and attack it with Katz-style hypergeometric sheaf methods.
