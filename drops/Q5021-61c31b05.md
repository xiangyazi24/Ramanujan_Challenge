# 1. Exact continuant transport from a physical block boundary

The Apéry recurrence is
\[
 (n+1)^3u_{n+1}=P(n)u_n-n^3u_{n-1},
 \qquad
 P(n)=(2n+1)(17n^2+17n+5).
 \tag{1.1}
\]
The canonical gap continuants satisfy
\[
 N_0(X)=0,\qquad N_1(X)=1,
\]
\[
 N_{h+1}(X)
 =P(X+h)N_h(X)-(X+h)^6N_{h-1}(X).
 \tag{1.2}
\]
For \(J\ge0\) and \(r\ge1\), define
\[
 \Delta_r(J)=\prod_{j=2}^{r}(J+j)^3,
 \tag{1.3}
\]
with the empty product equal to one.

## Lemma 1.1 — exact boundary transport

For every characteristic-zero solution of (1.1),
\[
 \boxed{
 \Delta_r(J)u_{J+r}
 =N_r(J)u_{J+1}
 -(J+1)^3N_{r-1}(J+1)u_J.}
 \tag{1.4}
\]

### Proof

The case \(r=1\) is immediate from \(N_1=1,N_0=0\). Suppose the
formula holds for \(r\) and \(r-1\). Multiplying (1.1), with
\(n=J+r\), by \(\Delta_r(J)\), and using
\(
\Delta_r(J)=(J+r)^3\Delta_{r-1}(J)
\), gives
\[
\begin{aligned}
 \Delta_{r+1}(J)u_{J+r+1}
 &=P(J+r)\Delta_r(J)u_{J+r}
   -(J+r)^6\Delta_{r-1}(J)u_{J+r-1}.
\end{aligned}
\]
Substitution of the two induction hypotheses makes the coefficient of
\(u_{J+1}\) equal to \(N_{r+1}(J)\), by (1.2), and makes the coefficient
of \(-(J+1)^3u_J\) equal to \(N_r(J+1)\), again by (1.2). This proves
(1.4). \(\square\)

If \(J+r<p\), every factor in \(\Delta_r(J)\) is a \(p\)-unit. In
particular, when \(b_x\equiv0\pmod p\), (1.4), used with \(J=x\), gives
\[
 \Delta_h(x)b_{x+h}=N_h(x)b_{x+1}.
 \tag{1.5}
\]
No two Apéry zeros are consecutive, so \(b_{x+1}\ne0\pmod p\). Hence
for a physical forward displacement,
\[
 \boxed{
 b_x=b_{x+h}=0\pmod p
 \quad\Longleftrightarrow\quad
 b_x=0\pmod p,\quad N_h(x)=0\pmod p.}
 \tag{1.6}
\]
This recovers the local return equation, but (1.4) also retains the
absolute distinguished boundary state. That retained state is the part
needed for the present audit.

# 2. Strongest exact formula for block activity

Let
\[
 I_J=[J,J+H)\cap\mathbb Z,
 \qquad 0\le J,\quad J+H\le p,
\]
be a full physical block. Put
\[
 \beta_{p,J}=[b_{J+1}:b_J]\in\mathbf P^1(\mathbb F_p).
 \tag{2.1}
\]
This point is defined because two consecutive \(b\)'s cannot both vanish.
For \(1\le r<H\), define the moving target
\[
 \tau_{J,r}
 =\bigl[(J+1)^3N_{r-1}(J+1):N_r(J)\bigr]
 \in\mathbf P^1(\mathbb F_p),
 \tag{2.2}
\]
and put \(\tau_{J,0}=[1:0]\). The two coordinates in (2.2) cannot
vanish simultaneously: they form the nonzero boundary functional obtained
from an invertible physical transfer product.

Equation (1.4), with the case \(r=0\) read directly, gives the exact
equivalence
\[
 \boxed{
 b_{J+r}\equiv0\pmod p
 \quad\Longleftrightarrow\quad
 \beta_{p,J}=\tau_{J,r}\qquad(0\le r<H).}
 \tag{2.3}
\]

To state the core condition without ever confusing a local projective root
with an actual zero, let \(x=J+r\), and let
\(\kappa_{p,J}(r)\in\{0,1\}\) be the following purely local predicate.
Starting from the projective zero state at \(x\), the recurrence has three
successive literal first returns at gaps \(a,b,c\), where
\[
 a,b,c\ge L,
 \qquad a+b+c\le H-R,
\]
the resulting quadruple is physically interior in \(I_J\), and all six
pair-return roots are simple. Equivalently, with
\[
 d_0=0,\quad d_1=a,\quad d_2=a+b,\quad d_3=a+b+c,
\]
the predicate contains
\[
 N_{d_j-d_i}(x+d_i)=0,
 \qquad
 N'_{d_j-d_i}(x+d_i)\ne0
 \quad(0\le i<j\le3),
 \tag{2.4}
\]
together with
\[
 N_h(x)\ne0\ (1\le h<a),
\]
\[
 N_h(x+a)\ne0\ (1\le h<b),
 \qquad
 N_h(x+a+b)\ne0\ (1\le h<c),
 \tag{2.5}
\]
and the inherited geometric cuts. Literal first return makes the triple
\((a,b,c)\) unique if it exists, so \(\kappa_{p,J}(r)\) is binary.

Now let \(q_{\rm core}(p,I_J)\) be the number of actual selected core
starts in \(I_J\). Then
\[
 \boxed{
 q_{\rm core}(p,I_J)
 =\sum_{0\le r<H}
   \kappa_{p,J}(r)\,
   \mathbf 1_{\{b_{J+r}\equiv0\pmod p\}}
 =\sum_{0\le r<H}
   \kappa_{p,J}(r)\,
   \mathbf 1_{\{\beta_{p,J}=\tau_{J,r}\}}.}
 \tag{2.6}
\]

This is the exact block/start formula requested in the question. The local
predicate may have projective solutions in other fibers, but (2.6) counts
one only when the distinguished Apéry boundary state actually reaches that
zero state. Hence no arbitrary projective root is counted.

For activity rather than multiplicity, define the set of local moving
targets
\[
 T_{p,J}^{\rm core}
 =\{\tau_{J,r}:0\le r<H,\ \kappa_{p,J}(r)=1\}.
 \tag{2.7}
\]
Then
\[
 \boxed{
 \mathbf 1_{\{q_{\rm core}(p,I_J)>0\}}
 =\mathbf 1_{\{\beta_{p,J}\in T_{p,J}^{\rm core}\}}.}
 \tag{2.8}
\]
Thus active-block sparsity is exactly a moving-target hitting problem for the
distinguished nonautonomous projective orbit.

For \(r\ge1\), the integer cross-product in (2.3) is
\[
 \Psi_{J,r}
 :=N_r(J)b_{J+1}
 -(J+1)^3N_{r-1}(J+1)b_J.
 \tag{2.9}
\]
Equation (1.4) says more precisely that
\[
 \boxed{\Psi_{J,r}=\Delta_r(J)b_{J+r}.}
 \tag{2.10}
\]
Therefore the exact additive detector is
\[
 \mathbf1_{\{\beta_{p,J}=\tau_{J,r}\}}
 =\frac1p\sum_{\lambda\bmod p}e_p(\lambda\Psi_{J,r}).
 \tag{2.11}
\]
This is actual-orbit-sensitive, but it does not turn the problem into a
low-degree polynomial phase: after removal of the unit
\(\Delta_r(J)\), the phase is exactly the sequence value \(b_{J+r}\).

# 4. Exact actual-zero Fourier identities

The strongest currently available way to retain actuality while using the
proved Fourier information is to Fourier-expand the actual zero set itself.
Let
\[
 \mathcal Z_p=\{x\in[0,p):b_x\equiv0\pmod p\},
 \qquad
 F_p(k)=\sum_{x\in\mathcal Z_p}e_p(kx).
 \tag{4.1}
\]
Let \(S_p^{\rm core}\subseteq\mathcal Z_p\) be the set of all actual
selected core starts in the physical canonical blocks, and put
\[
 Q_p=|S_p^{\rm core}|,
 \qquad
 G_p(k)=\sum_{x\in S_p^{\rm core}}e_p(kx).
 \tag{4.2}
\]
Orthogonality, using \(S_p^{\rm core}\subseteq\mathcal Z_p\), gives
\[
 \sum_{k\bmod p}F_p(k)\overline{G_p(k)}=pQ_p.
\]
Since the zero-frequency term is \(Z(p)Q_p\),
\[
 \boxed{
 \left(1-\frac{Z(p)}p\right)Q_p
 =\frac1p\sum_{k=1}^{p-1}F_p(k)\overline{G_p(k)}.}
 \tag{4.3}
\]
This identity contains no projective phantoms.

For active blocks, choose canonically the least actual core start in every
active block. Let that set be \(E_p\), and define
\[
 A_p=|E_p|
 =\#\{I:q_{\rm core}(p,I)>0\},
 \qquad
 \Omega_p(k)=\sum_{x\in E_p}e_p(kx).
 \tag{4.4}
\]
The same proof gives
\[
 \boxed{
 \left(1-\frac{Z(p)}p\right)A_p
 =\frac1p\sum_{k=1}^{p-1}F_p(k)\overline{\Omega_p(k)}.}
 \tag{4.5}
\]
The pointwise bound \(Z(p)\ll p^{2/3}\) makes
\(1-Z(p)/p=1+O(P^{-1/3})\) throughout the top band.

Equations (4.3) and (4.5) are the exact actual-orbit scalar correlations.
They are stronger for the present purpose than expanding the local
projective equations alone, because every point in \(G_p\) or \(\Omega_p\)
is already an actual Apéry zero.

# 7. Why additive, multiplicative, and ordinary large-sieve expansions stop

## 7.1 Additive detection of the sequence value

Substitution of (2.11) into (2.6) gives an exact formula involving
\[
 e_p\bigl(\lambda\Delta_r(J)b_{J+r}\bigr).
 \tag{7.1}
\]
For a fixed \(r\), multiplication by the unit \(\Delta_r(J)\) merely
renames \(\lambda\); across the \(r\)-sum it is a varying coefficient.
The genuinely difficult object is therefore an incomplete nonlinear sum of
sequence values
\[
 \sum_{J,r}\kappa_{p,J}(r)\,e_p(\lambda_{J,r}b_{J+r}).
 \tag{7.2}
\]
The current source proves Fourier information for the **zero set** of the
sequence, not a bounded-conductor estimate for the value phase
\(e_p(\lambda b_n)\) as \(n\) varies. Interpolating \(n\mapsto b_n\pmod
p\) gives a polynomial of degree as large as \(p-1\), so ordinary Weil
bounds do not supply a useful estimate. The Cartier coefficient formula
likewise does not by itself turn (7.2) into a fixed-conductor trace function
in the index variable.

The zero-set identity (4.5) is therefore the stronger unconditional route,
and Section 6 exhausts what the current short-window energy yields from it.

## 7.2 Multiplicative characters of the boundary slope

On a block where the boundary state and the relevant targets lie in the
affine torus, write
\[
 \sigma_{p,J}=\frac{b_{J+1}}{b_J},
 \qquad
 t_{J,r}=\frac{(J+1)^3N_{r-1}(J+1)}{N_r(J)}.
\]
Multiplicative orthogonality gives the exact generic detector
\[
 \mathbf1_{\{\sigma_{p,J}=t_{J,r}\}}
 =\frac1{p-1}\sum_{\chi\bmod p}
   \chi(\sigma_{p,J})\overline{\chi(t_{J,r})}.
 \tag{7.3}
\]
The zero and infinite slopes can be retained separately by the projective
formula (2.3); omitting them cannot create a power saving.

The nonprincipal part of (7.3) is a correlation between
\[
 \chi\!\left(\frac{b_{J+1}}{b_J}\right)
 \quad\hbox{and}\quad
 \sum_r\kappa_{p,J}(r)\chi(t_{J,r}).
 \tag{7.4}
\]
Three obstacles are exact:

1. exact detection requires the full family of \(p-1\) characters, not a
   conjugation-stable family of \(P^{\rho}\) characters;
2. the target transform depends jointly on \(p,J\), and on the local core
   predicate;
3. the boundary coefficient is the distinguished prefix ratio itself.

Thus the completed small-character sectors in the current
`oracleA_result.tex` do not instantiate (7.4). Applying character
orthogonality and Cauchy without a new estimate for the boundary-ratio orbit
returns the collision energy of the \(\sigma_{p,J}\)'s and gives no saving.

## 7.3 Why an ordinary additive large sieve does not see the block condition

The coefficients \(G_p(k)\) and \(\Omega_p(k)\) are different
\(p\)-dependent selectors for every prime. There is no common coefficient
sequence to which the classical cross-modulus large sieve can be applied.
Per-prime Parseval is exactly the no-gain calculation of Section 5.

Moreover, one point per length-\(H\) block does not force small high-frequency
Fourier coefficients. At a frequency of size comparable with \(p/2\), an
arbitrary selector can choose one of the two parities available in each
block so that a fixed real projection of the phases has one sign. Hence a
linear-size high-frequency coefficient is compatible with the bare block
geometry. This is only a saturation model for the method, not an alleged
Apéry-zero example. It proves that cancellation in (6.12) must use the
arithmetic of the distinguished prefix orbit.

# 8. Exact characteristic-zero block carrier and its height wall

The boundary transport identity gives a canonical homogeneous block

 \right).
 \tag{8.1}
\]
Evaluation at the distinguished boundary state is exact:
\[
 \boxed{
 \mathscr P_{J,H}(b_{J+1},b_J)
 =b_J\prod_{r=1}^{H-1}\Delta_r(J)b_{J+r}.}
 \tag{8.2}
\]
After removing the physical \(p\)-unit clearings, the minimal evident
integer carrier for zero activity in the block is simply
\[
 \mathscr B_{J,H}=\prod_{r=0}^{H-1}b_{J+r}.
 \tag{8.3}
\]
Every active core block contributes at least four factors divisible by
\(p\), and a block with \(q\) selected consecutive core starts contributes
at least \(q+3\) distinct zero factors. Hence (8.3) is an exact
actual-orbit carrier.

Its height is nevertheless at the absolute-index scale. The canonical
bound \(\log b_n\le3.6n\) gives
\[
 \log\mathscr B_{J,H}\ll HJ+H^2.
 \tag{8.4}
\]
Summing over canonical origins \(J=mH\ll P\),
\[
 \sum_J\log\mathscr B_{J,H}
 \ll P^2+PH
 \ll P^{2+o(1)}.
 \tag{8.5}
\]
Thus the product formula supplies at best
\[
 \sum_{p,J:\,q_{\rm core}(p,I_J)>0}\log p
 \ll P^{2+o(1)},
 \tag{8.6}
\]
even after using the four zero factors, which only changes the constant.
The target is \(P^2/H^{1+\delta}\). The block carrier therefore misses an
entire factor \(H^{1+\delta}\).

Choosing only the first core start would avoid the product of all \(H\)
sequence values, but that first start depends on \(p\). There is then no
single characteristic-zero integer attached to the block to which the
product formula can be applied.

This gives a precise carrier dichotomy:

```text
retain the distinguished boundary evaluation:  actual, but J/P-scale height
eliminate the boundary variables:               H-scale, but returns to the
                                                 already-audited local
                                                 cofactor/content algebra
```

Simplicity of the six local roots changes local multiplicity; it does not
reduce the height of \(b_J\), \(b_{J+1}\), or (8.3). Consequently no new
active-block saving follows from a resultant unless one proves a genuinely
new gcd or correlation theorem coupling the distinguished prefix values to
the local continuants.

A still more direct version of the same wall is
\[
 \sum_{x<2P}\sum_{\substack{P<p\le2P\\p\mid b_x}}\log p
 \le\sum_{x<2P}\log b_x
 \ll P^2.
 \tag{8.7}
\]
The one-per-block selection is \(p\)-dependent, so it cannot be replaced in
(8.7) by one fixed \(H\)-spaced set of indices.

# 9. Shifted block partitions do not create the missing saving

Let a core quadruple have span
\[
 s=a+b+c\le H-R.
\]
Among the \(H\) shifts of a length-\(H\) block partition, the physical
interval containing the quadruple exists for exactly \(H-s\) shifts.
Thus it is selected in at least \(R\) shifted partitions. If
\(Q_p^{(t)}\) denotes the core-start count for shift \(t\), then, after the
already removed global endpoint strips,
\[
 RQ_p^{\rm core}
 \le\sum_{t\bmod H}Q_p^{(t)}.
 \tag{9.1}
\]
The first-zero bound on each shift gives only
\[
 \sum_tQ_p^{(t)}\le HZ(p),
 \qquad
 Q_p^{\rm core}\le\frac HRZ(p),
 \tag{9.2}
\]
which loses the factor
\[
 \frac HR=H^{5/41+\xi}.
\]

Trying to pass through shifted active blocks is no better. The packing cap
(0.3) gives
\[
 RQ_p^{\rm core}
 \ll \frac HL\sum_{t\bmod H}A_p^{(t)}.
 \tag{9.3}
\]
Across all shifts there are \(O(p)\) physical shifted blocks, so
\[
 Q_p^{\rm core}\ll \frac{pH}{LR}.
 \tag{9.4}
\]
After summing over primes, this is
\[
 \ll \frac{P^2H}{LR}
 =H^{333/82+O(\xi)},
 \tag{9.5}
\]
well above \(H^{159/41}=H^{318/82}\).

The factor \(R\) in (9.1) is combinatorially sharp: intervals of span
\(H-R\) have admissible-shift arcs of length exactly \(R\), and without
arithmetic information their start residues modulo \(H\) may align those
arcs. Again this is a method-saturation configuration, not an Apéry-zero
counterexample. Block shifting supplies multiplicity, but not cancellation
or active-orbit dispersion.

## 10.1 Active prime--blocks

Put

The exact desired active sparsity is

Fix \(\eta>0\), set

and define the ultra-high-frequency actual-orbit correlation
\[
 \mathfrak H_{\rm act}(P,H;\eta)
 :=\operatorname{Re}
 \sum_{P<p\le2P}\frac{\log p}{p}
 \sum_{|k|_p>K_{\rm act}}
 F_p(k)\overline{\Omega_p(k)}.
 \tag{10.1}
\]
By (4.5) and (6.11), for every
\[
 0<\varepsilon<\eta/2,
\]
the explicit inequality
\[
 \boxed{
 \mathfrak H_{\rm act}(P,H;\eta)
 \ll P^{159/100-\varepsilon}}
 \tag{AO-PB}_{\eta,\varepsilon}
\]
implies \((\mathrm{PB})_\delta\) for every
\[
 0<\delta<\frac{100}{41}\varepsilon.
\]
Conversely, if active blocks saturate the \(P^{159/100}\) frontier, then
(6.11) forces the high-frequency term (10.1) to carry that frontier. Thus
\((\mathrm{AO\!\!-\!PB})\) is not hiding a low-frequency loss: it is the
precise residual after an unconditional power-saving deletion.

This is the smallest explicit active-orbit input isolated by the present
attack. It concerns only actual first core starts and only frequencies of
wavelength at most \(H^{1/41+o(1)}\); it neither asserts nor implies a global
improvement for \(\sum Z(p)\).

## 10.2 Original total selected-quadruple mass

Active sparsity alone is not sufficient for the original \(Q_p\), because
(0.3) allows many core starts in one active block. To make this exact,
order the starts in each block and let \(E_{p,\nu}\) contain the \(\nu\)-th
start from every block having at least \(\nu\) starts. Then
\[
 Q_p=\sum_{\nu\le H/L+O(1)}|E_{p,\nu}|.
 \tag{10.2}
\]
A theorem only for \(\nu=1\) leaves the entire occupancy factor \(H/L\).

For the full actual selector, put
\[
 K_{\rm core}=P^{193/200-\eta}
\]
and
\[
 \mathfrak H_{\rm core}(P,H;\eta)
 :=\operatorname{Re}
 \sum_{P<p\le2P}\frac{\log p}{p}
 \sum_{|k|_p>K_{\rm core}}
 F_p(k)\overline{G_p(k)}.
 \tag{10.3}
\]
The original target follows from the single inequality
\[
 \boxed{
 \mathfrak H_{\rm core}(P,H;\eta)
 \ll P^{159/100-\varepsilon}}
 \tag{AO-HF}_{\eta,\varepsilon}

provided
\[
 0<\varepsilon<
 \frac\eta2-\frac{41}{200}\xi.
 \tag{10.4}
\]
Indeed, (6.7) treats the complementary frequencies, and
\(\varepsilon=(41/100)\delta\) gives
\[
 \sum_{P<p\le2P}\log p\,Q_p
 \ll H^{159/41-\delta+o(1)}.
\]

This is the exact full-mass inequality still missing. It is strictly more
localized than any improvement of the global first-zero moment: its second
factor is the selector of actual balanced, simple, physically interior,
literal-first-return core starts only.

# 11. Saturation audit: why weaker inputs cannot force the exponent

The following are logical saturation models for the listed estimates, not
claims that the configurations occur for Apéry zeros.

### 11.1 One actual start per physical block

There are weighted \(P^2/H=P^{159/100+o(1)}\) physical prime--blocks. One
core start in every block saturates the \(\delta=0\) activity frontier and
respects every cardinality bound used above. Thus physical interiority,
balanced gaps, and one-per-block injectivity do not by themselves imply a
power-density saving.

### 11.2 The first-zero row can fit inside the occupancy cap

Putting
\[
 H^{1/41}=H^{2/82}
\]
starts in every active block gives total mass
\[
 \frac{P^2}{H}\,H^{1/41}
 =P^{8/5+o(1)}.
\]
This is allowed by
\[
 H^{1/41}<H^{5/82+\xi}\asymp H/L.
\]
Therefore even a sharp count of all physical active blocks does not improve
the total first-zero row unless one also controls occupancy or the summed
layers in (10.2).

### 11.3 Hilbert-space saturation

The Cauchy--Parseval proof sees only the two energies
\[
 \sum|F_p|^2=pZ(p),
 \qquad
 \sum|G_p|^2=pQ_p.
\]
Vectors concentrated on the same high-frequency subspace saturate that
argument at the \(P^{8/5}\) scale. The low-frequency theorem rules out
such saturation below the cutoffs (6.6) and (6.10), but generic Hilbert-space
information says nothing about the remaining subspace.

### 11.4 Moving-target saturation

For an arbitrary nonautonomous projective orbit one may prescribe a moving
target set containing the orbit point in every block. The recurrence makes
both the orbit and target sets arithmetic, but no present theorem quantifies
their relative motion. Hence (2.8) alone cannot yield sparsity; the new
input must distinguish the actual Apéry boundary orbit from an arbitrary
moving orbit.

These audits identify exactly where the missing \(H^{1/41}\) cost lives:
not in another local return resultant, but in the ultra-high-frequency or,
equivalently, moving-target correlation of the distinguished prefix orbit.

\begin{lemma}[Exact continuant transport]\label{lem:ao-block-transport}
Let $u_n$ satisfy
\[
 (n+1)^3u_{n+1}=P(n)u_n-n^3u_{n-1},
 \qquad P(n)=(2n+1)(17n^2+17n+5),

 =N_r(J)u_{J+1}
 -(J+1)^3N_{r-1}(J+1)u_J.

\begin{proof}
The assertion for $r=1$ follows from $N_1=1$ and $N_0=0$.
