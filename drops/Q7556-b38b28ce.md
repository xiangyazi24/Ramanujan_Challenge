## 2. Exact moment inequalities

### 2.1 Two-group ANOVA

The exact variance decomposition is

```text
sum_t (A_q(t)-bar_mq)^2
 = sum_(t in Z_q)   (A_q(t)-m_1(q))^2
 + sum_(t notin Z_q)(A_q(t)-m_0(q))^2
 + G_q delta_q^2.                                       (2.1)
```

Thus

```text
G_q delta_q^2 <= sum_t(A_q(t)-bar_mq)^2.               (2.2)
```

This is exactly the existing UVD/second-moment route.

### 2.2 Fourth between-group term

Jensen in the two groups and `(1.9)` give

```text
sum_t |A_q(t)-bar_mq|^4
 >= Z(q)(1-rho_q)^4 delta_q^4
  + (q-Z(q))rho_q^4 delta_q^4
  = G_q[(1-rho_q)^3+rho_q^3]delta_q^4.                 (2.3)
```

Since

```text
(1-rho)^3+rho^3 = 1-3rho(1-rho) >= 1/4,
```

one obtains

```text
G_q delta_q^4
 <= 4 sum_t |A_q(t)-bar_mq|^4.                         (2.4)
```

### 2.3 Stronger one-sided domination

If `Delta_q>0`, then `m_0(q)>=0` implies `Delta_q<=m_1(q)`. For every real `r>=1`, Jensen gives

```text
Z(q)m_1(q)^r <= sum_(t in Z_q) A_q(t)^r.
```

Since `G_q<=Z(q)`,

```text
G_q Delta_q^r
 <= sum_(t in Z_q) A_q(t)^r
 <= sum_(t mod q) A_q(t)^r.                            (2.5)
```

After summing,

```text
C_r^+(T,J) := sum_q G_q Delta_q^r
           <= P_r_pre(T,J) := sum_(q,t) A_q(t)^r.       (2.6)
```

The final inequality is deliberately crude but noncircular. In particular, no unproved factor `rho_q` is inserted on the right.

### 2.4 What spacing can and cannot refine

Let

```text
s_q = #{t in Z_q : A_q(t)>0}.
```

Hölder gives

```text
M_q^r <= s_q^(r-1) sum_(t in Z_q) A_q(t)^r,
```

and hence

```text
G_q Delta_q^r
 <= (1-rho_q)(s_q/Z(q))^(r-1)
    sum_(t in Z_q) A_q(t)^r.                           (2.7)
```

If the support of `A_q` lay in a bounded number of deterministic intervals, the subinterval theorem would control `s_q`. The literal support is instead a union of inverse leaves, and the union of candidate windows can be macroscopic. Also `Z(q)` may equal one. Thus `(2.7)` gives no uniform power or logarithmic saving from current spacing information.

## 6. Entropy route

Assume `A_q^0>0` and define

```text
P_q(t) = A_q(t)/A_q^0
s_q    = P_q(Z_q) = M_q/A_q^0.
```

Under the uniform measure on the fibre, `Z_q` has mass `rho_q`. Data processing for relative entropy gives

```text
H_q^load
 := sum_t A_q(t) log(qA_q(t)/A_q^0)
 >= A_q^0 d(s_q || rho_q),                             (6.1)
```

where

```text
d(s||rho)
 = s log(s/rho)+(1-s)log((1-s)/(1-rho)).
```

Equivalently,

```text
A_q^0 d(s_q||rho_q)
 = q[ rho_q m_1(q) log(m_1(q)/bar_mq)
     +(1-rho_q)m_0(q) log(m_0(q)/bar_mq) ].             (6.2)
```

Put

```text
a_q = (M_q-rho_qA_q^0)_+
D_q = rho_qA_q^0
nu_q = a_q/D_q
```

when `D_q>0`. Then

```text
nu_q = (1-rho_q)Delta_q/bar_mq.                        (6.3)
```

For `s>=rho`,

```text
(1-s)log((1-s)/(1-rho)) >= -(s-rho).
```

Therefore, with

```text
h(u)=(1+u)log(1+u)-u,
```

one has

```text
H_q^load >= D_q h(nu_q).                               (6.4)
```

Since `h(u)/u` is increasing, splitting at `nu_q=R` gives

```text
APUC_A^+
 <= R D + [R/h(R)] H^load,                             (6.5)
```

where

```text
D      = sum_q rho_q A_q^0
H^load = sum_q H_q^load.
```

The density mean is already subcritical:

```text
D <<_J T^(-1/3)M0
  = T^(28/15)L^(-3/5)
  =: D0.                                                (6.6)
```

For integer `A>=1`, `A log A <= A(A-1)`. Also

```text
A_q^0 log(q/A_q^0) <= A_q^0 log q.
```

Hence

```text
H^load <= F2_pre+O_J(L)M1_pre.                         (6.7)
```

This is noncircular: its right side is entirely pre-upper.

The largest relative cutoff whose low part is at target scale is

```text
Rmax = B/D0 = T^(2/15)L^(-7/5).                        (6.8)
```

Take `R=Rmax/omega(T)` with `omega(T)->infinity` and `omega(T)=T^o(1)`. Then the low term is `B/omega`, while

```text
R/h(R) asymp 1/L.
```

Thus the entropy route closes under

```text
H^load = o_J(BL) = o_J(T^2/L).                         (6.9)
```

The current bound is only

```text
H^load
 <<_J T^(13/5)L^(-9/5)+T^(11/5)L^(2/5),               (6.10)
```

which misses `(6.9)`. The leading term exceeds the threshold by `T^(3/5)L^(-4/5)`.

If one chooses `R=Rmax/L`, the low part is `B/L`, while the high part is approximately `H^load/L`. Therefore:

```text
high part o(B):       requires H^load=o(BL);
whole sum O(B/L):     requires H^load=O(B);
whole sum o(B/L):     requires H^load=o(B),
                      with a further slowly growing cutoff factor.
```

This also shows why entropy can buy at most one logarithm: on a nonempty zero fibre, `1/q<=rho_q`, so the maximal relative alignment has logarithm at most `log q=O(L)`.

### Support-relative entropy does not remove the selector problem

Let

```text
S_q = {t:A_q(t)>0}
H_q = |S_q|
r_q = |S_q intersect Z_q|/H_q.
```

Since positive integer loads imply `H_q<=A_q^0`,

```text
sum_(t in S_q) A_q(t) log(H_q A_q(t)/A_q^0)
 <= sum_t A_q(t)log A_q(t)
 <= sum_t(A_q(t))_2.                                   (6.11)
```

This controls the difference between the load-biased zero mass `s_q` and the support occupancy `r_q`. But

```text
s_q-rho_q = (s_q-r_q)+(r_q-rho_q).                    (6.12)
```

The second term is a support-selector alignment problem. Current spacing permits `S_q` itself to be a nonconsecutive reflection-invariant subset of `Z_q`. Thus support-relative entropy only moves the open theorem into a support-level PRE-CUT statement.

## Final assessment

The contrast identity

```text
M_q-(Z(q)/q)A_q^0
 = G_q(m_1(q)-m_0(q))
```

is exact and useful. The requested fourth-moment inequality is valid and sharp for its information. Its clean uniform threshold is

```text
T^(16/5)L^(-28/5).
```

But the current first and second moment banks do not reach it. The first genuinely new factorial input could already be the third moment at

```text
T^(14/5)L^(-22/5).
```

Rare high-alignment rows become deletable only after one of these new moments is proved. A deliberate one-log low-row cutoff demands three extra logarithms of fourth-moment decay merely for closure and four to preserve the one-log final gain.

The entropy route confirms that extreme alignment can buy at most one logarithm, and it exposes the missing pre-upper load entropy `o(T^2/L)`. The current factorial bounds are still power-supercritical.

Therefore the present conclusion is negative:

```text
upper zero size/spacing + pre-upper first moment + pre-upper PF2
    do not delete the high-alignment rows;

a fourth-moment split is valid but needs PRE-F4;
PRE-F3 is an even lower-order sufficient alternative;

entropy can save at most one logarithm and needs PRE-ENT;

no unconditional one-log gain follows from the currently banked moments.
```
