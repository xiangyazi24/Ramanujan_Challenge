## 2. Exact second- and fourth-moment inequalities

### 2.1 Two-group ANOVA

For every `q`,

\[
\begin{aligned}
\sum_t(A_q(t)-\overline m_q)^2
={}&
\sum_{t\in\mathcal Z_q}(A_q(t)-m_1(q))^2\\
&+
\sum_{t\notin\mathcal Z_q}(A_q(t)-m_0(q))^2\\
&+G_q\delta_q^2.
\end{aligned}
\tag{2.1}
\]

Thus

\[
G_q\delta_q^2
\le
\sum_t(A_q(t)-\overline m_q)^2.
\tag{2.2}
\]

Summing `(2.2)` is exactly the usual UVD/second-moment route. It does not create a new saving.

### 2.2 Exact fourth between-group term

Jensen inside the two groups and `(1.9)` give

\[
\begin{aligned}
\sum_t|A_q(t)-\overline m_q|^4
\ge{}&
Z(q)(1-\rho_q)^4\delta_q^4\\
&+(q-Z(q))\rho_q^4\delta_q^4\\
={}&
G_q\bigl((1-\rho_q)^3+\rho_q^3\bigr)\delta_q^4.
\end{aligned}
\tag{2.3}
\]

Since

\[
(1-\rho)^3+\rho^3
=1-3\rho(1-\rho)\ge\frac14,
\]

one obtains

\[
\boxed{
G_q\delta_q^4
\le
4\sum_t|A_q(t)-\overline m_q|^4.
}
\tag{2.4}
\]

This is the literal fourth-order analogue of ANOVA.

### 2.3 Stronger one-sided raw-moment domination

For the positive contrast there is a sharper inequality. If `Delta_q>0`, then `m_0(q)>=0` implies

\[
\Delta_q\le m_1(q).
\]

For every real `r>=1`, Jensen gives

\[
Z(q)m_1(q)^r
\le
\sum_{t\in\mathcal Z_q}A_q(t)^r.
\]

Because `G_q<=Z(q)`, one gets

\[
\boxed{
G_q\Delta_q^r
\le
\sum_{t\in\mathcal Z_q}A_q(t)^r
\le
\sum_{t\bmod q}A_q(t)^r.
}
\tag{2.5}
\]

After summing,

\[
\boxed{
\mathcal C_r^+(T,J)
:=\sum_qG_q\Delta_q^r
\le
P_r^{\rm pre}(T,J)
:=\sum_{q,t}A_q(t)^r.
}
\tag{2.6}
\]

The final inequality in `(2.5)` is deliberately crude but noncircular. We do **not** write

\[
\sum_{t\in\mathcal Z_q}A_q(t)^r
\approx \rho_q\sum_tA_q(t)^r.
\]

That would assume the upper/lower mixing which is precisely open.

### 2.4 What spacing can refine

Let

\[
s_q:=\#\{t\in\mathcal Z_q:A_q(t)>0\}.
\]

Hölder yields

\[
M_q^r
\le
s_q^{r-1}
\sum_{t\in\mathcal Z_q}A_q(t)^r.
\]

Therefore

\[
\boxed{
G_q\Delta_q^r
\le
(1-\rho_q)
\left(\frac{s_q}{Z(q)}\right)^{r-1}
\sum_{t\in\mathcal Z_q}A_q(t)^r.
}
\tag{2.7}
\]

If the support of `A_q` were contained in a bounded number of deterministic intervals `I_j`, `(0.5)` would give

\[
s_q\ll\sum_j(|I_j|^{2/3}+1).

For the literal q6 load, however, the support is a union of inverse leaves, not a bounded interval family with a proved small occupancy ratio. The natural union of all candidate windows can have macroscopic length. Moreover `Z(q)` may equal one, in which case the factor in `(2.7)` can be one. Thus `(2.7)` supplies no uniform power or logarithmic saving from the current spacing theorem.

## 6. Entropy inequality and the maximal one-log gain

The entropy route measures **relative** rather than absolute conditional alignment.

Assume `A_q^0>0` and define the load probability distribution

\[
\nu_q(t):=\frac{A_q(t)}{A_q^0}
\]

on `Z/qZ`. Put

\[
s_q:=\nu_q(\mathcal Z_q)=\frac{M_q}{A_q^0}.
\tag{6.1}
\]

Under the uniform distribution on the fibre, the same set has mass `rho_q`. Data processing for relative entropy gives

\[
\boxed{
\mathscr H_q^{\rm load}
:=
\sum_tA_q(t)
\log\frac{qA_q(t)}{A_q^0}
\ge
A_q^0\,d(s_q\|\rho_q),
}
\tag{6.2}
\]

where

\[
d(s\|\rho)
=s\log\frac{s}{\rho}
+(1-s)\log\frac{1-s}{1-\rho}.
\]

Equivalently, the grouped entropy is

\[
\begin{aligned}
A_q^0d(s_q\|\rho_q)
=q\bigg[{}
&\rho_qm_1(q)\log\frac{m_1(q)}{\overline m_q}\\
&+(1-\rho_q)m_0(q)\log\frac{m_0(q)}{\overline m_q}
\bigg].
\end{aligned}
\tag{6.3}
\]

This is another exact inequality involving `m_1-m_0`.

### 6.1 Bennett form

Put

\[
a_q:=(M_q-\rho_qA_q^0)_+,
\qquad
D_q:=\rho_qA_q^0,
\qquad
u_q^{\rm rel}:=\frac{a_q}{D_q}
\]

when `D_q>0`. Then

\[
\nu_q^{\rm rel}
=
\frac{(1-\rho_q)\Delta_q}{\overline m_q}.
\tag{6.4}
\]

For `s>=rho`, the complement term in binary relative entropy obeys

\[
(1-s)\log\frac{1-s}{1-\rho}\ge-(s-\rho).
\]

Consequently, with

\[
h(u):=(1+u)\log(1+u)-u,
\]

one has

\[
\boxed{
\mathscr H_q^{\rm load}
\ge
D_qh(\nu_q^{\rm rel}).
}
\tag{6.5}
\]

The function `h(u)/u` is increasing because

\[
\frac{d}{du}\frac{h(u)}u
=
\frac{u-\log(1+u)}{u^2}>0.
\]

Splitting at a relative alignment `R>0` gives

where

The already-banked density mean satisfies

\ll_J
