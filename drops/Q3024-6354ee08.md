# 1. Exact support of `Lambda^q`

Write

\[
\Lambda
=(1+x)(1+y)(1+z)
\left(1+\frac{(1+y)(1+z)}{xyz}\right).
\tag{6}
\]

Expand the last factor:

\[
\Lambda^q
=
\sum_{t=0}^q
\binom qt
x^{-t}y^{-t}z^{-t}
(1+x)^q(1+y)^{q+t}(1+z)^{q+t}.
\tag{7}
\]

Every coefficient in `(7)` is nonnegative, so there is no cancellation in the support.
For a fixed `t`, the exponent ranges are

\[
-t\le u\le q-t,
\qquad
-t\le v\le q,
\qquad
-t\le w\le q.
\tag{8}
\]

Thus `(u,v,w)` occurs iff there is an integer `t` with

\[
\max(0,-u,-v,-w)\le t\le\min(q,q-u).
\tag{9}
\]

The existence condition `(9)` is equivalent to

\[
-q\le u,v,w\le q,
\qquad
v\ge u-q,
\qquad
w\ge u-q.
\]

This proves `(1)`.

## 1.1 Exact Ehrhart count

For `u<=0`, both `v,w` have `2q+1` choices.  For `1<=u<=q`, each of `v,w` has

\[
q-(u-q)+1=2q-u+1
\]

choices.  Hence

\[
\begin{aligned}
|S_q|
&=(q+1)(2q+1)^2
 +\sum_{u=1}^q(2q-u+1)^2\\
&=(q+1)(2q+1)^2
 +\sum_{j=q+1}^{2q}j^2\\
&=4q^3+8q^2+5q+1
 +\frac{q(2q+1)(7q+1)}6\\
&=\boxed{\frac{38q^3+57q^2+31q+6}{6}}.
\end{aligned}
\tag{10}
\]

Therefore the Euclidean leading coefficient is `19/3` and the normalized three-dimensional volume is

\[
\boxed{3!\operatorname{Vol}(P)=38.}
\tag{11}
\]

The associated Ehrhart `h^*`-polynomial is

\[
\boxed{1+18T+18T^2+T^3,}
\tag{12}
\]

because `L_P(0)=1`, `L_P(1)=22`, `L_P(2)=100`, and the coefficients sum to the normalized volume `38`.

This is the exact geometric source of the old number `38`.  It is useful, but it is not yet the sequence-rank theorem in the question.

# 3. Why the ambient Dwork number `38` is not the answer

A natural but invalid shortcut is:

```text
Newton normalized volume = 38
=> Dwork/GKZ cohomology has rank 38
=> all sequences k -> c_k(-u) lie in a 38-dimensional Q-space.
```

The last implication is false.  The first rank is a rank over a function/differential field (or an ambient cohomological rank); the question asks for a **constant-field `Q`-linear span of coefficient sequences**.  Rational functions of the parameter, derivatives, or contiguity operators can produce arbitrarily many `Q`-independent sequences while remaining inside one finite-rank differential module.

There is an exact internal witness that no constant `38`-dimensional `Q`-bound can hold.

## Lemma 3.1 — triangular independent family

For every `q>=0`, the sequences

\[
\boxed{
s_j(k):=c_k(0,-j,-j),\qquad 0\le j\le q,}
\tag{17}
\]

belong to `M_q` and are linearly independent over `Q`.

### Proof

Take

\[
u_j=(0,j,j).
\]

By `(1)`, `u_j\in S_q` for `j<=q`, so `s_j(k)=c_k(-u_j)` belongs to `M_q`.

If `k<j`, the exponent `(0,-j,-j)` is not in `S_k`, since its second coordinate is less than `-k`.  Hence

\[
c_k(0,-j,-j)=0\qquad(k<j).
\tag{18}
\]

At `k=j`, use `(14)` with `(u,v,w)=(0,-j,-j)`:

\[
 c_j(0,-j,-j)
 =\sum_t
 \binom jt^2
 \binom{2j-t}{2j}^2.
\]

The final binomial is nonzero only at `t=0`, where it is `1`.  Therefore

\[
\boxed{c_j(0,-j,-j)=1.}
\tag{19}
\]

The matrix `(s_j(k))_{0\le k,j\le q}` is lower triangular with diagonal `1`.  Thus the sequences are independent.  QED.

Consequently

\[
\boxed{\dim M_q\ge q+1.}
\tag{20}
\]

In particular, for `q>=38`, `dim M_q>38`.  So the ambient Newton-volume number cannot be interpreted as the desired constant-field span rank.

This does **not** contradict Dwork/Griffiths--Dwork theory.  It identifies exactly the coefficient-field error that a proposed proof must avoid.

# 4. What a valid Griffiths--Dwork proof would have to prove

A valid use of Jacobian/Griffiths--Dwork reduction has to retain the filtration cost when rational parameter coefficients are cleared.

For a Laurent polynomial `A`, put

\[
\mathcal G_A(z)
:=\sum_{k\ge0}\operatorname{CT}(A\Lambda^k)z^k
=\operatorname{CT}\frac{A}{1-z\Lambda}.
\tag{21}
\]

A differential-cohomological reduction may express `G_A` in a finite basis over `Q(z)`.  To get a bound on `dim_Q M_q`, one must additionally prove that for all monomials `A=X^{-u}`, `u in S_q`, the rational coefficient functions lie in a `Q`-space whose dimension is at most `8q-2` after common denominators are cleared.

That is the missing filtration theorem.  Merely saying “the Gauss--Manin rank is bounded” does not prove it, by Lemma 3.1.

The exact rank data suggest the much sharper graded statement

\[
\operatorname{gr}_1 M\text{ has dimension }5,
\qquad
\operatorname{gr}_q M\text{ has dimension }8\ (q\ge2).
\tag{22}
\]

Equivalently the conjectural Hilbert series is

\[
\boxed{
\sum_{q\ge0}\dim(M_q/M_{q-1})T^q
=1+5T+8T^2+8T^3+\cdots
=\frac{1+4T+3T^2}{1-T}.
}
\tag{23}
\]

and the filtered rank series would be

\[
\boxed{
\sum_{q\ge0}\dim M_q\,T^q
=\frac{1+4T+3T^2}{(1-T)^2}.
}
\tag{24}
\]

Formula `(24)` explains `1,6,14,22,30,38,...`, but at present it is a **target Hilbert series**, not a theorem extracted from the first five values.

# 5. Machine-verifiable all-`k` certificate schema

The right certificate is a symbolic telescoping certificate, not a long prefix of values.

For `u=(u_1,u_2,u_3)` define the shifted summand for `s_u(k)=c_k(-u)` by

\[
T_{k,u}(t)
:=
\binom kt
\binom{k}{t+u_1}
\binom{2k-t}{k+u_2}
\binom{2k-t}{k+u_3}.
\tag{25}
\]

Use the central summand

\[
W_k(t)
:=T_{k,0}(t)
=\binom kt^2\binom{2k-t}{k}^2.
\tag{26}
\]

Every `T_{k,u}/W_k` is a rational function of `(k,t)` after replacing binomial ratios by finite products.  The base ratio is

\[
\boxed{
\frac{W_k(t+1)}{W_k(t)}
=\frac{(k-t)^4}{(t+1)^2(2k-t)^2}.
}
\tag{27}
\]

Suppose we want to certify the all-`k` identity

\[
s_u
=\sum_i\alpha_i s_{a_i}
 +\sum_{v\in S_{q-1}}\beta_v s_v.
\tag{28}
\]

Let

\[
Q(k,t)
:=\frac{T_{k,u}(t)}{W_k(t)}
 -\sum_i\alpha_i\frac{T_{k,a_i}(t)}{W_k(t)}
 -\sum_v\beta_v\frac{T_{k,v}(t)}{W_k(t)}.
\tag{29}
\]

It is enough to give one rational function `R(k,t)` satisfying

\[
\boxed{
Q(k,t)
=
\frac{(k-t)^4}{(t+1)^2(2k-t)^2}R(k,t+1)-R(k,t).
}
\tag{30}
\]

After multiplying through by the common denominator, `(30)` is a polynomial identity in `Q[k,t]`; it is directly checkable by a CAS using exact integer arithmetic.  Summing `(30)W_k(t)` over all integers `t` telescopes.  Because the binomial convention makes `W_k(t)` finitely supported, the boundary term vanishes identically.  Thus `(28)` holds for every integer `k>=0`.

This is a theorem certificate, not interpolation.

## 5.1 Shell certificate

A proof of `(SHELL)` can therefore be delivered as follows.

For each `q>=2`:

1. choose eight shell anchors
   \[
   a_{q,1},\ldots,a_{q,8}\in S_q\setminus S_{q-1};
   \]
2. for every `u in S_q\setminus S_{q-1}`, give constants `alpha_i`, inner-shell constants `beta_v`, and a rational `R_u(k,t)` satisfying `(30)`;
3. organize the formulas by the eight facet cases in `(13)`;
4. verify the cleared polynomial identities symbolically.

Then every shell class lies in the span of eight anchors modulo `M_{q-1}`, proving

\[
\dim(M_q/M_{q-1})\le8.
\]

For `q=1`, the analogous certificate uses six anchors and proves `dim M_1<=6`.

The exact finite ranks quoted in the question indicate that such certificates should be sharp for `q<=5`, but the current accessible files do not provide a `q`-uniform family of `R_u(k,t)`.  Producing these rational telescopers, or an equivalent Gröbner/Griffiths--Dwork normal form with the same Hilbert series `(23)`, is the smallest missing identity.

# 6. Exact convolution target

For `r>=q`, multiplication of Laurent polynomials gives

\[
\Lambda^r=\Lambda^q\Lambda^{r-q}.
\]

Taking constant terms,

\[
\begin{aligned}
b_r
&=\operatorname{CT}\Lambda^r\\
&=\sum_{u\in S_q}
 [X^u]\Lambda^q\,[X^{-u}]\Lambda^{r-q}\\
&=\boxed{\sum_{u\in S_q}c_q(u)c_{r-q}(-u)}.
\end{aligned}
\tag{31}
\]

This is the target functional in the question.

If `r<q`, `(31)` is not the correct splitting because `r-q<0`.  But for fixed `q`, the possible target indices `0<=r<q` form a fixed finite set; any target prime then divides one of the fixed integers `b_0,...,b_{q-1}`.  Those are fixed-prime exceptions and are not part of the asymptotic actual-locus packet.  In particular, `r=0` never contributes because `b_0=1`.

# 7. Scoped no-go: characteristic-zero linear toric syzygies cannot create a second target equation

This part is completely unconditional and does not depend on the unproved rank formula.

Let

\[
v_k=(c_k(-u))_{u\in S_q}\in\mathbf Q^{S_q}.
\tag{32}
\]

Define the full characteristic-zero linear syzygy space

\[
K_q
:=\{\lambda\in\mathbf Q^{S_q}:
\lambda\cdot v_k=0\text{ for every }k\ge0\}.
\tag{33}
\]

Thus

\[
\mathbf Q^{S_q}/K_q
\]

is the dual coordinate space of the actual sequence span.

Put

\[
a_q=(c_q(u))_{u\in S_q}.
\tag{34}
\]

Equation `(31)` says

\[
\boxed{a_q\cdot v_{r-q}=b_r.}
\tag{35}
\]

The class of `a_q` is nonzero over `Q`: evaluate it on `v_0`.  Since

\[
v_0(u)=\mathbf 1_{u=0},
\]

we get

\[
a_q\cdot v_0=c_q(0)=b_q>0.
\tag{36}
\]

Hence

\[
 a_q\notin K_q.
\tag{37}
\]

Now impose the target condition in some characteristic `p` for which the characteristic-zero quotient remains valid (in particular, exclude the fixed denominator/saturation primes of a chosen integral syzygy basis).  Suppose a second linear equation

\[
d\cdot v_{r-q}=0
\tag{38}
\]

is obtained **only** by taking linear combinations of

- the characteristic-zero toric syzygies `K_q`, and
- the target equation `a_q\cdot v_{r-q}=0`.

Then by elementary linear algebra

\[
d\in K_q+\mathbf Q a_q
\]

(or after reduction, `\overline K_q+\mathbf F_p\overline a_q`).  Therefore in the quotient

\[
\boxed{[d]\in\mathbf Q[a_q],}
\tag{39}
\]

so the second equation is proportional to the first one.  It is not independent.

This proves:

> **Linear toric-syzygy no-go.** Characteristic-zero linear relations among the coordinate sequences can compress the ambient coordinate vector to its true quotient, but after that compression the single target condition `b_r=0` remains one hyperplane condition.  The linear syzygy module alone cannot manufacture a second independent vanishing functional.

A second relation can still come from something genuinely new:

1. a characteristic-`p` rank drop not lifting to characteristic zero;
2. a nonlinear quadratic/determinantal identity;
3. an adjacent jet/Casoratian condition;
4. Frobenius/Cartier structure using the defining characteristic.

The no-go is deliberately scoped only to **linear characteristic-zero toric syzygies**.
