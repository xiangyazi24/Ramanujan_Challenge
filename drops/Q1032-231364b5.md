## 1. Corrected identity

Let

```text
w_l(x)=sum_{k=0}^H binom(x,k) M_(k,l).
```

For each boundary parameter b, the truncated block

```text
R_(H,H-b)=M[H-b+1..H,0..b]
```

has a primitive kernel vector q^(b).  Padding q^(b) to length H+1 and forming

```text
Q_H=[q^(0) q^(1) ... q^(H)]
```

with columns ordered by increasing b gives the coefficient change of basis.  The exact check is:

```text
(P_(H,H)(x),...,P_(H,0)(x)) = w(x)^T Q_H.
```

The equality is over Z[x].  The sign convention is fixed by requiring the last nonzero coordinate of every primitive kernel vector to be positive.  Without this normalization the identity holds only up to independent column signs.

No total positivity assumption is used.  In particular, the existence of negative minors in order six only prevents using a positivity shortcut; it does not invalidate the integer kernel construction.

## 2. Rank-defect handling

The possible rank defect is handled by computing the rational rank of each block R_(H,a) before kernel extraction.  A zero determinant of a candidate maximal minor is not interpreted as positivity failure.  Instead the primitive kernel is taken from the actual nullspace lattice.

The corrected algorithm therefore does:

```text
for b=0..H:
    compute R_(H,H-b)
    compute integer null lattice
    choose primitive generator q^(b)
    normalize sign
```

No division by a guessed determinant is introduced.

## 4. Obstruction

The first obstruction is:

```text
log |det(Q_H)| remains linear/exponential scale in H.
```

The signed reflection

```text
binom(-n-1,k)=(-1)^k binom(n+k,k)
```

does identify a common Apéry reflection pattern, but it does not annihilate the primitive lattice index.  The positive and negative evaluations live in the same transformed lattice; they do not produce an independent low-height quotient.

A relation of the form

```text
T^+ G^+ + T^- G^- = 0
```

would require coefficients carrying the inverse Smith factors.  The exact Smith decomposition shows those factors are not bounded by exp(o(H)).
