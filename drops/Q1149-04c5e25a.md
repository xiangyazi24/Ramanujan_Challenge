## Exact valuation reduction

For fixed odd prime p define

\[
H(n):\quad v_p(L_j(n))+v_p(b_j)\ge 2\quad(0\le j<M).
\]

Only states with

\[
v_p(L_j(n))\in\{0,1\}
\]

matter. If the valuation is at least two, the term is already irrelevant.

The target is

\[
v_p(b_n)\ge2.
\]

The Kummer formula gives

\[
v_p(L_j)=C_1(n,j)+C_2(n,j),
\]

where

\[
C_1=\#\text{ carries in }j+(n-j)=n,
\]

and

\[
C_2=\#\text{ carries in }(M-1-j)+(n-M)=n-j-1.
\]

The second summand is the subtraction by j from M-1, not a complementary j+1 expression.

## Digit transition state

For n and j written in base p,

\[
n=\sum n_i p^i,\qquad j=\sum j_i p^i,
\]

an executable digit state at position i is:

```
(i, n_i, j_i,
 carry1,
 carry2,
 borrow_j,
 borrow_m,
 parity,
 M_digit,
 v_trunc,
 apery_residue)
```

where:

* `carry1` is the carry in j+(n-j);
* `carry2` is the carry in (M-1-j)+(n-M);
* `borrow_j` tracks the subtraction n-j;
* `borrow_m` tracks M-1-j;
* `parity` records n mod 2 because M=floor(n/2);
* `v_trunc` is the accumulated Kummer contribution truncated at 2.

A transition reads `(n_i,j_i)` and updates the two carry counters by the usual base-p addition rule. The M digits are obtained by the exact floor-halving transition:

```
h_i = (n_i - parity + p*next_parity) // 2
```

with the next parity propagated to the next digit.

## What a proof would require

A successful finite-state proof must show that every accepting state satisfying H forces the Apéry residue state

```
b_n mod p^2 = 0
```

rather than merely controlling the Newton coefficients.

The missing bridge is a transition statement of the form:

> For every reachable state with no index j having valuation contribution below two, the Apéry p-adic residue component must enter the zero class.

This is stronger than the Lucas congruence because the Lucas congruence only provides

\[
b_{pA+t}=b_A(b_t+2\epsilon(t)ApD_s)\pmod {p^2},
\]

and does not by itself identify which low digit states are forced by the Newton kernel.

## Remaining unresolved configurations

The unresolved cases are exactly the digit configurations where:

1. the minimal Kummer valuation is 0 or 1;
2. every such index j has
   \(v_p(L_j)+v_p(b_j)\ge2\);
3. the high part N in n=pN+r is arbitrary;
4. the derivative term
   \(2\epsilon(r)NpD_s\)
   can contribute a nonzero first p-adic correction.

These are the states where a direct descent has to remove the high prefix or prove a forced cancellation.

## Verification code skeleton

```python
from math import comb


def apery(n):
    return sum(comb(n,k)**2*comb(n+k,k)**2 for k in range(n+1))


def vp(x,p):
    x=abs(x)
    c=0
    while x and x%p==0:
        x//=p
        c+=1
    return c


def L(n,j):
    m=n//2
    return comb(n,j)*comb(n-j-1,m-1-j)


def check(p,n):
    b=[apery(i) for i in range(n+1)]
    m=n//2
    return min(vp(L(n,j),p)+vp(b[j],p) for j in range(m))
```

This verifies the Kummer side but does not prove the missing Apéry transition. A full proof would require adding the residue-state transition and proving closure under arbitrary high prefixes.

Therefore the exact status is: finite-state reduction is available; the exponent-two implication is not yet established from the supplied congruences alone.
