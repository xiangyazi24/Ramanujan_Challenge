# P3.2 closing route: gcd(A_r,A_s)=1 audit

## Verdict

The proposed orthogonality/Racah route does not close as stated. The displayed three-term recurrence is not by itself a positive-measure orthogonal-polynomial theorem over the finite fields required for P3.2.

What is proved is:

- `gcd(A_n,A_{n+1})=1` in good characteristic by the recurrence.
- A general `gcd(A_r,A_s)=1` theorem requires an additional invariant: a finite-field nondegenerate Racah measure, a strong zero-propagation theorem, or an explicit resultant formula.

The computational evidence is consistent with pairwise coprimality, but does not supply the missing uniform theorem.

## Consecutive case

If `alpha` is a common root of `A_n` and `A_{n+1}`, the recurrence

```
T A_n = a_n A_{n+1}-(a_n+c_n)A_n+c_n A_{n-1}
```

implies

```
c_n A_{n-1}(alpha)=0.
```

For primes not dividing the recurrence denominators this gives `A_{n-1}(alpha)=0`. Descending eventually gives `A_0(alpha)=0`, contradicting `A_0=1`.

Hence adjacent members are coprime.

## Why this does not extend automatically

For separated indices, a second-order recurrence allows a solution to vanish at two separated positions. The Casoratian only proves independence of fundamental solutions; it does not forbid separated zeros of one solution. This is the same obstruction encountered in the earlier Casoratian route.

## Orthogonality route

If one had a genuine orthogonal family

```
∫ A_r(T)A_s(T)dμ(T)=0,
```

with a positive nondegenerate measure, then simple real roots and interlacing would imply pairwise coprimality.

However Favard's theorem requires a normalized recurrence with nondegenerate recurrence coefficients. The displayed coefficients

```
a_n=(n+1)^3/(2(2n+1)),
c_n=n^3/(2(2n+1))
```

only give a formal recurrence. The required measure has not been constructed, and reduction modulo `p` can make coefficients vanish.

Therefore the orthogonality argument is not currently a proof in `F_p[T]`.

## Resultant route

Characteristic zero gives

```
Res_Q(A_r,A_s) != 0.
```

But after reduction,

```
Res_Fp(A_r,A_s)=Res_Z(A_r,A_s) mod p.
```

The relevant prime `p` depends on the Apéry zero data, so a nonzero characteristic-zero resultant is insufficient. A useful theorem would need a closed formula for the resultant with controlled prime divisors.

## Missing theorem needed for closure

One of the following would finish Q32:

1. Construct a Racah measure whose Hankel determinants remain nonzero modulo every physical prime.
2. Prove a zero-propagation invariant:

```
A_r(alpha)=A_s(alpha)=0 => recurrence coefficient contradiction.
```

3. Derive an explicit contiguous resultant formula:

```
Res(A_r,A_s)=± product of controlled nonzero factors.
```

## Final status

Proved:

```
gcd(A_n,A_{n+1})=1
```

in good characteristic.

Open:

```
gcd(A_r,A_s)=1 for arbitrary r != s in F_p[T].
```

Thus the proposed closing route reduces P3.2 to a missing nondegenerate Racah/resultant theorem; it is not completed by the current recurrence identities alone.
