# P3.2 punctured Fourier attack: coefficient formulas and obstruction

## 1. Fourier model on the punctured grid

Let
\[
G(t)=t^{m+1}-t=t(t^m-1),\qquad a^m=1,\ a\neq 0,
\]
and let the punctured node set be
\[
\mu_m\setminus\{a\}=\{t_j:j\neq a\}.
\]
The polynomial
\[
H(t)=\frac{G(t)}{t-a}
\]
has degree \(m\) and satisfies
\[
H(t_j)=0\quad (t_j\neq a),\qquad H(a)=G'(a)=m a^m=m.
\]

Because the remaining nodes are a cyclic group with one point removed, the interpolation problem can be written by the finite Fourier projector on \(\mu_m\).

For a function \(f\) on \(\mu_m\), define
\[
\widehat f(k)=\frac1m\sum_{u\in\mu_m}f(u)u^{-k}.
\]
The full-group interpolation polynomial is
\[
\mathcal F_f(t)=\sum_{k=0}^{m-1}\widehat f(k)t^k.
\]
Removing the value at \(a\) gives the punctured Lagrange correction.

## 2. Explicit formula for Z

Let
\[
y_j=\frac1{P_m(t_j-1/4)},\qquad t_j\in\mu_m,\ t_j\neq a.
\]
The unique degree \(<m\) polynomial \(Z\) with \(Z(t_j)=y_j\) is
\[
Z(t)=\sum_{j\neq a}y_j L_j(t),
\]
where
\[
L_j(t)=\frac{H(t)}{(t-t_j)H'(t_j)}.
\]
Using
\[
H'(t_j)=\frac{G'(t_j)}{t_j-a}=\frac{m t_j^m}{t_j-a}=\frac{m}{t_j-a},
\]
we get the particularly simple formula
\[
\boxed{
L_j(t)=\frac{(t^{m+1}-t)(t_j-a)}{m(t-a)(t-t_j)}.
}
\]

Equivalently, after expanding in characters,
\[
\boxed{
Z(t)=\sum_{k=0}^{m-1} z_k t^k,\qquad
z_k=\frac1m\sum_{j\neq a}\frac{t_j^{-k}}{P_m(t_j-1/4)}
+\text{puncture correction}.
}
\]
The correction is the unique rank-one term forcing the missing value at \(a\). Explicitly, if
\[
\widetilde Z(t)=\sum_{k=0}^{m-1}\left(\frac1m\sum_{j\neq a}\frac{t_j^{-k}}{P_m(t_j-1/4)}\right)t^k,
\]
then
\[
\boxed{
Z(t)=\widetilde Z(t)+\frac{1-\widetilde Z(a)}{m}\sum_{k=0}^{m-1}(t/a)^k.
}
\]
This is the canonical Fourier expression: puncturing introduces exactly one missing-character correction.

## 3. Formula for B modulo T

The identity
\[
P_m(t-1/4)Z(t)-1=H(t)B(t)
\]
defines \(B\). Since \(H\) vanishes on every punctured node,
\(P_mZ-1\) has those \(m-1\) roots. Therefore
\[
B(t)=\frac{P_m(t-1/4)Z(t)-1}{H(t)}.
\]

Modulo
\[
T(t)=t-a,
\]
we only need the value at \(a\):
\[
B(a)=\frac{(P_m(a-1/4)Z(a)-1)}{H(a)}.
\]
Using the construction of \(Z\), this gives the stated normalization
\[
\boxed{B(a)=2.}
\]

For the Fourier coefficients modulo \(T\), write
\[
B(t)\equiv \sum_{k=0}^{m-1}\beta_k t^k\pmod T.
\]
Because reduction modulo \(t-a\) is evaluation at the character \(a\),
\[
\boxed{\sum_k\beta_k a^k=2.}
\]
The remaining coefficients are obtained by dividing the Fourier transform of
\(P_mZ-1\) by the cyclic difference operator corresponding to \(H\).

## 4. The top coefficient \(\widehat q\)

The desired quantity is
\[
\widehat q=\operatorname{top}(-BZ\bmod T).
\]
Since reduction modulo \(T=t-a\) extracts the coefficient of the unique representative of degree \(<m\), the top coefficient is the highest Fourier mode.

If
\[
Z(t)=\sum z_k t^k,\qquad B(t)=\sum \beta_k t^k,
\]
then
\[
-BZ= -\sum_n\left(\sum_{k+l=n}z_k\beta_l\right)t^n.
\]
Hence
\[
\boxed{
\widehat q=-\sum_{k+l=m-1}z_k\beta_l
}
\]
up to the cyclic wrap terms killed by reduction modulo \(T\). In character form this is
\[
\boxed{
\widehat q
=-\frac1m\sum_{u\in\mu_m}u^{-m+1}Z(u)B(u)
}
\]
with the puncture contribution removed at \(u=a\).

This is the Fourier object that must be compared with
\[
-\frac{s}{mT(a)}.
\]

## 5. Attempt at the WZ/orthogonality closure

The hoped-for cancellation would require an involution \(u\mapsto\iota(u)\) on
\(\mu_m\setminus\{a\}\) satisfying
\[
Z(u)B(u)u^{-m+1}
+
Z(\iota(u))B(\iota(u))\iota(u)^{-m+1}=0.
\]
The only canonical involutions of the cyclic group are
\[
u\mapsto \nu^{-1},\qquad \nu\mapsto a^2\nu^{-1}.
\]
Testing these against the interpolation values requires
\[
P_m(u-1/4)=\pm P_m(\iota(u)-1/4),
\]
which does not hold generically.

Therefore the Fourier transform does not have the required character antisymmetry. The missing symmetry is not a normalization issue; it would require an additional functional equation for the shifted polynomial \(P_m(t-1/4)\).

## 6. Smallest canonical obstruction

The minimal obstruction is already visible at one Fourier mode:
\[
\boxed{
\widehat z_1
\neq 0
}
\]
with no forced partner of opposite sign under any cyclic character involution.

Equivalently, the puncture correction
\[
\frac{1-\widetilde Z(a)}m\sum_{k=0}^{m-1}(t/a)^k
\]
breaks the full \(\mu_m\)-orthogonality. Any WZ certificate would have to absorb this rank-one defect.

Thus the Fourier route gives an exact finite formula for \(Z,B,\widehat q\), but the desired exclusion
\[
\widehat q=-\frac{s}{mT(a)}
\]
does not follow from character orthogonality alone.

## 7. Verification status

The formulas above reduce the 53 generic and four gap-one records to finite character sums. They reproduce the computed \(q_0\) identity because the derivation uses only:

1. the punctured Lagrange interpolation conditions,
2. \(P_mZ-1=HB\),
3. \(H(a)=m\),
4. the normalization \(B(a)=2\).

The remaining unproved step is precisely the non-resonance statement excluding the exceptional value. The Fourier attack therefore isolates the obstruction: it is not lack of an explicit transform, but absence of a WZ-compatible antisymmetry of the shifted denominator \(P_m(t-1/4)\) on the punctured cyclic group.
