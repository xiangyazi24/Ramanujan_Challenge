# Wronskian constraint on Apéry atoms

## Short answer

The Wronskian identity is extremely useful for relating the two Apéry solutions, but it does **not** currently give an additional independent bound on the number of large atom primes dividing \(G_m\). The reason is that the valuation information at a prime \(p\mid b_m\) is already encoded in the same denominator cancellation that gives the existing height bound.

The partial fraction expansion gives a global rational identity, whereas an atom argument needs independent local restrictions at many distinct primes. The Wronskian does not separate those local contributions.

## 1. What the Wronskian actually says

The Apéry Casoratian is

```text
 a_m b_{m-1} - a_{m-1} b_m = 6/m^3.
```

Iterating gives

```text
 a_m/b_m = sum_{k=1}^m 6/(k^3 b_k b_{k-1}).
```

Thus \(a_m/b_m\) is a sum of explicit rational terms. If \(p>m/2\) and \(p\mid b_m\), then \(p\) occurs in the denominator of \(a_m/b_m\), because \(p\nmid d_m\) and the denominator of the reduced Apéry fraction is controlled by the \(b_m\)-factor.

However, the right hand side has many denominators \(b_kb_{k-1}\). For a large prime \(p>m/2\), none of the indices \(k<m\) can contain \(p\) in \(b_k\), by the Lucas/top-window relation. Therefore the \(p\)-adic contribution is concentrated in the final term(s), but this only recovers the known valuation relation.

## 2. Why it does not bound the atom height

Suppose

```text
p_i | b_m,   p_i > m/2,
```

for \(i=1,\dots,T\). Then the denominator of \(a_m/b_m\) contains

```text
prod_i p_i.
```

But this is exactly the same product appearing in

```text
G_m >= prod_i p_i.
```

The Wronskian does not produce a second quantity whose size is smaller than the denominator height. It merely expresses the same rational number in another form.

The estimate remains

```text
sum_i log p_i <= log G_m <= log d_m + log |a_m|
```

which gives the existing

```text
T <= O(m/log X).
```

No extra factor of \(T\) appears.

## 3. Could cancellation of partial fractions help?

A possible route would be to prove that every atom prime forces a nontrivial contribution to

```text
sum_{k=1}^m 6/(k^3 b_k b_{k-1})
```

which cannot be cancelled by the other terms.

But this seems unlikely because the identity is an equality in \(\mathbb Q\), not a sum with a positivity structure. The signs of the terms are not sufficient to prevent rational cancellation, and the primes \(p_i\) do not correspond to disjoint summands.

For an additional bound one would need a genuinely new statement such as:

```text
for every large p | b_m, the Wronskian forces a new independent denominator
obstruction in a second Apéry quantity.
```

The current identity only controls the single ratio \(a_m/b_m\).

## 4. The useful part of the Wronskian

The Wronskian remains powerful for:

* proving the denominator connection lemma;
* relating valuations of \(a_m\) and \(b_m\);
* ruling out common zeros of the two Apéry solutions;
* controlling multiplicities of zero residues.

In particular, if \(p\mid b_r\) and \(p>r\), then the Casoratian forces \(a_r\not\equiv0\pmod p\), because otherwise

```text
a_r b_{r-1}-a_{r-1}b_r ≡ 0 (mod p)
```

would contradict the nonzero value \(6/r^3\).

This is an important local rigidity statement, but it is not an atom-counting theorem.

## 5. What kind of Wronskian refinement would be needed?

A successful strengthening would likely require one of:

1. **Higher Casoratians:** a second independent solution or a higher exterior-power relation producing another denominator constraint.

2. **A modular/Galois interpretation:** showing that the zero condition \(b_r\equiv0\pmod p\) forces a restricted Frobenius class, then using independence across primes.

3. **A signed partial-fraction certificate:** proving a positivity or monotonicity property after a suitable transformation, so that each large prime contributes visibly.

The first-order Wronskian alone does not provide this.

## Conclusion

The Wronskian gives the correct local rigidity and explains why atom primes divide the gcd through the denominator connection, but it does not add a new independent restriction on the atom height. It reproduces the existing bound

```text
T << m/log X
```

rather than improving it. A true improvement would require an additional independent arithmetic invariant beyond the single Apéry Wronskian.
