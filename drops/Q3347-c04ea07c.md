# 13. Scope and first live escape

The no-go is strong but not universal.

It **does cover**:

```plain text
- every rational-gauge solution;
- every hypergeometric multiplier with rational consecutive quotient;
- arbitrary finite nesting in the standard split d'Alembertian class;
- every fixed-width rational carrier source R with nonzero DC for which
  the current exact rational-gauge system is inconsistent;
- both sampled slopes s=4 and s=7, and in fact every s>=1 over the stated
  constant field.
```

It **does not cover**:

```plain text
- enlarging the constant field to Q(sqrt(2));
- algebraic/non-split difference extensions whose minimal annihilator does
  not split into first-order factors over F;
- an Apéry-specific creative-telescoping identity that introduces a new
  arithmetic section not expressible in the above difference field;
- widths for which the rational-gauge system has not actually been certified
  inconsistent;

```

The first clean next test is the quadratic constant extension

\[

There the infinity polynomial factors:

=(z-(17+12\sqrt2)^s)(z-(17-12\sqrt2)^s).

If that quadratic-extension search is also empty, the multiplier route has moved decisively outside ordinary hypergeometric/d'Alembertian territory.
