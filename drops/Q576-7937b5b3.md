# P3.2 — Gross–Koblitz formulas, finite-field hypergeometric functions, and where Apéry zeroes occur

## Executive summary

The short answer is:

* The Apéry numbers do have a hypergeometric/Gauss-sum description modulo p.
* Gross–Koblitz converts each Gauss sum in the finite-field hypergeometric expression into a quotient of p-adic Gamma values.
* However, this does **not** give a single product formula for \(b_r\bmod p\). It gives a finite character sum of Gamma products.
* The vanishing condition \(b_r\equiv0\pmod p\) therefore occurs by **cancellation among character terms**, not because one Gamma factor vanishes.
* The Greene–McCarthy formalism is excellent for identifying the trace function, but by itself does not give a uniform bound on the number of zeros \(Z_p\).

The obstruction for AFP is exactly the last point: hypergeometric trace structure is known, but a theorem saying that a Mellin transform of the Apéry Hasse function has only \(O(1)\) zero Fourier coefficients is not currently available.

---

## (A) Explicit Gamma/Gauss sum formula

The Apéry numbers satisfy

\[
b_r=\sum_{k=0}^r {r\choose k}^2 {r+k\choose k}^2.
\]

Modulo a prime \(p>r\), this is the truncated hypergeometric value

\[
b_r\equiv {}_4F_3\left(\begin{matrix}-r,-r,r+1,r+1\\1,1,1\end{matrix};1\right)\pmod p.
\]

Equivalently, the Apéry motive has a finite-field hypergeometric realization. In McCarthy notation one obtains a trace expression of the form

\[
T_p(r)=\frac{p}{p-1}\sum_{\chi\in\widehat{\mathbf F_p^\times}}
 \frac{g(A_1\chi)g(A_2\chi)g(A_3\chi)g(A_4\chi)}
 {g(B_1\chi)g(B_2\chi)g(B_3\chi)}\chi(1),
\]

where the \(A_i,B_j\) are the characters corresponding to the Apéry parameters (the classical specialization is the \(4F_3(1/2,1/2,1/2,1/2;1,1,1|1)\) motive after a standard transformation).

Now apply Gross–Koblitz:

\[
g(\omega^{-m})=-\pi^{m/(p-1)}
\Gamma_p\left(\left\langle\frac m{p-1}\right\rangle\right).
\]

Therefore every term becomes

\[
\prod_i\Gamma_p(\alpha_i(m))\ /
\prod_j\Gamma_p(\beta_j(m))
\]

up to an explicit power of \(\pi\) and a root of unity.

So the correct statement is:

\[
\boxed{
 b_r\pmod p
 =\sum_m C_m
 \frac{\prod_i\Gamma_p(\alpha_{i,m})}
 {\prod_j\Gamma_p(\beta_{j,m})}
}
\]

not a single Gamma product.

---

## (B) Where can the zero come from?

A single Gamma factor cannot vanish:

\[
\Gamma_p(x)\in \mathbf Z_p^\times
\]

for all \(x\in\mathbf Z_p\).

Hence

\[
\prod_i\Gamma_p(\alpha_i)/\prod_j\Gamma_p(\beta_j)
\neq0.
\]

The zero condition

\[
b_r\equiv0\pmod p
\]

is therefore a cancellation condition:

\[
\sum_m C_mG_m=0.
\]

Geometrically this is important. It means the zero set is not a divisor of a Gamma product. It is a zero set of a Frobenius trace function.

This is analogous to elliptic curves: the Hasse invariant is a polynomial whose zeros are supersingular points; the trace itself vanishes because Frobenius eigenvalues cancel, not because a Gamma factor disappears.

---

## (C) Is there a binomial closed form like Legendre?

For the Legendre family,

\[
\sum_k {r\choose k}^2={2r\choose r}
\]

because the underlying motive has rank 2 and a particularly simple period.

For Apéry:

\[
\sum_k {r\choose k}^2{r+k\choose k}^2
\]

is a rank-4 hypergeometric period. No analogous factorial factorization is known.

The reason is structural: the Apéry motive is not a single Kummer/Beta convolution. It is a genuine higher hypergeometric motive with monodromy \(Sp_4\).

A product formula would imply a dramatic simplification of the Frobenius representation and is not expected.

---

## (D) Can Greene–McCarthy imply \(|Z_p|=O(1)\)?

Not directly.

Greene/McCarthy gives a trace function

\[
r\mapsto b_r\pmod p.
\]

A bound on zeros would require a theorem of the form:

\[
\#\{r:b_r=0\}\ll 1.
\]

For a general trace function this is false. A bounded-conductor sheaf can have many zeros. Deligne gives bounds for sums:

\[
\left|\sum_r \psi(b_r)\right|\ll \sqrt p,
\]

but not the number of points where the trace equals zero.

The best generic consequence is a square-root type estimate if one can prove non-degeneracy, not a constant bound.

Thus the desired AFP estimate

\[
\frac1\pi(X)\sum_{p\le X}|Z_p|=O(1)
\]

needs extra arithmetic input beyond hypergeometricity.

## (E) Mellin transform viewpoint

The useful representation is

\[
b_r=-\sum_{t\in\mathbf F_p^\times}Ha_p(t)\omega(t)^{-r}.
\]

This says \(b_r\) is the Kummer Mellin transform of the Hasse trace function.

Define

\[
M(r)=\sum_t H_a(t)\omega(t)^{-r}.
\]

Then

\[
Z_p=\{r:M(r)=0\}.
\]

If \(H_a(t)\neq0\) everywhere, this only says the Fourier transform is taken on full support. It does not prevent many Fourier coefficients from vanishing.

For example, a nonzero function on a finite cyclic group can have many zero Fourier coefficients.

The relevant missing theorem would be a rigidity statement for the specific Apéry Hasse function:

\[
\#\{r:\widehat{H_a}(r)=0\}\ll1.
\]

No general Mellin uncertainty principle gives this.

---

## Relation to AFP

The Gamma-sum formula clarifies the AFP bottleneck:

\[
|Z_p|=\#\{r:\operatorname{Frob}_p\text{ trace vanishes}\}.
\]

The known sheaf gives:

1. bounded rank;
2. controlled monodromy;
3. Deligne cancellation for additive twists.

It does not automatically give:

\[
\#\text{zero Fourier modes}=O(1).
\]

The most promising route remains the Apéry-specific structure already identified in the project:

* the rank-drop interpretation using transfer matrices;
* the Sp(4) monodromy constraints;
* the Mellin sheaf product-independence across primes.

The Gross–Koblitz formula is therefore a useful explicit description of the local trace, but the vanishing mechanism lives in **global cancellation of hypergeometric character sums**, not in Gamma zeros.

The exact missing lemma for AFP is a zero-count theorem for this special Mellin transform, not a further simplification of the Gamma factors.
