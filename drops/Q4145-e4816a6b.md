# Q4145 — fixed upper occurrence radical carrier versus residual C4 packing

## Verdict

**PARTIAL POSITIVE, but NO unconditional closure of the upper-occurrence tail from the committed structural interfaces alone.**

There is one genuine occurrence-preserving strengthening that uses the residual C4 packing:

* for a fixed actual typed upper occurrence `(q,u)`, after choosing one actual assigned-plus witness row per packed cycle using `(q,u)`, the map
  \[
  C\longmapsto (t(C),p(C)),\qquad t(C)\in\{u,q-1-u\},
  \]
  is injective on each fixed `t` branch;
* hence the selected-cycle lower-prime product on that branch is **squarefree** and divides the legal-window radical of a fixed two-index gcd;
* the fixed-state gcd carrier extends, by the same Lucas/reflection calculation, to the complementary branch `t=q-1-u`, not only `t=u`;
* the forced common upper prime `q` and the finite exceptional lower primes dividing `b_6 b_13` may be removed completely from the carrier.

Explicitly, with
\[
n_t:=6q+t,\qquad w_t:=12q+t,
\tag{1}
\]
and
\[
G_t(q,u):=\gcd(b_{n_t},b_{w_t}),
\tag{2}
\]
let
\[
E:=\operatorname{rad}(b_6b_{13}),
\]
and define the `qE`-free part
\[
G_t^{\circ}:=
\prod_{\ell\nmid qE}\ell^{v_\ell(G_t)}.
\tag{3}
\]
If `\mathcal C_{q,u,t}` is any selected packed-cycle family witnessed by residual assigned-plus rows of branch `t`, and `p_C` is the lower prime of the chosen witness, then
\[
\boxed{
P_{q,u,t}:=\prod_{C\in\mathcal C_{q,u,t}}p_C
\ \mid\ 
\operatorname{rad}G_t^{\circ}.
}
\tag{4}
\]
The left side is squarefree.

This gives an exact selected-cycle excess truncation. If every residual lower prime is at least `P_-(T)\asymp_J T`, and there are two distinct `t` branches, then, writing
\[
m_t:=|\mathcal C_{q,u,t}|,

\[
(d_{U,+}(q,u)-6R)_+
\le
\sum_{t\in\{u,q-1-u\}}(m_t-3R)_+,
\tag{5}

\[

\le
\bigl[
\log\operatorname{rad}G_t^{\circ}
-3R\log P_-(T)
\bigr]_+.
}
\tag{6}
\]
For the central fixed point `u=(q-1)/2`, there is one branch and one may use `6R` rather than `3R` in (6).

Thus a sufficient arithmetic estimate for the desired tail is
\[
\boxed{
\sum_{(q,u)}\sum_{t\in\{u,q-1-u\}}
\bigl[
\log\operatorname{rad}G_t^{\circ}
-3R\log P_-(T)
\bigr]_+
=o_J\!\left(\frac{T^2}{\log T}\right).
}
\tag{PLUS-RADICAL-EXCESS}
\]
Indeed division by `\log P_-(T)\asymp\log T` then gives
\[
\sum_{(q,u)}(d_{U,+}(q,u)-6R)_+
=o_J\!\left(\frac{T^2}{(\log T)^2}\right).
\tag{7}

But **none of the extra C4 hypotheses proves `PLUS-RADICAL-EXCESS`**. The first exact obstruction is that different lower primes `p` contributing to one fixed `(q,u,t)` lie in different lower-characteristic support graphs. Edge-disjointness therefore creates no reuse, no power of a common prime, and no second fixed integer. A maximum packing can contain one private C4 for every such `p` simultaneously. Complete fibres only add movable companion rows; they do not pin the companions to the same `(q,u)` or to any second fixed characteristic-zero carrier.

The complementary `t` pair does yield a genuine *intersection* carrier, but it cannot control the union. Put
\[
t_-:=\min(u,q-1-u),\quad
t_+:=\max(u,q-1-u),\quad
\delta:=t_+-t_->0.
\tag{8}
\]
If the **same** lower prime `p` supports residual plus rows in both branches, then, for the standard gap continuant `N_h`,
\[
\boxed{
p\mid
\gcd\!\left(
N_\delta(-n_{t_+}-1),
N_\delta(w_{t_-})
\right).
}
\tag{9}

This is a real new fixed carrier for `P_{t_-}\cap P_{t_+}`. However the two branch prime sets may be disjoint, and no C4/maximality condition forces a common `p`. \tag{10}

# 2. PROVED: the two-index carrier extends to both `t` branches

Assume `p\in I_t^{\rm res}(q,u)` and `p\nmid b_6b_{13}`.

From (13),
\[
n=7p-z-1=6p+(p-1-z),
\tag{18}
\]
with `0\le p-1-z<p`, while
\[
w=13p+a,
\tag{19}
\]
with `0\le a<p`.

The Apéry Lucas congruence gives
\[
b_n\equiv b_6 b_{p-1-z}\pmod p,
\qquad
b_w\equiv b_{13}b_a\pmod p.
\tag{20}
\]
The committed reflection zero-equivalence gives
\[
p\mid b_{p-1-z}\iff p\mid b_z.
\tag{21}
\]
Since `p\nmid b_6b_{13}`,
\[
\boxed{
\bigl(p\mid b_z\text{ and }p\mid b_a\bigr)
\iff
\bigl(p\mid b_n\text{ and }p\mid b_w\bigr).
}
\tag{22}
\]

The calculation does not use `t=u`; it uses only (12)-(13). Hence (22) is valid equally for

```text
t = u,
t = q-1-u,
```

whenever the exact row is legal and residual.

This is the first positive extension beyond a note stated only on the `t=u` branch.

# 3. The forced upper factor can be quotiented out

Because `(q,u)` is an actual upper occurrence,
\[
q\mid b_u.
\tag{23}
\]
For `t=u`, Lucas at the upper prime gives
\[
b_{6q+u}\equiv b_6b_u\equiv0\pmod q,
\]
\[
b_{12q+u}\equiv b_{12}b_u\equiv0\pmod q.
\tag{24}
\]
For the complementary branch `t=q-1-u`, reflection gives
\[
q\mid b_{q-1-u},
\tag{25}
\]
so the same Lucas calculation yields
\[
q\mid b_{6q+q-1-u},
\qquad
q\mid b_{12q+q-1-u}.
\tag{26}
\]
Therefore
\[
\boxed{q\mid G_t(q,u)\quad\text{for every }t\in T(q,u).}
\tag{27}

Since every assigned lower prime has `p<q`, the complete `q`-primary part of `G_t` is irrelevant to the lower-prime carrier and may be removed. The same is true of the finite exceptional set `p\mid b_6b_{13}`. This gives (3).

This quotient is exact, but quantitatively small: it removes the forced fixed-state factor, not a factor per selected cycle. Reusing `(q,u)` in `m` different packed cycles does **not** imply

\tag{28}

The repeated use is combinatorial; the upper divisibility `q\mid b_u` is one arithmetic fact. This is the first place where a tempting “divisibility reuse” argument fails.

# 4. PROVED: C4 edge-disjointness gives a squarefree selected-cycle product

Fix `(q,u,t)` and consider residual packed cycles which use this upper occurrence through an assigned-plus witness of branch `t`.

If one cycle has several such physical rows, choose one deterministically. For example, choose the lexicographically least actual witness in its complete assigned fibre. This is only a counting selector; it does not alter the packing.

For the chosen row of a cycle `C`, write its lower prime as `p_C`. Then (13) determines the lower support edge
\[
e_C=\{z(p_C),a(p_C)\}.
\tag{29}
\]

## Lemma 4.1

For fixed `(q,u,t)`,
\[
C\longmapsto p_C
\tag{30}
\]
is injective on the edge-disjoint packed family.

### Proof

If `p_C=p_D=p`, then (13) gives the same ordered pair `(z,a)`, hence the same support edge `e_C=e_D`. Distinct packed cycles cannot share a support edge. Therefore `C=D`. QED.

Thus the selected-cycle prime product
\[
P_{q,u,t}=\prod_Cp_C
\tag{31}
\]
is squarefree. By (22), every factor divides both `b_n` and `b_w`; by residual legality none divides `qE`. Hence
\[
P_{q,u,t}\mid\operatorname{rad}G_t^\circ,
\]
which is (4).

Notice what was and was not used:

```text
used:      deterministic assigned support edge + edge-disjoint packing;
not used:  maximality of the packing;
not used:  independence/randomness;
not used:  a new gcd-height estimate.
```

Maximum packing cannot improve the injectivity: the statement is already sharp for an arbitrary edge-disjoint packing.

# 5. Exact excess truncation supplied by the radical carrier

\[
P_-(T)\asymp_JT.
\tag{32}
\]
If `m_t` cycles are selected on branch `t`, then (4) gives
\[
P_-(T)^{m_t}
\le P_{q,u,t}
\le\operatorname{rad}G_t^\circ.
\tag{33}
\]
Hence
\[
\boxed{
m_t
\le
\frac{\log\operatorname{rad}G_t^\circ}{\log P_-(T)}.}
\tag{34}
\]

More importantly for the capacity quotient, if `m_t>3R`, reserve any `3R` of the selected primes. The remaining squarefree product has at least
\[
P_-(T)^{m_t-3R}

and is a divisor of the radical after the reserved factors are removed. Therefore
\[
(m_t-3R)\log P_-(T)
\le
\log\operatorname{rad}G_t^\circ-3R\log P_-(T),

(x+y-6R)_+

If `u=(q-1)/2`, the two values of `t` coincide. Then there is one branch and the exact version is

This is the cleanest verifier-ready selected-cycle form of PLUS-EXCESS I can derive from the residual C4 interfaces.

# 6. Why this does not close the aggregate tail

The target (7) would follow from `PLUS-RADICAL-EXCESS`. But the committed pointwise height
\[
\log G_t(q,u)=O_J(T)
\tag{38}
\]
only implies
\[
\log\operatorname{rad}G_t^\circ\le O_J(T).
\tag{39}
\]
It gives no aggregate cancellation or sparsity as `(q,u)` varies.

The subtraction
\[
3R\log P_-(T)
\tag{40}
\]
is useful only after one controls how often the radical height materially exceeds it. Nothing in edge-disjointness, maximum packing, complete fibres, or the residual width/prefix cutoffs gives such a height distribution theorem.

Equivalently, define the exact legal-window divisor count
\[
\omega_t^{\rm res}(q,u)
:=
\#\{p\in I_t^{\rm res}(q,u):p\mid G_t^\circ\}.
\tag{41}
\]
Then the selected packing gives only
\[
m_t\le\omega_t^{\rm res}(q,u),
\tag{42}
\]
and the unresolved arithmetic statement is
\[
\boxed{
\sum_{(q,u),t}
(\omega_t^{\rm res}(q,u)-3R)_+
=o_J\!\left(\frac{T^2}{(\log T)^2}\right).
}
\tag{43}
\]
The radical formulation (PLUS-RADICAL-EXCESS) is a sufficient height version of (43). No committed structural C4 theorem proves either one.

Thus replacing `G_t` by its radical is a genuine occurrence-level sharpening, but **not an exponent gain** without a new radical-height or large-prime-divisor theorem.

# 7. Complementary `t` pair: exact geometry

Let
\[
t_0=u,\qquad t_1=q-1-u,
\qquad \Delta:=t_1-t_0=q-1-2u.
\tag{44}
\]
For a fixed lower prime `p`, write `(z_j,a_j)` for the pair from `t_j`. Then
\[
\boxed{
z_1=z_0-\Delta,
\qquad a_1=a_0+\Delta.}
\tag{45}
\]
Both support edges have the same endpoint sum by (17).

If `\Delta=0`, this is the central fixed point and there is only one `t` branch.

Assume `\Delta\ne0`. The two support edges are not equal. Direct equality would require `\Delta=0`. The only other way two unordered two-element edges with the same sum could agree is by swapping endpoints. That would require
\[
z_0-a_0=\Delta.
\tag{46}
\]
But
\[
z_0-a_0
=20p-18q-2t_0-1,
\tag{47}
\]
so using `\Delta=q-1-2t_0`, (46) becomes
\[
20p=19q.
\tag{48}
\]
For macroscopic prime `p,q` this is impossible. Hence
\[
\boxed{e_{t_0}(p)\ne e_{t_1}(p).}
\tag{49}
\]
Since the two edges have equal endpoint sum, sharing even one endpoint would force them to be equal. Therefore they are actually vertex-disjoint:
\[
\boxed{e_{t_0}(p)\cap e_{t_1}(p)=\varnothing.}
\tag{50}
\]

This is adverse for the hoped-for packing improvement: edge-disjointness does not prevent one lower prime from supporting one selected cycle in each complementary branch.

# 8. PROVED: a complementary-branch intersection continuant carrier

There is nevertheless one additional arithmetic constraint when the **same** lower prime occurs in both branches.

Let
\[
t_-<t_+,
\qquad
\delta=t_+-t_->0.
\tag{51}
\]
Then (45) gives
\[
z_{t_+}=z_{t_-}-\delta,
\qquad
 a_{t_+}=a_{t_-}+\delta.
\tag{52}
\]
If both rows are legal, all four lower indices lie in `[0,p-1]`, so automatically
\[
0<\delta<p.
\tag{53}
\]

For the standard Apéry gap continuant
\[
N_0(X)=0,\quad N_1(X)=1,
\]
\[
N_{h+1}(X)
=(34(X+h)^3+51(X+h)^2+27(X+h)+5)N_h(X)
-(X+h)^6N_{h-1}(X),
\tag{54}
\]
the exact transfer theorem says that two `p`-zeros `r,r+h` with `0\le r<r+h<p` imply
\[
p\mid N_h(r).
\tag{55}
\]
Therefore a common lower prime for the two complementary branches satisfies
\[
p\mid N_\delta(z_{t_+}),
\qquad
p\mid N_\delta(a_{t_-}).
\tag{56}
\]
Now
\[
z_{t_+}=7p-n_{t_+}-1
\equiv -n_{t_+}-1\pmod p,
\tag{57}
\]
while
\[
a_{t_-}=w_{t_-}-13p
\equiv w_{t_-}\pmod p.
\tag{58}
\]
Because `N_\delta` has integer coefficients,
\[
\boxed{
p\mid
C_{q,u}:=\gcd\!\left(
N_\delta(-n_{t_+}-1),
N_\delta(w_{t_-})
\right).}
\tag{59}
\]

Thus, if `\Pi_-` and `\Pi_+` are the two selected lower-prime sets,
\[
\boxed{
\prod_{p\in\Pi_-\cap\Pi_+}p
\mid
\operatorname{rad}\gcd\!\left(
G_{t_-}^\circ,
G_{t_+}^\circ,
C_{q,u}
\right).
}
\tag{60}
\]

This is a real complementary-pair improvement. It is not enough for the requested tail for two independent reasons.

### 8.1 It controls only the intersection

The selected load is
\[
|\Pi_-|+|\Pi_+|
=|\Pi_-\cup\Pi_+|+|\Pi_-\cap\Pi_+|.
\tag{61}
\]
Equation (60) controls only the second term. The first can be arbitrarily large at the interface level with
\[
\Pi_-\cap\Pi_+=\varnothing.
\tag{62}
\]
No maximum-packing or complete-fibre theorem forces overlap.

Equivalently,
\[
\operatorname{rad}(G_-^\circ)
\operatorname{rad}(G_+^\circ)
=
\operatorname{rad}(G_-^\circ G_+^\circ)
\operatorname{rad}(\gcd(G_-^\circ,G_+^\circ)),
\tag{63}
\]
so a complementary gcd does not permit division by the overlap: a prime used in both branches counts twice in the cycle load and must be paid twice.

### 8.2 Long `\delta` has no useful committed height saving

For `|X|+\delta\ll_JT`, the recurrence (54) gives the elementary characteristic-zero bound
\[
\log(1+|N_\delta(X)|)
\ll_J\delta\log T.
\tag{64}
\]
When `\delta` is macroscopic, this is `O(T\log T)`, not a gain over the fixed-state `O(T)` gcd bound. For short `\delta`, (59) is useful, but that is exactly a short-gap subregime rather than the residual long frontier.

So the complementary pair supplies a correct new carrier, but not the missing aggregate theorem.

# 9. Why the other three C4 edges do not lower the fixed-state height

Take a selected cycle `C` at lower prime `p`, with selected support edge `e_C` carrying `(q,u,t)`. Its three other support edges are distinct by simplicity; across packed cycles all support edges are distinct by edge-disjointness.

Complete fibres say that the actual assigned rows above those edges are available. But their upper data are movable:

\[
(q'_1,u'_1),\ (q'_2,u'_2),\ (q'_3,u'_3)
\]
need not equal `(q,u)` and need not agree across different cycles.

Therefore the extra C4 edges may force additional divisibilities of the form
\[
p\mid G_{t'_j}(q'_j,u'_j),
\tag{65}
\]
but the integers on the right depend on the cycle. There is no committed theorem putting all of them into one fixed second integer attached to `(q,u)`.

This destroys the hoped-for `p^2` reuse. From
\[
p\mid G_t(q,u)
\]
and
\[
p\mid H_C
\]
with `H_C` varying with `C`, one cannot conclude
\[
p^2\mid G_t(q,u)
\tag{66}
\]
or any lower fixed height for `G_t`.

Globally multiplying all companion carriers merely transfers the problem to an uncontrolled product over other upper states. That is circular with the all-occurrence upper-load tail itself.

The residual upper/lower/prefix cutoffs do not change this: they remove rows from consideration, but for a surviving row they do not identify the companion upper states or force a common characteristic-zero divisor.

# 10. CONDITIONAL SHARPNESS CONFIGURATION

The following is the concrete finite configuration showing why selected-cycle packing cannot improve the one-branch fixed-state carrier.

Fix one `(q,u,t)` and choose distinct legal primes
\[
p_1,\dots,p_m\in I_t^{\rm res}(q,u),
\qquad p_i\nmid b_6b_{13},
\tag{67}
\]
such that
\[
p_i\mid G_t(q,u)
\qquad(1\le i\le m).
\tag{68}
\]
For each `i`, form the forced support edge
\[
e_i=\{z_i,a_i\},
\]
\[
z_i=7p_i-n_t-1,
\qquad
a_i=w_t-13p_i.
\tag{69}
\]
Suppose `e_i` extends to one simple C4
\[
C_i=(z_i,a_i,r_i,s_i,z_i)
\tag{70}
\]
whose other three edges are private in the lower-`p_i` support graph, and whose assigned fibre contains the residual physical witness `(q,u,t,p_i)`.

Take each lower-`p_i` component to contain no other C4. Then

```text
1. C_1,...,C_m are pairwise support-edge-disjoint automatically, since their lower primes differ;
2. their union is the unique maximum edge-disjoint C4 packing of these components;
3. all m cycles use the same typed upper occurrence (q,u);
4. the branch prime product is exactly p_1...p_m;
5. the packing imposes no divisibility beyond p_1...p_m | rad G_t^circ.
```

Thus
\[
d_{U,+}(q,u)\ge m
\tag{71}
\]
is fully compatible with maximum packing whenever the arithmetic fixed gcd has `m` legal lower-prime divisors and the corresponding edges admit private completions.

This is a **conditional configuration in the actual arithmetic notation**, not a claim that the Apéry sequence realizes arbitrarily large `m`. Its point is logical: C4 packing does not rule out the arithmetic premise (68). Ruling out large `m` is exactly the new arithmetic theorem that is missing.

There is an equally sharp two-branch version. If the same `p_i` is legal for both noncentral complementary branches, (50) shows the two forced support edges are vertex-disjoint. Give each edge a private C4 inside the same lower-`p_i` component. Then a maximum packing contains both, so one `p_i` contributes two cycles at `(q,u)`. Hence even complementary reuse is not forbidden by packing.

Fix a residual edge-disjoint packed C4 family and a typed actual upper occurrence `(q,u)`. For every packed cycle incident to `(q,u)` through an assigned-plus row, choose one such actual row. Let its reflection choice be `t\in\{u,q-1-u\}` and lower prime be `p`. Assume the exact legal lower indices (13), deterministic support-edge assignment, and the standard Apéry Lucas/reflection equivalence outside `p\mid b_6b_{13}`.

Then, for each fixed `t`, distinct chosen cycles have distinct lower primes and
\[
\prod_Cp_C
\mid
\operatorname{rad}
\left(
\gcd(b_{6q+t},b_{12q+t})_{(q b_6b_{13})\text{-free}}
\right).
\tag{72}
\]
Consequently (6) holds. If both complementary branches are used by the same lower prime, that prime additionally divides the fixed continuant carrier (59).

No bound of the form
\[
\sum_{(q,u)}(d_U(q,u)-6R)_+
=o_J(T^2/\log^2T)
\tag{73}
\]
follows from

```text
edge-disjointness of a maximum C4 packing,
complete assigned fibres,
residual upper/lower/prefix cutoffs,
the two-index divisibilities p | b_{6q+t}, b_{12q+t},
and pointwise log gcd(b_{6q+t},b_{12q+t}) = O_J(T)
```

alone. A sufficient additional arithmetic input is `PLUS-RADICAL-EXCESS`, equivalently a bound of the form (43) on legal large-prime divisor excess.

The conditional private-C4 construction in §10 proves that this is a real logical obstruction, not merely a failure of the present proof strategy.

---

# 12. What would genuinely close the frontier

Any successful next lemma must add information not present in the fixed-state divisibility carrier. Examples of the required *type* of theorem are:

\[
\sum_{(q,u),t}
\bigl[
\log\operatorname{rad}G_t^\circ-cR\log T
\bigr]_+
=o_J(T^2/\log T),
\tag{74}
\]
for the correct branch quota `c`, or directly
\[
\sum_{(q,u),t}
(\omega_t^{\rm res}(q,u)-cR)_+
=o_J(T^2/\log^2T).
\tag{75}
\]

An alternative would be a new C4 arithmetic theorem forcing each selected fixed-state prime `p` into a **second fixed integer depending only on `(q,u,t)`**, with aggregate height substantially below that of `G_t`. The current mate/fibre structure does not provide such an integer: its companion upper state varies with the cycle.

A theorem merely bounding
\[
\log G_t=O(T),
\]
or replacing `G_t` by the product of the two complementary gcds, is not enough. Nor is a theorem on the complementary intersection alone, because the one-branch configuration (67)-(71) survives unchanged.

# 13. Heuristic only

It is plausible that for a typical actual upper state `(q,u)`, the two fixed Apéry values
\[
b_{6q+t},\qquad b_{12q+t}
\]
share very few lower primes in the narrow legal window, and that the complementary branch intersection is even sparser. Under a random-divisor heuristic, (43) should be far smaller than the required scale.

**None of that is used above.** No independence hypothesis, GRH, random-zero model, or unproved gcd-height estimate is invoked. The proved content stops at the radical carrier and the complementary intersection continuant; the aggregate radical excess remains the first arithmetic gate.
