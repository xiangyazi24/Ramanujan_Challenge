# Section 1: blocked inequalities

Let
E = E^pi
m_v = #{n : pi(n)=v}
M = max_v m_v = p^theta

Exact identity:
E = sum_v m_v^2
  = sum_v m_v + sum_v m_v(m_v-1)

Block proof:
Choose block length L.
Number of blocks:
B = p/L

Inside one block:
For gap h <= L,
R_h <= deg(N_h) <= 3(h-1)

Therefore
S_p(L)
= sum_{h=1}^L R_h
<= sum_{h=1}^L (3(h-1)+1)
= (3/2)L^2 + O(L)

Total block contribution:
B*S_p(L)
<= (p/L)*(3/2)L^2
= (3/2)pL

The blocked inequality:
E <= O(pL) + O(p^2/L)

Optimization:
pL = p^2/L
=> L=sqrt(p)

E <= O(p^(3/2))

Needed but unavailable inequality for delta gain:
S_p(L) <= L^(2-epsilon)

would imply
E <= (p/L)*L^(2-epsilon)+p^2/L

= p L^(1-epsilon)+p^2/L

Optimization:
p L^(1-epsilon)=p^2/L
=> L^(2-epsilon)=p
=> L=p^(1/(2-epsilon))

Then
E <= p^(2-1/(2-epsilon))

For any epsilon>0:
2-1/(2-epsilon) > 3/2

So even this insertion into the old block split does NOT improve unless the
cross-block term p^2/L is also sharpened.

The missing inequality is therefore stronger:
S_p(L)<=L^(2-epsilon)
AND
cross-block=o(p^2/L)

Neither is proved.


# Section 2: hybrid multiplicity optimization

Let
M=max_v m_v=p^theta.

Split values:
Low: m_v <= M0
High: m_v > M0

Take threshold
M0=p^mu.

Energy:
E=sum_v m_v^2

Low part:

E_low
<= M0 * sum_v m_v

Since
sum_v m_v = p,

E_low <= p^(1+mu)


High part:

For m_v>M0,

m_v^2 <= M*m_v

hence

E_high <= M * sum_{high} m_v

Need use the cubic energy control:

T3=sum_v m_v(m_v-1)(m_v-2)

and

m_v^3 <= M*T2_v  (equivalently T3 controls the high tail)

For m_v>M0:

m_v^2 <= m_v^3/M0

Therefore

E_high
<= (1/M0) sum_v m_v^3

<= (1/M0)(T3+3E+3p)

Using the known relation

E <= 2p + T3

and the block bound

T3 <= p^(1+theta)

(one high multiplicity value contributes at most M times the quadratic mass)

we get

E_high <= p^(1+theta-mu)

Thus the interpolation bound is

E <= p^(1+mu)+p^(1+theta-mu)

Balance exponents:

1+mu = 1+theta-mu

2mu=theta

mu=theta/2

Therefore

f(theta)=1+theta/2


Substitute the proved value:

theta=2/3

f(2/3)=1+1/3

=4/3


But this formal gain requires the missing cubic tail estimate:

sum_v m_v^3 <= p^(1+theta)

which is not available from

max m_v <= p^theta.

The actual proven implication is only

sum_v m_v^3 <= M sum_v m_v^2

= p^theta E

which closes as

E <= p^(1+mu)+p^(theta-mu)E

and gives no gain unless

p^(theta-mu)<1.

That requires

mu>theta,

contradicting the balancing choice mu=theta/2.

Therefore the hybrid optimization dies at this inequality.


# Section 3: mirror reduction

Mirror law:
pi(r)=pi(p-1-r)

Hence

E_full=2E_half+O(1)

The block argument on half orbit gives

E_half<=O((p/2)L)+O((p/2)^2/L)

=O(pL)+O(p^2/L)

The same optimization gives

L=sqrt(p)

E_half=O(p^(3/2))

and therefore

E_full=O(p^(3/2)).

The desired false inequality would be:

"paired gaps reduce independent collision pairs by sqrt(2)"

meaning

S_half(L)<=S_full(L)/sqrt(2)

or

sum_h R_h^half <= (1/sqrt(2)) sum_h R_h^full

No algebraic mechanism proves this.

Counter-mechanism:
if pi(r)=pi(s), then automatically

pi(p-1-r)=pi(p-1-s).

Every collision creates a synchronized mirror collision.

Thus

number of collision pairs doubles,

not square-roots.

Mirror gives constants only, not exponent improvement.
