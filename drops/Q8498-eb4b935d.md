# 1. Exact centered Fourier expansion

Let

\[
 \mathcal P_X=\{p\text{ prime}:X<p\le2X\},
 \qquad M=X^2,
 \qquad z_p=|Z_p|.
\]

For \(r\in\mathbb Z/p\mathbb Z\), define the centered column

\[
 g_p(r)=1_{Z_p}(r)-\frac{z_p}{p}.
\]

Use

\[
 e_n(t)=\exp(2\pi i t/n),
 \qquad
 F_p(a)=\sum_{r\in Z_p}e_p(ar),
\]

and fix the Dirichlet-kernel convention

\[
 D_M(x)=\sum_{m=0}^{M-1}e^{-2\pi i mx}.
\tag{1.1}
\]

The finite Fourier transform of \(g_p\) is

\[
 \widehat g_p(a)=\sum_{r\bmod p}g_p(r)e_p(ar).
\]

At \(a=0\), centering gives

\[
 \widehat g_p(0)=z_p-z_p=0.
\]

At \(a\ne0\), the constant part has zero transform, so

\[
 \widehat g_p(a)=F_p(a).
\]

Fourier inversion is therefore

\[
\boxed{
 g_p(m)=\frac1p\sum_{a\in(\mathbb Z/p\mathbb Z)^\times}
 F_p(a)e_p(-am).
}
\tag{1.2}
\]

For distinct \(p,q,\ell\in\mathcal P_X\), define

\[
 C_{p,q,\ell}
 =\sum_{m=0}^{M-1}g_p(m)g_q(m)g_\ell(m).
\tag{1.3}
\]

Insert (1.2). With \(N=pq\ell\), this gives

\[
 C_{p,q,\ell}
 =\frac1N
 \sum_{a\ne0}\sum_{b\ne0}\sum_{c\ne0}
 F_p(a)F_q(b)F_\ell(c)
 D_M\!\left(\frac ap+\frac bq+\frac c\ell\right).
\tag{1.4}
\]

For \(h\bmod N\), put

\[
 a_p(h)=h(q\ell)^{-1}\pmod p,
\]

\[
 a_q(h)=h(p\ell)^{-1}\pmod q,
 \qquad
 a_\ell(h)=h(pq)^{-1}\pmod\ell.
\tag{1.5}
\]

The map

\[
 h\longmapsto(a_p(h),a_q(h),a_\ell(h))
\]

is the CRT bijection from \(\mathbb Z/N\mathbb Z\) to the product of the three residue rings. Moreover

\[
 a_p(h)q\ell+a_q(h)p\ell+a_\ell(h)pq\equiv h\pmod N,
\]

so

\[
 \frac{a_p(h)}p+\frac{a_q(h)}q+\frac{a_\ell(h)}\ell
 \equiv\frac hN\pmod1.
\]

All three frequencies are nonzero exactly when \((h,N)=1\). Hence

\[
\boxed{
 C_{p,q,\ell}
 =\frac1N
 \sum_{\substack{h\bmod N\\(h,N)=1}}
 D_M\!\left(\frac hN\right)
 F_p(a_p(h))F_q(a_q(h))F_\ell(a_\ell(h)).
}
\tag{1.6}
\]

This is the required CRT \(h\)-sum, with every zero-frequency term removed by centering rather than estimated.

If ordered distinct prime triples are used, set

\tag{1.7}

# 4. Ramanujan-sum evaluation of the coprime kernel

From (1.1) and (3.3),

\[

\tag{4.1}
\]

The inner sum is the Ramanujan sum

\[
 c_N(u-m)=\sum_{h\in(\mathbb Z/N\mathbb Z)^\times}e_N(h(u-m)).
\]

Since \(N=pq\ell\) is squarefree, CRT multiplicativity gives

\[
 c_N(t)=c_p(t)c_q(t)c_\ell(t).
\tag{4.2}

For a prime \(s\),

\[
 c_s(t)=
 \begin{cases}
 s-1,&s\mid t,\\
 -1,&s\nmid t.

Equivalently,

\[
 \frac{c_s(t)}s=1_{s\mid t}-\frac1s.
\tag{4.3}
\]

Combining (4.1)--(4.3) yields the exact physical-space formula

\[
\boxed{
 U_{N,M}(u)
 =\sum_{m=0}^{M-1}

  \left(1_{m\equiv u\ (\mathrm{mod}\ s)}-\frac1s\right).

\tag{4.4}

Thus the coprime \(h\)-sum for one zero tuple is exactly the centered incidence of its three singleton residue classes.

For a subset of moduli, let

and define \(I_{p,\ell}(u)\), \(I_{q,\ell}(u)\), and

 I_{p,q,\ell}(u)=1_{\{u<M\}}.

# 5. Unit-hit theorem

## Theorem 5.1 — every contributing tuple has unit coprime mass

Let \(X\ge3\), \(M=X^2\), and let \(p,q,\ell\in(X,2X]\) be distinct primes. If \(0\le u<M\), then

\[
 I_{p,q,\ell}(u)
 =I_{p,q}(u)
 =I_{p,\ell}(u)
 =I_{q,\ell}(u)=1.
\]

Indeed \(u\) itself is a representative of every displayed class, and uniqueness follows from \(pq,p\ell,q\ell>M\). Substitution into (4.5) proves (E1):

\[
 U_{N,M}(u)
 =1-\frac1p-\frac1q-\frac1\ell
 +\frac{A_p(u)}{q\ell}
 +\frac{A_q(u)}{p\ell}
 +\frac{A_\ell(u)}{pq}
 -\frac{M}{N}.
\]

The three \(A\)-terms are nonnegative. Since

\[
 \frac1p+\frac1q+\frac1\ell<\frac3X,
 \qquad
 \frac{M}{N}<\frac{X^2}{X^3}=\frac1X,
\]

we obtain

\[
\boxed{U_{N,M}(u)>1-4/X.}
\]

No cancellation estimate is used. The inequality is a direct evaluation of the exact coprime-frequency sum. ∎

## Theorem 5.2 — every nonhit tuple is bounded below by \(-4/X\)

If \(u\ge M\), then \(I_{p,q,\ell}(u)=0\), while each pair indicator in (4.5) is at most one. Again discard the nonnegative \(A\)-terms. This gives

\[
\boxed{U_{N,M}(u)>-4/X.}
\tag{5.1}
\]

This one-sided bound is all that is needed for the reflection corollary.

## Corollary 5.3 — full Apéry reflection does not cancel a hit

Reflection maps

\[
 (r_p,r_q,r_\ell)
 \longmapsto
 (p-1-r_p,q-1-r_q,\ell-1-r_\ell).
\]

The reflected CRT representative satisfies

\[
 u^*\equiv-1-u\pmod p,
 \quad
 u^*\equiv-1-u\pmod q,
 \quad
 u^*\equiv-1-u\pmod\ell,
\]

and therefore

\[
\boxed{u^*=N-1-u.}
\tag{5.2}
\]

If \(u<M\), then for \(X\ge3\),

\[
 u^*\ge N-M>X^3-X^2\ge2X^2>M.
\]

Theorems 5.1 and 5.2 now give

\[
\boxed{
 U_{N,M}(u)+U_{N,M}(u^*)>1-8/X.
}
\tag{5.3}
\]

Thus neither tuplewise cancellation nor grouping the exact reflected pair can supply a decaying factor.

# 7. The precise sufficient lemma class and its obstruction

A natural attempt to prove ACF3 after expanding the amplitudes is the following.

## Tuplewise horizontal-saving schema THS

Find \(\eta_X=X^{-1+o(1)}\) such that, pointwise in \(X\), for every distinct \(p,q,\ell\in\mathcal P_X\) and every actual zero tuple,

\[
\boxed{
 \bigl(U_{p q\ell,M}(u(r_p,r_q,r_\ell))\bigr)_+
 \le\eta_X.
}
\tag{THS}
\]

This schema is sufficient. Indeed, from (3.4),

\[
 (C_X^\times)_+
 \le
 \sum_{\substack{p,q,\ell\in\mathcal P_X\\\text{distinct}}}
 \sum_{r_p\in Z_p,r_q\in Z_q,r_\ell\in Z_\ell}
 (U_{p q\ell,M}(u))_+.
\]

Under THS,

\[
 (C_X^\times)_+
 \le \eta_X\left(\sum_{p\in\mathcal P_X}z_p\right)^3.
\]

Since \(p\le2X\),

\[
 \sum_pz_p
 =\sum_p p\frac{z_p}{p}
 \le2X\lambda_X.
\]

Therefore

\[
 (C_X^\times)_+
 \le8X^3\eta_X\lambda_X^3
 =X^{2+o(1)}\lambda_X^3.
\tag{7.1}
\]

So THS supplies exactly the missing horizontal factor.

But Theorem 5.1 gives the exact opposite behavior on every hit:

\[
 u<M\quad\Longrightarrow\quad
 (U_{N,M}(u))_+>1-4/X.
\tag{7.2}
\]

The major-arc theorem says more: for an early hit, a positive constant is already present before the minor arcs are included.

Accordingly, THS and all stronger variants obtained by

- taking absolute values before summing zero tuples;
- taking positive parts before summing zero tuples;
- estimating each prime triple by the sum of absolute tuple kernels;
- pairing only the full reflected tuple;
- asking the range \(|h|\ll N/M\) to provide the missing factor;

are blocked exactly.

An asymptotic tuplewise decay statement could survive only by proving that eventually **no actual zero triple has a CRT representative below \(M\)**. That is much stronger than ACF3 itself and is not a consequence of the Fourier kernel. The base-tree exact Apéry data show that the schema is already nonvacuously wrong at \(X=4096\).

Because \(u<M=X^2\) and \(p>X\), one has \(a_p<X<p\). The Apéry Lucas/Cartier congruence gives

\[
 b_u\equiv b_{a_p}b_{r_p}\pmod p.
\]

Since \(b_{r_p}\equiv0\pmod p\),

\[
 p\mid b_u.
\]

Thus the witness also satisfies

\[
 p q\ell\mid b_u.
\tag{9.1}
\]

This does not contradict any height bound: \(\log b_u\asymp u\), while \(\log(pq\ell)\asymp\log X\). The characteristic-zero size of \(b_u\) is far too large to force an \(X^{-1}\) incidence saving.

Likewise the Laurent/diagonal realization of \(b_u\) proves that all three divisibilities concern one canonical coefficient, but it gives no cancellation among the three defining characteristics. A modular parametrization also remains prime-local unless one proves an additional theorem relating the three selected Frobenius/zero conditions. None of these identities changes the exact kernel evaluation (E1).

The obstruction therefore sits after all of those local identities: once an actual cross-characteristic hit exists, the interval projector assigns it unit mass.

# 10. What a surviving ACF3 theorem must estimate

The exact decomposition is

\[
 C_X^\times
 =\sum_{\substack{p,q,\ell\in\mathcal P_X\\\text{distinct}}}
  \sum_{r_p\in Z_p,r_q\in Z_q,r_\ell\in Z_\ell}
  U_{p q\ell,M}(u(r_p,r_q,r_\ell)).
\tag{10.1}
\]

The positive part must remain **outside** both sums. The remaining acceptable target is therefore a genuinely signed statement of the shape

\[
\boxed{
 \left(
 \sum_{\substack{p,q,\ell\in\mathcal P_X\\\text{distinct}}}
  \sum_{r_p\in Z_p,r_q\in Z_q,r_\ell\in Z_\ell}
  U_{p q\ell,M}(u)
 \right)_+
 \ll X^{2+o(1)}\lambda_X^3.
}
\tag{10.2}
\]

The unit contributions of hit tuples must be offset, in aggregate, by the signed kernels of nonhit tuples or by cancellation across prime triples. That is exactly the cross-characteristic selection problem identified by the pair-Palm formulation in the base tree.

A useful future theorem would need one of the following genuinely global forms.

1. **Signed CRT discrepancy for actual Apéry zeros.** Bound the signed count of Apéry zero tuples whose CRT representatives lie in \([0,M)\), without moving absolute values or positive parts inside the residue sum.
2. **Mixed-prime trace correlation.** Produce one common characteristic-zero or automorphic trace object whose specialization simultaneously controls the three different defining characteristics and the interval projector.
3. **Pair-Palm anti-overload.** Bound the aggregate positive conditional excess of third-prime hits on actual two-prime CRT loci, as isolated in `hm3_result.tex`.

Primewise Parseval, ordinary large sieve, reflection, and tuplewise major-arc oscillation cannot supply this statement. The exact obstruction above explains why: on a real hit the interval Fourier projector is doing precisely what it should do—returning approximately one.

The following standard-library verifier recomputes the three Apéry zero sets from the exact denominator-cleared recurrence, verifies the CRT witness and reflection mate, and checks the rational kernel bounds. It is included as source only; it was **not executed** in this connector-only session, in accordance with the instruction not to use Python/code-interpreter/sandbox tools.

```python
#!/usr/bin/env python3
from fractions import Fraction
from math import isqrt, prod


def is_prime(n: int) -> bool:
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    for d in range(3, isqrt(n) + 1, 2):
        if n % d == 0:
            return False
    return True


def apery_zeros(p: int) -> tuple[int, ...]:
    """Zeros of b_0,...,b_{p-1} via Y_n=(n!)^3 b_n."""
    assert is_prime(p)
    zeros: list[int] = []
    ym1 = 1 % p
    y = 5 % p
    if ym1 == 0:
        zeros.append(0)
    if y == 0:
        zeros.append(1)
    for n in range(1, p - 1):
        P = (34*n**3 + 51*n**2 + 27*n + 5) % p
        ynext = (P*y - pow(n, 6, p)*ym1) % p
        ym1, y = y, ynext
        if y == 0:
            zeros.append(n + 1)
    return tuple(zeros)


def crt(residues: tuple[int, ...], moduli: tuple[int, ...]) -> int:
    N = prod(moduli)
    value = 0
    for r, p in zip(residues, moduli):
        cofactor = N // p
        value += r * cofactor * pow(cofactor, -1, p)
    return value % N


def single_count(M: int, p: int, r: int) -> int:
    assert 0 <= r < p < M
    return (M - 1 - r) // p + 1


def tuple_kernel(
    M: int,
    moduli: tuple[int, int, int],
    residues: tuple[int, int, int],
) -> Fraction:
    p, q, ell = moduli
    rp, rq, rell = residues
    N = p*q*ell

    full = int(crt(residues, moduli) < M)
    pq = int(crt((rp, rq), (p, q)) < M)
    pell = int(crt((rp, rell), (p, ell)) < M)
    qell = int(crt((rq, rell), (q, ell)) < M)

    Ap = single_count(M, p, rp)
    Aq = single_count(M, q, rq)
    Aell = single_count(M, ell, rell)

    return (
        Fraction(full, 1)
        - Fraction(pq, ell)
        - Fraction(pell, q)
        - Fraction(qell, p)
        + Fraction(Ap, q*ell)
        + Fraction(Aq, p*ell)
        + Fraction(Aell, p*q)
        - Fraction(M, N)
    )


def main() -> None:
    X = 4096
    M = X*X
    moduli = (4283, 7333, 8087)
    residues = (18, 4433, 7567)
    u = 1_075_051

    assert all(X < p <= 2*X for p in moduli)
    assert all(is_prime(p) for p in moduli)
    assert tuple(u % p for p in moduli) == residues
    assert u < M // 4

    for p, r in zip(moduli, residues):
        Z = set(apery_zeros(p))
        assert r in Z
        assert p - 1 - r in Z

    N = prod(moduli)
    assert N == 253_990_341_793
    assert crt(residues, moduli) == u

    H = N // (8*M)
    assert H == 1892
    assert H < min(moduli)

    counts = tuple(
        single_count(M, p, r)
        for p, r in zip(moduli, residues)
    )
    assert counts == (3918, 2288, 2074)

    U = tuple_kernel(M, moduli, residues)
    assert U > 1 - Fraction(4, X)

    reflected = tuple(p - 1 - r for p, r in zip(moduli, residues))
    u_reflected = crt(reflected, moduli)
    assert u_reflected == N - 1 - u
    assert u_reflected >= M

    U_reflected = tuple_kernel(M, moduli, reflected)
    assert U_reflected > -Fraction(4, X)
    assert U + U_reflected > 1 - Fraction(8, X)

    print("CHATGPT_ACF3_EXACT_ATTEMPT2=PASS")
    print("N", N)
    print("H", H)
    print("U", U.numerator, U.denominator)
    print("U_reflected", U_reflected.numerator, U_reflected.denominator)


if __name__ == "__main__":
    main()
```
