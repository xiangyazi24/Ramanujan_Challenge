# Critical-value irreducibility: p-adic audit and the surviving route

## 0. Verdict

The proposed all-h theorem

```text
(M1) C_h(T) = Res_x(N_h(x)-T L_h(x)^3, K_h(x)) is irreducible over Q
```

is not proved here. The ordinary Eisenstein/Newton-polygon route at the fixed primes

```text
2, 3, 5, 17
```

does not close it. The obstruction is structural, not merely computational:

- `C_h(T)` is even, so its critical values occur in pairs `a,-a`.
- Modulo 2, the first critical polynomial is a square.
- Modulo 3, `N_h` is a Frobenius cube and `K_h` loses its entire first layer.
- For every fixed odd prime `q != 3`, once `h > q`, several poles of `Delta_h` collide modulo `q`; this forces common factors of `L_h` and `K_h` modulo `q` and hence several local Newton blocks.
- The exact endpoint valuations contain `Res(N_h,N_h')`, the discriminant whose nonvanishing is precisely (M2). Thus an endpoint-slope argument that ignores the discriminant is circular.

There is, however, a precise surviving p-adic route.

```text
[3-RESIDUAL ROUTE]
Compute the first nonzero 3-adic layer H_h of K_h.
The first nonzero 3-adic reduction of C_h is an explicit resultant

    G_h(T) = Res_x(R_h(x)-T L_h(x), H_h(x)) over F_3,

where N_h = R_h^3 mod 3.
```

If the complete higher-order 3-adic type of this residual family is one leaf, then (M1) follows. More generally, intersecting the complete local factor-degree sets at `2,3,5,17` gives exactly the weak block-size exclusion requested in Task 2.

The main proved additions in this audit are:

```text
[P1] exact evaluations of N_h and K_h at every pole;

[P7] a fixed-prime pole-collision lemma explaining why ordinary reduction
```

The honest final status is:

## 1. Normalization and the involution

Put

```text
L_h(x) = product_{j=1}^h (x+j),
F_h(x,T) = N_h(x)-T L_h(x)^3,
K_h(x) = L_h(x) N_h'(x)-3 L_h'(x) N_h(x).
```

Write

```text
d = deg_x F_h = 3h,
k = deg K_h = 4h-4,
lambda_h = lc(N_h).
```

Then

```text
lc(K_h) = -3 lambda_h.                                  (1.1)
```

Indeed the two terms of `K_h` have degree `4h-4`, and their leading coefficient is

```text
(3h-3)lambda_h - 3h lambda_h = -3lambda_h.
```

Define the reflection

```text
rho_h(x) = -h-1-x.
```

The proved continuant reflection gives

```text
N_h(rho_h(x)) = (-1)^(h-1) N_h(x),
L_h(rho_h(x)) = (-1)^h L_h(x).                           (1.2)
```

Differentiating (1.2) gives

```text
N_h'(rho_h(x)) = (-1)^h N_h'(x),
L_h'(rho_h(x)) = (-1)^(h+1) L_h'(x).
```

Therefore

```text
K_h(rho_h(x)) = K_h(x),
Delta_h(rho_h(x)) = -Delta_h(x),                         (1.3)
```

where `Delta_h=N_h/L_h^3`.

Changing `x` to `rho_h(x)` in the resultant now gives

```text
C_h(-T) = C_h(T).                                        (1.4)
```

Thus, after removing scalar content,

```text
C_h(T) = D_h(T^2),
deg C_h = 4h-4,
deg D_h = 2h-2.                                          (1.5)
```

This is not a factorization over Q. An even polynomial can be irreducible. It does show that the p-adic problem should normally be run first on `D_h(Z)`, followed by the quadratic Capell condition:

```text
C_h(T)=D_h(T^2) is irreducible over Q
iff
D_h(Z) is irreducible over Q and a root of D_h is not a square
in its root field.                                      (1.6)
```

For Task 2, failure of the second condition can create two factors of degree `2h-2` even when `D_h` is irreducible. Hence a proof of transitivity for `D_h` alone is not quite (M1).

## 2. Exact pole values

The pole evaluations are the cleanest all-h arithmetic input.

### Lemma 2.1 [PROVED]

For `1 <= j <= h`,

```text
N_h(-j)
 = (-1)^(j-1) ((j-1)!(h-j)!)^3 b_{j-1} b_{h-j}.          (2.1)
```

Proof. Use the symmetric tridiagonal continuant for `N_h`. At `x=-j`, the edge with weight `(x+j)^6` vanishes. The determinant splits into a left continuant of length `j-1` and a right continuant of length `h-j`. The right block is the usual positive endpoint evaluation, and the left block is its reflected version. The endpoint identity

```text
N_m(-1)=((m-1)!)^3 b_{m-1}
```

then gives (2.1). The sign also follows by reflection from `j=1`.

Since every integer Apery number `b_n` is positive,

```text
gcd(N_h,L_h)=1 over Q.                                  (2.2)
```

In particular all poles of `Delta_h` are honest triple poles.

Also

```text
L_h'(-j)=(-1)^(j-1)(j-1)!(h-j)!.
```

Consequently

### Corollary 2.2 [PROVED]

```text
K_h(-j)
 = -3 ((j-1)!(h-j)!)^4 b_{j-1} b_{h-j} != 0.            (2.3)
```

This proves in particular that no root of `K_h` is an actual pole over Q.

Put

```text
S_h = product_{i=0}^{h-1} i!,
B_h = product_{i=0}^{h-1} b_i.
```

Multiplying (2.1) and (2.3) over all poles gives, up to the displayed harmless sign in the first formula,

```text
Res(L_h,N_h)
 = (-1)^(h(h-1)/2) S_h^6 B_h^2,                         (2.4)

Res(L_h,K_h)
 = (-3)^h S_h^8 B_h^2.                                  (2.5)
```

These identities are exact and are suitable for a one-line Sage assertion.

## 3. Exact endpoint coefficients of the critical-value resultant

Let

```text
C_h^raw(T)=Res_x(F_h(x,T),K_h(x)).
```

The word `raw` matters: this polynomial generally has a very large integer content. Irreducibility over Q means irreducibility of its primitive part.

### Proposition 3.1 [PROVED]

If

```text
C_h^raw(T)=sum_{i=0}^{4h-4} c_i T^i,
```

then, up to sign,

```text
c_{4h-4}=Res(L_h,K_h)^3
          =3^(3h) S_h^24 B_h^6,                         (3.1)
```

and

```text
c_0=(-3lambda_h)^3 Res(N_h,L_h) Res(N_h,N_h').          (3.2)
```

Proof. The coefficient of the highest power of `T` is

```text
Res(L_h^3,K_h)=Res(L_h,K_h)^3.
```

For the constant term, use the root-product formula with `deg F_h=3h`. At `T=0`, the degree of `F_h` falls by three, so specialization contributes the extra factor `lc(K_h)^3`. At a root of `N_h`,

```text
K_h = L_h N_h'.
```

Hence

```text
Res(N_h,K_h)=Res(N_h,L_h)Res(N_h,N_h'),
```

which proves (3.2).

Therefore, for every rational prime `q`,

```text
v_q(c_top)
 = 3h v_q(3)+24 v_q(S_h)+6 v_q(B_h),                    (3.3)

v_q(c_0)
 = 3v_q(3lambda_h)+6v_q(S_h)+2v_q(B_h)
   +v_q(Res(N_h,N_h')).                                 (3.4)
```

Equations (3.3)-(3.4) are the strongest all-h endpoint valuation formulas available from the current data.

They also identify the circular point in a proposed endpoint-slope proof:

```text
v_q(Res(N_h,N_h'))
```

is unknown. Its finiteness is exactly (M2), and its exact value controls the lower endpoint of the Newton polygon. Thus the leading-coefficient law, factorial valuations, and apparition data do not determine the Newton polygon of `C_h` by themselves.

Intermediate coefficients are mixed subresultants. Their valuations are not determined by (3.3)-(3.4), by the factorization of `P` modulo `q`, or by the leading coefficient of `N_h`.

## 4. The h=2 certificate kills the naive pure-slope proposal

The primitive critical-value polynomial for `h=2`, obtained in Q6561, is

```text
C_2(T)=625 T^4+541064 T^2+22717712.                      (4.1)
```

Its coefficient valuations, listed in increasing exponent order `0,2,4`, are

```text
q=2:  (4,3,0),
q=3:  (0,0,0),
q=5:  (0,0,4),
q=17: (5,0,0).                                          (4.2)
```

The exact constant factorization at 17 is

```text
22717712 = 16*17^5.
```

Thus the Newton polygons are:

```text
q=2:  one edge of slope -1; reduced denominator 1;
q=3:  one horizontal edge;
q=5:  a horizontal edge of length 2, then slope 2;
q=17: slope -5/2 of length 2, then a horizontal edge of length 2. (4.3)
```

None has a single slope whose reduced denominator is `4=deg C_2`. Hence none is an Eisenstein-Dumas proof of irreducibility.

At `q=3`, irreducibility comes instead from the residual polynomial:

```text
C_2(T) mod 3 = T^4+2T^2+2.                              (4.4)
```

Let `Z=T^2`. The quadratic

```text
Z^2+2Z+2
```

is irreducible over `F_3`; a root has norm `2` in `F_9`, hence is not a square in `F_9`. By the quadratic Capell criterion, (4.4) is irreducible over `F_3`. This proves the `h=2` case, but it proves it by a residual factorization, not by a pure Newton slope.

The finite base case does not logically rule out a different all-h slope after discarding finitely many `h`. It does show that the proposed fixed-prime mechanism is not visible even in the first nontrivial member.

## 5. Prime 2: the first layer is always inseparable

Modulo 2,

```text
K_h=L_hN_h'-3L_h'N_h
   =L_hN_h'+L_h'N_h
   =(L_hN_h)' mod 2.                                    (5.1)
```

The derivative of every polynomial over `F_2` is a polynomial in `x^2`, hence a square in `F_2[x]`. Therefore there is an `A_h(x)` such that

```text
K_h(x)=A_h(x)^2 mod 2.                                  (5.2)
```

If the integer content of `K_h` is odd, then

```text
C_h^raw(T)
 = Res(F_h,A_h^2)
 = Res(F_h,A_h)^2 mod 2.                                (5.3)
```

If the content is even, the raw resultant is zero modulo 2 and one must first divide by the exact 2-content and inspect the next layer.

Thus the ordinary mod-2 reduction is never a squarefree irreducibility certificate. This is consistent with the four-step mod-2 degeneration of `N_h` already proved in Q6490. A useful 2-adic argument must be a higher-order type computation after content division.

Verdict:

```text
[2-ADIC FIRST-LAYER IRREDUCIBILITY: IMPOSSIBLE]
[2-ADIC HIGHER-ORDER TYPES: STILL POSSIBLE]
```

## 6. Prime 3: exact first residual polynomial

This is the most promising exact reformulation.

Modulo 3,

```text
P(u)=(u-1)^3.                                           (6.1)
```

Define `R_h in F_3[x]` by

```text
R_1=1,
R_2=x,
R_{h+1}=(x+h-1)R_h-(x+h)^2R_{h-1}.                     (6.2)
```

The characteristic-3 Frobenius identity and the continuant recurrence give

```text
N_h(x)=R_h(x)^3 mod 3                                   (6.3)
```

for every `h>=1`.

In particular `N_h'=0 mod 3`, so

```text
K_h=0 mod 3.                                            (6.4)
```

Let

```text
e_h = min valuation_3 of the coefficients of K_h,
H_h(x)=3^(-e_h)K_h(x) mod 3,
```

so `H_h` is nonzero over `F_3` by definition.

Scaling the second entry of a resultant gives

```text
C_h^raw(T)/3^(3h e_h)
 = Res_x(F_h(x,T),3^(-e_h)K_h(x)).                      (6.5)
```

Reduce (6.5) modulo 3 and adjoin a formal element `t` with `t^3=T`. Then

```text
F_h(x,T)=R_h(x)^3-TL_h(x)^3
        =(R_h(x)-tL_h(x))^3.                            (6.6)
```

Hence

```text
C_h^raw(T)/3^(3h e_h) mod 3
 = Res_x(R_h-tL_h,H_h)^3.                               (6.7)
```

If

```text
G_h(t)=Res_x(R_h(x)-tL_h(x),H_h(x)) in F_3[t],          (6.8)
```

then Frobenius changes `G_h(t)^3` into the same coefficient polynomial with `t^3=T`. Therefore (6.7) is precisely

```text
G_h(T),                                                  (6.9)
```

with the variable renamed.

This gives the exact sufficient theorem:

### [M1-3RES]

For every `h>=2`:

1. after removing the full 3-content, (6.9) has degree `4h-4`;
2. `G_h(T)` is irreducible over `F_3`.

Then `C_h(T)` is irreducible over Q.

The degree clause is essential. For fixed prime 3 and growing `h`, many poles coalesce modulo 3, so the leading coefficient can vanish after the first content division. In that case (6.9) is only the first side of a higher-order Newton polygon, not a full-degree Dedekind certificate.

### 6.1 Explicit first correction

When `e_h=1`, the polynomial `H_h` can be computed without forming `C_h`.

Choose integer lifts of `R_h` and write

```text
N_h=R_h^3+3S_h mod 9.                                   (6.10)
```

Put

```text
E(u)=(P(u)-(u-1)^3)/3
    =11u^3+18u^2+8u+2.                                  (6.11)
```

For `a=x+h`, define

```text
A=(a-1)R_h,
B=a^2R_{h-1},
R_{h+1}=A-B mod 3.
```

Using

```text
(A-B)^3=A^3-B^3-3AB(A-B),
```

one obtains the exact recurrence

```text
S_{h+1}
 = E(a)R_h^3+(a-1)^3S_h-a^6S_{h-1}
   +(a-1)a^2 R_hR_{h-1}R_{h+1} mod 3.                  (6.12)
```

The initial values are

```text
S_1=0,
S_2=E(x+1) mod 3.                                       (6.13)
```

Differentiating (6.10) gives

```text
K_h/3
 = L_h(R_h^2R_h'+S_h')-L_h'R_h^3 mod 3.                (6.14)
```

Thus (6.2), (6.12), and (6.14) give a completely explicit finite-field recurrence for the first 3-adic critical layer.

If (6.14) vanishes identically for some residue class of `h`, repeat the same construction one 3-adic layer deeper. This is exactly an Ore-MacLane-Montes type tree, not an ordinary Newton polygon.

## 7. Fixed odd primes and pole collisions

The factorial suggestion has a built-in obstruction.

### Lemma 7.1 [PROVED]

Let `q != 3` be prime. Reduce modulo `q`, and let `a` be a residue containing `m_a` of the consecutive poles `-1,...,-h`. Assume `N_h(a) != 0 mod q`. Then

```text
ord_{x=a} gcd(L_h,K_h) >= m_a-1.                        (7.1)
```

Proof. Write

```text
L_h=(x-a)^m u,
u(a)!=0.
```

Then `ord L_h'=m-1`, unless `q|m`, in which case the order only increases. Since

```text
K_h=L_hN_h'-3L_h'N_h
```

and `3N_h(a)` is a unit, (7.1) follows.

For consecutive poles,

```text
sum_a (m_a-1)=h-min(h,q).                               (7.2)
```

Thus, for every fixed `q != 3`, once `h>q`, the reduction has at least `h-q` pole-cluster critical roots before any additional degeneration is counted.

Consequences:

- Direct irreducible reduction modulo a fixed `q` cannot persist uniformly.
- A prime `q<=h` chosen because it divides factorials necessarily creates several pole clusters and normally several Newton sides.
- A prime `q>h` avoids pole collisions, but then all factorials in (3.3) are units and the proposed factorial Eisenstein mechanism disappears.

This is the exact small-prime dichotomy.

### 7.2 The primes 5 and 17

Modulo 5,

```text
P(u)=2u(u+1)(2u+1).                                     (7.3)
```

This gives special singular shifts, but it does not determine the mixed subresultants forming the coefficients of `C_h`.

For 17, the leading coefficient `lambda_h` satisfies

```text
lambda_1=1,
lambda_2=34,
lambda_{h+1}=34lambda_h-lambda_{h-1}.                   (7.4)
```

The proved Lucas lifting law is

```text
v_17(lambda_h)=0                         if h is odd,
v_17(lambda_h)=1+v_17(h/2)              if h is even.   (7.5)
```

This controls `lc(K_h)`, hence the critical points escaping toward infinity. It does not control `Res(L_h,K_h)` or the intermediate coefficients of `C_h`.

The `h=2` polygon at 17 already shows the typical effect: a length-two side, not a full-degree side. A prime divisor of `lambda_h` is therefore useful for producing a small local cycle after transitivity is known; it does not establish transitivity.

## 8. The weak block-size exclusion

Let the primitive critical polynomial have degree

```text
n_h=4h-4.
```

For a prime `q`, factor it over `Q_q` into irreducible factors of degrees

```text
d_{q,h,1},...,d_{q,h,s(q,h)}.
```

Define the subset-sum set

```text
D_{q,h}
 = {sum_{i in I} d_{q,h,i} : I subset {1,...,s(q,h)}}.  (8.1)
```

Every rational factor degree belongs to every `D_{q,h}`. Hence

```text
intersection_{q in {2,3,5,17}} D_{q,h} = {0,n_h}        (8.2)
```

would prove (M1).

For the weaker composition obstruction, let `m|3h`, `1<m<3h`, and let

```text
r_m=2m-2.
```

It is enough to prove

```text
intersection_q D_{q,h} intersect {1,...,r_m} is empty   (8.3)
```

for every such `m`.

An ordinary Newton polygon provides only slope denominators. If a side has reduced slope `a/b`, the local factors attached to that side have degrees divisible by `b`. With several sides, a rational factor may combine local factors from several sides. Therefore endpoint slopes alone do not determine `D_{q,h}`. One needs the residual polynomial on every side and, at 2 and 3, the higher-order descendants.

This is the precise minimal strengthening of the proposed Newton argument:

```text
[GAP-MONTES-DEGREE]
Compute the complete local factor-degree multisets at 2,3,5,17 uniformly in h,
and prove (8.2), or at least (8.3).
```

No ordinary one-slope calculation currently proves even the requested weak statement for all `h`.

## 9. Squarefreeness of N_h and K_h

### 9.1 What is proved for N_h

From (2.2),

```text
gcd(N_h,L_h)=1.                                         (9.1)
```

Therefore

```text
gcd(N_h,K_h)=gcd(N_h,N_h').                             (9.2)
```

Indeed, modulo `N_h`, one has `K_h=L_hN_h'`, and `L_h` is invertible modulo every factor of `N_h`.

Thus

```text
(M2)  <=>  Res(N_h,N_h') != 0
      <=>  C_h^raw(0) != 0.                             (9.3)
```

Adjacent coprimality `gcd(N_h,N_{h+1})=1` does not imply (9.3). A polynomial can have a repeated factor while remaining coprime to the next polynomial.

The mod-3 cube reduction also cannot prove squarefreeness: it makes every root inseparable in the first residue layer. One again needs the first nonzero 3-adic correction or a good prime depending on `h`.

Verdict:

```text
[M2 ALL h: GAP]
[POLES HONEST: PROVED]
```

### 9.2 What is proved for K_h

Equation (1.3) says that `K_h` is invariant under the affine involution. In the centered coordinate

```text
s=2x+h+1,
```

there is a polynomial `J_h` of degree `2h-2` such that, after multiplying by a nonzero rational scalar,

```text
K_h(x)=J_h(s^2).                                        (9.4)
```

Consequently

```text
K_h squarefree
iff
J_h squarefree and J_h(0)!=0.                           (9.5)
```

If `h` is odd, `s=0` is the central pole, and (2.3) proves `J_h(0)!=0`.

If `h` is even, `s=0` is the forced finite zero of `N_h`. In that case

```text
K_h(center)=L_h(center)N_h'(center),                    (9.6)
```

so (M2) implies `J_h(0)!=0`.

There is currently no all-h proof that `J_h` is squarefree.

Verdict:

```text
[M3 ALL h: GAP]
[M3 REDUCED TO DEGREE 2h-2 CENTERED DISCRIMINANT: PROVED]
```

### 9.3 Logical redundancy of (M2) and (M3) after (M1)

For the raw resultant, (M1) already implies both squarefreeness statements.

- If `N_h` has a repeated non-pole root `alpha`, then `K_h(alpha)=0` and the corresponding critical value is `0`. Hence `T` divides `C_h`, contradicting irreducibility of degree greater than one.
- If `K_h` has a repeated root `alpha`, then the linear factor associated with `Delta_h(alpha)` occurs with multiplicity in the root-product expression for `C_h`. Thus `C_h` is not squarefree and cannot be irreducible in characteristic zero.
- The same argument shows that (M1) forces distinct finite critical values.

The separate assumptions (M2)-(M3) are still useful when proving the degree and ramification statements before (M1), but they are not independent final obligations once raw-resultant irreducibility is established.

## 10. Machine-verification specification

The following Sage-style skeleton checks every proved identity without expanding unnecessary multivariate objects.

```python
R.<x> = PolynomialRing(ZZ)
RT.<T> = PolynomialRing(ZZ)
RXT.<x> = PolynomialRing(RT)

P = lambda u: 34*u^3 + 51*u^2 + 27*u + 5

def apery(n):
    return sum(binomial(n,k)^2 * binomial(n+k,k)^2 for k in range(n+1))

def Npoly(h):
    if h == 1:
        return R(1)
    Nm1 = R(1)
    N0 = P(x+1)
    if h == 2:
        return N0
    for d in range(2,h):
        N1 = P(x+d)*N0 - (x+d)^6*Nm1
        Nm1,N0 = N0,N1
    return N0

def critical_data(h):
    N = Npoly(h)
    L = prod(x+j for j in range(1,h+1))
    K = L*N.derivative() - 3*L.derivative()*N
    return N,L,K

for h in range(2,HMAX+1):
    N,L,K = critical_data(h)
    assert N.degree() == 3*(h-1)
    assert K.degree() == 4*h-4

    rho = -h-1-x
    assert N(rho) == (-1)^(h-1)*N
    assert L(rho) == (-1)^h*L
    assert K(rho) == K

    for j in range(1,h+1):
        rhsN = (-1)^(j-1) * factorial(j-1)^3 * factorial(h-j)^3 \
               * apery(j-1) * apery(h-j)
        rhsK = -3 * factorial(j-1)^4 * factorial(h-j)^4 \
               * apery(j-1) * apery(h-j)
        assert N(-j) == rhsN
        assert K(-j) == rhsK

    assert gcd(N,L) == 1
    assert gcd(N,K) == gcd(N,N.derivative())
```

For the critical polynomial:

```python
N,L,K = critical_data(h)
NX = RXT(N)
LX = RXT(L)
KX = RXT(K)
Craw = (NX - T*LX^3).resultant(KX)
C = Craw.primitive_part()
assert all(C[i] == 0 for i in range(1,C.degree()+1,2))
```

For the exact `h=2` certificate:

```python
C2 = 625*T^4 + 541064*T^2 + 22717712
assert C == C2 or C == -C2
```
