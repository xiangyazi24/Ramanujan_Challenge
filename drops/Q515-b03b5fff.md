# Q515: Decoupling the trilinear Weyl sum

## Summary

The proposed decoupling idea is the right direction, but the main obstacle is that the variables are not independent in the Fourier phase. The useful point is that the Weyl sum is not a generic CRT sum: it is a multilinear sum of trace/Fourier coefficients of sparse sets. The strongest available route is a hybrid of bilinear large sieve and Deligne-type bounds, rather than a direct Erdős--Turán argument.

## (A) Bounding the inner prime sum

For fixed q,r,

\[
S_{q,r}(h)=\sum_p \widehat Z_p(h(qr)^{-1}\bmod p).
\]

The trivial estimate is

\[
|S_{q,r}(h)|\leq \sum_p |Z_p|\ll X/\log X.
\]

A square-root estimate would require cancellation between the trace functions

\[
p\mapsto \widehat Z_p(h(qr)^{-1}).
\]

This is plausible because the argument changes with p, but it is not a consequence of |Z_p|=O(1). Sparsity alone gives no cancellation. For example, if every Z_p contains a fixed residue pattern, the Fourier coefficients can align.

The needed input is a prime-aspect trace-function estimate:

\[
\sum_{X<p\leq 2X} \widehat Z_p(h(qr)^{-1})\ll X^{1/2+o(1)}.
\]

This would be analogous to Bombieri--Vinogradov for a family of trace functions, but it is not currently automatic from Sp_4 monodromy.

## (B) Which decoupling strategy is best?

The three approaches have different strengths.

### 1. Cauchy-Schwarz on one prime variable

This is the most realistic first step. Write

\[
W(h)=\sum_{q<r} \widehat Z_q(\alpha_q)\widehat Z_r(\alpha_r)S_{q,r}(h).
\]

Then

\[
|W(h)|^2\leq
\left(\sum_{q<r}|\widehat Z_q|^2|\widehat Z_r|^2\right)
\left(\sum_{q<r}|S_{q,r}(h)|^2\right).
\]

The first factor is small because |Z_p| is O(1):

\[
\sum_{q<r}|\widehat Z_q|^2|\widehat Z_r|^2\ll (X/\log X)^2.
\]

The second factor is the real problem. Expanding it gives a four-prime correlation sum. This converts the trilinear problem into a quadratic correlation problem, which is exactly the situation where large sieve methods are strongest.

Therefore this is the preferred route.

### 2. Triple Kloosterman interpretation

The inverse factor

\[
(qr)^{-1}\pmod p
\]

resembles Kloosterman geometry, but the coefficients \widehat Z_p\ are not additive characters of a fixed algebraic function. A genuine Deligne bound would require a compatible l-adic sheaf over the prime parameter p, which is not presently available.

So this is a useful heuristic, but not the first rigorous route.

### 3. Bilinear forms

Writing

\[
W(h)=\sum_p \widehat Z_p(\alpha_p)B_p(h)
\]

is promising. A large sieve inequality of the form

\[
\sum_p |B_p(h)|^2\ll \frac{X}{\log X}\cdot \text{(average size)}
\]

would immediately give a saving. This is essentially equivalent to proving decorrelation of two-prime CRT channels, and is closely related to HM_2.

## (C) Random model size

Let

\[
P=\pi(2X)-\pi(X)\sim X/\log X.
\]

The number of triples is

\[
N\sim P^3/6.
\]

If each Fourier coefficient behaves like an independent random variable of size O(1), then

\[
\mathbb E|W(h)|^2\asymp N,
\]

so

\[
|W(h)|\asymp \sqrt N
\asymp \frac{X^{3/2}}{\log^{3/2}X}.
\]

The trivial bound is

\[
|W(h)|\ll N\asymp \frac{X^3}{\log^3X}.
\]

Thus the desired cancellation is a square-root saving over the number of triples.

## Relation to (HM)_3

For the Erdos--Turan argument, one does not need full equidistribution of CRT images. One needs a bound on the nonzero Fourier modes:

\[
\sum_{h\neq0}|\widehat{1_S}(h)|.
\]

The trilinear Weyl sum is exactly this Fourier coefficient. Therefore bounding W(h) is the correct analytic formulation.

The universal twist and palindromic zero sets help by reducing the possible structure of Z_p, but they do not alone imply Fourier cancellation. The missing theorem is a genuine prime-aspect decorrelation statement:

\[
\widehat Z_p(\alpha_p),\widehat Z_q(\alpha_q),\widehat Z_r(\alpha_r)
\]

must behave independently for distinct primes.

## Recommended proof architecture

1. Prove HM_2-style bilinear decorrelation for
\[
\sum_{p,q}\widehat Z_p(a_p)\widehat Z_q(a_q).
\]

2. Apply Cauchy-Schwarz to reduce HM_3 to this bilinear estimate.

3. Interpret the Fourier coefficients through the Mellin/trace-function description of Apéry zeros.

4. Use monodromy independence across primes to obtain square-root cancellation.

The most promising route is therefore: **Cauchy-Schwarz + bilinear large sieve + trace-function independence**, not direct CRT enumeration or a raw Kloosterman estimate.
