# Q750: Fixed-q to q=1 transfer — exact incidence survives, but pointwise q=1 is insufficient

## 1. The valid incidence map

The correction identifies a real but limited structure. For a fixed quotient q, let

\[
p\in (n/(q+1),n/q],\qquad r=n-qp.
\]

Then

\[
0\le r<p,
\]

and the Apéry-Lucas congruence gives

\[
p\mid b_n \Longleftrightarrow p\mid b_r.
\]

Define

\[
M_p=n-(q-1)p.
\]

Then

\[
M_p=p+r,
\]

so the same prime p is a q=1 carrier for the smaller argument M_p:

\[
p\in(M_p/2,M_p],\qquad p\mid b_{M_p}.
\]

Thus every fixed-q incidence produces a q=1 incidence, but on a different horizontal slice M_p depending on p.

The graph map is therefore

\[
(p,n)\mapsto(p,M_p=n-(q-1)p).
\]

This map is exact. The invalid step in Q745 was replacing the family of different M_p by one common M.

## 2. Countermodel: pointwise q=1 bounds do not imply fixed-q bounds

Let

\[
B_1(M)=\#\{p: p\in(M/2,M],\ p\mid b_M\}
\]

be an abstract q=1 counting function. Suppose only that

\[
B_1(M)=o(M/\log M)
\]

for every individual M.

This does not control a set of pairs (p,M_p), because the number of different M values can itself be large.

Construct an abstract model as follows. For every integer M let

\[
B_1(M)=\begin{cases}
\lfloor M/(\log M\log\log M)\rfloor,&M\in S,\\
0,&M\notin S,
\end{cases}
\]

where S is a sparse set chosen so that each individual M still satisfies

\[
B_1(M)/(M/\log M)=1/\log\log M\to0.
\]

Now choose a sequence of fixed-q affine maps

\[
M_p=n-(q-1)p
\]

whose images hit S for many p. The fixed-q count becomes

\[
D_q(n)=\#\{p:M_p\in S,\ p\text{ counted at }M_p\}.
\]

Since the M_p are distinct, the pointwise estimate gives only

\[
\sum_{M\in S\cap [n/q,n]} B_1(M),
\]

not one value of B_1. This sum can be as large as

\[
\asymp n/\log n
\]

while every individual term remains o(M/log M).

Hence:

\[
\forall M,\ B_1(M)=o(M/\log M)
\not\Rightarrow
D_q(n)=o(n/\log n).
\]

The missing ingredient is uniform control over the affine image set.

## 3. The weakest sufficient q=1 theorem

The correct replacement is an affine prime-sampled aggregate bound.

For fixed q define

\[
\mathcal M_q(n)=\{M_p=n-(q-1)p:p\in(n/(q+1),n/q]\}.
\]

The required q=1 statement is not pointwise but:

\[
\sum_{M\in\mathcal M_q(n)} B_1(M)=o_q(n/\log n).
\]

A stronger convenient form is:

\[
\sup_{A\subset [N,2N]}
\sum_{M\in A}B_1(M)
=o(N/\log N)
\]

for every affine image set A of the form

\[
A=\{n-cp:p\in(P,2P]\}.
\]

This is the weakest natural q=1 carrier theorem that actually transfers through the exact incidence map.

## 4. Can CRT or large sieve prove this aggregate statement?

Currently no nontrivial unconditional bound of the required strength follows from the known q=1 carrier.

The reason is that the affine set

\[
M_p=n-(q-1)p
\]

is highly structured, but the events

\[
p\mid b_{M_p}
\]

are not ordinary independent residue conditions. The modulus p changes with the sampled point.

A large sieve estimate typically controls sums such as

\[
\sum_p\left|\sum_{m\in A}a_m e(pm^{-1}/p)\right|^2,
\]

where the modulus and sequence are separated. Here the same prime p determines both the sampling location and the divisibility condition.

CRT gives independence between different primes only after fixing residue classes. It does not control the sparse diagonal incidence set

\[
\{(p,M):M=n-(q-1)p,\ p\mid b_M\}.
\]

Thus CRT alone gives no saving.

## 5. Strongest unconditional bound from this structure alone

The exact map gives only the trivial injection:

\[
D_q(n)\leq \sum_{M\in\mathcal M_q(n)}B_1(M).
\]

Since

\[
|\mathcal M_q(n)|\asymp n/(q\log n)
\]

(the number of primes in the interval), a pointwise q=1 estimate gives at best

\[
D_q(n)\leq \sum_M o(M/\log M),
\]

which is not useful. The little-o constants are not uniform over the sampled M.

No recurrence argument improves this: the recurrence connects b_M with neighboring indices but does not constrain the distribution of prime divisors over a moving affine family.

## 6. What remains after deleting invalid edges

The corrected incidence graph has:

- vertices: primes p and q=1 carriers M;
- valid edges:

\[
p\longrightarrow M_p=n-(q-1)p;
\]

- edge labels satisfying:

\[
p\mid b_n\Longleftrightarrow p\mid b_{M_p}.
\]

The deleted invalid edge is:

\[
\text{all }M_p\text{ replaced by a single }M.
\]

That replacement is exactly where the false implication entered.

Therefore the q=1 reduction is not false; the exact incidence map is real. What fails is the passage from pointwise q=1 sparsity to sparsity on an affine prime-sampled family. Closing fixed-q requires a new aggregate q=1 theorem, not a stronger pointwise theorem.
