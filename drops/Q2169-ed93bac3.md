# 1. Primitive numerator with an lcm denominator

Let

```text
u=U1/V1,
v=U2/V2,
```

be reduced rationals, with `Vi>0`.
Put

```text
g  = gcd(V1,V2),
W  = lcm(V1,V2) = V1*V2/g,
s1 = W/V1 = V2/g,
s2 = W/V2 = V1/g.
```

Then exactly

```text
u+v-1
 = (s1*U1+s2*U2-W)/W.
```

Define

```text
M=s1*U1+s2*U2-W,
d=gcd(|M|,W).
```

If `M!=0`, the reduced fraction is

```text
u+v-1 = (M/d)/(W/d).
```

If `M=0`, it reduces to `0/1`; the formula is still compatible with the convention `gcd(0,W)=W`.

Therefore

```text
boxed:
Ncorner = M/d,
Dcorner = W/d.                                      (1.1)
```

This is the unique primitive numerator up to the conventional overall sign.

## 1.1 Why using `V1*V2` is artificial

The product-denominator numerator would be

```text
Mprod = V2*U1 + V1*U2 - V1*V2.
```

Since `V1*V2=g*W`, one has exactly

```text
Mprod = g*M.                                        (1.2)
```

Thus the product-denominator construction inserts the structural common factor `gcd(V1,V2)` before primitive reduction.

A small exact example is

```text
u=5/12,
v=7/18.
```

Then

```text
W=lcm(12,18)=36,
s1=3,
s2=2,
M=3*5+2*7-36=-7,
```

so

```text
u+v-1=-7/36.
```

The product denominator gives `-42/216`, which is the same rational only after cancelling the artificial factor `6`.

## 1.2 Endpoint constants

If the raw corner is written

```text
d*X+a*Y-a*d,
```

then after dividing by `a*d` it is

```text
u+v-1,

u=X/a,
v=Y/d
```

(up to whichever naming convention is used for the two endpoints).
The theorem above is applied **after** these two values are reduced to `Ui/Vi`.

If a rational endpoint constant introduces an extra denominator `ei` not already absorbed by the interval theorem, and only

```text

```

is known, then the same proof gives the harmless replacement


```text

```

Everything below then acquires the additive height term `log lcm(e1,e2)`.

# 2. Exact valuation theorem for one corner

Let

```text
c=u+v-1=Ncorner/Dcorner
```

be reduced and nonzero.
For every prime `ell`,

```text
v_ell(Ncorner)=max(v_ell(c),0),
v_ell(Dcorner)=max(-v_ell(c),0).                    (2.1)
```

This is simply the uniqueness of a reduced rational numerator/denominator, but it is the cleanest formulation of mark survival.

Equivalently, from `M/W`,

```text
v_ell(Ncorner)
 = max(v_ell(M)-v_ell(W),0).                       (2.2)
```

## 2.1 The designated `0/1` conditions

Suppose `ell` is a marked shell prime and both reduced denominators are units:

```text
v_ell(V1)=v_ell(V2)=0.                              (2.3)
```

If for some `r>=1`

```text
U1 ≡ 0  (mod ell^r),
U2 ≡ V2 (mod ell^r),                                (2.4)
```

then in `Z_ell`

```text
u ≡ 0,
v ≡ 1                         (mod ell^r),
```

hence

```text
v_ell(c)>=r,
ell^r | Ncorner.                                    (2.5)
```

Likewise

```text
U1 ≡ V1,
U2 ≡ 0                         (mod ell^r)           (2.6)
```

implies the same conclusion.

These are exactly the two endpoint patterns used by a normalized corner: one bridge takes its selected value `0`, while the other takes its endpoint constant `1`.

The statement remains valid if the endpoint constant is another rational `rho`: replace `U2-V2` by the numerator of `v-rho`, and require the denominator of `rho` to be an `ell`-unit.

# 3. Closed trail: factorwise marks versus global rational reduction

Let the alternating corners be indexed by `j=1,...,m`, and reduce each separately:

```text
c_j=u_j+v_j-1=N_j/D_j,
gcd(N_j,D_j)=1,
D_j>0.                                               (3.1)
```

## 3.1 Safe factorwise integer carrier

Define

```text
Ktrail=product_j N_j.                                (3.2)
```

Suppose a marked shell prime `ell` is assigned multiplicity `r_(ell,j)` at corner `j`, meaning the local conditions of Section 2 prove

```text
v_ell(N_j)>=r_(ell,j).
```

Then exactly

```text
v_ell(Ktrail)
 =sum_j v_ell(N_j)
 >=sum_j r_(ell,j).                                  (3.3)
```

There is no further condition. In particular, a denominator at a different corner cannot cancel a divisor of the **integer** `Ktrail`.

Thus if alternating corners use every source and target bridge once and the local corner construction assigns the required shell-prime marks across those corners, multiplying the primitive corner numerators preserves all of those marks.

This is the safe object for a height/divisibility contradiction.

## 3.2 What changes if the whole rational product is reduced

If instead one forms

```text
Cglobal=product_j c_j
       =(product_j N_j)/(product_j D_j)
```

and then reduces once globally, its primitive numerator satisfies

```text
boxed:
v_ell(Nglobal)
 = max(
     sum_j v_ell(N_j)-sum_j v_ell(D_j),
     0
   ).                                                (3.4)
```

Therefore a required multiplicity `m_ell` survives global rational reduction iff

```text
sum_j v_ell(N_j)-sum_j v_ell(D_j) >= m_ell.         (3.5)
```

A strong sufficient condition is

```text
ell ∤ product_j D_j.                                 (3.6)
```

In a nonwrapping shell normalization where every denominator factor is `<N<ell`, (3.6) holds simultaneously for every shell mark.

## 3.3 Why the distinction is real

The abstract reduced factors

```text
c1=101/2,
c2=1/101
```

show the issue sharply.

Factorwise, the first primitive numerator carries `101`. But

```text
c1*c2=1/2,
```

so the global primitive numerator does not.

This is **not** claimed to be an Apéry corner fixture. It only proves the arithmetic point: local mark survival does not imply survival after a separate global rational reduction unless (3.5) is checked.

For the P3.2 carrier one may avoid this issue completely by using the integer `Ktrail` in (3.2).


```text

 =max(v_p(V1),v_p(V2))
 <=5*max(v_p(L1),v_p(L2))
 =v_p(L12^5).
```

Hence

```text
boxed:
W | L12^5.                                          (4.2)
```

Now from

```text
M=W*(u+v-1)
```

we have

```text
|Ncorner|
 <=|M|
 <=W*(1+|u|+|v|).
```

Therefore

```text
boxed:
log |Ncorner|
 <=5 log L12 + log(1+|u|+|v|).                     (4.3)
```

This is the strongest clean upper bound obtainable from only `(4.1)` and the actual values `u,v`; primitive cancellation can only improve it.

In fact, when `M!=0`, the exact identity is

```text
log |Ncorner|
 =log W
  +log |u+v-1|
  -log gcd(|M|,W).                                  (4.4)
```

Combining with (4.3),


This is the rational normalized version of the raw max-vs-sum compression: the two numerator heights still enter through `max`, not through `H1+H2`.

# 5. Exact lcm defect: what remains of the max gain

For positive integers `Ls,Lt`, define

```text
delta(Ls,Lt)
 =log lcm(Ls,Lt)-max(log Ls,log Lt).                (5.1)
```

Using

```text
lcm(Ls,Lt)*gcd(Ls,Lt)=Ls*Lt,
```

one gets the exact formula

```text
boxed:
delta(Ls,Lt)
 =log( min(Ls,Lt)/gcd(Ls,Lt) ) >=0.                (5.2)
```

Hence

```text
boxed:
log lcm(Ls,Lt)
 =max(log Ls,log Lt)+delta(Ls,Lt).                 (5.3)
```

Two useful interpretations are immediate.

### Loss relative to the ideal max

The normalized denominator pays exactly

```text
5*delta(Ls,Lt)                                      (5.4)
```

more than the ideal raw `max` ledger.

### Saving relative to the naive product/sum

Compared with

```text
5*(log Ls+log Lt),
```

the lcm denominator still saves exactly

```text
5*log gcd(Ls,Lt).                                   (5.5)
```

So even when the ideal max fails, the rational lcm construction can retain a strict part of the raw compression.

The lcm cost interpolates exactly between max and sum:

```text
max(log Ls,log Lt)
 <=log lcm(Ls,Lt)
 <=log Ls+log Lt.                                   (5.6)
```

# 6. Actual sign-uniform shell geometry at one alternating corner

Write an even closed trail in source/target form

```text
p1 - q1 - p2 - q2 - ... - pm - qm - p1,
```

where the intrinsic arrows are all `p -> q` (the sign-uniform branch). Indices are cyclic.

Consider the alternating corner at the shared edge

```text
p_(i+1) -> q_i.
```

Put

```text
x_i = a(p_(i+1),q_i)
    = p_(i+1) - (q_i+1)/2,

DeltaP_i = p_(i+1)-p_i,
DeltaQ_i = q_(i+1)-q_i.                              (6.1)
```

The target bridge at `q_i` has its other label

```text
a(p_i,q_i)
 =x_i-DeltaP_i.                                     (6.2)
```

The source bridge at `p_(i+1)` has its other label

```text
a(p_(i+1),q_(i+1))
 =x_i-DeltaQ_i/2.                                   (6.3)
```

Since all shell primes are odd, `DeltaQ_i/2` is an integer.

Thus the two bridge intervals share the endpoint label `x_i`.
They extend to the **same side** of `x_i` iff

```text
DeltaP_i*DeltaQ_i > 0.                              (6.4)
```

They extend to opposite sides iff the product is negative.

The other alternating parity has the analogous criterion with the preceding target increment.

## 6.1 Same-side corners are exactly the good geometric case

Under the repository denominator convention, a gap `h` between lower label `r` and upper label `r+h` uses factors

```text
I(r,h)={r+2,...,r+h}.                               (6.5)
```

If two bridges share the same endpoint and extend to the same side, their factor intervals are nested. Therefore one interval lcm divides the other:

```text
Ls | Lt  or  Lt | Ls.                               (6.6)
```

Consequently

```text
lcm(Ls,Lt)=max(Ls,Lt),
delta(Ls,Lt)=0.                                     (6.7)
```

This proves:

> **Order-compatible normalized-corner theorem.**
> On an alternating corner with `DeltaP*DeltaQ>0`, the exponent-five common-denominator contribution is exactly `5*max(log Ls,log Lt)`. The rational normalization loses none of the raw max-vs-sum denominator gain at that corner.

This includes the monotone rectangle corners used in Q2148 and the monotone six-cycle ordering tested in Q2156.

## 6.2 Sign-uniformity is weaker than order compatibility

The hypothesis

```text
p<q for every intrinsic edge
```

places every edge in one chamber, but it does not impose the same rise/fall pattern on the cyclic source sequence `(p_i)` and target sequence `(q_i)`.
Thus (6.4) need not hold at every alternating corner.

The next section gives an exact shell-prime fixture.

```text
       Hs(c)-log Vs(c),
       Ht(c)-log Vt(c)
     ).                                               (8.1)
```

Summing over the alternating corners gives the safe integer trail carrier

```text
Ktrail=product_c N_c
```

with

```text

 <= H_ideal(C) + 5*Delta_lcm(C),                    (8.2)
```

where

```text
H_ideal(C)
 := sum_c [
      5*max(log Ls(c),log Lt(c))

           Hs(c)-log Vs(c),
           Ht(c)-log Vt(c))
    ],

 := sum_c delta_c.                                  (8.3)
```

This is the strongest clean total estimate from the banked denominator theorem plus the actual reduced numerator heights.

No additional `V_s*V_t` cost occurs.

# 9. Precisely what strict raw gain survives

There are two separate max-vs-sum effects.

## 9.1 Numerator-height compression survives unconditionally

At every rational normalized corner, the numerator-height term is

```text
max(0,Hs-log Vs,Ht-log Vt),                         (9.1)
```

up to `log 3`.
It is never replaced by

```text
(Hs-log Vs)+(Ht-log Vt).
```

So this part of the raw corner compression survives rational normalization completely.

## 9.2 Denominator compression survives with exact defect

The ideal raw-max denominator term would be

```text
5*max(log Ls,log Lt).
```

The normalized rational term is

```text
5*max(log Ls,log Lt)+5*delta.                       (9.2)
```

Thus:

```text
same-side/nested corner:
    delta=0, full max gain survives;

arbitrary corner:
    0<=delta<=min(log Ls,log Lt),
    so the cost lies between max and sum;

relative to the naive sum:
    exact saving = 5*log gcd(Ls,Lt).                (9.3)
```

The six-prime fixture proves only that `delta` cannot be set identically to zero from sign-uniform shell geometry alone.
It does **not** say the lcm construction has no gain.

# 12. Dependency-map theorem

The clean theorem to bank is:

## Theorem `Q32_RATIONAL_ALTERNATING_CORNER_LCM`

Let an alternating corner consist of two fully reduced endpoint-normalized exponent-five Apéry bridges

```text
u=U_s/V_s,
v=U_t/V_t,
V_s | L_s^5,
V_t | L_t^5.
```

Then:

1. the primitive numerator of `u+v-1` is exactly `(PNU)` with denominator `lcm(V_s,V_t)` before primitive cancellation;
2. a designated shell-prime mark survives the local primitive reduction whenever the corresponding reduced denominators are units and the `0/1` endpoint congruences hold; the exact valuation is `(VAL-local)`;
3. multiplying the local primitive **integer numerators** around a trail preserves all factorwise marks; replacing this by the primitive numerator of the global rational product is valid only under `(VAL-global)`;
4. the local primitive numerator height satisfies `(HEIGHT-red)`;
5. the denominator lcm decomposes exactly as `max + delta`, with `delta` given by `(DEFECT)`;
6. at an order-compatible alternating corner (`DeltaP*DeltaQ>0`) the two actual denominator intervals are nested and `delta=0`;
7. sign-uniform shell geometry alone does not force `delta=0`, as witnessed by the exact six-prime fixture (7.1)--(7.6).

# 13. Bottom line

The rational normalization does **not** destroy the raw corner mechanism.
The correct arithmetic is

```text
common denominator = lcm(Vs,Vt),
not Vs*Vt,
```

and this gives two genuine savings:

```text
numerator height: max rather than sum;
denominator height: log lcm rather than log product.
```

At order-compatible alternating corners, the actual interval sets are nested, so

```text
lcm(Ls,Lt)=max(Ls,Lt)
```

and the full raw max-vs-sum denominator gain survives exponent-five normalization.

For a general sign-uniform trail, the only extra cost is the exact nonnegative quantity

```text
5*Delta_lcm
 =5*sum_c log(
      min(Ls(c),Lt(c))/gcd(Ls(c),Lt(c))
    ).
```

The six-prime shell fixture proves that this quantity cannot be declared zero from order geometry alone. It does not refute an actual-Apéry selectedness bound on it.

Finally, the safe carrier is the product of the **locally reduced primitive corner numerators**. This distinction matters: those integer factors retain their marks without any cross-corner unit hypothesis, whereas a subsequent global rational reduction can cancel a marked prime against a denominator from another corner.

So the next high-value statement is sharply scoped:

```text
prove, for the actual selected trail decomposition,

5*Delta_lcm < raw-max carrier margin,
```

or prove a stronger order-compatible selection theorem making `Delta_lcm` negligible. Either statement would preserve enough of the raw corner compression to make the two-sided exponent-five carrier genuinely subcritical; pure sign-uniform prime geometry by itself does not prove it.
