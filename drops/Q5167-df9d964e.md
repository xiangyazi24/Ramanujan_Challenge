# 7. Audit of the two-anchor crossed carrier

The new two-anchor algebra is real and should be retained, but it does not close the full-core one-prefix UPRC.

Suppose a transverse pair also shares a second physical prefix \(J+d\).  With

\[
a=a_p(J)<a'=a_q(J),
\qquad \Delta=a'-a,
\]

the endpoint-clean opposite table gives the pointwise carrier

\[
pq\mid N_a(J)N_{d-a'}(J+a')
\]

of logarithmic length \(d-\Delta\).  This is genuinely shorter than the old \(d\)-length carrier.

There are two reasons it does not improve (6.3).

First, it is still an \(\ell^1\) radical statement.  At a fixed edge and two colors, it bounds the **sum** of shell-prime masses supported by the relevant short factors.  The transverse energy contains their **product**.  Values of order \(H\) in each color remain legal, giving an \(H^2\) pair contribution.

Second, the exact four-point Wronskian/Pluecker relation already proves that the obvious attempt to make a second exterior carrier is algebraically neutral: on the transverse table it equals the old \(N_d(J)\)-adic valuation because the short factor \(N_\Delta(J+a)\) is a unit modulo both selected characteristics.

For the long physical edges where the active two-anchor problem was difficult, \(d\gg H\), so

\[
\frac{\Delta}{d}=o(1)
\]

and the shortening \(d-\Delta\) changes no exponent anyway.

Most importantly for this question, Q5164's useful cumulative short-edge estimate depended on one-per-\(H\)-block packing.  The full balanced core does **not** inherit that packing from the pointwise carrier.  I therefore do not use that estimate here.

There is no nonwrap leak in this audit.  The two-anchor Pluecker table is used only under

\[
J+d<\min\{p,q\},
\]

so every factorial/continuant transfer denominator is a unit.  The first-return-pair resultant argument in Sections 1--5 is even safer: it only uses the ordinary same-characteristic selected quadruple's own nonwrapping span, not a cross-characteristic endpoint rewrite.

# 8. Why the new window moments still cannot force a global saving

The failure of a global improvement is not just the absence of a convenient inequality.  The numerical interfaces used above still admit an interior packet at the \(HP^2\) scale.

This is an **interface saturation model**, not an actual Apéry construction.

Take first-return labels in two fixed interior subbands of length \(\asymp H\), for example constant-proportion subintervals well above \(\mathsf A\) and well below \(H_1\).  Because

\[
\frac{\mathsf A}{H}=P^{-1/40+o(1)}\to0,
\qquad
\frac{R_0}{H}=P^{-1/20+o(1)}\to0,
\]

one can keep all three formal first-return gaps \(\gg\mathsf A\) and retain positive headroom while staying away from every endpoint window in (S).

At the exponent level take

\[
N_J\asymp\frac{P^2}{H^3}
\]

physical starts.  At each such start use \(\asymp H\) interior first-return colors and give each color logarithmic shell-prime mass \(\asymp H\).  Then

\[
M\asymp N_JH^2
=\frac{P^2}{H}
=P^{159/100+o(1)},
\]

and the weighted physical first-return length is

\[
\asymp HM\asymp P^2,
\]

so the exact spacing moment is saturated but not violated.

The same-label energy is

\[
N_J\cdot H\cdot H^2
\asymp P^2,
\]

again exactly compatible with (1.5).

The unequal-label energy is

\[
N_J\cdot H^4
\asymp P^2H,
\]

which saturates the Q5119 ceiling.

The new fixed-label resultant capacities also have room.  One color carries first mass

\[
N_JH=P^2/H^2=P^{118/100+o(1)},
\]

while the summed first-return-pair resultant capacity for a fixed interior first label is

\[
aH^2\asymp H^3=P^{123/100+o(1)}.
\]
