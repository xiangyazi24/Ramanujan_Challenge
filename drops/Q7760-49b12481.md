# 1. Exact folding of a fixed hit

Fix

\[
X^2<m\le2X^2,
\qquad X<p\le2X,
\]

and write

\[
m=q p+r,
\qquad 0\le r<p.
\tag{4}
\]

Suppose `r in Z_p`.  By reflection,

\[
p-1-r\in Z_p.
\]

Put

\[
s:=\min(r,p-1-r).
\tag{5}
\]

Since `p<=2X`,

\[
0\le s\le\frac{p-1}{2}<X.
\tag{6}
\]

Also `p|b_s`.  There are exactly two branches.

### Lower branch

If `r=s`, then

\[
p\mid m-s.
\tag{7}
\]

### Reflected branch

If `r=p-1-s`, then

\[
m+s+1=(q+1)p,
\]

so

\[
p\mid m+s+1.
\tag{8}
\]

Therefore every hit supplies a folded index `s<X` satisfying

\[
p\mid b_s,
\qquad
p\mid(m-s)(m+s+1).
\tag{9}
\]

The converse is equally exact.  Let `0<=s<X` and `p in (X,2X]`.  Since `s<p`, if

\[
p\mid b_s,
\qquad p\mid m-s,
\]

then `m mod p=s in Z_p`.  If instead

\[
p\mid b_s,
\qquad p\mid m+s+1,
\]

then

\[
m\bmod p=p-1-s,
\]

which lies in `Z_p` by reflection.

We have proved:

> **Fixed-`m` affine folding theorem.**  For `p in (X,2X]`,
> \[
> m\bmod p\in Z_p
> \iff
> \exists s\in[0,X):
> p\mid b_s\ \text{and}\ p\mid(m-s)(m+s+1).
> \tag{10}
> \]

A prime may be represented by both `s` and its reflected index when both are below `X`; taking a radical removes this harmless duplication.  Equation (10) proves the carrier identity (2).

This is the requested pair count in characteristic-zero form.  It has no moving `Z_p` left:

\[
K_X(m)
=\#\left\{p\in(X,2X]:
 p\mid
 \prod_{s<X}\gcd\bigl(b_s,(m-s)(m+s+1)\bigr)
\right\}.
\tag{11}
\]

# 2. The two-ray and quotient formulas

It is useful to retain the quotient and reflection-gap coordinates.  Define

\[
h:=p-1-2s\ge0.
\tag{12}
\]

Then `h` is always even.  In the lower branch,

\[
2m+1+h=(2q+1)p,
\tag{13}
\]

whereas in the reflected branch,

\[
2m+1-h=(2q+1)p.
\tag{14}
\]

Equivalently, after folding, every hit lies on one of the two affine rays

\[
p=\frac{m-s}{q}
\qquad\text{or}\qquad
p=\frac{m+s+1}{q+1}.
\tag{15}
\]

This is the same two-ray reduction found by the fixed-exponent Mellin audit, now written directly at the integer level.

For later comparison, the quotient range is

\[
\frac X2-O(1)\le q\le2X+O(1).
\tag{16}
\]

Thus one can rewrite the two parts of the tail as hyperbolic sums

\[
\sum_{\substack{p\sim X,\ q\asymp X\\H<m-pq<X\\p\mid b_{m-pq}}}\log p,
\tag{17}
\]

and

\[
\sum_{\substack{p\sim X,\ q\asymp X\\H<pq-m-1<X\\p\mid b_{pq-m-1}}}\log p.
\tag{18}
\]

There is a critical warning.  In (17),

\[
m-pq\equiv m\pmod p,
\]

and in (18), reflection gives the same selected residue event.  Hence the `q`-sum does **not** average different residues modulo `p`; it merely records the unique quotient.  Turning (17)--(18) into a bilinear-looking expression does not manufacture Kloosterman cancellation.  This is the fixed-`m` analogue of the zero-numerator diagonal in the cubic CRT audit.

So the entire target-scale contribution from small folded indices is already controlled.  The hard range is exactly

s=\frac{p-1}{2},

# 4. Why the gap polynomial is identically blind to the reflected pair

This is the exact local obstruction, not merely an adversarial slogan.

The gap polynomials satisfy the reflection identity

\[
N_h(-x-h-1)=(-1)^{h-1}N_h(x).
\tag{25}
\]

For a folded reflection pair, `h=p-1-2s` is even.  Therefore (25) is anti-invariance about the center

\[
x=-\frac{h+1}{2},
\]

and the primitive linear polynomial

\[
2x+h+1
\]

divides `N_h(x)` in `Z[x]`.  At the folded starting point,

\[
2s+h+1=p.
\tag{26}
\]

Consequently

\[
N_h(s)\equiv0\pmod p
\tag{27}
\]

for the purely structural reason that its central linear factor is `p`.  The necessary zero-to-zero certificate has supplied no extra arithmetic information whatever.

This explains the anchored-star obstruction exactly.  Fix one integer

\[
m_0\in(X^2,2X^2]
\]

and, for every prime `p in (X,2X]` outside an `O(1)` exceptional set, put

\[
r_p=m_0\bmod p,
\qquad
Z_p^*=\{r_p,p-1-r_p\}.
\tag{28}
\]

Delete the window primes dividing

\[
(m_0-1)m_0(m_0+1)(m_0+2)(2m_0+1)
\]

to avoid endpoints and the central fixed point.  Then:

- `|Z_p^*|=2`;
- reflection holds;

- the interval and `O(p^(2/3))` bounds hold trivially;

Therefore

\[
K_X^*(m_0)=\pi(2X)-\pi(X)-O(1)\sim\frac X{\log X}.
\tag{29}
\]

This proves:

# 5. The single closing lemma

Here is the cleanest statement I recommend adding to the research ledger.

> **Affine Apéry tail lemma (AAT).**  For every `epsilon>0`, uniformly for
> \[
> X^2<m\le2X^2,
> \]
> one has
> \[
> \log\operatorname{rad}_{X}\!\left(
>  \prod_{X^{1/3}<s<X}
>  \gcd\bigl(b_s,(m-s)(m+s+1)\bigr)
> \right)
> \ll_\varepsilon X^{2/3+\varepsilon}.
> \tag{30}
> \]

### Proof that (AAT) closes (AT'')

Combine:

1. the exact carrier identity (2);
2. the small-index estimate (20);
3. the central `O(log X)` estimate;
4. (30).

This gives

\[
\sum_{\substack{X<p\le2X\\m\bmod p\in Z_p}}\log p
\ll_\varepsilon X^{2/3+\varepsilon}.
\tag{31}
\]

Since every term on the left is at least `log X`,

\[
K_X(m)\ll_\varepsilon\frac{X^{2/3+\varepsilon}}{\log X}.
\tag{32}
\]

The estimate is uniform in `m`, so taking the maximum proves (AT'').

This proof is complete conditional on (AAT).  What is open is (30), not the reduction.

### Why this is a useful formulation rather than a renamed finite-field target

Equation (30) is a characteristic-zero gcd/radical statement involving:

- the fixed integer sequence `b_s`;
- two explicit affine forms in `s` and the external integer `m`;
- one fixed dyadic prime window.

It is the form to which a Subspace-theorem variant, a p-adic height theorem, a modular selected-trace sieve, or a new G-function gcd theorem would have to apply.  The moving sets `Z_p` have disappeared.

It is also stronger than a density-one statement and has the correct quantifier: **every fixed `m`**.

# 6. Equivalent selected-section discrepancy

Let

\[
\widehat Z_p(a)=\sum_{r\in Z_p}e_p(-ar),
\qquad e_p(t)=e^{2\pi i t/p}.
\]

Fourier inversion gives

\[
1_{m\bmod p\in Z_p}
=\frac{Z(p)}p
+\frac1p\sum_{a\ne0}\widehat Z_p(a)e_p(am).
\tag{33}
\]

Therefore the weighted atom is

\[
\begin{aligned}
W_X(m)
&:=\sum_{\substack{X<p\le2X\\m\bmod p\in Z_p}}\log p\\
&=\underbrace{\sum_{X<p\le2X}\frac{Z(p)}p\log p}_{\Lambda_X^{\log}}
+\underbrace{\sum_{X<p\le2X}\frac{\log p}{p}
 \sum_{a\ne0}\widehat Z_p(a)e_p(am)}_{E_X(m)}.
\end{aligned}
\tag{34}
\]

The main term satisfies

\[
\Lambda_X^{\log}
\le\log(2X)\lambda_X
=X^{2/3+o(1)}
\tag{35}
\]

under the scale in the question.  Thus an equivalent analytic interface is the one-sided selected-section estimate

\[
\boxed{
\sup_{X^2<m\le2X^2}E_X(m)
\ll_\varepsilon X^{2/3+\varepsilon}.
}
\tag{SS}
\]

A square-root estimate `E_X(m)<<X^(1/2+epsilon)` would be much stronger than needed.  The required saving is only from the trivial weighted size `asymp X` down to `X^(2/3+o(1))`.

But (SS) is emphatically **cross-prime**.  Parseval for one `p`, the short-window Fourier energy in `atom_tail_section.tex`, and bounded codegrees do not control the deterministic sum of the selected phases `e_p(am)` as `p` varies.  The anchored star chooses the row phases so that this sum is positive and of size `asymp X`.

# 7. The exact Apéry-specific arithmetic input

The missing input can be stated in three equivalent languages.

## 7.1 Characteristic-zero gcd language

Medium prime divisors of the actual `b_s` must have uniform anti-correlation with the two affine divisors

\[
m-s,
\qquad m+s+1.
\]

Quantitatively, this is (AAT).

## 7.2 Residual affine-transfer language

The repository constructs the exact nonautonomous transfer state

\[
\mathcal A_{p,r}\in\operatorname{AGL}_2(\mathbb F_p)
\]

with `b_r` as a literal matrix coefficient.  One needs a theorem saying that the actual samples

\[
\mathcal A_{p,m\bmod p},
\qquad X<p\le2X,
\]

do not lie in the zero hyperplane at more than the expected `X^(2/3+o(1))/log X` primes.

The ambient hyperplane/codimension calculation is not enough.  A deterministic orbit can lie in a proper locus much more often than ambient density predicts.  The new theorem must control the **actual selected orbit across defining characteristics**.

## 7.3 Mellin/K3 language

For

\[
q_p=\left\lfloor\frac mp\right\rfloor,
\qquad r_p=m-q_pp,
\]

the fixed-exponent Mellin identity in the repository gives a defining-prime reduction of the selected coefficient to `b_{r_p}`.  The desired event is therefore the vanishing of one deterministic Kummer/Mellin character per field.

A proof would require a horizontal theorem for the selected section

\[
\chi_p=\omega_p^{\,m-q_p}
\]

at the prime above `p` itself.  Existing varying-characteristic Mellin equidistribution averages essentially all characters in each field; one selected character has mass `1/(p-1)` and may be exceptional for every `p` without affecting that average.  Standard compatible-system large sieves reduce at auxiliary primes `ell != p`; they cannot be specialized to `ell=p`.

### A concrete conjectural proof architecture

A genuine proof of (SS), and hence (AAT), could proceed as follows.

1. Construct an integral lisse/overconvergent realization of the level-6 Apéry/K3 system together with the required Eichler/affine extension, uniform in the Kummer character.
2. Prove large geometric monodromy and exclude an exceptional subobject containing the selected section `chi_p=omega_p^(m-q_p)`.
3. Establish a **defining-characteristic selected-section large sieve** over rational primes, not an auxiliary-`ell` sieve.  A square-root discrepancy in the prime variable would give
   \[
   E_X(m)\ll X^{1/2+\varepsilon},
   \]
   which is more than enough.
4. Treat the bounded-character-order sector by the divisor argument already banked in Q7736; apply the new sieve only to the growing-order sector.

Steps 1--3 are not present in the repository and are not consequences of current trace-function technology.  This is a proposed new theorem, not an invocation of an existing one.

# 8. Why the tempting alternatives do not supply the missing saving

## 8.1 Lucas collapse

Apéry--Lucas implies every hit prime also divides the single integer `b_m`.  Thus

\[
K_X(m)\le\omega_{(X,2X]}(b_m).
\]

But

\[
\log b_m\asymp m\asymp X^2,
\]

so height alone gives only `O(X^2/log X)`, even worse than prime counting.  The fact that the detector collapses to `b_m` is conceptually important, but it does not give smooth-radical anti-concentration.

## 8.2 The linear carrier without `b_s`

Equation (23) has logarithmic height `O(X log X)`, yielding only `K=O(X)`.  This is exactly the `X^(1/3)` exponent gap.

## 8.3 Gap/resultant certificates

They control two or more zero incidences **at one prime**.  An atom can consist of many primes, each contributing only one reflected pair.  For that pair the gap polynomial vanishes through its forced central factor (26).  Fixed-depth resultants cannot amplify one incidence per changing prime.

## 8.4 Ordinary large sieve

The natural interval has length `X^2` and the moduli are `asymp X`, the critical `N=Q^2` regime.  The ordinary large sieve controls an average `L^2` norm over `m`; it permits isolated atoms of size `X/log X`, as the anchored-star model demonstrates.

## 8.5 Trilinear Kloosterman fractions

After writing `m-s=pq`, the low residue is still `m mod p`; the quotient does not vary it.  In the cubic CRT expansion, the same obstruction appears as the zero-numerator diagonal.  Off-diagonal Bettin--Chandee/DFI-type cancellation does not estimate the atom itself.

## 8.6 A fixed finite family of companions

A finite local separator can certify that some coordinate is nonzero, but it does not bound how many defining primes make the original period coordinate vanish at a selected row.  Multiplying finitely many companion forms also incurs exponential characteristic-zero height.  The fixed-family state-space route does not provide (AAT).

# 10. Exact Sage check at `X=128`

The following script:

- computes every `Z_p` for `128<p<=256` directly from the Apéry recurrence;
- scans every `m` in `(128^2,2*128^2]`;
- verifies the exact affine carrier identity prime by prime;
- records the actual maximum `K_X(m)` and its witnesses;
- verifies that every reflected gap is even and that its gap-polynomial value vanishes at the forced center;
- separates the already-controlled `s<=X^(1/3)` part from the tail.

It prints finite data only and makes no asymptotic inference.

```python
#!/usr/bin/env sage -python
from sage.all import ZZ, RR, prime_range, inverse_mod

X = 128
M_LO = X * X + 1
M_HI = 2 * X * X
PRIMES = list(prime_range(X + 1, 2 * X + 1))


def P(n):
    n = ZZ(n)
    return 34*n**3 + 51*n**2 + 27*n + 5


def apery_exact(N):
    """Return b_0,...,b_N as exact integers."""
    if N == 0:
        return [ZZ(1)]
    b = [ZZ(1), ZZ(5)]
    for n in range(1, N):
        num = P(n)*b[n] - ZZ(n)**3*b[n-1]
        den = ZZ(n + 1)**3
        q, r = num.quo_rem(den)
        assert r == 0
        b.append(q)
    return b


def apery_mod_p(p):
    """Return b_0,...,b_{p-1} in F_p via the recurrence."""
    b = [0] * p
    b[0] = 1
    b[1] = 5 % p
    for n in range(1, p - 1):
        den = pow(n + 1, 3, p)
        rhs = (int(P(n) % p) * b[n]
               - pow(n, 3, p) * b[n-1]) % p
        b[n+1] = (rhs * int(inverse_mod(den, p))) % p
    return b


def gap_value_mod(p, x, h):
    """
    Evaluate the repo gap polynomial N_h(x) modulo p:
      N_1=1,
      N_2=P(x+1),
      N_{k+1}=P(x+k)N_k-(x+k)^6 N_{k-1}.
    """
    assert h >= 1
    if h == 1:
        return 1 % p
    nm1 = 1 % p
    cur = int(P(x + 1) % p)
    if h == 2:
        return cur
    for k in range(2, h):
        nxt = (int(P(x + k) % p) * cur
               - pow((x + k) % p, 6, p) * nm1) % p
        nm1, cur = cur, nxt
    return cur


# Exact rows and zero sets.
B = apery_exact(X - 1)
rows = {p: apery_mod_p(p) for p in PRIMES}
Z = {p: {r for r, v in enumerate(rows[p]) if v == 0}
     for p in PRIMES}
folded_zero_indices = {
    p: [s for s in range(X) if rows[p][s] == 0]
    for p in PRIMES
}

# Cross-check exact and modular recurrences on every index used by the carrier.
for p in PRIMES:
    for s in range(X):
        assert B[s] % p == rows[p][s]
    assert all((p - 1 - r) in Z[p] for r in Z[p])

H = 1
while (H + 1)**3 <= X:
    H += 1

lambda_X = sum(RR(len(Z[p])) / RR(p) for p in PRIMES)
weighted_mean = sum(RR(p).log() * RR(len(Z[p])) / RR(p)
                    for p in PRIMES)

max_K = -1
max_ms = []
max_weight = RR(0)
seen_reflection_gaps = set()

for m in range(M_LO, M_HI + 1):
    # Original finite-field definition.
    hits = {p for p in PRIMES if (m % p) in Z[p]}

    # Characteristic-zero affine carrier support.
    carrier = set()
    witnesses = {}
    for p in PRIMES:
        ss = []
        for s in folded_zero_indices[p]:
            assert B[s] % p == 0
```
