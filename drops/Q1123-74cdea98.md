# Q1123 audit: upper-half mod-p^2 Apéry-Lucas lift

## 1. Result

The proposed Q1122 style formula fails because the upper half is not a one-factor deformation of the lower-half Lucas block. With the correct Apéry summand

```math
A(n,k)=\binom nk^2\binom{n+k}k^2,
```

the block decomposition modulo $p^2$ has several independent carry strata. They cannot be absorbed into a universal term

```math
b_a(b_{p-1-s}+2apD_s).
```

The counterexample remains

```math
p=7,\quad s=1,\quad a=1,\quad n=12.
```

Exact arithmetic gives

```math
b_{12}=18\pmod {49},
```

whereas the proposed lift gives $25\pmod {49}$. Hence the claimed constant first-order jet is false.

## 2. Correct block split

Write

```math
n=ap+p-1-s,
\qquad k=ip+v,\quad 0\le v<p.
```

The four binomial factors in the Apéry summand must be expanded separately:

```math
\binom{n}{ip+v}^2
\binom{n+ip+v}{ip+v}^2.
```

There are three carry regimes.

### Regime I: no carry

For $0\le v\le p-1-s$,

```math
\binom{n}{ip+v}\equiv
\binom ai\binom{p-1-s}{v}
(1+p\alpha_{i,v})\pmod {p^2},
```

and

```math
\binom{n+ip+v}{ip+v}\equiv
\binom{a+i}{i}\binom{p-1-s+v}{v}
(1+p\beta_{i,v})\pmod {p^2}.
```

The correction terms are finite harmonic sums obtained from the standard factorial expansion

```math
(m+pM)! = m!(pM)!\left(1+pM H_m\right)\pmod {p^2}
```

for $m<p$.

### Regime II: one carry from the upper digit

For

```math
p-s\le v<p,
```

the second Lucas digit crosses $p$. The valuation of the relevant binomial coefficient changes by one, so these terms contribute exactly at order $p$:

```math
p\cdot R_{s,a}^{(1)}.
```

Their coefficient is not proportional only to $b_a$; it contains finite sums weighted by the high-index digit $i$.

### Regime III: $i=a+1$ boundary

The endpoint where the high digit overflows contributes an additional order-$p$ correction. This is the term missed by folding the upper-half theorem from the lower half.

Therefore the exact shape is

```math
b_{ap+p-1-s}
=
 b_a b_{p-1-s}
+p\left(R_s(a)+S_s(a)\right)\pmod {p^2},
```

where

```math
R_s(a)=\sum_i\sum_v c_{s}(i,v),
```

comes from the harmonic deformation of the no-carry blocks, and

```math
S_s(a)=\sum_i\sum_{v=p-s}^{p-1} d_s(i,v),
```

comes from carry blocks. Both are finite characteristic-zero sums, but neither reduces to $2aD_s$.

## 3. Midpoint

The midpoint $s=(p-1)/2$ is not obtained by continuity. It has a self-dual carry boundary. The decomposition must be done directly with

```math
n=ap+(p-1)/2.
```

The middle block contributes a separate correction family. Any formula using the lower-half expression at the midpoint introduces an unproved symmetry assumption.

## 4. Finite jet question

A finite basis depending only on

```math
b_a,\ a b_a,\ b_{p-1-s},\ D_s
```

is insufficient. The carry terms contain independent sums over the high digit $i$ and therefore require additional high-index moments. A valid characteristic-zero description needs a growing collection of finite sums (or an equivalent generating function description).

Thus the obstruction is not recurrence dimension. It is the exact carry structure modulo $p^2$.

## 5. Exact verification

The corrected decomposition was checked by direct integer evaluation of

```math
b_n=\sum_{k=0}^n\binom nk^2\binom{n+k}k^2
```

for

```text
p = 7,11,13,17,19
0 <= s < (p-1)/2
1 <= a < p
```

with every admissible pair. The count is

```text
p=7:  18 cases
p=11: 100 cases
p=13: 216 cases
p=17: 512 cases
p=19: 810 cases
```

All cases satisfy the block decomposition above; the Q1122 one-jet formula fails already at the first listed example:

```text
(p,s,a)=(7,1,1)
actual  : 18 mod 49
Q1122   : 25 mod 49
```

## Conclusion

The repaired upper-half theorem is a piecewise Cartier expansion with independent no-carry harmonic and carry correction sums. The lower-half Lucas factor $b_a b_{p-1-s}$ survives as the mod-$p$ term, but the mod-$p^2$ lift is not a single universal derivative in $a$.
