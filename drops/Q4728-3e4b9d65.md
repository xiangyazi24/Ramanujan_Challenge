\[
q_j
\quad\text{and}\quad
p_1\text{ if }j\text{ is even},
\quad
p_2\text{ if }j\text{ is odd}.
\]
Then:

- every rational column has degree exactly two;
- the RC5 high set is empty for every `T>>sqrt(N/log N)`;

# 6. What the rational tail really deletes

There is a useful exact dichotomy, but it stops before LAFI.

For an affine cell `C`, let `v_C(n)` be the number of its occurrences mapping to rational column `n` in one fixed chart/residue, and put
\[
R_C=\sum_nv_C(n).
\]
Fix `T`. Split columns into
\[
\mathcal H_T=\{n:m(n)\ge T\},
\qquad
\mathcal L_T=I\setminus\mathcal H_T.
\]
Then either
\[
\sum_{n\in\mathcal H_T}v_C(n)\ge R_C/2,
\]
or
\[
\#\{n\in\mathcal L_T:v_C(n)>0\}
\ge\frac{R_C}{2T}.
\tag{6.1}
\]
The first alternative is vertically rich and RC5 bounds the number of possible columns. The second is horizontally spread and can reuse the same source prime across all those columns. No theorem in the source bounds that reuse after an affine-level selector is imposed.

An attempt to convert (6.1) into row diversity by dividing by the selected mass is exactly the forbidden step: the level may retain only the incidences of one or two source-prime groups. The formal model in Section 5 realizes the second alternative with equality-scale behavior.
