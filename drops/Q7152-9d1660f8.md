# P32 boundary-array/polluted-column audit

## Conclusion

The distinguished polluted column does not presently give a new obstruction. The exact boundary identity
\[
 N_h(-m)=(-1)^{m-1}b_{m-1}b_{h-m}((m-1)!)^3((h-m)!)^3
\]
shows that a zero of the distinguished Apéry solution creates a vertical zero column in the continuant array, but this column is already the algebraic shadow of the same zero orbit/reflection data. Coupling it with a short return chain at the reflected point does not, by itself, force an adjacent centered pair.

A genuinely new constraint would require a mixed identity relating two independent fibers of the transfer matrix; the existing continuant identities only relate entries inside one fiber and therefore collapse to reflection plus vanishing of the same Apéry values.

## 1. What the polluted column actually says

Let \(b_r=0\pmod p\). Put \(m=r+1\). For every \(h\ge r+1\),
\[
N_h(-r-1)=(-1)^r b_r b_{h-r-1}(r!)^3((h-r-1)!)^3=0.
\]
Thus the column indexed by \(x=-r-1\) vanishes after height \(r+1\).

This is a boundary-column statement. It does not assert that the transfer state \(\pi_r=[b_r,c_r]\) is zero: the second coordinate generally survives. Therefore the column is not an additional zero state of the projective dynamics.

## 2. Attempted coupling with a short chain

Suppose
\[
r_0<r_1<r_2<r_3,\qquad r_3-r_0=s<\sqrt p,
\]
are actual zeros. The gap continuants give
\[
N_{r_{i+1}-r_i}(r_i)=0.
\]
Reflection gives
\[
b_{p-1-r_i}=0.
\]
The polluted column from \(r_0\) is at
\[
x=-r_0-1\equiv p-1-r_0 \pmod p.
\]
Hence its location is exactly the reflected zero. No independent point has appeared.

Any attempt to combine
\[
N_h(-r_0-1)=0
\]
with
\[
N_{r_{i+1}-r_i}(r_i)=0
\]
uses two evaluations of the same polynomial family at reflected arguments. Applying reflection identities transports one condition into the other; it does not create a new linear dependence among the gap parameters.

## 3. Desnanot--Jacobi / 2D grid test

The continuants satisfy determinant identities of the form
\[
D_{a,b}D_{a+1,b+1}-D_{a,b+1}D_{a+1,b}=\text{minor term}.
\]
A possible route would require the polluted boundary value to occupy a corner of a non-degenerate rectangle and the short returns to occupy opposite corners.

Here the boundary corner is singular: every entry on that side already contains the factor \(b_{r_0}\). Consequently the determinant identity becomes
\[
0\cdot D-D\cdot0=0
\]
or a restatement of the known factorization. There is no surviving minor containing both \(b_{r_0}\) and three independent return gaps.

Therefore no nontrivial Desnanot--Jacobi constraint follows from the currently verified identities.

## 4. Distinguished versus projective fibers

The obstruction is the distinction:

* distinguished zero: \(b_r=0\), while \(c_r\) may be nonzero;
* projective return: \(\pi_{r+h}\) is proportional to \(\pi_r\), equivalently a continuant vanishes.

The polluted column detects the first object only. A short chain detects projective returns. Identifying these two fibers would be an invalid step.

The known offcenter example at \(p=3727\) is therefore not contradicted: it has a distinguished zero pattern compatible with projective short returns without producing an adjacent pair. Any argument eliminating it must use additional arithmetic information about the Apéry recurrence, not only the boundary array.

## 5. What would be needed for a new theorem

A successful strengthening would need an identity involving both coordinates of \(\pi_r\), for example a relation forcing a determinant
\[
\det(\pi_{r_i},\pi_{r_j})
\]
to vanish from the boundary tail. The current formula only has the scalar factor \(b_r\), so it cannot see the nonzero companion coordinate \(c_r\).

Possible additional inputs:

1. a genuine two-coordinate monodromy constraint;
2. a rank statement for the full continuant matrix rather than one boundary column;
3. a p-adic restriction on simultaneous zeros of \(b_r\) and short return determinants.

None follows from the given hypotheses.

## Final audit result

The polluted-column mechanism is algebraically real but not stronger than reflection for the current purpose. The strongest rigorous statement obtainable from the supplied identities is:

\[
 b_{r_0}=0\implies N_h(-r_0-1)=0\ (h\ge r_0+1),
\]

and the location \(-r_0-1\) is exactly the reflected zero. Adding a short chain of returns does not force an adjacent centered pair. Any such implication would require new recurrence-specific input beyond the boundary rank-one identity.
