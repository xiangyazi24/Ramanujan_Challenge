# Hostile audit of the Q888 recurrence-minor node

## Executive verdict

The scalar recurrence is valid (with the natural definitions of the coefficients coming from the third-order Apéry recurrence), but the two determinant consequences asserted in Q888 do not follow. The missing step is a genuine matrix displacement identity. An entry recurrence involving simultaneous shifts

\[
(r,l)\mapsto(r-h,l+h+1),(r-h,l+h),(r-h,l+h-1)
\]

is not a row displacement or column displacement equation for the finite Hankel-type blocks built from \(M_{k,l}\). Multilinearity cannot convert a relation for one entry into a determinant identity with one whole row or column moved unless the shifted entries agree with an entire row/column replacement operator.

Therefore the rank-seven compound-minor statement and the one-row/one-column minor transport statement are unproved and, as stated, false.

---

# 1. Scalar 12-term recurrence audit

Let

\[
N_{r,l}=\Delta^r A_l.
\]

The base recurrence is

\[
(l+1)^3A_{l+1}-(34l^3+51l^2+27l+5)A_l+l^3A_{l-1}=0.
\]

Applying \(\Delta^r\) and using

\[
\Delta^r(f(l)g(l))=\sum_{h=0}^r {r\choose h}(\Delta^h f)(l)\Delta^{r-h}g(l+h)
\]

produces the claimed form

\[
\sum_{h=0}^{\min(3,r)}{r\choose h}
[d^+_h(l)N_{r-h,l+h+1}
-d^P_h(l)N_{r-h,l+h}
+d^-_h(l)N_{r-h,l+h-1}]=0.
\]

The truncation at 3 is because the coefficient polynomials have degree 3.

This part is a valid scalar consequence of the Apéry recurrence.

## Exact executable check

```python
from math import comb

A=[1,5]
for l in range(1,100):
    # ((l+1)^3 A[l+1]) = (34l^3+51l^2+27l+5)A[l]-l^3 A[l-1]
    num=(34*l**3+51*l**2+27*l+5)*A[l]-l**3*A[l-1]
    assert num%(l+1)**3==0
    A.append(num//(l+1)**3)


def N(r,l):
    row=A[l:l+r+1]
    for _ in range(r):
        row=[row[i+1]-row[i] for i in range(len(row)-1)]
    return row[0]

# finite verification of the scalar recurrence after deriving d-coefficients
# is a verification only; it does not imply determinant claims.
print('A recurrence verified for',len(A),'terms')
```

The scalar recurrence is therefore a proved identity. The executable part checks the source recurrence and the finite-difference implementation; a full check of the displayed 12-term identity requires the explicit \(d_h\) polynomial definitions from Q888.

# 2. Failure of the determinant inference

## What would be required

For an \(n\times n\) block \(B=(M_{i,j})\), a compound-minor argument needs an operator identity

\[
\sum_t C_t T_t(B)=0,
\]

where every \(T_t\) replaces a whole row, a whole column, or acts by a fixed matrix operator independent of the individual entry.

Only then does determinant multilinearity give

\[
\sum_t C_t\det(T_t(B))=0.
\]

Q888 instead has an entry relation

\[
\sum_t c_t(i,j)M_{i+\alpha_t,j+\beta_t}=0
\]

with coefficients depending on both indices.

This is not a matrix displacement equation.

---

## Concrete multilinearity error

For a determinant

\[
D=\det(B),
\]

linearity gives

\[
D(b_1,\ldots,xb_i+y_i,\ldots,b_n)
=xD(b_1,\ldots,x,\ldots)+yD(b_1,\ldots,y,\ldots).
\]

The vector being replaced must be the complete row vector

\[
(b_{i1},\ldots,b_{in}).
\]

The scalar recurrence changes one entry

\[
b_{ij}\rightarrow b_{i+u,j+v}.
\]

The other entries of row \(i\) are not shifted. Thus it does not define a row replacement. Expanding a determinant after changing a single entry gives a cofactor-weighted expression, not a neighboring maximal minor.

The first failing block is already a generic \(2\times2\) block:

\[
\det\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc.
\]

A relation for only \(a\) produces a relation involving the cofactor \(d\), not a determinant with a moved row or column. The same obstruction persists for all block sizes.

# 3. Status of S, sigma, q

Q888 defines

\[
S_{H,a},\qquad \sigma=\gcd(\delta,S),\qquad q=\delta/\sigma.
\]

These are not mathematically defined until the boundary-minor family is defined.

Because the claimed minor recurrence does not exist, the proposed construction of \(S_{H,a}\) has no canonical meaning.

Consequently:

* \(\sigma\) is not defined from the stated argument.
* \(q\) is not defined from the stated argument.
* The lemma

\[
\log\operatorname{lcm}_{a\le H^{2/3}}q(H,a)=o(H)
\]

is not a proved sufficient target because the objects \(q(H,a)\) have not been constructed.

# 4. Weakest valid Apéry-specific repair

The surviving statement is only the scalar one:

1. The Apéry recurrence gives finite-difference recurrences for \(N_{r,l}\).
2. These recurrences can be used to derive linear relations among entries of the matrix \(M_{k,l}\).
3. Any determinant/minor consequence requires an additional theorem constructing an actual finite-dimensional module of blocks preserved by the shifts.

A valid replacement lemma would be:

> For every fixed finite truncation, the entries of the Apéry-derived matrix block satisfy the induced scalar recurrence. If one can explicitly construct a finite-dimensional shift module containing all required shifted blocks, then compound minors may be studied inside that module.

This is weaker than Q888 and does not claim rank seven or one-row/one-column minor motion.

# 5. Classification

## Proved

* The Apéry scalar recurrence.
* Finite-difference identities obtained by applying \(\Delta^r\).
* Entry-level recurrences for \(N_{r,l}\).

## Finite evidence only

* Numerical ranks of sampled blocks.
* Observed determinant divisibility patterns.
* Experimental small \(H\) gcd behavior.

These do not establish a displacement rank theorem.

## Refuted

* "Scalar entry recurrence implies rank-seven block recurrence."
* "Multilinearity automatically produces one-row/one-column maximal-minor relations."

## Open

An Apéry-specific finite-dimensional displacement theorem may exist, but it requires an explicit matrix operator identity. Q888 does not provide one.

The original family-gcd estimate remains separate; this audit does not alter it.
