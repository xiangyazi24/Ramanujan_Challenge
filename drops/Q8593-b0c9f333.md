# Q8593 — Apéry Lucas support identity audit

## 1. Definitions and the basic Lucas split

Fix \(m<X^2\) and a shell prime \(X<p\le 2X\). Write
\[
m=qp+r,\qquad 0\le r<p.
\]
The Apéry Lucas congruence is
\[
A_{qp+r}\equiv A_qA_r\pmod p.
\]
Therefore
\[
p\mid A_m \iff A_qA_r\equiv0\pmod p.
\]
Over ℔/p this has exactly two possible mechanisms:

1. **root mechanism:** \(A_r\equiv0\pmod p\);
2. **companion mechanism:** \(A_q\equiv0\pmod p\).

The two mechanisms overlap when both vanish.

Let
\[
Z_p=\{r\in[0,p):A_r\equiv0\pmod p\}.
\]
For the fixed \(m,p\), the residue \(r=m\bmod p\) is unique, and the quotient digit \(q=\lfloor m/p\rfloor\) is unique.

---

## 2. Exact relation between \(K_{\rm full},K_{\rm tri},R_{\rm tri},T\)

For the shell \(X<p\le2X\), define
\[
K_{\rm full}(m)=\#\{p:X<p\le2X:r=m\bmod p\in Z_p\}.
\]

The target-triangular load keeps only \(p\le m\):
\[
K_{\rm tri}(m)=\#\{p:X<p\le m:r\in Z_p\}.
\]

Hence identically
\[
K_{\rm tri}(m)\le K_{\rm full}(m).
\]
Equality holds only when every shell prime tested satisfies \(p\le m\); for small \(m\) it is false.

Now define
\[
R_{\rm tri}(m)=\#\{p:X<p\le m:r\in Z_p,\ A_q\not\equiv0\pmod p\}.
\]

Let
\[
C(m)=\#\{p:X<p\le m:r\notin Z_p,\ A_q\equiv0\pmod p\},
\]
the companion-only load, and
\[
D(m)=\#\{p:X<p\le m:r\in Z_p,\ A_q\equiv0\pmod p\},
\]
the double-zero overlap.

Then the exact partition is
\[
T(m)=R_{\rm tri}(m)+C(m)+D(m).
\]
Also
\[
K_{\rm tri}(m)=R_{\rm tri}(m)+D(m).
\]
Therefore
\[
T(m)=K_{\rm tri}(m)+C(m).
\]
This is the fundamental identity. The root load is not the full divisibility load unless the companion-only term vanishes.

---

## 3. Monotonicity relations

The only unconditional inequalities are
\[
R_{\rm tri}(m)\le K_{\rm tri}(m)\le K_{\rm full}(m),
\]
and
\[
R_{\rm tri}(m)\le T(m)\le K_{\rm tri}(m)+C(m).
\]

There is no pointwise ordering between \(T\) and \(K_{\rm tri}\):

* if \(C(m)>0\), then \(T(m)>K_{\rm tri}(m)\);
* if \(D(m)>0\), then \(K_{\rm tri}\) counts a root hit but \(R_{\rm tri}\) does not.

The possible loads are related by the Venn diagram
\[
\begin{array}{c|c}
\text{set}&\text{condition}\\
\hline
R_{\rm tri}&A_r=0,\ A_q\ne0\\
D&A_r=0,\ A_q=0\\
C&A_r\ne0,\ A_q=0\\
\end{array}
\]
with
\[
T=R_{\rm tri}\sqcup D\sqcup C.
\]

## 4. Counterexamples to false equalities

### False claim: \(T=K_{\rm tri}\)

This would require \(C(m)=0\) for every \(m\). But the Lucas identity itself permits
\[
A_q\equiv0,\qquad A_r\not\equiv0,
\]
which gives \(p\mid A_m\) with no root hit. Any \(q\) satisfying \(p\mid A_q\) and any \(m=qp+r\) with \(A_r\not\equiv0\) gives a counterexample.

### False claim: \(T=R_{\rm tri}\)

A double zero gives
\[
A_q\equiv A_r\equiv0\pmod p,
\]
so \(p\mid A_m\), but it is removed by the condition \(A_q\ne0\) in \(R_{\rm tri}\). Hence \(D(m)>0\) contradicts equality.

### False claim: \(K_{\rm full}=K_{\rm tri}\)

Take \(m<X\). Then every shell prime has \(p>m\), so \(K_{\rm tri}=0\). But a residue \(m\bmod p=m\) may lie in \(Z_p\), giving \(K_{\rm full}>0\).

---

## 5. True support of \(\gcd(\operatorname{lcm}(1,\ldots,m),A_m)\)

A prime \(p\) contributes to
\[
\gcd(\operatorname{lcm}(1,\ldots,m),A_m)
\]
iff
\[
p\le m\quad\text{and}\quad p\mid A_m.
\]
For shell primes this is exactly the support counted by \(T(m)\), not by \(K_{\rm tri}\) or \(R_{\rm tri}\).

Using Lucas:
\[
p\in\operatorname{supp}\iff p\le m\text{ and }(A_q=0\text{ or }A_r=0).
\]
Thus the true object is the union support
\[
\{A_r=0\}\cup\{A_q=0\}.
\]

---

## 6. Consequence for factorial moment arguments

A factorial moment estimate for \(K_{\rm tri}\) or \(R_{\rm tri}\) is not automatically an estimate for \(T\).

For \(K_{\rm tri}\):
\[
T=K_{\rm tri}+C.
\]
A bound for \(K_{\rm tri}\) transfers only after proving a separate companion estimate, for example
\[
\sum_{m<X^2}(C(m))_j\ll \text{desired error}
\]
or a pointwise inequality
\[
C(m)\le E(m)
\]
with a separately controlled load \(E\).

For \(R_{\rm tri}\):
\[
T=R_{\rm tri}+C+D.
\]
One needs both companion-only control and double-zero overlap control. The double-zero term cannot be silently discarded because it is invisible to \(R_{\rm tri}\).

Therefore a statement of the form

"the factorial moment bound for \(R_{\rm tri}\) proves the gcd support bound"

is invalid unless the companion and overlap contributions have independent proved estimates.

## Final verdict

The exact support variable for the gcd is \(T\). The root variables satisfy only
\[
R_{\rm tri}\le K_{\rm tri}\le T
\]
up to the missing companion term, with the precise correction
\[
T=K_{\rm tri}+C=R_{\rm tri}+D+C.
\]
Any reduction from \(T\) to \(R_{\rm tri}\) or \(K_{\rm tri}\) requires a separate theorem controlling companion-only and double-zero fibres; it is not a consequence of the Lucas factorization alone.
