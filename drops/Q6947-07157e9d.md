## Column-defined U is the right Lean representation

Do not expand the nine entries of U. Define

```lean
U (n : ℕ) : Matrix (Fin 3) (Fin 3) ℚ :=
  ![e0, T n *ᵥ e0, (T n * T (n+1)) *ᵥ e0]
```

Then the Miller relation is proved from associativity:

```lean
lemma T_mul_U_succ (n : ℕ) :
  T n ⬝ U (n+1) = U n ⬝ C n := by
  ext i j
  simp [U, C]
  ring
```

where

```text
C(n) = [[0,0,c0],
        [1,0,c1],
        [0,1,c2]].
```

This is strictly shorter than proving all nine expanded polynomial identities.

## Orientation of the terminal pullback

With

```
A = C^{-T},
```

the terminal object is a column of the transpose inverse chain:

```
A(N-k) ... A(N-1) U(N)^T e_j.
```

The orientation mismatch to avoid is replacing this by a right multiplication by A. The Miller vector is a column vector.

## Exact box proof

Positivity:

```
N^2(2N+1)(2N+3)
(48N^4+306N^3+715N^2+729N+275) >= 0
```

and every coefficient of R2 is positive, hence

```
R2 > 0.
```

For the upper bound:

```
R2 - 16 * numerator(u2)
```

has coefficient list

```
[1800,19200,78196,169691,226106,191752,99912,28752,3456]
```

so it is coefficient-positive and therefore

```
0 <= u2 <= 1/16.
```

Since

```
v2 = 0,
```

we immediately obtain

```
0 <= v2 <= 1/256.
```

The scalar nonvanishing lemma is simply:

```lean
lemma scalar_tau2_ne_zero (N : ℕ) (hN : 2 ≤ N) :
  scalarTau2 N ≠ 0 := by
  positivity
```

after factoring the scalar into positive factors.

## Reindexing m=N-2

The shift

```
m = N-2
```

is useful only after the formula has been established. It removes the terminal indexing clutter in the recurrence, but it does not reduce the positivity proof materially: R2 and R2-16*num already have positive coefficients in N.

For Lean, keep the N-formulas. A shifted m-form introduces extra rewriting obligations.
