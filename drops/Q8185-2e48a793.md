# 1. Reflection coordinates and the midpoint

Fix an odd prime \(p\).  Write
\[
\iota(U)=-1-U,\qquad x=2U+1,\qquad V=U(U+1).
\]
Then
\[
\iota(x)=-x,\qquad \iota(V)=V,\qquad x^2=4V+1.
\]
Over the integers one has the exact invariant/anti-invariant rings
\[
\boxed{\mathbf Z[U]^+=\mathbf Z[V],\qquad
       \mathbf Z[U]^-=x\mathbf Z[V].}
\]
For the first identity, subtract the integer leading coefficient times
\(V^d\) and induct on the degree.  For the second, an anti-invariant
\(P\) satisfies \(P(-1/2)=0\); the primitive polynomial \(2U+1\) divides
\(P\) in \(\mathbf Z[U]\) by Gauss's lemma, and the quotient is invariant.

Over \(\mathbf F_p\), division by \(2\) is allowed, so every polynomial
splits uniquely into its \(+\) and \(-\) parts.  If
\[
a=\left\lfloor\frac A2\right\rfloor,
\]
then
\[
\mathbf F_p[U]_{\le A}^{+}
 =\{F(V):\deg F\le a\},
\]
with dimension \(a+1\), while
\[
\mathbf F_p[U]_{\le A}^{-}
 =\{xH(V): 2\deg H+1\le A\},
\]
with dimension \(\lceil A/2\rceil\).

The unique fixed point of \(\iota\) is
\[
c=-\frac12\in\mathbf F_p,\qquad v_*=c(c+1)=-\frac14.
\]
If an anti-invariant datum \(d\) is defined at \(c\), then
\[
d(c)=-d(c),
\]
so, because \(p\) is odd,
\[
\boxed{d(c)=0.}
\]
For the Apéry shape this is also immediate from \(2c+1=0\).

Let the reflected zero set be
\[
Z_p=\{r_1,s_1,\ldots,r_t,s_t\}
       \sqcup (\{c\}\text{ if }\varepsilon=1),\qquad
s_i=\iota(r_i),
\]
where \(arepsilon\in\{0,1\}\).  Put
\[
z=|Z_p|=2t+\varepsilon,\qquad
v_i=r_i(r_i+1)=s_i(s_i+1).
\]
The \(v_i\), and \(v_*\) when present, are distinct: if
\(u(u+1)=v(v+1)\), then
\((u-v)(u+v+1)=0\), so \(u=v\) or \(u=\iota(v)\).

For a nonmidpoint orbit define the normalized jet
\[
e_i=\frac{d(r_i)}{2r_i+1}.
\]
Anti-invariance of \(d\) and of \(2U+1\) makes this independent of the
chosen member of the reflected pair:
\[
\frac{d(s_i)}{2s_i+1}=e_i.
\]
In the Apéry case \(e_i=E_{p,r_i}\).

# 2. Exact local value map and index

Let
\[
\mathcal P_A=\mathbf Z[U]_{\le A},\qquad
\overline{\mathcal P}_{A,p}=\mathbf F_p[U]_{\le A}.
\]
The value map is
\[
\operatorname{ev}_{p,A}:\overline{\mathcal P}_{A,p}
 \longrightarrow \mathbf F_p^{Z_p},\qquad
P\longmapsto(P(r))_{r\in Z_p}.
\]
If
\[
C_p(U)=\prod_{r\in Z_p}(U-r),
\]
then
\[
\ker(\operatorname{ev}_{p,A})
 =\{P:\ C_p\mid P,\ \deg P\le A\}.
\]
Hence the Vandermonde rank is exactly
\[
\boxed{\operatorname{rank}\operatorname{ev}_{p,A}
       =\min(A+1,z).}
\]
Therefore the local zero lattice
\[
L_{0,p}(A)=\{P\in\mathcal P_A:P(r)\equiv0\pmod p
                         \ \forall r\in Z_p\}
\]
has exact index
\[
\boxed{[\mathcal P_A:L_{0,p}(A)]
       =p^{\min(A+1,z)}.}
\]

For the global dyadic lattice
\[
L_0(A)=\bigcap_{X<p\le2X}L_{0,p}(A),
\]
the prime moduli are coprime, so coefficientwise CRT gives
\[
\boxed{[\mathcal P_A:L_0(A)]
 =\prod_{X<p\le2X}p^{\min(A+1,|Z_p|)}.}
\]
This is the exact value-lattice index; reflection does not change it in the
full polynomial space.

# 3. Full Hermite map: a jet prescription is an affine coset

The full value-derivative map is
\[
\mathcal H_{p,A}:\overline{\mathcal P}_{A,p}
 \longrightarrow (\mathbf F_p^2)^{Z_p},\qquad
P\longmapsto\bigl(P(r),P'(r)\bigr)_{r\in Z_p}.
\]
Its homogeneous kernel is exactly
\[
\{P:C_p(U)^2\mid P\},
\]
so confluent Vandermonde interpolation gives
\[
\boxed{\operatorname{rank}\mathcal H_{p,A}
 =\min(A+1,2z).}
\]
The corresponding homogeneous integer Hermite lattice has index
\[
\boxed{p^{\min(A+1,2z)}}.
\]

For a prescribed jet \(d\), however, the object is
\[
\mathcal J_{p,A}(d)=
\{P:P(r)=0,\ P'(r)=d(r)\quad(r\in Z_p)\}.
\]
If nonempty, this is an **affine coset** of the homogeneous Hermite kernel.
It is not a lattice.

This disposes of one possible misuse in the Claude argument.  If one first
interpolates the nonzero anti-invariant numbers \(d(r)\) as **values** of an
odd polynomial \(J\), then \(J\) lies in
\(\operatorname{ev}^{-1}(d)\), not in \(L_0\).  Unless all jets vanish,
that odd interpolant is not a vector of the zero lattice at all.  The relevant
object is a polynomial whose **values vanish and whose derivatives equal the
jets**.

# 4. Reflection-equivariant Hermite map, with midpoint

For an even polynomial \(P(U)=F(V)\),
\[
P'(U)=xF'(V).
\]
Consequently the entire reflected value-zero / anti-invariant-derivative
problem reduces to
\[
\Psi^+_{p,A}:\mathbf F_p[V]_{\le a}
 \longrightarrow
 \mathbf F_p^{\,t+\varepsilon}\times\mathbf F_p^{\,t},
\]
\[
F\longmapsto
\left(
 (F(v_i))_{1\le i\le t},
 (F(v_*)\text{ if }\varepsilon=1);
 (F'(v_i))_{1\le i\le t}
\right).
\]
The target for the Apéry jet is
\[
(0,\ldots,0; e_1,\ldots,e_t).
\]
There is **no derivative coordinate at the midpoint**: every even polynomial
has derivative \(0\) there, exactly as anti-invariance requires.

The homogeneous kernel is generated by
\[
K_Z(V)=
(V-v_*)^{\varepsilon}\prod_{i=1}^t(V-v_i)^2,
\]
whose degree is
\[
\varepsilon+2t=z.
\]
Hence
\[
\boxed{\operatorname{rank}\Psi^+_{p,A}=\min(a+1,z),}
\]
and the homogeneous even Hermite lattice has exact local index
\[
\boxed{p^{\min(a+1,z)}}.
\]

In particular, if \(a+1\ge z\), the map is surjective for **every**
anti-invariant jet, not just the Apéry jet.

There is also an explicit interpolant.  Put
\[
R_0(V)=(V-v_*)^{\varepsilon}\prod_{i=1}^t(V-v_i).
\]
For \(t\ge1\), choose \(K(V)\) of degree at most \(t-1\) satisfying
\[
K(v_i)=\frac{e_i}{R_0'(v_i)}.
\]
Then
\[
F(V)=R_0(V)K(V)
\]
has all required zero values and all required normalized derivatives, and
\[
\deg F\le z-1,\qquad \deg_U F(V)\le2z-2.
\]
If the zero set consists only of the midpoint, \(F=0\) suffices.

So the Apéry shape \(d=xE\) is not merely *compatible in parity* with an even
polynomial: ordinary Hermite interpolation produces such an even polynomial
at the natural reflected dimension.

For completeness, if \(P=xH(V)\) is odd, then
\[
P'(U)=2H(V)+(4V+1)H'(V),
\]
which is even.  At the midpoint \(P(c)=0\) automatically, while
\(P'(c)=2H(v_*)\).  Thus the full reflection-equivariant Hermite problem
splits exactly into even-value/odd-derivative and odd-value/even-derivative
blocks.  The requested value-zero/anti-derivative datum lives entirely in the
first block; the odd block can simply be zero.

# 5. Exact aligned map: the claimed parity gain has the wrong sign

Write
\[
G_m(U)=V-M,\qquad M=m(m+1).
\]
Let
\[
\alpha=M\pmod p.
\]
For an even exactly aligned polynomial
\[
P(U)=G_m(U)Q(U)=(V-M)R(V),
\]
the quotient is automatically even, so \(Q(U)=R(V)\).
If \(\deg P\le A\), then
\[
\deg R\le a-1,
\]
so the quotient coefficient space has dimension \(a\).

At a nonmidpoint reflected orbit \(v_i\),
\[
\frac{P'(r_i)}{2r_i+1}
=R(v_i)+(v_i-\alpha)R'(v_i).
\]
There are two cases.

## 5.1 Nonaligned local orbit: \(\alpha\ne v_i\)

The value condition gives
\[
R(v_i)=0,
\]
and the derivative condition then gives
\[
R'(v_i)=\frac{e_i}{v_i-\alpha}.
\]
Thus this orbit imposes two independent Hermite conditions on \(R\).

At a midpoint root with \(\alpha\ne v_*\), only
\[
R(v_*)=0
\]
is imposed; the derivative is automatically zero.

## 5.2 Aligned nonmidpoint orbit: \(\alpha=v_j\)

At that orbit the value is automatic, and the derivative condition collapses
to the single condition
\[
\boxed{R(v_j)=e_j.}
\]
There is **no** condition on \(R'(v_j)\).

Every other nonmidpoint orbit still contributes two conditions, and a
midpoint root (if present) contributes one.  Total number of conditions:
\[
1+2(t-1)+\varepsilon=z-1.
\]

## 5.3 Aligned midpoint: \(\alpha=v_*\)

Modulo \(p\),
\[
V-v_*=(U-c)^2,
\]
so \(G_m\) has a double root at the midpoint.  Both
\[
P(c)=0,\qquad P'(c)=0=d(c)
\]
are automatic.  The remaining \(t\) nonmidpoint orbits contribute two
conditions each, for a total
\[
2t=z-1.
\]

## 5.4 Unified rank and index

Define
\[
\delta_p(m)=
\begin{cases}
1,&m\bmod p\in Z_p,\\
0,&m\bmod p\notin Z_p.
\end{cases}
\]
Equivalently, \(\delta_p(m)=1\) iff \(\alpha\) equals one of the folded
\(V\)-nodes of \(Z_p\).

The aligned even quotient system has exactly
\[
\boxed{c_p(m)=z-\delta_p(m)}
\]
independent local conditions.  Its homogeneous kernel is the obvious mixed
Hermite divisor of degree \(c_p(m)\), hence
\[
\boxed{\operatorname{rank}=\min(a,c_p(m)),\qquad
       \text{local index}=p^{\min(a,c_p(m))}.}
\]
At a hit, the aligned quotient space is therefore a factor \(p\) *denser*
than the same quotient space at a nonhit once the ranks are saturated.
There is no extra parity codimension.

Notice also that the raw solution counts agree with the unquotiented even
Hermite count at a saturated hit:
\[
p^{(a+1)-z}=p^{a-(z-1)}.
\]
The exact factor removes one coefficient dimension and the hit simultaneously
removes one local Hermite condition.

# 6. The same conclusion without assuming the quotient is even

The previous section already kills the parity argument, but the full aligned
map is also elementary.

Let \(P=G_mQ\) with arbitrary \(Q\in\mathbf F_p[U]\),
\(\deg Q\le A-2\), so the quotient coefficient space has dimension \(A-1\).

If \(m\bmod p\notin Z_p\), then \(G_m\) is a unit in every local length-two
Artin ring at the roots of \(Z_p\).  Multiplication by \(G_m\) is therefore
an automorphism on each value-derivative fiber, and the quotient receives
\(2z\) independent conditions.

If \(m\bmod p\in Z_p\):

* at a nonmidpoint hit pair \(r,s=\iota(r)\), the two value conditions are
  automatic and the two derivative conditions become the two quotient-value
  conditions
  \[
  Q(r)=\frac{d(r)}{G_m'(r)},\qquad
  Q(s)=\frac{d(s)}{G_m'(s)};
  \]
  since both numerator and denominator change sign, the two target values
  agree, but they are evaluations at two distinct points;
* at a midpoint hit, \(G_m=(U-c)^2\) modulo \(p\), so both the value and
  derivative conditions at \(c\) are automatic.

Thus in either hit case the mixed Hermite divisor on \(Q\) has degree
\(2z-2\).  Consequently
\[
\boxed{
\operatorname{rank}(Q\mapsto\text{jet constraints on }G_mQ)
=
\begin{cases}
\min(A-1,2z),&m\bmod p\notin Z_p,\\
\min(A-1,2z-2),&m\bmod p\in Z_p.
\end{cases}}
\]
The corresponding \(p\)-indices are \(p\) to these ranks.

This makes the local obstruction especially transparent:

> **At every hit prime, every value-zero Apéry jet lift is already divisible
> by \(G_m\) modulo \(p\).**

For a nonmidpoint hit this follows because both roots of \(G_m\) belong to
\(Z_p\).  At a midpoint hit, the zero value and the forced zero derivative
make the midpoint a double root.  Therefore no argument using only one
characteristic can distinguish exact integer divisibility by \(G_m\) from the
jet conditions.

# 7. CRT surjectivity: actual Apéry jets admit exact aligned lifts

The local count upgrades to a global existence theorem.

Let all odd primes in the dyadic window be included, and suppose only that the
jet \(d_{p,r}\) is anti-invariant for every \(p\).  Put
\[
z_p=|Z_p|,\qquad
c_p(m)=z_p-\delta_p(m).
\]
If
\[
\boxed{\left\lfloor\frac A2\right\rfloor
       \ge \max_{X<p\le2X}c_p(m),}
\]
then there exists an integer polynomial \(R(V)\) with
\(\deg R\le\lfloor A/2\rfloor-1\) such that
\[
\boxed{P(U)=G_m(U)R(U(U+1))}
\]
obeys, simultaneously for every window prime and every root,
\[
P(r)\equiv0\pmod p,\qquad
P'(r)\equiv d_{p,r}\pmod p.
\]

**Proof.**  For each prime separately, Section 5 gives a surjective affine
Hermite system on the coefficients of \(R\), because the coefficient
dimension is at least \(c_p(m)\).  Choose one local solution \(R_p\) and pad
its coefficient vector to the common length.  The moduli \(p\) are pairwise
coprime, so coefficientwise CRT produces one integer vector reducing to
\(R_p\) for every \(p\).  The resulting \(P=G_mR(V)\) has exact divisibility
by \(G_m\) in \(\mathbf Z[U]\), not merely modulo the primes.  QED.

This theorem applies in particular to the actual Apéry data
\(d_{p,r}=D_r=(2r+1)E_{p,r}\).

It does **not** say the CRT lift is small; its coefficients can be as large as
the product of the window primes.  That distinction is exactly where a
legitimate future argument would have to enter.  What it proves is that the
jets themselves do not make the aligned affine fiber empty, and parity cannot
be used to deduce an escape.

# 8. Exact reflected countermodel: the shortest jet lift can itself be \(G_m\)

The previous theorem is an existence no-go.  The following construction also
kills any claim that reflection plus the shape \(d=(2r+1)E_r\) forces the
**shortest** lift to escape alignment.

Take \(X\) sufficiently large and choose a physical integer
\[
X\le m<X^2.
\]
Choose five distinct primes
\[
p_1,\ldots,p_5\in(X,2X]
\]
none dividing \(2m+1\).  Such a choice is available for large \(X\): there are
many dyadic primes, while at most two of them can divide \(2m+1<2X^2+1\),
because the product of three window primes exceeds \(X^3\).

For \(p=p_i\), define
\[
Z_p=\{m\bmod p,\,-1-m\bmod p\},
\]
and for all other window primes take \(Z_p=\varnothing\).  Set
\[
d_{p,r}=2r+1.
\]
Then \(Z_p\) is reflection-stable, \(d\) is anti-invariant, and it even has
the Apéry formal shape
\[
d_{p,r}=(2r+1)E_{p,r}
\]
with the symmetric datum \(E_{p,r}\equiv1\).

Now
\[
G_m(U)=U^2+U-m(m+1)
\]
satisfies all value and derivative conditions exactly:
\[
G_m(r)\equiv0,\qquad G_m'(r)=2r+1=d_{p,r}.
\]

Let \(P\in\mathbf Z[U]_{\le2}\) be any other polynomial satisfying the same
jets.  For each \(p_i\), the difference
\[
H=P-G_m
\]
has a double zero at each of two distinct points modulo \(p_i\).  A polynomial
of degree at most \(2\) cannot have four units of root multiplicity unless it
is zero.  Hence
\[
P\equiv G_m\pmod{p_i}
\]
coefficientwise for every \(i\).

Putting
\[
Q=p_1p_2p_3p_4p_5,
\]
the entire degree-2 jet fiber is exactly
\[
\boxed{G_m+Q\,\mathbf Z[U]_{\le2}.}
\]
Since
\[
Q>X^5,\qquad M=m(m+1)<X^4+X^2,
\]
we have \(Q>2M\) for large \(X\).  The coefficient vector of \(G_m\) is
\[
(-M,1,1),
\]
which lies strictly inside the centered coefficient cube
\((-Q/2,Q/2)^3\).  Therefore \(G_m\) is the **unique coefficientwise
\(\ell^\infty\)-shortest representative** of this affine jet coset; every
nonzero CRT translate changes some coefficient by at least \(Q\) and is much
larger.

This is an exact algebraic countermodel, not numerical evidence.
It is deliberately not claimed to be an actual Apéry zero set.  Its scope is
precise:

> reflection invariance, anti-invariant jets, and even the formal factorization
> \(d=(2r+1)E\) with symmetric \(E\) do not imply short-vector escape from
> \(G_m\mathbf Z[U]\).

Any theorem for the actual Apéry zero sets must use additional arithmetic.

# 9. Audit of the truncated polynomial \(S_X\)

Define
\[
A_k(U)=\binom Uk\binom{U+k}{k},\qquad
S_X(U)=\sum_{0\le k<X}A_k(U)^2.
\]
There are exact polynomial identities
\[
\binom{-1-U}{k}=(-1)^k\binom{U+k}{k},\qquad
\binom{k-1-U}{k}=(-1)^k\binom Uk.
\]
Hence
\[
A_k(-1-U)=A_k(U),\qquad
\boxed{S_X(-1-U)=S_X(U).}
\]
Thus
\[
S_X(U)=F_X(V)
\]
for a unique \(F_X\in\mathbf Q[V]\), with
\[
\deg_U S_X=4X-4,\qquad \deg_VF_X=2X-2.
\]
Differentiation gives the exact anti-invariance
\[
S_X'(U)=xF_X'(V),\qquad
S_X'(-1-U)=-S_X'(U).
\]

## 9.1 Why the node identity is valid only at nodes below \(X\)

For an integer \(0\le h<X\), every term with \(k>h\) has
\(inom Uk=0\) at \(U=h\).  Because the summand is squared, that term has a
double zero there, so its first derivative also vanishes.  Therefore
truncation does not affect either the value or first derivative at such a
node:
\[
S_X(h)=b_h,\qquad
\boxed{S_X'(h)=2D_h}
\]
with the convention in the question.

For a physical integer \(m\ge X\), the second equality is **not** an integer
identity.  This is exactly the guard in the question and it must not be
silently extended beyond the interpolation nodes.

## 9.2 What remains true at a physical \(m\)

Let \(p\in(X,2X]\), and let \(r=m\bmod p\).  The reflection orbit of \(r\)
has a representative
\[
0\le h\le\frac{p-1}{2}<X.
\]
All coefficient denominators of \(S_X\) are \(p\)-units because \(k<X<p\).
Consequently, if \(r\in Z_p\), reflection and the node identities imply
\[
S_X(r)\equiv0\pmod p,\qquad
S_X'(r)\equiv2d_{p,r}\pmod p.
\]
Since polynomial evaluation depends only on the residue class,
\[
\boxed{S_X(m)\equiv0\pmod p,\qquad
       S_X'(m)\equiv2d_{p,r}\pmod p.}
\]
This is only a **residue congruence**.  There is no global integer equality
\(S_X'(m)=2D_m\) for \(m\ge X\).

## 9.3 \(S_X\) does give a high-degree nonaligned actual-jet lift

Let
\[
C_X=((X-1)!)^4.
\]
Then \(C_XS_X\in\mathbf Z[U]\).  It is invariant, so by Section 1 there is
an \(H_X\in\mathbf Z[V]\) with
\[
H_X(V)=C_XS_X(U).
\]
No window prime divides \(2C_X\).  Let
\[
\Pi_X=\prod_{X<p\le2X}p
\]
and choose an integer \(c_X\) with
\[
2c_XC_X\equiv1\pmod{\Pi_X}.
\]
Then
\[
P_X(U)=c_XC_XS_X(U)\in\mathbf Z[U]
\]
satisfies for every actual Apéry root in every window characteristic
\[
P_X(r)\equiv0,\qquad P_X'(r)\equiv d_{p,r}\pmod p.
\]
So \(P_X\) is an explicit global member of the actual Apéry jet affine fiber.

For every physical \(m\ge0\),
\[
S_X(m)>0
\]
because the \(k=0\) summand is \(1\) and all summands are squares.
Therefore \(G_m\nmid S_X\) in \(\mathbf Q[U]\), and hence
\[
\boxed{G_m\nmid P_X\quad\text{in }\mathbf Z[U].}
\]
Thus, once the degree cap allows \(4X-4\), a nonaligned actual-jet lift exists
explicitly.

This does **not** rescue the Claude argument.  It proves neither that a
geometry-of-numbers-short lift has this form nor that the shortest lift lies
outside the aligned sublattice.  Sections 7 and 8 show the opposite structural
fact: aligned lifts also exist, and reflection alone can make an aligned lift
the unique shortest representative.

# 10. The exact corrected derivative carrier

There is one legitimate residue of the proposed idea, but it needs a new
cross-characteristic premise.

Continue with
\[
C_XS_X(U)=H_X(V),\qquad M=m(m+1).
\]
Suppose an **even exactly aligned** candidate has the form
\[
P(U)=(V-M)R(V)
\]
and realizes the actual Apéry derivative jet.

Let \(p\in(X,2X]\) be a nonmidpoint hit by \(m\).  Then at the hit node
\(V\equiv M\pmod p\), Section 5 gives
\[
R(M)\equiv E_{p,r}\pmod p.
\]
On the other hand
\[
S_X'=xF_X'(V)\equiv2xE_{p,r}\pmod p,
\]
so cancellation of the nonzero \(x=2r+1\) gives
\[
E_{p,r}\equiv\frac12F_X'(M)\pmod p.
\]
Since \(H_X'=C_XF_X'\), every such hit prime divides the **single integer**
\[
\boxed{
\Delta_{X,m,R}=2C_XR(M)-H_X'(M).}
\]
That is an exact cross-characteristic statement.

Midpoint hit primes satisfy \(p\mid2m+1\), so the normalization by \(x\)
loses them.  For \(m<X^2\), there are at most two such window primes for
large \(X\), since three distinct window primes have product \(>X^3\) whereas
\(2m+1<2X^2+1\).  They are therefore an \(O(1)\) exceptional set in this
particular carrier.

The crucial point is what **does not** follow:
\[
\boxed{\text{reflection and jet oddness do not imply }
       \Delta_{X,m,R}\ne0.}
\]
The identity \(\Delta=0\) is fully compatible with an aligned polynomial.
It is only one equality at the physical value \(M\); even a degree mismatch
between \(R\) and \(F_X'\) would not rule out equality at that one integer.
Local Hermite surjectivity likewise supplies no nonvanishing.

Therefore the statement

> “\(D\) is odd and \(G_m\) is even, hence the derivative produces a nonzero
> shell integer”

is not a theorem.  The word **nonzero** is exactly where genuinely new
mixed-characteristic arithmetic is required.

Also, the canonical \(S_X\) has degree \(O(X)\).  Although one can bound its
individual coefficient/evaluation logarithmic height by \(O(X\log X)\), the
fifth-moment problem needs an **aggregate** height after all shell objects are
charged.  A small value for one carrier does not supply that aggregate bound.

## Hypothesis CJET\(_\theta\) (mixed-characteristic jet mismatch)

Let \(\mathscr S_X\) be the finite family of shell-selected aligned candidates
\((m,R)\) used by the intended corank/tail argument.  For each candidate set

\Delta_s=2C_XR(m(m+1))-H_X'(m(m+1)).

3. **bounded charge multiplicity:** a fixed pair \((s,p)\) receives at most
   \(X^{o(1)}\) actual incidences;
4. **aggregate logarithmic height:**
   \[
   \boxed{
   \sum_{s\in\mathscr S_X}\log(2+|\Delta_s|)
   \le X^{\theta+o(1)}.}

The midpoint incidences may be removed separately at \(X^{o(1)}\) cost (in

\#\{\text{charged incidences}\}

# 12. Height exponent needed for the fifth moment

There is a notation issue that matters here.

The current repository file `problems/3.2/atom_tail_section.tex` defines
\[
n_T(X)=\#\{m<X^2:K_X(m)\ge T\}.
\]
For that \(m\)-tail it records the second-moment Chebyshev bound
\[
n_T(X)\le \frac{5X^2\lambda_X^2}{(T)_2},
\]
and the \(k\)-th-moment target has the form
\[
X^{2+o(1)}\lambda_X^k/T^k.
\]
So the displayed bound in the question
\[
\frac{X^{8/5}}{T\log X}
\]
is **not** the current repository's \(m\)-tail bound under that notation.

It is instead exactly the Markov tail naturally attached to the current
average zero-count estimate
\[
\sum_{p\le x}Z(p)\ll\frac{x^{8/5}}{\log x},
\]
which `atom_tail_section.tex` derives from the First Lemma/corank argument.
If
\[
\nu_T(X)=\#\{p\in(X,2X]:Z(p)\ge T\},
\]
then
\[
\nu_T(X)\le\frac1T\sum_{X<p\le2X}Z(p)
\ll\frac{X^{8/5}}{T\log X}.
\]
If the Claude report used the symbol \(n_T\) for this root/shell tail, then
\(
u_T\) here is that quantity; it should not be conflated with the current
`atom_tail_section.tex` \(m\)-tail.

Now suppose CJET\(_\theta\) (or any other correct cross-characteristic
certificate) improves the logarithmic-height exponent to
\[
\sum Z(p)\ll\frac{X^{\theta+o(1)}}{\log X}.
\]
Write the average-zero exponent in the repository's corank notation as
\[
c=\theta-1.
\]
The current moment tradeoff is
\[
c+\frac2k<1.
\]
For \(k=5\), this becomes
\[
\theta-1+\frac25<1,
\]
that is
\[
\boxed{\theta<\frac85.}
\]
Therefore the **minimal robust power-exponent requirement** is any fixed
saving
\[
\boxed{\theta=\frac85-\delta\qquad(\delta>0).}
\]
Indeed then
\[
c+\frac25
=\left(\frac35-\delta\right)+\frac25
=1-\delta<1.
\]

The cleaner target already singled out by the repository's corank ladder is
the square-root average
\[
c=\frac12,
\]
which corresponds to
\[
\boxed{\theta=\frac32.}
\]
That is a saving of \(1/10\) in the power of \(X\) relative to \(8/5\).
It is stronger than the strictly minimal fixed power saving, but it gives a
comfortable fifth-moment margin and matches the conditional \(c=1/2\) row in
`atom_tail_section.tex`.

A mere relabeling of the \(8/5\) estimate, or a parity statement with no
nonzero cross-characteristic carrier, gives no such improvement.  A
borderline logarithmic saving at exponent \(8/5\) would require a separate
borderline summation argument; the currently banked corank criterion is the
strict power inequality above.
