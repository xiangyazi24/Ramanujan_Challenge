# 8. Bounded height shifts/intersections retain the linear entropy

A natural attempt is to keep slope 4 but intersect the selectors for nearby heights

```text
H, H+1, ..., H+T,
```

hoping that the gcd becomes small while the far target primes remain selected.

There is an exact obstruction.

Let

```text
U(X,R)=binom(-X,R)
      =(-1)^R binom(X+R-1,R).                       (8.1)
```

If a height shift changes

```text
X -> X+a,
R -> R+b,
```

then `|a|+|b|=O(T+s)`. The ratio

```text
U(X+a,R+b)/U(X,R)                                   (8.2)
```

is a rational product of only `O(T+s)` linear factors in `X,R`. After cancellation, write it in lowest terms as

```text
P/Q,
gcd(P,Q)=1.                                         (8.3)
```

Every factor has size `O(m)`, hence

```text
log|P|+log|Q| = O((T+s)log m).                       (8.4)
```

Since both binomial values are integers and `P/Q` is reduced, there is an integer `g` with

```text
U(X,R)=gQ,
U(X+a,R+b)=gP.
```

Therefore exactly

```text
gcd(U(X,R),U(X+a,R+b))=|g|=|U(X,R)|/|Q|.            (8.5)
```

Combining `(7.4)` and `(8.4)`, for `T=O(H)` and `H log m=o(m)`,

```text
log gcd(U_H,U_(H+T))
 = (4/(3s))*h(1/4)*m + o(m).                        (8.6)
```

So one bounded height shift does not remove the exponential core.

The same argument handles many shifts. If `U_t/U_0=P_t/Q_t` in lowest terms, then

```text
gcd_t U_t
```

can lose from `U_0` at most the lcm of the denominators `Q_t`, hence at most their product. Thus

```text
log gcd_(0<=t<=T) U_(H+t)
```

Slope 4 is therefore not an arbitrary choice; it is essentially the first admissible fixed slope that splits `q mod 12` in the useful way.

# 11. Exact recurrence/reflection obstruction

The remaining far target has, after prefix removal,

```text
p|b_j,
f=min(j,p-1-j)>H.
```

Reflection gives

```text

```

Put

```text

h=t-f=p-1-2f.                                      (11.1)
```

Then `h` is even. The Apéry gap continuant satisfies

```text
N_h(-X-h-1)=(-1)^(h-1)N_h(X).                       (11.2)
```

Therefore for even `h`,

```text
N_h(X)=(2X+h+1)Q_h(X),
Q_h(X) in Z[X].                                      (11.3)
```

At `X=f`,

```text
2f+h+1=p,
```

so

```text
N_h(f)=p Q_h(f).                                    (11.4)
```

The factor `p` is **universal**: it occurs for every geometric reflected pair, target or not. Keeping it gives no nuisance exclusion.

Deflating it loses actual targets. The exact first-lift formula at a target is

```text
N_h(f)/p
 == ((t!/f!)^3) c_f G_f                 (mod p),    (11.5)
```

where `c_f` is the canonical companion and `G_f` the genuine Gessel first jet. At a target in the noncentral range, both the factorial ratio and `c_f` are p-units. There is no theorem forcing `p|G_f`.

The canonical fixture is exact:

```text

f=2,
t=70,
h=68,

N_68(2)/73 == 31 (mod 73).                          (11.6)
```

Thus the deflated centered continuant is a 73-unit at an actual target.

So the obvious recurrence/reflection carrier has the sharp dichotomy

```text
keep center factor p:       target survives, but every geometric candidate survives;
deflate center factor p:    nuisance improves, but actual targets can disappear.
```

This rules out the natural centered-continuant repair.
