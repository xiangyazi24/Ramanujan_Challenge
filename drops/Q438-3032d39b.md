# Q438 — Equidistribution of the reflected Apéry-zero location

## Executive verdict

Taking the computation in the question as given, the new statistic is genuinely interesting and should be added to the P3.2 paper. It identifies a much sharper random model than the zero-count statistic alone:

> Conditional on `z_p=2`, the unique reflected zero pair appears to be uniformly located in the half-row.

However, the three answers are:

1. **No existing Sato–Tate, Dwork, or Katz theorem appears to prove this equidistribution.** Those theories explain Frobenius traces, unit roots, Hasse invariants, and character-aspect complex equidistribution. The variable `r_p` is instead the location of an exact mod-`p` zero selected from a row whose length and residue characteristic both grow with `p`. Proving its distribution requires a new local-limit theorem for Hasse zeros, not merely a monodromy theorem.
2. **Marginal equidistribution of `alpha_p` is not sufficient for P3.2.** It gives the right unweighted fixed-frequency heuristic, but the actual off-diagonal form uses growing Fourier modes and highly nonuniform Farey-kernel weights depending on `p,q,h,k`. What is sufficient is a quantitative, weighted, hybrid equidistribution theorem that is essentially the pair-dispersion hypothesis already isolated in the project.
3. **`alpha_p` is not a Frobenius eigenangle.** It is best interpreted as a normalized **Kummer-character label** at which the Mellin transform of the Apéry K3 trace function loses its unit root. The central label is the special quadratic character related to the level-8 weight-4 modular form; a general `r_p` is a nonordinary twist in a whole character family. The generic rank-four hypergeometric/`Sp(4)` object and the rank-three K3 transcendental object should not be conflated.

The discovery is therefore not an immediate proof route, but it is a strong and conceptually clean new conjecture. The right next target is not simply “prove `alpha_p` is uniform,” but a hierarchy:

- fixed-frequency Weyl equidistribution;
- quantitative equidistribution uniform in frequencies growing with `p`;
- denominator-sensitive bilinear equidistribution against the Farey/Dirichlet kernel;
- the full reflected-pair point-process statement for primes with `z_p>=4`.

Only the third level directly closes the second-moment gap in P3.2.

## 1. Exact Fourier formula and two corrections

Let

```text
Z_p = {r_p, p-1-r_p},
0 <= r_p < (p-1)/2,
alpha_p = (2r_p+1)/p.
```

With `e_p(x)=exp(2*pi*i*x/p)`, one has exactly

```text
F_p(h)
 = e_p(h r_p) + e_p(h(p-1-r_p))
 = 2 exp(-pi*i*h/p) cos(pi*h*alpha_p)
 = 2 e(-h/(2p)) cos(pi*h*alpha_p).
```

Thus

```text
|F_p(h)| = 2 |cos(pi*h*alpha_p)|.
```

This is a useful one-parameter description of the `z_p=2` primes. The phase `e(-h/(2p))`, however, must be retained in a signed bilinear form. It disappears from `|F_p(h)|`, but not from cross-prime covariance.

### 1.1 The cosine orthogonality constant

For positive integers `h,k`,

```text
integral_0^1 cos(pi*h*x) cos(pi*k*x) dx
  = 0      if h != k,
  = 1/2    if h = k.
```

So for the same uniformly distributed parameter the average is `delta_{h,k}/2`, not `delta_{h,k}/4`. After multiplying by the two factors of `2` in `F_p` and `F_q`, the amplitude contribution is `2 delta_{h,k}` in a same-parameter average.

For **independent distinct** uniform parameters `alpha_p,alpha_q`, the situation is different:

```text
E[cos(pi*h*alpha_p) cos(pi*k*alpha_q)]
 = E[cos(pi*h*alpha_p)] E[cos(pi*k*alpha_q)]
 = 0
```

for every `h,k>=1`, including `h=k`. This is the heuristic relevant to distinct primes.

### 1.2 What the KS statistic establishes

For `1534` observations, the usual 5% one-sample Kolmogorov–Smirnov threshold is approximately

```text
1.36/sqrt(1534) = 0.0347.
```

Thus `D_KS=0.018` is excellent agreement with uniformity. Under the idealized iid continuous null, it corresponds roughly to a non-small p-value (about `0.7`), so there is no detectable deviation.

But “perfectly equidistributed” is too strong. The accurate paper wording is:

> The conditional sample is statistically indistinguishable from the uniform distribution at the tested range; its KS discrepancy is 0.018.

There are three reasons not to treat the KS number as a proof-level probability:

- the sample is deterministic, not iid;
- it is selected by the arithmetic event `z_p=2`;
- several related statistics and ranges may have been inspected before this one was selected.

The result is nonetheless striking and worth reporting.

### 1.3 The covariance ratio is not “five times better than random” in significance

Suppose the sampled pair covariances are `C_1,...,C_m`, and compare the signed and absolute sums. Under an independent random-sign null, the standard deviation of

```text
(sum_i eps_i |C_i|)/(sum_i |C_i|)
```

is

```text
sqrt(sum_i C_i^2) / sum_i |C_i|
  = 1/sqrt(m_eff),

m_eff := (sum_i |C_i|)^2 / sum_i C_i^2.
```

Only when all magnitudes are equal is this `1/sqrt(m)`. If `m_eff=500`, the random-sign standard deviation is `0.0447`; the observed ratio `0.009` is only about `0.20` standard deviations from zero. A value this close to zero is not rare under a centered normal approximation.

Therefore the covariance experiment supports cancellation, but it does **not** yet show cancellation stronger than random. The correct comparison is a permutation or sign-flip distribution using the observed magnitudes, preferably for all pairs in complete dyadic blocks. Report:

```text
R = |sum C_pq| / sum |C_pq|,
m_eff = (sum |C_pq|)^2 / sum C_pq^2,
Z = R sqrt(m_eff),
and the permutation p-value.
```

The important empirical fact is that the signed aggregate is tiny relative to the absolute mass, exactly as the P3.2 dispersion heuristic predicts.

## 2. Can known results prove the equidistribution of `alpha_p`?

## 2.1 A precise theorem would already be new

Write

```text
P_2(X) = {p <= X prime : z_p=2},
pi_2(X) = |P_2(X)|.
```

The basic conditional equidistribution statement is

```text
(1/pi_2(X)) sum_{p in P_2(X)} phi(alpha_p)
  -> integral_0^1 phi(x) dx
```

for every continuous `phi`, together with `pi_2(X)->infinity`.

By Weyl's criterion, it is equivalent to proving, for every fixed nonzero integer `m`,

```text
A_m(X)
 := sum_{p in P_2(X)} exp(2*pi*i*m*alpha_p)
 = o(pi_2(X)).
```

I found no published theorem that gives this statement. Even proving that `P_2(X)` has the predicted positive density is beyond the currently cited results. The observed proportion

```text
1534/5133 = 0.2989...
```

is close to the reflected-Poisson prediction

```text
P(Poisson(1/2)=1) = (1/2)e^{-1/2} = 0.3033...,
```

but this density itself is conjectural.

## 2.2 Why Sato–Tate for the level-8 form does not imply it

The known modular-form congruence singles out the central coefficient

```text
r = (p-1)/2.
```

In the normalization used in the current manuscript, the condition

```text
b_{(p-1)/2} = 0 mod p
```

is related to nonordinarity of the weight-4 level-8 newform

```text
f_8(z) = eta(2z)^4 eta(4z)^4.
```

Sato–Tate controls the distribution of the normalized real Frobenius traces

```text
a_p(f_8) / p^{3/2}.
```

It does not control which of the `p` coefficient indices `r` first satisfies `b_r=0 mod p`. In particular:

- `a_p(f_8)` is one scalar attached to `p`;
- `r_p` is selected from the whole row `(b_0,...,b_{p-1}) mod p`;
- divisibility by `p` is a lattice/local-limit event invisible to weak convergence of normalized real traces.

Even if the Sato–Tate measure has a smooth density, it does not by itself estimate the probability that an integer trace lies in the sparse set of multiples of `p`. This is the standard distinction between an archimedean distribution theorem and a mod-`p` local-limit theorem.

Thus Sato–Tate may explain why no macroscopic deterministic bias is expected, but it does not prove the location law for `r_p`.

Relevant sources are Ahlgren–Ono's hypergeometric and Apéry congruences and the general Sato–Tate theorem for non-CM modular forms:

- S. Ahlgren and K. Ono, [A Gaussian hypergeometric series evaluation and Apéry number congruences](https://doi.org/10.1515/crll.2000.004), J. Reine Angew. Math. 518 (2000), 187–212.
- T. Barnet-Lamb, T. Gee and D. Geraghty, [The Sato–Tate conjecture for Hilbert modular forms](https://arxiv.org/abs/0912.1054).

## 2.3 Why Dwork crystals do not presently imply it

The Dwork-crystal framework controls:

- Cartier operators and Hasse–Witt matrices;
- unit-root formulas;
- congruences between truncated periods;
- Frobenius lifts and supercongruences.

These are exactly the correct structures behind the Apéry digit laws. They explain why `b_r mod p` is a Hasse-invariant-type quantity and why the row has strong Frobenius symmetry.

They do not currently provide a theorem saying that the **indices** at which a Hasse invariant vanishes are uniformly distributed after normalization by `p`. The difficulty is that the event

```text
b_r = 0 mod p
```

is caused by cancellation among equal-slope `p`-adic units. The repository's Gross–Koblitz/Morita analysis makes this explicit: the Newton polygon does not isolate a unique lowest term; the zero event is precisely the residual cancellation left after all slope information has been used.

So a Dwork proof would require a genuinely new ingredient, for example a `p`-adic local-limit theorem for the unit-root/Hasse-invariant values as the character exponent `r` varies.

The relevant general framework is:

- F. Beukers and M. Vlasenko, [Dwork Crystals I](https://doi.org/10.1093/imrn/rnaa119).
- F. Beukers and M. Vlasenko, [Dwork Crystals II](https://doi.org/10.1093/imrn/rnaa120).
- F. Beukers and M. Vlasenko, [Dwork Crystals III](https://doi.org/10.1093/imrn/rnad101).

## 2.4 Why Katz monodromy does not presently imply it

Katz's finite-field Mellin-transform theory is the closest conceptual framework. It studies, for an algebro-geometric trace function `t_p(a)`, the character sums

```text
M_p(chi) = sum_{a in F_p^*} t_p(a) chi(a)
```

and proves Sato–Tate-type equidistribution of normalized Frobenius conjugacy classes under suitable geometric monodromy hypotheses.

The current P3.2 repository has exactly this kind of identity: for the Apéry/K3 trace function `theta_p(a)`, the Mellin coefficient with character exponent `r` satisfies schematically

```text
M_p(r) = sum_{a in F_p^*} theta_p(a) omega_p(a)^r
       = -b_r mod p.
```

This gives a beautiful interpretation of `r_p`: it is a character label at which a K3 Mellin transform is divisible by `p`.

But Katz's theorem controls the distribution of the **normalized complex Frobenius conjugacy classes** as characters vary. The condition

```text
M_p(r) = 0 mod p
```

is a microscopic `p`-adic condition. It is not a continuous class function on the compact Sato–Tate group. Approximating it would require test functions whose complexity grows with `p`, destroying the fixed-conductor error terms that make the equidistribution theorem effective.

There are four additional obstacles:

1. The residue characteristic changes with `p`.
2. The number of character labels also grows with `p`.
3. We condition on there being exactly one inverse pair of zeros.
4. We select the smaller member of that pair, a nonlinear order statistic.

Katz's theorem is therefore a strong explanation for the random-matrix heuristic, not a proof of the exact zero-location law.

See N. Katz, [Convolution and Equidistribution: Sato–Tate Theorems for Finite-Field Mellin Transforms](https://doi.org/10.23943/princeton/9780691153308.001.0001), Annals of Mathematics Studies 180 (2012).

## 2.5 Fixed-gap Chebotarev does not reach the moving normalized gap

The reflected pair has gap

```text
h_p = p-1-2r_p = p(1-alpha_p).
```

Thus equidistribution of `alpha_p` is equivalent to uniform distribution of the normalized reflected gap `h_p/p`.

For a **fixed** gap `h`, the repository's gap polynomial `N_h(x)` is a fixed polynomial over `Q`, so Chebotarev can study its roots modulo varying primes. But fixed `h` corresponds to

```text
alpha_p = 1 - h/p -> 1,
```

not to an interior limiting distribution. Uniform `alpha_p` requires `h` to grow linearly with `p`. Then the degree and height of `N_h` grow with `p`, and there is no fixed number field or bounded-conductor sheaf to which ordinary Chebotarev applies.

Moreover, for the reflected pair the point is the structural center

```text
r_p = (p-1-h_p)/2 = -(h_p+1)/2 mod p.
```

The central root of the gap certificate is forced by the palindrome; it does not by itself say that the distinguished Apéry solution vanishes there. This is exactly the distinction between a projective return certificate and an actual coefficient zero.

### Verdict on Question 1

**The observed equidistribution is not a known consequence of Sato–Tate, Dwork crystals, or Katz monodromy.** A proof would be a genuinely new theorem about the distribution of nonordinary character labels/Hasse zeros in a growing Mellin family.

The weakest plausible first theorem is fixed-frequency Weyl cancellation:

```text
A_m(X) = o(pi_2(X))                 for every fixed m != 0.
```

A version useful for P3.2 must be much stronger, with `m` growing with the prime scale and with arithmetic weights depending on the denominators.

## 3. Would equidistribution of `alpha_p` suffice for P3.2?

## 3.1 Unweighted pair independence does not need a separate hypothesis

There is a useful deterministic point. Suppose a finite empirical measure

```text
mu_X = (1/M_X) sum_{p in P_2(X)} delta_{alpha_p}
```

converges weakly to Lebesgue measure. Then the uniformly weighted empirical measure on **all distinct ordered prime pairs** automatically converges to the product measure. Indeed, for bounded functions `f,g`,

```text
1/(M(M-1)) sum_{p != q} f(alpha_p)g(alpha_q)
 = M/(M-1) (1/M sum_p f(alpha_p))(1/M sum_q g(alpha_q))
   - 1/(M-1)(1/M sum_p f(alpha_p)g(alpha_p)).
```

The diagonal term is `O(1/M)`. Hence ordinary one-dimensional equidistribution already gives ordinary unweighted pair equidistribution. One does not need to posit probabilistic independence of two randomly and uniformly selected distinct primes as an additional axiom.

This observation, however, does **not** solve the P3.2 bilinear form.

## 3.2 The P3.2 weights are not uniform

For an interval `I` of length `N`, write

```text
K_I(theta) = sum_{n in I} e(n theta).
```

For `z_p=z_q=2`, the off-diagonal Fourier contribution has the form

```text
4/(pq) sum_{1<=h<p} sum_{1<=k<q}
  e(-h/(2p) + k/(2q))
  cos(pi*h*alpha_p) cos(pi*k*alpha_q)
  K_I(h/p-k/q),
```

up to the harmless convention for conjugation/signs.

This is not an equal-weight average over `(p,q)`. The kernel satisfies

```text
|K_I(theta)| <= min(N, 1/(2||theta||)),
```

so it heavily emphasizes near-resonances

```text
h/p approximately k/q.
```

The weights therefore depend simultaneously on:

```text
p, q, h, k, and the Diophantine separation |hq-kp|/(pq).
```

Marginal uniformity of `alpha_p` says nothing about whether the subsequences selected by these near-resonant weights remain uniform.

## 3.3 Fixed-frequency equidistribution is far too weak

Weyl equidistribution gives cancellation for each **fixed** integer `m`:

```text
sum_p e(m alpha_p) = o(number of p).
```

In the Fourier expansion, however, `h` ranges up to `p-1` and `k` up to `q-1`. The relevant frequencies grow with the sample size. It is easy for a deterministic sequence to be equidistributed for every fixed frequency while having large correlations at frequencies that grow with its index.

A useful theorem would need a quantitative estimate such as

```text
max_{1<=|m|<=P^theta}
|sum_{p in (P,2P], z_p=2} e(m alpha_p)|
  <= pi_2(P) P^{-eta}
```

for some positive `theta,eta`, and even this would not by itself handle the denominator-coupled Farey weights.

## 3.4 The conditioning `z_p=2` covers only part of the prime set

For an ordinary prime with several reflected pairs, write

```text
Z_p = union_{j=1}^{z_p/2} {r_{p,j}, p-1-r_{p,j}},
alpha_{p,j} = (2r_{p,j}+1)/p.
```

Then

```text
F_p(h)
 = 2 e(-h/(2p)) sum_j cos(pi*h*alpha_{p,j}).
```

Thus P3.2 also needs:

- the distribution of the number of pairs;
- the joint point-process distribution of the `alpha_{p,j}` within one prime;
- cross-prime decorrelation of the resulting cosine sums;
- separate treatment of the exceptional central fixed point at nonordinary primes.

The `z_p=2` statistic is the cleanest and most frequent nonempty case, but it is not the whole Fourier transform.

## 3.5 The sufficient statement is a weighted hybrid theorem

A clean physical-space formulation is preferable. For each sign choice `sigma,tau in {+,-}`, let

```text
r_p^+ = r_p,
r_p^- = p-1-r_p,
```

and let `x_{p,q}^{sigma,tau}` be the CRT class modulo `pq` solving

```text
x = r_p^sigma mod p,
x = r_q^tau   mod q.
```

When `pq>N`, each class contributes at most one point to `I`. The relevant centered pair discrepancy is

```text
Delta_{p,q}(I)
 = sum_{sigma,tau}
   (1_{x_{p,q}^{sigma,tau} has a representative in I}
    - expected boundary-corrected mass).
```

A sufficient dyadic hypothesis is an aggregate estimate of diagonal size, schematically

```text
sum_{p != q in a dyadic prime block} Delta_{p,q}(I)
  << N^{1+o(1)}
```

or, block by block, at the corresponding diagonal scale. Combined with the known diagonal term, this gives

```text
sum_{n in I} |sum_p g_p(n)|^2 <= N^{1+o(1)}.
```

The trivial `L^2`-to-`L^infinity` inequality then yields a pointwise count `N^{1/2+o(1)}`, far below `N/log N`, and hence P3.2.

In Fourier language, the equivalent requirement is cancellation of the cosine products **after weighting by the Farey kernel**. This is not ordinary equidistribution; it is a hybrid large-sieve/dispersion theorem.

### Verdict on Question 2

- **Unweighted** joint independence of two uniformly sampled distinct `alpha_p` values follows from marginal equidistribution.
- **Weighted** independence against the P3.2 kernel does not.
- Proving the weighted statement would suffice, but it is essentially the missing cross-prime pair-dispersion theorem in a new one-parameter coordinate system.

So the alpha discovery gives a compelling model and may expose additional structure, but ordinary equidistribution alone does not close P3.2.

## 4. Relation to the Apéry K3 Frobenius eigenvalues

## 4.1 The classical K3 connection

The Apéry generating function is a period of a family of K3 surfaces, and its differential equation is the corresponding Picard–Fuchs equation. The foundational references are:

- F. Beukers and C. Peters, [A family of K3 surfaces and zeta(3)](https://doi.org/10.1515/crll.1984.351.42), J. Reine Angew. Math. 351 (1984), 42–54.
- J. Stienstra and F. Beukers, [On the Picard–Fuchs equation and the formal Brauer group of certain elliptic K3 surfaces](https://doi.org/10.1007/BF01455990), Math. Ann. 271 (1985), 269–304.

In characteristic `p`, truncated period coefficients such as `b_r mod p` occur naturally in Hasse–Witt/Cartier and formal-Brauer-group calculations.

## 4.2 `r` is a character label, not a geometric fiber coordinate

The current repository's Mellin identity is the most precise conceptual bridge. Let `theta_p(a)` be the primitive K3 trace attached to the geometric fiber parameter `a in F_p^*`, and let `omega_p` be the Teichmüller character. Then the `r`-th multiplicative Mellin moment satisfies

```text
M_p(r) = sum_{a in F_p^*} theta_p(a) omega_p(a)^r
       = -b_r mod p.
```

Therefore:

- `a` is the K3 **fiber parameter**;
- `r` is the **multiplicative-character exponent**;
- `r_p` is a character exponent at which the Mellin transform is divisible by `p`.

The natural involution on characters sends

```text
r -> p-1-r,
```

which is exactly the palindromic pairing of zeros. The statistic

```text
alpha_p = (2r_p+1)/p
```

is an archimedean normalization of the smaller member of this inverse-character pair. The perhaps more intrinsic character-group coordinate is `2r_p/(p-1)`; the two differ by `O(1/p)`, so they have the same limiting distribution.

Thus the best geometric formulation of the new observation is:

> Conditional on there being exactly one inverse pair of nonordinary Kummer characters, the normalized position of that pair in the character group appears uniform.

That is a very natural Katz-style conjecture, but with the crucial extra word **nonordinary**, which makes it a `p`-adic local-limit problem.

## 4.3 The p-adic meaning of a zero

In the internal hypergeometric calculation recorded in `problems/3.2/lemmaBprime_result.tex`, the `r`-indexed twist has a Frobenius factor of the schematic form

```text
(X-p)(X^2-a_{p,r}X+p^3),

a_{p,r} = b_r mod p.
```

At an ordinary index `b_r != 0 mod p`, the Newton polygon has a slope-zero unit root. At a Hasse zero `b_r=0 mod p`, that unit root disappears and the Newton polygon rises.

This makes `alpha_p` a label of a twist whose **p-adic slope pattern changes**. It is still not an eigenangle of the complex Frobenius matrix. Sato–Tate distributes normalized complex eigenvalues/conjugacy classes; `alpha_p` distributes the labels at which the p-adic Newton polygon is nonordinary.

## 4.4 The central quadratic character and the modular form

The central index

```text
r=(p-1)/2
```

corresponds to the quadratic character, which is self-inverse. This is why it is exceptional under the palindrome and why it is the index connected to the level-8 weight-4 newform. General reflected zero pairs correspond to nonquadratic inverse character pairs. Sato–Tate for the single modular form controls only the central slice, not the entire family of twists.

## 4.5 `Sp(4)` versus the K3 rank-three system

There are two related but distinct monodromy objects:

1. The generic balanced rank-four hypergeometric system associated with a `_4F_3` expression is symplectically self-dual and belongs to the `Sp(4)` side of the Beukers–Heckman/Katz theory.
2. The transcendental variation of the Apéry K3 family is rank three and has orthogonal/`SO(3)`-type structure (often viewed through a symmetric-square description).

At the special balanced parameter, a rank-four hypergeometric object can acquire a rank drop/nearby-cycle quotient whose effective K3 piece is rank three. Therefore “Katz `Sp(4)` monodromy of the generic hypergeometric family” and “Frobenius on the Apéry K3 transcendental cohomology” are related, but they are not the same representation.

The monodromy classification reference is F. Beukers and G. Heckman, [Monodromy for the hypergeometric function](https://doi.org/10.1007/BF01393900), Invent. Math. 95 (1989), 325–354.

### Verdict on Question 3

`alpha_p` is most naturally connected to Frobenius as follows:

```text
alpha_p
  = normalized exponent of an exceptional Kummer character
  = label where a K3 Mellin transform has Hasse invariant 0
  = label where the p-adic Frobenius loses a unit root.
```

It is **not** directly a function of the Frobenius eigenvalues of the untwisted K3 surface, and it is not a Sato–Tate eigenangle.

## 5. What theorem should now be conjectured?

The computation suggests three progressively stronger conjectures.

## Conjecture A — conditional marginal equidistribution

For every continuous `phi`,

```text
1/pi_2(X) sum_{p<=X, z_p=2} phi(alpha_p)
  -> integral_0^1 phi(x) dx.
```

Equivalently, for every fixed nonzero integer `m`,

```text
sum_{p<=X, z_p=2} e(m alpha_p) = o(pi_2(X)).
```

This is the exact theorem supported by the KS experiment.

## Conjecture B — quantitative growing-frequency equidistribution

There exist `theta,eta>0` such that, in each dyadic prime block,

```text
max_{1<=|m|<=P^theta}
|sum_{P<p<=2P, z_p=2} e(m alpha_p)|
  << pi_2(P) P^{-eta}.
```

This begins to interact with the Fourier expansion but still ignores the rational-frequency kernel.

## Conjecture C — hybrid reflected-pair dispersion

For every relevant integer interval `I`, dyadic prime blocks, and all reflected pairs, the boundary-corrected CRT discrepancies have signed aggregate of diagonal size. Equivalently, the cosine coefficients satisfy a bilinear large-sieve estimate with the kernel

```text
K_I(h/p-k/q).
```

Conjecture C implies the second-moment estimate needed for all-index P3.2. Conjecture A does not imply Conjecture C by any known argument.

For primes with more than one reflected pair, Conjecture C should be stated for the empirical point measure

```text
nu_p = sum_j delta_{alpha_{p,j}}
```

rather than only its first atom.

## 6. Recommended computational campaign

The current test should be expanded in ways aligned with the theorem hierarchy.

### 6.1 Make the marginal result publication-grade

For every prime in the range, save

```text
p, z_p, all zeros, r_p, alpha_p.
```

Report:

- KS and Cramér–von Mises statistics;
- dyadic-shell KS statistics;
- the first 20–100 Weyl sums `A_m(X)`;
- the normalized quantities `|A_m|/sqrt(pi_2(X))`;
- discrepancy by residue classes `p mod 8`, `p mod 24`, and other natural conductors;
- conditional tests by the sign/size of the level-8 modular coefficient.

This checks whether uniformity is stable rather than an aggregate cancellation across arithmetic subfamilies.

### 6.2 Test the growing-frequency regime

For prime blocks `P<p<=2P`, compute

```text
max_{1<=m<=M} |sum e(m alpha_p)|
```

for `M=P^theta` at several small `theta`. Compare with random uniform points and record the extreme-value normalization. Fixed `m<=10` is not enough for the P3.2 kernel.

### 6.3 Test denominator-sensitive bias

The key new diagnostic is whether `alpha_p` remains uniform after conditioning on the rational-frequency data selected by the kernel. For example, group prime pairs by

```text
|h q-k p|,
p/q,
prime dyadic block,
and CRT representative location.
```

Then test cosine cancellation within each Farey shell. This directly measures the gap between Conjectures B and C.

### 6.4 Replace the 500-pair sample by complete block sums

For each dyadic `N`, compute all active pairs and report:

```text
signed off-diagonal sum,
absolute off-diagonal sum,
sum of squares,
effective sample size,
random-sign/permutation p-value,
and comparison with random reflected zero sets of the same sizes.
```

The full aggregate, not a random subset of pairs, is the object entering the theorem.

### 6.5 Include `z_p>=4`

For each prime, form the ordered point configuration

```text
0 < alpha_{p,1} < ... < alpha_{p,z_p/2} < 1.
```

Test whether, conditional on `z_p=2k`, it behaves like `k` independent uniform points ordered in `(0,1)`, or whether there is repulsion. This determines the correct multi-pair Fourier model.

## 7. Most plausible proof route—and its exact missing input

The most conceptually promising route is a character-aspect formulation:

1. Construct one integral Mellin/hypergeometric object whose character trace at exponent `r` reduces to `b_r mod p`.
2. Determine its geometric and arithmetic monodromy uniformly.
3. Prove a **local-limit theorem modulo `p`** for the Hasse invariant as the character varies.
4. Upgrade the one-prime result to a two-prime, denominator-weighted bilinear theorem.

Steps 1–2 are close to the current Katz/Dwork infrastructure. Step 3 is not supplied by standard equidistribution of complex Frobenius classes. Step 4 is the horizontal cross-prime obstruction.

A second route is a two-parameter dynamical Chebotarev theorem for the Apéry transfer orbit, with gap and starting point both growing with `p`. Existing fixed-polynomial Chebotarev cannot handle this because the algebraic complexity grows linearly with the gap.

Therefore the minimum genuinely new arithmetic statement is not merely “the monodromy group is `Sp(4)`.” It is something like:

> The Hasse-zero indicators of the Kummer twists are quantitatively equidistributed in the character label, uniformly across residue characteristics, and satisfy a two-prime large-sieve estimate.

That statement would be a significant theorem in its own right and would indeed have enough strength to close P3.2.

## Final answers

### 1. Can `alpha_p` equidistribution be proved from known results?

**Not at present, as far as the standard literature and the current repository show.** Sato–Tate controls a single modular Frobenius trace; Dwork controls slopes, unit roots, and congruences; Katz controls complex Frobenius conjugacy classes of Mellin transforms. The selected exact zero index is a p-adic local-limit/order-statistic problem with growing characteristic and growing family size. The computation points to a genuinely new conjecture.

### 2. If equidistribution is proved, does it suffice for P3.2?

**Ordinary marginal equidistribution does not suffice.** It automatically gives unweighted pair-product distribution for uniformly sampled distinct primes, so no separate abstract “joint independence” is needed at that level. But P3.2 uses nonuniform Farey-kernel weights and frequencies growing up to the prime scale. A quantitative weighted/hybrid version is needed; that version is essentially the desired pairwise dispersion theorem. One must also incorporate primes with multiple reflected zero pairs.

### 3. What is the Frobenius/K3 meaning of `alpha_p`?

It is the normalized label of an inverse pair of Kummer characters for which the Apéry K3 Mellin transform is nonordinary. Equivalently, it labels a twist whose Hasse invariant vanishes and whose p-adic Frobenius loses a unit root. It is not itself a Frobenius eigenangle. The quadratic central character is the special slice related to the level-8 weight-4 form; general `alpha_p` values belong to the full character family. The generic rank-four `Sp(4)` hypergeometric object and the special rank-three K3 piece are related but distinct.

## Bottom line for P3.2

This discovery is a **major heuristic sharpening**, not yet a shortcut around the dispersion frontier. It converts the dominant `z_p=2` Fourier coefficients into a one-parameter cosine model and suggests that the hidden horizontal variable is the Kummer-character position. The paper should state and document Conjecture A, but the proof program should target Conjecture C.

The clean slogan is:

> The Apéry zero pairs appear uniformly distributed in character space; P3.2 requires that this uniformity persist under the growing-frequency Farey weights imposed by the CRT.
