## 2. From the recurrence to the support-visible return polynomial

Start from

\[
(n+1)^3b_{n+1}=P(n)b_n-n^3b_{n-1}.
\tag{2.1}
\]

Suppose `p\mid b_x`. The first step is

\[
(x+1)^3b_{x+1}=-x^3b_{x-1}\pmod p.
\tag{2.2}
\]

This is the literal first recurrence-native identity at a zero. A support ledger cannot test it because it does not record `b_{x-1}` or `b_{x+1}`.

Eliminate those unknown values. For `h\ge1`, let

\[
D_h(x):=\prod_{j=2}^{h}(x+j)^3,
\qquad D_1(x):=1.
\]

A direct induction using `(2.1)` proves

\[
\boxed{
D_h(x)b_{x+h}=K_h(x)b_{x+1}
\pmod p
}
\tag{2.3}
\]

whenever `p\mid b_x`, where `K_h` is defined by `(R1)`.

The induction is exact. For `h=1` it is tautological. For `h=2`,

\[
(x+2)^3b_{x+2}=P(x+1)b_{x+1}.
\]

If `(2.3)` holds for `h` and `h-1`, applying `(2.1)` at `x+h` and multiplying by `D_h` gives

\[
D_{h+1}b_{x+h+1}
=igl(P(x+h)K_h-(x+h)^6K_{h-1}\bigr)b_{x+1},
\]

which is `(R1)`.

Now assume

\[
0<x<x+h<p.
\]

Then `D_h(x)` is a `p`-unit. If `p\mid b_x`, no adjacency gives `p\nmid b_{x+1}`. Hence

\[
p\mid b_{x+h}
\quad\Longleftrightarrow\quad
p\mid K_h(x).
\tag{2.4}
\]

This is stronger than reflection/no adjacency but weaker than full recurrence realizability:

- it is a necessary and sufficient return condition **conditioned on the actual prefix zero** `p\mid b_x`;
- a formal root `K_h(x)=0` without the actual prefix may be a phantom root;
- several formal returns must also be compatible with one distinguished recurrence orbit.

In the notation used elsewhere in the project, `K_h(x)` is the normalized gap-continuant entry `N_{h-1}(x+1)`, up to the harmless chosen unit normalization. Defining it by `(R1)` avoids every indexing ambiguity.

\Longrightarrow K_h(x)=0\pmod p.

\tag{4.1}

   \[

The first case is the requested first explicit identity. The other two explain why merely adding formal continuant roots to the countermodel would not yet make it an actual-Apéry model.

## 7. Quantitative candidate lemma for the shifted tail

Let

\[
\mathcal T_K(T,J)
 :=\sum_s\bigl((A_s-K)_+\bigr)_2.
\tag{7.1}
\]

The committed deterministic extremal shows that, from the current marginal banks alone,

\[
\mathcal T_K
\lesssim_J
F_{2,\rm pre}
\left(\frac{C-K}{C}\right)^2,
\qquad
C\asymp_J T/\log T,
\tag{7.2}
\]

and this is sharp at the interface level. A recurrence theorem must therefore control the alignment between high actual load and high actual recurrence capacity.

### Candidate theorem: `SARC_K`

For each fixed integer `J` and the deterministic shift `K=K(T)` used by the current high-load decomposition,

\[
\boxed{
\sum_s
(A_s-K)_+
(C_s^{\rm Ap}-K-1)_+
=o_J\!\left(
T^{12/5}(\log T)^{-16/5}
\right).
}
\tag{7.3}
\]

This theorem is:

- **recurrence-native:** `C_s^{Ap}` is built from actual Apéry values, not planted zero support;
- **support-blind on the capacity side:** the radicals are defined before selecting which shell primes are q6 leaves;
- **Boolean-union compatible:** the lcm counts a lower prime once if it supports both signs;
- **strictly localized:** empty and low-load states cost nothing;
- **exactly sufficient:** `(R9)` proves `(R10)` with no Cauchy or logarithmic loss.

The stronger pure-capacity statement `(R11)` is sometimes easier to present, but it asks for a tail theorem on high recurrence radicals even when no actual inverse leaf lands there. `SARC_K` is the weaker and more strategically faithful target.

 =\{s:H\le A_s-K<2H\}.

It is enough to prove the summable estimate

\[
\boxed{

H\sum_{s\in\mathcal S_H}
(C_s^{\rm Ap}-K-1)_+
=o_J(\Phi_T).
}
\tag{7.4}

Separate little-oh statements in each bin are not sufficient unless their errors are uniform and summable.

### Marked variant

If the shifted tail is taken only after the upper selector, insert

in `(7.3)` and `(7.4)`. The same pointwise implication holds. The target scale should then be the exact marked-owner scale used in that consumer rather than silently reusing `\Phi_T`.

The scalar resultant of one `K_h` is not enough. Its degree grows with the gap, and formal roots need not be actual prefixes. The theorem must be averaged over the exact moving q6 family or use the common actual-value radicals.

Therefore the countermodel is strategically useful but narrowly scoped. It shows that the current formal-support interfaces are terminal. It does **not** obstruct a theorem based on the actual recurrence. The first such theorem should be formulated not as another zero-count moment, but as a return-continuant or common-radical anti-concentration estimate of the form `SARC_K`.
