# Exact p^2 audit of the Newton residual

## Executive summary

Let
\[
Y_d=C_M(d)=\sum_{\nu\in d\mathbf Z^3}c_M(\nu),\qquad M=n-1,
\]
and let
\[
\delta=\Delta^{N+1}Y_{D-1}.
\]
The adjacent Newton identity gives
\[
G_{D-1,N}-G_{D,N}=(-1)^{N+1}\binom{D+N}{N}\Delta^{N+1}Y_{D-1}.
\]
For a target prime p=D+j in the block, p divides the binomial factor exactly once. Therefore the observed nonzero values of
\[
\frac{G_{D-1,N}-G_{D,N}}p\pmod p
\]
are equivalent to
\[
\delta\not\equiv0\pmod p.
\]

The strict conclusion is:

* Laurent coefficient identities give an exact expression for \(\delta\bmod p\).
* Targetness \(p\mid C_M(p-1)\) alone does not force \(p\mid\delta\).
* The only universal implication is the opposite: if the entire target stencil is annihilated by the same Frobenius shell condition then all finite differences vanish, but that is a stronger condition than targetness.

No central symmetry of coefficients is used.

## 1. Exact Lucas expansion

Write
\[
M=ap+s,\qquad 0\le s<p.
\]
Freshman's dream gives in characteristic p
\[
\Lambda(X)^M\equiv \Lambda(X^p)^a\Lambda(X)^s\pmod p.
\]
Hence for every exponent vector \(\mu\),
\[
c_M(\mu)\equiv\sum_{\alpha,\beta:p\alpha+\beta=\mu}
 c_a(\alpha)c_s(\beta)\pmod p.
\]
For the shell at p-1,
\[
Y_{p-1}=C_M(p-1)
=\sum_{\kappa\in\mathbf Z^3}c_M((p-1)\kappa).
\]
Thus
\[
Y_{p-1}\equiv
\sum_{\kappa}\sum_{p\alpha+\beta=(p-1)\kappa}
 c_a(\alpha)c_s(\beta)\pmod p.
\]
This is the exact usable formula.

## 2. Exact formula for delta

Expanding the finite difference,
\[
\delta=\sum_{i=0}^{N+1}(-1)^{N+1-i}\binom{N+1}{i}Y_{D-1+i}.
\]
For a target prime p=D+j, substitute
\[
D-1+i=p-1+(i-j).
\]
Therefore
\[
\boxed{
\delta\equiv
\sum_i(-1)^{N+1-i}\binom{N+1}{i}
\sum_\kappa c_M((p-1+i-j)\kappa)\pmod p.
}
\]
This is the exact Laurent coefficient expression. The target condition removes only the term i=j:
\[
C_M(p-1)\equiv0\pmod p.
\]
It gives no cancellation relation among the other shifted shells.

## 3. What would be required for p^2 cancellation

A target-blind block would need
\[
p\mid\delta
\]
for every target p in the block. The above formula shows that this requires
\[
\sum_i(-1)^{N+1-i}\binom{N+1}{i}C_M(p-1+i-j)=0\pmod p.
\]
The single equation
\[
C_M(p-1)=0\pmod p
\]
is insufficient: it removes one summand only.

The five audited blocks are consistent with this:

* (200,128,63): p=139,181 give residuals 22,37.
* (272,180,63): p=191,233 give 52,83.
* (300,180,57): p=191,227 give 43,128.
* (321,168,53): p=179,193,211 give 159,150,197.
* (755,582,161): p=593,733 give 174,639.

All are nonzero modulo p.

## 4. Why a general theorem cannot be strengthened from targetness alone

A target is one shell hyperplane:
\[
C_M(p-1)=0.
\]
The finite difference is a linear functional on the whole vector
\[
(C_M(p-1-N),\ldots,C_M(p-1+N+1)).
\]
The kernel of the first coordinate condition has codimension one. The finite-difference functional is another linear functional. No identity from Laurent support or Lucas factorization makes these two functionals proportional.

The precise obstruction is therefore not a generic CRT model: it is the missing shifted-shell identity
\[
\Delta^{N+1}C_M(p-1)=0
\]
inside the actual Laurent coefficient module. Targetness supplies no such identity.

## 5. Valid scan design

A strict audit should compute coefficients directly from the Laurent polynomial:

```python
# exact pseudocode
poly = expand(Lambda**M)
def shell(d):
    return sum(coeff[v] for v in coeff if all(x%d==0 for x in v))

for target_prime in primes:
    if shell(p-1) % p == 0:
        delta = sum(((-1)**(N+1-i))*binom(N+1,i)*shell(D-1+i)
                    for i in range(N+2))
        assert delta % p != 0   # experimental only
```

The scan must not use coefficient symmetry, because \(c_M(\nu)\neq c_M(-\nu)\) in general.

## Final audit verdict

The strongest proved statement is:

\[
\boxed{p\mid C_M(p-1)\not\Rightarrow p\mid\Delta^{N+1}C_M(D-1).}
\]

The p^2 obstruction is a genuine shifted-shell problem. Any future proof that removes the binomial p-factor must introduce an additional distinguished-state relation involving neighboring shells; the target congruence alone cannot provide it.
