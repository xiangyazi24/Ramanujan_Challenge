## 1. Claim A: exact divisor expansion

Set

\[
g(n):=\prod_{\ell\mid n}\left(1+\frac5\ell\right).
\]

For a prime \(\ell\), put

\[
\alpha(\ell)
:=\left(1+\frac5\ell\right)^3-1
=\frac{15}{\ell}+\frac{75}{\ell^2}+\frac{125}{\ell^3}.
\]

Define \(a(1)=1\), let \(a\) be multiplicative, set

\[
a(d):=\prod_{\ell\mid d}\alpha(\ell)
\]

for squarefree \(d\), and set \(a(d)=0\) for nonsquarefree \(d\). Then the expansion is exact:

\[
\boxed{
 g(n)^3=\sum_{d\mid n}a(d).
}
\]

Indeed, this is just the expansion of

\[
\prod_{\ell\mid n}(1+\alpha(\ell)).
\]

All coefficients are nonnegative. Therefore, for every \(Z\ge1\),

\[
\begin{aligned}
\sum_{n\le Z}g(n)^3
&=\sum_{d\le Z}a(d)\left\lfloor\frac Zd\right\rfloor\\
&\le Z\sum_{d\ge1}\frac{a(d)}d\\
&=Z\prod_\ell
 \left(1+\frac{15}{\ell^2}
          +\frac{75}{\ell^3}
          +\frac{125}{\ell^4}\right)\\
&\ll Z.
\end{aligned}
\]

The Euler product converges absolutely because its nonconstant local term is \(O(\ell^{-2})\). Thus

\[
\boxed{
\sum_{n\le Z}g(n)^3=O(Z).
}
\tag{A1}
\]

Also \(g\) is submultiplicative, so the stipulated singular modifier satisfies

\[
S(h,k)
\ll g(56hk(h+k))
\le g(56)g(h)g(k)g(h+k).
\tag{A2}
\]

Now let \(\mathcal R\) be any subset of a dyadic rectangle

\[
h\asymp X,
\qquad
k\asymp Y,
\qquad
X\le Y.
\]

The set \(\mathcal R\) may impose any of the exact order, parity, divisibility, or congruence restrictions. Hölder gives

\[
\sum_{(h,k)\in\mathcal R}g(h)g(k)g(h+k)
\le A_h^{1/3}A_k^{1/3}A_+^{1/3},
\]

where

\[
A_h:=\sum_{\mathcal R}g(h)^3,
\qquad
A_k:=\sum_{\mathcal R}g(k)^3,
\qquad
A_+:=\sum_{\mathcal R}g(h+k)^3.
\]

By enlarging \(\mathcal R\) to the full rectangle and using (A1),

\[
A_h\ll Y\sum_{h\ll X}g(h)^3\ll XY,
\qquad
A_k\ll X\sum_{k\ll Y}g(k)^3\ll XY.
\]

For the third factor, write

\[
A_+=\sum_n r_{\mathcal R}(n)g(n)^3,
\qquad
r_{\mathcal R}(n)
:=\#\{(h,k)\in\mathcal R:h+k=n\}.
\]

Once \(h\) is fixed, \(k=n-h\) is fixed, so

\[
r_{\mathcal R}(n)\ll X.
\]

Moreover \(h+k\ll Y\), because \(X\le Y\). Hence

\[
A_+\ll X\sum_{n\ll Y}g(n)^3\ll XY.
\]

Consequently

\[
\boxed{
\sum_{(h,k)\in\mathcal R}S(h,k)\ll XY.
}
\tag{A3}
\]

This proves Claim A. The key point about the exact lattice restrictions is monotonicity: they select a subset of the full dyadic rectangle. No average distribution theorem inside those classes is being asserted or used.

## 2. Claim B: occurrence multiplicity and logarithmic weight

For one fixed pair \((h,k)\) and one physical order cell, the stated Selberg theorem gives

\[
\#\{(p,q_1,q_2)\}
\ll_J \frac{T}{L^3}S(h,k).
\]

Each such lower prime \(p\) supports at most

\[
3\min(h,k)\ll X
\]

actual starting residues. Summing the finite three order cells and then using (A3),

\[
\begin{aligned}
A(X,Y)
&:=\#\{\text{actual occurrences in the box}\}\\
&\ll_J
\frac{TX}{L^3}
\sum_{h\asymp X,\,k\asymp Y}S(h,k)\\
&\ll_J
\boxed{\frac{TX^2Y}{L^3}}.
\end{aligned}
\tag{B1}
\]

Since the shell condition gives \(\log p\asymp_J L\), and an upper bound needs only \(\log p\ll_JL\), the one-log weighted mass is

\[
\boxed{
H(X,Y)\ll_J\frac{TX^2Y}{L^2}.
}
\tag{B2}
\]

Thus Claim B is correct. The unweighted estimate (B1) follows directly from the Selberg count; it need not be recovered by dividing a weighted estimate.

## 3. Claim C: dyadic hyperbolic summation

Sum (B2) over dyadic \(X,Y\) satisfying

\[
M<X\le Y,
\qquad
X^2Y\le B.
\]

For one fixed dyadic \(X\), the geometric sum over \(Y\) is

\[
\sum_{\substack{Y\text{ dyadic}\\X\le Y\le B/X^2}}X^2Y
\ll X^2\frac{B}{X^2}
\ll B.
\tag{C1}
\]

There is no logarithmic loss from the \(Y\)-sum. Since \(Y\ge X\), a nonempty box must satisfy \(X^3\le B\). Hence the number of possible dyadic \(X\)-scales is

\[
N_X
\le
1+\left\lfloor
\log_2^+\!\left(\frac{B^{1/3}}{M}\right)
\right\rfloor
=O\!\left(1+\log_+\!\frac{B}{M^3}\right).
\tag{C2}
\]

If \(B<M^3\), the pointwise sector is empty, apart from harmless boundary-box conventions; the displayed upper bound remains valid. Combining (C1) and (C2) gives

\[
\boxed{
H_{M,B}
\ll_J
\frac{TB}{L^2}
\left(1+\log_+\frac{B}{M^3}\right),
}
\tag{C3}
\]

and

\[
\boxed{
A_{M,B}
\ll_J
\frac{TB}{L^3}
\left(1+\log_+\frac{B}{M^3}\right).
}
\tag{C4}
\]

Strict inequalities, integer floors, the final incomplete dyadic box, swapping the two gap labels, and the three physical cells alter only absolute constants.

## 4. Compatibility with the prior cutoff

Use the stated current scales

\[
R=\frac{T^{2/5}}{\Omega L^{6/5}},
\qquad
B=\frac{RT}{\omega},
\qquad
M=\frac{T^{1/5}}
        {L^{1/10}\Omega^{1/2}\eta^{1/2}}.
\]

Then

\[
M^3
=
\frac{T^{3/5}}
     {L^{3/10}\Omega^{3/2}\eta^{3/2}},
\]

and therefore

\[
\boxed{
\frac{B}{M^3}
=
\frac{T^{4/5}\Omega^{1/2}\eta^{3/2}}
     {\omega L^{9/10}}.
}
\tag{D1}
\]

In the project slow-function hierarchy, \(\Omega,\eta,\omega=T^{o(1)}\), with \(\omega\to\infty\). Thus

\[
\frac{B}{M^3}=T^{4/5+o(1)}\to\infty
\]

and

\[
1+\log_+\frac{B}{M^3}
=\left(\frac45+o(1)\right)L.
\tag{D2}
\]

So the new sector is compatible with, and nonvacuous beyond, the prior lower cutoff \(X>M\). No extra ordering relation among \(\omega,\Omega,\eta\) is needed beyond the already-used slow hierarchy.

Substituting \(B=RT/\omega\) into (C3) gives

\[
\begin{aligned}
H_{M,B}
&\ll_J
\frac{RT^2}{\omega L^2}
\left(1+\log_+\frac{B}{M^3}\right)\\
&=
\frac{RT^2}{L}
\cdot
O_J\!\left(
\frac{1+\log_+(B/M^3)}{\omega L}
\right).
\end{aligned}
\]

Likewise, (C4) gives

\[
A_{M,B}
=
\frac{RT^2}{L^2}
\cdot
O_J\!\left(
\frac{1+\log_+(B/M^3)}{\omega L}
\right).
\]

By (D2), the common normalized factor is

\[
\boxed{
\frac{1+\log_+(B/M^3)}{\omega L}
=O\!\left(\frac1\omega\right)
=o(1).
}
\tag{D3}
\]

Therefore

\[
\boxed{
H_{M,B}=o_J\!\left(\frac{RT^2}{L}\right),
\qquad
A_{M,B}=o_J\!\left(\frac{RT^2}{L^2}\right).
}
\tag{D4}
\]

If \(R\) and the cutoffs are implemented with floors, the project slow hierarchy gives \(R=T^{2/5-o(1)}\to\infty\); replacing them by their integer parts changes only \(1+o(1)\) factors and at most one boundary dyadic scale.
