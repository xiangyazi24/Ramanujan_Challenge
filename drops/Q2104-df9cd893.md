# 1. Exact continuant algebra

Put

```text
c_n := (n!)^3 b_n.
```

The Apery recurrence becomes the denominator-free recurrence

```text
c_{n+1} = P(n)c_n - n^6 c_{n-1}.                  (1.1)
```

This is immediate because

```text
(n+1)!^3 = (n+1)^3 n!^3,
n!^3/(n-1)!^3 = n^3.
```

The Q2104 continuant is therefore the exact fundamental solution of (1.1).

## Theorem 1.1 -- propagation identity [PROVED]

For every integer `r>=0` and every `h>=1`,

```text
c_{r+h}
 = N_h(r)c_{r+1}
   - (r+1)^6 N_{h-1}(r+1)c_r.                    (1.2)
```

**Proof.** For `h=1` this is `c_{r+1}=c_{r+1}`. For `h=2` it is (1.1) at `n=r+1`. Induction in `h` uses the same recurrence for both sides. QED.

Hence, if `q` is prime, `r+h<q`, and `q|b_r`, then the factorials are `q`-units and no two consecutive `b`'s can vanish modulo `q`. Therefore

```text
q | b_{r+h}   <=>   q | N_h(r).                  (1.3)
```

This is the exact one-index return encoding used in Q2104.

## Theorem 1.2 -- addition / renewal law [PROVED]

For all integers `x>=0`, `h>=1`, `d>=1`,

```text
N_{h+d}(x)
 = N_d(x+h) N_{h+1}(x)
   - (x+h+1)^6 N_{d-1}(x+h+1) N_h(x).            (1.4)
```

This is proved by induction on `d`; the cases `d=1,2` are exactly the defining recurrence.

Now let `q` be prime with `x+h+d<q`. If `q|N_h(x)`, then

```text
q does not divide N_{h+1}(x).                    (1.5)
```

Indeed, if two consecutive continuants vanished, the recurrence can be run backwards because every `(x+j)^6` encountered is a `q`-unit, eventually forcing `q|N_1(x)=1`.

Reducing (1.4) modulo `q` therefore gives the exact restart rule

```text
q | N_h(x)
    =>
(q | N_{h+d}(x)  <=>  q | N_d(x+h)).             (1.6)
```

This is the cleanest companion/Casoratian fact I found.

## Corollary 1.3 -- selected-path multiplicity [PROVED]

Let

```text
r=s_0 < s_1 < ... < s_K < q
```

and suppose `q|b_{s_i}` for every `i`. Put `g_i=s_i-s_{i-1}`. Then

```text
q | N_{g_i}(s_{i-1})       for i=1,...,K,          (1.7)
```

and hence

```text
q^K | product_{i=1}^K N_{g_i}(s_{i-1}).           (1.8)
```

Conversely, starting from `q|b_{s_0}`, the K segment conditions in (1.7) recreate the K later zeros.

So there **is** a genuine K-fold multiplicity gain once the actual selected return path is known.

The obstruction is selection: the ordered gaps `(g_1,...,g_K)` depend on `q`. A fixed integer which detects *there exists some K-subset of returning offsets* has to encode the union over all choices. Section 4 proves that the universal threshold algebra is already saturated at degree `n_r-K+1`; the low-degree path product cannot be made choice-free for free.

A crude but useful height bound is

```text
log |N_h(x)| = O(h log N)      (0<=x, x+h<=N),     (1.9)
```

because after dividing the h-th step by `N^{3(h-1)}` the recurrence is bounded by a constant-coefficient two-step majorant. Therefore a selected path has

```text
log | product_i N_{g_i}(s_{i-1}) | = O(N log N),   (1.10)
```

since `sum_i g_i=s_K-s_0<N`.

This local fact is real, but by itself it does not sum over primes because every prime can choose a different path.

# 2. The threshold-gcd sum is exactly a high-zero-count tail

For a prime `q>N` and parity `eps in {0,1}`, define

```text
Z_{q,eps}(N)
 := { 1<=r<N : r == eps (mod 2), q|b_r },

z_{q,eps}(N) := |Z_{q,eps}(N)|.                  (2.1)
```

Also note

```text
n_r = floor((N-r-1)/2).                          (2.2)
```

## Theorem 2.1 -- exact aggregate identity [PROVED]

For every `N>=2` and every integer `K>=1`,

```text
S_{N,K}
 := sum_{1<=r<N} log Rad_(N,2N] H_{N,K}(r)

 = sum_{N<q<=2N, q prime} log q *
     [ (z_{q,0}(N)-K)_+ + (z_{q,1}(N)-K)_+ ].    (2.3)
```

Here `(u)_+=max(u,0)`.

**Proof.** Fix `q` and one parity. Write its zeros below `N` in increasing order

```text
r_1 < r_2 < ... < r_z.
```

At `r_i` there are exactly `z-i` later same-parity zeros. The Q2104 support equivalence says `q|H_{N,K}(r_i)` iff `z-i>=K`. Thus exactly `max(z-K,0)` bases contribute. If such K later values exist then automatically `n_{r_i}>=K`, so the convention `H=1` when `n_r<K` causes no exception. Sum over parities and primes. QED.

Define the unweighted excess count

```text
M_{N,K}
 := sum_{N<q<=2N} sum_{eps=0,1} (z_{q,eps}(N)-K)_+.   (2.4)
```

Since `log N < log q <= log(2N)`, (2.3) gives

```text
log N * M_{N,K} <= S_{N,K} <= log(2N) * M_{N,K}.    (2.5)
```

Therefore, with `K=K_N`,

```text
(SFT)
<=>
M_{N,K_N} = o(N/loglog N).                         (2.6)
```

No prime number theorem is used in this equivalence.

Moreover the signed-tail bound becomes

```text
E_{N,K}^sgn
 <= 2 log(2N)/log N * M_{N,K}.                     (2.7)
```

Thus the exact remaining theorem is a large-deviation estimate for the parity-zero counts, not a height estimate in disguise.

**Status of (2.6): OPEN.**

# 3. Exact higher factorial moments and the amount of multiplicity actually needed

For an integer `m>=2`, define the weighted m-fold selected collision mass

```text
C_m(N)
 := sum_{N<q<=2N} log q *
      sum_{eps=0,1} binom(z_{q,eps}(N),m).          (3.1)
```

There is an exact selected-gcd representation of this quantity.

For a same-parity tuple

```text
1 <= r_0 < r_1 < ... < r_{m-1} < N
```

put

```text
G(r_0; r_1,...,r_{m-1})
 := gcd( b_{r_0},
         N_{r_1-r_0}(r_0),
         ...,
         N_{r_{m-1}-r_0}(r_0) ).                  (3.2)
```

Because every relevant prime is bigger than all indices, (1.3) gives

```text
C_m(N)
 = sum_{same-parity r_0<...<r_{m-1}<N}
     log Rad_(N,2N] G(r_0; r_1,...,r_{m-1}).       (3.3)
```

So (3.1) is precisely the genuinely *selected* m-fold gcd ledger.

## Theorem 3.1 -- factorial threshold gain [PROVED]

If `K>=m-1`, then

```text
S_{N,K} <= C_m(N) / binom(K,m-1).                  (3.4)
```

**Proof.** Every base counted by `S_{N,K}` has at least K later selected zeros of its parity, hence anchors at least `binom(K,m-1)` m-tuples. Exchange the order of summation over bases and primes. QED.

Special cases are

```text
m=2:   S_{N,K} <= C_2(N)/K,

m=3:   S_{N,K} <= C_3(N)/binom(K,2).               (3.5)
```

This is the exact higher-multiplicity gain available from fixed tuple order.

It also explains why pair/triple resultants do not change the power exponent. With

```text
K_N = log N/(loglog N)^2 + O(1),
```

any fixed `m` gives only a polylogarithmic divisor `K_N^(m-1)`.

More sharply, even if one could prove, uniformly for every *fixed* m,

```text
C_m(N) <= N^(8/5+o(1)),                            (3.6)
```

then to reduce the `N^(8/5)` power to the `N^1` scale through (3.4) one would need

```text
(m-1) log K_N >= (3/5+o(1)) log N,
```

i.e.

```text
m-1 >= (3/5+o(1)) * log N / loglog N.              (3.7)
```

Thus **a fixed exterior power, fixed resultant order, or fixed selected-gcd moment cannot close SFT**. The required novelty would be a *growing-order* factorial-moment theorem, uniform for `m` of order `log N/loglog N`, or something comparably strong.

## A concrete second-moment theorem which would already suffice

From `m=2`, it is enough to prove the unweighted estimate

```text
U_2(N)
 := sum_{N<q<=2N} sum_{eps=0,1} binom(z_{q,eps}(N),2)

 = o( K_N N / loglog N )
 = o( N log N / (loglog N)^3 ).                   (3.8)
```

Equivalently, at the weighted gcd level it is enough to prove

```text
C_2(N)
 = o( K_N N log N / loglog N )
 = o( N (log N)^2 / (loglog N)^3 ).               (3.9)
```

A natural stronger theorem such as

```text
sum_{N<q<=2N} |Z_q|^2 = O(N/log N)                 (3.10)
```

would crush (3.8), but no such theorem is presently banked.

So an **average gcd / second-factorial-moment route remains OPEN**, with (3.8)--(3.9) as exact quantitative targets. This is, in my view, the cleanest surviving target after the threshold encoding.

# 4. Sharp algebraic saturation of the diagonal threshold detector

This section gives an exact no-go theorem for attempts to obtain a cheap universal algebraic detector of `at least K of the x_D vanish`.

Let `x_1,...,x_n` be indeterminates and let

```text
V_{n,K}
 := { x : at least K coordinates x_i are zero }.   (4.1)
```

For every K-subset `S` of `{1,...,n}`, let

```text
I_S := (x_i : i in S).
```

Then the vanishing ideal of the union of those coordinate subspaces is

```text
I_{n,K}
 := intersection_{|S|=K} I_S

 = ( product_{j in J} x_j : |J|=n-K+1 ).          (4.2)
```

## Theorem 4.1 -- threshold ideal [PROVED]

The squarefree monomials of degree `n-K+1` in (4.2) are the minimal monomial generators of `I_{n,K}`. In particular,

```text
I_{n,K} contains no nonzero polynomial of total degree < n-K+1.  (4.3)
```

**Proof.** A monomial belongs to every `I_S` iff its support meets every K-subset S. This is equivalent to the complement of its support having size at most `K-1`, i.e. its support has size at least `n-K+1`. QED.

For the Q2104 diagonal matrix

```text
D = diag(x_D : D in D_N(r)),
```

`T_{N,K}(r)` is exactly the `(n_r-K+1)`-st determinantal divisor of `D`: its nonzero minors of that size are precisely the products in the definition of `T`.

Thus the near-full minor degree is not an averaging mistake. It is the **minimal universal algebraic degree of the threshold condition itself**.

This sharpens audited limit (2): a formal polynomial/determinantal closure in the `x_D` variables alone cannot replace the coefficient `(n_r-K+1)/n_r` by a reciprocal `1/(n_r-K+1)` factor. The threshold variety forces degree `n_r-K+1`.

## Theorem 4.2 -- exact q-adic determinant frontier [PROVED]

Suppose, at some prime q, exactly K of the n diagonal entries have valuation 1 and the other `n-K` are q-units. Let `Delta_j(D)` denote the j-th determinantal divisor. Then for `1<=s<=K`,

```text
v_q( Delta_{n-K+s}(D) ) = s.                      (4.4)
```

In particular the Q2104 threshold divisor is the case `s=1`:

```text
v_q(T_{N,K}(r)) = 1,                              (4.5)
```

not K.

At the other endpoint, `s=K` is the full determinant/product and has valuation K. So the entire family of diagonal minors lies on the obvious linear exponent/height frontier; there is no hidden superlinear multiplicity.

This is an exact saturation theorem, not a heuristic.

# 6. Rank-two / subspace / exterior-power route: exact saturation

Use the integer state

```text
v_n := (c_{n+1}, c_n)^T,

v_n = S_n v_{n-1},

S_n = [ P(n)  -n^6 ]
      [  1      0  ],

det S_n = n^6.                                    (6.1)
```

For every relevant prime `q>N` and every `n<N`, `S_n` lies in `GL_2(Z_(q))`.

At a zero `q|b_n`, the second state coordinate is zero modulo q and the first is a q-unit. Thus all zero states lie on one projective line modulo q.

If K+1 selected zero states are put as columns of a `2 x (K+1)` matrix W, then

```text
rank(W mod q) = 1,
q divides every 2x2 minor of W.                    (6.2)
```

But this forces only **one** q in the second determinantal divisor. There is no higher exterior power: `wedge^3` of a two-dimensional state space is identically zero, while `wedge^2 S_n=det(S_n)=n^6` is a q-unit.

## Sharp abstract Smith countermodel [PROVED]

For every prime q and every K>=1, consider

```text
W_K = [ 0   q   2q  ...  Kq ]
      [ 1   1    1  ...   1 ].                    (6.3)
```

All K+1 columns lie on the same line modulo q. Every 2x2 minor is `q(i-j)`, and an adjacent-column minor is exactly `+-q`. Hence the Smith invariants are

```text
s_1(W_K)=1,
s_2(W_K)=q,                                       (6.4)
```

independent of K.

So **rank-one coincidence of arbitrarily many states cannot force a growing q-adic Smith exponent**.

This is the same local mechanism found in the Q2059 adjacent-transfer audit: q-unimodular propagation preserves primitive state Smith data.

# 7. CFVMZ coefficient-square structure: sharp no-sparsity theorem

The published theorem says, for the truncated Apery polynomial

```text
A_q(t) = sum_{n=0}^{q-1} b_n t^n in F_q[t],
```

there is a polynomial `B_q(t)` such that for primes `q>3`,

```text
q == 1,5,7,11 (mod 24):
    A_q(t) = B_q(t)^2,

q == 13,17,19,23 (mod 24):
    A_q(t) = (t^2-34t+1) B_q(t)^2.                (7.1)
```

This is a theorem about **polynomial factorization / root multiplicities**. It is not a theorem about coefficient support.

There is an exact algebraic reason it cannot, by itself, control zero coefficients.

## Theorem 7.1 -- truncated square map is locally an automorphism [PROVED]

Let F be any field of characteristic not 2 and let

```text
R_L := F[t]/(t^(L+1)).
```

On the unit group `1+t R_L`, the map

```text
B -> B^2                                              (7.2)
```

is a bijection. More generally, if `Q(0)=1`, then

```text
B -> Q B^2                                            (7.3)
```

is a bijection of `1+tR_L`.

The coefficients are solved recursively: if

```text
B = 1 + c_1 t + ...,
A = Q B^2 = 1 + a_1 t + ...,
```

then for every n

```text
a_n = 2 c_n + F_n(c_1,...,c_{n-1}),               (7.4)
```

and 2 is invertible.

Thus a square (or `Delta*square`, since `Delta(0)=1`) imposes **zero local equations on a finite coefficient prefix** as long as the square root still has coefficients available at those degrees.

For (7.1), this means:

```text
square branch:       deg B_q = (q-1)/2,
Delta-square branch: deg B_q = (q-3)/2.            (7.5)
```

So roughly the first half of the coefficient vector is algebraically free in the abstract factorization class.

## Theorem 7.2 -- even adding palindromy leaves a quarter-prefix free [PROVED]

This is stronger and directly addresses the known Apery reflection symmetry.

Let

```text
Q(t)=1
```

or

```text
Q(t)=1-34t+t^2.
```

Fix `d>=2`, put `m=floor((d-1)/2)`, and restrict to reciprocal monic polynomials

```text
B(t)=t^d B(1/t),
B(0)=1,
leading coefficient(B)=1.                         (7.6)
```

For `1<=n<=m`, the reflected high coefficients of B do not enter `[t^n]QB^2`, and one still has the triangular formula

```text
[t^n] Q(t)B(t)^2
 = 2 c_n + F_n(c_1,...,c_{n-1}).                  (7.7)
```

Therefore **any prescribed values of the first m coefficients of `QB^2` occur for a unique choice of `c_1,...,c_m`**, after which the reciprocal coefficients are filled in.

Since Q and B are reciprocal, `QB^2` is reciprocal/palindromic, has constant coefficient 1 and leading coefficient 1.

Consequently, for every sufficiently large odd characteristic one may prescribe, in this whole quarter-prefix,

```text
a_1 = 5,
a_n = 0   for odd n>=3,
a_n = 1   for even n,                              (7.8)
```

while keeping the exact square / Delta-square factorization, palindromy, endpoint normalization, and separated (non-adjacent within the prefix) zero coefficients.

The number of forced zero coefficients in (7.8) is `Theta(q)`, vastly larger than `K_N`.

So the following implication is **REFUTED**:

```text
CFVMZ square structure + palindromy + endpoint data
    => o(q) coefficient zeros
```

or any comparable high-multiplicity sparsity statement.

This does **not** refute a future theorem exploiting the *specific* CFVMZ square root / specific Apery recurrence. It proves that the factorization pattern itself supplies no such theorem.

## Explicit sparse countermodels

Even without the triangular theorem, the point is visible from

```text
square branch:
    A(t) = (1+t^d)^2,
```

which is reciprocal and has only three nonzero coefficients, and

```text
Delta-square branch:
    A(t) = (1-34t+t^2)(1+t^d)^2,
```

which is reciprocal and has at most nine nonzero coefficients.

These are countermodels to any attempt to infer coefficient sparsity from root-square structure.

## Franel / modular coordinate

The CFVMZ proof uses the rational coordinate

```text
t = x(1-8x)/(1+x) = x + O(x^2)                    (7.9)
```

and the Franel-type square representation behind the Apery series. Because the linear term in (7.9) is 1, substitution

```text
F(t) -> F(t(x))                                    (7.10)
```

is a triangular automorphism of every truncated power-series ring. In particular

```text
[x^n]F(t(x)) = [t^n]F(t) + a linear combination
               of lower t-coefficients.            (7.11)
```

Hence K zero coefficients in the t-coordinate become K independent triangular linear conditions in the x-coordinate; they do not become K zero coefficients of the Franel polynomial or K roots of anything.

**Verdict for a formal modular/Franel coordinate gain: REFUTED.** Any gain must exploit arithmetic of the particular Franel coefficients, not the coordinate change or the square structure.

# 8. What a successful theorem now has to say

Combining Sections 2--7, the surviving target can be stated without carriers.

## High-multiplicity tail theorem (equivalent to SFT)

For

```text
K_N = max(1, floor(log N/(loglog N)^2)),
```

prove

```text
sum_{N<q<=2N, q prime}
  sum_{eps=0,1}
    ( z_{q,eps}(N) - K_N )_+

 = o(N/loglog N).                                  (8.1)
```

This is exactly equivalent to SFT by (2.5).

A strong but very natural sufficient theorem is the selected second moment

```text
sum_{N<q<=2N}
  sum_{eps=0,1} binom(z_{q,eps}(N),2)

 = o(N log N/(loglog N)^3).                        (8.2)
```

A random/Poisson-strength `O(N/log N)` bound would be far stronger than necessary.

At the gcd level, (8.2) is exactly

```text
sum_{1<=r<s<N, r==s (mod 2)}
 log Rad_(N,2N] gcd(b_r, N_{s-r}(r))

 = o(N (log N)^2/(loglog N)^3)                    (8.3)
```

after restoring the `log q` weight.

This is the clean average-gcd theorem to attack.

What will **not** suffice without an additional new arithmetic input:

1. another fixed pair/triple resultant product;
2. another fixed exterior power of the rank-two transfer state;
3. the formal threshold/minor geometry of the `x_D` alone;
4. the CFVMZ square factorization as a root-multiplicity statement;
5. the Franel coordinate substitution by itself.

The needed new ingredient is an arithmetic anti-coexistence theorem saying that, averaged over `q`, the selected base zero `q|b_r` very rarely coexists with `K_N` or more same-parity returns.

That is not currently proved by the banked inputs.
