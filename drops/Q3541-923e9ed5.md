# P3.2 — determinant-line audit of the cross-slope gap charge

## Verdict

There **is** an exact exterior-line formula for the row wedge, but it is **not** just the determinant of the bare recurrence transfer from `j` to `p-1-j`.

For the scan normalization, write

```text
R7 = p  - X7,
R4 = 2p - X4,
n7(t) = sigma7 + 7t,
n4(u) = sigma4 + 4u.
```

Define

```text
beta_R(t) := (-1)^(R-t) * (t+1-2R) * binom(R,t).
```

At the first hit the raw selector factors are

```text
binom(-X7,R7) = 1  (mod p),
binom(-X4,R4) = 1  (mod p),
```

so the two scalar factors actually computed by `q32_cross_slope_gap_charge_scan.py` are

```text
G7(p,j;H)
 = sum_{t=0}^{R7} beta_R7(t) b_(sigma7+7t),

G4#(p,j;H)
 = sum_{u=u0}^{R4} beta_R4(u) b_(sigma4+4u-p),

u0 := ceil((p-sigma4)/4).
```

All congruences in this answer are modulo `p` unless stated otherwise. The scan determinant is exactly

```text
det_bc = G7 * G4#.
```

If, as in the question, the determinant line is normalized by

```text
W_j(b,c) = b_(j-1)c_j - c_(j-1)b_j = 1/j^3,

det_bc = U_(p,j) * W_j(b,c),
```

then the explicit row-wedge scalar is

```text
boxed:
U_(p,j;H) = j^3 G7(p,j;H) G4#(p,j;H)  (mod p).
```

This is the exact formula in the current scan normalization.

The proposed bare transfer determinant is only one ingredient in a point-evaluation minor. It does **not** equal `U_(p,j)` because each `C_s` is a long Newton-gap functional, not a single point evaluation. In exterior algebra, the wedge of two sums is a sum of two-point transfer minors, not one transfer determinant.

There is also a sign correction: for the recurrence state

```text
V_n = (y_n,y_(n-1))^T,
```

the normalized Apéry transfer matrix has

```text
det M_n = + n^3/(n+1)^3,
```

not the negative of this quantity. Thus the bare product in the question telescopes to

```text
prod_{n=j+1}^{p-2-j} det M_n
 = ((j+1)/(p-1-j))^3
 = -1 (mod p),
```

because `p-1-j = -(j+1) mod p`. If one inserts an extra minus sign at every step, the interval has odd length and the answer becomes `+1`. Neither value agrees with the actual row wedge in general.

The smallest exact fixture already disproves the bare-transfer identification:

```text
(p,j,H)=(19,8,0):
    det_bc = 13,
    W_8 = 1/8^3 = 18,
    U_(19,8) = 13 / 18 = 6   (mod 19).
```

So `U_(19,8)=6`, whereas the bare transfer product is `18` (or `1` with the extra-sign convention).

Accordingly, the 46/46 scan has **not yet been converted into an automatic telescoping proof**. The exact theorem still needed is the nonvanishing of the two Newton-row symbols `G7` and `G4#` (or directly of their product) for every q=6 valuation-one target.

# 2. First correction: the recurrence transfer determinant has positive sign

With

```text
V_n = [y_n, y_(n-1)]^T,
```

the recurrence gives

```text
V_(n+1) = M_n V_n,

M_n = 1/(n+1)^3 *
      [[P(n),       -n^3],
       [(n+1)^3,       0]].
```

Therefore

```text
det M_n
 = 0 - (-n^3/(n+1)^3)
 = n^3/(n+1)^3.
```

For `a<b`,

```text
Phi(b <- a) := M_(b-1) ... M_a
```

satisfies

```text
det Phi(b <- a) = (a/b)^3.
```

For the interval written in the question,

```text
n=j+1,...,p-2-j,
```

we get

```text
Dtr
 = prod n^3/(n+1)^3
 = ((j+1)/(p-1-j))^3.
```

Modulo `p`,

```text
p-1-j = -(j+1),
```

so

```text
boxed: Dtr = -1 mod p.
```

This is certainly a p-unit, but it is **not** the cross-slope row wedge.

Why not? Because `Dtr` is the area-scaling factor for **one common state transfer**. The two gap charges are different linear combinations of many point evaluations along two different arithmetic progressions. Their relative orientation contains extra data which `det Phi` does not see.

# 3. Expand the mass-two charge as an explicit row

For a sampled solution

```text
y_t^(s) = y_(sigma_s+s t),
d_k^(s) = Delta^k y_0^(s),
```

the scan uses

```text
C_s(y)
 = U_(s,R) [R d_(R-1) + (1-R)d_R].
```

Now

```text
Delta^R y_0
 = sum_{t=0}^R (-1)^(R-t) binom(R,t)y_t.
```

For `t<R`,

```text
R (-1)^(R-1-t) binom(R-1,t)
 = -(-1)^(R-t)(R-t)binom(R,t).
```

Adding the `(1-R)Delta^R` term gives the coefficient

```text
(-1)^(R-t)
[(1-R)-(R-t)] binom(R,t)
 = (-1)^(R-t)(t+1-2R)binom(R,t).
```

The same formula also works at `t=R`, because it becomes `1-R`. Hence exactly

```text
boxed:
beta_R(t)
 = (-1)^(R-t)(t+1-2R)binom(R,t),

C_s(y)
 = U_(s,R)
   sum_{t=0}^R beta_R(t)y_(sigma_s+s t).
```

This is the actual charge covector. It is a long row, not a coordinate projection at the seam.

# 4. The selector factor at the first hit is exactly 1 modulo p

For slope 7,

```text
X7+R7=p.
```

Therefore

```text
U_(7,R7)
 = binom(-X7,R7)
 = (-1)^R7 binom(p-1,R7)
 = 1 mod p,
```

because

```text
binom(p-1,R) = (-1)^R mod p.
```

For slope 4,

```text
X4+R4=2p,
```

and `R4<p`, so Lucas gives

```text
U_(4,R4)
 = (-1)^R4 binom(2p-1,R4)
 = (-1)^R4 binom(p-1,R4)
 = 1 mod p.
```

Thus **no hidden selector scalar remains** in the first-hit determinant. All nontriviality sits in the two long charge rows.

# 5. Exact slope-4 Bockstein/desingularized row

Let

```text
n4(u)=sigma4+4u.
```

The scan substitutes the exact first-seam law

```text
p^3 c_n = 0              mod p,  n<p,
p^3 c_(p+q) = b_q        mod p,  0<=q<p.
```

Set

```text
u0 := min{u : sigma4+4u >= p}
    = ceil((p-sigma4)/4).
```

Since the physical first hit is

```text
sigma4+4R4 = 2p-1-j,
```

for `u0<=u<=R4` the shifted index

```text
q_u := sigma4+4u-p
```

lies in

```text
0 <= q_u <= p-1-j < p.
```

Consequently the exact transverse slope-4 scalar is

```text
boxed:
G4#(p,j;H)
 = p^3 C_4(c)
 = sum_{u=u0}^{R4}
     beta_R4(u) b_(sigma4+4u-p)
   mod p.
```

This explains why the Q3527 auxiliary-prime denominators never enter this scan: the high-block companion is replaced immediately by a first-block Apéry value.

There is a useful module interpretation. Let

```text
W_j(b,c)
 = b_(j-1)c_j-c_(j-1)b_j
 = 1/j^3,
```

and define the companion-coordinate dual functional

```text
B_j(y)
 := [b_(j-1)y_j-b_j y_(j-1)] / W_j(b,c).
```

Then

```text
B_j(b)=0,
B_j(c)=1.
```

The singular block law says that, on the associated graded,

```text
p^3 ev_(p+q) = b_q B_j.
```

Therefore

```text
boxed:
C4# = G4# * B_j.
```

The slope-4 regularized row is rank one and points exactly in the dual direction transverse to the distinguished Apéry line.

# 6. Exact slope-7 row and determinant

All slope-7 first-hit indices are below `p`:

```text
sigma7+7R7 = p-1-j < p.
```

Hence

```text
boxed:
G7(p,j;H)
 := C_7(b)
 = sum_{t=0}^{R7}
     beta_R7(t)b_(sigma7+7t)
   mod p.
```

The associated-graded charge matrix in the `(b,c)` columns is exactly

```text
[ C7(b)    C7(c) ]
[   0       G4#  ].
```

Therefore

```text
boxed:
det_bc
 = G7 G4#
 mod p.
```

Using the question's normalization

```text
det_bc = U_(p,j) W_j(b,c),
W_j=1/j^3,
```

gives

```text
boxed:
U_(p,j;H)
 = j^3
   [sum_{t=0}^{R7}
      beta_R7(t)b_(sigma7+7t)]
   [sum_{u=u0}^{R4}
      beta_R4(u)b_(sigma4+4u-p)]
   mod p.
```

This is the requested explicit determinant-line formula.

It is basis-independent in the expected sense: changing from `(b,c)` to any other basis multiplies the evaluation determinant and the Casoratian by the same determinant, leaving `U_(p,j)` unchanged. But it is **not** merely the determinant of a bare state-transfer product. It contains the two endpoint Newton covectors.

# 7. Exterior-algebra form: where the telescoping determinants really occur

Let `E_n^(j)` be the row functional which evaluates `y_n` from the state at `j`. On a regular interval it is obtained from the transfer matrix:

```text
E_n^(j) = e1^T Phi(n <- j)
```

(with the inverse transport used when `n<j`). Then

```text
C7
 = sum_t beta_R7(t) E_(n7(t))^(j).
```

Before reducing at the singular seam, the slope-4 row has the analogous sum. Therefore

```text
C7 wedge C4#
 = sum_{t,u}
     beta_R7(t) beta_R4(u)
     [E_(n7(t))^(j) wedge E#_(n4(u))^(j)].
```

This is the precise location of the transfer determinants. Each **two-point minor** contains the determinant scaling of a recurrence transport. But the full row wedge is a weighted sum of those minors.

For two ordinary point evaluations `a<b<p`, the pushed Green identity gives

```text
b_a c_b-c_a b_b
 = V_(b-a)(a+1)/(a+1)^3
```

or equivalently the long-gap continuant formula. Thus each point-evaluation wedge is a Green/continuant coefficient times the telescoping determinant. There is no identity in the current source that collapses the whole double sum to one transfer determinant.

After the `p^3` seam regularization the double sum collapses in a different way:

```text
p^3(b_a c_(p+q)-c_a b_(p+q))
 = b_a b_q mod p,
```

because `c_a` is p-integral and

```text
p^3 c_(p+q)=b_q mod p.
```

That factorization is exactly what produces `G7*G4#` above.

So the correct conceptual picture is

```text
bare transfer determinant:        telescoping p-unit
        +
Newton endpoint row 7:            nontrivial scalar G7
        +
Bockstein/Newton endpoint row 4:  nontrivial scalar G4#
        =
full row wedge U_(p,j).
```

The first line is automatic. The last two are not.

# 10. What remains to prove for an all-prime theorem

The determinant-line reduction is useful, but the automatic p-unit proof does **not** stop at the telescoping transfer determinant.

The exact remaining theorem is

```text
For every q=6 valuation-one target (p,j,H),

G7(p,j;H) != 0 mod p,
G4#(p,j;H) != 0 mod p.
```

Equivalently,

```text
U_(p,j;H) != 0 mod p.
```

The 46/46 computation is evidence for exactly this statement.

A promising next symbolic attack is now sharply defined: prove the two row symbols above are nonzero, preferably by rewriting each as a short Green/continuant value at the common endpoint `p-1-j`. If one can show

```text
G7 = unit * K7(p,j),
G4# = unit * K4(p,j),
```

where `K7,K4` are explicit restart continuants whose zeros would force a forbidden consecutive Apéry zero or one of the already-classified low-height gap polynomials, then the scan can be replaced by a theorem.

But the bare identity

```text
det Phi = telescoping p-unit
```

by itself does not prove this. It controls area transport **after the two covectors are specified**; it does not prove those covectors are transverse.

## Bottom line

```text
1. det M_n = +n^3/(n+1)^3.
2. The proposed transfer product is a p-unit, in fact -1 mod p.
3. It is NOT U_(p,j).
4. The exact scan-normalized row wedge is

   U_(p,j;H)
    = j^3 G7(p,j;H) G4#(p,j;H) mod p,

   with the two explicit binomial/Apéry sums above.
5. At (19,8,0): det_bc=13, U=6, not +/-1.
6. At (17,3,0): det_bc=15, U=14, not +/-1.
7. Therefore the 46/46 p-unit phenomenon still requires a genuine
   nonvanishing theorem for the two Newton endpoint rows; it is not an
   automatic consequence of the telescoping determinant line.
```
