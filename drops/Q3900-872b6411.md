# 3. Claim (ii): occurrence injectivity and repeated upper-state pairs

A frozen charge occurrence is the tuple

```text
c = (n,p,q_i,q_j),
q_i < q_j,
```

where `(n,p,q_j)` is the distinguished final edge and `(n,p,q_i)` is one of its selected earlier actual witnesses.

For fixed `(n,p,q_i,q_j)`, both physical plus edges are uniquely reconstructed. Therefore the map

```text
c -> ((n;q_i,q_j), p)                                       (3.1)
```

is injective.

The map

```text
c -> (n;q_i,q_j)                                             (3.2)
```

is **not** injective in general. The same ordered upper-state pair can be shared by two or more different lower primes `p_1,p_2,...`. This is exactly the same-row plus-rectangle phenomenon already isolated in Q3886.

That failure does not invalidate the radical payment. For every actual upper state define a squarefree lower-shell radical `R^+_(n,q)`. If the same ordered pair is charged at distinct lower primes

```text
p_1, ..., p_s,
```

then each `p_r` divides both radicals and the primes are distinct. Hence

```text
p_1 ... p_s | gcd(R^+_(n,q_i), R^+_(n,q_j)),                (3.3)
```

so

```text
sum_{r=1}^s log p_r
 <= log gcd(R^+_(n,q_i), R^+_(n,q_j)).                       (3.4)
```

Equivalently, in unweighted normalization,

```text
s <= omega_Plow(gcd(R^+_(n,q_i), R^+_(n,q_j))).              (3.5)
```

On the fixed macroscopic shell, `(3.4)` and `(3.5)` differ only by a factor comparable to `L`.

Thus the correct global charge is

```text
sum_{charge occurrences c} log p(c)
 <= sum_{distinct selected (n;q_i,q_j)}
      log gcd(R^+_(n,q_i), R^+_(n,q_j)).                     (3.6)
```

The right side sums one gcd per distinct ordered upper pair; that one gcd simultaneously pays every distinct lower-prime charge above the pair.

There is no collision at fixed `p`: once `(n,p,q_i,q_j)` is fixed, the charge is fixed. Therefore no higher `p`-adic power is needed to pay two occurrences with the same `p` above one pair.

# 6. Claim (v): exact raw-plus radical and gcd log payment

## 6.1 Exact plus-legality interval

Fix an actual upper state `(n,q)` and put

```text
u := n-6q,
0 <= u < q,
q | b_u.
```

For a candidate lower prime `p`, define

```text
r := n-6p,
z := p-1-r = 7p-1-n,
a := n+6q-13p.                                               (6.1)
```

The four lower digit inequalities

```text
0 <= r < p,
0 <= z < p,
0 <= a < p
```

are equivalent to the single interval

```text
n/7 < p <= (n+6q)/13.                                        (6.2)
```

Indeed:

```text
z>=0       <=> p>(n/7),
a>=0       <=> p<=(n+6q)/13,
```

while `p>n/7` implies `a<p` because `u=n-6q>=0`, and the upper bound in `(6.2)` implies `r>=0` and `z<p`. Also

```text
(n+6q)/13 = (12q+u)/13 < q,
```

so `p<q` is automatic.

## 6.2 Correct exact radical

For all sufficiently large `T`, lower-shell primes do not divide the two fixed integers `b_6 b_13`. Equivalently, one may explicitly remove the finite exceptional set of prime divisors of `b_6b_13`.

Define

```text
R_raw^+(n,q)
 := product of lower-shell primes p satisfying

      n/7 < p <= (n+6q)/13,
      p | b_n,
      p | b_(n+6q),

    together with any already-fixed deterministic outer filters.          (6.3)
```

This product is squarefree.

For a nonexceptional lower-shell prime `p`,

```text
p | R_raw^+(n,q)
```

implies an actual raw plus leaf:

- write `n=6p+r` with `0<=r<p`; Apéry Lucas gives
  ```text
  b_n == b_6 b_r (mod p),
  ```
  so `p|b_r`;
- reflection gives `p|b_(p-1-r)=b_z`;
- write `n+6q=13p+a` with `0<=a<p`; Lucas gives
  ```text
  b_(n+6q) == b_13 b_a (mod p),
  ```
  so `p|b_a`;
- the fixed upper state supplies `q|b_u`;
- `(6.1)` gives `z+a+1=6(q-p)`.

Conversely, an actual raw plus leaf has `p|b_z,b_a`; reflection and Lucas give

```text
p | b_n,
p | b_(n+6q),
```

and its legal digits put `p` in `(6.2)`. Therefore

```text
p | R_raw^+(n,q)
iff
(n,p,q) is a raw-legal actual plus leaf                  (6.4)
```

apart from the fixed finite exceptional primes and whatever explicitly stated deterministic filters are intentionally omitted.

## 6.3 Why the bare radical has no converse

The simpler radical

```text
R_over^+(n,q)
 := rad_Plow gcd(b_n,b_(n+6q))                              (6.5)
```

is always a safe overcarrier, but it may contain a lower-shell prime outside `(6.2)`. For such a prime the two Lucas residues need not be legal plus digits. Therefore

```text
p | R_over^+(n,q) => raw plus leaf
```

is false.

This distinction is load-bearing for the third-moment comparison in Section 7. It is not needed merely for the one-way payment of already known actual charges.

## 6.4 Exact gcd payment

For two actual upper states in the same row, `q_1<q_2`, the exact radicals satisfy

```text
log gcd(R_raw^+(n,q_1),R_raw^+(n,q_2))
 = sum log p over lower-shell primes p for which
   (n,p,q_1) and (n,p,q_2) are both raw plus leaves.           (6.6)
```

Thus every selected actual charge above the pair is paid once. Repeated upper-pair occurrences at distinct lower primes are all paid simultaneously by their distinct factors in the gcd.

If the overcarrier `(6.5)` is used instead, equality in `(6.6)` becomes the safe inequality

```text
selected charge log mass
 <= log gcd(R_over^+(n,q_1),R_over^+(n,q_2)).                 (6.7)
```

**Audit of (v): PASS for `(6.3)`; REFUTE the converse for the bare radical `(6.5)`.**

The minimal correction is to insert the interval `(6.2)` into the radical support. No other change is needed.

# 7. Claim (vi): exact third-moment comparison

Define the vertical third factorial zero moment on the lower shell by

```text
B3(T) := sum_p (Z(p))_3
```


```text

a_2 := n+6q_2-13p.                                           (7.2)
```

They are pairwise distinct:

- `a_1<a_2` because `q_1<q_2`;
- `z=a_i` is impossible because
  ```text
  z+a_i+1 = 6(q_i-p)
  ```

  has an even right side and an odd left side when `z=a_i`.

The map

```text
(n,p,q_1,q_2) -> (p,z,a_1,a_2),  with a_1<a_2,               (7.3)
```

```text

q_i = (13p+a_i-n)/6.                                         (7.4)
```

For one `p`, the number of triples with distinguished `z` and unordered remaining pair `a_1<a_2` is

```text
Z(p) binom(Z(p)-1,2) = (Z(p))_3/2.
```

Consequently the total unweighted common-factor occurrence mass, over **any** family of once-oriented pairs `q_1<q_2`, satisfies


For the fully ordered convention `q_1!=q_2`, the right side is `B3(T)`.

The logarithmic version is


Thus the exact sufficient third-moment estimate for an `o(B0)` final-edge bound is
