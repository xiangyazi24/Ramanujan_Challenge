# Half-cutoff large-prime support audit

## 1. Setup

Let
\[
 n=qp+r,
\quad 0\le r<p,
\quad q<p,
\quad M=\lfloor n/2\rfloor,
\]
and
\[
 L_j=(-1)^{M-1-j}\binom nj\binom{n-j-1}{M-1-j}.
\]
For \(p^2>n\), the first binomial has no two-digit carries, so Kummer gives
\[
v_p\binom nj=\#\{\text{borrows in }j+(n-j)=n\}=0
\]
precisely when the base-p digits of \(j\) are bounded digitwise by those of \(n\).
The second binomial contributes the same type of condition for
\[
j+(M-1-j)=M-1.
\]
Hence
\[
p\nmid L_j
\]
iff both additions are carry-free.

## 2. The exact unit set U

Write \(n=qp+r\).

For the second addition use the base-p expansion of \(M-1\).

### Case q=2Q

Here
\[
M=Qp+\lfloor r/2\rfloor.
\]
Thus
\[
M-1=Qp+s,
\qquad s=\lfloor r/2\rfloor-1.
\]
The unit indices satisfy
\[
0\le j_0\le r,
\qquad j_1\le Q,
\]
where \(j=j_1p+j_0\), together with
\[
j<M=Qp+\lfloor r/2\rfloor .
\]
The endpoint condition forces
\[
 j_1<Q\quad\text{or}\quad (j_1=Q,\,j_0<\lfloor r/2\rfloor).
\]
Therefore
\[
U=\{j_1p+j_0:0\le j_1<Q,0\le j_0\le r\}
\cup
\{Qp+j_0:0\le j_0<\lfloor r/2\rfloor\}.
\]

### Case q=2Q+1

Now
\[
M=Qp+\frac{p+r-1}{2}.
\]
Put
\[
t=(p+r-1)/2.
\]
Then the carry-free conditions give
\[
0\le j_1\le Q,
\]
and
\[
 j_0\le r
\]
from the first binomial. The endpoint \(j<M\) removes the upper slice.
Hence
\[
U=\{j_1p+j_0:0\le j_1<Q,0\le j_0\le r\}
\cup
\{Qp+j_0:0\le j_0<t\}.
\]
Since \(t>r/2\), the second interval is always nonempty; the boundary cases \(r=0,1\) are included with the same formula.

These are the complete Kummer strata.

## 3. Consequence for Gamma

Because
\[
\Gamma_n=\gcd_{j<M}L_jb_j,
\]
we have
\[
p\mid\Gamma_n
\iff
b_j\equiv0\pmod p
\quad\forall j\in U.
\]
Using Lucas for Apéry numbers,
\[
b_{ap+s}\equiv b_ab_s\pmod p.
\]
Therefore every element of U reduces to products of the finite set
\[
\{b_a:0\le a\le q\}\cup\{b_s:0\le s\le r\}.
\]
In particular, the proposed simplification
\[
p\mid\Gamma_n\iff q\text{ odd and }p\mid b_r
\]
is not a consequence of Lucas alone. It requires the additional fact that the unit stratum contains an index with residue 0 and quotient 1 exactly when q is odd, while all other factors remain units. Without that extra nonvanishing theorem it is not proved.

## 4. D_n comparison

For
\[
D_n=\gcd_{j<M}L_j(b_n-b_j),
\]
we similarly obtain
\[
p\mid D_n
iff
b_n\equiv b_j\pmod p\quad\forall j\in U.
\]
Lucas gives
\[
b_n=b_qb_r\pmod p.
\]
Thus the exact condition is
\[
 b_qb_r=b_ab_s
\]
for every pair \((a,s)\) represented by U.
This is stronger than the Gamma condition.

The exceptional alternative is therefore:

\[
p\mid\Gamma_n\text{ but }p\nmid D_n
\]
can occur if all allowed \(b_j\) vanish but the difference conditions fail, or if the unit stratum contains several nonzero Lucas products with unequal values.

No simplification to identical supports follows from the triangle identity alone.

## 5. Correct large-prime lemma needed

A valid theorem would require:

**Lemma.** For every prime \(p\ge7\) with \(p^2>n\), and every Kummer unit stratum U above, the set
\[
\{b_j:j\in U\}
\]
has the same zero/nonzero pattern as \(b_n\).

Equivalently:

1. if \(b_n\not\equiv0\), some unit index has \(b_j\not\equiv0\);
2. if \(b_n\equiv0\), all unit indices satisfy \(b_j\equiv0\).

This is the missing Apéry-specific p-adic statement. It cannot be replaced by Lucas alone.

## 6. Audit conclusion

The Kummer derivation gives explicit U and reduces the problem to finitely many Apéry residues. The statement that Gamma support is exactly “q odd and p divides b_r” is not proved from the stated hypotheses; it requires a further theorem about the zero set of Apéry residues across the Kummer unit strata.

Likewise D and Gamma support agreement for all large odd primes is an additional prime-power theorem, not a formal gcd consequence. The remaining task is precisely this uniform Lucas-Dwork/Kummer compatibility lemma.
