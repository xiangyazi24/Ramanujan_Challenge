# Exact Hecke-iteration audit for the fixed-n form

No finite scan is used below.

```text
Notation.

x := exp(2*pi*i*tau)                    # modular q-variable
p >= 5 prime, p not dividing 6
n = Q*p + r
Q = floor(n/p) >= 1
0 <= r <= p-1

f := Omega_n
   = E(x) * (D t(x)/t(x)) * t(x)^(-n)
   = sum_{m >= -n} a_m x^m

weight(f) = 4.

t(x) = x*w(x),
w(x) = 1 - 12*x + 66*x^2 - 220*x^3 + ... in 1+x*Z[[x]].
```

## 1. Hecke operators, diamonds, and negative Laurent exponents

```text
For f in M_k^!(Gamma_1(6)) and p not dividing 6, use the standard
normalized good-prime operator

T_p = U_p + p^(k-1) * V_p * <p>,

where

U_p(sum_m a_m x^m) = sum_j a_(p*j) x^j,
V_p(sum_m a_m x^m) = sum_m a_m x^(p*m).

The formula is valid for finite principal parts as well as holomorphic
q-series: the root-of-unity filter

(1/p) * sum_{a=0}^{p-1} exp(2*pi*i*m*a/p)

is 1 if p|m and 0 otherwise for every integer m, positive or negative.

For f = Omega_n we in fact have

f in M_4^!(Gamma_0(6))

with trivial Nebentypus. Hence every good-prime diamond fixes f:

<p> f = f,
<p^2> f = f.

Therefore, on this particular f,

T_p f = U_p f + p^3 V_p f.                              (1.1)
```

```text
Let Pi_p := V_p U_p, the projection onto exponents divisible by p:

[x^m] Pi_p f = a_m if p|m,
               0   otherwise.

Then

U_p V_p = 1,
V_p U_p = Pi_p.

For weight 4 and trivial diamond,

T_(p^2) f
 = U_p^2 f + p^3 Pi_p f + p^6 V_p^2 f,                  (1.2)

and

T_p^2 f = T_(p^2) f + p^3 f.                            (1.3)

Equivalently, before restricting to the trivial-diamond subspace,

T_p^2 = T_(p^2) + p^3 <p>.                              (1.4)

Thus the normalization in the question is exactly correct at weight 4.
```

```text
Coefficient formulas, valid for every integer m:

[x^m] T_p f
 = a_(p*m) + p^3 * 1_(p|m) * a_(m/p).                   (1.5)

[x^m] T_(p^2) f
 = a_(p^2*m)
   + p^3 * 1_(p|m) * a_m
   + p^6 * 1_(p^2|m) * a_(m/p^2).                       (1.6)

These formulas include m<0 without alteration.
```

## 2. Top and neighboring principal-part coefficients

Assume first the hard Q7597/Q7601 triangular range

```text
Q < p.
```

This follows in particular from `p > n^(2/3)`.

Define

```text
u_j := [x^(-Q+j)] U_p f
     = a_(-p*(Q-j)),

0 <= j <= Q.                                             (2.1)
```

Then `u_0` is the top principal-part coefficient and `u_Q=a_0` is the constant term.

From Q7601,

```text
u_0 = a_(-p*Q) == b_r                                  (mod p).   (2.2)
```

For every negative exponent `-Q+j`, `0 <= j < Q`, one has

```text
0 < Q-j < p,

so p does not divide Q-j.  Hence the V_p term in (1.5) is absent:

[x^(-Q+j)] T_p f = u_j                                 over Z.    (2.3)
```

At the constant term,

```text
[x^0] T_p f = (1+p^3) a_0.                              (2.4)
```

## 3. The neighboring coefficient is not independent

For integers `M,s >= 0`, put

```text
c_(M,s) := [X^s] w(X)^M.

c_(M,0) = 1,
c_(M,1) = -12*M.                                        (3.1)
```

For `0 <= j <= Q`, the exact coefficient identity

```text
b_(r+p*j) = CT_x( f * t(x)^(p*(Q-j)) )                 (3.2)
```

and Frobenius

```text
t(x)^p == t(x^p)                                       (mod p)   (3.3)
```

give, because `r<p`,

```text
b_(r+p*j)
 == sum_{s=0}^j c_(Q-j,s) * u_(j-s)                    (mod p).  (3.4)
```

There are no terms with `s>=j+1`: their x-exponent is at least

```text
p*(Q-j+j+1) = p*(Q+1) > p*Q+r = n,
```

outside the principal part of `f`.

Since `j<Q<p`, Apéry-Lucas gives

```text
b_(r+p*j) == b_j * b_r                                  (mod p). (3.5)
```

Combining (2.2), (3.4), and (3.5) yields the triangular recursion

```text
u_j
 == b_j*u_0 - sum_{s=1}^j c_(Q-j,s)*u_(j-s)            (mod p). (3.6)
```

Thus every coefficient of the entire nonpositive principal part of `U_p f`
is in the one-dimensional span of the single atom `u_0`.

For `j=1`, (3.6) is explicit:

```text
b_(p+r)
 == u_1 - 12*(Q-1)*u_0                                 (mod p),

b_(p+r) == b_1*b_r = 5*b_r == 5*u_0                    (mod p),

therefore

u_1 == (12*Q - 7)*u_0                                  (mod p). (3.7)
```

Hence

```text
u_0 == 0 (mod p)
  => u_1 == 0 (mod p),                                  (3.8)
```

but (3.8) is not a second constraint: it is a scalar multiple of the same
rank-one condition.

In fact, induction in (3.6) gives the stronger statement

```text
u_0 == 0 (mod p)
  => u_j == 0 (mod p) for every 0 <= j <= Q.            (3.9)
```

Equivalently,

```text
p | b_r
  => U_p Omega_n has zero principal part AND zero constant term mod p.
                                                                    (3.10)
```

By (1.1), the same is true for `T_p Omega_n` modulo p.

This is a complete rank-one collapse, not an independent first jet.

## 4. Why dividing the neighboring relation by p does not create a jet

Define the integral Frobenius defect

```text
F_p(x) := ( t(x)^p - t(x^p) ) / p.                      (4.1)
```

Freshman's dream makes `F_p(x)` integral.  Since

```text
t(x) = x - 12*x^2 + ...,
```

the leading x^p term cancels and

```text
F_p(x) in x^(p+1) Z[[x]],
[x^(p+1)] F_p = -12.                                    (4.2)
```

Modulo `p^2`, for every integer `M>=1`,

```text
t(x)^(p*M)
 = (t(x^p) + p*F_p(x))^M
 == t(x^p)^M
    + p*M*t(x^p)^(M-1)*F_p(x)                          (mod p^2). (4.3)
```

Put

```text
C_0 := CT_x( f * t(x^p)^(Q-1) * F_p(x) ).              (4.4)
```

Then

```text
b_r
 == u_0 + p*Q*C_0                                      (mod p^2). (4.5)
```

Because of (4.2), `C_0` uses only the off-grid principal coefficients

```text
a_(-p*Q-s),  1 <= s <= r.                              (4.6)
```

For `Q>=2`, put

```text
C_1 := CT_x( f * t(x^p)^(Q-2) * F_p(x) ).              (4.7)
```

Then

```text
b_(p+r)
 == u_1 - 12*(Q-1)*u_0
    + p*(Q-1)*C_1                                      (mod p^2). (4.8)
```

For `Q=1`, (4.8) is simply the exact identity

```text
b_(p+r) = a_0 = u_1,                                   (4.9)
```

so the last term is absent.

For `Q>=2`, `C_1` uses principal coefficients at offsets

```text
1 <= s <= p+r                                           (4.10)
```

from the grid point `-p*(Q-1)`.  Thus it imports a block of size Theta(p)
in the worst case.

Subtracting `5*(4.5)` from (4.8) gives

```text
D_1 := u_1 - (12*Q-7)*u_0.

D_1
 == b_(p+r) - 5*b_r
    - p*(Q-1)*C_1 + 5*p*Q*C_0                          (mod p^2). (4.11)
```

Both `D_1` and `b_(p+r)-5*b_r` are divisible by p.  Hence the divided
first-jet candidate satisfies

```text
D_1/p
 == (b_(p+r)-5*b_r)/p
    - (Q-1)*C_1 + 5*Q*C_0                              (mod p).  (4.12)
```

Formula (4.12) is the precise obstruction:

```text
The divided neighboring coefficient is NOT determined by u_0 mod p.
It contains

  (i) the Apéry Lucas quotient (b_(p+r)-5*b_r)/p,
  (ii) the Frobenius-defect term C_0,
  (iii) the Frobenius-defect term C_1,

and C_0,C_1 involve off-p-grid principal coefficients extending over
an index interval of length up to Theta(p).
```

Therefore no divided first jet modulo p follows from the Hecke algebra alone.
A proof of such a jet would require genuine mod-p^2 Dwork/Lucas information,
not the weight-4 Hecke relation.

## 5. Iterating U_p in the hard range Q<p

Since

```text
Q < p
=> n = Q*p+r <= p^2-1,                                  (5.1)
```

we have

```text
U_p^2 f = sum_j a_(p^2*j) x^j
```

with no negative exponent at all:

```text
[x^(-h)] U_p^2 f = 0 for every h>=1.                    (5.2)
```

Thus the second U-iteration has already consumed the entire principal part,
independently of whether `b_r` vanishes.

At the constant term,

```text
[x^0] U_p^2 f = a_0 = b_n.                              (5.3)
```

Apéry-Lucas gives

```text
b_n == b_Q*b_r                                          (mod p). (5.4)
```

Therefore an atom `p|b_r` forces the constant term in (5.3) to vanish modulo
p, but again only through the same factor `b_r`.

## 6. T_p^2 and T_(p^2): exact negative coefficients

Assume `Q<p`.  For every integer `h` with

```text
1 <= h <= Q < p,
```

we have

```text
p does not divide h,
p^2*h > n.                                               (6.1)
```

Hence (1.6) gives the exact identity

```text
[x^(-h)] T_(p^2) f = 0.                                 (6.2)
```

Using the Hecke relation (1.3),

```text
[x^(-h)] T_p^2 f = p^3 * a_(-h).                        (6.3)
```

In particular,

```text
[x^(-Q)] T_(p^2) f = 0,
[x^(-Q)] T_p^2 f = p^3*a_(-Q),                          (6.4)
```

and, for `Q>=2`,

```text
[x^(-Q+1)] T_(p^2) f = 0,
[x^(-Q+1)] T_p^2 f = p^3*a_(-Q+1).                      (6.5)
```

Thus, modulo p and modulo p^2,

```text
T_p^2 f == U_p^2 f                                     (mod p^2),
T_(p^2) f == U_p^2 f                                   (mod p^2),

and every negative coefficient on both sides is identically 0 mod p^2.
                                                                    (6.6)
```

This happens whether or not `p|b_r`.

The first Hecke-algebra correction occurs only at order `p^3`:

```text
T_p^2 f - T_(p^2) f = p^3 f.                            (6.7)
```

Dividing (6.7) by p or by p^2 still gives 0 modulo p.  Dividing by p^3
merely returns the original form `f`; it does not create a new congruence
condition tied to the atom.

Hence there is no second mod-p or mod-p^2 constraint in the negative
principal part coming from `T_p^2=T_(p^2)+p^3<p>`.

## 7. What happens outside Q<p

For completeness, write

```text
Q = S*p + s,
0 <= s <= p-1.

Then

n = S*p^2 + s*p + r,
S = floor(n/p^2).                                       (7.1)
```

The top coefficient after two U-iterations is

```text
v_0 := [x^(-S)] U_p^2 f
     = a_(-p^2*S).                                      (7.2)
```

The same fixed-n Frobenius argument, now at scale p^2, gives

```text
v_0 == b_(s*p+r)                                        (mod p). (7.3)
```

Apéry-Lucas then gives

```text
b_(s*p+r) == b_s*b_r                                    (mod p),

so

v_0 == b_s*b_r                                          (mod p). (7.4)
```

Thus even when `Q>=p`, the iterated top coefficient is not independent of
the original atom: modulo p it contains the same factor `b_r`.

At modulus p^2, extracting more from (7.3) requires supercongruence data for
an Apéry index `s*p+r`, which is of scale p.  This is exactly the
``imports coefficients at index scale p'' obstruction.

In the Q7597 hard range `Q<p`, one has `S=0`, so this imported second digit
disappears and the second U-iteration has no negative principal part at all.

## 8. Endpoint r=0

```text
r=0
=> b_r=b_0=1.

From the top coefficient identity,

u_0 == 1 (mod p).                                       (8.1)
```

Therefore the vanishing hypothesis can never occur at `r=0`.

No endpoint correction is needed in any Hecke formula.

## 9. Endpoint r=p-1

For `1<=k<=p-1`,

```text
binom(p-1+k,k)
```

contains a factor p in the numerator and no factor p in `k!`.  Hence all
terms with `k>=1` in the Apéry sum for `b_(p-1)` vanish modulo p, while the
`k=0` term is 1.  Therefore

```text
b_(p-1) == 1 (mod p).                                   (9.1)
```

So the top coefficient cannot vanish at `r=p-1` either.

The only possible atom range is therefore

```text
1 <= r <= p-2.                                          (9.2)
```

The Frobenius truncation remains exact at `r=p-1`; it is simply never a
zero case.

## 10. Endpoint Q=1

Now

```text
n = p+r,
0 <= r <= p-1.
```

The first U-image has only one negative coefficient:

```text
u_0 = [x^-1] U_p f = a_-p == b_r                        (mod p). (10.1)
```

The neighboring coefficient is the constant term

```text
u_1 = a_0 = b_n.
```

Lucas gives

```text
u_1 = b_n == b_1*b_r = 5*b_r == 5*u_0                  (mod p). (10.2)
```

Thus top vanishing also kills the constant term modulo p, but supplies no
independent condition.

For the actual Hecke operator,

```text
[x^0] T_p f = (1+p^3)*a_0,                              (10.3)

[x^0] T_p^2 f = (1+p^3)^2 * a_0,                       (10.4)

[x^0] T_(p^2) f = (1+p^3+p^6) * a_0,                   (10.5)
```

and indeed

```text
(1+p^3)^2 - (1+p^3+p^6) = p^3,                         (10.6)
```

exactly matching (1.3).

Modulo p^2 all three constant terms reduce to `a_0`.  The atom gives only
`p|a_0`, not `p^2|a_0`.  Hence `Q=1` also produces no mod-p^2 second
constraint.

## 11. p=5 and p=7

```text
5 does not divide 6,
7 does not divide 6.
```

Therefore both are ordinary good Hecke primes for level 6.  Equations
(1.1)--(10.6) apply without modification.  The only exceptional Hecke primes
for the level are 2 and 3.

## 12. Scoped no-go

The exact outcome is:

```text
THEOREM (Hecke-iteration no-go for the Q7601 fixed-n carrier).

Let p>=5, p not dividing 6, n=Q*p+r, 0<=r<p, and let
f=Omega_n in M_4^!(Gamma_0(6)).

(A) If Q<p, then modulo p the entire nonpositive principal part of U_p f
    is rank one over the atom b_r:

      [x^(-Q+j)]U_p f == C_(Q,j)*b_r   (mod p),
      0<=j<=Q,

    for explicit integers C_(Q,j) determined recursively by (3.6).

(B) In particular,

      [x^-Q]U_p f == b_r,
      [x^(-Q+1)]U_p f == (12Q-7)b_r    (mod p).

    Thus the neighboring coefficient is not independent.

(C) Since weight(f)=4,

      T_p == U_p                                (mod p^2),
      T_p^2 == T_(p^2) == U_p^2                 (mod p^2).

    If Q<p, then U_p^2 f has no negative principal part at all.
    Therefore the relation

      T_p^2 = T_(p^2) + p^3<p>

    yields no second mod-p or mod-p^2 negative-coefficient condition.

(D) The first possible divided neighboring jet is (4.12).  It contains the
    mod-p^2 Lucas quotient and Frobenius-defect terms involving off-grid
    principal coefficients over an interval of length Theta(p).  It is not
    controlled by the Hecke algebra.

(E) If Q>=p, the second U-iteration reaches the next base-p quotient digit:

      [x^-floor(Q/p)]U_p^2 f
      == b_( (Q mod p)*p + r )
      == b_(Q mod p)*b_r                         (mod p).

    Thus iteration is still mod-p dependent on b_r; mod p^2 it imports
    Apéry data at index scale p rather than producing a local second jet.
```

```text
Conclusion.

The Hecke algebra does not provide a second independent constraint from the
vanishing of the Q7601 top principal-part coefficient.

In the hard triangular range Q<p:

  * the first neighboring coefficient is a scalar multiple of the same atom;
  * in fact the whole U_p principal part is rank one modulo p;
  * T_p^2 and T_(p^2) have no negative information modulo p^2 because their
    first difference is p^3*Omega_n;
  * a divided first jet necessarily leaves the Hecke algebra and enters the
    mod-p^2 Frobenius defect / Apéry-supercongruence problem.

So the exact next arithmetic input, if this route is continued, must be a
mod-p^2 theorem controlling

  (b_(p+r)-5*b_r)/p

simultaneously with the off-grid coefficients in (4.12), or an equivalent
Dwork/Cartier first-jet theorem.  The ordinary Hecke relations alone are
provably exhausted at rank one.
```
