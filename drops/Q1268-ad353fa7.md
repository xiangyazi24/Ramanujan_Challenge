# Verdict

There is an exact one-wrap reduction, but it is **not** the naive statement that the rows `r` and `p+r` simply duplicate.  The correct identity is

```text
U[p+r,k] = 2 U[r,k] - U[p-1-r,k]        (mod p),   0 <= k < p,
U[p+r,p+l] = U[r,l]                     (mod p).
```

For the Apéry data one simultaneously has

```text
b[p-1-r] = b[r]                         (mod p),
b[p+r]   = 5 b[r]                       (mod p).
```

Because every numerator in the growing family has `a < p/2` when `p>2A`, its values really do fold:

```text
P(tau(p+r)) = P(tau(r)) = P(tau(p-1-r))    (mod p).
```

The denominator does not.  Its `k=p+l` columns are exactly the missing degrees of freedom.

The main exact consequence is the following wrap-degeneracy theorem.

Let `H=p+d<2p`, `a<p/2`, and reduce the combined interpolation system modulo `p`.

* If `a>d`, then `deg Q=p+d-a<p`, hence there are no `k=p+l` denominator columns.  Every numerator reduction, including the reduction of the primitive combined pair, satisfies

```text
P(tau(r)) = 0   (mod p),     0 <= r <= d.               (W>)
```

This holds whether or not `b_r=0`.

* If `a<=d`, write the high denominator part as

```text
R(tau(r)) = sum_{0<=l<=d-a} q[p+l] U[r,l].
```

Then the projection of the **global** mod-`p` kernel to its numerator coordinates is exactly the intersection of two much smaller spaces:

```text
pi_P Ker(C[H,a] mod p)
 = N(d,a;p) intersect V(Z_p,a).                           (W<=)
```

Here `N(d,a;p)` is the numerator projection of the ordinary height-`d` Padé kernel

```text
P(tau(r)) = b_r Rtilde(tau(r)),  0<=r<=d,
deg P<=a, deg Rtilde<=d-a,
```

and `V(Z_p,a)` is the space of degree-at-most-`a` numerator polynomials vanishing on every folded zero class of `b_0,...,b_{p-1}`.

Thus the one-wrap problem recursively contains a height-`d` Padé problem.  This is the load-bearing algebraic fact.  In particular, the observation “the interval `[0,d]` occurs while the wrapped block is zero-free and disappears when the first zero lift enters” is **not a theorem from the zero pattern alone**.  A zero entering `0..d` changes `N(d,a;p)` and enlarges the raw mod-`p` kernel, but which vector is the primitive combined integral pair is then a Smith/saturation question.

I therefore do **not** promote the finite `p=17,19,31` pattern to a fully quantified common-root law.  I give below (i) the exact matrix reduction, (ii) a corrected conditional common-root theorem, (iii) an exact evaluation-specific Smith criterion for `p|F_n`, and (iv) the precise prime-distribution statement that would be needed for a linear-mass no-go or for an `o(H)` height proof.

This also explains why the older `p>H` zero-absorber theorem in `q32_pade_zero_absorber.py` / working-note Section 160 cannot simply be reused here: that proof explicitly uses that every relevant factorial is a `p`-unit and the interpolation nodes are ordinary distinct polynomial nodes.  In the present `H>p` range, the middle and `p+l` columns are exactly where that hypothesis fails.  The all-degree content theorem recorded later in Section 163 has the same `p>H` scope.

# 1. Exact reduction of `U` for `H=p+d<2p`

Assume throughout that `p` is odd.  Write rows as

```text
s=r,          0<=r<p,
s=p+r,        0<=r<=d,
```

and recall

```text
U[s,k] = C(s+k,2k).
```

## 1.1 Low columns: `2k<p`

For `0<=k< p/2`, Lucas gives

```text
U[r,k] =
  C(r+k,2k),    if k <= r <= p-1-k,
  0,            otherwise,                              (1.1)
```

and

```text
U[p+r,k] = U[r,k]  (mod p).                             (1.2)
```

Since `(2k)!` is a `p`-unit, `Phi_k(Y)` is an honest polynomial over `F_p`; therefore

```text
U[p-1-r,k] = U[r,k]  (mod p)                            (1.3)
```

as well, because `tau(p-1-r)=tau(r)`.

## 1.2 Middle columns: `p/2<k<p`

Put

```text
q = 2k-p,
j = p-1-k.
```

Thus `1<=q<=p-2` and `0<=j<(p-1)/2`.  For the base rows,

```text
U[r,k] =
  0,                         r<k,
  C(r+k-p,q),                r>=k.                       (1.4)
```

For a wrapped row,

```text
U[p+r,k] =
  C(r+k,q),                  0<=r<=j,
  0,                         j<r<k,
  2 C(r+k-p,q),              r>=k.                       (1.5)
```

The factor `2` in the last line is the Lucas high-digit factor `C(2,1)`.

Equations (1.4)-(1.5) can be compressed into the very useful identity

```text
U[p+r,k] = 2 U[r,k] - U[p-1-r,k]   (mod p)               (1.6)
```

for every `0<=k<p`.  For low columns this reduces to (1.2), because the reflected values agree.

## 1.3 Wrapped columns: `k=p+l`

For `0<=l<=d`, rows below `p` see no such column:

```text
U[r,p+l] = 0,                      0<=r<p,                (1.7)
```

while Lucas gives

```text
U[p+r,p+l] = U[r,l]                (mod p),               (1.8)
```

for `0<=r<=d`.  This remains true on both sides of `2l=p`; the carry cases vanish on both sides in the same way.

Hence, splitting rows and columns at `p`,

```text
U_H  =  [ U_(p-1)      0   ]
        [    B         U_d ]          (mod p),             (1.9)
```

where both diagonal blocks are lower unitriangular, and the rows of `B` satisfy

```text
B[r,*] = 2 U_(p-1)[r,*] - U_(p-1)[p-1-r,*].              (1.10)
```

Equivalently, for any coefficient vector supported in columns `<p`, if `f_s` denotes its values on the first `p` rows, then

```text
f_(p+r) = 2 f_r - f_(p-1-r)          (mod p).             (1.11)
```

This is the cleanest form of the triangular wrap.

### Symbolic check: `p=7`

Take the middle column `k=4`.  Then `q=1,j=2`.  The base and wrapped slices are

```text
r=0..6:  U[r,4]     = [0,0,0,0,1,2,3],
r=0..5:  U[7+r,4]   = [4,5,6,0,2,4]      (mod 7).
```

The second row is exactly `2 U[r,4]-U[6-r,4]`.  For `k=5`, `q=3,j=1`,

```text
U[r,5]     = [0,0,0,0,0,1,4],
U[7+r,5]   = [3,6,0,0,0,2]               (mod 7).
```

Finally `U[7+r,7+l]=U[r,l]`; e.g.

```text
U[9,8] = C(17,16) = 17 = 3 = U[2,1]       (mod 7).
```

# 2. The two Apéry congruences needed by the wrap

For `0<=r<p` one has the exact mod-`p` identities

```text
b_(p-1-r) = b_r,                                            (2.1)
b_(p+r)   = 5 b_r.                                          (2.2)
```

These can be proved directly from the defining sum; no finite experiment is needed.

For (2.1), use

```text
C(p-1-r,k)     = (-1)^k C(r+k,k),
C(p-1-r+k,k)   = (-1)^k C(r,k)                (mod p).
```

After squaring, the summand is exactly the Apéry summand for `r`; terms beyond `k=r` vanish.

For (2.2), split the summation index as `k=u` and `k=p+u`, `0<=u<=r`.  Lucas gives one copy of the `r`-summand from `k=u` and four copies from `k=p+u`, because the second binomial acquires the high-digit factor `C(2,1)=2`, which is squared.  Hence `1+4=5`.

Let

```text
Z_p = { folded labels rho(s) : 0<=s<p and b_s=0 mod p },
rho(s) = min(s, p-1-s).
```

Since every numerator has degree `<p/2`, each `t in Z_p` is a genuine common numerator root modulo `p`.

# 3. Exact triangular-Padé wrap degeneracy

Assume now

```text
H=p+d<2p,
0<=a<=A,
p>2A.
```

Thus `a<p/2`.  Write the denominator degree as

```text
L = H-a = p+d-a.
```

## 3.1 Case `a>d`: no high denominator columns

Here `L<p`.  Therefore `Q` uses only columns `k<p`, so (1.11) gives

```text
Q(tau(p+r)) = 2Q(tau(r)) - Q(tau(p-1-r)).                 (3.1)
```

For the numerator,

```text
P(tau(p+r)) = P(tau(r)) = P(tau(p-1-r)).                 (3.2)
```

If `b_r` is a unit modulo `p`, then the two base interpolation equations and (2.1) give

```text
Q(tau(p-1-r)) = Q(tau(r)).                               (3.3)
```

Hence `Q(tau(p+r))=Q(tau(r))`.  Comparing the base and wrapped interpolation equations and using (2.2),

```text
P(tau(r)) = b_r Q(tau(r)),
P(tau(r)) = 5 b_r Q(tau(r)),
```

so `4P(tau(r))=0`.  If `b_r=0`, the base equation already gives `P(tau(r))=0`.  Therefore:

> **Proved wrap-root lemma.**  If `a>d` and `p>2a`, then every exact integral interpolation pair, primitive or not, satisfies
>
> ```text
> P_(H,a)(tau(r)) = 0  (mod p),   0<=r<=d.                (3.4)
> ```

No statement about an arbitrary enlarged kernel is being used here; (3.4) holds for the actual primitive combined pair because it holds for every exact pair.

This also shows that a denominator-degree restriction forcing `H-a<p` does **not** cure the wrap.  It makes the nuisance interval mandatory.

## 3.2 Case `a<=d`: the high block is a smaller Padé problem

Now the high denominator columns are exactly

```text
k=p+l,   0<=l<=d-a.
```

Split

```text
Q = Q0 + Qhi,
```

where `Q0` uses `k<p`.  Define a local polynomial `R` of degree at most `d-a` by

```text
R(tau(r)) = sum_(0<=l<=d-a) q_(p+l) U[r,l].              (3.5)
```

Using (1.6) and (1.8),

```text
Q(tau(p+r))
 = 2Q(tau(r)) - Q(tau(p-1-r)) + R(tau(r)).               (3.6)
```

If `b_r` is nonzero, the first two base equations again give equality of the two base denominator values.  Substituting into the wrapped equation yields

```text
R(tau(r)) = -(4/5) Q(tau(r)),
P(tau(r)) = -(5/4) b_r R(tau(r)).                         (3.7)
```

At a zero `b_r=0`, both the base and wrapped equations merely require `P(tau(r))=0`; equation (3.7), after introducing an independent local denominator value, imposes no additional restriction there.

Put

```text
Rtilde = -(5/4) R.
```

Then the numerator must satisfy the genuine height-`d` Padé equations

```text
P(tau(r)) = b_r Rtilde(tau(r)),   0<=r<=d,
deg P<=a,
deg Rtilde<=d-a.                                     (3.8)
```

Conversely, suppose `P` satisfies (3.8) and also vanishes at every folded zero class in the full base block `0,...,p-1`.  On every nonzero base row set `Q(tau(s))=P(tau(s))/b_s`; choose arbitrary values on the zero rows; the unitriangular `p x p` block `U_(p-1)` determines the coefficients of `Q0`.  Taking the high coefficients to realize `R=-(4/5)Rtilde` then makes all wrapped equations hold.  Thus the converse is exact as well.

Let

```text
K_(d,a)(p)
```

be the mod-`p` height-`d` Padé kernel from (3.8), let `N_(d,a)(p)` be its numerator projection, and let

```text
V_(Z_p,a) = {P : deg P<=a and P(tau(t))=0 for every t in Z_p}.
```

Then we have the exact identity

```text
pi_P Ker(C_(H,a) mod p)
   = N_(d,a)(p) intersect V_(Z_p,a),       a<=d.           (3.9)
```

This is, in my view, the right “triangular-Padé wrap degeneracy” statement.

If the local height-`d` system is normal, `N_(d,a)(p)` is a one-dimensional line generated by a local numerator `L_(d,a)`.  Then (3.9) says

```text
there exists a nonzero global mod-p numerator
iff
L_(d,a)(tau(t))=0 for every t in Z_p.                     (3.10)
```

If (3.10) fails, **every** vector in the global mod-`p` kernel has zero numerator.  Therefore the actual primitive combined pair has `P_(H,a)=0 mod p` regardless of how enlarged the kernel is; no Smith ambiguity remains in that direction.

If (3.10) holds, however, the mod-`p` kernel contains a nonzero-numerator branch and usually also zero-numerator directions coming from zero rows.  Then the primitive combined integral pair cannot be identified from an arbitrary mod-`p` vector.  The first nonzero Smith layer is required.

That is precisely the normalization issue requested in the question.

# 4. Audit of the proposed common-root law

## 4.1 What is rigorously forced

For every `a<=A`:

1. every folded zero class in `Z_p` is a numerator root;
2. if `a>d`, every folded label in `rho({0,...,d})` is a numerator root by (3.4);
3. if `a<=d`, the numerator is controlled by the intersection (3.9), not by the zero pattern alone.

When `d<(p-1)/2`, which is the range in the examples and in the reflected nuisance window, `rho({0,...,d})=[0,d]` literally.

## 4.2 A corrected sufficient theorem for the observed zero-free interval

Assume:

```text
(i)  p>2A and d<(p-1)/2;
(ii) the local height-d systems are normal for 0<=a<=min(A,d);
(iii) for every 0<=a<=min(A,d), there exists t in Z_p with
      L_(d,a)(tau(t)) != 0 mod p.                          (T)
```

Then (3.10) fails for every `a<=d`, so every such global primitive numerator is the zero polynomial modulo `p`.  For `a>d`, (3.4) gives the roots `0,...,d`.  Hence

```text
Z_p union [0,d]
  is contained in
intersection_(0<=a<=A) Roots(P_(H,a) mod p).              (4.1)
```

To upgrade containment to the claimed **equality**, one still needs one saturated “purifier” member.  A clean sufficient hypothesis is that for some `a_*<=A`,

```text
a_* = |Z_p union [0,d]|,
P_(H,a_*) is nonzero mod p.                               (P)
```

Then its degree is exactly the number of forced distinct roots, so it has no additional roots, and (4.1) is equality.

Thus the exact proof obligation behind the observed law is `(T)+(P)`, not merely “the wrapped block contains no zero.”

## 4.3 Why “the first zero lift makes the interval disappear” is not a theorem

When a zero `t` enters `0..d`, the local kernel `K_(d,a)(p)` changes: every local numerator already has the corresponding prescribed root.  This can turn the intersection in (3.9) from zero into nonzero.  That is a real mechanism and it explains why the scans can switch exactly when `p+t` enters.

But the logical implication

```text
first zero enters  =>  common interval disappears
```

is too strong.  If there are several folded zero classes, the first one entering does not make a local numerator vanish at the still-uncovered classes.  Even when all classes are covered, the mod-`p` kernel is typically enlarged by the duplicate zero rows, so the primitive combined pair is selected only after dividing by the maximal-minor determinantal divisor.  The raw kernel does not tell us which branch survives.

For the special examples `p=17,19,31`, where the scan appears to have only one relevant folded zero class, “first” and “last uncovered” coincide.  The data are therefore consistent with the mechanism above, but they do not prove it for primes having several folded zero classes.

## 4.4 Literal counterexample to the zero-pattern-only formulation

The statement also needs a nonempty target-zero/transversality hypothesis.  Take

```text
p=13, H=13, d=0, A=ceil(13^(2/3))=6, so p>2A.
```

The exact Apéry residues are

```text
b_0,...,b_6 = 1,5,8,2,7,5,9              (mod 13),
```

and (2.1) gives

```text
b_7,...,b_12 = 5,7,2,8,5,1,
b_13 = 5 b_0 = 5.                          (mod 13).
```

So there is no folded zero at all and the wrapped block `{0}` is zero-free.  For `a=0`, the `Q` block has degree `H`; its matrix is the square matrix `-D U_H`, whose determinant is a unit modulo `13`.  Therefore the maximal minor obtained by deleting the `P` column is a `13`-unit.  The primitive combined kernel has a nonzero constant numerator modulo `13`, and label `0` is not a root.

So “zero-free wrap block implies `[0,d]` is common” is false without the additional target-zero/transversality input.  This is an exact normalization-aware counterexample, not a numerical rank guess.  It is not a counterexample to a narrower conjecture restricted to load-bearing target primes with nonempty `Z_p`.

# 5. Exact primitive normalization and the one-evaluation criterion for `p|F_n`

There is a completely exact evaluation-specific Smith formulation, and it is the right fallback when the kernel dimension jumps.

Write the coefficient vector in the `Phi` basis and define the integer interpolation matrix

```text
C_(H,a)
 = [ U[:,0..a]   |   -D U[:,0..H-a] ],                    (5.1)
```

an `(H+1) x (H+2)` matrix.  Assume its rational rank is `H+1`, which is the stated one-dimensional Padé condition.

For each column `j`, let

```text
mu_j = (-1)^j det(C_(H,a) with column j deleted),
```

and let

```text
delta_(H,a) = gcd_j mu_j.                                 (5.2)
```

This is the top determinantal divisor, equivalently the product of all Smith invariant factors of `C_(H,a)`.  The primitive **combined** coefficient vector is exactly

```text
z_(H,a) = +/- (mu_0,...,mu_(H+1)) / delta_(H,a).          (5.3)
```

No numerator-only primitive normalization is being used.

At the single evaluation `N=tau(n)`, append the row

```text
lambda_a(n)
 = [ U[n,0],...,U[n,a], 0,...,0 ].                        (5.4)
```

Define the bordered determinant

```text
Delta_(H,a)(n)
 = det( [ C_(H,a)  ] ).                                   (5.5)
        [ lambda_a(n)]
```

Laplace expansion along the last row gives the exact identity

```text
Delta_(H,a)(n)
   = +/- delta_(H,a) P_(H,a)(tau(n)).                     (5.6)
```

Therefore

```text
v_p(P_(H,a)(tau(n)))
 = v_p(Delta_(H,a)(n)) - v_p(delta_(H,a)),                (5.7)
```

and, finally,

```text
v_p(F_n)
 = min_(0<=a<=A)
     [ v_p(Delta_(H,a)(n)) - v_p(delta_(H,a)) ].          (5.8)
```

In particular,

```text
p | F_n
iff
v_p(Delta_(H,a)(n)) > v_p(delta_(H,a))
for every 0<=a<=A.                                        (5.9)
```

Equation (5.9) is a genuine necessary-and-sufficient condition, keeps the special evaluation `tau(n)`, and automatically handles every primitive-pair saturation issue.  It is also directly checkable in exact arithmetic for small `H`.

The structural wrap reduction sharpens (5.9) as follows:

* for `a>d`, labels `0,...,d` are forced roots by (3.4);
* for `a<=d`, use the local intersection (3.9); if that intersection is zero then `P_(H,a)=0 mod p` automatically, whereas if it is nonzero the Smith quotient in (5.7) decides which branch the primitive pair selects.

I do not see a valid simpler iff depending only on `Z_p` and `d`.

# 6. Does the wrap force linear logarithmic mass?

Not from the present theorem.  The finite `p=17,19,31` pattern is not enough.

For the reflected branch singled out in the question, write `n=3H+c`.  If `n<4p`, the reflected folded label is

```text
r = 4p-n-1.
```

The exact condition `0<=r<=d=H-p` is

```text
ceil((3H+c+1)/4)
 <= p <=
floor((4H+c+1)/5).                                      (6.1)
```

The real interval has length

```text
(H-c-1)/20 = H/20 + O(1).                                (6.2)
```

Hence the prime number theorem gives

```text
sum_(p in the geometric interval (6.1)) log p
 = H/20 + o(H).                                           (6.3)
```

But (6.3) alone says nothing about how many of those primes satisfy the **Apéry/Smith** condition needed to divide the whole family gcd.

There is also an important asymptotic warning.  On (6.1),

```text
d=H-p is between about H/5 and H/4,
A=H^(2/3)+O(1)=o(H),
```

so for all sufficiently large `H`, every family degree `a<=A` lies in the difficult case `a<=d`.  The easy forced-root lemma (3.4), which is visible in the small `p=17,19,31` examples because sometimes `A>d`, is asymptotically irrelevant on this reflected interval.  The height frontier is exactly the recursive local-Padé/Smith problem (3.9), not the no-high-column case.

## 6.1 Precise no-go lemma that would imply linear mass

Define the transversality event

```text
T(p,d,A):
  for every 0<=a<=A,
  N_(d,a)(p) intersect V_(Z_p,a) = {0}.                  (6.4)
```

In the locally normal case this is equivalent to

```text
for every a<=A, some folded zero t in Z_p satisfies
L_(d,a)(tau(t)) != 0 mod p.                               (6.5)
```

If additionally the challenge folded label `r` lies in `[0,d]`, then `(6.4)` makes every small-degree global numerator identically zero modulo `p`, so `p|F_n`.

A rigorous linear-height no-go would therefore follow from the prime-distribution statement

```text
there exists eta>0 such that, for infinitely many (or all large) H,

sum log p >= eta H,                                      (6.6)
```

where the sum is over primes in (6.1), `p>2A`, satisfying the relevant target-zero hypotheses and `T(p,H-p,A)`.

The simplified empirical law would replace `T` by the weaker condition

```text
Z_p intersect [0,H-p] = empty                            (6.7)
```

(or `t_p>H-p` for the smallest folded zero `t_p`).  Under that conjectural simplification, the exact distribution statement needed for a no-go is

```text
liminf_(H->infinity) (1/H)
  sum_{p in (6.1), t_p>H-p} log p  > 0.                  (6.8)
```

Conversely, an `o(H)` height proof based on the claimed “zero lift kills wrap” mechanism would need at least

```text
sum_{p in (6.1), t_p>H-p} log p = o(H),                  (6.9)
```

plus an `o(H)` bound for the residual Smith-exception primes where a zero is present but the primitive saturated numerator still vanishes at the challenge evaluation.

PNT proves only (6.3), not (6.8) or (6.9).  Those are distribution statements about the first folded Apéry zero and, in the exact formulation, about local Padé transversality/Smith saturation.  The scans through a few primes do not decide them.

# 7. Minimal modification audit

## 7.1 Denominator-degree restriction: fails in the wrong direction

To eliminate the `k=p+l` columns one would impose

```text
H-a < p  <=>  a>d.
```

But (3.4) then proves that every wrapped label `0,...,d` is a numerator root.  So this restriction **creates a theorem forcing the nuisance interval**; it does not remove it.

Moreover, on the asymptotic reflected interval (6.1), `d=Theta(H)` while `A=H^(2/3)`, so the original sublinear family has no degree `a>d` at all for large `H`.

## 7.2 A shifted block of the same length does not remove the wrap uniformly

Any consecutive block of `H+1>p` integer nodes contains `H-p+1=d+1` pairs separated by `p`.  A fixed shift therefore moves the paired residue interval but does not remove it.  To choose the shift so that the challenge folded label avoids the paired block requires knowing `p` (hence `d=H-p`), so it is not a single global carrier.  The target-zero node can likewise move out of the block.

Thus a shifted block is at best a prime-dependent local repair.

## 7.3 The exact local purifier is a second height `d`, but it is prime-dependent

For a fixed troublesome prime, the wrap reduction itself gives the minimal purifier: use the height-`d`, degree-`d` Padé member.  Its denominator is constant, so

```text
P_(d,d)(tau(r)) = const * b_r,    0<=r<=d.                (7.1)
```

If the wrapped block is zero-free, (7.1) is nonzero at every nuisance label and therefore kills the spurious factor immediately.

The problem is that

```text
d = H-p
```

depends on the prime.  A single second height cannot realize (7.1) for all primes in the proportional interval.

## 7.4 A macroscopic second height removes the geometric wrap but does not preserve the banked injection for free

For the reflected interval (6.1), any fixed

```text
H2 < (3H+c+1)/4
```

—for example `H2=floor((3H+c)/4)-1`—satisfies `H2<p` for every reflected nuisance prime, so the second system has no `s,s+p` node pair at all.

However, the banked growing-family theorem bounds the **number** of folded zero classes by `A`; it does not put every target zero label below `H2`.  This is exactly the distinction in the repository's Section 160 zero-absorber theorem.  Therefore one cannot simply assert that the same target prime still divides every second-height numerator at the same challenge evaluation.

If one gives the second height its own challenge-compatible evaluation (or chooses a shifted block specifically to contain the target zero), target injection can be restored—but that is precisely the previously known two-evaluation/two-geometry carrier, not a new one-evaluation height proof.

So, with the currently banked hypotheses, I do **not** find a p-independent one-evaluation modification among the three proposed knobs that both (a) provably removes the wrap interval and (b) provably retains every target prime.  The provable repair reverts to the old two-evaluation carrier unless one first proves a new location theorem for the folded zero classes.

A genuinely new one-evaluation repair would follow from a statement of the form

```text
all target folded zero labels lie in a fixed subheight H2 < 3H/4,          (7.2)
```

because then the second-height zero-absorber could retain target injection while avoiding every prime in (6.1).  What is banked is a zero-**count** bound, not (7.2).
