# Exact P2.4 integral certificate

## Executive result

Put

\[
L=\log 2,\qquad Z_3=\operatorname{Li}_3(1),\qquad
A=\int_0^1\frac{\log^2 x\,\log(1-x)}{1+x}\,dx.
\]

The shortest robust certificate is

\[
\boxed{
Q=\frac74LZ_3-\frac{\pi^4}{90}-\frac12A.
}
\tag{1}
\]

The already-proved log-square integral should be used in the form

\[
\boxed{
A=\frac{\pi^4}{90}+\frac{\pi^2L^2}{6}
   -\frac{L^4}{6}-4\operatorname{Li}_4\!\left(\frac12\right).
}
\tag{2}
\]

Substituting (2) into (1) and applying `ring` gives

\[
\begin{aligned}
Q
&=2\operatorname{Li}_4\!\left(\frac12\right)
  +\frac{L^4}{12}-\frac{\pi^2L^2}{12}
  +\frac74LZ_3-\frac{\pi^4}{60}\\[2mm]
&=\frac{-\pi^4-5\pi^2L^2
 +5\left(L^4+24\operatorname{Li}_4(1/2)+21LZ_3\right)}{60}.
\end{aligned}
\]

No closed form for `Li4 (1 / 2)` is used or desired.

The key implementation point is that (1) can be proved without a large weight-4 primitive and without multiplying conditionally convergent endpoint series. It uses:

1. one finite integration-by-parts calculation for `∫ x^n log (1+x)`;
2. an absolutely convergent Li₂ termwise integration;
3. the absolutely convergent generating function for finite alternating harmonic sums;
4. `hasSum_zeta_four`.

Consequently the code below uses adapter names `Li2`, `Li3`, and `Li4`; replace only those aliases by the declarations in the active checkout. # 1. The finite moment identity

Define the finite alternating harmonic sum

\[
a_n=\sum_{j=1}^{n}\frac{(-1)^{j-1}}j,\qquad a_0=0.
\]

In zero-based Lean form:

```lean
private def altH24 (n : ℕ) : ℝ :=
  ∑ j in Finset.range n, (-1 : ℝ) ^ j / (((j + 1 : ℕ) : ℝ))

@[simp] lemma altH24_zero : altH24 0 = 0 := by
  simp [altH24]

lemma altH24_succ (n : ℕ) :
    altH24 (n + 1) =
      altH24 n + (-1 : ℝ) ^ n / (((n + 1 : ℕ) : ℝ)) := by
  simp [altH24, Finset.sum_range_succ]
```

A sharp bound is unnecessary. The elementary bound

```lean
lemma abs_altH24_le_nat (n : ℕ) : |altH24 n| ≤ n := by
  calc
    |altH24 n| ≤
        ∑ j in Finset.range n,
          |(-1 : ℝ) ^ j / (((j + 1 : ℕ) : ℝ))| := by
      simpa [altH24, Real.norm_eq_abs] using
        norm_sum_le (fun j : ℕ ↦
          (-1 : ℝ) ^ j / (((j + 1 : ℕ) : ℝ))) (Finset.range n)
    _ ≤ ∑ _j in Finset.range n, (1 : ℝ) := by
      gcongr with j hj
      simp only [abs_div, abs_pow, abs_neg, abs_one, one_pow]
      rw [abs_of_pos (by positivity : (0 : ℝ) < (j + 1 : ℕ))]
      exact one_div_le_one (by positivity)
    _ = n := by simp
```

may need only minor cast normalization in the active file. It is enough for every summability argument below, since `n / n^3` is bounded by a square p-series.

Now set

\[
R_n=\int_0^1\frac{x^n}{1+x}\,dx.
\]

The two exact finite identities are

\[
R_0=L,\qquad
R_{n+1}=\frac1{n+1}-R_n.
\tag{3}
\]

The recurrence follows from

\[
\frac{x^{n+1}}{1+x}=x^n-\frac{x^n}{1+x}.
\]

Induction using `altH24_succ` gives

\[
\boxed{R_n=(-1)^n(L-a_n).}
\tag{4}
\]

Recommended declarations:


The displayed `remMoment24_zero` may elaborate more cleanly by first rewriting with
`intervalIntegral.integral_comp_add_left`; the mathematical content is simply
`∫₀¹ (1+x)⁻¹ dx = ∫₁² y⁻¹ dy`.

Next define

\[
M_n=\int_0^1x^n\log(1+x)\,dx.
\]

A regular integration by parts on the closed interval `[0,1]` gives

\[
\begin{aligned}
M_n
&=\left[\frac{x^{n+1}}{n+1}\log(1+x)\right]_0^1
 -\frac1{n+1}\int_0^1\frac{x^{n+1}}{1+x}\,dx\\
&=\frac{L-R_{n+1}}{n+1}.
\end{aligned}
\]

Therefore

\[
\boxed{
M_n=
\frac{L-(-1)^{n+1}(L-a_{n+1})}{n+1}.
}
\tag{5}
\]

\]

Formula (5) gives both values exactly.

# 2. Termwise Li₂ integration

Use the current real Li₂ series in the zero-based form

```lean
HasSum
  (fun n : ℕ ↦ x ^ (n + 1) / (((n + 1 : ℕ) : ℝ) ^ 2))
  (Li2 x)
```

for `0 ≤ x ≤ 1`. After division by `x`, the `n`-th integrand is

```lean
private def qTerm24 (n : ℕ) (x : ℝ) : ℝ :=
  x ^ n * Real.log (1 + x) /
    (((n + 1 : ℕ) : ℝ) ^ 2)
```

At `x=0`, both the original integrand and every `qTerm24 n` are zero, because `Li2 0 = 0` and `log 1 = 0`; no informal cancellation of `x/x` at zero is used.

For `0 ≤ x ≤ 1`,

\[
0\le \log(1+x)\le x\le1,
\]

so

\[
\int_0^1|qTerm24(n,x)|\,dx
\le\frac1{(n+1)^3}.
\]

Thus `MeasureTheory.hasSum_integral_of_summable_integral_norm` applies with
`μ = volume.restrict (Set.Ioc 0 1)`.

# 3. The alternating-harmonic generating function

For `|x|<1`, the exact generating function is

\[
\boxed{
\sum_{N\ge1}(-1)^Na_Nx^N
=\frac{\log(1-x)}{1+x}.
}
\tag{9}
\]

This is an absolutely convergent Cauchy product, not an endpoint rearrangement:

\[
\log(1-x)=-\sum_{j\ge1}\frac{x^j}{j},
\qquad
\frac1{1+x}=\sum_{r\ge0}(-x)^r.
\]

The coefficient of `x^N` is

\[
-\sum_{j=1}^{N}\frac{(-1)^{N-j}}j
=(-1)^N\sum_{j=1}^{N}\frac{(-1)^{j-1}}j
=(-1)^Na_N.
\]

Compile-oriented theorem:

```lean
lemma hasSum_altH24_generating {x : ℝ} (hx : |x| < 1) :
    HasSum
      (fun n : ℕ ↦
        (-1 : ℝ) ^ (n + 1) * altH24 (n + 1) * x ^ (n + 1))
      (Real.log (1 - x) / (1 + x)) := by
  have hlog :=
    (Real.hasSum_pow_div_log_of_abs_lt_one hx).neg
  have hgeom :=
    hasSum_geometric_of_abs_lt_one
      (show |-x| < 1 by simpa using hx)
  have hprod :=
    hasSum_sum_range_mul_of_summable_norm
      hlog.summable.norm hgeom.summable.norm
  convert hprod using 1
  · ext n
    -- Isolate this as a finite lemma if simplification becomes noisy:
    -- the Cauchy coefficient is
    -- `(-1)^(n+1) * altH24 (n+1) * x^(n+1)`.
    ...
  · rw [hlog.tsum_eq, hgeom.tsum_eq]
    simp [one_sub_neg, div_eq_mul_inv]
```

The Cauchy-product API name above is exactly the Mathlib 4.29 declaration
`hasSum_sum_range_mul_of_summable_norm`.

A useful finite helper is

```lean
lemma altH24_cauchy_coeff (n : ℕ) (x : ℝ) :
    (∑ k in Finset.range (n + 1),
        (-(x ^ (k + 1) / (((k + 1 : ℕ) : ℝ)))) *
          (-x) ^ (n - k))

    (-1 : ℝ) ^ (n + 1) * altH24 (n + 1) * x ^ (n + 1) := by
  -- `Finset.sum_congr`; for `k < n+1`, use `k ≤ n`,
  -- `k + 1 + (n-k) = n+1`, and the parity identity
  -- `-(-1)^(n-k) = (-1)^(n+1) * (-1)^k`.
  ...
```

Keeping this coefficient algebra separate makes the analytic theorem very short.

# 5. The one-line shifted-series cancellation

From

\[
a_N-a_{N-1}=\frac{(-1)^{N-1}}N,
\]

we get

\[
\begin{aligned}
E+T
&=-1+
  \sum_{N\ge2}
   \frac{(-1)^Na_N+(-1)^{N-1}a_{N-1}}{N^3}\\
&=-1-\sum_{N\ge2}\frac1{N^4}\\
&=-\sum_{N\ge1}\frac1{N^4}
=-\frac{\pi^4}{90}.
\end{aligned}
\tag{12}
\]

The signs here are load-bearing:

- `E` uses `(-1)^N a_N / N^3`;
- after shifting (11), `T` contributes `(-1)^(N-1) a_(N-1) / N^3`;
- their numerator is `(-1)^N (a_N-a_(N-1)) = -1/N`.

Lean shape:

```lean

    altEuler3_24 + shiftedAltEuler3_24 =
      -(Real.pi ^ 4 / 90) := by

  rw [altEuler3_24, hE]
  have htail :

  linarith
```

`.comp_nat_add 1`. Also, `tsum_add` may be easier than rewriting with a method form.

# 7. Optional finite Li₂ primitive

There is a compact finite primitive which is useful as an independent check and may be preferable if the active file already has a good improper-integration-by-parts layer. Define

\[
P(x)=\operatorname{Li}_2\!\left(\frac{1+x}{2}\right)
 -\operatorname{Li}_2\!\left(\frac12\right)
 -\operatorname{Li}_2(x)-L\log(1+x).
\]

For `0<x<1`, direct differentiation gives

\[
\boxed{
P'(x)=\frac{\log(1-x)}{x(1+x)}.
}
\tag{13}
\]

Indeed,

\[
\frac d{dx}\operatorname{Li}_2\!\left(\frac{1+x}{2}\right)
=\frac{-\log(1-x)+L}{1+x},
\]

and the two `L/(1+x)` terms cancel.

The endpoint values are

\[
P(0)=0,\qquad
P(1)=-\operatorname{Li}_2(1/2)-L^2
=-\frac{\pi^2}{12}-\frac{L^2}{2}.
\]

The last equality uses the already-proved
`Li2 (1/2) = π²/12 - L²/2`.

Moreover, for `|x|<1`,

\[
P(x)=\sum_{N\ge1}\frac{(-1)^Na_N}{N}x^N.
\]

Consequently

\[
E=-\int_0^1P(x)\frac{\log x}{x}\,dx.
\]

Integrating by parts with `d(log²x/2)=log x\,dx/x` and using (13) gives

\[
E=\frac12\int_0^1
  \frac{\log^2x\,\log(1-x)}{x(1+x)}\,dx
 =\frac12C-\frac12A,
\]

where

\[
C=\int_0^1\frac{\log^2x\,\log(1-x)}x\,dx
=-\frac{\pi^4}{45}.
\]

Thus again `E = -π⁴/90 - A/2`.

\[

\]

`Li3 (1/2)` is not load-bearing in either route. It may occur in the existing proof of the log-square integral, but forcing it into the capstone only lengthens the proof. The cancellation is real, not an omission.

# 9. Endpoint and legality audit

1. **At `x=0` in Q:** Mathlib division is totalized. Prove the pointwise series identity by an explicit `by_cases hx : x = 0`; do not cancel `x` without `hx`.

2. **At `x=1` in Q:** the integrand is finite. Li₂ is absolutely summable at `1`, so no endpoint issue occurs in the Q interchange.

3. **At `x=1` in (9):** the coefficient terms do not tend to zero. Therefore (9) must be used only for `x<1`. In the integral proof, remove the singleton `{1}` with `Measure.ae_ne`; never state a `HasSum` at `x=1`.

4. **At `x=0` in the log-square integral:** each term contains `x^(N)` with `N≥1`, and the existing monomial log-square theorem supplies integrability. Do not infer genuine analytic continuity from Mathlib's totalized value `Real.log 0 = 0`.

5. **At `x=1` in the log-square integral:** `log(1-x)` is singular in the ordinary limiting sense even though `Real.log 0` is totalized. Again, use a.e. equality plus absolute integral-norm summability, not continuity at the endpoint.

6. **All rearrangements are absolute:**

   ```text
   Q terms:       integral norm ≤ 1/(n+1)^3
   Euler E terms: |a_N|/N^3 ≤ 1/N^2
   shifted terms: |a_N|/(N+1)^3 ≤ 1/N^2
   log-square terms after integration: ≤ 2/N^2
   ```

   Hence no Abel regularization and no conditional `HasSum` is hidden in the proof.

7. **Index signs:** with `altH24 (n+1)=a_(n+1)`, the Euler term is
   `(-1)^(n+1) * a_(n+1)/(n+1)^3`, while the shifted log-square term is
   `(-1)^(n+1) * a_(n+1)/(n+2)^3`.

8. **The factor `1/2` in (11)** comes from
   `∫₀¹ x^N log²x dx = 2/(N+1)^3`. Missing it changes the Li₄ coefficient from `2` to `4`.
