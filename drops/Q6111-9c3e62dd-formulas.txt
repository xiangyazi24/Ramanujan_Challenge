3. EXACT LOCAL TRANSFER AND UNIT AUDIT
======================================
For u >= 1 define
  S_u(X) = product_(j=2)^u (X+j)
  A_u(X) = S_u(X)^3
  E_u(X) = (X+1)^3 N_(u-1)(X+1)

Exact transfer:
  A_u(X)b_(X+u) = N_u(X)b_(X+1) - E_u(X)b_X

Desnanot identity:
  N_u(X)N_u(X+1)
  - N_(u+1)(X)N_(u-1)(X+1)
  = S_u(X)^6

For every actual chamber leaf, 0 <= x < x+u < p. Hence:
  p does not divide A_u(x)
  p does not divide b_(x+1)              (no consecutive zeros)
  p divides N_u(x)                       (two actual zeros)
  p does not divide E_u(x)               (Desnanot identity)

Thus all divisions by A_u(x), b_(x+1), and E_u(x) used below are legal.
No division by the leading coefficient of N_u is used. Leading-degree drop
modulo p therefore causes no failure of the formulas.

4. TAYLOR EXPANSION AND Q6092 V1-V3
===================================
Let G_u be the fixed-column integer in the chosen chamber chart. Then
  G_u = N_u(x + kappa_c p)
with kappa_c in {6,-7,-2}.

Integer Taylor expansion:
  G_u = N_u(x) + kappa_c p N_u'(x)  (mod p^2)

Since p divides both G_u and N_u(x):
  G_u/p = N_u(x)/p + kappa_c N_u'(x)  (mod p)

Endpoint quotients:
  eta_x       = (b_x/p) mod p
  eta_(x+u)   = (b_(x+u)/p) mod p

Transfer units and derivative coordinate:
  lambda_u(x) = E_u(x)/A_u(x) mod p, and lambda_u(x) != 0
  J_u(x) = b_(x+1) A_u(x)^(-1) N_u'(x) mod p

V1 (chart-fixed normalized own-modulus Bockstein):
  Theta_c(x,u)
    = b_(x+1) A_u(x)^(-1) (G_u/p) mod p

Dividing the exact transfer by p gives:
  b_(x+1) A_u(x)^(-1) (N_u(x)/p)
    = eta_(x+u) + lambda_u(x) eta_x mod p

V2:
  Theta_c(x,u)
    = eta_(x+u)
      + lambda_u(x) eta_x
      + kappa_c J_u(x)                       mod p

V3:
  c=I:    x=a, y=r, kappa=+6
  c=II:   x=a, y=z, kappa=-7
  c=III:  x=w, y=r, kappa=-2

Valuation >=2 audit:
  If p^2 | G_u, then Theta_c=0.
  If p^2 | N_u(x), then the term N_u(x)/p is 0 mod p.
  The Taylor and transfer identities remain valid in both cases.

Interpretive correction:
  V2 is valid, but eta_x and eta_(x+u) are not independent inside V2.
  Their combination eta_(x+u)+lambda eta_x is already fixed by the divided
  transfer. The genuinely unresolved diagonal datum is the chart-fixed
  quotient Theta_c, equivalently the pair (N_u(x)/p, N_u'(x)) with its
  adjacent-state p-unit gauge.

6. WRONSKIAN, REFLECTION JET, AND SELECTED q
================================================
Let c_0=0,c_1=1 be the unit companion solution. The exact Wronskian is
  j^3 ( b_(j-1)c_j - b_j c_(j-1) ) = 1.

At an actual zero p|b_x:
  (x+1)^3 b_(x+1)c_x = -1 mod p.

For the return transfer and p|N_u(x):
  A_u(x)c_(x+u) = -E_u(x)c_x mod p,
so
  lambda_u(x) = E_u(x)/A_u(x) = -c_(x+u)/c_x mod p.

Therefore
  Theta_c
    = eta_(x+u) - (c_(x+u)/c_x)eta_x + kappa_c J_u(x),

and also
  Theta_c
    = -(G_u/p) / ( A_u(x)(x+1)^3 c_x ) mod p.

The Wronskian replaces one p-unit by the private companion value c_x; it does
not remove the diagonal quotient.

Banked first-Witt reflection convention:
  b_(p-1-j) = b_j - p g_j  (mod p^2).
At a zero p|b_j:
  eta_(p-1-j) = eta_j - g_j mod p.

Thus, in the chosen charts:
  Chamber I:   Theta = eta_r + lambda eta_a + 6J
  Chamber II:  Theta = eta_r - g_r + lambda eta_a - 7J
  Chamber III: Theta = eta_r + lambda(eta_a-g_a) - 2J

The g_j are moving index jets, not bounded-degree constants.

Since p and q are distinct and both divide b_s and b_n, write
  b_s = pq H_s
  b_n = pq H_n
with H_s,H_n integers.
The selected condition q|b_t supplies the q-divisibility of these common rows,
but gives no relation fixing H_s or H_n modulo the lower prime p. The divided
Lucas laws introduce H_s,H_n and digit/index jets; they do not eliminate Theta.

7. LONG DERIVATIVE WORD AND ZERO-CUT SEAM
=========================================
Let
  D_h(X) = d/dX V_h(X)
  M'(Y) = [ P'(Y)  -6Y^5 ]
          [ 0          0  ]
Then
  D_(h+1)(X) = M(X+h)D_h(X) + M'(X+h)V_h(X).

With V_1=(1,0)^T and D_1=(0,0)^T:
  D_u(X)
    = sum_(j=1)^(u-1)
      M(X+u-1)...M(X+j+1) M'(X+j) V_j(X).

Thus N_u'(x) is a variation-of-constants word with u-1 summands and long
monodromy factors. No checked identity reduces this word to bounded conductor.

A full p-block is not invertible because
  M(0) = [5 0]
         [1 0]
and
  [0  1] M(0) = [1 0]
  [1 -5]        [0 0].

Wilson controls products of scalar determinants. Crossing the zero seam loses a
state coordinate; its first lift is a Bockstein datum, not an invertible short
reversal.

8. GAUGE-FAITHFUL HOSTILE MODEL
===============================
Choose c in {10,16} and sigma in {+1,-1}. Let
  p_m = p_0 + 2 sigma m
  u_m = u_0 + c m
with:
  Chamber I:   c=10, sigma=-1, u_m+5p_m constant
  Chamber II:  c=16, sigma=+1, u_m-8p_m constant
  Chamber III: c=16, sigma=-1, u_m+8p_m constant

Let
  Phi_m = product_(j=0)^(c-1) (X+u_m+j)^3
  F_(m+1) = Phi_m F_m
  W_m = F_m (p_m,1)^T

Then
  W_(m+1)
    = Phi_m [1  2sigma] W_m
              [0    1  ]

and
  det( Phi_m [1 2sigma; 0 1] )
    = Phi_m^2
    = product_(j=0)^(c-1)(X+u_m+j)^6.

The first coordinate is
  G_m = F_m p_m,
so
  p_m | G_m
at every prime level, while the gauge-normalized divided coordinate is
  G_m/(F_m p_m) = 1.

On any finite p-safe interval choose parameters so that none of the factors in
Phi_m is 0 mod p_m. This rank-two polynomial model matches the exact affine law
and factorial determinant gauge and has maximal one-color close-pair energy. It
is not the Apéry recurrence and is not claimed to realize Apéry zeros.
