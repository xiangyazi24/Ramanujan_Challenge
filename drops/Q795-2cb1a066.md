# Q795: paired affine-diagonal carrier audit for LGTQ-2

## 1. Exact algebraic setup

Let the two packets have fixed gap

```
h=q d
```

and small-index variables `u` and `u+s`. The four candidate primes are

```
p,
p-d,
p-s/q,
p-d-s/q.
```

The actual constraints are four independent characteristic conditions:

```
p | b_u,
(p-d) | b_{u+h},
(p-s/q) | b_{u+s},
(p-d-s/q) | b_{u+s+h}.
```

The cross conditions require the opposite divisibilities to fail. Therefore the four primes are not interchangeable roots of one scalar recurrence relation.

## 2. What the recurrence transfer matrix gives

The factorial-cleared Apéry transfer matrix gives a universal polynomial relation between consecutive Apéry values. After clearing denominators, any single characteristic stream admits a continuant identity of the form

```
C_h(u) b_u + D_h(u) b_{u+h} = N_h(u)
```

with integer coefficients.

Reducing modulo a prime attached to one endpoint gives a divisibility implication only when that same prime divides the relevant Apéry value. For example, if

```
p | b_u,
```

then

```
p | N_h(u)
```

only after the companion term is controlled modulo p. The same statement does not transfer directly to `p-d` or the second packet.

## 3. Saturated elimination after removing the forced prime product

Introduce variables representing the four quotient conditions. The raw elimination ideal contains the obvious factor

```
p(p-d)(p-s/q)(p-d-s/q).
```

After saturation by this product, the remaining ideal tests whether the shared affine geometry creates an additional scalar obstruction.

For generic recurrence initial data, the elimination leaves only the unit ideal in the scalar parameter direction:

```
I : <p(p-d)(p-s/q)(p-d-s/q)>^∞
```

has no nontrivial polynomial in the row variable alone.

The reason is that each packet contributes a separate Frobenius characteristic. The same gap h does not identify the four mod-p quotient streams.

## 4. Why the obvious continuant carrier saturates

A natural attempt is to multiply the two transfer identities:

```
(C_h b_u + D_h b_{u+h})
(C_h b_{u+s}+D_h b_{u+s+h}).
```

Modulo the four primes this produces factors divisible by the expected prime product, but after saturation the remaining factors are precisely the transversality units:

```
C_h,
D_h,
N_h
```

evaluated in incompatible characteristics.

For a fully transverse packet these factors are required to be nonzero. Hence the continuant carrier is a unit rather than a new small integer divisible by an extra prime.

## 5. Actual Apéry initial condition caveat

The generic recurrence computation is not a no-go theorem for the true Apéry sequence. The actual sequence has the special initial vector

```
b_0=1,
```

and the binomial-sum representation

```
b_n=sum_k binom(n,k)^2 binom(n+k,k)^2.
```

A special cancellation could occur only through identities using this initial condition. Such a cancellation is not visible in the recurrence module alone.

Therefore the valid conclusion is:

```
no generic recurrence carrier survives;
actual-Apéry bounded fibre multiplicity remains open unless a binomial-sum-specific identity is found.
```

## 6. Scoped symbolic certificate

A certificate for the generic statement is:

1. Work in the polynomial ring generated by recurrence parameters and four independent prime variables.
2. Impose four hit equations.
3. Saturate by the prime product and by all transversality units.
4. Eliminate the Apéry variables.

The resulting scalar elimination contains no nonzero polynomial in the affine row parameter.

This proves only that no carrier follows from the recurrence relations plus generic initial data.

## 7. Surviving narrower construction

The remaining viable route is narrower:

- retain the explicit binomial-sum initial vector;
- construct a determinant/resultant involving truncated Apéry sums rather than recurrence symbols;
- prove its coefficient height is `o(n)`;
- prove each fully transverse packet forces divisibility.

Without this extra binomial-sum input, the paired same-gap construction saturates at the forced prime product and cannot close LGTQ-2.
