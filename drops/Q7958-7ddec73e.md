## Required symbolic verifier

The verifier should take the homogeneous equation

```
F(U,V,W,T;a)=0
```

as an explicit polynomial object and never replace it by an abstract ADE normal form. The pipeline is:

1. Parse the exact homogeneous equation and parameter specialization.
2. Enumerate every affine chart of `(P1)^3`:

```
U=1/V=1/W=1
U=1/V=1/T=1
...
```

including all boundary charts used by the toric compactification.
3. In each chart compute:

```
Fx = diff(f,x)
Fy = diff(f,y)
Fz = diff(f,z)
Ft = diff(f,t)
```

and solve the Jacobian ideal together with the exceptional-locus equations.

## Blow-up verification

For a center `(x,y)` the verifier introduces charts:

```
x = y*u
or
 y = x*v
```

then divides the total transform by the exceptional multiplicity. The strict transform is the saturated ideal

```
I_strict = saturation(I_total, exceptional_variable)
```

The exceptional divisor is checked by setting the exceptional coordinate to zero and recomputing the Jacobian ideal. A residual singular point on a chart overlap is a failure.
