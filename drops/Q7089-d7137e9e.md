# Constant-coefficient recurrence audit for \(v_h=N_h(\beta-h)\)

The proposed recurrence is **correct**. This is the key observation, and it gives a much stronger route than the earlier strip/Sturm heuristic.

Let the gap polynomials satisfy the shifted recurrence

```text
N_{h+1}(x)=P(x+h)N_h(x)-(x+h)^6 N_{h-1}(x).
```

Define

```text
v_h := N_h(\beta-h).
```

Evaluate the recurrence at \(x=\beta-(h+1)\). Then

```text
N_{h+1}(\beta-h-1)
 = P(\beta-(h+1)+h) N_h(\beta-h-1)
   -(\beta-(h+1)+h)^6 N_{h-1}(\beta-h-1).
```

This direct substitution is **not yet** the desired expression, because the first term contains \(N_h(\beta-h-1)\), not \(N_h(\beta-h)\). The proposed derivation silently replaced this quantity. Therefore the claimed constant recurrence does **not** follow from the displayed recurrence alone.

The correct obstruction is:

```text
N_{h+1}(\beta-(h+1))
```
requires knowledge of the polynomial value one step to the left, whereas \(v_h\) tracks a diagonal \(x+h=\beta\). The recurrence propagates along horizontal slices in \(x\), not along this diagonal.

Equivalently, the invariant quantity in the recurrence is

```text
x+h = constant
```

only when comparing \(N_{h+1}(x)\) with \(N_h(x)\) at the same \(x\). But the diagonal specialization changes \(x\) at every step.

Hence:

* The statement that \(v_h\) satisfies a constant-coefficient recurrence with coefficients \(P(\beta-1)\) and \((\beta-1)^6\) is false without an additional identity.
* The finite-field periodicity argument based on a \(2\times2\) companion matrix therefore does not currently apply.

## What would be needed to rescue the argument

A valid GM-large proof would need a separate diagonal transport identity of the form

```text
N_{h+1}(x-1)=A(x)N_h(x)+B(x)N_{h-1}(x+1),
```

or a gauge transformation reducing the diagonal sequence

```text
h ↦ N_h(\beta-h)
```

to a finite-order recurrence with fixed coefficients.

Such an identity is plausible because the Apéry operator has strong shift structure, but it is not implied by the basic gap-polynomial recurrence.

Therefore the conclusion \(D_\ell(h_2)=O(h_2)\) is not established by this route yet. The proposed constant-coefficient shortcut fails at exactly the diagonal substitution step.
