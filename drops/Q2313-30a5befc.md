# Q2313 — Apéry Racah orthogonality audit

The proposed orthogonality route is not valid as stated.  The polynomial

\[
A_n(T)= {}_4F_3(-n,n+1,-x,x+1;1,1,1;1),\qquad T=x(x+1),
\]
is a Racah-type polynomial, but it is **not** the positive finite Racah system obtained by simply taking the standard Racah parameters
\((a,b,c,d)=(0,0,0,0)\).

## 1. Parameter identification

The standard Racah polynomial is

\[
R_n(\lambda(x);\alpha,\beta,\gamma,\delta)
={}_4F_3\left(\begin{matrix}-n,n+\alpha+\beta+1,-x,x+\gamma+\delta+1\\
\alpha+1,\beta+\delta+1,\gamma+1
\end{matrix};1\right),
\]
with \(\lambda(x)=x(x+\gamma+\delta+1)\).

Matching the numerator parameters gives

\[
\alpha+\beta=0,\qquad \gamma+\delta=0,
\]
and matching denominators gives

\[
\alpha=0,\qquad \gamma=0,\qquad \beta+\delta=0.
\]

Hence the formal choice is indeed

\[
\alpha=\beta=\gamma=\delta=0.
\]

However, the finite positive Racah measure requires a truncation condition, namely one of

\[
\alpha+1=-N,\quad \beta+\delta+1=-N,\quad \gamma+1=-N
\]

for some nonnegative integer \(N\).  With the above parameters these quantities are all equal to \(1\), so no finite support exists.

Therefore the usual finite Racah orthogonality theorem does not apply.

## 2. The formal Racah weight degenerates

The Racah weight contains the factor

\[
\frac{(\alpha+1)_x(\beta+\delta+1)_x(\gamma+1)_x(\gamma+\delta+1)_x}
{x!(\alpha+\delta+1)_x(\beta+1)_x(\gamma+1)_x}
\]
(up to the standard normalization and the terminating factor coming from the truncation parameter).

For \((0,0,0,0)\), all Pochhammer parameters are positive and nonzero, but there is no terminal index \(N\).  The issue is not a negative weight; the issue is absence of a finite discrete measure.  The finite orthogonality lattice has not been specified.

Thus there is no positive finite measure whose orthogonal polynomials are exactly these \(A_n\) for all \(n\).

## 3. Consequence for coprimality

The three-term recurrence

\[
T A_n=A_n^{(+)}A_{n+1}-(A_n^{(+)}+C_n)A_n+C_nA_{n-1}
\]

with

\[
A_n^{(+)}=\frac{(n+1)^3}{2(2n+1)},\qquad
C_n=\frac{n^3}{2(2n+1)}
\]

is a Favard recurrence over \(\mathbb Q\).  It gives a formal orthogonal polynomial sequence after choosing an appropriate linear functional, but it does not automatically give a positive measure on \(\mathbb R\).

The coefficients are positive, so the Jacobi matrix has positive off-diagonal entries after normalization.  This does imply the usual formal Sturm properties for the finite truncations: consecutive polynomials have no common zero and their zeros are real/simple for the corresponding finite Jacobi matrices.

However, the desired statement

\[
\gcd(A_r,A_s)=1\quad(r\neq s)
\]

over \(\mathbb Q[T]\) does not follow from the claimed Racah finite-measure argument.

A separate proof is needed: for example, a Jacobi-matrix argument showing that every pair of nonconsecutive members of this particular recurrence has no common eigenvalue, or an arithmetic argument using the recurrence.

## Conclusion

The exact answer is:

* The formal Racah parameters are \((0,0,0,0)\).
* They do **not** satisfy the Racah finite truncation condition.
* There is no finite positive discrete Racah measure for the whole family \(A_n\).
* The degeneration is failure of termination, not negative weights.
* The proposed immediate proof of pairwise coprimality from positive Racah orthogonality is therefore unavailable.
