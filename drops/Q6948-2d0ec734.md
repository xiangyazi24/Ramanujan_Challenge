# Exact algebra audit for the signed dual row

## 0. Conventions

Let

```text
J = diag(1,-1,1),
M_n = challengeMatrix(n),
B_n = positiveMatrix(n) = -J M_n J,
d_n = dualVector(n) as a column,
lambda_n = (n+1)(n+2)^2(n+3)^2(2n+7)^2,
sigma_n = -2(n+2)^2(n+3)^2(2n+5)(2n+7)^2.
```

Write

```text
s_i = coordinateSign(i) in {1,-1,1},
w_n(i) = s_i d_n(i).
```

Thus, as a row,

```text
w_n = d_n^T J = [d_n(0), -d_n(1), d_n(2)].
```

The two available identities are

```text
B_n d_(n+1) = lambda_n d_n,                          (0.1)
T_n^T M_n = sigma_n I.                               (0.2)
```

The target is

```text
scale(n+1) w_(n+1) = scale(n) w_n T_n,               (0.3)
```

with

```text
scale(0)=1,
scale(n+1)=scale(n) * 2(2n+5)/(n+1).                 (0.4)
```

All matrices below are over `ℝ`; casts from the integral challenge matrix are entrywise.

# 1. Exact transpose/sign derivation

The repository theorem

```lean
dualVector_adjoint n i :
  ∑ j : Fin 3,
    (positiveMatrix (n : ℤ) i j : ℝ) * dualVector (n+1) j
  = dualCertLambda (n : ℝ) * dualVector n i
```

is exactly the component form of (0.1).

The existing sign-conjugation theorem is

```lean
positiveMatrix_eq_sign_conjugate (n : ℤ) (i j : Fin 3) :
  positiveMatrix n i j =
    -coordinateSign i * challengeMatrix n i j * coordinateSign j.
```

After casting to `ℝ`, (0.1) is

```text
sum_j [-s_i M_n(i,j) s_j] d_(n+1)(j)
  = lambda_n d_n(i).                                 (1.1)
```

Multiply (1.1) by `-s_i`.  Since `s_i^2=1`,

```text
sum_j M_n(i,j) [s_j d_(n+1)(j)]
  = -lambda_n [s_i d_n(i)].                          (1.2)
```

Therefore the first intermediate vector equality is

```text
M_n (J d_(n+1)) = -lambda_n (J d_n).                 (V1)
```

Transpose (V1).  Since `J^T=J`,

```text
(J d_(n+1))^T M_n^T
  = -lambda_n (J d_n)^T.
```

By the definition of `w`, the second intermediate equality is

```text
w_(n+1) M_n^T = -lambda_n w_n.                       (V2)
```

Transpose (0.2):

```text
M_n^T T_n = sigma_n I.                               (1.3)
```

Multiply (V2) on the right by `T_n` and use (1.3):

```text
w_(n+1) M_n^T T_n = -lambda_n w_n T_n,
sigma_n w_(n+1)   = -lambda_n w_n T_n.               (V3)
```

Since `lambda_n > 0`,

```text
w_n T_n = (-sigma_n/lambda_n) w_(n+1).               (1.4)
```

This orientation is the important one.  The recurrence is for the row `w_n` by **right** multiplication with `T_n`.  No inverse of `M_n` or `T_n` is used.

# 2. Scalar cancellation

Put

```text
A_n=(n+2)^2(n+3)^2(2n+7)^2.
```

Then

```text
lambda_n=(n+1)A_n,
sigma_n=-2(2n+5)A_n.
```

Hence

```text
-sigma_n/lambda_n
 = 2(2n+5)A_n / ((n+1)A_n)
 = 2(2n+5)/(n+1).                                    (2.1)
```

Every cancelled factor is nonzero for `n : ℕ`.

A direct Lean lemma should be:

```lean
def dualLambda (n : ℕ) : ℝ := dualCertLambda (n : ℝ)

def trajectorySigma (n : ℕ) : ℝ :=
  -2 * ((n : ℝ) + 2)^2 * ((n : ℝ) + 3)^2 *
    (2 * (n : ℝ) + 5) * (2 * (n : ℝ) + 7)^2

lemma dualLambda_pos (n : ℕ) : 0 < dualLambda n := by
  unfold dualLambda dualCertLambda
  positivity

lemma dualLambda_ne (n : ℕ) : dualLambda n ≠ 0 :=
  (dualLambda_pos n).ne'

lemma trajectorySigma_ne (n : ℕ) : trajectorySigma n ≠ 0 := by
  unfold trajectorySigma
  have h2 : ((n : ℝ) + 2) ≠ 0 := by positivity
  have h3 : ((n : ℝ) + 3) ≠ 0 := by positivity
  have h5 : (2 * (n : ℝ) + 5) ≠ 0 := by positivity
  have h7 : (2 * (n : ℝ) + 7) ≠ 0 := by positivity
  positivity

lemma neg_sigma_div_lambda (n : ℕ) :
    -trajectorySigma n / dualLambda n =
      2 * (2 * (n : ℝ) + 5) / ((n : ℝ) + 1) := by
  have h1 : ((n : ℝ) + 1) ≠ 0 := by positivity
  have h2 : ((n : ℝ) + 2) ≠ 0 := by positivity
  have h3 : ((n : ℝ) + 3) ≠ 0 := by positivity
  have h7 : (2 * (n : ℝ) + 7) ≠ 0 := by positivity
  unfold trajectorySigma dualLambda dualCertLambda
  field_simp [h1, h2, h3, h7]
  ring
```

`trajectorySigma_ne` is useful elsewhere, but it is **not needed** for the row recurrence.  The only division in (1.4) is by `lambda_n`.

The nonzero hypotheses which `field_simp` may ask for are precisely

```text
n+1 != 0,
n+2 != 0,
n+3 != 0,
2n+7 != 0.
```

They are all discharged by `positivity`.  There is no denominator `2n+5` in (2.1).

# 3. Lean definitions for the signed row

Use functions rather than a `1 × 3` matrix.  This avoids coercion and transpose noise.

```lean
def challengeMatrixR (n : ℕ) : Matrix (Fin 3) (Fin 3) ℝ :=
  fun i j => (challengeMatrix (n : ℤ) i j : ℝ)

/-- `d_n^T J`, represented as a function on `Fin 3`. -/
def dualRow (n : ℕ) : Fin 3 → ℝ :=
  fun j => (coordinateSign j : ℝ) * dualVector n j

@[simp] lemma dualRow_zero (n : ℕ) :
    dualRow n 0 = dualVector n 0 := by
  simp [dualRow, coordinateSign]

@[simp] lemma dualRow_one (n : ℕ) :
    dualRow n 1 = -dualVector n 1 := by
  simp [dualRow, coordinateSign]

@[simp] lemma dualRow_two (n : ℕ) :
    dualRow n 2 = dualVector n 2 := by
  simp [dualRow, coordinateSign]

lemma coordinateSign_sq_real (i : Fin 3) :
    (coordinateSign i : ℝ)^2 = 1 := by
  fin_cases i <;> norm_num [coordinateSign]

/-- Right multiplication of a row represented as a function. -/
def rowMul (x : Fin 3 → ℝ) (A : Matrix (Fin 3) (Fin 3) ℝ) : Fin 3 → ℝ :=
  fun k => ∑ i : Fin 3, x i * A i k
```

# 4. First componentwise equality: `M_n (Jd_(n+1)) = -lambda_n Jd_n`

The most robust proof expands `Fin 3` only after applying the adjoint theorem.

```lean
lemma challenge_mul_signedDual_succ (n : ℕ) (i : Fin 3) :
    ∑ j : Fin 3,
        (challengeMatrix (n : ℤ) i j : ℝ) * dualRow (n+1) j
      = -dualLambda n * dualRow n i := by
  have h := dualVector_adjoint n i
  -- Cast the entrywise sign-conjugation identity.
  have hsign (r c : Fin 3) :
      (positiveMatrix (n : ℤ) r c : ℝ) =
        -(coordinateSign r : ℝ) *
          (challengeMatrix (n : ℤ) r c : ℝ) *
          (coordinateSign c : ℝ) := by
    exact_mod_cast positiveMatrix_eq_sign_conjugate (n : ℤ) r c

  -- Expanding the three coordinates makes all signs literal ±1.
  rw [Fin.sum_univ_three] at h ⊢
  simp only [hsign] at h
  fin_cases i <;>
    simp [dualRow, dualLambda, coordinateSign, Matrix.cons_val_two] at h ⊢ <;>
    linarith
```

If `simp only [hsign]` does not rewrite beneath the cast, replace it by

```lean
simp_rw [hsign] at h
```

The proof is intentionally componentwise.  For each fixed `i`, it is just multiplication of the adjoint equation by `-s_i`.

An alternative generic algebra proof is possible using `coordinateSign_sq_real`, but the `fin_cases` version is less brittle with casts.

This lemma is (V1) in components.

# 5. Second componentwise equality: transposed row form

Because real multiplication is commutative, (V2) follows by a one-line rearrangement:

```lean
lemma dualRow_mul_challengeTranspose (n : ℕ) (i : Fin 3) :
    ∑ j : Fin 3,
        dualRow (n+1) j * (challengeMatrix (n : ℤ) i j : ℝ)
      = -dualLambda n * dualRow n i := by
  simpa [mul_comm] using challenge_mul_signedDual_succ n i
```

This is exactly coordinate `i` of

```text
w_(n+1) M_n^T = -lambda_n w_n.
```

Note the indices: `(M_n^T)(j,i)=M_n(i,j)`, so the matrix entry in this lemma is `challengeMatrix ... i j`, not `j i`.

# 6. Transposing `T_n^T M_n = sigma_n I` without matrix simp

Assume the independently checked identity is available in the shape

```lean
trajectory_transpose_mul_challenge (n : ℕ) :
  (trajectoryMatrixR n).transpose * challengeMatrixR n =
    trajectorySigma n • (1 : Matrix (Fin 3) (Fin 3) ℝ)
```

The needed transpose is `M_n^T T_n=sigma_n I`.  Prove it componentwise by evaluating the existing identity at `(k,j)`:

```lean
lemma challengeTranspose_mul_trajectory
    (n : ℕ) (j k : Fin 3) :
    ∑ i : Fin 3,
        (challengeMatrix (n : ℤ) i j : ℝ) *
          trajectoryMatrixR n i k
      = trajectorySigma n *
          (1 : Matrix (Fin 3) (Fin 3) ℝ) j k := by
  have h := congrArg
    (fun A : Matrix (Fin 3) (Fin 3) ℝ => A k j)
    (trajectory_transpose_mul_challenge n)
  simp only [Matrix.mul_apply, Matrix.transpose_apply, Matrix.smul_apply] at h
  -- `h` has `T(i,k) * M(i,j)`; commute the scalar factors.
  simpa [mul_comm, Matrix.one_apply, eq_comm] using h
```

Depending on how scalar multiplication of matrices simplifies in the local file, the right side may appear as

```lean
trajectorySigma n * ((1 : Matrix (Fin 3) (Fin 3) ℝ) k j)
```

instead.  `Matrix.one_apply` plus `eq_comm` converts `k=j` to `j=k`.

This componentwise lemma is the exact content of

```text
M_n^T T_n = sigma_n I.
```

No theorem about `Matrix.transpose_mul` is required.

# 7. Third equality: `sigma_n w_(n+1) = -lambda_n w_n T_n`

The following sum proof keeps the orientation explicit and avoids matrix inverses.

```lean
lemma sigma_mul_dualRow_succ
    (n : ℕ) (k : Fin 3) :
    trajectorySigma n * dualRow (n+1) k =
      -dualLambda n * rowMul (dualRow n) (trajectoryMatrixR n) k := by
  unfold rowMul

  calc
    -dualLambda n *
        (∑ i : Fin 3, dualRow n i * trajectoryMatrixR n i k)
      = ∑ i : Fin 3,
          (-dualLambda n * dualRow n i) *
            trajectoryMatrixR n i k := by
          rw [Finset.mul_sum]
          apply Finset.sum_congr rfl
          intro i hi
          ring

    _ = ∑ i : Fin 3,
          (∑ j : Fin 3,
              dualRow (n+1) j *
                (challengeMatrix (n : ℤ) i j : ℝ)) *
            trajectoryMatrixR n i k := by
          apply Finset.sum_congr rfl
          intro i hi
          rw [dualRow_mul_challengeTranspose n i]

    _ = ∑ i : Fin 3, ∑ j : Fin 3,
          dualRow (n+1) j *
            (challengeMatrix (n : ℤ) i j : ℝ) *
            trajectoryMatrixR n i k := by
          apply Finset.sum_congr rfl
          intro i hi
          rw [Finset.sum_mul]
          apply Finset.sum_congr rfl
          intro j hj
          ring

    _ = ∑ j : Fin 3, ∑ i : Fin 3,
          dualRow (n+1) j *
            (challengeMatrix (n : ℤ) i j : ℝ) *
            trajectoryMatrixR n i k := by
          exact Finset.sum_comm

    _ = ∑ j : Fin 3,
          dualRow (n+1) j *
            (∑ i : Fin 3,
              (challengeMatrix (n : ℤ) i j : ℝ) *
                trajectoryMatrixR n i k) := by
          apply Finset.sum_congr rfl
          intro j hj
          rw [Finset.mul_sum]
          apply Finset.sum_congr rfl
          intro i hi
          ring

    _ = ∑ j : Fin 3,
          dualRow (n+1) j *
            (trajectorySigma n *
              (1 : Matrix (Fin 3) (Fin 3) ℝ) j k) := by
          apply Finset.sum_congr rfl
          intro j hj
          rw [challengeTranspose_mul_trajectory n j k]

    _ = trajectorySigma n * dualRow (n+1) k := by
          fin_cases k <;>
            simp [Fin.sum_univ_three, Matrix.one_apply]
```

The displayed `calc` starts with the right side of (V3) and ends with its left side.  If Lean expects the target in the opposite direction, use `.symm` on the completed calculation.

A shorter fallback, exploiting that the dimension is exactly three, is:

```lean
  have h0 := dualRow_mul_challengeTranspose n 0
  have h1 := dualRow_mul_challengeTranspose n 1
  have h2 := dualRow_mul_challengeTranspose n 2
  have t0 := challengeTranspose_mul_trajectory n 0 k
  have t1 := challengeTranspose_mul_trajectory n 1 k
  have t2 := challengeTranspose_mul_trajectory n 2 k
  simp only [Fin.sum_univ_three] at h0 h1 h2 t0 t1 t2 ⊢
  fin_cases k <;>
    simp [Matrix.one_apply] at t0 t1 t2 ⊢ <;>
    linear_combination
      (trajectoryMatrixR n 0 k) * h0 +
      (trajectoryMatrixR n 1 k) * h1 +
      (trajectoryMatrixR n 2 k) * h2 -
      (dualRow (n+1) 0) * t0 -
      (dualRow (n+1) 1) * t1 -
      (dualRow (n+1) 2) * t2
```

The first proof is structurally clearer; the second is useful if rewriting finite sums becomes awkward.

# 8. Unscaled and scaled row recurrences

First divide (V3) only by `lambda_n`.

```lean
lemma dualRow_mul_trajectory (n : ℕ) (k : Fin 3) :
    rowMul (dualRow n) (trajectoryMatrixR n) k =
      (-trajectorySigma n / dualLambda n) * dualRow (n+1) k := by
  have h := sigma_mul_dualRow_succ n k
  have hλ := dualLambda_ne n
  field_simp [hλ]
  -- After denominator clearing the target is
  -- `dualLambda n * rowMul ... = -trajectorySigma n * dualRow ...`.
  linarith
```

If `field_simp` normalizes products in an inconvenient order, use the explicit division lemma:

```lean
  apply (eq_div_iff hλ).2
  rw [div_mul_eq_mul_div]
  nlinarith [sigma_mul_dualRow_succ n k]
```

Now define the requested scale.

```lean
def dualScale : ℕ → ℝ
  | 0 => 1
  | n+1 => dualScale n *
      (2 * (2 * (n : ℝ) + 5) / ((n : ℝ) + 1))

@[simp] lemma dualScale_zero : dualScale 0 = 1 := rfl

@[simp] lemma dualScale_succ (n : ℕ) :
    dualScale (n+1) = dualScale n *
      (2 * (2 * (n : ℝ) + 5) / ((n : ℝ) + 1)) := rfl
```

The final recurrence is then purely rewriting:

```lean
theorem scaled_dualRow_recurrence (n : ℕ) :
    (fun k => dualScale (n+1) * dualRow (n+1) k) =
      (fun k => dualScale n *
        rowMul (dualRow n) (trajectoryMatrixR n) k) := by
  funext k
  rw [dualScale_succ, dualRow_mul_trajectory n k,
```

Equivalently, with row/matrix notation,

```text

```

No nonzero theorem for `dualScale n` is needed.  If desired, positivity follows immediately by induction because every factor in (0.4) is positive.

# 9. Initial pairing directly from the positive pairings

# 10. Minimal dependency/order checklist

The companion file should import at least the files exposing:

```text
positiveMatrix_eq_sign_conjugate,
dualVector_adjoint,
dualVector_initial_numerator_pair,
dualVector_initial_denominator_pair,

```

Recommended proof order:

```text
1. challengeMatrixR, trajectorySigma, dualLambda;
2. dualRow, rowMul, sign simp lemmas;
3. challenge_mul_signedDual_succ                 (V1);
4. dualRow_mul_challengeTranspose                (V2);
5. challengeTranspose_mul_trajectory             (transpose of T^T M=sigma I);
6. sigma_mul_dualRow_succ                        (V3);
7. neg_sigma_div_lambda;
8. dualRow_mul_trajectory;
9. dualScale and scaled_dualRow_recurrence;
10. initial sign lemmas and the two initial pairings.
```

The two orientation mistakes to guard against are:

```text
- `dualVector_adjoint` has `B(i,j)d'(j)`, so V1 is `M(i,j)w'(j)`.
- evaluating `T^T M=sigma I` at `(k,j)` gives the inner sum
  `sum_i T(i,k)M(i,j)`, which is the `(j,k)` entry of `M^T T`.
```

With those indices fixed, every remaining step is commutative-ring algebra.
