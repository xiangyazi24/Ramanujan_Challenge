# Exact structure of the eighth factorial moment and the genuine HM\(_8\) obstruction

## Executive verdict

The proposed “partition-type” analysis contains a crucial category error:

\[
(K_X(m))_8
\]

already excludes repeated prime labels. Its expansion contains **only ordered 8-tuples of pairwise distinct primes**. There are no diagonal partition types in HM\(_8\), and the bound \(|Z_p|=O(p^{2/3})\) is not being used to dispose of repeated-prime terms.

The exact expansion is

\[
F_8(X):=\sum_{0\le m<X^2}(K_X(m))_8
 =\sum_{(p_1,\ldots,p_8)\in\mathcal P_X^{\underline 8}}
 I(p_1,\ldots,p_8),
\]

where

\[
I(p_1,\ldots,p_8)
=\#\{0\le m<X^2:m\bmod p_i\in Z_{p_i}\ \forall i\}.
\]

For a fixed distinct tuple, CRT gives an exact product set of
\(\prod_i|Z_{p_i}|\) residues modulo
\(Q=p_1\cdots p_8\). Since \(Q\asymp X^8\) while the interval has length
\(M=X^2\), each residue tuple has at most one representative, but that only gives

\[
I(p_1,\ldots,p_8)\le\prod_i|Z_{p_i}|.
\]

The independent prediction contains the additional landing probability

\[
\frac{M}{Q}\asymp X^{-6}.
\]

Recovering this factor **on aggregate** is precisely HM\(_8\). It is not an endpoint error that can be handled by estimating finitely many diagonal patterns.

The current repository has an exact pair-Palm characterization. Put

\[
J_{p,q}=|\Omega_p\cap\Omega_q|,
\qquad
T_{p,q}^{[6]}
 =\sum_{m\in\Omega_p\cap\Omega_q}(K_X(m)-2)_6,
\]

and

\[
\lambda_{p,q}=\sum_{\ell\in\mathcal P_X\setminus\{p,q\}}
\frac{|Z_\ell|}{\ell}.
\]

Then

\[
F_8(X)=\sum_{p\ne q}T_{p,q}^{[6]},
\]

and, with

\[
\mathscr P_8(X)=
\sum_{p\ne q}
\left(T_{p,q}^{[6]}-J_{p,q}\lambda_{p,q}^6\right)_+,
\]

one has the exact sandwich

\[
\boxed{
\mathscr P_8(X)\le F_8(X)
\le \mathscr P_8(X)+4X^2\lambda_X^8.}
\]

Therefore HM\(_8\) is equivalent to

\[
\boxed{
\mathscr P_8(X)\ll X^{2+o(1)}\lambda_X^8.}
\]

This locates the missing arithmetic exactly: it is the **positive sixth-factorial overload of additional prime hits after conditioning on an actual two-prime CRT intersection**.

The current primewise and pairwise package cannot prove this. The repository’s anchored-rainbow-star construction has \(|Z_p|\le2\), reflection, no adjacent zeros, interval sparsity, the correct second moment, uniformly bounded row codegree, and even the existing value-fiber/energy constraints, yet it has one row hit by \(\asymp X/\log X\) primes. Consequently

\[
F_8^*(X)\asymp\frac{X^8}{(\log X)^8},
\qquad
X^2(\lambda_X^*)^8\asymp\frac{X^2}{(\log X)^8}.
\]

It violates HM\(_8\) by the exact missing factor \(X^6\). This is not an actual Apéry counterexample; it is a sharp no-go theorem for every argument using only the currently proved local and pairwise facts.

The Kummer-Mellin supertrace is a potentially relevant source of **new** arithmetic structure, but no existing Deligne, trace-function, or Frobenius large-sieve theorem converts it into the required mixed-characteristic short-interval CRT discrepancy. HM\(_8\) is therefore not currently provable by careful bookkeeping alone.

## 1. Notation and two corrections to the premise

Let

\[
\mathcal P_X=\{p\text{ prime}:X<p\le2X\},
\qquad M=X^2,
\]

and write

\[
z_p=|Z_p|,
\qquad x_p=\frac{z_p}{p},
\qquad \lambda=\lambda_X=\sum_{p\in\mathcal P_X}x_p.
\]

Put

\[
\Omega_p=\{0\le m<M:m\bmod p\in Z_p\},
\qquad f_p(m)=\mathbf1_{\Omega_p}(m),
\]

so

\[
K(m)=K_X(m)=\sum_{p\in\mathcal P_X}f_p(m).
\]

### Correction 1: factorial moments have no repeated primes

Because the \(f_p(m)\) are \(0\)-\(1\) variables,

\[
(K(m))_8
=\sum_{\substack{p_1,\ldots,p_8\in\mathcal P_X\\
                    p_i\text{ pairwise distinct}}}
 f_{p_1}(m)\cdots f_{p_8}(m).
\tag{1.1}
\]

Thus every prime occurs with multiplicity exactly one.

### Correction 2: the CRT error is not \(O(1)\) for the full zero-set intersection

For one fixed residue vector

\[
(r_1,\ldots,r_8)\in Z_{p_1}\times\cdots\times Z_{p_8},
\]

the number of representatives in \([0,M)\) is

\[
\frac{M}{Q}+O(1),
\qquad Q=p_1\cdots p_8.
\]

But there are \(\prod_i z_{p_i}\) residue vectors. Therefore the fixed-prime-tuple formula is

\[
I(p_1,\ldots,p_8)
=\frac{M}{Q}\prod_i z_{p_i}
+O\!\left(\prod_i z_{p_i}\right),
\tag{1.2}
\]

not a main term plus an aggregate \(O(1)\) error. Since \(Q>M\), the error in (1.2) is not a small technical boundary term; it is the whole short-interval landing problem.

## 2. Part (a): the exact expansion and the partition issue

### 2.1 The HM\(_8\) expansion

Summing (1.1) over \(m\) gives

\[
\boxed{
F_8(X)
=\sum_{(p_1,\ldots,p_8)\in\mathcal P_X^{\underline 8}}
I(p_1,\ldots,p_8).}
\tag{2.1}
\]

Equivalently, with unordered 8-element prime sets,

\[
F_8(X)
=8!\sum_{\{p_1,\ldots,p_8\}\subset\mathcal P_X}
I(p_1,\ldots,p_8).
\tag{2.2}
\]

The only equality pattern is

\[
1+1+1+1+1+1+1+1.
\]

It “dominates” because it is the entire factorial moment.

### 2.2 What the full partition expansion would be for the raw moment \(K^8\)

If the intended quantity were

\[
\sum_{m<M}K(m)^8,
\]

then set partitions do occur. Since \(f_p^r=f_p\), a prime repeated \(r\) times still contributes only one local indicator. If a partition of the eight positions has \(j\) blocks, its contribution is a copy of \((K)_j\).

The complete grouping is

\[
\boxed{
K^8
=(K)_8+28(K)_7+266(K)_6+1050(K)_5
+1701(K)_4+966(K)_3+127(K)_2+K.}
\tag{2.3}
\]

The coefficients are the Stirling numbers \(S(8,j)\).

More finely, for an integer partition
\(\nu=1^{m_1}2^{m_2}\cdots8^{m_8}\vdash8\), the number of set partitions with that block-size pattern is

\[
c_\nu
=\frac{8!}{\prod_{r=1}^8(r!)^{m_r}m_r!}.
\tag{2.4}
\]

The full list is:

| multiplicity type | distinct primes \(j\) | coefficient \(c_\nu\) |
|---|---:|---:|
| \(8\) | 1 | 1 |
| \(7+1\) | 2 | 8 |
| \(6+2\) | 2 | 28 |
| \(6+1+1\) | 3 | 28 |
| \(5+3\) | 2 | 56 |
| \(5+2+1\) | 3 | 168 |
| \(5+1+1+1\) | 4 | 56 |
| \(4+4\) | 2 | 35 |
| \(4+3+1\) | 3 | 280 |
| \(4+2+2\) | 3 | 210 |
| \(4+2+1+1\) | 4 | 420 |
| \(4+1+1+1+1\) | 5 | 70 |
| \(3+3+2\) | 3 | 280 |
| \(3+3+1+1\) | 4 | 280 |
| \(3+2+2+1\) | 4 | 840 |
| \(3+2+1+1+1\) | 5 | 560 |
| \(3+1+1+1+1+1\) | 6 | 56 |
| \(2+2+2+2\) | 4 | 105 |
| \(2+2+2+1+1\) | 5 | 420 |
| \(2+2+1+1+1+1\) | 6 | 210 |
| \(2+1+1+1+1+1+1\) | 7 | 28 |
| \(1+1+1+1+1+1+1+1\) | 8 | 1 |

Consequently

\[
\sum_{m<M}K(m)^8
=F_8+28F_7+266F_6+1050F_5
+1701F_4+966F_3+127F_2+F_1,
\tag{2.5}
\]

where \(F_j=\sum_m(K(m))_j\).

Under the independent sparse model \(F_j\sim M\lambda^j\), the raw eighth moment is the Touchard polynomial

\[
M\bigl(\lambda^8+28\lambda^7+266\lambda^6+1050\lambda^5
+1701\lambda^4+966\lambda^3+127\lambda^2+\lambda\bigr).
\]

If \(\lambda\to0\), as in the empirical scale \(\lambda\asymp1/\log X\), the heavily diagonal raw-moment terms dominate. This is exactly why the project uses falling factorials: HM\(_8\) isolates the genuinely eight-prime event.

## 3. Part (b): the distinct-prime CRT main term and the exact error

Fix an ordered pairwise-distinct tuple

\[
\mathbf p=(p_1,\ldots,p_8),
\qquad Q=\prod_{i=1}^8p_i.
\]

CRT gives a bijection

\[
\prod_{i=1}^8\mathbb F_{p_i}
\longrightarrow \mathbb Z/Q\mathbb Z.
\]

Let

\[
a_{\mathbf p}(r_1,\ldots,r_8)\in[0,Q)
\]

denote the standard representative of the CRT lift. Because

\[
Q>X^8>M=X^2,
\]

one has the exact formula

\[
\boxed{
I(\mathbf p)
=\#\left\{
(r_1,\ldots,r_8)\in\prod_iZ_{p_i}:
 a_{\mathbf p}(r_1,\ldots,r_8)<M
\right\}.}
\tag{3.1}
\]

The independent prediction is

\[
I_{\mathrm{ind}}(\mathbf p)
=\frac{M}{Q}\prod_i z_{p_i}
=M\prod_i x_{p_i}.
\tag{3.2}
\]

Define the signed discrepancy

\[
\Delta(\mathbf p)
=I(\mathbf p)-M\prod_i x_{p_i}.
\tag{3.3}
\]

Then

\[
F_8(X)
=M B_8(X)+\Delta_8(X),
\tag{3.4}
\]

where

\[
B_8(X)
=\sum_{\mathbf p\in\mathcal P_X^{\underline8}}
 \prod_i x_{p_i}
=8!e_8((x_p)_{p\in\mathcal P_X}),
\tag{3.5}
\]

and

\[
\Delta_8(X)=
\sum_{\mathbf p\in\mathcal P_X^{\underline8}}\Delta(\mathbf p).
\]

Since

\[
0\le B_8(X)\le\lambda_X^8,
\tag{3.6}
\]

the main term is already at the required HM\(_8\) scale. Thus HM\(_8\) is equivalent, up to the harmless main term, to the one-sided aggregate estimate

\[
\boxed{
(\Delta_8(X))_+
\ll X^{2+o(1)}\lambda_X^8.}
\tag{3.7}
\]

Bounding

\[
\sum_{\mathbf p}|\Delta(\mathbf p)|
\]

would be much stronger than necessary.

### 3.1 Why HM\(_2\) is special

For two shell primes,

\[
pq>X^2=M,
\]

but also \(pq\asymp M\). CRT injectivity gives

\[
|\Omega_p\cap\Omega_q|\le z_pz_q,
\]

and therefore

\[
F_2(X)\le\left(\sum_pz_p\right)^2
\le(2X\lambda)^2=4M\lambda^2.
\tag{3.8}
\]

No additional small landing probability is needed because \(M/(pq)\asymp1\).

For eight primes, the same argument gives only

\[
F_8(X)\le\left(\sum_pz_p\right)^8
\le(2X\lambda)^8.
\tag{3.9}
\]

Compared with the target \(M\lambda^8=X^2\lambda^8\), (3.9) misses the factor

\[
X^{8-2}=X^6.
\]

This is the clean conceptual distinction between HM\(_2\) and HM\(_8\).

### 3.2 Exact Fourier form of the CRT error

Let

\[
A_{\mathbf p}\subset\mathbb Z/Q\mathbb Z
\]

be the CRT image of \(Z_{p_1}\times\cdots\times Z_{p_8}\). Thus

\[
|A_{\mathbf p}|=\prod_i z_{p_i}.
\]

For unnormalized Fourier transforms on \(\mathbb Z/Q\mathbb Z\),

\[
\widehat{1_I}(h)
=\sum_{0\le m<M}e_Q(-hm),
\]

and

\[
\widehat{1_{Z_p}}(a)
=\sum_{r\in Z_p}e_p(-ar),
\]

one has

\[
I(\mathbf p)
=\frac1Q\sum_{h\bmod Q}
\widehat{1_I}(-h)\widehat{1_{A_{\mathbf p}}}(h).
\tag{3.10}
\]

Under CRT,

\[
\widehat{1_{A_{\mathbf p}}}(h)
=\prod_{i=1}^8
\widehat{1_{Z_{p_i}}}(u_i(h)),
\tag{3.11}
\]

where each \(u_i(h)\) is the reduction of \(h\) modulo \(p_i\), multiplied by a harmless CRT unit. The zero frequency in (3.10) gives (3.2), and

\[
\boxed{
\Delta(\mathbf p)
=\frac1Q\sum_{0\ne h\bmod Q}
\widehat{1_I}(-h)
\prod_{i=1}^8\widehat{1_{Z_{p_i}}}(u_i(h)).}
\tag{3.12}
\]

The unconditional one-prime information is only

\[
|\widehat{1_{Z_p}}(a)|\le z_p,
\qquad
\sum_{a\bmod p}|\widehat{1_{Z_p}}(a)|^2=pz_p,
\tag{3.13}
\]

plus the structural facts about \(Z_p\). The interval transform satisfies

\[
|\widehat{1_I}(h)|
\le\min\left(M,\frac1{2\|h/Q\|}\right).
\tag{3.14}
\]

These identities do not yield (3.7). Even the generic Cauchy bound

\[
|\Delta(\mathbf p)|
\le\sqrt{M\prod_i z_{p_i}}
\tag{3.15}
\]

is far above the aggregate target after summing over prime tuples.

There is no known exponential-sum estimate that recovers the factor \(M/Q\asymp X^{-6}\) uniformly or on the required aggregate scale. Standard trace-function results concern bounded-conductor functions over one finite field. Here the modulus is the product of eight varying characteristics, the interval is extremely short relative to \(Q\), and the local zero indicators are not presently realized as one bounded-conductor trace function on \(\mathbb Z/Q\mathbb Z\).

## 4. Part (c): what happens to the alleged diagonal terms?

### 4.1 They are absent from HM\(_8\)

There is no contribution with a prime of multiplicity \(r\ge2\) in (2.1). Therefore no estimate of the form

\[
\frac{|Z_p|^r}{p}
\]

is needed for HM\(_8\).

Moreover, that expression is not the correct local factor in the raw moment either. If the same prime occurs \(r\) times, then

\[
f_p(m)^r=f_p(m),
\]

so the local density is

\[
\frac{z_p}{p},
\]

once, not \(z_p^r/p\).

### 4.2 Repeated labels occur only in the Poisson comparison \(\lambda^8\)

The independent Bernoulli factorial baseline is

\[
B_8(X)=\sum_{p_1,\ldots,p_8\ \mathrm{distinct}}
\prod_i x_{p_i}.
\]

The simpler Poisson upper baseline \(\lambda^8\) also contains repeated prime labels. This only makes it larger and therefore safer for an upper bound.

Quantitatively, by assigning every repeated ordered tuple to one repeated pair of positions,

\[
0\le\lambda^8-B_8
\le\binom82\left(\sum_px_p^2\right)\lambda^6.
\tag{4.1}
\]

Since \(z_p\ll p^{2/3}\),

\[
x_p\ll X^{-1/3},
\qquad
\sum_px_p^2\le(\max_px_p)\lambda\ll X^{-1/3}\lambda.
\]

Hence

\[
0\le\lambda^8-B_8
\ll X^{-1/3}\lambda^7.
\tag{4.2}
\]

This is a statement about the comparison baseline, not an HM\(_8\) diagonal.

### 4.3 What is actually known unconditionally for \(F_8\)

Let

\[
L_X=\#\{p\in\mathcal P_X:z_p>0\}.
\]

The current pair-Palm analysis proves

\[
F_8(X)
\le(L_X-2)_6F_2(X)
\le4X^2\lambda^2(L_X-2)_6.
\tag{4.3}
\]

Also

\[
L_X\le\sum_pz_p\le2X\lambda,
\qquad
L_X\ll\frac{X}{\log X}.
\]

Therefore

\[
\boxed{
F_8(X)
\ll X^8\lambda_X^2
\min\left\{\lambda_X,\frac1{\log X}\right\}^{6}.}
\tag{4.4}
\]

Using \(z_p\ll p^{2/3}\), so that

\[
\lambda_X\ll\frac{X^{2/3}}{\log X},
\]

gives

\[
\boxed{
F_8(X)\ll\frac{X^{28/3}}{(\log X)^8}.}
\tag{4.5}
\]

If \(\lambda_X\) were as large as its unconditional upper bound, the HM\(_8\) target would be

\[
X^2\lambda_X^8
\ll\frac{X^{22/3}}{(\log X)^8},
\]

so the current envelope still misses by \(X^2\). At the empirical scale \(\lambda_X\asymp1/\log X\), (4.4) is

\[
F_8(X)\ll\frac{X^8}{(\log X)^8},
\]

whereas HM\(_8\) asks for

\[
\frac{X^2}{(\log X)^8};
\]

the gap is \(X^6\).

## 5. The exact algebraic structure that replaces the partition analysis

The most useful exact decomposition is not by repeated-prime partitions but by conditioning on a genuine two-prime locus.

For ordered \(p\ne q\), put

\[
J_{p,q}=|\Omega_p\cap\Omega_q|
\]

and

\[
T_{p,q}^{[6]}
=\sum_{m\in\Omega_p\cap\Omega_q}(K(m)-2)_6.
\tag{5.1}
\]

Equivalently,

\[
T_{p,q}^{[6]}
=\sum_{\substack{\ell_1,\ldots,\ell_6\notin\{p,q\}\\
                  \ell_i\text{ pairwise distinct}}}
|\Omega_p\cap\Omega_q\cap
 \Omega_{\ell_1}\cap\cdots\cap\Omega_{\ell_6}|.
\tag{5.2}
\]

At a row with \(K(m)=t\), there are \((t)_2\) ordered anchor pairs and then \((t-2)_6\) ordered extensions. Therefore

\[
(t)_2(t-2)_6=(t)_8,
\]

which gives the exact identity

\[
\boxed{
F_8(X)=\sum_{p\ne q}T_{p,q}^{[6]}.}
\tag{5.3}
\]

The exact independent Bernoulli extension baseline is

\[
\Lambda_{p,q}^{[6]}
=6!e_6\left(
\left(\frac{z_\ell}{\ell}\right)_{\ell\notin\{p,q\}}
\right).
\tag{5.4}
\]

It satisfies

\[
0\le\Lambda_{p,q}^{[6]}\le\lambda_{p,q}^6.
\]

Using the slightly larger Poisson baseline gives

\[
\mathscr P_8(X)
=\sum_{p\ne q}
\left(T_{p,q}^{[6]}-J_{p,q}\lambda_{p,q}^6\right)_+.
\tag{5.5}
\]

The repository proves

\[
\boxed{
\mathscr P_8(X)
\le F_8(X)
\le\mathscr P_8(X)+4X^2\lambda_X^8.}
\tag{5.6}
\]

Thus the exact residual is

\[
\boxed{
\mathrm{PP}_8:\quad
\sum_{p\ne q}
\left(
\sum_{m\in\Omega_p\cap\Omega_q}(K(m)-2)_6
-J_{p,q}\lambda_{p,q}^6
\right)_+
\ll X^{2+o(1)}\lambda_X^8.}
\tag{5.7}
\]

Statement (5.7) is equivalent to HM\(_8\), not a proof of it and not a weaker theorem in disguise.

One can also package the conditional distribution by

\[
\Phi_{p,q}(z)
=\frac1{J_{p,q}}
\sum_{m\in\Omega_p\cap\Omega_q}
\prod_{\ell\notin\{p,q\}}(1+zf_\ell(m)),
\]

when \(J_{p,q}>0\). Then

\[
\Phi_{p,q}^{(6)}(0)=\frac{T_{p,q}^{[6]}}{J_{p,q}}.
\]

HM\(_8\) asks, on average with weight \(J_{p,q}\), that the positive excess of this sixth conditional factorial coefficient over the Poisson value \(\lambda_{p,q}^6\) be at most the independence scale.

This is the exact algebraic content of the hypothesis.

## 6. Part (d): the precise combinatorial obstruction

### 6.1 CRT injectivity is not CRT equidistribution

For a fixed tuple of eight primes and eight zero residues, CRT produces one residue modulo \(Q\). Since \(Q>M\), at most one representative lies below \(M\). To prove HM\(_8\), one must show that only the expected fraction

\[
\frac{M}{Q}\asymp X^{-6}
\]

of all zero-residue tuples have that representative below \(M\).

No current theorem gives that selection factor.

### 6.2 The anchored-rainbow-star no-go theorem

The repository constructs an abstract family as follows. Choose one row

\[
m_0\asymp X^2
\]

and, for almost every shell prime, set

\[
Z_p^*=\{m_0\bmod p,\ p-1-(m_0\bmod p)\}.
\]

Then all active primes hit \(m_0\). If \(L\asymp X/\log X\) is the number of active primes,

\[
K_X^*(m_0)=L,
\qquad
F_8^*(X)\ge(L)_8\asymp\frac{X^8}{(\log X)^8}.
\]

At the same time

\[
\lambda_X^*\asymp\frac1{\log X}.
\]

Thus

\[
\frac{F_8^*(X)}{X^2(\lambda_X^*)^8}\asymp X^6.
\tag{6.1}
\]

The model still satisfies:

- \(|Z_p^*|\le2\);
- reflection invariance;
- no adjacent elements;
- the proved interval sparsity condition;
- the universal HM\(_2\) bound;
- the natural centered second-moment scale;
- a uniform \(O(1)\) common-row codegree;
- extensions to value maps satisfying the present fiber and collision-energy bounds;
- the currently available necessary gap-polynomial certificate.

Therefore no combination of those facts can prove HM\(_8\). A successful proof must use an Apéry-specific cross-prime restriction absent from the star.

### 6.3 Cauchy-Schwarz does not bootstrap HM\(_2\) to HM\(_8\)

The exact overlap identity gives, at \(k=8\),

\[
F_8^2
\le F_2\bigl(
F_{14}+36F_{13}+450F_{12}+2400F_{11}
+5400F_{10}+4320F_9+720F_8
\bigr).
\tag{6.2}
\]

The extra terms record overlaps between two ordered six-prime extension tuples. They cannot be discarded. Hence repeated applications of Cauchy-Schwarz move the problem to still higher moments rather than closing it from HM\(_2\).

### 6.4 Lucas congruences and integer height do not rule out a star

Lucas does supply a genuine common-integer coupling:

\[
m\bmod p\in Z_p\quad\Longrightarrow\quad p\mid b_m.
\]

Therefore the product of all shell primes counted by \(K_X(m)\) divides \(b_m\). But the exponential height bound

\[
\log b_m=O(m)
\]

only gives

\[
K_X(m)\log X\le O(m).
\]

For \(m<X^2\), this is

\[
K_X(m)\ll\frac{X^2}{\log X},
\]

which is weaker than the trivial number of shell primes \(O(X/\log X)\). Thus Lucas plus growth does not provide the missing \(X^{-6}\) landing factor.

### 6.5 Verdict on “finitely many partition types”

There are not finitely many analytic errors corresponding to diagonal partitions that remain to be checked. There is one all-distinct term, and it contains a high-dimensional short-interval CRT discrepancy. The anchored-star construction proves that current one-prime and two-prime estimates leave this discrepancy completely uncontrolled.

## 7. Part (e): what the Kummer-Mellin supertrace can and cannot do

The repository proves, for \(0\le j\le p-2\),

\[
\boxed{
b_j
\equiv-
\sum_{(x,y,z)\in(\mathbb F_p^\times)^3}
\Lambda(x,y,z)^j\pmod p,}
\tag{7.1}
\]

for one fixed Laurent polynomial \(\Lambda\). It also constructs a rank-one Kummer sheaf on a fixed toric complement whose Frobenius supertrace

\[
\widetilde c_{p,j}^{\mathrm{tor}}
\]

reduces modulo a prime over \(p\) to \(b_j\). The geometric Betti complexity of this local object is uniformly bounded in \((p,j)\).

This is substantial structure, but it does not currently estimate HM\(_8\), for four separate reasons.

### 7.1 Exact zero is a defining-characteristic divisibility condition

The condition is

\[
\widetilde c_{p,j}^{\mathrm{tor}}\equiv0\pmod{\mathfrak p},
\]

not

\[
\widetilde c_{p,j}^{\mathrm{tor}}=0
\]

as a characteristic-zero Frobenius trace. For example, the repository records

\[
\widetilde c_{11,5}^{\mathrm{tor}}=-33\ne0,
\qquad
b_5\equiv0\pmod{11}.
\]

Deligne’s complex absolute-value bounds do not control this \(p\)-adic divisibility event.

### 7.2 The index \(j\) is a Mellin-character exponent, not a geometric base point

For each \(j\), one twists the fixed toric object by a different Kummer character. This is well suited to Mellin-transform monodromy, but the desired statistic counts exact zero reductions of the Mellin coefficients as \(j\) varies. Existing equidistribution of normalized complex Mellin traces is not a local-limit theorem modulo the varying defining prime.

### 7.3 The eight factors live in eight different characteristics

For HM\(_8\), the relevant expression is a correlation of

\[
1_{b_{m\bmod p_i}\equiv0\pmod{p_i}}
\]

for eight distinct primes \(p_i\). There is no single finite field over which the eight local sheaves can be tensored and then handled by one Grothendieck-Lefschetz trace formula.

### 7.4 Zero detection is nonlinear

Additive orthogonality gives

\[
1_{b_j=0}
=\frac1p\sum_{u\in\mathbb F_p}e_p(ub_j).
\]

Substituting (7.1) produces

\[
e_p\left(-u\sum_{(x,y,z)}\Lambda(x,y,z)^j\right),
\]

which is the exponential of a complete character sum, not a linear trace-function sum to which Deligne applies directly. Treating each \(u\) separately also loses the cancellation among the \(p\) zero-detection frequencies.

Most decisively, even perfect one-prime information such as \(|Z_p|\le2\) and \(|\widehat{1_{Z_p}}|\le2\) would not prove HM\(_8\): the anchored-star model has exactly those properties and still violates the target by \(X^6\).

### 7.5 What a successful Kummer-Mellin use would have to prove

The geometry would need to produce a genuinely mixed-prime theorem, for example either

\[
(\Delta_8(X))_+
\ll X^{2+o(1)}\lambda_X^8,
\tag{7.2}
\]

or the equivalent pair-Palm estimate (5.7). This would be an adelic or mixed-characteristic local-limit/large-sieve theorem for the reductions of the Kummer-Mellin supertraces along the short CRT section.

No current Deligne theorem, Fouvry-Kowalski-Michel trace-function correlation theorem, or Kowalski Frobenius large sieve has these hypotheses or this conclusion. Those methods operate with bounded-complexity objects over one finite field, or average conjugacy classes in a fixed geometric family. The present problem is defining-characteristic, marked, mixed-prime, and localized to an interval of length \(X^2\) inside a CRT period of size \(X^8\).

## 8. A conditional proof of HM\(_8\)

The proof would be immediate from either of the following genuinely new inputs.

### Input A: aggregate short-interval CRT discrepancy

Assume

\[
\left(
\sum_{\mathbf p\in\mathcal P_X^{\underline8}}
\left[
I(\mathbf p)-M\prod_i\frac{z_{p_i}}{p_i}
\right]
\right)_+
\ll M X^{o(1)}\lambda_X^8.
\tag{8.1}
\]

Then, by (3.4)-(3.6),

\[
F_8(X)
\le M\lambda_X^8+O(MX^{o(1)}\lambda_X^8)
\ll X^{2+o(1)}\lambda_X^8.
\]

### Input B: the pair-Palm sixth-extension estimate

Assume PP\(_8\), namely (5.7). Then the sandwich (5.6) gives HM\(_8\) immediately.

These are exact proof sketches, but the assumed statements are the missing theorem. They are not consequences of current CRT, \(|Z_p|\ll p^{2/3}\), Lucas, or Kummer-Mellin estimates.

A stronger but more recognizable sufficient statement would be a Poisson-tail bound

\[
\#\{m<M:K_X(m)\ge t\}
\ll M X^{o(1)}\left(\frac{C\lambda_X}{t}\right)^t
\qquad(t\ge8),
\]

which would imply all fixed factorial moments. This is far stronger than anything presently proved.

## 9. Direct answers

### (a) Full expansion and dominant partition types

For HM\(_8\), there is only the all-distinct type \(1^8\), as in (2.1). Repeated-prime partitions occur only in the raw moment \(K^8\), whose full expansion is (2.3) and whose 22 integer-partition coefficients are listed above. In the empirical sparse regime, raw-moment diagonal terms dominate, but they are intentionally absent from the factorial moment.

### (b) Main term and error

The main term is

\[
M\,8!e_8((z_p/p)_p)\le M\lambda_X^8.
\]

The error is the aggregate discrepancy of whether the unique CRT representatives of zero-residue tuples fall below \(M=X^2\). Its exact Fourier form is (3.12). Known one-prime Fourier/Deligne estimates do not control the required mixed-prime short-interval sum.

### (c) Diagonal bounds

There are no diagonal terms in HM\(_8\). In a raw moment, a repeated prime contributes one factor \(z_p/p\), not \(z_p^r/p\). The bound \(z_p\ll p^{2/3}\) controls \(\lambda_X\), the active-prime count, and the current envelope (4.4)-(4.5), but it does not supply the missing CRT landing probability.

### (d) Is this finite bookkeeping or a genuine obstruction?

It is a genuine high-order alignment obstruction. The anchored-star family satisfies all presently proved local and pairwise structural facts but violates HM\(_8\) by \(X^6\). The exact missing statement is PP\(_8\), the sixth conditional factorial extension bound on pair intersections. Current technology does not prove it.

### (e) Can the Kummer-Mellin representation improve CRT?

Not with existing theorems. It gives a bounded-complexity local Frobenius object whose reduction is \(b_j\), but exact vanishing is a defining-characteristic divisibility condition, and HM\(_8\) couples eight different characteristics along one short integer interval. It could become the source of a new mixed-prime large sieve or crystalline local-limit theorem, but it does not presently estimate the required error.

---

## Final conclusion

HM\(_8\) is not blocked by repeated primes. Falling factorials have already removed them. It is blocked by a single precise phenomenon:

\[
\boxed{
\text{Do the CRT lifts of eight Apéry-zero residues land in }[0,X^2)
\text{ with aggregate frequency }X^2/(p_1\cdots p_8)?}
\]

For shell primes, that expected frequency is \(X^{-6}\). HM\(_2\) needs no analogous saving because two-prime products are already on the interval scale. Every current local and pairwise theorem is compatible with total alignment at one row, as the anchored-star construction proves.

Therefore HM\(_8\) is not currently derivable from known technology by completing a finite partition expansion. The next real theorem must be an Apéry-specific mixed-prime orbit-selection, short-interval CRT discrepancy, or pair-Palm sixth-extension estimate. Proving any one of these would yield HM\(_8\), and hence the all-\(n\) Apéry GCD conjecture with

\[
\log G_n\ll n^{11/12+o(1)}.
\]
