# Uniformity of Apéry zeros in arithmetic progressions

## Short answer

The proposed estimate

```
Z_p(a,q)=|Z_p|/q+O(sqrt(p))
```

is not currently a consequence of standard character-sum technology. The obstruction is that the function

```
r -> 1_{b_r=0 mod p}
```

is not presently known to be a trace function of a bounded-conductor l-adic sheaf on the r-line. The Mellin sheaf gives a trace formula for b_r itself, but passing from a trace value to its zero indicator is a nonlinear operation that destroys the sheaf structure.

This is exactly the same defining-characteristic barrier that appears in the full CRT independence problem.

---

## 1. The desired Fourier formulation

Write

```
Z_p(a,q)-|Z_p|/q
```

using additive Fourier expansion in the q-variable. For h != 0 one needs cancellation in

```
S(h)=sum_{r mod p} 1_{b_r=0 mod p} exp(2 pi i h r/q).
```

If this were a trace function with bounded conductor, Deligne's theorem would suggest a square-root bound.

The missing statement is therefore not the final Fourier estimate; it is the geometric realization of the zero indicator.

---

## 2. Why the naive delta-function expansion fails

One can write formally

```
1_{b_r=0}=1/p sum_t exp(2 pi i t b_r).
```

But then the needed sums become

```
sum_r exp(2 pi i t b_r(r)) exp(2 pi i h r/q).
```

Here b_r is not a polynomial function of r over F_p. It is generated by a recurrence of length r. There is no fixed-degree exponential sum to which Weil's bound applies.

The degree grows with r, so this is not a standard Deligne situation.

---

## 3. What the Mellin sheaf actually gives

The Mellin sheaf gives a geometric object whose Frobenius trace satisfies

```
Tr(Frob_r)=b_r mod p
```

(up to the known normalizations).

Therefore Katz theory gives information about distributions of the trace values:

```
{b_r mod p : r in F_p}
```

as values of an SL_2 trace function.

However the indicator

```
Tr(Frob_r)=0
```

is a level-set indicator of that trace. It is analogous to asking for the distribution of zeros of a trace function, not the trace itself.

There is no general theorem saying that zeros of arbitrary SL_2 trace functions have square-root equidistribution in arithmetic progressions.

---

## 4. Could Fourier transform of the Mellin sheaf help?

For additive Fourier transform of a genuine trace function, Laumon theory gives another sheaf and preserves bounded conductor.

But the relevant function would have to be

```
r -> delta_{Tr(Frob_r),0}.
```

This is not the Fourier transform of the Mellin sheaf. It is a nonlinear function of its trace.

One possible route would be to approximate the delta function by character expansions in the representation ring of SL_2(F_p). Then one needs uniform control of high tensor powers

```
M^{\otimes n}
```

and their Fourier transforms.

This becomes a large monodromy problem, not a rank-2 problem.

---

## 5. What can actually be proved from existing tools

There are three weaker statements available in principle:

### (a) Fixed p distribution

Using SL_2 monodromy one expects estimates for polynomial moments of b_r and averages of functions expressible as low-degree class functions on SL_2.

### (b) Average over p

One may hope to use Deligne bounds after averaging over primes and replacing the zero indicator by a smooth approximation.

This would be closer to a Bombieri-Vinogradov theorem, but no theorem currently supplies the required uniformity.

### (c) Gap-polynomial bounds

The known factorization

```
H_p(t)=B_p(t)^2
```

and degree bounds for B_p give information on |Z_p|. They do not control the location of zeros relative to another modulus q.

---

## 6. What theorem would be new

A sufficient new theorem would be:

For primes p,q with p != q and q not too large,

```
sum_{r mod pq} 1_{b_r=0 mod p}1_{r=a mod q}
 = |Z_p|/q + O(p^{1/2+epsilon}).
```

Equivalently, the zero locus of the Apéry Mellin trace would need arithmetic-progression equidistribution.

This is a genuine new "zero-sieve for trace functions" theorem.

---

## Conclusion

The answer is:

* Weil/Deligne bounds do not directly apply.
* The Mellin sheaf controls b_r, but not the nonlinear event b_r=0.
* A bounded-conductor sheaf whose trace is the zero indicator would solve the problem, but constructing such an object is currently the missing step.
* Proving the proposed O(sqrt(p)) estimate would already be a major theorem, essentially a first case of the desired cross-prime independence mechanism.
