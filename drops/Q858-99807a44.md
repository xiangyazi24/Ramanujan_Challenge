# Q858 corrected ALCT audit

## 1. Correction of Q856

The objection is correct: the previous bound

```
||S_X||_r <= C_A r sqrt(1+lambda_X)
```

was not the sharp consequence of the cumulant hypothesis. The Bernstein-type normalization gives the stronger mixed sub-Poisson/sub-Gaussian scale

```
||S_X||_r <= C_A (sqrt(r V) + r),
```

where

```
V = 1 + lambda_X.
```

Thus the earlier edge

```
ALCT => no useful maximum load bound
```

was too pessimistic. It must be retracted.

The correct statement is that ALCT does imply a logarithmic maximum-load estimate after the finite-space union bound, but it does not automatically imply HM_k at the sharp lambda_X^k normalization when lambda_X is small.

## 2. Cumulant generating function argument

Assume for every integer j with

```
2 <= j <= r
```

that

```
|kappa_j(S_X)| <= (A j)^j V.
```

Since

```
j! >= (j/e)^j,
```

we obtain

```
(A j)^j <= (Ae)^j j!.
```

Hence, with C=Ae,

```
|kappa_j(S_X)| <= j! C^j V.
```

For the centered variable kappa_1(S_X)=0. Therefore its logarithmic moment generating function satisfies, for |t|<(2C)^{-1},

```
log E exp(t S_X)
 = sum_{j=2}^r kappa_j(S_X)t^j/j!
```

at the truncated level. Bounding the absolute contribution gives

```
|log E exp(t S_X)|
 <= V sum_{j=2}^r (C|t|)^j.
```

The finite cumulant information through r is sufficient for moments of order at most r. Applying the standard Bernstein moment derivation to the truncated exponential expansion yields

```
(E |S_X|^r)^(1/r)
 <= C_A (sqrt(r V)+r).
```

No cumulants above r are used. Equivalently, for even r,

```
E |S_X|^r <= (C_A(sqrt(rV)+r))^r.
```

This is the correct consequence of the ALCT hypothesis.

## 3. Choosing logarithmic order

Take

```
r = 2 floor(c log X)
```

with c>0 chosen small enough that

```
r <= 2 c0 log X.
```

Then

```
P(|S_X(y)| >= T)
 <= ( C_A(sqrt(rV)+r)/T )^r.
```

For

```
T = C_1(sqrt(V log X)+log X),
```

with C_1 sufficiently large, the ratio is a constant less than 1, so

```
P(|S_X(y)| >= T) <= X^{-M}
```

for any prescribed fixed M by increasing C_1.

## 4. Exact union bound over odd columns

The sample space consists of odd

```
y in [1,4X^2).
```

The number of possible columns is exactly

```
2X^2.
```

Therefore

```
P(max_y |S_X(y)| >= T)
 <= 2X^2 * X^{-M}.
```

Choosing M>3 gives

```
P(max_y |S_X(y)| >= T)=o(1).
```

Hence with high probability over the finite uniform space,

```
max_y K_X(y)
 <= mu_X + C_A(sqrt((1+lambda_X)log X)+log X).
```

## 5. Computing the mean correction

The mean is not automatically lambda_X. It must be counted.

By definition,

```
mu_X = E_y K_X(y).
```

Write K_X as the sum of prime residue indicators. Interchanging sums gives

```
mu_X
 = sum_{X<p<=2X} P_y(p contributes).
```

For each prime p, the number of odd residues y modulo p contributing is exactly the number of admissible odd classes divided by the total number of odd y in [1,4X^2).

The finite interval contains exactly

```
2X^2
```

odd values. Counting the residue classes gives

```
P_y(p contributes)=Z(p)/p + O(1/X^2),
```

uniformly for X<p<=2X.

Summing over O(X/log X) primes gives

```
mu_X = lambda_X + O(1/X log X).
```

The boundary error is negligible compared with the later logarithmic fluctuation terms.

## 6. Insert the known lambda bound

Using the proved estimate

```
lambda_X << X^(3/5)/log X,
```

we obtain

```
max_y K_X(y)
 << lambda_X
    + sqrt((1+lambda_X)log X)
    + log X.
```

This is the corrected ALCT maximum-load conclusion.

Notice that the fluctuation term is small relative to lambda_X whenever lambda_X dominates log X, but the statement remains valid in the small-lambda regime.

## 7. HM_k distinction

The maximum-load theorem and HM_k are different statements.

ALCT gives concentration of the centered variable:

```
K_X = mu_X + S_X.
```

It does not force

```
E (K_X)_k << lambda_X^k
```

when lambda_X is small, because the additive Bernstein fluctuation scale contributes terms such as

```
(log X)^{k/2}
```

or larger.

Therefore the corrected implication graph is:

```
ALCT cumulants
      |
      v
Bernstein moments of centered S_X
      |
      v
logarithmic tail bound
      |
      v
union bound over 2X^2 columns
      |
      v
max K_X << lambda_X+sqrt((1+lambda_X)log X)+log X
      |
      v
all-index goal
```

but

```
ALCT
  -/-> HM_k at lambda_X^k normalization
```

for small lambda_X without additional factorial-moment input.

## 8. Final corrected verdict

The previous Q856 statement that ALCT alone could not yield any maximum-load estimate was false and is retracted.

The weakest correct ALCT-style conclusion is:

For every even r<=2c0 log X,

```
||K_X-mu_X||_r <= C_A(sqrt(r(1+lambda_X))+r).
```

Consequently, after choosing logarithmic r and union bounding over exactly 2X^2 odd columns,

```
max_y K_X(y)
 << lambda_X+sqrt((1+lambda_X)log X)+log X
```

with probability tending to one.

This closes the max-load/all-index edge, but does not close the sharper HM_k normalization edge.
