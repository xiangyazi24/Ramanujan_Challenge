# qFAM: family-averaged Weil errors for the Apery gap family

## Executive verdict

The proposed Fourier reduction is real, but two corrections materially change the attack map.

First, claims (D1)--(D4) are correct on the stated nonwrapping regular windows. Claim (D5), as written, uses the wrong quantity from the sigma ladder. The sigma-ladder variable in the proved paper is

```text
Q_p(D) = sum_r binom(d_D(r),2),
```

which counts triple returns from one base. It is not the plain pair count

```text
sum_(h<=D) C_h = sum_r d_D(r).
```

Nevertheless, [COINC] still gives the advertised new exponent by the direct block inequality, without the sigma ladder:

```text
F_p <= ceil(M/H) * (M + 2 sum_(h<=H) C_h).
```

At `H=p^(2/3)`, [COINC] gives

```text
sum_(h<=H) C_h << H + sqrt(pH) << p^(5/6),
```

and hence

```text
F_p << p^(4/3).
```

So the proposed conclusion survives, but its stated bridge does not.

Second, the generic difference curve

```text
f_h(x)=f_k(y),
f_h(r)=Delta_(r,h),
```

has bidegree about `(3h,3k)` in `P1 x P1`. Its generic arithmetic genus is therefore of order `hk`, not `h+k`. The rigorous per-pair Weil error is consequently of order

```text
hk sqrt(p),
```

up to component and singularity bookkeeping. The triangle sum is of order

```text
H^4 sqrt(p),
```

not `H^3 sqrt(p)`. To reach the [COINC] error scale `pH`, raw pairwise Weil is restricted to about `H<=p^(1/6)`. The additive-genus estimate in (D6) is an unproved special-geometry assertion, not the generic bound.

No currently published Fouvry-Kowalski-Michel, Kowalski-Chavdarov, or large-sieve-for-Frobenius theorem averages this deterministic list at the needed scale. Those theorems require either a fixed trace sheaf of bounded conductor, or a fixed algebraic family over a finite-type parameter space with bounded rank and Betti complexity. Here the standard Fourier sheaf attached to `f_h` has rank/conductor growing at least linearly, and usually quadratically after Fourier transform, while `h` is an iteration length rather than an algebraic parameter.

The exact transfer law does provide a useful new formulation. Put

```text
T(q,A,B) = (q+1, P(q)A-q^6B, A).
```

Then

```text
T^m(s,1,0) = (s+m, U_m(s), U_(m-1)(s)).
```

Thus the discrete family is an orbit of one fixed skew-polynomial map in dimension three. This is the correct finite-dimensional object. But an initial orbit segment of length `H` is not an algebraic subvariety of bounded degree. Eliminating the intermediate states produces degree growing with `H`; retaining them produces a path variety whose complexity grows with `H`. Existing Deligne/large-sieve machinery does not cross this discrete-clock step.

The fourth moment does not repair that defect. It replaces the two-copy coincidence count by an additive-energy variety with four copies of `(r,h)`, hence eight scalar coordinates, and leaves every `h_i` as a discrete iteration length. It is a stronger theorem than [COINC], not a more algebraic one.

The single most promising route is a Bombieri-Davenport variance in the gap-difference shells. Define

```text
E_(h,k)
 = #{(r,r') in I_h x I_k : Delta_(r,h)=Delta_(r',k)}
   - |I_h||I_k|/p,

A_d(H) = sum_(1<=h<=H-d) E_(h,h+d).
```

The exact target is

```text
[FAM-BDH]
For every eps>0, every prime p>=7, and every H<=p^(2/3),

sum_(0<=d<H) |A_d(H)|^2 <<_eps p^(2+eps) H.
```

By Cauchy-Schwarz, [FAM-BDH] implies

```text
N_coinc(H) - (#S_H)^2/p <<_eps p^(1+eps) H,
```

which is [COINC] with a `p^eps` loss, and therefore

```text
F_p <<_eps p^(4/3+eps).
```

The transfer composition identity makes fixed `d` the one direction in which a proof could exist. The genuine obstruction is the following construction problem:

```text
[GAP-CLOCK-SHEAF]
Realize the centered shell function h -> E_(h,h+d), jointly in (h,d),
as a bounded-complexity trace object, or as a cohomological transform whose
large-sieve constant has summable dependence on d.
```

If [GAP-CLOCK-SHEAF] is achieved together with the expected component/self-twist classification, the remaining steps are standard: Grothendieck-Lefschetz, Deligne, completion of the moving intervals, and a large-sieve or `TT*` argument. At present the standard construction has rank and conductor growing with `h`, so this is the nonstandard theorem, not a missing routine application.

# 1. Audit of (D1)--(D5)

## 1.1 The determinant identity (D1)

Fix `r` and write

```text
z_h = Delta_(r,h)
    = b_r c_(r+h) - b_(r+h)c_r.
```

As a function of `h`, `z_h` satisfies the Apery recurrence at the shifted index:

```text
(r+h+1)^3 z_(h+1)
 = P(r+h) z_h - (r+h)^3 z_(h-1).                    (1.1)
```

The initial values are

```text
z_0 = 0,

z_1 = b_r c_(r+1)-b_(r+1)c_r
    = -W_(r+1)
    = 1/(r+1)^3.                                    (1.2)
```

Put

```text
D_h(r) = product_(j=1)^h (r+j)^3,
w_h(r) = D_h(r) z_h.
```

Multiplying (1.1) by `D_h(r)` gives

```text
w_(h+1)
 = P(r+h)w_h - (r+h)^6w_(h-1),
w_0=0,
w_1=1.                                             (1.3)
```

These are exactly the initial values and recurrence of `N_h(r)`. Therefore

```text
Delta_(r,h)
 = N_h(r) / product_(j=1)^h (r+j)^3.                (1.4)
```

Thus (D1) is correct, including its sign.

On the window

```text
1<=r<=M-h,
```

all denominator factors lie in `{2,...,p-2}`, so no pole occurs.

## 1.2 Orthogonality and Parseval

Let

```text
S_H = {(r,h):1<=h<=H, 1<=r<=M-h},
N = #S_H = H M - H(H+1)/2.
```

By (1.4), the number of zero determinants in `S_H` is exactly

```text
S(H) := sum_(h<=H) C_h.
```

Additive orthogonality gives

```text
S(H)
 = (1/p) sum_(t in F_p) B_t(H)
 = N/p + (1/p)sum_(t!=0)B_t(H).                     (1.5)
```

This proves (D2).

Expanding the square and summing over `t` gives

```text
sum_(t in F_p)|B_t(H)|^2
 = p N_coinc(H).                                    (1.6)
```

Since `B_0(H)=N`, subtracting the `t=0` term gives

```text
sum_(t!=0)|B_t(H)|^2
 = p N_coinc(H)-N^2.                                (1.7)
```

This proves (D3).

## 1.3 [COINC] implies the stated first-moment estimate

Assume

```text
N_coinc(H) <= N^2/p + K N.                          (1.8)
```

Then (1.7) gives

```text
sum_(t!=0)|B_t(H)|^2 <= K p N.
```

Cauchy-Schwarz in (1.5) gives

```text
S(H)
 <= N/p
    +(1/p)sqrt((p-1)sum_(t!=0)|B_t(H)|^2)
 <= N/p + sqrt(KN).                                 (1.9)
```

Since `N<=pH`,

```text
S(H) << H + sqrt(KpH).                              (1.10)
```

Thus (D4) is correct.

## 1.4 The sigma-ladder mismatch in (D5)

The proved sigma machine uses

```text
d_D(r) = #{1<=h<=D : r+h<=M and pi(r)=pi(r+h)},

Q_p(D) = sum_r binom(d_D(r),2).                     (1.11)
```

This counts two distinct returns from the same base, equivalently projective triples

```text
pi(r)=pi(r+h)=pi(r+k).
```

By contrast,

```text
sum_(h<=D) C_h = sum_r d_D(r)                       (1.12)
```

counts ordinary collision pairs. There is no inequality

```text
Q_p(D) <= sum_(h<=D)C_h
```

in general: when `d_D(r)` is large, `binom(d_D(r),2)` is much larger than `d_D(r)`.

Therefore the invocation of the sigma ladder in (D5) is invalid.

## 1.5 Direct recovery of the `p^(4/3)` theorem from [COINC]

The desired conclusion nevertheless follows directly.

Partition `I_p` into

```text
B = ceil(M/H)
```

consecutive blocks of length at most `H`. Let `m_(v,j)` be the number of occurrences of color `v` in block `j`. For each `v`, Cauchy-Schwarz gives

```text
m_p(v)^2 <= B sum_j m_(v,j)^2.
```

Summing over `v`, every off-diagonal equal-color pair inside a block has positive gap at most `H`, so

```text
F_p
 <= B * (M + 2 sum_(h<=H)C_h).                      (1.13)
```

Under [COINC], (1.10) gives

```text
F_p
 << (p/H) * (p + sqrt(pH) + H)
 << p^2/H + p^(3/2)/sqrt(H) + p.                    (1.14)
```

At

```text
H = floor(p^(2/3)),
```

this becomes

```text
F_p << p^(4/3) + p^(7/6) + p
    << p^(4/3).                                      (1.15)
```

With a `p^eps` loss in [COINC], the conclusion is

```text
F_p <<_eps p^(4/3+eps).
```

So [COINC] at `H=p^(2/3)` is indeed a new theorem target, but the proof is the direct block argument, not the sigma ladder.

# 2. The difference curves: corrected geometry and main terms

Put

```text
f_h(X) = Delta_(X,h)
       = N_h(X)/D_h(X),

D_h(X) = product_(j=1)^h (X+j)^3.                  (2.1)
```

Over the generic characteristic-zero model,

```text
deg N_h = 3(h-1),
deg D_h = 3h.
```

Thus the rational map `f_h:P1->P1` has degree at most `3h`, and generically exactly `3h` after cancellation is excluded.

For fixed `h,k`, the full difference curve is

```text
X_(h,k):
N_h(X)D_k(Y)-N_k(Y)D_h(X)=0.                        (2.2)
```

Its bidegree in `P1 x P1` is at most

```text
(3h,3k).                                            (2.3)
```

A smooth irreducible divisor of bidegree `(a,b)` in `P1 x P1` has arithmetic genus

```text
(a-1)(b-1).
```

Therefore the generic genus scale here is

```text
g_(h,k) = O(hk),                                    (2.4)
```

not `O(h+k)`.

After geometric component and singularity bookkeeping, the direct Weil estimate has the shape

```text
#X_(h,k)(F_p)
 = rho_(h,k) p + O(hk sqrt(p)+hk),                  (2.5)
```

where `rho_(h,k)` is the number of Frobenius-stable geometric components contributing dimension-one main terms. Formula (2.5) is schematic but has the correct generic complexity scale.

Summing the rigorous errors by absolute values gives

```text
sum_(h,k<=H) hk sqrt(p)
 << H^4 sqrt(p).                                    (2.6)
```

To obtain the [COINC] error `O(pH)` by this route would require

```text
H^4 sqrt(p) <= pH,
```

hence only

```text
H <= p^(1/6).                                       (2.7)
```

This is farther from `p^(2/3)` than the estimate in (D6).

There is a possible statistical nuance. If the `O(hk)` Frobenius eigenvalues within one curve already exhibit random-matrix cancellation, the typical error could be much smaller than the Weil maximum. But that is itself a family equidistribution theorem. It cannot be inserted as a per-pair input.

## 2.1 The component main term is part of the theorem

For `h=k`, the fiber product

```text
f_h(X)=f_h(Y)
```

always contains the diagonal `X=Y`. If the geometric monodromy of `f_h` is two-transitive, the remaining off-diagonal ordered-pair locus is geometrically irreducible. Thus the generic self-pair has two main components, not one.

For `h!=k`, geometric irreducibility of the fiber product is equivalent to the two covers having no nontrivial common quotient, after the usual separability hypotheses. Full symmetric monodromy of each primitive factor does not alone prove this pairwise independence: common sign fields, common quadratic quotients, reflection quotients, and low-gap exceptional fields must be classified.

The component target needed by [COINC] is roughly

```text
sum_(h,k<=H) (rho_(h,k)-1) << H.                    (2.8)
```

The diagonal contributes `H`, exactly the permitted `O(pH)` correction. Any positive-density family of off-diagonal common quotients would violate [COINC] at the main-term level, before Weil errors are considered.

Call the required statement

```text
[GAP-COMP]
After removing the proved mirror/diagonal components and finitely described
low-gap fields, the covers f_h and f_k have no common geometric quotient for
all but O(H) pairs h,k<=H.
```

This is a monodromy/Goursat prerequisite. It is separate from family cancellation of the remaining Frobenius errors.

## 2.2 Window restriction

The actual count uses

```text
I_h = {1,...,M-h},
```

not all of `F_p`. One cannot simply replace `I_h` by the complete field and charge `O(h)` without controlling how the added points collide with all other slices.

The standard exact remedy is additive completion:

```text
1_(I_h)(r)
 = (1/p) sum_(a in F_p) I_hat_h(a)e_p(ar),

sum_a |I_hat_h(a)| << p log p.                      (2.9)
```

Thus a complete-sum theorem in `(r,h)` transfers to the moving intervals with logarithmic losses and an extra additive-twist parameter. The boundary is not the conceptual obstruction, but it must be retained in a rigorous proof.

# 3. Fouvry-Kowalski-Michel trace-function methods

For a complete-field model, define the value multiplicity

```text
mu_h(x) = #{r in F_p away from poles : f_h(r)=x}
```

and its normalized Fourier transform

```text
K_h(t)
 = p^(-1/2) sum_r e_p(t f_h(r)).                    (3.1)
```

The sheaf-theoretic construction is standard for each fixed `h`:

1. push the constant sheaf forward by `f_h`;
2. take the normalized l-adic Fourier transform.

The resulting trace function is `K_h(t)`, up to the standard extension values at singular points.

## 3.1 What FKM actually gives

Fouvry-Kowalski-Michel, Proposition 1.1 in "A study in sums of products", gives square-root cancellation for a fixed tensor product of middle-extension sheaves when its top compactly supported cohomology vanishes. The implied constant depends on the number of factors and on their conductors. Their Goursat-Kolchin-Ribet criteria classify when a constant summand causes a diagonal main term.

This is exactly the right theorem for one fixed pair `(h,k)` after [GAP-COMP]. It is not a theorem in the family label `h`.

The complexity is not bounded here. The generic pushforward by `f_h` has rank about

```text
deg f_h = 3h.
```

Therefore its conductor is at least linear in `h`. The standard Fourier-transform conductor estimate is quadratic in the input conductor:

```text
cond(FT(F)) << cond(F)^2.                            (3.2)
```

This estimate is stated, for example, as Lemma 2.3 in Perret-Gentil's large-sieve paper, citing the conductor theorem of Fouvry-Kowalski-Michel. Thus the standard construction gives at best a conductor polynomial in `h`, and naturally of order up to `h^2`.

Even if one optimistically replaced all conductor constants by an absolute constant, pairwise FKM plus the triangle inequality would give

```text
sum_(h,k<=H) |E_(h,k)| << H^2 sqrt(p),               (3.3)
```

which reaches `O(pH)` only for `H<=sqrt(p)`. It still misses `H=p^(2/3)`. Actual growing conductors make the range worse.

Therefore FKM supplies:

```text
fixed pair + nonisomorphism + known conductor
    => one square-root estimate,
```

but not

```text
H^2 changing sheaves
    => cancellation among their Frobenius traces.
```

That second implication is the requested new theorem.

## 3.2 Why the algebraic trace-function large sieve does not directly apply

The large-sieve inequalities of Xi, Fouvry, Kowalski, and Michel iterate Fourier transforms and multiplicative convolutions of one fixed non-Kummer trace function. The family members are generated from a fixed bounded-complexity sheaf by specified algebraic operations.

Our `K_h` are not presently known to be translates, dilates, PGL2 transforms, tensor powers of bounded order, or boundedly many cohomological transforms of one fixed sheaf. Their generic ranks grow with `h`.

A useful exact theorem would be the operator inequality

```text
[AFLS]
For H<=p^(2/3) and arbitrary complex coefficients a_h,

sum_(t!=0) |sum_(h<=H) a_h K_h(t)|^2
 <<_eps p^(1+eps) sum_(h<=H)|a_h|^2.                (3.4)
```

Taking `a_h=1` gives [COINC]. But (3.4) is precisely a new large sieve in the iteration-length aspect; it is not a corollary of the existing fixed-trace-function large sieve.

# 4. Kowalski's large sieve for Frobenius and Chavdarov families

Kowalski's large sieve for Frobenius averages Frobenius conjugacy classes over points of a fixed algebraic parameter variety. Chavdarov's theorem and its refinements concern a fixed family of curves with fixed genus and large monodromy. Perret-Gentil's coherent-family formulation likewise takes a compatible system with finite conductor

```text
sup_lambda cond(F_lambda) < infinity.
```

These hypotheses fail in two ways.

First, the parameter `h` is not a point of a fixed algebraic family. It is the number of transfer steps.

Second, even if one regards each `X_(h,k)` as a fiber in a list, the genus, rank, conductor, and total Betti number grow with `h,k`. Large-sieve constants depend on those data. Perret-Gentil's displayed hyperelliptic-family example has an exponent whose denominator is quadratic in the fixed genus; allowing the genus to grow with `p` collapses the saving.

There is a genuine fixed-field, growing-genus literature for large natural ensembles, for example averages over all hyperelliptic curves of genus `g` over a fixed finite field. Results such as Roditty-Gershon's trace-moment theorem exploit averaging over an exponentially large coefficient family of defining polynomials. The Apery list has only one highly structured curve per pair `(h,k)` and no coefficient-space average. Those theorems do not transfer.

Thus Kowalski-Chavdarov machinery would become relevant only after constructing a fixed finite-type master family whose fibers encode the transfer length. That is exactly the missing algebraization.

# 5. The exact transfer composition and the Hooley/Birch swap

The transfer law does give a strong identity. From

```text
G_(m+d)(s)=G_d(s+m)G_m(s)
```

one obtains

```text
U_(m+d)(s)
 = U_d(s+m)U_m(s)
   -(s+m)^6 U_(d-1)(s+m+1)U_(m-1)(s).               (5.1)
```

For `d=1`, this is exactly the defining recurrence.

Equation (5.1) is the reason fixed gap difference `d` is the correct shell variable: the relative transfer from length `m` to length `m+d` has only length `d`.

There is also a completely fixed-dimensional autonomous encoding. Define

```text
T(q,A,B)=(q+1, P(q)A-q^6B, A).                      (5.2)
```

Then

```text
T^m(s,1,0)=(s+m,U_m(s),U_(m-1)(s)).                 (5.3)
```

This is the cleanest answer to the question whether the recurrence can be viewed dynamically in finite dimension: yes.

It does not yet permit a Birch swap. The set

```text
{T^m(s,1,0):1<=m<=H}
```

is an initial orbit segment, not the `F_p`-points of a bounded-degree subvariety.

There are two exact ways to algebraize it, and both lose uniformity:

1. Eliminate the intermediate states. The resulting endpoint equation is `U_m(s)`, of degree `3m`.
2. Keep every intermediate state. The path variety has `O(m)` state variables and equations, so its dimension/Betti complexity grows with `m`.

The clock coordinate `q->q+1` is deterministic and has no expansion. Passing from the nonautonomous recurrence to the skew product therefore does not create mixing by itself.

In the language of difference equations, the matrices define a rank-two difference connection. The parallel transport from `s` to `s+m` is the product `G_m(s)`. A bounded-conductor l-adic sheaf on the ordinary algebraic `(s,m)`-plane would require this parallel transport to be algebraic in the endpoint `m` with bounded complexity. No such comparison theorem is known, and the increasing generic rank of the Fourier sheaves is evidence against a naive construction.

Consequently, the Hooley/Birch swap is viable only if one proves a new "difference-sheaf" or "clock-sheaf" theorem. The transfer identity reduces its shape, but does not prove it.

# 6. Bombieri-Davenport dispersion in the fixed-difference aspect

Define the exact centered pair correlation on the actual windows:

```text
E_(h,k)
 = #{(r,r') in I_h x I_k : f_h(r)=f_k(r')}
   - |I_h||I_k|/p.                                  (6.1)
```

Then

```text
N_coinc(H)-N^2/p
 = sum_(h,k<=H) E_(h,k).                            (6.2)
```

Group by the difference `d=k-h`:

```text
A_d(H)=sum_(h=1)^(H-d) E_(h,h+d),
0<=d<H.                                             (6.3)
```

Symmetry gives

```text
N_coinc(H)-N^2/p
 = A_0(H)+2 sum_(d=1)^(H-1) A_d(H).                 (6.4)
```

This is the precise Bombieri-Davenport organization.

## 6.1 The minimal variance lemma

State the family theorem as follows.

```text
[FAM-BDH]
For every eps>0 there is C_eps such that, for every prime p>=7 and
1<=H<=p^(2/3),

sum_(d=0)^(H-1) |A_d(H)|^2
 <= C_eps p^(2+eps) H.                              (6.5)
```

Cauchy-Schwarz and (6.4) give

```text
|N_coinc(H)-N^2/p|
 << sqrt(H) * (p^(2+eps)H)^(1/2)
 << p^(1+eps)H.                                     (6.6)
```

Thus [FAM-BDH] implies the epsilon-loss version of [COINC]. Sections 1.3 and 1.5 then give

```text
sum_(h<=p^(2/3)) C_h <<_eps p^(5/6+eps),
F_p <<_eps p^(4/3+eps).                             (6.7)
```

This is the exact lemma I would target.

## 6.2 Why fixed difference is better than raw pairs

The raw family has two unrelated long lengths `(h,k)`. In the shell `k=h+d`, equation (5.1) expresses the second endpoint through the first endpoint and a transfer of fixed length `d`.

A successful proof would proceed as follows.

1. Use additive completion to replace the moving windows by complete sums with two bounded `L1` Fourier weights.
2. Represent each complete pair correlation as a Frobenius trace of the tensor product of the Fourier sheaves attached to `f_h` and `f_(h+d)`.
3. Use (5.1) to rewrite the relative tensor object in terms of the length-`d` transfer and the current two-coordinate state `(U_h,U_(h-1))`.
4. Classify constant summands and common quotients. This is [GAP-COMP].
5. Prove that the centered shell traces, jointly in `(h,d)`, form a large-sieve family with the square mean (6.5).
6. Apply Deligne and the standard `TT*`/large-sieve argument. No new analytic step remains after Step 5.

The hard step is Step 5, not Deligne.

## 6.3 The exact missing geometric construction

A sufficiently strong construction would be:

```text
[GAP-CLOCK-SHEAF]
There is a fixed-dimensional cohomological transform K over the clock variables
(h,d), with all nontrivial fibers pure of weight zero, such that its trace is
the centered shell error E_(h,h+d), and such that the total conductor/Betti
complexity entering the large sieve is summable in d up to p^(2/3).
```

"Summable" is essential. A separate Deligne estimate with a constant growing linearly in `d`, followed by absolute summation over `d`, is still too large at `p^(2/3)`. The theorem must retain cancellation in the `d` family, not merely algebraize each fixed `d` separately.

The genuine obstruction is now precise:

```text
The addition law keeps the old state (U_h,U_(h-1)).
It does not express that state as a bounded-degree algebraic function of h.
```

Thus standard finite-type l-adic geometry sees either increasing rank or an increasing path space. If no alternative compression exists, [GAP-CLOCK-SHEAF] fails and [FAM-BDH] is a genuinely new difference-dynamical large-sieve theorem rather than an application of existing machinery.

# 7. The completed fourth moment

Let

```text
A=S_H,
N=#A,
f(r,h)=Delta_(r,h).
```

For `k>=1`, define

```text
T_k(H)
 = #{a_1,...,a_k,b_1,...,b_k in A :
     sum_i f(a_i)=sum_i f(b_i)}.                    (7.1)
```

Expanding and using orthogonality gives the exact identity

```text
sum_(t in F_p)|B_t(H)|^(2k)=p T_k(H),               (7.2)
```

and therefore

```text
sum_(t!=0)|B_t(H)|^(2k)=p T_k(H)-N^(2k).            (7.3)
```

For `k=1`, this is (D3).

For `k=2`, `T_2` counts

```text
f(r_1,h_1)+f(r_2,h_2)
 =f(r_3,h_3)+f(r_4,h_4).                            (7.4)
```

There are four independent pairs `(r_i,h_i)`, hence eight scalar coordinates before the one equation. It is not a six-variable variety after the `h_i` are included.

## 7.1 The fourth-moment theorem needed

Holder gives

```text
sum_(t!=0)|B_t|^2
 <= sqrt(p * sum_(t!=0)|B_t|^4).                    (7.5)
```

To recover [COINC], it would suffice to prove the random-scale bound

```text
sum_(t!=0)|B_t|^4 << p N^2.                         (7.6)
```

By (7.3), this is equivalent to

```text
T_2(H) <= N^4/p + O(N^2).                           (7.7)
```

Thus the fourth-moment route asks for near-minimal additive energy of the multiset of determinant values. This is stronger than the second-moment coincidence theorem, not weaker.

## 7.2 Why the extra moment does not make `h` algebraic

For one fixed `h`, define

```text
S_h(t)=sum_(r in I_h)e_p(t f_h(r)).
```

Then

```text
sum_h sum_t |S_h(t)|^4
 =p sum_h #{r_1,r_2,r_3,r_4 in I_h :
            f_h(r_1)+f_h(r_2)=f_h(r_3)+f_h(r_4)}.    (7.8)
```

If `h` were an algebraic coordinate of a fixed family, (7.8) would involve a five-coordinate family `(h,r_1,r_2,r_3,r_4)`. But `U_h` is not a bounded-degree polynomial in `h`. Encoding it by the recurrence still needs a path of length `h`.

For the full fourth moment of `B_t`, the four lengths `h_1,...,h_4` are independent, so the discrete-clock problem is multiplied fourfold.

Higher moments add diagonal partition strata, common-quotient strata, and increasing tensor ranks. They are useful after a family local-limit theorem is available, for example to prove tails or a central limit theorem. They do not manufacture the missing algebraic parameter.

Verdict on Question 2:

```text
The fourth moment is a valid stronger target [COINC4], but it does not turn the
family into a fixed variety. It moves the problem from value collisions to
additive energy and makes the component/diagonal classification harder.
```

# 8. What an actual fixed master variety would give

It is useful to state the hypothetical positive scenario precisely.

Suppose one could construct, uniformly in `p`, a fixed-complexity pure sheaf on a fixed-dimensional space with coordinates including

```text
h,k,t
```

whose trace equals the normalized completed sums and whose relative tensor square has only the explicitly classified diagonal constant summands.

After completing the two `h,k` intervals, the off-diagonal total would become a bounded linear combination of complete sums on a fixed three-dimensional variety. Deligne would then give an error of order

```text
p^(3/2) * polylog(p),                               (8.1)
```

with a fixed Betti constant. At `H=p^(2/3)`, this is smaller than the allowed

```text
pH=p^(5/3).                                         (8.2)
```

So a genuine bounded-complexity master object would solve the problem.

The reason this is not already a proof is structural. The standard Fourier sheaf for the `h`th slice has generic rank growing with `h`. Restriction of one fixed-rank sheaf to the fibers of an algebraic `h`-line cannot reproduce this standard family. A different, unexpectedly compressed representation would be required.

This observation gives a clean go/no-go criterion:

```text
If the K_h admit a bounded-rank master realization, qFAM reduces to standard
Deligne plus monodromy.

If every realization has rank or conductor growing at least like h, the simple
master-variety route is dead and one needs a genuinely dynamical large sieve.
```

# 9. Final answer to the three questions

## 9.1 Existing machinery

Fouvry-Kowalski-Michel handles any fixed tuple once conductor and geometric independence are controlled. It does not average a list whose rank and conductor grow with the list index. The FKM conductor dependence is load-bearing here.

The algebraic trace-function large sieve handles transforms and convolutions of a fixed bounded-complexity trace function. No identification of the Apery `K_h` with such an orbit is known.

Kowalski's large sieve for Frobenius and Chavdarov's theorem average over points of a fixed algebraic parameter family with fixed monodromy data. They do not apply to iteration length. Growing-genus fixed-field theorems use very large natural coefficient ensembles, absent here.

The exact transfer law does turn the nonautonomous recurrence into the autonomous skew map (5.2), and gives the addition formula (5.1). This is a genuine structural gain. It reduces the family problem to distribution of a line under a zero-entropy skew product. It does not make the orbit-time variable algebraic.

## 9.2 Higher moments

The exact `2k`th moment counts equal sums of `k` determinant values. The fourth moment is the additive energy of an eight-coordinate discrete family. It implies [COINC] at random scale, but is stronger and has more diagonal strata. No fixed-dimensional Deligne theorem appears merely by taking one more moment.

## 9.3 Single best route

The best route is [FAM-BDH], the shell variance in `d=k-h`.

Its advantages are:

1. it is exactly strong enough for `F_p<<p^(4/3+eps)`;
2. it retains signed cancellation instead of summing Weil bounds absolutely;
3. the transfer addition law isolates the short relative length `d`;
4. it has the correct Bombieri-Davenport/large-sieve form;
5. it is directly falsifiable numerically shell by shell.

The proof skeleton is complete through the reduction to [GAP-CLOCK-SHEAF]. After that construction, only standard component classification, Grothendieck-Lefschetz, Deligne, completion, and `TT*` remain.

The genuine obstruction, if the route dies, is:

```text
There is no bounded-complexity algebraic or l-adic object in the iteration
length h. The parallel transport G_h(s) is a difference-equation fundamental
solution whose rank/conductor grows with h.
```

That is the exact family-compatibility wall in this coordinate system.

# 10. Single next action

Compute the shell variance itself, not only `N_coinc`.

For each test prime and each `H` in the ranges `p^(1/3)`, `p^(1/2)`, and the largest feasible scale toward `p^(2/3)`:

```text
1. Compute E_(h,k) with the exact moving-window baseline |I_h||I_k|/p.
2. Form A_d(H)=sum_h E_(h,h+d).
3. Record

   V_p(H)=sum_d |A_d(H)|^2/(p^2 H),
   max_d |A_d(H)|/p,
   and the signed total (A_0+2sum_(d>0)A_d)/(pH).

4. Separate d=0, the proved mirror component, h=2/-51 effects, and every
   detected common-factor/common-quotient pair.
5. Repeat with complete-r sums and with the actual windows to isolate the
   boundary-completion cost.
```

If `V_p(H)` stays bounded while individual curve errors grow, [FAM-BDH] is the correct theorem and the effort should move to the clock-sheaf construction. If a small set of `d` carries the variance, those shells should be attacked algebraically by the addition formula. If `V_p(H)` grows as a power of `H` after all explicit components are removed, the proposed family-averaged Weil route does not reach `p^(4/3)`.
