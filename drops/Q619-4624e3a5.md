# Wan slope conjecture and the missing character-direction bound

## Summary

The Wan slope viewpoint is the closest existing framework, but the proposed implication is still one step too strong.

The key point is:

```
variation of Newton slopes in an algebraic family
        !=
variation of slopes on the finite character group r in Z/(p-1)Z
```

A successful AFP proof would require converting the character torus of Kummer twists into an algebraic parameter space where a nonordinary locus has bounded complexity. This is plausible, but not an automatic consequence of Wan's conjecture.

The missing theorem is a character-space analogue of Deuring's supersingular bound.

## (A) Apéry and Wan's slope theory

The identification

```
b_r = 0 mod p  <=>  C_r is nonordinary
```

is the correct crystalline interpretation.

For an ordinary rank-two F-crystal, the Hodge polygon has slopes approximately

```
0, 1
```

and the first Newton slope jumps from 0 exactly on the nonordinary locus.

Wan's philosophy predicts that nonordinary points are controlled by the gap between Hodge slopes. In a genuine algebraic family of dimension one, codimension-one nonordinary loci are finite and have bounded geometric complexity.

However, the parameter set

```
r in Z/(p-1)Z
```

is not itself a fixed algebraic variety. It is the set of Teichmuller points in the character group, and its size changes with p.

Therefore Wan's theorem cannot be applied directly.

## (B) Universal Kummer character torus

The right construction is indeed the universal Kummer family:

```
T = G_m = Spec(Z_p[t,t^{-1}])
```

with the twist parameter t.

The points

```
t = omega^r
```

recover the finite order characters.

If one could prove that the nonordinary locus

```
N = {t in T : first Frobenius slope > 0}
```

is a closed subscheme of bounded degree independent of p, then:

```
|N(F_p) intersect mu_{p-1}| = O(1)
```

would follow.

This is exactly the desired AFP mechanism.

The obstruction is that the Frobenius matrix of the twisted crystal is not generally a polynomial function of t of bounded degree. It is a p-adic analytic object whose complexity may grow with p because the Kummer characters have conductor p-1.

Thus bounded degree of the character nonordinary locus is the missing statement.

## (C) Kedlaya slope algorithms

Kedlaya's theory gives effective computation of Newton polygons for individual p-adic differential equations and certain families.

But an algorithm computing all Kummer twists simultaneously does not automatically imply AFP.

An algorithmic bound would need a uniform statement:

```
number of parameters where the first slope changes
<= constant depending only on rank and singularities
```

Complexity of computation is not the same as geometric degree of the exceptional locus.

A finite computation for each p does not rule out a number of exceptional characters growing with p.

## (D) Rank-two, four-singularity question

There is no known universal bound of the form

```
#{nonordinary Kummer twists} <= f(rank, number of singularities)
```

for arbitrary overconvergent F-crystals.

Rank and singularity count alone are insufficient.

Counterexamples can be produced by introducing arithmetic structure into the Frobenius function while keeping rank and singularity data fixed.

What is needed is additional rigidity:

```
rank 2
+ four singularities
+ Apéry hypergeometric monodromy
+ irreducibility
+ no exceptional character symmetry
```

Under these extra assumptions, a bounded exceptional-character theorem becomes plausible.

The expected bound would depend on conductor, local monodromy, and geometric monodromy group, not only on (2,4).

## (E) Deuring analogy

The elliptic curve analogy is instructive because it shows both the possibility and the obstruction.

For quadratic twists:

```
a_p(E twisted by chi) = chi(d) a_p(E)
```

so ordinarity is unchanged. The character direction contains no new information:

```
number of nonordinary twists = 0 or p-1
```

The Apéry case differs precisely because Kummer twisting changes the hypergeometric Frobenius operator itself.

Therefore the character parameter genuinely moves through the moduli of F-crystals.

The analogue of Deuring would be:

```
The nonordinary characters of a rigid hypergeometric F-crystal form a set
of bounded complexity independent of p.
```

No general theorem currently provides this.

## Correct target theorem for AFP

The desired statement should not be phrased as Wan slope variation alone. It should be a character-space Newton polygon theorem:

```
Let C be the Apéry hypergeometric F-crystal.
For every p, let mu_{p-1} be the Teichmuller character points.
Then the first-slope-zero locus of C tensor L_t
has uniformly bounded intersection with mu_{p-1}.
```

Possible routes:

1. Katz hypergeometric rigidity: prove the exceptional characters correspond to zeros of a bounded-complexity invariant.

2. Dwork unit-root deformation: show the unit-root function on character space is a rigid analytic function with bounded Weierstrass degree.

3. Wan-style slope theory on a rigid character variety, with a uniform conductor bound.

## Final assessment

Wan's conjecture identifies the correct geometric phenomenon, but the missing bridge is:

```
F-crystal overconvergence
        +
character torus geometry
        +
monodromy rigidity
        =>
bounded nonordinary characters
```

For arbitrary rank-two four-singularity crystals this is false. For the Apéry crystal it is a realistic conjecture because Sp_4-type hypergeometric rigidity supplies the extra structure.

AFP is therefore not a pure slope theorem; it is a slope theorem plus character anti-concentration.
