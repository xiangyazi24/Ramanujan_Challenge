# Strategic audit: physical top-block second factorial moment

## Verdict

The weaker target

\[
F_{\rm top}(N)=o\!\left(\frac{N^2}{\log^2 N}\right)
\]

is **not** presently proved unconditionally, but it admits a sharper exact reduction than diagonal AMTD and there are three unconditional little-oh prunings that remove growing sectors while retaining the actual Apéry zero sets.

The useful exact structure is obtained by folding each actual zero set by the Apéry reflection.  For

\[
\widehat Z_p:=Z_p\cap\left[0,\frac{p-1}{2}\right],
\qquad
\widehat Z_p^\circ:=Z_p\cap\left[0,\frac{p-3}{2}\right],
\]

define the two physical hit maps

\[
L_p(u)=p+u,
\qquad
R_p(u)=2p-1-u.
\]

The center, if it is a zero, is assigned only to the left branch.  Then the physical hit set is the disjoint union of the valid left and right hits.  For primes `N<p<q<=2N`, put `d=q-p`.  Every collision is of exactly one of the following three kinds:

\[
\boxed{
\begin{array}{lll}
LL:&u-v=d,&q+v\le2N,\\[2mm]
RL:&u+v=p-d-1,&q+v\le2N,\\[2mm]
RR:&v-u=2d,&2q-1-v\le2N,
\end{array}}
\tag{1}
\]

with `u` an actual folded zero of `p` and `v` an actual folded zero of `q`; for an `R` branch the representative is required to lie in `\widehat Z^\circ`.  The fourth formal branch `L_p=R_q` is impossible when `p<q`.

Consequently

\[
\boxed{
F_{\rm top}(N)
=2\sum_{N<p<q\le2N}
\bigl(C_{LL}(p,q)+C_{RL}(p,q)+C_{RR}(p,q)\bigr).
}
\tag{2}
\]

This is not just a relabeling of pair intersections: reflection has removed one branch completely and converts the remaining pair event into three explicit linear Diophantine relations among the prime gap and the two **actual folded Apéry zeros**.

There is then an unconditional pruning theorem.  Let `D,S,H>=1`.  Write `F_gap`, `F_fold`, and `F_edge` for the ordered collision contributions with respectively

- `q-p<=D`;
- at least one folded zero representative at most `S`;
- `2N-q<=H` for the larger prime `q`.

Using only the proved repository bound `Z(p)=O(p^(2/3))`, its proved subinterval version, Lucas, and elementary Apéry height, one gets

\[
\boxed{
F_{\rm gap}
\ll \frac{N^{5/3}D}{\log N},
\qquad
F_{\rm fold}
\ll \frac{NS^2}{\log^2 N},
\qquad
F_{\rm edge}
\ll \frac{NH^{5/3}}{\log N}.
}
\tag{3}
\]

Thus the concrete choice

\[
D=\frac{N^{1/3}}{\log^2N},
\qquad
S=\frac{N^{1/2}}{\log^2N},
\qquad
H=\frac{N^{3/5}}{\log^2N}
\tag{4}
\]

gives

\[
F_{\rm gap}=O(N^2/\log^3N),
\quad
F_{\rm fold}=O(N^2/\log^6N),
\quad
F_{\rm edge}=O(N^2/\log^{13/3}N),
\tag{5}
\]

all of which are `o(N^2/log^2 N)`.

Hence the physical target is equivalent to the following sharply quantified residual statement:

\[
\boxed{
R_N:=R_{LL}(N)+R_{RL}(N)+R_{RR}(N)
=o\!\left(\frac{N^2}{\log^2N}\right),
}
\tag{6}
\]

where only collisions satisfying

\[
q\le2N-H,
\qquad
q-p>D,
\qquad
u_p>S,
\qquad
u_q>S
\tag{7}
\]

remain (`\nu_p,\nu_q` denote the folded representatives involved in the collision), together with the branch equations `(1)`.

The branch equations add the exact geometric restrictions

\[
LL:\quad q\le\frac{3p-1}{2},
\tag{8a}
\]

\[
RR:\quad q\le\frac{4p-1}{3},
\tag{8b}
\]

and, on the residual sector,

\[
RL:\quad q\le2p-1-2S.
\tag{8c}
\]

Parity gives only

\[
d\equiv0\pmod2,
\qquad
\nu_p\equiv\nu_q\pmod2,
\tag{9}
\]

in all three surviving branches.  This is a constant-factor lattice restriction, not a little-oh mechanism.

I do **not** find an unconditional proof of `(6)`.  The sharp obstruction is that the audited one-characteristic mechanisms do not couple the moving choices of folded zero across distinct primes.  In fact a residual-scale star model survives all of the following black-box constraints simultaneously: reflection, parity, the physical triangle, no consecutive zeros, `|Z_p|=O(p^(2/3))`, the subinterval zero-count shape, and the elementary height budget.  It produces `Theta(N^2/log^2 N)` collisions entirely inside the `LL` residual sector.  This does not assert that the actual Apéry sequence realizes the model; it proves that those mechanisms, used only through the audited consequences, cannot by themselves imply the desired little-oh.

The smallest remaining theorem is therefore `(6)`, equivalently its three-branch form below.  It is strictly weaker than diagonal AMTD: it asks only for a vanishing proportion at the natural prime-pair scale after three unconditional sectors have already been discarded.

# 2. Exact physical reindexing

For

\[
N<m\le2N,
\qquad
N<p\le m,
\]

put

\[
X_p(m)=1_{\{m-p\in Z_p\}},
\qquad
\lambda(m)=\sum_pX_p(m).
\]

Since `p>N` and `m<=2N<2p`, write `m=p+r` with `0<=r<p`.  Lucas gives, for `p>=7`,

\[
b_m=b_{p+r}\equiv5b_r\pmod p.
\]

Therefore

\[
\boxed{X_p(m)=1_{\{p\mid b_m\}}.}
\tag{10}
\]

In particular

\[
F_{\rm top}(N)
=\sum_{N<m\le2N}\lambda(m)(\lambda(m)-1)
=2\sum_{N<p<q\le2N}|\Omega_p\cap\Omega_q|,
\tag{11}
\]

where

\[
\Omega_p=\{m\in(N,2N]:X_p(m)=1\}.
\]

For `p<q`, put

\[
d=q-p,
\qquad
m=q+s=p+(s+d).
\]

Then

\[
0\le s\le2N-q
\]

and the collision conditions are exactly

\[
q\mid b_s,
\qquad
p\mid b_{s+d}.
\tag{12}
\]

Thus

\[
\frac{F_{\rm top}(N)}2
=
\sum_{d\ge1}
\sum_{\substack{N<p<p+d\le2N\\p,p+d\ {m prime}}}
\sum_{0\le s\le2N-p-d}
1_{\{s\in Z_{p+d}\}}
1_{\{s+d\in Z_p\}}.
\tag{13}
\]

Formula `(13)` is the useful gap reindexing from the question.  The next section is the non-tautological step.

# 3. Folded left/right decomposition

For odd `p`, reflection gives

\[
r\in Z_p\iff p-1-r\in Z_p.
\tag{14}
\]

Define

\[
\widehat Z_p
:=Z_p\cap\left\{0,\ldots,\frac{p-1}{2}\right\},
\]

\[
\widehat Z_p^\circ
:=Z_p\cap\left\{0,\ldots,\frac{p-3}{2}\right\}.
\]

For `u in \widehat Z_p`, the left hit is

\[
L_p(u)=p+u.
\]

For `u in \widehat Z_p^\circ`, the reflected right hit is

\[
R_p(u)=2p-1-u.
\]

Only hits at most `2N` are retained.  The center `u=(p-1)/2`, if present, is assigned only to `L`, so the union is disjoint:

\[
\boxed{
\Omega_p
=
\{L_p(u):u\in\widehat Z_p,\ L_p(u)\le2N\}
\ \dot\cup\
\{R_p(u):u\in\widehat Z_p^\circ,\ R_p(u)\le2N\}.
}
\tag{15}
\]

Now fix `p<q` and `d=q-p`.

## 3.1 Left--right is impossible

For every allowed folded representative,

\[
L_p(u)\le\frac{3p-1}{2}
<\frac{3q-1}{2}
\le R_q(v).
\]

Hence

\[
\boxed{L_p(u)\ne R_q(v)\qquad(p<q).}
\tag{16}
\]

This deletes one of the four formal branch orientations exactly.

## 3.2 The three surviving equations

The other three equalities reduce to:

### LL

\[
p+u=q+v
\iff
\boxed{u-v=d}.
\tag{17}
\]

The common hit is physical iff `q+v<=2N`.

### RL

\[
2p-1-u=q+v
\iff
\boxed{u+v=p-d-1}.
\tag{18}
\]

Again the common hit is physical iff `q+v<=2N`.

### RR

\[
2p-1-u=2q-1-v
\iff
\boxed{v-u=2d}.
\tag{19}
\]

The common hit is physical iff `2q-1-v<=2N`.

Let `C_LL(p,q)`, `C_RL(p,q)`, `C_RR(p,q)` be the numbers of actual folded-zero pairs satisfying `(17)`, `(18)`, `(19)` with the relevant branch and physical conditions.  Then `(2)` follows exactly.

## 3.3 Immediate geometric consequences

Since `u<=(p-1)/2`, equation `(17)` gives

\[
d\le\frac{p-1}{2},
\qquad
q\le\frac{3p-1}{2}.
\]

Since `v<=(q-1)/2`, equation `(19)` gives

\[
2d\le\frac{q-1}{2},
\qquad
q\le\frac{4p-1}{3}.
\]

For `(18)`, if `u,v>S`, then

\[
d=p-1-u-v<p-1-2S,
\]

hence `(8c)`.

Finally, all primes here are odd.  Therefore `d=q-p` is even.  Each of `(17)--(19)` then forces

\[
u\equiv v\pmod2.
\]

There is no stronger parity exclusion available from the recurrence: the Apéry numbers themselves are odd, but the parity of the **index** of a zero modulo an odd prime is unrestricted by that fact.

# 4. A universal row-load bound from height

The elementary binomial estimate

\[
b_j
=\sum_{k=0}^j\binom jk^2\binom{j+k}{k}^2
\le (j+1)64^j
\tag{20}
\]

is enough for all height arguments below.

For a fixed physical row `m`, every hit prime `p>N` is a distinct prime divisor of `b_m` by `(10)`.  Hence

\[
N^{\lambda(m)}\le\prod_{X_p(m)=1}p\le b_m,
\]

and therefore, uniformly for `N<m<=2N`,

\[
\boxed{
\lambda(m)\le\frac{\log b_m}{\log N}\ll\frac{N}{\log N}.
}
\tag{21}
\]

This bound is crude, but it is sufficient for the pruning arguments.

# 5. Unconditional pruning I: small prime gaps

Let `F_gap(N;D)` be the ordered collision contribution from `0<q-p<=D`.

For a fixed pair `p<q`,

\[
|\Omega_p\cap\Omega_q|\le|Z_p|\ll N^{2/3}
\tag{22}
\]

by the proved zero-count theorem.  There are `O(N/log N)` choices of prime `p`, and for each `p` at most `D` integer choices for `d=q-p`; we may discard the requirement that `q` itself be prime.  Thus

\[
\boxed{
F_{\rm gap}(N;D)
\ll
\frac{N^{5/3}D}{\log N}.
}
\tag{23}
\]

Therefore

\[
D=o\!\left(\frac{N^{1/3}}{\log N}\right)
\]

is enough to make this sector `o(N^2/log^2 N)`.

The explicit choice in `(4)` gives the first bound in `(5)`.

# 6. Unconditional pruning II: a small folded zero

Let `I_S` be the set of physical incidences `(p,m)` whose folded representative

\[
u=\min(m-p,p-1-(m-p))
\]

satisfies `u<=S`.

For each fixed `u`, every prime `p>N` contributing such an incidence divides the fixed integer `b_u`.  Therefore

\[
\#\{p>N:p\mid b_u\}
\le\frac{\log b_u}{\log N}
\ll\frac{u+1}{\log N}.
\tag{24}
\]

Each such prime yields at most two physical hits, one on each reflected branch.  Hence

\[
|I_S|
\ll
\frac1{\log N}\sum_{u\le S}(u+1)
\ll\frac{S^2}{\log N}.
\tag{25}
\]

Charge every ordered collision having at least one small-folded incidence to one such incidence.  By `(21)` there are `O(N/log N)` possible partners at its row.  Thus

\[
\boxed{
F_{\rm fold}(N;S)
\ll
\frac{NS^2}{\log^2N}.
}
\tag{26}
\]

Consequently every choice `S=o(sqrt(N))` makes this sector little-oh at the required scale.  The explicit choice `(4)` yields the second bound in `(5)`.

This is a genuine large-prime-divisor saving: it uses the fact that a prime `>N` dividing a **small folded coefficient** consumes `log N` units of the height of that fixed `b_u`.

# 7. Unconditional pruning III: the upper physical triangle

Let `F_edge(N;H)` be the ordered contribution from pairs whose larger prime satisfies

\[
2N-q\le H.
\]

For such a prime `q`, all physical residues lie in

\[
0\le s\le2N-q.
\]

The proved subinterval zero-count theorem gives

\[
A_q:=|\Omega_q|
=\#\bigl(Z_q\cap[0,2N-q]\bigr)
\ll(H+1)^{2/3}.
\tag{27}
\]

There are at most `H+1` integer values of `q` in the strip, so the total number of `q`-incidences there is

\[
\ll H^{5/3}.
\tag{28}
\]

Each such incidence has at most `O(N/log N)` partners by `(21)`.  Hence

\[
\boxed{
F_{\rm edge}(N;H)
\ll
\frac{NH^{5/3}}{\log N}.
}
\tag{29}
\]

Thus

\[
H=o\!\left((N/\log N)^{3/5}\right)
\]

is sufficient for a little-oh contribution.  The explicit choice `(4)` yields the third bound in `(5)`.

# 8. The quantified residual theorem

Take `D,S,H` as in `(4)`.  Remove collisions counted by any of Sections 5--7.  The remaining folded representatives satisfy

\[
u>S,\qquad v>S,
\]

the gap satisfies

\[
d>D,
\]

and the larger prime satisfies

\[
q\le2N-H.
\]

Define

\[
\begin{aligned}
R_{LL}(N)
:=2\!\sum_{\substack{N<p<q\le2N-H\\q-p>D}}
\#\{(u,v):&\ u\in\widehat Z_p,\ v\in\widehat Z_q,\\
&u,v>S,\ u-v=q-p,\ q+v\le2N\},
\end{aligned}
\tag{30}
\]

\[
\begin{aligned}
R_{RL}(N)
:=2\!\sum_{\substack{N<p<q\le2N-H\\q-p>D}}
\#\{(u,v):&\ u\in\widehat Z_p^\circ,\ v\in\widehat Z_q,\\
&u,v>S,\ u+v=2p-q-1,\ q+v\le2N\},
\end{aligned}
\tag{31}
\]

and

\[
\begin{aligned}
R_{RR}(N)
:=2\!\sum_{\substack{N<p<q\le2N-H\\q-p>D}}
\#\{(u,v):&\ u\in\widehat Z_p^\circ,\ v\in\widehat Z_q^\circ,\\
&u,v>S,\ v-u=2(q-p),\ 2q-1-v\le2N\}.
\end{aligned}
\tag{32}
\]

Then the pruning estimates prove the unconditional identity-with-error

\[
\boxed{
F_{\rm top}(N)
=R_{LL}(N)+R_{RL}(N)+R_{RR}(N)
+o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{33}
\]

Therefore the requested target is **equivalent** to

\[
\boxed{
R_{LL}(N)+R_{RL}(N)+R_{RR}(N)
=o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{34}
\]

This is the sharpest residual statement I can obtain unconditionally from the mechanisms in the question.

# 9. Audit of the proposed mechanisms

## 9.1 Reflection

Reflection is useful: it gives the exact branch decomposition and kills `L_p=R_q` completely.  It also forces the ratio restrictions `(8a)--(8c)`.

It does **not** delete an asymptotically full sector.  The `LL` branch alone still occupies a positive-area region of prime-pair space, for example any compact region with

\[
N<p<q<\frac32p
\]

away from the boundaries.

## 9.2 Parity

Since all relevant primes are odd, `d` is even.  The three branch equations force the two folded zero representatives to have the same parity.  This is at most a constant-factor lattice restriction.  There is no Apéry theorem saying that one parity of zero index is absent.

## 9.3 Physical triangular boundary

The physical cutoff gives the genuine saving `(29)` near `q=2N` and the branch restrictions `(8)`.  But after deleting a width `N^(3/5-o(1))`, a macroscopic triangle remains.  Boundary geometry alone cannot supply the required vanishing proportion.

## 9.4 Central singleton zeros

If `Z_p` is the true singleton

\[
\left\{\frac{p-1}{2}\right\},
\]

its unique hit is `(3p-1)/2`, which is strictly increasing in `p`.  Hence two true central singleton columns never collide.

This is exact but does not control collisions of a central prime with a noncentral prime, nor is there an unconditional theorem that an asymptotically full share of nonempty `Z_p` are central singletons.

## 9.5 Recurrence and gap polynomials

The current gap-polynomial theorem is monochromatic: it constrains two zero positions in one fixed `Z_p`.  The residual equations `(30)--(32)` couple one zero modulo `p` to a different zero modulo `q`.

For a reflected pair inside one `Z_p`, the second zero is already forced by reflection.  Applying the gap polynomial to that reflected pair therefore supplies no cross-prime information.  No existing recurrence identity in `proof.tex` couples the choice of folded zero for distinct characteristics `p` and `q`.

Thus the recurrence technology used through no-consecutive zeros, reflection, zero-count, and gap certificates does not close `(34)`.

## 9.6 Lucas

Lucas is exact and valuable because it converts every collision into

\[
pq\mid b_m.
\tag{35}
\]

But it does not force a third divisor, a square, or a second independent relation.  In this range `pq>N^2`, while `b_m` has exponential size `e^{Theta(N)}`.  Two or even `Theta(N/log N)` distinct top primes are not excluded by size.

## 9.7 Height and large-prime divisor structure

Height gives the small-folded saving `(26)`, but once the folded indices exceed `sqrt(N)/log^2N`, a single prime of size `N` costs only `log N`, far below the available `Theta(u)` logarithmic height of `b_u`.

At the endpoint row, the same obstruction is even clearer.  The term `k=m` in the Apéry sum gives

\[
b_m\ge\binom{2m}{m}^2
=\exp(m\log16-O(\log m)).
\tag{36}
\]

So a product of `cN/log N` primes of size `N`, whose logarithm is only `cN+o(N)`, fits comfortably inside the size budget of one `b_m` for any sufficiently small fixed `c>0`.

Therefore large-prime divisor size alone cannot imply the desired little-oh.

# 10. A residual-scale no-go model for the audited structural constraints

This section is deliberately scoped.  It is **not** an Apéry counterexample.  It shows that the structural consequences audited above do not, as black-box conditions, imply `(34)`.

Fix

\[
m_0=\left\lfloor\frac65N\right\rfloor.
\]

For every prime

\[
N<p\le m_0-S
\]

put

\[
r_p=m_0-p.
\]

Then for large `N`,

\[
S\le r_p\le\frac N5<\frac{p-1}{2}.
\]

Define the artificial palindromic set

\[
Z_p^*=\{r_p,p-1-r_p\}.
\tag{37}
\]

These sets have the following properties.

1. `|Z_p^*|=2`, so they satisfy the size shape `O(p^(2/3))` with enormous room.
2. They are exactly reflection-symmetric.
3. Their two zeros are not consecutive for large `N`, since
   \[
   p-1-2r_p=3p-2m_0-1\gg N.
   \]
4. Their common physical hit is the **left** hit
   \[
   L_p(r_p)=p+r_p=m_0.
   \]
5. All folded representatives exceed `S`.
6. Every larger prime `q` is at most `m_0<2N-H`, so the upper boundary pruning does not touch the star.
7. For a pair `p<q`,
   \[
   r_p-r_q=q-p,
   \]
   so every collision lies in the exact `LL` equation.
8. Since all `p,q` are odd, all gaps are even and all `r_p` have the same parity, so the parity restriction is satisfied.

Let

\[
K_N=\#\{p:N<p\le m_0-S\}.
\]

By the prime number theorem,

\[
K_N\sim\frac{N}{5\log N}.
\]

The number of pairs in the star with `q-p<=D` is at most `K_ND`; because `D=o(N/log N)`, this is `o(K_N^2)`.  Hence after the small-gap pruning there remain

\[
(1-o(1))K_N(K_N-1)
=\Theta\!\left(\frac{N^2}{\log^2N}\right)
\tag{38}
\]

ordered residual collisions.

So reflection + parity + physical geometry + two-point zero sets + no-consecutive zeros + the proved zero-count scale do not force a little-oh.

### Why height does not kill the model

For each retained `r_p>=S`, the elementary lower bound

\[
b_{r_p}\ge\binom{2r_p}{r_p}^2
\]

is already much larger than `p` because `S>>log N`.  Thus the mere size of the individual low coefficient does not prevent it from having one prescribed prime divisor of size `N`.

If all star hits were actual, Lucas would also put all those primes into `b_{m_0}`.  Their product has logarithm

\[
\vartheta(m_0)-\vartheta(N)
=\frac N5+o(N),
\]

whereas `(36)` gives

\[
\log b_{m_0}\ge\frac65N\log16-O(\log N).
\]

Again there is no size contradiction.

The missing fact is therefore not another height inequality.  It is a **cross-prime Apéry non-alignment theorem** saying that the actual folded zero chosen by characteristic `p` cannot line up with those chosen by many other characteristics at one physical row.

# 11. What has actually been gained

The original desired statement was

\[
F_{\rm top}(N)=o(N^2/\log^2N).
\]

The audit gives four rigorous improvements to its formulation:

1. the exact collision problem has only three reflection branches, not four;
2. gaps up to `N^(1/3)/log^2N` are already negligible unconditionally;
3. collisions involving a folded index up to `sqrt(N)/log^2N` are already negligible unconditionally;
4. the triangular strip of width `N^(3/5)/log^2N` at the top edge is already negligible unconditionally.

After these deletions the surviving problem is `(34)`.  It concerns actual Apéry zeros in two different characteristics, both at genuinely long folded depth and genuinely separated prime gap, away from the physical edge.

This is substantially weaker than asking for diagonal AMTD or `F_top=O(T)`.  A proof of any one of

\[
R_{LL}=o(N^2/\log^2N),
\quad
R_{RL}=o(N^2/\log^2N),
\quad
R_{RR}=o(N^2/\log^2N)
\]

still leaves the other two, but the branch equations are different enough that different arithmetic tools could in principle attack them separately.

The most plausible next theorem is a cross-characteristic large-prime divisor estimate along one of the affine branch relations, for example

\[
\sum_{\substack{N<p<q\le2N\\q-p>D}}
\#\{u\in\widehat Z_p,\ v\in\widehat Z_q:
 u,v>S,\ u-v=q-p\}
=o(N^2/\log^2N),
\tag{39}
\]

with the physical cutoff included.  This is an actual-zero theorem, not a fixed-prime zero-count theorem and not an empirical boundedness assumption.

# 12. Exact regression checker

The following standard-library Python program verifies the exact physical reindexing and the folded `LL/RL/RR` decomposition for any finite `N`.  It is a regression checker only; no finite output is used in the proof above.

```python
from math import isqrt


def P(n):
    return 34*n**3 + 51*n**2 + 27*n + 5


def primes_upto(n):
    s = bytearray(b"\x01") * (n + 1)
    if n >= 0:
        s[0] = 0
    if n >= 1:
        s[1] = 0
    for q in range(2, isqrt(n) + 1):
        if s[q]:
            s[q*q:n+1:q] = b"\x00" * (((n-q*q)//q) + 1)
    return [q for q in range(2, n + 1) if s[q]]


def zero_set(p):
    # Exact recurrence modulo p through index p-1.
    b = [1, 5 % p]
    for n in range(1, p - 1):
        num = (P(n) * b[n] - n**3 * b[n-1]) % p
        b.append(num * pow((n+1)**3, -1, p) % p)
    return {r for r, x in enumerate(b) if x == 0}


def physical_hits(N, p, Z):
    return {p+r for r in Z if N < p+r <= 2*N}


def folded_branch(p, m):
    r = m - p
    assert 0 <= r < p
    c = (p - 1) // 2
    if r <= c:
        return (r, "L")
    return (p - 1 - r, "R")


def audit(N):
    ps = [p for p in primes_upto(2*N) if N < p <= 2*N]
    Z = {p: zero_set(p) for p in ps}
    Om = {p: physical_hits(N, p, Z[p]) for p in ps}

    # Direct lambda / factorial moment.
    lam = {m: 0 for m in range(N + 1, 2*N + 1)}
    for p in ps:
        for m in Om[p]:
            lam[m] += 1
    F = sum(x * (x - 1) for x in lam.values())

    LL = RL = RR = LR = 0
    for i, p in enumerate(ps):
        for q in ps[i+1:]:
            d = q - p
            for m in Om[p] & Om[q]:
                u, bp = folded_branch(p, m)
                v, bq = folded_branch(q, m)
                assert u in Z[p] and v in Z[q]
                assert u <= (p-1)//2 and v <= (q-1)//2

                if bp == "L" and bq == "L":
                    assert u - v == d
                    assert q + v == m <= 2*N
                    LL += 1
                elif bp == "R" and bq == "L":
                    assert u + v == p - d - 1
                    assert q + v == m <= 2*N
                    RL += 1
                elif bp == "R" and bq == "R":
                    assert v - u == 2*d
                    assert 2*q - 1 - v == m <= 2*N
                    RR += 1
                else:
                    # L_p = R_q must be impossible for p<q.
                    LR += 1

                assert d % 2 == 0
                assert (u - v) % 2 == 0

    assert LR == 0
    assert F == 2 * (LL + RL + RR)

    print("N", N)
    print("F_top", F)
    print("unordered branches", LL, RL, RR)


if __name__ == "__main__":
    audit(200)
```

# Final conclusion

There **is** unconditional little-oh progress at the weaker `N^2/log^2 N` target scale, but it comes from pruning, not from pairwise independence:

\[
\boxed{
F_{\rm top}
=R_{LL}+R_{RL}+R_{RR}
+o(N^2/\log^2N)
}
\]

with the explicit long-depth, large-gap, interior residual sector `(30)--(32)`.

Reflection kills one branch exactly; the proved `O(p^(2/3))` theorem kills a growing small-gap sector; height kills a growing small-folded-index sector; and the subinterval zero theorem kills a growing physical-edge sector.  Parity gives only a constant-factor condition.

No audited mechanism deletes the remaining sector asymptotically.  The residual star model shows why: all of reflection, parity, the physical triangle, two-point zero sets, no-consecutive zeros, the zero-count scale, and the available height budget can coexist with `Theta(N^2/log^2N)` aligned collisions.  The model is not an Apéry counterexample; it isolates precisely what a proof still needs to use.

The sharp remaining lemma is the actual-zero cross-characteristic non-alignment estimate `(34)`, or one of its branch-specific forms such as `(39)`.  Proving that is enough for the requested top-block target and is strictly weaker than diagonal AMTD.
