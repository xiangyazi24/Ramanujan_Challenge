# P3.2 exact endpoint-rectangle quotient-descent attack

## Verdict

There is a clean all-`n` theorem behind the scan, and it is stronger than merely “there is no quotient-2 nuisance.”  For every `n>=8` and every prime `p>=7` with `p>sqrt(n)`, write

```text
n = q*p + r,       0 <= r < p,
s = p-1-r,
I_n = {ceil(n/3), ..., floor(n/2)}.
```

Let `p` survive the endpoint package if

```text
p | lcm(E^+,E^-).
```

Then:

```text
(1) q=1:
    p survives  <=>  p is an actual q=1 Apéry target,
    i.e. p | b_r (equivalently p | b_s by reflection).

(2) q=2:
    p never survives.

(3) q=3:
    the + branch never survives, and the - branch survives exactly when

        n = 4*p - 1 - s,
        4*s < p-1,
        p | b_s.

(4) q>=4:
    the + branch never survives, and every - survivor satisfies

        p <= q + floor(q/3) + 1,

    hence

        p <= (3 + sqrt(48*n+9))/6.
```

There is one fixed small-prime exception outside the `p>=7` theorem:

```text
(n,p)=(19,5)
```

survives the `q=3` negative branch because the quotient-level scalar `-15` vanishes modulo `5`.

Consequently, if `Nuis(n)` denotes the product of all non-q=1 prime factors `p>sqrt(n)` of `lcm(E^+,E^-)`, then

```text
log Nuis(n)
 = sum_(p in N3(n)) log p + O(sqrt(n)),
```

where

```text
N3(n) = {
  p>=7 prime :
  p>sqrt(n),
  exists s>=0,
  n=4*p-1-s,
  4*s<p-1,
  p|b_s
}.
```

Thus the quotient descent gives `log Nuis(n)=o(n)` **if and only if**

```text
sum_(p in N3(n)) log p = o(n).
```

The existing Lucas/Kummer/Newton mechanism does not prove that last estimate.  It actually saturates on `N3(n)`: for every `p in N3(n)` all the `K`-dependent negative Newton congruences collapse to the single scalar congruence

```text
B_K(-n-1) == -15*b_s  (mod p).
```

So repeating the same descent is idempotent on the only potentially linear-scale nuisance sector.  The `q>=4` remainder is already `O(sqrt(n))` in logarithmic mass.

This also explains the observed first genuine nuisance

```text
(n,p,s)=(64,17,3),
```

because

```text
b_3 = 1445 = 5*17^2.
```

It is the smallest `p>=7` quotient-3 survivor.  However, the scan’s stronger numerical statement

```text
max nuisance p/n = 17/64
```

is **not** an all-`n` consequence of this descent.  The exact `q=3` conditions permit ratios arbitrarily close to `4/15` at the purely Kummer level.  A proof of the `17/64` constant would require a new theorem excluding Apéry zeros from a short terminal subinterval of the allowed `q=3` band.

The rest of this answer proves all of these assertions from Lucas/Kummer and the ordinary-Newton block law.

# 2. First lemma: the Newton coefficients themselves satisfy Lucas

Put

```text
d_m = Delta^m b_0
    = sum_(j=0)^m (-1)^(m-j) binom(m,j) b_j.
```

## Lemma 2.1 — Newton block law

For every prime `p` and `0<=a,r<p`,

```text
d_(a*p+r) == d_a*d_r (mod p).
```

### Proof

Write `j=c*p+t`.  Lucas gives

```text
binom(a*p+r,c*p+t)
 == binom(a,c) binom(r,t) (mod p),

b_(c*p+t) == b_c b_t (mod p).
```

All terms outside `0<=c<=a`, `0<=t<=r` vanish.  For odd `p`,

```text
(-1)^((a-c)*p+r-t)
 = (-1)^(a-c) (-1)^(r-t),
```

and in characteristic two the signs are irrelevant.  Hence the finite-difference sum factors as

```text
[sum_c (-1)^(a-c) binom(a,c)b_c]
*
[sum_t (-1)^(r-t) binom(r,t)b_t]
 = d_a*d_r.
```

QED.

This is the exact Newton analogue of the Apéry Lucas block law.

# 3. Arbitrary truncated Newton block formula

Assume now

```text
p > sqrt(n),
n = q*p+r,
0<=q,r<p.
```

Thus `n<p^2`.  Write a cutoff as

```text
K=A*p+B,
0<=A,B<p.
```

The cutoffs in the question all satisfy this because `K<n/2<p^2/2`.

## Proposition 3.1 — positive endpoint

Modulo `p`,

```text
B_K(n)
 == b_r * B_(A-1)(q)
    + d_A*binom(q,A)*B_B(r),
```

where `B_(-1)=0` by convention.

If `B>=r`, this simplifies to

```text
B_K(n) == b_r * B_A(q)  (mod p).
```

### Proof

Write `j=a*p+t`.  By Lemma 2.1 and Lucas,

```text
d_j binom(n,j)
 == d_a*d_t * binom(q,a)binom(r,t).
```

Every completed low block `a<A` contributes

```text
d_a binom(q,a) * b_r.
```

The last partial block contributes

```text
d_A binom(q,A) * B_B(r).
```

Summing gives the formula.  If `B>=r`, `B_B(r)=b_r` and the high-digit sum becomes `B_A(q)`.

QED.

## Proposition 3.2 — negative endpoint

Put

```text
s = p-1-r,
qv = p-1-q.
```

Then

```text
B_K(-n-1)
 == b_s * B_(A-1)(qv)
    + d_A*binom(qv,A)*B_B(s)       (mod p).
```

If `B>=s`,

```text
B_K(-n-1)
 == b_s * B_A(qv)
 == b_s * B_A(-q-1)                (mod p).
```

### Proof

For `j=A*p+B<p^2`, generalized Lucas for the p-adic integer `-n-1` gives

```text
binom(-n-1,a*p+t)
 == binom(p-1-q,a) binom(p-1-r,t)  (mod p).
```

Equivalently one may start from

```text
binom(-n-1,j)=(-1)^j binom(n+j,j)
```

and apply Kummer/Lucas digitwise.  Combine this with Lemma 2.1 exactly as in Proposition 3.1.

QED.

This is the block identity that drives the quotient descent.

# 4. The two Kummer guards

Set

```text
H0=floor((n-1)/3),
H1=floor(n/2)-1.
```

Then the binomial guard is tested at

```text
k=K+1 in I_n,
I_n={ceil(n/3),...,floor(n/2)}.
```

Write

```text
k=a*p+t,
0<=a,t<p.
```

Because `q<p`, Lucas gives

```text
binom(n,k)
 == binom(q,a) binom(r,t)  (mod p).
```

For every `k in I_n`, one has `a<=q`, so the high factor is nonzero.  Therefore

```text
p | binom(n,k)
 <=> t>r.                                      (4.1)
```

For the negative guard, use

```text
(-1)^k binom(n+k,k)=binom(-n-1,k).
```

The first two p-adic digits of `-n-1` are `(p-1-q, p-1-r)`.  Thus

```text
p | binom(n+k,k)
 <=> a>p-1-q  OR  t>s,                         (4.2)

s=p-1-r.
```

Equations (4.1) and (4.2) are the entire Kummer geometry of the rectangle.

# 5. Quotient 1: exact target capture

Assume

```text
n=p+r,
p>=7,
p>n/2.
```

Then every `K<=H1` is `<p`.

For the `+` branch, (4.1) holds for every `k in I_n` exactly when

```text
ceil(n/3)>r
<=> r<=H0.
```

If this holds, then for every `K in [H0,H1]`,

```text
B_K(n) == b_r (mod p).
```

Hence

```text
p | E^+
<=> r<=H0 and p|b_r.                           (5.1)
```

The `L_K` condition is automatic once `r<=H0` and `p|b_r`.

For the negative branch, (4.2) reduces to `k>s`, so

```text
p | E^-
<=> s<=H0 and p|b_s.                           (5.2)
```

Reflection gives `b_s==b_r mod p`.

Finally, at least one of `r,s` is `<=H0`.  Indeed, if `r>H0`, then `r>=ceil(n/3)` and

```text
s=n-2*r-1 <= H0
```

by checking the three residue classes of `n mod 3`.

Therefore every genuine q=1 target occurs in `lcm(E^+,E^-)`, and conversely every `q=1`, `p>=7` survivor is a genuine target.

This proves the desired exact target retention.

# 6. The + endpoint has no quotient >=2 survivor

This is stronger than the scan observation.

## Proposition 6.1

Let `p>sqrt(n)` and `q=floor(n/p)>=2`.  Then

```text
p does not divide E^+.
```

### q=2

The interval `I_n` contains `k=p`, and

```text
binom(n,p) == 2 (mod p),
```

so the `+` Kummer guard fails.

### q=3

The left endpoint is

```text
k=p+ceil(r/3).
```

Its low digit is `ceil(r/3)<=r`, and

```text
binom(3,1) != 0 mod p
```

because `p>3`.  So the guard again fails.

### q>=4

Put

```text
a=ceil(n/(3*p)),
k=a*p.
```

For `n/p>=4`, one has

```text
ceil(n/3) <= a*p <= floor(n/2),
```

so `k in I_n`.  Its low digit is zero, hence

```text
binom(n,a*p) == binom(q,a) != 0 (mod p).
```

Thus the guard fails.

QED.

So every large-prime nuisance comes from `E^-`, never `E^+`.

The only remaining numerical possibility with `n>=8` is

```text
For every n>=8 and every prime p>sqrt(n),

```

This is the exact all-`n` theorem behind the “no quotient-2 nuisance” scan.

# 8. Quotient 3: complete classification

Now let

```text
n=3*p+r,
p>sqrt(n).
```

Then `p>=5` and

```text
I_n
 = {p+t : ceil(r/3)<=t<=floor((p+r)/2)}.
```

The `+` branch is impossible by Proposition 6.1.

For the negative branch, every `k=p+t` has high digit `1`.  Since

```text
p-1-q=p-4,
```

and `binom(p-4,1)` is nonzero for `p>=5`, equation (4.2) says that the binomial guard vanishes for every `K` exactly when

```text
ceil(r/3) > s,
s=p-1-r.
```

Since `r=p-1-s`,

```text
ceil((p-1-s)/3)>s
<=> p-1-s>3*s
<=> 4*s<p-1.                                  (8.1)
```

Under (8.1), every cutoff has the form

```text
K=p+B,
B>=s.
```

Proposition 3.2 therefore gives

```text
B_K(-n-1)
 == b_s * B_1(p-4)
 == b_s * (1+4*(p-4))
 == -15*b_s                                  (mod p).   (8.2)
```

Here

```text
d_0=1,
d_1=b_1-b_0=4.
```

For `p>=7`, `-15` is a unit modulo `p`.  Thus all Newton conditions are equivalent to

```text
p|b_s.
```

The `L_K` condition is then automatic because `s<=H0`, and `p|Lambda_n` is automatic.

We have proved:

## Theorem 8.1 — exact q=3 nuisance

For `p>=7`, `p>sqrt(n)`, `floor(n/p)=3`,

```text
p | lcm(E^+,E^-)
```

if and only if there is an integer `s>=0` such that

```text
n=4*p-1-s,
4*s<p-1,
p|b_s.
```

There is no hidden K-dependent condition after this reduction.

### The fixed prime p=5

When `p=5`, the scalar `-15` in (8.2) vanishes.  The condition (8.1) forces `s=0`, hence

```text
n=4*5-1=19.
```

Indeed `(n,p)=(19,5)` survives the negative branch although `5` does not divide `b_0`.

This is the only small-prime defect in Theorem 8.1.

# 9. Why (64,17) appears, and what is actually proved about p/n

For `p>=7`, the first possible q=3 nuisance requires a zero `p|b_s` with

```text
4*s<p-1.
```

For `p=7`, the allowed `s` are `0,1`, and neither `b_0=1` nor `b_1=5` is zero mod `7`.

For `p=11`, the allowed `s` are `0,1,2`, and

```text
b_2=73
```

is not zero mod `11`.

For `p=13`, the same `s=0,1,2` check applies.

For `p=17`, `s=3` is allowed and

```text
b_3=1445=5*17^2.
```

Then

```text
n=4*17-1-3=64.
```

Thus `(64,17)` is the smallest q=3 nuisance with `p>=7`.

The Kummer condition also yields a universal ratio bound.  From

```text
n=4*p-1-s,
4*s<p-1,
```

one gets

```text
15*s < n-3,
```

and hence

```text
60*p <= 16*n+11.
```

So every q=3 nuisance satisfies

```text
p <= floor((16*n+11)/60)
  = (4/15)n + O(1).
```

Every `q>=4` prime already satisfies `p<=n/4`.  Therefore every non-q=1 survivor `p>sqrt(n)` satisfies the universal bound

```text
p <= floor((16*n+11)/60)
```

apart from no additional asymptotic exception.

This is the strongest simple ratio bound supplied by the rectangle alone.

## Why 17/64 is not proved all-n

For a q=3 nuisance,

```text
p/n > 17/64
```

is equivalent to

```text
17*(s+1) > 4*p.
```

The Kummer condition is only

```text
4*s < p-1.
```

These two inequalities are compatible for large `p`; they leave a short but nonempty interval of possible `s` near `p/4`.

Therefore the empirical maximum `17/64` cannot be deduced from Lucas, Kummer, and the Newton block law alone.  One would need a new Apéry-specific theorem excluding zeros `s in Z_p` from that terminal interval.

# 10. Quotient >=4 is automatically near sqrt(n)

Let `q>=4` and suppose `p` survives the negative branch.

Put

```text
a=ceil(n/(3*p)),
k=a*p.
```

As in Proposition 6.1, `k in I_n`.  Its low base-`p` digit is zero.  By (4.2), the negative guard can vanish at this `k` only through the high digit:

```text
a > p-1-q.
```

Equivalently,

```text
p <= q+a.                                      (10.1)
```

Because `0<=r<p`,

```text
a <= floor(q/3)+1.
```

Hence the exact quotient restriction is

```text
p <= q + floor(q/3) + 1.                       (10.2)
```

In particular

```text
3*p <= 4*q+3 <= 4*n/p+3,
```

so

```text
3*p^2 - 3*p - 4*n <= 0.
```

Therefore

```text
p <= P(n) := (3+sqrt(48*n+9))/6
            = sqrt(4*n/3)+O(1).                (10.3)
```

This used only one Kummer guard; the Apéry and Newton conditions can only shrink the set further.

By Chebyshev,

```text
sum_(p<=P(n)) log p = O(P(n)) = O(sqrt(n)).
```

Thus all `q>=4`, `p>sqrt(n)` nuisances have total logarithmic mass `O(sqrt(n))=o(n)`.

# 11. Exact terminal nuisance reduction

For `p>=7`, define

```text
N3(n)
 = { p prime :
     p>sqrt(n),
     exists s>=0,
     n=4*p-1-s,
     4*s<p-1,
     p|b_s }.
```

Let `Nuis(n)` be the product of all non-q=1 prime factors `p>sqrt(n)` of `lcm(E^+,E^-)`.

Since `p>sqrt(n)`, every such prime occurs only to the first power in `Lambda_n`.  Thus the large-prime part is squarefree, and Theorems 8.1 and 10.3 give

```text
log Nuis(n)
 = sum_(p in N3(n)) log p + O(sqrt(n)),          (11.1)
```

with the fixed `(19,5)` contribution absorbed in `O(1)`.

Consequently the following are equivalent:

```text
(A) log Nuis(n)=o(n).

(B) sum_(p in N3(n)) log p=o(n).
```

In epsilon form, `(B)` is exactly

```text
for every eps>0,
there exists N_eps,
for every n>=N_eps,

  sum_(p in N3(n)) log p <= eps*n.
```

This is the sharp remaining statement after the endpoint rectangle.

The trivial prime-counting bound gives only `O(n)`, because `N3(n)` lies in an interval of positive linear length near `n/4`.  The one-prime bound `Z(p)=O(p^(2/3))` also does not control this masked diagonal: for each prime `p`, the relevant index is the single moving value

```text
s=4*p-n-1.
```

So no unconditional little-oh follows from the currently stated one-prime information.

# 12. Why literal iteration stalls

There are two possible meanings of “iterate the quotient drop.”  Neither gives a new all-`n` little-oh theorem from the present ingredients.

## 12.1 Reapply the same endpoint rectangle at the same n

This is exactly idempotent on `N3(n)`.

For every `p in N3(n)`, every negative cutoff already satisfies

```text
B_K(-n-1) == -15*b_s == 0 (mod p),
```

and every Kummer guard and `L_K` condition also vanishes.  There is no residual `K`-dependence left to exploit.  A second copy of the same gcd/lcm cannot remove `p`.

So the same rectangle does **not** turn `q=3` into `q>=4`.

## 12.2 Regard a q=3 nuisance as a new q=1 target

For `p in N3(n)`, put

```text
m_p = p+s = 5*p-n-1.
```

Then

```text
p | b_s,
m_p=p+s,
s<p/4,
```

so `p` is indeed a q=1 target at the smaller endpoint `m_p`.

Moreover

```text
(n+1)/4 <= m_p < n/3.
```

But `m_p` depends injectively on `p`.  Thus the q=3 nuisance family fans out into q=1 targets at **different endpoints**.  Reclassifying each prime this way does not create one common characteristic-zero carrier of smaller height; multiplying the separate endpoint carriers simply reconstructs the original nuisance product (with worse height bookkeeping).

Therefore the per-prime descent terminates, but the aggregate logarithmic mass is not reduced.

# 13. Sharp iteration barrier from target coverage

There is also a simple geometric reason the same uniform endpoint rectangle cannot just be moved inward.

For a q=1 target `n=p+r`, the two possible local zero indices are

```text
r,
s=p-1-r=n-2*r-1.
```

The exact universal statement is

```text
min(r,s) <= floor((n-1)/3).
```

The constant `1/3` is the sharp target-covering threshold for an argument that knows only the direct/reflected pair.  Lowering the universal cutoff from about `n/3` to about `n/4` would leave possible q=1 target positions with both `r` and `s` beyond the cutoff.

So a second Kummer rectangle designed merely by shrinking `[H0,H1]` cannot be justified uniformly while retaining every q=1 target.  A further descent needs an additional Apéry-specific relation, not another copy of the same endpoint geometry.

# Final answer

The strongest exact all-`n` quotient drop is not merely

```text
non-target survivor => floor(n/p)>=3.
```

It is the sharper decomposition

```text
q=1 : exactly the target support;
q=2 : empty;
q=3 : exactly n=4p-1-s, 4s<p-1, p|b_s (p>=7);
q>=4: p <= (3+sqrt(48n+9))/6.
```

Hence

```text
log nuisance
 = log(product of the q=3 affine residual primes) + O(sqrt(n)).
```

The quotient-3 residual is therefore the unique remaining obstruction to `o(n)` for this construction.  The Newton block law shows that the construction is already saturated there: the entire endpoint rectangle reduces to `-15*b_s mod p`.  Literal iteration does not improve the quotient.

So the exact next lemma, if one wants this route to close, is

```text
Q3-AFFINE-RESIDUAL:

for every eps>0, for all sufficiently large n,

sum_{p>sqrt(n), p>=7,
    n=4p-1-s, 4s<p-1, p|b_s}
    log p
 <= eps*n.
```

That statement is strictly narrower than the original large-prime problem, but it is not a consequence of Lucas/Kummer/Newton alone.  In particular, the observed global-looking constant `17/64` remains empirical beyond the exact first survivor `(64,17)`.
