## 2. What “p-safe signed interpolation” means

A modular argument based on the Newton basis is p-safe only while every
factorial \(k!\) appearing in \(inom{x}{k}\) is invertible modulo the moving
prime.  Here this means

\[
 0\le k\le m<p.
 \tag{2.1}
\]

For such \(k\), the polynomial

\[
 \binom{x}{k}=\frac{x(x-1)\cdots(x-k+1)}{k!}
\]

belongs to \(\mathbf Z_{(p)}[x]\).  Since \(n\equiv r_p\pmod p\),

\[
 \boxed{\binom nk\equiv\binom{r_p}{k}\pmod p
 \qquad(0\le k\le m).}
 \tag{2.2}
\]

This is exactly the step used by the Newton carrier

\[
 I_n=\sum_{k=0}^m\binom nkd_k.
\]

If \(k\ge p\), (2.2) is no longer a legitimate polynomial congruence.  The
first counterexample is

\[
 \binom{p+r}{p}\equiv1\pmod p,
 \qquad
 \binom rp=0.
 \tag{2.3}
\]

Thus a purported high-degree interpolation proof must explicitly include the
new base-\(p\) Lucas block.  It cannot silently use the degree-\(<p\) argument.
Q476 performs the analogous toric audit: the top-half power has 22 aliases,
but termwise Frobenius reduces their one weighted relation to the original
coefficient equation \(A_r=0\).  No second linear relation appears.

We now isolate the complete degree-\(<p\) signed class.

### Definition 2.1 — p-safe universal linear carrier

Let \(D\ge1\) and \(c_0,\ldots,c_m\in\mathbf Z\), with

\[
 \gcd(D,\Pi_n)=1.
 \tag{2.4}
\]

The rational linear form

\[
 F_c(X)=\frac1D\sum_{k=0}^m c_kX_k
 \tag{2.5}
\]

is called p-safe universal if, for every \(p\in\mathcal P_n\) and every
\(x=(x_0,\ldots,x_m)\in\mathbf F_p^{m+1}\),

\[
 \sum_{k=0}^{r_p}\binom{r_p}{k}x_k=0
 \quad\Longrightarrow\quad
 \sum_{k=0}^m c_kx_k=0.
 \tag{2.6}
\]

This definition deliberately treats the Newton data as independent.  It is
the precise hypothesis under which divisibility is proved only from the one
moving zero \(A_{r_p}=0\), not from an additional identity special to the
actual sequence.

## 3. Classification of every p-safe signed linear carrier

For each \(p\in\mathcal P_n\), define the nonzero row

\[
 b_p=\left(\binom{r_p}{0},\binom{r_p}{1},\ldots,
            \binom{r_p}{m}\right)\in\mathbf F_p^{m+1}.
 \tag{3.1}
\]

The entries after \(r_p\) are zero.  Its first coordinate is \(1\), so
\(b_p\ne0\).

### Lemma 3.1 — kernel inclusion is proportionality

Let \(K\) be a field, \(b\in K^N\setminus\{0\}\), and \(c\in K^N\).  If

\[
 b\cdot x=0\Longrightarrow c\cdot x=0
 \qquad(x\in K^N),
\]

then \(c=\lambda b\) for some \(\lambda\in K\).

#### Proof

The kernel of the nonzero linear functional \(b\cdot-\) has codimension one.
The hypothesis says that \(c\cdot-\) vanishes on this kernel, so it descends
to the one-dimensional quotient.  Hence it is a scalar multiple of
\(b\cdot-\).  \(\square\)

Applying the lemma to (2.6) gives, modulo \(p\),

\[
 c_k\equiv\lambda_p\binom{r_p}{k}.
 \tag{3.2}
\]

At \(k=0\), the binomial coefficient is \(1\), so

\[
 \lambda_p\equiv c_0\pmod p.
 \tag{3.3}
\]

Using (2.2),

\[
 c_k\equiv c_0\binom nk\pmod p
 \qquad(p\in\mathcal P_n).
 \tag{3.4}
\]

The candidate primes are distinct, so the Chinese remainder theorem gives the
following exact classification.

### Theorem 3.2 — signed Newton congruence module

A linear form is p-safe universal if and only if there exist integers
\(t_0,\ldots,t_m\) such that

\[
 \boxed{
 c_k=c_0\binom nk+\Pi_nt_k
 \qquad(0\le k\le m).
 }
 \tag{3.5}
\]

Equivalently, after evaluation at the actual \(d_k\), its numerator is

\[
 \boxed{
 \sum_{k=0}^m c_kd_k
   =c_0 I_n+\Pi_n\sum_{k=0}^m t_kd_k.
 }
 \tag{3.6}
\]

#### Proof

Necessity is (3.4) for every prime dividing \(\Pi_n\).  Conversely, reducing
(3.5) modulo a candidate \(p\) gives

\[
 \sum c_kx_k
 \equiv c_0\sum\binom nkx_k
 \equiv c_0\sum\binom{r_p}{k}x_k,
\]

so (2.6) follows.  \(\square\)

Thus signed interpolation does not create a new congruence module.  It gives
one Newton row plus arbitrary full-candidate-primorial corrections.

## 4. Exact obstruction to cancelling the central \(4^k\) alias

For a coefficient vector \(c\), define

\[
 Z_4(c)=\sum_{k=0}^m c_k4^k.
 \tag{4.1}
\]

This is exactly the contribution obtained by retaining only the constant
monomial \(4\) in each factor of \((\Lambda-1)^k\).

Modulo a candidate \(p\), Theorem 3.2 gives

\[
 \begin{aligned}
 Z_4(c)
 &\equiv c_0\sum_{k=0}^m\binom nk4^k\\
 &\equiv c_0\sum_{k=0}^{r_p}\binom{r_p}{k}4^k\\
 &=c_0 5^{r_p}
 \pmod p.
 \end{aligned}
 \tag{4.2}
\]

The truncation at \(r_p\) is automatic because
\(inom{r_p}{k}=0\) for \(k>r_p\).

Since \(p\ge7\), \(5^{r_p}\) is a p-unit.  Therefore

\[
 \boxed{p\mid Z_4(c)\Longleftrightarrow p\mid c_0.}
 \tag{4.3}
\]

Prime by prime this yields

\[
 \boxed{
 \gcd(Z_4(c),\Pi_n)=\gcd(c_0,\Pi_n).
 }
 \tag{4.4}
\]

### Theorem 4.1 — exact central-alias cancellation forces primorial content

If \(F_c\) is p-safe universal and

\[
 Z_4(c)=0,
 \tag{4.5}
\]

then

\[
 \boxed{\Pi_n\mid c_k\qquad(0\le k\le m).}
 \tag{4.6}
\]

If in addition

\[
 C=\frac1D\sum_{k=0}^m c_kd_k\in\mathbf Z
\]

is nonzero, then

\[
 \boxed{\Pi_n\mid C.}
 \tag{4.7}
\]

Consequently

\[
 \boxed{
 \log|C|\ge\vartheta(n)-\vartheta(n/2)
 =\left(\frac12+o(1)\right)n.
 }
 \tag{4.8}
\]

#### Proof

Equation (4.5) and (4.3) give \(p\mid c_0\) for every
\(p\in\mathcal P_n\).  Then (3.4) gives \(p\mid c_k\) for every \(k\).
Hence \(\Pi_n\mid c_k\) for all \(k\).

Write

\[
 \sum c_kd_k=\Pi_nE.
\]

Because \(C\in\mathbf Z\), \(D\mid\Pi_nE\).  By (2.4),
\(\gcd(D,\Pi_n)=1\), so \(D\mid E\).  Thus

\[
 C=\Pi_n(E/D),
\]

which proves (4.7).  The prime number theorem gives (4.8).  \(\square\)

This is the requested sharp explanation of why signs do not remove the
central \(4^k\) alias in the p-safe linear class.  The central specialization
of the target row is \(5^{r_p}\), a unit.  Therefore making that specialization
zero destroys the selective row and forces the whole candidate prime into the
coefficient content.

### Corollary 4.2 — the canonical Newton class cannot be corrected cheaply

Let

\[
 S_n=\sum_{k=0}^m\binom nk4^k
\]

be the central-alias contribution of \(I_n\).  Then

\[
 S_n\equiv5^{r_p}\not\equiv0\pmod p
 \qquad(p\in\mathcal P_n),
\]

so

\[
 \boxed{\gcd(S_n,\Pi_n)=1.}
 \tag{4.9}
\]

Every signed p-safe correction has central contribution

\[
 c_0S_n+\Pi_nT.
\]

It can equal zero only if \(\Pi_n\mid c_0\).  Thus one cannot start from the
Newton carrier and cancel its \(4^k\) contribution by adding a
full-primorial correction while retaining a p-unit coefficient of \(I_n\).

### Sharpness of the linear-height scale

The lower bound cannot be improved within this theorem.  Since

\[
 A_0=1,\quad A_1=5,\quad A_2=73,
\]

we have

\[
 d_2=A_2-2A_1+A_0=64.
\]

Therefore

\[
 C_n^{\mathrm{sharp}}
 =\Pi_n(d_2-16d_0)=48\Pi_n
 \tag{4.10}
\]

is nonzero, cancels the central \(4^k\) alias exactly, and has

\[
 \log C_n^{\mathrm{sharp}}
 =\left(\frac12+o(1)\right)n.
\]

It is intentionally nonselective: every candidate prime was inserted into the
coefficients.  This is precisely the alternative forced by Theorem 4.1.

## 5. A degree/window tradeoff before central cancellation

The p-safe restriction alone already gives a useful exact lower bound for
short signed windows.

Suppose

\[
 c_k=0\qquad(k>L),
 \tag{5.1}
\]

with \(L<m\).  Take a candidate \(p\) with \(r_p>L\).  In (3.4), choose
\(k=r_p\).  Then

\[
 0=c_{r_p}\equiv c_0\binom{r_p}{r_p}=c_0\pmod p.
\]

Hence \(p\mid c_0\), and then \(p\mid c_k\) for every \(k\).  Put

\[
 \Pi_{n,L}
 =\prod_{\substack{n/2<p<n-L\\p\text{ prime}}}p.
 \tag{5.2}
\]

The inequality \(p<n-L\) is exactly \(r_p>L\).  We have proved:

### Proposition 5.1 — short-window primorial content

Every p-safe universal linear carrier supported in degrees \(0,\ldots,L\)
has

\[
 \boxed{\Pi_{n,L}\mid c_k\quad(0\le k\le L).}
 \tag{5.3}
\]

After p-safe denominator clearing, every nonzero integer value is divisible by
\(\Pi_{n,L}\).  In particular, if \(L=o(n)\),

\[
 \log|C|
 \ge\vartheta(n-L)-\vartheta(n/2)
 =\left(\frac12+o(1)\right)n.
 \tag{5.4}
\]

More generally, for fixed \(0<\alpha<1/2\) and \(L\le\alpha n\),

\[
 \log|C|\ge\left(\frac12-\alpha+o(1)\right)n.
 \tag{5.5}
\]

Thus a slowly growing finite-difference order cannot even reach the central
indices without paying almost the entire top-half candidate primorial.  To
avoid this immediate obstruction, the order must reach
\(m-o(n)\).  At that point Theorem 4.1 controls exact signed removal of the
central \(4^k\) contribution.

## 6. Arbitrary-degree central-alias transversality

The linear theorem is strong but does not include a determinant whose central
alias vanishes through nonlinear rank cancellation.  The following ideal
calculation covers arbitrary polynomial degree.

Let

\[
 \mathscr R_n=\mathbf Z[X_0,\ldots,X_m].
\]

For \(p\in\mathcal P_n\), define

\[
 L_p(X)=\sum_{k=0}^{r_p}\binom{r_p}{k}X_k,
 \qquad
 \mathfrak J_p=(p,L_p).
 \tag{6.1}
\]

The simultaneous formal target ideal is

\[
 \mathfrak I_n=\bigcap_{p\in\mathcal P_n}\mathfrak J_p.
 \tag{6.2}
\]

Distinct \(\mathfrak J_p\)'s are comaximal because they contain distinct
integer primes.  Hence

\[
 \mathfrak I_n=\prod_{p\in\mathcal P_n}\mathfrak J_p.
 \tag{6.3}
\]

Define the central-alias specialization

\[
 \sigma_4:\mathscr R_n\longrightarrow\mathbf Z,
 \qquad
 \sigma_4(X_k)=4^k,
\]

and its kernel

\[
 \mathfrak M_4=\ker\sigma_4
 =(X_0-1,X_1-4,\ldots,X_m-4^m).
 \tag{6.4}
\]

For every candidate \(p\),

\[
 \sigma_4(L_p)=\sum_{k=0}^{r_p}\binom{r_p}{k}4^k=5^{r_p}.
 \tag{6.5}
\]

Moreover

\[
 L_p-5^{r_p}\in\mathfrak M_4.
\]

Since \(\gcd(p,5^{r_p})=1\), choose integers \(a,b\) with

\[
 ap+b5^{r_p}=1.
\]

Then

\[
 1=ap+bL_p-b(L_p-5^{r_p})
 \in\mathfrak J_p+\mathfrak M_4.
\]

Thus

\[
 \boxed{\mathfrak J_p+\mathfrak M_4=(1)}
 \qquad(p\in\mathcal P_n).
 \tag{6.6}
\]

Passing to the product (6.3),

\[
 \boxed{\mathfrak I_n+\mathfrak M_4=(1).}
 \tag{6.7}
\]

Comaximal ideals have intersection equal to product, so:

### Theorem 6.1 — all-degree target/central-alias factorization

\[
 \boxed{
 \mathfrak I_n\cap\mathfrak M_4
 =\mathfrak I_n\mathfrak M_4.
 }
 \tag{6.8}
\]

There is no degree restriction in this theorem.

#### Interpretation

A polynomial \(F\in\mathfrak I_n\) is a universal carrier whose divisibility
is formally deduced from the one target equation \(A_{r_p}=0\) in every
candidate characteristic.  The additional condition
\(F\in\mathfrak M_4\) says that its central \(4^k\) toric alias cancels
exactly.  Equation (6.8) says these are independent constraints.  The central
cancellation does not divide or saturate the target equation; it multiplies it
by a separate alias-vanishing factor.

Every determinant, minor, resultant, discriminant, polynomial creative-
telescoping output, or integer-valued-polynomial construction becomes an
element of \(\mathscr R_n\) after expansion and p-safe denominator clearing.
If its target divisibility is formal and its central alias vanishes exactly,
it lies in the product ideal (6.8).

## 7. Exact evaluation image after central-alias cancellation

Evaluate at the actual Newton coefficients:

\[
 \varepsilon_d:\mathscr R_n\longrightarrow\mathbf Z,
 \qquad
 \varepsilon_d(X_k)=d_k.
 \tag{7.1}
\]

Newton's identity (1.1) gives

\[
 \varepsilon_d(L_p)=A_{r_p}.
\]

Therefore

\[
 \varepsilon_d(\mathfrak J_p)
 =(p,A_{r_p})\mathbf Z.
\]

Multiplying over the candidate primes,

\[
 \boxed{\varepsilon_d(\mathfrak I_n)=R_n\mathbf Z.}
 \tag{7.2}
\]

This is the Newton-coordinate version of Q5630's all-degree evaluation-image
theorem.

For the alias ideal,

\[
 \varepsilon_d(\mathfrak M_4)
 =g_m\mathbf Z,
 \qquad
 g_m=\gcd_{0\le k\le m}(d_k-4^k).
 \tag{7.3}
\]

Evaluation carries a product of ideals to the product of their image ideals.
Using Theorem 6.1,

\[
 \boxed{
 \varepsilon_d(\mathfrak I_n\cap\mathfrak M_4)
 =R_ng_m\mathbf Z.
 }
 \tag{7.4}
\]

The extra factor is bounded independently of \(n\).  Indeed,

\[
 d_2=64,
 \qquad
 d_2-4^2=48.
\]

Also

\[
 d_3=A_3-3A_2+3A_1-A_0
 =1445-3\cdot73+3\cdot5-1
 =1240,
\]

so

\[
 d_3-4^3=1176.
\]

Consequently, for \(m\ge3\),

\[
 \boxed{
 g_m\mid\gcd(48,1176)=24.
 }
 \tag{7.5}
\]

### Corollary 7.1 — exact cancellation gives no radical compression

The gcd of **all** actual integer evaluations of arbitrary-degree universal
carriers whose central alias cancels exactly is \(R_ng_m\), with
\(g_m\mid24\).  Thus complete Smith/Fitting/Bézout saturation of this class
returns the unknown target radical, up to a fixed harmless factor.

This is stronger than saying that one natural signed determinant is too large.
It computes the fully saturated arithmetic output of the entire class.

It is not a proof that every individual evaluation is large.  An individual
polynomial might evaluate to \(R_n\), \(24R_n\), a larger multiple, or zero.
The theorem says that obtaining a subexponential nonzero value from this class
would already amount to proving that \(R_n\) is subexponential.  Exact central
alias cancellation itself contributes no such bound.

## 8. Several aliases and toric-alias determinants

The transversality argument is not special to the number \(4\).

Let \(v=(v_0,\ldots,v_m)\in\mathbf Z^{m+1}\), let

\[
 \sigma_v(X_k)=v_k,
 \qquad
 \mathfrak M_v=\ker\sigma_v.
\]

If

\[
 L_p(v)\not\equiv0\pmod p,
 \tag{8.1}
\]

then exactly the same Bézout argument gives

\[
 \mathfrak J_p+\mathfrak M_v=(1).
 \tag{8.2}
\]

For a geometric alias \(v_k=a^k\),

\[
 L_p(v)=(1+a)^{r_p}.
\]

Hence every fixed alias with \(p\nmid1+a\) is transverse to the target
hyperplane.

For finitely many alias points \(v^{(1)},\ldots,v^{(s)}\), put

\[
 \mathfrak M=\bigcap_{i=1}^s\mathfrak M_{v^{(i)}}.
\]

If each \(L_p(v^{(i)})\) is a p-unit, then
\(\mathfrak J_p+\mathfrak M_{v^{(i)}}=(1)\) for every \(i\).  Multiplying the
corresponding decompositions of \(1\) shows

\[
 \mathfrak J_p+\mathfrak M=(1).
\]

Therefore

\[
 \boxed{
 \mathfrak I_n\cap\mathfrak M=\mathfrak I_n\mathfrak M.
 }
 \tag{8.3}
\]

Thus cancelling several p-unit aliases by a determinant does not create a
second target condition.  It merely multiplies the target ideal by an
independent alias-vanishing ideal.  Any useful gain must come from an
independent, nontrivial bound on the actual evaluation of that alias ideal.

### Relation to Q476's 22 aliases

Q476 proves that the top-half torus-orthogonality sum has exactly 22 alias
locations.  Termwise Frobenius identifies the alias vector with the ordinary
convolution coordinates for \(A_{r_p}\), and the bad-prime event is one

If the alias coordinates are treated as independent variables \(Y_v\), with

lemma as Lemma 3.1 says:

\[
 \lambda\cdot Y=0\Longrightarrow\mu\cdot Y=0
 \quad\text{for every }Y
 \quad\Longrightarrow\quad
 \mu=\alpha\lambda.
 \tag{8.4}
\]

So a signed **linear** recombination of the 22 aliases supplies no second
relation.  A determinant or resultant built only from that one relation lies
in its polynomial ideal and is covered by the all-degree saturation theorem.

The concrete cancellation at \((n,p,r)=(20,17,3)\) recorded in Q476 also shows
why one cannot take gcds or products of selected aliases: individual aliases
need not vanish at a target prime.

## 9. Recurrence identities: what is covered and what is not

### 9.1 Linear recurrence use is covered completely

Adding an exact linear recurrence identity to a linear signed carrier does not
change its value.  After expanding every \(A_j\) in the Newton basis
\(d_0,\ldots,d_m\), one obtains a coefficient vector \(c\).  If the modular
proof uses only the one zero \(A_{r_p}=0\), Theorems 3.2 and 4.1 apply.

Thus recurrence transport cannot rescue a p-safe **linear** signed
finite-difference certificate from the primorial-content conclusion.

### 9.2 Polynomial recurrence use is saturated modulo the targets

Q5630 proves that after reducing an arbitrary recurrence window to the two
integral state variables, the full polynomial target ideal still has actual
evaluation image exactly \(R_n\mathbf Z\), with no bound on degree or window
length.  Hence nonlinear recurrence determinants do not create extra modular
content merely from the target zero.

### 9.3 The central-alias specialization is not a recurrence solution

There is, however, a real scope boundary.  The fake Newton data

\[
 d_k^{\mathrm{cent}}=4^k
\]

correspond to

\[
 A_r^{\mathrm{cent}}=\sum_{k=0}^r\binom rk4^k=5^r.
\]

The sequence \(5^r\) is not a solution of the Apéry recurrence.  Therefore a
nonlinear cancellation that becomes visible only **after** quotienting by the
full recurrence need not define a polynomial vanishing at the central alias
point before quotienting.

This is the exact remaining recurrence loophole.  To exploit it, one must
prove an actual-state-specific signed cancellation unavailable on independent
Newton data.  Q32_SEPARATION_ANALYSIS already identifies the corresponding
bounded-tensor barrier: bounded templates leave a dominant Apéry slot unless
they imply a new algebraic relation for the distinguished state; growing
templates require a quantitative polynomial-approximation estimate.  The
present argument does not upgrade that observation into a full impossibility
theorem for every growing recurrence-specific construction.

## 10. Denominator and degree audit

A valid modular certificate must satisfy both of the following.

### 10.1 Denominators

If a rational coefficient has denominator divisible by a moving candidate
prime \(p\), reduction modulo \(p\) is undefined until that denominator is
cleared.  The cleared integer may acquire exactly the candidate factor one was
trying to prove selectively.

Theorems 3.2 and 4.1 allow arbitrary denominators \(D\) satisfying

\[
 \gcd(D,\Pi_n)=1.
\]

Such denominators do not evade the conclusion: if the cleared numerator has
full \(\Pi_n\)-content and division by \(D\) still gives an integer, coprimality
forces the quotient to retain \(\Pi_n\).

### 10.2 Degrees at least \(p\)

For \(k\ge p\), the congruence

\[
 \binom nk\equiv\binom{n-p}{k}\pmod p
\]

is generally false.  A high-degree certificate must be decomposed into its
base-\(p\) Lucas blocks.  Because \(p\) moves with \(n\), these blocks are
p-dependent.  Treating them as one fixed polynomial identity is invalid.

Q476 shows that the analogous toric block decomposition is finite in the
specific top-half power, but it still yields only the original one weighted
alias equation.  A high-degree escape therefore needs a genuinely new
identity between distinct Lucas/toric blocks, not a reuse of the degree-\(<p\)
interpolation congruence.

## 11. Exact scope of the obstruction

### Ruled out

The following are ruled out as sources of an \(o(n)\)-height certificate.

1. A signed linear combination of \(d_0,\ldots,d_m\) whose divisibility is
   formally deduced from \(A_{r_p}=0\), if it cancels the \(4^k\) alias
   exactly.
2. Any signed linear finite-difference window of order \(L=o(n)\), even before
   central cancellation.
3. Rational p-safe coefficients; candidate-prime denominators do not count as
   valid modular steps.
4. Arbitrary-degree polynomial, determinant, resultant, discriminant, Smith,
   Fitting, or elimination constructions in independent Newton variables,
   when target divisibility comes only from \(A_{r_p}=0\) and central alias
   cancellation is exact.
5. Finite collections of toric aliases at which the target Newton form is a
   p-unit.
6. Linear recombinations of Q476's 22 aliases: they are proportional to the
   original weighted equation.

### Not ruled out

The following remain genuine loopholes.

1. **Archimedean near-cancellation, not exact alias removal.**  A signed
   carrier may retain a large nonzero central contribution and cancel it
   against noncentral toric aliases at the actual Apéry values.  Positivity no
   longer bounds such an expression.  Proving a nonzero \(e^{o(n)}\) remainder
   would be new arithmetic information; it is not supplied by the modular
   ideal.
2. **A second target-selective congruence.**  For example, a relation involving
   \(A_{r_p}/p\), a derivative, a reflected quotient, or another coordinate
   that is not generated by the single equation \(A_{r_p}=0\).
3. **A recurrence-specific nonlinear identity.**  It must use that the actual
   Apéry state satisfies the full global recurrence in a way that the fake
   central sequence \(5^r\) does not.
4. **A degree-\(\ge p\) Lucas-block identity.**  It must explicitly control the
   moving high digit and provide more than the one Frobenius-collapsed alias
   equation audited in Q476.
5. **Cross-prime coupling.**  An identity linking different residues
   \(n-p\) before multiplying candidate-wise carriers would fall outside the
   one-prime target ideal.

These are not cosmetic gaps.  Each is exactly an input absent from the
p-safe signed interpolation/alias calculus.

## 12. Final theorem package

For convenient reuse, the result can be quoted as follows.

### Theorem A — linear p-safe central-alias obstruction

Fix \(n>10\), set \(m=\lfloor(n-1)/2\rfloor\), and let
\(\Pi_n=\prod_{n/2<p\le n}p\).  Let \(D\) be coprime to \(\Pi_n\), and let

\[
 C=\frac1D\sum_{k=0}^m c_kd_k\in\mathbf Z.
\]

Assume that for every candidate prime \(p\), vanishing of the formal Newton
row

\[
 \sum_{k=0}^{n-p}\binom{n-p}{k}X_k
\]

implies vanishing of \(\sum c_kX_k\) over \(\mathbf F_p\).  Then

\[
 c_k=c_0\binom nk\pmod{\Pi_n}
 \qquad(0\le k\le m).
\]

If additionally

\[
 \sum_{k=0}^m c_k4^k=0,
\]

then \(\Pi_n\mid C\).  Hence either \(C=0\), or

\[
 \log|C|\ge\left(\frac12+o(1)\right)n.
\]

### Theorem B — all-degree transversality

With

\[
 L_p=\sum_{k=0}^{n-p}\binom{n-p}{k}X_k,
 \quad
 \mathfrak I_n=\bigcap_{n/2<p\le n}(p,L_p),
 \quad
 \mathfrak M_4=(X_k-4^k:0\le k\le m),
\]

one has

\[
 \mathfrak I_n\cap\mathfrak M_4
 =\mathfrak I_n\mathfrak M_4.
\]

At the actual Newton coefficients,

\[
 \operatorname{ev}_d(\mathfrak I_n\cap\mathfrak M_4)
 =R_ng_m\mathbf Z,
 \qquad
 g_m=\gcd_k(d_k-4^k),
 \qquad
 g_m\mid24\quad(m\ge3).
\]

Therefore exact signed cancellation of the central \(4^k\) alias does not
compress the moving target radical.  In the linear p-safe class it forces the
entire candidate primorial; in the arbitrary-degree polynomial class its
fully saturated arithmetic effect is only an independent fixed factor.

That is the strongest rigorous obstruction presently available for this
narrow carrier route.  A positive solution must enter one of the explicitly
listed loopholes rather than refine the same p-safe interpolation or toric-
alias cancellation argument.
