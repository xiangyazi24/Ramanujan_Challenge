# Overconvergence transfer: geometric direction does not automatically imply character direction

## Short answer

The proposed implication is **not currently valid**:

```
overconvergence in t
        |
        v
analyticity of theta_p(t)
        |
        X
bounded number of Mellin coefficients b_r divisible by p
```

The obstruction is that Mellin transform changes the geometry completely. Overconvergence controls the analytic continuation of a function on the geometric parameter space. AFP asks for anti-concentration of its values after reduction modulo p in the finite character group. These are different directions.

The missing step is:

```
(overconvergent trace function)
        =>
(non-degeneracy / p-adic anti-cancellation of Mellin coefficients)
```

and this is not supplied by overconvergence alone.

## (A) Mellin transform relation

The identity

```
b_r = - sum_t theta_p(t) t^r   (mod p)
```

is correct: the sequence b_r is the multiplicative Fourier transform of the trace function theta_p.

Overconvergence says that theta_p belongs to a good p-adic function space (roughly a dagger algebra on the ordinary locus). This gives strong bounds on the coefficients of theta_p with respect to a geometric expansion.

However, Mellin coefficients are not the same coefficients. The Mellin transform diagonalizes the multiplicative action of F_p^*, not the local analytic expansion in t.

A function can be overconvergent and still have many Mellin coefficients vanishing modulo p because of global multiplicative symmetries.

## (B) Why exponential Fourier decay is insufficient

For a p-adic analytic function on an annulus, one has estimates of the form:

```
|c_n|_p <= C rho^{-n}
```

for suitable expansion coefficients c_n.

But AFP concerns:

```
#{r : b_r = 0 mod p}
```

which is a statement about whether a coefficient has valuation at least one. Exponential decay gives information about large n. It does not prevent many coefficients from landing exactly in the maximal ideal.

The logical gap is:

```
large p-adic size of coefficients
!=
nonzero reduction modulo p
```

A coefficient can be small, zero, or highly divisible by p for arithmetic reasons unrelated to analytic radius.

## (C) The lacunarity statement is too strong

The claim:

```
The Mellin transform is lacunary: only O(1) coefficients are p-adically small.
```

does not follow from overconvergence.

A correct replacement would require an additional hypothesis such as:

```
The Mellin transform has no persistent congruence obstruction
```

or equivalently a quantitative independence statement for the multiplicative characters.

This is exactly the missing AFP input.

For example, an overconvergent function could be a multiplicative character itself:

```
theta(t)=chi(t)
```

which is perfectly rigid analytically, but its Mellin transform is concentrated at one character. Conversely, combinations of characters can force many Mellin zeros.

## (D) Location of the failed implication

The chain

```
C overconvergent in t
    |
    v
controlled theta_p(t)
    |
    ?
controlled Mellin valuations of b_r
    |
    v
AFP
```

fails at the middle arrow.

The missing theorem would be a p-adic multiplicative uncertainty principle:

```
If f is an overconvergent trace function with geometric monodromy G,
then its Mellin transform cannot vanish on a large subset of characters
unless f has an algebraic symmetry forcing this.
```

No general theorem of this strength is known.

The relevant additional structures that could provide it are:

1. large geometric monodromy (Sp_4 for the Apéry motive);
2. irreducibility of the associated hypergeometric sheaf;
3. Katz-type bounds for character sums;
4. p-adic slope constraints on the unit-root F-crystal.

Overconvergence alone is insufficient.

## (E) Jacobi sums comparison

The elliptic curve example is special because the character twist is essentially multiplicative on a one-dimensional unit root:

```
alpha(r)=u^r
```

for a p-adic unit u. Therefore:

```
alpha(r) != 0
```

for every r.

The Apéry situation is different. The twist changes the entire hypergeometric Frobenius operator. The unit root is not obtained by multiplying one fixed unit by a character value.

Therefore cancellation among Mellin components is possible.

## Quantitative answer: what bound follows from rank and radius?

For a general rank-d overconvergent F-crystal with radius rho>1, there is **no universal bound**:

```
#{r : alpha(r)=0 mod p} <= F(d,rho)
```

because one can construct overconvergent functions with arbitrarily many prescribed vanishing Mellin coefficients.

A bound of the desired type requires arithmetic hypotheses beyond overconvergence, for example:

```
large monodromy + no exceptional character subspaces
```

Then one expects bounds of the shape:

```
number of bad characters = O(rank, conductor, singularity data)
```

coming from trace-function technology, not from radius alone.

## Consequence for AFP

The correct surviving route is therefore:

```
Apéry overconvergent crystal
        |
        v
Katz hypergeometric monodromy / Sp_4 rigidity
        |
        v
multiplicative character anti-concentration
        |
        v
#{r:b_r=0 mod p}=O(1)
```

The new missing theorem is not overconvergence transfer. It is a **Mellin anti-concentration theorem for the Apéry hypergeometric trace function**.

Overconvergence supplies the analytic environment; monodromy supplies the randomness. AFP requires the combination.
