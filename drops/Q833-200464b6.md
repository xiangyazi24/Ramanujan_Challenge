# Localized resultant audit for the Franel shell carrier

## Conclusion

The proposed localized resultant route does not currently close the shell carrier. The full resultant identity is exact, but every known localization that preserves divisibility by a macroscopic family of target primes still has height at least linear in the number of surviving local clusters. The obstruction is not the universal factorial content; it is that a single integer carrier must simultaneously vanish at evaluations belonging to separated fibres.

The strongest unconditional statement obtained from the supplied hypotheses is therefore a localized gcd lemma, not a fibre-wide carrier.

## 1. Exact divisibility bookkeeping

Let

```
Q_X(Y) = (X!)^2 S_X(Y)
B_X(Y) = product_{0 <= h < X} (Y-h(h+1)).
```

At the root

```
Y=m(m+1)
```

the prime divisors of the window gcd are exactly the shell target primes by the banked theorem. Thus for a fixed h,

```
p | gcd(Q_X(h(h+1)), B'_X(h(h+1)))
```

means p divides the corresponding Franel evaluation and p belongs to the folded shell attached to h.

However, replacing B_X by a subset

```
B_A(Y)=product_{h in A}(Y-h(h+1))
```

only captures primes arising from h in A. A carrier built from disjoint local sets A_i satisfies

```
Res(Q_X,B_A)= product_{h in A} Q_X(h(h+1))
```

up to leading coefficients. Therefore primes from different A_i are combined only by multiplying the corresponding evaluation values.

## 2. Removing factorial content does not solve the height problem

The factor (X!)^2 is universal. Dividing it gives the primitive evaluations

```
S_X(h(h+1)).
```

This removes

```
log((X!)^2)=O(X log X)
```

from each evaluation, but it does not remove the independent contribution of separated h values.

If there are k transverse clusters with representatives h_1,...,h_k, any product carrier

```
C = product_i S_X(h_i(h_i+1))
```

has logarithmic height bounded below by the sum of the non-universal parts. The available information gives no cancellation between these values.

## 3. Subresultants

Subresultants do not improve this obstruction. They replace the full resultant by coefficients in the polynomial remainder sequence. For coprime polynomials, the subresultant chain certifies coprimality, but divisibility by a prime p requires a common root modulo p.

A local factor B_A gives only the congruence classes attached to A. Different clusters have different roots modulo p. A subresultant cannot merge unrelated modular roots into one smaller integer without an additional algebraic relation among the evaluations.

## 4. Franel recurrence

The recurrence among nearby Franel values gives linear relations of the form

```
a_0 S_X(t)+a_1 S_X(t+1)+...+a_r S_X(t+r)=0.
```

Such relations can reduce the number of independent evaluations inside one bounded cluster. They do not currently produce a multiplicative identity forcing all cluster primes to divide one small integer.

The missing implication would be:

```
local shell divisibility + Franel recurrence
        => one low-height global carrier.
```

This implication is not established.

## 5. Canonical obstruction model

A compatible obstruction is obtained by assigning each transverse cluster C_i an independent prime label p_i and evaluation value

```
S_i = p_i * u_i
```

with u_i coprime to every p_j, j != i, while maintaining the recurrence through integer linear choices of the u_i. The existing hypotheses only prescribe which primes divide which evaluations; they do not prescribe cross-cluster multiplicative overlap.

For such a model, any integer divisible by all p_i must contain

```
product_i p_i
```

and hence has logarithmic height at least

```
sum_i log p_i.
```

If the number of transverse clusters is Omega(X/log X), this gives no o(X) carrier from the present inputs.

This obstruction is canonical-compatible: it does not use arbitrary masks, only the missing independence between distinct shell fibres.

## 6. Weakest remaining lemma

The remaining useful target is the following.

**Localized resultant/gcd lemma (open).** Let H be an interval of h-values of polylogarithmic diameter containing one fully transverse cluster. Then there exists an explicitly computable integer C_H with

1. every target prime arising from H divides C_H;
2. C_H is nonzero;
3. 

```
log |C_H| = o(|H| + log N)
```

uniformly over fixed-q bad rows.

A stronger fibre-wide version would require combining Omega(X/log X) clusters into one carrier of height o(X), and is not implied by the current resultant, subresultant, recurrence, or factorial-removal arguments.

## Final status

No proved macroscopic low-height carrier exists from the stated inputs. The exact remaining obstruction is not identifying target primes; it is proving cross-cluster algebraic dependence strong enough to compress the product of local carriers. The next lemma should therefore be a single-cluster localized resultant lemma, with explicit height bound, rather than a global shell carrier theorem.
