# Q168 — Directly sieving the large prime factors of the Apéry number \(b_n\)

## Executive verdict

There are two important corrections before evaluating the five proposed approaches.

1. The literal fixed-saving statement is already true for a completely trivial reason stronger than the height bound. If
   
   \[
   K_{\mathrm{top}}(n)=\#\{p:n/2<p\le n,\ p\mid b_n\},
   \]
   
   then
   
   \[
   K_{\mathrm{top}}(n)\le \pi(n)-\pi(n/2)
   =\left(\frac12+o(1)\right)\frac{n}{\log n}.
   \]
   
   Thus one may take, for example, \(arepsilon=3\) in the proposed bound
   
   \[
   K_{\mathrm{top}}(n)\le (3.52-arepsilon)\frac n{\log n}
   \]
   
   for all sufficiently large \(n\). No Apéry structure is needed.

2. A single fixed saving does **not** imply the conjecture. Every bound
   
   \[
   K_{\mathrm{top}}(n)\le c\frac n{\log n}
   \qquad(c>0\text{ fixed})
   \]
   
   still allows
   
   \[
   B_{\mathrm{top}}(n)=\sum_{\substack{n/2<p\le n\\p\mid b_n}}\log p
   \asymp n.
   \]
   
   What is required is a zero-density statement inside the available primes:
   
   \[
   \boxed{
   K_{\mathrm{top}}(n)
   =o\!\left(\pi(n)-\pi(n/2)\right)
   =o\!\left(\frac n{\log n}\right).
   }
   \]

After this correction, the substantive answer is negative: none of the proposed generic tools—supercongruences, divisor bounds, Erdős–Kac, Rosser–Iwaniec sieve, or Lucas-sequence prime-factor technology—currently gives this pointwise zero density. The exact obstruction is the same cross-prime moving-diagonal problem isolated elsewhere in the project.

The Apéry structure does give a very sharp reformulation:

```text
p in (n/2,n), p >= 7:

p | b_n  <==>  p | b_{n-p}  <==>  n-p in Z_p.
```

Thus the question is not an ordinary problem about the factorization of one generic integer. It is the pointwise incidence problem

\[
K_{\mathrm{top}}(n)
=\#\{p\in(n/2,n):n-p\in Z_p\},
\]

where the target set \(Z_p\) changes with \(p\). A direct sieve would have to prove cross-prime anti-alignment of these targets; that is essentially the missing atom-tail/factorial-moment theorem, not something supplied automatically by classical sieve theory.

## 1. The correct elementary bounds

Let

\[
\alpha=17+12\sqrt2=(1+\sqrt2)^4,
\qquad
\lambda=\log\alpha=3.525494348\ldots .
\]

The recurrence gives

\[
\log b_n=\lambda n+O(\log n).
\]

The height argument therefore gives

\[
K_{\mathrm{top}}(n)\log(n/2)
\le \log b_n
=\lambda n+O(\log n),
\]

and hence

\[
K_{\mathrm{top}}(n)
\le (\lambda+o(1))\frac n{\log n}.
\]

This is valid, but it is not the best trivial estimate for **distinct** prime factors. There are only

\[
\pi(n)-\pi(n/2)
=\left(\frac12+o(1)\right)\frac n{\log n}
\]

candidate primes. Consequently

\[
\boxed{
K_{\mathrm{top}}(n)
\le \left(\frac12+o(1)\right)\frac n{\log n}.
}
\]

Equivalently, for every fixed

\[
0<\varepsilon<\lambda-\frac12
=3.025494348\ldots,
\]

one has

\[
K_{\mathrm{top}}(n)
\le (\lambda-arepsilon)\frac n{\log n}
\]

for all sufficiently large \(n\).

There is a useful notation distinction here:

\[
\omega_I(N)=\#\{p\in I:p\mid N\}
\]

counts distinct prime divisors, whereas

\[
\Omega_I(N)=\sum_{p\in I}v_p(N)
\]

counts them with multiplicity. Prime supply directly bounds \(\omega_I\), while the height bound directly controls \(\Omega_I\). The question is stated with \(\omega\), so the coefficient \(1/2\), not \(3.52549\), is the natural trivial barrier.

For the logarithmically weighted radical,

\[
B_{\mathrm{top}}(n)
:=\sum_{\substack{n/2<p\le n\\p\mid b_n}}\log p,
\]

prime supply gives

\[
B_{\mathrm{top}}(n)
\le \vartheta(n)-\vartheta(n/2)
=\left(\frac12+o(1)\right)n.
\]

Because every \(p\) in the window satisfies

\[
\log(n/2)\le \log p\le \log n,
\]

we have the exact scale equivalence

\[
K_{\mathrm{top}}(n)=o(n/\log n)
\quad\Longleftrightarrow\quad
B_{\mathrm{top}}(n)=o(n).
\]

A fixed positive coefficient, whether \(3.52\), \(1/2\), \(10^{-6}\), or anything else, remains linear after logarithmic weighting and does not prove \(e^{o(n)}\).

## 2. Height is extraordinarily far from seeing the desired sparsity

Define the top-window primorial

\[
Q_n=\prod_{n/2<p\le n}p.
\]

The prime number theorem gives

\[
\log Q_n
=\vartheta(n)-\vartheta(n/2)
=\left(\frac12+o(1)\right)n.
\]

Compare this with

\[
\log b_n=(3.525494348\ldots)n+O(\log n).
\]

Therefore

\[
\log Q_n^7=(3.5+o(1))n<\log b_n
\]

for sufficiently large \(n\). In other words, size alone is compatible not merely with **every** prime in \((n/2,n]\) dividing \(b_n\), but with every such prime occurring to exponent seven. Of course this does not assert the divisibility; it shows that no contradiction based only on total height is possible.

This also quantifies what a valuation-amplification argument would need. Suppose hypothetically that every top-window hit satisfied

\[
v_p(b_n)\ge \kappa.
\]

Then height would give only

\[
K_{\mathrm{top}}(n)
\le \left(\frac{\lambda}{\kappa}+o(1)\right)\frac n{\log n}.
\]

For \(\kappa\le7\), this is weaker than the ambient-prime bound \(1/2\). A fixed \(\kappa\ge8\) would give a genuine fixed saving below \(1/2\), but still not \(o(n/\log n)\). To obtain the conjecture from multiplicities alone, one would need a lower bound \(\kappa=\kappa(n)\to\infty\) for essentially all hits. Neither the known supercongruences nor the observed factorizations suggest such behavior.

Similarly, proving one large prime factor outside the window saves only its logarithm from the height budget. A Stewart-type lower bound of polynomial or mildly superpolynomial size has logarithm \(o(n)\) and therefore cannot create a fixed linear saving, let alone force \(B_{\mathrm{top}}(n)=o(n)\). To solve the problem by accounting for factors outside the window, one would need to prove that those outside factors consume

\[
(\lambda-o(1))n
\]

of logarithmic mass. That is essentially another formulation of the desired theorem, not a preliminary estimate.

## 3. The exact top-window reformulation supplied by the Lucas law

Let \(p\in(n/2,n)\) and write

\[
n=p+r,
\qquad 0\le r<p.
\]

The base-\(p\) digits of \(n\) are \(1,r\). Gessel's Lucas congruence gives

\[
b_n=b_{p+r}\equiv b_1b_r=5b_r\pmod p.
\]

Hence, for \(p\ge7\),

\[
\boxed{
p\mid b_n\quad\Longleftrightarrow\quad p\mid b_{n-p}.
}
\]

The endpoint \(p=n\) is not a hit for \(p\ge7\), because

\[
b_p\equiv b_1b_0=5\not\equiv0\pmod p.
\]

Thus, up to the finite prime \(5\),

\[
\boxed{
K_{\mathrm{top}}(n)
=\sum_{n/2<p<n}\mathbf1_{Z_p}(n-p).
}
\]

Equivalently, changing variables \(r=n-p\),

\[
\boxed{
K_{\mathrm{top}}(n)
=\sum_{0\le r<n/2}
\mathbf1_{\mathbb P}(n-r)
\mathbf1_{\,n-r\mid b_r}.
}
\]

This is a Goldbach-like shifted-divisor incidence: \(n-r\) must simultaneously be prime and divide the different integer \(b_r\). It explains why factor-counting methods on the single integer \(b_n\) lose the essential structure, while product estimates over the integers \(b_r\) become much too large.

There is one small direct consequence. If \(p=n-r\mid b_r\), then \(b_r\ge p>n/2\). Since

\[
\log b_r=\lambda r+O(\log r),
\]

we get

\[
r\ge \frac{\log n}{\lambda}+O(\log\log n).
\]

Thus no hit can occur with \(p\) in an \(O(\log n)\)-length interval immediately below \(n\), apart from small exceptions. This removes only \(o(n/\log n)\) candidate primes and leaves the coefficient \(1/2\) unchanged. It is a genuine structural restriction, but quantitatively negligible for the conjecture.

## 4. Audit of the five proposed routes

### 4.1 Supercongruences and multiplicative structure

The Beukers-type congruence

\[
b_{mp^s}\equiv b_{mp^{s-1}}\pmod{p^{3s}}
\]

is powerful when the **index is divisible by \(p\)**. A top-window hit has

\[
n=p+r,
\qquad 0<r<p,
\]

so \(p\nmid n\). The only possible multiple in this range is \(n=p\), and, as just noted,

\[
b_p\equiv5\pmod p
\]

for \(p\ge7\). Therefore the standard supercongruence is literally off the relevant locus.

The Apéry sequence is also not multiplicative or a divisibility sequence in the integer sense. There is no analogue of

\[
m\mid n\Longrightarrow b_m\mid b_n
\]

and no factorization of \(b_n\) indexed by the divisors of \(n\). The \(p\)-Lucas property is multiplicative in the **base-\(p\) digits modulo \(p\)**; it is not an integer factorization.

A generalized \(p\)-adic block law could in principle control \(v_p(b_{p+r})\) in terms of \(b_r\), but a fixed valuation gain would still face the quantitative obstruction in Section 2. What is needed is scarcity of distinct primes, not merely a bounded congruence exponent.

**Verdict:** the known supercongruences do not touch generic top-window hits, and even a fixed multiplicity theorem would not prove the required little-\(o\) bound.

### 4.2 Generic and sequence-specific divisor bounds

Let \(	au(N)\) be the divisor function. Since every distinct top-window prime doubles the number of divisors,

\[
2^{K_{\mathrm{top}}(n)}\le \tau(b_n).
\]

The maximal-order bound of Wigert–Ramanujan type is

\[
\log\tau(N)
\le(\log2+o(1))\frac{\log N}{\log\log N}.
\]

With \(N=b_n\), this becomes

\[
\log\tau(b_n)
\le(\lambda\log2+o(1))\frac n{\log n},
\]

and therefore

\[
K_{\mathrm{top}}(n)
\le(\lambda+o(1))\frac n{\log n}.
\]

So the sharp generic divisor bound reproduces the height coefficient and is substantially weaker than prime supply.

A genuinely sequence-specific theorem such as

```text
tau(b_n) = exp(o(n/log n))   for every n
```

would solve the problem, because \(2^{K_{\mathrm{top}}(n)}\le\tau(b_n)\). But this would be an extremely strong global factorization theorem about Apéry numbers. It is not a routine consequence of being hypergeometric or holonomic. The binomial-factorial product structure belongs to the summands

\[
\binom nk^2\binom{n+k}{k}^2,
\]

and summation destroys the divisibility factorization that would be needed for a divisor theorem.

Thus “prove an improved divisor bound for \(b_n\)” is a logically valid target, but presently it is a restatement at least as hard as the original large-prime problem, not an available technique.

**Verdict:** generic divisor theory gives no saving; a sufficient Apéry-specific divisor bound would itself be a major new theorem.

### 4.3 Erdős–Kac for the sequence \(b_n\)

The random-integer heuristic is useful for predicting the answer, but it is not a theorem one can transfer automatically to the sparse deterministic sequence \(b_n\). In fact the fixed-prime local statistics of Apéry numbers are very different from those of random integers.

Let

\[
z_p=|Z_p|=\#\{0\le a<p:p\mid b_a\}.
\]

For \(0\le m<p^k\), write \(m\) in base \(p\). By the Lucas product law,

\[
p\nmid b_m
\]

if and only if every base-\(p\) digit avoids \(Z_p\). Hence the exact count is

\[
\#\{0\le m<p^k:p\nmid b_m\}=(p-z_p)^k,
\]

so

\[
\frac1{p^k}\#\{0\le m<p^k:p\mid b_m\}
=1-\left(1-\frac{z_p}{p}\right)^k.
\]

If \(z_p>0\), this density tends to \(1\) as \(k\to\infty\). A fixed active prime therefore divides \(b_m\) for almost every sufficiently long base-\(p\) digit string. This is the opposite of the random-integer local probability \(1/p\).

The top window is special because \(n<2p\): the high digit is fixed at \(1\), and only the low digit \(r=n-p\) varies. Its local density is \(z_p/p\). If the observed mean \(z_p\approx1\) persists, then the heuristic mean is

\[
\sum_{n/2<p\le n}\frac{z_p}{p}
\sim\frac{\log2}{\log n},
\]

which agrees strikingly with the project computation. But proving this uniformly in the moving range \(p\asymp n\), and especially proving an all-\(n\) upper tail, is exactly the hard problem.

Even a full Erdős–Kac theorem for \(\omega(b_m)\) as \(m\le N\) varies would normally be a normal-order or density-one statement. It could still leave an infinite sparse sequence \(n_j\) with very large \(K_{\mathrm{top}}(n_j)\). The project already has density-one control; the unresolved conjecture is precisely the pointwise exceptional tail.

The directly relevant published result is Luca–Shparlinski (2008), which proves for a density-one set of indices the **lower** bounds

\[
\omega(b_n)>c_0\log\log\log n,
\qquad
P(b_n)>c_0(\log n\log\log n)^{1/2}.
\]

These results use the recurrence and Lucas congruences, but they go in the opposite direction and are far below the top-window scale.

**Verdict:** the heuristic is excellent, but a classical Erdős–Kac theorem neither follows from existing structure nor would, by itself, settle the all-\(n\) conjecture.

### 4.4 Rosser–Iwaniec or Selberg sieve

A combinatorial sieve needs an ensemble and distribution data. In a standard notation one must estimate, for squarefree \(d\),

\[
A_d(X)=\#\{m\le X:d\mid b_m\}
=Xg(d)+r_d,
\]

with a multiplicative local density \(g\) and a sufficiently strong average bound for the remainders \(r_d\).

For one fixed \(n\), there is no ensemble: one is asking for the prime divisors of a single integer \(b_n\). Treating the prime \(p\) as the sieve variable does not help, because the condition \(p\mid b_n\) is not a congruence class condition on \(p\); it is simply membership in the unknown divisor set of a constant.

If one dualizes and averages over \(n\), then the one-prime density is indeed governed by \(Z_p\). But a sieve requires joint information. For distinct primes \(p,q\asymp X\), simultaneous hits are controlled by CRT modulo \(pq\asymp X^2\), while the \(n\)-interval has length only \(X\). There is no complete period. The \(O(1)\) boundary error per CRT class is harmless for one pair but becomes dominant after summing over many pairs and tuples. This is exactly the pair-to-third-moment barrier identified in `problems/3.2/proof.tex` and `problems/3.2/DOCTRINE.md`.

Knowing only

\[
g(p)=\frac{z_p}{p}
\]

is not enough. A Rosser–Iwaniec upper-bound sieve would need, in some form, estimates for

\[
\#\{m\in I:m\bmod p_i\in Z_{p_i}\ 	ext{for all }i\}
\]

uniformly for products of large, co-varying primes. Such estimates are the desired cross-prime independence theorem.

In the project's language, the sieve needs the same input as a sufficiently high factorial moment \((\mathrm{HM})_k\), or the pointwise atom-tail estimate

\[
\max_m K_X(m)\ll \lambda_X X^{o(1)}.
\]

The sieve does not manufacture this input; it consumes it.

**Verdict:** classical sieve theory repackages the missing joint-distribution statement and gives no independent shortcut.

### 4.5 Fibonacci/Lucas-sequence analogies

The useful prime-factor theory for Fibonacci and Lucas numbers rests on structures absent here:

\[
\gcd(F_m,F_n)=F_{\gcd(m,n)},
\qquad
m\mid n\Longrightarrow F_m\mid F_n,
\]

cyclotomic decompositions of \(\alpha^n-eta^n\), ranks of apparition, and primitive divisors. Bilu–Hanrot–Voutier proved that every Lucas or Lehmer term with index \(n>30\) has a primitive divisor. Stewart's later theorem gives a lower bound of the shape

\[
P(u_n)>n\exp\!\left(\frac{\log n}{104\log\log n}\right)
\]

for the greatest prime factor of the relevant Lucas/Lehmer cyclotomic component.

These are powerful because prime divisors of a primitive component have orders tied to \(n\), often forcing congruences such as \(p\equiv\pm1\pmod n\). Apéry numbers have a polynomial-coefficient recurrence, not a constant-coefficient Binet formula; they are not a strong divisibility sequence and have no known cyclotomic factorization.

Moreover, primitive-divisor and greatest-prime-factor theorems are mostly **lower** bounds on the presence or size of prime factors. A factor of size \(n\exp(\log n/(104\log\log n))\) uses only \(O(\log n)\) logarithmic mass, negligible compared with

\[
\log b_n\asymp n.
\]

So even a perfect Apéry analogue of Stewart's theorem would not give a fixed linear saving in the top radical.

The “Luca (2001)” statement quoted in the question should be checked against a precise reference. I could not match the stated formulation to a standard theorem. It may be a conflation with the 2001 primitive-divisor theorem of Bilu–Hanrot–Voutier or with later work of Stewart. In any event, an upper bound merely of order \(O(n/\log n)\) is the scale already supplied for \(b_n\) by generic divisor theory and is still insufficient for the conjecture.

**Verdict:** the Fibonacci technology depends on strong divisibility and cyclotomic order constraints that do not presently exist for Apéry numbers.

### 4.6 The modular-form connection

The congruence

\[
b_{(p-1)/2}\equiv a_p(f)\pmod p
\]

controls the central zero. For a top-window hit \(r=n-p\), the central condition is

\[
n-p=\frac{p-1}{2},
\]

which forces

\[
p=\frac{2n+1}{3}.
\]

Thus, for each fixed \(n\), the modular-form congruence can govern at most one top-window candidate prime. It cannot bound the bulk. Extending the modular interpretation to arbitrary \(r\) leads to the moving-character Mellin problem already identified in the project, not to a fixed modular form whose coefficients can be sieved conventionally.

## 5. A rigorous obstruction: all known local zero-set constraints allow maximal alignment

It is useful to isolate exactly why the gap-polynomial and zero-count information cannot by themselves improve the coefficient \(1/2\).

Fix a large \(n\). For every prime \(p\in(n/2,n)\), put

\[
r_p=n-p
\]

and define an artificial reflection-symmetric set

\[
Y_p=\{r_p,\ p-1-r_p\}.
\]

Discard the \(O(1)\) primes for which a point is an endpoint, the two points coincide, or the two points are adjacent. Then the family \(Y_p\) has all of the following properties:

- \(Y_p\subset\{1,\ldots,p-2\}\);
- \(Y_p\) is invariant under \(r\mapsto p-1-r\);
- \(|Y_p|=2\), far stronger than the proved \(O(p^{2/3})\) bound;
- it has no consecutive elements;
- for every fixed gap \(h\ge2\), there is at most one start \(r\) with \(r,r+h\in Y_p\), hence it satisfies the numerical gap cap \(1\le3(h-1)\).

Nevertheless,

\[
r_p=n-p\in Y_p
\]

for every retained prime, so the diagonal hit count is

\[
\left(\frac12+o(1)\right)\frac n{\log n}.
\]

This is not a model for the actual Apéry zero sets; it is a logical obstruction theorem. It proves that no argument using only

```text
|Z_p| bounds,
reflection,
endpoint exclusion,
no adjacent zeros,
and the per-gap numerical root cap
```

can give even a fixed saving below the ambient coefficient \(1/2\). One needs an Apéry-specific relation that couples the **locations** of the selected roots as \(p\) varies.

Even a bounded average \(\sum_{p\le x}|Z_p|\ll\pi(x)\) does not repair this. Put \(Y_p\) on any positive-density subset of the primes and take \(Y_p=\varnothing\) on the rest. The average zero count stays \(O(1)\), while the chosen primes may still align on the diagonal and produce \(c\,n/\log n\) hits for a fixed \(c>0\). Marginal statistics do not control pointwise cross-prime alignment.

This abstract construction is the direct-factor analogue of the “star” obstructions recorded in the current campaign notes.

## 6. What is actually known specifically for Apéry numbers

The specific structure gives several deep facts:

1. **Lucas digit law.** It converts a top-window divisor into the moving zero event \(n-p\in Z_p\).
2. **Reflection and recurrence rigidity.** The zero set is reflected, has no adjacent zeros, and obeys gap-polynomial constraints.
3. **Unconditional local zero bound.** The project proves
   
   \[
   |Z_p|=O(p^{2/3}).
   \]
4. **Second-moment control.** The project has \((\mathrm{HM})_2\), yielding strong density-one conclusions.
5. **Very strong numerical sparsity.** `problems/3.2/bn_bigscan_report.md` records, through \(n=2{,}000{,}000\),
   
   \[
   \max K_{\mathrm{top}}(n)=3,
   \]
   
   with mean approximately \(0.0530\). Over primes through \(2{,}000{,}000\), the mean of \(|Z_p|\) is approximately \(1.0012\), and the observed zero-count distribution is close to the predicted Poisson model.

What is not known is a pointwise theorem preventing a single diagonal \(r=n-p\) from selecting roots for many different primes. The first four items are vertical, prime-by-prime information; the missing assertion is horizontal across primes.

The most directly relevant published factorization result remains Luca–Shparlinski's density-one lower bounds on \(\omega(b_n)\) and \(P(b_n)\). Delaygue's work proves strong \(p\)-adic valuation and \(p\)-Lucas properties for Apéry-like sequences, but it does not give a pointwise upper bound for the number of large prime divisors in this moving interval.

I do not know of a published theorem that improves

\[
K_{\mathrm{top}}(n)
\le\left(\frac12+o(1)\right)\frac n{\log n}
\]

for every \(n\). The computation suggests the truth is enormously stronger—probably \(K_{\mathrm{top}}(n)=n^{o(1)}\), and perhaps a very small polylogarithmic bound—but current arithmetic tools do not prove it.

## 7. What a successful “direct sieve” theorem would have to say

There are four honest target shapes.

### Target A: pointwise diagonal sparsity

For some \(\delta>0\), prove uniformly in \(n\asymp N\)

\[
\#\{p\in(n/2,n):n-p\in Z_p\}
\ll \frac{N}{(\log N)^{1+\delta}},
\]

or more strongly

\[
\max_{n\asymp N}K_{\mathrm{top}}(n)\le N^{o(1)}.
\]

This is the cleanest direct theorem and matches the project's atom-tail target.

### Target B: a sufficiently high factorial moment

Prove, for one fixed sufficiently large \(k\), the independence-scale estimate for

\[
\sum_m (K_X(m))_k.
\]

The manuscript records that a fixed \(k>6\), together with the proved \(Z_p\ll p^{2/3}\), is enough for the full conjecture. This is a sieve-compatible route, but its content is precisely the missing multi-prime correlation bound.

### Target C: actual sieve level of distribution

For squarefree products of distinct primes in the relevant dyadic block, establish joint counts with a summable total error:

```text
# simultaneous Apéry-zero congruences
= expected product density + error,

sum of errors over the needed moduli = o(main scale).
```

Such a theorem would allow Rosser–Iwaniec or Selberg machinery to operate. But proving it is the breakthrough; applying the sieve afterward would be routine.

### Target D: a global factorization theorem

Any one of

\[
\log\operatorname{rad}_{(n/2,n]}(b_n)=o(n),
\]

\[
\tau(b_n)=\exp(o(n/\log n)),
\]

or a factorization \(b_n=C_nD_n\) with

\[
\log C_n=(\lambda-o(1))n
\]

and \(C_n\) free of top-window primes would solve the problem. These are valid direct arithmetic targets, but no existing hypergeometric or modular-form theorem supplies them.

Of these, Target A or B is the most realistic within the current project because it uses the actual finite-field zero geometry already developed rather than asking for a new integer factorization theory of \(b_n\).

## 8. Final assessment of the proposed approaches

| Proposed idea | What it really gives | Pointwise \(o(n/\log n)\)? |
|---|---|---:|
| Height of \(b_n\) | \((\lambda+o(1))n/\log n\) | No |
| Number of available primes | \((1/2+o(1))n/\log n\) | No, but already proves the requested fixed saving |
| Supercongruence \(b_{mp^s}\) | Valuation control when \(p\mid n\) | No; generic top hits have \(p\nmid n\) |
| Generic divisor bound | Recovers the height scale | No |
| Apéry-specific divisor theorem | Would work if extremely strong | No such theorem known |
| Erdős–Kac heuristic | Predicts a tiny Poisson mean in the top window | Heuristic/density-one, not all-\(n\) |
| Rosser–Iwaniec sieve | Requires multi-prime distribution as input | Not independently |
| Fibonacci/Lucas analogy | Uses strong divisibility and cyclotomic factors | Structure absent for \(b_n\) |
| Modular form \(a_p(f)\) | Controls the unique central candidate | At most one prime per \(n\) |
| Gap polynomial and \(Z_p\) bounds | Strong prime-by-prime rigidity | No cross-prime anti-alignment |

The clean conclusion is therefore:

\[
\boxed{
\begin{minipage}{0.88\textwidth}
The proposed fixed saving below \(3.52\) is already trivial—indeed the coefficient is at most \(1/2+o(1)\) by prime counting. But this does not advance the conjecture. No currently known direct factorization or classical-sieve theorem gives the required zero density among the top-window primes. The specific Apéry structure converts the problem into the moving diagonal \(n-p\in Z_p\); proving that this diagonal cannot align for many primes is exactly the missing cross-prime theorem.
\end{minipage}
}
\]

So the most productive formulation is not “improve \(3.52\) by a fixed \(arepsilon\),” but rather:

```text
POINTWISE APÉRY DIAGONAL SIEVE

Prove uniformly for n -> infinity that

  #{p in (n/2,n) : n-p in Z_p} = o(n/log n),

preferably N^{o(1)} on each dyadic shell.
```

That theorem would be genuinely new, would use the right arithmetic object, and would close the top-window problem. The five proposed generic routes do not presently bypass it.
