# Hostile audit: can the exceptional-set theorem lower the physical I5 moment order?

## Conclusion

No. The current exceptional-set theorem does not imply that the selector-preserving physical fifth falling-factorial tail can be replaced by a third- or fourth-order tail. The theorem controls the number of bad indices in the all-index parameter n, while PI5 controls a shell-by-shell physical selector correlation indexed by characteristic columns. The two quantifiers do not match.

The exceptional theorem is therefore an auxiliary sparsity statement, not a moment-reduction theorem.

## Quantifier mismatch

The banked exceptional estimate is

```
#{ n <= N : log G_n > epsilon n } = O_epsilon(log^2 N).
```

This says that among indices n, only logarithmically many have large canonical gcd load.

The physical I5 argument instead fixes a dyadic prime shell

```
X < p <= 2X
```

and sums over physical columns m carrying characteristic events. The load parameter is a function of shell geometry, selector thresholds, and folded indices. A shell column m can contribute through many possible n-values, and a single n-value can correspond to many physical columns.

There is no proved injection

```
physical bad column -> exceptional index n
```

with bounded multiplicity. Without such a map, the O(log^2 N) exceptional count cannot replace a fifth moment estimate.

## Why sparse exceptional indices do not lower moments

Suppose one tries to sum only exceptional columns. A typical reduction would need an estimate of the form

```
number of selected physical columns <= O(log^2 X)
```

or at least a bound strong enough to offset the missing moment. The exceptional theorem only gives a count after projecting to n. The projection may collapse many shell columns onto the same exceptional n.

Thus Markov-style conversion is unavailable.

## Moment comparison

The physical fifth tail controls a selector-preserving quantity of the form

```
Σ_m (load(m))_5
```

where the falling factorial preserves distinct characteristic choices.

An order-four replacement would require proving

```
Σ_m (load(m))_4
```

controls the same isolated five-star contribution.

But the missing fifth incidence is exactly the configuration where four lower-order choices coexist while a fifth characteristic is unconstrained. The exceptional theorem does not forbid this configuration.

## Lambda and shell scaling

The physical theorem uses

```
H = X^(7/15)(log X)^(-1/3)
```

and the near-collision estimate

```
K_X^near(m;H)=O(H^2).
```

This gives geometric isolation of most surviving roots. It does not give a bound on the number of five-way CRT-compatible isolated configurations. The remaining isolated tail is arithmetic, not merely geometric.

Reducing PI5 to PI4 would need a new implication of the form:

```
isolated five-star configuration
    => exceptional high-load index
```

with controlled multiplicity.

No such implication follows from the current exceptional-set theorem.

## Precise obstruction

A canonical-compatible obstruction is the following logical model. Assume the Apéry sequence has a set E of O(log^2 X) exceptional indices. It is consistent with the exceptional theorem that every n in E supports X^c/log^d X physical selectors, provided all these selectors collapse to the same exceptional index. The theorem still holds, but the shell fifth moment remains large.

This is not a claim about the actual Apéry sequence; it shows the exceptional theorem alone lacks the incidence information required for moment reduction.

## Comparison with PI5

PI5 closes every index because it is selector-preserving and directly counts the five-characteristic CRT tail. The exceptional theorem removes only indices with large global load. It does not replace the local five-characteristic correlation estimate.

## Weakest missing lemma that would make reduction possible

A valid reduction would require a new incidence theorem:

> For every dyadic shell X and selector threshold L, the number of physical isolated k-stars (k=5) whose carrier index is exceptional is bounded by the corresponding fourth-order selector tail with a saving sufficient to recover the PI5 scale.

Equivalently, one needs a shell-to-index multiplicity bound together with an exceptional-index structural theorem.

Until this lemma is proved, the first unsupported inequality is the replacement

```
physical PI5 tail <= exceptional-set contribution controlled by PI4 or PI3.
```

The exceptional-set theorem is therefore not a lower-moment substitute.
