# Q500: Can palindromic symmetry plus small zero sets close (HM)_3?

## Executive verdict

No. The proposed CRT argument contains a quantifier reversal. Palindromic symmetry gives a pairing

\[
r\leftrightarrow p-1-r,
\]

but it does **not** imply that every CRT representative is large. It only implies that the set of CRT values is symmetric under

\[
m\leftrightarrow M-1-m,
\qquad M=p_1p_2p_3.
\]

A symmetric set can contain many values near \(0\) and their reflected values near \(M-1\). The midpoint argument only shows that each pair contributes at least one large element; it says nothing about the small partner. Therefore the small-zero cases do not make (HM)_3 trivial.

The remaining difficulty is exactly the lower-tail problem:

\[
\#\{(r_1,r_2,r_3)\in Z_{p_1}\times Z_{p_2}\times Z_{p_3}:\operatorname{CRT}(r_1,r_2,r_3)\le X^2\}.
\]

Palindromy reduces the number of cases by a factor of two, but it does not remove this count.

---

## (A) The midpoint CRT formula

Let

\[
a_i=(p_i-1)/2.
\]

Because every modulus \(p_i\) is odd,

\[
2a_i\equiv -1\pmod {p_i}.
\]

The CRT solution \(m\) therefore satisfies

\[
2m\equiv -1\pmod {p_1p_2p_3}.
\]

Since \(M=p_1p_2p_3\) is odd, the unique representative in \([0,M)\) is

\[
\boxed{m=(M-1)/2.}
\]

So the midpoint triple is completely explicit.

---

## (B) Midpoint triples are harmless

Yes. Since

\[
M\asymp X^3,
\]

we have

\[
\frac{M-1}{2}\asymp X^3/2.
\]

For the HM_3 counting range \(m\le X^2\), this contribution is absent for sufficiently large \(X\).

Thus triples where all three primes contribute only the midpoint zero are harmless.

---

## (C) The |Z_p|=2 case

Suppose

\[
Z_{p_i}=\{r_i,p_i-1-r_i\}.
\]

There are eight CRT values. If \(m\) is one of them, then replacing every residue by its reflection gives

\[
M-1-m.
\]

Hence the eight values form four reflected pairs.

The observation

\[
\max(m,M-1-m)\ge (M-1)/2
\]

is true, but it proves only that **one** member of each pair is large.

The other member may be tiny. For example, a CRT solution can be a small positive integer \(m\ll X^2\); its reflected partner is then \(M-1-m\gg X^3\).

Therefore the desired conclusion

\[
\text{all eight values}>X^2
\]

is false in general.

---

## (D) The proposed contradiction is reversed

The condition for a CRT value to be bad in HM_3 is only

\[
m\le X^2.
\]

It does **not** require simultaneously

\[
M-1-m\le X^2.
\]

That second inequality describes the reflected partner also being bad. But HM_3 counts each CRT tuple separately. A small value and a huge reflected value are not the same event.

Thus the implication

\[
m\le X^2\Rightarrow M-1-m\le X^2
\]

is invalid.

The correct statement is:

- palindromy pairs bad small CRT values with good large values;
- it does not eliminate the bad values.

---

## (E) The |Z_p|=3 case

For an odd cardinality palindromic set, the midpoint must occur. Hence a size-three set has shape

\[
Z_p=\{r,(p-1)/2,p-1-r\}.
\]

The 27 CRT choices split into reflected pairs plus the all-midpoint choice.

The all-midpoint choice gives exactly

\[
(M-1)/2,
\]

which is harmless.

But the other 26 choices can contain small CRT representatives. The reflection pairing argument has the same limitation as the size-two case.

---

## What small |Z_p| actually gives

If

\[
|Z_p|\le C
\]

uniformly, then the number of CRT candidates for a prime triple is bounded by \(C^3\). This is valuable, but HM_3 requires a bound on where those \(C^3\) CRT points land.

The missing statement is not cardinality control; it is distribution control:

\[
\boxed{
\sum_{p_1,p_2,p_3}
\#\{(r_1,r_2,r_3):
\operatorname{CRT}(r_1,r_2,r_3)\le X^2\}
=o(X^2/\log^3X).
}
\]

This is precisely a three-prime CRT equidistribution problem.

---

## Why the palindromic gain is still useful

Palindromy is not useless. It gives:

1. midpoint triples that can be removed exactly;
2. reflected pairing of CRT configurations;
3. a factor-of-two reduction in the number of independent lower-tail events;
4. stronger Fourier cancellation because zero sets have conjugate phases.

But it does not replace HM_3. The remaining issue is the same one identified elsewhere in P3.2: cross-prime decorrelation of the moving zero sets.

## Final answer

- (A) Midpoint CRT is exactly \((M-1)/2\).
- (B) Midpoint-only triples are automatically harmless.
- (C) Size-two palindromic sets do not force all CRT values above \(X^2\).
- (D) The contradiction argument fails because HM_3 counts small values and does not require their reflected partners to be small.
- (E) Size-three sets have the same issue; only the all-midpoint element disappears.

Therefore:

\[
\boxed{
\text{Palindromy + }|Z_p|=O(1)\text{ does not make }(HM)_3\text{ trivial.}
}
\]

It reduces the problem, but the essential three-prime CRT dispersion estimate remains open.
