# 9. First failed implication beyond the proved sector

After the repairs above, the geometry itself is no longer the obstruction.

A tempting next line would be:

> on one actual rational ray, every gap \(g\) has a fixed carrier \(\mathcal R_g^{\rm cen}(C,e)\); the \(N_g\)'s are pairwise coprime; therefore the moving primes over all gaps have a power-saving total count.

That implication is false from the current bank.

For \(g\ne g'\), pairwise coprimality prevents the **same characteristic-zero root** from making both carriers vanish, so at most one gap on a ray has zero carrier.  But for the nonzero carriers the selected moving prime may vary with \(g\):
\[
 s_g\mid\mathcal R_g^{\rm cen}(C,e),
\qquad
 s_{g'}\mid\mathcal R_{g'}^{\rm cen}(C,e),
\qquad
s_g\ne s_{g'}.
\]
The logarithmic height
\[
\log|\mathcal R_g^{\rm cen}(C,e)|\ll g\log N
\]
allows a private shell divisor for every one of \(N^{3/5}\) distinct large gaps.  Pairwise resultants or gcds do not charge such private divisors.  The fixed-gap quotient lemma (6.4) actually shows that a surviving large major ray is naturally a matching: essentially one moving characteristic per gap.  All current collision moments are blind to this singleton configuration.

Therefore the repaired residual is exactly
\[
\boxed{
\begin{gathered}
 q\nmid h,
 \qquad G>N^{3/5-2\sigma},\\
 \exists\text{ two actual graph points with }
 0<|v_1-v_2|\le N^{2\sigma},\\
 \mathscr G^{\rm fr}_\Theta
 \text{ is covered by }O(1)\text{ actual rays }ey-fs=C,\\
 \text{and each fixed gap contributes only }N^{o(1)}
 \text{ occurrences.}
\end{gathered}}
\tag{9.1}
\]
No current RR26--RR44 theorem gives a fixed power against a set of distinct large gaps on one such ray.

The smallest useful new arithmetic input is consequently the following genuinely narrower statement, not a generic graph bound:
\[
\boxed{
\begin{minipage}{0.88\linewidth}
For every fixed literal nonresonant RR outer datum and every actual
short-secant ray \(ey-fs=C\), the number of moving shell primes \(s\)
for which the forced centered pair \(y,y+g\), with
\(G<g\le2G\), is an actual primitive Ap\'ery first-return pair is
\(\ll N^{3/5-\delta+o(1)}\) for some fixed \(\delta>0\), uniformly in
the surviving large-gap range.
\end{minipage}}
\tag{AGR_\delta}
\]
Equivalently, in the literal weighted form,
\[
 \sum_{(s,y,g)\in\mathscr R_{\Theta,C}(G)}|u_s|
 \ll N^{-2/5-\delta+o(1)}.
\tag{9.2}
\]
Since the major branch has only \(N^{o(1)}\) rays, (AGR\(_\delta\)) would give
\[
\mathfrak E^{\rm ff}_{\rm major}
\ll N^{11/5-\delta+o(1)},
\]
and hence the required target for every \(0<\sigma<\delta/2\).
