# Q851 audit: common-m obstruction in the GH1 ambient construction

## Verdict

The proposed ambient construction is **INVALID** under the stated quantifiers. The obstruction is not a lack of clever prime selection; it is the common-index affine constraint

```
m = c_i p_i + s_i
```

which couples all labels through the same integer m. The previous construction treated the pairs `(p_i,c_i)` as independent. They are not.

A deterministic saving follows from the affine packing constraint. No infinitely-often counterexample satisfying all the required separation conditions is currently obtained.

## 1. Correct interpretation of GH1

The first correction is essential:

* `V_g` counts incident labels, not unordered pairs.
* `R_X = log X` is the distance threshold for the a-coordinate and is distinct from the larger Kummer/order separation threshold `G_X`.

Therefore a claimed contribution

```
sum_g (V_g-a)_+ >> k^2
```

requires actual high multiplicity buckets of labels after all pruning, not merely many close pairs.

## 2. The common m constraint

Suppose

```
X < p_i < 2X,
Y_X <= m < X^2,

m = c_i p_i + s_i.
```

Then

```
c_i = (m-s_i)/p_i.
```

Thus once the lifts `s_i` and common m are chosen, the quotients are forced. They cannot be independently prescribed.

For two labels i,j,

```
c_i p_i - c_j p_j = s_j-s_i.
```

Hence any attempt to place many labels in one signed-lift progression requires simultaneous divisibility constraints

```
p_i | (m-s_i).
```

This is the missing condition in the Q850-style construction.

## 3. AP lifts do not rescue the construction

Take an arithmetic progression of lifts

```
s_i = s_0+i d.
```

Then the required primes satisfy

```
p_i | (m-s_0-i d).
```

For fixed m and d this is a sequence of shifted divisors of one interval of length O(X^2). It is not a freely chosen prime family.

The number of admissible labels is controlled by the divisor structure of the shifted values. A long run with large bucket multiplicity would require many values

```
m-s_0-id
```

to contain distinct primes in `(X,2X]`, while also maintaining the separation constraints on `a_p` and `h_p`.

No unconditional argument supplies such a family, and it is incompatible with treating the c_i as free variables.

## 4. Distance-edge separation and pruning

The conditions

```
|a_p-a_q| > R_X,
|h_p-h_q| > G_X
```

make the situation harder. They force any surviving high-Kummer bucket to arise from genuinely different affine data, not repeated representations of the same m.

After deterministic pruning, each surviving bucket must pay either:

1. affine divisor scarcity from the common m equation; or
2. spacing loss from the a/h separation.

The earlier proposed `k^2` excess cannot be obtained without violating one of these two costs.

## 5. No valid infinite construction

A valid construction would need all of the following simultaneously:

```
k >= L,
X < p_i < 2X,
common m < X^2,
large bucket excess,
|a_p-a_q| > log X,
|h_p-h_q| > G_X,
high Kummer order after pruning.
```

The only available degrees of freedom are the actual common m and admissible lifts. They do not provide enough independent choices to force k arbitrary labels.

Therefore the requested ambient adversarial configuration is not established.

## 6. Deterministic saving that replaces it

The correct replacement lemma is:

> **Affine common-index packing lemma (weaker GH1 consequence).** Fix X. For any common m and any admissible lift family S, the number of labels p in `(X,2X]` satisfying `p | (m-s)` with s in S and surviving the separation pruning is bounded by the available large-prime divisors of the shifted set `{m-s : s in S}`.

Consequently any large GH1 bucket forces concentration in shifted divisors, and this concentration is exactly the configuration excluded by the existing divisor/codegree estimates.

This is weaker than a full construction obstruction theorem but is the deterministic saving available without invoking unproved prime-AP statements.

## Conclusion

The Q850 construction claim fails because it dropped the first-order dependency: one common m determines all quotients c_i. There is no valid proof of an infinite ambient configuration with k>=L satisfying every inequality. The repaired conclusion is a deterministic packing obstruction, not a new adversarial model.
