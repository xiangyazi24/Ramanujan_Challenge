# Q7211 (rc3): Spectral/expansion routes for the Apéry projective cocycle

## Summary

The standard expansion, trace-function, and algebraic-dynamics theorems do **not** directly control the far-bridge correlations needed in Problem 3.2. The obstruction is structural: the Apéry evolution is a deterministic nonstationary cocycle over the additive cycle, not a random walk in a fixed subgroup of \(SL_2(\mathbf F_p)\).

The closest genuinely new statement would be a spectral estimate for the skew-product transfer operator of the augmented cocycle
\[
F(n,q)=(n+1,A(n)q).
\]

Such a theorem would be an Apéry-specific analogue of expansion/mixing for polynomial cocycles.

---

## 1. The augmented dynamical system

The recurrence gives
\[
\pi_{n+1}=A(n)\pi_n,
\]
where
\[
A(n)=\begin{pmatrix}P(n)&-n^3\\(n+1)^3&0\end{pmatrix}.
\]

Augmenting the base point gives
\[
F:\mathbf A^1(\mathbf F_p)\times \mathbf P^1(\mathbf F_p)\to
\mathbf A^1(\mathbf F_p)\times \mathbf P^1(\mathbf F_p),
\]
\[
F(n,q)=(n+1,A(n)q).
\]

The base coordinate is the full deterministic cycle
\[
n\mapsto n+1\pmod p.
\]
The fiber map changes at every step.

A long return is not
\[
g^Lq=q
\]
for a fixed matrix \(g\), but
\[
A(n+L-1)\cdots A(n)q=q.
\]

This distinction is the main obstruction.

---

# 2. Why SL2 expansion theorems do not apply

## Bourgain-Gamburd type expansion

The expansion theorem for Cayley graphs of \(SL_2(\mathbf F_p)\) (Bourgain--Gamburd, *Uniform expansion bounds for Cayley graphs of \(SL_2(\mathbf F_p)\)*, Annals of Mathematics 2008) assumes a fixed finite generating set
\[
S\subset SL_2(\mathbf F_p)
\]
whose random walk operator
\[
Tf(x)=\frac1{|S|}\sum_{s\in S}f(sx)
\]
has a spectral gap.

The Apéry system has instead
\[
T_L(n)=A(n+L-1)\cdots A(n).
\]
There is no fixed probability measure on a fixed group.

Failure points:

1. **Nonstationarity**: the matrix distribution changes with the time coordinate.
2. **Determinism**: the sequence visits each \(n\) exactly once; there is no averaging over generators.
3. **Moving target**: the return condition is to the original projective line, but after adjoining the base coordinate the target is a section of the skew product.
4. **Singular fibers**: \(A(n)\) is not always invertible. Indeed
\[
\det A(n)=(n+1)^3n^3,
\]
so \(n=0,-1\) are singular.

Therefore SL2 expansion cannot be invoked.

---

# 3. Polynomial matrix cocycle results

The relevant general theory is closer to:

* Furstenberg theory of random matrix products;
* Katz's theory of trace functions over finite fields;
* Deligne bounds for complete exponential sums.

None directly matches this cocycle.

## Katz/Deligne trace-function approach

A trace-function estimate typically controls sums
\[
\sum_x \chi(f(x))
\]
or correlations of algebraic sheaves.

The Apéry return indicator is instead
\[
1_{N_L(x)=0},
\]
where
\(N_L\) has degree growing with \(L\).
For the far bridge, \(L\) can be of size \(p\).

The associated sheaf would therefore have conductor depending on \(L\), losing the uniformity needed for
\[
L\sim p.
\]

No existing Deligne/Katz theorem gives the required bound uniformly in this moving-degree family.

---

# 4. Algebraic dynamics/mixing obstruction

The map
\[
F(n,q)=(n+1,A(n)q)
\]
is an algebraic correspondence on
\[
\mathbf A^1\times\mathbf P^1.
\]

However, it is not a fixed endomorphism iterated many times. Instead,
\[
F^L(n,q)=
(n+L,A(n+L-1)\cdots A(n)q).
\]

Because the base coordinate changes the fiber map at every iteration, standard results on:

* mixing of algebraic maps over finite fields;
* equidistribution of polynomial orbits;
* expander maps;

do not apply without a new theorem for skew products with additive base dynamics.

---

# 5. Exact missing spectral statement

The closest useful theorem would be:

## Apéry cocycle spectral gap conjecture

Let
\[
\mathcal H=L^2(\mathbf F_p\times\mathbf P^1(\mathbf F_p)).
\]
Define the normalized skew transfer operator
\[
(Uf)(n,q)=f(n+1,A(n)q).
\]

Let \(\mathcal H_0\) be the subspace orthogonal to functions constant on the full orbit.

A sufficient theorem would be

\[
\|U^L f\|_2\le p^{-\delta}\|f\|_2
\]
for
\[
1\le L\le p
\]
and some absolute \(\delta>0\), after removing the invariant components forced by the deterministic cycle.

A weaker statement exactly matching Problem 3.2 is:

For every short-return test function \(\varphi_H\) supported on carrier-clean four-return chains,
\[
\left|
\langle \varphi_H,U^L\varphi_H\rangle
-\mathrm{main\ term}
\right|
\ll p^{1-\eta+o(1)}.
\]

This is the nonconcentration theorem required for the far bridge.

# 6. Relation to the far-bridge energy

The far separated pair condition is
\[
N_s(x)=0,
\qquad
N_L(x+s)=0,
\]
with
\[
L\gg H.
\]

The first condition selects a short-return section. The second asks that the cocycle returns to the selected projective state after a long deterministic evolution.

The desired estimate
\[
\sum_{X<p\le2X}E_p^{sep}
\ll X^{2+o(1)}/\log X
\]
would follow from a bound of the form
\[
\sum_{x\in\mathbf F_p}
1_{N_s(x)=0}
1_{N_L(x+s)=0}
\ll p^{1+o(1)}
\]
uniformly for
\[
s\le \sqrt p,\qquad L\le p.
\]

No standard expansion theorem supplies this.

---

# 7. Final conclusion

Existing theorems fail for precise reasons:

| Method | Missing hypothesis |
|---|---|
| SL2(Fp) expansion | no fixed generating set/random walk |
| Bourgain-Gamburd | nonstationary deterministic matrices |
| Furstenberg theory | needs randomness |
| Deligne/Katz trace bounds | conductor grows with bridge length |
| algebraic mixing | not a fixed self-map iteration |

The far-bridge problem is therefore a genuinely new finite-field cocycle problem. The weakest new result needed is not full mixing, but a **short-return-to-long-return decorrelation estimate** for the Apéry skew product. Proving that statement would directly close the remaining separated-chain energy bound.
