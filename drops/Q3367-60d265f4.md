# 1. The balanced fiber of one primitive selector vector

The `2x2` minors of `C_x` are exactly the differences `x_j-x_i`, so the determinantal divisors of `C_x` are

```text
Im_Z(C_x)
 = Z(1,x_0)+Z(0,d_x)
```

This is the same affine-lattice description used in Q3361.

# 3. Smith formula for `kappa_x(y)`

Form the augmented `3xr` matrix

```text
A_x(y)
 = [ 1   1   ... 1
     x_0 x_1 ... x_{r-1}
     y_0 y_1 ... y_{r-1} ].                         (3.1)
```

Let

```text
D3(x,y)
 := gcd_{i<j<k}
      det [ 1   1   1
            x_i x_j x_k
            y_i y_j y_k ],                          (3.2)
```

with `D3=0` if all such minors vanish.

## Lemma 3.1

```text
boxed: kappa_x(y)=D3(x,y)/d_x.                      (3.3)
```

### Proof

Take Smith form of `C_x`.  There are unimodular matrices `P in GL_2(Z)` and `Q in GL_r(Z)` with

```text
P C_x Q = [ 1 0 0 ... 0
            0 d_x 0 ... 0 ].                        (3.4)
```

Write

```text
y Q = (c_1,c_2,w_3,...,w_r).                        (3.5)
```

In these coordinates the integral kernel of `C_x` consists exactly of vectors whose first two coordinates vanish.  Hence

```text
kappa_x(y)=gcd(w_3,...,w_r).                         (3.6)
```

After the same unimodular row/column operations, the nonzero `3x3` minors of the augmented matrix have gcd

```text
d_x * gcd(w_3,...,w_r).                             (3.7)
```

Determinantal divisors are invariant under unimodular operations.  Equations `(3.6)-(3.7)` prove `(3.3)`.

`QED`

There is also a concrete three-support version.  For every triple `i,j,k`, define

```text
z_x^{ijk}(i) = (x_j-x_k)/d_x,
z_x^{ijk}(j) = (x_k-x_i)/d_x,
z_x^{ijk}(k) = (x_i-x_j)/d_x,                       (3.8)
```

Thus the ideal generated by these three-support value increments is exactly `kappa_x(y) Z`.

The ideal generated by an affine coset `h_0+gZ` is `gcd(h_0,g)Z`.  Hence:

```text
     h_0,
```

# 5. Cross-minor HNF and the exact divisor `Delta`

Define the two row lattices in `Z^2`

```text
L_e := sum_i Z(e_i,U_i),
L_f := sum_j Z(f_j,V_j).                             (5.1)
```

Because `e` and `f` are primitive,

```text
gcd_i e_i=1,
gcd_j f_j=1,                                        (5.2)
```

the first-coordinate projection of each lattice is all of `Z`.  Hence each has a row-Hermite form

```text
L_e = Z(1,b_e)+Z(0,D_e),
L_f = Z(1,b_f)+Z(0,D_f),                            (5.3)
```

where

```text
D_e = gcd_{i<i'} |e_i U_{i'}-e_{i'}U_i|,
D_f = gcd_{j<j'} |f_j V_{j'}-f_{j'}V_j|,            (5.4)
```

with `D_s=0` in the rank-one case.

The ideal generated by determinants of one vector from `L_e` and one from `L_f` is generated, on the HNF bases, by

```text
b_f-b_e,
D_e,
D_f.                                                 (5.5)
```

But bilinearity of determinant shows that this is exactly the ideal generated by the original cross minors

```text
M_ij=e_iV_j-f_jU_i.                                 (5.6)
```

Therefore

```text
boxed:
Delta
 = gcd_{i,j}(e_iV_j-f_jU_i)
 = gcd(D_e,D_f,b_f-b_e).                            (5.7)
```

This is the cross-lattice HNF formula.

# 6. Why `Delta | Gamma`

The divisibility is exact and uses only primitivity.

Take any admissible `A,B`, so

```text
f·A=e·B=:t.                                         (6.1)
```

Choose Bezout vectors

```text
u in Z^{|e|},   e·u=1,
v in Z^{|f|},   f·v=1.                              (6.2)
```

Define the integer matrix

```text
Q := u A^T + (B-t u) v^T.                           (6.3)
```

Then

```text
Q^T e=A,                                             (6.4)
```

because `(B-tu)·e=t-t=0`, and

```text
Q f=B.                                               (6.5)
```

Consequently

```text
sum_{i,j} q_ij(e_iV_j-f_jU_i)
 = A·V-B·U
 = H(A,B).                                           (6.6)
```

So every admissible `H` lies in `Delta Z`.  Taking the gcd of all admissible values gives

```text
boxed: Delta | Gamma.                               (6.7)
```

If `Delta=0`, all cross minors vanish and `(6.6)` gives `H=0` for every compatible source, hence `Gamma=0` as well.  The quotient question is therefore relevant only for `Delta>0`.

# 7. Exact nonzero-link counterexample

Now fix **any** primitive selector vectors `e,f` satisfying the hypotheses of Q3367, in particular

```text
d_e|2,
d_f|2.                                             (7.1)
```

They may be the actual consecutive normalized q=6 negative-binomial selector vectors.  Section 1 shows the balanced fibers are nonempty.

Let `p` be any odd prime and put

```text
alpha:=p-1.                                         (7.2)
```

Thus `alpha` is even.  Define arbitrary integer value vectors by

```text
U_i:=0,
V_j:=alpha f_j+1.                                   (7.3)
```

## 7.1 Every balanced nonzero-link source has the same value

For every admissible `A,B`,

```text
sum A=sum B=2,
f·A=e·B=2.                                          (7.4)
```

Hence

```text
A·V
 = alpha(f·A)+sum A
 = 2alpha+2
 = 2p,                                               (7.5)
```

while

```text
B·U=0.                                               (7.6)
```

Therefore

```text
boxed:
H(A,B)=2p
for every admissible (A,B).                         (7.7)
```

The generated ideal is thus

```text
boxed: Gamma=2p.                                    (7.8)
```

This uses the required **nonzero** common selector moment `2` essentially; it is not a link-zero construction.

## 7.2 The cross-minor gcd is `1`

Because `U=0`,

```text
M_ij=e_i(alpha f_j+1).                              (7.9)
```

Since `e` is primitive,

```text
gcd_i e_i=1,
```

and therefore

```text
Delta
 = gcd_j(alpha f_j+1).                              (7.10)
```

Let `g` divide every `alpha f_j+1`.  Then

```text
gcd(g,alpha)=1,                                     (7.11)
```

because `g | alpha f_j+1`.  Also

```text
g | alpha(f_j-f_k)
```

for every `j,k`; by `(7.11)`,

```text
g | f_j-f_k
```

for every `j,k`.  Hence

```text
g | d_f | 2.                                        (7.12)
```

But `alpha` is even, so every `alpha f_j+1` is odd.  Thus `g` is odd.  Combining this with `(7.12)` gives

```text
g=1.                                                (7.13)
```

Therefore

```text
boxed: Delta=1.                                     (7.14)
```

Combining `(7.8)` and `(7.14)`,

```text
boxed:
Gamma/Delta=2p.                                     (7.15)
```

As `p` ranges over odd primes this contains arbitrarily large odd factors.  In particular there is no absolute `C` with

```text
Gamma/Delta | 2^C.                                  (7.16)
```

There is not even a bound of the form `Gamma/Delta <= 2^C`.

This counterexample works verbatim for the actual q=6 selector vectors, whatever their individual large entries are.  The only selector facts used are

```text
primitive e,
d_f|2,
```

plus nonemptiness of the balanced fibers, which follows from `d_e,d_f|2`.

# 9. Why the nonzero translation does not cure saturation

The tempting intuition is that fixing

```text
sum A=sum B=2,
f·A=e·B=2
```

should rigidify the affine fiber enough to force its value ideal to be close to the full cross-minor ideal.  Formula `(4.6)` shows exactly why this is false.

The balanced constraints determine, for each slope, only one residue class

```text
tau_x(y) mod kappa_x(y).                            (9.1)
```

They do not relate that residue to the primitive two-dimensional row-lattice invariant which controls the unrestricted cross-minor gcd `Delta`.

In the counterexample

```text
V=alpha f+1,
```

the value functional is literally constant on the balanced fiber:

```text
A·V=alpha(f·A)+sum A=2(alpha+1).                    (9.2)
```

Thus

```text
kappa_f(V)=0.                                       (9.3)
```

Likewise `U=0` gives

```text
kappa_e(U)=0.                                       (9.4)
```

Formula `(4.6)` therefore collapses to

```text
Gamma=|h_0|=2p,                                     (9.5)
```

while the unrestricted cross minors still have gcd `1`.  The affine translation has frozen the source value instead of saturating it.

This is fundamentally different from the old link-zero adjacent-family obstruction.

# 10. What remains possible for the actual Apéry value vectors

The counterexample disproves the universal statement requested in Q3367 because the question allows arbitrary integer `U,V`.

It does **not** prove that the special Apéry values

```text
U_i=T4_i,
V_j=T7_j
```

have unbounded `Gamma/Delta`.  A theorem for those specific values could still be true.

But such a theorem cannot follow from only

```text
primitive e,f,
consecutive negative-binomial selector recurrence,
d_e,d_f|2,
source-image saturation / HNF.
```

Section 7 satisfies all of those selector hypotheses and still gives arbitrary odd saturation.

Therefore any positive q=6 theorem for the genuine Apéry `T4,T7` must use additional arithmetic of the value vectors themselves—for example an Apéry recurrence identity, reflection, a divided first-order relation, or a genuine Green/Cartier input.  It cannot be a pure small-source lattice theorem.

In particular, the source-construction result of Q3361 remains valid: it gives polynomial-height sources with core-unit DC.  What fails here is the stronger claim that **all** balanced nonzero-link sources automatically generate an ideal within bounded `2`-power index of the full cross-minor ideal.
