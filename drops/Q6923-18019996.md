# 3. Complete rational adjoint solution space

Let

```text
h(z) = c0 + c1/z + c2/z^2.
```

Exact substitution gives the striking collapse

```text
D* h
 = z (-124200 c0 + 13500 c1 - 2557800 c2)
 = 900 z (-138 c0 + 15 c1 - 2842 c2).       (3.1)
```

Therefore

```text
ker(D*) intersect Qbar(z)
 = { c0+c1/z+c2/z^2 : 15c1-138c0-2842c2=0 }.
```

A convenient basis is

```text
h1(z) = 5 + 46/z,
h2(z) = 2842/z + 15/z^2.                    (3.2)
```

This is the **complete** rational solution space, not merely a degree-bounded
search:

- at `z=1` and at the two roots of `z^2-34z+1`, all adjoint exponents are
  nonnegative integers, so a rational solution cannot have poles there;
- at `z=0`, its pole order is at most two;
- hence it is a Laurent polynomial with lowest power at least `-2`;
- the integral exponents at infinity are `0,-1,-3`; the `-3` case is
  incompatible with lowest power `-2` unless the function is zero;
- consequently the general rational candidate is exactly
  `c0+c1/z+c2/z^2`, and (3.1) finishes the classification.

## No additional algebraic adjoint solution

For an algebraic solution, every Frobenius exponent must be rational. The two
sextics in Section 2 have no rational roots. At every finite singularity except
zero the remaining exponents are integers. Hence any non-rational algebraic
branch can ramify only at `0` and `infinity`, and its ramification is at most
quadratic. It therefore lies in `sqrt(z) Qbar(z)`.

The half-integral exponent constraints at zero and infinity leave only one
possible nonzero candidate up to scale:

```text
z^(-1/2).
```

It fails exactly:

```text
D*(z^(-1/2)) = -25650 z^(1/2) != 0.          (3.3)
```

Thus the algebraic solution space of the formal adjoint is precisely the
rational two-dimensional space (3.2).

This rules out an exact residue kernel built from a rational function,
an algebraic Brafman weight, or a rational/algebraic gauge of one elementary
hypergeometric term.

# 4. Exact second-order factor stripped from the adjoint

The Wronskian of the two rational solutions is

```text
W(h1,h2)
 = h1 h2' - h1' h2
 = -10 (69+15z+1421z^2) / z^4.               (4.1)
```

Put

```text
g(z) = 69 + 15z + 1421z^2,

A(z) = (276+45z+2842z^2)/(z g(z)),
B(z) = 138/(z^2 g(z)),

R2 = d^2/dz^2 + A(z) d/dz + B(z).            (4.2)
```

Then

```text
R2 h1 = R2 h2 = 0.
```

Noncommutative right division in `Q(z)<d/dz>` gives the exact factorization

```text
D* = Q11 o R2,                                (4.3)
```

where `Q11` has order 11. The remainder is identically zero. The coefficients
of `Q11` are large, so dumping them obscures rather than helps; Section 9
constructs them deterministically from (4.3) and verifies the zero remainder.

Taking formal adjoints reverses the product:

```text
D = R2* o Q11*,                               (4.4)
```

where

```text
R2* f = f'' - A f' + (B-A') f.               (4.5)
```

This is an exact symbolic factorization of the Q6920 theta operator. It
explains two of the seven extra differential orders in the mechanical
order-13 conversion.

# 6. Correct adjoint Green formula for the pole coefficient

The local exponents of `D` at `rho` are

```text
-1,0,1,...,11,
```

while those of `D*` are `0,1,...,12`. The simple-pole channel of a solution of
`D` therefore pairs with the exponent-12 adjoint branch, not with either
rational adjoint in Section 3.

Let `w_rho` be the unique local Frobenius solution of

```text
D* w_rho = 0,

w_rho(z) = (z-rho)^12 + O((z-rho)^13).        (6.1)
```

For

```text
D = sum_{j=0}^{13} a_j(z) d^j/dz^j,
```

define the Lagrange concomitant

```text
B_D(F,w)
 = sum_{j=1}^{13} sum_{k=0}^{j-1}
     (-1)^k F^(j-1-k) (a_j w)^(k).           (6.2)
```

It obeys the exact identity

```text
d/dz B_D(F,w) = w D F - F D* w.              (6.3)
```

At `rho`, one has

```text
a_13(rho)=0,
a_12(rho)=13 a_13'(rho).
```

If

```text
F(z) = C_rho(F)/(1-z/rho) + O(1),
```

then a direct leading-term evaluation of (6.2) gives

```text
lim_{z->rho} B_D(F,w_rho)
 = -rho 12! a_13'(rho) C_rho(F).             (6.4)
```

The finite combinatorial reduction behind (6.4) is

```text
13! H_13 - 13*12! H_12 = 12!,
```

where `H_m` is the `m`th harmonic number.

Thus define the exactly normalized adjoint branch

```text
wtilde_rho
 = -w_rho / (rho 12! a_13'(rho)).            (6.5)
```

Then

```text
C_rho(F) = lim_{z->rho} B_D(F,wtilde_rho).    (6.6)
```

Integrating (6.3) from zero to `rho`, with `FP_0` denoting the Frobenius/Hadamard
finite boundary value at zero, gives

```text
C_rho(Qhat)
 = FP_0 B_D(Qhat,wtilde_rho),                 (6.7)

C_rho(Phat)
 = FP_0 B_D(Phat,wtilde_rho)
   + c integral_0^rho z^2 wtilde_rho(z) dz.  (6.8)
```

The integral converges: the smallest adjoint exponent at zero is `-2`, so
`z^2 wtilde_rho(z)` is locally integrable.

Consequently the desired Catalan evaluation is exactly the finite
adjoint-integral identity

```text
FP_0 B_D(Phat-G Qhat,wtilde_rho)
 + 65021616000 integral_0^rho z^2 wtilde_rho(z) dz
 = 0.                                         (6.9)
```

This is a genuine Green pairing, not an asymptotic restatement. What is still
missing is an exact representation of the non-algebraic function
`wtilde_rho` that evaluates (6.9) by Catalan's integral.

# 7. Smallest remaining concrete ansatz

Apply the exact factor `R2` to the residue adjoint branch:

```text
h_rho = R2 w_rho.
```

By (4.3),

```text
Q11 h_rho = 0.                                (7.1)
```

Because `R2` is regular at `rho` and `w_rho=(z-rho)^12+...`,

```text
h_rho(z)
 = 132 (z-rho)^10 + O((z-rho)^11).           (7.2)
```

This is the smallest remaining Frobenius problem produced by exact
factorization:

```text
Q11 h = 0,
h(z) = 132(z-rho)^10 + O((z-rho)^11).        (NEXT)
```

Once `h_rho` is represented, recover `w_rho` by the elementary
variation-of-constants formula for `R2 w=h`. From (4.1),

```text
w(z)
 = -h1(z) integral [h2(s) h(s)/W(s)] ds
   +h2(z) integral [h1(s) h(s)/W(s)] ds,      (7.3)
```

with constants chosen to enforce (6.1). More explicitly,

```text
h1/W = -z^3(5z+46)/(10g(z)),
h2/W = -z^2(2842z+15)/(10g(z)).              (7.4)
```

Therefore no further matrix or six-dimensional state is needed. The next exact
search should be performed on `(NEXT)`:

1. factor `Q11` in `Q(z)<d/dz>`;
2. or find a pullback/hypergeometric representation specifically for its
   exponent-10 branch;
3. then insert that representation into the two elementary integrals (7.3).

The repository's coefficient experiments suggest that five more apparent
orders may remain before the true order-6 core, but I do **not** claim that
factorization here. The exact statement proved in this answer stops at the
order-11 operator (4.3).

# 9. Standalone exact verifier

This script reconstructs the Q6920 operator, proves the rational adjoint
classification, the algebraic half-power obstruction, the second-order
factorization, the polynomial preimage of `z^2`, and the Green normalization
constant. It uses exact SymPy arithmetic only.

```python
import sympy as s
from sympy.functions.combinatorial.numbers import stirling

n, th, z, r = s.symbols("n th z r")

R = lambda x: (
    1806156 + 3929280*x + 3483853*x**2 + 1615610*x**3
    + 414064*x**4 + 55680*x**5 + 3072*x**6)
S = lambda x: R(x+1)
T = lambda x: (
    78407415225 + 226466421477*x + 286416594222*x**2
    + 208287850700*x**3 + 96028512072*x**4
    + 29119642544*x**5 + 5810223840*x**6
    + 735843584*x**7 + 53692416*x**8 + 1720320*x**9)
U = lambda x: (
    195670909710 + 603914277213*x + 825643834707*x**2
    + 659435701854*x**3 + 341146546318*x**4
    + 119560001580*x**5 + 28770039448*x**6
    + 4696686576*x**7 + 498082432*x**8
    + 30999552*x**9 + 860160*x**10)

p0 = lambda x: -4*(x+1)*(x+3)**2*(x+4)*(2*x+3)*(2*x+5)*(2*x+7)*S(x)
p1 = lambda x: (x+2)**2*(x+4)*(2*x+7)*T(x)
p2 = lambda x: -2*(x+2)*(x+3)*(2*x+9)*U(x)
p3 = lambda x: 4*(x+2)*(x+3)*(x+4)**2*(2*x+7)*(2*x+11)**2*R(x)

# theta^m = sum_j Stirling2(m,j) z^j D^j
def theta_poly_to_D(poly):
    P = s.Poly(s.expand(poly), th)
    deg = P.degree()
    out = []
    for j in range(14):
        out.append(s.expand(sum(
            P.nth(m) * stirling(m, j, kind=2) * z**j
            for m in range(j, deg+1))))
    return out

terms = [
    (z**3, p0(th)),
    (z**2, p1(th-1)),
    (z,    p2(th-2)),
    (1,    p3(th-3)),
]

Dop = [s.expand(sum(mult * theta_poly_to_D(poly)[j]
                    for mult, poly in terms))
       for j in range(14)]

assert s.factor(Dop[13]) == \
    -98304*(z-1)*z**13*(z**2-34*z+1)

# Formal adjoint coefficients.
Dstar = [s.expand(sum(
    (-1)**j * s.binomial(j, k) * s.diff(Dop[j], z, j-k)
    for j in range(k, 14)))
    for k in range(14)]

def apply(op, f):
    return s.cancel(sum(op[j] * s.diff(f, z, j)
                        for j in range(len(op))))

# Complete rational adjoint family.
c0, c1, c2 = s.symbols("c0 c1 c2")
h = c0 + c1/z + c2/z**2
assert s.factor(apply(Dstar, h)) == \
    z*(-124200*c0 + 13500*c1 - 2557800*c2)

h1 = 5 + 46/z
h2 = 2842/z + 15/z**2
assert apply(Dstar, h1) == 0
assert apply(Dstar, h2) == 0

# Only possible non-rational algebraic branch.
assert s.factor(apply(Dstar, z**s.Rational(-1, 2))) == \
    -25650*s.sqrt(z)

f0 = s.Poly(
    3072*r**6 + 18048*r**5 + 37744*r**4 + 32774*r**3
    + 7957*r**2 - 3384*r - 1380, r)
finf = s.Poly(
    3072*r**6 - 384*r**5 - 6416*r**4 + 838*r**3
    + 1699*r**2 - 144*r - 45, r)
assert f0.is_irreducible
assert finf.is_irreducible

# Second-order factor R2.
g = 69 + 15*z + 1421*z**2
A = (276 + 45*z + 2842*z**2)/(z*g)
B = 138/(z**2*g)
R2 = [B, A, s.Integer(1)]

assert apply(R2, h1) == 0
assert apply(R2, h2) == 0
assert s.factor(h1*s.diff(h2,z)-s.diff(h1,z)*h2) == -10*g/z**4

# Noncommutative differential-operator composition.
# Lists store the coefficients of D^0,D^1,... .
def compose(left, right):
    out = [s.Integer(0)] * (len(left)+len(right)-1)
    for i, ai in enumerate(left):
        for j, bj in enumerate(right):
            for k in range(i+1):
                out[i-k+j] += ai*s.binomial(i,k)*s.diff(bj,z,k)
    return [s.cancel(x) for x in out]

def right_divide(dividend, divisor):
    rem = list(dividend)
    m, d = len(dividend)-1, len(divisor)-1
    quot = [s.Integer(0)] * (m-d+1)
    for shift in range(m-d, -1, -1):
        lead = s.cancel(rem[shift+d]/divisor[d])
        quot[shift] = lead
        sub = compose([s.Integer(0)]*shift+[lead], divisor)
        sub += [s.Integer(0)]*(len(rem)-len(sub))
        rem = [s.cancel(rem[i]-sub[i]) for i in range(len(rem))]
    return quot, rem

Q11, remainder = right_divide(Dstar, R2)
assert len(Q11) == 12
assert all(x == 0 for x in remainder)
reconstructed = compose(Q11, R2)
assert all(s.cancel(x-y) == 0 for x,y in zip(reconstructed,Dstar))

# Adjoint second-order factor and its polynomial particular solution.
def R2star_apply(f):
    return s.cancel(s.diff(f,z,2) - A*s.diff(f,z)
                    + (B-s.diff(A,z))*f)

u = s.Rational(23,2842)*z**2 + s.Rational(5,2842)*z**3 \
    + s.Rational(1,6)*z**4
assert R2star_apply(u) == z**2

# Local pole pairing normalization.
rho = 17 - 12*s.sqrt(2)
a13prime = s.simplify(s.diff(Dop[13],z).subs(z,rho))
assert a13prime != 0
assert s.simplify(Dop[12].subs(z,rho) - 13*a13prime) == 0
assert s.simplify(
    s.factorial(13)*s.harmonic(13)
    - 13*s.factorial(12)*s.harmonic(12)
    - s.factorial(12)) == 0

print("Q6923 exact adjoint identities verified")
```
