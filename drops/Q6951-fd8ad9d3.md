There are two corrections to the earlier reports:

1. The correct lift is
   
   ```text
   lift(u,v) = (1,u,v),
   ```
   
   so the terminal identity is a scalar multiple of `![1,u2,0]`, **not** `![u2,0,1]`.

2. `N` is the **absolute terminal time**. After two pulls the base time is `N-2`. The subtraction-free Lean theorem should use a base index `h` and terminal time `h+2`:
   
   ```text
   pullMatrix h * pullMatrix (h+1) * (U(h+2)^T e2).
   ```

The order is also fixed: the vector at time `h+2` is first acted on by `pullMatrix (h+1)`, then by `pullMatrix h`.

# 1. Column orientation of `U`

Let

```text
e0 = (1,0,0)^T,
e2 = (0,0,1)^T.
```

The Krylov matrix is defined by **columns**:

```text
U(n) = [ e0, T(n)e0, T(n)T(n+1)e0 ].
```

In Lean, do not write the outer vector literal as though it automatically creates columns. The robust definition is

```lean
private def Ucol (n : ℕ) : Fin 3 → (Fin 3 → ℝ)
  | 0 => e0
  | 1 => (T n).mulVec e0
  | 2 => (T n * T (n + 1)).mulVec e0

private def U (n : ℕ) : Matrix (Fin 3) (Fin 3) ℝ :=
  fun i j => Ucol n j i
```

Equivalently, if a row-major literal is used, it must be transposed.

With the column definition,

```text
U(N)^T e2
```

is the third row of `U(N)` written as a column. This is the moving companion terminal corresponding to the original challenge column `j=2`. By contrast,

```text
U(N)e2
```

is the third Krylov column and is the wrong terminal.

# 2. Companion and pull orientation

The exact companion is

```text
C(n) =
[ 0  0  c0(n) ]
[ 1  0  c1(n) ]
[ 0  1  c2(n) ],
```

with

```text
T(n) U(n+1) = U(n) C(n).
```

Define

```text
a(n) = -c1(n)/c0(n),
b(n) = -c2(n)/c0(n),
r(n) =  1/c0(n).
```

Then the inverse-transpose companion should be defined explicitly, without `Matrix.inv`:

```text
pullMatrix(n) = C(n)^(-T)
 = [ a(n) b(n) r(n) ]
   [ 1    0    0    ]
   [ 0    1    0    ].
```

Thus for a column `x=(x0,x1,x2)^T`,

```text
pullMatrix(n)x
 = (a(n)x0+b(n)x1+r(n)x2, x0, x1)^T.
```

A useful Lean lemma is

```lean
private theorem pullMatrix_mulVec (n : ℕ) (x : Fin 3 → ℝ) :
    (pullMatrix n).mulVec x =
      ![a n * x 0 + b n * x 1 + r n * x 2, x 0, x 1] := by
  funext i
  fin_cases i <;>
    simp [pullMatrix, Matrix.mulVec, Fin.sum_univ_three]
```


```text
pullMatrix(N-2)
```

The vanishing third coordinate is structural: after the first pull the middle coordinate is the original terminal first coordinate, namely zero; after the second pull the third coordinate is that zero middle coordinate.

# 9. Lean algebraic theorem skeleton

Define the terminal with the corrected column-oriented `U`:

```lean
private def terminal2 (N : ℕ) : Fin 3 → ℝ :=
  (U N).transpose.mulVec e2
```

First isolate the three exact coordinate identities. This keeps the final theorem small.

```lean
private theorem terminal2_formula (N : ℕ) :
    terminal2 N = ![0, terminalW1 N, terminalW2 N] := by
  funext i
  fin_cases i <;>
    simp [terminal2, U, Ucol, terminalW1, terminalW2, terminalP6,
      T, Matrix.mulVec, Fin.sum_univ_three] <;>
    field_simp <;>
    ring
```

The exact proof may need the local denominator-nonzero lemmas in the `field_simp` list if `T` is defined by explicit rational entries.

Now prove one pull and two pulls:

```lean
private theorem terminal2_pull_once (h : ℕ) :
    (pullMatrix (h + 1)).mulVec (terminal2 (h + 2)) =
      ![firstPullHead2 (h + 2), 0, terminalW1 (h + 2)] := by
  rw [terminal2_formula, pullMatrix_mulVec]
  funext i
  fin_cases i <;>
    simp [firstPullHead2, terminalW1, terminalW2, terminalP6,
      a, b, r, c0, c1, c2] <;>
    field_simp <;>
    ring

private theorem terminal2_pull_twice_components (h : ℕ) :
    (pullMatrix h).mulVec
        ((pullMatrix (h + 1)).mulVec (terminal2 (h + 2))) =
      ![millerScalar2 (h + 2), firstPullHead2 (h + 2), 0] := by
  rw [terminal2_pull_once, pullMatrix_mulVec]
  funext i
  fin_cases i <;>
    simp [millerScalar2, millerR2, firstPullHead2, terminalW1,
      a, b, r, c0, c1, c2] <;>
    field_simp <;>
    ring
```

The chart normalization identity is small:

```lean
private theorem scalar_mul_u2_eq_firstPullHead2 (N : ℕ) (hN : 2 ≤ N) :
    millerScalar2 N * millerU2 N = firstPullHead2 N := by
  have hR : millerR2 N ≠ 0 := (millerR2_pos N).ne'
  have hN0 : (N : ℝ) ≠ 0 := by
    exact_mod_cast (show N ≠ 0 by omega)

    firstPullHead2]

```

Finally:

```lean
private theorem terminal2_two_pull_base (h : ℕ) :
    (pullMatrix h).mulVec
        ((pullMatrix (h + 1)).mulVec (terminal2 (h + 2))) =
      millerScalar2 (h + 2) • lift (millerChart2 (h + 2)) := by
  rw [terminal2_pull_twice_components]
  have hmul := scalar_mul_u2_eq_firstPullHead2 (h + 2) (by omega)
  funext i
  fin_cases i <;>
    simp [lift, millerChart2, hmul]
```

The requested terminal-index statement follows by reindexing:

```lean
private theorem terminal2_two_pull (N : ℕ) (hN : 2 ≤ N) :

        ((pullMatrix (N - 1)).mulVec (terminal2 N)) =
      millerScalar2 N • lift (millerChart2 N) := by
  have h1 : N - 2 + 1 = N - 1 := by omega
  have h2 : N - 2 + 2 = N := by omega
  simpa only [h1, h2] using terminal2_two_pull_base (N - 2)
```

# 11. Exact audit checklist

The implementation is correct only if all of the following hold:

- `U i j = (Ucol j) i`; the outer index is the row and the inner index chooses the Krylov column.
- The terminal is `(U N).transpose.mulVec e2`.
- `j=2` is zero-based, hence the third challenge column.
- `N` is terminal time; after two pulls the base is `N-2`.
- The nested action is `pull(N-2) (pull(N-1) terminal)`.
- The chart lift is `![1,u,v]`.
- The exact output has third coordinate zero.
- The scalar is (4.3), is positive, and is not merely `R2`.

Under the normalization `T(n)^T M(n)=sigma(n)I` displayed above, no additional sign or Miller normalization factor remains.
