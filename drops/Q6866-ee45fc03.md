# Fixed-prime Apéry lag problem: an exact two-frequency box reduction, and the remaining arithmetic wall

## Executive verdict

There is a clean arithmetic formulation that aggregates all lag pairs before taking absolute values. It gives a genuine conditional logarithm removal:

```text
[APERY-BOX-LS(W)]

|| E_(p,D) ||_(2->2) <= D/(2W)
```

for the double-nonzero-frequency extension operator defined below implies, provided `16 D W <= p`,

```text
Q_D <= D^2/W.
```

At the mesoscopic scale

```text
D = sqrt(N) L,     N = p-2,
```

one may take

```text
W = L^2 Omega(N),
```

with any subpower `Omega(N) -> infinity` satisfying `L^3 Omega(N) = o(sqrt(N))`. The conclusion is then

```text
Q_D <= (1+o(1)) N/Omega(N).
```

Thus this one theorem would remove both the abstract `log D` and the extraneous `L^2`.

However, none of the banked inputs proves `[APERY-BOX-LS(W)]` for any unbounded `W`. Parity only removes the forced mirror matching; it gives no signed cancellation in the remaining primitive-primitive box. Characteristic-zero coprimality plus saturated resultants gives nonvanishing of each eliminant, but no fixed-prime nonconcentration across the triangular family. Root-cell geometry and `[CRIT-2H]` are archimedean and finite-height; they do not control the growing mod-`p` operator. A `TT*` proof of the large-sieve statement introduces a new two-coordinate determinant-value energy for which no current estimate exists.

The exact named scalar statistic is the **Apéry two-return box bias** `ATB_p(D)`. It satisfies an identity, not merely an inequality:

```text
Q_D
 = ATB_p(D)
   + (W_1(D)+W_2(D))/p
   - T_D/p^2.
```

The last two terms are `O(D^3/p)` using only `deg N_h = 3h-3`. Consequently, whenever `D W = o(p)`,

```text
Q_D << D^2/W
```

is equivalent up to absolute constants and an `o(D^2/W)` term to

```text
ATB_p(D)^+ << D^2/W.
```

This is the exact arithmetic statistic standing between the present theorem and logarithm removal.

**Unambiguous verdict:** no unconditional unbounded saving follows from the currently banked inputs. The correct next theorem is `[APERY-BOX-LS]`, or equivalently a subpower upper bound for `ATB_p(D)^+`. The fixed-prime problem remains **OPEN**.

## 1. Exact setup and renewal coordinate

Use the repository's nonwrapping first-block convention. Let

```text
I(r,h) = 1  if pi(r)=pi(r+h),
         0  otherwise,
```

where the endpoints must both lie in the physical interval. Then

```text
R_h   = sum_r I(r,h),
S_D   = sum_(h<=D) R_h,
d_D(r)= sum_(h<=D) I(r,h),
Q_D   = sum_r binom(d_D(r),2).
```

The continuant dictionary is

```text
I(r,h)=1  <=>  N_h(r)=0
```

on the regular nonwrapping domain. The exact renewal identity gives the already banked sequential-chain formula

```text
Q_D
 = sum_(a,g>=1, a+g<=D) rho_p(a,g),                 (1.1)
```

where

```text
rho_p(a,g)
 = #{r : r+a+g is nonwrapping,
          N_a(r)=0,
          N_g(r+a)=0}.                              (1.2)
```

Equivalently, in projective determinant coordinates, put

```text
delta_1(r,a,g) = det(v_r,     v_(r+a)),
delta_2(r,a,g) = det(v_(r+a), v_(r+a+g)).           (1.3)
```

Then `rho_p(a,g)` counts the `r` for which both determinants vanish.

This is the correct same-box object. It is already saturated geometrically because only regular physical roots are counted.

## 2. Exact two-frequency orthogonality identity

Let

```text
T_D = {(r,a,g): a,g>=1, a+g<=D,
                  r+a+g lies in the physical interval}.
```

Write `#T_D` for its cardinality. Define the two weighted one-edge counts

```text
W_1(D) = sum_((r,a,g) in T_D) I(r,a),
W_2(D) = sum_((r,a,g) in T_D) I(r+a,g).             (2.1)
```

Finally define the double-nonzero-frequency box sum

```text
B_p(D)
 = sum_(s,t in F_p^*)
     sum_((r,a,g) in T_D)
       e_p( s delta_1(r,a,g) + t delta_2(r,a,g) ).   (2.2)
```

Define the normalized scalar

```text
ATB_p(D) := B_p(D)/p^2.                              (2.3)
```

This is the Apéry two-return box bias.

### Proposition 2.1: exact identity

```text
Q_D
 = ATB_p(D)
   + (W_1(D)+W_2(D))/p
   - #T_D/p^2.                                      (2.4)
```

### Proof

For `x in F_p`, additive orthogonality gives

```text
1_(x=0) = (1/p) sum_(s in F_p) e_p(sx).             (2.5)
```

Apply (2.5) to both determinants and sum over `T_D`. The `(s,t)=(0,0)` term is `#T_D`. The `s!=0,t=0` term equals

```text
sum_((r,a,g) in T_D) (p I(r,a)-1)
 = p W_1(D)-#T_D.                                   (2.6)
```

The `s=0,t!=0` term is similarly `p W_2(D)-#T_D`. The `s,t!=0` term is `B_p(D)`. Therefore

```text
p^2 Q_D
 = #T_D
   + (pW_1-#T_D)
   + (pW_2-#T_D)
   + B_p(D),                                        (2.7)
```

which is (2.4).

No per-pair absolute value has appeared. All `(a,g)` are summed before the oscillatory term is estimated.

## 3. The zero-frequency terms are genuinely lower order

The gap polynomial has degree

```text
deg N_h = 3h-3.
```

Hence, without using Weil or any pair estimate,

```text
R_h <= 3(h-1),
S_D <= sum_(h=1)^D 3(h-1)
    = (3/2)D(D-1).                                  (3.1)
```

Each first edge of length `a` has at most `D-a` choices of `g`, and each second edge of length `g` has at most `D-g` choices of the preceding gap. Therefore

```text
W_1(D) <= (D-1)S_D,
W_2(D) <= (D-1)S_D.                                 (3.2)
```

Combining (3.1) and (3.2),

```text
W_1(D)+W_2(D)
 <= 3D(D-1)^2
 < 3D^3.                                            (3.3)
```

Since the final term in (2.4) is nonpositive, we obtain the concrete inequality

```text
Q_D <= ATB_p(D)^+ + 3D^3/p.                         (3.4)
```

Here `x^+=max(x,0)`.

This is the requested exponent audit. At

```text
D = sqrt(N)L,     p=N+2,
```

one has

```text
3D^3/p = (3+o(1)) sqrt(N) L^3.                      (3.5)
```

Against a target `D^2/W`, the ratio of this error to the target is

```text
(3D^3/p)/(D^2/W) = 3DW/p.                           (3.6)
```

Thus the zero-frequency terms are negligible for every subpower `W` with

```text
DW=o(p).                                             (3.7)
```

In particular this holds for `W=L^2 Omega(N)` whenever

```text
L^3 Omega(N)=o(sqrt(N)).                             (3.8)
```

## 4. A concrete conditional logarithm-removal theorem

### Theorem 4.1: scalar box cancellation

Let `W>=1`. If

```text
|B_p(D)| <= p^2 D^2/(2W)                            (4.1)
```

and

```text
6DW <= p,                                            (4.2)
```

then

```text
Q_D <= D^2/W.                                        (4.3)
```

### Proof

Equation (3.4) and (4.1) give

```text
Q_D <= D^2/(2W) + 3D^3/p.                           (4.4)
```

Condition (4.2) makes the second term at most `D^2/(2W)`.

### Mesoscopic consequence

Choose

```text
D = floor(sqrt(N)L),
W = L^2 Omega(N),                                   (4.5)
```

where `L=N^o(1)`, `Omega(N)->infinity`, and both are chosen so slowly that (3.8) holds. Then (4.3) becomes

```text
Q_D <= (1+o(1)) N/Omega(N).                         (4.6)
```

This is stronger than merely deleting `log D`; it deletes the `L^2` from `D^2=N L^2` as well.

Taking `W=L^2` gives `Q_D=O(N)`. Taking `W=L^2 omega(N)` gives `Q_D=O(N/omega(N))`.

## 5. Spectral/large-sieve form

The scalar condition (4.1) can be packaged as a genuine extension operator.

For `a,g>=1`, `a+g<=D`, define

```text
E_(p,D)(a,g)
 = (1/p^2) sum_(s,t in F_p^*)
     sum_r e_p( s delta_1(r,a,g)+t delta_2(r,a,g) ), (5.1)
```

where `r` is restricted to the physical nonwrapping domain for `(a,g)`. Put the entry equal to zero when `a+g>D`. Then

```text
ATB_p(D) = <1, E_(p,D) 1>.                          (5.2)
```

The vector has at most `D-1` coordinates, so

```text
|ATB_p(D)|
 <= D ||E_(p,D)||_(2->2).                           (5.3)
```

Therefore the following is a sufficient arithmetic theorem.

```text
[APERY-BOX-LS(W)]

||E_(p,D)||_(2->2) <= D/(2W).                       (5.4)
```

Together with `6DW<=p`, it implies `Q_D<=D^2/W`.

This is a real large-sieve statement: it is uniform in arbitrary coefficient vectors. Explicitly, (5.4) says that for all complex vectors `alpha=(alpha_a)` and `beta=(beta_g)`,

```text
| (1/p^2) sum_(s,t!=0)
    sum_(a+g<=D) alpha_a beta_g
    sum_r e_p(s delta_1(r,a,g)+t delta_2(r,a,g)) |

 <= D/(2W) ||alpha||_2 ||beta||_2.                  (5.5)
```

The all-ones specialization is exactly the missing same-box cancellation.

### Equivalent extension-matrix formulation

Let

```text
RHO_(p,D)(a,g) = rho_p(a,g).                        (5.6)
```

Then

```text
Q_D = <1,RHO_(p,D)1>.                               (5.7)
```

Orthogonality decomposes `RHO` into the double-nonzero matrix `E` plus the zero- and one-frequency matrices. Using `R_h<=3(h-1)` and Schur's test gives the safe operator bound

```text
||RHO_(p,D)||_(2->2)
 <= ||E_(p,D)||_(2->2) + 8D^2/p.                   (5.8)
```

Hence a slightly stronger but convenient form is:

```text
if ||E_(p,D)|| <= D/(2W) and 16DW<=p,
then ||RHO_(p,D)|| <= D/W,
and therefore Q_D <= D^2/W.                        (5.9)
```

This is the precise spectral target suggested by the small observed row and column weights in `CODEX_MESOPAIR_DIAG_report.md`. The data support it; they do not prove it.

## 6. Parity and mirror symmetry do not supply the cancellation

The exact row law is

```text
R_h = 1_(2|h) + 2 mu_h + endpoint_h.                (6.1)
```

The forced even-lag collision has base

```text
r_h = (p-1-h)/2.                                    (6.2)
```

As `h` varies over the even lags, the bases `r_h` are distinct. Thus the forced mirror edges form a matching in the base-incidence sense: no base supports two forced edges.

Write

```text
d_D(r)=f_D(r)+d_D^prim(r),
```

where `f_D(r)` counts forced mirror edges. Apart from the banked endpoint clauses,

```text
f_D(r) in {0,1}.                                    (6.3)
```

Consequently

```text
Q_D
 = Q_D^prim + sum_r f_D(r)d_D^prim(r),              (6.4)
```

and hence

```text
Q_D^prim <= Q_D <= Q_D^prim+S_D^prim.               (6.5)
```

There is no forced-forced contribution. This is useful peeling, but it does not save an unbounded factor: the whole logarithmic obstruction can live in the primitive-primitive term.

Reflection also sends a chain with adjacent gaps `(a,g)` to one with gaps `(g,a)`. It therefore gives

```text
rho_p(a,g)=rho_p(g,a)                               (6.6)
```

up to the explicit boundary convention. This is symmetry, not cancellation. The entries are nonnegative. Splitting the triangular matrix into `EE`, `EO`, `OE`, and `OO` blocks merely partitions a positive sum.

Most importantly, the parity law is a statement about the zero sets of the determinants. It supplies no relation of the form

```text
delta_1(reflected point) = -delta_1(point)
```

with a compatible normalization across both edges and all lags. Even such a sign relation would pair phases into cosines, not make the total vanish. Thus parity does not bound `ATB_p(D)`.

## 7. Saturated resultants: the correct algebraic face, but no fixed-prime saving

For each `(a,g)`, let `e_(a,g)^sat` denote the generator of the regular saturated elimination ideal for

```text
N_a(X)=0,
N_g(X+a)=0,                                         (7.1)
```

with all clock/cut-edge divisors removed. The banked characteristic-zero coprimality says

```text
e_(a,g)^sat != 0.                                   (7.2)
```

For good leading-coefficient primes, every regular common root contributes at least one unit of `p`-adic resultant valuation. Therefore

```text
rho_p(a,g) <= v_p(e_(a,g)^sat),                     (7.3)
```

and

```text
Q_D
 <= V_p(D)
 := sum_(a+g<=D) v_p(e_(a,g)^sat).                  (7.4)
```

This is the correct averaged resultant statistic. It contains no raw cut-edge pollution.

But characteristic-zero coprimality proves only that the integers in (7.2) are nonzero. It does not stop one fixed prime from dividing many of them. The available archimedean height route gives, even optimistically,

```text
V_p(D) << D^4 log D / log p.                        (7.5)
```

At `D=sqrt(N)L`, the ratio of (7.5) to the desired `D^2/W` is

```text
(D^4 log D/log p)/(D^2/W)
 = D^2 W log D/log p
 asymp N L^2 W.                                     (7.6)
```

For `W=L^2 Omega`, the missing factor is of order

```text
N L^4 Omega.                                        (7.7)
```

No sharpening of a polynomial height constant can bridge that gap. What is missing is a fixed-prime nonconcentration theorem for the entire triangular family, i.e. precisely a bound on `V_p(D)` or on the stronger oscillatory operator `E_(p,D)`.

Renewal has already done all the algebraic simplification available here: it replaces same-base raw resultants by the shifted regular family (7.1). It does not impose a low-rank recurrence on the array of saturated resultants.

## 8. Why a routine `TT*`/large-sieve proof stops

A natural attempt is to prove (5.5) by `TT*`. For a triple `z=(r,a,g)`, define the determinant-value pair

```text
Phi(z) = (delta_1(r,a,g), delta_2(r,a,g)) in F_p^2. (8.1)
```

Parseval in `(s,t)` converts the second moment of the exponential sums into the pair-value energy

```text
J_p(D)
 = #{(z,z') in T_D^2 : Phi(z)=Phi(z')}.             (8.2)
```

With coefficient vectors present, one obtains weighted variants of (8.2), but the arithmetic object is the same: a two-coordinate determinant-value collision energy for the three-parameter family `(r,a,g)`.

The currently banked collision-energy theorem concerns scalar fibers of the Apéry value sequence. It does not bound (8.2). The map in (8.1) is not a fixed bounded-degree algebraic map: its degree grows with `a+g`, and the lag indices are discrete recurrence times rather than coordinates on a fixed low-degree variety.

Taking absolute values before summing `(a,g)` returns the prohibited fixed-pair Weil route and is much worse. If a fixed pair and fixed frequencies are bounded by `O((a+g)sqrt(p))`, summing over `O(D^2)` lag pairs and `O(p^2)` frequency pairs gives, after the `p^-2` normalization, a bound of order

```text
D^3 sqrt(p),                                        (8.3)
```

which at `D=sqrt(p)L` is `p^2 L^3`, far above even the abstract estimate.

Thus `[APERY-BOX-LS]` is not a repackaging of fixed-h Weil. It requires cancellation across the lag-pair family, or a new estimate for the joint energy (8.2).

## 9. Why the other banked inputs do not bound the box bias

### 9.1 Root cells and characteristic-zero coprimality

The near-lattice root-cell theorem locates complex roots of each `N_h` and proves characteristic-zero separation. It gives no control on simultaneous reduction of two distinct root sets modulo one prime. Resultant divisibility is exactly the information lost in passing from complex separation to mod-`p` coincidence.

### 9.2 `[CRIT-2H]` and `h<=60`

The finite-height critical-value and `L2` frequency results control only finitely many lag rows. Removing the rows `a<=60` or columns `g<=60` is a finite-rank perturbation of the matrix in (5.1). The balanced block

```text
61 <= a,g,
a+g<=D                                             (9.1)
```

still has dimension comparable with `D`, and none of the finite-height estimates bounds its operator norm.

### 9.3 Renewal

Renewal proves (1.1) and identifies the shifted pair `(N_a(X),N_g(X+a))`. It does not make the restarted base `r+a` independent of the first return. This dependence is exactly what appears in both phases in (2.2).

### 9.4 Abstract orbit combinatorics

The sharp abstract theorem

```text
Q_D <= 66D^2(1+log D)                               (9.2)
```

is saturated by multiscale words. In the present language, those examples have a large positive `ATB` after the zero-frequency terms are removed. Therefore no rearrangement of the abstract proof can establish (4.1); an Apéry-specific bound on the determinant phases or saturated extension matrix is necessary.

## 10. The exact missing statistic

There are three equivalent interfaces, in increasing strength.

### Scalar, exactly equivalent at the mesoscopic scale

```text
ATB_p(D)
 = (1/p^2) sum_(s,t!=0)
     sum_(a+g<=D) sum_r
       e_p(s delta_1+t delta_2).                    (10.1)
```

The exact identity is

```text
ATB_p(D)
 = Q_D
   - (W_1(D)+W_2(D))/p
   + #T_D/p^2.                                      (10.2)
```

Since the correction is `O(D^3/p)`, for `DW=o(p)` the statement

```text
Q_D << D^2/W                                        (10.3)
```

is equivalent, up to absolute constants, to

```text
ATB_p(D)^+ << D^2/W.                                (10.4)
```

### Spectral, robust sufficient form

```text
||E_(p,D)||_(2->2) << D/W.                          (10.5)
```

This is `[APERY-BOX-LS]`.

### Algebraic, nonoscillatory sufficient form

```text
V_p(D)
 = sum_(a+g<=D) v_p(e_(a,g)^sat)
 << D^2/W.                                          (10.6)
```

This is stronger than needed because it discards all cancellation and counts multiplicity. Current height estimates do not approach it.

The scalar statistic (10.1) is the minimal exact obstruction. The spectral statistic (10.5) is the most plausible theorem format. The valuation statistic (10.6) is the cleanest algebraic sufficient condition but appears substantially stronger.

## 11. Direct `S_D` target

The same orthogonality method gives an exact one-frequency aggregate, without summing fixed-h Weil bounds. Let

```text
M_D = sum_(h<=D) (number of admissible bases for h),

AOB_p(D)
 = (1/p) sum_(t in F_p^*)
     sum_(h<=D) sum_r e_p(t det(v_r,v_(r+h))).       (11.1)
```

Then

```text
S_D = M_D/p + AOB_p(D).                             (11.2)
```

Since

```text
M_D/p = D+O(D^2/p),                                 (11.3)
```

at `D=sqrt(N)L` a direct theorem

```text
AOB_p(D) << N/omega(N)                              (11.4)
```

would imply

```text
S_D << N/omega(N)                                   (11.5)
```

provided `L omega(N)=o(sqrt(N))`.

The two-frequency theorem controls repeated returns, not private single returns, so it does not by itself imply (11.4). This cleanly separates the two goals:

```text
ATB controls Q_D;
AOB controls S_D directly.                          (11.6)
```

The banked finite-h `L2` results again control only finitely many columns and do not bound (11.1) for growing `D`.

## 12. Final verdict and precise next theorem

The arithmetic aggregation succeeds as a reduction but not yet as a proof.

What is proved here:

```text
1. Exact identity:
   Q_D = ATB_p(D)+(W_1+W_2)/p-#T_D/p^2.

2. Explicit error:
   Q_D <= ATB_p(D)^+ + 3D^3/p.

3. Conditional saving:
   |B_p(D)| <= p^2D^2/(2W),  6DW<=p
   => Q_D <= D^2/W.

4. Spectral sufficient theorem:
   ||E_(p,D)|| <= D/(2W)
   => the same conclusion.

5. At D=sqrt(N)L, taking W=L^2 Omega(N)
   gives Q_D <= (1+o(1))N/Omega(N).
```

What is not proved:

```text
No current Apéry-specific input bounds ATB_p(D)
by D^2/W for any W->infinity.
```

The exact theorem to seek is therefore:

```text
[APERY-TWO-RETURN-BOX-LARGE-SIEVE]

For D=sqrt(p) p^o(1), there exists W(p)->infinity such that

||E_(p,D)||_(2->2) <= D/W(p).                       (12.1)
```

A version with

```text
W(p) >= L^2 Omega(p)
```

would yield the desired `Q_D=o(N)` scale. A scalar all-ones version bounding `ATB_p(D)^+` would already suffice and is strictly weaker.

**VERDICT: OPEN.** The logarithm cannot be removed from the banked inputs alone. The missing ingredient is exactly subpower cancellation in the Apéry two-return box bias, equivalently a large-sieve bound for the regular shifted extension operator. Parity, renewal, characteristic-zero coprimality, saturation, root cells, and the finite `h<=60` frequency results do not presently control that statistic.
