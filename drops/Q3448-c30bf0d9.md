# 5. A centered lift is not a characteristic-zero homomorphism

Let `p` be odd and let

```text
ctr_p : F_p -> Z
```

be the usual centered section, with image in

```text
[-(p-1)/2, (p-1)/2].
```

It satisfies

```text
ctr_p(x) == x (mod p),                              (5.1)
```

but it is not additive. For example put

```text
a = (p-1)/2 in F_p.
```

Then

```text
ctr_p(a) + ctr_p(a) = p-1,
ctr_p(a+a) = ctr_p(-1) = -1.                        (5.2)
```

The two sides differ by `p`. Thus

```text
ctr_p(x+y) = ctr_p(x)+ctr_p(y)+p*k_p(x,y)           (5.3)
```

for a generally nonzero carry `k_p`.

Therefore, if `E_(p,j)` is produced by centering a residue class, equations derived from modular linearity remain congruences modulo `p`; replacing every residue by its centered integer representative does not automatically turn them into exact characteristic-zero linear identities.

The same issue appears in determinants/Cramer numerators. Changing a lift by `p` changes an integer determinant or Cramer numerator by a multiple of `p`. The mod-`p` result is unchanged, but the characteristic-zero representative is not canonical.

## 5.1 Dependence on the target prime

More importantly, `ctr_p` depends on `p`. Thus

```text

```

is a family of local representatives chosen *after the target prime is known*. The radical argument needs a single characteristic-zero carrier, schematically

```text

```

selected independently of the individual target prime, with

```text
p | C(m,H)   for every target p,                    (5.5)
```

plus nonvanishing and the required subexponential height bound.

A collection

```text

```

with `p | C_p` does not imply `(5.5)` for one common integer. It gives no useful bound on the product of the target primes. CRT-gluing the separate centered representatives merely produces a number defined modulo the target radical; without an independent small-height compatibility theorem, its natural modulus is precisely the radical one is trying to bound. That is circular.

Hence the centered-lift construction can be a local normalization or a local counterexample tool. It is not by itself a global carrier construction.

# 6. The coefficient-one `C47` decomposition: exact corrected meaning

### 6.1 Equality in an auxiliary `F_p` vector space

This does **not** imply that `C47` lies in the image of the original source quotient.

### 6.2 Congruence between chosen integer lifts

This can also be correct modulo `p`:


But different centered choices change the characteristic-zero right side by multiples of `p`. Equation `(6.2)` is still a fixed-target congruence, not a uniform exact identity.

### 6.3 Exact characteristic-zero source decomposition

This is the statement needed for the proposed global carrier route, and it is **not justified** by 6.1 or 6.2. To obtain it one must exhibit a single `p`-independent source element and an exact identity before reduction:


with the same element used for every target prime. A centered residue section does not furnish `(6.3)`.

Thus the phrase “coefficient-one C47 decomposition” is safe only with the qualification:

> coefficient-one decomposition in a fixed-`p`, gauge-fixed auxiliary first-Witt presentation.

It is unsafe if promoted to:

> coefficient-one decomposition in the original characteristic-zero balanced source quotient.
