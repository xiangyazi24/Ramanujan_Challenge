# Exact conductor audit for the one-gap complete sum

## Verdict

[PROVED] The claimed `(4h+1)*sqrt(p)` estimate is safe but its cohomological count is off by exactly two.

For the regular project range

```text
p >= 7,
1 <= h <= p-3,
t in F_p^*,
```

let

```text
Q_h(r) = product_(j=1)^h (r+j),
f_h(r) = N_h(r)/Q_h(r)^3,
S_h(t) = sum_(r in F_p, f_h regular at r) e_p(t*f_h(r)).
```

If the reduction has all `h` displayed poles and all are triple, then the exact dimensions are

```text
dim H_c^1(P^1 minus {-1,...,-h}, L_psi(t f_h)) = 4h-2,

dim H_c^1(A^1 minus {-1,...,-h}, L_psi(t f_h)) = 4h-1.
```

The first space controls `S_h(t)+1`, because infinity is regular and contributes `e_p(0)=1`. The second controls `S_h(t)` itself.

Therefore the sharp statement supplied directly by this method is

```text
|S_h(t)+1| <= (4h-2)*sqrt(p),
|S_h(t)|   <= (4h-2)*sqrt(p)+1.
```

In the requested pure form `C(h)*sqrt(p)`, the correct clean integer coefficient is

```text
boxed: C(h)=4h-1.
```

Thus the answer to the proposed alternatives is:

```text
4h+1 : an overcount by 2;
4h-1 : the exact affine compact-support dimension and the correct clean bound;
4h-2 : the exact projective-open dimension, but it bounds S_h(t)+1, not S_h(t).
```

There are no `H_c^0` or `H_c^2` corrections for `t != 0`. The only `+1` is the ordinary local trace at the regular point infinity when one passes between the projective-open and affine sums.

The requested numerical check was run in two independent implementations. All 15 samples had no pole cancellation, and the two computations agree to 12 decimal places. The largest observed normalized maximum is

```text
3.232723416018
```

at `(p,h)=(499,3)`, far below every conductor bound above.

# 1. Pole audit

## 1.1 Characteristic-zero pole structure

The already proved determinant identity is

```text
Delta_(r,h) = f_h(r) = N_h(r)/Q_h(r)^3.
```

The exact boundary values are

```text
N_h(-j)
 = (-1)^(j-1)
   * (((j-1)!*(h-j)!)^3)
   * b_(j-1)*b_(h-j),
1 <= j <= h.
```

This follows by writing `N_h(r)=U_(h-1)(r+1)`. At `r=-j`, one edge in the continuant has weight zero, so the continuant splits into pieces of lengths `j-1` and `h-j`; then use

```text
U_m(0)  = (m!)^3 b_m,
U_m(-m) = (-1)^m U_m(0).
```

Over `Q`, all Apéry numbers are positive, so every displayed point

```text
-1,-2,...,-h
```

is a pole of exact order three. Also

```text
deg N_h   = 3h-3,
deg Q_h^3 = 3h,
```

so infinity is a zero of order three, not a pole.

## 1.2 Reduction modulo p: cancellations can occur, but only help

The characteristic-zero coprimality does not imply that every pole remains triple modulo every prime. The displayed value can vanish modulo `p` if one of the factors `b_(j-1)` or `b_(h-j)` vanishes modulo `p`.

Let

```text
R_h = actual finite pole set of f_h after cancellation,
m_h = #R_h,
d_x = actual pole order at x in R_h.
```

Since `h<p`, the displayed denominator roots are distinct, and

```text
R_h is a subset of {-1,...,-h},
1 <= d_x <= 3,
m_h <= h,
sum_(x in R_h) d_x <= 3m_h <= 3h.
```

At least one pole survives. For `h=1`, this is immediate from `N_1=1`. For `h>=2`,

```text
N_h(-1) = ((h-1)!)^3 b_(h-1),
N_h(-2) = -5*((h-2)!)^3 b_(h-2).
```

If both vanished modulo `p`, then `b_(h-1)=b_(h-2)=0`. Because all recurrence coefficients in this range are regular, backward propagation would force `b_0=0`, contradicting `b_0=1`.

Thus `f_h` has at least one actual pole, and at least one displayed nonzero numerator gives an actual triple pole.

Infinity remains regular after reduction. A modular degree drop in `N_h` can only increase its zero order there.

## 1.3 Artin-Schreier nondegeneracy

Let `psi` be the standard nontrivial additive character and put

```text
L_t = L_psi(t f_h),
t != 0.
```

At an actual pole of order `d_x`, where `1<=d_x<=3<p`, the local Swan conductor is

```text
Swan_x(L_t)=d_x.
```

Also `f_h` cannot have Artin-Schreier form

```text
f_h = g^p-g+c.
```

Indeed, every pole of a nonconstant function `g^p-g+c` has order divisible by `p`, whereas `f_h` has an actual pole of order at most three. This also proves that `L_t` is geometrically nonconstant.

# 2. The exact Euler-characteristic calculation

Put

```text
D_h = sum_(x in R_h) d_x.
```

## 2.1 Projective open: coefficient `m_h+D_h-2`

Let

```text
V_h = P^1 minus R_h.
```

Infinity belongs to `V_h`, because `f_h` extends there with value zero. The rank-one Grothendieck-Ogg-Shafarevich formula gives

```text
chi_c(V_h,L_t)
 = chi_c(V_h,Q_l) - sum_(x in R_h) Swan_x(L_t)
 = (2-m_h)-D_h.
```

The two outside cohomology groups vanish:

```text
H_c^0(V_h,L_t)=0,
H_c^2(V_h,L_t)=0.
```

The first vanishing holds because `V_h` is a connected nonproper curve. For the second, Poincare duality identifies `H_c^2` with the dual of the geometric invariant space of `L_t^vee`; the nontrivial wild inertia at an actual pole makes that invariant space zero.

Hence

```text
dim H_c^1(V_h,L_t) = m_h+D_h-2.
```

The trace formula is

```text
S_h^red(t)+1
 = -Tr(Frob_p | H_c^1(V_h,L_t)),
```

where `S_h^red` means that only actual poles are omitted. The added `1` is exactly the trace at infinity:

```text
f_h(infinity)=0,
e_p(t*f_h(infinity))=1.
```

Deligne's weight bound therefore gives

```text
|S_h^red(t)+1|
 <= (m_h+D_h-2)*sqrt(p)
 <= (4h-2)*sqrt(p).
```

## 2.2 Affine open: coefficient `m_h+D_h-1`

Now let

```text
U_h = A^1 minus R_h
    = V_h minus {infinity}.
```

Here

```text
chi_c(U_h,Q_l)=1-m_h,
```

so Grothendieck-Ogg-Shafarevich gives

```text
chi_c(U_h,L_t)=1-m_h-D_h.
```

Again `H_c^0=H_c^2=0`, hence

```text
dim H_c^1(U_h,L_t)=m_h+D_h-1.
```

The affine trace dictionary is exact:

```text
boxed:
S_h^red(t) = -Tr(Frob_p | H_c^1(U_h,L_t)).
```

There are no other terms. Consequently

```text
|S_h^red(t)|
 <= (m_h+D_h-1)*sqrt(p)
 <= (4h-1)*sqrt(p).
```

This is the answer to Task 2.

## 2.3 Why the two dimensions differ by one

Deleting the regular point infinity gives the exact sequence

```text
0 -> Q_l -> H_c^1(U_h,L_t) -> H_c^1(V_h,L_t) -> 0.
```

Frobenius acts on the left line with eigenvalue `1`. Therefore

```text
dim H_c^1(U_h,L_t)
 = dim H_c^1(V_h,L_t)+1,

S_h^red(t)
 = -1-Tr(Frob_p | H_c^1(V_h,L_t)).
```

This is the missing bookkeeping in the `(4h+1)` derivation.

The worker effectively used

```text
-dim-like baseline = h+1
```

where the correct affine baseline is

```text
h-1.
```

Equivalently,

```text
chi_c(A^1 minus h points,Q_l)=1-h,
```

not `-1-h`. The resulting error is exactly two.

# 3. Exact bound for the user's displayed-denominator convention

There are two possible meanings of "no pole."

1. Omit only actual poles of the reduced rational function. Then the formulas of Section 2 apply literally and there are no finite-point corrections.

2. Mechanically omit all displayed denominator zeros `-1,...,-h`, even if a numerator cancellation makes one removable. Then let

```text
C_h = {-1,...,-h} minus R_h,
c_h = #C_h = h-m_h.
```

At every point of `C_h`, the reduced function has a finite value. Therefore the mechanically truncated sum differs from `S_h^red(t)` by exactly `c_h` explicit unit-modulus local terms. Thus

```text
|S_h^disp(t)|
 <= (m_h+D_h-2)*sqrt(p)+1+c_h
 <= (4h-2)*sqrt(p)+1,
```

and also

```text
|S_h^disp(t)| <= (4h-1)*sqrt(p).
```

So pole cancellation never invalidates the final universal bound. It only means that the bare identity

```text
S_h(t)=-Tr H_c^1
```

must use the actual-pole domain, or else include the explicitly omitted removable-point traces.

For every numerical sample requested below, `c_h=0`, so the displayed and actual-pole sums coincide.

# 4. The exact all-triple-pole specialization

When

```text
N_h(-j) != 0 mod p for every 1<=j<=h,
```

one has

```text
m_h=h,
D_h=3h.
```

Therefore

```text
dim H_c^1(V_h,L_t)=4h-2,
dim H_c^1(U_h,L_t)=4h-1,
```

and

```text
boxed:
|S_h(t)+1| <= (4h-2)*sqrt(p),
|S_h(t)|   <= (4h-2)*sqrt(p)+1
           <= (4h-1)*sqrt(p).
```

Thus the most precise final verdict is:

```text
The exact cohomological coefficient is 4h-2 for S_h+1.
The exact affine H_c^1 dimension is 4h-1 for S_h.
The strongest direct numerical inequality is (4h-2)*sqrt(p)+1.
```

A bare `(4h-2)*sqrt(p)` bound for `S_h` itself does not follow from this argument, because the regular point infinity contributes exactly one.

# 5. Numerical verification

## 5.1 Audit method

Two independent computations were run.

The first computed `N_h(r)` pointwise from

```text
N_0=0,
N_1=1,
N_(h+1)(r)=P(r+h)N_h(r)-(r+h)^6N_(h-1)(r),
```

formed the residue histogram of `f_h(r)`, and took its discrete Fourier transform over every `t!=0`.

The second constructed every polynomial `N_h` coefficient-by-coefficient in `F_p[r]` using polynomial multiplication, evaluated it by Horner's rule, and computed each complex sum directly without using the first histogram code.

The two methods agree to 12 decimal places in all 15 cases. They were recorded in GitHub Actions runs


respectively.

For every requested `(p,h)`, the numerator was nonzero at all `h` displayed denominator roots. Hence all poles were genuinely triple and the summation had exactly `p-h` terms.

The sums are real up to floating-point roundoff. This is forced by the proved reflection law

```text
f_h(-h-1-r)=-f_h(r).
```

Nonfixed points pair into complex conjugate contributions. The fixed point is either an omitted pole when `h` is odd or a zero of `f_h` when `h` is even. Accordingly, maximizing `t` values occur in pairs `{t,p-t}`.

# 6. Bankable theorem

[PROVED] Let `p>=7`, `1<=h<=p-3`, and `t in F_p^*`. Let `S_h^disp(t)` be the complete sum over all `r` for which the displayed denominator `Q_h(r)` is nonzero. Then

```text
|S_h^disp(t)|
 <= (4h-2)*sqrt(p)+1
 <= (4h-1)*sqrt(p).
```

If all displayed poles remain triple modulo `p`, then

```text
S_h(t)+1
 = -Tr(Frob_p | H_c^1(P^1 minus {-1,...,-h},L_psi(t f_h))),

dim H_c^1 = 4h-2,
```

and

```text
S_h(t)
 = -Tr(Frob_p | H_c^1(A^1 minus {-1,...,-h},L_psi(t f_h))),

dim H_c^1 = 4h-1.
```

No `H_c^0` or `H_c^2` terms occur.

This proves the desired fixed-gap square-root estimate with a linear conductor constant. It does not address the project bottleneck: summing the separate fixed-`h` errors over `h` still loses the growing-family factor.
