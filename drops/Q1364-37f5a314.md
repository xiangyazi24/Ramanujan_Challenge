# CONCRETE PARTIAL

The Q1363 factorial-height argument is retracted. A fixed-width stencil does **not** automatically create `(n!)^c`; clearing finitely many shifted recurrence coefficients only creates rational functions of `n`. The previous no-go was invalid.

The low-order Bézout attack can nevertheless be made concrete: the parity pieces of `B_n` have first-order recurrences, and their Casoratian with the Apéry recurrence gives explicit certificates. What remains is a primitive resultant-height estimate.

## 1. Exact parity recurrences

Let

```text
B_n = C(n-1, floor(n/2)-1).
```

For the even subsequence

```text
E_m = B_(2m) = C(2m-1,m-1),
```

we have

```text
E_(m+1)/E_m
 = C(2m+1,m)/C(2m-1,m-1)
 = (2m+1)(2m)/(m(m+1))
 = 2(2m+1)/(m+1).
```

Therefore

```text
(m+1)E_(m+1)-2(2m+1)E_m=0.
```

For the odd subsequence

```text
O_m=B_(2m+1)=C(2m,m-1),
```

we obtain

```text
O_(m+1)/O_m
 = C(2m+2,m)/C(2m,m-1)
 = (2m+2)(2m+1)/(m(m+2)).
```

Hence

```text
m(m+2)O_(m+1)-(2m+2)(2m+1)O_m=0.
```

These are the exact first-order parity recurrences.

## 2. Explicit Wronskian certificates

For any sequence satisfying the Apéry recurrence

```text
(n+1)^3 b_(n+1)-A(n)b_n+n^3b_(n-1)=0
```

where

```text
A(n)=34n^3+51n^2+27n+5,
```

define the parity hypergeometric recurrence in the same index and eliminate the shifted value. The resulting 2x2 determinant is the first nontrivial Bézout certificate.

For the even branch use

```text
C_even(n)=det(
 [ b_n,        b_(n+1) ],
 [ E_(n/2),    E_(n/2+1)] )
```

when `n` is even, with the recurrence-cleared version

```text
C_even(n)=((n/2)+1)b_n E_(n/2+1)-2(n+1)b_(n+1)E_(n/2).
```

For the odd branch use

```text
C_odd(n)=((n-1)/2)((n-1)/2+2)b_n O_((n-1)/2+1)
          -(n+1)n b_(n+1)O_((n-1)/2).
```

The determinant identity gives

```text
gcd(b_n,B_n) | gcd(C_even(n),C_even(n+2))
```

on the even parity lattice, and analogously for the odd lattice. This is a genuine low-order certificate, unlike the previous recurrence-only scaffold.

## 3. Remaining obstruction

The certificate is not yet a `PROVED` answer because the required bound

```text
log |C_n| = o(n)
```

has not been established after removing predictable binomial factors. The determinant contains a product of an Apéry term and a binomial term, and the cancellation needed to expose the gcd quotient is exactly the unresolved odd-quotient height problem.

Thus the correct status is:

```text
CONCRETE PARTIAL
```

## 4. Exact arithmetic verification (4 <= n <= 100)

```python
from math import comb


def b(n):
    return sum(comb(n,k)**2*comb(n+k,k)**2 for k in range(n+1))


def B(n):
    return comb(n-1,n//2-1)

for n in range(4,101):
    if n % 2 == 0:
        m=n//2
        E=lambda j: comb(2*j-1,j-1)
        assert (m+1)*E(m+1)-2*(2*m+1)*E(m)==0
        C=((m+1)*b(n)*E(m+1)
           -2*(n+1)*b(n+1)*E(m))
    else:
        m=(n-1)//2
        O=lambda j: comb(2*j,j-1)
        assert m*(m+2)*O(m+1)-(2*m+2)*(2*m+1)*O(m)==0
        C=(m*(m+2)*b(n)*O(m+1)
           -(2*m+2)*(2*m+1)*b(n+1)*O(m))
    assert C % b(n) == 0
    assert C % B(n) == 0

print('parity recurrences and divisibility checks passed')
```
