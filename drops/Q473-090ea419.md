# Q473: Precise mean of |Z_p| for Apéry numbers

## Summary

The discrepancy is real: the naive USp(4) trace-density heuristic predicts approximately 2/pi = 0.6366 zeros per prime, while computation gives approximately 1. The explanation is not a simple missing normalization factor in the Kummer trace. The main issue is that the sequence b_r is not sampling the ordinary Frobenius trace of a single rank-4 USp(4) representation. It is a toric exponential/Kloosterman-type moment whose zero condition has extra arithmetic structure. The USp(4) heuristic is therefore only a partial model.

## (A) Relation between b_r and Frobenius traces

The Apéry numbers have the toric representation

```
b_r = sum_{x in (F_p^*)^3} Lambda(x)^r mod p.
```

This is a finite-field moment sum. It should be viewed through the Fourier transform of the torus point distribution. For a Laurent polynomial Lambda on a d-dimensional torus, the character sums

```
S(chi) = sum_x chi(Lambda(x))
```

are Frobenius traces of the Kummer pullback sheaves. The rank-4 Apéry motive appears after taking the appropriate middle cohomology piece and removing Tate/trivial contributions.

The important point is:

```
b_r is not equal to Tr(Frob_p | V_r)
```

for a fixed 4-dimensional representation V. Instead b_r is a moment of the eigenvalue distribution of Lambda. The associated Frobenius trace contains normalization factors from the toric cohomology decomposition, including lower-dimensional boundary pieces.

Thus multiplying the USp(4) density by a scalar cannot explain the difference. A scalar normalization changes trace size, but the event b_r = 0 is governed by the full arithmetic distribution of the moment sum.

## (B) Picard-Fuchs interpretation

The Picard-Fuchs operator

```
L = theta^4 - z(2theta+1)(17theta^2+17theta+5) + z^2(theta+1)^4
```

controls the period family whose local system has rank 4.

The variable z is the generating-function parameter. It is not directly the Kummer character parameter r. The relation is indirect:

```
Kummer character r -> twisted toric sheaf -> Frobenius trace -> coefficient sequence b_r.
```

Equivalently, r indexes a multiplicative character twist, while z indexes the deformation parameter of the Picard-Fuchs family. They should not be identified as z = 1/Lambda(x).

## (C) Small-prime computation

Using the Apéry recurrence

```
(n+1)^3 b_{n+1} = (2n+1)(17n^2+17n+5)b_n - n^3 b_{n-1}
```

modulo p, the values are:

| p | |Z_p| |
|---|---:|
| 5 | 2 |
| 7 | 0 |
| 11 | 2 |
| 13 | 0 |
| 17 | 2 |
| 19 | 2 |
| 23 | 0 |
| 29 | 2 |
| 31 | 2 |

Mean:

```
(2+0+2+0+2+2+0+2+2)/9 = 12/9 = 1.333...
```

The sample is too small and strongly parity-biased. The larger computation to p <= 100000 gives approximately

```
E |Z_p| ~= 1.
```

which agrees with the empirical law

```
|Z_p|/2 ~ Poisson(1/2).
```

## (D) Why palindromic symmetry is not enough

The objection is correct. The symmetry

```
b_r = 0  <=>  b_{p-1-r} = 0
```

only forces pairing. It changes the parity distribution but does not increase the expected number of zeros.

The missing factor is more plausibly from the arithmetic realization of the Apéry family. Several possibilities remain:

1. The relevant monodromy for the zero statistic is not the generic USp(4) distribution.
2. The toric moment has additional self-dual constraints.
3. The rank-4 representation is not the only cohomological contribution controlling b_r mod p.
4. The trace-zero event is correlated across twists r because the family is a one-parameter Kummer orbit, not independent Haar samples.

A useful analogy is that a random matrix trace model captures the marginal distribution of a single trace but not necessarily the distribution of zeros in an arithmetic family.

## (E) Central binomial comparison

The central binomial example confirms the limitation of the random-matrix heuristic.

For C(2r,r), the object has finite/solvable monodromy. The finite group produces strong arithmetic resonance. Therefore a Haar U(1) model gives the wrong prediction:

```
f_U(1)(0)=1/2
```

but the actual zero set is approximately

```
|Z'_p| ~= (p-1)/2.
```

This is not a small normalization error. It is a failure of the independence/Haar model caused by finite monodromy.

## Conclusion

The current best interpretation is:

* The USp(4) density 2/pi is the correct generic rank-4 Haar prediction.
* The Apéry zero statistic is not governed only by that rank-4 Haar distribution.
* b_r is a toric moment/Kummer family trace, not directly a normalized Frobenius trace.
* The empirical mean 1 is evidence of extra arithmetic structure, not a missing factor in normalization.
* A complete explanation likely requires the monodromy of the full Kummer-twisted toric family rather than the Picard-Fuchs monodromy alone.

The next decisive computation would be to explicitly identify the Kummer sheaf decomposition of the Laurent polynomial Lambda and compute the geometric monodromy of the r-twist family. That is the object whose trace-zero density should match the observed mean 1.
