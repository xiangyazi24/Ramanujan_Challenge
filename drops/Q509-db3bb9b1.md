# Q509 — Chen–Stein for the dyadic Apéry hit count

## Executive verdict

The proposed singleton-neighborhood argument does **not** establish the needed independence. The phrase

```text
given m mod q for every q != p, the residue m mod p remains free
```

is true when `m` is sampled uniformly from a **complete CRT period**. It is false when `m` is sampled from the short interval `[0,X^2)`. In fact, the residues modulo all the other primes determine `m` uniquely on that interval, because their product is much larger than `X^2`.

There are then two separate conclusions.

1. Under the empirical hypothesis that `|Z_p|=O(1)` on average, so that
   
   ```text
   lambda_X = sum_{X<p<=2X} |Z_p|/p ~ 1/log X -> 0,
   ```
   
   the law of `K_X(m)` for uniform `m<X^2` **does** converge in total variation to `Poisson(lambda_X)`—but this is nearly vacuous. Both distributions converge to the point mass at zero. One can prove this without any independence at all.

2. Total-variation Poisson convergence does **not** imply `(HM)_k`. The falling factorial `(K)_k` is an unbounded test function whose maximum grows like the number of primes in the block. A set of only one exceptional row among `X^2` rows is invisible in total variation but can dominate the third and higher factorial moments.

The repository already contains an exact counterexample of this type: the anchored rainbow star in [`problems/3.2/hm3_result.tex`](https://github.com/xiangyazi24/Ramanujan_Challenge/blob/main/problems/3.2/hm3_result.tex). Its distribution is total-variation close to a small-mean Poisson law, its second factorial moment has the natural size, yet its third factorial moment exceeds the `(HM)_3` scale by a factor `X^{1-o(1)}`.

Thus the answer is:

> **Chen–Stein in total variation is too weak for P3.2. The missing theorem is not ordinary Poisson convergence, but uniform integrability / Poisson factorial-moment control of the upper tail. In the repository’s language, that is exactly the pair-Palm or atom-tail problem.**

Finally, even a proof of `(HM)_3` alone would not close the all-`n` conjecture through the current pointwise theorem. The repository proves that `(HM)_k` gives

```text
log G_n << n^(2/3 + 2/k + o(1))
```

for every `n`; one needs `k>6` for an exponent below one. Genuine Poisson factorial-moment bounds for every fixed `k` would suffice, because one could choose `k=7` or `8`. Total-variation convergence does not provide them.

## 1. The exact probability space and the correct mean

Let

```text
P_X = {p prime : X < p <= 2X},
M   = X^2,
Omega = {0,1,...,M-1},
```

and choose `m` uniformly from `Omega`. Put

```text
Omega_p = {m<M : m mod p in Z_p},
X_p(m)  = 1_{Omega_p}(m),
K(m)    = sum_{p in P_X} X_p(m).
```

The exact Bernoulli parameter is

```text
pi_p = E[X_p] = |Omega_p|/M,
```

not exactly `z_p/p`, where `z_p=|Z_p|`. For every marked residue class modulo `p`, the number of representatives below `M` differs from `M/p` by less than one, so

```text
| |Omega_p| - M z_p/p | <= z_p,
```

and hence

```text
|pi_p - z_p/p| <= z_p/M.
```

Write

```text
mu_X     = E[K] = sum_p pi_p,
lambda_X = sum_p z_p/p.
```

The finite-interval correction proved in `hm3_result.tex` is

```text
|mu_X-lambda_X|
 <= (1/M) sum_p z_p
 <= 2 lambda_X/X.
```

Thus `mu_X=(1+O(1/X))lambda_X`, but Chen–Stein should formally use `mu_X` as its Poisson parameter.

Under the empirical bounded-mean model for `z_p`,

```text
lambda_X ~ 1/log X -> 0.
```

This vanishing parameter is central: total-variation convergence to `Poisson(lambda_X)` is then a very weak statement.

## 2. Where the CRT independence argument breaks

### 2.1 Independence holds on a complete CRT period

Put

```text
Q_X = product_{p in P_X} p.
```

If `m` were uniform modulo `Q_X`, the CRT isomorphism

```text
Z/Q_X Z  ~=  product_{p in P_X} Z/pZ
```

would make the residue coordinates `m mod p` mutually independent. Consequently the indicators `X_p` would be independent Bernoulli variables with parameters exactly `z_p/p`.

In that different probability space one would have, for every fixed `k`,

```text
E[(K)_k]
 = sum_{p_1,...,p_k distinct}
   product_i z_{p_i}/p_i
 <= lambda_X^k.
```

So the complete-period model gives all factorial moments immediately. It is not the P3.2 model.

The interval `[0,M)` contains only `M=X^2` points, whereas `Q_X` is exponentially large in `X`. Under the CRT embedding, `[0,M)` is an extremely thin deterministic subset of the full product of residue spaces. Uniform measure on that thin subset is not product measure.

### 2.2 The residues modulo the other primes determine `m`

Fix `p in P_X` and let

```text
Q_{-p} = product_{q in P_X, q != p} q.
```

For all sufficiently large `X`, `Q_{-p}>M`. If `m,m'<M` have

```text
m = m' mod q  for every q != p,
```

then `Q_{-p}` divides `m-m'`. Since `|m-m'|<M<Q_{-p}`, one must have `m=m'`.

Therefore the map

```text
m -> (m mod q)_{q != p}
```

is injective on `[0,M)`. Conditioning on all the other **residues** determines `m`, and hence determines `m mod p` and `X_p` as well. This is the opposite of conditional independence.

The Chen–Stein term `b_3` conditions only on the other **indicators**, which is a coarser sigma-field than all the residues. But coarsening does not create an independence theorem. It merely means that the exact conditional law is harder to describe.

### 2.3 Pairwise independence already fails

For distinct `p,q in P_X`, let

```text
J_{p,q} = |Omega_p intersect Omega_q|.
```

Because `pq>M`, every pair `(a,b) in Z_p x Z_q` has at most one representative below `M`. Thus

```text
J_{p,q}
 = sum_{a in Z_p} sum_{b in Z_q}
   1_{CRT_{p,q}(a,b)<M}.
```

Hence

```text
E[X_p X_q] = J_{p,q}/M.
```

Independence would require

```text
J_{p,q}/M = pi_p pi_q.
```

There is no such identity. For a fixed residue pair, the left side is either `0` or `1/M`, while the product-model prediction is approximately `1/(pq)`. The aggregate second-moment theorem controls the sum of these discrepancies; it does not make each pair independent.

This same short-interval CRT discrepancy is precisely what becomes the triple obstruction in `(HM)_3`.

## 3. What happens to the Chen–Stein terms

Use the Arratia–Goldstein–Gordon notation with

```text
W = K = sum_p X_p,
E[X_p] = pi_p,
E[W] = mu_X.
```

For neighborhoods `B_p={p}`, one has

```text
b_1 = sum_p pi_p^2,
b_2 = 0,
b_3 = sum_p E | E[X_p-pi_p | sigma(X_q:q!=p)] |.
```

See Arratia–Goldstein–Gordon, [*Two Moments Suffice for Poisson Approximations: The Chen–Stein Method*](https://doi.org/10.1214/aop/1176991491), and their survey [*Poisson Approximation and the Chen–Stein Method*](https://doi.org/10.1214/ss/1177012015).

### 3.1 `b_1` is small

If `z_p=O(1)` on average, then `pi_p` has size `1/X` and there are `asymp X/log X` primes. Thus

```text
b_1 = O(1/(X log X)).
```

The coarser estimate `O(1/X)` in the question is harmless, but the logarithm is available.

### 3.2 `b_3` is not zero

The assertion `b_3=0` is exactly the false conditional-independence claim. To have `b_3=0`, one needs

```text
E[X_p | sigma(X_q:q!=p)] = pi_p
```

almost surely for every `p`. Coprimality of the moduli does not imply this under uniform measure on `[0,M)`.

There is, however, a trivial bound:

```text
E | E[X_p-pi_p | F] |
 <= E|X_p-pi_p|
 = 2 pi_p(1-pi_p)
 <= 2 pi_p.
```

Therefore

```text
b_3 <= 2 mu_X.
```

If `mu_X->0`, this already implies `b_3->0`. So even the singleton-neighborhood theorem can yield total-variation convergence, but for a completely uninformative reason: all successes are rare in aggregate.

### 3.3 A valid complete-neighborhood application

One can instead choose

```text
B_p = P_X
```

for every `p`. Then the outside sigma-field is trivial, so `b_3=0` legitimately. The other terms become

```text
b_1 = sum_p sum_q pi_p pi_q = mu_X^2,
```

and

```text
b_2
 = sum_p sum_{q!=p} E[X_p X_q]
 = E[(K)_2]
 = (1/M) sum_{m<M}(K_X(m))_2.
```

The repository proves

```text
sum_{m<M}(K_X(m))_2 <= 4 M lambda_X^2
```

in [`problems/3.2/pairpalm_result.tex`](https://github.com/xiangyazi24/Ramanujan_Challenge/blob/main/problems/3.2/pairpalm_result.tex) (the earlier harmless constant was `5`). Hence, under the quoted simple Chen–Stein bound,

```text
d_TV(Law(K_X), Poisson(mu_X))
 << mu_X^2 + lambda_X^2
 << lambda_X^2.
```

If `lambda_X~1/log X`, this tends to zero.

This is a correct Chen–Stein consequence of the proved second moment. It still does not imply `(HM)_3`.

## 4. Total-variation Poisson convergence is almost automatic here

Let `Y_X` have the Poisson distribution with mean `mu_X`. By the triangle inequality through the point mass `delta_0`,

```text
d_TV(Law(K_X),Law(Y_X))
 <= d_TV(Law(K_X),delta_0)
    + d_TV(delta_0,Law(Y_X)).
```

Now

```text
P(K_X>0) <= E[K_X] = mu_X
```

by Markov, while

```text
P(Y_X>0)=1-e^{-mu_X} <= mu_X.
```

Therefore

```text
boxed:
d_TV(Law(K_X),Poisson(mu_X)) <= 2 mu_X.
```

No independence, CRT, recurrence, trace function, or second moment is needed.

Thus, once `mu_X->0`, the statement

```text
K_X(m) is asymptotically Poisson in total variation
```

is nearly equivalent to saying that both laws concentrate at zero. It does not assert the Poisson-sized probabilities of the rare events `K_X=3,4,...` with the precision needed for factorial moments.

This is a standard degeneration issue: convergence in distribution to a law whose parameter itself tends to zero can hide arbitrary behavior on events of vanishing probability.

## 5. Why total variation does not imply `(HM)_k`

The factorial-moment hypothesis is

```text
sum_{m<M}(K_X(m))_k
 << M X^{o(1)} lambda_X^k.
```

Equivalently, for uniform `m<M`,

```text
E[(K_X)_k] << X^{o(1)} lambda_X^k.
```

A Poisson variable of mean `mu_X` has exact factorial moment

```text
E[(Y_X)_k] = mu_X^k.
```

But total variation controls expectations only for bounded test functions. The test

```text
h(k)=(k)_j
```

has size up to approximately

```text
L_X^j,
qquad L_X=|P_X| asymp X/log X.
```

If

```text
d_TV(Law(K_X),Poisson(mu_X)) = delta_X,
```

then the crude implication is only

```text
E[(K_X)_j]
 <= mu_X^j + O(L_X^j delta_X).
```

Consequently, to recover `(HM)_j` from total variation alone, one would need roughly

```text
delta_X
 <= X^{o(1)} (lambda_X/L_X)^j.
```

Under `lambda_X~1/log X` and `L_X~X/log X`, this is

```text
delta_X <= X^{-j+o(1)}.
```

For `j=3`, one would need a rate close to `X^{-3}`, not merely `o(1)`, `1/log X`, or even the independent-Bernoulli Le Cam scale `1/(X log X)`.

This rate calculation is not saying that independence would be insufficient: under actual independence one computes factorial moments directly. It says that **passing only through total variation discards precisely the upper-tail information that P3.2 needs**.

## 6. The repository’s anchored-star counterexample is decisive

The proposition “An anchored rainbow star with bounded codegrees” in [`hm3_result.tex`](https://github.com/xiangyazi24/Ramanujan_Challenge/blob/main/problems/3.2/hm3_result.tex) constructs zero sets `Z_p^*` with all of the following properties:

- every nonempty `Z_p^*` has size two;
- reflection symmetry holds;
- endpoint and consecutive-zero exclusions hold;
- the same interval sparsity used for genuine Apéry zeros holds;
- the universal second factorial-moment bound holds;
- the centered second moment has the natural scale;
- row codegrees are uniformly bounded;
- the existing bounded-fiber and collision-energy consequences can also be imposed.

Nevertheless there is one row `m_0<X^2` hit by essentially every active prime. If

```text
L_X asymp X/log X
```

is the number of active primes, then

```text
K_X^*(m_0)=L_X,
```

and

```text
E[(K_X^*)_3]
 >= (L_X)_3/M
 asymp X/(log X)^3.
```

On the other hand,

```text
mu_X^* asymp 1/log X,
(mu_X^*)^3 asymp 1/(log X)^3.
```

Thus the third factorial moment is too large by a factor `asymp X`.

Yet its law is total-variation close to `Poisson(mu_X^*)`, because

```text
d_TV(Law(K_X^*),Poisson(mu_X^*))
 <= 2 mu_X^*
 -> 0.
```

This gives the exact logical counterexample sought here:

```text
Poisson convergence in total variation
+ correct first moment
+ correct second factorial-moment scale

DOES NOT IMPLY (HM)_3.
```

The obstruction is a vanishingly rare but extremely large atom. Total variation sees its probability, about `1/M`, but the third moment multiplies that probability by `L_X^3`.

## 7. The Stein identity reveals the exact missing stronger statement

For `Y~Poisson(mu)`, Stein’s identity is

```text
E[mu f(Y+1)-Y f(Y)] = 0.
```

The usual total-variation theorem solves the Stein equation for bounded indicator test functions. To access factorial moments, one must instead insert an unbounded polynomial test.

Take

```text
f_j(w)=(w-1)_{j-1}.
```

Then

```text
w f_j(w)       = (w)_j,
mu f_j(w+1)    = mu (w)_{j-1}.
```

Hence the relevant Stein discrepancy is

```text
E[(K)_j]-mu E[(K)_{j-1}].
```

For `j=3`, this is

```text
E[(K)_3]-mu E[(K)_2].
```

Controlling this polynomial-test discrepancy at scale `O(lambda_X^3)` would prove `(HM)_3`, because `(HM)_2` is already known. But estimating it requires exactly the conditional third-prime overload that the repository isolates.

Indeed, define

```text
J_{p,q}=|Omega_p intersect Omega_q|,
T_{p,q}=sum_{m in Omega_p intersect Omega_q}
        sum_{ell notin {p,q}} X_ell(m),
lambda_{p,q}=sum_{ell notin {p,q}} z_ell/ell.
```

Then [`hm3_result.tex`](https://github.com/xiangyazi24/Ramanujan_Challenge/blob/main/problems/3.2/hm3_result.tex) proves exactly

```text
sum_{p!=q} T_{p,q}
 = sum_{m<M}(K_X(m))_3,
```

and `(HM)_3` is equivalent to

```text
sum_{p!=q}
  (T_{p,q}-J_{p,q}lambda_{p,q})_+
 << M X^{o(1)} lambda_X^3.
```

Thus an unbounded-test Chen–Stein attack does not make the missing correlation disappear. It lands on the already identified pair-Palm theorem.

## 8. What form of “Poisson convergence” would actually imply all `(HM)_k`?

Any one of the following would be sufficient.

### 8.1 Direct factorial-moment convergence

For every fixed `k`, prove uniformly in dyadic `X` that

```text
E[(K_X)_k] <= X^{o(1)} lambda_X^k.
```

This is precisely `(HM)_k`.

### 8.2 Uniform exponential-moment control

Prove for some fixed `theta>0` a bound of the form

```text
E[(1+theta)^{K_X}]
 <= exp(X^{o(1)} theta lambda_X).
```

Expanding the factorial generating function

```text
E[(1+z)^{K_X}]
 = sum_{k>=0} E[(K_X)_k] z^k/k!
```

would control every fixed factorial moment. This is much stronger than total variation.

### 8.3 A Poisson upper-tail estimate uniform in the tail parameter

For example, a bound comparable to

```text
P(K_X>=t)
 <= X^{o(1)} (e lambda_X/t)^t
```

through the range of `t` that can contribute to the desired moments would yield uniform integrability. Fixed-`t` convergence alone is insufficient.

### 8.4 The project’s atom-tail / maximum-row condition

The elementary inequality

```text
sum_m (K_X(m))_k
 <= (max_m K_X(m))^{k-2}
    sum_m (K_X(m))_2
```

shows that a pointwise estimate of the form

```text
max_m K_X(m)
 <= lambda_X X^{o(1)}
```

combined with `(HM)_2` gives every fixed `(HM)_k`. This is the repository’s atom-tail collapse. It is exactly the kind of uniform-integrability input that total variation lacks.

## 9. Gap between “Poisson for most `m`” and the all-`n` statement

There are two distinct gaps.

### 9.1 Rare exceptional rows

A statement such as

```text
for every fixed t,
# {m<M : K_X(m)=t}/M
 = Poisson_{lambda_X}(t)+o(1)
```

allows one exceptional row at every scale. One row has density `1/X^2`, hence is invisible in the limiting distribution. But if that row has

```text
K_X(m) asymp X/log X,
```

it can dominate every factorial moment of order at least three and can be the row corresponding to a pointwise integer `n` that the all-`n` theorem must control.

The all-`n` conjecture is therefore an anti-exceptional-set theorem, not merely an almost-all theorem.

### 9.2 `(HM)_3` is not yet a high enough moment for the current pointwise deduction

The theorem in [`problems/3.2/proof.tex`](https://github.com/xiangyazi24/Ramanujan_Challenge/blob/main/problems/3.2/proof.tex) states that one fixed `(HM)_k` gives

```text
log G_n << n^(2/3+2/k+o(1))
```

for every `n`. Therefore:

```text
k=3 gives exponent 4/3,   not a saving;
k=6 gives exponent 1,     still not o(n);
k>=7 gives exponent <1,   and closes the all-n asymptotic.
```

So even a complete proof of `(HM)_3` would be a major structural advance but would not, by itself, close P3.2 through the current theorem. A genuine Poisson factorial-moment theorem for all fixed orders would close it by choosing `k=7` or `8`.

If such a deterministic uniform theorem held for every sufficiently large dyadic `X`, then finite computation could cover any explicitly excluded finite range. But finite computation cannot repair a theorem that controls only a density-one set or only total variation while allowing infinitely many sparse exceptional rows.

## 10. Direct answers to the question

### Does `B_p={p}` give `b_3=0`?

**No.** On `[0,X^2)`, the residue coordinates are not under product measure. Conditioning on all other residues actually determines `m`; conditioning on all other indicators is coarser but is not independent. The CRT independence statement applies only to uniform measure on a complete product period.

### Does Chen–Stein nevertheless prove total-variation Poisson convergence?

**Conditionally yes, but vacuously.** If the empirical bounded-mean zero-count law implies `lambda_X->0`, then

```text
d_TV(Law(K_X),Poisson(mu_X)) <= 2mu_X ->0
```

without any independence. Using the full dependency neighborhood and the proved `(HM)_2` improves the formal bound to `O(lambda_X^2)`.

Under the currently proved worst-case bound `Z(p)<<p^{2/3}`, one does not know that `lambda_X->0`; the small-mean conclusion itself still uses unproved average information about `Z(p)`.

### Does total-variation Poisson convergence imply `(HM)_k` for all `k`?

**No.** It controls bounded events, not the unbounded factorial tests `(K)_k`. The anchored-star construction is an explicit repository-level counterexample: total variation tends to zero while `(HM)_3` fails by a factor `X^{1-o(1)}`.

### What additional statement would imply `(HM)_k`?

One needs factorial-moment convergence, an exponential-moment bound, a Poisson tail bound uniform far into the upper tail, or the project’s atom-tail/maximum-row estimate. In Stein language, one must control polynomial test functions, and that is equivalent to the pair-Palm correlation problem already isolated in the repository.

### Would this close the all-`n` P3.2 theorem?

- Mere total-variation Poisson convergence: **no**.
- `(HM)_3` alone via the current pointwise theorem: **no**.
- Uniform `(HM)_k` for one fixed `k>6`: **yes**.
- Poisson factorial-moment bounds for every fixed `k`: **yes**, by choosing `k=7` or `8`.
