# 4. Dyadic occupancies and higher moments: where the formal route stops

The question asks specifically whether the dyadic occupancies `C_J` can be
pushed through higher moments or Nash interpolation.  There is a basic
obstruction that must be separated from any genuinely new moment theorem.

On a dyadic layer

\[
D\le C_J<2D,
\]

for every `r>s>=0`,

\[
D^{r-s}\sum_J C_J^s
\le
\sum_J C_J^r
\le
(2D)^{r-s}\sum_J C_J^s.
\tag{4.1}
\]

Consequently, once one has conditioned on `C_J\asymp D`, replacing a second
moment by a third, fourth, or fractional moment using only the pointwise
bound `C_J\asymp D` merely inserts the corresponding power of `D`.  It is
not an additional arithmetic saving.

In particular, a proposed argument of the form

```text
use Cauchy/Hölder on the D-layer;
bound the new higher moment by (2D)^(r-2) times the old energy;
interpolate back
```

is circular at power precision: (4.1) returns the same dyadic exponent.

A genuinely useful higher-moment argument would therefore need a **new
source theorem** whose `P` exponent is smaller than the trivial dyadic
consequence of CC2q37.  No such theorem is present among the committed
Problem 3.2 inputs I can read.

## 4.1 Why ordinary Nash does not manufacture the missing theorem

\sum_J|C_{J+1}-C_J|^2

Neither offset uniqueness nor the committed actual-gap theorem implies a
power-saving bound for that Dirichlet form.  Thus applying Nash with a

# 6. Offset uniqueness is not one-per-block packing

Offset uniqueness is useful for avoiding an extra multiplicity once a
record and its offset are fixed.  It does not imply that only one record or
one transverse pair may occupy a common-prefix cell.

A minimal incidence model demonstrates the logical gap.  In one cell take
`D` left records and `D` right records indexed by `Z/DZ`.  For every offset
`t` connect left record `i` to right record `i+t`.  Then:

- for fixed `(i,t)` the right endpoint is unique;
- for fixed `(j,t)` the left endpoint is unique;
- the graph is simple for each offset;
- nevertheless the cell contains `D^2` ordered incidences when all offsets
  are allowed.

So uniqueness of the **solution for a fixed offset** cannot be promoted to
one-per-block packing unless the source separately proves that only one
(or `P^{-theta}D`) offsets survive in the literal selected set.  The current
committed source contains no such theorem for CC2q37.

This is exactly the assumption the question forbids, and I do not use it.

# 7. Resultants and subresultants do not control the required actual multiplicity

There are two separate issues.

## 7.1 Nonzero support is not actual-root multiplicity

Root-strip separation can prove that an integer resultant is nonzero.  A
selected prime supporting a common polynomial root then divides that
resultant.  But `E_D` is an actual selected-edge multiplicity statistic.
A prime that divides one resultant may support many actual roots, and an
algebraic common root counted by a resultant may fail to be an actual Apéry
zero altogether.

The committed `lem:qc-fd`/following audit provides explicit primitive,
off-center common-root phantoms.  Therefore a support bound cannot be
substituted for the actual root multiplicity in CC2q37.

## 7.2 Subresultant corank is only linear in the gcd degree

If two degree-`O(H)` polynomials have gcd degree `g` modulo `p`, the Sylvester
matrix has corank `g`; equivalently the appropriate first `g`
subresultants/minors vanish modulo `p`.  The resulting generic determinant
or Smith divisibility is of order

\[
p^{O(g)},
\]

not automatically

\[
p^{\Omega(g^2)}.
\]

Meanwhile the standard resultant heights in the current mesoscopic range
are quadratic in the polynomial degrees (up to logarithms).  A linear
`g log p` divisor charge against an `O(H^2 log P)` height therefore permits
`g` on the ordinary degree scale.  It gives no fixed `P^{-theta}` saving in
the CC2q37 occupancy energy.

To improve this route one would need a new theorem coupling **actual
selected roots** to a stronger Smith-minor valuation/moment.  Ordinary
nonzero-resultant height is insufficient.
