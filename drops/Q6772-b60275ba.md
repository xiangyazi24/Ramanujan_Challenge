# Q63 scattered extremal re-emit (with NO-RUN retraction adjustment)

## Executive verdict

The scattered-padding adversary survives. The previous q63 conclusion that NO-RUN was insufficient remains the correct abstract extremal verdict, but the reason must be stated more carefully: the candidate NO-RUN input is no longer available as an arithmetic theorem. The supplied status update has been retracted because the proposed companion action identity xi_{r+1}=M_r xi_r is false (counterexample p=997,r=248,d=182). Therefore one cannot use the claimed run-rigidity mechanism as an Apery input.

Even granting an abstract NO-RUN axiom, scattered padding still survives. Without NO-RUN, the conclusion is only stronger: the word/clique constraints leave at least as much room.

## (i) Scattered padding

A scattered construction exists under the abstract constraint set.

Choose gaps d in (D/2,D]. For each d choose a sparse set Z_d of starting points. Respect the degree budget by taking |Z_d| <= 3(d-1). Spread the points so that each individual Z_d has no local interval concentration. Assign every pair (r,r+d) a private color.

Then:

- every collision is a two-point fiber;
- primitive count k_r=1 is maximized;
- clique constraints are satisfied because each color class has size two;
- reflection symmetry is imposed by adding reflected pairs;
- C_d degree budgets are respected.

There are Theta(D) gap values and each gap has Theta(D) available placements, so the total abstract capacity is Theta(D^2). Since D=sqrt(N)L, this is much larger than N. Hence one can select Theta(N) primitive pairs.

The hostile check is the 2/3 window law. It does not obstruct this construction. The law bounds the multiplicity of a fixed fiber in an interval. Private colors make every fiber multiplicity at most two. Dense occupation of positions by many different colors is invisible to that constraint.

The triangle contribution can remain O(D^2 log D) by taking the scattered layer triangle-free and attaching only the allowed small triangle-rich component. Thus the abstract model still permits P_D=Theta(N) while P_D Q_D/N^2 diverges.

Conclusion for (i): scattered padding exists. Any proof of break-3/2 must use an arithmetic statement beyond word/clique constraints and beyond local run information.

## (ii) Candidate extra seeds

### (a) NO-RUN

Fails even as a hypothetical abstract condition. It only forbids consecutive positions inside one fixed Z_d. Scattered padding distributes the primitive mass among many gap classes.

The later retraction is important: the proposed Apery proof of NO-RUN is not valid because the assumed companion action relation is false. Therefore NO-RUN should not currently be treated as an available arithmetic seed.

### (b) Gap regularity

Assume a spacing condition inside each Z_d:

|x-y| >= g(d).

Then

|Z_d| <= 1 + D/g(d).

Summing over d <= D gives

P_D <= sum_d (1+D/g(d)).

A power spacing g(d)>=d^alpha yields

P_D << D^(2-alpha),

which is a power saving over the degree-sum D^2. This would imply the FR_eta type estimate.

This is stronger than NO-RUN and asks for genuine repulsion of roots of the same gap polynomial.

### (c) Additive energy

A bound only on each individual Z_d is not enough. The adversary can make every Z_d sparse and low-energy while distributing mass over many d.

A useful statement would need a summed or cross-gap form, not merely E(Z_d).

### (d) Cross-gap rigidity

This directly targets the obstruction.

A condition such as

|Z_d intersect (Z_{d'}+t)| << 1

uniformly for d != d'

prevents hidden reuse of endpoints across different gaps. This is the first candidate that sees the scattered construction itself.

It would convert the clique graph from potentially dense to nearly a linear-incidence graph, allowing triangle counts to be bounded by primitive edge counts instead of by the S_D^(3/2) estimate.

## (iii) Minimal seed S*

The minimal useful seed is a quenched growing-gap cross-correlation statement.

One suitable formulation is:

For d,d' in a dyadic gap range and every shift t,

sum_{d,d'} |Z_d intersect (Z_{d'}+t)| <= D^(3-eta).

This is a family-level anti-coexistence statement.

Proof sketch:

1. Primitive collisions are edges partitioned by gap classes.
2. The only way to realize the extremal scattered construction is to make many gap classes coexist without creating many constrained intersections.
3. Cross-correlation bounds prevent this coexistence.
4. The number of 2-paths and triangles drops from the clique worst case to near-linear scale.
5. The resulting incidence estimate forces P_D below the dangerous regime.

The candidate hierarchy is:

NO-RUN < gap regularity < additive-energy control < cross-gap rigidity.

The likely Apery mechanisms differ:

- Consecutive-position statements could come from transfer identities only if the underlying action relation is correctly formulated.
- Gap regularity might come from restart/zero-spacing arguments.
- Additive energy needs arithmetic control of root-set correlations.
- Cross-gap rigidity needs a new mechanism: a family-averaged monodromy/cocycle correlation theorem, not a fixed-gap spectral theorem.

## Confidence and blind spot

Least confident step: the exact quantitative implication from a proposed cross-gap S* statement to P_D Q_D=o(N^2). The qualitative direction is clear, but the sharp incidence inequality still needs a complete proof.

Blind spot in the question: it assumes the only missing arithmetic is a visible combinatorial rigidity of the sets Z_d. The true obstruction may instead be a global property of the Apery cocycle preventing private-color-like fiber behavior altogether. Such a constraint is invisible in the abstract extremal model.
