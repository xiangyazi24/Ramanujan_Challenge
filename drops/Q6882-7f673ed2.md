# Fixed-prime Apéry ATB audit

## Verdict

The double-orthogonality identity is correct, with one important qualification: the one-frequency terms must be the **boundary-weighted** counts on the physical three-point triangle. They are not exactly `(D-a)R_a` and `(D-g)R_g` unless one deliberately extends by zero outside the physical interval and keeps the resulting weights.

With the correct definitions,

```text
Q_D = ATB_p(D) + (W_1(D)+W_2(D))/p - |T_D|/p^2.
```

Reflection gives an exact involution

```text
(r,a,g) <-> (p-1-r-a-g,g,a),
```

so it swaps the two sequential gaps and implies `W_1=W_2`; it does not preserve an individual `(a,g)` stratum. The centered parity law gives an exact conjugate phase pairing, hence `ATB_p(D)` is real, but it gives no sign cancellation.

I do not obtain any unconditional unbounded `W` from the currently banked Apéry inputs. The four suggested mechanisms fail for distinct sharp reasons:

```text
TT*:                 controls an L2 norm of a two-dimensional histogram,
                     while ATB is one distinguished cell; even the ideal
                     random benchmark loses a full factor p.

Twisted symplectic:  is automatic for every 2x2 cocycle and therefore does
                     not distinguish the Apéry orbit from abstract words.

Parity/reflection:   removes or identifies only an O(D) fixed skeleton and
                     pairs all remaining phases with their conjugates.

Exact phase pairing: proves reality, not negativity; the fixed phase orbits
                     contribute +1 rather than cancel.
```

There is also a sharp countermodel. A reflected version of the packed sparse-progression word already proved in `chatgpt-answers/Q6638-cf61b0fd.md` satisfies, after harmless constant thinning,

```text
R_h <= 3h,
no consecutive returns,
max window multiplicity << D^(1/2) <= 4D^(2/3),
reflection symmetry,
Q_D >= c D^2,
word length O(D^(3/2)).
```

For `D=sqrt(p)L`, `L=o(p^(1/6))`, it embeds in length `p+O(1)` and has

```text
ATB_p(D) = Q_D + o(D^2) >= c' D^2.
```

Thus no estimate `ATB_p^+(D) << D^2/W` with `W -> infinity` can follow from the present zero-count, restart, reflection, parity, window-multiplicity, or generic symplectic data. Any winning argument must use arithmetic special to the actual Apéry continuants, not merely those structural consequences.

The smallest concrete new arithmetic lemma I recommend is a **regular triangular common-factor sparsity theorem**. After removing all boundary/cut factors, let

```text
G^reg_{a,g,p}(X)
  = the regular part of gcd_Fp[X](N_a(X), N_g(X+a)).
```

It would suffice to prove, for `D=sqrt(p)L`,

```text
sum_{a,g>=1, a+g<=D} deg G^reg_{a,g,p} << p/omega(p),
omega(p) -> infinity.                                  [REG-GCD-TRIANGLE]
```

This is not a large-sieve hypothesis. It is a quenched common-factor theorem for the specific Apéry continuants and can be attacked through the exact addition law, the shifted resultant factorization, and saturated subresultants. It immediately gives `Q_D=o(p)`.

```text
d_D(r)=sum_{1<=h<=D} I(r,h),
```

```text
T_D = {(r,a,g):
```

## 2. Exact sequential-return identity

For `a,g>=1`, define the physical sequential count

```text
rho(a,g)
 = #{r:
       (r,a,g) in T_D,
       N_a(r)=0,
       N_g(r+a)=0}.
```

A pair of returns from one base has unique ordered lags

```text
0<h_1<h_2<=D.
```

Set

```text
a=h_1,
g=h_2-h_1.
```

Then

```text
pi(r)=pi(r+a)=pi(r+a+g),
```

and conversely every such triple gives one pair of returns from `r`. Hence

```text
Q_D = sum_{a,g>=1, a+g<=D} rho(a,g).         (2.1)
```

The Apéry addition law makes this a genuine restart identity. In the regular physical triangle,

```text
N_{a+g}(r)
 = N_g(r+a)N_{a+1}(r)
   - (r+a+1)^6 N_{g-1}(r+a+1)N_a(r).        (2.2)
```

At a return `N_a(r)=0`, adjacent coprimality/no consecutive projective values gives

```text
N_{a+1}(r) != 0.
```

Therefore

```text
N_a(r)=0  =>
[N_{a+g}(r)=0 <=> N_g(r+a)=0].              (2.3)
```

Equation (2.1), however, needs only projective transitivity; it does not require (2.2).

## 3. Double orthogonality, including the physical boundary

Let

```text
e_p(x)=exp(2*pi*i*x/p),
K_p(x)=sum_{u in F_p^*} e_p(ux).
```

Then

```text
K_p(x)=p*1_{x=0}-1.                          (3.1)
```

For `(r,a,g) in T_D`, put

```text
X(r,a,g)=N_a(r),
Y(r,a,g)=N_g(r+a).
```

Define the both-nonzero-frequency term

```text
ATB_p(D)
 = (1/p^2)
   sum_{u,v in F_p^*}
   sum_{(r,a,g) in T_D}
     e_p(uX(r,a,g)+vY(r,a,g)).               (3.2)
```

Define the two physical one-zero counts

```text
W_1(D)=sum_{(r,a,g) in T_D} 1_{X(r,a,g)=0},
W_2(D)=sum_{(r,a,g) in T_D} 1_{Y(r,a,g)=0}.  (3.3)
```

Using (3.1),

```text
ATB_p(D)
 = (1/p^2) sum_{T_D} K_p(X)K_p(Y)
 = Q_D - (W_1+W_2)/p + |T_D|/p^2.           (3.4)
```

Rearranging gives the claimed identity:

```text
Q_D
 = ATB_p(D) + (W_1(D)+W_2(D))/p - |T_D|/p^2. (3.5)
```

### 3.1 The exact boundary weights

The first term is not exactly `sum_a (D-a)R_a`, because a collision ending near `M` has fewer possible second gaps. Explicitly,

```text
W_1(D)
 = sum_{a=1}^{D-1}
   sum_{r=1}^{M-a}
     I(r,a) * min(D-a, M-r-a).               (3.6)
```

Here the minimum is zero when no positive `g` is physically available.

For `W_2`, set `s=r+a`. Then

```text
W_2(D)
 = sum_{g=1}^{D-1}
   sum_{s=2}^{M-g}
     I(s,g) * min(D-g, s-1).                 (3.7)
```

Thus the safe bounds are

```text
W_1(D) <= sum_{a<D}(D-a)R_a <= D S_D,
W_2(D) <= sum_{g<D}(D-g)R_g <= D S_D.        (3.8)
```

Any formula without the minima is either an upper bound or is using an explicit zero extension outside the physical interval.

### 3.2 Centered covariance form

Put

```text
z(x)=1_{x=0}-1/p.
```

Then (3.4) is equivalently

```text
ATB_p(D)
 = sum_{(r,a,g) in T_D} z(N_a(r))z(N_g(r+a)). (3.9)
```

So `ATB` is exactly the centered two-return covariance on the physical sequential triangle. The Fourier notation does not soften the zero-correlation problem; after summing the frequencies, it is the same problem in centered coordinates.

## 4. Reflection and parity audit

The reflection-stable physical interval is `1<=r<=p-2`, with

```text
r <-> p-1-r.
```

The gap-polynomial reflection law is

```text
N_h(p-1-h-r)=(-1)^(h+1) N_h(r) mod p.        (4.1)
```

Equivalently, in the centered variable `s=2r+h+1`, `N_h` is odd in `s` for even `h` and even in `s` for odd `h`. In particular, even `h` has the forced mirror root

```text
r=(p-1-h)/2.                                  (4.2)
```

### 4.1 Reflection of a sequential triple

Define

```text
tau(r,a,g)=(p-1-r-a-g, g, a).                (4.3)
```

If `(r,a,g) in T_D`, then `tau(r,a,g) in T_D`; the physical inequalities are preserved exactly. The three positions

```text
r < r+a < r+a+g
```

are reflected and reversed. If

```text
X=N_a(r),
Y=N_g(r+a),
epsilon_h=(-1)^(h+1),
```

then

```text
X(tau)=N_g(p-1-r-a-g)=epsilon_g Y,
Y(tau)=N_a(p-1-r-a)=epsilon_a X.             (4.4)
```

Consequences:

```text
1. tau swaps the (a,g) and (g,a) strata;
2. tau swaps the events X=0 and Y=0;
3. therefore W_1(D)=W_2(D) exactly.           (4.5)
```

One must not claim that reflection preserves a fixed ordered pair `(a,g)` unless `a=g`.

### 4.2 Fixed reflection skeleton

A triple is fixed by `tau` only when

```text
a=g,
2r+2a=p-1.                                    (4.6)
```

There are only `O(D)` such physical triples. Reflection then makes the two adjacent return conditions identical. This is a real deterministic skeleton, but it is `o(p)` at `D=sqrt(p)L`, `L=p^o(1)`, and cannot be the wall.

### 4.3 Exact phase pairing

For nonzero frequencies, define

```text
sigma_{a,g}(u,v)=(-epsilon_g v, -epsilon_a u). (4.7)
```

Using (4.4),

```text
e_p(
  sigma_1 X(tau)+sigma_2 Y(tau)
)
 = conjugate(e_p(uX+vY)).                     (4.8)
```

Thus the combined involution

```text
(r,a,g,u,v)
 <->
(tau(r,a,g), -epsilon_g v, -epsilon_a u)      (4.9)
```

pairs every phase with its complex conjugate. This proves

```text
ATB_p(D) is real.                              (4.10)
```

It does not prove cancellation. On a fixed orbit of (4.9), the phase is actually `1`, not `-1`. On a two-element orbit, the contribution is `2 Re(e_p(theta))`, with unrestricted sign.

This closes the exact-phase-pairing route: it is a reality identity, not an anti-pairing identity.

## 6. TT* audit: exact formula and sharp norm obstruction

Let

```text
nu(x,y)
 = #{(r,a,g) in T_D:
      N_a(r)=x,
      N_g(r+a)=y}.
```

Let its marginals be

```text
nu_1(x)=sum_y nu(x,y),
nu_2(y)=sum_x nu(x,y),
n=|T_D|.
```

Define the doubly centered histogram

```text
nu^o(x,y)
 = nu(x,y)-nu_1(x)/p-nu_2(y)/p+n/p^2.        (6.1)
```

Then

```text
ATB_p(D)=nu^o(0,0).                           (6.2)
```

For

```text
A(u,v)=sum_{T_D} e_p(uX+vY),
```

Fourier projection and Parseval give the exact TT* identity

```text
sum_{u,v in F_p^*} |A(u,v)|^2
 = p^2 sum_{x,y in F_p} |nu^o(x,y)|^2.        (6.3)
```

Hence the strongest direct pointwise consequence is

```text
ATB_p^+(D)
 <= ||nu^o||_2
 = (1/p)
   (sum_{u,v!=0}|A(u,v)|^2)^(1/2).            (6.4)
```

### 6.1 Why this is the wrong norm even for random data

The number of physical triples is

```text
n=|T_D| asymp pD^2.                            (6.5)
```

For an ideal random map from `T_D` to `F_p^2`, every nonzero Fourier coefficient has variance about `n`. Thus the random benchmark is

```text
sum_{u,v!=0}|A(u,v)|^2 asymp p^2 n.           (6.6)
```

Substituting into (6.4) gives only

```text
ATB_p^+(D) << sqrt(n) asymp D sqrt(p).         (6.7)
```

At `D=sqrt(p)L`, this is

```text
D sqrt(p)=pL,                                  (6.8)
```

which is worse than the desired `p/omega(p)` by the factor `L omega(p)`.

The actual random fluctuation of one cell is only

```text
sqrt(n/p^2)=D/sqrt(p)=L.                       (6.9)
```

TT* loses the full factor `p` between the L2 norm of all `p^2` cells and one specified cell. This is not an Apéry defect; it is the unavoidable norm loss of a single second-moment argument.

Equivalently, (5.6) would require

```text
sum_{u,v!=0}|A(u,v)|^2
 << p^2 D^4/W^2.                               (6.10)
```

At `D^2=pL^2` and `W=L^2 omega`, the right side is `p^4/omega^2`, whereas the random benchmark (6.6) is `p^4 L^2`. A TT* proof would need the centered Fourier energy to be smaller than random by `L^2 omega^2`, which is the opposite of what a generic mixing heuristic predicts.

Therefore a bare TT* energy cannot produce an unbounded `W`. One would need a genuinely pointwise delocalization theorem for the two-dimensional value histogram, or cancellation in the **L1 sum of Fourier coefficients** beyond what L2 sees.

## 7. Twisted symplectic determinant identity: generic, not Apéry-specific

For a `2x2` matrix `T` and

```text
J=[[0,1],[-1,0]],
```

one always has

```text
T^T J T = det(T) J.                            (7.1)
```

Thus the banked identity

```text
T_n^T J T_n = lambda_n J
```

is equivalent to the determinant normalization of the transfer matrix. It transports Casoratians and yields the determinant formula for `Delta_{r,h}`, but by itself it imposes no mixing on the projective word.

Indeed, take any finite projective word

```text
v_1,v_2,...,v_M in P^1(F_p)
```

with `v_n!=v_{n+1}`. Choose vector representatives. For any prescribed nonzero scalars `lambda_n`, one can choose `T_n in GL_2(F_p)` such that

```text
T_n v_n=v_{n+1},
det(T_n)=lambda_n.                              (7.2)
```

Then (7.1) holds exactly. Consequently every abstract no-consecutive-repeat word can be embedded in a twisted-symplectic nonautonomous cocycle.

The determinant identity therefore cannot rule out the packed clique countermodels. What is special about Apéry is not (7.1), but the rigid polynomial dependence

```text
T_n = the explicit Apéry transfer matrix at n,
```

and any winning proof must use that dependence in a way not captured by generic symplectic transport.

## 8. Parity and reflection give constants, not an unbounded saving

The parity law separates a forced mirror factor from even `h`:

```text
N_h(X)=(2X+h+1)M_h(X) for even h.              (8.1)
```

This contributes one forced collision to each even row. In `Q_D`, a forced outer mirror collision is not automatically a three-return event; the middle point must still have the same projective value. The only fully fixed three-point skeleton is (4.6), containing `O(D)` triples.

Removing all forced mirror roots changes

```text
S_D by O(D),
Q_D by at most the mirror-primitive cross term,
```

and cannot supply a factor tending to infinity. The four parity classes of `(a,g)` are permuted by the reflection/frequency involution, but multiplication of a nonzero frequency by `-1` is a bijection of `F_p^*`. Hence no parity class has fewer Fourier frequencies or an automatic negative sign.

The exact kernel makes the obstruction especially transparent:

```text
K_p(X)K_p(Y)=
  (p-1)^2       if X=Y=0,
  -(p-1)        if exactly one of X,Y is zero,
  1             if X!=0 and Y!=0.             (8.2)
```

Reflection preserves these three categories. It does not pair a double zero with a single zero. Therefore it cannot force the positive double-zero contribution to cancel.

## 9. Sharp countermodel to all currently extracted structural inputs

The packed construction in `chatgpt-answers/Q6638-cf61b0fd.md`, Proposition 8.1, gives a word of length `O(D^(3/2))` with

```text
R_h<=2h,
minimum equal-color gap >= sqrt(D),
Q_D>=cD^2.                                      (9.1)
```

For completeness, here is a slightly thinned and reflected version adapted to the present audit.

### 9.1 Packed private progressions

Put

```text
S=ceil(sqrt(D)),
T={S,S+1,...,2S-1}.
```

For each `s in T`, reserve a private block and a private color `c_s`. Put that color at

```text
B_s,
B_s+s,
...,
B_s+m_s s,

m_s=floor(D/(4s)).                              (9.2)
```

All remaining positions initially get singleton colors. The private blocks have total length `O(D^(3/2))`.

For a fixed lag `h<=D`, the class with step `s` contributes only when `s|h`. The map `s -> h/s` is injective on divisors `s in [S,2S)`, so there are at most `h/S` relevant steps. Each contributes at most

```text
m_s+1 <= S/4+2.
```

Thus, for all large `D`,

```text
R_h <= h/2.                                      (9.3)
```

Each class contains `asymp S` points and every triple in it has span at most `D/4`. There are `S` classes, hence

```text
Q_D >= c_0 S*S^3 >= c_1 D^2.                   (9.4)
```

Also,

```text
max_r d_D(r) << S << D^(1/2),                  (9.5)
```

and there are no consecutive equal colors.

### 9.2 Reflection symmetrization

Embed this word in the far left of the physical interval and put its reflected copy in the far right, using the same color on reflected positions. Keep the two copies more than `D` apart. Fill the middle by fresh reflection-paired colors.

Then

```text
pi(r)=pi(p-1-r)                                 (9.6)
```

holds exactly. For gaps at most `D`, the two private copies do not interact. Their row counts double; the singleton mirror fillers add at most one forced pair to each even gap. Therefore

```text
R_h <= h+1 <= 2h <= 3h,                        (9.7)
Q_D >= 2c_1D^2,                                (9.8)
max_r d_D(r) << D^(1/2),                       (9.9)
```

and the no-consecutive-return property remains true.

Since the original length is `O(D^(3/2))`, the reflected word embeds in an interval of length `p+O(1)` whenever

```text
D=sqrt(p)L,
L=o(p^(1/6)).                                  (9.10)
```

This includes every arbitrarily slowly growing `L` relevant to the campaign.

### 9.3 It also defeats ATB

For this word,

```text
S_D=sum_{h<=D}R_h << D^2.                      (9.11)
```

Therefore the exact boundary terms satisfy

```text
(W_1+W_2)/p << D^3/p.                          (9.12)
```

Using (3.5), (9.8), and `|T_D|/p^2<<D^2/p`,

```text
ATB_p(D)
 = Q_D - (W_1+W_2)/p + |T_D|/p^2
 >= cD^2 - O(D^3/p) - O(D^2/p).               (9.13)
```

At `D=sqrt(p)L`, `L=o(sqrt(p))`,


so

```text
ATB_p(D) >= c' D^2.                            (9.14)
```

Thus an unbounded `W` is impossible for this structural class.

### 9.4 Compatibility with determinant phases and symplectic transport

Choose a distinct projective point of `P^1(F_p)` for each color. There are enough points. Let `v_r` be representatives. Then

```text
Delta_{r,h}=det(v_r,v_{r+h})
```

vanishes exactly on the return set. Reflection gives

```text
Delta_{p-1-r-h,h}=-Delta_{r,h}.                (9.15)
```

This countermodel therefore respects:

It does not satisfy the **specific Apéry polynomial transfer matrices**. That is exactly the point: the currently extracted generic consequences do not suffice. A winning theorem must use arithmetic not shared by this model.

## 10. The smallest new arithmetic lemma that would suffice

The exact addition law identifies the relevant algebraic pair:

```text
N_a(X),
N_g(X+a).                                      (10.1)
```

Raw resultants are polluted by boundary roots and by the known factors involving Apéry zeros. Therefore the correct object must be saturated before measuring common factors.

### 10.1 Regular saturated gcd

For `s=a+g`, define the boundary polynomial

```text
B_s(X)=X product_{j=1}^{s+1}(X+j).             (10.2)
```

Its roots are precisely the residues outside the one-based physical interval that can occur at the left endpoint of a span-`s` triple.

Let

```text
H_{a,g,p}(X)
 = gcd_{F_p[X]}(N_a(X), N_g(X+a)).             (10.3)
```

Remove from `H_{a,g,p}` every irreducible factor dividing `B_s`; call the result

```text
G^reg_{a,g,p}(X).                              (10.4)
```

Every physical common root counted by `rho(a,g)` is a root of `G^reg`, so

```text
rho(a,g) <= deg G^reg_{a,g,p}.                 (10.5)
```

Hence

```text
Q_D
 <= sum_{a,g>=1,a+g<=D} deg G^reg_{a,g,p}.     (10.6)
```

### 10.2 Minimal sufficient theorem

It is enough to prove:

```text
[REG-GCD-TRIANGLE]

There exists omega(p)->infinity such that, for
D=sqrt(p)L, L=p^o(1),

sum_{a,g>=1,a+g<=D} deg G^reg_{a,g,p}
  << p/omega(p).                               (10.7)
```

Then (10.6) gives immediately

```text
Q_D << p/omega(p)=o(p).                        (10.8)
```

This is strictly arithmetic and zero-specific. It is not a restatement of a large-sieve or exponential-sum hypothesis. It asks that the actual shifted Apéry continuants acquire few regular common factors modulo the fixed prime.

### 10.3 Why the recurrence makes this the right target

The addition law gives, at a common root,

```text
N_a(r)=N_g(r+a)=0
 => N_{a+g}(r)=0.                              (10.9)
```

The banked resultant relation has the form

```text
Res(N_a(X),N_{a+g}(X))
 = A_{a-1} * Res(N_a(X),N_g(X+a))              (10.10)
```

up to the explicit sign/normalization already recorded in the project. The factor `A_{a-1}` is the cut-edge pollution. Saturation by (10.2), followed by primitive subresultants, isolates the regular common-factor degree that can contribute physically.

Thus a concrete attack on (10.7) is:

```text

2. divide the explicit A_{a-1} pollution;
3. prove that, for fixed p, only o(p) total regular subresultant degree
   survives over the triangle a+g<=sqrt(p)L.
```

That is the smallest place where genuinely new Apéry arithmetic can enter.

### 10.4 A stronger but clean dyadic version

A convenient theorem with room to sum dyadically would be

```text
[REG-GCD-SQRT]

For dyadic A,G with A+G<=D,

sum_{A<a<=2A, G<g<=2G} deg G^reg_{a,g,p}
 << (AG/p + sqrt(AG)) (log p)^C.               (10.11)
```

Summing over `O(log^2 D)` boxes gives

```text
Q_D
 << (D^2/p + D)(log p)^(C+2)
 = p^(1/2+o(1))=o(p)                           (10.12)
```

at `D=sqrt(p)L`, `L=p^o(1)`.

This dyadic square-root form is much stronger than the minimal (10.7), but it is a precise algebraic target and avoids the vague phrase "large-sieve cancellation."
