# 1. The coefficients are exactly the Lagrange weights

The first useful identity is

\[
\boxed{
\lambda_j=
\prod_{\substack{0\le k<M\\k\ne j}}
\frac{n-k}{j-k}.
}
\tag{1.1}
\]

Indeed,

\[
\prod_{k\ne j}(n-k)
=\frac{n!}{(n-M)!(n-j)},
\]

whereas

\[
\prod_{k\ne j}(j-k)
=(-1)^{M-1-j}j!(M-1-j)!,
\]

which gives exactly the displayed binomial formula.

Consequently, for every polynomial \(f\) of degree at most \(M-1\),

\[
f(n)=\sum_{j=0}^{M-1}\lambda_j f(j).
\tag{1.2}
\]

Taking \(f=1\) gives

\[
\boxed{\sum_j\lambda_j=1.}
\tag{1.3}
\]

In particular

\[
\boxed{\gcd_j\lambda_j=1.}
\tag{1.4}
\]

So the proposed primitive-coefficient assertion is exact, not merely heuristic.

---

# 2. Exact lattice invariant: the Smith form is `diag(1,R_n)`

Define the column vectors

\[
v_j=\lambda_j(1,b_j)^t\in\mathbf Z^2
\]

and their lattice

\[
\mathcal L_n=\sum_{j\in J}\mathbf Z v_j\subset\mathbf Z^2.
\]

Also define the single multi-label interpolant

\[
\beta_n:=\sum_{j=0}^{M-1}\lambda_j b_j.
\tag{2.1}
\]

Because of (1.3),

\[
u_n:=\sum_jv_j=(1,\beta_n)^t\in\mathcal L_n.
\tag{2.2}
\]

The matrix with columns \(v_j\) has first determinantal divisor

\[
\Delta_1=\gcd_j(\lambda_j,\lambda_jb_j)=\gcd_j\lambda_j=1.
\]

Its \(2\times2\) minors are

\[
\det(v_i,v_j)=\lambda_i\lambda_j(b_j-b_i),
\]

so its second determinantal divisor is exactly

\[
\Delta_2=R_n.
\]

Since \(b_0=1\), \(b_1=5\), and \(\lambda_0\lambda_1\ne0\), the rank is two for \(M\ge2\). Hence the Smith normal form is

\[
\boxed{\operatorname{SNF}(v_0,\dots,v_{M-1})=\operatorname{diag}(1,R_n),}
\tag{2.3}
\]

and therefore

\[
\boxed{
\mathbf Z^2/\mathcal L_n\simeq\mathbf Z/R_n\mathbf Z,
\qquad
[\mathbf Z^2:\mathcal L_n]=R_n.
}
\tag{2.4}
\]

There is an even more explicit description. Subtract \(\lambda_j u_n\) from \(v_j\):

\[
v_j-\lambda_j u_n
=(0,\lambda_j(b_j-\beta_n))^t.
\]

Let

\[
g_n:=\gcd_j\lambda_j(b_j-\beta_n).
\]

Then

\[
\mathcal L_n
=\mathbf Z(1,\beta_n)^t+\mathbf Z(0,g_n)^t.
\]

Its index is \(g_n\), so comparison with (2.4) gives the exact one-row formula

\[
\boxed{
R_n=\gcd_j\lambda_j(b_j-\beta_n)
}
\tag{2.5}
\]

and the exact lattice decomposition

\[
\boxed{
\mathcal L_n
=\mathbf Z(1,\beta_n)^t\oplus\mathbf Z(0,R_n)^t.
}
\tag{2.6}
\]

This is the complete lattice invariant of the vectors \(\lambda_j(1,b_j)\).

# 3. Adjoining the target vector gives exactly `D_n = gcd(R_n,E_n)`

Put

\[
x_n=(1,b_n)^t,
\qquad
E_n:=b_n-\beta_n.
\tag{3.1}
\]

Then

\[
\det(v_j,x_n)=\lambda_j(b_n-b_j)=c_j.
\tag{3.2}
\]

From (2.6),

\[
x_n-(1,\beta_n)^t=(0,E_n)^t,
\]

hence

\[
\mathcal L_n+\mathbf Zx_n
=\mathbf Z(1,\beta_n)^t
+\mathbf Z(0,R_n)^t
+\mathbf Z(0,E_n)^t.
\]

Therefore

\[
\boxed{
[\mathbf Z^2:\mathcal L_n+\mathbf Zx_n]
=\gcd(R_n,E_n).
}
\tag{3.3}
\]

But the left side is also the gcd of the \(2\times2\) minors of the augmented matrix \([v_0\ \cdots\ v_{M-1}\ x_n]\), namely \(\gcd(R_n,D_n)\). Pairwise elimination gives \(D_n\mid R_n\), so

\[
\boxed{
D_n=\gcd(R_n,E_n).
}
\tag{3.4}
\]

Equivalently, in the cyclic group \(\mathbf Z^2/\mathcal L_n\simeq\mathbf Z/R_n\mathbf Z\), the class of \(x_n\) is represented by \(E_n\bmod R_n\), and

\[
\boxed{
\operatorname{ord}(x_n\bmod\mathcal L_n)=R_n/D_n.
}
\tag{3.5}
\]

This is the exact Smith-theoretic meaning of the Padé minor gcd.

# 4. Higher Smith/Plücker minors of the natural augmentation add nothing

The most obvious three-row augmentation is

\[
A_n=
\begin{pmatrix}
\lambda_j\\
\lambda_jb_j\\
c_j
\end{pmatrix}_{j\in J}.
\]

But row three satisfies identically

\[
(c_j)_j=b_n(\lambda_j)_j-(\lambda_jb_j)_j.
\tag{4.1}
\]

Hence

\[
\operatorname{rank}A_n\le2,
\]

all \(3\times3\) Plücker minors vanish, and the nonzero determinantal ideal in degree two is the same one already generated by \(R_n\). No higher exterior-power invariant exists in this rank-two module.

More generally, unimodular row/column operations, adjoining rows in the integral span of the three natural rows, taking Fitting ideals, or passing to Smith normal form cannot create an invariant strictly between the data \(R_n\) and \(D_n\). The rank-two determinantal data are exhausted by

\[
\boxed{1,\ R_n,\ D_n.}
\tag{4.2}
\]

Thus a genuinely new higher-minor attack must add an arithmetically independent row, not merely another presentation of \(1,b_j,c_j\).

# 5. `R_n` has an unavoidable top-prime factor of logarithmic height `(1/2+o(1))n`

Define the top interpolation interval

\[
I_n:=\{p\text{ prime}:n-M+1\le p\le n,\ p\ge5\}
\]

and

\[
P_n:=\prod_{p\in I_n}p.
\tag{5.1}
\]

For \(p\in I_n\), put

\[
r=n-p.
\]

Then \(0\le r<M\) and \(p>M\). Using (1.1) in factorial form,

\[
\lambda_j
=(-1)^{M-1-j}
\frac{n!}{(n-M)!(n-j)j!(M-1-j)!}.
\tag{5.2}
\]

The numerator product \(n(n-1)\cdots(n-M+1)\) contains exactly one multiple of \(p\), namely \(n-r=p\). All factorials in the denominator are \(p\)-units. Therefore

\[
\boxed{
v_p(\lambda_r)=0,
\qquad
v_p(\lambda_j)=1\quad(j\ne r).
}
\tag{5.3}
\]

Moreover (1.3) implies

\[
\lambda_r\equiv1\pmod p.
\tag{5.4}
\]

Every pair \(\lambda_i\lambda_j\) is therefore divisible by \(p\), so \(p\mid R_n\). The valuation is exactly one. Indeed, choose \(k\ne r\) among \(0,1\) so that

\[
b_k\not\equiv b_r\pmod p.
\]

Such a \(k\) exists because \(b_0=1\), \(b_1=5\), and \(p\nmid4\). Then

\[
v_p(\lambda_r\lambda_k(b_r-b_k))=1.
\]

Hence

\[
\boxed{
v_p(R_n)=1\qquad(p\in I_n).}
\tag{5.5}
\]

In particular,

\[
\boxed{P_n\mid R_n,\quad \gcd(R_n,P_n^\infty)=P_n.}
\tag{5.6}
\]

By the prime number theorem,

\[
\log P_n
=\vartheta(n)-\vartheta(n-M)+O(1)
=M+o(n)
=\left(\frac12+o(1)\right)n.
\tag{5.7}
\]

So

\[
\boxed{
\log R_n\ge\left(\frac12+o(1)\right)n.
}
\tag{5.8}
\]

There is also a simple linear upper bound. Since \(R_n\) divides every minor,

\[
R_n\mid \lambda_0\lambda_1(b_1-b_0)=4\lambda_0\lambda_1.
\]

Now

\[
|\lambda_0|=\binom{n-1}{M-1},
\qquad
|\lambda_1|=n\binom{n-2}{M-2},
\]

so Stirling gives

\[
\log|\lambda_0\lambda_1|
=2n\log2+O(\log n).
\]

Therefore

\[
\boxed{
\left(\frac12+o(1)\right)n
\le\log R_n
\le 2(\log2)n+O(\log n).
}
\tag{5.9}
\]

Thus

\[
\boxed{\log R_n=\Theta(n).}
\tag{5.10}
\]

The pairwise determinant carrier itself is decisively too large.

# 6. The linear factor is structural, not target-aware

The crucial point is that (5.5) holds for **every** \(p\in I_n\), independent of whether \(p\mid b_{n-p}\). So \(R_n\) has exactly the wrong behavior: it saturates the whole top prime interval.

This is not a defect of the Apéry values. It comes solely from the interpolation coefficients: modulo \(p\), exactly one label \(r=n-p\) has a unit coefficient and every other label carries one factor of \(p\).

This explains why merely taking more pairwise minors cannot improve the top-prime height.

# 7. The exact target selector is the single Newton-tail residue `E_n`

For a top prime \(p\in I_n\), write again \(n=p+r\), \(0\le r<M\). The Apéry Lucas congruence gives

\[
b_n=b_{p+r}\equiv b_1b_r=5b_r\pmod p.
\tag{7.1}
\]

On the other hand, by (5.3)--(5.4),

\[
\beta_n=\sum_j\lambda_jb_j\equiv b_r\pmod p.
\tag{7.2}
\]

Hence

\[
\boxed{
E_n=b_n-\beta_n\equiv4b_r=4b_{n-p}\pmod p.
}
\tag{7.3}
\]

Since \(p\ge5\), the factor \(4\) is a unit. Combining (3.4), (5.5), and (7.3),

\[
\boxed{
 v_p(D_n)=
 \begin{cases}
 1,&p\mid b_{n-p},\\
 0,&p\nmid b_{n-p},
 \end{cases}
 \qquad(p\in I_n).
}
\tag{7.4}
\]

Thus

\[
\boxed{
\gcd(P_n,E_n)
=\gcd(P_n,D_n)
=\prod_{\substack{p\in I_n\\p\mid b_{n-p}}}p.
}
\tag{7.5}
\]

This is an exact global CRT encoding of the top-window Apéry target set.

### Odd-`n` endpoint

If \(n=2M+1\), the only prime in \((n/2,n]\) not covered by \(I_n\) could be

\[
p=M+1=(n+1)/2.
\]

Then \(r=n-p=M=p-1\), and reflection gives

\[
b_r=b_{p-1}\equiv b_0=1\pmod p.
\]

So this omitted endpoint is never a target prime. Therefore, for all sufficiently large \(n\), (7.5) is exactly the full direct top-window radical

\[
\boxed{
\prod_{\substack{n/2<p\le n\\p\mid b_{n-p}}}p
=\gcd(P_n,E_n).
}
\tag{7.6}
\]

This is the strongest genuinely target-aware simplification produced by the rank-two lattice.

It is also tautological at the height level: its logarithm is exactly the unresolved weighted top-prime mass.

# 8. All multi-label Bézout relations are classified

Let \(u_j\in\mathbf Z\) be arbitrary and set

\[
A=\sum_j u_j\lambda_j,
\qquad
B=\sum_j u_j\lambda_jb_j.
\]

Then \((A,B)^t\in\mathcal L_n\). By (2.6), there is an integer \(k\) such that

\[
B=A\beta_n+kR_n.
\tag{8.1}
\]

Therefore

\[
\sum_j u_jc_j
=Ab_n-B
=A(b_n-\beta_n)-kR_n
=AE_n-kR_n.
\tag{8.2}
\]

Conversely, every pair \((A,k)\in\mathbf Z^2\) occurs because (2.6) is an equality of lattices. Hence

\[
\boxed{
\left\{\sum_j u_jc_j:u_j\in\mathbf Z\right\}
=E_n\mathbf Z+R_n\mathbf Z
=D_n\mathbf Z.
}
\tag{8.3}
\]

In the special first-coordinate-one case

\[
\sum_j u_j\lambda_j=1,
\]

every Bézout carrier is exactly

\[
\boxed{E_n-kR_n\qquad(k\in\mathbf Z).}
\tag{8.4}
\]

So there is **no second independent multi-label Bézout invariant** hidden in the \(\lambda_j\). The entire family is one residue class modulo \(R_n\), and its ideal is exactly \((D_n)\).

One may choose \(k\) to make \(|E_n-kR_n|\le R_n/2\) unless the residue is zero; in the zero case \(D_n=R_n\). This gives a carrier with a better numerical constant than the raw Newton tail, but only the unconditional linear bound

\[
\log|E_n-kR_n|\le2(\log2)n+O(\log n)
\]

in the nonzero case. Continuing the Euclidean algorithm eventually produces \(D_n\) itself, but then the height problem is exactly the original problem.

# 9. The most natural Bézout carrier `E_n` also has linear height

Let

\[
d_k=\Delta^k b_0
\]

be the Newton coefficients of the Apéry sequence. Since \(\beta_n\) is the degree-\((M-1)\) interpolation polynomial evaluated at \(n\), Newton interpolation gives the exact formulas

\[
\boxed{
\beta_n=\sum_{k=0}^{M-1}d_k\binom nk,
\qquad
E_n=\sum_{k=M}^{n}d_k\binom nk.
}
\tag{9.1}
\]

The repository proof `Q32_SIGNED_PADE_DEGREE_ONE_NO_GO.md` establishes

\[
d_k=\kappa\gamma^k k^{-3/2}
\left(1+O(k^{-1})\right),
\qquad
\gamma=16+12\sqrt2,
\qquad
\kappa>0.
\tag{9.2}
\]

Hence \(d_k>0\) for every sufficiently large \(k\). For sufficiently large \(n\), all terms in (9.1) with \(k\ge M\) are therefore positive, so

\[
E_n\ge d_M\binom nM.
\]

Stirling and \(M=n/2+O(1)\) give

\[
\boxed{
\log E_n
\ge
n\left(\log2+\frac12\log(16+12\sqrt2)\right)
+O(\log n).
}
\tag{9.3}
\]

The constant is positive (approximately \(2.44\)). Thus the simplest multi-label Bézout carrier is also exponentially large:

\[
\boxed{\log E_n=\Omega(n).}
\tag{9.4}
\]

So neither `R_n` nor the canonical `sum lambda_j c_j = E_n` can be the desired subexponential carrier.

# 10. Recurrence normalization cannot remove the top structural factor faithfully

The Apéry recurrence is

\[
(k+1)^3b_{k+1}
=(2k+1)(17k^2+17k+5)b_k-k^3b_{k-1}.
\tag{10.1}
\]

For the state \((b_k,b_{k-1})^t\), the transfer matrix has determinant

\[
\det T_k=\frac{k^3}{(k+1)^3}.
\tag{10.2}
\]

Let \(p\in I_n\). Then \(p>M\). For every

\[
1\le k<M,
\]

both \(k\) and \(k+1\) are \(p\)-units, and hence

\[
T_k\in\operatorname{GL}_2(\mathbf Z_{(p)}).
\tag{10.3}
\]

Therefore any recurrence change of basis among the lower-label states, after clearing only the standard recurrence denominators, is \(p\)-unimodular at every top prime. It cannot change a determinantal valuation at such a \(p\).

In particular, the structural valuation

\[
v_p(R_n)=1
\]

cannot be removed by a recurrence normalization whose nonunit factors are supported on indices \(\le M\). Dividing it out requires explicitly dividing by the large prime \(p\) itself.

But if \(p\) is a target prime, (7.4) says

\[
v_p(D_n)=1.
\]

Thus a value-blind normalization

\[
R_n\longmapsto R_n/P_n
\]

is **not** an upper carrier for \(D_n\): it deletes exactly the target prime whenever that target occurs.

The recurrence singularity at \(k=0\) does not rescue this route. A top target cannot have \(r=n-p=0\), because that would require \(p\mid b_0=1\). For every actual target top prime the relevant lower state lies in the \(p\)-invertible recurrence range.

# 11. Exact target-aware structural deflation

There is a clean general formula which isolates exactly what a faithful normalization must pay.

Let \(S_n\) be **any** positive divisor of \(R_n\). Define

\[
C_n(S_n):=rac{R_n}{S_n}\gcd(S_n,E_n).
\tag{11.1}
\]

Then

\[
\boxed{D_n\mid C_n(S_n).}
\tag{11.2}
\]

Proof: for a prime \(q\), write

\[
a=v_q(R_n),\quad s=v_q(S_n),\quad e=v_q(E_n).
\]

Then

\[
v_q(C_n(S_n))=a-s+\min(s,e)
\ge\min(a,e)=v_q(D_n).
\]

The most relevant choice is the universal top structural factor \(S_n=P_n\). Then

\[
\boxed{
C_n^{\sharp}
:=\frac{R_n}{P_n}\gcd(P_n,E_n)
}
\tag{11.3}
\]

is a genuinely smaller target-aware carrier and

\[
\boxed{D_n\mid C_n^{\sharp}.}
\tag{11.4}
\]

Moreover, by (7.6),

\[
\log C_n^{\sharp}
=\log(R_n/P_n)
+\sum_{\substack{n/2<p\le n\\p\mid b_{n-p}}}\log p.
\tag{11.5}
\]

This is the sharpest useful conclusion of the present determinant algebra:

* the completely spurious top-prime mass \(\log P_n\sim n/2\) can be removed;
* the primes that must be reinserted are **exactly** the original target primes;
* any remaining estimate for \(R_n/P_n\) is a genuine cross-label problem, but even the ideal bound \(R_n/P_n=e^{o(n)}\) would still leave the original target mass in (11.5).

One can similarly take the full coefficient-only structural divisor

\[
H_n:=\gcd_{i<j}|\lambda_i\lambda_j|,
\]

which satisfies \(P_n\mid H_n\mid R_n\), and form

\[
\frac{R_n}{H_n}\gcd(H_n,E_n).
\]

This removes all coefficient-only Smith content. It does not remove the target problem, because \(\gcd(H_n,E_n)\) still contains the exact top target radical (7.6).

Taking \(S_n=R_n\) reduces (11.1) to

\[
C_n(R_n)=\gcd(R_n,E_n)=D_n,
\]

which shows where the process terminates: complete target-aware saturation is exactly the original gcd.

# 12. Rigorous scoped no-go for the rank-two multi-label determinant class

Define the **rank-two Padé determinant class** to consist of constructions obtained from the columns

\[
\lambda_j(1,b_j)^t
\]

and the target column \((1,b_n)^t\) by any finite combination of:

1. integral unimodular row or column operations;
2. Smith/Fitting/determinantal divisors;
3. adjoining rows in the integral span of the natural rows \(\lambda_j\), \(\lambda_jb_j\), and \(c_j\);
4. using the Apéry three-term recurrence only as a change of state basis, with the standard denominators cleared;
5. saturating by value-independent structural factors.

Then the following is exact.

### Theorem (scoped no-go)

For every sufficiently large \(n\):

**(a)** Without the target column, the only nontrivial rank-two Smith invariant is \(R_n\), and

\[
\log R_n=\Theta(n).
\]

In fact every prime \(p\in I_n\) occurs in \(R_n\) exactly once, independently of the Apéry zero condition.

**(b)** Adding the target column changes the second determinantal divisor exactly to

\[
D_n=\gcd(R_n,E_n).
\]

There is no higher Plücker invariant in the natural augmentation because its rank is two.

**(c)** The three-term recurrence is \(p\)-unimodular for every top prime \(p\in I_n\) at every positive lower index. Hence recurrence normalization cannot remove the universal top factor while preserving a target prime.

**(d)** Any faithful value-independent removal of the universal top factor must be repaired by

\[
\gcd(P_n,E_n)
=\prod_{\substack{n/2<p\le n\\p\mid b_{n-p}}}p,
\]

which is exactly the original target radical.

Therefore **no construction in this rank-two multi-label determinant class gives a new proof of an `e^{o(n)}` carrier merely by Smith reduction, higher minors, recurrence normalization, or a multi-label Bézout identity.** Either it keeps the universal \(e^{(1/2+o(1))n}\) structural factor, or it removes that factor and must reinsert precisely the unknown target-prime product.

This is a no-go for the method, not a no-go for the conjecture and not a proof that every conceivable target-aware carrier has linear height.

# 13. What would genuinely escape the theorem?

A successful escape must add information not already contained in the rank-two lattice.

The obvious shifted-state enlargement

\[
(b_j,b_{j+1})
\]

does not immediately help in the top window: Lucas gives

\[
(b_n,b_{n+1})\equiv5(b_r,b_{r+1})\pmod p,
\]

so the corresponding state Casoratian vanishes for **every** top prime, not only when \(b_r=0\). It is another label-blind saturation at the prime level.

Thus a genuinely different candidate would have to use, for example,

* an independent companion solution together with a nontrivial integral normalization;
* a nonlinear cross-label identity not generated by the rank-two Plücker ideal;
* a higher-rank object whose target rank drop is not already forced by Lucas for every prime;
* or an Apéry-specific cross-label relation controlling the residual factor \(R_n/H_n\).

Those possibilities are outside the theorem above. I do not find an exact faithful linear/higher-Smith construction inside the present Padé column module that escapes the reduction to \(D_n\) or the original target radical.

# 14. Final verdict

The proposed pairwise elimination is correct but is not the end of the exact algebra. The decisive identities are

\[
\boxed{
\mathcal L_n
=\mathbf Z(1,\beta_n)^t\oplus\mathbf Z(0,R_n)^t,
}
\]

\[
\boxed{
D_n=\gcd(R_n,b_n-\beta_n),
}
\]

and, for the top-prime product

\[
P_n=\prod_{n-M+1\le p\le n}p,
\]

\[
\boxed{
v_p(R_n)=1\quad(p\mid P_n),}
\]

\[
\boxed{
(b_n-\beta_n)\bmod p=4b_{n-p}\bmod p,
}
\]

so

\[
\boxed{
\gcd(P_n,b_n-\beta_n)
=\prod_{\substack{n/2<p\le n\\p\mid b_{n-p}}}p.
}
\]

Consequently

\[
\boxed{
\log R_n\ge(1/2+o(1))n,
}
\]

and the canonical Newton-tail Bézout carrier also has \(\Omega(n)\) logarithmic height. Higher Plücker minors of the natural module vanish; recurrence changes of basis are top-prime units; and all multi-label Bézout relations reduce to \(AE_n-kR_n\).

The best exact target-aware deflation is

\[
\boxed{
C_n^{\sharp}
=\frac{R_n}{P_n}\gcd(P_n,b_n-\beta_n),
\qquad D_n\mid C_n^{\sharp},
