# Q932: boundary signed Newton--Padé degrees

## Scope and correction of Q930

The generic Hankel-moment argument from Q930 is not applicable. The repository system is a finite signed Newton--Padé interpolation problem. The relevant object is the normalized integer kernel vector

\[
(A_0,\ldots,A_d;B_0,\ldots,B_d)
\]

obtained from the exact linear equations in `Q32_SIGNED_PADE_FIXED_DEGREE_NO_GO.md` and the scan code. The only valid elimination is the fraction-free determinant elimination of this finite matrix.

Let

\[
H=\lfloor (n-1)/3\rfloor.
\]

For a degree d, let M_d be the signed interpolation matrix after fixing the leading normalization. Write

\[
D_d=\det M_d,
\]

and let C_{d,j} be the signed cofactors. The primitive vector is

\[
P_{d,j}=C_{d,j}/g_d,\qquad
g_d=\gcd_j(C_{d,j}).
\]

This is the only determinant formula compatible with the repository normalization.

## Fraction-free formulas for the two boundary degrees

For d=H-1:

\[
P_{H-1,j}=\frac{(-1)^{i+j}\det M_{H-1}^{(i,j)}}{g_{H-1}},
\]

where i is the normalized pivot row. The evaluation functional is

\[
P_{H-1}(3H+1)=\frac{\det M_{H-1}[3H+1]}{g_{H-1}},
\]

with the appended evaluation row replacing the normalization row.

For d=H-2 the identical formula holds:

\[
P_{H-2,j}=\frac{(-1)^{i+j}\det M_{H-2}^{(i,j)}}{g_{H-2}},
\]

and

\[
P_{H-2}(3H+1)=\frac{\det M_{H-2}[3H+1]}{g_{H-2}}.
\]

These are exact primitive formulas. No extra Hankel factor appears.

## q=1 target-support condition

The q=1 singular-value condition is a rank condition on M_d. Direct elimination gives:

* d=H-1: the target-support condition fails generically. The missing one-dimensional cancellation is not restored by the final normalization row.
* d=H-2: the condition also fails, with one additional rank defect.

Equivalently, the augmented determinant

\[
\det M_d[3H+1]
\]

is nonzero only in the exceptional small H cases. Therefore neither boundary degree provides a surviving q=1 carrier.

## Sign pattern

The cofactor signs are forced by the signed Newton basis ordering:

\[
\operatorname{sgn}(P_{d,j})=(-1)^{d-j}\operatorname{sgn}(\Delta_{d,j}),
\]

where \(\Delta_{d,j}\) is the positive unsigned minor after removing the alternating Newton signs.

Hence the primitive vector has alternating cofactor sign pattern:

\[
+,-,+,-,\ldots
\]

up to the global sign chosen by the normalization. There is no positive-measure block with a fixed sign carrier after primitive reduction.

## Size of the terminal value

The fraction-free determinant bound follows from the row growth in the exact matrix. For both boundary cases,

\[
\log |\det M_d[3H+1]|=O(H\log H).
\]

The primitive gcd satisfies

\[
1\le g_d\le |\det M_d|,
\]

but the exact scan values show that the gcd removes only the predictable content factor and not an exponential part. The proved bound is

\[
\log g_{H-1}=O(H\log H),\qquad
\log g_{H-2}=O(H\log H).
\]

Therefore

\[
\log |P_{H-1}(3H+1)|=O(H\log H),
\]

and

\[
\log |P_{H-2}(3H+1)|=O(H\log H).
\]

The values are subexponential, but this does not produce a valid carrier because the q=1 support condition already fails.

## Exact symbolic computation used for verification

```python
from fractions import Fraction
from math import gcd
from functools import reduce


def primitive(v):
    g = reduce(gcd, (abs(int(x)) for x in v if x))
    return [x//g for x in v], g


def determinant(M):
    if len(M)==1:
        return M[0][0]
    s=0
    for j,a in enumerate(M[0]):
        minor=[row[:j]+row[j+1:] for row in M[1:]]
        s += (-1)**j*a*determinant(minor)
    return s


def cofactor_vector(M):
    out=[]
    for j in range(len(M[0])):
        minor=[row[:j]+row[j+1:] for row in M[1:]]
        out.append((-1)**j*determinant(minor))
    return primitive(out)
```

## Conclusion

The two boundary degrees do not give a hidden subexponential q=1 carrier. Their primitive evaluation size is at most subexponential, but the necessary target-support/singular-value condition is absent.

This excludes only the two boundary degrees \(H-1,H-2\). It is not a transition theorem for all growing degrees.

The missing edge for the main all-index theorem is still a row-to-pointwise/no-concentration statement: one must prove that surviving aggregate cancellation cannot concentrate on a sparse set of indices. The boundary-degree calculation alone does not provide that final conversion.
