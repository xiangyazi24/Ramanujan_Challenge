# Verdict

I do **not** see an unconditional proof of

\[
\sum_{\ell\le H}v_\ell(G_{\rm full}^+G_{\rm full}^-)\log \ell=o(H)
\]

from the canonical GitHub state currently visible, and I also do **not** see an Apéry counterfamily showing that this bound is false.

There is, however, a useful exact all-prime reduction which is stronger than the individual adjacent-Padé bounds and which isolates the remaining obstruction very sharply. The key point is to take the **gcd of all adjacent cross identities**, not their product. For either evaluation point `x` one gets

```text
G_full(x) | gcd(L_H, F_H(x), binom(x,H+1) K_H),

L_H = lcm(A_0,...,A_H),
F_H = the degree-H Newton interpolant of A_0,...,A_H,
K_H = gcd_b kappa_{H,b},
```

where

```text
P_b Q_{b+1} - P_{b+1} Q_b
    = kappa_{H,b} binom(X,H+1)
```

is the exact primitive adjacent identity already audited in `q32_adjacent_pade_kappa.py`.

Prime-by-prime this gives the unconditional bound

```text
v_ell(G_full(x))
 <= min(
      E_ell(H),
      v_ell(F_H(x)),
      v_ell(binom(x,H+1)) + d_ell(H)
    ),                                      (1)

E_ell(H) = max_{0<=s<=H} v_ell(A_s),
d_ell(H) = min_b v_ell(kappa_{H,b}).
```

This works for **every** prime `ell`, including `ell<=H`; no distinct-node-mod-`ell` hypothesis is used.

There is a second useful all-prime statement. If

```text
c_{ell,a}=v_ell(content(P_{H,a})),
b=H-a,
e_s=v_ell(A_s),
```

then

```text
max_{0<=t<=b} min_{t<=s<=t+a} e_s
    <= c_{ell,a}
    <= min_{0<=t<=a} max_{t<=s<=t+b} e_s.          (2)
```

For `ell>H`, the repository's exact order-statistic theorem improves this sandwich to equality with the `(a+1)`-st largest `e_s`. For `ell<=H`, (2) is the correct unconditional substitute: it uses consecutive-node unimodularity, which survives at small primes, while arbitrary-node unimodularity does not.

The consequence for Q2637 is that the small-prime problem splits into two explicit Apéry carriers. Put

```text
A_H(x) = gcd(L_H,F_H(x)),
B_H(x) = abs(binom(x,H+1)),
C_H(x) = gcd(A_H(x),B_H(x)),
D_H(x) = gcd(A_H(x),K_H).
```

Then

```text
G_full(x) | C_H(x) D_H(x).                         (3)
```

Hence, for the two evaluation points `x_+`,`x_-`,

```text
sum_{ell<=H} v_ell(G_full^+ G_full^-) log ell
 <= log (C_H(x_+) C_H(x_-))_{<=H}
    + 2 log (K_H)_{<=H}.                           (4)
```

Here `N_{<=H}` denotes the `H`-smooth part of `N`. Thus it is enough to prove

```text
log (C_H(x_+) C_H(x_-))_{<=H} = o(H),              (C)
log (K_H)_{<=H} = o(H).                             (K)
```

This is a strict, non-CRT reduction. `(C)` is the endpoint/binomial (central-binomial-type) height problem; `(K)` is the genuinely new all-degree primitive-normalization problem. The all-degree availability enters `(K)` through the **minimum** `min_b v_ell(kappa_{H,b})`, which is exactly the quantity an all-exponents Gamma formula should be used on.

I would therefore not try to prove Q2637 by multiplying adjacent identities or by bounding each degree separately. The correct p-adic interface is `(1)`--`(4)`.

# 1. Exact endpoint degree 0: the constant numerator is the Apéry lcm

Let `(P_{H,0},Q_{H,0})` be the primitive integral Newton pair

```text
deg P <= 0,
deg Q <= H,
P(s)=A_s Q(s), 0<=s<=H.
```

Write `P=c`. Since `Q(s)` is an integer at every integer node,

```text
A_s | c   for every 0<=s<=H.
```

Therefore

```text
L_H := lcm(A_0,...,A_H) | c.
```

Conversely, prescribe

```text
Q(s)=L_H/A_s, 0<=s<=H.
```

These are integers. Interpolation on consecutive integer nodes in the Newton/binomial basis has a unimodular evaluation matrix, so the interpolating `Q` has integral Newton coefficients. Moreover

```text
gcd_{0<=s<=H} L_H/A_s = 1,
```

because the lcm of the `A_s` is `L_H`; the same gcd holds for the Newton coefficients by unimodularity. Thus `(L_H,Q)` is already jointly primitive. Hence

```text
P_{H,0}=+-L_H.                                     (5)
```

Consequently, for every integer evaluation point `x`,

```text
G_full(x) | L_H,

v_ell(G_full(x)) <= E_ell(H)
                  := max_{0<=s<=H}v_ell(A_s).       (6)
```

This endpoint statement is valid at every prime, including the problematic `ell<=H` range.

# 2. Exact endpoint degree H: the ordinary Newton interpolant

At the other endpoint `a=H`, `Q` has degree zero. Taking `Q=1` gives the unique degree-`H` Newton interpolant

```text
F_H(X)=sum_{k=0}^H Delta^k A_0 binom(X,k).
```

It is primitive because `F_H(0)=A_0=1`. Therefore

```text
P_{H,H}=F_H,
G_full(x) | F_H(x).                                (7)
```

Combining (6) and (7),

```text
G_full(x) | A_H(x):=gcd(L_H,F_H(x)).               (8)
```

This is already a useful small-prime reduction: no prime can enter the full family merely from a universal factorial/Smith content. It must simultaneously occur in an actual prefix Apéry value and in the endpoint Newton extrapolant.

# 3. Gcd all adjacent identities; do not multiply them

Use the repository's denominator-degree indexing for a moment. For `0<=b<H`, the exact primitive identity is

```text
P_b(X) Q_{b+1}(X)-P_{b+1}(X) Q_b(X)
    = kappa_{H,b} binom(X,H+1),                    (9)
```

with

```text
kappa_{H,b}
 = binom(H+1,b+1)
   * (top Newton coefficient of P_b)
   * (top Newton coefficient of Q_{b+1}).          (10)
```

Both (9) and (10) are checked in `q32_adjacent_pade_kappa.py` with the primitive normalization.

If `G_full(x)` divides every numerator evaluation, it divides the left side of (9) at `x`, hence

```text
G_full(x) | kappa_{H,b} binom(x,H+1)
```

for every `b`. Taking a gcd over `b` gives

```text
G_full(x)
 | binom(x,H+1) K_H,

K_H := gcd_{0<=b<H} |kappa_{H,b}|.                 (11)
```

This is materially stronger than multiplying the adjacent identities. Multiplication pays the binomial carrier `H` times; (11) pays it **once** and replaces all primitive-normalization pollution by the minimum valuation

```text
d_ell(H)=v_ell(K_H)=min_b v_ell(kappa_{H,b}).      (12)
```

Together with (8) this proves (1).

# 4. Two-carrier factorization

Let

```text
A=A_H(x), B=B_H(x)=abs(binom(x,H+1)), K=K_H.
```

From (8) and (11),

```text
G_full(x) | gcd(A,BK).
```

For every prime `ell`, with `alpha=v_ell(A)`, `beta=v_ell(B)`, `k=v_ell(K)`,

```text
min(alpha,beta+k)
 <= min(alpha,beta)+min(alpha,k).
```

Therefore

```text
gcd(A,BK) | gcd(A,B) gcd(A,K),
```

which is exactly (3):

```text
G_full(x)
 | C_H(x) D_H(x),

C_H(x)=gcd(L_H,F_H(x),B_H(x)),
D_H(x)=gcd(L_H,F_H(x),K_H).                        (13)
```

Since `D_H(x)|K_H`, summing the two signs gives (4).

This is the cleanest interface I can prove from the pushed state.

# 5. The universal part of K_H is already negligible

Formula (10) shows that `kappa_{H,b}` contains the Pascal-row factor

```text
binom(H+1,b+1), 1<=b+1<=H.
```

The classical gcd of the interior binomial coefficients satisfies

```text
gcd_{1<=j<=H} binom(H+1,j)
 = p   if H+1 is a power of a prime p,
 = 1   otherwise.                                  (14)
```

Thus the part of `K_H` which can be forced **solely** by the common binomial row has logarithmic size at most

```text
log(H+1)=o(H).
```

Any linear-size small-prime contribution to `K_H` must therefore come from a simultaneous Apéry-specific divisibility of the primitive leading numerator/denominator coordinates in (10). This is exactly where the missing `Q32_FULL_PADE_GAMMA_ALL_EXPONENTS.md` should enter.

The quantity to extract from that memo is not a sum over degrees but

```text
min_{0<=b<H} v_ell(kappa_{H,b})                    (15)
```

for each `ell<=H`, followed by

```text
sum_{ell<=H} min_b v_ell(kappa_{H,b}) log ell.     (16)
```

If the all-exponents formula implies `(16)=o(H)`, then `(K)` is finished.

# 6. Small-prime replacement for the p>H order-statistic theorem

The exact theorem committed in `1113361cf05bb316c88f1062a15328b47d962ef3` proves, for `p>H`,

```text
v_p(content(P_{H,a}))
 = the (a+1)-st largest of {v_p(A_s):0<=s<=H}.     (17)
```

Its proof needs arbitrary subsets of `a+1` interpolation nodes to remain distinct modulo `p`. That fails at `ell<=H`, so (17) cannot simply be reused there.

What does survive is consecutive-node unimodularity, and it gives (2).

## Lemma

Let

```text
b=H-a,
e_s=v_ell(A_s),
c=v_ell(content(P_{H,a})).
```

Then

```text
L_a := max_{0<=t<=b} min_{t<=s<=t+a} e_s
       <= c
       <=
U_a := min_{0<=t<=a} max_{t<=s<=t+b} e_s.         (18)
```

## Proof of the lower bound

Take any consecutive block

```text
t,t+1,...,t+a.
```

If every `A_s` on that block is divisible by `ell^m`, then

```text
P_{H,a}(s)=A_s Q_{H,a}(s)
```

is divisible by `ell^m` at all `a+1` nodes. Evaluation of a degree-at-most-`a` integer-valued polynomial in the Newton basis at `a+1` consecutive integers has determinant `+-1`. Hence every Newton coefficient of `P_{H,a}` is divisible by `ell^m`. Therefore

```text
c >= min_{t<=s<=t+a}e_s.
```

Maximize over `t`.

## Proof of the upper bound

Take a consecutive block of `b+1` nodes. Suppose

```text
c > max e_s
```

on that block. Then for every node in the block,

```text
v_ell(Q_{H,a}(s))
 = v_ell(P_{H,a}(s))-e_s
 >= c-e_s
 >= 1.
```

The same consecutive-node unimodularity, now for the degree-at-most-`b` denominator, forces every Newton coefficient of `Q_{H,a}` to be divisible by `ell`. Since `c>0`, all numerator coefficients are also divisible by `ell`, contradicting joint primitivity. Thus

```text
c <= max e_s
```

on every such block; minimize over the block start.

This proves (18).

# 7. What Lucas gives at small primes, and what it does not

For an Apéry Lucas prime `ell`, write

```text
Z_ell={r in [0,ell-1]: A_r=0 mod ell}.
```

The Lucas law gives

```text
A_s=0 mod ell
iff at least one base-ell digit of s lies in Z_ell. (19)
```

Therefore (5) immediately gives an exact support restriction:

```text
ell | G_full(x), ell<=H
 => ell | L_H
 => Z_ell is nonempty.                             (20)
```

So the small-prime nuisance is supported only on **actual Apéry-singular primes**. It is not a generic factorial/CRT support.

At exponent one, (18) translates the digit pattern into content information:

```text
c_{ell,a}>=1
if some run of a+1 consecutive prefix indices is entirely in the
Lucas zero language;

c_{ell,a}=0
if some run of H-a+1 consecutive prefix indices consists entirely
of Apéry ell-units.                                (21)
```

This explains why the availability of all degrees helps, but also why Lucas alone does not finish the problem. Once `Z_ell` is nonempty, every interval of `ell` consecutive integers contains every possible low base-`ell` digit, so no such interval can be entirely unit. Thus for genuinely small `ell`, the easy content-free degrees from (21) are forced very near the top of the Padé staircase; there the projective numerator has high degree and can still vanish at the external residue.

The prime `5` is an actual Apéry example of this obstruction, not a generic CRT toy:

```text
A_0,A_1,A_2,A_3,A_4 mod 5 = 1,0,3,0,1,
Z_5={1,3}.
```

Hence the exponent-one zero pattern repeats in every base-5 block. This is consistent with the persistent `5`-power nuisance already seen in the older growing-family experiment (for example the committed Section 161 data include `5^2` at `H=10`, `5^3` at `H=20`, `5^4` at `H=35`). It is **not** evidence that the desired little-oh bound is false; it is evidence that a proof which merely asks for a long zero-free Lucas block cannot work.

To control powers `ell^m`, one really needs the Dwork/all-order refinement of (19). The point of (18) is that it tells exactly how such a refinement has to be inserted: it must bound the sliding-window extrema of `v_ell(A_s)` or the primitive projective evaluation, not merely the radical zero set.

# 8. Why the old smooth determinantal-divisor estimate does not automatically solve Q2637

`q32_delta_smooth.py` records a very attractive precedent for the *raw full Padé determinantal divisor*: prime powers below `sqrt(n)` have total logarithmic weight `O(sqrt(n))`, while primes above `sqrt(n)` satisfy an exact odd-quotient Lucas law.

It is tempting to quote that here. That transfer is not valid without one more argument.

The primitive all-degree values have the bordered-minor form recorded in the Padé family notes:

```text
P_{H,a}(x)
 = +- det([R_{H,a};w(x)]) / delta_{H,a},           (22)
```

where `delta_{H,a}` is the gcd of the maximal minors of the bottom Padé block. At `ell<=H`, these saturation indices carry exactly the small-prime mass which is absent in the large-candidate-prime analysis. Therefore a small-prime bound for the unsaturated determinantal divisor cannot simply be inherited by the individually primitive quotients in (22).

The reduction through `K_H` is a way of packaging those varying saturations after primitivization. If the local Gamma memo gives all `v_ell(delta_{H,a})` / leading-coordinate exponents, the right operation is to take their all-degree minimum through (12), not to invoke the old raw determinant estimate unchanged.

# 9. Relation to the existing all-cutoff and central-binomial work

The committed all-cutoff theorem gives, for `n=q ell+r`, an exact Lucas block law and the folded high-digit loss exponent

```text
e_ell(q)=min(q,ell-1-q),
```

with losses at the cutoffs

```text

```

That result is very useful for locating exponent-one block losses, but it deliberately leaves the height sum open. In particular, it shows why “many available cutoffs/degrees” by itself does not force a little-oh bound: divisibility may disappear and reappear in exact Lucas plateaux.

The central-binomial scripts make the same warning in a different form. `q32_central_gcd.py` verifies the exact top-half support equivalence (apart from the finite boundary) between the q=1 target and

```text

```

`q32_inverse_denominator_audit.py` gives an exact inverse-central-binomial defect carrier with the same top-half target support. These are support equivalences, not an unconditional proof that their entire small-prime logarithmic height is `o(n)`.

Therefore reducing `(C)` to the already known central-binomial carrier is useful only if the newer local “central-binomial height equivalence” genuinely contains a proved *height* estimate, rather than another support equivalence. # 10. The exact remaining theorem I would attack

The full Q2637 estimate follows from the conjunction of the following two statements.

## Kappa-minimum lemma

For fixed `q` and the height/evaluation regime of the full-degree reduction,

```text
sum_{ell<=H} min_b v_ell(kappa_{H,b}) log ell = o(H).   (K*)
```

Because of (14), only the Apéry leading-coordinate part of `kappa` is substantive. If `Q32_FULL_PADE_GAMMA_ALL_EXPONENTS.md` contains an exact all-degree valuation formula, `(K*)` is the first thing to test: minimize its exponent formula in `b` before summing in `ell`.

## Endpoint-binomial lemma

For each sign,

```text
C_H^+- = gcd(
    L_H,
    F_H(x_+-),
    binom(x_+-,H+1)
),
```

and one needs

```text
log (C_H^+ C_H^-)_{<=H} = o(H).                    (C*)
```

This is already a much smaller statement than controlling every primitive Padé numerator separately. It involves only the two endpoint degrees plus one binomial carrier. It is also the place where the central-binomial height equivalence should be inserted if that newer theorem is available locally.

Then (4) gives immediately

```text
sum_{ell<=H} v_ell(G_full^+G_full^-) log ell
 <= o(H)+2o(H)
 = o(H).
```
