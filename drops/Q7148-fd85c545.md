## 1. Define `j_act(t)` on actual same-lift lower-`E3` occurrences

Fix all data that OV-SETF-K regards as fixed at `g4`, including the same lift and lower `E3` token type.  Let `Omega` be the **actual surviving occurrence multiset** after the deterministic SETF-K gates.  An element of `Omega` is an occurrence, not merely a distinct algebraic endpoint.

For a fixed same-lift lower-`E3` token `t`, define

\[
\boxed{
 j_{\rm act}(t)
 :=\#\{\omega\in\Omega:\operatorname{tok}(\omega)=t\}.
}
\tag{5}
\]

If the physical bookkeeping maps an occurrence to a bounded number of token presentations, (5) is taken with that bounded multiplicity.  Do **not** replace (5) by the number of distinct endpoint values: that loses exactly the occurrence multiplicity that the tail argument has to preserve.

Let

\[
 s:\Omega\to\mathscr S
\]

be the endpoint-fibre map.  For an endpoint fibre `s` put

\[
\Omega_s:=\{\omega\in\Omega:s(\omega)=s\},
\qquad
j_s:=|\Omega_s|.
\tag{6}
\]

Equivalently, when each token has one endpoint fibre,

\[
j_s=\sum_{t:\,s(t)=s}j_{\rm act}(t).
\tag{7}
\]

This is the correct heavy variable.  The dyadic fibre layer is

\[
\mathscr S_J:=\{s:J\le j_s<2J\},
\qquad
X_J:=\sum_{s\in\mathscr S_J}j_s.
\tag{8}
\]

`X_J` is **occurrence mass**, not number of fibres.

## 2. Occurrence-preserving endpoint lemma

Define the first three falling-factorial endpoint moments on the same `Omega`:

\[
M_1=\sum_s j_s,
\quad
M_2=\sum_s(j_s)_2,
\quad
M_3=\sum_s(j_s)_3,
\tag{9}
\]

where `(j)_r=j(j-1)...(j-r+1)`.

### Lemma

For every integer `J >= 3`,

\[
\boxed{
X_J\le
\min\left\{
 M_1,
 \frac{M_2}{J-1},
 \frac{M_3}{(J-1)(J-2)}
\right\}.
}
\tag{10}
\]

### Proof

For every `s in S_J`, `j_s >= J`, hence

\[
(j_s)_2=j_s(j_s-1)\ge (J-1)j_s
\]

and

\[
(j_s)_3=j_s(j_s-1)(j_s-2)
\ge (J-1)(J-2)j_s.
\]

Sum over the **same fibres and same occurrences**.  This gives the second and cubic terms in (10); the first is tautological.  No independence statement occurs anywhere.  QED.

This is the key correction to the tempting but invalid calculation

```text
(endpoint tail) * (raw-u tail) * (translated-pair density).
```

Those quantities are projections of the same occurrence set.  Their valid combination is an intersection/minimum after putting them on the same counting measure.

## 3. How raw `u`, translated pairs, and lower `E3` enter without fake independence

There are two different kinds of banked tail statements, and they must not be conflated.

### 3.1 A raw tail counting fibres/tokens

If the banked raw statement is

\[
N_u(J):=\#\{s:j_s\ge J\}\le U(J),
\tag{11}
\]

then on a dyadic layer

\[
\boxed{X_J\le 2J\,U(J).}
\tag{12}
\]

If the banked raw statement already bounds weighted **occurrence mass** `U_occ(J)`, then use instead

\[
X_J\le U_{\rm occ}(J).
\tag{13}
\]

Multiplying (12) by (10) is wrong; take their minimum.

### 3.2 A translated-pair incidence bound

Let `Gamma_J` be the actual ordered translated-pair incidence relation on occurrences in the layer.  Suppose the geometry gives a deterministic lower degree

\[
d_{\rm tr}(J)
\le \#\{\omega':(\omega,\omega')\in\Gamma_J\}
\quad
\text{for every relevant }\omega,
\tag{14}
\]

and the banked translated-pair theorem gives

\[
|\Gamma_J|\le P_{\rm tr}(J).
\tag{15}
\]

Then, because (14) and (15) count the **same incidences**,

\[
\boxed{X_J\le P_{\rm tr}(J)/d_{\rm tr}(J).}
\tag{16}
\]

For an unordered-pair convention there is only the harmless factor `2`.

This lower-degree hypothesis is essential.  A global pair bound by itself is **not** a bound for `X_J`; one cannot silently divide by an “expected number of partners”.

### 3.3 Lower `E3`

The lower-`E3` bank must likewise be put on the actual occurrence measure.  If it is a direct occurrence cap `E_3(J)`, use

\[
X_J\le E_3(J).
\tag{17}
\]

If it is an incidence cap, first divide by the deterministic per-occurrence `E3` degree exactly as in (16).  Again, no product of marginals is legal.

### 3.4 Combined theorem

Under (11), (14)--(17), for `J>=3`,

\[
\boxed{
X_J\le
\min\left\{
M_1,
\frac{M_2}{J-1},
\frac{M_3}{(J-1)(J-2)},
2J U(J),
\frac{P_{\rm tr}(J)}{d_{\rm tr}(J)},
E_3(J)
\right\}.
}
\tag{18}
\]

Equation (18) is the requested occurrence-preserving theorem.  It is not a relabeling of the target: each term is a banked statistic and the proof is a deterministic counting injection/inequality on the original occurrences.

## 7. The smallest heavy-centred off-diagonal moment

Once all layers satisfying (26) are discarded by existing banked bounds, restrict to

\[
\Omega_{\rm heavy}

\[
\boxed{
\mathcal M^{\rm heavy}_{2,\rm off}
:=\sum_{a\in\mathcal A_D}|Y_a-\mu_a|^2,
\qquad |\mathcal A_D|\asymp D.
}
\tag{36}
\]

The definition must retain:

1. actual occurrence multiplicity from (5)--(8);
2. the actual translated-pair relation, not a product measure;
3. the lower-`E3` same-lift restriction;
4. exclusion of the same endpoint-fibre diagonal already paid for by endpoint moments.

Then Cauchy gives

\[
|\mathcal E_{\rm heavy}|
\le D^{1/2}

\tag{37}
\]

To force the desired residual bound

\[
|\mathcal E_{\rm heavy}|\ll D R_\theta H^{o(1)},

\[
\mathcal M^{\rm heavy}_{2,\rm off}
