```text

    many characteristics p_i, one prescribed zero block in each p_i.
```

Equivalently, the new detector recognizes

\[

whereas a high-load fixed-`q` row gives

\[
Z_{p_i}(j_i)\wedge Z_{p_k}(j_k),\qquad p_i\ne p_k.

\[
p_i\mid b_{j_k}
\]

1. **Common fixed-q anchor.**  All candidate primes act on the same characteristic-zero Padé coefficient vector. There is no second null direction for the rank-two detector to see.

The resulting per-prime marked carrier is actually tautological: after inserting the linear crossing factor it is exactly `p`.  Multiplying these carriers gives back the target radical itself and no independent height upper bound.

So my classification is:

> **No current join.**  The first obstruction is a `one-characteristic/two-zero` versus `many-characteristic/one-zero` signature mismatch.  The associated height obstruction appears immediately if one tries to repair that mismatch by importing the reflection mate.

# 1. Fixed-q target in variables that can actually be joined

Fix an odd quotient `q` and an integer `n`.  For a candidate prime

\[
p\in I_q(n):=\left(\frac{n}{q+1},\frac nq\right],
\]

write

\[
n=qp+r_p,\qquad 0\le r_p<p,
\]

and fold the lower digit by

\[
j_p=\min(r_p,p-1-r_p).
\]

The fixed-q truncation index is

\[
J=J_q(n):=\left\lfloor\frac{n-q}{2q+1}\right\rfloor.                 \tag{1.1}
\]

The crucial good feature is that `J` depends only on `(n,q)`, **not** on the candidate prime `p`.

Let

\[
T_{n,q}(c)=\sum_{d=0}^n C_d(n,q)c^d
\]

be the fixed-q Legendre--Euler truncation used by `q32_fixed_q_content.py`, and let

\[
\Gamma_{n,q}:=\gcd_{0\le d\le n} C_d(n,q).                          \tag{1.2}
\]

The exact Lucas block law encoded there is

\[
T_{n,q}(c)\equiv b_{j_p}Q_q(c^p)\pmod p,
\qquad
Q_q(t)=\sum_k\binom qk\binom{q+k}{k}t^k.                            \tag{1.3}
\]

Since the constant coefficient of `Q_q` is 1,

\[
p\mid\Gamma_{n,q}
\iff
p\mid b_{j_p}                                                          \tag{1.4}
\]

for the fixed-q candidates in the range of the reduction.  Define

\[
\mathcal S_q(n)
 =\{p\in I_q(n):p\mid b_{j_p}\},
\qquad
L_q(n)=|\mathcal S_q(n)|,                                               \tag{1.5}
\]

and the slice radical

\[
R_q(n):=\prod_{p\in\mathcal S_q(n)}p.                                  \tag{1.6}
\]

Then

\[
R_q(n)\mid\Gamma_{n,q}.                                                  \tag{1.7}
\]

Moreover `q32_content_smith.py` identifies the local Smith exponent.  Away from the one midpoint configuration, a bad candidate occurs in the content with exponent exactly one.  Thus the fixed-q carrier is genuinely a **singleton carrier**, not a hidden source of extra powers.

Because every `p` in the slice is comparable to `n`,

\[
L_q(n)\bigl(\log n-\log(q+1)\bigr)
\le \log R_q(n)
\le L_q(n)\bigl(\log n-\log q\bigr).                                  \tag{1.8}
\]

Therefore

\[
\boxed{
\log R_q(n)=o_q(n)
\iff
L_q(n)=o_q(n/\log n).
}                                                                       \tag{1.9}
\]

This is the exact target ledger.  Any successful join must manufacture a characteristic-zero integer/divisor `D_{n,q}` satisfying

\[
R_q(n)\mid D_{n,q},
\qquad
\log|D_{n,q}|=o_q(n).                                                    \tag{1.10}
\]

The old content itself only gives the correct divisibility half.  A crude bound from any one coefficient of `T_{n,q}` gives

\[
\log\Gamma_{n,q}=O_q(n),                                                \tag{1.11}
\]

which is exactly linear and therefore insufficient.

## 3.1 The exact Smith signature of the fixed-q coefficient matrix

Let `F=(F_0,...,F_J)^T` be the Franel input vector and let `M=M_{n,q}` be the integer coefficient map such that

\[
C=M F.                                                                  \tag{3.1}

Let

\[
P_{n,q}=\prod_{\substack{p\ge7\\ \lfloor n/p\rfloor=q}}p              \tag{3.2}

be the squarefree product of all fixed-q candidate primes, target or not.

The integral elimination in `q32_content_smith.py` gives

\[
M\sim \operatorname{diag}(1,P_{n,q}W)                                  \tag{3.3}
\]

under unimodular row/column operations, and

\[
\operatorname{content}(MF)
 =\gcd\!\left(S,
      P_{n,q}\gcd_d (WF)_d\right),                                     \tag{3.4}
\]

where `S` is the zeroth/anchor coefficient.

For every non-midpoint candidate `p`, the reverse-triangular diagonal of `W` is a list of `p`-units; in particular

\[
W\bmod p\quad\text{has full column rank}.                              \tag{3.5}
\]

This gives an exact dichotomy.

### Raw matrix

Modulo every candidate `p`, target **or not**, the factor `P_{n,q}` makes the lower Smith block vanish.  Thus a raw rank defect of `M mod p` is **universal candidate-prime structure**, not target structure.  A determinant/cofactor detector applied before primitive division is swamped by false positives.

### Primitive residual matrix

After the universal candidate factor is divided out, `W mod p` is invertible/full-rank.  Targetness does **not** produce a rank defect in `W`.  It is only the scalar condition

\[
S\equiv b_{j_p}\equiv0\pmod p.                                        \tag{3.6}

Therefore a rank-two cofactor detector applied after primitive division sees no second null direction at all.

This is the first fixed-q signature mismatch in its cleanest form:

```text
Q2699 detector input:      corank >= 2 of one local matrix mod p;
fixed-q primitive input:  full-rank W mod p + one scalar S(F)=0 mod p.
```

There is no choice of endpoint principal cofactor inside the current primitive fixed-q coefficient block that turns (3.6) into an independent second zero: the structural Smith calculation says precisely that the residual block is a `p`-unit.

Hence **the direct fixed-q endpoint-Padé transport fails**.

 =\gcd\!\left(

\prod_{p\in\mathcal S_q(n)}\widetilde C_p=R_q(n).                       \tag{5.6}

p-1-j>J                                                               \tag{5.12}

Thus the fixed-q rectangle has exactly the folded representative available to its low-digit reduction; the same-orbit reflection mate lies beyond the truncation.

This is the height version of the signature mismatch.

# 7. Shell / TCUS join: unit synchronization does not synchronize the zero coordinate

The shell/TCUS route can be abstracted to the exact local data needed here.

For each candidate characteristic `p`, after primitive division choose a two-border vector

\[
v_p=(a_p,u_p)\in\mathbf Z^2                                              \tag{7.1}
\]

such that at a target

\[
a_p\equiv0\pmod p,
\qquad
u_p:=u_p\bmod p\in\mathbf F_p^\times.                                  \tag{7.2}
\]

The nonzero second coordinate is precisely the endpoint-cofactor/shell weak-edge witness that the zero is a singleton.

A two-characteristic common-unit normalization can rescale the second coordinates so that, schematically,

\[
u_p\mapsto1,
\qquad
u_{p'}\mapsto1.                                                         \tag{7.3}
\]

But now form the only natural rank-two characteristic-zero join,

\[
D_{p,p'}=\det(v_p,v_{p'}).                                              \tag{7.4}
\]

Modulo `p`, using (7.2),

\[
D_{p,p'}
\equiv -u_p\,a_{p'}\pmod p.                                            \tag{7.5}
\]

After the unit normalization (7.3), this is simply

\[
D_{p,p'}\equiv-a_{p'}\pmod p.                                          \tag{7.6}
\]

Therefore

\[
p\mid D_{p,p'}
\iff
p\mid a_{p'}.                                                           \tag{7.7}
\]

That is: the second **anchor** must also be a zero in characteristic `p`.

The target fact for `p'` is only

\[
p'\mid a_{p'},                                                         \tag{7.8}
\]

which says nothing about (7.7).

So TCUS can identify/synchronize the **unit coordinate**, but the obstruction lives in the **zero coordinate**.  A unit rescaling cannot move a zero from characteristic `p'` into characteristic `p`.

This is the exact anchored-singleton mismatch, not a vague appeal to missing cross-prime information.

## 7.1 Common anchor versus local anchor is exhaustive for the present constructions

There are only two ways the current machinery tries to avoid (7.7):

1. Move all local anchors to one fixed `(n,q)` anchor.  Then we are back in Section 3, where the zero becomes the common scalar `S=b_j` and the primitive residual block `W` is invertible.

2. Keep the rank-two local endpoint geometry.  Then the anchors differ with `p`, and (7.5) shows the cross wedge is a unit unless there is an actual same-characteristic cross-hit.

Thus the current endpoint-Padé and shell/TCUS mechanisms meet on opposite sides of the same wall.

\]

upgrade.

This is the cleanest way I know to state why the new M1 result, although genuinely stronger locally, does not yet attack the main fixed-q frontier.

# 11. What exact new lemma would make a join work

The analysis isolates a more precise target than “cross-prime information.”

A successful join needs a **zero-coordinate transporter**, not merely a common-unit theorem.

One sufficient form would be:

> **Fixed-q singleton second-border lemma.**  For each fixed `q`, construct two characteristic-zero integers/polynomial coefficients
> \[
> A_{n,q},B_{n,q}\in\mathbf Z
> \]
> independent of the candidate prime `p`, such that for every sufficiently large non-midpoint
> \[
> p\in I_q(n),\quad p\mid b_{j_p},
> \]
> one has
> \[
> p\mid A_{n,q},\qquad p\mid B_{n,q},                                  \tag{11.1}
> \]
> while after all universal candidate factors are removed the two rows are independent modulo `p`, and
> \[
> \log\gcd(A_{n,q},B_{n,q})=o_q(n).                                    \tag{11.2}
> \]

Then immediately

\[
R_q(n)\mid\gcd(A_{n,q},B_{n,q})                                       \tag{11.3}
\]

and (1.8) gives

\[
L_q(n)\log(n/(q+1))
\le o_q(n),                                                             \tag{11.4}
\]

hence

\[
\boxed{L_q(n)=o_q(n/\log n).}                                          \tag{11.5}
\]

The current endpoint/cofactor construction does **not** supply (11.1): at a singleton it deliberately gives one zero coordinate and one unit coordinate.

The current TCUS/common-unit mechanism addresses the unit coordinate in (7.2), whereas the missing theorem must transport the zero coordinate itself from the moving local anchor to a common `(n,q)` anchor **without** collapsing into the already-known scalar content `S` and without reintroducing the universal candidate product `P_{n,q}`.

That is, in my view, the exact next algebraic interface worth searching for.

A second possible sufficient input is simply the pointwise fixed-q singleton theorem isolated by Q2719:

\[
\sup_{N<n\le2N}L_q(n)=o_q(N/\log N).                                  \tag{11.6}
\]

But that is the frontier itself, not a join.

# 12. Final classification

The rank-two endpoint/cofactor repair is real and valuable, but its natural domain is **same-characteristic pair mass**.  It removes the old M1 spectral `OR` contamination exactly.  It does not convert a cross-characteristic rainbow pile-up into a common small integer.

The fixed-q Padé carrier and the rank-two detector fail to join for a very specific reason:

```text
fixed common anchor:
    target = one scalar zero;
    primitive residual matrix = invertible mod p.

local rank-two anchor:
    target = one zero + one cofactor unit;
    second target prime lives at another anchor/characteristic.

cross wedge:
    zero_i * unit_k - unit_i * zero_k
    is NOT zero mod p_i, because zero_k is only zero mod p_k.
```

The reflection mate supplies the missing same-`p` zero only outside the fixed-q truncation, forcing `H=p` and destroying the height budget.  The quotient-three seam reaches only a bounded central fringe unless it is enlarged linearly.  TCUS can synchronize endpoint units but cannot synchronize the moving zero anchors.

The quantitative ledgers confirm that no hidden win remains:

\[
\log R_q(n)\asymp L_q(n)\log n,                                       \tag{12.1}
\]

so the fixed-q goal is exactly `o(n)` height; the current common content gives only `O(n)`.  On the pair side, the strongest current first-moment plus pointwise zero-count bounds give

\[
\sum_{X<p\le2X}\binom{z_p}{2}\log p
\ll X^{34/15},                                                         \tag{12.2}
\]

not `o(X^2)`.  And even a future pair-second-moment theorem would not by itself exclude a single rainbow high-load row.

So the answer to Q2718 is **no current join**, with the first signature mismatch precisely identified as

\[
\boxed{
\text{same characteristic / two zeros}
\quad\text{vs.}\quad
\text{many characteristics / one zero each}.
}
\]

The next genuinely new algebraic object would have to be a **common-anchor zero-coordinate transporter** (or an equivalent second characteristic-zero border) whose primitive height is `o(n)`.  A common-unit normalization alone is one coordinate short.
