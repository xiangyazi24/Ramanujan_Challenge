# Gap-polynomial + birthday paradox analysis of the top-window load

## 1. The proposed direction is genuinely different from the first-moment route

The key distinction is between an **average over n** statement and a **uniform pointwise bound**.

For the top window

\[
 n/2<p\le n,
\]

we have

\[
p\mid b_n \iff n\bmod p\in Z_p.
\]

Writing

\[
K(n)=\#\{p\in(n/2,n]:n\bmod p\in Z_p\},
\]

we want a bound holding for every n.

A first moment estimate

\[
\sum_p \frac{|Z_p|}{p}
\]

only controls the average of K(n). It cannot exclude exceptional n with unusually many hits.

Therefore the birthday/gap-polynomial idea is aimed at exactly the missing step: converting local zero-set sparsity into a deterministic bound on a single orbit point.

---

# 2. The first obstacle: the birthday heuristic is not automatically valid

The heuristic says:

- each prime p has a set Z_p of size about n^{2/3};
- the residue n mod p is one point in a universe of size about n;
- if K primes hit, collisions should occur.

However, the variables are not random.

The residues

\[
r_p=n\bmod p
\]

are coupled by the single integer n.

For different primes p,q, the pair

\[
(r_p,r_q)
\]

is not uniformly random unless one averages over n in a complete CRT box.

So the birthday paradox cannot directly give a pointwise theorem.

A counterexample to the naive reasoning would be a structured family where many primes choose their allowed residues so that one particular n is hit repeatedly.

The gap polynomial is precisely the tool needed to rule out such adversarial alignment.

---

# 3. What a collision actually means

Suppose two primes p,q both hit n:

\[
r=n\bmod p\in Z_p,
\]

\[
s=n\bmod q\in Z_q.
\]

Because p,q are both larger than n/2, we have

\[
r=n-p,
\]

\[
s=n-q.
\]

Thus

\[
p=n-r,\qquad q=n-s.
\]

A collision of residue values means

\[
r=s.
\]

Then

\[
p=q,
\]

so distinct primes cannot have the same literal residue in the top window.

This is actually stronger than the birthday analogy suggests:

> The top-window map p -> n mod p is injective.

Therefore the correct collision notion is not equality of residues.

The useful collision is an **algebraic collision**: many distinct pairs (p,r) satisfying

\[
p-r=n
\]

with

\[
r\in Z_p.
\]

The same n lies on many zero loci.

---

# 4. The gap-polynomial mechanism

For each prime p, the zero set

\[
Z_p=\{r:b_r\equiv0\pmod p\}
\]

has no consecutive elements and satisfies the gap-polynomial constraints.

If a polynomial relation detects many zeros in an interval, then the corresponding finite-field polynomial must vanish identically or have bounded degree.

The existing bound

\[
|Z_p|\ll p^{2/3}
\]

comes from exactly this phenomenon.

To improve K(n), we need to apply the same idea in the opposite direction:

Assume

\[
K(n)=M.
\]

Then there are M primes

\[
p_i\in(n/2,n]
\]

with

\[
b_{n-p_i}\equiv0\pmod {p_i}.
\]

Equivalently, the points

\[
(n-p_i,p_i)
\]

lie on the Apéry zero correspondence.

A large M creates a high-density set of Frobenius constraints.

The missing theorem would say that such a configuration forces too many zeros of a low-degree gap polynomial.

---

# 5. The plausible quantitative target

The desired statement is

\[
K(n)\ll n^{2/3+\epsilon}.
\]

This would imply

\[
\sum_{p>\sqrt n,p|b_n}\log p
\ll n^{2/3+\epsilon}\log n=o(n),
\]

which is enough for the GCD conjecture.

The exponent 2/3 is natural because it is the current zero-set exponent.

The question is whether one can transfer

\[
|Z_p|\ll p^{2/3}
\]

from individual primes to the simultaneous condition over many primes.

---

# 6. Why the simple counting argument fails

A tempting argument is:

Each prime contributes one residue slot among at most p^{2/3} possibilities, therefore many primes must collide.

But the slots live in different fields:

\[
Z_p\subset\mathbf F_p.
\]

There is no common ambient set.

The correct ambient object is the set of integers

\[
\{(p,r):p-r=n,\ r\in Z_p\}.
\]

A bound on this incidence set is needed.

This is an incidence problem, not a birthday problem.

---

# 7. A possible rigorous route

A viable theorem would look like:

For every N and every set of primes

\[
P\subset(N/2,N],
\]

we have

\[
\#\{p\in P:n-p\in Z_p\}
\ll N^{2/3+o(1)}.
\]

To prove this one could attempt:

1. Assume M hits.
2. Construct a polynomial or determinant annihilating all hit residues.
3. Use the gap-polynomial degree bound.
4. Show M above N^{2/3+epsilon} forces a contradiction.

This resembles:

- large sieve for moving moduli;
- determinant method incidence bounds;
- Bombieri-Pila style counting of integral points.

The key new ingredient is that the Apéry zero condition is algebraic, not arbitrary.

---

# 8. Connection with the previous approaches

This route is actually a bridge between the moment method and the finite-field method.

The high-moment method tries to prove:

\[
\mathbb E[(K)_3]\ll1.
\]

The gap-polynomial incidence method tries to prove the stronger pointwise statement:

\[
K(n)\ll n^{2/3+o(1)}.
\]

If successful, it bypasses all probabilistic independence issues.

The reason this is attractive is that it uses the strongest known structural fact:

\[
|Z_p|\ll p^{2/3}.
\]

It does not need Sato-Tate or cross-prime independence.

---

# 9. Verdict

The birthday paradox intuition is not literally correct because the residues are not random and the residue spaces differ for every prime.

But the underlying idea is sound after reformulation:

> A large K(n) would create an impossible high-density incidence pattern between primes and Apéry zero sets.

The missing theorem is not a probabilistic collision bound. It is an algebraic incidence theorem:

\[
\boxed{K(n)\ll n^{2/3+\epsilon}}.
\]

The gap-polynomial machinery is the most plausible tool for proving it.

If this theorem is established, it would immediately imply the Apéry GCD conjecture because the remaining contribution is

\[
B(n)\ll K(n)\log n=n^{2/3+\epsilon}\log n=o(n).
\]

So this is a viable new route, but the decisive missing lemma is a **moving-modulus Apéry incidence bound**, not the birthday paradox itself.
