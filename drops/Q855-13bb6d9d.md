# Q855 audit: ALCT => AAT => AT'' dependency chain

## 1. Verdict

The implication chain is **not valid as written**. The issue is the small-lambda regime in AT''. The statement

```
max_{K <= lambda_X} K <= lambda_X X^o(1)
```
(or the equivalent shell-tail form without the additive baseline) cannot follow from ALCT and is false whenever a shell contains a single active zero prime: the left side can be 1 while lambda_X tends to 0.

The chain is repairable by replacing every such bound by a centered factorial-tail statement with the natural normalization

```
K <= (1 + lambda_X) X^o(1).
```

No lower bound lambda_X >= X^{-o(1)} is needed.

## 2. Correct probability space

For a fixed dyadic scale X, the probability space is the uniform choice of a shell column (equivalently the relevant fixed-q affine column) among the admissible columns. Let

```
Z_i = 1_{p_i divides b_m}
```

be the centered prime-zero indicators. The shell load is

```
K = sum_i Z_i,
```
with mean

```
lambda_X = E K.
```

The all-index theorem requires control of the maximum over about X^2 columns, so the failure probability for a single column must be at most X^{-2-o(1)}.

## 3. What ALCT actually gives

An ALCT hypothesis of the needed strength is not a pointwise maximum estimate. It is a cumulant bound:

```
|kappa_r(K)| <= C_r (1+lambda_X) L_X^r
```

for all r through a truncation order L_X growing like c log X. The constants must be uniform over shells and fixed-q families.

The moment-cumulant formula then gives factorial moments

```
E (K)_r <= (1+lambda_X)^r X^{o(1)}
```

for r <= L_X.

## 4. Correct tail extraction

Using

```
1_{K >= T} <= (K)_r/(T)_r
```

and choosing r approximately c log X gives

```
P(K >= T) <= ((1+lambda_X)/T)^r X^{o(1)}.
```

For T above the required high-load threshold this is X^{-A} with A>2, which is enough for the union bound over all columns.

The proof must therefore use a factorial tail estimate directly; an intermediate AT'' maximum statement is unnecessary.

## 5. Relation to AAT and AT''

The repaired chain is:

```
ALCT (uniform cumulants)
      |
      v
factorial moments / high tail
      |
      v
AAT (atom tail bound with 1+lambda baseline)
      |
      v
AT'' (only after corrected normalization)
      |
      v
all-index theorem.
```

The uncorrected AT'' drops the baseline term and is stronger than what ALCT implies.

## 6. Weakest useful hypothesis

The weakest direct hypothesis is not a maximum bound. It is:

For every fixed A>2 there exists r_X=O(log X) such that uniformly for every shell column,

```
E (K)_r_X <= X^{o(1)}(1+lambda_X)^r_X
```

and

```
((1+lambda_X)/T_X)^r_X <= X^{-A-o(1)}
```

for the target threshold T_X.

This skips the invalid AT'' step and directly proves the required high-load exclusion.

## 7. Conclusion

The dependency map must be repaired. ALCT does not imply the displayed AT'' when lambda_X can be small. The corrected theorem is:

```
ALCT with factorial/cumulant control through c log X
=> corrected AAT with baseline 1+lambda_X
=> high factorial tail bound
=> all-index theorem.
```

The additive 1 is essential: it represents the unavoidable contribution of isolated active primes and cannot be removed without an extra hypothesis excluding sparse shells.
