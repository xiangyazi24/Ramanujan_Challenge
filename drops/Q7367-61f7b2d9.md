# Q32 three-moment gcd height attack

## Verdict

**Top verdict: NO APPLICABLE THEOREM.**

The existing gcd theorems for linear recurrences, holonomic sequences, G-functions, Subspace Theorem arguments, and Padé approximation do not directly prove

```
log gcd(L_n,U_1(n),U_2(n),U_3(n)) = o(n).
```

The obstruction is not the Apéry recurrence. The obstruction is that the common divisor is taken after multiplying three different rational holonomic sequences by the moving denominator powers `L_n^s`, and the relevant arithmetic information is concentrated at the finite set of primes `q <= n` whose valuations vary irregularly with `n`.

## 1. Known applicable structure

Let

```
R_s(n)=sum_{k=1}^n b_(n-k)/k^s.
```

Then

```
R_s(n)=[t^n] B(t) Li_s(t),
U_s(n)=L_n^s R_s(n).
```

The Apéry generating function `B(t)` is a G-function and satisfies a Picard-Fuchs differential equation. Closure properties of G-functions imply that `B(t)Li_s(t)` is again holonomic. Hence each fixed `s` gives a P-recursive rational sequence.

However, the desired object is not a gcd statement about `R_s(n)` or a fixed recurrence sequence. It is

```
gcd(L_n, L_n R_1(n), L_n^2 R_2(n), L_n^3 R_3(n)).
```

The factor `L_n` is not P-recursive and has no fixed recurrence compatible with the Apéry operator.

## 2. Why P-recursive gcd theorems do not apply

A typical recurrence gcd theorem has the form:

```
For a fixed integer linear recurrence sequence a_n satisfying
sum_{i=0}^d c_i a_(n+i)=0
with fixed integer coefficients and nondegenerate characteristic roots,
prime divisors/common divisors of a_n and b_n have restricted growth.
```

Examples include results of Corvaja-Zannier on integral values of recurrence sequences and gcd growth of sequences.

The required hypotheses fail:

1. The sequences `U_s(n)` are not given as fixed integer recurrences.
2. The denominator clearing factor `L_n^s` changes with n and introduces all primes up to n.
3. We need a simultaneous gcd among three unrelated denominator-scaled sequences.

The fact that `R_s` is holonomic is insufficient because holonomicity is a statement over characteristic zero functions, not a statement controlling reductions modulo every prime dividing `L_n`.

## 3. G-function denominator estimates

The main G-function theorem is the André/Chudnovsky theory: a G-function has coefficients with controlled denominator growth and satisfies a differential equation with arithmetic bounds.

A representative statement:

```
If f(t)=sum a_n t^n is a G-function, then there exist constants C such that
common denominators of a_0,...,a_n divide an integer of size exp(C n).
```

Primary sources:

- Y. André, *G-functions and Geometry*, Vieweg, 1989.
- G. Chudnovsky and D. Chudnovsky, theory of G-functions.

This gives an upper bound on denominator growth. It does not give lower bounds on cancellation of the form

```
ord_q(gcd(L_n,U_1,U_2,U_3)).
```

The missing ingredient is independence modulo every small prime.

## 4. Subspace Theorem route

The Subspace Theorem controls solutions to linear forms in logarithms or S-unit equations.

A standard consequence:

```
Solutions to a fixed nondegenerate S-unit equation
x_1+...+x_m=1
have finite exceptional structure.
```

Primary source:

- W. Schmidt, *Diophantine Approximation*, Lecture Notes in Mathematics 785.
- Evertse-Schlickewei-Schmidt, quantitative Subspace Theorem.

This does not apply because the relevant S-set is

```
S_n={q prime : q<=n},
```

which grows with n. Moreover the three quantities are not values of fixed S-units. The moving set of allowed primes is exactly the arithmetic difficulty.

Algebraic independence of `Li_1,Li_2,Li_3` or of the underlying periods cannot imply a gcd estimate. Independence controls analytic relations, not p-adic valuation cancellation.

## 5. Padé approximation route

Apéry's original method uses simultaneous Padé approximation. Such methods can prove irrationality and linear independence by constructing small linear forms:

```
A_n zeta(2)+B_n zeta(3)+C_n -> 0.
```

But the desired statement is different. It asks for a bound on the integer content after clearing all small denominators.

A Padé estimate gives archimedean smallness:

```
|linear form| < exp(-c n).
```

It does not prevent the coefficient vector from having a large common divisor.

## 6. Sharp intermediate statement that would imply the target

The exact missing lemma is a simultaneous local non-saturation statement:

For every epsilon > 0, there exists N such that for n>N,

```
sum_{q<=n} min(
 v_q(L_n),
 v_q(U_1(n)),
 v_q(U_2(n)),
 v_q(U_3(n))
) log q
 <= epsilon n.
```

Equivalently, one needs a uniform bound on the common q-adic content of the vector

```
(L_n,U_1(n),U_2(n),U_3(n))
```

over all moving primes q.

No currently standard holonomic theorem supplies this.

## 7. Apéry-specific possible route

The plausible route is not analytic gcd theory but local Apéry structure.

A successful proof would likely need:

1. Derive the exact mod-q reduction of

```
R_s(n)=sum b_(n-k)/k^s
```

for each q dividing L_n.

2. Separate primes according to q|n and q<n.

3. Use the Apéry recurrence modulo q to identify when

```
U_1,U_2,U_3
```

vanish simultaneously modulo q.

4. Prove that high q-adic valuation forces a rare exceptional congruence.

This would be a new nonarchimedean theorem about the Apéry G-function, not an application of an existing holonomic gcd theorem.

## 8. Why archimedean asymptotics fail

The asymptotic size of `U_s(n)` is approximately controlled by the dominant singularity of the Apéry generating function. This explains the observed height:

```
log |U_s(n)| = Theta(n).
```

But gcd is an arithmetic cancellation phenomenon. Two integers of size `exp(c n)` can have gcd `1` or `exp(c n)` without changing archimedean asymptotics.

Therefore:

```
archimedean growth != arithmetic content control.
```

The computation through n=3000 is evidence of local randomness, but it is not converted into a theorem without a prime-by-prime argument.

## Final assessment

The target remains a **live reduction**, not a proved consequence of known gcd theory. The sharp next theorem is a uniform p-adic non-saturation statement for the triple of Apéry polylogarithmic coefficient sequences after LCM denominator clearing. Proving that statement would likely solve the required gcd bound, but it is currently an Apéry-specific new theorem rather than an instance of existing P-recursive, G-function, Subspace Theorem, or Padé approximation machinery.
