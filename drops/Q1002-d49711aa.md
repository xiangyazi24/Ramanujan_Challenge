# Hostile repair of shell reciprocity attack

## 1. Correct phase identity

Let

```
u = q^{-1} (mod p),   v = p^{-1} (mod q).
```

For integer residues `s_p,s_q` and integer frequency `k`,

```
e_p(k u s_p)e_q(k v s_q)
 = e_pq(k(q u s_p+p v s_q)).
```

Since

```
q u = 1 + p alpha,
p v = 1 + q beta,
```

we have

```
q u s_p+p v s_q
 = s_p+s_q+p alpha s_p+q beta s_q,
```

and the ordered shell kernel is rewritten as

```
e_pq(k s_p)e_q(k v(s_q-s_p))
```

with no division by `p` or `q` modulo itself.

The previous expression

```
e((a q-b p)/(pq)) = e_p(aq^{-1})e_q(-bp^{-1})
```

fails because the integer lifts of the two CRT components differ by a nonzero rational phase.

## 2. Exact shell reduction

The unequal-prime contribution has the form

```
S = sum_{p != q in (X,2X]} W(p,q)
       sum_k K(k)
       e_p(k u s_p)e_q(k v s_q),
```

where `W(p,q)` is the actual finite Apéry shell weight and `K(k)` is the finite kernel. The corrected identity gives

```
S = sum_{p != q} W(p,q)
      sum_k K(k)
      e_pq(k s_p)e_q(kv(s_q-s_p)).
```

The second factor is the only remaining transverse variable. It depends on

```
Delta = s_q-s_p
```

and not on two independent local states.

## 3. Attempted treated sector

A natural treated sector is

```
|Delta| <= D
```

for a parameter `D` smaller than the full shell width. Counting gives at most

```
O(pi(X)D)
```

ordered pairs per fixed residue class.

This is a genuine nonempty sector, but the available estimate only gives the trivial bound

```
|S_D| <= sum_{|Delta|<=D} |W(p,q)| ||K||_1.
```

Without a new cancellation input this remains at the critical scale. The CRT decomposition alone does not save a power.

The untreated sector

```
|Delta|>D
```

is larger and requires the same missing inverse-phase cancellation.

## 4. Large-sieve route audit

The corrected decomposition suggests grouping by `Delta`:

```
T_D = sum_Delta A_D
       sum_q c_q e_q(k q^{-1} Delta).
```

However, the moduli are the prime variables themselves, and the inverse phases vary with both `q` and the Apéry residue. A standard additive large sieve cannot be directly applied without proving that the shell weights satisfy the required coefficient norm bound after the `pq` denominator normalization.

Thus the missing estimate is not the CRT identity; it is a weighted inverse-modulus large-sieve bound preserving the Apéry weights.

## 6. Scoped obstruction

A precise obstruction is:

> Any completion that uses only the corrected CRT identity and absolute-value bounds for the transformed finite kernel cannot reach `o(N^2)`.

Reason: after the transformation, the transverse factor is oscillatory only in `q` through `q^{-1}Delta`; discarding that oscillation leaves a shell pair count of the same order as the original sum.

This is a scoped analytic no-go, not a statement about the true Apéry-weighted sum.
