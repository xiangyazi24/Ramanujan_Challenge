# 2. The fixed-pair logarithmic root-mass bound

For `d,r>=2` and a shell prime `p`, define the actual affine common-root count

\[
m_{d,r}(p)
:=\#\{x\in\mathbb F_p:
N_d(x)=N_r(x+d)=0\}.
\tag{2.1}
\]

I first rederive the exact bound needed later, because this is the place where a simple-support/root-multiplicity error would kill the argument.

Fix `d,r=o(P)` and `P<p<=2P`.  By `lem:nonvanish`, both reduced continuants are nonzero.  By `cor:atomtail-firstlemma`, the integer resultant `S_{d,r}` is nonzero.  If the two reductions have `t=m_{d,r}(p)` distinct common roots, evaluation at those roots gives `t` independent linear functionals annihilating the image of the reduced Sylvester map.  Hence the fixed characteristic-zero-size Sylvester matrix has corank at least `t` modulo `p`.  Smith normal form gives

\[
\boxed{m_{d,r}(p)\le v_p(S_{d,r}).}
\tag{2.2}
\]

This remains valid if a leading coefficient drops modulo `p`: the Sylvester matrix is formed at its generic integer size before reduction, exactly as in the valuation argument around `lem:qc-aligned`.

Multiplying by `\log p` and summing only over the shell primes gives

\[
\begin{aligned}
\sum_{P<p\le2P}(\log p)m_{d,r}(p)
&\le
\sum_{P<p\le2P}(\log p)v_p(S_{d,r})\\
&\le \log|S_{d,r}|\\
&\ll(d+r)^2\log(d+r).
\end{aligned}
\tag{2.3}
\]

Thus, whenever `d,r\asymp\mathsf A` and `W=o(\mathsf A)`, uniformly for
`\mathsf A<d,r<\mathsf A+W`, one has

\[
\boxed{
\sum_{P<p\le2P}(\log p)m_{d,r}(p)
\ll \mathsf A^2P^{o(1)}.}
\tag{2.4}
\]

Equation (2.4) counts every numerical root.  It is stronger than merely saying that `p|S_{d,r}`.

# 3. Geometry of the maximal-separation tail

Put

\[
H_1:=H-2\mathsf A-R_0,
\qquad
\Gamma:=H_1-\mathsf A=H-3\mathsf A-R_0.
\tag{3.1}
\]

The full core has

\[
\mathsf A<a<a'<H_1.
\tag{3.2}
\]

For an integer window width `W` define

\[
I_-(W):=(\mathsf A,\mathsf A+W]\cap\mathbb Z,
\qquad
I_+(W):=[H_1-W,H_1)\cap\mathbb Z,
\tag{3.3}
\]

and

\[
R_-(J;W):=\sum_{a\in I_-(W)}R(J,a),
\qquad
R_+(J;W):=\sum_{a\in I_+(W)}R(J,a).
\tag{3.4}
\]

The exact identity

\[
\boxed{
\Gamma-(a'-a)
=(a-\mathsf A)+(H_1-a')}
\tag{3.5}
\]

has two nonnegative terms under (3.2).  Hence

\[
\Gamma-(a'-a)\le W
\tag{3.6}
\]

forces

\[
\boxed{a\in I_-(W),\qquad a'\in I_+(W).}
\tag{3.7}
\]

There is no endpoint leak:

- `a>\mathsf A` and (3.6) give `a<=\mathsf A+W`;
- `a'<H_1` and (3.6) give `a'>=H_1-W`.

Because all weights are nonnegative, after dropping every other transverse mask the tail contribution satisfies

\[
\boxed{
\mathfrak U_{\rm tr}^{\rm max-tail}(W)
\le \sum_JR_-(J;W)R_+(J;W).}
\tag{3.8}
\]

With the exact set selector, no Palm label has been marginalized in (3.8).  Expanding the product gives every ordered characteristic pair `(p,q)` with its full factor `(\log p)(\log q)`.  Since one fixed `p,J` has one value `a_p(J)`, the same characteristic cannot simultaneously lie in the disjoint bottom and top windows, so there is no hidden diagonal issue either.

# 5. Top first moment: the crucial line

\[
M_+(W):=\sum_JR_+(J;W).
\tag{5.1}
\]

Take one literal term in this sum, so for some shell prime `p`, `J\in S_p` and the first gap

\[

\[

\qquad
H-a-b-c>R_0.
\tag{5.2}

\[
H-a-R_0\le2\mathsf A+W.

\[
b+c<2\mathsf A+W,

hence

\[
\boxed{
(b-\mathsf A)+(c-\mathsf A)<W.}
\tag{5.3}
\]

In particular

\[
\mathsf A<b,c<\mathsf A+W.
\tag{5.4}
\]

Now recenter at the second actual zero

\[
x:=J+a.
\tag{5.5}
\]

The two later consecutive returns imply

\[
N_b(x)=N_c(x+b)=0\pmod p.
\tag{5.6}
\]

The map from the selected occurrence to

\[
(p,x;b,c)
\tag{5.7}
\]

is injective.  Indeed, `(p,x,b,c)` fixes the second, third, and fourth actual zeros.  The original `J` is the unique immediate previous actual zero before `x`; therefore `J` is recovered, and then `a=x-J` is recovered.  This is exactly where the current **set-selector** definition matters: there is one literal record for the selected start, not an additional source-fiber multiplicity over the same recovered quadruple.

Consequently

\[
\begin{aligned}
M_+(W)
&\le
\sum_{\substack{b,c>\mathsf A\\
(b-\mathsf A)+(c-\mathsf A)<W}}
\sum_{P<p\le2P}(\log p)m_{b,c}(p)\\
&\le
\sum_{\mathsf A<b,c<\mathsf A+W}

\end{aligned}
\tag{5.8}

Apply (2.4) to every pair `(b,c)`.  There are `O(W^2)` integer pairs, so

\[
\boxed{
M_+(W)
=\|R_+(\cdot;W)\|_1
\ll \mathsf A^2W^2P^{o(1)}.}
\tag{5.9}

This is fully unconditional under the current set-selector definition.

# 8. Hostile checks

## 8.1 Numerical-root multiplicity

No simple-support substitution occurs.  For fixed `(b,c,p)`, every distinct common `F_p` root contributes separately to `m_{b,c}(p)`, and (2.2) pays all of them through `v_p(S_{b,c})`.  This is exactly the multiplicity distinction emphasized by `prop:energy-column-exact`.

## 8.2 Palm factorial multiplicity

No ordered companion prime is discarded.  The current one-characteristic packet is binary, but the product

\[
R_-(J;W)R_+(J;W)
\]

expands into the full ordered `(p,q)` sum with weight `(\log p)(\log q)`.  This is the same quantifier order as `pairpalm_result.tex`, Theorem `thm:pairpalm-hierarchy`: binary `f_p(m)` first, ordered prime tuples after multiplication.

## 8.3 Recentered predecessor marking

The previous zero is not chosen from all earlier zeros.  It is the **immediate predecessor** in an actual consecutive quadruple, hence unique.  Therefore recentering loses no marking.

## 8.4 Block overlap / orientation

The exact current `S_p` is a set.  Membership can be proved by several masks or decompositions without creating multiple copies in `\mathbf1_{S_p}(J)`.  Reflection/orientation likewise changes which start lies in the set; it is not a multiplicative label above one selected start.

## 8.5 Physical residue lifts

The maximal-tail proof is at the current selected-start coordinate `J` and uses the prompt-authoritative injection of a selected consecutive quadruple after recentering.  It does not replace a set of physical rows by one existence indicator.  In particular, the Q5204 abstract source-fiber model is inapplicable to (0.1).

## 8.6 Endpoint inclusivity

The choices

\[
I_-(W)=(\mathsf A,\mathsf A+W],
\qquad
I_+(W)=[H_1-W,H_1)
\]

match the strict full-core inequalities `a>\mathsf A`, `a'<H_1`.  The tail condition with `<=W` lands exactly in these half-open windows.  Integer rounding changes only constants.

## 8.7 Does exact triangular headroom improve the `W^3` power further?

Not from the present two inputs.  If `v=H_1-a'` is the top deficit, the cumulative top mass up to deficit `v` is `O(\mathsf A^2v^2P^{o(1)})`, while the allowed bottom width is `W-v` and has pointwise mass `O(\mathsf A(W-v)P^{o(1)})`.  Abel summation gives again

\[
\mathsf A\int_0^W \mathsf A^2v^2\,dv
\asymp \mathsf A^3W^3.
\]

So `41/120` is the critical exponent of this asymmetric packet-cap/resultant route.  A larger width would require a new input, not merely a more exact summation of the same geometry.
