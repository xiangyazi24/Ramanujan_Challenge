# The simple `4F3` path: exact Mellin reconstruction, real finite-part Euler branch, and the unavoidable global cycle

## Verdict

There is an exact conclusion, but it is not the requested all-in-one positive integral.

After Mellin transformation the scalar density is fixed only up to multiplication by an arbitrary meromorphic function of period one, and the inverse transform is fixed only after a homology/rapid-decay cycle is chosen.  Different choices have the same differential equation and the same exact trajectory matrix `A_n`, while having different coefficients of the three Poincare modes.

# 2. Mellin reconstruction forced by the operator

Consider formally

```text
F_n(z) = integral_Gamma m_n(s) z^s ds.                (2.1)
```

If

```text
P(s)=s(s+5/2)^2(s+3),
Q_n(s)=(s+n+4)^2(s-n-1/2)(s-n),
```

then inserting (2.1) into `P(theta)F-zQ_n(theta)F=0` gives the scalar shift equation

```text
m_n(s)/m_n(s-1)
 = (s+n+3)^2 (s-n-3/2)(s-n-1)
   ---------------------------------.                  (2.2)
        s(s+5/2)^2(s+3)
```

A complete gamma-product solution is

```text
                         Gamma(s+n+4)^2
m_n(s) = ------------------------------------------------------------
         Gamma(s+1) Gamma(s+7/2)^2 Gamma(s+4)

         * Gamma(s-n-1/2) Gamma(s-n).                  (2.3)
```

No special-function table is used here: (2.3) follows by replacing every linear factor in (2.2) by one gamma quotient.

The `n` shift is equally exact:

```text
m_(n+1)(s)/m_n(s)
 = (s+n+4)^2
   -------------------------------.                   (2.4)
     (s-n-3/2)(s-n-1)
```

Equation (2.4) is the Mellin form of the four unit shifts

```text
(n+4,n+4,-n-1/2,-n)
 -> (n+5,n+5,-n-3/2,-n-1).
```

If a cycle `Gamma` is such that all integrals converge and no pole is crossed, then applying (2.4) under the integral gives the same contiguous relation as the CMF construction.  Hence

```text
J_n(Gamma)
 = (F_n(1), theta F_n(1), theta^2 F_n(1))
```

satisfies exactly

```text
J_(n+1)(Gamma) = J_n(Gamma) A_n.                      (2.5)
```

An integration-by-parts proof and the Mellin proof are the same certificate in two coordinate systems: multiplication by `s` in (2.2) is differentiation of the real Euler kernel, and a shift of `s` is multiplication by its integration variable.

# 3. Exact ambiguity theorem

## Theorem 3.1 — periodic Mellin ambiguity

Let `p(s)` be any meromorphic function satisfying

```text
p(s+1)=p(s).                                          (3.1)
```

Then

```text
m_n^p(s)=p(s)m_n(s)                                   (3.2)
```

satisfies both (2.2) and (2.4).  Therefore every admissible inverse-Mellin cycle gives a row solution of the same matrix recurrence (2.5).

### Proof

The factor `p` cancels from `m(s)/m(s-1)` by (3.1), and it is independent of `n`, so it also cancels from `m_(n+1)/m_n`.  Nothing else is used.

## Corollary 3.2 — local data do not select the recessive line

The differential equation, all rational contiguous matrices, the determinant of `A_n`, and every finite product identity are unchanged when `p` or the inverse-Mellin cycle is changed.  Nevertheless the three connection coefficients at infinity change.

In particular, one may add any multiple of the terminating row `B_n` to a second solution without changing (2.5).  This changes its dominant coefficient and destroys any proposed decay estimate.  Thus an estimate

```text
|J_n| <= C n^d mu^n,       mu=17-12 sqrt(2),          (3.3)
```

is not a consequence of the local module; it is itself a global connection theorem.

This is the precise sense in which a genuine construction is forced to be a Meijer G in disguise.  A Meijer G is simply the gamma symbol (2.3) together with a specified separating/rapid-decay cycle.  One may derive that cycle independently and never use the name “Meijer G”, but one cannot omit the cycle.

# 4. Why the zero-upper-parameter tangent is the wrong global branch

Q6931 regularized the upper parameter `-n` by replacing it by `epsilon-n` and differentiating at `epsilon=0`.  For terms beyond the terminating range,

```text
(d/d epsilon (epsilon-n)_k)|_(epsilon=0)
 = (-1)^n n! (k-n-1)!,        k>n.                    (4.1)
```

This produces a one-sign tail.  In Mellin language, it is obtained from a fixed vertical cycle after reflection of the two factors

```text
Gamma(s-n),  Gamma(s-n-1/2).
```

A fixed vertical cycle has only polynomial `n` dependence after the reflection formula; restoring the scalar normalization of the raw path yields the neutral `16^n` character.  It does not move to the saddle/thimble selecting `mu`.

The same conclusion is visible from the connection expansion at `z=infinity`.  The branch attached to the upper parameter `-n-1/2`, after regularizing the collision with `-n`, has a terminating core

```text
_4F3(
  -n-1/2, -n-3, -n-3, -n-7/2 ;
  -2n-7/2, -2n-7/2, 1/2 ; 1).                        (4.2)
```

All its coefficients have one sign after the elementary prefactor is removed.  Stirling's formula for the prefactor gives the same middle exponential character.  Thus the positive derivative tail is not “almost” the wanted minimal solution; it is the canonical representative of a different formal mode.

The Catalan vector at `n=0` found in Q6931 remains correct.  What fails is the inference that its naive forward transport is recessive.

# 5. The independently derived real Euler branch

Although the global cycle is not selected, the logarithmic branch associated with the repeated upper parameter `n+4,n+4` has a completely real Euler representation.

Put `w=1/z` and define

```text
C_n = Gamma(2n+11/2) Gamma(2n+5)
      ------------------------------------------------,
      Gamma(n+3/2)^2 Gamma(n+4) Gamma(n+7/2)
```

```text
Y_n(w)=C_n integral_0^1 integral_0^1
 t^(n+1/2) (1-t)^(n+3)
 u^(n+1/2) (1-u)^(n+5/2)
 -------------------------------------- dt du.        (5.1)
       (1-wtu)^(n+4)
```

For `0<=w<1`, expansion of the last factor and two beta integrals give

```text
Y_n(w)=_3F2(
 n+4,n+3/2,n+3/2 ;
 2n+11/2,2n+5 ; w).                                  (5.2)
```

Let

```text
D_n = (1/n!) product_(j=1)^n (theta_w+j).
```

Then coefficientwise

```text
D_n w^k = (n+1)_k/k! * w^k,
```

and therefore

```text
X_n(w)=D_n Y_n(w)
 = _4F3(
    n+4,n+3/2,n+3/2,n+1 ;
    2n+11/2,2n+5,1 ; w).                              (5.3)
```

This is the real Euler core of either infinity branch obtained by splitting the repeated upper parameter.

## 5.1 The logarithmic finite part

Split the repeated parameter as `n+4+delta,n+4-delta`.  For the `+delta` branch the hypergeometric core is

```text
X_(n,delta)(w)=_4F3(
 n+4+delta,
 n+3/2+delta,n+3/2+delta,n+1+delta ;
 1+2delta,2n+11/2+delta,2n+5+delta ; w).              (5.4)
```

At `delta=0`, `X_(n,0)=X_n`.  The derivative of (5.4) is also a real integral.  First define

```text
Y_(n,delta)(w)=C_(n,delta) integral_[0,1]^2
 t^(n+1/2+delta)(1-t)^(n+3)
 u^(n+1/2+delta)(1-u)^(n+5/2)
 (1-wtu)^(-n-4-delta) dt du,                          (5.5)
```

where

```text
C_(n,delta)=
 Gamma(2n+11/2+delta) Gamma(2n+5+delta)
 ----------------------------------------------------.
 Gamma(n+3/2+delta)^2 Gamma(n+4) Gamma(n+7/2)
```

Differentiation under the integral gives

```text
(d/d delta Y_(n,delta))|_0
 = C_n integral_[0,1]^2 K_n(t,u;w)
   [chi_n+log t+log u-log(1-wtu)] dt du,              (5.6)
```

with `K_n` the positive kernel in (5.1) without `C_n`, and

```text
chi_n = psi(2n+11/2)+psi(2n+5)-2psi(n+3/2).           (5.7)
```

The remaining derivative comes from

```text
(n+1+delta)_k/(1+2delta)_k.
```

For a series `f(w)=sum a_k w^k`, define

```text
(H_n f)(w)
 = integral_0^1 (r^n-2)/(1-r) [f(w)-f(rw)] dr.       (5.8)
```

The coefficient of `a_k w^k` in (5.8) is exactly

```text
(H_(n+k)-H_n)-2H_k.                                  (5.9)
```

Consequently

```text
(d/d delta X_(n,delta))|_0
 = D_n ((d/d delta Y_(n,delta))|_0) + H_n X_n.        (5.10)
```

Equations (5.1), (5.6), (5.8), and (5.10) are an entirely real finite-part Euler representation.  The logarithms are not inserted by hand; they are forced by coalescence of the two equal upper parameters.  Half-integer digamma values in (5.7) are the source of `log 2`.

The full coalesced infinity solution is a rational gamma prefactor times

```text
(d/d delta X_(n,delta))|_0
 + ell_n X_n + X_n log z,                             (5.11)
```

where `ell_n` is the finite part of the two gamma connection coefficients.  It is an explicit rational combination of ordinary and half-integer harmonic numbers.  Formula (5.11) is exactly what one obtains by deriving the logarithmic branch from the differential equation; no official parameter list is needed.

# 6. Why the Euler branch does not yet give a `mu^n` bound

The kernel in (5.1) contains

```text
(1-tu)^(-n-4).
```

Its saddle competes with the four beta factors.  The resulting finite-part logarithmic solution contains a nonzero middle-mode coefficient; in the raw normalization this is the observed `16^n` growth.  Taking an absolute value in (5.1) therefore proves the wrong estimate.

To obtain the recessive solution one must form

```text
J_n = logarithmic_branch_n
      - c_plus * dominant_branch_n
      - c_zero * middle_branch_n,                    (6.1)
```

where `c_plus,c_zero` are global connection coefficients.  The condition that both unwanted coefficients vanish is exactly the rapid-decay-cycle condition.  Local integration by parts verifies the recurrence for every value of `c_plus,c_zero`; it cannot determine them.

An elementary positive bound for (6.1) would be extremely valuable, but proving it would already prove the missing connection theorem.  It cannot be inferred by applying the triangle inequality before the cancellations in (6.1).

# 7. The tempting compact positive moment, and why it is not the answer

There is a remarkably close real moment.  Put

```text
rho(x)=x(1-x)/(1+x),
mu=(3-2sqrt(2))^2=17-12sqrt(2),                       (7.1)
```

and

```text
R_n(z)=integral_0^1 rho(x)^(2n)
        arctan(zx)/(x(1+x)) dx.                       (7.2)
```

Since

```text
max_(0<=x<=1) rho(x)=rho(sqrt(2)-1)=3-2sqrt(2),       (7.3)
```

one gets the elementary positive estimate

```text
0<R_n(1)<=mu^n R_0(1).                               (7.4)
```

The base theta jet is exactly

```text
R_0(1)       = G - pi log(2)/8,
theta R_0(1) = pi/8 + log(2)/4,
theta^2R_0(1)= pi/8.                                 (7.5)
```

For completeness, the first identity follows from

```text
integral_0^1 arctan x/x dx = G,
```

and

```text
integral_0^1 arctan x/(1+x) dx = pi log(2)/8.         (7.6)
```

To prove (7.6), integrate by parts and use the involution
`x -> (1-x)/(1+x)` to show

```text
integral_0^1 log(1+x)/(1+x^2) dx = pi log(2)/8.
```

Thus (7.2) has exactly the two aesthetic features sought in the question: the sharp exponential `mu` and the constants `G,log 2`.

It is nevertheless **not** the required scalar theta solution.  As a function of `z`, `R_n(z)` has branch cuts produced by `arctan(zx)` along

```text
z in i[1,infinity) union -i[1,infinity),              (7.7)
```

whereas every solution of (1.1) has singularities only at

```text
z=0,1,infinity.                                      (7.8)
```

A rational theta gauge cannot remove the continuum of singular points in (7.7).  Hence the theta jet of (7.2) cannot be the `4F3` state whose contiguous matrix is `A_n`.

This exact rejection is useful: a compact positive moment with the right saddle and the right constants is not enough.  One must also provide the de Rham/contiguous certificate.

# 8. The one exact statement that would finish the construction

Let `M_n(s)` be (2.3).  A complete independent solution is equivalent to finding an explicit period-one multiplier `p_rec(s)` and an explicit rapid-decay cycle `Gamma_rec` such that

```text
j_n(z)=integral_(Gamma_rec) p_rec(s)M_n(s)z^s ds      (8.1)
```

has the following three properties:

```text
(A) no pole crosses Gamma_rec under n -> n+1;
(B) its n=0 theta jet is the Q6931 Catalan vector;
(C) |theta^r j_n(1)| <= C_r n^d mu^n, r=0,1,2.       (8.2)
```

Property (A), together with (2.4), proves

```text
J_(n+1)=J_n A_n
```

exactly.  Property (B) identifies the connection coefficient.  Property (C) proves recessiveness without Poincare-root recognition.

The official Meijer-G trajectory is one encoding of `(p_rec,Gamma_rec)`.  Any independently derived real Euler/Laplace formula satisfying (A)--(C) is another encoding of exactly the same datum.  Sections 2--5 derive the integrand and all real finite-part pieces; the still-missing item is the rapid-decay cycle/cancellation in (C).

This is not an issue of terminology.  The periodic ambiguity theorem proves that no manipulation confined to (1.1) and the rational matrices `A_n` can determine `(p_rec,Gamma_rec)`.

The real Euler layer should be formalized first for `0<=w<1`, where every kernel in (5.1), (5.6), and (5.8) is integrable and differentiation is dominated.  The final analytic interface should expose the missing datum rather than hide it:

structure SimpleRecessiveCycle where
  j : Nat -> Real -> Real

# 11. Standalone exact checks

The following script checks the Mellin identities, the Euler coefficient identity, and the compact-moment constants.  It performs no numerical limit test.

```python
import sympy as sp

s,n,k = sp.symbols('s n k', integer=True, nonnegative=True)

m = (
    sp.gamma(s+n+4)**2
    * sp.gamma(s-n-sp.Rational(1,2))
    * sp.gamma(s-n)
    / (sp.gamma(s+1)*sp.gamma(s+sp.Rational(7,2))**2*sp.gamma(s+4))
)

ratio_s = sp.simplify(sp.expand_func(m / m.subs(s,s-1)))
expected_s = (
    (s+n+3)**2*(s-n-sp.Rational(3,2))*(s-n-1)
    /(s*(s+sp.Rational(5,2))**2*(s+3))
)
assert sp.simplify(ratio_s-expected_s) == 0

m_succ = m.subs(n,n+1)
expected_n = (s+n+4)**2/((s-n-sp.Rational(3,2))*(s-n-1))
assert sp.simplify(sp.expand_func(m_succ/m)-expected_n) == 0

# The differential operator D_n multiplies w^k by (n+1)_k/k!.
assert sp.simplify(
    sp.rf(k+1,n)/sp.factorial(n) - sp.rf(n+1,k)/sp.factorial(k)
) == 0

# Harmonic multiplier in (5.8).
r = sp.symbols('r', positive=True)
hmult = sp.integrate((r**n-2)*(1-r**k)/(1-r),(r,0,1))
assert sp.simplify(
    hmult - (sp.harmonic(n+k)-sp.harmonic(n)-2*sp.harmonic(k))
) == 0

# Compact moment saddle.
x = sp.symbols('x', positive=True)
rho = x*(1-x)/(1+x)
xstar = sp.sqrt(2)-1
assert sp.simplify(sp.diff(rho,x).subs(x,xstar)) == 0
assert sp.simplify(rho.subs(x,xstar)-(3-2*sp.sqrt(2))) == 0
assert sp.expand((3-2*sp.sqrt(2))**2-(17-12*sp.sqrt(2))) == 0

# n=0 theta-jet integrals.
I1 = sp.integrate(1/((1+x)*(1+x**2)),(x,0,1))
I2 = sp.integrate((1-x)/(1+x**2)**2,(x,0,1))
assert sp.simplify(I1-(sp.pi/8+sp.log(2)/4)) == 0
assert sp.simplify(I2-sp.pi/8) == 0

print('all exact local certificates passed')
```

The script intentionally contains no assertion that the compact moment obeys `A_n`, because it does not provide the correct theta differential module.  Adding such an assertion without an exact integration-by-parts identity would recreate the same gap in a new notation.
