# Erdős–Turán discrepancy for CRT images of Apéry zero sets

The computation has found the right obstruction: Erdős–Turán is not the correct tool for obtaining a nontrivial CRT error when the point set has only \(N\approx 8\) points. The apparent contradiction comes from applying a discrepancy theorem designed for large point sets to a tiny set.

## 1. The Erdős–Turán application

The normalized Erdős–Turán inequality for \(N\) points \(x_1,\dots,x_N\in[0,1)\) is

```text
D_N <= C(1/H + sum_{h=1}^H |S(h)|/hN)

where S(h)=sum_j exp(2π i h x_j).
```

Here the points are

\[
x(a,b,c)=\frac{\operatorname{CRT}(a,b,c)}{pqr},
\]

with

\[
N=|Z_p||Z_q||Z_r|.
\]

The interval being counted is

\[
[0,M),\qquad M\asymp X^2,
\]

inside a modulus interval of length

\[
pqr\asymp X^3.
\]

Therefore the expected count is

\[
N\frac{M}{pqr}\asymp \frac{8}{X}.
\]

The absolute counting error is bounded by \(N D_N\).

The key point: \(N\) is not growing. It is approximately 8. Therefore no discrepancy theorem can force a small error. A set of 8 points can have discrepancy of size a positive constant regardless of how large the ambient interval is.

Your first estimate

\[
|S(h)|\le 1
\]

is correct, because

\[
S(h)=\frac{1}{N}
\widehat g_p(h\bar{qr})
\widehat g_q(h\bar{pr})
\widehat g_r(h\bar{pq})
\]

and each Fourier coefficient is at most the size of the zero set.

But the conclusion

\[
D_N\ll \log X
\]

is not meaningful: discrepancy is always bounded by an absolute constant. The harmonic sum estimate is simply too crude because it ignores that the discrepancy cannot exceed 1.

Thus the correct statement is:

```text
D_N <= min(1, C/H + C/N * sum_{h<=H} |S(h)|/h).
```

With \(N=8\), the trivial bound dominates.

## 2. Why the Parseval calculation gets worse

The Cauchy–Schwarz computation is algebraically correct but is estimating the wrong quantity.

Indeed,

\[
\sum_{h\le pqr}
|\hat g_p(h)|^2|\hat g_q(h)|^2|\hat g_r(h)|^2
\]

is approximately

\[
(p|Z_p|)(q|Z_q|)(r|Z_r|)\asymp pqr.
\]

Therefore the square root is

\[
\asymp (pqr)^{1/2}\asymp X^{3/2}.
\]

After dividing by \(N\approx 8\), this gives a huge number. This is not a contradiction. It only says that an L² estimate over all Fourier frequencies is too weak for a tiny point set.

The error is conceptual:

- Parseval measures the total Fourier energy.
- Erdős–Turán needs control of low Fourier frequencies.
- The CRT point set has only eight atoms, so its low-frequency spectrum can be large.

There is no reason for the L² mass to be spread uniformly enough to improve discrepancy.

## 3. What the product structure actually gives

The product formula

\[
\hat g_p(h\bar{qr})\hat g_q(h\bar{pr})\hat g_r(h\bar{pq})
\]

is still valuable, but not through absolute values.

The useful quantity would be a signed average:

\[
\sum_h
\frac{
\hat g_p(h\bar{qr})
\hat g_q(h\bar{pr})
\hat g_r(h\bar{pq})
}{h}.
\]

Taking absolute values destroys the CRT independence. The factors may have cancellation as functions of \(h\), but

\[
|ABC|\le |A||B||C|
\]

cannot see it.

A genuine improvement would require a theorem of the form

```text
sum_h c_h * ghat_p(h) * ghat_q(h) * ghat_r(h)
     << X^epsilon
```

for suitable harmonic weights \(c_h\), i.e. a trilinear Fourier correlation estimate.

That is much closer to the HM_3 / moving-target discrepancy problem already identified in the project.

## 4. The correct scale of the CRT problem

For a fixed triple \(p,q,r\), the CRT image has only about eight points:

\[
Z_p\times Z_q\times Z_r.
\]

The interval 

\[
[0,X^2]
\]

captures a proportion about \(1/X\) of the ambient CRT circle. Hence the expected number of points is

\[
8/X.
\]

But the actual number is an integer in

\[
\{0,1,\ldots,8\}.
\]

Therefore the best possible deterministic discrepancy bound is naturally

\[
O(1),
\]

not \(o(1)\).

This is why the naive CRT argument previously hit the "O(1) per triple" barrier. Erdős–Turán does not remove this barrier; it confirms it.

## 5. Consequence for the Apéry GCD program

The triple-moment problem cannot be solved by treating each CRT box

\[
Z_p\times Z_q\times Z_r
\]

as a uniformly distributed set of eight points.

The missing input is not discrepancy of a finite CRT image. It is cancellation after summing over many triples:

\[
\sum_{p,q,r}
\mathbf{1}\{\exists(a,b,c)\in Z_p\times Z_q\times Z_r:
\operatorname{CRT}(a,b,c)<M\}.
\]

The required theorem is therefore a collective statement:

```text
average cancellation over triples of primes,
not discrepancy of one eight-point CRT configuration.
```

This matches the earlier HM_3 obstruction: pair moments can be controlled by large sieve methods, but triple moments need a genuine trilinear correlation estimate.

## Final answer

1. The Erdős–Turán setup is formally correct, but useless because the number of points \(N\approx8\) is fixed.

2. The product Fourier structure does not help after taking absolute values.

3. Parseval gives a bound of size \(X^{3/2}\), which is worse because it estimates global Fourier energy rather than low-frequency cancellation.

4. The correct discrepancy scale for a single CRT image is

\[
D_N=O(1),\qquad |E_{pqr}|=O(1).
\]

The way past the CRT barrier is not improving the discrepancy of one triple. It is proving cancellation when averaging over many prime triples.
