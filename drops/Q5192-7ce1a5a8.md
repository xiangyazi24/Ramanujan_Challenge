## 3. Attack A: a bilinear/two-sided large sieve with both zero modes removed

### 3.1 What one would like

After the exact principal subtraction on each side, one would hope for something schematically like

\[

\tag{3.1}
\]

for the **actual** Apéry coefficient vector, and then apply it to both CD15 factors.

The temptation is to argue that deleting the principal mode on the left and the right should remove the large main eigenvector of the reciprocal system.

### 3.2 Exact first failure: CD10 already has `J != 0`

That implication does not survive contact with the literal source. In CD10 the slope is

\[
 J\equiv g\bar p\pmod q,
\]

and is explicitly called **nonzero** before the large sieve is invoked. Nevertheless the proof still uses

\[
 \delta(J/q,J'/q')\gg N^{-2}
\]

and incurs the standard

\[
 D+\delta^{-1}=N^{2+o(1)}
\]

large-sieve constant because `D=N^(41/100) << N^2`.

So the implication

```text
reciprocal slope zero absent
        +
principal mode subtracted on both rows
        +
N^-2 spacing of reciprocal fractions
        => N^-2rho improvement of the large-sieve constant
```

is **false as an inference from the current source interfaces**.

The standard large sieve sees the geometry of the whole set of surviving fractions, not just whether one distinguished fraction is absent. Removing one output mode does not alter the `N^-2` near-collision scale among nonzero fractions.

This also explains the observation fixed in Q5192 that generic reciprocal-prime equidistribution reproduces the endpoint. Marginal equidistribution does not control the top singular direction of the actual selected covariance.

### 3.3 Zero-mode leakage audit

There is an even earlier danger if one tries to identify the principal mode with `J=0`. CD8 says the exact phase is

\[
 (-1)^d e\!\left(\frac{d(k-1/2)}{pq}\right)e_q(dJ).
\]

Thus `e_q(dJ)` is only one factor. The slow `d`-phase and `\widehat w(Nd/(pq))` are separated into literal tensor factors; they are not source deletion masks. Consequently:

- `J=0` is not, by itself, the full source principal vector;
- deleting `J=0` before reassembling the smooth atom is not the same operation as the PS principal projector;
- doing “zero-mode deletion” independently after a source mask can change the vector because source masking and later projection do not commute.

The legal object is the exact `C_PS` applied in the source order, not a hand-made `J!=0` restriction.

### 3.4 Determinant-block dependence audit

A second possible loss is to run the large sieve branchwise and then sum absolute values over the two circular determinant branches. That destroys precisely the cross-branch covariance Q5192 asks us to preserve. Conversely, summing the branches first and asking the ordinary large sieve to exploit their relative phase gives no saving because the large sieve is an arbitrary-coefficient inequality: it has no arithmetic information saying that the branch-generated coefficients avoid its top singular directions.

Therefore the branch dependence must live inside the actual coefficient/profile vector in `SAPG_rho`; it cannot be recovered after a branchwise positive inequality.

### 3.5 Mask noncommutation audit

CD7/CD9 allow bounded `d`-independent **source** deletions, so the additive-source large sieve can legitimately be run after such a deletion. But the source paragraph after CD15 explicitly proves that the high-gap band is a joint `(k,ell)` tensor under multiplicative-character expansion. Hence the following step is illegal:

```text
prove a postprojection reciprocal estimate
then insert/delete the source band as if it were a support restriction
of each character factor separately.
```

Any large-sieve defect that is supposed to apply to the final residual must be proved either:

1. directly for the source-masked actual profile, with the later projection kept in its actual position; or
2. for a class of joint tensors broad enough to contain the projected source mask.

The current positive one-sided endpoint does not provide such a signed defect.

### 3.6 Normalization audit

If Attack A did prove `(3.1)` uniformly for each actual color row, then the energy gain would be `2rho` in each row and CD15 would give

\[
 N^{161/100-2\rho+o(1)}.

Thus no additional factor is lost at the consumer. The route fails before the consumer: it does not produce the `N^{-2rho}` energy factor.

## 4. Attack B: use the two circular determinant branches / reflection as an actual covariance identity

This route is genuinely different: instead of trying to improve a generic reciprocal large sieve, try to show that the **two actual orbit profiles are negatively correlated** after centering.

### 4.1 The hoped-for mechanism

Let the exact centered Gram, before any positive majorization, be written in circular-branch blocks

\[
 \mathcal K^{\circ}
 =\begin{pmatrix}
   K_{++}&K_{+-}\\
   K_{-+}&K_{--}
  \end{pmatrix}.
\tag{4.1}
\]

A strong covariance identity such as

\[
 K_{+-}\approx-K_{++}
\]

on the physical branch combination would create the desired defect even when the two diagonal branch norms individually remain at the `161/100` endpoint.

This is attractive because it attacks exactly the information thrown away by a positive majorant.

### 4.2 What reflection really gives

The literal source warning after CD15 supplies one exact symmetry fact: simultaneous reflection kills **opposite parity**, but can leave an **odd-odd** sector. Thus reflection gives a parity block decomposition, not a full covariance cancellation.

In particular, the inference

```text
both circular branches present
   + signed d phase
   + simultaneous reflection
   => cross-branch centered covariance is zero/small
```

fails at the same-parity block.

The odd-odd survivor is already a source-level certificate that no universal “reflection pairs the two profiles away” argument is available. Depending on the exact PS/SRG parity decomposition, an even-even centered high-frequency block may also remain; I do not delete it without the literal current PS equation.

### 4.3 Signed `d` does not by itself create negative energy

A possible shortcut is to use `d -> -d` and complex conjugation. Even if a branch involution identifies one profile with a conjugate of another under `d -> -d`, that only identifies norms. The two-sided energy is a sum of squared magnitudes / Gram products. To obtain a power defect one needs an **extra signed covariance identity** fixing the relative branch phase on the actual source support. Conjugacy alone supplies no negative sign in the squared norm.

This is why both signs of `d` must stay in the Gram rather than being replaced by a positive half after absolute values.

### 4.4 Source masks are a fatal issue for a symmetry-only proof

There is a further exact obstruction. CD7 is uniform under bounded `d`-independent source deletions. A proof that obtains cancellation solely by pairing every source label with its reflected/other-branch mate is not stable under such deletions: deleting one member of a pair destroys the cancellation.

This does **not** prove that the actual fixed mask has no covariance. It proves something narrower and useful:

> any theorem uniform in the legal CD source-deletion class cannot derive a branch spectral gap from reflection symmetry alone. A successful theorem for the actual residual must include the literal mask inside the arithmetic covariance statement.

That is exactly the masked operator `K^circ_{kappa,M}` in Section 2.

### 4.5 Cauchy--Schwarz/PSD gives only the old endpoint

Without new arithmetic information, the cross block satisfies at best the natural Hilbert-space bound

\[
 |\langle R_+,R_-\rangle|
 \le \|R_+\|\,\|R_-\|,
\]

which is the same `161/100` scale. Trace/marginal equidistribution similarly controls an average of eigenvalues, not the largest eigenvalue on the actual masked same-parity sector.

Thus the branch route and the large-sieve route meet at the same precise object from opposite directions:

\[
 \text{largest eigenvalue of the exact masked centered actual Gram.}
\]

### 4.6 Smallest arithmetic theorem that repairs Attack B

Let `P_same` be the exact same-parity projector from the PS/SRG branch/reflection decomposition, **after** the literal source mask has been inserted in its legal position. The needed theorem can be stated as

\[
 \boxed{
 \|P_{\rm same}\mathcal K_{\kappa,M}^{\circ}P_{\rm same}\|_{\rm op}
 \ll N^{161/100-2\rho+o(1)},
 \qquad \rho>1/100.}
\tag{MXCov-rho}
\]

with the physical two-branch combination retained. If the source already disposes of one same-parity block, then `P_same` should be narrowed correspondingly; the point is that the theorem must attack the **last same-parity nonprincipal block**, not the already-vanishing opposite-parity block.

Arithmetic interpretation: conditioned on the actual Apéry zero predicates and the source masks, the two circular reciprocal-angle profiles must have an `N^{-1/50}` **energy** defect in their centered Gram top eigenvalue.

This is not a statement about a generic reciprocal set. It is an actual-orbit covariance theorem.

**Attack B verdict:** no unconditional defect from the banked symmetries. First failed implication: reflection/branch conjugacy does not control the same-parity centered cross-covariance, and source masks can destroy a putative pairing. The smallest repair is `MXCov_rho`, which is the branch-block version of `SAPG_rho`.

\]

Then

\[
 K u=0,\qquad Q_0KQ_0=K,
 \qquad \|K\|_{\rm op}=\Lambda.
\]

So the principal mode is removed **exactly**, yet the centered Gram retains the full top scale. Rank-one mode subtraction alone has no spectral-gap content.

```text
u = (1, 1)/sqrt(2)       principal
v = (1,-1)/sqrt(2)       centered
K = Lambda * v v*
K u = 0
||Q K Q|| = Lambda
```

### Certificate B: preserving two branches plus branch-exchange symmetry still gives no gap

Using the centered `K` above, define

\[
 K_{\rm br}
 =\begin{pmatrix}K&K\\K&K\end{pmatrix}.
\]

This matrix is invariant under exchange of the two branches and keeps both branches. Its top eigenvalue is `2 Lambda`, not a saving. Even the more conservative block diagonal matrix `diag(K,K)` has norm `Lambda`.

Thus “two symmetric branches are present” does not imply negative covariance. The sign of the cross block is the arithmetic theorem.

### Certificate C: positive majorization has no cancellation information

Take the actual test direction `a=(1,1)^T` and

\[
 G_+=\begin{pmatrix}1&1\\1&1\end{pmatrix},
 \qquad
 G_-=\begin{pmatrix}1&-1\\-1&1\end{pmatrix}.
\]

They have the same entrywise positive majorant:

\[
 |G_+|=|G_-|=
 \begin{pmatrix}1&1\\1&1\end{pmatrix}.
\]

But

\[
 a^*G_+a=4,
 \qquad
 a^*G_-a=0.
\]

Therefore no theorem proved only for the positive majorant can certify the signed cancellation of the actual quadratic form. One must prove the sign/covariance statement before majorization.

### Certificate D: source band and factorwise projection do not commute

Let the model projection and mask be

\[
 P=\frac12\begin{pmatrix}1&1\\1&1\end{pmatrix},
 \qquad
 M=\begin{pmatrix}1&0\\0&0\end{pmatrix}.
\]

Then

\[
 PM=\frac12\begin{pmatrix}1&0\\1&0\end{pmatrix},
 \qquad
 MP=\frac12\begin{pmatrix}1&1\\0&0\end{pmatrix},
\]

so

\[
 [P,M]=PM-MP
 =\frac12\begin{pmatrix}0&-1\\1&0\end{pmatrix}\ne0.
\]

This finite matrix is the abstract version of the literal post-CD15 warning: a joint source band cannot be moved through a factorwise character projector.
