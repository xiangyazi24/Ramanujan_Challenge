# Q908 corrected audit

## Verdict 1: `prop:reflection` — VALID; previous objection withdrawn

The objection that an endpoint normalization of `u` is missing is not a valid objection. The displayed proof already has the needed algebraic step.

From

```
W_n(Ru-u,b)=0
```
with the nonzero Wronskian, the two solutions are linearly dependent, so

```
Ru-u = c b.
```

Now apply the reflection operator `R`. The reflection relation gives

```
R(Ru-u)=u-Ru=-(Ru-u).
```
On the other hand,

```
R(cb)=cRb=cb,
```
because `b` is the reflection-invariant solution. Therefore

```
cb = -cb.
```
Since the characteristic is odd and `b` is nonzero, this implies

```
c=0.
```

Hence `Ru=u` follows directly. No independent endpoint condition on `u` is required.

The only possible failure point would have been an earlier failure of the reflection action, Wronskian sign, or two-dimensional solution-space assumption. Those do not fail in the displayed argument. The dependency map entry should therefore be:

```
prop:reflection
  status: VALID
  dependencies:
    - nonzero Wronskian identity
    - reflection operator involution
    - R(b)=b
    - odd characteristic
  no extra endpoint normalization required
```

## Verdict 2: `prop:companion-height` — VALID under its stated recurrence inputs

The previous criticism that the proposition extracted numerator height only from an approximation was incorrect. The displayed proof does not use approximation alone.

The actual chain is:

1. The recurrence/telescoping identity gives

```
|a_q| = exp(O(q)).
```

2. Write the rational number in lowest terms:

```
a_q = A_q / C_q.
```

3. The denominator divisibility input gives

```
C_q | d_q
```

and the supplied estimate gives

```
log d_q = O(q).
```

Therefore

```
log |C_q| = O(q).
```

Combining with the first estimate,

```
|A_q| = |a_q| C_q = exp(O(q)).
```

Thus the numerator-height conclusion is unconditional from the three explicit inputs above.

Dependency-map entry:

```

  status: VALID
  dependencies:
    - recurrence/telescoping estimate |a_q|=exp(O(q))
    - reduced fraction a_q=A_q/C_q
    - denominator divisibility C_q|d_q
    - log d_q=O(q)
  conclusion:
    log |A_q|=O(q)
```
