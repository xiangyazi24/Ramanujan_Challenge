# Correct higher-Cartier alias formula

## Verdict

The objection is correct at the general level.

For

```text
M = a*p+s,
0 <= s < p,
d_v = q*p-v,
t_v = floor(M/d_v),
m = floor(a/q),
```

the shell is initially summed over

```text
t_v P cap Z^3,
```

not over the fixed set `P cap Z^3`.  After Freshman's-dream coefficient matching, the effective domain is

```text
m P cap Z^3,
```

provided the exact safety inequality

```text
s + v*t_v < p
```

holds.

Thus the corrected formula is

```text
C_(a*p+s)(q*p-v)
  = sum_(kappa in mP cap Z^3)
      c_a(q*kappa)c_s(-v*kappa)                 (mod p).
```

For the pair used in Q5881 this gives

```text
C_M(q*p-1)
  = sum_(kappa in mP cap Z^3)
      c_a(q*kappa)c_s(-kappa)                  (mod p),

C_M(q*p-2)+C_M(q*p)
  = sum_(kappa in mP cap Z^3)
      c_a(q*kappa)
      {c_s(-2*kappa)+b_s}                      (mod p).
```

The second identity needs

```text
s + 2*floor(M/(q*p-2)) < p,
```

not merely `s+2<p`.

The fixed-domain formulas written in Q5881 are nevertheless correct in the **strict three-node first-cell regime**

```text
1 <= q*p-2,
q*p <= M,
M < 2*(q*p-2),
s+2 < p.
```

Indeed, these inequalities force

```text
t_2=t_1=t_0=1,
m=floor(a/q)=1,
```

so the corrected domain really is `P cap Z^3`.

The Q5881 wording was therefore underspecified rather than uniformly correct: saying only that the central shell `q*p-1` is in the first cell does **not** suffice for the three-shell `J_(a,q)` identity.

The first failure of that weaker reading is

```text
(p,a,q,s,M)=(3,1,1,0,3).
```

In the usual `p>=5` range, the first failure is

```text
(p,a,q,s,M)=(5,1,1,2,7).
```

There

```text
floor(7/3)=2,
floor(7/4)=floor(7/5)=1,

(C_7(3),C_7(4),C_7(5)) = (3,0,0) mod 5,
```

while the Q5881 fixed-`P` right side for the paired expression is

```text
sum_(kappa in P cap Z^3)
  c_1(kappa){c_2(-2*kappa)+b_2}
 = 545+40*73
 = 3465
 = 0 mod 5.
```

Hence

```text
C_7(3)+C_7(5) = 3 != 0 mod 5.
```

So the missing shell-domain layer produces a genuine discrepancy.

# 2. General coefficient lemma

Use the convention

```text
c_t(nu)=0 when nu is outside tP.
```

## Theorem 2.1 — corrected higher-Cartier shell alias

Let `p` be prime, let

```text
M=a*p+s,
0 <= s < p,
q >= 1,
v >= 0,
d_v=q*p-v,
1 <= d_v <= M,
t_v=floor(M/d_v),
m=floor(a/q).
```

Assume

```text
s+v*t_v < p.                                      (2.1)
```

Then

```text
C_M(d_v)
  = sum_(kappa in mP cap Z^3)
      c_a(q*kappa)c_s(-v*kappa)                  (mod p).          (2.2)
```

No symmetry of `P` is being used.  In particular, because this Newton polytope is not centrally symmetric, the factor `c_s(-v*kappa)` must retain its sign exactly as written.

## Proof

Freshman's dream gives

```text
Lambda^(a*p+s)
 = Lambda^a(X^p)Lambda^s(X)                      (mod p).
```

Therefore, for every exponent `nu`,

```text
c_(a*p+s)(nu)
 = sum_(mu in aP cap Z^3)
     c_a(mu)c_s(nu-p*mu)                         (mod p).          (2.3)
```

Fix

```text
kappa in t_v P cap Z^3
```

and substitute

```text
nu=(q*p-v)kappa.
```

A term in (2.3) has

```text
beta=(q*p-v)kappa-p*mu
     =p(q*kappa-mu)-v*kappa,

mu in aP,
beta in sP.                                      (2.4)
```

Put

```text
delta=q*kappa-mu in Z^3.
```

If `delta` is nonzero, choose a coordinate `i` with

```text
|delta_i| >= 1.
```

Because `kappa` belongs to `t_vP` and `P` is contained in `[-1,1]^3`,

```text
|kappa_i| <= t_v.
```

Equation (2.4) then gives

```text
|beta_i|
 >= p-v*t_v
 > s,
```

contradicting

```text
beta in sP subset [-s,s]^3.
```

Thus the only possible term is

```text
delta=0,
mu=q*kappa,
beta=-v*kappa,                                  (2.5)
```

and hence

```text
c_M((q*p-v)kappa)
 =c_a(q*kappa)c_s(-v*kappa)                       (mod p).          (2.6)
```

It remains to identify the nonzero summation domain.  First,

```text
t_v >= m,                                         (2.7)
```

because `q*p-v <= q*p` implies

```text
M/(q*p-v) >= a/q.
```

Second, for an integral `kappa`,

```text
q*kappa in aP
  iff kappa in mP.                                (2.8)
```

To see this, write the defining inequalities of `P` as

```text
L_j(x) <= 1,
```

where every `L_j` has integral coefficients.  Then

```text
q*kappa in aP
  iff L_j(kappa) <= a/q for every j
  iff L_j(kappa) <= floor(a/q)=m for every j,
```

because every `L_j(kappa)` is an integer.  This is precisely `kappa in mP`.

The terms with `kappa` in `t_vP` but outside `mP` therefore have

```text
c_a(q*kappa)=0.
```

Using (2.7) reduces the shell sum from `t_vP` to `mP`, proving (2.2).  QED.

# 3. The formulas needed in Q5881

# 4. Strict first-cell corollary

## Corollary 4.1

Assume

```text
1 <= q*p-2,
q*p <= M=a*p+s,
M < 2*(q*p-2),
s+2 < p.                                          (4.1)
```

Then

```text
t_2=t_1=t_0=1,
m=floor(a/q)=1.                                  (4.2)
```

Consequently

```text
C_M(q*p-1)
 =sum_(kappa in P cap Z^3)
    c_a(q*kappa)c_s(-kappa)                       (mod p),

C_M(q*p-2)+C_M(q*p)
 =sum_(kappa in P cap Z^3)
    c_a(q*kappa){c_s(-2*kappa)+b_s}               (mod p).          (4.3)
```

### Proof

The first three nodes all lie in `(M/2,M]`, so their shell quotients are one.  Moreover

```text
t_0=floor(M/(q*p))=floor(a/q)=m,
```

hence `m=1`.  The inequality `s+2<p` is exactly (2.1) for the leftmost row because `t_2=1`.  Apply Theorem 2.1.  QED.

This is the precise version under which Q5881's fixed `P cap Z^3` formulas are valid.

# 5. First counterexamples to the weaker wording

Suppose only the central node `q*p-1` is required to be in the first cell, while the left neighbor `q*p-2` is not.

## 5.1 Absolute first counterexample

Take

```text
p=3,
a=q=1,
s=0,
M=3,
(d_2,d_1,d_0)=(1,2,3).
```

Then

```text
(t_2,t_1,t_0)=(3,1,1),
s+2<p.
```

The central node is in the strict first cell, but the left node is not.  Since the sum of all coefficients of `Lambda` is `40`,

```text
C_3(1)=40^3=1 mod 3,
C_3(3)=40=1 mod 3.
```

The fixed-`P` right side is

```text
sum_(kappa in P cap Z^3)
 c_1(kappa){c_0(-2*kappa)+b_0}
 =c_1(0)+sum_kappa c_1(kappa)
 =5+40
 =0 mod 3.
```

Thus

```text
C_3(1)+C_3(3)=2 != 0 mod 3.
```

## 5.2 First counterexample with `p>=5`

Take

```text
p=5,
a=q=1,
s=2,
M=7,
(d_2,d_1,d_0)=(3,4,5).
```

Then

```text
(t_2,t_1,t_0)=(2,1,1),
s+2<p.
```

Direct use of the one-fold formula implemented by `shell_batch` gives

```text
(C_7(3),C_7(4),C_7(5))=(3,0,0) mod 5.             (5.1)
```

For `a=q=1`, the Q5881 right side is the doubled-period packet

```text
J_2=h_2+40b_2=545+40*73=3465=0 mod 5.             (5.2)
```

Equations (5.1)--(5.2) give

```text
C_7(3)+C_7(5)=3 != J_2=0 mod 5.
```

The failure is exactly the omitted second shell layer in

```text
floor(7/3)P=2P.
```

Notice that the single-shell `B_(a,q)` formula at `d_1=4` still works.  The failure is in the paired `J_(a,q)` formula, because its leftmost shell is no longer first-cell and the correct safety condition is

```text
s+2*t_2=2+4=6 < 5,
```

which is false.

# 6. Exhaustive finite audit through `p<=101`

For the strict three-node conditions (4.1), every odd prime `p>=5` has exactly

```text
N_p=(p-1)(p-3)(p+2)/4                              (6.1)
```

parameter triples `(a,q,s)`.

To derive (6.1), write `p=2k+1`.

- If `a=2h`, the admissible `q` are `h+1,...,2h`, and each permits `p-2` values of `s`.
- If `a=2h+1`, the values `q=h+2,...,2h+1` each permit `p-2` values of `s`; the boundary value `q=h+1` has `2q-a=1` and permits exactly `p-4` values because the strict first-cell inequality becomes `s<=p-5`.

Summing gives (6.1).  The prime `p=3` contributes one additional case.

Therefore the exhaustive range `p<=101` contains

```text
1,392,279 strict first-cell parameter cases,
2,784,558 shell identities.                              (6.2)
```

The corrected theorem proves that every one of these identities holds; there are zero corrected counterexamples.

A literal invocation of the repository's `shell_batch` on the complete subrange `p<=13` consists of

```text
1+14+54+260+450=779 parameter cases,
1,558 shell equalities.                                  (6.3)
```

The checker below performs that literal cross-check and performs the full `p<=101` audit using the exact Freshman's-dream coefficient convolution.  The latter is not a recurrence guess or a replacement definition: it computes the same coefficient sum as `shell_batch`, but avoids constructing binomial rows of length `Theta(M)` for each of the 1.39 million cases.

#!/usr/bin/env python3
from functools import lru_cache
from itertools import product
from pathlib import Path
import sys

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE))

from q32_cartier_packet_audit import (
    coefficient,
    polytope_points,
    primes_up_to,
    shell_batch,
)

P = tuple(polytope_points(1))


def scale(v, c):
    return tuple(c*x for x in v)


def sub(u, v):
    return tuple(u[i]-v[i] for i in range(3))


def in_poly(v, t):
    if t < 0:
        return False
    x, y, z = v
    return (
        -t <= x <= t and -t <= y <= t and -t <= z <= t
        and x-y <= t and x-z <= t
    )


@lru_cache(maxsize=None)
def c(t, nu):
    if not in_poly(nu, t):
        return 0
    return coefficient(t, *nu)


def corrected_rhs(p, a, q, s, v):
    m = a // q
    return sum(
        c(a, scale(kappa, q))*c(s, scale(kappa, -v))
        for kappa in polytope_points(m)
    ) % p


def full_cartier_shell(p, a, q, s, v):
    """Exact C_(ap+s)(qp-v) modulo p from coefficient convolution."""
    M = a*p+s
    d = q*p-v
    t = M // d
    # beta=p*delta-v*kappa lies in sP subset [-s,s]^3.
    # Hence |delta_i| <= floor((s+v*t)/p).
    radius = (s+v*t) // p
    total = 0
    for kappa in polytope_points(t):
        for delta in product(range(-radius, radius+1), repeat=3):
            mu = sub(scale(kappa, q), delta)
            beta = sub(scale(delta, p), scale(kappa, v))
            if in_poly(mu, a) and in_poly(beta, s):
                total += c(a, mu)*c(s, beta)
    return total % p


def strict_cases(limit=101):
    cases = 0
    for p in primes_up_to(limit):
        if p < 3:
            continue
        for a in range(1, p):
            for s in range(p):
                M = a*p+s
                for q in range(1, a+1):
                    d2, d1, d0 = q*p-2, q*p-1, q*p
                    if not (
                        1 <= d2
                        and d0 <= M
                        and M < 2*d2
                        and s+2 < p
                    ):
                        continue

                    assert M//d2 == M//d1 == M//d0 == 1
                    assert a//q == 1

                    lhs_B = full_cartier_shell(p,a,q,s,1)
                    rhs_B = corrected_rhs(p,a,q,s,1)
                    assert lhs_B == rhs_B

                    lhs_J = (
                        full_cartier_shell(p,a,q,s,2)
                        + full_cartier_shell(p,a,q,s,0)
                    ) % p
                    rhs_J = (
                        corrected_rhs(p,a,q,s,2)
                        + corrected_rhs(p,a,q,s,0)
                    ) % p
                    assert lhs_J == rhs_J
                    cases += 1
    assert cases == 1_392_279
    return cases


def literal_shell_batch_subaudit(limit=13):
    cases = 0
    for p in primes_up_to(limit):
        if p < 3:
            continue
        for a in range(1, p):
            for s in range(p):
                M = a*p+s
                for q in range(1, a+1):
                    d2, d1, d0 = q*p-2, q*p-1, q*p
                    if not (
                        1 <= d2
                        and d0 <= M
                        and M < 2*d2
                        and s+2 < p
                    ):
                        continue
                    values = shell_batch(M,(d2,d1,d0),modulus=p)
                    assert values[d1] == corrected_rhs(p,a,q,s,1)
                    assert (values[d2]+values[d0]) % p == (
                        corrected_rhs(p,a,q,s,2)
                        + corrected_rhs(p,a,q,s,0)
                    ) % p
                    cases += 1
    assert cases == 779
    return cases


def boundary_counterexamples():
    values = shell_batch(7,(3,4,5),modulus=5)
    assert (values[3],values[4],values[5]) == (3,0,0)
    assert (
        corrected_rhs(5,1,1,2,2)
        + corrected_rhs(5,1,1,2,0)
    ) % 5 == 0


if __name__ == "__main__":
    boundary_counterexamples()
    print("literal cases",literal_shell_batch_subaudit())
    print("full cases",strict_cases())
    print("Q5919_HIGHER_CARTIER_AUDIT=PASS")

# Final correction to Q5881

The higher-Cartier discussion should use the following wording.

```text
Let M=a*p+s with 0<=s<p. For d_v=q*p-v put

t_v=floor(M/d_v),
m=floor(a/q).

If 1<=d_v<=M and s+v*t_v<p, then

C_M(d_v)
  =sum_(kappa in mP cap Z^3)
     c_a(q*kappa)c_s(-v*kappa) mod p.

In particular, if q*p<=M<2(q*p-2) and s+2<p,
then m=t_0=t_1=t_2=1, so the sums may be written over
P cap Z^3.
```

That corrected lemma is exact.  The fixed-`P` formula is not valid outside the strict three-node first-cell regime without replacing both its domain and its safety inequality as above.
