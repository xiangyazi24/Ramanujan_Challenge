# Q6687: renewal self-similarity of collision sets

## (1) Exact algebraic renewal map

The renewal identity is

```text
K_{m+g+1}(X)=K_{m+1}(X)K_g(X+m+1)
 -(X+m+1)^6 K_m(X)K_{g-1}(X+m+2).
```

At a collision base X=x0 with K_m(x0)=0, the second term vanishes identically and we get

```text
K_{m+g+1}(x0)=K_{m+1}(x0) K_g(x0+m+1).
```

Therefore, provided K_{m+1}(x0) is nonzero, the higher collision condition is exactly

```text
K_{m+g+1}(x0)=0 <=> K_g(x0+m+1)=0.
```

The precise self-similarity statement is not simply

```text
(r,h) in Z and (r+h,g) in Z <=> (r,h+g) in Z.
```

There is a correction factor. The exact statement is:

```text
(r,h) in Z,
K_{h+1}(r) != 0
=>
(r,h+g) in Z <=> (r+h+1,g-1) in Z_shift,
```

where the shifted system is the continuant family beginning at the translated base r+h+1. The index shift depends on whether h denotes the zero order or the continuant length; with the convention above the renewal increment is h+1.

If the bounded factor K_{h+1}(r) also vanishes, the point is a higher-order collision and the decomposition recurses through the left factor instead. Hence the true object is a tree of renewals, not a single renewal chain.

Conclusion: Z is an algebraic renewal set in a generalized sense, but not a classical renewal process. The renewal kernel is deterministic and state-dependent.

## (2) Renewal equation for collision counts

Let P_d be the primitive/first-return collision count at depth d, and let S_D be the total number of collisions with depth <=D. The formal renewal equation is

```text
S_D = P_D + sum_{j=0}^{D-1} P_j S_{D-j-1}
```

or in generating-function form

```text
S(z)=P(z)/(1-P(z)).
```

This is the exact analogue of the probabilistic renewal equation, but the coefficients here are algebraic return counts.

The transfer consequence is:

If

```text
sum_{j<=D} P_j << f(D)
```

and the total primitive mass stays subcritical,

```text
P(1)=sum_j P_j < 1-\epsilon,
```

then

```text
S_D << f(D).
```

More generally, without subcriticality, one only gets the convolution bound

```text
S_D <= P_D + (P*S)_D,
```

and the growth is governed by the singularity of P(z). Thus the required primitive input is not a sharp pointwise bound on all collisions; it is a first-return estimate plus exclusion of renewal mass accumulation.

This is weaker than the current wall faces in one direction: it asks for primitive collisions only. However, it introduces a new hard input: prove that repeated algebraic returns do not create a critical branching factor.

## (3) Obstruction: what replaces independence?

The probabilistic renewal proof uses independence of future increments. Here there is no independence.

The replacement would have to be an algebraic transversality statement:

```text
K_g(x0+m+1)
```

must behave like a fresh member of the continuant family evaluated at a shifted point.

The obstruction is exactly that the shift is not random. The translated point x0+m+1 is produced by the previous collision history. Therefore the next collision event is conditioned on an algebraic constraint inherited from the first collision.

The wall re-enters at:

```text
(r,h) -> (r+h+1,g)
```

because the translated starting point belongs to the same orbit. The shifted polynomial family is fresh symbolically but not statistically fresh. Existing gap-polynomial and moment bounds control each fixed fiber but do not control this orbit-conditioned recurrence.

A successful theorem would need one of:

1. a primitive-return sparsity theorem stable under all renewal translations;
2. a rank-drop argument showing higher renewals force extra algebraic constraints;
3. a monotone renewal inequality over the collision tree.

## Least-confident point

The least-confident step is the exact normalization of the indices in the renewal map. The algebraic factorization is certain, but whether the translated collision should be written as (r+h+1,g-1), (r+h,g), or an equivalent shifted convention depends on the precise definition of K_m versus gap length.

## Blind spot

The main blind spot is treating the collision set as a one-dimensional renewal process. The correct structure is a branching renewal tree because a collision can simultaneously kill the right factor and create a new collision in the left factor. Any future proof must count renewal depth, not only collision depth.

The opportunity is real: primitive first-return control could be substantially stronger than marginal zero-set bounds. The obstruction is that deterministic algebraic translation replaces probabilistic independence, and that is exactly where current estimates lose their leverage.
