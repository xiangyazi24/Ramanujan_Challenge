# Zero-specific renewal of the continuant collision lattice

## Executive verdict

There is a genuine exact renewal law, but the correct conclusion is sharper and more restrictive than the previous draft.

1. On the regular locus, the correction factor `K_(m+1)(x)` can never vanish at a zero of `K_m(x)`. Thus the collision lattice is not a branching renewal tree. Every fixed base has one deterministic chain of successive returns.

2. In physical gap notation the exact self-similarity is precisely

```text
(r,h) in Z_reg and (r+h,g) in Z_reg
    <=>
(r,h+g) in Z_reg,
```

provided the first event `(r,h)` is present. Equivalently, after the first return of length `h`, all later returns are exactly `h` plus the return set from the translated base `r+h`.

3. The exact counting equation is base-dependent:

```text
u_n(r)
 = f_n(r)
   + sum_(2<=h<=n-2) f_h(r) nu_(n-h)(r+h).
```

After summing over `r`, the second term is a shifted correlation. It is not the scalar convolution `P*S`. The scalar renewal equation would require an independence or mixing statement and, after normalization, would contain a factor `1/p`.

4. A bound only on the primitive counts

```text
P_(<=D)=sum_(h<=D) P_h << f(D)
```

implies at best

```text
S_D << D f(D)
```

from the renewal structure alone. To obtain `S_D << f(D)`, one must also control continuation along the first-return map, for example by a repeated-return bound or a shifted-correlation estimate.

5. Reflection upgrades the first-return map to a partial bijection. This removes branching exactly, but it does not create contraction: the resulting renewal operator is a partial permutation with spectral radius potentially equal to `1`. Long chains are the deterministic replacement for critical renewal mass.

At the target `D=sqrt(p)`, the genuinely sufficient package remains

```text
primitive support P_(<=D) << D p^epsilon,
repeated-return mass Q_D << D p^epsilon.
```

The primitive clause is formally weaker than the total collision bound, but in the expected regime repeated returns are only `O(1)`, so it is essentially the same main-term difficulty.

## 1. Conventions and the regular locus

Use the continuants

```text
K_(-1)(X)=0,
K_0(X)=1,
K_1(X)=P(X),
K_(m+1)(X)=P(X+m)K_m(X)-(X+m)^6K_(m-1)(X).
```

The banked addition identity is

```text
K_(m+g+1)(X)
 = K_(m+1)(X) K_g(X+m+1)
   -(X+m+1)^6 K_m(X) K_(g-1)(X+m+2).       (1.1)
```

A zero of `K_m(X)` represents a zero-to-zero gap of physical length `m+1`: the previous zero is at `X-1`, the new zero is at `X+m`, and the next restart base is `X+m+1`.

The transfer is regular through this segment when

```text
Delta_m(X)=product_(j=1)^m (X+j) != 0.       (1.2)
```

All collision gaps extracted from the nonwrapping physical interval lie on this regular locus. The excluded points are exactly the cut-edge/singular-transfer points that produce the polluted vertical rays in the raw polynomial root diagram.

For physical gap notation, define

```text
N_h(r)=K_(h-1)(r+1),        h>=1.             (1.3)
```

Thus `N_1=1`, so every genuine collision gap has `h>=2`. Its regularity condition is

```text
Gamma_h(r)=product_(j=1)^h (r+j) != 0.        (1.4)
```

## 2. The correction factor is automatically nonzero

Suppose

```text
K_m(x)=0,
Delta_m(x)!=0.                                  (2.1)
```

Then `K_(m-1)(x)!=0`. Indeed, if both `K_m(x)` and `K_(m-1)(x)` vanished, the recurrence and the nonvanishing of the edge factors would propagate backward to `K_0(x)=0`, contradicting `K_0=1`.

Now the recurrence gives

```text
K_(m+1)(x)
 = P(x+m)K_m(x)-(x+m)^6K_(m-1)(x)
 = -(x+m)^6K_(m-1)(x)
 !=0.                                             (2.2)
```

Therefore, at every regular collision, (1.1) reduces to

```text
K_(m+g+1)(x)
 = K_(m+1)(x) K_g(x+m+1),                       (2.3)
```

with a nonzero first factor. Hence

```text
K_(m+g+1)(x)=0
    <=>
K_g(x+m+1)=0.                                    (2.4)
```

This is an equivalence, not merely one implication.

The only way the correction factor can also vanish is to leave the regular locus. More precisely,

```text
{K_m=K_(m+1)=0}
 subset
{Delta_m=0}.                                     (2.5)
```

Thus the raw set has a singular correction, but the regular collision set used in the gap argument does not.

This corrects the earlier branching interpretation: there is no regular case in which both the left bounded factor and the translated fresh factor independently create descendants.

## 3. Exact self-similarity in both index conventions

### 3.1 Continuant-index convention

Let

```text
Z_K^reg
 ={(x,m):m>=1, Delta_m(x)!=0, K_m(x)=0}.
```

If `(x,m)` lies in `Z_K^reg`, then for every `g>=1`, with the concatenated segment regular,

```text
(x,m+g+1) in Z_K^reg
    <=>
(x+m+1,g) in Z_K^reg.                              (3.1)
```

The `+1` is not an error: a `K_m` collision has physical length `m+1`, and after the endpoint zero one advances one step to the next restart base.

### 3.2 Physical gap convention

Let

```text
Z^reg
 ={(r,h):h>=2, Gamma_h(r)!=0, N_h(r)=0}.
```

Put `m=h-1`, `g=k-1`, and `x=r+1` in (2.4). Then

```text
N_(h+k)(r)=0
    <=>
N_k(r+h)=0,                                        (3.2)
```

whenever `N_h(r)=0` regularly. Including regularity, the clean statement is

```text
(r,h) in Z^reg and (r+h,k) in Z^reg
    <=>
(r,h) in Z^reg and (r,h+k) in Z^reg.               (3.3)
```

Thus the map proposed in the question is exactly correct when `h` and `k` denote physical zero-to-zero distances.

There is no remaining index ambiguity:

```text
K-index:       m followed by g gives m+g+1.
physical gap:  h followed by k gives h+k.
restart base:  x moves to x+m+1.
zero base:     r moves to r+h.
```

## 4. First returns and the exact deterministic renewal chain

For a regular base `r`, define its return set

```text
H(r)={h>=2:(r,h) in Z^reg}.                         (4.1)
```

If `H(r)` is nonempty, define the primitive or first-return length

```text
tau(r)=min H(r).                                    (4.2)
```

Applying (3.2) with `h=tau(r)` gives the disjoint identity

```text
H(r)
 ={tau(r)} disjoint_union
  {tau(r)+g:g in H(r+tau(r))}.                      (4.3)
```

Iterate this. Put

```text
r_0=r,
h_i=tau(r_(i-1)),
r_i=r_(i-1)+h_i,
```

as long as the next first return exists. Then

```text
H(r)
 ={h_1,
   h_1+h_2,
   h_1+h_2+h_3,
   ...}.                                            (4.4)
```

Every later collision has a unique decomposition into consecutive primitive gaps. There is no branching for a fixed base.

This is a genuine deterministic renewal structure. It is not a classical probabilistic renewal process because the increments

```text
h_1, h_2, ... = tau(r_0), tau(r_1), ...
```

are neither independent nor identically distributed. They are values of one deterministic function `tau` along the translated orbit.

A precise name is:

```text
nonstationary deterministic Markov renewal system,
```

or, after reflection below,

```text
length-decorated partial permutation.
```

## 5. Reflection makes the first-return map a partial bijection

The continuants satisfy the banked reflection law

```text
K_m(-X-m)=(-1)^m K_m(X).                            (5.1)
```

In physical gap notation this becomes

```text
N_h(-1-r-h)=(-1)^(h-1) N_h(r).                      (5.2)
```

Let

```text
J(r)=-1-r mod p.                                    (5.3)
```

A collision edge

```text
r ----h----> r+h
```

is reflected to

```text
J(r+h) ----h----> J(r).                             (5.4)
```

Regularity is preserved because the edge factors are merely reversed up to sign.

Primitivity is also preserved. If the reflected edge had an intermediate collision, reflecting that subcollision back would give a collision segment ending at `r+h` from an interior point of the original segment. Since the suffix transfer is invertible, the original trajectory would then be in the restart state at that interior point, contradicting that `h=tau(r)` was the first return.

Define the first-return map

```text
F(r)=r+tau(r)                                      (5.5)
```

on the set where `tau(r)` exists. Reflection gives

```text
F(J(F(r)))=J(r).                                    (5.6)
```

Equivalently,

```text
F^(-1)=J F J                                        (5.7)
```

on the range of `F`. Therefore `F` is injective. It is a partial bijection between its domain and range.

Another useful formulation is

```text
G=J F.
```

Then `G` is an involution on the primitive edge set:

```text
G^2=id.                                             (5.8)
```

For a fixed lag `h`, this is exactly the banked row reflection

```text
r -> p-1-h-r.
```

Thus the primitive graph is not a tree. It is a union of directed paths and, if one works cyclically modulo `p`, possibly cycles. In the nonwrapping interval relevant to the gap argument, the edges move forward and one sees directed paths.

This injectivity is a real algebraic gain: there is no multiplicative branching of descendants. But a partial permutation can still have arbitrarily long paths, so injectivity alone does not bound the number of ancestor-descendant pairs.

## 6. The exact renewal equation

Define the all-return and first-return indicators

```text
u_h(r)=1_[(r,h) in Z^reg],

f_h(r)=1_[tau(r)=h].                                (6.1)
```

Set

```text
nu_0(r)=1,
nu_1(r)=0.
```

Then the exact pointwise renewal equation is

```text
nu_n(r)
 = sum_(2<=h<=n) f_h(r) nu_(n-h)(r+h).              (6.2)
```

Because at most one `f_h(r)` is nonzero, (6.2) is simply (4.3) written coefficientwise. Splitting off `h=n` gives

```text
nu_n(r)
 = f_n(r)
   + sum_(2<=h<=n-2) f_h(r) nu_(n-h)(r+h).          (6.3)
```

### 6.1 Cumulative form

Put

```text
U_D(r)=sum_(2<=n<=D) nu_n(r),
F_D(r)=sum_(2<=h<=D) f_h(r)=1_[tau(r)<=D].           (6.4)
```

Then

```text
U_D(r)
 = F_D(r)
   + sum_(2<=h<=D-2) f_h(r) U_(D-h)(r+h).           (6.5)
```

This is the exact algebraic renewal equation for one base.

### 6.2 Summed form

Let

```text
A_n=sum_r nu_n(r),
P_h=sum_r f_h(r),
P_(<=D)=sum_(h<=D)P_h,
S_D=sum_(n<=D)A_n=sum_r U_D(r).                      (6.6)
```

Summing (6.3) gives

```text
A_n
 = P_n
   + sum_(2<=h<=n-2) C_(h,n-h),                     (6.7)
```

where the continuation correlation is

```text
C_(h,g)
 = sum_r f_h(r) nu_g(r+h)
 = #{r:tau(r)=h and N_g(r+h)=0 regularly}.          (6.8)
```

The cumulative equation is

```text
S_D
 = P_(<=D)
   + sum_(h+g<=D, h>=2, g>=2) C_(h,g).              (6.9)
```

Every non-first return is counted exactly once in the second term: use its unique first primitive segment `h` and its remaining return length `g`.

Equation (6.9), not a scalar convolution, is the exact global renewal equation.

### 6.3 Operator form

For `|z|<1`, define

```text
(K_z phi)(r)
 = sum_(h>=2) f_h(r) z^h phi(r+h)
 = z^(tau(r)) phi(F(r))                              (6.10)
```

on the domain of `F`. If

```text
R(r,z)=sum_(n>=0)nu_n(r)z^n,
```

then

```text
R=1+K_z R,
R=(I-K_z)^(-1)1.                                    (6.11)
```

Because `F` is injective, `K_1` is a partial permutation operator. For `1<=q<=infinity`,

```text
||K_z||_(ell^q -> ell^q) <= |z|^2.                  (6.12)
```

The issue is what happens as `z` tends to `1`: the norm tends to `1`, so the resolvent need not remain bounded. Long paths are the operator-theoretic obstruction.

## 7. Why the scalar probabilistic renewal equation is false here

A classical renewal sequence with first-return probabilities `q_h` obeys

```text
u_n=q_n+sum_h q_h nu_(n-h).                         (7.1)
```

If one chooses the base `r` uniformly from `F_p`, the natural normalized quantities are

```text
q_h=P_h/p,
v_n=A_n/p.                                         (7.2)
```

A scalar renewal equation would therefore have the form

```text
A_n
 = P_n
   +(1/p)sum_h P_h A_(n-h).                         (7.3)
```

The factor `1/p` is essential. The unnormalized formula `S=P+P*S` has the wrong scale.

Equation (7.3) would follow if, conditional on `tau(r)=h`, the translated point `r+h` were distributed like a fresh uniform base. It is not. It lies in the deterministic image

```text
F({r:tau(r)=h}),                                    (7.4)
```

and future return mass may be concentrated on precisely that image.

Reflection says this image is size-preserving; it does not say it is equidistributed. In fact the full first-return image satisfies

```text
Range(F)=J(Domain(F)).                              (7.5)
```

Thus the exact replacement for probabilistic independence is reversibility, not randomness.

## 8. What primitive-count bounds alone actually imply

Suppose `tau(r)=h<=D`. Every subsequent primitive gap has length at least `2`, because consecutive zeros are impossible. Hence this base contributes at most

```text
1+floor((D-h)/2)                                    (8.1)
```

returns of total length at most `D`.

Summing over first-return bases gives the unconditional inequality

```text
S_D
 <= sum_(2<=h<=D)
      (1+floor((D-h)/2)) P_h
 <= (D/2) P_(<=D)+P_(<=D).                         (8.2)
```

Therefore

```text
P_(<=D) << f(D)
    implies only
S_D << D f(D)                                       (8.3)
```

from the renewal structure alone.

This loss is real for the abstract deterministic renewal equation. A long path with short primitive edges has only linearly many primitive edges but quadratically many ancestor-descendant return pairs. Reflection can pair such a path with its reverse and does not remove the example.

Consequences for the current wall:

```text
known degree bound:  P_h <= #roots(N_h) <= 3(h-1),
therefore:           P_(<=D) << D^2.                (8.4)
```

Feeding (8.4) into (8.2) gives `D^3`, which is worse than the direct marginal root bound

```text
S_D=sum_(h<=D)#roots(N_h) << D^2.                   (8.5)
```

Even the conjectural primitive count

```text
P_h=O(1),
P_(<=D)=O(D)                                        (8.6)
```

would give only `S_D=O(D^2)` through counts alone.

Thus classical renewal gain does not come merely from replacing total returns by first returns. It comes from a second statement preventing the first-return map from feeding its image into another high-return set too often.

## 9. Two sufficient ways to recover a renewal gain

### 9.1 Shifted decorrelation

Assume an estimate of the form

```text
C_(h,g)
 <= (P_h A_g)/p + E_(h,g).                          (9.1)
```

Summing over `h+g<=D` gives

```text
S_D
 <= P_(<=D)
    +(1/p)sum_(h+g<=D)P_h A_g
    +E_D,                                           (9.2)
```

where

```text
E_D=sum_(h+g<=D)E_(h,g).
```

Let

```text
M_D=max_(L<=D)S_L.
```

Then

```text
M_D
 <= P_(<=D)
    +(P_(<=D)/p)M_D
    +E_D.                                           (9.3)
```

If

```text
P_(<=D) <= (1-delta)p,                              (9.4)
```

then

```text
S_D
 <= (P_(<=D)+E_D)/(1-P_(<=D)/p).                   (9.5)
```

At `D<=sqrt(p)`, the desired primitive estimate

```text
P_(<=D) << D p^epsilon=o(p)                         (9.6)
```

makes the denominator `1-o(1)`. Then an aggregate error `E_D<<D p^epsilon` transfers primitive control to total control with no loss.

This is the true scalar-renewal analogue.

### 9.2 Primitive support plus repeated-return mass

Let

```text
d_D(r)=U_D(r),
Q_D=sum_r binom(d_D(r),2).                          (9.7)
```

The number of bases with at least one return is exactly `P_(<=D)`. Also

```text
d <= 1+binom(d,2)       for every integer d>=1.
```

Therefore

```text
S_D
 <= P_(<=D)+Q_D.                                    (9.8)
```

A slightly sharper exact decomposition is

```text
S_D=P_(<=D)+E_D^first,                              (9.9)
```

where

```text
E_D^first
 =sum_(h+g<=D)
   #{r:tau(r)=h and nu_g(r+h)=1}.                   (9.10)
```

Since every non-first return pairs with the first return, one has

```text
E_D^first <= Q_D.                                   (9.11)
```

Thus the clean sufficient package is

```text
P_(<=D) << D p^epsilon,
Q_D      << D p^epsilon,                            (9.12)
```

which yields

```text
S_D << D p^epsilon.                                 (9.13)
```

This is exactly the primitive-support plus renewal-pair formulation of the previously isolated quenched renewal local-limit target.

## 10. Is the primitive input genuinely weaker?

Formally, yes:

```text
P_(<=D) <= S_D.                                     (10.1)
```

It ignores all later returns from a base and asks only whether a base is hit for the first time somewhere in the family.

Quantitatively, at the target scale it is not much weaker. The random model predicts

```text
P_(<=D) asymp D,
Q_D asymp S_D^2/p.                                  (10.2)
```

At `D=sqrt(p)` and `S_Dasymp D`, this gives

```text
Q_D=O(1).                                           (10.3)
```

So almost every collision is a singleton primitive collision. In that regime

```text
S_D=P_(<=D)+O(1).                                   (10.4)
```

This explains the singleton obstruction:

```text
all root sets for different h may be disjoint,
then Q_D=0 but P_(<=D)=S_D can still be of order D^2.
```

The model can retain the row reflection symmetry and the degree bounds. Hence perfect control of repeated returns does not imply the needed first moment.

The known wall faces give only

```text
P_h <= O(h),
P_(<=D) <= O(D^2),                                  (10.5)
```

which is the same exponent as the total marginal root count. The desired

```text
P_(<=D) << D p^epsilon                              (10.6)
```

is therefore not supplied by the existing inequalities. It is a cleaner statement than the total bound, but it contains the main missing anti-concentration theorem.

The splitting identities organize the proof after a first return; they do not prove that only `O(D)` bases possess a first return.

## 11. The exact point where the wall re-enters

The continuation term is

```text
C_(h,g)
 =#{r:
      tau(r)=h,
      N_g(r+h)=0}.                                  (11.1)
```

Ignoring the first-return exclusions for a moment, this is the common-root problem

```text
N_h(X)=0,
N_g(X+h)=0.                                         (11.2)
```

Equivalently, it is controlled by the shifted gcd or resultant

```text
gcd(N_h(X),N_g(X+h)),
Res_X(N_h(X),N_g(X+h)).                             (11.3)
```

The renewal identity says that on `N_h(X)=0`,

```text
N_(h+g)(X)
 = nonzero_factor(X) * N_g(X+h).                    (11.4)
```

This is an exact quotient-ring identity. It does not imply that the second factor behaves randomly on the roots of the first.

The precise conditioned object is

```text
the class of N_g(X+h)
inside F_p[X]/(N_h^prim(X)).                        (11.5)
```

A fixed-p theorem must show that this class vanishes on very few primitive `F_p`-points on average over the growing two-parameter family `(h,g)`.

For each fixed pair, generic coprimality or a nonzero resultant is useful. But at `D=sqrt(p)` there are `asymp D^2asymp p` pairs. Individual degree bounds or nonzero integer resultants do not control how often one fixed prime divides the entire family of resultants.

This is exactly the cross-`h` family-compatibility wall in zero-specific form.

The shifted polynomial is fresh symbolically, but the evaluation point is not fresh statistically:

```text
r is conditioned by tau(r)=h,
r+h is the deterministic first-return image F(r).  (11.6)
```

What must replace probabilistic independence is one of the following genuinely new statements:

```text
1. shifted primitive-root decorrelation as in (9.1);
2. an average gcd/resultant bound over (h,g);
3. an expansion or mixing theorem for the partial permutation F;
4. a direct bound on long first-return chains;
5. a primitive-support theorem P_(<=D)<<D p^epsilon.
```

The renewal algebra itself proves none of these.

## 12. Positivity, monotonicity, and why they are insufficient

There is positivity:

```text
nu_h(r), f_h(r), U_D(r) are nonnegative indicators/counts.
```

There is also monotonicity in `D`.

Moreover reflection gives exact mass preservation for one first-return step because `F` is injective. In operator language, `K_1` is a partial isometry/permutation.

But classical renewal transfer needs more than positivity. It needs either:

```text
stationarity of the post-renewal law,
```

or

```text
contraction/mixing of the renewal operator.
```

Here one has neither. At `z=1`, the operator norm is `1`, and a long directed path causes

```text
1+K_1+K_1^2+...+K_1^L
```

to have norm of order `L`.

So the obstruction is no longer a branching factor. It is a conservative, nonmixing first-return dynamics. The deterministic future can remain trapped in a high-return chain.

This is the exact location where the probabilistic analogy stops.

## 13. Strongest rigorous consequence of renewal alone

The unconditional structural theorem is:

```text
THEOREM.
On the regular nonwrapping collision locus:

(a) every collision has a unique first-return decomposition;
(b) the return fiber from r is the sequence of partial sums of tau
    along the translated first-return orbit;
(c) reflection makes the first-return map a reversible partial bijection;
(d) the exact global count is

    S_D=P_(<=D)+sum_(h+g<=D) C_(h,g);

(e) primitive counts alone imply

    S_D <= sum_h (1+floor((D-h)/2))P_h
        << D P_(<=D).
```

No better exponent follows from the renewal identity without an additional correlation or chain-length theorem.

At the hatch scale `D=sqrt(p)L`, the route becomes decisive only if one proves the primitive-support estimate and one weak continuation estimate. The minimal target can be stated as

```text
[PRIMITIVE]
P_(<=D) << D p^epsilon,

[CONTINUATION]
E_D^first << D p^epsilon
```

uniformly for `D<=sqrt(p)`; or replace `[CONTINUATION]` by the stronger `Q_D<<D p^epsilon`.

Then the exact identity gives `S_D<<D p^epsilon` immediately.

## 14. Least-confident point

The least-confident part is not the renewal identity or the index normalization; those are exact. It is the negative assessment that the reversible first-return map has no further Apéry-specific restriction strong enough to bound long chains.

Abstractly, a reversible partial permutation can have long paths and the renewal equation gives no contraction. But the actual map comes from one special tridiagonal/Apéry cocycle. There could be an additional invariant, low-indegree theorem, noncrossing law, or arithmetic monotone quantity that forbids the abstract long-chain configurations. None is visible in the banked continuant, reflection, Casoratian, or splitting identities, but this is the point at which a genuinely zero-specific new operation could still enter.

---

## 15. Blind spot

The principal blind spot is that “primitive first return” is not Zariski closed. It is

```text
N_h(r)=0
and
N_j(r)!=0 for every 2<=j<h.                         (15.1)
```

Resultants and gcds naturally see the closed supersets `N_h=0`, not the exclusions. It is possible that the exclusions force much stronger geometry than the raw polynomial intersections reveal. Conversely, saturating away cut edges and earlier returns may destroy a global identity that is useful only before saturation.

A second blind spot is wraparound. The nonwrapping physical application is acyclic, while the full finite-field first-return map is a reversible partial permutation that may contain cycles crossing the singular indices. A proof using global cycle structure would not be visible in the local renewal equation above.

## Final answer to the three requested questions

### (1) Exact self-similarity

Yes, after restricting to regular collisions. In physical gap notation:

```text
N_h(r)=0
    =>
[N_(h+g)(r)=0 <=> N_g(r+h)=0].
```

The correction factor is automatically nonzero. The regular collision set is a deterministic renewal chain, not a branching tree. Reflection makes the primitive first-return map a partial bijection.

### (2) Renewal-theoretic transfer

The exact equation is

```text
S_D
 =P_(<=D)
  +sum_(h+g<=D)
    #{r:tau(r)=h and N_g(r+h)=0}.
```

A primitive bound `P_(<=D)<<f(D)` alone yields only `S_D<<D f(D)`. To transfer `P_(<=D)<<f(D)` to `S_D<<f(D)`, one also needs shifted decorrelation, bounded repeated-return mass, or an equivalent no-long-chain theorem.

At `D=sqrt(p)`, the required primitive input `P_(<=D)<<D p^epsilon` is formally weaker than the total bound but is not weaker in the expected main-term sense. It is the singleton first-return wall.

### (3) Exact obstruction

The obstruction occurs in the correlation

```text
#{r:tau(r)=h and N_g(r+h)=0}.
```

The shifted point `r+h` is not independent; it is the deterministic image under the first-return partial permutation. Algebraically, one must control `N_g(X+h)` on the primitive roots of `N_h(X)` across a growing fixed-prime family. Reflection supplies reversibility and positivity supplies monotonicity, but neither supplies mixing. That is precisely where the wall re-enters.
