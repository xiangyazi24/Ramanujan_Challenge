# The universal transverse pair \((b_r,\Xi_r)\): exact structure, counterexamples, and the surviving theorem target

## Executive verdict

The strongest pointwise transversality statement one might first hope for is false:

\[
\boxed{\text{There are primes }p>r\text{ with }p\mid b_r\text{ and }p\mid\Xi_r.}
\]

The first one is already

\[
\boxed{(r,p)=(13,17)},
\]

with

\[
b_{13}=364713572395983725,
\]

\[
\Xi_{13}=-344867095710258781523217696937913796,
\]

and

\[
\gcd(b_{13},\Xi_{13})=17,
\qquad
v_{17}(b_{13})=v_{17}(\Xi_{13})=1.
\]

This is exactly the unique transverse zero that was implicit in the `p<=199` audit of Q7617.

An exact scan through every `1<=r<=5000` finds only one further prime larger than its index:

\[
\boxed{(r,p)=(492,2237)},
\]

again with

\[
v_{2237}(b_{492})=v_{2237}(\Xi_{492})=1.
\]

Since

\[
\frac{2237}{492}=4.546747\ldots,
\]

even the pointwise exclusion `p>4r` and `p>(9/2)r` is false.  No prime `p>5r` occurs through `r=5000`, but **that is only a finite observation and is not promoted to a theorem**.

The exact structural outcome is nevertheless useful.  For every prime `p>r`:

\[
\boxed{
p\mid b_r,\ p\mid\Xi_r
\iff
p\mid b_r,\ \kappa_r\equiv0\pmod p,
}
\tag{V1}
\]

where reduction of the rational number `kappa_r` is legitimate because its denominator has no prime factor larger than `r`.  Moreover

\[
\boxed{
p\mid b_r,\ p\mid\Xi_r
\Longrightarrow
p\mid\Xi_r\text{ and }p\mid\Xi_{r+1}.
}
\tag{V2}
\]

Thus the transverse pair can be viewed either as the common zero of the homogeneous Apéry solution `b` and the universal inhomogeneous solution `kappa`, or as a forced pair of consecutive zeros of `Xi`.

What I **do not** obtain is an arithmetic Bezout/resultant bound of size `exp(o(r))`.  The natural Casoratian is already exactly `Xi_r`; saturating it at primes `p>r` merely replaces `Xi_r` by the numerator of `kappa_r`.  The analytic sizes are

\[
\log b_r=r\log(17+12\sqrt2)+O(\log r),
\]

\[
\log|\Xi_r|=2r\log(17+12\sqrt2)+O(\log r),
\]

so raw characteristic-zero height gives only an `O(r)` logarithmic bound, not `o(r)`.

The corrected arithmetic target is therefore the genuinely new statement

\[
\boxed{
\log\operatorname{rad}_{>r}\gcd(b_r,\Xi_r)=o(r),
}
\tag{TR}
\]

or, for direct use in the fixed-`n` problem, an aggregate version over the sampled residues `r=n mod p`.  Nothing in the Picard--Fuchs/Casoratian formalism proved below implies `(TR)` by itself.

Finally, this transverse theorem would control **only the doubly exceptional primes for which the normalized `p^3` defect also vanishes**.  It does not by itself control all primes `p|b_{n mod p}`.  The `p^3` defect is not target-selective.

# 1. Exact normalization

Put

\[
\mathscr P(x)=34x^3+51x^2+27x+5,
\qquad
\Delta(t)=1-34t+t^2,
\qquad
\theta=t\frac d{dt}.
\]

The Apéry generating function is

\[
F(t)=\sum_{r\ge0}b_rt^r,
\qquad
b_0=1,\quad b_1=5,
\]

and satisfies

\[
\boxed{
\mathcal L F=0,
\qquad
\mathcal L
=\theta^3-t\mathscr P(\theta)+t^2(\theta+1)^3.
}
\tag{1.1}
\]

Coefficient extraction gives the standard recurrence

\[
\boxed{
(r+1)^3b_{r+1}
=\mathscr P(r)b_r-r^3b_{r-1}.
}
\tag{1.2}
\]

Let `a_r` be the companion solution

\[
a_0=0,
\qquad a_1=6,
\]

satisfying the same recurrence.  Its exact Casoratian is

\[
\boxed{
r^3(a_rb_{r-1}-a_{r-1}b_r)=6
\qquad(r\ge1).
}
\tag{1.3}
\]

For the Beukers modular parameter one has the exact identity from the preceding modular calculation

\[
\boxed{H=F\sqrt\Delta.}
\tag{1.4}
\]

Consequently the reciprocal period appearing in Q7617 is

\[
\boxed{
C(t):=\frac1{F(t)^2\sqrt{\Delta(t)}}
      =\frac1{F(t)H(t)}
      =\sum_{r\ge0}g_rt^r.
}
\tag{1.5}
\]

If `q=q(t)` is the inverse mirror map, then

\[
\theta\log q=\frac1H,
\]

so there is also the useful exact form

\[
\boxed{C=\frac{\theta\log q}{F}.}
\tag{1.6}
\]

In the modular `q` coordinate,

\[
C(t(q))=\frac1{E(q)H(q)}.
\tag{1.7}
\]

Because `E,H` are integral unit `q`-series and `q(t)` is an integral compositional inverse, (1.7) proves

\[
\boxed{g_r\in\mathbf Z.}
\tag{1.8}
\]

The first values are

\[
\boxed{
(g_0,g_1,g_2,g_3,g_4,g_5)
=(1,7,192,5520,165168,5068320).
}
\tag{1.9}
\]

# 2. Differential equation and exact recurrence for `g_r`

From (1.5),

\[
\frac{\theta C}{C}
=-2\frac{\theta F}{F}
 -\frac12\frac{\theta\Delta}{\Delta}.
\]

Since

\[
\frac12\theta\Delta=t(t-17),
\]

we obtain the exact first-order equation

\[
\boxed{
\Delta F\,\theta C
+\bigl(2\Delta\,\theta F+t(t-17)F\bigr)C=0.
}
\tag{2.1}
\]

This is the cleanest differential equation for `C` coupled to the known period `F`.

For a coefficient recurrence, set `b_j=0` for `j<0` and define

\[
A_k=b_k-34b_{k-1}+b_{k-2},
\tag{2.2}
\]

\[
B_k=2k b_k+(51-68k)b_{k-1}+(2k-3)b_{k-2}.
\tag{2.3}
\]

Then

\[
\Delta F=\sum_{k\ge0}A_kt^k,
\]

\[
2\Delta\theta F+t(t-17)F
=\sum_{k\ge0}B_kt^k.
\]

Taking `[t^n]` in (2.1) gives

\[
\sum_{k=0}^n\bigl((n-k)A_k+B_k\bigr)g_{n-k}=0.
\tag{2.4}
\]

Since `A_0=1`, `B_0=0`, this is triangular:

\[
\boxed{
ng_n=-\sum_{k=1}^n M_{n,k}g_{n-k},
}
\tag{2.5}
\]

where

\[
\boxed{
M_{n,k}
=(n+k)b_k
 +(51-34n-34k)b_{k-1}
 +(n+k-3)b_{k-2}.
}
\tag{2.6}
\]

For example,

\[
g_1=7,
\qquad
g_2=192,
\qquad
g_3=5520.
\]

Equation (2.5) is an exact recurrence, but it has growing width.  I have not derived a finite-order scalar P-recursive recurrence for `g`; none is needed for the identities below.

# 3. The universal inhomogeneous Apéry solution `kappa_r`

Define

\[
\boxed{
\kappa_0=0,
\qquad
\kappa_1=-36.
}
\tag{3.1}
\]

For `r>=2`, Q7617 gives

\[
\boxed{
r^3\kappa_r
-\mathscr P(r-1)\kappa_{r-1}
+(r-1)^3\kappa_{r-2}
=-5g_r.
}
\tag{3.2}
\]

The first nontrivial value is

\[
\kappa_2=-\frac{1293}{2},
\]

which is a useful sign/denominator check:

\[
8\kappa_2-117(-36)=-960=-5g_2.
\]

Inductively, every prime occurring in the reduced denominator of `kappa_r` is at most `r`.  Therefore for every prime `p>r`, `kappa_r` has an unambiguous reduction modulo `p`.

Let

\[
K(t)=\sum_{r\ge0}\kappa_rt^r.
\]

The exceptional `r=1` initial term is exactly one unit more negative than `-5g_1=-35`.  Hence the complete generating-function equation is

\[
\boxed{
\mathcal L K=-5(C-1)-t.
}
\tag{3.3}
\]

Indeed:

- the constant coefficient on the right is zero;
- the coefficient of `t` is `-5g_1-1=-36`;
- for every `r>=2` it is `-5g_r`.

This is the smallest linear inhomogeneous Picard--Fuchs equation for `K` produced by the construction.

# 4. Green formula with all signs fixed

Use the fundamental homogeneous pair `(a_r,b_r)`.  Variation of constants with the Casoratian (1.3) yields

\[
\boxed{
\kappa_r
=-\frac{a_r}{6}
 -\frac56\sum_{m=1}^r
 g_m\bigl(a_rb_{m-1}-b_ra_{m-1}\bigr).
}
\tag{4.1}
\]

At `r=1`, this gives

\[
-\frac66
-\frac56\,7(6\cdot1-5\cdot0)
=-1-35=-36,
\]

so the endpoint sign is correct.

Define the companion transverse sum

\[
\Psi_r:=\sum_{m=1}^r g_ma_{m-1}.
\tag{4.2}
\]

The Green formula then simplifies to a particularly useful identity once `Xi_r` is introduced:

\[
\boxed{
6\kappa_r=a_r\Xi_r+5b_r\Psi_r.
}
\tag{4.3}
\]

This is one of the simplest exact closed forms I found.  It is not a new divisibility theorem, but it makes the two independent variation-of-constants directions explicit.

There is a second Casoratian:

\[
\boxed{
r^3(\kappa_ra_{r-1}-\kappa_{r-1}a_r)
=-5\Psi_r.
}
\tag{4.4}
\]

Together, (4.3)--(4.4) are the natural `2 x 2` variation-of-constants package for the inhomogeneous solution.

# 5. Derivation of `Xi_r` as the exact discrete Casoratian

Define

\[
\boxed{
\Xi_0=-1,
\qquad
\Xi_r=-1-5\sum_{m=1}^r g_mb_{m-1}\quad(r\ge1).
}
\tag{5.1}
\]

Thus

\[
\boxed{
\Xi_r-\Xi_{r-1}=-5g_rb_{r-1}.
}
\tag{5.2}
\]

The first values are

\[
\Xi_0=-1,
\qquad
\Xi_1=-36,
\qquad
\Xi_2=-4836,
\]

\[
\Xi_3=-2019636,
\qquad
\Xi_4=-1195358436.
\tag{5.3}

Now define

\[
W_r:=r^3(\kappa_rb_{r-1}-\kappa_{r-1}b_r).
\tag{5.4}
\]

Multiply (3.2) by `b_{r-1}`, multiply the homogeneous recurrence for `b_r` by `kappa_{r-1}`, and subtract.  For `r>=2` this gives

\[
W_r-W_{r-1}=-5g_rb_{r-1}.
\tag{5.5}

At the initial point,

\[
W_1=\kappa_1=-36
=-1-5g_1b_0.
\tag{5.6}

Therefore, by induction,

\[
\boxed{
\Xi_r
=r^3(\kappa_rb_{r-1}-\kappa_{r-1}b_r)
\in\mathbf Z
\qquad(r\ge1).

\tag{5.7}

This fixes the sign in the determinant identity.

Combining (5.1) with the Green formula also gives (4.3) directly:

6\kappa_r
=-a_r-5a_r\sum_{m=1}^rg_mb_{m-1}
 +5b_r\sum_{m=1}^rg_ma_{m-1}
=a_r\Xi_r+5b_r\Psi_r.

# 6. Generating function for `Xi`

Let

\[
X(z)=\sum_{r\ge0}\Xi_rz^r.
\]

Write `odot` for the Hadamard product:

\[
\left(\sum u_rz^r\right)\odot
\left(\sum v_rz^r\right)
:=\sum u_rv_rz^r.
\]

Since the coefficient of `z^r` in `zF(z)` is `b_{r-1}` for `r>=1`, (5.2) gives

\[
\boxed{
(1-z)X(z)
=-1-5\,(C\odot zF)(z).
}
\tag{6.1}
\]

Equivalently, using (5.7),

\[
\boxed{
X(z)+1
=\theta_z^3\Bigl((zF)\odot K-F\odot(zK)\Bigr).
}
\tag{6.2}
\]

Indeed the coefficient of `z^r`, `r>=1`, on the right is

\[
r^3(b_{r-1}\kappa_r-b_r\kappa_{r-1})=\Xi_r.
\]

For analytic manipulations the Hadamard product has the contour representation

\[
(A\odot B)(z)
=\frac1{2\pi i}\oint A(w)B(z/w)\frac{dw}{w}.
\tag{6.3}
\]

This is the exact generating function.  The crucial point is that it is **Hadamard**, not an ordinary product.  That is why no low-degree algebraic simplification of `Xi` follows from the elementary identity `C=1/(F^2 sqrt(Delta))`.

# 7. A closed recurrence system for `Xi`

The smallest exact coefficient system I obtain without guessing is:

\[
(r+1)^3b_{r+1}
=\mathscr P(r)b_r-r^3b_{r-1},
\tag{7.1}
\]

\[
ng_n=-\sum_{k=1}^nM_{n,k}g_{n-k},
\tag{7.2}
\]

\[
\Xi_n=\Xi_{n-1}-5g_nb_{n-1}.
\tag{7.3}
\]

One can eliminate `g_n` explicitly.  Put

\[
\delta_n:=\Xi_n-\Xi_{n-1}.
\]

Then

\[
g_n=-\frac{\delta_n}{5b_{n-1}}.
\]

Substituting in (7.2) yields the scalar growing-width recurrence

\[
\boxed{
\frac{n\delta_n}{b_{n-1}}
+\sum_{k=1}^{n-1}
M_{n,k}\frac{\delta_{n-k}}{b_{n-k-1}}
=5M_{n,n}.
}
\tag{7.4}
\]

This is exact over `Q`.  It is not finite width.

On the differential side, the closed system is

\[
\boxed{
\mathcal LF=0,
}
\tag{7.5}
\]

\[
\boxed{
\Delta F\theta C
+(2\Delta\theta F+t(t-17)F)C=0,
}
\tag{7.6}
\]

\[
\boxed{
\mathcal LK=-5(C-1)-t,
}
\tag{7.7}
\]

together with the Hadamard extraction (6.2).

I do **not** claim that this proves `Xi` is non-P-recursive, nor do I claim a scalar minimal-order differential equation.  What is proved is that the direct Picard--Fuchs elimination supplied by the construction leaves either a Hadamard product or a recurrence whose width grows with `n`.

# 8. Exact large-prime equivalences

Let `p>r` be prime and assume

\[
p\mid b_r.
\]

The no-two-consecutive-zeros lemma for the Apéry recurrence gives

\[
p\nmid b_{r-1}.
\tag{8.1}
\]

Also `p` does not divide `r`, and it does not divide the denominator of `kappa_r`.  Reducing (5.7) modulo `p` gives

\[
\Xi_r\equiv r^3b_{r-1}\kappa_r\pmod p.
\tag{8.2}
\]

The prefactor is a unit.  Hence

\[
\boxed{
p\mid b_r
\quad\Longrightarrow\quad
\left(p\mid\Xi_r\iff\kappa_r\equiv0\pmod p\right).
}
\tag{8.3}
\]

This is the exact universal transverse criterion behind Q7617.

If `kappa_r=A_r/D_r` is reduced, with every prime factor of `D_r` at most `r`, then

\[
\boxed{
\operatorname{rad}_{>r}\gcd(b_r,\Xi_r)
=
\operatorname{rad}_{>r}\gcd(b_r,A_r).
}
\tag{8.4}
\]

So Smith saturation at large primes does not make the problem disappear; it simply replaces the Casoratian by the numerator of the inhomogeneous solution.

There is another exact consequence.  From (5.2),

\[
\Xi_{r+1}=\Xi_r-5g_{r+1}b_r.
\]

Thus

\[
\boxed{
p\mid b_r,\ p\mid\Xi_r
\Longrightarrow
p\mid\Xi_{r+1}.
}
\tag{8.5}
\]

Therefore

\[
\boxed{
\operatorname{rad}_{>r}\gcd(b_r,\Xi_r)
\mid
\operatorname{rad}_{>r}\gcd(\Xi_r,\Xi_{r+1}).
}
\tag{8.6}
\]

If in addition `p does not divide g_{r+1}`, the converse holds modulo `p`:

\[
p\mid\Xi_r,\ p\mid\Xi_{r+1}
\Longrightarrow p\mid b_r.
\tag{8.7}
\]

This consecutive-`Xi` reformulation is exact, but the counterexamples below show that it cannot be upgraded to a universal no-consecutive-zero theorem.

# 11. Singularity and height audit

Let

\[
\rho=17-12\sqrt2=(\sqrt2-1)^4,
\qquad
\alpha=\rho^{-1}=17+12\sqrt2.
\tag{11.1}
\]

These are the roots of

\[
\Delta(t)=1-34t+t^2.
\]

## 11.1 Local exponents of the Apéry Picard--Fuchs operator

When `L` is expanded in powers of `theta`, the coefficient of `theta^3` is `Delta`, and the coefficient of `theta^2` is

\[
3t(t-17).
\]

At `t=rho`, the indicial factor is

\[
\lambda(\lambda-1)
\left[
\rho\Delta'(\rho)(\lambda-2)+3\rho(\rho-17)
\right].
\]

Because

\[
\Delta'(\rho)=2(\rho-17),
\]

the third factor is proportional to `2 lambda-1`.  Hence the local exponents are

\[
\boxed{0,\frac12,1.}
\tag{11.2}
\]

The Apéry solution has the square-root singular component, and the recurrence gives

\[
\boxed{
b_r\asymp c_b\alpha^r r^{-3/2}}
\tag{11.3}
\]

with `c_b>0`.  The exponent `-3/2` can also be recovered directly from a recurrence ansatz `b_r ~ alpha^r r^s`: the `1/r` term gives

\[
s(\alpha-\alpha^{-1})=51-3\alpha=-36\sqrt2,
\]

while

\[
\alpha-\alpha^{-1}=24\sqrt2,
\]

so

\[
s=-\frac32.
\]

## 11.2 Reciprocal period

Since `F(rho)` is finite and nonzero while `sqrt(Delta)` has exponent `1/2`, (1.5) gives

\[
C(t)\sim c_C(1-t/\rho)^{-1/2}.
\]

Therefore

\[
\boxed{g_r\asymp c_g\alpha^r r^{-1/2}.}
\tag{11.4}
\]

Consequently

\[
g_rb_{r-1}\asymp c\alpha^{2r}r^{-2}.
\]

Because consecutive terms have limiting ratio `alpha^2>1`, the terminal terms dominate the cumulative sum in (5.1), and

\[
\boxed{|\Xi_r|\asymp c_\Xi\alpha^{2r}r^{-2}.}
\tag{11.5}
\]

At logarithmic scale,

\[
\boxed{\log b_r=r\log\alpha+O(\log r),}
\tag{11.6}
\]

\[
\boxed{\log|\Xi_r|=2r\log\alpha+O(\log r).}
\tag{11.7}
\]

The Hadamard product in (6.1) correspondingly has dominant singular radius `rho^2`; its coefficient is of order `rho^{-2r}r^{-2}`, so the local singularity is of `(1-z/rho^2) log(1-z/rho^2)` type up to analytic terms.

This singularity analysis is important negatively: the natural integer `Xi_r` is **not** a subexponential-height carrier.  Its logarithmic height is linear in `r`.

# 12. Resultant / Bezout / Casoratian audit

## 12.1 The natural determinant is already `Xi_r`

The pair `(b_r,b_{r-1})` is a homogeneous two-dimensional Apéry state.  The pair `(kappa_r,kappa_{r-1})` obeys the same transfer with forcing `-5g_r`.  Their `2 x 2` determinant is precisely

\[
\frac{\Xi_r}{r^3}.
\]

Thus the first natural state resultant does not produce a new smaller integer: it **is the transverse integer under study**.

For `p>r` with `p|b_r`, the factors `r` and `b_{r-1}` are units, so Smith saturation gives exactly (8.3).  No `p`-content is lost.

## 12.2 Adding the companion solution does not create a unit certificate

The homogeneous Casoratian

\[
r^3(a_rb_{r-1}-a_{r-1}b_r)=6
\]

is a unit at every `p>r`, `p>=5`.  But when `kappa` is inserted, the second determinant is

\[
r^3(\kappa_ra_{r-1}-\kappa_{r-1}a_r)=-5\Psi_r,
\]

not a constant.  The resulting identity

\[
6\kappa_r=a_r\Xi_r+5b_r\Psi_r
\]

is exact but tautological from the divisibility viewpoint: at a common zero of `b_r` and `Xi_r`, it merely says `kappa_r=0 mod p`, already known from (8.3).

## 12.3 Consecutive `Xi` is not a contradiction

A common prime forces

\[
\Xi_r\equiv\Xi_{r+1}\equiv0\pmod p.
\]

The explicit counterexamples prove that no unit-valued universal Bezout certificate between two consecutive `Xi` values can hold at all primes `p>r`.

The identity

\[
\Xi_{r+1}-\Xi_r=-5g_{r+1}b_r
\]

is the exact obstruction: the consecutive-zero condition is another representation of the same transverse event, not an additional independent condition.

## 12.4 Raw height only gives `O(r)`

Trivially,

\[
\operatorname{rad}_{>r}\gcd(b_r,\Xi_r)\le b_r,
\]

so (11.6) yields

\[
\boxed{
\log\operatorname{rad}_{>r}\gcd(b_r,\Xi_r)
\le r\log\alpha+O(\log r).
}
\tag{12.1}
\]

This is linear, not sublinear.

Using `Xi_r` itself gives an even larger linear constant.  Direct polynomial resultants or determinant norms therefore do not meet the desired `exp(o(r))` height scale.

## 12.5 What would actually be new

A proof of

\[
\log\operatorname{rad}_{>r}\gcd(b_r,\Xi_r)=o(r)
\]

must exploit arithmetic distribution of common prime divisors of these two special sequences.  It cannot come merely from:

- the homogeneous Apéry Casoratian;
- the inhomogeneous Picard--Fuchs equation;
- Smith saturation by denominators supported on primes `<=r`;
- the first `2 x 2` determinant;
- a raw norm/resultant whose height is controlled only by `b_r`, `kappa_r`, or `Xi_r`.

The two exact counterexamples rule out any attempted derivation that would force the large-prime resultant to be a unit.

# 14. Corrected conjectures after the counterexamples

The strongest clean pointwise statement `p>r => no common prime` is false.

The scan also disproves every universal threshold `p>Cr` with

\[
C<\frac{2237}{492}=4.546747\ldots.
\]

The statement

\[
p>5r\Longrightarrow p\nmid\gcd(b_r,\Xi_r)
\tag{14.1}
\]

survives the exact scan through `r=5000`, but there is currently no structural proof, and the counterexample ratio `4.5467...` leaves too little margin for me to regard `5` as a natural constant.  I therefore do **not** recommend (14.1) as the main conjecture.

The arithmetic invariant naturally suggested by the problem is

\[
R_r^\perp:=\operatorname{rad}_{>r}\gcd(b_r,\Xi_r).
\]

The corrected pointwise aggregate conjecture is

\[
\boxed{
\log R_r^\perp=o(r).
}
\tag{T_perp}
\]

This tolerates rare genuine large common primes such as `17` and `2237` while still giving the kind of logarithmic saving a norm/product argument would need.

A stronger but still structurally plausible version would be

\[
\log R_r^\perp=O(r^{1-\eta})
\]

for some fixed `eta>0`; I have no proof or evidence sufficient to choose an `eta`.

For the original fixed-`n` problem the directly relevant aggregate statement is instead

\[
\boxed{
\sum_{\substack{p>n^{2/3}\\
 r_p=n\bmod p\\
 p\mid b_{r_p},\ p\mid\Xi_{r_p}}}
\log p=o(n).
}
\tag{T_fixed}
\]

This is weaker than controlling all target primes, because it only counts those at which the first normalized `p^3` defect also vanishes.

# 15. Exact fixed-`n` consumer and its limitation

For the Beukers form at fixed `n`, let

\[
n=pQ+r,
\qquad
p>n^{2/3},
\qquad
0\le r<p.
\]

Then `Q<p`, and Q7617 gives

\[
J_{p,r}\equiv\beta_pb_r+\kappa_r\pmod p.
\]

On a target prime `p|b_r`, the endpoint term disappears:

\[
J_{p,r}\equiv\kappa_r\pmod p.
\]

By (8.3), because automatically `p>r`,

\[
\boxed{
p\mid b_r,\ J_{p,r}\equiv0\pmod p
\iff
p\mid b_r,\ p\mid\Xi_r.
}
\tag{15.1}
\]

Thus any theorem on `R_r^perp` or `(T_fixed)` has a precise consumer: it bounds the primes at which both

1. the original top principal coefficient vanishes modulo `p`, and
2. the first normalized `p^3` transverse defect also vanishes.

That is useful for a **dichotomy** argument if one separately knows how to handle the complementary case

\[
p\mid b_r,
\qquad
J_{p,r}\not\equiv0\pmod p.
\]

But no such second argument is currently supplied by the Picard--Fuchs/Hecke formalism.

Therefore:

\[
\boxed{
\text{Transversality of }(b_r,\Xi_r)
\text{ does not by itself bound the full smooth radical.}
}
\tag{15.2}
\]

In particular, nonvanishing of `J_{p,r}` is **not** evidence that the target prime disappears: the target condition remains `p|b_r`.  The `p^3` defect is not target-selective.

A successful continuation would need a mechanism that converts the generic alternative `J_{p,r} != 0` into a global counting/height saving, with `(T_fixed)` handling only the exceptional zero-defect residue classes.

# 16. Final classification

## Proved exactly

1. `C=1/(F^2 sqrt(Delta))=1/(FH)` has integral coefficients `g_r`.
2. `C` obeys the first-order differential equation (2.1) and exact triangular recurrence (2.5)--(2.6).
3. `kappa_0=0`, `kappa_1=-36` and
   \[
   r^3\kappa_r-\mathscr P(r-1)\kappa_{r-1}+(r-1)^3\kappa_{r-2}=-5g_r.
   \]
4. Its generating equation is
   \[
   \mathcal LK=-5(C-1)-t.
   \]
5. The Green formula is (4.1).
6. The integer transverse determinant is
   \[
   \Xi_r=r^3(\kappa_rb_{r-1}-\kappa_{r-1}b_r)
   =-1-5\sum_{m=1}^rg_mb_{m-1}.
   \]
7. `6 kappa_r=a_r Xi_r+5 b_r Psi_r`.
8. The exact generating function is the Hadamard identity (6.1).
9. For every prime `p>r` with `p|b_r`,
   \[
   p|\Xi_r\iff\kappa_r=0\pmod p.
   \]
10. A common prime also divides `Xi_{r+1}`.
11. The exact scan through `r=5000` has precisely the two `p>r` pairs
    \[
    (13,17),\quad(492,2237).
    \]
12. Both have valuation one in both `b_r` and `Xi_r`.
13. Hence `p>r`, `p>4r`, and `p>(9/2)r` pointwise exclusion theorems are false.

## Not proved

- No universal constant `C` with `p>Cr` excluded.
- In particular `C=5` is only scan-compatible, not a theorem.
- No `exp(o(r))` Bezout/resultant integer has been derived.
- No proof of
  \[
  \log\operatorname{rad}_{>r}\gcd(b_r,\Xi_r)=o(r)
  \]
  is currently obtained.

## Minimal new arithmetic theorem

The clean surviving theorem target is `(T_perp)`, or the fixed-`n` aggregate `(T_fixed)`.  Either would be genuinely arithmetic information about simultaneous prime divisors of the two special Apéry-derived sequences; it is not a formal consequence of the existing Picard--Fuchs, Casoratian, or Hecke identities.
