# Exact one-row Smith transition and the \(m=607,\ p=97\) boundary fixture

## Verdict

There is a clean exact transition formula, stronger than merely recomputing all new maximal minors.

Let

\[
\delta_i:=u_i-u_A,\qquad q_i:=Q_i-Q_A,\qquad
q_0:=Q_k-Q_A,\qquad a:=v-cu_A.
\]

Then

\[
\boxed{d'=\gcd(cd,a).}
\tag{T1}
\]

For \(i\in I\), let

\[
E_i=\det
\begin{pmatrix}
1&1&1\\
v&cu_A&cu_i\\
Q_k&Q_A&Q_i
\end{pmatrix}
=c\delta_iq_0-aq_i.
\tag{T2}
\]

If \(D_3=d\kappa\) is the old third determinantal divisor, then the new one is

\[
\boxed{
D_3'=\gcd\bigl(cD_3,\ E_i:\ i\in I\setminus\{A\}\bigr)
      =\gcd\bigl(cd\kappa,\ E_i:\ i>A\bigr).
}
\tag{T3}
\]

Thus the \(B-A\) anchored determinants \(E_{A+1},\ldots,E_B\), together with the single old number \(cD_3\), suffice. No \(O(|I|^2)\) family of boundary minors is needed.

There is an even smaller formula for the normalized kernel ideal. Choose any Bézout row \((r_i)_{i>A}\) satisfying

\[
\sum_{i>A}r_i(u_i-u_A)=d.
\tag{T4}
\]

Put

\[
\boxed{
L:=\frac{1}{d'}\sum_{i>A}r_iE_i
 =\frac{cd(Q_k-Q_A)-a\sum_{i>A}r_i(Q_i-Q_A)}{d'}.
}
\tag{T5}
\]

Then \(L\in\mathbf Z\), it is an actual kernel value for the enlarged window, and

\[
\boxed{
\kappa'=\gcd(\kappa,L),\qquad
D_3'=d'\gcd(\kappa,L).
}
\tag{T6}
\]

Equivalently,

\[
\boxed{
\gcd\bigl(cd\kappa,E_{A+1},\ldots,E_B\bigr)
=d'\gcd(\kappa,L).
}
\tag{T7}
\]

The prime-local survival criterion is therefore exact:

\[
\boxed{
p\mid\kappa'\quad\Longleftrightarrow\quad
p\mid\kappa\ 	ext{and}\ p\mid L.}
\tag{T8}
\]

In particular, adjoining a row can only remove factors from \(\kappa\):

\[
\boxed{\kappa'\mid\kappa.}
\tag{T9}
\]

For the stated \(q=6,\ m=607,\ H=3,\ p=97\) fixture, the first lower row has \(97\mid L\) on both slopes, so \(97\) survives. At the second lower row it does not survive. Indeed

\[
\kappa_4^{(2)}=3064973520740652258387\equiv37\pmod{97},
\qquad
\kappa_7^{(2)}=89\not\equiv0\pmod{97}.
\]

More locally, the three-row primitive kernel values on \(40,41,42\) and on \(8,9,10\) are respectively \(15\) and \(86\) modulo \(97\). Each is a direct element of the enlarged kernel-value ideal, so each by itself certifies that \(97\) no longer divides the corresponding \(\kappa\).

Hence the fixture **does refute** any universal claim that the old common divisor

\[
\gcd(h_{20},\kappa_4,\kappa_7)=97
\]

must propagate through every bounded downward enlargement of the ordinary full kernel ideals: two rows are already an \(O(1)\) enlargement, and after those two rows

\[
v_{97}\!\left(\gcd(h_{20},\kappa_4^{(2)},\kappa_7^{(2)})\right)=0.
\]

It does **not** prove that no specially selected boundary identity exists. A special sublattice, a coupled slope-\(4\)/slope-\(7\) identity, or a target-specific relation may still have values divisible by \(97\). What fails is the assertion that divisibility by \(97\) remains forced by the entire enlarged Smith kernel-value ideal.

## 1. Old window and its Smith decomposition

Let \(I=[A,B]\cap\mathbf Z\). The raw selector column is \(U_i\), with content

\[
G=\gcd_{i\in I}U_i,
\qquad
u_i:=u_i=U_i/G,
\qquad
\gcd_{i\in I}u_i=1.
\]

Let \(Q_i\in\mathbf Z\). Define the rank-two constraint map

\[
\Phi:\mathbf Z^I\longrightarrow\mathbf Z^2,
\qquad
z\longmapsto
\left(\sum_i z_i,\sum_i u_i z_i\right).
\]

Its kernel is

\[
K_I=\left\{z\in\mathbf Z^I:\sum_i z_i=0,\ \sum_i u_i z_i=0\right\}.
\]

The value map on this kernel is

\[
Q(z)=\sum_i z_iQ_i,
\qquad
Q(K_I)=\kappa\mathbf Z.
\tag{1.1}
\]

Fix the anchor \(A\), and put

\[
\delta_i=u_i-u_A.
\]

Then

\[
d=\gcd_{i\in I}\delta_i
 =\gcd_{i>A}(u_i-u_A).
\tag{1.2}
\]

Let \(M_I\) be the \(3\times |I|\) integer matrix with columns

\[
m_i=(1,u_i,Q_i)^{\mathsf T}.
\]

Let \(D_3\) be the gcd of its \(3\times3\) minors.

### Lemma 1 — \(D_3=d\kappa\)

One has

\[
\boxed{D_3=d\kappa.}
\tag{1.3}
\]

### Proof

The image of the first two rows is

\[
\operatorname{im}\Phi
=\mathbf Z(1,u_A)+\sum_{i>A}\mathbf Z(0,u_i-u_A)
=\mathbf Z(1,u_A)+\mathbf Z(0,d).
\]

Therefore

\[
[\mathbf Z^2:\operatorname{im}\Phi]=d.
\tag{1.4}
\]

Now consider the full map

\[
\Psi:\mathbf Z^I\longrightarrow\mathbf Z^3,
\qquad
z\longmapsto
\left(\sum_i z_i,\sum_i u_i z_i,\sum_i Q_i z_i\right).
\]

Projection onto the first two coordinates maps \(\operatorname{im}\Psi\) onto \(\operatorname{im}\Phi\). Its vertical kernel is exactly

\[
\{(0,0,Q(z)):z\in K_I\}=(0,0,\kappa\mathbf Z).
\]

Consequently

\[
[\mathbf Z^3:\operatorname{im}\Psi]
=[\mathbf Z^2:\operatorname{im}\Phi]\,[\mathbf Z:\kappa\mathbf Z]
=d\kappa.
\tag{1.5}
\]

For a full-row-rank integer matrix, the index of its column lattice is the gcd of its maximal minors. Hence the left side of (1.5) is \(D_3\), proving (1.3). \(\square\)

There is also a useful anchored form. Subtract column \(A\) from every other column. With

\[
q_i:=Q_i-Q_A,
\]

the anchored minors become

\[
\Delta_{Aij}
=\det(m_A,m_i,m_j)
=\delta_iq_j-\delta_jq_i.
\tag{1.6}
\]

Every old three-column minor is an integer combination of these anchored minors, via

\[
\Delta_{ijl}
=\Delta_{Ajl}-\Delta_{Ail}+\Delta_{Aij}.
\tag{1.7}
\]

Thus the anchored \(\Delta_{Aij}\) already generate \(D_3\mathbf Z\).

## 3. Boundary determinants and the new third divisor

For \(i\in I\), define the anchored boundary determinant

\[
E_i
:=\det
\begin{pmatrix}
1&1&1\\
v&cu_A&cu_i\\
Q_k&Q_A&Q_i
\end{pmatrix}.
\tag{3.1}
\]

Subtracting the anchor column gives

\[
\boxed{
E_i=c(u_i-u_A)(Q_k-Q_A)-(v-cu_A)(Q_i-Q_A)
=c\delta_iq_0-aq_i.
}
\tag{3.2}
\]

In particular \(E_A=0\).

Let \(D_3'\) be the gcd of all \(3\times3\) minors of the enlarged matrix with columns

\[
(1,v,Q_k)^{\mathsf T},\qquad
(1,cu_i,Q_i)^{\mathsf T}\quad(i\in I).
\]

### Theorem 2 — anchored-minor transition

One has

\[
\boxed{
D_3'=\gcd\bigl(cD_3,E_i:i>A\bigr)
     =\gcd\bigl(cd\kappa,E_i:i>A\bigr).
}
\tag{3.3}
\]

### Proof

First consider a minor using only old columns. Relative to the old matrix, its selector row has been multiplied by \(c\), while the rows of ones and \(Q\)-values are unchanged. Hence every old-only minor is multiplied by \(c\). Their generated ideal is therefore

\[
cD_3\mathbf Z.
\tag{3.4}
\]

Now let

\[
C_{ij}:=\det
\begin{pmatrix}
1&1&1\\
cu_A&cu_i&cu_j\\
Q_A&Q_i&Q_j
\end{pmatrix}
=c\Delta_{Aij}.
\tag{3.5}
\]

For a boundary minor containing \(k,i,j\), the affine triangle identity gives

\[
\det(k,i,j)=E_j-E_i+C_{ij}.
\tag{3.6}
\]

Thus every boundary minor lies in the ideal generated by the \(E_i\) and the scaled old minors. Conversely, each \(E_i\) is itself a boundary minor, and every scaled old minor is an enlarged old-only minor. Hence the entire maximal-minor ideal is exactly

\[
(cD_3,E_{A+1},\ldots,E_B).
\]

Taking its nonnegative generator gives (3.3). \(\square\)

### Which \(E_i\) suffice?

The exact answer is:

1. \(E_A\) is zero and is unnecessary.
2. The anchored family
   
   \[
   E_{A+1},\ldots,E_B
   \]
   
   suffices together with \(cD_3\).
3. No pairwise family \(\det(k,i,j)\) has to be computed; equation (3.6) reconstructs all of it.
4. More generally, a subset \(S\subseteq I\setminus\{A\}\) suffices whenever the vectors
   
   \[
   (c\delta_i,q_i),\qquad i\in S,
   \]
   
   generate the same old anchored difference lattice as all \(i>A\). Without additional structure on the window, no fixed pair of actual indices is guaranteed to have this property.

For \(\kappa'\), even the full anchored list can be compressed to one Bézout-weighted aggregate, as follows.

## 4. Exact transition for \(\kappa\): one new boundary value

Choose integers \(r_i\), \(i>A\), with

\[
\sum_{i>A}r_i\delta_i=d.
\tag{4.1}
\]

Such a row exists by the definition of \(d\). Put

\[
R:=\sum_{i>A}r_iq_i.
\tag{4.2}
\]

Define

\[
\boxed{
L:=\frac{cdq_0-aR}{d'}.
}
\tag{4.3}
\]

This is an integer because \(d'\mid cd\) and \(d'\mid a\). From (3.2),

\[
\sum_{i>A}r_iE_i
=cq_0\sum_{i>A}r_i\delta_i-a\sum_{i>A}r_iq_i
=cdq_0-aR,
\]

so

\[
\boxed{
L=\frac{1}{d'}\sum_{i>A}r_iE_i.
}
\tag{4.4}
\]

### Theorem 3 — one-row kernel-value transition

The enlarged kernel-value ideal is

\[
\boxed{\kappa'\mathbf Z=\kappa\mathbf Z+L\mathbf Z,}
\tag{4.5}
\]

and therefore

\[
\boxed{\kappa'=\gcd(\kappa,L).}
\tag{4.6}
\]

### Proof

After eliminating the anchor coefficient, an old kernel vector is represented by \(y=(y_i)_{i>A}\) satisfying

\[
\sum_{i>A}\delta_i y_i=0.
\tag{4.7}
\]

Its value is

\[
\sum_{i>A}q_i y_i,
\]

and these values generate \(\kappa\mathbf Z\).

For the enlarged window, let \(t\) be the coefficient of the new row \(k\). After again eliminating the coefficient at \(A\), the selector equation is

\[
at+c\sum_{i>A}\delta_i y_i=0,
\tag{4.8}
\]

and the value is

\[
q_0t+\sum_{i>A}q_i y_i.
\tag{4.9}
\]

Because the image of the row \((\delta_i)\) is \(d\mathbf Z\), write

\[
\sum_{i>A}\delta_i y_i=dn.
\]

Modulo the old kernel, an enlarged kernel vector is therefore classified by an integer pair \((t,n)\) satisfying

\[
at+cdn=0.
\tag{4.10}
\]

The integer kernel of the row \((a,cd)\) is infinite cyclic, generated by

\[
\left(\frac{cd}{d'},-\frac{a}{d'}\right).
\tag{4.11}
\]

Use the chosen Bézout row \(r=(r_i)\) to lift this generator:

\[
t=\frac{cd}{d'},
\qquad
y_i=-\frac{a}{d'}r_i.
\tag{4.12}
\]

Its value under (4.9) is exactly

\[
\frac{cd}{d'}q_0-rac{a}{d'}R=L.
\]

Every enlarged kernel vector differs from an integer multiple of this lift by an embedded old kernel vector. Hence all enlarged values are generated by the old ideal \(\kappa\mathbf Z\) and \(L\), proving (4.5) and (4.6). \(\square\)

### Independence of the Bézout choice

If \(r'\) is another row satisfying (4.1), then \(r'-r\) belongs to the old selector kernel. Therefore

\[
\sum_i(r_i'-r_i)q_i\in\kappa\mathbf Z.
\]

The corresponding \(L'\) differs from \(L\) by a multiple of \((a/d')\kappa\). Thus

\[
\gcd(\kappa,L')=\gcd(\kappa,L).
\]

So the transition is independent of the chosen Bézout certificate, even though the displayed representative \(L\) is not unique.

Combining Theorem 3 with Lemma 1 for the enlarged window gives

\[
D_3'=d'\kappa'=d'\gcd(\kappa,L),
\tag{4.13}
\]

which, together with Theorem 2, proves (T7).

## 5. Prime-local form and monotonicity

For every prime \(p\), Theorem 3 gives

\[
\boxed{
 v_p(\kappa')=\min\{v_p(\kappa),v_p(L)\}.
}
\tag{5.1}
\]

Consequently:

- \(p\mid\kappa'\) iff \(p\mid\kappa\) and \(p\mid L\);
- if \(p\nmid L\), the new row removes \(p\) from the full kernel ideal immediately;
- if \(\kappa'=\kappa\), then in fact \(\kappa\mid L\), not merely \(p\mid L\) for one selected prime;
- \(\kappa'\mid\kappa\).

The last point also has a direct interpretation. Every old kernel vector extends to the new window by assigning coefficient zero to the added row. The old values are therefore a subset of the new values. Hence

\[
\kappa\mathbf Z\subseteq\kappa'\mathbf Z,
\]

which is equivalent to \(\kappa'\mid\kappa\).

This is the precise monotonicity direction: adding rows can make the integer generator smaller by removing prime factors, but cannot introduce a new forced factor into the full value ideal.

## 6. Three-row primitive kernel witness

The final \(p=97\) claim can be certified without computing the gcd of every maximal minor.

### Lemma 4 — primitive three-row certificate

Let three rows have primitive selector coordinates \(x_0,x_1,x_2\in\mathbf Z\) and values \(Y_0,Y_1,Y_2\in\mathbf Z\). Put

\[
g=\gcd(x_1-x_0,x_2-x_0).
\tag{6.1}
\]

Define

\[
z_0=\frac{x_2-x_1}{g},
\qquad
z_1=\frac{x_0-x_2}{g},
\qquad
z_2=\frac{x_1-x_0}{g}.
\tag{6.2}
\]

Then

\[
\sum_{r=0}^2z_r=0,
\qquad
\sum_{r=0}^2z_rx_r=0,
\qquad
\gcd(z_0,z_1,z_2)=1.
\tag{6.3}
\]

Its kernel value is

\[
\boxed{
W_{012}:=z_0Y_0+z_1Y_1+z_2Y_2
=\frac{1}{g}
\det
\begin{pmatrix}
1&1&1\\
x_0&x_1&x_2\\
Y_0&Y_1&Y_2
\end{pmatrix}.
}
\tag{6.4}
\]

If these three rows lie in a larger window with kernel ideal \(\kappa\mathbf Z\), then

\[
\boxed{\kappa\mid W_{012}.}
\tag{6.5}
\]

### Proof

The first two equalities in (6.3) follow by direct cancellation. The gcd of the three numerators in (6.2) is exactly the gcd of all pairwise selector differences, which is \(g\); hence the vector is primitive. Expanding the determinant in (6.4) gives the displayed value. Extending \((z_0,z_1,z_2)\) by zeros on every other row produces a valid kernel vector in the full window, so its value belongs to \(\kappa\mathbf Z\). \(\square\)

Thus a single congruence

\[
W_{012}\not\equiv0\pmod p
\]

proves \(p\nmid\kappa\). This is a direct certificate in the defining ideal, not a statistical or scan-based inference.

## 8. Exact scope of the counterexample

Let the old common divisor be

\[
\gcd(h_{20},\kappa_4^{(0)},\kappa_7^{(0)})=97.
\tag{8.1}
\]

Because both second-stage \(\kappa\)'s are \(97\)-units,

\[
\begin{aligned}
v_{97}\!\left(\gcd(h_{20},\kappa_4^{(2)},\kappa_7^{(2)})\right)
&=\min\left(v_{97}(h_{20}),v_{97}(\kappa_4^{(2)}),v_{97}(\kappa_7^{(2)})\right)\\
&=0.
\end{aligned}
\tag{8.2}
\]

This gives the precise verdict.

### What is refuted

The fixture refutes each of the following universal mechanisms:

1. **Monotone prime inheritance for the full kernel ideal.** It is false that a prime dividing \(\kappa\) must continue to divide \(\kappa\) after every downward row addition.
2. **Bounded-depth inheritance.** It is false that the old factor \(97\) must survive through every \(O(1)\) downward extension. Depth \(2\) is already a counterexample.
3. **Propagation of the old three-way gcd by ordinary window enlargement.** Replacing the two old \(\kappa_s\) by the full kernel ideals of the two-row-enlarged windows removes \(97\) from their common gcd with \(h_{20}\).
4. **A proof strategy using only old divisibility plus formal row inclusion.** Row inclusion acts in the opposite ideal-theoretic direction: it enlarges the set of kernel values and can decrease the gcd generator.

The counterexample is stronger than a numerical fluctuation. The nonzero three-row values are explicit vectors in the defining lattices. They prove that \(97\) is not a forced divisor of the enlarged ideals.

### What is not refuted

The fixture does **not** prove any of the following stronger claims:

1. It does not say that every kernel value in the enlarged window is a \(97\)-unit. It says only that their gcd is a unit at \(97\). Many specially chosen values may still be divisible by \(97\).
2. It does not rule out a special boundary sublattice all of whose values retain \(97\).
3. It does not rule out a coupled slope-\(4\)/slope-\(7\) identity using relations unavailable in the two separate full kernel ideals.
4. It does not rule out an identity using \(h_{20}\), extra Apéry recurrence rows, a reflected endpoint, a divided \(p\)-adic row, or another target-specific normalization.
5. It does not rule out a different \(O(1)\) extension pattern chosen specially for this target. It refutes the universal claim that ordinary downward extension automatically transports the old divisor.
6. It does not contradict the one-row persistence in this same fixture; \(97\) really does survive the first addition and dies only at the second.

So the exact conclusion is:

> **Yes:** the \(m=607,\ p=97\) fixture is a rigorous depth-two counterexample to propagation of the old common divisor through the ordinary full Smith kernel ideals under bounded downward enlargement.
>
> **No:** it is not a no-go theorem for every possible special boundary identity.
