\[

Split the last factor:

\[
\Lambda
=\frac{(1+x)A^2}{xyz}+(1+x)A.

Therefore

\[
\operatorname{supp}\Lambda
=
\bigl(\{-1,0\}\times\{-1,0,1\}^2\bigr)

\bigl(\{1\}\times\{0,1\}^2\bigr),

with cardinality

\[
9+9+4=22.

# 2. The three Vieta involutions really fix `Lambda`

The clean way to verify them is to display `Lambda` as `a/t+b+ct` in each variable.

## 2.1 `x`-Vieta

With `A=(1+y)(1+z)`, exactly

\[
\Lambda
=\frac{A}{yz}
\left(
\frac{A}{x}+(A+yz)+yz\,x
\right).
\]

Hence

\[
\boxed{
\tau_x:\quad
x\longmapsto\frac{A}{yz\,x},
\quad y\mapsto y,
\quad z\mapsto z
}
\]

interchanges the first and last terms in the parentheses and fixes the middle term. Therefore

\[
\Lambda\circ\tau_x=\Lambda.
\]

It is also visibly an involution.

## 2.2 `y`-Vieta

Put

\[
B=1+z,\qquad C=1+z+xz=B+xz.
\]

Then

\[
\Lambda
=\frac{(1+x)B}{xz}
\left(
\frac{B}{y}+(2B+xz)+Cy
\right).
\]

Thus

\[
\boxed{
\tau_y:\quad
 y\longmapsto\frac{B}{Cy}
 =\frac{1+z}{(1+z+xz)y}
}
\]

with `x,z` fixed satisfies

\[
\Lambda\circ\tau_y=\Lambda.
\]

Again it is an involution because `B,C` are independent of `y`.

## 2.3 `z`-Vieta

By the literal `y<->z` symmetry, putting

\[
B'=1+y,\qquad C'=1+y+xy,
\]

one has

\[
\Lambda
=\frac{(1+x)B'}{xy}
\left(
\frac{B'}{z}+(2B'+xy)+C'z
\right),
\]

so

\[
\boxed{
\tau_z:\quad
 z\longmapsto\frac{1+y}{(1+y+xy)z}
}
\]

fixes `Lambda`.

### No dubious multivariate change-of-variables step is needed

For example, regard `Lambda^k` as a Laurent polynomial in `y` over the coefficient field `Q(x,z)`:

\[
\Lambda^k=\sum_m f_m(x,z)y^m.
\]

The identity under `tau_y` gives coefficientwise

\[
f_{-1}=\frac{B}{C}f_1,
\qquad\text{hence}\qquad
C f_{-1}=B f_1.
\]

That is an algebraic equality in `Q[x^{+-1},z^{+-1}]` after clearing the displayed factor. Extracting an `x,z` coefficient gives the finite stencil. Thus one does not need to assert a general Jacobian-free invariance theorem for arbitrary rational torus substitutions.

Since

\[
\Lambda(x,y,z)=\Lambda(x,z,y),

for every `k>=0`, whenever both coordinates occur in the support,

\[
s_{(a,b,c)}(k)=s_{(a,c,b)}(k).

The seven nontrivial pairs are

These seven rows are independent.

## 3.2 Four `x`-Vieta stencils

Write

\[
\Lambda^k=\sum_m g_m(y,z)x^m.

From `tau_x`,

\[

Extracting the coefficient that corresponds to `s_(1,a,b)` gives, for `a,b in {0,1}`,

\boxed{

=\sum_{\epsilon,\eta\in\{0,1\}}
 s_{(-1,a-1+\epsilon,b-1+\eta)}.

\tag{X_{a,b}}

Every one of the four terms on the right is an actual `x=-1` support point.

Explicitly:

The signs are all `+` on the right; this is forced by `A=(1+y)(1+z)`.

## 3.3 Four `y`-Vieta stencils

From

C f_{-1}=B f_1,

\boxed{

\tag{Y_{a,c}}

\boxed{

# 4. Independent rank computation: the 19 rows have rank exactly 14

This does not require evaluating any sequence at finitely many `k` values.

First quotient by the seven independent swap rows. The 22 support coordinates become 15 symmetry orbits. Name them

\[
\begin{array}{lll}
A=s_{(-1,-1,-1)},&
B=s_{(-1,-1,0)}=s_{(-1,0,-1)},&
C=s_{(-1,-1,1)}=s_{(-1,1,-1)},\\
D=s_{(-1,0,0)},&
E=s_{(-1,0,1)}=s_{(-1,1,0)},&
F=s_{(-1,1,1)},\\[2mm]
G=s_{(0,-1,-1)},&
H=s_{(0,-1,0)}=s_{(0,0,-1)},&
I=s_{(0,-1,1)}=s_{(0,1,-1)},\\
J=s_{(0,0,0)},&
K=s_{(0,0,1)}=s_{(0,1,0)},&
L=s_{(0,1,1)},\\[2mm]
M=s_{(1,0,0)},&
N=s_{(1,0,1)}=s_{(1,1,0)},&
O=s_{(1,1,1)}.
\end{array}
\]

Modulo the swaps, the twelve Vieta rows reduce to the following seven distinct equations:

\[
\begin{aligned}
M&=A+2B+D,\\
N&=B+C+D+E,\\
O&=D+2E+F,\\
K&=A+B-C-E,\\
L&=B+C-E-F,\\
I+K+N-G-H&=0,\\
K+L+O-H-I&=0.
\end{aligned}
\tag{4.1}
\]

Why only seven? `X01` and `X10` become the same row after the swap quotient, and each `z`-row becomes the corresponding `y`-row.

The seven rows in (4.1) are independent. One can use successively the pivots

```text
M, N, O, K, L, G, H.
```

Indeed, the first five solve `M,N,O,K,L`; the sixth contains the new variable `G`; the seventh contains `H` after the previous pivots.

Equivalently, the last two simplify further. From the first five,

\[
K+N=M,
\qquad
K+L+O=M.
\]

Hence

\[
H=M-I,
\qquad
G=2I.
\tag{4.2}
\]

Thus the quotient solution space is parametrized by exactly the eight symbols

\[
A,B,C,D,E,F,I,J.
\]

Consequently

\[
\boxed{
\operatorname{rank}_{\mathbf Q}(\text{19 rows})
=7+7=14.
}
\]

This is exact linear algebra on the 22 support labels. It is **not** a sampled rank on `0<=k<=K`.

# 5. Exact coefficient formula underlying the two WZ identities

Expand the last factor in `Lambda^k`:

\[
\begin{aligned}
\Lambda^k
&=x^{-k}y^{-k}z^{-k}
 (1+x)^k(1+y)^k(1+z)^k
 \bigl((1+y)(1+z)+xyz\bigr)^k\\
&=\sum_{j=0}^k
 \binom{k}{j}
 x^{j-k}y^{j-k}z^{j-k}
 (1+x)^k(1+y)^{2k-j}(1+z)^{2k-j}.
\end{aligned}
\]

Therefore, with the convention that an out-of-range binomial coefficient is zero,

\[
\boxed{
 s_{(a,b,c)}(k)
 =\sum_{j=0}^k
 \binom{k}{j}
 \binom{k}{j+a}
 \binom{2k-j}{k+b}
 \binom{2k-j}{k+c}.
}
\tag{5.1}
\]

Put

\[
r=k-j.
\]

Then the same formula is

\[
\boxed{
 s_{(a,b,c)}(k)
 =\sum_{r=0}^k
 \binom{k}{r}
 \binom{k}{r-a}
 \binom{k+r}{r-b}
 \binom{k+r}{r-c}.
}
\tag{5.2}
\]

Let

\[
t_{k,r}:=\binom{k}{r}^2\binom{k+r}{r}^2.
\]

Its exact adjacent ratio is

\[
\boxed{
\frac{t_{k,r+1}}{t_{k,r}}
=\frac{(k-r)^2(k+r+1)^2}{(r+1)^4}.
}
\tag{5.3}
\]

For the eight surviving classes, division by `t_{k,r}` gives the following exact weights:

\[
\begin{array}{c|c}
\text{sequence}&\text{summand weight}\\ \hline
A&\dfrac{k^2(k-r)}{(r+1)^3}\\[2mm]
B&\dfrac{k(k-r)}{(r+1)^2}\\[2mm]
C&\dfrac{kr(k-r)}{(k+1)(r+1)^2}\\[2mm]
D&\dfrac{k-r}{r+1}\\[2mm]
E&\dfrac{r(k-r)}{(k+1)(r+1)}\\[2mm]
F&\dfrac{r^2(k-r)}{(k+1)^2(r+1)}\\[2mm]
I&\dfrac{kr}{(k+1)(r+1)}\\[2mm]
J&1.
\end{array}
\tag{5.4}
\]

These formulas pin down unambiguously which Laurent coefficients the WZ identities concern.

# 6. WZ identity 1: `A = C + D`

The first exact identity is

\[
\boxed{
A-C-D=0,
}
\tag{6.1}
\]

i.e.

\[
\boxed{
 c_k(1,1,1)
 =c_k(1,1,-1)+c_k(1,0,0).
}
\tag{6.2}
\]

All three support labels are exactly

```text
A : u=(-1,-1,-1)
C : u=(-1,-1, 1)
D : u=(-1, 0, 0),
```

so there is no sign-orientation mismatch between (6.1) and `s_u=c_k(-u)`.

For `k>=1`, let the difference summand be

\[
F^{(1)}_{k,r}
=t_{k,r}
\left(
\frac{k^2(k-r)}{(r+1)^3}
-\frac{kr(k-r)}{(k+1)(r+1)^2}
-\frac{k-r}{r+1}
\right).
\]

Define

\[
\boxed{
R_1(k,r)=\frac{r(k-r)}{k(k+1)},
\qquad
G^{(1)}_{k,r}=R_1(k,r)t_{k,r}.
}
\tag{6.3}
\]

Using (5.3), direct simplification gives

\[
\boxed{
F^{(1)}_{k,r}
=G^{(1)}_{k,r+1}-G^{(1)}_{k,r}.
}
\tag{6.4}
\]

Equivalently,

\[
\frac{t_{k,r+1}}{t_{k,r}}R_1(k,r+1)-R_1(k,r)
=
\frac{k^2(k-r)}{(r+1)^3}
-\frac{kr(k-r)}{(k+1)(r+1)^2}
-\frac{k-r}{r+1}.
\]

The endpoint check is exact:

- `r=0`: `R_1(k,0)=0`, so `G^{(1)}_{k,0}=0`;
- after the last summand, `t_{k,k+1}=0` by the binomial convention, while `R_1(k,k+1)=-1/k` is finite for `k>=1`, so `G^{(1)}_{k,k+1}=0`.

Thus summing (6.4) over `0<=r<=k` proves (6.1) for every `k>=1`.

### The `k=0` correction

At `k=0`, the rational expression (6.3) is undefined. But the three coefficients in (6.1) are all nonconstant Laurent coefficients of `Lambda^0=1`, so

\[
A(0)=C(0)=D(0)=0.
\]

Hence (6.1) is true at `k=0` directly. This is the only endpoint repair needed.

# 7. WZ identity 2: `I = B + C`

The second exact identity is

\[
\boxed{
I-B-C=0,
}
\tag{7.1}
\]

i.e.

\[
\boxed{
 c_k(0,1,-1)
 =c_k(1,1,0)+c_k(1,1,-1).
}
\tag{7.2}
\]

The labels are

```text
I : u=( 0,-1, 1)
B : u=(-1,-1, 0)
C : u=(-1,-1, 1).
```

From (5.4), the difference weight is

\[
\begin{aligned}
W_2(k,r)
&=\frac{kr}{(k+1)(r+1)}
 -\frac{k(k-r)}{(r+1)^2}
 -\frac{kr(k-r)}{(k+1)(r+1)^2}\\
&=\frac{k\bigl(2r(r+1)-k(k+1)\bigr)}
 {(k+1)(r+1)^2}.
\end{aligned}
\tag{7.3}
\]

Define

\[
\boxed{
R_2(k,r)=-\frac{r^2}{(k+1)^2},
\qquad
G^{(2)}_{k,r}=R_2(k,r)t_{k,r}.
}
\tag{7.4}
\]

Then (5.3) gives

\[
\begin{aligned}
&\frac{t_{k,r+1}}{t_{k,r}}R_2(k,r+1)-R_2(k,r)\\
&=\frac{r^2(r+1)^2-(k-r)^2(k+r+1)^2}
 {(r+1)^2(k+1)^2}\\
&=\frac{k\bigl(2r(r+1)-k(k+1)\bigr)}
 {(k+1)(r+1)^2}
=W_2(k,r).
\end{aligned}
\]

In the middle equality use

\[
(k-r)(k+r+1)=k(k+1)-r(r+1).
\]

Therefore

\[
F^{(2)}_{k,r}
=G^{(2)}_{k,r+1}-G^{(2)}_{k,r}.
\]

Both endpoints are legal **also at `k=0`**:

- `R_2(k,0)=0`;
- `t_{k,k+1}=0`;
- the denominator `(k+1)^2` never vanishes for `k>=0`.

So (7.1) holds for every `k>=0` with no separate base case required.

# 10. No finite-window inference is used in the upper bound

This point passes, with an important logical distinction.

## Legitimate finite object 1: the 19-row coefficient matrix

The rank-14 calculation concerns a **fixed 19 x 22 matrix of rational coefficients of exact identities**. Its entries do not depend on a cutoff in `k`. Proving that this relation matrix has rank 14 is exact finite-dimensional algebra and yields 14 identities valid for every `k`.

It is not a statement of the form

```text
rank of sampled sequence values for 0<=k<=K is 14.
```

## Legitimate finite object 2: the lower-bound determinant

A nonzero determinant at six particular `k` values is sufficient for a **lower** bound. If six sequences were globally linearly dependent, every evaluation matrix at every finite set of points would be singular. Thus one nonzero exact determinant disproves global dependence.

## What would be invalid

It would be invalid to argue

```text
sampled rank is <=6 for k<=K, therefore global dimension is <=6.
```

No such step is needed here. The upper bound comes only from:

- exact Vieta invariance;
- exact `y<->z` symmetry;
- exact coefficient extraction;
- the two symbolic telescoping identities.

Therefore the all-`k` upper bound contains no finite-window smuggling.
