Write

after \(H=H_n=\lfloor(n-1)/3\rfloor\) and \(M=M_n=\lfloor n/2\rfloor\),

\[
I_1(n)=\gcd_{H\leq J\leq M}\Gamma_{n,J}.
\]

The strongest exact closed form furnished by the cutoff transforms is the
following first-Smith formula:

\[
\boxed{
 I_1(n)=\gcd\bigl(\Gamma_{n,H},D_n^-\bigr),\qquad
 D_n^-:=\gcd_{H<J\leq M}\kappa_{n,J},
}
\tag{V.1}
\]

where

\[
\boxed{
 \kappa_{n,J}
 =\gcd_{J\leq k\leq n}
 \binom nk\binom{n+k}{k}\binom{k}{J}.
}
\tag{V.2}
\]

There is an exact valuation formula and an exact digitwise Lucas criterion
for every prime.  In particular, the entire large-prime part of the
safe-difference denominator is universal:

\[
\boxed{
D_n^-=
 \left(\prod_{M<\ell\leq n+H+1\atop \ell\ {m prime}}\ell\right)
 D_n^{\leq M},
\qquad
\text{every prime divisor of }D_n^{\leq M}\text{ is }\leq M.
}
\tag{V.3}
\]

Every prime in the displayed interval occurs in \(D_n^-\) to exponent
exactly one.  Thus

\[
\log D_n^-\geq
\vartheta(n+H+1)-\vartheta(M)
=\frac56n+o(n).
\tag{V.4}
\]

So the full safe-cutoff denominator is not a subexponential-height object;
it already contains a universal linear-logarithmic prime block.

The boundary polynomial \(T_{n,H}\), and only that boundary polynomial,
selects which of these universal primes survive in \(I_1(n)\).  For the top
shell and \(n\geq10\), one obtains the exact identity

\[
\boxed{
\gcd\left(I_1(n),\prod_{M<p\leq n}p\right)
 =\prod_{M<p\leq n\atop p\mid b_n}p.
}
\tag{V.5}
\]

All top-shell exponents in \(I_1(n)\) are exactly one.

For the natural LCM shell carrier

\[
C_n^{\rm top}
=\frac{\operatorname{lcm}(1,\ldots,n)}
       {\operatorname{lcm}(1,\ldots,M)},
\]
there is a squarefree factorization

\[
C_n^{\rm top}=P_nU_n,\qquad
P_n=\prod_{M<p\leq n}p,\qquad
\operatorname{supp}(U_n)\subseteq\{\ell:\ell\leq\sqrt n\},
\tag{V.6}
\]

and hence, with

\[
R_1(n)=\prod_{M<p\leq n\atop p\mid b_n}p,
\]

\[
\boxed{
\gcd(I_1(n),C_n^{\rm top})
 =R_1(n)\,N_n,\qquad N_n\mid U_n,
}
\tag{V.7}
\]

so that

\[
0\leq
\log\gcd(I_1(n),C_n^{\rm top})-\log R_1(n)
\leq \sqrt n\log n=o(n).
\tag{V.8}
\]

Consequently

\[
\boxed{
\log\gcd(I_1(n),C_n^{\rm top})=o(n)
\quad\Longleftrightarrow\quad
\sum_{M<p\leq n\atop p\mid b_n}\log p=o(n).
}
\tag{V.9}
\]

Thus the natural shell denominator does not produce an independent attack:
the desired overlap estimate is, up to an already \(o(n)\) small-prime
term, exactly the \(q=1\) moving-zero problem one is trying to prove.

There is a literal post-safe denominator whose overlap with \(I_1(n)\) is
\(o(n)\), but it is useless as a common target carrier because it deliberately
loses every top-shell prime.  Finally, an affine countermodel using the
actual cutoff increments shows that the safe-difference Smith data permit
an arbitrary subset of the top-shell primes.  Therefore no argument based
only on the \(\kappa_{n,J}\), their Smith invariants, binomial valuations, and
the safe cutoff differences can prove the useful \(o(n)\) bound.  New input
must control the actual boundary residues \(b_{j_p(n)}\bmod p\), preferably
through a genuinely cross-prime theorem.

There is one finite exceptional correction to the premise in the question.
For \(q=1\), \(b_n\equiv b_1b_r=5b_r\pmod p\).  The cutoff content detects the
low digit \(p\mid b_r\), not the high-digit singular factor \(p\mid b_1\).
Thus \(p=5\) is exceptional.  For example, \(5\mid b_5\), but
\(5\nmid I_1(5)\).  This exception disappears automatically for \(n\geq10\),
because every prime \(p>n/2\) is then \(>5\).  All asymptotic statements
below are therefore unaffected.

## 1. Exact cutoff algebra

Use the repository notation, with \(A_n=b_n\) and \(F_j=f_j\):

\[
L_k(n)=\binom nk\binom{n+k}{k},\qquad
Q_n(t)=\sum_{k=0}^nL_k(n)t^k,
\]

\[
K_{n,J}(c)=[y^J]Q_n(c+y)
 =\sum_{k=J}^nL_k(n)\binom{k}{J}c^{k-J},
\tag{1.1}
\]

\[
g_J(c)=\sum_{i=0}^J\binom Ji(-c)^{J-i}f_i,
\]

and

\[
T_{n,J}(c)=\sum_{s=0}^J K_{n,s}(c)g_s(c),\qquad
\Gamma_{n,J}=\operatorname{cont}_c T_{n,J}(c).
\]

The proved Franel-tail theorem in the repository gives

\[
T_{n,n}(c)=b_n,\qquad \Gamma_{n,J}\mid b_n.
\tag{1.2}
\]

The leading coefficient of \(g_J\) is

\[
[c^J]g_J(c)=(-1)^Jf_0=(-1)^J,
\]

so \(g_J\) is primitive.  Consecutive cutoffs satisfy the exact identity

\[
T_{n,J}-T_{n,J-1}=K_{n,J}g_J.
\tag{1.3}
\]

By Gauss's lemma,

\[
\operatorname{cont}(K_{n,J}g_J)
 =\operatorname{cont}(K_{n,J})\operatorname{cont}(g_J)
 =\operatorname{cont}(K_{n,J})
 =\kappa_{n,J},
\tag{1.4}
\]

which is precisely (V.2).

### Lemma 1.1 (full safe-block intersection)

For arbitrary integers \(0\leq H\leq M\leq n\),

\[
\boxed{
\gcd_{H\leq J\leq M}\Gamma_{n,J}
 =\gcd\bigl(\Gamma_{n,H},
             \kappa_{n,H+1},\ldots,\kappa_{n,M}\bigr).
}
\tag{1.5}
\]

#### Proof

An integer \(d\) divides every coefficient of every \(T_{n,J}\),
\(H\leq J\leq M\), if and only if it divides every coefficient of
\(T_{n,H}\) and every consecutive difference
\(T_{n,J}-T_{n,J-1}\), \(H<J\leq M\).  Apply (1.3) and (1.4).  This is an
equality of ideals, not merely a divisibility.  ∎

### Smith-normal-form interpretation

Let \({\bf t}_J\in\mathbb Z^{n+1}\) be the coefficient vector of
\(T_{n,J}\), padded with zeros, and let

\[
A_n^-=
\begin{pmatrix}
{\bf t}_H\\
{\bf t}_{H+1}\\
\vdots\\
{\bf t}_M
\end{pmatrix}.
\]

If \(\Delta_1(A)\) denotes the first determinantal divisor, i.e. the gcd of
all entries of \(A\), then

\[
I_1(n)=\Delta_1(A_n^-).
\tag{1.6}
\]

Applying the unimodular row operation

\[
({\bf t}_H,{\bf t}_{H+1},\ldots,{\bf t}_M)
\longmapsto
({\bf t}_H,{\bf t}_{H+1}-{\bf t}_H,\ldots,
 {\bf t}_M-{\bf t}_{M-1})
\]

preserves the complete Smith normal form and proves (1.5) at the first
invariant.

Let \(B_n^-\) be the rectangular matrix whose rows are indexed by
\(H<J\leq M\), whose columns are indexed by \(0\leq k\leq n\), and whose
entries are

\[
(B_n^-)_{J,k}=
\begin{cases}
L_k(n)\binom{k}{J},&k\geq J,\\
0,&k<J.
\end{cases}
\]

Then

\[
D_n^-=\Delta_1(B_n^-),
\tag{1.7}
\]

and (V.1) follows.

This also identifies a limitation of the higher-Smith route.  Multiplication
by the primitive polynomial \(g_J\) preserves the content of each individual
row, but it is not in general a unimodular column operation on the whole
matrix.  Therefore Gauss's lemma justifies replacing \(K_{n,J}g_J\) by
\(K_{n,J}\) for \(\Delta_1\), but not for higher determinantal divisors.
The finite `q32_primitive_cutoff_smith.py` computation is useful
reconnaissance, but its normalized higher minors are not an exact alternate
formula for \(I_1(n)\).

### Completely expanded first-divisor formula

For completeness, write

\[
T_{n,H}(c)=\sum_{d=0}^n\tau_{n,H,d}c^d.
\]

The coefficient formulas used in `q32_fixed_q_content.py` are

\[
\tau_{n,H,0}=\sum_{i=0}^H L_i(n)f_i,
\tag{1.8}
\]

and, for \(1\leq d\leq n\),

\[
\tau_{n,H,d}
=\sum_{i=\max(0,H+1-d)}^{\min(H,n-d)}
 (-1)^{H-i}L_{i+d}(n)
 \binom{i+d}{i}\binom{d-1}{H-i}f_i.
\tag{1.9}
\]

Consequently the full safe-cutoff intersection has the explicit scalar
form

\[
\boxed{
I_1(n)=\gcd\left(
 \{\tau_{n,H,d}:0\leq d\leq n\}
 \cup
 \left\{L_k(n)\binom{k}{J}:
        H<J\leq M,\ J\leq k\leq n\right\}
\right).
}
\tag{1.10}
\]

This is the first Smith divisor of the augmented coefficient matrix.  It is
an exact closed form; the remaining difficulty is arithmetic, not matrix
bookkeeping.

## 2. Exact prime-by-prime valuations

Let \(v_\ell\) be the \(\ell\)-adic valuation and \(s_\ell(m)\) the sum of
the base-\(\ell\) digits of \(m\).

### Lemma 2.1 (valuation formula)

For every prime \(\ell\),

\[
\boxed{
 v_\ell(\kappa_{n,J})
 =\min_{J\leq k\leq n}
 \left(
 v_\ell\binom nk+v_\ell\binom{n+k}{k}
 +v_\ell\binom{k}{J}
 \right).
}
\tag{2.1}
\]

Equivalently,

\[
\boxed{
 v_\ell(\kappa_{n,J})
 =\min_{J\leq k\leq n}
 \frac{
 s_\ell(k)+s_\ell(n-k)-s_\ell(n+k)
 +s_\ell(J)+s_\ell(k-J)
 }{\ell-1}.
}
\tag{2.2}
\]

Therefore

\[
v_\ell(D_n^-)
 =\min_{H<J\leq M}v_\ell(\kappa_{n,J}),
\tag{2.3}
\]

and

\[
\boxed{
 v_\ell(I_1(n))
 =\min\left(
   \min_{0\leq d\leq n}v_\ell(\tau_{n,H,d}),
   \min_{H<J\leq M\atop J\leq k\leq n}
    v_\ell\left(L_k(n)\binom{k}{J}\right)
 \right).
}
\tag{2.4}
\]

#### Proof

Equation (2.1) is the valuation of a gcd.  Apply Legendre's digit-sum
formula separately to the three binomial coefficients.  The terms
\(s_\ell(n)\) cancel, as do two of the three occurrences of
\(s_\ell(k)\), leaving (2.2).  Equations (2.3) and (2.4) follow from
(V.1) and (1.10).  ∎

Kummer's theorem gives an equivalent interpretation of (2.1): it is the
minimum, over \(k\), of the total number of base-\(\ell\) carries in

\[
k+(n-k)=n,\qquad n+k,\qquad J+(k-J)=k.
\]

Thus (2.1) is also an exact finite-state digit optimization, with no
unproved cancellation assumption.

### Lemma 2.2 (exact radical criterion)

Write

\[
n=\sum_i n_i\ell^i,\qquad J=\sum_iJ_i\ell^i,
\]

and define the folded digit capacity

\[
\rho_{\ell,i}(n)=\min(n_i,\ell-1-n_i).
\]

Then

\[
\boxed{
\ell\nmid\kappa_{n,J}
\quad\Longleftrightarrow\quad
J_i\leq\rho_{\ell,i}(n)\quad\text{for every }i.
}
\tag{2.5}
\]

Consequently

\[
\boxed{
\ell\mid D_n^-
\quad\Longleftrightarrow\quad
\text{no integer }J\in(H,M]
\text{ lies digitwise below }\rho_\ell(n).
}
\tag{2.6}
\]

#### Proof

A term \(L_k(n)\binom{k}{J}\) is an \(\ell\)-adic unit if and only if all
three binomial factors are units.  By Lucas and Kummer this is equivalent
to

\[
k_i\leq n_i,\qquad k_i\leq\ell-1-n_i,\qquad J_i\leq k_i
\]

for every digit \(i\).  Such a \(k\) exists if and only if

\[
J_i\leq\min(n_i,\ell-1-n_i)
\]

for every \(i\).  Necessity is immediate, and sufficiency follows by taking
\(k=J\).  This proves (2.5); taking the gcd over the safe cutoffs proves
(2.6).  ∎

This digit criterion is the exact radical-level closed form for all primes;
(2.1) or (2.2) gives the exact exponents.

## 3. Complete large-prime part of the safe denominator

The preceding digit criterion becomes especially rigid above \(M\).

### Theorem 3.1 (universal large-prime interval)

Assume the safe increment block is nonempty.  For every prime
\(\ell>M\),

\[
\boxed{
 v_\ell(D_n^-)=
 \begin{cases}
 1,&M<\ell\leq n+H+1,\\
 0,&\ell>n+H+1.
 \end{cases}
}
\tag{3.1}
\]

In particular, (V.3) holds.

#### Proof: the \(q=1\) interval \(M<\ell\leq n\)

Write

\[
n=\ell+r,\qquad 0\leq r<\ell,\qquad
j=\min(r,\ell-1-r).
\]

First,

\[
j\leq H=\left\lfloor\frac{n-1}{3}\right\rfloor.
\tag{3.2}
\]

Indeed, if \(j=r\), then \(2r\leq\ell-1\), so
\(3r\leq\ell+r-1=n-1\).  If \(j=\ell-1-r\), then
\(r\geq(\ell-1)/2\), and

\[
3(\ell-1-r)\leq\ell+r-1
\quad\Longleftrightarrow\quad
r\geq(\ell-1)/2.
\]

Also \(M<\ell\), since \(n<2\ell\).  In base \(\ell\), \(n\) has digits
\((1,r)\), and its folded capacity has digits \((1,j)\).  Every safe cutoff
\(J\in(H,M]\) has digits \((0,J)\) with \(J>j\), so (2.5) gives

\[
\ell\mid\kappa_{n,J}
\qquad(H<J\leq M).
\tag{3.3}
\]

To see that the exponent is exactly one, choose \(k=\ell\).  For odd
\(\ell\), Lucas gives

\[
\binom{\ell+r}{\ell}\equiv1\pmod\ell,\qquad
\binom{2\ell+r}{\ell}\equiv2\pmod\ell,
\]

whereas

\[
v_\ell\binom{\ell}{J}=1
\qquad(0<J<\ell).
\]

Thus one entry in every safe \(K_{n,J}\) has valuation exactly one, proving
\(v_\ell(\kappa_{n,J})=1\) and hence the first case of (3.1).

#### Proof: the \(q=0\) reflected interval \(n<\ell\leq n+H+1\)

Now \(n\) has one base-\(\ell\) digit.  Since

\[
\ell-1-n\leq H,
\]

its folded capacity is \(\ell-1-n\), and every safe \(J>H\) violates
(2.5).  Thus \(\ell\mid\kappa_{n,J}\) for every safe \(J\).

For the exact exponent, take \(k=J\).  The factors
\(inom nJ\) and \(inom JJ\) are \(\ell\)-adic units.  In
\(inom{n+J}{J}\), the numerator interval

\[
n+1,n+2,\ldots,n+J
\]

contains \(\ell\) exactly once, while \(J!\) contains no \(\ell\).  Hence

\[
v_\ell\left(L_J(n)\binom JJ\right)=1.
\]

#### Proof above the interval

If \(\ell>n+H+1\), take \(J=H+1\) and \(k=J\).  Then
\(n+J<\ell\), so all three binomial factors are \(\ell\)-adic units.
Therefore \(\ell\nmid\kappa_{n,H+1}\), and hence
\(\ell\nmid D_n^-\).  This completes the proof.  ∎

By the prime number theorem,

\[
\log\prod_{M<\ell\leq n+H+1}\ell
 =\vartheta(n+H+1)-\vartheta(M)
 =\frac56n+o(n),
\]

which proves (V.4).  This is a theorem-level obstruction to bounding the raw
safe denominator by \(\exp(o(n))\).

## 4. The boundary row selects the moving zeros

The arbitrary-cutoff block theorem already proved in the repository states
that, for \(n=q\ell+r\), \(J=A\ell+B\),

\[
T_{q\ell+r,A\ell+B}(c)
\equiv
b_rT_{q,A-1}(c^\ell)
+K_{q,A}(c^\ell)g_A(c^\ell)T_{r,B}(c)
\pmod\ell.
\tag{4.1}
\]

For every prime in the universal interval of Theorem 3.1, one has
\(H<\ell\), so \(A=0\).  After reflecting the residue and using \(H\geq j\),
(4.1) reduces to

\[
\boxed{
T_{n,H}(c)\equiv b_jQ_q(c^\ell)\pmod\ell,
}
\tag{4.2}
\]

where \(q=1\) on \(M<\ell\leq n\), \(q=0\) on
\(n<\ell\leq n+H+1\), and \(Q_q(0)=1\).  Therefore

\[
\boxed{
\ell\mid\Gamma_{n,H}
\quad\Longleftrightarrow\quad
\ell\mid b_j.
}
\tag{4.3}
\]

For clarity, define

\[
j_\ell(n)=
\begin{cases}
\min(n-\ell,\,2\ell-1-n),&M<\ell\leq n,\\
\ell-1-n,&n<\ell\leq n+H+1.
\end{cases}
\tag{4.4}
\]

Then Theorem 3.1 and (4.3) give the complete large-prime factorization.

### Theorem 4.1 (exact large-prime part of \(I_1(n)\))

Put

\[
R_1^{\rm low}(n)
 =\prod_{M<p\leq n\atop p\mid b_{j_p(n)}}p,
\tag{4.5}
\]

and

\[
R_0^{\rm refl}(n)
 =\prod_{n<p\leq n+H+1\atop p\mid b_{p-1-n}}p.
\tag{4.6}
\]

Then

\[
\boxed{
I_1(n)=R_0^{\rm refl}(n)R_1^{\rm low}(n)I_1^{\leq M}(n),
}
\tag{4.7}
\]

where every prime divisor of \(I_1^{\leq M}(n)\) is at most \(M\).
Every prime in the two displayed radicals occurs in \(I_1(n)\) to exponent
exactly one.

#### Proof

For \(\ell>M\), Theorem 3.1 says that \(D_n^-\) has valuation one exactly
on the universal interval and zero above it.  Equation (4.3) says exactly
when the boundary content contributes that prime.  Taking the minimum of
the two valuations gives (4.7).  ∎

For a top-shell prime \(p\), write \(n=p+r\).  Apéry Lucas and reflection
give

\[
b_n\equiv b_1b_r\equiv5b_r\equiv5b_{j_p(n)}\pmod p.
\tag{4.8}
\]

Thus, for \(p\neq5\),

\[
p\mid b_n
\quad\Longleftrightarrow\quad
p\mid b_{j_p(n)}.
\tag{4.9}
\]

For \(n\geq10\), every \(p>M\) is \(>5\), so (4.5) is exactly

\[
R_1(n)=\prod_{M<p\leq n\atop p\mid b_n}p,
\]

and (V.5) follows.  This also proves rigorously that the full cutoff
intersection makes the top shell squarefree; it does not merely appear
squarefree in finite data.

### The \(p=5\) correction

When \(p=5\), the implication \(5\mid b_n\Rightarrow5\mid b_{j_p(n)}\)
can fail because \(5\mid b_1\).  At \(n=5\), for example,
\(H=1\), \(j=0\), and

\[
T_{5,1}(c)\equiv b_0Q_1(c^5)=1+2c^5\not\equiv0\pmod5,
\]

although \(b_5\equiv b_1b_0\equiv0\pmod5\).  Therefore the exact all-\(n\)
statement uses \(R_1^{\rm low}\), while the stated target radical is exact
without qualification for \(n\geq10\).  One may also adjoin the single
prime \(5\) by hand in a global asymptotic argument.

## 5. The optimal elementary shell cap and the circularity theorem

Let

\[
C_n^{\rm top}
=\frac{\operatorname{lcm}(1,\ldots,n)}
       {\operatorname{lcm}(1,\ldots,M)}.
\]

### Lemma 5.1 (exact factorization of the LCM quotient)

The integer \(C_n^{\rm top}\) is squarefree and

\[
\boxed{
C_n^{\rm top}=P_nU_n,\qquad
P_n=\prod_{M<p\leq n}p,
}
\tag{5.1}
\]

where

\[
U_n=
\prod_{\substack{\ell\leq\sqrt n\ {m prime}\\
                  \exists a\geq2:\ M<\ell^a\leq n}}
\ell.
\tag{5.2}
\]

In particular,

\[
\log U_n\leq\pi(\sqrt n)\log n\leq\sqrt n\log n=o(n).
\tag{5.3}
\]

#### Proof

For a prime \(\ell\), the exponent of \(\ell\) in
\(\operatorname{lcm}(1,\ldots,x)\) is the largest \(a\) with
\(\ell^a\leq x\).  Between \(M=\lfloor n/2\rfloor\) and \(n\), this
exponent can increase by at most one, so the quotient is squarefree.  A
new first power is exactly a prime in \((M,n]\).  If the new power is
\(\ell^a\) with \(a\geq2\), then \(\ell\leq\sqrt n\).  This proves
(5.1) and (5.2); (5.3) is immediate.  ∎

Combining Lemma 5.1 with Theorem 4.1 gives the central exact statement.

### Theorem 5.2 (shell cap equals target radical up to \(o(n)\))

For \(n\geq10\),

\[
\boxed{
\gcd(I_1(n),C_n^{\rm top})
 =R_1(n)\,\gcd(I_1^{\leq M}(n),U_n).
}
\tag{5.4}
\]

Consequently

\[
0\leq
\log\gcd(I_1(n),C_n^{\rm top})-\log R_1(n)
\leq\sqrt n\log n,
\tag{5.5}
\]

and hence (V.9) holds.

#### Proof

The factor \(C_n^{\rm top}\) removes the reflected \(q=0\) interval above
\(n\).  Its large-prime factor \(P_n\) meets \(I_1(n)\) in exactly \(R_1(n)\)
by (V.5).  Its remaining factor \(U_n\) is supported below \(\sqrt n\), hence
inside the lower-prime factor \(I_1^{\leq M}(n)\).  All factors are
squarefree and have disjoint prime support, proving (5.4).  Equation (5.5)
follows from (5.3).  ∎

This is the strongest useful closed form I can derive from the full safe
intersection.  It explains the finite observation that the shell-capped
intersection is often the target radical times a small nuisance, but it
does not promote that observation to a sparsity theorem.  Instead it proves
that the desired estimate is equivalent, modulo an unconditional \(o(n)\)
term, to the target radical estimate itself.

### Why the obvious endpoints do not improve this

The denominator \(D_n^-\) is no help by itself because

\[
I_1(n)\mid D_n^-,
\qquad
\gcd(I_1(n),D_n^-)=I_1(n).
\tag{5.6}
\]

Likewise \(I_1(n)\) divides every safe \(\Gamma_{n,J}\).

There is also a natural first-omitted endpoint

\[
E_n^-=L_{H+1}(n)
=\binom{n}{H+1}\binom{n+H+1}{H+1}.
\tag{5.7}
\]

Every top-shell prime divides \(E_n^-\): for such a prime \(p\), one has
\(j_p(n)\leq H\), \(H+1<p\), and the coefficient with \(k=H+1\) in
\(K_{n,H+1}\) is \(L_{H+1}(n)\), which is zero modulo \(p\).  Therefore

\[
R_1(n)\mid\gcd(I_1(n),E_n^-).
\tag{5.8}
\]

Moreover Stirling's formula, with \(H+1=n/3+O(1)\), gives

\[
\log E_n^-=n\log4+O(\log n).
\tag{5.9}
\]

Thus this endpoint has exactly linear logarithmic height and can
accommodate the whole top shell.  An \(o(n)\) bound for its gcd with
\(I_1(n)\) would again have to prove the target radical bound rather than
follow from endpoint size alone.

More generally, any target-independent endpoint or denominator known to be
divisible by every target prime necessarily satisfies

\[
R_1(n)\mid\gcd(I_1(n),E_n).
\]

Therefore a useful \(o(n)\) overlap theorem for such an \(E_n\) is already a
theorem about \(R_1(n)\).  The exact formulas above show that the
safe-difference denominator offers no additional prime-by-prime
selectivity in the top shell: every shell prime has the same valuation one.

## 6. A literal \(o(n)\) post-safe denominator, and why it is not useful

It is possible to obtain an unconditional \(o(n)\) overlap by allowing the
denominator to cross the first-loss locations.  Define

\[
D_n^+=\gcd_{M<J\leq n}\kappa_{n,J}
\tag{6.1}
\]

and the post-safe cutoff intersection

\[
E_n^+=\gcd_{M\leq J\leq n}\Gamma_{n,J}.
\tag{6.2}
\]

The same telescoping proof as Lemma 1.1 gives

\[
E_n^+=\gcd\bigl(\Gamma_{n,M},D_n^+\bigr).
\tag{6.3}
\]

### Lemma 6.1 (prime-specific loss row)

For every odd prime \(p\) with \(M<p\leq n\),

\[
p\nmid\kappa_{n,p}.
\tag{6.4}
\]

#### Proof

Write \(n=p+r\).  At \(J=k=p\),

\[
L_p(n)\binom pp
=\binom{p+r}{p}\binom{2p+r}{p}
\equiv1\cdot2\not\equiv0\pmod p.
\]

Thus the row content \(\kappa_{n,p}\) is a \(p\)-adic unit.  ∎

Since the index \(J=p\) occurs in the post-safe block, Lemma 6.1 implies

\[
\gcd(D_n^-,D_n^+,P_n)=1,
\qquad
\gcd(E_n^+,P_n)=1.
\tag{6.5}
\]

Consequently

\[
\boxed{
\gcd(C_n^{\rm top},D_n^+)\mid U_n,\qquad
\gcd(C_n^{\rm top},E_n^+)\mid U_n,
}
\tag{6.6}
\]

and both displayed integers have logarithm \(O(\sqrt n\log n)=o(n)\).
For example, the explicit single denominator

\[
\mathcal A_n=\gcd(C_n^{\rm top},E_n^+)
\]

satisfies

\[
\log\gcd(I_1(n),\mathcal A_n)=o(n)
\tag{6.7}
\]

unconditionally.

This is the literal positive answer to an unrestricted reading of
“a suitable endpoint or denominator,” but it cannot advance the GCD
conjecture: every top-shell target prime is absent from \(\mathcal A_n\).
The prime-specific cutoff \(J=p\) is exactly where that prime is lost.  A
common carrier must stay inside the safe block, and there the obstruction
of Sections 3--5 applies.

## 7. Transform-specific countermodel to any safe-Smith-only proof

The obstruction can be stated without heuristics and without changing the
actual kernel rows.

For \(H<J\leq M\), let

\[
\Delta_J(c)=K_{n,J}(c)g_J(c)
\]

be the actual Franel-tail cutoff increment.  Put

\[
P_n=\prod_{M<p\leq n}p.
\]

Theorem 3.1 implies

\[
P_n\mid\operatorname{cont}(\Delta_J)
\qquad(H<J\leq M),
\tag{7.1}
\]

because every top-shell prime divides every safe \(K_{n,J}\)
coefficientwise.

For an arbitrary squarefree divisor \(Q\mid P_n\), define an affine safe
cutoff chain by

\[
\widetilde T_H(c)=Q,
\qquad
\widetilde T_J(c)
 =Q+\sum_{u=H+1}^J\Delta_u(c)
\quad(H<J\leq M).
\tag{7.2}
\]

This chain has exactly the same consecutive differences as the actual
Franel-tail transform:

\[
\widetilde T_J-\widetilde T_{J-1}=K_{n,J}g_J.
\tag{7.3}
\]

Hence it has the same \(K_{n,J}\), the same primitive \(g_J\), the same
\(\kappa_{n,J}\), the same difference matrix \(B_n^-\), and every Smith
invariant of that difference matrix is unchanged.

Let

\[
\widetilde I_1(n)=
\gcd_{H\leq J\leq M}\operatorname{cont}(\widetilde T_J).
\]

For a top-shell prime \(p\), (7.1) gives

\[
\widetilde T_J(c)\equiv Q\pmod p
\qquad(H\leq J\leq M).
\]

Therefore

\[
\boxed{
\gcd(P_n,\widetilde I_1(n))=Q.
}
\tag{7.4}
\]

Thus, while all safe increment data and all their Smith invariants are held
fixed, the shell part of the common content can be an arbitrary subset of
the shell primes.  Taking \(Q=P_n\) gives

\[
\log Q=\vartheta(n)-\vartheta(M)=\frac12n+o(n).
\tag{7.5}
\]

This is not a counterexample to the Apéry sequence.  It is a countermodel
to the information content of the proposed method.  It is specific to the
actual Franel-tail transform because it keeps every actual safe increment
\(K_{n,J}g_J\) unchanged; it varies only the integration constant, namely
the boundary polynomial at \(J=H\).  The actual Apéry transform fixes that
boundary through

\[
T_{n,H}(c)\equiv b_{j_p(n)}Q_1(c^p)\pmod p,
\]

and this is precisely where the moving-zero arithmetic enters.

Consequences:

1. The \(\kappa_{n,J}\), their exact valuations, and the complete Smith
   normal form of the safe difference matrix cannot distinguish good from
   bad top-shell primes.
2. Normalizing each difference row by its content removes a universal shell
   factor, but does not create an independent selector for
   \(p\mid b_{j_p(n)}\).
3. Including the actual boundary row in the full Smith matrix can of course
   recover \(I_1(n)\), but its first invariant is exactly (1.10); bounding it
   then requires the same boundary arithmetic one started with.
4. Any proof of a useful \(o(n)\) common-carrier overlap must add information
   not contained in the safe difference module: a cross-prime relation,
   an auxiliary integer of independently sublinear height that still
   contains every target, or a theorem directly bounding the moving-zero
   sum.

## 8. Final conclusion for the all-index attack

The full safe cutoff intersection is completely understood at the level
that Smith normal form and binomial valuations can provide:

\[
I_1(n)=\Delta_1(A_n^-)
      =\gcd(\Gamma_{n,H},D_n^-),
\]

with exact formulas (1.10), (2.1), (2.2), and (2.5).  Its safe denominator
has a universal squarefree prime block from \(M\) all the way to \(n+H+1\),
and its top-shell part is exactly the target radical selected by the
boundary Apéry zeros.

After the optimal elementary magnitude filter \(C_n^{\rm top}\), the
remaining nuisance has logarithm at most \(O(\sqrt n\log n)\), but the target
radical remains unchanged.  Hence the desired useful estimate

\[
\log\gcd(I_1(n),C_n^{\rm top})=o(n)
\]

is equivalent to the \(q=1\) moving-zero estimate and is not an independent
consequence of the cutoff/SNF machinery.  The post-safe block gives a
sublinear overlap only by deleting the targets.  The affine fixed-increment
countermodel proves that this limitation is structural, not a conclusion
from finite evidence.

Accordingly, the q=1 top-shell route is reduced exactly, but not solved: the
next theorem must constrain the simultaneous congruences

\[
p\mid b_{\min(n-p,\,2p-1-n)}
\qquad(n/2<p\leq n)
\]

across varying primes.  No further manipulation of the safe
\(\kappa_{n,J}\) or their Smith invariants can supply that missing
cross-prime input.
