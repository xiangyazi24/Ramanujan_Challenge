# Verdict

The weighted sum is exactly computable, and it gives the desired nonvanishing.
For every integer `r >= 1`, one has the **integer identities**

\[
\boxed{6K(r,r-1)=b_r+b_{r-1}}
\tag{1}
\]

and

\[
\boxed{
\sum_{k=0}^{r}D(r,k)^2\frac{k}{r+k}
   =\frac{5b_r-b_{r-1}}{12}.}
\tag{2}
\]

Consequently, for a prime `p >= 5` and a lower spectral index

\[
1\le r\le \frac{p-1}{2},
\]

if

\[
b_r\equiv0\pmod p,
\]

then the no-consecutive-zero lemma gives

\[
b_{r-1}\not\equiv0\pmod p,
\]

and therefore

\[
\boxed{
K(r,r-1)\equiv \frac{b_{r-1}}6\not\equiv0\pmod p,}
\tag{3}
\]

while

\[
\boxed{
\sum_{k=0}^{r}D(r,k)^2\frac{k}{r+k}
   \equiv-\frac{b_{r-1}}{12}\not\equiv0\pmod p.}
\tag{4}
\]

Thus the requested seed nonvanishing is proved. The sum is **not** the Hasse
jet `g_r/(2r+1)`; it is a backward contiguous **value** involving
`b_{r-1}`.

# 1. Set up the adjacent rows

Write

\[
d_k:=D(r,k),\qquad e_k:=D(r-1,k),
\qquad 0\le k\le r,
\]

where `e_r=0`. The elementary contiguous ratio is

\[
e_k=\frac{r-k}{r+k}d_k.
\tag{5}
\]

Also, for `1 <= k <= r`,

\[
\frac{d_k}{d_{k-1}}
 =\frac{(r-k+1)(r+k)}{k^2},
\tag{6}
\]

or equivalently

\[
(r-k+1)^2d_{k-1}^2
 =\frac{k^4}{(r+k)^2}d_k^2.
\tag{7}
\]

Set `d_{-1}=0`.

---

# 2. Fraction-free telescoping certificate

The decisive termwise identity is

\[
\boxed{
\begin{aligned}
&r^2\bigl(6d_ke_k-d_k^2-e_k^2\bigr)\\
&\qquad=4\Bigl((r-k)^2d_k^2
 -(r-k+1)^2d_{k-1}^2\Bigr),
\end{aligned}}
\tag{8}
\]

valid for every `0 <= k <= r`, with `d_{-1}=0`.

Indeed, by (5),

\[
6d_ke_k-d_k^2-e_k^2
 =d_k^2\left(
 6\frac{r-k}{r+k}-1-\frac{(r-k)^2}{(r+k)^2}
 \right),
\]

and the parenthesis simplifies to

\[
\frac{4(r^2-2k^2)}{(r+k)^2}.
\tag{9}
\]

On the other hand, (7) gives

\[
\begin{aligned}
&(r-k)^2d_k^2-(r-k+1)^2d_{k-1}^2\\
&\quad=d_k^2\left((r-k)^2-rac{k^4}{(r+k)^2}\right)\\
&\quad=\frac{d_k^2}{(r+k)^2}
 \left((r^2-k^2)^2-k^4\right)\\
&\quad=\frac{r^2(r^2-2k^2)}{(r+k)^2}d_k^2,
\end{aligned}
\]

which proves (8).

Now sum (8) over `k=0,...,r`. The right-hand side telescopes:

\[
\begin{aligned}
&4\sum_{k=0}^{r}
 \Bigl((r-k)^2d_k^2-(r-k+1)^2d_{k-1}^2\Bigr)\\
&\qquad=0.
\end{aligned}
\tag{10}
\]

The left-hand side is

\[
r^2\left(
6\sum_{k=0}^{r}d_ke_k
 -\sum_{k=0}^{r}d_k^2
 -\sum_{k=0}^{r}e_k^2
\right).
\]

Since

\[
\sum_{k=0}^{r}d_ke_k=K(r,r-1),
\quad
\sum_{k=0}^{r}d_k^2=b_r,
\quad
\sum_{k=0}^{r}e_k^2=b_{r-1},
\]

we obtain

\[
r^2\bigl(6K(r,r-1)-b_r-b_{r-1}\bigr)=0.
\]

This is an equality over the integers, and `r >= 1`, so (1) follows:

\[
\boxed{6K(r,r-1)=b_r+b_{r-1}.}
\]

The certificate (8) is fraction-free and therefore can also be reduced
directly modulo `p`.

# 3. Exact evaluation of the weighted sum

Define

\[
W_r:=\sum_{k=0}^{r}d_k^2\frac{k}{r+k}.
\]

Using (5),

\[
\begin{aligned}
K(r,r-1)
 &=\sum_{k=0}^{r}d_k^2\frac{r-k}{r+k}\\
 &=\sum_{k=0}^{r}d_k^2
   \left(1-rac{2k}{r+k}\right)\\
 &=b_r-2W_r.
\end{aligned}
\tag{11}
\]

Substitute (1) into (11):

\[
b_r-2W_r=\frac{b_r+b_{r-1}}6.
\]

Hence

\[
12W_r=5b_r-b_{r-1},
\]

which is exactly (2).

In the lower-root range `2r <= p-1`, all denominators `r+k` occurring in
`W_r` are nonzero modulo `p`. The denominator-free identity (1) itself does
not require this chart restriction.

# 4. Why `b_{r-1}` cannot vanish at a zero `b_r`

The Apéry recurrence is

\[
(n+1)^3b_{n+1}=P(n)b_n-n^3b_{n-1},
\qquad
P(n)=34n^3+51n^2+27n+5.
\tag{12}
\]

Assume

\[
b_r\equiv b_{r-1}\equiv0\pmod p,
\qquad 1\le r\le \frac{p-1}{2}.
\]

If `r=1`, this already contradicts `b_0=1`.

If `r>=2`, apply (12) at `n=r-1`:

\[
r^3b_r=P(r-1)b_{r-1}-(r-1)^3b_{r-2}.
\]

The first two terms vanish, and `r-1` is a unit modulo `p`, so

\[
b_{r-2}\equiv0\pmod p.
\]

Repeating the argument descends to `b_0 congruent 0 mod p`, contradicting
`b_0=1`. Therefore

\[
\boxed{b_r\equiv0\pmod p\Longrightarrow b_{r-1}\not\equiv0\pmod p.}
\tag{13}
\]

Combining (13) with (1), and using that `6` is a unit for `p>=5`, proves
(3). Combining it with (2), and using that `12` is a unit, proves (4).

The recurrence at `s=r` also now gives the explicit next value

\[
\boxed{
K(r,r+1)
 =-\frac{r^3}{(r+1)^3}K(r,r-1)
 =-\frac{r^3}{6(r+1)^3}b_{r-1}
e0\pmod p.}
\tag{14}
\]

Thus both adjacent Racah values are nonzero at an Apéry zero.

# 5. Comparison with the Hasse jet `g_r`

Let

\[
\lambda_n=n(n+1)
\]

and introduce the normalized Newton polynomials

\[
q_k(T):=\frac{1}{(k!)^2}
 \prod_{j=0}^{k-1}(T-\lambda_j).
\tag{15}
\]

Then

\[
q_k(\lambda_r)=D(r,k).
\tag{16}
\]

For `k<=r`, logarithmic differentiation gives

\[
\frac{q_k'(\lambda_r)}{q_k(\lambda_r)}
 =\sum_{j=0}^{k-1}
  \frac{1}{(r-j)(r+j+1)}.
\]

Using

\[
\frac{2r+1}{(r-j)(r+j+1)}
 =\frac1{r-j}+\frac1{r+j+1},
\]

we obtain

\[
(2r+1)\frac{q_k'(\lambda_r)}{q_k(\lambda_r)}
 =H_{r+k}-H_{r-k}.
\tag{17}
\]

With the normalization from the Hasse value/jet package,

\[
A_p(T)=u_p\sum_{k=0}^{M}q_k(T)^2,
\qquad
A_p(\lambda_r)=u_pb_r,
\]

and terms with `k>r` contribute neither to the value nor to the first
derivative at `lambda_r`. Therefore

\[
\boxed{
g_r
 =2\sum_{k=0}^{r}D(r,k)^2
  \bigl(H_{r+k}-H_{r-k}\bigr),}
\tag{18}
\]

because

\[
(2r+1)A_p'(\lambda_r)=u_pg_r.
\]

This harmonic weight is different from `k/(r+k)`. For example, at `r=1`,

\[
W_1=2,
\qquad
g_1=12,
\qquad
\frac{g_1}{2r+1}=4.
\]

Thus

\[
\boxed{W_r\ne \frac{g_r}{2r+1}\quad\text{in general}.}
\]

The exact Hasse interpretation of (1) and (2) is instead

\[
\boxed{
K(r,r-1)
 =\frac{A_p(\lambda_r)+A_p(\lambda_{r-1})}{6u_p},}
\tag{19}
\]

and

\[
\boxed{
W_r
 =\frac{5A_p(\lambda_r)-A_p(\lambda_{r-1})}{12u_p}.}
\tag{20}
\]

At a Hasse zero `A_p(lambda_r)=0`, these become

\[
K(r,r-1)=\frac{A_p(\lambda_{r-1})}{6u_p},
\qquad
W_r=-\frac{A_p(\lambda_{r-1})}{12u_p}.
\]

So the weighted sum is a neighboring Hasse **value**, not a local Hasse jet.

# 6. Exact logical consequence for the all-gap attack

This task closes the seed issue completely:

```text
b_r = 0
    => b_(r-1) != 0
    => K(r,r-1) = b_(r-1)/6 != 0
    => K(r,r+1) != 0.
```

It does **not**, by itself, rule out a later zero of the forward solution
`K(r,s)`. A second-order recurrence can start from a nonzero state and later
have a zero first coordinate. To finish universal Racah nonvanishing on a
second Apéry zero `b_s=0`, one still needs an invariant linking that later
zero to the Apéry orbit—for example a Casoratian, a saturated resultant, or
an exact terminal-ratio exclusion.

But the specific assertion requested in Q2288 is now proved without any
simplicity assumption on the Hasse root:

\[
\boxed{
b_r\equiv0\pmod p
\quad\Longrightarrow\quad
K(r,r-1)\not\equiv0\pmod p.}
\]
