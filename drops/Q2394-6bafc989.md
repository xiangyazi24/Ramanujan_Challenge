# Verdict

**Yes.** There is an exact, canonical way to formalize “the resultant restricted to the Apéry-zero locus.” It is not a new characteristic-zero resultant of three fixed polynomials. It is a **fiberwise marked norm**—equivalently, a zeroth-Fitting determinant—on the finite common-root algebra of the two continuants.

The clean definition is:

\[
\boxed{
\mathfrak M_{p,h}
:=\operatorname{Norm}_{C_{p,h}/\mathbf F_p}
 \bigl(\overline{\mathscr B_p}\bigr)
=\det(m_{\overline{\mathscr B_p}}),
}
\tag{V1}
\]

where

- \(C_{p,h}\) is the finite reduced \(\mathbf F_p\)-algebra supported on the **physical common roots** of \(N_h\) and \(\mathcal R_{h-1}\);
- \(\mathscr B_p(X)\) is the canonical polynomial function satisfying
  \(\mathscr B_p(r)=b_r\) on the physical grid;
- \(m_{\overline{\mathscr B_p}}\) is multiplication by the Apéry mark in \(C_{p,h}\).

Because the common-root algebra is a product of copies of \(\mathbf F_p\),

\[
\boxed{
\mathfrak M_{p,h}
=\prod_{r\in Z_{p,h}^{\mathrm{phys}}} b_r.
}
\tag{V2}
\]

Consequently,

\[
\boxed{
\mathfrak M_{p,h}\ne0
\iff
Z_{p,h}^{\mathrm{phys}}\cap\{r:b_r=0\}=\varnothing.
}
\tag{V3}
\]

This is exactly the refined invariant requested in the question.

For the Q2374 point \((p,h)=(61,3)\), the full prime-field common roots are

\[
r=8,49,
\]

with

\[
(b_8,b_{49})=(12,7)\pmod{61}.
\]

Thus the full-grid marked norm is

\[
12\cdot7=84\equiv23\pmod{61},
\]

while on the physical lower chart only \(r=8\) remains, and

\[
\boxed{\mathfrak M_{61,3}^{\mathrm{low}}=b_8=12\ne0.}
\]

So the prime \(61\), although present in
\(\operatorname{Res}(N_3,\mathcal R_2)\), disappears completely from the **marked** obstruction.

There are two crucial qualifications.

1. The literal unsaturated statement
   \(Z_{p,h}\cap\{b_r=0\}=\varnothing\) is false. For example, at
   \(p=73,h=3,r=70\), one has
   \(N_3=\mathcal R_2=b_{70}=0\), but \(r+h=p\): this is a wrapping boundary point, and it does not encode a physical double zero. The physical selector or the standard denominator saturation is essential.
2. Nonvanishing of \(\mathfrak M_{p,h}\) is **equivalent to the desired theorem**, not presently easier. The construction removes the irrelevant common roots exactly, but proving its norm is a unit still requires genuinely Apéry-specific input.

The potentially useful new fact is that only the residue class of the Hasse/Apéry polynomial in an algebra of dimension at most \(3(h-1)\) matters. Thus the correct uniform target is not the large degree-\(\asymp p\) polynomial itself, but

\[
\boxed{
\mathscr B_p(X)\bmod G_{p,h}(X)
\quad\text{and its norm.}
}
\tag{V4}
\]

That is a genuinely smaller marked object and may be the right place to use the Picard–Fuchs/Hasse, companion, or Frobenius structure.

# 1. First correction: the common-root set must be physical

Write

\[
M=\frac{p-1}{2}.
\]

After reflection folding, the stable physical lower chart for a gap \(h\) is

\[
\Omega_{p,h}
:=\{r\in\mathbf Z:1\le r\le M-h\}
\subset\mathbf F_p.
\tag{1.1}
\]

On this chart,

\[
r,r+1,\ldots,r+h\ne0\pmod p,
\]

and nonmateness is automatic because

\[
1<2r+h+1\le2(M-h)+h+1=p-h<p.
\tag{1.2}
\]

Define the physical selector polynomial

\[
\boxed{
L_{p,h}(X)=\prod_{a=1}^{M-h}(X-a)
\in\mathbf F_p[X],
}
\tag{1.3}
\]

with the convention \(L_{p,h}=1\) if \(M-h<1\). Its zero set is exactly \(\Omega_{p,h}\).

This selector is not cosmetic. Q2355/Q2374 show the following nonphysical common roots at gap three:

- \(p=5,r=3=-2\), where \(r+2=0\);
- \(p=73,r=70=-3\), where \(r+3=p\).

At both points the continuation denominators wrap. At \(p=73,r=70\), one even has \(b_{70}=0\). Therefore the statement

\[
N_h=\mathcal R_{h-1}=b_r=0
\quad\Longrightarrow\quad\bot
\]

is false without the physical/nonwrapping restriction.

A full-grid version can instead use \(X^p-X\) and saturate by

\[
(2X+h+1)\prod_{j=0}^{h}(X+j),
\]

but the lower-chart selector (1.3) is cleaner and already incorporates the inequalities exactly.

# 2. The Apéry mark is polynomial in each finite-field fiber

The assertion that Apéry zeros are “not algebraic roots of a fixed polynomial” needs one qualification:

- there is no single fixed polynomial in \(\mathbf Z[X]\), independent of \(p\), whose roots are the variable indices \(r\) with \(b_r=0\pmod p\);
- but for each fixed \(p\), the Apéry mark is a perfectly canonical polynomial function.

Put

\[
\lambda_a=a(a+1),
\qquad 0\le a\le M.
\]

The \(\lambda_a\) are pairwise distinct in \(\mathbf F_p\), since

\[
\lambda_a-\lambda_b=(a-b)(a+b+1)
\]

and neither factor vanishes for distinct \(a,b\in[0,M]\).

Hence there is a unique polynomial

\[
\boxed{
\mathscr A_p(T)\in\mathbf F_p[T],
\qquad \deg\mathscr A_p\le M,
}
\tag{2.1}
\]

such that

\[
\boxed{
\mathscr A_p(\lambda_a)=b_a
\qquad(0\le a\le M).
}
\tag{2.2}
\]

Explicitly,

\[
\mathscr A_p(T)
=\sum_{a=0}^{M}
 b_a
 \prod_{\substack{0\le j\le M\\j\ne a}}
 \frac{T-\lambda_j}{\lambda_a-\lambda_j}.
\tag{2.3}
\]

This is the centered Apéry/Hasse interpolation polynomial used in the Q2261–Q2264 chain. Define the index-coordinate mark

\[
\boxed{
\mathscr B_p(X):=\mathscr A_p\bigl(X(X+1)\bigr).
}
\tag{2.4}
\]

Then

\[
\mathscr B_p(r)=b_r
\qquad(r\in\Omega_{p,h}).
\tag{2.5}
\]

Equivalently, one may define \(\mathscr B_p\) as the unique degree-\(<p\) interpolation polynomial modulo \(X^p-X\). The centered form (2.4) is smaller and respects reflection.

# 3. The physical common-root polynomial

Let \(N_h(X)\) and \(\mathcal R_{h-1}(X)\) be the fixed-gap Apéry and Racah continuants in the normalization of Q2355–Q2375. Define

\[
\boxed{
G_{p,h}(X)
:=\operatorname{monic}\gcd_{\mathbf F_p[X]}
 \bigl(L_{p,h}(X),N_h(X),\mathcal R_{h-1}(X)\bigr).
}
\tag{3.1}
\]

Because \(G_{p,h}\mid L_{p,h}\), it is squarefree and splits completely over \(\mathbf F_p\). Its roots are exactly

\[
\boxed{
Z_{p,h}^{\mathrm{phys}}
=\{r\in\Omega_{p,h}:N_h(r)=\mathcal R_{h-1}(r)=0\}.
}
\tag{3.2}
\]

Set

\[
\boxed{
C_{p,h}:=\mathbf F_p[X]/(G_{p,h}).
}
\tag{3.3}
\]

Then

\[
C_{p,h}
\cong
\prod_{r\in Z_{p,h}^{\mathrm{phys}}}\mathbf F_p.
\tag{3.4}
\]

The degree bound is small relative to \(p\):

\[
\boxed{
\dim_{\mathbf F_p}C_{p,h}
=\deg G_{p,h}
\le3(h-1),
}
\tag{3.5}
\]

because both continuants have degree \(3(h-1)\) before the harmless even-gap mate factor is removed.

This finite algebra is the exact scheme-theoretic replacement for the informal common-root set.

# 4. The Apéry-restricted resultant

Let \(\overline{\mathscr B_p}\) be the image of \(\mathscr B_p\) in \(C_{p,h}\). Multiplication by this class defines an endomorphism

\[
m_{\overline{\mathscr B_p}}:
C_{p,h}\longrightarrow C_{p,h}.
\]

Define

\[
\boxed{
\mathfrak M_{p,h}
:=\det m_{\overline{\mathscr B_p}}.
}
\tag{4.1}
\]

This has four exactly equivalent descriptions.

## 4.1 Norm

\[
\boxed{
\mathfrak M_{p,h}
=\operatorname{Norm}_{C_{p,h}/\mathbf F_p}
 (\overline{\mathscr B_p}).
}
\tag{4.2}
\]

## 4.2 Ordinary resultant after taking the common-root scheme

Since \(G_{p,h}\) is monic,

\[
\boxed{
\mathfrak M_{p,h}
=\operatorname{Res}_X
 \bigl(G_{p,h}(X),\mathscr B_p(X)\bigr).
}
\tag{4.3}
\]

This is the precise meaning of “resultant restricted to the common-root locus.” One first forms the common-root polynomial \(G_{p,h}\); only then does one take the resultant with the mark.

## 4.3 Product over physical common roots

Using (3.4),

\[
\boxed{
\mathfrak M_{p,h}
=\prod_{r\in Z_{p,h}^{\mathrm{phys}}}\mathscr B_p(r)
=\prod_{r\in Z_{p,h}^{\mathrm{phys}}}b_r.
}
\tag{4.4}
\]

The empty product is \(1\), so if the two continuants have no physical common root then \(\mathfrak M_{p,h}=1\).

## 4.4 Zeroth Fitting determinant

The bad-intersection module is

\[
C_{p,h}/\overline{\mathscr B_p}C_{p,h}
=\operatorname{coker}(m_{\overline{\mathscr B_p}}).
\]

Its zeroth Fitting ideal is generated by

\[
\det(m_{\overline{\mathscr B_p}})=\mathfrak M_{p,h}.
\]

Thus

\[
\boxed{
\mathfrak M_{p,h}\ne0
\iff
\overline{\mathscr B_p}\in C_{p,h}^{\times}
\iff
C_{p,h}/\overline{\mathscr B_p}C_{p,h}=0.
}
\tag{4.5}
\]

Combining (4.4) and (4.5),

\[
\boxed{
\mathfrak M_{p,h}\ne0
\iff
Z_{p,h}^{\mathrm{phys}}\cap\{r:b_r=0\}=\varnothing.
}
\tag{4.6}
\]

This is the exact desired equivalence.

# 5. Why this is exactly the P3.2 bad locus

On the physical chart, the Green formula gives

\[
\frac{N_h(r)}{(r+1)_h^3}
=b_rc_{r+h}-c_rb_{r+h}.
\tag{5.1}
\]

At \(b_r=0\), the companion Casoratian implies \(c_r\ne0\). Therefore

\[
\boxed{
 b_r=0
\quad\Longrightarrow\quad
N_h(r)=0\iff b_{r+h}=0.
}
\tag{5.2}
\]

Likewise Q2337 gives, at \(b_r=0\),

\[
K(r,r+h)
=-\frac{r^3b_{r-1}}{6(r+1)_h^3}
 \mathcal R_{h-1}(r).
\tag{5.3}
\]

The coefficient is a unit on the physical chart: the edge factors are units and \(b_{r-1}\ne0\) by the adjacent Casoratian. Hence

\[
\boxed{
 b_r=0
\quad\Longrightarrow\quad
\mathcal R_{h-1}(r)=0
\iff K(r,r+h)=0.
}
\tag{5.4}
\]

Thus a root of

\[
L_{p,h},\quad \mathscr B_p,\quad N_h,\quad\mathcal R_{h-1}
\]

is exactly a physical nonmate triple

\[
b_r=b_{r+h}=K(r,r+h)=0.
\]

No information is lost in (4.6).

# 6. Direct ideal and Bézout formulations

The complete marked bad-locus ideal is

\[
\boxed{
I_{p,h}^{\mathrm{bad}}
=
\bigl(
L_{p,h}(X),
N_h(X),
\mathcal R_{h-1}(X),
\mathscr B_p(X)
\bigr)
\subset\mathbf F_p[X].
}
\tag{6.1}
\]

Since \(\mathbf F_p[X]\) is a PID,

\[
\boxed{
I_{p,h}^{\mathrm{bad}}=(1)
\iff
\gcd(L_{p,h},N_h,\mathcal R_{h-1},\mathscr B_p)=1.
}
\tag{6.2}
\]

Equivalently, there exist polynomials \(A,B,C,D\in\mathbf F_p[X]\) such that

\[
\boxed{
A L_{p,h}
+B N_h
+C\mathcal R_{h-1}
+D\mathscr B_p
=1.
}
\tag{6.3}
\]

After forming \(G_{p,h}\), this reduces to the minimal marked certificate

\[
\boxed{
U_{p,h}(X)G_{p,h}(X)
+V_{p,h}(X)\mathscr B_p(X)=1.
}
\tag{6.4}
\]

So another exact statement of the missing theorem is

\[
\boxed{
\mathscr B_p(X)^{-1}
\text{ exists modulo }G_{p,h}(X).
}
\tag{6.5}
\]

This formulation is often better than speaking about a “three-polynomial resultant.” There is no single classical scalar resultant for three overdetermined univariate polynomials with all the desired functorial properties. The quotient norm/Fitting determinant is the canonical scalar invariant.

# 7. Spectral-coordinate version

The same construction can be written directly in the \(T=\lambda_r\) coordinate used by the Hasse polynomial.

Define

\[
\boxed{
H_{p,h}(T)
:=\operatorname{Res}_X
 \bigl(G_{p,h}(X),T-X(X+1)\bigr).
}
\tag{7.1}
\]

Because \(G_{p,h}\) is monic and the map

\[
r\longmapsto r(r+1)
\]

is injective on the lower chart,

\[
\boxed{
H_{p,h}(T)
=\prod_{r\in Z_{p,h}^{\mathrm{phys}}}
 (T-\lambda_r).
}
\tag{7.2}
\]

Then

\[
\boxed{
\mathfrak M_{p,h}
=\operatorname{Res}_T
 \bigl(H_{p,h}(T),\mathscr A_p(T)\bigr).
}
\tag{7.3}
\]

Indeed,

\[
\operatorname{Res}_T(H_{p,h},\mathscr A_p)
=\prod_{r\in Z_{p,h}^{\mathrm{phys}}}
 \mathscr A_p(\lambda_r)
=\prod_{r\in Z_{p,h}^{\mathrm{phys}}}b_r.
\]

Formula (7.3) is perhaps the closest literal answer to “the resultant restricted to the Apéry-zero locus.” It is a nested elimination:

1. eliminate the index coordinate on the physical common-root scheme;
2. take the resultant of its spectral support with the Hasse mark.

# 8. Exact gap-three example

At \(p=61,h=3\), Q2355/Q2374 give

\[
\gcd\bigl(X^{61}-X,N_3,\mathcal R_2\bigr)
=(X-8)(X-49).
\tag{8.1}
\]

The two values are

\[
\mathscr B_{61}(8)=b_8=12,
\qquad
\mathscr B_{61}(49)=b_{49}=7.
\tag{8.2}
\]

Therefore the full-grid norm is

\[
\boxed{
\operatorname{Res}
\bigl((X-8)(X-49),\mathscr B_{61}(X)\bigr)
=12\cdot7
=23\pmod{61}.
}
\tag{8.3}
\]

On the lower chart,

\[
M=30,\qquad \Omega_{61,3}=\{1,\ldots,27\},
\]

so only \(r=8\) survives:

\[
G_{61,3}=X-8.
\]

Thus

\[
\boxed{
\mathfrak M_{61,3}=12.
}
\tag{8.4}
\]

In spectral coordinates,

\[
\lambda_8=8\cdot9=11\pmod{61},
\]

so

\[
H_{61,3}(T)=T-11,
\]

and

\[
\operatorname{Res}_T(T-11,\mathscr A_{61}(T))
=\mathscr A_{61}(11)
=b_8
=12.
\tag{8.5}
\]

For comparison, if one retains the upper reflected root \(49\), then

\[
\lambda_{49}=10,
\]

and the spectral common-root polynomial is

\[
(T-11)(T-10),
\]

whose marked resultant is \(12\cdot7=23\).

This is exactly how the refined object removes the unmarked \(61\)-intersection that contaminates the ordinary characteristic-zero resultant.

# 9. Relation to the ordinary fixed-gap resultant

Let

\[
S_h=\operatorname{Res}_{\mathbf Z[X]}
 \bigl(N_h,\mathcal R_{h-1}\bigr).
\]

For fixed \(h\),

\[
p\nmid S_h
\quad\Longrightarrow\quad
G_{p,h}=1
\quad\Longrightarrow\quad
\mathfrak M_{p,h}=1.
\tag{9.1}
\]

If \(p\mid S_h\), then the ordinary resultant says only that the special fiber has at least one common root over \(\overline{\mathbf F}_p\). It does not say:

- that the root lies in \(\mathbf F_p\);
- that it lies on the physical grid;
- that it is nonmate/nonwrapping;
- that the Apéry mark vanishes there.

The refinement performs these filters in the correct order:

\[
\boxed{
\begin{array}{c}
p\mid S_h\\ \downarrow\end{array}
\quad
G_{p,h}=\gcd(L_{p,h},N_h,\mathcal R_{h-1})
\quad
\begin{array}{c}\downarrow\\
\mathfrak M_{p,h}=\operatorname{Res}(G_{p,h},\mathscr B_p).
\end{array}}
\tag{9.2}
\]

Thus the fixed-gap proof architecture becomes:

1. factor \(S_h\);
2. for each exceptional prime \(p\), compute \(G_{p,h}\);
3. prove or calculate \(\mathfrak M_{p,h}\ne0\).

This is exactly what the Q2355/Q2374 finite audit did informally at gap three. The marked norm packages the last step into one scalar.

There is no reason for \(\mathfrak M_{p,h}\) to be an integer factor of \(S_h\). The two invariants live at different stages:

- \(S_h\in\mathbf Z\) detects every special-fiber common root;
- \(\mathfrak M_{p,h}\in\mathbf F_p\) evaluates a new, \(p\)-dependent mark on the physical common-root fiber.

One cannot obtain the marked invariant merely by “dividing extraneous prime factors” from \(S_h\): which roots are marked is only visible after reduction modulo that prime.

# 10. Why this is not yet a uniform proof

The construction is exact, but

\[
\mathfrak M_{p,h}\ne0
\]

is equivalent to the theorem being sought. It names the missing unit; it does not automatically prove it.

The obstruction to a single characteristic-zero resultant is precise. The two continuants are fixed polynomials in \(\mathbf Z[X]\) for each \(h\), but the mark

\[
\mathscr A_p(T)
\]

depends on \(p\), and its degree grows like \(p/2\). There is no fixed polynomial \(B(X)\in\mathbf Z[X]\) with

\[
B(r)=b_r
\quad\text{for all }r.
\]

Therefore an expression such as

\[
\operatorname{Res}_{\mathbf Z[X]}
(N_h,\mathcal R_{h-1},b_X)
\]

is not defined in the ordinary polynomial category.

For fixed integers \(r,h\), one can define the genuine characteristic-zero integer

\[
\boxed{
d_{r,h}:=\gcd\bigl(b_r,N_h(r),\mathcal R_{h-1}(r)\bigr).
}
\tag{10.1}
\]

A bad physical prime must divide \(d_{r,h}\). A uniform arithmetic proof could therefore take the form of a divisibility theorem

\[
\boxed{
 d_{r,h}\mid U_{r,h},
}
\tag{10.2}
\]

where every prime divisor of \(U_{r,h}\) is forced into known boundary, denominator, or mate factors. Equivalently, one wants an integral marked Bézout identity

\[
\boxed{
\alpha_{r,h}N_h(r)
+\beta_{r,h}\mathcal R_{h-1}(r)
+\gamma_{r,h}b_r
=U_{r,h},
}
\tag{10.3}
\]

with \(U_{r,h}\) a known physical unit modulo \(p\).

No such all-gap identity is currently present. The point \((p,r,h)=(61,8,3)\) proves that the first two terms alone cannot yield a product of obvious units: at that point both continuants vanish while every elementary edge factor is a unit. The third, genuinely marked term is essential.

# 11. The promising low-dimensional reduction

Although \(\deg\mathscr A_p\asymp p\), the marked norm depends only on the remainder

\[
\boxed{
E_{p,h}(X)
:=\mathscr B_p(X)\bmod G_{p,h}(X),
\qquad
\deg E_{p,h}<\deg G_{p,h}\le3(h-1).
}
\tag{11.1}
\]

Moreover,

\[
\boxed{
\mathfrak M_{p,h}
=\operatorname{Res}(G_{p,h},E_{p,h}).
}
\tag{11.2}
\]

Thus the actual missing information is a vector of at most \(3(h-1)\) coefficients, not all \((p+1)/2\) Hasse coefficients.

This suggests a sharper next theorem:

> **Marked common-root algebra theorem.** For every physical \((p,h)\), the residue class of the Apéry Hasse polynomial in
> \[
> C_{p,h}=\mathbf F_p[X]/(G_{p,h})
> \]
> is a unit.

A useful proof would derive \(E_{p,h}\) or its inverse from one of the structures that actually knows the Apéry mark:

1. the Picard–Fuchs differential equation for \(\mathscr A_p\), reduced in the finite algebra \(C_{p,h}\);
2. the Hasse-square/Frobenius structure, again reduced modulo \(G_{p,h}\);
3. a companion-Casoratian identity producing
   \(V_{p,h}\mathscr B_p\equiv1\pmod{G_{p,h}}\);
4. a bounded-width marked transfer matrix whose determinant is \(\mathfrak M_{p,h}\).

This is more focused than proving squarefreeness of the whole Hasse polynomial and more refined than the ordinary fixed-gap resultant. It asks only for the mark on the small common-root algebra.

However, without one of these additional identities, the norm construction is an exact reformulation, not a completed proof.

# 12. Exact Sage checker

The following Sage script constructs the physical common-root polynomial, the centered Apéry interpolation polynomial, and both the physical and full-grid marked norms. It verifies the Q2374 fixture.

```sage
from sage.all import *


def apery_row_mod_p(p):
    F = GF(p)
    b = [F(0)] * p
    b[0] = F(1)
    b[1] = F(5)
    for n in range(1, p - 1):
        Pn = F(34*n^3 + 51*n^2 + 27*n + 5)
        b[n + 1] = (
            Pn*b[n] - F(n)^3*b[n - 1]
        ) / F(n + 1)^3
    return b


def centered_apery_polynomial(p, b):
    F = GF(p)
    RT = PolynomialRing(F, 'T')
    T = RT.gen()
    M = (p - 1) // 2

    A = RT(0)
    for a in range(M + 1):
        la = F(a*(a + 1))
        num = RT(1)
        den = F(1)
        for j in range(M + 1):
            if j == a:
                continue
            lj = F(j*(j + 1))
            num *= T - lj
            den *= la - lj
        A += b[a] * num / den

    assert A.degree() <= M
    for a in range(M + 1):
        assert A(F(a*(a + 1))) == b[a]
    return A


def continuants_mod_p(p, h):
    F = GF(p)
    RX = PolynomialRing(F, 'x')
    x = RX.gen()

    P = lambda t: 34*t^3 + 51*t^2 + 27*t + 5
    Q = lambda m: (2*x + 2*m + 1) * (
        3*x^2 + 2*x*m + m^2 + 3*x + m + 1
    )

    # N_0=0, N_1=1.
    Nm1, Ncur = RX(0), RX(1)
    for m in range(1, h):
        Nm1, Ncur = (
            Ncur,
            P(x + m)*Ncur - (x + m)^6*Nm1,
        )
    Nh = Ncur

    # R_0=1, R_1=Q_1.
    if h - 1 == 0:
        Rhm1 = RX(1)
    else:
        Rm2, Rm1 = RX(1), Q(1)
        for m in range(2, h):
            Rm2, Rm1 = (
                Rm1,
                Q(m)*Rm1 - (x + m)^6*Rm2,
            )
        Rhm1 = Rm1

    return RX, x, Nh, Rhm1


def marked_norm(p, h):
    F = GF(p)
    b = apery_row_mod_p(p)
    A = centered_apery_polynomial(p, b)
    RX, x, Nh, Rhm1 = continuants_mod_p(p, h)

    # Substitute T = x(x+1).
    RT = A.parent()
    phi = RT.hom([x*(x + 1)], RX)
    Bx = phi(A)

    M = (p - 1) // 2

    # Physical lower-chart selector.
    L = RX(1)
    for a in range(1, M - h + 1):
        L *= x - F(a)

    Gphys = gcd(gcd(Nh, Rhm1), L).monic()
    Mphys = Gphys.resultant(Bx)

    # Full prime-field common-root scheme, for comparison only.
    Gfull = gcd(gcd(Nh, Rhm1), x^p - x).monic()
    Mfull = Gfull.resultant(Bx)

    # Direct ideal/gcd test.
    bad_gcd = gcd(Gphys, Bx).monic()
    assert (Mphys != 0) == (bad_gcd == 1)

    return {
        'Gphys': Gphys,
        'Mphys': Mphys,
```

# Final assessment

The refined object exists and is mathematically clean:

\[
\boxed{
\mathfrak M_{p,h}
=\operatorname{Res}_X
 \left(
 \gcd(L_{p,h},N_h,\mathcal R_{h-1}),
 \mathscr A_p(X(X+1))
 \right).
}
\]

Equivalently,

\[
\boxed{
\mathfrak M_{p,h}
=\operatorname{Res}_T
 \bigl(H_{p,h}(T),\mathscr A_p(T)\bigr)
=\prod_{r\in Z_{p,h}^{\mathrm{phys}}}b_r.
}
\]

It does exactly what the ordinary resultant cannot: it discards nonphysical and unmarked common roots. At \(p=61,h=3\), it converts the ordinary common-root obstruction into the unit \(12\).

But its nonvanishing is exactly the all-gap theorem in marked-norm form. The additional input still needed is a uniform proof that

\[
\boxed{
\mathscr A_p(X(X+1))
\text{ is a unit in }
\mathbf F_p[X]/(G_{p,h}).
}
\]

The strongest genuinely new reduction is that this unit problem lives in dimension at most \(3(h-1)\). A formula for the Hasse polynomial modulo the physical common-root polynomial—or a companion/Frobenius construction of its inverse there—would be a real closing identity.
