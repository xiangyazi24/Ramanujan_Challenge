# Q856 ALCT hostile repair audit

## 1. Repository status and scope

The requested ALCT documents were not available under the exact paths searched through the repository API (`problems/3.2/research/proofs/Q32_ALCT_FRONTIER.md` was not found in the accessible tree). Therefore this audit separates:

- statements that follow mathematically from the supplied ALCT hypothesis;
- statements that may exist only in Q7765 summaries or roadmap prose and are not independently verified here.

The starting hypothesis is exactly:

For the finite uniform space of odd y in [1,4X^2), with K_X(y) and

  S_X(y) = K_X(y) - E K_X,

assume

  |kappa_j(S_X)| <= (A j)^j (1 + lambda_X)

for 2 <= j <= 2 c0 log X.

Here lambda_X = sum_{X<p<=2X} Z(p)/p.

The first cumulant issue is important: kappa_1(S_X)=0 by centering. The displayed estimate is only a bound on centered cumulants starting at order 2. It gives no independent control of E K_X beyond the definition of centering.

## 2. What the cumulant hypothesis actually gives

Let r <= 2 c0 log X. The moment-cumulant formula gives

  E(S_X^r) = sum over partitions pi of [r] product over B in pi kappa_|B|(S_X).

Because kappa_1(S_X)=0, all singleton blocks vanish. Therefore only partitions with block sizes at least 2 contribute.

For every surviving partition,

  product_B |kappa_|B||
    <= product_B (A |B|)^|B| (1+lambda_X).

If m=|pi| is the number of blocks, then m <= r/2. Hence

  |E(S_X^r)|
    <= (1+lambda_X)^(r/2)
       sum_{pi: no singleton} product_B (A |B|)^|B|.

The partition count is the key combinatorial cost. A crude but valid bound is

  sum_{pi} product_B (A |B|)^|B|
       <= r! (C A)^r

for an absolute C. Consequently

  E|S_X|^r <= (C' A r)^r (1+lambda_X)^(r/2).

This is the correct logarithmic moment consequence.

It is not the stronger claim

  E|S_X|^r <= (C r)^r

uniformly unless lambda_X is separately bounded.

## 3. Logarithmic-order tail bound

For integer r with 2 <= r <= 2 c0 log X and T>0, Markov gives

  P(|S_X| >= T)
     <= E|S_X|^r / T^r
     <= ((C A r sqrt(1+lambda_X))/T)^r.

Choose r = floor(c log X) only when

  floor(c log X) >= 2

and

  floor(c log X) <= 2 c0 log X.

Then

  P(|S_X| >= T)
     <= exp( r log(C A r sqrt(1+lambda_X)/T) ).

Thus logarithmic moments imply exponential-in-log-X tails only above a threshold satisfying

  T >> r sqrt(1+lambda_X).

They do not imply a bound at the natural scale T=lambda_X unless lambda_X dominates log X. This is exactly the small-lambda obstruction.

## 4. Why max K_X <= lambda_X X^{o(1)} does not follow

The proposed maximum-load step confuses a centered fluctuation bound with a deterministic upper bound.

Since

  K_X = E K_X + S_X,

a max estimate needs both:

1. a mean estimate E K_X approximately lambda_X;
2. a uniform tail bound for S_X over all y.

The ALCT cumulant statement alone only gives probabilistic control of S_X. It does not rule out rare y with

  K_X(y) - E K_X

larger than lambda_X X^{o(1)}.

Using a union bound over |Omega_X| approximately X^2 samples requires a tail probability much smaller than X^{-2-o(1)}. The logarithmic-order Markov bound can supply this only if the threshold is above the logarithmic moment scale.

Therefore the implication

  ALCT => max_y K_X(y) <= lambda_X X^{o(1)}

is false without an additional small-deviation argument.

## 5. Fixed HM_7 and fixed HM_k

### HM_7

A fixed seventh moment statement requires control of

  E(K_X)_7

or equivalently the seventh factorial moment of the load variable.

ALCT controls ordinary centered moments of S_X. It does not automatically transfer to factorial moments of K_X because:

  (K_X)_7

is a polynomial in K_X and therefore contains powers of the mean E K_X as well as centered fluctuations.

If the mean estimate and the lower centered moment bounds are supplied, then fixed HM_7 can be derived. ALCT alone does not imply HM_7.

### All fixed HM_k

The same obstruction remains for every fixed k. ALCT provides a family of centered moment estimates up to logarithmic order, but HM_k is a statement about the original nonnegative load K_X and its factorial moments.

The missing bridge is:

  centered cumulants + mean/factorial conversion + arithmetic representation
       => HM_k.

Only the first arrow is provided by ALCT.

Therefore:

  ALCT alone does not imply all fixed HM_k.

## 6. Factorial Markov correction

A common invalid step is to write

  P(K_X >= T) <= E(K_X)_r / (T)_r

without checking T>=r.

The identity

  1_{K>=T} <= (K)_r/(T)_r

requires

  T>=r

because otherwise (T)_r is zero or not the correct monotone denominator.

For logarithmic r=c log X, factorial Markov is only valid for loads above the same logarithmic threshold.

## 7. Correct weakest ALCT-style statement

The strongest unconditional conclusion from the supplied ALCT hypothesis is:

For every integer r satisfying

  2 <= r <= 2 c0 log X,

we have

  E|K_X-EK_X|^r
      <= (C r)^r (1+lambda_X)^(r/2),

and consequently

  P(|K_X-EK_X|>=T)
      <= ((C r sqrt(1+lambda_X))/T)^r

for every T>0.

This is a centered fluctuation theorem. It becomes a max-load theorem only after adding:

- an independent mean bound;
- a threshold regime T above logarithmic fluctuation scale;
- a union bound over the finite sample space.

It becomes HM_k only after adding a factorial-moment conversion theorem.

## 9. Verdict on Q7765 references

Q7765-style summaries claiming that ALCT directly closes AAT, AT'', HM_k, or all-index should be treated as roadmap assertions unless they contain the missing conversion lemmas above. The cumulant estimate itself is not enough.

Final verdict: ALCT is a valid fluctuation input, but not a complete load-control theorem. The weakest correct repair is to insert explicit mean/factorial conversion and threshold hypotheses before claiming HM_k, maximum load, or all-index consequences.
