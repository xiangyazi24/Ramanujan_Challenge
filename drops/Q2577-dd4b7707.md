# P3.2 denominator retention: exact fixed-slice valuation and the remaining horizontal first moment

## Executive verdict

There is an exact and useful denominator-retention theorem, but the currently banked Apéry inputs do **not** prove the required little-oh.

Fix `q>=1` and let

```text
I_q(n) = { primes p : n/(q+1) < p <= n/q }.
```

For all sufficiently large `n` (depending only on `q`), every `p in I_q(n)` has `p>q`, `p^2>n`, and a unique decomposition

```text
n = q p + r,        0 <= r < p.
```

Write

```text
R_m = sum_(k=1)^m b_(m-k)/k.
```

Then there is an explicitly defined `p`-integral regular part `C_(p,q,r)` such that

```text
boxed:  R_n = b_r R_q / p + C_(p,q,r),        C_(p,q,r) in Z_(p).       (A)
```

Equivalently, away from a finite set of primes depending only on `q`,

```text
boxed:  v_p(R_n) = -1  iff  p does not divide b_r,
        v_p(R_n) >= 0  iff  p divides b_r.                           (B)
```

Apéry--Lucas also gives `b_n = b_q b_r (mod p)`. Once the fixed primes dividing `b_q` are excluded, (B) becomes

```text
boxed:  p is lost from den(R_n)  iff  p divides b_n.                  (C)
```

Thus the prime-to-`p` denominators in the convolution do not create a second cancellation event: they are `p`-integral and cannot cancel a nonzero pole residue. They matter only after the pole coefficient has already vanished.

Let

```text
L_n  = lcm(1,...,n),
N_n  = L_n R_n in Z,
Pi_q(n) = product_(p in I_q(n)) p.
```

For all sufficiently large `n`, the fixed-slice identity is exactly

```text
boxed:
 gcd(N_n, Pi_q(n)) = gcd(b_n, Pi_q(n)),                              (D)
```

and hence

```text
boxed:
 sum_(p in I_q(n))
   (v_p(L_n)-v_p(den(R_n))) log p
 = log gcd(b_n,Pi_q(n))
 = sum_(p in I_q(n), p|b_n) log p.                                  (E)
```

This proves the denominator formulation is not merely analogous to the fixed-`q` Apéry-zero problem: on every fixed slice it is literally the same squarefree support.

The strongest unconditional varying-prime estimate supplied by the recurrence is the one-height bound

```text
sum_(p in I_q(n), p|b_n) log p
 <= log b_n
 < n log 34.                                                        (F)
```

Using the standard Apéry asymptotic sharpens the right side to

```text
n log(17+12 sqrt(2)) + O(log n),
```

but it remains linear. Consequently

```text
#{p in I_q(n) : p|b_n}
 <= n log 34 / log(n/(q+1))
 = O_q(n/log n),                                                    (G)
```

not `o_q(n/log n)`.

The exact missing input is a **horizontal, cross-characteristic first-moment cancellation theorem** for the marked Apéry state at the moving times `r_p=n-qp`. One precise form is

```text
sum_(p in I_q(n)) (log p)/p
  sum_(h in F_p^*) exp(2 pi i h b_(n-qp)/p)
   = o_q(n).                                                        (H)
```

The `h=0` contribution is only `O_q(1)`, and additive orthogonality makes (H) exactly equivalent to the desired weighted slice estimate. The point of (H) is not to rename the conclusion; it identifies the missing mechanism: cancellation must occur **as `p` varies**. The Apéry recurrence, Lucas/Dwork congruences, and companion Wronskian are all vertical, one-characteristic identities. Their exact consequences are audited below, and none supplies (H).

So the final status is:

# 1. The completely general `p`-adic decomposition

Before specializing to a fixed quotient, it is useful to record the exact prime-power formula.

For a prime `p`, let

```text
e=e_p(n)=max{a>=0 : p^a<=n}.
```

For `0<=a<=e`, define

```text
S_(p,a)(n)
 = sum_(1<=u<=floor(n/p^a), p does not divide u)
     b_(n-p^a u)/u.
```

Every denominator `1<=k<=n` has a unique representation

```text
k=p^a u,       p does not divide u.
```

Therefore

```text
boxed:
 R_n = sum_(a=0)^e p^(-a) S_(p,a)(n).                              (1.1)
```

Each `S_(p,a)(n)` lies in `Z_(p)`. Multiplying by `p^e` gives the exact valuation formula

```text
boxed:
 v_p(R_n)
 = -e + v_p( sum_(a=0)^e p^(e-a) S_(p,a)(n) ).                    (1.2)
```

Thus no contribution from a denominator divisible by a higher power of `p` is being suppressed. Formula (1.2) is valid for every `p` and `n`.

For a fixed quotient slice and large `n`, it simplifies drastically. If

```text
p in I_q(n),        n=qp+r,
```

and `n>(q+1)^2`, then

```text
p>n/(q+1)>q,
qquad p^2>n.
```

Hence `e=1`, and the only `p`-divisible denominators are exactly

```text
p,2p,...,qp.
```

Formula (1.1) becomes

```text
R_n
 = U_(p,n)
   + (1/p) sum_(j=1)^q b_((q-j)p+r)/j,                            (1.3)
```

where the entire prime-to-`p` part is

```text
U_(p,n)
 = sum_(1<=k<=n, p does not divide k) b_(n-k)/k
 in Z_(p).                                                        (1.4)
```

This is already the exact answer at valuation level:

```text
boxed:
 v_p(R_n)
 = -1 + v_p(
       sum_(j=1)^q b_((q-j)p+r)/j + p U_(p,n)
     ).                                                           (1.5)
```

## 1.1 Every prime-to-`p` denominator, written in blocks

To make (1.4) completely explicit, write every nonmultiple of `p` as `jp+a`. Since `n=qp+r`,

```text
boxed:
U_(p,n)
 = sum_(j=0)^(q-1) sum_(a=1)^(p-1)
       b_((q-j)p+r-a)/(jp+a)
   + sum_(a=1)^r b_(r-a)/(qp+a).                                  (1.6)
```

Every displayed denominator is a `p`-adic unit. The first double sum consists of `q` complete residue blocks; the last sum is the final partial block. Together with the `q` terms `k=jp` in (1.3), this accounts for every `1<=k<=n` exactly once.

# 2. Extraction of the pole coefficient by Apéry--Lucas

The Apéry numbers have the Lucas property

```text
b_(ap+t) = b_a b_t  (mod p),       0<=t<p.                         (2.1)
```

Here `p>q`, so it applies to every high digit `q-j`. Define the integral Lucas quotients

```text
epsilon_j(p,r)
 = ( b_((q-j)p+r) - b_(q-j)b_r )/p,
                 1<=j<=q.                                         (2.2)
```

(The last one is identically zero because `q-j=0`.) Then

```text
sum_(j=1)^q b_((q-j)p+r)/j
 = b_r sum_(j=1)^q b_(q-j)/j
   + p sum_(j=1)^q epsilon_j(p,r)/j.                               (2.3)
```

The fixed rational number in the first term is exactly `R_q`:

```text
R_q = sum_(j=1)^q b_(q-j)/j.                                      (2.4)
```

Substituting (2.3) into (1.3) proves the central identity

```text
boxed:
R_(qp+r)
 = b_r R_q/p + C_(p,q,r),                                         (2.5)
```

where

```text
C_(p,q,r)
 = U_(p,qp+r)
   + sum_(j=1)^q epsilon_j(p,r)/j
 in Z_(p).                                                        (2.6)
```

Consequently

```text
boxed:
v_p(R_(qp+r))
 = -1 + v_p( b_r R_q + p C_(p,q,r) ).                             (2.7)
```

This is the requested exact `p`-adic formula. It contains all `k=jp` terms through the Lucas quotients and all prime-to-`p` denominators through `U_(p,n)`.

## 2.1 Form directly in terms of `b_n`

Define also

```text
eta_(p,q,r) = (b_(qp+r)-b_qb_r)/p in Z.                            (2.8)
```

If `p` does not divide the fixed integer `b_q`, then

```text
b_r = (b_n-p eta_(p,q,r))/b_q.
```

Thus (2.5) may be rewritten as

```text
boxed:
R_n = (R_q/b_q) b_n/p + C^*_(p,q,r),                              (2.9)
```

with

```text
C^*_(p,q,r)
 = C_(p,q,r) - (R_q/b_q) eta_(p,q,r)
 in Z_(p).                                                        (2.10)
```

Equivalently,

```text
boxed:
v_p(R_n)
 = -1 + v_p( (R_q/b_q)b_n + p C^*_(p,q,r) ).                      (2.11)
```

Formula (2.11) makes the denominator-loss event at the original index `n` transparent.

# 3. What the regular part looks like modulo `p`

For denominator support, it is enough that `C_(p,q,r)` is integral. For completeness, the prime-to-`p` part itself has an exact first-digit reduction.

Put

```text
Sigma_m = sum_(i=0)^m b_i,
```

and define, in `F_p`,

```text
T_(p,r)
 = sum_(u=0)^(p-r-2) b_u/(u+r+1),                                (3.1)
```

with an empty sum when `r=p-1`. Then the block decomposition (1.6), Lucas, and the reflection congruence

```text
b_(p-1-u)=b_u  (mod p)                                           (3.2)
```

give

```text
boxed:
U_(p,qp+r)
 = Sigma_q R_r + Sigma_(q-1) T_(p,r)  (mod p).                    (3.3)
```

Indeed, in a complete block with high digit `h`:

- for `a<=r`, the index is `hp+(r-a)`, contributing `b_h R_r`;
- for `a>r`, one borrows a digit and gets `(h-1)p+(p+r-a)`, contributing `b_(h-1)T_(p,r)`;
- the final partial block contributes the extra `b_0R_r`.

Summing `h=1,...,q` proves (3.3).

If `p|b_r`, write `t_r=b_r/p`. Then (2.5), (2.6), and (3.3) give the exact first integral residue

```text
boxed:
R_n
 = t_r R_q
   + sum_(j=1)^q epsilon_j(p,r)/j
   + Sigma_q R_r
   + Sigma_(q-1) T_(p,r)            (mod p).                      (3.4)
```

Thus higher Dwork congruences can, in principle, compute or constrain the Lucas quotients in (3.4). But this controls whether `v_p(R_n)` is `0`, `1`, or larger **after** the factor `p` has already disappeared from the reduced denominator. It cannot alter the support criterion established next.

# 4. Exact denominator-support theorem on a fixed slice

Let

```text
D_q = lcm(1,...,q),
H_q = D_q R_q.
```

Since every `b_m` is positive,

```text
H_q in Z_(>0).                                                     (4.1)
```

Let `E_q` be the finite set of primes dividing

```text
b_q H_q,
```

together with the primes at most `q`. Choose `n` so large that

```text
n>(q+1)^2,
qquad n/(q+1)>max E_q.                                             (4.2)
```

For every `p in I_q(n)`, the quantities `b_q`, `D_q`, and `H_q` are then `p`-adic units. Since `D_q` is a unit, `R_q` is a unit as well.

From (2.7),

```text
p does not divide b_r
 => b_rR_q is a unit
 => v_p(R_n)=-1.                                                   (4.3)
```

Conversely,

```text
p divides b_r
 => b_rR_q+pC_(p,q,r) is divisible by p
 => v_p(R_n)>=0.                                                   (4.4)
```

Therefore

```text
boxed:
v_p(R_n)=-1  iff p does not divide b_r,
v_p(R_n)>=0  iff p divides b_r.                                   (4.5)
```

Apéry--Lucas at the full index says

```text
b_n=b_qb_r  (mod p).                                              (4.6)
```

Because `b_q` is a unit, (4.5) is equivalent to

```text
boxed:
v_p(R_n)=-1  iff p does not divide b_n,
v_p(R_n)>=0  iff p divides b_n.                                   (4.7)
```

No assertion about `v_p(R_n)` beyond nonnegativity is needed for denominator retention.

## 4.1 Exact gcd identity

Let

```text
L_n=lcm(1,...,n),
N_n=L_nR_n.
```

Because every summand of `R_n` has denominator dividing `L_n`, one has `N_n in Z`. For `p in I_q(n)`, condition (4.2) gives `p^2>n`, so

```text
v_p(L_n)=1.                                                       (4.8)
```

Hence

```text
p|N_n
 iff 1+v_p(R_n)>=1
 iff v_p(R_n)>=0
 iff p|b_n.                                                       (4.9)
```

Since `Pi_q(n)` is squarefree, (4.9) proves

```text
boxed:
gcd(N_n,Pi_q(n))=gcd(b_n,Pi_q(n)).                               (4.10)
```

If `d_n=den(R_n)`, then `v_p(d_n)=max(0,-v_p(R_n))`. Equations (4.7) and (4.8) therefore give

```text
boxed:
sum_(p in I_q(n)) (v_p(L_n)-v_p(d_n))log p
 = log gcd(b_n,Pi_q(n))
 = sum_(p in I_q(n),p|b_n)log p.                                 (4.11)
```

This is the exact fixed-slice denominator-retention identity.

# 5. The unconditional varying-prime inequality that does follow

Let

```text
P_q(n)={p in I_q(n):p|b_n}.
```

The primes are distinct and all divide the single integer `b_n`, so

```text
product_(p in P_q(n))p | b_n.                                    (5.1)
```

Thus

```text
boxed:
sum_(p in P_q(n))log p <= log b_n.                               (5.2)
```

The Apéry recurrence is

```text
(m+1)^3 b_(m+1)
 =(34m^3+51m^2+27m+5)b_m-m^3b_(m-1).                             (5.3)
```

All terms are positive, and

```text
34m^3+51m^2+27m+5 < 34(m+1)^3.
```

Therefore, for `m>=1`,

```text
b_(m+1)<34b_m.
```

Since `b_1=5`,

```text
b_n<34^n.                                                        (5.4)
```

Combining (5.2) and (5.4) yields the fully proved cross-prime bound

```text
boxed:
sum_(p in I_q(n),p|b_n)log p < nlog34.                           (5.5)
```

Because `p>n/(q+1)` on the slice,

```text
boxed:
#P_q(n)
 <= nlog34/log(n/(q+1))
 = O_q(n/log n).                                                  (5.6)
```

The standard Poincaré asymptotic for the recurrence is

```text
b_n=C(17+12sqrt(2))^n n^(-3/2)(1+O(1/n)),                        (5.7)
```

so (5.5) can be sharpened to

```text
sum_(p in P_q(n))log p
 <= nlog(17+12sqrt(2))-(3/2)log n+O(1).                           (5.8)
```

This still has a positive linear main term.

## 5.1 Why the height estimate is genuinely saturated

By the prime number theorem, the total logarithmic mass of the whole slice is

```text
sum_(p in I_q(n))log p
 ~ n/q-n/(q+1)
 = n/(q(q+1)).                                                    (5.9)
```

For every fixed `q`,

```text
1/(q(q+1)) <= 1/2 < log(17+12sqrt(2)).                            (5.10)
```

Thus even the hostile scenario in which **every prime in the slice divides `b_n`** is compatible with the sharp exponential height of `b_n`. No refinement of the constant in a one-integer height estimate can produce the desired little-oh.

The numerator carrier `N_n=L_nR_n` is no better: (4.10) gives the right support, but `log|N_n|=O(n)` as well. Positivity of `R_n` prevents archimedean cancellation in its size; it does not force `gcd(N_n,L_n)` to be subexponential.

# 6. Audit of the Apéry recurrence

The recurrence supplies two exact types of information.

First, all target primes divide the same integer `b_n`, which is exactly the one-height inequality (5.2). This is the only direct cross-prime aggregation coming from the recurrence.

Second, modulo an individual prime it propagates a two-dimensional state. Put

```text
c_m=(m!)^3b_m.
```

Then

```text
c_(m+1)=P(m)c_m-m^6c_(m-1),
P(m)=34m^3+51m^2+27m+5.                                          (6.1)
```

For `m<p`, the transfer matrix

```text
M_m = [[P(m),-m^6],[1,0]]                                        (6.2)
```

has determinant `m^6`, a unit modulo `p`. Since `r<p`, the condition `p|b_r` is exactly the condition that the moving projective orbit hits the coordinate line `c_r=0` at time `r=n-qp`.

Invertibility forbids a zero state and yields no-consecutive-zero statements, but it does not bound, for one fixed `n`, how often the varying systems

```text
(F_p, M_1,...,M_(r_p-1)),       r_p=n-qp,
```

hit that line as `p` varies. This is a horizontal orbit problem, not a consequence of the local recurrence identity.

A single zero also does not create growing divisibility in a common carrier. Any method that requires two or more nonmate returns is silent on a prime with one reflection orbit of zeros. This is exactly the singleton obstruction recorded in the connected gcd-tail audit: aligned pairwise gcds compute a higher factorial moment and miss fibers of multiplicity one.

So the recurrence proves (5.5), local simplicity, and transfer invertibility. It does not prove an `o(n)` weighted first moment.

# 7. Audit of Lucas and Dwork congruences

## 7.1 What Lucas proves exactly

Lucas proves the decisive support identities

```text
b_((q-j)p+r)=b_(q-j)b_r  (mod p),
b_n=b_qb_r              (mod p).                                (7.1)
```

These identities are precisely what produce the pole coefficient `b_rR_q` in (2.5). Thus Lucas identifies the cancellation event perfectly. It does not count the primes for which the moving low digit is a zero.

## 7.2 Why higher precision does not restore a lost denominator prime

Dwork congruences can refine

```text
b_((q-j)p+r)=b_(q-j)b_r+p epsilon_j(p,r).                         (7.2)
```

Those corrections enter the integral regular part in (2.6) and the residue (3.4). But on this slice `v_p(L_n)=1`. Once `b_rR_q=0 (mod p)`, equation (2.5) shows `R_n in Z_p`; the prime has already disappeared from the denominator. Knowing (7.2) modulo `p^2`, `p^3`, or higher can decide only how positive `v_p(R_n)` is.

Therefore a higher Dwork congruence helps the denominator theorem only if it implies a new restriction on the **occurrence** of

```text
b_(n-qp)=0  (mod p)                                               (7.3)
```

as `p` varies. The connected Dwork proofs are vertical congruences within one characteristic and provide no such horizontal first moment.

## 7.3 Hostile digit-block model for Lucas plus endpoint supercongruences

There is an exact formal obstruction to deriving horizontal sparsity from the usual digit laws alone.

Fix a prime `p`. Choose arbitrary coefficients

```text
c_0,...,c_(p-1) in {0,1}
```

with

```text
c_0=c_q=c_(p-1)=1,
```

and, if desired, impose reflection

```text
c_(p-1-r)=c_r.
```

Define

```text
C_p(X)=sum_(r=0)^(p-1)c_rX^r,
F_p(X)=product_(nu>=0) C_p(X^(p^nu)).                             (7.4)
```

If `u_m=[X^m]F_p(X)`, then the base-`p` digits `m_i` give the exact identity

```text
u_m=product_i c_(m_i).                                            (7.5)
```

Hence

```text
u_(ap+r)=u_a u_r                                                   (7.6)
```

exactly, while the interior zero set `{r:u_r=0}` is arbitrary (subject to the optional reflection).

Moreover

```text
mp^k-1=(m-1)p^k+(p^k-1),
```

so its final `k` digits are all `p-1`. Since `c_(p-1)=1`,

```text
u_(mp^k-1)=u_(m-1)=u_(mp^(k-1)-1)                                (7.7)
```

as an exact integer equality, hence in particular modulo `p^(3k)`.

Thus the Lucas law, reflection, and the cited endpoint supercongruence can coexist with an arbitrary prescribed interior singleton zero orbit. This model is deliberately characteristic-by-characteristic and is not claimed to satisfy the full Apéry recurrence. Its rigorous conclusion is the needed one: **any proof using only those digit and endpoint congruence schemas, independently for each `p`, cannot supply the cross-prime first moment.** An additional Apéry-specific horizontal input is indispensable.

# 8. Audit of the companion Wronskian

Let `a_m` be the standard companion solution, normalized by

```text
a_0=0,
a_1=6.
```

The exact weighted Casoratian is

```text
boxed:
m^3(a_m b_(m-1)-a_(m-1)b_m)=6.                                 (8.1)
```

Let `p>=5`, `1<=r<p`, and suppose `p|b_r`. Since all denominators of `a_0,...,a_r` have prime factors at most `r`, these values are `p`-integral. Reducing (8.1) gives

```text
boxed:
r^3 a_r b_(r-1)=6  (mod p).                                     (8.2)
```

Therefore

```text
p does not divide a_r,
p does not divide b_(r-1),
v_p(a_r/b_r)=-v_p(b_r).                                          (8.3)
```

This is a strong local statement, but it points in the wrong direction for denominator compression: the companion numerator cancels **none** of the target prime in `a_r/b_r`.

The vector Lucas law likewise has the form

```text
(p^3a_(qp+r), b_(qp+r))
 = b_r(a_q,b_q)  (mod p).                                        (8.4)
```

At a target zero, both coordinates in (8.4) vanish because of the same scalar `b_r`; it is not an independent second equation.

Multiplying the local denominators `den(a_r/b_r)` over all possible moving residues does not help. Their aggregate archimedean height is at least on the scale obtained by summing `log b_r` over `r<=n/(q+1)`, which is quadratic in `n`, whereas the target bound is linear. The Wronskian supplies local units but no common sublinear-height carrier and no cancellation across different primes.

# 9. Hostile singleton audit of all local multizero packages

The fixed-`q` problem asks about one marked reflection orbit in each characteristic. To see why local collision estimates cannot control it, consider the following abstract zero-set model.

For every prime `p in I_q(n)`, let

```text
r_p=n-qp,
Z_p={r_p,p-1-r_p},                                                (9.1)
```

with the set collapsing to one point at the midpoint. Then:

- `Z_p` is reflection invariant;
- it has exactly one reflection orbit;
- it has no consecutive pair;
- its size is at most two;
- every estimate that only counts two or more **nonmate** zero orbits is vacuous;
- nevertheless `r_p in Z_p` for every prime in the slice.

Thus the marked count is the full slice size

```text
#I_q(n) ~ n/(q(q+1)log n),                                       (9.2)
```

# 10. The precise minimal horizontal inequality

The exact weighted slice defect is


By Lucas, for all sufficiently large `n`, this is also


Additive character orthogonality gives, for every integer `x`,

```text

```

Substitution into (10.2) yields the exact identity


where

```text
H_q(n)
 = sum_(p in I_q(n)) (log p)/p
     sum_(h in F_p^*) e_p(h b_(n-qp)).                            (10.5)
```

Chebyshev's bound for `theta(x)` gives

```text
sum_(p in I_q(n)) (log p)/p = O_q(1).                             (10.6)
```
