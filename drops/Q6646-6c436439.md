# Verdict

The vector-7 transfer works, and it is stronger than the question suggests.

The paper's restart proof is not special to the particular Apery solution b. It is special to a zero fiber of a nonzero homogeneous solution of the second-order recurrence. Every fixed projective fiber

```text
pi(n) = v
```

is such a zero fiber: if v = [A:B], then

```text
y_n = A c_n - B b_n
```

is a homogeneous solution, and y_n = 0 exactly when pi(n) = v. Therefore every projective fiber, in every regular nonwrapping window, has the same H^(2/3) zero-count bound.

In particular, for a fixed base r,

```text
z_d = Delta_{r,d} = det(v_r,v_{r+d})
```

is a nonzero homogeneous solution in the absolute index r+d, with z_0 = 0 and z_1 = 1/(r+1)^3. Its positive zeros are exactly the returns pi(r+d) = pi(r). The restart argument therefore transfers verbatim and gives, uniformly in r,

```text
d_D(r) << D^(2/3).
```

There are, however, two corrections.

First, the constant

```text
1 + (3/2)(H-1)^(2/3)
```

does not follow from

```text
R_rel <= (3/2)Y^2,
Z <= 1 + R_rel + H/(Y+1).
```

The correct leading constant from that optimization is

```text
3^(4/3)/2 = 2.163374...
```

not 3/2. The exponent 2/3 is correct.

Second, recursively applying the per-base bound to R_rel does not improve the exponent. It bounds rows of the incidence matrix (fixed start, varying return time), whereas the degree estimate bounds columns (fixed return time, varying start). The legitimate recursion leaves the exponent at 2/3. A formal golden-ratio fixed point would arise only after adding a genuinely new horizontal root-count theorem; it is not a consequence of restart.

The complete argument follows.

# 1. Audit of the claimed determinant formula

The claim (D1) is correct on every regular nonwrapping window.

Fix r with

```text
1 <= r,
r+h <= p-2.
```

Put

```text
z_h = Delta_{r,h} = b_r c_{r+h} - b_{r+h} c_r.
```

As a function of the absolute index n = r+h, z_h is the fixed linear combination

```text
z_h = b_r c_{r+h} - c_r b_{r+h}
```

of the two homogeneous solutions b and c. Hence

```text
(r+h+1)^3 z_{h+1}
  = P(r+h) z_h - (r+h)^3 z_{h-1}.
```

Define

```text
A_h = (prod_{j=1}^h (r+j)^3) z_h,
A_0 = z_0.
```

Clearing the recurrence gives

```text
A_{h+1}
  = P(r+h) A_h - (r+h)^6 A_{h-1}.
```

The initial values are

```text
A_0 = 0,
A_1 = (r+1)^3 Delta_{r,1}.
```

By the proved Casoratian identity,

```text
W_{r+1}
  = b_{r+1}c_r - b_r c_{r+1}
  = -1/(r+1)^3.
```

Therefore

```text
Delta_{r,1} = -W_{r+1} = 1/(r+1)^3,
A_1 = 1.
```

The defining recurrence and initial values for N_h(r) are exactly

```text
N_0(r) = 0,
N_1(r) = 1,
N_{h+1}(r)
  = P(r+h)N_h(r) - (r+h)^6N_{h-1}(r).
```

Thus

```text
A_h = N_h(r),
```

and hence

```text
Delta_{r,h}
  = N_h(r) / prod_{j=1}^h (r+j)^3.
```

All denominator factors are units because the window is regular and nonwrapping. This proves (D1), including its sign.

# 2. The universal reset lemma

The key point is a statement about every homogeneous solution, not specifically b.

Let y be a nonzero solution of

```text
(n+1)^3 y_{n+1}
  = P(n)y_n - n^3 y_{n-1}
```

on a regular interval. Define its projective recurrence state by

```text
X_n(y) = [n^3 y_{n-1} : y_n].
```

A direct use of the recurrence gives

```text
X_{n+1}(y) = M_n X_n(y),

M_n = [[0,(n+1)^6],[-1,P(n)]].
```

Indeed,

```text
M_n [n^3y_{n-1}:y_n]
 = [(n+1)^6y_n:-n^3y_{n-1}+P(n)y_n]
 = [(n+1)^6y_n:(n+1)^3y_{n+1}]
 = [(n+1)^3y_n:y_{n+1}].
```

On a regular window,

```text
det M_n = (n+1)^6 != 0.
```

Consequently a nonzero solution cannot have two consecutive zeros. If y_z = 0, then y_{z-1} and y_{z+1} are nonzero and

```text
X_z(y) = infinity,
X_{z+1}(y) = M_z(infinity) = 0.
```

Equivalently, immediately after every zero, the recurrence state is the same fixed point

```text
0 = [0:1].
```

This is the reset. The absolute start parameter changes from zero to zero, but the projective state does not retain any information from the part of the orbit before the zero.

For a zero at z and a later zero at z+h, h >= 2, one starts at

```text
X_{z+1}(y) = 0
```

and applies h-1 transfer matrices. The proved transfer formula gives

```text
G_{h-1}(z+1)[0:1]
 = [(z+h)^6 U_{h-2}(z+1):U_{h-1}(z+1)].
```

The terminal state is infinity, so

```text
U_{h-1}(z+1) = 0.
```

Using

```text
N_h(z) = U_{h-1}(z+1),
```

we obtain the universal gap law

```text
y_z = y_{z+h} = 0
  ==> N_h(z) = 0.
```

No property of the initial values b_0 = 1, b_1 = 5 enters this implication.

# 3. Exactly where the apparent b-specialness enters

## 3.1 The b-zero fiber

The fiber b_n = 0 is the projective fiber

```text
pi(n) = [0:1].
```

It is also the zero set of the homogeneous solution y = b. At a zero b_z = 0, the homogeneous state resets:

```text
X_z(b) = infinity,
X_{z+1}(b) = 0.
```

If

```text
z_1 < z_2 < ... < z_k
```

are the b-zeros, each consecutive gap h_i = z_{i+1}-z_i produces one root

```text
N_{h_i}(z_i) = 0.
```

This is why one zero-to-zero gap is controlled by one polynomial N_h. Short gaps have only one discrete parameter h, and the total degree mass up to h <= Y is quadratic:

```text
sum_{h=2}^Y deg N_h
 = sum_{h=2}^Y 3(h-1)
 = (3/2)Y(Y-1).
```

Balancing this Y^2 cost against the long-gap cost H/Y gives exponent 2/3.

The first zero of b costs an additive 1 because there is no preceding b-zero from which to restart. After that first zero, the proof is completely solution-independent.

## 3.2 Why a nonzero scalar value fiber does not reset

The paper's general fiber bound

```text
N_p(a) << p^(3/4)
```

concerns scalar value fibers

```text
b_n = a,
```

not projective fibers pi(n) = v.

For a != 0, put

```text
w_n = b_n - a.
```

Then w does not satisfy the homogeneous recurrence. Substitution gives

```text
(n+1)^3 w_{n+1}
 = P(n)w_n - n^3w_{n-1} + 4a(2n+1)^3.
```

Thus at a hit w_n = 0,

```text
(n+1)^3w_{n+1}
 = -n^3w_{n-1} + 4a(2n+1)^3.
```

The next state depends on the incoming value w_{n-1}. There is no fixed reset point.

The same failure is visible in the state x_n used for b:

```text
x_n = n^3 b_{n-1}/b_n.
```

At b_n = a != 0,

```text
x_n = n^3 b_{n-1}/a,
```

which is arbitrary. A hit of the scalar value a does not determine x_n or x_{n+1}.

This is the exact telescoping failure. One hit leaves one projective state parameter undetermined. Two more equations are required to eliminate it, so the scalar argument uses triples of equal values rather than pairs.

## 3.3 Reconstruction of the p^(3/4) argument, including its windowed form

For completeness, here is the current paper argument in windowed form.

Define

```text
Pi_m(x) = prod_{j=1}^m (x+j)^3.
```

Let B_m be the second continuant solution with

```text
B_0 = 1,
B_1 = 0,
B_m(x) = -(x+1)^6 N_{m-1}(x+1),
```

and put

```text
R_m(x) = Pi_m(x) - B_m(x).
```

If

```text
b_t = b_{t+m} = a,
```

the cleared solution formula gives

```text
N_m(t)(t+1)^3 b_{t+1} - R_m(t)a = 0.
```

If

```text
b_t = b_{t+h} = b_{t+k} = a,
1 <= h < k,
```

then the two rows for h and k kill the same nonzero vector

```text
((t+1)^3b_{t+1},a).
```

Their determinant vanishes:

```text
D_{h,k}(t) = 0,
D_{h,k} = N_hR_k - N_kR_h.
```

The proved factorization is

```text
D_{h,k}(x) = Pi_h(x) Delta_{h,k}(x),
```

where

```text
Delta_{h,k}(x)
 = N_h(x)Pi_{k-h}(x+h)
   - N_k(x)
   + Pi_h(x)N_{k-h}(x+h).
```

The current range-nonvanishing theorem gives

```text
Delta_{h,k} != 0 mod p
```

for every

```text
1 <= h < k < p,
```

and

```text
deg Delta_{h,k} = 3(k-1).
```

Now let J be any interval of L consecutive regular indices, and list one scalar fiber as

```text
t_1 < t_2 < ... < t_s,
b_{t_i} = a.
```

For i <= s-2 define

```text
h_i = t_{i+1}-t_i,
k_i = t_{i+2}-t_i.
```

Fix an integer Y with 2 <= Y < p.

If k_i <= Y, then t_i is a root of the nonzero polynomial Delta_{h_i,k_i}. For a fixed pair (h,k), there are at most 3(k-1) such bases. Hence the number of short triples is at most

```text
sum_{k=2}^Y sum_{h=1}^{k-1} 3(k-1)
 = 3 sum_{j=1}^{Y-1} j^2
 = Y(Y-1)(2Y-1)/2.
```

If k_i >= Y+1, split the indices i into the two parity classes. In either parity class the increments

```text
t_{i+2}-t_i
```

telescope and have total at most L-1. Therefore the number of long triples is at most

```text
2 floor((L-1)/(Y+1)).
```

Adding the final two fiber elements gives the exact windowed bound

```text
#{n in J:b_n=a}
 <= 2 floor((L-1)/(Y+1))
    + Y(Y-1)(2Y-1)/2
    + 2.
```

Balancing

```text
L/Y + Y^3
```

gives Y about L^(1/4) and therefore exponent 3/4.

The older displayed record

```text
N_p(a) <= 8p^(3/4)
```

is a coarse consequence. For p >= 16 choose Y = floor(p^(1/4)). Then

```text
2p/(Y+1) < 2p^(3/4),
Y(Y-1)(2Y-1)/2 < Y^3 <= p^(3/4),
```

so the exact bound is already less than

```text
3p^(3/4)+2,
```

and hence less than 8p^(3/4). The finitely many smaller primes are trivial. The sharper optimized leading constant in the current file is

```text
4(2/3)^(3/4) = 2.951151...
```

The exponent difference is therefore structural:

```text
homogeneous zero/projective fiber:
  pair certificates, one gap parameter, degree mass Y^2,
  exponent 2/3;

nonzero scalar value fiber:
  triple certificates, two gap parameters, degree mass Y^3,
  exponent 3/4.
```

# 4. Every fixed projective fiber has the reset

Fix

```text
v = [A:B] in P^1(F_p).
```

Define

```text
y_n(v) = A c_n - B b_n.
```

This is a homogeneous solution. It is nonzero: if y_0(v) = y_1(v) = 0, then

```text
-B = 0,
A-5B = 0,
```

so A = B = 0, impossible for a projective point.

Moreover,

```text
y_n(v) = 0
  <=> det((A,B),(b_n,c_n)) = 0
  <=> pi(n) = v.
```

Therefore every projective fiber is the zero set of a nonzero homogeneous solution. At every hit of v, the recurrence state of y(v) resets to 0. The target v can be arbitrary; it need only remain fixed while the fiber is being counted.

This resolves the apparent moving-point problem for vector 7. For a fixed base r, the target

```text
v = pi(r)
```

is fixed throughout the row d = 0,1,...,D. It may depend on r from row to row, but the bound is uniform in v, so that dependence is harmless.

# 5. The uniform windowed zero theorem

We now state the exact deterministic theorem that the restart proof gives.

## Theorem [THM-PROJECTIVE-WINDOW-2/3]

Let y be any nonzero homogeneous solution of the Apery recurrence modulo p on a regular nonwrapping interval J of H consecutive indices. Let

```text
Z_y(J) = #{n in J:y_n=0}.
```

For every integer Y with

```text
2 <= Y <= H-1,
```

one has

```text
Z_y(J)
 <= 1
    + (3/2)Y(Y-1)
    + floor((H-1)/(Y+1)).
```

Consequently

```text
Z_y(J) << H^(2/3)
```

with an absolute implied constant, uniformly in p, J, and y.

The same statement holds for every projective fiber:

```text
#{n in J:pi(n)=v} << H^(2/3)
```

uniformly in v.

## Proof

Write the zeros of y in J as

```text
z_1 < z_2 < ... < z_k.
```

If k <= 1 there is nothing to prove. Since the transfer matrices are invertible on J, consecutive zeros cannot occur. Thus every gap

```text
h_i = z_{i+1}-z_i
```

satisfies h_i >= 2.

Call a gap short if h_i <= Y. By the universal reset lemma,

```text
N_{h_i}(z_i) = 0.
```

For each fixed h, the proved nonvanishing theorem says N_h is not the zero polynomial modulo p in the regular range, and

```text
deg N_h = 3(h-1).
```

Hence there are at most 3(h-1) possible starts z_i for a short gap of length h. The total number of short gaps is therefore at most

```text
sum_{h=2}^Y 3(h-1)
 = (3/2)Y(Y-1).
```

Call a gap long if h_i >= Y+1. The gaps telescope:

```text
sum_{i=1}^{k-1} h_i
 = z_k-z_1
 <= H-1.
```

Thus the number of long gaps is at most

```text
floor((H-1)/(Y+1)).
```

Since k is one plus the total number of gaps, the claimed exact inequality follows.

This proof uses only:

```text
1. invertibility of the recurrence transfer on the window;
2. reset after a zero;
3. N_h not identically zero;
4. deg N_h = 3(h-1).
```

It does not use the initial values of b.

# 6. The per-base return theorem

Fix r and D with

```text
1 <= r,
r+D <= p-2.
```

Let

```text
d_D(r) = #{1 <= d <= D:pi(r+d)=pi(r)}.
```

Use the homogeneous solution

```text
z_d = Delta_{r,d}.
```

By Section 1,

```text
z_0 = 0,
z_1 = 1/(r+1)^3 != 0,
z_d = 0 <=> pi(r+d)=pi(r).
```

List its zeros in d = 0,...,D as

```text
0 = e_0 < e_1 < ... < e_q,
```

where q = d_D(r). Applying the proof above to the q consecutive gaps, without the additive cost for an unknown first zero, gives the exact bound

```text
d_D(r)
 <= (3/2)Y(Y-1) + floor(D/(Y+1))
```

for every integer

```text
2 <= Y <= D.
```

Equivalently,

```text
d_D(r)
 <= min_{2 <= Y <= D}
      ((3/2)Y(Y-1) + floor(D/(Y+1))).
```

For D = 1, d_D(r) = 0 because

```text
Delta_{r,1} = 1/(r+1)^3 != 0.
```

Choosing

```text
Y = ceil((D/3)^(1/3))
```

for large D gives

```text
d_D(r)
 <= (3^(4/3)/2)D^(2/3)
    + (3^(2/3)/2)D^(1/3).
```

After enlarging the lower-order constant, this is valid for all D. In particular,

```text
max_r d_D(r) << D^(2/3)
```

uniformly over all regular bases r.

This is the desired vector-7 theorem. It is not merely analogous to the b-zero proof; it is an instance of the same universal zero theorem.

# 7. Correction of the claimed 3/2 leading constant

The parallel claim quoted in the question uses

```text
Z(H) <= 1 + R_rel(p,Y) + H/(Y+1),
R_rel(p,Y) <= (3/2)Y^2,
Y about (H/3)^(1/3).
```

Substituting that Y into the two leading terms gives

```text
(3/2)(H/3)^(2/3)
 + H/(H/3)^(1/3)

= (3^(1/3)/2)H^(2/3)
  + 3^(1/3)H^(2/3)

= (3^(4/3)/2)H^(2/3).
```

Thus the leading constant furnished by the displayed argument is

```text
3^(4/3)/2 = 2.163374...,
```

not

```text
3/2 = 1.5.
```

The exact short-gap expression

```text
(3/2)Y(Y-1)
```

and the exact long-gap denominator Y+1 improve only lower-order terms; they do not change this leading optimization constant.

Therefore the bankable statement is

```text
Z_y(J)
 <= 1 + (3^(4/3)/2)(H-1)^(2/3)
      + O(H^(1/3)),
```

and, for the base-r return count,

```text
d_D(r)
 <= (3^(4/3)/2)D^(2/3)
      + O(D^(1/3)).
```

The exponent and uniformity survive intact. Only the advertised 3/2 coefficient must be removed.

# 8. Does restarting R_rel recursively improve 2/3?

No. The proposed recursion transposes the incidence relation.

Define the local return incidence count

```text
R_I(Y)
 = #{(s,m):s in I,1 <= m <= Y,U_m(s)=0},
```

with the usual regularity restrictions.

There are two directions in this incidence matrix.

For fixed m and varying s, U_m(s) is one polynomial of degree 3m. Therefore

```text
#{s in I:U_m(s)=0} <= 3m,
```

and summing columns gives

```text
R_I(Y)
 <= sum_{m=1}^Y 3m
 = (3/2)Y(Y+1).
```

For fixed s and varying m, the condition U_m(s)=0 counts returns of the reset solution based at s-1. The new per-base theorem gives

```text
#{1 <= m <= Y:U_m(s)=0}
 << Y^(2/3).
```

Summing rows over an interval I of length H gives only

```text
R_I(Y) << H Y^(2/3).
```

This is not a replacement of Y^2 by Y^(5/3). It contains the extra factor H because the theorem controls varying m for each fixed s, whereas the desired improvement would need control of varying s for each fixed m.

At the restart scale

```text
Y about H^(1/3),
```

the two bounds are

```text
column degree bound:  Y^2 about H^(2/3),
row restart bound:    H Y^(2/3) about H^(11/9).
```

The row bound is much worse. The original degree bound remains the active one.

## 8.1 The legitimate exponent map

Suppose abstractly that a per-base theorem gives exponent e:

```text
#{m <= Y:U_m(s)=0} << Y^e,
0 <= e < 1.
```

Then

```text
R_I(Y)
 << min(Y^2,H Y^e).
```

The crossover is

```text
Y = H^(1/(2-e)).
```

The minimizer of the original expression

```text
Y^2 + H/Y
```

is Y = H^(1/3). For every e >= 0,

```text
1/3 <= 1/(2-e),
```

so this minimizer lies in the region where the column degree bound Y^2 is already smaller than H Y^e. Consequently the restarted estimate remains

```text
H^(2/3).
```

Thus the legitimate bootstrap map is

```text
T(e) = 2/3,
```

and its fixed point is 2/3.

## 8.2 Where the golden-ratio map would come from, and why it is unavailable

If one had the genuinely new horizontal theorem

```text
#{s:U_m(s)=0 in the relevant range} << m^e
```

for each fixed m, then

```text
R_I(Y) << sum_{m <= Y} m^e << Y^(e+1).
```

The restart inequality would become

```text
Z(H) << Y^(e+1) + H/Y.
```

Optimizing would give the formal map

```text
T_horizontal(e) = (e+1)/(e+2).
```

Its positive fixed point is

```text
e = (sqrt(5)-1)/2 = 0.618033...
```

and starting from e = 2/3 would give 5/8 in one step.

But the premise is not supplied by the per-base theorem. It is a bound in the opposite direction of the incidence matrix. In the project notation it is essentially a sub-degree horizontal root bound for the family N_h, or an S_D-type theorem. That is one of the actual last-wall arithmetic inputs.

The renewal congruence

```text
U_{a+1+b}(s)
 congruent U_{a+1}(s)U_b(s+a+1) mod U_a(s)
```

does not repair this. It describes later returns on the locus U_a(s)=0. It does not imply that U_a divides U_{a+1+b}, does not factor U_m into first-return polynomials of controlled total degree, and does not bound the number of starts s for a fixed m. This is exactly the already-audited failure of the factor-composition-tree argument.

Therefore no recursive exponent improvement is currently bankable.

# 9. Consequences for vector 7

The following statement is unconditional and can be used as the vector-7 bottom input:

```text
[THM-BASE-RETURN-2/3]
For every prime p >= 7, every regular base r, and every D with
r+D <= p-2,

d_D(r)
 <= min_{2 <= Y <= D}
      ((3/2)Y(Y-1) + floor(D/(Y+1)))
 << D^(2/3).
```

More generally:

```text
[THM-PROJECTIVE-FIBER-2/3]
For every v in P^1(F_p) and every regular interval J of length H,

#{n in J:pi(n)=v} << H^(2/3).
```

This theorem identifies the structural source correctly:

```text
not b-specialness,
but homogeneous zero-fiber specialness.
```

It also explains why the scalar N_p(a) bound remains at exponent 3/4: b_n=a with a != 0 is an affine level set, not a homogeneous projective fiber.

The new row bound does not by itself cross the last wall. For example, combining

```text
max_r d_D(r) << D^(2/3)
```

with the trivial

```text
S_D << D^2
```

and

```text
Q_D <= (max_r d_D(r))S_D/2
```

gives only

```text
Q_D << D^(8/3).
```

At

```text
D = p^(1/2)L,
```

this is

```text
Q_D << p^(4/3)L^(8/3),
```

which is far above the required O(p). Thus the theorem is a valid multiscale input, but it does not replace the missing S_D or family-averaged arithmetic estimate.


2. The reset argument applies to every nonzero homogeneous solution and hence to every fixed projective fiber.

3. For every regular base r,

```text
d_D(r) << D^(2/3)
```

uniformly and unconditionally.

4. The precise exact inequality is

```text
d_D(r)
 <= (3/2)Y(Y-1)+floor(D/(Y+1))
```

for every 2 <= Y <= D.

```text
3^(4/3)/2,
```
