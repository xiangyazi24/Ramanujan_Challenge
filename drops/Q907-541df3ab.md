## 1. Reflection of p-integral recurrence solutions

Let R be reversal modulo p:

  (Ru)_j = u_{p-1-j}.

The recurrence coefficients are palindromic after reduction modulo p. Hence reversal maps a solution to a solution. For the Apéry solution b this gives Rb=b modulo p.

The Wronskian calculation is the critical point. For

  W_n(u,b)=u_n b_{n-1}-u_{n-1}b_n,

one obtains, with the indexing convention used in the proof,

  W_n(Ru,b)=-W_{p-n}(u,b).

Using the p-periodic reduction of the Casoratian gives

  W_{p-n}(u,b)=-W_n(u,b),

so

  W_n(Ru,b)=W_n(u,b).

Therefore

  Ru-u=c b

inside the two-dimensional solution space over F_p. The endpoint argument must then show c=0. This requires that the chosen normalization has u_0 and u_{p-1} compatible with the fixed solution, not merely that Rb=b. With that endpoint condition, the reflection statement is valid.

Dependency-map entry:

```
prop:reflection
status: proved
edge: recurrence symmetry + Casoratian + endpoint normalization
role: residue transport only
```

It does not create a new multiplicative invariant.

## 2. Companion endpoint reflection

The statement

  a_(p-1)=0 mod p^2

for p>=7 is compatible with the binomial-tail representation. The required cancellations are:

1. pair k and p-1-k terms;
2. use the first-order harmonic expansion of the factorial ratios;
3. use the vanishing of the paired constant term modulo p;
4. retain the harmonic correction modulo p^2.

No division by a non-unit is allowed in this step. The denominator factors in the rational companion formula must first be reduced to p-integral terms. Under that normalization the result is valid.

Dependency-map entry:

```
cor:companion-reflection-depth
status: proved
edge: companion tail identity -> p^2 endpoint zero
role: removes endpoint companion residue classes
```

It is not a cross-prime carrier.

## 3. Companion-block height claim

The proposed argument is:

  sum_{sqrt(n)<p<=n, p|num(a_floor(n/p))} log p = O(n^(2/3)).

The split at q=n^(1/3) is natural, but the sentence

  log|num(a_q)|=O(q)

does not follow merely from the fact that a_q/b_q approximates zeta(3). The denominator and numerator of the rational companion must be controlled separately. A rational approximation statement does not imply numerator-height control.

A valid replacement requires an explicit height lemma, for example:

  log |num(a_q)| <= C q

with the exact normalization of a_q and denominator clearing proved independently. Without this lemma the O(n^(2/3)) conclusion is conditional.

Dependency-map entry:

```
prop:companion-height
status: conditional
missing edge: rational-height lemma for a_q
role: conditional pruning estimate only
```

## Interaction with endpoint supercongruence

The congruence

  p^3 a_(qp)=a_q mod p^3

is a local transport law. Together with

  b_(qp)=b_q mod p^3

it gives companion endpoint transfer. It does not manufacture a fixed integer whose prime factors include several target primes.

The general-q b-jet similarly gives

  b_(qp+r)=b_q(b_r+2qpD_r) mod p^2.

At p|b_r this yields

  b_(qp+r)/p = b_q(b_r/p+2qD_r) mod p.

The remaining term b_r/p is essential. Removing it would falsely create an extra universal slope.

Combining these laws gives local coordinates at each prime, but no proved global elimination relation.
