# Verdict

There **is** a standard cohomological construction attached to the coefficient index `r`, but it is not a rank-three K3 fiber `V_r`, and it does not turn `p | b_r` into the disappearance of a unit-root line.

The clean coefficient-indexed object is a **Kummer-twisted Mellin cohomology complex**. Let

```text
F(x,y,z,w) = (1 - x - y)(1 - z - w) - x y z w,
T          = (G_m)^4,
U_F        = T minus V(F),
m(x,y,z,w) = x y z w.
```

For `1 <= r <= p - 2`, let `ω` be the Teichmüller character and put

```text
χ_{p,r} = ω^{-r} composed with m.
```

Let `K_{p,r}` denote the corresponding rank-one Kummer overconvergent F-isocrystal. Then

```text
C_{p,r} := RΓ_{rig,c}(U_F / Q_p, K_{p,r})
```

is a finite-dimensional coefficient-indexed complex with Frobenius, and

```text
STr(Frob_p | C_{p,r}) = J_{p,r},
J_{p,r} mod p = b_r mod p.
```

Thus `b_r mod p` is exactly the reduction of a Frobenius **supertrace** on a p-adic cohomology object attached to `r`.

There is also a literal idempotent attached to `r`: the `χ_{p,r}`-isotypic projector on a Kummer cover. It is a **character projector**, not a slope-zero projector. The event `b_r = 0 mod p` is generally cancellation in a Frobenius trace, not a rank drop of the transformed cohomology.

Consequently:

1. **Question 1:** yes, there is a known and concrete p-adic cohomological realization, but naturally as a Kummer-twisted supertrace, not as the trace of a rank-three crystal.
2. **Question 2:** Cartier and Mellin can be composed in a derived/cohomological sense. The result is a Frobenius complex and a p-adic Mellin trace. It does not formally yield a zero-detecting projector `Π^{ur}_{p,r}`.
3. **Question 3:** Dwork, Adolphson-Sperber, Katz, arithmetic D-module hypergeometric theory, and p-adic GKZ theory provide extensive precedent for exactly this geometric-variable versus Kummer-parameter distinction.

The missing Apéry theorem is therefore not the existence of the transform. It is uniform structural and analytic control of its Frobenius traces when the defining prime `p` and the character index `r` move together.

# 1. Exact Kummer-twisted realization of `b_r mod p`

## 1.1 The character sum

Let

```text
ω : F_p^× -> μ_{p-1} inside Q_p^×
```

be the Teichmüller lift. For `1 <= r <= p - 2`, define

```text
χ_{p,r}(x,y,z,w) = ω(x y z w)^(-r).
```

Consider the Jacobi-type sum

```text
J_{p,r}
  = sum χ_{p,r}(x,y,z,w),
```

where the sum is over all `(x,y,z,w)` in `(F_p^×)^4` satisfying

```text
F(x,y,z,w) != 0.
```

Then

```text
J_{p,r} = b_r modulo p.
```

### Proof

Modulo the maximal ideal of `Z_p`, the Teichmüller value `ω(u)` reduces to `u`. Fermat gives

```text
1_{F(x) != 0} = F(x)^(p-1) in F_p.
```

Therefore

```text
J_{p,r}
  = sum_{x,y,z,w != 0}
      F(x,y,z,w)^(p-1) (x y z w)^(-r)
      modulo p.
```

Because `F` is multilinear, every exponent of every variable in `F^(p-1)` lies between `0` and `p-1`. For `1 <= r <= p-2`, multiplicative orthogonality gives

```text
sum_{u in F_p^×} u^(i-r)
  = -1  if i = r,
  =  0  otherwise,
```

for `0 <= i <= p-1`.

There are four variables, so the four factors `-1` multiply to `+1`. The character sum therefore selects exactly the coefficient of

```text
x^r y^r z^r w^r
```

in `F^(p-1)`. The checked-in diagonal Cartier theorem identifies that coefficient with `b_r mod p`.

The endpoints `r = 0` and `r = p-1` have the expected exponent-aliasing terms. The interior range relevant to the zero problem has no aliases.

## 1.2 Rigid-cohomology trace formula

Let `K_{p,r}` be the rank-one Kummer overconvergent F-isocrystal on `U_F` with trace function `χ_{p,r}`. The rigid Lefschetz trace formula gives, with the usual choice between arithmetic and geometric Frobenius,

```text
J_{p,r}
  = sum_i (-1)^i
      Tr(Frob_p | H^i_{rig,c}(U_F / Q_p, K_{p,r})).
```

Equivalently,

```text
J_{p,r} = STr(Frob_p | C_{p,r}).
```

This is the strongest unconditional answer currently justified:

> `b_r mod p` is the reduction of a Frobenius supertrace on a fixed toric complement with a rank-one Kummer coefficient system indexed by `r`.

It is not yet justified to replace “supertrace” by “trace on one rank-three group.”

## 1.3 The Straub threefold and a possible single `H³` trace

Because `χ_{p,r}` is nontrivial,

```text
sum_{(x,y,z,w) in (F_p^×)^4} χ_{p,r}(x,y,z,w) = 0.
```

Hence

```text
J_{p,r}
  = - sum_{x in Y_F(F_p)} χ_{p,r}(x).
```

Thus the same scalar is the negative Frobenius supertrace on the Kummer-twisted compactly supported cohomology of the threefold `Y_F`.

If one proves that, after the correct resolution or middle extension and after removing boundary Tate pieces, every nonresonant Kummer twist is concentrated in degree `3`, then one obtains

```text
J_{p,r}
  = Tr(Frob_p |
       H³_{rig,c}(Y_F, K_{p,r})_primitive).
```

That is the precise version of the proposed `H³` interpretation.

Concentration cannot simply be assumed. A direct derivative calculation shows that the fixed hypersurface has a singular point at

```text
(1,1,1,1).
```

One must resolve it, use intersection cohomology, or compute its local correction explicitly.

## 1.4 The literal Mellin idempotent

The Kummer coefficient can be realized through the cover

```text
U_tilde_p
  = { (x,y,z,w,s) :
      (x,y,z,w) in U_F,
      s^(p-1) = x y z w }.
```

Its deck group is `μ_{p-1}`. Define

```text
e_r^Kum
  = (1 / (p-1))
    sum_{ζ in μ_{p-1}} ζ^(-r) [ζ].
```

Then

```text
(e_r^Kum)^2 = e_r^Kum,
C_{p,r} is isomorphic to
  e_r^Kum RΓ_{rig,c}(U_tilde_p / Q_p).
```

This is the genuine projector attached to the coefficient index. It projects to a character-isotypic component. It is not a unit-root slope projector.

The Kummer-isocrystal formulation is preferable to the cover: the cover has degree `p-1`, while the coefficient object has rank one.

# 2. Dwork exponential form

Choose a nontrivial additive character

```text
ψ : F_p -> μ_p.
```

Since the total `χ_{p,r}`-sum on the torus vanishes, additive orthogonality gives

```text
J_{p,r}
  = -(1/p)
    sum_{u in F_p^×}
    sum_{x in (F_p^×)^4}
      χ_{p,r}(x) ψ(u F(x)).
```

This is a multiplicatively twisted toric exponential sum in five multiplicative variables. It is exactly the setting of Dwork and Adolphson-Sperber.

Put

```text
λ_{p,r} = -r / (p-1).
```

The Kummer character is represented in de Rham form by a rank-one logarithmic connection with exponent `λ_{p,r}`. Schematically, the Dwork complex has differential

```text
∇_{p,r}
  = d
    + π d(u F)
    + λ_{p,r} dlog(x y z w),
```

with the sign changed if the opposite Kummer convention is chosen.

The identity

```text
p λ_{p,r} - λ_{p,r} = -r
```

explains the Frobenius structure. Frobenius changes the logarithmic exponent from `λ` to `p λ`; multiplication by the integral monomial `(x y z w)^(-r)` returns it to the original exponent. Dwork's splitting function supplies the exponential part of the Frobenius chain map.

Therefore “the `r`-th power of the toric coordinate” should be interpreted as either

- a monomial gauge factor in Frobenius; or
- a Kummer logarithmic twist of a de Rham complex,

not as ordinary de Rham cohomology of a new variety obtained merely by raising a coordinate to the `r`-th power.

If the five-variable phase

```text
G(u,x,y,z,w) = u F(x,y,z,w)
```

is nondegenerate with respect to its Newton polyhedron for the relevant character, and if the character is nonresonant, Adolphson-Sperber theory can concentrate the Dwork cohomology in middle degree and compute its rank from normalized Newton volume. Those hypotheses have not yet been checked in the repository for this singular Straub model.

# 3. Cartier followed by Mellin: what is valid

## 3.1 Exact multivariate Cartier identity

Define the four-variable coefficient Cartier operator by

```text
C_p^(4)( sum_{ν} a_ν x^ν )
  = sum_{ν} a_{pν} x^ν.
```

Put `m = x y z w`. For `1 <= r <= p-2`, the checked-in diagonal theorem immediately gives the identity in `F_p[x,y,z,w]`

```text
C_p^(4)( m^(p-r) F^(p-1) ) = b_r m.
```

Reason: every exponent of `F^(p-1)` is between `0` and `p-1`. After the shift by `p-r`, the only multiple of `p` in each variable is `p`, and its coefficient is the original diagonal coefficient at exponent `r`.

This is the exact multivariate analogue of the moving-frame Cartier extraction already proved in `gap_kernel_cartier_defect.tex`.

It validates the proposed coefficient extraction, but it is an **extraction functional**, not an idempotent on a fixed rank-three crystal. Both the monomial shift and the polynomial degree depend on `p` and `r`.

The Kummer twist packages the moving frame into a rank-one coefficient object. It does not turn it into a K3 fiber projector.

## 3.2 The correct relative K3 Mellin functor

Let

```text
f : X -> B
```

be the smooth part of the Apéry K3 family, and let

```text
V := R² f_{rig,*} Q_p
```

be its rank-three primitive F-isocrystal. For any coefficient object `E` on the base, define

```text
Mel_{p,r}(E)
  := RΓ_{rig,c}(B_open,
                E tensor K_{ω^{-r}}).
```

This is the cohomological Mellin transform at the character `ω^{-r}`.

Let `L` be the one-dimensional Hodge line of `V`. Modulo `p`, its Cartier/Hasse-Witt map has scalar

```text
H_p(t) = sum_{j=0}^{p-1} b_j t^j.
```

Multiplicative orthogonality gives

```text
-b_r
  = sum_{t in F_p^×} H_p(t) t^(-r)
```

for `1 <= r <= p-2`.

Thus the Mellin transform of the **Cartier map on the Hodge line** recovers `b_r`, after adding the finite singular-fiber correction objects needed when the geometric smooth base is smaller than all of `G_m`.

This is the precise formal meaning of “compose Cartier with Mellin projection.”

## 3.3 Mellin-transforming the unit-root line

On the ordinary locus, suppose the unit-root line `U_p` has Frobenius scalar `α_p(t)`, normalized so that

```text
α_p(t) = H_p(t) modulo p
```

at Teichmüller points. Then

```text
b_tilde_{p,r}
  := -STr(Frob_p | Mel_{p,r}(U_p))
```

is a p-adic Mellin lift of `b_r`. At the trace-function level,

```text
b_tilde_{p,r}
  = - sum_{t in ordinary F_p-points}
        α_p(t) ω(t)^(-r),
```

plus explicit corrections at removed singular fibers. Nonordinary smooth fibers contribute zero modulo `p` because their Hasse scalar vanishes. Hence, after the fixed corrections,

```text
b_tilde_{p,r} = b_r modulo p.
```

The operator that carries the Apéry information is

```text
Frobenius times Π^{ur},
```

not the bare projector. On every ordinary fiber,

```text
Tr(Π^{ur}_{p,t}) = 1.
```

Mellin-transforming only the projector would therefore produce the character sum over the ordinary locus, not the Mellin coefficient of `H_p(t)`.

There is also a technical extension problem. The full Gauss-Manin F-isocrystal is overconvergent on the smooth base. Its unit-root subobject on the ordinary locus need not extend overconvergently through the Hasse divisor. A rigorous implementation needs one of:

- a log-growth coefficient category;
- an arithmetic D-module or middle-extension construction;
- the direct Straub toric Kummer complex, which avoids the extension problem.

## 3.4 Why this still does not produce a zero detector

Suppose a horizontal unit-root idempotent exists as a morphism of coefficient objects. Functoriality would give an idempotent after Mellin transform. That does not make `b_r = 0` a rank-drop event.

The coefficient is a trace:

```text
b_r = STr(Φ_{p,r}) modulo p.
```

A trace can vanish while the cohomology, its slope-zero subspace, and its spectral projector are all nonzero. Therefore none of the following is formal:

```text
b_r = 0
  implies slope-zero cohomology is zero;

b_r = 0
  implies Tr(Π_{p,r}^{slope 0}) = 0;

1_{b_r=0}
  = 1 - Tr(Π_{p,r}^{slope 0}).
```

A zero-detecting projector would require a new theorem asserting something like:

1. the transformed slope-zero piece has rank at most one;
2. its Frobenius trace is congruent to `b_r`;
3. no other slope-zero eigenvalues or alternating-degree cancellations occur.

No such theorem follows from standard Dwork theory, and none is currently in the repository.

The honest coefficient-indexed invariant is the full Mellin Frobenius polynomial

```text
P^{Mel}_{p,r}(T)
  = product over i of
      det(1 - T Frob_p | H^i_{rig,c}(U_F,K_{p,r}))
      with alternating exponents.
```

Its first logarithmic coefficient is `J_{p,r}`, hence reduces to `b_r`. Its Newton polygon and slope-zero factor carry genuinely new p-adic data, but a rank-drop interpretation must be tested rather than assumed.

# 4. Two different Cartier operations

The project uses two related but distinct operations.

## 4.1 Coefficient Cartier

For a series

```text
f(t) = sum_n a_n t^n,
```

coefficient Cartier is

```text
C_p(f) = sum_n a_{pn} t^n.
```

After an `r`-dependent monomial shift, it extracts a chosen coefficient. This is the operation in the checked-in Green-kernel theorem and in the four-variable identity above.

## 4.2 Geometric Hasse-Witt Cartier

For a smooth K3 fiber, Cartier or inverse Cartier acts on Hodge pieces of `H²_dR`. In a trivialization of the one-dimensional Hodge line, its scalar is the Hasse-Witt value `H_p(t)`.

Toric residue theory explains why coefficients of a `(p-1)`-st power occur in Hasse-Witt matrices. But an entry of a Hasse-Witt matrix and a coefficient-extraction operator are not automatically the same endomorphism on one fixed vector space.

The Mellin construction connects them at the scalar level:

```text
fiberwise Hasse scalar H_p(t)
       -- Kummer Mellin -->
coefficient b_r.
```

The direct diagonal construction computes the same scalar through

```text
F^(p-1)
       -- monomial shift and Cartier -->
coefficient b_r.
```

They are two realizations of the same coefficient, but they live in different geometries.

# 5. Literature precedent

The construction is standard; the desired Apéry estimate is not.

## 5.1 Dwork hypergeometric Frobenius

Bernard Dwork constructed Frobenius structures on generalized hypergeometric differential equations and expressed them using p-adic analytic hypergeometric functions.

Primary reference:

- Bernard Dwork, *On p-adic differential equations IV: generalized hypergeometric functions as p-adic analytic functions in one variable*, Annales scientifiques de l'École Normale Supérieure 6 (1973), 295-316, DOI 10.24033/asens.1249.

Dwork's theory distinguishes the geometric argument from exponent parameters. The Apéry index `r` belongs on the exponent/Kummer side.

## 5.2 Adolphson-Sperber twisted toric sums

The direct precedents for the five-variable twisted exponential sum are:

- Alan Adolphson and Steven Sperber, *Exponential sums and Newton polyhedra: cohomology and estimates*, Annals of Mathematics 130 (1989), 367-406, DOI 10.2307/1971424.
- Alan Adolphson and Steven Sperber, *Exponential sums on (G_m)^n*, Inventiones Mathematicae 101 (1990), 63-80.
- Alan Adolphson and Steven Sperber, *On twisted exponential sums*, Mathematische Annalen 290 (1991), 713-726.

Their theory supplies Newton-polyhedron nondegeneracy tests, middle-degree concentration, rank formulas, and p-adic Frobenius estimates for multiplicatively twisted toric sums.

## 5.3 Rigid trace formula

The cohomological interpretation of L-functions of overconvergent F-isocrystals is supplied by:

- Jean-Yves Étesse and Bernard Le Stum, *Fonctions L associées aux F-isocristaux surconvergents I: interprétation cohomologique*, Mathematische Annalen 296 (1993), 557-576.

This is the formal basis for the rigid-cohomology trace formula used above.

## 5.4 Katz and multiplicative convolution

On the ℓ-adic side, Katz's hypergeometric sheaves are built from Kummer and Artin-Schreier sheaves by multiplicative convolution. Mellin transforms are governed by Gauss sums. This is the sheaf-theoretic prototype of turning an exponent or coefficient parameter into character-isotypic cohomology.

Standard reference:

- Nicholas Katz, *Exponential Sums and Differential Equations*, Annals of Mathematics Studies 124, Princeton University Press, 1990.

## 5.5 Modern p-adic hypergeometric and GKZ constructions

The same architecture exists directly in p-adic cohomology:

- Kazuaki Miyatani, *p-adic generalized hypergeometric equations from the viewpoint of arithmetic D-modules*, arXiv:1607.04852. This uses multiplicative convolution and constructs overconvergent hypergeometric F-isocrystals.
- Lei Fu, Peigen Li, Daqing Wan, and Hao Zhang, *The p-adic Gelfand-Kapranov-Zelevinsky hypergeometric complex*, arXiv:1804.05297. The object is a twisted relative de Rham complex with Frobenius; Teichmüller-fiber traces are finite-field hypergeometric functions.
- Kiran Kedlaya, *Frobenius structures on hypergeometric equations*, arXiv:1912.13073. This gives explicit Dwork-GKZ Frobenius formulas and p-adic gamma factors.
- Frits Beukers and Masha Vlasenko, *Dwork Crystals I*, International Mathematics Research Notices 2021, 8807-8844, DOI 10.1093/imrn/rnaa119. This develops explicit Hasse-Witt matrices and p-adic limit formulas for toric hypersurfaces.

These are genuine precedents for the coefficient-versus-fiber problem. None turns the vanishing of a Mellin trace into absence of a unit-root constituent without an extra special theorem.

## 5.6 The remaining cross-prime wall

For a fixed rational exponent `λ`, hypergeometric F-crystals can often be organized uniformly over primes satisfying denominator conditions. Here

```text
λ_{p,r} = -r / (p-1)
```

moves with both `p` and `r`. The associated character order is

```text
(p-1) / gcd(p-1,r),
```

which can be as large as `p-1`.

Thus the construction has bounded coefficient rank at each prime, but it is not automatically one fixed compatible system across all defining characteristics. This is the precise form of the same-characteristic wall.

# 6. Concrete Apéry-specific computation

The next computation should target the fixed Straub coefficient geometry rather than manufacture a rank-three `V_r`.

A suitable verifier would be

```text
problems/3.2/research/scripts/q7806_straub_kummer_dwork.sage
```

with the following gates.

## Gate A: exact finite-field identity

For `p = 11, 13, 17` and every `1 <= r <= p-2`, compute

```text
J_{p,r} mod p
  = sum_{F(x) != 0} (x y z w)^(-r) mod p
```

and compare it with `b_r mod p` obtained independently from the Apéry recurrence. Record all indices, not only zeros.

## Gate B: exact multivariate Cartier identity

Expand `F^(p-1)` and verify

```text
C_p^(4)( (x y z w)^(p-r) F^(p-1) )
  = b_r x y z w
```

for every interior `r`.

## Gate C: singularity and Newton-polyhedron audit

1. Determine all singular points of `Y_F` in `(G_m)^4`.
2. Resolve or compute the local rigid-cohomology correction at `(1,1,1,1)`.
3. Form the phase `G(u,x,y,z,w) = u F(x,y,z,w)`.
4. Check Adolphson-Sperber nondegeneracy face by face.
5. Classify resonant character indices `r`.
6. Compute normalized Newton volume and the expected generic cohomology rank.

This determines whether the coefficient is literally one primitive `H³` trace or a supertrace with explicit corrections.

## Gate D: Dwork Frobenius

Using the twisted de Rham or Koszul basis from Gate C, compute Frobenius modulo `p^N`, initially with `N = 4` or `6`. Verify

```text
STr(Φ_{p,r}) = b_r modulo p.
```

Record

```text
P^{Mel}_{p,r}(T),
its Newton polygon,
the dimension of its slope-zero part.
```

## Gate E: decisive projector test

At every index with `b_r = 0 mod p`, test whether the transformed slope-zero part vanishes.

- If the slope-zero dimension is nonzero at even one Apéry zero, then a rank-drop projector interpretation is false for this Mellin cohomology.
- If the slope-zero dimension is zero at all tested zeros and one at all tested nonzeros, that is strong evidence but still requires a theorem excluding cancellation and higher-rank exceptions.

This is the correct test of the object indexed by `r`; inspecting only fiberwise K3 unit roots does not test the coefficient event.

## Gate F: compare two p-adic lifts

Independently compute the ordinary-base K3 Mellin trace

```text
b_tilde^{K3}_{p,r}
  = - sum_t α_p(t) ω(t)^(-r),
```

including singular-fiber corrections, and compare it modulo `p²` or `p³` with the Straub toric trace `J_{p,r}`.

Agreement modulo `p` is forced by the Hasse and diagonal identities. Agreement to higher powers would be a new comparison theorem between the K3 unit-root Mellin complex and the Straub coefficient motive. Disagreement would show that they are different p-adic lifts of the same residual coefficient.

# 7. The theorem that would actually move the project

The construction above supplies an exact coefficient-indexed Frobenius object. To become useful for the Ramanujan Challenge, one needs more than existence.

A realistic first target is:

> **Uniform Mellin-cohomology theorem.** Outside an explicitly classified set of resonant characters, the complexes `C_{p,r}` are concentrated in one fixed degree, have uniformly bounded rank and tame conductor, and their connected tensor square has no rank-one Kummer constituent after fixed boundary and Tate pieces are removed.

Even this is still a single-prime theorem. The cross-prime step would then require a defining-characteristic dispersion estimate for the traces

```text
J_{p,r} = b_r modulo p
```

as both `p` and `r` move. Standard auxiliary-ℓ Deligne-Katz theory does not automatically specialize to this diagonal defining-characteristic problem.

The advance over the fiberwise proposal is that the new object now type-checks:

```text
geometric parameter t
  is replaced by
Kummer character ω^(-r)
  through a genuine cohomological transform.
```

The cost is equally clear: the transformed object is not rank three, and `p | b_r` remains a trace-zero condition.

# Direct answers

## (1) Is there a known cohomological construction realizing `b_r mod p`?

**Yes, as a Frobenius supertrace on Kummer-twisted rigid or Dwork cohomology.** The exact object is `C_{p,r}` above. Under an additional middle-degree concentration theorem, it becomes a trace on one primitive `H³` group of the Straub threefold with Kummer coefficients.

The index `r` enters through a Kummer logarithmic exponent or a character-isotypic projector. It is not a point of the K3 base.

## (2) Can one build `Π^{ur}_{p,r}` by Cartier followed by Mellin projection?

One can build all of the following:

1. the exact coefficient Cartier extractor;
2. the Kummer idempotent `e_r^Kum`;
3. the derived Mellin Frobenius complex;
4. a p-adic Mellin lift of `b_r` obtained from unit-root Frobenius eigenvalues.

One cannot formally build a **zero-detecting unit-root projector**. Mellin-transforming the bare projector loses the Hasse eigenvalue; Mellin-transforming Frobenius times the projector gives a trace that can cancel. An indicator identity requires a new rank-one and no-cancellation theorem.

## (3) Is there precedent in Dwork's p-adic hypergeometric theory?

**Yes.** Kummer exponent parameters, twisted de Rham complexes, Dwork Frobenius, multiplicative convolution, Gauss sums, and GKZ hypergeometric complexes are exactly the standard machinery for this coefficient-versus-fiber distinction.

The missing Apéry result is not the existence of the Mellin transform. It is uniform structural and analytic control of the resulting defining-characteristic Frobenius traces as the prime and character vary together.
