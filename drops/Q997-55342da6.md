# Affine Apéry-lcm recurrence attack

## Verdict

**OPEN**

The affine coupling `m=n-r` does create a real recurrence interface, but the currently available division-free recurrence identities do not yet yield a nonzero characteristic-zero carrier of height `o(n)` divisible by the large part of

\[
A_n=\operatorname{lcm}_{0\le r<n/2}\gcd(n-r,b_r).
\]

The smallest missing lemma is:

> **Affine diagonal compression lemma.** For the Apéry recurrence with its actual coefficients, there exists a nonzero integer `C(n)` depending only on the diagonal `m+r=n` such that every sufficiently large prime-power contribution to `gcd(n-r,b_r)` divides `C(n)`, while `log |C(n)|=o(n)` after removing the already controlled small-prime and `m\le\sqrt n` parts.

No such carrier is currently proved.

---

## 1. Exact recurrence interface

Write the Apéry recurrence in cleared form

```
α(r)b_{r+1}+β(r)b_r+γ(r)b_{r-1}=0.
```

The coefficients `α,β,γ` are retained as integer polynomials.  For a divisor

```
d | (n-r),   d | b_r,
```

reduce the recurrence modulo `d` only after multiplying by the needed leading coefficients.  This gives a division-free transport relation

```
α(r)b_{r+1} ≡ -γ(r)b_{r-1}  (mod d)
```

with the middle term removed because `b_r≡0 (mod d)`.

The affine condition is then inserted as

```
m=n-r.
```

The key point is that the modulus travels along a moving diagonal, not along a fixed recurrence index.

---

## 2. Candidate continuant transport

A natural attempt is to define continuants `K_{r,n}` from the cleared recurrence and propagate

```
d | b_r
```

into a boundary expression

```
d | K_{r,n} b_n + L_{r,n} b_{n+1}.
```

This is valid as an individual transport statement.  It uses the actual Apéry recurrence and does not replace `b_r` by a generic positive sequence.

However, for the lcm over all `r`, the boundary expressions are not yet the same integer.  The coefficients `K_{r,n},L_{r,n}` retain dependence on `r`.

Thus the naive lcm-to-one-carrier step fails:

```
all d_r divide different boundary integers
```

and cannot be combined without a height estimate on the coefficient lattice.

---

## 3. Why the generic resultant family does not close

Consider the resultant candidate

```
Res_r( B_r , n-r )
```

where `B_r` denotes the recurrence-generated polynomial carrier for `b_r`.

The obstruction is that `b_r` is not a polynomial sequence in `r`; it is a holonomic sequence. Clearing denominators converts the problem into a determinant of recurrence transition matrices.

The determinant has the form

```
Π_{j=r}^{n-1} det(T_j),
```

where `T_j` is the two-dimensional recurrence transfer matrix.

Its logarithmic height accumulates linearly:

```
log |det carrier| = Ω(n)
```

unless there is additional cancellation specific to the affine endpoint.  The recurrence alone does not provide this cancellation.

---

## 4. Prime and prime-power audit

The lcm requires valuations:

```
v_p(A_n)=max_r min(v_p(n-r),v_p(b_r)).
```

A proof cannot multiply all divisors `d`.

For each prime:

1. choose the maximizing residue index `r_p`;
2. transport only that prime power;
3. bound overlap between different `p` separately.

The already controlled ranges are not affected:

- primes `p` below the cutoff remain in the small-prime error;
- indices with `m=n-r≤sqrt(n)` are already handled.

The open part is the large `m` and fresh prime contribution.

---

## 5. Exact finite verifier

A finite audit can test proposed carriers:

```python
from math import gcd, lcm

def apery_lcm_carrier(n, b):
    A = 1
    for r in range(n//2):
        A = lcm(A, gcd(n-r, b[r]))
    return A

for n in range(10,200):
    print(n, apery_lcm_carrier(n, apery_values(n)))
```

This checks only divisibility and height for finite `n`; it cannot establish asymptotic cancellation.

---

## 6. Scoped obstruction

A precise obstruction is available for the natural single-boundary continuant family:

> Any carrier obtained only by transporting each pair `(n-r,b_r)` independently to a boundary expression and taking products/lcms of those independent continuants cannot prove `log A_n=o(n)`.

Reason:

- the transported objects have independent `r`-dependent coefficient growth;
- their common boundary is two-dimensional (`b_n,b_{n+1}`);
- determinant/resultant elimination without new affine cancellation has linear height;
- the lcm does not permit replacing many prime-power constraints by a product.

This is an Apéry-specific obstruction, not a free CRT model.

---

## Conclusion

The affine diagonal is the correct surviving interface, but no new affine carrier has been constructed. The missing ingredient is an affine compression identity showing that the `r`-dependent continuant lattice has sublinear determinant height.
