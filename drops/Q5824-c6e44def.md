For each endpoint shape z_j, store:

```text

```

with the lifted flattening logarithms

```text
w0 = log(z) + p*pi*i

```

and verify Neumann's flattening conditions:

1. every edge has zero log-parameter sum;
2. parity sums vanish mod 2;
3. the filling longitude/meridian correction is included.

Without this data, a Rogers sum is only a numerical expression, not an extended Bloch element.

# Real dilogarithm reductions

The endpoint shapes are real:

```text
T < 0,
U,V,W > 1.
```

For real arguments the useful identities are:

```text
Li2(x)+Li2(1-x)=pi^2/6-log(x)log(1-x)

Li2(x)+Li2(1/x)= -pi^2/6 - 1/2 log(-x)^2
```

with branch conventions.

The shape relations suggest looking for transformations generated by:

```text
z -> 1-z
z -> 1/z
z -> z/(z-1)
```

because these preserve the Bloch five-term class.

A possible elementary endpoint reduction would therefore need exact proofs of relations such as:

```text
[T]+[U]+[V]+[W]
   = rational combination of
     [constants], [cross-ratios], or five-term reductions
```

No such exact relation is currently established.
