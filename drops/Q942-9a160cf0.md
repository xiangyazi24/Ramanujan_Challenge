# Q942: near-full signed Newton--Pade attack at fixed deficit s

## 1. Reduction of the exact system

Let d=H-s and let the primitive kernel vector be written in the repository normalization as

```
Q(x)=sum_{j=0}^{H-s} q_j x^j,
P(x)=sum_{j=0}^{s} u_j N_j(x),
```

where N_j are the integer-valued Newton basis polynomials. The equations

```
P(m)=A_m Q(m), 0<=m<=H
```

are not merely divisibility constraints: after eliminating the Q-coefficients they give s independent high divided differences

```
D_ell(u_0,...,u_s)=0,   1<=ell<=s.
```

The numerator vector therefore lies on a one-dimensional rational line in Z^{s+1}. The missing ingredient in a generic lattice argument is precisely this line condition.

## 2. The fixed-s case

For fixed s the exact cofactor construction gives

```
u_j = C_j(H)/gcd(C_0(H),...,C_s(H)) .
```

The C_j are signed maximal minors of the divided-difference matrix. The primitive evaluation is therefore

```
P(3H+1)= (sum_j C_j(H) N_j(3H+1))/gcd(C_0,...,C_s).
```

The denominator gcd is the Smith content, not an arbitrary polynomial gcd.

A linear lower bound would follow from the lemma:

```
log |sum_j C_j(H)N_j(3H+1)| - log gcd(C_0,...,C_s)
>= c_s H-O_s(log H).
```

At present this lemma is the exact remaining Apéry input.

## 3. Why generic divisibility is insufficient

The relations

```
A_m | P(m)
```

alone admit many small integer-valued polynomials. They do not impose the divided-difference line. Thus a polynomial-divisibility lattice estimate cannot prove the claim.

The required estimate must use the signed Apéry moments appearing in the eliminated equations.

## 4. s=2 explicit form

For s=2 write

```
P(x)=u_0+u_1 x+u_2*x(x-1)/2.
```

There are two exact constraints:

```
D_1(u)=0,
D_2(u)=0.
```

Hence

```
(u_0,u_1,u_2)=lambda*(C_0,C_1,C_2)/g
```

with

```
g=gcd(C_0,C_1,C_2).
```

The target becomes the explicit determinant estimate

```
|P(3H+1)| = |lambda|/g * |det(M_H)|,
```

where M_H is the 3-column augmented divided-difference matrix. A proof of

```
log|det(M_H)|-log g >= c_2 H-O(log H)
```

would settle s=2.

## 5. Sign and cancellation issue

The possible cancellation

```
P(3H+1)=0
```

cannot be excluded by node divisibility. It requires a strict sign-regularity statement for the reciprocal Apéry moment matrix. A sufficient statement is:

For the signed divided-difference matrix V_H,

```
(-1)^sigma det(V_H[I,J]) > 0
```

for all relevant contiguous minors.

This would imply the cofactor sum has fixed sign and no cancellation.

## 7. Precise remaining lemma

The weakest sufficient Apéry statement is:

**Primitive reciprocal-moment growth lemma.** For each fixed s there exist c_s>0 and C_s such that the primitive cofactor vector satisfies

```
log |sum_j C_j(H)N_j(3H+1)| >= c_s H-C_s log H
```

and

```
log gcd(C_0(H),...,C_s(H))=O_s(log H).
```

This is exactly the point where total positivity or an Apéry-specific gcd theorem is needed.

Conclusion: the near-full fixed-deficit route is not excluded, but it is reduced to a concrete primitive cofactor growth lemma. No transition theorem for varying s follows from this argument.
