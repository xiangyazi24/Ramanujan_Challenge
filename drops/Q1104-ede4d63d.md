# Q1104 audit: the proposed 2-adic upper witnesses

## Verdict

The witness strategy is structurally plausible, but the stated proof is not complete as written. The first failure is not the all-ones case. The problematic point is the claimed uniform six-top-bit implication in the `r >= 4` branch: the expression for the shifted witness index does not cover all admissible low parts `q`, because the proposed `j=q-H/4` can be negative.

The correction is that the large-run witness must be split according to whether `q >= H/4`. The stated formula is valid only in the latter range; the former range requires a different witness.

## 1. Endpoint checks

Let `H=2^k`, `n=H+q`, `0<=q<H`, and `M=floor(n/2)`.

### Case (i): n=2H-1

Here

```
M=H-1,
j=0.
```

The endpoint condition `j<M` holds for every `H>1`.

Also

```
L_0 = C(2H-1,0) C(2H-2,H-2).
```

Since

```
v2(C(2H-2,H-2))=0
```

by the standard Kummer carry criterion (the two summands have disjoint binary carries), `L_0` is odd.

Therefore this witness reduces the valuation to

```
v2(b_(2H-1)-b_0).
```

The mod-64 rule gives the required residue only after checking the final four bits. It is not a consequence of the recurrence alone.

## 2. Case r<=3

The suggested witness is `j=q`.

The endpoint condition is:

```
q < floor((H+q)/2).
```

This is equivalent to

```
q < H,
```

so it always holds.

For this branch the two binomial valuations reduce to Kummer additions with no carries. Hence the combinatorial coefficient contributes zero 2-adic valuation.

The remaining claim is exactly

```
v2(b_(H+q)-b_q)=2+r.
```

This is not proved merely by the mod-64 recurrence. The recurrence gives a four-bit automaton, but one still needs an induction showing that the leading-one run survives the subtraction. The finite table is evidence, not the proof.

## 3. Case r>=4: failure of the stated witness

The proposed witness is

```
j=q-H/4.
```

The condition `j>=0` is necessary because a binomial index cannot be negative.

For example, with

```
H=16,
q=0b011110=30
```

(the analogous low part after normalizing the leading bit), the expression can leave the legal interval. More generally whenever

```
q < H/4,
```

we have

```
j=q-H/4<0.
```

Therefore the claimed witness is not a universal witness for the entire `r>=4` class.

The calculation

```
h=H/4-1+u
c=H-u
h+c=H+H/4-1
```

is arithmetically correct only after the missing domain condition is imposed. It does not prove existence of the required binomial term for all `q`.

## 4. Popcount identity

For the valid subcase `q>=H/4`, write

```
t=ceil(q/2),
u=H/2-t.
```

Then the second Kummer pair is

```
h=H/4-1+u,
c=H-u.
```

The sum is

```
h+c=H+H/4-1.
```

Its binary form has the low `k-2` bits equal to ones and the two top positions separated. Hence the carry count is two. This establishes the claimed coefficient valuation for this subcase.

It does not establish the full branch.

## 5. Mod-64 rule

The local rule

```
b_(2m+e)=c_e[m mod 8] b_m
```

with

```
c0=[1,53,33,37,1,21,33,5]
c1=[5,33,21,1,37,33,53,1]
```

is sufficient to compute residues recursively. However, an automaton proof must specify the state invariant. The missing statement is a theorem of the form:

```
For every prefix state, the residue of b_(H+q)-b_j
mod 64 depends only on the retained top-window state.
```

Without this induction the six-bit table is only a finite verification.

## 6. Corrected theorem shape

The strongest statement supported by the arithmetic is:

* all-one numbers: the `j=0` witness is valid and gives the claimed bound once the mod-64 residue lemma is proved;
* leading run `r<=3`: the `j=q` witness is valid, but the valuation identity needs a binary induction lemma;
* leading run `r>=4`: the proposed `j=q-H/4` witness works only for `q>=H/4`; the remaining range needs another witness.

Thus the claimed lower bound is not disproved, but the supplied upper-witness proof has a gap.

## 7. Required missing lemma

A complete proof needs an explicit p-adic automaton lemma:

For every binary prefix state `s`, there exists a legal witness `j(s)` satisfying `j<M` such that

```
v2(L_j)=0                    (small-run branch)
```

or

```
v2(L_j)=2                   (large-run branch)
```

and the residue automaton gives the matching Franel difference valuation.

The current argument proves only the arithmetic of selected witnesses, not their total coverage.

## Conclusion

The first false statement is the universal use of

```
j=q-H/4
```

for all `r>=4` cases. The missing condition is `q>=H/4`. The Kummer calculation itself is correct when the witness exists. No finite scan is needed to find this failure; it follows directly from the endpoint inequality `j>=0`.
