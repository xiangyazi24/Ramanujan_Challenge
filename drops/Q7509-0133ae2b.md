# Research audit: the Apéry invariant \(J_n\)

## Executive verdict

The proposed prime-by-prime law is **false as literally stated**, because it omits the necessary endpoint condition \(p\le n\).  For \(p>n\), one has \(p\nmid L_n\), so \(p\nmid J_n\), while the first residue condition can certainly hold; for example \(n=2,p=73\), since \(b_2=73\).  Moreover \(q=0\) there, so \(U_1(q)\) is outside the stated domain.

After the necessary repair
\[
\sqrt n<p\le n,
\]
the law is exact:
\[
\boxed{
 p\mid J_n
 \iff
 \bigl[p\mid b_r\bigr]
 \ \lor\ 
 \bigl[p\mid b_q\text{ and }p\mid U_1(q)\bigr].
}
\tag{1}
\]
It follows from nothing deeper than Apéry--Lucas and a direct reduction of the convolution defining \(U_1\).

The second, quotient-only branch is genuinely cheap.  If
\[
\mathcal F_n
 :=\{p:\sqrt n<p\le n,\ p\nmid b_r,\ p\mid b_q,\ p\mid U_1(q)\},
\]
then
\[
\boxed{
\sum_{p\in\mathcal F_n}\log p=O(n^{2/3}).
}
\tag{2}
\]
For fixed quotient \(q\), the exact integer controlling the product of these primes is
\[
\boxed{D_q:=\gcd(b_q,U_1(q)).}
\tag{3}
\]
Indeed the product of all distinct false-branch primes with that quotient divides \(\operatorname{rad}(D_q)\), hence divides \(D_q\).

More importantly, if
\[
T_n:=\prod_{\substack{\sqrt n<p\le n\\p\mid b_{\,n\bmod p}}}p,
\tag{4}
\]
then the corrected law and the small-prime estimate give the theorem
\[
\boxed{
\log J_n=\log T_n+O(n^{2/3}).
}
\tag{5}
\]
Thus
\[
\boxed{\log J_n=o(n)\iff \log T_n=o(n).}
\tag{6}
\]
So the new intersection with \(U_1(n)\) cleanly removes the quotient-only Lucas branch at sublinear cost, but it does **not** bypass the existing pointwise leading-residue obstruction.  This is the main mathematical conclusion of the audit.

For characteristic-zero constructions, I do **not** obtain an explicit nonzero integer \(H_n\) with
\[
J_n\mid H_n,\qquad \log|H_n|=o(n).
\]
There is a precise reason this is hard: every such \(H_n\) would satisfy \(T_n\mid H_n\), hence would already prove the unresolved estimate \(\log T_n=o(n)\).  The extra congruence supplied by \(U_1\) is locally automatic on every true-residue prime \(p\mid b_r\).

Growing moments do give a beautiful exact Vandermonde identity.  With
\[
S_s(q)=\sum_{a=1}^q\frac{b_{q-a}}{a^s}
\]
and
\[
Q_q(x):=x\prod_{a=1}^{q-1}(ax-1)=\sum_{s=1}^q A_{q,s}x^s,
\]
one has
\[
\boxed{
\sum_{s=1}^q A_{q,s}L_q^{q-s}U_s(q)
=(-1)^{q-1}(q-1)!\left(\frac{L_q}{q}\right)^q.
}
\tag{7}
\]
The right side is a **nonzero integer**, has exact logarithm
\[
\log((q-1)!)+q\log(L_q/q),
\tag{8}
\]
and hence logarithmic height \(O(q^2)\).  All of its prime divisors are at most \(q\).  Consequently the first \(q\) moments annihilate the quotient false branch for a prime \(p>q\).  But this is a statement about a **stronger gcd** containing all those moments; that stronger gcd divides \(J_n\), rather than containing it.  It is not an upper bound for \(J_n\).

The distinction is concrete: \(5\mid J_{15}\), but \(5\nmid U_2(15)\).  So higher moments cannot simply be adjoined to a characteristic-zero carrier for \(J_n\).

# 1. Exact top-prime law

Recall
\[
U_1(n)=L_nR_n
=\sum_{k=1}^n b_{n-k}\frac{L_n}{k}\in\mathbb Z.
\tag{9}
\]
Let \(p\) be prime and suppose
\[
\sqrt n<p\le n,
\qquad n=qp+r,
\qquad 0\le r<p.
\tag{10}
\]
Then
\[
1\le q<p,
\qquad p^2>n,
\qquad v_p(L_n)=1.
\tag{11}
\]
Put
\[
M:=\frac{L_n}{p}.
\tag{12}
\]
Then \(p\nmid M\).

## 1.1 Apéry--Lucas for \(b_n\)

Apéry--Lucas gives
\[
b_{qp+r}\equiv b_qb_r\pmod p,
\tag{13}
\]
so
\[
p\mid b_n
\iff
p\mid b_qb_r.
\tag{14}
\]

## 1.2 Direct convolution reduction for \(U_1(n)\)

Reduce (9) modulo \(p\).

If \(p\nmid k\), then \(L_n/k\) is still divisible by \(p\), because \(v_p(L_n)=1\).  Thus every such term vanishes modulo \(p\).

The only surviving terms have \(k=ap\), where \(1\le a\le q\).  Hence
\[
\begin{aligned}
U_1(n)
&\equiv
\sum_{a=1}^q
b_{n-ap}\frac{L_n}{ap}
\pmod p\\
&=
\sum_{a=1}^q
b_{(q-a)p+r}\frac{M}{a}
\pmod p.
\end{aligned}
\tag{15}
\]
For \(0\le q-a<p\), Apéry--Lucas gives
\[
b_{(q-a)p+r}\equiv b_{q-a}b_r\pmod p.
\tag{16}
\]
Also, because \(ap\le n\), one has \(ap\mid L_n\), hence \(a\mid M\) for every \(1\le a\le q\).  Therefore
\[
L_q\mid M.
\tag{17}
\]
Set
\[
C_{n,p}:=\frac{M}{L_q}
=\frac{L_n/p}{L_q}\in\mathbb Z.
\tag{18}
\]
Since \(q<p\), \(p\nmid L_q\), and since \(p\nmid M\),
\[
p\nmid C_{n,p}.
\tag{19}
\]
Now (15)--(18) yield the exact modular convolution law
\[
\boxed{
U_1(n)\equiv C_{n,p}\,b_r\,U_1(q)\pmod p.
}
\tag{20}
\]

## 1.3 Logical combination

Because \(p\le n\), we already know \(p\mid L_n\).  Thus
\[
p\mid J_n
\iff
p\mid b_n\ \text{and}\ p\mid U_1(n).
\tag{21}
\]
Using (13), (20), and the fact that \(C_{n,p}\) is a unit modulo \(p\), this is
\[
(b_qb_r\equiv0)\ \text{and}\ (b_rU_1(q)\equiv0)\pmod p.
\tag{22}
\]
Writing \(A=(p\mid b_r)\), \(B=(p\mid b_q)\), and \(D=(p\mid U_1(q))\), this is
\[
(A\lor B)\land(A\lor D)
=A\lor(B\land D).
\tag{23}
\]
Therefore
\[
\boxed{
 p\mid J_n
 \iff
 \bigl[p\mid b_r\bigr]
 \lor
 \bigl[p\mid b_q\text{ and }p\mid U_1(q)\bigr].
}
\tag{24}
\]
This proves the repaired law.

## 1.4 Endpoint audit

All endpoints matter.

### (a) \(p>n\): the original statement fails

Then \(p\nmid L_n\), hence \(p\nmid J_n\).  But the first residue condition can hold.  For example
\[
n=2,\qquad p=73,\qquad b_2=73,
\]
so \(p>\sqrt2\), \(r=2\), and \(p\mid b_r\), while \(p\nmid J_2\) because \(73\nmid L_2=2\).

Also \(q=0\) in this range, whereas the problem defined \(U_1(q)\) only for positive index.  Thus \(p\le n\) is both mathematically necessary and needed to make the proposed right side uniformly well-defined.

### (b) \(p=n\), with \(n\) prime

Then \(q=1,r=0\).  Since
\[
b_0=1,\qquad U_1(1)=1,
\]
both branches in (24) are false.  This correctly handles, for example, the fact that \(5\mid b_1\) does not cause \(5\mid J_5\): the required factor \(5\mid U_1(1)\) is absent.

### (c) \(q=1\)

Again \(U_1(1)=1\), so the quotient-only branch is impossible.  Only the residue branch \(p\mid b_r\) can occur.

### (d) \(p=\sqrt n\)

This is deliberately excluded.  If \(n=p^2\), then \(v_p(L_n)=2\), \(q=p\) is no longer a base-\(p\) digit, and the simple one-surviving-layer convolution argument above changes.  The strict inequality \(p>\sqrt n\) is essential.

### (e) small \(n\)

For \(n=1\), the repaired interval \(\sqrt n<p\le n\) is empty.  For \(n=2\), its only prime is \(p=2\), where \(q=1,r=0\); (24) gives no divisibility, consistent with
\[
J_2=\gcd(2,73,11)=1.
\]

# 2. The quotient-only branch has logarithmic mass \(O(n^{2/3})\)

Define the false branch
\[
\mathcal F_n
:=\left\{
 p:\sqrt n<p\le n,\ p\nmid b_r,\ p\mid b_q,\ p\mid U_1(q)
\right\}.
\tag{25}
\]
For fixed \(q\), let
\[
\mathcal F_{n,q}
:=\{p\in\mathcal F_n:\lfloor n/p\rfloor=q\}.
\tag{26}
\]
The exact fixed-\(q\) carrier is
\[
D_q:=\gcd(b_q,U_1(q))>0.
\tag{27}
\]
Every \(p\in\mathcal F_{n,q}\) divides \(D_q\).  Since the primes are distinct,
\[
\boxed{
P_{n,q}:=\prod_{p\in\mathcal F_{n,q}}p
\mid \operatorname{rad}(D_q)\mid D_q.
}
\tag{28}
\]
This is the precise answer to the requested fixed-quotient product question.

A crude exponential bound on \(b_q\) is enough.  For \(0\le k\le q\),
\[
\binom qk\le2^q,
\qquad
\binom{q+k}k\le2^{q+k}\le2^{2q}.
\tag{29}
\]
Thus each Apéry summand is at most \(64^q\), and
\[
1\le b_q\le(q+1)64^q.
\tag{30}
\]
Since \(D_q\le b_q\),
\[
\log D_q\le q\log64+\log(q+1)=O(q).
\tag{31}
\]

Choose
\[
Q:=\lfloor n^{1/3}\rfloor
\]
for large \(n\); finitely many small \(n\) can be absorbed into the constant.

## 2.1 Small quotients \(q\le Q\)

By (28)--(31),
\[
\begin{aligned}
\sum_{\substack{p\in\mathcal F_n\\q(p)\le Q}}\log p
&\le \sum_{q\le Q}\log D_q\\
&=O\left(\sum_{q\le Q}q\right)\\
&=O(Q^2)
=O(n^{2/3}).
\end{aligned}
\tag{32}
\]

## 2.2 Large quotients \(q>Q\)

If \(q=\lfloor n/p\rfloor\ge Q+1\), then
\[
p\le\frac{n}{Q+1}.
\tag{33}
\]
Therefore
\[
\sum_{\substack{p\in\mathcal F_n\\q(p)>Q}}\log p
\le \vartheta\left(\frac{n}{Q+1}\right),
\tag{34}
\]
where \(\vartheta(x)=\sum_{p\le x}\log p\).

The elementary Chebyshev bound \(\vartheta(x)=O(x)\) is enough.  One quick proof is that every prime \(m<p\le2m\) divides \(\binom{2m}{m}\), so
\[
\vartheta(2m)-\vartheta(m)
\le\log\binom{2m}{m}
\le2m\log2,
\tag{35}
\]
and dyadic summation gives \(\vartheta(x)=O(x)\).

Hence
\[
\sum_{\substack{p\in\mathcal F_n\\q(p)>Q}}\log p
=O(n/Q)
=O(n^{2/3}).
\tag{36}
\]
Combining (32) and (36) proves (2).

### What the new intersection actually improves

For the old top-prime Lucas decomposition of \(\gcd(L_n,b_n)\), the quotient branch at fixed \(q\) was merely constrained by \(p\mid b_q\).  The new invariant refines that fixed-\(q\) carrier from \(b_q\) to
\[
D_q=\gcd(b_q,U_1(q)).
\]
This can be a strong finite reduction, but the asymptotic quotient-splitting argument already has the needed \(O(q)\) height from \(b_q\), so the global bottleneck remains elsewhere.

# 3. Exact reduction of \(J_n\) to the true residue branch

Define
\[
T_n:=\prod_{\substack{\sqrt n<p\le n\\p\mid b_{n\bmod p}}}p.
\tag{37}
\]
For every prime in this product, (24) gives \(p\mid J_n\).  Conversely, every top prime dividing \(J_n\) but not \(T_n\) lies in \(\mathcal F_n\).  Since \(p^2>n\), every top prime occurs in \(L_n\), hence in \(J_n\), with exponent at most one.

For the small-prime part,
\[
\begin{aligned}
\sum_{p\le\sqrt n}v_p(J_n)\log p
&\le
\sum_{p\le\sqrt n}v_p(L_n)\log p\\
&\le
\sum_{p\le\sqrt n}\log n\\
&\le \sqrt n\log n
=O(n^{2/3}).
\end{aligned}
\tag{38}
\]
The final estimate is for large \(n\), with small \(n\) absorbed in the constant.

Together with (2),
\[
0\le \log J_n-\log T_n
\le O(n^{2/3}),
\tag{39}
\]
which is (5).

This gives an exact interpretation of what \(U_1\) has achieved:

> **Theorem.**  Up to \(O(n^{2/3})\) logarithmic mass, \(J_n\) is exactly the product of the top primes for which the base-\(p\) remainder itself is an Apéry zero.

In particular, the quotient-only estimate is a useful theorem, but it is **not** a theorem that \(\log J_n=o(n)\).  The latter is equivalent to the still-unresolved estimate
\[
\boxed{
\sum_{\substack{\sqrt n<p\le n\\p\mid b_{n\bmod p}}}\log p=o(n).
}
\tag{40}
\]

# 4. General inverse moments: exact modular law and a counterexample to using them as \(J_n\)-carriers

For \(s\ge1\), define
\[
U_s(n)
:=\sum_{k=1}^n b_{n-k}\left(\frac{L_n}{k}\right)^s
=L_n^sS_s(n),
\qquad
S_s(n):=\sum_{k=1}^n\frac{b_{n-k}}{k^s}.
\tag{41}
\]
The same surviving-term argument used for \(U_1\) gives, for \(\sqrt n<p\le n\),
\[
\boxed{
U_s(n)\equiv C_{n,p}^{\,s}b_rU_s(q)\pmod p,
}
\tag{42}
\]
where \(C_{n,p}=(L_n/p)/L_q\) is a unit modulo \(p\).

Thus every true-residue prime \(p\mid b_r\) automatically divides **every** \(U_s(n)\).  Higher moments have no leverage at all against the hard branch at this mod-\(p\) level.

More seriously, \(J_n\) does not in general divide \(U_s(n)\) for \(s\ge2\).

## 4.1 Explicit counterexample: \((n,p)=(15,5)\)

The first Apéry values are
\[
b_0=1,\quad b_1=5,\quad b_2=73,\quad b_3=1445.
\tag{43}
\]
Since \(L_3=6\),
\[
\begin{aligned}
U_1(3)
&=73\cdot6+5\cdot3+1\cdot2\\
&=455,
\end{aligned}
\tag{44}
\]
so
\[
5\mid b_3,\qquad 5\mid U_1(3).
\tag{45}
\]
But
\[
\begin{aligned}
U_2(3)
&=73\cdot6^2+5\cdot3^2+1\cdot2^2\\
&=2677\\
&\equiv2\pmod5.
\end{aligned}
\tag{46}
\]
Now take \(n=15,p=5\).  Then
\[
15=3\cdot5+0,
\qquad p>\sqrt{15},
\tag{47}
\]
and
\[
L_{15}=360360,
\qquad
C_{15,5}=\frac{(L_{15}/5)}{L_3}=12012\equiv2\pmod5.
\tag{48}
\]
Apéry--Lucas and (20) give
\[
5\mid b_{15},\qquad 5\mid U_1(15),
\tag{49}
\]
so
\[
5\mid J_{15}.
\tag{50}
\]
But by (42),
\[
U_2(15)
\equiv C_{15,5}^2 b_0U_2(3)
\equiv2^2\cdot1\cdot2
\equiv3\pmod5.
\tag{51}
\]
Therefore
\[
\boxed{5\mid J_{15}\quad\text{but}\quad5\nmid U_2(15).}
\tag{52}
\]

This is an exact obstruction to the tempting maneuver
\[
J_n\stackrel{?}{\mid}\gcd(U_1(n),U_2(n),\ldots).
\]
The divisibility direction is the reverse: adding moments produces a **smaller** invariant.

# 5. The growing-moment Vandermonde identity

Let
\[
S_s(q)=\sum_{a=1}^q\frac{b_{q-a}}{a^s}.
\tag{53}
\]
Consider
\[
P_q(x):=x\prod_{a=1}^{q-1}\left(x-\frac1a\right).
\tag{54}
\]
Then
\[
P_q(1/a)=0\qquad(1\le a<q),
\tag{55}
\]
while
\[
\begin{aligned}
P_q(1/q)
&=\frac1q\prod_{a=1}^{q-1}\left(\frac1q-\frac1a\right)\\
&=\frac1q\prod_{a=1}^{q-1}\frac{a-q}{qa}\\
&=\frac{(-1)^{q-1}}{q^q}.
\end{aligned}
\tag{56}
\]
If
\[
P_q(x)=\sum_{s=1}^q c_{q,s}x^s,
\tag{57}
\]
then, because \(b_0=1\),
\[
\boxed{
\sum_{s=1}^q c_{q,s}S_s(q)
=\frac{(-1)^{q-1}}{q^q}.
}
\tag{58}
\]
This is the requested isolation identity.

## 5.1 Exact integral clearing

A natural exact integral clearing is
\[
Q_q(x):=(q-1)!P_q(x)
=x\prod_{a=1}^{q-1}(ax-1)
=\sum_{s=1}^q A_{q,s}x^s,
\tag{59}
\]
where
\[
A_{q,s}=(-1)^{q-s}e_{s-1}(1,2,\ldots,q-1)\in\mathbb Z.
\tag{60}
\]
Then
\[
\boxed{
\sum_{s=1}^q A_{q,s}S_s(q)
=(-1)^{q-1}\frac{(q-1)!}{q^q}.
}
\tag{61}
\]
Using \(U_s(q)=L_q^sS_s(q)\) and multiplying by \(L_q^q\) gives the exact integer identity
\[
\boxed{
\sum_{s=1}^q A_{q,s}L_q^{q-s}U_s(q)
=V_q,
}
\tag{62}
\]
with
\[
\boxed{
V_q:=(-1)^{q-1}(q-1)!\left(\frac{L_q}{q}\right)^q\ne0.
}
\tag{63}
\]
The exact logarithmic height of the right side is
\[
\boxed{
\log|V_q|
=\log((q-1)!)+q\bigl(\log L_q-\log q\bigr).
}
\tag{64}
\]

An elementary bound \(\log L_q=O(q)\) follows from the same Chebyshev estimate used above: indeed
\[
\log L_q
=\sum_{a\ge1}\vartheta(q^{1/a})
=O(q)+O(\sqrt q\log q)
=O(q).
\tag{65}
\]
Hence
\[
\boxed{\log|V_q|=O(q^2).}
\tag{66}
\]

There is an even stronger structural fact: every prime divisor of \(V_q\) is at most \(q\), because both \((q-1)!\) and \(L_q/q\) are composed only of primes \(\le q\).

## 5.2 What the identity really proves

Suppose \(\sqrt n<p\le n\), so \(p>q\), and suppose \(p\nmid b_r\).  If one knew
\[
p\mid U_s(n)\qquad(1\le s\le q),
\tag{67}
\]
then (42), with \(C_{n,p}b_r\) invertible modulo \(p\), would imply
\[
p\mid U_s(q)\qquad(1\le s\le q).
\tag{68}
\]
Identity (62) would then force \(p\mid V_q\), impossible because every prime factor of \(V_q\) is at most \(q<p\).

Therefore:

> **Vandermonde false-branch theorem.**  For a top prime \(p>\sqrt n\), the intersection of \(b_n\) with the first \(q=\lfloor n/p\rfloor\) inverse moments has no quotient-only branch.  Any such prime must satisfy \(p\mid b_r\).

For example one may define the stronger invariant
\[
G_{n,m}:=\gcd(L_n,b_n,U_1(n),\ldots,U_m(n)).
\tag{69}
\]
If \(m\ge\lfloor\sqrt n\rfloor\), then every top prime of \(G_{n,m}\) is in the true-residue product \(T_n\).

But
\[
G_{n,m}\mid J_n,
\tag{70}
\]
not the other way around.  Thus (62) is **not** a characteristic-zero upper bound for \(J_n\).

The concrete \(q=3,p=5\) example makes this completely visible.  Here
\[
b_3=1445,\qquad U_1(3)=455,
\]
are both divisible by \(5\), but
\[
V_3=2!\left(\frac{6}{3}\right)^3=16
\]
is not divisible by \(5\).  The missing divisibility is supplied precisely by the higher moments, and \(U_2(3)\not\equiv0\pmod5\).

So the Vandermonde construction kills the quotient false branch **only after strengthening the invariant**.  It does not bound \(J_n\).

# 6. Exact-zero moment vectors and the LLL/pigeonhole trap

The same interpolation viewpoint also exposes a serious exact-zero issue.

Define
\[
Z_q(x):=x\prod_{a=1}^{q}(ax-1)
=\sum_{s=1}^{q+1}B_{q,s}x^s,
\qquad B_{q,s}\in\mathbb Z.
\tag{71}
\]
For every \(1\le a\le q\),
\[
Z_q(1/a)=0.
\tag{72}
\]
Therefore
\[
\boxed{
\sum_{s=1}^{q+1}B_{q,s}S_s(q)=0.
}
\tag{73}
\]
Equivalently, after multiplying by \(L_q^{q+1}\),
\[
\boxed{
\sum_{s=1}^{q+1}
B_{q,s}L_q^{q+1-s}U_s(q)=0.
}
\tag{74}
\]
This is an **exact integer zero vector**, not merely a numerically small combination.

That is fatal to a naive pigeonhole/LLL argument.  In general, if
\[
x_0,\ldots,x_m\in g\mathbb Z,
\]
then every integer linear combination
\[
y=\sum_i c_ix_i
\]
is either exactly zero or satisfies
\[
|y|\ge g.
\tag{75}
\]
Thus a geometry-of-numbers argument that produces a very small combination proves an upper bound on \(g\) only after it certifies
\[
y\ne0.
\tag{76}
\]
If the evaluation lattice has an exact kernel, the shortest vectors can live entirely in that kernel.

For growing moment families this is not a toy pathology: (74) constructs such a kernel explicitly.  Any LLL experiment must therefore output both the coefficient vector and its **exact evaluated integer**, and must reject zero evaluations before interpreting the size as a gcd bound.

# 7. Characteristic-zero audit of \(b_n\) together with \(R_n\)

The basic observation is simple but important.  Since
\[
J_n\mid b_n,
\qquad
J_n\mid U_1(n),
\tag{77}
\]
every integer combination
\[
A_nb_n+B_nU_1(n)
\tag{78}
\]
is an upper carrier for \(J_n\), provided it is nonzero.  The problem is to make such a carrier subexponential in absolute value and to certify nonvanishing.

The separate trivial carriers have only exponential-scale bounds:
\[
\log b_n=O(n),
\qquad
\log U_1(n)=O(n).
\tag{79}
\]
For the second estimate, use \(\log L_n=O(n)\), (30), and
\[
R_n\le H_n\max_{m<n}b_m.
\]
Thus simply intersecting the two integers does not by itself produce a sublinear-height Bézout witness.

## 7.1 Fixed-width determinants / Casoratians

For \(1\le j\le n\), define the denominator-cleared minor
\[
\boxed{
C_{n,j}
:=L_n\bigl(b_nR_{n-j}-b_{n-j}R_n\bigr).
}
\tag{80}
\]
Because denominators of \(R_{n-j}\) divide \(L_{n-j}\mid L_n\), this is an integer.  Rewriting,
\[
C_{n,j}
=b_n\bigl(L_nR_{n-j}\bigr)-b_{n-j}U_1(n),
\tag{81}
\]
so
\[
\boxed{J_n\mid C_{n,j}.}
\tag{82}
\]
This is a genuine family of characteristic-zero carriers whenever the chosen minor is nonzero.

There are, however, two independent problems.

### Nonzero certification

The \(j=0\) minor is identically zero.  For a fixed width \(j\ge1\), the fact that a determinant looks nontrivial does not itself prove that it is nonzero for every \(n\).  One can avoid total ambiguity by taking \(j=n\): since \(R_0=0\), \(b_0=1\),
\[
C_{n,n}=-U_1(n)\ne0,
\tag{83}
\]
but this is merely the original exponential-size carrier and is not fixed-width.

A finite scan of adjacent minors can suggest nonvanishing or a small gcd, but a production proof needs a uniform exact nonvanishing statement or a rule selecting one certified nonzero minor.

### Height

The raw bound from (30), \(\log L_n=O(n)\), and \(R_m\le H_m\max_{t<m}b_t\) gives
\[
\boxed{\log|C_{n,j}|=O(n)}
\tag{84}
\]
for every fixed \(j\) whenever \(C_{n,j}\ne0\).  This is still exponential size.  Any improvement to \(o(n)\) must come from a proved cancellation, not from the determinant formalism alone.

### Why the ordinary Casoratian mechanism does not close

The harmonic convolution \(R_n\) is not a second solution of the same Apéry recurrence.  This can be seen at the first nontrivial index.  We have
\[
R_0=0,\qquad R_1=1,\qquad R_2=\frac{11}{2},
\]
and the Apéry operator at \(n=2\) gives
\[
2^3R_2-(3)(39)R_1+R_0
=44-117
=-73\ne0.
\tag{85}
\]
So the usual two-solution Casoratian conservation/product formula is unavailable.

There is no claim here that \(R_n\) is non-holonomic.  In fact, if
\[
B(z)=\sum_{n\ge0}b_nz^n,
\]
then
\[
\sum_{n\ge0}R_nz^n
=B(z)\bigl(-\log(1-z)\bigr).
\tag{86}
\]
For fixed moment order this does lead to fixed-order differential/recurrence relations after elimination.  The obstruction is narrower: those relations are not the same homogeneous Apéry recurrence, and the naive fixed-width resultants/minors obtained from them retain exponential-height Apéry data.  I do not see a uniform resultant identity whose **nonzero** right side has logarithm \(o(n)\).

If one takes several nonzero minors,
\[
\gcd(C_{n,1},\ldots,C_{n,w})
\]
is again divisible by \(J_n\).  This is a legitimate experimental target and is close in spirit to the repository's adjacent-minor scans.  But proving that this gcd has sublinear logarithmic height is exactly an additional theorem; the finite observations do not supply it.

# 8. Fixed and growing inverse moments as characteristic-zero carriers

For fixed \(s\), a crude bound gives
\[
|U_s(n)|
\le n\,(n+1)64^nL_n^s,
\tag{87}
\]
hence
\[
\log|U_s(n)|=O_s(n).
\tag{88}
\]
So a fixed moment by itself is again only an exponential-size integer.

For growing \(s\), the raw height gets worse:
\[
\log|U_s(n)|=O((s+1)n)
\tag{89}
\]
under the same elementary bounds.  A growing-dimensional construction must therefore exploit cancellation very aggressively.

But for the original \(J_n\) there is a more basic divisibility obstruction: by (52), \(J_n\nmid U_2(n)\) in general.  Thus an identity involving \(U_2,U_3,\dots\) is not automatically an upper carrier for \(J_n\).

One can certainly study
\[
G_{n,m}=\gcd(L_n,b_n,U_1(n),\ldots,U_m(n)),
\]
and the Vandermonde identity proves that sufficiently many moments remove the top quotient branch of **that** invariant.  But
\[
G_{n,m}\mid J_n,
\]
so a small upper bound for \(G_{n,m}\) says nothing in the needed direction about \(J_n\).

This is the key direction-of-divisibility check that any growing-moment proposal must pass.

# 9. Pigeonhole / LLL combinations

A generic lattice strategy starts from integers all divisible by \(J_n\), such as \(b_n,U_1(n)\), or the determinant carriers (80), and tries to find a short integer coefficient vector giving a small linear combination.

There are two mandatory proof obligations:

1. **integrality/divisibility:** every input coordinate must actually be divisible by \(J_n\);
2. **nonzero output:** the selected small combination must be proved nonzero.

The second is not cosmetic.  Suppose all inputs are multiples of an unknown integer \(g\).  Then no nonzero combination can have absolute value below \(g\).  If pigeonhole or LLL seems to produce something much smaller, the possibility that it produced an exact relation must be excluded.

For moment families, (74) gives exact relations explicitly once the dimension reaches the support size.  For determinant/resultant families, algebraic recurrence relations can likewise create exact dependencies.  Therefore a dimension-count or Minkowski estimate by itself is not a gcd bound.

A valid LLL-based theorem would need, at minimum:

- an explicitly defined integral lattice;
- a determinant/covolume estimate;
- a coefficient/height estimate giving a subexponential evaluated integer;
- and an independent exact argument that the chosen evaluation is nonzero.

The repository's current numerical moment/minor/Padé/Newton scripts are useful for discovering candidates, but they do not discharge this last step.

# 10. Precise obstruction to a standard subexponential \(H_n\)

The strongest clean statement I can justify is the following.

> **Carrier obstruction.**  Let \(H_n\ne0\) be any integer with \(J_n\mid H_n\).  Then
> \[
> T_n\mid H_n.
> \]
> Consequently
> \[
> \log|H_n|\ge\log T_n.
> \]
> Therefore an explicit construction satisfying \(\log|H_n|=o(n)\) would, by itself, prove the unresolved pointwise residue-prime estimate (40).

This is not a philosophical objection; it is an exact divisibility consequence of the corrected modular law.

Moreover, on every prime in \(T_n\),
\[
p\mid b_r
\]
forces
\[
p\mid U_s(n)\qquad\text{for every }s\ge1
\]
by (42).  So the entire family of inverse moments is locally redundant on the hard branch modulo \(p\).  The moments can attack the quotient false branch, but they do not add a second local condition on the true branch.

Accordingly, I do **not** claim an impossibility theorem for every conceivable characteristic-zero construction.  A sufficiently subtle global identity could still force cancellation that is invisible in the local mod-\(p\) description.  What is ruled out by the present audit is the inference that the standard determinant/moment/LLL constructions already provide such a subexponential carrier.  They do not, for the explicit reasons above.

# 11. Finite-test suggestions (diagnostic only)

These tests would be useful for falsification and design, but none should be promoted to an all-\(n\) proof without a separate theorem.

1. **Exact law regression.**  For a large finite range of \(n\), enumerate primes \(\sqrt n<p\le n\) and verify (24) exactly.  Separately test \(p>n\) to keep the missing-endpoint counterexamples visible.

2. **Fixed-\(q\) carrier regression.**  Compute
   \[
   D_q=\gcd(b_q,U_1(q))
   \]
   exactly and verify that every observed quotient-only prime with that \(q\) divides \(D_q\).  Record \(\log\operatorname{rad}(D_q)\), not only \(\log D_q\).

3. **Branch mass plot.**  Separate top primes into the true-residue set \(T_n\) and false quotient set \(\mathcal F_n\).  Plot/log only as diagnostics; theorem (2) already settles the latter asymptotically.

4. **Higher-moment regression.**  Include the exact counterexample
   \[
   (n,p)=(15,5)
   \]
   as a unit test showing \(5\mid J_{15}\) but \(5\nmid U_2(15)\).

5. **Vandermonde identity regression.**  For small \(q\), construct the integer coefficients of
   \[
   Q_q(x)=x\prod_{a=1}^{q-1}(ax-1)
   \]
   and check (62) in exact arithmetic.  Also verify the exact-zero polynomial (71) and relation (74).

6. **Determinant scan with zero tracking.**  For fixed widths \(j\), compute \(C_{n,j}\) exactly, record which values are zero, and separately record
   \[
   \gcd\{C_{n,j}:C_{n,j}\ne0\}.
   \]
   A small observed gcd is a candidate theorem, not a theorem itself.

7. **LLL audit discipline.**  Every returned coefficient vector should be evaluated exactly.  Label an output `EXACT_ZERO` rather than reporting its bit size as evidence.  The polynomial kernel (74) should be included as a mandatory adversarial test.

These suggestions fit the current repository doctrine: finite computations are for theorem discovery, endpoint checking, and counterexample search.

# 12. The unresolved step

The theorem-level state after this audit is now especially sharp:

\[
\boxed{
\log J_n=o(n)
\quad\Longleftrightarrow\quad
\sum_{\substack{\sqrt n<p\le n\\p\mid b_{n\bmod p}}}\log p=o(n).
}
\tag{90}
\]

Everything else in the top-prime decomposition costs only \(O(n^{2/3})\).

So the remaining problem is **not** the quotient branch and is **not** denominator bookkeeping for \(U_1\).  It is the pointwise incidence problem for Apéry zeros in the moving remainder \(r=n\bmod p\).

A successful characteristic-zero construction must therefore do something genuinely new on that branch.  Concretely, it must either:

- produce a nonzero integer expression divisible by every prime with \(p\mid b_{n\bmod p}\), with sublinear logarithmic height; or
- prove the log-mass estimate (40) directly by arithmetic of the residue values \(b_r\).

The fixed-width determinant/Casoratian constructions audited above currently give only \(O(n)\) logarithmic height and need uniform nonzero/cancellation control.  Fixed higher moments are not \(J_n\)-carriers, growing moments have exact-zero kernels, and the Vandermonde identity, although exact and nonzero, only removes the quotient false branch for a strengthened moment intersection.

That is the rigorous stopping point: the false branch is solved at \(O(n^{2/3})\), the exact moment interpolation identity is valid, and the full \(J_n\) problem remains equivalent to the true residue branch rather than being solved by the new intersection.
