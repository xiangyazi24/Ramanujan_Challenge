# Small-prime unit-index attack on the exact Padé carrier

## 1. Status of the carrier identity

The characteristic-zero identity reduces the problem to the primitive integer gcd

\[
D_n=\gcd_{0\le j<M} L_j(n)(b_n-b_j),\qquad M=\lfloor n/2\rfloor.
\]

The already proved top-half factorization is compatible with the unit-index
approach, but it does not by itself control the lower-prime factor
\(S_n\). The useful observation is that a prime \(\ell\mid D_n\) forces

\[
b_j\equiv b_n\pmod \ell
\]

for every index with \(\ell\nmid L_j(n)\). Hence the size of the unit set
\(U_\ell(n)\) is the decisive arithmetic quantity.

No determinant-height estimate is used here; the discussion below is entirely
prime-by-prime.

---

## 2. Exact valuation description of the unit indices

For

\[
L_j(n)=(-1)^{M-1-j}{n\choose j}{n-j-1\choose M-1-j},
\]

Kummer gives

\[
v_\ell\!\left({N\choose K}\right)=\#\{
\text{carries when adding }K+(N-K)\text{ in base }\ell\}.
\]

Therefore

\[
v_\ell(L_j(n))=
 c_\ell(j,n-j)+c_\ell(M-1-j,n-M),
\]

where the two terms are the Kummer carry counts for the two binomial
coefficients. Consequently

\[
j\in U_\ell(n)\iff
\begin{cases}
\text{no carries in }j+(n-j),\\
\text{no carries in }(M-1-j)+(n-M).
\end{cases}
\]

Equivalently, using Lucas,

\[
j\in U_\ell(n)
\]

iff the base-\(\ell\) digits satisfy simultaneously

\[
j_r\le n_r,
\]

and

\[
(M-1-j)_r\le(n-M)_r
\]

for every digit position \(r\).

For prime powers the same statement must be applied through the valuation
formula above; Lucas alone only detects divisibility modulo \(\ell\), not the
full exponent \(v_\ell(L_j(n))\). The prime-power filtration therefore is:

\[
U_{\ell^e}(n)=\{j:v_\ell(L_j(n))<e\}.
\]

The ordinary unit set used in the gcd is \(U_{\ell}(n)=U_{\ell^1}(n)\).

---

## 3. The j=0,1 elimination mechanism

The first obstruction is immediate.

For \(j=0\),

\[
L_0(n)=(-1)^{M-1}{n-1\choose M-1}.
\]

For \(j=1\),

\[
L_1(n)=(-1)^{M-2}n{n-2\choose M-2}.
\]

A prime \(\ell\ge5\) dividing both gcd factors must make both indices non-units
unless the two Apéry residues coincide modulo \(\ell\). If both are units then

\[
b_0\equiv b_1\pmod\ell.
\]

Since

\[
b_0=1,\qquad b_1=5,
\]

this implies

\[
\ell\mid4,
\]

which excludes every odd \(\ell\ge5\).

Thus the surviving lower-prime contribution is forced into the exceptional
set where the first few indices are all removed from \(U_\ell(n)\) by Kummer
carries, or where the corresponding small Apéry values happen to collide.

Extending this to indices \(0\le j\le J\) gives the deterministic reduction:

if there exist \(i,j\le J\) with

\[
i,j\in U_\ell(n),\qquad b_i\not\equiv b_j\pmod\ell,
\]

then \(\ell\nmid D_n\).

Hence the residual primes satisfy a simultaneous carry condition for all tested
indices and a congruence condition on a finite Apéry prefix.

## 4. Attempted height reduction

The desired estimate is

\[
\log S_n=\sum_{\ell\le n/2}v_\ell(D_n)\log\ell=o(n).
\]

The unit-index argument proves the following split:

\[
\log S_n=
\sum_{\ell\in E_J(n)}v_\ell(D_n)\log\ell,
\]

where \(E_J(n)\) is the residual set

\[
E_J(n)=\{\ell\le n/2:
U_\ell(n)\cap[0,J]\text{ contains no separating pair}\}.
\]

For fixed \(J\), this is a genuine reduction, but it is not yet an
\(o(n)\) theorem. The missing step is a uniform estimate showing that the
Kummer exceptional primes have sufficiently small weighted valuation sum.

No valid argument currently upgrades the finite-prefix elimination to

\[
\sum_{\ell\le n/2}v_\ell(D_n)\log\ell=o(n).
\]

In particular, one cannot replace this step by a generic determinant bound,
because that introduces an exponential lattice height unrelated to the gcd.

## 5. Exact computational experiment specification

The correct experiment must compute the original quantities, not a surrogate:

```python
for n in range(4,N):
    M=n//2
    vals=[]
    for j in range(M):
        L=(-1)**(M-1-j)*binom(n,j)*binom(n-j-1,M-1-j)
        vals.append(L*(apery(n)-apery(j)))
    D=gcd_all(vals)
    split = factor(D)
    top=[p for p in split if n//2 < p <= n]
    low=[p for p in split if p <= n//2]
```

The checks required are:

* every prime in the top half has exponent one;
* top-half primes agree with \(p\mid b_{n-p}\);
* all remaining mass is assigned to \(S_n\);
* the largest contributors are reported by \(v_p(D_n)\log p\).

Finite data can identify exceptional carry patterns, but cannot prove their
asymptotic density.

---

## 6. Surviving obstruction

The attack does produce a meaningful arithmetic reduction:

\[
S_n\text{ is supported only on primes whose base-}p\text{ carry pattern}
\]

\[
\text{kills all separating small Apéry indices.}
\]

However, the remaining obstruction is precise:

**there is currently no proved bound on the weighted contribution of the
Kummer-exceptional prime set.**

The obstruction is not a determinant-height failure and not a generic Smith
form issue. It is the absence of a uniform theorem controlling the density and
valuation contribution of primes for which

\[
U_p(n)\cap[0,J]
\]

fails to contain a residue-separating pair.

Thus the route is reduced to a sharply defined residual arithmetic problem,
but the target estimate

\[
\log S_n=o(n)
\]

is not established by the present unit-index method.

## Separation of conclusions

**Proved:**

* Kummer/Lucas characterization of unit indices.
* Prime-power valuation interpretation through carry counts.
* Finite-prefix elimination criterion.
* Reduction of \(S_n\) to a residual Kummer-congruence prime set.

**Finite evidence:**

* Exact gcd/factorization scans can measure surviving primes and valuations.
* Small-index residue filters remove many primes in computations.

**Open:**

* Prove the weighted exceptional-prime estimate needed for \(\log S_n=o(n)\).
* Or replace the finite-prefix filter by an Apéry-specific structural theorem controlling all exceptional primes.
