# Bounded outer-index stencils: an exact saturation theorem

## Verdict

There is a genuine cross-prime consequence of the outer sequence, but it is the wrong one: after all nearby values are put over one common lcm, every fixed-width Apéry-recurrence residual is divisible by **every** interior prime in the fixed-quotient slice. Hence every nonzero integer obtained purely from those residuals has linear logarithmic height.

More strongly, there is an exact coefficient-lattice normal form. For any fixed bounded window of outer indices, the localized polynomial ring in the window values is a polynomial ring in:

- the two free coordinates at offsets zero and one; and
- the recurrence residuals.

The target equation kills only the offset-zero coordinate. Consequently every bounded polynomial stencil, including every fixed Hankel or Toeplitz determinant, has exactly one of three behaviors:

1. it is not forced to vanish at a target at all;
2. modulo the universal recurrence residuals it is a multiple of the central value, so it is only the original pointwise selector in disguise; or
3. it lies entirely in the recurrence-residual ideal, in which case every prime in the slice divides it and every nonzero cleared integer has logarithmic height Theta_q(n).

Thus no bounded outer-index stencil gives a primitive nonzero carrier of logarithmic height o(n). A successful cross-prime argument must use an outer range growing with n, genuinely multiplicative outer indices, or additional global arithmetic not contained in the local selector plus the Apéry recurrence.

This conclusion is compatible with the current repository state in `problems/3.2/proof.tex`, `problems/3.2/research/scripts/q32_fixed_q_certificates.py`, `q32_content_smith.py`, and `q32_block_pascal_gcd_audit.py`: those constructions also split into a target coordinate and a universal saturated block.

# 1. Inputs

Write the Apéry recurrence as follows.

```text
(k+1)^3 b_{k+1} - P(k)b_k + k^3 b_{k-1} = 0,

P(k) = 34k^3 + 51k^2 + 27k + 5.
```

Let the integral outer sequence be

```text
Y_m = Lambda_m X_m,

Lambda_m = lcm(1,2,...,m).
```

The two fixed-q congruences used below are

```text
b_{qp+r} = b_q b_r                 (mod p),

p X_{qp+r} = b_r X_q               (mod p),
```

under the hypotheses

```text
0 <= r < p,
q < p.
```

For fixed q, the primes in the q-th slice are

```text
C_{n,q} = { p prime : n/(q+1) < p <= n/q }.
```

For every member of this set there is a unique residue r with

```text
n = qp + r,
0 <= r < p.
```

For all sufficiently large n, every prime in the slice is larger than q and larger than every fixed exceptional prime dividing the fixed rational number X_q or the fixed integer b_q.

# 2. The balanced outer window

Fix nonnegative integers u and v, with v at least one. The window of offsets is

```text
-u, -u+1, ..., 0, 1, ..., v.
```

Put every member of the window over the same lcm:

```text
M_n = Lambda_{n+v},

Z_h(n) = M_n X_{n+h}
       = (Lambda_{n+v}/Lambda_{n+h}) Y_{n+h},

-u <= h <= v.
```

Every Z_h(n) is an integer. The change from Y_{n+h} to Z_h is harmless for the slice primes: for an interior candidate prime, both lcms contain p exactly once, so the multiplier is a p-adic unit.

Define the interior candidates by requiring that every shifted outer index remain in the same quotient cell:

```text
C^o_{n,q;u,v}
 = { p in C_{n,q} : u <= r <= p-v-1 },

where r = n-qp.
```

Only finitely many candidates are removed from each end. More precisely, the upper-boundary failures have one of the forms

```text
r = 0,1,...,u-1,

p = (n-r)/q,
```

and the lower-boundary failures have one of the forms

```text
p-r = 1,2,...,v,

p = (n+(p-r))/(q+1).
```

Therefore at most u+v primes are omitted. Their total logarithmic weight is

```text
O_{u,v}(log n).
```

For fixed q, u, and v, and sufficiently large n, every interior candidate also satisfies

```text
p^2 > n+v,

v_p(M_n) = 1.
```

For every offset in the window, the shifted selector gives

```text
p X_{n+h} = b_{r+h} X_q              (mod p).
```

Multiplying by the p-unit M_n/p gives one common scalar for the entire window:

```text
Z_h(n) = kappa_p b_{r+h}              (mod p),

kappa_p = (M_n/p) X_q                 (mod p).
```

For all sufficiently large slice primes, kappa_p is nonzero. The Apéry-Lucas congruence then gives the exact target equivalence

```text
p | b_n
<=> p | b_r
<=> p | Z_0(n).
```

The first equivalence uses that the fixed integer b_q is a p-unit. The second uses that the fixed nonzero rational X_q is a p-unit.

# 3. A genuine cross-prime identity, and its fatal height

For each internal recurrence index define

```text
R_h(n)
 = (n+h+1)^3 Z_{h+1}(n)
   - P(n+h) Z_h(n)
   + (n+h)^3 Z_{h-1}(n),

-u+1 <= h <= v-1.
```

This is an integer involving several outer indices. For every interior candidate prime, substitute the common-scalar congruence and use

```text
n+h = r+h                            (mod p).
```

One obtains

```text
R_h(n)
 = kappa_p [
      (r+h+1)^3 b_{r+h+1}
      - P(r+h)b_{r+h}
      + (r+h)^3 b_{r+h-1}
   ]                                  (mod p)
 = 0                                  (mod p).
```

Thus the whole interior slice primorial divides every recurrence residual:

```text
Pi^o_{n,q;u,v}
 = product_{p in C^o_{n,q;u,v}} p,

Pi^o_{n,q;u,v} | R_h(n)
```

for every admissible h.

This is genuinely cross-prime: one integer formed from several outer indices vanishes simultaneously in all characteristics in the slice. It is also completely saturated, because it selects all candidate primes rather than the Apéry-zero subset.

Let

```text
theta(x) = sum_{p <= x} log p.
```

The prime number theorem and the O_{u,v}(1) boundary loss give

```text
log Pi^o_{n,q;u,v}
 = theta(n/q) - theta(n/(q+1)) + O_{u,v}(log n)
 = n/(q(q+1)) + o_q(n).
```

Consequently every nonzero recurrence residual has the unconditional lower bound

```text
log |R_h(n)|
 >= n/(q(q+1)) + o_q(n).
```

The matching linear upper bound is elementary. The explicit algebraic branch satisfies

```text
d/dt log x(t) = 1/sqrt(1-34t+t^2),
```

so the coefficients of log x grow at most exponentially. The binomial formula for b_m also gives an exponential upper bound. Hence

```text
log |X_m| = O(m).
```

Chebyshev's bound for the lcm gives

```text
log Lambda_m = O(m).
```

Since the outer width is fixed,

```text
Lambda_{n+v}/Lambda_{n+h}
```

divides a product of only u+v consecutive integers and therefore has logarithm O_{u,v}(log n). It follows that

```text
max_{-u <= h <= v} log(1+|Z_h(n)|) = O_{u,v}(n).
```

Every fixed-degree polynomial stencil with coefficient height exp(o(n)) therefore has logarithmic height O(n). In particular, whenever a cleared recurrence-ideal stencil is nonzero, its height is exactly linear in scale:

```text
log |carrier_n| = Theta_q(n).
```

# 4. Exact localized normal form

The preceding residual is not an isolated accident. It is the complete bounded-window cross-index structure.

Introduce formal variables

```text
z_{-u}, z_{-u+1}, ..., z_v
```

and formal recurrence residuals

```text
rho_h
 = (n+h+1)^3 z_{h+1}
   - P(n+h)z_h
   + (n+h)^3 z_{h-1},

-u+1 <= h <= v-1.
```

The only denominators needed to solve the recurrence forward and backward are the fixed pivot product

```text
D_{u,v}(n)
 = [ product_{h=-u+1}^{0} (n+h)^3 ]
   [ product_{h=1}^{v-1} (n+h+1)^3 ],
```

where an empty product is one. Work over the localization

```text
R_n = Z[1/D_{u,v}(n)].
```

For every interior candidate prime,

```text
p does not divide D_{u,v}(n).
```

Indeed, the backward pivots reduce modulo p to integers between one and r, and the forward pivots reduce to integers between r+2 and r+v, all lying strictly between zero and p.

Now use z_0, z_1, and the rho_h as coordinates. Forward recovery is given recursively by

```text
z_{h+1}
 = [ rho_h + P(n+h)z_h - (n+h)^3 z_{h-1} ]
   / (n+h+1)^3,

1 <= h <= v-1.
```

Backward recovery is given recursively by

```text
z_{h-1}
 = [ rho_h - (n+h+1)^3 z_{h+1} + P(n+h)z_h ]
   / (n+h)^3,

-u+1 <= h <= 0.
```

Therefore the linear coordinate map

```text
(z_{-u},...,z_v)
  ->
(z_0,z_1,(rho_h)_{-u+1 <= h <= v-1})
```

is invertible over R_n. Equivalently,

```text
R_n[z_{-u},...,z_v]
 = R_n[z_0,z_1,(rho_h)_{-u+1 <= h <= v-1}]
```

as polynomial rings after the displayed invertible linear change of coordinates.

Let the recurrence ideal be

```text
I_n = ( rho_h : -u+1 <= h <= v-1 ).
```

Then the quotient is exactly

```text
R_n[z_{-u},...,z_v] / I_n
  isomorphic to
R_n[z_0,z_1].
```

At the coefficient-lattice level, the recurrence matrix is equivalent over R_n to a matrix with an identity block and two zero columns:

```text
M_rec
  ~
[ I_{u+v-1}  0  0 ].
```

Thus its row lattice is primitive and its quotient is free of rank two. There is no hidden Smith or Fitting torsion after the bounded pivot factors are inverted.

Adding the target equation z_0 gives

```text
J_n = I_n + (z_0),
```

and

```text
R_n[z_{-u},...,z_v] / J_n
  isomorphic to
R_n[z_1].
```

The enlarged coefficient matrix is similarly equivalent to

```text
M_target
  ~
[ I_{u+v}  0 ].
```

Hence even after imposing the target, the localized quotient remains torsion-free. The target contributes one primitive coordinate and nothing else.

# 5. The bounded-stencil saturation theorem

A polynomial stencil F in the outer window has a unique recurrence normal form

```text
NF_n(F) in R_n[z_0,z_1],
```

obtained by setting every rho_h to zero in the coordinate system above.

Call F formally target-forced if its vanishing follows from only the recurrence equations and the target equation, with the remaining scale z_1 arbitrary. This is exactly the condition

```text
NF_n(F)(0,z_1) = 0
```

as a polynomial identity in z_1.

Since the kernel of evaluation at z_0 equal to zero is the principal ideal generated by z_0, one has the exact equivalence

```text
F is formally target-forced

<=> NF_n(F) = z_0 A_n(z_0,z_1)

<=> F = z_0 A_n + sum_h B_{h,n} rho_h
```

for polynomials A_n and B_{h,n} over R_n.

After multiplying by a fixed power of D_{u,v}(n), this becomes an exact integral polynomial identity:

```text
D_{u,v}(n)^M F
 = A_{0,n} z_0
   + sum_h B_{0,h,n} rho_h,
```

where M depends only on the fixed stencil complexity, not on p.

Evaluate at the actual outer jet. Every interior candidate prime is a unit on the left-hand denominator and kills every recurrence residual. Therefore

```text
D_{u,v}(n)^M F(Z_{-u}(n),...,Z_v(n))
 = A_{0,n}(Z(n)) Z_0(n)              (mod p).
```

This is the exact dichotomy.

## Case A: nonzero target normal form

If

```text
NF_n(F) = z_0 A_n
```

with A_n nonzero, then the target divisibility is mediated entirely by Z_0. If A_n is a p-unit, the stencil has exactly the same slice target as the original selector. If A_n vanishes modulo some candidate primes, it only adds ghost primes. It supplies no second congruence and no cross-prime compression.

## Case B: zero normal form

If

```text
NF_n(F) = 0,
```

then F lies in the recurrence ideal after localization. Its cleared integer value is divisible by every interior candidate prime:

```text
Pi^o_{n,q;u,v}
 |
D_{u,v}(n)^M F(Z(n)).
```

If the cleared value is nonzero and the stencil has fixed degree and coefficient height exp(o(n)), then

```text
log |D_{u,v}(n)^M F(Z(n))|
 = Theta_q(n).
```

The denominator-clearing factor has only logarithmic height:

```text
log D_{u,v}(n)^M = O_{u,v,M}(log n),
```

so it cannot change linear height into sublinear height.

There is no third case. This is the promised sharp scoped counterexample: after quotienting out the pointwise target coordinate, every bounded outer-index consequence is universal and linearly large.

# 6. Bounded Mobius or finite-difference transforms

Consider any bounded linear transform, with arbitrary integer weights of subexponential size:

```text
F_n = sum_{h=-u}^{v} c_h(n) Z_h(n).
```

This includes bounded finite differences and bounded windows with Mobius-type arithmetic weights. Its recurrence normal form is linear:

```text
NF_n(F_n) = a_n z_0 + c_n z_1.
```

It is target-forced exactly when

```text
c_n = 0.
```

Then either

```text
a_n is nonzero,
```

in which case the transform is the central selector plus universal recurrence residuals, or

```text
a_n = 0,
```

in which case the transform is universal and every interior slice prime divides it. A nonzero value in the second case has linear logarithmic height.

Thus no bounded Mobius, von-Mangoldt-style, or finite-difference stencil can be both genuinely cross-prime and subexponential. A true divisor-wide Mobius inversion is not bounded and is outside this theorem.

# 7. Hankel and Toeplitz determinants

The first balanced Hankel determinant already fails before any height issue arises. Take the forward window with offsets zero, one, and two, and define

```text
H_2(n)
 = det [ [ Z_0(n), Z_1(n) ],
         [ Z_1(n), Z_2(n) ] ]
 = Z_0(n)Z_2(n) - Z_1(n)^2.
```

At an interior target prime,

```text
Z_0(n) = 0                               (mod p),

Z_1(n) = kappa_p b_{r+1}                 (mod p).
```

A target residue cannot have two consecutive Apéry zeros. Indeed, if both b_r and b_{r+1} vanished, the recurrence at r would force b_{r-1} to vanish, and backward iteration would contradict b_0 equal to one. Therefore

```text
b_{r+1} is nonzero                        (mod p).
```

For all sufficiently large slice primes, kappa_p is also nonzero, and hence

```text
H_2(n)
 = -kappa_p^2 b_{r+1}^2
 != 0                                    (mod p).
```

So the naive two-by-two Hankel determinant misses every interior target.

Any fixed Hankel or Toeplitz determinant built from a bounded set of outer indices is a polynomial F in the variables z_h. The saturation theorem gives its complete classification:

```text
not target-forced,

or

NF_n(F) = z_0 A_n,

or

NF_n(F) = 0.
```

The middle alternative is the old selector under a determinant wrapper. The last alternative is divisible by the full slice primorial and has linear height when nonzero. Correcting the determinant with recurrence coefficients cannot create a fourth alternative.

# 8. Finite product formulas cannot distribute the targets

Suppose a fixed finite product of bounded stencils is proposed:

```text
F = F_1 F_2 ... F_s.
```

Pass to recurrence normal forms. The target ideal in the quotient ring is the prime ideal generated by z_0:

```text
(z_0) in R_n[z_0,z_1].
```

If the product is formally target-forced, then

```text
NF_n(F_1) NF_n(F_2) ... NF_n(F_s)
 belongs to (z_0).
```

Because the ideal is prime, at least one factor satisfies

```text
NF_n(F_i) belongs to (z_0).
```

Thus a bounded finite product cannot arrange for different target primes to choose different factors by a consequence of the local equations. One factor already contains the original pointwise target coordinate, or it is universally zero modulo every candidate prime. Again the only alternatives are the old selector or a full-slice linear-height factor.

# 9. Why the obvious gcd is only the target renamed

The recurrence residuals can be used to manufacture an exact candidate-supported gcd identity. Assume the window contains at least one residual. For all sufficiently large n, the radical supported on the interior candidate set satisfies

```text
rad_{C^o_{n,q;u,v}}
 gcd( Z_0(n), R_{-u+1}(n), ..., R_{v-1}(n) )

 = product_{
       p in C^o_{n,q;u,v},
       p | b_n
   } p.
```

The equality holds because every candidate prime divides every R_h, while a candidate prime divides Z_0 exactly when it divides b_n.

This identity is exact but gives no new height estimate. Its right-hand side is precisely the unknown target radical. Bounding the gcd by e^{o(n)} is equivalent to controlling the target primes; the outer residuals have contributed only the universal candidate modulus. This is the concrete reason that taking a gcd with the cross-prime residuals merely returns the target under a new name.

# 10. Primitive saturation interpretation

There are two different universal factors, and both must be distinguished from target information.

First, common-lcm balancing introduces no target factor at a candidate prime because

```text
Z_h(n)
 = (Lambda_{n+v}/Lambda_{n+h})Y_{n+h}
```

and the multiplier is a p-unit throughout the interior window.

Second, the recurrence residuals acquire the full candidate primorial through the selector congruence. Removing that primorial removes every guaranteed candidate-prime factor, including every target-prime factor. The localized recurrence matrix itself is primitive:

```text
coker(M_rec) is free of rank 2 over R_n,

coker(M_target) is free of rank 1 over R_n.
```

Therefore no coefficient-lattice torsion survives the bounded pivot saturation. Any further common divisor after the universal factor is removed is an arithmetic property of the actual Apéry target set, not a formal consequence of the bounded outer-index equations.

# 11. Scope

The no-go theorem covers all constructions with the following fixed-complexity features:

- a fixed finite set of additive outer offsets, enlarged to a fixed consecutive window;
- fixed polynomial degree;
- coefficient height exp(o(n));
- denominators supported on a fixed power of the recurrence pivot product;
- target divisibility proved only from the fixed-q selector and the Apéry recurrence.

It covers bounded linear transforms, fixed finite differences, fixed Hankel and Toeplitz determinants, fixed resultants of such stencils, and fixed finite products.

It does **not** rule out the following genuinely global possibilities:

- a window width tending to infinity with n;
- a transform over all divisors or prime powers rather than bounded additive offsets;
- outer indices depending multiplicatively on the candidate characteristic;
- an identity using arithmetic information about the actual set of Apéry zeros beyond the local recurrence;
- analytic cancellation across an unbounded family of outer indices.

Those are precisely the places where a real cross-prime theorem could still enter.

# 12. Final conclusion

The whole outer sequence does yield the exact simultaneous congruences

```text
Pi^o_{n,q;u,v} | R_h(n),
```

but their height is unavoidably linear:

```text
log Pi^o_{n,q;u,v}
 = n/(q(q+1)) + o_q(n).
```

The exact bounded-window coordinate decomposition is

```text
outer window
 = two free coordinates
   + recurrence-residual coordinates,
```

and after imposing the target it becomes

```text
one free coordinate
 + recurrence-residual coordinates.
```

Hence every bounded target-forced stencil satisfies

```text
F
 = Z_0 times another stencil
   + a combination of universal recurrence residuals.
```

The first term is the already-known pointwise selector. The second is divisible by all slice primes and has linear height whenever nonzero. Therefore bounded outer-index Hankel, Toeplitz, Mobius, finite-difference, and finite-product constructions cannot produce the required primitive nonzero e^{o(n)} carrier.
