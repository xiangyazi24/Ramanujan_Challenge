# ABC conjecture and Apéry GCD

## Executive answer

The ABC conjecture does not currently give the desired bound on the large-prime divisor count of b_n. It gives information about the radical of certain combinations involving consecutive Apéry terms, and this is interesting, but it does not isolate rad(b_n) strongly enough. The Mason-Stothers theorem has no direct analogue applicable to the integer Apéry sequence.

## 1. Casoratian and ABC

The Apéry relation

```
a_{n+1} b_n-a_n b_{n+1}=6/(n+1)^3
```

is a determinant identity. After clearing denominators one obtains an integer relation, but it is not an equation

```
x+y=z
```

where x,y,z have independent arithmetic structure. The terms contain large common factors coming from the denominators of a_n and the neighboring Apéry values.

ABC can be applied only after extracting gcd factors. It gives a statement about the radical of the entire triple

```
(a_{n+1}b_n, a_n b_{n+1}, denominator factors).
```

It does not imply a lower bound for the radical of b_n alone.

## 2. The almost-squarefree heuristic

The proposed deduction is directionally correct:

If one assumes strong ABC-type input, then the determinant identity suggests that

```
rad(b_n b_{n+1})
```

must be very large. Since

```
log b_n = (log(17+12*sqrt(2))+o(1)) n ≈ 3.525 n,
```

ABC heuristics are compatible with b_n being close to squarefree.

However, the implication

```
log rad(b_n b_{n+1}) large => log rad(b_n) large
```

is false without controlling the overlap between b_n and b_{n+1}. The Casoratian only gives

```
gcd(b_n,b_{n+1}) | 6
```

(up to the standard normalization), so the consecutive overlap is small, but this still does not localize the radical between the two terms.

## 3. Why this does not prove omega_(n/2,n](b_n)=o(n/log n)

The target quantity is

```
#{p in (n/2,n] : p | b_n}.
```

These primes are not controlled by the total radical. A number of size exp(3.5n) can be squarefree and still have about n/log n primes in a prescribed interval.

The missing ingredient is not multiplicity control; it is distribution of prime divisors.

The ABC conclusion would at best say:

```
large prime powers are rare.
```

The conjecture needs:

```
large primes near n almost never divide b_n.
```

These are different statements.

## 4. Mason-Stothers analogy

The polynomial ABC theorem works because a polynomial identity

```
a(x)+b(x)=c(x)
```

has a derivative relation. The Wronskian forces many distinct roots.

The Apéry recurrence is a difference equation:

```
(n+1)^3 u_{n+1}=P(n)u_n-n^3u_{n-1}.
```

There is no polynomial parameter x whose roots correspond to prime divisors of b_n. A generating function or differential equation does not convert the arithmetic problem into a polynomial ABC problem.

Therefore Mason-Stothers cannot be directly applied.

## 5. Partial ABC results

Known unconditional results toward ABC (including squarefree-value and radical estimates in special families) do not apply because b_n is a single value of a hypergeometric sequence, not a polynomial value with controlled degree.

The relevant object is the p-adic condition

```
p | b_n iff n mod p belongs to Z_p.
```

This is a moving family of finite-field conditions. ABC is largely blind to this.

## 6. What ABC would actually help with

A useful conditional theorem would be:

```
For every epsilon>0,
#{p : p|b_n and v_p(b_n)>=2} << n^epsilon.
```

ABC plausibly supports such a statement.

But the Apéry GCD problem requires a different theorem:

```
#{p in (n/2,n] : n mod p in Z_p}=o(n/log n).
```

This is a cross-prime equidistribution / anti-concentration statement for the zero sets Z_p.

## Final verdict

ABC gives a plausible explanation why Apéry numbers should be close to squarefree, but it does not solve the GCD conjecture. The obstruction is not repeated prime factors; it is the simultaneous occurrence of many distinct large prime divisors.

The correct missing theorem remains a moving-character or cross-prime independence estimate for the Apéry zero sets Z_p, not an ABC radical estimate.
