# Q835 Cross-prime Apéry-Lucas propagation audit

## Verdict

The proposed cross-prime propagation does not currently yield an unconditional theorem. The exact Lucas-type congruence is strong enough to transport a zero only while the modulus is fixed. The attempted step from a collection of primes in one affine row to a second common carrier fails at the changing-modulus interface.

The strongest unconditional interface obtained from the given identities is:

```
A hit p in the q-cell gives p | b_{j_p}, where j_p = n-q p (or the reflected index).
```

Together with

```
b_{a+mp} = b_a b_m (mod p),
```

this gives propagation inside the p-adic characteristic p only. It does not produce a congruence modulo another prime ell.

## 1. Fixed modulus propagation

For a fixed prime p, write

```
n = q p + r.
```

The direct branch has

```
j_p = r,
```

and the hit condition is

```
b_r = 0 (mod p).
```

The Lucas congruence gives

```
b_{r+mp} = b_r b_m (mod p).
```

Therefore every index in the arithmetic progression

```
r, r+p, r+2p, ...
```

inherits the zero modulo p.

This is exact.

## 2. Why many primes do not synchronize

Suppose p and ell are two hits in the same q-row. Then

```
p | b_{j_p},
ell | b_{j_ell}.
```

The two congruences live in different residue fields:

```
F_p and F_ell.
```

There is no implication

```
p | b_a  ==> ell | b_a
```

nor

```
p | b_a and ell | b_c ==> p ell | b_d
```

without an independent integer identity connecting a,c,d.

The affine relation

```
p=(n-r)/q
```

only says that the indices originate from the same row. It does not identify the lower indices.

## 3. DD/RR adjacent gaps

For adjacent hits p and ell=p-h, the folded gap laws imply that the lower indices differ by controlled amounts:

```
j_p-j_ell = O(h).
```

For DD/RR this gives exact short-distance relations between lower zeros.

However, short distance is not the same as a common carrier. A relation of the form

```
p | b_j,
ell | b_{j+s}
```

does not imply that either prime divides a canonical expression at a shared index.

## 4. Candidate common carriers

### b_j

The obvious carrier would be a common lower Apéry number. This requires

```
p | b_j and ell | b_j
```

for many pairs. The known gap identities only give

```
p | b_j,
ell | b_{j+s}.
```

No transfer across s is available.

### Second carrier from recurrence

A second-order recurrence does not automatically create a multiplicative resultant. One would need a proved identity of the form

```
C(n,p,ell) = 0
```

with

```
p ell | C
```

and

```
log |C| = o(n/log n).
```

No such canonical C follows from the current congruences.

### Exceptional outer rows

Reflection gives outer rows carrying individual primes. As in the fixed-gap reflection audit, one prime contributes only O(log n) logarithmic weight. It does not create exceptional rows without collision amplification.

## 5. Exact missing interface

A sufficient new lemma would be a cross-prime synchronization statement:

```
For every fixed q and every short DD/RR chain
p_i | b_{j_i},

there exists a canonical integer C_q(n,chain)
with
p_1 ... p_k | C_q(n,chain)
```

and

```
log |C_q(n,chain)| = o(n/log n).
```

The crucial restrictions are:

- C must be built from the actual Apéry sequence;
- no free local quotient variables;
- divisibility must be proved in each characteristic separately.

This is the minimal interface needed for a contradiction argument.

## 6. Conclusion

The cross-prime attack isolates a real possible mechanism, but the current identities only provide independent characteristic-wise propagation. The changing modulus is the fatal obstruction:

```
Lucas propagation modulo p
!=
Lucas propagation modulo ell.
```

No unconditional common carrier or exceptional-row amplification follows from the present inputs. The next decisive result would be an Apéry-specific cross-characteristic resultant/congruence, not another gap-counting lemma.
