# 1. Exact normalized edge chain

Put

```text

```

Let

```text

```

and let the Newton multiplication matrix be

```text
M_(k,l)
 = binom(k,l) Delta^(k-l)b_l
 = binom(k,l)
   sum_(t=0)^l binom(l,t)c_(k-l+t).
```

For denominator degree `d`, the high Newton matrix is

```text
R_(H,d)
 = M[H-d+1,...,H ; 0,...,d],
```

of size `d x (d+1)`.  Let

```text
Delta_(H,d)
 = gcd(all maximal minors of R_(H,d)),

Delta_(H,0)=1.
```

The signed maximal-cofactor vector divided by `Delta_(H,d)` is the primitive denominator vector.  The numerator is reconstructed from it.  There is no second numerator-content division.

For

```text
1 <= j <= m-1,
d = j-1,
```

define the solid minor

```text
T_(m,j)
 = det M[m-j,...,m-1 ; 0,...,j-1]
 = tau_(H,j-1).
```

The two adjacent primitive endpoint coordinates are

```text
L_(m,j)
 = T_(m,j) / Delta_(H,j-1),

R_(m,j)
 = (-1)^j T_(m,j) / Delta_(H,j).
```

They are integers.  Indeed, they are respectively

```text
the top numerator coordinate of denominator degree j-1,

the top denominator coordinate of denominator degree j.
```

The exact same-height adjacent Wronskian scalar is therefore

```text
K_(m,j)
 = binom(m,j) L_(m,j) R_(m,j)

 = (-1)^j binom(m,j)
   T_(m,j)^2 /
   (Delta_(H,j-1) Delta_(H,j)).
```

```text

```

Thus, for each prime `p`, set

```text
nu_p(m) := v_p(delta_(m-1)).
```

```text
nu_p(m)

     + v_p R_(m,j)
   ].
```

This is the normalized chain that a terminal-block or number-wall argument must control.  The raw solid minor `T_(m,j)` is not the normalized chain.

# 3. Proved regular terminal-partial-block lemma

## Lemma 3.1

Let

```text
m=Ap+R,
A>=1,
1<=R<p,
H=m-1.
```

If

```text
p does not divide
c_A * product_(r=0)^(R-1) b_r,
```

then

```text
p does not divide delta_H.
```

More precisely, the single aligned edge

```text
j=R
```

is a `p`-unit.

## Proof

For `j=R`, the solid minor is

```text
T_(m,R)
 = det M[Ap,...,Ap+R-1 ; 0,...,R-1].
```

The Kronecker law gives entrywise

```text
M_(Ap+r,s)
 = M_(A,0) M_(r,s)
 = c_A M_(r,s)                         (mod p),

0<=r,s<R.
```

Hence

```text
T_(m,R)
 = c_A^R det M[0,...,R-1 ; 0,...,R-1]
 = c_A^R product_(r=0)^(R-1)b_r       (mod p).
```

By hypothesis this is a unit.  The two determinantal divisors

```text
Delta_(H,R-1),
Delta_(H,R)
```

both divide `T_(m,R)`, because

```text
L_(m,R)=T_(m,R)/Delta_(H,R-1),
R_(m,R)=(-1)^R T_(m,R)/Delta_(H,R)
```

are integers.  Therefore both determinantal divisors and both normalized endpoint coordinates are `p`-units.

Finally Lucas gives

```text
binom(Ap+R,R)=1                         (mod p).
```

Thus

```text
K_(m,R)=binom(m,R)L_(m,R)R_(m,R)
```

is a unit, and so is the gcd of the full edge chain at `p`.  This proves the lemma.

## Scope of the proved lemma

This closes every terminal block in which the obvious local determinant survives.  The only remaining case is

```text
p divides c_A
or
p divides some b_r with 0<=r<R.
```

In that singular case the raw terminal determinant is zero, and primitive Smith saturation becomes load-bearing.

# 4. Why the mod-`p` Kronecker law is insufficient in the singular case

When a Kronecker block is zero or rank-deficient modulo `p`, the primitive kernel is obtained only **after** dividing the common maximal-minor content.  That quotient depends on the first nonzero `p`-adic layer, not on the reduction modulo `p`.

This is not a philosophical objection.  It already occurs in the smallest valid Newton multiplication matrix.

For any odd prime `p` and integer `t>=1`, take the two interpolation values

```text
u_0=1,
u_1=1+p^t.
```

Their Newton multiplication matrix through height one is

```text
M^(t)
 = [ 1     0     ]
   [ p^t   1+p^t ].
```

Every `M^(t)` has the same reduction modulo `p`:

```text
M^(t) = identity_2                       (mod p).
```

The two jointly primitive Padé pairs are

```text
P^[0](X)=1+p^t binom(X,1),
Q^[0](X)=1,

P^[1](X)=1+p^t,
Q^[1](X)=1+p^t-p^t binom(X,1).
```

Their Wronskian is exactly

```text
P^[0]Q^[1]-P^[1]Q^[0]
 = -2p^(2t) binom(X,2).
```

Thus

```text
v_p(delta_1)=2t,
```

which is arbitrarily large although the complete mod-`p` multiplication block is unchanged.

This is not a counterexample to the Apéry theorem—the first `p`-adic lift of the Apéry matrix is highly special.  It proves the exact logical point:

```text
mod-p Kronecker factorization
+ joint primitive normalization

is not enough to bound the valuation of the normalized kappa chain.
```

One must prove a first-Bockstein or Smith-saturation transfer theorem for the actual Apéry lift.

# 6. Precise missing local Smith theorem

Put

```text
epsilon_p=v_p(40),

epsilon_2=3,
epsilon_5=1,
```


## APERY-ALIGNED-SMITH, part II: complete-block descent

```text
min_(1<=B<A)
 [
   v_p binom(Ap,Bp)
```


```text

p does not divide u.
```

# 8. Why the ordinary number-wall theorem cannot yet be invoked

The raw number-wall entry on this anti-diagonal is

```text
T_(m,j)=tau_(H,j-1).
```

A classical square-window/frame theorem controls zeros and frame ratios of these raw determinants.  The normalized Wronskian edge is instead

```text
K_(m,j)
 = (-1)^j binom(m,j)
   T_(m,j)^2 /
   (Delta_(H,j-1)Delta_(H,j)).
```

There are two different primitive scales on the two sides of the same wall entry.  Therefore none of the implications

```text
T_(m,j)=0 mod p
<=> K_(m,j)=0 mod p,

v_p K_(m,j)=2v_p T_(m,j),

raw frame content = primitive frame content
```

is valid without an additional theorem.

The exact identification required before using the square-window theorem is:

## SATURATED-WALL-FRAME

For every Kronecker square/partial-square window, the classical frame relations descend after the two-sided divisions

```text
T_(m,j) ->
(
  T_(m,j)/Delta_(H,j-1),
  T_(m,j)/Delta_(H,j)
),
```

and the descended terminal frame has `p`-content at most

```text
epsilon_p
```

for `R>0`, while a complete `p`-block contributes at most one additional `p`.

This is exactly APERY-ALIGNED-SMITH in wall language.  It is not contained in the ordinary raw-determinant square-window theorem.  Proving only the raw wall theorem and then dividing by the Smith contents afterward is circular: those contents are the unknown valuations in `delta_H`.

- verifies the Lucas–Kronecker entry law in requested finite ranges;
- constructs the primitive cofactor kernels and normalized edges;

- proves the regular terminal formula computationally;
- prints the aligned terminal indices in every singular case;
- verifies the two-point lift counterexample from Section 4.

It is an audit, not a substitute for APERY-ALIGNED-SMITH.

```python
#!/usr/bin/env python3
from __future__ import annotations

import argparse
from functools import reduce
from math import comb, gcd


def gcd_list(values):
    return reduce(gcd, (abs(int(x)) for x in values), 0)


def apery_values(N):
    if N <= 0:
        return []
    if N == 1:
        return [1]
    b = [1, 5]
    for n in range(1, N-1):
        middle = 34*n**3 + 51*n**2 + 27*n + 5
        numerator = middle*b[n] - n**3*b[n-1]
        denominator = (n+1)**3
        assert numerator % denominator == 0
        b.append(numerator // denominator)
    return b


def forward_differences(values):
    row = list(values)
    out = []
    while row:
        out.append(row[0])
        row = [row[i+1]-row[i] for i in range(len(row)-1)]
    return out


def M_entry(k, ell, c):
    if ell < 0 or ell > k:
        return 0
    return comb(k, ell) * sum(
        comb(ell, t)*c[k-ell+t]
        for t in range(ell+1)
    )


def bareiss_det(A):
    n = len(A)
    if n == 0:
        return 1
    B = [list(row) for row in A]
    sign = 1
    previous = 1
    for k in range(n-1):
        if B[k][k] == 0:
            pivot_row = next(
                (i for i in range(k+1, n) if B[i][k] != 0),
                None,
            )
            if pivot_row is None:
                return 0
            B[k], B[pivot_row] = B[pivot_row], B[k]
            sign = -sign
        pivot = B[k][k]
        for i in range(k+1, n):
            for j in range(k+1, n):
                numerator = B[i][j]*pivot-B[i][k]*B[k][j]
                assert numerator % previous == 0
                B[i][j] = numerator // previous
            B[i][k] = 0
        previous = pivot
    return sign*B[-1][-1]


def vp(n, p):
    n = abs(int(n))
    if n == 0:
        return 10**9
    e = 0
    while n % p == 0:
        n //= p
        e += 1
    return e


def primes_up_to(N):
    flags = bytearray(b"\x01")*(N+1)
    if N >= 0:
        flags[0] = 0
    if N >= 1:
        flags[1] = 0
    q = 2
    while q*q <= N:
        if flags[q]:
            flags[q*q:N+1:q] = b"\x00"*((N-q*q)//q+1)
        q += 1
    return [q for q in range(2, N+1) if flags[q]]


def tau(H, d, c):
    if d == -1:
        return 1
    return bareiss_det([
        [M_entry(k, ell, c) for ell in range(d+1)]
        for k in range(H-d, H+1)
    ])


def determinantal_divisor(H, d, c):
    if d == 0:
        return 1
    a = H-d
    rows = [
        [M_entry(k, ell, c) for ell in range(d+1)]
        for k in range(a+1, H+1)
    ]
    cofactors = []
    for deleted in range(d+1):
        minor = [
            row[:deleted]+row[deleted+1:]
            for row in rows
        ]
        cofactors.append((-1)**deleted*bareiss_det(minor))
    answer = gcd_list(cofactors)
    assert answer > 0
    return answer


def normalized_edge(H, j, c):
    assert 1 <= j <= H
    d = j-1
    T = tau(H, d, c)
    Dminus = determinantal_divisor(H, d, c)
    Dplus = determinantal_divisor(H, d+1, c)
    assert T % Dminus == 0
    assert T % Dplus == 0
    L = T // Dminus
    R = (-1)**j * (T // Dplus)
    K = comb(H+1, j)*L*R
    return {
        "j": j,
        "T": T,
        "Dminus": Dminus,
        "Dplus": Dplus,
        "L": L,
        "R": R,
        "K": K,
    }


def delta_exact(H, c):
    return gcd_list(
        normalized_edge(H, j, c)["K"]
        for j in range(1, H+1)
    )


EXPECTED = {
    3: 32,
    4: 40,
    5: 8,
    6: 56,
    7: 32,
    8: 24,
    9: 40,
    10: 88,
    11: 8,
    12: 104,
    13: 8,
    14: 40,
    15: 160,
}


def verify_kronecker(p, max_upper):
    limit = (max_upper+1)*p
    b = apery_values(limit+1)
    c = forward_differences(b)
    checked = 0
    for a in range(max_upper+1):
        for upper_col in range(a+1):
            for r in range(p):
                for s in range(p):
                    k = a*p+r
                    ell = upper_col*p+s
                    if k > limit or ell > limit:
                        continue
                    left = M_entry(k, ell, c) % p
                    right = (
                        M_entry(a, upper_col, c)
                        * M_entry(r, s, c)
                    ) % p
                    assert left == right, (
                        p, a, upper_col, r, s, left, right
                    )
                    checked += 1
    print(f"KRONECKER p={p} checked={checked}")


def verify_regular_terminal(p, A, R):
    assert A >= 1 and 1 <= R < p
    m = A*p+R
    H = m-1
    b = apery_values(m+1)
    c = forward_differences(b)

    T = tau(H, R-1, c)
    rhs = pow(c[A] % p, R, p)
    for r in range(R):
        rhs = (rhs * (b[r] % p)) % p
    assert T % p == rhs

    if rhs != 0:
        edge = normalized_edge(H, R, c)
        assert edge["K"] % p != 0
        status = "REGULAR_UNIT_EDGE"
    else:
        aligned = [
            B*p+R
            for B in range(A)
            if comb(A, B) % p != 0
        ]
        status = f"SINGULAR_NEEDS_SMITH aligned={aligned}"

    print(
        f"TERMINAL p={p} A={A} R={R} H={H} "
        f"Tmodp={T%p} {status}"
    )


def verify_toy_lift(p, maximum_t=4):
    assert p % 2 == 1
    for t in range(1, maximum_t+1):
        values = [1, 1+p**t]
        c = forward_differences(values)
        delta = delta_exact(1, c)
        assert delta == 2*p**(2*t)
    print(f"TOY_LIFT p={p} t<= {maximum_t} PASS")


def scan_bound(max_height):
    b = apery_values(max_height+1)
    c = forward_differences(b)
    for H in range(2, max_height+1):
        delta = delta_exact(H, c)
        if H in EXPECTED:
            assert delta == EXPECTED[H]
        if H >= 3 and (40*(H+1)) % delta != 0:
            raise AssertionError(
                f"COUNTEREXAMPLE H={H} delta={delta} "
                f"40m={40*(H+1)}"
            )
        print(
            f"DELTA H={H} value={delta} "
            f"quotient={(40*(H+1))//delta if H>=3 else '-'}"
        )


def first_singular_upper(max_A, max_prime):
    b = apery_values(max_A+1)
    c = forward_differences(b)
    candidates = []
    for p in primes_up_to(max_prime):
        if p in (2, 5):
            continue
        for A in range(1, max_A+1):
            if c[A] % p == 0:
                m = A*p+1
                candidates.append((m-1, p, A, 1, c[A]))
    candidates.sort()
    if candidates:
        H, p, A, R, cA = candidates[0]
        aligned = [
            B*p+R
            for B in range(A)
            if comb(A, B) % p != 0
        ]
        print(
            "FIRST_SINGULAR_UPPER_IN_RANGE",
            {
                "H": H,
```

The missing point is not another Lucas identity and not a height estimate.  It is the following exact local assertion:

```text
in a singular terminal Kronecker block,
after dividing the two adjacent maximal-minor contents,
```
