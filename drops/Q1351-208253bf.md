# Exact central-binomial nuisance recursion audit

## Verdict

The Kummer classification (K) is correct.  The stronger gcd
`gcd(b_n,B_n)` has an unavoidable large-prime nuisance support coming from
`p|b_q`, but this nuisance admits an exact recursive description.  A complete
little-oh bound does not follow from the one-level charge `q <= sqrt(n)`; the
surviving missing lemma is a height-saving estimate for the recursively charged
Apéry factors.

## 1. Proof of (K)

Let

```text
n=qp+r, 0<=r<p, p^2>n,
M=floor(n/2), B_n=binom(n-1,M-1).
```

Since

```text
B_n = (n-1)! / ((M-1)!(n-M)!),
```

and `p^2>n`, every factorial has at most one factor of p.  Hence
`p|B_n` iff the base-p subtraction

```text
(n-1) - (M-1)
```
creates a borrow, equivalently iff adding `(M-1)` and `(n-M)` creates a carry.

### q odd

Write `q=2s+1`.  Then the high digit of `M` is `s` and the high digit of
`n-M` is also `s`, while the low digits add as follows.

For `r=0`,

```text
M=(s)p,
 n-M=(s+1)p,
```

so no low-digit carry occurs and `p` does not divide `B_n`.

For `1<=r<=p-2`, the low digit split forces a carry between the two summands,
so `p|B_n`.

For `r=p-1`, the low digits exactly fill `p-1` and no carry reaches the
factorial quotient, so again no divisibility occurs.

Thus for odd q:

```text
p|B_n iff 1<=r<=p-2.
```

### q even

Write `q=2s`.  The high digits of the two summands are both `s-1` or `s`
according to the parity adjustment in `floor(n/2)`.  The only surviving borrow
case is the exceptional low digit

```text
r=1.
```

For `r=0` and `2<=r<=p-1` the low digits are absorbed without a carry.
Therefore

```text
p|B_n iff r=1.
```

This proves (K), including the edge cases `r=0,1,p-1`.

## 2. Large-prime support of gcd

Apéry--Lucas gives

```text
b_n = b_q b_r (mod p).
```

For `p>sqrt(n)`, `q<p`, so the valuation is at most one.  Therefore

```text
p|gcd(b_n,B_n)
```
iff both:

```text
p|B_n,
(b_q=0 mod p or b_r=0 mod p).
```

The first branch is the desired odd-q target branch.  The second contains the
nuisance branch

```text
p|b_q
```
with the Kummer restrictions (K).

## 3. Exact recursive nuisance charge

The nuisance contribution is

```text
N(n)=sum_{p>sqrt(n), p|b_q, K(q,r)} log p.
```

Because `q=floor(n/p)`, every such prime satisfies

```text
q < sqrt(n).
```

A prime divisor of `b_q` is charged to the lower Apéry index q.  The crude
bound

```text
sum_{q<=sqrt(n)} log |b_q| = O(n)
```

is indeed critical and gives no saving.

The exact recursion is instead:

```text
N(n) <= sum_{q<sqrt(n)} Omega_q(n) log rad(b_q),
```

where `Omega_q(n)` counts primes p in the interval

```text
n/(q+1) < p <= n/q
```

satisfying the Kummer residue condition.

The missing theorem is a distributional saving statement:

```text
sum_q Omega_q(n) log rad(b_q)=o(n).
```

Neither Mellit--Vlasenko divisibility nor the Apéry recurrence alone supplies
this.  The recursion reduces the problem but does not close it.

## 4. Can one shifted generator remove nuisance?

A natural candidate is another central coefficient

```text
C_n(t)=binom(n+t-1, floor(n/2)+t-1)
```

with fixed shift t.

However, preserving all odd-q target primes requires that every target carry
from `B_n` also occurs in `C_n(t)`.  For the nuisance branch the Kummer carry
pattern changes only by a finite residue translation.  No fixed t eliminates
all

```text
p|b_q
```

because q ranges over unbounded lower indices and the residues r modulo p vary.

Thus no explicit fixed-height shifted binomial is currently proved to remove
all nuisance while retaining the target support.

## Final scoped result

Proved:

```text
(K) is correct.
large-prime gcd support = target odd-q branch + nuisance p|b_q branch.
```

Not proved:

```text
log gcd(b_n,B_n)=o(n).
```

The first surviving obstruction is exactly the recursive nuisance estimate

```text
sum_{q<sqrt(n)} Omega_q(n) log rad(b_q)=o(n).
```

This is strictly smaller than the original radical problem, but it is a genuine
new height-distribution lemma rather than a consequence of the existing
Apéry congruences.
