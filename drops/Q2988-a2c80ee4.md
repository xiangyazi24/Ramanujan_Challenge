# 13. Why a Bézout/resultant identity among cuts cannot remove `Q`

Normalize each moving cut by the same universal lower baseline:

\[
\widetilde M(c)
:=\frac{M(c)}{B^-}.
\]

By `(3.3)` and `(3.5)`,

\[
\widetilde M(c)
=DQ\cdot\frac{M(c)}{\Delta_k(n)}.
\tag{13.1}
\]

Thus

\[
\boxed{DQ\mid\widetilde M(c)\quad\text{for every }c.}
\tag{13.2}
\]

Consequently every integer linear combination

\[
\sum_c a_c\widetilde M(c),
\qquad a_c\in\mathbf Z,
\]

is still divisible by `DQ`.

A Euclidean algorithm, Sylvester resultant, Desnanot identity, or characteristic-zero Bézout relation among these normalized cuts can therefore do only one of two things:

1. retain the common factor `DQ`; or
2. divide by a coefficient/content already carrying the same prime support.

It cannot manufacture an integer carrier divisible by `D` but not by `Q` without an additional normalization that sees the **full** lower determinantal surplus.

This is an algebraic obstruction, not a heuristic about coefficient growth.

Hence a low-height Bézout identity for the moving cuts would at best prove a bound for

\[
G=\gcd_c M(c)/\Delta_k.
\]

Even the optimal conclusion

\[
G=1
\]

would leave

\[
T_q(n)\mid\Sigma^\ast/H
\]

by `(8.4)`.

# 14. The exact residual premises for a square-root height bound

There are now two separate arithmetic problems.

## 14.1 Unavoidable high-tail premise

A necessary condition for

\[
\log(\Sigma^\ast/H)
=O_q(\sqrt n\,\mathrm{polylog}\,n)
\]

is

\[
\boxed{
\log T_q(n)
=O_q(\sqrt n\,\mathrm{polylog}\,n).
}
\tag{14.1}
\]

This is not the original fixed-`q` shell estimate.  It is a simultaneous high-tail estimate over **all quotient cells below `q` in prime size**, namely all

\[
h=\left\lfloor\frac np\right\rfloor\ge q+1
\]

with `p>sqrt(n)`.

It is already necessary when `G=1`.

## 14.2 Genuine moving-cut excess premise

The remaining object that a Bézout attack can address is exactly

\[
\boxed{
G_{n,q}
=\gcd_{1\le c\le\lfloor n/q\rfloor}
\frac{M(c)}{\Delta_k(n)}.
}
\tag{14.2}
\]

A sufficient second premise is

\[
\boxed{
\log G_{n,q}
=O_q(\sqrt n\,\mathrm{polylog}\,n).
}
\tag{14.3}
\]

Then `(4.2)`, `(9.5)`, `(14.1)`, and `(14.3)` give the desired bound for `SigmaStar/H`.

The point is that `(14.1)` and `(14.3)` are mathematically distinct:

- `(14.1)` concerns the full Fitting ideal and cannot be improved by changing the moving cuts;
- `(14.3)` concerns only the failure of this restricted family of cuts to generate the full determinantal divisor.

This is the exact residual split, not a generic “gcd is hard” warning.

# 16. Universal LCM baseline versus residual Smith content

It is worth stating exactly what went wrong with the optimistic normalization.

The product

\[
B^-=\prod_{i\le k-1}\beta_i(n)
\]

removes the universal LCM-cube contribution from the lower Smith factors.  It does **not** remove their Apéry-specific residual content.

That residual content is precisely

\[
Q=\frac{\Delta_{k-1}(n)}{B^-}.
\]

For small primes, its height is only `O_q(sqrt(n))`, which is excellent.  For large primes, however, `(6.5)` says that `Q` is exactly the capped candidate contribution from every deeper quotient shell.

So the normalization is correct algebraically but insufficient arithmetically.

This is why a finite-power comparison with only the adjacent-size factor `E` cannot close the height problem: at a deeper candidate prime, `D` and `E` each contribute the same cubic baseline and cancel, leaving the residual exponent from a *lower* Smith factor untouched.

# 17. A natural structural repair, without a height claim

The obstruction points to the correct algebraic operation if one wants to keep pursuing the moving-cut family.

The same-size neighbor

\[
d_{k-1}(n)
\]

is absent at every genuine fixed-`q` target prime, because those primes have corank exactly `q+1`; but it is present at every deeper candidate prime, whose corank is at least `q+2`.

Therefore a **full-support saturation** of `C` by `d_{k-1}(n)` would remove the mandatory deeper factor `Q` at the level of prime support without touching `R_q`.

One would then use the adjacent-size `E=d_{k-1}(n-1)` to remove the exact-corank `q+1` nuisance strip, and finally an `n`-saturation to remove the rollover endpoint, exactly in the spirit of the safe saturation selector audited earlier.

I do **not** claim that this repaired carrier has small height: the restricted-minor excess `G` and target multiplicities would still need control.  The point is only that the current `SigmaStar` stops one saturation too early to have any chance of a square-root bound from moving-cut Bézout identities alone.

# 18. Best unconditional global upper bound from these inputs

For completeness, the current normalization at least removes the `n log n` factorial scale.

Use the cut `c=1`.  Then

\[
M(1)=K_{n-q}(q),
\]

the determinant of the trailing principal block on vertices `q,...,n-1`.

The Apéry Jacobi matrix is positive definite, so Hadamard gives

\[
M(1)
\le
\prod_{t=q}^{n-1}P(t).
\]

Since

\[
P(t)\le117(t+1)^3,
\]

\[
\log M(1)
\le
3\log\frac{n!}{q!}+O(n).
\tag{18.1}
\]

On the other hand

\[
\log B^-
=3\sum_{s=q+2}^{n}
\psi\!\left(\left\lfloor\frac ns\right\rfloor\right).

The exact divisor-switching identity

\[
\sum_{s=1}^{n}
\psi\!\left(\left\lfloor\frac ns\right\rfloor\right)
=\log(n!)
\]

gives

\[
\log B^-
=3\log(n!)
-3\sum_{s=1}^{q+1}
\psi\!\left(\left\lfloor\frac ns\right\rfloor\right).
\tag{18.2}
\]

Because `C|M(1)/B^-`, `(18.1)-(18.2)` yield

\[
\boxed{
\log C=O_q(n),
\qquad
\log\Sigma^\ast=O_q(n).
}
\tag{18.3}
\]

This is only a linear-height bound.  The p-adic analysis above explains exactly why the present inputs do not improve it to square-root height.

## Bottom line

The corrected normalization is mathematically sound, but it reveals that the proposed carrier is not yet normalized deeply enough.  After stripping the universal `LCM^3` baselines, it still contains the Apéry-specific residual Smith content of all lower layers:

\[
\boxed{
Q=\Delta_{k-1}(J_n)/B_{n,k-1}.
}
\]

Above `sqrt(n)`, this is exactly the powered union of all deeper candidate shells.  That factor survives the adjacent-size gcd and is already present in every cut, so no Euclidean/resultant identity among the cuts can erase it.

The moving-cut attack therefore splits into two genuinely different tasks:

1. remove/saturate the lower-layer Smith factor `Q` by a different algebraic operation; and
2. only then attack the true moving-family excess `G` by Bézout/resultant methods.

With the current `SigmaStar`, an `O_q(sqrt(n) polylog n)` bound would already imply the new high-tail theorem `(HT)`.  The construction does not prove that theorem.
