## Verdict

The normalization is **integral and structurally correct**, and it preserves the exact fixed-`q` target-shell selector. But it does **not** isolate the ordinary adjacent quotient `H` up to a small-prime factor. The obstruction is an exact, unavoidable lower-Fitting factor already present in every moving cut.

\[
\Delta_j(n):=\prod_{i=1}^j d_i(n),\qquad
B^-:=B_{n,k-1}=\prod_{i\le k-1}\beta_i(n).
\]

Since `B_{n,k}=B^-\beta_k`, the proposed normalization simplifies to

\[
C=\frac{\beta_k\Gamma}{B_{n,k}}=\frac{\Gamma}{B^-}.
\]

Define

\[
Q:=\frac{\Delta_{k-1}(n)}{B^-},\qquad
G:=\frac{\Gamma}{\Delta_k(n)}.
\]

Then all three quantities are positive integers and, exactly,

\[
\boxed{C=DQG,}
\tag{V1}
\]

with

\[
\boxed{
G=\gcd_{1\le c\le\lfloor n/q\rfloor}
\frac{M(c)}{\Delta_k(n)}.

\tag{V2}
\]

\[
\boxed{D\mid C,\qquad H:=\frac D{\gcd(D,E)}\mid
\Sigma^\ast:=\frac C{\gcd(C,E)},}
\tag{V3}

and more strongly

\[
\boxed{\frac{\Sigma^\ast}{H}\mid QG.}
\tag{V4}

## 1. Integrality and exact factorization of the normalized carrier

Fix `q`, put `k=n-q`, and write

\[
D=d_k(n),\qquad E=d_{k-1}(n-1).
\]

For `1\le i\le k`, let

\[
\beta_i(n)=L_{\lfloor n/(n-i+1)\rfloor}^3,
\qquad
B_{n,k}=\prod_{i\le k}\beta_i(n).
\]

Set

\[
B^-:=B_{n,k-1}.
\]

Then `B_{n,k}=B^-\beta_k`, so

\[
\boxed{C=\Gamma/B^-.}
\tag{1.1}
\]

Let

\[
\Delta_j(n)=\gcd\{\text{all }j\times j\text{ minors of }J_n\}
=\prod_{i=1}^j d_i(n).
\tag{1.2}
\]

Every `M(c)` is a `k\times k` minor, hence

\[
\Delta_k(n)\mid M(c)\quad\forall c,
\qquad
\Delta_k(n)\mid\Gamma.
\tag{1.3}
\]

The banked baseline gives `\beta_i(n)\mid d_i(n)`, so

\[
B^-\mid\Delta_{k-1}(n)\mid\Delta_k(n)\mid\Gamma.
\tag{1.4}
\]

Thus `C` is a positive integer. Now define

\[
Q:=\frac{\Delta_{k-1}(n)}{B^-},
\qquad
G:=\frac{\Gamma}{\Delta_k(n)}.
\tag{1.5}
\]

Since `\Delta_k=D\Delta_{k-1}`,

\[
\boxed{C=DQG.}
\tag{1.6}
\]

Moreover, because `\Delta_k` divides each moving cut,

\[
\boxed{
G=\gcd_c\frac{M(c)}{\Delta_k(n)}.
}
\tag{1.7}
\]

This decomposition is the main structural fact. `Q` comes from the full Fitting ideal and is present in every `k`-minor; `G` is the only part specific to the restricted moving-cut family.

In particular `D\mid C`. Valuation monotonicity then gives

\[
H=\frac D{\gcd(D,E)}\mid
\Sigma^\ast=\frac C{\gcd(C,E)}.
\tag{1.8}
\]

If `d=v_\ell(D)`, `u=v_\ell(QG)`, and `e=v_\ell(E)`, then

v_\ell(\Sigma^\ast/H)

which proves the stronger divisibility

\[
\boxed{\Sigma^\ast/H\mid QG.}
\tag{1.9}

## 3. Exact large-prime valuation of the unavoidable factor `Q`

Fix `p>\sqrt n`, and write

\[
h=\lfloor n/p\rfloor,\qquad r=n-hp,\qquad
\epsilon=\mathbf 1_{p\mid b_r}.
\]

Since `p^2>n`, only the first power of `p` can occur in any LCM cutoff. Among the factors of `B^-`, the prime `p` occurs exactly `\max(h-q-1,0)` times, each cubed:

\[
\boxed{v_p(B^-)=3\max(h-q-1,0).}
\tag{3.1}
\]

The exact corank is `c_n(p)=h+\epsilon`. The factor `\Delta_{k-1}` contains all Smith factors except the final `q+1`, hence it contains the first

\[
\max(c_n(p)-(q+1),0)
\]

positive `p`-Smith exponents.

The large-prime scalar-core theorem says that, if `\epsilon=0`, these relevant exponents are all `3`; if `\epsilon=1`, they begin with one residual exponent `e_p(n)\in\{1,2,3\}` followed by `3`s. Therefore

\[
v_p(\Delta_{k-1})=
\begin{cases}
3\max(h-q-1,0),&\epsilon=0,\\
e_p(n)+3(h-q-1),&\epsilon=1,\ h\ge q+1,\\
0,&h\le q.
\end{cases}
\tag{3.2}
\]

Subtracting (3.1) gives

\[
\boxed{
v_p(Q)=
\begin{cases}
e_p(n),&h\ge q+1\text{ and }p\mid b_r,\\
0,&\text{otherwise}.
\end{cases}}
\tag{3.3}
\]

Define

\[
T_q(n)=
\prod_{\substack{p>\sqrt n\\
\lfloor n/p\rfloor\ge q+1\\
p\mid b_{n\bmod p}}}p.
\tag{3.4}
\]

Then, exactly,

\[
\boxed{T_q(n)\mid Q_{>\sqrt n}\mid T_q(n)^3.}
\tag{3.5}
\]

This is the powered union of the deeper candidate shells.

## 4. Small primes in `Q`

Use the shifted `(k-1)\times(k-1` minor with rows `0,\ldots,k-2` and columns `1,\ldots,k-1`. It is triangular with determinant

\[
((k-1)!)^3.
\]

Hence

\[
\Delta_{k-1}(n)\mid((k-1)!)^3.
\tag{4.1}
\]

On the other hand

\[
v_p(B^-)=3\sum_{a\ge1}
\max\!\left(\left\lfloor\frac n{p^a}\right\rfloor-q-1,0\right).
\tag{4.2}
\]

Legendre's formula and the elementary bound

\[
0\le
\left\lfloor\frac{n-q-1}{p^a}\right\rfloor-
\max\!\left(\left\lfloor\frac n{p^a}\right\rfloor-q-1,0\right)
\le q+1

give

\[
\boxed{v_p(Q)\le3(q+1)\lfloor\log_p n\rfloor.}
\tag{4.3}

Therefore

\[
\begin{aligned}
\log Q_{\le\sqrt n}
&\le3(q+1)\sum_{p\le\sqrt n}
\lfloor\log_p n\rfloor\log p\\
&=O_q(\sqrt n),
\end{aligned}
\tag{4.4}
\]

using Chebyshev's `\vartheta(x)=O(x)` and the prime-power decomposition of the sum. Thus

\[
\boxed{
\log T_q(n)\le\log Q
\le3\log T_q(n)+O_q(\sqrt n).
}
\tag{4.5}

\tag{5.1}

At size `n-1`, the corank is exactly `h`, and `E=d_{k-1}(n-1)` is the `(h-q)`th positive exponent, again interior. Hence

v_p(E)=3.

Writing `g_p=v_p(G)` and using `C=DQG`, we obtain

## 6. What varying `c` actually gains on the desired target shell

Let `p>\sqrt n` be a fixed-`q` target prime:

\[
n=qp+r,\qquad p\mid b_r,\qquad0<r<p.
\]

Here `Q` and `E` are `p`-units. Let

\[
a=v_p(K_r(qp)).
\]

For the cut `c=p`, the `q` complete `(p-1)`-blocks are `p`-units, so

\[
v_p(M(p))=a.
\tag{6.1}
\]

The scalar-core theorem gives

\[
v_p(D)=\min(a,3).
\tag{6.2}
\]

If `a\le3`, then `D\mid\Gamma\mid M(p)` already forces `v_p(\Gamma)=v_p(D)`.

If `a>3` and `r\ge q`, use `c=p+1`. Modulo `p`, `J_n` splits into `q` complete singular `p`-blocks followed by the singular residual `r`-block. The deleted vertices

\[
p,\ 2p+1,\ldots,\ qp+q-1
\]

hit each complete block except the first once and hit the residual block once. Every such block is irreducible tridiagonal of corank one, so every kernel coordinate is nonzero; deleting any one vertex leaves a nonzero principal cofactor. Thus all hit blocks contribute `p`-units.

The untouched first block contributes

\[
K_p(0)=(p!)^3b_p.
\]

Apéry Lucas gives `b_p\equiv b_1=5\pmod p`, so for `p\ne5` this determinant has valuation exactly `3`. Terms using an aligned inter-block edge use the off-diagonal entry twice and therefore have valuation at least `6`. Hence

\[
\boxed{v_p(M(p+1))=3.}
\tag{6.3}
\]

Combining (6.1)-(6.3),

\[
\boxed{v_p(\Gamma)=v_p(D),\qquad v_p(G)=0.}
\tag{6.4}
\]

If `r<q`, then `p` divides one of the finitely many fixed integers `b_1,\ldots,b_{q-1}`. For fixed `q` this gives only finitely many prime exceptions; `p=5` is also fixed. Therefore for all sufficiently large fixed-`q` target primes,

\[
\boxed{v_p(\Sigma^\ast)=v_p(H).}
\tag{6.5}
\]

So the moving family genuinely solves the **target multiplicity** issue. Its failure is the imported deeper-layer factor `Q`, not the desired shell itself.

## 7. Rollover endpoint

## 9. Why a Bézout/resultant identity among cuts cannot remove `Q`

Normalize each cut by `B^-`:

\[
\widetilde M(c):=M(c)/B^-.
\]

Using `\Delta_k=D\Delta_{k-1}` and the definition of `Q`,

\[
\widetilde M(c)
=DQ\cdot\frac{M(c)}{\Delta_k(n)}.
\tag{9.1}
\]

Therefore

\[
\boxed{DQ\mid\widetilde M(c)\quad\text{for every }c.}
\tag{9.2}
\]

Every integer linear combination of the normalized cuts is still divisible by `DQ`. A Euclidean algorithm, Desnanot identity, or resultant among these cuts can therefore only reduce the final factor `G`. It cannot remove `Q` unless one divides by an additional characteristic-zero content already containing the same prime support.

So the exact residual premises for a square-root-height conclusion split into two independent statements:

\[
\boxed{
\log T_q(n)=O_q(\sqrt n\,\mathrm{polylog}\,n)
}
\tag{9.3}
\]

for the unavoidable lower-Fitting high tail, and

\[
\boxed{
\log G_{n,q}
=O_q(\sqrt n\,\mathrm{polylog}\,n),
\qquad
G_{n,q}:=\gcd_c\frac{M(c)}{\Delta_k(n)},
}
\tag{9.4}
\]

for the genuine moving-family excess.

Under (9.3)-(9.4), (5.5) would give the desired square-root bound for `\Sigma^\ast/H`. Without (9.3), even the fantasy `G=1` is insufficient.

This is the exact residual premise, not a generic warning that “gcds are hard.”
