# Verdict: VALID, with the standard q6 shell stated explicitly

The proposed joint-shallow deletion is correct. The exact rectangular bounds are

\[
\boxed{
|\mathcal M^-_T(U,A)|
\ll \frac{UA(U+A)}{\log T}
}
\]
for true minus rows with \(1\le u\le U\), \(1\le a=L^-\le A\), and

\[
\boxed{
|\mathcal M^+_T(W,A)|
\ll \frac{WA(W+A)}{\log T}
}
\]
for true plus rows with \(1\le w=q-1-u\le W\), \(1\le a=L^+\le A\), provided the rows are in the current macroscopic q6 shell, equivalently with the lower endpoint prime satisfying \(p>T/7\). In the usual row shell \(m\ge T\), this lower bound is automatic from
\[
m=6p+r<7p.
\]
Since \(q>p\), also \(q>T/7\).

More precisely, if \(\kappa\) is any absolute constant with
\[
\log b_j\le \kappa j\qquad(j\ge1),
\]
then one has the explicit bounds
\[
\boxed{
|\mathcal M^-_T(U,A)|
\le
\frac{\kappa}{4\log(T/7)}\,UA(U+A+2)
}
\tag{R-}
\]
and
\[
\boxed{
|\mathcal M^+_T(W,A)|
\le
\frac{\kappa}{4\log(T/7)}\,WA(W+A+2).
}
\tag{R+}
\]
An elementary choice of \(\kappa\) follows directly from the binomial formula for the Apéry numbers: \(b_j\le (j+1)64^j\), so for \(j\ge1\), \(\log b_j\le (\log64+1)j\).

Thus the exact asymptotic rectangular hypotheses are
\[
UA(U+A+2)=o\!\left(\frac{T^2}{\log T}\right)
\tag{C-}
\]
and
\[
WA(W+A+2)=o\!\left(\frac{T^2}{\log T}\right).
\tag{C+}
\]
Under either condition, the corresponding row count is
\[
o\!\left(\frac{T^2}{\log^2T}\right).
\]
For the square corner \(U=A=H\), or \(W=A=H\), this becomes exactly
\[
\boxed{
H=o\!\left(\frac{T^{2/3}}{(\log T)^{1/3}}\right).
}
\]

The new region is genuinely nonempty relative to the existing one-coordinate threshold \(H=o(T^{2/3}/\sqrt{\log T})\), but it is a **corner enlargement**, not a global replacement: it permits a larger secondary index only when the matched upper/reflected index is shallow as well. For example
\[
H(T)=\frac{T^{2/3}}{(\log T)^{5/12}}
\]
satisfies the new square-corner hypothesis, while
\[
\frac{H(T)}{T^{2/3}/\sqrt{\log T}}
=(\log T)^{1/12}\to\infty,
\]
so this range is not covered by the older a-only threshold.

# 1. Minus geometry

Write one q6 row as
\[
m=6q+u=6p+r,
\qquad q=p+d,
\qquad 0\le u<q,
\qquad 0\le r<p.
\]
Subtracting the two representations gives
\[
\boxed{r=u+6d.}
\tag{1.1}
\]
The minus secondary index is
\[
L^-=7d-r-1,
\]
so by (1.1)
\[
\boxed{a:=L^-=d-1-u.}
\tag{1.2}
\]
Hence
\[
\boxed{d=u+a+1.}
\tag{1.3}
\]
This identity is exact.

A true minus secondary row has the two required zero divisibilities
\[
\boxed{q\mid b_u,\qquad p\mid b_a.}
\tag{1.4}
\]
The first is the upper q-selected condition. The second is exactly the minus secondary-zero condition at \(a=L^-\). Thus the proposed radical argument uses genuine Apéry zeros, not merely a formal continuant root.

# 2. Fixed \((u,a)\): injectivity and multiplicity

Fix integers \(u,a\ge1\). Equation (1.3) fixes
\[
d=u+a+1.
\]
For any row in this cell,
\[
p=q-d.
\]
If two rows had the same \(q\), then they would have the same \(u\), the same \(d\), the same \(p\), and hence the same row
\[
m=6q+u.
\]
Therefore distinct rows in one \((u,a)\)-cell have distinct \(q\)'s. Since subtraction by the fixed \(d\) is injective, they also have distinct \(p\)'s.

Let the rows in this cell be indexed by \(i=1,\ldots,R_{u,a}^-\), with endpoint primes \(p_i<q_i\). Then (1.4) gives
\[
\prod_i p_i\mid \operatorname{rad}(b_a),
\qquad
\prod_i q_i\mid \operatorname{rad}(b_u).
\tag{2.1}
\]
Consequently
\[
\boxed{
\left(\prod_i p_i\right)\left(\prod_i q_i\right)
\mid
\operatorname{rad}(b_a)\operatorname{rad}(b_u).
}
\tag{2.2}
\]

## Cross equality \(p_i=q_j\) causes no defect

This is worth checking valuation-by-valuation. The \(p_i\)'s are pairwise distinct and the \(q_i\)'s are pairwise distinct. Hence any rational prime \(\lambda\) occurs at most once in the lower list and at most once in the upper list. If \(\lambda=p_i=q_j\), then
\[
\lambda\mid b_a
\quad\text{and}\quad
\lambda\mid b_u,
\]
so the right side of (2.2) has exactly the two available radical copies needed to pay the exponent \(2\) on the left. Thus possible cross-row equality does not require coprimality of the two endpoint products and does not lose occurrence multiplicity.

# 3. Minus cell bound and rectangular summation

Every charged lower endpoint in the current shell satisfies
\[
p_i>T/7,
\]
and \(q_i>p_i\), so
\[
q_i>T/7.
\]
Therefore
\[
2R_{u,a}^-\log(T/7)
\le
\log\left(\prod_i p_iq_i\right).
\tag{3.1}
\]
Using (2.2),
\[
2R_{u,a}^-\log(T/7)
\le
\log\operatorname{rad}(b_a)+\log\operatorname{rad}(b_u)
\le
\log b_a+\log b_u.
\]
Thus
\[
\boxed{
R_{u,a}^-
\le
\frac{\kappa(a+u)}{2\log(T/7)}.
}
\tag{3.2}
\]
Summing over the rectangle gives
\[
\begin{aligned}
|\mathcal M^-_T(U,A)|
&\le
\frac{\kappa}{2\log(T/7)}
\sum_{u=1}^U\sum_{a=1}^A(u+a)\\
&=
\frac{\kappa}{2\log(T/7)}
\left(
A\frac{U(U+1)}2
+U\frac{A(A+1)}2
\right)\\
&=
\boxed{
\frac{\kappa}{4\log(T/7)}UA(U+A+2).
}
\end{aligned}
\]
This proves (R-). The exponent is cubic on a square: for \(U=A=H\), the numerator is \(2H^3+2H^2\), not \(H^4\).

# 4. Plus geometry and reflection

Again
\[
m=6q+u=6p+r,
\qquad q=p+d,
\qquad r=u+6d.
\]
Put
\[
\boxed{w=q-1-u.}
\tag{4.1}
\]
Since \(0\le u<q\), one has \(0\le w<q\). The pushed Apéry reflection symmetry modulo the prime \(q\) gives
\[
b_{q-1-u}\equiv b_u\pmod q.
\]
Hence the upper selected zero supplies
\[
\boxed{q\mid b_w.}
\tag{4.2}
\]

The plus secondary index is
\[
L^+=r+6d-p.
\]
Using \(r=u+6d\) and \(p=q-d\),
\[
\boxed{
 a:=L^+=u+13d-q.
}
\tag{4.3}
\]
Combining (4.1) and (4.3),
\[
\boxed{a+w=13d-1.}
\tag{4.4}
\]
Thus
\[
\boxed{d=\frac{a+w+1}{13}.}
\tag{4.5}
\]
In particular, an admissible \((w,a)\)-cell must satisfy
\[
a+w+1\equiv0\pmod{13};
\]
cells failing this congruence are empty and only improve the estimate.

A true plus secondary row also gives
\[
\boxed{p\mid b_a.}
\tag{4.6}
\]
Therefore the two divisibilities used by the proposed argument are exactly
\[
\boxed{p\mid b_a,\qquad q\mid b_w.}
\tag{4.7}
\]
Again, these are actual Apéry zero divisibilities. Reflection is used only to move the genuine upper zero from \(u\) to \(w\).

# 5. Fixed \((w,a)\): injectivity

Fix \(w,a\ge1\). If the cell is nonempty, (4.5) fixes \(d\). For a row with upper prime \(q\),
\[
u=q-1-w,
\qquad
p=q-d,
\qquad
m=6q+u=7q-1-w.
\]
Thus \(q\) determines the entire row. Distinct rows in one \((w,a)\)-cell therefore have distinct \(q\)'s and, since \(d\) is fixed, distinct \(p\)'s.

Exactly as in the minus case, if these rows are \((p_i,q_i)\), then
\[
\boxed{
\left(\prod_i p_i\right)\left(\prod_i q_i\right)
\mid
\operatorname{rad}(b_a)\operatorname{rad}(b_w).
}
\tag{5.1}
\]
Possible cross equality \(p_i=q_j\) is harmless for the same valuation reason: a prime occurs at most once in each endpoint list, and if it occurs in both then it divides both \(b_a\) and \(b_w\), so the product of the two radicals supplies exponent two.

# 6. Plus cell bound and rectangular summation

The shell gives \(p_i,q_i>T/7\). Therefore if \(R_{w,a}^+\) is the cell multiplicity,
\[
2R_{w,a}^+\log(T/7)
\le
\log b_a+\log b_w
\le
\kappa(a+w),
\]
so
\[
\boxed{
R_{w,a}^+
\le
\frac{\kappa(a+w)}{2\log(T/7)}.
}
\tag{6.1}
\]
Summing gives
\[
\boxed{
|\mathcal M^+_T(W,A)|
\le
\frac{\kappa}{4\log(T/7)}WA(W+A+2),
}
\]
which is (R+).

# 7. Endpoint audit: \(0\) contributes nothing

The proposed rectangles start at \(1\), and this loses no true events.

- Minus, \(u=0\): the upper condition would require \(q\mid b_0=1\), impossible.
- Minus, \(a=0\): the secondary condition would require \(p\mid b_0=1\), impossible.
- Plus, \(w=0\): (4.2) would require \(q\mid b_0=1\), impossible. Equivalently \(u=q-1\), and reflection gives \(b_{q-1}\equiv b_0\equiv1\pmod q\).
- Plus, \(a=0\): again \(p\mid b_0=1\), impossible.

Thus one may replace \(1\le\cdot\) by \(0\le\cdot\) without changing either true-event set.

# 8. Asymptotic threshold

From (R-), a sufficient and exact rectangular condition is
\[
UA(U+A+2)=o\!\left(\frac{T^2}{\log T}\right).
\]
Then
\[
|\mathcal M^-_T(U,A)|
=o\!\left(\frac{T^2}{\log^2T}\right).
\]
The plus statement is identical with \(U\) replaced by \(W\).

For \(U=A=H\),
\[
UA(U+A+2)=2H^3+2H^2,
\]
so the condition is
\[
H^3=o\!\left(\frac{T^2}{\log T}\right),
\]
i.e.
\[
\boxed{
H=o\!\left(T^{2/3}(\log T)^{-1/3}\right).
}
\]
The same calculation holds for \(W=A=H\).

# 9. Comparison with the existing a-only deletion

The old one-coordinate threshold quoted in the question is
\[
H_{\rm old}=o\!\left(T^{2/3}(\log T)^{-1/2}\right).
\]
The new matched-corner threshold is
\[
H_{\rm new}=o\!\left(T^{2/3}(\log T)^{-1/3}\right).
\]
Their scale ratio is
\[
\frac{T^{2/3}(\log T)^{-1/3}}
     {T^{2/3}(\log T)^{-1/2}}
=(\log T)^{1/6}\to\infty.
\]
So there is a genuine asymptotic band in which the old a-only theorem does not apply but the new joint theorem does. A concrete witness scale is
\[
H(T)=T^{2/3}(\log T)^{-5/12}.
\]
It obeys
\[
H=o\!\left(T^{2/3}(\log T)^{-1/3}\right)
\]
but not
\[
H=o\!\left(T^{2/3}(\log T)^{-1/2}\right).
\]
Hence the claimed new region is genuinely nonempty.

The scope distinction matters: the new theorem does not supersede the old a-only deletion for arbitrary \(u\) or \(w\). It enlarges the deletable secondary range precisely on the matched shallow corners \((u,a)\) and \((w,a)\).
