# Fixed-length full-margin cross-minors: exact curvature identity and universal endpoint no-go

## Executive verdict

The focused answer is **no** for arbitrary integer arrays.

The exact beta-Pade complementary identity does give a whole-family integral endpoint formula. However, after the visible sum of the normalized adjacent minors, an interior bilinear curvature term remains. In the notation developed below, the exact formula is

```text
det(a_0,a_r)
  = sum_{s=0}^{r-1} P_s E_s
    + sum_{0<=t<s<=r-1} P_t P_s det(j_s,j_t),

r = m-1.
```

The second sum is not presentation noise. For arbitrary integer arrays, the packet vectors

```text
j_0,...,j_{r-1}
```

are integrally independent data. The skew form carried by the curvature term has rank

```text
r       if r is even,
r-1     if r is odd.
```

Consequently it cannot be represented by a determinant, or by any fixed number of determinants, of linear boundary packets. At least

```text
floor(r/2) = floor((m-1)/2)
```

packet determinants are required in the generic bilinear category.

There is an even stronger integral obstruction. For every fixed length and every family having at least two adjacent minors, there are actual integer arrays for which

```text
p divides every E_s,
```

while the left-right endpoint determinant is a unit modulo the same arbitrarily large prime. Thus no parameter-only integral Bezout identity can force the gcd of the full family to divide a genuine cross-boundary determinant.

The strongest universal endpoint statement is a **saturated** Plucker identity. If

```text
c_i = gcd(G_{d_i,L}(Y), G_{d_i,L}(Z)),
```

then there are exact integer coefficients such that

```text
(product_{i=1}^{r-1} c_i) det(a_0,a_r)
  = sum_{s=0}^{r-1} U_s P_s E_s.
```

This is integral, but it is useless for the desired height bound: clearing the rational propagation denominators necessarily introduces a product over all interior carrier columns. In the proportional full-margin regime its worst-case logarithmic height is of order

```text
Theta(m n),
```

and hence of order

```text
Theta(n^2)
```

when the maximal margin is linear in the moment.

For the Apéry shell, the weakest genuinely new statement needed is therefore an exact low-height **curvature telescoper**. In ideal form it is

```text
C_curv - B_boundary = sum_s U_s E_s,
```

where

```text
C_curv = sum_{0<=t<s<=r-1} P_t P_s det(j_s,j_t),
```

and where `B_boundary` uses only a fixed number of first-cell shell packets and has controlled primitive height. This identity cannot come from the beta-Pade kernel alone. It must use the actual Apéry coefficient array.

## 2. Exact fixed-length beta-Pade calculus

Fix a length `L`. For a translated carrier beginning at `d`, put

```text
Q_d(T)
  = Q_{d+1,L}(T)
  = sum_{i=0}^L
      (-1)^i binom(d+i,i) binom(d+L+1,L-i) T^i,

R_d(T)
  = R_{d+1,L}(T)
  = sum_{j=0}^d binom(L+j,j) T^j,

B_L(T) = (1-T)^(L+1),

K_d(T) = T^d Q_d(T),

P_d = binom(d+L+1,L).
```

The Q5788 beta-Pade identity, multiplied by `T^(-1)`, is exactly

```text
K_d(T) + T^(-1) B_L(T) R_d(T) = T^(-1).
```

The complementary polynomials are nested, with one new monomial at each translation:

```text
R_{d+1}(T) - R_d(T)
  = binom(L+d+1,d+1) T^(d+1)
  = P_d T^(d+1).
```

Subtracting two consecutive beta-Pade identities gives the exact polynomial difference law

```text
K_d(T) - K_{d+1}(T)
  = P_d T^d B_L(T).
```

This is the complete fixed-length kernel reduction. It is stronger and more informative than saying that the rows are related by Pascal identities: it identifies the new independent direction added at translation `d` as the monomial multiple

```text
T^d (1-T)^(L+1).
```

### Pairing with an arbitrary integer array

For the arbitrary-array part, adjoin one formal endpoint value and use the integral pairing

```text
<F,T^q> = F_q.
```

Define

```text
A_d(F) = <F,K_d> = G_{d,L}(F),

S(F) = F_(-1),

H_d(F) = <F,T^(-1) B_L R_d>,

J_d(F) = <F,T^d B_L>.
```

The high-difference packet is explicitly

```text
J_d(F)
  = sum_{q=0}^{L+1}
      (-1)^q binom(L+1,q) F_{d+q}
  = (-1)^(L+1) Delta^(L+1) F_d.
```

Pairing the two polynomial identities gives, with no denominators,

```text
A_d(F) + H_d(F) = S(F),

H_{d+1}(F) - H_d(F) = P_d J_d(F),

A_d(F) - A_{d+1}(F) = P_d J_d(F).
```

The last line is precisely the adjacent-difference factor used to prove integrality of the primitive cross-minor.

## 3. Vector form and exact integrality of every E_s

For two arbitrary integer arrays `Y,Z`, define the two-vectors

```text
a_d = (A_d(Y), A_d(Z)),

h_d = (H_d(Y), H_d(Z)),

sigma = (S(Y), S(Z)),

j_d = (J_d(Y), J_d(Z)).
```

Use the determinant convention

```text
det((x_1,y_1),(x_2,y_2)) = x_1 y_2 - y_1 x_2.
```

The beta-Pade equations become

```text
a_d + h_d = sigma,

a_d - a_{d+1} = P_d j_d,

h_{d+1} - h_d = P_d j_d.
```

Therefore

```text
det(a_d,a_{d+1})
  = det(a_{d+1}+P_d j_d,a_{d+1})
  = P_d det(j_d,a_{d+1}).
```

Thus the normalized minor is integrally equal to either of the two adjacent packet Wronskians

```text
E_{d,L}
  = det(a_d,a_{d+1}) / P_d
  = det(j_d,a_{d+1})
  = det(j_d,a_d).
```

No rational Smith argument is being used here. The quotient is an exact integer because the numerator has been written as `P_d` times an explicit integral determinant.

## 4. The exact whole-family endpoint identity

Now use the full fixed-length family in the question. Put

```text
r = m-1,

d_s = d0+s,                 0 <= s <= r,

P_s = binom(d_s+L+1,L),      0 <= s <= r-1,

a_s = a_{d_s},

j_s = j_{d_s},

E_s = E_{d_s,L}.
```

Iterating the exact difference law gives

```text
a_s
  = a_0 - sum_{t=0}^{s-1} P_t j_t,


a_{s+1}
  = a_0 - sum_{t=0}^{s} P_t j_t.
```

Substitution into the integral Wronskian formula gives, for every edge,

```text
E_s
  = det(j_s,a_0)
    - sum_{t=0}^{s-1} P_t det(j_s,j_t).
```

The left-right endpoint determinant is

```text
det(a_0,a_r)
  = sum_{s=0}^{r-1} P_s det(j_s,a_0).
```

Eliminating the terms `det(j_s,a_0)` yields the exact whole-family identity

```text
THEOREM 4.1.

For arbitrary integer arrays Y,Z,

  det(a_0,a_r)
    = sum_{s=0}^{r-1} P_s E_s
      + C_curv,

where

  C_curv
    = sum_{0<=t<s<=r-1}
        P_t P_s det(j_s,j_t).
```

This is the exact answer supplied by binomial inversion and the complementary beta-Pade polynomial. It is already a Bezout-style relation in the sense that

```text
gcd(E_0,...,E_{r-1})
```

divides

```text
det(a_0,a_r) - C_curv.
```

But `C_curv` uses all interior high-difference packets. The requested O(1)-boundary collapse would require a new identity that removes this term.

### Equivalent complementary-polygon form

The same obstruction can be written entirely in the complementary packets. For each edge,

```text
P_s E_s
  = det(h_{s+1},sigma)
    - det(h_s,sigma)
    + det(h_s,h_{s+1}).
```

Summing gives

```text
sum_{s=0}^{r-1} P_s E_s
  = det(h_r,sigma)
    - det(h_0,sigma)
    + sum_{s=0}^{r-1} det(h_s,h_{s+1}).
```

The first two terms are true endpoints. The final sum is the signed area of the complementary-packet path. This area is the same curvature obstruction as `C_curv`.

The Q/R identity therefore supplies a boundary term plus an interior area, not a pure boundary term.

## 5. Why maximal m does not remove the curvature

The crucial point is that the high-difference packets remain independent for arbitrary integer arrays even at the maximal first-cell margin.

### Integral realization lemma

Fix `d0,L,r`. Given arbitrary integers

```text
A_0,
J_0,...,J_{r-1},
```

there exists an integer sequence `F` such that

```text
G_{d0,L}(F) = A_0,

J_{d0+s}(F) = J_s
for 0 <= s <= r-1.
```

Proof:

1. Set any initial block of `L+1` consecutive values.
2. Recursively choose the next value so that the prescribed `(L+1)`-st difference is obtained. The coefficient of the new last value is `+1` or `-1`, so every step stays integral.
3. After the differences are fixed, add one integer constant to the entire used block. Every `J_s` is unchanged, while the carrier changes by that constant because

```text
sum_{i=0}^L
  (-1)^i binom(d0+i,i) binom(d0+L+1,L-i)
  = Q_{d0+1,L}(1)
  = 1.
```

Thus `A_0` can be adjusted to any prescribed integer.

Apply the construction independently to the two coordinates. It follows that the vector data

```text
a_0,j_0,...,j_{r-1}
```

are arbitrary integral data, and the rest of the carrier path is determined only by

```text
a_{s+1}=a_s-P_s j_s.
```

There is no extra universal shell relation hidden in the beta-Pade kernel.

## 6. Direct integral counterexample to endpoint gcd divisibility

Assume the family has at least two edges:

```text
r >= 2.
```

Choose any prime satisfying

```text
p does not divide P_0 P_1.
```

Let `u,v` be least positive inverses modulo `p`:

```text
P_0 u = 1 mod p,

P_1 v = 1 mod p.
```

Define the first three carrier vectors and first two high-difference vectors by

```text
a_1 = (p,p),

j_0 = (u,0),

a_0 = a_1 + P_0 j_0
    = (p+P_0 u,p),

j_1 = (0,-v),

a_2 = a_1 - P_1 j_1
    = (p,p+P_1 v).
```

For every later edge, take

```text
j_s = (0,0),

a_{s+1}=a_s.
```

The recurrence is exact over the integers. The realization lemma produces actual integer arrays `Y,Z` with these carrier vectors. The normalized minors are

```text
E_0 = det(j_0,a_1) = p u,

E_1 = det(j_1,a_2) = p v,

E_s = 0 for s >= 2.
```

Hence

```text
gcd(E_0,...,E_{r-1}) = p gcd(u,v).
```

But the endpoint determinant satisfies

```text
det(a_0,a_r)
  = det(a_0,a_2)
  = 1 mod p.
```

Indeed, modulo `p`, the two endpoints are the independent vectors

```text
a_0 = (1,0) mod p,

a_r = (0,1) mod p.
```

Therefore

```text
gcd(E_0,...,E_{r-1})
  does not divide det(a_0,a_r).
```

Since `p` can be arbitrarily large, no fixed parameter factor can repair this.

The same specialization disproves any identity of the form

```text
B_boundary = sum_s U_s E_s
```

whenever the proposed cross-boundary integer `B_boundary` is nonzero on two independent left and right directions. Every term on the right is divisible by `p`, while the boundary determinant can be chosen to be a unit modulo `p`.

This is the integral zero-separator obstruction. Modulo `p`, a zero interior carrier vector disconnects the chain: the carrier directions on its left and right can be unrelated while every adjacent minor vanishes.

## 7. Exterior-rank obstruction to O(1) packet determinants

The curvature term cannot even be compressed universally to a fixed number of determinants of arbitrary linear packet aggregates.

Put

```text
u_s = P_s j_s.
```

Then

```text
C_curv
  = sum_{0<=t<s<=r-1} det(u_s,u_t).
```

Suppose one tries to write it as a sum of `q` determinants of linear packet aggregates:

```text
C_curv
  = sum_{a=1}^q det(U_a,V_a),

U_a = sum_s alpha_{a,s} u_s,

V_a = sum_s beta_{a,s} u_s.
```

One determinant contributes the skew coefficient matrix

```text
alpha_a beta_a^T - beta_a alpha_a^T,
```

which has rank at most two. The curvature has coefficient matrix

```text
S_{s,t}
  =  1  if s>t,
  = -1  if s<t,
  =  0  if s=t.
```

This matrix has rank

```text
rank(S) = r       for even r,
rank(S) = r-1     for odd r.
```

For even order its Pfaffian is `+1` or `-1`, so its determinant is one. For odd order, the leading even principal submatrix is invertible while skew rank must be even.

Therefore

```text
2q >= rank(S),
```

and hence

```text
q >= floor(r/2)
  = floor((m-1)/2).
```

This lower bound allows each packet aggregate to use every interior `j_s`; it is therefore stronger than a local-boundary no-go. The beta-Pade curvature has exterior rank growing linearly with the margin.

## 8. The strongest universal integral endpoint bridge

Although a pure endpoint identity fails, there is a canonical exact identity after saturating by all interior carrier columns.

Write

```text
a_i=(x_i,y_i),

D_{i,j}=det(a_i,a_j).
```

For every chain, the repeated Plucker identity gives

```text
(product_{i=1}^{r-1} x_i) D_{0,r}
  = sum_{s=0}^{r-1}
      (product_{0<=i<=r, i not in {s,s+1}} x_i)
      D_{s,s+1}.
```

Since

```text
D_{s,s+1}=P_s E_s,
```

this is an exact integral Bezout identity for the normalized minors:

```text
(product_{i=1}^{r-1} x_i) det(a_0,a_r)
  = sum_{s=0}^{r-1}
      (product_{i not in {s,s+1}} x_i)
      P_s E_s.
```

The same formula holds with `x_i` replaced by any fixed primitive integer linear form evaluated at `a_i`.

### Coordinate-free content form

Let

```text
c_i = gcd(x_i,y_i),
```

and choose Bezout coefficients

```text
alpha_i x_i + beta_i y_i = c_i.
```

The local three-column identity is

```text
c_i det(u,w)
  = (alpha_i x_w + beta_i y_w) det(u,a_i)
    + (alpha_i x_u + beta_i y_u) det(a_i,w).
```

Iterating it across the chain gives integers `U_s` such that

```text
(product_{i=1}^{r-1} c_i) det(a_0,a_r)
  = sum_{s=0}^{r-1} U_s P_s E_s.
```

Consequently the universal exact divisibility statement is

```text
gcd(E_0,...,E_{r-1})
  divides
  (product_{i=1}^{r-1} c_i) det(a_0,a_r).
```

Algebraically, if

```text
I = (D_{0,1},D_{1,2},...,D_{r-1,r})
```

in the generic two-row column ring, then

```text
(product_{i=1}^{r-1} (x_i,y_i)) D_{0,r} is contained in I.
```

This saturation is sharp in the relevant sense:

```text
D_{0,r} is not contained in radical(I).
```

Set one interior column equal to zero, take every column to its left along one direction, and every column to its right along an independent direction. All adjacent determinants vanish, but the endpoint determinant does not.

Thus rational transitivity becomes integral only after multiplying by ideals from every interior column.

## 9. Denominator and height audit

The rational slope identity behind the previous formula is

```text
D_{0,r}/(x_0 x_r)
  = sum_{s=0}^{r-1}
      D_{s,s+1}/(x_s x_{s+1}),
```

whenever the displayed coordinates are nonzero. Clearing denominators gives exactly the product identity above. Therefore a rational finite-difference or slope elimination does not yield an integral endpoint theorem unless every interior denominator is accounted for.

For the full-margin family in the question,

```text
d0 = D-m+1,

L = N+m-2,

r = m-1,

d_s = D-m+1+s.
```

The adjacent factorials are

```text
P_s
  = binom(d_s+L+1,L)
  = binom(D+N+s,N+m-2),

0 <= s <= m-2.
```

When all macroscopic parameters are proportional to `n`, Stirling's formula gives

```text
log P_s = Theta(n).
```

A transition argument that clears a product of these factors has height

```text
log product_s P_s = Theta(m n).
```

At maximal linear margin this becomes

```text
Theta(n^2).
```

The carrier-coordinate saturation has the same problem. The individual shell carriers have linear exponential scale, so a product of one coordinate or one content from every interior column can again have logarithmic height of order `m n`.

This cannot explain a final gcd of only 30 to 60 bits. It merely transfers the large interior data into an explicit multiplier.

The scalar Bezout identity for the numbers `P_s` does not help. Although integers `lambda_s` can satisfy

```text
sum_s lambda_s P_s = gcd(P_0,...,P_{r-1}),
```

one has

```text
sum_s lambda_s P_s j_s,
```

not a common vector times the scalar gcd. The vectors `j_s` are independent for arbitrary arrays. Treating them as one shared state is precisely the false step that the exact Q/R difference law rules out.

## 10. What maximal m actually changes

For each normalized edge, the Kummer numerator interval of `P_s` is

```text
I_s
  = [d_s+2, d_s+L+1]
  = [D-m+s+3, D+N+s].
```

The intersection over the complete fixed-length family is exactly

```text
intersection_{s=0}^{m-2} I_s
  = [D+1,D+N].
```

This interval is independent of `m`. Its `k`-fold ghost interval is

```text
[ceil((D+1)/k), floor((D+N)/k)].
```

Thus moving to the maximal margin does not create a new beta-Pade endpoint factor. It does two things only:

1. it pushes the union of shell nodes to one or both first-cell boundaries;
2. it maximizes the number

```text
m-1
```

of independent high-difference packet Wronskians.

For a large prime in the common Kummer window, Q5788 gives the exact normalized congruence

```text
E_s
  = J_{d_s}(Y) Z_{kp-1}
    - Y_{kp-1} J_{d_s}(Z)
    mod p.
```

In vector form, with

```text
v_p = (Y_{kp-1}, Z_{kp-1}),
```

this is

```text
E_s = det(j_s,v_p) mod p.
```

Hence the exact common-factor condition is

```text
p divides every E_s
iff
det(j_s,v_p)=0 mod p for every s.
```

If `v_p` is nonzero, every added full-margin edge imposes another collinearity condition on `j_s`. This is an exact structural reason that the nuisance gcd can collapse rapidly as `m` grows. It is not an endpoint Bezout identity.

If `v_p` is zero, all those congruences vanish automatically. This is the modular zero-separator analogue and is why a universal endpoint determinant cannot retain exactly the desired target support without extra Apéry arithmetic.

## 11. The weakest Apéry-shell-specific identity needed

For a first-cell shell array, the high-difference packet has the exact constant-term form

```text
J_d(C_M)
  = CT[
      Lambda^M
      sum_{kappa in {-1,0,1}^3}
        T_kappa^d (1-T_kappa)^(L+1)
    ].
```

For two moment choices `Y,Z`, the curvature is therefore an explicit bilinear constant-term sum. The beta-Pade kernel has reduced the problem to this one object:

```text
C_curv
  = sum_{0<=t<s<=r-1}
      P_t P_s
      (J_s(Y)J_t(Z)-J_s(Z)J_t(Y)).
```

The logically weakest exact shell-specific endpoint theorem is the following ideal certificate.

```text
There exist an integer B_boundary and integers U_s such that

  C_curv - B_boundary = sum_s U_s E_s,

where B_boundary uses only O(1) first-cell endpoint packets.
```

Combining this with Theorem 4.1 gives

```text
det(a_0,a_r) - B_boundary
  = sum_s (P_s+U_s) E_s,
```

and hence

```text
gcd_s E_s
  divides det(a_0,a_r)-B_boundary.
```

To be useful for height, the certificate must also satisfy all of the following.

```text
1. B_boundary has primitive logarithmic height o(n),
   or has an exact removable factorial content leaving o(n) height.

2. Any common denominator used to construct U_s or B_boundary
   has logarithmic height o(n).

3. The denominator is one global low-height factor,
   not product_{s} P_s and not product_{s} ell(a_s).

4. The identity is proved before specializing numerical n,D,N.
```

### Concrete bounded-width telescoper ansatz

Define the incremental curvature

```text
C_s
  = sum_{t=0}^{s-1} P_t P_s det(j_s,j_t)
  = P_s det(j_s, sum_{t<s} P_t j_t).
```

A concrete sufficient Apéry identity would be

```text
C_s
  = B_{s+1}-B_s
    + sum_{q=-R}^{R} u_{s,q} E_{s+q},
```

with

```text
R = O(1),
```

where `B_s` is built from a fixed number of shifted first-cell shell packets and all coefficients are integral after one low-height global denominator. Summing in `s` collapses the curvature to

```text
B_r-B_0
```

plus an integral combination of the `E_s`.

This is the appropriate WZ or creative-telescoping target. A recurrence of fixed order for the packet state is not enough by itself: iterating a transfer matrix across `m` steps generally recreates an exponential-height transition product. What is needed is a genuine discrete Lagrange or WZ boundary certificate.

### Weaker radical-only alternative

For prime support alone, it would be enough to prove that every nuisance prime dividing all `E_s` sees no zero interior carrier vector:

```text
a_i is nonzero mod p
for every 1 <= i <= r-1.
```

Then adjacent collinearity propagates over the field and forces the endpoint determinant to vanish modulo `p`. This does not give an integral Bezout identity, does not control prime powers, and is usually incompatible with target primes whose marked shell vector is itself zero. It is therefore weaker than what the gcd-height problem requires.

## 12. Dependency-free symbolic checker

The following standard-library script checks:

- the exact Q/R complementary identity;
- the exact fixed-length difference law;
- integrality of `E_s`;
- the endpoint-plus-curvature formula;
- the saturated Plucker identity;
- the explicit arbitrary-prime counterexample, including construction of actual integer arrays realizing the prescribed packet path.

```python
from math import comb, gcd, prod


def C(n, k):
    return comb(n, k) if 0 <= k <= n else 0


def clean(poly):
    return {k: v for k, v in poly.items() if v}


def add(left, right):
    out = dict(left)
    for k, v in right.items():
        out[k] = out.get(k, 0) + v
    return clean(out)


def scale(poly, scalar):
    return clean({k: scalar * v for k, v in poly.items()})


def shift(poly, amount):
    return {k + amount: v for k, v in poly.items()}


def multiply(left, right):
    out = {}
    for i, a in left.items():
        for j, b in right.items():
            out[i + j] = out.get(i + j, 0) + a * b
    return clean(out)


def q_poly(d, L):
    return {
        i: (-1) ** i * C(d + i, i) * C(d + L + 1, L - i)
        for i in range(L + 1)
    }


def r_poly(d, L):
    return {j: C(L + j, j) for j in range(d + 1)}


def b_poly(L):
    return {q: (-1) ** q * C(L + 1, q) for q in range(L + 2)}


def pair(poly, values):
    return sum(coefficient * values.get(index, 0)
               for index, coefficient in poly.items())


def G(values, d, L):
    return sum(
        (-1) ** i
        * C(d + i, i)
        * C(d + L + 1, L - i)
        * values[d + i]
        for i in range(L + 1)
    )


def J(values, d, L):
    return sum(
        (-1) ** q * C(L + 1, q) * values[d + q]
        for q in range(L + 2)
    )


def H(values, d, L):
    poly = shift(multiply(b_poly(L), r_poly(d, L)), -1)
    return pair(poly, values)


def det(left, right):
    return left[0] * right[1] - left[1] * right[0]


def add_vec(left, right):
    return (left[0] + right[0], left[1] + right[1])


def sub_vec(left, right):
    return (left[0] - right[0], left[1] - right[1])


def scale_vec(scalar, vector):
    return (scalar * vector[0], scalar * vector[1])


def gcd_many(values):
    out = 0
    for value in values:
        out = gcd(out, abs(value))
    return out


def realize(d0, L, A0, prescribed_J):
    """Integral realization lemma for one scalar array."""
    r = len(prescribed_J)
    values = {k: 0 for k in range(d0, d0 + L + 1)}

    for s, target in enumerate(prescribed_J):
        d = d0 + s
        known = sum(
            (-1) ** q * C(L + 1, q) * values[d + q]
            for q in range(L + 1)
        )
        last_coefficient = (-1) ** (L + 1)
        values[d + L + 1] = (target - known) // last_coefficient
        assert J(values, d, L) == target

    correction = A0 - G(values, d0, L)
    for k in range(d0, d0 + r + L + 1):
        values[k] = values.get(k, 0) + correction

    assert G(values, d0, L) == A0
    for s, target in enumerate(prescribed_J):
        assert J(values, d0 + s, L) == target
    values[-1] = 0
    return values


def audit_qr():
    for d in range(1, 9):
        for L in range(0, 7):
            Q = q_poly(d, L)
            R = r_poly(d, L)
            B = b_poly(L)

            complement = add(
                shift(Q, d),
                shift(multiply(B, R), -1),
            )
            assert complement == {-1: 1}
            assert sum(Q.values()) == 1

            next_Q = q_poly(d + 1, L)
            difference = add(
                shift(Q, d),
                scale(shift(next_Q, d + 1), -1),
            )
            P = C(d + L + 1, L)
            assert difference == scale(shift(B, d), P)


def audit_arrays():
    d0, L, r = 3, 4, 5
    lower = -1
    upper = d0 + r + L
    Y = {k: (k + 7) ** 3 - 2 * k + 11
         for k in range(lower, upper + 1)}
    Z = {k: 3 ** (k + 2) + 5 * k * k - 7
         for k in range(lower, upper + 1)}

    a = [
        (G(Y, d0 + s, L), G(Z, d0 + s, L))
        for s in range(r + 1)
    ]
    h = [
        (H(Y, d0 + s, L), H(Z, d0 + s, L))
        for s in range(r + 1)
    ]
    sigma = (Y[-1], Z[-1])
    j = [
        (J(Y, d0 + s, L), J(Z, d0 + s, L))
        for s in range(r)
    ]
    P = [C(d0 + s + L + 1, L) for s in range(r)]

    for s in range(r + 1):
        assert add_vec(a[s], h[s]) == sigma

    E = []
    for s in range(r):
        assert sub_vec(a[s], a[s + 1]) == scale_vec(P[s], j[s])
        raw = det(a[s], a[s + 1])
        assert raw % P[s] == 0
        value = raw // P[s]
        assert value == det(j[s], a[s + 1])
        E.append(value)

    curvature = sum(
        P[t] * P[s] * det(j[s], j[t])
        for s in range(r)
        for t in range(s)
    )
    endpoint = det(a[0], a[r])
    assert endpoint == sum(P[s] * E[s] for s in range(r)) + curvature

    polygon = sum(det(h[s], h[s + 1]) for s in range(r))
    assert sum(P[s] * E[s] for s in range(r)) == (
        det(h[r], sigma) - det(h[0], sigma) + polygon
    )

    x = [vector[0] for vector in a]
    plucker_left = prod(x[1:r]) * endpoint
    plucker_right = sum(
        prod(x[i] for i in range(r + 1) if i not in (s, s + 1))
        * P[s]
        * E[s]
        for s in range(r)
    )
    assert plucker_left == plucker_right


def audit_counterexample():
    d0, L, r = 4, 3, 4
    p = 101
    P = [C(d0 + s + L + 1, L) for s in range(r)]
    assert P[0] % p and P[1] % p

    u = pow(P[0], -1, p)
    v = pow(P[1], -1, p)

    j = [(u, 0), (0, -v)] + [(0, 0)] * (r - 2)
    a0 = (p + P[0] * u, p)
    a = [a0]
    for s in range(r):
        a.append(sub_vec(a[-1], scale_vec(P[s], j[s])))

    assert a[1] == (p, p)
    assert a[2] == (p, p + P[1] * v)

    Y = realize(d0, L, a0[0], [vector[0] for vector in j])
    Z = realize(d0, L, a0[1], [vector[1] for vector in j])

    actual_a = [
        (G(Y, d0 + s, L), G(Z, d0 + s, L))
        for s in range(r + 1)
    ]
    assert actual_a == a

    E = []
    for s in range(r):
        raw = det(a[s], a[s + 1])
        assert raw % P[s] == 0
        E.append(raw // P[s])

    assert E[0] == p * u
    assert E[1] == p * v
    assert all(value == 0 for value in E[2:])

    common = gcd_many(E)
    endpoint = det(a[0], a[-1])
    assert common % p == 0
    assert endpoint % p == 1


def main():
    audit_qr()
    audit_arrays()
    audit_counterexample()
    print("PASS: Q/R, curvature, Plucker saturation, integral no-go")


if __name__ == "__main__":
    main()
```

## 13. Final conclusion

The exact beta-Pade/Newton kernel does **not** provide the requested universal O(1)-boundary determinant for the maximal fixed-length family.

What it provides exactly is

```text
endpoint determinant
  = visible integral combination of E_s
    + full-rank curvature of the independent high-difference packets.
```

The curvature is generically of exterior rank proportional to `m`, and an explicit integral prime counterexample rules out any unsaturated cross-boundary gcd divisibility theorem. The only universal endpoint bridge carries a product of all intermediate carrier contents or coordinates, whose height is too large.

Therefore the observed 30-60-bit collapse at maximal margin should be interpreted as simultaneous vanishing of many exact packet Wronskians, not as a hidden beta-Pade endpoint Bezout identity. To convert that collapse into a theorem, the next exact target is the Apéry-specific low-height curvature certificate stated in Section 11.
