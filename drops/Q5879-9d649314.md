# 2. The six-column Smith lemma

For `i=m-1,m`, form the integer matrix

\[
 {\cal R}_i=
 \begin{pmatrix}
 (R_{-1,i})_1&(R_{0,i})_1&\cdots&(R_{4,i})_1\\
 (R_{-1,i})_2&(R_{0,i})_2&\cdots&(R_{4,i})_2
 \end{pmatrix}
 \in M_{2,6}(\mathbb Z).
\tag{2.1}
\]

Let

\[
 \delta_i=d_2({\cal R}_i)
 :=\gcd_{-1\le r<s\le4}
 \det(R_{r,i},R_{s,i})
\tag{2.2}
\]

be its second determinantal divisor, and put

\[
 \gamma_i:=\gcd(A_i^-,A_i^+),
\qquad
 \kappa_i:=\gcd(H_i,T_{0,i},\ldots,T_{4,i}).
\tag{2.3}
\]

## Theorem 2.1 — exact six-column divisibility

For each admissible margin `i`,

\[
\boxed{
 c_i\kappa_i\mid\gamma_i\delta_i.
}
\tag{2.4}
\]

### Proof

Write

\[
 A_i=\gamma_i A_i^{\rm prim},
 \qquad \gcd((A_i^{\rm prim})_1,(A_i^{\rm prim})_2)=1.
\]

Choose `U in SL_2(Z)` sending `A_i^{prim}` to `(1,0)`.  Write

\[
 UR_{r,i}=(x_r,y_r).
\]

Unimodularity preserves all gcds of `2 x 2` minors.  Therefore

\[
 \det(A_i,R_{r,i})=\gamma_i y_r.
\]

Since `c_i` divides all six determinants by (1.20),

\[
 c_i\kappa_i
 =\gcd_r\det(A_i,R_{r,i})
 =\gamma_i\gcd_r y_r.
\tag{2.5}
\]

Put `t=gcd_r y_r`.  Every pairwise minor

\[
 x_ry_s-y_rx_s
\]

is divisible by `t`, hence `t|delta_i`.  Equation (2.4) follows.  This is exactly the two-row Smith argument behind equation (68.152), now with the origin-cancelled column adjoined.

## Primewise form

If a prime `ell` divides all six carriers at margin `i`, then

\[
 \ell\nmid c_i\delta_i
 \quad\Longrightarrow\quad
 \ell\mid A_i^-\text{ and }\ell\mid A_i^+.
\tag{2.6}
\]

No generic rank statement stronger than (2.6) is available: `delta_i` is precisely the rank-drop obstruction.

\[
\boxed{
 \operatorname{rad}K_{\rm hyb}\mid

# 4. Sharp top-half non-target corollary

Let `p` be a safe prime in the retained core `(D,D+N]`.  Lagrange reduction of every Newton row containing `p-1` gives

\[
 A_i^-\equiv A_i^+\equiv Y_{p-1}\equiv b_{n-p}\pmod p.
\tag{4.1}

The common-node Kummer calculation gives

\[
 v_p(g_i)=v_p(Q_I)=1,
 \qquad p\nmid c_i.
\tag{4.2}

For `p>5`, Apéry--Lucas gives

\[
 p\mid b_n\Longleftrightarrow p\mid b_{n-p}.
\tag{4.3}

\[
 p\mid\kappa_i\Longrightarrow p\mid\delta_i.

Using both margins gives the promised primewise elimination:

\[
\boxed{
 p\in(D,D+N],\quad p\mid K_{\rm hyb},\quad p\nmid b_n,

 p\mid\gcd(\delta_{m-1},\delta_m).

\tag{4.5}
\]

Thus, inside the actual target interval, **all non-target leakage is exactly a simultaneous six-column rank drop**.  The endpoint packets in (3.8) are needed only for primes outside this clean core or for primes at excluded normalizer boundaries.

# 5. Why the theorem does not yet give `o(n)`

The fixed origin content is harmless.  The current script proves

\[
 \gcd_{\mathbb Q[n]}(M,u_0,\ldots,u_4)=1.
\]

Hence there are integer polynomials `a_M,a_0,...,a_4` and a fixed nonzero integer `C_org` such that

\[
 a_M(n)M(n)+\sum_{j=0}^4a_j(n)u_j(n)=C_{\rm org}.
\tag{5.1}
\]

Consequently

\[
 c(n)=\gcd(M(n),u_0(n),\ldots,u_4(n))\mid C_{\rm org}
\tag{5.2}
\]

for every integer `n`.  Any `c_safe` extracted from this content has `O(1)` logarithmic radical.

The remaining factors are different.

1. `c_i=g_i/Q_I` is residual Pascal content.  Its large prime factors are the higher-multiple Kummer ghosts in the common numerator interval; the present exact classification gives only `log c_i=O(n)`.
2. `rho_-` and `rho_+` are binomial coefficients of linear parameters, so each has logarithm `O(n)`.
3. `B_-` and `B_+` are high differences of the actual shell.  The coefficient-sum bound for the Laurent polynomial gives `log|B_\pm|=O(n)`, and the boundary audit records linear-size bit lengths.
4. Each quotient column `R_{k,i}` is a fixed linear combination of shell values at moments at most `n+9`, multiplied by degree-35 polynomial values and Newton weights.  Hence every `2 x 2` minor has logarithm `O(n)`, but no smaller bound is proved.  The script's values are thousands of bits, exactly on this scale.

Thus (3.9) yields at best

\[
 \log\operatorname{rad}K_{\rm hyb}=O(n),
\tag{5.3}
\]

not `o(n)`.

The empirical `<=21`-bit hybrid gcd is evidence for a new arithmetic collapse, but it is not implied by fixed matrix size.  The exact missing estimate can now be stated without ambiguity:

\[
\boxed{
 \log\operatorname{rad}
 \left[
 c_{m-1}c_m\,
 \delta_{m-1}\delta_m\,
 \gcd(B_-,B_+)
 \right]_{\rm hybrid\ nuisance}
 =o(n).
}
\tag{5.4}
\]

For non-target primes in the retained core, the still sharper missing theorem is

\[
 \log\operatorname{rad}_{\substack{D<p\le D+N\\p\nmid b_n}}
 \gcd(\delta_{m-1},\delta_m)=o(n),
\tag{5.5}
\]

or ideally a divisibility of this radical by a fixed polynomial in `n,D,N,m`.

# 6. A concrete local countermodel

The next proposition explains why no coefficient-only resultant can prove (5.4).

## Proposition 6.1 — arbitrary-prime hybrid leakage

Fix admissible integers `n,D,N,m`.  Let `P_0` be any prescribed nonzero integer built from finitely many evaluations of

```text
M, u_0,...,u_4,
lambda_0,...,lambda_5,
Pascal multipliers and their polynomial resultants.
```

There is a prime `ell` not dividing `P_0`, outside the genuine top-half target set, and an integral finite moment array `C_t(d)` satisfying the exact operator definitions (1.5), (1.13), (1.15), all candidate-primorial divisibilities used to define `H_i,T_(k,i)`, and such that

\[
 \ell\mid H_{m-1},H_m,T_{0,m-1},\ldots,T_{4,m}.
\tag{6.1}
\]

The array may be chosen so that all twelve displayed integers are nonzero and the marked `Y` value is an `ell`-unit.

### Construction

The certified distinguished sequences satisfy

\[
 {\cal U}(J)_n=M(n)b_n,
 \qquad
 {\cal L}(J)_{n+k}=0\quad(0\le k\le4).
\tag{6.2}
\]

Choose an integer `q` clearing the denominators of the finite list

\[
 J_n,J_{n+1},\ldots,J_{n+9}
\]

and put

\[
 a=q b_n,
 \qquad s_t=qJ_t.
\tag{6.3}
\]

On the complete node interval needed by the two margins, define

\[
 C_{n-1}(d)=a
\tag{6.4}
\]

for every `d`.  For each `n<=t<=n+9`, choose an integral spatial row satisfying

\[
 C_t(d-1)+C_t(d+1)=s_t
\tag{6.5}
\]

at every required node.  This always has an integral solution: choose two initial entries and use

\[
 C_t(d+1)=s_t-C_t(d-1).
\]

Equations (6.2)--(6.5) give, identically in `d`,

\[
 Y_d=a,
 \qquad Z_n(d)=M(n)a,
 \qquad W_d=0,
 \qquad X_n^{(k)}(d)=0.
\tag{6.6}
\]

The Newton weights in (1.3) sum to one.  Hence

\[
 A_i=(a,a),
 \qquad B_i=0,
 \qquad R_{k,i}=0,
\tag{6.7}
\]

and all hybrid carriers vanish.

Now choose a prime

\[
 \ell\nmid
 P_0Q_Ic_{\rm safe}c_{m-1}c_ma.
\tag{6.8}
\]

Perturb every finitely used coefficient by

\[
 C'_t(d)=C_t(d)+
 \ell Q_Ic_{\rm safe}c_{m-1}c_m E_t(d),
 \qquad E_t(d)\in\mathbb Z.
\tag{6.9}
\]

Modulo every candidate prime, (6.9) preserves the nodewise ghost vanishing needed for the exact divisions by `Q_I`.  Modulo `ell`, it preserves (6.6)--(6.7).  After division by `g_i=Q_Ic_i` or `c_i`, every hybrid carrier is therefore still divisible by `ell`; the extra factors in (6.9) also ensure that division by `c_safe` is legitimate.

The twelve carrier values are polynomial functions of the finitely many variables `E_t(d)`.  None is the zero polynomial—the actual shell specialization already supplies nonzero examples.  A finite union of proper algebraic hypersurfaces cannot cover `Z^r`, so the perturbation can be chosen with all twelve values nonzero.

Finally choose `ell>n`; it is automatically not a genuine top-half target and can avoid the arbitrary fixed integer `P_0`.

### Consequence

The proposition does **not** disprove a theorem for the distinguished Laurent shell.  It proves the precise no-go needed here:

> the determinant definitions, the Ore--CRT identity, the common-annihilator identity, the candidate node congruences, and fixed polynomial resultants do not force a coefficient-only nuisance factor.

Any successful theorem for the actual shell must use information absent from the model, such as the coefficient formula for `Lambda^n`, the quotient-one/quotient-two packet decomposition, or a WZ identity for the maximal boundary packets.  This is why the evaluated factors `delta_i` and `B_\pm` cannot simply be deleted from (3.8).

# 7. Executable Sage certificate

The following code is a drop-in companion to the two current scripts.  It takes the exact `Y`, `W`, and five ghost dictionaries already constructed there, computes the six-column Smith factors, verifies (2.4), verifies both boundary identities, forms (3.8), and checks every prime of the small observed `K_hyb` against (3.9).

```sage
#!/usr/bin/env sage

from pathlib import Path
import sys

HERE = Path(__file__).resolve().parent
sys.path.insert(0, str(HERE))
load(str(HERE / "q32_ghost_quotient_audit.sage"))


def det2(left, right):
    return ZZ(left[0]) * ZZ(right[1]) - ZZ(left[1]) * ZZ(right[0])


def fd(values, start, order):
    return ZZ(sum(
        (-1) ** (order - j) * binomial(order, j) * values[start + j]
        for j in range(order + 1)
    ))


def radical_support(value):
    value = abs(ZZ(value))
    return prod(p for p, _ in factor(value)) if value not in (0, 1) else value


def margin_vectors(Y, W, ghosts, D, N, margin, QI):
    d = D - margin + 1
    L = N + margin - 2
    A = (
        newton_carrier(Y, d, L),
        newton_carrier(Y, D, L),
    )
    B = (
        newton_carrier(W, d, L),
        newton_carrier(W, D, L),
    )
    g = margin_normalizer(D, N, margin)
    assert g % QI == 0
    c = g // QI
    assert B[0] % QI == 0 and B[1] % QI == 0

    columns = [(B[0] // QI, B[1] // QI)]
    for k in GHOST_SHIFTS:
        X = (
            newton_carrier(ghosts[k], d, L),
            newton_carrier(ghosts[k], D, L),
        )
        assert X[0] % QI == 0 and X[1] % QI == 0
        columns.append((X[0] // QI, X[1] // QI))

    carriers = []
    for column in columns:
        numerator = det2(A, column)
        assert numerator % c == 0
        carriers.append(numerator // c)

    H = carriers[0]
    T = tuple(carriers[1:])
    assert H == det2(A, B) // g

    delta = gcd_many(
        det2(columns[r], columns[s])
        for r in range(len(columns))
        for s in range(r + 1, len(columns))
    )
    gamma = gcd_many(A)
    kappa = gcd_many(carriers)
    assert (gamma * delta) % (c * kappa) == 0

    return {
        "margin": margin,
        "d": d,
        "L": L,
        "A": A,
        "B": B,
        "columns": tuple(columns),
        "H": H,
        "T": T,
        "c": c,
        "gamma": gamma,
        "delta": delta,
        "kappa": kappa,
    }


def hybrid_primewise_certificate(
    index, D, N, Y, W, ghosts, c_safe
):
    moment = index - 1
    m = min(
        D - moment // 2,
        moment - D - N + 2,
    )
    assert m >= 3
    margins = (m - 1, m)

    candidates = tuple(prime_range(D + 1, D + N + 1))
    QI = ZZ(prod(candidates))
    rec = {
        i: margin_vectors(Y, W, ghosts, D, N, i, QI)
        for i in margins
    }

    h_gcd = gcd_many(rec[i]["H"] for i in margins)
    assert h_gcd % c_safe == 0
    t_gcd = gcd_many(
        value
        for i in margins
        for value in rec[i]["T"]
    )
    Khyb = gcd(h_gcd // c_safe, t_gcd)

    d = rec[m]["d"]
    L = rec[m]["L"]
    rho_minus = binomial(D + N, L)
    rho_plus = binomial(D + L, L)
    Bminus = fd(Y, d, L)
    Bplus = fd(Y, D, L)

    assert rec[m]["A"][0] - rec[m - 1]["A"][0] == (
        (-1) ** L * rho_minus * Bminus
    )
    assert rec[m]["A"][1] - rec[m - 1]["A"][1] == (
        (-1) ** L * rho_plus * Bplus
    )

    obstruction = ZZ(
        c_safe
        * rec[m - 1]["c"] * rec[m]["c"]
        * rec[m - 1]["delta"] * rec[m]["delta"]
        * rho_minus * rho_plus
        * gcd(Bminus, Bplus)
    )

    # Khyb is tiny in the reported scan, so factoring only Khyb is cheap.
    for ell, _ in factor(abs(Khyb)):
        assert obstruction % ell == 0

    # Strong non-target core test (4.5).
    for p in candidates:
        if Khyb % p or c_safe % p == 0:
            continue
        if ZZ(apery(index - p)) % p != 0:
            assert rec[m - 1]["delta"] % p == 0
            assert rec[m]["delta"] % p == 0

    return {
        "n": index,
        "core": (D, N),
        "margins": margins,
        "Khyb": Khyb,
        "Khyb_factor": factor(abs(Khyb)),
        "obstruction_bits": abs(obstruction).nbits(),
        "boundary": (Bminus, Bplus),
        "records": rec,
    }
```
