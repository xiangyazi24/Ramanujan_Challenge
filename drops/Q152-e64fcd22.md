# p-adic analytic continuation and Strassmann for the Apéry sequence

## 1. Does n ↦ b_n have a p-adic analytic continuation?

The supercongruence

```
b_{mp^s} ≡ b_{mp^{s-1}} (mod p^{3s})
```

is a genuine p-adic phenomenon, but it does not by itself imply that the full sequence n ↦ b_n extends to a rigid analytic function on Z_p.

The limits

```
L_p(m)=lim_s b_{mp^s}
```

exist in Z_p because the congruence gives a Cauchy sequence. However, this only defines values on the sparse set of integers divisible by arbitrarily large powers of p. Extending these values analytically requires compatibility conditions between different residue disks. A p-adic analytic function is determined by much more than isolated congruence limits.

The correct framework is Dwork theory: the Apéry generating function is a period of a K3 family, and its Frobenius structure gives p-adic differential equations. Dwork's unit-root theory can construct analytic functions on ordinary loci, but a global analytic interpolation of the integer sequence b_n is not currently known.

## 2. Mahler expansion and Strassmann

Any continuous function f:Z_p→Z_p has a Mahler expansion

```
f(n)=Σ c_k binom(n,k).
```

For the Apéry sequence the formal coefficients are

```
c_k = Δ^k b_0.
```

They are integers, but their p-adic valuations are not known in a form strong enough for Strassmann.

Strassmann would require a bound of the form:

```
min_k v_p(c_k)
```

with a unique controlling coefficient. No such valuation theorem is currently available.

Even if obtained, Strassmann controls zeros of an analytic function in Z_p. The set

```
Z_p={r mod p : b_r=0 mod p}
```

is a reduction modulo p condition, not a zero set of a p-adic analytic function on the whole disk. Additional lifting information would be needed.

Therefore Strassmann does not currently improve the known bounds on |Z_p|.

## 3. Relation with p-adic L-functions

The analogy with Bernoulli numbers is suggestive but incomplete.

For Bernoulli numbers, Kummer congruences arise from special values of a single p-adic L-function. The congruences encode variation in the weight variable.

For the Apéry modular form f in S_4(Γ_0(6)), there are p-adic L-functions attached to f (in the sense of Mazur-Swinnerton-Dyer, Stevens, Panchishkin and others). They interpolate critical L-values of f, not directly the Apéry coefficients b_n.

The sequence b_n is a period sequence of the associated motive, not a sequence of special values of L(f,s). Thus the Iwasawa μ-invariant of the modular form's p-adic L-function does not directly control zeros of

```
b_n mod p.
```

A new theory connecting Apéry periods to a p-adic L-function in the interpolation variable n would be required.

## 4. Does p-adic theory remove the defining-characteristic barrier?

It removes one obstruction but introduces another.

Advantage:

* crystalline Frobenius works in characteristic p;
* Hasse invariants and Cartier operators directly detect b_r mod p;
* no mismatch between coefficient characteristic and sheaf coefficient characteristic.

This is why the Hasse invariant factorization

```
H_p(t)=B_p(t)^2
```

is so powerful.

However, the CRT problem requires comparing different primes p and q. Crystalline methods are naturally vertical: they analyze one prime at a time. There is no known horizontal independence theorem for the collection

```
{B_p(t)}_p.
```

Ogus crystalline Torelli gives a p-adic period map for a fixed prime p and controls deformation inside that characteristic. It does not provide independence between period maps attached to different characteristics.

---

## Conclusion

The p-adic approach is probably the correct language for understanding individual zero sets Z_p, but it does not currently solve cross-prime independence.

Known:

* Dwork theory explains p-adic unit roots and Frobenius structures.
* Hasse invariants describe the defining-characteristic zero condition.
* Supercongruences give strong vertical congruences.

Missing:

* a p-adic analytic interpolation of b_n;
* valuation estimates for Mahler coefficients;
* a horizontal independence theorem for crystalline period data across primes.

The desired CRT independence would require a new arithmetic-geometric large sieve combining Dwork/Cartier theory with variation in the prime p.
