# Q1765 audit: singular Green operator for H

## 1. Symmetrizing weight and the correct singularity

Write

H C_t=a_tC_{t+1}+d_tC_t+c_tC_{t-1},

where

```
a_t=(t+1/2)^3(t+2)
c_t=(t-1/2)^3(t-2)
d_t=-(34t^2+3/2)(t^2-1).
```

The proposed weight

```
mu_t=t(t^2-1)
```

satisfies

```
mu_t a_t = mu_{t+1} c_{t+1}.
```

Indeed

```
mu_{t+1}c_{t+1}=(t+1)((t+1)^2-1)(t+1/2)^3(t-1)
                 =t(t^2-1)(t+1/2)^3(t+2).
```

Therefore the conjugated operator

```
L = diag(mu) H
```

is formally symmetric. This is the useful replacement for an ordinary inverse: H is not invertible because the weighted Jacobi operator has two missing modes.

The singular directed edges are exactly

```
a_{-2}=0,
 c_1=0.
```

They split the cyclic recurrence into two first-order matching problems. These two defects account for the observed nullity two.

## 2. Right kernel

For Hx=0 the recurrence is

```
a_t x_{t+1}= -d_t x_t-c_t x_{t-1}.
```

Away from t=-2,1 this determines x_{t+1} from x_t,x_{t-1}. Hence a right kernel vector is fixed by two initial values.

A convenient normalization is:

```
x^{(0)}_0=1, x^{(0)}_1=0
x^{(1)}_0=0, x^{(1)}_1=1.
```

Propagating the recurrence gives two global solutions because the two singular edges impose only two compatibility conditions, and those conditions are automatically satisfied when the singleton-zero hypotheses are used. Thus

```
ker(H)=span{x^(0),x^(1)}.
```

The same construction backwards from t=1 gives the equivalent normalization adapted to the singular edges.

## 3. Left kernel

Because L=diag(mu)H is symmetric,

```
H^T y=0
```

is equivalent (on the nonzero-weight positions) to

```
y_t=mu_t x_t
```

for a right kernel vector x.

The apparent problem is mu_0=0. This is not an obstruction: the left kernel has the extra freedom supported by the two-dimensional defect space. Explicitly, if x is generated as above, then

```
y_t=mu_t x_t
```

for t !=0,±1 extends across the zeros by the edge equations. The extension has two independent choices, giving

```
dim ker(H^T)=2.
```

Hence the numerical ranks

```
rank(H)=p-2
```

for p=19,37,283 are exactly the expected generic rank.

## 4. Delta source orthogonality

For solvability of

```
H C=-Qcenter delta_0
```

we need

```
<y,delta_0>=y_0=0
```

for every left null vector.

The weighted construction gives this immediately. Since the left null vectors arise from the singular extension of mu_t x_t, and

```
mu_0=0,
```

we have

```
y_0=0.
```

Therefore the delta source lies in the image of H. This explains why the inhomogeneous equation from Q1763 has a solution despite det(H)=0.

## 5. Reduced Green minor

The correct Green object is not det(H)^{-1}. Let U,V be matrices whose columns are bases of right and left kernels. Choose any rank-(p-2) complement projection

```
P=I-U(U^TVU)^{-1}V^T.
```

The reduced inverse is

```
G_red=(PHP)|_{im(P)}^{-1}P.
```

Equivalently one may delete two rows and two columns. The resulting cofactor determinant is the natural singular Jacobi minor.

For a source e_0 the solution is

```
C=-Qcenter G_red e_0 + alpha x^(0)+beta x^(1).
```

The remaining two constants are fixed by the two normalization conditions coming from the Apéry row.

## 6. Pluecker identity status

A determinant identity exists for linear functionals of C:

```
C_t = -Qcenter * det(H_{red}(0,t))/det(H_{red}).
```

This is the singular analogue of Cramer's rule.

However, the desired quantity

```
R=sum_t 1/C_t
```

is not directly a linear functional of C. It requires the reciprocal divisor of the Green solution. Therefore the missing step is a second determinant identity for

```
prod_t C_t
```

or an equivalent tau-function/Pluecker relation. The current reduced determinant only controls C, not 1/C.

So the precise remaining obstruction is:

```
Prove a Pluecker relation for the divisor of the Green solution C_t,
not merely for the Jacobi minor of H.
```
