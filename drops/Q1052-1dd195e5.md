# Q1052: radical containment for the full Padé minor

## 1. Status of (R)

The proposed implication

```text
p >= 5 and p | D_n  ==>  p | b_n
```

is not proved by the available half-cutoff and carry-free suffix facts alone.  Those facts prove a weaker statement: for every prime p dividing the gcd, every index j with p ∤ L_j(n) satisfies

```text
b_j = b_n (mod p).
```

To deduce p | b_n one needs one such unit-weight index j with

```text
b_j = 0 (mod p).
```

The carry-free suffix lemma only supplies existence of unit-weight indices. It does not guarantee that the supplied index is an Apéry zero modulo p.

Therefore the claimed implication is reduced to the following missing arithmetic statement:

```text
For every p >= 5 dividing D_n, there exists j < floor(n/2)
with p ∤ L_j(n) and b_j = 0 (mod p).
```

No such statement follows from Lucas alone.

## 2. Exact unit-weight characterization

Write

```text
L_j(n)=(-1)^(M-1-j) C(n,j) C(n-j-1,M-1-j).
```

The sign is irrelevant modulo p. For a prime p,

```text
p ∤ L_j(n)
```

iff both binomial coefficients are nonzero modulo p.

By Lucas/Kummer this is exactly:

```text
C(n,j) != 0 mod p
```

and

```text
C(n-j-1,M-1-j) != 0 mod p.
```

Equivalently, both additions are carry-free in base p:

```text
j + (n-j) = n
```

and

```text
(M-1-j) + (n-M) = n-j-1.
```

The second condition is not equivalent to digitwise comparison between M-1-j and n-M after ignoring borrows. Prime powers require the full valuation formula

```text
v_p(C(a,b)) = sum_{r>=1} ( floor(a/p^r)-floor(b/p^r)-floor((a-b)/p^r) ),
```

so the unit condition is the simultaneous vanishing of all Kummer carry counts at every p^r.

## 3. What p | D_n actually gives

Assume p | D_n. Then for every j,

```text
p | L_j(n)(b_n-b_j).
```

For every unit index j in U_p(n),

```text
p ∤ L_j(n),
```

hence

```text
b_j = b_n (mod p).
```

The argument does not permit replacing this by

```text
b_j = 0 (mod p).
```

That replacement is precisely the unproved step required for (R).

The indices j=0,1 give the strong elimination:

```text
L_0(n) = C(n-1,M-1),
L_1(n) = n C(n-2,M-2).
```

If both are p-units, then

```text
b_0=b_1=b_n (mod p).
```

Since b_0=1 and b_1=5 for the Apéry sequence,

```text
p | (b_1-b_0)=4,
```

which excludes all odd p>=5. However there remain primes for which at least one of these two weights is divisible by p.

## 4. Finite computation

The following search pattern is the correct exact test. It uses Apéry-Lucas residues rather than floating point values.

```python
from math import comb

# apery numbers modulo p by recurrence

def apery_mod(N, p):
    b=[1,5]
    for n in range(1,N):
        # (n+1)^3 b_(n+1) = (34 n^3+51 n^2+27 n+5)b_n - n^3 b_(n-1)
        a=(34*n**3+51*n*n+27*n+5)%p
        rhs=(a*b[n]-n**3*b[n-1])%p
        den=(n+1)**3%p
        if den==0:
            b.append(None)
        else:
            b.append(rhs*pow(den,-1,p)%p)
    return b

# for each n and p, check all unit weights and gcd condition
```

A complete run must report separately:

* incidences p | D_n,
* incidences p | b_n,
* incidences p | D_n but p ∤ b_n.

The available n<=1200 computation gives zero failures, but this is evidence only.

## 5. Consequence if (R) were proved

The exact consequence would be

```text
rad_{>=5}(D_n) divides rad(b_n).
```

Together with the already proved top-half valuation statement,

```text
D_n = S_n * product_(n/2<p<=n, p|b_(n-p)) p,
```

one would obtain the stronger containment

```text
rad(D_n) | rad(b_n) * rad(product_(n/2<p<=n, p|b_(n-p))p)
```

with the top-half factor already controlled.

However this does not by itself imply

```text
log D_n = o(n).
```

The missing input would be an independent height estimate for the relevant Apéry values or for their radical. Divisibility by b_n is a structural containment, not a height bound.

## 6. Obstruction

The current obstruction is not a determinant-height obstruction. It is an arithmetic gap:

```text
unit-weight index  =>  equality with b_n mod p
```

but no available theorem gives

```text
unit-weight index  =>  a known Apéry zero mod p.
```

The finite data supports (R), but a proof requires a new theorem connecting the Kummer geometry of L_j(n) with the zero set of Apéry numbers modulo p. Until that bridge is supplied, (R) remains a conjectural strengthening rather than a proved radical containment.
