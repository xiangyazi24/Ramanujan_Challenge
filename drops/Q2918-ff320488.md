# P3.2 cold algebra audit: fixed-r forward differences, quadratic cancellation, and the fixed-q obstruction

## Verdict

There is a clean theorem-level local statement, but it is weaker than a global no-go.

Let

\[
U_r(X)=\sum_{k\ge 0}u_{r,k}X^k\in \mathbf Z_p[[X]],\qquad u_{r,0}=b_r,
\]

for the fixed residue index \(r<p\), and assume \(p\mid b_r\). Put

\[
\lambda_r:=\frac{b_r}{p}\in\mathbf Z_p,
\qquad \delta:=\lambda_r\pmod p,
\qquad F_c:=U_r(cp).
\]

Then for fixed integers \(c\),

\[
F_c=p(\lambda_r+c\,u_{r,1})+p^2c^2u_{r,2}+p^3c^3u_{r,3}+\cdots.
\]

The forward differences annihilate \(b_r\) **exactly**, not merely to leading order. For every \(d\ge1\),

\[
\Delta^dF_c
=\sum_{k\ge d}u_{r,k}p^k\Delta^d(c^k),
\]

and the exact Stirling/falling-factorial formula is

\[
\boxed{
\Delta^dF_c
=\sum_{k\ge d}u_{r,k}p^k
\sum_{j=d}^{k}{k\brace j}\,j!\binom{c}{j-d}.
}
\]

In particular,

\[
\boxed{
\Delta^dF_c
=p^d d!\,u_{r,d}
+p^{d+1}d!\left((d+1)c+\binom{d+1}{2}\right)u_{r,d+1}
+O(p^{d+2}).
}
\]

Thus, if \(d<p\),

\[
\frac{\Delta^dF_c}{p^d}\equiv d!\,u_{r,d}\pmod p.
\]

For homogeneous quadratic forms there is an exact order-\(p^2\) classification. If \(Q\) is a fixed integer homogeneous quadratic form in \(m\) variables and

\[
\mathbf 1=(1,\ldots,1),\qquad
\mathbf c=(c_1,\ldots,c_m),
\]

with polar bilinear form

\[
B_Q(x,y):=Q(x+y)-Q(x)-Q(y),
\]

then

\[
\boxed{
\frac{Q(F_{c_1},\ldots,F_{c_m})}{p^2}
\equiv
Q(\mathbf1)\delta^2
+B_Q(\mathbf1,\mathbf c)\delta\,u_{r,1}
+Q(\mathbf c)u_{r,1}^2
\pmod p.
}
\]

Hence the **universal/formal** condition that the normalized \(p^2\)-term be independent of \(\delta\) is

\[
\boxed{
Q(\mathbf1)=0,\qquad B_Q(\mathbf1,\mathbf c)=0
}
\]

(over \(\mathbf Z\) for a prime-uniform fixed form, or modulo the particular odd prime \(p\) for a one-prime statement). Under those two conditions every surviving quadratic signal is only

\[
\boxed{
Q(\mathbf c)\,u_{r,1}^2\pmod p.
}
\]

So **all** \(\delta\)-free quadratic \(p^2\)-signals collapse to the same local first jet \(u_{r,1}^2\), up to a fixed scalar. If one also demands independence from the first jet for arbitrary admissible \(U_r\), then necessarily \(Q(\mathbf c)=0\), and the entire \(p^2\)-term vanishes. This is the strongest rigorous local obstruction at quadratic order.

The proposed \(2\times2\) Casoratian is the canonical example. With the forward convention

\[
\Delta F_c:=F_{c+1}-F_c,
\]

set

\[
\mathcal C_{a,b}:=F_a\Delta F_b-F_b\Delta F_a.
\]

Exactly,

\[
\mathcal C_{a,b}=F_aF_{b+1}-F_bF_{a+1}.
\]

Its first two nontrivial \(p\)-adic orders are

\[
\boxed{
\mathcal C_{a,b}
=(a-b)p^2u_{r,1}^2
+(a-b)p^3u_{r,2}
\bigl((a+b+1)u_{r,1}-2\lambda_r\bigr)
+O(p^4).
}
\]

Therefore the exact sign at order \(p^2\) is **\(a-b\)**:

\[
\boxed{
\frac{\mathcal C_{a,b}}{p^2}
\equiv (a-b)u_{r,1}^2\pmod p.
}
\]

The \(\delta\)-cancellation is only first-order after normalization: for odd \(p\), \(\delta\) generally reappears in the coefficient of \(p\) through

\[
-2(a-b)\,\delta\,u_{r,2}.
\]

This is important. The Casoratian is **not** an exact target-residue eliminator; it is an order-\(p^2\) eliminator.

For fixed-\(q\) divisor switching, with

\[
p=M-t,\qquad r=a_0+qt,
\]

we obtain only the pointwise statement

\[
\frac{Q(F_{c_1},\ldots,F_{c_m})}{p^2}
\equiv Q(\mathbf c)u_{a_0+qt,1}^2\pmod{M-t}
\]

for any universally \(\delta\)-free quadratic \(Q\), and in particular

\[
\frac{\mathcal C_{a,b}}{p^2}
\equiv(a-b)u_{a_0+qt,1}^2\pmod{M-t}.
\]

The **rigorous obstruction** is: fixed-\(r\) \(c\)-difference algebra supplies no relation whatsoever between the jets \(u_{r,1}\) at distinct values of \(r\). Therefore a divisor-switching argument that uses only (i) local \(p\)-integrality, (ii) \(p\mid u_{r,0}\), and (iii) fixed-\(r\) \(c\)-difference identities cannot convert the quadratic cancellation into a cross-prime bounded-degree certificate. In that axiom system the surviving first jets are free local parameters.

But this does **not** prove that the actual Apéry jets are uncontrolled. The actual family may satisfy extra cross-\(r\) recurrence, Wronskian, hypergeometric, Dwork, or Smith identities. Moreover

\[
r=a_0+qt=a_0+qM-qp\equiv a_0+qM\pmod p,
\]

so if one could prove that \(u_{r,1}\bmod p\) is given by a fixed rational/polynomial function of \(r\) with \(p\)-unit denominator, the moving \(r\) could actually collapse to a fixed residue modulo \(p\). The local difference calculation neither proves nor rules out such a cross-\(r\) formula. Thus the correct conclusion is a sharp obstruction to this **local-only attack class**, not a global impossibility theorem.

## 1. Exact forward-difference calculus

Write \(u_k=u_{r,k}\) for this section and define

\[
\Delta G(c):=G(c+1)-G(c).
\]

Since

\[
F_c=\sum_{k\ge0}u_kp^kc^k,
\]

we have exactly

\[
\Delta^dF_c
=\sum_{k\ge0}u_kp^k\Delta^d(c^k).
\]

Use the falling-factorial expansion

\[
c^k=\sum_{j=0}^k {k\brace j}c^{\underline j},
\qquad
c^{\underline j}=j!\binom cj,
\]

where \({k\brace j}\) is a Stirling number of the second kind. Since

\[
\Delta^d c^{\underline j}
=\frac{j!}{(j-d)!}c^{\underline{j-d}}
=j!\binom c{j-d}
\]

for \(j\ge d\), and vanishes for \(j<d\),

\[
\Delta^d(c^k)
=\sum_{j=d}^k{k\brace j}j!\binom c{j-d}.
\]

Therefore

\[
\boxed{
\Delta^dF_c
=\sum_{k\ge d}u_kp^k
\sum_{j=d}^k{k\brace j}j!\binom c{j-d}.
}
\tag{1}
\]

Equivalently, define the Newton coefficients

\[
A_j:=\Delta^jF_0
=j!\sum_{k\ge j}{k\brace j}u_kp^k.
\]

Then

\[
\boxed{
F_c=\sum_{j\ge0}\binom cj A_j,
\qquad
\Delta^dF_c=\sum_{j\ge d}\binom c{j-d}A_j.
}
\tag{2}
\]

The second form is often the cleanest one for congruences. It gives

\[
A_j\in p^j\mathbf Z_p,
\qquad
A_j\equiv p^j j!u_j\pmod{p^{j+1}}.
\tag{3}
\]

No Apéry-specific input is used here. Rationality of \(U_r\) is also not used except to justify the local Taylor expansion; the identities hold for any \(U_r\in\mathbf Z_p[[X]]\).

At the target \(u_0=b_r=p\lambda_r\),

\[
\begin{aligned}
F_c
&=p(\lambda_r+cu_1)+p^2c^2u_2+p^3c^3u_3+O(p^4),\\
\Delta F_c
&=pu_1+p^2(2c+1)u_2+p^3(3c^2+3c+1)u_3+O(p^4),\\
\Delta^2F_c
&=2p^2u_2+6(c+1)p^3u_3+O(p^4),\\
\Delta^3F_c
&=6p^3u_3+O(p^4).
\end{aligned}
\tag{4}
\]

More generally, from the \(k=d\) and \(k=d+1\) terms of (1),

\[
\boxed{
\Delta^dF_c
=p^dd!u_d
+p^{d+1}d!\left((d+1)c+\binom{d+1}{2}\right)u_{d+1}
+O(p^{d+2}).
}
\tag{5}
\]

Thus every positive-order forward difference eliminates \(u_0=b_r\) exactly. It does not eliminate the higher Taylor jets; it merely moves the first surviving jet from \(u_0\) to \(u_d\).

## 2. Classification of homogeneous quadratics at normalized order \(p^2\)

Let

\[
\mathbf F=(F_{c_1},\ldots,F_{c_m}),
\qquad
\mathbf1=(1,\ldots,1),
\qquad
\mathbf c=(c_1,\ldots,c_m).
\]

Modulo \(p^2\),

\[
\mathbf F
\equiv p(\lambda_r\mathbf1+u_1\mathbf c)\pmod{p^2}.
\]

For a homogeneous quadratic form \(Q\),

\[
Q(x+y)=Q(x)+B_Q(x,y)+Q(y).
\]

Therefore

\[
\frac{Q(\mathbf F)}{p^2}
\equiv
Q(\lambda_r\mathbf1+u_1\mathbf c)
\pmod p,
\]

which expands to

\[
\boxed{
\frac{Q(\mathbf F)}{p^2}
\equiv
Q(\mathbf1)\delta^2
+B_Q(\mathbf1,\mathbf c)\delta u_1
+Q(\mathbf c)u_1^2
\pmod p.
}
\tag{6}
\]

This is the complete order-\(p^2\) answer.

### Coefficient form

Write

\[
Q(z_1,\ldots,z_m)
=\sum_i A_i z_i^2+\sum_{i<j}B_{ij}z_iz_j.
\]

Set

\[
\begin{aligned}
A&:=\sum_iA_i+\sum_{i<j}B_{ij},\\
L&:=2\sum_iA_ic_i+\sum_{i<j}B_{ij}(c_i+c_j),\\
C&:=\sum_iA_ic_i^2+\sum_{i<j}B_{ij}c_ic_j.
\end{aligned}
\]

Then

\[
A=Q(\mathbf1),\qquad
L=B_Q(\mathbf1,\mathbf c),\qquad
C=Q(\mathbf c),
\]

and (6) is simply

\[
\boxed{
p^{-2}Q(\mathbf F)\equiv A\delta^2+L\delta u_1+Cu_1^2\pmod p.
}
\tag{7}
\]

For an odd prime, the robust/formal \(\delta\)-independence conditions are

\[
\boxed{A\equiv0\pmod p,\qquad L\equiv0\pmod p.}
\tag{8}
\]

If \(Q\) and the \(c_i\) are fixed integers and one wants this for all sufficiently large primes, then the prime-uniform classification is the exact integer pair

\[
\boxed{A=0,\qquad L=0.}
\tag{9}
\]

There are two important qualifications.

1. At one particular target, if \(u_1\equiv0\pmod p\), then the \(L\)-term vanishes accidentally. That is not a structural cancellation.
2. If \(\delta=0\), i.e. \(p^2\mid b_r\), every \(\delta\)-dependence is invisible at that particular target. Again this is accidental and cannot classify the form.

Under (8),

\[
\boxed{
p^{-2}Q(\mathbf F)\equiv C u_1^2\pmod p.}
\tag{10}
\]

So the space of all quadratic \(\delta\)-free leading signals has image of dimension at most one: everything is a fixed scalar multiple of \(u_1^2\).

If one asks for the normalized \(p^2\)-term to be independent of **both** \(\delta\) and the unknown first jet for arbitrary admissible local series, then \(C=0\) as well, hence

\[
p^{-2}Q(\mathbf F)\equiv0\pmod p.
\]

There is no nonzero universal constant left at quadratic order.

## 3. Exact residue-cancellation hierarchy beyond order \(p^2\)

The previous classification is only the first layer of a useful exact identity. Put

\[
\mathbf c^{[k]}=(c_1^k,\ldots,c_m^k).
\]

Then

\[
\mathbf F
=p\lambda_r\mathbf1+
\sum_{k\ge1}p^ku_k\mathbf c^{[k]}.
\]

Hence

\[
\begin{aligned}
Q(\mathbf F)
={}&p^2\lambda_r^2Q(\mathbf1)\\
&+\lambda_r\sum_{k\ge1}p^{k+1}u_k
 B_Q(\mathbf1,\mathbf c^{[k]})\\
&+Q\!\left(\sum_{k\ge1}p^ku_k\mathbf c^{[k]}\right).
\end{aligned}
\tag{11}
\]

Therefore the target residue is removed:

- at normalized order \(p^0\) iff \(Q(\mathbf1)=0\) and \(B_Q(\mathbf1,\mathbf c)=0\);
- through the next normalized order iff additionally \(B_Q(\mathbf1,\mathbf c^{[2]})=0\);
- through successively higher orders only after imposing the corresponding moment conditions
  \(B_Q(\mathbf1,\mathbf c^{[k]})=0\).

If the \(c_i\) are pairwise distinct and one demands exact \(u_0\)-independence for arbitrary Taylor jets, the Vandermonde vectors

\[
\mathbf1,\mathbf c,\mathbf c^{[2]},\ldots,\mathbf c^{[m-1]}
\]

span \(\mathbf Q^m\). Thus exact independence forces

\[
B_Q(\mathbf1,z)=0\quad\text{for every }z,
\qquad Q(\mathbf1)=0.
\]

Equivalently,

\[
Q(z+t\mathbf1)=Q(z)
\]

identically: \(Q\) is a quadratic form in the differences \(z_i-z_m\). Such a form eliminates \(b_r\) exactly, but its first nonzero term is still a polynomial in the higher jets. The cancellation never manufactures a cross-\(r\) constant by itself.

## 4. Audit of the \(2\times2\) Casoratian

Define

\[
\mathcal C_{a,b}=F_a\Delta F_b-F_b\Delta F_a,
\qquad
\Delta F_c=F_{c+1}-F_c.
\]

First,

\[
\boxed{
\mathcal C_{a,b}=F_aF_{b+1}-F_bF_{a+1}.
}
\tag{12}
\]

The exact double Taylor sum is

\[
\boxed{
\mathcal C_{a,b}
=\sum_{k,\ell\ge0}u_ku_\ell p^{k+\ell}
\left[a^k(b+1)^\ell-b^k(a+1)^\ell\right].
}
\tag{13}
\]

Remember that the \(k=0\) coefficient itself has the extra target factor \(u_0=p\lambda_r\).

Using (4),

\[
\begin{aligned}
F_a\Delta F_b
={}&p^2(\lambda_r+au_1)u_1\\
&+p^3\left((\lambda_r+au_1)(2b+1)u_2+a^2u_1u_2\right)
+O(p^4),
\end{aligned}
\]

and the same formula with \(a,b\) interchanged. Subtracting gives

\[
\boxed{
\mathcal C_{a,b}
=(a-b)p^2u_1^2
+(a-b)p^3u_2\left((a+b+1)u_1-2\lambda_r\right)
+O(p^4).
}
\tag{14}
\]

The sign is therefore

\[
\boxed{a-b}
\]

for the stated forward-difference convention. A sanity check is \(a=0,b=1\): the leading term is \(-p^2u_1^2\).

Thus

\[
\boxed{
\frac{\mathcal C_{a,b}}{p^2}
\equiv(a-b)u_{r,1}^2\pmod p.
}
\tag{15}
\]

The \(\delta\)-term has canceled completely at this level. But (14) also shows the limitation:

\[
\frac{\mathcal C_{a,b}}{p^2}
=(a-b)u_1^2
+p(a-b)u_2\left((a+b+1)u_1-2\lambda_r\right)
+O(p^2).
\tag{16}
\]

So the first target-residue contamination after the leading term is

\[
\boxed{-2p(a-b)\lambda_r u_2.}
\]

For odd \(p\), modulo the next normalized digit this contributes

\[
-2(a-b)\delta u_2.
\]

The Casoratian is therefore not an exact elimination identity unless some additional relation kills that term (or all the relevant higher moment terms).

## 5. Strongest rigorous obstruction to the fixed-\(q\) switching attack

Now impose the switching parameterization from the question:

\[
p_t=M-t,
\qquad
r_t=a_0+qt.
\]

For a universal \(\delta\)-free quadratic \(Q\), equation (10) gives at each target

\[
\boxed{
\frac{Q(F_{c_1},\ldots,F_{c_m})}{p_t^2}
\equiv Q(\mathbf c)u_{r_t,1}^2
\pmod{p_t}.
}
\tag{17}
\]

For the Casoratian,

\[
\boxed{
\frac{\mathcal C_{a,b}(r_t)}{p_t^2}
\equiv(a-b)u_{a_0+qt,1}^2
\pmod{M-t}.
}
\tag{18}
\]

This exposes the exact mismatch:

- the \(c\)-difference calculus compares \(U_r(cp)\) at several \(c\)'s while holding **the same \(r\)** fixed;
- divisor switching changes \(p\) and, when \(q\ne0\), changes \(r\) simultaneously.

The local algebra has no operator that transports \(u_{r,1}\) to \(u_{r+q,1}\).

### A precise non-derivability statement for the local axiom system

Suppose the only hypotheses available about each \(U_r\) are:

1. \(U_r\in\mathbf Z_p[[X]]\) locally at the relevant prime;
2. \(p\mid u_{r,0}\) at the target;
3. identities obtained from evaluating the same \(U_r\) at \(cp\) and taking \(c\)-differences.

For distinct target indices \(r_t\), the first jets are independent parameters in this axiom system. Indeed, for any finite collection of targets and arbitrary prescribed \(\lambda_t,\alpha_t\in\mathbf Z_{p_t}\), the polynomial local models

\[
U_{r_t}(X)=p_t\lambda_t+\alpha_tX
\]

satisfy all three hypotheses and realize arbitrary \(u_{r_t,1}=\alpha_t\). Higher jets can be prescribed independently by adding \(\beta_tX^2+\cdots\).

Therefore no cross-\(t\) relation on the residues

\[
u_{r_t,1}^2\pmod{p_t}
\]

can be deduced from those local hypotheses alone. In particular, after the quadratic \(\delta\)-cancellation, there is no theorem in this local axiom system that turns (17) or (18) into a fixed bounded-degree polynomial/rational function of \(t\), or into a prime-independent constant.

This is a genuine obstruction theorem for the **attack class defined by those inputs**.

### Why this is not a global no-go

The actual Apéry family has much more structure than an arbitrary collection of local power series. The argument above does **not** prove any of the following:

- that \(u_{r,1}\) is arithmetically random as \(r\) varies;
- that no recurrence in \(r\) exists for \(u_{r,1}\);
- that a Wronskian or contiguous relation cannot express \(u_{r,1}\) in terms of known Apéry data;
- that a higher-degree determinant or higher finite-difference construction cannot eliminate \(u_{r,1}\) and expose a more rigid quantity;
- that a Dwork/Smith/hypergeometric identity cannot couple the moving \(p\) and \(r\);
- that fixed-\(q\) divisor switching is impossible in principle.

There is also an especially important escape hatch in the actual switching geometry:

\[
r_t=a_0+qt=a_0+q(M-p_t)=a_0+qM-qp_t,
\]

hence

\[
\boxed{r_t\equiv a_0+qM\pmod{p_t}.}
\tag{19}
\]

So if a surviving jet were proved to have the form

\[
u_{r,1}\equiv R(r)\pmod p
\]

for a fixed rational function \(R\) whose denominator is a \(p\)-unit in the relevant range, then (19) would give

\[
u_{r_t,1}\equiv R(a_0+qM)\pmod{p_t},
\]

and the apparent moving-\(r\) obstruction would disappear modulo each target prime. The fixed-\(r\) difference algebra itself does not provide such a formula, but it also cannot exclude it.

Thus the strongest correct conclusion is:

> **Local quadratic no-go.** At normalized order \(p^2\), every fixed integer homogeneous quadratic combination of the values \(F_{c_i}=U_r(c_ip)\) whose leading residue is formally independent of \(\delta=b_r/p\bmod p\) reduces to a fixed scalar multiple of \(u_{r,1}^2\). The \(2\times2\) Casoratian gives the scalar \(a-b\), with sign exactly as in (15). Fixed-\(r\) \(c\)-difference identities alone provide no cross-\(r\) control of this surviving jet, so they are insufficient by themselves for fixed-\(q\) divisor switching when \(r=a_0+qt\) varies. Any successful continuation must add a genuinely cross-\(r\) theorem about the surviving jet(s). This does not rule out such an Apéry-specific theorem.

That is the rigorous obstruction and the correct stopping point.

## 6. Small-prime and degeneracy caveats

1. **\(p=2\).** Formulae (1)--(16) are integral identities and remain valid provided the assumed Taylor coefficients are \(2\)-integral. But classification by polynomial functions of \(\delta\) has an extra degeneracy because \(\delta^2=\delta\) in \(\mathbf F_2\). The robust/formal conditions \(Q(\mathbf1)=B_Q(\mathbf1,\mathbf c)=0\) are still the correct prime-uniform conditions, but they are stronger than mere constancy as a function on the two-element field. Also the next Casoratian contamination \(-2(a-b)\delta u_2\) vanishes modulo \(2\), so the first reappearance of \(\delta\) can be delayed.

2. **\(p=3\).** The degree-two polynomial classification has no functional collapse: degree \(2<3\), so the usual coefficient test is valid. Nevertheless all assumed \(3\)-integrality of the Taylor coefficients must be checked in the actual Apéry normalization; it does not follow from the formal algebra.

3. **Large forward-difference order.** Although
   \[
   \Delta^dF_c/p^d\equiv d!u_d\pmod p
   \]
   is always formally correct, it ceases to identify \(u_d\bmod p\) once \(d\ge p\), because \(p\mid d!\).

4. **Shift collisions modulo \(p\).** If \(p\mid a-b\), the Casoratian \(p^2\)-term vanishes. For fixed distinct integers \(a,b\), this is only a finite set of small exceptional primes; if \(a,b\) themselves vary with \(p\), it must be tracked explicitly.

5. **Vanishing first jet.** If \(u_{r,1}\equiv0\pmod p\), then the nominal \(p^2\) Casoratian term vanishes and the true first nonzero order is higher. One may not divide by \(u_{r,1}\) or infer a unit without a separate lemma.

6. **Higher target valuation.** If \(p^2\mid b_r\), then \(\delta=0\); any apparent \(\delta\)-cancellation at that prime is vacuous.

7. **\(q=0\).** The moving-\(r\) obstruction disappears if \(q=0\), because then \(r=a_0\) is fixed under switching. The obstruction discussed above is specifically the \(q\ne0\) situation in which the candidate primes correspond to distinct residue indices.

8. **Fixed versus \(p\)-dependent forms.** The exact integer classification (9) assumes the \(c_i\) and coefficients of \(Q\) are fixed independently of \(p\). A deliberately \(p\)-dependent quadratic form can exploit congruences unavailable to a fixed form and lies outside this audited class.

## Final assessment

The \(c\)-difference idea does accomplish something real: it can remove the target digit \(\delta\) from the first normalized quadratic layer. The Casoratian does this optimally and yields

\[
\boxed{(a-b)u_{r,1}^2}
\]

with the exact sign \(a-b\).

But that cancellation trades the target value \(u_{r,0}/p\) for the first local jet \(u_{r,1}\). In fixed-\(q\) divisor switching the residue index moves with the prime, so the fixed-\(r\) difference algebra alone has no mechanism for comparing those first jets across candidates. That is the exact, rigorous obstruction. The next mathematically meaningful question is therefore not another quadratic \(c\)-combination; it is whether the **actual Apéry jet** \(u_{r,1}\) admits a cross-\(r\) congruence/recurrence strong enough to exploit \(r\equiv a_0+qM\pmod p\).
