# Q7173 toric degree audit R2

## Audit result

The proposed degree lower bound is correct under the stated Laurent-polynomial hypotheses. The argument is unconditional once the exact properties

* `CT(Λ^n)=b_n`,
* Λ has nonnegative integral coefficients,
* `Λ(1,1,1)=40`,
* hence `(Λ-1)(1,1,1)=39`,

are available from the repository.

The only required correction is the endpoint convention: the lower-bound argument applies only when the reduced representative degree satisfies `d_p < p-1`. When `d_p=p-1`, no nonzero finite-difference vanishing argument forces the next difference to vanish.

## Finite-difference lemma

Let `f(r)=b_r mod p` on `F_p`, and suppose its reduced polynomial representative is `P(X)` of degree `d<p-1`.

For every integer `m>d`,

```
Δ^m P(0)=0.
```

Taking `m=d+1`, and using the constant-term representation,

```
Δ^m b_0 = CT((Λ-1)^m).
```

The sign is positive here: the binomial identity gives

```
Σ_{j=0}^m (-1)^{m-j} C(m,j) Λ^j=(Λ-1)^m,
```

so the finite difference equals the constant term of `(Λ-1)^m` exactly.

Reduction modulo `p` gives

```
p | CT((Λ-1)^{d+1}).
```

Because `(Λ-1)` has nonnegative coefficients, including constant coefficient `4`, we have

```
CT((Λ-1)^m) >= 4^m >0.
```

Therefore the divisible integer cannot be zero, and hence

```
p <= CT((Λ-1)^{d+1}).
```

On the other hand evaluation at `(1,1,1)` bounds the sum of coefficients:

```
CT((Λ-1)^m) <= (Λ(1,1,1)-1)^m =39^m.
```

Thus

```
p <=39^{d+1},
```

and therefore

```
d >= log(p)/log(39)-1.
```

No exceptional prime occurs in this inequality except the excluded case `d=p-1`; the statement is not claiming anything for the full-degree representative.

## Consequence for zero bounds

A degree lower bound is a lower bound on interpolation complexity, not an upper bound on the number of roots. It prevents very low-degree collapse of the sequence modulo p, but by itself does not imply a useful estimate for

```
#{r : b_r=0 mod p}.
```

A degree-`d` polynomial over `F_p` can still have at most `d` roots, but here the bound gives only

```
d >= c log p,
```

rather than an upper bound `d << p^α` with α<1. Hence it does not produce a square-root-scale variance estimate.

## Square/twisted-square Hasse route

The square/twisted-square Hasse factorization can be useful only if it supplies an additional structural restriction such as:

1. bounded multiplicity of roots of the Hasse polynomial;
2. equidistribution of the relevant Frobenius parameters;
3. a monodromy statement controlling the image of the parameter map.

The factorization alone does not imply these properties. A factorization identity tells how the Hasse polynomial decomposes, but without a theorem on the factors' arithmetic distribution it does not control the number of zero parameters.

Therefore the rigorous conclusion is:

* the logarithmic interpolation-degree obstruction is proved;
* it rules out extremely low-degree periodic collapse;
* it does not by itself imply a variance bound at the `sqrt(p)` scale;
* reaching that scale requires a new input (monodromy/equidistribution or another independent arithmetic cancellation mechanism).

No stronger consequence follows from the currently verified identities alone.
