## 2. Formula audit: the plus carrier

For a legal plus edge with lower prime `p`, Q3744's lower digit is

```text
m_p = 6q+u-6p,
```

and the common upper state is `12q+u`.  Thus the grouping by `(q,u)` is the correct one: all lower-edge factors go into the first argument, while the expensive upper factor appears only once.

For any prime `ell`,

```text
v_ell(G^+_{q,u})
 = min(
     sum_{p in P_J(q,u;T)} v_ell(b_{6q+u-6p}),
     v_ell(B^+_{q,u})
   ).
```

For `ell != q`,

```text
v_ell(B^+_{q,u}) = v_ell(b_{12q+u}).
```

For `ell = q`, because `q` is prime,

```text
v_q(B^+_{q,u}) = max(v_q(b_{12q+u})-1,0).
```

Two skeptical points matter.

First, the notation “stripped” here removes **one compulsory copy of `q`**, not the whole q-primary part.  If `q^2 | b_{12q+u}`, then `q` still divides `B^+_{q,u}`.  One must not silently replace this by the q-free part `b_{12q+u}/q^{v_q(b_{12q+u})}`.

Second, stripping the upper factor first is not in general the same integer as taking the gcd first and then dividing that gcd by one `q`.  At the q-adic place,

```text
min(v_q(X), max(v_q(Y)-1,0))
```

need not equal

```text
max(min(v_q(X),v_q(Y))-1,0).
```

So the Q3744 carrier should be kept exactly as written.

For the lower target primes `p<q`, this q-strip cannot delete the target `p`.  Hence every plus edge whose transfer gives

```text
p | b_{m_p},
p | b_{12q+u}
```

is visible in `G^+_{q,u}`.  The product in the first argument is essential when one wants valuation-weighted, edge-multiplicity bookkeeping rather than merely the set of distinct prime divisors.

## 4. Does the pair close the Smith OR?

Yes at the carrier/bookkeeping level, provided the prescribed sets are quantified as above.

Let an admissible Smith sign assignment partition the prescribed edges into `E_+` and `E_-`.  For a fixed upper state `(q,u)`, the plus incidences are charged to `G^+_{q,u}` and the minus incidences to `G^-_{q,u}`.  In valuation form, what is required is

```text
mu^+_{q,u}(ell) <= v_ell(G^+_{q,u}),
mu^-_{q,u}(ell) <= v_ell(G^-_{q,u}),
```

where `mu^+` and `mu^-` are the edge multiplicities of the lower target prime `ell` assigned to the two signs.  Then

```text
mu^+_{q,u}(ell) + mu^-_{q,u}(ell)
 <= v_ell(G^+_{q,u} G^-_{q,u}).
```

Thus the universally safe joint carrier is

```text
G^vee_{q,u} := G^+_{q,u} G^-_{q,u}.
```

After summing logarithms, every edgewise Smith choice is bounded by the same sign-independent aggregate.  No global sign selection is needed.

This is exactly why the two branch carriers solve the **OR-quantifier problem** that the simultaneous-plus-and-minus (`AND`) incidence bounds did not solve.  An AND theorem controls edges on which both secondary zeros occur.  The Smith escape only promises one of them, so an AND theorem cannot charge the complementary one-sided edges.  The two-star product can.

## 5. The exact two aggregate height inequalities sufficient for closure

For each fixed `J`, as `T -> infinity`, it is sufficient to prove

```text
H^+_J(T)
:= sum_{(q,u) in S_J(T)}
     log gcd(
       prod_{p in P_J(q,u;T)} b_{6q+u-6p},
       b_{12q+u}/gcd(b_{12q+u},q)
     )
 = o_J(T^2/log T),
```

and

```text
H^-_J(T)
:= sum_{(q,u) in S_J(T)}
     log(
       gcd(b_{6q+u},b_{q-1-u})
       / gcd(gcd(b_{6q+u},b_{q-1-u}),q)
     )
 = o_J(T^2/log T).
```

These are the two exact aggregate inequalities I would put into the final reduction.  Since all summands are nonnegative,

```text
H^+_J(T) + H^-_J(T) = o_J(T^2/log T).
```

The Smith-selected edge mass is then bounded by this sum, so the secondary OR escape is negligible at the required `T^2/log T` scale.

The order of quantifiers matters:

```text
for every fixed J,
  prove the two little-o estimates as T -> infinity
  on the full prescribed state set S_J(T).
```

One should not choose the Smith signs first and then allow the exceptional state set or the implied constants to depend uncontrollably on that assignment.

## 7. Can the two carriers be algebraically coupled to beat the product?

The first formal candidate is

```text
lcm(G^+_{q,u},G^-_{q,u})
 = G^+_{q,u} G^-_{q,u} / gcd(G^+_{q,u},G^-_{q,u}),
```

so

```text
log lcm(G^+,G^-)
 = log G^+ + log G^- - log gcd(G^+,G^-).
```

This is certainly numerically no larger than the product.  But it is **not automatically a valid edge-multiplicity carrier**.

If a prime `ell` has `a` plus edges and `b` minus edges at the same upper state, the product has valuation

```text
v_ell(G^+) + v_ell(G^-),
```

which can cover `a+b`.  The lcm has only

```text
max(v_ell(G^+),v_ell(G^-)).
```

Therefore `lcm(G^+,G^-)` is safe only after proving an additional no-splitting/max-multiplicity statement such as

```text
mu^+_{q,u}(ell)+mu^-_{q,u}(ell)
 <= max(v_ell(G^+_{q,u}),v_ell(G^-_{q,u})).
```

A special case would be: for every `(q,u,ell)` there is at most one relevant edge and Smith chooses exactly one sign for that unique edge.  If the actual prescribed-edge parametrization has this uniqueness, then the lcm is a valid sharper carrier.  If repeated edges with the same lower target prime can occur and their signs can split, it is not.

I cannot certify that uniqueness from the connector-visible material, so the product is the correct unconditional bookkeeping object for this audit.

There is also no currently justified way to prove a large common factor after stripping.  Trivially,

```text
gcd(G^+_{q,u},G^-_{q,u})
```

divides the four-way common divisor

```text
gcd(
  prod_{p in P_J(q,u;T)} b_{6q+u-6p},
  b_{12q+u}/gcd(b_{12q+u},q),
  b_{6q+u},
  b_{q-1-u}
),
```

but this is an **upper** constraint on the overlap, not a useful lower bound.  The secondary-index identity

```text
L_+ + L_- = 13d-p-1
```

and the minus antidiagonal identity `7q-1` do not turn into a known integer divisibility relation among these four Apéry values.  So they do not justify cancelling a positive proportion of `gcd(G^+,G^-)` from the product.

Accordingly, the only presently rigorous product improvement is conditional:

```text
if the prescribed-edge parametrization gives no same-prime sign splitting,
then it is enough to prove

sum_{(q,u) in S_J(T)} log lcm(G^+_{q,u},G^-_{q,u})
  = o_J(T^2/log T).
```

This single coupled estimate is formally weaker than the pair `H^+=o` and `H^-=o`.  But without a theorem forcing substantial overlap, it is not known to be asymptotically easier; and without the no-splitting multiplicity condition it is not even the correct carrier.
