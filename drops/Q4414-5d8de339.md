## 1. Exact gate and accounting frames

The issue cannot be settled until the counted objects are typed correctly.

Fix a sign `sigma`, a translate `tau mod Lambda`, an actual selected upper state `x`, and a length-`Lambda` lower-prime cell `C=(tau,x,j)`.  Let

```text
S_C = set of actual selected lower primes in C,
K_C = #S_C,
```

where the indicator includes, before any classification:

```text
q prime,
0 <= t < q,
q divides b_t,
both exact lower Apéry-zero conditions,
the raw sign window,
every residual/depth/primitive mask,
and the authoritative raw minus-first assignment.
```

The scales are

```text
Y      = T^beta,
Lambda = Y^(5/6),
H      = Y^(1/2),
J_*    = Y^(1/6).
```

A rich cell satisfies `K_C>H`.

There are four distinct accounting frames.

### 1.1 Actual marked vertex mass

This is the frame of `M_sigma(T)` and the rich first mass:

```text
M_sigma(T) = sum over actual selected marked leaves,

R_rich = (1/Lambda) sum_tau sum_{C rich at tau} K_C.
```

An **additive marked-mass exception** is a set `Exc` for which the proof uses

```text
R_rich <= Mass(Exc) + Mass(good sector),
Mass(Exc) << M_sigma(T) T^(-gamma).
```

Such a term enters the final minimum of exponents.

### 1.2 Cellwise local pruning

A local pruning has the form

```text
B_C subset S_C,
#B_C <= b(T),
K_C^good = K_C-#B_C >= c K_C
```

for every rich cell, with a fixed `c>0`.  If the inverse construction is rerun on `S_C\B_C`, then

```text
K_C <= c^(-1) K_C^good.
```

There is no additive global term.  Summation occurs only after the multiplicative comparison has been made cell by cell.

### 1.3 Collision or matching mass

The canonical popular-edge mass is

```text
E_pop
  = (1/Lambda) sum_tau sum_{C in DPRM(tau)} R_C,
```

where `R_C` is a vertex-disjoint matching size.  An `O_J(1)` loss in `R_C` or an `O_J(1)` factor in the matching estimate is not an actual marked-mass error.  It changes only the implicit constant in the deterministic conversion

```text
K_C <<_J (Lambda/H) R_C.
```

### 1.4 Bounded class selection

If a matching is partitioned into `m_J=O_J(1)` classes,

```text
R_C = sum_{theta in Theta_J} R_{C,theta},
```

then

```text
max_theta R_{C,theta} >= R_C/m_J.
```

This is neither a vertex-mass deletion nor a power loss.  It is a constant-factor collision-level pigeonhole.

The ledger error was caused by computing a valid bound in frame 1.1 for a set that the proof actually handles in frame 1.2, and then verbally treating that bound as though the proof had used an additive decomposition.

## 2. Where the `T^{-beta/6}` number actually comes from

The source is the stable fold/order refinement in the rich-fibre inverse theorem, audited in Q4215 Section 3.3.

For one folded quotient row of slope `c`, the folded coordinate has one of the two affine slopes

```text
-c,
c+1.
```

Thus the two row slopes lie in

```text
s_6 in {-6,7},

s_plus  in {-13,14},
s_minus in {-1,2}.
```

A fold branch changes only at a finite set of affine transition points.  The relative order of the two folded coordinates also changes only at a finite set of affine crossing points.

Before the stable refinement, the popular-gap argument supplies a maximum relevant gap

```text
Delta_max <<_J Lambda/K_C <= Lambda/H = Y^(1/3).
```

Choose once and for all a slightly larger deterministic bound

```text
Delta_bar = A_J Lambda/H = A_J Y^(1/3).
```

Around every fold or order transition point remove all integer positions within distance `Delta_bar`.  Since the number of transition points is `O_J(1)`, the removed set in one cell has cardinality

```text
b_C <= B_J Y^(1/3).
```

At a fixed translate the number of rich cells is at most

```text
M_sigma(T)/H,
```

because their occupancies are disjoint and each exceeds `H`.  Therefore the aggregate transition-strip marked mass satisfies

```text
(1/Lambda) sum_tau sum_{C rich} b_C
    <<_J (M_sigma(T)/H) Y^(1/3)
     = M_sigma(T) Y^(-1/6)
     = M_sigma(T) T^(-beta/6).
```

This calculation is correct.  What is incorrect is the inference

```text
there exists a globally small transition set
    therefore its mass must be added to the final error ledger.
```

An upper bound on a removable set is not a statement that the proof must discard it additively.

## 3. The cellwise absorption proof

The decisive inequality is local:

```text
b_C/K_C
    <= B_J Y^(1/3)/H
     = B_J Y^(-1/6)
     = o_J(1).
```

For all sufficiently large `T`, every rich cell therefore has

```text
K_C^st := #S_C^st
        = K_C-b_C
        >= K_C/2,
```

where `S_C^st` is the stable core.

Now rerun the popular-gap construction on `S_C^st`; do **not** take the old matching and merely erase its unstable edges.

Write the stable points in increasing order:

```text
p_1 < ... < p_{K_C^st}.
```

Their consecutive gaps sum to less than `Lambda`.  Hence at least a fixed fraction of them satisfy

```text
gap <= 2 Lambda/K_C^st.
```

There are at most `2 Lambda/K_C^st` possible positive integer gap values in that range, so one gap `Delta_C` occurs on

```text
E_C >> (K_C^st)^2/Lambda
```

consecutive edges.  The equal-gap consecutive-edge graph has maximum degree at most two, so a greedy matching retains

```text
R_C^pre >> (K_C^st)^2/Lambda.
```

Because the transition strips were defined using the universal bound `Delta_bar`, every edge in this matching stays on one fold branch for each row and does not cross an order transition.

There are only `m_J=O_J(1)` resulting fold/order types.  Retain the lexicographically first largest type class.  Its matching size satisfies

```text
R_C
   >= R_C^pre/m_J
   >>_J (K_C^st)^2/Lambda
   >>_J K_C^2/Lambda.
```

Since `K_C>H`,

```text
R_C >>_J (H/Lambda)K_C,
```

and therefore

```text
K_C <<_J (Lambda/H)R_C.
```

This is exactly the canonical inequality consumed later.  It compares the **original rich-cell occupancy** `K_C` with a typed matching constructed from the stable core.  No transition-strip term remains.

Summing gives

```text
R_DPRM_sigma(Lambda,H)
   <<_J (Lambda/H) E_pop_sigma
    = Y^(1/3) E_pop_sigma.
```

This proves that the type refinement changes constants but not powers.

### Local-core absorption lemma

The preceding argument is an instance of a reusable lemma.

> Let every cell in a family have occupancy `K_C>H`.  Suppose a bad subset has size `b_C<=b(T)` with `b(T)=o(H)`.  Suppose that, after deleting the bad subset and rerunning an inverse construction, one obtains
> 
> ```text
> R_C >= c (K_C-b_C)^2/Lambda.
> ```
> 
> Then for large `T`,
> 
> ```text
> R_C >= (c/4)K_C^2/Lambda,
> K_C <= (4/c)(Lambda/H)R_C.
> ```
> 
> A bounded subsequent class pigeonhole only changes `c` by a constant.  The global estimate for the sum of the `b_C` is irrelevant to the final exponent.

The type-selection step meets every hypothesis with

```text
b(T)=O_J(Y^(1/3+o(1))),
H=Y^(1/2),
b(T)/H=Y^(-1/6+o(1)) -> 0.
```

## 7. Audit of every other named loss

### 7.1 Folded-thin deletion at `J_*=Y^(1/6)`

For each rich cell there are `O_J(J_*)` folded-thin positions.  Since the number of rich cells at one translate is at most `M_sigma/H`, the banked global estimate is

```text
thin marked mass
  <<_J (M_sigma/H)J_*
   = M_sigma Y^(-1/3)
   = M_sigma T^(-beta/3).
```

**Classification in the current ledger: additive actual marked-mass sector, paid once.**

This is the explicit first term in the Q4203/Q4215 rich-mass decomposition.  It is one source of the inherited `beta/3` ceiling.

There is also a local statement

```text
K_C-O_J(J_*) >= K_C/2
```

inside every rich cell.  That local fact is used to construct the deep core.  It does not authorize silently deleting the explicit global term from the already stated Q4203 theorem.  Removing that term altogether would require a rephrased classification that weights every original rich cell by its deep core and rechecks all later consumers.  Such an improvement may be possible, but it is not presently banked and is unnecessary for resolving Q4414.

The important bookkeeping rule is:

```text
pay the folded-thin term once in the global classification;
do not pay it again when constructing the local deep core.
```

### 7.2 Boundary-vacancy strips

The boundary theorem proves that the relevant raw fibre is empty in explicit logarithmic strips.  This is an exact pointwise exclusion, not a deletion estimate.

**Classification: zero contribution, no additive error.**

Moreover `O(log T)<<J_*`, so these strips lie inside the already handled folded-thin region on the DPRM scale.  They must not be charged as a second error after the `T^{-beta/3}` thin term.

If one nevertheless bounded their possible positions geometrically before using vacancy, the crude rich-cell count would be

```text
M_sigma log T/H
  = M_sigma T^(-beta/2+o(1)),
```

which is stronger than `T^{-beta/3}`.  The exact theorem is better: the actual mass there is zero.

### 7.3 Endpoint uniqueness layers

The endpoint radical-spacing theorem proves vacancy in the first layer and at most one lower prime in the next short layer.

**Classification: pointwise/local.**

For a rich-cell matching, deleting one endpoint-layer vertex removes at most one edge from a vertex-disjoint matching.  This is absorbed into

```text
K_C -> K_C-O_J(1),
R_C -> R_C-O_J(1).
```

Since `K_C>H` and `R_C>>Y^(1/6)`, neither change affects a power.

If charged globally over rich cells, the vertex mass is at most

```text
M_sigma/H = M_sigma T^(-beta/2),
```

again below the existing `beta/3` ceiling.  There is no reason to enter it separately.

### 7.4 The low-zero exception

The low-zero theorem says that, in one actual selected state/sign fibre, at most one lower prime can satisfy `|Z_p|<=3`, and none can satisfy `|Z_p|<=2`.

**Classification: pointwise/local, not an additive `beta/6` loss.**

Removing that single vertex from a rich fibre leaves `K_C-1` vertices and removes at most one edge from the canonical vertex-disjoint matching.  Thus the deep high-zero inverse theorem has the same asymptotic constants.

In the full pair count, changing `K` to `K-1` changes `K(K-1)` by `2(K-1)`, a lower-order linear term relative to the rich quadratic count.  Summed over rich cells, it is controlled directly by the actual first mass.  It does not create a new exponent bottleneck.

### 7.5 Stable transition strips

The aggregate bound is

```text
M_sigma T^(-beta/6+o(1)),
```

but the correct classification is the local-core absorption proved in Sections 2 and 3.

**Classification: locally absorbed before matching; not additive.**

### 7.6 Finite fold/order type selection

The number of types is `O_J(1)`.

**Classification: constant-factor collision pigeonhole.**

It has no marked-mass exponent at all.

### 7.7 Complementary/major-arc and the Q4190 light term

These sectors are already represented by explicit additive or structural `T^{-beta/3}` terms in the global theorem.

**Classification: additive/structural and paid once.**

They are independent of the type-selection issue and continue to enforce the `beta/3` ceiling even if one someday improves the thin-sector bookkeeping.

## 10. Self-attack

### 10.1 Could the global strip estimate still have to be paid because the target counts the original vertices?

No.  The proof establishes a cellwise domination

```text
K_C^raw << K_C^st
      << (Lambda/H)R_C.
```

The original occupancy is therefore charged through the stable matching.  It is not being silently dropped.

### 10.2 Is the argument circular because the transition-strip width uses the popular gap found after pruning?

No.  Use the universal rich-cell bound

```text
Delta_bar = A_J Lambda/H = A_JY^(1/3)
```

before pruning.  The rerun on a core of size at least `K_C/2` produces

```text
Delta_C << Lambda/K_C^st
        << Lambda/K_C
        <= Lambda/H,
```

which is inside the preselected width.

### 10.3 Could a stable-core matching cross an order transition even when neither endpoint lies in a strip?

Not when the strip radius is at least the maximum legal edge length.  Any affine branch or order change along the interval would put one endpoint within that radius of the corresponding transition point.  The finite set of transition points and a uniform `Delta_bar` make the argument deterministic.

### 10.4 Does the bounded number of types depend on `T`?

No, for fixed campaign parameter `J`.  It depends only on the two choices of folded slope for each row, their relative order, and the fixed finite orientation conventions.  It is `O_J(1)`.  If a future argument lets `J` grow with `T`, the type count must be re-audited; that is outside the present bank.

### 10.5 Does raw minus-first survive the pruning and type selection?

Yes.  The actual sign assignment is imposed in the indicator defining `S_C`.  Every later step only takes subsets of `S_C`; no leaf is moved from minus to plus or counted twice.

### 10.6 Is a lower bound on `M_sigma(T)` hidden in `#rich cells<=M_sigma/H`?

No.  This is a deterministic upper bound.  If `M_sigma=0`, there are no rich cells.  No ratio is formed and no density lower bound is used.

### 10.7 Does translate averaging change local absorption into an additive loss?

No.  The inequality

```text
K_C^raw <<_J (Lambda/H)R_C
```

holds for every cell and every translate before summation.  Averaging preserves it.  The separate aggregate strip estimate is never invoked in that summation.

### 10.8 Is the folded-thin term being treated inconsistently with the transition term?

The two local estimates look similar, but their **banked consumers differ**.  Q4203 explicitly states the global rich-mass decomposition with the folded-thin/non-DPRM `T^{-beta/3}` term.  Q4215 explicitly states that the transition term is not part of that decomposition.
