# Concise proof audit

Let

```text
F(t) = #{1 <= h <= D : R_h >= t},
S    = sum_{h<=D} R_h,
T    = T0 = ceil(sqrt(N/D)).
```

It is enough to take integer `t>=1`, since the `R_h` are integers. Assume throughout
`1 <= D <= N` and `0 <= R_h <= 3(h-1)`.

## Verdict

At the intended scale

```text
D = sqrt(N) L,   L = N^o(1),
```

the correct hierarchy is

```text
old Z  ==>  Condition A  ==>  Condition B,
```

and both arrows are strict even under the degree bound and the mirror parity rule.
Condition B does not imply A.

For arbitrary `D`, without the mesoscopic specialization, A need not imply B; the
cutoff is essentially `D <= N^(3/5)`. Thus globally A and B are incomparable, while
at the actual hatch scale A is stronger.

Most importantly:

```text
A gives S = o(N) at D = sqrt(N)L,
B gives only S = O(N), and this is sharp.
```

So B is sufficient only if the target is literally `O(N)`. It does not by itself
close any step requiring `o(N)`.

---

## 1. Condition A implies `S=O(N)`

Condition A is

```text
E := sum_h max(R_h-T,0) = O(N/sqrt(T)).
```

Since

```text
R_h <= T + max(R_h-T,0),
```

we have

```text
S <= D T + E.
```

Also

```text
D T <= sqrt(ND) + D = O(N)
```

for `D<=N`, and `N/sqrt(T) <= N`. Hence

```text
S = O(N).
```

At `D=sqrt(N)L`,

```text
T = N^(1/4)L^(-1/2)(1+o(1)),
D T = N^(3/4)L^(1/2)(1+o(1)),
N/sqrt(T) = N^(7/8)L^(1/4)(1+o(1)).
```

Because `L=N^o(1)`, both are `o(N)`. Therefore A actually gives

```text
S = O(N^(7/8+o(1))) = o(N).
```

---

## 2. Condition B implies `S=O(N)`

Condition B is

```text
W := sup_{t>=1} t^(3/2) F(t)
   = O(N^(3/2)/sqrt(D)).
```

By layer cake,

```text
S = sum_{t>=1} F(t).
```

Put

```text
U = ceil(N/D).
```

For `t<=U`, use `F(t)<=D`; for `t>U`, use `F(t)<=W t^(-3/2)`.
Thus

```text
S <= D U + W sum_{t>U} t^(-3/2)
  <= N + D + 2W/sqrt(U)
  = O(N).
```

Indeed `U>=N/D`, so

```text
W/sqrt(U)
 <= (N^(3/2)/sqrt(D)) sqrt(D/N)
 = N.
```

This estimate is critical: it gives no power saving. The separating profile below
has B and `S asymp N`.

---

## 3. The old `Z` condition implies both A and B

The old condition is

```text
Z := sup_{t>T} t^2 F(t) = O(N).
```

### `Z ==> A`

Using layer cake for the excess,

```text
E = sum_{t>T} F(t)
  <= Z sum_{t>T} t^(-2)
  <= Z/T
  = O(N/T).
```

Since `T>=1`, this is stronger than

```text
E = O(N/sqrt(T)).
```

### `Z ==> B`

For `t<=T`,

```text
t^(3/2)F(t) <= D T^(3/2).
```

For `t>T`,

```text
t^(3/2)F(t) <= Z/sqrt(t) <= Z/sqrt(T).
```

Since `T asymp sqrt(N/D)`, both quantities are

```text
O(N^(3/4)D^(1/4)).
```

For `D<=N`,

```text
N^(3/4)D^(1/4) <= N^(3/2)/sqrt(D).
```

Hence old `Z` implies B as well.

The implication is very non-sharp: old `Z` has a `t^-2` tail, A records only the
integrated excess, and B allows merely a weak-`L^(3/2)` tail.

---

## 4. Relation between A and B

### At the intended scale, `A ==> B`

This implication uses the structural cap `R_h<=3(h-1)<=3D`.

For `t<=2T`, trivially

```text
t^(3/2)F(t) <= D(2T)^(3/2).
```

For `t>2T`, every `h` counted by `F(t)` contributes at least `t-T>=t/2`
to `E`. Therefore

```text
F(t) <= 2E/t,
```

and, since `F(t)=0` for `t>3D`,

```text
t^(3/2)F(t) <= 2E sqrt(t) <= 2E sqrt(3D).
```

Under A,

```text
W <= C [D T^(3/2) + N sqrt(D/T)].
```

For `D=sqrt(N)L`, this is

```text
W <= N^(7/8+o(1)) + N^(9/8+o(1)).
```

The B threshold is

```text
N^(3/2)/sqrt(D) = N^(5/4)L^(-1/2).
```

The ratio of the second term to the B threshold is

```text
N^(-1/8) L^(5/4) = N^(-1/8+o(1)) -> 0.
```

Thus A implies B, with room to spare, in the actual mesoscopic regime.

More generally this argument works when

```text
D <= N^(3/5-o(1)).
```

### Globally, A need not imply B

Take

```text
N = n^12,   D = n^8,   T = n^2.
```

Choose `m=n^3` lags in `[D/2,D]`, and put `R_h=D+O(1)` on those lags,
with the `O(1)` parity adjustment described below. Put only the mirror baseline
on all other lags. Then

```text
E asymp mD = n^11 = N/sqrt(T),
```

so A holds, while

```text
W >= m D^(3/2) asymp n^15,
N^(3/2)/sqrt(D) = n^14.
```

Thus B fails. Hence A and B are globally incomparable, although A implies B at
`D=sqrt(N)L`.

## 5. Strict parity-respecting separating profiles

Use the compulsory mirror baseline

```text
kappa_h = 1  if h is even,
          0  if h is odd.
```

For any chosen height `H`, define `H_h` to be the largest integer at most `H`
with

```text
H_h congruent kappa_h mod 2.
```

Then `H_h=H+O(1)`. On inactive lags set `R_h=kappa_h`; on selected lags set
`R_h=H_h`.

If selected lags lie in `[D/2,D]` and `H<=D`, then for all large `D`,

```text
R_h <= D <= 3(h-1).
```

Thus every profile below satisfies both the degree cap and the exact mirror parity.

### Profile P: A and B hold, old Z fails

Take

```text
N=n^4,   D=n^2,   T=n.
```

Select `m=n` lags in `[D/2,D]` and use height `H=D`.
Then

```text
E asymp mD = n^3 = o(n^(7/2)) = o(N/sqrt(T)),
```

so A holds. Also

```text
W = O(max(D, mD^(3/2))) = O(n^4),
```

whereas the B allowance is

```text
N^(3/2)/sqrt(D) = n^5.
```

Thus B holds. But at `t=H-O(1)`,

```text
t^2 F(t) asymp D^2 m = n^5,
```

while `N=n^4`. Hence old Z fails by a factor `n`.

This proves that both implications `Z=>A` and `Z=>B` are strict.

### Profile Q: B holds, A fails

Again take

```text
N=n^4,   D=n^2,   T=n.
```

Select `m=floor(D/4)` lags in `[D/2,D]` and use height `H=D`.
Then

```text
W asymp mD^(3/2) asymp n^5
  = N^(3/2)/sqrt(D),
```

so B holds at its natural critical scale. However

```text
E asymp mD asymp n^4 = N,
```

whereas

```text
N/sqrt(T) = n^(7/2).
```

Thus A fails by a factor `n^(1/2)`. Moreover

```text
S asymp N,
```

showing that B cannot be upgraded from `O(N)` to `o(N)` without a little-`o`
improvement in its hypothesis.

## Final audit

```text
Each of A and B implies S=O(N).                    YES
Old Z implies A.                                   YES, strongly
Old Z implies B.                                   YES
At D=sqrt(N)L, A implies B.                        YES, using R_h<=3D
At D=sqrt(N)L, B implies A.                        NO
For arbitrary D, A and B imply one another.        NO; globally incomparable
A gives S=o(N) at the hatch scale.                 YES
B gives S=o(N) at the hatch scale.                 NO; only O(N)
```

The hidden asymptotic issue is therefore exactly the critical normalization in B:

```text
W = O(N^(3/2)/sqrt(D))
```

permits `S asymp N`. To obtain the wall-breaking little-`o` conclusion from B, one
must assume

```text
W = o(N^(3/2)/sqrt(D)),
```

or add an independent condition excluding the critical plateau profile.
