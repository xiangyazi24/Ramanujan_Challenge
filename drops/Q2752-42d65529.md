# P3.2: adaptive sparse covariance / private-clique audit

## Verdict

There is an exact dispersion/duality identity, but it goes in the hostile direction.
On the actual fixed-`q` exceptional rows selected by high load, the unequal-prime covariance is **forced to be positive and of the same order as the square of the load**.  If

\[
X_q(n)=T_q(n)-\mu_q(n),
\qquad
X_q(n)\ge \tau_N\asymp_{\varepsilon,q}\frac{N}{\log N}
\]

on the selected rows, then, writing `E=E_{\varepsilon,q}(N)` for precisely those actual rows,

\[
\boxed{
CV_q^{\rm exc}(N)
=
\sum_{n\in E}X_q(n)^2-D_q^{\rm exc}(N),
}
\tag{A}
\]

and

\[
D_q^{\rm exc}(N)
\ll_{\varepsilon,q}N\log N
=o\!\left(\frac{N^2}{\log^2N}\right).
\tag{B}
\]

Consequently

\[
\boxed{
CV_q^{\rm exc}(N)
\ge
|E|\tau_N^2-o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{C}
\]

In particular, **one surviving high-load exceptional row already forces**

\[
CV_q^{\rm exc}(N)
\ge
(1-o_{\varepsilon,q}(1))\tau_N^2
\asymp_{\varepsilon,q}
\frac{N^2}{\log^2N}.
\tag{D}
\]

Thus adaptively restricting to the high rows does not create a new source of cancellation.  It conditions on the very event that aligns the prime columns.  The requested one-sided covariance bound is therefore conclusion-scale: proving `o(N^2/log^2 N)` on this adaptive set already rules out every selected row.

The private-prime clique makes the obstruction completely explicit.  For the raw incidence matrix `B`, a single row carrying `K` target primes which occur on no other exceptional row has

\[
BB^{\mathsf T}=[K],
\qquad
B^{\mathsf T}B=J_K.
\]

Hence all vertical repeated-support off-diagonal energy is zero, while the horizontal same-row prime-pair mass is

\[
K(K-1).
\]

For `K\asymp N/log N` this is exactly the forbidden `N^2/log^2 N` scale.  Transposition preserves the singular values and total Frobenius energy, but it converts the **row diagonal** into **column off-diagonal clique mass**.  Row separation, gap-polynomial codegree, and repeated-support prefix quotients control the wrong side of this transfer.

The missing Apéry input is therefore precise: one needs a genuinely **mixed-characteristic, conditional anti-alignment theorem** saying that the `p`-zero event at the moving residue `n-qp` has nontrivial discrepancy even after the row has been selected using the zero events in the other characteristics.  Primewise authenticated zero-bank membership, reflection, `Z(p)` bounds, same-prime gap codegrees, and repeated-support quotients do not give such a statement.

I do not see an unconditional proof of that correlation in the current repository state.  What can be proved unconditionally is the exact adaptive Gram identity, the private-clique obstruction, and a sharper quantitative endpoint: a uniform upper bound strictly below the one-row threshold `(1-o(1)) tau_N^2` would already finish this sparse step; little-oh is stronger than necessary.

# 1. Exact fixed-`q` centered incidence matrix

Fix `q` and a dyadic shell `N<n<=2N`.  Put

\[
I_q(n)=\left(\frac{n}{q+1},\frac nq\right],
\qquad
r_p(n)=n-qp.
\tag{1.1}
\]

For a prime `p`, let

\[
Z_p=\{0\le r<p:p\mid b_r\},
\qquad
\rho_p=\frac{|Z_p|}{p}.
\tag{1.2}
\]

The raw target indicator and centered column are

\[
A_{n,p}
={\bf1}_{\{p\in I_q(n)\}}
 {\bf1}_{\{r_p(n)\in Z_p\}},
\tag{1.3}
\]

\[
Y_{n,p}
={\bf1}_{\{p\in I_q(n)\}}
\left({\bf1}_{\{r_p(n)\in Z_p\}}-\rho_p\right).
\tag{1.4}
\]

Then

\[
T_q(n)=\sum_pA_{n,p},
\qquad
\mu_q(n)=\sum_{p\in I_q(n)}\rho_p,
\tag{1.5}
\]

and

\[
X_q(n)=T_q(n)-\mu_q(n)=\sum_pY_{n,p}.
\tag{1.6}
\]

The zero-count bound and `p\asymp_q N` on a fixed quotient slice give

\[
\rho_p\ll_q N^{-1/3}.
\tag{1.7}
\]

There are `O_q(N/log N)` candidate primes in one row, hence

\[
\boxed{
\mu_q(n)\ll_q\frac{N^{2/3}}{\log N}
=o_q\!\left(\frac N{\log N}\right).
}
\tag{1.8}
\]

Let `E=E_{\varepsilon,q}(N)` denote the actual exceptional rows retained by the sparse-covariance reduction and heavy in this fixed quotient cell.  Thus for some fixed `eta=eta(epsilon,q)>0`,

\[
T_q(n)\ge\eta\frac N{\log N}
\qquad(n\in E).
\tag{1.9}
\]

By (1.8), for all sufficiently large `N`,

\[
\boxed{
X_q(n)\ge
\tau_N:=\frac\eta2\frac N{\log N}
\qquad(n\in E).
}
\tag{1.10}
\]

Also

\[
|E|\ll_\varepsilon\log^2N.
\tag{1.11}
\]

Everything that follows uses **this actual set**, not all `N` rows.

# 2. Exact adaptive Gram identity

Let `Y` be the full shell-by-prime matrix with entries `Y_{n,p}`.  Let

\[
w_n={\bf1}_{\{n\in E\}},
\qquad
W=\operatorname{diag}(w_n),
\]

and let `1` denote the all-ones vector in the prime coordinate.
Then

\[
(Y\mathbf1)_n=X_q(n).
\tag{2.1}
\]

Therefore

\[
\mathbf1^{\mathsf T}Y^{\mathsf T}WY\mathbf1
=
\|W^{1/2}Y\mathbf1\|_2^2
=
\sum_{n\in E}X_q(n)^2.
\tag{2.2}
\]

The trace is exactly the same-prime diagonal:

\[
\operatorname{tr}(Y^{\mathsf T}WY)
=
\sum_{n\in E}\sum_pY_{n,p}^2
=:D_q^{\rm exc}(N).
\tag{2.3}
\]

Subtracting the diagonal gives the requested unequal-prime covariance:

\[
\boxed{
CV_q^{\rm exc}(N)
=
\mathbf1^{\mathsf T}
\bigl(Y^{\mathsf T}WY-\operatorname{diag}(Y^{\mathsf T}WY)\bigr)
\mathbf1
}
\tag{2.4}
\]

and hence the exact dispersion identity

\[
\boxed{
CV_q^{\rm exc}(N)
=
\|W^{1/2}Y\mathbf1\|_2^2
-
\|W^{1/2}Y\|_F^2.
}
\tag{2.5}
\]

This is the cleanest dual form I know.  It uses the actual adaptive selector `W` exactly; no replacement by a generic sparse weight has occurred.

## 2.1 The adaptive selection forces positivity

For each selected row define

\[
D_q(n)=\sum_pY_{n,p}^2.
\]

Since `|Y_{n,p}|<=1` and there are only `O_q(N/log N)` candidate primes,

\[
D_q(n)\ll_q\frac N{\log N}.
\tag{2.6}
\]

The row contribution to the unequal-prime covariance is exactly

\[
C_q(n)
:=\sum_{p\ne\ell}Y_{n,p}Y_{n,\ell}
=X_q(n)^2-D_q(n).
\tag{2.7}
\]

Using (1.10),

\[
C_q(n)
\ge
\tau_N^2-O_q\!\left(\frac N{\log N}\right).
\tag{2.8}
\]

But

\[
\frac{N/\log N}{\tau_N^2}
\ll_{\varepsilon,q}\frac{\log N}{N}
=o(1).
\]

Therefore

\[
\boxed{
C_q(n)
\ge(1-o_{\varepsilon,q}(1))\tau_N^2
\qquad(n\in E).
}
\tag{2.9}
\]

Summing gives (C):

\[
\boxed{
CV_q^{\rm exc}(N)
\ge
(1-o(1))|E|\tau_N^2.
}
\tag{2.10}
\]

This corrects a tempting interpretation of a one-sided covariance estimate: on an arbitrary row set negative covariance could indeed help, but **after conditioning on these high-load rows the total unequal-prime covariance cannot be substantially negative**.  The adaptive selector has already chosen rows on which the prime columns align.

# 3. Exact row formula: centering does not dissolve the clique

The preceding estimate used only `|Y|<=1`.  We can see the private clique more sharply.

Fix one row `n` and write

\[
S_n=\{p\in I_q(n):r_p(n)\in Z_p\},
\qquad
T=|S_n|=T_q(n),
\tag{3.1}
\]

\[
R_1(n)=\sum_{p\in S_n}\rho_p,
\qquad
R_2(n)=\sum_{p\in I_q(n)}\rho_p^2.
\tag{3.2}
\]

Because the raw indicator is `0` or `1`,

\[
D_q(n)
=
\sum_{p\in I_q(n)}(A_{n,p}-\rho_p)^2
=T-2R_1(n)+R_2(n).
\tag{3.3}
\]

Thus

\[
\boxed{
C_q(n)
=(T-\mu_q(n))^2
-T+2R_1(n)-R_2(n).
}
\tag{3.4}
\]

Now (1.7) gives

\[
R_1(n)\ll_q TN^{-1/3},
\qquad
R_2(n)\ll_q\frac{N^{1/3}}{\log N}.
\tag{3.5}
\]

On a high row `T>=eta N/log N`,

\[
\frac{\mu_q(n)}{T}\ll_{\varepsilon,q}N^{-1/3},
\qquad
\frac1T\ll_{\varepsilon,q}\frac{\log N}{N}.
\tag{3.6}
\]

Hence

\[
\boxed{
C_q(n)
=T_q(n)^2\bigl(1+O_{\varepsilon,q}(N^{-1/3})\bigr).
}
\tag{3.7}
\]

So the centered covariance is asymptotically the **raw target clique squared** on every selected row.  The small negative background `-rho_p` from non-target candidate primes is lower order and cannot cancel the clique.

This is exactly why centering, while essential for full-shell dispersion, does not help after conditioning on a row where the uncentered load is linear in the number of available primes.

# 4. Transpose duality and the private-prime clique

Now use the raw incidence matrix

\[
B_{n,p}=A_{n,p}
\]

restricted to the actual exceptional rows.  This is the cleanest object for support geometry.

The row Gram matrix is

\[
(BB^{\mathsf T})_{n,m}
=|S_n\cap S_m|.
\tag{4.1}
\]

This is the side seen by:

- row separation;
- same-prime gap-polynomial codegree;
- repeated-support prefix quotients;
- any theorem charging a prime only after it occurs on two different rows.

The column Gram matrix is

\[
(B^{\mathsf T}B)_{p,\ell}
=\#\{n\in E:p,\ell\in S_n\}.
\tag{4.2}
\]

Its off-diagonal mass is exactly the same-row prime-pair mass:

\[
\boxed{
\sum_{p\ne\ell}(B^{\mathsf T}B)_{p,\ell}
=
\sum_{n\in E}T_q(n)(T_q(n)-1).
}
\tag{4.3}
\]

Of course

\[
\operatorname{tr}(BB^{\mathsf T})
=
\operatorname{tr}(B^{\mathsf T}B)
=
\sum_{n\in E}T_q(n),
\tag{4.4}
\]

and `BB^T` and `B^TB` have the same nonzero eigenvalues.  But this spectral duality **does not preserve the diagonal/off-diagonal split**.

## 4.1 One-row private clique

Suppose one actual exceptional row has `K` target primes and each of those prime columns occurs on no other exceptional row.  On those columns the raw matrix is simply

\[
B=(1,1,\ldots,1)
\qquad(1\times K).
\tag{4.5}
\]

Then

\[
\boxed{
BB^{\mathsf T}=[K],
\qquad
B^{\mathsf T}B=J_K.
}
\tag{4.6}
\]

Therefore:

- row off-diagonal repeated-support mass = `0`;
- row diagonal energy = `K^2` at the level of `BB^T` Frobenius mass;
- column diagonal mass = `K`;
- column off-diagonal mass = `K(K-1)`.

Indeed,

\[
\|BB^{\mathsf T}\|_F^2
=
\|B^{\mathsf T}B\|_F^2
=K^2,
\]

but transposition has moved essentially all of the energy from a **row diagonal entry** to a **column off-diagonal clique**.

For

\[
K\asymp\frac N{\log N},
\]

this clique contributes

\[
\boxed{
K(K-1)\asymp\frac{N^2}{\log^2N}.
}
\tag{4.7}
\]

That is precisely the critical sparse covariance scale.

This example is an interface-level obstruction, not a claim that such a configuration has been found in the actual Apéry sequence.  It proves that any argument using only the currently banked **vertical** facts cannot exclude the configuration.  To exclude it one must inject an additional theorem coupling different residue characteristics.

## 4.2 Centered private clique

For the target primes in such a private set `P_n`, the positive target-target piece of the centered covariance is

\[
\sum_{\substack{p,\ell\in P_n\\p\ne\ell}}
(1-\rho_p)(1-\rho_\ell)
=
K(K-1)+O_q(K^2N^{-1/3}).
\tag{4.8}
\]

So centering changes the private clique only by relative `O(N^{-1/3})`.  The interactions with non-target candidate columns can be negative, but the exact full-row formula (3.4) shows that even after all those interactions are included the total remains

\[
T_q(n)^2(1+o(1)).
\]

Thus the private clique is not an artifact of using raw indicators.

# 6. Why row separation and repeated-support quotients do not touch the obstruction

Let `S_n` be the target-prime set of an exceptional row.  Decompose it as

\[
S_n=S_n^{\rm rep}\sqcup S_n^{\rm priv},
\]

where a prime is `rep` if it also occurs on another selected exceptional row and `priv` otherwise.

All mechanisms based on a common characteristic across two rows see only `S_n^{rep}`.  In particular:

- a gap polynomial constrains `p` only when the same `p` supplies zeros at two indices;
- a row-codegree bound controls `|S_n cap S_m|` for `n!=m`;
- a repeated-support prefix quotient activates only after support repeats vertically.

None of these statements gives an upper bound for `|S_n^{priv}|`.

If `|S_n^{priv}|=(1-o(1))T_q(n)`, then by (4.8) the private part alone already contributes `(1-o(1))T_q(n)^2` target-target pair mass.

If instead a positive fraction of `S_n` is repeated, then repeated-support technology has something to charge.  Thus the exact dichotomy is

\[
\boxed{
\text{either many vertical repeats, or a horizontal private clique.}
}
\tag{6.1}
\]

The currently visible banked results handle only the first branch.  There is no theorem forcing a high-load Apéry row into that branch.

This is the first precise obstruction; it occurs before any height optimization of the repeated-support quotient.

# 7. Sparse Fourier duality: a singleton row has no kernel decay

Define the zero-bank Fourier transform

\[
F_p(a)=\sum_{r\in Z_p}e_p(ar).
\tag{7.1}
\]

Then finite Fourier inversion gives

\[
Y_{n,p}
=
\frac{{\bf1}_{\{p\in I_q(n)\}}}{p}
\sum_{a=1}^{p-1}F_p(a)e_p(-an).
\tag{7.2}
\]

For a pair `p,l` define the actual-exceptional-row kernel

\[
K^E_{p,\ell}(\theta)
=
\sum_{\substack{n\in E\\p,\ell\in I_q(n)}}
e(n\theta).
\tag{7.3}
\]

The exact unequal-prime covariance is

\[
\boxed{
CV_q^{\rm exc}
=
\sum_{p\ne\ell}\frac1{p\ell}
\sum_{a=1}^{p-1}\sum_{b=1}^{\ell-1}
F_p(a)\overline{F_\ell(b)}
K^E_{p,\ell}\!\left(\frac b\ell-\frac ap\right).
}
\tag{7.4}
\]

This is the sparse analogue of the shell Dirichlet formula, but the kernel behaves in the opposite way from a long interval.

If `E` contains only one relevant row `n_0`, then for every pair of candidate primes on that row

\[
K^E_{p,\ell}(\theta)=e(n_0\theta),
\qquad
|K^E_{p,\ell}(\theta)|=1.
\tag{7.5}
\]

There is **no** Dirichlet-kernel decay

\[
\min(L,\|\theta\|^{-1})
\]

because there is no physical interval to average over.  Equation (7.4) simply reconstructs the pointwise products `Y_{n_0,p}Y_{n_0,l}`.  When the row was selected because their sum is large, those products aggregate to (3.7).

Therefore a generic sparse large sieve cannot manufacture the needed saving merely from `|E|=polylog N`.  In the singleton case there is no phase averaging to exploit at all.  Any saving must come from nontrivial correlation among the **Apéry Fourier coefficients in different characteristics**, not from the geometry of the sparse set.

# 8. Leave-one-prime-out identity: the exact missing correlation

There is one more useful exact dual form.  For each prime `p` set

\[
X_q^{(-p)}(n)
=\sum_{\ell\ne p}Y_{n,\ell}
=X_q(n)-Y_{n,p}.
\tag{8.1}
\]

Then

\[
\boxed{
CV_q^{\rm exc}
=
\sum_p\sum_{n\in E}
Y_{n,p}X_q^{(-p)}(n).
}
\tag{8.2}
\]

The importance of (8.2) is conceptual rather than cosmetic.  The weight `X_q^{(-p)}(n)` is built from the other residue characteristics.  Since `|Y_{n,p}|<=1`, a selected row satisfies

\[
X_q^{(-p)}(n)
\ge\tau_N-1
\qquad
\text{for every candidate }p.
\tag{8.3}
\]

Thus high-load selection by the other primes already places the `p`-th column in a large positive environment.

A successful adaptive argument would need an Apéry theorem of the following **type**:

> after the events in the characteristics `ell != p` have selected a sparse collection of rows / assigned a large predictable weight, the centered event
> \[
> p\mid b_{n-qp}
> \]
> still has a power-saving discrepancy relative to `rho_p`, on average over `p`.

This is a conditional one-prime-vs-other-primes statement.  It is not supplied by knowing the zero set `Z_p` exactly, by bounding `|Z_p|`, or by bounding same-`p` returns at two rows.

There is a further adaptivity issue: the actual GCD-exceptional mask itself is produced from the full arithmetic row, so a theorem valid only for masks chosen independently of the `p`-column would not yet be enough.  One needs uniformity robust enough to tolerate the realized actual exceptional mask, or a separate argument making that mask predictable without the `p`-column.

This is the precise extra correlation missing from the authenticated primewise zero-bank interface: **mixed-characteristic conditional decorrelation under high-load selection**.

It is strictly different in signature from the existing same-characteristic gap/resultant information:

```text
current vertical input:
    fix p; compare two row positions in Z_p

missing adaptive input:
    fix p; compare the p-zero event with a row weight generated by
    the zero events in many ell != p characteristics
```

Without such a theorem the private-prime clique is legal at the level of every presently available marginal and vertical constraint.

# 9. The sparse covariance target is equivalent-scale to the desired first moment

Let

\[
M_q^{\rm exc}(N)=\sum_{n\in E}X_q(n).
\tag{9.1}
\]

Since `X_q(n)>=tau_N` on `E`,

\[
X_q(n)^2\ge\tau_NX_q(n).
\]

Using (A),

\[
\boxed{
CV_q^{\rm exc}
\ge
\tau_N M_q^{\rm exc}-D_q^{\rm exc}.
}
\tag{9.2}
\]

Conversely, a fixed quotient cell contains only `C_q N/log N` candidate primes, so

\[
X_q(n)\le C_q\frac N{\log N}
\le C_{\varepsilon,q}'\tau_N.
\tag{9.3}
\]

Therefore

\[
\sum_{n\in E}X_q(n)^2
\le C_{\varepsilon,q}'\tau_NM_q^{\rm exc}.
\]

Hence

\[
\boxed{
\tau_N M_q^{\rm exc}-D_q^{\rm exc}
\le CV_q^{\rm exc}
\le C_{\varepsilon,q}'\tau_NM_q^{\rm exc}.
}
\tag{9.4}
\]

The diagonal satisfies, using only `|E|=O(log^2 N)`,

\[
D_q^{\rm exc}
\ll |E|\frac N{\log N}
\ll_{\varepsilon,q}N\log N
=o(\tau_N^2).
\tag{9.5}
\]

So, on the adaptive high rows, the covariance and the desired centered first moment are already equivalent up to the deterministic factor `tau_N` and constants.

This explains why no purely formal dualization can close the gap.  Once the set has been selected by `X_q>=tau_N`, asking the covariance to be little-oh is essentially asking that the selected set be empty.

# 10. A useful quantitative weakening of the covariance upper bound

Although I do not prove the required upper bound, the lower bound above sharpens what an eventual analytic theorem would need to deliver.

If `E` is nonempty, then from (2.8)

\[
CV_q^{\rm exc}
\ge
\tau_N^2-C_q\frac N{\log N}.
\tag{10.1}
\]

Therefore it is **not necessary** to prove the full

\[
CV_q^{\rm exc}=o\!\left(\frac{N^2}{\log^2N}\right).
\]

It would already suffice to prove, for example, that for some fixed `delta>0`,

\[
\boxed{
CV_q^{\rm exc}(N)
\le(1-\delta)\tau_N^2
}
\tag{10.2}
\]

for all sufficiently large `N` (with the harmless `O(N/log N)` correction inserted if one wants an exact finite-`N` threshold).  Equation (10.1) would then force `E` to be empty.

So the analytic target can be weakened from a little-oh asymptotic to a **constant-factor subcritical upper bound below the one-row clique threshold**.  What cannot be weakened away is the mixed-characteristic anti-rainbow content: any such bound must somehow rule out the private clique.

---

# 11. Final obstruction / next theorem signature

The current inputs have the following division of labor.

### Already controlled

- `|E_epsilon(N)|=O_epsilon(log^2 N)` actual exceptional rows;
- fixed-`q` total load
  \[
  \sum T_q(n)\ll N^{8/5}/\log^{4/5}N;
  \]
- primewise zero-set size `Z(p)<<p^(2/3)`;
- exact fixed-`q` candidate support through the Legendre--Euler/Smith reduction;
- same-characteristic row-to-row constraints from recurrence/gap geometry;
- repeated-support carriers/quotients when a prime actually repeats vertically.

### Still uncontrolled

A row can in principle be a **rainbow**:

\[
\boxed{
\text{many distinct }p,
\quad
p\mid b_{n-qp},
\quad
\text{with essentially no }p\text{ repeated on another exceptional row}.}
\tag{11.1}
\]

Every primewise authenticated interface may be completely correct in (11.1); the missing assertion is about their **joint alignment at the same characteristic-zero row `n`**.

The first new Apéry theorem capable of exploiting adaptivity must therefore control the conditional correlation between

\[
{\bf1}_{\{p\mid b_{n-qp}\}}-\rho_p
\]

and a row selector/weight generated from the corresponding events for `ell != p`, with enough uniformity to survive the actual exceptional mask.  A same-prime gap theorem, a stronger bound on `Z(p)`, or an exact zero-bank lookup does not have this signature.

Equivalently in Fourier language, one needs cancellation in the cross-characteristic family

\[
\frac1p\sum_{a\ne0}F_p(a)e_p(-an)
\]

as `p` varies **at a row selected because this very family has large aggregate value**.  That is a large-deviation / conditional decorrelation problem, not an ordinary sparse-set large sieve.

## Bottom line

The adaptive sparse restriction saves the logarithm found in the previous reduction, but it does not itself supply the remaining cancellation.  Exact Gram duality shows why:

\[
\boxed{
\text{high-load selection}
\Longrightarrow
\text{positive same-row prime clique}
\Longrightarrow
CV_q^{\rm exc}\asymp \sum_{n\in E}T_q(n)^2.
}
\]

The private-prime clique is the terminal obstruction to all presently visible vertical/repeated-support mechanisms.  The missing input is a genuinely mixed-characteristic Apéry anti-alignment theorem robust under other-prime/adaptive row selection.  Without that new correlation, I do not see a valid unconditional upper bound below the one-row threshold, and therefore no proof of the sparse exceptional covariance step from the current repository interfaces alone.
