## 1. Complex recurrence and uniqueness

```lean
/-- Homogeneous Zudilin source recurrence over `ℂ`.

Using the homogeneous equation is important: it avoids coercing divisions and
makes recurrence uniqueness a single cancellation of `ctAlpha27 k`. -/
def ZudilinSatisfiesRecC27 (u : ℕ → ℂ) : Prop :=
  ∀ k : ℕ,
    (ctAlpha27 k : ℂ) * u (k + 3)
      - (ctBeta27 k : ℂ) * u (k + 2)
      + (ctGamma27 k : ℂ) * u (k + 1)
      - (ctDelta27 k : ℂ) * u k = 0

private theorem ctAlpha_ne_zero27 (k : ℕ) :
    (ctAlpha27 k : ℂ) ≠ 0 := by
  have hA : zudilinA (k + 2) ≠ 0 :=
    ne_of_gt (zudilinA_pos k)
  have hq : ctAlpha27 k ≠ 0 := by
    simp only [ctAlpha27]
    exact mul_ne_zero (by norm_num) hA
  exact_mod_cast hq

/-- Third-order recurrence uniqueness from values at `0,1,2`. -/
theorem ZudilinSatisfiesRecC27.eq_of_initial
    {u v : ℕ → ℂ}
    (hu : ZudilinSatisfiesRecC27 u)
    (hv : ZudilinSatisfiesRecC27 v)
    (h0 : u 0 = v 0)
    (h1 : u 1 = v 1)
    (h2 : u 2 = v 2) :
    u = v := by
  funext n
  induction n using Nat.strong_induction_on with
  | h n ih =>
      match n with
      | 0 => exact h0
      | 1 => exact h1
      | 2 => exact h2
      | k + 3 =>
          have huk := hu k
          have hvk := hv k
          rw [ih (k + 2) (by omega),
            ih (k + 1) (by omega),
            ih k (by omega)] at huk
          apply mul_left_cancel₀ (ctAlpha_ne_zero27 k)
          linear_combination huk - hvk
```

There is no hidden nonvanishing premise here.  The repository theorem

```lean
zudilinA_pos (k) : 0 < zudilinA (k + 2)
```

proves the only coefficient needed for forward uniqueness is nonzero.

## 2. Exact rational-to-complex recurrence cast

Do not try to `exact_mod_cast` the divided recurrence directly.  Division by rational coefficients makes that brittle.  Cast the cleared equation already supplied by `zudilinSatisfiesRec_iff_ct27`:

```lean
/-- Rational source recurrence transported to `ℂ`. -/
theorem ZudilinSatisfiesRec.castComplex27
    {u : ℕ → ℚ}
    (hu : ZudilinSatisfiesRec u) :
    ZudilinSatisfiesRecC27 (fun n => (u n : ℂ)) := by
  intro k
  change
    (ctAlpha27 k : ℂ) * (u (k + 3) : ℂ)
      - (ctBeta27 k : ℂ) * (u (k + 2) : ℂ)
      + (ctGamma27 k : ℂ) * (u (k + 1) : ℂ)
      - (ctDelta27 k : ℂ) * (u k : ℂ) = 0
  have hq := (zudilinSatisfiesRec_iff_ct27 u).1 hu k
  have hc := congrArg (fun q : ℚ => (q : ℂ)) hq
  push_cast at hc
  exact hc
```

This is the robust Lean 4.29 cast pattern for all four recurrence coefficients:

```text
rational cleared identity
  -> congrArg (fun q : ℚ => (q : ℂ))
  -> push_cast
```

It avoids manually proving cast lemmas for each quotient.

# Exact coefficient relation to the repository recurrence

The homogeneous complex predicate uses the already-audited repository definitions

```lean
ctAlpha27 k = 2 * zudilinA (k + 2)
ctBeta27  k = 2 * zudilinM (k + 2)
ctGamma27 k = 2 * (k + 2) * zudilinN (k + 2)
ctDelta27 k = zudilinR (k + 2) * (k + 2) * (k + 1)^3.
```

Thus its equation is

```text
2 A(k+2) u(k+3)
- 2 M(k+2) u(k+2)
+ 2 (k+2) N(k+2) u(k+1)
- R(k+2) (k+2) (k+1)^3 u(k) = 0.
```

Dividing by `2 * zudilinA (k+2)` gives exactly `ZudilinSatisfiesRec`.  The rational equivalence is already proved as

```lean
zudilinSatisfiesRec_iff_ct27
```

in `Problem27BarnesTelescoper.lean`.  No sign, scalar, or index adjustment remains at the normalization stage.

# Hazards

## 1. Do not cast the divided recurrence directly

This is brittle:

```lean
exact_mod_cast zudilinB_rec
```

because the target contains nested rational divisions.  Use
`zudilinSatisfiesRec_iff_ct27`, `congrArg`, and `push_cast` exactly as above.

## 2. The leading coefficient must be cancelled

The cleared equation does not definitionally solve for `u (k+3)`.  The uniqueness proof must use

```lean
mul_left_cancel₀ (ctAlpha_ne_zero27 k)
```

or an equivalent `field_simp` argument.

## 3. The third initial numerator is `7425/16`

The exact sum is

```text
2145/8 + 3135/16 = 4290/16 + 3135/16 = 7425/16.
```

Writing `7425/8` silently destroys the uniqueness match.

## 4. Anchor divisions in `ℂ`

Use

```lean
(7425 / 16 : ℂ)
```

in complex theorem statements.  Without the type annotation Lean may infer the wrong division before coercion elaboration stabilizes.

## 5. The Barnes normalization scalar is already present

`zudilinBarnesErrorIntegral27` already contains the `π/2` fixed-line normalization and is equal to the common-line raw integral times `1/(2π)`.  Do not insert another factor in the recurrence or initial values.  Homogeneity guarantees the existing common scalar preserves the recurrence.

## 6. Use real parts for the final cast back

The current repository helper uses

```lean
(Complex.continuous_re.tendsto _).comp hcomplex
```

which is stable in Mathlib 4.29.  There is no need to depend on a more specialized `Complex.tendsto_ofReal_iff` theorem name.

## 7. Public theorem naming

The current name `problem27_zeta2_add_zeta3` is already occupied by the conditional theorem.  Add a new name such as

unless you deliberately rename the old theorem to `_of_error` and update all callers.
