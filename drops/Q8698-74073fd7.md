# Constant-term Newton-polytope audit of the quotient-one reduction

## Verdict

The bounded-coefficient extraction is correct in principle, but the proposed cross-prime compression does not follow from the Newton-polytope restriction alone. The exact coefficient set can be enumerated, and it yields a finite vector of coefficients. The remaining question is a correlation problem for this vector as the prime varies; ordinary recurrence/resultant saturation does not create a new target-selective relation.

## 1. Exact bounded coefficient set

Write

\[
\Lambda=\frac{N(x,y,z)}{xyz},
\]

where

\[
N=(x+y)(z+1)(x+y+z)(y+z+1).
\]

The Newton polytope of \(N\) is the Minkowski sum of the four segment/simplex pieces. The exponent set of \(N\) has coordinate ranges

\[
0\le i\le3,\qquad 0\le j\le3,\qquad 0\le k\le2,
\]

with total degree between 0 and 4. Hence for

\[
\Lambda^{n-1}=N^{n-1}x^{-(n-1)}y^{-(n-1)}z^{-(n-1)},
\]

all occurring exponents satisfy

\[
-(n-1)\le e_x,e_y,e_z\le 3(n-1),
\]

and the torus sum keeps exactly those terms with

\[
e_x=a(p-1),\quad e_y=b(p-1),\quad e_z=c(p-1).
\]

Therefore

\[
0\le a,b,c\le \left\lfloor\frac{3(n-1)+(n-1)}{p-1}\right\rfloor.
\]

For \(3n/4<p\le n\), one has

\[
\frac{4(n-1)}{p-1}<\frac{16}{3}+O(1/n),
\]

so the only possible multipliers are

\[
(a,b,c)\in\{0,1,2,3,4,5\}^3
\]

with the additional polytope inequalities inherited from \((n-1)\operatorname{Newt}(N)\). In particular the set is finite and independent of the shell size.

The endpoint cases are:

* multiplier 0 occurs only when the corresponding exponent equals zero;
* multiplier 5 can occur only at the extreme coordinate faces, and only when the bound \(4(n-1)/(p-1)\ge5\) is met, which requires the smallest allowed primes. It disappears for the strict large-shell regime.

Thus the exact set is obtained by intersecting the dilated Newton polytope with

\[
(p-1)\mathbf Z^3.
\]

## 2. Explicit coefficient criterion

Define

\[
A_{a,b,c}(n)=[x^{a(p-1)}y^{b(p-1)}z^{c(p-1)}]N^{n-1}.
\]

The torus identity gives

\[
B_u\equiv-\sum_{(a,b,c)\in S_p}A_{a,b,c}(n)\pmod p,
\]

where

\[
S_p=((n-1)\operatorname{Newt}(N)-(n-1,n-1,n-1))\cap(p-1)\mathbf Z^3.
\]

Hence an explicit integer certificate is

\[
\boxed{C_n(p)=\sum_{(a,b,c)\in S_p}A_{a,b,c}(n).}
\]

Then

\[
\boxed{p\mid B_u\iff p\mid C_n(p).}
\]

The point is that \(C_n(p)\) is a bounded-length sum of explicit multinomial coefficients, not that it is already a small global object.

## 3. Recurrence/resultant compression audit

The coefficient vector

\[
(A_{a,b,c}(n))_{(a,b,c)\in S_p}
\]

has bounded dimension. However, bounded dimension does not imply a useful recurrence in the varying prime parameter.

A fixed recurrence would require that the dependence on

\[
p-1
\]

inside the coefficient extraction be generated by a fixed linear operator. The extraction indices themselves move with p, so the natural object is a family of diagonals of a rational function, not one recurrence sequence.

Likewise, a determinant/resultant among these coefficients can only help if it gives a nonzero relation whose coefficients have height independent of the defining prime. The generic interpolation/resultant construction saturates:

* the coefficient vector is finite-dimensional;
* the local condition \(C_n(p)=0\) is one linear condition modulo p;
* CRT permits independent residues at distinct primes unless an additional global relation couples them.

Thus the finite Newton geometry alone gives no cross-prime compression theorem.

## 4. Precise saturation statement

Let

\[
V_p=(A_{a,b,c}(n))_{(a,b,c)\in S_p}.
\]

After localizing away from primes dividing the bounded combinatorial denominators, the condition

\[
p\mid C_n(p)
\]

is a single hyperplane condition on the finite coefficient vector modulo p.

Any construction using only:

1. linear combinations of the bounded coefficients;
2. fixed determinants/resultants in those coefficients;
3. CRT across distinct shell primes;

saturates to the product of independent local ideals

\[
(p,C_n(p)).
\]

It cannot produce a new short-height integer vanishing for all such primes.

The exact residual problem is therefore narrower:

> prove a genuine correlation theorem for the bounded diagonal coefficient vectors \(V_p\) as p varies.

This must use arithmetic information beyond the Newton polytope, such as a proven relation between the diagonal coefficients across different defining primes.

## Final conclusion

The quotient-one reduction is valid as a bounded Newton-polytope coefficient extraction. The exact certificate is the finite coefficient sum \(C_n(p)\) above. The bounded support is real, but it does not by itself yield a recurrence, determinant, or resultant compression across primes. The surviving obstruction is a coefficient-correlation problem, not a missing enumeration of Newton-polytope terms.
