# GPRV = quenched Chebotarev variance: literature, GRH wall, and random-model baseline

## Executive verdict

The target

```
Sum_{h<=p-3} (C_h - mu_h)^2 <= C p
```

is a genuinely quenched statement: the characteristic p is fixed and the polynomial family index h grows. Existing Chebotarev, large sieve, and trace-function theorems do not directly prove this quantifier order.

The correct classification is:

```
fixed h, p varies:  classical Chebotarev / Deligne regime
fixed p, h varies:  growing-conductor family regime (open here)
```

The new [Q-SIGMA-1/2] result

```
Q_p(Delta) << Delta^(5/2)
```

improves the geometric energy side but does not remove the family compatibility obstruction. The missing ingredient is still a sigma>1 family cancellation statement.

# 1. Literature audit

## 1.1 Chebotarev for one polynomial

The standard theorem is not in the required regime.

Let f in Z[x] be fixed, with splitting field K and Galois group G. Chebotarev gives, as x varies,

```
#{ell <= x : Frob_ell in C}
=
(|C|/|G|) Li(x)+error.
```

Under GRH for Dedekind zeta(K), Lagarias-Odlyzko gives square-root error.

Reference:

Lagarias-Odlyzko, "Effective versions of the Chebotarev density theorem", Algebraic Number Fields (1977), Theorem 1.1.

Does not cover:

```
p fixed,
{M_h mod p : h=1,...,p}
```

because the averaging variable is reversed.

---

## 1.2 Kowalski Frobenius large sieve

Relevant theorem:

E. Kowalski, "The large sieve and its applications", Cambridge Tracts 175 (2008), Chapter 8, especially Theorem 8.18 (Frobenius large sieve).

The theorem controls sums over primes/places of a fixed arithmetic family of l-adic sheaves. The geometric conductor is fixed while the finite-field parameter varies.

Our situation has:

```
p fixed,
h -> M_h,
deg(M_h) ~ h,
conductor(M_h) grows with h.
```

The conductor explosion is exactly outside the theorem.

---

## 1.3 Trace-function large sieve

Relevant results:

- Fouvry, Kowalski, Michel, "Algebraic trace functions over the primes", Duke Math. J. 163 (2014).
- Kowalski, Michel, Sawin, "Bilinear forms with Kloosterman sums and applications", Ann. of Math. 186 (2017).

These prove cancellation when a family of trace functions has bounded conductor.

They do not apply to

```
h -> root-count trace of M_h
```

because the conductor parameter grows approximately with degree.

---

## 1.4 Kurlberg-Rudnick type variance

Kurlberg-Rudnick variance results concern averaging over primes or moduli.

Example:

P. Kurlberg and Z. Rudnick, "The distribution of spacings between reciprocal square roots modulo one", Duke Math. J. 100 (1999).

The philosophy is close:

```
variance = diagonal + off-diagonal cancellation
```

but the averaging direction differs.

No theorem found for:

```
fixed finite field F_p,
growing-degree polynomial family,
root-count variance.
```

---

## 1.5 Polynomial congruence root distribution

Classical results (Hooley, Toth and successors) mostly treat:

```
f fixed,
p varies.
```

For example:

- Hooley, "On the power free values of polynomials", Mathematika 14 (1967).

The transpose

```
p fixed,
f=f_h varies
```

is not covered unless the family has additional bounded-complexity geometry.

---

## Literature conclusion

No published theorem directly covers GPRV.

Closest frameworks:

1. Frobenius large sieve: wrong quantifier.
2. Trace-function large sieve: conductor grows.
3. Chebotarev: fixed polynomial only.
4. Polynomial congruence statistics: usually p-average, not f-average.

Therefore GPRV is a new quenched family-variance problem.

# 2. GRH quantitative wall

Assume:

```
Gal(M_h)=S_{m_h}
Artin holomorphy
GRH for all Artin L-functions
```

Let m_h=deg(M_h)=3(h-1)-[h even].

A Chebotarev/Artin estimate gives schematically:

```
C_h-mu_h = O(m_h^A sqrt(p) log(D_h p)).
```

The root-disk and leading coefficient estimates imply

```
log |Disc(M_h)| = O(m_h^2 log m_h).
```

Therefore

```
log(D_h p)=O(h^2 log h + log p).
```

Hence

```
|C_h-mu_h|^2
<<
 h^(2A) p (h^2 log h)^2.
```

Summing h<=p gives

```
Sum_h (C_h-mu_h)^2
<<
 p * Sum_{h<=p} h^(2A+4)(log h)^2.
```

Thus

```
GRH bound
<< p^(2A+6) (log p)^2.
```

Even the optimistic A=0 case gives

```
G <= p^6 log^2 p,
```

far above the target

```
G <= Cp.
```

So:

```
GPRV is strictly stronger than individual GRH Chebotarev.
```

# 3. The missing family-independence hypothesis

The exact missing statement is not another GRH. It is a second-moment independence statement for the family of Artin representations.

Let rho_h be the permutation representation attached to the roots of M_h and let

```
T_h(p)=Tr(rho_h(Frob_p))-E Tr(rho_h).
```

GPRV is essentially:

```
Sum_h |T_h(p)|^2 << p.
```

The required additional hypothesis is:

## Family Artin variance hypothesis (FAV)

For the triangular family {rho_h},

```
Sum_{h<=H} |Tr(rho_h(Frob_p))-E_h|^2
<= C p
```

uniformly for

```
H<=p.
```

Equivalently, after expanding traces through Artin L-functions, one needs cancellation in the explicit formula cross terms:

```
Sum_{h,k<=H}
Sum_rho
 c(h,k,rho) x^{i gamma_rho}
```

with off-diagonal h,k cancellation.

This is a family linear-independence statement of Frobenius eigenphases.

A concise formal implication is:

```
GRH + Artin + FAV => GPRV.
```

GRH alone does not imply FAV.

This is the "quantifier wall".
