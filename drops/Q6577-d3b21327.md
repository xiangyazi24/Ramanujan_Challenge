# 1. Exact setup

Let `I` be the consecutive index set on which the projective orbit is being counted, ending at `p-2`. For `h>=1`, define

```text
I(r,h) = 1 if r+h<=p-2 and pi(r)=pi(r+h),
         0 otherwise.
```

Put

```text
d_H(r) = sum_{1<=h<=H} I(r,h),
Q_H    = sum_r C(d_H(r),2),
R_h    = sum_r I(r,h),
S_1(H) = sum_{1<=h<=H} R_h.
```

Here and below

```text
H=min(Delta,p-3).
```

If `Delta>p-3`, there are no additional admissible gaps, so

```text
Q_p(Delta)=Q_p(H)<=Q_p(Delta)
```

in the claimed asymptotic scale. It is therefore enough to treat `1<=H<=p-3`.

The first-moment identity is exact:

```text
S := sum_r d_H(r)
   = sum_{h=1}^H R_h
   = S_1(H).
```

Using the banked nonzero gap polynomial and its degree,

```text
R_h <= 3(h-1).
```

Consequently

```text
S <= 3 sum_{h=1}^H (h-1)
  = (3/2)H(H-1)
  <= (3/2)H^2.
```

No irreducibility, Galois-group statement, or probabilistic input is used.

# 2. Step (i): the pointwise box inequality

Fix an integer box length `D` with `1<=D<=H`, and partition `[1,H]` into consecutive boxes

```text
B_j = {(j-1)D+1,...,min(jD,H)},
1<=j<=q,
q=ceil(H/D).
```

The last box may be shorter. For each base `r`, let

```text
a_j(r) = #{h in B_j : I(r,h)=1},
L_r    = sum_{j=1}^q C(a_j(r),2).
```

Then

```text
d_H(r)=sum_j a_j(r)
```

and

```text
sum_j a_j(r)^2
= sum_j (2 C(a_j(r),2)+a_j(r))
= 2L_r+d_H(r).
```

Cauchy gives

```text
d_H(r)^2 <= q sum_j a_j(r)^2
           = q(2L_r+d_H(r)).
```

Therefore

```text
2 C(d_H(r),2)
= d_H(r)^2-d_H(r)
<= 2qL_r+(q-1)d_H(r),
```

so the exact useful inequality is

```text
C(d_H(r),2)
<= qL_r+((q-1)/2)d_H(r).                  (2.1)
```

The proposed inequality with `(q/2)d_H(r)` is weaker but valid.

Summing (2.1) over `r` gives

```text
Q_H <= qL+((q-1)/2)S,                     (2.2)
```

where

```text
L=sum_r L_r.
```

This step has no divisibility or endpoint issue. The last short box is already included in the definition of `a_j(r)`.

# 3. Step (iii): the triple-collision injection

For fixed `1<=h<k<=H`, define the joint count

```text
T(h,k)
= #{r : r+k<=p-2,
       pi(r)=pi(r+h)=pi(r+k)}.
```

Expanding `L` gives the exact identity

```text
L = sum_j sum_{h<k, h,k in B_j} T(h,k).    (3.1)
```

This is the decisive count. It is a count of triples consisting of

```text
(base r, first gap h, second gap k),
```

with the gap pair unordered by imposing `h<k`.

Fix one pair `(h,k)` and put

```text
d=k-h.
```

For every `r` counted by `T(h,k)`, set

```text
u=r+h.
```

Then

```text
u+d = r+k <= p-2
```

and transitivity of equality gives

```text
pi(u)=pi(r+h)=pi(r+k)=pi(u+d).
```

Thus `u` is a valid base of a gap-`d` collision. The map

```text
r -> u=r+h
```

is injective for this fixed `(h,k)`. Hence

```text
T(h,k) <= R_{k-h}.                         (3.2)
```

## The counting-mouth issue

The question correctly singles out the following possible objection:

```text
The same u may arise from different pairs (h,k).
```

That is true and harmless. Equation (3.1) counts `(r,{h,k})`, not distinct translated bases `u`. We apply (3.2) separately to every fixed pair and then add the resulting upper bounds. No line of the proof claims that the images for distinct pairs are disjoint.

Equivalently, if one translated base `u` supports ten different pair certificates, then it contributes ten times to `L`, and the right side also contains ten separately indexed copies of a suitable `R_d` bound. This is exactly the required multiplicity convention.

The nonwrapping boundary is also preserved automatically:

```text
r+k<=p-2  =>  u+d<=p-2.
```

There is no lost or newly introduced endpoint.

# 4. Counting same-box pairs and bounding L

For `1<=d<D`, let

```text
B_d = #{(h,k): h<k, k-h=d, h and k lie in one box}.
```

If the box lengths are `ell_1,...,ell_q`, then exactly

```text
B_d = sum_{j=1}^q max(ell_j-d,0).          (4.1)
```

In particular,

```text
B_d <= H                                      (4.2)
```

because each pair is determined by its first member `h`, and also

```text
B_d <= q(D-d).                               (4.3)
```

The incomplete final box only decreases these quantities.

Combining (3.1), (3.2), and (4.2),

```text
L <= sum_{d=1}^{D-1} B_d R_d
  <= H sum_{d=1}^{D-1} R_d
  = H S_1(D-1).                              (4.4)
```

Using `R_d<=3(d-1)`,

```text
L <= 3H sum_{d=1}^{D-1}(d-1)
  = (3/2)H(D-1)(D-2)
  <= (3/2)H D^2.                             (4.5)
```

This verifies steps (iii) and (iv) exactly.

# 6. Mirror collisions

No separate mirror term is required.

For the appropriate parity of `d`, the reflection law contributes the known forced root of the gap polynomial. That root is already one of the bases counted by `R_d`, and the root-count estimate

```text
R_d <= deg N_d
```

already includes it.

Likewise, if a translated triple-collision certificate lands at a mirror base, it remains an ordinary element of the gap-`d` collision set used in (3.2). Nothing changes in the injection.

Subtracting the mirror root before applying the proof could improve lower-order constants, but cannot change the exponent `5/2`.

# 7. Artificial-sequence attack

## 7.1 No counterexample under the actual hypotheses

The proof above never uses the Apéry recurrence after the estimates `R_d<=3d` are supplied. Therefore it proves the following abstract statement.

> Abstract box lemma. Let `x_0,...,x_N` be an arbitrary word over an arbitrary set. Define `R_d`, `d_H(r)`, and `Q_H` by equality of word values, with nonwrapping indices. If `R_d<=Cd` for every `1<=d<=H`, then `Q_H<<_C H^(5/2)`.

Consequently no artificial word satisfying the one-gap profile can be a counterexample. A brute-force search would only re-check a theorem already proved by the injection.

## 7.2 Counterexample to a weaker, tempting replacement

There is, however, a sharp artificial counterexample if one keeps only the aggregate first moment

```text
S=sum_{d<=H}R_d=O(H^2)
```

and drops the individual short-gap bounds.

Take a constant word of length `H+1`:

```text
x_0=x_1=...=x_H.
```

Then

```text
R_d=H+1-d,
S=sum_{d=1}^H R_d=H(H+1)/2=O(H^2),
```

but

```text
d_H(r)=H-r,
Q_H=sum_{r=0}^H C(H-r,2)
   =C(H+1,3)
   asymp H^3.
```

Thus the first-moment estimate alone cannot imply `H^(5/2)`. This artificial word fails the actual hypothesis at the shortest gap:

```text
R_1=H,
```

whereas the Apéry gap bound gives `R_1=0` and, more generally, `R_d<=3d`.

This test identifies step (iii), not step (i), as the genuinely new input.

# 8. Conditional enhancement with S_1(D)

The proof gives a stronger master inequality before inserting any degree estimate.

Recall

```text
S_1(Y)=sum_{1<=d<=Y}R_d.
```

From (2.2) and (4.4),

```text
boxed:
Q_H <= q H S_1(D-1) + ((q-1)/2)S_1(H),
q=ceil(H/D).                                    (8.1)
```

An even more precise weighted form follows from (4.1):

```text
Q_H
<= q sum_{d=1}^{D-1} B_d R_d
   + ((q-1)/2)S_1(H),                           (8.2)
```

where

```text
B_d=sum_j max(ell_j-d,0)
   <= min(H,q(D-d)).
```

Thus one may also use

```text
Q_H
<= q^2 sum_{d=1}^{D-1}(D-d)R_d
   + ((q-1)/2)S_1(H).                           (8.3)
```

These are the clean conditional versions requested in the question.

For example, suppose only the short range is improved to

```text
S_1(Y) << Y^(2-eta)       for Y<=D,
```

while the long range retains the degree bound `S_1(H)<<H^2`. Then (8.1) gives

```text
Q_H << H^2 D^(1-eta) + H^3/D.                  (8.4)
```

Optimizing with

```text
D=H^(1/(2-eta))
```

gives


Checks:

```text

eta=1/2   gives exponent 7/3;

```

If the improved bound also holds at the long scale `H`, insert it in the second term of (8.1) as well; this yields a still stronger optimization. The exact formula (8.1) is preferable to baking one particular conditional exponent into the theorem statement.

# 9. Compatibility with Q_H <= 3 H^(8/3)

The older estimate comes from a different interpolation. Using the banked window multiplicity bound in the schematic form

```text
max_r d_H(r) <= 3H^(2/3)
```

and the first moment `S<= (3/2)H^2`, one gets

```text

= sum_r C(d_H(r),2)

<= (9/4)H^(8/3),
```

which is safely recorded as

```text

```

The new result is stronger because

```text
H^(5/2) / H^(8/3) = H^(-1/6).
```

There is no inconsistency:

```text
old proof: pointwise L-infinity control of d_H(r);
new proof: translation of same-box triple certificates into short-gap
           collision counts R_d.
```

Both may be retained as

```text
Q_H << min(H^(5/2),H^(8/3)).
```

For `H>=1`, the first term is asymptotically the stronger one.

# 10. What the theorem does and does not buy

Since

```text
5/2 = 3-1/2,
```

the theorem is correctly named `[THM-Q-SIGMA-ONE-HALF]`.

Feeding it into the established sigma machine gives

```text
E^pi(p) << p^(2-1/(5/2)) = p^(8/5),
```

up to the usual epsilon bookkeeping. This does not beat the direct unconditional `p^(3/2)` block-energy theorem. Its importance is instead that it proves a nontrivial factorial-moment saving inside the `Q_p(Delta)` architecture and exposes the exact reusable input (8.1).

Any further improvement within this box method must improve at least one of:

```text
S_1(D),
S_1(H),
the bound T(h,k)<=R_{k-h},
or the Cauchy cross-box loss q.
```

Merely changing the box endpoints or treating the forced mirror root separately cannot improve the exponent.

# 12. Required confidence audit

## (a) Least certain step

The new combinatorial argument itself is the part I am most confident in. The least certain interface is external to it: the all-prime use of the banked statement

```text
R_d <= 3(d-1)
```

in exactly the chosen orbit/index convention, including every possible mod-`p` degree-drop or identically-zero exception. The repository's current orbit-energy section explicitly treats the gap polynomial as nonzero on the relevant regular range, and the question grants `R_d<=3d`; under that banked input the proof above is unconditional. If that earlier nonvanishing theorem were ever weakened to "all but exceptional `(p,d)`", the present theorem would inherit precisely those exceptions and no others.

## (b) Possible shared blind spot

The likely shared blind spot is assuming that the separate inequalities

```text
T(h,k) <= R_{k-h}
```

can be close to saturated for many pairs simultaneously. The box proof deliberately forgets that all translated collision certificates come from one projective orbit and one holonomic transfer cocycle. There may be strong incompatibilities among the sets

```text
{r : pi(r)=pi(r+h)=pi(r+k)}
```

for different `(h,k)` which are invisible after each pair is bounded separately by `R_{k-h}`.

Thus the next gain is unlikely to come from a more careful ceiling function or from mirror bookkeeping. It would come from a genuinely joint theorem, for example a weighted bound on

```text
sum_{h<k in one box} T(h,k)
```

that beats the sum of the individual `R_{k-h}` bounds. In the language of the current campaign, that is exactly where a two-gap holonomic incompatibility, ATR-type estimate, or integrated Radon statement could enter.
