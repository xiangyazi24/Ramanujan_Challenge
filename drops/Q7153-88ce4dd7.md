# P32 Hasse factorization source audit

## 1. Source/theorem audit

The claimed identity is a version of the Apéry polynomial factorization for the truncated generating polynomial
\[
A_p(t)=\sum_{n=0}^{p-1} b_n t^n,
\]
where
\[
b_n=\sum_{k=0}^n {n\choose k}^2 {n+k\choose k}^2.
\]

The relevant statement in the Beukers--Vlasenko work is a factorization of the Hasse polynomial associated with the Apéry motive. The invariant object is not the raw coefficient polynomial with an arbitrary normalization, but the Hasse invariant modulo p up to multiplication by a nonzero scalar and, depending on the residue class, multiplication by a fixed quadratic Hasse factor.

The residue-class split used in the project is consistent with the expected quadratic twist:

* if p ≡ 1,7,17,23 (mod 24), the ordinary factor is a square;
* if p ≡ 5,11,13,19 (mod 24), the extra factor is the quadratic polynomial
  \[
  t^2-34t+1.
  \]

However, the statement must be read as an equality in the relevant finite-field polynomial ring up to a nonzero scalar normalization. Writing an exact monic equality without fixing normalization is too strong.

The notation issue is real: the paper's Hasse polynomial notation and the local `oracleB_result`/`proof.tex` notation use different names (`H_p` versus `A_p`, or square-root factor versus the full Hasse polynomial). They should not be identified literally without a normalization map.

## 2. Small-prime sanity checks

The Apéry coefficients begin

```
b_0 = 1
b_1 = 5
b_2 = 73
b_3 = 1445
...
```

For small admissible primes one checks the constant and reciprocal coefficients:

* the polynomial is self-reciprocal because
  \[
  b_n \equiv b_{p-1-n}\pmod p
  \]
  in the relevant finite-field range;
* therefore any factorization must respect the involution
  \[
  t\mapsto t^{-1}.
  \]

The quadratic factor
\[
t^2-34t+1
\]
is exactly reciprocal, since its coefficients are symmetric. Thus the residue split is compatible with self-reciprocity.

The possible discrepancy in a direct computation is only a scalar factor in \(\mathbf F_p^\times\), not a different quadratic polynomial.

## 3. What this says about zero coefficients

It does **not** give a useful bound for coefficient zeros.

The factorization controls the polynomial as a function of the variable t:

\[
A_p(t)=0
\]
means an evaluation root in \(\overline{\mathbf F}_p\).

The P32 problem concerns coefficient zeros:

\[
b_r\equiv0\pmod p.
\]

These are completely different statements. A polynomial can have many zero coefficients while having no special evaluation roots, and conversely a polynomial can have many evaluation roots while all coefficients are nonzero.

Therefore Hasse factorization cannot directly bound the number of indices r with \(p\mid b_r\), nor four nearby coefficient zeros.

## 4. Self-reciprocity is insufficient

Self-reciprocity gives only

\[
b_r=b_{p-1-r},
\]

which explains the reflection pairing already used in P32. It gives no restriction on the local density of zeros near one side of the interval.

A formal counterexample under the same algebraic constraints is obtained by taking a reciprocal polynomial

\[
F(t)=\sum_{r\in S}t^r,
\]

where S is symmetric under r→p−1−r and chosen to contain arbitrary clusters of coefficient zeros. Multiplying by a reciprocal square factor preserves self-reciprocity but does not remove those coefficient gaps.

Hence:

* reciprocal symmetry: no local zero-density theorem;
* differential equation: controls the function space/period, not arbitrary coefficient support;
* Hasse factorization: controls evaluation roots, not coefficient vanishing.

## 5. Differential equation audit

The Apéry polynomial is related to a Picard--Fuchs differential equation. The equation implies constraints on the sequence globally, but a linear differential equation with polynomial coefficients does not prevent long sparse patterns in one finite coefficient truncation.

To derive a four-zero bound one would need an additional statement converting differential constraints into coefficient-rank constraints modulo p. No such theorem follows from the Hasse factorization alone.

## 6. Correct conclusion for P32

The Hasse factorization is a valid structural identity after correcting:

1. notation (`A_p` versus `H_p`);
2. normalization (equality up to \(\mathbf F_p^\times\));
3. interpretation (evaluation polynomial, not coefficient sequence).

It does not improve the deterministic cluster estimates for
\[
Z_p=\{r:b_r\equiv0\pmod p\}.
\]

The four-nearby-zero problem remains governed by the continuant identities, return polynomials, pair counts, and moving-prime estimates. Any claim that Hasse factorization alone gives an \(O(H^{1+o(1)})\) bound on coefficient-zero clusters would be a category error: it replaces coefficient arithmetic with evaluation geometry.

No additional P32 zero-cluster theorem follows from the Hasse factorization source.
