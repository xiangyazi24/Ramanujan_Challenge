# Cold audit of the all-exponent Newton-content theorem

## Verdict

The claimed implication is not established by the stated block argument. The first exact gap is the boundary lemma's fixed-length-prefix grouping: the Mellit--Vlasenko block decomposition does not, from the stated data alone, license replacing the sum of all preceding blocks by `b_(T_(l-1))` when the prefix contains internal or top-position zero digits. The proof needs an additional zero-block compatibility lemma. Without it, the all-exponent theorem remains unproved.

This is a different failure mode from the older Q1152 audit: the issue is not merely that a generic Dwork congruence is too weak; the issue is whether the proposed stronger block partition identity actually follows from the canonical word decomposition.

## 1. Fixed-length-prefix grouping

The argument groups partitions according to the final block containing the newly appended nonzero top digit. For a block length `l`, it claims that all blocks before that final block sum to

```text
b_(T_(l-1)).
```

The Mellit--Vlasenko formula is indexed by admissible contiguous block partitions of a canonical base-p word. Therefore this identification requires that deleting the final top-containing block leaves exactly the canonical base-p word used for `T_(l-1)`, with the same admissibility rules and the same treatment of every zero digit.

The problematic case is not a leading zero at the numerical value level; it is a zero digit inside the fixed-length representation. Canonical concatenation is sensitive to the chosen digit word. A proof must show that the chosen fixed-length prefix with internal zeros has the same partition sum as the canonical representation of the truncated integer.

That equivalence is not supplied by the displayed block formula alone.

## 2. The `c(0)=1` step

The claimed repair is:

```text
leading zero digits in the fixed-length prefix are forced singleton zero blocks
with c(0)=1.
```

This requires two separate facts:

1. the construction actually defines `c(0)` and gives exactly `1`, not merely a p-integral coefficient;
2. every admissible partition containing those zero digits has no alternative grouping that changes the sum.

The valuation statement

```text
v_p(c(a)) >= length_p(a)-1
```

does not imply `c(0)=1`. Since `length_p(0)` conventions vary and the valuation bound only constrains divisibility, it cannot replace an explicit evaluation of the coefficient. Thus the proof must exhibit the Mellit--Vlasenko coefficient formula at `a=0` and prove the exact value.

## 3. Kummer suffix ladder

The suffix ladder is the right type of input, but the boundary lemma requires every boundary case, not only the generic case. The required hypotheses include:

```text
p^(e-k) | b_(T_k), 0 <= k < e.
```

The exceptional shapes

```text
n = 2 p^d - 1
n < p^e
```

cannot be silently absorbed into the ordinary carry argument. They need explicit verification that the suffixes `T_k` appearing in the block lemma are exactly the suffixes covered by the Kummer computation.

From the statement provided, this verification is asserted but not derived. Therefore the ladder is incomplete until those edge cases are matched digit-by-digit with the boundary lemma's `T_k` definition.

## 4. Laurent polynomial / lattice-point hypothesis

The final geometric input requires that the cited Laurent polynomial generates exactly this Apéry sequence and satisfies the unique-interior-lattice-point condition required by the theorem.

A Laurent polynomial producing Apéry-like numbers is not enough. The proof needs:

```text
constant_term(P(x)^n) = b_n
```

for the exact Apéry numbers used in `Gamma_n`, and the Newton polytope condition used by the theorem.

No argument in the block lemma itself establishes this identification. It must be checked independently from the chosen polynomial.

## Final classification

The proposed proof has the correct high-level architecture:

```text
Newton content
 -> primitive numerator divisibility
 -> Mellit--Vlasenko block valuations
 -> boundary induction
 -> Apéry divisibility
```

However, the induction step is not yet closed. The first exact missing lemma is:

```text
For a fixed-length base-p word with zero padding, the sum of all
admissible prefix block partitions equals the Mellit--Vlasenko value
of the numerically truncated suffix T_(l-1), including all internal
zero digits.
```

Until this is proved together with the exact `c(0)=1` calculation and the exceptional Kummer cases, the implication

```text
p^e | Gamma_n => p^e | b_n
```

is not a proved all-exponent theorem.
