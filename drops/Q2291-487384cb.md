结论分成两部分，而且必须把它们分开：

1. **相邻核的 gcd 模式完全可证，而且比题目猜测更强。** 对每个 `r>=1`，
   \[
   \boxed{6K(r,r-1)=b_r+b_{r-1}},
   \tag{1}
   \]
   并且
   \[
   \boxed{\gcd\!\bigl(r^3K(r,r-1),b_r\bigr)\mid (r!)^3.}
   \tag{2}
   \]
   因而该 gcd 的每个素因子都满足 `q<=r`，不只是 `q<=r+1`。

2. **所声称的 Racah“传播”是假的。** `K(r,r-1)\ne0` 只给出一个非零初始方向；二阶递推仍可在以后出现孤立零点。严格下半区已有精确反例
   \[
   \boxed{(p,r,s)=(41,10,13)}:
   \qquad b_{10}=0,\quad K(10,9)\ne0,\quad K(10,13)=0\pmod{41}.
   \tag{3}
   \]
   这里 `10<13<20=(41-1)/2`，且 `10+13+1=24\not\equiv0 mod 41`，所以它既不是 diagonal、mate，也不是中央 pole。

因此三个问题的精确答案是：

- **(a) YES。** 有显式恒等式和显式整数 Bézout 证书；事实上得到 (2)。
- **(b) NO。** 它不是 Beukers 超同余、Stienstra--Beukers 几何或 CFVZ 平方结构的等价改写；它只是一个特征零的相邻 Racah/终止 `4F3` contiguous identity，再加 Apéry 递推。
- **(c) YES。** 对相邻和存在直接的 fraction-free 组合证明。但这并不推出所有后继 `K(r,s)` 非零，所以它不是最终 all-gap 证明。

# 1. 相邻 Racah 核的精确恒等式

写

\[
D(n,k)=\binom nk\binom{n+k}{k},
\qquad
b_n=\sum_{k=0}^nD(n,k)^2,
\]

以及

\[
K(r,s)=\sum_{k=0}^{\min(r,s)}D(r,k)D(s,k).
\]

固定 `r>=1`，令

\[
d_k=D(r,k),\qquad e_k=D(r-1,k),\qquad 0\le k\le r,
\]

并约定 `e_r=0`、`d_{-1}=0`。两个直接的二项式比值为

\[
e_k=\frac{r-k}{r+k}d_k,
\tag{4}
\]

以及

\[
\frac{d_k}{d_{k-1}}
=\frac{(r-k+1)(r+k)}{k^2}.
\tag{5}
\]

关键是下面的 **fraction-free telescoping certificate**：

\[
\boxed{
\begin{aligned}
&r^2\bigl(6d_ke_k-d_k^2-e_k^2\bigr)\\
&\qquad=4\Bigl((r-k)^2d_k^2
 -(r-k+1)^2d_{k-1}^2\Bigr).
\end{aligned}}
\tag{6}
\]

证明只需代入 (4)--(5)。事实上

\[
6d_ke_k-d_k^2-e_k^2
=\frac{4(r^2-2k^2)}{(r+k)^2}d_k^2,
\]

而

\[
(r-k)^2d_k^2-(r-k+1)^2d_{k-1}^2
=\frac{r^2(r^2-2k^2)}{(r+k)^2}d_k^2.
\]

将 (6) 对 `k=0,...,r` 求和，右边完全望远镜消去。左边成为

\[
r^2\bigl(6K(r,r-1)-b_r-b_{r-1}\bigr)=0.
\]

由于这是整数恒等式且 `r>=1`，得到

\[
\boxed{6K(r,r-1)=b_r+b_{r-1}.}
\tag{7}
\]

所以题目中的整数是

\[
\boxed{
M_r=r^3K(r,r-1)=\frac{r^3}{6}(b_r+b_{r-1}).}
\tag{8}
\]

`M_r` 的正性和整性也立即成立：原定义中的每个求和项都是正整数，而 (7) 另外说明 `6|(b_r+b_{r-1})`。

# 2. 连续 Apéry 值的 factorial-cube Bézout 证书

设

\[
P(n)=34n^3+51n^2+27n+5.
\]

Apéry 递推是

\[
(n+1)^3b_{n+1}=P(n)b_n-n^3b_{n-1}.
\tag{9}
\]

定义整数 `x_r,y_r`：

\[
x_1=0,\qquad y_1=1,
\tag{10}
\]

且对 `r>=2`，

\[
\boxed{
\begin{aligned}
x_r&=-r^3y_{r-1},\\
y_r&=(r-1)^3x_{r-1}+P(r-1)y_{r-1}.
\end{aligned}}
\tag{11}
\]

则有精确恒等式

\[
\boxed{x_rb_r+y_rb_{r-1}=((r-1)!)^3.}
\tag{12}
\]

## 证明

`r=1` 时 (12) 是 `b_0=1`。假设 `r-1` 时成立，乘以 `(r-1)^3`：

\[
((r-1)!)^3
=(r-1)^3x_{r-1}b_{r-1}
 +(r-1)^3y_{r-1}b_{r-2}.
\]

将 (9) 在 `n=r-1` 处改写为

\[
(r-1)^3b_{r-2}=P(r-1)b_{r-1}-r^3b_r,
\]

代入即得到 (11)--(12)。特别地，

\[
\boxed{\gcd(b_r,b_{r-1})\mid ((r-1)!)^3.}
\tag{13}
\]

这不是仅仅关于素因子集合的论证；它给出了实际的整数线性组合。

# 3. 对 `M_r` 的显式 Bézout 证书

由 (8)，

\[
6M_r=r^3(b_r+b_{r-1}).
\tag{14}
\]

把 (12) 乘以 `r^3`，并用 (14) 消去 `r^3b_{r-1}`，得到

\[
\boxed{
6y_rM_r+r^3(x_r-y_r)b_r=(r!)^3.}
\tag{15}
\]

这正是题目所要求的“小素数分母/互素性”证书的无分母版本。它说明在局部化环中

\[
(M_r,b_r)\,\mathbf Z[1/r!]=\mathbf Z[1/r!].
\]

因此

\[
\boxed{\gcd(M_r,b_r)\mid(r!)^3,}
\tag{16}
\]

并且对每个素数 `q`，

\[
v_q\!\left(\gcd(M_r,b_r)\right)
\le 3v_q(r!).
\tag{17}
\]

所以题目观察到的 “所有素因子 `<=r+1`” 是真的，但可加强成

\[
\boxed{q\mid\gcd(M_r,b_r)\Longrightarrow q\le r.}
\tag{18}
\]

例如 `r=2` 时，`x_2=-8,y_2=117`，(15) 给出

\[
702M_2-1000b_2=8,
\]

即

\[
702\cdot104-1000\cdot73=8.
\]

# 4. 对问题 (c) 的直接证明

设 `p>r+1` 为素数且 `p|b_r`。由 (16)，若同时 `p|M_r`，则

\[
p\mid(r!)^3,
\]

但 `p>r`，矛盾。因此

\[
p\nmid M_r.
\]

又因 `p>r`，`r^3` 是 `p`-unit，所以

\[
\boxed{p\nmid K(r,r-1).}
\tag{19}
\]

也可更短地从 (7) 证明。若 `p>=5` 且 `b_r=K(r,r-1)=0 mod p`，则

\[
b_{r-1}\equiv0\pmod p.
\]

在 (9) 中从 `n=r-1` 开始反向递推；因 `1,...,r-1` 全是 `p`-unit，会依次得到

\[
b_{r-2}\equiv\cdots\equiv b_0\equiv0\pmod p,
\]

与 `b_0=1` 矛盾。

所以问题 (c) 的相邻命题已经有一个完全初等、无概率、无几何输入的证明。

# 5. 与 Beukers、Stienstra--Beukers、CFVZ 的关系

## 5.1 它是一个终止 `4F3` contiguous identity

因为

\[
D(r,k)=(-1)^k\frac{(-r)_k(r+1)_k}{(k!)^2},
\]

(7) 等价于

\[
\begin{aligned}
6\,{}_4F_3\!\left(
\begin{matrix}-r,r+1,1-r,r\\1,1,1\end{matrix};1\right)
={}&{}_4F_3\!\left(
\begin{matrix}-r,-r,r+1,r+1\\1,1,1\end{matrix};1\right)\\
&+{}_4F_3\!\left(
\begin{matrix}1-r,1-r,r,r\\1,1,1\end{matrix};1\right).
\end{aligned}
\tag{20}
\]

这是参数 `r -> r-1` 的相邻 contiguous relation；(6) 是它的 WZ/Gosper 型证书。

## 5.2 不是三个深层理论的等价改写

- Beukers 的 Apéry 同余/超同余处理不同指标之间的 `p`-进关系。
- Stienstra--Beukers 处理 Picard--Fuchs 方程、形式 Brauer 群和相关 K3 几何。
- CFVZ 的结果处理模 `p` 生成级数的 Galois 群及 Hasse 截断多项式的 quadratic-times-square 结构。

而 (6)--(7) 在 `Z` 上对每个整数 `r` 成立，只用两个二项式比值；证明中没有素数、Frobenius、Hasse--Witt、模形式或 Galois 表示。因此：

\[
\boxed{\text{它与这些理论相容，但不是它们的等价形式，也不需要它们。}}
\]

最准确的分类是：**Racah/Legendre Newton 行之间的相邻离散 Green 恒等式。**

相关文献背景为：

- F. Beukers, *Some congruences for the Apéry numbers*, J. Number Theory 21 (1985), 141--155.
- J. Stienstra and F. Beukers, *On the Picard--Fuchs equation and the formal Brauer group of certain elliptic K3-surfaces*, Math. Ann. 271 (1985), 269--304.
- X. Caruso, F. Fürnsinn, D. Vargas-Montoya and W. Zudilin, *Galois groups of Apéry-like series modulo primes*, Bull. Aust. Math. Soc. 114 (2026), 65--78.

# 6. 决定性问题：相邻非零不会传播到所有 `s`

二阶递推只说明两个连续值不能同时为零；它不说明从一个非零初值出发以后永不为零。当前项目的 gap continuant 正是描述“以后何时再次命中零”的对象。

下面是严格下半区中的精确反例：

\[
p=41,\qquad r=10,\qquad s=13.
\]

整数值为

\[
b_{10}=13657436403073
      =41\cdot333108204953,
\tag{21}
\]

\[
K(10,9)=2354354542013\equiv21\pmod{41},
\tag{22}
\]

但

\[
K(10,13)=1302144726557533
        =41\cdot31759627477013.
\tag{23}
\]

同时

\[
b_{13}=364713572395983725\equiv30\pmod{41}.
\tag{24}
\]

几何排除条件也全部检查：

\[
10\ne13,
\qquad10+13+1=24\not\equiv0\pmod{41},
\qquad10<13<20.
\]

所以 `(10,13)` 既不是 diagonal，也不是 mate，且两点都不在中央 ramification node。于是

\[
\boxed{
K(r,r-1)\ne0
\centernot\Longrightarrow
K(r,s)\ne0\quad\text{for all nonmate }s>r.}
\tag{25}
\]

该反例与 Q2273 完全一致：`p=41` 的 Apéry/Hasse 零集只有 `r=10`；`s=13` 使 Racah 核为零，但并不是第二个 Apéry 零。因此它不反驳真正的 marked 命题，却证明单独的 Racah 递推无法完成 marked 命题。

真正仍需证明的是更窄而更强耦合的陈述：

\[
\boxed{
\begin{gathered}
p\mid b_r,\qquad p\mid b_s,\\
r\ne s,\qquad r+s+1\not\equiv0\pmod p
\end{gathered}
\Longrightarrow
K(r,s)\not\equiv0\pmod p.}
\tag{26}
\]

相邻 seed (19) 没有使用 `b_s=0`，因此也不可能自动产生 (26)。要完成 (26)，仍需要把第二个 Apéry 零加入证书：例如 off-diagonal CD/Bailey bridge、saturated resultant、second-Fitting 排除，或终端 ratio inequality。

# 7. 依赖标准库的精确 verifier

```python
from math import comb, factorial, gcd


def D(n, k):
    if k < 0 or k > n:
        return 0
    return comb(n, k) * comb(n + k, k)


def b(n):
    return sum(D(n, k) ** 2 for k in range(n + 1))


def K(r, s):
    return sum(D(r, k) * D(s, k)
               for k in range(min(r, s) + 1))


def P(n):
    return 34*n**3 + 51*n**2 + 27*n + 5


# Fraction-free telescoping and adjacent identity.
for r in range(1, 101):
    for k in range(r + 1):
        d = D(r, k)
        e = D(r - 1, k)
        dm = D(r, k - 1)
        lhs = r*r * (6*d*e - d*d - e*e)
        rhs = 4 * ((r-k)**2*d*d - (r-k+1)**2*dm*dm)
        assert lhs == rhs
    assert 6*K(r, r-1) == b(r) + b(r-1)


# Consecutive-value and M_r Bézout certificates.
x, y = 0, 1
for r in range(1, 101):
    if r > 1:
        x, y = -r**3*y, (r-1)**3*x + P(r-1)*y

    assert x*b(r) + y*b(r-1) == factorial(r-1)**3

    M = r**3 * K(r, r-1)
    assert 6*y*M + r**3*(x-y)*b(r) == factorial(r)**3
    assert factorial(r)**3 % gcd(M, b(r)) == 0


# Exact failure of the claimed propagation.
p, r, s = 41, 10, 13
assert b(r) == 13657436403073
assert b(r) % p == 0
assert K(r, r-1) == 2354354542013
assert K(r, r-1) % p == 21
assert K(r, s) == 1302144726557533
assert K(r, s) % p == 0
assert b(s) == 364713572395983725
assert b(s) % p == 30
assert r != s and (r+s+1) % p != 0
assert r < s < (p-1)//2

print("Q2291 identities and propagation counterexample: VERIFIED")
```
