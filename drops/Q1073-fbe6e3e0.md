# Audit of the conjectural exact 2-adic Padé-content exponent

## Executive verdict

The claimed formula

```text
v₂(D_n)=2                         if n=2^a-1
v₂(D_n)=min(5,2+r₂(n))             otherwise
```

is not proved by the available information. The finite scan through `n<=1200` is consistent with it, but the requested all-length finite-state certificate is not presently available from the stated Apéry facts. The missing ingredient is an explicit mod-64 digit transducer for the Apéry sequence together with a proof that it interacts with the Kummer carry automaton exactly as required.

No counterexample is produced here; the correct audited conclusion is that the conjecture remains an open p-adic lemma.

---

# 1. Reduction to the p-adic minimization problem

Since

```text
D_n=gcd_j L_j(b_n-b_j),
```

we have

```text
v₂(D_n)=min_j (v₂(L_j)+v₂(b_n-b_j)).
```

Kummer gives

```text
v₂(binomial(a,b)) = number of carries when adding b and a-b in base 2.
```

Therefore

```text
v₂(L_j)= carries(j,n-j)+carries(M-1-j,n-M).
```

This part is exact. The remaining term is

```text
v₂(b_n-b_j),
```

which requires a uniform description of Apéry numbers modulo powers of two.

---

# 2. Required Apéry congruence data

The following statements are true and sufficient building blocks:

* every Apéry number is odd;
* therefore `b_n-b_j` is always even;
* modulo powers of two, only the residue class of the pair `(n,j)` matters.

However, an ordinary periodicity claim such as "Apéry numbers are periodic modulo 64" is not enough. A proof requires a stronger statement:

There must exist a finite state set `S` and transition maps

```text
T_0,T_1 : S -> S
```

such that reading the binary digits of `m` gives a state `s(m)` satisfying

```text
output(s(m)) = b_m mod 64.
```

No such transition table and invariant has been supplied. The assertion that the sequence is 2-automatic is therefore not an executable certificate.

---

# 3. Why the conjectured finite-state proof is incomplete

A valid certificate needs to combine two independent automata:

## Kummer component

A state must record:

```text
carry/borrow status for the two binomial factors in L_j;
comparison j<M;
```

This determines the contribution `v₂(L_j)`.

## Apéry component

The same digit scan must record:

```text
b_n mod 64,
b_j mod 64.
```

The combined transition invariant must prove:

1. every reachable state gives valuation at least the claimed exponent;
2. a reachable witness state gives equality.

The second item is essential. A lower bound alone cannot establish the gcd valuation.

---

# 4. Missing witness lemma

The precise missing lemma is:

> For every binary expansion of n>=4, there exists a valid j<M such that
>
> ```text
> v₂(L_j)+v₂(b_n-b_j)=min(5,2+r₂(n))
> ```
>
> with value 2 for n=2^a-1.

This is the valuation-exact witness construction.

The leading-one run `r₂(n)` suggests that the witness is controlled by the first block of digits after the leading run, but the Apéry residue transition needed to force the exact cancellation modulo 4/8/16/32/64 has not been derived.

# 5. Computer evidence

The existing computation through `n<=1200` supports the formula. It does not prove it.

A valid independent verifier would have to:

```python
for n in range(4,N):
    compute Apery numbers exactly
    for j in range(floor(n/2)):
        compute L_j exactly
        compute v2(L_j*(b_n-b_j))
    compare minimum with conjectured value
```

and additionally produce witness indices `j`.

The present answer does not claim a new range or a counterexample without executing such a verifier.

# 6. Narrow explicit lemma that would settle the theorem

The conjecture would follow from the following finite-state statement:

**Mod-64 Apéry/Kummer separation lemma.**

There exists a finite transducer whose input is a pair of binary digit streams `(n,j)` and whose state invariant simultaneously gives:

1. the two Kummer carry counts for `L_j` truncated at 6;
2. the residue pair `(b_n mod 64,b_j mod 64)`;
3. whether `j<M`.

For every reachable terminal state:

```text
valuation >= min(5,2+r₂(n))
```

and for at least one terminal state equality holds.

This lemma is exactly what remains to be proved.
