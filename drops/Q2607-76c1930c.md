# P3.2 direct global compression: exact Smith saturation for the direct/Strehl pair

## Verdict

The strongest natural second representation in the repository is the Strehl--Franel identity paired with the direct Apéry sum. Their fixed-`q` truncations do give strict Archimedean savings, but the savings remain linear in `n` and the two representations do not give independent congruences.

The exact obstruction is an integral Smith block. Modulo every admissible prime in the fixed-`q` interval, the universal Legendre--Euler coefficient matrix has rank one. Over the integers it has the form

```text
U M V = diag(1, Pi_{n,q} W),
```

where `Pi_{n,q}` is the squarefree product of all admissible candidate primes. The lower block is therefore universally saturated by the whole candidate interval. The sole selective coordinate is the constant coefficient. For the direct and Strehl--Franel inputs that coordinate is the same folded Apéry value.

Consequently:

- the candidate part of the common primitive content is exactly the desired fixed-`q` Apéry radical;
- every raw resultant is divisible by all candidate primes, including non-hits;
- removing the universal/resultant content requires dividing by the target radical itself;
- the sharp automatic boundary carrier has positive linear rate, not `o(n)`.

This is option (2): a scoped exact no-go for the strongest same-index two-representation class. It covers the direct and Strehl--Franel formulas, their binomial translations, finite center/evaluation grids, and all integral/unimodular changes of the same finite coefficient lattice. It does not rule out a genuinely different modular representation with a second Frobenius direction.

## 1. Fixed-q exceptions and the exact target

Put

```text
L(n,k) = binom(n,k) binom(n+k,k),
F_k    = sum_{a=0}^k binom(k,a)^3.
```

The two exact characteristic-zero identities are

```text
b_n = sum_{k=0}^n L(n,k)^2,

b_n = sum_{k=0}^n L(n,k) F_k.
```

Fix `q>=1`. Lucas gives

```text
n=qp+r,  0<=r<p
==>
b_n = b_q b_r (mod p).
```

The equivalence between a slice hit and a low-digit hit therefore has one fixed finite exception set. Define

```text
E_q = { primes p : p<=2q or p|b_q }
      union {2,3,5}.
```

The admissible candidate set and its product are

```text
P_{n,q}
= { primes p not in E_q : floor(n/p)=q }
= { primes p not in E_q : n/(q+1)<p<=n/q },

Pi_{n,q} = product_{p in P_{n,q}} p.
```

The set `E_q` depends only on `q`. It contributes `O_q(1)` primes and, once `n` is large enough, none of its members lies in the moving interval. Thus it has no effect on the required asymptotic.

For `p` in the admissible set, write

```text
n=qp+r,
0<=r<p,
j=min(r,p-1-r).
```

Reflection gives

```text
b_r = b_j (mod p),
```

and `p` is a slice hit exactly when

```text
p|b_n  <=>  p|b_r  <=>  p|b_j.
```

Define the admissible fixed-`q` radical

```text
R_{n,q}
= product_{p in P_{n,q}, p|b_n} p.
```

For all sufficiently large `n`, this differs from the full fixed-`q` slice radical by nothing at all.

## 2. The canonical folded cutoff

Use

```text
J = floor((n-q)/(2q+1)).
```

The folded index satisfies

```text
j<=J<p.
```

For the direct branch, `j=r` and

```text
2r<=p-1  ==>  (2q+1)r<=n-q.
```

For the reflected branch, `r=p-1-j`, and

```text
2j<=p-1  ==>  (2q+1)j<=n-q.
```

Define the two positive truncation anchors

```text
D_{n,q} = sum_{k=0}^J L(n,k)^2,
S_{n,q} = sum_{k=0}^J L(n,k) F_k.
```

Lucas and reflection give, for every admissible candidate prime,

```text
D_{n,q} = b_j (mod p),
S_{n,q} = b_j (mod p).
```

Hence

```text
R_{n,q} divides gcd(D_{n,q},S_{n,q}).
```

The question is whether the second representation makes this gcd small for a structural reason. The answer below is no: the two reductions lie on the same rank-one line.

## 3. Universal Legendre--Euler transform

Let

```text
Q_n(t) = sum_{k=0}^n L(n,k)t^k.
```

For an arbitrary integer vector

```text
x=(x_0,...,x_J),
```

define

```text
K_{n,m}(c)   = [y^m]Q_n(c+y),
g_m^x(c)     = sum_{i=0}^m binom(m,i)(-c)^(m-i)x_i,
T_{n,J}^x(c) = sum_{m=0}^J K_{n,m}(c)g_m^x(c).
```

Its constant coefficient is

```text
S_x = T_{n,J}^x(0)
    = sum_{i=0}^J L(n,i)x_i.
```

The transform is an exact binomial change of basis. If `Q_a` has degree at most `J`, then

```text
sum_{m=0}^J K_{a,m}(c)g_m^x(c)
= sum_{i=0}^J L(a,i)x_i.
```

Indeed, the coefficient of `L(a,k)x_i` is

```text
sum_{m=i}^k binom(k,m)binom(m,i)
                 c^(k-m)(-c)^(m-i)
= binom(k,i)c^(k-i)
  sum_{u=0}^{k-i}binom(k-i,u)(-1)^u,
```

which is one for `k=i` and zero otherwise.

The two Apéry representations correspond to

```text
x_i^D = L(n,i),
x_i^F = F_i.
```

At the saturated cutoff `J=n`, both transforms are independent of `c` and equal `b_n`.

## 4. Exact rank-one collapse modulo every candidate prime

For `p>q`, Lucas gives

```text
Q_{qp+r}(t)=Q_q(t^p)Q_r(t) (mod p).
```

Substitute `t=c+y`. Since `J<p`, the terms of `y`-degree at most `J` use only the constant term in `y^p` from the high factor. Thus

```text
K_{n,m}(c)=Q_q(c^p)K_{r,m}(c) (mod p)
for 0<=m<=J.
```

If `r=p-1-j`, the reflected binomial congruences give

```text
Q_r(t)=Q_j(t) (mod p).
```

Since `j<=J`, the low transform is saturated. Therefore, for every integer input vector `x`,

```text
T_{n,J}^x(c)
= Q_q(c^p) sum_{i=0}^j L(j,i)x_i
= Q_q(c^p) S_x
  (mod p).
```

The last equality follows by setting `c=0` and using `Q_q(0)=1`.

For the direct and Franel vectors, the scalar is the same folded Apéry value:

```text
T_{n,J}^{x^D}(c)=b_j Q_q(c^p) (mod p),
T_{n,J}^{x^F}(c)=b_j Q_q(c^p) (mod p).
```

This is the decisive no-go identity. The second representation supplies the same scalar equation on the same coefficient line. It is not a second characteristic-zero direction.

## 5. Exact coefficient matrix

Write

```text
T_{n,J}^x(c)
= sum_{d=0}^n (sum_{i=0}^J M_{d,i}x_i)c^d.
```

The entries are

```text
M_{0,i}=L(n,i).
```

For `d>=1`,

```text
M_{d,i}
= (-1)^(J-i)L(n,i+d)
  binom(i+d,i)binom(d-1,J-i)
```

when

```text
max(0,J+1-d)<=i<=min(J,n-d),
```

and they are zero otherwise.

This follows from

```text
binom(i+d,i)
  sum_{u=0}^{min(J-i,d)}(-1)^u binom(d,u)
```

and the partial alternating-binomial identity

```text
sum_{u=0}^{J-i}(-1)^u binom(d,u)
= (-1)^(J-i)binom(d-1,J-i).
```

Since the reduction of `M` has rank one and `M_{0,0}=1`, every admissible candidate prime divides

```text
N_{d,i}=M_{d,i}-M_{d,0}M_{0,i}
```

for all `d>=1` and `i>=1`. Hence

```text
Pi_{n,q}|N_{d,i}.
```

Put

```text
W_{d,i}=N_{d,i}/Pi_{n,q}.
```

## 6. Exact Smith block and content identity

Perform the unimodular operations

```text
row_d <- row_d-M_{d,0}row_0       for d>=1,
col_i <- col_i-M_{0,i}col_0       for i>=1.
```

They give

```text
U M V =
[ 1          0 ]
[ 0   Pi_{n,q}W ].
```

For one input vector define

```text
R_d(x)=sum_{i=1}^J W_{d,i}x_i,
G_x   =gcd_{d>=1}R_d(x).
```

Unimodular row operations preserve coefficient content, so

```text
content(T_{n,J}^x)
= gcd(S_x,Pi_{n,q}G_x).
```

For a finite family of inputs, the common coefficient gcd is

```text
Gamma_X
= gcd(S_{x^(1)},...,S_{x^(m)},Pi_{n,q}G_X),
```

where

```text
G_X=gcd_{a,d>=1}R_d(x^(a)).
```

This is an exact Smith/content calculation, not a dimension count. The whole lower coefficient block is divisible by every candidate prime. Only the anchors can distinguish a hit from a non-hit.

## 7. Exact primitive valuation away from one midpoint

Put

```text
B=J+1.
```

Take rows

```text
d_i=B-i,  1<=i<=J,
```

and columns `1,...,J`. The corresponding submatrix of `W` is triangular, with diagonal

```text
W_{B-i,i}
= (-1)^(J-i)(L(n,B)/Pi_{n,q})binom(B,i).
```

Therefore

```text
det(W_triangle)
= +/- (L(n,B)/Pi_{n,q})^J
      product_{i=1}^J binom(B,i).
```

For a candidate prime, at least one of the two binomial factors in `L(n,B)` has a carry. Both have a carry exactly in the midpoint case

```text
2n+1=(2q+1)p.
```

Thus, away from the unique possible midpoint prime,

```text
v_p(L(n,B))=1,
p does not divide L(n,B)/Pi_{n,q},
p does not divide binom(B,i).
```

The triangular block is therefore invertible modulo `p`.

For the Franel input,

```text
x_1^F=F_1=2,
```

so its tail vector is nonzero modulo every candidate prime. Hence

```text
p does not divide G_{x^F}
```

away from the midpoint. It follows that

```text
v_p(content(T_{n,J}^{x^F}))
= 1 if p|b_j,
= 0 if p does not divide b_j.
```

The same formula holds for the common content of the direct/Franel pair:

```text
v_p(Gamma_{D,F})
= 1 if p|b_j,
= 0 if p does not divide b_j.
```

At the midpoint, support equivalence remains true but the exponent can exceed one. There is at most one midpoint prime, so its logarithmic contribution is `O(log n)`.

Consequently the exact candidate-radical identity is

```text
gcd(rad(Gamma_{D,F}),Pi_{n,q})=R_{n,q}.
```

Thus the primitive common content does not produce a smaller independent object. Its candidate part is exactly the radical whose subexponential height is the target.

## 8. Raw resultants are universally saturated

For every admissible candidate prime,

```text
T_{n,J}^{x^D}(c)
= T_{n,J}^{x^F}(c)
= b_j Q_q(c^p)
  (mod p).
```

Because the exception set includes `p<=2q`, the polynomial `Q_q` has degree `q` with unit leading coefficient modulo every admissible prime. Hence both transforms share

```text
Q_q(c^p)
```

of degree `qp` modulo every candidate, including non-hits.

If the characteristic-zero resultant is nonzero, the Sylvester matrix has nullity at least `qp` modulo `p`. Therefore

```text
p^(qp) divides
Res_c(T_{n,J}^{x^D},T_{n,J}^{x^F}).
```

The aggregate universal factor has quadratic logarithmic size:

```text
sum_{p in P_{n,q}}qp log p=Theta_q(n^2).
```

Taking primitive polynomials does not give a free carrier. The exact factorization is

```text
Res(A,B)
= content(A)^(deg B)
  content(B)^(deg A)
  Res(A_prim,B_prim).
```

At a bad prime the selective factor is already in the two contents, whose candidate part is exactly `R_{n,q}` by the Smith calculation. Removing those contents re-imports the target radical. Any further prime in the primitive resultant is accidental; it is not forced by the two-representation identities.

The same rank-one argument applies to finite center grids and evaluation determinants. If an evaluation of `Q_q` vanishes, it adds a non-hit candidate; if it is a unit, it gives only the original anchor equation.

## 9. Sharp automatic boundary carrier and its height

The boundary coefficient

```text
C_{n,q}=L(n,J+1)
```

is divisible by every admissible candidate prime, once away from the midpoint exactly once. Therefore

```text
gcd(Pi_{n,q},rad(gcd(S_{n,q},C_{n,q})))
=R_{n,q}.
```

This is an exact characteristic-zero support formula, but its height is linear.

Put

```text
alpha_q=1/(2q+1),

lambda(alpha)
=(1+alpha)log(1+alpha)
 -(1-alpha)log(1-alpha)
 -2alpha log(alpha).
```

Stirling gives

```text
log C_{n,q}
=lambda(alpha_q)n+O_q(log n).
```

The direct and Strehl truncations have rates

```text
log D_{n,q}
=2lambda(alpha_q)n+O_q(log n),

log S_{n,q}
=(lambda(alpha_q)+alpha_q log 8)n
 +O_q(log n).
```

The full Apéry rate is

```text
log b_n
=log(17+12sqrt(2))n+O(log n).
```

For `q=1`,

```text
lambda(1/3)=log 4,
log D_{n,1}=(log 16)n+O(log n),
log S_{n,1}=(log 8)n+O(log n),
log C_{n,1}=(log 4)n+O(log n).
```

These are strict savings, but each is still `c n` with `c>0`.

Even the candidate product itself has positive linear rate:

```text
log Pi_{n,q}
=theta(n/q)-theta(n/(q+1))+O_q(log n)
=n/(q(q+1))+o_q(n).
```

Removing the fixed finite exception set changes only the `O_q(1)` term. Thus any lower coefficient, boundary determinant, raw resultant, or finite grid whose divisibility is universal over the whole candidate interval is blocked from an `o(n)` height estimate.

## 10. Exact concrete saturation example

Take

```text
n=20,
q=1,
J=6.
```

The candidate primes and folded indices are

```text
p=11: r=9, j=1,
p=13: r=7, j=5,
p=17: r=3, j=3,
p=19: r=1, j=1.
```

Here

```text
b_1=5,
b_3=1445=5*17^2,
b_5=819005=5 (mod 13).
```

Therefore

```text
Pi_{20,1}=11*13*17*19=46189,
R_{20,1}=17.
```

Since

```text
Q_1(t)=1+2t,
```

the two transformed representations satisfy

```text
mod 11: T_D(c)=T_F(c)=5(1+2c^11),
mod 13: T_D(c)=T_F(c)=5(1+2c^13),
mod 17: T_D(c)=T_F(c)=0,
mod 19: T_D(c)=T_F(c)=5(1+2c^19).
```

Thus the common coefficient content has candidate support exactly `17`, but the raw resultant is divisible by all four candidates. The three non-hits `11`, `13`, and `19` enter the resultant before the single hit is selected. Also

```text
11*13*17*19 divides L(20,7),
```

with each valuation equal to one.

This is an exact counterexample to the hope that the direct/Strehl resultant is selective.

## 11. Scope and terminal implication

The Smith block is invariant under unimodular row and column changes. It therefore covers:

- monomial, Newton, binomial, and translated coefficient bases;
- integral center changes;
- finite integral coefficient combinations;
- constant-term or diagonal re-expansions that are integral changes of this coefficient lattice;
- finite evaluation or moment grids;
- the direct and Strehl--Franel inputs, or any finite family with the same saturated low-digit transform.

Non-unimodular postprocessing only adds lattice-index factors. Modulo each candidate prime its image still has rank at most one. Clearing rational denominators likewise adds universal factors and cannot improve primitive content.

The theorem does not exclude a genuinely different representation whose reduction is not of the form

```text
scalar * Q_q(c^p).
```

Such a representation would need a second Frobenius eigenline or a genuinely cross-prime canonical quotient identity. The Apéry companion, finite cusp-unit grids, and local Racah collisions do not presently supply that direction.

The exact conclusion for this class is

```text
U M V=diag(1,Pi_{n,q}W),

gcd(rad(Gamma_{D,F}),Pi_{n,q})=R_{n,q}.
```

Raw resultants are universally saturated, primitive contents reproduce the target radical, and boundary carriers have positive linear height. Therefore this class does not prove

```text
# { p in (n/(q+1),n/q] : p|b_n }
=o_q(n/log n).
```

A fully unconditional proof must escape the rank-one Smith class rather than add another same-index binomial, Franel, constant-term, or finite-grid rewrite.
