# P3.2 direct global compression: exact Smith saturation for the direct/Strehl pair

## Verdict

The strongest natural two-representation candidate in the present repository is the pair consisting of the direct Apéry sum and the Strehl--Franel sum.  Both are exact characteristic-zero representations of the same integer, and their canonical fixed-`q` truncations are substantially smaller than the full Apéry number.

They nevertheless do **not** give a new height mechanism.  The obstruction is exact:

1. modulo every prime in the fixed-`q` candidate interval, whether or not it is an Apéry hit, the universal Legendre--Euler coefficient matrix has rank one;
2. over the integers that matrix has an explicit Smith block

```text
U M V = diag(1, Pi_{n,q} W),
```

where `Pi_{n,q}` is the squarefree product of **all** primes in the fixed-`q` interval;
3. for the direct and Strehl--Franel inputs, the candidate-prime part of the common primitive content is exactly the desired fixed-`q` Apéry radical, with exponent one away from one midpoint prime;
4. every raw resultant of the two transformed polynomials is divisible by every candidate prime, including the non-hits, because the two reductions have the same universal factor;
5. removing that universal saturation leaves the hit information only in the coefficient contents, whose candidate part is already exactly the target radical.

Thus this two-representation class does not produce an independent carrier whose smallness can be proved from its construction.  It repackages the unknown radical exactly.  Its best automatic Archimedean carriers have positive linear exponential rate; for `q=1` the successive rates are `log 16`, `log 8`, and `log 4`, not `o(n)`.

This is a scoped no-go, not a claim about every conceivable modular-parametric representation.  It covers the direct sum, the Strehl--Franel sum, their binomial translations, finite center/evaluation grids, coefficient/constant-term re-expansions obtained by integral linear operations, and all unimodular changes of the corresponding coefficient bases.

## 1. The two exact characteristic-zero representations

Put

```text
L(n,k) = binom(n,k) binom(n+k,k),
F_k    = sum_{a=0}^k binom(k,a)^3.
```

The direct Apéry representation is

```text
b_n = sum_{k=0}^n L(n,k)^2.
```

The Strehl--Franel representation is

```text
b_n = sum_{k=0}^n L(n,k) F_k.
```

These are genuinely different summand systems.  The second has a smaller positive truncation height because the factor `F_k` grows like `8^k` up to powers of `k`, whereas `L(n,k)` supplies a second copy of the binomial kernel in the direct sum.

For the fixed-`q` slice define

```text
P_{n,q} = { primes p >= 7 : floor(n/p) = q }
        = { primes p : n/(q+1) < p <= n/q },
Pi_{n,q} = product_{p in P_{n,q}} p.
```

For a member `p` of this set, write

```text
n = q p + r,
0 <= r < p,
j = min(r, p-1-r).
```

The canonical folded cutoff is

```text
J = floor((n-q)/(2q+1)).
```

The elementary folded bound is

```text
j <= J < p.
```

For the direct branch, the inequality follows from

```text
2r <= p-1  ==>  (2q+1)r <= n-q.
```

For the reflected branch, write `r=p-1-j`; the same assertion follows from

```text
2j <= p-1  ==>  (2q+1)j <= n-q.
```

The finitely many cases with `p <= q` are irrelevant for fixed `q`; below, assume `p>q`, which is automatic once `n` is large enough.

Define the two positive truncation anchors

```text
D_{n,q} = sum_{k=0}^J L(n,k)^2,
S_{n,q} = sum_{k=0}^J L(n,k) F_k.
```

Lucas and the reflected binomial congruences give

```text
D_{n,q} = b_j (mod p),
S_{n,q} = b_j (mod p).
```

Consequently every fixed-`q` hit divides both anchors.  This is the strongest immediate two-representation gcd candidate:

```text
R_{n,q} := product_{p in P_{n,q}, p | b_n} p
         divides gcd(D_{n,q}, S_{n,q}).
```

The remainder of the answer proves that the coincidence has only one selective scalar degree of freedom.  All other common divisibility is universal candidate-prime saturation.

## 2. The universal Legendre--Euler transform

Let

```text
Q_n(t) = sum_{k=0}^n L(n,k) t^k.
```

For an arbitrary integer input vector

```text
x = (x_0, x_1, ..., x_J),
```

define

```text
K_{n,m}(c)   = [y^m] Q_n(c+y),
g_m^x(c)     = sum_{i=0}^m binom(m,i) (-c)^(m-i) x_i,
T_{n,J}^x(c) = sum_{m=0}^J K_{n,m}(c) g_m^x(c).
```

At `c=0`, its constant coefficient is the truncated anchor

```text
T_{n,J}^x(0) = S_x := sum_{i=0}^J L(n,i) x_i.
```

The transform is an exact change of basis.  If the polynomial `Q_a` has degree at most `J`, then

```text
sum_{m=0}^J K_{a,m}(c) g_m^x(c)
= sum_{i=0}^J L(a,i) x_i.
```

Indeed, the coefficient of `L(a,k) x_i` on the left is

```text
sum_{m=i}^k binom(k,m) binom(m,i)
                 c^(k-m) (-c)^(m-i)
= binom(k,i) c^(k-i)
  sum_{u=0}^{k-i} binom(k-i,u) (-1)^u
= 1 if k=i, and 0 otherwise.
```

The two exact representations above correspond to the input vectors

```text
x^D_i = L(n,i),
x^F_i = F_i.
```

At the saturated cutoff `J=n`, the transforms are independent of `c` and both equal `b_n`.

## 3. Exact rank-one collapse at every candidate prime

Lucas factorization gives

```text
Q_{qp+r}(t) = Q_q(t^p) Q_r(t) (mod p).
```

Substitute `t=c+y`.  Since `J<p`, the terms of `y`-degree at most `J` can only use the constant term in `y^p` from the high factor.  Hence

```text
K_{n,m}(c) = Q_q(c^p) K_{r,m}(c) (mod p)
for 0 <= m <= J.
```

If `r=p-1-j`, the reflected binomial identities give

```text
Q_r(t) = Q_j(t) (mod p).
```

Since `j<=J`, the low transform is saturated.  Therefore, for every integer input vector `x`, not only for the Apéry inputs,

```text
T_{n,J}^x(c)
= Q_q(c^p) sum_{i=0}^j L(j,i) x_i
= Q_q(c^p) S_x
  (mod p).
```

The last equality uses `Q_q(0)=1`, so the scalar is the constant coefficient of the same polynomial.

This is the load-bearing no-go identity.  It says that the entire coefficient vector of every transform in this class is a scalar multiple of one fixed vector modulo `p`.  The collapse holds for every candidate prime, not merely for the primes satisfying `p|b_j`.

For the direct and Franel inputs the scalar is the same:

```text
T_{n,J}^{x^D}(c) = b_j Q_q(c^p) (mod p),
T_{n,J}^{x^F}(c) = b_j Q_q(c^p) (mod p).
```

Thus a second same-index representation supplies no second modular equation.  It supplies the same scalar equation in the same one-dimensional coefficient line.

## 4. Exact coefficient matrix

Write

```text
T_{n,J}^x(c) = sum_{d=0}^n (sum_{i=0}^J M_{d,i} x_i) c^d.
```

The entries are explicitly

```text
M_{0,i} = L(n,i).
```

For `d>=1`,

```text
M_{d,i}
= (-1)^(J-i) L(n,i+d) binom(i+d,i) binom(d-1,J-i)
```

when

```text
max(0,J+1-d) <= i <= min(J,n-d),
```

and `M_{d,i}=0` otherwise.

To verify this, expand `K_{n,m}` and `g_m^x`.  The coefficient multiplying `L(n,i+d)x_i` is

```text
binom(i+d,i)
  sum_{u=0}^{min(J-i,d)} (-1)^u binom(d,u).
```

For `d=0` this is one.  For `d>=1`, the alternating partial-binomial identity gives

```text
sum_{u=0}^{J-i} (-1)^u binom(d,u)
= (-1)^(J-i) binom(d-1,J-i)
```

exactly in the displayed range, and gives zero outside it.

Because the reduction of `M` has rank one for every candidate prime and because

```text
M_{0,0}=1,
```

one has

```text
M_{d,i} - M_{d,0} M_{0,i} = 0 (mod p)
```

for all candidate primes `p`, all `d>=1`, and all `i>=1`.  Therefore the integer

```text
N_{d,i} := M_{d,i} - M_{d,0}M_{0,i}
```

is divisible by the full squarefree candidate product:

```text
Pi_{n,q} | N_{d,i}.
```

Define the integral residual matrix by

```text
W_{d,i} = N_{d,i}/Pi_{n,q}
for d>=1 and i>=1.
```

## 5. Exact Smith block

Perform the following integral elementary operations:

```text
row_d <- row_d - M_{d,0} row_0       for d>=1,
col_i <- col_i - M_{0,i} col_0       for i>=1.
```

Both operations are unimodular.  They give the exact block decomposition

```text
U M V =
[ 1          0 ]
[ 0   Pi_{n,q} W ].
```

This is not merely a rank computation modulo one prime.  It is an integral Smith block simultaneously for all primes in the fixed-`q` interval.

For one input vector `x`, put

```text
R_d(x) = sum_{i=1}^J W_{d,i} x_i,
G_x    = gcd_{d>=1} R_d(x).
```

Since unimodular row operations preserve coefficient content, one obtains the exact identity

```text
content(T_{n,J}^x)
= gcd(S_x, Pi_{n,q} G_x).
```

For a finite family of input vectors `x^(1),...,x^(m)`, define the common content to be the gcd of every coefficient of every transformed polynomial.  Then

```text
Gamma_X
= gcd(S_{x^(1)}, ..., S_{x^(m)},
      Pi_{n,q} G_X),
```

where

```text
G_X = gcd_{a,d>=1} R_d(x^(a)).
```

This formula is the exact scoped no-go.  The entire lower coefficient block carries `Pi_{n,q}` universally.  The only selective quantities are the scalar anchors `S_x`.

## 6. The normalized residual is a unit at every non-midpoint candidate

The Smith block can be sharpened.  Put

```text
B = J+1.
```

Use rows

```text
d_i = B-i,   1 <= i <= J,
```

and columns `1,...,J`.  The corresponding submatrix of `W` is triangular.  Its diagonal is

```text
W_{B-i,i}
= (-1)^(J-i)
  (L(n,B)/Pi_{n,q}) binom(B,i).
```

Thus

```text
det(W_triangle)
= +/- (L(n,B)/Pi_{n,q})^J
      product_{i=1}^J binom(B,i).
```

For a candidate prime `p`, the two binomial factors in `L(n,B)` have at most one carry each because `n<p^2`.  Since `B>j`, at least one carry occurs.  Both occur exactly at the unique midpoint configuration

```text
2n+1 = (2q+1)p.
```

Hence, away from that one possible prime,

```text
v_p(L(n,B)) = 1,
p does not divide L(n,B)/Pi_{n,q},
p does not divide binom(B,i).
```

Therefore `W_triangle` is invertible modulo every non-midpoint candidate prime.

For the Franel input,

```text
x^F_1 = F_1 = 2,
```

which is a unit for every candidate prime at least seven.  Consequently the vector `W x^F_tail` is not zero modulo any non-midpoint candidate prime.  In particular,

```text
p does not divide G_{x^F}.
```

The same conclusion holds for the common residual of the direct/Franel pair.

It follows that, for every non-midpoint candidate prime,

```text
v_p(content(T_{n,J}^{x^F}))
= 1 if p|b_j,
= 0 if p does not divide b_j.
```

For the common content of the direct and Franel polynomials,

```text
v_p(Gamma_{D,F})
= 1 if p|b_j,
= 0 if p does not divide b_j.
```

At the midpoint prime, if it exists, the same support equivalence remains true but the exponent can exceed one.  There is at most one such prime for each `n`, so it contributes only `O(log n)` to every logarithmic count.

Define the fixed-`q` bad radical by

```text
R_{n,q}
= product_{p in P_{n,q}, p|b_n} p.
```

Then the exact radical statement is

```text
gcd(rad(Gamma_{D,F}), Pi_{n,q}) = R_{n,q}.
```

Away from the possible midpoint, the candidate-prime valuations of `Gamma_{D,F}` are all exactly one.

Thus the primitive common content does not improve the target: its candidate part **is** the full fixed-`q` Apéry radical.

## 7. Why a resultant is even more saturated

For every candidate prime, one has

```text
T_{n,J}^{x^D}(c)
= T_{n,J}^{x^F}(c)
= b_j Q_q(c^p)
  (mod p).
```

Assume `p>2q`, which again excludes only finitely many primes for fixed `q`.  Then `Q_q` has degree `q` modulo `p`, with unit leading and constant coefficients.  Hence the two transformed polynomials have the common factor

```text
Q_q(c^p)
```

of degree `qp` modulo **every** candidate prime, including every non-hit.

If the characteristic-zero resultant is nonzero, the Sylvester matrix has nullity at least `qp` modulo `p`; equivalently,

```text
p^(qp) divides
Res_c(T_{n,J}^{x^D}, T_{n,J}^{x^F}).
```

This is universal saturation.  It does not distinguish `p|b_j` from `p` not dividing `b_j`.

The aggregate universal factor is enormous:

```text
sum_{p in P_{n,q}} qp log p = Theta_q(n^2).
```

Passing to primitive polynomials does not create a free hit carrier.  The exact factorization is

```text
Res(A,B)
= content(A)^(deg B)
  content(B)^(deg A)
  Res(A_prim,B_prim).
```

At a bad prime, the selective divisibility already lies in the two content factors.  By the Smith theorem, their candidate part is exactly `R_{n,q}`.  Dividing those contents out before taking the primitive resultant therefore requires dividing by the very radical one is trying to bound.  A primitive resultant may have additional accidental factors, but no additional candidate-prime divisibility is forced by the two representations.

The same argument applies to finite center grids and evaluation determinants.  Modulo a candidate prime, every evaluated row remains a scalar multiple of the same anchor.  If the chosen value of `Q_q` vanishes, it introduces a non-hit prime; if it is a unit, it contributes only the original anchor equation.

## 8. The sharp automatic carrier exposed by the Smith block

The boundary coefficient

```text
C_{n,q} = L(n,J+1)
```

is divisible by every candidate prime.  Away from the midpoint, each candidate occurs exactly once.  Therefore

```text
gcd(Pi_{n,q}, rad(gcd(S_{n,q}, C_{n,q})))
= R_{n,q}.
```

This is an exact characteristic-zero carrier formula.  It is useful as a support identity, but not as a height theorem.

Let

```text
alpha_q = 1/(2q+1),
lambda(alpha)
= (1+alpha) log(1+alpha)
  -(1-alpha) log(1-alpha)
  -2alpha log(alpha).
```

Stirling's formula gives

```text
log C_{n,q}
= lambda(alpha_q) n + O_q(log n).
```

The constant is strictly positive for every fixed `q`.  Thus this exact carrier has linear, not sublinear, logarithmic height.

The direct and Strehl truncations have the rates

```text
log D_{n,q}
= 2 lambda(alpha_q) n + O_q(log n),

log S_{n,q}
= (lambda(alpha_q) + alpha_q log 8)n
  + O_q(log n).
```

The full Apéry number has

```text
log b_n
= log(17+12sqrt(2)) n + O(log n).
```

For `q=1`, these become

```text
lambda(1/3) = log 4,
log D_{n,1} = (log 16)n + O(log n),
log S_{n,1} = (log 8)n + O(log n),
log C_{n,1} = (log 4)n + O(log n).
```

These are genuine strict savings over the full Apéry rate, but every one is still `c n` with `c>0`.

Even the squarefree product of all candidate primes has positive linear rate.  The prime number theorem gives

```text
log Pi_{n,q}
= theta(n/q)-theta(n/(q+1))+O_q(log n)
= n/(q(q+1)) + o_q(n).
```

Therefore any lower coefficient, boundary determinant, raw resultant, or finite grid whose divisibility is universal over the whole candidate interval is automatically blocked from an `o(n)` estimate.

## 9. Exact smallest concrete saturation example

Take

```text
n=20,
q=1,
J=floor(19/3)=6.
```

The candidate primes and folded indices are

```text
p=11: r=9, j=1,
p=13: r=7, j=5,
p=17: r=3, j=3,
p=19: r=1, j=1.
```

The required small Apéry values are

```text
b_1 = 5,
b_3 = 1445 = 5*17^2,
b_5 = 819005 = 5 (mod 13).
```

Hence the candidate product and bad radical are

```text
Pi_{20,1} = 11*13*17*19 = 46189,
R_{20,1}  = 17.
```

Since

```text
Q_1(t)=1+2t,
```

the two exact transformed representations satisfy

```text
mod 11: T_D(c)=T_F(c)=5(1+2c^11),
mod 13: T_D(c)=T_F(c)=5(1+2c^13),
mod 17: T_D(c)=T_F(c)=0,
mod 19: T_D(c)=T_F(c)=5(1+2c^19).
```

Thus:

- the common coefficient content has candidate-prime support exactly `17`;
- the non-hit primes `11`, `13`, and `19` do not divide that content;
- nevertheless the raw resultant is divisible by all four candidates, because the two polynomials share `1+2c^p` modulo each one;
- the boundary coefficient satisfies

```text
11*13*17*19 divides L(20,7),
```

with each valuation equal to one.

This is an exact counterexample to the hope that the direct/Strehl resultant itself is selective.  It is saturated by three non-hit primes before it sees the one hit prime.

## 10. Scope of the no-go

The exact Smith block is invariant under every unimodular row or column change.  Consequently it covers:

- replacing monomial coefficients by Newton, binomial, or translated coefficient bases;
- changing the center `c` by an integral translation;
- finite integral linear combinations of coefficients;
- constant-term or diagonal re-expansions that amount to an integral change of the same finite coefficient lattice;
- adjoining any finite number of evaluations or moments from this lattice;
- using both the direct and Strehl--Franel inputs, or any finite family of inputs with the same saturated low-digit transform.

A non-unimodular integral postprocessing can only add determinant/index factors.  Modulo each candidate prime the image still has rank at most one, so it cannot create a second independent hit equation.  Clearing rational denominators likewise adds universal factors and cannot improve primitive content.

The theorem does **not** rule out a genuinely different representation whose reduction is not on the line

```text
scalar * Q_q(c^p).
```

For example, an as-yet-unknown modular-parametric construction with a second Frobenius eigenline could evade this class.  The Apéry companion does not presently do so: its Wronskian relation introduces the canonical quotient coordinate and re-imports the original gcd problem.  Finite cusp-unit grids and local Racah pair identities also remain outside the desired cross-prime first-moment mechanism for the reasons already recorded in the project.

## Conclusion

The direct and Strehl--Franel formulas are the correct strongest test of a second same-index characteristic-zero representation.  Their fixed-`q` truncations do compress the individual Archimedean rate, but the exact integral coefficient algebra is

```text
U M V = diag(1, Pi_{n,q} W).
```

The lower block is divisible by every candidate prime.  The sole selective coordinate is the common anchor, and for the direct/Franel pair its primitive candidate content is exactly

```text
R_{n,q}
= product_{n/(q+1)<p<=n/q, p|b_n} p.
```

Raw resultants are universally saturated; primitive contents reproduce the target radical; boundary carriers have positive linear height.  Therefore this entire two-representation class does not prove the required estimate

```text
# { p in (n/(q+1),n/q] : p|b_n }
= o_q(n/log n).
```

A successful fully unconditional route must supply a representation whose reduction has a genuinely second candidate-prime direction, or a cross-prime theorem controlling the canonical anchor quotients.  No same-index binomial/Franel/constant-term rewrite in the Smith class provides that direction.
