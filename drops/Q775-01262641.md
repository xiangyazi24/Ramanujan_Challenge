# Q775: hostile repair of the direct diagonal Apéry expansion

## 1. Setup and the point of the correction

Let
\[
b_m=\sum_{k=0}^m c_k(m)^2,\qquad c_k(m)=\binom mk\binom{m+k}{k}.
\]
The condition \(p\mid b_j\) is a cancellation statement for the full Apéry sum. It is not implied by the terminal summand \(c_j(j)=\binom{2j}{j}\). The computation below keeps the full truncated sum.

Write
\[
n=qp+r,
\]
with fixed \(q\), \(0\le r<p\), and take a direct diagonal point
\[
j=r,\qquad p=(n-j)/q.
\]
Define
\[
D_q(n)=\sum_{k=0}^{J}c_k(n)^2,
\qquad J=\left\lfloor\frac{n-q}{2q+1}\right\rfloor .
\]
The relevant comparison is modulo \(p^2\), because after dividing by \(p\) we need the first jet modulo \(p\).

## 2. First-order expansion of the summands

For every \(k\) with \(k<p\) and \(k\le r\),
\[
\frac{\binom{qp+r}{k}}{\binom rk}
=\prod_{i=0}^{k-1}\left(1+\frac{qp}{r-i}\right),
\]
hence
\[
\binom{qp+r}{k}
\equiv
\binom rk\left(1+qp\sum_{i=0}^{k-1}\frac1{r-i}\right)\pmod {p^2}.
\]

Similarly,
\[
\frac{\binom{qp+r+k}{k}}{\binom{r+k}{k}}
=\prod_{i=1}^{k}\left(1+\frac{qp}{r+i}\right),
\]
so
\[
\binom{qp+r+k}{k}
\equiv
\binom{r+k}{k}\left(1+qp\sum_{i=1}^{k}\frac1{r+i}\right)\pmod {p^2}.
\]

Multiplying gives
\[
c_k(n)
\equiv
c_k(r)\left(1+qpH_k(r)\right)\pmod {p^2},
\]
where
\[
H_k(r)=\sum_{i=0}^{k-1}\frac1{r-i}+\sum_{i=1}^{k}\frac1{r+i}.
\]
Therefore
\[
c_k(n)^2
\equiv
c_k(r)^2(1+2qpH_k(r))\pmod {p^2}.
\]

## 3. Range split: J<r, J=r, J>r

The formula depends on whether the truncated range reaches the terms that vanish modulo p.

### Case I: J<r

All terms satisfy \(k\le J<r<p\). Hence every denominator above is a unit and
\[
D_q(n)/p
\equiv
2q\sum_{k=0}^{J}c_k(r)^2H_k(r)
\pmod p.
\]
This is the generic case.

There is no simplification to zero: the harmonic correction is a weighted Apéry moment.

### Case II: J=r

The last term contributes with the same expansion. Thus
\[
\frac{D_q(n)}p
\equiv
2q\sum_{k=0}^{r}c_k(r)^2H_k(r)
\pmod p.
\]
The condition \(p\mid b_r\) removes only the zeroth-order term
\[
\sum c_k(r)^2,
\]
not the first derivative.

### Case III: J>r

For \(k>r\), the factor \(\binom{qp+r}{k}\) contains the factor
\(qp\) coming from the term \(r-r=0\). Therefore
\[
c_k(n)^2\equiv0\pmod {p^2}.
\]
The apparent carry terms do not contribute after squaring. Consequently the complete formula is still
\[
\boxed{
\frac{D_q(n)}p
\equiv
2q\sum_{k=0}^{r}c_k(r)^2H_k(r)
\pmod p
}
\]
with the upper limit replaced by \(J\) when \(J<r\).

Equivalently:
\[
\boxed{
\frac{D_q(n)}p
\equiv
2q\sum_{k=0}^{\min(J,r)}c_k(r)^2H_k(r)\pmod p.
}
\]

This is the exact first jet.

## 4. Division by the verified boundary unit

The boundary factor is
\[
B_q(n)=\binom nA\binom{n+A}{A},\qquad A=J+1.
\]
When \(2r<p-1\), the already established valuation-one formula is
\[
\frac{B_q(n)}p
\equiv
q(-1)^{A-r-1}\frac{(A-r-1)!(r+A)!}{(A!)^2}\pmod p.
\]
Hence the normalized diagonal quotient is
\[
\boxed{
\frac{D_q(n)/p}{B_q(n)/p}
\equiv
\frac{2q\sum_{k\le\min(J,r)}c_k(r)^2H_k(r)}
{q(-1)^{A-r-1}(A-r-1)!(r+A)!/(A!)^2}
\pmod p .
}
\]
The q cancels. There is no universal vanishing residue.

## 5. Brute-force verifier

The following program checks all admissible direct targets using exact integer arithmetic and modular inverses.

```python
from math import comb


def apery(m):
    return sum(comb(m,k)**2*comb(m+k,k)**2 for k in range(m+1))


def check(qmax=8, pmax=200):
    bad=[]
    simple=[]
    for q in range(1,qmax+1):
        for p in range(q+2,pmax):
            # prime test
            if any(p%d==0 for d in range(2,int(p**0.5)+1)):
                continue
            for r in range(p):
                n=q*p+r
                J=(n-q)//(2*q+1)
                if r>J:
                    continue
                if apery(r)%p:
                    continue
                s=0
                for k in range(J+1):
                    ck=comb(r,k)*comb(r+k,k) if k<=r else 0
                    if k<=r:
                        H=sum(pow(r-i,-1,p) for i in range(k))
                        H+=sum(pow(r+i,-1,p) for i in range(1,k+1))
                        s=(s+ck*ck*H)%p
                lhs=sum((comb(n,k)*comb(n+k,k))**2 for k in range(J+1))//p%p
                rhs=(2*q*s)%p
                if lhs!=rhs:
                    bad.append((q,p,r,J,lhs,rhs))
                if rhs==0:
                    simple.append((q,p,r))
    print('formula failures:', bad[:10])
    print('zero normalized cases:', simple[:20])

check()
```

This is an exhaustive check over the stated finite range and prints failures of any claimed universal zero formula.

## 6. Consequence for carriers

The normalized ratio is not a new characteristic-zero carrier by itself. It introduces the harmonic weighted Apéry moment
\[
\sum c_k(r)^2H_k(r),
\]
which has no known factorization by the boundary primes.

Therefore the repaired conclusion is:

* the direct diagonal expansion is exact;
* the first jet does not vanish merely from \(p\mid b_r\);
* the quotient by \(B_q(n)/p\) is a rational modular expression, not a smaller integer carrier;
* obtaining a smaller carrier would require a new theorem identifying this harmonic Apéry moment with a low-height integer factor.

No such theorem follows from Apéry-Lucas, reflection, or the first-order binomial expansion alone.
