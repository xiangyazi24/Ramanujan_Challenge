# Bombieri--Vinogradov approaches to (HM)_3

## Summary

A Bombieri--Vinogradov theorem in its classical form is not the right tool for this problem. The obstruction is that (HM)_3 is a statement about a very sparse set of individual CRT points, not an average distribution statement for a long sequence. The correct object is a short-interval concentration problem for CRT images of the zero sets.

The strongest realistic route is a hybrid of:

1. trace-function cancellation for the individual zero sets Z_p;
2. additive-combinatorial bounds on CRT configurations;
3. a large-sieve estimate over prime triples.

## (A) Can Bombieri--Vinogradov be applied to 1_{b_n=0 mod p}?

Not directly.

The Bombieri--Vinogradov theorem controls averages of arithmetic progressions:

```
Σ_{q≤Q} max_a |Σ_{n≤x,n≡a(q)} f(n)-expected|
```

for a fixed arithmetic function f.

Here the function depends on p:

```
f_p(n)=1[b_n ≡ 0 (mod p)].
```

Moreover, p is itself one of the moduli defining the condition. There is no single f to which BV applies.

The relevant replacement would be a family estimate of the form

```
Σ_{p∈(X,2X]} |Σ_{n≤N} (1_{Z_p}(n mod p)-|Z_p|/p)| ≪ ...
```

which is closer to a large sieve for trace functions than classical BV.

## (B) Can the Borel--Cantelli heuristic be made rigorous?

The heuristic is correct but currently missing independence.

For one CRT point,

```
Prob(CRT(r1,r2,r3)<X^2)≈X^2/(p1p2p3)≈1/X.
```

If |Z_p| is bounded, each prime triple contributes O(1) points, so the expected contribution is O(1/X).

However, expectation alone does not prove that the total contribution is small. One needs either:

* a second moment bound over prime triples;
* a variance estimate;
* or a sufficiently strong discrepancy theorem.

The missing statement is essentially:

```
Σ_{p1,p2,p3} #(CRT(Zp1,Zp2,Zp3)∩[0,X^2))
```

has the predicted size.

## (C) Is CRT randomness known?

For arbitrary sets Z_p of bounded size: no.

There are counterexamples. A bounded set can be chosen adversarially so that CRT values cluster near zero. Small cardinality does not imply randomness.

What is needed is arithmetic pseudorandomness of the sets Z_p.

For Apéry zeros, possible sources are:

* Mellin sheaf monodromy;
* Deligne bounds for Fourier transforms of 1_{Z_p};
* independence of local Frobenius conditions at distinct primes.

The desired estimate is roughly:

```
|Σ_{r∈Z_p} e(hr/p)| ≪ p^{-δ}|Z_p|
```

for nonzero h, averaged over p. This is much stronger than |Z_p|=O(1).

## (D) Why not enumerate all CRT values?

For one fixed triple, yes, enumeration is trivial. There are at most

```
|Z_p1||Z_p2||Z_p3|=O(1)
```

values.

But the theorem must hold uniformly for all triples of primes. The number of triples is about

```
(X/log X)^3.
```

Checking each finite set does not provide a proof unless one proves a structural theorem preventing exceptional triples.

A single CRT value can be small because of accidental cancellation among the three congruence conditions.

## Better formulation

The right target is not equidistribution of the whole CRT image. The image has only O(1) points.

The right statement is a short interval avoidance estimate:

```
#{(p1,p2,p3,r1,r2,r3): CRT(r1,r2,r3)<X^2}
   ≪ X^2 λ_X^3.
```

This is a sparse large sieve problem.

## What could prevent clustering?

The useful input is that Z_p is not arbitrary. It is defined by

```
b_r ≡ 0 (mod p)
```

where b_r is a hypergeometric trace sequence.

The universal twist gives symmetry

```
r∈Z_p => p-1-r∈Z_p,
```

but symmetry alone does not prevent clustering.

The needed extra property is Fourier decay of the zero indicator. In sheaf language, one wants the indicator of the zero fiber of the trace function to have small nontrivial additive Fourier coefficients.

## Conclusion

Bombieri--Vinogradov alone is unlikely to prove (HM)_3. The closest analogue is a large-sieve theorem for the family of Apéry trace functions. The remaining bottleneck is proving that the bounded-size sets Z_p behave like independent Frobenius zero fibers rather than arbitrary bounded subsets of F_p.

The most promising route is therefore:

```
Sp4 monodromy
      ↓
Fourier decay of zero fibers
      ↓
CRT short-interval large sieve
      ↓
(HM)_3
```
