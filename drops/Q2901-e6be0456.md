# P3.2 exact lemma: all Taylor jets of the restart continuant

## Verdict

The all-jet lemma is **true for every `r` and every Taylor order `j`**.
There is no counterexample.

Put

```text
P(t)=34*t^3+51*t^2+27*t+5,
K_{-1}(X)=0,
K_0(X)=1,
K_1(X)=P(X),
K_{r+1}(X)=P(X+r)K_r(X)-(X+r)^6 K_{r-1}(X),
Lambda_r=lcm(1,...,r),   Lambda_0=1,
U_r(X)=K_r(X)/(X+1)_r^3.
```

Write

```text
U_r(X)=sum_{j>=0} u_{r,j} X^j.
```

Then

```text
THEOREM.
For all r>=0 and j>=0,

    Lambda_r^j * u_{r,j} is an integer.

Equivalently,

    K_r(Lambda_r*T)/(r!)^3 is in Z[T].
```

The proof is not a scan.  It has two exact ingredients:

1. an Apéry WZ identity gives the first Taylor jet explicitly and proves its `Lambda_r` denominator;
2. the continuant concatenation identity, combined with reflection, gives every Laurent principal part of `U_r` at `X=-k`.  A rank induction on those principal parts proves all higher jets.  The only apparent circularity, the pole at `-r`, closes at order two by an exact symmetric convolution identity.

The requested p-adic consequences then follow immediately from the polynomial-coefficient form:

```text
p prime, m=p^a, x=j*m, r<m
    => U_r(x) is p-integral,

and

v_p((x+m)^3 U_m(x)) >= 3*a.
```

For the second formula, if `x=-m` one should read the left side after cancelling the removable factor `(X+m)^3`; for the intended `j>=0` no convention is needed.

# 2. Basic continuant identities

Let `A_r(X)` be the symmetric `r x r` tridiagonal matrix

```text
(A_r)_{ii}     = P(X+i-1),                   1<=i<=r,
(A_r)_{i,i+1}  = (A_r)_{i+1,i} = (X+i)^3,   1<=i<r.
```

Then

```text
K_r(X)=det A_r(X).                            (2.1)
```

This gives three identities we will use repeatedly.

## 2.1 Value at zero

Set

```text
B_r=K_r(0)/(r!)^3.
```

The recurrence for `K_r` becomes

```text
(r+1)^3 B_{r+1}=P(r)B_r-r^3B_{r-1},
B_0=1, B_1=5.
```

Hence

```text
K_r(0)=(r!)^3 b_r,
U_r(0)=b_r in Z.                              (2.2)
```

## 2.2 Reflection

Because

```text
P(-t-1)=-P(t),
```

reversing the tridiagonal matrix gives

```text
A_r(-X-r) = -J A_r(X) J,
```

where `J` is the reversal matrix.  Therefore

```text
K_r(-X-r)=(-1)^r K_r(X).                      (2.3)
```

After dividing by the rising factorial,

```text
X^3 U_r(-X-r)=(X+r)^3 U_r(X).                 (2.4)
```

In particular, near the endpoint pole `X=-r`, with `X=-r+z`,

```text
U_r(-r+z)=-(r-z)^3/z^3 * U_r(-z).             (2.5)
```

## 2.3 Cutting the continuant at one edge

For `1<=k<=r`, with `K_{-1}=0`, the standard continuant concatenation identity is

```text
K_r(X)
 = K_k(X) K_{r-k}(X+k)
   -(X+k)^6 K_{k-1}(X) K_{r-k-1}(X+k+1).     (2.6)
```

Dividing by `(X+1)_r^3` gives the especially clean normalized identity

```text
U_r(X)
 = U_k(X) U_{r-k}(X+k)
   - ((X+k)/(X+k+1))^3
       U_{k-1}(X) U_{r-k-1}(X+k+1).          (2.7)
```

This identity is the engine for every jet of order at least two.

# 3. The first jet: an exact finite WZ formula

The first derivative is the one place where the pole induction is one denominator short.  It has an independent closed formula.

For `k>=0`, define the polynomial-in-`z` hypergeometric term

```text
A_k(z)
 = ( binom(z,k) binom(z+k,k) )^2
 = [ (-z)_k (z+1)_k / (k!)^2 ]^2,
```

and

```text
C_k(z)
 = 4*(2*z+1)*( k*(2*k+1) - (2*z+1)^2 )*A_k(z),
C_{-1}(z)=0.
```

There is the exact rational/polynomial WZ identity

```text
(z+1)^3 A_k(z+1) - P(z) A_k(z) + z^3 A_k(z-1)
 = C_k(z)-C_{k-1}(z).                         (3.1)
```

This is an identity in `Q(z,k)` and hence, after clearing denominators, a polynomial identity.  A one-line verification uses

```text
A_k(z+1)/A_k(z) = ((z+k+1)/(z-k+1))^2,
A_k(z-1)/A_k(z) = ((z-k)/(z+k))^2,
A_{k-1}(z)/A_k(z) = k^4/((z-k+1)^2*(z+k)^2).
```

Now define the finite quantity

```text
g_n^* = sum_{k=0}^n A_k'(n).
```

Differentiate (3.1), set `z=n`, and sum over `0<=k<=n+1`.  The right side telescopes.  Moreover `A_{n+1}(z)` has a double zero at `z=n`, so both `C_{n+1}(n)` and `C_{n+1}'(n)` vanish.  Terms beyond the natural Apéry range therefore contribute neither a value nor a first derivative.

Consequently `g_n^*` satisfies

```text
(n+1)^3 g_{n+1}^* - P(n)g_n^* + n^3 g_{n-1}^*
 = P'(n)b_n
   -3(n+1)^2 b_{n+1}
   -3n^2 b_{n-1}.                             (3.2)
```

On the other hand, differentiating the normalized restart recurrence (1.1) at `X=0` shows that

```text
g_n := U_n'(0)
```

satisfies exactly the same recurrence.  The initial values are

```text
g_0=0,
g_1=P'(0)-3P(0)=27-15=12.
```

The finite WZ expression has the same initials, so uniqueness gives

```text
U_n'(0)=g_n^*.                                (3.3)
```

For `k<=n`, logarithmic differentiation of

```text
binom(z,k)binom(z+k,k)
 = Gamma(z+k+1)/(Gamma(z-k+1)(k!)^2)
```

at the integer `z=n` gives

```text
H_{n+k}-H_{n-k}.
```

Thus we obtain the explicit first-jet formula

```text
boxed:
U_n'(0)
 = 2 * sum_{k=0}^n
       binom(n,k)^2 binom(n+k,k)^2
       * (H_{n+k}-H_{n-k}).                   (3.4)
```

This formula is exact for every `n`, not fitted from data.

# 4. Why the first jet has only the denominator Lambda_n

Let

```text
L=Lambda_n,
a_{n,k}=binom(n,k)^2 binom(n+k,k)^2.
```

We prove the stronger termwise fact

```text
L * a_{n,k}/h is an integer                    (4.1)
```

for every

```text
n-k+1 <= h <= n+k.
```

Fix a prime `ell`, and put `c=v_ell(h)`.

If

```text
ell^c <= n,
```

then `ell^c | L`, so there is nothing to prove.

Suppose instead

```text
ell^c > n.
```

Since `h<=n+k<=2n`, `h` cannot have any additional factor at least `2`; otherwise

```text
h >= 2*ell^c > 2n.
```

Hence

```text
h=ell^c.
```

Also

```text
ell^(c-1) <= h/2 <= n,
```

so `L` already supplies `ell^(c-1)`.

Finally `n<h<=n+k` and `n,k<h`.  In base `ell`, the addition `n+k` crosses the place value `h=ell^c`, hence has a carry into that digit.  Kummer's theorem therefore gives

```text
ell | binom(n+k,k).
```

In fact `ell^2 | a_{n,k}`.  Thus

```text
v_ell(L*a_{n,k}/h) >= (c-1)+2-c >=0.
```

This proves (4.1) for every prime.

Expanding the harmonic difference in (3.4) as

```text
H_{n+k}-H_{n-k}
 = sum_{h=n-k+1}^{n+k} 1/h
```

now gives

```text
boxed:
Lambda_n * U_n'(0) is an integer.             (4.2)
```

This is the only genuinely Apéry/WZ input needed in the higher-jet proof.

# 5. Laurent principal parts at every pole

The rational function `U_r(X)` has finite poles only at

```text
X=-1,-2,...,-r,
```

each of order at most three.  Its value at infinity is an integer: if `ell_r` is the leading coefficient of `K_r`, then

```text
ell_0=1,
ell_1=34,
ell_{r+1}=34*ell_r-ell_{r-1},
```

so `ell_r in Z`.

Therefore there is a unique partial-fraction expansion

```text
U_r(X)
 = ell_r
   + sum_{k=1}^r sum_{s=1}^3
       alpha_{r,k,s} * (k/(X+k))^s.           (5.1)
```

We now compute every `alpha` from smaller restart blocks.

Fix `k` and put `X=-k+z`.  In (2.7), the second term is `O(z^3)`: its explicit prefactor is `(z/(z+1))^3`, and the two remaining normalized continuants are regular at `z=0`.

For the first term, reflection (2.4) gives

```text
U_k(-k+z)=-(k-z)^3/z^3 * U_k(-z).
```

Hence, if

```text
H_{r,k}(z)
 := U_k(-z) U_{r-k}(z)
  = h_0+h_1*z+h_2*z^2+...,
```

then the entire principal part of `U_r` at `-k` is

```text
-(k-z)^3/z^3 * H_{r,k}(z).                    (5.2)
```

Comparing with (5.1) yields the exact formulas

```text
alpha_{r,k,3} = -h_0,
alpha_{r,k,2} =  3*h_0 - k*h_1,
alpha_{r,k,1} = -3*h_0 + 3*k*h_1 - k^2*h_2.  (5.3)
```

Nothing here is asymptotic.

# 6. The quadratic jet closes the endpoint circularity

We now induct on `r`.  Assume the theorem for every smaller rank.
The zeroth jet was proved in (2.2), and the first jet was proved for all ranks in Section 4.

Let

```text
u_{r,2}=[X^2]U_r(X).
```

The coefficient of `X^2` in a single pole block of (5.1) is

```text
( alpha_1 + 3*alpha_2 + 6*alpha_3 )/k^2.
```

Using (5.3), all lower terms cancel and this becomes simply

```text
-h_2.                                         (6.1)
```

Since the constant `ell_r` contributes no positive Taylor degree,

```text
u_{r,2} = -sum_{k=1}^r h_{r,k,2}.             (6.2)
```

At the endpoint `k=r`,

```text
H_{r,r}(z)=U_r(-z),
```

so

```text
h_{r,r,2}=u_{r,2}.
```

Therefore

```text
boxed:
2*u_{r,2}
 = -sum_{k=1}^{r-1} h_{r,k,2}.               (6.3)
```

Moreover

```text
h_{r,k,2}
 = b_{r-k} u_{k,2}
   + b_k u_{r-k,2}
   - u_{k,1}u_{r-k,1}.                        (6.4)
```

This is symmetric under `k <-> r-k`.

Every term in (6.4) has denominator dividing `Lambda_r^2` by the induction hypothesis, because

```text
Lambda_k | Lambda_r,
Lambda_{r-k} | Lambda_r.
```

If `r` is odd, the right side of (6.3) is a sum of paired equal terms, hence the factor `2` cancels integrally.

If `r=2q` is even, only `k=q` is unpaired.  Its contribution is

```text
h_{2q,q,2}=2*b_q*u_{q,2}-u_{q,1}^2.
```

Thus

```text
u_{2q,2}
 = -(paired sum)
   -b_q*u_{q,2}
   +u_{q,1}^2/2.                              (6.5)
```

The first two terms have the required denominator.  For the last term use

```text
v_2(Lambda_{2q})=v_2(Lambda_q)+1,
```

so `Lambda_{2q}/Lambda_q` is even.  Therefore

```text
Lambda_{2q}^2 * u_{q,1}^2/2
 = ((Lambda_{2q}/Lambda_q)^2/2)
   * (Lambda_q*u_{q,1})^2
```

is an integer.

We have proved

```text
boxed:
Lambda_r^2 * [X^2]U_r(X) is an integer.       (6.6)
```

This is the exact closure of the endpoint-pole circularity.

# 7. All jets of order at least three

Fix a prime `p` and write

```text
e=v_p(Lambda_r),
t=v_p(k),  1<=k<=r.
```

Thus `0<=t<=e`.

For `k<r`, the induction hypothesis gives

```text
v_p(h_0) >= 0,
v_p(h_1) >= -e,
v_p(h_2) >= -2e.
```

For `k=r`, exactly the same bounds now hold by Sections 2, 4, and 6, because

```text
H_{r,r}(z)=U_r(-z).
```

The formulas (5.3) therefore imply, uniformly for every `1<=k<=r`,

```text
v_p(alpha_{r,k,3}) >= 0,
v_p(alpha_{r,k,2}) >= -(e-t),
v_p(alpha_{r,k,1}) >= -2*(e-t).              (7.1)
```

Now

```text
(k/(X+k))^s=(1+X/k)^(-s),
```

and

```text
[X^j](1+X/k)^(-s)
 = (-1)^j * binom(s+j-1,j) * k^(-j).         (7.2)
```

The binomial coefficient is integral.  Hence the three possible pole contributions have p-adic valuations at least

```text
s=3:  -j*t,

s=2:  -(e-t)-j*t
      = -e-(j-1)t,

s=1:  -2(e-t)-j*t
      = -2e-(j-2)t.
```

For `j>=3` (indeed, for the last line already for `j>=2`) these are all at least `-j*e`, because `t<=e`.

Thus every individual pole contribution to `[X^j]U_r` has denominator dividing the p-part of `Lambda_r^j`.  The constant term at infinity contributes nothing when `j>0`.  Summing over the finitely many poles gives

```text
v_p(u_{r,j}) >= -j*v_p(Lambda_r)
```

for every prime `p` and every `j>=3`.

Together with Sections 2, 4, and 6 this completes the induction:

```text
boxed:
Lambda_r^j [X^j]U_r(X) in Z
for every r,j>=0.                             (7.3)
```

# 8. Equivalence with the coefficient-content statement

The Taylor statement is exactly equivalent to the divisibility formulation in the question.

Indeed,

```text
U_r(Lambda_r*T) in Z[[T]]                    (8.1)
```

is precisely (7.3).  Also

```text
(X+1)_r^3 |_{X=Lambda_r*T}
 = (r!)^3 * product_{i=1}^r
     (1 + (Lambda_r/i)*T)^3.                 (8.2)
```

Every `Lambda_r/i` is an integer, so the product in (8.2) belongs to `Z[T]`.  Therefore

```text
K_r(Lambda_r*T)/(r!)^3 in Z[[T]].
```

The left side is a polynomial, hence

```text
boxed:
K_r(Lambda_r*T)/(r!)^3 in Z[T].              (8.3)
```

Equivalently, `(r!)^3` divides every coefficient of `K_r(Lambda_r*T)`.

Conversely, if (8.3) holds, divide by the polynomial

```text
product_{i=1}^r (1+(Lambda_r/i)T)^3,
```

whose constant term is `1`.  Its inverse lies in `Z[[T]]`, recovering (8.1).  So the two statements really are equivalent, not merely implications in one direction.

A useful coefficientwise p-adic restatement is the following.  If

```text
K_r(X)=sum_d c_{r,d} X^d,
e_r=v_p(Lambda_r),
```

then (8.3) says

```text
boxed:
v_p(c_{r,d}) + d*e_r >= 3*v_p(r!)            (8.4)
```

for every `d`.

# 9. The requested p-power evaluations

Let

```text
m=p^a,   a>=1,
x=j*m
```

with integral `j`.

## 9.1 `r<m`: p-integrality of `U_r(x)`

For `r<m`,

```text
e_r=v_p(Lambda_r) <= a-1.
```

From (8.4), and `v_p(x)>=a`, every monomial of `K_r(x)` satisfies

```text
v_p(c_{r,d}x^d)
 >= 3*v_p(r!) + d*(a-e_r)
 >= 3*v_p(r!).                                (9.1)
```

Hence

```text
v_p(K_r(x)) >= 3*v_p(r!).                     (9.2)
```

For every `1<=i<=r<m`, we have `v_p(i)<a<=v_p(x)`, so the two valuations are unequal and

```text
v_p(x+i)=v_p(i).
```

Therefore

```text
v_p((x+1)_r^3)=3*v_p(r!).                    (9.3)
```

Combining (9.2) and (9.3),

```text
boxed:
v_p(U_r(x)) >= 0,  r<m.                      (9.4)
```

## 9.2 The endpoint `r=m`

Now

```text
v_p(Lambda_m)=a.
```

Equation (8.4) and `v_p(x)>=a` give

```text
v_p(K_m(x)) >= 3*v_p(m!).                     (9.5)
```

After cancelling the endpoint denominator,

```text
(x+m)^3 U_m(x)
 = K_m(x) / product_{i=1}^{m-1}(x+i)^3.       (9.6)
```

For `i<m`, again `v_p(x+i)=v_p(i)`.  Hence

```text
v_p(product_{i=1}^{m-1}(x+i)^3)
 =3*v_p((m-1)!)
 =3*(v_p(m!)-a).                              (9.7)
```

Subtracting (9.7) from (9.5) gives exactly

```text
boxed:
v_p((x+m)^3 U_m(x)) >= 3*a.                  (9.8)
```

This is the requested endpoint valuation, with no finite-scan input.

# 10. Exact checker (diagnostic only)

The proof above is algebraic.  The following Wolfram Language code was run only as a regression guard for signs and indexing.  In particular it symbolically verifies the WZ rational identity, then checks the first few exact jets and the quadratic convolution; none of those finite ranges is used in the proof.

```mathematica
ClearAll["Global`*"];
P[t_] := 34 t^3 + 51 t^2 + 27 t + 5;

(* WZ identity after division by A_k(z) *)
rr = Together[
  (z + 1)^3*((z + k + 1)/(z - k + 1))^2
  - P[z]
  + z^3*((z - k)/(z + k))^2
];
ck[k_] := 4 (2 z + 1) (k (2 k + 1) - (2 z + 1)^2);
prev = Together[k^4/((z - k + 1)^2 (z + k)^2)];
Assert[FullSimplify[Together[rr - (ck[k] - ck[k - 1]*prev)]] === 0];

K[-1] = 0;
K[0] = 1;
K[1] = P[X];
Do[
  K[r + 1] = Expand[P[X + r] K[r] - (X + r)^6 K[r - 1]],
  {r, 1, 12}
];
U[r_] := Together[K[r]/Product[X + i, {i, 1, r}]^3];

b[n_] := Sum[Binomial[n, q]^2 Binomial[n + q, q]^2, {q, 0, n}];
gform[n_] := 2 Sum[
  Binomial[n, q]^2 Binomial[n + q, q]^2
   (HarmonicNumber[n + q] - HarmonicNumber[n - q]),
  {q, 0, n}
];

Do[
  L = LCM @@ Range[1, Max[1, r]];
  ser = Normal@Series[U[r], {X, 0, 3}];
  Assert[And @@ Table[IntegerQ[Together[L^j Coefficient[ser, X, j]]],
                      {j, 0, 3}]];
  Assert[Together[Coefficient[ser, X, 1] - gform[r]] === 0],
  {r, 1, 12}
];

u0[s_] := Coefficient[Normal@Series[U[s], {X, 0, 2}], X, 0];
u1[s_] := Coefficient[Normal@Series[U[s], {X, 0, 2}], X, 1];
u2[s_] := Coefficient[Normal@Series[U[s], {X, 0, 2}], X, 2];

Do[
  rhs = -Sum[
    u2[k] u0[r - k] + u0[k] u2[r - k] - u1[k] u1[r - k],
    {k, 1, r - 1}
  ];
  Assert[Together[2 u2[r] - rhs] === 0],
  {r, 2, 10}
];

Print["PASS"];
```

The exact run returned the symbolic WZ identity as `True`, all tested jet/integrality assertions as `True`, and all quadratic-convolution assertions as `True`.

# 11. What actually made the theorem work

There are two structural points worth preserving for later P3.2 use.

First, the `Lambda_r` denominator is not coming from a generic rational-recurrence denominator estimate.  The first jet is sharper because every dangerous harmonic denominator `h` with `n<h<=2n` must be a prime power, and crossing that prime-power boundary forces a Kummer carry in `binom(n+k,k)`.  That is the Apéry hypergeometric input.

Second, after the first jet, one never differentiates the recurrence repeatedly.  The local continuant cut (2.7) makes every pole principal part a product of **smaller normalized continuants**.  The loss at a pole `-k` is measured by `v_p(k)`, while the lower-rank jet loss is measured by `v_p(Lambda_r)`; the factor `k` in (5.3) exactly compensates the difference.  This is why the induction closes at every order.

So the theorem is stronger than the finite observations: the entire Taylor tower is controlled uniformly, and the two p-power evaluation statements are unconditional consequences.
