## 1. Exact dyadic incidence ledger, with occurrence multiplicity

Put

\[
L=\log T,
\qquad
P_0=\frac{T}{L},
\qquad
R\asymp \frac{T^{2/5}}{L^{6/5}\Omega(T)},
\qquad
M_{\rm crit}=R P_0^2
\asymp \frac{T^{12/5}}{L^{16/5}\Omega(T)}.
\tag{1.1}
\]

Fix one residual dyadic cell, one sign, and one surviving plus branch.  Let
\(\mathscr O_K\) be the **multiset of literal selected occurrences** in the cell for which

\[
K\le k(o)<2K,
\tag{1.2}
\]

where \(k(o)\) is the number of surviving lower-prime witnesses of occurrence \(o\).  If the source has several occurrence labels projecting to the same actual upper state, they remain separate copies in \(\mathscr O_K\); no support collapse is made.

\tag{1.4}

\tag{1.5}

\tag{1.6}

### Lemma 1.1 — the sharp generic inverse ledger

Assume \(K\ge4\).  Then:

1. Degree, incidence, and pair mass are comparable:

   \qquad

   \tag{1.7}
   \]

2. A popular lower pair exists:
   \[
   \boxed{
   \max_{p<p'}C_2(p,p')
   \ge \frac{E_K}{\binom P2}.}
   \tag{1.8}
   \]

3. More generally, for \(s\ge2\), let
   \[
   C_s(S):=\#\{o\in\mathscr O_K:S\subseteq S(o)\},
   \qquad |S|=s.
   \]
   If \(K\ge2s\), then
   \[
   \boxed{
   \max_{|S|=s}C_s(S)
   \gg_s \frac{E_KK^{s-2}}{P^s}.}
   \tag{1.9}
   \]

4. If the admissible differences \(\Delta=p'-p\) lie in an integer interval
   \(\mathcal D\) of length \(D\), then, with
   \[
   r(\Delta):=\sum_{p:p,p+\Delta\in\mathcal P}C_2(p,p+\Delta),

   \[
   \boxed{
   \max_{\Delta\in\mathcal D}r(\Delta)\ge \frac{E_K}{D}.}
   \tag{1.10}
   \]

5. Let \(\pi(o)=(n(o),N(o))\) be the actual lifted state and let
   \[
   \mu:=\max_{p<p',x}

   The popular pair in (1.8) supports at least
   \[
   \frac{E_K}{\mu\binom P2}
   \tag{1.12}

\[
\binom{k}{2}=\frac{k(k-1)}2
\in\left[\frac{K-1}{2}k,\,Kk\right),

which gives (1.7).  Identity (1.6) followed by averaging over the
\(\binom P2\) lower pairs proves (1.8).

For (1.9), double-count \((o,S)\) with \(S\subseteq S(o)\), \(|S|=s\):

\[
\sum_{|S|=s}C_s(S)=\sum_o\binom{|S(o)|}{s}.
\tag{1.13}

For \(k\in[K,2K)\) and \(K\ge2s\),

\[
\binom{k}{s}\gg_s K^{s-2}\binom{k}{2}.

Divide (1.13) by \(\binom Ps\ll_sP^s\).  Equation (1.10) is the same averaging after grouping (1.6) by \(\Delta\).  Finally, every projected state has at most \(\mu\) occurrence copies, proving (1.12).  ∎

## 3. Why Balog--Szemerédi--Freiman does not apply

The critical energy is

\[
E_K=\sum_o\binom{|S(o)|}{2}.
\tag{3.1}
\]

This is a factorial degree moment.  It is **not** additive energy:

\[
E_+(A)=\#\{a_1+a_2=a_3+a_4:a_i\in A\}.
\tag{3.2}
\]

No term in (3.1) records an equation among four lower primes.  Grouping by
\(\Delta\) gives only the first moment of a difference histogram across different occurrences.  BSG would require many additive quadruples inside one fixed set and one fixed ambient group; neither is supplied.

There is a second obstruction.  The actual zero sets live in varying fields
\(\mathbf F_p\).  The integer lifts in (2.4)--(2.5) place common values on one integer line only after all no-wrap and branch masks have been imposed.  They do not identify the recurrence transfers, continuant polynomials, or projective Apéry orbits across \(\mathbf F_p\) and \(\mathbf F_{p'}\).  A Freiman model of the lower-prime labels would therefore not preserve the arithmetic predicates being counted.

The following elementary lemma shows that even low doubling of the lower-prime witness sets is unavailable.

### Lemma 3.1 — maximal doubling is compatible with the degree ledger

Let \(S\subset\mathbf Z\) have \(|S|=P\), and let \(2\le K\le P\).  There exists \(A\subset S\), \(|A|=K\), such that

\[
E_+(A)\ll K^2+\frac{K^4}{P}.
\tag{3.3}
\]

Consequently

\[
|A-A|\gg \frac{K^4}{K^2+K^4/P}
\gg \min(K^2,P).
\tag{3.4}
\]

In particular, if \(K^2=o(P)\), then \(|A-A|\gg K^2\), the maximal order.

#### Proof

Choose a uniform random \(K\)-subset of \(S\).  The trivial additive quadruples contribute \(O(K^2)\).  Quadruples with exactly three distinct entries contribute \(O(K^3/P)\), and those with four distinct entries contribute at most

\[
P^3\left(\frac KP\right)^4=\frac{K^4}{P},
\]

because three entries determine the fourth.  Since \(K^3/P\le K^2\), the expected energy is bounded by (3.3), so some subset attains it.  Cauchy--Schwarz applied to the difference representation function gives (3.4).  ∎

At \(K=K_0\) and \(P\asymp P_0\),

\[
\frac{K_0^2}{P_0}\asymp \frac{T^{-1/5}}L=o(1).
\tag{3.5}
\]

Thus a critical block can use lower-prime sets with essentially maximal doubling.  Such a set cannot lie in any fixed-rank generalized arithmetic progression of size \(O(K)\), because every such progression has difference set \(O_r(K)\).  Low rank and low doubling are not inverse consequences of C4 pair mass.

## 4. Sharp pure-incidence countermodel: critical mass with no repeated triple

The preceding exponent failure is not merely a weakness of averaging.  There is an explicit block design at the same scales.

Take

\[
P\asymp P_0,
\qquad
K=K_0,
\qquad
U\asymp \frac{M_{\rm crit}}{K^2}.
\tag{4.1}
\]

Choose a prime power \(\ell\asymp P/K\), and choose
\(D\subset\mathbf F_\ell\) with \(|D|=K\).  The abstract lower-prime vertex set is

\[
V=D\times\mathbf F_\ell,
\qquad |V|=K\ell\asymp P.
\tag{4.2}
\]

For every quadratic polynomial

\[
f_{\alpha,\beta,\gamma}(x)
=\alpha x^2+\beta x+\gamma
\qquad(\alpha,\beta,\gamma\in\mathbf F_\ell),
\]

define the block

\[
B_f:=\{(x,f(x)):x\in D\}.
\tag{4.3}
\]

There are \(\ell^3\) blocks, each of size \(K\), and two distinct blocks intersect in at most two vertices because their difference is a nonzero polynomial of degree at most two.  Equivalently,

\[
\boxed{\text{every three distinct vertices lie in at most one block}.}
\tag{4.4}
\]

The number of blocks required for critical pair mass is feasible because

\[
\frac{U}{\ell^3}
\asymp
\frac{(R P^2/K^2)}{P^3/K^3}
=\frac{RK}{P}
\asymp
\frac{T^{-1/5}}{L^{6/5}\Omega(T)}=o(1).
\tag{4.5}
\]

Select \(U\) blocks.  Then

\[
\sum_f\binom{|B_f|}{2}
\asymp UK^2
\asymp M_{\rm crit},
\tag{4.6}
\]

but every triple codegree is at most one.  Therefore the incidence graph contains no \(K_{3,2}\), and hence no larger complete bipartite configuration with at least three lower-prime vertices and at least two occurrence vertices.

The pair-codegree scale can also be made sharp.  Select each quadratic independently with probability

\[
\theta\asymp U/\ell^3.
\]

Two vertices in distinct \(x\)-columns lie on exactly \(\ell\) quadratics, so their expected codegree is

\[
\theta\ell
\asymp \frac{U}{\ell^2}
\asymp R.
\tag{4.7}
\]

Since \(R\gg\log P\), Chernoff and a union bound over \(O(P^2)\) pairs give a realization with every pair codegree \(O(R)\), while the total pair mass remains \(\asymp M_{\rm crit}\).  Thus (1.15) is sharp up to constants.

To impose the retained far-separation cell, partition

\[
D=D_{\rm left}\sqcup D_{\rm right},
\qquad |D_{\rm left}|,|D_{\rm right}|\asymp K.
\]

Label vertices in the left columns bijectively by actual primes in one lower-prime interval and vertices in the right columns by primes in a separated interval.  Every block then contains \(\asymp K\) primes in each cloud and therefore \(\asymp K^2\) counted cross-cloud pairs, all with \(\Delta\) in the prescribed far dyadic cell.  The uncounted within-cloud pairs may be discarded.

Finally, choose the prime labels randomly inside the two clouds.  For each block, Lemma 3.1's calculation gives expected additive energy \(O(K^2+K^4/P)=O(K^2)\).  By Markov, a positive proportion of the \(\ell^3\) blocks have \(|B_f-B_f|\gg K^2\).  Because \(U=o(\ell^3)\), one can select the needed \(U\) blocks from this good family and retain the pair-codegree bounds after a further random thinning.

This construction is deliberately only an incidence countermodel; it does not claim to realize Apéry zeros.  Its purpose is exact: **no theorem using only dyadic degrees, total pair mass, far separation, and occurrence multiplicity can force repeated triples, low doubling, or low-rank progression structure.**

### 5.3 The banked zero-set constraints can all be imposed

The following elementary random-cell construction is sufficient.

Close each lower zero set under

\tag{5.22}

The new differences are old differences or reflected sum representations, so (5.20) remains true up to constants.  Randomly avoid the fixed midpoint and the finitely many offset strips.  Reflection changes all cardinalities only by a constant and selected incidences remain in the original one-branch cell.

def is_prime(n: int) -> bool:
    if n < 2:
        return False
    if n % 2 == 0:
        return n == 2
    d = 3
    while d <= isqrt(n):
        if n % d == 0:
            return False
        d += 2
    return True


def reflection_close(p: int, values: set[int]) -> set[int]:
    return values | {p - 1 - x for x in values}

    xs = sorted(values)
    out: Counter[int] = Counter()
    for i, x in enumerate(xs):
        for y in xs[i + 1:]:
            out[y - x] += 1
    return out

    for h, multiplicity in counts.items():
