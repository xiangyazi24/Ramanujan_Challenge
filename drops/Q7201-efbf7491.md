# Q7201 (rc5): Deterministic separated near/far bridge energy audit

## Summary

The deterministic combinatorial analysis does give a sharp near-bridge bound, but it does **not** give any general \(K/H\) saving for genuinely long bridges. The strongest unconditional inequality from the allowed facts is

\[
\sum_{X<p\le 2X}E_p^{\rm near}(K)\ll H^2K^2,
\]

for bridges \(G\le K\). With \(H\asymp X^{1/2}\), choosing

\[
K=H/\sqrt{\log X}
\]

already gives the target \(X^2/\log X\).

For the remaining range \(G>K\), no deterministic \(K/H\) improvement follows from sliding-window structure, reflection quotienting, mass bounds, or pair caps alone.

## 1. Near bridge bound

A quotient chain is a filtered sliding window of four consecutive occurrences of one projective state. For an ordered separated pair choose the canonical orientation with first interval before the second:

\[
\gamma=(x,\ldots,x+s),\qquad
\delta=(x+s+G,\ldots,x+s+G+t).
\]

Consecutiveness implies that the tuple

\[
(p,x,s,G)
\]

is injective: once \(x\) and the bridge start \(x+s+G\) are fixed, the second window is determined by the occurrence list. This is the crucial point where actual Apéry orbits differ from arbitrary window systems.

The pair contributes a common root of

\[
N_s(x)=0,\qquad N_G(x+s)=0.
\]

Let

\[
R_{s,G}=\operatorname{Res}_x(N_s(x),N_G(x+s)).
\]

The complex root strips of the two continuants are disjoint, hence

\[
R_{s,G}\neq0.
\]

Smith normal form gives the common-root multiplicity bound

\[
\nu_p(s,G)\le v_p(R_{s,G}).
\]

The continuant height estimate gives

\[
\log |R_{s,G}|\ll sG\log H.
\]

Summing valuations over primes therefore yields

\[
\begin{aligned}
\sum_{X<p\le2X}E_p^{\rm near}(K)
&\ll \frac1{\log X}\sum_{s\le H}\sum_{G\le K}\log|R_{s,G}|\\
&\ll H^2K^2.
\end{aligned}
\]

This is the strongest available deterministic estimate for the near range.

## 2. Why the false far-partner estimate fails

The claim

\[
\text{far partners per chain}\le p/K
\]

is false for clustered occurrence lists.

Construct an artificial state occurrence list with blocks of density one:

\[
B_i=[iM,iM+M/2]
\]

separated by gaps larger than \(H\). Every point in a block participates in many four-consecutive windows, but every window in one block is farther than \(K\) from every window in another block.

The number of far partners of a chain is then proportional to the number of windows in the other dense blocks, not the number of length-\(K\) gaps. Hence distance alone does not control partner count.

The example is not an Apéry orbit, but it proves that sliding-window combinatorics alone cannot imply the desired saving.

## 3. Dyadic packing and Cauchy-Schwarz

Let \(M_q\) be the number of selected chains in state \(q\). The full return-energy input gives

\[
\sum_q M_q^2\ll p^{3/2+o(1)}.
\]

For bridges in a dyadic interval

\[
2^jK<G\le2^{j+1}K,
\]

a trivial packing bound only gives

\[
E_j\le \sum_q M_q^2,
\]

so

\[
E_j\ll p^{3/2+o(1)}.
\]

There is no factor \(K/2^j\) because the state occurrences may cluster. Summing over dyadic ranges gives only

\[
E_{G>K}\ll p^{3/2+o(1)}\log(p/K),
\]

which is the original full-energy bound and contains no \(K/H\) gain.

## 4. Pair-cap bounds do not improve this

Pair caps constrain fixed gaps:

\[
A_Z(h)\le C h
\]

or related bounds for return pairs. They control the number of pairs with a prescribed short separation, but separated energy fixes the state equality and leaves the bridge free. The long bridge parameter remains.

Therefore pair caps cannot replace a cocycle nonconcentration theorem.

## 5. Strongest valid deterministic statement

Combining the unconditional near estimate and the trivial far energy gives

\[
\boxed{
\sum_{X<p\le2X}E_p^{\rm sep}
\ll
\sum_{X<p\le2X}H^2K^2
+
\sum_{X<p\le2X}p^{3/2+o(1)}\mathbf 1_{G>K}
}
\]

or per prime

\[
E_p^{\rm sep}(K)
\ll H^2K^2+p^{3/2+o(1)}.
\]

No deterministic \(K/H\) improvement survives for the long-bridge term.

## 6. Remaining required arithmetic input

The missing theorem is an Apéry-specific nonconcentration statement:

For \(H\le p^{1/2}\),

\[
\sum_q\#\{(\gamma,\delta):q(\gamma)=q(\delta),\
\operatorname{bridge}(\gamma,\delta)>H\}\ll p^{1+o(1)}.
\]

This uses the actual cocycle

\[
\pi_{n+1}=A(n)\pi_n
\]

and cannot be derived from arbitrary occurrence lists.

Thus the deterministic optimization is complete: near bridges are solved by resultants, while far bridges require genuinely arithmetic Apéry orbit nonconcentration.
