# Exact real-variable certificate

Put

```text
Z = zeta(3),
L = log 2.
```

The proof has two independent branches.

```text
real Li2/Li3 calculus
        |
        v
auxiliary Euler integral E
        |
        v
R = integral Li2(t)/(2-t)
        |
        v
J = integral log(x)log(1+x)/(1-x)

absolutely convergent cubic double sum
        |
        v
M = integral x^2 log(x)log(1+x)/(1-x^3)

J and M
   |
   v
I = J - 3 M = -(7/36) Z.
```

The exact values are

```text
E = Z - (pi^2/12)L,
R = (pi^2/4)L - Z,
J = Z - (pi^2/4)L,
M = (43/108)Z - (pi^2/12)L.
```

The last cancellation is then

```text
I
 = [Z - (pi^2/4)L]
   - 3[(43/108)Z - (pi^2/12)L]
 = -(7/36)Z.
```

Everything below is over real arguments.  No roots of unity, Clausen values,
Gamma functions, polygamma functions, or analytic continuation outside the real
unit interval occur.

# 1. Basic real polylogarithm facts

For `0 < x < 1`, use

```text
Li2'(x) = -log(1-x)/x,
Li3'(x) = Li2(x)/x.
```

The endpoint values used are

```text
Li2(0)   = 0,
Li2(1)   = pi^2/6,
Li2(1/2) = pi^2/12 - L^2/2,

Li3(0)   = 0,
Li3(1)   = Z,
Li3(-1)  = -(3/4)Z,
Li3(1/2) = (7/8)Z - (pi^2/12)L + L^3/6.
```

The following primitive is repeatedly useful:

```text
Q(x) = Li3(x) - log(x) Li2(x).
```

Indeed,

```text
Q'(x)
 = Li2(x)/x
   - [Li2(x)/x - log(x)log(1-x)/x]
 = log(x)log(1-x)/x.                              (1.1)
```

Moreover `Q(x) -> 0` as `x -> 0+`, while `Q(1)=Z`.  Therefore

```text
integral_0^1 log(x)log(1-x)/x dx = Z.             (1.2)
```

After `u=1-x`, the same value is

```text
integral_0^1 log(x)log(1-x)/(1-x) dx = Z.         (1.3)
```

Thus the ordinary radial weight-three integral is itself a two-line real FTC
lemma; it need not be imported from the target calculation.

# 2. An independent auxiliary Euler integral

Define

```text
E = integral_0^1 log(1-t)log(1-t/2)/t dt.         (2.1)
```

We prove

```text
E = Z - (pi^2/12)L.                               (2.2)
```

This proof contains no occurrence of `R`, `J`, `M`, or `I`.

## 2.1. Möbius substitution

Set

```text
t = 2x/(1+x).
```

It maps `[0,1]` increasingly onto `[0,1]`, and

```text
dt/t = dx/[x(1+x)],
1-t   = (1-x)/(1+x),
1-t/2 = 1/(1+x).
```

Hence, for `0 < x < 1`,

```text
log(1-t)   = log(1-x)-log(1+x),
log(1-t/2) = -log(1+x).
```

Consequently

```text
E = integral_0^1
      [-log(1-x)log(1+x)+log(1+x)^2]/[x(1+x)] dx.
                                                               (2.3)
```

Introduce

```text
A = integral_0^1 log(1-x)log(1+x)/x dx,
B = integral_0^1 log(1-x)log(1+x)/(1+x) dx,
C = integral_0^1 log(1+x)^2/x dx,
D = integral_0^1 log(1+x)^2/(1+x) dx.
```

Since

```text
1/[x(1+x)] = 1/x - 1/(1+x),
```

(2.3) is exactly

```text
E = -A + B + C - D.                               (2.4)
```

For a Lean proof, one may apply the substitution first on
`[eps,1-eps]` and let `eps -> 0+`.  All four kernels in (2.4) are absolutely
integrable.  Alternatively use the interval-integral change-of-variables theorem
with the already established `IntervalIntegrable` lemmas and prove the pulled-back
identity almost everywhere on `Ioo 0 1`.

## 2.2. The two log-square integrals

The existing real theorem gives

```text
C = Z/4.                                           (2.5)
```

For `D`, the primitive is elementary:

```text
(d/dx) [(1/3)log(1+x)^3] = log(1+x)^2/(1+x).
```

Thus

```text
D = L^3/3.                                         (2.6)
```

## 2.3. Evaluation of `A`

First prove

```text
Kminus := integral_0^1 log(1-x)^2/x dx = 2Z.       (2.7)
```

Use

```text
P(x)=log(x)log(1-x)^2.
```

For `0 < x < 1`,

```text
P'(x)
 = log(1-x)^2/x
   - 2log(x)log(1-x)/(1-x).                        (2.8)
```

Both endpoint limits of `P` are zero.  At zero this follows from
`log(1-x)=O(x)`; at one it follows from `log x=O(1-x)` and
`(1-x)log(1-x)^2 -> 0`.  Integrating (2.8) and using (1.3) proves (2.7).

Now substitute `u=x^2`:

```text
integral_0^1 log(1-x^2)^2/x dx
 = (1/2) integral_0^1 log(1-u)^2/u du
 = Z.                                               (2.9)
```

Since `log(1-x^2)=log(1-x)+log(1+x)` on `(0,1)`,

```text
2log(1-x)log(1+x)
 = log(1-x^2)^2-log(1-x)^2-log(1+x)^2.             (2.10)
```

Integrating (2.10) divided by `x` and using (2.5), (2.7), and
(2.9),

```text
2A = Z-2Z-Z/4 = -(5/4)Z,
A  = -(5/8)Z.                                      (2.11)
```

The sign is forced: the integrand defining `A` is negative.

## 2.4. Evaluation of `B`

Use

```text
y=(1-x)/2,
x=1-2y.
```

The reversal of the bounds cancels the sign from `dx=-2dy`, and

```text
1-x=2y,
1+x=2(1-y).
```

Therefore

```text
B = integral_0^(1/2)
      (L+log y)(L+log(1-y))/(1-y) dy.              (2.12)
```

Write

```text
U = integral_0^(1/2) log y/(1-y) dy,
V = integral_0^(1/2) log(1-y)/(1-y) dy,
W = integral_0^(1/2) log y log(1-y)/(1-y) dy.
```

Then

```text
B = L^3 + L U + L V + W.                           (2.13)
```

The first two values follow from explicit primitives:

```text
U = Li2(1/2)-Li2(1),                               (2.14)
V = -L^2/2.                                        (2.15)
```

For `W`, split (1.3) at `1/2`:

```text
Z = W + integral_(1/2)^1 log y log(1-y)/(1-y) dy.
```

In the second integral put `u=1-y`.  It becomes

```text
integral_0^(1/2) log u log(1-u)/u du.
```

By the primitive `Q` in (1.1), this is

```text
Li3(1/2)+L Li2(1/2).
```

Thus

```text
W = Z-Li3(1/2)-L Li2(1/2).                         (2.16)
```

Substitution of (2.14)--(2.16) into (2.13) cancels
`L Li2(1/2)` before any special-value simplification:


Using the stated value of `Li3(1/2)`,


# 4. The reflected kernel `J`

Define

```text
J = integral_0^1 log(x)log(1+x)/(1-x) dx.          (4.1)
```

Use

```text
G(x)=log(1+x)Li2(1-x).
```

The chain-rule sign is positive:

```text
(d/dx)Li2(1-x)
 = [-log x/(1-x)](-1)
 = log x/(1-x).
```

Therefore

```text
G'(x)
 = Li2(1-x)/(1+x)
   + log x log(1+x)/(1-x).                         (4.2)
```

Also

```text
G(0)=0,
G(1)=0.                                            (4.3)
```

FTC and the affine reflection `t=1-x` give

```text
0
 = J + integral_0^1 Li2(1-x)/(1+x) dx
 = J + integral_0^1 Li2(t)/(2-t) dt
 = J+R.                                             (4.4)
```

There is no minus sign in the reflected integral: `dx=-dt` and the reversed
bounds cancel.  Hence

```text
J = -R = Z-(pi^2/4)L.                              (4.5)
```

This makes the circularity audit explicit: first (2.18), then (3.4), and only
then (4.5).

# 5. The cubic remainder `M`

Define

```text
M = integral_0^1 x^2 log(x)log(1+x)/(1-x^3) dx.    (5.1)
```

The proof below uses an absolutely convergent double series and one already
evaluated, grouped real residue-class sum.  No colored constant remains in the
result.

## 5.1. Legal series-to-integral interchange

For `0<=x<1`,

```text
1/(1-x^3) = sum_(n>=0) x^(3n),
log(1+x)  = sum_(m>=1) (-1)^(m+1)x^m/m.
```

After integrating the absolute values, the relevant majorant is

```text
sum_(m>=1) sum_(n>=1) 1/[m(m+3n)^2].               (5.2)
```

For each `m`, monotonicity gives

```text
sum_(n>=1) 1/(m+3n)^2
 <= integral_0^infinity du/(m+3u)^2
 = 1/(3m).
```

Thus (5.2) is at most

```text
(1/3)sum_(m>=1)1/m^2,
```

so Tonelli/Fubini and termwise integration are valid.  Since

```text
integral_0^1 x^(m+3n-1)log x dx = -1/(m+3n)^2,
```

we get

```text
M
 = -sum_(n>=1) sum_(m>=1)
      (-1)^(m+1)/[m(m+3n)^2].                      (5.3)
```

## 5.2. Exact inner summation

For positive integers `m,N`,

```text
1/[m(m+N)^2]
 = (1/N^2)(1/m-1/(m+N))
   -(1/N)1/(m+N)^2.                                (5.4)
```

Define finite alternating harmonic numbers

```text
h1(N)=sum_(j=1)^N (-1)^(j+1)/j,
h2(N)=sum_(j=1)^N (-1)^(j+1)/j^2.                 (5.5)
```

Use

```text
sum_(m>=1)(-1)^(m+1)/m   = L,
sum_(m>=1)(-1)^(m+1)/m^2 = pi^2/12.               (5.6)
```

Shifting `m+N` in (5.4) gives, for every `N>=1`,

```text
sum_(m>=1) (-1)^(m+1)/[m(m+N)^2]
 = L(1-(-1)^N)/N^2
   + (-1)^N h1(N)/N^2
   - (-1)^N pi^2/(12N)
   + (-1)^N h2(N)/N.                               (5.7)
```

This identity is best proved first for a finite upper bound on `m`; the two tail
terms then converge by the alternating test.  No double-series rearrangement is
involved.

For `N=3n`, `(-1)^N=(-1)^n`.  Keep the following two terms grouped:

```text
C3 = sum_(n>=1) (-1)^n
       [h1(3n)/n^2+3h2(3n)/n].                    (5.8)
```

The project's evaluated ordinary/cubic residue-class theorem is precisely

```text
C3 = (pi^2/4)L-(43/12)Z.                           (5.9)
```

Equation (5.9) is an evaluated real `HasSum`, not an unevaluated colored Euler
sum.  Its Lean statement must remain grouped exactly as in (5.8); the
`h2(3n)/n` component is not to be split off unless its convergence has separately
been established.  In the current development this is a finite wrapper around
the already proved ordinary and cubic alternating residue-class `HasSum`
theorems, followed by `ring`.

For completeness, the only additional scalar sums needed after (5.7) are

```text
sum_(n>=1) [1-(-1)^n]/n^2 = pi^2/4,
sum_(n>=1) (-1)^n/n       = -L.                   (5.10)
```

Summing (5.7) over `N=3n` therefore gives

```text
sum_(n,m>=1) (-1)^(m+1)/[m(m+3n)^2]
 = (pi^2/36)L+(pi^2/36)L+C3/9
 = (pi^2/18)L+C3/9.                                (5.11)
```

The leading minus sign in (5.3) is essential.  Hence

```text
M = -(pi^2/18)L-C3/9.                              (5.12)
```

Substitute (5.9):

```text
M
 = -(pi^2/18)L
   -(1/9)[(pi^2/4)L-(43/12)Z]
 = (43/108)Z-(pi^2/12)L.                           (5.13)
```

The sign check is immediate: the integrand in (5.1) is negative on `(0,1)`, and
the right side is approximately `-0.09149397536`.

# 6. Final rational decomposition


```text
(1+2x)/(1+x+x^2)
```

Indeed both sides become

```text
(1+x-2x^2)/[(1-x)(1+x+x^2)].
```

Multiplying (6.1) by `log x log(1+x)` and integrating almost everywhere,


```text

 = [Z-(pi^2/4)L]
   -3[(43/108)Z-(pi^2/12)L]

 = -(7/36)Z.                                       (6.3)
```

This is the claimed value.
