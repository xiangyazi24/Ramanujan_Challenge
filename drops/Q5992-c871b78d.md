# Direct integral-remainder proof for the period-two pi continued fraction

## Result

No Bauer-Muir transformation is needed for the missing analytic step. The seed itself has an exact positive integral remainder.

Let `P(N), Q(N)` be the continuants of the fraction in the question. For every `n >= 0`, define

```text
J(m) = Integral[t=0..1]
       2*t^(2*m)*(1-t^2)^(2*m-1)/(1+t^2)^(2*m) dt,
       m >= 1,

kappa(n) = (-1)^(n+1) * ((2*n+1)!)^2 / 2^n.
```

Then the exact identity is

```text
P(2*n) - pi*Q(2*n) = kappa(n)*J(n+1).             (1)
```

Moreover all denominators are positive, and

```text
Q(2*n) >= abs(kappa(n)),
0 <= J(n+1) <= (1/4)^n * J(1),
J(1) = pi - 3.
```

Consequently

```text
abs(P(2*n)/Q(2*n) - pi) <= (pi-3)*(1/4)^n.        (2)
```

Every odd convergent is a positive weighted average of the two adjacent even convergents, so also

```text
abs(P(2*n+1)/Q(2*n+1) - pi)
  <= (pi-3)*(1/4)^n.                              (3)
```

Thus, for every `N >= 0`, with `N/2` denoting natural-number division,

```text
abs(P(N)/Q(N) - pi)
  <= (pi-3)*(1/4)^(N/2)
  <= 2*(pi-3)*(1/2)^N.                            (4)
```

The last expression tends to zero by the standard geometric-sequence limit. This proves

```text
P(N)/Q(N) -> pi.
```

Everything before that final geometric limit is a finite recurrence identity, a rational-function derivative identity, or an order inequality on `[0,1]`.

## 1. Coefficients in factored form

The coefficients are more transparent as

```text
c(0)       = 3,
c(2*n+1)   = (n+1)*(10*n+9),
c(2*n+2)   = (2*n+3)*(5*n+6),

d(1)       = 1,
d(2*n+2)   = -4*(n+1)^2*(2*n+3)^2,
d(2*n+3)   = (n+1)*(n+2)*(2*n+3)^2.
```

For either `X=P` or `X=Q`, the continuant recursion is

```text
X(N) = c(N)*X(N-1) + d(N)*X(N-2),                 (5)
```

with

```text
P(-1)=1, P(0)=3,
Q(-1)=0, Q(0)=1.
```

The displayed continued fraction therefore starts

```text
3 + 1/(9 - 36/(18 + 18/(38 - 400/(55 + ...)))).
```

## 2. Initial values

The first continuants are obtained directly from (5):

```text
N=0:
P(0)=3,
Q(0)=1,
P(0)/Q(0)=3.

N=1:
P(1)=9*3+1*1=28,
Q(1)=9*1+1*0=9,
P(1)/Q(1)=28/9.

N=2:
P(2)=18*28-36*3=396,
Q(2)=18*9-36*1=126,
P(2)/Q(2)=22/7.

N=3:
P(3)=38*396+18*28=15552,
Q(3)=38*126+18*9=4950,
P(3)/Q(3)=864/275.

N=4:
P(4)=55*15552-400*396=696960,
Q(4)=55*4950-400*126=221850,
P(4)/Q(4)=7744/2465.
```

The values at `N=0,2,4` will also check the integral identity (1).

## 3. Exact recurrence for the even subsequence

Although the project already has an even-contraction proof, it is useful to record the exact recurrence needed below.

For `n >= 1`, write

```text
A(n)     = (n+1)*(10*n+9),
B(n)     = n*(n+1)*(2*n+1)^2,
E(n)     = (2*n+1)*(5*n+1),
C(n)     = (2*n+3)*(5*n+6),
Gamma(n) = 4*n^2*(2*n+1)^2,
Delta(n) = 4*(n+1)^2*(2*n+3)^2.
```

The three consecutive period-two recurrences are

```text
X(2*n+1) = A(n)*X(2*n) + B(n)*X(2*n-1),

X(2*n)   = E(n)*X(2*n-1) - Gamma(n)*X(2*n-2),

X(2*n+2) = C(n)*X(2*n+1) - Delta(n)*X(2*n).       (6)
```

Eliminating `X(2*n-1)` gives

```text
E(n)*X(2*n+1)
 = (E(n)*A(n)+B(n))*X(2*n)
   + B(n)*Gamma(n)*X(2*n-2).
```

Substitute this into the last line of (6). The two required factorizations are

```text
C(n)*(E(n)*A(n)+B(n)) - Delta(n)*E(n)
 = (n+1)*(2*n+1)*(2*n+3)
   *(220*n^3+484*n^2+301*n+42),

C(n)*B(n)*Gamma(n)
 = 4*n^3*(n+1)*(2*n+1)^4*(2*n+3)*(5*n+6).
```

After cancelling the factor `2*n+1`, every continuant solution satisfies, for `n >= 1`,

```text
(5*n+1)*X(2*n+2)
 = (n+1)*(2*n+3)
   *(220*n^3+484*n^2+301*n+42)*X(2*n)

   + 4*n^3*(n+1)*(2*n+1)^3*(2*n+3)*(5*n+6)
     *X(2*n-2).                                    (7)
```

This is a pure `ring` certificate after the three rewrites in (6).

## 4. A finite rational integral

Define, for `0 <= t <= 1`,

```text
w(t) = t*(1-t^2)/(1+t^2),

H(m,t) = 2*t^(2*m)*(1-t^2)^(2*m-1)/(1+t^2)^(2*m),
          m >= 1,

J(m) = Integral[t=0..1] H(m,t) dt.
```

The useful factorization is

```text
H(m,t) = H(1,t)*w(t)^(2*m-2).                      (8)
```

The denominator `1+t^2` is nonzero on all of `R`, so every integrand here is continuous on `[0,1]`.

### Evaluation of `J(1)`

Set

```text
F(t) = 4*atan(t) - 2*t*(t^2+2)/(1+t^2).
```

Direct differentiation gives

```text
F'(t) = 2*t^2*(1-t^2)/(1+t^2)^2 = H(1,t).         (9)
```

Using `atan(0)=0` and `atan(1)=pi/4`,

```text
J(1) = F(1)-F(0) = pi-3.                          (10)
```

This is the only evaluation of a transcendental integral needed in the proof.

## 5. Exact recurrence for the integrals

Define

```text
alpha(m) = 220*m^3 - 176*m^2 - 7*m + 5.
```

For `m >= 2`, define the polynomial

```text
R(m,z)
 = (10*m^2-8*m-2)
   + (-30*m^2+9*m+7)*z
   + (-60*m^2+38*m+4)*z^2
   + (30*m^2-19*m-5)*z^3
   + (10*m^2-8*m)*z^4,
```

and the rational certificate

```text
Phi(m,t)
 = -2*t^(2*m-1)*(1-t^2)^(2*m-2)*R(m,t^2)
   /(1+t^2)^(2*m+1).
```

A direct differentiation and clearing of the positive denominator gives the identity

```text
d/dt Phi(m,t)
 = 2*m*(2*m+1)*(5*m-4)*H(m+1,t)
   + alpha(m)*H(m,t)
   - 2*(m-1)*(2*m-1)*(5*m+1)*H(m-1,t).            (11)
```

There is no summation or asymptotic argument hidden in (11). After multiplying by a sufficient power of `1+t^2`, both sides are the same polynomial in `t` and `m`. In Lean this should close with `field_simp` followed by `ring` or `ring_nf`.

For `m >= 2`, the factor `t^(2*m-1)` makes `Phi(m,0)=0`, and the factor `(1-t^2)^(2*m-2)` makes `Phi(m,1)=0`. Integrating (11) therefore yields

```text
2*m*(2*m+1)*(5*m-4)*J(m+1)
 + alpha(m)*J(m)
 - 2*(m-1)*(2*m-1)*(5*m+1)*J(m-1)
 = 0,                                               (12)
```

for every `m >= 2`.

### The exceptional first step

The first step must not be hidden under a phrase such as "correcting initial terms." Use the explicit certificate

```text
Phi1(t)
 = -4*t^3*(t^6+3*t^4-9*t^2-7)/(1+t^2)^3.
```

It satisfies

```text
Phi1'(t) = 6*H(2,t) + 42*H(1,t),
Phi1(1)-Phi1(0) = 6.
```

Hence

```text
6*J(2) + 42*J(1) = 6,
J(2) = 1-7*J(1) = 22-7*pi.                        (13)
```

At `m=2`, (12) gives

```text
120*J(3) + 1047*J(2) - 66*J(1) = 0,
```

so

```text
J(3) = -968/5 + (493/8)*pi.                       (14)
```

These formulas already explain the familiar rational approximants `22/7` and `7744/2465`.

## 6. Matching the integral recurrence to the continuants

Define

```text
kappa(n) = (-1)^(n+1) * ((2*n+1)!)^2 / 2^n.
```

Its consecutive ratios are

```text
kappa(n+1)/kappa(n)
 = -2*(n+1)^2*(2*n+3)^2,

kappa(n)/kappa(n-1)
 = -2*n^2*(2*n+1)^2,       n >= 1.                (15)
```

Set

```text
Y(n) = kappa(n)*J(n+1).
```

Substitute `m=n+1` into (12), and use (15). Since

```text
alpha(n+1) = 220*n^3+484*n^2+301*n+42,
```

one obtains, for `n >= 1`,

```text
(5*n+1)*Y(n+1)
 = (n+1)*(2*n+3)
   *(220*n^3+484*n^2+301*n+42)*Y(n)

   + 4*n^3*(n+1)*(2*n+1)^3*(2*n+3)*(5*n+6)
     *Y(n-1).                                       (16)
```

This is exactly the even-continuant recurrence (7).

Now define the even error

```text
E(n) = P(2*n) - pi*Q(2*n).
```

Because (7) is linear, `E(n)` also satisfies (16). The first two values agree with `Y(n)`:

```text
E(0) = 3-pi
     = -J(1)
     = kappa(0)*J(1)
     = Y(0),

E(1) = 396-126*pi
     = 18*(22-7*pi)
     = kappa(1)*J(2)
     = Y(1).
```

Induction in the second-order recurrence (16) proves the promised exact identity

```text
P(2*n) - pi*Q(2*n)
 = (-1)^(n+1)*((2*n+1)!)^2/2^n * J(n+1)           (17)
```

for all `n >= 0`.

### First three checks of (17)

For `n=0`,

```text
kappa(0)*J(1) = -(pi-3) = 3-pi
              = P(0)-pi*Q(0).
```

For `n=1`,

```text
kappa(1)*J(2) = 18*(22-7*pi)
              = 396-126*pi
              = P(2)-pi*Q(2).
```

For `n=2`, using (14),

```text
kappa(2)*J(3)
 = -3600*(-968/5+(493/8)*pi)
 = 696960-221850*pi
 = P(4)-pi*Q(4).
```

Thus the indexing, signs, and exceptional initial step are all fixed explicitly.

## 7. Positivity and a lower bound for the denominators

Define

```text
mu(n) = abs(kappa(n)) = ((2*n+1)!)^2/2^n.
```

Then

```text
mu(0)=1,
mu(n+1)=2*(n+1)^2*(2*n+3)^2*mu(n).                (18)
```

We prove simultaneously that all `Q(N)` are positive and

```text
Q(2*n) >= mu(n).                                  (19)
```

The base values are

```text
Q(0)=1=mu(0),
Q(1)=9>0.
```

For `n=0`, the next inequality below is an equality because `Q(-1)=0`. For `n>=1`, the odd partial numerator is positive. Hence, for all `n>=0`,

```text
Q(2*n+1)
 >= (n+1)*(10*n+9)*Q(2*n)
 > 0.                                               (20)
```

The following even step has a negative partial numerator, but (20) is sufficiently strong:

```text
Q(2*n+2)
 = (2*n+3)*(5*n+6)*Q(2*n+1)
   -4*(n+1)^2*(2*n+3)^2*Q(2*n)

 >= (n+1)*(2*n+3)*(42*n^2+85*n+42)*Q(2*n).         (21)
```

The polynomial in (21) comes from the exact identity

```text
(10*n+9)*(5*n+6)-4*(n+1)*(2*n+3)
 = 42*n^2+85*n+42.
```

Finally,

```text
42*n^2+85*n+42 - 2*(n+1)*(2*n+3)
 = 38*n^2+75*n+36
 >= 0.
```

Therefore (21) implies

```text
Q(2*n+2)
 >= 2*(n+1)^2*(2*n+3)^2*Q(2*n).
```

Together with (18), this proves positivity and (19) by induction. In particular every convergent denominator is nonzero.

## 8. Geometric decay of the integral remainder

For `0 <= t <= 1`,

```text
0 <= w(t)
   <= t/(1+t^2)
   <= 1/2.                                          (22)
```

The last inequality is just

```text
2*t <= 1+t^2,
```

or equivalently `(1-t)^2 >= 0`.

By (8), (22), and nonnegativity of `H(1,t)`,

```text
0 <= H(n+1,t) <= (1/4)^n*H(1,t).
```

Integrating gives

```text
0 <= J(n+1) <= (1/4)^n*J(1)
                  = (1/4)^n*(pi-3).                (23)
```

Combine (17), (19), and (23):

```text
abs(P(2*n)/Q(2*n)-pi)
 = abs(kappa(n))*J(n+1)/Q(2*n)
 <= J(n+1)
 <= (pi-3)*(1/4)^n.                                (24)
```

This establishes convergence of the even subsequence with an explicit error bound.

## 9. Odd convergents are convex combinations

Put

```text
C(n)     = (2*n+3)*(5*n+6),
Delta(n) = 4*(n+1)^2*(2*n+3)^2.
```

The even recurrence step is

```text
P(2*n+2) = C(n)*P(2*n+1)-Delta(n)*P(2*n),
Q(2*n+2) = C(n)*Q(2*n+1)-Delta(n)*Q(2*n).
```

Rearranging and using positivity of all denominators gives the exact finite identity

```text
P(2*n+1)/Q(2*n+1)
 = [ Q(2*n+2)*(P(2*n+2)/Q(2*n+2))
     + Delta(n)*Q(2*n)*(P(2*n)/Q(2*n)) ]
   /[ Q(2*n+2)+Delta(n)*Q(2*n) ].                  (25)
```

Thus the odd convergent is a convex combination of the neighboring even convergents. Subtracting `pi` in (25), applying the triangle inequality, and using (24) at `n` and `n+1` gives

```text
abs(P(2*n+1)/Q(2*n+1)-pi)
 <= max(
      abs(P(2*n)/Q(2*n)-pi),
      abs(P(2*n+2)/Q(2*n+2)-pi))
 <= (pi-3)*(1/4)^n.                                (26)
```

Equations (24) and (26) prove the full-sequence bound (4), hence convergence to `pi`.

## 10. Lean-friendly organization

The cleanest formalization avoids factorial algebra in the main induction. Define the integral sequence with zero-based indexing

```text
j(n) = J(n+1)
     = Integral[t=0..1]
       2*t^(2*n+2)*(1-t^2)^(2*n+1)/(1+t^2)^(2*n+2) dt.
```

Define the scaling recursively:

```text
kappa(0)   = -1,
kappa(n+1) = -2*(n+1)^2*(2*n+3)^2*kappa(n),

mu(0)      = 1,
mu(n+1)    = 2*(n+1)^2*(2*n+3)^2*mu(n).
```

The closed forms involving factorials can be proved afterward and are not needed for convergence.

A practical lemma order is:

1. `first_continuants`: prove the exact values through `N=4` by `norm_num`.
2. `continuant_even_recurrence`: prove (7) for a generic sequence satisfying the two-step recurrence. This is rewriting plus `ring`.
3. `hasDerivAt_F`: prove (9), then use the interval-integral fundamental theorem and `Real.arctan_one` to obtain `j(0)=pi-3`.
4. `hasDerivAt_phi1`: prove the exceptional derivative and boundary values, obtaining `6*j(1)+42*j(0)=6`.
5. `hasDerivAt_phi`: prove (11) for `m>=2`. Prove `1+t^2 != 0`, clear denominators with `field_simp`, then use `ring_nf`.
6. `j_recurrence`: integrate the derivative certificate. Keep `m=1` separate so no truncated natural subtraction appears.
7. `scaled_j_recurrence`: combine `j_recurrence` with the recursive definition of `kappa`; this is again `ring`.
8. `even_error`: prove (17) by induction from `n=0,1` and the common recurrence.
9. `denominator_pos_lower`: prove simultaneously `0<Q(2*n)`, `0<Q(2*n+1)`, and `mu(n)<=Q(2*n)` using (20)-(21).
10. `w_nonneg`, `w_le_half`, and `j_bound`: prove (22)-(23) by interval-integral monotonicity.
11. `even_ratio_bound`: combine `even_error`, `denominator_pos_lower`, and `j_bound`.
12. `odd_convex`: prove (25) by `field_simp` using denominator positivity.
13. `all_ratio_bound`: split `N` into `2*n` or `2*n+1` and prove (4).
14. Apply the standard theorem that `(1/2)^N` tends to zero and squeeze the absolute error.

A suitable final theorem statement is

```text
theorem periodTwo_tendsto_pi :
  Tendsto (fun N => P N / Q N) atTop (nhds Real.pi)
```

with no analytic hypothesis.

## 11. What the proof uses analytically

The proof uses only:

```text
1. d/dt atan(t) = 1/(1+t^2),
2. atan(1) = pi/4,
3. the fundamental theorem of calculus on [0,1],
4. (1/2)^N -> 0.
```

There is no appeal to Cohen's value theorem, no unexpanded Bauer-Muir assertion, no infinite continued-fraction tail manipulation, and no Poincare-Perron argument. The key bridge is the exact finite identity (17), which gives a signed positive integral remainder for every even convergent; positivity and the convex-combination formula then control the full period-two sequence.
