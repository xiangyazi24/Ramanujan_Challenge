# Q867 hostile audit: C3 height bridge

## Verdict summary

The proposed edge is essentially correct under the stated banked local formula, but one quantifier must be made explicit: the implication from W(n) to C3(n) requires the local divisibility statement to hold for every prime p in the W(n) range, including the treatment of p-adic powers separately. The rad-conjecture is not needed for this particular height equivalence.

The reverse inequality C3(n) <= W(n)+O(n^(2/3)) is not automatic from the displayed W(n) definition alone; it requires the already-banked estimate for C1(n) together with the inclusion C3 | C1. This is the only place where the argument uses the global C1 theorem.

---

## Line-by-line audit

### Definition

> W(n)=sum_{sqrt(n)<p<=n, p|b_{n mod p}} log p.

Verdict: valid. This counts primes only, with exponent one. It does not count prime powers.

Important consequence: W(n) is a radical contribution, not a valuation sum.

---

### Banked theorem for C1

> 0 <= log C1(n)-W(n) << n^(2/3).

Verdict: accepted as input.

This statement already absorbs all prime-power issues for C1. It means the difference between the full C1 valuation and the prime-level W contribution is bounded. No new prime-power argument is needed here.

---

### Definition

> C3(n)=gcd(L_n,U_1(n),U_2(n),U_3(n)).

Verdict: valid.

Immediate relation:

C3(n) | C1(n),

because C1 is gcd(L_n,U_1(n)). Hence

log C3(n) <= log C1(n).

Combining with the banked C1 estimate gives

log C3(n) <= W(n)+O(n^(2/3)).

This direction is unconditional once the C1 theorem is accepted.

---

## Lower bound audit

Claim:

> Every p counted by W(n) divides every U_s(n), s=1,2,3.

Verdict: this is the critical dependency.

If the banked local formula says exactly:

p | b_{n mod p}, p>sqrt(n) => p | U_s(n) for s=1,2,3,

then p divides L_n as well, because p<=n. Therefore

p | gcd(L_n,U_1,U_2,U_3)=C3.

Thus

rad(W contribution) | C3,

and therefore

log C3(n) >= sum_{p counted by W(n)} log p=W(n).

No missing prime-power factor occurs here because W only contributes one copy of each p.

Verdict: valid conditional on the stated local formula with the exact quantifier "for every prime p in the W range".

---

## Prime powers and small primes

### Prime powers

No issue for the lower bound:

W(n) only has p once, while C3 may have p^e. Extra valuation only increases log C3.

For the upper bound, prime powers are already inside

log C3 <= log C1 <= W+O(n^(2/3)).

Therefore no additional rad-gcd statement is required.

### Small primes

The W definition excludes p<=sqrt(n). Such primes can occur in C3, but they are included in the C1 error term. The argument does not claim that C3 has no small-prime contribution; it claims the total excess over W is controlled by n^(2/3).

Verdict: valid.

---

## Rad gcd conjecture audit

Proposed separate conjecture:

rad gcd(U_1(a),U_2(a),U_3(a)) | rad L_a.

Verdict: not needed for the height equivalence.

Reason: C3 already contains L_n in the gcd. The only possible problem would be an unwanted prime dividing all U_s but not L_n, but such a prime is automatically absent from C3 because C3 takes the gcd with L_n.

The rad statement would be useful for structural descriptions of the common divisors of U_s, but it is not required for

W(n)<=log C3(n)<=W(n)+O(n^(2/3)).

## Main consumer audit

Given:

log G_n <= O(sqrt(n))+O(n^(2/3))+6 log C3(n).

Using

log C3(n)=W(n)+O(n^(2/3)),

we obtain

log G_n <= O(sqrt(n))+O(n^(2/3))+6W(n).

Therefore:

If W(n)=o(n), then

log G_n=o(n).

Forward implication: valid.

---

## Does GOAL imply W(n)=o(n)?

Need to distinguish two directions.

The proposed equivalence needs the reverse implication. From

W(n)<=log C3(n),

and if the main theorem gives only

log G_n=o(n),

there is no immediate implication unless there is also a lower bound

log C3(n) <= O(log G_n)

or an independent relation placing C3 inside G_n.

If the existing consumer has the form

log G_n <= ... + 6 log C3,

that is only an upper bound. It cannot be inverted.

Therefore:

- W(n)=o(n) => log G_n=o(n): YES.
- log G_n=o(n) => W(n)=o(n): NOT proved from this inequality alone.

A reverse implication requires an additional lower-height link between C3 and G_n, or a theorem that C3 divides a controlled power of G_n.
