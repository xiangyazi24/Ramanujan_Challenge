# 14. Final audit conclusion

The hostile objection to Q2059 is valid in one precise sense:

```text
The predecessor errors can be put on a common rank-lambda integral
node/evaluation order and multiplied with the primitive Q2055 star
operator.  The own p exponents then add:

    (lambda-1) + 1 = lambda.
```

So a blanket statement that the new `[p]` relation must remain a separate Smith block is false.

But the stronger construction does not move the Problem 3.2 residual.  The exact carrier comparison is

```text
L1 = R * L0 * Q_height,
Q_height >= 1.
```

Hence the new normalized height slack is never smaller than the old one:

```text
Slack1 = Slack0 + log Q_height.
```

The Q2059 synthetic local-transfer family realizes

```text
Q_height = 2,
```

so this saturation is sharp up to an absolute factor.

The actual `m=321` orbit is consistent with the same picture: the same-rank oriented-star product has mod-p corank one and gains one exact predecessor valuation at each of `179,193,211`, while its predecessor-error lcm is already 1454 digits.

The first datum not exhausted by this audit would have to yield an extra marked valuation **without multiplying the primitive star eigenvalue by an integer already carrying that same marked prime**.  Equivalently, it must change the normalized height slack, not merely the Smith exponent.  A connected cross-index Apéry syzygy or a distinguished-orbit relation among the quotients
