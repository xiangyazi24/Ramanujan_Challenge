# P32 marked-initial-state R2 audit

## Executive verdict

No genuinely new identity is obtained from the three proposed marked constructions alone. The mark `L(s)=s_1-5s_0` is real arithmetic data, but once one conditions on four zeros of the distinguished solution `b`, all three routes reduce to either:

1. the already-known equations `b_{r_i}=0`, or
2. a transfer identity that is valid for every initial vector in the same two-dimensional recurrence space.

Therefore none of (1)--(3), by itself, yields the missing implication

```
(r0,r1,r2,r3 consecutive zeros, (r3-r0)^2 <= p) => some r_i+r_{i+1}=p-1.
```

A successful square-root proof needs an additional marked invariant involving the actual arithmetic embedding of the Apéry solution, not just a covector evaluated on the transported state.

## 1. Transfer matrices and the initial mark

Write the recurrence as

\[
S_{n+1}=T_nS_n,
\qquad
S_n=\binom{u_n}{u_{n+1}},
\]

where

\[
T_n=
\begin{pmatrix}
0&1\\
-\frac{n^3}{(n+1)^3}&\frac{P(n)}{(n+1)^3}
\end{pmatrix}.
\]

For a fixed initial state, the condition `u_r=0` is a linear equation on the transported vector. The marked covector is

\[
L(x,y)=y-5x.
\]

Since `L(b_0,b_1)=0` and `L(c_0,c_1)=1`, it records the initial coordinate:

\[
L(b-qc)=-q.
\]

At a return index r, let

\[
M_r=T_{r-1}\cdots T_0.
\]

Then the transported mark is

\[
L(M_r(b-qc)).
\]

Expanding in q gives

\[
L(M_r b)-qL(M_r c).
\]

The equation that the fibre `b-qc` returns to the zero line is exactly one linear equation in q. For q=0 it becomes

\[
L(M_r b)=0
\]

which is equivalent to `b_r=0` after choosing the corresponding return covector.

There is no extra determinant equation hidden here: the two coefficients are the two minors of the same 2x2 matrix.

## 2. Four returns and determinant minors

Suppose

\[
b_{r_0}=b_{r_1}=b_{r_2}=b_{r_3}=0.
\]

Each condition says that the transported initial vector lies on the distinguished kernel line at that time. Equivalently,

\[
\det(e_1,M_{r_i}b)=0.
\]

Taking two such equations gives a determinant relation between rows of transfer matrices, but it is exactly the statement that the same vector b lies in both kernels.

For four returns, every 2x2 determinant formed from the four transported vectors factors through the already imposed zero conditions. There is no independent fourth-order determinant because the state space is dimension two.

More concretely, if `R_i` denotes the row functional detecting the zero at `r_i`, then

\[
R_i b=0\quad(i=0,1,2,3).
\]

Any proposed determinant

\[
\det\begin{pmatrix}
R_i b&R_i c\\
R_j b&R_j c
\end{pmatrix}
\]

has first column zero. Hence it only says that the two functionals have compatible kernels. It does not impose a new relation on the indices.

Thus the four-return minor route is a repackaging of `b_{r_i}=0`.

## 3. Varying q and the companion values

For

\[
u=b-qc,
\]

we have

\[
u_r=b_r-qc_r.
\]

At a distinguished zero of b,

\[
b_r=0,
\]

so the fibre equation becomes

\[
u_r=-qc_r.
\]

For q=0 all four values vanish. For q!=0, a return of the fibre requires

\[
c_r=0.
\]

This does not create a new relation among the four b-zero indices. It merely asks whether the companion solution has simultaneous zeros.

The Wronskian prevents this at the same index:

\[
c_rb_{r-1}-c_{r-1}b_r=K/r^3\neq0,
\]

so when `b_r=0`, the companion value cannot also vanish together with the neighboring state. But it gives no information about sums

\[
r_i+r_{i+1}=p-1.
\]

The carrier-clean projective repeats (including the supplied p=709,q=67 example) show that projective return patterns survive away from q=0. Therefore the q-family cannot be separated by the existing label law.

## 4. Inhomogeneous and index-derivative lifts

A derivative lift differentiating the transfer matrix with respect to the index parameter would retain information lost under projectivization, but the raw derivative satisfies a forced equation

\[
D_{n+1}=T_nD_n+T'_nS_n.
\]

The forcing term is determined by the original orbit `S_n`. At a zero of b, the lifted equation still contains the same initial condition constraint. It does not automatically create a second independent equation.

Likewise an inhomogeneous augmentation

\[
\widetilde S_{n+1}
=\widetilde T_n\widetilde S_n+F_n
\]

only helps if the forcing F is tied to the marked Apéry normalization. An arbitrary lift is not invariantly attached to q=0.

Therefore a derivative/inhomogeneous route is potentially useful only after adding genuinely arithmetic data.

## 5. No-go lemma

**Lemma (marked transfer no-go).**
Let V be the two-dimensional solution space of the Apéry recurrence over F_p. Let A be any expression constructed only from:

1. transfer matrices T_n,
2. projective states in P(V),
3. determinants/minors of transported vectors,
4. the covector L evaluated on transported states,
5. finitely many return conditions u_{r_i}=0.

Then, restricted to the locus where the same solution u has zeros at r_0,...,r_k, A is either invariant under changing the complementary basis vector or is algebraically equivalent to the existing zero equations.

**Reason.** The recurrence evolution is linear in V. Four returns constrain one vector in a two-dimensional space. Every determinant involving that vector vanishes because one column is already fixed by the return conditions. The only basis-breaking scalar is the initial coordinate q=L(u). If q is not explicitly retained as an arithmetic normalization, the construction is GL_2/gauge blind.

## 6. What extra datum could work?

The minimal missing datum is not another transport identity. It is an arithmetic normalization selecting the Apéry vector.

Examples:

* the exact initial condition `(b_0,b_1)=(1,5)`, not merely the projective line;
* the marked covector `L` together with its preferred lattice normalization;
* an integral congruence property of b_n (for example Lucas-type structure).

Any successful proof of the square-root adjacent-reflection claim must combine the short-gap continuant information with one of these non-projective inputs.

The reflection symmetry

\[
r\mapsto p-1-r
\]

is exactly such an arithmetic input: it is not a consequence of arbitrary transfer geometry. A proof must show that four short returns force interaction with that marked involution. The three proposed routes do not do so.
