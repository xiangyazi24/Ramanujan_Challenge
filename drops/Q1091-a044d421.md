# Gamma_n height attack: valuation analysis and obstruction

## Summary

The proposed target is a polynomial-height bound

\[
\Gamma_n\le n^C
\]

obtained from

\[
v_p(\Gamma_n)=\min_{0\le j<M}(v_p(L_j)+v_p(b_j)).
\]

The useful observation is that the minimization is over the *same* index set for the two terms. Radical containment only proves that the set of possible primes is small; it gives no control on the exponent. A valid attack therefore has to control prime powers.

The strongest general lemma available from the definition of L_j is the following.

## Carry-free suffix lemma

For every prime p and n, choose j<M such that the base-p digits of j are a suffix of the digits of n in the sense that all carries in the subtraction n-j vanish. Then Kummer's theorem gives

\[
v_p\binom nj=0.
\]

Moreover, if the same digit condition is imposed on the second binomial,

\[
v_p\binom{n-j-1}{M-1-j}=0,
\]

then

\[
v_p(L_j)=0.
\]

Consequently

\[
v_p(\Gamma_n)\le v_p(b_j).
\]

This reduces the height problem to finding, for every p dividing the q=1 support, a bounded family of carry-free suffix indices j with small Apéry valuation.

## Prime-power obstruction

The missing step is not support. The support theorem already gives

\[
\operatorname{rad}(\Gamma_n)\mid b_n.
\]

The remaining issue is whether

\[
v_p(b_j)
\]

can be uniformly bounded for one of the carry-free choices. A Lucas-type argument only detects

\[
b_j\not\equiv0\pmod p
\]

and therefore cannot control

\[
v_p(b_j)>1.
\]

Thus the natural strengthened statement needed for a proof is:

**Conjectural valuation selector lemma.** For every prime p and every n there exists j in a set of at most O(log_p n) carry-free suffix candidates such that

\[
v_p(L_j)+v_p(b_j)\le 1+\lceil \log_p n\rceil.
\]

If true, summing over p≤n gives

\[
\log \Gamma_n
=\sum_{p\le n}v_p(\Gamma_n)\log p
=O(\pi(n)\log n),
\]

which is still too weak, but restricting to the q=1 support primes and using the known support sparsity would yield the desired polynomial bound.

## Modular search strategy

The correct computational test is not to compute Gamma values alone. For each n and each prime p≤n one should compute

```
min(v_p(L_j)+v_p(b_j) for 0<=j<n//2)
```

and compare it with the selector bound above. A violation with growing

```
max_p v_p(Gamma_n)
```

would disprove polynomial height.

The first candidate counterexample mechanism would be a prime p where every carry-free suffix j satisfies

\[
v_p(b_j)\ge c\log_p n
\]

because then the Apéry side, not the binomial coefficient side, forces large prime powers.

## Conclusion

The direct height route does not follow from radical containment. The new bottleneck is exactly the valuation selector lemma above. It separates the two phenomena:

* support size: controlled by the known radical theorem;
* prime-power valuation: requires a carry-free index avoiding high Apéry valuations.

No superpolynomial pattern is established by the available data n≤1200. The data are consistent with a polynomial-height theorem, but a proof requires the valuation selector lemma (or a counterexample producing unavoidable high p-adic Apéry valuations).
