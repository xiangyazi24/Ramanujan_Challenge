# Q7936: Exact overlap expansion of the HM3 output energy

## 1. Setup and exact expansion

Write
\[
E_p=\sum_{q,l\ne p,\ q\ne l} T_{p;q,l},\qquad
T_{p;q,l}=\sum_{m<M}g_p(m)g_q(m)g_l(m).
\]
The ordered convention is used throughout. Hence
\[
T=\sum_p z_p^{-1}E_p^2
=\sum_p z_p^{-1}\sum_{q,l\ne p}\sum_{q',l'\ne p}T_{p;q,l}T_{p;q',l'}.
\]
The only issue is the intersection pattern of the two ordered pairs.

For fixed output prime p there are four cases:

1. **Four distinct input primes**: q,l,q',l' all different.
2. **One shared prime**: exactly one equality among q,l and q',l'.
3. **Same unordered pair**: {q,l}={q',l'}.
4. **Diagonal orientation**: (q,l)=(l',q') with q≠l.

The multiplicities are exact because the sum is over ordered pairs. A same unordered pair contributes two orientations, while the identical ordered pair contributes once.

## 2. Physical interpretation

Each term is a centred factorial moment. If
\[
N(m)=\sum_p f_p(m),\qquad G(m)=N(m)-\lambda_X,
\]
then the triple term is the third centred factorial contribution. Expanding the product gives CRT intersection counts.

For distinct primes, CRT gives independent local choices. Thus the all-five-prime contribution (p plus four inputs) is the only class not controlled by existing second factorial information.

## 3. Bounds from current repository inputs

Using
\[
Z(p)\le p^{2/3+o(1)},\qquad \lambda=\sum_p Z(p)/p,
\]
and the proved second factorial estimate
\[
\sum_m\sum_{q\ne l}g_q(m)g_l(m)^2\ll M\lambda^2,
\]
the repeated-prime classes satisfy
\[
\sum_{p}z_p^{-1}\sum_{\substack{q,l,q',l'\\\text{with overlap}}}|T_{p;q,l}T_{p;q',l'}|
\ll X^{4+o(1)}\lambda^5.
\]
The same-unordered-pair class is smaller because it is controlled by fourth moments of individual rows and the factor z_p^{-1} is cancelled by the support size bound.

No such estimate exists from the current hypotheses for
\[
q,l,q',l',p\ \text{all distinct}.
\]

## 4. Remaining theorem needed

The exact missing statement is the five-prime correlation bound:

For distinct active primes,
\[
\sum_{p,q,l,q',l'}z_p^{-1}
\left(\sum_{m<M}g_p(m)g_q(m)g_l(m)\right)
\left(\sum_{n<M}g_p(n)g_{q'}(n)g_{l'}(n)\right)
\ll X^{4+o(1)}\lambda^5.
\]
Equivalently, after removing all overlap classes, the five-variable CRT incidence tensor must have cancellation beyond what follows from marginal densities.

## 5. Anchored-star obstruction

The anchored-star model has a deterministic common location m=a. Every row contains the same exceptional point. Therefore the five-prime tensor has a rank-one component. This component contributes
\[
\asymp X^5\lambda^5
\]
in the five-distinct class before the output normalization, so the required bound fails.

Hence the current rowwise hypotheses cannot imply the HM3 estimate. The missing theorem must explicitly exclude coherent common anchors, not merely impose reflection, sparsity, and pairwise CRT injectivity.
