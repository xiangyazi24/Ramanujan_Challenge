# Cold audit: multi-height triangular Padé internal support

## 1. Verdict

The proposed implication is not currently a theorem from the stated hypotheses. The folded-node argument proves the forward direction

\[
\sqrt n<p\le n,\quad p\mid b_{n\bmod p}
\Longrightarrow p\mid J_n,
\]

but the converse requires an additional modular-rank statement about the primitive Padé kernels. That statement is exactly the missing content lemma. Finite computations up to `H<=50` are consistent with it, but they do not prove it.

The rigorous conclusion is therefore a conditional theorem: the implication holds if and only if a certain family of reduced Padé evaluation lattices has no extra rank defect modulo `p`.

## 2. Correct modular formulation

Fix a height `K` and a prime `p` with

\[
2\max A_K<p\le n.
\]

For every `a`, let the primitive pair be represented by the saturated integer vector

\[
v_{K,a}=(p_{K,a,0},\ldots,p_{K,a,a},q_{K,a,0},\ldots,q_{K,a,K-a}).
\]

Reduction modulo `p` must be performed after this saturation. A rational kernel vector reduced before primitive normalization can acquire a false zero because its denominator content may vanish modulo `p`.

Define the evaluation functional

\[
\lambda_n(P)=P(\tau(n))\pmod p.
\]

Then

\[
p\mid F_{K,n}
\]

is equivalent to

\[
\lambda_n(P_{K,a})=0
\]

for every `a` in the allowed range.

Thus `p|J_n` means that the vector of primitive numerator evaluations vanishes for every height in the interval.

## 3. Rank/content lemma required for the converse

The missing exact statement is:

**Lemma (primitive evaluation rank).** For every admissible prime `p` and height `K`, let

\[
R_{K,p}(n)=\operatorname{span}_{\mathbf F_p}\{P_{K,a}(\tau(n)):0\le a\le A_K\}.
\]

After primitive saturation,

\[
\dim R_{K,p}(n)=0
\]

if and only if

\[
p\mid b_{n\bmod p}.
\]

Equivalently, the matrix whose columns are the reduced primitive numerator coefficient vectors has evaluation rank zero exactly at folded Apéry zeros.

A checkable determinant version is:

choose any maximal nonzero minor of the saturated coefficient matrix `C_K`. The converse requires

\[
\operatorname{rank}_{\mathbf F_p}(E_nC_K)=0
\Rightarrow p\mid b_{n\bmod p},
\]

where `E_n` is evaluation in the `Phi` basis.

No ordinary polynomial root count proves this because `p<=2K` is allowed. The issue is not the number of roots; it is whether primitive content introduces additional modular kernel vectors.

## 4. First counterexample mechanism

A counterexample would arise from a prime `p` satisfying

\[
2\max A_K<p\le n
\]

and a height `K` for which

\[
\operatorname{rank}_{\mathbf F_p}(E_nC_K)=0
\]

but

\[
p\nmid b_{n\bmod p}.
\]

The mechanism is a hidden Smith invariant divisible by `p` in the primitive Padé lattice.

More explicitly, if the Smith normal form of the saturated interpolation matrix has a diagonal factor

\[
s_i\equiv0\pmod p
\]

not forced by the Apéry value `b_{n\bmod p}`, then all primitive numerator evaluations vanish modulo `p` while the folded-node condition fails.

This is exactly what must be excluded by computation or proof.

## 5. Height interval: what is actually needed

The interval

\[
H\le K\le H+L
\]

is sufficient for the intended forward construction, but the converse does not use its length automatically.

The weakest provable requirement is:

there must exist a finite set of heights `S_n` such that the combined evaluation matrix

\[
M_{S,p}(n)=
\begin{bmatrix}
E_nC_K
\end{bmatrix}_{K\in S_n}
\]

has full expected rank whenever `p\nmid b_{n\bmod p}`.

The number of consecutive heights required is therefore the smallest `r` for which every interval of length `r` contains such a separating set. No value of `r` follows from the supplied definitions alone.

## 6. Content lemmas for independent verification

The needed lemmas are:

### Saturation lemma

If `W_K` is the rational one-dimensional Padé kernel, then the primitive integer pair is the generator of

\[
(W_K\cap\mathbf Z^N)^{sat}.
\]

Reduction modulo `p` must use this generator.

### Evaluation-content lemma

For admissible `p`, if every primitive numerator evaluation is zero modulo `p`, then the vanishing is caused by the Apéry interpolation equations and not by a Smith invariant of the coefficient lattice.

### Multi-height separation lemma

For a proposed set of heights `S`, the block evaluation matrix satisfies

\[
\operatorname{rank}_{\mathbf F_p}M_{S,p}(n)>0
\]

whenever

\[
p\nmid b_{n\bmod p}.
\]

These are finite rank statements and can be independently checked by exact modular linear algebra.

## 7. Relation to observed computations

The computation for `H<=50` establishes only:

\[
\text{no observed extra Smith-support prime in tested cases}.
\]

It does not prove the rank/content lemmas for all heights.

The disappearance of one-height exceptions `19,31,37` after shifts is evidence that those primes were height-local rank defects, not proof that all such defects are impossible.

## 8. What remains outside the no-go

The internal-support statement, if proved, would only classify primes supported by the fixed multi-height triangular carrier.

It does not cover:

* evaluation-dependent bordered lattices;
* gcds involving several unrelated determinant heights;
* constructions where extra evaluation constraints change the saturated lattice.

Such methods require new rank/content statements because their determinant lattices are not the same as the triangular Padé numerator lattice.

## Final conclusion

The requested implication is currently an unproved modular-rank conjecture, not a consequence of folded-node counting. The exact obstruction is a possible hidden Smith/content defect in the primitive Padé lattice. The correct theorem is therefore conditional on the primitive evaluation-rank lemma. Finite `H<=50` regression supports the conjecture but cannot replace that lemma.
