# Multi-slope passport for the transverse Apéry content: exact valuation load, a projective-scale no-go, and the missing local-height theorem

## Verdict

Let

\[
I_R=\{R+1,\dots,2R\},\qquad
D_R(Y)=\prod_{r\in I_R}(b_r+Y\Xi_r),\qquad
C_R=\operatorname{cont}D_R.
\]

The multi-slope idea has a clean theorem, but it does **not** by itself prove

\[
\log [C_R]_{>2R}=o(R^2).
\tag{BFH}
\]

The precise outcome is as follows.

1. If
   \[
   g_r:=\gcd(b_r,\Xi_r),\qquad
   a_r=b_r/g_r,\quad c_r=\Xi_r/g_r,
   \]
   and
   \[
   H_R(Y):=D_R(Y)/C_R=\prod_{r\in I_R}(a_r+Yc_r),
   \]
   then for every finite integer slope set \(S\)
   \[
   \boxed{
   \frac{G_{R,S}}{C_R}
   =\gcd_{y\in S} H_R(y).
   }
   \tag{V1}
   \]
   Thus the false passport factor is **exactly primitive/projective**, while the desired content \(C_R=\prod g_r\) is exactly the row-scale factor removed before taking projective slopes.

2. For \(p>\max(2R,\operatorname{diam}S)\), a primitive row has at most one root in \(S\pmod p\). If
   \[
   e_p(y)=\sum_{r\in I_R}v_p(a_r+yc_r),
   \]
   then, with valuations retained,
   \[
   \boxed{
   v_p(G_{R,S}/C_R)=\min_{y\in S}e_p(y).
   }
   \tag{V2}
   \]
   Hence an extra passport valuation \(t\) supplies at least \(t\) layers, each containing one root-row for every slope. This is stronger than the radical statement in the prompt.

3. If \(S\) is an interval of \(M\) consecutive integers, define for distinct rows
   \[
   K_{r,s}(d)
   :=a_rc_s-a_sc_r-dc_rc_s,
   \qquad 0<|d|<M.
   \tag{V3}
   \]
   For all sufficiently large \(R\), every such \(K_{r,s}(d)\) is a nonzero integer, and
   \[
   \boxed{
   \binom M2\,v_p(G_{R,S}/C_R)
   \le
   \sum_{R<r<s\le2R}
   \sum_{0<|d|<M}v_p(K_{r,s}(d))
   }
   \tag{V4}
   \]
   for every \(p>2R\). Using the proved Apéry/CM sizes gives
   \[
   \boxed{
   \log [G_{R,S}/C_R]_{>2R}
   \ll \frac{R^3}{M}.
   }
   \tag{V5}
   \]
   This is a rigorous load-to-height theorem, including valuations. But for \(M=o(R)\), (V5) is **not subquadratic**. In fact the cruder one-polynomial resultant bound is only \(O(R^2)\), so the direct projective passport does not cross the quadratic barrier.

4. This failure is not merely a weak estimate. There is an exact **scale-invariance obstruction**: replacing every row by
   \[
   (b_r,\Xi_r)\mapsto(q_ra_r,q_rc_r),\qquad q_r\in\mathbf Z_{>0},
   \]
   leaves \(H_R\), every primitive projective slope, and every quotient \(G_{R,S}/C_R\) unchanged, while it changes
   \[
   C_R\mapsto\prod_r q_r
   \]
   arbitrarily. Therefore **no theorem using only noncommon projective slope loads can bound the target content**. In the actual Apéry system the row scales are of course not arbitrary, but exploiting that fact requires a scale-sensitive recurrence/Eichler theorem; it cannot follow from the passport combinatorics alone.

5. Standard finite differences/Vandermonde do not provide the missing scale-sensitive cancellation. For all sufficiently large \(R\), \(\Xi_r<0\) on \(I_R\), so
   \[
   F_R(Z):=D_R(-Z)=\prod_{r\in I_R}(b_r+Z|\Xi_r|)=\sum_{k=0}^R A_kZ^k
   \]
   has positive coefficients. Hence
   \[
   \Delta^kF_R(0)
   =k!\sum_{m=k}^R A_m\,S(m,k)
   \ge k!A_k\ge A_0,
   \]
   and
   \[
   \boxed{
   \log A_0
   =\sum_{r=R+1}^{2R}\log b_r
   =\frac32\log(17+12\sqrt2)R^2+O(R\log R).
   }
   \tag{V6}
   \]
   The same positivity holds for ordinary divided differences at nonnegative nodes. Conversely, cancelling only \(k=o(R)\) top degree layers leaves a coefficient \(A_{R-k}\) of logarithmic size \(3\log(17+12\sqrt2)R^2-o(R^2)\). Thus the canonical finite-difference/Vandermonde certificates remain quadratic-height.

6. Resultants and discriminants have the same homogeneity barrier:
   \[
   \operatorname{Res}(D_R,P_S)
   =C_R^M\operatorname{Res}(H_R,P_S),
   \qquad P_S(Y)=\prod_{y\in S}(Y-y),
   \tag{V7}
   \]
   but its logarithmic height is \(\Theta(MR^2)\); and
   \[
   \operatorname{Disc}(D_R)=C_R^{2R-2}\operatorname{Disc}(H_R),
   \tag{V8}
   \]
   while the direct determinant height is \(O(R^3)\). Dividing by the content exponent returns only \(O(R^2)\). A homogeneous invariant of degree \(e\) cannot improve this by degree amplification alone: generic height grows as \(eR^2\) at the same time as the content exponent grows as \(e\).

7. There is, however, a **precise sufficient passport theorem** that would make a slowly growing slope set work for the *false factor*. If the pair congruences (V3) can be replaced by exact integers \(T_{r,s}(d)\) with the same p-adic implication but with **local transition height**
   \[
   \log|T_{r,s}(d)|\ll (|r-s|+1)\log R,
   \tag{V9}
   \]
   then taking \(M=\lceil R^{2/3}\rceil\) consecutive slopes yields
   \[
   \boxed{
   \log [G_{R,S}/C_R]_{>2R}
   \ll R^{5/3}\log R=o(R^2)
   }
   \tag{V10}
   \]
   with **full valuations**, not just radicals. I prove this below. The current obvious certificate \(K_{r,s}(d)\) does not have (V9): the term \(dc_rc_s\) has logarithmic size \(\Theta(R)\) even when \(|r-s|=1\). Producing a p-unit descaling that turns this global \(\Theta(R)\) height into local \(O(|r-s|\log R)\) height is the concrete new theorem exposed by the passport.

8. Even (V10) would only prove that the finite-slope gcd is a faithful approximation to the row content; it would **not** prove (BFH), because of the exact scale obstruction in item 4. For (BFH), one still needs a scale-sensitive small-height object. A sufficient theorem is the cross-pole-order saturation theorem already isolated by the level-6 Eichler audit: construct a functorial finite quotient \(\mathcal Q_R\), before taking row gcds, such that for all \(p>2R\)
   \[
   \sum_{r\in I_R}v_p(g_r)
   \le \operatorname{length}_{\mathbf Z_p}(\mathcal Q_R\otimes\mathbf Z_p),
   \qquad
   \log|\mathcal Q_R|=o(R^2).
   \tag{V11}
   \]
   Equivalently, a direct small-height Bezout certificate
   \[
   0\ne B_R=\sum_{y\in S_R}A_{R,y}D_R(y),
   \qquad \log|B_R|=o(R^2),
   \tag{V12}
   \]
   would suffice because \(C_R\mid B_R\). The new passport analysis says exactly what cannot produce such a certificate: projective incidence by itself, ordinary resultants/discriminants, and canonical finite-difference/Vandermonde elimination.

9. The locked \(p=4013\), \(R=1024\) example is exactly the six-consecutive-slope obstruction:
   \[
   S_6=\{-2,-1,0,1,2,3\}.
   \]
   The six listed roots are distinct rows, so \(4013\mid G_{R,S_6}/C_R\). They generate all \(\binom62=15\) pair congruences (V3), but only the ten signed differences \(\pm1,\ldots,\pm5\). For every pair of these six witness rows the **raw** projective determinant is a 4013-unit, because the slopes are distinct. Thus this is coverage, not a collision. Enlarging to
   \[
   S_8=\{-3,-2,-1,0,1,2,3,4\}
   \]
   clears 4013 exactly as stated in the prompt. This is finite data; no asymptotic conclusion is drawn from it.

So the answer is a scoped no-go plus a concrete next theorem: **multi-slope coverage is a real valuation-level purifier, but it is scale-blind. Its present pair/resultant height is quadratic or worse. To make slowly growing slopes genuinely subquadratic one needs a local-height transition certificate; to prove BFH one additionally needs a scale-sensitive cross-pole saturation/Bezout identity.**

# 1. Primitive factorization: target scale versus false projective passport

Put

\[
g_r:=\gcd(b_r,\Xi_r)>0,
\qquad
(a_r,c_r):=(b_r/g_r,\Xi_r/g_r).
\tag{1.1}
\]

Then \(\gcd(a_r,c_r)=1\) and Gauss's lemma gives

\[
C_R=\prod_{r\in I_R}g_r.
\tag{1.2}
\]

Factor rowwise:

\[
D_R(Y)
=C_RH_R(Y),
\qquad
H_R(Y)=\prod_{r\in I_R}\ell_r(Y),
\qquad
\ell_r(Y)=a_r+Yc_r.
\tag{1.3}
\]

Since \(C_R\) is independent of \(y\),

\[
\begin{aligned}
G_{R,S}
&=\gcd_{y\in S}D_R(y)\\
&=C_R\gcd_{y\in S}H_R(y).
\end{aligned}
\]

Thus

\[
\boxed{
E_{R,S}:=G_{R,S}/C_R
=\gcd_{y\in S}H_R(y).
}
\tag{1.4}
\]

This identity is exact over \(\mathbf Z\), before choosing a prime.

It is conceptually decisive: **all common-row scale has been factored into \(C_R\); all multi-slope false factors live in the primitive split polynomial \(H_R\).**

## 1.1 One primitive row has at most one finite root

Let \(p>\operatorname{diam}S\). Suppose

\[
p\mid\ell_r(y),\qquad p\mid\ell_r(z)
\]

for two distinct \(y,z\in S\). Subtracting gives

\[
p\mid (y-z)c_r.
\]

If \(p\mid c_r\), then \(p\mid a_r\) as well, contradicting \(\gcd(a_r,c_r)=1\). Hence \(c_r\) is a p-unit, so \(p\mid y-z\). But

\[
0<|y-z|<p,
\]

impossible. Therefore a primitive row has at most one root in \(S\pmod p\).

This argument also covers rows with \(p\mid c_r\): they have no finite root at all, because then \(a_r\) is a unit.

## 1.2 Exact valuation formula

For a prime \(p\), write

\[
e_p(y):=v_p(H_R(y))
=\sum_{r\in I_R}v_p(a_r+yc_r).
\tag{1.5}
\]

By definition of an integer gcd,

\[
\boxed{
v_p(E_{R,S})=\min_{y\in S}e_p(y).}
\tag{1.6}
\]

So if

\[
t:=v_p(E_{R,S})>0,
\]

then **every** slope \(y\in S\) has total noncommon p-adic root weight at least \(t\).

For the radical, this immediately implies at least \(|S|\) distinct root rows. For valuations, think of row \(r\) at slope \(y\) as supplying

\[
v_p(a_r+yc_r)
\]

copies of a token. Every slope has at least \(t\) tokens. Since one row can occur at only one slope, each token layer contains \(|S|\) distinct rows.

This token formulation is what makes the pair argument below retain full valuations.

# 2. Consecutive slopes: an exact pair-certificate load theorem

Let

\[
S=\{A,A+1,\dots,A+M-1\},
\qquad 2\le M\le R.
\tag{2.1}
\]

For ordered row/slope pairs define

\[
K_{r,s}(d)
:=a_rc_s-a_sc_r-dc_rc_s,
\qquad d\in\mathbf Z\setminus\{0\}.
\tag{2.2}
\]

Suppose row \(r\) is a root at slope \(y\) and row \(s\) is a root at slope \(z\), with

\[
d=z-y.
\]

Then the key identity is not merely a congruence:

\[
\boxed{
K_{r,s}(d)
=(a_r+yc_r)c_s-(a_s+zc_s)c_r.
}
\tag{2.3}
\]

At a prime \(p>\operatorname{diam}S\), both \(c_r,c_s\) are p-units whenever the corresponding rows have finite roots. Hence

\[
\boxed{
 v_p(K_{r,s}(d))
 \ge
 \min\{v_p(a_r+yc_r),v_p(a_s+zc_s)\}.
}
\tag{2.4}
\]

This is the valuation transfer needed below.

## 2.1 Nonvanishing over the integers

Set the rational projective slope

\[
x_r:=-a_r/c_r=-b_r/\Xi_r.
\tag{2.5}
\]

Then

\[
\frac{K_{r,s}(d)}{c_rc_s}
=x_s-x_r-d.
\tag{2.6}
\]

By (0.8), uniformly for \(r\in I_R\),

\[
|x_r|\to0
\]

exponentially as \(R\to\infty\). Thus for all sufficiently large \(R\),

\[
|x_r|<1/4
\qquad(r\in I_R).
\]

Consequently

\[
|x_s-x_r|<1/2,
\]

so it cannot equal a nonzero integer \(d\). Therefore

\[
\boxed{K_{r,s}(d)\ne0}
\tag{2.7}
\]

for every \(r,s\in I_R\), \(r\ne s\), and every nonzero integer \(d\), once \(R\) is large enough.

This removes the zero-certificate loophole without appealing to finite data.

## 2.2 Valuation-layer counting

Fix \(p>2R\), so in particular \(p>M\), and let

\[
t=v_p(E_{R,S}).
\]

For each \(y\in S\), list row \(r\) exactly

\[
v_p(a_r+yc_r)
\]

times. There are at least \(t\) entries in every slope-list. Choose \(t\) entries from each list and arrange them into \(t\) layers.

In one layer, there is one row for every slope and all \(M\) rows are distinct. Pair every two slopes. This gives \(\binom M2\) row-pairs in that layer. Across all \(t\) layers this gives

\[
t\binom M2
\]

pair incidences.

If the same row-pair with the same signed slope difference \(d\) occurs in several layers, its multiplicity is at most the minimum of the two row-root valuations. By (2.4), that multiplicity is at most \(v_p(K_{r,s}(d))\). Therefore

\[
\boxed{
\binom M2\,v_p(E_{R,S})
\le
\sum_{R<r<s\le2R}
\sum_{0<|d|<M}
 v_p(K_{r,s}(d)).
}
\tag{2.8}
\]

Notice the compression specific to consecutive slopes: there are \(\binom M2\) slope-pairs, but only

\[
2(M-1)
\]

possible signed differences.

Equation (2.8) is a genuine valuation theorem; it is not a radical-only occupancy statement.

## 2.3 Archimedean height and the \(R^3/M\) barrier

The primitive coordinates are no larger than the original ones:

\[
|a_r|\le b_r,
\qquad
|c_r|\le|\Xi_r|.
\]

By (0.7), for \(r,s\le2R\) and \(|d|<M\le R\),

\[
\begin{aligned}
\log|K_{r,s}(d)|
&\le
\log\bigl(|a_rc_s|+|a_sc_r|+|d||c_rc_s|\bigr)\\
&\le 8R\log\lambda+O(\log R).
\end{aligned}
\tag{2.9}
\]

Multiply (2.8) by \(\log p\) and sum over all \(p>2R\). Since every \(K_{r,s}(d)\ne0\),

\[
\sum_{p>2R}v_p(K_{r,s}(d))\log p
\le\log|K_{r,s}(d)|.
\]

Hence

\[
\binom M2\log[E_{R,S}]_{>2R}
\le
\binom R2\,2(M-1)
\bigl(8R\log\lambda+O(\log R)\bigr).
\]

Cancelling \(M-1\) gives the explicit form

\[
\boxed{
\log[E_{R,S}]_{>2R}
\le
\frac{16\log\lambda+o(1)}{M}R^3.
}
\tag{2.10}
\]

Thus

\[
\log[E_{R,S}]_{>2R}\ll R^3/M.
\]

This is the strongest unconditional theorem I can extract from the elementary pair-difference certificate.

For \(M=o(R)\), however,

\[
R^3/M\not=o(R^2).
\]

So the pair-load amplification does not close even the false-factor problem in the slowly-growing-slope regime.

# 3. The one-polynomial/Vandermonde detector is exactly quadratic

There is a more compressed way to encode the same coverage.

Let

\[
P_S(Y)=\prod_{y\in S}(Y-y).
\tag{3.1}
\]

For \(p>M\), an extra passport prime has every \(y\in S\) as a root of \(H_R\pmod p\), so

\[
P_S(Y)\mid H_R(Y)\pmod p.
\]

Equivalently, \(p\) divides every coefficient of the remainder of \(H_R\) modulo \(P_S\). The scalar resultant is

\[
\operatorname{Res}(H_R,P_S)
=\prod_{y\in S}H_R(y).
\tag{3.2}
\]

At valuation level,

\[
M\,v_p(E_{R,S})
\le v_p\operatorname{Res}(H_R,P_S).
\tag{3.3}
\]

This looks like a gain of \(M\), but the binary form detecting \(S\) necessarily has degree \(M\). Indeed, over any \(\mathbf F_p\) with \(p>M\), a nonzero polynomial of degree \(<M\) cannot vanish at all \(M\) distinct slopes. The degree cost and root-load gain therefore scale together.

Using

\[
\operatorname{Res}(D_R,P_S)
=C_R^M\operatorname{Res}(H_R,P_S)
=\prod_{y\in S}D_R(y),
\tag{3.4}
\]

and the theorem-level sizes (0.7), each fixed polynomial-size slope evaluation has logarithmic size \(\Theta(R^2)\). Hence

\[
\log|\operatorname{Res}(D_R,P_S)|=\Theta(MR^2)
\]

for the natural fixed/polynomial-size slope ranges. Dividing by the content exponent \(M\) gives only a quadratic estimate.

This is the exact integer-height obstruction requested in the prompt: **a degree-\(M\) root detector costs \(M\) copies of a quadratic-height block.**

# 4. A theorem-level finite-difference/Vandermonde no-go in the natural one-sided category

The CM asymptotic gives more than an upper-bound barrier. It rules out the canonical finite-difference cancellation mechanism outright.

From (0.6), \(\Xi_r<0\) for all sufficiently large \(r\). Put

\[
F_R(Z):=D_R(-Z)
=\prod_{r\in I_R}(b_r+Z|\Xi_r|)
=\sum_{k=0}^R A_kZ^k.
\tag{4.1}
\]

Every \(A_k\) is positive. Moreover \(|\Xi_r|>b_r\) for all large \(r\), so

\[
A_k\ge A_0
\qquad(0\le k\le R),
\tag{4.2}
\]

where

\[
A_0=\prod_{r\in I_R}b_r.
\]

Using (0.4),

\[
\boxed{
\log A_0
=\frac32\log\lambda\,R^2+O(R\log R).
}
\tag{4.3}
\]

## 4.1 Forward differences

For the ordinary forward difference,

\[
\Delta^k Z^m\big|_{Z=0}=k!\,S(m,k),
\]

where \(S(m,k)\) is a Stirling number of the second kind. Therefore

\[
\Delta^kF_R(0)
=k!\sum_{m=k}^R A_mS(m,k).
\]

All terms are nonnegative and the \(m=k\) term is \(k!A_k\). Hence

\[
\boxed{
\Delta^kF_R(0)\ge k!A_k\ge A_0.
}
\tag{4.4}
\]

Thus every canonical finite-difference Bezout combination of the values

\[
D_R(0),D_R(-1),\dots,D_R(-k)
\]

has logarithmic height at least

\[
\frac32\log\lambda\,R^2+O(R\log R).
\]

Increasing \(k\) slowly does not help.

## 4.2 General nonnegative-node divided differences

For distinct nonnegative nodes \(z_0,\dots,z_k\), the divided difference of a monomial satisfies

\[
[z_0,\dots,z_k]Z^m
=h_{m-k}(z_0,\dots,z_k)\ge0,
\]

with \(h_0=1\). Therefore

\[
[z_0,\dots,z_k]F_R
=\sum_{m=k}^R A_mh_{m-k}(z_0,\dots,z_k)
\ge A_k\ge A_0.
\tag{4.5}
\]

Multiplying by the Vandermonde denominator to obtain an integral linear combination of the evaluations only increases the absolute size. So the ordinary nonnegative-node Vandermonde interpolation certificate is also quadratically large.

## 4.3 Cancelling the top instead of the bottom

One can reverse the polynomial and try to annihilate its top degree layers. But

\[
A_{R-k}
\ge
\left(\prod_{r\in I_R}|\Xi_r|\right)
\exp(-O(kR))
\]

because replacing \(|\Xi_r|\) by \(b_r\) in only \(k\) rows loses at most \(O(kR)\) in logarithmic height. By (0.7),

\[
\sum_{r\in I_R}\log|\Xi_r|
=3\log\lambda\,R^2+O(R\log R).
\]

Hence, for \(k=o(R)\),

\[
\boxed{
\log A_{R-k}
\ge3\log\lambda\,R^2-o(R^2).
}
\tag{4.6}
\]

So a Vandermonde functional that merely kills \(o(R)\) top layers still leaves a quadratic-height coefficient.

This is a **scoped** no-go. It does not prove that an arbitrary signed, Apéry-specific Bezout combination cannot exhibit a miraculous cross-layer cancellation. It proves that ordinary finite differences, divided differences, and moment-annihilation of only \(o(R)\) degree layers cannot be that miracle.

# 5. Discriminants: good logical purifier, wrong height scale

For a split polynomial

\[
D_R(Y)=\prod_r(b_r+Y\Xi_r),
\]

the discriminant is

\[
\boxed{
\operatorname{Disc}(D_R)
=\prod_{r<s}(b_r\Xi_s-b_s\Xi_r)^2.
}
\tag{5.1}
\]

After primitive factorization,

\[
\boxed{
\operatorname{Disc}(D_R)
=C_R^{2R-2}\operatorname{Disc}(H_R).
}
\tag{5.2}
\]

A prime dividing \(\operatorname{Disc}(H_R)\) is a projective **collision** prime: two primitive rows have the same slope modulo \(p\). That is logically different from the multi-slope coverage condition. In particular, two witness rows for distinct slopes \(y\ne z\) satisfy

\[
a_rc_s-a_sc_r
\equiv(z-y)c_rc_s\not\equiv0\pmod p.
\tag{5.3}
\]

Thus intersecting a multi-slope gcd with a discriminant can kill coverage-only false factors such as the six-row 4013 witness configuration, provided there is no independent collision elsewhere in the block.

But the height ratio does not improve automatically. By (0.7), each determinant in (5.1) has logarithmic size \(O(R)\), and there are \(\Theta(R^2)\) pairs. Therefore

\[
\log|\operatorname{Disc}(D_R)|=O(R^3).
\tag{5.4}
\]

Since the content exponent in (5.2) is only \(2R-2\), this gives at best

\[
\log C_R=O(R^2).
\]

So discriminants provide a better **false-prime predicate**, but not the required scale saving.

The same conclusion holds for ordinary resultants with shifts or derivatives: their homogeneity exponent in the row scale grows in lockstep with the generic archimedean height unless an additional Apéry-specific cancellation is proved.

# 6. Exact scale-invariance no-go for projective-only arguments

This is the strongest conceptual obstruction and should be kept separate from all height estimates.

Fix any primitive integer pairs

\[
(a_r,c_r),\qquad\gcd(a_r,c_r)=1.
\]

For arbitrary positive integers \(q_r\), set

\[
b_r'=q_ra_r,
\qquad
\Xi_r'=q_rc_r.
\tag{6.1}
\]

Then

\[
C_R'=\prod_r q_r,
\tag{6.2}
\]

but

\[
\frac{D_R'(Y)}{C_R'}
=\prod_r(a_r+Yc_r)
=H_R(Y).
\tag{6.3}
\]

Therefore, for **every** finite slope set \(S\),

\[
\boxed{
\frac{G'_{R,S}}{C_R'}
=\gcd_{y\in S}H_R(y)
}
\tag{6.4}
\]

is independent of all the scales \(q_r\).

Equivalently, every noncommon projective slope and every false-passport valuation is unchanged, while \(C_R'\) can be made arbitrarily large by choosing large fresh primes in the \(q_r\).

Hence:

> **Projective-scale no-go.** No theorem whose hypotheses and conclusion use only the primitive projective points \([a_r:c_r]\), their reductions modulo \(p\), slope-cover counts, collision counts, large-sieve energies of those points, or the quotients \(G_{R,S}/C_R\) can, by itself, upper-bound \(C_R\) in a general row-factor system.

For Apéry, the pairs are not freely rescalable; they come from the fixed recurrence/Eichler structure. That is exactly why the missing theorem must use the **integral scale coupling across different rows**. The passport is useful only after such a scale-sensitive input has entered.

This also explains why the finite fact

```text
fresh common rows through r=10000:
(17,13), (2237,492)
```

cannot be promoted to an asymptotic statement by projective arguments: the scan is evidence about the actual row scales, while the projective passport has divided those scales out.

# 7. The concrete theorem that would make slowly growing slopes subquadratic

Although the existing \(K_{r,s}(d)\) is too tall, the valuation-layer proof tells us exactly what stronger certificate is sufficient.

## Short-transition passport theorem (sufficient condition)

Let

\[
S=\{A,A+1,\dots,A+M-1\},
\qquad M\le R,
\]

and let \(H_R=\prod\ell_r\) be the primitive polynomial above.

Assume there is a constant \(A_0>0\) and, for every

\[
R<r<s\le2R,
\qquad 0<|d|<M,
\]

a nonzero integer \(T_{r,s}(d)\) satisfying:

**(T1) p-adic transfer.** For every prime \(p>2R\), every \(y,z\in S\) with \(z-y=d\), if

\[
p\mid\ell_r(y),\qquad p\mid\ell_s(z),
\]

then

\[
 v_p(T_{r,s}(d))
 \ge
 \min\{v_p(\ell_r(y)),v_p(\ell_s(z))\}.
\tag{7.1}
\]

**(T2) local transition height.** Uniformly,

\[
\boxed{
\log|T_{r,s}(d)|
\le A_0(|r-s|+1)\log R.
}
\tag{7.2}
\]

Then, for

\[
M=\lceil R^{2/3}\rceil,
\]

one has

\[
\boxed{
\log [E_{R,S}]_{>2R}
=O_{A_0}(R^{5/3}\log R)
=o(R^2).
}
\tag{7.3}
\]

This controls full p-adic valuations.

### Proof

Set

\[
L=\left\lceil\frac{4R}{M}\right\rceil.
\tag{7.4}
\]

Partition the \(R\) row indices in \(I_R\) into

\[
q=\lceil R/L\rceil
\]

consecutive bins of length at most \(L\).

Fix \(p>2R\) and put

\[
t=v_p(E_{R,S}).
\]

As in section 2, make \(t\) token layers, each with one distinct root row for every one of the \(M\) slopes.

In one layer, let \(m_j\) be the number of chosen rows in bin \(j\). Then

\[
\sum_jm_j=M.
\]

The number of pairs in the same bin is

\[
\sum_j\binom{m_j}{2}
=\frac12\left(\sum_jm_j^2-M\right)
\ge
\frac12\left(\frac{M^2}{q}-M\right)
=:Q.
\tag{7.5}
\]

Every such pair has row gap \(<L\).

Because \(L\ge4R/M\),

\[
q\le M/4+1.
\]

For \(M\ge8\), this implies \(q\le3M/8\), hence

\[
Q\ge\frac56M.
\tag{7.6}
\]

Across all \(t\) layers there are therefore at least \(Qt\) close-pair incidences. The same multiplicity argument as in section 2, now using (T1), gives

\[
Qv_p(E_{R,S})
\le
\sum_{\substack{R<r<s\le2R\\s-r<L}}
\sum_{0<|d|<M}
 v_p(T_{r,s}(d)).
\tag{7.7}
\]

Sum over \(p>2R\) with weight \(\log p\). There are at most \(RL\) row pairs with gap \(<L\), at most \(2M\) signed differences, and by (T2) every certificate has

\[
\log|T_{r,s}(d)|\le A_0(L+1)\log R.
\]

Therefore

\[
Q\log[E_{R,S}]_{>2R}
\le
2A_0RLM(L+1)\log R.
\]

Using \(Q\ge5M/6\),

\[
\log[E_{R,S}]_{>2R}
\le
\frac{12A_0}{5}RL(L+1)\log R.
\]

Since

\[
L\asymp R/M,
\]

we obtain

\[
\boxed{
\log[E_{R,S}]_{>2R}
\ll A_0\frac{R^3\log R}{M^2}.
}
\tag{7.8}
\]

Taking \(M=\lceil R^{2/3}\rceil\) gives (7.3). QED.

## 7.1 Why the obvious certificate misses (T2)

For the exact certificate (2.2),

\[
K_{r,s}(d)=a_rc_s-a_sc_r-dc_rc_s.
\]

Even when \(s=r+1\), the last term has

\[
\log|dc_rc_s|=\Theta(R)
\]

for polynomial-size \(d\), because \(|c_r|\) is at most the exponentially large \(|\Xi_r|\) and no theorem gives a p-safe cancellation of that scale.

Thus the current certificate has a **global row-height** \(O(R)\), not a **local transition height** \(O((s-r)\log R)\).

What would prove (T2)? One needs an exact Apéry/Eichler normalization which divides out the exponential row scales by quantities that are guaranteed p-units at every noncommon root prime, while retaining the valuation implication (T1). A mere rational normalization by \(c_rc_s\) is not enough: although it is a p-unit at the particular root prime, the reduced numerator of

\[
(x_s-x_r)-d
\]

still generically has logarithmic height \(\Theta(R)\).

So (T2) is not a cosmetic improvement of (2.9); it is a real new arithmetic theorem.

# 8. Why even the short-transition theorem would not yet prove BFH

Suppose (7.3) were proved. Then for the chosen slowly growing interval,

\[
G_{R,S}=C_RE_{R,S}
\]

with

\[
\log[E_{R,S}]_{>2R}=o(R^2).
\]

This says the multi-slope gcd is a faithful fresh-prime **detector** for \(C_R\), up to a subquadratic false factor.

It still gives no upper bound on \(C_R\). The equality

\[
\log G_{R,S}
=\log C_R+\log E_{R,S}
\]

does not help if the only archimedean bound on \(G_{R,S}\) is \(\Theta(R^2)\).

The scale-invariance theorem in section 6 proves that this is not fixable by strengthening the projective load theorem alone.

The remaining sufficient theorem must be scale-sensitive.

## 8.1 One exact sufficient theorem: cross-pole saturation

The level-6 audit in Q7672 identifies the natural form.

Let

\[
W_M=\bigoplus_{m=0}^M\mathbf Z\Omega_m,
\qquad
\Omega_m=EHt^{-m},
\]

and let the fixed functionals be

\[
\ell_0(f)=\operatorname{CT}f,
\qquad
\ell_1(f)=\operatorname{CT}(Uf),
\]

so that

\[
b_r=\ell_0(\Omega_r),
\qquad
\kappa_r=\ell_1(\Omega_r),
\]

and \(\Xi_r\) is the adjacent Pluecker coordinate of these two evaluations.

A sufficient theorem for BFH is:

> **Cross-pole saturation theorem.** Construct, functorially from the integral principal-part block \(W_{2R}/W_R\) and the fixed level-6 Eisenstein-Eichler class, a finite abelian group \(\mathcal Q_R\), without first inserting the row gcds, such that for every \(p>2R\)
> \[
> \sum_{r\in I_R}v_p\gcd(b_r,\Xi_r)
> \le
> \operatorname{length}_{\mathbf Z_p}(\mathcal Q_R\otimes\mathbf Z_p),
> \tag{8.1}
> \]
> and
> \[
> \boxed{\log|\mathcal Q_R|=o(R^2).}
> \tag{8.2}
> \]

Then

\[
\begin{aligned}
\log[C_R]_{>2R}
&=\sum_{p>2R}\log p\sum_{r\in I_R}v_p(g_r)\\
&\le\sum_{p>2R}\log p\,
\operatorname{length}_{\mathbf Z_p}(\mathcal Q_R\otimes\mathbf Z_p)\\
&\le\log|\mathcal Q_R|\\
&=o(R^2).
\end{aligned}
\]

This is scale-sensitive and therefore escapes the no-go in section 6.

Q7672 also explains why the standard fixed-dimensional Manin-symbol/SNF object does not furnish \(\mathcal Q_R\): a fresh target is a **zero labelled column**, which need not cause a rank drop of the global \(2\times R\) evaluation matrix. Keeping the labels by direct sum recovers exactly \(C_R\), with no compression. A new cross-pole-order identity is required.

## 8.2 Equivalent Bezout target

A more elementary sufficient statement is: find a deterministic slope set \(S_R\) and integers \(A_{R,y}\), produced without knowing/factoring \(C_R\), such that

\[
B_R:=\sum_{y\in S_R}A_{R,y}D_R(y)\ne0
\]

and

\[
\boxed{\log|B_R|=o(R^2).}
\tag{8.3}
\]

Since every \(D_R(y)\) is divisible by \(C_R\),

\[
C_R\mid B_R,
\]

and BFH follows immediately.

Sections 3--5 show that ordinary resultant/discriminant homogeneity and canonical Vandermonde elimination do not produce such a \(B_R\). The modular/Eichler structure has to supply an actual cross-row cancellation, not merely a different encoding of the same projective roots.

# 9. Large-sieve interpretation

The primitive points are

\[
\mathcal X_R(p)
=\left\{-a_rc_r^{-1}:r\in I_R,\ c_r\not\equiv0\pmod p\right\}
\subset\mathbf F_p.
\]

For \(p>2R\) and \(|S|=M<p\), an extra passport prime satisfies

\[
S\subset\mathcal X_R(p).
\]

The pair theorem is a deterministic larger-sieve analogue: every embedded copy of the interval \(S\) contributes \(\binom M2\) prescribed difference congruences, while the difference alphabet has only \(O(M)\) values.

But a standard projective large sieve can only control the primitive quotient \(E_{R,S}\). It is invariant under the row rescalings in section 6. Therefore even a perfect theorem of the form

\[
\log[E_{R,S_R}]_{>2R}=o(R^2)
\]

would be a **purification theorem**, not BFH.

A large-sieve route to BFH would have to incorporate a scale weight that changes under

\[
(a_r,c_r)\mapsto(q_ra_r,q_rc_r),
\]

for example an integral cross-pole covolume or a p-adic length attached to the actual level-6 principal-part lattice. That is essentially the saturation theorem (8.1)--(8.2), not an ordinary projective-point large sieve.

# 10. The locked \(p=4013\) example

For

\[
R=1024,
\qquad p=4013>2R,
\]

the six-slope set in the prompt is, after sorting,

\[
S_6=\{-2,-1,0,1,2,3\}.
\]

The supplied exact roots are

\[
\begin{array}{c|c}
y&r\\\hline
-2&1451\\
-1&1594\\
0&1866\\
1&1961\\
2&1025\\
3&1274
\end{array}
\tag{10.1}
\]

and all six rows are noncommon for 4013. Therefore

\[
4013\mid E_{1024,S_6}.
\]

For any two witnesses \((r,y)\), \((s,z)\),

\[
a_rc_s-a_sc_r
\equiv(z-y)c_rc_s\pmod{4013}.
\]

Because

\[
0<|z-y|\le5<4013
\]

and the root rows have \(c_r,c_s\) as 4013-units,

\[
\boxed{
4013\nmid a_rc_s-a_sc_r
}
\tag{10.2}
\]

for every pair among the six witnesses. Thus the six-point witness is **not an internal projective collision**.

On the other hand,

\[
K_{r,s}(z-y)
=(a_r+yc_r)c_s-(a_s+zc_s)c_r
\equiv0\pmod{4013},
\]

so all

\[
\binom62=15
\]

pair certificates are divisible by 4013. They use only the ten signed differences

\[
\pm1,\pm2,\pm3,\pm4,\pm5.
\]

This is exactly the combinatorial amplification in (2.8).

Adding the two endpoint slopes gives

\[
S_8=\{-3,-2,-1,0,1,2,3,4\}.
\]

The prompt's exact computation says 4013 no longer divides the gcd over these eight evaluations. Equivalently,

\[
\min_{y\in S_8}
\sum_{r\in I_R}v_{4013}(a_r+yc_r)=0.
\]

This is a perfect finite illustration of the theorem and of its limitation: six prescribed residues can be covered by six distinct projective points, while two more slopes destroy the cover. Nothing in this finite event bounds the scale factors \(g_r\) asymptotically.

# 11. Deterministic slowly growing slope set and computational cost

A natural deterministic choice for experiments is

\[
m_R=\left\lceil\frac12R^{2/3}\right\rceil,
\qquad
S_R=\{-m_R,-m_R+1,\dots,m_R\}.
\tag{11.1}
\]

Then

\[
M_R=|S_R|=R^{2/3}+O(1)=o(R),
\]

and for every fresh prime \(p>2R\),

\[
M_R<p,
\qquad
\operatorname{diam}S_R<p.
\]

The slopes have \(O(\log R)\) bit length. From (0.7), each row factor

\[
b_r+y\Xi_r
\]

has \(O(R)\) bit length for \(|y|\le R^{O(1)}\), and each product \(D_R(y)\) has \(O(R^2)\) bit length. Computing \(M_R\) such evaluations by exact integer product trees is polynomial-time in \(R\) in the ordinary bit model. Thus this choice meets the requested polynomial/subexponential evaluation-cost condition.

It also contains \(-3,4\) for \(R=1024\), so it necessarily clears the locked 4013 false factor once the exact S8 fact is known.

What is missing is not computational feasibility; it is theorem (7.2), followed by a scale-sensitive theorem such as (8.1)--(8.2) or (8.3).

# 12. Exact Sage verifier for the 4013 passport

The following script recomputes \(b_n\), the exact Green coefficients \(g_n\), and \(\Xi_n\) from the theorem-level generating function. It then checks the six supplied roots, verifies that the witness-pair determinants are 4013-units while the pair-difference certificates vanish modulo 4013, computes the actual extra p-adic valuation of the finite-slope gcd, and verifies that adding \(-3,4\) clears 4013.

It does **not** infer any asymptotic statement from the output.

```sage
# Run with: sage q7683_passport_4013.sage
from sage.all import *
from itertools import combinations
from collections import defaultdict


def P(n):
    n = ZZ(n)
    return 34*n**3 + 51*n**2 + 27*n + 5


def apery_numbers(N):
    b = [ZZ(1), ZZ(5)]
    for n in range(2, N + 1):
        num = P(n - 1)*b[n - 1] - ZZ(n - 1)**3*b[n - 2]
        den = ZZ(n)**3
        assert num % den == 0
        b.append(num // den)
    return b[:N + 1]


def transverse_xi(N, b):
    # Q7672/Q7669 exact identity:
    #   C(t)=1/(F(t)^2*sqrt(1-34t+t^2)) = sum g_n t^n
    #   Xi_n = -1 - 5*sum_{j=1}^n g_j b_{j-1}.
    PS = PowerSeriesRing(QQ, 't', default_prec=N + 2)
    t = PS.gen()
    F = PS([QQ(x) for x in b])
    Delta = PS(1 - 34*t + t**2)
    Cser = 1 / (F**2 * Delta.sqrt())

    g = []
    for n in range(N + 1):
        q = QQ(Cser[n])
        assert q.denominator() == 1, (n, q)
        g.append(ZZ(q))

    Xi = [ZZ(-1)]*(N + 1)
    cur = ZZ(-1)
    for n in range(1, N + 1):
        cur -= 5*g[n]*b[n - 1]
        Xi[n] = cur

    # Normalization check: Xi_1 = b_0*kappa_1 = -36.
    assert Xi[1] == -36
    return g, Xi


def vp_nonzero(n, p):
    n = ZZ(n)
    if n == 0:
        raise ValueError("exact zero encountered; handle separately")
    n = abs(n)
    e = 0
    while n % p == 0:
        n //= p
        e += 1
    return e


def primitive_row(r, b, Xi):
    gr = gcd(b[r], Xi[r])
    return ZZ(b[r] // gr), ZZ(Xi[r] // gr), ZZ(gr)


def root_mod_p(r, p, b, Xi):
    a, c, _ = primitive_row(r, b, Xi)
    if c % p == 0:
        # gcd(a,c)=1, so then a is a unit and there is no finite root.
        assert a % p != 0
        return None
    return ZZ((-a * inverse_mod(c, p)) % p)


def rows_for_slope(R, p, y, b, Xi):
    yy = ZZ(y) % p
    return [r for r in range(R + 1, 2*R + 1)
            if root_mod_p(r, p, b, Xi) == yy]


def common_vp(R, p, b, Xi):
    ans = 0
    for r in range(R + 1, 2*R + 1):
        _, _, gr = primitive_row(r, b, Xi)
        ans += vp_nonzero(gr, p)
    return ans


def extra_vp(R, p, S, b, Xi):
    # v_p(E_{R,S}) for E=G/C, computed from primitive rows.
    vals = []
    for y in S:
        ey = 0
        for r in range(R + 1, 2*R + 1):
            a, c, _ = primitive_row(r, b, Xi)
            val = a + ZZ(y)*c
            if val == 0:
                raise ValueError(("exact integer slope root", r, y))
            ey += vp_nonzero(val, p)
        vals.append(ey)
    return min(vals), vals


R = 1024
p = 4013
N = 2*R
b = apery_numbers(N)
g, Xi = transverse_xi(N, b)

expected = {
     0: [1866],
     1: [1961],
    -1: [1594],
     2: [1025],
    -2: [1451],
     3: [1274],
}

S6 = [0, 1, -1, 2, -2, 3]
S8 = [0, 1, -1, 2, -2, 3, -3, 4]

print("checking supplied roots")
for y in S6:
    got = rows_for_slope(R, p, y, b, Xi)
    print("y =", y, "rows =", got)
    assert got == expected[y]

cv = common_vp(R, p, b, Xi)
print("v_p(C_R) at p=4013:", cv)
assert cv == 0

e6, vals6 = extra_vp(R, p, S6, b, Xi)
print("per-slope v_p(H_R(y)) for S6:", dict(zip(S6, vals6)))
print("v_p(G/C) for S6:", e6)
assert e6 >= 1

e8, vals8 = extra_vp(R, p, S8, b, Xi)
print("per-slope v_p(H_R(y)) for S8:", dict(zip(S8, vals8)))
print("v_p(G/C) for S8:", e8)
assert e8 == 0

# Verify the 15 pair certificates and show that none of the raw
# projective determinants is divisible by 4013.
witnesses = [(ZZ(y), expected[y][0]) for y in S6]
for (y, r), (z, s) in combinations(witnesses, 2):
    ar, cr, _ = primitive_row(r, b, Xi)
    ass, cs, _ = primitive_row(s, b, Xi)
    d = z - y

    det = ar*cs - ass*cr
    K = det - d*cr*cs

    assert K % p == 0, (y, r, z, s, d)
    assert det % p != 0, (y, r, z, s, d)

print("all 15 K-certificates vanish mod 4013")
print("all 15 raw witness determinants are 4013-units")

# Optional: inspect every projective collision in the whole block.
buckets = defaultdict(list)
for r in range(R + 1, 2*R + 1):
    x = root_mod_p(r, p, b, Xi)
    if x is not None:
        buckets[int(x)].append(r)

collisions = {x: rs for x, rs in buckets.items() if len(rs) > 1}
print("global projective collisions mod 4013:", collisions)

# A deterministic slowly growing test set containing S8.
m = ceil(R**(QQ(2)/3) / 2)
Sdet = list(range(-ZZ(m), ZZ(m) + 1))
edet, _ = extra_vp(R, p, Sdet, b, Xi)
print("|Sdet| =", len(Sdet), "v_p(G/C) =", edet)
assert edet == 0
```

The `collisions` print is deliberately not asserted: the six supplied witness rows prove only that the locked coverage configuration has no **internal** collision. A separate exact scan is needed to decide whether some other two rows of the block collide modulo 4013.

# 13. What is theorem, what is finite data, and what remains open

### Proved here from landed theorem-level inputs

- Exact primitive factorization \(D_R=C_RH_R\) and \(G/C=\gcd H(y)\).
- Exact valuation formula (1.6).
- One-root-per-primitive-row for \(p>\operatorname{diam}S\).
- Valuation-layer pair inequality (2.8).
- Nonvanishing of the integer pair certificates for all sufficiently large \(R\), using the proved CM asymptotic \(-b_r/\Xi_r\to0\).
- The aggregate pair bound \(\log[E]_{>2R}\ll R^3/M\).
- The finite-difference/divided-difference quadratic-height no-go in the natural one-sided category.
- The exact projective-scale invariance showing that projective passport data alone cannot bound \(C_R\).
- The conditional short-transition theorem: (T1)+(T2) imply \(O(R^{5/3}\log R)\) for the **full-valuation** false factor when \(M=R^{2/3}\).

### Fixed finite data supplied by the question

- Common-row scan through \(r=10000\): only \((17,13)\) and \((2237,492)\) among the stated high pairs; no repeated high prime in that scan.
- Six slopes clear all high false factors through the stated \(R\le512\) experiments.
- At \(R=1024\), \(p=4013\) covers the six rows listed in (10.1).
- Adding slopes \(-3,4\) clears 4013.

None of these finite statements is used to infer an asymptotic.

### Not proved

- The desired BFH theorem \(\log[C_R]_{>2R}=o(R^2)\).
- Any theorem asserting that a fixed or slowly growing slope interval always kills all false high primes.
- The local-height certificate (T2) for the actual Apéry/Eichler projective points.
- A subquadratic scale-sensitive quotient \(\mathcal Q_R\) or a subquadratic Bezout value \(B_R\).
- Any asymptotic consequence of the scan to 10000.

# 14. Recommended mathematical target

The multi-slope passport should be kept, but its role should be narrowed:

\[
\boxed{
\text{passport} = \text{primitive false-factor purifier, not a content bound.}
}
\]

The most concrete next theorem exposed by this audit is the local-height transition statement (T1)--(T2). It is strong enough that the deterministic choice

\[
M_R\asymp R^{2/3}
\]

would force the extra passport factor to have

\[
O(R^{5/3}\log R)
\]

fresh logarithmic mass, valuations included. The locked 4013 example is completely compatible with this: \(M=6\) is far below the asymptotic regime and simply supplies the expected \(15\) pair congruences.

But closing BFH still demands scale-sensitive arithmetic. The level-6 principal-part realization from Q7672 is therefore not optional decoration: it is precisely where the missing row-scale coupling must live. A proof that only sees the reductions of

\[
-b_r/\Xi_r
\]

has already divided out the arithmetic quantity BFH asks us to bound.
