# 2. A denominator-growth inequality for a primitive plateau

For the symmetric radial factor at integer radius `r`, write

```text
raw factor after removing the structural source prime p:
    Rraw_(p,r),

primitive exponent-five cofactor:
    w_(p,r),

exact reduction factor:
    e_(p,r) = Rraw_(p,r)/w_(p,r) in Z_(>0).
```

Thus

```text
Rraw_(p,r)=e_(p,r)*w_(p,r).                        (2.1)
```

Put

```text
A_(p,r)=log Rraw_(p,r),
E_(p,r)=log e_(p,r),
W_(p,r)=log w_(p,r),
```

so

```text
W=A-E.                                             (2.2)
```

The banked raw radial theorem says that successive radius ranks have raw separation greater than `3 log p`.  Let

```text
gamma_p = inf_r (A_(p,r+1)-A_(p,r)).               (2.3)
```

In the banked normalization,

```text
gamma_p > 3*log p.                                 (2.4)
```

Now let

```text
r_1<...<r_m
```

be actual selected radii on one sign.  By (1.6),

```text
r_j-r_i >= 2*(j-i).                                (2.5)
```

Therefore

```text
A_(p,r_j)-A_(p,r_i)
  >= (r_j-r_i)*gamma_p
  > 6*(j-i)*log p.                                 (2.6)
```

Suppose all `m` primitive weights lie in one logarithmic interval of width `H`:

```text
T <= W_(p,r_i) <= T+H.                             (2.7)
```

Then

```text
W_(p,r_m)-W_(p,r_1) <= H.                          (2.8)
```

Subtract (2.8) from (2.6) using `E=A-W`:

```text
E_(p,r_m)-E_(p,r_1)
  > 6*(m-1)*log p - H.                             (2.9)
```

Exponentiating gives

```text
boxed:

e_(p,r_m)/e_(p,r_1)
  > p^(6*(m-1))*exp(-H).                           (2.10)
```

Equivalently,

```text
m
  < 1 + (H+log(e_(p,r_m)/e_(p,r_1)))/(6*log p).   (2.11)
```

This is a clean denominator-growth obstruction to a primitive plateau.  It uses the actual source selectedness exactly once, through the factor-two radius spacing.

### If the banked raw theorem is indexed differently

If the proved `>3 log p` theorem means only that two successive members of the *already admissible* raw list are separated, and it does not count the omitted integer radius between two selected radii, then (2.6) is only

```text
A_(p,r_j)-A_(p,r_i) > 3*(j-i)*log p,
```

and every `6` in (2.9)-(2.11) must be replaced by `3`.  The no-consecutive-zero exclusion of the `53;9,10` fixture remains valid independently.  The verifier below tests whichever literal raw-gap list is supplied by the caller-local routine.

## 2.1 What exponent five still has to prove

Equation (2.10) isolates the exact remaining issue.  A plateau of length `m` can survive only if the primitive reduction factors grow at essentially the same rank rate as the raw determinants.

It would be enough to prove, only on actual selected radii,

```text
log(e_(p,r_j)/e_(p,r_i))
  <= (6-delta)*(j-i)*log p + C*log p               (2.12)
```

for some fixed `delta>0`.  Comparing with (2.9) gives

```text
delta*(m-1)*log p < H+C*log p,                     (2.13)
```

hence

```text
m <= 1 + (H+C*log p)/(delta*log p).                (2.14)
```

For `H=eta log N` and `p~N`, this is `O(1)`.

This is why I regard selected denominator growth, not primitive monotonicity itself, as the weakest useful next lemma.  It asks only that the exponent-five cancellation fail to track the raw `6 log p` selected-rank growth with coefficient one.

The visible Q2124 result proves the universal exponent reduction `7 -> 5`; it does **not** prove (2.12).  A universal exponent bound and a bound on variation of the *actual primitive gcd reduction* are different statements.  The known nonselected inversion is exactly a warning about this distinction.

```text
R_(p,q)
```

```text
eta_(p,q)
```

Now write the exact primitive reduction as


and the fact that every incident source at `q` is an actual selected characteristic, through

```text
product_(q~p) q
```

Each bracket is, by (3.13), already `q` times an actual Apéry quotient.  There is no new common integer whose archimedean height is paid once.

# 4. Nonconsecutive bridges: exact cross-zero law

Suppose a fixed source `p` has actual selected roots

```text
x_1<x_2<...<x_d<c=(p-1)/2
```

on the `p<q` branch.  Let `q_i` be the target attached to `x_i`.  Thus

```text
p*q_i | b_(x_i),
q_i=p+2*(c-x_i)>p>N.                               (4.1)
```

For `i<j` set

```text
h_ij=x_j-x_i,
G_ij=N_(h_ij)(x_i)/p.                              (4.2)
```

The quotient is integral because `p|b_(x_i),b_(x_j)` and every index in the interval is `<p`; equivalently the return condition is the principal continuant condition from Q2104/Q2125.

Now use the *target* characteristic `q_i`.  We have

```text
q_i | b_(x_i),
x_j<q_i,                                             (4.3)
```

so Q2127's exact return equivalence gives

```text
q_i | N_(h_ij)(x_i)
   <=> q_i | b_(x_j).                               (4.4)
```

Because `q_i!=p`, division by `p` preserves this support:

```text
boxed:
q_i | G_ij
   <=> q_i | b_(x_j).                               (4.5)
```

This is the exact arithmetic content of adding the nonconsecutive bridge `(i,j)`.

Define the cross-zero set

```text
X_i={j>i : q_i | b_(x_j)}.                         (4.6)
```

Then

```text
q_i^(|X_i|) | product_(j in X_i) G_ij,             (4.7)
```

and, after any primitive reduction that is a `q_i`-unit, the same target-prime support remains.

Thus there is a precise dichotomy.

* If many cross-zero incidences occur, the nonconsecutive bridge pool contains many extra large marked prime factors.  One can try to charge those directly.
* If cross-zero incidences are sparse, the new bridges do **not** acquire the endpoint target characteristics.  Their primitive heights still need an independent rank-spread theorem.

The currently banked unconditional `Z(q)=O(q^(2/3))` is far too large to make (4.6) sparse at the bicore degree scales of interest.  Q2125's prime-local saturation theorem explains why recurrence/reflection identities do not automatically improve it.

## 4.1 Why indiscriminate pool enlargement cannot help

There is also a simple order-statistic issue.  If a carrier is allowed to use the `r_p=d_p-k_p` smallest weights from a candidate pool and one merely adds more candidates, then the `r_p`-th order statistic can only decrease.  Therefore nonconsecutive bridges improve the obstruction only if the carrier theorem supplies an **admissible rank/basis constraint**, for example:

```text
choose a d_p-element arithmetic basis from the enlarged pool,
then pay the r_p smallest weights in that basis.
```

Without such a basis condition, “enlarge the pool” points in the wrong direction for a rank-spread lower bound.

The exact law (4.5) says what a useful basis theorem would have to exploit: cross-zero support, not just graph distance.

# 5. Exact rank spread in the carrier algebra

This section converts any genuine primitive band exclusion into the requested subcritical height statement.

Fix a source `p`, suppress it from notation, and write

```text
0<=W_1<=...<=W_d,
r=d-k_p.
```

Define adjacent gaps

```text
g_i=W_(i+1)-W_i >=0,       1<=i<d.                (5.1)
```

The banked local-optimum quantities are

```text
L=r*W_r-sum_(j<=r)W_j,
U=sum_(j>r)W_j-(d-r)*W_(r+1).                      (5.2)
```

For endpoint cutoffs use the natural empty-sum convention `L=0` at `r=0`, `U=0` at `r=d`.

A direct telescoping gives

```text
L=sum_(i=1)^(r-1) i*g_i,                           (5.3)
U=sum_(i=r+1)^(d-1) (d-i)*g_i.                    (5.4)
```

The gap `g_r` does not occur.  This is the exact algebraic meaning of “two levels plus one free cutoff jump.”

Put

```text
S_p(r)=L_p+U_p.                                    (5.5)
```

Adding the two banked slack identities gives

```text
B+W_total-2*F(J)
 = sum_p S_p(r_p) + s_add+s_rem.                   (5.6)
```

Therefore at any one-flip local optimum, and in particular at a global minimizer,

```text
boxed:
min_J F(J)
 <= (B+W_total-sum_p S_p(r_p))/2.                 (5.7)
```

This already expresses exactly how much rank spread is needed.

# 6. From band multiplicity to an explicit aggregate deficit

Assume that at one source every interval of logarithmic width `H` contains at most `m` weights.  Equivalently, after a harmless endpoint convention,

```text
W_(i+m)-W_i >= H
for every i with i+m<=d.                           (6.1)
```

Define

```text
Phi_m(n)=sum_(s=0)^(n-1) floor(s/m).               (6.2)
```

If

```text
n=A*m+b, 0<=b<m,
```

then exactly

```text
Phi_m(n)=m*A*(A-1)/2+A*b.                          (6.3)
```

Indeed there are `m` occurrences of each quotient `0,...,A-1` and then `b` occurrences of `A`.

For `j<=r`, chaining (6.1) gives

```text
W_r-W_j >= H*floor((r-j)/m).                       (6.4)
```

Hence

```text
L_p
 = sum_(j<=r)(W_r-W_j)
 >= H*Phi_m(r).                                    (6.5)
```

Similarly

```text
U_p>=H*Phi_m(d-r).                                 (6.6)
```

Thus

```text
S_p(r)
 >= H*(Phi_m(r)+Phi_m(d-r)).                       (6.7)
```

The increment `Phi_m(n+1)-Phi_m(n)=floor(n/m)` is nondecreasing, so the symmetric expression in (6.7) is minimized at a balanced split.  Therefore, exactly,

```text
S_p(r)
 >= H*Sigma_m(d),                                  (6.8)

Sigma_m(d)
 := Phi_m(floor(d/2))+Phi_m(ceil(d/2)).            (6.9)
```

There is also a convenient closed lower bound.  From (6.3),

```text
Phi_m(n)
 = n^2/(2*m)-n/2 + b*(m-b)/(2*m)
 >= n^2/(2*m)-n/2.                                (6.10)
```

Using `r^2+(d-r)^2>=d^2/2`,

```text
boxed:
S_p(r)
 >= H*(d^2/(4*m)-d/2).                             (6.11)
```

If the right side is negative, replace it by the trivial `0`.

## 6.1 Minimum degree `k`

Let

```text
M=sum_p d_p=number of source-edge incidences.      (6.12)
```

Assume the bicore has

```text
d_p>=k
```

for every source.  Summing (6.11) gives

```text
sum_p S_p(r_p)
 >= H*(k/(4*m)-1/2)*M                              (6.13)
```

whenever the bracket is positive, because

```text
sum_p d_p^2 >= k*sum_p d_p=k*M.                    (6.14)
```

Now define the exact critical two-ledger excess

```text
E_crit
 := B+W_total-2*M*log N.                           (6.15)
```

Substitute (6.13) into (5.7):

```text
boxed:

min_J F(J)-M*log N
 <= E_crit/2
    -(H/2)*(k/(4*m)-1/2)*M.                       (6.16)
```

This answers the height part of the question without appealing to an approximation ratio.

### Subcritical criterion

Put

```text
H=eta*log N.                                       (6.17)
```

Then for any fixed `delta0>0`, the sufficient condition

```text
E_crit/(M*log N)
 <= eta*(k/(4*m)-1/2)-2*delta0                     (6.18)
```

implies

```text
min_J F(J)
 <= (1-delta0)*M*log N.                            (6.19)
```

In particular:

* if `m=o(k)` and `E_crit=o((k/m)M log N)`, the rank deficit dominates the critical excess;
* even `m<=rho*k` with a fixed `rho<1/2` produces a fixed positive local spread coefficient once the right side of (6.18) is positive;
* the selected denominator-growth lemma `(SDG)` gives `m=O(1)` for `H~log N`, so on a minimum-degree `k->infinity` bicore it is vastly more than enough, subject only to the already-banked control of `E_crit`.

If (6.16) becomes formally negative, the conclusion is simply that the assumed degree/band/excess configuration cannot occur, since `F(J)>=0`.

# 7. What is actually open, and the weakest extra lemma

I do not see a theorem in the connected project state that rules out rapid exponent-five cancellation along a long **actual selected** radial subsequence.  The exact state is therefore:

```text
PROVED:
  actual radii are 2-separated;
  the p=53 radii 9,10 inversion cannot be selected;
  a primitive plateau forces the denominator escalation (2.10);
  the selected radial/target identity (3.13);
  the nonconsecutive cross-zero equivalence (4.5);
  the exact carrier deficit (6.16).

OPEN:
  a selected upper bound on the rank growth of e_(p,r)
  strong enough to contradict (2.10).
```

The weakest clean extra statement I recommend is endpoint-only denominator growth.

### `[SDG_delta]` — selected exponent-five denominator growth

For some `delta>0` and `C<infinity`, for every dyadic shell, every actual selected same-sign source `p`, and every pair of selected ranks `i<j`, whenever the primitive weights between those ranks lie in a band under consideration,

```text
log(e_(p,r_j)/e_(p,r_i))
 <= (6-delta)*(j-i)*log p+C*log p.                 (7.1)
```

The lemma does **not** assert primitive monotonicity.  It does **not** bound every reduction factor individually.  It does **not** ask for a fixed-gap bridge estimate.  It only says that, on an actual selected radial subsequence, exponent-five cancellation cannot keep pace with all six raw logarithmic units per selected rank.

By (2.9), `[SDG_delta]` immediately implies the band bound (2.14), hence (6.16).

If the banked raw theorem has constant `3` rather than selected-upgraded `6` in the precise local indexing, replace `(6-delta)` by `(3-delta)` everywhere.

## 7.1 A more arithmetic formulation suggested by (3.13)

One can instead aim at a joint residual statement.  For each selected edge define

```text
D_(p,q)
 := (a+1)^3*b_(a+1)*e_(p,q)*w_(p,q)
    -Q_h(a)*(P_q/p)*C_q.                           (7.2)
```

Then exactly

```text
D_(p,q)
 = q*(a+1)^6*N_(h-1)(a+1)*b_a/(p*q).              (7.3)
```

A theorem saying that many selected radii cannot simultaneously have

```text
w_(p,q) in one H-band
```

and

```text
log e_(p,q) growing at the rate forced by (2.10)
```

while satisfying the exact moving-modulus equations (7.3) would also close the route.  This is genuinely Apéry-specific because both `C_q` and `b_a/(pq)` are actual Apéry quotients.

But `[SDG_delta]` is the smaller target: it strips away the target quotient and asks only for the precise denominator behavior that the primitive obstruction needs.

## 7.2 Formal countermodel to using only the modular coupling

Equation (3.18) by itself cannot imply a band bound.  Fix distinct primes `q_i`, arbitrary units `theta_i mod q_i`, and arbitrary positive integers `w_i`, even all equal.  There always exist positive integers `C_i` satisfying

```text
C_i == theta_i^(-1)*w_i (mod q_i).                 (7.4)
```

Thus the collection of one-prime congruences admits an arbitrarily flat `w_i` profile.  This is only a formal countermodel to the **congruence-only inference**; it is not claimed to realize the actual Apéry numbers or the exact primitive normalization.

The repository's primitive candidate scans make the same methodological distinction: primitive/projective phantoms occur, while actual distinguished-orbit selectedness is an additional condition.

I therefore do not issue a broad no-go verdict and I do not claim the desired primitive-band statement is false.

```python
    return 34*n**3 + 51*n**2 + 27*n + 5
```
