# Problem 3.2: center radical residual versus the Hensel quotient

## Verdict

**Scoped no-go, with an exact bridge.**  The corrected radical midpoint row does give a new-looking formula for the center residual, but after translating it into the first Hensel correction it does **not** eliminate the Q1601 scalar `J_m` and does **not** supply an independent equation for `q0`.

Use

\[
x_j:=\lambda_j=j(j+1),\qquad y=x_r,
\]

\[
G(Y)=\prod_{j=0}^{m}(Y-x_j),\qquad
G_0(Y)=\prod_{j=0}^{m-1}(Y-x_j),
\]

\[
T(Y)=\prod_{j=r+1}^{m-1}(Y-x_j),
\qquad d:=\deg T=m-r-1>0,
\]

and the verified Hensel notation

\[
A=\frac{P_m}{Y-y},\qquad AU-1=GE,
\]

\[
C\equiv-UE\pmod T,\qquad \deg C<d,
\]

\[
V=U+GC,
\qquad
J=\frac{E+AC}{T}=\frac{AV-1}{GT}.
\]

Here `U` is the **radical first inverse** modulo `G`; `V` is the **full Hensel lift** modulo `GT`.  They must not be interchanged.

The exact new bridge is

\[
\boxed{
8A_m\,W_U(x_m)=(x_{m-1}-y)\,C(x_{m-1}).
}
\tag{B1}
\]

Equivalently, because `C=-UE` at a tail root and `U_m=A_m^{-1}`,

\[
\boxed{
W_U(x_m)
=\frac{x_{m-1}-y}{8A_m}\,C(x_{m-1})
=-\frac{x_{m-1}-y}{8A_mA_{m-1}}E(x_{m-1}).
}
\tag{B2}
\]

Thus `W_U(x_m)` is controlled by the **last open-tail Hensel value**, not by a center scalar alone.

Write

\[
B(Y):=\prod_{j=r+1}^{m-2}(Y-x_j)
\]

(with `B=1` if `d=1`) and decompose the degree-`<d` correction in Newton form

\[
\boxed{
C(Y)=L(Y)+q_0B(Y),\qquad \deg L\le d-2.
}
\tag{N}
\]

Then (B1) gives

\[
\boxed{
q_0=
\frac{8A_mW_U(x_m)/(x_{m-1}-y)-L(x_{m-1})}
     {B(x_{m-1})}.
}
\tag{Bq}
\]

This is a legitimate way to **reconstruct** the top Newton coefficient from the last tail value.  It is not an additional constraint on the same `C`.

At the center, since

\[
T(Y)=(Y-x_{m-1})B(Y),
\]

and

\[
x_m-x_{m-1}=2m=-1\quad\text{in }\mathbf F_p,
\]

we have

\[
B(x_m)=-T_m.
\]

Hence

\[
C_m=L_m-T_mq_0.
\]

Q1601's exact center identity

\[
E_m+A_mC_m=T_mJ_m
\]

therefore gives

\[
\boxed{
q_0=
\frac{E_m+A_mL_m-T_mJ_m}{A_mT_m}.
}
\tag{Cq}
\]

Equating (Bq) and (Cq) yields the apparent `W_U`--`J_m` bridge

\[
\boxed{
J_m=
\frac{E_m+A_mL_m}{T_m}
-
\frac{A_m}{B(x_{m-1})}
\left(
  \frac{8A_mW_U(x_m)}{x_{m-1}-y}-L(x_{m-1})
\right).
}
\tag{BJ}
\]

But now substitute the midpoint identity (B1):

\[
\frac{8A_mW_U(x_m)}{x_{m-1}-y}
=C(x_{m-1})
=L(x_{m-1})+q_0B(x_{m-1}).
\]

The second term of (BJ) becomes `-A_m q0`, so

\[
J_m
=\frac{E_m+A_mL_m}{T_m}-A_mq_0
=\frac{E_m+A_m(L_m-T_mq_0)}{T_m}
=\frac{E_m+A_mC_m}{T_m}.
\]

That is **exactly the definition already known from Q1601**.

Therefore:

\[
\boxed{
\text{midpoint Riccati row + center Hensel row does not eliminate }J_m.
}
\]

It merely evaluates the same polynomial `C` in two coordinate systems: at the last tail node and at the center.

The smallest extra datum for a genuinely center-level closure is the **next divided difference**

\[
\boxed{
\nu_m
:=[x_{r+1},\ldots,x_{m-1},x_m](-UE)
=\left(\frac{-UE-C}{T}\right)(x_m),
}
\tag{nu}
\]

for which

\[
\boxed{J_m=-A_m\nu_m.}
\tag{Jnu}
\]

This is a fully specified one-scalar datum, not an unspecified “higher jet.”  The midpoint row determines the endpoint value `(-UE)(x_{m-1})=C(x_{m-1})`; it does **not** determine the next divided difference `nu_m`.

# 2. Derivation of the midpoint/Hensel bridge

Let

\[
t_j:=x_j-y,
\]

and define the rational radical reconstruction

\[
Q(Y):=\frac{Y-y}{U(Y)}.
\]

Since `P_m=(Y-y)A` and `AU=1+GE`, one has the exact identity

\[
Q(Y)=\frac{P_m(Y)}{1+G(Y)E(Y)}.
\]

Put

\[
f(Y):=Q(Y)-P_m(Y).
\]

At a complete-grid node `x_j`, Q1601 gives

\[
\alpha_j:=f_Y'(x_j)
=-b_jG'(x_j)E_j.
\]

On the open tail, the Hensel correction is

\[
C_j:=C(x_j)=-U_jE_j
=\frac{t_j\alpha_j}{b_j^2G'(x_j)}.
\tag{2.1}
\]

For `j<m`, the complete-grid derivative is

\[
G'(x_j)=-\frac12.
\]

Let

\[
b:=m-1.
\]

Then

\[
2b+1=2m-1=-2\quad\text{in }\mathbf F_p.
\]

The pulled first-`z` defect is

\[
\eta_b=(2b+1)\alpha_b=-2\alpha_b.
\]

Substitute `alpha_b=-eta_b/2` and `G'(x_b)=-1/2` into (2.1):

\[
C_b
=\frac{t_b(-\eta_b/2)}{b_b^2(-1/2)}
=\frac{t_b\eta_b}{b_b^2}.
\]

But on a non-root tail node

\[
U_b=\frac{t_b}{b_b},
\]

hence

\[
\boxed{
\eta_b=\frac{t_bC_b}{U_b^2}.
}
\tag{2.2}
\]

The corrected radical midpoint theorem gives independently

\[
\eta_b
=\frac{8W_U(x_m)}{U_b^2U_m}.
\tag{2.3}
\]

Equating (2.2) and (2.3), cancelling the unit `U_b^2`, and using

\[
U_m=A_m^{-1}
\]

gives

\[
t_bC_b=\frac{8W_U(x_m)}{U_m}=8A_mW_U(x_m).
\]

This proves (B1).

No center quotient appears in this derivation.  The only non-center datum forced by the midpoint row is the last tail value `C_b`, equivalently `E_b`.

# 3. Why the center equation is not independent

Set

\[
a=r+1,\qquad b=m-1,\qquad
B(Y)=\prod_{j=a}^{b-1}(Y-x_j).
\]

Then `deg B=d-1`.  Every correction of degree `<d` has a unique decomposition

\[
C=L+q_0B,
\qquad \deg L\le d-2.
\]

At the last tail node,

\[
C_b=L_b+q_0B_b,
\]

so the midpoint bridge is exactly the interpolation equation

\[
\frac{8A_mW_m}{t_b}=L_b+q_0B_b.
\tag{3.1}
\]

At the center,

\[
T=(Y-x_b)B.
\]

Because

\[
x_m-x_b=2m=-1,
\]

we get

\[
B_m=-T_m.
\]

Thus

\[
C_m=L_m-T_mq_0.
\tag{3.2}
\]

Q1601's center quotient formula is

\[
E_m+A_mC_m=T_mJ_m.
\tag{3.3}
\]

Insert (3.2):

\[
E_m+A_mL_m-A_mT_mq_0=T_mJ_m.
\tag{3.4}
\]

Equations (3.1) and (3.4) give two formulas for `q0`, namely (Bq) and (Cq).  Eliminating `q0` gives (BJ), but substituting (3.1) back into it reproduces (3.3) identically.

Therefore the algebraic rank has not increased.  In particular, no argument of the following form is valid:

```text
midpoint row gives W_m;
center Hensel row gives E_m + A_m C_m = T_m J_m;
therefore J_m cancels and q0 is forced independently.
```

The first line evaluates `C` at `x_b`; the second evaluates the quotient of `E+AC` at `x_m`.  Without one additional scalar connecting these two interpolation levels, `J_m` remains.

# 4. Exact nature of the missing scalar

Put

\[
F(Y):=-U(Y)E(Y).
\]

The Hensel correction is the remainder

\[
C\equiv F\pmod T,
\qquad \deg C<d.
\]

Hence there is a polynomial `N` with

\[
F-C=TN.
\]

The next Newton coefficient at the center is

\[
\boxed{
\nu_m:=N(x_m)
=[x_a,x_{a+1},\ldots,x_b,x_m]F.
}
\]

Now

\[
F=-UE,
\qquad AU=1+GE.
\]

A direct algebraic calculation gives

\[
J_m=-A_m\nu_m.
\]

This is the smallest datum needed **if the goal is to remove `J_m` from the center equation**.  It is one explicit divided difference of a named polynomial/rational expression, with a fixed node set.

By contrast, the midpoint row determines only

\[
F(x_b)=C(x_b)
\]

and hence the one-node endpoint quantity in (B1).  A value at `x_b` cannot determine the next divided difference at `(x_a,\ldots,x_b,x_m)` without an additional relation on `F`.

So the precise remaining target is not “some higher jet”; it is one of the following exactly equivalent scalars:

\[
\boxed{\nu_m}
\qquad\Longleftrightarrow\qquad
\boxed{J_m=-A_m\nu_m}.
\]

If a future argument computes `nu_m` from already controlled data, the center equation becomes triangular.  The present midpoint identity does not do so.

#!/usr/bin/env sage
from sage.all import *
from pathlib import Path
from collections import defaultdict
import argparse, json, struct


def load_records_json(path):
    data = json.loads(Path(path).read_text())
    if isinstance(data, dict):
        data = data.get("records", data.get("canonical_records", data))
    if not isinstance(data, list):
        raise ValueError("record JSON must be a list or contain records/canonical_records")
    out = []
    for row in data:
        if isinstance(row, dict):
            p = int(row.get("p", row.get("prime")))
            r = int(row.get("r", row.get("root")))
        else:
            p, r = map(int, row[:2])
        out.append((p, r))
    return out


def load_folded_singletons_from_binary(path):
    # Format documented by problems/3.2/oracleB_explore.py:
    # headerless little-endian uint32 pairs (p, zero_index).
    raw = Path(path).read_bytes()
    if len(raw) % 8:
        raise ValueError("partial record in zero-pair binary")
    grouped = defaultdict(list)
    for p, z in struct.iter_unpack("<II", raw):
        grouped[p].append(z)

    out = []
    for p in sorted(grouped):
        folded = sorted(set(min(z, p - 1 - z) for z in grouped[p]))
        if len(folded) == 1:
            r = folded[0]
            m = (p - 1)//2
            if r <= m - 2:       # nonempty open tail
                out.append((p, r))
    return out


def check_record(p, r, verbose=False):
    F = GF(p)
    R.<Y> = PolynomialRing(F)
    S.<u> = PolynomialRing(F)
    one = R(1)
    m = (p - 1)//2

    if p != 2*m + 1 or not is_prime(p):
        raise ValueError((p, r, "p must be an odd prime 2m+1"))
    if not (0 <= r <= m - 2):
        raise ValueError((p, r, "requires nonempty tail"))

    def x(j):
        return F(j*(j+1))

    def prodR(items):
        ans = R(1)
        for z in items:
            ans *= z
        return ans

    def subst_to_S(poly, z):
        ans = S(0)
        for k, c in enumerate(poly.list()):
            ans += S(c) * z**k
        return ans

    # Actual finite Racah polynomial: deg P_m = 2m.
    phi = R(1)
    Pm = phi**2
    for k in range(1, m + 1):
        phi *= (Y - x(k-1)) / F(k)**2
        Pm += phi**2
    assert Pm.degree() == 2*m

    y = x(r)
    A, rem = Pm.quo_rem(Y - y)
    assert rem == 0
    assert A.degree() == 2*m - 1

    G = prodR(Y - x(j) for j in range(m + 1))
    G0 = prodR(Y - x(j) for j in range(m))
    assert G == (Y - x(m))*G0
    assert G0(x(m)) == -F(1)
    assert G.derivative()(x(m)) == -F(1)
    for j in range(m):
        assert G.derivative()(x(j)) == -F(1)/2

    # U = A^{-1} mod G.
    gg, s, _ = (A % G).xgcd(G)
    assert gg == 1
    U = s % G
    assert (A*U - one) % G == 0
    assert U.degree() <= m

    E, rem = (A*U - one).quo_rem(G)
    assert rem == 0

    a = r + 1
    b = m - 1
    T = prodR(Y - x(j) for j in range(a, m))
    d = T.degree()
    assert d == m - r - 1

    C = (-U*E) % T
    assert C.degree() < d or C == 0
    q0 = C[d-1]                 # top designated coefficient; lc if nonzero

    V = U + G*C
    M = G*T
    assert (A*V - one) % M == 0
    assert V.degree() < M.degree()
    assert V[M.degree()-1] == q0

    J, rem = (E + A*C).quo_rem(T)
    assert rem == 0
    J2, rem = (A*V - one).quo_rem(M)
    assert rem == 0
    assert J == J2

    xm = x(m)
    xb = x(b)
    tb = xb - y
    Am = A(xm)
    Ab = A(xb)
    Um = U(xm)
    Ub = U(xb)
    Em = E(xm)
    Eb = E(xb)
    Cm = C(xm)
    Cb = C(xb)
    Tm = T(xm)
    Jm = J(xm)

    assert Am != 0 and Ab != 0 and Um == 1/Am and Ub == 1/Ab
    assert tb != 0 and Tm != 0
    assert Cb == -Ub*Eb
    assert Em + Am*Cm == Tm*Jm

    # Correct odd radical Riccati residual Phi_U(u)=u R_U(lambda(u)).
    lam0 = (u**2 - S(1)) / S(4)
    lamp = lam0 + u + 1
    lamm = lam0 - u + 1

    t0 = lam0 - S(y)
    tp = lamp - S(y)
    tm = lamm - S(y)
    U0 = subst_to_S(U, lam0)
    Up = subst_to_S(U, lamp)
    Umn = subst_to_S(U, lamm)

    Phi = (
        ((u+1)**3 / S(8)) * tp * Umn * U0
        - (u*(S(17)*u**2 + S(3)) / S(4)) * t0 * Umn * Up
        + ((u-1)**3 / S(8)) * tm * U0 * Up
    )

    assert Phi(0) == 0
    Ru_u, rem = Phi.quo_rem(u)
    assert rem == 0

    # Ru_u is even in u, hence a polynomial in Y=(u^2-1)/4.
    Ru = R(0)
    for k, c in enumerate(Ru_u.list()):
        if c:
            assert k % 2 == 0, (p, r, "R_U not even after removing u", k, c)
            Ru += R(c) * (4*Y + 1)**(k//2)

    WU, rem = Ru.quo_rem(G0)
    assert rem == 0, (p, r, "G0 does not divide R_U", rem)
    Wm = WU(xm)

    assert Phi.derivative()(0) == -S(Wm)

    assert 8*Am*Wm == tb*Cb
    assert Wm == -tb*Eb/(8*Am*Ab)

    eta_mid = 8*Wm/(Ub**2*Um)
    eta_hensel = tb*Cb/(Ub**2)
    assert eta_mid == eta_hensel

    # Newton decomposition C=L+q0 B.

    L = C - q0*B
    assert L.degree() <= d-2 or L == 0
    Bb = B(xb)
    Bm = B(xm)
    assert Bb != 0

        (Em + Am*L(xm))/Tm
        - Am/Bb * (8*Am*Wm/tb - L(xb))

    assert J_bridge == (Em + Am*Cm)/Tm

    Fpoly = -U*E

    assert rem == 0
    nu = N(xm)
    assert Jm == -Am*nu

# 8. Final classification

The corrected midpoint Riccati row supplies the exact and useful identity

\[
\boxed{
8A_mW_U(\lambda_m)
=(\lambda_{m-1}-y)C(\lambda_{m-1}).
}
\]

This is the **closed bridge** between the center radical residual and the first Hensel correction.

However, it is a bridge to the last-tail value of `C`, not to the next center quotient.  Combining it with

\[
E_m+A_mC_m=T_mJ_m
\]

does not remove `J_m`; after Newton interpolation it reduces identically to that same quotient equation.

Therefore the requested outcome is:

\[
\boxed{\textbf{PRECISE SCOPED NO-GO.}}
\]

The minimum center-level datum not supplied by the midpoint row is exactly

\[
\boxed{
\nu_m=[\lambda_{r+1},\ldots,\lambda_{m-1},\lambda_m](-UE),
\qquad J_m=-A_m\nu_m.
}
\]

The `(17,3)` record proves the distinction sharply:

\[
W_U(\lambda_m)=0,
\quad E_m=2,
\quad J_m=5,
\quad C_m=6,
\quad \nu_m=11.
\]

So the radical midpoint equation does **not** secretly contain the missing center Hensel quotient, and no independent `q0` equation emerges from combining the two rows.
