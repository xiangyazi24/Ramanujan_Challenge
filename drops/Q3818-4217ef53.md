# 2. What a useful threshold divisor must certify

A fixed integer of the correct numerical size is not enough.  To enter a carrier proof, it must certify actual incidences in one of the following two senses.

## 2.1 Selected actual divisor

One could ask for a squarefree divisor `D_sigma` satisfying

\[
D_\sigma\mid P_\sigma,
\qquad
\omega(D_\sigma)\ge d_\sigma.
\tag{2.1}
\]

Then

\[
\log D_\sigma\ge d_\sigma\log(T/7).
\tag{2.2}
\]

This is the ideal object, but its prime support is an actual-partner selection.

## 2.2 Universal paying carrier

A weaker and more realistic atom-only request is a fixed integer `D_sigma`, independent of the unknown actual subset, such that

\[
\omega(\gcd(D_\sigma,P_\sigma))\ge d_\sigma.
\tag{2.3}
\]

Only the candidate-prime support of `D_sigma` matters.  Powers and non-window factors merely increase height, so put

\[
E(D_\sigma)
:=
\{\ell\in W_\sigma:\ell\mid D_\sigma\}.
\tag{2.4}
\]

Condition (2.3) is

\[
|E(D_\sigma)\cap S_\sigma|\ge d_\sigma.
\tag{2.5}
\]

This is the precise combinatorial problem solved below.

## 2.3 The circular numerical construction

If `k_sigma` is handed to us and no actual-divisibility certification is required, one can multiply any `d_sigma` primes from `W_sigma`; its logarithm is automatically `asymp d_sigma log T`.  That construction does not use an Apéry theorem.  It simply rewrites the unknown count `d_sigma` as the number of factors in a new integer.  There is no reason its factors pay any actual rows, and there is no independent height estimate which bounds `d_sigma`.

Thus (2.1) or (2.3), not mere numerical size, is the load-bearing interpretation of “threshold divisor.”

# 3. Sharp unmarked threshold saturation theorem

The following finite statement is the exact obstruction.

## Theorem 3.1 — unmarked threshold saturation

Let

\[
C=\ell_1\cdots\ell_m
\]

be squarefree, with distinct primes `ell_i`.  Fix `0<=k<=m`, and let `D` be an integer independent of an unknown squarefree divisor `P|C` with `omega(P)=k`.  Put

\[
e:=\omega(\gcd(C,\operatorname{rad}D)).
\]

Then

\[
\boxed{
\min_{\substack{P\mid C\\P\text{ squarefree}\\\omega(P)=k}}
\omega(\gcd(D,P))
=
\max\{0,k-(m-e)\}.
}
\tag{3.1}
\]

Consequently, for an integer `d` with `1<=d<=k`, the uniform requirement

\[
\omega(\gcd(D,P))\ge d
\quad
\text{for every squarefree }P\mid C,\ \omega(P)=k
\tag{3.2}
\]

holds if and only if

\[
\boxed{e\ge m-k+d.}
\tag{3.3}
\]

### Proof

Let `E` be the `e` candidate primes dividing `D`; its complement in the `m` candidates has `m-e` primes.  To minimize `|E cap supp(P)|`, choose as many of the `k` primes of `P` as possible from that complement.

- If `m-e>=k`, one can choose all `k` outside `E`, so the minimum intersection is `0`.
- If `m-e<k`, every `k`-subset must use exactly at least `k-(m-e)` primes from `E`, and this is attained by taking every complement prime and then filling from `E`.

This proves (3.1).  Since `d>0`, (3.2) is equivalent to

\[
k-(m-e)\ge d,
\]

which rearranges to (3.3).  ∎

## Corollary 3.2 — exact capacity-R threshold

Take

\[
d=(k-R)_+.
\]

On a nontrivial star `k>R`, condition (3.2) forces

\[
\boxed{e\ge m-R.}
\tag{3.4}
\]

Thus a fixed carrier guaranteed to contain `k-R` actual factors must contain **all but at most `R` candidate factors**.  Conversely, every candidate support omitting at most `R` primes does contain at least `k-R` primes from every actual `k`-subset.  The bound is sharp.

## Corollary 3.3 — comparable rather than exact charge

Suppose only a fixed proportion `0<c<=1` of the excess must be paid.  Put

\[
d=\left\lceil c(k-R)\right\rceil.
\]

Then every unmarked universal carrier has

\[
\boxed{
e\ge m-k+\left\lceil c(k-R)\right\rceil.}
\tag{3.5}
\]

The term `m-k` is unavoidable.  It is precisely the number of spurious candidate factors.  Therefore a constant-factor threshold carrier can be substantially cheaper than the full radical only after one independently proves

\[
m-k=O(k-R)
\]

or an aggregate analogue.

## Corollary 3.4 — no nontrivial uniformly actual divisor

Suppose `0<k<m` and a fixed candidate-supported integer `D` is required to divide **every** possible actual product `P` of `k` candidate primes.  Then

\[
\boxed{\gcd(C,\operatorname{rad}D)=1.}
\tag{3.6}
\]

Indeed, every candidate prime is omitted by some `k`-subset.  Thus no nontrivial candidate prime can divide a divisor common to all possible actual products.

This is the exact distinction between a selected actual divisor and a universal paying carrier:

- the former collapses to `1` without actual selection;
- the latter saturates to all but `R` candidates.

\qquad
m=m_\sigma,
\qquad

Any atom-only universal exact threshold carrier on a star with `k_sigma>R` has at least `m_sigma-R` lower-window prime factors.  Hence

\[
\boxed{
\log|D_\sigma|
\ge
(m_\sigma-R)\log(T/7).
}
\tag{4.1}
\]

Since

\[
m_\sigma-R
=(k_\sigma-R)+(m_\sigma-k_\sigma),
\]

this is

\[
\boxed{
\log|D_\sigma|
\ge
\bigl((k_\sigma-R)+(m_\sigma-k_\sigma)\bigr)
\log(T/7).
}
\tag{4.2}

The first term is the desired Hall excess.  The second is exactly the atom noise.

Summing over nontrivial stars gives

\[
\boxed{
\sum_{\sigma:k_\sigma>R}\log|D_\sigma|
\ge

\sum_{\sigma:k_\sigma>R}(m_\sigma-k_\sigma)

\log(T/7).

\tag{4.3}

# 5. Audit of the proposed constructions

## 5.1 Determinantal divisors and Fitting ideals

Let the candidate primes at one star be

\[
\ell_1,\ldots,\ell_m,
\qquad
C=\prod_{i=1}^m\ell_i.
\]

The exact diagonal local model is

\[
M=\bigoplus_{i=1}^m\mathbf Z/\ell_i\mathbf Z,
\]

with presentation matrix

\[
\operatorname{diag}(\ell_1,\ldots,\ell_m).
\]

Its `j`-th determinantal divisor is

\[
\Delta_j
=
\gcd_{|I|=j}
\prod_{i\in I}\ell_i.
\]

For every `1<=j<m`, each candidate prime is avoided by some `j`-minor, so

\[
\boxed{
\Delta_j=1\quad(1\le j<m),
\qquad
\Delta_m=C.
}
\tag{5.1}
\]

Equivalently,

\[
\operatorname{Fitt}_0(M)=(C),
\qquad
\operatorname{Fitt}_r(M)=\mathbf Z\quad(r\ge1).
\tag{5.2}
\]

There is no intermediate Fitting divisor which records “more than `R` of the distinct characteristics occur.”  The reason is structural: rank is measured separately in each residue field.  One rank drop in `F_{ell_1}` and one rank drop in `F_{ell_2}` do not form a two-dimensional rank drop in a common field.

The dual cofactor diagonal is no better.  For

\[
M^\vee
=
\operatorname{diag}(C/\ell_1,\ldots,C/\ell_m),
\]

one gets exactly

\[
\boxed{
\Delta_j(M^\vee)=C^{j-1}
\quad(1\le j\le m).
}
\tag{5.3}
\]

So the two canonical diagonal presentations exhibit the only two behaviours relevant here:

- intermediate minors have gcd `1`, losing every candidate factor;
- or they contain powers of the whole radical, becoming more expensive.

A more elaborate atom-built matrix may select some fixed subset of candidates through additional congruences, but that subset is still independent of the unknown actual set.  Theorem 3.1 then gives the sharp support lower bound.

This does **not** conflict with the global determinantal route in Q3803.  A presentation with rows indexed by actual occurrence constraints, or with a finite-type system whose mod-`p` points are proved equivalent to actual rows, has additional information.  It is no longer an unmarked two-atom construction.  Such a determinant may accumulate actual prime divisibility and is outside this no-go.

## 5.2 CRT formulation of the same saturation

At squarefree level,

\[
\mathbf Z/C\mathbf Z
\cong
\prod_{i=1}^m\mathbf F_{\ell_i}.
\tag{5.4}
\]

Every candidate characteristic is a separate coordinate.  The actual subset `S` is an additional idempotent/coordinate-selection datum.  The two gcd atoms determine which coordinates are candidates and, at most, whether a coordinate lies in the minus atom, plus atom, or both.  They do not supply the actual-selection idempotent.

Any ideal formed from the unmarked atom data therefore has a fixed coordinate support `E`.  Requiring it to meet every possible actual `k`-coordinate submodule in at least `d` coordinates is exactly Theorem 3.1.  Saturating over all unmarked `k`-subsets forces

\[
|E|\ge m-k+d,
\]

and for `d=k-R`, all but `R` coordinates.

The threshold “at least `k-R` among many disconnected residue characteristics” is a global cardinality condition on components of `Spec(Z/CZ)`.  It is not a local rank condition in one component.

## 5.3 Elementary symmetric products

Let

\[
M_I:=\prod_{i\in I}\ell_i,
\qquad |I|=d,
\qquad 1\le d<m.
\]

The exact principalization identities are

\[
\boxed{
\gcd_{|I|=d}M_I=1,
\qquad
\operatorname{lcm}_{|I|=d}M_I=C.
}
\tag{5.5}
\]

The first equality holds because every candidate prime is omitted by some `d`-subset.  The second holds because every candidate prime occurs in some `d`-subset.

Their total product is

\[
\boxed{
\prod_{|I|=d}M_I
=C^{\binom{m-1}{d-1}},
}
\tag{5.6}
\]

which is much more expensive than the radical.

The elementary symmetric sum

\[
e_d(\ell_1,\ldots,\ell_m)
=
\sum_{|I|=d}M_I
\]

has attractive numerical size but no guaranteed candidate divisibility.  Modulo `ell_j`, all terms containing `ell_j` vanish, while the terms omitting it remain:

\[
e_d(\ell_1,\ldots,\ell_m)
\equiv
 e_d(\ell_1,\ldots,\widehat{\ell_j},\ldots,\ell_m)
\pmod{\ell_j}.
\tag{5.7}
\]

There is no universal reason for the right side to vanish.  Accidental divisibility does not identify actual partners.

Thus the nonprincipal monomial family can formally encode choices, but its principal integer avatars are exactly the two saturated extremes:

```text
existential/gcd principalization  -> 1
universal/lcm principalization    -> full radical C
product of all choices            -> a high power of C
```

It does not yield an actual-tail divisor.

## 5.4 Quotient by `R` smallest factors

Order the candidate primes as

\[
\ell_1<\ell_2<\cdots<\ell_m.
\]

The proposed quotient

\[
Q_{\rm small}
:=
\frac{C}{\ell_1\cdots\ell_R}
=
\ell_{R+1}\cdots\ell_m
\tag{5.8}
\]

is a valid **universal paying carrier**.  It omits only `R` candidates, so every actual `k`-subset contributes at least `k-R` factors to `gcd(Q_small,P)`.

But it has

\[
(m-R)\log(T/7)
\le
\log Q_{\rm small}
\le
(m-R)\log(T/3),
\tag{5.9}
\]

so it pays all spurious candidate factors.

Moreover, `Q_small` is the **largest**, not the smallest, product among quotients obtained by deleting `R` candidates.  The least-height robust quotient is

\[
Q_{\rm opt}
:=
\frac{C}{\ell_{m-R+1}\cdots\ell_m}
=
\ell_1\cdots\ell_{m-R},
\tag{5.10}
\]

which deletes the `R` largest candidates.  It still has `m-R` factors and is therefore still full-radical scale.  Because all primes lie in one macroscopic window, (5.8) and (5.10) differ only by fixed-factor logarithmic constants, not by the structural exponent.

Now order the **actual** partners as

\[
p_1<\cdots<p_k.
\]

Then

\[
\frac{P}{p_1\cdots p_R}
\tag{5.11}
\]

really is a product of exactly `k-R` actual factors, but it requires knowing the actual set.  It is the largest actual `k-R` tail.  The least-height actual tail instead deletes the `R` largest actual factors:

\[
\operatorname{Tail}_R(P)
:=
\begin{cases}
\displaystyle
\frac{P}{p_{k-R+1}\cdots p_k},&k>R,\\[3mm]
1,&k\le R.
\end{cases}
\tag{5.12}
\]

Both actual tails have logarithm comparable to `(k-R) log T`.  The distinction is irrelevant asymptotically in the fixed window, but (5.12) gives the weakest possible tail-height premise.

## 5.5 Recurrence and continuant flags

The current recurrence machinery produces genuine and useful same-characteristic certificates, but it does not supply an unmarked threshold across distinct lower characteristics.

At the upper characteristic `q`, the conditions

\[
q\mid b_u,
\qquad
q\mid b_{q-1-u},
\qquad
q\mid b_{6q+u},
\qquad
q\mid b_{12q+u}
\tag{5.13}
\]

all descend from the **one selected zero** `u` by reflection and Lucas.  The reflected zero is the same selected orbit, not a new independent upper occurrence for each lower neighbor.  Therefore the q-side recurrence state has fixed-dimensional degeneracy independent of `k_sigma`.

Every actual lower partner `p` lives in a different field `F_p`.  In the reflected coordinates of Q3779, an actual row yields a p-specific flag of the form

\[
p\mid b_x,
\qquad
p\mid N_h(x),
\tag{5.14}
\]

with `h` and `x` depending on `p`, `d=q-p`, and the plus/minus branch.  These are excellent local certificates.  But:

- a product over **all prescribed candidate** `(p,h,x)` flags pays all candidate primes and is another full carrier;
- a product over only **actual** flags is exactly a selected actual-tail construction;
- stacking flags for distinct primes in one characteristic-zero matrix gives a CRT-diagonal collection of rank drops, not one rank defect of dimension `k` in a common residue field;
- taking higher exterior powers at `q` cannot see the number of distinct lower fields, because the q-side supplies one selected zero orbit regardless of `k`.

A recurrence/resultant construction could escape only if it proves a new relation linking the p-specific flags across different `p` and thereby restricts the feasible actual subsets.  That would be a cross-characteristic theorem, not an atom-only threshold operation, and is explicitly not ruled out here.

# 6. The exact narrowness of the no-go

Let `F_sigma` denote the family of actual subsets of `W_sigma` which are compatible with **all** true Apéry and q6 constraints.  If that family were known, the optimal support size for a carrier meeting every actual set in at least `d` factors would be the transversal parameter

\[
\tau_d(F_\sigma)
:=
\min\bigl\{|E|:
|E\cap S|\ge d\text{ for every }S\in F_\sigma
\bigr\}.
\tag{6.1}
\]

The two unmarked gcd atoms alone give only

\[
F_\sigma\subseteq\binom{W_\sigma}{k_\sigma},
\]

with no further subset restriction.  If one works solely from those premises, the safe ambient family is the whole binomial family, and Theorem 3.1 says

\[
\boxed{
\tau_d\!\left(\binom{W_\sigma}{k_\sigma}\right)
=m_\sigma-k_\sigma+d.
}
\tag{6.2}
\]

For `d=k_sigma-R`, this is `m_sigma-R`.

A future theorem may prove that the true family `F_sigma` is far smaller and has a much smaller transversal.  Examples include:

- a cross-characteristic eliminant forcing all actual partners into a prescribed small divisor;
- an analytic theorem showing that almost every candidate is spurious in a controlled way and that actual sets concentrate in a small subfamily;
- a global algebraic presentation in which actual occurrences are rows and the relevant maximal minors acquire one prime factor per excess occurrence;
- a trace-function or monodromy statement controlling simultaneous p/q selectedness.

None of these is contradicted by (6.2).  The theorem says only that such a restriction is **additional mathematical content**; it cannot be obtained by principalizing the two unmarked gcd atoms.

# 7. Smallest selected actual-Apéry tail-height premise

The clean replacement premise should discard all candidate noise and retain only the minimum actual information needed by Hall capacity.

## 7.1 Canonical weakest actual tail

For each star, order the actual partners

\[
p_{\sigma,1}<\cdots<p_{\sigma,k_\sigma}.
\]

Define

\[
\boxed{
\operatorname{Tail}_R(P_\sigma)
:=
\min_{\substack{E\subseteq S_\sigma\\|E|\le R}}
\prod_{p\in S_\sigma\setminus E}p.
}
\tag{7.1}
\]

Equivalently,

\[
\operatorname{Tail}_R(P_\sigma)
=
\begin{cases}
\displaystyle
P_\sigma/
\prod_{j=k_\sigma-R+1}^{k_\sigma}p_{\sigma,j},
&k_\sigma>R,\\[3mm]
1,&k_\sigma\le R.
\end{cases}
\tag{7.2}
\]

Thus the weakest tail discards the `R` largest actual factors.  It has exactly `(k_sigma-R)_+` prime factors, so

\[
\boxed{
(k_\sigma-R)_+\log(T/7)
\le
\log\operatorname{Tail}_R(P_\sigma)
\le
(k_\sigma-R)_+\log(T/3).
}
\tag{7.3}
\]

Summing gives the exact comparison

\[
\boxed{
H_R\log(T/7)
\le
\sum_\sigma\log\operatorname{Tail}_R(P_\sigma)
\le
H_R\log(T/3).
}
\tag{7.4}
\]

## 7.2 Branch-aware Apéry formulation

Choose a deterministic actual sign for every actual partner: for example, assign it to minus whenever the actual minus secondary condition holds, and otherwise to plus.  This partitions

\[
S_\sigma=S^-_\sigma\sqcup S^+_\sigma
\tag{7.5}
\]

with

\[
\prod_{p\in S^-_\sigma}p\mid G^-_\sigma,
\qquad
\prod_{p\in S^+_\sigma}p\mid G^+_\sigma.
\tag{7.6}
\]

Select an exceptional set `E_sigma subset S_sigma` with

\[
|E_\sigma|=\min\{R,k_\sigma\}.
\]

Define the selected actual Apéry tails

\[
D^-_{\sigma,R}
:=
\prod_{p\in S^-_\sigma\setminus E_\sigma}p,
\qquad
D^+_{\sigma,R}
:=
\prod_{p\in S^+_\sigma\setminus E_\sigma}p.
\tag{7.7}
\]

Then

\[
D^-_{\sigma,R}\mid G^-_\sigma,
\qquad
D^+_{\sigma,R}\mid G^+_\sigma,
\tag{7.8}
\]

and

\[
\omega(D^-_{\sigma,R}D^+_{\sigma,R})
=(k_\sigma-R)_+.
\tag{7.9}
\]

The **smallest selected actual-Apéry tail-height premise** is:

> **SATH\(_R\).**  There are deterministic valid branch assignments and exceptional sets `E_sigma`, with at most `R` actual partners discarded per upper state, such that
> \[
> \boxed{
> \sum_\sigma
> \log\bigl(D^-_{\sigma,R}D^+_{\sigma,R}\bigr)
> =o_J\!\left(\frac{T^2}{\log T}\right).
> }
> \tag{7.10}
> \]

No full gcd radical is present in this premise.  It does not charge nonactual factors, does not require a pointwise smoothness theorem, and does not require a uniform statement for every artificial sign assignment.  It retains exactly one squarefree lower-prime unit for each row beyond upper capacity `R`.

By (7.3)-(7.4), SATH\(_R\) implies

\[
\boxed{
H_R
=o_J\!\left(\frac{T^2}{(\log T)^2}\right).
}
\tag{7.11}
\]

Conversely, in the fixed macroscopic window, (7.11) implies (7.10) for every choice of exactly `min(R,k_sigma)` discarded actual partners.  Thus SATH\(_R\) is equivalent to the desired Hall-excess estimate up to fixed constants.  That equivalence is a feature: it identifies the exact remaining arithmetic content without strengthening it to a noisy full-radical statement.

## 7.3 A stronger recurrence-certified version

A continuant or resultant attack may use a stronger sufficient premise.  For every retained actual partner, choose its actual p-specific recurrence certificate `W_{sigma,p}`—for example the appropriate value `N_h(x)` in the reflected bistar coordinates—with

\[
p\mid W_{\sigma,p}.
\]

Then it would suffice to prove

\[
\sum_\sigma
\log\operatorname{rad}_{\text{window}}
\left(
\prod_{p\in S_\sigma\setminus E_\sigma}
W_{\sigma,p}
\right)
=o_J\!\left(\frac{T^2}{\log T}\right).
\tag{7.12}
\]

This is genuinely selected and may be approachable by a new cross-characteristic norm or resultant.  It is stronger than SATH\(_R\), because the certificate radical may contain extra primes.  The atom-only product over every candidate certificate is precisely the saturated construction rejected above.

# 8. Final answer to each proposed route

| Route | Exact audit |
|---|---|
| Determinantal divisor/Fitting ideal from only the two local gcd atoms | Intermediate diagonal minors principalize to `1`; the full determinant gives the candidate radical.  Any more elaborate fixed output obeys Theorem 3.1 and must contain all but `R` candidates to pay all possible actual tails. |
| Elementary symmetric sum | Has roughly attractive numerical degree but no guaranteed divisibility by any chosen candidate prime. |
| Gcd of all `d`-fold products | Equals `1` for `d<m`. |
| Lcm of all `d`-fold products | Equals the full radical. |
| Product of all `d`-fold products | Equals a high power of the full radical. |
| Full radical divided by `R` smallest candidates | Valid universal paying carrier, but has `m-R` factors and is near-full; it is actually the largest `R`-deletion quotient. |
| Full radical divided by `R` largest candidates | Sharp least-height universal carrier, still has `m-R` factors and pays all candidate noise. |
| Actual product divided by `R` actual factors | Exact desired tail, but requires actual-partner selection.  Deleting the `R` largest actual factors gives the weakest height premise. |
| q-side recurrence/reflection flag | One selected q-zero orbit, fixed dimension independent of `k`; it cannot turn distinct p-characteristics into a `k`-fold rank defect. |
| Product of prescribed p-continuant flags | If prescribed over all candidates, saturated/full-noise; if selected over actual partners, it is a valid route but assumes precisely the missing actual selection. |

The sharp algebraic conclusion is therefore

\[
\boxed{
\text{unmarked exact threshold support}
=	ext{all candidates except at most }R.
}
\tag{8.1}
\]

Equivalently, for every active star,

\[
\boxed{
\text{unavoidable atom-only overhead}
=(m_\sigma-k_\sigma)\log T.
}
\tag{8.2}
\]

A substantially cheaper carrier requires new information which distinguishes actual partners from foreign factors.  The smallest theorem to request is SATH\(_R\), or a genuinely cross-characteristic certificate theorem implying it—not another principalization of the two prescribed gcd atoms.
