# Q8495 — Corrected MOD43 localization audit

## Executive verdict

The previous counterexample using `M=[4], b=[2]` was invalid for
`R = Z[1/q : q prime, q <= 32]`, because 2 is a unit in R. The corrected
example is `M=[43^2], b=[43]`.

Classification:

- The implication from an R-solution to every residue-field solution is a
  **proved theorem**.
- The claim that residue-field solvability for every maximal ideal implies
  R-solvability is a **false converse** in general.
- The matrix `[43^2]` example is an **exact finite counterexample**.
- Extra hypotheses such as cokernel flatness/saturation can restore a form of
  the converse and are **conditional implications**.

## Always-valid forward implication

Let R be any commutative ring and let

\[
Mx=b
\]

be a finite matrix equation over R. For any maximal ideal m of R, reduction
modulo m gives a ring map

\[
R\to R/m.
\]

If x is a solution over R, then applying this map entrywise gives

\[
\bar M\bar x=\bar b
\]

in the residue field. Therefore:

\[
\exists x\in R^n,\ Mx=b
\Longrightarrow
\forall\mathfrak m\in\operatorname{Max}(R),
\exists \bar x\in(R/\mathfrak m)^n,
\bar M\bar x=\bar b.
\]

This is the only direction needed for a valid MOD43 obstruction.

## Correct counterexample

Take

\[
M=[43^2],\qquad b=[43].
\]

The equation is

\[
43^2x=43,
\]

so it requires

\[
x=1/43.
\]

Because

\[
R=\mathbb Z[1/q:q\le 32],
\]

43 is not inverted. Hence

\[
1/43\notin R,
\]

and the equation has no solution over R.

Now reduce modulo every maximal ideal.

For a prime P>32, the residue field is F_P.

- If P=43, then both sides reduce to zero:

\[
0\cdot x=0,
\]

so every x is a solution.

- If P\ne43, then 43 is invertible in F_P and

\[
43^2x=43
\]

has solution

\[
x=43^{-1}\in F_P.
\]

Therefore the equation is solvable modulo every prime P>32, but not solvable in R.

## Why localization/Nakayama/Smith does not give the converse

The obstruction is the torsion class

\[
[43]\in \operatorname{coker}(43^2:R\to R).
\]

The cokernel is

\[
R/(43^2),
\]

which contains nonzero 43-primary torsion. Reduction modulo maximal ideals detects whether the class vanishes after tensoring with residue fields, but it does not detect the required higher valuation.

In Smith normal form language, the invariant factor is

\[
43^2.
\]

The target has valuation one at 43. The residue-field test only sees whether the valuation is zero or positive after reduction; it does not see that one power of 43 remains missing.

Thus mod-P solvability alone does **not** detect higher P-adic Smith valuations.

## Conditions restoring a converse

A sufficient condition is that the relevant cokernel have no torsion obstruction.

For a map

\[
M:R^n\to R^m,
\]

write

\[
C=\operatorname{coker}(M).
\]

The equation Mx=b is solvable exactly when the class [b] in C is zero.

If C is flat over R, then vanishing after tensoring with all residue fields forces the class to vanish in the relevant finitely presented setting. Equivalently, if im(M) is saturated:

\[
au r\in \operatorname{im}(M),
\quad \tau\ne0
\Longrightarrow
r\in\operatorname{im}(M),
\]

then hidden prime-power torsion cannot occur.

Another exact sufficient condition is the full Smith valuation condition: for every prime P not inverted in R, the P-adic valuation inequalities on the Smith factors must certify that b lies in the image. Checking only residue classes modulo P is weaker.
