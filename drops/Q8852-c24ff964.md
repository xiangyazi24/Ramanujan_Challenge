# Exact CRT audit of Palm-1: the requested estimate is true, but it is deterministic rather than independence

## Executive verdict

The displayed target is valid with an absolute implied constant, but for a much simpler reason than Erdős–Turán, the large sieve, or Apéry-specific equidistribution:

\[
0\leq N_{p,q}:=\#\{m<M:m\bmod p\in Z_p,\ m\bmod q\in Z_q\}
\leq |Z_p|\,|Z_q|.
\]

Moreover every proposed “independent” main term also lies between \(0\) and \(|Z_p||Z_q|\), because \(pq>M=X^2\). Hence

\[
\boxed{
\left|N_{p,q}-\frac{M|Z_p||Z_q|}{pq}\right|
\leq |Z_p||Z_q|
}
\]

and, with the \(J_p\) used in the question,

\[
\boxed{
\left|N_{p,q}-J_p\frac{|Z_q|}{q}\right|
\leq |Z_p||Z_q|.
}
\]

The constant \(1\) works in both boxes. No distribution theorem is being used.

This is exactly the same deterministic content as the already-bankable \(k=2\) estimate in `problems/3.2/pairpalm_result.tex`, where the repository proves

\[
F_2(X)\leq 4M\lambda_X^2.
\]

Thus Q8851’s proposed Palm-1 statement is closed, but it must not be recorded as “independence.” Its error is of the same natural size as the full pair mass, and it provides no input toward the genuinely open \(k\geq 3\), especially \(k=7,8\), cross-prime problem.

There are also two normalization corrections:

1. Since \(pq>M\), one has \(\lfloor M/(pq)\rfloor=0\) exactly, not “0 or 1.” The number of representatives of one CRT class is nevertheless \(0\) or \(1\).
2. The identity
   \[
   J_p=|Z_p|\lfloor M/p\rfloor
   =\#\{m<M:m\bmod p\in Z_p\}
   \]
   is generally false. It misses the residue classes in the final incomplete block.

The corrected exact marginal is given below.

---

## 1. Correct the one-prime marginal first

Write

\[
s_p:=|Z_p|,\qquad
k_p:=\left\lfloor\frac Mp\right\rfloor,\qquad
r_p:=M-pk_p,\quad 0\leq r_p<p,
\]

and

\[
\Omega_p:=\{0\leq m<M:m\bmod p\in Z_p\},\qquad
A_p:=|\Omega_p|.
\]

Each residue \(z\in Z_p\) occurs \(k_p+1\) times below \(M\) when \(z<r_p\), and \(k_p\) times otherwise. Therefore

\[
\boxed{
A_p=s_pk_p+u_p,\qquad
u_p:=|Z_p\cap[0,r_p)|,\qquad 0\leq u_p\leq s_p.
}
\]

Thus the quantity called \(J_p\) in the question is the lower-block marginal

\[
J_p^-:=s_pk_p,
\]

not the exact marginal. One has

\[
A_p=\frac{Ms_p}{p}+\delta_p,\qquad |\delta_p|\leq s_p,
\]

and likewise

\[
J_p^- =\frac{Ms_p}{p}+\delta_p^-,\qquad |\delta_p^-|<s_p.
\]

The distinction is harmless at the requested \(O(s_ps_q)\) scale, but it matters if the formula is described as exact.

## 2. Exact CRT proof of the pair estimate

For distinct \(p,q\in(X,2X]\), put

\[
N_{p,q}:=|\Omega_p\cap\Omega_q|.
\]

For every \((a,b)\in Z_p\times Z_q\), CRT gives one class \(c_{p,q}(a,b)\in[0,pq)\). Since \(pq>M\), that class contributes exactly

\[
\mathbf 1_{c_{p,q}(a,b)<M}
\]

to \(N_{p,q}\). Hence

\[
N_{p,q}
=\sum_{a\in Z_p}\sum_{b\in Z_q}
  \mathbf 1_{c_{p,q}(a,b)<M},
\]

so immediately

\[
0\leq N_{p,q}\leq s_ps_q.
\]

Now set

\[
B_{p,q}:=\frac{Ms_ps_q}{pq}.
\]

Because \(0<M/(pq)<1\), one also has

\[
0<B_{p,q}<s_ps_q
\]
when \(s_ps_q>0\). Since both \(N_{p,q}\) and \(B_{p,q}\) lie in the interval \([0,s_ps_q]\),

\[
\boxed{
D_{p,q}:=\left|N_{p,q}-\frac{Ms_ps_q}{pq}\right|
\leq s_ps_q.
}
\]

For the baseline in the question,

\[
0\leq J_p^-\frac{s_q}{q}
\leq s_ps_q\frac{M}{pq}
<s_ps_q,
\]

and therefore, by the identical interval argument,

\[
\boxed{
N_{p,q}=J_p^-\frac{s_q}{q}+E_{p,q},\qquad
|E_{p,q}|\leq s_ps_q.
}
\]

This proves the requested target with implied constant \(1\).

### Sharpness of the deterministic scale

No universal \(o(s_ps_q)\) replacement is possible for arbitrary product sets. Fix \(a\in\mathbb F_p\) and let

\[
B_a:=\{b\in\mathbb F_q:c_{p,q}(a,b)<M\}.
\]

The map from integers \(m<M\) with \(m\equiv a\pmod p\) to \(m\bmod q\) is injective because \(M<pq\), so

\[
|B_a|=\#\{m<M:m\equiv a\pmod p\}
\in\{k_p,k_p+1\}.
\]

Choose \(Z_p=\{a\}\) and any \(t\)-element subset \(Z_q\subseteq B_a\). Then every one of the \(t=s_ps_q\) CRT points lies below \(M\), whence

\[
N_{p,q}=t,\qquad
D_{p,q}=t\left(1-\frac{M}{pq}\right).
\]

For \(p,q\) near \(2X\), this is close to \(3t/4\). Thus the \(O(s_ps_q)\) scale is genuinely sharp without extra arithmetic input, even for sparse sets.

## 3. The corrected Palm-1 identity

Let

\[
F_1:=\sum_{q\in\mathcal P_X}A_q
=\sum_{0\leq m<M}K_X(m)
\]

be the actual first factorial moment, and let

\[
T_p^{\mathrm{Palm},1}:=
\sum_{\substack{q\in\mathcal P_X\\q\ne p}}N_{p,q}.
\]

The clean finite-marginal form is

\[
\boxed{
T_p^{\mathrm{Palm},1}
=\frac{A_p(F_1-A_p)}{M}
+O\!\left(s_p\sum_{q\ne p}s_q\right).
}
\]

Indeed,

\[
A_p=\frac{Ms_p}{p}+O(s_p),\qquad
A_q=\frac{Ms_q}{q}+O(s_q),
\]

so

\[
\frac{A_pA_q}{M}
=\frac{Ms_ps_q}{pq}+O(s_ps_q),
\]

and the preceding CRT estimate gives

\[
N_{p,q}=\frac{A_pA_q}{M}+O(s_ps_q).
\]

Summing over \(q\ne p\) proves the box.

The question’s \(J_p^-\)-version is also valid at the same error scale. Let

\[
F_1^-:=\sum_qJ_q^-.
\]

Since

\[
\left|\frac{s_q}{q}-\frac{J_q^-}{M}\right|<\frac{s_q}{M},
\]

one has

\[
N_{p,q}=rac{J_p^-J_q^-}{M}+O(s_ps_q).
\]

Consequently

\[
T_p^{\mathrm{Palm},1}
=\frac{J_p^-(F_1^--J_p^-)}{M}
+O\!\left(s_p\sum_{q\ne p}s_q\right).
\]

Finally \(0\leq F_1-F_1^-\leq\sum_qs_q\), so replacing \(F_1^-\) by the actual \(F_1\), or replacing \(J_p^-\) by \(A_p\), changes the displayed main term by an amount already absorbed by the same error. This is the precise sense in which the two Palm formulations are equivalent.

### Aggregate consequence

With

\[
\lambda_X:=\sum_{X<p\leq2X}\frac{s_p}{p},
\]

we have

\[
\sum_p s_p
=\sum_p p\frac{s_p}{p}
\leq2X\lambda_X.
\]

Therefore the total discrepancy satisfies, without Cauchy–Schwarz,

\[
\boxed{
\sum_{p\ne q}D_{p,q}
\leq\sum_{p\ne q}s_ps_q
\leq\left(\sum_ps_p\right)^2
\leq4X^2\lambda_X^2
=4M\lambda_X^2.
}
\]

This is exactly the requested aggregate scale. It is also exactly why `pairpalm_result.tex` obtains the four-constant bound for \(F_2\).

## 4. Correct Fourier factorization

Let

\[
e_n(x):=e^{2\pi i x/n},\qquad
S_p(u):=\sum_{a\in Z_p}e_p(ua).
\]

Let \(\bar q\) denote the inverse of \(q\pmod p\), and \(\bar p\) the inverse of \(p\pmod q\). A CRT lift is

\[
c_{p,q}(a,b)
\equiv aq\bar q+bp\bar p\pmod{pq}.
\]

Hence the exact product formula is

\[
\boxed{
S_{A_{p,q}}(h)
=S_p(h\bar q\bmod p)\,
 S_q(h\bar p\bmod q),
}
\]

where \(A_{p,q}=c_{p,q}(Z_p\times Z_q)\subseteq\mathbb Z/(pq)\mathbb Z\).
The unit factors \(\bar q,\bar p\) are missing from the formula in the question. They only permute the nonzero frequencies, so they do not affect pointwise magnitudes or Parseval norms, but they matter in an exact identity.

Because \(h\pmod{pq}\mapsto(h\bar q\pmod p,h\bar p\pmod q)\) is a bijection,

\[
\sum_{h\bmod pq}|S_{A_{p,q}}(h)|^2
=\left(\sum_{u\bmod p}|S_p(u)|^2\right)
 \left(\sum_{v\bmod q}|S_q(v)|^2\right)
=pq\,s_ps_q.
\]

Thus

\[
\frac1{pq}\sum_{h\bmod pq}|S_{A_{p,q}}(h)|^2=s_ps_q.
\]

So the product set has RMS Fourier size \(\sqrt{s_ps_q}\). This is real mean-square cancellation, but it is only ordinary Parseval: every subset of size \(s_ps_q\) in a cyclic group of order \(pq\) satisfies the same identity. It is not an extra gain from CRT multiplicativity.

Moreover Cauchy–Schwarz in the full Erdős–Turán harmonic sum gives only

\[
\sum_{h=1}^{pq-1}\frac{|S_{A_{p,q}}(h)|}{h}
\ll\sqrt{pq\,s_ps_q},
\]

which is roughly \(X\sqrt{s_ps_q}\). In the sparse regime \(s_ps_q=O(1)\), this is much worse than the elementary bound \(D_{p,q}\leq s_ps_q\).

## 5. Answers to the five questions

### 5.1 Does the product structure itself give useful cancellation?

**Only at the universal Parseval level, not at the needed low-frequency or discrepancy level.**

The exact full-period mean square is

\[
\sum_{h\bmod pq}|S_A(h)|^2=pq|A|,\qquad |A|=s_ps_q.
\]

But this holds for every set \(A\subseteq\mathbb Z/(pq)\mathbb Z\). The sharpness construction in Section 2 shows that a CRT product set can still have discrepancy \(\asymp |A|\). Therefore product factorization does not force a nontrivial pairwise discrepancy estimate.

The observed fact

\[
\max_{1\leq h<p}|S_p(h)|\approx s_p
\]

is also not surprising. For a two-point set \(Z_p=\{a,b\}\), multiplication by \(a-b\) permutes the nonzero residues, and

\[
\max_{h\ne0}|e_p(ha)+e_p(hb)|
=2\cos(\pi/p)=2-o(1).
\]

The current Apéry data are dominated by empty zero sets and reflection pairs of size \(2\), so pointwise maxima near \(|Z_p|\) are essentially forced. They do not contradict random-looking locations.

### 5.2 Can the different frequencies cancel in the Erdős–Turán sum?

**Not in the displayed Erdős–Turán majorant.** It contains

\[
\sum_{h\leq H}\frac{|S_p(h\bar q)|\,|S_q(h\bar p)|}{h},
\]

whose summands are nonnegative. All phase oscillation has already been discarded by the absolute values.

One may return to the signed Fourier identity

\[
N_{p,q}-\frac{Ms_ps_q}{pq}
=\frac1{pq}\sum_{h\ne0}
 S_{A_{p,q}}(h)\,\overline{S_{[0,M)}(h)},
\]

where phase cancellation is possible. But proving cancellation in this signed sum is exactly the original discrepancy problem; “different frequencies” do not supply it for free. The variable \(h\) runs through one deterministic CRT coupling of the two frequency systems, not through independent random samples.

### 5.3 Is there an applicable Bombieri–Vinogradov theorem for most pairs?

**No off-the-shelf Bombieri–Vinogradov theorem applies to this object.** Classical Bombieri–Vinogradov and Barban–Davenport–Halberstam control a fixed arithmetic sequence, especially the von Mangoldt function, averaged over moduli and residue classes. Sparse-moduli variants and uniform-residue-class refinements still use the arithmetic of primes in progressions.

Here:

* the residue set itself changes with \(p\), through the condition \(b_r\equiv0\pmod p\);
* the modulus is \(pq\asymp M\), so the interval contains less than one full period;
* the quantity is a correlation between two modulus-dependent sparse sets, not an error term for a fixed sequence in arithmetic progressions.

A theorem giving \(D_{p,q}\leq C\) for most pairs would therefore be a new Apéry zero-set theorem, not a direct corollary of Bombieri–Vinogradov.

More importantly, the numerical \(O(1)\) phenomenon has a simpler explanation:

\[
D_{p,q}\leq s_ps_q.
\]

Under the empirical Poisson\((1/2)\) model for reflection-pair counts, \(Z_p\) is empty with probability about \(e^{-1/2}\). Thus about

\[
1-(1-e^{-1/2})^2\approx0.845
\]

of all pairs have at least one empty zero set and hence \(D_{p,q}=0\) identically. Among pairs where both sets are nonempty, the most common case is \(s_p=s_q=2\), and then \(D_{p,q}\leq4\) deterministically. Consequently “\(D=0\) or \(O(1)\) for most pairs” is not, by itself, numerical evidence for CRT equidistribution.

A Poisson cardinality law would imply the weaker tightness statement: for every \(\varepsilon>0\), some \(C(\varepsilon)\) bounds \(D_{p,q}\) for all but an \(\varepsilon\)-fraction of pairs. That is primarily a one-prime zero-count statement, not a BV phenomenon.

### 5.4 Can a large-sieve second moment help?

There are two different answers.

#### The useful bound is already elementary

Since \(D_{p,q}\leq s_ps_q\),

\[
\boxed{
\sum_{p,q}D_{p,q}^2
\leq\left(\sum_ps_p^2\right)^2.
}
\]

Thus any second-moment theorem

\[
\sum_{X<p\leq2X}s_p^2\ll X/\log X
\]

would immediately give

\[
\sum_{p,q}D_{p,q}^2\ll X^2/(\log X)^2.
\]

Under the Poisson\((1/2)\) reflection-pair heuristic, \(s_p=2K_p\) away from the rare central zero and

\[
\mathbb E(s_p^2)=4\mathbb E(K_p^2)=4(1/2+1/4)=3,
\]

so this second-mass scale is exactly what the heuristic predicts. But this again uses only the sizes \(s_p\), not the CRT locations.

For the actual goal stated in the question, even this is unnecessary, because the direct \(L^1\) estimate already gives

\[
\sum_{p,q}D_{p,q}\leq4X^2\lambda_X^2.
\]

Cauchy–Schwarz is strictly superfluous here.

#### What the generic additive large sieve gives

It is still useful to audit the natural large-sieve route. Define the centered periodic function

\[
g_p(m):=1_{m\bmod p\in Z_p}-\frac{s_p}{p}.
\]

Its nonzero Fourier coefficients are

\[
c_{p,a}=\frac1pS_p(-a),\qquad 1\leq a<p,
\]

with

\[
\sum_{a=1}^{p-1}|c_{p,a}|^2
=\frac{s_p}{p}-\frac{s_p^2}{p^2}.
\]

The reduced fractions \(a/p\), for \(p\in(X,2X]\), are separated by at least \(1/(4X^2)\). Hence the additive large sieve, with \(M=X^2\), gives for \(S_X:=\max_ps_p\)

\[
\left\|\sum_px_pg_p\right\|_{\ell^2([0,M))}^2
\ll X S_X\sum_p|x_p|^2.
\]

If \(G=(\langle g_p,g_q\rangle)_{p,q}\) is the Gram matrix, then

\[
\|G\|_{\mathrm{op}}\ll XS_X
\]

and

\[
\operatorname{tr}G
=\sum_p\|g_p\|_2^2
\ll M\lambda_X+\sum_ps_p+\sum_ps_p^2.
\]

Therefore

\[
\sum_{p,q}|\langle g_p,g_q\rangle|^2
=\operatorname{tr}(G^2)
\ll XS_X\left(M\lambda_X+\sum_ps_p+\sum_ps_p^2\right).
\]

In the empirically bounded-size regime \(S_X=O(1)\), \(\lambda_X\asymp1/\log X\), this is of order at best

\[
X^3/\log X,
\]

and Cauchy–Schwarz over about \(X^2/(\log X)^2\) ordered pairs gives an \(L^1\) bound of order \(X^{5/2}/(\log X)^{3/2}\), much worse than the elementary \(X^2/(\log X)^2\) bound. Thus the standard additive large sieve is not the missing mechanism.

### 5.5 Do the Apéry zero sets have a proved equidistribution property?

**No proved spatial equidistribution theorem of the needed type is currently present in the repository or in the standard Apéry congruence literature.** The current exact structure is:

1. **Gessel’s \(p\)-Lucas law:**
   \[
   b_{mp+r}\equiv b_m b_r\pmod p.
   \]
   This controls digit propagation but not the positions of zeros within the first digit block.
2. **Reflection:**
   \[
   b_{p-1-r}\equiv b_r\pmod p.
   \]
   Hence \(Z_p\) is invariant under \(r\mapsto p-1-r\).
3. **No consecutive zeros**, the gap-polynomial argument, the current \(O(p^{2/3})\) total zero bound, and the corresponding interval bound \(O(|I|^{2/3})\).
4. The recent generating-series result of Caruso–Fürnsinn–Vargas-Montoya–Zudilin, arXiv:2510.23298, proves a striking factorization of the truncation polynomial
   \[
   A_p(t)=\sum_{r=0}^{p-1}b_rt^r
   \]
   as a square or a fixed quadratic times a square, depending on \(p\bmod24\), and computes the associated function-field Galois group. This does not imply equidistribution of the zero coefficients \(b_r=0\).

Reflection merely makes the Fourier transform real after a harmless phase. If \(c=(p-1)/2\), then \(Z_p-c\) is symmetric under \(x\mapsto-x\), so

\[
e_p(-hc)S_p(h)
\]

is real. This is symmetry, not cancellation; symmetric sets can have Fourier coefficients as large as their cardinality.

The Poisson\((1/2)\) observation can be formalized as a conjecture, but the correct strong form is a **marked Poisson law**, not only a law for \(|Z_p|\). Let \(R_p\subset[0,(p-1)/2)\) contain one representative from each noncentral reflection pair. A natural fixed-test conjecture is that, for every fixed \(k\) and continuous test function \(F\),

\[
\frac{1}{\pi(2Y)-\pi(Y)}
\sum_{Y<p\leq2Y}
\sum_{\substack{r_1,\ldots,r_k\in R_p\\\text{distinct}}}
F\!\left(\frac{r_1}{p},\ldots,\frac{r_k}{p}\right)
\longrightarrow
\int_{(0,1/2)^k}F(x_1,\ldots,x_k)\,dx_1\cdots dx_k.
\]

Taking \(F=1\) gives factorial moments \((1/2)^k\), i.e. Poisson\((1/2)\) pair counts. Nonconstant \(F\) adds spatial equidistribution.

Even this fixed-test statement would not automatically control the Erdős–Turán maximum over frequencies growing with \(p\). For that one needs a quantitative, mesoscopic marked-Poisson theorem or an averaged signed CRT-dispersion estimate. No such theorem is currently proved.

The repository’s existing Chebotarev Poisson calculation for fixed gap polynomials \(N_h\) does not bridge this gap: it concerns roots of a fixed polynomial as \(p\) varies. The actual zero set \(Z_p\) involves indices \(r\) moving through an interval of length \(p\), so the quantifier order is different.

## 6. What should be banked from Q8852

### Bankable lemma

For arbitrary subsets \(Z_p\subseteq\mathbb F_p\), distinct primes \(p,q\in(X,2X]\), and \(M=X^2\),

\[
N_{p,q}
=\#\{(a,b)\in Z_p\times Z_q:c_{p,q}(a,b)<M\}
\]

satisfies

\[
\left|N_{p,q}-\frac{M|Z_p||Z_q|}{pq}\right|
\leq|Z_p||Z_q|.
\]

With \(A_p=|\Omega_p|\) and \(F_1=\sum_pA_p\),

\[
T_p^{\mathrm{Palm},1}
=\frac{A_p(F_1-A_p)}M
+O\!\left(|Z_p|\sum_{q\ne p}|Z_q|\right).
\]

Consequently

\[
\sum_{p\ne q}D_{p,q}\leq4M\lambda_X^2,
\qquad
F_2(X)\leq4M\lambda_X^2.
\]

### Do not bank

Do not describe this as pairwise equidistribution, Palm independence, a Bombieri–Vinogradov theorem, or Fourier cancellation. The error is exactly of the same order as the total number of candidate residue pairs and is sharp for arbitrary CRT product sets.

### Exact remaining arithmetic

For \(k=2\), no further arithmetic is needed for the upper bound used in the project. For higher factorial moments, the open input remains an aggregate statement saying that only the expected tiny fraction of \(k\)-fold residue tuples have a representative below \(M\). When \(k\geq3\), the product cardinality \(\prod_i|Z_{p_i}|\) no longer gives the independence-scale estimate because \(\prod_i p_i\gg M\), and this is where the genuine cross-prime problem begins.

## Final answer

1. The CRT product has ordinary RMS Fourier cancellation, but no automatic discrepancy gain.
2. The absolute Erdős–Turán sum cannot exploit phase oscillation; the signed version is the original problem.
3. No standard Bombieri–Vinogradov theorem applies; most observed \(O(1)\) discrepancies are already forced by the tiny zero-set sizes.
4. The desired aggregate bound follows immediately from \(D_{p,q}\leq|Z_p||Z_q|\); neither a large sieve nor Cauchy–Schwarz is needed.
5. Apéry zeros have Lucas propagation, reflection, no-consecutive-zero and gap-polynomial structure, but no proved spatial equidistribution. Poisson\((1/2)\) remains a cardinality/marked-point-process conjecture for the actual coefficient zeros.

So Q8851’s exact target is proved, after correcting the marginal \(J_p\), but it closes only the already-known \(k=2\) deterministic layer.
