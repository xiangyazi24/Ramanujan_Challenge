# Poisson convergence for all (HM)_k: Chen–Stein route

## Short answer

The Chen–Stein idea is the right conceptual compression: if one can prove Poisson convergence for
\[
K_X(m)=\#\{p\in(X,2X]:m\bmod p\in Z_p\},
\]
then every factorial moment hypothesis (HM)_k follows simultaneously. However, the current CRT estimate in (C) is not enough by itself to prove Chen–Stein convergence, because the Chen–Stein error is not the raw count of simultaneous solutions; it requires a coupling/dependency estimate for the whole family of indicators.

The obstruction is the same one already visible in P3.2: CRT gives independence when averaging over a complete residue box, but P3.2 fixes the integer m and asks for density over m. The required statement is a global equidistribution theorem for the Apéry zero sets.

## (A) Chen–Stein formulation

Let
\[
X_p(m)=1_{m\bmod p\in Z_p},\qquad \lambda_p=|Z_p|/p.
\]
Then
\[
\lambda_X=\sum_{X<p\le 2X}\lambda_p.
\]
Since computationally |Z_p| is typically O(1), \(\lambda_p\asymp 1/p\), and therefore
\[
\lambda_X\approx\sum_{X<p\le2X}\frac1p\asymp\frac1{\log X}.
\]
So the expected number of hits is small in the dyadic interval.

For a genuinely independent family, Poisson approximation is immediate. The problem is proving that the deterministic sequence
\[
m\mapsto (X_p(m))_p
\]
behaves like independent Bernoulli variables.

## (B) Pairwise independence

For a random residue m modulo pq, CRT gives exact independence:

\[
\Pr(X_p=1,X_q=1)=\frac{|Z_p||Z_q|}{pq}=\lambda_p\lambda_q.
\]

But P3.2 does not sample m modulo pq independently. It samples the interval [0,N] and asks about the actual Apéry values b_m. Therefore the needed statement is a discrepancy estimate:

\[
\#\{m\le N:m\bmod p\in Z_p,m\bmod q\in Z_q\}
=\frac{N|Z_p||Z_q|}{pq}+o(N\lambda_p\lambda_q).
\]

CRT alone only supplies the exact count in one complete period pq.

## (C) Why the O(1) CRT error is insufficient

The proposed estimate is

\[
\frac{X^2}{pq}|Z_p||Z_q|+O(|Z_p||Z_q|).
\]

The main term is roughly

\[
\frac{X^2}{p^2q^2},
\]

because |Z_p|,|Z_q| are empirically O(1). The error is O(1).

For a fixed pair this is harmless only when the averaging interval is much longer than pq. In the P3.2 range p,q are themselves of size X, so pq is of size X^2. Hence the interval [0,X^2) contains only about one CRT period. The O(1) error is therefore the same size as (or larger than) the expected count.

This is the key failure mode: pairwise CRT independence exists in the finite probability space Z/(pq), but not automatically in the initial segment of integers.

## (D) Would Poisson convergence solve all (HM)_k?

Yes.

If one proves

\[
d_{TV}(K_X,\operatorname{Poisson}(\lambda_X))\to0,
\]

then all bounded factorial moments converge:

\[
E[(K_X)_k]\to\lambda_X^k
\]

for every fixed k. Therefore all higher (HM)_k hypotheses follow from one theorem instead of proving them separately.

Moreover, a sufficiently strong Poisson theorem would close P3.2 because it implies the required control on the number of large prime divisors of b_n.

## But what theorem is actually needed?

The Chen–Stein route reduces P3.2 to proving a rare-event point-process theorem:

For primes p in (X,2X], the residue sets Z_p must be jointly equidistributed against intervals of integers with an error smaller than the Poisson scale.

A possible sufficient statement is a uniform pair correlation bound:

\[
\sum_{p\ne q}\left|
\#\{m\le N:X_p(m)=X_q(m)=1\}
-N\lambda_p\lambda_q
\right|=o(\lambda_X).
\]

This is substantially stronger than the CRT identity.

## Relation to the existing P3.2 strategy

The factorial moment method and the Chen–Stein method are not competing approaches:

* Proving every (HM)_k separately is a moment method.
* Proving Poisson convergence packages all moments at once.
* Both ultimately require the same arithmetic input: cancellation/equidistribution of the Apéry zero sets Z_p.

The advantage of Chen–Stein is organizational: it identifies the true target as a point-process convergence theorem. The disadvantage is that the required dependency estimates are essentially as hard as the original higher-moment problem.

## Conclusion

(A) Chen–Stein is mathematically appropriate.

(B) Pairwise CRT independence is exact only after averaging modulo pq, not for a fixed initial segment of integers.

(C) The O(1) CRT error is not sufficient in the critical range p,q≈X because the interval length is only one CRT period.

(D) A genuine Poisson convergence theorem would imply every (HM)_k simultaneously and would close P3.2, but proving that theorem requires the same deep equidistribution input that the current factorial moment approach is trying to establish.

The correct reformulation of P3.2 is therefore not merely “prove bounded factorial moments,” but “prove Poisson statistics for the Apéry zero residue process.”
