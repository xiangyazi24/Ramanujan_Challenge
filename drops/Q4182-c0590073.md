# 2. Termwise truncated Apéry-prefix congruence: PASS

Define
\[
\mathscr K_R(M)
:=\sum_{k=0}^{R}
\binom Mk^2\binom{M+k}{k}^2.
\]
Let `ell` be prime and write
\[
M=c\ell+r,\qquad 0\le r<\ell,
\]
with `r<=R<ell`.  In the q6 applications `c` is literally `6`, `13`, or `1`, so the large-shell primes automatically satisfy the harmless `c<ell` guard.

For `0<=k<ell`, Lucas gives
\[
\binom Mk\equiv\binom rk\pmod\ell.
\]
For the second binomial there are exactly two cases.

If `r+k<ell`, then no low-digit carry occurs and
\[
\binom{M+k}{k}
\equiv
\binom{r+k}{k}\pmod\ell.
\]

If `r+k>=ell`, the low base-`ell` digit of `M+k` is `r+k-ell<k`; therefore Lucas gives
\[
\binom{M+k}{k}\equiv0\pmod\ell.
\]
The ordinary integer `binom(r+k,k)` has the same one carry, so it too is `0 mod ell`.

Thus for every `k<ell`,
\[
\binom Mk^2\binom{M+k}{k}^2
\equiv
\binom rk^2\binom{r+k}{k}^2
\pmod\ell.
\]
For `k>r`, the first factor `binom(r,k)` is zero. Since `R>=r`, summing through `R` gives exactly
\[
\boxed{
\mathscr K_R(M)\equiv
\sum_{k=0}^{r}\binom rk^2\binom{r+k}{k}^2
=b_r\pmod\ell.
}
\]

No Gessel-Lucas theorem, recurrence division, or unproved p-adic lifting is being smuggled in. It is ordinary termwise binomial Lucas.

**Verdict:** PASS.

> **ONE-SCALE MARKED CELL DISPERSION `OMCD_(beta,rho)`.**  For one fixed `rho>0`, for each raw sign `sigma`, at the single cell length `Y=T^beta`,
> \[
> \boxed{
> \sum_{u,j}\nu_{u,j}^2
> \ll_J
> M_\sigma(T)\bigl(1+Y T^{-\rho}\bigr).
> }
> \tag{OMCD}
> \]
> It is enough that this hold for one fixed translate of the cell partition; logically, existence of one good translate is already sufficient.

The diagonal contribution is exactly
\[
\sum_{u,j}\nu_{u,j}=M_\sigma(T),
\]
so `(OMCD)` asks only for the off-diagonal same-cell mass
\[
\sum_{u,j}\nu_{u,j}(\nu_{u,j}-1)
\ll_J
Y M_\sigma(T)T^{-\rho}.
\]

Insert `(OMCD)` into (10.1):
\[
\begin{aligned}
E_\sigma(D)
&\ll_J
\frac DY M_\sigma(T)
\bigl(1+Y T^{-\rho}\bigr)\\
&=
D M_\sigma(T)
\left(Y^{-1}+T^{-\rho}\right)\\
&\ll
D M_\sigma(T)
\left(T^{-\beta}+T^{-\rho}\right).
\end{aligned}
\]
Thus
\[
\boxed{
OMCD_{\beta,\rho}
\Longrightarrow
APD_\eta
\quad\text{for every }0<\eta<\min\{\beta,\rho\}.
}
\tag{11.1}
\]

For the safe fixed choice
\[
\beta=\alpha_0/2,
\]
any
\[
\boxed{
0<\eta<\min\{\alpha_0/2,\rho\}
}
\]
closes every hard block.

An equivalent power-in-`Y` form is
\[
\sum_{u,j}\nu_{u,j}^2
\ll_J
M_\sigma(T)\bigl(1+Y^{1-\delta}\bigr)
\tag{OMCD-delta}
\]
for some `delta>0`. Then
\[
E_\sigma(D)
\ll_J
D M_\sigma(T)
\left(T^{-\beta}+T^{-\beta\delta}\right),
\]
so every
\[
\eta<\beta\min\{1,\delta\}
\]
works.

This is strictly leaner than `IPRD_delta` in the sense relevant to the proof task:

```text
IPRD_delta:
  every hard D;
  every deep base leaf;
  all shell-prime divisors of Gpref;
  includes phantom divisors;

OMCD_(beta,rho):
  one single mesoscopic scale Y=T^beta;
  aggregate over all selected states;
  actual marked leaves only;
  one local L2 statistic;
  no carrier and no phantom divisor.
```

It also uses **no lower bound** on `M_sigma`: the right side is normalized by the actual marked count itself.

I therefore regard `(OMCD)` as the weakest clean noncircular arithmetic theorem exposed by this independent reduction that genuinely closes full hard-range `APD_eta`. A direct APD assertion is logically weaker, of course, but would merely rename the desired conclusion; `(OMCD)` changes both the scale and the statistic.

# 12. Apéry-specific route to `OMCD`: joint quotient-row energy

The mesoscopic theorem has a concrete Apéry interpretation independent of Q4178 prefixes.

For a shell prime `p` let
\[
Z_p:=\{0\le x<p:p\mid b_x\}.
\]
For an integer quotient slope `k`, define the row-incidence indicator
\[
C_k(m,p)
:=
1_{\{0\le m-kp<p\}}
1_{\{m-kp\in Z_p\}}.
\]
For two lower primes `p<p'=p+Delta`, define
\[
J_k(p,p')
:=
\#\{x\in Z_p:x-k\Delta\in Z_{p'}\}.
\]
Equivalently `J_k(p,p')` is the number of common quotient-`k` row keys of the two prime columns.

## Plus

A same-state plus pair has two common rows
\[
n=6p+\rho=6p'+\rho',
\]
\[
N=13p+\alpha_+=13p'+\alpha_+'.
\]
Thus it supplies one collision counted by `J_6` and one by `J_13`.
The two row keys reconstruct the selected upper state:
\[
\boxed{
q=\frac{N-n}{6},
\qquad
t=2n-N.
}
\]
The typed event additionally keeps `q` prime, `0<=t<q`, `q|b_t`, the raw plus window, and the minus-first exclusion.

## Minus

A same-state minus pair has
\[
n=6p+\rho=6p'+\rho',
\]
\[
s=p+\alpha_-=p'+\alpha_-'.
\]
It therefore lies in `J_6 J_1`, and the row keys reconstruct
\[
\boxed{
q=\frac{n+s+1}{7},
\qquad
t=q-s-1.
}
\]
Again the selected upper mark and exact raw minus predicates are retained.

Hence every same-state pair injects into the appropriate **two-slope** lower-zero overlap:
\[
+ : J_6(p,p')J_{13}(p,p'),
\qquad
- : J_6(p,p')J_1(p,p').
\]
This is the structural reason `OMCD` is a plausible next theorem: it is not asking for generic spacing of prime divisors of a huge integer. It asks for decorrelation of **two distinct quotient-row incidence systems** at one mesoscopic prime scale.

One can package the selected version even more directly. For plus set
\[
H_+(u,p)
=C_6(n(u),p)C_{13}(N(u),p)
\]
and for minus
\[
H_-(u,p)
=C_6(n(u),p)C_1(s(u),p),
\]
then insert the exact raw window and minus-first predicates. Outside the fixed coefficient-prime set this is the actual marked incidence matrix `1_{p in P_sigma(u)}`.

For a cell `I_j`,
\[
\nu_{u,j}=\sum_{p\in I_j}H_\sigma(u,p).
\]
Thus `(OMCD)` is exactly the band-restricted second moment
\[
\boxed{
\sum_{u,j}
\left|\sum_{p\in I_j}H_\sigma(u,p)\right|^2
\ll_J
M_\sigma(T)(1+YT^{-\rho}).
}
\tag{12.1}
\]
This is a natural large-sieve/dispersion target for the **joint** `(6,c_sigma)` row system.

# 13. What current inputs give for the one-scale theorem

The current bank does not prove `(OMCD)`.

## Prime spacing alone

For one base prime, Brun--Titchmarsh gives only `O(Y/L)` possible prime partners in a length-`Y` interval. Consequently the direct prime-only envelope is
\[
\sum_{u,j}\nu_{u,j}^2
\ll_J
M_\sigma(T)\left(1+\frac YL\right),
\]
which is logarithmic, not `Y T^{-rho}`.

## Fixed separation plus `S_2`

Summing a fixed-Delta bound over `Delta<Y` gives at best `Y S_2(T)`. There is no known lower bound
\[
M_\sigma(T)\gg S_2(T)T^{-A}
\]
that would convert this to the required relative-`M_sigma` estimate. Using such a conversion would be exactly the forbidden lower-bound error the question asks us to detect.

## One-slope moments

Controlling `J_6` and `J_c` separately does not bound their intersection at a common prime pair. The needed statistic is genuinely two-slope.

## Ordinary resultants

The two lower zero pairs live in different defining characteristics `p` and `p'`. A same-field common-root resultant has the wrong quantifiers. Nothing in the cell argument changes that.

Thus the missing power is precisely a selected cross-characteristic two-slope decorrelation theorem.

# 14. A concrete proof program independent of prefixes

I would attack `(OMCD)` in the following order.

## 14.1 Expand only the off-diagonal cell energy

Write
\[
\sum_{u,j}\nu_{u,j}^2
=M_\sigma(T)+2\mathcal E^{\rm cell}_\sigma(Y),
\]
where `E_cell` counts actual marked same-state pairs whose two lower primes fall in one `Y`-cell.

Do **not** enlarge first to all divisors of a characteristic-zero carrier. Keep the selected `q` mark and the two quotient-row collisions visible.

## 14.2 Reindex by the two common row keys

For plus use `(n,N)`, for minus `(n,s)`.  The map from a pair of row keys to `(q,t)` is affine and fibre one by the formulas in Section 12.  This removes the false free `q`-average but also prevents occurrence loss.

The off-diagonal is then a banded column-pair energy of the joint incidence matrix `H_sigma`.

## 14.3 Large-sieve target

The first useful analytic theorem would be a dual large-sieve estimate of the shape
\[
\sum_{I\in\mathcal I_Y}
\sum_u
\left|\sum_{p\in I}a_p H_\sigma(u,p)\right|^2
\ll_J
\left(1+Y T^{-\rho}\right)
\sum_p|a_p|^2
\tag{14.1}
\]
for `a_p=1` on the shell, or even only for those `a_p` needed by the actual marked family.  Taking `a_p=1` gives `(OMCD)`.

This is much weaker than a full spectral theorem for every coefficient sequence, so one should not insist on the full operator norm if a direct positive-coefficient argument is available.

## 14.4 Primitive two-slope eliminant as a secondary route

For an actual transport with `c=13` or `1`, the characteristic-zero cross determinant
\[
\mathscr D_{c,\Delta}(r,a)
=
 b_r b_{a-c\Delta}
-b_a b_{r-6\Delta}
\]
is divisible by `p(p+Delta)`. Pointwise height is too large and the determinant changes with `Delta`, so Q4049's no-go remains.

But at the single mesoscopic range `Delta<Y=T^beta`, an **average primitive determinant radical** estimate could prove `(OMCD)` without ever constructing a prefix gcd. The correct order is:

```text
1. remove every universal small/content factor symbolically;
2. retain the selected reconstruction (q,t);
3. average the primitive large-prime divisor incidence over the cell band;
4. target only Y*T^{-rho} partners per marked leaf on average.
```

This is substantially less demanding than `IPRD_delta`, which asks to control every shell-prime divisor of every deep prefix gcd throughout every hard block.

## 14.5 Failure criterion

If even the joint two-row incidence matrix admits a theorem-compatible model with
\[
\sum_{u,j}\nu_{u,j}^2
\asymp
M_\sigma(T)(1+Y/L)
\]
at every polynomial `Y<T^{alpha_0}`, then the cell route has reached the same logarithmic barrier as Q4168/Q4169.  The next missing theorem would then have to use a genuinely p-adic or geometric relation between the two quotient-row zero conditions, not another scalar carrier.
