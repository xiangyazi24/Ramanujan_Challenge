## 3. Factorial-gauge modulus shift: exact identity, but no new restriction

Set

\[
P(n)=34n^3+51n^2+27n+5,
\qquad
\beta_n=(n!)^3b_n.
\]

Then the Apéry recurrence becomes the denominator-free sextic recurrence

\[
\boxed{\beta_{n+1}=P(n)\beta_n-n^6\beta_{n-1}.}
\tag{3.1}
\]

Define the h-step continuants

\[
W_0(X)=1,\qquad W_1(X)=P(X),
\]

\[
W_{h+1}(X)
=P(X+h)W_h(X)-(X+h)^6W_{h-1}(X).
\tag{3.2}
\]

A one-line induction on `h` gives the exact block identity

\[
\boxed{
\beta_{s+h}
=W_h(s)\beta_s
-s^6W_{h-1}(s+1)\beta_{s-1}.
}
\tag{3.3}
\]

Now take a genuine shifted pair

\[
q=p+h,\qquad q\mid\beta_s,\qquad p\mid\beta_{s+h}.
\]

Write

\[
u=\frac{\beta_s}{q},
\qquad
C_{s,h}=s^6W_{h-1}(s+1)\beta_{s-1}.
\]

Then (3.3) becomes

\[
\beta_{s+h}=qW_h(s)u-C_{s,h}.
\tag{3.4}
\]

Replacing `q` by `p+h` gives the apparent modulus-shift congruence

\[
\boxed{
p\mid hW_h(s)u-C_{s,h}.}
\tag{3.5}
\]

But this is **exactly tautological**.  Put

\[
X=hW_h(s)u-C_{s,h}.
\]

Then

\[
\boxed{qX=h\beta_{s+h}-pC_{s,h}.}
\tag{3.6}
\]

Since in the q=1 range

\[
0<h<N<p<q,
\]

both `q` and `h` are units modulo `p`.  Therefore

\[
\boxed{p\mid X\iff p\mid\beta_{s+h}.}
\tag{3.7}
\]

So the factorial gauge does not create an extra congruence: after the unavoidable quotient \(u=\beta_s/q\) is cleared, one recovers the original divisibility condition identically.

This also explains why a formal "finite difference in the modulus" has no quotient-free content here.  For any fixed integer `B`, if `q=p+h` and `q|B`, then `B=(p+h)u` and

\[
B\equiv hu\pmod p.
\]

The quotient `u=B/q` is intrinsic.  A WZ/binomial representation of the same integer cannot remove it without supplying a genuinely new identity.  Thus the modulus-shift route, by itself, is not the missing cross-prime input.

## 4. New aggregate pruning: the near-maximal gap tail is little-oh

Q2043 removes small gaps.  There is a complementary elementary geometry at the other end.

Let

\[
E_{\rm edge}(N;K)
\]

be the number of **ordered** q=1 prime pairs, with or without the Apéry divisibility conditions, satisfying

\[
N-K<|q-p|<N.
\]

Dropping the Apéry conditions only enlarges this count.

Consider `h=q-p>0` and write

\[
h=N-k,
\qquad1\le k<K.
\]

Because `q=p+h<=m<=2N`,

\[
p\le2N-h=N+k.
\]

Hence

\[
N<p\le N+k.
\tag{4.1}
\]

For fixed `p,h`, write `s=m-q`.  Then

\[
0\le s\le2N-q=2N-p-h=N+k-p.
\]

Thus the number of possible rows for this `p` is at most

\[
N+k-p+1\le k+1.
\]

Consequently

\[
E_h^+
\le
(k+1)\bigl(\pi(N+k)-\pi(N)\bigr).
\tag{4.2}
\]

For `k` in the upper half of `[1,K]`, Brun--Titchmarsh gives

\[
\pi(N+k)-\pi(N)\ll\frac{k}{\log k}
\ll\frac{k}{\log K}.
\]

For `k<=K^{1/2}` use the trivial bound.  Summing (4.2) gives

\[
\boxed{
E_{\rm edge}(N;K)
\ll \frac{K^3}{\log K}+K^{3/2}.
}
\tag{4.3}
\]

The negative-gap orientation contributes the same bound.

Now choose

\[
\boxed{
K_N=\left(\frac{N^2}{\log N\,\log\log N}\right)^{1/3}.
}
\tag{4.4}
\]

Since \(\log K_N\asymp\log N\),

\[
\boxed{
E_{\rm edge}(N;K_N)
\ll
\frac{N^2}{\log^2N\,\log\log N}
+\frac{N}{\sqrt{\log N\log\log N}}
=o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{4.5}
\]

This is a genuine new deletion: it removes a band of width

\[
K_N\asymp N^{2/3}(\log N\log\log N)^{-1/3}
\]

next to the maximal possible prime gap `N`.

No Apéry height estimate is used in (4.5).

F_{\rm HM}(N)
=
\sum_{\substack{N<m\le2N\\\lambda(m)>L_N}}

 p\ne q,\

\tag{5.1}

F_{\rm top}(N)=F_{\rm HM}(N)

## 6. Remove the trivial additive characters: exact dispersion residual

For `p>N` and `0<=r<p`, define

\[
I_p(r)=\mathbf1_{p\mid b_r},
\qquad
\Delta_p(r)=I_p(r)-\frac1p.
\]

By additive-character orthogonality,

\[
\boxed{
\Delta_p(r)
=\frac1p\sum_{a=1}^{p-1}e_p(a b_r).
}
\tag{6.1}
\]

Thus `Delta` contains **only nontrivial additive characters**.

Let the sum below run over exactly the heavy-midgap records in (5.1), but with `p,q` ranging over all top primes in the row, not only selected ones.  Put

\[
\mathfrak D_{\rm HM}(N)
:=
\sum_{\rm HM}\Delta_p(m-p)\Delta_q(m-q).
\tag{6.2}
\]

Expanding one factor gives

\[
I_pI_q-\Delta_p\Delta_q
=\frac{I_p}{q}+\frac{I_q}{p}-\frac1{pq}.
\tag{6.3}
\]

For every row

\[
\sum_{N<p\le m}\frac1p\ll\frac1{\log N}.
\tag{6.4}
\]

Therefore, after summing (6.3),

\[
\begin{aligned}
|F_{\rm HM}(N)-\mathfrak D_{\rm HM}(N)|
&\ll
\frac{T_{\rm top}(N)}{\log N}
+N\left(\frac1{\log N}\right)^2\\
&\ll
\frac{N^{5/3}}{\log^2N}
+\frac N{\log^2N}\\
&=o\!\left(\frac{N^2}{\log^2N}\right).
\end{aligned}
\tag{6.5}
\]

Hence

\[
\boxed{
F_{\rm top}(N)
=\mathfrak D_{\rm HM}(N)
+o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{6.6}
\]

This is the useful dispersion normalization: the constant character and both one-sided linear terms have been disposed of at little-oh cost.

### Correct shifted form

Take the positive orientation

\[
h=q-p=r-s>0,
\qquad r=s+h.
\]

Then half of (6.2) is

\[
\boxed{
\begin{aligned}
\mathfrak D_{\rm HM}^+(N)
={}&
\sum_{H_N<h\le N-K_N}
\sum_{\substack{p>N\\p+h\ {m prime}}}
\sum_{0\le s\le2N-p-h}
\mathbf1_{\lambda(p+s+h)>L_N}\\
&\qquad\qquad\times
\Delta_p(s+h)\Delta_{p+h}(s).
\end{aligned}
}
\tag{6.7}
\]

and

\[
\mathfrak D_{\rm HM}(N)=2\mathfrak D_{\rm HM}^+(N).
\]

Using (6.1), this becomes the completely explicit mixed-characteristic sum

\[
\boxed{
\begin{aligned}
\mathfrak D_{\rm HM}^+(N)
={}&
\sum_{h,p,s}^{\rm HM}
\frac1{p(p+h)}
\sum_{a=1}^{p-1}
\sum_{c=1}^{p+h-1}
 e_p(a b_{s+h})e_{p+h}(c b_s).
\end{aligned}
}
\tag{6.8}
\]

Equivalently, because `p` and `p+h` are coprime,

\[
e_p(a b_{s+h})e_{p+h}(c b_s)
=
 e_{p(p+h)}\!\left(a(p+h)b_{s+h}+cp\,b_s\right).
\tag{6.9}
\]

This is the replacement attack I recommend.

> **Q32-SHIFTED-HM-DISP (SHMD).** Prove the aggregate estimate
> \[
> \mathfrak D_{\rm HM}^+(N)
> =o\!\left(\frac{N^2}{\log^2N}\right).
> \]

By (5.2) and (6.5), SHMD closes the q=1 top pair energy.

The important point is that SHMD is not a pointwise fixed-gap statement.  It already sums simultaneously over the residue index `s`, the long/midrange gap `h`, the prime `p`, and both nontrivial additive characters.

### Why a pointwise square-root bound is still the wrong target

Even if one could prove, for each fixed `p,h,a,c`, square-root cancellation in the `s`-sum in (6.8), summing its absolute value over all `a,c,p,h` would lose the factor `p(p+h)` from the character count and still be too large.  The required saving must therefore be genuinely **aggregate in the character and prime variables** -- a dual large sieve / dispersion theorem for the family of recurrence phases in (6.9).

That is exactly the kind of cross-prime input absent from the saturated local continuant/resultant identities.

## 7. A cleaner global L2 form

There is also a useful equivalent form without gap cutoffs.  For
`N<m<=2N`, set

\[
\eta_N(m)=\sum_{N<p\le m}\frac1p,
\qquad
S_N(m)=\lambda(m)-\eta_N(m)
=\sum_{N<p\le m}\Delta_p(m-p).
\]

Then

\[
\sum_mS_N(m)^2
=\sum_m\lambda(m)^2
-2\sum_m\lambda(m)\eta_N(m)
+\sum_m\eta_N(m)^2.
\]

Since

\[
F_{\rm top}(N)=\sum_m\lambda(m)^2-T_{\rm top}(N),
\]

we get the exact identity

\[
F_{\rm top}(N)-\sum_mS_N(m)^2
=-T_{\rm top}(N)
+2\sum_m\lambda(m)\eta_N(m)
-\sum_m\eta_N(m)^2.
\]

Using `eta_N(m)<<1/log N` and the Q2043 first moment,

\[
\boxed{
F_{\rm top}(N)
=
\sum_{N<m\le2N}|S_N(m)|^2
+o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{7.1}
\]

Finally

\[
\boxed{
S_N(m)
=
\sum_{N<p\le m}
\frac1p\sum_{a=1}^{p-1}e_p\!\left(a b_{m-p}\right).
}
\tag{7.2}
\]

Thus a direct large-sieve formulation is:

\[
\boxed{
\sum_{N<m\le2N}
\left|
\sum_{N<p\le m}
\frac1p\sum_{a\ne0}e_p(a b_{m-p})
\right|^2
=o\!\left(\frac{N^2}{\log^2N}\right).
}
\tag{7.3}
\]

Equation (7.3) is stronger-looking analytically but is equivalent to the desired pair-energy theorem modulo an already-proved little-oh term.  Equation (6.8) is the gap-localized version compatible with the current heavy-row/long-gap reduction.

## 8. What was and was not proved

### Proved here

- The same-direction shift `p+h` / `r+h` is incompatible with the exact q=1 row geometry.
- There is an actual Apéry counterexample to that same-direction replacement: `(N,m,p,r,q,s)=(100,200,139,61,181,19)` and `b_103 mod 181 = 32`.
- The factorial-gauge `p -> p+h` congruence (3.5) is exact but equivalent to the original divisibility condition; it gives no extra pruning.
- The near-maximal gap band `N-K_N<|p-q|<N` has total size `o(N^2/log^2N)` with the explicit choice (4.4).
- Combining that with Q2043 yields the strictly smaller heavy-midgap residual HMG.
- Trivial additive characters and all linear terms may be removed at little-oh cost, leaving the pure nontrivial-character dispersion residual SHMD.

### Still open

I do not prove SHMD.  In particular I do not have an aggregate dual-large-sieve estimate strong enough for the mixed recurrence phases

\[
a(p+h)b_{s+h}+cp\,b_s\pmod{p(p+h)}.
\]

The next useful theorem should be aggregate in `(s,h,p,a,c)`.  A new pointwise fixed-gap resultant, another characteristic-zero height bound, or a modulus-Taylor identity that merely reintroduces the quotient `b_s/(p+h)` will not close the node.

## 9. Standalone executable checker

The following script uses only Python's standard library and exact integer/rational arithmetic.  It checks:

1. the Apéry recurrence;
2. the q=1 common-row divisor collapse;
3. the actual `m=200` pair and the sign error in the same-direction shift;
4. the factorial-gauge block identity and the exact tautology (3.6);
5. the centered L2 identity behind (7.1);
6. finite top-pair regressions at several `N`.

The finite computations are regression checks only; the asymptotic estimates in §§4--7 are proved above.

```python
#!/usr/bin/env python3
from fractions import Fraction
from math import isqrt


def P(n: int) -> int:
    return 34*n**3 + 51*n**2 + 27*n + 5


def apery(limit: int) -> list[int]:
    assert limit >= 1
    b = [0] * (limit + 1)
    b[0], b[1] = 1, 5
    for n in range(1, limit):
        num = P(n) * b[n] - n**3 * b[n-1]
        den = (n + 1)**3
        assert num % den == 0
        b[n+1] = num // den
    return b


def beta(limit: int) -> list[int]:
    z = [0] * (limit + 1)
    z[0], z[1] = 1, 5
    for n in range(1, limit):
        z[n+1] = P(n) * z[n] - n**6 * z[n-1]
    return z


def w_value(h: int, x: int) -> int:
    assert h >= 0
    if h == 0:
        return 1
    w0, w1 = 1, P(x)
    if h == 1:
        return w1
    for k in range(1, h):
        w0, w1 = w1, P(x + k) * w1 - (x + k)**6 * w0
    return w1


def primes_upto(n: int) -> list[int]:
    sieve = bytearray(b"\x01") * (n + 1)
    sieve[:2] = b"\x00\x00"
    for p in range(2, isqrt(n) + 1):
        if sieve[p]:
            sieve[p*p:n+1:p] = b"\x00" * (((n - p*p)//p) + 1)
    return [p for p in range(2, n + 1) if sieve[p]]


def top_rows(N: int, b: list[int], primes: list[int]):
    rows = {}
    for m in range(N + 1, 2*N + 1):
        original = [
            p for p in primes
            if N < p <= m and b[m-p] % p == 0
        ]
        common = [
            p for p in primes
            if N < p <= m and b[m] % p == 0
        ]
        # q=1 Lucas collapse, checked on actual data.
        assert original == common, (N, m, original, common)
        rows[m] = original
    return rows


def centered_l2(N: int, rows, primes):
    T = 0
    F = 0
    S2 = Fraction(0)
    lam_eta = Fraction(0)
    eta2 = Fraction(0)

    for m, selected in rows.items():
        lam = len(selected)
        all_top_primes = [p for p in primes if N < p <= m]
        eta = sum((Fraction(1, p) for p in all_top_primes), Fraction(0))
        S = Fraction(lam) - eta

        T += lam
        F += lam * (lam - 1)
        S2 += S * S
        lam_eta += lam * eta
        eta2 += eta * eta

    correction = -T + 2*lam_eta - eta2
    assert Fraction(F) - S2 == correction
    return T, F, S2, correction


def regression():
    b = apery(2000)
    z = beta(100)
    primes = primes_upto(2000)

    # Actual q=1 pair which also kills the same-direction shift.
    N = 100
    rows = top_rows(N, b, primes)
    assert rows[200] == [139, 181], rows[200]

    p, r = 139, 61
    q, s = 181, 19
    h = q - p
    assert h == r - s == 42
    assert p + r == q + s == 200
    assert b[r] % p == 0
    assert b[s] % q == 0
    assert b[r + h] % q == 32   # same-direction shift fails
    assert b[200] % p == 0
    assert b[200] % q == 0

    # Exact factorial-gauge block identity.
    W = w_value(h, s)
    C = s**6 * w_value(h - 1, s + 1) * z[s-1]
    assert z[r] == W * z[s] - C
    assert z[s] % q == 0
    u = z[s] // q
    X = h * W * u - C
    assert q * X == h * z[r] - p * C
    assert X % p == 0
    assert z[r] % p == 0

    T, F, S2, corr = centered_l2(N, rows, primes)
    assert F == 2
    assert T == 4
    assert Fraction(F) - S2 == corr

    # Additional actual top-pair regression rows.
    expected = {
        500: (755, [593, 733]),
        1000: (1773, [1229, 1427]),
    }
    for NN, (mm, pp) in expected.items():
        rr = top_rows(NN, b, primes)
        assert rr[mm] == pp, (NN, mm, rr[mm])

    print("m=200 pair:", (p, r), (q, s), "gap", h)
    print("b_103 mod 181 =", b[103] % 181)
    print("N=100: T_top=", T, "F_top=", F)
    print("all Q2046 exact regression checks passed")


if __name__ == "__main__":
    regression()
```

## Bottom line

The proposed modulus shift does not reveal a hidden recurrence congruence: the written same-direction shift is geometrically wrong, and the corrected factorial-gauge shift collapses exactly to the original divisibility after the unavoidable quotient is cleared.
