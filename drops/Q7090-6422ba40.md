# Exceptional mass bound for the Apéry quadruple corank

The proposed argument identifies the correct obstruction: the crude bound
\[
|Z(p)|\ll p^{2/3}
\]
is too weak when summed over the exceptional prime set.  The fact that a prime in the exceptional set satisfies \(p\mid b_j\) for a small index \(j\le H\) must be used more strongly.

## 1. What the naive argument gives

For
\[
E_b(H)=\{p\in(X,2X]: p\mid b_j\text{ for some }j\le H\},
\]
we have
\[
\sum_{p\in E_b(H)}|Z(p)|
\le \max_{p\sim X}|Z(p)|\sum_{p\in E_b(H)}1.
\]
Using only
\[
|Z(p)|\ll X^{2/3}
\]
and
\[
\#E_b(H)\le \sum_{j\le H}\omega_X(b_j)\ll H^2/\log X,
\]
indeed gives
\[
\ll X^{2/3}H^2/\log X.
\]
At \(H=X^{1/2}\), this is \(X^{5/3}/\log X\), so this route cannot close the desired \(X^{3/2+o(1)}\) bound.

## 2. Small-index zeros do not obviously force small \(Z(p)\)

The tempting strengthening is:

> If \(p\mid b_j\) for a small \(j\), then \(|Z(p)|\) should usually be smaller than the generic \(p^{2/3}\) bound.

This is plausible numerically, but the known structural facts do not imply it directly. The condition
\[
j\in Z_p
\]
only says that the projective Apéry orbit hits zero at one time. The reflection symmetry
\[
r\in Z_p\Longrightarrow p-1-r\in Z_p
\]
and the no-consecutive-zero theorem still allow a large zero set containing that point.

Thus there is no currently proved implication of the form
\[
j\le H,\ j\in Z_p \Longrightarrow |Z_p|\ll p^{\theta},\quad \theta<1/2,
\]
which would immediately solve the mass estimate.

## 3. The right replacement: count incidences, not primes

The exceptional mass is naturally an incidence sum:

\[
\sum_{p\in E_b(H)}|Z(p)|
=\sum_{p\sim X}\sum_{r<p}1_{p\mid b_j\text{ for some }j\le H}1_{p\mid b_r}.
\]

Equivalently, we need control of the number of pairs
\[
(j,r,p),\qquad j\le H,\quad p\sim X,\quad p\mid b_j,\quad p\mid b_r.
\]

But the project already has the stronger fixed-prime codegree machinery: two zero conditions are governed by gap polynomials. For a pair \((j,r)\), the common-prime count is controlled by the resultant
\[
S_{j,r}=\operatorname{Res}(N_j,N_r(\cdot+j)).
\]
After removing structural content, the large-prime part is bounded by the reduced resultant, while small primes can be handled separately.

Therefore the correct route is not to improve \(|Z(p)|\) pointwise, but to prove an averaged incidence estimate
\[
\sum_{p\sim X}|Z_p|\,1_{p\mid \mathfrak U_H}
\ll X^{3/2+o(1)}.
\]

## 4. Conditional consequence of the GM/resultant bounds

If the generic gcd/resultant estimates proved for the quadruple argument hold, then for each fixed small zero \(j\), the number of additional zero locations \(r\) sharing the same prime is controlled by the resultant family.

The relevant quantity is
\[
\sum_{j\le H}\sum_r \#\{p\sim X:p\mid b_j,p\mid b_r\}.
\]
The reduced resultants eliminate the possibility that many \(r\)'s share the same large prime except through structural content. Hence the mass becomes a pair-correlation problem rather than a worst-case \(Z_p\) problem.

## Conclusion

The answer is:

* The hoped-for statement that \(p\mid b_j\) with small \(j\) forces \(|Z(p)|\) to be smaller is **not currently justified** by the known zero-set structure.
* The exceptional mass bound should instead be proved by **incidence counting using the gap-polynomial resultants**.
* The needed gain is exactly the gain provided by the GM-large/common-resultant estimates: exceptional primes are arithmetically correlated with a small zero index, so they cannot simultaneously contribute the full generic \(p^{2/3}\) zero mass.

Thus the obstruction is not a missing exponent in the individual bound \(|Z(p)|\); it is the need to exploit the pairwise resultant geometry.
