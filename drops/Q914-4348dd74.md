# Q914 audit: fixed-q affine gcd slice

## Verdict

No existing Bugeaud--Corvaja--Zannier, Subspace Theorem, primitive-divisor, or general G-function gcd theorem currently supplies the required bound for this Apéry diagonal. The fixed-q slice is therefore reduced to a concrete missing input rather than solved by a standard Diophantine theorem.

The missing statement is:

```
For every fixed q >= 1 and every epsilon > 0,
# { p prime : n/(q+1) < p <= n/q,
          p | b_n }
= o_q(n/log n)
```

Equivalently, with the affine parametrization `r=n-qp`, one needs a saving in

```
Σ_{p in (n/(q+1), n/q]} 1_{p | b_{n-qp}}.
```

The exact gcd reformulation gives factors of `gcd(b_r,n-r)`, but present gcd technology does not control this correlated moving-index diagonal.

## Why the standard gcd theorems do not apply

### 1. Bugeaud--Corvaja--Zannier style estimates

The typical hypotheses concern gcds such as

```
gcd(u_m-1,u_n-1)
```

or values of multiplicatively independent algebraic objects. The required object is instead

```
gcd(b_r, n-r),   r=n-qp,
```

where `b_r` is a nonconstant-coefficient P-recursive sequence.

The two variables are not independent: the integer whose divisibility is tested is exactly the affine function selecting the recurrence index. No known Subspace-Theorem estimate gives a power-saving for this diagonal.

### 2. Primitive divisor theory

Primitive divisor results for Lucas/Lehmer type sequences rely on a fixed algebraic group or characteristic polynomial. The Apéry recurrence

```
(n+1)^3 b_{n+1}=P(n)b_n-n^3b_{n-1}
```

has variable coefficients, so there is no fixed companion matrix whose eigenvalue factorization controls prime divisors.

A primitive-divisor theorem for the Apéry sequence would have to prove a statement about new primes of `b_r` avoiding the moving arithmetic progression `n-r=q p`. No such theorem is available.

## Exact affine-gcd reduction

For fixed q:

```
p=(n-r)/q,
0 <= r < p/2.
```

The condition `p | b_r` implies

```
p | gcd(b_r,n-r).
```

After reflection, the radical contribution is exactly the product over these affine gcd factors. Hence the desired estimate is equivalent to proving

```
log R_q(n)=o_q(n).
```

A generic bound gives only

```
log gcd(b_r,n-r) <= log(n-r)=O(log n),
```

and there are `O(n/log n)` candidate primes, producing only `O(n)`.

## Product-tree/resultant viewpoint

A characteristic-zero resultant construction would need a polynomial `F_n(X)` with:

1. every selected prime divisor appearing in `rad(F_n(n))`;
2. logarithmic height `h(F_n)=o(n)`;
3. degree controlled enough that the radical estimate survives.

The recurrence can generate polynomial identities, but the natural elimination objects have height exponential in the number of recurrence steps. A resultant formed from an `O(n)`-length recurrence chain has logarithmic height `O(n)` and therefore gives no improvement over the trivial bound.

Thus the proposed product-tree route identifies the required target but does not prove it.

## Sharp current conclusion

The strongest unconditional statement from the present interfaces is:

```
log R_q(n) = O_q(n).
```

The missing uniform input is a diagonal Apéry gcd estimate:

```
For fixed q and every delta>0,
Σ_{p in (n/(q+1),n/q]} log rad(gcd(b_{n-qp},n-qp))
= O_q(n^{1-delta})
```

(or any equivalent `o_q(n)` estimate).

No cited existing theorem supplies this. The fixed-q slice remains an open Diophantine input in Q32-SLICE-COUNT-FAMILY/Q32-AAT rather than a consequence of known G-function gcd theory.
