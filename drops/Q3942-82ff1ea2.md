# 3. Uniform prime count in the moving intervals

We use the following standard uniform consequence of Brun--Titchmarsh.

## Lemma 3.1

There is an absolute constant `C_π` such that every real interval `J` of length `H≥0` satisfies

\[
\#(J\cap\mathbb P)
\le
C_\pi\left(1+\frac{H}{\log(2+H)}\right).
\tag{3.1}
\]

### Proof

For bounded `H`, the assertion follows after enlarging the absolute constant. Assume `H≥2` and write the positive part of the interval as `[y,y+H]`.

If `y≥H`, Brun--Titchmarsh gives

\[
\pi(y+H)-\pi(y)
\ll \frac{H}{\log H}.
\tag{3.2}
\]

If `0≤y<H`, then `y+H<2H`, and the standard Chebyshev upper bound gives

\[
\pi(y+H)\le\pi(2H)
\ll\frac{H}{\log H}.
\tag{3.3}
\]

If the original interval starts below zero, deleting its negative part only reduces the count and places the positive endpoint below `H`. Since `\log H` and `\log(2+H)` are comparable for `H≥2`, (3.1) follows. ∎

Now the map

\[
t\longmapsto q^-=q-t
\tag{3.4}
\]

is injective and sends each `t`-interval to a `q^-`-interval of exactly the same length. Intersecting with `q^->0`, `q^-<q`, a prime shell, selectedness, or a frozen predecessor set only reduces the count.

There are at most two components. Using Lemma 3.1 on each, (2.5)--(2.7), and monotonicity/comparability of `H/\log(2+H)`, one obtains one absolute `C_loc` such that

\[
\boxed{
\#\{q^-\text{ prime}:q^-<q,\ \beta(q^-)\le E\}
\le
C_{\rm loc}
\left(1+\frac{E}{\log(2+E)}\right).
}
\tag{3.5}
\]

The constant includes the two-component loss and all bounded-length cases. It is independent of `R,n,p,q,E`.

Two bookkeeping points are important.

1. The `O`-constant in (3.5) must be fixed before defining `E_OS`. One cannot define the cutoff using an unspecified smaller constant. This is the reason for (V2).
2. No statistical independence is being asserted. Equation (3.5) counts every possible prime in the moving intervals; every arithmetic or graph-theoretic condition imposed later is merely a thinning.

# 6. Multiplicity and dependence audit

## 6.1 Local uniqueness

At fixed terminal `(n,p,q)`, a predecessor prime `q^-` determines

\[
t=q-q^-,
\qquad
a^-=a-6t.
\tag{6.1}
\]

Thus it determines one sorted triple and one value of `β`. There is no orientation multiplicity: the predecessor is already oriented by `q^-<q`.

## 6.2 Repetition across lower primes

The same upper-state pair

\[
(n;q^-,q)
\tag{6.2}
\]

may occur at several lower primes `p`. The proof does not collapse those occurrences. It applies the local bound separately to each terminal `(n,p,q)` and counts the global good family in the occurrence space

\[
(n,p,q;q^-).
\tag{6.3}
\]

Hence repeated upper pairs across different `p` are preserved exactly.

This is also why `B` must be occurrence-counted. If a support-level exceptional family contains one pair `(n;q^-,q)` but that pair is used by `m` lower primes, its contribution to (5.12) is `m`, not `1`.

## 6.3 No hidden probabilistic dependence

The long-gap property, the exceptional predicate, primality, actual Apéry selectedness, and `β>E_OS` may be arbitrarily dependent. The argument uses only:

```text
one deterministic upper bound for all small-β predecessor primes;
one deterministic lower bound for the long-gap subset;
one global occurrence count for exceptions.
```

No distributional or independence premise is present.

## 6.4 Units of the exceptional ledger

Equations (V5)--(V8) are unweighted charge-count statements. If the exceptional theorem supplies a logarithmically weighted mass instead, or if the remaining carrier counts each charge with weight `w(τ,q^-)`, then every term must be put in the same units. For shell weights `w\asymp\log T`, one may multiply the entire charge inequality by the appropriate uniform weight bound, but one may not insert an unweighted `B` directly into a weighted inequality.

# 7. Exact failure modes and smallest repairs

The repaired lemma above is rigorous. The following variants are not.

## Failure 1: support-level exceptional count

If

```text
B = number of distinct exceptional q^- values
or distinct exceptional pairs (n;q^-,q),
```

with no reuse theorem, then (5.12) can fail by an arbitrarily large factor.

**Smallest repair:** define

\[
B
=
\#\{(n,p,q;q^-):\text{this charge occurrence is exceptional}\},
\tag{7.1}
\]

or prove a reuse bound `m` and replace `B` by `mB`.

## Failure 2: repeated predecessors at one terminal

If one prime `q^-` is listed several times among the `λ` frozen predecessors, (3.5) bounds only distinct primes and does not bound the multiset load.

**Smallest repair:** require a set of distinct earlier primes, or insert the maximum local repetition multiplicity.

## Failure 3: unfixed implicit constant

Writing only

\[
O\left(1+E/\log(2+E)\right)
\]

and then choosing `E_OS` with an unrelated constant does not prove (5.6).

**Smallest repair:** fix `C_loc` first and choose `C≥C_loc` in (V3).

## Failure 4: real predecessor count

If the upstream `λ` is not an integer, “exactly `λ` predecessors” has no literal meaning.

**Smallest repair:** freeze `H=floor(λ)` once and use `H` consistently in the cutoff and coefficient.

## Failure 5: claiming closure

Equation (V8) leaves `|\mathcal G|` untouched. It does not prove

\[
|\mathcal T|=o(T^2/(\log T)^2)
\]

without a separate bound for the long-gap, nonexceptional, large-`β` carrier.

**Smallest repair:** state only the reduction (V5)--(V8), exactly as above.
