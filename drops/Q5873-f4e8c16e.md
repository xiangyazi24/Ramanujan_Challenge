# Q5873 audit: reverse direction for the chart elimination

## Executive conclusion

The requested reverse implication cannot be certified by the already displayed linear-subresultant sign argument alone. The identity

```
r*F = -(r^4-r^2+1)E + X(r^2-1)^2
```

only proves that on the negative root, if `E=0`, then the subresultant coefficient has the required sign. It does not prove that `Atilde=0` forces `E=0`.

The non-circular route is to eliminate `r` completely. The exact certificate to seek is:

```
E(rneg) E(rpos) = P(X,L) * Atilde(X,L)
```

with `P` a product of powers of `X`, `L`, `1-X`, and the discriminant factor of `H`. Such an identity would reduce the problem to proving `E(rpos) != 0`.

I do not find a justified proof from the supplied identities that `E(rpos)` has fixed sign. Therefore the reverse implication remains an algebraic resultant obligation, not a consequence of the current argument.

## 1. Exact setup

Let

```
E=(t-r)(Xt-r)(t-Xr)-X r^4 t,
t=1-r^2

H=(L+X^3)t-Xr(L+X).
```

For fixed `X,L`, the two roots of `H` satisfy

```
rneg < -1,
0 < rpos < 1,
```

and

```
rneg*rpos=-1.
```

The elimination problem is:

```
H(r)=0,
Atilde(X,L)=0
```

implies

```
E(rneg)=0.
```

## 2. What is already proved

The subresultant calculation gives

```
D^4 ca = X^6 (X-1)^4 (X+1)^4 F,
D=t-rX.
```

and

```
rF = -(r^4-r^2+1)E + X(r^2-1)^2.
```

Therefore on an `E=0` root:

```
rF = X(r^2-1)^2.
```

Since `X>0` and `rneg<0`, this fixes the sign of `F` and hence `ca`.

This is only the forward direction.

## 3. Required reverse certificate

The clean target identity is a norm identity in the quadratic extension generated by `H`:

```
Norm_H(E)=E(rneg)E(rpos).
```

Because `H` is quadratic, this norm is a polynomial/rational function in `X,L`.

The required machine-checkable statement is:

```
E(rneg)*E(rpos)
 = Q(X,L)*Atilde(X,L)
```

where `Q(X,L)>0` on the branch.

Then `Atilde=0` implies the product vanishes.

The remaining lemma must be:

```
0<X<1 ∧ 0<L<1 ∧ branch_conditions
  ⟹ E(rpos) != 0.
```

Without this lemma, the conclusion could be that the positive root is the zero of `E` instead.

## 4. Why the positive-root argument is the missing step

The substitution used in the forward direction privileges the negative root. The positive root has different signs:

```
0<rpos<1,
0<t=1-rpos^2<1.
```

Expanding `E` into factors gives no immediate contradiction because:

* `(t-rpos)>0`,
* `(Xt-rpos)` can change sign,
* `(t-Xrpos)>0`,
* the last term `-X rpos^4 t` is negative.

Hence the sign of `E(rpos)` is not determined from `0<X,L<1` alone.

A valid proof needs an additional true branch inequality or an exact factorization of `E(rpos)` after substituting the positive root.

ring_nf(Norm_H(E) - Q*Atilde)=0

for an explicit `Q`.

## 6. Current obstruction

The existing `ca` identity is an implication:

```
E=0 => ca has sign.
```

It is not an equivalence:

```
ca=0 <=> E=0
```

unless the second subresultant coefficient is also controlled. Any proof using `ca!=0` before establishing the resultant relation is circular.

Therefore the next exact computation should be the quadratic norm/resultant of `E` with `H`; if it factors by `Atilde`, it supplies the missing algebraic bridge. If it has extra factors, those factors must be audited separately.
