# Q860 ALCT connected discrepancy audit

## 1. Setup

Let

\[
Y_X=\{y:1\le y<4X^2,\ y\text{ odd}\},
\]

with the uniform probability measure. For each prime \(X<p\le 2X\), put

\[
I_p(y)=1_{\Omega_p}(y\bmod p),\qquad
\Omega_p=\{2r+1:r\in\mathbb Z_p\},
\]

and

\[
K_X(y)=\sum_{X<p\le 2X}I_p(y),\qquad S_X=K_X-\mathbb EK_X.
\]

The target is

\[
|\kappa_j(S_X)|\le (Aj)^j(1+\lambda_X),\qquad j\le 2c_0\log X.
\]

This note derives the exact reduction. It does not identify ALCT with AAT or QPF.

## 2. Exact cumulant expansion

For centered variables the joint cumulant formula gives

\[
\kappa_j(S_X)=
\sum_{p_1,\ldots,p_j}
\kappa(I_{p_1},\ldots,I_{p_j}),
\]

where the sum is over ordered prime tuples \(X<p_i\le2X\). The multilinear cumulant is

\[
\kappa(X_1,\ldots,X_j)=
\sum_{\pi\in\Pi([j])}
(|\pi|-1)!(-1)^{|\pi|-1}
\prod_{B\in\pi}
\mathbb E\prod_{i\in B}X_i.
\]

For a tuple \(\mathbf p=(p_1,\ldots,p_j)\), define

\[
N(\mathbf p_B)=
\#\{y\in Y_X:y\bmod p_i\in\Omega_{p_i}\ \forall i\in B\}.
\]

Then

\[
\mathbb E\prod_{i\in B}I_{p_i}=\frac{N(\mathbf p_B)}{|Y_X|}.
\]

Hence the exact finite formula is

\[
\boxed{
\kappa_j(S_X)=
\sum_{p_1,\ldots,p_j}
\sum_{\pi\in\Pi([j])}
(|\pi|-1)!(-1)^{|\pi|-1}
\prod_{B\in\pi}
\frac{N(\mathbf p_B)}{|Y_X|}
}
\]

with the understanding that repeated primes are included. Repeated-prime tuples are not an error term; they are the diagonal cumulant contributions.

## 3. CRT evaluation and boundary error

If \(d\) is squarefree and consists of distinct primes, CRT gives

\[
N(d)=\frac{|Y_X|}{2^{\omega(d)}}+E_X(d),
\]

because each odd residue class modulo \(d\) has asymptotic density \(1/d\) inside the odd interval, while every prime condition removes one half of the odd residue classes.

The finite interval produces

\[
|E_X(d)|\ll 1+\frac{2^{\omega(d)}}{d}|Y_X|^0,
\]

more explicitly an endpoint discrepancy of size at most the number of residue classes modulo \(d\). The exact normalization is therefore

\[
\frac{N(d)}{|Y_X|}=2^{-\omega(d)}+O\left(\frac{2^{\omega(d)}}{X^2}\right)
\]

for \(d\) in the relevant logarithmic prime ranges.

The cumulant cancellation removes the product-density terms. What remains is a connected discrepancy.

## 4. Weakest sufficient connected-discrepancy statement

The needed input is not a full high-moment theorem. A sufficient statement is:

For every \(2\le m\le 2c_0\log X\), and every distinct prime set
\(P=\{p_1,\ldots,p_m\}\subset(X,2X]\), define

\[
\Delta(P)=
\sum_{\pi\in\Pi(P)}
(|\pi|-1)!(-1)^{|\pi|-1}
\prod_{B\in\pi}
\frac{N(B)}{|Y_X|}.
\]

Then it is enough to prove

\[
\boxed{
\sum_{|P|=m}|\Delta(P)|
\ll (Cm)^m(1+\lambda_X)
}
\]

uniformly for \(m\le2c_0\log X\), together with the same type of bound for repeated-prime diagonals.

This is the minimal signed connected-discrepancy form. A positive bound on all joint counts is stronger than necessary because the partition Möbius coefficients already enforce cancellation.

## 5. Relation to the pair estimate

The already proved pair codegree/second factorial moment controls only

\[
\sum_{p\ne q}
\left|
\frac{N(pq)}{|Y_X|}-\frac14
\right|
\]

or an equivalent second-order discrepancy.

This establishes rank two.

The missing ranks are exactly the connected cumulants

\[
3\le m\le 2c_0\log X.
\]

Rank two does not automatically control logarithmic rank. A reduction is required.

## 6. Possible one-partition reduction

The useful reduction target is:

All partition contributions except the one-block partition are bounded by existing CRT/product estimates, leaving only

\[
\sum_{|P|=m}
\left|
\frac{N(P)}{|Y_X|}-2^{-m}
\right|
\]

as the new input.

Equivalently, prove that the only genuinely connected obstruction is the full prime tuple discrepancy.

A concrete next lemma is therefore:

> **Connected full-tuple lemma.** There exists \(C>0\) such that for every squarefree product \(d\) of \(m\le2c_0\log X\) primes in \((X,2X]\),
> 
> \[
> \sum_{\substack{d=p_1\cdots p_m\\X<p_i\le2X}}
> \left|
> N(d)-2^{-m}|Y_X|
> \right|
> \le (Cm)^m X^2(1+\lambda_X).
> \]

A gap-polynomial or Cartier argument would naturally attack this because it asks for cancellation in the simultaneous residue constraints rather than independent local densities.

## 7. Exponent bookkeeping

The number of columns is about

\[
|Y_X|=2X^2+O(1).
\]

For \(m\sim c_0\log X\), the allowed connected bound must absorb the combinatorial partition factor

\[
\sum_{\pi\in\Pi_m}(|\pi|-1)!\ll m!
\]

and therefore constants must be exponential in \(m\), not polynomial.

A bound of the form

\[
(Cm)^m(1+\lambda_X)
\]

is compatible with the required Bernstein cumulant target.

## 8. Precise conclusion

The current verified chain is:

```
connected discrepancy estimates for ranks 2..O(log X)
        |
        v
ALCT cumulant bound
        |
        v
Bernstein moments and logarithmic tails
        |
        v
possible max-load control
```

The pair codegree result supplies only rank 2.

The concrete remaining problem is logarithmic-rank connected discrepancy, not AAT/QPF. A successful Cartier/gap-polynomial proof of the connected full-tuple lemma would be a direct ALCT route.
