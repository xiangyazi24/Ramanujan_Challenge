## 1. Exact Smith content of a finite radial chain

Put

\[
R=\mathbb Z[M],\qquad
A_j=4j+6,\qquad B_j=2M+2j+5.
\tag{1.1}
\]

For integers \(a<b\), let \(D_{a,b}\) be the \((b-a)\times(b-a+1)\) bidiagonal presentation matrix with rows indexed by \(j=a,\ldots,b-1\), columns indexed by \(a,\ldots,b\), and row \(j\)

\[
A_j e_j+B_j e_{j+1}.
\tag{1.2}
\]

Let

\[
s_{a,b}(M_0)
 =\gcd\{\text{all maximal minors of }D_{a,b}(M_0)\}
\tag{1.3}
\]

for an integer specialization \(M=M_0\).

### Lemma 1.1 -- maximal minors and the min-cut valuation

Deleting column \(k\), \(a\le k\le b\), gives, up to sign,

\[
\Delta_k
 =\prod_{j=a}^{k-1}A_j
  \prod_{j=k}^{b-1}B_j.
\tag{1.4}
\]

Hence, for every prime \(p\),

\[
\boxed{
 v_p(s_{a,b}(M_0))
 =\min_{a\le k\le b}
 \left(
   \sum_{j=a}^{k-1}v_p(A_j)
  +\sum_{j=k}^{b-1}v_p(B_j(M_0))
 \right).
}
\tag{1.5}
\]

#### Proof

After deleting column \(k\), the matrix splits into a lower triangular block using the \(A_j\)'s for \(j<k\), and an upper triangular block using the \(B_j\)'s for \(j\ge k\).  This proves (1.4).  Taking the minimum valuation among the maximal minors gives (1.5).  No PID or generic-rank assumption is needed.  \(\square\)

### Lemma 1.2 -- ordered zero walls

For a prime \(p\), write

\[
Z_A(p)=\{i\in[a,b-1]:p\mid A_i\},
\qquad
Z_B(p)=\{j\in[a,b-1]:p\mid B_j(M_0)\}.
\tag{1.6}
\]

Then

\[
\boxed{
 p\mid s_{a,b}(M_0)
 \iff
 \text{there are }i\in Z_A(p),\ j\in Z_B(p)
 \text{ with }i\le j.
}
\tag{1.7}
\]

Equivalently, a \(p\)-unit maximal minor exists precisely when all `B`-walls lie strictly to the left of all `A`-walls.

#### Proof

The minor \(\Delta_k\) is a \(p\)-unit exactly when

\[
Z_A(p)\cap[a,k-1]=\varnothing,
\qquad
Z_B(p)\cap[k,b-1]=\varnothing.
\]

Such a cut \(k\) exists exactly when

\[
\max Z_B(p)<\min Z_A(p),
\]

with the evident conventions when one zero set is empty.  Negating this condition gives (1.7).  \(\square\)

### Corollary 1.3 -- the linear wall factors

Let \(W=b-a\).  Then

\[
\boxed{
 \operatorname{rad}s_{a,b}(M_0)
 \mid
 \prod_{h=1}^{W}|M_0+h|.
}
\tag{1.8}
\]

#### Proof

The prime \(2\) does not divide the Smith content: every \(B_j(M_0)\) is odd, so \(\Delta_a=\prod B_j\) is odd.

Let \(p\) be odd and divide the Smith content.  By Lemma 1.2 there are \(i\le j\) with

\[
p\mid A_i,\qquad p\mid B_j(M_0).
\]

The exact identity

\[
2B_j-A_i
 =4(M_0+j-i+1)
\tag{1.9}
\]

gives

\[
p\mid M_0+h,\qquad h=j-i+1\in[1,W].
\]

This proves (1.8).  \(\square\)

This is the rigorous content behind the observed factors `n+h`.  It also gives the correct logarithmic implication: if the actual endpoint ledger reduced the possible wall gaps to a set \(H_n\) with

\[
|H_n|=o(n/\log n),
\tag{1.10}
\]

then

\[
\log\prod_{h\in H_n}|M+h|=o(n).
\tag{1.11}
\]

For large target primes, multiplicity is also harmless.  If \(W<p\) and all displayed \(A_i,B_j\) have absolute value below \(p^2\), there is at most one wall of each type and (1.5) shows that an ordered wall contributes exactly one copy of \(p\).  Small-prime powers require their own primitive-content ledger; they are not supplied by the radical statement (1.8).

The important limitation is that Lemmas 1.1--1.3 apply only after one has proved that the **actual integral packet** is represented by a finite, saturated chain interval.  A formal completion does not provide that fact.

## 2. An exact algebraic radial chart on the actual smooth component

The formal inverse is unnecessary at the first algebraic step.  There is an exact rank-two algebraic chart.

Put

\[
u=1+y,\qquad v=1+z,\qquad
r=uv=(1+y)(1+z),
\tag{2.1}
\]

\[
t=-1-y-z,\qquad d=yz=t+r.
\tag{2.2}
\]

The critical component

\[
C:\quad y=z=-1
\tag{2.3}
\]

is the locus \(u=v=0\).  Away from \(x=-1\), the normal quadratic term of \(\Lambda\) is \((1+x)uv\), so this is the smooth Morse--Bott part of the component.

Define the exact algebraic radial coordinate

\[
q=\frac{\Lambda}{1+x}.
\tag{2.4}
\]

Using

\[
\Lambda
 =\frac{(1+x)r(r+xd)}{xd},
\tag{2.5}
\]

we obtain

\[
q=r+\frac{r^2}{xd}.
\tag{2.6}
\]

Multiplying by \(xd=x(t+r)\) gives the quadratic relation

\[
\boxed{
 (x+1)r^2+x(t-q)r-qxt=0.
}
\tag{2.7}
\]

There is also the exact inverse identity

\[
\boxed{
 (t+r)\{t+xq-(x+1)r\}=t^2,
}
\tag{2.8}
\]

hence

\[
\boxed{
 d^{-1}
 =\frac{t+xq-(x+1)r}{t^2}.
}
\tag{2.9}
\]

### Lemma 2.1 -- finite algebraic replacement for the formal Morse inverse

Let

\[
B=\mathbb Z[x^{\pm1},(1+x)^{-1},t^{\pm1},q].
\tag{2.10}
\]

Then the localized symmetric Laurent ring is a free rank-two \(B\)-module:

\[
\boxed{
\mathbb Z[x^{\pm1},y^{\pm1},z^{\pm1}]^{y\leftrightarrow z}
 [(1+x)^{-1},t^{-1}]
 \simeq
 B[r]/\bigl((x+1)r^2+x(t-q)r-qxt\bigr),
}
\tag{2.11}
\]

with basis \(1,r\).

#### Proof

The symmetric Laurent ring in \(y,z\) is

\[
\mathbb Z[y+z,yz,(yz)^{-1}].
\]

Here

\[
y+z=-1-t,\qquad yz=t+r.
\]

Equation (2.7) puts \(r\) in a quadratic algebra over \(B\), and after inverting \(x+1\) the relation is monic in \(r\).  Equation (2.8) proves that \(t+r=yz\) is already invertible in the quadratic algebra after inverting \(t\).  Thus the quadratic algebra contains all symmetric Laurent generators.  Conversely, (2.6) shows that \(q\) belongs to the localized symmetric Laurent ring.  The two maps are inverse, and the monic quadratic gives the free basis \(1,r\).  \(\square\)

This is the correct algebraic substitute for writing down an infinite formal coordinate inverse.  It is exact, finite, and replayable.

### Filtration consequence

Give \(q\) and \(r\) degree one, and give \(x,t\) degree zero.  From (2.7),

\[
r^2
 =\frac{x(q-t)}{x+1}r+rac{xqt}{x+1},
\tag{2.12}
\]

so reduction to the basis \(1,r\) never increases total \((q,r)\)-degree.

A symmetric Laurent monomial whose \(y,z\)-exponents have absolute value at most \(E\) therefore has an exact representation

\[
f=A_f(x,t,q)+rB_f(x,t,q)
\tag{2.13}
\]

after multiplication by a power of \((1+x)t\), with

\[
\deg_q A_f,\deg_q B_f=O(E).
\tag{2.14}
\]

A safe explicit bound is \(3E\).  The precise constant is not important here; the point is that the algebraic chart gives a finite, linear bound without ever truncating a formal inverse.

However, the localization is not harmless.  For the actual Laurent unit \(d^{-E}\), (2.9) gives

\[
d^{-E}
 =\frac{\{t+xq-(x+1)r\}^{E}}{t^{2E}}.
\tag{2.15}
\]

The coefficient of \(q^E\) is exactly \(x^E/t^{2E}\).  Terms containing at least one \(r\) reduce to \(q\)-degree at most \(E-1\).  Thus the \(q^E\) term cannot cancel, and the denominator \(t^{2E}\) is sharp.

So the algebraic chart has an **unbounded saturation index** as \(E\) grows.  It is a local chart on the smooth component, not a fixed integral splitting of the global Laurent lattice.  Any global Brieskorn/Rees proof must account for the divisors

\[
t=0,\qquad x+1=0,
\tag{2.16}
\]

rather than silently inverting them.

## 3. The correct Rees filtration is a pole filtration, not a finite radial-degree filtration

The actual reason the formal inverse is infinite can be seen before any large computation.

In the normal coordinates \(u=1+y\), \(v=1+z\),

\[
d^{-E}=(yz)^{-E}
 =(1-u)^{-E}(1-v)^{-E}.
\tag{3.1}
\]

Its formal expansion is

\[
d^{-E}
 =\sum_{a,b\ge0}
   \binom{E+a-1}{a}
   \binom{E+b-1}{b}
   u^av^b.
\tag{3.2}
\]

In the quadratic tangent quotient, the off-diagonal monomials \(u^av^b\), \(a\ne b\), are tangent divergences, while the diagonal monomials survive as \(q^j=(uv)^j\).  Therefore the radial image is

\[
\boxed{
\Pi_E(q)
 =\sum_{j\ge0}\binom{E+j-1}{j}^2q^j.
}
\tag{3.3}
\]

This series is infinite for every \(E\ge1\).  It has an exact rational form:

\[
\boxed{
\Pi_E(q)
 =\frac{P_{E-1}(q)}{(1-q)^{2E-1}},
\qquad
P_{E-1}(q)=\sum_{k=0}^{E-1}\binom{E-1}{k}^2q^k.
}
\tag{3.4}
\]

Equation (3.4) is Euler's hypergeometric transformation applied to

\[
{}_2F_1(E,E;1;q).
\]

Since

\[
P_{E-1}(1)=\binom{2E-2}{E-1}\ne0,
\tag{3.5}
\]

the pole order at \(q=1\) is exactly

\[
\boxed{2E-1.}
\tag{3.6}
\]

This gives the rigorous Rees object:

\[
F_\nu
 =\{f(q):(1-q)^\nu f(q)\text{ is regular at }q=1\},
\qquad
\operatorname{Rees}_F=\bigoplus_{\nu\ge0}F_\nu T^\nu.
\tag{3.7}
\]

The class of \(d^{-E}\) lies in

\[
F_{2E-1}\setminus F_{2E-2}.
\tag{3.8}
\]

Thus an exact algebraic bridge exists, but its endpoint is a pole order growing linearly with the Laurent exponent.  The infinite Morse series is not replaced by a bounded radial polynomial; it is replaced by a rational radial function with a linearly growing pole.

### The actual full-margin packet contains this tail

At a right-active maximal boundary, (68.141) contains, for

\[
\kappa=(0,1,1),
\]

the multiplier

\[
X^{-D\kappa}(X^{-\kappa}-1)^L
 =d^{-D}(d^{-1}-1)^L.
\tag{3.9}
\]

Writing \(E=D+i\), this is

\[
\sum_{i=0}^L(-1)^{L-i}\binom Li d^{-(D+i)}.
\tag{3.10}
\]

The last term \(d^{-(D+L)}\) has pole order

\[
2(D+L)-1,
\tag{3.11}
\]

while every preceding term has pole order at most

\[
2(D+L)-3.
\]

Hence the pole in (3.11) cannot cancel inside this ray term.  At the active boundary \(D+L=M\), it is exactly

\[
2M-1=\Theta(n).
\tag{3.12}
\]

Moreover, the monomial \(x^0y^{-M}z^{-M}\) coming from \(\kappa=(0,1,1)\) and the top binomial term is unique in the raw endpoint multiplier.  Therefore no claim of a bounded radial endpoint can be made from Laurent support or Pascal syntax alone.  Any cancellation after the remaining tangent quotient would have to be proved by an explicit integral homotopy for the actual packet.

The pole filtration (3.7), not a finite Taylor truncation, is the correct starting point for such a proof.

## 4. Why every finite-Morse truncation acquires new, genuine wall factors

The preceding pole can also be read directly in the radial chain.

Over \(\mathbb Q(M)\), relation (0.1) gives

\[
q^{j+1}
 =-\frac{4j+6}{2M+2j+5}q^j
 =-2\frac{j+3/2}{M+j+5/2}q^j.
\tag{4.1}
\]

Thus, for a finite truncation,

\[
q^j
 =(-2)^j\frac{(3/2)_j}{(M+5/2)_j}q^0.
\tag{4.2}
\]

Take the actual diagonal truncation

\[
S_J(q)=\sum_{j=0}^{J}inom{E+j-1}{j}^2q^j.
\tag{4.3}
\]

Its reduction to \(q^0\) is

\[
\sum_{j=0}^{J}
 \binom{E+j-1}{j}^2
 (-2)^j\frac{(3/2)_j}{(M+5/2)_j}.
\tag{4.4}
\]

The last summand contains the new denominator

\[
B_{J-1}=2M+2J+3.
\tag{4.5}
\]

No previous summand contains this factor.  At \(B_{J-1}=0\), all earlier denominator factors are nonzero, and the numerator of the last summand is nonzero.  Therefore (4.5) is a genuine new pole; it is not a presentation artifact that cancels in the truncation.

## 6. Observation-lattice content is not distinguished-state content

The relevant elementary lemma is the following.

### Lemma 6.1 -- observation determinant times state content

Let \(O\in M_r(\mathbb Z)\) have nonzero determinant, let \(\xi\in\mathbb Z^r\), and put

\[
c(\xi)=\gcd(\xi_1,\ldots,\xi_r).
\]

Then

\[
\boxed{
\gcd\bigl((O\xi)_1,\ldots,(O\xi)_r\bigr)
 \mid c(\xi)\det O.
}
\tag{6.1}
\]

The same conclusion holds for a rectangular observation matrix after choosing any full-rank square row minor.

#### Proof

Write \(\xi=c(\xi)\xi_0\) with \(\xi_0\) primitive.  If

\[
g_0=\gcd(O\xi_0),
\]

then

\[
\det(O)\xi_0=\operatorname{adj}(O)O\xi_0
\]

shows that \(g_0\) divides \(\det(O)(\xi_0)_i\) for every \(i\).  Since the coordinates of \(\xi_0\) have gcd one, \(g_0\mid\det O\).  Multiplying back by \(c(\xi)\) proves (6.1).  \(\square\)

The finite radial-chain Smith calculation controls the determinant or Fitting ideal of \(O\).  It says nothing about \(c(\xi)\).

This distinction is not hypothetical in the present problem:

* Section 68.5 proves that the normalized translated Newton exterior rows are primitive in the free Pluecker coefficient lattice.
* At a target prime, the actual marked values of both distinguished coordinates vanish, so every evaluated normalized minor is still divisible by \(p\).
* Therefore the surviving target factor is not coefficient-row content.  It is distinguished-state content, or equivalently failure of observability at that state.

Scaling gives the abstract counterexample immediately: replacing a distinguished state \(\xi\) by \(c\xi\) leaves the radial module, filtration, support, and observation determinant unchanged, while multiplying every output by \(c\).  In the actual Apéry specialization the target radical plays precisely this local role.

Accordingly, a proof of (68.72) requires not only an endpoint filtration for the observation rows, but also a primitive prefix or observability certificate for the actual Apéry state.  This is the missing factor \(\Theta_T\) in the terminal exterior-state audit.

## 7. Target preservation and integrality: where division is forbidden

The target ledger must be kept over \(\mathbb Z_{(p)}\) until the last step.

For a target node \(p-1\) inside two adjacent Newton stencils with \(L<p\), the two integer Newton rows satisfy

\[
c_\alpha\equiv c_\beta\equiv e_{p-1}\pmod p.
\tag{7.1}
\]

Their wedge has one universal copy of \(p\).  Dividing by the Kummer binomial normalization removes exactly that copy and gives the primitive row

\[
\frac{c_\alpha\wedge c_\beta}{p}
 \equiv e_{p-1}\wedge(v-u)\pmod p.
\tag{7.2}
\]

Evaluation on the distinguished pair still vanishes because

\[
Y_{p-1}\equiv W_{p-1}\equiv0\pmod p.
\tag{7.3}
\]

This is the exact source of the one surviving target digit in (68.60).

Now consider a radial wall.  If

\[
p\mid A_j\quad\text{or}\quad p\mid B_j,
\]

then the formal reductions

\[
q^j=-\frac{B_j}{A_j}q^{j+1},
\qquad
q^{j+1}=-\frac{A_j}{B_j}q^j
\tag{7.4}
\]

are not operations in \(\mathbb Z_{(p)}\).  One must clear the wall factor before specializing.

There are only two possibilities.

1. Keep the factor.  Then it is structural Smith content and may be charged to a boundary linear factor by Lemma 1.3.
2. Divide it out.  Then one needs an independently certified extra copy of \(p\) in the actual numerator.

The first-Pascal-quotient and \(p^2\)-jet audits rule out obtaining that extra copy from targetness alone.  After imposing the marked value zero, the adjacent once-divided increments remain free modulo \(p\).  Equivalently, the module of universally target-preserving rows is

\[
\boxed{
\mathcal P_p=\mathbb Z_{(p)}\tau_p+pV^\vee.
}
\tag{7.5}
\]

Any two rationally independent target-preserving rows have a rank-two minor divisible by \(p\).  Dividing that \(p\) produces a primitive row whose divided increment is no longer target-forced.

Therefore an argument that cancels an `A`- or `B`-wall in \(\mathbb Q(M)\), and only afterward reduces modulo \(p\), is invalid.  Target preservation is lost exactly at the cancellation step.

## 8. The prefix obstruction survives the radial reduction

The exact prefix calculation from the preceding audit is

\[
a_s-a_{s+1}=P_sj_s,
\qquad
k_s=\sum_{t<s}P_tj_t=a_0-a_s,
\qquad
c=a_s+k_s=a_0,
\tag{8.1}
\]

and

\[
P_s\det(j_s,k_s)
 =B_{s+1}-B_s-P_sE_s,
\qquad
B_s=\det(c,a_s).
\tag{8.2}
\]

This is a legitimate one-step telescoper, but its boundary mode is the conserved global column \(c=a_0\).  Summing (8.2) returns the exponentially tall endpoint determinant.

The no-prefix theorem says that no finite local combination of the ray states and their tensor/exterior powers can remove this affine mode.  In Rees language, the cumulative extension is not split by a target-preserving integral map.  Locally at a target, any rank-two recovery of the conserved column pays a moving Smith factor \(p\); dividing by it loses target preservation by (7.5).

The radial chain does not change this conclusion.  It may compress the local tangent state, but it does not make the affine extension split, and it does not supply the missing primitive prefix value.

This is also the terminal-observability obstruction in the rank-8001 formulation.  A terminal zero tail propagates only after proving that the observability determinant \(\Theta_T\) is a unit.  Transfer regularity and radial Smith regularity do not imply that assertion.

## 9. The exact conditional theorem that would prove the desired boundary-factor bound

The correct positive statement is the following.

### Theorem 9.1 -- strict Rees plus primitive observability

For a full-margin block, suppose there is an integral filtered Brieskorn lattice \(H\), an actual exterior state \(\xi\in H\), and translated observation rows \(O_s\in H^\vee\) such that:

1. **Actual identity:**
   \[
   E_s=O_s(\xi)
   \]
   in \(\mathbb Z\), with every denominator cleared before specialization.

2. **Strict finite Rees support:** after multiplying by a fixed integer \(C_0\), the actual Laurent packet maps into an uncompleted finite radial presentation; the homotopies are finite, and the Rees homology has no additional torsion on the packet.

3. **Endpoint Fitting bound:** some full-rank observation minor \(\Delta\) satisfies
   \[
   \Delta\mid C_1\prod_{h\in H_n}(M+h)
   \]
   with \(C_1\) fixed and \(|H_n|=o(n/\log n)\).

4. **Primitive prefix:** the content of \(\xi\) in this integral lattice divides a fixed integer \(C_2\).

Then

\[
\boxed{
\gcd_s E_s
 \mid C_0C_1C_2\prod_{h\in H_n}(M+h),
}
\tag{9.1}
\]

up to the explicitly separated small-prime multiplicity ledger.  Consequently

\[
\log\gcd_s E_s=o(n).
\tag{9.2}
\]

#### Proof

Choose the square observation submatrix whose determinant is \(\Delta\).  Apply Lemma 6.1 to the integral state after the fixed saturation clearing.  This gives

\[
\gcd_s E_s\mid C_0c(\xi)\Delta.
\]

Use assumptions 3 and 4.  Finally,

\[
\log\prod_{h\in H_n}|M+h|
 \le |H_n|\log(O(n))=o(n).
\]

All target specializations are legitimate because assumption 1 clears denominators before reduction.  \(\square\)

This theorem isolates the exact missing inputs.  The new formal calculation addresses only part of assumption 3.  It does not establish assumptions 2 or 4.

## 10. Why the present data do not satisfy Theorem 9.1

### 10.1 Strict finite Rees support fails at the level currently proved

The actual boundary monomial \(d^{-M}\) has the infinite radial expansion (3.3), or equivalently a pole of order \(2M-1\).  Every finite Taylor truncation introduces a new genuine `B`-wall.  Thus the completed formal quotient is not a finite radial presentation of the global Laurent packet.

The rank-two algebraic chart (2.11) is finite, but it is localized at \(t(x+1)\), and its saturation denominator grows like \(t^{2M}\).  No fixed integral Rees splitting has been proved.

### 10.2 The endpoint determinant is not the radial transfer determinant

The terminal exterior audit separates

\[
\det(\text{transfer})
\]

from

\[
\Theta_T=\det(\text{observability}).
\]

The radial chain can control transfer and finite-chain presentation walls.  It does not compute \(\Theta_T\) for the actual translated Newton observations.

### 10.3 The actual state is not known to have fixed content

The target radical divides every evaluated normalized minor while the coefficient rows are primitive.  This is exactly the factor \(c(\xi)\) in Lemma 6.1.  Bounding it is the original arithmetic problem, not a consequence of the formal quotient.

### 10.4 Dividing a moving wall is not target-safe

The target supplies one surviving copy of \(p\) after the universal Newton normalization.  The first divided increment is free modulo \(p\).  Hence no wall factor may be canceled without a new, actual Apéry identity certifying a second copy.

## 11. Precise conclusion

The exact answer to the question is:

* The finite-chain Smith theorem is valid and is given by Lemmas 1.1--1.3.
* A rigorous algebraic bridge away from the false formal inverse exists: the rank-two chart (2.11) and the pole Rees filtration (3.7).
* Applied to the actual full-margin endpoint multiplier, that bridge gives a pole endpoint of linear size, \(2M-1\), and not a bounded radial degree.
* The finite radial Smith content controls only presentation/observation content.  It does not control the distinguished Apéry-state factor that contains the target radical.
* The terminal prefix/observability determinant and an integral primitive-state certificate remain missing.

Therefore the current smooth-tangent/radial structure cannot prove that the common gcd divides a fixed constant times only \(O(1)\), or \(o(n/\log n)\), boundary linear factors.

The precise counterexample to the proposed inference is the actual Laurent boundary term

\[
(yz)^{-M},
\]

whose radial image has exact pole order \(2M-1\) and whose finite truncations acquire a new genuine wall at every depth, together with the actual target instance \((n,p)=(200,181)\), where target divisibility occurs before the radial presentation has any ordered wall in the visible range.

This does **not** disprove (68.72).  It proves that a completion of (68.72) must add one of the following genuinely new ingredients:

1. an integral exterior cancellation showing that the \((1-q)^{-(2M-1)}\) pole cancels in the **actual cross-minor family** down to \(o(n/\log n)\) pole order, together with a proof that the cancellation is target-preserving; or
2. an explicit uncompleted Laurent/Brieskorn Bezout identity
   \[
   \sum_s U_sE_s=Q,
   \qquad
   0\ne Q\mid C\prod_{h\in H_n}(M+h),
   \qquad
   |H_n|=o(n/\log n),
   \]
   with every denominator and every prefix value audited over \(\mathbb Z\).

Without one of these, the formal radial chain is a correct local model but not a proof of the full-margin exterior-content lemma.

## 12. Exact replay fragment

The following Sage fragment checks the algebraic chart and the finite-chain minors.  It uses only exact polynomial arithmetic.

```sage
# SageMath
R.<x,t,q,r,M> = PolynomialRing(QQ)

f = (x+1)*r^2 + x*(t-q)*r - q*x*t
N = t + x*q - (x+1)*r

# In the quotient by f, (t+r)N=t^2.
assert ((t+r)*N - t^2).reduce([f]) == 0

# Radial coefficients.
def A(j):
    return 4*j + 6

def B(j):
    return 2*M + 2*j + 5

# Maximal minor after deleting column k from [a,b].
def radial_minor(a,b,k):
    left  = prod(A(j) for j in range(a,k))
    right = prod(B(j) for j in range(k,b))
    return left*right

# Every odd common prime comes from an ordered A/B wall and divides M+h:
# 2*B(j)-A(i)=4*(M+j-i+1).
i,j = var('i j')
assert expand(2*(2*M+2*j+5) - (4*i+6)) == 4*(M+j-i+1)

# The n=200, p=181 wall positions.
p = 181
M0 = 199
A_walls = [j for j in range(0, 271) if (4*j+6) % p == 0]
B_walls = [j for j in range(0, 252) if (2*M0+2*j+5) % p == 0]
assert A_walls[:2] == [89,270]
assert B_walls[:2] == [70,251]
```
