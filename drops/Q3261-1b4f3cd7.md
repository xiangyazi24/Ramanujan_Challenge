# Part I. Exact recurrence for the slope subsequence

## 2. Start from the Apéry transfer

Write

```text
P(n) = 34*n^3 + 51*n^2 + 27*n + 5.
```

The Apéry recurrence is

```text
(n+1)^3*b_(n+1) - P(n)*b_n + n^3*b_(n-1) = 0.
```

Use the two-dimensional state

```text
S_n = (b_n,b_(n-1))^T.
```

Define

```text
H(n) = [ P(n)     -n^3     ]
       [ (n+1)^3   0       ]
```

and

```text
A(n) = H(n)/(n+1)^3.
```

Then exactly

```text
S_(n+1) = A(n) S_n.
```

For fixed `s>=1`, define the polynomial matrix and scalar denominator

```text
Q_s(n) = product_{j=1}^s (n+j)^3,

C_s(n) = H(n+s-1) H(n+s-2) ... H(n)
       = [ alpha_s(n)  beta_s(n)  ]
         [ gamma_s(n)  delta_s(n) ].
```

Thus the exact `s`-step transfer is

```text
S_(n+s) = M_s(n) S_n,
M_s(n) = C_s(n)/Q_s(n).
```

All of `alpha_s,beta_s,gamma_s,delta_s,Q_s` are integer polynomials in `n`; every entry of `C_s` has degree at most `3*s`, and `Q_s` has degree exactly `3*s`.

Also

```text
det A(n) = n^3/(n+1)^3,
```

so telescoping gives

```text
det M_s(n) = n^3/(n+s)^3.
```

## 3. Eliminate the hidden state: exact order-two sampled recurrence

For a general two-dimensional recurrence

```text
(y_(t+1),z_(t+1))^T
 = [a_t b_t; c_t d_t] (y_t,z_t)^T,
```

the first coordinate satisfies the exact elimination identity

```text
b_t*y_(t+2)
- (b_t*a_(t+1) + b_(t+1)*d_t)*y_(t+1)
+ b_(t+1)*det(M_t)*y_t
= 0.
```

Apply this to

```text
n = sigma+s*t,
y_t = b_n,
M_t = M_s(n).
```

Define the three integer polynomials

```text
B_2(n)
 = beta_s(n) * Q_s(n+s) * (n+s)^3,

B_1(n)
 = -(n+s)^3
   * ( beta_s(n)*alpha_s(n+s)
       + beta_s(n+s)*delta_s(n) ),

B_0(n)
 = beta_s(n+s) * Q_s(n) * n^3.
```

Then, with `n=sigma+s*t`, the slope subsequence satisfies

```text
B_2(n)*y_(t+2) + B_1(n)*y_(t+1) + B_0(n)*y_t = 0.       (S2)
```

No division remains in `(S2)`, so it stays valid even at a specialization where a transfer entry such as `beta_s(n)` vanishes.

### Degree and leading coefficients

Put

```text
d = 6*s+3.
```

Let the integer sequence `u_s` be

```text
u_0 = 0,
u_1 = 1,
u_(s+1) = 34*u_s - u_(s-1),
```

and put

```text
L_s = u_(s+1) - u_(s-1).
```

For

```text
T = [34 -1; 1 0],
```

one has exactly

```text
T^s = [ u_(s+1)   -u_s     ]
      [ u_s       -u_(s-1) ],
```

hence `L_s=tr(T^s)`. Since

```text
H(n) = n^3*T + O(n^2),
Q_s(n) = n^(3*s) + O(n^(3*s-1)),
```

we get

```text
B_2(n) = -u_s*n^d + O(n^(d-1)),
B_1(n) =  u_s*L_s*n^d + O(n^(d-1)),
B_0(n) = -u_s*n^d + O(n^(d-1)).                        (LC-t)
```

Thus all three have degree exactly `d`, since `u_s>0` for `s>=1`.

After substituting `n=sigma+s*t`, their leading coefficients as polynomials in `t` are

```text
lc_t B_2 = -u_s*s^d,
lc_t B_1 =  u_s*L_s*s^d,
lc_t B_0 = -u_s*s^d.                                    (LC-t2)
```

For later regression checks:

# Part II. Exact recurrence for `c_K = Delta^K y_0`

## 4. Binomial-transform operator identities

Let

```text
y_t = sum_{K>=0} binom(t,K)c_K,
```

with `c_K=0` for `K<0`.

On `K`-sequences define

```text
(E c)_K = c_(K+1),
(R c)_K = c_(K-1),
(N c)_K = K*c_K.
```

Then the binomial transform gives the two exact conjugation rules

```text
shift t -> t+1     corresponds to     1+E,

multiplication by t corresponds to     Theta := N*(1+R).
```

The second identity is just

```text
t*binom(t,K)
 = K*binom(t,K) + (K+1)*binom(t,K+1).
```

Now set

```text
q_i(t) = B_i(sigma+s*t),   i=0,1,2.
```

Each `q_i` is an integer polynomial of degree `d=6*s+3`.

Define the exact Laurent difference operator

```text
L_minus
 = q_2(Theta)*(1+E)^2
   + q_1(Theta)*(1+E)
   + q_0(Theta).                                           (NL)
```

Then

```text
L_minus c = 0.
```

Because `Theta=N*(1+R)` uses shifts only `0,-1`, `q_i(Theta)` has no shift below `-d`. Therefore

```text
L := E^d * L_minus                                      (NK)
```

is an ordinary forward polynomial recurrence operator. Normal-order it as

```text
L = sum_{j=0}^{R_s} C_j(K;s,sigma) E^j,
R_s = d+2 = 6*s+5.                                      (NKn)
```

Then the exact Newton recurrence is

```text
sum_{j=0}^{6*s+5} C_j(K;s,sigma)*c_(K+j) = 0.           (NREC)
```

For fixed `s`,

```text
C_j(K;s,sigma) in Z[K,sigma],
deg_K C_j <= d.
```

The raw operator has nonzero extreme shifts, so its displayed support really is `0,...,d+2`; I do **not** claim that `d+2` is the minimal order of the annihilator after Ore factorization.

This proves existence of a fixed-order recurrence for every fixed slope. For `s=4` the raw order is `29`; for `s=7` it is `47`.

### Height

For fixed `s`, the symbolic degrees in `K` and `sigma` are `O(s)`, with integer coefficients depending only on `s`. Hence if

```text
|K| + |sigma| <= C*m,
```

then

```text
log |C_j(K;s,sigma)| = O_s(log m).
```

Thus the recurrence coefficients have polynomial, hence subexponential, height on the active range. There is no characteristic-zero height obstruction for fixed slopes `4` or `7`.

If `s` itself were allowed to grow with `m`, both the order and coefficient complexity grow with `s`; no uniform-in-growing-`s` sublinear statement is asserted here.

# Part III. The correct residual of `a_K`

## 5. Define the residual

Let the selector comparison sequence be

```text
a_K = (X+2*K+1)/(K+1)
    = 2 + (X-1)/(K+1).                                  (a)
```

Apply the correct slope-Newton operator `(NK)`:

```text
rho_(s,sigma)(K;X)
 = (L a)_K
 = sum_{j=0}^{R_s} C_j(K;s,sigma)*a_(K+j).               (rho)
```

Clear only the explicit comparison denominators by

```text
D_K = product_{j=0}^{R_s} (K+j+1),

Rho_(s,sigma)(K;X)
 = D_K * rho_(s,sigma)(K;X).                             (RHO)
```

Then, for fixed `s`,

```text
Rho_(s,sigma)(K;X) in Z[K,sigma,X],
```

and it is affine in `X`.

A crude but sufficient degree bound is

```text
deg_K Rho <= d + R_s + 1 = 12*s+9.                      (degR)
```

## 6. Uniform nonvanishing theorem

The residual is nonzero for **every** `s>=1`, independently of `sigma` and `X`.

Indeed, if a sequence `f_K=C+O(1/K)`, then

```text
Theta f = N*(1+R)f = 2*C*K + O(1),
```

and inductively

```text
Theta^d f = 2^d*C*K^d + O(K^(d-1)).
```

Since

```text
(1+E)^i a_K = 2^(i+1) + O(1/K),
```

and `(LC-t2)` gives the leading coefficients of `q_i`, the coefficient of `K^d` in `L_minus a` is exactly

```text
u_s*s^d*2^(d+1) * (2*L_s - 5).                          (LC-rho)
```

The left multiplication by `E^d` only shifts `K` and does not change this leading coefficient. Therefore

```text
rho_(s,sigma)(K;X)
 = u_s*s^d*2^(d+1)*(2*L_s-5)*K^d
   + O_s,sigma,X(K^(d-1)).                               (rho-asym)
```

Equivalently, the cleared polynomial `(RHO)` has degree `d+R_s+1` and the same leading coefficient:

```text
lc_K Rho_(s,sigma)
 = u_s*s^d*2^(d+1)*(2*L_s-5).                            (LC-RHO)
```

Now `u_s>0` and

```text
L_1=34,
L_(s+1)=34*L_s-L_(s-1),
L_0=2,
```

so `L_s>=34` for every `s>=1`. Hence

```text
2*L_s-5 > 0.
```

Thus

```text
boxed: Rho_(s,sigma)(K;X) is not the zero polynomial
       for every fixed integer s>=1.                     (NONZERO)
```

This is a theorem, not numerical evidence.

### Height of the residual

For fixed `s`, if

```text
K,sigma,X = O(m),
```

then

```text
log |Rho_(s,sigma)(K;X)| = O_s(log m)                    (HEIGHT)
```

whenever the value is nonzero. Thus a prime-power divisor forced into one such residual costs only `O_s(log m)` logarithmic height.

This is exactly the kind of low-height characteristic-zero residual sought in the question.

# Part IV. Consequence for the primitive minor carrier

The following uses only the standard selector identities; it does not use the invalid Q3246 recurrence.

Assume the normalized first column is `v_K` and the truncated values are `T_K`, with

```text
(K+1)*v_(K+1) = -(X+K)*v_K,                              (V)

T_(K+1)-T_K = G*v_K*c_K.                                 (T)
```

Define

```text
d_K = v_K*T_(K+1) - v_(K+1)*T_K,
A_K = X+2*K+1,
Q_K = (K+1)*T_(K+1) + (X+K)*T_K.
```

Then exactly

```text
(K+1)*d_K = v_K*Q_K,                                    (M1)
```

and with

```text
J_K = (K+1)*A_(K+1)*c_K - (K+2)*A_K*c_(K+1),
```

one has

```text
A_(K+1)*Q_K - A_K*Q_(K+1) = G*v_(K+1)*J_K.              (M2)
```

Since `a_K=A_K/(K+1)`, also

```text
J_K
 = (K+1)*(K+2)*(a_(K+1)*c_K-a_K*c_(K+1)).               (M3)
```

## 7. Direct regular-adjacent lemma

Let `ell` be prime and suppose `ell^e` divides

```text
d_K,d_(K+1),...,d_(K+R_s).
```

Assume on the corresponding stencil that

```text
ell does not divide v_i,
ell does not divide i+1,
ell does not divide A_i,
```

for all required indices, and put

```text
g = v_ell(G),
t = min_{0<=j<=R_s} v_ell(c_(K+j)).
```

Then `(M1)--(M3)` imply that the `c_(K+j)` are projectively proportional to `a_(K+j)` modulo `ell^(e-g)`, up to the common scalar valuation `t`. Applying the correct recurrence `(NREC)` and clearing `D_K` gives

```text
e
 <= g + v_ell(Rho_(s,sigma)(K;X))
      + min(t,max(e-g,0)).                                (ADJ)
```

In particular, in the primitive unit case

```text
ell does not divide G,
min_j v_ell(c_(K+j)) = 0,
```

one gets

```text
ell^e divides Rho_(s,sigma)(K;X).                        (ADJ-unit)
```

By `(HEIGHT)`, such a common adjacent-minor prime power has only polynomial-height room.

This is the corrected version of the Q3237 five-step idea: the old fixed order-four residual must be replaced by the slope-dependent `R_s=6*s+5` residual above.

# Part V. Stronger full-second-Fitting lemma: only one unit anchor is needed

This is the useful Smith/Fitting formulation because it removes the requirement that every `v_i` in the recurrence stencil be an `ell`-unit.

## 8. Full determinant setup

Let the row vectors be

```text
M_i = (v_i,T_i)
```

on an interval containing all rows needed below, and let

```text
Delta_2 = gcd_{i<j} det(M_i,M_j).
```

Assume

```text
gcd_i v_i = 1.                                           (primitive)
```

Fix a prime `ell` and put

```text
e = v_ell(Delta_2).
```

Choose an index `q` with

```text
ell does not divide v_q.
```

Such a `q` exists by primitivity. Since every two-row minor is `0 mod ell^e`, there is a unique residue

```text
lambda = T_q / v_q mod ell^e
```

such that for every row index `i`,

```text
T_i = lambda*v_i mod ell^e.                              (PROP)
```

Using `(T)` and `(V)`, for every `i` for which `i+1` is an `ell`-unit,

```text
G*v_i*c_i
 = -lambda*a_i*v_i mod ell^e.                            (GC)
```

No division by `v_i` has been made.

## 9. Gauge the slope recurrence around the one unit anchor

Take any recurrence stencil

```text
K,K+1,...,K+R_s
```

containing the unit anchor `q=K+h`, `0<=h<=R_s`, and with the next row available so that `(T)` defines the final `c` value.

From `(V)`, for `j>=0`,

```text
v_(K+j)/v_K
 = (-1)^j
   * (X+K)^(bar j) / (K+1)^(bar j),                      (ratio)
```

where

```text
z^(bar j) = z*(z+1)*...*(z+j-1),
z^(bar 0)=1.
```

Set

```text
W_K
 = (K+1)^(bar R_s) * (X+K)^(bar R_s).                   (W)
```

Then for every `0<=j<=R_s`,

```text
omega_j
 = W_K * v_q/v_(K+j)
```

is an integer, by `(ratio)`.

Multiply `(NREC)` by `W_K*v_q` after substituting

```text
c_(K+j) = (v_(K+j)c_(K+j))/v_(K+j).
```

This gives the exact integer gauged recurrence

```text
sum_{j=0}^{R_s}
  C_j(K;s,sigma)*omega_j*(v_(K+j)c_(K+j))
= 0.                                                      (GAUGE)
```

Applying the same coefficients to the comparison sequence gives exactly

```text
sum_{j=0}^{R_s}
  C_j(K;s,sigma)*omega_j*(v_(K+j)a_(K+j))
= W_K*v_q*rho_(s,sigma)(K;X).                            (GAUGE-a)
```

Now apply `(GAUGE)` to congruence `(GC)`. One obtains

```text
lambda*W_K*v_q*rho_(s,sigma)(K;X) = 0 mod ell^e.         (FIT-res)
```

If additionally

```text
ell does not divide W_K,
ell does not divide D_K,
ell does not divide lambda,
```

then `v_q` is already a unit, and `(FIT-res)` gives the sharp conclusion

```text
boxed: ell^e divides Rho_(s,sigma)(K;X).                 (FIT-unit)
```

This is stronger than `(ADJ-unit)`: the other `v_(K+j)` may all be divisible by `ell`; only one unit anchor in the stencil is required.

More generally, with `v_q` a unit and `D_K` an `ell`-unit,

```text
e
 <= v_ell(lambda)
    + v_ell(W_K)
    + v_ell(Rho_(s,sigma)(K;X)).                          (FIT)
```

Here `v_ell(lambda)` is understood truncated at `e` if `lambda=0 mod ell^e`.

### Target support is preserved

This formulation does not divide out an unknown target factor.

For a core non-target prime in the stated slope construction, the exact Lucas law gives a nonzero common truncated value, so at a unit anchor `lambda` is an `ell`-unit; then `(FIT-unit)` excludes any unexplained high valuation by the low-height residual.

For a core target prime, all relevant `T_i` vanish modulo the target prime, so `lambda` is nonunit (indeed `0 mod ell` at the first level). The argument then deliberately does **not** divide by `lambda`, and the target remains in `Delta_2`.

Thus the residual is compatible with the target-carrier requirement.
