## 1. The script’s “raw” vectors are exactly the eight actual terminal node vectors

Put \(n=M+1\), and for \(0\le r\le7\) define

\[
 R_r=(Y_r,W_r),
 \qquad
 Y_r=C_M(M-r),
\]

with \(W_r\) the actual origin-cancelled coordinate at the same node. The backward terminal differences in the script are

\[
 B_L=\sum_{r=0}^{L}(-1)^r\binom LrR_r.
\tag{1}
\]

The script then defines

\[
 \widetilde R_r=
 \sum_{L=0}^{r}(-1)^L\binom rL B_L.
\tag{2}
\]

This is not another presentation of the packet: it is exactly binomial inversion. The coefficient of \(R_t\) in (2) is

\[
 \sum_{L=t}^{r}(-1)^{L+t}inom rL\binom Lt
 =\binom rt\sum_{u=0}^{r-t}(-1)^u\binom{r-t}{u}
 =\delta_{r,t}.
\]

Therefore

\[
 \boxed{\widetilde R_r=R_r.}
\tag{3}
\]

Consequently the 28 integers called `raw_minors` are precisely

\[
 \Delta_{ab}=\det(R_a,R_b),
 \qquad 0\le a<b\le7.
\tag{4}
\]

This removes one possible ambiguity in the scan: the raw gcd is the second determinantal divisor of the actual \(2\times8\) terminal-node matrix, not an artifact of two nested binomial transforms.

## 2. Exact finite Plücker formula for all seven exterior carriers

Let \(V_L\) be the cumulative terminal packet used by the scan. Its recursion is

\[
 V_0=R_0,
 \qquad
 V_L=V_{L-1}+(-1)^L\binom nL B_L.
\tag{5}
\]

For \(1\le L\le7\), direct summation gives

\[
 V_{L-1}=
 \sum_{r=0}^{L-1}\nu_{L,r}(n)R_r,
\tag{6}
\]

where

\[
 \boxed{
 \nu_{L,r}(n)=
 (-1)^{L-1-r}
 \binom nr
 \binom{n-r-1}{L-1-r}.}
\tag{7}
\]

Indeed,

\[
 \begin{aligned}
 [R_r]V_{L-1}
 &=\sum_{k=r}^{L-1}
   (-1)^{k+r}\binom nk\binom kr\\
 &=\binom nr
   \sum_{u=0}^{L-1-r}(-1)^u\binom{n-r}{u}\\
 &=(-1)^{L-1-r}\binom nr
   \binom{n-r-1}{L-1-r}.
 \end{aligned}
\]

Write

\[
 \beta_{L,r}=(-1)^r\binom Lr.
\]

The actual exterior carrier is

\[
 E_L=\det(B_L,V_{L-1}).
\]

Expanding in the basis (4) gives the completely explicit identity

\[
 \boxed{
 E_L=\sum_{0\le i<j\le L}\gamma^{(L)}_{ij}(n)\Delta_{ij},}
\tag{8}
\]

with

\[
 \gamma^{(L)}_{ij}=
 \begin{cases}
 \beta_{L,i}\nu_{L,j}-\beta_{L,j}\nu_{L,i},&j<L,\\[2mm]
 -\beta_{L,L}\nu_{L,i},&j=L.
 \end{cases}
\tag{9}
\]

All coefficients are integral polynomials in \(n\). In particular,

\[
 E_1=\Delta_{01}.
\tag{10}
\]

Thus

\[
 \boxed{
 \gcd_{a<b}\Delta_{ab}\mid\gcd_{1\le L\le7}E_L.}
\tag{11}
\]

This proves exactly why every moving factor already seen in the raw gcd persists in the exterior prefix. It also shows what the primitive universal Plücker-row computation does and does not say: it rules out a universal coefficient-lattice index, but it gives no upper bound on the evaluated determinantal divisor in (4).

## 3. Exact removal of the five origin-operator coefficients

Let

\[
 S_d(X)=\sum_{\kappa\in P\cap\mathbb Z^3}X^{-d\kappa},
 \qquad
 C_N(d)=\operatorname{CT}\bigl(\Lambda(X)^N S_d(X)\bigr).
\]

For \(0\le r\le7\) and \(0\le j\le4\), set

\[
 Q_{j,r}=
 C_{n+j}(n-r-2)+C_{n+j}(n-r).
\tag{12}
\]

If \(u_0(n),\ldots,u_4(n)\) and \(\mu(n)\) are the certified origin-operator coefficients, then

\[
 W_r=Z_r-\mu(n)Y_r,
 \qquad
 Z_r=\sum_{j=0}^{4}u_j(n)Q_{j,r}.
\tag{13}
\]

The multiplier \(\mu\) cancels **identically** from every raw minor:

\[
 \begin{aligned}
 \Delta_{ab}
 &=Y_aW_b-W_aY_b\\
 &=Y_aZ_b-Z_aY_b\\
 &=\sum_{j=0}^{4}u_j(n)
   \bigl(Y_aQ_{j,b}-Q_{j,a}Y_b\bigr).
 \end{aligned}
\tag{14}
\]

Define

\[
 D^{(j)}_{ab}=Y_aQ_{j,b}-Q_{j,a}Y_b.
\tag{15}
\]

Then

\[
 \boxed{
 \Delta_{ab}=\sum_{j=0}^{4}u_j(n)D^{(j)}_{ab}.}
\tag{16}
\]

This gives the requested pointwise separation. Put

\[
 g_u(n)=\gcd\bigl(u_0(n),\ldots,u_4(n)\bigr).
\tag{17}
\]

Writing \(u_j(n)=g_u(n)\bar u_j(n)\) pointwise gives

\[
 \Delta_{ab}=g_u(n)\widehat\Delta_{ab},
 \qquad
 \widehat\Delta_{ab}=
 \sum_j\bar u_j(n)D^{(j)}_{ab},
\]

and hence the exact multiplicative factorization

\[
 \boxed{
 \gcd_{a<b}\Delta_{ab}
 =g_u(n)\gcd_{a<b}\widehat\Delta_{ab}.}
\tag{18}
\]

For this determinant problem the exact coefficient content is therefore the gcd of the **five** \(u_j\)'s. Including \(\mu\) in the pointwise gcd is unnecessary and can only make the displayed divisor smaller; \(\mu\) is determinant-invisible by (14).

The certified polynomials satisfy

\[
 \gcd_{\mathbb Q[n]}(u_0,\ldots,u_4)=1.
\]

Therefore there are \(A_j(n)\in\mathbb Z[n]\) and a fixed nonzero integer \(C_U\) such that

\[
 \boxed{
 \sum_{j=0}^{4}A_j(n)u_j(n)=C_U.}
\tag{19}
\]

It follows pointwise that

\[
 \boxed{g_u(n)\mid C_U\quad\text{for every integer }n.}
\tag{20}
\]

Thus all unbounded/moving content lies in the distinguished normalized moment gcd in (18), not in the five origin coefficients. The Sage code below computes an exact cleared-denominator Bezout certificate (19), with no interpolation in \(n\). A minimal \(C_U\) is not needed for the conclusion; any nonzero cleared Bezout constant supplies the fixed-prime bound.

## 4. The distinguished part is one exact double Laurent moment

The common convolution can be retained without introducing labelled rays. Since

\[
 \Lambda^{n+j}=\Lambda^{n-1}\Lambda^{j+1},
\]

put

\[
 F_r(X)=S_{n-1-r}(X),
 \qquad
 H_r(X)=S_{n-r-2}(X)+S_{n-r}(X).
\tag{21}
\]

Then

\[
 Y_r=\operatorname{CT}_X\bigl(\Lambda(X)^{n-1}F_r(X)\bigr),
\]

\[
 Q_{j,r}=\operatorname{CT}_X
 \bigl(\Lambda(X)^{n-1}\Lambda(X)^{j+1}H_r(X)\bigr).
\]

Using independent torus variables \(X\) and \(X'\), (15) becomes

\[
 D^{(j)}_{ab}
 =\operatorname{CT}_{X,X'}
 \left(
 \Lambda(X)^{n-1}\Lambda(X')^{n-1}
 K^{(j)}_{ab}(X,X')
 \right),
\tag{22}
\]

where

\[
 \boxed{
 \begin{aligned}
 K^{(j)}_{ab}(X,X')={}&
 F_a(X)\Lambda(X')^{j+1}H_b(X')\\
 &-\Lambda(X)^{j+1}H_a(X)F_b(X').
 \end{aligned}}
\tag{23}
\]

Equations (16), (22), and (23) are the exact finite distinguished Laurent-moment packet requested in the question. They use the common power \(\Lambda^{n-1}\) essentially and are not valid for arbitrary independent arrays.

## 5. Exact no-go theorem for a regular multiplication-by-\(\Lambda\) Koszul/Bezout scalar

Let \(\theta_x=x\partial_x\), \(\theta_y=y\partial_y\), and \(\theta_z=z\partial_z\). For one torus copy, the twisted integration-by-parts generator appropriate to the weight \(\Lambda^{n-1}\) is

\[
 \mathcal T_i(G)=
 n(\theta_i\Lambda)G+\Lambda\theta_iG,
\tag{24}
\]

because

\[
 \operatorname{CT}\theta_i(\Lambda^nG)=0.
\]

Take the corresponding generators in both torus copies. Let \(\mathcal J\) be the \(\mathbb Q(n)\)-Laurent module generated by

1. all kernels \(K^{(j)}_{ab}\), \(0\le a<b\le7\), \(0\le j\le4\);
2. all twisted IBP generators (24) in either copy; and
3. ordinary multiplication-by-\(\Lambda\) Koszul generators in either copy.

Consider the actual torus curve

\[
 \mathcal C=\{(q,-1,-1):q\in\mathbb G_m\}.
\]

The committed terminal audit verifies, and direct substitution shows,

\[
 \Lambda|_{\mathcal C}=0,
 \qquad
 (\theta_x\Lambda)|_{\mathcal C}
 =(θ_y\Lambda)|_{\mathcal C}
 =(θ_z\Lambda)|_{\mathcal C}=0.
\tag{25}
\]

Restrict both torus copies to \(\mathcal C\). Denote this homomorphism by

\[
 \rho:\mathbb Q(n)[X^{\pm1},X'^{\pm1}]
 \longrightarrow
 \mathbb Q(n)[q^{\pm1},q'^{\pm1}].
\]

Every term in (23) contains a positive power of \(\Lambda(X)\) or \(\Lambda(X')\), so

\[
 \rho(K^{(j)}_{ab})=0.
\tag{26}
\]

Equation (25) also gives

\[
 \rho(\mathcal T_i(G))=0
\tag{27}
\]

for every regular Laurent polynomial \(G\), and similarly for every ordinary multiplication-by-\(\Lambda\) Koszul generator. Hence

\[
 \rho(\mathcal J)=0.
\]

But \(\rho\) fixes the scalar field \(\mathbb Q(n)\). Therefore

\[
 \boxed{
 \mathcal J\cap\mathbb Q(n)=\{0\}.}
\tag{28}
\]

In particular, for every nonzero \(P(n)\in\mathbb Q[n]\), there is no regular Laurent identity

\[
 P(n)=
 \sum_{a<b}A_{ab}(n,X,X')\Delta\text{-kernel}_{ab}
 +\text{Koszul/IBP boundaries}.
\tag{29}
\]

Taking

\[
 P(n)=C\prod_{h=2}^{7}(n+h)
\]

gives the requested exact negative result for the proposed construction. It is stronger than a bounded-degree search: (28) rules out **all** regular Laurent degrees and all rational functions of \(n\).

A completely concrete counterevaluation to (29) is obtained by setting

\[
 n=8,\qquad X=X'=(1,-1,-1).
\]

Every generator on the right is zero, while a nonzero constant \(C\) gives

\[
 C\prod_{h=2}^{7}(8+h)
e0.
\]

Again, this is a counterexample to the proposed Laurent/Koszul identity, not to an identity that might hold only after applying the distinguished constant-term functional.

## 7. Exact status of the observed \(n+2,\ldots,n+7\) support

Let

\[
 G_{\rm raw}(n)=\gcd_{0\le a<b\le7}\Delta_{ab}(n),
 \qquad
 G_{\rm dist}(n)=G_{\rm raw}(n)/g_u(n).
\tag{30}
\]

The strongest suggested value-level statement is

\[
 G_{\rm dist}(n)\mid
 C_0\prod_{h=2}^{7}(n+h)
\tag{31}
\]

for a fixed \(C_0\). The observed prime-support statement is weaker:

\[
 \operatorname{rad}G_{\rm dist}(n)\mid
 C_0\prod_{h=2}^{7}(n+h).
\tag{32}
\]

A linear Bezout combination of the 28 evaluated minors with value equal to the right side of (31) would prove the full valuation statement (31), not just (32). The present scan should therefore not be read as evidence for more \(q\)-adic multiplicity than it actually records.

For every prime \(q\nmid C_UC_0\prod_{h=2}^{7}(n+h)\), the radical statement (32) is exactly equivalent to

\[
 \boxed{
 \operatorname{rank}_{\mathbb F_q}
 \begin{pmatrix}
 Y_0&Y_1&\cdots&Y_7\\
 W_0&W_1&\cdots&W_7
 \end{pmatrix}=2.}
\tag{33}
\]

The full valuation statement is

\[
 \min_{a<b}v_q(\Delta_{ab})
 \le v_q(C_0)+
 \sum_{h=2}^{7}v_q(n+h).
\tag{34}
\]

Equations (33)–(34) are the exact remaining distinguished-moment theorem. The formal radial chain proves that a wall can force \(q\mid n+h\); it supplies one direction. The primitive Plücker lattice proves that no universal row index creates an additional factor. Neither statement proves the converse rank assertion (33). The singular-curve cokernel in (28) is precisely the missing module that a naive resultant calculation overlooks.

I found no supplied exact row violating (31) or (32), so there is no honest basis for declaring the numerical bound false. Conversely, the data and the wall calculation do not constitute a symbolic upper-bound proof. A successful continuation must do one of the following:

1. prove (33), and then its \(q\)-adic lift (34), by a Cartier calculation for the **common** convolution \(\Lambda^{n+j}=\Lambda^{n-1}\Lambda^{j+1}\); or
2. give a boundary-sensitive double-constant-term identity whose boundary correction has nonzero restriction on \(\mathcal C\), followed by an exact cancellation of its linearly growing pole.

A regular multiplication-by-\(\Lambda\) Koszul/Singular computation that omits that boundary sector is now ruled out by (28).

# 1. Formal binomial inversion and exterior-to-Pluecker matrix.
# ------------------------------------------------------------------
PN.<N> = PolynomialRing(QQ)


def pbinom(value, order):
    if order < 0:
        return PN.zero()
    return PN(
        prod(value - shift for shift in range(order)) / factorial(order)
    )


def wedge(left, right):
    out = {}
    for i in range(8):
        for j in range(i + 1, 8):
            entry = PN(left[i] * right[j] - left[j] * right[i])
            if entry:
                out[(i, j)] = entry
    return out


# The second binomial transform in q32_terminal_prefix_gcd_scan.sage
# is exactly the inverse of the backward-difference transform.
for residue in range(8):
    for node in range(residue + 1):
        coefficient_value = ZZ(
            sum(
                (-1) ** (order + node)
                * binomial(residue, order)
                * binomial(order, node)
                for order in range(node, residue + 1)
            )
        )
        assert coefficient_value == (1 if node == residue else 0)


for length in range(1, 8):
    beta = [PN.zero() for _ in range(8)]
    for node in range(length + 1):
        beta[node] = PN((-1) ** node * binomial(length, node))

    # Direct coefficients of V_{L-1} from the Pascal recursion.
    v_direct = [PN.zero() for _ in range(8)]
    v_direct[0] = PN.one()
    for order in range(1, length):
        pascal = PN((-1) ** order) * pbinom(N, order)
        for node in range(order + 1):
            v_direct[node] += (
                pascal
                * PN((-1) ** node * binomial(order, node))
            )

    # Closed formula (7).
    v_closed = [PN.zero() for _ in range(8)]
    for node in range(length):
        v_closed[node] = (
            PN((-1) ** (length - 1 - node))
            * pbinom(N, node)
            * pbinom(N - node - 1, length - 1 - node)
        )
    assert v_direct == v_closed

    direct_exterior = wedge(beta, v_direct)
    closed_exterior = {}
    for i in range(length):
        for j in range(i + 1, length + 1):
            if j < length:
                entry = (
                    beta[i] * v_closed[j]
                    - beta[j] * v_closed[i]
                )
            else:
                entry = -beta[length] * v_closed[i]
            entry = PN(entry)
            if entry:
                closed_exterior[(i, j)] = entry
    assert direct_exterior == closed_exterior

    [PN(1), PN(-1)] + [PN.zero()] * 6,
    [PN(1)] + [PN.zero()] * 7,

bezout_rows = [UPR.one()]

    for row in integer_bezout_rows
