# P32 far-bridge audit: what large sieve can and cannot prove

## Conclusion

The arithmetic far-bridge formulation is the correct direction, but the standard large-sieve inputs do not close the required exponent. The obstruction is not the number of formal gap parameters; after the near-bridge reduction the canonical variables are already optimal:

\[
(s,G,x),\qquad s\le H:=\sqrt{2X},\qquad G>H/\sqrt{\log X}.
\]

The required bound is

\[
\sum_{X<p\le 2X}E_{\rm far}(p)\ll \frac{X^{2+o(1)}}{\log X}.
\]

Equivalently, before dividing by the prime logarithm, one needs total prime-weighted height/count

\[
X^{2+o(1)}.
\]

A generic resultant gives a factor proportional to \(sG\), which is too large for long bridges. Replacing the resultant by ordinary integer large sieve, polynomial large sieve, or dispersion over \(x,G\) does not currently remove the same barrier.

The exact missing input is a conditioned projective mixing statement:

\[
\boxed{
\#\{(x,G):N_s(x)=N_G(x+s)=0\}\ \text{must gain a factor }1/p
\text{ beyond the two short-return marginals.}
}
\]

No standard large sieve theorem supplies this because the family indexed by \(G\) has conductor/degree growing with \(G\).

---

## 1. Canonical counting problem

After the near-bridge theorem, a separated pair is encoded injectively by

\[
(p,x,s,G),
\]

where

\[
N_s(x)=0,\qquad N_G(x+s)=0.
\]

The second equation is the long return. For fixed \(s,G\), define

\[
A_{s,G}(p)=\#\{x\in\mathbf F_p:
N_s(x)=N_G(x+s)=0\}.
\]

The target is

\[
\sum_{X<p\le2X}\sum_{s\le H}\sum_{G>H/\sqrt{\log X}}A_{s,G}(p)
\ll X^{2+o(1)}/\log X.
\]

There are

\[
H\cdot X=X^{3/2}
\]

possible \((s,G)\) pairs.

The trivial degree estimate gives

\[
A_{s,G}(p)\le \deg N_s\le 3(s-1),
\]

so summing directly gives

\[
\sum_{p,s,G}A_{s,G}(p)
\ll
\frac{X}{\log X}\cdot H\cdot X\cdot H
=X^{7/2}/\log X,
\]

far too large.

The long-return condition must be used arithmetically.

---

## 2. Switching order of summation over x

For fixed prime \(p\) and short span \(s\), let

\[
Z_s(p)=\{x:N_s(x)=0\}.
\]

Then

\[
|Z_s(p)|\le 3(s-1).
\]

The far count is

\[
\sum_{x\in Z_s(p)}
\#\{G:N_G(x+s)=0\}.
\]

This is the correct arithmetic ordering.

However the known polynomial degree bound gives

\[
\#\{G\le X:N_G(y)=0\}\le X
\]

trivially, because the index is the parameter of the polynomial itself. Unlike a fixed polynomial in \(G\), the degree grows like \(G\):

\[
\deg_XN_G=3(G-1).
\]

Therefore an ordinary polynomial large sieve in the variable \(G\) is unavailable: the conductor is of the same order as the summation length.

A valid large sieve would need a new theorem controlling the variable-index continuant family.

---

## 3. Integer large sieve obstruction

Suppose one treats each fixed \((s,G)\) as a polynomial congruence in \(x\).

The resultant

\[
R_{s,G}=\operatorname{Res}_x(N_s(x),N_G(x+s))
\]

has

\[
\log |R_{s,G}|\ll sG\log(s+G).
\]

For all long bridges this gives

\[
\sum_{s\le H}\sum_{G\le X}sG\log X
\asymp
H^2X^2\log X
=X^3\log X.
\]

Thus the height route misses by exactly a factor \(X\).

An integer large sieve would have to replace the height contribution by an average cancellation estimate of size

\[
\sum_{X<p\le2X}A_{s,G}(p)
\approx \frac{|Z_s||Z_G|}{p}.
\]

But proving this is precisely the unresolved correlation problem.

---

## 4. What a successful dispersion theorem would need

For fixed \(s,G\), the heuristic independent probability is

\[
\Pr(N_s(x)=0,N_G(x+s)=0)\approx p^{-2},
\]

because each projective equality costs roughly one condition.

There are \(p\) choices of \(x\), hence the expected count per prime is

\[
A_{s,G}(p)\approx 1/p.
\]

Summing over \(H X\) parameter pairs gives

\[
HX\cdot \frac1X=H=X^{1/2}
\]

per prime, which is negligible. Even allowing the short-return multiplicity factor \(H\), the desired global size is reachable.

A sufficient theorem would be:

\[
\boxed{
\sum_{X<p\le2X}A_{s,G}(p)
\ll X^{o(1)}
}
\]

uniformly for all

\[
s\le H,\qquad G\in[H/\sqrt{\log X},X].
\]

Then

\[
\sum_{s,G,p}A_{s,G}(p)
\ll
HX\cdot X^{o(1)}
=X^{5/2+o(1)},
\]

which is stronger than required.

A weaker averaged version is enough:

\[
\sum_{s,G}\sum_pA_{s,G}(p)
\ll X^{2+o(1)}.
\]

This is the exact arithmetic target.

---

## 5. Optional second short return

At

\[
y=x+s+G,
\]

one may include a short return \(t\le H\):

\[
N_t(y)=0.
\]

This adds another independent-looking condition. The expected count becomes

\[
\frac{|Z_s||Z_t|}{p^2}
\]

and could in principle close the problem.

However the corresponding family is

\[
N_G(x+s)=0,
\quad N_t(x+s+G)=0,
\]

and any elimination in \(G\) again has degree proportional to \(G\). Scalar resultants of the three equations do not solve this because they lose the common-root alignment.

The correct object would be a component-aligned arithmetic sieve, not a scalar gcd of resultants.

---

## 6. Precise stopping point of standard methods

The available methods give:

| Method | Output | Obstruction |
|---|---|---|
| Resultant height | \(X^{3+o(1)}\) | long degree \(G\) |
| Integer large sieve in p | needs average root cancellation | equivalent to missing mixing theorem |
| Polynomial large sieve in G | unavailable | degree/conductor \(\asymp G\) |
| Dispersion in x,G | needs shifted-index correlation | no known estimate |
| Add second short return | stronger heuristic | still requires aligned three-polynomial sieve |

Therefore the rigorous conclusion is:

\[
\boxed{
\text{Standard large-sieve technology stops one full factor }X
\text{ short.}
}
\]

The remaining theorem needed for Problem 3.2 is not a better height estimate but a new Apéry-specific long-return correlation theorem:

\[
\boxed{
\sum_{X<p\le2X}\sum_{s\le\sqrt X}\sum_{G\gg\sqrt X/\sqrt{\log X}}
A_{s,G}(p)
\ll X^{2+o(1)}.
}
\]

Any proof must exploit arithmetic structure of the variable-index continuants; treating \(N_G\) as a generic polynomial family necessarily fails because its degree and conductor grow with the bridge length.
