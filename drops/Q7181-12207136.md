# P32 AC^tr R3: Lucas-rank cutoff and incidence bounds

## Executive summary

Let
\[
N_p(H)=\#\{(a,b,c):a,b,c\ge 2,\ a+b+c\le H,\ p\mid \mathcal C^*_{a,b,c}\}.
\]
The Lucas-rank cutoff removes all primes with a short carrier zero. For a surviving prime, the correct consequence is not a uniform `O(H^2/\rho(p))` bound. The exact occurrence-list formula gives an incidence count on the projective orbit. The unconditional bound is a divisor-type incidence bound; an `H^2/\rho(p)` improvement requires an additional equidistribution hypothesis on the orbit.

For the tested primes:

* p=131: rho(131)=? must be computed from the exact order of the Lucas transfer; the surviving range is only H<rho(131).
* p=157 and p=653 similarly require the exact projective order, not a guessed period.

The structural conclusion is:

\[
N_p(H)\le \sum_{s\le H}\tau_s(p),
\]

where \(\tau_s(p)\) is an explicit triple-incidence multiplicity in the period-p occurrence lists. The desired global estimate

\[
\sum_p N_p(H)\log p\le H^{3+o(1)}
\]

is not a consequence of rank alone; it needs a uniform orbit-incidence theorem.

## 1. Survivor condition

The fully deflated aligned content removes the structural factors supported on

\[
U_H=\{p:p\mid b_j\text{ or }p\mid V_{j+1}\text{ for some }j\le H\}.
\]

Hence a residual prime satisfies

\[
 b_j\not\equiv0,\qquad V_{j+1}\not\equiv0\pmod p
\]

for all \(j\le H\).

For
\[
V_n=U_{n-1}(17),
\]
this means that no Lucas return occurs before H. If \(\rho(p)\) denotes the first positive Lucas zero index/order, then

\[
H<\rho(p).
\]

This is a cutoff on possible short gaps, not a direct saving factor.

## 2. Exact occurrence-list formulation

Let

\[
\pi_j=[b_j:c_j]\in \mathbf P^1(\mathbf F_p)
\]

be the projective Apéry orbit. For every state q define the occurrence list

\[
L_q=\{j\in[0,p-1]:\pi_j=q\}.
\]

A fully deflated aligned triple contributes exactly when three shifted returns occur in the same projective fiber. Therefore

\[
N_p(H)=
\sum_q\#\{(x,a,b,c):
 x,x+a,x+a+b,x+a+b+c\in L_q,
 a+b+c\le H,\
\text{deflated conditions}
\}.
\]

Equivalently, with the gap-difference incidence function

\[
I_q(a,b,c)=\#\{x:x,x+a,x+a+b,x+a+b+c\in L_q\},
\]

we have the exact identity

\[
\boxed{N_p(H)=\sum_{a+b+c\le H}\sum_q I_q(a,b,c)\,1_{\rm defl}(a,b,c,q).}
\]

No approximation occurs here.

## 3. What rank gives

The condition \(H<\rho(p)\) implies that the Lucas coordinate has no short periodic return. It prevents the obvious repeated-factor families.

However, a projective orbit may revisit a state without producing a Lucas zero. The map

\[
j\mapsto [b_j:c_j]
\]

is in \(\mathbf P^1(\mathbf F_p)\), while rho controls only one distinguished coordinate.

Therefore rank alone does not imply

\[
I_q(a,b,c)\ll 1/\rho(p).
\]

## 4. Divisor-type unconditional bound

For fixed q and fixed total span s=a+b+c, every occurrence of a quadruple is a 4-point pattern inside L_q. The trivial incidence estimate is

\[
I_q(a,b,c)\le |L_q|.
\]

Summing gives

\[
N_p(H)\le \sum_q |L_q|\#\{(a,b,c):a+b+c\le H\}
\]

and hence

\[
N_p(H)\ll pH^3.
\]

This is too weak, but it is the unconditional divisor-type baseline.

Using the survivor condition removes arithmetic divisors: for each gap s, possible starts lie in the intersection of translated occurrence lists. Thus a sharper form is

\[
N_p(H)=\sum_{s\le H}\sum_q R_q(s),
\]

where

\[
R_q(s)=\sum_{a+b+c=s}\#(L_q\cap(L_q-a)\cap(L_q-a-b)\cap(L_q-s)).
\]

This is the exact four-fold additive energy of the projective fibers.

## 5. Why O(H^2/rho) is conjectural

An `H^2/rho` estimate would require that every additional gap constraint costs a factor comparable to the Lucas rank:

\[
R_q(s)\approx \frac{H^2}{\rho(p)}.
\]

This is an orbit mixing statement. It does not follow from the recurrence identities currently available.

A possible conjectural bound is

\[
N_p(H)\ll H^{2+o(1)}/\rho(p),
\]

for residual primes. Summing this with rank growth could give the AC^tr target.

## 6. Tested primes

The correct computation must be:

```
rho(p)=min{r>0 : U_{r-1}(17)=0 mod p}
```

or equivalently the exact Lucas projective order.

The three examples must therefore be checked by the same occurrence-list program:

```
for p in [131,157,653]:
    compute rho(p)
    assert no Lucas zero before rho(p)
    build pi_j for j< p
    enumerate a+b+c<=H
    count four-fold fiber incidences
```

A previously reported numerical rho without this exact order computation is not sufficient.

## 7. Final theorem status

Proved:

1. Residual primes satisfy \(H<\rho(p)\).
2. \(N_p(H)\) has the exact projective occurrence-list incidence formula above.
3. Rank eliminates the structural U_H families.

Not proved:

\[
N_p(H)=O(H^2/\rho(p)).
\]

This is an additional projective-orbit equidistribution statement.

Therefore the AC^tr route currently reduces to proving either

\[
\sum_p N_p(H)\log p\ll H^{3+o(1)},
\]

or a sufficient replacement such as a rank-weighted incidence theorem. The Lucas cutoff is a useful sieve, but not by itself the missing arithmetic compression.
