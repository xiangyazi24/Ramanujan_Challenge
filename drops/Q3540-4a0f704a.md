Consequently the associated-graded slope-4 transverse charge is


# 11. What exactly differs from Q3529

Q3529 considers only the ordinary order-two recurrence transport.  If the input is the actual Apéry column, then regardless of how one partitions the same recurrence product,

```text
[b_j,b_(j-1)]  --->  [b_(p-1),b_(p-2)] = [1,5] mod p.
```

That map has forgotten how the source was **sampled** before entering the recurrence state space.  Consequently both slope labels collapse onto the same one-dimensional seam line.

The Newton construction keeps additional information before this collapse:

```text
slope 7 remembers
  b_1,b_8,b_15,...,b_71
  through d_0^(7),...,d_10^(7),

slope 4 remembers
  b_4,b_8,b_12,...,b_168
  through d_0^(4),...,d_41^(4).
```

These are two different linear functionals of the entire Apéry sequence.  They are not functions of the final two-component seam vector alone.

Equivalently, if `S_s` denotes the sampling operator

```text
(S_s b)_t = b_(sigma_s+s t),
```

and `Delta` the triangular forward-difference transform, then the Q3531 datum is built from

```text
Delta S_7 b
```

versus

```text
Delta S_4 b,
```

not from two copies of the same recurrence state at `p-1`.

That is the precise mathematical location of the cross-slope transversality.

If desired, the integer differences can be printed from the pushed `q32_newton.py` without changing any mathematics; reducing those huge integers modulo `97` must reproduce the two vectors above term-for-term.
