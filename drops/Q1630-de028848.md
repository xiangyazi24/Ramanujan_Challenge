## 4. Exact reciprocal-Apéry/Riccati equation

The canonical node values

\[
p_j:=P_m(\lambda_j)=b_j
\]

satisfy the Apéry recurrence

\[
(j+1)^3p_{j+1}
-c_jp_j
+j^3p_{j-1}=0,
\qquad
c_j:=34j^3+51j^2+27j+5.
\tag{4.1}
\]

Put

\[
z_j:=Z(\lambda_j),
\qquad
\epsilon_j:=1-p_jz_j.
\]

By (3.2),

\[
\boxed{\epsilon_j=\delta_{jr}=-H(\lambda_j)B(\lambda_j).}\tag{4.2}
\]

Substitute

\[
p_i=\frac{1-\epsilon_i}{z_i}
\]

into (4.1) and cross-multiply by
\(z_{j-1}z_jz_{j+1}\). This avoids dividing by the unconstrained target value \(z_r\). Define

\[
\mathcal R_j(Z):=
(j+1)^3z_{j-1}z_j
-c_jz_{j-1}z_{j+1}
+j^3z_jz_{j+1}.
\]

Then the exact forced reciprocal equation is

\[
\boxed{
\begin{aligned}
\mathcal R_j(Z)
={}&(j+1)^3\epsilon_{j+1}z_{j-1}z_j\\
&-c_j\epsilon_jz_{j-1}z_{j+1}\\
&+j^3\epsilon_{j-1}z_jz_{j+1}.
\end{aligned}}
\tag{Riccati}
\]

Using \(\epsilon_i=-H_iB_i\), this can be written explicitly in terms of the punctured quotient:

\[
\boxed{
\begin{aligned}
\mathcal R_j(Z)
={}&-(j+1)^3H_{j+1}B_{j+1}z_{j-1}z_j\\
&+c_jH_jB_jz_{j-1}z_{j+1}\\
&-j^3H_{j-1}B_{j-1}z_jz_{j+1}.
\end{aligned}}
\tag{4.3}
\]

Here \(H_i=H(\lambda_i)\), etc.

For an interior deleted target, all forcing is concentrated in the three rows touching \(r\):

\[
\boxed{\mathcal R_{r-1}=r^3z_{r-2}z_{r-1},}
\tag{4.4a}
\]

\[
\boxed{\mathcal R_r=-c_rz_{r-1}z_{r+1},}
\tag{4.4b}
\]

\[
\boxed{\mathcal R_{r+1}=(r+1)^3z_{r+1}z_{r+2},}
\tag{4.4c}

and \(\mathcal R_j=0\) elsewhere; endpoint rows truncate in the evident way.

This is the clean reciprocal-Riccati equation requested in the question. It is useful for locating the defect, but **it is not a new constraint**. It was obtained by inserting the punctured inverse values into the known Apéry recurrence. Conversely, with the Apéry initial/boundary normalization and off-target nonvanishing, undoing the same cross-multiplication reconstructs the same value recurrence. ## 5. The first genuinely new object is Hermite data

Let \(\nu\) be a simple root of \(T\). Then \(\nu\ne a\), \(H(\nu)=0\), and

\[
P_m(\nu)Z(\nu)=1.
\]

Differentiate

\[
P_mZ-1=HB.
\]

At \(Y=\nu\),

\[
P_m'(\nu)Z(\nu)+P_m(\nu)Z'(\nu)
=H'(\nu)B(\nu),
\]

which gives (H1), and hence

\[
\boxed{
-B(\nu)Z(\nu)
=-\frac{Z'(\nu)+P_m'(\nu)/P_m(\nu)^2}{H'(\nu)}.
}\tag{5.1}
\]

Now \(\widehat C\) is the degree-\(<\tau\) interpolation polynomial for these values on the roots of \(T\). The coefficient of \(Y^{\tau-1}\) in a Lagrange interpolant is the sum of the interpolation values divided by \(T'\). Therefore

\[
\boxed{
 c_T:=[Y^{\tau-1}]\widehat C
=-\sum_{\nu:T(\nu)=0}
\frac{Z'(\nu)+P_m'(\nu)/P_m(\nu)^2}
{H'(\nu)T'(\nu)}.
}\tag{5.2}
\]

This is the exact coefficient source. It sharply separates what is already known from what is missing:

* \(Z\) and therefore \(Z'(\nu)\) are fixed by the punctured inverse values;
* \(P_m(\nu)\) is the Apéry value \(b_j\);
* **\(P_m'(\nu)\)** is genuine Hermite data of the true degree-\(2m\) shell;
* \(B(a)=2\) does not appear.

This also explains exactly why the low-degree interpolant used in the old Q1604 verifier was fatal: it preserves \(P_m(\lambda_j)\) but changes the \(P_m'(\lambda_j)\) appearing in (5.2).

The true shell gives an explicit WZ-friendly formula for this derivative. Put

\[
F_{j,k}:=\binom jk\binom{j+k}{k}.
\]

For \(k\le j\), logarithmic differentiation of \(\phi_k\) gives

\[
\phi_k'(\lambda_j)
=F_{j,k}
\sum_{\ell=0}^{k-1}
\frac1{\lambda_j-\lambda_\ell}.
\]

All denominators are nonzero for \(0\le\ell<j\le m\), since

\[
\lambda_j-\lambda_\ell=(j-\ell)(j+\ell+1)
\]

and \(j+\ell+1\le p-1\). Terms with \(k>j\) make no contribution to the derivative of \(\phi_k^2\), because \(\phi_k(\lambda_j)=0\). Hence

\[
\boxed{
P_m'(\lambda_j)
=2\sum_{k=1}^{j}F_{j,k}^2
\sum_{\ell=0}^{k-1}
\frac1{(j-\ell)(j+\ell+1)}.
}\tag{5.3}
\]

In particular,

\[
A(a)=P_m'(a)
\]

is given by (5.3) at \(j=r\).

Equation (5.3), inserted into (5.2), is the correct place to seek a **genuine new Apéry/WZ telescoper**. Such a telescoper would control a hypergeometric-harmonic/Hermite sum. Merely proving (Riccati) again would not.

```sage
         + P.derivative()(lam[j]) / P(lam[j])^2)
        / (H.derivative()(lam[j]) * T.derivative()(lam[j]))
        for j in range(r+1, m)
    )
    assert hermite == ctop
else:
    q0_punctured = Z.leading_coefficient() + 1/(Aa*G.derivative()(a))

assert q0_punctured == stored_q0
```

For weighted controls, keep the same basis and alter only the coefficients of \(\phi_k^2\); require the top weight nonzero so the shell remains degree \(2m\). The two exact counterexamples above should be permanent negative gates against any future claim of the form “\(B(a)=2\) forces \(q_0\ne0\).”
