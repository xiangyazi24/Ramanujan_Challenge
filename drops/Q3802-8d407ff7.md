# 5. Definition and simplicity of `H_n`

Fix `n`.  Let `E_n` be the set of surviving physical q6 rows at this `n`, after the deterministic OR sign partition.  Define `H_n` by

\[
V(H_n)
=
\{v_{\ell,n}:\ell\text{ occurs as }p\text{ or }q
\text{ in some }e\in E_n\},
\tag{5.1}
\]

and give each row `e=(n,p,q)` the edge

\[
\{v_{p,n},v_{q,n}\}.
\tag{5.2}
\]

Because the map

\[
\ell\longmapsto 7\ell-1-n
\]

is injective, one may equivalently draw `H_n` on the prime labels `\ell`; the resource itself is still the labeled pair `(\ell,A_{\ell,n})`.

## No loops

Every row has `p<q`, so its two vertices are distinct.

## No parallel edges

Suppose two rows of `E_n` have the same unordered endpoints.  Since rows are oriented by `p<q`, they have the same `p` and `q`.  Then

\[
d=q-p,
\qquad
u=n-6q,
\qquad
r=n-6p
\]

are all fixed.  Hence they are the same physical row.

If both sign alternatives hold on that row, the deterministic sign partition retains exactly one copy.  Therefore the row set contains only one edge.

The plus fibre-two phenomenon does not create a parallel edge here: its two rows have different upper digits `u`, hence different values of `n=6q+u`, and therefore lie in different graphs `H_n`.

Thus

\[
\boxed{H_n\text{ is a simple graph.}}
\tag{5.3}
\]

This conclusion requires that the input is a set of physical rows.  If identical rows or both signs are retained as separate records, the correct object is a multigraph and the later `4`-vertex/`5`-edge minimum is no longer automatic.

# 6. Exact anchor-only Hall deficiency

Form the bipartite incidence graph `B_{\rm anc,n}` whose left vertices are the edges of `H_n`, whose right vertices are `V(H_n)`, and where a row-edge is adjacent to its two endpoints.

For a connected component `C` of a finite loopless graph, write

\[
e_C:=|E(C)|,
\qquad
v_C:=|V(C)|.
\]

## Lemma

The maximum number of edges of `C` that can be assigned injectively to incident vertices is

\[
\boxed{\nu_{\rm anc}(C)=\min(e_C,v_C).}
\tag{6.1}
\]

### Proof

If `e_C=v_C-1`, then `C` is a tree.  Root it and assign every edge to its child endpoint.  All `e_C` edges are assigned distinctly.

If `e_C\ge v_C`, choose a spanning tree and one additional edge.  This gives a spanning unicyclic subgraph with exactly `v_C` edges.  Orient the unique cycle cyclically and assign each cycle edge to its head; assign every tree edge away from the cycle to its child.  This matches `v_C` edges to all `v_C` vertices.

No matching can use more than either the number of edges or the number of vertices, proving `(6.1)`.

## Consequence

The exact number of anchor-unmatched rows in `C` is

\[
\boxed{e_C-\nu_{\rm anc}(C)=\max(0,e_C-v_C).}
\tag{6.2}
\]

Because anchor resources split by `n`, the global anchor-only deficiency is exactly

\[
\boxed{
D_{\rm anc}
=
\sum_n\sum_{C\in\pi_0(H_n)}
\max(0,e_C-v_C).
}
\tag{6.3}
\]

This formula actually remains true for loopless multigraphs.  Simplicity is needed only for the claimed smallest obstructing component.

# 8. Bicyclic consequence and the smallest simple obstruction

If `D_4>0`, then `(7.3)` gives `D_{\rm anc}>0`.  Hence some connected component `C` of some `H_n` satisfies

\[
e_C>v_C.
\tag{8.1}
\]

Its cyclomatic number is

\[
\beta(C)=e_C-v_C+1\ge2.
\tag{8.2}
\]

Thus it is bicyclic or more highly cyclic.

Because `H_n` is simple:

- for `v=1`, `e=0`;
- for `v=2`, `e\le1`;
- for `v=3`, `e\le3=v`.

So `(8.1)` forces

\[
\boxed{v_C\ge4,\qquad e_C\ge5.}
\tag{8.3}
\]

The minimum abstract component is `K_4` minus one edge.

A triangle has

\[
v_C=e_C=3,
\]

so its three edges can be cyclically assigned to its three vertices.  It contributes zero to `D_{\rm anc}`, and therefore cannot by itself force `D_4>0`.

More generally, a triangle with trees attached remains unicyclic and has `e_C=v_C`; it is equally harmless for Hall deficiency.

The word “harmless” here is narrow:

- it means no unmatched row in the occurrence matching;
- it does not mean zero carrier height;
- it does not mean a triangle is irrelevant to some different determinant or cycle identity.

# 9. Weight and carrier-height audit

## 9.1 Cheap anchor occurrence carrier

Let

\[
\mathcal V_{\rm anc}
=
\bigcup_n V(H_n)
\]

as a set of labeled pairs `(\ell,A)`, and define

\[
V_{\rm anc}(T)
:=
\prod_{(\ell,A)\in\mathcal V_{\rm anc}}
\gcd(\ell,b_A).
\tag{9.1}
\]

Every displayed gcd equals `\ell`, so

\[
V_{\rm anc}(T)
=
\prod_{(\ell,A)\in\mathcal V_{\rm anc}}\ell.
\tag{9.2}
\]

For a fixed prime `\ell`, distinct anchor resources have distinct zero indices, because `(\ell,A)` determines `n`.  Hence their number is at most `Z(\ell)`.

In the current q6 shell,

\[
T/7<p<q\le n/6\le T/3.
\tag{9.3}
\]

Therefore

\[
\begin{aligned}
\log V_{\rm anc}(T)
&\le
\sum_{\ell\le T/3}Z(\ell)\log\ell\\
&\ll
T^{2/3}\sum_{\ell\le T/3\atop\ell\ {m prime}}\log\ell\\
&=O_J(T^{5/3}).
\end{aligned}
\tag{9.4}
\]

This is the same squarefree zero-occurrence height mechanism audited in Q3799.  In particular,

\[
O_J(T^{5/3})=o_J(T^2/\log T).
\]

Using the raw product of the integers `b_A` is unnecessary and gives a much poorer ledger; the squarefree occurrence carrier `(9.1)` is the right object.

## 9.2 What an anchor matching pays

Let `M` be an anchor matching and assign a matched row `e=(p,q)` to its incident anchor prime

\[
\ell_e\in\{p,q\}.
\]

Because the assigned anchor vertices are distinct,

\[
\prod_{e\in M}\ell_e\mid V_{\rm anc}(T).
\tag{9.5}
\]

For the canonical lower-prime weight,

\[
\log p_e\le\log\ell_e.
\]

Thus

\[
\boxed{
\sum_{e\in M}\log p_e
\le
\log V_{\rm anc}(T)
=O_J(T^{5/3}).
}
\tag{9.6}
\]

Choose a maximum anchor matching.  It leaves exactly `D_{\rm anc}` rows unmatched.  Since every lower prime is at most `T/3`,

\[
\boxed{
\sum_{e\in E}\log p_e
\le
O_J(T^{5/3})
+D_{\rm anc}\log(T/3).
}
\tag{9.7}
\]

Consequently the anchor reduction closes the weighted residual whenever

\[
D_{\rm anc}=o_J(T^2/\log^2T).
\tag{9.8}
\]

If every `H_n` is a pseudoforest, then `D_{\rm anc}=0` and the whole family has weight `O_J(T^{5/3})`.

## 9.3 Divisibility warning

Equation `(9.5)` concerns the **assigned endpoint primes**.  It does not imply

\[
\prod_{e\in M}p_e\mid V_{\rm anc}(T).
\]

If an edge is assigned to its `q`-anchor, the carrier supplies a factor `q`, while the desired lower label is `p`.  What is true is the numerical inequality

\[
\prod_{e\in M}p_e
\le
\prod_{e\in M}\ell_e
\le
V_{\rm anc}(T).
\tag{9.9}
\]

This distinction already appears on a triangle.  For primes `p<q<s`, the three edge lower labels are `p,p,q`, while a cyclic anchor assignment uses one copy each of `p,q,s`.  Numerically

\[
p^2q\le pqs,
\]

but no divisibility `p^2q\mid pqs` follows.

Thus the proposal is valid for logarithmic height or row count.  It is not an exact lower-prime product carrier theorem.

## 9.4 Weighted deficiency is not `(6.3)`

For edge weights `w_e=\log p_e`, define the exact anchor weighted residual by

\[
D_{\rm anc}^{(w)}
:=
\min_{M\ {m anchor\ matching}}
\sum_{e\notin M}w_e.
\tag{9.10}
\]

There is no component formula using only `e_C-v_C`; the choice of which edges remain unmatched matters.  The shell comparison gives the safe bounds

\[
\boxed{
\log(T/7)D_{\rm anc}
\le
D_{\rm anc}^{(w)}
\le
\log(T/3)D_{\rm anc}.
}
\tag{9.11}
\]

The full weighted matching residual is at most `D_{\rm anc}^{(w)}`, for the same incidence-inclusion reason as `(7.3)`.

# 10. Relation to the Q3799 fungibility correction

The present theorem concerns endpoint-respecting Hall matching.  It does not undo the correction proved in Q3799.

The squarefree carrier

\[
\prod_{\ell}\prod_{j:\,\ell\mid b_j}\ell
\]

contains fungible copies of each rational prime `\ell`.  An unused `\ell`-zero in one graph component can pay an `\ell`-labelled row arising elsewhere, even if it is not incident to that row in the endpoint graph.

Therefore:

- `D_{\rm anc}` is an exact deficiency of the two-anchor incidence problem;
- `D_4` is an exact deficiency of the full four-occurrence incidence problem;
- neither is automatically the exact p-adic carrier deficiency;
- `D_4>0` implies a bicyclic anchor component, but a bicyclic component does not imply `D_4>0`;
- even `D_4>0` does not by itself imply an unpaid valuation after all nonincident same-prime carrier slack is allowed.

This is a scoped qualification, not a defect in `(V2)` or `(V3)`.

# 11. Corrected theorem

## Theorem — canonical-anchor Hall reduction for q6 rows

Let `E` be a finite set of actual q6 residual rows

\[
e=(n,p,q),
\qquad p<q,
\qquad n=6q+u=6p+r,
\]

satisfying

\[
p\mid b_r,
\qquad
q\mid b_u,
\]

and one of the exact plus/minus secondary-zero alternatives.  Assume:

1. every underlying physical row occurs once;
2. double-sign rows are assigned deterministically to one sign;
3. resource vertices are labeled zero occurrences `(\ell,j)`, with duplicate midpoint slots identified.

For every row define

\[
A_p=7p-1-n,
\qquad
A_q=7q-1-n.
\]

For each `n`, form the graph `H_n` with vertex `(\ell,7\ell-1-n)` for every incident prime and edge `p-q` for every row at `n`.  Let

\[
\Delta_{\rm anc}
=
\sum_n\sum_{C\in\pi_0(H_n)}
(|E(C)|-|V(C)|)_+.
\]

Then:

1. `A_p` is one endpoint of the exact lower reflected zero pair on both signs, and `A_q` is the reflected upper zero endpoint;
2. every anchor is a genuine Apéry zero occurrence;
3. every `H_n` is simple;
4. the exact two-anchor unmatched row count is `\Delta_{\rm anc}`;
5. if `D_4` is the full four-occurrence unweighted Hall deficiency, then
   \[
   D_4\le\Delta_{\rm anc};
   \]
6. if `D_4>0`, some `H_n` has a component of cycle rank at least two; such a simple component has at least four vertices and five edges;
7. a triangle or any unicyclic component contributes no Hall deficiency;
8. for the q6 shell,
   \[
   \sum_{e\in E}\log p_e
   \le
   O_J(T^{5/3})+\Delta_{\rm anc}\log(T/3).
   \]

Items 4–7 are unweighted matching statements.  Item 8 is a numerical height inequality, not lower-prime product divisibility.

# Bottom line

The proposed strengthening is mathematically sound in its intended unweighted form:

\[
D_4>0
\Longrightarrow
\exists n\ \exists C\subseteq H_n:
|E(C)|>|V(C)|.
\]

With the deterministic sign partition, `H_n` is simple, so this means a component with at least four anchor primes and five rows.  A triangle is harmless for Hall deficiency.

The corrected reduction should say **anchor-only Hall excess**, not exact weighted or p-adic excess.  Its useful weighted output is

\[
\sum_e\log p_e
\le
O_J(T^{5/3})
+\log(T/3)
\sum_{n,C}(|E(C)|-|V(C)|)_+.
\]

That is a genuine theorem.  Any stronger claim of exact lower-prime divisibility, full `n`-splitting, or exact carrier obstruction would reintroduce the defects isolated above.
