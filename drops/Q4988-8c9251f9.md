# 2. A new exact actual-index polynomial

The coefficient formula itself gives a useful actual-orbit descent which is not phrased in terms of projective return roots.

## Proposition 2.1 — quadratic-index formula

Let `p` be odd and `0<=n<=p-1`.  Put

```latex
T_n=n(n+1)\in\mathbb F_p.
```

Define

```latex
R_p(T)
:=\sum_{k=0}^{p-1}
\frac{1}{(k!)^4}
\left(
 \prod_{j=0}^{k-1}(T-j(j+1))
\right)^2
\in\mathbb F_p[T].
\tag{2.1}
```

Then

```latex
\boxed{b_n\equiv R_p(T_n)\pmod p.}
\tag{2.2}
```

### Proof

For every integer `n` and `k>=0`,

```latex
\binom nk\binom{n+k}{k}
=\frac{(n+k)!}{(k!)^2(n-k)!}
=\frac1{(k!)^2}
 \prod_{j=0}^{k-1}(n-j)(n+j+1).
```

But

```latex
(n-j)(n+j+1)=n(n+1)-j(j+1)=T_n-j(j+1).
```

Therefore

```latex
\binom nk^2\binom{n+k}{k}^2
=\frac1{(k!)^4}
 \left(
  \prod_{j=0}^{k-1}(T_n-j(j+1))
 \right)^2.
\tag{2.3}
```

For `0<=k<=p-1`, `k!` is a unit in `F_p`.  If `k>n`, the product in (2.3) contains the factor with `j=n`, hence vanishes at `T=T_n`.  Thus the usual sum from `k=0` to `n` may be extended through `p-1`, proving (2.2).  QED.

## Corollary 2.2 — exact descent through the palindrome quotient

The map

```latex
n\longmapsto T_n=n(n+1)
```

has exactly `(p+1)/2` values on `F_p`, because

```latex
T_u=T_v
\iff
(u-v)(u+v+1)=0.
\tag{2.4}
```

Consequently there is a unique polynomial

```latex
Q_p(T)\in\mathbb F_p[T],
\qquad
\deg Q_p\le\frac{p-1}{2},
\tag{2.5}
```

such that

```latex
Q_p(T_n)=b_n
\qquad(0\le n<p).
\tag{2.6}
```

One may take `Q_p` to be the interpolation of the explicit values (2.2) on the quadratic image.

The second root in (2.4) is `v=-1-u=p-1-u`, so this descent makes the canonical palindrome

```latex
b_n=b_{p-1-n}
```

completely transparent.

In the residual off-center core, two distinct displayed indices cannot have the same `T` value: equality would mean their sum is `p-1`, i.e. a centered pair.  Therefore an actual residual quadruple gives four **distinct** roots

```latex

\quad
T_{x+a},
\quad
T_{x+a+b},
\quad
T_{x+s}
```

of the one distinguished actual polynomial `Q_p`.

### What this gains, and what it does not

This removes projective phantoms completely: `Q_p` is built from the actual coefficient formula, and its roots on the quadratic image are exactly actual Apéry zero pairs.

However, the degree is of order `p`, and finite-field root counting contains no notion of the Archimedean spacing of the chosen lifts `x,x+a,...`.  More importantly, as a function on `F_p`, *every* palindromic function `f(n)=f(-1-n)` descends uniquely through `T=n(n+1)`.  Thus the mere existence of `Q_p` is equivalent to palindrome symmetry; the extra information is the explicit Newton-type representation (2.1).

A successful proof from this route would therefore have to exploit the very special coefficients and squared Newton factors in (2.1), not only `deg Q_p` or the quotient symmetry.

# 3. Exact Cartier-to-Mellin formula for the actual orbit

There is a second reformulation which is more geometric and potentially more suitable for a correlation theorem.

Recall the canonical Cartier polynomial

```latex
F(x,y,z,w)=(1-x-y)(1-z-w)-xyzw.
```

For `t in F_p^*`, define the integer point count

```latex
C_p(t)
:=\#\{(u,v,z,w)\in(\mathbb F_p^*)^4:
       F(u,v,z,w)=0,\ uvzw=t\},
```

and regard its reduction modulo `p` as an element of `F_p`.

## Proposition 3.1 — exact actual Mellin transform

For every prime `p` and every interior index

```latex
1\le r\le p-2,
```

one has in `F_p`

```latex
\boxed{
 b_r
 =-\sum_{t\in\mathbb F_p^*}C_p(t)t^{-r}.}
\tag{3.1}
```

### Proof

The canonical Cartier theorem gives

```latex
b_r=[x^ry^rz^rw^r]F^{p-1}\pmod p.
```

The polynomial `F` is multi-affine, hence `F^{p-1}` has degree at most `p-1` in each variable.  Write

```latex
F^{p-1}=\sum c_{i,j,k,l}x^iy^jz^kw^l.
```

For `1<=r<=p-2`, orthogonality on `F_p^*` gives

```latex
\sum_{u\in\mathbb F_p^*}u^{i-r}
=
\begin{cases}
-1,&i=r,\\
0,&i\ne r,
\end{cases}
```

because `0<=i<=p-1` and the only exponent congruent to `r` modulo `p-1` is `i=r`.  Therefore

```latex
\sum_{(u,v,z,w)\in(\mathbb F_p^*)^4}
F(u,v,z,w)^{p-1}(uvzw)^{-r}
=b_r,
\tag{3.2}
```

the four factors `-1` multiplying to `+1`.

By Fermat,

```latex
F(u,v,z,w)^{p-1}
=
\begin{cases}
1,&F(u,v,z,w)\ne0,\\
0,&F(u,v,z,w)=0.
\end{cases}
```

On the other hand, since `r` is a nontrivial exponent modulo `p-1`,

```latex
\sum_{(u,v,z,w)\in(\mathbb F_p^*)^4}(uvzw)^{-r}=0.
```

Hence the sum over `F!=0` is minus the sum over `F=0`.  Grouping the latter by `t=uvzw` gives (3.1).  QED.

## Consequence

The actual zero set is precisely the zero-frequency set of the finite-field Mellin transform

```latex
\widehat C_p(r)=\sum_{t\ne0}C_p(t)t^{-r}.
```

Thus the residual problem is no longer “which projective return roots happen to come from `[5:1]`?”  It can be stated intrinsically as:

> prove that the Mellin transform of this one fixed Cartier hypersurface point-count function cannot have four residual consecutive zero frequencies in an interval of length `p^(41/100+eta)`, or prove an averaged version with the saving quantified in Section 7.

This is, in my view, the cleanest genuine actual-orbit target exposed by the requested coefficient/constant-term route.

### Why generic uncertainty does not prove it

The group `F_p^*` has order `p-1`; (3.1) is simply its Fourier transform over `F_p`, whose characteristic does not divide the group order.  Ordinary uncertainty inequalities relate

```latex
|supp C_p|
```

to the **number** of nonzero Mellin coefficients.  They do not forbid four specified vanishing frequencies, much less distinguish an interval of short integer lifts.  Four zero coefficients are only four linear equations on a function with `p-1` coordinates.

One can Teichmüller-lift (3.1) to a cyclotomic integer

```latex
S_r=\sum_{t\ne0}C_p(t)\omega(t)^{-r}.
```

Then `b_r=0 mod p` says that `S_r` is divisible by a prime above `p`.  Deligne/Weil-type complex bounds for the conjugates of `S_r` do not by themselves rule this out: the cyclotomic degree is of order `p`, so an upper bound of polynomial size in `p` on each conjugate is entirely compatible with the algebraic norm being divisible by `p`.

Therefore a standard complex square-root estimate for a single Mellin coefficient is not the missing statement.  What is needed is a **mod-`p` anti-lacunarity or correlation theorem** for this special family of Mellin coefficients.

A natural weighted form would bound the four-zero correlation

```latex
\sum_r
  1_{\widehat C_p(r)=0}
  1_{\widehat C_p(r+a)=0}
  1_{\widehat C_p(r+a+b)=0}
  1_{\widehat C_p(r+s)=0}
```

on the residual gap range, with a power saving over the corresponding local-projective root count.  Section 7 gives the tiny power saving actually required.

# 4. The full-period transfer is the exact distinguished-line `p`-curvature

Q4975 showed that the local return matrices are orbit-blind and that actuality is the prefix condition.  There is a useful global reformulation which makes precise what a `p`-curvature attack would have to control.

Set, modulo `p`,

```latex
A_n=
\begin{pmatrix}
P(n)&-n^3\\
(n+1)^3&0
\end{pmatrix},
\qquad
P(n)=(2n+1)(17n^2+17n+5).
\tag{4.1}
```

For interior `n`, `A_n` is invertible.  At the two singular residues,

```latex
A_0=
\begin{pmatrix}5&0\\1&0\end{pmatrix},
\qquad
A_{p-1}=A_{-1}=
\begin{pmatrix}-5&1\\0&0\end{pmatrix}.
\tag{4.2}
```

For `p>3`,

```latex
A_0A_{p-1}
=\begin{pmatrix}-25&5\\-5&1\end{pmatrix}
```

is nonzero of rank one.

For `1<=x<=p-1`, define the full cyclic period product based at `x` by

```latex
\mathscr C_x
:=A_{x-1}\cdots A_1A_0A_{p-1}\cdots A_x.
\tag{4.3}
```

## Proposition 4.1 — rank-one period selector

For every `p>3` and `1<=x<=p-1`,

```latex
\operatorname{rank}\mathscr C_x=1,
```

and

```latex
\boxed{
\operatorname{im}\mathscr C_x
=[b_x:b_{x-1}].}
\tag{4.4}
```

In particular, with `Z=[0:1]`,

```latex
\boxed{
b_x=0\iff\operatorname{im}\mathscr C_x=Z.}
\tag{4.5}
```

### Proof

All factors other than `A_0,A_{p-1}` are invertible, while their adjacent product `A_0A_{p-1}` is nonzero rank one, so `mathscr C_x` has rank one.

The image of `A_{p-1}` is `[1:0]`.  Applying `A_0` sends this line to

```latex
[5:1]=L_A,
```

the distinguished Apéry initial line.  Applying the remaining prefix

```latex
A_{x-1}\cdots A_1
```

sends `L_A` to the actual Apéry state line `[b_x:b_{x-1}]` by the exact recurrence transfer identity from Q4975.  This proves (4.4) and (4.5).  QED.

## Proposition 4.2 — conjugacy transports exactly the local return problem

For `1<=x<=p-2`,

```latex
\mathscr C_{x+1}=A_x\mathscr C_xA_x^{-1}.
\tag{4.6}
```

More generally, for a nonwrapping interior displacement `h`,

```latex
\mathscr C_{x+h}
=M_h(x)\mathscr C_xM_h(x)^{-1},
\qquad
M_h(x)=A_{x+h-1}\cdots A_x.
\tag{4.7}
```

Hence, if `x` is an actual zero,

```latex
b_{x+h}=0
\iff
M_h(x)Z=Z
\iff
N_h(x)=0\pmod p,
\tag{4.8}
```

with the usual interior unit conditions.

### Meaning for `p`-curvature

The cyclic product `mathscr C_x` is the natural difference-equation analogue of a period/`p`-curvature operator.  Its conjugacy class is global, but its rank-one image eigenline moves with `x`, and that moving eigenline is **exactly the actual Apéry orbit**.

Equation (4.8) is a hostile audit of the hoped-for mechanism: once `mathscr C_x` has image `Z`, all later zero conditions in a short window are precisely the local return equations already used in CC2.  The additional actual information is only the location of the moving rank-one image at the first index.

Thus a `p`-curvature proof can work only if it proves a new theorem controlling how often or how rapidly this distinguished eigenline can hit `Z`.  Trace, rank, determinant, or any other conjugacy invariant of `mathscr C_x` cannot see those hit positions.  Recovering the image line by conjugation is exactly the prefix-transfer problem from Q4975.

This does not prove that a deeper crystalline/Frobenius argument is impossible.  It identifies the precise datum such an argument must estimate: the **eigenline**, not the conjugacy class.

# 5. Picard--Fuchs, Frobenius, and the 2026 Hasse factorization

Let

```latex
f(t)=\sum_{n\ge0}b_nt^n.
```

The Apéry numbers have the `p`-Lucas property, hence

```latex
f(t)\equiv A_p(t)f(t)^p\pmod p,
\qquad
A_p(t)=\sum_{n=0}^{p-1}b_nt^n.
\tag{5.1}
```

The generating series satisfies the third-order Picard--Fuchs/symmetric-square operator

```latex
\left(
\theta^3
-t(2\theta+1)(17\theta^2+17\theta+5)
+t^2(\theta+1)^3
\right)f=0,
\qquad
\theta=t\frac d{dt}.
\tag{5.2}
```

The recent theorem of
X. Caruso, F. Fürnsinn, D. Vargas-Montoya and W. Zudilin,
*Galois groups of Apéry-like series modulo primes*,
Bull. Austral. Math. Soc. **114** (2026), no. 1, 65--78,
DOI `10.1017/S0004972725100932`, proves that for every prime `p>3` there is `B_p in F_p[t]` with

```latex
A_p(t)=B_p(t)^2
```

for

```latex
p\equiv1,5,7,11\pmod{24},
```

and

```latex
A_p(t)=\Delta(t)B_p(t)^2,
\qquad
\Delta(t)=t^2-34t+1,
```

for

```latex
p\equiv13,17,19,23\pmod{24}.
\tag{5.3}
```

Their proof uses the rational parametrization

```latex
t=\frac{x(1-8x)}{1+x},
\qquad
f(t)=(1+x)h(x)^2
```

with the Franel generating series `h`, and the quadratic extension with discriminant `Delta`.

This is exactly the sort of Frobenius/Hasse input the question asks us to test.  Unfortunately its natural geometry is in the **generating parameter** `t`: it controls the divisor and Galois structure of `A_p(t)`.  The present zero set is

```latex
\mathcal Z_p=\{n:[t^n]A_p(t)=0\},
```

a coefficient condition.

The following lemma shows sharply why square factorization plus palindrome cannot bridge that gap by itself.

## Lemma 5.1 — hostile low-coefficient freedom

Let `p>3`, let

```latex
D(t)=1
```

or

```latex
D(t)=t^2-34t+1,
```

and suppose

```latex
A(t)=D(t)B(t)^2
```

has degree `p-1`, constant coefficient `1`, and is reciprocal:

```latex
t^{p-1}A(1/t)=A(t).
```

Write `m=deg B`; thus

```latex
m=\frac{p-1}{2}
```

when `D=1`, and

```latex
m=\frac{p-3}{2}
```

when `D=Delta`.

Then one may choose a sign `epsilon=+/-1` such that

```latex
t^mB(1/t)=\epsilon B(t).
\tag{5.4}
```

After fixing `c_0=1` in

```latex
B(t)=\sum_{j=0}^m c_jt^j,
```

the coefficients

```latex
[t]A,\ [t^2]A,\ldots,[t^N]A
```

can be prescribed **arbitrarily** for every

```latex
N<\frac m2.
\tag{5.5}
```

### Proof

`D` is reciprocal and `A` is reciprocal.  Hence

```latex
(t^mB(1/t))^2=B(t)^2.
```

Since `p` is odd and `F_p[t]` is an integral domain, (5.4) follows.

For `n<m/2`, the reciprocity relation has not yet identified `c_n` with a previously chosen low coefficient: `c_n` is a free coordinate, and the high coefficient `c_{m-n}` is determined afterward by (5.4).

Since `D(0)=1`, the coefficient of `t^n` in `DB^2` has the triangular form

```latex
[t^n]A
=2c_0c_n+P_n(c_0,c_1,\ldots,c_{n-1}),
\tag{5.6}
```

where `P_n` also includes the fixed `-34` and `1` contributions from `D` in the `Delta` case.  Because `2c_0=2` is a unit, for any desired value of `[t^n]A` there is a unique choice of `c_n`, once the earlier coefficients have been chosen.  Induction proves arbitrary prescription through every `N<m/2`.  QED.

## Corollary 5.2

Square/`Delta`-square factorization plus exact palindrome is compatible with an arbitrary pattern of zero and nonzero coefficients at any prescribed positions contained in the first approximately `p/4` indices.

In particular, those two global structural facts alone cannot prove `AO_eta`: a residual short block could lie in that coefficient range, and four zeros at its chosen positions create no algebraic contradiction with (5.3) and reciprocity.

This is **not** a counterexample to the actual Apéry polynomial, because the true `B_p` is additionally constrained by the Picard--Fuchs/Franel geometry.  It is a proof that the Hasse factorization and palindrome, taken as the proposed mechanism, do not themselves yield coefficient-zero spacing.  Any successful Frobenius proof must use additional information that couples the Franel/Picard--Fuchs solution to its coefficient sequence.

### Why the differential equation does not automatically supply that coupling

Taking coefficients in (5.2) reproduces the Apéry recurrence.  Thus, at the coefficient level, the directly available local consequence of the Picard--Fuchs equation is precisely the second-order transfer algebra already exploited by the gap polynomials.

The Frobenius relation (5.1) is extremely strong for base-`p` digits **above** the first digit: it is the Lucas property.  But on the first digit range `0<=n<p`, `A_p` is exactly the data we are trying to understand.  It does not create a shorter recurrence in the Euclidean index.

Likewise, `p`-adic analyticity or a crystalline local argument by itself cannot recognize that two distinct residues `x` and `x+a`, with `0<a<p`, are Archimedean-close: their difference is a `p`-adic unit.  The scale `a<p^{0.41+eta}` is an Archimedean lifting condition.  Any proof of that scale must therefore combine the Frobenius structure with an integer-height or short-lift argument; purely local `p`-adic zero counting cannot distinguish `a=2` from a generic nonzero residue.

# 6. Wronskians and palindrome: exact remaining obstruction

For completeness, the Wronskian obstruction from Q4975 survives all of the new reformulations.

For two recurrence solutions `u,v`,

```latex
W_n(u,v)
=(n+1)^3(u_{n+1}v_n-u_nv_{n+1})
```

is constant.  If `q^(x)` is the local solution normalized by

```latex
q_x=0,
\qquad
q_{x+1}=1,
```

then it is proportional to the distinguished Apéry solution exactly when

```latex
5q_0-q_1=0.
```

This is another scalar form of

```latex
\operatorname{im}\mathscr C_x=Z
```

and of the prefix equality `Pi_x^{-1}Z=[5:1]`.

The palindrome reflects an actual zero `r` to `p-1-r`.  A useful exact amplitude identity is obtained by defining, at an actual zero,

```latex
J_r:=r^3b_{r-1}=-(r+1)^3b_{r+1}.
```

Then reflection gives

```latex
J_{p-1-r}=J_r.
\tag{6.1}
```

Indeed

```latex
b_{p-2-r}=b_{r+1},
```

and

```latex
(p-1-r)^3b_{p-2-r}
=(-r-1)^3b_{r+1}
=r^3b_{r-1}.
```

This is genuine actual-orbit information, but for a residual block disjoint from its reflection it only identifies the amplitudes at corresponding reflected zeros.  It supplies no relation among the four amplitudes inside the original block.  If a reflected zero coincides with a displayed zero, one is back in the centered/overlap sector already removed.  Otherwise the comparison crosses a complementary arc of length `p-O(H)`, i.e. the same global-prefix wall.

So neither Wronskian normalization nor palindrome produces a new `H`-scale equation in the generic residual sector.

The target is

for some


i.e. strictly below

It is enough to prove, uniformly on the residual balanced-simple packets,

```latex

  w(p,x,a,b,c)\,p^{-\sigma}}
```

with the same nonnegative CC2 packet weight `w` used in `M_loc`, for any fixed

Using (7.1),

This exponent is strictly smaller than `4-5/41` precisely when



QED.

works, because

This is a very small actual-orbit saving.  Heuristically, selecting one distinguished line among `~p` projective lines would cost about `p^{-1}`, vastly stronger than necessary.  No such heuristic is used as proof; it only shows how weak (7.2) is relative to the natural random-line scale.

# 9. Exceptional-sector audit

The actual-orbit reformulations above preserve the exclusions rather than hiding them.

### 9.1 Small primes

The Hasse factorization is stated for `p>3`; `p=2,3` and any finite initial set are irrelevant to the asymptotic residual core and can be absorbed separately.

### 9.2 Endpoints

`b_0=1`, and the palindrome gives `b_{p-1}=1`, so actual zeros are interior.  Proposition 3.1 was intentionally stated for `1<=r<=p-2`, exactly where torus coefficient extraction has no endpoint aliasing.

### 9.3 Centered pairs

The quadratic descent has

```latex
T_u=T_v
\iff u=v\ \text{or}\ u+v=p-1.
```

Thus the only collision between two distinct actual zero indices is a centered pair.  Those are precisely the reflection-overlap configurations already separated in the CC2 analysis.  On the residual off-center core the four `T` roots are distinct.

### 9.4 Singular local returns

Nothing above converts a multiple local return root into a simple one.  The user-specified residual core already removes the singular ledger.  `ACT_sigma` is explicitly only a theorem on the simple residual packets.

### 9.5 Structural-carrier primes

The existing `mathfrak U_H` exceptional sector remains separate.  The new actual formulas neither assume its absence globally nor claim to repair its local valuation bookkeeping; they are intended for the already-localized residual packets after that sector has been charged.

### 9.6 Arithmetic-progression/all-equal and reflection-overlap slices

These remain the previously handled lower-dimensional slices.  The claimed new target is only the generic balanced residual.  No argument below silently uses an all-equal gap vector as representative of the generic case.

### 9.7 The two Hasse congruence classes

There is no missing prime class.  Every `p>3` lies in one of the eight residues modulo `24` appearing in (5.3).  The `Delta` factor is not an exceptional actual-zero sector: its roots are roots of the **generating polynomial** and do not by themselves correspond to zero coefficients `b_n`.

### 9.8 Projective phantoms

No phantom root is treated as actual anywhere in Propositions 2.1, 3.1, or 4.1.  The canonical phantom computations are relevant only to the older obstruction that local return algebra does not select `[5:1]`.  The new polynomial `Q_p`, Mellin function `C_p`, and rank-one period image are all defined from the distinguished Apéry solution itself.
