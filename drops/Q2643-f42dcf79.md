# P3.2 exact three-integer endpoint gate

## Verdict

The proposed estimate is **not presently proved**, but it admits a sharp exact reduction.  The good news is that the extra two binomial gates really do kill all purely Newton-certificate pollution at subexponential cost.  The bad news is that they do **not** isolate the single quotient slice `t=q`, nor even finitely many fixed quotient slices.

Let

\[
 m:=2q+1,\qquad H=\left\lfloor\frac{n-q}{m}\right\rfloor,\qquad k:=H+1,
\]
\[
 L_H=\operatorname{lcm}(b_0,\ldots,b_H),\qquad
 B_H(X)=\sum_{j=0}^H c_j\binom Xj,\qquad c_j:=\Delta^j b_0.
\]

Set

\[
 S_q(n):=
 \log\gcd\!\left(L_H,B_H(n),\binom nk\right)
 +\log\gcd\!\left(L_H,B_H(-n-1),\binom{n+k}{k}\right).
\]

Then, for fixed `q` and `n -> infinity`, the following is unconditional.

```text
EXACT ENDPOINT-GATE REDUCTION

For each prime p > n/log n write

    n = t p + r,         0 <= r < p,
    k = a p + h,         0 <= h < p,
    r* = p-1-r.

Define

    w_q(n,p) = 1_{h>r} + 1_{h>r*}  in {0,1,2}.

Then

    S_q(n)
      = sum_{p>n/log n, p | b_r} w_q(n,p) log p
        + O_q(n/log n + (log n)^3).

Here p is allowed to exceed n (then t=0); if p is outside the support of
one of the binomial coefficients the corresponding indicator is simply 0.
```

Thus the desired statement is **equivalent** to

\[
 \boxed{
 \sum_{p>n/\log n\atop p\mid b_{\,n\bmod p}}
 w_q(n,p)\log p=o_q(n).
 }
\]

The `O_q((log n)^3)` term contains every large-prime Newton ghost.  The `O_q(n/log n)` term contains all primes at most `n/log n`, including all prime powers.  So this is not merely a radical-support statement.

However, if

\[
 \varepsilon:=mk-n\in\{1-q,2-q,\ldots,q+1\},\qquad
 \sigma:=t-ma,
\]
then the exact digit relation is

\[
 r=mh-\sigma p-\varepsilon.
\]

Moreover

\[
 \boxed{\sigma\ge q\quad\Longrightarrow\quad w_q(n,p)\ge1.}
\]

Away from the two bounded endpoint anomalies `r=O_q(1)` and `r*=O_q(1)`, one has

\[
 \sigma\equiv t\pmod m,\qquad 0\le \sigma<m.
\]

The anomalous primes have total logarithmic mass `O_q(log n)`.  Consequently

\[
 S_q(n)\ge
 \sum_{\substack{p>n/\log n,\ p\mid b_{n\bmod p}\\
                  t=\lfloor n/p\rfloor,\ 
                  t\bmod(2q+1)\in\{q,q+1,\ldots,2q\}}}
 \log p-o_q(n).
\]

So the endpoint gate retains a **positive-density family of quotient classes**.  Since `t < log n` in the remaining range, the number of surviving quotient slices grows like a positive constant times `log n`; it is not a fixed finite set.

This is the obstruction.  Proving `S_q(n)=o_q(n)` would already prove a positive-density masked version of the repository's remaining top-window occupancy problem.  It is therefore not a finite-slice shortcut.

## 2. Prime powers below `sqrt(n)` are harmless

Let

\[
 C_+(n)=\binom nk,\qquad C_-(n)=\binom{n+k}{k}.
\]

For any prime `p`, each endpoint gcd has `p`-valuation at most the valuation of its binomial gate.  Hence the entire contribution of `p <= sqrt(n)` is bounded by

\[
 \sum_{p\le\sqrt n}
 \bigl(v_p(C_+(n))+v_p(C_-(n))\bigr)\log p.
\]

By Kummer, the valuation is the number of base-`p` carries.  Therefore

\[
 v_p(C_+(n)),v_p(C_-(n))\le 1+\log_p(2n).
\]

Chebyshev gives `pi(x) << x/log x` and `theta(x) << x`, so

\[
 \sum_{p\le\sqrt n}
 \bigl(v_p(C_+)+v_p(C_-)\bigr)\log p
 \ll \pi(\sqrt n)\log n+\vartheta(\sqrt n)
 =O(\sqrt n)=o(n).
\]

This treats **all prime powers**, not only radical support.

For the intermediate range

\[
 \sqrt n<p\le n/\log n,
\]
we have `n < p^2` and `n+k < 2n < 2p^2`, so Kummer gives at most two carries per gate. Thus

\[
 \sum_{\sqrt n<p\le n/\log n}
 \bigl(v_p(C_+)+v_p(C_-)\bigr)\log p
 \ll\vartheta(n/\log n)
 =O(n/\log n)=o(n).
\]

Therefore only

\[
 p>n/\log n
\]
matters.  In this range

\[
 t=\lfloor n/p\rfloor<\log n,
\]
and for large `n`, `t+a<p`; in particular the reflected binomial has no second-digit Kummer anomaly.

## 3. The Newton coefficients themselves satisfy Lucas

For `p > n/log n`, hence eventually `p >= 7`, use the Apéry-Lucas congruence

\[
 b_{cp+d}\equiv b_c b_d\pmod p,
 \qquad 0\le c,d<p.
\]

Write `j=ap+s`, `0<=a,s<p`.  Since

\[
 c_j=\sum_{u=0}^j(-1)^{j-u}\binom ju b_u,
\]
Lucas on the binomial coefficient and Apéry-Lucas on `b_u` give

\[
 \begin{aligned}
 c_{ap+s}
 &\equiv
 \sum_{c=0}^a\sum_{d=0}^s
 (-1)^{a-c+s-d}
 \binom ac\binom sd b_c b_d\\
 &=c_a c_s\pmod p.
 \end{aligned}
\]

(The sign factors because `p` is odd.)

So the Newton coefficient sequence has the same two-digit Cartier factorization as the Apéry sequence:

\[
 \boxed{c_{ap+s}\equiv c_a c_s\pmod p.}
\]

This is the key identity for the endpoint gate.

## 4. Exact factorization on the positive endpoint gate

For `p>n/log n`, write

\[
 n=tp+r,\qquad k=ap+h,
 \qquad 0\le r,h<p.
\]

Because `k<n`, the high base-`p` digit causes no obstruction for \(\binom nk\).  Lucas/Kummer gives

\[
 p\mid\binom nk\quad\Longleftrightarrow\quad h>r.
\]

If `h>r`, then `h>=1` and

\[
 H=k-1=ap+(h-1).
\]

Split the Newton sum into full `p`-blocks and its last partial block.  Using both Lucas laws,

\[
 \begin{aligned}
 B_H(n)
 &\equiv
 \sum_{c=0}^{a-1}c_c\binom tc
   \sum_{s=0}^{p-1}c_s\binom rs
 +c_a\binom ta
   \sum_{s=0}^{h-1}c_s\binom rs\\
 &\equiv
 b_r\sum_{c=0}^a c_c\binom tc\\
 &=b_r B_a(t)\pmod p,
 \end{aligned}
\]

because `r <= h-1` on the gate and the inner Newton sum is exactly `b_r`.

Hence

\[
 \boxed{
 h>r\quad\Longrightarrow\quad
 B_H(n)\equiv b_r B_a(t)\pmod p.
 }
\]

Since `r <= H`, if `p | b_r` then automatically `p | L_H`.  Thus every **true** zero prime on this gate survives all three integers.

## 5. Exact factorization on the reflected endpoint gate

Put

\[
 r^*=p-1-r.
\]

As a `p`-adic integer,

\[
 -n-1=(p-1-r)+(p-1-t)p+(p-1)p^2+\cdots.
\]

For `p>n/log n`, `t+a<p`, so Lucas for `p`-adic binomial coefficients gives

\[
 p\mid\binom{-n-1}{k}
 \quad\Longleftrightarrow\quad h>r^*.
\]

Using

\[
 \binom{-n-1}{k}=(-1)^k\binom{n+k}{k},
\]
this is exactly the second binomial gate.

If `h>r*`, then again `H=ap+h-1` and blockwise Lucas gives

\[
 \begin{aligned}
 B_H(-n-1)
 &\equiv
 b_{r^*}
 \sum_{c=0}^a c_c\binom{-t-1}{c}\\
 &=b_{r^*}B_a(-t-1)\pmod p.
 \end{aligned}
\]

Therefore

\[
 \boxed{
 h>r^*\quad\Longrightarrow\quad
 B_H(-n-1)\equiv b_{r^*}B_a(-t-1)\pmod p.
 }
\]

The repository's reflection congruence gives

\[
 b_{r^*}\equiv b_r\pmod p.
\]

Thus the true zero condition is the same on the two branches.

## 6. Every certificate-only ghost has `o(n)` total mass

The preceding factorization leaves possible ghosts

\[
 p\nmid b_r,\quad p\mid B_a(t)
\]

or

\[
 p\nmid b_{r^*},\quad p\mid B_a(-t-1).
\]

The important point is that these evaluated lower-scale Newton integers are never zero.

From the Apéry sum

\[
 b_j=\sum_{\ell=0}^j
 \binom j\ell^2\binom{j+\ell}\ell^2,
\]
for every `ell>=1`,

\[
 \binom j\ell\binom{j+\ell}\ell
 =\binom{j+\ell}{2\ell}\binom{2\ell}\ell
\]

is even because the central binomial coefficient \(\binom{2\ell}\ell\) is even.  Hence

\[
 b_j\equiv1\pmod4
\]
for every `j`.  Therefore

\[
 c_0=1,\qquad 4\mid c_j\quad(j\ge1),
\]
so for every integer `x`

\[
 \boxed{B_a(x)\equiv1\pmod4.}
\]

In particular `B_a(t)` and `B_a(-t-1)` are nonzero.

A crude uniform height bound suffices.  Since

\[
 b_j\le (j+1)64^j,
\]
we have

\[
 |c_j|\le (j+1)128^j.
\]
For `a=O(t+1)`, this gives

\[
 \log|B_a(t)|+\log|B_a(-t-1)|=O(t+1).
\]

For fixed `t`, the possible values of `a=floor(k/p)` lie in a set of size `O_q(t+1)` (in fact only a bounded number occur, but that sharpening is unnecessary).  Every ghost in quotient class `t` therefore divides a nonzero product of logarithmic height

\[
 O_q((t+1)^2).
\]

Since `p>n/log n` implies `0<=t<log n`, the total logarithmic mass of all ghosts is

\[
 O_q\!\left(\sum_{t<\log n}(t+1)^2\right)
 =O_q((\log n)^3)
 =o(n).
\]

This proves that the Newton part itself contributes no remaining obstruction.

## 7. Exact quotient classification of the true part

The cutoff has a bounded exact defect.  Define

\[
 \varepsilon:=mk-n.
\]

From

\[
 H=\left\lfloor\frac{n-q}{m}\right\rfloor,
\]
one gets

\[
 \boxed{1-q\le\varepsilon\le q+1.}
\]

Now use

\[
 n=tp+r,\qquad k=ap+h.
\]
Then

\[
 mk-n=(ma-t)p+(mh-r),
\]
so with

\[
 \sigma:=t-ma
\]
we have the exact identity

\[
 \boxed{r=mh-\sigma p-\varepsilon.}
\]

The two gates are

\[
 h>r
\quad\Longleftrightarrow\quad
 (m-1)h<\sigma p+\varepsilon,
\]

and

\[
 h>r^*
\quad\Longleftrightarrow\quad
 h+r\ge p
\quad\Longleftrightarrow\quad
 (m+1)h\ge(\sigma+1)p+\varepsilon.
\]

There is a very simple exact consequence.

Assume neither gate holds.  Then `h<=r` and `h<=r*`, hence

\[
 2h\le p-1.
\]

Also `h<=r` gives

\[
 (m-1)h=2qh\ge\sigma p+\varepsilon.
\]

If `sigma>=q`, then

\[
 qp+\varepsilon
 \le \sigma p+\varepsilon
 \le 2qh
 \le q(p-1)=qp-q.
\]

Thus `epsilon<=-q`, contradicting `epsilon>=1-q`.  Therefore

\[
 \boxed{\sigma\ge q\Longrightarrow h>r\ \text{or}\ h>r^*.}
\]

By reflection, if `p|b_r`, whichever gate fires carries the same actual zero prime into `S_q(n)`.

This is exactly why the endpoint gate does not isolate `t=q`.

## 8. Relation of `sigma` to the ordinary quotient residue `t mod (2q+1)`

Write

\[
 t=mA+s,\qquad 0\le s<m.
\]

Since

\[
 \frac{k}{p}
 =A+\frac{s+(r+\varepsilon)/p}{m},
\]
for all large main-range primes the equality `a=A` fails only at the two wrap boundaries:

* `s=0` and `r+epsilon<0`, which forces `r=O_q(1)`;
* `s=m-1` and `r+epsilon>=p`, which forces `r*=O_q(1)`.

All primes in the first exceptional set divide one of finitely many integers `n-c`; all primes in the second divide one of finitely many integers `n+c+1`.  Hence their total logarithmic mass is

\[
 O_q(\log n).
\]

Outside these boundary primes,

\[
 \sigma=s=t\bmod m.
\]

Therefore all true zero primes with

\[
 t\bmod(2q+1)\in\{q,q+1,\ldots,2q\}
\]
are passed by at least one gate, up to `O_q(log n)` total boundary mass.

Since the main range has `t<log n`, this is a growing family of approximately

\[
 \frac{q+1}{2q+1}\log n
\]
quotient slices, not a fixed finite family.

## 9. Concrete off-`q` survivor

The failure to isolate `t=q` is not merely formal.

Take `q=1`, so `m=3`.  The Apéry recurrence modulo `41` gives

\[
 b_{10}\equiv0\pmod{41}
\]
(and reflection gives `b_30=0`).

Choose

\[
 n=4\cdot41+10=174.
\]

Then

\[
 H=\left\lfloor\frac{173}{3}\right\rfloor=57,
 \qquad k=58=1\cdot41+17.
\]

Thus

\[
 t=4,\quad r=10,\quad a=1,\quad h=17.
\]

Since `h>r`,

\[
 41\mid\binom{174}{58},
\]
and the exact block factorization gives

\[
 B_{57}(174)\equiv b_{10}B_1(4)\equiv0\pmod{41}.
\]

Also `41|L_57` because `b_10` occurs in the lcm.  Therefore

\[
 41\mid\gcd\!\left(L_{57},B_{57}(174),\binom{174}{58}\right).
\]

This is a genuine **quotient `t=4`** contribution to the `q=1` gate.  It is not a Newton ghost and it lies beyond the finite set `{t=0,1,2}` one might have hoped the two endpoint gates would leave.

The same zero can be placed on further quotient levels separated by `m=3` while the two-digit pattern persists, so the phenomenon is structurally a quotient ladder, not an isolated accident.

## 10. Final theorem and consequence for P3.2

Combining Sections 2--6 gives the promised exact theorem.

### Theorem (three-integer endpoint gate, exact reduction)

For each fixed positive integer `q`, let `m=2q+1`, `H=floor((n-q)/m)`, `k=H+1`, `L_H=lcm(b_0,...,b_H)`, and let `B_H` be the ordinary Newton interpolant of `b_0,...,b_H`.  For each prime `p>n/log n` write

\[
 n=tp+r,\quad k=ap+h,\quad 0\le r,h<p,
\]
and put

\[
 w_q(n,p)=\mathbf1_{h>r}+\mathbf1_{h>p-1-r}.
\]
Then

\[
 \boxed{
 S_q(n)=
 \sum_{\substack{p>n/\log n\\p\mid b_{n\bmod p}}}
 w_q(n,p)\log p
 +O_q\!\left(\frac n{\log n}+(\log n)^3\right).
 }
\]

The error includes all prime-power valuation below `n/log n` and all large-prime certificate ghosts.  Hence

\[
 S_q(n)=o_q(n)
\]
if and only if

\[
 \sum_{\substack{p>n/\log n\\p\mid b_{n\bmod p}}}
 w_q(n,p)\log p=o_q(n).
\]

Furthermore, with `epsilon=(2q+1)(H+1)-n` and `sigma=t-(2q+1)a`,

\[
 \sigma\ge q\Longrightarrow w_q(n,p)\ge1,
\]
and, outside `O_q(log n)` endpoint-boundary mass,

\[
 \sigma=t\bmod(2q+1).
\]

Therefore a necessary consequence of the desired endpoint estimate is

\[
 \sum_{\substack{p>n/\log n,\ p\mid b_{n\bmod p}\\
 t\bmod(2q+1)\in\{q,\ldots,2q\}}}
 \log p=o_q(n).
\]

That is a positive-density masked version of the original top-window radical problem.

## Bottom line

The three-integer endpoint gate is **arithmetically clean but not quotient-selective**.

* `p <= sqrt(n)`: all valuations contribute `O(sqrt(n))`.
* `sqrt(n) < p <= n/log n`: all valuations contribute `O(n/log n)`.
* `p > n/log n`: Lucas factorizes both Newton evaluations exactly.
* All large-prime certificate-only ghosts contribute `O_q((log n)^3)`.
* What remains is exactly a weighted radical of **actual Apéry zeros**.
* The weight passes every quotient class with `sigma>=q`, and modulo bounded endpoint anomalies this means every `t mod (2q+1)` in `{q,...,2q}`.

So there is no reduction here to a fixed finite set of original fixed-`t` radicals.  Closing the displayed endpoint estimate requires a genuinely new estimate for a growing, positive-density set of the same original fixed-quotient zero radicals.  In the present repository state, that is still the occupancy-one obstruction identified in `SUBMIT/3.2/README.md`.
