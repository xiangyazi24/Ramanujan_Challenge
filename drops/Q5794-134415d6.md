## 2. Exact one-shell Kummer lemma

The sigma convention is unambiguous:

```text
Let q >= 5 be prime. Let alpha be 1 or 2 and write

    M = alpha*q+r,
    0 <= r < q.

Set

    c = alpha-1,
    e = c*q+sigma = (alpha-1)*q+sigma,
    0 < sigma < q.

Thus

    alpha=1: e=sigma,
    alpha=2: e=q+sigma.

For M/2 < e <= M, these are the relevant first-cell branches; c is not
an additional free parameter.
```

Lemma 2.1:

```text
The exact termwise Kummer criterion is

    r < sigma < q-r.                                      (2.1)

Under (2.1), whenever binom(M,t) is nonzero modulo q, every noncentral
binomial in

    X = sum_{u=-1}^1 binom(M,M-t+e*u),
    Y = sum_{v=-1}^1 binom(2M-t,M-t+e*v)

is divisible by q. Only the central terms survive, and

    C_M(e) = b_alpha*b_r (mod q).                         (2.2)

In particular

    C_{q+r}(e)  = 5*b_r  (mod q),
    C_{2q+r}(e) = 73*b_r (mod q).
```

Proof and termwise converse:

```text
Lucas gives

    q does not divide binom(M,t)

if and only if

    t = beta*q+a,
    0 <= beta <= alpha,
    0 <= a <= r.

Condition (2.1) implies 2*r < q.

By symmetry, the X packet is

    binom(M,t)+binom(M,t-e)+binom(M,t+e).

For t+e, the low base-q digit is a+sigma. It is less than q and greater
than r. Lucas kills the term.

For t-e, one borrow gives low digit q+a-sigma. It is greater than r
because sigma < q-r. Lucas kills the term whenever the index is in
range.

For the Y packet,

    2M-t = (2*alpha-beta)q+(2r-a),

where 0 <= 2r-a < q. The +e lower index has low digit r-a+sigma, which
is greater than 2r-a because sigma > r. The -e lower index, after one
borrow, has low digit q+r-a-sigma, which is greater than 2r-a because
q-sigma > r. Lucas kills both side terms.

The central contribution is

    sum_t binom(M,t)^2 binom(2M-t,M-t)^2 = b_M.

Lucas separates the beta and a sums, so

    b_M = b_alpha*b_r (mod q).

No cancellation among nonzero side terms is used.

Conversely, if sigma <= r, take t=0. Then binom(M,e) is a q-unit. If
q-sigma <= r, take t=alpha*q. The outer binomial and the side binomial
binom(M,q-sigma) are q-units. Thus (2.1) is necessary and sufficient for
termwise side-packet collapse.

This converse says nothing about cancellation in C_M(e), H, or E.
```

## 6. Forced, target, and accidental divisibility

```text
Coefficient-forced:
    (3.1), (3.4a), and (3.4b) hold. Side packets vanish termwise. The
    result is independent of all u_j(n).

Target candidate:
    q-1 lies in the common prime-node interval, every stencil length is
    less than q, and b_{n-alpha*q}=0 modulo q. This uses distinguished
    Apery/Ore-CRT data, not flatness.

Extra universal cancellation:
    Every coefficient-basis minor E(Y,Z_j) vanishes although a flatness
    inequality fails. This is independent of u_j but is not termwise.

Actual accidental divisibility:
    The actual Z minors vanish outside coefficient-forced and target
    mechanisms. This classification requires the five actual u_j(n).
```

The checker uses the five basis sequences:


Since `E(Y,Z)` is linear in `Z`, vanishing for all five basis sequences proves vanishing for the actual `Z=sum_j u_j(n)Z_j` for arbitrary integer coefficients. def ceil_div(a: int, b: int) -> int:
```python
    assert b > 0
    return -((-a) // b)


def primes_upto(limit: int) -> list[int]:
    if limit < 2:
        return []
    mark = bytearray(b"\x01") * (limit + 1)
    mark[0] = mark[1] = 0
    for p in range(2, isqrt(limit) + 1):
        if mark[p]:
            start = p * p
            count = (limit - start) // p + 1
            mark[start : limit + 1 : p] = b"\x00" * count
    return [p for p in range(2, limit + 1) if mark[p]]


class Lucas:
    def __init__(self, prime: int) -> None:
        self.p = prime
        self.fac = [1] * prime
        for i in range(1, prime):
            self.fac[i] = self.fac[i - 1] * i % prime
        self.ifac = [1] * prime
        self.ifac[-1] = pow(self.fac[-1], prime - 2, prime)
        for i in range(prime - 1, 0, -1):
            self.ifac[i - 1] = self.ifac[i] * i % prime
        self.cache: dict[tuple[int, int], int] = {}

    def small(self, n: int, k: int) -> int:
        if not 0 <= k <= n < self.p:
            return 0
        return self.fac[n] * self.ifac[k] * self.ifac[n - k] % self.p

    def choose(self, n: int, k: int) -> int:
        if k < 0 or k > n:
            return 0
        k = min(k, n - k)
        key = (n, k)
        if key in self.cache:
            return self.cache[key]
        nn, kk, out = n, k, 1
        while nn or kk:
            nd, kd = nn % self.p, kk % self.p
            if kd > nd:
                out = 0
                break
            out = out * self.small(nd, kd) % self.p
            nn //= self.p
            kk //= self.p
        self.cache[key] = out
        return out


class ShellMod:
    def __init__(self, prime: int) -> None:
        self.p = prime
        self.lucas = Lucas(prime)
        self.cache: dict[tuple[int, int], int] = {}

    def shell(self, moment: int, node: int) -> int:
        key = (moment, node)
        if key in self.cache:
            return self.cache[key]
        if not (0 < node <= moment and 2 * node > moment):
            raise ValueError(f"not first-cell: M={moment}, e={node}")
        c = self.lucas.choose
        total = 0
        for t in range(moment + 1):
            outer = c(moment, t)
            if outer == 0:
                continue
            base = moment - t
            x_packet = (
                c(moment, base - node)
                + c(moment, base)
                + c(moment, base + node)
            ) % self.p
            y_packet = (
                c(2 * moment - t, base - node)
                + c(2 * moment - t, base)
                + c(2 * moment - t, base + node)
            ) % self.p
            total = (
                total + outer * x_packet * y_packet * y_packet
            ) % self.p
        self.cache[key] = total
        return total

def apery_mod(index: int, prime: int) -> int:
    if not 0 <= index < prime:
        raise ValueError((index, prime))
    if index == 0:
        return 1
    b0, b1 = 1, 5 % prime
    if index == 1:
        return b1
    for k in range(1, index):
        p_k = (2 * k + 1) * (17 * k * k + 17 * k + 5)

        denominator = pow(k + 1, 3, prime)
        b2 = numerator * pow(denominator, prime - 2, prime) % prime
        b0, b1 = b1, b2
    return b1

def quotient_stable(n: int, q: int, alpha: int) -> bool:
    return alpha * q <= n - 1 and n + 4 < (alpha + 1) * q


def coefficient_forced(n: int, q: int, alpha: int, family: Family) -> bool:
    return (
        quotient_stable(n, q, alpha)
        and q >= n + 5 - family.e_minus
        and 2 * alpha * q >= n + 5 + family.e_plus

def q_bounds(n: int, alpha: int, family: Family) -> tuple[int, int]:
    q_lo = max(
        ceil_div(n + 5, alpha + 1),
        n + 5 - family.e_minus,
        ceil_div(n + 5 + family.e_plus, 2 * alpha),
    )
    return q_lo, (n - 1) // alpha


def carrier(values: dict[int, int], d: int, length: int, lucas: Lucas) -> int:
    q, out = lucas.p, 0
    for i in range(length + 1):
        weight = (
            lucas.choose(d + i, i)
            * lucas.choose(d + length + 1, length - i)
        ) % q
        if i & 1:
            weight = -weight
        out = (out + weight * values[d + i]) % q
    return out


def high_difference(
    values: dict[int, int], d: int, length: int, lucas: Lucas
) -> int:
    q, out = lucas.p, 0
    for i in range(length + 2):
        weight = lucas.choose(length + 1, i)
        if i & 1:
            weight = -weight
        out = (out + weight * values[d + i]) % q
    return out


def primitive_minor_from_parts(
    gy: int,
    hy: int,
    z_values: dict[int, int],
    d: int,
    length: int,
    lucas: Lucas,
) -> int:
    gz = carrier(z_values, d, length, lucas)
    hz = high_difference(z_values, d, length, lucas)
    return (hy * gz - gy * hz) % lucas.p


def poly_eval_mod(coefficients: list[int], n: int, q: int) -> int:
    out = 0
    for coefficient in reversed(coefficients):
        out = (out * n + coefficient) % q
    return out

        for row in data
    ):
        raise ValueError("every coefficient row must contain integers")
    return data


@dataclass
class ExactResult:
    used_shells_equal_flat_residue: bool
    every_basis_minor_zero: bool
    every_actual_minor_zero: Optional[bool]


def exact_family_evaluation(
    n: int,
    q: int,
    alpha: int,
    family: Family,
    oracle: ShellMod,
    u_coefficients: Optional[list[list[int]]],
) -> ExactResult:
    x_lo = min(d for d, _ in family.minors)
    x_hi = max(d + length + 1 for d, length in family.minors)
    xs = range(x_lo, x_hi + 1)

    b_alpha = apery_mod(alpha, q)
    r_y = n - 1 - alpha * q
    expected_y = b_alpha * apery_mod(r_y, q) % q

    flat_equal = True
    y_values: dict[int, int] = {}
    for x in xs:
        value = oracle.shell(n - 1, x)
        y_values[x] = value
        flat_equal &= value == expected_y

    z_basis: list[dict[int, int]] = []
    for j in range(5):
        moment = n + j
        residue = moment - alpha * q
        expected = b_alpha * apery_mod(residue, q) % q
        values: dict[int, int] = {}
        for x in xs:
            left = oracle.shell(moment, x - 1)
            right = oracle.shell(moment, x + 1)
            flat_equal &= left == expected and right == expected
            values[x] = (left + right) % q
        z_basis.append(values)

    u_values: Optional[list[int]] = None
    actual_z: Optional[dict[int, int]] = None
    if u_coefficients is not None:
        u_values = [poly_eval_mod(row, n, q) for row in u_coefficients]
        actual_z = {
            x: sum(u_values[j] * z_basis[j][x] for j in range(5)) % q
            for x in xs
        }

    basis_all_zero = True
    actual_all_zero: Optional[bool] = None if actual_z is None else True

    for d, length in family.minors:
        gy = carrier(y_values, d, length, oracle.lucas)
        hy = high_difference(y_values, d, length, oracle.lucas)
        basis_minors = [
            primitive_minor_from_parts(
                gy, hy, z_basis[j], d, length, oracle.lucas
            )
            for j in range(5)
        ]
        basis_all_zero &= all(value == 0 for value in basis_minors)

        if actual_z is not None and u_values is not None:
            actual_minor = primitive_minor_from_parts(
                gy, hy, actual_z, d, length, oracle.lucas
            )
            multiplication_back = sum(
                u_values[j] * basis_minors[j] for j in range(5)
            ) % q
            assert actual_minor == multiplication_back
            actual_all_zero &= actual_minor == 0

    return ExactResult(flat_equal, basis_all_zero, actual_all_zero)


def target_candidate(n: int, q: int, alpha: int, family: Family) -> bool:
    if not quotient_stable(n, q, alpha):
        return False
    if not family.target_q_lo <= q <= family.target_q_hi:
        return False
    if not all(length < q for _, length in family.minors):
        return False
    return apery_mod(n - alpha * q, q) == 0


def note(record: dict, category: str, item: tuple) -> None:
    record[category] = record.get(category, 0) + 1
    samples = record.setdefault(category + "_samples", [])
    if len(samples) < 20:
        samples.append(item)


def verify_newton_identity() -> None:
    for q in (5, 7, 11, 13):
        lucas = Lucas(q)
        for d in range(2, 9):
            for length in range(0, 6):
                y = {
                    x: (x**3 + 7 * x + 11) % q
                    for x in range(d, d + length + 2)
                }
                z = {
                    x: (3**x + x * x + 5) % q
                    for x in range(d, d + length + 2)
                }
                gy = carrier(y, d, length, lucas)
                gy1 = carrier(y, d + 1, length, lucas)
                hy = high_difference(y, d, length, lucas)
                gz = carrier(z, d, length, lucas)
                gz1 = carrier(z, d + 1, length, lucas)
                hz = high_difference(z, d, length, lucas)
                b = lucas.choose(d + length + 1, length)
                assert (gy - gy1 - b * hy) % q == 0
                assert (gz - gz1 - b * hz) % q == 0
                raw = (gy * gz1 - gy1 * gz) % q
                primitive = (hy * gz - gy * hz) % q
                assert raw == b * primitive % q


def first_prime_at_least(lower: int, primes: list[int]) -> int:
    return next(q for q in primes if q >= lower)


def verify_q5787_table() -> None:
    expected = (
        (236, 151, 48, 13, 223, 223),
        (272, 174, 55, 16, 256, 257),
        (300, 193, 61, 17, 283, 283),
        (311, 200, 63, 18, 293, 293),
        (350, 225, 71, 21, 329, 331),
        (400, 258, 81, 25, 375, 379),
    )
    primes = primes_upto(500)
    for n, d0, l0, k0, p0, first0 in expected:
        d = 13 * n // 20 - 2
        length = n // 5 + 1
        k_raw = (n - d - length - 11) // 2
        endpoint = n - k_raw
        first = first_prime_at_least(endpoint, primes)
        family = rectangle_family("table", "rect3x5", d, length, 0, 2, -2, 2)
        q_lo, _ = q_bounds(n, 1, family)
        assert (d, length, k_raw, endpoint, first) == (
            d0, l0, k0, p0, first0
        )
        assert n - q_lo == k_raw


def verify_full_margin_residues() -> None:
    residue_seven = {3, 4, 6, 9, 12, 18}
    for n in range(50, 401):
        D = 13 * n // 20 - 1
        N = n // 5 + 1
        m_left = D - (n + 4) // 2 - 1
        m_right = n - D - N + 1
        delta = m_right - m_left
        assert delta in {5, 6, 7}
        assert (delta == 7) == (n % 20 in residue_seven)
        assert 2 <= m_left <= m_right
        family = translated_family(D, N, m_left, "translated_full")
        assert first_cell_ok(n, family)

        q_lo_top, _ = q_bounds(n, 1, family)
        assert n - q_lo_top == (1 if delta == 7 else 0)

        q_lo_half, _ = q_bounds(n, 2, family)
        assert n - 2 * q_lo_half < 1


def audit_range(
    n_min: int,
    n_max: int,
    scan_all: bool,
    all_widths: bool,
    u_coefficients: Optional[list[list[int]]],
    quiet: bool,
) -> None:
    primes = primes_upto(n_max)
    stats: dict[tuple[str, int], dict] = {}

    for n in range(n_min, n_max + 1):
        d = 13 * n // 20 - 2
        base_length = n // 5 + 1
        rectangle = rectangle_family(
            f"rect3x5(n={n})", "rect3x5", d, base_length, 0, 2, -2, 2
        )
        assert first_cell_ok(n, rectangle)

        D, N = d + 1, base_length
        m_left = D - (n + 4) // 2 - 1
        m_right = n - D - N + 1
        m_full = min(m_left, m_right)
        if m_full < 2:
            raise AssertionError((n, D, N, m_left, m_right))

        if all_widths:
            translated = [
                translated_family(D, N, m, "translated_width")
                for m in range(2, m_full + 1)
            ]
        else:
            translated = [
                translated_family(D, N, m_full, "translated_full")
            ]
        families = [rectangle] + translated
        assert all(first_cell_ok(n, family) for family in families)

        for alpha in (1, 2):
            for q in primes:
                if q < 5 or q > n or not quotient_stable(n, q, alpha):
                    continue

                work: list[tuple[Family, bool, bool]] = []
                for family in families:
                    predicted = coefficient_forced(n, q, alpha, family)
                    target = target_candidate(n, q, alpha, family)
                    if scan_all or predicted or target:
                        work.append((family, predicted, target))
                if not work:
                    continue

                oracle = ShellMod(q)
                for family, predicted, target in work:
                    result = exact_family_evaluation(
                        n, q, alpha, family, oracle, u_coefficients
                    )
                    record = stats.setdefault((family.kind, alpha), {})
                    note(record, "checked", (n, family.label, q))

                    if predicted:
                        note(record, "predicted", (n, family.label, q))
                        assert result.used_shells_equal_flat_residue, (
                            "predicted shell residue failure",
                            n,
                            q,
                            alpha,
                            family,
                        )
                        assert result.every_basis_minor_zero, (
                            "predicted basis minor failure",
                            n,
                            q,
                            alpha,
                            family,
                        )
                        if result.every_actual_minor_zero is not None:
                            assert result.every_actual_minor_zero

                    if target:
                        note(record, "target", (n, family.label, q))

                    if result.used_shells_equal_flat_residue and not predicted:
                        note(
                            record,
                            "extra_shell_equality",
                            (n, family.label, q, target),
                        )

                    if result.every_basis_minor_zero and not predicted:
                        note(
                            record,
                            "extra_universal_minor",
                            (n, family.label, q, target),
                        )

                    actual = result.every_actual_minor_zero
                    if actual and not predicted:
                        category = (
                            "actual_target_not_flat" if target else "actual_accidental"
                        )
                        note(record, category, (n, family.label, q))

        if not quiet and (n == n_min or n == n_max or n % 25 == 0):
            print("PROGRESS", n)

    print("Q5794_LUCAS_AUDIT=PASS")
    print("N_RANGE", n_min, n_max)
    print("SCAN_ALL_STABLE_PRIMES", scan_all)
    print("ALL_TRANSLATED_WIDTHS", all_widths)
    print("ACTUAL_U_COEFFICIENTS", u_coefficients is not None)
    for key in sorted(stats):
        kind, alpha = key
        record = stats[key]
        print("SUMMARY", kind, "alpha", alpha)
        for category in sorted(record):
            if category.endswith("_samples"):
                continue
            print(" ", category, record[category])
            samples = record.get(category + "_samples", [])
            if category not in {"checked", "predicted"} and samples:
                print("   samples", samples)


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--n-min", type=int, default=50)
    parser.add_argument("--n-max", type=int, default=400)
    parser.add_argument(
        "--scan-all",
        action="store_true",
        help="evaluate every stable prime, including accidental cases",
    )
    parser.add_argument(
        "--all-widths",
        action="store_true",
        help="audit every admissible translated width",
    )
    parser.add_argument(
        "--u-coeffs",
        type=str,
        default=None,
        help="optional JSON coefficient lists for u_0,...,u_4",
    )
    parser.add_argument("--quiet", action="store_true")
    args = parser.parse_args()

    if args.n_min < 50 or args.n_max < args.n_min:
        raise ValueError("require 50 <= n_min <= n_max")

    verify_newton_identity()
    verify_q5787_table()
    verify_full_margin_residues()
    audit_range(
        args.n_min,
        args.n_max,
        args.scan_all,
        args.all_widths,
        load_u_coefficients(args.u_coeffs),
        args.quiet,
    )


if __name__ == "__main__":
    main()
```

The checker makes only the following implications:

```text
predicted flatness
    => every directly evaluated used shell has residue b_alpha*b_r
    => every coefficient-basis primitive minor is zero
    => every actual primitive minor is zero for arbitrary u_j.

Failure of predicted flatness does not imply nondivisibility. The program
reports target candidates and, under --scan-all, extra shell equality and
extra universal minor vanishing. With --u-coeffs it additionally separates
actual target-not-flat and actual accidental divisibility.
```
