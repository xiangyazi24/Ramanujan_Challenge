# 2. PROVED: endpoint-plus-midpoint deletion

For
\[
 d_\ell^{\rm bd}
 =\min\{s_\ell,\ell-1-s_\ell,|\ell-1-2s_\ell|\},
\]

\[

 \#\{\ell\in\mathcal R:d_\ell^{\rm bd}\le U\}

\tag{2.1}
\]

### Proof

The moving determinant equation is
\[
 \ell\mid\delta+Cs_\ell.
\tag{2.2}
\]

### Left endpoint
If \(s_\ell=u\le U\), then
\[
 \ell\mid \delta+Cu.
\tag{2.3}
\]
The integer in (2.3) is nonzero: otherwise \(C\mid\delta\), contradicting (0.1).  Its absolute value is
\[
 \ll_v |\delta|+CU
 \ll_v N^{359/100+\varepsilon}+N^3,
\]
so it has \(O_v(1)\) shell-prime divisors.  Summing over \(u\le U\) gives \(O_v(U)\).

### Right endpoint
If \(\ell-1-s_\ell=u\le U\), then
\[
 s_\ell=\ell-1-u.
\]
Modulo \(\ell\), (2.2) becomes
\[
 \ell\mid\delta-C(1+u).
\tag{2.4}
\]
Again the integer is nonzero by (0.1), and the same size/divisor argument gives \(O_v(U)\).

### Midpoint
Put the signed centered displacement
\[
 j_\ell=\ell-1-2s_\ell.
\tag{2.5}
\]
If \(|j_\ell|\le U\), then
\[
 2s_\ell=\ell-1-j_\ell.
\]
Multiplying (2.2) by two gives
\[
 \ell\mid 2\delta+2Cs_\ell
 =2\delta+C(\ell-1-j_\ell),
\]
so
\[
 \boxed{
 \ell\mid 2\delta-C(1+j_\ell).}
\tag{2.6}
\]
The integer on the right is nonzero: if
\(2\delta=C(1+j_\ell)\), then the odd integer \(C=pq\) divides \(2\delta\), hence divides \(\delta\), contradicting (0.1).  Its size is again \(N^{359/100+\varepsilon}+O_v(N^3)\), so for each \(j\) it has \(O_v(1)\) shell-prime divisors.  Summing over \(|j|\le U\) gives \(O_v(U)\).
