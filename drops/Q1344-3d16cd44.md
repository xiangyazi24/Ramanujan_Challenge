# General q-block recursion of the triangular Padé lattice

## Verdict

The correct recursion is not a tensor product recursion.  The base-p split has two independent carry mechanisms:

1. the carry in `s+k` versus `2k`;
2. the carry in the doubled digit `2t` inside `2k`.

The resulting block matrix contains ordinary Lucas blocks plus exceptional carry blocks.  Repeated blocks therefore do not automatically force universal numerator content; they introduce lower-height local constraints and, in particular, denominator-side purifier freedoms.

## 1. Exact block entries

Write

```text
s = qp+r,
k = up+t,
0 <= r,t < p.
```

Then

```text
U[s,k] = binom(qp+r+up+t, 2up+2t).
```

Let

```text
epsilon = floor((r+t)/p),
delta = floor(2t/p).
```

The numerator digit sum is

```text
s+k = (q+u+epsilon)p + (r+t-p epsilon),
```

and

```text
2k = (2u+delta)p + (2t-p delta).
```

Lucas gives the exact block entry

```text
U[qp+r,up+t]
 = binom(q+u+epsilon,2u+delta)
   binom(r+t-p epsilon,2t-p delta)        (mod p).
```

This is the required block formula.  The off-diagonal effects are exactly the cases

```text
r+t >= p
```

and

```text
2t >= p.
```

They cannot be omitted.

## 2. Recursive kernel projection

Let the full matrix be split into row blocks indexed by `q` and column blocks indexed by `u`:

```text
C_H = [C_{q,u}]_{0<=q<=m,0<=u<=m}
```

with each block having entries above.

For a vector of numerator/denominator coefficients split as

```text
x=(x_0,...,x_m), y=(y_0,...,y_m),
```

row block `q` imposes

```text
sum_u C^P_{q,u} x_u - D sum_u C^Q_{q,u} y_u = 0.
```

The top block recursion is obtained by eliminating the highest column block.  Define

```text
K_H = ker(C_H),
P_H = projection to numerator coordinates.
```

Then

```text
P_H
 = {x : exists y_0,...,y_m satisfying all block equations}.
```

After separating the last block:

```text
C_{m,m} z_m + R_m z_{<m}=0,
```

there are two cases.

### Case A: invertible last denominator block

The last denominator variables are uniquely determined and the recursion reduces to

```text
P_H = P_{(m-1)p+d}(Schur(C_{m,m})).
```

### Case B: singular last block

Let

```text
F_m = ker(C_{m,m}).
```

Then all vectors in `F_m` are free zero-row freedoms.  The projection gains

```text
pi_P(F_m)
```

unless killed by earlier row blocks.

Thus the exact dimension recursion is

```text
dim P_H
 = dim P_reduced
 + dim(pi_P(F_m intersect previous constraints)).
```

The second term is the missing zero-row freedom in a pure tensor-product treatment.

## 3. Repeated blocks: content or purifier?

Repeated base-p blocks do not by themselves imply universal numerator divisibility.

They do one of two things:

```text
rank-preserving repetition -> transports lower-height constraints;
rank-deficient repetition  -> creates purifier columns/free variables.
```

A universal numerator-content theorem would require proving that every repeated-block null direction has zero numerator projection.  The block formula does not imply this.

Therefore a persistent wrap obstruction is possible precisely when the carry blocks repeatedly eliminate numerator projection; otherwise the new blocks may restore numerator freedom.

## 4. Effect of consecutive height shifts

Replacing

```text
H=mp+d
```

by

```text
H+1=mp+(d+1)
```

changes only the partial final block until `d=p-1`.

The changes are:

1. one additional row in the terminal block;
2. one additional column condition in the folded Padé lattice;
3. possible changes in the carry boundary `r+t=p-1`;
4. changes in the terminal Schur complement.

When `d=p-1`, the next shift changes the quotient block:

```text
mp+(p-1) -> (m+1)p+0.
```

At this point a new full block appears and the recursion restarts with a different terminal block.

Hence consecutive heights are not independent samples; they are adjacent modifications of the same recursive elimination tree.

## 5. Minimal verifier

A direct verifier should compute the block formula and compare it against the original binomial matrix.

```python
from math import comb


def block(p,q,r,u,t):
    e=(r+t)//p
    d=(2*t)//p
    return comb(q+u+e,2*u+d)*comb(r+t-p*e,2*t-p*d)%p


def direct(p,s,k):
    return comb(s+k,2*k)%p

for p in [7,11]:
    for m in [2,3]:
        H=m*p+3
        ok=True
        for s in range(H+1):
            for k in range(H+1):
                q,r=divmod(s,p)
                u,t=divmod(k,p)
                if block(p,q,r,u,t)!=direct(p,s,k):
                    ok=False
        print(p,m,ok)
```

The verifier tests the `m=2,3` block laws directly.  It is not a proof of kernel projection claims; those require rank computations over the assembled block matrix.

## Final consequence

The exact q-block theorem is:

```text
Projection recursion = lower-height recursion + terminal carry-block nullspace.
```

Any proof of a multi-height separation lemma must control the terminal carry-block projection at every quotient level.  Conversely, any persistent wrap obstruction must exhibit a chain of terminal blocks whose numerator projections vanish.  Repeated blocks alone are insufficient evidence for either conclusion.
