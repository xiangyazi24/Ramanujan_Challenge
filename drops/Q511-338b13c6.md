# Trilinear Weyl sums for Apéry zeros: the right proof route

## Verdict

The most promising route is **not** to prove square-root cancellation for each individual Fourier transform \(\widetilde Z_p(\alpha)\). Since \(|Z_p|=O(1)\), the local transforms are already bounded. The missing cancellation is entirely in the **prime-triple summation**.

The correct target is a prime-aspect equidistribution theorem for the family
\[
\alpha_p(h;q,r)=h(qr)^{-1}\pmod p.
\]

The hierarchy of approaches is:

1. **Second moment / dispersion in \(h\)**: most promising.
2. **Factorization after opening one prime variable**: plausible and compatible with large sieve.
3. **Katz trace-function machinery**: useful only after identifying a genuine algebraic trace structure.
4. **Palindromic symmetry**: helps constants/phases but is unlikely to solve the cancellation alone.

---

## (A) Katz-style bounds on \(\widetilde Z_p(\alpha)\)

A direct Katz estimate is unlikely to be the main step.

We have
\[
\widetilde Z_p(\alpha)=\sum_{a\in Z_p}e_p(\alpha a).
\]
Because \(|Z_p|\ll1\), trivially
\[
|\widetilde Z_p(\alpha)|\le |Z_p|\ll1.
\]

A Katz bound would normally improve a sum of length \(p\), for example
\[
\sum_x e_p(f(x))\ll p^{1/2}.
\]
Here the support itself has size \(O(1)\). There is no local square-root phenomenon left to exploit.

The hard object is instead
\[
\sum_{p<q<r} f_p(q,r)f_q(p,r)f_r(p,q),
\]
where the arguments of the Fourier transforms are coupled by inverses modulo the other primes.

Therefore the needed input is a **cross-prime independence theorem**, not a single-prime exponential sum theorem.

---

## (B) Factorization / decoupling

This is the most natural analytic route.

Write
\[
W(h)=\sum_{p<q<r}A_p(q,r)A_q(p,r)A_r(p,q).
\]

The obstacle is that the variables are coupled. However, the dependence is structured: each prime appears only through two modular inverse factors.

A possible route is:

1. Freeze two primes, say \(q,r\).
2. Study
\[
\sum_p \widetilde Z_p(h(qr)^{-1})\cdot G_{q,r}(p).
\]
3. Apply a prime large sieve / bilinear form estimate.

The required statement would look like
\[
\sum_{p\sim X}\widetilde Z_p(a_p) e(\phi_p)
=o(\pi(X))
\]
for structured phases \(a_p\) generated by modular inverses.

This is much closer to a large-sieve problem than to a classical Weyl sum.

---

## (C) Variance argument: the strongest candidate

Yes. A variance argument is probably the shortest path.

Define
\[
W(h)=\sum_{p<q<r}T_{pqr}(h).
\]

Compute
\[
\sum_{h\bmod H}|W(h)|^2.
\]
Expanding gives
\[
\sum_{p,q,r}\sum_{p',q',r'}
\sum_h T_{pqr}(h)\overline{T_{p'q'r'}(h)}.
\]

The inner \(h\)-sum produces orthogonality. For generic distinct triples one expects cancellation unless
\[
(p,q,r)=(p',q',r').
\]

The diagonal contribution is
\[
\sum_{p<q<r}|T_{pqr}|^2.
\]
Since each local Fourier factor is \(O(1)\), this is
\[
O(N_{\rm triples}).
\]

Therefore the desired estimate is exactly
\[
\mathbb E_h|W(h)|^2\ll N_{\rm triples}.
\]

This matches the computation:
\[
|W(h)|\approx \sqrt{N_{\rm triples}}.
\]

However, this only gives "most \(h\)". To obtain **every fixed h**, one needs a uniform version where the exceptional set does not contain small fixed frequencies.

A practical strategy:

- Prove the second moment over all \(h\).
- Prove a separate low-frequency bound for fixed \(h=1,2,\dots,H_0\).
- Since Weyl only needs finitely many fixed \(h\) at each stage, this may suffice.

---

## (D) Palindromic symmetry

The symmetry
\[
b_{p-1-r}\equiv b_r\pmod p
\]
means
\[
Z_p=-1-Z_p
\]
inside \(\mathbb F_p\).

Hence
\[
\widetilde Z_p(\alpha)
=e_p(-\alpha)\widetilde Z_p(-\alpha).
\]

Equivalently,
\[
e_p(\alpha/2)\widetilde Z_p(\alpha)
\]
has a real phase normalization.

This is useful because it removes arbitrary phases. It may allow one to replace complex correlations by real correlations:
\[
\widetilde Z_p(\alpha)\overline{\widetilde Z_p(\beta)}
\]
has additional symmetry.

But symmetry alone does not create cancellation between different primes. A completely symmetric set can still have large Fourier coefficients.

So palindrome is a supporting lemma, not the main engine.

---

# Recommended proof architecture

The most promising route is:

## Step 1: Prove a second-moment dispersion theorem

Show
\[
\sum_h |W(h)|^2\ll N_{\rm triples}X^{o(1)}.
\]

The proof should use:

- orthogonality in \(h\);
- the already proved Fourier non-concentration of \(Z_p\);
- pair/triple prime separation.

## Step 2: Upgrade fixed \(h\)

For each fixed nonzero \(h\), prove
\[
W(h)=o(N_{\rm triples})
\]
using either:

- the dispersion bound plus a finite exceptional-frequency elimination;
- or a direct large sieve estimate.

## Step 3: Close \((HM)_3\)

Then Weyl gives
\[
F_3(X)=X^2\lambda_X^3(1+o(1)).
\]

---

# Final assessment

| Route | Assessment |
|---|---|
| Katz on individual \(\widetilde Z_p\) | unlikely; local sums are already short |
| Prime-variable factorization | promising, likely needed |
| Variance / dispersion | **most promising** |
| Palindrome | useful normalization only |

The numerical observation \(|W(h)|\sim\sqrt{N_{\rm triples}}\) is exactly what the second-moment method predicts. The key theorem to prove is therefore not a local Fourier bound, but a **prime-triple large sieve for the Apéry zero process**.
