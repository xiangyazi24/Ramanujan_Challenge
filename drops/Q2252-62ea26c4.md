# 6. The single fraction-free marked determinant

After deleting `L_p`, deflate **all common factors supported on the explicit pole polynomial** by monic polynomial gcd/division. This is polynomial saturation, not division by any `b_j`. Denote the resulting reduced centered pair by

```text
F(Z), G(Z).                                             (6.1)
```

There are now no pole common roots. The central root is excluded by `Sq`.

To keep matrices of degree `<deg F` without coefficient fractions, replace `H` and `Sq` by fraction-free pseudo-remainders modulo the actual reduction of `F` in `F_p[Z]`:

```text
Hbar  = prem_F(H),
Sqbar = prem_F(Sq).                                    (6.2)
```

At every root `alpha` of `F`, pseudo-remainder multiplication changes the value only by a nonzero power of the actual leading coefficient of `F`. Hence

```text
Hbar(alpha)=0  <=> H(alpha)=0,
Sqbar(alpha)=0 <=> Sq(alpha)=0.                        (6.3)
```

Now set

```text
A0 = B(F,G),
AH = B(F,Hbar),
AS = B(F,Sqbar).                                       (6.4)
```

By linearity of the Bezoutian in its second argument,

```text
boxed:
D(U,V)
 := det(A0 + U AH + V AS)
  = det B(F,G+U Hbar+V Sqbar).                         (6.5)
```

This is the promised single determinant.

## 6.1 Root-product proof of the exact criterion

Pass only for the proof to a splitting field and write the roots of `F`, with multiplicity, as `alpha_i`. The standard resultant/Bezout product formula gives, up to one nonzero convention scalar,

```text
D(U,V)
 = c_F * product_i
   [ G(alpha_i)
     + U Hbar(alpha_i)
     + V Sqbar(alpha_i) ].                             (6.6)
```

This is an identity of polynomials in the indeterminates `U,V`.

If some `alpha` satisfies

```text
F(alpha)=G(alpha)=Hbar(alpha)=Sqbar(alpha)=0,
```

the corresponding factor in (6.6) is identically zero, so `D(U,V)` is the zero polynomial.

Conversely, if no such root exists, every factor in (6.6) is a nonzero affine linear polynomial in `U,V`; their product is nonzero in the integral domain `Fbar_p[U,V]`. Therefore

```text
boxed:
D(U,V) == 0 as a polynomial

<=> exists alpha:
    F(alpha)=G(alpha)=H(alpha)=Sq(alpha)=0.             (6.7)
```

By §§3-5, the right side is exactly the existence of an additional stable physical nonmate common root with the canonical `b_r=0` condition.

This proves the requested **reduction without root enumeration**.

This is exactly what the theory above predicts. The saturated Bezout kernel plus the quadratic cover is **not enough**; the canonical target polynomial `H` is indispensable.

Again, (10.9) is not a counterexample to the desired marked exclusion, because it fails the canonical `b_r=0` condition.

# 11. Pochhammer/lcm bookkeeping

Nothing in the reduction hides a forbidden division.

1. `S_h,R_(h-1)` remain the caller's primitive Pochhammer-cleared polynomials.
2. `Q_L` and the additional explicit pole deflator are monic polynomial products. No `b_j` is divided.
3. The `E`-congruence factor is made only of fixed node gaps. For `p>2h-1` it is a `p`-unit by (1.9).
4. The canonical target clearer is

```text
4^(p-1)(M!)^4,
```

which is a `p`-unit.
5. The transfer proof retains

```text
A_h(r)=product_(j=2..h)(r+j)^3
```

and the Cassini edge product explicitly. They are called units only after imposing the separate physical nonwrapping inequalities.
6. `Hbar,Sqbar` may be formed by pseudo-remainder, multiplying by powers of the **actual nonzero leading coefficient modulo p** rather than introducing rational denominators.
7. No new `Lambda` denominator is introduced here. The `Lambda^2` issue belongs to the Frobenius curvature normalization; the canonical polynomial (2.2) is integral from the start.

# 12. Symbolic checker

The following SageMath script is designed to check the exact identities, not to serve as proof by scanning. It verifies:

- centered `S_h` and Mellin `R_n` construction;
- the exact Bezout deflation identity `(1.4)`;
- the integer Newton target identity `(2.4)`;
- the `h=3,p=433` fixture;
- the generic perturbed-Bezout identity `(6.5)` on supplied polynomials.

```python
# SageMath
from sage.all import *

# ---------- Apéry recurrence / Frobenius jet ----------

def PP(t):
    return 34*t^3 + 51*t^2 + 27*t + 5


def apery_bg(N):
    # returns b_0..b_N and g_0..g_N, N >= 1
    b = [ZZ(1), ZZ(5)]
    for k in range(1, N):
        num = PP(k)*b[k] - k^3*b[k-1]
        den = (k+1)^3
        assert num % den == 0
        b.append(num // den)

    g = [QQ(0), QQ(12)]
    for k in range(1, N):
        phi = ((102*k^2 + 102*k + 27)*b[k]
               - 3*(k+1)^2*b[k+1]
               - 3*k^2*b[k-1])
        g.append((PP(k)*g[k] - k^3*g[k-1] + phi)/(k+1)^3)
    return b, g


QB.<beta> = PolynomialRing(QQ)
QX.<x> = PolynomialRing(QQ)
QZ.<Z> = PolynomialRing(QQ)
KB = QB.fraction_field()


def primitive_Z(q):
    q = QZ(q)
    den = lcm([c.denominator() for c in q.list()] or [1])
    a = [ZZ(den*c) for c in q.list()]
    c = gcd([abs(t) for t in a if t] or [1])
    a = [t//c for t in a]
    out = ZZ['Z'](a)
    if out.leading_coefficient() < 0:
        out = -out
    return out


def center_poly(f, n):
    # beta = x-n/2, so Z=x^2-n^2/4
    px = sum(QQ(f[i])*(x-QQ(n)/2)^i for i in range(f.degree()+1))
    assert all(px[i] == 0 for i in range(1, px.degree()+1, 2))
    return QZ(sum(px[2*j]*(Z+QQ(n*n)/4)^j
                  for j in range(px.degree()//2 + 1)))


def centered_S(h):
    n = h-1
    prev, cur = QB(0), QB(1)       # N_0, N_1
    for m in range(1, h):
        t = beta + m - 1            # r+m, since beta=r+1
        prev, cur = cur, PP(t)*cur - t^6*prev
    if h % 2 == 0:
        kappa = 2*beta+n
        cur, rem = cur.quo_rem(kappa)
        assert rem == 0
    return primitive_Z(center_poly(cur, n))


def centered_R(h):
    n = h-1
    b, g = apery_bg(n)
    B = KB(beta)

    Pcal = -2*sum(
        (4*j + 2*B + 1)*b[j]*b[n-j]
        / ((2*j+1)^2 * (B+j)^2)
        for j in range(n+1)
    )

    Wcal = 2*sum(
        (n-2*i)*(b[i]*g[n-i]-g[i]*b[n-i])
        / ((2*i+1)*(B+i)*(2*(n-i)+1)*(B+n-i))
        for i in range(n+1)
    )

    O = 2*Pcal/(2*(B+n)+1) - Wcal
    clear = prod(B+j for j in range(n+1))^2
    rr = KB(clear*O)
    # Pochhammer clearing leaves only a rational scalar denominator.
    assert QB(rr.denominator()).degree() == 0
    f = QB(rr.numerator())
    return primitive_Z(center_poly(f, n))


# ---------- Bezout matrix / common-factor identity ----------

def bezout_matrix(f, g, d=None):
    K = f.base_ring()
    if d is None:
        d = max(f.degree(), g.degree())
    Rxy.<X,Y> = PolynomialRing(K, 2)
    fx = sum(K(f[i])*X^i for i in range(f.degree()+1))
    fy = sum(K(f[i])*Y^i for i in range(f.degree()+1))
    gx = sum(K(g[i])*X^i for i in range(g.degree()+1))
    gy = sum(K(g[i])*Y^i for i in range(g.degree()+1))
    num = fx*gy-gx*fy
    q, rem = num.quo_rem(X-Y)
    assert rem == 0
    return matrix(K, d, d,
        lambda i,j: q.monomial_coefficient(X^i*Y^j))


def convolution_matrix(Q, dred):
    K = Q.base_ring()
    d = dred + Q.degree()
    C = matrix(K, d, dred, 0)
    for j in range(dred):
        for k in range(Q.degree()+1):
            C[j+k,j] = Q[k]
    return C


def check_bezout_deflation(F, G, Q):
    S, R = Q*F, Q*G
    C = convolution_matrix(Q, F.degree())
    lhs = bezout_matrix(S,R,S.degree())
    rhs = C*bezout_matrix(F,G,F.degree())*C.transpose()
    assert lhs == rhs


# ---------- canonical Newton-Racah target ----------

ZT.<T> = PolynomialRing(ZZ)

def target_A(p):
    M = (p-1)//2
    FM = factorial(M)
    psi = ZT(1)
    A = ZT(0)
    for k in range(M+1):
        if k > 0:
            a = k-1
            psi *= T-a*(a+1)
        A += (FM//factorial(k))^4 * psi^2
    return A


def apery_mod(p, N):
    F = GF(p)
    b0, b1 = F(1), F(5)
    if N == 0: return b0
    if N == 1: return b1
    for k in range(1,N):
        b2 = (F(PP(k))*b1-F(k)^3*b0)/F(k+1)^3
        b0,b1 = b1,b2
    return b1


def check_target_eval(p, js):
    F = GF(p)
    M = (p-1)//2
    A = target_A(p)
    u = F(factorial(M))^4
    for j in js:
        assert F(A(j*(j+1))) == u*apery_mod(p,j)
```

# 13. What would finish the all-`h` theorem

The exact remaining statement can now be written without roots:

```text
For every h>=2 and every stable p>2h-1,
after the explicit lower-pole/common-pole deflation,

Theta_(p,h,L)(U,V) != 0 in F_p[U,V],                  (13.1)
```

or equivalently in the one-parameter compression,

```text
theta_(p,h,L) != 0.                                    (13.2)
```

A successful proof must use the fact that `H_(p,h)` is the **canonical** Newton-Racah/Apéry target, not merely a local solution of the same Jacobi recurrence. The natural next identities to seek are therefore either

```text
(1) a mixed subresultant/compound recurrence in h for theta,
```

or

```text
(2) an exact global transfer identity from the initial state (1,5)
    to the complementary Bezout nullvector, whose boundary term is theta.
```

Ordinary Cassini controls the local kernel and proves its corank-one behavior, but §9 shows why it cannot by itself supply (13.2).

This is also consistent with the earlier prime-local Bézout target

```text
gcd(b_r,b_s,D_(s-r)) | (r+s+1) Lambda_(s+1)^2:
```

both problems require one exact identity tying a gap/auxiliary kernel to the **distinguished Apéry state**. The determinant above isolates that missing coordinate fraction-free; it does not pretend that finite resultant data prove its nonvanishing.

# Bottom line

The requested all-`h` exclusion is **not proved** in the current audit, but it has been reduced to one exact, fraction-free marked compound:

```text
D_(p,h,L)(U,V)
 = det( complementary Bezout block
        + U * canonical-target block
        + V * square-lift block ).
```

Its zero-polynomial condition is **equivalent**, not merely necessary, to the existence of a stable physical nonmate common root satisfying canonical `b_r=0`. The first nonzero homogeneous piece `Theta`, or the scalar `theta` after the subresultant compression `J=gcd(H,Sq)`, is the smallest surviving invariant.

The exact local Dirichlet construction proves that transfer/Cassini without this canonical coordinate can never close the theorem. The `h=3,p=433` fixture exhibits the obstruction concretely: saturation plus square lift occurs, but the canonical Apéry coordinate is nonzero.
