and the canonical companion satisfies, for `n>=2`,
\[
n^3\kappa_n-P(n-1)\kappa_{n-1}+(n-1)^3\kappa_{n-2}=-5g_n,
\tag{1.2}
\]
with
\[
\kappa_0=0,\qquad\kappa_1=-36.
\]
Here
\[
F(t)=\sum_{n\ge0}b_nt^n,
\qquad
\Delta(t)=1-34t+t^2,

\[
\boxed{
G(t):=\frac1{F(t)^2\sqrt{\Delta(t)}}

\tag{1.3}
\]
The integral transverse Casoratian is
\[
\boxed{
\Xi_n
=n^3(b_{n-1}\kappa_n-b_n\kappa_{n-1})
=-1-5\sum_{m=1}^n g_mb_{m-1}\in\mathbf Z.
}
\tag{1.4}
\]
For `p>n`, every prime in the reduced denominator of `\kappa_n` is a `p`-unit. If also `p|b_n`, no-two-consecutive-zeros gives `p\nmid b_{n-1}`. Hence
\[
\Xi_n\equiv n^3b_{n-1}\kappa_n\pmod p,
\]
and therefore
\[
\boxed{
 p>n,\ p\mid b_n:\qquad
 p\mid\Xi_n\iff\kappa_n\equiv0\pmod p.
}
\tag{1.5}
\]

Now take `p>2R` and `R<r<s<=2R`. Then
\[
p>s>r.
\tag{1.6}
\]
Every division used below is justified as follows.

- `r,r+1,...,s` are nonzero modulo `p`, so every cube or sixth power of one of these integers is a unit.

No division by `g_m`, by `\Xi_m`, or by an unproved resultant is used.

# 2. Ordinary return plus a new terminal-source lemma

Let
\[
h=s-r\ge2.
\]
Define the ordinary Apéry continuants
\[
N_1(X)=1,\qquad N_2(X)=P(X+1),
\]
\[
\boxed{
N_{j+1}(X)
=P(X+j)N_j(X)-(X+j)^6N_{j-1}(X).
}
\tag{2.1}
\]
If `b_r=0`, forward iteration of (1.1) gives
\[
\boxed{
 b_{r+j}\equiv
 \frac{N_j(r)}{D_j(r)}b_{r+1}\pmod p,
 \qquad1\le j\le h.
}
\tag{2.2}
\]
Every denominator is a unit by §1. Since `b_{r+1}` is a unit, a second Hasse zero at `s=r+h` forces
\[
\boxed{N_h(r)=0\pmod p.}
\tag{2.3}
\]

## Lemma 2.1 — the penultimate continuant is automatically a unit

Assume `(2.3)`. Then
\[
\boxed{N_{h-1}(r)\ne0\pmod p.}
\tag{2.4}
\]

**Proof.** Suppose `N_h(r)=N_{h-1}(r)=0`. Apply (2.1) at the last step:
\[
0=N_h(r)
=P(r+h-1)N_{h-1}(r)-(r+h-1)^6N_{h-2}(r).
\]
Because
\[
r+h-1=s-1<p,
\]
the coefficient `(r+h-1)^6` is a unit, so `N_{h-2}(r)=0`. Iterating backward forces
\[
N_{h-3}(r)=\cdots=N_1(r)=0,
\]
contradicting `N_1=1`. ∎

This elementary lemma is useful because it shows that a homogeneous return leaves the marked endpoint **transverse rather than singular** in the last source coordinate.

# 3. Marked Duhamel return is a one-dimensional shooting condition

The already-banked marked continuant is
\[
\boxed{
M_h(r)=
\sum_{j=1}^{h-1}
 g_{r+j+1}N_j(r)
 \prod_{q=j+1}^{h-1}(r+q)^3.
}
\tag{3.1}
\]
If `r` and `s=r+h` are both transverse-common, then
\[
p\mid N_h(r),\qquad p\mid M_h(r).
\tag{3.2}
\]
The coefficient of the *last* source value `g_s=g_{r+h}` in (3.1) is exactly
\[
N_{h-1}(r),
\]
which is a unit by Lemma 2.1. Therefore, once the ordinary return `N_h(r)=0` is imposed, the marked return has the unique endpoint solution
\[
\boxed{
 g_s\equiv
 -N_{h-1}(r)^{-1}
 \sum_{j=1}^{h-2}
 g_{r+j+1}N_j(r)
 \prod_{q=j+1}^{h-1}(r+q)^3
 \pmod p.
}
\tag{3.3}
\]
This is the continuant form of the shooting law.

There is an even cleaner Green form. From (1.4),
\[
\boxed{
\Xi_s-\Xi_r
=-5\sum_{m=r+1}^{s}g_mb_{m-1}.
}
\tag{3.4}
\]
If `b_s=0`, then `b_{s-1}` is a unit. Thus, conditional on `\Xi_r=0`, the second common condition `\Xi_s=0` is equivalent to
\[
\boxed{
 g_s\equiv
 -b_{s-1}^{-1}
 \sum_{m=r+1}^{s-1}b_{m-1}g_m
 \pmod p.
}
\tag{3.5}
\]
Equations `(3.3)` and `(3.5)` are the same condition: using (2.2), `b_{s-1}/b_{r+1}` differs from `N_{h-1}(r)` only by the proved unit `D_{h-1}(r)`.

### Interpretation

A two-common-index theorem is therefore not asking for a second mysterious rank drop. After the first common row is fixed, every later Hasse return presents the canonical source with **one forbidden residue** at its terminal coefficient. Uniqueness is exactly an endpoint-avoidance theorem for the fixed source `g`.

That is stronger information than the bare pair `(N_h,M_h)=0`, because it isolates the sole coordinate at which the actual Eisenstein arithmetic must enter.

# 4. Formal source freedom: a theorem-level no-go

The shooting law also proves that formal recurrence methods cannot establish `(U)`.

## Theorem 4.1 — triangular source controllability

Fix a prime `p>=7`. Let
\[
2\le r_1<r_2<\cdots<r_k<p
\]
be Hasse zeros of the fixed Apéry solution:
\[
b_{r_i}=0\pmod p.
\]
Start from any source sequence `s_n` and the inhomogeneous solution
\[
x_0=0,\quad x_1=-36,
\]
\[
n^3x_n-P(n-1)x_{n-1}+(n-1)^3x_{n-2}=-5s_n.
\tag{4.1}
\]
Then there are perturbations supported only at the selected rows,
\[
s'_n=s_n+\sum_{i=1}^k\delta_i\mathbf1_{n=r_i},
\]
such that the new solution satisfies
\[
\boxed{x'_{r_1}=\cdots=x'_{r_k}=0\pmod p.}
\tag{4.2}
\]

**Proof.** Order the rows increasingly. A perturbation `\delta` at row `r` changes the value at that same row by
\[
\Delta x_r=-\frac5{r^3}\delta,
\tag{4.3}
\]
while perturbations at later rows cannot affect earlier values. Thus the map
\[
(\delta_1,\ldots,\delta_k)
\longmapsto
(x_{r_1},\ldots,x_{r_k})
\]
is triangular with diagonal entries `-5/r_i^3`. Each is a unit because `p>r_i` and `p\ne5`. Solve successively:
\[
\delta_i=\frac{r_i^3}{5}\,x^{(i-1)}_{r_i}.
\tag{4.4}
\]
This sets the current target to zero and does not disturb the earlier targets. ∎

Because the homogeneous orbit `b`, the transfer coefficients `P(n)`, and the initial line are untouched, Theorem 4.1 is a precise obstruction to all arguments that depend only on:

- the three-term transfer matrix;
- projective dynamics of the homogeneous Apéry orbit;
- `p`-unit denominator bookkeeping;
- the formal discrete Green/Wronskian identity;
- formal adjointness or Ore syzygies;
- real total positivity/Sturm sign structure of the transfer coefficients, without using the exact arithmetic source.

All those features survive the perturbation.

# 7. Why projective dynamics, Sturm theory, and total positivity stop here

## 7.1 Projective dynamics

The homogeneous state
\[
(b_{n-1},b_n)
\]
propagates by an invertible `2x2` transfer matrix for `n<p`. But the companion state is affine because of `g_n`. At a common row the pair `(b_n,\kappa_n)` is actually `(0,0)`, so its projective class is undefined. One can augment by a source coordinate, but Theorem 4.1 shows that the augmented affine system is controllable in exactly the target direction unless the source is constrained by (1.3)/(6.6).

Thus projective dynamics can organize the problem; it cannot prove uniqueness without an arithmetic theorem on the forcing orbit.

## 7.2 Discrete Sturm / total positivity

Over the reals, positivity and sign-regularity of Apéry-related transfer matrices give strong nonvanishing information. Modulo `p`, there is no order relation to transport. More decisively, the source-flexibility theorem constructs a mod-`p` inhomogeneous solution with the same homogeneous transfer and two prescribed common zeros. Any argument whose hypotheses are unchanged by that source perturbation cannot distinguish it from the canonical case.

A sign determinant could still yield a divisibility certificate, but to exclude `p` by Archimedean size one would need the determinant to have absolute value `<p`. Natural Apéry/Green determinants in the dyadic range have exponential height, while the allowed prime can be as small as `2R+1`; no such inequality is available.

# 8. Wronskians, pair determinants, resultants, and the best repeated-prime Fitting carrier

## 8.1 Two-endpoint determinant

For
\[
D_{m,n}=b_m\kappa_n-b_n\kappa_m,
\]
minimal shared-denominator clearing is `p`-unit when `p>\max(m,n)`. If both endpoints are common, the cleared determinant is divisible by `p^2`, not merely `p`, because each term contains one factor from the `b` coordinate and one from the `\kappa` coordinate.

This retains the distinguished companion line and is a valid local certificate. The problem is global coverage. If a repeated prime occurs at exactly two unknown rows, an edge family guaranteed to contain that pair must be the complete graph. Q7669's CM analysis gives logarithmic height `O(R)` for each normalized pair determinant in a dyadic block. Multiplying over `Theta(R^2)` possible edges therefore has raw logarithmic height `O(R^3)`, far above the target.

A sparse graph cannot solve the exact two-row problem: an adversarial two-element subset can be a non-edge.

## 8.2 Optimal PID/Fitting compression of repeated support

\qquad(R<r\le2R).
\tag{8.1}

\[
e_{p,r}=v_p(c_r),\qquad E_p=\sum_r e_{p,r}.

\mathcal M_R=\bigoplus_{R<r\le2R}S_R/(c_r),

where `S_R=Z[(\prod_{q<=2R}q)^{-1}]`.

\boxed{

=\frac{\prod_{R<r\le2R}c_r}
       {\operatorname{lcm}_{R<r\le2R}c_r}.

\tag{8.2}

Indeed,
\[
\boxed{
 v_p(D_R^{\mathrm{rep}})
 =E_p-\max_r e_{p,r}.
}
\tag{8.3}
\]
Therefore
\[
p\mid D_R^{\mathrm{rep}}
\iff
p\text{ occurs at at least two rows.}
\tag{8.4}
\]
This is the exact prime-independent carrier for repeated support/excess; it is strictly more efficient than multiplying all pairwise gcds.

But the available height is only
\[
\log D_R^{\mathrm{rep}}
\le\sum_{R<r\le2R}\log c_r
\le\sum_{R<r\le2R}\log b_r
=O(R^2).
\tag{8.5}
\]
Showing `o(R^2)` in (8.5) is already the repeated-prime theorem. Fitting theory compresses the Boolean OR exactly; it does not create the missing power saving.

## 8.3 Continuant/resultant range

For a fixed gap `h`, the ordinary return polynomial has controlled degree and coefficient height, and the known short-gap resultant machinery produces
\[
O(RH^2\log R)
\]
logarithmic mass for gaps `h<=H`. Choosing
\[
H_R=\left\lfloor\frac{\sqrt R}{\log R}\right\rfloor
\tag{8.6}
\]
gives
\[
O(R^2/\log R)=o(R^2).
\]
The obstruction is therefore correctly localized to far gaps. The terminal-source lemma makes the far-gap equation maximally explicit, but it does not by itself lower the height: one still has `Theta(R^2)` possible `(r,s)` pairs, and no bounded-degree resultant for the canonical endpoint coefficient is supplied by the `Theta(p)` Cartier state in §6.

# 9. The exact theorem still needed

There are three useful levels.

## 9.1 Pointwise closure theorem — sufficient for uniqueness

The smallest source-specific pointwise statement I see is `(EIS-2RET)`:

\[
\boxed{
\begin{gathered}
p\ge7,\quad0<r<s<p,\\
b_r=b_s=0,\quad\Xi_r=0
\\[2mm]
\Longrightarrow\quad
\sum_{m=r+1}^{s}b_{m-1}g_m\ne0\pmod p.
\end{gathered}
}
\tag{9.1}
\]

By (3.4), this is exactly
\[
\Xi_s\ne0.
\]
Thus `(9.1)` proves that once a common row occurs, no later Hasse zero is common; hence each prime has at most one transverse-common index in the whole interval `1,...,p-1`, which is stronger than `(U)`.

Crucially, `(9.1)` does **not** assert that Green periods between arbitrary Hasse zeros are nonzero. The exact `(41,10,30)` collision shows that stronger theorem is false.

In terminal-source language, `(9.1)` is
\[
\boxed{
[t^s]R_p(t)
\ne
-b_{s-1}^{-1}
\sum_{m=r+1}^{s-1}b_{m-1}[t^m]R_p(t)
}
\tag{9.2}
\]
under the same hypotheses. This is a precise defining-characteristic coefficient-avoidance statement for the canonical unit-root forcing function.

## 9.2 Explicit constant multiplicity

A weaker pointwise theorem
\[
\#\{r<p:b_r=\Xi_r=0\}\le C
\tag{9.3}
\]
with an absolute `C` would be useful, but **by itself it does not imply** an `o(R^2)` logarithmic repeated-prime bound. It only says that multiplicity-weighted repeated mass is at most `(C-1)` times repeated-prime support. One still needs a saving for the support.

This distinction matters because a set of fresh primes of quadratic total log height can each occur exactly twice.

## 9.3 Far-gap aggregate theorem — sufficient for the repeated tail

Let
\[
\mathcal P_{\rm far}(R)
=
\left\{
 p>2R:\exists\ R<r<s\le2R,
\begin{array}{l}
 s-r>H_R,\\
 b_r=b_s=\Xi_r=\Xi_s=0\pmod p
\end{array}
\right\}.
\tag{9.4}
\]
A minimal radical-support theorem is
\[
\boxed{
\sum_{p\in\mathcal P_{\rm far}(R)}\log p=o(R^2).
}
\tag{MARKED-FAR}
\]
The banked short-gap result with `(8.6)` already gives `o(R^2)` for primes possessing a close common pair. Hence `(MARKED-FAR)` gives subquadratic **repeated-prime support** over the full dyadic block.

If one also proves the absolute multiplicity bound `(9.3)`, then
\[
\sum_{p>2R}(m_p(R)-1)\log p=o(R^2),
\]
where `m_p(R)` is the number of common rows in `(R,2R]`.

Alternatively one can ask directly for the multiplicity-weighted far theorem and omit `(9.3)`.

### The smallest missing geometric theorem

In crystalline language, `(MARKED-FAR)` asks for a two-coordinate, defining-characteristic **Mellin anti-return theorem** for the pair consisting of

1. the Apéry Hasse coefficient coordinate `b_r`, and
2. the canonical Eisenstein extension/Green coordinate `\Xi_r`.

It must exploit the exact relation `(6.6)` and the exact Eichler normalization `(6.3)`--`(6.4)`. A theorem only about the root divisor of `A_p(t)`, the formal Brauer height, the unit-root eigenvalue at a fixed fiber, or generic monodromy on the geometric `t`-line does not have the right parameter.

from sage.all import *

PMAX = 3000

def P(n):
    n = ZZ(n)
    return 34*n^3 + 51*n^2 + 27*n + 5

def apery_mod(p):
    Fp = GF(p)
    b = [Fp(1), Fp(5)]
    for n in range(2, p):
        b.append((Fp(P(n-1))*b[n-1]
                  - Fp((n-1)^3)*b[n-2]) / Fp(n^3))
    return b

def g_mod(p, b):
    # 1/sqrt(1-34t+t^2) = sum P_n(17)t^n.
    Fp = GF(p)
    R = PowerSeriesRing(Fp, 't', default_prec=p)
    q = [Fp(1), Fp(17)]
    for n in range(1, p-1):
        q.append((Fp(17*(2*n+1))*q[n]
                  - Fp(n)*q[n-1]) / Fp(n+1))
    F = R(b).add_bigoh(p)
    Q = R(q).add_bigoh(p)
    G = (Q/(F*F)).add_bigoh(p)
    return [Fp(G[n]) for n in range(p)]

def kappa_mod(p, g):
    Fp = GF(p)
    k = [Fp(0), Fp(-36)]
    for n in range(2, p):
        k.append((Fp(P(n-1))*k[n-1]
                  - Fp((n-1)^3)*k[n-2]
                  - Fp(5)*g[n]) / Fp(n^3))
    return k

def xi_mod(p, b, g):
    Fp = GF(p)
    xi = [Fp(-1)]
    for n in range(1, p):
        xi.append(xi[-1] - Fp(5)*g[n]*b[n-1])
    return xi

def force_common_sources(p, b, g, rows):
    Fp = GF(p)
    out = list(g)
    deltas = []
    for r in rows:
        k = kappa_mod(p, out)
        assert b[r] == 0
        delta = Fp(r^3)*k[r]/Fp(5)
        out[r] += delta
        deltas.append(int(delta))
        assert kappa_mod(p, out)[r] == 0
    k = kappa_mod(p, out)
    xi = xi_mod(p, b, out)
    assert all(k[r] == 0 and xi[r] == 0 for r in rows)
    return out, deltas

def N_values(p, r, h):
    Fp = GF(p)
    N = [None, Fp(1), Fp(P(r+1))]
    for j in range(2, h):
        N.append(Fp(P(r+j))*N[j]
                 - Fp((r+j)^6)*N[j-1])
    return N

def marked_M(p, r, h, g):
    Fp = GF(p)
    N = N_values(p, r, h)
    total = Fp(0)
    for j in range(1, h):
        tail = Fp(1)
        for q in range(j+1, h):
            tail *= Fp((r+q)^3)
        total += g[r+j+1]*N[j]*tail
    return total, N

# Actual canonical scan and Xi-collision search.
collisions = []
commons = []
for p in prime_range(7, PMAX+1):
    p = int(p)
    b = apery_mod(p)
    z = [r for r in range(1,p) if b[r] == 0]
    if not z:
        continue
    g = g_mod(p,b)
    xi = xi_mod(p,b,g)
    seen = {}
    for r in z:
        v = int(xi[r])
        if v in seen:
            collisions.append((p,seen[v],r,v))
        else:
            seen[v] = r
        if xi[r] == 0:
            commons.append((p,r))

assert (41,10,30,7) in collisions
assert (17,13) in commons
assert (2237,492) in commons
