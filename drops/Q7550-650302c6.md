# 1. First cold-audit correction: the cutoff is phase-shifted

Let
\[
m=kp+r,\qquad 0\le r<p,
\]
with \(k\in\mathbf Z\). Since \(p\equiv1\pmod{p-1}\),
\[
m\equiv k+r\pmod{p-1}.
\]
Therefore the cutoff in the question is
\[
\boxed{
 d_p(m)=\frac{p-1}{\gcd(k+r,p-1)}.
}
\tag{1.1}
\]

By contrast, the decomposition theorem for the local cover \(H_{p,r}\) uses
\[
\boxed{
 \delta_p(r)=\frac{p-1}{\gcd(r,p-1)}.
}
\tag{1.2}
\]

These coincide only when the quotient shift \(k\) is invisible modulo \(p-1\); in particular they coincide in the nonwrapping range \(k=0\), i.e. \(0\le m<p\). There is no monotone comparison in general.

## Exact actual-Apéry counterexamples in both directions

The standard Apéry values include
\[
b_3=1445=17\cdot85,
\qquad
b_5=819005=11\cdot74455.
\]

### High HD cutoff, low local degree

Take \(p=11\), \(m=16=1\cdot11+5\). Then \(b_{m\bmod p}=b_5\equiv0\pmod{11}\), but
\[
d_{11}(16)=\frac{10}{\gcd(16,10)}=5,
\qquad
\delta_{11}(5)=\frac{10}{\gcd(5,10)}=2.
\]
Thus for \(2<D<5\), the incidence is retained by the HD cutoff although its local cover is in the small-degree class.

### Low HD cutoff, high local degree

Take \(p=17\), \(m=20=1\cdot17+3\). Then \(b_3\equiv0\pmod{17}\), but
\[
d_{17}(20)=\frac{16}{\gcd(20,16)}=4,
\qquad
\delta_{17}(3)=\frac{16}{\gcd(3,16)}=16.
\]
Thus for \(4<D<16\), the HD cutoff discards an incidence whose local cover has maximal inner degree.

This proves:

> **Proposition 1 (cutoff mismatch).** For the HD-PC2 definition in the question, local cover decomposition rigidity cannot by itself yield a \(D\)-saving, because the parameter being cut off is not the local decomposition degree after a wrap. The two parameters are arithmetically independent up to the shift \(r\mapsto r+k\) modulo \(p-1\).

This point is separate from Q7542's local no-implication model. Q7542 used the anchor \(m=r=1\), where the two parameters happen to agree. For arbitrary intervals, that agreement disappears.

# 2. Endpoint bookkeeping and row masses

Write
\[
I=\{M,M+1,\ldots,M+P-1\}.
\]
For every prime \(P<p\le2P\), one has \(P\le p-1<p\). Therefore:

- the map \(m\mapsto m\bmod p\) is injective on \(I\);
- the map \(m\mapsto m\bmod(p-1)\) is injective if \(P<p-1\), and is bijective when \(P=p-1\).

Let
\[
R_p=\sum_{m\in I}a_{p,m}.
\]
The high-\(d\) mask can only delete zero digits, so the proved Apéry bound \(Z(p)\ll p^{2/3}\) gives the uniform row estimate
\[
\boxed{R_p\le Z(p)\ll P^{2/3}.}
\tag{2.1}
\]
Consequently
\[
T=\sum_{P<p\le2P}R_p
\ll \frac{P^{5/3}}{\log P}.
\tag{2.2}
\]

No wraparound convention is hidden here: the injectivity statement is literal because the interval length is strictly less than \(p\).

# 3. Variance algebra: exact AHD2 relation

Put
\[
C_{p,q}=\sum_{m\in I}a_{p,m}a_{q,m}
\qquad(p\ne q).
\]
Then
\[
F=\sum_{p\ne q}C_{p,q}.
\]
Define the centered aggregate
\[
\mathcal B_D
=\sum_{p\ne q}
\left(C_{p,q}-\frac{R_pR_q}{P}\right).
\]
Since
\[
\sum_{p\ne q}R_pR_q=T^2-\sum_pR_p^2,
\]
one has the exact identity
\[
\boxed{
F-\frac{T^2}{P}
=\mathcal B_D-\frac1P\sum_pR_p^2.
}
\tag{3.1}
\]

By (2.1),
\[
\frac1P\sum_pR_p^2
\le \frac{\max_pR_p}{P}T
\ll P^{-1/3}T.
\tag{3.2}
\]
Thus the one-sided centered estimate
\[
\mathcal B_D\le P^{o(1)}T
\tag{AHD2}
\]
is sufficient for HD-PC2, and conversely HD-PC2 implies AHD2 with only an additional \(O(P^{-1/3}T)\) term. This checks the centering algebra exactly.

# 4. A sharper exact equivalence: common-frequency horizontal large sieve

Translate \(I\) to \(\{0,\ldots,P-1\}\) and define
\[
A_{p,D}(h)
=\sum_{t=0}^{P-1}a_{p,M+t}e_P(-ht),
\qquad h\in\mathbf Z/P\mathbf Z.
\tag{4.1}
\]
Then
\[
A_{p,D}(0)=R_p,
\qquad
\sum_pA_{p,D}(0)=T.
\]
If
\[
K(t)=\sum_{P<p\le2P}a_{p,M+t},
\]
then its discrete Fourier transform is
\[
\widehat K(h)=\sum_pA_{p,D}(h).
\]
Parseval gives
\[
\sum_{t=0}^{P-1}\left(K(t)-\frac TP\right)^2
=\frac1P\sum_{h=1}^{P-1}
\left|\sum_pA_{p,D}(h)\right|^2.
\tag{4.2}
\]
On the other hand,
\[
\sum_t\left(K(t)-\frac TP\right)^2
=T+F-\frac{T^2}{P}.
\tag{4.3}
\]
Combining (4.2) and (4.3) proves the following exact statement.

> **Theorem 2 (HD-PC2 = horizontal prime-row large sieve).** For any \(E(P)\ge0\),
> \[
> F\le \frac{T^2}{P}+E(P)T
> \]
> if and only if
> \[
> \boxed{
> \sum_{h=1}^{P-1}
> \left|\sum_{P<p\le2P}A_{p,D}(h)\right|^2
> \le P(1+E(P))T.
> }
> \tag{HLS-Ap}
> \]

In particular, HD-PC2 is equivalent to
\[
\boxed{
\sum_{h=1}^{P-1}
\left|\sum_{P<p\le2P}A_{p,D}(h)\right|^2
\le P^{1+o(1)}T.
}
\tag{4.4}
\]

This is not generic large-sieve advice; it is an identity-derived target with the exact normalization required by HD-PC2.

## Scale check

Rowwise Parseval gives
\[
\sum_{h=0}^{P-1}|A_{p,D}(h)|^2=PR_p.
\]
Therefore the trivial Cauchy estimate in the prime variable yields only
\[
\sum_h\left|\sum_pA_{p,D}(h)\right|^2
\le \#\{P<p\le2P\}\,P\,T
\asymp \frac{P^2}{\log P}T,
\]
whereas (4.4) asks for \(P^{1+o(1)}T\). Thus one must save essentially the full factor \(P/\log P\) coming from the number of prime rows. The missing cancellation is genuinely horizontal in \(p\).

# 5. Exact row formula, including the wrap and the high-\(d\) shift

For fixed \(p\), split the interval at the at most one point where \(\lfloor(M+t)/p\rfloor\) changes. On each resulting piece write
\[
M+t=kp+r,
\qquad 0\le r<p,
\]
with \(k\) fixed on that piece. Then
\[
a_{p,M+t}
=\mathbf1_{b_r\equiv0\,(p)}
 \mathbf1_{(p-1)/\gcd(r+k,p-1)>D}.
\tag{5.1}
\]
Hence
\[
A_{p,D}(h)
=\sum_{\text{at most two pieces }J}
\sum_{\substack{r\in J\cap\mathcal Z_p\\
 (p-1)/\gcd(r+k_J,p-1)>D}}
 e_P\!\left(-h(k_Jp+r-M)\right),
\tag{5.2}
\]
where
\[
\mathcal Z_p=\{0\le r<p:b_r\equiv0\pmod p\}.
\]

Formula (5.2) is the exact object that a horizontal theorem must control. The local cover is attached to \(r\), while the cutoff is attached to the shifted residue \(r+k_J\) modulo \(p-1\).

# 6. The high-\(d\) mask has an exact Ramanujan transform

Let \(N=p-1\) and define the additive order
\[
\operatorname{ord}_N(s)=\frac{N}{\gcd(s,N)}.
\]
For \(v\in\mathbf Z/N\mathbf Z\), define
\[
H_{N,D}(v)=
\sum_{s\bmod N}
\mathbf1_{\operatorname{ord}_N(s)>D}e_N(-vs).
\]
The residue classes of exact additive order \(d\mid N\) are
\[
s=\frac Nd a,
\qquad a\in(\mathbf Z/d\mathbf Z)^\times.
\]
Therefore
\[
\sum_{\operatorname{ord}_N(s)=d}e_N(-vs)
=\sum_{a\in(\mathbf Z/d\mathbf Z)^\times}e_d(-va)
=c_d(v),
\]
where \(c_d(v)\) is the Ramanujan sum. Since the high-order set is the complement of the disjoint union of exact-order classes \(d\le D\),
\[
\boxed{
H_{N,D}(v)
=N\mathbf1_{v=0}
-\sum_{\substack{d\mid N\\d\le D}}c_d(v).
}
\tag{6.1}
\]

This proves (Ram). Two useful exact consequences are
\[
H_{N,D}(0)
=N-\sum_{\substack{d\mid N\\d\le D}}\varphi(d),
\tag{6.2}
\]
and, writing \(L_{N,D}\) for the low-order indicator,
\[
\sum_{v\bmod N}|\widehat{L}_{N,D}(v)|^2
=N\sum_{\substack{d\mid N\\d\le D}}\varphi(d)
\le N\sum_{d\le D}\varphi(d)
\ll ND^2.
\tag{6.3}
\]

Thus all analytic difficulty is in how these explicit Ramanujan weights correlate with the Apéry coefficient-zero positions; the cutoff itself is not a hidden geometric object.

# 7. Where the actual global Apéry laws enter

## 7.1 Lucas converts every hit into a prime divisor of the global integer \(b_m\)

For \(m\ge0\), Gessel's Apéry--Lucas law gives
\[
b_m\equiv\prod_i b_{m_i}\pmod p
\]
for the base-\(p\) digits \(m_i\). Therefore
\[
\boxed{
 b_{m\bmod p}\equiv0\pmod p
 \quad\Longrightarrow\quad
 p\mid b_m.
}
\tag{7.1}
\]
If \(m=kp+r<p^2\), then more precisely
\[
b_m\equiv b_kb_r\pmod p.
\tag{7.2}
\]
Thus, away from the leading-digit contamination \(b_k\equiv0\pmod p\), the lower-digit condition is exactly the prime-divisor event for the single global Apéry integer \(b_m\).

Consequently
\[
F\le
\sum_{m\in I}
\omega_{(P,2P]}(b_m)
\bigl(\omega_{(P,2P]}(b_m)-1\bigr),
\tag{7.3}
\]
where \(\omega_{(P,2P]}\) counts distinct prime divisors in the dyadic block. This is rigorous, but it is not yet useful: controlling the right side at the required scale is itself a moving smooth-prime second-moment problem for the actual Apéry integers.

## 7.2 Exact recurrence-phase exponential sums

Let
\[
z_p(r)=\mathbf1_{b_r\equiv0\,(p)},
\qquad
Z_p(u)=\sum_{r=0}^{p-1}z_p(r)e_p(-ur).
\]
Additive orthogonality gives
\[
z_p(r)=\frac1p\sum_{y\in\mathbf F_p}e_p(yb_r),
\]
so
\[
\boxed{
Z_p(u)
=\frac1p\sum_{y\in\mathbf F_p}E_p(y,u),
\qquad
E_p(y,u)=\sum_{r=0}^{p-1}e_p(yb_r-ur).
}
\tag{7.4}
\]
This is the cleanest place where the actual recurrence/ODE can contribute: \(E_p(y,u)\) is an exponential sum along the distinguished Apéry solution, not along an arbitrary polynomial or rational function.

For \(u\ne0\), the \(y=0\) term vanishes identically. Thus every nonzero Fourier mode of the zero set is controlled by the nontrivial recurrence-phase sums
\[
E_p(y,u),\qquad y\ne0.
\]

No evaluation-root substitution has occurred: (7.4) detects the coefficient zero \(b_r=0\) exactly.

# 8. Fully finite-field two-characteristic normal form

For completeness, one can combine the \(p\)-Fourier transform of \(z_p\) and the \((p-1)\)-Fourier transform of the high-order mask. Since \(\gcd(p,p-1)=1\), define
\[
\theta_p(u,v)=\frac up+\frac v{p-1}\pmod1.
\]
Then
\[
a_{p,m}
=\frac{1}{p(p-1)}
\sum_{u\bmod p}\sum_{v\bmod(p-1)}
Z_p(u)H_{p-1,D}(v)e\bigl(m\theta_p(u,v)\bigr).
\tag{8.1}
\]

Let
\[
G_I(\alpha)=\sum_{m\in I}e(m\alpha)
\]
and define the centered interval kernel
\[
\Gamma_I(\alpha,\beta)
=G_I(\alpha+\beta)
-\frac1P G_I(\alpha)G_I(\beta).
\tag{8.2}
\]
Then for \(p\ne q\),
\[
\begin{aligned}
C_{p,q}-\frac{R_pR_q}{P}
={}&\frac{1}{p(p-1)q(q-1)}
\sum_{u,v}\sum_{u',v'}
Z_p(u)H_{p-1,D}(v)
Z_q(u')H_{q-1,D}(v')\\
&\hspace{4em}\times
\Gamma_I\bigl(\theta_p(u,v),\theta_q(u',v')\bigr).
\end{aligned}
\tag{8.3}
\]

The centering is exact: \(\Gamma_I(0,\beta)=\Gamma_I(\alpha,0)=0\). Hence the complete zero frequency on either side disappears automatically.

Substituting (7.4) and (6.1) into (8.3) gives an exact bilinear expression built only from:

- actual Apéry recurrence-phase sums \(E_p(y,u)\);
- explicit Ramanujan sums \(c_d(v)\);
- the elementary incomplete-interval kernel \(\Gamma_I\).

This is a genuine reduction of HD-PC2 to a named exponential-sum problem, with no local-passport surrogate.

# 9. The precise missing estimate

The cleanest statement is the common-frequency form (HLS-Ap):

> **Apéry horizontal row large sieve (ARLS).** Uniformly for every dyadic \(P\), every interval \(I\) of \(P\) consecutive integers, and the allowed cutoff \(D\),
> \[
> \boxed{
> \sum_{h=1}^{P-1}
> \left|
> \sum_{P<p\le2P}
> \sum_{m\in I}
> \mathbf1_{d_p(m)>D}
> \mathbf1_{b_{m\bmod p}=0}
> e_P(-h(m-M))
> \right|^2
> \le P^{1+o(1)}T.
> }
> \tag{ARLS}
> \]

By Theorem 2, **ARLS is equivalent to HD-PC2 at the requested \(P^{o(1)}T\) precision.**

This formulation makes the needed novelty explicit: it is cancellation in the **prime-as-modulus variable** after all rows have been put on one common length-\(P\) Fourier grid.

# 10. Primary theorem audit

## 10.1 Fouvry--Kowalski--Michel, trace weights over primes

Primary source:

É. Fouvry, E. Kowalski, P. Michel, *Algebraic trace functions over the primes*, Duke Math. J. **163** (2014), no. 9, 1683--1736. DOI: [10.1215/00127094-2690587](https://doi.org/10.1215/00127094-2690587). Preprint: [arXiv:1211.6043](https://arxiv.org/abs/1211.6043).

Their Theorem 1.5 assumes a fixed prime modulus \(q\) (their paper writes \(p\)) and an **isotypic trace weight** \(K:\mathbf F_q\to\mathbf C\) coming from a nonexceptional geometrically isotypic Fourier sheaf. The estimate is for
\[
\sum_{\ell\ \mathrm{prime}}K(\ell)V(\ell/X),
\]
with power saving whose constant depends polynomially on the sheaf conductor. In particular the finite field / modulus is fixed inside each application, and uniformity requires bounded conductor.

It does **not** apply to ARLS for three independent reasons:

1. ARLS sums over \(p\) where \(p\) is itself the defining characteristic / modulus. The FKM prime variable is an **argument of one fixed trace function**, not the modulus of that trace function.
2. No theorem identifies
   \[
   r\mapsto\mathbf1_{b_r\equiv0\,(p)}
   \]
   as an isotypic trace weight of conductor bounded independently of \(p\).
3. Even a separate estimate for every fixed \(p\) would not supply cancellation in
   \[
   \sum_{P<p\le2P}A_{p,D}(h),
   \]
   which is the horizontal sum ARLS actually needs.

Therefore Theorem 1.5 cannot be inserted into (ARLS).

## 10.2 Fouvry--Kowalski--Michel--Sawin, 2026 bilinear trace theorem

Primary source:

É. Fouvry, E. Kowalski, P. Michel, W. Sawin, *Bilinear forms with trace functions*, [arXiv:2511.09459v3](https://arxiv.org/abs/2511.09459), 11 March 2026.

Their Theorem 1.3 assumes:

- one prime \(q\);
- one gallant and light \(\ell\)-adic sheaf \(\mathscr F\) on \(\mathbf A^1_{\mathbf F_q}\);
- its trace function \(K\);
- summation variables \(m,n\) inside intervals in the **same** field / modulus \(q\);
- a monomial kernel \(K(m^bn^c)\);
- constants depending on the complexity of \(\mathscr F\).

For example, their Type II estimate bounds
\[
\sum_{m\sim M}\sum_{n\sim N}\alpha_m\beta_nK(m^bn^c)
\]
under explicit size conditions such as \(M\le q\) and \(MN\ge q^{3/4+\delta}\), with a power saving determined by \(\delta\) and the sheaf complexity.

Again the hypotheses do not match ARLS:

- there is no single modulus \(q\);
- the outer variable is a family of changing characteristics \(p\);
- the zero event is a coefficient cancellation, not a known trace value \(K(x)\);
- the high-\(d\) factor lives modulo \(p-1\), not in the same finite field as the coefficient zero;
- no uniform gallant/light sheaf whose trace is the row indicator has been constructed.

The theorem is uniform *once a bounded-complexity sheaf over each fixed \(\mathbf F_q\) is supplied*, but it is not a horizontal large sieve over the moduli \(q\) themselves.

Therefore the 2026 theorem also does not apply.

# 11. Why the exact Apéry ODE has not yet crossed the gap

The exact second-order ODE for \(B_p\), squarefreeness, and the passport of \(H_{p,r}\) are strong statements in characteristic \(p\). But ARLS concerns
\[
\sum_{P<p\le2P}A_{p,D}(h),
\]
so a successful ODE argument must produce a relation among the **distinguished solutions for different primes**.

The recurrence already gives all of the following:

- the vertical root count \(Z(p)\ll p^{2/3}\);
- no consecutive zero digits;
- reflection;
- the exact Lucas block law;
- the global implication (7.1).

None of these supplies the sign/cancellation in the prime-row sum in ARLS. This is exactly analogous to the obstruction in `gcdtail_result.tex`: strong row, column, and codegree information can still coexist with a large aligned incidence pattern unless one controls the alignment parameter itself.

There cannot be a nontrivial countermodel preserving the **same** Apéry recurrence together with the same initial data \(b_0=1,b_1=5\): the recurrence uniquely determines the sequence. Thus the next theorem must be a theorem about this distinguished global solution, not another formal consequence of the recurrence class.

# Final tactical conclusion

The clean next target is not another passport theorem. It is the exact prime-row Fourier inequality (ARLS). The actual Apéry recurrence/ODE would become genuinely useful for HD-PC2 only if it can prove cancellation for the recurrence-phase transforms \(E_p(y,u)\) **uniformly while the defining characteristic changes**, or otherwise construct a common arithmetic object whose prime specializations control the row transforms \(A_{p,D}(h)\).

The strongest current trace-function bilinear theorems do not supply that step: they start after one has already placed all oscillation inside one fixed finite field and one bounded-complexity sheaf. ARLS is precisely the missing bridge from the global integral Apéry solution to such horizontal cancellation.
