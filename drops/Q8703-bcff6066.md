# Q8703 actual-Apéry six-point dispersion audit

## Verdict

No unconditional six-point dispersion theorem is obtained from the currently available Apéry structures. The generic mechanisms listed in the prompt are saturated. The remaining crux is an actual-Apéry correlation statement, not a recurrence-free interpolation statement.

The EPC3 reduction is correctly scoped:

\[
\max_{m<R_X(m)\ge H_X}\ J_{MH}(m)=o(X/\log^3X)
\]

with

\[
H_X=\lceil X/\log^2(2X)\rceil
\]

is a sufficient target. It is not proved by the existing root-count, reflection, CRT, spacing, or rank-two Pluecker carriers.

## 1. Fixed common row does not by itself close the argument

For a row m, every hit prime satisfies

\[
B_{z_p}\equiv0\pmod p,
\]

with either

\[
m=c_pp+z_p
\]

or

\[
m=c_pp-1-z_p.
\]

The fact that all hits share the same integer m is stronger than independent root-set models, but the immediate consequence is only that all selected zeros are evaluations of the same Apéry sequence at different indices.

A candidate compression would need an identity of the form

\[
\sum_i \lambda_i B_{z_i}=0
\]

or a bounded-height integer relation among normalized divided values

\[
B_{z_i}/p_i.
\]

No such relation follows from the second-order recurrence alone: the recurrence transports the two-dimensional state along the index variable, but the six different primes impose six different residue conditions.

## 2. Recurrence-state saturation

Writing the factorial-cleared state as

\[
S_r=(C_r,C_{r-1})^t,
\]

all six values are linear forms

\[
B_{z_i}=\ell_i(S_0).
\]

The shell conditions give

\[
\ell_i(S_0)\equiv0\pmod {p_i}.
\]

For distinct primes the local conditions combine by CRT. Unless there is an additional cross-prime identity, they define a lattice of index roughly

\[
\prod_i p_i,
\]

not an impossible overdetermined system.

Therefore replacing six values by a rank-two state does not by itself give six-point dispersion.

## 3. Constant-term / Cartier route

The constant-term representation and Cartier operators can potentially provide the missing ingredient because they are genuinely arithmetic across primes.

The required statement would have to be a coefficient-correlation estimate of the form:

For every admissible key k and every shell of primes,

\[
\#\{(p_1,\ldots,p_6): \text{same EPC key and all six Cartier conditions hold}\}
=o(\text{generic six-fold mass}).
\]

Equivalently, one needs a power saving after imposing the common-row equations, not merely a bound on individual zero sets.

No unconditional estimate of this form is currently derived.

## 4. Lower-arity reduction if six-point closure fails

The exact residual statement can be reduced to the smallest missing actual-Apéry correlation:

> Bound the number of pairs of distinct shell primes p,q producing a prescribed translation defect and a common normalized quotient relation.

A pair estimate of the form

\[
\max_k \#\{(p,q):k(p,q)\text{ occurs}\}=o(X^2/\log^2X)
\]

would be a genuine lower-arity input. However, it is not a consequence of CRT or recurrence saturation; it must use arithmetic information about Apéry zeros.

## 5. Double-copy formulation

The equivalent condition

\[
S_{6,\kappa}/J_{\kappa}=o(X^{1/3}/\log^6(2X))
\]

has the same obstruction. The denominator J records geometric multiplicity, while S records actual Apéry-labelled collisions. Generic carriers control J but not the ratio.

## Final conclusion

The current crux remains a genuine Apéry coefficient-correlation theorem. The available recurrence, constant-term, Cartier, normalized quotient, and Newton-content frameworks do not yet yield it.

Any successful proof must introduce a new cross-prime arithmetic statement. Any argument using only root counts, reflection, CRT, spacing, or rank-two state dimension is a saturated presentation and cannot close the EPC3 bound.
