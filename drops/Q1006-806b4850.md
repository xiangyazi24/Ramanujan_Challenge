## 1. Canonical three vertex equations

Write

```
p0 = p, p1 = p-g, p2 = p-2g,
r_i = a+i g,
m=p_i+r_i.
```

The target congruences are

```
b_{r_i}=p_i c_i.
```

Since the same output is used,

```
b_m=p0 p1 p2 T
```

for an integer cofactor T only after the three divisibilities have actually been combined.

The local quotient/Gessel relations have the form

```
b_m/p_i = p_j p_k T
```

with the sign determined by the quotient convention. They are not three independent equations over one residue field: each is a congruence modulo a different p_i.

## 2. Exact recurrence transfer

The Apéry recurrence is used through its transfer matrix

```
(b_{n+1}, b_n)^T = M_n (b_n,b_{n-1})^T
```

with the actual Apéry coefficients. Therefore

```
S_1 = M_{a+g-1} ... M_a S_0
S_2 = M_{a+2g-1} ... M_{a+g} S_1.
```

No free defect variables are introduced. The p-adic defect relation is inserted only as

```
b_{p+r}=5 b_r+10 p D_r (mod p^2).
```

Thus the three states are functions of the fixed initial vector

```
(b_0,b_1)=(1,5).
```

## 3. Elimination status

The natural elimination variables are:

After clearing denominators, one obtains an integer ideal generated by the three local residual equations and the two transfer identities.

A general resultant notation is insufficient: the resulting determinant must be computed from the actual Apéry transfer entries. No proof that the first nonzero minor has the required divisibility and height has been obtained.

## 5. Clearing and height

The integral clearing factor is the product of recurrence denominators and the powers of p_i introduced when converting the three congruences to integer equations:

```
C(a,g,m) R(a,g,m) in Z.
```

The degree/height bound follows from the recurrence transfer length:

```
log |C R| <= O(g log m + m log m)
```

for a naive clearing. This is not a saving. A successful carrier requires cancellation reducing this to below the accumulated prime logarithmic mass.

## 6. Why the three-vertex case is not yet a carrier

The obstruction is not the local congruence. It is the missing implication:

```
(local p_i equations)
        =>
(one nonzero integer divisible by p0,p1,p2).
```

The three equations live in different residue fields. Combining them before constructing a characteristic-zero object would repeat the original CRT error.

Therefore the exact three-vertex system remains a valid test case, but no explicit eliminant satisfying the requested carrier property has been proved.
