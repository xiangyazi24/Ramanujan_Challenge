# Audit of corrected Q1104 witness construction

## Verdict

After removing the impossible endpoint from Q1104, the proposed witness strategy has no arithmetic contradiction at the level of the three claimed cases. The Q1104 objection `q >= H` was invalid because the decomposition is `n=H+q` with `0<=q<H`; the displayed counterexample `H=16,q=30` was outside the domain. The corrected argument must nevertheless separate what is proved from what remains a required p-adic lemma.

## 1. Endpoint checks

Let `H=2^k` and `n=H+q`, `0<=q<H`.

If the leading-one run is at least four, the bits immediately below the leading bit satisfy

```
q >= H/2 + H/4 + H/8 = 7H/8.
```

Hence

```
j=q-H/4 >= 5H/8 > 0.
```

Also

```
M=floor((H+q)/2).
```

Since `q<H`,

```
q < (H+q)/2,
```

so every proposed `j=q` witness satisfies `j<M` whenever it is used. The excluded value `q=H-1` is exactly `n=2^{k+1}-1`, the all-one branch.

Therefore the endpoint inequalities do not refute the construction.

## 2. Kummer witness arithmetic

For

```
L_j=C(n,j)C(n-j-1,M-1-j),
```

Kummer gives the 2-adic valuation by the number of binary carries in the corresponding additions.

### Small leading run

For `q<=H-2`, choose `j=q`.

The first binomial has

```
C(H+q,q),
```

and the addition `q+(H)` is carry-free because the bit supports are disjoint. The second binomial similarly has the required no-carry form after substituting `M=floor((H+q)/2)`. Thus the combinatorial coefficient contributes no additional factor of two.

The remaining valuation is exactly the valuation of

```
b_{H+q}-b_q.
```

The claimed value `2+r` is therefore reduced to the independent Apéry residue lemma.

### Long leading run

For `r>=4`, set

```
t=ceil(q/2),
u=H/2-t,
j=q-H/4.
```

The required endpoint inequality follows from `q>=7H/8`, and `j<M` follows from the general inequality above.

The two Kummer additions are:

```
h=H/4-1+u,
c=H-u,
h+c=H+H/4-1.
```

The binary identity gives exactly two carries. Therefore

```
v2(L_j)=2.
```

No extra combinatorial factor is hidden here.

## 3. Residue cancellation

Iterating

```
b_(2m+e)=c_e[m mod 8] b_m mod 64
```

produces

```
b_n = product_i c_{n_i}[n_{i+1}+2n_{i+2}+4n_{i+3}] mod 64.
```

For numbers differing only in the leading bit, all factors below the top four windows are identical. Since each coefficient is odd, those common factors cancel when considering ratios of residues modulo 64.

The top-window possibilities reduce to the stated ratio classes:

```
{9,25,41,57}, {17,49}, {33}.
```

Changing both the top bit and the k-2 bit requires the next two windows, giving the six-bit table rather than the four-bit table. This is why the long-run case needs six top bits.

The cancellation argument is valid provided the local recurrence is established for every scale; it is not merely a finite scan.

## 4. Popcount conclusion

Combining the coefficient valuation and the residue valuation gives:

- all-one case: `v2(D_n)>=2` from `j=0` and the residue `37 mod 64`;
- leading run `r<=3`: `v2(L_q)=0` and `v2(b_n-b_q)=2+r`;
- leading run `r>=4`: `v2(L_j)=2` and `v2(b_n-b_j)=3`, hence total `5`.

The witness mechanism therefore yields the claimed upper-bound obstructions if the residue lemma is accepted.

## 5. Remaining proof obligation

The argument does not prove the full gcd valuation by itself. The missing theorem is an Apéry-specific local congruence lemma:

```
v2(b_(H+q)-b_q)=2+leading_one_run(q)
```

for the short-run branch and

```
v2(b_(H+q)-b_(q-H/4))=3
```

for the long-run branch.

A finite automaton description is acceptable only after proving the transition rule and proving that every binary length is covered by induction.

## Classification

- `q>=7H/8` for leading run at least four.
- positivity and admissibility of `j=q-H/4`.
- Kummer carry counts assuming the displayed binary decompositions.

Finite/evidence only:

Open lemma:

Refuted:
