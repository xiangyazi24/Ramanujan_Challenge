# Problem 2.4: shortest real-variable certificate for the two linear weight-four sums

## Verdict

Both target formulas are correct with the stated sign convention

```text
R_n = H_n + 2 * sum_{k=1}^n (-1)^k/k.
```

The shortest route I see that is genuinely formalizable in Lean 4.29, uses no WZ theorem, and does not require a general harmonic-polylogarithm library is:

1. use the already-proved generating function only for `|x| < 1`;
2. apply the coefficient-integration kernel `log^2(x)/2` and pass to `x = 1` by **absolute convergence of the weight-four target series**;
3. reduce both answers to two mixed endpoint integrals;
4. prove those two integrals from a small shared package consisting of:
   - one finite/positive proof of `zeta(3,1) = zeta(4)/4` by partial fractions;
   - the derivative of `Li4`;
   - one explicit primitive for `log^3(x)/(1-x)`;
   - the classical trilogarithm reflection/Landen identity, proved by differentiation from the available `Li2` identities.

No value formula for `Li4(1/2)` is assumed. It remains the named constant

```text
A = Li4(1/2).
```

In fact, the proof only needs `Li4(0)=0` and the value at `1/2` by definition. The signed quartic endpoint that appears temporarily is evaluated directly from its absolutely convergent series, not imported as a `Li4(-1)` axiom.

The final values are

```text
S  = -(7/2)*L*Z3 + (3/4)*Z2^2,
Sa = -2*A - L^4/12 + (1/2)*L^2*Z2
     + (7/4)*L*Z3 + (1/10)*Z2^2.
```

Numerically,

```text
S  = -0.88685217333353786796766192280077...
Sa =  1.06964731019266711381006955193830...
```

The positive sign of `Sa` is consistent with the first term: `R_1=-1`, so
`(-1)^1 R_1 = +1`.

# 1. Notation

Throughout, write

```text
l(x) = log x,
a(x) = log(1-x),
b(x) = log(1+x),
L    = log 2,
Z2   = zeta(2) = pi^2/6,
Z3   = zeta(3),
Z4   = sum_{n>=1} 1/n^4,
A    = Li4(1/2).
```

Use

```text
Z4 = (2/5)*Z2^2.                                      (1.1)
```

This follows from `Z4=pi^4/90` and `Z2=pi^2/6`; in Lean it should be a
one-line `ring` consequence after the two zeta-value theorems.

The finite sequence bound needed everywhere is deliberately crude:

```text
|R_n| <= H_n + 2 H_n <= 3n.                           (1.2)
```

Hence

```text
sum |R_n|/n^3 <= 3 sum 1/n^2 < infinity.              (1.3)
```

The alternating target has the same norm. Therefore neither final HasSum
proof uses a conditionally convergent raw harmonic or alternating-harmonic

# 2. Exact integral bridge and the alternating sign

The available generating function is

```text
G(x) := sum_{n>=1} R_n x^(n-1)
      = -(a(x)+2b(x))/(x(1-x)),       |x|<1.           (2.1)
```

For `0<r<1`, termwise integration gives

```text
(1/2) integral_0^r log^2(x/r) G(x) dx
  = sum_{n>=1} R_n r^n/n^3.                           (2.2)
```

Pass `r -> 1-` using (1.3), or equivalently prove the endpoint formula first
for the power series and use dominated convergence. This gives

```text
S = -(1/2) integral_0^1
      l(x)^2 * (a(x)+2b(x)) / (x(1-x)) dx.            (2.3)
```

For the alternating series, note the essential minus sign:

```text
-G(-x) = sum_{n>=1} (-1)^n R_n x^(n-1)
       = -(b(x)+2a(x))/(x(1+x)).                       (2.4)
```

Therefore

```text
Sa = -(1/2) integral_0^1
       l(x)^2 * (b(x)+2a(x)) / (x(1+x)) dx.           (2.5)
```

All endpoint values of the displayed integrands may be assigned arbitrarily;
the equalities are Lebesgue/interval-integral equalities up to null endpoints.
A robust Lean implementation proves every integration-by-parts formula first
on `[eps,1-eps]` and then sends `eps -> 0+`.

Suggested theorem shapes are

```lean
theorem tsum_R_div_cube_eq_integral :
    (∑' m : ℕ, R (m+1) / (m+1 : ℝ)^3) =
      -(1/2) * ∫ x in (0:ℝ)..1,
        Real.log x ^ 2 *
          (Real.log (1-x) + 2*Real.log (1+x)) /
          (x*(1-x)) := by
  ...

theorem tsum_alt_R_div_cube_eq_integral :
    (∑' m : ℕ, (-1:ℝ)^(m+1) * R (m+1) / (m+1 : ℝ)^3) =
      -(1/2) * ∫ x in (0:ℝ)..1,
        Real.log x ^ 2 *
          (Real.log (1+x) + 2*Real.log (1-x)) /
          (x*(1+x)) := by
  ...
```

# 3. The one shared ordinary weight-four lemma

The only non-level-two quartic fact not already a single zeta value is

```text
T := integral_0^1 log x * log^2(1-x) / x dx
   = -Z4/2.                                           (3.1)
```

Do not prove this by importing an Euler-sum table. There is a short positive
double-sum proof.

Define the absolutely convergent positive sums

```text
D22 = sum_{m,n>=1} 1/(m^2*(m+n)^2),
D31 = sum_{m,n>=1} 1/(m*(m+n)^3).                     (3.2)
```

Splitting the square defining `Z2^2` into the diagonal and the two strict
triangles gives

```text
Z2^2 = Z4 + 2*D22.                                    (3.3)
```

For positive integers `m,n`, the exact pointwise identities are

```text
1/(m^2*n^2)
 = 1/(m^2*(m+n)^2)
 + 1/(n^2*(m+n)^2)
 + 2/(m*n*(m+n)^2),                                   (3.4)

1/(m*n*(m+n)^2)
 = 1/(m*(m+n)^3) + 1/(n*(m+n)^3).                    (3.5)
```

Summing (3.4)-(3.5), with only nonnegative terms, gives

```text
Z2^2 = 2*D22 + 4*D31.                                 (3.6)
```

Subtracting (3.3) yields

```text
D31 = Z4/4.                                           (3.7)
```

Finally, expand the two logarithms in (3.1). Tonelli applies to `-T`, and

```text
-T = sum_{m,n>=1} 1/(m*n*(m+n)^2)
   = 2*D31
   = Z4/2.                                            (3.8)
```

This is the exact finite algebra certificate behind the usual
`zeta(3,1)=zeta(4)/4`. Every summability obligation is dominated by the
product family `1/(m^2*n^2)`; no conditional rearrangement occurs.

A useful shared Lean lemma is therefore

```lean
theorem integral_log_mul_log_one_sub_sq_div_self :
    (∫ x in (0:ℝ)..1,
      Real.log x * Real.log (1-x)^2 / x) = -Z4/2 := by
  ...
```

It immediately also gives

```text
integral_0^1 l(x)^2*a(x)/(1-x) dx = T = -Z4/2,        (3.9)
```

because

```text
a(x)/(1-x) dx = -(1/2) d(a(x)^2),                    (3.10)
```

and the boundary term `l(x)^2 a(x)^2` vanishes at both endpoints.

# 4. Elementary endpoint integrals

Directly from the absolutely convergent logarithm series after multiplying by
`l(x)^2`,

```text
I_a0 := integral_0^1 l(x)^2*a(x)/x dx = -2*Z4,        (4.1)
I_b0 := integral_0^1 l(x)^2*b(x)/x dx =  7*Z4/4.     (4.2)
```

For (4.2), one uses

```text
sum_{n>=1} (-1)^(n+1)/n^4 = (1-2^(-3))*Z4 = 7*Z4/8.
```

This endpoint series is absolutely convergent. No theorem about the raw
alternating harmonic series is used.

Together with (3.9), only two mixed integrals remain:

```text
E := integral_0^1 l(x)^2*b(x)/(1-x) dx,               (4.3)
K := integral_0^1 l(x)^2*b(x)/(1+x) dx.               (4.4)
```

They will be proved as

```text
E = (7/2)*L*Z3 - (19/8)*Z4,                           (4.5)

K = 4*A + L^4/6 - L^2*Z2
    + (7/2)*L*Z3 - (15/4)*Z4.                         (4.6)
```

These are the only two genuinely level-two weight-four endpoint lemmas.

# 5. Minimal Li4 API

Define, in the same normalization as the existing `polylog4`,

```text
Li4(x) = sum_{n>=1} x^n/n^4.                          (5.1)
```

Only the following derivative theorem is needed:

```lean
theorem li4_hasDerivAt {x : ℝ} (hx : |x| < 1) (hx0 : x ≠ 0) :
    HasDerivAt Li4 (Li3 x / x) x := by
  ...
```

The proof is the same locally uniform differentiated-series argument already
used for `dilog` and `Li3`.

The only `Li4` endpoint values used as such are

```text
Li4(0)   = 0,
Li4(1/2) = A                                            (definition). (5.2)
```

No Landen, reflection, or closed formula for `A` is assumed. The temporary
integral

```text
integral_0^1 Li3(-u)/u du = -7*Z4/8                   (5.3)
```

is proved directly from the absolutely convergent signed quartic series. If
desired, (5.3) may be recorded afterward as the theorem
`Li4(-1)=-7*Z4/8`; it is not an extra hypothesis. Likewise
`Li4(1)=Z4` is immediate from the defining series but is not needed below.

The primitive used at `1/2` is

```text
P3(u) = -log^3(u)*log(1-u)
        -3*log^2(u)*Li2(u)
        +6*log(u)*Li3(u)
        -6*Li4(u).                                    (5.4)
```

On `0<u<1`, direct differentiation gives

```text
P3'(u) = log^3(u)/(1-u).                              (5.5)
```

The limit of `P3(u)` at `0+` is zero. Hence, with

```text
L2h = Li2(1/2) = Z2/2 - L^2/2,
L3h = Li3(1/2) = 7*Z3/8 - L*Z2/2 + L^3/6,             (5.6)
```

one gets

```text
A3 := integral_0^(1/2) log^3(u)/(1-u) du
    = -L^4 -3*L^2*L2h -6*L*L3h -6*A.                 (5.7)
```

By `u -> 1-u` and

```text
integral_0^1 log^3(u)/(1-u) du = -6*Z4,               (5.8)
```

we obtain the half-interval companion

```text
B3 := integral_0^(1/2) log^3(1-u)/u du
    = 6*A + L^4/2 - (3/2)*L^2*Z2
      + (21/4)*L*Z3 - 6*Z4.                           (5.9)
```

Equations (5.4)-(5.9) are the complete Li4 contribution to the proof.

```text
J12 := integral_0^(1/2)
```

```text
C21 := integral_0^(1/2)
```

```text
C21 = J12 - L^4/2.                                    (6.4)
```

```text
T = J12 + C21.                                        (6.5)
```

# 7. The mixed `1/(1-x)` integral E

## 7.1 The needed trilogarithm identity

For `0<x<1` (and in this proof only `x<=1/2` is used), prove

```text
Li3(x) + Li3(1-x) + Li3(-x/(1-x))
 = Z3 + Z2*log(1-x)
   - (1/2)*log(x)*log^2(1-x)
   + (1/6)*log^3(1-x).                                (7.1)
```

This should not be imported as a table entry. Define the difference of the
two sides, differentiate, and use only the available dilogarithm formulas

```text
Li2(x)+Li2(1-x) = Z2-log(x)log(1-x),                  (7.2)
Li2(-x/(1-x))   = -Li2(x)-(1/2)log^2(1-x).            (7.3)
```

The derivative is zero; the limit at `x -> 0+` is zero. This is a short
`constant_of_has_deriv_right_zero` proof of exactly the same kind already used
in `Dilogarithm.lean`.

## 7.2 One transformed trilogarithm integral

Define

```text
Eneg := integral_0^(1/2) Li3(-x/(1-x))/x dx.           (7.4)
```

Use `u=x/(1-x)`. Then

```text
Eneg = integral_0^1 Li3(-u)/(u*(1+u)) du
     = integral_0^1 Li3(-u)/u du
       - integral_0^1 Li3(-u)/(1+u) du.                (7.5)
```

The first term is `-7*Z4/8` by (5.3). For the second term, integration by
parts and `d Li2(-u) = -log(1+u)/u du` give

```text
integral_0^1 Li3(-u)/(1+u) du
 = Li3(-1)*L
   - integral_0^1 log(1+u)*Li2(-u)/u du
 = -(3/4)*L*Z3 + Z2^2/8.                              (7.6)
```

Therefore, using `Z2^2=(5/2)Z4`,

```text
Eneg = (3/4)*L*Z3 - (19/16)*Z4.                       (7.7)
```

Every sign in (7.6) is forced by

```text
d Li2(-u) = -log(1+u)/u du,
```

so

```text
integral log(1+u)*Li2(-u)/u du
  = -(1/2)*Li2(-u)^2 |_(0)^1
  = -Z2^2/8.
```

## 7.3 The integral of `Li3(1-x)-Z3`

Set

```text
D := integral_0^(1/2) (Li3(1-x)-Z3)/x dx.             (7.8)
```

Integrating (7.1) after division by `x`, and using (5.9), (6.2), and (7.7),
produces the exact finite reduction

```text
D = -A - Eneg - Z2*L2h - J12/2 + B3/6                (7.9)
  = -(15/16)*Z4 + (1/4)*L^2*Z2
    - L^4/24 + (1/8)*L*Z3.                            (7.10)
```

The `A` terms cancel in (7.10).

## 7.4 A one-step generating function

For `H_n^(2)=sum_{k=1}^n 1/k^2`, the finite coefficient identity is

```text
sum_{n>=1} (H_n^2+H_n^(2)) x^n
 = (log^2(1-x)+2*Li2(x))/(1-x),       |x|<1.           (7.11)
```

After one coefficient integration, the normalized primitive is

```text
Q1(x) = 2*Li3(x)+2*Li3(1-x)-2*Z3
        -2*Z2*log(1-x)
        +log(x)*log^2(1-x)
        -(1/3)*log^3(1-x).                            (7.12)
```

A direct derivative check gives

```text
Q1'(x)
 = (log^2(1-x)+2*Li2(x))/(x*(1-x)),                   (7.13)
```

and `Q1(x)->0` as `x->0+`. Thus

```text
Qhalf := sum_{n>=1} (H_n^2+H_n^(2))/(n^2*2^n)
       = integral_0^(1/2) Q1(x)/x dx                 (7.14)
       = 2*A + 2*D + 2*Z2*L2h + J12 - B3/3
       = (19/8)*Z4 - (3/2)*L*Z3.                      (7.15)
```

Finally, the elementary beta moment

```text
integral_0^1 y^(n-1)*log^2(1-y) dy
 = (H_n^2+H_n^(2))/n                                 (7.16)
```

and the absolutely convergent expansion of `log(1-y/2)` imply

```text
integral_0^1
  log^2(1-y)*log(1-y/2)/y dy
 = -Qhalf
 = (3/2)*L*Z3 - (19/8)*Z4.                            (7.17)
```

The interchange in (7.17) is dominated by a geometric series: from
`H_n<=n` and `H_n^(2)<=n`,

```text
(H_n^2+H_n^(2))/(n^2*2^n) <= 2/2^n.                  (7.18)
```

Now put `y=1-x` in (4.3). Since

```text
log(1+x) = L + log(1-y/2),                            (7.19)

integral_0^1 log^2(1-y)/y dy = 2*Z3,                  (7.20)
```

we obtain

```text
E = 2*L*Z3 + (3/2)*L*Z3 - (19/8)*Z4
  = (7/2)*L*Z3 - (19/8)*Z4.                           (7.21)
```

This proves the first mixed endpoint lemma (4.5).

# 8. The mixed `1/(1+x)` integral K

This one is shorter. Since

```text
d(log^2(1+x)) = 2*log(1+x)/(1+x) dx,
```

integration by parts gives

```text
K = - integral_0^1 log(x)*log^2(1+x)/x dx.            (8.1)
```

Make the substitution

```text
u = x/(1+x),       x = u/(1-u),       0<=u<=1/2.      (8.2)
```

Writing `p=log u`, `q=log(1-u)`, expansion plus one integration by parts gives

```text
K = -J12 + (2/3)*B3 + L^4/12.                         (8.3)
```

For clarity, the finite calculation behind (8.3) is

```text
integral_0^1 log(x)*log^2(1+x)/x dx
 = integral_0^(1/2) (p-q)*q^2/(u*(1-u)) du

 = J12
   + [-L^4/3 + B3/3]
   - B3
   + L^4/4

 = J12 - (2/3)*B3 - L^4/12.                           (8.4)
```

The bracketed term is

```text
integral_0^(1/2) p*q^2/(1-u) du
 = -L^4/3 + B3/3.                                     (8.5)
```

Substitute (5.9) and (6.2) into (8.3):

```text
K = 4*A + L^4/6 - L^2*Z2
    + (7/2)*L*Z3 - (15/4)*Z4.                         (8.6)
```

This proves (4.6). No additional polylogarithm identity occurs.

# 9. Avoid evaluating the second `1/(1+x)` integral separately

Let

```text
Km := integral_0^1 l(x)^2*a(x)/(1+x) dx.              (9.1)
```

A direct evaluation of `Km` would be another level-two calculation. It is
unnecessary. The exact differential identity

```text
b(x)/(1-x) - (a(x)+b(x))/(1+x)
 = -d/dx [a(x)*b(x) + b(x)^2/2]                       (9.2)
```

implies, after integration by parts,

```text
E-(K+Km)
 = integral_0^1 l(x)/x *
     (log^2(1-x^2)-log^2(1-x)) dx.                    (9.3)
```

In the first term of (9.3), put `u=x^2`. It becomes `T/4`; the second term is
`T`. Consequently, by (3.1),

```text
E-(K+Km) = -3*T/4 = 3*Z4/8.                           (9.4)
```

Therefore

```text
K+Km = E-3*Z4/8
     = (7/2)*L*Z3 - (11/4)*Z4.                        (9.5)
```

The exact combination needed by `Sa` is

```text
C := Km + K/2
   = (K+Km)-K/2                                       (9.6)
   = -2*A - L^4/12 + (1/2)*L^2*Z2
     + (7/4)*L*Z3 - (7/8)*Z4.                         (9.7)
```

This identity is the main size reduction in the proof: only `K`, not `Km`,
requires a level-two endpoint calculation.

# 10. Assembly of S

Split

```text
1/(x*(1-x)) = 1/x + 1/(1-x).                          (10.1)
```

Using (4.1), (4.2), (3.9), and (7.21), equation (2.3) becomes

```text
S
 = -(1/2) [(-2*Z4-Z4/2) + 2*(7*Z4/4+E)]
 = -E-Z4/2                                            (10.2)
 = -(7/2)*L*Z3 + (15/8)*Z4.                           (10.3)
```

Finally, (1.1) gives

```text
(15/8)*Z4 = (15/8)*(2/5)*Z2^2 = (3/4)*Z2^2,           (10.4)
```

so

```text
S = -(7/2)*L*Z3 + (3/4)*Z2^2.                         (10.5)
```

# 11. Assembly of Sa

Split

```text
1/(x*(1+x)) = 1/x - 1/(1+x).                          (11.1)
```

The `1/x` contribution to `b+2a` is

```text
7*Z4/4 + 2*(-2*Z4) = -9*Z4/4.                         (11.2)
```

The `1/(1+x)` contribution is

```text
K+2*Km = 2*C.                                         (11.3)
```

Therefore (2.5) gives

```text
Sa = 9*Z4/8 + C                                       (11.4)
   = -2*A - L^4/12 + (1/2)*L^2*Z2
     + (7/4)*L*Z3 + Z4/4.                             (11.5)
```

Using `Z4/4=Z2^2/10`,

```text
Sa = -2*A - L^4/12 + (1/2)*L^2*Z2
     + (7/4)*L*Z3 + (1/10)*Z2^2.                      (11.6)
```

This is exactly the target normalization and sign.

# 13. Endpoint and domination obligations

No hidden improper-integral theorem is required. The exact bounds sufficient
for all passages are:

```text
|R_n|/n^3 <= 3/n^2;                                   (13.1)

(H_n^2+H_n^(2))/(n^2*2^n) <= 2/2^n;                  (13.2)

1/(m^2*(m+n)^2) <= 1/(m^2*n^2);                       (13.3)
```

and all terms in the double-sum proof of Section 3 are nonnegative.

For integration by parts, it suffices to have the concrete endpoint limits

```text
x^c * |log x|^j -> 0                 as x->0+, c>0,
(1-x)^c * |log(1-x)|^j -> 0         as x->1-, c>0,    (13.4)
```

for `j<=4`. The weight-three file should already contain the same lemmas for
smaller powers; the general fixed-natural-power statement is preferable to
four ad hoc repetitions.

For (7.17), `|log(1-y/2)|<=L` on `[0,1]`, and
`log^2(1-y)` is integrable. For the series proof, (13.2) is even simpler.

For (5.4), (7.1), and all other derivative certificates, work on compact
subintervals of `(0,1)` and use the endpoint limits only after the finite
identity has been established.

# 14. Exact coefficient audit

The whole final arithmetic can be checked without integration:

```text
B3    = 6*A + L^4/2 - 3*L^2*Z2/2 + 21*L*Z3/4 - 6*Z4,
J12   = L^4/4 - Z4/4,
Eneg  = 3*L*Z3/4 - 19*Z4/16,
D     = -L^4/24 + L^2*Z2/4 + L*Z3/8 - 15*Z4/16,
Qhalf = -3*L*Z3/2 + 19*Z4/8,
E     = 7*L*Z3/2 - 19*Z4/8,
K     = 4*A + L^4/6 - L^2*Z2 + 7*L*Z3/2 - 15*Z4/4,
K+Km  = 7*L*Z3/2 - 11*Z4/4,
C     = -2*A - L^4/12 + L^2*Z2/2 + 7*L*Z3/4 - 7*Z4/8.
```

Then

```text
S  = -E-Z4/2
   = -7*L*Z3/2 + 15*Z4/8
   = -7*L*Z3/2 + 3*Z2^2/4,

Sa = 9*Z4/8+C
   = -2*A-L^4/12+L^2*Z2/2+7*L*Z3/4+Z4/4
   = -2*A-L^4/12+L^2*Z2/2+7*L*Z3/4+Z2^2/10.
```

This isolates every coefficient and sign. In particular:

- the `L*Z3` coefficient in `S` is negative because the entire mixed
  `1/(1-x)` integral enters with coefficient `-1`;
- the `Li4(1/2)` coefficient in `Sa` is `-2`, coming from
  `-(1/2)K` in (9.6);
- the final quartic-zeta coefficient in `Sa` is
  `9/8-7/8=1/4`, hence `Z2^2/10`.

## Final recommendation

Implement the route above rather than a generic weight-four HPL reducer.
The strongest reusable new lemma is Section 3's finite partial-fraction proof
of `zeta(3,1)=zeta(4)/4`; it supplies the ordinary quartic boundary in both
linear sums. After that, the only bespoke level-two work is `E` and `K`, and
`K` is a one-substitution consequence of `B3` and `J12`. The second
`1/(1+x)` integral should **not** be evaluated separately: identity (9.2)
removes it exactly.
