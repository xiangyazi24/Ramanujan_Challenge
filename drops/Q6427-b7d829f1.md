# 1. Specialized pole and removable-zero structure

For `1 ≤ m ≤ n`, the numerator has a cubic factor at the crossed integer:

```lean
theorem ctNumerator_factor27 {n m : ℕ} (hm1 : 1 ≤ m) (hmn : m ≤ n)
    (t : ℂ) :
    ctNumerator27 n t =
      (t - (m : ℂ)) ^ 3 * ctNumeratorWithout27 n m t
```

The strip is

```lean
def halfIntegerStrip (m : ℤ) : Set ℂ :=
  {z | (m : ℝ) - 1 / 2 ≤ z.re ∧ z.re ≤ (m : ℝ) + 1 / 2}
```

Every denominator factor is nonzero there:

```lean
theorem ctPoleProduct_ne_zero_on_strip27 {n m : ℕ} (hm1 : 1 ≤ m)
    {t : ℂ} (ht : t ∈ halfIntegerStrip (m : ℤ)) :
    ctPoleProduct27 (n + 1) t ≠ 0
```

Indeed, for every `j ≥ 0`,

```text
Re (t + j) ≥ m - 1/2 + j ≥ 1/2.
```

Thus every rational pole `t = -j` is strictly to the left of every strip crossed in the transport `m = 1, ..., n`.

The sine quotient is extended with Mathlib's divided slope:

```lean
def sinePi (z : ℂ) : ℂ :=
  Complex.sin ((Real.pi : ℂ) * z)

def sineSlope (m : ℤ) : ℂ → ℂ :=
  dslope sinePi (m : ℂ)
```

The exact factorization is global:

```lean
theorem sinePi_eq_sub_mul_sineSlope (m : ℤ) (z : ℂ) :
    sinePi z = (z - (m : ℂ)) * sineSlope m z
```

and the extension is nonzero throughout the closed strip:

```lean
theorem sineSlope_ne_zero_on_strip (m : ℤ) {z : ℂ}
    (hz : z ∈ halfIntegerStrip m) : sineSlope m z ≠ 0
```

The nonvanishing proof has two cases.

- At `z = m`, `dslope_same` gives the derivative `π cos(πm)`, and `Real.cos_int_mul_pi` proves this is nonzero.
- Away from `m`, a zero of `sineSlope` would force a zero of `sin(πz)`. `Complex.sin_eq_zero_iff` then gives another integer in the half-integer strip, and integer arithmetic forces it to equal `m`.

The holomorphic extension of the full integrand is

```lean
def ctExtension27 (n m : ℕ) (t : ℂ) : ℂ :=
  (Real.pi : ℂ) ^ 2 * (t - (m : ℂ)) * ctRemoved27 n m t /
    sineSlope (m : ℤ) t ^ 2
```

The cubic rational zero cancels the two sine zeros, leaving one factor `t-m`. Consequently the extension actually vanishes at the crossed integer.

The extension is holomorphic on the closed strip:

```lean
theorem ctExtension_differentiableOn27 {n m : ℕ} (hm1 : 1 ≤ m) :
    DifferentiableOn ℂ (ctExtension27 n m) (halfIntegerStrip (m : ℤ))
```

Crucially, the raw totalized quotient is equated with the extension only away from `m`:

```lean
theorem ctIntegrand_eq_extension27 {n m : ℕ}
    (hm1 : 1 ≤ m) (hmn : m ≤ n)
    {t : ℂ} (ht : t ∈ halfIntegerStrip (m : ℤ))
    (htm : t ≠ (m : ℂ)) :
    ctIntegrand27 n t = ctExtension27 n m t
```

There is no theorem asserting global continuity of `ctIntegrand27 n`; Lean's division-by-zero value at `m` is never used as the removable value.

# 2. Rectangle orientation and finite-to-infinite passage

The exact Mathlib Cauchy theorem used is:

```lean
Complex.integral_boundary_rect_eq_zero_of_differentiableOn
```

The compiled generic wrapper is:

```lean
theorem verticalIntegral_eq_of_horizontal_tendsto
    {F : ℂ → ℂ} {a b : ℝ} (hab : a ≤ b)
    (hF : DifferentiableOn ℂ F (closedVerticalStrip a b))
    (hleft : Integrable (fun y : ℝ => F (verticalPoint a y)))
    (hright : Integrable (fun y : ℝ => F (verticalPoint b y)))
    (htop : Tendsto
      (fun T : ℝ => ∫ x in a..b,
        F ((x : ℂ) + (T : ℂ) * Complex.I))
      atTop (𝓝 0))
    (hbottom : Tendsto
      (fun T : ℝ => ∫ x in a..b,
        F ((x : ℂ) - (T : ℂ) * Complex.I))
      atTop (𝓝 0)) :
    (∫ y : ℝ, F (verticalPoint a y)) =
      ∫ y : ℝ, F (verticalPoint b y)
```

For opposite corners `a - iT` and `b + iT`, Mathlib's boundary identity normalizes to

```text
bottom - top + i * right - i * left = 0.
```

Multiplying by `i` and using `i² = -1` yields

```text
left - right = i * (top - bottom).
```

The finite vertical segments converge to the whole-line Bochner integrals with the exact theorem

```lean
MeasureTheory.intervalIntegral_tendsto_integral
```

applied as

```lean
MeasureTheory.intervalIntegral_tendsto_integral
  hleft tendsto_neg_atTop_atBot tendsto_id
```

and similarly on the right. Uniqueness of limits is then `tendsto_nhds_unique`.

# 3. Explicit horizontal-edge decay

The proof does not use an opaque “rational functions have polynomial growth” assertion.

For `T ≥ 1`, the complex sine is bounded directly from its exponential definition:

```lean
theorem norm_sinePi_top_ge_final (x T : ℝ) (hT : 1 ≤ T) :
    Real.exp (Real.pi * T) / 4 ≤
      ‖sinePi ((x : ℂ) + (T : ℂ) * Complex.I)‖

theorem norm_sinePi_bottom_ge_final (x T : ℝ) (hT : 1 ≤ T) :
    Real.exp (Real.pi * T) / 4 ≤
      ‖sinePi ((x : ℂ) - (T : ℂ) * Complex.I)‖
```

The proof expands

```text
sin w = (exp(-wi) - exp(wi)) i / 2
```

and applies `norm_sub_norm_le`. One exponential has norm `exp(πT)`, the other has norm `exp(-πT)`, and for `T ≥ 1` the smaller term is at most half the larger.

This gives the squared-kernel estimate

```lean
theorem norm_ctKernel_top_le_final (x T : ℝ) (hT : 1 ≤ T) :
    ‖ctKernel27 ((x : ℂ) + (T : ℂ) * Complex.I)‖ ≤
      16 * Real.pi ^ 2 / Real.exp (Real.pi * T) ^ 2
```

and the identical bottom-edge bound.

For `x ∈ [m-1/2,m+1/2]`, `1 ≤ m ≤ n`, and every numerator index `r<n`, the compiled estimate is

```lean
theorem norm_horizontal_factor_le_final ... :
    ‖(x : ℂ) + (y : ℂ) * Complex.I - (r + 1 : ℕ)‖ ≤
      ((n : ℝ) + 2) * (1 + |y|)
```

while every denominator factor has norm at least `1/2`. Therefore

```lean
theorem norm_ctR_on_strip_le_final ... :
    ‖ctR27 n ((x : ℂ) + (y : ℂ) * Complex.I)‖ ≤
      ((((n : ℝ) + 2) * (1 + |y|)) ^ 3) ^ n /
        (1 / 2 : ℝ) ^ (n + 1)
```

The resulting explicit majorant is

```lean
def ctHorizontalMajorant27Final (n : ℕ) (T : ℝ) : ℝ :=
  ((2 * ((n : ℝ) + 2)) ^ (3 * n) /
      (1 / 2 : ℝ) ^ (n + 1)) *
    (16 * Real.pi ^ 2 / Real.exp (Real.pi * T) ^ 2) *
    T ^ (3 * n)
```

and both horizontal integrands satisfy the uniform bound

```lean
‖ctIntegrand27 n (x ± T * I)‖ ≤ ctHorizontalMajorant27Final n T.
```

The limit is proved from the exact Mathlib theorem

```lean
Real.tendsto_pow_mul_exp_neg_atTop_nhds_zero
```

because the majorant is a constant multiple of

```text
T^(3n) * exp(-2πT).
```

Finally,

```lean
intervalIntegral.norm_integral_le_of_norm_le_const
```

bounds each horizontal interval integral. Its interval has length exactly one, so the same majorant controls the edge norm. The compiled conclusions are

```lean
theorem ctHorizontal_top_tendsto_zero27_final ... : Tendsto ... atTop (𝓝 0)
theorem ctHorizontal_bottom_tendsto_zero27_final ... : Tendsto ... atTop (𝓝 0)
```

# 4. Whole-line vertical integrability

The same majorant is integrable, not merely convergent to zero. The positive-tail proof reduces to the Gamma integral:

```lean
theorem integrableOn_pow_mul_exp_neg_mul27_final
    (p : ℕ) {a : ℝ} (ha : 0 < a) :
    IntegrableOn (fun t : ℝ => t ^ p * Real.exp (-(a * t))) (Ioi 0)
```

using the exact Mathlib declarations

```lean
Real.GammaIntegral_convergent
integrableOn_Ioi_comp_mul_left_iff
```

Reflection through `Measure.map_neg_eq_self` gives the negative half-line. This produces the global even majorant

```lean
def ctAbsMajorant27Final (n : ℕ) (y : ℝ) : ℝ :=
  ctHorizontalMajorant27Final n |y|

theorem integrable_ctAbsMajorant27_final (n : ℕ) :
    Integrable (ctAbsMajorant27Final n)
```

Vertical integrability is then split into:

- the compact middle interval `[-1,1]`, using continuity and `ContinuousOn.integrableOn_compact`;
- the positive tail, dominated by the top-edge estimate;
- the negative tail, dominated by the bottom-edge estimate.

The extension and raw boundary integrands are both proved integrable:

```lean
theorem integrable_ctExtension_vertical27_final ... : Integrable ...

theorem integrable_ctIntegrand_vertical27_final ... : Integrable ...
```

The raw/extension equality on a boundary line is pointwise because `Re t = m ± 1/2`, hence the boundary never contains `m`.

# 5. One strip and repeated shift

The completed one-strip theorem has no analytic hypotheses left:

```lean
theorem ctR_one_strip_shift_complete27_final
    {n m : ℕ} (hm1 : 1 ≤ m) (hmn : m ≤ n) :
    ctVerticalIntegral27Final n ((m : ℝ) - 1 / 2) =
      ctVerticalIntegral27Final n ((m : ℝ) + 1 / 2)
```

Iteration gives

```lean
theorem ctR_repeated_shift27_final
    (n a d : ℕ) (had : a + d ≤ n) :
    ctVerticalIntegral27Final n ((a : ℝ) + 1 / 2) =
      ctVerticalIntegral27Final n (((a + d : ℕ) : ℝ) + 1 / 2)
```

and setting `d = n-a` gives the native-line transport:

```lean
theorem ctR_shift_to_native27_final
    {n a : ℕ} (ha : a ≤ n) :
    ctVerticalIntegral27Final n ((a : ℝ) + 1 / 2) =
      ctVerticalIntegral27Final n ((n : ℝ) + 1 / 2)
```

# Using it in the four-term telescoper

Suppose the rational creative-telescoping identity is proved on a common line `Re t = a+1/2`:

```lean
α n • ctR27 (n + 1) t - β n • ctR27 n t
  + γ n • ctR27 (n - 1) t - δ n • ctR27 (n - 2) t
  = ctS27 n (t + 1) - ctS27 n t
```

For each term whose index is `k`, apply

```lean
ctR_shift_to_native27_final (n := k) (a := a) ha
```

where `ha : a ≤ k`. Thus every common-line integral is replaced by the corresponding native integral on `Re t = k+1/2`. Scalar coefficients commute with the Bochner integral through the standard integral linearity lemmas (`MeasureTheory.integral_const_mul`, `MeasureTheory.integral_add`, and `MeasureTheory.integral_sub`) once the integrability theorems above are in scope.

For the certificate difference, apply the same one-strip machinery to the certificate after factoring its crossed zeros, or use the finite shift identity if its line displacement is already exactly one. The important point is that the `ctR27` terms no longer share a hidden line convention: the theorem explicitly transports each index from the common line to its own native line.
