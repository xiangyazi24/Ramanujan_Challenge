# Q7190: Hasse squareness + reciprocity is insufficient for the P32 short-window principle

## 1. Setup

Let

\[
B(t)=1+x_1t+\cdots+x_{d-1}t^{d-1}+t^d,
\]

with reciprocity

\[
x_{d-j}=x_j.
\]

For odd characteristic let

\[
H(t)=\Delta(t)^\epsilon B(t)^2,\qquad \Delta(t)=t^2-34t+1,
\]

where \(\epsilon\in\{0,1\}\). Write

\[
H(t)=1+H_1t+\cdots.
\]

The question is whether the first \(m\) coefficients of \(H\), for \(m<d/2\), impose any useful restriction on the possible zero patterns.

The answer is no: the coefficient map is locally and globally triangular, hence it is a polynomial automorphism. Therefore Hasse squareness and reciprocity alone allow arbitrary first-half coefficient patterns.

## 2. Triangular coefficient calculation

Because \(m<d/2\), the coefficient of \(t^i\) in \(B^2\) only depends on \(x_1,\ldots,x_i\), and the term containing \(x_i\) is obtained only from

\[
(1)(x_it^i)+(x_it^i)(1).
\]

Thus

\[
[t^i]B(t)^2=2x_i+P_i(x_1,\ldots,x_{i-1}),
\]

where \(P_i\) is an integral polynomial in earlier variables.

Multiplying by \(\Delta^\epsilon\) does not change triangularity. Since

\[
\Delta(t)^\epsilon=1+q_1t+q_2t^2+\cdots,
\]

we get

\[
H_i=2x_i+Q_i(x_1,\ldots,x_{i-1}),
\]

for another polynomial \(Q_i\).

Therefore the Jacobian matrix

\[
\frac{\partial(H_1,\ldots,H_m)}{\partial(x_1,\ldots,x_m)}
\]

is lower triangular with diagonal entries all equal to 2.

Because the characteristic is odd,

\[
2\neq0,
\]

so the determinant is

\[
2^m\neq0.
\]

Hence the map is a polynomial automorphism of affine \(m\)-space.

## 3. Explicit inverse construction

Given arbitrary target coefficients

\[
a_1,\ldots,a_m,
\]

solve recursively:

\[
2x_1=a_1-Q_1,
\]

then

\[
2x_2=a_2-Q_2(x_1),
\]

and generally

\[
2x_i=a_i-Q_i(x_1,\ldots,x_{i-1}).
\]

Since division by 2 is valid, this uniquely determines

\[
(x_1,\ldots,x_m).
\]

The remaining coefficients are supplied by reciprocity:

\[
x_{d-i}=x_i.
\]

Thus every prescribed vector

\[
(H_1,\ldots,H_m)=(a_1,\ldots,a_m)
\]

occurs from a reciprocal polynomial square of the required form.

## 4. Range of realizable patterns

The range is the full affine space:

\[
(H_1,\ldots,H_m)\in k^m.
\]

In particular one may prescribe

\[
H_i=0
\]

on any chosen subset

\[
S\subseteq\{1,\ldots,m\}
\]

and choose arbitrary nonzero values elsewhere.

Therefore any clustered zero configuration among the first half of coefficients is realizable. For example, a block

\[
H_r=H_{r+1}=\cdots=H_{r+s-1}=0
\]

with arbitrary prescribed neighboring coefficients can be forced.

Because the polynomial is reciprocal, the corresponding mirrored coefficients appear at the opposite end. The first-half construction automatically gives the reflected cluster:

\[
t^dH(t^{-1})=H(t)
\]

(up to the predictable factor contributed by \(\Delta^\epsilon\), which is itself reciprocal).

Hence a short zero window near one side has a matching reflected window.

## 5. Consequence for P32

The desired P32 short-window principle is a statement about the actual Apéry/Hasse polynomial attached to the arithmetic object. It is not a formal consequence of:

1. reciprocity of the Hasse polynomial;
2. being a square (or discriminant times a square);
3. odd characteristic.

Those conditions leave the first \(m\) coefficients completely free.

The obstruction is deterministic:

\[
\text{Hasse square + reciprocity}\not\Rightarrow\text{restricted short zero windows}.
\]

Any proof of the actual short-window principle must use additional arithmetic structure of the genuine vector

\[
(x_1,\ldots,x_m)
\]

coming from the Apéry recurrence, Frobenius representation, or related monodromy/geometry.

## 6. Important distinction: abstract family versus actual \(B_p\)

The construction above produces a large abstract family of reciprocal squares. It proves only a no-go statement about what can be deduced from the algebraic shape alone.

It does **not** imply that the actual Hasse polynomial \(B_p\) for a given prime \(p\) realizes arbitrary coefficient patterns. The arithmetic vector

\[
(x_1(p),\ldots,x_{d-1}(p))
\]

is a single special point in this affine family, constrained by:

- Frobenius compatibility;
- the Apéry recurrence;
- geometric origin of the associated motive/curve;
- additional congruence and distribution properties.

Therefore the correct conclusion is:

> Hasse squareness and reciprocity provide no deterministic coefficient exclusion. Any P32 short-window theorem must exploit arithmetic information distinguishing the actual Apéry Hasse polynomial from the full reciprocal-square parameter space.
