# Q1144: small-prime Padé/Newton valuation attack

## Verdict

The remaining implication

\[
\min_{j<M}(v_p(L_j(n))+v_p(b_j))=\min_{j<M}(v_p(L_j(n))+v_p(b_n-b_j))
\]

for every odd prime \(p\ge5\) with \(p^2\le n\) is not proved here. The known large-prime argument does not descend automatically because the minimizing index can move between base-p digit classes. No counterexample is produced.

The strongest rigorous reduction obtained from the available facts is the following.

## Carry decomposition

Write

\[
n=\sum_i n_i p^i,\qquad j=\sum_i j_i p^i.
\]

Kummer gives

\[
v_p\binom nj=C_1(n,j),
\]

where \(C_1\) is the number of carries in the digit addition \(j+(n-j)=n\).

For the second binomial,

\[
v_p\binom{n-j-1}{M-1-j}=C_2(n,j),
\]

where \(C_2\) is the number of carries in

\[
(M-1-j)+(n-M)=n-j-1.
\]

Therefore

\[
v_p(L_j)=C_1(n,j)+C_2(n,j).
\]

Any comparison of the two gcd valuations must therefore preserve both carry processes simultaneously.

## Apéry contribution

Lucas gives

\[
b_n\equiv\prod_i b_{n_i}\pmod p.
\]

Hence if some digit \(n_i\) satisfies \(b_{n_i}\equiv0\pmod p\), then \(p\mid b_n\). This explains why the previously proved large-prime case works: the digit length is too short for competing carry patterns.

For the small-prime range, however, the candidate minimizing \(j\) may have nontrivial higher digits and the term

\[
b_n-b_j
\]

is controlled by the first differing digit together with the derivative correction in the congruence

\[
b_{pN+r}=b_N(b_r+2\epsilon(r)NpD_s)\pmod {p^2}.
\]

The unresolved case is exactly when the leading Lucas factor vanishes and the derivative correction is needed.

## New intermediate lemma obtainable

A useful conditional lemma is:

**Lemma.** Suppose a minimizing index \(j\) for \(\Gamma_n\) has all base-p digits below the first zero digit of \(b_n\) equal to the corresponding digits of \(n\). If the first differing digit \(r\) satisfies

\[
b_r\not\equiv0\pmod p,
\]

then the same carry class gives a D-witness with equal valuation.

**Reason.** At the first differing digit the Apéry Lucas factor is a unit, so the difference \(b_n-b_j\) has the same p-adic order as the corresponding Apéry factor in \(b_j\). The Newton carry contribution is unchanged because the two Kummer carry streams have the same prefix and only the unit digit branch changes.

The missing digit configurations are therefore exactly those where the first differing digit lies in

\[
\{r: b_r\equiv0\pmod p\}
\]

and the derivative term \(2\epsilon(r)NpD_s\) controls the first nonzero coefficient.

## Exact verification code

```python
from math import comb
from math import gcd


def apery(n):
    return sum(comb(n,k)**2*comb(n+k,k)**2 for k in range(n+1))


def vp(x,p):
    x=abs(x)
    c=0
    while x and x%p==0:
        c+=1
        x//=p
    return c


def L(n,j):
    M=n//2
    return (-1)**(M-1-j)*comb(n,j)*comb(n-j-1,M-1-j)


def scan(limit=1200, primes=(5,7,11,13,17,19,23)):
    bad=[]
    b=[apery(i) for i in range(limit+1)]
    for n in range(4,limit+1):
        M=n//2
        for p in primes:
            if p*p>n:
                continue
            g=min(vp(L(n,j)*b[j],p) for j in range(M))
            d=min(vp(L(n,j)*(b[n]-b[j]),p) for j in range(M))
            if g!=d:
                bad.append((p,n,g,d))
    return bad

print(scan())
```

This code checks the proposed pattern exactly; a positive result is only finite evidence.

## Remaining infinite obstruction

The unresolved class is:

* primes \(p\ge5\);
* numbers \(n\) with at least one base-p digit \(r\le(p-1)/2\) satisfying \(p\mid b_r\);
* minimizing Newton indices whose first digit deviation occurs inside that zero set;
* cases where the derivative coordinate \(D_s\) also vanishes modulo \(p\), forcing depth \(p^3\) information.

A complete proof requires a nonvanishing statement for the folded derivative tower or a descent showing that a minimal bad digit pattern produces a strictly smaller high part. Neither follows from the current congruence modulo \(p^2\) alone.
