# Q774: fixed-q first-jet attack on the normalized Apéry carrier

## 1. Setup and notation

Write

```
T_k(n) = binom(n,k) binom(n+k,k),
D_qn = sum_{k=0}^J T_k(n)^2,
B_qn = T_A(n),
A=J+1.
```

In the fixed-q window we have

```
n=qp+r, 0<=r<p, p>sqrt(n),
J=floor((n-q)/(2q+1)) < p.
```

Hence every binomial occurring in the sum has lower index strictly smaller than p. The relevant calculation is therefore a genuine p-adic expansion of each summand, not a division of a congruence modulo p.

The first important point is that the target hypothesis `p | b_r` only says that the Lucas residue of the terminal Lucas block vanishes. It does not automatically force a second characteristic-zero congruence.

## 2. First jet of the Apéry summand

For fixed k<p, put

```
b_k = binom(r,k) binom(r+k,k).
```

If k<=r, expanding the two binomial factors with n=qp+r gives

```
binom(qp+r,k)
 = binom(r,k) * (1 + qp * H_1(r,k)) mod p^2,
```

where

```
H_1(r,k)=sum_{i=0}^{k-1}(1/(r-i)-1/(k-i))
```

is interpreted in F_p. Similarly

```
binom(qp+r+k,k)
 = binom(r+k,k) * (1 + qp * H_2(r,k)) mod p^2,
```

with

```
H_2(r,k)=sum_{i=1}^{k}(1/(r+i)-1/i).
```

Therefore

```
T_k(n)=b_k(1+qp h_k) mod p^2,
```

where

```
h_k=H_1(r,k)+H_2(r,k).
```

Consequently

```
T_k(n)^2 = b_k^2 + 2qp b_k^2 h_k mod p^2.
```

This is the exact first jet for all non-pivot terms k<=r.

For k>r, write k=r+s. Then Lucas gives

```
v_p(T_k(n))>=1,
```

and the first nonzero term is the corresponding carry jet. More explicitly one obtains

```
T_{r+s}(n)=p*c_{r,s} mod p^2,
```

where c_{r,s} is the product of the two carry binomial factors times the quotient of the unique p-containing factorial ratio. Hence

```
T_{r+s}(n)^2 = 0 mod p^2.
```

Thus only k<=r contributes to D_qn/p modulo p.

## 3. Exact formula for D_qn/p mod p

Assume the target condition

```
b_r=0 mod p.
```

Since k=r is the only possible terminal nonzero Lucas block and its square is p^2-small after the target cancellation, the normalized value is

```
D_qn/p
 = (1/p) * sum_{k=0}^{r-1} T_k(n)^2 + first-jet contribution of k=r
       mod p.
```

Substituting the expansions gives the explicit formula

```
D_qn/p
 = sum_{k=0}^{r-1} (2q b_k^2 h_k)
   + 2q b_r^2 h_r/p
   + carry correction
   mod p.
```

The middle expression is zero in the target case because b_r is already divisible by p. Therefore the clean target-only formula is

```
D_qn/p mod p
 = 2q * sum_{k=0}^{r-1} b_k^2 h_k + C_q(n,r)
 mod p,
```

where C_q(n,r) is the explicit finite carry correction from the k>r terms. There is no dependence on a mysterious global Apéry identity: it is a finite truncated Apéry first jet.

## 4. Direct and reflected branches

The two branches only change which Lucas block supplies the p-factor in B.

### Direct branch

Here

```
p=(n-r)/q.
```

The unique p-factor is in the factor

```
(qp+r-k+1)...(qp+r-k)
```

of binom(n,A). The quotient B/p modulo p is the unit

```
B/p = (-1)^A * q * A!^{-2} * product_{i=0}^{A-1}(r-i)
       * product_{i=1}^{A}(r+i)
 mod p
```

after removing the single zero factor. Therefore

```
(D_qn/p)/(B_qn/p)
 = [2q sum_{k<r} b_k^2 h_k+C_q(n,r)] / U_D
 mod p,
```

where U_D is the above unit.

### Reflected branch

Here

```
p=(n+1+r')/(q+1)
```

for the reflected residue r'. The same calculation holds with the second binomial carrying the p-factor. The denominator unit is

```
B/p = U_R mod p,
```

where U_R is obtained by removing the unique zero factor from

```
prod_{i=1}^{A}(qp+r+i)/i.
```

Again

```
(D_qn/p)/(B_qn/p)= (explicit first jet)/(U_R) mod p.
```

The direct/reflected distinction therefore changes only the unit normalization, not the numerator mechanism.

## 5. Does targetness produce a smaller carrier?

No universal second congruence appears.

The tempting statement would be

```
p | b_r  ==>  D_qn/p = 0 mod p
```

or a similar characteristic-zero relation. The first-jet computation shows why this is unlikely:

```
D_qn/p mod p = 2q sum_{k<r} b_k^2 h_k + C_q(n,r).
```

The right side involves all lower Apéry coefficients and harmonic weights. The condition

```
b_r=0 mod p
```

only constrains the top Lucas coefficient. It does not force the weighted lower sum to vanish.

A smaller carrier would require an additional identity of the form

```
sum_{k<r} b_k^2 h_k = algebraic expression depending only on b_r,
```

or a new characteristic-zero Apéry differential equation evaluated at the special residue. No such identity follows from Lucas theory alone.

## 6. Numerical verification protocol

The correct verification is to compute modulo p^2:

```python
for fixed q,n,p:
    T = [binom(n,k)*binom(n+k,k) for k in range(J+1)]
    assert D % p == 0
    lhs = (D//p) % p
    rhs = first_jet_formula(q,n,r) % p
    assert lhs == rhs
```

The division is performed after computing the integer D modulo p^2 (or the exact integer), never after replacing D by a mod-p congruence.

## Conclusion

The first-jet attack succeeds in identifying the exact normalized residue: it is a finite weighted truncated Apéry sum plus an explicit carry term. The target condition p|b_r kills the terminal Lucas block but does not create a second vanishing congruence. Therefore the normalized ratio

```
(D_qn/p)/(B_qn/p) mod p
```

is an explicit unit-sensitive first-jet invariant, not a new universal smaller carrier.
