# Q1067 audit: exact gcd ratio node

## Scope and verdict

This audit separates three levels:

1. exact identities following from the definitions;
2. finite computational evidence;
3. statements requiring a new p-adic theorem.

The reported valuation formula through `n=1200` is evidence only. It is not a proof of the ratio formula.

The surviving rigorous part is the content comparison identity. The claimed exact prime-power formula remains an open local lemma.

## 1. Is Gamma exactly the old content?

With

\[
L_j=(-1)^{M-1-j}{n\choose j}{n-j-1\choose M-1-j},\qquad M=\lfloor n/2\rfloor,
\]

and

\[
\Gamma_n=\gcd_{j<M}(L_j b_j),
\]

this is the same normalization as the Dwork/content construction only if the old node uses:

* the identical cutoff `j<M`;
* the same binomial coefficient normalization;
* the same Apéry denominator numerator convention for `b_j`;
* no additional factor removed from the coefficients `L_j`.

A change of normalization by a common factor in all `L_j` changes both contents but can change the displayed quotient. Therefore the equality must be checked from the actual source definitions, not inferred from the notation.

## 2. Exact computation

A complete verification script must compute the Apéry values, the coefficients, and gcds with arbitrary precision integers. The following is a self-contained implementation.

```python
from math import comb, gcd


def apery(n):
    return sum(comb(n,k)**2 * comb(n+k,k)**2 for k in range(n+1))


def coeffs(n):
    M=n//2
    out=[]
    for j in range(M):
        L=(-1)**(M-1-j)*comb(n,j)*comb(n-j-1,M-1-j)
        out.append(L)
    return out


def content(vals):
    g=0
    for x in vals:
        g=gcd(g,x)
    return abs(g)


def ratio(n):
    M=n//2
    b=[apery(i) for i in range(n+1)]
    L=coeffs(n)
    Gamma=content([L[j]*b[j] for j in range(M)])
    D=content([L[j]*(b[n]-b[j]) for j in range(M)])
    return D//Gamma, Gamma, D


def v_p(x,p):
    r=0
    while x%p==0 and x:
        r+=1
        x//=p
    return r


for n in range(2,200):
    q,_,_=ratio(n)
    print(n,q,v_p(q,2),v_p(q,3))
```

This verifies finite cases only. It does not establish the valuation pattern.

## 3. Corpus/theorem audit

The old Q888-style argument establishes a radical/content direction: a linear combination with coefficients summing to one can force divisibility by the relevant content.

However, the missing step is prime-power control. Knowing

\[
\Gamma_n\mid b_n
\]

does not determine

\[
v_p(D_n/\Gamma_n).
\]

The open statement is the stronger local assertion:

\[
v_p(D_n)=v_p(\Gamma_n)+e_p(n)
\]

with the proposed explicit values of `e_p(n)`.

A radical statement controls the set of primes. It does not control their exponents.

## 4. Hostile audit of the exponent formula

The proposed formula predicts:

\[
v_2(D_n/\Gamma_n)=
\begin{cases}
2,& n=2^a-1,\\
\min(5,2+\operatorname{leading\_one\_run}(n)),&\text{otherwise}.
\end{cases}
\]

and

\[
v_3(D_n/\Gamma_n)=1
\]

only for `n=2*3^a` or `2*3^a+1`.

The necessary hostile checks are:

* `n=2,3,4` where the cutoff has one or two terms;
* all `n=2^a-1` endpoints;
* transitions where the leading-one run changes;
* all proposed 3-adic exceptional endpoints.

Finite agreement through `1200` is not a proof. No counterexample follows without an exact larger computation. The statement should therefore remain classified as:

**finite evidence, not theorem.**

## 5. Consequences if the ratio theorem is proved

Assume the claimed formula is eventually proved and `sum_j L_j=1` holds.

The Padé relation gives

\[
\sum_j L_jb_j=b_n.
\]

Since every term on the left is divisible by `Gamma_n`,

\[
\Gamma_n\mid b_n.
\]

For every prime `p>=5`, the claimed ratio has zero valuation, hence

\[
v_p(D_n)=v_p(\Gamma_n).
\]

Therefore all primes at least five contribute identically to the two contents. The quotient contains only the bounded 2 and 3 parts, so

\[
\log D_n=\log\Gamma_n+O(1)
\]

provided the exceptional local factors remain bounded as claimed.

Thus the height nodes are equivalent up to an additive constant.

## 6. Minimal missing lemma

The exact theorem needed is not a generic CRT statement. It is an Apéry-specific local lemma:

For each prime `p`, prove a valuation formula for

\[
\gcd_j L_j(b_n-b_j)
\]

relative to

\[
\gcd_j L_jb_j.
\]

The 2-adic part requires an induction on the binary expansion of `n`, likely through the Apéry recurrence modulo powers of two and the binomial coefficient structure of `L_j`.

The 3-adic part requires an analogous induction on the ternary exceptional families.

Until those two local lemmas are proved, the exact set `{4,8,12,16,24,32,48,96}` is an observed pattern, not a theorem.
