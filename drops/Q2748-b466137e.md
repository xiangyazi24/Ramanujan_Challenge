# 2. The exact fixed-height Padé statement

Q2584 supplies the following one-height setup. Put

```text
tau(s) = s(s+1),
Phi_A(tau(s)) = binom(s+A,2A).
```

For a fixed height `K`, the jointly primitive numerators satisfy a fraction-free terminal identity

```text
sum_(a=0)^A c_(K,A,a) P_(K,a)(Y)
  = d_(K,A) Phi_A(Y),

gcd(c_(K,A,0),...,c_(K,A,A),d_(K,A)) = 1.
```

At an integral evaluation point `y`, define

```text
G_(K,A)(y) = gcd_(0 <= a <= A) P_(K,a)(y).
```

Then exactly

```text
G_(K,A)(y) | d_(K,A) Phi_A(y).
```

This is the strongest unconditional divisibility supplied by the fixed-height Euclidean descent.

## 2.1 Correct universal-factor saturation

From

```text
G | d Phi
```

one may remove the `Phi` valuation prime by prime. Define

```text
v_l(G^res)
  = max(v_l(G) - v_l(Phi), 0).
```

Equivalently, `G^res` is obtained by saturating `G` by the complete prime-power support of `Phi`, not by merely dividing once by a squarefree candidate product. Then

```text
G^res | d.
```

Q2740 introduces an object `overline G` described only as the result after removing “the universal Newton/binomial factor.” Unless `overline G` is defined by the valuation formula above, its displayed divisibility by `d` is not a theorem.

**Verdict on the fixed-height Euclidean identity: ACCEPT.**

**Verdict on Q2740 equation (1.5) as written without an exact saturation: REJECT.**

# 4. Union of height supports is not a height gcd

Let `C_K` be any local integer at height `K`, and let

```text
S_p = {K : p | C_K}.
```

Then

```text
p | gcd_K C_K  iff  S_p is the entire height interval,
p | lcm_K C_K  iff  S_p is nonempty.
```

The endpoint/full-rectangle geometry is a coverage statement unless one proves otherwise: a target has one or more legal witness heights. Coverage is a union, hence an `lcm` operation.

The current connected multi-height theorem, Q1992, makes this explicit. It defines

```text
E_(K,a)
  = P_(K,a)(tau(K+1))
    - b_(K+1) Q_(K,a)(tau(K+1)),

R_K = gcd(E_(K,0),E_(K,1)),

F_K(n)
  = tau(n)-tau(K+1)
  = (n-K-1)(n+K+2),
```

and its support-complete window carrier is

```text
C_E(n;W)
  = lcm_(K in W) gcd(R_K, |F_K(n)|).
```

The theorem does not replace this lcm by a gcd. It proves that a target is retained at its revisit height.

Q2740's crucial assertion is stronger:

```text
p target on branch epsilon
  => p | d^epsilon_(K,A) for every K in [H0,U-1].
```

No connector-visible file proves it.

**Verdict on Q2740 equations (2.2), (3.1), and especially (3.3) as target-support theorems: REJECT.**

The definitions are formally legal once `d^epsilon` exists, but their claimed support is not.

# 6. Audit of the prefix-tail divisor

Q2584 states, for one unbranched height `K`,

```text
Dtail_(K,A)
  = product_(ell > K+A)
      ell^( max_(A <= s <= K) v_ell(b_s) )
  | d_(K,A).
```

Equivalently,

```text
Dtail_(K,A)
 = Sat_((K+A)!) lcm(b_A,...,b_K).
```

## 6.1 Single-height claim

Assuming the Q2584 proof and its normal-table hypotheses, this is correctly normalized: `d_(K,A)` is the primitive terminal Smith denominator, not a raw determinant.

**Verdict: ACCEPT for the one unbranched `d_(K,A)`.**

## 6.2 Passage to the rectangle gcd

Let

```text
H0 <= K <= U-1
```

and define the proposed common tail

```text
Dtail_rect
 = product_(ell > U-1+A)
     ell^( max_(A <= s <= H0) v_ell(b_s) ).
```

For every such `K`:

```text
ell > U-1+A >= K+A,
A <= s <= H0 <= K.
```

Therefore

```text
max_(A <= s <= K) v_ell(b_s)
  >= max_(A <= s <= H0) v_ell(b_s),
```

so

```text
Dtail_rect | Dtail_(K,A) | d_(K,A)
```

for every `K`. Hence

```text
Dtail_rect | gcd_(H0 <= K <= U-1) d_(K,A).
```

This elementary divisibility is correct.

**Verdict: ACCEPT as a conditional deduction from the one-height tail theorem.**

## 6.3 Passage to two branches

If the branches differ only in evaluation, the two Smith denominators are equal and the preceding statement applies once, not twice. If their coefficient lattices differ, the branchwise tail theorem is unproved.

**Verdict on Q2740 equation (4.4) with `epsilon`: REJECT as an established branchwise theorem.**

## 6.4 The common tail is not target-complete

Return to `n=321,q=1`. Here

```text
A = ceil(106^(2/3)) = 23,
U-1+A = 159+23 = 182.
```

The common tail contains only primes strictly larger than `182`. The genuine target `179` is therefore absent from the alleged prefix-tail divisor. More concretely, its reflected zero index is `36`, but for the top heights `K>=156` the hypothesis

```text
179 > K+A
```

fails, so the Q2584 tail theorem does not force `179` into every `d_(K,A)`.

Thus even after accepting the conditional common-tail divisibility, an additional theorem is required for the boundary target primes.

**Verdict on using the prefix tail to prove full support of `R_q(n)`: REJECT.**

# 10. Correct reconstruction of a rectangle carrier from current formulas

Without a new all-height theorem, the set-theoretically correct construction is height-local.

For every branch and height, define the actual residual family gcd by exact valuation saturation:

```text
v_l(C^epsilon_K)
 = max(
     v_l(G^epsilon_(K,A)(y^epsilon_(n,q)))
     - v_l(Phi_A(y^epsilon_(n,q))),
     0
   ).
```

Then the Euclidean identity implies

```text
C^epsilon_K | d^epsilon_(K,A)
```

whenever the branch-specific terminal identity has actually been proved.

A union of legal height/branch witnesses is represented by

```text
C_union_(n,q,A)
 = lcm_(epsilon in {+,-})
     lcm_(H0 <= K <= U-1) C^epsilon_K.
```

This is support-correct under an existence-of-witness theorem. It may have unacceptable height; that is a separate problem. Replacing either inner lcm by a gcd is permissible only after the all-height lemma below.

The current Q1992 carrier is a sharper instance of exactly this pattern because it additionally intersects each local residual with the low-height external-node factor `F_K(n)` before taking the lcm.

# 11. The smallest valid new lemma

The first missing statement is local, prime-by-prime, and contains no Archimedean height claim.

## ALL-HEIGHT-RESIDUAL-SURVIVAL(`q`)

Fix `q`, `n`,

```text
H0 = floor((n-q)/(2q+1)),
U  = floor(n/(q+1)),
A  = ceil(H0^(2/3)).
```

Let `p` be a safe target prime, let `epsilon(p)` be its actual oriented branch, and let

```text
G^epsilon_(K,A)(n,q)
 = gcd_(0 <= a <= A)
     P^epsilon_(K,a)(y^epsilon_(n,q))
```

be the **actual** jointly primitive branch family gcd. Then prove, for every

```text
H0 <= K <= U-1,
```

the exact valuation inequality

```text
v_p(G^epsilon_(K,A)(n,q))
  >
 v_p(Phi_A(y^epsilon_(n,q))).
```

Equivalently, the prime survives complete removal of the universal Newton factor at every legal height:

```text
p | C^epsilon_K.
```

Once the branch terminal identity is fixed, this implies

```text
p | d^epsilon_(K,A)
```

for every legal `K`, and only then does

```text
p | gcd_K d^epsilon_(K,A)
```

follow.

This is the smallest valid new lemma because:

1. it is strictly weaker than any `o_q(n)` height theorem;
2. it is not a renamed version of `R_q(n)`;
3. it is exactly the missing implication used in Q2740 equation (3.3);
4. it is machine-checkable from the actual primitive family values and the exact universal factor;
5. it separates support from height cleanly.

Before proving it, the local write-up must also decide whether the two branch coefficient matrices are identical. If they are, delete the superscript from `d`; if they are not, state and prove their terminal identities and Smith normalizations separately.
