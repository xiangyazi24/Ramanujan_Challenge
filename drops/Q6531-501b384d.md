# Beukers modular parametrization audit (P3.2)

## Executive verdict

The requested explicit formulas split into three levels.

1. The Hauptmodul/eta parametrization is standard and can be written explicitly, but normalization differs between Beukers, Almkvist-Zudilin, and later Apéry/K3 papers.
2. The homogeneous Apéry solution is genuinely modular. The companion solution is not another modular form of the same type: it is a mixed extension object (normal function / Eichler-integral type object). I do not know a published closed eta formula for it.
3. The congruence kappa_p == -2 zeta_p(3) mod p is compatible with p-adic regulator interpretations, but I do not find a theorem identifying this exact constant with a Kubota-Leopoldt value in the Beukers parametrization. The safe interpretation is syntomic/K-theoretic, not classical Dirichlet p-adic L-value.

# 1. Characteristic-zero modular parametrization

## 1.1 Hauptmodul

A convenient normalization is the one in which the Apéry differential equation has singularities

```
t = 0, 1, infinity
```

and the mirror map is expanded at the cusp q=exp(2*pi*i*tau)=0.

The modular curve is the Fricke quotient X_0(6)+. A standard Hauptmodul is

```
t(tau) = (eta(tau) eta(6tau) / (eta(2tau) eta(3tau)))^12
```

up to the Möbius transformation required to send the chosen cusp to t=0.

Warning: Beukers' 1987 normalization uses a different coordinate. The above is the commonly used eta-quotient coordinate; the Apéry variable is obtained from it by a rational fractional-linear change.

The eta quotient is weight zero because the eta exponents sum to zero.

## 1.2 The Apéry period

Let

```
B(t) = sum_{n>=0} b_n t^n.
```

Then Beukers identifies B(t) with a weight-two modular form evaluated at the modular parameter:

```
B(t(tau)) = F(tau) / Phi(tau)
```

where F is a weight-two eta/theta expression and Phi is the modular pullback factor from the chosen Hauptmodul normalization.

The invariant statement is:

```
B(t(tau)) dt/dtau
```
is a weight-four modular differential on X_0(6)+.

This is the normalization-independent form.

Reference:

A. Beukers, "Irrationality proofs using modular forms", in Journées Arithmétiques de Besançon (1985), Astérisque 147-148 (1987), especially the Apéry sections. The paper gives the modular parametrization but does not use the later eta-normalizations uniformly used today.

For the K3 interpretation:

F. Beukers and C. Peters, "A family of K3-surfaces and ζ(3)", J. Reine Angew. Math. 351 (1984), 42-54.

The Picard-Fuchs operator is the Apéry operator.

# 2. Companion solution C(t)

Let

```
L B = 0,
L C = t.
```

The second equation means C is not a period of the same pure variation. It belongs to an extension

```
0 -> H -> E -> Q(0) -> 0
```

rather than to H itself.

After substituting t=t(tau), write

```
Y(tau)=C(t(tau)).
```

If

```
D_tau = (dt/dtau)^(-1) d/dtau,
```

then the pulled-back equation is exactly

```
L_tau Y = t(tau),
```

where L_tau is obtained from the Picard-Fuchs operator by replacing every d/dt by D_tau.

The boundary condition at the MUM cusp is:

```
Y(tau)=c_1 t(tau)+c_2 t(tau)^2+...
```

with no logarithmic term in the chosen Frobenius solution.

## Eichler integral candidate

The natural candidate is not an eta product but an Eichler integral.

If f is the weight-four modular form corresponding to the Apéry period, then a primitive

```
Integral f(tau)(tau-z)^2 d tau
```

is the expected object. Differentiating three times returns f.

Equivalently C(t(tau)) should be expressible as a linear combination of:

```
Eichler integral of f
+ elementary logarithmic/quasimodular correction terms.
```

I do not know a published closed formula identifying the exact Apéry C with one named Eichler integral.

# 3. The p-adic constant kappa_p

The verified congruence

```
kappa_p == -2 zeta_p(3) mod p
```

should not immediately be read as a Kubota-Leopoldt value.

The safer interpretation is:

```
Apéry K3 motive
    -> syntomic regulator / crystalline extension class
    -> finite-field reduction
    -> p-adic zeta value
```

The companion solution is exactly the kind of object where regulator classes appear.

Relevant references:

- F. Vologodsky / Besser syntomic regulator theory: syntomic cohomology explains why extension classes produce p-adic polylogarithmic constants.
- M. Asakura, works on p-adic polylogarithms and regulators of K3 surfaces, especially the Apéry-type examples.
- V. Vlasenko and F. Beukers, works on Dwork crystals and zeta values.

However:

I cannot cite a theorem of the form

```
kappa_p = explicit Kubota-Leopoldt L_p(3,chi)
```

for this exact Apéry extension. That identification would be stronger than the currently standard regulator interpretation.

# 4. What this says for the mod-p orbit question

The modular parametrization does NOT currently give a Heegner collision criterion.

Reason:

The orbit

```
pi(n)=[b_n:c_n] mod p
```

is an index-by-coefficient object in a Frobenius/crystalline module. It is not naturally the sequence of reductions of points on X_0(6)+.

A Heegner point is a geometric point of a modular curve satisfying a CM condition. Here the collision

```
pi(r)=pi(r+h)
```

means a linear dependence of two Frobenius solutions at two coefficient indices.

That is a recurrence/F-crystal statement, not an isogeny-class statement on X_0(6).

Therefore Duke-type equidistribution does not directly apply.

# 5. Answers to required uncertainty questions

## (a) Least certain step

The least certain part is the exact normalization dictionary between:

```
Beukers' eta quotient coordinate
modern X_0(6)+ Hauptmodul coordinate
Apéry t-variable
```

The invariant modular statements are reliable; the displayed eta quotient requires checking the exact fractional-linear normalization against the chosen t.

## (b) Shared blind spot

The likely shared blind spot is confusing three different objects:

1. characteristic-zero modular periods;
2. p-adic Frobenius/crystalline extensions;
3. finite-field recurrence trajectories.

The first two are related by deep comparison theorems. The third requires an integral Frobenius-compatible model. Without that bridge, modular parametrization does not automatically solve the collision-energy problem.

## Final project verdict

The modular route gives valuable conceptual identification of B and C, and explains why zeta_p(3) appears. It does not presently replace the missing energy theorem.

The missing theorem would be:

```
A Frobenius-compatible integral realization of the Apéry extension in which
collision pi(r)=pi(r+h) becomes a geometric special-cycle condition.
```

No such theorem is currently available in the required form.
