# Automata theory and the Apéry zero set: what it can and cannot prove

## Executive verdict

The automata viewpoint is structurally correct and useful, but it does **not** by itself solve LGTQ-3. The obstruction is exactly the same one appearing in other routes: the automaton is excellent for understanding the zero set for a **fixed prime p**, while the conjecture requires controlling a diagonal family of automata with the base changing together with the prime.

The strongest conclusion is:

* Lucas gives a genuine p-automatic description of the full zero set in all digit lengths.
* Cobham-type theorems do not apply because there is no single sequence automatic in two fixed multiplicatively independent bases.
* Normality of n is not enough for the all-n theorem because the exceptional n problem is a maximum problem, not an average digit-frequency problem.
* The right formulation is a cross-prime digital sieve problem.

No existing automatic-sequence theorem appears to improve the unconditional |Z_p| = O(p^{2/3}) bound or prove LGTQ-3.

---

# 1. The Lucas automaton is real, but it is a fixed-p object

For

\[
d=d_0+d_1p+\cdots+d_kp^k,
\]

Gessel's congruence gives

\[
b_d\equiv \prod_i b_{d_i}\pmod p.
\]

Therefore

\[
b_d\equiv0\pmod p
\]

if and only if at least one digit belongs to

\[
F_p=Z_p^{(1)}=\{0\le r<p:b_r\equiv0\pmod p\}.
\]

Hence the language

\[
\{d\ge0:b_d\equiv0\pmod p\}
\]

is p-automatic.

The minimal automaton is essentially a two-state automaton:

* NONZERO: no forbidden digit has appeared;
* ZERO: a forbidden digit has appeared.

This gives the exact count

\[
\#\{d<p^k:b_d\equiv0\pmod p\}
=p^k-(p-|F_p|)^k.
\]

Equivalently the density is

\[
1-(1-|F_p|/p)^k.
\]

This is a strong structural statement, but it concerns numbers up to p^k in one fixed base.

---

# 2. Why Cobham's theorem does not apply

Cobham's theorem says roughly:

> A sequence which is automatic in two multiplicatively independent fixed bases must be ultimately periodic.

The Apéry situation is different.

For every prime p we have a different sequence

\[
f_p(n)=1_{b_n\equiv0\ (p)}.
\]

It is p-automatic, but the base is changing:

\[
f_5\text{ is 5-automatic},
\quad f_7\text{ is 7-automatic},
\quad f_{11}\text{ is 11-automatic},\dots
\]

There is no single sequence which is simultaneously p-automatic and q-automatic.

The desired quantity

\[
1_{n\bmod p\in F_p}
\]

is not a second automatic representation of the same sequence. It is a family of unrelated automata queried at their own bases.

Therefore Cobham-Semenov theory does not directly constrain

\[
\sum_{p>\sqrt n}1_{n\bmod p\in F_p}.
\]

---

# 3. The multi-base correlation problem

The real object is

\[
S(n)=\sum_p1_{n\bmod p\in F_p}.
\]

Each summand is a digital condition in base p.

The problem is therefore:

> Given one integer n and a collection of changing bases p, how often does the final digit of n in base p fall into a prime-dependent forbidden set?

This is closer to a large sieve problem than an automatic-sequence problem.

The automata describe the forbidden sets. They do not describe correlations between different bases.

The missing theorem would look like:

\[
\max_n\sum_{p\in(X,2X]}1_{n\bmod p\in F_p}=o(X/\log X).
\]

That is a quenched cross-prime anti-concentration statement.

---

# 4. Comparison with Mauduit-Rivat type digital methods

Digital methods have succeeded for sequences such as:

* Thue-Morse;
* sum-of-digits functions;
* Gelfond type digit phases.

The common feature is that the digit function is fixed:

\[
s_2(n),\quad (-1)^{s_2(n)},\dots
\]

and one studies it along primes or polynomial sequences.

Here the situation is reversed.

The sequence changes with p:

\[
F_p\subset\{0,\dots,p-1\}.
\]

There is no fixed digit function.

A Mauduit-Rivat style argument would require exponential sum estimates of the form

\[
\sum_{p\sim X}e(\alpha(n\bmod p))
\]

with a phase depending on the Frobenius data of p.

No current digital theorem provides this.

---

# 5. Normal numbers: why density-one is easy but all-n is hard

For a fixed base p, normality suggests that digits are random.

The last digit of n in base p is simply

\[
n\bmod p.
\]

If n behaves randomly modulo p, then

\[
\Pr(n\bmod p\in F_p)\approx |F_p|/p.
\]

Since empirically

\[
|F_p|\approx1,
\]

we get expected contribution

\[
\sum_{p\in(\sqrt n,n)}\frac{|F_p|}{p}\approx O(1).
\]

This explains why the density-one theorem is natural.

However normality controls almost every n. The conjecture requires every n.

The difference is exactly the difference between:

\[
\mathbb E S(n)=O(1)
\]

and

\[
\max_n S(n)=o(n/\log n).
\]

A sparse set of abnormal integers can destroy an all-n theorem.

---

# 6. Forbidden digit sets and p-adic digit restriction literature

The analogy with digit-restricted integers is real:

\[
D_p=\{n:n\bmod p\notin F_p\}
\]

is a large set of allowed digits.

But classical digit restriction results fix the base.

For example, one studies:

\[
\text{digits of squares in base }10.
\]

Here the base is the prime itself and changes with the modulus.

The family

\[
(F_p)_p
\]

has no uniform automaton complexity bound.

Indeed the first-level automaton already has p-dependent alphabet size.

Therefore standard fractal/digital dimension arguments do not apply.

---

# 7. The promising direction: combine Lucas with Frobenius data

The only route where automata may become decisive is if one can compress

\[
b_{n-p}\pmod p
\]

into Frobenius information attached to p.

For example, a formula of the shape

\[
b_{n-p}\equiv \Phi_p(n)\pmod p
\]

where \(\Phi_p\) depends only on a bounded amount of modular data at p would transform LGTQ-3 into a standard Frobenius equidistribution problem.

Possible sources:

* the weight-4 level-8 modular form attached to the Apéry K3;
* Dwork congruences;
* Cartier-Manin matrices;
* Frobenius traces.

At present this conversion is not known.

Lucas gives digit factorization, but not enough Frobenius compression.

---

# 8. Can the maximum be controlled combinatorially?

A naive random model says:

\[
S(n)\sim\text{Poisson}(1).
\]

The maximum over n up to N would then be roughly

\[
\frac{\log N}{\log\log N}.
\]

This is already far below the required threshold.

The problem is proving that the Apéry events behave independently enough.

The automaton perspective helps identify the event:

\[
E_p(n)=\{n\bmod p\in F_p\}.
\]

But independence across p is exactly the missing arithmetic input.

---

# Final answers

## (1) Cobham theorem?

No direct application. The base changes with p, so there is no single multi-base automatic sequence.

## (2) Cobham-Semenov framework?

It explains why fixed-base structure is rigid, but does not control a family of p-dependent automata.

## (3) Mauduit-Rivat methods?

Conceptually related, but current methods require a fixed digital function. The Apéry forbidden digits vary with Frobenius.

## (4) Normal numbers?

They explain density-one behavior, not the all-n maximum.

## (5) Digit restriction theory?

The analogy is useful, but varying bases prevent direct transfer.

## (6) Is there a new combinatorial argument?

Not from automata alone. The missing ingredient is cross-prime decorrelation.

The best research direction is therefore not pure automata theory but:

\[
\boxed{\text{Lucas automaton} + \text{Frobenius/Cartier compression} + \text{large sieve over primes}.}
\]

If the Apéry K3 Frobenius data can replace the p-dependent forbidden digit sets by a bounded-complexity arithmetic object, then the automata viewpoint could become a route to LGTQ-3. Without that extra compression, it is a reformulation rather than a proof.
