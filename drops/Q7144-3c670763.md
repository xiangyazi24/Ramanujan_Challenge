# Prime-averaged distinguished-state hitting for short Apéry return chains

## Executive finding

I audited the current repository state at main commit
`a8159d911d92b2e5089d4cc8643f3b6f33b01827`.

The local continuant equations determine when four indices lie in one
projective fibre, but they do not distinguish which fibre is labelled `0` by
the fixed Apéry solution `b = (1,5)`. They are invariant under changing the
basis `(b,c)` of the two-dimensional solution space; the condition
`pi_x = 0`, equivalently `b_x = 0`, is not.

There is an exact `1/(p+1)` saving after averaging the target point in
`P^1(F_p)` or after averaging the solution basis. There is no known way to
de-randomize that artificial average to the fixed Apéry line. In particular,
none of the four proposed off-the-shelf mechanisms currently proves a `1/p`
saving:

* additive characters lead to complete sums with prefix depth `x` as large as
  `p` and no bounded-conductor realization;
* projective mixing would need a return-conditioned variance theorem, not
  marginal equidistribution of the orbit;
* the simultaneous short-gap root event is vertical resultant divisibility,
  not a Chebotarev Frobenius event;
* bilinear completion reduces to a long-prefix/short-continuant gcd average for
  which no level of distribution is known.

A precise diagonal-size projective large-sieve estimate would imply the
requested bound. It is stated in Section 3. A second, entirely
fixed-initial-data Type-II estimate is stated in Section 8. Neither estimate is
currently a theorem.

The strongest unconditional baseline remains

```text
sum over X<p<=2X of A_p
  <= sum over X<p<=2X of Z(p)
  << X^(8/5) / log X,
```

where `A_p` is the number of actual primitive off-center short chains. No
unconditional square-root average is claimed below.

## 1. Exact chain count and the role of primitivity

I follow `primitive_projective_prime_scan.cpp`. For `0 <= n < p`, put

```text
pi_n = [b_n : c_n] in P^1(F_p).
```

The pair never vanishes simultaneously. In the scanner's affine chart,
`pi_n = 0` exactly when `b_n = 0`.

Let `H_p = floor(sqrt(p))`. Let `S_p` be the set of starts `x` for which the
next three occurrences of the projective state `pi_x` are

```text
x+a,  x+a+b,  x+s,        s = a+b+c <= H_p,
```

with `a,b,c >= 2`, no centered adjacent pair, the gaps not all equal, and
`p` outside the structural carrier

```text
U_s = product over j<=s of (j! * b_j * V_{j+1}).
```

Thus the complete return-offset set in `[0,s]` is exactly
`{0,a,a+b,s}`. Define

```text
C_p(q) = number of x in S_p with pi_x = q,
M_p    = sum over q in P^1(F_p) of C_p(q) = |S_p|,
A_p    = C_p(0).
```

This is the exact scanner convention behind the repository's primitive
formal-chain census. If the question is read as including the all-equal or
carrier-supported pieces, those are separate lower-dimensional/exceptional
terms in the existing decomposition; the distinguished-state issue discussed
here is the generic piece.

Primitivity gives an important cap. The next three returns of a state are
unique, so a fixed index starts at most one primitive chain. Hence

```text
M_p <= p,
sum over X<p<=2X of M_p << X^2 / log X.                (1.1)
```

Every chain in `S_p` satisfies the necessary local equations

```text
N_a(x) = N_b(x+a) = N_c(x+a+b) = 0 mod p.              (1.2)
```

Because it is off-center, it also survives all three reflection-center
deflations. The converse is false: (1.2) does not exclude intermediate
returns, and one start may satisfy many gap triples in the low-degree
algebraic relaxation.

The computation in the repository illustrates the distinction. The
prime-first projective scan through `p <= 500000` found twenty primitive
off-center chains with `p > s^2`, including

```text
(p,x; a,b,c) = (128047,42375; 41,86,37),
p/s^2 = 4.760819...
```

and all twenty lie in nondistinguished fibres. The actual-zero census through
`p <= 5*10^6` found no off-center four-zero window of span at most `sqrt(p)`.

## 2. The exact artificial 1/p average

For each fixed prime,

```text
(1/(p+1)) * sum over q in P^1(F_p) of C_p(q)
  = M_p/(p+1).                                         (2.1)
```

Equivalently, let `g` range over `PGL_2(F_p)`. Replacing the solution basis by
`g(b,c)` applies the same projective transformation to every `pi_n`, preserves
all return patterns, and gives

```text
average over g of C_p(g^(-1) 0) = M_p/(p+1).           (2.2)
```

Thus the `1/p` heuristic is exact after an artificial target or basis average.
It does not control the one basis fixed by the initial data.

If the distinguished count equalled its artificial mean, (1.1) would give

```text
sum over X<p<=2X of M_p/(p+1) << X/log X,              (2.3)
```

which is much stronger than the requested target. The real issue is the
fixed-target discrepancy.

## 3. One exact intermediate estimate that closes the target

Define the projective chain-state variance

```text
V_p = sum over q in P^1(F_p) of
        ( C_p(q) - M_p/(p+1) )^2.                      (3.1)
```

Equivalently, if `R_p` denotes the number of ordered pairs of distinct
primitive chains having the same projective state, then

```text
V_p = M_p + R_p - M_p^2/(p+1).                         (3.2)
```

The natural prime-averaged hitting lemma is:

### Distinguished projective large sieve (DPLS)

```text
sum over X<p<=2X of V_p
  << X^o(1) * sum over X<p<=2X of M_p,                 (DPLS)
```

where each `S_p` uses the full ranges

```text
0 <= x < p,       a,b,c >= 2,       a+b+c <= floor(sqrt(p)).
```

This is a diagonal-size variance estimate: after subtracting uniform
projective mass, only the number of primitive chains remains.

It gives the desired exponent immediately. Since one term of `V_p` is the
term at `q=0`,

```text
A_p <= M_p/(p+1) + sqrt(V_p).
```

Therefore

```text
sum A_p
 <= sum M_p/(p+1)
    + sqrt( (# primes in (X,2X]) * (sum V_p) )

 << X/log X
    + sqrt( (X/log X) * ( X^o(1) * X^2/log X ) )

 << X^(3/2+o(1)) / log X.                              (3.3)
```

This is the requested exact intermediate estimate with all summation ranges
and the complete exponent calculation. In a genuinely bounded-conductor
family, a Deligne-type complete-sum bound followed by a large sieve for trace
functions or Frobenius classes is the standard technology one would try.
Here the bounded-complexity hypotheses fail.

## 4. Additive and multiplicative character detectors

Let

```text
w_p(x) = 1 if x is in S_p, and 0 otherwise,
S_p(t) = sum over 0<=x<p of w_p(x) * e_p(t b_x).
```

Additive orthogonality gives the exact identity

```text
A_p = M_p/p + (1/p) * sum over nonzero t in F_p of S_p(t).  (4.1)
```

The difference between `1/p` and `1/(p+1)` contributes only
`O(M_p/p^2)`.

A diagonal-size character estimate

```text
sum over X<p<=2X and nonzero t in F_p of |S_p(t)|^2
  << X^(1+o(1)) * sum over X<p<=2X of M_p              (4.2)
```

would also imply (3.3). Indeed,

```text
| sum_p (1/p) sum_{t!=0} S_p(t) |^2
 <= ( sum_p (p-1)/p^2 ) * ( sum_p sum_{t!=0} |S_p(t)|^2 ),
```

and the first factor is `O(1/log X)`.

The obstruction is exact under Parseval. Put

```text
nu_p(y) = number of x in S_p with b_x = y mod p.
```

Then

```text
sum over t in F_p of |S_p(t)|^2
  = p * sum over y in F_p of nu_p(y)^2,                (4.3)
```

while the zero-frequency term is `M_p^2`. Thus (4.2) asserts that,
after subtraction of uniform mass, collisions

```text
b_x = b_x' mod p,       x,x' in S_p,
```

have only diagonal-size total contribution. Both indices were selected by
future returns of the same nonautonomous orbit, so this is already a
conditioned equidistribution theorem.

No standard complete-sum estimate applies. The available descriptions of the
index function `x -> b_x mod p` are:

1. a nonautonomous transfer product of depth `x`;
2. a Cartier diagonal coefficient of `F^(p-1)`;
3. an interpolation polynomial of degree `O(p)`.

All known algebraic/sheaf complexity bounds therefore grow with `p`. A direct
Artin-Schreier construction from the interpolation polynomial has
`p`-dependent conductor, so the resulting Weil/Deligne bound is not
nontrivial at this scale. No bounded-conductor trace-function realization of
`x -> b_x` is known.

Multiplicative characters do not improve the situation. They live on
`F_p^*`, whereas the event is `b_x=0`; the principal character only gives the
nonzero indicator and has no oscillation. The finite-field Fermat detector

```text
1_{b_x=0} = 1 - b_x^(p-1)
```

has degree growing with `p` and recreates the same conductor problem.

## 5. The precise diagonal obstruction after algebraic relaxation

There is a sharp primitivity-algebraicity tradeoff.

If exact primitivity is retained, (1.1) makes a diagonal-size estimate such as
(DPLS) or (4.2) sufficient. But exact primitivity means excluding every
intermediate return up to span `H`; it is not a bounded-complexity algebraic
condition.

If primitivity is dropped, the three equations (1.2) give a low-degree
algebraic superset. Let `M_tilde(X,H)` count its tuples `(p,x,a,b,c)`, with the
same carrier exclusion, for

```text
X<p<=2X,        a,b,c>=2,        a+b+c<=H.
```

The fully deflated pencil-content argument gives

```text
M_tilde(X,H)
 << (1/log X) * sum_{a+b+c<=H}
       (a+b+c)^2 * log(2a+2b+2c)
 << H^5 log(2H) / log X.                               (5.1)
```

Here a common root contributes to the `p`-adic valuation of a nonzero pencil
content, and the generic Sylvester-height bound is `O(s^2 log s)` for
`s=a+b+c`.

At `H=sqrt(X)`, (5.1) is `X^(5/2+o(1))`. A positive character second
moment at its diagonal scale `X*M_tilde` yields only

```text
sqrt( X * M_tilde(X,sqrt(X)) / log X )
  = X^(7/4+o(1)).                                      (5.2)
```

The target would require a factor `X^(1/2)` below this positive second-moment
diagonal. This is the exact obstruction behind the earlier `7/4` warning.
It applies to the low-degree algebraic relaxation, not to the exact primitive
set.

No standard procedure simultaneously keeps the primitive cap `M_p<=p` and
bounded algebraic complexity. Inclusion-exclusion over all intermediate
return times has exponentially many terms.

## 6. Finite-field projective mixing

The vector `(C_p(q))_q` can be arbitrarily concentrated from the viewpoint of
the local continuant equations. Those equations determine the partition of
indices into return fibres, but not which fibre is labelled `0` by the chosen
Apéry basis.

The artificial `PGL_2` average (2.2) controls the mean and nothing more. An
arbitrary nonnegative vector of mass `M_p` can have variance of order `M_p^2`;
transitivity of the group does not rule that out.

There is also no random walk to which a spectral-gap theorem applies. The
prefix transfer is the prescribed nonautonomous product

```text
T_x = A_{x-1} A_{x-2} ... A_0,
```

with `A_n` depending on `n`. Enlarging the state by the time coordinate makes
the map autonomous, but time still advances deterministically and supplies no
mixing measure.

Marginal equidistribution of all `pi_x` would not suffice. The starts in `S_p`
are selected by three future returns of the same orbit. The variance (3.1)
requires mixing conditioned on those returns. Moreover, a pair counted in
`R_p` may have starts separated by order `p`; expressing `pi_x=pi_y` by a gap
continuant introduces `N_{y-x}(x)` of long depth. Thus the second moment itself
reintroduces the high-depth prefix problem.

## 7. Chebotarev cannot couple the local roots to the prefix

For fixed gaps, put

```text
F = N_a(x),
G = N_b(x+a),
J = N_c(x+a+b).
```

The root-strip theorem implies that `F` and `G` have no common root in
characteristic zero. Hence the common-root scheme of `F,G,J` has empty generic
fibre over the integers. Common roots modulo `p` occur only at vertical bad
primes dividing a nonzero resultant or pencil content. They are not Frobenius
classes in a horizontal finite etale cover. Chebotarev for the splitting field
of one `N_h` does not control this simultaneous-root event.

The distinguished condition is the exact prefix identity

```text
N_{x+1}(-1) = (x!)^3 * b_x.                            (7.1)
```

Since `x<p`, the factorial is a unit modulo `p`, and `pi_x=0` is equivalent to
`N_{x+1}(-1)=0 mod p`. But the subscript `x+1` is a recurrence depth, not
evaluation of a fixed-degree polynomial at the small-gap root `x`. As `x`
ranges up to `p`, all known degree, height, field, and sheaf complexity grows
with `p`. There is no fixed number field or bounded-degree cover whose
Frobenius records both the short-gap root and this prefix hit.

Thus the Chebotarev proposal fails twice: the local intersection is vertical,
and the global prefix is a growing-depth object.

## 8. Bilinear completion and a fixed-initial-data observable

Swapping `p` and `x` gives a clean arithmetic target. For `s=a+b+c`, define

```text
g_{a,b,c}(x) = gcd(
    N_{x+1}(-1),
    N_a(x),
    N_b(x+a),
    N_c(x+a+b)
).                                                       (8.1)
```

For `X<p<=2X` and `x+s<p`, every actual chain forces `p` to divide this gcd.
For dyadic powers `A,B,C` with `2<=A,B,C<=sqrt(2X)`, define

```text
Theta(X;A,B,C) =
  sum over A<=a<2A, B<=b<2B, C<=c<2C, s<=sqrt(2X)
  sum over 0<=x<2X-s
  sum of log p over primes p satisfying
       max(X,x+s) < p <= 2X,
       p does not divide U_s,
       p divides g_{a,b,c}(x).                          (8.2)
```

Primitivity and off-center restrictions are omitted, so this is an upper-bound
observable.

A sufficient Type-II estimate is

```text
Theta(X;A,B,C)
  << X^o(1) * ABC * (A+B+C)^2 / X,                     (DH)
```

uniformly in the displayed ranges. Summing the `O((log X)^3)` boxes gives

```text
sum_{A,B,C} Theta(X;A,B,C)
  << X^o(1) * H^5/X,        H=sqrt(2X),
```

because the sum of `(a+b+c)^2` over triples of total at most `H` is `O(H^5)`.
Every actual chain contributes at least `log X`, so (DH) implies

```text
sum over X<p<=2X of A_p
  << H^(5+o(1)) / (X log X)
  << X^(3/2+o(1)) / log X.                             (8.3)
```

This is the requested `1/p` thinning in fixed-initial-data form: the local
three-return algebra has logarithmic complexity `H^(5+o(1))`, and the extra
prefix divisibility is required to cost `1/p`, of order `1/X`.

Standard bilinear completion does not prove (DH). Opening the four divisibility
conditions leaves complete sums containing `e_p(t b_x)`, hence the same
growing-depth prefix. Squaring returns to the collision diagonal in Sections
4-5. Summing over `p` first says only that `p` is a large prime divisor of the
long-short gcd (8.1); no level of distribution for these gcds is known.

## 9. Recommended fixed-initial-data observables

The repository's existing actual observable is `E_sw(p;eta)`, the number of
four consecutive actual Apéry zeros of span at most `eta*sqrt(p)` with no
centered adjacent pair. It proves the exact reduction

```text
Z(p) < 3*eta^(-1)*sqrt(p) + 6 + E_sw(p;eta).           (9.1)
```

Therefore

```text
sum over X<p<=2X of E_sw(p;1)
  << X^(3/2+o(1)) / log X                              (9.2)
```

would already be sufficient and cannot count projective phantoms.

For arithmetic work, the more structured fixed-initial-data observable is the
window-prime count of (8.1):

```text
G(X,H) =
  sum over a,b,c>=2 with a+b+c<=H
  sum over 0<=x<2X-a-b-c
  number of primes p such that
       max(X,x+a+b+c) < p <= 2X,
       p divides g_{a,b,c}(x),
       p does not divide U_{a+b+c}.                    (9.3)
```

Every actual primitive off-center chain is counted by `G`, and
`N_{x+1}(-1)` anchors the local return algebra to the fixed Apéry initial data.
The target

```text
G(X,sqrt(2X)) << X^(3/2+o(1)) / log X                 (9.4)
```

is equivalent in scale to (DH). This is the replacement observable I
recommend: it retains the common start and the distinguished initial line
without pretending that the prefix has fixed degree.

## 10. Precise obstruction and final assessment

The obstruction has four components.

1. **Basis symmetry:** local return equations are `PGL_2`-invariant, while the
   label `q=0` is fixed by the initial data.
2. **Growing prefix conductor:** detecting `pi_x=0` requires the depth-`x`
   endpoint `N_{x+1}(-1)`, with `x` as large as `p`.
3. **Vertical local algebra:** simultaneous shifted roots are primes dividing
   resultants/contents, not Chebotarev Frobenius events.
4. **Primitivity-algebraicity tradeoff:** exact primitivity gives the useful
   cap `M_p<=p` but is not bounded-complexity algebraic; the low-degree
   relaxation is algebraic but has the `X^(7/4+o(1))` diagonal.

Accordingly:

* additive characters give an exact detector but no available complete-sum
  bound;
* multiplicative characters do not oscillate at zero;
* projective mixing would have to prove (DPLS), which is the missing theorem;
* Chebotarev cannot see either the vertical triple intersection or the growing
  prefix;
* bilinear completion reduces to (DH), another genuinely new Apéry-specific
  input.

The mathematically sharp next lemma is (DPLS). The arithmetically sharp
fixed-initial-data replacement is (DH), equivalently the long-short gcd target
(9.4). Either gives `X^(3/2+o(1))/log X`; neither follows from generic PGL
identities, fixed-degree resultants, or standard Chebotarev.
