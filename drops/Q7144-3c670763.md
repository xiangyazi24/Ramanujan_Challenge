# Prime-averaged distinguished-state hitting: exact target, obstruction, and replacement observable

## 1. Verdict

I audited the current main state at commit `a8159d911d92b2e5089d4cc8643f3b6f33b01827`.
The distinguished-state condition is the genuinely new input. The local
continuant equations see only that four indices lie in one projective fibre;
they are invariant under changing the basis of the two-dimensional solution
space. The assertion that this common fibre is the Apéry fibre `q = 0` is not
basis-invariant.

Consequently:

* averaging the target point `q` gives an exact factor `1/(p+1)`;
* averaging a change of solution basis gives the same exact factor;
* none of the presently available identities de-randomizes that average to
  the fixed Apéry line;
* additive characters, a projective large sieve, Chebotarev, or bilinear
  completion would close the problem only after a new long-prefix/short-return
  independence estimate;
* no such estimate follows from standard bounded-conductor technology, because
  the prefix depth is `x+1` of order `p`, while the exact primitive-chain
  selector itself has complexity up to `H` of order `sqrt(p)`.

There is a clean large-sieve-shaped statement that would imply the requested
bound. It is stated and exponent-checked in Section 4.

> **Fail-closed conclusion.** No unconditional `1/p` distinguished-state
> saving is currently available. A diagonal-size projective variance estimate
> would suffice, but proving it is essentially the missing orbit-coupling
> theorem. If exact primitive chains are replaced by the low-degree local
> algebraic superset, the set becomes algebraic but its unavoidable character
> diagonal is at scale `X^(7/4+o(1))`, not `X^(3/2+o(1))`.

The strongest unconditional baseline already in the repository is

```text
Σ_{X<p≤2X} A_p  ≤  Σ_{X<p≤2X} Z(p)  ≪  X^(8/5) / log X,
```

where `A_p` denotes the number of actual primitive off-center short chains.
No unconditional square-root average is claimed here.

## 2. Exact counting convention

I follow `primitive_projective_prime_scan.cpp`. For a prime `p`, write

```text
π_n = [b_n : c_n] in P^1(F_p),        0 ≤ n < p.
```

The two coordinates never vanish simultaneously. In the scanner's affine
chart,

```text
q_n = b_n / c_n when c_n is nonzero, and q_n = infinity otherwise.
```

Thus `q_n = 0` exactly when `b_n = 0`.

Let `H_p = floor(sqrt(p))`. A start `x` belongs to the exact primitive
formal-chain set `S_p` when the next three occurrences of the state `π_x` are

```text
x+a,   x+a+b,   x+s,        s = a+b+c ≤ H_p,
```

with `a,b,c ≥ 2`, no centered adjacent pair, the gap vector not all equal, and
`p` not dividing the repository's structural carrier

```text
U_s = product over j≤s of (j! * b_j * V_{j+1}).
```

Equivalently, the complete return-offset set in `[0,s]` is
`{0,a,a+b,s}`. Define

```text
C_p(q) = number of x in S_p with π_x = q,
M_p    = Σ_{q in P^1(F_p)} C_p(q) = |S_p|,
A_p    = C_p(0).
```

Then `A_p` is the quantity requested, after the all-equal and structural-carrier
pieces already separated in the repository. A centered adjacent pair belongs
to at most three sliding quadruples, so centered chains contribute only
`O(1)` per prime.

The word **primitive** is crucial. Each index `x` starts at most one chain made
from the next three returns of its state. Therefore

```text
M_p ≤ p,
Σ_{X<p≤2X} M_p ≪ X^2 / log X.                         (2.1)
```

This elementary bound is stronger than a resultant-height estimate for the
exact primitive set.

Every `x in S_p` necessarily satisfies the three local equations

```text
N_a(x) = N_b(x+a) = N_c(x+a+b) = 0 mod p.             (2.2)
```

Because the chain is off-center, the three fully deflated equations hold as
well. The converse is false: (2.2) does not exclude intermediate returns, and
one start can satisfy many gap triples in the algebraic relaxation.

The repository computations make this distinction concrete. The prime-first
formal scan through `p ≤ 500000` found twenty primitive off-center chains with
`p > s^2`, including

```text
(p,x; a,b,c) = (128047,42375; 41,86,37),
p / s^2 = 4.760819...
```

but all twenty were in nondistinguished fibres. The actual-zero census through
`p ≤ 5*10^6` found no off-center four-zero window of span at most `sqrt(p)`.

## 3. Where an exact 1/p exists

For each fixed prime,

```text
(1/(p+1)) * Σ_{q in P^1(F_p)} C_p(q) = M_p/(p+1).     (3.1)
```

Equivalently, let `g` range over `PGL_2(F_p)`. Changing the basis of the two
recurrence solutions sends every state `q` to `gq`, preserves all return
patterns, and gives

```text
average over g of C_p(g^(-1) 0) = M_p/(p+1).          (3.2)
```

Thus the heuristic factor `1/p` is exact after an artificial average over the
target line or over the solution basis.

The problem is that the local continuant algebra is invariant under this basis
change, while the first solution `b = (1,5)` is not. An argument using only
basis-invariant return identities cannot distinguish `q=0` from an adversarial
fibre. It must use the fixed initial data, equivalently the long prefix from
the initial point to index `x`.

If `C_p(0)` could simply be replaced by its mean in (3.1), then (2.1) would
give the much stronger bound

```text
Σ_{X<p≤2X} M_p/(p+1) ≪ X / log X.                    (3.3)
```

Therefore the requested `X^(3/2)/log X` leaves room for a square-root-size
discrepancy. The challenge is not the mean term; it is controlling the one
fixed target.

## 4. Exact intermediate estimate that closes the target

Define the projective chain-state variance

```text
V_p = Σ_{q in P^1(F_p)} ( C_p(q) - M_p/(p+1) )^2.     (4.1)
```

The correct prime-averaged hitting lemma is the following.

### Distinguished projective large sieve (DPLS)

For `H_p = floor(sqrt(p))`,

```text
Σ_{X<p≤2X} V_p  ≪  X^o(1) * Σ_{X<p≤2X} M_p.          (DPLS)
```

This is a diagonal-size large-sieve or mixing estimate: after subtracting the
uniform projective mass, only the number of primitive chains remains.
All ranges are explicit: `X<p≤2X`, `0≤x<p`, and span `s≤sqrt(p)`.

It immediately gives the desired result. One summand of `V_p` is the
distinguished state, so

```text
C_p(0) ≤ M_p/(p+1) + sqrt(V_p).
```

Cauchy-Schwarz, (2.1), and the standard prime-counting upper bound give

```text
Σ A_p
 ≤ Σ M_p/(p+1)
   + sqrt( #primes in (X,2X] ) * sqrt-square(Σ V_p)

 ≪ X/log X
   + sqrt( (X/log X) * ( X^o(1) * X^2/log X ) )

 ≪ X^(3/2+o(1)) / log X.                              (4.2)
```

In the first display, `sqrt-square(Σ V_p)` means simply `Σ V_p`; written
without prose, the error is

```text
sqrt( (#primes in (X,2X]) * (Σ V_p) ).
```

In a bounded-conductor family, Deligne-type complete-sum estimates followed by
a large sieve for trace functions or Frobenius classes are exactly the sort of
technology one would try to use for (DPLS). The Apéry family does not meet the
bounded-complexity hypotheses.

## 5. Additive and multiplicative characters

Let

```text
w_p(x) = 1 if x is in S_p, and 0 otherwise,
S_p(t) = Σ_{0≤x<p} w_p(x) * e_p(t b_x).
```

Because `q_x=0` exactly when `b_x=0`, additive orthogonality gives

```text
A_p = M_p/p + (1/p) * Σ_{t in F_p, t≠0} S_p(t).       (5.1)
```

The difference between `1/p` and `1/(p+1)` contributes only
`O(M_p/p^2)`.

A diagonal-size character large sieve

```text
Σ_{X<p≤2X} Σ_{t≠0} |S_p(t)|^2
  ≪ X^(1+o(1)) * Σ_{X<p≤2X} M_p                      (5.2)
```

would also prove (4.2). Indeed,

```text
| Σ_p (1/p) Σ_{t≠0} S_p(t) |^2
 ≤ ( Σ_p (p-1)/p^2 ) * ( Σ_p Σ_{t≠0} |S_p(t)|^2 ),
```

and the first factor is `O(1/log X)`. Combining (5.2) with (2.1)
gives an error `X^(3/2+o(1))/log X`.

The obstruction is exact under Parseval. Put

```text
nu_p(y) = number of x in S_p with b_x = y mod p.
```

Then

```text
Σ_{t in F_p} |S_p(t)|^2 = p * Σ_{y in F_p} nu_p(y)^2, (5.3)
```

while the `t=0` term is `M_p^2`. Thus (5.2) says that, after removal
of uniform mass, collisions

```text
b_x = b_x' mod p,       x,x' in S_p,
```

have only diagonal-size total contribution on average over `p`. Both indices
have already been selected by future returns of the same orbit. This is a
conditioned equidistribution theorem, not a generic orthogonality calculation.

There is no known complete-sum estimate for `S_p(t)`. The available
descriptions of the function `x -> b_x mod p` are:

1. the depth-`x` nonautonomous transfer product;
2. the Cartier diagonal coefficient of `F^(p-1)`;
3. an interpolation polynomial of degree `O(p)`.

All have complexity growing with `p`. The direct Artin-Schreier sheaf attached
to the interpolation representation has conductor controlled only by this
`p`-dependent degree, so a Weil or Deligne estimate is no better than the
trivial bound. No bounded-conductor trace-function realization of the index
function `x -> b_x` is known.

Multiplicative characters are weaker. They live on `F_p^*`, while the event is
`b_x=0`. The principal character merely gives the nonzero indicator and has no
oscillation. The Fermat detector

```text
1_{b_x=0} = 1 - b_x^(p-1)
```

has degree growing with `p` and reproduces the same conductor problem.

### The 7/4 diagonal after low-degree algebraic relaxation

There is an essential distinction between the exact primitive set `S_p` and
its low-degree algebraic superset. If primitivity is dropped and one sums over
all tuples `(x,a,b,c)` satisfying the three local equations, a fixed `x` can
occur with many gap triples. Let `M_tilde(X,H)` be that formal multiplicity for
`X<p≤2X` and `a+b+c≤H`.

The fully deflated pencil content gives the unconditional bound

```text
M_tilde(X,H)
 ≪ (1/log X) * Σ_{a,b,c≥2, a+b+c≤H}
       (a+b+c)^2 * log(2a+2b+2c)
 ≪ H^5 log(2H) / log X.                               (5.4)
```

A common root contributes to the `p`-adic valuation of the nonzero pencil
content, and the generic Sylvester-height bound is `O(s^2 log s)` for
`s=a+b+c`.

At `H=sqrt(X)`, (5.4) is `X^(5/2+o(1))`. A positive second-moment
argument at diagonal scale `X*M_tilde` then gives

```text
sqrt( X * M_tilde(X,sqrt(X)) / log X )
  = X^(7/4+o(1)),                                      (5.5)
```

which misses the target by `X^(1/4)`. Recovering `X^(3/2)` would require a
factor `X^(1/2)` below this positive diagonal second moment.

This is the precise primitivity-algebraicity tradeoff:

* exact primitivity gives `M_p≤p`, so a diagonal-size large sieve closes the
  problem;
* the three low-degree equations give algebraic access, but their multiplicity
  makes the diagonal too large;
* inclusion-exclusion over every intermediate return restores primitivity only
  at complexity exponential in the number of possible intermediate gaps.

## 6. Projective mixing and finite-field large sieve

The vector

```text
( C_p(q) )_{q in P^1(F_p)}
```

may have arbitrary concentration from the viewpoint of the local continuant
equations. Those equations determine which indices return to the same state,
but not which state is labelled `0` by the chosen Apéry basis.

The artificial `PGL_2` average (3.2) controls only the mean. It gives no bound
on the variance (4.1). An arbitrary nonnegative vector of total mass `M_p` can
have variance of order `M_p^2`, and group transitivity does not rule that out.

There is also no random walk to which an expander theorem applies. The
recurrence transfer is a deterministic nonautonomous product

```text
T_x = A_{x-1} A_{x-2} ... A_0,
```

with `A_n` depending on `n`. Enlarging the state by the time coordinate makes
the evolution autonomous, but time still advances deterministically and
supplies no spectral gap. Standard expansion in `PGL_2(F_p)` concerns random
or suitably averaged words, not this one prescribed word of length `x`.

Marginal mixing of all `π_x` would not be enough. The set `S_p` is endogenous:
it is selected by three future returns of the same orbit. What is needed is
mixing conditioned on those returns, precisely (DPLS). Generic PGL identities
and fixed codegree estimates do not provide it.

## 7. Chebotarev

Chebotarev is useful for root statistics of one fixed `N_h`, as already used in
the repository. It is not the right mechanism for simultaneous short-gap
returns.

For fixed `(a,b,c)`, put

```text
F = N_a(x),
G = N_b(x+a),
J = N_c(x+a+b).
```

The root-strip theorem already implies that `F` and `G` have no common root in
characteristic zero. Hence the common-root scheme of `F,G,J` has empty generic
fibre over the integers. Its points modulo `p` occur only at vertical bad
primes: primes dividing a nonzero resultant or pencil content. They are not
Frobenius classes in a horizontal finite étale cover. Applying Chebotarev to
the simultaneous-root event would therefore be a category error. It is a
prime-divisor problem for a fixed algebraic integer, not a splitting-density
problem.

Adding the distinguished condition does not fix this. The exact prefix
identity is

```text
N_{x+1}(-1) = (x!)^3 * b_x.                            (7.1)
```

For `x<p`, the factorial is a unit modulo `p`, so `q_x=0` is equivalent to
`N_{x+1}(-1)=0 mod p`. But the subscript `x+1` is the depth of the continuant.
It is not evaluation of one fixed-degree polynomial at the small-gap root
`x`. As `x` ranges up to `p`, the degree, height, transfer length, and all
known field or sheaf complexities grow with `p`. There is no fixed number
field or bounded-degree cover whose Frobenius simultaneously records the
short-gap root and the prefix hit.

Even a growing-family effective Chebotarev theorem would face degrees and
discriminants growing with `x`; at `x` of order `p` its error is far larger
than a `1/p` saving. More fundamentally, the short common-root event itself is
vertical.

## 8. Bilinear completion and an exact fixed-initial-data estimate

Swapping the prime and start sums exposes a fixed-initial-data observable, but
it does not automatically give cancellation.

For `a,b,c≥2`, `s=a+b+c`, define the long-short gcd

```text
g_{a,b,c}(x) = gcd(
    N_{x+1}(-1),
    N_a(x),
    N_b(x+a),
    N_c(x+a+b)
).                                                       (8.1)
```

For `X<p≤2X` and `x+s<p`, an actual chain forces `p` to divide this gcd.
For dyadic powers `A,B,C` with `2≤A,B,C≤sqrt(2X)`, define

```text
Theta(X;A,B,C) =
  Σ over A≤a<2A, B≤b<2B, C≤c<2C, s=a+b+c≤sqrt(2X)
  Σ over 0≤x<2X-s
  Σ over primes p satisfying
       max(X,x+s) < p ≤ 2X,
       p does not divide U_s,
       p divides g_{a,b,c}(x)
  of log p.                                             (8.2)
```

Primitivity and off-center restrictions are deliberately omitted, so (8.2)
is an upper-bound observable.

The exact Type-II estimate that would imply the requested result is

```text
Theta(X;A,B,C)
  ≪ X^o(1) * ABC * (A+B+C)^2 / X,                       (DH)
```

uniformly in the stated dyadic ranges. Summing the `O((log X)^3)` boxes gives

```text
Σ_{A,B,C} Theta(X;A,B,C)
  ≪ X^o(1) * H^5 / X,        H = sqrt(2X),
```

because the sum of `(a+b+c)^2` over triples of total at most `H` is `O(H^5)`.
Every actual chain contributes at least `log X` to the left side. Hence (DH)
implies

```text
Σ_{X<p≤2X} A_p
  ≪ H^(5+o(1)) / (X log X)
  ≪ X^(3/2+o(1)) / log X.                              (8.3)
```

This is the fixed-initial-data form of the desired thinning. The local
three-return algebra has logarithmic complexity `H^(5+o(1))`; adding the
prefix divisibility should cost `1/p`, of order `1/X`.

Standard bilinear completion does not prove (DH). Opening the four divisibility
conditions with additive characters leaves complete sums containing
`e_p(t b_x)`, equivalently the depth-`x` prefix transfer. There is no bounded-
degree polynomial phase and no bounded-conductor trace function. Squaring and
completing returns to the collision diagonal in Section 5. Summing over `p`
first only says that `p` is a large prime divisor of the long-short gcd (8.1);
no level of distribution for these gcds is known.

## 9. Precise obstruction

The obstruction has four independent parts.

1. **Basis symmetry.** Local return equations are `PGL_2`-invariant; the label
   `q=0` is fixed by the initial data. The exact `1/(p+1)` average cannot be
   de-randomized by invariant identities.

2. **Growing prefix conductor.** Detecting `q_x=0` requires the depth-`x`
   quantity `N_{x+1}(-1)`, with `x` as large as `p`. All available algebraic
   or sheaf realizations have complexity growing with `p`.

3. **Vertical short algebra.** Simultaneous shifted continuant roots occur at
   primes dividing resultants or pencil contents. They are special-fibre
   intersections, not Frobenius events in a fixed extension.

4. **Primitivity-algebraicity diagonal.** Exact primitive chains have one start
   per index and a diagonal-size large sieve would close the target. The
   low-degree algebraic relaxation has multiplicity `H^(5+o(1))`, whose
   positive character diagonal gives `X^(7/4+o(1))` at `H=sqrt(X)`.

The precise missing theorem is therefore conditioned, prime-averaged
equidistribution of the fixed Apéry line among exact primitive return fibres,
or equivalently a `1/X` average estimate for the anchored long-short gcd in
(8.2).

## 10. Recommended fixed-initial-data observables

### 10.1 Actual short-window count

The repository already defines `E_sw(p;eta)`, the number of four consecutive
actual Apéry zeros of span at most `eta*sqrt(p)` with no centered adjacent
pair, and proves

```text
Z(p) < 3*eta^(-1)*sqrt(p) + 6 + E_sw(p;eta).            (10.1)
```

Thus the direct target

```text
Σ_{X<p≤2X} E_sw(p;1) ≪ X^(3/2+o(1)) / log X            (10.2)
```

is already sufficient. It is less algebraic than a resultant, but it is the
exact fixed-orbit quantity and cannot count phantoms.

### 10.2 Anchored long-short gcd

For arithmetic work, use (8.1), or its window-prime count

```text
G(X,H) =
  Σ_{a,b,c≥2, a+b+c≤H}
  Σ_{0≤x<2X-a-b-c}
  number of primes p such that
      max(X,x+a+b+c) < p ≤ 2X,
      p divides g_{a,b,c}(x),
      p does not divide U_{a+b+c}.                      (10.3)
```

Every actual primitive off-center chain is counted by `G`. The factor
`N_{x+1}(-1)` anchors the local return equations to the fixed Apéry initial
data. The target

```text
G(X,sqrt(2X)) ≪ X^(3/2+o(1)) / log X                   (10.4)
```

is equivalent in scale to (DH).

This is the observable I recommend for further work. It states exactly what a
successful argument must prove: large prime divisors common to one long
continuant endpoint and three short shifted continuants are sparse on average.
It does not pretend that the prefix is fixed-degree, and it retains both the
common start and the distinguished initial line.

## 11. Final assessment

* **Additive characters:** exact detector, but no bounded-conductor complete-sum
  estimate; the required collision theorem is (5.2) or (DPLS).
* **Multiplicative characters:** do not oscillate at zero; the Fermat detector
  has degree `p-1`.
* **Projective mixing / large sieve:** (DPLS) closes the problem, but the
  deterministic nonautonomous orbit and return-conditioned selector are
  outside standard expander and trace-function hypotheses.
* **Chebotarev:** applies to roots of one `N_h`, not to vertical simultaneous-
  root primes, and cannot absorb the depth-`x` prefix.
* **Bilinear completion:** reduces exactly to (8.2), but no available Type-II
  estimate controls its `b_x` phase.

Therefore all four proposed off-the-shelf mechanisms fail at a precise point.
The mathematically sharp next lemma is (DPLS); the arithmetically sharp
replacement is (DH)/(10.4). Either would imply
`X^(3/2+o(1))/log X`, but each is a genuinely new Apéry-specific input rather
than a consequence of generic PGL identities, fixed-degree resultants, or
standard Chebotarev.
