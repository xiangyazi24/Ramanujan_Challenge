# Strategic planning for the Apéry GCD conjecture

## Executive assessment

The current landscape suggests that the original all-n conjecture is no longer blocked by computation or by finding more elementary manipulations of the recurrence. The bottleneck is a genuine cross-prime distribution theorem for the moving family of Apéry zeros.

The three most promising directions are:

| Rank | Direction | Estimated success probability | Scale |
|---|---|---:|---|
| 1 | I5 / weaker exponent route | highest | 1--5 years |
| 2 | New cross-characteristic Apéry identity | medium | 5 years |
| 3 | Density-one or restricted-case theorem | medium-high for partial results | 1--5 years |

The defining-characteristic Katz equidistribution route is mathematically natural but should be considered a 10+ year foundational project, not the shortest route to the conjecture.

---

# 1. I5 route: prove a weaker multi-prime intersection estimate

## Target theorem

Instead of proving (HM)_3 in its strongest form, prove:

```
T_3(X) = #{(p1,p2,p3,m): pi in (X,2X],
          m mod pi in Z_pi for all i}
       << X^(14/15+eta)
```

(or the equivalent exponent needed by the I5 reduction).

This would already imply a nontrivial bound on the number of large prime divisors of the Apéry gcd.

## Key input needed

A usable estimate for triple correlations:

```
Sum_m prod_{i=1}^3 1_{Z_pi}(m mod pi)
```

with cancellation after averaging over triples of primes.

The important point is that this does not require a complete distribution theorem for every Mellin transform. It only requires enough averaged cancellation.

## Why this is promising

The existing evidence already supports this:

- T3 numerics follow Poisson behavior.
- Pair-witness spectral transversality is small.
- The obstruction to (HM)_2 is sharp, but (HM)_3 has extra geometric room.

Estimated project: 1--5 years.

Probability: highest among the options.

# 2. Search for a new Apéry identity crossing characteristics

## Target theorem

Find an identity of the form:

```
b_r mod p = expression involving a fixed auxiliary object
```

where the auxiliary object has controlled global arithmetic behavior.

Examples of desirable forms:

- a modular-form coefficient identity;
- a K3 Frobenius trace identity;
- a finite-field hypergeometric transformation;
- a p-adic interpolation formula.

The ideal result would convert:

```
p | b_r
```

into a condition on a fixed algebraic variety whose bad events can be counted globally.

## Key input needed

A hidden structure relating the Apéry recurrence simultaneously in:

- characteristic zero;
- characteristic p;
- p-adic cohomology.

The existing K3 interpretation is close, but the missing piece is a theorem that controls the zero locus rather than the trace size.

## Why promising

The Apéry family has unusually rich structure:

- modular form interpretation;
- K3 geometry;
- hypergeometric representation;
- supercongruences.

A new identity could bypass the need for general crystalline Katz theory.

Estimated project: about 5 years.

Probability: medium.

---

# 3. Prove a weaker theorem first: density-one n or restricted primes

## Target theorem A: density-one version

Prove:

```
For a set S of integers n with density 1,
log(G_n)=o(n).
```

This avoids controlling exceptional arithmetic coincidences for every n.

## Target theorem B: restricted prime family

For example:

```
(HM)_3 holds for primes p = 1 mod 6.
```

or another geometrically favorable Chebotarev class.

Then combine with sieve arguments to remove most primes.

## Key input needed

A partial equidistribution theorem, such as:

- average Mellin cancellation over p;
- monodromy for a restricted family;
- a positive-density set of primes with generic Frobenius.

## Why promising

The full theorem requires uniformity everywhere. A density-one result allows exceptional primes or exceptional n to be discarded.

Estimated project: 1--5 years for a strong partial theorem.

Probability: relatively high for a meaningful result, lower for the full conjecture.

# Lower-ranked directions

## (a) Developing crystalline/p-adic Katz equidistribution

Exact target:

Prove square-root cancellation for Mellin transforms of the Apéry F-isocrystal:

```
|Sum_a Tr(Frob_a)^k chi(a)| <= C p^(1/2)
```

uniformly in p and relevant characters.

This is the cleanest theoretical solution, but it requires new p-adic trace-function technology in defining characteristic.

Estimated project: 10+ years.

## (d) Single congruence classes only

Useful as a laboratory, but unlikely alone to prove the conjecture.

A theorem for p = 1 mod 6 would clarify the geometry but still leaves the remaining prime classes.

Estimated project: 1--3 years.

---

## (f) Only prove B(n) <= n^(1-epsilon)

This is much weaker than the conjecture but may be accessible through existing sieve technology.

However, it does not exploit the special Apéry geometry enough and may not illuminate the true mechanism.

Estimated project: 1--5 years.

# Recommended research sequence

## Phase 1

Attack I5:

```
Prove averaged triple-correlation decay.
```

This has the best ratio of difficulty to impact.

## Phase 2

Develop a restricted geometric theorem:

```
For a Chebotarev-positive set of primes,
prove Apéry zero equidistribution.
```

## Phase 3

Use the resulting structure to search for the missing cross-characteristic identity.

## Long-term

Develop defining-characteristic Katz theory for the Apéry F-isocrystal.

# Final ranking

1. **I5 weaker exponent route** — best chance of producing a genuine proof advance; 1--5 years.
2. **New Apéry identity crossing characteristics** — potentially decisive but discovery-driven; about 5 years.
3. **Density-one / restricted-case theorem** — most realistic partial theorem and possible stepping stone; 1--5 years.

The full all-n conjecture likely requires a new arithmetic input rather than another refinement of existing sieve machinery.
