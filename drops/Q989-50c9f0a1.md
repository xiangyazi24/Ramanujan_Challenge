## 1. Exact row system

Let the normalized interpolation data be the reciprocal Apéry values

```

```

For denominator degree d, write

```
P(x)/Q(x)
```

with `deg Q <= d` and interpolation constraints

```

```

The integer object is not the monomial numerator alone. Clearing denominators gives

```
N_H(x)=L_H P(x),
L_H=lcm(A_0,...,A_H),
```

followed by primitive normalization in `Z[x]`.

The Newton normalization is different: its coefficients are integer-valued basis coefficients. A small Newton coefficient vector does not imply a small monomial polynomial.

## 2. High divided-difference constraints

The constraints are equivalent to vanishing divided differences:

```
[y_0,...,y_k; P-Qy]=0
```

for all required orders through H-d. These high-order equations cannot be omitted. They are exactly the constraints that produce the Newton sign pattern in the fixed-degree proofs.

For bounded numerator degree `r=H-d`, the last r+1 divided differences determine the primitive numerator after the denominator part is eliminated. The resulting coefficients are linear combinations of exact positive minors of the normalized interpolation matrix.

Strict total positivity therefore implies that the Newton coefficients have one sign and cannot all cancel.

## 3. Bounded numerator degree obstruction

Assume

```

```

The numerator is determined by a fixed number of terminal divided differences. After primitive normalization, at least one Newton coefficient contains a positive interpolation minor times the Apéry denominator scale.

Because


and the primitive normalization only removes the common integer gcd, the remaining numerator height satisfies


for some `c_r>0` depending on the fixed numerator degree.

Thus bounded positive numerator degree does not give an `o(H)` certificate.
