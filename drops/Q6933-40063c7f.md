# Special three-dimensional Miller theorem: the shortest honest Lean route

## Verdict

Use **(B), but strengthen it to a two-bundle graph-transform argument**:

1. construct the unique bounded pullback line for `A_n = C_n^{-T}` near the dominant eigendirection of `A_inf`;
2. construct an exact invariant complementary hyperplane by a forward graph transform on covectors;
3. prove explicit line-growth and hyperplane-growth estimates;
4. use the known root-rate of the concrete solution to prove that its initial state lies on the pullback line;
5. apply the backward product to the moving terminal vectors and use their nonzero limiting dominant coefficient;
6. restore the finite prefix and rescale so that the limit is exactly `f_0`, not merely an unspecified line.

This is an elementary special exponential-dichotomy theorem. It requires no Harris--Lutz transformation, no summable perturbation theorem, no Poincare--Perron theorem, and no projective-space topology. It can be formalized using ordinary limits in `R x R^2`, geometric-series estimates, and continuous linear maps.

The `C_n = C_inf + C_1/n + O(n^-2)` expansion is **not needed**. Mere convergence `C_n -> C_inf`, together with the spectral gaps and the state-level small-growth hypothesis, suffices. The expansion would only be needed for sharp polynomial prefactors or full Levinson asymptotics.

I do **not** recommend (A) unless a full asymptotic fundamental basis is independently needed. I do **not** recommend (C) unless two additional exact scalar solutions are already available; otherwise it merely hides the same dichotomy theorem inside a scalar Poincare--Perron argument.

The current repository state is consistent with this assessment:

- `lean/RamanujanChallenge/Problem25Moment.lean` still has the sole `positiveCatalanError_brackets` sorry;
- `scripts/miller_gauge_2_5.py` and `scripts/backward_ratio_2_5.py` are numerical/discovery scripts, not all-index theorems;
- no tracked Lean file presently supplies a Miller, Levinson, Poincare--Perron, or exponential-dichotomy result.

Assuming the stated root-rate theorem and the terminal-limit/nonzero-pairing theorem are already rigorous, there is **no deep analytic residual**. The remaining work is a substantial but elementary finite-dimensional argument.

# 1. Orientation and exact reduction

Put

```text
A_n   = C_n^{-T},
Phi_N = C_0 C_1 ... C_(N-1).
```

Then

```text
Phi_N^{-T} = A_0 A_1 ... A_(N-1).
```

The order matters: when this product is applied to a terminal vector at time `N`, the rightmost factor `A_(N-1)` acts first.

Let

```text
mu     = 17 - 12 sqrt(2),
lambda = mu^{-1} = 17 + 12 sqrt(2).
```

The already proved silver-ratio identity gives `lambda * mu = 1`. Exact rational inequalities sufficient for the argument are

```text
0 < mu < 1/32,
lambda > 33.
```

A Lean proof of the upper bound `mu < 1/32` may use

```text
(181/128)^2 = 32761/16384 < 2,
```

hence `181/128 < sqrt(2)`, and therefore

```text
17 - 12 sqrt(2) < 17 - 12*(181/128) = 1/32.
```

Similarly `4/3 < sqrt(2)` gives `lambda > 33`.

Choose an explicit real eigenbasis matrix `P` for `A_inf` such that

```text
P^{-1} A_inf P = diag(lambda, 1, mu).
```

Define

```text
B_n = P^{-1} A_n P.
```

Since `C_inf` is invertible and `C_n -> C_inf`, one has `A_n -> A_inf`; no library theorem about continuity of inversion is essential, because the exact identity

```text
C_n^{-1} - C_inf^{-1}
  = C_n^{-1} (C_inf - C_n) C_inf^{-1}
```

and eventual boundedness of `C_n^{-1}` prove it directly. Consequently

```text
B_n -> D := diag(lambda, 1, mu).
```

Discard a finite prefix. In the splitting

```text
R^3 = R e_0  direct_sum  Y,     Y = R^2,
```

write

```text
B_n (x,y) = (a_n x + b_n(y), c_n x + D_n y),
```

where

```text
a_n : R,
b_n : Y ->L[R] R,
c_n : Y,
D_n : Y ->L[R] Y.
```

Because `B_n -> diag(lambda,1,mu)`, there is an index `N0` after which the following **rational tail bounds** hold:

```text
a_n >= 131/4,
||b_n|| <= 1/4,
||c_n|| <= 1/4,
||D_n|| <= 5/4,
b_n -> 0,
c_n -> 0.
```

Here the norm on `R x Y` is the product/max norm. The norm on continuous linear maps is the operator norm. These coarse constants are deliberately far from sharp.

Reindex the tail by replacing `B_n` with `B_(N0+n)`. Everything below starts at tail index zero.

# 2. The generic tail theorem with explicit constants

Use the constants

```text
r     = 1/8,
alpha = 1047/32,
beta  = 41/32,
kappa = 1/20.
```

They satisfy

```text
0 < r < 1,
1 < beta < alpha,
beta / alpha = 41/1047 < 1/20,
mu < 1/32 < 32/41 = beta^{-1}.
```

The following is the recommended generic Lean theorem.

## Theorem: three-dimensional tail Miller filter

Let `Y` be a complete real normed space and let `V = R x Y`. Let `B_n : V ->L[R] V` have the block form above and satisfy, for every `n`,

```text
a_n >= 131/4,
||b_n|| <= 1/4,
||c_n|| <= 1/4,
||D_n|| <= 5/4,
```

with `b_n -> 0` and `c_n -> 0`.

Then the following objects and estimates exist.

### (i) Unique bounded pullback line

There is a unique sequence `q_n : Y` satisfying

```text
||q_n|| <= r,
q_n = T_n(q_(n+1)),
q_n -> 0,
```

where

```text
T_n(q) = (c_n + D_n q) / (a_n + b_n(q)).
```

Put

```text
v_n = (1,q_n),
L_n = R v_n.
```

Then

```text
B_n v_(n+1) = sigma_n v_n,
sigma_n = a_n + b_n(q_(n+1)),
sigma_n >= alpha.
```

### (ii) Exact invariant complementary hyperplane

Define covectors `p_n : Y ->L[R] R` by

```text
p_0 = 0,
p_(n+1) = U_n(p_n),
U_n(p) = (b_n + p.comp D_n) / (a_n + p(c_n)).
```

Then

```text
||p_n|| <= r,
p_n -> 0.
```

Define

```text
ell_n(x,y) = x + p_n(y),
H_n = ker ell_n.
```

There is a scalar

```text
rho_n = a_n + p_n(c_n) >= alpha
```

such that

```text
ell_n(B_n z) = rho_n * ell_(n+1)(z).
```

Hence

```text
B_n(H_(n+1)) subset H_n.
```

If the `B_n` are invertible, equality holds, but equality is not needed for the backward estimate.

### (iii) Uniform growth separation

For every `z in H_(n+1)`,

```text
||B_n z|| <= beta ||z||.
```

Also

```text
||v_n|| = 1,
ell_n(v_n) >= 1-r^2 = 63/64.
```

Thus every `z in V` has the unique decomposition

```text
z = gamma_n(z) v_n + h_n(z),
h_n(z) in H_n,

gamma_n(z) = ell_n(z) / ell_n(v_n),
```

and the projections are uniformly bounded. Explicitly,

```text
|gamma_n(z)| <= (8/7) ||z||,
||h_n(z)|| <= (15/7) ||z||.
```

For the backward product

```text
Psi_N = B_0 B_1 ... B_(N-1),
S_N   = product_(k < N) sigma_k,
```

one has

```text
Psi_N v_N = S_N v_0,
S_N >= alpha^N,
```

and for `h in H_N`,

```text
||Psi_N h|| <= beta^N ||h||.
```

### (iv) Moving-terminal Miller convergence

Let terminal vectors `z_N : V`, scalars `s_N`, and `z_inf : V` satisfy

```text
s_N z_N -> z_inf,
first(z_inf) != 0.
```

Then

```text
Psi_N z_N  projectively tends to  v_0.
```

A quotient-free Lean statement is

```text
exists t : N -> R,
  Tendsto (fun N => t N * Psi_N(z_N)) atTop (nhds v_0).
```

Indeed, decompose the scaled terminal vector

```text
s_N z_N = gamma_N v_N + h_N.
```

Because `p_N -> 0`, `q_N -> 0`, and `s_N z_N -> z_inf`,

```text
gamma_N -> first(z_inf) != 0,
```

and `h_N` is bounded. For all sufficiently large `N`, define

```text
t_N = s_N / (gamma_N S_N).
```

Then

```text
||t_N Psi_N z_N - v_0||
  <= (||h_N|| / |gamma_N|) * (beta/alpha)^N
  -> 0.
```

This is the exact place where the moving nature of `w_N` is handled. One must decompose the **scaled** vectors `s_N w_N`; treating `w_N` as fixed is invalid in general.

### (v) Rate characterization of the pullback line

Let `g_n : V` satisfy

```text
g_n = B_n g_(n+1),
g_0 != 0.
```

Suppose, in a Lean-friendly exponential form,

```text
for all sufficiently large n,
  ||g_n|| <= (1/2)^n.
```

Then

```text
g_0 in L_0.
```

Proof: decompose

```text
g_n = gamma_n v_n + h_n,     h_n in H_n.
```

Exact invariance and uniqueness of the decomposition give

```text
h_0 = Psi_n h_n.
```

If `h_0 != 0`, then

```text
||h_n|| >= beta^{-n} ||h_0||,
||g_n|| >= (7/15) ||h_n||,
```

hence

```text
||g_n|| >= (7/15) ||h_0|| * (32/41)^n.
```

This contradicts `||g_n|| <= (1/2)^n`, because

```text
(1/2) * beta = 41/64 < 1.
```

Therefore `h_0=0`, so `g_0` is a nonzero multiple of `v_0`.

The hypothesis can be weakened to

```text
limsup ||g_n||^(1/n) < beta^{-1} = 32/41.
```

The concrete rate `mu` is vastly smaller than this threshold.

# 3. Proof of the graph-transform estimates

All numerical inequalities are exact and should be proved once by `norm_num`.

For `||q|| <= r`,

```text
a_n + b_n(q)
  >= 131/4 - (1/4)(1/8)
  = 1047/32
  = alpha.
```

Also

```text
||c_n + D_n q||
  <= 1/4 + (5/4)(1/8)
  = 13/32.
```

Therefore

```text
||T_n(q)|| <= (13/32)/(1047/32) = 13/1047 < 1/8.
```

The same calculation applies to `U_n`.

For `q,q'` in the radius-`r` ball, use

```text
T_n(q)-T_n(q')
 = D_n(q-q') / d(q)
   + (c_n+D_n q') * (d(q')-d(q)) / (d(q)d(q')),
```

where `d(q)=a_n+b_n(q)`. The first term is bounded by

```text
(5/4)/alpha = 40/1047.
```

For the second term, the self-map numerator bound implies

```text
||c_n+D_n q'|| <= r alpha,
```

so it is bounded by

```text
r*(1/4)/alpha = 1/1047.
```

Thus

```text
||T_n(q)-T_n(q')||
  <= (41/1047) ||q-q'||
  < (1/20) ||q-q'||.
```

Again the identical proof applies to `U_n`.

For the hyperplane estimate, write `z=(x,y) in H_(n+1)`. Then

```text
x = -p_(n+1)(y),
|x| <= r ||y||,
||z|| = ||y||.
```

The second coordinate of `B_n z` satisfies

```text
||c_n x + D_n y||
  <= (1/4)(1/8)||y|| + (5/4)||y||
  = (41/32)||y||
  = beta ||z||.
```

Since `B_n z in H_n` and `||p_n||<1`, the max norm of `B_n z` equals the norm of its second coordinate. This proves the claimed bound.

# 4. Constructing the pullback line without Banach's fixed-point theorem

Do not formalize a space of sequences unless desired. Define finite-horizon approximants directly:

```lean
noncomputable def qApprox (n : Nat) : Nat -> Y
  | 0     => 0
  | k + 1 => lineStep n (qApprox (n + 1) k)
```

Interpret `qApprox n k` as pulling the terminal line `(1,0)` backward for `k` steps.

Prove by induction:

```text
||qApprox n k|| <= r.
```

For `m,k >= 0`, repeated contraction gives

```text
||qApprox n (k+m) - qApprox n k|| <= r * kappa^k.
```

Therefore, for each fixed `n`, `qApprox n k` is Cauchy. Define

```text
q_n = lim_(k -> infinity) qApprox n k.
```

Passing to the limit in

```text
qApprox n (k+1) = T_n(qApprox (n+1) k)
```

gives

```text
q_n = T_n(q_(n+1)).
```

Uniqueness among all radius-`r` solutions follows from

```text
||q_n-q'_n|| <= kappa^m ||q_(n+m)-q'_(n+m)|| <= 2r kappa^m
```

for every `m`.

To prove `q_n -> 0`, use

```text
||q_n|| <= kappa ||q_(n+1)|| + ||T_n(0)||,
T_n(0) = c_n/a_n -> 0.
```

Given `eps>0`, choose `J` with `r kappa^J < eps/2`, and then choose `n` so large that

```text
||T_(n+j)(0)|| <= (1-kappa) eps/2
```

for all `j>=0`. Iterating `J` times proves `||q_n||<eps`.

The proof that `p_n -> 0` is the forward analogue:

```text
||p_(n+1)|| <= kappa ||p_n|| + ||U_n(0)||,
U_n(0)=b_n/a_n -> 0.
```

These are elementary epsilon proofs and avoid any unavailable nonautonomous fixed-point theorem.

# 5. Identifying the line with the concrete solution `f_0`

This step is load-bearing. A projective contraction alone proves only the existence of **some** pullback line. It does not identify that line with the known Catalan/Miller solution.

Let

```text
g_n = P^{-1} f_(N0+n).
```

Because

```text
f_n = A_n f_(n+1),
```

we have

```text
g_n = B_n g_(n+1).
```

The proved state root-rate

```text
||f_n||^(1/n) -> mu
```

implies the Lean-friendly estimate

```text
for all sufficiently large n,
  ||g_n|| <= (1/2)^n.
```

A convenient formal bridge is:

1. use `mu < 1/32 < 1/4` to obtain eventually
   
   ```text
   ||f_m|| <= (1/4)^m;
   ```

2. use `||P^{-1}x|| <= ||P^{-1}|| ||x||` and the finite shift `N0` to get
   
   ```text
   ||g_n|| <= K (1/4)^n;
   ```

3. absorb the fixed constant `K` into the larger geometric sequence `(1/2)^n`, using `2^n -> infinity`.

Apply the rate-characterization lemma. It yields

```text
g_0 = c v_0
```

for some `c != 0`. Hence

```text
f_N0 = c P v_0.
```

Let

```text
K0 = A_0 A_1 ... A_(N0-1) P.
```

Then

```text
f_0 = c K0 v_0.
```

This is the exact identification required later. The finite prefix is essential: the backward limit at time zero is generally **not** the dominant eigenvector of `A_inf`; it is the finite-prefix image `K0 v_0`.

# 6. Moving terminal vectors and the final theorem

Define

```text
z_n = s_(N0+n) * P^{-1} w_(N0+n).
```

The assumed convergence gives

```text
z_n -> z_inf := P^{-1} w_inf.
```

Choose the eigenbasis `P` so that its first column is the dominant right eigenvector of `A_inf`. Then the first coordinate of `P^{-1}w_inf` is the coefficient of `w_inf` along that eigenvector.

More invariantly, if `r_mu` is the right eigenvector of `C_inf` with eigenvalue `mu`, normalized as the dual covector to the dominant right eigenvector of `A_inf`, then

```text
first(P^{-1} w_inf) = <r_mu, w_inf>.
```

This must be proved with the **dual eigenvector**, not by taking an ordinary Euclidean dot product with the dominant vector unless the basis is orthonormal. The hypothesis says exactly

```text
first(z_inf) != 0.
```

The moving-terminal theorem gives scalars `u_n` such that

```text
u_n * (B_0 ... B_(n-1)) (P^{-1}w_(N0+n)) -> v_0.
```

Apply the fixed continuous linear map `K0`:

```text
u_n * Phi_(N0+n)^{-T} w_(N0+n) -> K0 v_0 = c^{-1} f_0.
```

Multiply the scalar sequence by `c`. Therefore

```text
Phi_N^{-T} w_N  projectively tends to  f_0.
```

A precise quotient-free final statement is:

```lean
def ProjectivelyTendsto
    (x : Nat -> V) (v : V) : Prop :=
  v != 0 ∧ ∃ t : Nat -> Real,
    Filter.Tendsto (fun n => t n • x n) Filter.atTop (nhds v)

 theorem special_miller
    (...) :
    ProjectivelyTendsto
      (fun N => PhiInvTranspose N (w N)) f0
```

There is no need to import or formalize a projective quotient.

# 8. Comparison of the three proposed routes

## (A) Harris--Lutz plus discrete Levinson

**Mathematically valid:** yes.

**Formal content required:**

1. exact expansion in a diagonal basis;
2. solve the off-diagonal commutator equation for a near-identity `I+X/n` gauge;
3. prove the transformed remainder is summable;
4. construct three independent asymptotic solutions by a Volterra/fixed-point argument;
5. prove a fundamental-matrix/Cramer expansion;
6. handle polynomial `n^gamma_i` factors;
7. prove the moving-terminal coefficient survives;
8. identify the minimal basis vector with `f` from its root rate.

This produces much more than needed. Also, the false shortcut

```text
C_n = C_inf + O(1/n)  implies  Phi_n ~ C_inf^n
```

must not be used. Products of `1 + gamma/n` generate `n^gamma` factors, so a normalized product need not converge.

**Lean assessment:** honest but longest. It amounts to writing a special discrete Levinson theorem from scratch.

## (B) Projective graph transform

**Mathematically valid:** yes, with the important modification described above.

A single attracting-line construction is insufficient. One must also construct an invariant complementary hyperplane and establish the quantitative separation

```text
line backward growth >= alpha^n,
hyperplane backward growth <= beta^n,
beta < alpha.
```

The hyperplane is what makes the root-rate identification rigorous and prevents cancellation.

**Lean assessment:** shortest. It uses only convergence and explicit inequalities. No `1/n` expansion or summability is needed.

## (C) Scalar recurrence and Wronskians

**Mathematically valid only with extra data.** If three exact independent scalar solutions with separated rates were already known, Cramer/Wronskian formulas would be short. They are not currently available.

The scalar Casoratian law gives only the product of the three multipliers. Knowing one solution has rate `mu` and knowing the determinant does not separately construct the rate-`1` and rate-`mu^{-1}` solutions. Proving their existence is precisely a Poincare--Perron/dichotomy theorem.

**Lean assessment:** no genuine simplification. It either invokes the unavailable theorem or re-proves route (B) in companion coordinates with more index bookkeeping.

# 9. False implications and necessary hypotheses

The following distinctions should be made explicit in the formal development.

1. **`O(1/n)` does not give a convergent normalized product.** Polynomial factors may occur. The present theorem uses only coarse exponential gaps, so this causes no problem.

2. **A root rate for the single scalar `F_n` is not automatically a state-norm rate.** One needs a theorem for
   
   ```text
   f_n = (F_n,F_(n+1),F_(n+2))
   ```
   
   or enough positivity/comparability to derive it. The question states the state-level rate, which is sufficient.

3. **Constructing an attracting line does not identify it with `f_0`.** The invariant-hyperplane estimate and the rate-exclusion argument are mandatory.

4. **The limiting line at tail time zero is not automatically an eigenline of `A_inf`.** The exact time-zero target is the finite-prefix image `A_0...A_(N0-1)P v_0`.

5. **Pointwise nonzero dominant coefficients of `w_N` are insufficient.** They could tend to zero exponentially at the same rate as the spectral separation. The assumption
   
   ```text
   s_N w_N -> w_inf,
   dominantCoefficient(w_inf) != 0
   ```
   
   gives the required uniform nonvanishing after projective normalization.

6. **The terminal vectors need not approach the minimal solution.** Generic terminal data are acceptable; backward multiplication is the filter. Do not try to prove `w_N` projectively approaches `f_N`.

7. **The coefficient is a dual pairing.** In a nonorthogonal eigenbasis it is not the Euclidean inner product with the dominant eigenvector. It is the pairing with the corresponding left eigenvector of `A_inf`, equivalently the right `mu`-eigenvector of `C_inf`.

8. **The root-rate equality is stronger than necessary.** An eventual upper exponential rate strictly below `32/41` suffices.

Formalize the generic tail theorem above in a new file, for example

```text

```

and keep all Problem 25 matrix algebra in a separate application file. The generic proof should never mention Catalan's constant, moments, or the original positive matrix. Its input is only the conjugated block cocycle, the small-growth state, and the moving terminal limit.

The application then consists of exact finite-dimensional bridges:

1. define `C_n`, `A_n=C_n^{-T}`, and the products;
2. prove the exact real diagonalization of `A_inf`;
3. prove `B_n -> diag(lambda,1,mu)` and obtain the tail bounds;
4. convert the proved root-rate into the eventual `(1/2)^n` bound;
5. prove the terminal scaled limit and its exact nonzero dual pairing;
