## Verdict

The state-adaptive threshold does yield a useful strict reduction, but the right stratification is not “prove the same little-o separately in every bin.” The correct arbitrary-stratum consumer is

```text
sum_alpha sqrt(U_alpha F_alpha) = o_J(B),              (SG-Cauchy)
```

with a summable uniformity condition if the number of strata grows. For dyadic load strata `K <= kappa_vee < 2K`, the sharper occurrence-preserving form is

```text
sum_{K>=2} F_K/K = o_J(B).                             (SG-load)
```

The banked first and second moments already delete:

1. singleton states;
2. all loads below `T^(2/5)L^(-6/5)` by the upper-state first moment;
3. all loads above `T^(3/5)L^(1/5)` by the banked factorial moment; and
4. all intermediate states satisfying the support-blind product inequality
   `kappa_vee(q,t) * w(q) << T/L`, where `w(q)` is the pre-lower-mark legal upper-window occupancy.

Thus the only unresolved states lie in the intermediate-load/high-window wedge

```text
T^(2/5)L^(-6/5)  <= kappa_vee <= T^(3/5)L^(1/5),
kappa_vee * w(q) >= T/L,                               (exceptional wedge)
```

up to slowly growing safety factors. In power-exponent coordinates this is

```text
2/5 <= load exponent <= 3/5,
load exponent + window exponent >= 1.
```

This is substantially smaller than global MF2 as a domain. It is **not** yet a uniformly weaker numerical theorem: current moments do not prove that most actual occupied mass lies outside the wedge. A moment extremizer can place all allowed mass in the wedge. The first genuinely new theorem is therefore a localized marked factorial theorem, or an occupied-support theorem, on that wedge only.

The balanced dangerous cell is

```text
kappa_vee ~ w(q) ~ T^(1/2)L^(-1/2),
```

and its local factorial threshold is

```text
F_bal = o_J(T^(5/2)L^(-5/2)).                          (balanced threshold)
```

The two boundary corners retain different thresholds, detailed below.

## 1. Literal Boolean-union object

Let `x=(q,t)` range over complete upper-selected quotient-six states: `q` is prime, `0<=t<q`, `q|b_t`, and all inherited deterministic upper masks are retained. Let

```text
P_vee(x) = P_-(x) union P_+(x)
kappa(x) = #P_vee(x).
```

The union is Boolean: a lower prime lying in both raw signs is counted once, consistently with the minus-first assignment. Define

```text
S       = {x : kappa(x)>0},
U       = #S,
M_vee   = sum_x kappa(x),
F_vee   = sum_x kappa(x)(kappa(x)-1).                  (1.1)
```

I use the ordered factorial convention in `(1.1)`. If the unavailable file writes `binom(kappa,2)`, replace `F_vee` by twice that quantity; every little-o threshold below changes only by an absolute factor.

Since every lower prime is in `I=(T/7,T/3]`,

```text
log p = L + O(1).
```

Consequently the exact marked-incidence reduction gives

```text
Cminus(T,J)+Cplus(T,J) <= C_J L M_vee.                 (1.2)
```

It is therefore enough to prove

```text
M_vee=o_J(B),     B=T^2/L^2.                           (1.3)
```

No sign-separated multiplicity or post-assignment annotation may be substituted for `kappa`; doing so would reintroduce the factor-two ambiguity that the Boolean union removed.

## 2. Theorem 5 consumer, with the actual occupied count

For every occupied state, `kappa>=1`, and

```text
(kappa-1)^2 <= kappa(kappa-1).
```

Hence

```text
M_vee-U
 = sum_{x in S}(kappa(x)-1)
 <= sqrt(U sum_{x in S}(kappa(x)-1)^2)
 <= sqrt(U F_vee).                                     (2.1)
```

Thus

```text
M_vee <= U+sqrt(U F_vee).                              (2.2)
```

The banked upper-zero first moment gives `U=o_J(B)`, so the only nontrivial term is the square root. This proves the caller-quoted state-adaptive condition:

```text
F_vee=o_J(B^2/U)  ==>  M_vee=o_J(B).                   (2.3)
```

The use of the **actual** `U` is legitimate in this implication. It becomes circular only if one later claims a small value of `U` by invoking the same unproved marked load or factorial estimate.

### Sharpness of this Cauchy step

If `kappa(x)=K` on `U` states, then

```text
M_vee-U=U(K-1),
F_vee=UK(K-1),
sqrt(UF_vee)=U sqrt(K(K-1)).
```

The last two quantities are comparable. Therefore no power improvement over `(2.1)` follows from the pair `(U,F_vee)` alone.

## 3. Correct arbitrary-stratum Cauchy inequality

Let `{S_alpha}` be any disjoint partition of the occupied states. It may be formed from modulus scale, upper zero-set size, pre-lower-mark window occupancy, load, or a product of these labels. Put

```text
U_alpha = #S_alpha,
M_alpha = sum_{x in S_alpha} kappa(x),
F_alpha = sum_{x in S_alpha} kappa(x)(kappa(x)-1).
```

Applying `(2.1)` inside each stratum gives

```text
M_alpha <= U_alpha+sqrt(U_alpha F_alpha).              (3.1)
```

After summing,

```text
M_vee <= U+sum_alpha sqrt(U_alpha F_alpha).             (3.2)
```

Therefore the optimal Cauchy-consumable stratified gate is

```text
U=o_J(B),
sum_alpha sqrt(U_alpha F_alpha)=o_J(B).                (SG-Cauchy)
```

“Optimal” here means order-sharp given only the local pairs `(U_alpha,F_alpha)`: constant-load configurations in each stratum saturate `(3.1)` up to constants.

### Coarsening and why a partition is not automatically a gain

For any union `A` of strata,

```text
sum_{alpha in A} sqrt(U_alpha F_alpha)
 <= sqrt((sum_{alpha in A}U_alpha)(sum_{alpha in A}F_alpha)).   (3.3)
```

Thus splitting does not itself beat global Cauchy. It helps only when the bank gives genuinely stronger local information, or when some strata have deterministic load or carrier caps. Repeating the global bound `F_alpha<=F_0` separately in every bin is invalid bookkeeping because it spends the same global factorial budget many times.

### Little-o uniformity

Suppose the number `R(T)` of strata grows. The statements

```text
F_alpha=o_J(B^2/U_alpha) for every alpha
```

are not sufficient unless the little-o is uniform and summable. They only say that each summand in `(3.2)` is `o(B)`; `R(T)` such errors can sum to more than `B`.

A clean sufficient formulation is: choose deterministic budgets `beta_alpha>=0` with `sum beta_alpha<=1`, and require one common `epsilon_J(T)->0` such that

```text
F_alpha
 <= epsilon_J(T)^2 beta_alpha^2 B^2/U_alpha           (3.4)
```

for every nonempty stratum. Then the sum in `(3.2)` is at most `epsilon_J(T)B`. With equal budgets over `R(T)` cells, the local threshold contains `R(T)^(-2)`. For a fixed finite partition, separate little-o statements are enough.

The direct aggregate condition `(SG-Cauchy)` is preferable because it states exactly the summability needed and does not hide a nonuniform diagonal argument.

## 4. Load stratification is sharper than repeating Cauchy

For dyadic `K=2^j>=2`, let

```text
S_K={x:K<=kappa(x)<2K},
M_K=sum_{x in S_K}kappa(x),
F_K=sum_{x in S_K}kappa(x)(kappa(x)-1).
```

On this stratum, `K-1<=kappa-1<2K`, so

```text
F_K/(2K) <= M_K <= F_K/(K-1).                         (4.1)
```

Thus, apart from the singleton stratum,

```text
M_vee=o_J(B)
```

is equivalent up to absolute constants to

```text
sum_{K>=2} F_K/K=o_J(B).                               (SG-load)
```

This is the most occurrence-preserving load-resolved gate. It discounts a factorial pair occurring in a load-`K` fibre by `1/K`, exactly because one occurrence in such a fibre participates in about `K` ordered pairs.

For a further partition by labels `alpha`, the correct local-sum form is

```text
sum_{alpha,K>=2} F_{alpha,K}/K=o_J(B).                 (4.2)
```

If one wants separate local hypotheses, a valid budgeted version is

```text
F_{alpha,K}
 <= epsilon_J(T) beta_{alpha,K} B K,
sum_{alpha,K} beta_{alpha,K}<=1,                       (4.3)
```

with one common `epsilon_J(T)->0`. Merely asserting `F_{alpha,K}=o_J(BK)` cell by cell is not enough for a growing family.

Condition `(4.2)` is very close to the desired occurrence count, so it is best viewed as the optimal **consumer**, not as an independently banked arithmetic theorem. The genuinely new arithmetic input should still be stated as a localized factorial or support estimate on a support-blindly defined exceptional region.

## 6. What the bank closes without a new theorem

Choose `omega(T)->infinity`, with `omega(T)=T^o(1)`, after fixing `J`. Constants depending on `J` can be absorbed by slowing or enlarging `omega`.

### 6.1 Singleton and low-load states

The singleton class has `F=0` and mass at most `U_0=o(B)`. For

```text
2<=kappa(x)<=K_0/omega,
```

one has

```text
M_low <= (K_0/omega)U_0 = B/omega.                    (6.1)
```

This uses only the pre-existing upper-state carrier `(5.1)`, not the target marked mass.

### 6.2 High-load states

For `kappa>=K>=2`,

```text
kappa <= kappa(kappa-1)/(K-1).
```

Hence, on

```text
kappa(x)>=omega K_1,
```

one gets

```text
M_high
 <= F_0/(omega K_1-1)
 <<_J B/omega.                                         (6.2)
```

This is a genuine use of the independently banked factorial estimate. It would be circular to replace `F_0` here by the unproved exceptional MF2 hypothesis and then advertise `(6.2)` as an independent support saving.

### 6.3 A support-blind window/load product class

For each relevant prime `q`, define the **pre-lower-mark legal upper occupancy**

```text
w(q)=# {t:
        0<=t<q,
        q|b_t,
        all deterministic upper masks hold,
        and the quotient-six numerical windows admit a candidate lower p,
        before testing any lower p-zero condition}.    (6.3)
```

Every occupied state over `q` is among these `w(q)` upper states. This is the correct window statistic for a noncircular carrier bound. It may use the upper mark `q|b_t`, because that is part of the state space, but it must not count lower primes or use `kappa` in its definition. If `Z(q)` is the full upper zero-set size, then `w(q)<=Z(q)`.

There are `N_q<<_J T/L` relevant upper primes. Consider states satisfying

```text
kappa(q,t) w(q) <= T/(L omega).                        (6.4)
```

For one fixed `q`, there are at most `w(q)` such `t`, and each has load at most `T/(L omega w(q))`. Therefore

```text
sum_{t satisfying (6.4)} kappa(q,t)
 <= T/(L omega).
```

Summing over q gives

```text
M_product <<_J (T/L)(T/(L omega))
          <<_J B/omega.                                (6.5)
```

This is the cleanest way to exploit window occupancy. It avoids an `O(log^c T)` accumulation because it is one global pointwise class, not a separate estimate for every dyadic `(w,K)` box.

The membership test in `(6.4)` uses the actual load, but the proof is not circular: the threshold is fixed in advance from `T`, `L`, and the pre-lower-mark `w(q)`, and `(6.5)` follows pointwise. No estimate for the distribution of the post-selected loads is assumed.

### 6.4 The exact remaining set

After deleting the three classes above, every remaining state lies in

```text
E_omega={x=(q,t):
          K_0/omega < kappa(x) < omega K_1,
          kappa(x) w(q) > T/(L omega)}.                (6.6)
```

The total mass outside `E_omega` is `o_J(B)`. Moreover `(6.6)` implies

```text
w(q) > K_0/omega^2,                                    (6.7)
```

because `K_0 K_1=T/L`. Thus the remainder is simultaneously intermediate-load and high-window. Since `w(q)<=Z(q)`, it is also contained in the high-upper-zero-set class

```text
Z(q)>K_0/omega^2.                                      (6.8)
```

This is a strict support reduction from global MF2.

## 7. Geometry of the exceptional wedge

Ignore the slowly growing safety factors for one display. Write a window dyadic scale as `W` and a load scale as `K`. For the full macroscopic q-range, the first-moment carrier in a `W`-bin is bounded by

```text
V(W) <= min((T/L)W, U_0).                              (7.1)
```

The first-moment side closes a cell when `K V(W)=o(B)`, while the global factorial side closes the high-load tail when `F_0/K=o(B)`. The nonautomatic cells therefore satisfy

```text
K_0 <= K <= K_1,
K W >= T/L.                                            (7.2)
```

Define

```text
W_0 = U_*/(T/L)
    = T^(2/5)L^(-6/5),                                 (7.3)

W_1 = U_0/(T/L)
    = T^(3/5)L^(1/5).                                  (7.4)
```

Numerically, `W_0=K_0` and `W_1=K_1`. The lower boundary of the wedge is

```text
K >= T/(LW),       W_0<=W<=W_1,
K >= K_0,          W>=W_1,                             (7.5)
```

with `K<=K_1` throughout.

In power coordinates `K=T^(k+o(1))`, `W=T^(w+o(1))`, the unresolved region is the triangle

```text
2/5 <= k <= 3/5,
k+w >= 1.                                              (7.6)
```

At the exact power boundary `k+w=1`, the logarithmic condition is `K W` at least `T/L`; the displayed `L`-powers in `(7.3)`--`(7.4)` are therefore load-bearing, not decoration.

### Modulus scale

If a deterministic q-stratum contains `N_Q` possible primes rather than `T/L`, then `(7.1)` becomes

```text
V_Q(W)<=min(N_Q W,U_{0,Q}).                            (7.7)
```

For a fixed finite collection of modulus strata, the same proof uses each `N_Q`. For a growing collection, assign budgets `beta_Q` with `sum beta_Q<=1` and replace `B` by `beta_Q B`; otherwise one illegitimately gives the full global error budget to every modulus bin. In the actual quotient-six C4 range `q` is macroscopic, `q asymp_J T`, so ordinary dyadic subdivision alone changes constants rather than producing a new `T`-power.

## 8. First remaining stratum and numerical thresholds

There is no unique “first” cell until one specifies whether the partial order starts from low load or from sparse windows. The exact boundary has two corners and one balanced point.

### 8.1 Increasing load first

The first nonautomatic load is

```text
K ~ K_0=T^(2/5)L^(-6/5).
```

To survive the product deletion it must sit over

```text
W ~ W_1=T^(3/5)L^(1/5).
```

On a dyadic load-`K` cell, `(4.1)` says that the local factorial threshold is `F_cell=o(BK)`. At this corner,

```text
F_cell
 =o_J(BK_0)
 =o_J(T^(12/5)L^(-16/5)).                              (8.1)
```

Thus the low-load/high-window corner retains the old global MF2 exponent. Stratification has made the domain much smaller, but the bank does not force a better exponent there.

### 8.2 Increasing window occupancy first

The first nonautomatic window is

```text
W ~ W_0=T^(2/5)L^(-6/5),
```

and it can survive only at


The local threshold is

```text

 =o_J(T^(13/5)L^(-9/5)).                               (8.2)
```

This asks for little-o at the scale of the banked `O(F_0)` estimate, but only on the sparse-window/high-load boundary cell.

### 8.3 Balanced dangerous cell

```text
K=W=K_c=T^(1/2)L^(-1/2).                               (8.3)
```

Here the occupied carrier at boundary size is

```text
U_cell ~ (T/L)W
```

and both the state-adaptive and load-resolved consumers give

This is the cleanest single numerical answer for the genuinely central exceptional stratum. It lies exactly halfway between the two corner exponents.

## 9. Optimal remaining theorem and consumer proof

Let `U_E` and `F_E` be the actual occupied count and ordered factorial moment restricted to `E_omega`.

### Coarsened exceptional theorem

A sufficient new theorem is

```text
Q6-C4-EXC-MF2:
F_E=o_J(B^2/U_E),                                      (9.1)
```

with the convention that it is vacuous when `U_E=0`.

Indeed, by `(2.2)`,

```text
M_E<=U_E+sqrt(U_EF_E)=o_J(B),                          (9.2)
```

because `U_E<=U_0=o(B)`. Sections 6.1--6.3 give `M_{outside E}=o(B)`, hence `M_vee=o(B)`, and `(1.2)` yields

```text
Cminus(T,J)+Cplus(T,J)=o_J(T^2/L).                     (9.3)
```

This is strictly smaller than global MF2 in support: it makes no demand on singleton fibres, either load tail, or low window-load products.

### Occupied-support alternative

The full banked `F_0` already closes the remainder if one proves only

```text
U_E=o_J(U_*),
U_*=T^(7/5)L^(-11/5).                                  (9.4)
```

Indeed `U_EF_E<=U_EF_0=o(B^2)`. Thus a new theorem controlling exceptional occupied states can replace a new factorial theorem entirely.

### Fully stratified optimal gate

If `E_omega` is partitioned into deterministic pre-strata `E_alpha`, the sharp Cauchy consumer is

```text
sum_alpha sqrt(U_alpha F_alpha)=o_J(B).                (9.5)
```

If it is further divided into dyadic load bins, the sharper load consumer is

```text
sum_{alpha,K} F_{alpha,K}/K=o_J(B).                    (9.6)
```

Equations `(9.5)` and `(9.6)`, with their aggregate summation, are the optimal provable stratified gates. The coarsened theorem `(9.1)` is easier to state and is sufficient by Cauchy, but can be stronger than `(9.5)` when local support and factorial mass are anticorrelated.

## 10. Do existing first and second moments close most strata?

### Yes, in exponent geometry

They remove both load tails and all cells below the hyperbola `KW=T/L`. Only the triangular strip `(7.6)` remains. In this precise sense most natural load/window exponent cells are already harmless.

### No, not in actual occupied mass

The bank does not prove that the removed cells contain most states or most incidences. At the level of the banked moments, take a constant load

```text
kappa=K_c=sqrt(F_0/U_0)
```

on `U_0` occupied states, placed over high-window q-fibres. Then

```text
F_vee asymp U_0 K_c^2 = F_0,
M_vee asymp U_0 K_c
      = sqrt(U_0F_0)
      = B T^(1/10)L^(7/10).                            (10.1)
```

This saturates both banked envelopes and exceeds the target by the square root of the Q7287 miss factor. It lies inside the exceptional wedge. This is a moment-interface extremizer, not an asserted Apéry configuration, but it proves that the banked first and second moments alone cannot show that the exceptional mass is negligible.

Consequently one must not report that “most actual states are closed.” What is proved is that **all states outside a precisely defined wedge are closed**.

## 11. What upper-window second moment would finish the support route?

Let

```text
S_2^w=sum_q w(q)^2.                                    (11.1)
```

Split q at a window threshold `Omega`. The pre-lower-mark carrier counts satisfy

```text
V_low <= (T/L)Omega,
V_high<=S_2^w/Omega.                                   (11.2)
```

The global banked factorial estimate closes a carrier union whenever its size is `o(U_*)`. Thus one can choose an `Omega` closing both sides precisely when

```text
S_2^w=o_J(U_*^2/(T/L))
     =o_J(T^(9/5)L^(-17/5)).                           (11.3)
```

This is the exact upper-window second-moment threshold exposed by the state-adaptive reduction. The currently visible bank does not contain `(11.3)`. The banked `F_0` controls lower-prime reuse after the upper state is selected; it is not a bound for `sum_q w(q)^2`. The visible unmarked second-moment scale `T^(11/5)L^(-3/5)` is also for the wrong marginal, and even a hypothetical window bound of that size would miss `(11.3)` by

```text
T^(2/5)L^(14/5).                                       (11.4)
```

Therefore the existing first/second moments do not close the high-window side of the wedge. The smallest clean support-side replacement is `(11.3)`, or directly `(9.4)` for the actually occupied exceptional states.

## 12. Cold audit for circular use of post-selected load

The following uses are valid:

1. Defining `U`, `F_vee`, and load bins from the actual Boolean-union fibres, then applying exact identities such as `(2.1)` or `(4.1)`.
2. Bounding actual occupied counts by a pre-lower-mark carrier formed from `q|b_t`, deterministic windows, modulus ranges, and upper zero-set sizes.
3. Using the independently banked absolute estimate `F_vee<=F_0` to delete the high-load tail.
4. Defining the product class `(6.4)` with a threshold fixed before inspecting which lower primes occur, and bounding it pointwise.
5. Stating the final theorem with the actual `U_E`; state adaptivity is a consumer feature and does not require a lower bound for `U_E`.

The following moves are circular or invalid:

1. `U_{kappa>=K}<=M_vee/K` followed by using this as an independent estimate in a proof whose goal is `M_vee=o(B)`.
2. `U_{kappa>=K}<=F_vee/K^2` when the `F_vee` on the right is the very exceptional theorem being proposed, followed by claiming a separate support gain. It is valid only with the already banked envelope `F_0`.
3. Defining “window occupancy” to mean the number of actual lower marked primes, rather than the pre-lower-mark number of legal upper states, and then billing it as a carrier estimate.
4. Choosing stratum budgets `beta_alpha`, Cauchy weights, or a favorable partition after seeing where the actual factorial mass landed. Budgets must be deterministic or the aggregate sum itself must be proved.
5. Proving `F_alpha=o(B^2/U_alpha)` separately for a growing number of cells without a common rate or summable allocation.
6. Normalizing a Palm or size-biased estimate by the actual marked mass without an independent lower bound for that mass. All estimates used here are absolute.
7. Replacing the actual `U` by a smaller guessed support. Replacing it by a proved upper carrier `V>=U` is valid but loses adaptivity, because `B^2/V<=B^2/U`.
8. Charging the upper mark `q|b_t` once for every lower prime in a star. It is an idempotent state condition, not a repeatable density factor.

The product deletion `(6.4)` survives this audit: it uses post-selected load only to classify a state under a deterministic pointwise ceiling; it never infers how many such states exist from the target marked mass.

## Final answer

