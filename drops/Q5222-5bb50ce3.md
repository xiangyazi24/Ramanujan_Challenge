# 13. Attack on the argument

## 13.1 Did I accidentally erase Palm factorial multiplicity?

No.  The SFL/source-fiber discussion is entirely about a **single characteristic before multiplication**.  The transverse consumer expands
\[

\sum_{p,q}(\log p)(\log q)s_p(a)s_q(a').
\]
Every ordered `(p,q)` pair is retained.  At a row with many hitting characteristics this still creates factorial multiplicity exactly as `pairpalm_result.tex` requires.

The prohibited move would be to replace the `q`-sum after expansion by an existence indicator.  Nothing here does that.

## 13.2 Did I confuse numerical root multiplicity with source multiplicity?

No.  A fixed `(a,b,p)` may have several actual `\mathbb F_p` common roots.  The fixed-gap resultant/Smith argument counts those distinct roots.  Each root is a separate geometric cell.

The source-fiber factor `\Lambda(\gamma)` is applied **after** a numerical root/geometric quadruple has been fixed.  Raw resultant support and nonsplit/projective roots are never promoted to literal occurrences.

## 13.3 Did recentering lose the predecessor marking?

No.  The recentered cell contains an actual consecutive chain beginning at `x=J+a`.  Its immediate previous actual zero is unique.  Therefore `J` and `a` are recovered.  If the current source has an absolute physical-row translate, the only remaining question is whether that absolute row is part of `J` or was summed out before `s_p`; recentering itself creates no new ambiguity.

## 13.4 Can reflection double a fixed source fiber?

No.  The stable selector is the increasing ordered quadruple.  Reflection sends it to the reflected increasing quadruple, generally with a different start.  If a chain is reflection-invariant as a set, the increasing tuple is still one tuple.  A proof branch may orient a reflection orbit, but that orientation is not an independent literal source weight.

## 13.5 Can block overlap create duplicates?

The stable `atom_tail_section.tex` selection uses one partition and sliding consecutive windows.  A zero may belong to several neighboring windows, but those windows have different starts.  For the same ordered quadruple/start there is one selected object.

If the unseen current local `CC2` construction averages several translated partitions and sums them into one `s_p`, that is exactly the source/block translate in `(ST)`.  The stale stable source does not authorize me to declare that averaging absent from the current local bytes.

## 13.6 Does the packet cap itself secretly imply SFL?

No.  It implies only `\Lambda(\gamma)\ll aP^{o(1)}`.  The one-cell saturation packet of Section 5 realizes this logical gap.

## 13.7 Can pair-Palm second moment imply the window averages `(AL0_0)/(AL1_0)`?

Not from the present interfaces.  The pair-Palm moment controls ordered cross-prime intersections of binary physical-row incidences.  `(AL0)/(AL1)` are conditional on a selected first-return geometry and measure any source/block multiplicity remaining after localization.  No theorem in the authoritative stable files transfers the pair-Palm second moment to these selected conditional fibers with the required growing-window uniformity.
