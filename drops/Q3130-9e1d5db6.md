# P3.2 marked Newton–Racah transversality

## Verdict

The proposed statement is **not proved by finite-field anisotropy**, but the marked Christoffel–Darboux norm admits a much sharper exact reduction.

For
\[
D_{m,s}=\sum_k\binom mk\binom{m+k}{k}\binom sk\binom{s+k}{k},
\qquad b_s=D_{s,s},
\]
put
\[
K_s^*=\sum_{m=0}^{s-1}(2m+1)D_{m,s}^2.
\]
Let \(A(z)\) be the entire Apéry interpolation and \(J_s=A'(s)\). Then for every prime
\[
p>2s+1,\qquad p\mid b_s,
\]
one has the exact congruence
\[
\boxed{
K_s^*\equiv
\frac{s^3b_{s-1}}{24(2s+1)}\,J_s\pmod p.
}
\tag{1}
\]
Every factor multiplying \(J_s\) is a \(p\)-unit. Consequently
\[
\boxed{
K_s^*\not\equiv0\pmod p
\iff
J_s\not\equiv0\pmod p.
}
\tag{2}
\]
Thus the marked Newton–Racah norm question is **exactly** the Apéry analytic-index transversality question; it is not merely implied by it.

Moreover, Gessel's mod-\(p^2\) congruence plus the exact reflection \(A(-1-z)=A(z)\) gives
\[
\boxed{
b_{p-1-s}\equiv b_s-pJ_s\pmod{p^2}.}
\tag{3}
\]
If
\[
D(p)=\{d\in\{0,\ldots,p-1\}:b_d\equiv b_{p-1-d}\pmod{p^2}\},
\]
then under the target hypotheses
\[
\boxed{
K_s^*\equiv0\pmod p
\iff J_s\equiv0\pmod p
\iff s\in D(p).
}
\tag{4}
\]
Therefore a counterexample to the proposed nonvanishing is *precisely* an intersection

```text
p > 2s+1,
p | b_s,
s in D(p)  (equivalently b_s == b_{p-1-s} mod p^2).
```

I did **not** find such an intersection in the published initial \(D(p)\) data described below. I also do not see a theorem in the available sources that excludes it for all \(p,s\). So the correct status is: **the conjectured nonvanishing is reduced to a very sharp finite-field condition, but is not globally proved or refuted here.**

There is, however, a clean all-\(s\) distinguished-endpoint identity whose right side is a \(p\)-unit at every target:
\[
\boxed{
\sum_{m=0}^{s-1}(2m+1)D_{m,s}D_{m,s-1}
=\frac{s^2}{4}\left(b_sb_{s-1}-c_s^2\right),
\quad c_s:=D_{s-1,s}=\frac{b_s+b_{s-1}}6.
}
\tag{5}
\]
Hence, if \(p>2s+1\) and \(p\mid b_s\),
\[
\boxed{
\sum_{m=0}^{s-1}(2m+1)D_{m,s}D_{m,s-1}
\equiv-\frac{s^2b_{s-1}^2}{144}\not\equiv0\pmod p.
}
\tag{6}
\]
This is the exact marked bilinear unit identity one would hope for from self-duality. It still does **not** force the diagonal norm \(K_s^*\) to be nonzero over \(\mathbf F_p\); that missing implication would be precisely the forbidden generic-anisotropy step.

## 1. The symmetric kernel is exactly Sun's \(v_n\) family

Write
\[
q_k(t):=\binom tk\binom{t+k}{k}.
\]
For integral \(t\ge0\),
\[
q_k(t)=\frac{(-t)_k(t+1)_k(-1)^k}{(k!)^2}.
\]
Therefore
\[
D_{m,s}=\sum_{k\ge0}q_k(m)q_k(s)
={}_4F_3\!\left(\begin{matrix}-m,m+1,-s,s+1\\1,1,1\end{matrix};1\right),
\tag{7}
\]
and symmetry \(D_{m,s}=D_{s,m}\) is literal.

Set
\[
x_r:=2r(r+1)+1.
\]
Zhi-Hong Sun's polynomial family is
\[
v_0(x)=1,\qquad v_1(x)=x,
\]
\[
(n+1)^3v_{n+1}(x)
=(2n+1)(n(n+1)+x)v_n(x)-n^3v_{n-1}(x).
\tag{8}
\]
Sun's Theorem 3.1 specializes exactly to
\[
\boxed{D_{m,s}=v_m(x_s).}
\tag{9}
\]
Thus for fixed \(s\),
\[
(m+1)^3D_{m+1,s}
=(2m+1)(m(m+1)+x_s)D_{m,s}-m^3D_{m-1,s}.
\tag{10}
\]
The diagonal is the ordinary Apéry number:
\[
b_s=D_{s,s}=v_s(x_s).
\tag{11}
\]

This is the useful finite-field formulation: the mark \(s\) is not an arbitrary evaluation point; it is the distinguished square point
\[
2x_s-1=(2s+1)^2.
\tag{12}
\]

## 2. Exact Christoffel–Darboux formula and its confluent limit

For any positive integer \(N\), the recurrence (8) gives the exact CD identity
\[
\boxed{
\sum_{m=0}^{N-1}(2m+1)v_m(x)v_m(y)
=\frac{N^3}{x-y}
\big(v_N(x)v_{N-1}(y)-v_{N-1}(x)v_N(y)\big).
}
\tag{13}
\]
Letting \(y\to x\),
\[
\boxed{
\sum_{m=0}^{N-1}(2m+1)v_m(x)^2
=N^3\big(v_{N-1}(x)v_N'(x)-v_N(x)v_{N-1}'(x)\big).
}
\tag{14}
\]
These are Sun's equations (3.4)–(3.5), with the displayed upper index there renamed \(N\).

Take \(N=s\) and \(x=x_s\). Put
\[
c_s:=D_{s-1,s}=v_{s-1}(x_s).
\]
Then
\[
\boxed{
K_s^*=s^3\big(c_sv_s'(x_s)-b_sv_{s-1}'(x_s)\big).
}
\tag{15}
\]
This is already the exact marked Bezout/Casoratian boundary term.

## 3. Relating the spectral derivative to the analytic-index derivative

The entire Apéry function is
\[
A(z)
=\sum_{k\ge0}\frac{\Gamma(z+k+1)^2}
{\Gamma(z-k+1)^2\Gamma(k+1)^4}
={}_4F_3(-z,-z,z+1,z+1;1,1,1;1).
\tag{16}
\]
At a nonnegative integer \(s\),
\[
A(s)=b_s,
\]
and its derivative is Gessel's quantity
\[
J_s=A'(s)
=2\sum_{k=0}^s q_k(s)^2\big(H_{s+k}-H_{s-k}\big).
\tag{17}
\]

For fixed integral \(s\), define
\[
F_s(z):=\sum_k q_k(s)q_k(z).
\]
By (9), analytically in the second parameter near \(z=s\),
\[
F_s(z)=v_s(x_z),\qquad x_z=2z(z+1)+1.
\]
Hence
\[
F_s'(s)=2(2s+1)v_s'(x_s).
\tag{18}
\]
On the other hand, differentiating the diagonal sum gives
\[
J_s=2F_s'(s).
\tag{19}
\]
Combining (18) and (19),
\[
\boxed{J_s=4(2s+1)v_s'(x_s).}
\tag{20}
\]

Substitute (20) into (15):
\[
K_s^*
=s^3\left(
\frac{c_sJ_s}{4(2s+1)}-b_sv_{s-1}'(x_s)
\right).
\tag{21}
\]
At a target \(p\mid b_s\),
\[
K_s^*\equiv
\frac{s^3c_s}{4(2s+1)}J_s\pmod p.
\tag{22}
\]

## 4. The endpoint companion \(c_s\) is a unit at every target

The first off-diagonal kernel has the exact contiguous identity
\[
\boxed{
c_s=D_{s-1,s}=\frac{b_s+b_{s-1}}6.}
\tag{23}
\]
Equivalently,
\[
\sum_{k=0}^{s-1}
\binom sk\binom{s+k}{k}
\binom{s-1}{k}\binom{s-1+k}{k}
=\frac{b_s+b_{s-1}}6.
\]
This is the main superdiagonal A352653 of the symmetric Apéry array A143007; the formula \(a(s)=(A005259(s)+A005259(s-1))/6\) is recorded explicitly there.

Now suppose \(p>2s+1\) and \(p\mid b_s\). Then
\[
b_{s-1}\not\equiv0\pmod p.
\tag{24}
\]
Indeed, the Apéry recurrence
\[
n^3b_n-(34n^3-51n^2+27n-5)b_{n-1}+(n-1)^3b_{n-2}=0
\tag{25}
\]
would, if both \(b_s\) and \(b_{s-1}\) vanished modulo \(p\), force \(b_{s-2}\equiv0\), then \(b_{s-3}\equiv0\), and so on to \(b_0=1\), because every integer \(1,\ldots,s\) is a \(p\)-unit.

Since \(p>2s+1\ge3\), \(6\) is also a unit. From (23),
\[
c_s\equiv\frac{b_{s-1}}6\not\equiv0\pmod p.
\tag{26}
\]
Putting (26) into (22) proves (1):
\[
\boxed{
K_s^*\equiv
\frac{s^3b_{s-1}}{24(2s+1)}J_s\pmod p,
}
\]
and every scalar factor is a unit. This establishes (2).

So the hoped-for norm theorem has been reduced without loss:
\[
\text{marked CD nonvanishing}\quad\Longleftrightarrow\quad
\text{simple zero of the Apéry interpolation at }s\pmod p.
\]

## 5. The finite-field reflection criterion: failure iff \(s\in D(p)\)

The Apéry function has the exact reflection
\[
\boxed{A(-1-z)=A(z),}
\tag{27}
\]
which is immediate from the symmetric hypergeometric parameters in (16).

Rowland–Yassawi–Krattenthaler prove that for every prime \(p\), every digit \(d\in\{0,\ldots,p-1\}\), and every integer \(n\), the denominator of \(A'(d)\) is prime to \(p\) and
\[
\boxed{
A(d+pn)\equiv(A(d)+pnA'(d))A(n)\pmod{p^2}.
}
\tag{28}
\]
Take \(d=s\) and \(n=-1\). By (27), \(A(-1)=A(0)=1\), and
\[
A(s-p)=A(p-1-s).
\]
Therefore
\[
\boxed{
b_{p-1-s}\equiv b_s-pJ_s\pmod{p^2}.}
\tag{29}
\]
Equivalently,
\[
pJ_s\equiv b_s-b_{p-1-s}\pmod{p^2}.
\tag{30}
\]
Because the denominator of \(J_s\) is a \(p\)-unit,
\[
J_s\equiv0\pmod p
\iff b_s\equiv b_{p-1-s}\pmod{p^2}.
\tag{31}
\]
The right side is exactly the definition of \(s\in D(p)\). Combining with (2) proves (4).

This is the finite-field obstruction in its sharpest form:

> **A target counterexample exists exactly when an Apéry zero digit is also a mod-\(p^2\) Lucas digit.**

No quadratic-form anisotropy statement enters.

## 6. A genuine all-\(s\) endpoint unit identity

The self-duality gives a particularly clean adjacent-mark specialization of the *nonconfluent* CD formula.

Take in (13)
\[
N=s,\qquad x=x_s,\qquad y=x_{s-1}.
\]
Since
\[
x_s-x_{s-1}=4s,
\tag{32}
\]
and by symmetry
\[
v_s(x_s)=b_s,\quad
v_{s-1}(x_{s-1})=b_{s-1},\quad
v_{s-1}(x_s)=v_s(x_{s-1})=c_s,
\]
we obtain the exact identity
\[
\boxed{
\sum_{m=0}^{s-1}(2m+1)D_{m,s}D_{m,s-1}
=\frac{s^2}{4}(b_sb_{s-1}-c_s^2).
}
\tag{33}
\]
Using (23), this can also be written solely in consecutive Apéry numbers:
\[
\boxed{
\sum_{m=0}^{s-1}(2m+1)D_{m,s}D_{m,s-1}
=\frac{s^2}{144}
\left(36b_sb_{s-1}-(b_s+b_{s-1})^2\right).
}
\tag{34}
\]
At a target,
\[
\boxed{
\sum_{m=0}^{s-1}(2m+1)D_{m,s}D_{m,s-1}
\equiv-\frac{s^2b_{s-1}^2}{144}\pmod p,
}
\tag{35}
\]
which is a \(p\)-unit by (24).

This is a precise all-\(s\) identity with distinguished endpoint and unit right side. It demonstrates that the marked vector
\[
(D_{0,s},\ldots,D_{s-1,s})
\]
is not in the radical of the weighted bilinear form. But it does **not** imply that its self-pairing \(K_s^*\) is nonzero: a nonzero isotropic vector can pair nontrivially with another vector over \(\mathbf F_p\). This is exactly why the generic anisotropy shortcut is unavailable.

## 7. Sun's full finite-field/p-adic norm is also a unit — at the wrong scale

There is a second striking distinguished-square identity. Sun's Theorem 4.4 evaluates
\[
\sum_{m=0}^{p-1}(2m+1)v_m(x)^2
\]
modulo \(p^4\) when \(2x-1\) is a square modulo \(p\).

For the marked point \(x=x_s\), equation (12) is an *integer* square. Under \(p>2s+1\), Sun's parameters are
\[
x_0=s+1,\qquad x_1=0.
\]
His theorem therefore specializes to
\[
\boxed{
\sum_{m=0}^{p-1}(2m+1)D_{m,s}^2
\equiv \frac{p^2}{2s+1}\pmod{p^4}.
}
\tag{36}
\]
In particular the full \(p\)-range norm has exact \(p\)-adic valuation \(2\).

This still does not settle \(K_s^*\). The reason is visible already modulo \(p\). For \(k\le s<p\),
\[
q_k(p-1-m)\equiv q_k(m)\pmod p,
\]
because \((p-1-m)(p-m)\equiv m(m+1)\pmod p\). Hence
\[
D_{p-1-m,s}\equiv D_{m,s}\pmod p,
\tag{37}
\]
while
\[
2(p-1-m)+1\equiv-(2m+1)\pmod p.
\tag{38}
\]
The reflected terms cancel pairwise in the full norm modulo \(p\), and the central weight is itself \(0\pmod p\). Thus (36) measures a first nonzero \(p^2\)-defect of the *whole reflected orbit*; it cannot by itself prevent the short prefix \(K_s^*\) from vanishing.

So (36) is strong confirmation that the distinguished square is the right finite-field geometry, but (1)/(4), not (36), is the exact criterion for the marked prefix.

## 8. Counterexample audit against the published \(D(p)\) table

Rowland–Yassawi–Krattenthaler list the first several primes for which \(D(p)\) has at least four digits:
\[
\begin{array}{c|l}
p&D(p)\\ \hline
7&\{0,2,3,4,6\}\\
23&\{0,7,11,15,22\}\\
43&\{0,5,18,21,24,37,42\}\\
59&\{0,6,29,52,58\}\\
79&\{0,18,39,60,78\}\\
103&\{0,17,51,85,102\}\\
107&\{0,14,21,47,53,59,85,92,106\}\\
127&\{0,17,63,109,126\}\\
131&\{0,62,65,68,130\}\\
139&\{0,68,69,70,138\}\\
151&\{0,19,75,131,150\}\\
167&\{0,35,64,83,102,131,166\}.
\end{array}
\tag{39}
\]
Only digits strictly below \((p-1)/2\) can satisfy \(p>2s+1\).

OEIS A133370 records primes that divide no Apéry number at all. It eliminates
\[
7,23,43,79,103,107,127,131,167
\]
from (39) immediately.

The three remaining displayed primes have the following lower-half exceptional digits:
\[
(p,s)=(59,6),(139,68),(151,19).
\]
Using the exact Apéry values (OEIS A005259 b-file),
\[
b_6=21460825\equiv47\pmod{59},
\tag{40}
\]
\[
b_{68}\equiv11\pmod{139},
\tag{41}
\]
\[
b_{19}=320453816254421403579490445\equiv59\pmod{151}.
\tag{42}
\]
So none is a target.

For reference, the smallest target \((p,s)=(5,1)\) has
\[
K_1^*=1,
\]
and hence is also nonexceptional.

Therefore **there is no counterexample in the published initial nontrivial \(D(p)\) table ending at \(p=167\)**. This is finite evidence only; I do not promote it to an all-prime theorem.

## 9. What remains, exactly

The Newton–Racah route has removed the quadratic-form ambiguity completely. The remaining statement is the one-dimensional finite-field assertion
\[
\boxed{
\forall p>2s+1:\quad p\mid b_s\Longrightarrow J_s\not\equiv0\pmod p.
}
\tag{43}
\]
By (29), equivalently
\[
\boxed{
 p\mid b_s\Longrightarrow b_{p-1-s}\not\equiv b_s\pmod{p^2}.
}
\tag{44}
\]
Or, in the digit language,
\[
\boxed{
\{s:0\le s<(p-1)/2,\ p\mid b_s\}\cap D(p)=\varnothing.
}
\tag{45}
\]

That is the next theorem one actually has to prove. Any proposed finite-field hypergeometric argument can now be judged against (45): if it does not separate Apéry zero digits from \(D(p)\), it does not settle the marked CD norm.

The two exact endpoint identities obtained here are complementary:

1. diagonal/confluent:
   \[
   K_s^*\equiv
   \frac{s^3b_{s-1}}{24(2s+1)}J_s\pmod p;
   \]
2. adjacent/nonconfluent:
   \[
   \sum_{m<s}(2m+1)D_{m,s}D_{m,s-1}
   \equiv-\frac{s^2b_{s-1}^2}{144}\pmod p.
   \]

The second gives a genuine unit but cannot rule out isotropy; the first gives the exact transversality scalar but leaves its nonvanishing equivalent to (45). I do not see an honest way to bridge that final gap from current CD/orthogonality identities alone.
