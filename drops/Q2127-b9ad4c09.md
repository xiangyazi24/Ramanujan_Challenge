# 1. Factorial gauge and the exact continuant transfer

Put

```text
c_n := (n!)^3 * b_n.
```

Then the Apéry recurrence becomes

```text
c_{n+1} = P(n)*c_n - n^6*c_{n-1},

P(n)=34*n^3+51*n^2+27*n+5.                    (1.1)
```

Define the denominator-free continuants by

```text
N_0(x) = 0,
N_1(x) = 1,

N_{h+1}(x)
  = P(x+h)*N_h(x) - (x+h)^6*N_{h-1}(x)

for h>=1.                                         (1.2)
```

Thus

```text
N_2(x)=P(x+1).
```

## Proposition 1.1 -- exact propagation

For every `r>=0` and `h>=1`,

```text
c_{r+h}
 = N_h(r)*c_{r+1}
   - (r+1)^6*N_{h-1}(r+1)*c_r.                  (1.3)
```

Proof: `h=1` is tautological; `h=2` is (1.1) at `n=r+1`; induction is the recurrence (1.2).

Applying (1.3) once more gives

```text
c_{r+h+1}
 = N_{h+1}(r)*c_{r+1}
   - (r+1)^6*N_h(r+1)*c_r.                      (1.4)
```

Equivalently, with the column state

```text
C_r := (c_{r+1}, c_r)^T,
```

one has

```text
C_{r+h}
 = T_h(r) * C_r,

T_h(r)
 = [ N_{h+1}(r)   -(r+1)^6*N_h(r+1)       ]
   [ N_h(r)       -(r+1)^6*N_{h-1}(r+1)   ].     (1.5)
```

## Proposition 1.2 -- exact continuant Cassini / Wronskian identity

For every `h>=1`,

```text
N_{h+1}(r)*N_{h-1}(r+1)
 - N_h(r)*N_h(r+1)

 = - product_{j=2}^h (r+j)^6.                   (1.6)
```

The product is `1` when `h=1`.

Proof: the determinant of one factorial-gauge transfer step is `(r+j)^6`.  Hence

```text
det T_h(r) = product_{j=1}^h (r+j)^6.            (1.7)
```

Taking the determinant of the displayed matrix in (1.5), factoring `(r+1)^6`, and cancelling gives (1.6).

This is the exact discrete Wronskian identity attached to the continuant propagation.

# 2. Exact characteristic-zero formula for D(r,s)

```text

Q_h(r) := product_{j=1}^h (r+j)^3,
Q_0(r) := 1.                                      (2.1)
```

```text
b_{r+h}
 = ((r+1)^3*N_h(r) / Q_h(r))*b_{r+1}
   - ((r+1)^6*N_{h-1}(r+1) / Q_h(r))*b_r.         (2.2)
```

Similarly,

```text
b_{r+h+1}
 = ((r+1)^3*N_{h+1}(r) / Q_{h+1}(r))*b_{r+1}
   - ((r+1)^6*N_h(r+1) / Q_{h+1}(r))*b_r.         (2.3)
```

Substitute (2.2)--(2.3) into

```text
D(r,r+h)
 = b_r*b_{r+h+1} - b_{r+h}*b_{r+1}.              (2.4)
```

After multiplying by the exact common endpoint denominator `Q_{h+1}(r)`, one obtains:

```text
Q_{h+1}(r) * D(r,r+h)

 = -(r+1)^3*(r+h+1)^3*N_h(r)*b_{r+1}^2

   + [
       (r+1)^3*N_{h+1}(r)
       + (r+1)^6*(r+h+1)^3*N_{h-1}(r+1)
     ] * b_r*b_{r+1}

   - (r+1)^6*N_h(r+1)*b_r^2.                    (2.5)
```

This is an exact characteristic-zero identity.  Every endpoint factor has been displayed; no modular argument is used.

A useful congruence form of (2.5) is

```text
Q_{h+1}(r) * D(r,r+h)
```

# 3. An exact discrete Christoffel-Darboux / Lagrange identity

The continuant identity is not the only exact formula.  There is a direct telescoping identity which exposes a genuine gap factor.

Fix `h>=1` and define

```text
W_n^(h)
 := (n+1)^3
    * ( b_n*b_{n+h+1} - b_{n+1}*b_{n+h} ).       (3.1)
```

Also set

```text
W_{-1}^(h) := 0.                                  (3.2)
```

Using the recurrence once for `b_{n+1}` gives

```text
W_n^(h) - W_{n-1}^(h)

 = b_n * [
      ((n+1)^3-(n+h+1)^3)*b_{n+h+1}
      + (P(n+h)-P(n))*b_{n+h}
      + (n^3-(n+h)^3)*b_{n+h-1}
   ].                                              (3.3)
```

Every coefficient difference has a factor `h`:

```text
(n+1)^3-(n+h+1)^3
 = -h * [ 3*(n+1)^2 + 3*h*(n+1) + h^2 ],

P(n+h)-P(n)
 = h * [
      102*n^2 + 102*n*h + 34*h^2
      + 102*n + 51*h + 27
   ],

n^3-(n+h)^3
 = -h * [ 3*n^2 + 3*n*h + h^2 ].                  (3.4)
```

Summing (3.3) from `n=0` to `n=r` gives the exact Christoffel-Darboux-type identity

```text
(r+1)^3 * D(r,r+h)

 = h * sum_{n=0}^r b_n * {
      -[3*(n+1)^2 + 3*h*(n+1) + h^2] * b_{n+h+1}

      +[102*n^2 + 102*n*h + 34*h^2
        +102*n + 51*h + 27] * b_{n+h}

      -[3*n^2 + 3*n*h + h^2] * b_{n+h-1}
   }.                                               (3.5)
```

Everything on the right of the outer factor `h` is an integer.

Therefore:

```text
h divides (r+1)^3 * D(r,r+h).                       (3.6)
```

Equivalently,

```text
h / gcd(h,(r+1)^3)
    divides
D(r,r+h).                                          (3.7)
```

Since

```text
gcd(h,r+1) = gcd(h,r+h+1),                         (3.8)
```

the same endpoint obstruction can be written with `s+1`.

This is a genuine explicit endpoint/gap factor forced in characteristic zero.

For a finite index set `R`, define

```text
F_gap(R)
 := gcd_{i<j} [
      (r_j-r_i)
      / gcd(r_j-r_i,(r_i+1)^3)
    ].                                              (3.9)
```

Then

```text
F_gap(R) divides Delta_2(R).                        (3.10)
```

Also

```text
F_gap(R) <= max(R)-min(R) < q                       (3.11)
```

for a q-root set.  Thus this entire uniformly forced gap contribution has only logarithmic height.

It is **not** the whole auxiliary support; Section 6 gives an exact counterexample.

# 4. The exact normalized determinant lattice

Let

```text
R = {r_0,...,r_{m-1}},

V_R := matrix with rows
       (b_{r_i}, b_{r_i+1}).                       (4.1)
```

Let `delta_2(V_R)` denote the gcd of all `2x2` minors.  By definition,

```text
Delta_2(R)=delta_2(V_R).                            (4.2)
```

Assume now that `q` is prime and

```text
q | b_{r_i}
```

for every `i`.  Define the first-divided matrix

```text
W_R := matrix with rows
       (b_{r_i}/q, b_{r_i+1}).                     (4.3)
```

The entire first column of `V_R` is `q` times the first column of `W_R`.  Therefore **every** `2x2` minor is exactly multiplied by `q`, and hence

```text
Delta_2(R)
 = q * delta_2(W_R).                               (4.4)
```

No hypothesis on the individual q-adic valuations of the `b_{r_i}` is needed.

This is the exact normalized-gcd identity asked for in Question 2.

## 4.1 Smith interpretation

If the rows span `Q^2`, let

```text
L_R := Z-span of the rows of W_R in Z^2.            (4.5)
```

Then Smith normal form gives

```text
delta_2(W_R)
 = [ Z^2 : L_R ].                                  (4.6)
```

Thus the normalized cofactor is literally the index of the first-divided state lattice.

## 4.2 The q-adic criterion

From (4.4),

```text
v_q(Delta_2(R))
 = 1 + v_q(delta_2(W_R)).                           (4.7)
```

Therefore

```text
v_q(Delta_2(R)) = 1

<=>
rank_Fq(W_R mod q) = 2.                            (4.8)
```

Equivalently, there must exist two roots `r_i,r_j` such that

```text
(b_{r_i}/q)*b_{r_j+1}
 - (b_{r_j}/q)*b_{r_i+1}

is nonzero mod q.                                  (4.9)
```

The observed `v_q=1` for `q<=3000` is exactly evidence for (4.8).  The second-order recurrence by itself does not force (4.8).

## 4.3 Auxiliary-prime support is unchanged by dividing out q

Equivalently,

This is the key obstruction.

That is genuine new arithmetic.  It is not a consequence of rank two or of the continuant recurrence.

# 5. Separating row-content primes from genuine line-collision primes

Some small auxiliary primes can enter because an individual state row is already zero modulo that prime.

Put

```text
g_r := gcd(b_r,b_{r+1}),

u_r := (b_r/g_r, b_{r+1}/g_r),                     (5.1)
```

so `u_r` is primitive.

For a prime `ell`, write

```text
a_i := v_ell(g_{r_i}),

e_ij := v_ell(det(u_{r_i},u_{r_j})).               (5.2)
```

Then exactly

```text
v_ell(Delta_2(R))
 = min_{i<j} (a_i+a_j+e_ij).                        (5.3)
```

Thus there are two mechanisms:

```text
CONTENT:
  enough selected rows are themselves 0 mod ell;

PROJECTIVE:
  the ell-primitive selected rows collapse to one line mod ell.  (5.4)
```

There is a simple endpoint restriction on the content mechanism.

## Proposition 5.1

If a prime `ell` divides both `b_n` and `b_{n+1}`, then

```text
ell <= n.                                           (5.5)
```

Proof: if `ell>n`, then `n` is invertible modulo `ell`.  The recurrence at `n` implies `ell|b_{n-1}`.  Repeating backwards forces `ell|b_0=1`, impossible.

Hence every prime in the content of the state `v_n` is at most its left endpoint.

This explains one source of the small auxiliary primes seen in computations, but it still gives only an exponential-size primorial envelope in the worst case:

```text
product_{ell<=n} ell = exp((1+o(1))*n).             (5.6)
```

So content control alone does not give the desired `exp(o(q))` cofactor.

More importantly, the next section shows that even after all three states are primitive, a genuinely large non-endpoint auxiliary prime can occur.

# 7. A primitive recurrence-compatible family with an arbitrary auxiliary prime

This is a second, different **COUNTEREXAMPLE**, aimed only at the phrase "from the recurrence alone".

Consider the denominator-free recurrence

```text
y_{n+1}=P(n)*y_n-n^6*y_{n-1}.                       (7.1)
```

For arbitrary integer initial values `(y_0,y_1)`, every `y_n` is an integer.

Fix any prime `ell`.  The value `y_ell` is a Z-linear form in `(y_0,y_1)`.  Modulo `ell`, choose a nonzero initial vector in its kernel:

```text
y_ell == 0 (mod ell),
(y_0,y_1) != (0,0) (mod ell).                       (7.2)
```

Such a nonzero vector always exists because one homogeneous linear equation in two variables over `F_ell` has nonzero solutions.  Lift it to coprime integers; dividing a common integer content if necessary does not destroy (7.2), because that content is an `ell`-unit.

At the singular step `n=ell`,

```text
y_{ell+1}
 = P(ell)*y_ell - ell^6*y_{ell-1}
 == 0 (mod ell).                                    (7.3)
```

Now two consecutive terms are divisible by `ell`, so forward induction gives

```text
y_n == 0 (mod ell)
for every n>=ell.                                   (7.4)
```

Hence, for the integer state

```text
Y_n=(y_n,y_{n+1}),                                  (7.5)
```

all states with `n>=ell` are zero modulo `ell`.  For example, with

```text
R_ell={ell,ell+1,ell+2},                            (7.6)
```

every `2x2` state minor is divisible by `ell^2`.

Since `ell` was arbitrary, recurrence-compatible primitive integer orbits can have arbitrarily large common state-minor primes.

# 8. First divided q-adic reflection: a one-index criterion for v_q=1

The finite observation `v_q(Delta_2)=1` can be sharpened to an exact congruence criterion, although I do not see a proof that the criterion is always nonzero.

For `0<=k<=r`, put

```text
A(r,k)=binom(r,k)^2*binom(r+k,k)^2,

U(r,k)=H_{r+k}-H_{r-k}
      = sum_{j=r-k+1}^{r+k} 1/j,

G_r := 2*sum_{k=0}^r A(r,k)*U(r,k).                 (8.1)
```

All denominators in `G_r` are q-units when `r<q`.

## Proposition 8.1 -- reflection modulo q^2

Let `q` be an odd prime and

```text
0 <= r <= (q-1)/2.
```

Then

```text
b_{q-1-r}
 == b_r - q*G_r
    (mod q^2).                                      (8.2)
```

Proof.  For `k<=r`, write the two binomial factors as exact products:

```text
binom(q-1-r,k)
 = (-1)^k * binom(r+k,k)
   * product_{j=1}^k (1-q/(r+j)),

binom(q-1-r+k,k)
 = (-1)^k * binom(r,k)
   * product_{j=r-k+1}^{r} (1-q/j).                 (8.3)
```

Squaring both and retaining the first q-adic digit gives

```text
binom(q-1-r,k)^2 * binom(q-1-r+k,k)^2

 == A(r,k) * (1-2*q*U(r,k))
    (mod q^2).                                      (8.4)
```

For `k>r`, the second binomial coefficient contains exactly one factor `q`, so its square is `0 mod q^2`.  Summing (8.4) proves (8.2).

Now assume `q|b_r`, put

```text
a_r := b_r/q,
s := q-1-r,
r < (q-1)/2.                                       (8.5)
```

Then

```text
b_s/q == a_r-G_r (mod q),                           (8.6)

b_{s+1}=b_{q-r} == b_{r-1} (mod q).                 (8.7)
```

Therefore

```text
D(r,s)/q
 == a_r*b_{r-1} - (a_r-G_r)*b_{r+1}
    (mod q).                                        (8.8)
```

At a root `q|b_r`, the recurrence gives

```text
r^3*b_{r-1} + (r+1)^3*b_{r+1} == 0 (mod q).        (8.9)
```

Since `r` and `b_{r+1}` are q-units,

```text
D(r,q-1-r)/q

 == b_{r+1} * [
      G_r
      - a_r * (r^3+(r+1)^3)/r^3
    ]
    (mod q).                                        (8.10)
```

Thus a reflected root pair already proves `v_q(Delta_2)=1` if the bracket in (8.10) is nonzero for that pair.

But the bracket contains

```text
a_r = b_r/q mod q,                                  (8.11)
```

the first q-adic digit of the actual Apéry value.  I know no recurrence identity forcing (8.10) to be nonzero for every root.

If `r=(q-1)/2` is the central fixed point, (8.2) reduces to

```text
G_r == 0 (mod q),                                   (8.12)
```

and again gives no automatic rank-two statement for the first-divided rows.

So Section 8 gives a concrete, one-index route to proving the observed q-adic saturation, but it does not close it.

# 9. What can be bounded unconditionally about the cofactor?

Because `Delta_2(R)/q` divides every normalized pair determinant,

```text
Delta_2(R)/q
 <= min_{i<j} |D(r_i,r_j)|/q.                       (9.1)
```

The binomial sum gives a crude exponential bound.  For `0<=k<=n`,

```text
binom(n,k) <= 2^n,
binom(n+k,k) <= 2^(n+k) <= 4^n.
```

Hence

```text
b_n <= (n+1)*64^n.                                  (9.2)
```

Therefore, for `r,s<q`,

```text
|D(r,s)|
 <= b_r*b_{s+1}+b_s*b_{r+1}
 <= exp(O(q)).                                      (9.3)
```

So

```text
Delta_2(R)/q <= exp(O(q)).                          (9.4)
```

This is the trivial height scale from the question.

Neither (2.5) nor the Christoffel-Darboux identity (3.5) improves `O(q)` to `o(q)` for an arbitrary q-root set.  The reason is structural, not just a poor estimate: auxiliary primes `ell!=q` are exactly the cross-prime line-collapse primes in (4.11), and the characteristic-zero recurrence supplies no support restriction for them.

The forced gap factor (3.9) is harmless:

```text
log F_gap(R)=O(log q).                               (9.5)
```

The row-content mechanism is not harmless by itself: the primorial envelope in (5.6) is still exponential.

The primitive projective mechanism can contain primes larger than every endpoint, as the exact `101` example proves.

Therefore the requested pointwise theorem

```text
Delta_2(R_q)/q = exp(o(q))                          (9.6)
```

remains **OPEN for actual q-root sets** and cannot be obtained from the recurrence identities proved here without a new cross-prime selectedness theorem.

# 10. The unmarked determinant does not directly detect Apéry roots

There is another exact obstruction to using `Delta_2` as a residual-gate carrier.

For a prime `p` larger than all indices, the condition

```text
p | gcd_{i<j} D(r_i,r_j)                            (10.1)
```

means only that the state rows are projectively equal modulo `p`.  It does **not** say that their first coordinates vanish.

The exact counterexample in Section 6 already shows this:

```text
101 | gcd(D(1,19),D(1,22),D(19,22)),
```

but `101` is not being selected by the zero condition `101|b_1`.

To recover source-faithful selectedness, one must mark one root coordinate.

## Proposition 10.1 -- exact marked pair detector

Let

```text
q > s > r >= 0
```

be prime.  Then

```text
q | gcd( b_r, D(r,s) )

<=>
q | b_r and q | b_s.                                (10.2)
```

Proof.  The forward implication gives `q|b_r`.  Because `r<q`, two consecutive Apéry values cannot both vanish modulo q; hence `q` is a unit on `b_{r+1}`.  Now

```text
D(r,s)
 == -b_s*b_{r+1} (mod q),                           (10.3)
```

so `q|D(r,s)` implies `q|b_s`.  The converse is immediate.

Combining with (2.7), on this channel one also has

```text
q | gcd(b_r,D(r,s))

<=>
q | gcd(b_r,N_{s-r}(r)).                            (10.4)
```

Thus the marked state determinant is support-equivalent to the Q2104 selected continuant gcd.

## Proposition 10.2 -- exact marked triple detector

For

```text
q > t > s > r,
```

one has

```text
q | gcd( b_r, D(r,s), D(r,t) )

<=>
q | b_r, q | b_s, q | b_t.                         (10.5)
```

This is again just (10.3) twice.

So the correct state-lattice carrier for the residual problem is **marked**.  The unmarked `Delta_2` is a projective-collision carrier and contains false positives.

# 11. Exact relation to the residual gate

Let

```text
z_q(N)
 := #{ 0<=r<N : q|b_r },

K_N
 := log N/(loglog N)^2.                             (11.1)
```

The target is

```text
sum_q (z_q(N)-K_N)_+
 = o(N/loglog N).                                   (11.2)
```

## 11.1 Exact marked pair moment

Define

```text
C2_state(N)
 := sum_{0<=r<s<N}
      log Rad_(N,2N] gcd( b_r, D(r,s) ).            (11.3)
```

By Proposition 10.1, for every prime `N<q<=2N` the prime q appears once for each pair of q-roots.  Therefore exactly

```text
C2_state(N)
 = sum_{N<q<=2N} binom(z_q(N),2)*log q.             (11.4)
```

This is a genuine theorem, with no false positives in the specified prime window.

For `z>=K`,

```text
binom(z,2)-binom(K,2)
 = sum_{j=K}^{z-1} j
 >= K*(z-K).                                        (11.5)
```

Hence

```text
(z-K)_+
 <= binom(z,2)/K.                                   (11.6)
```

Since `log q >= log N`,

```text
sum_{N<q<=2N} (z_q(N)-K_N)_+

 <= C2_state(N)/(K_N*log N).                        (11.7)
```

Thus a sufficient aggregate theorem is

```text
C2_state(N)
 = o( K_N*N*log N/loglog N )

 = o( N*(log N)^2/(loglog N)^3 ).                  (11.8)
```

But, by (10.4), this is exactly the same fixed-pair selected-gcd target already present in Q2104.  The state determinant has not lowered the arithmetic difficulty.

## 11.2 Exact marked triple moment

Define

```text
C3_state(N)
 := sum_{0<=r<s<t<N}
      log Rad_(N,2N]
        gcd( b_r, D(r,s), D(r,t) ).                 (11.9)
```

Then Proposition 10.2 gives exactly

```text
C3_state(N)
 = sum_{N<q<=2N} binom(z_q(N),3)*log q.             (11.10)
```

For `z>=K`,

```text
binom(z,3)-binom(K,3)
 = sum_{j=K}^{z-1} binom(j,2)
 >= binom(K,2)*(z-K).                               (11.11)
```

Therefore

```text
sum_q (z_q(N)-K_N)_+

 <= C3_state(N)/(binom(K_N,2)*log N).               (11.12)
```

A sufficient triple-moment theorem is consequently

```text
C3_state(N)
 = o( binom(K_N,2)*N*log N/loglog N )

 = o( N*(log N)^3/(loglog N)^5 ).                  (11.13)
```

Again this is a fixed-order factorial-moment route.  It gives only the expected `K_N^2` combinatorial gain and requires a new aggregate gcd estimate.

## 11.3 Why a pointwise cofactor theorem does not close the gate

Suppose, hypothetically, one proved for every high-zero prime q that

```text
Delta_2(R_q)/q = exp(o(q)).                         (11.14)
```

This still does not imply (11.2), for two separate reasons.

First, `R_q` itself depends on q.  The integer `Delta_2(R_q)` is therefore a different, q-selected integer for every prime.  There is no common global carrier whose height is being divided among many q's.

Second, the q-adic state rank saturates at dimension two:

```text
q | Delta_2(R_q)
```

provides one copy of q, no matter whether `z_q=3`, `30`, or `300`.  This is exactly the rank-two Smith saturation already isolated in Q2104.

Thus the pointwise cofactor theorem would be interesting arithmetic information, but it would not by itself estimate the excess multiplicity `(z_q-K_N)_+`.

To feed the gate one needs an **aggregate marked moment** such as (11.8) or (11.13), or a genuinely growing-order replacement.

So the answer to Question 4 is:

```text
The exact marked state-minor identities feed the residual gate
as a valid reduction.

The currently proved characteristic-zero determinant identities
and the normalized Delta_2/q lattice identity do NOT supply the
needed aggregate bound.

The unmarked Delta_2 route has no automatic multiplicity gain
and is not source-faithful without a marked b_r factor.          (11.15)
```

# 13. Minimal exact Python / SymPy checker

This checker verifies the nontrivial characteristic-zero identities for small indices and the exact `101` counterexample.  It is a checker only; none of the proofs above depend on it.

```python
from math import gcd, prod
from sympy import factorint


def P(n):
    return 34*n**3 + 51*n**2 + 27*n + 5


def apery(limit):
    b = [1, 5]
    for n in range(1, limit):
        num = P(n)*b[n] - n**3*b[n-1]
        den = (n+1)**3
        assert num % den == 0
        b.append(num // den)
    return b


def D(b, r, s):
    return b[r]*b[s+1] - b[s]*b[r+1]


def continuant(h, x):
    # N_0=0, N_1=1,
    # N_{m+1}=P(x+m)N_m-(x+m)^6 N_{m-1}
    if h == 0:
        return 0
    if h == 1:
        return 1
    a, c = 0, 1
    for m in range(1, h):
        a, c = c, P(x+m)*c - (x+m)**6*a
    return c


def Q(r, h):
    return prod((r+j)**3 for j in range(1, h+1))


def check_continuant_D(b, r, h):
    # Equation (2.5).
    lhs = Q(r, h+1) * D(b, r, r+h)
    rhs = (
        -(r+1)**3*(r+h+1)**3
        * continuant(h, r) * b[r+1]**2
        + (
            (r+1)**3*continuant(h+1, r)
            + (r+1)**6*(r+h+1)**3
              * continuant(h-1, r+1)
          ) * b[r]*b[r+1]
        - (r+1)**6*continuant(h, r+1)*b[r]**2
    )
    assert lhs == rhs


def check_cassini(r, h):
    lhs = (
        continuant(h+1, r)*continuant(h-1, r+1)
        - continuant(h, r)*continuant(h, r+1)
    )
    rhs = -prod((r+j)**6 for j in range(2, h+1))
    assert lhs == rhs


def check_lagrange(b, r, h):
    total = 0
    for n in range(r+1):
        total += b[n] * (
            -(3*(n+1)**2 + 3*h*(n+1) + h*h)
              * b[n+h+1]
            + (102*n*n + 102*n*h + 34*h*h
               + 102*n + 51*h + 27)
              * b[n+h]
            - (3*n*n + 3*n*h + h*h)
              * b[n+h-1]
        )
    assert (r+1)**3 * D(b, r, r+h) == h*total


b = apery(40)

for r in range(0, 7):
    for h in range(1, 6):
        check_continuant_D(b, r, h)
        check_cassini(r, h)
        check_lagrange(b, r, h)

# Exact primitive triple counterexample.
d1 = D(b, 1, 19)
d2 = D(b, 1, 22)
d3 = D(b, 19, 22)
g = gcd(gcd(abs(d1), abs(d2)), abs(d3))

assert d1 == 27061583764762207702911377520
assert d2 == 869991267225667034275852256340696
assert d3 == 1024389911536910183491784219857893585044957351762229298152
assert g == 7272
assert factorint(g) == {2: 3, 3: 2, 101: 1}

assert gcd(b[1], b[2]) == 1
assert gcd(b[19], b[20]) == 1
assert gcd(b[22], b[23]) == 1

states_mod_101 = [
    (b[n] % 101, b[n+1] % 101)
    for n in (1, 19, 22)
]
assert states_mod_101 == [(5, 73), (2, 9), (10, 45)]

# 61*(5,73) = (2,9), 2*(5,73) = (10,45) mod 101.
assert tuple((61*x) % 101 for x in states_mod_101[0]) == states_mod_101[1]
assert tuple((2*x) % 101 for x in states_mod_101[0]) == states_mod_101[2]

# 101 is not an endpoint/gap prime for this triple.
assert all(x % 101 for x in (2, 20, 23, 18, 21, 3))

print("all exact checks passed")
```

# Final answer to the four requested questions

## 1. Characteristic-zero identity

Yes.  Equations (2.5) and (3.5) are exact.  The first is the continuant/factorial-gauge identity with every endpoint denominator displayed.  The second is an exact discrete Lagrange/Christoffel-Darboux formula and proves the explicit divisor

```text
(r_j-r_i) / gcd(r_j-r_i,(r_i+1)^3)
  divides D(r_i,r_j).
```

## 2. Normalized determinant gcd

Exactly

```text
Delta_2(R_q)/q
 = delta_2( (b_r/q,b_{r+1})_{r in R_q} ).
```

For `ell!=q`, its support is exactly the set of primes for which the original selected states all collapse to one projective line modulo `ell`.  I do not see a recurrence proof of `exp(o(q))`; the missing input is a cross-prime selectedness theorem.

## 3. Obstruction / counterexample

There are two.

```text
Actual Apéry, primitive states:
R={1,19,22} has common auxiliary prime 101,
which is not an endpoint or gap prime.
```

And, for the denominator-free recurrence, every prescribed prime can be made a common state-minor prime in a primitive integer orbit by forcing `y_ell=0 mod ell` at the singular step.

So recurrence-only normalized-gcd control is decisively false in the broad sense required for a generic lattice argument.

## 4. Residual gate

The unmarked `Delta_2` does not close it.  It is both unmarked and rank-two saturated.

The source-faithful state determinant is

```text
gcd(b_r,D(r,s)),
```

and its aggregate is exactly the selected pair factorial moment.  Therefore the state-lattice route feeds the residual gate only if one proves a new aggregate estimate such as

```text
C2_state(N)
 = o( N*(log N)^2/(loglog N)^3 ).
```

That theorem is currently open and is support-equivalent to the Q2104 selected-continuant gcd target.

So the net result is a **decisive recurrence-only no-go plus two exact identities and a clean first-divided q-adic criterion**, not a closure of the all-q tail.
