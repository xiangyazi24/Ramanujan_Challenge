# Unconditional combinatorial baseline for one target-regular Apéry full-defect fibre

## 1. The fibre object is not parametrized by t alone

The fibre counts tuples

\[
(m,p_1<p_2<p_3),
\]

or equivalently the data

\[
(t,N,p_i,c_i),
\]

with

\[
z_1=t,\qquad z_i=t+d_i,
\]

and

\[
N-d_i=c_i p_i,
\qquad 1\le c_i<X.
\]

The statement "the trivial fibre bound is O(X) because t has O(X) choices" is false.  The variable N is not determined by t.

For fixed t, the possible N satisfy

\[
N\in [0,X^2+X+O(X)],
\]

subject to the three shell factorizations. Without using any arithmetic information, there are O(X^2) possible (t,N) pairs.

Thus the raw translation bound is

\[
|T_X(s,d_2,d_3)|\le O(X^3),
\]

not O(X).

---

## 2. Shell-prime uniqueness reduction

For each positive integer

\[
n_i=N-d_i<X^2+X,
\]

there is at most one shell prime

\[
p_i\in(X,2X]
\]

because two distinct shell primes would give

\[
p_ip_i'>X^2,
\]

contradicting the size bound.

Therefore the tuple is determined by the three integers

\[
n_1,n_2,n_3
\]

once the signs and defects are fixed.

The only remaining multiplicity comes from the choices of cofactors

\[
c_i=n_i/p_i.
\]

For fixed N there are at most three shell primes because the three shifted numbers are fixed. Hence

\[
\#\{p_1,p_2,p_3\mid N-d_i\}\le1.
\]

The problem is therefore the number of admissible N values, not translations.

---

## 3. Pair and triple CRT bounds

The equations

\[
N=c_1p_1,
\]

\[
N-d_2=c_2p_2,
\]

\[
N-d_3=c_3p_3
\]

imply

\[
c_1p_1-c_2p_2=d_2,
\]

\[
c_1p_1-c_3p_3=d_3.
\]

For fixed ordered shell primes, the coefficients satisfy

\[
1\le c_i<X.
\]

The first equation is a two-variable divisor/CRT condition. It gives at most O(X) coefficient pairs trivially, and the second condition intersects another affine lattice.

Hence a crude fixed-prime bound is

\[
O(X).
\]

Summing over shell triples gives

\[
O(X^3)\cdot O(X)=O(X^4),
\]

which is worse than the parameter count and therefore not useful.

The correct use is to count N directly: each shell triple contributes at most one N once the three congruences are imposed modulo

\[
p_1p_2p_3.
\]

Since

\[
p_1p_2p_3\asymp X^3,
\]

and N lies in an interval of length O(X^2), a fixed shell triple contributes at most one candidate. Therefore

\[
|T_X|\ll \#\{(p_1,p_2,p_3)\}
\ll X^3/(\log X)^3.
\]

This is the unconditional CRT baseline.

---

## 4. No-consecutive roots

The Apéry condition is

\[
p_i\mid B_{u_i}.
\]

The no-consecutive-zero property implies that for a fixed p the admissible folded roots have spacing at least two.

Therefore the number of possible t values for a fixed prime p is at most

\[
\frac p2+O(1),
\]

but this only removes a constant density factor. It does not reduce the unconditional exponent in X.

For a fixed prime triple, the three congruence conditions on t are compatible by CRT modulo

\[
p_1p_2p_3,
\]

and the t-range has length O(X). Since the modulus is X^3, the expected number is <1, but this is an average heuristic, not an unconditional upper bound without cancellation.

---

## 5. Height of B_u gives no unconditional fibre saving

The condition

\[
p\mid B_u
\]

with

\[
u<X
\]

means p divides a fixed integer of size approximately

\[
\log B_u=O(u)=O(X).
\]

Thus a single B_u may have at most O(X/log X) prime divisors. This gives the crude bound

\[
\#\{p\in(X,2X]:p\mid B_u\}=O(X/\log X),
\]

which is only a logarithmic saving and cannot replace a correlation estimate.

---

## 6. Explicit recurrence-free extremal model

Take an abstract family of folded zero sets satisfying only the frozen structural rules.

For every shell prime p choose a set

\[
Z_p\subset[0,(p-1)/2]
\]

with spacing at least two.  Put

\[
|Z_p|=\lfloor p/2\rfloor/2.
\]

Choose all Z_p so that the reflected congruence classes contain a common interval of CRT representatives.

Then for every compatible prime triple there exists a t solving

\[
s_i(t+d_i+\tau_i)\in Z_{p_i}.
\]

The factorization equations can then be realized by choosing

\[
N\equiv0\pmod {p_1},
\]

\[
N\equiv d_2\pmod {p_2},
\]

\[
N\equiv d_3\pmod {p_3},
\]

with the unique CRT solution in the allowed range whenever it exists.

This model satisfies:

- shell-prime uniqueness;
- folded reflection;
- no consecutive roots;
- all CRT factorization constraints.

It has fibre size comparable to the number of admissible shell triples:

\[
|T_X|\asymp X^3
\]

up to logarithmic factors.

The model does not use the Apéry recurrence. Therefore no argument using only the frozen combinatorial constraints can beat the cubic scale.

---

## 7. Correct baseline conclusion

The unconditional hierarchy is:

\[
\boxed{|T_X|\ll X^3}
\]

from parameter ranges and shell-prime uniqueness.

Pair CRT gives no improvement without extra arithmetic input.

No-consecutive roots and height of B_u give only density/logarithmic information.

A bound such as

\[
|T_X|=X^{o(1)}
\]

requires genuinely Apéry-specific correlation input (for example a third-order folded-zero estimate or a determinant/Casoratian mechanism). It cannot follow from the frozen structural constraints alone.
