# Verdict

The order pattern

```text
ord(Lf) = ord(Lg) = 8,
ord(gcrd(Lf,Lg)) = 7,
ord(lclm(Lf,Lg)) = 9
```

is highly informative, but it does **not** identify the limit.  Its exact meaning in the Ore ring

```text
K(k)<S>,     S a(k) = a(k+1) S,     K = Q
```

is that, after passing to the fraction field `Q(k)`, there are first-order left cofactors

```text
Lf = Af * D,
Lg = Ag * D,
```

where `D = gcrd(Lf,Lg)` has order 7 and `Af, Ag` have order 1.  Thus the two order-8 modules share a seven-dimensional right submodule, while each has one additional quotient direction.

This does **not** say that the particular solutions `f` and `g` have the same coefficient on any solution of `D`; those coefficients are integration/connection constants determined by initial data.  In fact, one may replace `g` by `g + c y` for a suitable common solution `D y = 0` without changing `Lg`, `Lf`, their GCRD, or their LCLM, while changing the limit of `g/f`.  Therefore no conclusion of the form

```text
g(k)/f(k) -> Catalan
```

can follow from the factor orders alone.

The right certificate to seek is an **initial-data-sensitive summation coboundary**.  The strongest concrete target is a discrete Wronskian identity whose non-coboundary term is exactly Catalan's defining summand.

# 2. Determine which mode lies in the quotient

Before searching for identities, compute the Poincare polynomial of the three exact factors separately:

```text
chi_D(xi), chi_Af(xi), chi_Ag(xi).
```

The full operators have

```text
chi_Lf = chi_Lg = (xi - 1)^2 (xi + 1/8)^6.
```

There are two materially different possibilities.

## Case A: the expected useful case

```text
chi_D = (xi - 1)^2 (xi + 1/8)^5,
chi_Af = chi_Ag = xi + 1/8.
```

Then the order-7 common core contains both root-1 channels, and the two extra quotient directions are decaying `-1/8` channels.  The hypergeometric forcings `D f` and `D g` only modify the subdominant part.  The limit `g/f` is the ratio of the coefficients of the dominant root-1 solution in the two particular inhomogeneous solutions.

This is exactly the setting in which an adjoint Green-sum or a Catalan coboundary should exist.

## Case B

```text
chi_D = (xi - 1) (xi + 1/8)^6,
```

with the extra first-order quotient carrying the second root-1 direction.  Then the dominant coefficient is already in the first-order sources, and one should first simplify `v/u`.  This case is less compatible with Catalan being a non-hypergeometric connection constant, but it must be checked rather than assumed.

Poincare factorization here is only a search guide.  It does not prove any coefficient vanishing.

# 3. Preferred certificate: a Catalan Wronskian coboundary

Define the rational approximants

```text
r_k := g_k/f_k
```

and their discrete Wronskian

```text
W_k := f_k g_{k+1} - f_{k+1} g_k.
```

Then, wherever `f_k f_{k+1} != 0`,

```text
r_{k+1} - r_k = W_k/(f_k f_{k+1}).          (3.1)
```

Let

```text
a_k := (-1)^k/(2k+1)^2,
C_0 := 0,
C_{k+1} := C_k + a_k.
```

The repository already proves `C_k -> catalanConstant`.

The exact symbolic certificate to seek is the following.

## Certificate CW

Find a small Ore operator

```text
T = t_0(k) + t_1(k) S + ... + t_m(k) S^m,
          t_i(k) in Q(k),     preferably m <= 7,
```

and define

```text
H_k := (T f)(k).
```

Prove the identity

```text
W_k
 = a_k f_k f_{k+1}
   + f_k H_{k+1} - f_{k+1} H_k              (CW)
```

for every `k >= k0`, together with the base normalization

```text
H_k0/f_k0 = g_k0/f_k0 - C_k0.               (CW0)
```

Dividing `(CW)` by `f_k f_{k+1}` gives

```text
r_{k+1} - r_k
 = a_k + H_{k+1}/f_{k+1} - H_k/f_k.
```

Telescope from `k0` to `N-1` and use `(CW0)`:

```text
g_N/f_N = C_N + H_N/f_N.                    (3.2)
```

Thus the complete connection theorem reduces to the independent decay statement

```text
H_N/f_N -> 0.                                (CW-decay)
```

Together with `C_N -> G`, equation (3.2) proves `g_N/f_N -> G` exactly.

This is the best certificate because it contains Catalan's series **symbolically**, not through a guessed real constant.

It also avoids every failed route:

- no fixed or shrinking signed cone;
- no invertible 3x3 rational gauge;
- no numerical cancellation of Poincare modes;
- no need to identify a 500-digit scalar;
- only a finite rational-function identity plus a separate decay estimate.

# 4. How to search for `T`

The equation `(CW)` is linear in the unknown rational functions `t_i(k)`.

## 4.1 Remove the `(-1)^k` coefficient cleanly

Either work in a difference-field extension with an element `eps` satisfying

```text
S(eps) = -eps,    eps^2 = 1,
```

or, more robustly, split into even and odd subsequences:

```text
f0(m)=f(2m),    f1(m)=f(2m+1),
g0(m)=g(2m),    g1(m)=g(2m+1).
```

Then

```text
a_{2m}   =  1/(4m+1)^2,
a_{2m+1} = -1/(4m+3)^2,
```

and all coefficients lie in `Q(m)`.

## 4.2 Denominator ansatz

Do not search arbitrary large rational functions.  Build the denominator of every `t_i(k)` from:

- factors of the leading and trailing coefficients of `Lf` and `D`;
- their shifts by at most `m+8`;
- `(2k+1)^2` and `(2k+3)^2`;
- factors appearing in the first-order quotients `Af`, `Ag`.

Let this product be `Q(k)`, and write

```text
t_i(k) = P_i(k)/Q(k)
```

with increasing polynomial-degree bounds.

Use exact terms only to solve the resulting linear system and discover a candidate.  A candidate found from terms is not the proof.

## 4.3 Symbolic verification by tensor companion matrices

Let

```text
F_k = (f_k,...,f_{k+7})^T,
G_k = (g_k,...,g_{k+7})^T.
```

From the exact operators obtain companion matrices

```text
F_{k+1} = Cf(k) F_k,
G_{k+1} = Cg(k) G_k.
```

The residual in `(CW)` is a rational bilinear expression in

```text
F_k tensor G_k,
F_k tensor F_k.
```

These states evolve by

```text
Cf(k) tensor Cg(k),
Cf(k) tensor Cf(k).
```

Therefore `(CW)` can be verified as a finite rational matrix identity after clearing denominators.  This is preferable to checking 401 terms.

A practical Sage route is:

```python
Cf = Lf.companion_matrix()
Cg = Lg.companion_matrix()
Mfg = Cf.tensor_product(Cg)
Mff = Cf.tensor_product(Cf)
```

Construct the row extracting the two sides of `(CW)`, shift it once using these matrices, and prove the resulting rational-function vector vanishes.  If the residual satisfies a nontrivial finite recurrence instead of vanishing universally, derive that recurrence symbolically and prove the required initial residuals are zero.

`ore_algebra` also provides `annihilator_of_polynomial(..., blocks=2)` for bilinear expressions, but the explicit Kronecker-state calculation is easier to audit.

# 5. How to prove `(CW-decay)`

Once a candidate `T` is found, compute an exact annihilator for `H = T f`:

```python
LH = Lf.annihilator_of_associate(T)
```

Then try the following in order.

## 5.1 Best outcome: `H` is hypergeometric

If `LH` has a first-order right factor and the initial values select that factor, prove

```text
H_{k+1} = rho(k) H_k
```

with `rho(k) in Q(k)` and an exact eventual inequality

```text
|rho(k)| <= q < 1.
```

If `f_k` is positive and bounded below, this immediately gives `H_k/f_k -> 0`.

## 5.2 Low-order contracting recurrence

If `H` has order 2 or 3, search for a rational invariant norm or interval cone for **this low-order subdominant recurrence**.  This is very different from the failed signed-error cone: the dominant root-1 direction has already been removed by the exact coboundary, so a simple contraction estimate is realistic.

## 5.3 Prove a denominator lower bound

The assertion `f_k > 0` on 401 terms is not enough.  Seek one of:

```text
f_{k+1} >= f_k > 0,
```

an explicit positive sum/integral for `f_k`, or a positive first-difference recurrence.  For `(CW-decay)`, a crude exact lower bound such as `f_k >= f_0 > 0` is sufficient if `H_k -> 0`.

If `f_k` grows linearly, as the current experiments suggest, proving monotonicity is substantially easier than proving a full asymptotic expansion.

# 6. A more direct diagnostic: test the raw Wronskian first

Before solving for `T`, calculate exact values of

```text
W_k = f_k g_{k+1} - f_{k+1} g_k.
```

Test whether

```text
W_{k+1}/W_k in Q(k).
```

If yes, `W_k` is hypergeometric and the ratio increments are controlled by an exact generalized continued-fraction determinant.  Prove the first-order recurrence symbolically using `Lf` and `Lg`.

Also test whether

```text
W_k - a_k f_k f_{k+1}
```

is already of the simple form

```text
f_k R_{k+1} - f_{k+1} R_k
```

with `R_k` hypergeometric or `R_k = t(k) f_{k+s}`.  Start with

```text
R_k = t(k) f_k,
R_k = t(k) f_{k+1},
R_k = t0(k)f_k+t1(k)f_{k+1},
```

before using a general order-7 operator.

A common order-7 factor does not force `W_k` to be first-order, but the codimension-one quotient makes this a high-value test.

A standard second-order continued fraction with coefficients in `Q(k)` is unlikely: if both `f` and `g` satisfied the same order-2 recurrence over `Q(k)`, their claimed minimal order-8 operators would not be minimal.  The relevant object is therefore a generalized Wronskian/coboundary, not an ordinary three-term recurrence unless the order-8 minimality claim changes after certification.

# 7. Fallback certificate: adjoint Green summation for the order-7 core

If no small `T` satisfies `(CW)`, use the common factor `D` directly.

Write

```text
D = d_0(k)+d_1(k)S+...+d_7(k)S^7.
```

Its formal adjoint is available as

```python
Dstar = D.adjoint()
```

and acts as

```text
(D* z)_k = sum_{i=0}^7 d_i(k-i) z_{k-i}.
```

For arbitrary sequences `z,y`, define the discrete concomitant

```text
B_D(z,y;k)
 = sum_{i=1}^7 sum_{j=0}^{i-1}
     d_i(k-i+j) z_{k-i+j} y_{k+j}.
```

A direct telescoping calculation gives the exact Lagrange identity

```text
B_D(z,y;k+1)-B_D(z,y;k)
 = z_k (D y)_k - y_k (D* z)_k.              (7.1)
```

Choose an exact solution `z` of `D* z=0` that extracts the dominant root-1 coefficient.  Then

```text
B_D(z,y;N+1)-B_D(z,y;k0)
 = sum_{k=k0}^N z_k (D y)_k.                (7.2)
```

For `y=f,g`, the right sides are sums of the explicit hypergeometric forcings `u=Df` and `v=Dg`.

The desired dominant coefficients therefore have exact Green-sum expressions

```text
A_f = boundary_f + sum z_k u_k,
A_g = boundary_g + sum z_k v_k,
```

and

```text
lim g_k/f_k = A_g/A_f.                      (7.3)
```

This is the canonical connection formula supplied by the GCRD structure.

However, to identify `(7.3)` with Catalan, one still needs an exact summation identity.  The sharp fallback certificate is:

```text
A_g = catalanConstant * A_f.                (GC)
```

Do not prove `(GC)` numerically.  Seek a Gosper/creative-telescoping identity reducing

```text
z_k v_k - C_N z_k u_k
```

to a boundary term, or express `A_g/A_f` as the Catalan series term by term.

First test whether `Dstar.right_factors(order=1)` produces a hypergeometric adjoint solution.  If it does, the sums in `(7.2)` are hypergeometric and Gosper/Zeilberger methods are realistic.  If the relevant adjoint solution has no d'Alembertian form, the Green route will be much harder than `(CW)`.

# 8. Why the GCRD alone is insufficient

There are three independent reasons.

## 8.1 It is a module statement, not an initial-value statement

`D` describes the intersection

```text
ker(Lf) intersection ker(Lg) = ker(D)
```

at a generic nonsingular point.  It says nothing about the coordinates of the particular `f` and `g` relative to a basis of this intersection.

## 8.2 The quotient equations leave seven constants

The first-order quotient gives

```text
D f = u,
D g = v,
```

with explicit hypergeometric `u,v`.  Solving either order-7 inhomogeneous recurrence requires seven constants.  The Catalan number is encoded in those constants, not in the formal factorization.

## 8.3 Same operators, different limits

Let `y` be a common solution of `D y=0` with a nonzero dominant root-1 coefficient.  Then

```text
g_c := g + c y
```

is still annihilated by `Lg`, and all operator data

```text
Lf, Lg, D, LCLM, Poincare polynomials
```

remain unchanged.  But, when `y/f` has a nonzero limit, the limit of `g_c/f` varies with `c`.  Thus an operator-only argument cannot select Catalan.

The missing input must involve the actual initial data through `(CW)`, `(GC)`, an integral representation, or an equivalent connection matrix.

# 9. Current guessed operators must be certified

The statements

```text
order 8 / degree 41 or 42,
GCRD order 7,
LCLM order 9
```

were discovered from 401 exact terms.  Verification on all 401 terms is strong evidence but not an all-`k` proof.

The inverse Delannoy transform is explicitly

```text
B^{-1}(k,N)
 = (-1)^(k+N) (2N+1) binom(k,N)
   / [2^k binom(2k,k) (k+N+1) binom(k+N,N)].
```

Hence

```text
f(k) = sum_{N=0}^k B^{-1}(k,N) Qhat_N,
g(k) = sum_{N=0}^k B^{-1}(k,N) Phat_N.
```

A rigorous source for `Lf,Lg` should be one of:

1. a creative-telescoping certificate in `N` using the exact 3x3 recurrence for `Qhat_N,Phat_N`;
2. an exact operator intertwining the 3x3 `N`-system with the `k`-recurrences;
3. a direct induction showing the transformed sums satisfy the displayed operators, after reducing all shifted terms with the original matrix recurrence.

The certificate should have the form

```text
Lf_k [ B^{-1}(k,N) Qhat_N ]
 = Delta_N( certificate_f(k,N) ),
```

and similarly for `g`, with all boundary terms checked exactly.

Only after this step should the GCRD factorization be imported into Lean as mathematical data.

# 11. The single sharp certificate that would close the theorem

The most useful deliverable is not another Poincare statement.  It is the following exact identity.

> **Catalan-coboundary certificate.**  There exists `T in Q(k)<S>` such that, with `H=T f`,
>
> ```text
> f_k g_{k+1} - f_{k+1} g_k
> = (-1)^k/(2k+1)^2 * f_k f_{k+1}
>   + f_k H_{k+1} - f_{k+1} H_k
> ```
>
> for every `k`, the initial normalization is exact, and `H_k/f_k -> 0`.

This immediately yields

```text
g_N/f_N
 = sum_{k=0}^{N-1} (-1)^k/(2k+1)^2 + H_N/f_N
 -> catalanConstant.
```

It is finite, algebraic, initial-data-sensitive, and independent of numerical identification.  The order-7 GCRD makes such a certificate plausible by showing that the discrepancy between the two order-8 modules is only one-dimensional, but the GCRD does not imply the certificate automatically.

If no small `T` exists, the exact replacement is the adjoint Green identity `(7.2)` plus a symbolic evaluation of its hypergeometric sum.  One of these two objects—not the GCRD order itself—is the actual missing connection proof.
