# Exact projectivization of the chronological pull product

The correct interval product is

```text
A[k,k+h) = A(k) A(k+1) ... A(k+h-1).
```

Because matrices act on columns from the rightmost factor first, this sends a terminal chart `z` through

```text
pull(k+h-1), ..., pull(k+1), pull(k),
```

which is exactly the recursive orientation

```lean
millerPullN k (h+1) z =
  millerPull k (millerPullN (k+1) h z).
```

The interval-product recursion below is therefore deliberately **left recursive**:

```lean
AInterval k (h+1) = A k * AInterval (k+1) h.
```

It represents the same chronological matrix word and makes the lift theorem a direct induction.

# 1. One pull on a homogeneous lift

First prove the algebraic statement with only a scalar nonzero hypothesis. This keeps all box reasoning out of the coordinate calculation.

```lean
private theorem millerPullMatrix_mulVec_lift_of_ne
    (n : ℕ) (z : MillerChart)
    (hden : millerDen n z ≠ 0) :
    millerPullMatrix n *ᵥ millerLift z =
      millerDen n z • millerLift (millerPull n z) := by
  have hleft :
      millerPullMatrix n *ᵥ millerLift z =
        ![millerDen n z, 1, z 0] := by
    funext i
    fin_cases i <;>
      simp [millerPullMatrix, millerLift, millerDen,
        Matrix.mulVec, dotProduct, Fin.sum_univ_three] <;>
      ring

  rw [hleft]
  funext i
  fin_cases i
  · simp [millerLift, millerPull]
  · simp [millerLift, millerPull]
    field_simp [hden]
  · simp [millerLift, millerPull]
    field_simp [hden]
```

The box version is the theorem normally used later:

```lean
private theorem millerPullMatrix_mulVec_lift
    (n : ℕ) {z : MillerChart} (hz : millerInBox z) :
    millerPullMatrix n *ᵥ millerLift z =
      millerDen n z • millerLift (millerPull n z) := by
  exact millerPullMatrix_mulVec_lift_of_ne n z
    (millerDen_pos_box n hz).ne'
```

No coefficient of `millerPullMatrix` is unfolded beyond its companion-row form, and no matrix inverse is used.

# 2. Interval product and accumulated positive scale

Define the chronological interval product by structural recursion on its length:

```lean
private def millerAIntervalProd : ℕ → ℕ → MillerMatR
  | _, 0 => 1
  | k, h + 1 =>
      millerPullMatrix k * millerAIntervalProd (k + 1) h

@[simp] private theorem millerAIntervalProd_zero (k : ℕ) :
    millerAIntervalProd k 0 = (1 : MillerMatR) := rfl

@[simp] private theorem millerAIntervalProd_succ (k h : ℕ) :
    millerAIntervalProd k (h + 1) =
      millerPullMatrix k * millerAIntervalProd (k + 1) h := rfl
```

The scale is accumulated in the same recursive orientation. At the outer step, the relevant denominator is evaluated on the already-pulled tail chart.

```lean
private def millerPullScale : ℕ → ℕ → MillerChart → ℝ
  | _, 0, _ => 1
  | k, h + 1, z =>
      millerDen k (millerPullN (k + 1) h z) *
        millerPullScale (k + 1) h z

@[simp] private theorem millerPullScale_zero
    (k : ℕ) (z : MillerChart) :
    millerPullScale k 0 z = 1 := rfl

@[simp] private theorem millerPullScale_succ
    (k h : ℕ) (z : MillerChart) :
    millerPullScale k (h + 1) z =
      millerDen k (millerPullN (k + 1) h z) *
        millerPullScale (k + 1) h z := rfl
```

Its positivity is purely inductive:

```lean
private theorem millerPullScale_pos
    (k h : ℕ) {z : MillerChart} (hz : millerInBox z) :
    0 < millerPullScale k h z := by
  induction h generalizing k with
  | zero =>
      simp [millerPullScale]

  | succ h ih =>
      rw [millerPullScale_succ]
      have htail :
          millerInBox (millerPullN (k + 1) h z) :=
        millerPullN_mem_box_adapter (k + 1) h hz
      exact mul_pos
        (millerDen_pos_box k htail)
        (ih (k := k + 1))

private theorem millerPullScale_ne
    (k h : ℕ) {z : MillerChart} (hz : millerInBox z) :
    millerPullScale k h z ≠ 0 :=
  (millerPullScale_pos k h hz).ne'
```

Now projectivize the entire interval product:

```lean
private theorem millerAIntervalProd_mulVec_lift
    (k h : ℕ) {z : MillerChart} (hz : millerInBox z) :
    millerAIntervalProd k h *ᵥ millerLift z =
      millerPullScale k h z •
        millerLift (millerPullN k h z) := by
  induction h generalizing k with
  | zero =>
      simp [millerAIntervalProd, millerPullScale, millerPullN]

  | succ h ih =>
      have htail :
          millerInBox (millerPullN (k + 1) h z) :=
        millerPullN_mem_box_adapter (k + 1) h hz

      rw [ih (k := k + 1)]
      rw [Matrix.mulVec_smul]
      rw [millerPullMatrix_mulVec_lift k htail]

# 3. Right-end recursion for the same chronological product

The left-recursive definition is best for projectivization. For comparison with the globally recursive `millerAProd`, prove that appending one step on the right gives the same interval product:

```lean
private theorem millerAIntervalProd_succ_right
    (k h : ℕ) :
    millerAIntervalProd k (h + 1) =
      millerAIntervalProd k h * millerPullMatrix (k + h) := by
  induction h generalizing k with
  | zero =>
      simp [millerAIntervalProd]

  | succ h ih =>
      calc
        millerAIntervalProd k (h + 2)
            = millerPullMatrix k *
                millerAIntervalProd (k + 1) (h + 1) := rfl
        _ = millerPullMatrix k *
              (millerAIntervalProd (k + 1) h *
                millerPullMatrix ((k + 1) + h)) := by
              rw [ih (k := k + 1)]
        _ = (millerPullMatrix k *
              millerAIntervalProd (k + 1) h) *
                millerPullMatrix (k + (h + 1)) := by
              rw [show (k + 1) + h = k + (h + 1) by omega]
              rw [← Matrix.mul_assoc]
        _ = millerAIntervalProd k (h + 1) *
              millerPullMatrix (k + (h + 1)) := rfl
```

This also yields interval concatenation if needed:

```lean
private theorem millerAIntervalProd_add
    (k h t : ℕ) :
    millerAIntervalProd k (h + t) =
      millerAIntervalProd k h *
        millerAIntervalProd (k + h) t := by
  induction t with
  | zero =>
      simp [millerAIntervalProd]

  | succ t ih =>
      calc
        millerAIntervalProd k (h + (t + 1))
            = millerAIntervalProd k ((h + t) + 1) := by
                congr 1
                omega
        _ = millerAIntervalProd k (h + t) *
              millerPullMatrix (k + (h + t)) :=
                millerAIntervalProd_succ_right k (h + t)
        _ = (millerAIntervalProd k h *
              millerAIntervalProd (k + h) t) *
                millerPullMatrix (k + (h + t)) := by
              rw [ih]
        _ = millerAIntervalProd k h *
              (millerAIntervalProd (k + h) t *
                millerPullMatrix ((k + h) + t)) := by
              rw [show k + (h + t) = (k + h) + t by omega]
              rw [Matrix.mul_assoc]
        _ = millerAIntervalProd k h *
              millerAIntervalProd (k + h) (t + 1) := by
              rw [← millerAIntervalProd_succ_right]
```

# 4. Relation to the global chronological product `millerAProd`

Recall the Q6957 recursion

```lean
millerAProd 0 = 1
millerAProd (n+1) = millerAProd n * millerPullMatrix n.
```

The exact prefix/interval decomposition is:

```lean
private theorem millerAProd_add_interval
    (k h : ℕ) :
    millerAProd (k + h) =
      millerAProd k * millerAIntervalProd k h := by
  induction h with
  | zero =>
      simp [millerAIntervalProd]

  | succ h ih =>
      calc
        millerAProd (k + (h + 1))
            = millerAProd ((k + h) + 1) := by
                congr 1
                omega
        _ = millerAProd (k + h) *
              millerPullMatrix (k + h) := by
                rw [millerAProd_succ]
        _ = (millerAProd k *
              millerAIntervalProd k h) *
                millerPullMatrix (k + h) := by
              rw [ih]
        _ = millerAProd k *
              (millerAIntervalProd k h *
                millerPullMatrix (k + h)) := by
              rw [Matrix.mul_assoc]
        _ = millerAProd k *
              millerAIntervalProd k (h + 1) := by
              rw [← millerAIntervalProd_succ_right]
```

At base zero, the global product is exactly the interval product:

```lean
private theorem millerAProd_eq_interval_zero (h : ℕ) :
    millerAProd h = millerAIntervalProd 0 h := by
  simpa using millerAProd_add_interval 0 h
```

The requested two-step identity is then:

```lean
private theorem millerAProd_add_two (h : ℕ) :
    millerAProd (h + 2) =
      (millerAProd h * millerPullMatrix h) *
        millerPullMatrix (h + 1) := by
  calc
    millerAProd (h + 2)
        = millerAProd h * millerAIntervalProd h 2 :=
          millerAProd_add_interval h 2
    _ = (millerAProd h * millerPullMatrix h) *
          millerPullMatrix (h + 1) := by
          simp [millerAIntervalProd, Matrix.mul_assoc]
```

Equivalently, with right association:

```lean
private theorem millerAProd_add_two_right (h : ℕ) :
    millerAProd (h + 2) =
      millerAProd h *
        (millerPullMatrix h * millerPullMatrix (h + 1)) := by
  simpa [Matrix.mul_assoc] using millerAProd_add_two h
```

# 5. Projectivized global-product corollaries

Combining the prefix decomposition with the interval lift theorem gives the useful general form:

```lean
private theorem millerAProd_add_mulVec_lift
    (k h : ℕ) {z : MillerChart} (hz : millerInBox z) :
    millerAProd (k + h) *ᵥ millerLift z =
      millerPullScale k h z •
        (millerAProd k *ᵥ
          millerLift (millerPullN k h z)) := by
  rw [millerAProd_add_interval, Matrix.mulVec_mulVec]
  rw [millerAIntervalProd_mulVec_lift k h hz]
  rw [Matrix.mulVec_smul]
```

For a product starting at zero, this simplifies to the exact projective formula for `millerAProd` itself:

```lean
private theorem millerAProd_mulVec_lift
    (h : ℕ) {z : MillerChart} (hz : millerInBox z) :
    millerAProd h *ᵥ millerLift z =
      millerPullScale 0 h z •
        millerLift (millerPullN 0 h z) := by
  rw [millerAProd_eq_interval_zero]
  exact millerAIntervalProd_mulVec_lift 0 h hz
```

Its scalar is positive and nonzero:

```lean
private theorem millerAProd_mulVec_lift_positive

# 7. Audit summary

- `millerAIntervalProd k h` is the chronological word `A(k)...A(k+h-1)`.
- Acting on a column, its rightmost factor acts first; this exactly matches `millerPullN`.
- Every accumulated denominator is evaluated on the correct tail chart.
- The scale is strictly positive for terminal charts in `millerInBox`.
- `millerAProd (k+h) = millerAProd k * millerAIntervalProd k h`.
- In particular,
  
  ```text
  millerAProd(h+2)
    = millerAProd(h) * A(h) * A(h+1).
  ```

No inverse matrix, determinant, exterior construction, `sorry`, axiom, or `native_decide` is used.
