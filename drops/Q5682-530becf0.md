# P3.2 shifted-Apéry lcm: exact valuation formula, rank-one Lucas saturation, and the remaining reopening lemma

## Executive verdict

I audited the current repository state at main commit [`2eb2e688d33442f32068c3d4051b21462acf5ef1`](https://github.com/xiangyazi24/Ramanujan_Challenge/commit/2eb2e688d33442f32068c3d4051b21462acf5ef1), in particular Sections 40–41 of `Q32_SEPARATION_ANALYSIS.md` and the earlier recurrence/Fitting saturation results `Q5526` and `Q5544`.

Let

\[
D_n=\operatorname{lcm}(1,\ldots,n),\qquad
L_n=\operatorname{lcm}_{1\le k\le n}
 \frac{k}{\gcd(k,A_{n-k})},\qquad
J_n=\frac{D_n}{L_n}.
\]

The near-maximal-lcm reformulation is exact and useful, but it does **not** create a new deterministic route to `log J_n=o(n)`. The sharp conclusions are:

1. **Exact prime-adic formula.** If
   \(
   \alpha_p=\lfloor\log_p n\rfloor
   \)
   and
   \(
   \rho_p=n\bmod p^{\alpha_p},
   \)
   then
   \[
   \boxed{p\mid J_n\iff p\mid A_{\rho_p}.}
   \tag{V1}
   \]
   More generally, `v_p(J_n) >= e` has an exact nested-shell criterion given in Theorem 1 below.

2. **The extra prime-power depth is already sublinear.** Since every prime `p>sqrt(n)` occurs in `D_n` only to exponent one,
   \[
   \boxed{
   0\le \log J_n-\log\operatorname{rad}(J_n)=O(\sqrt n).
   }
   \tag{V2}
   \]
   Thus the hard part is the first missing prime layer, not higher prime powers.

3. **`J_n` does not equal** \(\operatorname{rad}\gcd(A_n,D_n)\). One always has
   \[
   \operatorname{rad}(J_n)\mid \operatorname{rad}\gcd(A_n,D_n),
   \]
   but the quotient consists of outer-digit zeros. Quantitatively,
   \[
   \boxed{
   \log\operatorname{rad}\gcd(A_n,D_n)-O(n^{2/3})
   \le \log J_n
   \le \log\operatorname{rad}\gcd(A_n,D_n)+O(\sqrt n).
   }
   \tag{V3}
   \]
   For a concrete strict inequality, take `n=146`, `p=73`: because `A_2=73`, Apéry–Lucas gives `73|A_146`, but `146 mod 73=0` and `A_0=1`, so `73` divides the smooth Apéry radical but not `J_146`.

4. **The intended covering across top-valuation multiples collapses exactly.** Write
   \[
   n=a p^{\alpha}+\rho,\qquad 1\le a<p,\quad 0\le\rho<p^\alpha.
   \]
   The top-valuation multiples are `k=t p^alpha`, `1<=t<=a`, and Apéry–Lucas gives
   \[
   A_{n-tp^\alpha}\equiv A_{a-t}A_\rho\pmod p.
   \tag{V4}
   \]
   Since the shell contains `t=a`, whose coefficient is `A_0=1`, the ideal generated by the complete shell in `F_p` is exactly
   \[
   \boxed{
   (A_{n-p^\alpha},\ldots,A_{n-ap^\alpha})=(A_\rho).
   }
   \tag{V5}
   \]
   The many possible witnesses are therefore one Lucas-replicated equation, not independent covering constraints.

5. **Shifted lcms and Fitting/exterior constructions do not escape.** A fixed shift asks for a different zero `A_{rho+h}=0`; an original target does not force it, and for `h=1` the no-consecutive-zero theorem forces the opposite. Intersections lose target primes, unions retain the original `J_n`, and bounded-order recurrence/Fitting identities reduce q-locally to the principal target ideal `(A_rho)`.

6. **One genuinely new inequality survives.** Let `P_n` be the primes `p>sqrt(n)` dividing `J_n`. If `H` is a set of positive gaps and `W_unc(n;H)` is the logarithmic weight of those `p in P_n` for which the zero `rho_p` has no non-reflected second zero at distance in `H`, then the Apéry gap continuants give
   \[
   \boxed{
   \log J_n
   \ll \sqrt n+W_{\rm unc}(n;H)
      +\log n\sum_{h\in H}h.
   }
   \tag{V6}
   \]
   Consequently, a single **weighted non-reflection cover theorem**—existence of `H_n` with
   \[
   \sum_{h\in H_n}h=o(n/\log n),
   \qquad W_{\rm unc}(n;H_n)=o(n)
   \tag{V7}
   \]
   —would prove `log J_n=o(n)`. This is a real Apéry-specific reopening lemma. It does not follow from bounded zero fibers; exact reflection doublets are completely uncovered after reflection saturation.

The final verdict is therefore negative for the proposed lcm-only route but sharper than a bare equivalence: the exact circular step is (V5), and (V6) identifies a minimal additional horizontal input that would break it.

## 1. Exact `p`-adic valuation of the lcm defect

Fix a prime `p`, and write

\[
\alpha=\alpha_p:=\max\{s:p^s\le n\}.
\]

For `0<=s<=alpha`, define

\[
\mu_s(n,p):=\min_{\substack{1\le k\le n\\v_p(k)=s}}
 v_p(A_{n-k}).
\tag{1.1}
\]

The minimum is over a nonempty set. Since

\[
v_p\!\left(\frac{k}{\gcd(k,A_{n-k})}\right)
=\max\{v_p(k)-v_p(A_{n-k}),0\},
\]

taking the lcm gives

\[
v_p(L_n)=
\max_{0\le s\le\alpha}(s-\mu_s)_+.
\tag{1.2}
\]

Therefore:

### Theorem 1.1 — exact valuation formula

\[
\boxed{
 v_p(J_n)=
 \min_{0\le s\le\alpha}
 \bigl(\alpha-s+\min(s,\mu_s)\bigr).
}
\tag{1.3}
\]

Equivalently, for `1<=e<=alpha`,

\[
\boxed{
 v_p(J_n)\ge e
 \iff
 \mu_{\alpha-d}(n,p)\ge e-d
 \quad(0\le d<e).
}
\tag{1.4}
\]

#### Proof

Equation (1.3) is `alpha - (1.2)` and the identity

\[
\alpha-(s-\mu_s)_+
=\alpha-s+\min(s,\mu_s).
\]

For (1.4), the levels `s<=alpha-e` already contribute at least `e` through the term `alpha-s`; only the top `e` valuation shells can obstruct. At shell `s=alpha-d`, condition (1.3) is

\[
d+\min(\alpha-d,\mu_{\alpha-d})\ge e,
\]

which is equivalent to `mu_{alpha-d}>=e-d`. ∎

The first layer is especially simple:

\[
p\mid J_n
\iff
p\mid A_{n-k}
\quad\text{for every }k\le n\text{ with }v_p(k)=\alpha.
\tag{1.5}
\]

This is the exact “failure to realize the top prime power” statement proposed in the question.

## 2. Apéry–Lucas collapses the entire top shell to one digit

Write

\[
n=a p^\alpha+\rho,\qquad
1\le a<p,\qquad 0\le\rho<p^\alpha.
\tag{2.1}
\]

The integers `k<=n` with `v_p(k)=alpha` are exactly

\[
k=t p^\alpha,\qquad 1\le t\le a.
\tag{2.2}
\]

The base-`p` digits of `(a-t)p^alpha+rho` are the digit `a-t` followed by the `alpha` lower digits of `rho`. The Apéry numbers have the `p`-Lucas property, so

\[
A_{n-tp^\alpha}
=A_{(a-t)p^\alpha+\rho}
\equiv A_{a-t}A_\rho\pmod p.
\tag{2.3}
\]

For `t=a`, this is exactly `A_rho` because `A_0=1`. Hence all values in (2.3) vanish modulo `p` if and only if `A_rho` does. Combining with (1.5) proves:

### Theorem 2.1 — exact radical formula

\[
\boxed{
 p\mid J_n
 \iff
 p\mid A_{\,n\bmod p^{\lfloor\log_p n\rfloor}}.
}
\tag{2.4}
\]

Equivalently,

\[
\boxed{
\operatorname{rad}(J_n)
=
\prod_{\substack{p\le n\\
 p\mid A_{\,n\bmod p^{\lfloor\log_p n\rfloor}}}}p.
}
\tag{2.5}
\]

This is a stronger statement than the previously recorded `p>sqrt(n)` criterion. For `p>sqrt(n)`, `alpha=1`, and (2.4) reduces to

\[
p\mid J_n\iff p\mid A_{n\bmod p}.
\tag{2.6}
\]

### The exact circular step

The hoped-for proof was to use the several top-valuation multiples `t p^alpha` as several chances to realize `p^alpha` in `L_n`. Equation (2.3) shows that these chances are perfectly correlated. More precisely, in `F_p`,

\[
\begin{aligned}
&(A_{n-p^\alpha},A_{n-2p^\alpha},\ldots,A_{n-ap^\alpha})\\
&\qquad=A_\rho(A_{a-1},A_{a-2},\ldots,A_0),
\end{aligned}
\tag{2.7}
\]

and the last coordinate of the second vector is `1`. Thus

\[
\gcd_{\mathbb F_p}
(A_{n-p^\alpha},\ldots,A_{n-ap^\alpha})
=A_\rho
\tag{2.8}
\]

in the sense of generated principal ideals. There is no deterministic covering gain in the number `a` of multiples.

A useful audit summary is:

```text
prime p, top exponent alpha=floor(log_p n)
    top multiples: k=t p^alpha, 1<=t<=a
    all top values mod p: A_rho times a fixed coefficient vector
    final coefficient: A_0=1
therefore
    top shell vanishes  <=>  A_rho vanishes
    shell Fitting content = one copy of the target ideal
```

Products can turn this one factor into a power, but the Archimedean size and the fake repeated equations grow at the same time. Primitive saturation returns the single factor in (2.8).

## 3. Higher missing powers cost only `O(sqrt(n))`

The exact higher criterion (1.4) may look stronger, but all higher exponents occur at small primes. Since `v_p(J_n)<=alpha_p`,

\[
0\le
\log J_n-\log\operatorname{rad}(J_n)
\le
\sum_p(\alpha_p-1)_+\log p.
\tag{3.1}
\]

The right side is

\[
\sum_{m\ge2}\vartheta(n^{1/m})
=O(\sqrt n).
\tag{3.2}
\]

Therefore

\[
\boxed{
\log J_n
=
\sum_{\substack{p\le n\\p\mid A_{\rho_p}}}\log p
+O(\sqrt n),
\qquad
\rho_p=n\bmod p^{\alpha_p}.
}
\tag{3.3}
\]

This is the direct near-maximal-lcm identity:

\[
\log L_n
=\psi(n)-
\sum_{\substack{p\le n\\p\mid A_{\rho_p}}}\log p
+O(\sqrt n).
\tag{3.4}
\]

Thus proving `log L_n=n+o(n)` is exactly a first-layer zero-digit theorem. A sophisticated analysis of the conditions `p^2|J_n`, `p^3|J_n`, and so forth cannot solve the problem unless it first controls the radical in (3.3).

## 4. Exact comparison with `rad gcd(A_n,D_n)`

Continue to write

\[
n=a_p p^{\alpha_p}+\rho_p,\qquad 1\le a_p<p.
\tag{4.1}
\]

Apéry–Lucas gives

\[
A_n\equiv A_{a_p}A_{\rho_p}\pmod p.
\tag{4.2}
\]

Hence every prime in `rad(J_n)` divides `A_n`, and

\[
\operatorname{rad}(J_n)\mid
\operatorname{rad}\gcd(A_n,D_n).
\tag{4.3}
\]

The difference is exact. Put

\[
E_n:=
\prod_{\substack{p\le n\\
 p\nmid A_{\rho_p}\\
 p\mid A_{a_p}}}p.
\tag{4.4}
\]

Then

\[
\boxed{
\operatorname{rad}\gcd(A_n,D_n)
=\operatorname{rad}(J_n)E_n.
}
\tag{4.5}
\]

The factors are disjoint by definition.

### Proposition 4.1 — outer-digit error

\[
\boxed{\log E_n=O(n^{2/3}).}
\tag{4.6}
\]

#### Proof

Primes `p<=n^(2/3)` have total logarithmic weight `O(n^(2/3))`. If `p>n^(2/3)`, then `p^2>n`, so `alpha_p=1`, and

\[
a_p=\left\lfloor\frac np\right\rfloor<n^{1/3}.
\]

For each fixed `a<n^(1/3)`, all remaining exceptional primes divide the fixed nonzero integer `A_a`; therefore their product has logarithm at most `log A_a=O(a)`. Summing over `a<n^(1/3)` gives `O(n^(2/3))`. ∎

Combining (3.2), (4.5), and (4.6) yields the quantitative two-sided audit

\[
\boxed{
\log\operatorname{rad}\gcd(A_n,D_n)-O(n^{2/3})
\le\log J_n
\le\log\operatorname{rad}\gcd(A_n,D_n)+O(\sqrt n).
}
\tag{4.7}
\]

So the two quantities have the same asymptotic difficulty, but they are not equal.

### Concrete strict inequality

Take `n=146` and `p=73`. The top exponent is `alpha_p=1`, and `rho_p=0`. Therefore `p` does not divide `J_146`, because `A_0=1`. On the other hand,

\[
A_{146}=A_{2\cdot73+0}\equiv A_2A_0=73\equiv0\pmod{73},
\]

so `73` divides `rad gcd(A_146,D_146)`. This is a large-prime outer-digit exception, not merely the small example `n=5,p=5`.

## 5. Why a covering argument across `t` cannot improve the radical

For a missing first layer, every top multiple is bad. One might try to exploit the fact that there are `a` of them by taking products, gcds, determinants, or resultants.

Equation (2.7) is the complete local answer.

### 5.1 Products

The product of all shell values is congruent to

\[
A_\rho^a\prod_{u=0}^{a-1}A_u\pmod p.
\tag{5.1}
\]

It contains a higher power of the target coordinate only because the same equation was repeated `a` times. Its logarithmic height also contains all `a` long Apéry values. No ratio improvement follows.

### 5.2 Gcds

Since the shell contains the value `A_rho` itself, the local `p`-support of the shell gcd is exactly the local support of `A_rho`. The gcd has repackaged the target condition but has not strengthened it.

### 5.3 Exterior powers and Fitting ideals

The shell vector has rank one over `F_p`:

\[
\mathbf v_{p,n}=A_\rho
(A_{a-1},\ldots,A_0).
\tag{5.2}
\]

All exterior powers of degree at least two vanish identically. The ideal of its entries is `(A_rho)` because the final coefficient is `1`. Any presentation that records each shell equality separately can accumulate powers of `p` in a large determinant, but the subpresentation obtained by deleting the one primitive coordinate accumulates all but one of those powers. The transverse Smith/Fitting quotient is one factor `p`, exactly as in the repository’s zero-fiber and multi-cutoff saturation calculations.

### 5.4 Lower valuation shells

A number `k` with `v_p(k)<=alpha-1` cannot realize exponent `p^alpha` in `L_n`, regardless of its Apéry value. Lower shells only decide whether `v_p(J_n)` exceeds one. Their entire possible logarithmic contribution is already bounded by (3.2).

This is why the prime-power formulation does not provide an iterative descent: the first layer is one digital zero, and all later layers are sublinear in aggregate.

## 6. Reflection and the recurrence do not create another witness

For `p>sqrt(n)`, put `r=n mod p`. A target has `p|A_r`. Reflection gives the second zero

\[
p\mid A_{p-1-r}.
\tag{6.1}
\]

This does not help the lcm shell:

- the top-shell indices are `n-tp`, all congruent to `r` modulo `p`, not to `p-1-r`;
- the propagation from `r` to `r+p` crosses the singular row at `p`, and Apéry–Lucas is precisely the resulting rank-one replication;
- the continuant between a zero and its forced reflection has a universal factor `p`; after removing that factor, the quotient is a derivative/reflection defect, not a second target equation.

Within a nonsingular interval, the recurrence has state dimension two. At a zero `A_r=0`, the no-consecutive-zero theorem gives

\[
A_{r-1}\not\equiv0,\qquad A_{r+1}\not\equiv0\pmod p.
\tag{6.2}
\]

Thus local recurrence propagation supplies units around the target, not more zeros.

A bounded zero-fiber theorem cannot repair this. The abstract reflected rows

\[
Z_p^*=\{n\bmod p,\ p-1-(n\bmod p)\}
\]

have size at most two and align every selected prime on the same horizontal `n`. Therefore “at most two zeros per prime” is logically compatible with a target radical of linear logarithmic height.

## 7. Several shifted lcms do not escape

A natural shifted variant replaces `A_{n-k}` by `A_{n+h-k}`. Ignore the finitely many boundary primes where the quotient digit changes. For `p>sqrt(n)` and a stable quotient block, the same top-shell calculation gives

\[
p\mid J_n^{[h]}\iff p\mid A_{r+h}.
\tag{7.1}
\]

An original target only gives `A_r=0`.

- For `h=1`, (6.2) shows that an original target is **not** in the shifted defect.
- Taking a gcd/intersection of several shifted defects therefore loses target primes.
- Taking their lcm/union retains `J_n` as a factor and cannot make the upper bound smaller.
- Multiplying them increases height.
- A resultant between two shifted defects becomes divisible by `p` only when the same `p` is a zero at both shifts, which is an additional same-characteristic zero not forced by targetness.

There is an exact module explanation. On a nonsingular interval, every bounded shift is

\[
A_{r+h}=u_h(r)A_r+v_h(r)A_{r+1}\pmod p,
\tag{7.2}
\]

with rational functions whose denominators are `p`-units. A target-blind linear expression in bounded shifts is therefore

\[
U(r)A_r+V(r)A_{r+1}.
\tag{7.3}
\]

For it to vanish on every target state `A_r=0` while `A_{r+1}` remains free and nonzero, one must have `V(r)=0`; the expression descends to a multiple of `A_r`. For polynomial expressions, the vanishing ideal of the target line in the two-dimensional local state space is the principal ideal `(A_r)`. Thus bounded-order Fitting, resultant, and exterior constructions either:

1. descend to the original target coordinate;
2. vanish identically; or
3. require an additional zero not implied by the lcm defect.

This no-go is scoped correctly: it excludes recurrence-universal, bounded-order identities. It does not exclude a new high-degree identity special to the distinguished Apéry initial state.

## 8. Cyclotomic and multiscale packaging

The lcm `D_n` is already diagonal in prime-power coordinates:

\[
D_n=\prod_{p\le n}p^{\alpha_p}.
\]

Passing to cyclotomic products, factorial ratios, dyadic shells, or quotient arcs only repackages the nonnegative valuation vector. For `p>sqrt(n)`, the defect coordinate is Boolean:

\[
v_p(J_n)=\mathbf1_{p\mid A_{n\bmod p}}.
\tag{8.1}
\]

Any integer carrier retaining all such primes has logarithmic height at least their total logarithmic weight. Signed ratios can cancel a universal band of prime valuations only by canceling the target valuations in that band as well. This is the same height-versus-selectivity saturation proved for the factorial and folded-boundary carriers in the current project state.

Multiscale partitioning does give useful localization. Primes `p<=n/F(n)` have total possible weight `O(n/F(n))`, so one may restrict to `F(n)` outer quotient digits. The global folded-index/slack carriers in Section 41 of the working note further remove the two boundary regions at `o(n)` cost. But the remaining core still has one independent Boolean coordinate (8.1) for each candidate prime. Summing `O(n)` separate `O(log n)` carriers is exactly the forbidden step; no lcm identity compresses those core coordinates.

## 9. A genuine new inequality from non-reflection continuants

Although the lcm shell itself is saturated, the recurrence supplies a precise conditional improvement.

Let

\[
\mathcal P_n=\{p>\sqrt n:p\mid J_n\}.
\tag{9.1}
\]

For `p in P_n`, put `r_p=n mod p`. Let `H` be a finite set of positive integers. Call `p` **covered by H** if there is an `h in H` such that either

\[
p\mid A_{r_p+h}
\quad\text{or}\quad
r_p\ge h\text{ and }p\mid A_{r_p-h},
\tag{9.2}
\]

and the two zeros are not merely the forced reflection pair.

Let `N_h(x)` be the cleared Apéry gap continuant. The exact same-prime zero detector gives:

- if `p|A_{r_p}` and `p|A_{r_p+h}`, then `p|N_h(r_p)`;
- if `p|A_{r_p-h}` and `p|A_{r_p}`, then `p|N_h(r_p-h)`.

Since `r_p congruent n (mod p)`, every covered prime divides

\[
C_{n,H}:=\prod_{h\in H}N_h(n)N_h(n-h),
\tag{9.3}
\]

with the obvious omission when `n-h<0`. The continuants are positive nonzero integers and satisfy

\[
\log N_h(n)+\log N_h(n-h)\ll h\log n.
\tag{9.4}
\]

Define the uncovered logarithmic weight

\[
W_{\rm unc}(n;H):=
\sum_{\substack{p\in\mathcal P_n\\p\text{ not covered by }H}}
\log p.
\tag{9.5}
\]

Then (3.2), (9.3), and (9.4) prove:

### Theorem 9.1 — lcm defect versus a weighted second-zero cover

\[
\boxed{
\log J_n
\ll
\sqrt n+W_{\rm unc}(n;H)
+\log n\sum_{h\in H}h.
}
\tag{9.6}
\]

This is a genuinely new inequality rather than another equivalence.

### Minimal reopening input

A single Apéry-specific theorem of the following form would finish the lcm route:

> **Weighted non-reflection cover.** For every `n`, there exists a finite set `H_n` such that
> \[
> \sum_{h\in H_n}h=o(n/\log n)
> \]
> and the total logarithmic weight of target primes whose zero fiber has no non-reflected second zero at a gap in `H_n` is `o(n)`.

Theorem 9.1 would then give `log J_n=o(n)`.

This input is minimal in a meaningful sense: it creates exactly the extra same-characteristic equation absent from the rank-one Lucas shell. It is also genuinely nontrivial. If a target prime has the exact doublet fiber

\[
Z_p=\{r_p,p-1-r_p\},
\]

then no non-reflected second-zero carrier can cover it. The empirical smallness of zero fibers therefore does not imply the required cover; it often points in the opposite direction.

## 10. Final assessment

The near-maximal-lcm formulation is a clean prime-free interface:

\[
\log L_n=n+o(n)
\iff
\log J_n=o(n).
\]

But the reason it does not yet prove P3.2 is now exact:

1. recovering the top power `p^alpha` requires a top-shell multiple `t p^alpha`;
2. all top-shell Apéry values are `A_rho` times a fixed vector modulo `p`;
3. the vector contains the unit coefficient `A_0=1`;
4. therefore failure of the entire shell is exactly the single condition `p|A_rho`;
5. higher missing powers have only `O(sqrt(n))` total possible height;
6. bounded shifts and Fitting/exterior operations either lose targets or return the same principal target ideal.

So there is no independent “near-maximal lcm theorem” available from the multiplicity of top-valuation multiples, `p`-Lucas, reflection, or the order-two recurrence alone. The lcm is not hiding extra combinatorial redundancy: at the hard primes, it is an exact Boolean encoding of the horizontal Apéry zero.

The useful output is the exact valuation theorem (1.3)–(1.4), the exact radical identity (2.5), the quantitative comparison (4.7), and the recurrence-cover inequality (9.6). A proof must now add actual-Apéry horizontal information, such as the weighted non-reflection cover above or another distinguished-state characteristic-zero carrier of sublinear height.
