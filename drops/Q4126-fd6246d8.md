# 1. What maximum packing actually implies

Let `G` be the physical-row support graph or multigraph and let `P` be a maximum family of pairwise edge-disjoint simple C4s. Maximum cardinality gives the usual global statement:

```text
there is no family of C4s using unused rows that, after deleting r packed
cycles, inserts more than r replacement cycles.
```

Equivalently, the exchange hypergraph has no augmenting component. This is a statement about **rows**, not about how the chosen least rows are distributed among vertices or signed stars.

Fix a lower-zero vertex `x=(p,z)` and suppose `t` packed cycles have their canonical selected row assigned to the signed star `(x,epsilon)`. Every one of those cycles contains:

1. its selected row incident to `x`; and
2. one other perimeter row incident to `x`.

Because the packing is physical-edge-disjoint, the resulting `2t` incident rows are all distinct. Hence

\[
2t\le \deg_G^{\rm inc}(x),
\]

which proves the second member of `(V1)`. The first member is tautological because selected rows are actual rows of the signed star.

Nothing about maximum cardinality was used. The same estimate holds for an arbitrary edge-disjoint family. Therefore an exchange argument can improve `(V1)` only if it uses an additional property excluding the sharp examples below.

A useful way to see the logical gap is this. Maximality says every **outside C4** meets the packing. It does not say that packed cycles cannot share vertices, lower anchors, signed stars, row values, or zero occurrences. Edge-disjoint C4s may form an arbitrarily large vertex windmill.

# 2. Absolute smallest simple-support obstruction: `K_{2,4}`

Let the two hubs be `x<y` and let the four leaves be

\[
r_0<r_1<r_2<r_3.
\]

Take the simple complete bipartite graph

\[
K_{\{x,y\},\{r_0,r_1,r_2,r_3\}}.
\]

Every C4 is determined by an unordered pair of leaves. An edge-disjoint packing is exactly a partition of used leaves into pairs, so the maximum packing size is `2`. There are many maximum packings and many two-cycle exchanges between them.

Order all `x-r_i` rows before all `y-r_i` rows, and assign every `x-r_i` row to the same formal signed star `(x,P)`. In every maximum packing, each packed C4 has two `x` rows and two `y` rows, and its least row is an `x` row. Consequently

\[
\deg_T(x,P)=2
\]

for every maximum packing, including a lexicographically least maximum packing. Exchanges merely change which two `x` rows are selected; they cannot move the transversal away from the star.

This is the smallest simple-graph obstruction to a degree-one theorem. A simple graph on at most five vertices cannot contain two edge-disjoint C4s:

- on four vertices, two different Hamilton C4s share two edges;
- if two C4s have a five-vertex union, they share three vertices. Each uses two of the three possible edges among those shared vertices, and two two-element subsets of a three-element set intersect. Hence the cycles share an edge.

Thus `K_{2,4}` is vertex-minimal among simple graphs with two edge-disjoint C4s.

It is an abstract support obstruction. The edge labels just imposed are not asserted to satisfy q6 row formulas.

# 3. The requested one-vertex windmill

For `k>=1`, define `W_k` as follows. There is one central vertex `a`. For each `0<=i<k`, introduce three fresh vertices

\[
b_i<c_i<d_i
\]

with `a<b_i`. Add exactly the four physical rows

\[
\begin{array}{lll}
e_i:&a\longrightarrow c_i,&P,\\
f_i:&c_i\longrightarrow b_i,&M^+,\\
g_i:&b_i\longrightarrow d_i,&P,\\
h_i:&d_i\longrightarrow a,&M^+.
\end{array}
\tag{3.1}
\]

The `i`-th petal is the coherently directed AD1 cycle

\[
C_i=(a,c_i,b_i,d_i,a).
\tag{3.2}
\]

The assigned canonical lower anchors are

\[
\begin{array}{c|c|c}
\text{row}&\text{assigned anchor}&\text{assigned sign}\\ \hline
e_i&a&P\\
f_i&c_i&M\\
g_i&b_i&P\\
h_i&d_i&M.
\end{array}
\tag{3.3}
\]

Under the canonical anchor-first row order, `e_i` is therefore the unique least row of `C_i`. The same conclusion holds under unordered-endpoint lex order: the only two rows incident to the least endpoint `a` are `{a,c_i}` and `{a,d_i}`, and `c_i<d_i`.

Hence

\[
\boxed{
\operatorname{least}(C_i)=e_i,
\qquad
\operatorname{star}(e_i)=(a,P)
\quad(0\le i<k).
}
\tag{3.4}
\]

## 3.1 These are all the C4s

Delete `a`. The remaining graph is the disjoint union of paths

\[
c_i-b_i-d_i.
\]

A simple cycle must use `a`, and after leaving `a` through one of `c_i,d_i` it cannot reach another petal without returning to `a`. Returning to `a` would close the cycle. Therefore every simple cycle lies in one petal. Inside a petal the only cycle is `C_i`.

Thus

\[
\{\text{simple C4s of }W_k\}=\{C_0,\ldots,C_{k-1}\}.
\tag{3.5}
\]

The petals are pairwise edge-disjoint, so

\[
\boxed{
\mathcal P_k:=\{C_0,\ldots,C_{k-1}\}
}
\]

is the **unique maximum** C4 packing, of size `k`.

## 3.2 Every exchange condition is vacuous

There is no unpacked C4 at all. Therefore:

- `P_k` is maximal;
- `P_k` is maximum;
- it is the unique maximum;
- it is lexicographically least among maximum packings;
- it is locally optimal under every `r`-for-`r+1` or bounded-size exchange rule;
- its exchange graph has no outside cycle vertex.

Nevertheless

\[
\boxed{
\deg_{T_{\min}}(a,P)=k.
}
\tag{3.6}
\]

At the underlying vertex `a`, the rows are

\[
e_0,h_0,e_1,h_1,\ldots,e_{k-1},h_{k-1},

so

\[
\deg_G^{\rm inc}(a)=2k.
\]

Only the `e_i` are assigned to `(a,P)`, hence

\[
\deg_G(a,P)=k.
\]

This proves `(V2)` and shows that both parts of `(V1)` are sharp.

## 3.3 Minimality with the one-vertex requirement

Two edge-disjoint C4s sharing exactly one vertex have

\[
4+4-1=7

vertices and eight edges. The windmill `W_2` has exactly these numbers. Thus it is the smallest simple one-vertex petal obstruction requested in the question.

from itertools import permutations

P = 0
M = 1


def edge(x, y):
    return tuple(sorted((x, y)))


def normalize_cycle(cycle):
    cycle = tuple(cycle)
    candidates = []
    for seq in (cycle, tuple(reversed(cycle))):
        for shift in range(4):
            candidates.append(seq[shift:] + seq[:shift])
    return min(candidates)


def enumerate_c4(vertices, edges):
    answer = set()
    for cycle in permutations(vertices, 4):
        if all(edge(cycle[j], cycle[(j + 1) % 4]) in edges
               for j in range(4)):
            answer.add(normalize_cycle(cycle))
    return answer


def verify_windmill(k):
    assert k >= 1
    a = 0
    vertices = {a}
    edges = set()
    row_key = {}
    expected = set()
    petals = []

        # a < b_i < c_i < d_i
        b = 3 * i + 1
        c = 3 * i + 2
        d = 3 * i + 3

        f = edge(c, b)  # M+(c -> b), assigned star (c,M)

# 9. Consequence for the canonical two-sided-deep transfer

The local step that is valid is the occurrence-sensitive pair-energy bound already used in the current canonical-row transfer. If `k_s` selected deep rows land at a signed lower star `s`, then

\[
\binom{k_s}{2}
\]

is a genuine same-star pair count. Summing these pairs and applying the exact pointwise threshold inequality gives a reduction of the form

\[
\sum_s k_s
\le h\,\#\{s:k_s>0\}
+\frac{1}{2h-1}\sum_s\binom{k_s}{2}.
\tag{9.1}
\]

That quadratic term is not removable by saying the original C4 packing was maximum. In `W_k`, one signed star has

\[
k_s=k,
\qquad
\binom{k_s}{2}=\binom{k}{2},
\]

and this is exactly the amount of concentration that a two-sided-deep pair ledger must pay.

Therefore the minimal correction to any proof claiming a packing-induced degree cap is:

```text
Delete the local-optimality degree lemma.
Retain the canonical row-occurrence injection.
Retain the signed-star second-factorial/pair-energy term.
Use maximum packing only for the global cycle-excess/hitting reduction,
not for a per-star degree bound.
```

A genuinely new replacement premise would have to be arithmetic, for example an occurrence-preserving estimate on

\[
\sum_{p,z,\varepsilon}
\binom{k_{p,z,\varepsilon}^{\rm deep}}2,
\]

or a theorem ruling out actual q6/Apéry windmills of the type isolated above. It cannot be obtained from exchange optimality alone.
