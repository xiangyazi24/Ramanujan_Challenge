
### Proof

Define the polynomial recurrence defect



# 6. Cold audit of the proposed extra constraints

## 6.1 Discriminants and derivatives

The claim

```text
two distinct selected roots of w
  => p divides disc(f_w)disc(g_w)
```

is false. A discriminant detects repeated roots of one polynomial. The selected roots are distinct and simple, so (3.2) says the local derivative factors are units.

A product of derivatives over the actual roots is also a unit modulo `p`. It cannot supply a forced extra `p`. The resultant already records one unit of nullity per distinct common root; the next-to-last divisor records the second distinct direction.

A derivative involving the actual selector `B_p'(x)` is prime-local. Neither the recurrence nor the hard masks presently force it to vanish or take a common value on two actual roots. Introducing its resultant with `H_(w,p)` merely repackages the prime-specific interpolation polynomial.

## 6.2 Trace constraints

The K3/Mellin interface gives a residual trace realization of each coefficient `b_x`. Hence actual roots can be described as defining-prime trace zeros. For each **fixed** exponent this has bounded geometric conductor.

The quantifier needed here is different: all possible roots `x` of one moving shell prime must be assembled in one index family while preserving their physical labels. Theorem 5.1 shows that the direct polynomial index selector has degree at least `p-5`. The existing fixed-exponent trace objects therefore do not imply a support-independent low-complexity family in the moving root coordinate.

Moreover, the event is residual trace zero modulo the defining prime, not equality to zero as an algebraic or complex trace. Standard fixed-conductor complex trace bounds do not count it without an additional diagonal residual theorem.

## 6.3 Divided values and first-Witt data

At a simple ordinary common root, the invariant

```text
Omega_(a,b,p)(x)
  =N_a'(x)[N_b(x+a)/p]
   -N_b'(x+a)[N_a(x)/p] mod p                         (6.1)
```

vanishes exactly when the two simple gap roots share a lift modulo `p^2`. The actual `p=1049` fixture has

```text
Omega=269!=0,
```

so even a genuine distinguished occurrence need not enter the extra-valuation stratum.

For several distinct roots of the same word, the first-Witt equations live componentwise in the split algebra (4.6). The current identities impose no equality, zero, or low-degree relation among their `Omega` values. Post-selecting the roots and averaging these labels would again leave the physical count in the zero-frequency term. No such averaging is used here.

## 6.4 Reflection

Reflection sends

```text
(x,a,b) -> (p-1-x-a-b,b,a).                          (6.2)
```

After the fixed-centre deletion it acts freely and identifies one physical quotient orbit. It gives a constant-factor pairing, not a new affine root of the same oriented word and not a second Smith direction. The canonical reversal-class convention already removes this duplication.

## 6.5 Root separation

The characteristic-zero root strips prove `R_w!=0`. Modulo `p`, distinct common roots have nonzero pairwise differences and hence independent evaluation functionals. This is exactly the Vandermonde proof of (3.1). It does not give archimedean separation of their integer lifts or an additional divisibility.

## 6.6 Long return between two occurrences

If two actual occurrences of the same word start at `x<y`, then their common state gives a long return from one packet to the other. That equation is not a new fixed-word short equation; its continuant length is `y-x`, and with intervening returns it lies in the connected renewal ideal already audited in Q6370. It is excluded from the present attack and is not counted as a new Smith direction.

```text
     sum_(eps=+,-)(m_(p,gamma,eps)(w)-1)_+.           (8.3)
```

For one fixed `gamma`, the two canonical sides are disjoint subsets of the physical roots of `w`; hence

```text
sum_eps (m_(p,gamma,eps)(w)-1)_+
  <=(t_p^(hard,q0)(w)-1)_+.                           (8.4)
```

Summing over left roots gives the correct, multiplicity-preserving inequality

```text
R_mid(alpha,w;p)
  <=#A_p(alpha;q0)(t_p^(hard,q0)(w)-1)_+
  <=rho_p(alpha)(rho_p(w)-1)_+.                       (8.5)
```

The tempting replacement

```text
sum_gamma (m_gamma(w)-1)_+
  <=(t_p^(hard,q0)(w)-1)_+                            (FALSE)
```

would collapse distinct physical left uses of the same companion direction and amounts to dividing by an unknown selected left mass.

Define the support-independent mixed tail carrier

```text
Xi_tail(alpha,w)
  =product_(i=1)^n_alpha
     product_(j=1)^(n_w-1)
       rad(gcd(d_(alpha,i),e_(w,j))).                 (8.6)
```

Then

```text
v_p(Xi_tail(alpha,w))
  =rho_p(alpha)(rho_p(w)-1)_+,                        (8.7)
```

so (8.5) yields

```text
sum_(P<p<=2P)(log p)R_mid(alpha,w;p)
  <=log Xi_tail(alpha,w).                             (8.8)
```

Dropping radicals gives

```text
Xi_tail(alpha,w)
  divides Delta_(n_w-1)(w)^(n_alpha),

Xi_tail(alpha,w)
  divides |C_alpha|^(n_w-1).                         (8.9)
```

The current heights are

```text
n_alpha,n_w=H^(1+o(1)),
log |C_alpha|=H^(2+o(1)),
log |Delta_(n_w-1)(w)|=H^(2+o(1)).                   (8.10)
```

Therefore

```text
log Xi_tail(alpha,w)<<H^(3+o(1)).                    (8.11)
```

The required row scale is

```text
D R_theta
  =H^2 H^(1/2-2theta)H^o(1)
  =H^(5/2-2theta+o(1)).                               (8.12)
```

Hence the exact fixed-column deficit is

```text
H^3/(D R_theta)
  =H/R_theta
  =H^(1/2+2theta+o(1)).                               (8.13)
```

At the closing value `theta=5sigma/2`, this is

```text

```

The two-sided middle condition causes no orientation loss in (8.4), but it does not improve (8.5). One central block of repeated `w`-roots can lie in the middle relative to every sufficiently earlier fixed-left root. The same vertical tail direction can therefore be reused by all those marked left directions.

# 9. The additional packet-threshold loss

Even a target estimate for the duplicate mass does not automatically pay all entries of a repetition-rich packet.

Let


The only unconditional relation is


not `n=O(r)`. In the physical capacity,


```text

  <=(Lambda/R_theta)r H^o(1).                        (9.2)
```

This factor is sharp at the exposed packet level. Take one exact word `w_0` with



The repeated word uses only `R_theta+2=O(H)` roots, within the degree capacity of its fixed word scheme. Because `R_theta=o(Lambda)`, the packet can retain the required two-sided middle margins.

The first concerns physical reuse of one extra root; the second concerns singleton entries admitted by the definition of the rich packet.

## 11.2 Exact verifier specification

The following pseudocode is sufficient to produce the missing finite table without changing the theorem logic.

```python
# Exact modular recurrence; all inverses are legal for n+1<p.
def apery_mod(p, modulus):
    b = [0] * p
    b[0] = 1
    b[1] = 5 % modulus
    for n in range(1, p-1):
        Pn = 34*n**3 + 51*n**2 + 27*n + 5
        b[n+1] = (
            (Pn*b[n] - n**3*b[n-1])
            * pow((n+1)**3, -1, modulus)
        ) % modulus
    return b

# Returns N_h(x), N_h'(x) modulo modulus.
def continuant_jet(h, x, modulus):
    if h == 0:
        return 0, 0
    Nm1, N = 0, 1
    Dm1, D = 0, 0
    for k in range(1, h):
        y = x + k
        Py  = 34*y**3 + 51*y**2 + 27*y + 5
        Pdy = 102*y**2 + 102*y + 27
        Nnext = (Py*N - y**6*Nm1) % modulus
        Dnext = (
            Pdy*N + Py*D
            - 6*y**5*Nm1 - y**6*Dm1
        ) % modulus
        Nm1, N = N, Nnext
        Dm1, D = D, Dnext
    return N, D

def canonical_triple(p, x, a, b):
    reflected = (p-1-x-a-b, b, a)
    return min((x, a, b), reflected)

for p in primes_in_requested_range:
    bp  = apery_mod(p, p)
    bp2 = apery_mod(p, p*p)
    zeros = [x for x in range(p) if bp[x] == 0]

    groups = defaultdict(dict)
    for i in range(len(zeros)-2):
        x, x1, x2 = zeros[i:i+3]
        a, b = x1-x, x2-x1

        if not balanced_hard(a, b):
            continue
        if not deep_nonwrapping_offcentre(p, x, a, b):
            continue

        Na, Da = continuant_jet(a, x, p)
        Nb, Db = continuant_jet(b, x+a, p)
        assert Na == 0 and Nb == 0
        if Da == 0 or Db == 0:
            continue                    # selected roots must be simple

        rep = canonical_triple(p, x, a, b)
        word_class = min((a,b),(b,a))

        Na2, _ = continuant_jet(a, x, p*p)
        Nb2, _ = continuant_jet(b, x+a, p*p)
        Wa = (Na2 // p) % p
        Wb = (Nb2 // p) % p
        Omega = (Da*Wb - Db*Wa) % p

        groups[word_class][rep] = {
            "raw": (x,a,b),
            "slopes": (Da,Db),
            "W": (Wa,Wb),
            "Omega": Omega,
        }

    for word_class, roots in groups.items():
        if len(roots) >= 2:
            emit(p, word_class, roots)
```

For the campaign data, `balanced_hard` and `deep_nonwrapping_offcentre` must be replaced by the literal current mask rather than an informal numerical surrogate. The dictionary keyed by `canonical_triple` enforces physical deduplication. Grouping by the complete `word_class` prevents the `p=5683` error. The code reports slopes and `Omega` but does not assume they vanish.

This verifier was not executed in the connector runtime. It is included as an exact reproducible specification for extending the existing scan; finite output would remain evidence, not an asymptotic theorem.
