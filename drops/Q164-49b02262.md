# Poisson approximation via Stein–Chen: the missing point is not pairwise CRT error but joint dependence

## Executive conclusion

The Stein–Chen idea is very close to the correct framework, but the naive dependency graph interpretation is not. The CRT pair estimate is strong enough to show that every pair has tiny covariance, but classical dependency-graph Stein–Chen requires a graph encoding genuine independence, not merely small covariance.

For the Apéry indicators

\[
X_p(m)=1_{m\bmod p\in Z_p},
\qquad K_X(m)=\sum_{X<p\le 2X}X_p(m),
\]

we know the first moment

\[
\lambda_X=\sum_p \frac{|Z_p|}{p}\asymp \frac1{\log X}
\]

and the pair CRT error

\[
J_{pq}-\frac{M|Z_p||Z_q|}{pq}
\]

is absolutely bounded by \(O(|Z_p||Z_q|)\). This is not yet a Stein–Chen dependency theorem.

The missing object is a **uniform multi-prime mixing estimate**.

---

## 1. What is the natural dependency neighborhood?

For a genuine dependency graph, we need

\[
X_p\perp\{X_q:q\notin N_p\}.
\]

There is no obvious finite exceptional set \(N_p\) in the Apéry problem.

The event

\[
X_p=1
\]

is the condition

\[
m\equiv r\pmod p,
\qquad r\in Z_p.
\]

For a different prime \(q\), the condition is another congruence modulo \(q\). By CRT, the two congruences are independent at the level of residues.

However, when one samples \(m\) from a finite interval \([1,M]\), the only dependence comes from the boundary discrepancy. This dependence exists for every pair, but it is very small.

Therefore the natural neighborhood is not a combinatorial neighborhood such as

\[
N_p=\{q:|p-q|<H\}.
\]

There is no evidence for arithmetic clustering of bad primes.

A more appropriate notion is a **weighted dependency neighborhood**:

\[
N_p(\eta)=\{q:\ |\operatorname{Cov}(X_p,X_q)|>\eta\}.
\]

The CRT bound suggests

\[
|\operatorname{Cov}(X_p,X_q)|
\ll \frac{|Z_p||Z_q|}{M}.
\]

Hence for a sufficiently weak threshold, this neighborhood is empty.

But this is not the same as a classical dependency graph.

---

## 2. Does the \(O(X^{-2})\) covariance make the Stein–Chen graph empty?

No. It makes a **weighted graph** empty, not a dependency graph.

Classical Stein–Chen requires:

\[
X_i\text{ independent of }\sigma(X_j:j\notin N_i).
\]

The condition

\[
|E[X_iX_j]-E[X_i]E[X_j]|\ll X^{-2}
\]

only gives pairwise approximate independence.

Pairwise independence is insufficient for Poisson approximation.

A standard counterexample is a family of random variables where every pair is independent but the total sum has a strong global constraint.

The Apéry problem has the same possible obstruction: all indicators are functions of the same integer variable \(m\).

Therefore the empty dependency graph argument does not apply directly.

---

## 3. Does bounded dependency degree hold?

Not for the classical dependency graph.

The natural graph has an edge whenever two variables are not exactly independent. Since all variables are functions of \(m\), this graph is complete:

\[
d_p\asymp \pi(2X)-\pi(X)\asymp \frac X{\log X}.
\]

So Barbour's bounded-degree hypothesis fails.

What we need instead is an **approximate dependency graph theorem** where the error is measured by total covariance or coupling error.

The quantities to bound would be something like

\[
\sum_p\sum_{q\ne p}
|E[X_pX_q]-E[X_p]E[X_q]|.
\]

Using the CRT estimate gives only

\[
\ll \sum_{p,q}\frac{|Z_p||Z_q|}{pq},
\]

which is roughly

\[
\lambda_X^2.
\]

This is promising, but standard Stein–Chen does not automatically convert this into total variation.

---

## 4. Can Arratia–Goldstein–Gordon (AGG) help?

AGG is closer to the right tool because it allows dependency measured by coupling quantities.

The relevant theorem bounds

\[
d_{TV}(K,\operatorname{Poisson}(\lambda))
\]

by terms analogous to

\[
b_1+b_2+b_3.
\]

Here:

### Term \(b_1\)

\[
b_1=\sum_p E[X_p]^2.
\]

Since

\[
E[X_p]=\frac{|Z_p|}{p},
\]

and empirically \(|Z_p|=O(1)\),

\[
b_1\ll \sum_p p^{-2}\ll \frac1{X\log X}.
\]

This is negligible.

Even with the unconditional bound

\[
|Z_p|\ll p^{2/3},
\]

we get

\[
b_1\ll \sum_p p^{-2/3}
\ll X^{-2/3}\frac X{\log X},
\]

still small.

### Term \(b_2\)

For true dependencies, this is the problem term. The CRT estimate gives

\[
E[X_pX_q]
=E[X_p]E[X_q]+O(M^{-1}),
\]

but AGG needs a neighborhood where the remaining variables are coupled away.

No such neighborhood is currently proved.

### Term \(b_3\)

This is the real obstruction:

\[
b_3=\sum_p E|E[X_p-E[X_p]\mid \sigma(X_q:q\notin N_p)]|.
\]

This asks for conditional mixing of one Apéry zero event against all other prime tests.

That is essentially the missing multi-prime independence theorem.

---

## 5. What theorem would finish the problem?

A sufficient replacement for bounded dependency would be:

For every fixed \(k\),

\[
P(X_{p_1}=\cdots=X_{p_k}=1)
=(1+o(1))\prod_i\frac{|Z_{p_i}|}{p_i}
\]

uniformly over distinct primes.

Then the factorial moments satisfy

\[
E[(K)_k]=(1+o(1))\lambda_X^k,
\]

which gives Poisson convergence.

This is exactly the HM\(_k\) program already identified:

- HM\(_2\) is essentially proved.
- HM\(_3\) is the first genuinely difficult case.

Stein–Chen is another language for the same missing theorem.

---

## 6. Would Poisson approximation imply the GCD bound?

Yes, if the total variation error is strong enough.

If

\[
d_{TV}(K_X,\operatorname{Poisson}(\lambda_X))=o(1),
\]

then for any threshold \(T\),

\[
P(K_X\ge T)
\le
P(Pois(\lambda_X)\ge T)+o(1).
\]

For Poisson,

\[
P(Y\ge T)\approx \left(\frac{e\lambda}{T}\right)^T.
\]

Since

\[
\lambda_X\asymp 1/\log X,
\]

we can take

\[
T\sim \frac{\log X}{\log\log X}
\]

with overwhelming probability.

In fact this is much stronger than needed. The GCD conjecture only requires

\[
K(n)=o(n/\log n).
\]

A Poisson tail of size \(O(\log X/\log\log X)\) would immediately imply it.

The earlier heuristic \(O(\log\log X)\) is too optimistic for a Poisson variable with mean \(1/\log X\); the extreme-value scale over \(X\) samples is closer to

\[
\frac{\log X}{\log\log X}.
\]

Still completely sufficient.

---

# Final assessment

The Stein–Chen route is promising, but the missing step is not pairwise CRT error.

Known:

1. \(\lambda_X\asymp1/\log X\).
2. \(b_1=o(1)\).
3. Pairwise correlations are tiny.
4. HM\(_2\) is essentially available.

Unknown:

1. A bounded or sparse true dependency neighborhood.
2. The AGG \(b_3\) conditional mixing term.
3. Uniform HM\(_k\) estimates for \(k\ge3\).

The right interpretation is:

\[
\boxed{
\text{Stein--Chen does not remove the independence barrier; it isolates it as }b_3.
}
\]

The breakthrough theorem would be an approximate conditional independence statement for the moving Apéry zero events. Once that is obtained, Poisson approximation would likely finish the all-\(n\) GCD conjecture immediately.
