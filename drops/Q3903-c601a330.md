# 3. The precise `chi_+` repair

The common primary test must be factored out of the assignment predicate.

For row `i`, define the **reduced minus predicate**

\[
\operatorname{Minus}^{\circ}_i(p)
\tag{3.1}
\]

to be every clause of `MinusActive_i(p)` except the common primary divisibility `p|b_r`. In the basic q6 formula this is

\[
\operatorname{Minus}^{\circ}_i(p)
:=
G_i^-(p)
\wedge 0\le m_i<p
\wedge p\mid b_{m_i},
\tag{3.2}
\]

where any exact local minus-retention clauses not involving `p|b_r` are included in `G_i^-`.

Now define

\[
\boxed{
\chi_{+,i}(p)
:=
1-\mathbf 1_{\operatorname{Minus}^{\circ}_i(p)}.
}
\tag{3.3}
\]

Thus `chi_{+,i}(p)=1` precisely when the candidate row is not made minus-active by its competing secondary condition once the common primary zero is supplied.

For the upper pair set

\[
\boxed{
\chi_{+,12}(p):=\chi_{+,1}(p)\chi_{+,2}(p).}
\tag{3.4}
\]

Let `P_12^geom` be the set of candidate lower primes satisfying only:

- primality and the exact lower shell;
- the common-row equations (1.1);
- the recovered-coordinate equations (1.6)--(1.9);
- all exact plus geometric, residual, and short-gap conditions;
- the already fixed upper-state conditions `q_i|b_{u_i}`;
- exclusion of the fixed exceptional primes dividing `b_6b_13` if the theorem is stated without an “all sufficiently large `T`” qualifier;

and **not** any of

\[
p\mid b_z,
\qquad p\mid b_{a_1},
\qquad p\mid b_{a_2}.
\tag{3.5}
\]

The repaired target-blind product is

\[
\boxed{
\Sigma_{12}^+
:=
\prod_{p\in\mathcal P_{12}^{\rm geom}}
 p^{\chi_{+,12}(p)}.
}
\tag{3.6}
\]

Since each exponent is zero or one, `Sigma_12^+` is squarefree.

This construction is target-blind in the required sense:

- it does not use the primary target `p|b_z`;
- it does not use the plus-secondary targets `p|b_{a_1},p|b_{a_2}`;
- it only removes candidates for which the competing minus-secondary test would make the row assigned minus after the common primary is proved.

The exact factorization of the assignment predicate is now

\[
\boxed{
\mathbf 1_{\operatorname{AssignedPlus}_i(p)}
=
\mathbf 1_{G_i^+(p)}
\mathbf 1_{p\mid b_z}
\mathbf 1_{p\mid b_{a_i}}
\chi_{+,i}(p).
}
\tag{3.7}

Equation (3.7) is the precise repair requested in the question.

# 8. Recovery of `z,a_1,a_2` and pair multiplicity

The recovery map from an upper-pair occurrence and a carrier prime is

\[
\boxed{
\begin{aligned}
u_i&=n-6q_i,\\
d_i&=q_i-p,\\
z&=7p-1-n,\\
a_i&=n+6q_i-13p.
\end{aligned}}
\tag{8.1}
\]

Every quantity is unique. Substitution recovers

\[
q_i=p+\frac{z+a_i+1}{6},
\qquad
u_i=p-a_i-2z-2.
\tag{8.2}
\]

Thus there is no hidden orientation fibre once the selected upper occurrences `(q_i,u_i)` are retained in the key.

Let

\[
k_+(p,z)
:=
\#\{\text{retained minus-first assigned-plus leaves at }(p,z)\}.
\tag{8.3}
\]

Use unordered upper pairs with `q_1<q_2`, and keep the row coordinate `n` in the occurrence key. Since `Sigma_12^+` is squarefree, so is `H_12^+`. The exact multiplicity identity is

\[
\boxed{
\sum_{(n,q_1,q_2)}\log H_{12}^+
=
\sum_{(p,z)}\binom{k_+(p,z)}2\log p.
}
\tag{8.4}
\]

The proof is fibre one:

- each unordered pair of leaves at `(p,z)` gives one ordered-by-size upper pair `q_1<q_2` and hence one occurrence `(n,q_1,q_2,p)`;
- (8.1) recovers `(p,z,a_1,a_2)` from that occurrence;
- conversely, every prime divisor of one `H_12^+` gives exactly that pair by (7.2).

If the checker stores ordered pairs `(q_1,q_2)` and `(q_2,q_1)`, the left side is twice (8.4). It must either impose `q_1<q_2` or insert the explicit factor `1/2`. No factor two is present under the unordered convention.

Likewise, globally deduplicating the bare set `{p,q_1,q_2}` is invalid: the row `n` must remain part of the occurrence key.
