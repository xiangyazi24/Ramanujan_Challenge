# Q1928: gap-one finite first-integral search

## 1. Reduction to the Riccati-plus-sum system

Put

\[
r_n=\frac{X_{n-1}}{X_n},\qquad \sigma_n=\frac{Y_n}{P_n}.
\]

The continuant recurrence gives the exact Riccati update

\[
r_{n+1}=\frac{1}{a_n-c_nr_n},
\]

with

\[
a_n=4n(68n^2+3),\qquad c_n=(2n-1)^6.
\]

The second variable satisfies

\[
\sigma_n=\sigma_{n-1}-\frac{6(n^2-1)d_n}{X_n},
\]

and therefore the increment depends on the missing scale variable \(X_n\), not only on \(r_n\).

## 2. No-go for the closed ansatz \(I(n,r_n,\sigma_n)\)

Consider a rational first integral of bounded bidegree

\[
I(n,r,\sigma)=\frac{A(n,r,\sigma)}{B(n,r,\sigma)}
\]

whose increment vanishes under

\[
(r,\sigma)\mapsto\left(\frac1{a_n-c_nr},\sigma-6(n^2-1)d_n/X_n\right).
\]

The obstruction is that \(X_n\) is not determined by \(r_n\). Indeed the transformation

\[
(X_{n-1},X_n)\mapsto(\lambda X_{n-1},\lambda X_n)
\]

leaves \(r_n\) invariant but changes the sigma increment by

\[
\Delta\sigma_n\mapsto \lambda^{-1}\Delta\sigma_n.
\]

Hence two trajectories with the same \((n,r_n,\sigma_n)\) but different common scale have different next sigma values. Therefore no nonconstant rational first integral in the variables \((n,r_n,\sigma_n)\) alone can exist.

This is an exact compatibility obstruction, not a numerical failure of a search.

## 3. Minimal closure

Introduce the missing normalized scale

\[
z_n=\frac{d_n}{X_n}.
\]

Then

\[
\sigma_{n}=\sigma_{n-1}-6(n^2-1)z_n.
\]

Using the Riccati equation,

\[
z_{n+1}=\frac{d_{n+1}}{X_{n+1}}
      =\frac{(2n+1)^3d_n/X_n}{a_n-c_nr_n}
      =\frac{(2n+1)^3z_n}{a_n-c_nr_n}.
\]

Thus the minimal closed system is

\[
\boxed{
\begin{aligned}
r_{n+1}&=(a_n-c_nr_n)^{-1},\\
z_{n+1}&=(2n+1)^3z_n(a_n-c_nr_n)^{-1},\\
\sigma_{n+1}&=\sigma_n-6(n+1)^2z_{n+1}.
\end{aligned}}
\]

A first integral, if present, must live in this three-variable system.

## 4. Endpoint condition

The endpoint relation

\[
e_m=0
\]

implies

\[
r_m=\frac{X_{m-1}}{X_m}=\frac5{(2m-1)^3}.
\]

Substituting this into the Riccati update gives a constraint on the next ratio only:

\[
r_{m+1}=\frac1{4m(68m^2+3)-5(2m-1)^3}.
\]

It gives no direct vanishing relation for \(\sigma_m\). The missing invariant must couple the endpoint ratio with the accumulated derivative variable \(z_n\).

## 5. Candidate next ansatz

The smallest possible extension is therefore

\[
I(n,r_n,z_n,\sigma_n)
\]

with degree at most one in \(\sigma,z\):

\[
I=A(n,r)\sigma+B(n,r)z+C(n,r).
\]

Substitution into the closed system reduces the search to solving the dual linear recurrence for \(A,B,C\). A successful solution would give

\[
I(m,r_m,z_m,\sigma_m)=\text{unit}
\]

modulo \(2m+1\), proving \(\sigma_m\neq0\).

## Conclusion

There is no finite first integral in the requested \((n,r_n,\sigma_n)\) ansatz because sigma evolution contains the independent scale \(d_n/X_n\). The exact minimal closure is the addition of \(z_n=d_n/X_n\). Any valid telescoper or arithmetic certificate must be constructed in the resulting three-dimensional rational dynamical system; a two-variable pattern match cannot prove the gap-one statement.
