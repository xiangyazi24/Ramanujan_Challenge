# 3. Deterministic proof of the long-gap compression

Fix `u,tau,D,Y` with

\[
1\le Y\le D.
\]

Suppose

\[
p\in I_j^\tau,
\qquad
p'\in I_{j+r}^\tau,
\qquad
p<p'.
\]

From the half-open endpoint inequalities,

\[
(r-1)Y<p'-p<(r+1)Y.
\tag{3.1}
\]

If in addition

\[
D\le p'-p<2D,
\]

then necessarily

\[
\frac DY-1<r<\frac{2D}{Y}+1.
\tag{3.2}
\]

Let

\[
\mathcal L(D,Y)
:=
\left\{r\in\mathbb Z_{>0}:
\frac DY-1<r<\frac{2D}{Y}+1
\right\}.
\]

The interval in `(3.2)` has length `D/Y+2`, hence

\[
|\mathcal L(D,Y)|
\le\frac DY+3
\le4\frac DY
\tag{3.3}
\]

because `D/Y>=1`.

Therefore the same-state pair count at this `u` is bounded by

\[
E_u(D)
\le
\sum_{r\in\mathcal L(D,Y)}
\sum_j
\nu_{u,j}(\tau)
\nu_{u,j+r}(\tau).
\tag{3.4}
\]

For every fixed positive lag `r`, Cauchy--Schwarz gives

\[
\sum_j
\nu_{u,j}(\tau)
\nu_{u,j+r}(\tau)
\le
\left(\sum_j\nu_{u,j}(\tau)^2\right)^{1/2}
\left(\sum_j\nu_{u,j+r}(\tau)^2\right)^{1/2}
=
\sum_j\nu_{u,j}(\tau)^2.
\tag{3.5}
\]

Combining `(3.3)`--`(3.5)`,

\[
\boxed{
E_u(D)
\le
4\frac DY
\sum_j\nu_{u,j}(\tau)^2.
}
\tag{3.6}
\]

Summing over selected upper states gives

\[
\boxed{
E_\sigma(D)
\le
4\frac DY
\sum_{u,j}\nu_{u,j}(\tau)^2.
}
\tag{3.7}
\]

This is the requested deterministic reduction.  It is valid for **every** translated partition and for every finite family of sets `A_u`; no Apéry arithmetic was used.

The argument is slightly cleaner than Q4182's `2ab<=a^2+b^2` proof because each cell-lag correlation is simply an `l^2` inner product bounded by the cell `l^2` norm.

# 5. Exact translated-mesh identity

The translated partitions yield more than existence of a convenient origin.

For a fixed state `u`, expand

\[
S_u(\tau)
:=
\sum_j\nu_{u,j}(\tau)^2.
\]

This is

\[
S_u(\tau)
=
\sum_{p,p'\in A_u}
1_{\{p,p'\text{ lie in the same }I_j^\tau\}}.
\tag{5.1}
\]

Fix two distinct integers

\[
p<p',\qquad h=p'-p.
\]

As `tau` ranges through the `Y` integer translates modulo `Y`, the pair lies in one common cell for exactly

\[
Y-h
\]

translates if `1<=h<Y`, and for no translate if `h>=Y`.  Equivalently,

\[
\frac1Y
\sum_{\tau=0}^{Y-1}
1_{\{p,p'\text{ same cell}\}}
=
\left(1-\frac hY\right)_+.
\tag{5.2}
\]

For the diagonal `p=p'`, the average is `1`.

Summing `(5.2)` over states and ordered pairs gives the exact identity

\[
\boxed{
\frac1Y\sum_{\tau=0}^{Y-1}
\sum_{u,j}\nu_{u,j}(\tau)^2
=
M_\sigma(T)
+2\sum_{1\le h<Y}
\left(1-\frac hY\right)R_\sigma(h).
}
\tag{5.3}
\]

Here

\[
R_\sigma(h)
:=
\sum_u
\#\{p:p,p+h\in A_u\}.
\]

No cell endpoint error remains in `(5.3)`; the half-open convention and integer translate average make it exact.

## Consequence: an average theorem implies one good translate

If

\[
\sum_{1\le h<Y}
\left(1-\frac hY\right)R_\sigma(h)
\ll_J
Y T^{-\rho}M_\sigma(T),
\tag{5.4}
\]

then the average of the cell energies is

\[
\ll_J M_\sigma(T)(1+YT^{-\rho}).
\]

Therefore at least one translate satisfies OMCD.

## Converse warning

A single specially chosen translate can place boundaries through a short cluster and thereby reduce the same-cell energy.  Hence

```text

```

does **not** imply the average identity's off-diagonal bound `(5.4)`.

This is not a flaw in the APD reduction, because `(3.7)` needs only the one partition on which OMCD is known.

# 6. Does one good translate really suffice?

Yes.

The deterministic inequality `(3.7)` is true for every `tau`.  Therefore if there exists one translate

\[
\tau_*=\tau_*(T,\sigma,Y)
\]

with OMCD, apply `(3.7)` using exactly that translate.  The resulting scalar bound `(4.4)` is independent of the partition origin.

The good translate may depend on `T`, the sign and the chosen mesoscopic scale.  No canonical origin is required.  The implied constant in OMCD must of course be uniform in `T`.

The same `tau_*` then works simultaneously for **all** hard `D`, because `Y` is fixed and `(3.7)` holds for every `D>=Y`.

If one only proves existence of a possibly different good translate for each `D`, that still proves the scalar APD estimate block by block; it is simply a less elegant theorem statement.

## Even weaker: state-dependent translates

For each state choose an arbitrary translate `tau_u`.  Applying `(3.6)` state by state gives

\le
4\frac DY
\sum_u
\sum_j\nu_{u,j}(\tau_u)^2.
\tag{6.1}

Hence the weaker theorem

\boxed{

\ll_J
M_\sigma(T)(1+YT^{-\rho})

\tag{6.2}

already closes APD.

So Q4182's statement that one common good translate suffices is correct, but its claim to be the absolute weakest clean theorem can be sharpened.  A common mesh is an arithmetic convenience, not a logical necessity.

# 12. Fatal normalization flaw in Q4182's proposed large sieve

Q4182 Section 14.3 proposes schematically

\[
\sum_{I}\sum_u
\left|\sum_{p\in I}a_pH_\sigma(u,p)\right|^2
\ll
(1+YT^{-\rho})
\sum_p|a_p|^2.
\tag{12.1 bad}
\]

Expand the left side.  Since the cells partition the prime line,

\[
\begin{aligned}
\mathrm{LHS}
&=
\sum_p |a_p|^2
\sum_uH_\sigma(u,p)^2\\
&\quad+
2\Re
\sum_I
\sum_{\substack{p<p'\\p,p'\in I}}
 a_p\overline{a_{p'}}
 \mathcal N_\sigma(p,p').
\end{aligned}
\]

Because `H` is `0/1`,

\[
\sum_uH_\sigma(u,p)^2=d_\sigma(p).
\]

Hence the diagonal is exactly

\[
\boxed{
\sum_pd_\sigma(p)|a_p|^2.
}
\tag{12.2}
\]

Taking a coefficient sequence supported on one prime would force the bad display `(12.1)` to bound `d_sigma(p)` by an absolute constant close to one. No such multiplicity theorem is available or used elsewhere.

Therefore `(12.1)` is not a legitimate large-sieve target in the raw occurrence normalization.

## Smallest repair

Replace the right side by the actual diagonal measure:

\[
\boxed{
\sum_{I}\sum_u
\left|\sum_{p\in I}a_pH_\sigma(u,p)\right|^2
\ll_J
(1+YT^{-\rho})
\sum_pd_\sigma(p)|a_p|^2.
}
\tag{12.3 WLS}
\]

Now setting `a_p=1` for all shell primes gives

\[
\mathrm{RHS}
=(1+YT^{-\rho})M_\sigma(T),
\]

while the left is exactly the OMCD cell energy.

Thus the corrected weighted large sieve genuinely implies OMCD without any lower bound or multiplicity collapse.

# 13. Normalized-column form

For every prime with `d_sigma(p)>0`, define

\[
\widetilde H_\sigma(u,p)
:=
\frac{H_\sigma(u,p)}{\sqrt{d_\sigma(p)}}.
\tag{13.1}
\]

The columns now have norm one:

\[
\sum_u|\widetilde H_\sigma(u,p)|^2=1.
\]

Their Gram entries are

\[
\boxed{
G_\sigma(p,p')
=
\frac{\mathcal N_\sigma(p,p')}
{\sqrt{d_\sigma(p)d_\sigma(p')}}.
}
\tag{13.2}
\]

The weighted large sieve `(12.3)` is equivalent to saying that the Gram matrix after deleting all cross-cell entries has operator norm

\[
\ll_J1+YT^{-\rho}.
\]

OMCD itself asks for this quadratic form only on the special vector

\[
b_p=\sqrt{d_\sigma(p)},
\]

because

\[
\sum_{p\in I}b_p\widetilde H(u,p)
=
\sum_{p\in I}H(u,p).
\]

Therefore a full operator norm remains stronger than necessary.  A direct positive-coefficient proof of `(10.3)` is enough.

A still stronger but transparent Schur-type sufficient condition would be

\[
\sup_p
\sum_{\substack{p'\ne p\\p'\text{ in the same }Y\text{-cell}}}
\frac{\mathcal N_\sigma(p,p')}
{\sqrt{d_\sigma(p)d_\sigma(p')}}
\ll YT^{-\rho}.
\tag{13.3}
\]

I do **not** prove this pointwise bound; it is included only to identify the normalized local codegree that a spectral attack would have to control.

# 15. Independent attack II: retain the selected row mask

The tempting enlargement

with the two lower minus-first exclusions inserted, where `U_+(n,N)` is the selected upper-state indicator.  Minus has the analogous `(n,s)` formula with slopes `(6,1)`.

# 16. Why tensoring one-slope bounds does not currently close OMCD

If the selected upper mask is discarded, the two-slope row-pair incidence is a tensor product and the prime-pair Gram entry factorizes as

\[
J_6(p,p')J_{c_\sigma}(p,p').
\]

One may apply

\[
J_6J_c\le\frac12(J_6^2+J_c^2),
\]

or Cauchy--Schwarz over prime pairs.  But this only moves the problem to one-slope collision energies.

For one quotient slope, a common row `m=kp+x` means, outside the fixed Lucas-coefficient primes, that every prime in that row fibre divides one fixed common Apéry value `b_m`.  Its generic logarithmic height is `O_J(T)`.  Such a height can support

\[
O(T/\log T)
\]

shell-prime divisors globally and as many as the prime-counting allowance

\[
O(Y/\log T)
\]

inside a length-`Y` cell.  That is only logarithmic local control.

Therefore a proof that first replaces the selected codegree by the unselected tensor product and then invokes scalar row heights has no mechanism for the fixed `T^{-rho}` required by OMCD.

# 17. Why the full fixed-state gcd height also stops at the logarithmic barrier

For one selected state, outside fixed coefficient primes, every plus leaf divides

\[
\gcd(b_{6q+t},b_{12q+t})
\]

and every minus leaf divides

\[
\gcd(b_{6q+t},b_{q-1-t}).
\]

This is the already-known partner-independent full common-value carrier.  Its `O_J(T)` logarithmic height alone cannot prevent all of its large prime divisors from clustering in a length-`Y` interval.

An abstract integer of logarithmic height `O(T)` can contain the product of every prime in one interval of length `Y=T^beta` because that product has logarithm only `O(Y)=o(T)` for every `beta<1`.  Thus scalar height plus prime counting is logically compatible with cell occupancy of order

\[
Y/\log T,
\]

which is larger than the desired

\[
Y T^{-\rho}
\]

by a fixed power.

So OMCD must use how the actual Apéry gcds vary with the selected state, or equivalently the two-slope cross-characteristic structure in Section 11.

# 18. Independent attack III: the partner-dependent cross determinant

Let `c=13` on plus and `c=1` on minus.  For an actual same-state pair with

\[
p'=p+h,
\]

write the base lower zero indices as `(r,a)` so that the partner indices are

\[
r'=r-6h,
\qquad
a'=a-ch.
\]

Then the characteristic-zero determinant

\[
\boxed{
\mathscr D_{c,h}(r,a)
:=
 b_r b_{a-ch}
-b_a b_{r-6h}

\tag{18.1}
\]

satisfies

\[
\boxed{pp'\mid\mathscr D_{c,h}(r,a).}
\tag{18.2}
\]

Indeed `p` divides both unshifted factors `b_r,b_a`, while `p'` divides both shifted factors `b_{r-6h},b_{a-ch}`.

This eliminant is independent of prefix radicals and genuinely sees both characteristics.

However its pointwise logarithmic height remains `O_J(T)`, and it changes with `h` and with the base lower zero pair.  For a fixed base leaf, the family `h<Y` therefore produces `Y` different large integers.  Paying `O(T)` height for each one is much worse than the desired average budget

\[
O(LYT^{-\rho}).
\]

Thus the determinant is a valid algebraic certificate but not yet a counting theorem.

A useful new result would have to show cancellation in the **average primitive large-prime radical** of these determinants after all universal content is removed.  Stated at the selected occurrence level, that is essentially another characteristic-zero route to `(STS-Y)`.

No such radical theorem is currently banked.

# 19. Independent attack IV: deep common transfer blocks

On the deep reflected-gap interior and for `h<Y`, the base and partner recurrence intervals overlap in a block of length `H-O(Y)`.  One can factor the characteristic-zero transfer matrices into

* right boundary of length O(Y).

This is attractive because it is genuinely mesoscopic and does not use truncated binomial prefixes.

The obstruction is exact.  The base endpoint-return condition is imposed modulo `p`; the translated endpoint-return condition is imposed modulo `p'=p+h`.  Factoring out the same characteristic-zero middle matrix does not identify the two residue fields.  After one rewrites the base endpoint zeros as

and the partner endpoint zeros similarly, the short boundary equations retain the divided-value/projective coordinates `xi`. So the common-block route does isolate a plausible **divided-return mixing theorem**, but it does not presently prove one.

This is the same obstruction in a different language: the missing input is arithmetic decorrelation between two nearby defining characteristics, not another determinant identity inside one field.

# Bottom line

The Q4182 **reduction is correct** and can be proved more cleanly by cell-lag correlations.  It is genuinely self-normalized by the actual raw marked first mass and needs no unavailable lower bound.  A single good translate is sufficient because the long-gap inequality is translate-by-translate; translated averaging gives the exact triangular short-pair identity and is the most natural way to search for such a mesh.

\[

\left(1-\frac{p'-p}{Y}\right)
\#\{u:p,p'\in\mathcal P_\sigma(u)\}
\ll_J
YT^{-\rho}M_\sigma(T).

For plus this is the selected `(6,13)` collision system; for minus it is the selected `(6,1)` system, with raw minus-first assignment retained.  I do not find an unconditional proof of that theorem from the currently banked Apéry recurrence, scalar gcd height, one-slope moments, ordinary resultants or first divided-jet information.  The first genuinely new input must be cross-characteristic two-slope decorrelation (or an equivalent divided-return mixing theorem), not another prefix radical.
