3. **The construction is not identically zero.**  As a linear functional

   \log \mathfrak G_{M,d_0,L}
   =M\mathcal R_a(d_0/M)+O_a(L\log M),

   \[
   \mathcal R_a(\delta)\ge \log(17+12\sqrt2).

   \]

   \[
   \log |\mathfrak G_{M,d_0,L}|=\Theta(M)=\Theta(n),
   \qquad L\asymp H=n^{1/3}.
   \tag{0.8}
   \]

   The triangle estimate is therefore exponentially sharp in scale:
   interpolation may change the linear constant, but not the linear
   order.  It cannot give \(o(H)\).

   extra sample makes the stencil even while retaining every original

6. **Signed or shorter stencils do not repair the problem.**  A formal

   coefficient.  Nonlinear stencils satisfy the analogous monomial
   ideal statement.  They either retain all tall shell coordinates or
   pay the target product explicitly.

The Newton-extrapolation carrier is therefore a genuine common block
carrier, but after primitive normalization it remains exponentially tall.

## 1. Exact coefficient and one-sum shell formulas

Write

\[
\Lambda^M=\sum_{(u,v,w)\in\mathbb Z^3}c_M(u,v,w)x^uy^vz^w.
\tag{1.1}
\]

Use the convention \(\binom Nr=0\) unless \(0\le r\le N\).  Expanding the
last factor of (0.1) first gives

\[
\begin{aligned}
\Lambda^M
&=x^{-M}y^{-M}z^{-M}(1+x)^M(1+y)^M(1+z)^M\\
&\qquad\cdot
\sum_{t=0}^M\binom Mt(xyz)^t(1+y)^{M-t}(1+z)^{M-t}.
\end{aligned}
\tag{1.2}
\]

Therefore

\[
\boxed{
\begin{aligned}
c_M(u,v,w)
=\sum_{t=0}^M&\binom Mt
 \binom M{M-t+u}\\
&\cdot\binom{2M-t}{M-t+v}
 \binom{2M-t}{M-t+w}.
\end{aligned}}
\tag{1.3}
\]

This is the requested one-sum coefficient formula.

If \(\lfloor M/d\rfloor=a\), the support box of \(\Lambda^M\) shows that
only \(u=d\alpha,v=d\beta,w=d\gamma\) with
\(-a\le\alpha,\beta,\gamma\le a\) occur.  Define

\[
A_{M,t}^{(a)}(d)
 =\sum_{\alpha=-a}^a\binom M{M-t+d\alpha}
 =\sum_{\alpha=-a}^a\binom M{t-d\alpha},
\tag{1.4}
\]

and

\[
B_{M,t}^{(a)}(d)
 =\sum_{\beta=-a}^a
   \binom{2M-t}{M-t+d\beta}.
\tag{1.5}
\]

Then the three shell sums factor inside the \(t\)-sum:

\[
\boxed{
E_M(d)=
\sum_{t=0}^M\binom Mt
 A_{M,t}^{(a)}(d)
 \bigl(B_{M,t}^{(a)}(d)\bigr)^2.}
\tag{1.6}
\]

Equations (1.3) and (1.6) are dependency-free finite formulas.  For
example, for \(a=1\), the two packet factors are just

\[
\begin{aligned}
A_{M,t}^{(1)}(d)
 &=\binom M{t-d}+\binom Mt+\binom M{t+d},\\
B_{M,t}^{(1)}(d)
 &=\binom{2M-t}{M-t-d}
  +\binom{2M-t}{M-t}
  +\binom{2M-t}{M-t+d}.
\end{aligned}
\tag{1.7}
\]

For \(a=2\), add the two shifts \(\pm2d\).

The same formula can be written as a root-of-unity trace,

\[
d^3E_M(d)=
\sum_{\zeta_1^d=\zeta_2^d=\zeta_3^d=1}
\Lambda(\zeta_1,\zeta_2,\zeta_3)^M,
\tag{1.8}
\]

but (1.6) is more useful for exact integer computation.

## 2. Exact extrapolation weights

Put \(d_i=d_0+i\).  Lagrange interpolation at \(-1\) gives

\[
F(-1)=\sum_{i=0}^L\omega_iE_M(d_i),
\tag{2.1}
\]

where

\[
\begin{aligned}
\omega_i
&=\prod_{\substack{0\le j\le L\\j\ne i}}
  \frac{-1-d_j}{d_i-d_j}\\
&=(-1)^i
  \frac{(d_0+1)(d_0+2)\cdots(d_0+L+1)}
       {(d_0+i+1)i!(L-i)!}.
\end{aligned}
\tag{2.2}
\]

The factorial quotient is integral and factors into two binomial
coefficients:

\[
\boxed{
\omega_i=(-1)^i
\binom{d_0+i}{i}
\binom{d_0+L+1}{L-i}.}
\tag{2.3}
\]

Thus

\[
\boxed{
\mathfrak G_{M,d_0,L}
=F(-1)=
\sum_{i=0}^L(-1)^i
\binom{d_0+i}{i}
\binom{d_0+L+1}{L-i}
E_M(d_0+i).}
\tag{2.4}
\]

This is already an integer.  The equivalent Newton formula is

\[
\boxed{
\mathfrak G_{M,d_0,L}
=\sum_{k=0}^L
(-1)^k\binom{d_0+k}{k}\Delta^kE_M(d_0).}
\tag{2.5}
\]

Consequently

\[
G_{M,d_0,L}=L!\,\mathfrak G_{M,d_0,L}.
\tag{2.6}
\]

The values in (2.4) can be expanded by (1.6), giving the fully explicit
finite hypergeometric sum

\[
\boxed{
\begin{aligned}
\mathfrak G_{M,d_0,L}
=\sum_{i=0}^L\sum_{t=0}^M
&(-1)^i
\binom{d_0+i}{i}
\binom{d_0+L+1}{L-i}
\binom Mt\\
&\cdot A_{M,t}^{(a)}(d_0+i)
\bigl(B_{M,t}^{(a)}(d_0+i)\bigr)^2.
\end{aligned}}
\tag{2.7}
\]

Every summand has a rational consecutive-term quotient in both \(i\)
and \(t\); (2.7) is directly suitable for Zeilberger or creative
tele\-scoping.

## 3. The interpolation kernel as a terminating \({}_2F_1\)

Define the polynomial

\[
W_{d_0,L}(z)=\sum_{i=0}^L\omega_i z^i.
\tag{3.1}
\]

From (2.3),

\[
\boxed{
W_{d_0,L}(z)=
\binom{d_0+L+1}{L}
{}_2F_1\!\left(
\begin{matrix}-L,d_0+1\\d_0+2\end{matrix};z
\right).}
\tag{3.2}
\]

There are two useful exact alternatives.  Euler's beta integral gives

\[
\boxed{
W_{d_0,L}(z)=
\binom{d_0+L+1}{L}(d_0+1)
\int_0^1 t^{d_0}(1-zt)^L\,dt.}
\tag{3.3}
\]

Equivalently, with \(b=d_0+1\),

\[
W_{d_0,L}(z)=z^{-b}I_z(b,L+1),
\tag{3.4}
\]

where \(I_z\) is the regularized incomplete beta polynomial.  Expanding
that polynomial gives the purely algebraic form

\[
\boxed{
W_{d_0,L}(z)=
\sum_{j=0}^L
\binom{d_0+L+1}{d_0+1+j}
 z^j(1-z)^{L-j}.}
\tag{3.5}
\]

In particular,

\[
W_{d_0,L}(1)=1,
\qquad
\sum_{i=0}^L\omega_i=1.
\tag{3.6}
\]

The second equality will rule out an identically zero extrapolation.

## 4. Exact constant-term formula for the primitive carrier

For \(\kappa=(\kappa_1,\kappa_2,\kappa_3)\), write

\[
X^\kappa=x^{\kappa_1}y^{\kappa_2}z^{\kappa_3}.
\tag{4.1}
\]

Since \(\lfloor M/d_i\rfloor=a\), substitute (0.3) into (2.1) and
interchange the finite sums.  One obtains

\[
\begin{aligned}
\mathfrak G_{M,d_0,L}
&=\sum_{\kappa\in[-a,a]^3\cap\mathbb Z^3}
  \sum_{i=0}^L\omega_i
  [X^{(d_0+i)\kappa}]\Lambda^M\\
&=\sum_{\kappa\in[-a,a]^3\cap\mathbb Z^3}
 \operatorname{CT}\!\left(
 \Lambda(X)^M X^{-d_0\kappa}
 W_{d_0,L}(X^{-\kappa})
 \right).
\end{aligned}
\tag{4.2}
\]

Thus the cleanest closed formula is

\[
\boxed{
\mathfrak G_{M,d_0,L}
=\operatorname{CT}\!\left(
\Lambda(X)^M K_{a,d_0,L}(X)
\right),}
\tag{4.3}
\]

where

\[
\boxed{
K_{a,d_0,L}(X)=
\sum_{\kappa\in[-a,a]^3\cap\mathbb Z^3}
X^{-d_0\kappa}W_{d_0,L}(X^{-\kappa}).}
\tag{4.4}
\]

This is an exact characteristic-zero formula, not an estimate.
For each fixed \(\kappa\), the inner term is one coefficient extraction
with a terminating \({}_2F_1\) amplitude.

The zero shell \(\kappa=0\) contributes exactly

\[
\operatorname{CT}\Lambda^M\,W_{d_0,L}(1)=b_M.
\tag{4.5}
\]

## 5. Target divisibility and primitive content

Suppose \(q=d_i+1\) is prime and is a target in the fixed quotient block.
Writing \(M=ad_i+r\), Section 48 gives

\[
E_M(d_i)\equiv b_r\equiv b_{j(q)}\pmod q.
\tag{5.1}
\]

In the hard block, \(q>L\).  Since \(L!F(D)\in\mathbb Z[D]\),

\[
L!F(-1)\equiv L!F(d_i)=L!E_M(d_i)\pmod q.
\tag{5.2}
\]

The factor \(L!\) is a \(q\)-unit, so

\[
\boxed{
q\mid b_{j(q)}\quad\Longrightarrow\quad
q\mid\mathfrak G_{M,d_0,L}.}
\tag{5.3}
\]

Thus the primitive integer \(F(-1)\), not merely \(L!F(-1)\), is the
honest block carrier.

There is no further universal factorial or binomial content.  Indeed,
(3.6) implies

\[
\gcd(\omega_0,\ldots,\omega_L)=1.
\tag{5.4}
\]

Therefore the coefficient vector of \(G\) has gcd exactly \(L!\), and
that of \(\mathfrak G\) is primitive.  Any extra divisor of a particular
numerical value is arithmetic of \(\Lambda^M\), not universal
interpolation content.

This also answers the identity question.  In the formal coefficient
array, the variable \(c_M(0,0,0)\) occurs in every \(E_M(d_i)\), and its
coefficient in \(\mathfrak G\) is

\[
\sum_{i=0}^L\omega_i=1.
\tag{5.5}
\]

Hence

\[
\boxed{\mathfrak G_{M,d_0,L}\text{ is not an identically zero
functional in any block.}}
\tag{5.6}
\]

An exact zero for a particular triple \((M,d_0,L)\), if one occurs, is
an accidental cancellation among disjoint nonconstant shells; it is not
a finite-difference or WZ identity.

## 6. Sharp exponential height for a fixed quotient

The point of this section is to replace the crude triangle estimate by an
exact exponential-rate calculation.

Let

\[
h(u)=-u\log u-(1-u)\log(1-u)
\tag{6.1}
\]

for \(0\le u\le1\), with \(0\log0=0\).  Fix
\(\kappa=(\alpha,\beta,\gamma)\in[-a,a]^3\cap\mathbb Z^3\), put
\(d=\delta M+O(1)\), and set \(t=sM\) in (1.3).  Stirling's formula gives
the summand exponent

\[
\begin{aligned}
\Psi_\kappa(s,\delta)
={}&h(s)+h(s-\delta\alpha)\\
&+(2-s)h\!\left(\frac{1-s+\delta\beta}{2-s}\right)\\
&+(2-s)h\!\left(\frac{1-s+\delta\gamma}{2-s}\right),
\end{aligned}
\tag{6.2}
\]

on the region where all four binomial arguments are admissible.  Put

\[
\mathcal R_\kappa(\delta)
=\max_s\Psi_\kappa(s,\delta),
\tag{6.3}
\]

and

\[
\boxed{
\mathcal R_a(\delta)=
\max_{\kappa\in[-a,a]^3\cap\mathbb Z^3}
\mathcal R_\kappa(\delta).}
\tag{6.4}
\]

This is a finite, explicit variational formula.  The maximizing \(s\) for
one shell is the admissible solution of

\[
\boxed{
(1-s)(1-s+\delta\alpha)
(1-s+\delta\beta)(1-s+\delta\gamma)
=s(s-\delta\alpha)(2-s)^2.}
\tag{6.5}
\]

Thus \(\mathcal R_a\) can be computed by solving finitely many algebraic
saddle equations and comparing their values.

The elementary discrete Laplace method applied to (1.3) gives

\[
\log c_M(d\kappa)
=M\mathcal R_\kappa(\delta)+O_a(\log M),
\tag{6.6}
\]

uniformly when \(\delta\) stays in a compact subinterval of
\((1/(a+1),1/a)\).

Now assume first that \(L\) is even and \(L=O(M^{1/3})\).  In (4.2), the
coefficient extraction for a fixed \(\kappa\) has the same positive real
saddle as \([X^{d_0\kappa}]\Lambda^M\), with the slowly growing amplitude
\(W_{d_0,L}(X^{-\kappa})\).  Formula (3.3) gives

\[
W_{d_0,L}(z)>0\qquad(z>0,\ L\text{ even}).
\tag{6.7}
\]

Moreover, uniformly for positive \(z\) in a fixed compact set,

\[
\exp\{-O(L\log M)\}
\le W_{d_0,L}(z)
\le\exp\{O(L\log M)\}.
\tag{6.8}
\]

For completeness, the upper bound follows directly from (3.1)--(3.2).
For the lower bound, use the beta integral (3.3).  If \(z\) is separated
from one, integrate over a width \(M^{-1}\) interval next to \(t=1\).
If \(z=1+O(L/M)\), normalize (3.3) by the beta density
\(t^{d_0}(1-t)^L\); a beta-concentration interval of width
\(\asymp\sqrt L/M\) gives a lower bound
\(\exp\{-O(L\log L)\}\).  These two regimes cover a compact positive
set.  The same estimates hold for the finitely many derivatives needed
in the saddle expansion.

The support differences of \(\Lambda\) generate \(\mathbb Z^3\), so the
positive real saddle is aperiodic.  Standard coefficient saddle
localization, now with the subexponential amplitude (6.8), gives

\[
\log\left|
\operatorname{CT}\left(
\Lambda^M X^{-d_0\kappa}
W_{d_0,L}(X^{-\kappa})
\right)\right|
=M\mathcal R_\kappa(d_0/M)+O_a(L\log M).
\tag{6.9}
\]

The leading constant is positive because of (6.7).  Face directions are
handled by restricting to the corresponding exposed face; they have the
same exponential statement.

There are only \((2a+1)^3\) shells.  Contributions with maximal rate have
positive leading constants, so they do not cancel.  Summing (6.9) in
(4.2) proves the sharp rate

\[
\boxed{
\log \mathfrak G_{M,d_0,L}
=M\mathcal R_a(d_0/M)+O_a(L\log M),
\qquad L\text{ even}.}
\tag{6.10}
\]

In particular the carrier is positive and nonzero for all sufficiently
large \(M\) in such a fixed quotient block.

The shell \(\kappa=0\) is exactly \(b_M\).  Its rate is the usual Apéry
rate:

\[
\mathcal R_0(\delta)
=\log(17+12\sqrt2).
\tag{6.11}
\]

It is independent of \(\delta\).  Therefore

\[
\boxed{
\log \mathfrak G_{M,d_0,L}
\ge M\log(17+12\sqrt2)-O_a(L\log M).}
\tag{6.12}
\]

The total coefficient sum gives the matching linear upper scale

\[
\mathcal R_a(\delta)\le\log40,
\qquad
\log\mathfrak G_{M,d_0,L}
\le M\log40+O_a(L\log M).
\tag{6.13}
\]

Thus (6.10), not the triangle bound alone, proves that the interpolation
cancellation is only subexponential relative to the original shell
height.

### Fixed \(a=1\) and \(a=2\)

For \(a=1\),

\[
\frac12<\delta<1,
\tag{6.14}
\]

and (6.4) is a maximum over only \(27\) shell directions.  For \(a=2\),

\[
\frac13<\delta<\frac12,
\tag{6.15}
\]

and the maximum is over \(125\) directions.  In both cases, for
\(L\asymp M^{1/3}\),

\[
L\log M=o(M),
\tag{6.16}
\]

so (6.12) gives

\[
\boxed{
\log|\mathfrak G_{M,d_0,L}|=\Theta(M),
\quad a=1,2.}
\tag{6.17}
\]

Since \(M=n-a=n+O(1)\) for fixed \(a\), this is \(\Theta(n)\), whereas
\(H=n^{1/3}\).  Therefore

\[
\frac{\log|\mathfrak G_{M,d_0,L}|}{H}\longrightarrow\infty.
\tag{6.18}
\]

Adding back the question's universal factor changes the logarithm by

\[
\log L!=O(L\log L)=o(M),
\tag{6.19}
\]

and does not change the verdict.

## 7. Odd stencil length and nonvanishing

For odd \(L\), the beta integrand in (3.3) changes sign when \(z>1\), so
the leading amplitude at a nonzero shell can vanish for a special positive
saddle value.  This is the precise source of the previously noted
nonvanishing issue.

Three points are rigorous.

1. The functional is not identically zero, by (5.5).

2. A zero of \(W_{d_0,L}\) has finite order.  In a saddle expansion it can
   remove only a polynomial/subexponential prefactor; it cannot change the
   exponential rate unless leading contributions from several distinct
   shell directions satisfy an additional exact cancellation.  No such
   relation follows from the coefficient-shell algebra.

3. One can remove the parity issue without losing a single target.  Add
   one adjacent integer node and form the interpolation polynomial through
   \(L+2\) values.  The new degree is \(L+1\), which is even, and every
   original target prime still divides the new extrapolation at \(-1\).
   The extra node need not itself be prime or a target.  Formula (6.10)
   applies to this enlarged carrier.

Thus an odd full stencil might have isolated accidental zeros, but there
is no natural zero identity, and the harmless evenization gives a
provably nonzero carrier of linear height.  Odd-parity cancellation cannot
support a uniform \(o(H)\) block theorem.

If a single everywhere-nonzero integer is desired without choosing
parity, use

\[
D_{M,d_0,L}
=\mathfrak G_{M,d_0,L}^{\,2}
 +\mathfrak G_{M,d_0,L+1}^{\,2}.
\tag{7.1}
\]

Every original target divides both summands, hence divides \(D\), and the
even member is eventually nonzero.  Its logarithmic height is still
\(\Theta(M)\).

## 8. Why shorter or signed stencils cannot retain every divisor

The following formal lemma isolates the quantifier.

### Lemma 8.1: linear stencil saturation

Let \(q_0,\ldots,q_s\) be distinct primes and regard
\(Y_0,\ldots,Y_s\) as independent integer variables.  Suppose

\[
D(Y)=\sum_{j=0}^s c_jY_j
\tag{8.1}
\]

has the property that, for every \(i\),

\[
q_i\mid Y_i\quad\Longrightarrow\quad q_i\mid D(Y)
\tag{8.2}
\]

for all choices of the other variables.  Then

\[
\boxed{q_i\mid c_j\quad(i\ne j).}
\tag{8.3}
\]

Hence

\[
\prod_{i\ne j}q_i\mid c_j.
\tag{8.4}
\]

**Proof.**  Set \(Y_i=0\), set one other variable \(Y_j=1\), and set the
rest to zero.  Then (8.2) gives \(q_i\mid c_j\).  Multiply over
\(i\ne j\).  \(\square\)

The Lagrange coefficients (2.3) realize exactly this CRT pattern when
\(q_i=d_i+1>L\): modulo \(q_i\), all coefficients except \(\omega_i\)
vanish.

If a stencil omits \(Y_i\), every remaining coefficient must itself be
divisible by \(q_i\).  Thus a shorter stencil retains the omitted target
only by inserting that prime explicitly into its coefficients.  The
logarithmic cost is exactly the cost the construction was meant to avoid.

There is an analogous nonlinear statement.  If
\(P\in\mathbb Z[Y_0,\ldots,Y_s]\) satisfies (8.2), then every monomial not
containing \(Y_i\) has coefficient divisible by \(q_i\).  Equivalently,

\[
P\in(q_i,Y_i)\qquad\text{for every }i.
\tag{8.5}
\]

Therefore a nonlinear shorter stencil either

- contains every omitted \(Y_i\) in every surviving monomial, producing a
  product of tall shell values; or
- pays the omitted prime in its integer coefficient.

Sliding short finite differences and multiplying the resulting carriers
only repeats this dichotomy.  A gcd of short carriers does not retain a
prime unless every selected carrier contains its node.

This is a scoped no-go: it assumes the only input at node \(i\) is the
target congruence \(q_i\mid E_M(d_i)\).  A genuinely new relation among
the actual Apéry shell values could escape it, but the Newton stencil
itself supplies no such relation.

## 9. Independently codeable formulas

The following pseudocode uses the convention that `C(N,r)=0` outside
`0 <= r <= N`.

```text
C(N,r):
    if r < 0 or r > N: return 0
    return binomial(N,r)

coeff(M,u,v,w):
    total = 0
    for t = 0..M:
        total += C(M,t)
               * C(M,M-t+u)
               * C(2*M-t,M-t+v)
               * C(2*M-t,M-t+w)
    return total

shell(M,d):
    a = floor(M/d)
    total = 0
    for alpha = -a..a:
      for beta = -a..a:
        for gamma = -a..a:
            total += coeff(M,d*alpha,d*beta,d*gamma)
    return total

weight(d0,L,i):
    return (-1)^i
           * C(d0+i,i)
           * C(d0+L+1,L-i)

primitive_carrier(M,d0,L):
    return sum_{i=0}^L weight(d0,L,i) * shell(M,d0+i)

G(M,d0,L):
    return factorial(L) * primitive_carrier(M,d0,L)
```

The faster one-sum shell evaluation is

```text
shell(M,d):
    a = floor(M/d)
    total = 0
    for t = 0..M:
        A = sum_{alpha=-a}^a C(M,M-t+d*alpha)
        B = sum_{beta =-a}^a C(2*M-t,M-t+d*beta)
        total += C(M,t) * A * B^2
    return total
```

Regression identities are

```text
primitive_carrier(M,d0,0) = shell(M,d0)
sum_{i=0}^L weight(d0,L,i) = 1
G(M,d0,L) = factorial(L) * primitive_carrier(M,d0,L)
```

and, for every target prime `q=d0+i+1` with `q>L`,

```text
primitive_carrier(M,d0,L) % q = 0.
```

## 10. Final strategic conclusion

The fixed-moment shell synchronization is genuine: all primes in a
quotient block are testing one coefficient array \([X^\nu]\Lambda^M\),
and Newton interpolation produces one exact characteristic-zero integer
containing every target divisor.

The exact algebra nevertheless gives the wrong height.

\[
\boxed{
\text{primitive Newton carrier}
=F(-1),
\qquad
\log|F(-1)|=\Theta(n)
\text{ for fixed }a=1,2.}
\tag{10.1}
\]

The universal \(L!\) can be removed completely, but the remaining
integer still has the exponential rate (6.10).  The cancellation created
by the alternating stencil is only \(\exp(o(n))\) relative to the shell
coefficients; it is nowhere near the \(\exp(o(H))\) required by P3.2.

The next viable use of the fixed-moment model must therefore be genuinely
local in the prime spacing—such as a two-characteristic identity for
\(E_M(d)\) and \(E_M(d+h)\) with height
\(O(h\,\operatorname{polylog}n)\)—rather than full-block extrapolation
from \(d\) all the way to \(-1\).  No signed or shorter Newton stencil can
supply that identity by itself.
