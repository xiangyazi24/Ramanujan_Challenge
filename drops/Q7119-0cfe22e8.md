\[
N_h(-x-h-1)=(-1)^{h-1}N_h(x).

\[
L_h(x):=2x+h+1\mid N_h(x),\qquad
N_h^{\circ}(x)=N_h(x)/L_h(x),

The restart identity used below is the exact specialization of the continuant addition law:

\[
N_e(x_0)=0

N_{e+d}(x_0)=N_{e+1}(x_0)N_d(x_0+e).
\tag{8}

No two consecutive Apéry numbers vanish modulo \(p\), so \(b_{m+1}\ne0\).  Since every denominator in (9) is a unit when \(m+j<p\),

## 4. Why reflection does not rule out the example

Indeed its ordered gaps are

\[

\[

This pinpoints the logical failure in the proposed proof route:

Once a reflection fiber has at least eight visits, outer four-windows are possible.  The current restart and reflection identities do not prohibit them.

## 5. Correct replacement lemma and the missing hypothesis

The strongest unconditional statement furnished by the verified identities is the following.

### Lemma (primitive zero-window translation)

Let \(p>H\), let \(m+s<p\), and suppose

\[
m=z_0<z_1<z_2<z_3=m+s
\]

are four consecutive Apéry-zero indices modulo \(p\).  Put

\[
a=z_1-z_0,\qquad b=z_2-z_1,\qquad c=z_3-z_2.
\]

Then

\[
N_a(z_0)=N_b(z_1)=N_c(z_2)=0,
\]

and

\[
\{j:1\le j\le s,\ N_j(z_0)=0\}=\{a,a+b,s\}.
\]

If none of the selected adjacent pairs satisfies \(z_i+z_{i+1}=p-1\), then every selected even-gap center factor is a unit, and therefore

\[
N_a^{\circ}(z_0)=N_b^{\circ}(z_1)=N_c^{\circ}(z_2)=0.
\]

#### Proof

The first two assertions are (9)--(10) and restart (8).  For an even selected gap \(h=z_{i+1}-z_i\), its center factor vanishes exactly when

\[
2z_i+h+1=z_i+z_{i+1}+1=0\pmod p,
\]

i.e. exactly when \(z_i+z_{i+1}=p-1\).  If this does not occur, division by \(L_h(z_i)\) is legitimate and the raw root remains a root of \(N_h^{\circ}\).  ∎

This lemma proves that the proposed theorem is not a consequence of restart plus reflection: those identities translate an outer consecutive-zero window directly into a fully deflated primitive triple root.

### What must be added

The intended reflection argument requires a **central-window hypothesis**, not merely primitive consecutiveness.  A minimal local form is

\[
\exists i\in\{0,1,2\}:\quad z_i+z_{i+1}=p-1.
\tag{CW}
\]

To make central deflation itself a contradiction, one also needs the corresponding center to be simple after removal of the forced factor:

\[
N_{h_i}^{\circ}(z_i)\ne0,\qquad h_i=z_{i+1}-z_i.
\tag{CS}
\]

Condition (CS) can be imposed by proving that its exceptional primes are already supported on \(\mathfrak U_H\), or, absent such a theorem, by enlarging the carrier explicitly to

\[
\mathfrak U_H^{\mathrm{cent}}
=\mathfrak U_H
\prod_{\substack{2\le h\le H\\h\text{ even}}}
\operatorname{num}
\left(
N_h^{\circ}\!\left(-\frac{h+1}{2}\right)
\right).
\tag{13}
\]

Under (CW), (CS), and \(p\nmid\mathfrak U_H^{\mathrm{cent}}\), one selected deflated equation is nonzero, so the triple intersection is impossible.

A convenient global sufficient condition for (CW) is: the relevant reflection fiber is even and has at most six visits in the full block.  In particular, for the actual Apéry zero fiber, ordinary \(Z(p)\le6\) forces every block of four consecutive zeros to contain the central adjacent pair.  The counterexample has \(Z(28933)=8\), exactly the first combinatorial regime in which an outer four-window can occur.

Thus the corrected strategic conclusion is:

\[
\boxed{
\text{primitive consecutiveness alone is insufficient; one needs
central-window/low-fiber control, plus central simplicity.}}
\]

Neither condition follows from the verified continuant, restart, reflection, or current structural-carrier identities.

a, b, c = 3074, 1166, 253

def P(n):
    return (34*n**3 + 51*n**2 + 27*n + 5) % p

# beta_n=(n!)^3 b_n.  Since n<p, beta_n=0 iff b_n=0.
beta = [1, 5]
for n in range(1, p - 1):
    beta.append((P(n)*beta[n] - pow(n, 6, p)*beta[n-1]) % p)

zeros = [n for n, value in enumerate(beta) if value == 0]
assert zeros == [
    7602, 10676, 11842, 12095,
    16837, 17090, 18256, 21330,

            (P(x+h)*values[h]
             - pow((x+h) % p, 6, p)*values[h-1]) % p

    return values

at_r = N_values(r, s)
assert [j for j in range(1, s + 1) if at_r[j] == 0] == [
    a, a+b, s,

assert all(beta[j] != 0 for j in range(1, H + 1))

assert all(V[j+1] != 0 for j in range(1, H + 1))
