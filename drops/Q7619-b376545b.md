# Hostile audit: exact Smith theorem for the Apéry Picard–Fuchs prefix

## Verdict

The proposed theorem is **almost correct for the actual Apéry prefix, but not under the hypotheses as stated**. The missing hypothesis is integrality/primitivity of the coefficient prefix \(h^{(N)}=(h_0,\dots,h_N)\).

From only

\[
\sum_{\ell=0}^{10}K_\ell(m)h_{m-\ell}=0,\qquad h_{<0}=0,\qquad K_0(m)=m^5,\qquad h_0=1,
\]

with \(K_\ell(m)\in\mathbb Z\), one gets unconditionally:

1. the column-0-deleted minor is exactly \(d_N:=(N!)^5\);
2. \(R_N\) has rank \(N\) over \(\mathbb Q\);
3. \(\ker_{\mathbb Q}R_N=\mathbb Q h^{(N)}\);
4. the signed maximal minors satisfy the **exact orientation formula**
   \[
   (-1)^k\det R_N^{(k)}=d_Nh_k;
   \]
5. \(\operatorname{Sat}(\operatorname{row}_{\mathbb Z}R_N)=\{\lambda\in\mathbb Z^{N+1}:\lambda\cdot h^{(N)}=0\}\);
6. for an integer selector row \(\ell\), appended after the \(N\) recurrence rows,
   \[
   \det\binom{R_N}{\ell}=(-1)^N d_N(\ell\cdot h^{(N)}).
   \]

What does **not** follow from \(h_0=1\) alone is

\[
\gcd\{\text{maximal minors of }R_N\}=d_N.
\]

If the prefix \(h^{(N)}\) is rational rather than integral, let \(D_N\) be its least common denominator. Then the exact formula is

\[
\boxed{
\gcd\{\text{maximal minors of }R_N\}=\frac{(N!)^5}{D_N}.
}
\]

Thus the claimed gcd is exactly \((N!)^5\) **iff** \(h_0,\dots,h_N\in\mathbb Z\). Since \(h_0=1\), integrality then also gives primitivity automatically.

For the actual Apéry selector family, there is a clean way to supply this missing hypothesis. If

\[
\tau_{r,k}=[q^{r-k}]A(q)^{r-k},\qquad 0\le k\le r,
\]

with \(A(q)\in\mathbb Z[[q]]\), and the exact identities

\[
\tau_r\cdot h^{(r)}=b_r\in\mathbb Z
\]

hold for **every** \(0\le r\le N\), then the matrix

\[
T_N=(\tau_{r,k})_{0\le r,k\le N},\qquad \tau_{r,k}=0\ (k>r),
\]

is unit lower triangular over \(\mathbb Z\), because

\[
\tau_{r,r}=[q^0]A(q)^0=1.
\]

Hence \(T_N\in\mathrm{GL}_{N+1}(\mathbb Z)\). From

\[
(b_0,\dots,b_N)^T=T_N(h_0,\dots,h_N)^T
\]

and \(b_r\in\mathbb Z\), it follows that \(h_0,\dots,h_N\in\mathbb Z\). Under that actual selector bridge, the proposed gcd and primitive-quotient statements are therefore restored exactly.

The multi-selector claim also needs one wording correction: it is literally a gcd statement only **after saturation**. If one stacks several selectors directly on the unsaturated recurrence lattice, minors involving two or more selector rows can partially kill the old Smith defect. The correct invariant is the image ideal in the rank-one saturated quotient.

# 1. Exact matrix and the negative-index boundary

Write

\[
h^{(N)}=(h_0,h_1,\dots,h_N)^T.
\]

For \(1\le m\le N\) and \(0\le j\le N\), the recurrence row has coefficient

\[
(R_N)_{m,j}=
\begin{cases}
K_{m-j}(m),&0\le m-j\le 10,\\
0,&\text{otherwise}.
\end{cases}
\tag{1}
\]

This is exactly where the convention \(h_n=0\) for \(n<0\) enters. For \(m<10\), terms with \(\ell>m\) are genuinely zero and produce no hidden columns or inhomogeneous term. Thus row \(m\) has support only on

\[
\max(0,m-10)\le j\le m.
\]

In particular there are **no entries in columns \(j>m\)**.

This boundary is essential. If the negative coefficients were prescribed nonzero values instead of zero, the first rows would be inhomogeneous and \(R_Nh^{(N)}=0\) would no longer be the correct homogeneous presentation without adjoining extra coordinates.

Because all \(K_\ell(m)\) are integers at integer \(m\), \(R_N\) is an integer matrix.

The recurrence gives immediately

\[
R_N h^{(N)}=0.
\tag{2}
\]

Also, because \(K_0(m)=m^5\ne0\) for \(m\ge1\), the recurrence determines \(h_m\) recursively from earlier coefficients. Starting from \(h_0=1\), this already implies \(h_m\in\mathbb Q\), although not necessarily \(h_m\in\mathbb Z\).

# 2. Claim (a): exact triangular minor

Let \(R_N^{(0)}\) denote the \(N\times N\) matrix obtained by deleting column \(0\), retaining rows \(1,\dots,N\) and columns \(1,\dots,N\) in increasing order.

For a row \(m\) and a retained column \(j>m\), (1) gives zero. Therefore \(R_N^{(0)}\) is lower triangular.

Its diagonal entry in row \(m\), column \(j=m\), is

\[
K_{m-m}(m)=K_0(m)=m^5.
\]

Hence, with the natural row/column order,

\[
\boxed{
\det R_N^{(0)}=\prod_{m=1}^N m^5=(N!)^5=:d_N>0.
}
\tag{3}
\]

So **claim (a) is exactly correct**, including the positive sign. The order-10 bandwidth is irrelevant to this determinant except for guaranteeing finite support; triangularity uses only the one-sided recurrence and \(K_0(m)=m^5\).

# 3. Rank and rational kernel

Since (3) is nonzero,

\[
\operatorname{rank}_{\mathbb Q}R_N=N.
\tag{4}
\]

An \(N\times(N+1)\) rank-\(N\) matrix has one-dimensional rational kernel. Equation (2) supplies a nonzero kernel vector because \(h_0=1\). Therefore

\[
\boxed{
\ker_{\mathbb Q}R_N=\mathbb Q\,h^{(N)}.
}
\tag{5}
\]

This part of claim (b) is unconditional.

# 4. Exact signs of all maximal minors

For \(0\le k\le N\), let \(R_N^{(k)}\) be the \(N\times N\) matrix obtained by deleting column \(k\), keeping all remaining columns in increasing order. Define the signed cofactor vector

\[
\Delta=(\Delta_0,\dots,\Delta_N),\qquad
\Delta_k:=(-1)^k\det R_N^{(k)}.
\tag{6}
\]

The standard cofactor identity for an \(N\times(N+1)\) matrix gives

\[
R_N\Delta^T=0.
\tag{7}
\]

A quick sign calibration is useful: for a \(1\times2\) row \((a,b)\), (6) gives \((b,-a)\), which is indeed a kernel vector. Thus there is no hidden index shift in (6).

By (5), \(\Delta=c_Nh^{(N)}\) for some \(c_N\in\mathbb Q\). At \(k=0\),

\[
\Delta_0=\det R_N^{(0)}=d_N,
\]

while \(h_0=1\). Therefore \(c_N=d_N\), and

\[
\boxed{
\Delta_k=d_Nh_k,
\qquad
\det R_N^{(k)}=(-1)^k d_Nh_k.
}
\tag{8}
\]

This is stronger and cleaner than “a common orientation times \((N!)^5h_k\)”: with the stated natural ordering the sign is exactly \((-1)^k\). If one globally permutes recurrence rows, every maximal minor acquires the same extra orientation sign, but there is no \(k\)-dependent ambiguity beyond \((-1)^k\).

A useful arithmetic consequence of (8) is that

\[
d_Nh_k\in\mathbb Z\qquad(0\le k\le N),
\tag{9}
\]

because every maximal minor is integral. Thus every denominator occurring in the prefix divides the factorial Smith scale in aggregate.

# 5. The proposed gcd of maximal minors needs an integrality hypothesis

This is the one false step in claim (b) as stated.

Let \(D_N\) be the least positive integer such that

\[
u^{(N)}:=D_Nh^{(N)}\in\mathbb Z^{N+1}.
\tag{10}
\]

Because \(h_0=1\), the first coordinate of \(u^{(N)}\) is \(D_N\). Minimality of \(D_N\) implies that \(u^{(N)}\) is primitive:

\[
\gcd(u_0,\dots,u_N)=1.
\tag{11}
\]

Equation (8) becomes

\[
\Delta=\frac{d_N}{D_N}u^{(N)}.
\tag{12}
\]

Since \(\Delta\in\mathbb Z^{N+1}\) and \(u^{(N)}\) is primitive, (12) forces

\[
D_N\mid d_N.
\tag{13}
\]

Taking the gcd of the coordinates of (12), equivalently the gcd of all maximal minors, yields

\[
\boxed{
\delta_N:=\gcd_{0\le k\le N}\left|\det R_N^{(k)}\right|
=\frac{d_N}{D_N}
=\frac{(N!)^5}{D_N}.
}
\tag{14}
\]

Thus

\[
\boxed{
\delta_N=(N!)^5
\iff
D_N=1
\iff
h_0,\dots,h_N\in\mathbb Z.
}
\tag{15}
\]

Since \(h_0=1\), an integral prefix is automatically primitive.

## Minimal counterexample to the unstated inference

The error cannot be repaired by saying “but \(h_0=1\)”. Consider an integer-coefficient recurrence with

\[
K_0(m)=m^5,\qquad K_1(m)=2m-3,\qquad K_\ell(m)=0\quad(\ell\ge2),
\]

and \(h_0=1\). Then

\[
h_1=1,\qquad h_2=-\frac1{32}.
\]

For \(N=2\),

\[
R_2=
\begin{pmatrix}
-1&1&0\\
0&1&32
\end{pmatrix}.
\]

Deleting column \(0\) gives determinant \(32=(2!)^5\), but the three maximal minors have absolute values

\[
32,\ 32,\ 1,
\]

so their gcd is \(1\), not \(32\). Formula (14) gives exactly the right answer because \(D_2=32\).

Therefore the original theorem **must explicitly add integrality of \(h\)**, or use the denominator-corrected form (14).

# 6. Saturation of the recurrence row lattice

Let

\[
L_N:=\operatorname{row}_{\mathbb Z}(R_N)\subset\mathbb Z^{N+1}.
\]

Use the standard lattice saturation

\[
\operatorname{Sat}(L_N)
:=\{x\in\mathbb Z^{N+1}:\exists a\ge1,\ ax\in L_N\}
=\operatorname{span}_{\mathbb Q}(L_N)\cap\mathbb Z^{N+1}.
\tag{16}
\]

By (4), the rational row space has dimension \(N\). Every row is orthogonal to \(h^{(N)}\) by (2), so

\[
\operatorname{span}_{\mathbb Q}(L_N)
\subseteq
\{x\in\mathbb Q^{N+1}:x\cdot h^{(N)}=0\}.
\]

Both spaces have dimension \(N\), hence they are equal. Intersecting with \(\mathbb Z^{N+1}\) gives

\[
\boxed{
\operatorname{Sat}(L_N)
=
\{\lambda\in\mathbb Z^{N+1}:\lambda\cdot h^{(N)}=0\}.
}
\tag{17}
\]

This equality is valid even when \(h^{(N)}\) is merely rational. Equivalently, with the primitive integer vector \(u^{(N)}=D_Nh^{(N)}\),

\[
\operatorname{Sat}(L_N)=\{\lambda\in\mathbb Z^{N+1}:\lambda\cdot u^{(N)}=0\}.
\tag{18}
\]

For a rank-\(N\) sublattice of \(\mathbb Z^{N+1}\), the gcd of its \(N\times N\) minors is the index in its saturation. Consequently

\[
\boxed{
[\operatorname{Sat}(L_N):L_N]
=\delta_N
=\frac{(N!)^5}{D_N}.
}
\tag{19}
\]

Under the additional actual-prefix integrality hypothesis, \(D_N=1\) and this becomes

\[
[\operatorname{Sat}(L_N):L_N]=(N!)^5.
\tag{20}
\]

So the saturation part of claim (b) is correct; the claimed exact Smith content is correct only after the missing integrality is supplied.

# 7. Claim (c): exact selector determinant and exact sign

Let

\[
\ell=(\ell_0,\dots,\ell_N)\in\mathbb Z^{N+1}
\]

and append it as the **last row** below \(R_N\). Expanding the resulting \((N+1)\times(N+1)\) determinant along that last row gives

\[
\det\binom{R_N}{\ell}
=
\sum_{k=0}^N
(-1)^{(N+1)+(k+1)}\ell_k\det R_N^{(k)}.
\]

Thus

\[
\det\binom{R_N}{\ell}
=
\sum_{k=0}^N(-1)^{N+k}\ell_k\det R_N^{(k)}.
\]

Using (8),

\[
\det\binom{R_N}{\ell}
=
\sum_{k=0}^N(-1)^{N+k}\ell_k(-1)^kd_Nh_k
=(-1)^Nd_N\sum_{k=0}^N\ell_kh_k.
\]

Therefore

\[
\boxed{
\det\binom{R_N}{\ell}
=(-1)^N(N!)^5(\ell\cdot h^{(N)}).
}
\tag{21}
\]

So claim (c) is correct, and the sign can be made exact. This formula does **not** require \(h_k\in\mathbb Z\); integrality of the determinant simply says \(d_N(\ell\cdot h)\in\mathbb Z\).

If the selector row is inserted elsewhere, or the recurrence rows/columns are permuted, multiply (21) by the corresponding global permutation sign.

# 8. Exact multi-selector theorem after saturation

This is the correct formulation of claim (d).

First assume the actual integral case:

\[
h^{(N)}\in\mathbb Z^{N+1},\qquad h_0=1.
\tag{22}
\]

Then \(h^{(N)}\) is primitive. Let

\[
S_N:=\operatorname{Sat}(L_N)=h^{(N)\perp}\cap\mathbb Z^{N+1}.
\]

Define

\[
\phi:\mathbb Z^{N+1}\longrightarrow\mathbb Z,
\qquad
\phi(x)=x\cdot h^{(N)}.
\tag{23}
\]

Because \(h_0=1\), \(\phi(e_0)=1\), so \(\phi\) is surjective. Equation (17) says \(\ker\phi=S_N\). Hence

\[
\boxed{
\mathbb Z^{N+1}/S_N\cong\mathbb Z,
\quad [x]\longmapsto x\cdot h^{(N)}.
}
\tag{24}
\]

Now take integer selector rows

\[
\ell_1,\dots,\ell_s\in\mathbb Z^{N+1}
\]

and put

\[
a_i:=\ell_i\cdot h^{(N)}\in\mathbb Z.
\tag{25}
\]

Their images in the rank-one quotient generate the subgroup

\[
\boxed{
(a_1,\dots,a_s)
=
\gcd(a_1,\dots,a_s)\,\mathbb Z
\subseteq\mathbb Z.
}
\tag{26}
\]

Here the ideal notation is literal. Set

\[
M:=S_N+\sum_{i=1}^s\mathbb Z\ell_i.
\tag{27}
\]

If not all \(a_i\) vanish and

\[
g:=\gcd(a_1,\dots,a_s)>0,
\]

then \(M\) has full rank \(N+1\) and

\[
\boxed{
\mathbb Z^{N+1}/M\cong\mathbb Z/g\mathbb Z,
\qquad
[\mathbb Z^{N+1}:M]=g.
}
\tag{28}
\]

Equivalently: choose any \(\mathbb Z\)-basis of the saturated recurrence lattice \(S_N\), stack the selector rows beneath it, and take the gcd of all full-rank \((N+1)\times(N+1)\) minors. That top determinantal divisor is exactly

\[
\boxed{\gcd(a_1,\dots,a_s).}
\tag{29}
\]

One direct proof is to choose \(e_0\) as a complement to \(S_N\), since \(e_0\cdot h=1\). In the resulting unimodular coordinate system the saturated rows are \((I_N\ 0)\); subtracting their integer components from each selector turns selector \(i\) into \((0,\dots,0,a_i)\). Every nonzero full-size minor is then, up to sign, one of the \(a_i\), so their gcd is (29).

If every \(a_i=0\), then all selectors already lie in \(S_N\), \(M=S_N\) has rank \(N\), and the quotient remains infinite cyclic. In this case the full-size determinantal divisor is \(0\); it should not be described as a finite Smith index.

## Rational-prefix version

If \(h^{(N)}\) is not integral, use the primitive integer kernel generator

\[
u^{(N)}=D_Nh^{(N)}.
\]

Then the canonical integral quotient map is

\[
\phi_u(x)=x\cdot u^{(N)}.
\]

The selector ideal is therefore

\[
\boxed{
(\ell_1\cdot u^{(N)},\dots,\ell_s\cdot u^{(N)})
=D_N(\ell_1\cdot h^{(N)},\dots,\ell_s\cdot h^{(N)}).
}
\tag{30}
\]

So the literal ideal \((\ell_i\cdot h)\subset\mathbb Z\) only makes sense without scaling when the prefix is primitive integral.

# 9. Why this is intersection/gcd, not union coverage

Modulo a prime \(p\), (26) gives

\[
p\mid g
\iff
p\mid a_i\quad\text{for every }i.
\tag{31}
\]

Thus stacking several selectors on the **same saturated rank-\(N\) recurrence lattice** detects simultaneous vanishing of all their quotient coordinates. It detects the intersection

\[
\{p:p\mid a_1\}\cap\cdots\cap\{p:p\mid a_s\},
\]

not the union

\[
\{p:p\mid a_1\}\cup\cdots\cup\{p:p\mid a_s\}.
\]

This is not a weakness in the Smith calculation; it is exactly what addition of generators in a rank-one quotient does. The image subgroup generated by \(a_1,\dots,a_s\) is their gcd ideal. An OR/union condition is multiplicative in nature (for nonzero integers, \(p\mid\prod_i a_i\) iff \(p\mid a_i\) for at least one \(i\)); it is not represented by the additive image ideal of the stacked selector lattice.

So the slogan in claim (d) is correct once stated precisely:

> **Saturated multi-selector Smith content is a gcd/common-divisor invariant. It tests intersection, not union coverage.**

# 10. Important caveat: several selectors on the raw, unsaturated recurrence lattice

The phrase “after saturation” is essential.

Let

\[
L=L_N,\qquad S=\operatorname{Sat}(L),\qquad
E=\sum_i\mathbb Z\ell_i,
\]

and assume the integral primitive case. Let

\[
g=\gcd(\ell_1\cdot h,\dots,\ell_s\cdot h)\ne0.
\]

The saturated enlarged lattice is

\[
S+E,
\]

and by (28)

\[
[\mathbb Z^{N+1}:S+E]=|g|.
\tag{32}
\]

But the raw enlarged lattice is

\[
L+E\subseteq S+E.
\]

Its full-rank Smith content is

\[
[\mathbb Z^{N+1}:L+E]
=
|g|\,[S+E:L+E].
\tag{33}
\]

By the second isomorphism theorem,

\[
[S+E:L+E]
=
[S:S\cap(L+E)].
\tag{34}
\]

Since

\[
L\subseteq S\cap(L+E)\subseteq S,
\]

the second factor divides the old Smith defect

\[
[S:L]=d_N
\]

in the integral case. Thus

\[
\boxed{
[\mathbb Z^{N+1}:L+E]
=|g|\,c,
\qquad c\mid d_N.
}
\tag{35}
\]

For **one** selector with \(a=\ell\cdot h\ne0\), there is no nonzero multiple of \(\ell\) that falls back into \(S\): if \(x+n\ell\in S\) with \(x\in L\subseteq S\), then \(na=0\), hence \(n=0\). Therefore

\[
S\cap(L+\mathbb Z\ell)=L,
\]

so \(c=d_N\) and (35) reduces exactly to the one-selector determinant formula

\[
|\det(R_N;\ell)|=d_N|a|.
\]

With **two or more** selectors, however, a nontrivial relation

\[
\sum_i n_i(\ell_i\cdot h)=0
\]

can produce a selector combination \(\sum_i n_i\ell_i\in S\) that is not already in \(L\). Such combinations enlarge \(S\cap(L+E)\) and can reduce \(c\). Consequently:

\[
\boxed{
\text{The gcd of full-size minors of the raw stacked matrix need not equal }
 d_N\gcd_i(\ell_i\cdot h).
}
\tag{36}
\]

This is the exact reason to formulate the multi-selector theorem in the saturated quotient rather than by extrapolating the one-selector determinant identity.

# 11. The actual Apéry selector

For \(N=r\), let

\[
\tau_r=(\tau_{r,0},\dots,\tau_{r,r}),
\qquad
\tau_{r,k}=[q^{r-k}]A(q)^{r-k}.
\tag{37}

Assume the exact coefficient bridge from the actual Apéry construction:

\[
\boxed{
\tau_r\cdot h^{(r)}=b_r.
}
\tag{38}
\]

Then (21) gives immediately

\[
\boxed{
\det\binom{R_r}{\tau_r}
=(-1)^r(r!)^5b_r.

\tag{39}

Thus the sign is again exact for the natural convention: recurrence rows \(1,\dots,r\), selector appended last, columns \(h_0,\dots,h_r\).

The Smith argument itself does not prove (38); (38) is the selector/Picard–Fuchs coefficient identity that must be established where \(A(q)\) and \(W\) are defined. Once (38) is available, (39) is a formal determinant consequence with no further analytic or recurrence input.

# 12. Exact target-prime valuation for \(r<p\)

Let \(p\) be a prime and \(0\le r<p\). From (39),

\[
v_p\!\left(\det\binom{R_r}{\tau_r}\right)
=5v_p(r!)+v_p(b_r).
\tag{40}
\]

Since \(r<p\),

\[
v_p(r!)=0.
\]

Therefore

\[
\boxed{
 v_p\!\left(\det\binom{R_r}{\tau_r}\right)=v_p(b_r).
}
\tag{41}
\]

This assertion is exactly correct, with no hidden contribution from the recurrence lattice.

There is also a useful mod-\(p\) formulation. Because \(r<p\), the triangular minor

\[
(r!)^5
\]

is a \(p\)-adic unit. Hence

\[
\operatorname{rank}_{\mathbb F_p}(R_r)=r.
\]

Consequently

\[
\boxed{
 p\mid b_r
 \iff
 \operatorname{rank}_{\mathbb F_p}
 \binom{R_r}{\tau_r}<r+1.
}
\tag{42}
\]

So at a target prime larger than the index, the augmented Smith determinant sees precisely the Apéry divisibility and nothing from the factorial presentation defect.

If \(p\le r\), the equality in (41) is false in general; the correct formula remains (40), with the unavoidable extra term \(5v_p(r!)\).

# 13. Corrected theorem, ready to quote

Here is the strongest clean theorem supported by the stated recurrence.

## Theorem (prefix Smith/cofactor theorem)

Let \(N\ge1\). Suppose \(h_0=1\), \(h_n=0\) for \(n<0\), and

\[
\sum_{\ell=0}^{10}K_\ell(m)h_{m-\ell}=0
\qquad(m\ge1),
\]

where \(K_\ell(m)\in\mathbb Z\) at integer \(m\) and \(K_0(m)=m^5\). Let \(R_N\in M_{N,N+1}(\mathbb Z)\) be the matrix of the equations \(m=1,\dots,N\) on the coordinates \(h_0,\dots,h_N\), and put \(d_N=(N!)^5\).

Then:

1. \(R_N^{(0)}\) is lower triangular with diagonal \(1^5,\dots,N^5\), so
   \[
   \det R_N^{(0)}=d_N.
   \]

2. \(\operatorname{rank}_{\mathbb Q}R_N=N\) and
   \[
   \ker_{\mathbb Q}R_N=\mathbb Qh^{(N)}.
   \]

3. For every \(0\le k\le N\), with \(R_N^{(k)}\) obtained by deleting column \(k\) in the natural order,
   \[
   \det R_N^{(k)}=(-1)^kd_Nh_k.
   \]

4. If \(D_N\) is the least positive common denominator of \(h_0,\dots,h_N\), then \(D_N\mid d_N\) and
   \[
   \gcd_k|\det R_N^{(k)}|=d_N/D_N.
   \]

5. If \(L_N=\operatorname{row}_{\mathbb Z}(R_N)\), then
   \[
   \operatorname{Sat}(L_N)
   =\{\lambda\in\mathbb Z^{N+1}:\lambda\cdot h^{(N)}=0\},
   \]
   and
   \[
   [\operatorname{Sat}(L_N):L_N]=d_N/D_N.
   \]

6. For every \(\ell\in\mathbb Z^{N+1}\), appended as the last row,
   \[
   \det\binom{R_N}{\ell}=(-1)^Nd_N(\ell\cdot h^{(N)}).
   \]

If in addition \(h^{(N)}\in\mathbb Z^{N+1}\) — equivalently \(D_N=1\) — then \(h^{(N)}\) is primitive, the maximal-minor gcd and saturation index are exactly \(d_N\), and the quotient

\[
\mathbb Z^{N+1}/\operatorname{Sat}(L_N)
\]

is canonically \(\mathbb Z\) via \(x\mapsto x\cdot h^{(N)}\).

For integer selectors \(\ell_1,\dots,\ell_s\), their images in this quotient generate exactly

\[
(\ell_1\cdot h^{(N)},\dots,\ell_s\cdot h^{(N)})\subset\mathbb Z.
\]

If these pairings are not all zero, the top determinantal divisor after replacing \(L_N\) by its saturation is their gcd. Hence a prime divides that Smith content iff it divides **every** selector pairing.

Finally, if the actual Apéry selector satisfies \(\tau_r\cdot h^{(r)}=b_r\), then

\[
\det\binom{R_r}{\tau_r}=(-1)^r(r!)^5b_r,
\]

and for every prime \(p>r\),

\[
v_p\!\left(\det\binom{R_r}{\tau_r}\right)=v_p(b_r).
\]

- **(b), signed minors: PASS, with explicit sign** \(\det R_N^{(k)}=(-1)^k(N!)^5h_k\).
- **(b), gcd maximal minors \(=(N!)^5\): NEEDS HYPOTHESIS.** As stated it is false. Exact general value is \((N!)^5/D_N\). It becomes the claimed value when the actual prefix is integral. The full unitriangular selector family is sufficient to prove that integrality if \(A(q)\in\mathbb Z[[q]]\) and \(\tau_s\cdot h=b_s\) holds for all \(s\le N\).
- **(b), saturation hyperplane: PASS exactly**, even for rational \(h\).
- **(c): PASS, with exact sign** \((-1)^N\) when the selector is appended last.
- **(d): PASS only in the saturated quotient formulation.** The generated ideal is the gcd ideal, so it detects common divisibility/intersection. Do not extrapolate a one-selector raw determinant formula to several unsaturated selector rows.
- **Apéry selector determinant: PASS conditional only on the exact coefficient bridge** \(\tau_r\cdot h=b_r\); then the determinant is \((-1)^r(r!)^5b_r\).
- **Target valuation for \(r<p\): PASS exactly.** The factorial is a \(p\)-unit, hence the determinant valuation is precisely \(v_p(b_r)\).

The theorem therefore gives a very clean local detector for one target Apéry value, but it also proves the structural limitation of the multi-selector use: once the recurrence row lattice is saturated, stacking selectors performs **addition in one free rank-one quotient**, and addition produces a gcd. It cannot turn several target conditions into union coverage.
