# Cold algebra audit of the first normalized Apéry block

## 1. Block decomposition and the common p-content

Write
\[
m=cp+u,\qquad 1\le u<p.
\]
The transfer matrix is
\[
S_n=\begin{pmatrix}P(n)&-n^3\\(n+1)^3&0\end{pmatrix},
\]
with determinant
\[
\det S_n=n^6.
\]
For the segment
\[
T=S_{m-1}\cdots S_u,
\]
separate it into the initial partial block and c complete p-blocks. The periodicity of P modulo p and the standard Apéry block congruence give
\[
Q_q=S_{(q+1)p-1}\cdots S_{qp}\equiv 0\pmod {p^3},
\]
with the sharper normalized statement
\[
\frac{Q_q}{p^3}\equiv -S_q\pmod p.
\]
Hence each complete block contributes exactly three powers of p, and the whole segment has common content
\[
p^{3c}.
\]
After division by this content, the first normalized transfer is therefore
\[
 p^{-3c}T\equiv (-1)^c S_cS_{u-1}\cdots S_0^{-1}S_u\cdots S_{u-1}\pmod p,
\]
which is more naturally written using the state basis at u as
\[
\widetilde T_c(u)=(-S_c)(-S_{c-1})\cdots(-S_1)M_u,
\]
where M_u is the residual based monodromy of the first digit. The important point is that the c-dependence enters through the normalized block product; it is not removed by Lucas alone.

## 2. Root case and E21 shape

At an Apéry root
\[
B_u\equiv0\pmod p,
\]
the canonical state vector becomes a one-dimensional invariant line. In the adapted basis the based monodromy has the form
\[
M_u=\alpha_u E_{21},\qquad \alpha_u\ne0\pmod p.
\]
Thus
\[
M_u\binom{B_u}{*}=0
\]
mod p. This is the annihilation statement.

However this only says that the first layer kills the canonical root state. It does not say that the next layer is selective among all c.

The first normalized coefficient is controlled by
\[
(-S_c)E_{21}.
\]
Since
\[
S_cE_{21}=\begin{pmatrix} -c^3&0\\0&0\end{pmatrix},
\]
the image depends on c^3 and on the remaining state coordinate. Therefore the first layer retains c-information, but it is not a pure root indicator.

The unjustified jump would be:

> B_u=0 mod p implies p^2|B_{cp+u} exactly for one prescribed first-digit condition on c.

The matrix calculation only gives a linear condition on the normalized jet.

## 3. The H_c=0 exceptional layer

Let
\[
H_0=0,
\quad H_1=1,
\quad H_{n+1}=P(n)H_n-n^6H_{n-1}.
\]
The relevant normalized coefficient can vanish when
\[
H_c\equiv0\pmod p.
\]
This is an additional source of p-adic cancellation unrelated to whether c is a root index.

For c=2,
\[
H_2=P(1)=117\equiv5\pmod p.
\]
Hence the exceptional H_c mechanism does not occur for c=2 except at primes dividing 5 (excluded here). In particular at p=13,
\[
H_2\equiv5\not\equiv0\pmod{13}.
\]
So c=2,p=13 is a regular first-layer case; any extra divisibility must come from the u-dependent jet, not H_2.

## 4. The p=19,c=13,u=8 example

The data
\[
B_{13}\equiv10\pmod{19},
\]
while
\[
B_{255}\equiv0\pmod{19^2}
\]
with
\[
255=13\cdot19+8
\]
shows that a criterion depending only on the first digit c, or only on whether B_c vanishes, cannot characterize second-layer regularity.

It does not contradict the block formula. The first jet contains both:

1. a c-dependent transfer factor;
2. a u-dependent extension coefficient.

The vanishing of the product can occur because the second factor vanishes. Thus the first digit c=13 not being a root is irrelevant.

The correct interpretation is:
\[
\frac{B_{cp+u}}p\pmod p
\]
at a root u is a mixed first jet. It is not generally a function of c alone times a fixed root selector.

## 5. Consequence for shell-triple coupling

For three shell primes, first jets may couple conditions only through the actual linear congruence supplied by each prime's normalized transfer. They do not collapse to independent conditions on the quotients c_i.

A valid coupling argument must track
\[
(c_i,u_i,\alpha_{u_i},H_{c_i})
\]
for each prime. Replacing these by a statement of the form
\[
B_{c_ip_i+u_i}/p_i = f(c_i)g(u_i)
\]
requires a theorem not supplied by the block congruence.

## Conclusion

The block calculation proves the p^3 common content and identifies the root monodromy as an E21-type first-order annihilator. It does not prove target selectivity by the first digit. The H_c=0 locus and the u-dependent first jet are genuine exceptional mechanisms. The example (p,c,u)=(19,13,8) is evidence against any characterization based only on c or B_c; it is not a contradiction of the normalized monodromy formula itself.
