# Kloosterman Mellin transforms, Stickelberger slopes, and Apéry zeros

## Executive conclusion

There is no contradiction between a nonzero characteristic-zero Mellin value and zero reduction modulo a prime above p. A nontrivial Gauss sum has complex absolute value √p, but it is generally **not a p-adic unit**. Stickelberger and Gross–Koblitz describe its positive, usually fractional, valuations at primes above p.

The answers are:

```text
Raw Kloosterman Mellin transform:

Σ_{t ∈ F_p×} χ(t) Kl₂(1,t;p) = g(χ)².
```

There is no factor p or 1/p in the raw identity. A sign, a factor p^(−1/2), or a factor 1/(p−1) appears only after changing the sheaf-trace, weight, convolution, or Mellin normalization.

There are three inequivalent meanings of “zero mod p”:

| Reduction being tested | Number of nontrivial χ with g(χ)² zero |
|---|---:|
| Modulo one maximal ideal 𝔓, equivalently one uniformizer | p−2 |
| Modulo p in one selected local field K_𝔓 | (p−1)/2 |
| Modulo the global ideal p𝒪_K | 1 |

For every odd p, the unique global zero is the quadratic character. Therefore a computed average near 1.00 is naturally explained by **global divisibility by p𝒪_K**. Under the raw conventions, this predicts exactly one zero for every odd p, at exponent r = (p−1)/2, not merely one zero on average.

For Apéry, Gross–Koblitz can be applied term by term, but the known finite-field hypergeometric expression retains an outer sum of p−1 Gauss/Jacobi products. It does not reduce to one product of four Gamma values. Stickelberger determines the slope packets; the actual Apéry zero is cancellation among equal-slope units.

# (A) Exact Kloosterman normalization

## 1. Raw definitions

Let p be odd, let ψ(x) = ζ_p^x, and define

```text
K(t) = Kl₂(1,t;p)
     = Σ_{x ∈ F_p×} ψ(x + t/x)
     = Σ_{xy=t} ψ(x)ψ(y).
```

For a multiplicative character χ of F_p×, define

```text
g(χ) = Σ_{x ∈ F_p×} χ(x)ψ(x).
```

With this convention, g(1) = −1 for the trivial character. For nontrivial χ,

```text
|g(χ)| = √p,

g(χ)g(χ⁻¹) = χ(−1)p.
```

The second identity is already important: in general it is g(χ)g(χ⁻¹), not g(χ)², that is visibly p times a root of unity.

## 2. Direct derivation

Using t = xy,

```text
Σ_{t ≠ 0} χ(t)K(t)
  = Σ_{x,y ≠ 0} χ(xy)ψ(x)ψ(y)
  = (Σ_{x ≠ 0} χ(x)ψ(x)) (Σ_{y ≠ 0} χ(y)ψ(y))
  = g(χ)².
```

Thus

```text
Σ_{t ∈ F_p×} χ(t) Kl₂(1,t;p) = g(χ)².        (A.1)
```

For χ = 1, this gives Σ_t K(t) = 1.

## 3. Normalization table

| Convention | Mellin value |
|---|---:|
| Raw K(t), transform Σ_t χ(t)K(t) | g(χ)² |
| Transform using χ⁻¹ | g(χ⁻¹)² |
| Averaged transform (p−1)⁻¹Σ_t χ(t)K(t) | g(χ)²/(p−1) |
| Katz rank-two Kloosterman sheaf with trace −K(t) | −g(χ)² |
| Weight-zero analytic normalization p^(−1/2)K(t) | p^(−1/2)g(χ)² |
| Averaged and weight normalized | g(χ)²/((p−1)√p) |

The sheaf-theoretic sign comes from the cohomological shift in the usual Kloosterman-sheaf convention. A Tate/weight normalization contributes p^(−1/2). An averaged finite Fourier transform contributes 1/(p−1). The convolution theorem itself contributes neither 1/p nor 1/(p−1).

## 4. The notation t^r is ambiguous

Choose a generator g₀ of F_p×. The complex character indexed by r is

```text
χ_r(g₀^m) = exp(2πirm/(p−1)).
```

This is not the ordinary integer [g₀^m]^r. Therefore the exact characteristic-zero statement is

```text
Σ_t χ_r(t)K(t) = g(χ_r)²,
```

not literally Σ_t [t]^rK(t) = g(χ_r)².

If w_r(t) = [t]^r is the ordinary integer-power weight, character Fourier inversion gives the exact relation

```text
Σ_t w_r(t)K(t)
  = (1/(p−1)) Σ_χ ŵ_r(χ) g(χ)²,

ŵ_r(χ) = Σ_{u ≠ 0} w_r(u)χ(u)⁻¹.
```

So a literal integer-power weight is a linear combination of Gauss squares.

In the p-adic formulation one uses the Teichmüller character

```text
ω : F_p× → μ_{p−1} ⊂ Z_p×,
ω(t) ≡ t mod p.
```

Then ω(t)^r reduces to t^r in F_p at the chosen p-adic prime. This is a **local specialization** of the roots-of-unity character value. It is not the same operation as testing global divisibility in the full cyclotomic ring. That distinction can change the zero count from 1 to (p−1)/2.

# (B) Gross–Koblitz and the three reductions

## 5. One-prime valuation formula

Fix a p-adic embedding and its Teichmüller character ω. Choose π satisfying

```text
π^(p−1) = −p,
v_p(p) = 1,
v_p(π) = 1/(p−1).
```

For 0 ≤ j ≤ p−2, Gross–Koblitz gives

```text
g(ω^(−j)) = −π^j Γ_p(j/(p−1)).             (B.1)
```

Morita’s Γ_p is a p-adic unit on Z_p. Hence

```text
v_p(g(ω^(−j))) = j/(p−1).                   (B.2)
```

Equivalently, for 1 ≤ r ≤ p−2,

```text
v_p(g(ω^r)) = 1 − r/(p−1).                  (B.3)
```

The trivial character has g(1) = −1 and valuation zero. Every nontrivial character has positive valuation at the selected prime.

Thus the assertion “g(χ) is always a p-adic unit” is false. The complex identity |g(χ)| = √p proves nonvanishing in characteristic zero, not p-adic invertibility.

## 6. What is wrong with the scalar fractional-parts sum

The sum quoted in the question is

```text
Σ_{a=1}^{d−1} {a/d} = (d−1)/2.
```

This is not the valuation of one Gauss sum.

Suppose χ has exact order d and, at the chosen prime, is represented by

```text
χ = ω^(−(p−1)c/d),
1 ≤ c < d,
gcd(c,d) = 1.
```

Then the valuation of this one Gauss sum is

```text
v_p(g(χ)) = c/d.                            (B.4)
```

As the prime above p varies through the primes coming from the character-value field, the slopes form the multiset

```text
{ ⟨ac/d⟩ : a ∈ (Z/dZ)× }
  = { a/d : a ∈ (Z/dZ)× }.
```

Their sum is φ(d)/2 for d > 2. Summing over every a = 1,…,d−1, including nonprimitive powers, gives (d−1)/2. These are aggregate valuations of conjugates or powers. Stickelberger’s theorem is naturally a group-ring or ideal factorization with one coefficient for each prime above p; adding all coefficients loses the local information needed here.

## 7. Modulo one maximal ideal 𝔓

Let 𝔓 be the selected maximal ideal, with uniformizer π. From (B.1), every nontrivial Gauss sum lies in (π). Therefore

```text
g(χ)² ≡ 0 mod 𝔓
```

for all p−2 nontrivial characters.

This only requires positive valuation. It is not equivalent to v_p(g(χ)) ≥ 1/2.

## 8. Modulo p in one selected local field

In the selected local integer ring,

```text
p𝒪_{K_𝔓} = (π^(p−1)).
```

Thus

```text
g(ω^(−j))² ∈ p𝒪_{K_𝔓}
    ⇔ 2j ≥ p−1
    ⇔ v_p(g(ω^(−j))) ≥ 1/2.                 (B.5)
```

For χ = ω^(−j), the indices are

```text
(p−1)/2 ≤ j ≤ p−2,
```

so there are exactly (p−1)/2 characters.

For the indexing χ_r = ω^r, equation (B.3) reverses the interval:

```text
1 ≤ r ≤ (p−1)/2.
```

Therefore the correct equivalence is

```text
v_p(g(χ)) ≥ 1/2
    ⇔ g(χ)² is zero modulo p in the selected local ring,
```

not merely zero modulo its uniformizer.

Order by order, among characters of exact order d > 2, exactly φ(d)/2 have selected-prime slope at least 1/2; c pairs with d−c. The quadratic character contributes one. Hence

```text
1 + (1/2) Σ_{d | p−1, d>2} φ(d) = (p−1)/2.
```

## 9. Global divisibility by p𝒪_K

Let d = ord(χ) and K = Q(ζ_p,ζ_d). Because d divides p−1, p splits completely in Q(ζ_d) and is totally ramified in the ζ_p direction.

At the primes 𝔓_a above p, the normalized slopes of g(χ) are

```text
⟨ac/d⟩,  a ∈ (Z/dZ)×.
```

Global divisibility means satisfying the p-divisibility threshold at **every** such prime:

```text
g(χ)² ∈ p𝒪_K
  ⇔ 2⟨ac/d⟩ ≥ 1 for every a ∈ (Z/dZ)×.      (B.6)
```

Multiplication by c permutes the units modulo d, so the minimum slope is 1/d. Hence (B.6) holds exactly when

```text
2/d ≥ 1.
```

The trivial character has g(1)² = 1. The only nontrivial possibility is d = 2. Therefore

```text
g(χ)² ≡ 0 mod p𝒪_K
  ⇔ χ is the nontrivial quadratic character. (B.7)
```

There is exactly one such character for every odd p. Directly,

```text
g(φ)² = φ(−1)p.                             (B.8)
```

For every character of order d > 2, at least one prime above p has slope 1/d < 1/2, so the square is not globally divisible by p.

This also explains the nilpotent phenomenon. A nontrivial g(χ) lies in every maximal ideal above p, but it need not lie in the full ideal p𝒪_K. Its image in 𝒪_K/p𝒪_K can be a nonzero nilpotent. Squaring kills it globally only in the quadratic case.

## 10. Bonus: m-fold Kloosterman convolution

If an m-fold multiplicative Artin–Schreier convolution has Mellin transform g(χ)^m, the same minimum-slope argument gives

```text
g(χ)^m ∈ p𝒪_K
  ⇔ ord(χ) ≤ m,
```

apart from the trivial character. Its number of global Mellin zeros is therefore

```text
Σ_{d | p−1, 2≤d≤m} φ(d)
  ≤ Σ_{d=2}^m φ(d),
```

an absolute bound depending only on the convolution length. For m = 2, this is the singleton quadratic zero.

## 11. Comparison with the reported data

The three predicted patterns are unmistakable:

```text
Reduction in 𝒪_K/𝔓:
    every nontrivial r vanishes.

Reduction in 𝒪_{K_𝔓}/p:
    one contiguous half of the r-range vanishes;
    using χ⁻¹ reverses which half.

Reduction in 𝒪_K/p𝒪_K:
    exactly r = (p−1)/2 vanishes.
```

Thus a reported count near 1.00 is naturally explained by the third interpretation. Under the raw Kloosterman conventions it should sharpen to

```text
Z_p^Kl = { (p−1)/2 }
```

for every odd p.

If the actual data sometimes has zero or two zeros, or if its singleton is not the quadratic exponent, then the computed object is not the raw global character Mellin transform. Likely causes are:

* `t^r` was implemented as an ordinary representative rather than as a roots-of-unity character;
* the trace function differs from the raw K(t);
* a normalization or additive correction term was inserted;
* zero was tested after one specialization of the character-value field;
* the Kloosterman value is a rational/integer proxy rather than the classical cyclotomic sum.

A decisive unit test is (B.8): at r = (p−1)/2 the Mellin value must be exactly φ(−1)p, up to the single global sign dictated by the sheaf convention.

# (D) What survives for the Apéry hypergeometric problem

## 12. Why Kloosterman collapses and a fixed hypergeometric value does not

Kloosterman works because multiplicative convolution and Mellin transformation diagonalize each other:

```text
AS_ψ * AS_ψ  --Mellin-->  g(χ)².
```

After Mellin transformation there is one product and no outer summation.

A finite-field hypergeometric value at a fixed point is instead an inverse Mellin sum. Schematically, Greene’s definition has the form

```text
F_p(z) = C_p Σ_η A_p(η)η(z),                (D.1)
```

where A_p(η) is a bounded product or ratio of Gauss/Jacobi sums. Mellin transformation in the geometric variable z selects one term:

```text
Σ_{z ≠ 0} χ(z)⁻¹F_p(z)
  = (p−1)C_p A_p(χ).                        (D.2)
```

But evaluation at a fixed point such as z = 1/16 retains the complete sum:

```text
F_p(1/16) = C_p Σ_η A_p(η)η(1/16).         (D.3)
```

This is where “a product of four Γ_p values” becomes misleading. Each summand may become a product of Γ_p values under Gross–Koblitz; the hypergeometric value remains a sum of those products.

## 13. The direct classical Apéry identity

For the coefficient itself, the direct terminating identity is

```text
b_r = _4F_3(−r,−r,r+1,r+1; 1,1,1; 1).     (D.4)
```

A half-parameter expression with parameters

```text
(1/2,1/2,1/2,1/2; 1,1,1)
```

and a point such as 1/16 may describe a transformed period or a related finite-field family. It is not automatically the same as the Mellin coefficient b_r. Finite-field transformations also have normalization factors and exceptional-character terms.

The identity needed for the proposed argument must be proved at the level of the **function in the geometric Mellin variable**, not inferred merely from a hypergeometric representation of each coefficient:

```text
“b_r is a hypergeometric value”
    does not imply
“b_r is one Mellin-selected Gauss product.”
```

## 15. Exact Morita-Gamma criterion

For 0 ≤ k ≤ r ≤ p−1, define the p-adic unit

```text
U_{p,r,k}
  = Γ_p(r+k+1) /
    (Γ_p(k+1)² Γ_p(r−k+1)).                 (D.7)
```

Up to a sign that disappears after squaring,

```text
C(r,k) C(r+k,k)
  = p^[1 if r+k≥p, otherwise 0] U_{p,r,k}.  (D.8)
```

Therefore

```text
b_r = Σ_{k=0}^r
      p^[2 if r+k≥p, otherwise 0] U_{p,r,k}².  (D.9)
```

Put ρ = min(r,p−1−r). Reduction modulo p gives the exact criterion

```text
p divides b_r
  ⇔ Θ_{p,r} := Σ_{k=0}^ρ overline(U_{p,r,k})² = 0 in F_p.  (D.10)
```

Gross–Koblitz has determined exactly which terms survive. It has not determined whether their unit residues cancel. Equation (D.10) is explicit, but it is not a bounded-complexity location formula for the zeros.

The project’s sharp elementary witness is

```text
b_5 = 819005,

b_5 ≡ 0 mod 11,
b_5 ≡ 5 mod 13.
```

For both p = 11 and p = 13, all six terms k = 0,…,5 in (D.9) have valuation zero. The valuation vector is identical, but the unit residues cancel only for p = 11. Therefore the carry polygon alone cannot decide the zero event.

The exhaustive project audit through p ≤ 200 finds at most four Apéry zeros, with four at p = 181 and p = 193. This supports a small average zero count, but the slope polygon does not explain it.

## 16. The conditional route that really would work

The proposed strategy is valid if one first proves a genuine single-product identity for the actual AFP Mellin coefficient. Suppose one had

```text
M_r = u_r p^(−e_r)
      Π_{i=1}^A g(A_iχ_r)
      Π_{j=1}^B g(B_jχ_r⁻¹),                (D.11)
```

with no remaining character sum and with A, B, and the fixed characters independent of p.

Gross–Koblitz would then give, at every prime above p, a finite fractional-part expression of the schematic form

```text
v_p(M_r)
  = −e_r
    + Σ_i ⟨α_i + x_r⟩
    + Σ_j ⟨β_j − x_r⟩.                      (D.12)
```

Global p-divisibility would become a finite system of piecewise-linear inequalities over all Galois conjugates. This can produce an explicit uniformly bounded zero set, exactly as it does for g(χ)².

So the Stickelberger strategy is mathematically sound **conditional on the single-product collapse**.

The present Apéry formulas do not give that collapse. They give either the p−1-term character sum (D.5) or the r+1-term coefficient sum (D.9). Proving a transformation from either expression to (D.11) would be a genuine breakthrough. Gross–Koblitz alone does not perform it.

## 17. What Gross–Koblitz can still contribute to AFP

A rigorous Gross–Koblitz program should proceed in this order:

1. Fix one exact finite-field convention: Greene, Katz, or McCarthy. Record every factor of p and p−1, every sign, and every exceptional trivial-character term.
2. Prove that the function being transformed is the actual Apéry K3/Hasse trace function in the project’s geometric variable.
3. Take the Mellin transform in that geometric variable. Do not replace this by evaluation at one fixed hypergeometric argument.
4. Apply Gross–Koblitz term by term and compute the full Landau/carry function.
5. Remove all positive-slope terms modulo p.
6. Analyze the surviving unit sum.

For the formulas currently in the repository, steps 1–5 lead exactly to (D.10). Step 6 is the unresolved anti-cancellation problem.

The current project’s AFP target is an average bound for the number of Apéry coefficient zeros. A single-product collapse would be much stronger because it could give explicit locations. No such collapse is currently established.

# Final verdict

```text
Kloosterman:
  raw Mellin = one Gauss square;
  global mod-p zero ⇔ χ is quadratic;
  exactly one zero for every odd p.

Apéry:
  known finite-field formula = a large sum of Gauss/Jacobi products;
  Gross–Koblitz determines slopes but leaves a minimum-slope unit sum;
  zeros are unit cancellations, not valuation thresholds alone.
```

Thus the Kloosterman computation does provide a clean bounded-zero theorem, but it does **not** yet transfer to AFP. The missing Apéry ingredient is not another Stickelberger valuation calculation; it is either:

* a new identity collapsing the full hypergeometric/Jacobi sum to one bounded Gauss product, or
* a theorem controlling cancellation in the surviving minimum-slope unit packet.

## Code-level diagnostic for the Kloosterman experiment

Check these four points:

1. **Character lift:** is `chi_r(t)` a (p−1)-st root of unity indexed by the discrete logarithm of t, or merely the integer/field value t^r?
2. **Target ring:** is zero tested in 𝒪_K/𝔓, in 𝒪_{K_𝔓}/p, or in 𝒪_K/p𝒪_K?
3. **Trace convention:** is the value K(t), −K(t), or a weight-normalized trace?
4. **Quadratic test:** does r = (p−1)/2 give exactly φ(−1)p, up to the declared global sheaf sign?

These checks determine whether the expected count is p−2, (p−1)/2, or 1 without further numerical experimentation.
