
# 1. The singular base point and its canonical tangent

Define, initially for `|z| < 1`,

```text
H(a,z)
 = sum_(k>=0)
   (4)_k (-1/2)_k (a)_k
   ---------------------- z^k.
      (7/2)_k^2 k!
```

The cancellation of one upper `4` with the lower `4` has already been made. Near `a=0`, the series and its `a`-derivative converge normally on compact subsets of `|z|<=1`; at `z=1` the parametric excess is positive. Hence differentiation term by term is legitimate.

For `k>=1`,

```text
(d/da (a)_k)|_(a=0) = (k-1)!.
```

Therefore

```text
R(z)
 = sum_(k>=1)
   (4)_k (-1/2)_k
   ---------------- z^k.                         (1.1)
       k (7/2)_k^2
```

This is the canonical upper-parameter tangent. No finite-part convention is hidden in (1.1).

The ordinary state at `a=0` is indeed degenerate:

```text
H(0,z)=1,
theta H(0,z)=0,
theta^2 H(0,z)=0.
```

## 1.1 Regularization of the singular contiguous relation

For an upper parameter, the coefficientwise contiguous identity is

```text
(theta+a) H(a,z) = a H(a+1,z).                     (1.2)
```

Differentiate (1.2) at `a=0`. Since `H(0,z)=1`,

```text
theta R(z) + 1 = H(1,z).                            (1.3)
```

Set

```text
F(z) = H(1,z)
     = _3F2(4,-1/2,1 ; 7/2,7/2 ; z).
```

Then

```text
boxed:
F(z)=1+theta R(z),
theta F(z)=theta^2 R(z).                             (1.4)
```

Equation (1.4) identifies the regularized boundary state without taking a numerical limit and without selecting an arbitrary neighboring solution. It is exactly the finite part of the singular `a -> a+1` contiguous relation.

# 4. Why the scaling `D(n)` is the exterior-square path

Let `A(n)=raw(n)`. For the simple trajectory, the exact determinant is

```text
det A(n)=-(n+1)^3(2n+3)^4.                           (4.1)
```

For a `3 x 3` matrix, the second compound matrix in cross-product coordinates is

```text
C2(A)=det(A) A^(-T).                                 (4.2)
```

Combining (4.1)–(4.2), the matrix in the question is exactly

```text
D(n)=C2(raw(n)).                                     (4.3)
```

Thus the new gauge does more than match formal characters: it identifies the literal challenge module with the exterior square of the simple hypergeometric path.

For row states `x,y`,

```text
(x raw(n)) wedge (y raw(n))
 = (x wedge y) D(n).                                 (4.4)
```

This explains why a regularized second state is the correct analytic datum. The challenge numerator and denominator rows become two exterior products with the ordinary base state.

At `n=0`, the supplied identity

```text
C U(0)
 = -45 [[0,4915,754],
        [0,6930,1260]]                               (4.5)
```

has the cross-product interpretation

```text
(1,0,0) wedge (*,754,-4915) = (0,4915,754),
(1,0,0) wedge (*,1260,-6930) = (0,6930,1260).        (4.6)
```

The Catalan error combination is therefore

```text
G(0,6930,1260)-(0,4915,754)
 = (0,kappa_2,-kappa_1).                             (4.7)
```

Equation (4.7) is exactly the cross product of `(1,0,0)` with a second state whose first two theta coordinates are `-kappa_1,-kappa_2`. The local evaluation in Sections 1–3 identifies these connection coordinates exactly.

What (4.7) does **not** prove is that this second state is the minimal global solution selected by the backward product. That is the remaining connection theorem.

# 6. The scanner assertion is a separate theorem

The public `ramanujantools/limit.py` implementation of `Limit.identify` forms a numerical column, appends its multiples by a supplied constant, and calls PSLQ. It does not construct a parameter derivative, a Barnes contour, a positive remainder integral, or a proof of a projective limit.

The exact theorem needed is:

```text
[SIMPLE-PATH-CONNECTION]

Let c_N=R_N^(-T)e0 and kappa be (3.5). Then, in projective
coordinates,

        [c_N] -> [kappa].                             (6.1)
```

A denominator-normalized form avoiding projective notation is

```text
let d(x)=6930x_1+1260x_2;

d(c_N) != 0 eventually, and

c_N/d(c_N) -> kappa/d(kappa).                         (6.2)
```

Because `d(kappa)=-967680`, (6.2) immediately implies from (3.7)

```text
(4915c_(N,1)+754c_(N,2))
-------------------------------- -> G.               (6.3)
(6930c_(N,1)+1260c_(N,2))
```

Neither the finite gauge identity nor the local evaluation proves (6.1). A local value at the base point and the direction selected by a long backward product are different mathematical objects until a global connection theorem identifies them.

## 6.1 Why Poincare roots do not fill this gap

The roots determine possible exponential scales. They do not determine the connection coefficient of `e0` on the dominant adjoint line. In particular, knowing that a candidate vector has the correct asymptotic root and agrees numerically with `kappa` does not prove (6.1). This is precisely the invalid route excluded in the question.

## 6.2 An exact candidate minimal solution

For future use, the same upper tangent can be transported to every height. Define

```text
H_n(epsilon,z)
 = _4F3(n+4,n+4,-n-1/2,epsilon-n ; 7/2,7/2,4 ; z),

R_n(z)=(d/d epsilon H_n(epsilon,z))|_(epsilon=0).
```

For `k>n`, the derivative of the terminating upper factor is

```text
(d/d epsilon (epsilon-n)_k)|_(0)
 = (-1)^n n! (k-n-1)!.
```

Writing `k=n+1+m`, the nonterminating tail of `R_n` is

```text
- sum_(m>=0) A_(n,m) z^(n+1+m),                       (6.4)
```

where every `A_(n,m)` is positive and

```text
A_(n,m)=
 n! m! (1/2)_(n+1)(1/2)_m (n+4)_(n+1+m)^2
 ----------------------------------------------------,
 (7/2)_(n+1+m)^2 (4)_(n+1+m) (n+1+m)!
```

with exact term ratio

```text
A_(n,m+1)/A_(n,m)
 = (m+1)(m+1/2)(2n+m+5)^2
   ------------------------------------.              (6.5)
   (n+m+9/2)^2(n+m+5)(n+m+2)
```

Equations (6.4)–(6.5) are a genuine positive-tail starting point for proving (6.1). They are not, by themselves, the missing proof: one still needs an exact concomitant/contiguous identity showing that the backward covector `c_N` is normalized by this tail and an effective dominance estimate. I do not replace that theorem by a numerical check.

# 7. What is needed to conclude `commonLimit = catalanConstant`

From `Problem25Connection.lean`, every fixed challenge column ratio tends to `commonLimit`. Equation (5.5) uses the **moving**, signed final vector `U(N)e0`, so fixed-column convergence alone cannot be applied without a noncancellation estimate.

A sufficient exact statement is:

```text
[GAUGE-NONCANCELLATION]

Let p_N,q_N be the two rows of C M_N and v_N=U(N)e0.
There is a positive sequence K_N with

  K_N (2/3)^N -> 0

such that, eventually,

  sum_i |q_(N,i) v_(N,i)|
  <= K_N |sum_i q_(N,i) v_(N,i)|.                    (7.1)
```

Indeed the envelope theorem gives, for every coordinate,

```text
|p_(N,i)-commonLimit q_(N,i)|
 <= envelopeGap(N) |q_(N,i)|,

envelopeGap(N)=(2/3)^N envelopeGap(0).
```

Multiplying by `v_(N,i)`, summing, and using (7.1) proves

```text
[p_N v_N]/[q_N v_N] -> commonLimit.                  (7.2)
```

Combining (7.2), (5.5), `[SIMPLE-PATH-CONNECTION]`, and (3.7) yields

```text
commonLimit=catalanConstant,
```

and hence `Problem25Claim` by the already proved theorem

```text
problem25Claim_iff_commonLimit_eq_catalan.
```

The full polynomial numerator `P(n)` of `U(n)` can make (7.1) a finite family of rational polynomial inequalities after using the proved denominator projective cone

```text
1 <= denominatorX(n) <= 3/2,
0 <= denominatorY(n) <= 2.
```

But the coefficients of `P(n)` and such a factorization were not included in the question. The facts “`deg P=14`” and “`det U != 0`” do not imply (7.1). Dominant cancellation is possible for an invertible rational gauge.

Therefore the new gauge removes the old module-equivalence obstruction, but an honest proof of part (a) still requires (6.1) and a noncancellation certificate such as (7.1).

# 8. Why the all-N endpoint signs do not follow

The desired theorem

```text
positiveCatalanError N 0 <= 0 <= positiveCatalanError N 2
```

is stronger than equality of the limiting constant. Even if `commonLimit=G` is known, a convergent rational sequence may cross its limit finitely or infinitely often.

Under the exterior-square gauge, the error row begins as the explicit vector (4.7) and evolves by `D(n)`. To prove all-N signs, one needs one of the following exact finite-height statements:

1. a positive integral representation for the two relevant components of the transported exterior product; or
2. a forward-invariant cone for the regularized error state; or
3. a variation-diminishing theorem whose hypotheses are verified for every `raw(n)` and whose boundary ray is exactly `kappa`.

The local signs (3.8), the determinant identity, and projective convergence do not supply any of these. Previous exact audits in this repository already show that the obvious fixed rational polyhedral cones fail because the transverse limiting map is hyperbolic.

Thus part (b) is not established by the breakthrough as stated.

## 9.1 The theorem that is now ready to formalize

Using the repository's existing definition of `catalanConstant`, introduce the two regularized values by their Euler integrals and prove the two certificates in Section 2. The final theorem can have the small statement

```lean
/-- Exact regularized covector at the zero upper parameter. -/
theorem simplePath_regularized_covector :
    let f : R := 25 * (401 - 6 * catalanConstant) / 12288
    let tf : R := 25 * (-105 + 22 * catalanConstant) / 8192
    let k1 : R := -(1536 / 25) * (113 * f + 326 * tf)
    let k2 : R :=  (1536 / 5)  * (121 * f + 358 * tf)
    k1 = 754 - 1260 * catalanConstant /\
    k2 = -4915 + 6930 * catalanConstant /\
    (4915 * k1 + 754 * k2) /
      (6930 * k1 + 1260 * k2) = catalanConstant := by
  dsimp
  constructor
  · ring
  constructor
  · ring
  · have hden :
        (6930 : R) * (754 - 1260 * catalanConstant) +
          1260 * (-4915 + 6930 * catalanConstant) = -967680 := by
      ring
    rw [hden]
    ring
```

The real work preceding this final `ring` theorem is exactly (2.3)–(2.8), each central identity being `field_simp; ring` after the substitutions.

# 10. Standalone exact symbolic checks

The first script verifies every algebraic and antiderivative identity in Sections 1–3. It uses no floating point.

```python
# exact_regularized_catalan.py
import sympy as sp

u, x = sp.symbols('u x', positive=True)
G = sp.symbols('G')

# The elementary Gauss function after t=x^2.
gauss_x = (
    5*x*(-3 + 5*x**2*(-2 + 21*x**2))
    + 15*(1 + 3*x**2 + 15*x**4 - 35*x**6)*sp.atanh(x)
) / (768*x**5)

xu = (1-u**2)/(1+u**2)
# On 0<u<1: atanh(xu)=-log(u),
# (1-xu^2)^(3/2)=8u^3/(1+u^2)^3,
# and -d(xu^2)/du=8u*xu/(1+u^2)^2.
gauss_u = gauss_x.subs(x, xu).subs(sp.atanh(xu), -sp.log(u))
weight = sp.Rational(5,2) * 8*u**3/(1+u**2)**3
jac = 8*u*xu/(1+u**2)**2
J0 = sp.cancel(weight * gauss_u * jac)

# theta_z on the Euler integrand becomes t*d/dt=(x/2)*d/dx.
theta_gauss_x = sp.cancel(x*sp.diff(gauss_x, x)/2)
theta_gauss_u = theta_gauss_x.subs(x, xu).subs(
    sp.atanh(xu), -sp.log(u)
)
J1 = sp.cancel(weight * theta_gauss_u * jac)

S0 = 25*u*(
    3+8*u**2-2460*u**4+18936*u**6-28878*u**8
    +18936*u**10-2460*u**12+8*u**14+3*u**16
)/(6144*(u-1)**3*(u+1)**3*(1+u**2)**6)
T0 = 25*u*(
    9+26*u**2+12663*u**4-28468*u**6
    +12663*u**8+26*u**10+9*u**12
)/(18432*(u-1)**2*(u+1)**2*(1+u**2)**5)

S1 = -25*u*(
    33+88*u**2+9804*u**4-12888*u**6+26406*u**8
    -12888*u**10+9804*u**12+88*u**14+33*u**16
)/(12288*(u-1)**3*(u+1)**3*(1+u**2)**6)
T1 = -25*u*(
    99+3358*u**2-17379*u**4+12484*u**6
    -17379*u**8+3358*u**10+99*u**12
)/(36864*(u-1)**2*(u+1)**2*(1+u**2)**5)

cert0 = sp.together(
    J0 - sp.diff(S0*sp.log(u)+T0,u)
       - sp.Rational(25,2048)*sp.log(u)/(1+u**2)
)
cert1 = sp.together(
    J1 - sp.diff(S1*sp.log(u)+T1,u)
       + sp.Rational(275,4096)*sp.log(u)/(1+u**2)
)
assert sp.simplify(cert0) == 0
```

```python
    # z=1 pFq(4,3): theta*prod(theta+b_j-1)-prod(theta+a_i).
    R.<th> = PolynomialRing(K)
    pol = th*prod(th+bb-1 for bb in b)-prod(th+aa for aa in a)
    pol = pol / pol.leading_coefficient()  # cubic at z=1
    c0,c1,c2,_ = pol.list()+[0]*(4-len(pol.list()))
    return matrix(K,[[0,0,-c0],[1,0,-c1],[0,1,-c2]])

    return I3 + theta_matrix(a,b)/a[i]

def down(a,b,i):
    # state(a-e_i) * up(a-e_i,i) = state(a)
    aa=list(a); aa[i]-=1
    return up(aa,b,i).inverse()

    M *= down(a,b,2); a[2]-=1
    M *= down(a,b,3); a[3]-=1
    return M.apply_map(K)
```
