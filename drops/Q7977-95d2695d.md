# Corrected formulas and verdict

## 1. Central point chart at a=1

Put

\[
u=1+r,
\quad v=1+s,
\quad w=1+t,
\]

and set

\[
F=uv(w-1)(1-uvw)-w(u-1)(v-1).
\]

The completed local expansion at the origin is

\[
F=-(rs+rt+st+t^2)-rst-rs t^2-r^2st-rs^2t-r^2s^2t.
\]

Equivalently, after the linear change

\[
x=r+t,\qquad y=s+t,\qquad z=t,
\]

the quadratic part is \(-xy\), and the equation is

\[
xy=z^3+z^2(x+y)+\text{terms in }(x,y)\text{ of order }\ge 3.
\]

Because the coefficient of the cubic term in the null direction is \(-2\), and \(p\ge5\), the formal Morse lemma with parameters gives a completed-local-ring isomorphism

\[
\widehat{\mathcal O}_{X,(1,1,1)}\simeq k[[X,Y,Z]]/(XY-Z^3).
\]

Hence the singularity is exactly type A_2.

## 2. One blow-up

Blow up the maximal ideal \((X,Y,Z)\). The three affine charts are:

### X-chart

Set

\[
Y=Xy,\qquad Z=Xz.
\]

The strict transform is

\[
y-Xz^3=0.
\]

The chart is smooth because \(\partial/\partial y=1\).

### Y-chart

Set

\[
X=Yx,\qquad Z=Yz.
\]

The strict transform is

\[
x-Yz^3=0.
\]

The chart is smooth because \(\partial/\partial x=1\).

### Z-chart

Set

\[
X=Zx,\qquad Y=Zy.
\]

The strict transform is

\[
xy=Z.
\]

The chart is smooth because \(\partial/\partial Z=-1\).

Therefore the single ambient blow-up resolves the A2 point. No characteristic-p>=5 exception occurs.

## 3. (2,2,2) adjunction and cohomology

Let \(Y=(\mathbf P^1)^3\). Its canonical bundle is

\[
\omega_Y=\mathcal O_Y(-2,-2,-2).
\]

For a hypersurface \(X\) of multidegree \((2,2,2)\), adjunction gives

\[
\omega_X=(\omega_Y\otimes\mathcal O_Y(2,2,2))|_X\simeq\mathcal O_X.
\]

The defining exact sequence is

\[
0\to\mathcal O_Y(-2,-2,-2)
\to\mathcal O_Y
\to\mathcal O_X\to0.
\]

By Kunneth and the cohomology of \(\mathbf P^1\),

\[
H^1(Y,\mathcal O_Y)=0,
\]

and

\[
H^2(Y,\mathcal O_Y(-2,-2,-2))
=0
\]

because the only nonzero contribution is in degree 3:

\[
H^3(Y,\mathcal O_Y(-2,-2,-2))\cong k.
\]

The long exact sequence therefore gives

\[
H^1(X,\mathcal O_X)=0.
\]

The same sequence gives

\[
H^0(X,\mathcal O_X)=k,
\]

so X is connected. Since an anticanonical hypersurface with only rational double points is Cohen--Macaulay and has Cartier canonical divisor, it is Gorenstein. RDPs are normal. Geometric connectedness follows after base change because the H^0 calculation remains k over an algebraic closure.

## 4. Boundary components

The sixteen boundary equations remain distinct at both special parameters.

At a=1, the only degeneration is at the central point (1,1,1); it changes the local singularity from A1 to A2 but does not identify divisors. The boundary equations remain different codimension-one divisors in the toric boundary.

At

\[

\]

the additional A1 singularity is in the open torus. It does not meet or merge any boundary divisor.

Each displayed boundary component remains an irreducible rational curve because each is obtained by intersecting the irreducible (2,2,2) hypersurface with a toric boundary divisor and the residual equation is linear/bilinear in the remaining coordinates. No special value a=1 or D(a)=0 changes these factorisations.
