# Q7928 — Bilinear Kloosterman-fraction theorems versus AMTT4 Apéry residual

## Executive conclusion

The existing bilinear Kloosterman-fraction literature does not directly close AMTT4 for the Apéry centered transforms `R_p`. The obstruction is not a missing invocation of a named theorem; it is a mismatch of variables and coefficient structure.

The strongest applicable general technology is a Kuznetsov/spectral large sieve estimate in the Bettin--Chandee / Deshouillers--Iwaniec family. In the present regime it gives essentially square-root cancellation in the summation variables that are genuinely free, but the modulus-dependent Apéry coefficients occupy the wrong side of the bilinear form: they are not fixed trace-function coefficients with uniform conductor, nor are they independent sequences whose `ell^2` norms are small enough after the semiprime compression.

After the exact exponent audit, the best generic spectral estimate still leaves a loss of roughly a factor `X^{1/2}` (up to logarithms) relative to the AMTT4 target. An Apéry-specific correlation estimate of the size described below would make the existing theorem sufficient.

## 1. Exact compressed object

The output-prime compression writes the HM3 residual in the form

```
T_{p,qell} = (2 sqrt(p ell q))^{-1} U_p U_{qell}^t
```

with the semiprime side indexed by ordered pairs `(q,ell)` and the primitive Kloosterman/fraction phase coming from

```
h/(q ell)   with   h ~ X,
q,ell,p ~ X,
M=X^2.
```

The relevant facts are:

* `p,q,ell` are distinct primes in `(X,2X]`.
* The number of primes is `P ~ X/log X`.
* The semiprime blocks are ordered: `(q,ell)` and `(ell,q)` are distinct summation variables before any symmetry reduction.
* Primitive summation means `(h,pqell)=1`; replacing this by all residues introduces an invalid zero-frequency contribution.
* The centered transforms satisfy

```
R_p(a)=sum_{r in Z_p} exp(2 pi i a(r+1/2)/p),
```

with Parseval energy

```
sum_a |R_p(a)|^2 = p |Z_p|.
```

No theorem may replace this by a generic coefficient sequence with an assumed uniform bound.

## 2. Size of the coefficient vectors

For one prime `p`, the natural Fourier vector has norm

```
||R_p||_2^2 = p |Z_p|.
```

Using the known Apéry zero bound

```
|Z_p| <= p^{2/3+o(1)},
```

one gets

```
||R_p||_2 <= X^{5/6+o(1)}.
```

For a semiprime block `(q,ell)`, the tensor coefficient has norm

```
||R_q tensor R_ell||_2
 = ||R_q||_2 ||R_ell||_2
 <= X^{5/3+o(1)}.
```

The number of ordered semiprime blocks is

```
~ (X/log X)^2.
```

Thus the raw Hilbert space mass is already

```
(X/log X)^2 X^{5/3}
= X^{11/3}/log^2 X
```

before any oscillatory cancellation.

## 3. Comparison with available Kloosterman theorems

### Deshouillers--Iwaniec

The DI spectral large sieve controls bilinear sums of the schematic form

```
sum_{m,n} alpha_m beta_n S(m,n;c)/c
```

with fixed modulus structure and coefficients satisfying prescribed `ell^2` bounds.

The usable gain is approximately square root cancellation in the modulus/spectral aspect.

The AMTT4 expression does not have fixed coefficients:

```
alpha_m = R_p(h * inverse(q ell))
```

changes with the modulus `q ell` and with the prime `p`.

Therefore the DI theorem applies only after treating the Apéry transforms as arbitrary coefficients. That loses the arithmetic correlation and gives no closure.

---

### Bettin--Chandee

The Bettin--Chandee bilinear Kloosterman fraction bounds allow ranges

```
M,N,C
```
with coefficient norms and gain depending explicitly on those lengths.

The closest matching reduction has:

```
N ~ X^2        (ordered semiprime blocks)
h-length ~ X
modulus q ell ~ X^2.
```

The bilinear form is therefore near the transition range where the theorem gives only the expected square-root gain in the large variable. The coefficient norm contribution remains

```
||beta||_2 ~ X^{5/3+o(1)}.
```

The resulting bound has size

```
X^{3+o(1)} * X^{-1/2}
```

relative to the trivial cubic tuple scale.

AMTT4 requires the full missing factor coming from the centered Apéry cancellation. The generic theorem does not provide it.

---

### Duke--Friedlander--Iwaniec / Kuznetsov

Kuznetsov gives a spectral decomposition of the Kloosterman sum and the spectral large sieve controls the resulting Fourier coefficients.

However, the transformed Apéry coefficient is not a Hecke eigenvalue sequence in the modulus variable. In particular:

```
R_p(h inverse(q ell))
```

is not a fixed automorphic coefficient with known Ramanujan/conductor bounds.

The conductor therefore grows with the prime triple. Treating it generically reproduces the same `X^{1/2}` gap.

## 4. Exponent audit

The desired AMTT4 scale is roughly

```
Target = X^{2+o(1)} lambda^A
```

for the residual after compression.

The completely unsigned tuple bound gives

```
#(p,q,ell) * typical block size
~ (X/log X)^3.
```

The spectral theorem supplies at most one square-root saving from the Kloosterman variable:

```
h-range/modulus square root:
X^{1/2}.
```

Hence

```
X^3 / X^{1/2}=X^{5/2}
```

(up to logarithms and lambda powers).

This is still above

```
X^2 lambda^A
```

by

```
X^{1/2} log^A X.
```

No available theorem removes that final factor because it is exactly the missing correlation between the Apéry family members.

## 5. Weakest sufficient Apéry hypothesis

A minimal additional input is not pointwise cancellation. It is a bilinear correlation statement for centered transforms.

One sufficient hypothesis is:

For all dyadic prime ranges and all coefficients `c_{q,ell}` with

```
sum_{q,ell}|c_{q,ell}|^2 <= 1,
```

one has

```
| sum_{q,ell} c_{q,ell}
   R_q(h inverse(ell)) R_ell(h inverse(q)) |
 <= X^{1+o(1)}
```

uniformly for `h~X`.

Equivalently, the semiprime tensor family must have square-root cancellation beyond its Parseval norm:

```
operatorname{largest singular value}
(T_semiprime)
<= X^{1+o(1)}.
```

This is the weakest natural statement because it is exactly the input needed by the existing Bettin--Chandee/Kuznetsov machinery. It does not assume independence or a pointwise bound on `R_p`; it only controls the singular direction actually used by AMTT4.

Without that hypothesis, no currently published DI/BC/DFI/Kuznetsov theorem has hypotheses matching the modulus-dependent coefficients `R_p`, and the strongest black-box application leaves an unavoidable generic loss

## 7. Audit flags

* Full residue summation instead of `(h,pqell)=1` is invalid: it changes the zero-frequency term.
* Treating ordered `(q,ell)` as unordered changes constants and can lose a factor two; it does not repair the exponent gap.
* Replacing `R_p` by generic bounded coefficients discards the only Apéry-specific structure.
* Parseval alone gives `||R_p||_2^2=p|Z_p|`; it does not imply semiprime orthogonality.
* A claimed square-root bound in `h` alone is insufficient: the missing saving is in the modulus-dependent coefficient family.

The frontier is therefore a new Apéry bilinear correlation theorem, not a missing application of existing Kloosterman-fraction technology.
