# Hostile audit of qSELFREC: the scalar recurrence does not descend through pushforward

## Executive verdict

The proposed sheaf induction breaks at the exact place where the `r` variable is integrated out.

There is a correct and useful categorification before pushforward:

```text
f_{h+1}(r) = a_h(r) f_h(r) + b_h(r) f_{h-1}(r),

a_h(r) = P(r+h)/(r+h+1)^3,
b_h(r) = -(r+h)^3/(r+h+1)^3.
```

At the graph level, the graph of `f_{h+1}` is the image of the same-`r` joint graph of `(f_h,f_{h-1})` under the fiberwise linear map

```text
(r,x,y) -> (r, a_h(r)x + b_h(r)y).
```

After relative Fourier transform, this becomes the exact tensor identity

```text
L_psi(t f_{h+1}(r))
  = L_psi(a_h(r)t f_h(r)) tensor L_psi(b_h(r)t f_{h-1}(r)).
```

That is the entire surviving recurrence.

It does not produce a distinguished triangle relating the already pushed-forward objects `F_{h+1}`, `F_h`, and `F_{h-1}`. The objects `K_h = R(f_h)_! Q_l` and `K_{h-1}` are only the two marginals. They have forgotten that the two values came from the same `r`. Recovering `K_{h+1}` requires the joint sheaf of the pair `(f_h(r),f_{h-1}(r))`, not the two marginal pushforwards.

The three intended consequences then fail as follows.

1. Geometric irreducibility of the full `F_h` is false for every `h`: the finite cover pushforward contains a constant summand, whose Fourier transform is a punctual summand at `t=0`.
2. `Hom_geom(F_h,F_{h'})=0` is false for the full objects, again because all of them share that punctual summand. Even after removing it, the base case `h=1` is reducible into two cubic Kummer constituents.
3. No End-rank collapse follows. At good reduction, the generic rank of the exponential-sum sheaf `F_h` on `t != 0` is `4h-2`. Hence

```text
rank( direct_sum_{h<=H} F_h ) = 2 H^2,
rank End( direct_sum_{h<=H} F_h ) = 4 H^4.
```

A recurrence in a tensor category does not erase this rank invariant. It gives no formal route from `H^4` to `H^3`, let alone `H^2`.

The first case already kills the proposed induction: `F_1` is geometrically reducible, and `F_2` is obtained from `F_1` by an `r`-dependent scaling before the `r`-pushforward, not by any functor applied to `F_1` after pushforward.

Final verdict:

```text
Graph-level categorification: HOLDS, but is tautological.
Relative Fourier tensor identity: HOLDS and is worth recording.
Distinguished triangle F_{h+1} from F_h,F_{h-1}: DOES NOT EXIST in the proposed form.
Induction for full irreducibility: FALSE.
Induction for full Hom-vanishing: FALSE.
End-collapse from the recurrence: KILLED.
```

The sharp first lemma to bank is instead an augmentation-Hom/fiber-product dictionary: after deleting the common constant summands, off-diagonal Hom vanishing is equivalent to geometric connectedness of the fiber product

```text
f_h(r) = f_k(r').
```

That returns the campaign to the path-cover rigidity target identified in Q6548. The recurrence does not bypass that target.

## 1. Precise graph-level lift

Work over an algebraic closure of `F_p`, with `l != p`. Put

```text
S_h = {-1,-2,...,-h},
U_h = P^1_r minus S_h.
```

The rational function

```text
f_h(r) = Delta_{r,h} = N_h(r) / D_h(r),
D_h(r) = product_{j=1}^h (r+j)^3
```

is regular on `U_h` and has value `0` at `r=infinity`. Over characteristic zero it has exactly `h` triple poles. At a good reduction prime the same is true; if one of the endpoint coefficients vanishes modulo `p`, the corresponding pole order can drop and must be treated as bad reduction for the rank formulas below.

The scalar recurrence is

```text
f_{h+1}(r)
 = a_h(r) f_h(r) + b_h(r) f_{h-1}(r),
```

with

```text
a_h(r) = P(r+h)/(r+h+1)^3,
b_h(r) = -(r+h)^3/(r+h+1)^3.
```

It is valid on `U_{h+1}`.

Let

```text
i_h : U_h -> U_h x A^1_x,
i_h(r) = (r,f_h(r)),
```

and let

```text
G_h = R(i_h)_! Q_l
```

be the graph sheaf. On `U_{h+1}`, form the same-base joint graph

```text
j_{h,h-1}(r) = (r,f_h(r),f_{h-1}(r))
```

inside `U_{h+1} x A^1_x x A^1_y`. Define

```text
m_h : U_{h+1} x A^1_x x A^1_y -> U_{h+1} x A^1_z,

m_h(r,x,y) = (r,a_h(r)x+b_h(r)y).
```

Then there is an exact identity of graphs:

```text
m_h o j_{h,h-1} = i_{h+1}|_{U_{h+1}}.
```

Consequently

```text
G_{h+1}|_{U_{h+1}}
  = R(m_h)_! J_{h,h-1},
```

where `J_{h,h-1}` is the constant sheaf on the joint graph.

The joint graph can itself be written as a derived same-base product. If

```text
p_x : U_{h+1} x A^1_x x A^1_y -> U_{h+1} x A^1_x,
p_y : U_{h+1} x A^1_x x A^1_y -> U_{h+1} x A^1_y,
```

then, up to the standard graph-extension conventions,

```text
J_{h,h-1}
 = p_x^*(G_h|_{U_{h+1}})
   tensor^L
   p_y^*(G_{h-1}|_{U_{h+1}}).
```

This is the correct graph-level convolution-type statement.

It is not a statement about `K_h` and `K_{h-1}`. If

```text
q_x : U_h x A^1_x -> A^1_x,
K_h = R(q_x)_! G_h = R(f_h)_! Q_l,
```

then `K_h` has forgotten `r`. The external product `K_h boxtimes K_{h-1}` corresponds to two independent variables `r` and `r'`. The recurrence requires the diagonal condition `r=r'`.

At the trace-function level the difference is absolute. A convolution built from the two marginals produces a product of sums of the form

```text
( sum_r psi(t a_h(r) f_h(r)) )
( sum_{r'} psi(t b_h(r') f_{h-1}(r')) ).
```

The desired trace is

```text
sum_r psi(t a_h(r) f_h(r) + t b_h(r) f_{h-1}(r)).
```

The latter is a same-`r` correlation. It is not determined by the two marginal sums.

Verdict on Task 1 at graph level: HOLDS, but only before `r` is pushed away.

## 2. Exact Fourier-side operation

The cleanest formulation uses relative Fourier transform over the `r`-base.

Let `T=A^1_t`. On `U_h x T`, define

```text
E_h = L_psi(t f_h(r)).
```

Up to the standard cohomological shifts, the global Fourier object is

```text
F_h = R(pr_t)_! j_{h,!} E_h,
```

where `j_h : U_h x T -> P^1_r x T` is the open immersion.

Define the two moving scalings on `U_{h+1} x T`:

```text
alpha_h(r,t) = (r,a_h(r)t),
beta_h(r,t)  = (r,b_h(r)t).
```

The Artin-Schreier tensor rule gives the exact identity

```text
E_{h+1}
 = alpha_h^* E_h tensor beta_h^* E_{h-1}
```

on `U_{h+1} x T`.

Equivalently, relative Fourier transform turns the fiberwise linear map

```text
(x,y) -> a_h(r)x+b_h(r)y
```

into restriction along the dual moving line

```text
t -> (a_h(r)t,b_h(r)t).
```

In vector-bundle notation, if `m_h^vee` is the dual map

```text
m_h^vee(r,t) = (r,a_h(r)t,b_h(r)t),
```

then

```text
FT_{z/U}( R(m_h)_! J_{h,h-1} )
 = (m_h^vee)^* FT_{(x,y)/U}(J_{h,h-1}),
```

up to the normalizing shift and Tate twist. Since the two-variable Fourier transform of the joint graph is

```text
L_psi(t_1 f_h(r)+t_2 f_{h-1}(r)),
```

pullback along `m_h^vee` gives exactly `E_{h+1}`.

This is not multiplicative convolution of `F_h` and `F_{h-1}`. It is a pullback of a two-frequency joint sheaf along an `r`-dependent line. The joint sheaf is extra data.

The correct global formula is therefore

```text
F_{h+1}
 = R(pr_t)_! j_{h+1,!}
   ( alpha_h^*E_h tensor beta_h^*E_{h-1} ).
```

There is no simplification to an expression involving only the already integrated objects `F_h` and `F_{h-1}`.

Verdict on the proposed Fourier convolution: FIXABLE ONLY BY RETAINING THE JOINT `r`-SHEAF. As an operation on `F_h,F_{h-1}` alone, it is false.

## 3. There is no recurrence distinguished triangle

A distinguished triangle records additive information in a derived category. The scalar recurrence is additive inside the phase, and the Artin-Schreier sheaf converts addition of phases into tensor product:

```text
L_psi(A+B) = L_psi(A) tensor L_psi(B).
```

It does not convert the recurrence into a cone or extension.

The only canonical triangle available here is a localization triangle for the new deleted point.

Let

```text
V_h = U_h x T,
W_h = U_{h+1} x T,
j : W_h -> V_h,
i : {r=-(h+1)} x T -> V_h.
```

On `W_h`, put

```text
C_h = alpha_h^*E_h tensor beta_h^*E_{h-1}.
```

Then

```text
E_{h+1} = j_! C_h.
```

The standard localization triangle is

```text
j_! C_h
 -> Rj_* C_h
 -> i_* i^* Rj_* C_h
 -> +1.
```

After `R(pr_t)_!`, this becomes

```text
F_{h+1}
 -> R(pr_t)_! Rj_* C_h
 -> R(pr_t)_! i_* B_h
 -> +1,
```

where

```text
B_h = i^* Rj_* C_h
```

is the local boundary object at `r=-(h+1)`.

This triangle does not contain `F_h` or `F_{h-1}` as terms. Its middle term still contains the correlated tensor product before the `r`-pushforward.

The proposed error-support list is also wrong.

Put `u=r+h`. Then

```text
a_h = P(u)/(u+1)^3,
b_h = -u^3/(u+1)^3.
```

At `u=0`, one has

```text
a_h = 5,
b_h = 0.
```

The linear map `(x,y)->a_h x+b_h y` is still surjective. There is no linear-map degeneration. This point is `r=-h`, already deleted from `U_h` because `f_h` has a pole there.

At `u=-1`, both coefficients have a denominator pole. This is the genuinely new boundary point `r=-(h+1)`.

At a root of `P(u)`, one has `a_h=0` but `b_h != 0`, because `P(0)=5` and `P(-1)=-5`. Again the linear map is still surjective. These are not error points.

Thus the one-step boundary contribution is associated to the single new point `r=-(h+1)`, together with the already inherited old punctures. It is not a two-point error supported at `u=0` and `u=-1`.

The exact polar formula makes the new local object explicit. At `r=-(h+1)`, the principal coefficient of `f_{h+1}` is proportional to `b_h`, because the endpoint formula gives

```text
N_{h+1}(-(h+1))
 = (-1)^h (h!)^3 b_h.
```

After dividing by the nonvanishing complementary denominator factor, the local phase has the form

```text
f_{h+1}(r)
 = b_h/(r+h+1)^3 + lower polar terms.
```

If `b_h != 0 mod p`, the local Artin-Schreier sheaf has Swan conductor `3`. If `b_h=0 mod p`, the local type drops and must be placed in an exceptional reduction set. In either case, this local term is not constructed from `F_h` and `F_{h-1}` after pushforward.

Verdict on the requested distinguished triangle: FATAL. The only honest triangle is localization around the new pole, and it does not yield an `h`-recursion for the global Fourier objects.

## 4. Target (a): geometric irreducibility is false as stated

For `h>=1`, the map

```text
f_h : U_h -> A^1_x
```

is the base change to `A^1_x` of the finite rational map

```text
P^1_r -> P^1_x
```

of degree `3h`, at good reduction. Therefore `K_h=(f_h)_*Q_l` is generically a permutation local system of rank `3h`.

On the common finite-etale open there are canonical unit and trace maps

```text
Q_l -> (f_h)_*Q_l -> Q_l.
```

Their composition is multiplication by `3h`, which is invertible in `Q_l`. Hence the constant line splits off:

```text
K_h = Q_l direct_sum K_h^aug
```

on the etale open, and after middle extension in the semisimple pure category.

Fourier-Deligne transform sends the constant perverse sheaf to a punctual perverse sheaf at `t=0`, up to the normalizing shift and Tate twist. Thus

```text
F_h = delta_0 direct_sum F_h^aug.
```

Therefore the full `F_h` is never geometrically irreducible.

This is not a cosmetic basepoint issue. The proposed induction target must first be replaced by a primitive or augmentation object, for example

```text
A_h = ker( trace : (f_h)_*Q_l -> Q_l ),
F_h^aug = FT_psi( j_!* A_h[1] ).
```

Even that repaired target fails at `h=1`, as shown below.

Verdict on Task 2(a): FALSE for the objects named in the question. OPEN only after a nontrivial primitive decomposition is specified.

## 5. Target (b): full Hom-vanishing is false, primitive Hom-vanishing is a fiber-product problem

Because every `F_h` contains the same punctual `delta_0` summand,

```text
Hom_geom(F_h,F_k) != 0
```

for all `h,k` in the full category.

Removing the constant summand does not make the recurrence prove orthogonality. Fourier transform is an equivalence, so

```text
Hom_geom(F_h^aug,F_k^aug)
 = Hom_geom(K_h^aug,K_k^aug).
```

The right side is governed by the geometric fiber product of the two covers, not by the three-term recurrence alone.

The claim that the twist `phi_{r+h}` moves singularities and therefore makes `F_{h+1}` new is unsupported. The new point `r=-(h+1)` is a singularity in the integrated `r` variable. After Fourier transform and `r`-pushforward, it contributes local monodromy in the `t`-family, principally at the Fourier boundary. It does not create a new finite singular point labelled by `h+1` on the `t`-line. All levels live on the same Fourier line and share the same distinguished stratum `t=0` versus `t!=0`.

Novelty must therefore be proved from local monodromy characters, slopes, or common-quotient rigidity. It is not visible from the location of singularities.

Verdict on Task 2(b): FALSE for full objects; OPEN for augmentation objects; not implied by the recurrence.

## 6. Exact first-case failure: h=0,1,2

### 6.1 The level h=0

Take

```text
f_0=0.
```

As a map from `A^1_r` to `A^1_x`, it is constant. Therefore

```text
K_0 = R Gamma_c(A^1_r,Q_l) tensor delta_0
```

up to the standard shifts. Its Fourier transform is a constant sheaf on the dual line, again up to shift and Tate twist.

Thus `F_0` is not a neutral zero object. Any triangle that treats `F_0` as an innocuous punctual error is already using the wrong Fourier normalization.

### 6.2 The level h=1

Put `x=r+1`. Then

```text
f_1(r) = 1/(r+1)^3 = x^(-3).
```

On `G_m`, inversion identifies this cover with the cube map

```text
[3] : G_m -> G_m,
x -> x^3.
```

Over a geometric coefficient field containing the cubic roots of unity,

```text
[3]_* Q_l
 = Q_l direct_sum L_chi direct_sum L_{chi^(-1)},
```

where `chi` is a nontrivial cubic character.

Fourier transform sends the constant summand to `delta_0` and the two nontrivial Kummer summands to two Gauss-twisted Kummer sheaves on `G_m_t`. Therefore

```text
F_1|_{G_m_t}
 = G(chi,psi) tensor L_{chi^(-1)}
   direct_sum
   G(chi^(-1),psi) tensor L_chi,
```

up to shifts and the harmless inversion convention.

So even the augmentation part of `F_1` is geometrically reducible: it is a direct sum of two rank-one sheaves.

This is a literal counterexample to the proposed base case for irreducibility.

### 6.3 The level h=2

Here

```text
a_1(r) = P(r+1)/(r+2)^3,
b_1(r) = -(r+1)^3/(r+2)^3,
f_0=0.
```

Hence on `U_2`

```text
f_2(r) = a_1(r) f_1(r)
       = P(r+1)/((r+1)(r+2))^3.
```

At the exponential-sheaf level,

```text
E_2 = alpha_1^* E_1.
```

But `alpha_1(r,t)=(r,a_1(r)t)` depends on `r`. Therefore

```text
F_2 = R(pr_t)_! j_{2,!} alpha_1^*E_1
```

is not a pullback, convolution, extension, or cone formed from the already pushed-forward `F_1`.

The trace functions make the failure transparent:

```text
B_{1,t} = sum_r psi(t f_1(r)),
B_{2,t} = sum_r psi(t a_1(r) f_1(r)).
```

Knowledge of the first function of `t` does not determine the second. The moving multiplier `a_1(r)` is precisely the lost same-`r` information.

The boundary audit is also explicit:

- `r=-1` is the inherited pole of `f_1` and `f_2`.
- `r=-2` is the new denominator pole.
- roots of `P(r+1)` merely give `f_2(r)=0`; they are not degeneracy points of the linear map.

At good reduction, `f_1` has one triple pole and `f_2` has two triple poles. The generic Fourier ranks are therefore

```text
rank(F_1|_{t!=0}) = 2,
rank(F_2|_{t!=0}) = 6.
```

The first nontrivial step thus supplies no recurrence triangle and no irreducibility induction.

Verdict on Task 3: the proposed mechanism already breaks at `h=1 -> 2`.

## 7. Generic rank calculation and why End cannot collapse formally

Assume a good reduction pair `(p,h)` for which all `h` poles of `f_h` remain triple. For `t!=0`, the fiber of the Fourier sheaf is

```text
(F_h)_t = R Gamma_c(U_h, L_psi(t f_h))[1]
```

up to the standard normalization.

The open curve `U_h=P^1 minus h points` has

```text
chi_c(U_h,Q_l) = 2-h.
```

Each of the `h` poles contributes Swan conductor `3`. Grothendieck-Ogg-Shafarevich gives

```text
chi_c(U_h,L_psi(t f_h))
 = (2-h) - 3h
 = 2-4h.
```

For `t!=0`, the rank-one Artin-Schreier sheaf is geometrically nontrivial, so `H_c^0` and `H_c^2` vanish. Hence

```text
rank(F_h|_{t!=0}) = dim H_c^1 = 4h-2.
```

Therefore

```text
sum_{h=1}^H rank(F_h|_{t!=0})
 = sum_{h=1}^H (4h-2)
 = 2H^2.
```

For

```text
F_[1,H] = direct_sum_{h=1}^H F_h,
```

one has the generic rank identity

```text
rank End(F_[1,H]) = (2H^2)^2 = 4H^4.
```

This is a hard K-theoretic obstruction to the proposed rank collapse. A distinguished triangle can reorganize an object, but it cannot change the generic rank of the direct sum whose End sheaf enters the second moment.

Even an imaginary sequence of triangles

```text
F_{h+1} -> T_h(F_h,F_{h-1}) -> Error_h -> +1
```

would not imply

```text
dim H_c^*(End(F_[1,H])) = O(H^3).
```

The functor `End` is quadratic, and

```text
End( direct_sum_h F_h )
 = direct_sum_{h,k} Hom(F_h,F_k).
```

There are `H^2` pairwise Hom sheaves. Their generic ranks are of order `hk`, so the total generic rank is already of order `H^4`.

Off-diagonal `Hom_geom=0` would control only the invariant, or `H_c^2`, part responsible for extra `p`-sized main terms. It does not make the `H_c^1` error dimensions small. The COINC program needs both:

```text
1. component rigidity / Hom^0 vanishing, and
2. a family bound on the total H_c^1 conductor.
```

The recurrence supplies neither after pushforward.

If some poles cancel modulo `p`, the rank can drop. That does not rescue the proposed formal induction: the generic characteristic-zero or good-reduction member already has rank `4h-2`, so no sheaf-theoretic theorem derived solely from the recurrence can assert an `O(H^3)` End rank uniformly across the family.

Verdict on Task 2(c): FATAL. No End-collapse follows, and the generic rank arithmetic contradicts the hoped-for formal budget.

## 8. The precise formal implication of the recurrence

The recurrence gives one useful multiplicative identity in the Grothendieck group of relative exponential sheaves:

```text
[E_{h+1}]
 = [alpha_h^*E_h] [beta_h^*E_{h-1}]
```

where multiplication is tensor product.

It does not give an additive relation

```text
[F_{h+1}] = [F_h] + [F_{h-1}] + [errors].
```

Pushforward of a tensor product satisfies no formula in terms of the two separate pushforwards unless one has an independence or clean base-change theorem that reconstructs the same-`r` joint distribution. Proving such a theorem would be essentially the original family-compatibility problem in a new language.

In particular, the recurrence cannot be used as an induction that says `F_{h+1}` is an extension of old constituents. The operation depends on the rational functions `a_h(r),b_h(r)` and changes with `h`; it is not iteration of one fixed exact functor on a fixed category.

This is the categorical version of the clock obstruction found in Q6548.

## 9. Sharp first lemma: augmentation Hom equals fiber-product components

The first lemma I would prove and bank is not a recurrence triangle. It is the exact dictionary that identifies the true obstruction.

### Lemma [AUGMENTATION-HOM-DICTIONARY]

Let `h,k>=1`, and let `V` be a common geometric open subset of the value line over which both

```text
f_h : U_h -> A^1,
f_k : U_k -> A^1
```

are finite etale and have connected source. Put

```text
P_h = (f_h)_*Q_l|_V,
P_k = (f_k)_*Q_l|_V,
```

and let

```text
A_h = ker(trace_h : P_h -> Q_l),
A_k = ker(trace_k : P_k -> Q_l).
```

Let `c_{h,k}` be the number of geometric connected components of the fiber product

```text
U_h x_V U_k.
```

Then

```text
dim Hom_geom(A_h,A_k) = c_{h,k}-1.
```

If

```text
F_h^aug = FT_psi(j_!*A_h[1]),
F_k^aug = FT_psi(j_!*A_k[1]),
```

then Fourier equivalence gives

```text
dim Hom_geom(F_h^aug,F_k^aug) = c_{h,k}-1.
```

### Proof sketch

Choose a geometric basepoint of `V`. Let the geometric monodromy group act on the fibers

```text
Omega_h = f_h^(-1)(v),
Omega_k = f_k^(-1)(v).
```

The permutation local systems have fibers

```text
P_h(v) = Q_l[Omega_h],
P_k(v) = Q_l[Omega_k].
```

Therefore

```text
Hom(P_h,P_k)
 = ( Q_l[Omega_h]^vee tensor Q_l[Omega_k] )^G
 = Q_l[Omega_h x Omega_k]^G.
```

Its dimension is the number of monodromy orbits on `Omega_h x Omega_k`, which is exactly the number of geometric connected components of the fiber product.

Since each cover is connected,

```text
P_h = Q_l direct_sum A_h,
P_k = Q_l direct_sum A_k,
```

and neither augmentation representation has invariants. Hence

```text
Hom(P_h,P_k)
 = Hom(Q_l,Q_l) direct_sum Hom(A_h,A_k),
```

so

```text
dim Hom(A_h,A_k) = c_{h,k}-1.
```

Fourier-Deligne transform is an equivalence on the relevant perverse category, so it preserves Hom dimensions.

This lemma is formal, exact, and immediately useful.

Its hard geometric corollary target is:

```text
[PATH-COVER-RIGIDITY]
For h!=k outside an explicit exceptional list,
U_h x_V U_k is geometrically connected.
```

That statement is equivalent to primitive off-diagonal Hom vanishing. It is also exactly the component-control prerequisite for COINC identified in Q6548.

A proof would have to classify common geometric quotients of the rational covers `f_h` and `f_k`, using their ramification data, pole inertia, adjacent coprimality, and the explicit endpoint coefficients. The three-term recurrence may help compute those data, but it does not replace the common-quotient argument.

## 10. What remains potentially useful from qSELFREC

One piece should be kept.

### Bankable relative identity

Define on `U_h x A^1_t`

```text
E_h = L_psi(t f_h(r)).
```

Then on `U_{h+1} x A^1_t`:

```text
E_{h+1}
 = alpha_h^*E_h tensor beta_h^*E_{h-1}.
```

This can be cited as a relative Fourier recurrence. It may be useful for:

- recursively computing local monodromy at the newly added pole;
- proving formulas for Swan conductors and local Fourier transforms;
- comparing determinant characters;
- organizing an explicit stationary-phase decomposition level by level.

It does not by itself prove irreducibility, Hom orthogonality, or End compression.

The most plausible use is local, not global: determine the new local Fourier summand contributed by `r=-(h+1)` and test whether its character or refined Swan parameter distinguishes level `h+1` from every earlier level. If it does, it could provide a local-monodromy proof of some primitive Hom vanishings. Even then, the H_c^1 dimension problem for COINC remains.

## 11. Final task-by-task verdict

### Task 1

The algebraic map exists and is explicit:

```text
Psi_h(r;x,y) = (r; a_h(r)x+b_h(r)y).
```

It sends the same-`r` joint graph of `(f_h,f_{h-1})` to the graph of `f_{h+1}`.

Fourier transform converts this into pullback along the moving dual line

```text
t -> (a_h(r)t,b_h(r)t),
```

or equivalently the tensor identity for relative exponential sheaves.

There is no convolution operation on `K_h,K_{h-1}` alone and no distinguished triangle with terms `F_h,F_{h-1}`. The only canonical triangle is localization at the new pole.

Verdict: PARTIAL SURVIVAL, MAIN CLAIM KILLED.

### Task 2(a)

Full irreducibility is false because of the constant/punctual summand. The repaired augmentation object is still reducible at `h=1`.

Verdict: FATAL.

### Task 2(b)

Full Hom vanishing is false because of the shared punctual summand. Primitive Hom vanishing is equivalent to fiber-product connectedness and is not implied by recurrence.

Verdict: FATAL AS STATED; OPEN AFTER AUGMENTATION.

### Task 2(c)

At good reduction, the direct sum through level `H` has rank `2H^2`, so its End sheaf has rank `4H^4`. No formal triangle can collapse that generic rank.

Verdict: FATAL.

### Task 3

`F_1` is a reducible cubic-Kummer sum. The relation producing `f_2` is an `r`-dependent scaling before pushforward; it yields no triangle after pushforward. The only new boundary point is `r=-2`, not both `r=-1` and `r=-2` as new errors.

Verdict: FIRST CASE REFUTES THE INDUCTION.

### Task 4

The categorified recurrence is useful as a relative identity, but it does not plausibly deliver the stated irreducibility, Hom, or End-collapse goals.

Overall verdict:

```text
qSELFREC as a global sheaf induction for COINC: KILLED.
qSELFREC as a local-monodromy bookkeeping identity: SURVIVES.
First hard target: PATH-COVER-RIGIDITY / common-quotient classification.
```
