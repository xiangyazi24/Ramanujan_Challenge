PART 1. Near equality in mult(v) <= 3 p^(2/3-eps)

Continuant proof skeleton:

m_v = number of n with pi(n)=v.
Choose solutions:
 n_1 < ... < n_m.

For fixed v, the companion solution y^(v) satisfies a second order

 y^(v)(n_i)=0.

Split [0,p-2] into B blocks of length L:

B = p/L.

On one block:
number of zeros <= degree of continuant <= L.

Thus total collision pairs satisfy

sum_v binom(m_v,2)
 <= B * O(L^2) + cross-block contribution.

The optimized choice in the existing proof is

L = p^(1/3),

giving

m_v <= O(p/L + L^2)
     = O(p^(2/3)).

Near equality means both terms must saturate:

p/L ~ L^2

and

number of occupied blocks ~ p/L,

with almost every block contributing a maximal zero count.

Therefore a fiber with

m_v >= p^(2/3-eps)

#zeros in almost every block
 = L^(1-o(1)).

Equivalently the continuant polynomial for y^(v) must have
near-maximal zero density.

Required algebraic condition:

for most blocks I,

rank of the continuant evaluation map
on I

must drop by p^(-o(1)).

This is a very rigid condition. It is not implied by degree alone.

Current obstruction:
degree bound only says

number of zeros <= degree.

It gives no quantitative penalty for having degree-many zeros.

Need a transversality statement:

many zeros of y^(v)
=>
large gcd(continuant polynomial, shift family)
=>
rare v.

No such theorem is currently proved.


PART 2. Fiber counting theorem

#{m_v>T} << p^(3/2) T^(-2).

C=3/2,
D=2.

Desired improvement:

D>2

or

C<3/2.

Continuant route would need higher collision moments.

For k>=3:

sum_v (m_v)_k

counts k-tuples of indices with same fiber.

A possible target:

T_k := sum_v (m_v)_k

<< p^(1+delta_k).

Then

#{m_v>T} T^k
 <= T_k,

so

#{m_v>T}
 << p^(1+delta_k) T^(-k).

This gives

D=k.

The missing point is that the current continuant argument is single-fiber:

fix v,
count zeros.

A distribution theorem needs:

sum_v count_of_zero_patterns(v)

with cancellation over v.

No such cancellation is available from degree.
