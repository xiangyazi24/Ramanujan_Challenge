# 1. Candidate-by-candidate referee verdict

## 1.1 Exact Wronskian and master-sum reduction

**Status: PROVED, after corrections. This is core paper material.**

The exact Wronskian is

```text
a_n b_(n-1)-a_(n-1)b_n = 6/n^3.
```

For the integer vectors `A_n=d_n a_n`, `B_n=d_n b_n`, the safe adjacent determinant is

```text
A_(n+1)B_n-A_nB_(n+1)=6 d_n d_(n+1)/(n+1)^3.
```

Consequences include

```text
G_n G_(n+1) | 6 d_n d_(n+1)/(n+1)^3,
v_p(G_n)<=6 for sqrt(n)<p<=n,
G_n | 6 d_n^2/n^3.
```

The earlier claims `G_n|6d_n/n^3` and valuation cap `3` are false and must not appear.

For `p>sqrt(n)`, writing `n=qp+r`, the block congruence and the companion-height estimate isolate the only non-negligible channel. The exact master sum is

```text
M(n)=sum_(sqrt(n)<p<=n) log(p) 1_(p | b_(n mod p)).
```

The corrected reduction is

```text
log G_n <= 6M(n)+O(n^(2/3)),
M(n) <= log G_n+O(1).
```

Thus `M(n)=o(n)` is equivalent to the original theorem. This is a clean theorem, not merely a reformulation, because it also removes the small-prime and companion-numerator channels with effective error terms.

**Referee caveat.** The Lean file `Problem32/Wronskian.lean` is sorry-free in source, but the repository's generic fact-ledger script reported difficulty independently querying a private helper. Do not advertise a fully kernel-audited end-to-end gcd theorem. The paper proof of the Wronskian itself is elementary and should be written out.

## 1.3 Gessel digit criterion and exact cross-prime averaging

**Status: PROVED, with a precise scope. Core paper material.**

Gessel/Lucas gives

```text
b_(mp+r) = b_m b_r (mod p), 0<=r<p.
```

Iteration implies

```text
p | b_n
iff at least one base-p digit of n belongs to
Z_p={0<=r<p : p | b_r}.
```

In the top window `n/2<p<=n`, this collapses to the single digit `n-p` (apart from the harmless small-prime convention). Therefore

```text
TOP(n)=#{p in (n/2,n] : p | b_n}
```

satisfies the exact counting identity

```text
sum_(n<=X) TOP(n)
 = #{(p,r): r in Z_p, r>=1, p+r<=X}.
```

After boundary bookkeeping this identifies

```text
sum_(p<=X)|Z_p|=o(X)
```

with the unnormalized Cesàro `o(X)` statement for the **quotient-one/top-window contribution**.

What it does **not** do:

```text
- it is not equivalent to the every-n theorem;
- it sees only q=1 in n=qp+r;
- it supplies no anti-concentration for a fixed n;
- it does not prove AVG-ZERO.
```

The repository's unconditional record remains the degree-based

```text
sum_(p<=X)|Z_p| << X^(5/3)/log X.
```

This exact scope should be stated in the theorem title itself, for example “top-window Cesàro equivalence,” not “cross-prime equivalence to the main theorem.”

# 2. Dependency DAG in prose

## Layer A: standard arithmetic inputs

The Apéry recurrence, integrality of `d_n a_n` and `d_n b_n`, and Gessel/Lucas congruence are the base inputs. No result about critical values or fixed-prime energy is needed here.

## Layer B: corrected large-prime reduction

The shared recurrence gives the Wronskian. The Wronskian gives adjacent determinant divisibility and the valuation cap `6` for `p>sqrt(n)`. The block congruence

```text
p^3 a_(qp+r) = a_q b_r (mod p)
```

and the numerator-height bound for `a_q` remove the companion channel at total cost `O(n^(2/3))`. These inputs yield the exact master sum and the equivalence

```text
MAIN <=> M(n)=o(n).
```

This layer is independent of gap critical-value separation.

## Layer C: gap-continuant geometry

The transfer/continuant determinant defines `N_h`. Reflection, the symmetric tridiagonal pencil, strip localization, the exact pole values, and the restart identity establish:

```text
nonzero carriers,
controlled degree,
controlled logarithmic height,
all-height squarefreeness over Q.
```

Only the carrier nonvanishing and height estimates are needed for the gcd codegree theorem. The full squarefreeness/root census is mathematically valuable but stronger than necessary.

## Layer D: cross-level codegree

For two integers `m<n` in one dyadic block, set `h=n-m`. A prime counted in both master sums either is small relative to `h`, divides a no-wrap gap carrier, or divides an explicit wrap carrier. The Layer C height bounds show that the number of common eligible primes is `O(h)`.

This is the key bridge from a one-index master sum to a density-one theorem.

## Layer E: localized packing and exceptional set

Within an interval of length about `epsilon^2 N/log N`, exceptional integers each carry about `epsilon N/log N` primes. Cauchy gives a lower bound for the total pair load `sum_p binom(d_p,2)`, while Layer D bounds the same quantity by the sum of pairwise distances. Choosing the interval constant sufficiently small forces only `O_epsilon(1)` exceptional integers per interval. Dyadic summation yields `O_epsilon((log X)^2)`.

This is the end of the unconditional publishable chain.

## Layer F: digit/top-window branch

Gessel/Lucas independently gives the base-`p` digit criterion. Its quotient-one specialization gives the exact top-window identity and the Cesàro `[AVG-ZERO]` gateway. This branch explains the open problem but is not used to prove Layer E.

## Layer G: global CRT factorial-moment branch

The exact second factorial moment for `K_X(m)` follows from Chinese remaindering. It is independent of the codegree proof. It provides a clean conditional gateway:

```text
(HM)_k at the independence scale for one fixed k>6
    => pointwise master-sum bound
    => MAIN.
```

Only `k=2` is proved, and it is insufficient.

## Layer H: determinant/symplectic branch

The Casoratian identity feeds the chart-free determinant histogram. Orthogonality and exact moments produce conditional criteria for `[FR_eta]`. No proved estimate from this branch feeds Layers B--E. It is parallel research, not a dependency of the density-one theorem.

## Layer I: critical-value branch

Layer C also defines `delta_h=N_h/q_h^3`, its critical polynomial, and the reflection quotient. All-height squarefreeness plus exact reconstruction feed the Arb certificates for `h<=60`. An all-height theorem would require a correct connection/asymptotic separation theorem. This branch is independent of the gcd exceptional-set proof.

## Layer J: gcd-triangle/resultant branch

Restart and root sets feed the proposed gcd-triangle identities. The exact audit terminates at `H^(8/3)` and produces obstructions. There is no edge from this branch to the main theorem or to a subquadratic energy theorem.

# 5. Exact abstract-level wording

## Recommended abstract

> Let `a_n/b_n` be Apéry's rational approximants to `zeta(3)` and let `d_n=lcm(1,...,n)^3`. We study the common divisor `G_n=gcd(d_n a_n,d_n b_n)`. The conjectural estimate `log G_n=o(n)` for every `n` remains open. We prove a corrected large-prime reduction: up to an `O(n^(2/3))` contribution, `log G_n` is controlled by the exact master sum `sum_(sqrt(n)<p<=n) log p 1_(p|b_(n mod p))`. We introduce the associated gap continuants, prove reflection, root-strip, squarefreeness, renewal, and height properties, and use them to obtain a linear cross-level codegree bound. As a consequence, for every `epsilon>0`, `#{n<=X: log G_n>epsilon n}=O_epsilon((log X)^2)`. We also combine Gessel's digit congruence with an exact top-window averaging identity, reducing the average quotient-one problem to the cross-prime zero count `sum_(p<=X)|Z_p|`. These results give a quantitative density-one theorem but do not control a prescribed exceptional integer.

This wording is intentionally explicit that the main theorem is open and that the digit result is a quotient-one average statement.

> The argument does not prove `log G_n=o(n)` for every `n`. It leaves open both the pointwise anti-concentration problem for the prime-indexed sets `Z_p` and any improvement of `sum_(p<=X)|Z_p|<<X^(5/3)/log X`. The proved second factorial moment is insufficient for pointwise control, and no fixed power saving is currently known for the chart-free determinant mean. The exceptional-set theorem therefore permits an unspecified sequence of exceptional integers.

## Wording for the computer-assisted result, if mentioned

# 8. Bottom-line referee recommendation

A paper centered on `[MASTER-SUM] + [GAP-STRUCTURE] + [CODEGREE] + [EXCEPTIONAL-SET] + [DIGIT-TOP-AVG]` is coherent. It proves a quantitative density-one theorem, gives exact reductions for the remaining pointwise problem, and contains a substantial structural theory of the gap continuants.

A manuscript that additionally advertises determinant square-root cancellation, all-height critical-value separation, an exact Apéry connection constant, or a regular gcd-triangle theorem would presently overclaim. Those topics should be separated into conditional criteria, computational companions, conjectures, or failed-route appendices. The original Ramanujan Challenge Problem 3.2 must remain explicitly open in the title page, abstract, introduction, and conclusion.
