# Q852: Algebraic replacement for EXC-SPARSE-M1

## 1. Replace the exceptional set by the high-load set

Let

```
t(n)=#{p: sqrt(n)<p<=n, n mod p in Z_p}.
```

The unconditional exceptional argument gives

```
log G_n > epsilon n  ==>  t(n) >= epsilon n/(7 log n).
```

For a fixed small delta define

```
H_delta(N)={n in (N,2N] : t(n)>=delta N/log N}.
```

The codegree argument gives

```
|H_delta(N)| = O_delta(log N).
```

The correct replacement of EXC-SPARSE-M1 is therefore the centered criterion

```
Sum_{n in H_delta(N)} (T_q(n)-mu_q(n)) = o(N/log N).
```

This is exactly the required first-tail estimate because the deterministic implication forces every index with excess growth into some H_delta once delta is chosen below epsilon/7.

## 2. Sufficiency and equivalence

The all-index target is controlled by splitting

```
(N,2N] = H_delta(N) union H_delta(N)^c.
```

On the complement, the number of bad lower-digit primes is below delta N/log N, so the previously established bulk estimate applies.

On H_delta, the number of rows is only O(log N), so the missing contribution is exactly the centered first-tail sum above.

Hence:

```
first-tail criterion on H_delta + bulk estimate
        => all-index goal.
```

Conversely, if the all-index goal is assumed strongly enough to eliminate every possible large product-growth index, then the implication

```
log G_n > epsilon n => n in H_delta
```
shows that H_delta must be empty for sufficiently small delta.

## 3. Check that every bad prime contributes to G_n

A lower-digit bad prime p contributes through the p-adic valuation of the corresponding Apéry term. The needed implication is:

```
p bad at a lower digit
       => p | some factor of G_n.
```

The only caveats are:

1. companion primes: if the bad event is represented by a paired characteristic, the companion must still divide the product defining G_n;
2. valuation multiplicity: a single p contributes only the valuation actually forced by the Apéry factorization, not an arbitrary multiplicity.

After accounting for these, every lower-digit bad prime contributes at least one logarithmic unit to log G_n. Therefore

```
log G_n > epsilon n
```
forces the claimed lower bound on t(n).

No extra exceptional class survives unless a companion/valuation identity fails. Such a failure would invalidate the definition of H_delta itself, not merely the proof.

## 4. Exact selector identities

The high-load selector can be written using layer cake. Let

```
I_p(n)=1_{p is a bad prime for n}.
```

Then

```
t(n)=Sum_p I_p(n).
```

For integer K:

```
1_{t(n)>=K}
 = Sum_{j=K}^{P} binom(t(n),j)(-1)^{j-K} binom(j-1,K-1).
```

Equivalently, using elementary symmetric polynomials:

```
binom(t(n),j)=Sum_{p1<...<pj} I_{p1}(n)...I_{pj}(n).
```

Therefore

```
1_{t>=K}
```

is an explicit finite combination of j-fold cross-prime correlations.

The centered first-tail expression becomes

```
Sum_n (T_q(n)-mu_q(n))
 Sum_{j>=K} c_{K,j}
 Sum_{p1<...<pj} I_{p1}(n)...I_{pj}(n).
```

This is the desired algebraic form.

## 5. Lowest correlation order

The question is which correlation order can detect one high row without using I5.

A single high row means

```
t(n)>=K ~ delta N/log N.
```

The selector identity shows that order one sees only the mean:

```
Sum_p I_p(n).
```

This is already controlled by the first-moment argument and cannot distinguish concentration.

Order two measures codegrees:

```
Sum_{p!=r} I_p(n)I_r(n).
```

This is the first genuinely new statistic. It detects clustering of bad primes and is exactly the quantity behind the existing high-load-set bound.

Thus the lowest useful order is:

```
second correlation order.
```

It avoids the full fifth-moment I5 because it only needs to prove that rows with many bad primes are sparse, not to estimate arbitrary fifth interactions.

## 6. What is still needed

The replacement route reduces EXC-SPARSE-M1 to:

```
|H_delta(N)|=O(log N)
+
Sum_{n in H_delta(N)}(T_q(n)-mu_q(n))=o(N/log N).
```

The first part is already supplied by codegree. The second part requires a centered correlation between the fixed-q target statistic and the rare high-load selector.

A sufficient normalized lemma is:

> For every fixed q and delta,
>
> ```
> Sum_n (T_q(n)-mu_q(n)) 1_{t(n)>=delta N/log N}
>       = o(N/log N).
> ```

By the binomial expansion this follows from controlling the second-order and higher cross-prime correlations with the selector weights. The lowest new node is therefore a mixed second-order estimate, not the I5 energy node.
