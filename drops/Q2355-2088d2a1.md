## 3. Where the quadratic polynomial really appears

Write

\[
\begin{aligned}
P(r+1)&=(2r+3)(17r^2+51r+39),\\
P(r+2)&=(2r+5)(17r^2+85r+107),\\
Q_1(r)&=(2r+3)(3r^2+5r+3),\\
Q_2(r)&=(2r+5)(3r^2+7r+7).
\end{aligned}
\]

Since the same \(-(r+2)^6\) occurs in both continuants,

\[
N_3-\mathcal R_2=P(r+1)P(r+2)-Q_1Q_2.
\]

The difference of the two quartic factors is

\[
\begin{aligned}
&(17r^2+51r+39)(17r^2+85r+107)\\
&\qquad -(3r^2+5r+3)(3r^2+7r+7)\\
&=4(r+2)(r+3)(70r^2+219r+173).
\end{aligned}
\]

Therefore

\[
\boxed{
N_3-\mathcal R_2
=4(2r+3)(2r+5)(r+2)(r+3)
 (70r^2+219r+173).
}
\tag{3.1}
\]

Define

\[
\boxed{H(r)=70r^2+219r+173.}
\tag{3.2}
\]

In the P3.2 first-half range

\[
0\le r<r+3\le\frac{p-1}{2},

all four linear factors in (3.1) are units for odd \(p\).  Hence a common root of \(N_3\) and \(\mathcal R_2\) in that range necessarily satisfies

\[
H(r)=0.
\]

This is the natural degree-2 reduction alluded to in the prompt.  It is a necessary common-root condition, not the Racah continuant itself.

For this reduced pair one has

\[
\boxed{\gcd_{\mathbb Z[r]}(N_3,H)=1}

\tag{3.3}

It has the same exceptional-prime set as the full resultant.

## 4. GCD and full resultant

Both polynomials (1.1) and (2.1) are primitive.  Exact Euclidean reduction over \(\mathbb Q[r]\) gives

\[
\gcd_{\mathbb Q[r]}(N_3,\mathcal R_2)=1.
\]

Gauss's lemma therefore gives

\[
\boxed{\gcd_{\mathbb Z[r]}(N_3,\mathcal R_2)=1.}
\tag{4.1}
\]

The full resultant can be checked transparently from (3.1), rather than only by displaying a black-box Sylvester determinant.

The relevant linear resultants are

\[
\begin{aligned}
\operatorname{Res}(N_3,2r+3)&=2^6N_3(-3/2)=-1,\\
\operatorname{Res}(N_3,2r+5)&=2^6N_3(-5/2)=-1,\\
\operatorname{Res}(N_3,r+2)&=N_3(-2)=-25,\\
\operatorname{Res}(N_3,r+3)&=N_3(-3)=584=2^3\cdot73.
\end{aligned}
\tag{4.2}
\]

Resultants are unchanged by replacing the second polynomial by its difference with the first, so

\[
\operatorname{Res}(N_3,\mathcal R_2)
=\operatorname{Res}(N_3,\mathcal R_2-N_3).
\]

Using multiplicativity, (3.1), (3.3), and (4.2),

\[
\begin{aligned}
\operatorname{Res}(N_3,\mathcal R_2)
&=2^{12}(-1)(-1)(-25)(584)
  \operatorname{Res}(N_3,H)\\
&=-2^{18}5^7\,7\,61^2\,73^3.
\end{aligned}
\]

Thus

\[
\boxed{
\operatorname{Res}_r(N_3,\mathcal R_2)
=-2^{18}5^7\,7\,61^2\,73^3
=-207518224363520000000.
}
\tag{4.3}
\]

Since this integer is nonzero, the characteristic-zero GCD is indeed 1.  Since every prime divisor is at most 73,

\[
\boxed{
p>73\quad\Longrightarrow\quad
N_3,\mathcal R_2
\text{ have no common root modulo }p.
}
\tag{4.4}
\]

This conclusion is stronger than absence of an \(\mathbf F_p\)-root: for \(p\nmid\operatorname{Res}\), the reductions are coprime over \(\overline{\mathbf F}_p\).

## 5. Exact exceptional-prime root audit

Only

\[
p\in\{2,5,7,61,73\}
\]

can remain.  Direct reduction gives the following complete list of common roots in the prime field.

| \(p\) | roots \(r\in\mathbf F_p\) of \(N_3=\mathcal R_2=0\) | endpoint Apéry residues | P3.2 status |
|---:|:---|:---|:---|
| 2 | \(r=1\) | \((b_1,b_4)=(1,1)\) | characteristic excluded; not a zero pair |
| 5 | \(r=3\) | \((b_3,b_6)=(0,0)\) | degenerate: \(r+2=0\), \(r+3>p-1\) |
| 7 | none in \(\mathbf F_7\) | — | no prime-field common root |
| 61 | \(r=8,49\) | \((b_8,b_{11})=(12,7)\), \((b_{49},b_{52})=(7,12)\) | neither is a zero pair |
| 73 | \(r=70=-3\) | \((b_{70},b_{73})=(0,5)\) | wrapping endpoint \(r+3=p\); not a zero pair |

Here all endpoint values are modulo the displayed prime.

Some quick exact checks explain the table.

### Prime \(61\)

The reduced quadratic is

\[
H(r)\equiv 3(3r^2+12r+17)\pmod{61},
\]

whose roots are

\[
r=8,49.
\]

Both also satisfy \(N_3=0\), but

\[
b_8\equiv12,\qquad b_{11}\equiv7\pmod{61}.
\]

The Apéry reflection symmetry gives

\[
b_{49}\equiv b_{11}\equiv7,
\qquad
b_{52}\equiv b_8\equiv12\pmod{61}.
\]

Only \(r=8\) is in the folded first half, and it already fails the endpoint-zero condition.

### Prime \(73\)

Modulo 73,

\[
H(r)\equiv-3(r^2-9),
\]

but only \(r=-3=70\) is a root of the full pair.  It is the boundary factor \(r+3=0\).  Moreover

\[
b_{70}\equiv b_2\equiv0\pmod{73},
\]

while directly from the binomial definition

\[
b_p\equiv1+\binom{2p}{p}^2\equiv1+2^2=5\pmod p,
\]

so

\[
b_{73}\equiv5\pmod{73}.
\]

### Prime \(5\)

The root \(r=3=-2\) is caused by the factor \(r+2\).  Indeed

\[
b_3=1445\equiv0,
\qquad
b_6=21460825\equiv0\pmod5.
\]

But

\[
(r+1)_3=(r+1)(r+2)(r+3)\equiv0\pmod5,
\]

so Q2337's factorization

\[
K(r,r+3)
=-\frac{r^3b_{r-1}}{6(r+1)_3^3}\mathcal R_2(r)
\]

cannot be used there.  This is exactly why the nonwrapping hypothesis must be retained.

## 6. Reproducible exact scan for all primes below \(10000\)

The following Sage code performs the polynomial computation, factors the resultant, scans every prime below 10000, and checks the Apéry endpoint condition in both the full nonwrapping range and the folded first-half range.

```sage
R.<r> = PolynomialRing(ZZ)

P = lambda t: 34*t^3 + 51*t^2 + 27*t + 5
Q = lambda m: (2*r + 2*m + 1) * (
    3*r^2 + 2*r*m + m^2 + 3*r + m + 1
)

N3 = (P(r + 1) * P(r + 2) - (r + 2)^6).expand()
R2 = (Q(2) * Q(1) - (r + 2)^6).expand()
H  = 70*r^2 + 219*r + 173

assert N3 == (
    1155*r^6 + 13860*r^5 + 68535*r^4 + 178680*r^3
    + 259059*r^2 + 198156*r + 62531
)
assert R2 == (
    35*r^6 + 276*r^5 + 911*r^4 + 1644*r^3
    + 1715*r^2 + 984*r + 251
)
assert N3 - R2 == 4*(2*r+3)*(2*r+5)*(r+2)*(r+3)*H

assert gcd(N3, R2) == 1
assert gcd(N3, H) == 1

res_full = N3.resultant(R2)
res_quad = N3.resultant(H)

assert res_full == -2^18 * 5^7 * 7 * 61^2 * 73^3
assert res_quad ==  2^3  * 5^5 * 7 * 61^2 * 73^2

print(factor(res_full))
print(factor(res_quad))

# Compute b_0,...,b_{p-1} modulo p.  The denominator (n+1)^3
# is invertible throughout n=1,...,p-2.
def apery_row_mod_p(p):
    F = GF(p)
    b = [F(1), F(5)]
    for n in range(1, p-1):
        b.append(
            (F(P(n))*b[n] - F(n)^3*b[n-1]) / F(n+1)^3
        )
    return b

root_table = []
nonwrapping_endpoint_data = []
nonwrapping_zero_pairs = []
folded_zero_pairs = []

for p in prime_range(2, 10000):
    if res_full % p != 0:
        continue

    F = GF(p)
    Np = N3.change_ring(F)
    Rp = R2.change_ring(F)
    roots = [a for a in range(p)
             if Np(F(a)) == 0 and Rp(F(a)) == 0]
    root_table.append((p, roots))

    b = apery_row_mod_p(p)
    for a in roots:
        if a + 3 < p:
            data = (p, a, ZZ(b[a]), ZZ(b[a+3]))
            nonwrapping_endpoint_data.append(data)
            if b[a] == 0 and b[a+3] == 0:
                nonwrapping_zero_pairs.append((p, a))

            if a + 3 <= (p - 1)//2 and b[a] == 0 and b[a+3] == 0:
                folded_zero_pairs.append((p, a))

print(root_table)
print(nonwrapping_endpoint_data)
print(nonwrapping_zero_pairs)
print(folded_zero_pairs)
```

```text
-1 * 2^18 * 5^7 * 7 * 61^2 * 73^3
2^3 * 5^5 * 7 * 61^2 * 73^2
[(2, [1]), (5, [3]), (7, []), (61, [8, 49]), (73, [70])]
[(61, 8, 12, 7), (61, 49, 7, 12)]
[]
[]
```

For the literal unrestricted check, evaluating the integer Apéry binomial sum at the roots above gives only

```text

```

and, as explained, this is outside the Q2337/P3.2 hypotheses.

## 7. Gap-3 theorem obtained

Assume the Q2337 hypotheses, in particular an odd prime \(p\), a nonwrapping pair, and

\[
0<r<r+3\le\frac{p-1}{2}.
\]

Suppose

\[
b_r=b_{r+3}=0\pmod p.
\]

The Apéry gap-continuant identity gives

\[
N_3(r)=0\pmod p.
\]

If also

\[
K(r,r+3)=0\pmod p,
\]

then Q2337, together with the no-consecutive-zero fact and invertibility of \((r+1)_3\), gives

\[
\mathcal R_2(r)=0\pmod p.
\]

For \(p>73\), this contradicts the nonzero resultant.  For the exceptional primes, the table above shows that no folded common root is an Apéry zero pair.  Therefore

\[
\boxed{
 b_r=b_{r+3}=0,
 \quad 0<r<r+3\le\frac{p-1}{2}
 \quad\Longrightarrow\quad
 K(r,r+3)\ne0\pmod p.
}
\tag{7.1}
\]

So **gap 3 is closed** by the Q2337 two-continuant reduction plus this finite resultant audit.
