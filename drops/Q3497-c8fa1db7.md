# 7. Height ledger: source coefficients versus evaluated values

This distinction is essential.

## 7.1 Source coefficient height

The coefficients of `Z_K` are

```text
-(X+K), X, K+2,
```

hence `O(m)` on q=6 cells.  The coefficients of `Y_K=Z_(K+1)-Z_K` are also polynomial in `m`.  A fixed number of boundary sources therefore has

```text
log ||source coefficients|| = O(log m).             (7.1)
```

Even a long telescope

```text
sum_(K=u)^(v-1) Y_K = Z_v-Z_u                       (7.2)
```

collapses at the **source** level to two three-site sources, so its coefficient height is still `O(log m)`.

This does **not** imply that its value has small height.

## 7.2 Evaluated height at the nonlegal seam

The value of `(7.2)` is

```text
A_s(v)-A_s(u).                                      (7.3)
```

When `v` is at the selector seam / legal lower boundary, `v=Theta(m)`.  The cutoff value `q_v` is an accumulated Newton truncation of length `Theta(m)`.  No current theorem bounds `(7.3)` by `exp(o(m))`.  The existing Green/transfer work is precisely a no-go for obtaining that conclusion from homogeneous transfer alone.

Thus the minimal boundary extension has cheap **source coefficients** but does not have a proved cheap **evaluated boundary value**.

## 7.3 Bounded first-copy values really do have o(m) evaluated height

The first-copy cutoffs satisfy `(2.6)`.  Keep them as cutoff values.  For fixed bounded `K`,

```text
T_(s,K)
 = sum_(r=0)^(K-1)
     (Delta^r y)_0 * binom(-X_s,r).                 (7.4)
```

This is a bounded-length integer sum.  Each forward difference in `(7.4)` is itself a bounded linear combination of

```text
b_(sigma_s+s t),  0<=t<=K-1,
```

whose indices are `O(H+1)` at the first copy.  The binomial coefficients in `(7.4)` have fixed degree in `X_s=O(m)`.  Therefore

```text
log^+ |T_(s,K_first)| = O(H+log m),
log^+ |Q_(s,K_first)| = O(H+log m),                 (7.5)
```

and any fixed polynomial-height combination of these cutoff values has the same bound.  When `H=o(m)`, this is `o(m)`.

This proof does **not** replace `T_(s,K)` by a physical sample; it bounds the actual finite Newton sum.

The missing theorem is therefore exactly a bridge from the high evaluated seam class `(7.3)` to a bounded-cutoff functional of the form `(7.5)`.

# 8. The next strictly smaller missing lemma

Equation `(4.4)` shows that one boundary source is still target-divisible.  The first place where the forced target factor can disappear is the immediately preceding source.  If `A_s=r_s+1`, equation `(2)` gives the exact residue

```text
boxed:
8 D_s(A_s-2)
 = 8 D_s(r_s-1)
 == U_(s,r_s)
    [ r_s d_(s,r_s-1)+(1-r_s)d_(s,r_s) ]            (mod p).      (8.1)
```

The `(19,8,122)` certificate `(6.1)` proves that `(8.1)` is genuinely nonzero for the actual Apery sequence.  Hence the next step cannot be “adjoin one more boundary source on each slope independently”: that would make the enlarged slope kernel a `p`-unit at an actual target and destroy the target ideal.

The next missing lemma must therefore be **paired and cross-slope**.  A minimal proof target is:

> **Paired first-pre-seam lemma.**  There exist integer coefficients
> `u_4(m,H),u_7(m,H)` of `exp(o(m))` height, both units on the q=6 core,
> and a bounded-first-copy functional
>
> ```text
> B_1(m,H)
> = sum_(i=0)^R7 alpha_i(m,H) Q_7(L_0+i)
>   - sum_(j=0)^R4 beta_j(m,H) Q_4(K_0+j),           (8.2)
> ```
>
> with fixed `R_4,R_7`, polynomial-height integer coefficients,
> `B_1 != 0`, such that the first omitted paired seam charge satisfies
>
> ```text
> u_7 D_7(A_7-2) - u_4 D_4(A_4-2) - B_1(m,H)
>     in I_min.                                      (8.3)
> ```
>
> Equivalently, after reducing at an endpoint target prime, the two
> bracketed actual-Apery expressions in `(8.1)` cancel against one
> bounded-cutoff scalar before any separate slope denominator is cleared.

The height conclusion for `B_1` would then be automatic from `(7.5)`:

```text
log^+|B_1(m,H)|=O(H+log m)=o(m).                    (8.4)
```

This is **strictly smaller** than solving the full aligned ANT-28/Ore problem: it asks only for cancellation of the first layer that survives the one-row extension.  Conversely, it is stronger than merely checking another boundary row, because `(6.1)` proves that separate slope-wise extension is false.

If `(8.3)` fails, the next obstruction is explicit and local.  If `(8.3)` holds uniformly, it gives the first genuine mechanism for peeling the first-copy primorial one seam at a time without paying the full selector product.

# Bottom line

The legal-kernel telescope is real, and the first added boundary source is unusually benign: it crosses the selector hit without losing the target factor.  But it does **not** remove the nonlegal first-copy class.  The valuation-one fixture `(440,73,2)` leaves residue `5` after the legal kernels and both minimal boundary generators are removed.

So there is no positive theorem of the form “one boundary row per slope already turns `E_gap` into the required low characteristic-zero scalar” from the current identities.  Any such scalar would be a **new** identity.  The smallest place to look is not another full Green solve and not another separate slope extension; it is the paired first-pre-seam charge `(8.1)`, with a bounded-cutoff representative as in `(8.2)-(8.3)`.
