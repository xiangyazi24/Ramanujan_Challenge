# Q3539 — summand-level Lucas blocks for the q=6 Apéry kernel

## Bottom line

Yes.  In fact, for the specific arithmetic asked for here, one does **not** need to force the Apéry \({}_4F_3\) through an Andrews transformation first.  The Apéry summand itself already has the required base-\(p\) tensor product.

Put

\[
L(n,k)=\binom nk\binom{n+k}{k},\qquad
F(n,k)=L(n,k)^2,
\]

so that

\[
b_n=\sum_{k=0}^n F(n,k).
\]

Let \(p>6\), \(0\le j<p\), \(m=6p+j\), and write

\[
k=ap+b,\qquad 0\le a\le6,\quad 0\le b<p,
\]

with the convention \(F(n,k)=0\) for \(k>n\).  Then coefficientwise

\[
\boxed{
F(6p+j,ap+b)\equiv F(6,a)F(j,b)\pmod p.
}
\tag{1}
\]

Consequently, if

\[
S_a(p,j)=\sum_{b=0}^{p-1}F(6p+j,ap+b),
\]

then

\[
\boxed{
S_a(p,j)\equiv F(6,a)b_j\pmod p
\qquad (0\le a\le6).
}
\tag{2}
\]

In particular the first block is exactly

\[
\boxed{
S_0(p,j)=\sum_{b=0}^{p-1}F(6p+j,b)\equiv b_j\pmod p.
}
\tag{3}
\]

So the proposed “something” is not merely controlled: for the first block it is exactly **1** modulo \(p\).

```text
FIRST-BLOCK DETECTOR

S_0(p,j) := sum_{0 <= b < p} C(6p+j,b)^2 C(6p+j+b,b)^2

S_0(p,j) ≡ b_j (mod p).

Hence

        p | S_0(p,j)   <=>   p | b_j.

More generally

        S_a(p,j) ≡ F(6,a) b_j (mod p),   a=0,...,6.
```

This is exactly the moving Apéry-zero activation that Q3539 asks for.  It occurs at the **block-sum level before any global denominator clearing**.

The important qualification is that the block boundary \(p\) is itself prime-dependent.  Thus (3) is an excellent local arithmetic identity, but by itself it is not yet the prime-independent, subexponential-height FC-28 source.

## 1. Exact block decomposition

The change of variables \(k=ap+b\) gives the characteristic-zero identity

\[
\boxed{
b_{6p+j}=\sum_{a=0}^{6}S_a(p,j)}
\tag{4}
\]

where, explicitly,

\[
S_a(p,j)=\sum_{b=0}^{p-1}
 \binom{6p+j}{ap+b}^{\!2}
 \binom{(6+a)p+j+b}{ap+b}^{\!2}.
\tag{5}
\]

For \(a=6\), the terms \(b>j\) are simply zero because \(6p+b>6p+j\).

This is only a reindexing in characteristic zero.  The arithmetic enters after reducing each block modulo \(p\).

---

## 2. Proof of the summand-level factorization

For the first binomial, Lucas immediately gives

\[
\binom{6p+j}{ap+b}
\equiv
\binom6a\binom jb
\pmod p.
\tag{6}
\]

For the second binomial there are two cases.

### No low-digit carry: \(j+b<p\)

Then

\[
(6p+j)+(ap+b)=(6+a)p+(j+b),
\]

so Lucas gives

\[
\binom{(6+a)p+j+b}{ap+b}
\equiv
\binom{6+a}{a}\binom{j+b}{b}
\pmod p.
\tag{7}
\]

### Low-digit carry: \(j+b\ge p\)

Now

\[
(6+a)p+j+b=(7+a)p+(j+b-p).
\]

Since

\[
j+b-p<b
\]

(because \(j<p\)), the low Lucas digit on the left is zero.  On the right, \(\binom{j+b}{b}\equiv0\pmod p\) for exactly the same one-carry reason.  Hence (7) is still valid modulo \(p\).

Likewise, when \(b>j\), both sides of (6) vanish modulo \(p\).

Multiplying (6) and (7), and then squaring, gives

\[
F(6p+j,ap+b)
\equiv
\left(\binom6a\binom{6+a}{a}\right)^2
\left(\binom jb\binom{j+b}{b}\right)^2
\pmod p,
\]

which is exactly (1).

This is the square-kernel analogue of the factorization already used in the repository note

`problems/3.2/research/proofs/Q32_ALL_CUTOFF_BLOCK_AND_LOSS_PROOF.md`,

where the unsquared polynomial

\[
Q_n(t)=\sum_k L(n,k)t^k
\]

satisfies

\[
Q_{qp+r}(t)\equiv Q_q(t^p)Q_r(t)\pmod p.
\]

So the new observation is completely compatible with the current P3.2 Lucas-block machinery; here we simply apply the same digit factorization to \(L(n,k)^2\).

## 3. Polynomial form: the block matrix has rank one modulo p

Define the Apéry kernel polynomial

\[
R_n(t)=\sum_{k=0}^{n}F(n,k)t^k.
\]

For \(q<p\), the same proof gives

\[
\boxed{
R_{qp+r}(t)\equiv R_q(t^p)R_r(t)\pmod p.
}
\tag{8}
\]

Thus at quotient six,

\[
\boxed{
R_{6p+j}(t)\equiv R_6(t^p)R_j(t)\pmod p.
}
\tag{9}
\]

An even more literal high-digit/low-digit encoding is

\[
\boxed{
\sum_{a=0}^{6}\sum_{b=0}^{p-1}
F(6p+j,ap+b)X^aY^b
\equiv
\left(\sum_{a=0}^{6}F(6,a)X^a\right)
\left(\sum_{b=0}^{p-1}F(j,b)Y^b\right)
\pmod p.
}
\tag{10}
\]

Thus the \(7\times p\) matrix of summands, indexed by the high digit \(a\) and low digit \(b\), is an outer product modulo \(p\).

Setting \(Y=1\) gives the block-sum polynomial

\[
\boxed{
\sum_{a=0}^{6}S_a(p,j)X^a
\equiv b_j R_6(X)\pmod p.
}
\tag{11}
\]

The seven fixed coefficients are

\[
\begin{array}{c|r}
a&F(6,a)\\ \hline
0&1\\
1&1764\\
2&176400\\
3&2822400\\
4&9922500\\
5&7683984\\
6&853776
\end{array}
\]

and indeed

\[
\sum_{a=0}^{6}F(6,a)=21460825=b_6.
\]

Summing (2) over \(a\) recovers the familiar Lucas congruence

\[
b_{6p+j}\equiv b_6b_j\pmod p,
\]

but (2) is strictly more informative: it says the Lucas congruence holds **block by block**.

For every prime \(p\ge13\), all seven numbers \(F(6,a)\) are \(p\)-units.  Hence for those primes

\[
\boxed{
p\mid S_a(p,j)\quad\Longleftrightarrow\quad p\mid b_j
\qquad\text{for every }a=0,\dots,6.}
\tag{12}
\]

For \(a=0\), the equivalence is valid already for every \(p>6\), because \(F(6,0)=1\).

## 4. Exact characteristic-zero divisibility statement

Equation (2) implies that

\[
E_a(p,j):=rac{S_a(p,j)-F(6,a)b_j}{p}
\tag{13}
\]

is an integer.  Therefore there is an **exact** identity

\[
\boxed{
S_a(p,j)=F(6,a)b_j+pE_a(p,j),\qquad E_a(p,j)\in\mathbb Z.
}
\tag{14}
\]

At a valuation-one target

\[
b_j=p\eta,\qquad \eta\not\equiv0\pmod p,
\]

this becomes

\[
\boxed{
S_a(p,j)=p\bigl(F(6,a)\eta+E_a(p,j)\bigr).
}
\tag{15}
\]

So the desired moving condition is genuinely present in an integer block sum before any external denominator clearing.

However, (15) also displays the next obstruction: to recover the singular coordinate \(\eta=b_j/p\), one has to control the block error \(E_a\) modulo \(p\).  The zeroth-order Lucas factorization alone does not do that.

## 5. The first block one order deeper

The first block can be expanded explicitly modulo \(p^2\).  This is useful because it shows exactly what is hidden behind the clean congruence (3).

Let

\[
h=\min(j,p-1-j),
\]

and let \(H_r=\sum_{s=1}^r1/s\), \(H_0=0\).  For \(0\le b\le h\), no carry occurs in either binomial.  We have

\[
\binom{6p+j}{b}
=\binom jb
\prod_{s=j-b+1}^{j}\left(1+\frac{6p}{s}\right)
\equiv
\binom jb\left[1+6p(H_j-H_{j-b})\right]
\pmod{p^2},
\tag{16}
\]

and

\[
\binom{6p+j+b}{b}
=\binom{j+b}{b}
\prod_{s=j+1}^{j+b}\left(1+\frac{6p}{s}\right)
\equiv
\binom{j+b}{b}\left[1+6p(H_{j+b}-H_j)\right]
\pmod{p^2}.
\tag{17}
\]

After squaring and multiplying,

\[
\boxed{
F(6p+j,b)
\equiv
F(j,b)\left[1+12p(H_{j+b}-H_{j-b})\right]
\pmod{p^2}.
}
\tag{18}
\]

If \(b>j\), the first binomial has a carry and its square is divisible by \(p^2\).  If \(b\le j\) but \(j+b\ge p\), the second binomial has a carry and again its square is divisible by \(p^2\).  Therefore only \(b\le h\) matters modulo \(p^2\).

Define

\[
C_0(p,j)=
\sum_{b=0}^{h}
F(j,b)\bigl(H_{j+b}-H_{j-b}\bigr)
\in\mathbb Z_{(p)}.
\tag{19}
\]

Then

\[
\boxed{
S_0(p,j)\equiv b_j+12p\,C_0(p,j)\pmod{p^2}.
}
\tag{20}
\]

At a valuation-one zero \(b_j=p\eta\),

\[
\boxed{
\frac{S_0(p,j)}p
\equiv
\eta+12C_0(p,j)
\pmod p.
}
\tag{21}
\]

Thus the first block detects the zero perfectly modulo \(p\), but its divided value is **not** simply \(\eta\): there is a first-jet harmonic correction.

That is precisely where a genuine Krattenthaler–Rivoal-style transformation could still add value: not to create the mod-\(p\) divisibility, which is already present, but to rewrite or cancel the harmonic correction in (21) before expensive denominator clearing.

## 6. Stronger fact: all seven block quotients are affine in a modulo p

There is a useful q=6 first-jet formula that makes the prospective FSZ/Vandermonde step completely explicit.

Assume \(p\ge13\).  This ensures \(6+a<p\) for \(0\le a\le6\), so the high digits introduce no second base-\(p\) carry.  For the no-carry low-digit range \(0\le b\le h\), the standard first-order digit expansion gives

\[
\binom{6p+j}{ap+b}
\equiv
\binom6a\binom jb
\left[1+p\{6H_j-aH_b-(6-a)H_{j-b}\}\right]
\pmod{p^2},
\tag{22}
\]

and

\[
\binom{(6+a)p+j+b}{ap+b}
\equiv
\binom{6+a}{a}\binom{j+b}{b}
\left[1+p\{(6+a)H_{j+b}-aH_b-6H_j\}\right]
\pmod{p^2}.
\tag{23}
\]

(One may obtain these by factoring off \(\binom{6p}{ap}\) and \(\binom{(6+a)p}{ap}\); the latter high-digit binomials agree with \(\binom6a\) and \(\binom{6+a}a\) modulo \(p^2\) by the usual Jacobsthal/Ljunggren binomial congruence.)

Adding the two first-order logarithmic corrections, and then squaring, yields

\[
F(6p+j,ap+b)
\equiv
F(6,a)F(j,b)
\left[1+2pD_{a,b}\right]
\pmod{p^2},
\tag{24}
\]

where

\[
\begin{aligned}
D_{a,b}
&=(6+a)H_{j+b}-(6-a)H_{j-b}-2aH_b\\
&=6\bigl(H_{j+b}-H_{j-b}\bigr)
+a\bigl(H_{j+b}+H_{j-b}-2H_b\bigr).
\end{aligned}
\tag{25}
\]

Define the second residue sum

\[
C_1(p,j)=
\sum_{b=0}^{h}
F(j,b)\bigl(H_{j+b}+H_{j-b}-2H_b\bigr)
\in\mathbb Z_{(p)}.
\tag{26}
\]

The carry terms again vanish modulo \(p^2\) after squaring.  Summing (24) gives

\[
\boxed{
S_a(p,j)
\equiv
F(6,a)\left[
 b_j+p\{12C_0(p,j)+2aC_1(p,j)\}
\right]
\pmod{p^2}.
}
\tag{27}
\]

At a valuation-one zero \(b_j=p\eta\), all \(F(6,a)\) are \(p\)-units for \(p\ge13\), and therefore

\[
\boxed{
F(6,a)^{-1}\frac{S_a(p,j)}p
\equiv
\underbrace{\eta+12C_0(p,j)}_{\text{intercept}}
+2a\,C_1(p,j)
\pmod p.
}
\tag{28}
\]

This is a particularly clean structural statement:

> **The seven normalized block quotients lie on an affine line in the block index \(a\) modulo \(p\).**

Equivalently, every normalized second finite difference vanishes:

\[
F(6,a+2)^{-1}\frac{S_{a+2}}p
-2F(6,a+1)^{-1}\frac{S_{a+1}}p
+F(6,a)^{-1}\frac{S_a}p
\equiv0\pmod p.
\tag{29}
\]

This is exactly the kind of fixed-dimensional structure on which generalized Vandermonde/Schur elimination is strongest.

But it also gives a sharp no-go for the **blocks alone**: a Vandermonde elimination in \(a\) can remove the slope \(C_1\), but it cannot separate

\[
\eta
\quad\text{from}\quad
12C_0(p,j),
\]

because they multiply the same constant vector \(F(6,a)\).  In other words, the first-order block space has only the two fixed high-digit directions

\[
\bigl(F(6,a)\bigr)_{a=0}^6,
\qquad
\bigl(aF(6,a)\bigr)_{a=0}^6,
\]

and \(\eta\) is fused with the harmonic residue coordinate in the first of these directions.

So FSZ-type determinants can certify nonvanishing of the high-digit elimination matrix, but a **second source with a different intercept mixture** is still needed to isolate \(\eta\).

## 7. What this says about the Krattenthaler–Rivoal idea

The literal Apéry representation

\[
b_n={}_4F_3\!\left(
\begin{matrix}-n,-n,n+1,n+1\\1,1,1\end{matrix};1
\right)
\]

is a terminating balanced \({}_4F_3\).  It is not, as written, the standard very-well-poised single-sum input to the Andrews single-sum/multiple-sum identity exploited by Krattenthaler–Rivoal in their denominator arguments.  I therefore would **not** claim that there is a canonical “apply the KR Andrews transform to \(b_n\)” step already justified by the current setup.

More importantly, Q3539 does not need such a claim.  The sought p-visible decomposition is already (10)–(11).

The right analogy with Krattenthaler–Rivoal is instead:

1. **Lucas supplies the hidden divisibility before denominator clearing.**  At \(p\mid b_j\), every q=6 block sum is divisible by \(p\), and the first block is a perfect detector.

2. **The first divided layer exposes harmonic corrections.**  Formula (28) says exactly what must be eliminated at the next p-adic order.

3. **FSZ/Vandermonde can eliminate the high-digit slope with fixed coefficients**, because the \(a\)-dependence is only affine.

4. **A KR-style hypergeometric transform would be useful if it produces a second characteristic-zero source whose divided block intercept is**
   \[
   \alpha\eta+\beta C_0
   \]
   with \((\alpha,\beta)\) not proportional to \((1,12)\).  Two such intercepts would allow a fixed 2-by-2 elimination of \(C_0\) and isolate \(\eta\).

That is a much more precise target than “find an Andrews transform of the Apéry number.”

## 8. Height / FC-28 assessment

There are two distinct height questions.

### Good news: the Lucas multiplier has constant height

For the first block the multiplier is exactly \(1\).  For all seven blocks the multipliers are the fixed integers \(F(6,a)\), independent of \(p\), \(j\), and \(m\).  Thus the **high-digit elimination coefficients themselves have O(1) height**.

This is better than one could reasonably ask for at the mod-\(p\) level.

### Remaining problem: the block projector is prime-dependent

The source

\[
S_0(p,j)=\sum_{0\le k<p}F(6p+j,k)
\]

uses the cutoff \(p-1\).  For fixed \(m\), different candidate primes correspond to different \(p\) and hence different cutoffs.  Therefore \(S_0\) is not yet a single prime-independent characteristic-zero row indexed only by \(m\).

This is the same distinction emphasized by the current cutoff/block work in

`Q32_ALL_CUTOFF_BLOCK_AND_LOSS_PROOF.md`: Lucas gives extraordinarily rigid p-local block structure, but a cutoff chosen from the base-\(p\) geometry is still a p-dependent selector.

Moreover, the divided correction in (21)/(28) naturally contains harmonic numbers with denominators ranging up to \(p-1\) in the moving-\(j\) regime.  No subexponential characteristic-zero height bound follows merely from writing those harmonic sums down.

So the identity here solves the **activation problem**, but not yet the **global prime-independent selector problem**.

## 9. Recommended hybrid target

The best next object to search for is not another proof of (3); that part is finished.  Search for a second hypergeometric/contiguous source \(\widetilde S_a\) with the following three properties:

\[
\widetilde S_a\equiv \widetilde F_a\,b_j\pmod p,
\]

with fixed prime-independent \(\widetilde F_a\), and at a valuation-one zero

\[
\widetilde F_a^{-1}\frac{\widetilde S_a}{p}
\equiv
\alpha\eta+\beta C_0+\gamma aC_1
\pmod p,
\]

where

\[
\alpha\cdot12-\beta\ne0.
\]

Then:

- a two-point or Schur/Vandermonde elimination in \(a\) kills \(C_1\);
- a fixed 2-by-2 determinant between the original and transformed intercepts kills \(C_0\);
- the surviving coordinate is a nonzero fixed multiple of \(\eta=b_j/p\).

That would be a genuine Krattenthaler–Rivoal + Fischler–Sprang–Zudilin hybrid: the hypergeometric transformation changes the **low-digit first jet**, while the generalized Vandermonde handles the **high-digit block dependence**.

## 10. Answer to the exact question

Yes: the explicit identity exists, and it is simpler than an Andrews transform.

For \(p>6\), \(0\le j<p\), and \(k=ap+b\),

\[
\boxed{
\binom{6p+j}{ap+b}^{\!2}
\binom{6p+j+ap+b}{ap+b}^{\!2}
\equiv
\left[\binom6a^2\binom{6+a}{a}^2\right]
\left[\binom jb^2\binom{j+b}{b}^2\right]
\pmod p.
}
\]

Therefore

\[
\boxed{
S_0=\sum_{b=0}^{p-1}F(6p+j,b)\equiv b_j\pmod p,
}
\]

and more generally

\[
\boxed{
S_a\equiv F(6,a)b_j\pmod p.
}
\]

So at the moving Apéry-zero condition \(p\mid b_{m-6p}\), the first block—and in fact every q=6 block—is individually \(p\)-divisible.  The coefficient for the first block has perfect height: it is \(1\).

The decisive next-order refinement is (28): after division by \(p\), the normalized seven-block vector is affine in \(a\), but \(\eta\) is fused with one common harmonic intercept.  That tells us exactly what a true KR-style second source must change, and exactly what the FSZ determinant can then eliminate.
