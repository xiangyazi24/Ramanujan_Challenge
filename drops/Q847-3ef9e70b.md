# Q847 audit: sparse-exceptional first moment criterion

## Verdict summary

The proposed EXC-M1 route is a valid conditional reduction, but it is not proved by the existing exceptional-set theorem. The codegree/bucket proof gives the sparsity of the exceptional rows and some local rigidity of bad prime incidence; it does not provide the missing first-moment cancellation inside the exceptional rows.

Therefore:

* **EXC-M1 as an unconditional theorem: INVALID (not established).**
* **Conditional reduction from EXC-M1 to the all-index theorem: VALID.**
* **A strictly weaker lemma that follows from the current machinery can be proved, but it is insufficient unless strengthened to control a single exceptional row.**

---

## 1. Exact exceptional reduction

Fix epsilon > 0 and a dyadic block

```
E = E_epsilon(N) = { n in (N,2N] : log G_n > epsilon n }.
```

The exceptional theorem gives

```
|E| = O_epsilon(log N).
```

This statement is only a counting statement. It does not say that the exceptional rows are weak; a single row may still carry the entire obstruction.

For fixed q, write the centered contribution

```
D_q(E) = sum_{n in E} (T_q(n)-mu_q(n)).
```

The desired EXC-M1 input is essentially

```
D_q(E) = o(N/log N)
```

uniformly in fixed q and fixed epsilon.

If this holds for every fixed epsilon, the usual decomposition works:

```
all rows = nonexceptional rows + exceptional rows.
```

The nonexceptional rows are handled by the existing moment estimate because

```
log G_n <= epsilon n.
```

The exceptional rows are controlled by EXC-M1. Hence the conditional implication is valid.

---

## 2. Prime-shell/fixed-q formulation

The physical consumer uses the canonical shell column m=n. There is no replacement by a nearby selected index.

For a fixed q, the bad contribution has the form

```
T_q(n) = sum_{p in shell_q(n)} F_q(p,n),
```

where the shell primes satisfy the affine relation

```
 n - q p = j_p
```

with fixed-q folded coordinates.

Isolation removes primes already explained by the common factors. After centering,

```
T_q(n)-mu_q(n)
```

is a sum of prime-local deviations plus cross-prime correlations.

The exceptional-set theorem proves that the set of rows where the total product is unusually large is sparse. It does not prove that the centered prime-shell deviations cancel on those sparse rows.

---

## 3. Why the old bucket proof does not prove EXC-M1

The existing proof has two main outputs:

1. A common bad-prime codegree bound.
2. A residue-bucket count giving

```
# {n in (N,2N] : log G_n > epsilon n} = O(log N).
```

Both arguments are uncentered.

The obstruction is:

```
there may be one n in E whose fixed-q contribution is macroscopic.
```

Averages over all rows cannot remove this case because the exceptional set has already been isolated by removing almost all rows.

Thus the step

```
small exceptional cardinality => small centered first moment
```

is invalid without a new cancellation theorem.

---

## 4. Candidate dual/large-sieve attack

A possible route is to order

```
E = {n_1,...,n_r}, r=O(log N),
```

and attach each row its fixed-q prime carrier

```
S_i(q) = {p : p divides the isolated q-shell contribution at n_i}.
```

One would need a statement of the form:

```
if |sum_i sum_{p in S_i(q)} a_{i,p}| is large,
then the union of the carriers forces
an integer with too many distinct prime divisors
or too large a canonical height.
```

This is the missing carrier lemma.

The current common-divisor argument only gives

```
prime multiplicity inside one row.
```

It does not give

```
independent multiplicity across different exceptional rows.
```

The adversarial star-per-scale model can reuse the same small collection of prime buckets. A canonical Apéry sequence might prevent this, but that requires a new cross-row independence theorem.

---

## 5. Height accounting

The useful baseline is not

```
N^2 Lambda^k
```

but

```
|E| Lambda^k.
```

Since

```
|E| = O(log N),
```

this is dramatically smaller.

However, a single spike of size H contributes

```
H^k
```

regardless of |E|.

Therefore the required single-row bound is approximately

```
H = o((N/log N)^(1/k)).
```

The current exceptional theorem gives no such bound.

For k=2,3,4 the baseline improvement is real, but the single-spike term remains the decisive obstruction.

---

## 6. Sharpest weaker lemma currently supported

A weaker statement compatible with the existing proof is:

> For every fixed q and epsilon, the number of exceptional rows containing a prescribed large fixed-q bad-prime bucket is polylogarithmic.

Equivalently, no fixed bucket can account for too many exceptional rows.

This follows from the codegree/bucket mechanism.

But it does not imply

```
sum_{n in E}(T_q(n)-mu_q(n)) = o(N/log N).
```

A logarithmic number of unrelated rows can still contain one large contribution each.

---

## 7. Canonical Apéry versus star adversary

The canonical situation has extra structure:

* the same recurrence generates all b_n;
* shell columns are exactly m=n;
* fixed-q affine maps determine the folded indices;
* prime divisibility is not freely assignable.

The star-per-scale adversarial model discards this structure by allowing independently chosen bad rows and buckets.

The existing exceptional theorem bridges only the count of bad rows. It does not yet bridge the gap between the canonical recurrence and the adversarial model at the centered first-moment level.

---

## Final conclusion

No unconditional proof of EXC-M1 follows from the current exceptional-set proof.

The valid result is:

```
EXC-M1 + existing nonexceptional moment theorem
        => all-index theorem.
```

The next genuine target is not another counting estimate. It is a cross-row carrier/duality lemma showing that a sparse collection of canonical exceptional rows cannot share enough fixed-q prime mass to create a macroscopic centered first moment.

Until such a lemma is proved, k=2,3,4 sparse-exceptional moments remain a conditional route rather than a completed reduction.
