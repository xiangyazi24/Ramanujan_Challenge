# 1. Why the normalization factors are harmless locally

Let `p=2237`, `r=492`.  For an integer `m`, Legendre gives

\[
v_p(m!)=\sum_{j\ge1}\left\lfloor\frac{m}{p^j}\right\rfloor.
\]

Hence every factorial with argument `<2237` is a `2237`-unit.  In particular

\[
v_{2237}(492!)=0.
\]

Likewise

\[
v_p(\operatorname{lcm}(1,\ldots,m))
=\max\{e:p^e\le m\},
\]

so for every `m<2237`,

\[
v_{2237}(\operatorname{lcm}(1,\ldots,m)^3)=0.
\]

In particular

\[
v_{2237}(\operatorname{lcm}(1,\ldots,492)^3)=0.
\tag{1.1}
\]

The repository's `primitive_projective_prime_verify.py` uses exactly this type of carrier-clean argument: once the relevant span is below `p`, all factorial factors are units modulo `p`.  The code below does not assume that the missing notes use only `492!`: the constructor must return *every* factorial argument and every lcm bound/power, and the audit computes their valuations symbolically.  Thus a hidden factor with argument `>=2237` cannot slip through.

## Polynomial content

If

\[
F(X)=\sum_i a_iX^i\in\mathbf Z[X],\qquad
c(F)=\gcd_i a_i,
\]

then

\[
p\mid c(F)\iff F\equiv0\pmod p.
\tag{1.2}
\]

Therefore, at `r=492`, **we do not need to construct the enormous integer content**.  Construct `F` directly over `F_p`; `F != 0` proves that its integer content is a `p`-unit.  Division by the primitive content is then multiplication by a unit in `Z_p`, so the raw and primitive polynomials have identical local root data and identical `p`-primary Smith data.

For the exact `r<=40` computation we *do* construct over `ZZ`, compute the full contents, divide them out, and take the primitive resultant with FLINT.

## Leading coefficient

A resultant can pick up `p` for the wrong reason if a leading coefficient dies modulo `p`.  The local audit therefore also requires

\[
\deg \bar C=\deg C,\qquad \deg\bar K=\deg K.
\tag{1.3}
\]

This cleanly separates the affine root `X=492` from the projective-infinity contamination already emphasized elsewhere in the repository's resultant audits.

# 2. Exact local subresultant/SNF theorem

Let `O=Z_p`, `a=492`, `u=X-a`, and suppose the reductions of primitive `C,K` satisfy

\[
\bar C(a)=\bar K(a)=0.
\]

Put

\[
\mu=\operatorname{ord}_{u}\gcd(\bar C(a+u),\bar K(a+u)).
\]

This is the local common-root/subresultant multiplicity.  Equivalently, the resultant (the 0th principal subresultant) vanishes modulo `p`, while the first nonvanishing principal subresultant occurs at the gcd degree.

For the transverse case `mu=1`, at least one of `C'(a),K'(a)` is a unit.  Assume `C'(a)` is a unit; the other case is symmetric.  Hensel gives a unique root `alpha` of `C` in `a+pO`.  Modulo `p^2`,

\[
\alpha\equiv a-p\frac{c_1}{C'(a)}\pmod{p^2},
\qquad c_1=C(a)/p\pmod p.
\]

Therefore

\[
\frac{K(\alpha)}p
\equiv
k_1-K'(a)\frac{c_1}{C'(a)}
=
\frac{C'(a)k_1-K'(a)c_1}{C'(a)}
\pmod p.
\tag{2.1}
\]

Thus (0.1) is nonzero exactly when `v_p(K(alpha))=1`.

Because `C'(alpha)` is a unit, the p-adic implicit-function/Weierstrass map sends `u` to `alpha-a` and gives

\[
O[[u]]/(C)\simeq O.
\]

Under this isomorphism `K` maps to `K(alpha)`, so

\[
O[[u]]/(C,K)\simeq O/(K(\alpha)).
\tag{2.2}
\]

Hence, if `Xi != 0`, (2.2) is `O/(p)` up to a unit.  This proves all three local statements at once:

```text
local gcd/subresultant multiplicity = 1
local resultant valuation           = 1
local p-primary SNF exponents        = [1]
local p-primary invariant factors    = [2237]
```

No global Sylvester determinant is constructed.

If `Xi=0`, the same code Hensel-lifts the simple branch to increasing `p`-adic precision and computes

\[
e=v_p(K(\alpha)).
\]

As soon as the residue is nonzero modulo `p^N`, `e<N` is exact and (2.2) gives local SNF `[p^e]`.  Thus the code also distinguishes a genuine higher contact from a merely uncomputed first layer.

def vp_factorial(n, p):
    n = ZZ(n); p = ZZ(p)
    assert n >= 0 and p.is_prime()
    ans = ZZ(0)
    q = p
    while q <= n:
        ans += n // q
        q *= p
    return ans


def vp_lcm_upto(n, p):
    n = ZZ(n); p = ZZ(p)
    assert n >= 0 and p.is_prime()
    e = ZZ(0)
    q = p
    while q <= n:
        e += 1
        q *= p
    return e

    z = ZZ(z)
    if z == 0:

    z = abs(z)
    e = ZZ(0)
    while z % p == 0:
        z //= p
        e += 1
    return e

# 4. Why the code proves the primitive statement although the target path uses raw polynomials

Suppose the literal construction returns

\[
C^{\rm raw}=s_C c_C C^{\rm prim},\qquad
K^{\rm raw}=s_K c_K K^{\rm prim},
\]

where `s_C,s_K` collect factorial/lcm/external normalization factors and `c_C,c_K` are polynomial contents.

The trace audit proves

\[
v_p(s_C)=v_p(s_K)=0.
\]

The nonzero reductions of the two raw polynomials prove by (1.2)

\[
v_p(c_C)=v_p(c_K)=0.
\]

Hence raw and primitive differ by `p`-adic units.  Consequently:

* their zero sets over `F_p` are identical;
* `ord_(X-a)` of each polynomial and of their gcd is unchanged;
* the determinant `Xi` in (0.1) is multiplied by a unit;
* the localized quotient (2.2) is unchanged up to an automorphism;
* every local Smith exponent and the local resultant valuation are unchanged.

This is why the target certificate can stay entirely in `F_p` and `Z/p^N`, while the small calibration run explicitly primitive-divides over `ZZ`.

# 7. Local certificate versus global height: do not conflate them

The target local computation establishes only a statement of the form

\[
2237^e\parallel \operatorname{Res}(C_{492},K_{492})
\quad\text{at the local branch }X\equiv492\pmod{2237},
\]

with `e=1` exactly when (0.1) is nonzero.  It says nothing by itself about

\[
\log|\operatorname{Res}(C_{492},K_{492})|.
\]

The global resultant may contain very large contributions from other primes, other residual roots, and archimedean coefficient height.

Conversely, even a strikingly small sequence of values

\[
\frac{\log|R_r|}{r^2},\qquad r\le40,
\]
