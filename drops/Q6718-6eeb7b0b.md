# 1. A strictly weaker sufficient residual

Let `N -> infinity` through `p-1`, and let

```text
D = floor(sqrt(N) L),
L -> infinity,
L = N^{o(1)}.
```

Eventually `1 <= D <= N/2`. For arbitrary nonnegative integers
`R_1,...,R_D`, put

```text
T0 = ceil(sqrt(N/D)),
A_D(t) = #{h <= D : R_h >= t},
E_D = sum_{h <= D} (R_h - T0)_+.
```

Here `(x)_+ = max(x,0)`. Since the `R_h` are integers, there is the exact layer-cake identity

\[
E_D=\sum_{t>T_0}A_D(t).
\tag{1.1}
\]

## Theorem 1 (`[ZERO-EXCESS-eta]`)

Fix any constant `eta` with

\[
0<\eta<1.
\]

Assume, uniformly along the prime sequence,

\[
\boxed{
[\mathrm{ZERO\text{-}EXCESS\text{-}\eta}]
\qquad
E_D\ll_\eta \frac{N}{T_0^\eta}.
}
\tag{1.2}
\]

Then

\[
S_D:=\sum_{h\le D}R_h=o(N).
\tag{1.3}
\]

In particular, (1.2) implies W1.

### Proof

Split each root count at the automatic threshold:

\[
R_h=\min(R_h,T_0)+(R_h-T_0)_+.
\]

Therefore

\[
S_D\le DT_0+E_D.
\tag{1.4}
\]

The ceiling gives

\[
DT_0\le \sqrt{ND}+D
=N^{3/4}L^{1/2}+N^{1/2}L=o(N).
\tag{1.5}
\]

Also `T0 >= sqrt(N/D)`, so

\[
\frac{N}{T_0^\eta}
\le N\left(\frac DN\right)^{\eta/2}
=N^{1-\eta/4}L^{\eta/2}=o(N),
\tag{1.6}
\]

because `eta` is fixed and `L=N^{o(1)}`. Equations (1.2), (1.4), (1.5), and (1.6) prove (1.3). `square`

## Logical position in the ladder

The current implication ladder extends strictly as follows:

```text
BDH-LAG
   => SAME-LAG-L2
   => ZERO-TAIL-2
   => ZERO-EXCESS-eta
   => W1.
```

Indeed, if

\[
\mathcal Z_D:=\max_{t>T_0}t^2A_D(t)\ll N,
\]

then by (1.1)

\[
E_D
\le \mathcal Z_D\sum_{t>T_0}\frac1{t^2}
\le \frac{\mathcal Z_D}{T_0}
\ll \frac N{T_0}
\le \frac N{T_0^\eta}.
\tag{1.7}
\]

Thus `ZERO-TAIL-2` implies (1.2). Also

\[
t^2A_D(t)\le\sum_{h\le D}R_h^2,
\]

so `SAME-LAG-L2` implies `ZERO-TAIL-2`. Finally, if the exact mirror skeleton satisfies `0 <= kappa_h <= 1`, then

\[
\sum_{h\le D}R_h^2
\le 2\sum_{h\le D}(R_h-\kappa_h)^2+2D,
\]

and `BDH-LAG` implies `SAME-LAG-L2` at this scale.

## Strictness: it is genuinely weaker than `ZERO-TAIL-2`

This is a logical strictness statement at the deterministic root-count level; it does not claim realizability by an Apéry orbit.

Let

\[
M=\lfloor\sqrt{NL}\rfloor,
\qquad
h_* = \left\lceil\frac M3\right\rceil+1,
\]

and set

\[
R_{h_*}=M,
\qquad R_h=0\quad(h\ne h_*).
\tag{1.8}
\]

For all sufficiently large `N`, one has `h_* <= D`, and the polynomial degree cap is respected:

\[
R_{h_*}=M\le 3(h_*-1).
\]

Moreover

\[
E_D\le M= N^{1/2}L^{1/2+o(1)}
=o\!\left(N^{1-\eta/4}L^{\eta/2}\right)
=o\!\left(\frac N{T_0^\eta}\right),
\]

so `[ZERO-EXCESS-eta]` holds. But at `t=M`,

\[
t^2A_D(t)=M^2=(1+o(1))NL,
\]

which is not `O(N)` because `L -> infinity`. Hence `ZERO-TAIL-2` fails.

Thus (1.2) is strictly weaker even after imposing the natural degree bound `R_h <= 3(h-1)` and `R_1=0`.

## It is not a relabeling of W1

Conversely, W1 does not imply (1.2). Let

\[
q=\left\lfloor\frac{N}{4D}\right\rfloor.
\]

Choose `q` lags in `[ceil(2D/3),D]`, put `R_h=D` on those lags, and put zero elsewhere. There are enough lags because `q << D`, and the degree cap holds because `D <= 3(h-1)` on this interval. Then

\[
S_D=qD\le N/4,
\]

so W1 holds. But `T0=o(D)`, hence

\[
E_D=q(D-T_0)\ge (1+o(1))N/4,
\]

whereas `N/T0^eta=o(N)`. Therefore (1.2) fails.

So `[ZERO-EXCESS-eta]` is quantitatively stronger than W1, quantitatively weaker than `ZERO-TAIL-2`, and not equivalent to either.

# 2. Route A: the correct cross-lag identity

For `1 <= h <= D`, define the nonwrapping collision slice

\[
I_h=\{r:0\le r\le N-1-h,\ \pi(r)=\pi(r+h)\}.
\]

Thus `R_h=|I_h|`. For each starting point define its lag multiplicity

\[
d_r=\#\{h\le D:r\in I_h\}.
\]

Set

\[
T_D:=\sum_r\binom{d_r}{2}
=\sum_{1\le h<k\le D}|I_h\cap I_k|.
\tag{2.1}
\]

## Lemma 2 (`[SLICE-PAIR]`)

For every projective word, with no Apéry input,

\[
S_D\le N+T_D.
\tag{2.2}
\]

Also

\[
T_D\ge \frac12\left(\frac{S_D^2}{N}-S_D\right).
\tag{2.3}
\]

### Proof

For every integer `d >= 0`,

\[
d\le 1+\binom d2.
\]

Summing over the `N` possible starting positions gives (2.2). For (2.3), use

\[
\sum_r d_r^2=S_D+2T_D
\]

and Cauchy:

\[
S_D^2\le N\sum_r d_r^2=N(S_D+2T_D).
\]

Rearrange. `square`

Consequently the aggregate statement

\[
\boxed{
[\mathrm{TRIANGLE\text{-}INC}]
\qquad T_D\ll N
}
\tag{2.4}
\]

implies W1 directly.

## Exact triangle closure

If `1 <= h < k <= D`, then

\[
r\in I_h\cap I_k
\]

is equivalent to

\[
\pi(r)=\pi(r+h)=\pi(r+k).
\]

Hence

\[
\boxed{
|I_h\cap I_k|
=\#\{r:0\le r\le N-1-k,
\ N_h(r)=0,
\ N_{k-h}(r+h)=0\}.
}
\tag{2.5}
\]

This is the governing identity for route A. It converts “the same root occurs in two lag slices” into a shifted two-collision incidence.

### Hostile assessment

The viable target is the **aggregate** bound (2.4), or its shifted form obtained by summing (2.5). A raw characteristic-zero resultant `Res(N_h,N_k)` is not a viable method:

- `h,k` vary with the same prime `p`, so fixed-pair finiteness gives the wrong quantifier;
- resultant heights do not give a useful uniform exclusion at `h,k <= sqrt(N)L`;
- the already observed cut-edge factors create quenched divisibility unrelated to genuine nonwrapping intersections.

Thus A ranks second only in the form (2.4)--(2.5). The narrow missing arithmetic statement is an aggregate anti-coexistence estimate for the shifted zero sets, not pairwise resultant nonvanishing.

# 3. Route B: renewal does not propagate

Let

\[
Z_m=\{x:K_m(x)=0\}.
\]

The banked renewal identity is

\[
K_{m+g+1}(X)
=K_{m+1}(X)K_g(X+m+1)
-(X+m+1)^6K_m(X)K_{g-1}(X+m+2).
\tag{3.1}
\]

Adjacent coprimality gives `K_{m+1}(x) != 0` for every `x in Z_m`. Therefore (3.1) yields the exact equivalence

\[
\boxed{
 x\in Z_m:
\quad
K_{m+g+1}(x)=0
\iff
K_g(x+m+1)=0.
}
\tag{3.2}
\]

Equivalently,

\[
\boxed{
Z_m\cap Z_{m+g+1}
=Z_m\cap\bigl(Z_g-(m+1)\bigr).
}
\tag{3.3}
\]

This kills the proposed deterministic propagation step. A large `|Z_m|` supplies many *places at which a new shifted condition may be tested*; it supplies no reason for that shifted condition to hold at even one of them.

There is a second obstruction. Even granting the unrealistically strong conclusion that all `R_m` roots propagate to one later lag, the degree bound is monotone in the wrong direction:

\[
R_m\le 3m-3 < 3(m+g+1)-3.
\]

Thus `R_{m+g+1} >= R_m` does not contradict the longer-lag degree bound. Propagation into many different later lags also gives no contradiction from separate degree bounds.

Any successful use of (3.2) must prove a nontrivial correlation estimate between `Z_m` and `Z_g-(m+1)`. That is route A in shifted form, not an independent route B. Therefore B, as stated, is dead.

# 4. Route C: exact skeleton is normalization, not cancellation

Let `kappa_h` be the exact number of forced mirror roots in lag `h`. Under either endpoint convention for the reflection, one has uniformly

\[
0\le\kappa_h\le1.
\]

For example, under the convention `pi(r)=pi(N-r)`, the admissible forced root solves `2r+h=N`, so `kappa_h` is the appropriate parity indicator. The precise parity is irrelevant to the scale audit below.

Put

\[
\rho_h=R_h-\kappa_h\ge0.
\]

Then

\[
\sum_{h\le D}R_h
=\sum_{h\le D}\rho_h+O(D),
\tag{4.1}
\]

and

\[
\sum_{h\le D}R_h^2
\le 2\sum_{h\le D}\rho_h^2+O(D),
\qquad
\sum_{h\le D}\rho_h^2\le\sum_{h\le D}R_h^2.
\tag{4.2}
\]

Since `D=o(N)`, W1 for `R_h` is equivalent to W1 for `rho_h`, and `SAME-LAG-L2` is equivalent up to a negligible `O(D)` term.

The hostile point is that `rho_h` is still nonnegative. Subtracting the forced skeleton does not create signed cancellation; it merely removes one deterministic root. Thus “make the skeleton exact” does not itself control any fluctuation. It is useful only as the correct centering for a future trace/BDH theorem.

So C is legitimate bookkeeping and may simplify the statement of `BDH-LAG`, but it is not a route to the missing estimate by itself.

# 5. Final route ranking and the honest remaining target

## 1. D -- pursue

Theorem 1 lowers the bottom face from a weak-L2 **maximum** to a truncated-L1 **integrated excess** with any fixed power saving. It allows isolated degree-scale spikes that violate `ZERO-TAIL-2`.

The exact target is:

\[
\boxed{
\text{For some fixed }\eta>0,\qquad
\sum_{h\le D}(R_h-T_0)_+
\ll \frac N{T_0^\eta}.
}
\tag{5.1}
\]

This is the narrowest honest statement I recommend. Replacing the right side by merely `o(N)` would be essentially equivalent to `S_D=o(N)` because the low part `DT0` is already `o(N)`; that would hide the burden. The fixed power saving in (5.1) prevents that relabeling.

## 2. A -- viable only as aggregate triangle incidence

The exact target is (2.4), attacked through (2.5). It is a genuine arithmetic anti-coexistence problem. Do not return to raw resultant heights.

## 3. C -- retain as normalization

Record the exact parity formula for `kappa_h` and strip it before any trace calculation, but do not count this as progress toward W1 until a bound on the residual `rho_h` is proved.

## 4. B -- stop

Renewal gives (3.2), which is a correlation identity, not a cascade. Without a shifted-root correlation theorem it has no deterministic force; with such a theorem it has become route A.

# 6. What remains open

No current banked structural fact proves (5.1), (2.4), `ZERO-TAIL-2`, or `SAME-LAG-L2`. The exact reflection, squarefreeness, strip localization, degree bound, window sparsity, and global energy all permit lag concentration countermodels.

The narrowest unresolved arithmetic assertion is therefore not a new monodromy statement and not another one-polynomial root bound. It is:

```text
A fixed power saving in the total excess mass of lags whose zero fibres
rise above T0 = ceil(sqrt(N/D)).
```

Equivalently, using (1.1), it is an integrated cross-lag tail estimate

\[
\sum_{t>T_0}A_D(t)
\ll \frac N{T_0^\eta}
\]

for some fixed `eta>0`. This is strictly below all current bottom faces, still enough for W1, and does not demand control of nonzero values or of the full same-lag second moment.
