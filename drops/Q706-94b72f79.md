# Hidden conservation law: what can actually telescope the AFP sum?

## Executive conclusion

The coboundary idea is the correct structural target, but the naive forms are almost certainly too strong. The indicator

```text
1_{b_r=0} - 1/(p+1)
```

is not expected to be an ordinary finite-difference of a bounded function on the Riccati orbit. The right object is likely a **representation-theoretic or p-adic coboundary**: the Steinberg observable is a matrix coefficient, and the missing cancellation must come from a special invariant vector, not from a generic orbit identity.

The most promising candidate is not `log(x_r)` or `v_p(b_r)` individually, but a cocycle attached to the rank-one local system underlying the Apéry Picard-Fuchs equation.

---

## 1. Discrete logarithm of the Riccati orbit

Let

```text
x_r = b_r / b_{r-1}.
```

Then

```text
x_{r+1} = (P(r)x_r-r^3)/(r+1)^3.
```

Formally one can write

```text
L(r)=log_p(x_r).
```

However, this does not give the required telescope.

The reason is that

```text
L(r+1)-L(r)=log_p(phi_r(x_r)/x_r)
```

is a multiplicative cocycle of the projective action. Its singularities occur at both

```text
x_r=0
```

and

```text
x_r=infinity.
```

The AFP event is only

```text
x_r=0.
```

The poles therefore have the wrong symmetry. Reflection

```text
b_r=b_{p-1-r}
```

forces zeros and poles to pair, so a logarithmic derivative naturally sees a signed divisor, while AFP needs the positive counting measure of one side.

Conclusion: `log(x_r)` may encode the geometry, but it is not itself the telescoping observable.

---

## 2. Valuation function H(r)=v_p(b_r)

This is closer, but still insufficient.

For almost all r,

```text
v_p(b_r)=0.
```

At a simple zero,

```text
v_p(b_r)=1.
```

Hence

```text
H(r+1)-H(r)
```

is a signed jump process. Summing gives only boundary terms:

```text
sum_r (H(r+1)-H(r))=H(p-1)-H(0).
```

But AFP counts all zero locations, not the net number of upward/downward crossings.

To recover the indicator one would need a monotonicity theorem such as

```text
b_r can cross the p-adic valuation wall only once.
```

The Apéry recurrence does not have such a property. The valuation viewpoint is therefore useful for local analysis but unlikely to be the global conservation law.

---

## 3. Wronskian potential: the strongest classical candidate

The exact identity

```text
b_r c_{r-1}-b_{r-1}c_r=-1/r^3
```

shows that the pair `(b,c)` is a genuine SL_2 orbit.

At a zero of b_r:

```text
b_r=0  ==>  b_{r-1}c_r=1/r^3.
```

Thus zeros correspond to a precise intersection condition between the two projective coordinates.

A possible potential is a cross-ratio type quantity

```text
Phi(r)=F([b_r:c_r],[b_{r-1}:c_{r-1}]).
```

The difficulty is that the zero divisor of a section of a rank-two local system is not usually the difference of two adjacent values of a bounded scalar function.

The missing ingredient would be a discrete Abel theorem:

```text
Div(b) = Delta(Phi)
```

inside the function field of the Apéry motive.

No such identity is known. If it existed, it would essentially solve AFP immediately.

## 4. Unit-root normalization

Write

```text
b_r = alpha_p^r f_r.
```

Then

```text
f_{r+1}/f_r=x_{r+1}/alpha_p.
```

The exponential Frobenius eigenvalue has been removed. The variational equation becomes

```text
f_{r+1}=((P(r)x_r-r^3)/((r+1)^3 alpha_p)) f_r.
```

This is better conceptually because `f_r` is a unit-root period rather than a growing solution.

But the zero set is unchanged:

```text
b_r=0 <=> f_r=0.
```

The unit-root normalization can expose Frobenius invariance, but it does not automatically create a coboundary.

The right question is therefore not:

```text
Can f_r telescope?
```

but:

```text
Does Frobenius-equivariant variation of the unit-root crystal have an exact logarithmic derivative whose residue is the zero divisor?
```

## 5. Motivic conservation law

This is the most plausible formulation.

The Apéry recurrence comes from a rank-two motive. Frobenius acts through

```text
M_r in SL_2(F_p).
```

The Steinberg indicator is a matrix coefficient:

```text
1_{b_r=0}-1/(p+1)
```

is the exceptional value of a Steinberg observable.

A generic Deligne estimate gives only

```text
sum_r St(M_r)=O(sqrt(p)*dim(St)^{1/2}).
```

AFP requires cancellation far beyond generic square-root cancellation.

Therefore there must be an additional invariant. A motivic conservation law would have the shape

```text
St(M_r)=Phi(Frob_{r+1})-Phi(Frob_r).
```

Then

```text
sum_r St(M_r)=Phi(Frob_p)-Phi(Frob_0),
```

which is bounded.

The endpoint identities

```text
M(p-1)=[[0,1],[1,0]]
```

and

```text
b_r=b_{p-1-r}
```

are exactly the kind of boundary constraints one expects if such a conservation law exists.

---

## 6. What should be searched computationally

The right search is not for

```text
G(r+1)-G(r)=b_r^(p-1)-constant.
```

That has degree about p^2 and hides the structure.

Instead search in low-complexity functions of the orbit:

```text
G(r)=A(r)+B(r)x_r+C(r)x_r^{-1}
```

or more generally rational functions on P^1 invariant under the Apéry transfer matrices.

The equation becomes

```text
G(r+1)-G(r)=1_{x_r=0}-1/(p+1).
```

Because the right side is a divisor-supported function, any solution should be a rational function with controlled poles. This is a finite-dimensional ansatz for small primes.

A successful pattern would reveal the motivic law.

---

## Final answer

1. `log_p(x_r)` is a natural cocycle but detects the divisor with signs, not the zero counting measure. It is unlikely to telescope AFP directly.

2. `v_p(b_r)` captures simple zeros but its difference is a boundary term, not a counting function.

3. The Wronskian is the strongest classical source of a potential, but an exact divisor-coboundary identity would be a new Abelian/motivic statement.

4. Unit-root normalization removes irrelevant growth and is probably the correct p-adic setting, but the missing step is Frobenius-equivariant cancellation.

5. The realistic hidden conservation law is a **Steinberg/motivic coboundary**:

```text
Steinberg observable = Frobenius coboundary.
```

Finding this identity would prove AFP because the whole zero count collapses to endpoint terms. The existing reflection and swap symmetries strongly suggest that this is the correct direction rather than a direct exponential-sum estimate.
