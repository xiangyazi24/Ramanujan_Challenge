# The companion-denominator route: an exact local theorem, and why it is still the shell-radical problem

## Executive verdict

There is a substantial exact theorem hidden in the proposed idea, but it does **not** bypass the top-window prime-counting problem.

Let p ≥ 7 be prime and write

```text
p ≤ n < 2p,
n = p + r,
0 ≤ r < p.
```

Write the Apéry companion in lowest terms as

```text
a_n = A_n / D_n,
gcd(A_n,D_n) = 1,
D_n > 0.
```

Then the explicit harmonic formula gives

```text
p³ a_(p+r) ≡ 6 b_r  (mod p).                         (0.1)
```

Using the Lucas congruence `b_(p+r) ≡ 5 b_r (mod p)`, this is equivalently

```text
p³ a_n ≡ (6/5) b_n  (mod p).                         (0.2)
```

At a hit, the Casoratian upgrades this first-order congruence to an exact local identity

```text
p³ a_n = U_(p,n) b_n + p³ V_(p,n),                  (0.3)
```

where `U_(p,n)` and `V_(p,n)` are p-adic units and

```text
U_(p,n) ≡ 6/5  (mod p).
```

Consequently, if

```text
t = v_p(b_n),
```

then the reduced denominator of `a_n` satisfies the exact law

```text
v_p(D_n) = max(3 - t, 0).                            (0.4)
```

Equivalently, the loss from the full p³ denominator is

```text
3 - v_p(D_n) = min(v_p(b_n), 3).                    (0.5)
```

This is the correct companion theorem.

It immediately implies:

- A simple hit, `v_p(b_n)=1`, gives `v_p(a_n)=-2` and `v_p(G_n)=1`.
- If `v_p(b_n)=2`, then `v_p(a_n)=-1`, not `-2`.
- If `v_p(b_n)≥3`, then `a_n` is p-integral.

Thus the formula proposed in the question,

```text
v_p(a_n) = -3 + 1_(p divides b_n),
```

is not unconditional. It is exactly the **simple-hit case**. Q121 recorded an empirical one-layer defect; it did not prove that every top-window hit is simple.

If `Delta_n = lcm(1,...,n)³` is the denominator-clearing factor, then the exact top-window denominator defect is

```text
(Delta_n / D_n)_top
  = product over n/2 < p ≤ n of p^min(v_p(b_n),3).   (0.6)
```

Therefore

```text
rad_(n/2,n](b_n)
  divides (Delta_n / D_n)_top
  divides rad_(n/2,n](b_n)³.                        (0.7)
```

So proving that the companion denominator is almost maximal in the top window is equivalent, up to a factor of three in logarithms, to proving shell-radical sparsity. It is a new interface to the same obstruction, not an escape from it.

The proposed small-prime saturation statement is much stronger than needed and is probably false. A random integer of size `exp(cn)` has expected logarithmic contribution from primes `p≤n/2` only

```text
sum_(p≤n/2) log(p)/(p-1) = log n + O(1),
```

not `cn`. Yet its expected contribution from the narrow shell `(n/2,n]` is only

```text
sum_(n/2<p≤n) log(p)/p = log 2 + o(1).
```

Thus the shell conclusion is compatible with almost all of `log b_n` being carried by primes much larger than n. There is no reason for small primes to account for `3.525... n`.

Finally, the dominant-term proposal contains two concrete errors:

1. The term `k=n/2` is not dominant; it is exponentially smaller than the true saddle at `k≈n/sqrt(2)`.
2. From `p divides M+R` and `p does not divide M`, one gets `R ≡ -M ≠ 0 (mod p)`, not `p divides R`. A generic hit prime divides neither piece; it is a pure additive-cancellation prime.

The deepest useful output of this route is therefore the exact top-window denominator law (0.4), plus the following named residual.

> **Horizontal denominator-saturation problem.** Prove
>
> ```text
> log((Delta_n / D_n)_top) = o(n).
> ```

By (0.6)-(0.7), this is exactly the top-window shell-radical problem in companion language.

## 1. Q121 must be read as a simple-hit observation

The current repository drop `Q121-60e4e729.md` describes the empirical transition

```text
v_p(D_n): 3 -> 2
```

when `p divides b_n`, and suggests an indicator formula. The calculation below shows that the true invariant is the truncated valuation

```text
3 - v_p(D_n) = min(v_p(b_n),3).
```

Therefore the missing local statement behind the observed law is actually

```text
p divides b_n and p > n/2  implies  p² does not divide b_n.   (1.1)
```

No such theorem is currently present in the repository. Even if (1.1) were proved, it would control only the weight contributed by each hit. It would not control the number of hit primes.

## 2. Explicit extraction of the p to the minus three coefficient

Use Apéry's harmonic formula

```text
b_n = sum_(k=0)^n W_(n,k),
W_(n,k) = C(n,k)² C(n+k,k)²,                         (2.1)
```

and

```text
a_n = sum_(k=0)^n W_(n,k) c_(n,k),                  (2.2)
```

where

```text
c_(n,k)
 = sum_(j=1)^n 1/j³
   + sum_(j=1)^k (-1)^(j-1)
       / (2 j³ C(n,j) C(n+j,j)).                    (2.3)
```

Let `n=p+r<2p`. In the first harmonic sum, the only multiple of p is `j=p`, producing `p^(-3)`.

In the second sum, the `j=p` term is

```text
1 / (2 p³ C(n,p) C(n+p,p)).                         (2.4)
```

For `j≠p`, each of the two binomial denominators can contribute at most one inverse p-layer in this range. Thus, after multiplication by p³, every `j≠p` term vanishes modulo p.

It follows that `p³a_n` is p-integral and

```text
p³a_n ≡ b_n
       + [1 / (2 C(n,p) C(n+p,p))]
           sum_(k=p)^n W_(n,k)                       (mod p).  (2.5)
```

Put `k=p+t`, with `0≤t≤r`. Lucas gives

```text
C(p+r,p+t) ≡ C(r,t)                                  (mod p),
C(2p+r+t,p+t) ≡ 2 C(r+t,t)                           (mod p).  (2.6)
```

When `r+t≥p`, both sides of the second congruence vanish, so it remains valid. Hence

```text
W_(p+r,p+t) ≡ 4 W_(r,t)                              (mod p),
```

and therefore

```text
sum_(k=p)^(p+r) W_(p+r,k) ≡ 4b_r                    (mod p).  (2.7)
```

Also

```text
C(p+r,p) ≡ 1,
C(2p+r,p) ≡ 2                                        (mod p).  (2.8)
```

The second term in (2.5) is therefore `b_r`, while Lucas gives

```text
b_(p+r) ≡ b_1 b_r = 5b_r                            (mod p).  (2.9)
```

Combining these identities proves

```text
p³ a_(p+r) ≡ 6b_r                                   (mod p).  (2.10)
```

This immediately yields

```text
p does not divide b_n  implies  v_p(a_n) = -3,
p divides b_n          implies  v_p(a_n) ≥ -2.       (2.11)
```

The exact hit valuation comes from the Casoratian.

## 3. The Casoratian gives the full denominator law

The two Apéry solutions satisfy

```text
a_(n-1)b_n - a_n b_(n-1) = -6/n³.                  (3.1)
```

Assume `p divides b_n`, with `p≥7` and `n=p+r<2p`. Since

```text
b_n ≡ 5b_r                                           (mod p),
```

we have `p divides b_r`. Necessarily `r≠0`, since `b_0=1`.

There are no consecutive zeros among `b_0,...,b_(p-1)` modulo p. In this range the recurrence is reversible because the relevant cube factors are p-adic units. Two consecutive zeros would propagate backward to `b_0=0`, a contradiction. Hence

```text
p does not divide b_(r-1).                           (3.2)
```

Lucas and (2.10) now give

```text
b_(n-1) ≡ 5b_(r-1) ≠ 0                              (mod p),
p³a_(n-1) ≡ 6b_(r-1) ≠ 0                            (mod p).  (3.3)
```

Put `X_j=p³a_j`. Multiplying (3.1) by p³ gives

```text
X_(n-1)b_n - X_n b_(n-1) = -6p³/n³.                 (3.4)
```

Since `p does not divide n`, solve for `X_n`:

```text
X_n
 = [X_(n-1)/b_(n-1)] b_n
   + 6p³/[n³ b_(n-1)].                               (3.5)
```

Define

```text
U_(p,n) = X_(n-1)/b_(n-1),
V_(p,n) = 6/[n³ b_(n-1)].                            (3.6)
```

Both are p-adic units, and

```text
U_(p,n) ≡ 6/5                                        (mod p).  (3.7)
```

Thus

```text
p³a_n = U_(p,n)b_n + p³V_(p,n).                     (3.8)
```

Let `t=v_p(b_n)` and `s=v_p(p³a_n)`. Taking valuations in (3.8) gives

| t | s = v_p(p³a_n) | v_p(a_n) |
|---:|---:|---:|
| 0 | 0 | -3 |
| 1 | 1 | -2 |
| 2 | 2 | -1 |
| 3 | at least 3 | at least 0 |
| at least 4 | 3 | 0 |

For `t=3`, the exact value is

```text
s = 3 + v_p(U_(p,n) b_n/p³ + V_(p,n)).              (3.9)
```

There can be a further cancellation between two p-adic units. This changes the numerator of `a_n`, but not its reduced denominator.

Since `a_n=A_n/D_n` is reduced,

```text
v_p(D_n) = max(-v_p(a_n),0).
```

The table proves the exact formula

```text
v_p(D_n) = max(3-v_p(b_n),0).                        (3.10)
```

This is the rigorous replacement for the indicator law in Q121.

## 4. Exact factorization of the cleared gcd

Let

```text
Delta_n = lcm(1,...,n)³.
```

The user's `d_n` in Q132 is this clearing factor, since a top prime has valuation 3.

With `a_n=A_n/D_n` reduced and `D_n divides Delta_n`,

```text
Delta_n a_n = (Delta_n/D_n) A_n,
Delta_n b_n = (Delta_n/D_n) (D_n b_n).
```

Because `gcd(A_n,D_n)=1`,

```text
gcd(A_n,D_n b_n) = gcd(A_n,b_n).
```

Therefore

```text
G_n = (Delta_n/D_n) gcd(A_n,b_n).                    (4.1)
```

At a top-window prime, (3.10) gives

```text
v_p(Delta_n/D_n) = min(v_p(b_n),3).                  (4.2)
```

The reduced numerator `A_n` is a p-adic unit except possibly in the resonant case `v_p(b_n)=3`. More explicitly:

| v_p(b_n) | v_p(G_n) |
|---:|---:|
| 0 | 0 |
| 1 | 1 |
| 2 | 2 |
| 3 | `3 + min(v_p(a_n),3)` |
| at least 4 | 3 |

Thus every top hit contributes between one and six p-adic layers. If

```text
R_top(n) = product of p with n/2 < p ≤ n and p divides b_n,
```

then, apart from the fixed exceptional prime 5,

```text
R_top(n) divides G_n^top divides R_top(n)^6.          (4.3)
```

Consequently

```text
log G_n^top = o(n)
    iff
log R_top(n) = o(n).                                 (4.4)
```

Since every top prime lies between `n/2` and n,

```text
K_top(n) log(n/2)
 ≤ log R_top(n)
 ≤ K_top(n) log n.                                   (4.5)
```

Therefore

```text
log G_n^top = o(n)
    iff
K_top(n) = o(n/log n).                               (4.6)
```

This equivalence does not require a simple-hit assumption.

## 5. What the companion viewpoint genuinely buys

The companion route does not improve the numerical target, but it gives three real structural gains.

### 5.1 It identifies the local mechanism exactly

A top hit is precisely a failure of the companion denominator to retain the full p³ layer. The amount of failure is

```text
min(v_p(b_n),3).
```

The top radical is not merely correlated with the denominator defect; it is exactly its support.

### 5.2 It separates support from multiplicity

The empirical law `v_p(G_n)=1` says that the observed hits were simple. A mod-p² block theorem could potentially prove repeated top hits are rare. This would settle the local weights, but still not the support count.

### 5.3 It produces a next p-adic observable

At a hit, the first coefficient (2.10) vanishes. The next coefficient

```text
(p³a_(p+r))/p  (mod p)
```

is a tangent or extension-class observable at the zero `b_r=0 (mod p)`. Controlling its vanishing could prove simple-hit or nonresonance statements.

But none of this couples different primes. The first companion coefficient is proportional to the same `b_r` that already defines the hit. Any new information must come from the **next** p-adic coefficient.

A useful name for the exact residual is

```text
(TWDS) Top-window denominator saturation:

log product_(n/2<p≤n) p^(3-v_p(D_n)) = o(n).
```

By (3.10), TWDS is

```text
log product_(n/2<p≤n) p^min(v_p(b_n),3) = o(n),
```

and is equivalent to the shell-radical theorem.

Standard denominator theorems for recurrence solutions and G-functions run in the opposite direction: they construct a common denominator such as `Delta_n`, hence give an **upper bound** on `D_n`. TWDS requires a near-maximal **lower bound** on the reduced denominator after cancellation. No generic theorem supplies that lower bound.

## 6. Why small-prime saturation is not an equivalent route

Define

```text
S_small(n) = sum_(p≤n/2) v_p(b_n) log p.              (6.1)
```

The proposed theorem is

```text
S_small(n)
 ≥ [log(17+12 sqrt(2)) - o(1)] n.                    (6.2)
```

Because

```text
log b_n
 = log(17+12 sqrt(2)) n + O(log n),
```

(6.2) says that the entire cofactor of `b_n` supported on primes above `n/2` is subexponential. It controls not only the dangerous shell `(n/2,n]`, but every prime above n, including factors of exponential size.

This is far stronger than required.

A simple logical example shows the gap. Suppose an integer `N_n` of size `exp(cn)` is itself prime and exceeds n. Then

```text
omega_(n/2,n](N_n) = 0,
```

so the shell conclusion holds perfectly, while

```text
sum_(p≤n/2) v_p(N_n) log p = 0.
```

Shell evacuation does not require logarithmic mass to move downward into small primes. It may move upward into huge primes.

### 6.1 The random-integer model predicts the opposite of saturation

For a random integer X much larger than n,

```text
E[v_p(X)] ≈ sum_(j≥1) 1/p^j = 1/(p-1).
```

Therefore

```text
E[sum_(p≤n/2) v_p(X) log p]
 ≈ sum_(p≤n/2) log p/(p-1)
 = log n + O(1).                                     (6.3)
```

This is logarithmic, not linear.

Meanwhile

```text
E[sum_(n/2<p≤n, p divides X) log p]
 ≈ sum_(n/2<p≤n) log p/p
 = log 2 + o(1).                                     (6.4)
```

So the random model simultaneously predicts

```text
small primes carry only O(log n) logarithmic mass;
the dangerous shell carries only O(1) mass;
most of log X is carried by primes much larger than n.
```

This is exactly why small-prime saturation is the wrong target. The desired theorem is local evacuation of one shell, not global smoothness.

### 6.2 The factor count above n is not known to be bounded

The quantity `omega_(>n)(b_n)` is not known to be O(1). Height gives only

```text
omega_(>n)(b_n)
 ≤ log b_n / log n
 = O(n/log n).
```

Those primes may carry most of the logarithmic height. This is harmless for the top-window GCD problem but incompatible with the proposed saturation theorem.

## 7. Why Kummer carries of the summands cannot force small-prime mass

For each summand

```text
W_(n,k) = C(n,k)² C(n+k,k)²,
```

Kummer's theorem gives an exact carry formula for `v_p(W_(n,k))`. But a lower bound for individual summand valuations does not pass to their sum.

The most basic obstruction is

```text
W_(n,0) = 1.                                         (7.1)
```

Hence, for every prime p,

```text
min_(0≤k≤n) v_p(W_(n,k)) = 0.
```

The ultrametric inequality yields only `v_p(b_n)≥0`. To get positive valuation, the p-adic unit summands must cancel modulo p. Determining that cancellation is precisely the zero condition `b_n=0 (mod p)`.

Stratifying terms by carry patterns merely reconstructs the finite-field Apéry sum; it does not create an independent lower bound on the small-prime part.

The factorial factors of a term are not inherited by the sum. The model example is

```text
N! + 1.
```

Although `N!` contains every prime at most N, no prime at most N divides `N!+1`. A tiny positive remainder can destroy all small-prime divisibility of a dominant factorial term.

## 8. The proposed central term is not dominant

Let

```text
T_(n,k) = C(n,k)² C(n+k,k)².
```

The consecutive ratio is

```text
T_(n,k+1) / T_(n,k)
 = [((n-k)(n+k+1))/(k+1)²]².                         (8.1)
```

The transition from increasing to decreasing occurs at

```text
k = n/sqrt(2) + O(1),                                (8.2)
```

not at `n/2`.

For even n, Stirling gives

```text
T_(n,n/2) is asymptotic to a constant times 27^n/n², (8.3)
```

whereas

```text
b_n is asymptotic to
  C (17+12 sqrt(2))^n / n^(3/2),
17+12 sqrt(2) = 33.97056... .                        (8.4)
```

Thus

```text
T_(n,n/2)/b_n
 is on the order of
 n^(-1/2) [27/(17+12 sqrt(2))]^n,                    (8.5)
```

which is exponentially small.

Even the true maximal term near `n/sqrt(2)` has size only

```text
max_k T_(n,k)
 is on the order of
 (17+12 sqrt(2))^n / n².                             (8.6)
```

It is only of order `n^(-1/2)` of the total. Roughly `sqrt(n)` saddle-window terms contribute on the leading scale. There is no one-term decomposition with a negligible remainder.

### 8.1 The proposed prime dichotomy is logically false

Write

```text
b_n = M_n + R_n.
```

If `p divides b_n`, then

```text
R_n ≡ -M_n  (mod p).
```

There are two cases:

- If `p divides M_n`, then `p divides R_n`.
- If `p does not divide M_n`, then `p does not divide R_n`.

Thus the generic cancellation prime divides **neither** `M_n` nor `R_n`. One cannot bound the shell factors of `b_n` by the union of the shell factors of a selected term and its complement.

### 8.2 Relative smallness is irrelevant modulo p

Even if a saddle block captured `1-o(1)` of the positive real mass, the remainder would still be exponentially large in absolute value. A congruence

```text
M_n ≡ -R_n  (mod p)
```

has no difficulty occurring for `p` of order n. To rule it out by size, one would need `abs(R_n)<p`, or a subexponential product estimate, not merely `R_n=o(M_n)`.

Positivity is archimedean information; reduction modulo p forgets order and sign.

## 9. Could the mass escape to primes above n instead?

A logically valid alternative sufficient condition would be to prove that almost all of `log b_n` is carried by primes **above** n, leaving little room for the shell. For example, a sufficiently strong lower bound

```text
log rad_(>n)(b_n)
 ≥ [log(17+12 sqrt(2)) - o(1)] n                     (9.1)
```

would force shell evacuation after controlling small-prime powers.

This direction is more compatible with random factorization than small-prime saturation, but it is not currently easier:

- it asks for a lower bound on the large squarefree part of one Apéry value;
- largest-prime-factor and primitive-divisor theorems produce one factor, not almost all logarithmic mass;
- abc-type inequalities do not localize the radical to primes above n;
- the radicals of a selected Apéry summand and its remainder are not controlled;
- no cyclotomic, factorial-product, or gamma-product factorization of `b_n` is known.

Thus “mass escapes upward” is a plausible heuristic picture, not an available proof.

## 10. Why a global denominator estimate does not automatically help

The exact identity (4.1) connects the companion denominator to the reduced Apéry approximation. The rational number

```text
a_n/b_n = A_n/(D_n b_n)
```

has reduced denominator

```text
q_n = D_n b_n / gcd(A_n,b_n).                       (10.1)
```

Equation (4.1) is equivalently

```text
q_n = Delta_n b_n / G_n.                            (10.2)
```

A lower bound on `q_n` gives an upper bound on `G_n`, but ordinary irrationality measures are far too coarse. They control only the total exponential size of the denominator. They do not force `D_n` to retain almost every top-window p-layer.

Even an optimal irrationality exponent for zeta(3) would not identify which primes were cancelled from `Delta_n`. Prime support is finer information than denominator magnitude. This is the distinction already isolated in `Q115-f1049731.md`.

## 11. A realistic research program from the companion theorem

The companion idea should not be discarded. It yields several sharply posed tasks.

### Task A: formalize the first coefficient

Prove in the project notation

```text
p³a_(p+r) ≡ 6b_r  (mod p),
0≤r<p,
p≥7.
```

This is an elementary finite calculation from the harmonic formula and Lucas congruences.

### Task B: formalize the denominator law

Combine Task A with the Casoratian to prove

```text
v_p(D_n) = max(3-v_p(b_n),0)
```

for `p≤n<2p`, `p≥7`.

This corrects the indicator statement in Q121 and identifies the exact local invariant.

### Task C: study simple-hit and resonance loci

The next genuinely new local questions are

```text
p divides b_n  implies  p² does not divide b_n?
```

and, in the exceptional case `v_p(b_n)=3`, whether

```text
U_(p,n) b_n/p³ + V_(p,n) ≠ 0  (mod p).
```

These are mod-p² and mod-p⁴ refinements. They control local weights but not the number of primes.

### Task D: use both coordinates in a cross-prime sieve

The pair

```text
(b_(n-p) mod p, p³a_n mod p²)
```

contains a value and a tangent or extension coordinate. A future large-sieve or Dwork theorem might exploit the pair more effectively than `b_(n-p)` alone.

But at first order the companion coordinate is proportional to the same zero condition. Any gain must come from the next p-adic coefficient.

### Task E: horizontal denominator saturation

The global target remains

```text
log product_(n/2<p≤n) p^(3-v_p(D_n)) = o(n).        (11.1)
```

By the exact local law, this is

```text
log product_(n/2<p≤n) p^min(v_p(b_n),3) = o(n),
```

and hence is equivalent to the shell-radical theorem.

This is the precise point where a new cross-prime input is still required.

## 12. Final answer

The companion sequence does give an explicit and rigorous top-window theorem:

```text
p³a_(p+r) ≡ 6b_r  (mod p),
v_p(D_n) = max(3-v_p(b_n),0).
```

In particular, a simple hit gives

```text
v_p(a_n) = -2,
v_p(G_n) = 1.
```

But this is not a consequence merely of the indicator `p divides b_n`; it depends on hit multiplicity. The correct denominator defect is the truncated valuation `min(v_p(b_n),3)`.

The companion approach therefore transforms the conjecture into:

```text
The reduced denominator of a_n loses only exp(o(n))
in the top-prime window.
```

That statement is exactly equivalent to the shell-radical bound. No generic denominator theorem proves it.

The proposed small-prime saturation route should not be the main target. It asks for near-total `n/2`-smoothness of `b_n`, is far stronger than shell evacuation, and runs opposite to the natural random-factorization heuristic. Kummer carry information for the individual summands cannot force it because `W_(n,0)=1` and divisibility of the sum is governed by cancellation among p-adic units.

The dominant-term strategy also fails twice: `k=n/2` is exponentially subdominant, and a cancellation prime of `M+R` generically divides neither `M` nor `R`.

The best new theorem exposed by Q132 is the **top-window companion denominator law**. The remaining named residual is the **horizontal denominator-saturation theorem**, which is a clean p-adic restatement—but not a simplification—of the top-window Apéry zero-density problem.
