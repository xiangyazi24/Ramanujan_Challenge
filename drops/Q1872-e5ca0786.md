# Q1872 augmented determinant audit

## Summary

The bordered determinant identity is exact, but the attempted sparse Apéry augmentation does not provide a new invariant. It reduces to the same reciprocal pairing.

## Diagonal bordered determinant

For \(D=\operatorname{diag}(k_1,\ldots,k_n)\),

\[
M=\begin{pmatrix}D&\mathbf 1\\\mathbf1^T&0\end{pmatrix}.
\]

Schur complement gives

\[
\det M=-\left(\prod_i k_i\right)\sum_i k_i^{-1}.
\]

Hence the determinant is exactly the cleared reciprocal sum.

## Cyclic tridiagonal augmentation

For a singular cyclic tridiagonal Apéry matrix \(H\),

\[
\widetilde H=\begin{pmatrix}H&v\\w^T&0\end{pmatrix}
\]

satisfies, through the adjugate formula,

\[
\det\widetilde H=-w^T\operatorname{adj}(H)v.
\]

Since \(H\) has one-dimensional left and right kernels,

\[
\operatorname{adj}(H)=c\,r l^T,
\]

so the border only measures

\[
c(w^Tr)(l^Tv).
\]

All tested kernel-based choices are therefore equivalent to the original scalar pairing.
