# Q798: fixed-gap fibre combinatorial dichotomy audit

## 1. Setup

Fix q and h=qd. Let

\[
E=\{u: (u,u+h) \text{ is a fully transverse LGTQ-2 edge in the fibre}\}.
\]

Write \(R=|E|\). The graph with vertices \(u\) and edges \(u\to u+h\) is a disjoint union of paths because every vertex has at most one predecessor and one successor.

The hypothesis is

\[
R\ge c\,n/\log^2 n.
\]

The combinatorial conclusions below are exact. The arithmetic bounds needed to contradict this hypothesis are separate assumptions.

## 2. Exact path dichotomy

Let the path components have edge lengths \(L_i\). Then

\[
\sum_i L_i=R.
\]

Fix a threshold \(T\). Split components into:

- long paths: \(L_i\ge T\);
- short paths: \(L_i<T\).

If the number of adjacent edge pairs

\[
A=\sum_i \max(L_i-1,0)
\]

is large, then the graph contains many length-two chains

\[
u,\nu+h,\nu+2h.
\]

More precisely, if

\[
A\ge \eta R,
\]

then there are at least \(\eta R\) ordered chain occurrences (up to endpoint losses).

Otherwise

\[
A=o(R),
\]

and almost all edges lie in a matching after deleting one endpoint edge from every path component. Hence there is a matching of size

\[
M\ge R-A-o(R).
\]

This proves the first exact dichotomy.

## 3. Compression of the matching and rectangle extraction

For matching edges write their starts as \(u_i\). Since all lie in one quotient cell, the available start range is \(O(n/q)\).

For two matching edges define

\[
s=u_j-u_i.
\]

The corresponding four vertices are

\[
u_i,\quad u_i+h,\quad u_i+s,\quad u_i+s+h.
\]

A dyadic pigeonhole over the possible gaps gives:

- if \(M\) is large;
- and the number of possible compressed gaps is \(O(\log^2 n)\);

then some

\[
|s|=O(\log^2 n)
\]

occurs for many rectangles.

This is a pure combinatorial statement.

## 4. Weakest arithmetic bounds needed

To contradict LGTQ-2 failure with \(R\gg n/\log^2 n\), it is sufficient to prove either:

### Chain route

For every fixed q,h,

\[
\#\{u:u,u+h,u+2h\text{ are consecutive fully transverse hits}\}
=o(n/\log^2 n).
\]

### Rectangle route

For every fixed q,h and every \(s=O(\log^2 n)\),

\[
\#\{u:u,u+h,u+s,u+s+h\text{ form a valid rectangle}\}
=o(n/\log^2 n).
\]

These are sufficient because the combinatorial lemma forces one of these two populations to have positive density relative to R.

## 5. Transversality audit

Two original transverse edges give only:

\[
p\mid b_u,\quad p\nmid b_{u+h},
\]

and

\[
\ell\mid b_{u+h},\quad \ell\nmid b_u.
\]

For a second edge the analogous two conditions hold at its own characteristic.

They do NOT imply the full 4x4 off-diagonal unit pattern.

For a rectangle one needs additional statements such as

\[
p\nmid b_{u+s},\quad p\nmid b_{u+s+h},
\]

and analogous conditions for the other characteristics.

Therefore:

- rectangle extraction is exact;
- rectangle transversality is an extra arithmetic hypothesis.

## 6. Shared and crossing cases

### Shared-corner case

If \(s=\pm h\), vertices overlap. The rectangle degenerates into a chain of length two or three. It belongs to the chain alternative and must not be counted as a four-distinct rectangle.

### Crossing-order case

If starts interlace after ordering, the same path argument applies after translating by h. No new combinatorial obstruction appears.

## 7. Verdict

The proved content is the following implication:

\[
R\gg n/\log^2 n
\Longrightarrow
\text{many chains or many compressed-gap rectangles}.
\]

The missing arithmetic inputs are:

1. a chain upper bound;
2. or a rectangle upper bound with verified cross-characteristic transversality.

The original two-edge transversality does not by itself supply the 4x4 unit pattern. Thus the combinatorial dichotomy is a valid reduction, but it is not yet a closure of LGTQ-2.
