# Q7955 cold audit: one-node K3 specialization and endpoint middle extension

## Scope

Assume only:

1. a regular proper flat relative K3 model over a henselian trait;
2. a one-node semistable degeneration with ordinary double point local model;
3. nineteen horizontal Cartier divisors whose geometric intersection matrix has determinant 48.

No endpoint middle-extension theorem is assumed.

## 1. Local one-node l-adic sequence

For a geometric generic fiber \(X_{\bar\eta}\), special fiber \(X_{\bar s}\), and a single ordinary double point, the Clemens--Schmid/invariant-cycle input gives a one-dimensional vanishing quotient. In the l-adic formulation the relevant exact piece is

```tex
0 \to H^2(X_{\bar s},Q_l) \to H^2(X_{\bar\eta},Q_l) \to Q_l(-1) \to 0
```

up to the usual identification of the vanishing cycle summand and the choice of nearby-cycle normalization.

The Tate twist is forced by the fact that the vanishing cycle comes from a codimension-one Picard-Lefschetz contribution. Geometric Frobenius acts on \(Q_l(-1)\) by the inverse of the residue-field cardinality convention; arithmetic Frobenius acts oppositely. Any trace statement must fix this convention.

## 2. Exceptional curve versus vanishing quotient

After resolving the node, the exceptional curve is an algebraic divisor class in the resolved special fiber. It is not the same object as the vanishing quotient.

The distinction is:

| object | location | role |
|---|---|---|
| exceptional (-2)-curve | resolved special fiber | adds an algebraic divisor class |
| vanishing quotient | nearby-cycle quotient | measures failure of invariant cycles |

They interact through the Picard-Lefschetz pairing but cannot be identified without an additional comparison theorem.

## 3. Quadratic vanishing character

If the node is defined only after adjoining a quadratic extension, the monodromy character may be a quadratic character \(\chi\). The vanishing line then carries the character twist. The character does not change the dimension of the quotient; it changes Frobenius eigenvalues.

## 4. Consequence for E_br

Under the stated hypotheses alone, the following is justified:

* the local vanishing contribution has rank one;
* the local branch character is explicitly quadratic when the node splits only quadratically;
* the resolved exceptional curve belongs to the divisor lattice.

The stronger statement \(E_{br}=0\) requires an identification between the middle-extension trace defect and the local vanishing-cycle contribution. That identification is not supplied by the relative-model assumptions alone.

Therefore:

```text
relative regular model + divisor lattice determinant 48
        => local one-node invariant-cycle statement
        =/=> endpoint middle-extension branch defect vanishes
```

## 5. Middle-extension Mellin trace

A two-dimensional middle-extension Mellin trace congruence still requires endpoint hypotheses controlling:

1. local monodromy at the singular parameter;
2. conductor/drop in the sheaf extension;
3. compatibility of Frobenius traces with the chosen extension across the endpoint.

The relative K3 calculation does not prove these automatically.

## 6. Dependency table

| input | conclusion | status |
|---|---|---|
| regular proper flat model | nearby cycles exist; specialization maps defined | unconditional under assumption |
| one ordinary node | rank-one vanishing contribution | local theorem |
| nineteen horizontal divisors, determinant 48 | rank-19 algebraic lattice candidate | conditional on divisor hypotheses |
| quadratic splitting character | twisted vanishing Frobenius action | local calculation |
| endpoint middle extension | trace congruence | still requires monodromy hypotheses |

## 7. Citations

The exact theorem numbering for SGA 7, Clemens--Schmid analogues, and Katz-style middle-extension results was not independently verified here. They should not be cited with theorem numbers until checked against the edition used.

## 8. Minimal merge-ready proposition

```tex
\begin{proposition}
Let R be a henselian discrete valuation ring and let
\mathcal X/R be a regular proper flat relative surface whose generic
fiber is a K3 surface. Assume the geometric special fiber has exactly
one ordinary double point and let \widetilde X_s be its resolution.
Then the nearby-cycle specialization has a one-dimensional vanishing
quotient carrying the Picard--Lefschetz quadratic character (when the
node splits only quadratically). The exceptional curve of the
resolution is an algebraic divisor class on \widetilde X_s and is not
canonically identified with the vanishing quotient.
No assertion about endpoint middle-extension Mellin traces follows
without additional local monodromy hypotheses.
\end{proposition}
```

## 9. Verification pseudocode

```text
Input: local equation f over henselian DVR
1. Compute Jacobian ideal (f, df/dx_i).
2. Verify special fiber singular locus has length 1.
3. Check completed local ring is k[[x,y,z]]/(xy-z^2) (or equivalent ODP form).
4. Compute nearby-cycle ranks: invariant part and vanishing quotient.
5. Resolve node and record exceptional divisor class.
6. Verify exceptional class lies in divisor lattice, not in the quotient term.
7. Separately test endpoint sheaf monodromy data.
```

Unproved from the supplied assumptions: the global endpoint middle-extension congruence and any theorem identifying its branch defect with the local K3 vanishing calculation.
