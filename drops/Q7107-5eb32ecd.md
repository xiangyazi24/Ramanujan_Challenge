# Residual-prime rank amplification audit

## Conclusion

No known theorem from the order-two Apéry recurrence, Lucas symmetry, reflection `n -> p-1-n`, or the rank of apparition `rho(p)` forces a single aligned four-zero collision to generate an Omega(H) family of collisions or an Omega(rho(p)/H) family of zero witnesses. The tempting implication

```
p | aligned_content(a,b,c),  a+b+c <= H  ==>  rho(p) <= O(H)
```

is false.

The strongest unconditional statement available from the current setup is a **local algebraic witness statement**: an aligned collision gives a nonzero common-root/resultant condition for three gap continuants, and therefore certifies that the prime p lies in the finite exceptional support of the corresponding resultant content. It does not imply periodic proliferation of zeros.

## What the recurrence actually gives

The Apéry sequence modulo p is a second-order linear recurrence with nonconstant coefficients. The usual Lucas-type congruence and the reflection symmetry give relations between values in a complete period window, but they do not make the zero set a subgroup or an arithmetic progression.

For a fixed prime p, define

```
Z(p) = { n : b_n = 0 mod p }.
```

A collision

```
r, r+a, r+a+b, r+a+b+c
```

only says that the transfer matrix product over those three gaps maps a vector into a configuration with a common vanishing coordinate. It constrains one orbit segment. The transfer matrices before and after the segment are not forced to reproduce the same state.

The rank of apparition controls the first occurrence of a zero/divisibility phenomenon for a recurrence with suitable divisibility structure. The Apéry recurrence modulo p does not have the strong divisibility-sequence property needed to turn one zero into translated copies of that zero.

## The rank claim fails numerically and structurally

The listed residual primes already disprove the proposed scale relation:

```
prime     rho(p)     observed aligned height bound
107          27       H <= 28
131          33       H <= 28
157          79       H <= 28
653         327       H <= 28
```

For 157 and 653, an aligned witness occurs at total gap at most 28 while the rank is much larger. Therefore the only possible relation is not

```
rho(p) <= C H.
```

A corrected statement is one-sided and much weaker:

```
An aligned collision at gaps <= H can only involve primes p whose
finite-field transfer data satisfies a degree-O(H) algebraic condition.
```

Equivalently, p divides the content of a resultant of continuant polynomials of size O(H). This is a restriction on the prime support of the resultant, not on the recurrence period/rank.

## Why reflection does not amplify

The palindrome relation gives

```
b_r == b_{p-1-r} (mod p).
```

Hence every zero has a reflected zero. But this gives at most a two-point orbit

```
r <-> p-1-r.
```

It does not generate translations by the collision gaps. Unless an additional group law exists on the zero set, there is no implication

```
r in Z(p) => r+a in Z(p).
```

The aligned collision is therefore compatible with a zero set containing exactly one reflected pair plus the few points needed for the collision.

## Finite-field recurrence obstruction

A generic second-order recurrence over a finite field already provides a countermodel. Let

```
v_{n+1}=A_n v_n
```

with invertible 2x2 matrices A_n over F_p chosen periodically with period p. The scalar output can be chosen so that four positions

```
r,r+a,r+a+b,r+a+b+c
```

vanish, while all other positions in the period are nonzero except the forced reflection partners.

The transfer condition is local: three products of A_n are constrained. The remaining matrices are free. Thus a four-zero pattern does not force repetition at scale rho(p).

The Apéry case is more rigid, but its extra rigidity is reflection/Lucas symmetry, not a translation-invariant zero-set structure. No known identity upgrades the local resultant condition into a periodic propagation theorem.

## Consequence for the H^4 quadruple count

The aligned-content method currently saves the parameter in a different way: it replaces arbitrary quadruple enumeration by exact resultant contents and removes structural primes through saturation. It does not save a factor by proving that one collision creates many collisions.

A rank-amplification lemma strong enough to reduce the H^4 count would require a new theorem of the form

```
local four-zero transfer degeneracy
        =>
large structured subset of Z(p).
```

The current Apéry symmetries do not imply such a theorem.

Therefore the correct R1 status is:

```
Aligned collision => exceptional prime/resultant divisibility.

Aligned collision !=> rho(p)=O(H).

Aligned collision !=> Omega(rho(p)/H) witnesses.

A single aligned collision may be genuinely isolated.
```
