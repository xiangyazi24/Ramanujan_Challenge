# P3.2 exact second Frobenius jet: the corrected `Lambda^2` formula

## Verdict

The exact finite formulas are

```text
A[n,k] = binom(n,k)^2 * binom(n+k,k)^2

U[n,k] = H[n+k] - H[n-k]
       = sum_{j=n-k+1}^{n+k} 1/j

V[n,k] = H2[n+k] - H2[n-k]
       = sum_{j=n-k+1}^{n+k} 1/j^2

W[k]   = H2[k]
       = sum_{j=1}^{k} 1/j^2

b[n] = sum_{k=0}^n A[n,k]

g[n] = 2 * sum_{k=0}^n A[n,k] * U[n,k]

h[n] = 2 * sum_{k=0}^n A[n,k]
                * ( U[n,k]^2 - V[n,k] - W[k] ).
```

Here

```text
H[0] = H2[0] = 0,
H[m]  = sum_{j=1}^m 1/j,
H2[m] = sum_{j=1}^m 1/j^2.
```

These formulas satisfy the shifted recurrence through `Y^2`, with the stated initial data, and they imply term-by-term that

```text
Lambda[n]   * g[n] is an integer,
Lambda[n]^2 * h[n] is an integer.
```

The subtle point is the range `n-k+1 <= j <= n+k`: it can contain indices in `(n,2n]`. One must use the factor `binom(n+k,k)` to absorb the unique possible missing prime-power factor. It is false to argue that every such `j` divides `Lambda[n]`.

Consequently, in the current principal-part normalization the universal second-jet denominator can be taken to divide `Lambda[D]^2`, not `Lambda[D]^4`. Thus the carrier exponent drops by two, from `7` to `5`, under the same remaining normalization. This means a universal clearing denominator; it is not a claim that the reduced denominator of each individual coefficient is literally equal to `Lambda[D]^2`.

A useful sharpness check is `n=12`: the corrected formula gives denominator `5775` for `h[12]`; `Lambda[12]*h[12]` still has denominator `5`, while `Lambda[12]^2*h[12]` is integral. So exponent `1` is not a universal replacement for exponent `2`.

# 1. Definitions and the exact formulas

Write

```text
P(x) = 34*x^3 + 51*x^2 + 27*x + 5.
```

The Frobenius jet is defined by

```text
G[-1](Y) = 0,
G[0](Y)  = 1,

(Y+n+1)^3 G[n+1](Y)
  - P(Y+n) G[n](Y)
  + (Y+n)^3 G[n-1](Y) = 0,

G[n](Y) = b[n] + g[n]*Y + h[n]*Y^2 + O(Y^3).
```

For `0 <= k <= n`, define

```text
A[n,k] = binom(n,k)^2 * binom(n+k,k)^2.
```

Define the first and second harmonic sums by the exact ranges

```text
H[m] = sum_{j=1}^m 1/j,       H[0] = 0,
H2[m] = sum_{j=1}^m 1/j^2,    H2[0] = 0.
```

For each `0 <= k <= n`, define

```text
U[n,k]
  = H[n+k] - H[n-k]
  = sum_{j=n-k+1}^{n+k} 1/j.

V[n,k]
  = H2[n+k] - H2[n-k]
  = sum_{j=n-k+1}^{n+k} 1/j^2.

W[k]
  = H2[k]
  = sum_{j=1}^{k} 1/j^2.
```

The empty sums at `k=0` are zero.

The corrected finite formulas are

```text
b[n] = sum_{k=0}^n A[n,k].

g[n] = 2 * sum_{k=0}^n A[n,k] * U[n,k].

h[n] = 2 * sum_{k=0}^n A[n,k]
                * (U[n,k]^2 - V[n,k] - W[k]).
```

The `-W[k] = -H2[k]` term is indispensable.

# 3. A terminating hypergeometric jet whose first three coefficients are exactly `b,g,h`

For a rising factorial

```text
(a)_k = a*(a+1)*...*(a+k-1),
(a)_0 = 1,
```

define, for `0 <= k <= n`,

```text
T[n,k](Y)
 = ((-n)_k * (n+1)_k
    * (-n-2Y)_k * (n+1+2Y)_k
    * (1-Y)_k^2 * (1+Y)_k^2)
   / (k!)^8.
```

Because of the fixed factor `(-n)_k`, this is terminating: set

```text
T[n,k](Y) = 0    for k > n.
```

At `Y=0`,

```text
T[n,k](0) = A[n,k].
```

More importantly, division by `A[n,k]` gives an elementary product with no gamma-function ambiguity:

```text
T[n,k](Y) / A[n,k]
 = product_{j=n-k+1}^{n+k} (1 + 2Y/j)
   * product_{j=1}^{k} (1 - Y^2/j^2)^2.
```

Taking the formal logarithm through degree two,

```text
log(T[n,k](Y)/A[n,k])
 = 2*U[n,k]*Y
   - 2*(V[n,k] + W[k])*Y^2
   + O(Y^3).
```

Exponentiating,

```text
T[n,k](Y)
 = A[n,k]
   + 2*A[n,k]*U[n,k]*Y
   + 2*A[n,k]*(U[n,k]^2 - V[n,k] - W[k])*Y^2
   + O(Y^3).
```

Therefore, if

```text
Q[n](Y) = sum_{k=0}^n T[n,k](Y),
```

then the coefficients of `1,Y,Y^2` in `Q[n]` are exactly the claimed `b[n],g[n],h[n]`.

It remains to prove that `Q[n]` satisfies the shifted recurrence modulo `Y^3`.

# 4. Exact WZ/telescoping certificate through `Y^2`

Everything in this section is a finite rational-function identity. No convergence or numerical computation is used.

For `n >= 1`, put

```text
x = n + Y.
```

Define

```text
R0[n,k](Y)
 = 4*(2*x+1)
     * ( k*(2*k+1) - (2*x+1)^2 ).
```

Define the second-order correction

```text
S[n,k]
 = -16*(2*n+1)*k^2 / (n*(n+1)).
```

Set

```text
R[n,k](Y) = R0[n,k](Y) + S[n,k]*Y^2,

C[n,k](Y) = R[n,k](Y) * T[n,k](Y).
```

The certificate is

```text
(n+Y+1)^3*T[n+1,k](Y)
 - P(n+Y)*T[n,k](Y)
 + (n+Y)^3*T[n-1,k](Y)

 = C[n,k](Y) - C[n,k-1](Y) + O(Y^3).
```

This holds for all terms in the finite telescoping range `0 <= k <= n+1`, with the endpoint conventions explained below.

## 4.1 Interior substitution

For `1 <= k <= n`, the exact term ratios are

```text
T[n+1,k]/T[n,k]
 = ((n+k+1)*(n+k+1+2Y))
   / ((n-k+1)*(n-k+1+2Y)).
```

```text
T[n-1,k]/T[n,k]
 = ((n-k)*(n-k+2Y))
   / ((n+k)*(n+k+2Y)).
```

```text
T[n,k]/T[n,k-1]
 = ((n-k+1)*(n-k+1+2Y)
    *(n+k)*(n+k+2Y)
    *(k^2-Y^2)^2)
   / k^8.
```

First omit the `S*Y^2` correction and use only `R0`. Direct substitution of those three ratios gives

```text
[(n+Y+1)^3*T[n+1,k]
 - P(n+Y)*T[n,k]
 + (n+Y)^3*T[n-1,k]] / T[n,k]

 - [ R0[n,k]
     - R0[n,k-1] / (T[n,k]/T[n,k-1]) ]

 = E[n,k]*Y^2 + O(Y^3),
```

where the residual is exactly

```text
E[n,k]
 = 16*(2*n+1)*k^2
     *(2*k^2 - 2*k - n*(n+1))
   / ((n-k+1)^2*(n+k)^2).
```

The correction `S` was chosen so that its finite difference is exactly this residual. Since it is multiplied by `Y^2`, only the `Y=0` value of the `k`-ratio matters. At `Y=0`,

```text
T[n,k]/T[n,k-1]
 = ((n-k+1)^2*(n+k)^2)/k^4.
```

The needed polynomial identity is

```text
((n-k+1)^2*(n+k)^2)*S[n,k]
 - k^4*S[n,k-1]

 = 16*(2*n+1)*k^2
     *(2*k^2 - 2*k - n*(n+1)).
```

Substituting

```text
S[n,k] = -16*(2*n+1)*k^2/(n*(n+1))
```

reduces both sides to the same degree-four polynomial in `k`. Hence

```text
S[n,k]
 - S[n,k-1] / (T[n,k](0)/T[n,k-1](0))
 = E[n,k],
```

which cancels the entire `Y^2` residual. This proves the certificate for `1 <= k <= n`.

## 4.2 Lower boundary `k=0`

Set

```text
C[n,-1](Y) = 0.
```

Since `T[m,0](Y)=1` for every `m`, the left side at `k=0` is exactly

```text
(x+1)^3 - P(x) + x^3
 = -4*(2*x+1)^3.
```

On the certificate side,

```text
R[n,0](Y) = -4*(2*x+1)^3,
S[n,0] = 0.
```

So the `k=0` identity is exact, not merely modulo `Y^3`.

## 4.3 Upper boundary `k=n+1`

Because `(-n)_{n+1}=0`,

```text
T[n,n+1](Y) = 0,
C[n,n+1](Y) = 0.
```

Also `T[n-1,n+1](Y)=0`. Thus the `k=n+1` certificate reduces to

```text
(n+Y+1)^3*T[n+1,n+1](Y)
 = -C[n,n](Y) + O(Y^3).
```

Divide by the nonzero terminating diagonal term `T[n,n](Y)`. The exact diagonal ratio is

```text
T[n+1,n+1](Y) / T[n,n](Y)
 = 4*(2*n+1)^2/(n+1)^2
   * (1 + 2Y/(2*n+1))
   * (1 + Y/(n+1))
   * (1 - Y^2/(n+1)^2)^2.
```

At `k=n`, the correction is

```text
S[n,n] = -16*(2*n+1)*n/(n+1).
```

Therefore the boundary identity is the explicit degree-two expansion

```text
(n+Y+1)^3
 * 4*(2*n+1)^2/(n+1)^2
 * (1 + 2Y/(2*n+1))
 * (1 + Y/(n+1))
 * (1 - Y^2/(n+1)^2)^2

 + 4*(2*n+2Y+1)
     * (n*(2*n+1) - (2*n+2Y+1)^2)

 - 16*(2*n+1)*n/(n+1)*Y^2

 = O(Y^3).
```

Expanding the three coefficients `Y^0,Y^1,Y^2` gives `0,0,0`. This is the missing upper boundary term; it is why one cannot simply differentiate a naively truncated continuous-index Apéry sum and ignore the edge.

## 4.4 Telescoping the finite sum

Sum the certificate over

```text
k = 0,1,...,n+1.
```

The right side telescopes to

```text
C[n,n+1](Y) - C[n,-1](Y) = 0 - 0 = 0.
```

Because `T[n,k]=0` for `k>n`, the left side is exactly

```text
(n+Y+1)^3*Q[n+1](Y)
 - P(n+Y)*Q[n](Y)
 + (n+Y)^3*Q[n-1](Y)
 = O(Y^3)
```

for every `n >= 1`.

For `n=0`, one checks directly that

```text
Q[0](Y) = 1,

Q[1](Y)
 = 1 + 4*(1+2Y)*(1+Y)*(1-Y^2)^2
 = 5 + 12Y + 0*Y^2 + O(Y^3).
```

Hence

```text
(1+Y)^3*Q[1](Y) - P(Y)*Q[0](Y) = O(Y^3),
```

because both sides have coefficients

```text
5 + 27Y + 51Y^2
```

through degree two.

Thus `Q[-1]=0,Q[0]=1` and the shifted recurrence agree with the defining recurrence for `G` through `Y^2`. The coefficient recurrences are triangular, so these coefficients are unique. Therefore the finite formulas in Section 1 are proved.

For reference, the three coefficient recurrences obtained by substitution are

```text
(n+1)^3*b[n+1] - P(n)*b[n] + n^3*b[n-1] = 0.
```

```text
(n+1)^3*g[n+1] - P(n)*g[n] + n^3*g[n-1]
 + 3*(n+1)^2*b[n+1]
 - (102*n^2 + 102*n + 27)*b[n]
 + 3*n^2*b[n-1]
 = 0.
```

```text
(n+1)^3*h[n+1] - P(n)*h[n] + n^3*h[n-1]
 + 3*(n+1)^2*g[n+1]
 - (102*n^2 + 102*n + 27)*g[n]
 + 3*n^2*g[n-1]
 + 3*(n+1)*b[n+1]
 - (102*n + 51)*b[n]
 + 3*n*b[n-1]
 = 0.
```

# 5. Prime-by-prime proof that `Lambda[n]^2*h[n]` is integral

Let

```text
Lambda[n] = lcm(1,2,...,n),
Lambda[0] = 1.
```

Fix `n>=1`, `0<=k<=n`, and write

```text
D = binom(n,k),
C = binom(n+k,k),
A[n,k] = D^2*C^2.
```

The only nontrivial denominator issue is the range

```text
R[n,k] = {n-k+1, ..., n+k},
```

because its upper part may lie above `n`.

## Lemma 5.1 -- the missing prime power is unique

Fix a prime `p` and put

```text
e = v_p(Lambda[n]).
```

Equivalently, for `p<=n`, `e` is the largest integer with `p^e <= n`; for `p>n`, take `e=0`.

For every integer `j` with `1 <= j <= 2n`,

```text
v_p(j) <= e+1.
```

If equality occurs, then necessarily

```text
j = q := p^(e+1),

n < q <= 2n.
```

Indeed `q>n` by maximality of `e`, and a second multiple `2q` is already `>2n`. Thus there is at most one index in `(n,2n]` whose `p`-valuation exceeds the `p`-valuation supplied by `Lambda[n]`.

## Lemma 5.2 -- `binom(n+k,k)` supplies the missing `p`

Suppose the exceptional index

```text
q = p^(e+1)
```

lies in `R[n,k]`. Since `q>n`, this means

```text
q <= n+k.
```

Also `k<=n<q`. In Legendre's formula,

```text
v_p(binomial(n+k,k))
 = sum_{r>=1}
     ( floor((n+k)/p^r)
       - floor(n/p^r)
       - floor(k/p^r) ).
```

Each summand is `0` or `1`. At `r=e+1`,

```text
floor((n+k)/q) = 1,
floor(n/q) = 0,
floor(k/q) = 0.
```

Hence

```text
v_p(C) >= 1.
```

This is the exact repair for harmonic indices in `(n,2n]`.

## Lemma 5.3 -- every first-harmonic denominator is cleared by `Lambda[n]*C`

For every `j in R[n,k]`,

```text
Lambda[n]*C / j
```

is an integer.

Prime-by-prime: if `v_p(j)<=e`, `Lambda[n]` already supplies enough `p`; if `v_p(j)=e+1`, Lemma 5.1 forces `j=q`, and Lemma 5.2 supplies one extra `p` from `C`.

Therefore

```text
Lambda[n]*C*U[n,k]
 = sum_{j=n-k+1}^{n+k} Lambda[n]*C/j
```

is an integer.

The same lemma immediately gives

```text
Lambda[n]^2*C^2*V[n,k]
 = sum_{j=n-k+1}^{n+k} (Lambda[n]*C/j)^2
```

as an integer.

For `W[k]`, all indices satisfy `j<=k<=n`, so simply

```text
Lambda[n]^2*W[k]
 = sum_{j=1}^k (Lambda[n]/j)^2
```

is an integer.

## Finish the second-jet denominator

Using `A=D^2*C^2`,

```text
Lambda[n]^2*A[n,k]*U[n,k]^2
 = D^2 * (Lambda[n]*C*U[n,k])^2,
```

which is integral.

Also

```text
Lambda[n]^2*A[n,k]*V[n,k]
 = D^2
   * (Lambda[n]^2*C^2*V[n,k]),
```

which is integral.

And

```text
Lambda[n]^2*A[n,k]*W[k]
 = A[n,k]
   * sum_{j=1}^k (Lambda[n]/j)^2,
```

which is integral.

Therefore every individual `k`-summand in

```text
Lambda[n]^2*h[n]
 = 2 * sum_{k=0}^n
     Lambda[n]^2*A[n,k]
     *(U[n,k]^2 - V[n,k] - W[k])
```

is an integer. Hence

```text
Lambda[n]^2*h[n] is an integer
```

for every `n>=0`.

The identical first-order lemma also yields

```text
Lambda[n]*g[n] is an integer.
```

No cancellation between different `k` is needed for either denominator statement.

# 6. Principal-part denominator and the `7 -> 5` carrier improvement

The proved jet bounds are

```text
b[n] in Z,
Lambda[n]*g[n] in Z,
Lambda[n]^2*h[n] in Z.
```

Thus, for interval depth `D`, the second Frobenius/principal-part coefficient has a universal denominator dividing

```text
Lambda[D]^2.
```

Again: this is a clearing denominator, not necessarily the reduced denominator of each coefficient.

In the existing normalized-carrier bookkeeping described in Q2124, the old exponent `7` came from the fixed three powers already present in the continuant/interval normalization plus a four-power allowance for the second jet. Replacing that allowance by the proved two-power bound gives

```text
old universal exponent: 3 + 4 = 7,
new universal exponent: 3 + 2 = 5.
```

So the normalized universal interval carrier should use exponent `5`, not `7`, once the second-jet estimate is substituted. The local GitHub snapshot does not contain the caller-local `LCM7` proof/script, so I cannot truthfully claim to have edited or mechanically re-run that specific script; the mathematical exponent replacement itself is proved above.

The exponent `2` at the jet level is genuinely needed in general. For example the formula gives

```text
h[12] = 174773323116440167886 / 5775,
Lambda[12] = 27720,
```

and therefore

```text
Lambda[12]*h[12] has denominator 5,
Lambda[12]^2*h[12] is an integer.
```

# 8. Compact independent `Fraction` checker

The following script is only a checker; none of the proof above depends on finite computation.

```python
from fractions import Fraction
from math import comb, gcd


def qsum(xs):
    return sum(xs, Fraction(0))


def P(n):
    return 34*n**3 + 51*n**2 + 27*n + 5


def P1(n):
    return 102*n**2 + 102*n + 27


def P2(n):
    # coefficient of Y^2 in P(n+Y) = P''(n)/2
    return 102*n + 51


def lcm_upto(n):
    L = 1
    for j in range(1, n + 1):
        L = L*j // gcd(L, j)
    return L


def jets(n):
    b = Fraction(0)
    g = Fraction(0)
    h = Fraction(0)
    for k in range(n + 1):
        A = comb(n, k)**2 * comb(n + k, k)**2
        U = qsum(Fraction(1, j)
                 for j in range(n - k + 1, n + k + 1))
        V = qsum(Fraction(1, j*j)
                 for j in range(n - k + 1, n + k + 1))
        W = qsum(Fraction(1, j*j)
                 for j in range(1, k + 1))
        b += A
        g += 2*A*U
        h += 2*A*(U*U - V - W)
    return b, g, h


# Requested low-index values.
J = [jets(n) for n in range(4)]
assert [x[1] for x in J] == [0, 12, 210, 4438]
assert [x[2] for x in J] == [0, 0, 72, 2160]
```
