# 2. Fix the base-p word orientation once

Mellit--Vlasenko write a base-`p` expansion in **least-significant digit first** order:

```text
n = n_0+n_1 p+...+n_r p^r = overline(n_0 ... n_r).
```

Their concatenation

```text
a*b = a + b p^ell(a)
```

therefore puts the word for `a` on the **low** side and the word for `b` on the **high** side.

For CRJD it is safer not to use `*` when the low block has leading zero padding. Write instead

```text
n = c p^k + u,        0<=u<p^k,                     (2.1)
```

and regard `u` as a **fixed-width k-digit low word**

```text
U=(u_0,...,u_(k-1)),
```

including any zero digits at its high end. The digits of `c` form the high word `C`. Thus the full word is

```text
U | C                                                     (2.2)
low --> high.
```

By definition of `k`, the two indices `n` and `n-h` have the same high word `C` after deleting the first `k` low digits.

At depth `k-1` they do not have the same prefix. Let

```text
d=p^(k-1),
r=n mod d.                                             (2.3)
```

Then necessarily

```text
0<=r<h.                                                (2.4)
```

Indeed, if `r>=h`, subtracting `h` would stay in the same `d`-block, contradicting minimality of `k`. Equation (2.4) is the exact borrow witness used later.

# 4. What the Mellit--Vlasenko ghost theorem really gives

For a Laurent polynomial satisfying the one-interior-point hypothesis, Mellit--Vlasenko construct `c_m in Z_p` such that

```text
b_N = sum_(N=N^(1)*...*N^(r)) c_(N^(1)) ... c_(N^(r)),    (4.1)
```

where the sum is over all contiguous partitions of the base-`p` digit word, and

```text
c_M in p^(ell(M)-1) Z_p.                              (4.2)
```

Their proof comes from ghost polynomials `R_s`, with

```text
R_s == 0 mod p^s,
```

and the combinatorial fact that an indecomposable tuple of length `L` has total ghost weight at least `L-1`.

Apply this at the seam `(2.2)`. Keep the fixed-width zero digits in `U`; do **not** silently shorten the low word to the canonical expansion of the integer `u`.

There are two kinds of terms in (4.1):

1. partitions having a cut at the low/high seam;
2. partitions with one contiguous block crossing that seam.

If a crossing block uses `a>=1` low digits and `b>=1` high digits, its length is `a+b`, so the corresponding indecomposable coefficient has the guaranteed order

```text
v_p(c_cross) >= a+b-1 >= 1.                           (4.3)
```

This is the entire guaranteed seam gain. In particular, a block using one digit on each side has only

```text
v_p(c_cross) >= 1.                                    (4.4)
```

There is no factor `p^v_p(b_c)` in (4.3). The other blocks are merely `Z_p`-integral and can themselves be nonunits.

This is exactly compatible with the canonical loss `4 -> 3` in (3.2). A nonunit high-prefix value is a **sum of many block terms**; its valuation need not be inherited by each seam-crossing term after one more digit is attached.

Therefore the scalar ghost decomposition supplies a filtration by **crossing length**, not by **prefix Apéry valuation**.

That distinction is fatal to a proof of (1.3) based on replacing `lambda` by `v_p(b_c)`.

# 5. Nonunit prefix denominators: the exact loss formula

The safest Dwork statement here is the cross-multiplied Samol--van Straten/Mellit--Vlasenko congruence

```text
b_(a+m p^s) b_floor(a/p)
 ==
 b_a b_(floor(a/p)+m p^(s-1))             (mod p^s). (5.1)
```

It holds without dividing by either prefix coefficient.

Suppose abstractly that

```text
A B - C D in p^s Z_p.                                (5.2)
```

If `B,D` are nonzero and one insists on dividing in `Q_p`, then

```text
A/D - C/B = (A B-C D)/(B D),
```

so the exact guaranteed precision is only

```text
v_p(A/D-C/B) >= s-v_p(B)-v_p(D).                    (5.3)
```

If the right side is nonpositive, (5.1) gives no normalized congruence at all.

This is the termwise denominator ledger Q3192 asks for. Every time a Dwork cross-product is converted into a quotient, **both denominator valuations must be subtracted**. No argument may replace them by units merely because the underlying ratio looks like a Frobenius quotient.

The canonical example `(3.3)` shows that this is not bookkeeping pessimism: an actual prefix quotient can have negative valuation.

Hence the statement

```text
R_p(N):=b_N/b_floor(N/p) is always in Z_p
```

is false for the present Apéry sequence. For example `N=55,56`, `p=5` gives valuation `-1`.

# 9. Borrow-chain budget: an unconditional theorem

The following argument uses only the definition of `k`; no Dwork inheritance occurs.

## Lemma 9.1 -- one return gives one divisible boundary

For each return prime `p`, let `h=h_p` and `k=k_p` be as in Section 1. Put

```text
d=p^(k-1),
r=n mod d.                                           (9.1)
```

For `k=1`, take `d=1,r=0`. For `k>1`, minimality of `k` says

```text
floor(n/d) != floor((n-h)/d).
```

Therefore subtraction by `h` crosses a multiple of `d`, which is equivalent to

```text
0<=r<h.                                               (9.2)
```

Consequently

```text
p^(k-1) | n-r,
0<=r<H.                                               (9.3)
```

## Theorem 9.2 -- global digit-borrow budget

Group the return primes by their witness `r` in (9.3). For fixed `r`, the primes are distinct, so

```text
product_(p:r_p=r) p^(k_p-1) | n-r.
```

Taking logarithms,

```text
sum_(p:r_p=r) (k_p-1) log p <= log(n-r).              (9.4)
```

Summing `0<=r<H` gives

```text
boxed:
sum_(p in P_H(n)) (k_p-1) log p <= H log n.           (9.5)
```

Let

```text
rho_H(n)=sum_(p in P_H(n)) log p.                     (9.6)
```

Then

```text
boxed:
K_H(n):=sum_p k_p log p
       <= H log n + rho_H(n).                         (9.7)
```

Thus whenever the preceding return-radical stage supplies

```text
rho_H(n)=o(n)                                         (9.8)
```

and the campaign has

```text
H log n=o(n),                                         (9.9)
```

we obtain

```text
boxed: K_H(n)=o(n).                                   (9.10)
```

This is the exact global resource that a CRJD theorem is allowed to spend.

# 11. A genuinely averaged sufficient CRJD theorem

The pointwise tail is still an `L^1` condition. A weaker averaged target is available.

Put

```text
Q_H(n)=sum_p (w_p^2/k_p) log p.                      (11.1)
```

```text
S_H(n)
```

and therefore

```text
boxed:
S_H(n)^2 <= K_H(n) Q_H(n).                           (11.2)
```

If

```text
rho_H(n)=o(n),
```

This is a genuinely weighted-average theorem: isolated primes with `w_p/k_p` much larger than any fixed constant are allowed.

Neither scalar Mellit--Vlasenko ghosts nor the presently exposed all-exponent Padé content theorem proves (11.1). But (11.1) is a substantially weaker and more correctly aligned arithmetic target than a universal pointwise `C`.

# 12. What a successful ghost proof must actually prove

A scalar theorem of the form


cannot be part of the proof: it is false at `(p,c,u)=(5,11,0),(5,11,1)`.

A correct all-depth statement has to keep the canonical vector and all nonunit factors integral. One possible theorem-shaped target is:

```text
Weighted seam theorem.
Let n and n-h have common high digit word after k low digits, and let
lambda=min(v_p(b_n),v_p(b_(n-h))).
Then the canonical marked ghost/jet module satisfies

    min(v_p(b_n)-lambda,
        v_p(E_n)-2*lambda) <= Ck

whenever the left side is positive.                              (12.1)
```

The better asymptotic target is only the integrated version

```text
sum_p [
  min(v_p(b_n)-lambda_p,
      v_p(E_n)-2*lambda_p)
  -2k_p
```
