## 1. Fixed-width stencil class

Consider any determinant/Bézout construction whose entries are obtained from a fixed number of neighboring values

```text
b_{n+i}, B_{n+i},   -r <= i <= r
```

with coefficients in the rational function field `Q(n)`, followed by clearing denominators. Such a construction produces an integer certificate

```text
C_n = det(M_n) * D_n
```

satisfying `gcd(b_n,B_n) | C_n` only if the determinant eliminates the common solution of the two holonomic recurrences.

The Apéry recurrence has order two. The parity subsequences of `B_n` also have order one after hypergeometric normalization. Therefore the minimal elimination determinant is a contiguous resultant of a second-order recurrence with a first-order recurrence.

## 2. First obstruction

The determinant necessarily contains the leading factorial content coming from the cleared recurrence coefficients. In the Apéry recurrence the coefficient product over a fixed stencil contains

```text
prod_{j=1}^{m} j^3
```

terms (after shifting by `n`, these are products of linear factors of degree three). The logarithmic height contribution is therefore

```text
log((n!)^c) = c n log n + O(n)
```

for a positive constant `c` depending on the stencil width.

This is already larger than the required `o(n)` scale. Removing the obvious factorial/binomial factors leaves the normalized determinant, but the remaining resultant is not proved to be subexponential. The fixed-width closure therefore does not produce the requested `C_n`.

0 <= log(G_n)-log(Gamma_n)=O(n^(2/3)).

The unresolved quantity is exactly the primitive odd quotient height. A local holonomic resultant does not control it because the recurrence certificates introduce factorial-size denominators before cancellation.
