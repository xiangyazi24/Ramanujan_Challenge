# 2. Positive Euler transform derived from the defining series

Let

```text
f_m = 1/(2m+1)^2,
Delta f_m = f_m - f_(m+1).
```

The finite Euler transformation followed by passage to the limit gives

```text
G = sum_(m>=0) (-1)^m f_m
  = sum_(k>=0) Delta^k f_0 / 2^(k+1).
```

This can be derived directly from finite geometric summation; no special value is used. There is also a useful elementary integral evaluation:

```text
Delta^k f_0
 = integral_0^1 (-log x) (1-x^2)^k dx
 = 4^k (k!)^2/(2k+1)! * O_k,

O_k = sum_(j=0)^k 1/(2j+1).
```

For the last equality, put

```text
A_k = integral_0^1 (1-x^2)^k dx
    = 4^k (k!)^2/(2k+1)!,
I_k = integral_0^1 (-log x)(1-x^2)^k dx.
```

Integration by parts gives

```text
I_k = (2k/(2k+1)) I_(k-1) + A_k/(2k+1),
```

so `I_k = A_k O_k` by induction.

Thus define rational positive terms

```text
a_0 = 1/2,
O_0 = 1,
c_k = a_k O_k,

a_(k+1) = ((k+1)/(2k+3)) a_k,
O_(k+1) = O_k + 1/(2k+3),
E_K = sum_(k<K) c_k.
```

Then

```text
G = sum_(k>=0) c_k.
```

Moreover

```text
c_(k+1)/c_k
 = ((k+1)/(2k+3)) * O_(k+1)/O_k
 < 1/2.
```

Indeed `O_k >= 1 > 2(k+1)/(2k+3)`. Therefore the elementary two-sided tail bound is

```text
E_K < G < E_K + 2 c_K.                      (2.1)
```

For later diagnostics I used

```text

U_n = E_(K_n) + 2 c_(K_n).
```

At `n=0`, all relevant data are exact:

```text

c_12 = 1939818138112 / 28278652639111875,

E_12 - r_(0,2)
 = 678200584189 / 2461175042876550 > 0,
```

# 5. Accelerated Euler fiber and exact forced recurrence

```text
K_n = 7n+12,
E_n = E_(K_n),
U_n = E_(K_n) + 2c_(K_n).
```

```text
a_n = (E_n-r_(n,2))/g_n,
b_n = (r_(n,0)-U_n)/g_n,
w_n = 2c_(K_n)/g_n.
```

They satisfy the exact simplex identity

```text
a_n + b_n + w_n = 1.                        (5.1)
```

By the elementary Euler bound (2.1),

```text
a_n > 0 and b_n > 0
```

would imply the desired strict endpoint inequalities.

Define rational block parameters

```text
tau_n = c_(K_(n+1))/c_(K_n),

s_n = [E_(K_(n+1))-E_(K_n)]/[2c_(K_n)],

u_n = 1-s_n-tau_n
    = [U_n-U_(n+1)]/[2c_(K_n)].
```

All three are positive. Equations (4.3)--(4.4) give the exact forced recurrence

```text
b_(n+1) = [b_n-h_0+u_n w_n]/d_n,

w_(n+1) = tau_n w_n/d_n,

a_(n+1) = [a_n+s_n w_n-(1-h_2)]/d_n.       (5.2)
```

Equivalently, the exact one-step corridor needed for positivity is


# 6. Exact no-thickness theorem for polyhedral cones

The following explains why the previous rectangular and triangular searches fail.

## Proposition

Let `C_n` be any family of sets in the normalized state

```text
(X,Y,Xhat,Yhat,w,b)
```

for `n >= 6`, with these properties:

1. `C_n` lies in the projective cone (3.3);
2. `C_n` implies `a=1-b-w >= 0`, `b >= 0`, and `w >= 0`;
3. `C_n` is forward invariant under the exact map (3.1), (3.2), and (5.2).

Then every vertical fiber is a singleton: for fixed `(X,Y,Xhat,Yhat,w)`, the set of admissible `b` values contains at most one point.

## Proof

Take two states in the same fiber, with `b^+ != b^-`. Their four projective coordinates and their `w` coordinate have identical future evolution. Subtracting the two `b` recurrences in (5.2) gives

```text
b^+_(n+1)-b^-_(n+1)
 = [b^+_n-b^-_n]/d_n.
```

By (4.6), `d_n <= 1/4`. Hence after `k` steps,

```text
|b^+_(n+k)-b^-_(n+k)|
 >= 4^k |b^+_n-b^-_n|.
```

But condition 2 gives `0 <= b <= 1`, so the left side is at most one. This is impossible for large `k` unless `b^+_n=b^-_n`.

QED.

## Consequence

A full-dimensional rational polyhedral cone cannot close the problem. Any successful bounded polyhedral certificate must contain an **equality**, not merely facet inequalities: it must be the graph of one exact function

```text
b = beta_n(X,Y,Xhat,Yhat,w).                 (6.1)
```

The exact graph equation is

```text
beta_(n+1)(F_n(X,Y,Xhat,Yhat), tau_n*w/d_n)
 = [beta_n(X,Y,Xhat,Yhat,w)-h_0+u_n*w]/d_n. (6.2)
```

It must additionally satisfy

```text
0 < beta_n < 1-w.                            (6.3)
```

Thus the requested nonrectangular cone exists only if one first finds the missing exact stable graph. Equation (6.2) is an adjoint/connection identity in disguise.

This proposition does not rule out an exact rational graph, a positive remainder sum, or a Catalan Wronskian coboundary. It does rule out every genuine finite-width rectangle, triangle, trapezoid, or higher-facet rational polytope in the accelerated state.

```python
NMAX = 70
```

# 10. Final assessment

The arithmetic part of the projective dynamics is now tightly controlled by a small rational cone. The obstruction is not another missing corner estimate. It is the scalar connection graph (6.2).

A genuine closure must therefore provide one of:

1. an exact rational/finite-sum stable graph satisfying (6.2)--(6.3);
2. a positive remainder sum or integral derived directly from the defining alternating Catalan series;
3. a Catalan Wronskian/adjoint coboundary whose boundary term is elementary and whose residual has a positive sign.

Without one of these, replacing the `sorry` by a polyhedral induction would be unsound. The current answer supplies a rigorous no-go for nondegenerate cones, not a proof of the missing theorem.
