# Microscopic equidistribution and the AFP obstruction

## Executive conclusion

The key point is that **microscopic equidistribution is substantially stronger than Katz-Sarnak/Deligne equidistribution**. The available trace-function technology gives errors of square-root size, while AFP needs an error of constant size after sampling only p-1 characters.

The obstruction is not lack of a sufficiently strong random matrix model. The obstruction is that a fixed finite-field Mellin transform can have arithmetic correlations invisible to macroscopic equidistribution.

The Apéry problem requires a special anti-concentration theorem for its Mellin transform, not a generic equidistribution theorem.

---

## (A) Katz-Sarnak does not give microscopic pointwise equidistribution

For a lisse sheaf F with geometric monodromy G, Chebotarev/Katz gives statements of the form

```
#{t : Frob_t in C}
 = |C|/|G| * p + O(C(F) sqrt(p)).
```

The error is controlled by conductor and square-root cancellation. This is optimal in general.

For the zero-trace subset

```
C_0 = {g in G : tr(g)=0},
```

one obtains

```
#{t : tr(Frob_t)=0}
 = density(C_0)p + O(sqrt(p)).
```

This does not imply O(1).

Katz-Sarnak predicts the limiting distribution as p tends to infinity, but it is a macroscopic statement. It does not control individual finite-field fibers with microscopic precision.

---

## (B) Higher moments are insufficient for deterministic AFP

Moment methods can show statements such as

```
E(|Z_p|^k)=O_k(1)
```

or Poisson convergence in a family of primes.

This implies that large zero sets are rare statistically. However AFP requires:

```
|Z_p| <= C
```

for every prime p.

A moment theorem gives probability bounds, not a uniform deterministic bound.

Therefore moments are evidence for AFP but not a proof.

---

## (C) Serre mass formulas still have square-root error

Serre-style equidistribution gives:

```
count = expected main term + O(conductor * sqrt(p)).
```

Bounded conductor is important because it prevents the error from becoming worse, but it does not improve sqrt(p) to O(1).

Thus the proposed implication

```
bounded conductor => microscopic equidistribution
```

is false.

Bounded conductor gives uniform macroscopic control only.

---

## (D) No general horizontal Lang-Trotter theorem exists

There is no general theorem saying that for a trace function

```
M(chi)=sum_t chi(t)t_F(t)
```

one has

```
#{chi : M(chi)=a}=O(1)
```

for bounded conductor sheaves.

In fact, counterexamples exist. A trace function may have special multiplicative structure causing many Mellin coefficients to vanish.

The Mellin transform converts geometric randomness into arithmetic character correlations. Irreducible monodromy alone does not eliminate all such correlations.

---

## (E) Legendre family comparison

For the Legendre family

```
y^2=x(x-1)(x-t),
```

one has SL_2 monodromy, but

```
#{t : a_p(E_t)=0}
```

grows like the number of supersingular parameters. This is roughly linear in p.

This demonstrates that large monodromy does not imply bounded geometric zero sets.

Likewise, Mellin zeros can also be large for some families. Therefore the Apéry property cannot come only from SL_2 or symmetric-square monodromy.

---

## What is special about Apéry?

The possible structural advantages are:

1. **Hypergeometric rigidity.**

The Apéry sheaf is a hypergeometric-type object with constrained local monodromy.

2. **Self-duality / symmetric square structure.**

The rank-three representation behaves like Sym^2 of a rank-two system. This forces strong algebraic relations among Frobenius eigenvalues.

3. **Modular origin.**

The weight-4 level-6 modular form gives an additional arithmetic structure absent from a generic Legendre family.

However none of these currently gives a theorem of the form:

```
#{r : Mellin(Apery)(r)=0}=O(1).
```

---

## The missing theorem

The required result would look like a multiplicative analogue of a Larsen-Pink/Katz rigidity theorem:

```
For the Apéry hypergeometric sheaf F,
#{chi : Mellin(F,chi)=0}
<= C(F)
```

where C(F) depends only on rank, singularities, and monodromy.

Existing Deligne bounds control:

```
|Mellin(F,chi)| <= C sqrt(p)
```

but AFP requires controlling the number of exact zeros after reduction modulo p.

---

## Why the symmetric-square idea may still matter

The symmetric-square structure changes the problem from arbitrary SL_2 randomness to a constrained SO_3 trace distribution. In SO_3, the trace-zero locus has codimension one and expected probability about 1/p.

But sampling only p-1 characters means the expected number of hits is constant. To prove boundedness, one needs an arithmetic independence statement showing that the character samples do not cluster on the trace-zero hypersurface.

That is precisely the missing microscopic equidistribution theorem.

---

## Final assessment

The current hierarchy is:

```
Katz-Sarnak / Deligne
        |
        v
macroscopic equidistribution (sqrt(p) error)
        |
        X
microscopic equidistribution (O(1) error)
        |
        v
AFP
```

The Apéry-specific input must enter at the broken arrow. Candidates are:

- hypergeometric rigidity,
- modular parametrization,
- symmetric-square constraints,
- p-adic slope theory,
- multiplicative monodromy.

But no generic theorem currently upgrades Katz-Sarnak to the required microscopic bound.
