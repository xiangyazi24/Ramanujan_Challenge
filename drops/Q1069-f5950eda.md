# Audit of the exact 2-adic Padé-content excess

## Verdict

The proposed formula (E2) is not proved by the available information. The reduction to a finite 2-adic problem is valid, but the crucial uniform congruence and minimizer construction are missing. A finite scan through `n<=1200` is evidence only and cannot establish the claimed formula for all `n`.

No counterexample is produced here; the theorem remains open at the p-adic step described below.

---

# 1. Exact reduction

The starting identity is

```
v_2(D_n)=min_{0<=j<M}(v_2(L_j)+v_2(b_n-b_j)).
```

By Kummer,

```
v_2(C(a,b))
```

is the number of carries in adding `b` and `a-b` in base two. Hence

```
v_2(L_j)
```

is exactly the total carry count from the two binomial coefficients

```
C(n,j), C(n-j-1,M-1-j).
```

This gives a binary automaton for the possible valuations of the coefficient part. However, it does not determine the second term

```
v_2(b_n-b_j).
```

The Apéry arithmetic is the remaining obstruction.

---

# 2. Required Apéry congruence input

To prove (E2), one needs a uniform statement of the following type:

```
b_m mod 2^k = F_k(m mod 2^s)
```

for the relevant values `k<=6`, or an equivalent binary digit recurrence.

The fact that every Apéry number is odd gives only

```
v_2(b_m)=0.
```

It does not determine

```
v_2(b_n-b_j).
```

In particular, oddness alone does not imply the required lower bounds

```
v_2(L_j)+v_2(b_n-b_j) >= min(5,2+r_2(n)).
```

The missing lemma is a genuine Apéry 2-adic congruence lemma.

---

# 3. Claimed lower bound

A proof would require establishing for every `j<M`:

```
v_2(L_j)+v_2(b_n-b_j) >= E(n)
```

where

```
E(n)=2                    if n=2^a-1
E(n)=min(5,2+r_2(n))      otherwise.
```

Kummer controls the first summand. The second summand requires knowing exactly when two Apéry numbers are congruent modulo powers of two.

No such congruence follows merely from the recurrence modulo 2. Higher moduli `4,8,16,32,64` must be derived separately.

Therefore the universal lower bound is currently unproved.

---

# 4. Claimed minimizing indices

The upper bound requires, for every binary case, a specific index `j` such that

```
v_2(L_j)+v_2(b_n-b_j)=E(n).
```

The special cases

```
n=2^a-1
```

and

```
r_2(n)>=3
```

are precisely where carry patterns alone do not settle the value. One must show that the chosen `j` has the required Apéry difference valuation and that no cancellation raises the valuation.

This minimizing-index construction is not supplied by the binary pattern alone.

---

# 5. Finite automaton possibility

A valid computer certificate would need:

1. A finite state containing enough information about

```
n mod 2^s, j mod 2^s,
```

and the Apéry residues modulo `64`.

2. Transition rules for appending binary digits.

3. An invariant stating that every reachable state satisfies the lower bound and that each terminal class has a witness attaining equality.

A scan of all finite prefixes is not enough unless the transition invariant proves arbitrary-length closure.

---

# 6. Computational evidence

The reported range

```
4 <= n <= 1200
```

supports the conjectured pattern but does not prove it.

A complete executable verification beyond this range was not run in this audit, so no new certified range or failure point is claimed.

The required next computational artifact is a verifier that:

```
for n in range(4,N):
    compute Apéry numbers exactly
    compute every L_j
    compute min_j(v2(L_j)+v2(b_n-b_j))
    compare with E2(n)
```

and reports the first mismatch if one exists.

---

# 7. Narrowest missing lemma

A sufficient theorem would be:

> For all `n>=4` and all `j<floor(n/2)`, the quantity
> `v_2(L_j)+v_2(b_n-b_j)` is bounded below by the claimed exponent, and for each binary class there exists an explicit `j` attaining equality.

This separates the problem into:

* Kummer/carry analysis of `L_j`;
* uniform Apéry 2-adic congruences modulo `64`;
* a witness construction.

Proving this lemma would settle (E2).
