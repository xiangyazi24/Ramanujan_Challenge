# ASCII formula table

## [DEF-P]

```text
P(x) = 34*x^3 + 51*x^2 + 27*x + 5.
```

Range: all formulas below; p is a prime with p > 5.

## [DEF-b-c-W-U]

```text
(n+1)^3*b[n+1] = P(n)*b[n] - n^3*b[n-1].
(n+1)^3*c[n+1] = P(n)*c[n] - n^3*c[n-1].

b[0] = 1,  b[1] = 5.
c[0] = 0,  c[1] = 1.

W[n] = (n!)^3*c[n].
U[n] = (n!)^3*b[n].
```

Range: n >= 1 over Q; W[n], U[n] are integers.

## [A]

```text
p^3*c[a*p+v] == c[a]*b[v]  (mod p).
```

Range: p > 5 prime; 0 <= a < p; 0 <= v < p; a*p+v < p^2.

## [A-prime]

```text
W[a*p+v] / p^(3*(a-1))
    == (-1)^a * W[a] * (v!)^3 * b[v]  (mod p).
```

Range: p > 5 prime; 1 <= a < p; 0 <= v < p.

## [A-valuation]

```text
if p does not divide W[a]*b[v], then
    ord_p(W[a*p+v]) = 3*(a-1).

if p divides b[v], then
    ord_p(W[a*p+v]) >= 3*(a-1) + 1.
```

Range: p > 5 prime; 1 <= a < p; 0 <= v < p.

## [B0]

```text
K_0(T) = 1.
K_1(T) = P(T)/(T+1)^3.

(T+v+1)^3*K_(v+1)(T)
    = P(T+v)*K_v(T) - (T+v)^3*K_(v-1)(T).
```

Range: v >= 1; identity in Q(T), or coefficientwise in Q[[T]].

## [B-actual-recurrence]

```text
C_v^(p) = p^3*c[p+v].

(p+v+1)^3*C_(v+1)^(p)
    = P(p+v)*C_v^(p) - (p+v)^3*C_(v-1)^(p).
```

Range: v >= 0; C_(-1)^(p) = p^3*c[p-1].

## [B-initial-error]

```text
p^3*c[p+1] - (p^3*c[p])*K_1(p)
    = -p^6*c[p-1]/(p+1)^3.

c[p-1] == 0  (mod p).

therefore
p^3*c[p+1] == (p^3*c[p])*K_1(p)  (mod p^7).
```

Range: p > 5 prime.

## [B]

```text

```

Range: p > 5 prime; 0 <= v <= p-2.

## [Gessel-entire]

```text
A_ent(z)
    = sum_{k=0}^{infinity}
        binom(z,k)^2 * binom(z+k,k)^2

    = 4F3(-z,-z,z+1,z+1; 1,1,1; 1).

A_ent(v) = b[v].
```

Range: z complex or p-adic where the series is interpreted; v is a nonnegative integer.

## [JET-D]

```text
H_0 = 0.
H_m = sum_{j=1}^{m} 1/j.

D[v]
    = sum_{k=0}^{v}
        binom(v,k)^2 * binom(v+k,k)^2
        * (H_(v+k) - H_(v-k)).

A_ent'(v) = 2*D[v].
K_v'(0)   = 2*D[v].
```

Range: v >= 0; for reduction modulo p, use 0 <= v <= p-2.

## [JET-E-F]


Range: v >= 0; K_v(T) is defined by [B0].

## [2.1-definitions]
