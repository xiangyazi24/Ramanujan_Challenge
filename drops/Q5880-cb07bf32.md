## 4. Exact threshold-sensitive amplification

For integers \(u,v\ge0\),

\[
(u+v-2R)_+\le(u-R)_++(v-R)_+.
\tag{4.1}
\]

\[
\binom m2-\binom R2
=\frac{(m-R)(m+R-1)}2
\ge R(m-R).
\tag{4.2}
\]

Therefore

\[
(m-R)_+
\le\frac1R
\left(\binom m2-\binom R2\right)_+
\le\frac1R\binom m2.
\tag{4.3}
\]

Applying (4.1)--(4.3) state by state proves (A), and more sharply

\[
\boxed{
R(\kappa_\vee-2R)_+
\le
\sum_{\sigma\in\{-,+\}}
\left(\binom{k_\sigma}2-\binom R2\right)_+.}
\tag{4.4}
\]

## 7. Primitive first return and shared starts do not give a consumer bridge

The foreign witness gives the exact two endpoints \(a<r\) in \(\mathcal Z_p\).  It does **not** say there is no zero between them.  Replacing \((a,r)\) by a consecutive-zero subpair changes the affine inversions (2.8) or (2.15), hence changes \(q,t\); the new first-return pair need not consume the same upper state at all.

Even forgetting that loss, the map is not multiplicity preserving.  If a zero set contains two separated clusters \(A<R_0\), every cross pair in \(A\times R_0\) can collapse to the same distinguished consecutive pair at the cluster boundary.  The fiber can have size \(|A||R_0|\asymp Z(p)^2\).

Thus the first-return implication available is only

\[
\text{two actual endpoints}
\Longrightarrow
\text{some first-return subinterval},
\]

not

\[
\text{foreign incidence}
\Longrightarrow
\text{a distinct first-return incidence for the same consumer}.
\]

The latter is the multiplicity-preserving bridge that would be needed before importing first-return estimates, and it is false at the current interface level.  Shared-start restrictions have the same problem.

zero indices.  Reflection can be imposed by adjoining reflected indices, changing only the constant.

### 10.1 Height and integer-divisibility realization

## 11. Comparison with the Q5857 singleton obstruction

The two frontiers are not identical.

In Q5857, a selected first-return cell could be a singleton edge.  A matching supplied arbitrarily many selected objects with zero off-diagonal codegree.  There was no amplification to exploit.

Here, if \(\kappa_\vee>2R\), (4.4) forces at least \(R\) same-sign lower-prime pairs per unit of excess.  This is genuine new amplification and eliminates the literal singleton obstruction.

However, the pair \((p,p')\) can be reused by many upper states.  The rectangle in §10 gives every lower-prime pair in a block codegree

\[
C_+(p,p')\asymp\frac{Z^2}{L}.
\]

Thus the Q5857 matching obstruction reappears one categorical level higher as a **rectangle/codegree-reuse obstruction**:

```text
Q5857: one selected object need not create a pair;
Q5880: an overloaded object creates many pairs,
       but current inputs do not bound how often each pair is reused.
```

So upper foreign overload genuinely helps, but it does not by itself close C4.

## 12. The weakest clean non-equivalent arithmetic lemma that closes the gate

Define the literal actual cross-characteristic pair energy

\[
\mathfrak C_{\rm act}(T;J)
:=\sum_{p<p'}
 \bigl(C_-(p,p')+C_+(p,p')\bigr),
\tag{12.1}
\]

with \(C_\pm\) given by the exact formulas (5.2), (5.4), including \(z_q(t)\) and every signed-window mask.

The following is sufficient:

\[
\boxed{
\mathfrak C_{\rm act}(T;J)
=o_J\!\left(
\frac{T^{12/5}}{L^{16/5}\Omega(T)}
\right).}
\tag{ACTC2}
\]

By (A), `(ACTC2)` immediately gives the displayed C4 excess estimate.

This is not an equivalent restatement of the target.  It counts all same-sign pairs, including states with \(k_\sigma\le R\) that contribute zero to the target, and it penalizes high-degree states quadratically rather than linearly.  For example, a large family with \(k_\sigma=R\) has zero C4 excess but can have large \(\mathfrak C_{\rm act}\).  Hence `(ACTC2)` is a genuinely stronger, independently arithmetic statement.

An equivalent average-codegree formulation is

\[
\frac{1}{\#\{(p,p')\text{ eligible}\}}
\sum_{p<p'}(C_-+C_+)=o_J(R),
\tag{12.2}
\]

since there are \(O(T^2/L^2)\) eligible prime pairs.  No uniform bound is required.  A stronger but simpler theorem such as

\[
C_-(p,p')+C_+(p,p')\ll T^{2/5-\eta}
\quad(\eta>0)
\tag{12.3}
\]

would more than suffice.

If one is willing to drop the upper selector, the still-stronger overlap statement

\[
\sum_{p,\Delta}
A_6(p,p+\Delta)
\bigl(A_1(p,p+\Delta)+A_{13}(p,p+\Delta)\bigr)
=o_J\!\left(
\frac{T^{12/5}}{L^{16/5}\Omega(T)}
\right)
\tag{12.4}
\]

also closes the gate by (5.6)--(5.7).  But (12.4) discards useful upper actual selectedness and is not the weakest desired formulation.
