# 1. The exact factorial-moment expansion

Put

```math
\mathcal P_X=\{p\text{ prime}:X<p\le2X\},
\qquad N=X^2,
```

and define

```math
f_p(m)=\mathbf 1_{\{m\bmod p\in Z_p\}},
\qquad
K_X(m)=\sum_{p\in\mathcal P_X}f_p(m).
```

For a nonnegative integer \(K\), write

```math
(K)_k=K(K-1)\cdots(K-k+1).
```

## Proposition 1.1: falling factorials select distinct primes

For every \(m\) and every \(k\ge1\),

```math
\boxed{
(K_X(m))_k
=
\sum_{\substack{(p_1,\ldots,p_k)\in\mathcal P_X^k\\
                 p_i\text{ pairwise distinct}}}
\prod_{i=1}^k f_{p_i}(m).
}
```

### Proof

Let

```math
S_m=\{p\in\mathcal P_X:f_p(m)=1\}.
```

Then `|S_m|=K_X(m)`. The right-hand side counts ordered choices of \(k\) pairwise distinct elements of \(S_m\), and their number is exactly `(|S_m|)_k`. ∎

This identity is the entire reason for using factorial rather than ordinary moments. Repeated primes are absent before any estimate is made.

Define

```math
F_k(X)=\sum_{0\le m<N}(K_X(m))_k.
```

For an ordered tuple of pairwise distinct primes

```math
\mathbf p=(p_1,\ldots,p_k),
```

put

```math
I_{\mathbf p}(N)
=
\#\{0\le m<N:m\bmod p_i\in Z_{p_i}\text{ for every }i\}.
```

Then Proposition 1.1 gives the exact ledger

```math
\boxed{
F_k(X)
=
\sum_{\substack{\mathbf p\in\mathcal P_X^k\\p_i\text{ pairwise distinct}}}
I_{\mathbf p}(N).
}
```

In particular, `(HM)_8` contains only intersections at eight distinct primes.

# 2. What CRT gives for one distinct-prime tuple

Fix an ordered distinct tuple `\mathbf p=(p_1,\ldots,p_k)` and set

```math
Q_{\mathbf p}=p_1\cdots p_k,
\qquad
A_{\mathbf p}=\prod_{i=1}^k |Z_{p_i}|.
```

CRT gives a bijection

```math
\prod_{i=1}^k Z_{p_i}
\longrightarrow
\mathcal A_{\mathbf p}\subset\mathbf Z/Q_{\mathbf p}\mathbf Z,
```

where `|\mathcal A_{\mathbf p}|=A_{\mathbf p}`. Identifying each class with its least nonnegative representative,

```math
I_{\mathbf p}(N)
=
\#\bigl(\mathcal A_{\mathbf p}\cap[0,N)\bigr).
```

For one class \(a\bmod Q\),

```math
\#\{0\le m<N:m\equiv a\pmod Q\}
=
\frac NQ+O(1).
```

After summing over all \(A_{\mathbf p}\) classes, the correct formula is

```math
\boxed{
I_{\mathbf p}(N)
=
\frac{N}{Q_{\mathbf p}}A_{\mathbf p}
+E_{\mathbf p},
\qquad
|E_{\mathbf p}|\le A_{\mathbf p}.
}
```

The error is \(O(1)\) **per residue vector**, not \(O(1)\) uniformly for the whole set \(Z_{p_1}\times\cdots\times Z_{p_k}\).

Because every \(p_i>X\), one has

```math
Q_{\mathbf p}>X^k.
```

For every \(k\ge2\), this implies \(Q_{\mathbf p}>N=X^2\), so each CRT class has at most one representative below \(N\). Thus

```math
0\le I_{\mathbf p}(N)\le A_{\mathbf p}.
```

This uniqueness is exactly enough for \(k=2\), but not for \(k\ge3\).

# 3. Why `(HM)_2` is automatic but higher moments are not

Let

```math
z_p=|Z_p|,
\qquad
S_X=\sum_{p\in\mathcal P_X}z_p,
\qquad
\lambda_X=\sum_{p\in\mathcal P_X}\frac{z_p}{p}.
```

Since \(p\le2X\),

```math
\lambda_X\ge\frac{S_X}{2X},
\qquad
S_X\le2X\lambda_X.
```

For \(k=2\), CRT uniqueness gives

```math
\begin{aligned}
F_2(X)
&=\sum_{p\ne q}I_{p,q}(N)\\
&\le\sum_{p\ne q}z_pz_q\\
&\le S_X^2\\
&\le4X^2\lambda_X^2.
\end{aligned}
```

This is the universal CRT proof underlying the repository's stated bound

```math
F_2(X)\le5X^2\lambda_X^2.
```

The reason is geometric in scale: for two window primes,

```math
pq\asymp X^2=N.
```

The assertion “at most one representative per residue pair” is already at the expected scale.

For general \(k\), the identical argument gives only

```math
\begin{aligned}
F_k(X)
&\le
\sum_{\substack{p_1,\ldots,p_k\\\text{distinct}}}
\prod_{i=1}^k z_{p_i}\\
&\le S_X^k\\
&\le(2X\lambda_X)^k.
\end{aligned}
```

But `(HM)_k` asks for

```math
F_k(X)\ll X^{2+o(1)}\lambda_X^k.
```

The ratio between the CRT bound and the target is

```math
\boxed{X^{k-2+o(1)}.}
```

For \(k=8\), this is \(X^{6+o(1)}\).

## 3.1 The same loss in the main-term/error ledger

Summing the CRT main terms gives

```math
\begin{aligned}
M_k(X)
&=N\sum_{\substack{p_1,\ldots,p_k\\\text{distinct}}}
  \prod_{i=1}^k\frac{z_{p_i}}{p_i}\\
&\le N\lambda_X^k.
\end{aligned}
```

Thus the expected main term is already at the `(HM)_k` scale. The issue is the aggregate positive boundary overload

```math
E_{\mathbf p}
=I_{\mathbf p}(N)-\frac{N}{Q_{\mathbf p}}A_{\mathbf p}.
```

Define

```math
\mathscr D_k^+(X)
=
\sum_{\substack{\mathbf p\in\mathcal P_X^k\\p_i\text{ distinct}}}
(E_{\mathbf p})_+.
```

Then, up to harmless fixed-\(k\) constants,

```math
\boxed{
(HM)_k
\quad\Longleftrightarrow\quad
\mathscr D_k^+(X)
\ll X^{2+o(1)}\lambda_X^k.
}
```

Indeed,

```math
F_k\le M_k+\mathscr D_k^+,
```

while conversely

```math
\mathscr D_k^+\le F_k+M_k.
```

This is an exact formulation of Stage C: control the positive discrepancy of CRT representatives in a very short initial segment.

## 3.2 The \(k=8\) occupancy scale

For eight window primes,

```math
Q_{\mathbf p}\asymp X^8,
\qquad
N=X^2,
\qquad
\frac N{Q_{\mathbf p}}\asymp X^{-6}.
```

Suppose for intuition that every \(z_p=1\). Then each prime tuple has one CRT residue. Its intersection count is either \(0\) or \(1\), whereas its expected value is about \(X^{-6}\). There are about

```math
\left(\frac X{\log X}\right)^8
```

ordered prime tuples. The expected total is therefore

```math
X^{-6}\left(\frac X{\log X}\right)^8
\asymp
\frac{X^2}{(\log X)^8},
```

which is the `(HM)_8` scale. The bound \(I_{\mathbf p}\le1\) instead gives

```math
\frac{X^8}{(\log X)^8},
```

larger by \(X^6\).

This is why “the error is only \(O(1)\)” does not help.

# 5. Where the repeated-prime diagonals actually live

The repeated-prime discussion belongs to the **ordinary** power

```math
K_X(m)^8,
```

not to the falling factorial `(K_X(m))_8`.

## 5.1 Idempotence is exactly correct

Because \(f_p(m)\in\{0,1\}\),

```math
f_p(m)^r=f_p(m)
```

for every \(r\ge1\). Equivalently,

```math
\left(
\sum_{z\in Z_p}\mathbf1_{m\equiv z\pmod p}
\right)^r
=
\sum_{z\in Z_p}\mathbf1_{m\equiv z\pmod p}.
```

When the left side is expanded, a tuple `(z_1,\ldots,z_r)` contributes only if

```math
z_1=\cdots=z_r.
```

There are \(z_p\) surviving choices, not \(z_p^r\). Hence

```math
\sum_{m<N}f_p(m)^r
=
\frac Np z_p+O(z_p).
```

So part (d) of the question is correct.

## 5.2 Exact ordinary eighth-moment decomposition

Let

```math
F_j(X)=\sum_{m<N}(K_X(m))_j.
```

Grouping an ordered 8-tuple of primes according to its equality partition gives the Stirling-number identity

```math
\boxed{
\sum_{m<N}K_X(m)^8
=
F_8
+28F_7
+266F_6
+1050F_5
+1701F_4
+966F_3
+127F_2
+F_1.
}
```

The coefficient of \(F_j\) is the Stirling number `S(8,j)`.

Thus ordinary eighth moments contain lower factorial moments as diagonals. The falling factorial `(K)_8` removes all of them and leaves precisely \(F_8\).

## 5.3 The four-pairs partition

The equality pattern

```math
2+2+2+2
```

has

```math
\frac{8!}{(2!)^4\,4!}=105
```

set partitions. Its exact contribution to the ordinary eighth moment is therefore

```math
\boxed{105F_4(X).}
```

Equivalently, using unordered sets of four distinct primes, the coefficient is

```math
105\cdot4!=2520.
```

There is no factor \(z_p^2\) for a doubled prime. Each of the four distinct primes contributes only one local indicator and hence one factor \(z_p/p\) in the complete-period main term.

For completeness, the five block-size types contributing to the coefficient `S(8,4)=1701` are:

| Block sizes | Number of set partitions |
|---|---:|
| \(5+1+1+1\) | 56 |
| \(4+2+1+1\) | 420 |
| \(3+3+1+1\) | 280 |
| \(3+2+2+1\) | 840 |

## 5.4 Why factorial moments are the correct Poisson normalization

If \(K\) were Poisson with mean `\lambda`, then

```math
\mathbf E[(K)_8]=\lambda^8,
```

but

```math
\mathbf E[K^8]
=
\lambda
+127\lambda^2
+966\lambda^3
+1701\lambda^4
+1050\lambda^5
+266\lambda^6
+28\lambda^7
+\lambda^8.
```

In the Apéry shell model, `\lambda_X` is expected to be about \(1/\log X\), so the ordinary moment is dominated by the one-hit diagonal `\lambda_X`, not by `\lambda_X^8`. Asking for an ordinary eighth moment at scale `N\lambda_X^8` would be false even in the ideal independent Poisson model.

The falling factorial was chosen precisely to remove this unavoidable diagonal mass.

# 6. The exact Kummer–Mellin zero-indicator expansion

The repository constructs the fixed Laurent polynomial

```math
\Lambda(x,y,z)
=
\frac{(1+x)(1+y)(1+z)
 ((1+y)(1+z)+xyz)}{xyz}
```

and proves that for \(0\le r\le p-2\),

```math
c_{p,r}
:=-\sum_{u\in(\mathbf F_p^\times)^3}\Lambda(u)^r
\equiv b_r\pmod p.
```

The endpoint \(r=p-1\) is defined separately and equals \(1\), so it never belongs to \(Z_p\).

Let

```math
\psi_p(t)=e^{2\pi i t/p}.
```

Then additive orthogonality gives the exact zero detector

```math
\boxed{
f_p(r)
=\mathbf1_{\{c_{p,r}=0\}}
=\frac1p\sum_{a\in\mathbf F_p}\psi_p(a c_{p,r}).
}
```

For a distinct tuple `\mathbf p=(p_1,\ldots,p_k)`, this yields

```math
\boxed{
I_{\mathbf p}(N)
=
\frac1{Q_{\mathbf p}}
\sum_{a_i\in\mathbf F_{p_i}}
\sum_{m<N}
\prod_{i=1}^k
\psi_{p_i}\!\left(a_i c_{p_i,m\bmod p_i}\right).
}
```

This is the exact mixed-modulus exponential-sum formulation requested in part (a).

It does **not** yet put the sum in Deligne's standard framework.

## 6.1 A critical algebraic correction

Substituting the toric formula gives

```math
\psi_p(a c_{p,r})
=
\psi_p\!\left(
-a\sum_{u}\Lambda(u)^r
\right).
```

An additive character of a sum is a product:

```math
\boxed{
\psi_p\!\left(-a\sum_u\Lambda(u)^r\right)
=
\prod_u\psi_p(-a\Lambda(u)^r),
}
```

not a sum of `\psi_p(-a\Lambda(u)^r)`. There are about \(p^3\) torus points. Grouping by values of `\Lambda` gives

```math
\psi_p\!\left(-a\sum_{t\in\mathbf F_p}\mu_p(t)t^r\right),
```

where `\mu_p(t)` is the fiber-count function.

Thus zero detection exponentiates the entire Mellin coefficient. The bounded-complexity cohomology that linearly produces \(c_{p,r}\) does not remain bounded-complexity after this nonlinear operation.

## 6.2 Supertrace zero versus reduction of a supertrace

The cohomological lift in `oracleC_result.tex` is

```math
\widetilde c_{p,r}
=-\operatorname{Tr}_{\rm alt}\!\left(
\operatorname{Frob}_p\mid
R\Gamma_c(U_{\overline{\mathbf F}_p},
\Lambda^*\mathcal K_{\omega_p^r})
\right),
```

and its reduction at a prime above \(p\) is \(c_{p,r}=b_r\bmod p\).

The event defining \(Z_p\) is

```math
\widetilde c_{p,r}\equiv0\pmod{\mathfrak p},
```

not

```math
\widetilde c_{p,r}=0
```

as a characteristic-zero trace. The repository's explicit example is

```math
\widetilde c_{11,5}=-33\ne0,
\qquad
\widetilde c_{11,5}\equiv b_5\equiv0\pmod{11}.
```

Consequently ordinary equidistribution of characteristic-zero Frobenius traces does not count the desired defining-characteristic zeros.

## 6.3 There is no fixed sheaf on the index line

For each pair `(p,r)`, the Kummer-twisted cohomology has uniformly bounded rank and tame geometric complexity. But the object varies with the character `\omega_p^r`. As the repository emphasizes, these spaces do not assemble into one lisse sheaf on an `r`-line whose trace function is

```math
r\longmapsto b_r\pmod p.
```

Therefore one cannot directly apply a standard trace-function theorem to the sum over \(r\), let alone to the mixed-prime sum over \(m\).

## 6.4 The natural Artin–Schreier realization has growing conductor

One can force the function

```math
r\longmapsto\psi_p(a b_r)
```

into an Artin–Schreier trace-function model over `\mathbf F_p`. The current repository audit finds that the corresponding defining polynomial has degree `\asymp p`, hence Swan conductor `\asymp p`. Grothendieck–Ogg–Shafarevich plus Deligne then gives only

```math
O(p^{3/2}),
```

which is weaker than the trivial length-\(p\) estimate.

Thus the natural sheaf obtained after zero detection has lost the bounded complexity enjoyed by the linear Kummer–Mellin supertrace.

# 7. An exact Fourier formulation in the index variable

The shortest way to expose the Stage-C obstruction is to Fourier-expand the set \(Z_p\) itself.

Define

```math
\widehat f_p(h)
=
\sum_{r\in Z_p}e_p(-hr),
\qquad h\in\mathbf F_p.
```

Then

```math
f_p(m)
=
\frac1p\sum_{h\in\mathbf F_p}
\widehat f_p(h)e_p(hm).
```

For a distinct tuple `\mathbf p`, let

```math
Q=\prod_i p_i,
\qquad
H(\mathbf h)=\sum_i h_i\frac Q{p_i}\pmod Q,
```

and

```math
V_N(H)=\sum_{0\le m<N}e_Q(Hm).
```

The map `\mathbf h\mapsto H(\mathbf h)` is a bijection from `\prod_i\mathbf F_{p_i}` to `\mathbf Z/Q\mathbf Z`, because `Q/p_i` is invertible modulo \(p_i\). One obtains

```math
\boxed{
I_{\mathbf p}(N)
=
\frac1Q
\sum_{\mathbf h}
\left(\prod_i\widehat f_{p_i}(h_i)\right)
V_N(H(\mathbf h)).
}
```

The zero-frequency term is exactly

```math
\frac NQ\prod_i z_{p_i}.
```

Every nonzero frequency belongs to the short-CRT discrepancy.

The value-space Fourier formula and the index-space Fourier formula are connected by

```math
\widehat f_p(h)
=
\frac1p\sum_{a\in\mathbf F_p}
S_p(a,h),
```

where

```math
S_p(a,h)
=
\sum_{r\bmod p}
\psi_p(a b_r-hr).
```

A Deligne route would therefore first need useful uniform bounds for these local sums and then a horizontal theorem controlling their CRT-coupled products.

## 7.1 Complete periods are already independent

If the \(m\)-sum ran over a full period \(0\le m<Q\), then CRT gives exactly

```math
\sum_{m\bmod Q}\prod_i f_{p_i}(m)
=
\prod_i z_{p_i}.
```

Equivalently, the normalized complete-period density is

```math
\prod_i\frac{z_{p_i}}{p_i}.
```

No geometry is needed. The whole problem is that `(HM)_8` samples only the first \(X^2\) points of a period of length \(X^8\).

A product-variety or monodromy theorem that merely recovers complete-period independence proves something already supplied exactly by CRT.

## 7.2 The one-shot square-root benchmark is far too weak

Suppose, unrealistically favorably, that every nontrivial local complete sum satisfied a bounded-conductor estimate

```math
|S_p(a,h)|\ll p^{1/2}.
```

For a complete mixed-modulus product, CRT factorization would give a bound of order

```math
Q^{1/2}.
```

Completing the interval `[0,N)` modulo \(Q\) uses

```math
\sum_{H\bmod Q}|V_N(H)|\ll Q\log Q,
```

and therefore gives at best the Pólya–Vinogradov scale

```math
O(Q^{1/2}\log Q).
```

For \(k=8\),

```math
Q^{1/2}\asymp X^4,
```

which is larger than the original interval length \(N=X^2\). The trivial bound is better.

So even a hypothetical bounded-conductor product sheaf and a perfect Deligne square-root estimate would not by themselves detect the \(N/Q=X^{-6}\) occupancy probability.

What is needed is cancellation after averaging over prime tuples, residue vectors, or Fourier frequencies—a genuinely horizontal dispersion theorem, not a single Weil estimate.

# 8. Why there is no single product variety for distinct primes

For one finite field `\mathbf F_p`, products of varieties and tensor products of sheaves are standard. This is the setting in which Katz's product-monodromy and Goursat–Kolchin–Ribet arguments operate, and it can be relevant to several shifted Kummer twists **at the same prime**.

For distinct rational primes \(p\ne q\), the local objects live over different fields. There is no field containing both `\mathbf F_p` and `\mathbf F_q` as subfields, because their characteristics differ. Scheme-theoretically,

```math
\mathbf F_p\otimes_{\mathbf Z}\mathbf F_q=0,
```

so

```math
\operatorname{Spec}\mathbf F_p
\times_{\operatorname{Spec}\mathbf Z}
\operatorname{Spec}\mathbf F_q
```

is empty.

One may package the residue rings as

```math
\mathbf Z/Q\mathbf Z\cong\prod_i\mathbf F_{p_i},
```

but this is a finite ring, not a finite field. Its spectrum is a disjoint union of the characteristic-\(p_i\) points. There is no single geometric Frobenius whose trace is the desired product, and the Weil conjectures do not furnish a square-root theorem over this product ring.

Numerically, complete sums factor by CRT. Geometrically, that factorization is a product of unrelated local traces, not the trace of one Frobenius on one variety over one finite field.

The interval condition

```math
0\le m<X^2
```

is an archimedean condition on the diagonal embedding of the integers into the product ring. It is not an algebraic subvariety over any one `\mathbf F_{p_i}`. This is precisely the horizontal part that Deligne's local theorem does not see.

---

# 9. Direct answers to parts (a)–(e)

## (a) Can one write the \(k\)-fold sum using the supertrace, and does Deligne estimate it?

One can write it exactly as

```math
I_{\mathbf p}(N)
=
\frac1Q\sum_{a_i\in\mathbf F_{p_i}}
\sum_{m<N}
\prod_i\psi_{p_i}(a_i b_{m\bmod p_i}).
```

Using the toric marked coordinate replaces each \(b_r\bmod p\) by the reduction of a Kummer–Mellin supertrace.

However, this does **not** produce a standard bounded-complexity Deligne sum:

1. the additive zero detector applies `\psi_p` to the reduction of the supertrace, a nonlinear operation;
2. the natural index-variable Artin–Schreier sheaf has conductor `\asymp p`;
3. the inner \(m\)-sum is incomplete modulo \(Q\gg N\); and
4. the factors have different residue characteristics.

So the formula is exact, but it does not close `(HM)_k` with current trace-function technology.

## (b) Is there a product-variety formulation allowing one Weil-conjecture application?

Not for distinct \(p_i\). There is no common finite field and no single Frobenius. A product construction is available only in one characteristic. Across different characteristics, complete sums factor arithmetically by CRT, while the short interval remains a mixed-modulus discrepancy problem.

Even a fantasy product bound of size \(Q^{1/2}\) would be quantitatively useless for \(k=8\), because \(Q^{1/2}\asymp X^4>N=X^2\).

## (c) What is the exact diagonal contribution for \(k=8\)?

For `(HM)_8` there is **no diagonal contribution at all**:

```math
(K)_8
=
\sum_{p_1,\ldots,p_8\text{ distinct}}
 f_{p_1}\cdots f_{p_8}.
```

For the ordinary power \(K^8\), the full diagonal decomposition is

```math
K^8
=(K)_8+28(K)_7+266(K)_6+1050(K)_5
+1701(K)_4+966(K)_3+127(K)_2+(K)_1.
```

The four-pairs pattern `2+2+2+2` contributes exactly

```math
105(K)_4
```

pointwise, hence \(105F_4(X)\) after summing over \(m\).

## (d) Does multiplicity \(r\) at one prime collapse because the indicator is idempotent?

Yes. Exactly:

```math
f_p^r=f_p.
```

Thus one repeated-prime block contributes \(z_p/p\), not \(z_p^r/p\). The proposed `|Z_p|^r/p` diagonal factor is incorrect.

## (e) Does this make `(HM)_k` automatic for all \(k\)?

No. The falling factorial has already deleted every repeated-prime block, so idempotence removes an obstacle that was never present in `(HM)_k`. The surviving distinct-prime term is not controlled at the independence scale by CRT.

For \(k=8\), CRT supplies at most one row per residue vector, but `(HM)_8` requires only an \(X^{-6}\) fraction of all residue vectors to land below \(X^2\). Showing that fraction is the unresolved theorem.

---

# 10. What Kummer–Mellin can still contribute

The negative conclusion is specific to the claim of an immediate `(HM)_8` proof. The Kummer–Mellin package remains potentially valuable in three narrower roles.

## 10.1 Same-prime product monodromy

For fixed \(p\), several shifted or character-twisted local objects live over the same field. External tensor products, geometric irreducibility, and Goursat–Kolchin–Ribet criteria can potentially prove same-characteristic anti-concentration or product-monodromy statements.

This belongs to Stage B and may improve local bounds for \(Z_p\), local constellation counts, or index Fourier coefficients.

## 10.2 Vertical moment estimates

The supertrace can organize averages over characters \(r\), over geometric parameters, or over points of one finite field. Katz's finite-field Mellin theory is designed for such vertical averages.

Such results could prove better estimates for

```math
\sum_p z_p^j,
\qquad
\sum_{h}|\widehat f_p(h)|^{2j},
```

or same-prime shifted correlations. These would be useful inputs but do not by themselves control an anchored cross-prime star.

## 10.3 A local component of a new horizontal theorem

A future proof might combine:

1. bounded-complexity integral Kummer–Mellin objects;
2. same-prime product monodromy;
3. a new mixed-characteristic large sieve or dispersion theorem for their defining-characteristic reductions; and
4. the short interval \(m<X^2\).

The genuinely new item is (3). It is not supplied by Deligne's theorem or by current same-field trace-function product estimates.

---

# 11. The exact residual theorem

The most economical high-moment target remains the short-CRT discrepancy

```math
\boxed{
\mathscr D_8^+(X)
=
\sum_{\substack{p_1,\ldots,p_8\in\mathcal P_X\\\text{pairwise distinct}}}
\left(
I_{\mathbf p}(X^2)
-
\frac{X^2}{p_1\cdots p_8}
\prod_{i=1}^8 z_{p_i}
\right)_+
\ll
X^{2+o(1)}\lambda_X^8.
}
```

This statement is equivalent, up to the already controlled main term, to `(HM)_8`.

An alternative pointwise route from the repository is the atom bound

```math
\max_{m<X^2}K_X(m)
\le
\lambda_X X^{o(1)}.
```

Indeed, the proved moment-collapse inequality is

```math
\sum_{m<X^2}(K_X(m))_k
\le
\left(\max_{m<X^2}K_X(m)\right)^{k-2}
\sum_{m<X^2}(K_X(m))_2,
```

and `(HM)_2` then gives all fixed higher moments.

Both formulations target the same phenomenon: rule out a deterministic row that is marked by far too many different primes. Neither is a diagonal problem.

---

# 12. Final conclusion

The proposed insight contains one correct and useful correction:

```math
f_p^r=f_p,
```

so repeated-prime multiplicities do not create powers `z_p^r`. But the falling factorial had already removed those terms. The actual ledger is:

```math
\boxed{
(HM)_8
\text{ counts eight distinct primes and nothing else.}
}
```

The distinct-prime CRT formula is

```math
I_{\mathbf p}(X^2)
=
\frac{X^2}{p_1\cdots p_8}\prod_i z_{p_i}
+O\!\left(\prod_i z_{p_i}\right),
```

and summing the error loses \(X^6\). This loss is real, is attained by an anchored-star model, and is exactly the cross-prime Stage-C obstruction.

The Kummer–Mellin supertrace does not turn that error into a one-field Deligne sum. It provides a bounded-complexity **linear local coordinate**, whereas `(HM)_8` requires nonlinear zero detection, mixed characteristics, and distribution in an interval \(X^{-6}\) of a complete CRT period.

Therefore the definitive answer is:

> **No, `(HM)_k` is not automatic. The diagonal disappears, but the all-distinct term remains open. A direct Kummer–Mellin plus Deligne argument does not prove `(HM)_8`; doing so would require a new mixed-characteristic short-CRT dispersion theorem or an equivalent atom-tail bound.**
