The proposed automatic proof of all high moments is false, but the exact correction is simple.

1. The falling factorial \((K_X(m))_k\) contains only ordered \(k\)-tuples of pairwise distinct primes. There are no repeated-prime diagonal terms in \((HM)_8\).

2. The idempotence observation is correct: if

   ```math
   f_p(m)=\mathbf 1_{\{m\bmod p\in Z_p\}},
   ```

   then \(f_p(m)^r=f_p(m)\). Thus a repeated prime in an ordinary power contributes one factor \(Z(p)/p\), not \(Z(p)^r/p\).

3. The real error is the claim that the all-distinct term is already controlled by CRT. For \(k\) window primes, the product modulus is about \(X^k\), while the interval has length \(X^2\). CRT gives at most one representative per residue vector, but \((HM)_k\) requires only an \(X^{2-k}\) fraction of all residue vectors to lie in the interval. For \(k=8\), the missing saving is \(X^6\).

4. The Kummer–Mellin supertrace gives an exact local formula for \(b_j\bmod p\), but it does not turn the mixed-characteristic short-CRT problem into one bounded-complexity trace sum over a finite field. Zero detection is nonlinear, the natural Artin–Schreier realization has conductor of order \(p\), and the factors for distinct primes live in different characteristics.

5. Even an ideal local square-root estimate would not be enough. Completing a sum modulo \(Q\asymp X^8\) gives the scale \(Q^{1/2}\asymp X^4\), larger than the original interval \(X^2\).

Therefore:

> **The diagonal disappears, but the all-distinct short-CRT occupancy problem remains exactly open. A direct Kummer–Mellin plus Deligne argument does not prove \((HM)_8\).**

## 1. Exact expansion of the falling factorial

Let

```math
\mathcal P_X=\{p\text{ prime}:X<p\le2X\},
\qquad N=X^2,
```

and define

```math
f_p(m)=\mathbf 1_{\{m\bmod p\in Z_p\}},
\qquad
K_X(m)=\sum_{p\in\mathcal P_X}f_p(m).
```

For every \(m\) and every \(k\ge1\),

```math
\boxed{
(K_X(m))_k
=
\sum_{\substack{(p_1,\ldots,p_k)\in\mathcal P_X^k\\
p_i\text{ pairwise distinct}}}
\prod_{i=1}^k f_{p_i}(m).
}
```

Proof: if \(K_X(m)=t\), then exactly \(t\) primes are active at \(m\). The right-hand side counts ordered choices of \(k\) distinct active primes, and that number is \((t)_k\).

After summing over \(m\), put

```math
F_k(X)=\sum_{0\le m<N}(K_X(m))_k.
```

For an ordered tuple of distinct primes

```math
\mathbf p=(p_1,\ldots,p_k),
```

let

```math
I_{\mathbf p}(N)
=
\#\{0\le m<N:m\bmod p_i\in Z_{p_i}\text{ for every }i\}.
```

Then

```math
\boxed{
F_k(X)
=
\sum_{\substack{\mathbf p\in\mathcal P_X^k\\p_i\text{ pairwise distinct}}}
I_{\mathbf p}(N).
}
```

This is the complete prime ledger. In particular, \((HM)_8\) contains eight distinct primes and no prime diagonal.

## 2. What CRT gives for one distinct-prime tuple

Fix a distinct tuple \(\mathbf p=(p_1,\ldots,p_k)\) and set

```math
Q_{\mathbf p}=p_1\cdots p_k,
\qquad
A_{\mathbf p}=\prod_{i=1}^k |Z_{p_i}|.
```

CRT maps the \(A_{\mathbf p}\) residue vectors in

```math
Z_{p_1}\times\cdots\times Z_{p_k}
```

bijectively to a subset \(\mathcal A_{\mathbf p}\) of \(\mathbf Z/Q_{\mathbf p}\mathbf Z\). Taking least nonnegative representatives,

```math
I_{\mathbf p}(N)
=
\#(\mathcal A_{\mathbf p}\cap[0,N)).
```

For one residue class \(a\bmod Q\),

```math
\#\{0\le m<N:m\equiv a\pmod Q\}
=
\frac NQ+O(1).
```

Summing over all residue vectors gives

```math
\boxed{
I_{\mathbf p}(N)
=
\frac{N}{Q_{\mathbf p}}A_{\mathbf p}
+E_{\mathbf p},
\qquad
|E_{\mathbf p}|\le A_{\mathbf p}.
}
```

The \(O(1)\) error is per residue vector. It becomes \(O(A_{\mathbf p})\) for the whole prime tuple.

Since every \(p_i>X\), one has \(Q_{\mathbf p}>X^k\). For every \(k\ge2\), this is larger than \(N=X^2\), so each CRT class has at most one representative below \(N\). Hence

```math
0\le I_{\mathbf p}(N)\le A_{\mathbf p}.
```

This uniqueness is enough at \(k=2\), but not at higher order.

## 3. Why \(k=2\) is the borderline case

Write

```math
z_p=|Z_p|,
\qquad
S_X=\sum_{p\in\mathcal P_X}z_p,
\qquad
\lambda_X=\sum_{p\in\mathcal P_X}\frac{z_p}{p}.
```

Because \(p\le2X\),

```math
S_X\le2X\lambda_X.
```

For \(k=2\),

```math
\begin{aligned}
F_2(X)
&=\sum_{p\ne q}I_{p,q}(N)\\
&\le\sum_{p\ne q}z_pz_q\\
&\le S_X^2\\
&\le4X^2\lambda_X^2.
\end{aligned}
```

This is the universal CRT argument underlying the repository's stated inequality

```math
F_2(X)\le5X^2\lambda_X^2.
```

The reason it works is that \(pq\asymp X^2=N\).

For general \(k\), the same argument gives only

```math
F_k(X)
\le S_X^k
\le(2X\lambda_X)^k.
```

The target \((HM)_k\) is

```math
F_k(X)
\ll X^{2+o(1)}\lambda_X^k.
```

The missing factor is therefore

```math
\boxed{X^{k-2+o(1)}.}
```

For \(k=8\), one needs an \(X^6\) saving beyond the direct CRT bound.

### 3.1 Main term and positive discrepancy

The CRT main terms sum to

```math
M_k(X)
=
N\sum_{\substack{p_1,\ldots,p_k\\\text{distinct}}}
\prod_{i=1}^k\frac{z_{p_i}}{p_i}
\le N\lambda_X^k.
```

Define

```math
E_{\mathbf p}
=I_{\mathbf p}(N)-\frac{N}{Q_{\mathbf p}}A_{\mathbf p}
```

and

```math
\mathscr D_k^+(X)
=
\sum_{\substack{\mathbf p\in\mathcal P_X^k\\p_i\text{ distinct}}}
(E_{\mathbf p})_+.
```

Then

```math
F_k\le M_k+\mathscr D_k^+,
\qquad
\mathscr D_k^+\le F_k+M_k.
```

Thus, for fixed \(k\), \((HM)_k\) is equivalent up to harmless constants to

```math
\boxed{
\mathscr D_k^+(X)
\ll X^{2+o(1)}\lambda_X^k.
}
```

This is the exact short-CRT form of Stage C.

### 3.2 The \(k=8\) scale

For eight window primes,

```math
Q_{\mathbf p}\asymp X^8,
\qquad
N=X^2,
\qquad
\frac N{Q_{\mathbf p}}\asymp X^{-6}.
```

If every \(z_p=1\), each prime tuple has one CRT residue, whose count below \(N\) is either \(0\) or \(1\). There are about

```math
\left(\frac X{\log X}\right)^8
```

ordered tuples. CRT uniqueness gives \(X^8/(\log X)^8\). Independence predicts that only an \(X^{-6}\) fraction land below \(N\), giving

```math
\frac{X^2}{(\log X)^8},
```

which is the \((HM)_8\) scale.

So the statement “the CRT error is still \(O(1)\)” hides the entire missing \(X^6\).

## 4. The anchored-star counterexample

Choose one row \(m_0<N\), and for every \(p\in\mathcal P_X\) set

```math
Z_p^*=\{m_0\bmod p\}.
```

Then

```math
K_X^*(m_0)=|\mathcal P_X|\asymp\frac X{\log X},
\qquad
\lambda_X^*\asymp\frac1{\log X}.
```

Hence, for every fixed \(k\ge3\),

```math
\sum_{m<N}(K_X^*(m))_k
\ge
(K_X^*(m_0))_k
\asymp
\frac{X^k}{(\log X)^k},
```

whereas \((HM)_k\) asks for \(X^2/(\log X)^k\). The ratio is \(X^{k-2}\).

The anchored rainbow-star construction in [`hm3_result.tex`](https://github.com/xiangyazi24/Ramanujan_Challenge/blob/1fbbc40a58ba9faf4a123b7a2276eaaa1acd090c/problems/3.2/hm3_result.tex) strengthens this model: it uses reflection pairs and retains reflection symmetry, no adjacency, the interval-density bound, bounded row codegrees, the second factorial moment, and the necessary local gap certificate. It still has one row hit by \(\asymp X/\log X\) primes.

This proves that primewise cardinality, Fourier, or monodromy information cannot imply a high factorial moment unless it also controls cross-prime alignment. A singleton zero set even satisfies

```math
|\widehat{1_{Z_p}}(h)|=1
```

at every frequency.

## 5. Ordinary powers and repeated-prime diagonals

The repeated-prime discussion belongs to \(K_X(m)^8\), not to \((K_X(m))_8\).

### 5.1 Idempotence

Since \(f_p(m)\in\{0,1\}\),

```math
f_p(m)^r=f_p(m)
```

for every \(r\ge1\). Expanding

```math
\left(\sum_{z\in Z_p}\mathbf1_{m\equiv z\pmod p}\right)^r
```

shows that a residue tuple contributes only when all its entries are equal. There are \(z_p\) surviving choices, not \(z_p^r\). Therefore

```math
\sum_{m<N}f_p(m)^r
=
\frac Np z_p+O(z_p).
```

Part (d) of the question is correct.

### 5.2 Exact eighth-power decomposition

Let

```math
F_j(X)=\sum_{m<N}(K_X(m))_j.
```

Grouping an ordered 8-tuple of primes by its equality partition gives

```math
\boxed{
\sum_{m<N}K_X(m)^8
=
F_8+28F_7+266F_6+1050F_5
+1701F_4+966F_3+127F_2+F_1.
}
```

The coefficients are Stirling numbers \(S(8,j)\). The falling factorial removes all lower-\(j\) diagonal terms and leaves only \(F_8\).

### 5.3 The four-pairs pattern

The partition type \(2+2+2+2\) occurs

```math
\frac{8!}{(2!)^4\,4!}=105
```

times. Its exact contribution to the ordinary eighth moment is

```math
\boxed{105F_4(X).}
```

There is no factor \(z_p^2\) for a doubled prime. Each of the four distinct primes contributes one local density \(z_p/p\).

For completeness, the block-size types contributing to \(S(8,4)=1701\) are:

| Block sizes | Number |
|---|---:|
| \(5+1+1+1\) | 56 |
| \(4+2+1+1\) | 420 |
| \(3+3+1+1\) | 280 |
| \(3+2+2+1\) | 840 |
| \(2+2+2+2\) | 105 |
| **Total** | **1701** |

### 5.4 Poisson normalization

For a Poisson random variable of mean \(\lambda\),

```math
\mathbf E[(K)_8]=\lambda^8,
```

whereas

```math
\mathbf E[K^8]
=
\lambda+127\lambda^2+966\lambda^3+1701\lambda^4
+1050\lambda^5+266\lambda^6+28\lambda^7+\lambda^8.
```

When \(\lambda_X\asymp1/\log X\), the ordinary moment is dominated by the one-hit term \(\lambda_X\). Thus an ordinary eighth-moment estimate at scale \(N\lambda_X^8\) would be false even in the independent Poisson model. Falling factorials are essential.

## 6. Exact Kummer–Mellin zero detection

The repository constructs

```math
\Lambda(x,y,z)
=
\frac{(1+x)(1+y)(1+z)((1+y)(1+z)+xyz)}{xyz}
```

and proves, for \(0\le r\le p-2\),

```math
c_{p,r}
:=-\sum_{u\in(\mathbf F_p^\times)^3}\Lambda(u)^r
\equiv b_r\pmod p.
```

The endpoint \(r=p-1\) is separately defined as \(1\), so it is not in \(Z_p\).

Let \(\psi_p(t)=e^{2\pi i t/p}\). Additive orthogonality gives

```math
\boxed{
f_p(r)
=\mathbf1_{\{c_{p,r}=0\}}
=\frac1p\sum_{a\in\mathbf F_p}\psi_p(a c_{p,r}).
}
```

For a distinct tuple \(\mathbf p=(p_1,\ldots,p_k)\),

```math
\boxed{
I_{\mathbf p}(N)
=
\frac1{Q_{\mathbf p}}
\sum_{a_i\in\mathbf F_{p_i}}
\sum_{m<N}
\prod_{i=1}^k
\psi_{p_i}\!\left(a_i c_{p_i,m\bmod p_i}\right).
}
```

This is the exact mixed-modulus exponential-sum formulation requested in part (a). It is not yet a standard Deligne sum.

### 6.1 Zero detection is nonlinear

Substitution gives

```math
\psi_p(a c_{p,r})
=
\psi_p\!\left(-a\sum_u\Lambda(u)^r\right)
=
\prod_u\psi_p(-a\Lambda(u)^r).
```

An additive character of a sum is a product, not a sum. There are about \(p^3\) torus points. Equivalently,

```math
\psi_p(a c_{p,r})
=
\psi_p\!\left(-a\sum_{t\in\mathbf F_p}\mu_p(t)t^r\right),
```

where \(\mu_p(t)\) is the fiber-count function. The bounded-complexity cohomology that linearly produces \(c_{p,r}\) does not remain bounded-complexity after exponentiating that scalar.

### 6.2 Reduction of a supertrace is not a zero supertrace

The cohomological lift in `oracleC_result.tex` is

```math
\widetilde c_{p,r}
=-\operatorname{Tr}_{\rm alt}\!\left(
\operatorname{Frob}_p\mid
R\Gamma_c(U_{\overline{\mathbf F}_p},
\Lambda^*\mathcal K_{\omega_p^r})
\right).
```

Its reduction at a prime above \(p\) is \(c_{p,r}=b_r\bmod p\). The event defining \(Z_p\) is

```math
\widetilde c_{p,r}\equiv0\pmod{\mathfrak p},
```

not \(\widetilde c_{p,r}=0\). The repository gives the explicit example

```math
\widetilde c_{11,5}=-33\ne0,
\qquad
\widetilde c_{11,5}\equiv b_5\equiv0\pmod{11}.
```

Ordinary Frobenius-trace equidistribution therefore does not directly count the required defining-characteristic zeros.

### 6.3 No fixed sheaf on the index line

For each pair \((p,r)\), the Kummer-twisted cohomology has bounded rank and tame geometric complexity. But the object varies with the character \(\omega_p^r\). As the repository emphasizes, these spaces do not assemble into one lisse sheaf on an \(r\)-line whose trace function is \(r\mapsto b_r\pmod p\).

### 6.4 The natural Artin–Schreier model has growing conductor

One can represent \(r\mapsto\psi_p(a b_r)\) by an Artin–Schreier sheaf over \(\mathbf F_p\), but the repository audit finds conductor of order \(p\). Grothendieck–Ogg–Shafarevich and Deligne then give only \(O(p^{3/2})\), weaker than the trivial length-\(p\) estimate.

Thus the natural sheaf obtained after zero detection has lost the bounded complexity of the linear Kummer–Mellin object.

## 7. Fourier expansion in the index variable

Define

```math
\widehat f_p(h)
=
\sum_{r\in Z_p}e_p(-hr).
```

Then

```math
f_p(m)
=
\frac1p\sum_{h\in\mathbf F_p}\widehat f_p(h)e_p(hm).
```

For a distinct tuple \(\mathbf p\), put

```math
Q=\prod_i p_i,
\qquad
H(\mathbf h)=\sum_i h_i\frac Q{p_i}\pmod Q,
\qquad
V_N(H)=\sum_{0\le m<N}e_Q(Hm).
```

The map \(\mathbf h\mapsto H(\mathbf h)\) is a bijection because \(Q/p_i\) is invertible modulo \(p_i\). Therefore

```math
\boxed{
I_{\mathbf p}(N)
=
\frac1Q
\sum_{\mathbf h}
\left(\prod_i\widehat f_{p_i}(h_i)\right)
V_N(H(\mathbf h)).
}
```

The zero-frequency term is

```math
\frac NQ\prod_i z_{p_i}.
```

Every nonzero frequency belongs to the short-CRT discrepancy.

The value-space and index-space expansions are related by

```math
\widehat f_p(h)
=
\frac1p\sum_{a\in\mathbf F_p}S_p(a,h),
```

where

```math
S_p(a,h)
=
\sum_{r\bmod p}\psi_p(a b_r-hr).
```

A geometric proof would need useful local bounds for these sums and a horizontal theorem controlling their products after CRT coupling.

### 7.1 Complete periods are already independent

Over a full period modulo \(Q\), CRT gives exactly

```math
\sum_{m\bmod Q}\prod_i f_{p_i}(m)
=
\prod_i z_{p_i}.
```

The normalized complete-period density is \(\prod_i z_{p_i}/p_i\). No Weil theorem is needed. The difficulty is the truncation from period length \(X^8\) to interval length \(X^2\).

### 7.2 An ideal square-root bound is still too weak

Suppose every nontrivial local complete sum satisfied

```math
|S_p(a,h)|\ll p^{1/2}.
```

A complete mixed-modulus product would then be \(O(Q^{1/2})\). Completing the interval modulo \(Q\), using

```math
\sum_{H\bmod Q}|V_N(H)|\ll Q\log Q,
```

would give at best

```math
O(Q^{1/2}\log Q).
```

At \(k=8\), this is \(X^{4+o(1)}\), larger than the interval length \(X^2\). Hence a single Deligne square-root estimate cannot resolve \((HM)_8\). The necessary saving must come from averaging over primes, residues, or frequencies: a genuinely horizontal dispersion theorem.

## 8. No one-field product variety for distinct primes

For several twists at the same prime \(p\), products of varieties and tensor products of sheaves over \(\mathbf F_p\) are standard. Katz's product-monodromy and Goursat–Kolchin–Ribet methods operate in this setting and may help Stage B.

For distinct primes \(p\ne q\), the local objects live over different fields. There is no field containing both \(\mathbf F_p\) and \(\mathbf F_q\) as subfields. Scheme-theoretically,

```math
\mathbf F_p\otimes_{\mathbf Z}\mathbf F_q=0,
```

so their fiber product over \(\operatorname{Spec}\mathbf Z\) is empty.

One may write

```math
\mathbf Z/Q\mathbf Z\cong\prod_i\mathbf F_{p_i},
```

but this is a finite ring, not a finite field. Its spectrum is a disjoint union, not a variety carrying one Frobenius whose trace gives the desired product. Complete sums factor numerically by CRT, but the interval condition \(0\le m<X^2\) is an archimedean condition on the diagonal embedding of the integers. It is not an algebraic subvariety over any one residue field.

Therefore part (b) has a negative answer for distinct primes.

## 9. Direct answers to (a)–(e)

### (a)

The exact formula is

```math
I_{\mathbf p}(N)
=
\frac1Q\sum_{a_i\in\mathbf F_{p_i}}
\sum_{m<N}
\prod_i\psi_{p_i}(a_i b_{m\bmod p_i}).
```

It is not directly bounded by one Deligne theorem: zero detection is nonlinear, the natural index sheaf has conductor of order \(p\), the sum is incomplete modulo \(Q\gg N\), and the factors have different characteristics.

### (b)

There is no product variety over one finite field for distinct \(p_i\). Same-characteristic products may help local Stage B, but they do not solve the cross-prime moment.

### (c)

For \((HM)_8\), the diagonal contribution is exactly zero. The falling factorial contains only eight distinct primes.

For the ordinary power,

```math
K^8
=(K)_8+28(K)_7+266(K)_6+1050(K)_5
+1701(K)_4+966(K)_3+127(K)_2+(K)_1.
```

The four-pairs pattern contributes exactly \(105(K)_4\) pointwise.

### (d)

Yes. Since \(f_p^r=f_p\), a repeated-prime block contributes \(z_p/p\), not \(z_p^r/p\).

### (e)

No. Idempotence removes ordinary-moment diagonals, but the falling factorial had already removed them. The remaining distinct-prime term needs an \(X^{k-2}\) short-CRT saving. At \(k=8\), that is \(X^6\).

## 10. Exact residual theorem

The clean \((HM)_8\) residual is

```math
\boxed{
\sum_{\substack{p_1,\ldots,p_8\in\mathcal P_X\\\text{pairwise distinct}}}
\left(
I_{\mathbf p}(X^2)
-
\frac{X^2}{p_1\cdots p_8}
\prod_{i=1}^8 z_{p_i}
\right)_+
\ll
X^{2+o(1)}\lambda_X^8.
}
```

This is equivalent, up to the controlled main term, to \((HM)_8\).

The alternative pointwise residual in `atom_tail_section.tex` is

```math
\max_{m<X^2}K_X(m)
\le
\lambda_X X^{o(1)}.
```

The proved moment-collapse inequality

```math
\sum_{m<X^2}(K_X(m))_k
\le
\left(\max_{m<X^2}K_X(m)\right)^{k-2}
\sum_{m<X^2}(K_X(m))_2
```

then gives every fixed high moment from \((HM)_2\).

Both residuals rule out the same phenomenon: a deterministic row marked by too many distinct primes. Neither is a repeated-prime diagonal problem.

---

## Final conclusion

The correct ledger is

```math
\boxed{
(HM)_8
\text{ counts eight distinct primes and nothing else.}
}
```

For a distinct tuple,

```math
I_{\mathbf p}(X^2)
=
\frac{X^2}{p_1\cdots p_8}\prod_i z_{p_i}
+O\!\left(\prod_i z_{p_i}\right).
```

Summing the error loses \(X^6\). This loss is attained by an anchored-star model and is exactly the cross-prime Stage-C obstruction.

The Kummer–Mellin supertrace supplies a bounded-complexity linear local coordinate. The high moment requires nonlinear zero detection, mixed characteristics, and distribution in an interval occupying \(X^{-6}\) of a complete CRT period. Current Deligne/Katz theory does not bridge those steps.

> **Therefore \((HM)_k\) is not automatic. A direct Kummer–Mellin plus Deligne argument does not prove \((HM)_8\); a new mixed-characteristic short-CRT dispersion theorem, or an equivalent atom-tail theorem, is still required.**

- Pierre Deligne, [*La conjecture de Weil II*](https://numdam.org/item/PMIHES_1980__52__137_0/), Publications Mathématiques de l'IHÉS 52 (1980), 137–252.
- Nicholas M. Katz, [*Convolution and Equidistribution: Sato–Tate Theorems for Finite-Field Mellin Transforms*](https://doi.org/10.23943/princeton/9780691153308.001.0001), Annals of Mathematics Studies 180, Princeton University Press, 2012.
- Étienne Fouvry, Emmanuel Kowalski, and Philippe Michel, [*A study in sums of products*](https://arxiv.org/abs/1405.2293), Philosophical Transactions of the Royal Society A 373 (2015). Their product trace-function estimates work over one finite field under Goursat–Kolchin–Ribet-type independence; they do not supply the mixed-characteristic short-CRT estimate required here.
