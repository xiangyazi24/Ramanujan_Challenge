# Apéry Mellin coefficients as p-adic Gauss sums

## Executive summary

The proposed Jacobi-product route contains the right ingredients (finite-field hypergeometric functions, Gauss sums, Stickelberger valuations), but the key hoped-for simplification is false:

\[
b_r \not= \text{(bounded number of Jacobi sums depending only on }r\text{)}.
\]

The Apéry coefficient vector modulo p is a **finite-field hypergeometric / Mellin transform object**. The character sum over Greene hypergeometric terms is essential. Removing that sum would destroy the cancellation mechanism that produces the observed AFP behavior.

The zero problem is therefore not a Jacobi valuation problem for individual products; it is a cancellation problem in a family of Gauss-sum expressions.

---

# (A) Exact finite-field hypergeometric description

The correct finite-field statement is not a single Jacobi product. For a hypergeometric motive with parameters

\[
(\tfrac12,\tfrac12,\tfrac12,\tfrac12;1,1,1),
\]

Greene's definition gives

\[
{}_4F_3\left(\begin{matrix}\phi,\phi,\phi,\phi\\ \epsilon,\epsilon,\epsilon\end{matrix};1\right)_p
=
\frac{p}{p-1}\sum_\chi
\frac{J(\phi\chi,\bar\chi)^4}
{J(\phi,\epsilon)^4}
\chi(1).
\]

Equivalently, after Gross--Koblitz conversion, every summand is a product of p-adic Gamma values / Gauss sums.

For Apéry-type sequences the congruence is of the form

\[
b_r\pmod p
=
\text{(hypergeometric trace value depending on the Kummer twist }\omega^r).
\]

The important point is:

\[
b_r \quad\text{is a hypergeometric trace, not one hypergeometric summand.}
\]

The Mellin formula used in the project is the equivalent expression

\[
b_r\equiv-\sum_{t\in\mathbf F_p^\times}\theta_p(t)t^r\pmod p,
\]

where \(\theta_p\) is the primitive Apéry K3 trace function.

The Greene representation and the K3 trace representation are two descriptions of the same trace function.

---

# (B) Why the Jacobi-product valuation argument fails

Suppose artificially that

\[
b_r=J_1J_2.
\]

Then indeed each Jacobi sum has a fractional valuation in the cyclotomic field. However this does not imply

\[
b_r\equiv0\pmod p.
\]

The mistake is confusing valuations in \(\mathbf Q(\zeta_p)\) with the reduction of the hypergeometric trace in \(\mathbf F_p\).

A Gauss sum satisfies a valuation formula after choosing a prime \(\mathfrak p\mid p\), but:

1. the hypergeometric value is a sum of many Gauss-sum products;
2. denominators and normalizations also carry valuations;
3. reduction modulo p occurs after the full algebraic combination is formed.

Thus

\[
v_\mathfrak p(\sum_i A_i)
\neq \min_i v_\mathfrak p(A_i)
\]

when cancellation occurs.

This is exactly the same phenomenon as the AFP problem itself: the difficulty is not the size of individual terms, but cancellation among them.

---

# (C) The exact Greene expansion and the role of cancellation

A Greene hypergeometric value has the form

\[
{}_4F_3=\frac{p}{p-1}\sum_\chi T(\chi),
\]

where

\[
T(\chi)
=\prod_i \frac{J(A_i\chi,\bar\chi)}{J(A_i,\bar B_i)}.
\]

Each \(T(\chi)\) is a controlled Gauss/Jacobi expression. But

\[
b_r
\]

is the sum over all multiplicative characters.

The AFP event

\[
b_r=0
\]

is therefore

\[
\sum_\chi T_r(\chi)=0,
\]

not

\[
T_r(\chi_0)=0.
\]

Stickelberger controls individual summands. AFP requires a non-cancellation theorem for the complete character sum.

---

# (D) Does a closed Jacobi-product formula exist?

In general: no.

There are special cases where hypergeometric functions collapse using quadratic, cubic, or CM transformations. Examples include some finite-field \({}_2F_1\) evaluations and special CM fibers.

The Apéry family is different:

* generic fibers have rank-3 K3 primitive cohomology;
* the trace sheaf has nontrivial monodromy;
* the Mellin variable r is a Kummer twist parameter.

A formula of the form

\[
b_r=J(\chi_r,\psi_r)J(\chi'_r,\psi'_r)\cdot C_r
\]

would imply that the zero set is controlled by Stickelberger fractional-part conditions. Such a rigid description would likely force a highly structured zero pattern, contrary to the observed Poisson-like behavior.

The empirical randomness is evidence that the remaining character sum is genuinely irreducible.

---

# (E) Correct interpretation for AFP

The useful reformulation is not:

\[
\text{When does a Jacobi product vanish?}
\]

but:

\[
\text{How often does a hypergeometric trace Mellin coefficient vanish modulo }p?
\]

The relevant tools are therefore:

1. **p-adic hypergeometric functions** (McCarthy, Gross--Koblitz);
2. **F-crystal unit-root theory**;
3. **Deligne/Katz cancellation for trace functions**;
4. **non-archimedean anti-concentration**.

The missing theorem would be a statement like:

\[
\#\{r:\mathcal M(\theta_p)(\omega^r)=0\}=O(1).
\]

This is a Mellin zero theorem for a K3 hypergeometric trace function, not a Jacobi-sum valuation theorem.

---

# Final conclusion

The finite-field hypergeometric viewpoint is correct and probably the right language for AFP, but the hoped-for reduction is one level too strong.

The exact hierarchy is:

\[
\text{Apéry numbers mod }p
\rightarrow
\text{K3 trace function }
\theta_p
\rightarrow
\text{Mellin transform}
\rightarrow
\text{finite-field hypergeometric sum}
\rightarrow
\text{Gauss/Jacobi sums}.
\]

The final arrow is not invertible: a hypergeometric trace is not normally a single Jacobi product.

Therefore AFP is a **hypergeometric Mellin anti-cancellation problem**, not a Stickelberger zero-count problem.
