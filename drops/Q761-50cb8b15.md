# Q761: General fixed-q Kummer packetization audit

## 1. Setup

Let
\[
p\in (n/(q+1),n/q],\qquad n=qp+r,
\]
so
\[
0\le r<p,
\]
and define
\[
s=\min(r,p-1-r),\qquad g=\gcd(s,p-1),\qquad a=s/g,\qquad d=(p-1)/g.
\]
Then
\[
s=ga,\qquad p-1=gd,\qquad \gcd(a,d)=1.
\]
The Kummer reflection is governed by the congruence
\[
r\equiv \pm s\pmod p.
\]
The two signs give the two linear divisor relations.

## 2. Direct branch

For the direct branch take
\[
r=s=ga.
\]
Since
\[
 n=qp+r,
\]
we have
\[
 n-1=q(p-1)+(r+q-1).
\]
For q=1 this reduces to
\[
n-1=p-1+r=g(d+a).
\]
For general fixed q the corresponding packet parameter is the affine form
\[
\boxed{n-1=qgd+ga+(q-1)}.
\]
Equivalently, after removing the fixed q-offset,
\[
 n-q=g(qd+a).
\]
This is the direct Kummer linear relation.

## 3. Reflected branch

For the reflected representative,
\[
r=p-1-s=p-1-ga.
\]
Then
\[
n=qp+r=(q+1)p-1-ga,
\]
so
\[
n-1=(q+1)p-2-ga.
\]
Using
\[
p=gd+1,
\]
we obtain
\[
\boxed{n-1=(q+1)gd+q-1-ga}.
\]
For q=1 this becomes
\[
 n-1=g(2d-a),
\]
which is the known q=1 reflected formula.

Thus the exact generalization is:

Direct:
\[
\boxed{n-q=g(qd+a)}.
\]

Reflected:
\[
\boxed{n-1-(q-1)=g((q+1)d-a)}.
\]

## 4. Large-g packets

For fixed q, the packet identity implies
\[
g\mid O_q(n).
\]
Hence large g forces the possible s-values into divisors of a number of size O_q(n). The number of large-g packets is controlled by the divisor function.

However, a uniform statement
\[
\log \operatorname{rad}(\text{large-g contribution})=o_q(n)
\]
does not follow from the packet identity alone. One additionally needs that each packet contributes only a controlled number of primes, or that the relevant Kummer divisor values have bounded multiplicity.

The correct conditional statement is:

If the number of admissible prime packets with g\ge G is O_q(n^\epsilon), or if each packet radical is O_q(\exp(o(n))), then the large-g contribution is negligible. The linear divisor relation alone is insufficient.

## 5. Small-g factorial certificate

For small g, the complementary construction gives factorial certificates. Since
\[
s=ga,
\]
and the relevant binomial ranges have size controlled by p/g, the logarithmic height estimate has the form
\[
\log B_g=O_q\left(\frac{n}{g}\log g\right).
\]
This is the expected characteristic-zero certificate scale.

Again this is a height estimate only; it does not automatically prove that all target primes divide the certificate. The missing step is a congruence showing that the Kummer packet condition implies divisibility of the chosen factorial expression.

## 6. Endpoint exceptions

The formulas require the following exclusions:

1. r=0. Then s=0 and g=p-1, so the a,d parametrization degenerates.

2. r=p-1. This cannot occur for the canonical residue r=n mod p, but appears after reflection and must be treated separately.

3. p dividing fixed q-dependent constants introduced while clearing affine shifts.

4. The interval endpoints. The interval
\[
(n/(q+1),n/q]
\]
means the upper endpoint is included and the lower endpoint excluded. Equality cases must be checked separately when n/(q+1) or n/q is integral.

## Verdict

The exact Kummer packetization survives for fixed q with the corrected formulas:
\[
 n-q=g(qd+a),
\]
and
\[
 n-1-(q-1)=g((q+1)d-a).
\]
The q=1 identities n-1=g(d+a) and n-1=g(2d-a) are special cases.

Large-g negligibility is not a formal consequence of packetization; it requires an additional arithmetic multiplicity bound. The small-g factorial certificate height O_q(n/g log g) is plausible but requires a separate divisibility theorem. No endpoint or rounding issue changes the two exact linear relations except the degenerate s=0 cases.
