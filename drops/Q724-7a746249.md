# Cold audit of the four conclusions

## Executive verdict

The four conclusions are not equally reliable. The strongest part is the diagnosis that AFP is a difficult anti-concentration problem. The weakest parts are the claims that pointwise boundedness is the minimum threshold and that nonordinary Kummer twists are the inevitable final route.

The current evidence supports the following hierarchy:

1. AFP (in the sense \(\sum_{p\le X}|Z_p|=O(\pi(X))\)) is a genuinely nontrivial anti-concentration statement. **Plausible and essentially correct, but the word "new" is a judgment rather than a theorem.**
2. \(|Z_p|=O(1)\) is sufficient for AFP, but not necessary. The claim that it is the minimum threshold is **misframed**.
3. A Steinberg/coboundary mechanism is a mathematically natural possibility, but currently **plausible and unsupported**.
4. "All standard approaches fail, therefore attack nonordinary Kummer twists" is **not established**. It is a route choice, not a deduction.

The next theorem to attack should not be a speculative motivic conservation law. The concrete bottleneck is a quantitative orbit anti-concentration theorem weaker than pointwise bounded zeros but strong enough for AFP.

---

# 1. AFP is a genuinely new problem

## Verdict: plausible but unsupported (with a corrected formulation)

The statement depends on what "new" means.

The mathematical content is genuinely difficult because

\[
Z_p=\{r<p:b_r\equiv0\pmod p\}
\]

is a moving-target zero set of a recurrence modulo changing primes. Existing facts give:

- reflection symmetry,
- Lucas/Dwork congruences,
- K3/motive interpretations,
- sheaf-theoretic monodromy information,

but none immediately gives a uniform estimate for the number of hits of a single projective target under the non-autonomous orbit

\[
x_{r+1}=\phi_r(x_r).
\]

However, AFP is not identical to proving a new pointwise theorem. The required average estimate

\[
\sum_{p\le X}|Z_p|=O(\pi(X))
\]

could follow from weaker averaged equidistribution.

So the right statement is:

> AFP is a new anti-concentration problem for a family of arithmetic dynamical systems.

That is supported by the current reductions.

---

# 2. The minimum threshold is pointwise \(Z_p=O(1)\), and Dwork-Mellin is the only route

## Verdict: contradicted / misframed

Pointwise boundedness is sufficient:

\[
|Z_p|\le C \implies \sum_{p\le X}|Z_p|\le C\pi(X).
\]

But it is not necessary.

The empirical distribution

\[
|Z_p|/2\approx\mathrm{Poisson}(1/2)
\]

actually argues against expecting a universal bound. A Poisson-type model predicts occasional large values even when the mean remains bounded.

AFP only needs average control. Possible alternatives include:

- \(\sum |Z_p|^2\ll \pi(X)\),
- tail bounds \(\#\{p:|Z_p|>T\}\) decaying sufficiently fast,
- a large sieve estimate for the orbit targets,
- moment bounds for the Steinberg coefficients.

Therefore:

> \(|Z_p|=O(1)\) is a clean sufficient theorem, not the minimal theorem.

The Dwork-Mellin route is one possible way to obtain cancellation, but it is not known to be the only route.

---

# 3. Motivic/Steinberg coboundary is the most promising route

## Verdict: plausible but unsupported

The reason this idea is attractive is real.

The orbit formulation gives a representation-theoretic observable:

\[
\sum_r \mathrm{St}_{v,w}(M(r)).
\]

If the zero indicator were a coboundary,

\[
1_{b_r=0}-\frac1{p+1}=F(r+1)-F(r),
\]

then AFP would telescope.

This would explain the unexpectedly small zero counts through an exact conservation law rather than random cancellation.

But there is currently no construction of such an \(F\). The failed state-only search is evidence against naive forms, not against all motivic possibilities.

A realistic version would probably require:

- extending the state space beyond \(x_r=b_r/b_{r-1}\),
- incorporating Frobenius/unit-root data,
- using a sheaf-theoretic trace identity rather than an elementary recurrence identity.

Thus the idea is promising as a structural explanation, but it is not yet a proof strategy.

---

# 4. All standard approaches fail, so attack nonordinary Kummer twists

## Verdict: contradicted as a logical conclusion

Several approaches have genuine obstacles:

- ordinary Mahler-Strassmann does not help because the relevant analytic functions have too many possible zeros;
- direct CRT counting hits a third-moment barrier;
- generic equidistribution of the K3 family does not automatically control the shrinking target \([0:1]\).

But "failed so far" does not imply that nonordinary Kummer twists are the remaining route.

Possible alternatives remain:

- direct transfer-matrix forcing,
- stronger large sieve estimates for the non-autonomous orbit,
- collision bounds for large prime divisors of Apéry numbers,
- second/third moment estimates for \(K_X(m)\),
- a refined Steinberg spectral estimate.

The nonordinary Kummer twist direction is a hypothesis, not a theorem-driven necessity.

# What theorem should be attacked next?

The first concrete theorem should be:

## Moving-target orbit discrepancy theorem

For the Apéry projective orbit

\[
\Pi_r e_1\in\mathbf P^1(\mathbf F_p),
\]

prove an averaged discrepancy bound

\[
\sum_{p\le X}\left(|Z_p|-1\right)_+ =O(\pi(X)^{1-\delta})
\]

or even the weaker moment estimate

\[
\sum_{p\le X}|Z_p|^2\ll \pi(X).
\]

This is the first theorem because:

1. It directly targets AFP.
2. It does not require the unlikely statement \(|Z_p|=O(1)\).
3. It is compatible with the Poisson data.
4. It can potentially be attacked by existing tools: trace functions, large sieve, or Steinberg decomposition.

A stronger but still realistic intermediate target is:

\[
\sum_{r<p}|\mathbf 1_{b_r=0}-1/(p+1)|^2=O(1)
\]

on average over primes.

That would capture the observed random-function behavior without demanding a deterministic bounded-zero theorem.

---

# Final assessment

The key correction is:

AFP is not equivalent to proving that every Apéry orbit has bounded target visits. It is an average anti-concentration theorem.

The hidden conservation law remains an interesting possibility, but the next attack should be quantitative discrepancy/moment control, not a leap to a specific motivic twist. The most valuable theorem is one that separates the random-model prediction (bounded moments) from the stronger but probably unnecessary claim (uniform boundedness).
