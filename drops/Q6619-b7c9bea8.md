# Part 1. The logarithm is sharp

## 1.1 The master inequality from Q6592

The proof of Q6592 actually established the stronger intermediate inequality

```text
Q_H <= 22 H^2 sum_(d=1)^H R_d/d^2.                (1.1)
```

The hypothesis `R_d<=Cd` was used only afterward, to bound the last sum by `C(1+log H)`.

Thus the endpoint question is equivalent to asking whether a genuine word can spend a positive proportion of the budget

```text
R_d <= C d
```

at logarithmically many scales while keeping the equality relation globally consistent.

It can. The exact budget allocator is Euler's totient function.

## 1.2 Totient-weighted arithmetic-progression classes

Fix a large integer `H`. For every integer

```text
ceil(sqrt(H)) <= s <= floor(H/4),
```

put

```text
q_s = floor(H/s),
a_s = floor(phi(s) s/H),                           (1.2)
```

where `phi` is Euler's totient function.

For each of the `a_s` copies, introduce a private color and place it on the arithmetic progression

```text
b, b+s, b+2s, ..., b+q_s s.                       (1.3)
```

Use a separate interval of length `H+1` for every copy, and give every unused position a fresh singleton color. Thus distinct progression classes have distinct colors and produce no cross-class collisions. Every class in (1.3) has diameter at most `H`.

This is an actual finite word. Its length is irrelevant to the extremal assertion and may grow with `H`.

## 1.3 Exact verification of all gap budgets

Fix `1<=d<=H`. A class of step `s` contributes at gap `d` only when `s|d`; in that case it contributes

```text
q_s+1-d/s
```

pairs. Therefore

```text
R_d
 = sum_(s in the selected range, s|d)
     a_s (q_s+1-d/s).                              (1.4)
```

Using (1.2),

```text
a_s <= phi(s)s/H
```

and

```text
q_s+1-d/s
 <= H/s+1-d/s
 = (H+s-d)/s.
```

Hence

```text
R_d
 <= sum_(s|d) phi(s)(H+s-d)/H
 <= ((H-d)/H) sum_(s|d) phi(s)
    +(1/H) sum_(s|d) s phi(s).                     (1.5)
```

The sums in (1.5) were enlarged from the selected divisors to all divisors; this is legitimate because `H-d>=0`. Now use

```text
sum_(s|d) phi(s)=d
```

and the trivial estimate

```text
sum_(s|d) s phi(s)
 <= d sum_(s|d) phi(s)
 = d^2.
```

This gives the exact pointwise bound

```text
R_d <= ((H-d)d+d^2)/H = d.                        (1.6)
```

For `d>H`, every class has diameter at most `H`, so `R_d=0`. Thus the word satisfies

```text
R_d <= d
```

for every positive gap, not merely for `d<=H`.

The role of `phi(s)` is now visible: the identity `sum_(s|d)phi(s)=d` splits the gap-`d` budget exactly among all step sizes dividing `d`. Naively assigning equal weight to every dyadic layer incurs a divisor-sum loss; the totient weights remove that obstruction.

## 1.4 Lower bound for `Q_H`

Every triple inside one class (1.3) has span at most `H`, so that class contributes

```text
C(q_s+1,3)
```

to `Q_H`. Therefore

```text
Q_H = sum_s a_s C(q_s+1,3).                        (1.7)
```

For `s<=H/4`, put `x=H/s>=4`. Then

```text
q_s=floor(x)>=3x/4,
```

and consequently

```text
x^3/20 <= C(q_s+1,3) <= x^3/3.                    (1.8)
```

Also

```text
a_s >= phi(s)s/H-1.
```

Using the lower bound in (1.8) for the main term and the upper bound for the floor error gives

```text
Q_H
 >= (H^2/20) sum_(sqrt(H)<=s<=H/4) phi(s)/s^2
    -(H^3/3) sum_(s>=sqrt(H)) 1/s^3.               (1.9)
```

The two standard estimates needed here are

```text
sum_(s<=X) phi(s)/s^2
 = (6/pi^2) log X + O(1),                           (1.10)
```

and

```text
sum_(s>=sqrt(H)) 1/s^3 = O(1/H).                   (1.11)
```

For completeness, (1.10) follows directly from

```text
phi(n)/n = sum_(e|n) mu(e)/e
```

by writing `n=em`; the coefficient of `log X` is

```text
sum_(e>=1) mu(e)/e^2 = 1/zeta(2)=6/pi^2.
```

Taking the difference of (1.10) at `H/4` and `sqrt(H)` gives

```text
sum_(sqrt(H)<=s<=H/4) phi(s)/s^2
 = (3/pi^2) log H + O(1).                           (1.12)
```

Combining (1.9)-(1.12),

```text
Q_H >= (3/(20 pi^2)+o(1)) H^2 log H.               (1.13)
```

The numerical constant in (1.13) is not important; the point is the full logarithm.

## 1.5 Abstract endpoint theorem

The construction and Q6592 combine to give the following sharp result.

> **[THM-ABSTRACT-Q-H2LOGH-SHARP].** For every fixed `C>=1`, among finite words satisfying `R_d<=Cd` for `1<=d<=H`,
>
> ```text
> sup Q_H = Theta_C(H^2 log H).
> ```
>
> The lower bound already holds with `C=1`.

Thus the log is genuinely combinatorial. Arithmetic input is necessary even to remove it.

# Part 1(b). Conditional logarithm removal by Abel summation

The observation in the question is correct, and (1.1) makes the statement especially clean.

> **[THM-ABSTRACT-Q-H2-ABEL].** Suppose that for some `A>0` and `delta>0`,
>
> ```text
> S_1(Y)=sum_(d<=Y)R_d <= A Y^(2-delta)
> ```
>
> for every `1<=Y<=H`. Then
>
> ```text
> Q_H <= 22 A (3+2/delta) H^2.                     (2.1)
> ```
>
> The separate hypothesis `R_d<=Cd` is not needed for this implication.

Indeed, summation by parts gives

```text
sum_(d=1)^H R_d/d^2
 = S_1(H)/H^2
   +sum_(d=1)^(H-1)
      S_1(d)(1/d^2-1/(d+1)^2).                     (2.2)
```

Since

```text
1/d^2-1/(d+1)^2 <= 2/d^3,
```

we get

```text
sum_(d=1)^H R_d/d^2
 <= A H^(-delta)
    +2A sum_(d=1)^(H-1) d^(-1-delta)
 <= A(3+2/delta).                                  (2.3)
```

Insert (2.3) into (1.1) to obtain (2.1).

The totient construction necessarily violates this prefix hypothesis: it spends quadratically sized pair budgets across the relevant scales. Hence there is no conflict between the sharp logarithmic example and the conditional theorem.

For the Apéry orbit, removing the logarithm by this route is exactly an arithmetic prefix-census problem.

# Part 2. The mesoscopic target

## 3. `Q_D` is a graph triangle count

Form a graph `G_D` on the word positions. Join `u<v` by an edge when

```text
v-u<=D
```

and

```text
x_u=x_v.
```

Then

```text
|E(G_D)| = S_1(D).                                  (3.1)
```

A triple of vertices is a triangle in `G_D` if and only if the three positions have one color and their maximum minus minimum is at most `D`. Therefore

```text
Q_D = number of triangles of G_D.                  (3.2)
```

Every finite graph with `E` edges has at most

```text
(sqrt(2)/3) E^(3/2)                                (3.3)
```

triangles. A one-line spectral proof is as follows. If `A` is the adjacency matrix, `lambda` its largest eigenvalue, and `lambda_i` all eigenvalues, then

```text
6T = trace(A^3)
   = sum_i lambda_i^3
   <= lambda sum_i lambda_i^2
   = 2E lambda
   <= 2E sqrt(2E).
```

Combining (3.1)-(3.3) proves the universal inequality

```text
boxed:
Q_D <= (sqrt(2)/3) S_1(D)^(3/2).                   (3.4)
```

This uses only equality transitivity. It is independent of the inverse-square clique estimate.

## 4. What linear prefix control really says about window masses

Use the same half-open windows as Q6592:

```text
B_j = [jD,(j+1)D),
W_j = [jD,(j+2)D),                                  (4.1)
```

clipped at the ends of the word. For each color `a`, let

```text
m_(j,a) = #{n in W_j : x_n=a}.                     (4.2)
```

Three elementary relations are useful.

First, each position belongs to at most two `W_j`, so

```text
sum_(j,a) m_(j,a) <= 2(N+1).                       (4.3)
```

Second, put

```text
P_W(D)=sum_(j,a) C(m_(j,a),2).                     (4.4)
```

Every pair counted by (4.4) has gap less than `2D`, and a global pair is contained in at most two doubled windows. Conversely every monochromatic pair of gap at most `D` is contained in at least one `W_j`. Hence

```text
S_1(D) <= P_W(D) <= 2 S_1(2D).                     (4.5)
```

Third, assigning a `D`-span triple according to the block containing its least point gives

```text
Q_D <= sum_(j,a) C(m_(j,a),3).                     (4.6)
```

Now suppose

```text
S_1(Y) <= A Y
```

for `Y<=2D`. Then (4.5) gives

```text
P_W(D) <= 4AD.                                      (4.7)
```

Thus the actual distributional information is a global second-factorial-moment bound. In particular,

```text
#{(j,a):m_(j,a)>=t}
 <= 2P_W(D)/(t(t-1))
 << AD/t^2,                                         (4.8)
```

and

```text
max_(j,a) m_(j,a) << sqrt(AD).                     (4.9)
```

Since

```text
C(m,3)=((m-2)/3)C(m,2),
```

(4.7)-(4.9) yield

```text
sum_(j,a) C(m_(j,a),3)
 << (AD)^(3/2).                                     (4.10)
```

This is the window version of (3.4).

### Where the inverse-square proof loses `L^2`

Under the same linear prefix bound, Abel summation gives

```text
sum_(d<=D) R_d/d^2 = O(A).
```

The local inverse-square lemma then multiplies this by the worst-case geometric factor `D^2`, producing `O(AD^2)`. That step uses the weighted pair energy but discards the simultaneous unweighted second moment

```text
P_W(D)=O(AD).
```

Coupling the third moment to this unweighted second moment gives `D^(3/2)`, not `D^2`.

Thus the missing information was not a new arithmetic variance theorem. Linear prefix control itself already is the needed second-factorial-moment statement; it merely has to be coupled to triples by the triangle-edge inequality rather than fed only into the inverse-square estimate.

At

```text
D=sqrt(N)L,
```

(3.4) gives

```text
Q_D << A^(3/2) N^(3/4)L^(3/2).                     (4.11)
```

Hence `Q_D<<N` whenever

```text
L << N^(1/6).
```

This includes every intended slowly growing `L`.

# 6. There is no multiscale self-improvement from `Q_H<<H^2`

A tempting recursion would use a log-free theorem at scale `H` to improve pair counts or triple counts at scale `2H`. In the abstract word class this cannot work.

## 6.1 There is no arrow from triangles back to pairs

One may add arbitrarily many private two-point color classes. They increase `S_1(H)` but contribute nothing to `Q_H`. Thus no upper bound on `Q_H` can by itself produce an upper bound on the window pair moment at a larger scale.

The proposed recursion has the wrong direction: pair information controls triangles, but triangle information does not control pairs without an extension hypothesis saying that a substantial fraction of pairs participate in triples.

## 6.2 The exponent `2` is an actual dyadic fixed point

The explicit three-point construction from Q6592 already shows this. For every `t<=D/2`, take `t` private classes of the form

```text
b, b+t, b+2t.
```

Then for every `Y<=D`,

```text
Q_Y
 = sum_(t<=Y/2) t
 = (1/8+o(1))Y^2,                                  (6.1)
```

while

```text
R_d <= (5/2)d.                                     (6.2)
```

Thus the all-scale hypothesis

```text
Q_Y << Y^2 for every Y
```

is compatible with saturation `Q_Y asymp Y^2` at every dyadic scale. In particular,

```text
Q_(2Y)/Q_Y -> 4.
```

No purely recursive use of the same `Y^2` estimate can produce a power saving.

The clean exponent map is one-way:

```text
pair exponent beta
    -> triangle exponent min(2,3beta/2).           (6.3)
```

There is no reverse map in the abstract class. The fixed frontier is `beta=4/3`, triangle exponent `2`.

# 7. Comparison of the three proposed arithmetic inputs

Throughout this section, `N` is comparable to `p`, as in the Apéry orbit, and `D=o(N)`.

## 7.1 Candidate (i): linear prefix census

Assume

```text
(i)  S_1(Y) <= A Y for every Y<=D.                 (7.1)
```

Then (3.4) gives

```text
Q_D <= (sqrt(2)/3)A^(3/2)D^(3/2).                 (7.2)
```

Therefore (i) closes `[MESO-PAIR]` for every intended slowly growing `L`.

It is substantially stronger than necessary: the scalar threshold is only `S_1(D)<<N^(2/3)`.

Candidate (i) does not imply the row-variance scale in candidate (ii). To see this, let `m` be large and take one private arithmetic progression

```text
0,m,2m,...,m^2
```

with `H=m^2`, padding the rest of the word by singleton colors if desired. For every `Y<=H`,

```text
S_1(Y) << Y,
```

because the only occupied gaps are multiples of `m`, but

```text
sum_r d_H(r)^2 asymp m^3=H^(3/2),                 (7.3)
```

not `O(H)`.

So linear prefix control closes the mesoscopic target without forcing random-like row variance.

## 7.2 Candidate (ii): centered row variance

Let `I` be a lag interval, define

```text
d_I(r)=sum_(h in I) 1[x_r=x_(r+h)],
```

and let

```text
q_I(r)=#{h in I:r+h is admissible},
mu_I(r)=q_I(r)/p.                                  (7.4)
```

Assume

```text
(ii) V_I:=sum_r (d_I(r)-mu_I(r))^2 <= B|I|.        (7.5)
```

For the full interval `I=[1,D]`,

```text
2Q_D=sum_r d_I(r)^2-sum_r d_I(r).                 (7.6)
```

Using

```text
d_I(r)^2
 <= 2(d_I(r)-mu_I(r))^2+2mu_I(r)^2
```

and

```text
sum_r mu_I(r)^2
 <= (N+1)|I|^2/p^2
 << |I|^2/N,                                       (7.7)
```

we obtain

```text
Q_D <= V_I+O(D^2/N)
     << BD+D^2/N.                                  (7.8)
```

Thus candidate (ii) is far stronger than needed.

It also implies candidate (i), provided (7.5) is known for the prefix intervals. Indeed, since `d_I(r)` is a nonnegative integer,

```text
d_I(r) <= d_I(r)^2,
```

so the same calculation gives

```text
sum_r d_I(r)
 <= 2V_I+O(|I|^2/N)
 << B|I|+|I|^2/N.                                  (7.9)
```

For `|I|=o(N)`, this is linear.

Therefore the implication chain is

```text
(ii) => (i) => [MESO-PAIR].                        (7.10)
```

The reverse implication `(i)=>(ii)` is false by (7.3).

A narrower row statement sufficient for the target is merely

```text
[MESO-ROW-L2]
sum_r (d_D(r)-mu_D(r))^2 << N.                    (7.11)
```

It is enough at the single scale `D`; no all-interval WALL-zero theorem is required. However, (7.11) is close to a restatement of `Q_D<<N` through (7.6), so it is less attractive as an independent first target than the scalar census (0.2).

## 7.3 Candidate (iii): unweighted per-color window second moment

The proposed form is

```text
(iii) sum_(j,a) C(m_(j,a),2)
      << sum_(j,a)m_(j,a)
      << N.                                        (7.12)
```

This does not imply `Q_D<<N`.

The basic reason is moment mismatch. If

```text
e_(j,a)=C(m_(j,a),2),
```

then

```text
C(m_(j,a),3) asymp e_(j,a)^(3/2)                  (7.13)
```

for large masses. A bound on `sum e_(j,a)` permits that pair mass to concentrate in a few window-color cells, producing a much larger third moment.

### Genuine-word counterexample retaining `R_d<=3d`

This failure persists even under the banked pointwise gap bounds.

Fix a large `D`. Restrict the totient construction to the single band

```text
sqrt(D) <= s <= 2sqrt(D),
```

and take

```text
q_s=floor(D/s),
a_s=floor(3 phi(s)s/D).                            (7.14)
```

Use private arithmetic-progression classes as before. The same divisor calculation proves

```text
R_d <= 3d.                                         (7.15)
```

There are `Theta(sqrt(D))` classes. One way to see the lower bound is to use

```text
sum_(n in [X,2X]) phi(n)/n
 = (6/pi^2)X+O(log X).
```

A positive proportion of the integers in `[X,2X]` have `phi(n)/n>=1/2`; for such `s`, (7.14) gives `a_s>=1`.

Every class has

```text
Theta(sqrt(D)) positions,
Theta(D) pairs,
Theta(D^(3/2)) triples.                             (7.16)
```

Consequently the resulting word segment has

```text
S_1(D)=Theta(D^(3/2)),
Q_D=Theta(D^2),                                    (7.17)
```

and uses only `Theta(D^(3/2))` positions when the private classes are put in separate `(D+1)`-blocks.

Now choose any slowly growing `L=L(D)` with

```text
L^2=o(sqrt(D)),
```

and append singleton colors until the total length is

```text
N=(1+o(1))D^2/L^2.
```

Then `D=(1+o(1))sqrt(N)L`, while

```text
Q_D=Theta(D^2)=Theta(NL^2) >> N.                  (7.18)
```

On the other hand, every same-color pair has gap at most `D`, and every global pair occurs in at most two doubled windows, so

```text
sum_(j,a) C(m_(j,a),2)
 <= 2S_1(2D)
 = O(D^(3/2))
 = o(N).                                           (7.19)
```

Thus (iii) can hold with room to spare while `[MESO-PAIR]` fails by the full factor `L^2`.

In fact each active `D`-window in this construction has only `O(D)` monochromatic pairs, so even a natural local second-moment bound per window is insufficient. The missing factor is the size bias contributed by a large color mass inside that window.

Therefore

```text
(i) => (iii),
(ii) => (i) => (iii),
```

but

```text
(iii) does not imply (i), (ii), or Q_D<<N.         (7.20)
```

# 8. The correct window-variance formulations

There are three clean ways to repair candidate (iii).

## 8.1 Scalar second-moment threshold

From (4.6), (7.13), and convexity,

```text
Q_D
 <= (sqrt(2)/3)
    (sum_(j,a) C(m_(j,a),2))^(3/2).                (8.1)
```

Therefore the scalar window condition

```text
sum_(j,a) C(m_(j,a),2) << N^(2/3)                 (8.2)
```

closes the target. By (4.5), this is essentially the same as `[MESO-S1-2/3]`, up to the harmless use of `2D` in the doubled-window cover.

The scale `N`, proposed in (iii), is too large; the scalar threshold is `N^(2/3)`.

## 8.2 Distributed variance-tail condition

A weaker condition than (8.2), when the pair mass is well spread, is

```text
[MESO-WIN-3/2]
sum_(j,a) C(m_(j,a),2)^(3/2) << N.                (8.3)
```

Then (4.6) and (7.13) directly give `Q_D<<N`.

This is the correct distribution-sensitive replacement for the unweighted second moment. It permits a much larger total pair mass than `N^(2/3)` if that mass is spread among many bounded cells.

## 8.3 Palm/size-biased window variance

Let

```text
n_(j,a)=#{r in B_j:x_r=a}.
```

For a base `r in B_j` of color `a`, all of its forward returns of length at most `D` lie in `W_j`; hence

```text
d_D(r) <= m_(j,a)-1.
```

Therefore

```text
Q_D
 = sum_r C(d_D(r),2)
 <= (1/2) sum_(j,a)
      n_(j,a)(m_(j,a)-1)^2.                        (8.4)
```

Thus the genuinely second-moment, occurrence-weighted statement

```text
[MESO-PALM-WIN2]
sum_(j,a) n_(j,a)(m_(j,a)-1)^2 << N               (8.5)
```

also closes the target.

The factor `n_(j,a)` is load-bearing. Uniformly weighting window-color cells, as in (iii), misses exactly the large cells that are seen by many possible bases.

The row variance in candidate (ii) is the oriented, base-exact version of this Palm principle.

# 9. Recommended minimal arithmetic targets

There are two useful meanings of "minimal".

## 9.1 Minimal scalar census target

If one insists on using only the single number `S_1(D)`, the clean threshold is

```text
[MESO-S1-2/3]
```

## (a) Which step am I least confident in?

The proved implications and the totient construction are the parts I am most confident in. The statement I would qualify most carefully is the word "minimal" in `[MESO-S1-2/3]`.

There were two related blind spots.
