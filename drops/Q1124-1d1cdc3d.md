# Q1124 audit: aligned multiwindow carrier

## Conclusion

The simultaneous Cartier divisibility is genuine, but for the aligned family it does not produce a smaller characteristic-zero carrier. The obstruction is not recurrence dimension: it is that the characteristic-zero rows are evaluations of different high-height integer polynomials in the auxiliary variable m, and their common eliminants retain the same exponential height.

## 1. The exact divisibility information

For a candidate prime p with

```
q p <= n < (q+1)p
```

write r=n-qp. The Cartier computation gives, for every admissible k,

```
P_{h_k(p)}(n) = b_r R_k(q,n) (mod p),
```

where R_k is the shortened Newton value at q. Therefore

```
p | b_r  ==>  p | P_{h_1(p)}(n),...,p | P_{h_K(p)}(n).
```

This is K simultaneous congruences, but they are not K independent copies of a fixed integer.

## 2. The natural resultant carrier

Put

```
G_0(m)=m,
G_k(m)=P_{H-km+1}^{(M)}(n), 1<=k<=K.
```

The strongest direct fixed-q construction is a primitive gcd/resultant ideal:

```
I=(G_0,G_1,...,G_K) subset Z[m].
```

At m=p the desired prime divides every element of I. Any integer carrier obtained by Bezout elimination is therefore a primitive generator of a subresultant/content of these polynomials.

However the degrees and coefficients of G_k are inherited from the Newton window. For length M, the binomial factors contain products of O(M) consecutive linear factors in m. Hence

```
log ||G_k|| = Theta(M log n)=Theta(n log n)
```

in the generic fixed-q range.

Taking gcd or Smith combinations cannot remove this height. It can only reduce the content coming from accidental common factors. The primitive resultant satisfies the standard bound

```
log |Res(G_i,G_j)| <= deg(G_i) log||G_j|| + deg(G_j) log||G_i||,
```

so the upper bound is still O_q(n log n), not o_q(n).

## 3. Why multiplicity k does not divide the height constant

The rows are not powers of a common linear factor. Their leading terms come from shifted Newton kernels:

```
G_k(m)=sum_j c_{k,j}(m)b_j.
```

Changing k changes the shift h_k and changes the entire coefficient vector c_{k,j}. Thus the determinant of K rows is a genuine interpolation determinant, not a repeated Vandermonde factor with multiplicity K.

The K x K minors therefore have the form

```
Delta = sum products of binomial coefficients,
```

with primitive content bounded independently of p but with the same O(n log n) coefficient height. There is no factor K in the logarithmic height exponent.

## 4. Characteristic-zero countermodel

A countermodel preserving the window identities is obtained by replacing the Apéry sequence by arbitrary integer data satisfying only the Cartier residues:

```
b_{ap+r}=b_a b_r (mod p).
```

Choose characteristic-zero lifts of the shortened rows independently:

```
R_k(q,n)=L_k,
```

with prescribed primitive integers L_k of size exp(c n). The congruences remain valid because only their residues modulo p enter the Cartier factorization.

Then every common eliminant must vanish modulo primes dividing the chosen L_k, but its primitive representative still has size exp(c n). Therefore the aligned identities alone cannot force a subexponential carrier.

This obstruction is scoped to the exact aligned family; it does not rule out additional Apéry-specific cancellation beyond the Cartier rows.

## 5. Gamma-row formulation

The same argument applies to Gamma representations. Each row has factors of the form

```
Gamma(n+1)/(Gamma(j+1)Gamma(n-j+1))
```

with shifts depending on k. Resultants of these Gamma rows eliminate m but retain products of O(n) integers. Smith normalization removes only common integer content, not the factorial-scale growth.

## 6. Final carrier verdict

The strongest available fixed-q aligned carrier is

```
C_q(n)=primitive_content( gcd_Z(G_0,G_1,...,G_K) )
```

or equivalently a primitive subresultant of the Gamma-row system.

Its guaranteed height is

```
log C_q(n)=O_q(n log n),
```

and the characteristic-zero countermodel shows that the aligned Cartier identities alone do not improve this to o_q(n), nor reduce the critical coefficient by K.

The multiwindow attack therefore gives stronger congruence multiplicity but no new fixed-q radical carrier without an additional Apéry-specific cancellation theorem.
