# Density-one plus continuity: does it upgrade to all n?

## Short answer

The proposed argument identifies a real obstruction, but the continuity step does **not** work in the form stated. The missing quantity is not the density of the exceptional set alone; it is the size of the gaps between good indices together with a uniform bound on the change of the prime-factor count.

The density-one theorem is not strong enough to imply an all-n theorem by a nearest-good-point argument unless one proves substantially more quantitative information.

## 1. What the argument would need

Let

```
B(n)=#{p in (sqrt(n),n] : p | b_{n mod p}}
```

(or the weighted version giving the GCD exponent). Suppose the good set is

```
G={n : B(n) <= eps(n)n/log n}
```

with eps(n)->0 and density(G)=1.

For an arbitrary n, choose the nearest good n'. Then

```
B(n) <= B(n') + |B(n)-B(n')|.
```

The argument requires two inputs:

1. a small gap

```
|n-n'|=o(n/log n),
```

2. a Lipschitz estimate

```
|B(n+h)-B(n)| << h.
```

Only then would the conclusion follow.

## 2. Density one does not imply small gaps

A set of density one can have arbitrarily long gaps.

For example, remove intervals

```
[N_k, N_k+L_k]
```

where

```
L_k=o(N_k)
```

but L_k is still much larger than any prescribed function such as log N_k or N_k^0.01 along a subsequence.

The remaining set has density one, but there are points arbitrarily far from a good point.

Therefore density one alone gives no usable interpolation radius.

To make this strategy work, one needs something like:

```
Every interval [N,N+N^delta] contains a good n.
```

for some delta<1.

That is a much stronger quantitative density theorem.

## 3. The refreshing bound is also the difficult part

The claim

```
|B(n+1)-B(n)| <= D
```

is not currently justified.

The recurrence gives information about a fixed prime p dividing consecutive terms. Indeed, if p divides both b_n and b_{n+1}, then the recurrence forces algebraic constraints such as roots of the recurrence coefficient modulo p.

This controls **persistent divisors**.

But B(n) is not the set of persistent divisors. It counts all primes satisfying different congruence conditions:

```
p | b_{n mod p}.
```

When n changes to n+1, the relevant residue changes from

```
r=n mod p
```

to

```
r+1 mod p.
```

A prime can disappear and another unrelated prime can appear. The recurrence only controls overlap, not total variation.

Thus the true needed theorem is a bound on the number of entering/leaving primes:

```
#{p: p|b_{(n+1) mod p}, p not|b_{n mod p}} = O(1).
```

No such theorem is known.

## 4. What can actually be extracted from continuity?

The recurrence does imply strong local rigidity for the same prime:

```
p | b_r and p | b_{r+1}
```

is rare, because the Casoratian gives

```
gcd(b_r,b_{r+1}) | 6.
```

Hence large primes almost never persist from one index to the next.

But this means the factor set is refreshed, not that the count is stable. In fact, it suggests that consecutive B(n) values may behave almost independently.

The statement

```
most primes dividing b_n do not divide b_{n+1}
```

does not imply

```
B(n+1)-B(n)=O(1).
```

It only implies low correlation.

## 5. What exceptional-set estimate would be enough?

Suppose one had a stronger result:

```
# {m <= N : B(m) > eps N/log N} <= N^{1-delta}.
```

Then the largest gap between good points up to N is not automatically N^delta, but a covering argument would give useful intervals after additional local information.

If one could prove directly:

```
Every interval of length N^alpha contains a good point
```

and

```
B(n+1)-B(n) << 1,
```

then the desired upgrade would follow:

```
B(n) <= eps n/log n + O(n^alpha).
```

Choosing alpha<1 gives o(n/log n).

## 6. The real missing theorem

The density-one theorem already proves that large GCDs are rare. The all-n problem requires controlling the geometry of the exceptional set.

The missing statement is closer to:

```
Exceptional n cannot cluster in long intervals.
```

or equivalently a short-interval large sieve theorem for the moving targets:

```
B(n) is small for all but a negligible number of n in every interval.
```

This is stronger than a global variance estimate.

## Conclusion

The continuity idea is promising because it correctly identifies that the remaining gap is an exceptional-set problem. However:

1. density one does not imply nearby good integers;
2. the recurrence controls persistent primes but not the total change of B(n);
3. a uniform refreshing bound |B(n+1)-B(n)|=O(1) is itself essentially a new theorem.

A successful version would require a quantitative density-one theorem in short intervals plus a local variation bound. That would indeed upgrade the density-one GCD result to the full conjecture, but neither ingredient is currently available from the recurrence alone.
