# Verdict

There is **no global divisibility in either direction** between the capped positive-endpoint Padé rectangle and the short multicutoff Legendre–Euler intersection. The exact relationship becomes triangular only after separating primes above `M=floor(n/2)`.

For the cap that gives the stated `n=200` value, namely

```text
H = floor((n-1)/3),
B_+(n) = binom(n,H+1),
B_-(n) = binom(n+H+1,H+1),
G_+(n) = gcd_{0<=a<=H} |P_{H,a}(n)|,

R_+(n) = B_+(n) / gcd(B_+(n),B_-(n)),
E(n)   = gcd(G_+(n),R_+(n)),
```

and for the two Legendre–Euler intersections

```text
I(n)     = gcd_{H<=J<=M} Gamma_(n,J),
I_dir(n) = gcd_{H<=J<=n-H-1} Gamma_(n,J),
```

the exact large-prime decomposition is

```text
E(n)_{>M}     = D(n),
I_dir(n)_{>M} = D(n) C(n) O(n),
I(n)_{>M}     = D(n) C(n) R(n) O(n).
```

Here `D,C,R` are respectively the direct-exclusive, central, and reflected-exclusive genuine `q=1` Apéry target factors, while `O` is an overshoot factor made of primes `p>n`. All four factors are squarefree and pairwise coprime. Consequently the actual `q=1` target radical is

```text
T_q1(n) = D(n) C(n) R(n).
```

Thus, after localizing away from primes at most `M`, one has the integer divisibility triangle

```text
E(n)_{>M} | I_dir(n)_{>M} | I(n)_{>M},
```

or, equivalently, the reverse inclusion of principal ideals

```text
(I(n)_{>M}) subset (I_dir(n)_{>M}) subset (E(n)_{>M}).
```

Globally this fails because the three constructions have unrelated small-prime contents. The listed fixtures already reverse the divisibility direction:

```text
n=8:   E=1,  I=5,
n=36:  E=25, I=5.
```

The equality quoted at `n=200` is the **short/folded** multicutoff intersection:

```text
E(200) = I(200) = 5*139*181.
```

The longer direct-safe intersection is instead

```text
I_dir(200) = 139*181.
```

Combining the carriers by gcd does not solve the problem: it drops central and reflected targets. Combining by lcm retains overshoot nuisance. Even adjoining `I_dir` does not give a universal ideal-lattice purification, because a central target and an overshoot nuisance have the same three-carrier support signature.

# 1. Exact definitions and normalizations

Write the Apéry and Franel numbers as

```text
b_m = sum_k binom(m,k)^2 binom(m+k,k)^2,
F_m = sum_k binom(m,k)^3,
L(n,k) = binom(n,k) binom(n+k,k).
```

For the Padé family, `(P_{H,a},Q_{H,a})` is the jointly primitive integral Newton-basis pair satisfying

```text
deg P_{H,a} <= a,
deg Q_{H,a} <= H-a,
P_{H,a}(s) = b_s Q_{H,a}(s),       0<=s<=H,

gcd(all Newton coefficients of P and Q) = 1.
```

There is no numerator-only division after this joint normalization.

For the Legendre–Euler family, put

```text
Q_n(t) = sum_{k=0}^n L(n,k)t^k,
K_(n,m)(c) = [y^m] Q_n(c+y),
g_m(c) = sum_{i=0}^m binom(m,i)(-c)^(m-i)F_i,
T_(n,J)(c) = sum_{m=0}^J K_(n,m)(c)g_m(c),
Gamma_(n,J) = content_c T_(n,J)(c).
```

The exact consecutive-cutoff relation is

```text
T_(n,J)-T_(n,J-1) = K_(n,J) g_J.
```

Since `g_J` is primitive, Gauss's lemma gives

```text
content(T_(n,J)-T_(n,J-1)) = kappa_(n,J),

kappa_(n,J)
 = gcd_{J<=k<=n}
     L(n,k) binom(k,J).
```

Therefore the two intersections have the exact fast forms already used in `q32_multicutoff_content_intersection.py`:

```text
I(n)
 = gcd(Gamma_(n,H), kappa_(n,H+1), ..., kappa_(n,M)),

I_dir(n)
 = gcd(Gamma_(n,H), kappa_(n,H+1), ..., kappa_(n,n-H-1)).
```

For an integer `N`, write `N_{>M}` for its largest divisor supported on primes greater than `M`, with valuations retained.

# 2. The four-factor theorem

Let

```text
H = floor((n-1)/3),
M = floor(n/2).
```

For a prime `M<p<=n`, define the direct and reflected labels

```text
r_p = n-p,
s_p = 2p-1-n.
```

These satisfy `r_p,s_p>=0`, and at least one is at most `H`. Define

```text
D(n)
 = product over primes M<p<=n such that
     r_p<=H<s_p and p|b_(r_p),

C(n)
 = product over primes M<p<=n such that
     r_p<=H and s_p<=H and p|b_(r_p),

R(n)
 = product over primes M<p<=n such that
     s_p<=H<r_p and p|b_(s_p),

O(n)
 = product over primes n<p<=n+H+1 such that
     p|b_(p-1-n).
```

The central product contains at most one prime. More explicitly,

```text
C(n) = 2H+1
```

exactly when

```text
n=3H+1,
2H+1 is prime,
2H+1 divides b_H;
```

otherwise `C(n)=1`.

## Theorem

For every `n>=5`, the four displayed products are pairwise coprime and squarefree, and

```text
E(n)_{>M}     = D(n),
I_dir(n)_{>M} = D(n) C(n) O(n),
I(n)_{>M}     = D(n) C(n) R(n) O(n).
```

Moreover,

```text
T_q1(n)
 := product over primes n/2<p<=n with
      p | b_min(n-p,2p-1-n)
 = D(n) C(n) R(n).
```

## Proof: endpoint rectangle

Fix `p>M`. Then `p>H+1`. For every primitive pair, reduction in the Newton basis gives, whenever `0<=r_p<=H`,

```text
P_{H,a}(n)
 = P_{H,a}(r_p)
 = b_(r_p) Q_{H,a}(r_p)                 (mod p).
```

The member `a=H` has `Q_{H,H}=1`, so

```text
p | G_+(n)
 iff r_p<=H and p|b_(r_p).
```

The primitive adjacent-discriminant theorem shows that no prime `p>H+1` enters the common Padé gcd through the adjacent scale. Hence every such active prime occurs in `G_+(n)` to exactly the valuation supplied by `B_+`, which is one.

Legendre's formula, using `H+1<p`, gives

```text
v_p(B_+) = 1  iff p<=n and r_p<=H,
v_p(B_-) = 1  iff
  (p<=n and s_p<=H)
  or
  (n<p<=n+H+1).
```

Both valuations are zero otherwise, and neither can exceed one in this range. Therefore

```text
v_p(R_+) = 1
 iff p<=n and r_p<=H<s_p.
```

Intersecting with `G_+(n)` proves

```text
E(n)_{>M}=D(n).
```

In particular, the relative endpoint cap intentionally deletes the central overlap where both endpoint binomials contain the same target prime.

## Proof: short multicutoff intersection

For `M<p<=n`, write `n=p+r_p` and put

```text
j_p = min(r_p,s_p).
```

Lucas factorization and Apéry reflection give

```text
Q_n(t) = Q_1(t^p) Q_(j_p)(t)             (mod p).
```

For `n<p<=n+H+1`, put `j_p=p-1-n`; reflected binomial congruences give

```text
Q_n(t) = Q_(j_p)(t)                      (mod p).
```

Every cutoff in `H<=J<=M` is below `p`. Hence the low factor is saturated exactly when `j_p<=H`, and then the transformed polynomial reduces to

```text
T_(n,J)(c)
 = b_(j_p) Q_1(c^p)                      (mod p),  p<=n,

T_(n,J)(c)
 = b_(j_p)                               (mod p),  p>n.
```

Thus `p` divides every cutoff content exactly when `j_p<=H` and `p|b_(j_p)`.

The resulting valuation in the gcd is exactly one. This can be seen in the fast `kappa` presentation:

* on the direct or central branch, the `k=p` term of `kappa_(n,J)` has valuation one because `L(n,p)` is a unit and `v_p(binomial(p,J))=1`;
* on the reflected branch, at `J=H+1` the `k=J` term has `v_p(L(n,J))=1`;
* on the overshoot branch, the same `J=k=H+1` term has `v_p(L(n,J))=1`.

This proves

```text
I(n)_{>M}=D(n)C(n)R(n)O(n).
```

## Proof: direct-safe interval

The direct-safe interval ends at

```text
U=n-H-1.
```

For a direct prime, `p=n-r_p>=n-H>U`, so all cutoffs remain below `p`; it survives. The central prime also has `U=p-1`; it survives. An overshoot prime has `p>n>U`; it survives.

For a reflected-exclusive prime, `r_p>H`, hence

```text
p=n-r_p<=n-H-1=U.
```

The interval therefore includes the loss cutoff `J=p`, where the `q=1` block changes from zero to nonzero and the prime disappears from the content gcd. Hence

```text
I_dir(n)_{>M}=D(n)C(n)O(n).
```

The target identity follows because the genuine top-half `q=1` candidates are precisely the direct, central, and reflected branches with `p<=n`; the overshoot primes are not candidates.

# 3. Exact ideal triangle

Factor the three integers as

```text
E(n)     = E_0(n) D(n),
I_dir(n) = J_0(n) D(n)C(n)O(n),
I(n)     = K_0(n) D(n)C(n)R(n)O(n),
```

where every prime divisor of `E_0,J_0,K_0` is at most `M`. No general divisibility relation exists among these low factors.

Above `M`, however,

```text
gcd(E,I)_{>M}       = D,
gcd(E,I_dir)_{>M}   = D,
gcd(I,I_dir)_{>M}   = D C O,

(I/gcd(I,I_dir))_{>M} = R.
```

Equivalently,

```text
E_{>M} | I_dir_{>M} | I_{>M}.
```

In ideal notation, remembering that divisibility reverses inclusion for principal ideals,

```text
(I_{>M}) subset (I_dir_{>M}) subset (E_{>M}).
```

This is the exact relationship. There is no uncapped global ideal inclusion.

# 5. Can the carriers be combined to purify exactly?

No, not by gcd/lcm ideal arithmetic alone.

With only `E` and `I`, the large-prime support signatures are

```text
class                 E   I    desired
D direct target       1   1      1
C central target      0   1      1
R reflected target    0   1      1
O overshoot nuisance  0   1      0
```

Therefore

```text
gcd(E,I)_{>M}=D
```

loses both central and reflected targets, while

```text
lcm(E,I)_{>M}=D C R O
```

retains all overshoot nuisance.

Adding `I_dir` gives

```text
class                 E   I   I_dir   desired
D direct target       1   1     1       1
C central target      0   1     1       1
R reflected target    0   1     0       1
O overshoot nuisance  0   1     1       0
```

The central target and the overshoot nuisance have the identical signature `(0,1,1)`. Thus no primewise expression formed solely from gcd, lcm, ideal sum, ideal intersection, radical, or quotient-by-common-support operations on these three carriers can distinguish them universally.

The exact concrete collision is already present in the fixtures:

```text
n=16, p=11: central target,       signature (0,1,1),
n=13, p=17: overshoot nuisance,  signature (0,1,1).
```

Small primes give a second obstruction. At `n=36`, the nuisance prime `5` survives all three supports, so even the three-way gcd is not target-pure.

There is an exact reconstruction if one is allowed an explicit prime-range projection and the one-prime central correction:

```text
D(n)
 = gcd(E(n),I_dir(n))_{>M},

R(n)
 = (I(n)/gcd(I(n),I_dir(n)))_{>M},

T_q1(n)
 = D(n) C(n) R(n).
```

Equivalently, and more simply,

```text
T_q1(n) = rad_{M<p<=n} I(n).
```

This is an exact support identity, but it is not a new height theorem: the external interval projection is doing the nuisance removal, and no subexponential integral carrier for that projection follows from the two constructions.

# 6. Dependency-free verifier

The following script uses only the Python standard library. It:

* reconstructs the jointly primitive Padé family by signed maximal minors, with exactly one joint content division;
* recomputes `G_+(n)` and the capped endpoint rectangle for every mismatch through `n=56`;
* reconstructs the Legendre–Euler base content and both multicutoff intersections through `n=200`;
* checks the exact four-factor theorem and the mismatch classifications;
* optionally recomputes the full height-66 Padé family at `n=200` with `--full-200`; by default it uses the exact canonical fixture `G_+(200)=5*17*139*181` and verifies its cap.

```python
#!/usr/bin/env python3
"""Q2658: endpoint-cap versus multicutoff Legendre--Euler audit.

Standard library only.  All arithmetic is exact.
"""

from __future__ import annotations

import argparse
from functools import reduce
from math import comb, gcd


def gcd_list(values):
    return reduce(gcd, (abs(int(value)) for value in values), 0)


def primes_up_to(limit):
    if limit < 2:
        return []
    flags = bytearray(b"\x01") * (limit + 1)
    flags[0:2] = b"\x00\x00"
    p = 2
    while p * p <= limit:
        if flags[p]:
            count = (limit - p * p) // p + 1
            flags[p * p : limit + 1 : p] = b"\x00" * count
        p += 1
    return [p for p in range(2, limit + 1) if flags[p]]


def vp(value, prime):
    value = abs(value)
    exponent = 0
    while value and value % prime == 0:
        value //= prime
        exponent += 1
    return exponent


def factor_string(value):
    value = abs(value)
    if value <= 1:
        return str(value)
    factors = []
    divisor = 2
    while divisor * divisor <= value:
        exponent = 0
        while value % divisor == 0:
            value //= divisor
            exponent += 1
        if exponent:
            factors.append(
                str(divisor) if exponent == 1 else f"{divisor}^{exponent}"
            )
        divisor = 3 if divisor == 2 else divisor + 2
    if value > 1:
        factors.append(str(value))
    return "*".join(factors)


def apery_values(limit):
    if limit == 0:
        return [1]
    values = [1, 5]
    for n in range(1, limit):
        numerator = (
            (34 * n**3 + 51 * n**2 + 27 * n + 5) * values[n]
            - n**3 * values[n - 1]
        )
        denominator = (n + 1) ** 3
        assert numerator % denominator == 0
        values.append(numerator // denominator)
    return values[: limit + 1]


def franel_values(limit):
    return [
        sum(comb(index, part) ** 3 for part in range(index + 1))
        for index in range(limit + 1)
    ]


def forward_differences(values):
    row = list(values)
    result = []
    while row:
        result.append(row[0])
        row = [right - left for left, right in zip(row, row[1:])]
    return result


def eval_newton(coefficients, x):
    return sum(
        coefficient * comb(x, degree)
        for degree, coefficient in enumerate(coefficients)
    )


def multiplication_entry(row, column, differences):
    if column < 0 or column > row:
        return 0
    return comb(row, column) * sum(
        comb(column, shift) * differences[row - column + shift]
        for shift in range(column + 1)
    )


def bareiss_det(matrix):
    """Fraction-free exact determinant with row pivoting."""
    size = len(matrix)
    if size == 0:
        return 1
    assert all(len(row) == size for row in matrix)
    work = [list(map(int, row)) for row in matrix]
    sign = 1
    previous = 1
    for column in range(size - 1):
        pivot_row = next(
            (row for row in range(column, size) if work[row][column]),
            None,
        )
        if pivot_row is None:
            return 0
        if pivot_row != column:
            work[column], work[pivot_row] = work[pivot_row], work[column]
            sign = -sign
        pivot = work[column][column]
        for row in range(column + 1, size):
            for other in range(column + 1, size):
                numerator = (
                    work[row][other] * pivot
                    - work[row][column] * work[column][other]
                )
                assert numerator % previous == 0
                work[row][other] = numerator // previous
            work[row][column] = 0
        previous = pivot
    return sign * work[-1][-1]


def primitive_pade_pair(height, numerator_degree, differences, apery):
    """Return the unique jointly primitive integral Newton pair."""
    denominator_degree = height - numerator_degree
    if denominator_degree == 0:
        denominator = [1]
    else:
        frame = [
            [
                multiplication_entry(row, column, differences)
                for column in range(denominator_degree + 1)
            ]
            for row in range(numerator_degree + 1, height + 1)
        ]
        cofactors = []
        for deleted in range(denominator_degree + 1):
            minor = [
                row[:deleted] + row[deleted + 1 :]
                for row in frame
            ]
            cofactors.append((-1) ** deleted * bareiss_det(minor))
        delta = gcd_list(cofactors)
        assert delta > 0
        denominator = [value // delta for value in cofactors]

    numerator = [
        sum(
            denominator[column]
            * multiplication_entry(row, column, differences)
            for column in range(min(denominator_degree, row) + 1)
        )
        for row in range(numerator_degree + 1)
    ]

    # This is the one joint primitive normalization; no numerator-only divide.
    assert gcd_list(numerator + denominator) == 1
    for node in range(height + 1):
        assert eval_newton(numerator, node) == (
            apery[node] * eval_newton(denominator, node)
        )
    return numerator, denominator


def full_pade_gcd(n, apery):
    height = (n - 1) // 3
    local_apery = apery[: height + 1]
    differences = forward_differences(local_apery)
    values = []
    for numerator_degree in range(height + 1):
        numerator, _ = primitive_pade_pair(
            height, numerator_degree, differences, local_apery
        )
        values.append(eval_newton(numerator, n))
    return gcd_list(values)


def endpoint_cap(n, full_gcd):
    height = (n - 1) // 3
    plus = comb(n, height + 1)
    minus = comb(n + height + 1, height + 1)
    relative_plus = plus // gcd(plus, minus)
    return gcd(full_gcd, relative_plus)


def L(n, k):
    return comb(n, k) * comb(n + k, k)


def truncation_coefficients(n, cutoff, franel):
    coefficients = [
        sum(L(n, index) * franel[index] for index in range(cutoff + 1))
    ] + [0] * n
    for degree in range(1, n + 1):
        lower = max(0, cutoff + 1 - degree)
        upper = min(cutoff, n - degree)
        if lower > upper:
            continue
        coefficients[degree] = sum(
            (-1) ** (cutoff - index)
            * L(n, index + degree)
            * comb(index + degree, index)
            * comb(degree - 1, cutoff - index)
            * franel[index]
            for index in range(lower, upper + 1)
        )
    return coefficients


def kappa_against(n, cutoff, modulus):
    result = modulus
    for index in range(cutoff, n + 1):
        coefficient = L(n, index) * comb(index, cutoff)
        result = gcd(result, coefficient % result)
        if result == 1:
            break
    return result


def legendre_intersections(n, franel):
    height = (n - 1) // 3
    middle = n // 2
    upper_direct = n - height - 1
    gamma = gcd_list(truncation_coefficients(n, height, franel))

    short = gamma
    for cutoff in range(height + 1, middle + 1):
        short = kappa_against(n, cutoff, short)

    direct = gamma
    for cutoff in range(height + 1, upper_direct + 1):
        direct = kappa_against(n, cutoff, direct)

    return gamma, short, direct


def four_factors(n, apery):
    height = (n - 1) // 3
    middle = n // 2
    direct = central = reflected = overshoot = 1
    for prime in primes_up_to(n + height + 1):
        if prime <= middle:
            continue
        if prime <= n:
            r = n - prime
            s = 2 * prime - 1 - n
            if r <= height < s and apery[r] % prime == 0:
                direct *= prime
            elif r <= height and s <= height and apery[r] % prime == 0:
                central *= prime
            elif s <= height < r and apery[s] % prime == 0:
                reflected *= prime
        else:
            s = prime - 1 - n
            if 0 <= s <= height and apery[s] % prime == 0:
                overshoot *= prime
    return direct, central, reflected, overshoot


def interval_part(value, lower, upper):
    result = 1
    for prime in primes_up_to(upper):
        if prime <= lower:
            continue
        exponent = vp(value, prime)
        result *= prime**exponent
    return result


def signature(prime, endpoint, short, direct):
    return (
        int(endpoint % prime == 0),
        int(short % prime == 0),
        int(direct % prime == 0),
    )


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument(
        "--full-200",
        action="store_true",
        help="recompute the complete height-66 Padé family instead of using the exact fixture",
    )
    args = parser.parse_args()

    fixtures = (8, 13, 16, 36, 56, 200)
    maximum = max(fixtures)
    apery = apery_values(maximum)
    franel = franel_values(maximum)

    expected = {
        8:   (1, 5, 1),
        13:  (1, 17, 17),
        16:  (1, 11, 11),
        36:  (25, 5, 5),
        56:  (1, 37 * 61, 61),
        200: (5 * 139 * 181, 5 * 139 * 181, 139 * 181),
    }
    exact_gplus = {
        8: 1,
```
