# Q5866 — branch-selection lemma audit

## Summary

The requested factorization is not available from the supplied data alone. A direct symbolic elimination step is required: substituting

```
L = -X^2*(X*t-r)/(t-r*X),   t=1-r^2
```
into `ca` and reducing modulo the edge equation

```
E=(t-r)*(X*t-r)*(t-r*X)-X*r^4*t
```

must be performed in the polynomial ring `Q[X,r]`. The expression is too large to certify by inspection. The correct Lean-friendly route is not to assert `ca<0` from a guessed factorization, but to produce an explicit remainder identity.

## Exact certificate shape needed

The target identity should have the form

```text
D(X,r)^m * ca(X,L(X,r)) = F(X,r) + E(X,r)*G(X,r)
```

where `D=(t-r*X)^4` (or the minimal denominator power after normalization), and `F` factors into terms whose signs follow from

```
0<X<1,  r<-1,  t=1-r^2<0.
```

A Lean proof can then use:

```lean
have hE : E = 0 := ...
ring_nf at hcert
rw [hE] at hcert
```

followed by positivity lemmas.

## Subresultant inverse route

The identity

```text
S = ca*r + cb
```

only gives

```text
ca = 0 -> cb = 0
```

or, when `ca != 0`,

```text
r = -cb/ca.
```

To prove uniqueness of the negative H-root one needs two additional exact facts:

1. `ca != 0` on the chamber.
2. The reconstructed root satisfies `H=0` because

```text
Res_r(H,E)=Atilde(X,L)
```

and the subresultant chain has no exceptional gcd factor on the chamber.

The second statement is a polynomial identity; the first is the missing sign certificate.

```lean
  (hL : 0 < L) (hL1 : L < 1) :
  ca X L ≠ 0 := by

```

but the proof should consume an exported SOS/factor certificate rather than expand `ca` manually.

## What cannot be claimed yet

No exact elementary factorization proving `ca<0` has been verified here. Numerical samples are insufficient because the requested theorem is global over the connected chamber. The missing artifact is the polynomial remainder/factor certificate produced by a CAS computation (Sage/Singular/Magma) and then imported as a `ring` identity.

Once that certificate exists, the remaining proof is routine `ring + nlinarith` over the chamber inequalities.
